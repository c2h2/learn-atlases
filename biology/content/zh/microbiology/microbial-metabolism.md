动物谋生只有一种方式：用氧气把有机食物氧化掉。植物有两种，白天光合作用，夜里呼吸。细菌与古菌合起来则有好几十种。有的在黑暗中发酵糖类，不需要任何外部氧化剂；有的用硝酸盐、硫酸盐、铁锈或二氧化碳代替氧气来呼吸；有的靠氢气、氨、硫化物或亚铁离子维生，并用 CO₂ 制造其全部有机物质；有的用能吸收红外线的色素收集光；还有的能把大气中的氮——空气里最惰性的分子——变成氨。地球的化学——大气中的氧、土壤里的氮、沉积物中的硫与铁——已被这种多样性塑造了三十亿年以上。

这种多样性没有看上去那么令人眼花缭乱，因为它几乎全部建立一个原理之上：当电子从一个电对转移向还原电势更正的电对时，能量得以保存，而这些能量或者直接进入 ATP，或者（远更常见地）以跨膜离子梯度的形式被捕获。本章展开这一原理，并把它应用于发酵、以氧及以其他受体进行的呼吸、化能无机营养、光能营养、CO₂ 的固定与氮的固定。它建立在[[biochemistry/glycolysis-tca]]与[[biochemistry/oxidative-phosphorylation]]之上，也建立在[[diversity-of-life/bacteria-archaea#def-trophic]]定义的营养类别之上；这些过程在元素循环中的角色是[[microbiology/microbial-ecology]]的主题。

## 细胞的三种需求

任何细胞要生长都需要**能量**（ATP 与离子梯度）、**还原力**（电子，主要携作 NAD(P)H 与还原型铁氧还蛋白，用来从较氧化的前体制备生物量的还原分子）与**碳**（用来搭骨架）。在一个于空气中以葡萄糖生长的异养菌里，葡萄糖供给了全部三者；这就是为什么三者的区分容易被忽视。在其他生物中它们来自不同来源：蓝细菌从光取能量、从水取电子、从 CO₂ 取碳；硝化菌从氨取能量与电子、从 CO₂ 取碳；在光下以琥珀酸盐生长的紫色非硫细菌从光取能量，而碳与电子来自琥珀酸盐。[[diversity-of-life/bacteria-archaea#def-trophic]]的词表（photo-/chemo-、litho-/organo-、auto-/heterotroph）为这些组合命名。

无论来源如何，细胞生物合成的起点都是中央代谢中同样的十来个**前体代谢物**——6-磷酸葡萄糖、6-磷酸果糖、5-磷酸核糖、4-磷酸赤藓糖、磷酸丙糖、3-磷酸甘油酸、磷酸烯醇式丙酮酸、丙酮酸、乙酰辅酶A、α-酮戊二酸、琥珀酰辅酶A 与草酰乙酸——所有的氨基酸、核苷酸、脂质与糖都由它们制成。微生物到达这些前体的方式各不相同。除了熟悉的 Embden–Meyerhof 糖酵解途径，许多细菌，包括 *Pseudomonas* 与产乙醇的 *Zymomonas mobilis*，还经 **Entner–Doudoroff 途径**降解葡萄糖，它每个葡萄糖只产生一个 ATP，但需要的酶蛋白少得多；许多古菌使用两者经修饰的版本，用不同寻常的酶、用铁氧还蛋白而不是 NAD⁺ 作电子受体。

## 氧化还原电势与电子转移的能量

从供体电对向受体电对转移电子所能提供的能量，由二者的**标准还原电势**$E^{\circ\prime}$（pH 7下）决定，见[[biochemistry/bioenergetics#prop-nernst]]的介绍。

::: proposition 氧化还原反应的自由能 {#prop-redox}
把$n$个电子从供体电对（电势$E_\mathrm{donor}$）的还原型成员转移到受体电对（电势$E_\mathrm{acceptor}$）的氧化型成员，

$$
\Delta G^{\circ\prime} = -nF\,\Delta E^{\circ\prime}, \qquad \Delta E^{\circ\prime} = E^{\circ\prime}_\mathrm{acceptor} - E^{\circ\prime}_\mathrm{donor},
$$ {#eq-redox}

其中$F = 96.485$ kJ mol⁻¹ V⁻¹ 为法拉第常数。当受体的电势更正时，反应在标准条件下放能。在实际条件下，每个电对的电势都要用能斯特方程依浓度校正；而对消耗质子的电对，25 °C 时每电子每质子随 pH 每变化一个单位，电势改变$-59$ mV。
:::

微生物所用的电对横跨超过1伏又四分之一。把它们排成一座"氧化还原塔"、最强的还原剂排在顶上，哪些反应能够提供能量便一目了然：

| 电对（氧化型/还原型） | 电子数 | $E^{\circ\prime}$（V） |
|---|---|---|
| CO₂/葡萄糖 | 24 | −0.43 |
| 2 H⁺/H₂ | 2 | −0.41 |
| NAD⁺/NADH | 2 | −0.32 |
| S⁰/H₂S | 2 | −0.27 |
| CO₂/CH₄ | 8 | −0.24 |
| SO₄²⁻/HS⁻ | 8 | −0.22 |
| 延胡索酸/琥珀酸 | 2 | +0.03 |
| NO₂⁻/NH₄⁺ | 6 | +0.34 |
| NO₃⁻/NO₂⁻ | 2 | +0.42 |
| NO₃⁻/N₂ | 每个 N 5 | +0.75 |
| Fe³⁺/Fe²⁺（溶解态，酸性） | 1 | +0.77 |
| O₂/H₂O | 4 | +0.82 |

（表中数值为 pH 7、25 °C 下的标准电势，已取整；Fe³⁺/Fe²⁺ 的数值适用于溶解态离子，而它们只存在于酸性溶液中——中性 pH 下，三价铁以氧化物与氢氧化物沉淀，其电势近0至+0.2 V。）

原则上任何供体都能被表中位于其下方的任何受体氧化。塔顶的有机物与 H₂ 是最好的供体；塔底的 O₂ 是最好的受体；居于其间的许多无机电对依伙伴不同可此可彼。这座"电子塔"因此画出了可能的代谢空间。生长中的细胞里合成一个 ATP 约需50–70 kJ mol⁻¹ 的能量，而能量通常以更小的份额被保存——靠把离子泵过膜。

::: proposition 能量保存的量子 {#prop-quantum}
每摩尔质子以质子动力势$\Delta p$（以伏计，对有能量贮备的膜为负数）向内穿过膜释放$F\lvert\Delta p\rvert$；当$\Delta p = -0.15$ V 时约为14.5 kJ mol⁻¹。ATP 合酶把大约3到4个质子的内移与一个 ATP 的合成偶联（确切数目取决于其转子上$c$亚基的数目；[[biochemistry/oxidative-phosphorylation#prop-stoich]]）。因此，一个反应若能释放出泵送至少一个离子所需的能量，就能支持生长；于是生物可以靠每次周转所获远低于一个 ATP 之值的反应过活，低至大约−10到−20 kJ mol⁻¹（一个经验估计；[[diversity-of-life/bacteria-archaea#prop-gibbs]]）。
:::

## 发酵

::: definition 发酵 {#def-fermentation-micro}
**发酵**是这样一种能量代谢：有机底物既是电子供体，又在部分氧化之后成为电子受体的来源：产物整体的平均氧化态与底物相同，不使用外部受体，ATP 主要通过**底物水平磷酸化**制备——把磷酸基团从一个高能中间物（1,3-二磷酸甘油酸、磷酸烯醇式丙酮酸、乙酰磷酸、丁酰磷酸）转移给 ADP。
:::

一般原理与葡萄糖的主要几种发酵（乳酸型、酒精型）见[[biochemistry/glycolysis-tca#def-fermentation]]。微生物从两方面扩充了这个工具箱：它们发酵糖类之外的许多底物——氨基酸（梭菌的 **Stickland 反应**，其中一个氨基酸被氧化、另一个被还原）、嘌呤、有机酸，甚至乙炔——而且从同一底物造出范围很广的产物，取决于它们如何打发糖酵解释放的电子。

| 发酵 | 从葡萄糖的主要产物 | 生物 |
|---|---|---|
| 同型乳酸 | 2个乳酸 | *Lactococcus*、*Streptococcus*、许多乳杆菌 |
| 异型乳酸 | 乳酸、乙醇、CO₂ | *Leuconostoc*、某些乳杆菌 |
| 酒精型 | 2个乙醇、2个 CO₂ | 酵母、*Zymomonas* |
| 混合酸 | 乙酸、乙醇、乳酸、琥珀酸、甲酸（或 H₂ + CO₂） | *Escherichia*、*Salmonella* |
| 丁二醇 | 2,3-丁二醇、乙醇、CO₂、H₂ | *Enterobacter*、*Serratia* |
| 丁酸与丙酮-丁醇型 | 丁酸、乙酸、丁醇、丙酮、CO₂、H₂ | *Clostridium* |
| 丙酸型 | 丙酸、乙酸、CO₂ | *Propionibacterium freudenreichii*（瑞士干酪的气孔） |

微生物的两个花招把 ATP 的产量提高到糖酵解的每葡萄糖两个以上。第一，丙酮酸可以被 **丙酮酸甲酸裂解酶** 或丙酮酸：铁氧还蛋白氧化还原酶裂解成乙酰辅酶A，后者经乙酰磷酸转成乙酸，再多形成一个 ATP。但乙酰辅酶A 比乙醇或乳酸更氧化，所以制造乙酸会留下电子，而它们必须有个去处——进入乙醇、乳酸或琥珀酸盐，或者最妙的，进入 **H₂**。第二，电子可以由氢化酶作为 H₂ 释放，这就把细胞从必须把电子倒进自己的含碳产物中解脱出来。但来自 NADH 的 H₂ 生成只有在 H₂ 分压保持在很低时才在热力学上可行（H⁺/H₂ 的$E^{\circ\prime}$低于 NAD⁺/NADH），而当耗氢生物如产甲烷菌把它移走时就会如此—— **种间氢传递**，互营的基础（[[diversity-of-life/bacteria-archaea]]）。

::: example 配平一个混合酸发酵 {#ex-mixed-acid}
*E. coli* 在厌氧条件下以葡萄糖生长时，可以把一个葡萄糖变成一个乙酸、一个乙醇和两个甲酸。(a) 通过数 NADH 证明这在氧化还原上是配平的。(b) 每个葡萄糖造出多少个 ATP？(c) 为什么它不能干脆把葡萄糖变成两个乙酸和两个甲酸、多得一个 ATP？
::: solution
(a) 糖酵解把葡萄糖变成2个丙酮酸，产生2个 NADH。丙酮酸甲酸裂解酶把每个丙酮酸裂解成乙酰辅酶A 与甲酸，不发生任何氧化还原变化。一个乙酰辅酶A 变成乙酸（不用 NADH）。另一个被还原成乙醛再到乙醇，消耗2个 NADH。NADH 净额：$2 - 2 = 0$：配平。

(b) 糖酵解：2个 ATP（净）。乙酰辅酶A → 乙酰磷酸 → 乙酸：1个 ATP。合计：每葡萄糖3个 ATP，比同型乳酸发酵多50 %。

(c) 制造两个乙酸会留下2个 NADH 未被氧化，没有受体来再生 NAD⁺；糖酵解会停止。乙酸与乙醇的1 : 1之比是被氧化还原配平逼出来的。甲酸可以被甲酸氢裂解酶复合体裂解成 H₂ 与 CO₂，但这不改变 NADH 的平衡，因为甲酸并不携带来自 NADH 的电子。
:::
:::

发酵在工业上也很重要：乳制品与蔬菜发酵中的乳酸菌、酿酒与烘焙中的酵母，以及 *Clostridium acetobutylicum*——它的丙酮-丁醇发酵由哈伊姆·魏茨曼在第一次世界大战期间开发出来为炸药供应丙酮，如今正为生物燃料复兴（[[biotechnology]]）。

## 用多种受体的呼吸

在呼吸中，来自供体的电子经一条膜结合的**电子传递链**传给外部的终端受体，而链泵出质子（或 Na⁺）建立驱动 ATP 合酶的质子动力势（[[biochemistry/oxidative-phosphorylation#def-chain]]）。细菌的链不同于线粒体之处在于它们是**分支的、模块化的**。例如 *E. coli* 有好几种脱氢酶，把来自 NADH、琥珀酸盐、甲酸、乳酸、3-磷酸甘油或 H₂ 的电子送入一个醌池，又有好几种终端酶从醌取电子：细胞色素 *bo*₃ 氧化酶泵质子而对 O₂ 亲和力低，用于通气良好的条件；细胞色素 *bd* 氧化酶对 O₂ 亲和力极高却不泵质子，用于低 O₂ 时；以及硝酸盐、亚硝酸盐、延胡索酸、二甲基亚砜与三甲胺 *N*-氧化物的还原酶，在 O₂ 缺席时使用。调节因子（FNR 直接感应 O₂；ArcB–ArcA 感应醌池的氧化还原状态；NarX/NarL 感应硝酸盐）把链切换到可得到的最佳受体。主要受体的能量产出在[[biochemistry/oxidative-phosphorylation#ex-acceptors]]算出。

::: warning 发酵不是厌氧呼吸
"厌氧的"描述的是 O₂ 的缺席，而不是能量保存的机制。厌氧呼吸使用电子传递链和一个除 O₂ 以外的外部受体（硝酸盐、硫酸盐、Fe³⁺、CO₂、延胡索酸）；发酵不使用外部受体，其氧化还原配平也不需要链。两者都在无氧时发生，有些生物还在两者之间切换。反过来，发酵也可以在空气中发生：当糖充足时，酵母在 O₂ 存在下把糖发酵成乙醇（Crabtree 效应），而乳酸菌无论 O₂ 在否都发酵。
:::

好几种厌氧呼吸值得细看。

**反硝化作用。**硝酸盐被四个酶逐步还原：NO₃⁻ → NO₂⁻ → NO → N₂O → N₂—— 硝酸盐还原酶（Nar 或 Nap）、亚硝酸盐还原酶（NirK 或 NirS）、一氧化氮还原酶（Nor）与氧化亚氮还原酶（Nos）。*Paracoccus denitrificans* 与许多 *Pseudomonas* 这样的反硝化菌是兼性的：能使用时就用 O₂，O₂ 稀少而硝酸盐可得时便启动反硝化。反硝化把固定氮以 N₂ 送回大气；当最后一步不完全时还会释放 N₂O—— 一种强温室气体，也是如今排放的主要臭氧层消耗物质。有些细菌反而把亚硝酸盐还原成铵（**异化性硝酸盐还原为铵**，DNRA），把氮留在生态系统之内。

**硫酸盐还原。**硫酸盐是一个差的受体（SO₄²⁻/HS⁻ 的$E^{\circ\prime}$是−0.22 V），必须先以 ATP 活化成腺苷5′-磷酸硫酸（APS）才能被还原——这笔投资细胞只能靠随后的传递链收回。*Desulfovibrio* 之类的硫酸盐还原菌氧化 H₂、乳酸或乙酸并产生 H₂S，它赋予缺氧淤泥以气味与黑色（硫化铁）。在海洋沉积物中——海水里硫酸盐丰富——硫酸盐还原把到达海底的有机质的相当一部分氧化掉了。

**铁与锰的还原和胞外电子传递。**Fe³⁺ 与 Mn⁴⁺ 主要以不溶的氧化物矿物存在，所以呼吸它们的细菌必须把电子传出自细胞。*Shewanella oneidensis* 使用跨被膜、伸达外表面的多血红素细胞色素链，并分泌黄素把电子穿梭给矿物；*Geobacter sulfurreducens* 产生导电的胞外丝——最初被解释为菌毛（"纳米线"），2019年经低温电子显微镜证明其中含有聚合的细胞色素（Fengbin Wang 及同事；菌毛与细胞色素丝各自的相对作用仍有争论）。这些生物还能把电子交给电极，这使微生物燃料电池成为可能。

古菌的**甲烷生成**可以被看作以 CO₂ 为终端受体的呼吸（CO₂ + 4 H₂ → CH₄ + 2 H₂O），底物也可以是乙酸的甲基、甲醇或甲胺。它使用独特的辅酶（甲烷呋喃、四氢甲烷蝶呤、辅酶 F₄₂₀、辅酶 M 与辅酶 B），而其最后一步——由带镍辅因子 F₄₃₀ 的甲基辅酶 M 还原酶催化——只存在于产甲烷菌和与之相关的厌氧甲烷氧化古菌中，后者把这条途径倒着运行。**产乙酸菌**如 *Acetobacterium woodii* 经 Wood–Ljungdahl 途径用 H₂ 把 CO₂ 还原成乙酸。两者都生活在热力学可行性的边缘（[[diversity-of-life/bacteria-archaea#ex-methanogen]]）。

::: quiz
一种细菌只在供给硫酸盐时才以乳酸厌氧生长，其生长产生 H₂S 与乙酸。这是哪一类代谢？
- [ ] 乳酸的发酵
- [x] 以硫酸盐为终端电子受体的厌氧呼吸
- [ ] 以 H₂S 为电子供体的化能无机营养
- [ ] 不产氧光合作用
::: solution
生长需要一个外部受体（硫酸盐），它被还原（成 H₂S），同时有机供体（乳酸）被氧化（成乙酸与 CO₂）：这就是呼吸，此处是 *Desulfovibrio* 之类硫酸盐还原菌的硫酸盐呼吸。发酵不需要外部受体。H₂S 是产物，不是电子供体。
:::
:::

## 化能无机营养

化能无机营养者靠氧化无机化合物取得能量。Sergei Winogradsky 于1887年发现了它们（[[microbiology/microbial-world]]），如今已知它们能氧化 H₂、CO、还原态硫化物（H₂S、S⁰、硫代硫酸盐）、Fe²⁺、Mn²⁺、NH₃、亚硝酸盐、亚磷酸盐甚至亚砷酸盐。多数是自养菌，固定 CO₂；有些是**混合营养型**，用无机能源配有机碳。

| 过程 | 反应 | $\Delta G^{\circ\prime}$（kJ 每摩尔供体） | 生物 |
|---|---|---|---|
| 氢氧化 | H₂ + ½ O₂ → H₂O | −237 | *Cupriavidus necator*（"爆鸣气"细菌）、*Aquifex* |
| 硫化物氧化 | H₂S + 2 O₂ → SO₄²⁻ + 2 H⁺ | −798 | *Beggiatoa*、*Thiobacillus*、热液喷口共生菌 |
| 氨氧化 | NH₄⁺ + 1½ O₂ → NO₂⁻ + 2 H⁺ + H₂O | −275 | *Nitrosomonas*、*Nitrosopumilus* |
| 亚硝酸盐氧化 | NO₂⁻ + ½ O₂ → NO₃⁻ | −76 | *Nitrobacter*、*Nitrospira* |
| 亚铁氧化（pH 2） | Fe²⁺ + ¼ O₂ + H⁺ → Fe³⁺ + ½ H₂O | 约−33 | *Acidithiobacillus ferrooxidans*、*Leptospirillum* |
| 厌氧氨氧化 | NH₄⁺ + NO₂⁻ → N₂ + 2 H₂O | −357 | '*Candidatus* Brocadia'、'*Ca.* Kuenenia' |

（厌氧氨氧化的数值按每摩尔铵计，来自标准生成自由能。）

硝化作用分裂在不同生物之间：氨氧化菌（*Nitrosomonas* 之类细菌与丰富的氨氧化古菌）造出亚硝酸盐，亚硝酸盐氧化菌造出硝酸盐；例外是"完全氨氧化"（comammox）的 *Nitrospira*，两样都做（2015年；[[diversity-of-life/bacteria-archaea]]）。氨先被氨单加氧酶氧化成羟胺——该酶以 O₂ 为底物——羟胺再被羟胺氧化还原酶氧化成亚硝酸盐，后者释放出喂养传递链的电子。

化能无机营养者面对一个特殊问题：它们许多供体的电势远高于 NAD⁺/NADH 的（−0.32 V），所以不能直接还原 NAD⁺ 来制备固定 CO₂ 所需的 NADH。它们靠**逆电子传递**解决：用质子动力势把电子沿链的若干部分"向上"驱动，从供体到 NAD⁺。这消耗掉它们所保存能量中的很大一部分，这是亚硝酸盐与铁氧化菌长得慢、产量低的原因之一。

::: example 靠亚铁离子生活 {#ex-iron}
*Acidithiobacillus ferrooxidans* 在 pH 2下靠用 O₂ 氧化溶解的 Fe²⁺ 生长。(a) O₂/H₂O 电对在 pH 7时$E^{\circ\prime} = +0.816$ V。已知它随 pH 每降低一单位上升+59 mV，那么在 pH 2（其余均为标准态）时其电势是多少？(b) 已知 Fe³⁺/Fe²⁺ 的$E^\circ = +0.77$ V（与 pH 无关），计算 pH 2下每摩尔被氧化 Fe²⁺ 的$\Delta G$。(c) 若细胞制造一个 ATP 大约需要60 kJ、并以40 %的效率保存能量，它每摩尔 ATP 必须氧化多少摩尔 Fe²⁺？(d) 为什么嗜中性的铁氧化菌生活在含氧水与缺氧水的交界上？
::: solution
(a) $E = 0.816 + 0.059\times(7 - 2) = 0.816 + 0.295 = 1.11$ V。

(b) $\Delta E = 1.11 - 0.77 = 0.34$ V，$n = 1$，所以$\Delta G = -96.485\times0.34 = -33$ kJ 每摩尔 Fe²⁺。若对 pH 7下的溶解离子计算，产量会缩到$-96.485\times(0.816 - 0.77) = -4.4$ kJ mol⁻¹；酸性抬高 O₂/H₂O 电对的电势，从而让铁反应更值钱。（pH 7下三价铁沉淀，届时相关的电对是矿物那个，近0至+0.2 V。）

(c) 每个 Fe²⁺ 捕获的能量：$0.4\times33 = 13$ kJ；一个 ATP 需要60 kJ，所以每摩尔 ATP 约需$60/13 \approx 4.5$摩尔 Fe²⁺。制造一克细胞需要几十毫摩尔量级的 ATP，再加上为 NAD(P)H 准备的逆电子传递，所以这种细菌必须氧化海量的铁——这就是它作为酸性矿山排水中橙色三价铁沉淀清晰可见的原因，也是它被用来从贫矿中浸提铜与其他金属的原因。

(d) 在中性 pH 下，Fe²⁺ 在 O₂ 的非生物作用下几分钟内即被氧化，所以在充分含氧的水中细菌竞争不过；它们生活在从缺氧带向上扩散的 Fe²⁺ 与向下扩散的低浓度 O₂ 相遇之处，那里的化学反应很慢（例如 *Gallionella* 与 *Mariprofundus*，它们是微好氧菌）。
:::
:::

## 光能营养

光能营养者把光变成化学能。两套很不相同的系统做这件事。

**叶绿素型光能营养**利用这样的反应中心：一对特殊对叶绿素或菌绿素分子受光激发，把一个电子交给一串受体。反应中心有两种类型：**II 型**（还原醌型），见于紫细菌、Chloroflexota 与光系统 II；以及 **I 型**（铁硫型，还原铁氧还蛋白），见于绿硫细菌、太阳杆菌与光系统 I。

::: definition 产氧与不产氧光合作用 {#def-photosynthesis}
在**产氧光合作用**中（Cyanobacteriota，以及由它们衍生而来的藻类与植物的质体），两个串联的光系统 ——PSII 与 PSI—— 把电子从水驱动到 NADP⁺，而水的氧化释放 O₂。在**不产氧光合作用**中（紫色硫细菌与非硫细菌、绿硫细菌、Chloroflexota、太阳杆菌，以及其他一些门的一些成员），单一类型的反应中心驱动**环式电子传递**泵质子合成 ATP；还原 NAD(P)⁺ 所用的电子来自 H₂S、S⁰、H₂、Fe²⁺ 或有机酸之类的供体，常常需经逆电子传递，且不产生 O₂。
:::

Cornelis van Niel 在1930年代研究紫色与绿色硫细菌时，把光合作用写成一般形式 CO₂ + 2 H₂A → (CH₂O) + H₂O + 2 A，其中 H₂A 在硫细菌中是 H₂S、在植物中是 H₂O，并断定植物光合作用释放的 O₂ 来自水——后来用 ¹⁸O 标记的水得到证实（Samuel Ruben、Martin Kamen 及同事，1941）。不产氧光合作用更古老；使用地球上最丰富的电子供体的产氧光合作用在蓝细菌的祖先中演化出来，并在约24亿年前的大氧化事件改造了地球（[[diversity-of-life/origin-of-life]]）。

不产氧光能营养者吸收植物用不上的光。紫细菌的菌绿素 *a* 在活细胞中约在800–890 nm 处吸收，位于近红外；菌绿素 *b* 在1,000 nm 以上吸收；绿硫细菌把菌绿素 *c*、*d* 与 *e* 装进称为**绿小体**的巨大天线，其效率高到让一些成员能活在入光极少的黑海深处，而有一株甚至分离自深海热液喷口——那里唯一的光是热岩的微光（J. Thomas Beatty 及同事，2005）。在分层的池塘或 Winogradsky 柱里，顶上的蓝细菌与藻类吸收红光与蓝光，下面的紫细菌与绿细菌则利用透下来的远红光与红外光。

::: example 一个光子有多少能量？ {#ex-photon}
波长$\lambda$的一摩尔光子的能量为$E = N_Ahc/\lambda$，算下来是$119{,}600/\lambda$ kJ mol⁻¹，$\lambda$以 nm 计。(a) 对680 nm（被 PSII 吸收）、870 nm（紫细菌反应中心）与1,020 nm（菌绿素 *b*）算出它。(b) 紫细菌反应中心每个光子跨膜移动一个电子，在被激发的特殊对与它所还原的醌之间产生约0.5 V 的电势差。870 nm 光子的能量中有多大比例贮存在这个电荷分离之中？
::: solution
(a) 680 nm：$119{,}600/680 = 176$ kJ mol⁻¹。870 nm：$137$ kJ mol⁻¹。1,020 nm：$117$ kJ mol⁻¹。

(b) 每摩尔电子贮存的能量：$F\times0.5 = 96.5\times0.5 = 48$ kJ mol⁻¹；$48/137 = 35\,\%$。其余在使电荷分离又快速又不可逆的过程中作为热散失了。红外光子携带的能量更少，这限制了单个反应中心能产生的电势跨度——而水的裂解需要一个极强的氧化剂，因此需要第二个光系统与之串联，这是原因之一。
:::
:::

**视紫红质型光能营养**使用含视黄醛的蛋白，它们在吸收光时泵送离子：嗜盐古菌的菌视紫红质（Dieter Oesterhelt 与 Walther Stoeckenius，1971）与蛋白视紫红质——后者在透光层海洋的很大一部分细菌中被发现（Oded Béjà 及同事，2000）——把质子泵出胞外；另一些则泵 Na⁺ 或 Cl⁻。视紫红质是一个单一的小蛋白，没有电子传递，也不产生还原力——它只提供能量，补充一种异养的生活。

## 固定碳

自养菌用 CO₂ 构建其全部有机物质。植物与蓝细菌只用**卡尔文-本森循环**，而微生物至少使用七条途径：

| 途径 | 关键特征 | 存在于 |
|---|---|---|
| 卡尔文-本森循环 | RuBisCO；每个磷酸丙糖9个 ATP 与6个 NAD(P)H | 蓝细菌、许多变形菌、植物与藻类 |
| 还原性三羧酸循环 | 三羧酸循环倒转，使用依赖铁氧还蛋白的羧化酶 | 绿硫细菌、*Aquifex*、其他一些 |
| 还原性乙酰辅酶A（Wood–Ljungdahl） | 两个 CO₂ 变成乙酰辅酶A；使用一氧化碳脱氢酶/乙酰辅酶A 合酶；ATP 最省 | 产乙酸菌、产甲烷菌、厌氧氨氧化菌 |
| 3-羟基丙酸酯双循环 | 碳酸氢盐羧化 | *Chloroflexus* |
| 3-羟基丙酸酯/4-羟基丁酸循环 | 耐氧；嗜热嗜酸菌 | *Metallosphaera*、氨氧化古菌 |
| 二羧酸/4-羟基丁酸循环 | 对氧敏感 | *Ignicoccus* 与其他厌氧古菌 |
| 还原性甘氨酸途径 | CO₂ 到甲酸、甘氨酸、丝氨酸与丙酮酸 | *Desulfovibrio desulfuricans*（Irene Sánchez-Andrea 及同事，2020） |

这些途径在能量代价上、在对氧的敏感度上（有几条使用会被 O₂ 摧毁的酶）、以及在它们所利用的碳形态（CO₂ 还是碳酸氢盐）上互不相同。Wood–Ljungdahl 途径花费最少，而且因为它靠金属与简单辅因子运行，是最古老途径的候选者。固定的碳从自养菌流向生物圈的其余部分；异养菌靠它生活。

## 固氮

氮是最常限制生物生长的元素，然而大气是78 %的 N₂。N₂ 的三键异常稳定，而只有细菌与古菌能在生物界打断它。

::: definition 固氮酶 {#def-nitrogenase}
**固氮酶**是把 N₂ 还原成 NH₃ 的酶复合体。它由两个蛋白组成：**铁蛋白**（固氮酶还原酶，NifH），一个含一个[4Fe–4S]簇、水解 ATP 的同二聚体；以及**钼铁蛋白**（固氮酶，NifDK），一个含 P 簇与**铁钼辅因子**（FeMo-co，MoFe₇S₉C· 高柠檬酸）的α₂β₂ 四聚体，N₂ 在其上被结合和还原。电子来自还原型铁氧还蛋白或黄素氧还蛋白，先交给铁蛋白，铁蛋白再把它们每次一个地转给钼铁蛋白，每传一个电子水解两个 ATP。总化学计量为

$$
\mathrm{N_2 + 8\,H^+ + 8\,e^- + 16\,ATP \;\longrightarrow\; 2\,NH_3 + H_2 + 16\,ADP + 16\,P_i}.
$$ {#eq-nitrogenase}

当钼稀缺时，会启用活性部位含钒（VFe）或只含铁（FeFe）的替代固氮酶；它们效率较低且产生更多 H₂。
:::

固氮酶的两个特点塑造了每一个固氮菌的生物学。其一是**代价**：每个 N₂ 十六个 ATP 与八个电子，其中四个电子对之一必然以 H₂ 形式损失，许多固氮菌靠一种"吸收"氢化酶把它重新捕获。固氮昂贵至此，以至于只要有铵可用，细菌就关掉 *nif* 基因、并使酶失活。其二是**对氧的敏感**：两种蛋白都会被 O₂ 不可逆地摧毁，所以固氮菌必须在保护酶的同时，在许多情况下还要用 O₂ 呼吸、或靠光合作用制造 O₂。它们的解决办法包括：

- 厌氧生活（*Clostridium pasteurianum*，1893年由 Winogradsky 分离的第一个自由生活固氮菌）；
- **呼吸保护**：*Azotobacter* 的呼吸快到一个程度，使其细胞质几乎不含 O₂；
- **异形胞**：丝状蓝细菌如 *Anabaena* 与 *Nostoc*，把大约十分之一的细胞分化成异形胞——它没有光系统 II，有一层减缓 O₂ 进入的厚被膜，替整条菌丝固氮并换回糖类；
- **时间分离**：单细胞蓝细菌如 *Crocosphaera* 白天光合作用、夜间固氮；
- **共生**：在豆科植物的根瘤中，根瘤菌（作为类菌体）由植物供给二羧酸，植物则制造 **豆血红蛋白** 来结合 O₂，并以极低的游离浓度把它输送给类菌体的高亲和力氧化酶（[[microbiology/microbial-ecology]]）。

::: example 一克氮的代价 {#ex-nitrogen-cost}
(a) 按[[#eq-nitrogenase]]，固定1 g 氮需要多少摩尔 ATP 与电子？(b) 若电子来自葡萄糖（完全氧化时每葡萄糖24个电子），需要多少葡萄糖来供应？(c) 为什么豆科植物实际付出的比这更高？
::: solution
(a) 1 g N 是$1/14 = 0.0714$摩尔 N，即$0.0357$摩尔 N₂。ATP：$16\times0.0357 = 0.57$摩尔。电子：$8\times0.0357 = 0.29$摩尔。

(b) $0.29/24 = 0.0119$摩尔葡萄糖，$0.0119\times180 = 2.1$ g。ATP 也必须靠氧化更多底物来制造（比如每葡萄糖30个 ATP，则$0.57/30 = 0.019$摩尔，3.4 g），所以最低约为每克氮5–6 g 葡萄糖。

(c) 类菌体还要把能量花在维持、对 O₂ 的防护、把氨同化成氨基酸与生长上；植物则必须建造并维护根瘤、制造豆血红蛋白、运输固定的氮。对结瘤豆科植物碳代价的田间测定值相应地大于化学计量的最低值。
:::
:::

固氮酶还把乙炔（C₂H₂）还原成乙烯，后者用气相色谱很容易测量；**乙炔还原测定**（1960年代开发，其中包括 Ralph Hardy 及同事，1968）是检测与测量培养物、土壤和根瘤中固氮的标准方法。生物固氮每年向陆地与海洋添加大约1亿到2亿吨的氮，与工业哈伯-博施过程相当（[[diversity-of-life/bacteria-archaea]]）。

::: intuition 湖底沉积物的氧化还原阶梯
在沉积物里，最好的受体最先被用完。在近表面，好氧异养菌消耗 O₂；几毫米之内它就没了，反硝化菌接管，直到硝酸盐耗尽；然后是铁与锰还原菌，然后是硫酸盐还原菌；最后，在硫酸盐也耗尽的地方（如硫酸盐稀缺的淡水），是产甲烷菌与发酵菌。沿阶梯而下，每一步每个电子产出的能量更少，所以用更好受体的生物能把电子供体（H₂、乙酸）压到用较差受体的生物无法利用的浓度之下——这就是各条带彼此分离的原因。沿各条带向上，还原产物（Fe²⁺、H₂S、CH₄、NH₄⁺）遇到下来的氧化剂，化能无机营养者就生活在每一道边界上。整根柱子是一座在空间中铺开的氧化还原塔（[[microbiology/microbial-ecology]]）。
:::

::: application 工作中的微生物代谢
本章的每一个过程都在被人使用。乳酸、酒精与丙酸发酵制造食品与饮料；丙酮-丁醇与乙醇发酵制造溶剂与燃料。反硝化与厌氧氨氧化在污水处理厂从污水中除去氮；产甲烷菌在厌氧消化器里把废物变成沼气。氧化铁与硫的嗜酸菌从矿石中浸提铜、金与铀（生物采矿）。豆科植物根瘤中的根瘤菌与稻田中蓝细菌的固氮替代了肥料。*Cupriavidus necator* 的聚羟基丁酸酯是一种可生物降解塑料，而被工程化的化能无机自养菌与产乙酸菌正被开发用来把 CO₂、H₂ 与 CO 变成化学品（[[biotechnology]]）。
:::

::: history
巴斯德在1861年描述了丁酸发酵中的"无空气的生活"。Winogradsky 用 *Beggiatoa* 发现了化能无机营养（1887年）与硝化菌（1890年），并分离了 *Clostridium pasteurianum*（1893年）。Hermann Hellriegel 与 Hermann Wilfarth 在1886–1888年间证明，豆科植物只有当根部结瘤时才固氮；Martinus Beijerinck 于1888年分离出根瘤菌。Theodor Engelmann 在1883年发现紫细菌会在光下聚集，并被红外波段吸引；van Niel 对光合作用的比较生物化学研究（1931年起）把光合作用方程推广为一般形式。Kluyver 的"生物化学的统一性"（1926年）与米切尔（Peter Mitchell）的化学渗透理论（1961年）提供了共同的框架；Rudolf Thauer、Kurt Jungermann 与 Karl Decker 关于厌氧菌能量学的综述（1977年）提供了至今沿用的热力学数据表。2000年以来，厌氧氨氧化（1995–1999年）、蛋白视紫红质（2000年）、comammox（2015年）与新的固碳途径的发现表明，这份清单尚未闭合。
:::

::: summary
- 细胞需要能量、还原力与碳；中心代谢（Embden–Meyerhof 途径、Entner–Doudoroff 途径、TCA 循环）为生物合成提供约十二种前体代谢物。
- 电子传递的能量为$\Delta G^{\circ\prime} = -nF\Delta E^{\circ\prime}$；氧化还原塔从有机物与 H₂（约−0.4 V）一直排到 O₂（+0.82 V）。能量以每泵出一个离子（约−15 kJ mol⁻¹）为单位被保存，因此小的能量产出也能养活生命。
- 发酵在内部平衡氧化还原，并靠底物水平磷酸化制造 ATP；经乙酰磷酸生成乙酸会追加 ATP，而释放 H₂—— 由于耗 H₂ 伙伴的存在才成为可能——把电子释放出去。
- 细菌的呼吸链是分支的、模块化的；无氧呼吸使用硝酸盐（反硝化）、Fe³⁺ 与 Mn⁴⁺（伴随胞外电子传递）、硫酸盐（先活化为 APS）、CO₂（产甲烷、产乙酸）与其他受体。
- 化能无机营养者氧化 H₂、还原态硫化物、Fe²⁺、NH₃ 与亚硝酸盐；许多需要逆电子传递来产生 NAD(P)H。pH 2下的铁氧化每个 Fe²⁺ 约产出−33 kJ。
- 光能营养者使用叶绿素型反应中心（I 型与 II 型；产氧的用两个串联的光系统，不产氧的用单个并伴环式电子流），或使用基于视黄醛的视紫红质泵。
- 至少七条途径固定 CO₂：卡尔文-本森循环、还原性三羧酸循环、Wood–Ljungdahl 途径、数条羟基丙酸与羟基丁酸循环，以及还原性甘氨酸途径。
- 固氮酶（铁蛋白与钼铁蛋白）以16个 ATP 与8个电子的代价把 N₂ 还原成 NH₃，并产生 H₂；它被 O₂ 摧毁，固氮菌对此的对策是厌氧生活、呼吸保护、异形胞、时间分离与共生。
:::

## 习题

::: exercise 读懂氧化还原塔 {level=1}
利用氧化还原电势表，判断下列各项原则上能否支持能量保存：(a) 以硫酸盐氧化 H₂；(b) 以硝酸盐氧化 H₂S；(c) 以硫酸盐氧化 NH₄⁺；(d) 以硝酸盐氧化琥珀酸。
::: solution
(a) 可以：H⁺/H₂（−0.41 V）位于 SO₄²⁻/HS⁻（−0.22 V）之上；$\Delta E = +0.19$ V。(b) 可以：S⁰/H₂S（−0.27 V）或 SO₄²⁻/HS⁻（−0.22 V）位于 NO₃⁻/NO₂⁻（+0.42 V）之上；许多硫氧化菌就是反硝化菌。(c) 不行：NO₂⁻/NH₄⁺（+0.34 V）位于 SO₄²⁻/HS⁻（−0.22 V）之下，所以该反应强烈吸自由能。(d) 可以：延胡索酸/琥珀酸（+0.03 V）位于 NO₃⁻/NO₂⁻（+0.42 V）之上；$\Delta E = 0.39$ V。
:::
:::

::: exercise 氢与氧 {level=1 check="-237"}
已知 2H⁺/H₂ 的$E^{\circ\prime} = -0.414$ V、O₂/H₂O 的+0.816 V，计算 H₂ + ½ O₂ → H₂O 的$\Delta G^{\circ\prime}$，以每摩尔 H₂ 的 kJ 计。
::: solution
$\Delta E = 0.816 - (-0.414) = 1.230$ V，$n = 2$：$\Delta G^{\circ\prime} = -2\times96.485\times1.230 = -237$ kJ mol⁻¹。
:::
:::

::: exercise 代谢方式的命名 {level=1}
把下列过程分别归入发酵、好氧呼吸、无氧呼吸、化能无机营养或光能营养（可能不止一项适用）：(a) *Desulfovibrio* 以硫酸盐氧化 H₂；(b) *Lactococcus* 由乳糖制造乳酸；(c) *Nitrobacter* 以 O₂ 氧化亚硝酸盐；(d) *Chromatium* 在光下以 H₂S 固定 CO₂；(e) *Paracoccus* 以硝酸盐氧化乙酸。
::: solution
(a) 无氧呼吸与化能无机营养（无机供体 H₂）。(b) 发酵。(c) 通过好氧呼吸的化能无机营养（无机供体，O₂ 受体）。(d) 光能营养（不产氧光合作用），以 H₂S 为电子供体：一种光能无机自养菌。(e) 有机供体的无氧呼吸（反硝化）。
:::

::: exercise 亚硝酸盐氧化菌长得慢 {level=2 check="-76"}
(a) 已知 NO₃⁻/NO₂⁻ 的$E^{\circ\prime} = +0.42$ V，计算 NO₂⁻ + ½ O₂ → NO₃⁻ 每摩尔亚硝酸盐的$\Delta G^{\circ\prime}$（取到最接近的 kJ）。(b) 与 O₂ 氧化葡萄糖（$-2{,}870$ kJ mol⁻¹）比较。(c) 给出两条理由，说明 *Nitrobacter* 为什么生长慢、产量低。
::: solution
(a) $\Delta E = 0.816 - 0.42 = 0.396$ V，$n = 2$：$-2\times96.485\times0.396 = -76$ kJ mol⁻¹。(b) 每摩尔供体，葡萄糖释放的能量几乎是它的40倍；按每个电子算，两者之比是$2{,}870/24 = 120$ kJ 对 $76/2 = 38$ kJ。(c) 每个电子携带的能量很少，所以每合成一个 ATP 都必须氧化大量亚硝酸盐；而供体电势（+0.42 V）远高于 NAD⁺/NADH，为固定 CO₂（经卡尔文循环，其本身就很贵）制备还原力必须付出高昂代价的逆电子传递。
:::
:::

::: exercise 异型乳酸发酵的账目 {level=2 check="1"}
在异型乳酸发酵中，葡萄糖经磷酸酮醇酶途径变成一个乳酸、一个乙醇与一个 CO₂。6-磷酸葡萄糖被氧化成5-磷酸核酮糖与 CO₂（产生2个 NAD(P)H），后者被劈分成3-磷酸甘油醛与乙酰磷酸。数一数 ATP 与 NAD(P)H，并给出每个葡萄糖的净 ATP。
::: solution
ATP：磷酸化葡萄糖花去−1；3-磷酸甘油醛→丙酮酸得+2 ATP 与+1 NADH；丙酮酸→乳酸用去1 NADH。乙酰磷酸→乙酰辅酶A→乙醛→乙醇用去2 NAD(P)H（并放弃了乙酰酸激酶本可制造的那个 ATP）。NAD(P)H：+2（氧化脱羧）+1（3-磷酸甘油醛脱氢酶）−1（乳酸）−2（乙醇）= 0，平衡。净 ATP：$-1 + 2 = 1$ 个每个葡萄糖——是同型乳酸发酵的一半。如果有果糖可用作额外的电子受体（被还原成甘露醇），乙酰磷酸就可以改而生成乙酸并多得一个 ATP，正如 *Leuconostoc* 所做的那样。
:::
:::

::: exercise 保护固氮酶 {level=2}
就下列每一种，解释固氮酶如何受到保护、免遭 O₂ 破坏：(a) 在光中以 N₂ 生长的 *Anabaena*；(b) 空气中的 *Azotobacter vinelandii*；(c) 大豆根瘤中的 *Bradyrhizobium*；(d) *Clostridium pasteurianum*。在哪些情况下你会预期每一个细胞都有固氮酶活性？
::: solution
(a) 异形胞没有 PSII（不释放 O₂），有一层阻止 O₂ 进入的厚糖脂被膜，且呼吸活性高；只有异形胞（约占细胞的5–10 %）固氮。(b) 极高的呼吸速率在细胞表面消耗 O₂，使内部接近缺氧；此外还有一种蛋白（FeSII），在氧化胁迫期间把固氮酶结合成受保护的失活形式。(c) 植物根瘤限制 O₂ 扩散，豆血红蛋白以极低的游离浓度（几十纳摩尔）把 O₂ 输送给类菌体的高亲和力末端氧化酶。(d) 它是生活在缺氧微域的严格厌氧菌，无需任何保护。在(b)与(d)中每个细胞都能固氮；在(c)中是每个类菌体、但自由生活的细胞不能；在(a)中只有异形胞。
:::

::: exercise 来自一个光子的能量 {level=2 check="45"}
光系统 I 在700 nm 处吸收，每次循环把一个电子从质体蓝素（$E^{\circ\prime} \approx +0.37$ V）移到铁氧还蛋白（$E^{\circ\prime} \approx -0.43$ V）。光子的能量有多大比例被贮存在还原型铁氧还蛋白中？用$E = 119{,}600/\lambda$ kJ mol⁻¹ 与$F = 96.485$ kJ mol⁻¹ V⁻¹，并给出一个整数。
::: solution
光子能量：$119{,}600/700 = 170.9$ kJ mol⁻¹。贮存能量：$F\times\Delta E = 96.485\times0.80 = 77.2$ kJ mol⁻¹。比例：$77.2/170.9 = 45\,\%$。其余以热的形式耗散在那些快速、近乎不可逆的步骤中——正是它们阻止已分离的电荷重新结合。
:::
:::

::: exercise 解读沉积物剖面 {level=3}
在一个淡水湖的沉积物中，间隙水剖面显示：O₂ 从表面的250 µmol L⁻¹ 降到3 mm 处的零；硝酸盐在2 mm 处出现峰值、到8 mm 处消失；溶解的 Fe²⁺ 出现在10 mm 以下、在30 mm 处达到峰值；硫酸盐（淡水里含量低，上覆水100 µmol L⁻¹）降到40 mm 处的零；甲烷出现在40 mm 以下并随深度上升。(a) 解释这个序列。(b) 硝酸盐为什么在表面之下而不是在表面处出现峰值？(c) 当 Fe²⁺ 与 CH₄ 向上扩散时，你预期会发生什么？(d) 在海洋沉积物中剖面会有什么不同？
::: solution
(a) 电子受体按能量产出递减的次序被使用（O₂、硝酸盐、Mn⁴⁺ 与 Fe³⁺ 氧化物、硫酸盐，然后 CO₂ 用于产甲烷作用）；使用更好受体的生物在为供体而竞争中胜过其余生物，所以每种受体都在下一种被利用之前被耗尽。(b) 分解释放的铵在含氧层中被硝化，产生硝酸盐；在其下方，反硝化把它移除。硝酸盐的峰值标记出这样一个层带：硝化作用在其刚好处制造硝酸盐，而反硝化作用在其处把硝酸盐消耗掉。(c) Fe²⁺ 在含氧边界附近被重新氧化——或通过化学作用，或通过铁氧化菌——沉淀出铁氧化物（一层橙色物质）；CH₄ 在含氧边界附近被好氧甲烷氧化菌氧化，并部分地被厌氧氧化（偶联硫酸盐、硝酸盐或铁），所以只要沉积物未受扰动，很少有甲烷逸出。(d) 海水约含28 mmol L⁻¹ 硫酸盐，所以硫酸盐还原将延伸数米之多、并主导有机碳的氧化；产甲烷作用要到硫酸盐带之下深得多的地方才开始，而甲烷的厌氧氧化偶联硫酸盐还原会在硫酸盐-甲烷转换带消耗掉大部分甲烷。
:::

::: exercise 化能无机营养者的选择 {level=3}
一种细菌能以 O₂ 为受体，把 H₂S 一直氧化到硫酸盐（8个电子），或只氧化到元素硫（2个电子）。使用−0.27 V（S⁰/H₂S）、−0.22 V（SO₄²⁻/HS⁻）与+0.82 V（O₂/H₂O）的$E^{\circ\prime}$值，(a) 分别计算每摩尔 H₂S 的$\Delta G^{\circ\prime}$。(b) *Beggiatoa* 在硫化物充裕时贮存硫滴，在硫化物耗尽时把它们氧化成硫酸盐。解释这一举动的益处。(c) 一些 *Thiomargarita* 与 *Beggiatoa* 把硝酸盐贮存在液泡中。这让它们能够做什么？
::: solution
(a) 到 S⁰：$\Delta E = 0.82 + 0.27 = 1.09$ V，$n = 2$：$-2\times96.485\times1.09 = -210$ kJ mol⁻¹。到硫酸盐：$\Delta E = 0.82 + 0.22 = 1.04$ V，$n = 8$：$-8\times96.485\times1.04 = -803$ kJ mol⁻¹。(b) 氧化到 S⁰ 很快、每个硫化物用的 O₂ 更少，使细胞能在硫化物丰富时快速处理它；贮存的 S⁰ 是一份电子供体的储备（总能量的约四分之三仍在其中），可以留待以后使用，就像脂肪储备。(c) 贮存的硝酸盐是一份电子受体的储备：细胞可以靠反硝化或 DNRA，在缺氧、硫化物丰富而无 O₂ 的沉积物中氧化硫化物，再回到含氧或富硝酸盐的带中重新"充电"——把供体与受体在空间与时间上分离开来。
:::
