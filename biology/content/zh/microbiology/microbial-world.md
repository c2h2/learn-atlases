一茶匙花园土壤里的细菌细胞比地球上的人口还多，而近表层海水每一毫升约含一百万个细菌和比这多十倍的病毒。它们没有一种能用肉眼看见。在人类历史的几乎全部时间里，这个占生命绝大多数的隐形世界不为所知，而它的种种效应——发酵、腐败、肥沃的土壤、传染病——被归结为生命力、瘴气或神意。当透镜好到足以看见微生物时，微生物学开始了；而当人们学会一次只培养一种、并证明每一种都做什么时，它成为了一门科学。

本章介绍微生物学家所研究的这些生物、发现它们并确立其种种活动的实验，以及今天用来观察、计数、培养和鉴定它们的方法。它的定量主题是计数：微生物学里的几乎每一项测量都始于对细胞或菌落的计数，而泊松分布告诉我们这样的计数有多可信。微生物的细胞生物学是[[microbiology/microbial-cells]]的主题，它们的生长见[[microbiology/microbial-growth]]，原核谱系的概览见[[diversity-of-life/bacteria-archaea]]。

## 什么是微生物？

"微生物"（microbe）与"微生物有机体"（microorganism）不是分类学名词。它们按单一性质——不借助显微镜就小到无法被单独看见——把生物归为一类，因而横切生命之树。

::: definition 微生物 {#def-microbe}
**微生物**（microorganism，即 microbe）是只有在显微镜下才能被逐个研究的生物或感染性因子，通常因为其小于约0.1 mm。这个术语涵盖整个**细菌**与**古菌**两域；真核生物中单细胞的与简单多细胞的**真菌**（酵母与霉菌）、**原生生物**（原生动物与单细胞藻类）以及微型藻类；还有非细胞的**病毒**及其他亚病毒因子——它们不是细胞，另作处理（[[microbiology/viruses]]）。微生物学之为一个领域，既由它研究的生物界定，也由它的方法界定——显微术、纯培养、稀释计数，以及日益增多的 DNA 测序。
:::

即便在微生物世界内部，尺寸范围也很宽：

| 微生物 | 典型尺寸 | 备注 |
|---|---|---|
| 脊髓灰质炎病毒 | 直径30 nm | 最小的动物病毒之一 |
| 噬菌体 T4 | 头部约90 nm×120 nm，尾约100 nm | 感染 *Escherichia coli*（大肠杆菌） |
| '*Candidatus* Pelagibacter ubique'（SAR11 进化枝） | 约0.2 µm×0.6 µm | 海洋中数量最多的细胞之一 |
| *E. coli* | 约1 µm×2 µm | 实验室主力 |
| 拟菌病毒（Mimivirus） | 含纤维在内颗粒约0.75 µm | 阿米巴的"巨型病毒"，大到能在光学显微镜下看见（Bernard La Scola 及同事，2003） |
| *Saccharomyces cerevisiae*（酿酒酵母） | 5–10 µm | 单细胞真菌 |
| *Paramecium*（草履虫） | 体长约100–300 µm | 纤毛虫原生生物，处于肉眼可见的极限 |

细胞尺寸的下限由容纳一个基因组、核糖体和代谢机器所需的空间决定，上限由扩散与表面积对体积之比决定（[[cell-biology/cells-and-microscopy#prop-sv]]）。多数细菌和古菌都接近下限。

::: warning "微生物"不是一个自然类群
因为这个词按尺寸归类，它包含三个域的成员，而酵母与你的亲缘关系远比与 *E. coli* 的近。说某物"是一种微生物"，告诉你的是该怎样研究它，而不是它与什么亲缘相关、它会做什么。同样，"病菌"（germ）指导致疾病的微生物，而绝大多数微生物不是病菌：它们自由生活，或是植物与动物无害或有益的伙伴（[[microbiology/microbes-and-hosts]]）。
:::

## 看见无形者：列文虎克

胡克（Robert Hooke）的《显微图谱》（*Micrographia*，1665）已经载有一幅显微真菌的插图——他用复式显微镜看到的生长在皮革上的蓝霉。但第一个看见细菌与原生生物、并将其描述得我们今天仍能认出的人，是代尔夫特的布料商列文虎克（Antonie van Leeuwenhoek）。他磨制极小的近球形透镜，把每片夹在两块金属板之间；贴近眼睛时，它们能放大近270倍，优于当时任何复式显微镜——后者的透镜有严重的色差与球差。

从1673年起，列文虎克用荷兰语致信伦敦的皇家学会。1674年，他描述了湖水中的"微小动物"（animalcules）；1676年10月9日的信描述了他浸过胡椒粒的水里出现的生物：许多是原生生物，而最小的、他估计比虱眼小一千倍的，是细菌。他对它们数目的估计——一滴水里数百万个——是微生物学中的第一个定量陈述。1683年，他画下了自己牙垢中的杆菌、球菌与一种螺旋形生物。皇家学会一直持怀疑态度，直到1677年胡克重复出了这些观察。

列文虎克之后近两个世纪里，微生物始终是奇珍。在微生物学能成为实验科学之前，必须解决三个问题：微生物是否自然发生于非生命物质？它们是否引起伴随它们的化学变化（发酵、腐败）？特定的微生物是否导致特定的疾病？

## 自然发生及其驳斥

生命不断从非生命物质中产生——老鼠出于谷物、蛆出于腐肉——这一观念古已有之。雷迪（Francesco Redi）1668年证明，盖上纱布的罐子里肉上不生蛆，纱布挡得住苍蝇却放得住空气。但无论怎么做，微生物都会出现在煮过的肉汤里，它们似乎是自然发生的完美例证。John Needham（1748）把羊肉汤在加塞的瓶中短暂煮沸，几天后发现里面挤满了微生物；Lazzaro Spallanzani（1760年代）把肉汤更久地煮沸、瓶口熔封，发现肉汤是无菌的——但 Needham 反驳说，长时间煮沸破坏了肉汤和其上方空气中的"生命力"。

巴斯德（Louis Pasteur）1859–1861年的实验排除了这一反驳。他把装肉汤的烧瓶的瓶颈拉成长长的 S 形弯管，煮沸肉汤，让瓶子向空气敞开。尘埃及其上的微生物沉在瓶颈的弯曲处；空气能自由到达肉汤，而肉汤数月保持清澈。当他折断瓶颈，或把瓶子倾斜使肉汤碰到弯管中的尘埃，几天之内里面就挤满了微生物。这个实验是好设计的典范：Needham 假说所需要的空气在两种处理中都存在，不同的只是颗粒能否到达。

还剩一个难题：干草浸液即使彻底煮沸常常也无不了菌。1876–1877年，Ferdinand Cohn 发现 *Bacillus* 形成耐热**内生孢子**（[[microbiology/microbial-cells]]），丁铎尔（Tyndall）证明这类浸液可以在连续几天里反复煮沸而灭菌——每一轮杀死自上一轮以来萌发的孢子。孢子的耐热性正是实验室灭菌采用加压蒸汽的原因（[[microbiology/antimicrobials]]）。

::: intuition 对照是干什么用的
这段历史里每个著名实验都是对一个具体反驳的回答。Spallanzani 密封的瓶子回答的是"微生物来自空气"，Needham 反驳"你破坏了空气的生命力"；巴斯德的鹅颈瓶留下了空气而除去了颗粒。当你设计或阅读一个实验时，要问每个对照排除了哪种备择解释——又让哪种解释站立未倒。
:::

## 作为变化之因的微生物：发酵与疾病

巴斯德是通过化学走向微生物的。1850年代研究发酵时他证明，乳酸发酵伴随一种特定的微生物（1857），酒精发酵依赖活的酵母，而葡萄酒与啤酒变酸由沾污的微生物引起，这些微生物可以用温和加热杀死—— **巴氏消毒**。他还发现有些微生物无氧也能生活（他称它们"厌氧"的），而且酵母在无空气时比在有空气时每克生长消耗更多的糖——这一观察后来被称为 **巴斯德效应**。每种发酵似乎各有自己的微生物——一条专一性原则，他很快把它移用到疾病上。（布赫纳（Eduard Buchner）1897年证明酵母的无细胞提取物能发酵糖，所以发酵本身是酶的作为，而不是"生命"使然；见[[biochemistry/glycolysis-tca]]。）

传染病由活的因子引起这一想法，Girolamo Fracastoro 在1546年就已提出，并在1840–1860年代获得实践支持。Ignaz Semmelweis 于1847年证明，用氯石灰溶液洗手大大降低了维也纳一家产科病房产褥热的死亡；受巴斯德启发的 Joseph Lister 在1867年引入了石炭酸（苯酚）防腐外科。两者都没有证明疾病的原因。那需要一种分离单一微生物的方法。

### 纯培养

一份来自自然的样品含有许多种微生物，而在液体培养基里它们混杂地生长。科赫（Robert Koch）是普鲁士沃尔什泰因的一位乡村医生，他发展出使分离成为可能的技术。

::: definition 纯培养与菌落 {#def-pure-culture}
**纯培养**（无菌培养，axenic culture）只含一种细胞，全部由一个细胞传代而来。在固体培养基上，一个细胞长成一团可见的后代，即**菌落**，它是一个克隆（除非发生突变）。从一个分散良好的菌落挑取材料、接种到新鲜培养基中培养，即得纯培养。**菌株**是由一次分离得到的纯培养，以代号指明（*E. coli* K-12、*Bacillus subtilis* 168）。
:::

科赫起初把细菌培养在煮土豆片上，之后培养在用明胶固化的营养肉汤上（1881）。明胶在体温下熔化，而且会被许多细菌消化；琼脂是一种来自红藻的多糖，在近85 °C 熔化、近40 °C 凝固，几乎不被细菌分解，它是由 Fanny Angelina Hesse 根据烹饪经验建议给她的丈夫、科赫的助手之一 Walther Hesse 的（约1881年）。另一位助手 Julius Petri 在1887年描述了他那个带盖的浅玻璃皿。划线平板——把样品薄薄涂开在琼脂表面，使划线上某处单个细胞落得足够远、能各自形成单独的菌落——至今仍是获得纯培养的标准方法。

科赫在1876年研究炭疽时使用了这些方法：他跟踪了 *Bacillus anthracis* 的生活史（包括其孢子），并证明在动物体外的多次传代后，细菌仍能使小鼠致病。1882年他鉴定出结核的致病菌 *Mycobacterium tuberculosis*。这些研究的逻辑被总结为如今所称的科赫法则。

::: definition 科赫法则 {#def-koch}
一个微生物若满足以下条件就被接受为一种疾病的原因：(1)在每例该病中都存在而健康宿主中不存在；(2)能从患病宿主分离并培养成纯培养；(3)纯培养导入健康的易感宿主后引起该病；(4)能从实验感染的宿主再次分离出同一微生物。这些标准以这一形式由 Friedrich Loeffler（1884）与科赫（1884，1890）提出。
:::

::: warning 法则是充分的检验，不是因果的定义
科赫本人知道法则并不总能满足。许多宿主携带病原体而不发病（第一条对霍乱、脊灰等许多疾病都不成立）；有些病原体无法在纯培养中生长（梅毒的病原体 *Treponema pallidum*，以及宿主细胞外的一切病毒）；有些疾病没有动物模型；还有些疾病由群落而非单一物种引起。Stanley Falkow（1988）提出了法则的分子版本——问某个特定基因是否与疾病相关、使其失活是否降低毒力、恢复它是否恢复毒力；David Fredricks 与 David Relman（1996）提出了基于序列的版本。生物学中的因果由相互印证的证据线确立，而不是固定的清单。
:::

1876年到约1900年间——细菌学的"黄金时代"——引起大多数重大细菌性疾病的细菌被鉴定出来，主要出自科赫与巴斯德两家的学派。临床方面属于[医学图谱：微生物学](/learn/medicine/course.php?c=microbiology)；对我们要紧的是，纯培养把微生物从集体的"腐败之因"变成了具有稳定、可遗传性状的个体生物。

## 生态学传统：富集

第二个传统在荷兰与俄罗斯提出不同的问题：微生物在自然界里做什么？它的中心工具是**富集培养**。

::: definition 富集培养 {#def-enrichment}
**富集培养**是这样设计的一种培养基与条件组合：只有具备某种特定能力的生物才能在其中生长，其中接入预计此类生物稀少的自然样品。条件在选择生物：反复转接使之富集，直到它们占据优势，然后就能以纯培养把它们分离出来。Martinus Beijerinck 总结了这一原则："万物无处不在，环境选择"（这句话以这一形式出自 Lourens Baas Becking，1934）。
:::

Sergei Winogradsky 于1887年通过观察丝状硫细菌 *Beggiatoa* 氧化硫化氢并储存硫颗粒而发现了**化能无机营养**，并于1890年分离出硝化细菌——它们只靠氨和 CO₂ 生长，在医学细菌学的有机培养基上根本无法生长——他改用硅胶固化的平板。Martinus Beijerinck 于1888年分离出固氮的根瘤菌，1901年又通过在不含结合氮的培养基上富集——这样只有固氮菌能生长——分离出自由生活的 *Azotobacter*。**Winogradsky 柱**——一根装有添加纤维素与硫酸盐的淤泥、置于光下的试管——数周之间沿氧气与硫化物的梯度发育出不同微生物的分层，是[[microbiology/microbial-metabolism]]与[[microbiology/microbial-ecology]]讨论的氧化还原化学的活演示。

从这个"代尔夫特学派"产生了 Albert Jan Kluyver 与 Hendrick Jean Louis Donker（1926）的**生物化学的统一性**概括：在微生物代谢令人眼花缭乱的多样性之下，是同样少数几类反应，首先是氢（电子）在分子之间的转移。

::: example 设计一个富集 {#ex-enrichment}
你想从池塘淤泥里分离一种细菌：(a)在缺氧条件下固定 N₂ 并用光取能；(b)把氨氧化为亚硝酸盐并固定 CO₂。指定培养基与条件，并解释每项选择选什么、排什么。
::: solution
(a) 不含结合氮（无铵、硝酸盐或氨基酸）的矿物培养基，以苹果酸之类有机酸为碳源，隔绝空气密封，在光下培养。缺乏结合氮选择固氮菌；无氧排除好氧菌；无氧之下的光选择不产氧光能营养菌，如紫色非硫细菌，它们随后能胜过必须发酵苹果酸取得能量的厌氧异养菌。把一些瓶子放在暗处培养是有用的对照。

(b) 以铵为唯一能源、碳酸氢盐为唯一碳源、完全不含有机碳的矿物培养基，在空气中暗处培养，并把 pH 维持在近中性（硝化释放酸）。只有氧化氨的化能无机自养菌能生长。进展靠亚硝酸盐的出现来追踪。氨氧化菌长得慢（代时一天或更长），所以富集要几个星期，而靠痕量有机物生活的杂菌必须靠反复转接和稀释除去。
:::
:::

## 微生物计数

微生物学家无时无刻不在数细胞：测生长、制备标准接种物、测消毒剂的杀灭能力，或者估计一克土壤里生活着多少细菌。方法有两族，它们测量的东西不同。

**总数计数**数所有细胞，无论死活。细胞可以在已知深度的计数室里于显微镜下计数（Petroff–Hausser 计数室或血细胞计数板）；或者用荧光 DNA 染料（如 DAPI 或 SYBR Green）染色、收集在黑色膜滤器上、以**落射荧光显微术**计数（John Hobbie、Rutger Daley 与 Sigvard Jasper，1977）；或者在**流式细胞仪**里让细胞逐个流过激光时计数，后者还能测每个细胞的大小与荧光。光密度——悬浮液对光的散射——是生物量的快速间接量度（[[microbiology/microbial-growth]]）。

**活菌计数**只数在所给条件下能分裂的细胞，办法是让每个细胞长成一个菌落或一瓶浑浊培养。结果以**菌落形成单位**（CFU）表示，因为一个菌落可以来自一团长或链状的细胞，而不只是一个细胞。

::: example 计数室里的直接计数 {#ex-chamber}
一个 Petroff–Hausser 计数室的方格边长0.05 mm、深度0.02 mm。对一份稀释的细菌悬浮液计数，得平均每格12个细胞。上样之前悬浮液已稀释10倍。原来菌液的细胞浓度是多少，以每 mL 细胞数计？
::: solution
一格上方的体积为$0.05 \times 0.05 \times 0.02 = 5\times10^{-5}$ mm³。1 mL 是1 cm³ = $10^3$ mm³，所以体积为$5\times10^{-8}$ mL。稀释悬浮液含$12/(5\times10^{-8}) = 2.4\times10^{8}$个细胞每 mL，原菌液是它的十倍，每 mL $2.4\times10^{9}$个。计数室计数快，但对细菌不精确：它们小、会动、难以与碎片区分；而且分不清活细胞与死细胞。
:::
:::

### 稀释与涂布的活菌计数

每 mL $10^9$细胞的菌液会涂出多得数不清的菌落，所以先按十倍系列稀释——1 mL 接入9 mL 无菌稀释液，混匀，再取其中1 mL 接入另一管9 mL，如此继续——然后取每个稀释度的规定体积涂布在琼脂平板上。

::: proposition 由平板计数得浓度 {#prop-plate-count}
若一块接受了体积$v$、稀释因子为$d$的悬浮液（例如$d = 10^{-6}$）的平板长出$C$个菌落，且每个菌列出自一个菌落形成单位，则原样品中的浓度为

$$
N = \frac{C}{v\,d} \quad \text{单位体积的 CFU 数。}
$$ {#eq-plate-count}

若细胞在悬浮液中随机分布，则送入一块平板的 CFU 数是均值为$\lambda = N v d$的泊松随机变量，所以$C$的方差为$\lambda$，计数的相对标准误差约为$1/\sqrt{C}$。
:::

泊松假设值得一点辩护。一块平板接收的是充分混匀的悬浮液中极小比例的细胞，而每个细胞都彼此独立；在试验次数极多、每次成功概率极小的情况下，"成功"次数服从泊松分布（见[[biostatistics/probability-distributions]]）。当细胞结团、或混得不好时它会失效——这就是每次转接前要把悬浮液涡旋的原因。

::: example 由菌落到每 mL 的 CFU {#ex-plate-count}
一份菌液按十倍系列稀释，取$10^{-6}$稀释度的0.1 mL 分别涂布若干平板。某块平板上有156个菌落。估计菌液的浓度，并只凭泊松误差给出约95 %的置信区间。
::: solution
由[[#eq-plate-count]]，$N = 156/(0.1 \times 10^{-6}) = 1.56\times10^{9}$ CFU 每 mL。均值接近156的泊松计数，其标准差为$\sqrt{156} = 12.5$，所以菌落数的近似95 %区间为$156 \pm 2\times12.5$，大约131到181个菌落，相当于每 mL $1.3$到$1.8 \times 10^{9}$ CFU。实践中，重复平板和每一步稀释的移液误差通常比泊松项带来更多变异，所以仔细的估计要用几块平板和几个稀释度。
:::
:::

为什么微生物学手册建议只数菌落数大致在30–300之间的平板？下限来自泊松误差：30个菌落时相对标准误差为$1/\sqrt{30} \approx 18\,\%$，300个时低于6 %。上限来自拥挤：在长着好几百个菌落的平板上，邻近菌落会融合并争夺营养，所以计数低估细胞数目。

::: widget distribution

params: lambda=4
a: 0
b: 0
caption: 当细胞随机分散时，平板上的菌落数服从泊松分布。从均值为4个菌落开始：0处的柱（阴影）是一块平板为空的概率$e^{-4} \approx 0.018$。把均值提高到30（滑块的最大值），看分布如何相对于均值变窄：其标准差是均值的平方根，所以相对散布从均值4时的50 %降到30时的18 %、300个菌落时的6 %以下。这就是为什么几十个到几百个的计数可靠，而只有几个的计数不可靠。

### 最可能数与稀释至绝灭

有些微生物不在平板上形成菌落，却能在液体中生长。可以给许多管或孔接入稀释液的小体积，培养后把每管记为阳性（生长）或阴性来计数。一个孔为阴性只是因为它没有收到任何活细胞。

::: proposition 由阴性孔的比例计数 {#prop-mpn}
若$n$个孔各接入悬浮液的体积$v$，其中活细胞随机分布、浓度为$c$，则每孔的细胞数服从均值为$\lambda = cv$的泊松分布，而一个孔什么细胞都没收到的概率为$p_0 = e^{-\lambda}$。若$n$个孔中有$n_0$个保持阴性，则最大似然估计为

$$
\hat\lambda = -\ln\frac{n_0}{n}, \qquad \hat c = \frac{\hat\lambda}{v},
$$ {#eq-mpn}

而且用 delta 方法，$\hat\lambda$的标准误差约为$\sqrt{(1 - p_0)/(n p_0)}$。经典的**最可能数**（MPN）法在多个稀释度上使用这一推理，把各稀释度的信息合并起来。
:::

::: proof
每个孔都独立地以概率$p_0 = e^{-\lambda}$为阴性，所以$n_0$服从二项分布$(n, p_0)$，而$p_0$的最大似然估计是$n_0/n$。由于$\lambda = -\ln p_0$是$p_0$的一一函数，其最大似然估计是$-\ln(n_0/n)$。$\hat p_0$的方差为$p_0(1 - p_0)/n$，而$d\lambda/dp_0 = -1/p_0$，所以按一阶近似$\operatorname{Var}\hat\lambda \approx p_0(1 - p_0)/(n p_0^2) = (1 - p_0)/(n p_0)$。
:::

::: example 一块96孔板的计数 {#ex-mpn}
把一份海水样品稀释$10^{-5}$，取0.1 mL 接入装有培养基的96孔微量培养板的每一孔。培养后58个孔显示生长。估计样品中可培养细胞的浓度，并给出近似的95 %置信区间。
::: solution
阴性孔：$n_0 = 38$，所以$\hat p_0 = 38/96 = 0.396$，$\hat\lambda = -\ln 0.396 = 0.927$个细胞每孔。标准误差为$\sqrt{(1 - 0.396)/(96\times0.396)} = 0.126$，给出$\lambda$的95 %区间$0.927 \pm 1.96\times0.126$，即每孔$0.68$到$1.17$个细胞。每孔接到原样品的体积为$0.1 \times 10^{-5} = 10^{-6}$ mL，所以$\hat c = 0.927/10^{-6} = 9.3\times10^5$个可培养细胞每 mL（区间约为$6.8\times10^{5}$到$1.2\times10^{6}$）。

注意，粗略估计"58个阳性孔就是58个细胞"会错得离谱：许多阳性孔收到了两个或更多细胞。
:::
:::

同一个思想在高稀释度下运行，可以分离那些不在平板上生长的生物：若每孔平均不到一个细胞，多数阳性孔就是由单个细胞种下的。这种**稀释至绝灭**的做法，配上极稀的天然海水培养基，正是 Michael Rappé、Stephen Giovannoni 及同事（2002）首次培养出 SAR11 进化枝的成员'*Candidatus* Pelagibacter ubique' 的办法——它是海洋中最丰富的生物之一，在富琼脂上生长不良或根本不生长。

::: example 阳性孔有多"克隆"？ {#ex-clonal}
若每孔平均接种$\lambda = 0.5$个细胞，阳性孔占多大比例？阳性孔中由多于一个细胞种下的占多大比例？
::: solution
$P(0) = e^{-0.5} = 0.607$，所以$39.3\,\%$的孔为阳性。$P(1) = 0.5e^{-0.5} = 0.303$，于是$P(\ge2) = 1 - 0.607 - 0.303 = 0.090$。在阳性孔中，$0.090/0.393 = 23\,\%$收到了两个或更多细胞。要让混合培养更罕见就必须进一步稀释，代价是更多的空孔；当$\lambda = 0.1$时，混合阳性的比例降到约5 %。
:::
:::

::: widget plot

x: 0.01, 4
y: 0, 1
labels: \text{阴性孔 } e^{-\lambda}; \text{阳性孔}; \text{阳性中多细胞来源的比例}

## 绝大多数微生物从未被培养过

对自然样品中的细胞同时做直接计数和平板计数时，两个数字大相径庭。在海水里，落射荧光计数典型为每 mL $10^5$–$10^6$个细胞，而海洋培养基平板只能从其中远低于1 %的细胞长出菌落；土壤里的差距类似。James Staley 与 Allan Konopka（1985）称之为**巨大平板计数异常**（great plate count anomaly）。未计出的细胞有些已死或休眠，但多数属于根本不在所给条件下生长的谱系：它们的营养不对或过浓、它们需要伙伴、或者它们长得太慢，几天内形不成菌落。

自1980年代以来，微生物学家通过读取基因，在不培养的情况下研究生物。Norman Pace 及同事直接从环境 DNA 中扩增并测定**16S 核糖体 RNA 基因**序列，发现大多数序列属于未知的谱系；Edward DeLong、Gene Wickham 与 Pace（1989）引入了荧光 rRNA 靶向探针（"系统发育染色"，今称**荧光原位杂交**，FISH），在显微镜下鉴定单个细胞。**宏基因组学**——测定样品中全部 DNA 并把它组装成基因组——在2000年代随之而来，而**单细胞基因组学**测定单个分选细胞的基因组。这些方法、以及它们关于生命之树揭示的东西，是[[microbiology/microbial-diversity]]的主题。培养并没有被抛弃——只有培养出来的生物才能被完整地进行生理学与遗传学研究——而"培养组学"（平行数千种条件）和置放于自然环境中培养的扩散室等新方法，已把许多此前未培养过的谱系带进了实验室。

::: quiz
一份土壤悬浮液用落射荧光显微术计得每克$4\times10^9$个细胞，在富琼脂平板上每克$2\times10^7$ CFU。哪个结论最受支持？
- [ ] 土壤中99.5 %的细胞已死。
- [x] 在这些条件下最多约0.5 %的细胞形成了菌落；其余的已死、休眠，或不能在这种培养基上生长。
- [ ] 由于泊松误差，平板计数是错的。
- [ ] 荧光显微术把每个细胞约数了200遍。
::: solution
比值是$2\times10^7/4\times10^9 = 0.5\,\%$。仅凭数据无法把死细胞与不能在该培养基上生长的活细胞分开；要作判断需要对膜完整性或活性进行染色并测序。几十个到几百个菌落的计数的泊松误差只有百分之几，远不足以解释200倍的差别。
:::
:::

## 鉴定微生物

多数细菌看起来彼此一样——一两个微米宽的杆菌、球菌、弧菌与螺旋菌——所以单靠显微术很少能鉴定它们。经典鉴定结合**形态学**（形状、排列、运动性、孢子）、**染色**（革兰氏反应、分枝杆菌的抗酸染色；[[diversity-of-life/bacteria-archaea#def-envelope]]）与**生理学**：某菌株发酵哪些糖、能否无氧生长、有哪些酶（过氧化氢酶、氧化酶）、能在哪些培养基上生长。**选择培养基**含有抑制某些生物的因子（胆盐与染料抑制多数革兰氏阳性菌，高盐选择葡萄球菌），**鉴别培养基**含有使不同生物的菌落外观不同的指示剂（显示哪些菌落发酵乳糖的 pH 指示剂）。

如今鉴定多半是分子层面的。16S rRNA 基因的序列能以相当的把握把一个细菌或古菌归到属；全基因组测序以及两个基因组之间的**平均核苷酸一致性**（ANI）被用来界定物种，常用的阈值为约95–96 % ANI（Konstantinos Konstantinidis 与 James Tiedje，2005；Chirag Jain 及同事，2018）。全细胞蛋白的质谱（MALDI-TOF）在临床与食品实验室里广泛用于快速鉴定。原核生物的物种概念与命名法见[[diversity-of-life/classifying-life]]与[[microbiology/microbial-diversity]]。

## 模式微生物与安全操作

少数几种微生物被研究的程度远远超过其他，因为它们生长快、培养基简单、遗传上易于操作，而且拥有庞大的研究群体：

- *Escherichia coli* K-12：1922年分离的一株的实验室驯化后代，不能有效定殖人的肠道；细菌遗传学与分子生物学的基石（[[genetics/microbial-genetics]]）。
- *Bacillus subtilis* 168：革兰氏阳性土壤细菌，内生孢子形成与革兰氏阳性细胞生物学的模式生物。
- *Saccharomyces cerevisiae*，出芽酵母，模式真核细胞。
- *Caulobacter crescentus*（不对称细胞分裂）、*Vibrio fischeri*（群体感应与共生）、*Pseudomonas aeruginosa*（生物膜）、*Haloferax volcanii* 与 *Sulfolobus*（古菌细胞生物学），以及λ、T4 等噬菌体。

微生物实验室按风险对所操作的生物分类，并据此匹配规程、设备与建筑。多数教学与研究菌株，包括 *E. coli* K-12 与 *B. subtilis* 168，风险最低，用基本的良好微生物学操作处理即可——台面消毒、不用口吸移液、培养物与废弃物在处置之前灭菌。能引起严重人类疾病的因子只在逐级增高的防护设施（生物安全等级 BSL-1 至 BSL-4）中、依国家法规、由受训人员操作；世界卫生组织的《实验室生物安全手册》（第4版，2020）给出了基于风险的方法。防护保护工作者与公众，这也是微生物学不同于其早期历史、如今成为一门安全科学的原因之一。

::: application 食品中的微生物
发酵是最古老的生物技术：面包与啤酒依赖 *S. cerevisiae*，酸奶依赖 *Streptococcus thermophilus* 与 *Lactobacillus delbrueckii* subsp. *bulgaricus*，奶酪、酸菜、泡菜、酱油与醋依赖别的乳酸菌、乙酸菌与霉菌。这些微生物产生的酸与酒精通过抑制腐败生物来保藏食品——一次应用性的富集培养。食品微生物学也例行地为微生物计数，用本章的平板计数与 MPN 方法，检验巴氏消毒与卫生措施是否奏效。
:::

::: history
列文虎克的信件（1673–1683）之后，微生物学沉寂了150年。Christian Gottfried Ehrenberg 在1830年代描述了数百种"微小动物"（infusoria），Ferdinand Cohn 于1872年按形状给细菌分类、1876年描述了内生孢子。巴斯德关于发酵（自1857）、自然发生（1859–1861）与疫苗（鸡霍乱，1880；炭疽，1881）的工作，与科赫关于炭疽（1876）、纯培养（1881）与结核（1882）的工作奠定了医学微生物学；革兰氏染色始于1884年，Petri 皿始于1887年。Winogradsky 的化能无机营养者（1887–1890）与 Beijerinck 的富集培养及可过滤病毒的发现（1898）奠定了微生物生态学与病毒学。二十世纪增添了细菌遗传学（1940年代）、恒化器（1950）、古菌的发现（1977），以及自1980年代中期起凭基因进行的不依赖培养的微生物研究。
:::

::: summary
- 微生物由尺寸与方法界定，而非由祖裔：细菌、古菌、微型真菌、原生生物与藻类，以及非细胞的病毒。
- 列文虎克首先看到细菌（1676–1683）；巴斯德的鹅颈瓶（1859–1861）驳倒了自然发生，而耐热的内生孢子解释了例外。
- 固体培养基上的纯培养（科赫、Hesse 夫妇、Petri）使证明特定微生物引起特定发酵与疾病成为可能。科赫法则是好用但并非普适的因果检验。
- 富集培养（Winogradsky、Beijerinck）选择具有给定能力的生物；"环境选择"。
- 总数计数（计数室、落射荧光、流式细胞术）数所有细胞；活菌计数（平板、MPN）数能生长的细胞。平板计数给出$N = C/(vd)$，相对误差约为$1/\sqrt{C}$；阴性孔的比例给出$\hat\lambda = -\ln(n_0/n)$。
- 直接计数比平板计数高出100倍甚至更多（巨大平板计数异常）；rRNA 测序、FISH 与宏基因组学研究着未培养的大多数。
- 鉴定把形态学、染色与生理学和 16S rRNA 与基因组序列结合起来；对微生物的工作按其风险匹配防护与法规。
:::

## 习题

::: exercise 一次平板计数 {level=1 check="2.3e8"}
一份菌液的$10^{-5}$稀释液0.1 mL 长出230个菌落。菌液的浓度是多少，以 CFU 每 mL 计？
::: solution
$N = 230/(0.1\times10^{-5}) = 2.3\times10^{8}$ CFU 每 mL。
:::
:::

::: exercise 该数哪块平板？ {level=1}
用一份菌液的$10^{-4}$、$10^{-5}$与$10^{-6}$稀释度各0.1 mL 涂布的平板分别"多到数不清"、412与38个菌落。哪块板给出更可靠的估计？估计值是多少？412与38一致吗？
::: solution
412那块超出了约300的常用上限——菌落在那里会融合并竞争，所以宁取38那块：$N = 38/(0.1\times10^{-6}) = 3.8\times10^8$ CFU 每 mL，泊松相对误差约为$1/\sqrt{38} = 16\,\%$。$10^{-5}$那块预计应载有十倍之数、约380个（仅凭泊松误差，95 %范围大致为340–420），所以412是一致的。许多实验室会报告两块平板的加权合并结果。
:::
:::

::: exercise 鹅颈瓶 {level=1}
说出巴斯德的鹅颈瓶设计来检验的假说、它所排除的备择假说，以及把瓶子倾斜使肉汤碰到瓶颈弯曲处的作用。
::: solution
假说：煮过的肉汤里的微生物来自空气中的颗粒（携带微生物的尘埃），而不是自然发生。它排除的备择假说是 Needham 的：空气、或其中的某种"生命力"，是生命产生所必需的，而在密封的瓶中它被排除或破坏了——在巴斯德的瓶子里空气自由进入，却什么都不长。倾斜是阳性对照：它表明肉汤仍能支持生长、而截留在瓶颈里的颗粒含有活的微生物，所以无菌并不是因为肉汤已不能支持生命。
:::
:::

::: exercise 用孔计数 {level=2 check="3.3e5"}
四十八个孔各接入一份湖水样品$10^{-4}$稀释液的0.05 mL。9个孔保持阴性。估计湖水中可培养细胞的浓度，以每 mL 计（两位有效数字）。
::: solution
$\hat\lambda = -\ln(9/48) = -\ln 0.1875 = 1.674$个细胞每孔。每孔接到湖水的体积为$0.05\times10^{-4} = 5\times10^{-6}$ mL，所以$\hat c = 1.674/(5\times10^{-6}) = 3.3\times10^{5}$个每 mL。
:::
:::

::: exercise 一次计数室计数 {level=2 check="6e7"}
血细胞计数板的一个方格面积为0.0025 mm²、深度为0.1 mm。一份稀释1 : 100的酵母悬浮液给出平均每格1.5个细胞。未稀释悬浮液的浓度是多少，以每 mL 细胞数计？
::: solution
每格体积：$0.0025\times0.1 = 2.5\times10^{-4}$ mm³ $= 2.5\times10^{-7}$ mL。稀释后的浓度为$1.5/(2.5\times10^{-7}) = 6\times10^{6}$每 mL；未稀释为$6\times10^{8}$每 mL。
:::

::: exercise 科赫法则与携带者 {level=2}
一种细菌从95 %的某病患者身上分离出来，但也从30 %的健康人身上分离到。在一个合适的动物模型中，纯培养使60 %的动物发病，并从所有发病动物中被回收。(a) 哪些法则是满足的？(b) 得出这种细菌引起该病的结论合理吗？(c) 哪些进一步的证据能加强这一论证？
::: solution
(a) 第二条（纯培养分离）、第三条（至少部分成立：在易感宿主中致病）与第四条（再次分离）。第一条按严格形式不成立，因为这种菌也见于健康人。(b) 合理，但属暂定：无症状携带对许多病原体都很常见，而实验感染是有力证据；只在60 %的动物中致病提示宿主因素或剂量要紧。(c) 细菌载量与疾病之间一致的关联；一个基因（比如编码某种毒素的基因），其失活在模型中消除疾病、恢复之后疾病复原（分子科赫法则）；以及健康携带者与患者所带菌株之间的差异。
:::

::: exercise 单克隆孔 {level=2 check="0.049"}
每孔平均接种$\lambda = 0.1$个细胞。阳性孔中收到两个或更多细胞的占多大比例？给出三位小数。
::: solution
$P(0) = e^{-0.1} = 0.9048$，$P(1) = 0.1e^{-0.1} = 0.0905$，于是$P(\ge 2) = 1 - 0.9048 - 0.0905 = 0.00468$。阳性孔中混合的比例为$0.00468/0.0952 = 0.049$，约5 %。
:::

::: exercise 海水里的平板计数异常 {level=2}
表层海水用落射荧光计数含每 mL $8\times10^5$个细胞，其中 FISH 显示25 %属于 SAR11 进化枝。取0.1 mL 未稀释海水涂布在海洋培养基上得64个菌落，没有一个属于 SAR11。(a) 形成菌落的细胞占多大百分比？(b) 提出三条 SAR11 细胞不形成菌落的原因。(c) 怎样检验那些不可培养的细胞是否还活着？
::: solution
(a) $64/0.1 = 640$ CFU 每 mL，而$640/8\times10^5 = 0.08\,\%$。(b) SAR11 适应极低的营养浓度，在富培养基上会被抑制或被更快者胜过；它有特殊的营养需求（例如需要还原性硫化物以及甘氨酸或其前体，这些东西在海水中存在而在许多培养基里缺失）；它生长缓慢，约一天甚至更久才分裂一次，在别的细菌长满平板的时间里形不成可见的菌落。(c) 用膜完整性染色（活/死染色）、测定单个细胞对放射性标记底物的摄取（微自显影结合 FISH）、或用标记的氨基酸类似物检测 rRNA 含量或活跃的蛋白质合成——这些都显示活性而不需要在平板上生长。用过滤的天然海水做稀释至绝灭培养，可以检验它们究竟能不能被培养。
:::

::: exercise 稀释系列的精确度预算 {level=3}
一份菌液经过六次十倍稀释后涂板——每一步都用移液管取1.00 mL 加入9.00 mL—— 最后稀释度取0.100 mL 涂布。设每个移取体积都有独立的相对误差（标准差）2 %，而计数为150个菌落。(a) 估计稀释系列与最终涂布体积贡献的相对标准误差，把相对误差按平方和合成，忽略9.00 mL 体积的误差。(b) 与计数的泊松误差比较。(c) 这对如何提高精确度有什么提示？
::: solution
(a) 每个稀释因子为$V_1/(V_1 + 9.00)$；$V_1 = 1.00$ mL 的2 %误差使因子改变约$2\,\% \times 9/10 = 1.8\,\%$（因为转移的体积也出现在分母里）。六个独立步骤给出$1.8\,\%\times\sqrt6 = 4.4\,\%$。涂布体积再加2 %，所以体积部分合计$\sqrt{4.4^2 + 2^2} = 4.8\,\%$。(b) 泊松误差为$1/\sqrt{150} = 8.2\,\%$，所以总误差约为$\sqrt{8.2^2 + 4.8^2} = 9.5\,\%$；计数占主导。(c) 精确度主要靠数更多菌落来提高——在同一稀释度涂重复平板或更大体积——而不是靠更仔细的移液。系统误差（结团、混合不完全、菌落小到看不见）不因重复而减小，必须另行控制。
:::

::: exercise 解读富集数据 {level=3}
取两块田的土壤样品接入以甘露醇为碳源的无氮培养基，在空气中培养。5天后，A 田出现浑浊培养物以及一层由大卵形细胞构成的菌膜，B 田不长；3周后 B 田也出现浑浊培养。(a) 富集到了什么类型的生物？(b) 这一结果表明 B 田没有固氮菌或固氮菌较少吗？(c) 设计一个 MPN 实验比较它们的丰度。
::: solution
(a) 好氧的自由生活固氮菌，能利用甘露醇——大卵形细胞与菌膜是 *Azotobacter* 的典型特征，正是 Beijerinck 的那种生物。(b) 两者都不是直接的：三个星期后的生长表明它们存在于 B 田；出现较慢提示细胞较少（较小的接种物达到浑浊需要更久），或者是另一个生长更慢的群体。富集培养只是定性的。(c) 把每种土壤悬浮液做十倍系列稀释，在几个稀释度上各接入比如5管无氮甘露醇培养基；在固定时间后记阳性管，并在阳性管中确证固氮（例如通过乙炔还原）。阳性管在各个稀释度上的模式，按推广到多个稀释度的[[#prop-mpn]]的逻辑，给出每克土壤固氮菌的最可能数，并带着允许对两块田加以比较的置信限。
:::
