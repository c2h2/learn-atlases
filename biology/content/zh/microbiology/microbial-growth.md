在理想条件下，*Escherichia coli*（大肠杆菌）每20分钟分裂一次。从一个细胞出发，如此生长48小时将产生$2^{144} \approx 2\times10^{43}$个细胞，重量约为地球的3,700倍。这当然从未发生：养分耗尽，废物积累，远在此之前生长就停止了。但这次计算点明了支配微生物生命的那件事：微生物种群只要可能就以指数方式增长，它们能长得非常快，而关于它们的生态、进化与控制的几乎一切，都由这一事实及限制它的种种因素派生而来。

本章讨论生长——单个细胞的生长、锥形瓶中种群的生长，以及在连续培养中维持在稳态的种群的生长。我们描述细菌细胞如何生长与分裂，建立指数增长与分批培养生长曲线的数学，从 Monod 模型导出恒化器的稳态，并综述微生物能够生长的物理与化学条件——温度、pH、水与氧。计数方法已在[[microbiology/microbial-world]]中介绍；指数增长与逻辑斯谛增长的数学在[[ecology]]与[数学图谱](/learn/maths/)中进一步展开。

## 细菌如何生长与分裂

大多数细菌与古菌以**二分裂**繁殖：细胞生长，复制其染色体，把两份拷贝分开，并在中部一分为二，成为两个相似的子细胞。有些不对称分裂：*Caulobacter crescentus* 分裂为一个有柄细胞与一个游动细胞，二者命运不同；*Hyphomicrobium* 与许多其他细菌以**出芽生殖**繁殖。*Streptomyces* 以分枝菌丝生长，并以孢子繁殖。

*E. coli* 与 *Bacillus subtilis*（枯草芽孢杆菌）的分裂由一个微管蛋白样蛋白 FtsZ 组成的环组织：FtsZ 在细胞中部组装，并招募**分裂体**——一个由十几种蛋白质组成、合成隔膜新肽聚糖的复合体（[[microbiology/microbial-cells#def-peptidoglycan]]）。有两套系统把环放在中部：**Min 系统**，其蛋白在两极之间振荡，使抑制剂 MinC 在细胞中部的平均浓度最低；以及**类核阻遏**，它阻止在尚未分开的 DNA 上方分裂。

### 细菌的细胞周期

在真核生物中，DNA 复制与有丝分裂每个周期先后各发生一次（[[cell-biology/cell-cycle]]）。细菌有一个难题要解决：在 *E. coli* 中，复制整条染色体约需40分钟（**C 期**），复制结束到分裂又过20分钟（**D 期**），可细胞却能每20分钟分裂一次。Stephen Cooper 与 Charles Helmstetter（1968）用 *E. coli* B/r 展示了这如何可能：细胞在旧的复制轮尚未完成时就开启新的复制轮。在快速生长的细胞中，染色体同时携带好几对复制叉（**多叉复制**），新生细胞继承的染色体已经在为其女儿细胞与孙女细胞进行复制。

::: proposition Cooper–Helmstetter 模型 {#prop-cooper}
设每轮复制都从起点开始，耗时固定的$C$，其后经过固定的时间$D$发生分裂，且培养物以倍增时间$\tau$指数生长。则某一次分裂的起始发生在该分裂之前$C + D$，而在整个种群中，每细胞的平均起点数为$2^{(C+D)/\tau}$，起点的拷贝数与终点的拷贝数之比为

$$
\frac{n_\mathrm{ori}}{n_\mathrm{ter}} = 2^{C/\tau}.
$$ {#eq-ori-ter}
:::

::: proof
考虑生长培养物中的全部染色体。复制叉以时间$C$从起点移动到终点，所以时刻$t$存在的每一个终点拷贝，都来自时刻$t - C$存在的一个起点拷贝——当时每个起点拷贝对应一个终点拷贝。起点与平衡指数生长培养物中的一切其他东西一样，按$2^{t/\tau}$增长。因此$n_\mathrm{ter}(t) = n_\mathrm{ori}(t - C) = n_\mathrm{ori}(t)\,2^{-C/\tau}$，即[[#eq-ori-ter]]。对分裂施加同一论证——分裂在起始之后$C + D$发生——即知起点数目是分裂所产生的细胞数目的$2^{(C+D)/\tau}$倍——亦即，对每个细胞而言如此。同样的推理给出：在从起点到终点全程分数$x$处任一基因座的拷贝数，正比于$2^{-xC/\tau}$。
:::

最后这条评注是**标记频率分析**（Noboru Sueoka 与 Hiroshi Yoshikawa，1965）的基础：在生长的培养物中，靠近起点的基因比靠近终点的基因更丰富；对来自培养物——甚或来自宏基因组学中某个自然群落——的 DNA 测序，把读段深度对位置作图，就能看出细胞复制得有多快。

::: example 快速生长细胞中的起点 {#ex-origins}
取$C = 40$ min、$D = 20$ min。(a) 对$\tau = 20$ min，起始发生在分裂前多少代？每细胞的平均起点数是多少？ori/ter 比值是多少？(b) 对$\tau = 60$ min 重复计算。(c) 若$\tau$比$C$短，而每条染色体只能有一对复制叉，会发生什么？
::: solution
(a) 起始先于分裂$C + D = 60$ min，即三代：细胞启动的那些复制轮，将在它的曾孙细胞里完成（起始发生在最终分裂的那个细胞的"祖母"细胞中）。每细胞起点数：$2^{60/20} = 8$。Ori/ter：$2^{40/20} = 4$。

(b) 每细胞平均起点$2^{60/60} = 2$；ori/ter $= 2^{40/60} = 1.59$。起始发生在分裂前一代，恰在细胞出生之时。

(c) 它的生长无法快于每$C$ = 40 min 倍增一次（实际上是每$C$加上一个小间隙）。多叉复制正是 *E. coli* 能以其复制染色体所需时间不到的速度倍增的原因。
:::
:::

生长速率还决定细胞的大小与组成。Moselio Schaechter、Ole Maaløe 与 Niels Ole Kjeldgaard（1958）用在不同培养基上生长的 *Salmonella* Typhimurium（鼠伤寒沙门氏菌）证明，每个细胞的平均质量随生长速率指数增加，后来的工作又表明核糖体含量大致随生长速率线性增加：一个长得快的细胞又大又挤满了核糖体。这些"细菌生长定律"是生物学中为数不多的、在许多条件下都成立的定量规律之一，它们反映的是：核糖体的蛋白质合成是生长的主要瓶颈。William Donachie（1968）从 Cooper–Helmstetter 模型推断，复制在大约每个起点恒定的细胞质量处起始；而近年的单细胞研究表明，许多细菌在出生大小的基础上增加大约恒定的体积之后才分裂（"加法器"原则），无论那个出生大小是多少——这是一条使细胞大小保持稳定的简单规则。

## 指数增长

当每个细胞分裂为二，且任何短间隔内每个细胞都有相同的分裂机会时，种群增长的速度正比于其大小。

::: definition 比生长速率与倍增时间 {#def-growth-rate}
对$N$个细胞（或生物量$X$）的种群，**比生长速率**为

$$
\mu = \frac{1}{N}\frac{dN}{dt},
$$

单位是时间的倒数（h⁻¹）。**倍增时间**（平均代时）$t_d$是种群倍增所需的时间。两次计数$N_0$与$N$之间的**世代数**为$n = \log_2(N/N_0) = \log_{10}(N/N_0)/\log_{10}2 \approx 3.32\log_{10}(N/N_0)$。
:::

::: proposition 指数增长 {#prop-exp}
若$\mu$恒定，则

$$
N(t) = N_0e^{\mu t}, \qquad t_d = \frac{\ln 2}{\mu}, \qquad \mu = \frac{\ln N_2 - \ln N_1}{t_2 - t_1}.
$$ {#eq-exp}

$\ln N$（或$\log_{10} N$）对$t$的图是一条斜率为$\mu$（或$\mu/\ln 10$）的直线。
:::

::: proof
方程$dN/dt = \mu N$可分离：$dN/N = \mu\,dt$，于是$\ln N = \mu t + \text{常数}$且$N = N_0e^{\mu t}$。倍增$N = 2N_0$所需$t_d$满足$e^{\mu t_d} = 2$，故$t_d = \ln 2/\mu$。对解在两个时刻取对数，即得最后一式。
:::

请注意，培养物的倍增时间是一个平均值；单个细胞在不同年龄分裂，而指数期培养物的年龄分布并不均匀——即将分裂的细胞每有一个，新生细胞就有两个，因为每次分裂产生两个新生细胞。

::: example 由光密度求倍增时间 {#ex-od}
一个 *E. coli* 培养物在37 °C 的葡萄糖基本培养基中生长，10:00时600 nm 处的光密度（OD₆₀₀）为0.050，11:30为0.40。设在此范围内 OD 与生物量成正比，计算$\mu$与倍增时间。若生长照旧继续，该培养物从 OD 0.40到0.80需要多久？
::: solution
OD 上升了8倍，即90分钟内3次倍增，故$t_d = 30$ min。等价地，$\mu = \ln 8/1.5\ \text{h} = 2.079/1.5 = 1.39$ h⁻¹，$t_d = 0.693/1.39 = 0.50$ h。从0.40到0.80是再一次倍增：30分钟——只要没有任何东西成为限制。实践中，葡萄糖基本培养基中的培养物在 OD 接近1或更低时便开始偏离指数生长，具体取决于葡萄糖浓度。
:::
:::

**生长的测定。**光密度测量细胞散射的光，只有悬浮液很稀时才与生物量成正比（标准1 cm 比色皿中通常 OD₆₀₀ 在约0.3–0.5以下，但这取决于仪器），所以较浓的培养物读数前必须稀释；它不能分辨死活细胞，且 OD 与细胞数的关系随细胞大小而变，而细胞大小本身又随生长速率而变。生物量还可测干重或蛋白质，细胞数可测直接计数或活菌计数（[[microbiology/microbial-world]]）。单个细胞可用延时显微术直接追踪，常置于微流控装置（如"母亲机器"）中：细胞在细窄通道里生长数百代（Ping Wang 及同事，2010）。

## 分批培养的生长曲线

在装有固定量培养基的密闭容器——**分批培养**——中，生长遵循一条特征性的进程，最早由 Monod（1949）作了定量描述：

1. **延滞期。**转入新鲜培养基后，细胞进行调整：它们修复损伤，合成新培养基所需的酶与核糖体，一段时间内可能不分裂。若把指数生长的细胞转入同一培养基，延滞很短或没有；若用陈旧（稳定期）或受损细胞，或培养基不同，则延滞很长。
2. **指数（对数）期。**细胞在该条件下以恒定的最大速率生长，处于**平衡生长**状态：细胞的每一种成分都在相同时间内增至相同的倍数。
3. **稳定期。**当某种必需养分耗尽或废物（例如酸）积累时，生长停止。稳定期中的细胞并非只是闲置：在 *E. coli* 中，σ因子σ^S^（RpoS）开启胁迫抗性基因；细胞变得更小更圆，核糖体部分失活。有些细胞死亡，释放的养分被其他细胞利用。
4. **衰亡期。**活菌计数下降，起初常大致呈指数。延长保温显示出一种长期稳定期，其间种群是动态的：能在死细胞碎片上生长的突变体出现并接管培养物——即**稳定期生长优势**（GASP）表型（Maria Zambrano、Roberto Kolter 及同事，1993）。

当两种糖同时存在时，培养物可能先耗尽它所偏爱的一种，暂停一会儿，然后再在第二种糖上生长：这就是**二次生长**，Monod 以葡萄糖与乳糖发现了它，并由此引出了对 *lac* 操纵子的研究（[[molecular-biology/bacterial-gene-regulation]]）。

### Monod 模型

Monod 发现，比生长速率以双曲线的方式依赖于限制基质的浓度，正如酶反应速率之于底物。

::: proposition Monod 关系与得率 {#prop-monod}
若生长受单一基质浓度$S$限制，则比生长速率，作为一个**经验**关系，为

$$
\mu(S) = \mu_\mathrm{max}\frac{S}{K_s + S},
$$ {#eq-monod}

其中$\mu_\mathrm{max}$是最大生长速率，$K_s$是**半饱和常数**（$\mu = \mu_\mathrm{max}/2$时的$S$值）。生物量$X$由底物以**得率**$Y = -\Delta X/\Delta S$（每克底物生成的细胞克数）生成，并假定其为常数。在分批培养中

$$
\frac{dX}{dt} = \mu(S)X, \qquad \frac{dS}{dt} = -\frac{1}{Y}\mu(S)X,
$$ {#eq-batch}

于是$X + YS$为常数，底物耗尽时的最终生物量为$X_\mathrm{final} = X_0 + YS_0$。
:::

Monod 关系看起来像米氏方程（[[biochemistry/enzymes]]），常被解释为转运体的饱和，但它是一个描述而非推导：生长取决于成百上千个反应，而这条双曲线只是恰好把许多数据集拟合得很好。糖类运输的$K_s$值常在微摩尔范围，这就是锥形瓶中的指数生长能全速持续到基质几乎耗尽、然后戛然而止的原因。

::: example 得率与最终浓度 {#ex-yield}
*E. coli* 在基本培养基中以葡萄糖生长，有氧条件下得率约为每克葡萄糖0.5 g 干重。(a) 用2 g L⁻¹ 葡萄糖、从0.01 g L⁻¹ 出发，最终生物量是多少？(b) 若一个细胞的干重约0.3 pg，这相当于每毫升多少个细胞？(c) 从0.01 g L⁻¹ 出发、以$\mu = 1.2$ h⁻¹ 生长且直到最后都不减慢，培养物需多久达到0.4 g L⁻¹？
::: solution
(a) $X_\mathrm{final} = 0.01 + 0.5\times2 = 1.01$ g L⁻¹。

(b) $1.01$ g L⁻¹ $= 1.01\times10^{-3}$ g mL⁻¹；除以每个细胞$0.3\times10^{-12}$ g，得每毫升$3.4\times10^{9}$个细胞。

(c) $t = \ln(0.4/0.01)/1.2 = \ln 40/1.2 = 3.69/1.2 = 3.1$ h。得率决定底物能支撑**多少**生物量；生长速率决定**多快**达到。
:::
:::

把$S = (X_\mathrm{final} - X)/Y$代入，分批培养的方程可化为单个方程：

$$
\frac{dX}{dt} = \mu_\mathrm{max} X\,\frac{X_\mathrm{final} - X}{YK_s + X_\mathrm{final} - X}.
$$

当$YK_s$与$X_\mathrm{final}$相比很小时，曲线几乎全程指数增长、然后骤停；当它较大时，曲线逐渐弯平，类似种群生态学的逻辑斯谛曲线。

::: warning 指数增长是一个阶段，而不是一种属性
引用某种微生物的倍增时间——*E. coli* 20分钟、*Mycobacterium tuberculosis*（结核分枝杆菌）约24小时——是在最好的实验室条件下的最大值。在自然界，养分稀缺，大多数微生物大部分时间生长缓慢或根本不生长：对土壤与深部地下中倍增时间的估计，范围从数天到数年乃至更长；而据信哺乳动物肠道中的 *E. coli* 一天只倍增一两次。锥形瓶中的指数增长只持续几个小时。同样，若细胞大小改变或有些细胞不分裂，用光密度测得的倍增时间就可能与用活菌计数测得的不同。
:::

## 连续培养：恒化器

在分批培养中，环境不断变化。为了研究在恒定环境中以固定速率生长的细胞，Monod（1950）以及独立地，Aaron Novick 与 Leo Szilard（1950），发明了连续培养。Novick 与 Szilard 把他们的装置命名为**恒化器**。

::: definition 恒化器 {#def-chemostat}
**恒化器**是体积$V$固定的培养容器：含限制性底物、浓度为$S_R$的新鲜培养基以流量$F$泵入，同时培养物以相同速率排出。**稀释率**为$D = F/V$（h⁻¹）。培养物被搅拌，使其内含物均匀。
:::

::: proposition 恒化器的稳态 {#prop-chemostat}
在 Monod 生长[[#eq-monod]]与恒定得率$Y$下，恒化器满足

$$
\frac{dX}{dt} = (\mu(S) - D)X, \qquad \frac{dS}{dt} = D(S_R - S) - \frac{\mu(S)X}{Y}.
$$ {#eq-chemostat}

若$D < D_c = \mu_\mathrm{max} S_R/(K_s + S_R)$，则存在一个稳定的稳态，且

$$
\mu = D, \qquad S^* = \frac{K_sD}{\mu_\mathrm{max} - D}, \qquad X^* = Y(S_R - S^*).
$$ {#eq-chemostat-ss}

若$D > D_c$，细胞长不过被稀释的速度，培养物被**洗出**（$X \to 0$，$S \to S_R$）。
:::

::: proof
在$X^* > 0$的稳态处，$dX/dt = 0$要求$\mu(S^*) = D$。对$S$求解$\mu_\mathrm{max} S/(K_s + S) = D$得$S^* = K_sD/(\mu_\mathrm{max} - D)$，当且仅当$D < D_c$时它是低于$S_R$的正浓度。然后$dS/dt = 0$给出$D(S_R - S^*) = DX^*/Y$，故$X^* = Y(S_R - S^*)$。若$D \ge D_c$，则对每个可达到的$S \le S_R$都有$\mu(S) \le \mu(S_R) \le D$，$X$无法增长，于是唯一的稳态就是洗出。非平凡稳态的稳定性来自对[[#eq-chemostat]]的线性化：总量$Z = X + YS$满足$dZ/dt = D(YS_R - Z)$，故它以速率$D$弛豫到$YS_R$；而在直线$Z = YS_R$上，$X$的方程在$X^*$处有唯一的稳定平衡，因为当$X$增大（$S$下降）穿过该处时$\mu - D$减小。
:::

引人注目的是：实验者通过选择$D$设定了生长速率——细胞消耗底物，直到其浓度恰好低到它们生长的速率与被洗出的速率完全相等。稳态基质浓度只取决于$D$以及该微生物的$K_s$与$\mu_\mathrm{max}$，不取决于$S_R$，它只决定细胞的密度。

::: example 运转一个恒化器 {#ex-chemostat}
某细菌的$\mu_\mathrm{max} = 1.0$ h⁻¹，对葡萄糖的$K_s = 10$ mg L⁻¹，$Y = 0.5$。它在$S_R = 2$ g L⁻¹（2000 mg L⁻¹）的恒化器中生长。(a) 在$D = 0.5$ h⁻¹ 下，求$S^*$、$X^*$、倍增时间与生产力$DX^*$。(b) 临界稀释率是多少？(c) 若把$S_R$加倍，$S^*$与$X^*$会怎样？
::: solution
(a) $S^* = 10\times0.5/(1.0 - 0.5) = 10$ mg L⁻¹。$X^* = 0.5\times(2000 - 10) = 995$ mg L⁻¹，约1.0 g L⁻¹。细胞以$\mu = 0.5$ h⁻¹ 生长，故$t_d = 0.693/0.5 = 1.39$ h。生产力：$0.5\times0.995 = 0.50$ g L⁻¹ h⁻¹。

(b) $D_c = 1.0\times2000/(10 + 2000) = 0.995$ h⁻¹。在接近$D_c$处运转是有风险的：流量稍有增大就会把培养物洗出。

(c) $S^*$不变（它只取决于$D$、$K_s$、$\mu_\mathrm{max}$）；$X^*$约增至一倍，为$0.5\times(4000 - 10) = 2.0$ g L⁻¹。
:::
:::

::: intuition 恒化器中的竞争
在恒化器中被同一基质限制的两个物种不能共存：稳态时每个物种都需要$\mu(S) = D$，而这对每个物种都发生在该物种特有的底物浓度$S^*$处。$S^*$较低的那个物种——能在更少的食物上以速率$D$生长的那个——把底物拉到另一个物种所需水平之下，另一个便被洗出。这是生态学中竞争排斥原理与资源比值理论的微生物版本（[[ecology]]），并已在细菌与藻类的恒化器实验中得到证实。共存还需要别的东西：两种限制资源、交叉喂养、捕食者，或波动的环境。
:::

恒化器用于在固定生长速率下研究生理、用于工业生产细胞，以及用于**实验进化**：在恒化器中，$S^*$较低的突变体在几百代之内就接管种群，其基因组揭示对养分限制的适应如何实现。分批连续传代是另一种常见方式：在 Richard Lenski 的长期进化实验中，*E. coli* 的12个种群自1988年以来每天被转接到新鲜的限葡萄糖培养基中，到2020年代初已传过75,000代；其中一个种群进化出了在空气中以柠檬酸盐生长的能力——而这一性状本是界定 *E. coli* 为一个物种的特征之一（Zachary Blount、Christina Borland 与 Lenski，2008）；见[[evolution/natural-selection]]。

::: quiz
在一个葡萄糖限制的恒化器处于稳态时，实验者把稀释率从0.2提高到0.4 h⁻¹（仍低于临界速率）。培养物重新稳定后发生了什么？
- [ ] 生长速率不变，细胞密度减半。
- [x] 生长速率加倍，残余葡萄糖浓度上升，细胞密度略有下降。
- [ ] 残余葡萄糖浓度下降，因为细胞长得更快。
- [ ] 生长速率加倍，细胞密度加倍。
::: solution
稳态时$\mu = D$，所以细胞现在以0.4 h⁻¹ 生长。要长得更快，它们需要更高的基质浓度$S^* = K_sD/(\mu_\mathrm{max} - D)$，它随$D$上升。由于$X^* = Y(S_R - S^*)$，密度下降$Y$乘以$S^*$的增量——通常量很小，因为除接近洗出时外，$S^*$都远低于$S_R$。
:::
:::

## 生长的环境极限

每种微生物都只在每种物理与化学条件的一定范围内生长，有最低值、最适值与最高值——**三基点值**。微生物整体跨越的范围，远比任何动植物所能忍受的宽。

### 温度

| 类群 | 生长范围（近似） | 例子 |
|---|---|---|
| 嗜冷菌 | 0 °C 以下至约20 °C，最适≤15 °C | 海冰藻类与细菌、*Psychromonas* |
| 耐冷菌 | 0至约35 °C | *Listeria monocytogenes*（单核细胞增生李斯特菌）、*Pseudomonas* 腐败菌 |
| 嗜中温菌 | 约10至45 °C，最适20–40 °C | *E. coli*，土壤与动物中的大多数细菌 |
| 嗜热菌 | 约45至80 °C | *Thermus aquaticus*（水生栖热菌）、*Geobacillus stearothermophilus* |
| 超嗜热菌 | 最适高于80 °C | *Pyrococcus furiosus*、*Pyrolobus fumarii*、*Methanopyrus kandleri* |

已记录的生长最高温度为122 °C，由高压下的 *Methanopyrus kandleri* 菌株116创下（[[diversity-of-life/bacteria-archaea]]）；观察到细胞分裂的最低温度约在−15 °C 的卤水中。生长对温度的曲线通常不对称：生长速率逐渐升到最适值，大致类似化学反应速率的方式，越过最适值后急剧下降，因为蛋白质变性、膜变得过于流动。低于最低值时，膜变得过于僵硬，酶变得过于迟缓。

嗜热菌以更多的离子相互作用、更紧密的疏水核心与更少的热不稳定残基来稳定其蛋白质；它们的膜有更长的、更饱和的脂肪酸，古菌则用四醚脂质（[[microbiology/microbial-cells]]）。超嗜热菌具有**反向促旋酶**，可向 DNA 中引入正超螺旋。嗜冷菌的酶柔性好、在低温下活性高，膜不饱和，并有抗冻蛋白与冷激蛋白。

::: proposition 平方根模型 {#prop-ratkowsky}
在最适值以下，许多细菌的生长速率可由 David Ratkowsky 及同事（1982）的平方根关系**经验**地描述，

$$
\sqrt{\mu} = b\,(T - T_\mathrm{min}),
$$ {#eq-ratkowsky}

其中$T_\mathrm{min}$是一个名义上的最低温度（拟合直线的截距，未必是观察到生长的最低温度），$b$是拟合常数。在整个低于最适的温度范围内，它比 Arrhenius 方程更好地描述数据，但它没有从第一性原理出发的推导。
:::

::: example 冷藏为何有效 {#ex-ratkowsky}
对一种耐冷腐败细菌，拟合给出$T_\mathrm{min} = 2$ °C、$b = 0.03$ h^−1/2^ °C⁻¹。预测在37 °C、10 °C 与4 °C 下的倍增时间，并比较一周内在4 °C 与在10 °C 下的倍增次数。
::: solution
在37 °C：$\sqrt\mu = 0.03\times35 = 1.05$，故$\mu = 1.10$ h⁻¹，$t_d = 0.693/1.10 = 0.63$ h（若37 °C 仍在该生物最适温度以下；实践中未必如此）。在10 °C：$\sqrt\mu = 0.24$，$\mu = 0.058$ h⁻¹，$t_d = 12$ h。在4 °C：$\sqrt\mu = 0.06$，$\mu = 0.0036$ h⁻¹，$t_d = 193$ h，约8天。一周（168 h）之内，种群在10 °C 下倍增14次（增至约16,000倍），而在4 °C 下不足一次。在最低温度附近，几度之差会造成巨大差别，这就是冰箱应保持在约4–5 °C 或更低的原因。
:::
:::

### pH

大多数细菌是**嗜中性菌**，最适 pH 5.5–8。**嗜酸菌**在 pH 5.5以下生长最好，其中一些如古菌 *Picrophilus* 近于 pH 0；**嗜碱菌**在 pH 9–11下生长于碱湖及其他碱性环境。无论外部 pH 如何，细胞都使其细胞质远离外部值而更接近中性：pH 2下的嗜酸菌内部 pH 可维持在约6.5，pH 10.5下的嗜碱菌内部 pH 接近8.5。它们靠泵出质子、靠控制膜的通透性、并靠调节质子动力势在 pH 梯度与膜电位之间的分配来做到这一点（[[biochemistry/oxidative-phosphorylation#prop-pmf]]）。嗜碱菌有一个特殊问题：当 pH 梯度方向不对它们有利时如何制造 ATP；它们中许多改用钠梯度而非质子梯度来进行运输与运动。

许多微生物改变其环境的 pH：发酵者使培养基酸化，这就是乳酸菌能保藏食品、而培养基要加缓冲剂的原因。

### 水的可利用性

水的可利用性以**水分活度**$a_w$度量：溶液上方水的蒸气压与纯水上方蒸气压之比（纯水$a_w = 1$，海水约0.98）。溶质与干燥降低$a_w$。大多数细菌需要$a_w$高于约0.9；许多真菌与酵母可生长到约0.8，最耐受的（**嗜旱菌**，如霉菌 *Xeromyces bisporus*）到约0.61。**嗜盐菌**需要盐：中度嗜盐菌在1–3 mol L⁻¹ NaCl 下生长最好，极端嗜盐菌（大多为嗜盐古菌）则近乎饱和的卤水（约5 mol L⁻¹）中。

在高盐中生活有两种策略。大多数细菌与许多古菌积聚有机**相容性溶质**——甘氨酸甜菜碱、ectoine、脯氨酸、海藻糖——它们平衡外部渗透压而不妨碍酶。嗜盐古菌与少数细菌如 *Salinibacter ruber* 则反其道积聚 K⁺ 直至摩尔浓度（"盐内"策略）；它们的蛋白质已进化成在高盐中工作，表面带许多酸性残基，在淡水中反而会变性。以干燥、加盐或加糖来降低水分活度，是保藏食品最古老的方法之一。

### 氧

氧是强力的电子受体，但也是有毒**活性氧**——超氧化物（O₂⁻）、过氧化氢（H₂O₂）与羟自由基（·OH）——的来源：还原型黄素蛋白与其他酶与 O₂ 反应时便会形成它们（[[biochemistry/oxidative-phosphorylation]]）。与氧共存的生物以**超氧化物歧化酶**（2 O₂⁻ + 2 H⁺ → H₂O₂ + O₂）、**过氧化氢酶**（2 H₂O₂ → 2 H₂O + O₂）与过氧化物酶保护自己。

::: definition 氧的类别 {#def-oxygen}
- **专性需氧菌**呼吸需要 O₂（*Pseudomonas*、*Micrococcus*、*M. tuberculosis*）。
- **微好氧菌**需要 O₂ 但浓度须低于大气水平，大气浓度会损伤它们（*Campylobacter*、*Helicobacter*、许多趋磁细菌）。
- **兼性厌氧菌**有氧无氧都能生长：有氧时呼吸，无氧时发酵或呼吸其他受体（*E. coli*、*Saccharomyces cerevisiae*（酿酒酵母））；它们在有氧时长得更快。
- **耐氧厌氧菌**从不利用 O₂ 但能耐受它（大多数乳酸菌）。
- **专性（严格）厌氧菌**被 O₂ 杀死或抑制；许多缺乏过氧化氢酶与超氧化物歧化酶（*Clostridium*、*Bacteroides*、产甲烷菌）。
:::

这些类别可以在装有还原剂与氧化还原指示剂的试管中显现：氧只向管顶扩散——专性需氧菌在表面长成一窄带，微好氧菌在其下一点，专性厌氧菌只在底部，兼性厌氧菌满管都有但顶部最浓，耐氧厌氧菌则满管均匀。严格厌氧菌必须在已除氧的密封罐或厌氧培养箱中培养。

**压力**在深海中很重要：那里每千米深度压强约升高10 MPa（100 atm）；**嗜压菌**（barophiles）在高压下生长最好，有些只在50 MPa 以上生长。

::: application 食品安全中的预测微生物学
本章的方程每天都用于食品工业。把生长速率作为温度（如[[#eq-ratkowsky]]）、pH 与水分活度的函数、用 *Listeria monocytogenes*、*Salmonella* 与 *Clostridium botulinum* 等微生物的实验室数据拟合而成的模型，预测一个种群在贮存与流通期间将经历多少次倍增，从而确定保质期与贮存温度。这做法称为**预测微生物学**，其模型与"栅栏"（hurdles）相结合——若干温和的屏障（略酸、降低水分活度、低温、防腐剂），单个都不足以阻止生长，合起来则能。热与消毒剂杀死的动力学是[[microbiology/antimicrobials]]的主题。
:::

::: history
Monod 关于细菌生长的博士论文（1942）与其综述《The growth of bacterial cultures》（1949）定义了生长曲线、二次生长，以及生长速率对底物浓度的双曲线依赖。恒化器由 Monod 与 Novick 和 Szilard 于1950年分别描述；后者用它测量稳定生长的细菌的突变率。Schaechter、Maaløe 与 Kjeldgaard（1958）把细胞大小与组成同生长速率联系起来；Cooper 与 Helmstetter（1968）用重叠的复制轮解释了细菌的细胞周期。Thomas Brock 从黄石公园分离出 *Thermus aquaticus*（1969），开启了高温下生命的研究；Karl Stetter 自1980年代起分离超嗜热古菌，把已知的极限提到100 °C 以上。2000年代以来的单细胞方法正在逐细胞地重新审视这些经典定律。
:::

::: summary
- 细菌由 FtsZ 组织的二分裂增殖，FtsZ 环由 Min 系统与类核阻遏定位。在 *E. coli* 中复制耗时$C \approx 40$ min，复制结束到分裂的间隔$D \approx 20$ min；多叉复制允许更快的分裂，每细胞有$2^{(C+D)/\tau}$个起点，ori/ter 比为$2^{C/\tau}$。
- 指数增长：$N = N_0e^{\mu t}$，$t_d = \ln2/\mu$，世代数$n = 3.32\log_{10}(N/N_0)$。细胞大小与核糖体含量随生长速率而增。
- 分批培养呈现延滞、指数、稳定与衰亡各期；两种糖上出现二次生长。Monod：$\mu = \mu_\mathrm{max} S/(K_s + S)$（经验），得率为$Y$；最终生物量$X_0 + YS_0$。
- 在恒化器中，稀释率设定生长速率：$\mu = D$，$S^* = K_sD/(\mu_\mathrm{max} - D)$，$X^* = Y(S_R - S^*)$，超过$D_c$即被洗出。竞争单一资源时，$S^*$最低的物种获胜。
- 微生物能在0 °C 以下直到122 °C、pH 近0到11以上、水分活度低至0.61的条件下生长；最适值以下的生长常遵循$\sqrt\mu = b(T - T_\mathrm{min})$（经验）。
- 氧的类别——专性需氧菌、微好氧菌、兼性厌氧菌、耐氧厌氧菌与专性厌氧菌——反映了对 O₂ 的利用以及针对活性氧的防御（超氧化物歧化酶、过氧化氢酶）。
:::

## 习题

::: exercise 世代数 {level=1 check="23.3"}
一个培养物从每毫升$10^2$个细胞长到$10^9$个。它经历了多少代（保留一位小数）？
::: solution
$n = 3.32\times\log_{10}(10^9/10^2) = 3.32\times7$；更精确地，$7/\log_{10}2 = 7/0.30103 = 23.3$代。
:::
:::

::: exercise 由计数求倍增时间 {level=1 check="45"}
指数期的活菌计数在1 h 为$2.0\times10^5$ CFU mL⁻¹、在4 h 为$3.2\times10^6$ CFU mL⁻¹。倍增时间是多少分钟？
::: solution
增加了16倍，即4次倍增，历时3 h = 180 min，故$t_d = 45$ min。（$\mu = \ln 16/3 = 0.924$ h⁻¹。）
:::
:::

::: exercise 氧的类别 {level=1}
判别下列各微生物的类别：(a) 只在一管还原培养基的底部生长，且没有过氧化氢酶；(b) 满管生长，顶部最好；(c) 在表面之下几毫米处一个窄带内生长；(d) 满管均匀生长，无论有无 O₂ 都产乳酸。
::: solution
(a) 专性厌氧菌。(b) 兼性厌氧菌（能以 O₂ 呼吸处生长更快）。(c) 微好氧菌。(d) 耐氧厌氧菌：它无论如何都发酵，且不受 O₂ 伤害。
:::
:::

::: exercise 由测序求 ori/ter 比 {level=2 check="24"}
对指数生长培养物的 DNA 测序，起点附近的读段深度是终点附近的3.0倍。若 C 期为38 min，估计倍增时间（分钟）。
::: hint
用[[#eq-ori-ter]]并解出$\tau$。
:::
::: solution
$2^{C/\tau} = 3$，故$C/\tau = \log_2 3 = 1.585$，$\tau = 38/1.585 = 24.0$ min。由于$\tau < C$，这些细胞必定在进行多叉复制。
:::
:::

::: exercise 得率 {level=2 check="0.45"}
一个分批培养含5 mmol L⁻¹ 葡萄糖（摩尔质量180 g mol⁻¹），葡萄糖耗尽时生物量从0.02增至0.425 g 干重 L⁻¹。以每克葡萄糖的克干重表示得率（两位有效数字）是多少？
::: solution
葡萄糖：$5\times10^{-3}\times180 = 0.90$ g L⁻¹。$Y = (0.425 - 0.02)/0.90 = 0.405/0.90 = 0.45$ g g⁻¹。
:::
:::

::: exercise 恒化器的稳态 {level=2 check="0.5"}
某细菌$\mu_\mathrm{max} = 0.8$ h⁻¹、$K_s = 5$ mg L⁻¹，在$D = 0.4$ h⁻¹、$S_R = 1$ g L⁻¹、$Y = 0.5$的恒化器中生长。以 g L⁻¹ 表示的稳态生物量是多少（一位有效数字）？$S^*$是多少？
::: solution
$S^* = 5\times0.4/(0.8 - 0.4) = 5$ mg L⁻¹。$X^* = 0.5\times(1000 - 5) = 497.5$ mg L⁻¹ $\approx 0.5$ g L⁻¹。
:::
:::

::: exercise 洗出 {level=2}
对上一题的微生物，(a) 临界稀释率是多少？(b) 泵被误设为$D = 1.0$ h⁻¹。从稳态出发，细胞密度大约以多快的速度下降？(c) 为什么$\mu$不会升上去与之匹配？
::: solution
(a) $D_c = 0.8\times1000/(5 + 1000) = 0.796$ h⁻¹。(b) 基质浓度一旦升到接近$S_R$，细胞就以接近$\mu_\mathrm{max} = 0.8$ h⁻¹ 生长，却以1.0 h⁻¹ 被稀释，于是密度按$e^{-(1.0 - 0.8)t} = e^{-0.2t}$下降，约每3.5 h 减半；起初在基质升高之前下降更快，接近$e^{-0.6t}$。(c) 无论有多少基质可用，生长速率都无法超过$\mu_\mathrm{max}$。
:::

::: exercise 二次生长曲线 {level=2}
*E. coli* 在0.5 g L⁻¹ 葡萄糖与0.5 g L⁻¹ 乳糖的混合培养基中生长。OD 以40 min 的倍增时间指数上升，停30 min，然后以55 min 的倍增时间再次指数上升，达到约停顿处 OD 的两倍。(a) 解释各阶段。(b) 为什么第二阶段达到约第一平台的两倍？(c) 预测*lacI*^−^ 突变株的曲线，它组成型地合成 *lac* 酶。
::: solution
(a) 第一阶段：以葡萄糖生长，分解代谢物阻遏与诱导物排阻使 *lac* 操纵子保持关闭。停顿：葡萄糖耗尽，cAMP 上升，细胞诱导并合成 *lac* 酶（第二次延滞）。第二阶段：以乳糖生长，因乳糖支持的速率较低而较慢。(b) 每克糖支持的得率大致相同，所以乳糖阶段新增的生物量与葡萄糖阶段大致相当，使密度翻倍。(c) *lac* 酶本已存在，停顿应更短或消失；但葡萄糖仍优先被利用，部分经由诱导物排阻与其他途径的调节，所以斜率变化可能仍在。（[[molecular-biology/bacterial-gene-regulation]]。）
:::

::: exercise 竞争同一基质 {level=3}
物种 A 的$\mu_\mathrm{max} = 1.0$ h⁻¹、$K_s = 20$ µmol L⁻¹；物种 B 的$\mu_\mathrm{max} = 0.5$ h⁻¹、$K_s = 2$ µmol L⁻¹。(a) 在$D = 0.1$ h⁻¹ 的恒化器中谁获胜？在$D = 0.4$ h⁻¹ 呢？(b) 在什么稀释率下二者相当？(c) 在养分贫瘠的湖泊中你预期谁占优势？在污水出口呢？与"寡营养菌"和"富营养菌"的概念联系起来。
::: solution
(a) $S^*_A = 20D/(1 - D)$，$S^*_B = 2D/(0.5 - D)$。$D = 0.1$时：$S^*_A = 2.22$、$S^*_B = 0.5$ µmol L⁻¹，B 胜。$D = 0.4$时：$S^*_A = 13.3$、$S^*_B = 8.0$，仍是 B 胜。(b) 令$20D/(1 - D) = 2D/(0.5 - D)$：$20(0.5 - D) = 2(1 - D)$，即$10 - 20D = 2 - 2D$，$D = 8/18 = 0.444$ h⁻¹；高于此值后 A 胜，直到高$S_R$下接近$D = 0.98$ h⁻¹ 时它自己也濒临洗出。(c) B 亲和力高，是**寡营养菌**，在底物稀少、生长缓慢处占优；A 虽快但需要更多底物，是**富营养菌**，在养分丰沛或成批脉冲式到来处占优（如污水出口，或分批培养中——那里长得最快的拿走最多）。
:::

::: exercise 解读温度序列 {level=3}
测得某细菌在若干温度下的生长速率：在5 °C 为0.016 h⁻¹，10 °C 为0.144 h⁻¹，15 °C 为0.40 h⁻¹，20 °C 为0.78 h⁻¹，25 °C 为1.30 h⁻¹，30 °C 为1.10 h⁻¹，33 °C 为0.10 h⁻¹。(a) 用前四个点估计平方根模型的$b$与$T_\mathrm{min}$。(b) 最适值在哪里？这是哪一类微生物？(c) 为什么生长速率在最适值以上下降得如此陡峭？
::: solution
(a) $\sqrt\mu$：在5、10、15、20 °C 处为0.126、0.379、0.632、0.883。增量几乎恒定，每5 °C 约0.253，故$b \approx 0.0505$ h^−1/2^ °C⁻¹，直线在$T_\mathrm{min} \approx 5 - 0.126/0.0505 = 2.5$ °C 处降为零。(b) 最适在25 °C 附近，最高生长温度近33–35 °C：这是一种耐冷的嗜中温菌，能在冰箱里（缓慢）生长——是腐败或食品安全方面的隐患。(c) 越过最适值后，蛋白质与其他大分子开始变性，膜失去完整性；变性是一个协同过程，其速率随温度上升得极其陡峭，所以下降比上升陡峭得多。
:::
