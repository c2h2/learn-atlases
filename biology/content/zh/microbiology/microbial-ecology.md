假如地球上每一个微生物明天都停止工作，后果很快就会显现。死亡的动植物将堆积而不腐；其中的氮永远不会以铵和硝酸盐的形式回到土壤，庄稼会因缺氮而歉收；沉积物中产生的硫化物与甲烷将在抵达水体和大气之前不再被氧化；而在海洋——显微光能营养生物每年在此固定的碳与全部陆地植物大致相当——将失去半个星球的初级生产。微生物不是生态学的旁枝末节，而是它的化学引擎：地球表层碳、氮、硫的转化，多数由微生物催化。

本章讲环境中的微生物：它们如何以群落共处、以表面附着的生物膜共处，它们如何彼此相互作用、如何与大型生物形成共生，以及它们的集体代谢如何驱动碳、氮、硫的生物地球化学循环。代谢过程本身在[[microbiology/microbial-metabolism]]中描述，依序列鉴定群落成员见[[microbiology/microbial-diversity]]。一般生态学原理——种群、竞争、食物网、生态系统——见[[ecology]]。

## 微生物的生境

微生物在微米的尺度上体验其环境，而在那个尺度上，看似均匀的生境也是一幅马赛克。一块几毫米大的土壤团粒，表面可有好氧的、中心却有缺氧的，因为微生物消 O₂ 快于它经充水孔隙扩散进来；一颗海雪颗粒是稀薄海洋中的养分热点；根表、砂粒或牙面则提供附着场所与养分流。微生物的真正生境是其**微环境**，几十到几百微米范围内的氧、养分、pH 与氧化还原电位的梯度，决定着哪些生物能生活在何处。

::: definition 种群、群落与功能类群 {#def-community}
**种群**是生境中同一物种的细胞群体；**群落**是那里共同生活的所有不同物种的种群；**功能类群**（guild）则指执行同一功能的一组种群，如沉积物中的氨氧化菌或硫酸盐还原菌，无论其系统发育如何。**功能冗余**——同一功能类群中存在多个分类单元——意味着群落功能可以在组成波动时保持稳定。
:::

一些常见生境中的微生物数量能让人对规模有直观感受：表层海水每毫升约含$10^5$–$10^6$个原核细胞，农业土壤每克含$10^8$–$10^{10}$个，人结肠内容物每克含$10^{11}$个。多样性也相应巨大：一克土壤可能含数千到数万个等级为种的分类单元（这一估计高度依赖方法与定义；[[diversity-of-life/bacteria-archaea]]）。

## 生物膜

在自然界，多数微生物并不在液体中自由游动，而是附着于表面、嵌入自己制造的基质中生活。Bill Costerton 及同事自1970年代末起论证：这种固着的、表面附着的生活方式才是主导方式。

::: definition 生物膜 {#def-biofilm}
**生物膜**是附着于表面或彼此附着、嵌入自身产生的**胞外聚合物**（EPS）——多糖、蛋白质（包括淀粉样纤维）、胞外 DNA 与脂质——基质中的结构化微生物群落。生物膜形成于溪流中的石块上、牙齿上（牙菌斑）、管道内与医疗器械上；浮游的聚集体与菌席是其近亲。
:::

生物膜的形成在许多物种中遵循大体相似的过程：单个细胞的可逆附着，常由鞭毛与菌毛介导；细胞产生黏附素与基质后的不可逆附着；生长为微菌落；成熟为三维结构——在流动腔中培养的铜绿假单胞菌（*Pseudomonas aeruginosa*）可呈蘑菇状的塔，塔间由水流通道分隔；最后是扩散（dispersal），部分细胞离开去定殖新的表面。这些转变中的许多由细胞内第二信使**环二 GMP**（cyclic di-GMP）控制：高水平促进基质产生与固着生活，低水平则促进运动。

### 生活在梯度之中

基质会减慢大分子的移动，却不减慢小分子，而在厚生物膜中，供应的主要障碍不过是表面附近细胞对底物的消耗。扩散叠加消耗形成梯度，使生物膜内部成为与其表面不同的环境。

::: proposition 底物的穿透深度 {#prop-penetration}
考虑一块平整生物膜，其表面（$x = 0$处）的某种底物（如 O₂）浓度为$C_0$，以扩散系数$D$扩散，并在其存在之处以恒定的体积速率$q$被消耗（零级动力学，适用于消耗者的半饱和常数远小于$C_0$的情形）。稳态时的浓度分布为

$$
C(x) = C_0\left(1 - \frac{x}{\delta}\right)^2 \quad (0 \le x \le \delta), \qquad \delta = \sqrt{\frac{2DC_0}{q}},
$$ {#eq-penetration}

而超过**穿透深度**$\delta$后$C = 0$。
:::

::: proof
稳态下，扩散进入一薄层的量与其内部的消耗量相平衡：在$C > 0$处$D\,d^2C/dx^2 = q$。积分两次，$C(x) = \frac{q}{2D}x^2 + Ax + B$。在表面$C(0) = C_0$，故$B = C_0$。在穿透深度处，浓度与其通量同时为零，$C(\delta) = 0$且$C'(\delta) = 0$（底物不会流过它耗尽之点）。第二个条件给出$A = -q\delta/D$，第一个条件于是给出$\frac{q}{2D}\delta^2 - \frac{q}{D}\delta^2 + C_0 = 0$，即$\delta^2 = 2DC_0/q$。代回得$C(x) = \frac{q}{2D}(x^2 - 2\delta x + \delta^2) = \frac{q}{2D}(\delta - x)^2 = C_0(1 - x/\delta)^2$。
:::

::: example 氧能到达多深？ {#ex-penetration}
25 °C 的充空气水中，某生物膜表面 O₂ 约为250 µmol L⁻¹（0.25 mol m⁻³）。O₂ 在该生物膜中的扩散系数为$2\times10^{-9}$ m² s⁻¹，细胞消 O₂ 的速率为0.05 mol m⁻³ s⁻¹。(a) 计算穿透深度。(b) 到达穿透深度一半处 O₂ 浓度是多少？(c) 若生物膜厚500 µm，其深层是怎样的环境？可能生活着什么生物？
::: solution
(a) $\delta = \sqrt{2\times2\times10^{-9}\times0.25/0.05} = \sqrt{2\times10^{-8}} = 1.41\times10^{-4}$ m，约140 µm。

(b) 在$x = \delta/2$处，$C = C_0(1/2)^2 = 63$ µmol L⁻¹，为表面值的四分之一。

(c) 约140 µm 以下生物膜即缺氧。那里的兼性厌氧菌进行发酵或以硝酸盐呼吸；硫酸盐还原菌与产甲烷菌等严格厌氧菌可以生活在最深层。氧微电极测定（Niels Peter Revsbech 自1980年代起开创）显示，活跃生物膜与沉积物中的穿透深度为几十到几百微米，与此估计一致。同样的梯度意味着生物膜深处的细胞生长缓慢或完全不生长，这有助于生物膜耐受只杀死生长中细胞的抗生素（[[microbiology/antimicrobials]]）。
:::
:::

### 在群体中交谈

许多细菌依群体密度调控基因，即 **群体感应**：每个细胞以低速率分泌一种小信号分子—— **自诱导物**——当信号在受限空间中积累超过阈值——这只在大量细胞共存时才会发生——它便开启一组基因。这一机制发现于发光弧菌（*Vibrio fischeri*）（Kenneth Nealson、Terry Platt 与 Woodland Hastings，1970），并在[[molecular-biology/bacterial-gene-regulation]]中描述。革兰氏阴性细菌通常使用由 LuxI 类酶合成、由 LuxR 类受体感知的酰基高丝氨酸内酯；革兰氏阳性细菌使用由双组分系统感知的短肽；许多两类细菌都会合成呋喃酮衍生的 **自诱导物-2**——由 onnie Bassler 的课题组发现——它或许允许种间通讯。群体感应控制那些只有在众多细胞共同行动时才有回报的群体活动——发光、分泌胞外酶与毒素、生物膜的形成与扩散。

群体感应度量的究竟是密度还是别的什么，尚有争论：由于信号只要向细胞的扩散受限就会积累，它同样可以是一种“扩散感知”或“效率感知”——即检验分泌的产物是否会留在制造它们的细胞附近。

## 微生物之间的相互作用

微生物之间的相互作用，大型生物有的方式它们全都有。

| 相互作用 | 对 A、B 的影响 | 微生物实例 |
|---|---|---|
| 互利共生 | +, + | 互营的发酵菌与产甲烷菌；氨基酸与维生素的交叉喂养 |
| 偏利共生 | +, 0 | 除 O₂ 从而让厌氧菌得以生长的需氧菌；降解聚合物、其产物喂养他者的分解者 |
| 竞争 | −, − | 在恒化器或沉积物中争夺限制基质（[[microbiology/microbial-growth]]） |
| 偏害共生与拮抗 | 0或 +, − | 抗生素与细菌素的产生；乳酸菌的产酸酸化 |
| 捕食与寄生 | +, − | 原生生物牧食细菌；蛭弧菌属（*Bdellovibrio*）侵入其他细菌；噬菌体（[[microbiology/viruses]]） |

**交叉喂养**十分常见：在许多群落中，生物分泌的氨基酸、维生素或发酵产物正是其他生物所需，整个类群（如基因组极小的 Patescibacteria 与 DPANN 古菌；[[microbiology/microbial-diversity]]）似乎都依赖伙伴。**互营**（syntrophy）是极端情形：伙伴合起来完成任何一方单独都完不成的反应，因为一方把另一方的产物（常 H₂ 或甲酸）维持在足够低的浓度，使总反应放能（[[diversity-of-life/bacteria-archaea]]）。

许多微生物产物是**公共物品**：分泌的酶、搜刮铁的铁载体、帮助群游运动的表面活性剂。制造它们的细胞付出成本，而附近任何细胞都受益，于是停止制造的“作弊者”得以扩散。Ashleigh Griffin、Stuart West 与 ngus Buckling（2004）用铜绿假单胞菌及其铁载体 pyoverdine 证明，当亲缘关系高时合作者表现最好——邻居很可能是同一克隆的细胞，正如由少数奠基细胞长成的生物膜中那样——与亲缘选择理论一致（[[behaviour]]）。空间结构把亲缘个体聚在一起，是合作能在生物膜中存续的原因之一。

原生生物的**捕食**是水体与土壤中细菌死亡的主要原因，在海洋中与病毒裂解相当。牧食者偏好一定大小的细胞，细菌则靠形成丝状体、聚集体或生物膜、变得极小、或产生毒素来逃脱。

## 与植物和动物的共生

共生意为“共居”，包括互利共生、偏利共生与寄生，尽管人们常用它指紧密而持久的互利关系。几个例子可见其范围。

**豆科植物与根瘤菌。** *Rhizobium*、*Sinorhizobium* 与 *Bradyrhizobium* 等根瘤菌在豆科植物根瘤内固氮。伙伴关系始于一场分子对话：植物根分泌黄酮类化合物，诱导细菌的 *nod* 基因；细菌产生 **Nod 因子**——其结构决定哪些豆科植物可被结瘤的脂壳寡糖（Patrice Lerouge 及同事，1990）；根毛围绕细菌卷曲，细菌经植物长出的 **侵入线** 进入；根皮层细胞分裂形成根瘤，细菌在其中被释放进植物细胞、外被一层植物膜，并分化为固氮 **类菌体**。植物供应二羧酸与低氧环境（借助豆血红蛋白；[[microbiology/microbial-metabolism#def-nitrogenase]]）；类菌体则回报以铵。植物还会“制裁”固氮少的根瘤——减少其氧气供应。

**菌根**是根与真菌的伙伴关系，见于大多数陆生植物；详见[[diversity-of-life/fungi]]与[[plant-biology]]。

**化能合成共生。** 在深海热液喷口，巨型管虫 *Riftia pachyptila* 没有口也没有肠。它体内有一个充满硫氧化菌的营养体，这些细菌利用硫氧化的能量固 CO₂（Colleen Cavanaugh 及同事，1981）；蠕虫的血红蛋白同时向它们输 O₂ 与硫化物。在富硫沉积物中，蛤、贻贝与线虫也有类似的共生。

**昆虫与其内共生菌。** 约半数昆虫物种在特化的细胞内藏着细菌。蚜虫依赖布赫纳菌（*Buchnera aphidicola*），它合成蚜虫所食韧皮部汁液中缺乏的必需氨基酸，并由母体传给子代；这类共生体基因组细小而退化（[[microbiology/microbial-diversity]]）。

**发光器官。** 夏威夷短尾乌贼 *Euprymna scolopes* 从海水中把发光弧菌（*Vibrio fischeri*）引入发光器官，细菌在其中经群体感应发光；光向下发射，在月夜抹去乌贼的影子。每天清晨乌贼排出大部分细菌，余下的重新长起——这是研究动物如何选择其共生体的模式系统（Margaret McFall-Ngai 与 dward Ruby 的研究）。

**珊瑚礁**依赖珊瑚细胞内的光合甲藻（虫黄藻科 Symbiodiniaceae），后者提供珊瑚所需能量的大部分；受热胁迫时，珊瑚将其排出而“白化”。**地衣**是真菌与藻类或蓝细菌的伙伴关系。

动物（包括人类）的微生物组，以及微生物致病的方式，是[[microbiology/microbes-and-hosts]]的主题。

## 碳循环

碳在大气与海洋中 CO₂ 和生物体、土壤、沉积物中的有机物之间循环。微生物参与每一步。

**初级生产。** 海洋中的光合微生物——蓝细菌与真核藻类——固定的碳约占全球净初级生产力（每年约105 Pg（10¹⁵ g）碳）的一半（Christopher Field 及同事，1998，据卫星测定）。微小的蓝细菌原绿球藻（*Prochlorococcus*）到1988年才 Sallie Chisholm、Robert Olson 及同事借流式细胞术发现，却是地球上最丰富的光合生物。

**微生物环。** 浮游植物固定的碳有大量以溶解有机质（DOM）的形式释放——经渗漏、牧食与病毒裂解——稀薄得无法被动物摄食。异养细菌将其吸收，又被原生生物吃掉，原生生物再被浮游动物吃掉。Farooq Azam 及同事（1983）称之为 **微生物环**：它把溶解的碳送回食物网，但每一步都有一部分被呼吸成 CO₂。病毒裂解使之短路，把细菌内含物释放回 DOM 库（**病毒分流**；[[microbiology/viruses]]）。

**生物泵。** 一部分有机物以死亡细胞、粪粒与聚集体（“海雪”）的形式沉出海洋表层，其中大部分将在下行途中被细菌分解；抵达深海或沉积物的小部分则使碳几个世纪甚至更久地脱离与大气接触。

异养细菌把吸收的碳转化为新细胞的效率，决定多少有机碳沿食物网上传、多少被呼吸掉。

::: definition 细菌生长效率 {#def-bge}
**细菌碳需求**（BCD）是细菌吸收有机碳的速率，等于**细菌生产量**（BP，掺入生物量的碳）与**细菌呼吸**（BR，以 CO₂ 形式释放的碳）之和。**细菌生长效率**为$\mathrm{BGE} = \mathrm{BP}/\mathrm{BCD} = \mathrm{BP}/(\mathrm{BP} + \mathrm{BR})$。在天然水体中它通常很低，开阔大洋中约0.1–0.3，在高生产力的近岸海水中更高（Paul del Giorgio 与 onathan Cole，1998）。
:::

::: example 碳去了哪里？ {#ex-bge}
某近岸水样中，以放射性标记亮氨酸掺入蛋白质测得的细菌生产量为2 µg C L⁻¹ d⁻¹，生长效率估计为0.2。浮游植物的初级生产为40 µg C L⁻¹ d⁻¹。(a) 细菌碳需求与呼吸各是多少？(b) 初级生产的多大比例经过细菌？(c) 若原生生物以0.3的生长效率牧食细菌生产量，多少碳进入原生生物的生物量？
::: solution
(a) $\mathrm{BCD} = \mathrm{BP}/\mathrm{BGE} = 2/0.2 = 10$ µg C L⁻¹ d⁻¹；$\mathrm{BR} = 10 - 2 = 8$ µg C L⁻¹ d⁻¹。

(b) 初级生产的$10/40 = 25\,\%$被细菌加工（假设它们利用的溶解碳来自本地浮游植物）。

(c) $0.3\times2 = 0.6$ µg C L⁻¹ d⁻¹，经两步之后只占初级生产的1.5 %。进入微生物环的碳大部分被呼吸 CO₂—— 相对于向更高营养级的“链接”，它更像一个“汇”，这是海洋生态学中长期争论的问题。
:::
:::

陆地上的**分解**由细菌与真菌完成。纤维素两者都能在有氧与无氧条件下降解；木质素是第二丰富的生物聚合物，其高效降解主要靠有氧的白腐菌，这也是积水泥炭得以堆积的原因之一。土壤有机碳的储量约为大气的两到三倍，其形成与微生物分解（分解随增温而加快）之间的平衡，是气候变化预测的一大不确定源。

**甲烷循环。** 在硫酸盐等其他受体稀缺的缺氧环境——湿地、稻田、垃圾填埋场、淡水沉积物与瘤胃——分解的终产物是甲烷，由产甲烷古菌用发酵者提供的 H₂ + CO₂、乙酸与甲基化合物制造（[[microbiology/microbial-metabolism]]）。甲烷每分子的温室效应比 CO₂ 强许多倍，自然湿地、农业（反刍动物与水稻）与废弃物中的微生物产甲烷是大多数甲烷排放的源头。但产生的甲烷大多到不了大气：好氧的 **甲烷氧化菌**（如 *Methylococcus*）在好氧-厌氧界面消耗它，海洋沉积物中则由厌氧甲烷氧化古菌与硫酸盐还原菌组成的联合群落在缺氧处消耗它（[[diversity-of-life/bacteria-archaea]]）。在海洋沉积物中，这些厌氧氧化者据信消耗了其下方产生的大部分甲烷。

## 氮循环

氮在自然界存在于从−3（NH₃、有机氮）到+5（硝酸盐）的各个氧化态，微生物使它在其间移动。

| 过程 | 转化 | 条件 | 生物 |
|---|---|---|---|
| 固氮 | N₂ → NH₃ | 富能、固氮酶周围 O₂ | 固氮生物：根瘤菌、蓝细菌、固氮菌属（*Azotobacter*）、梭菌，一些产甲烷菌 |
| 同化 | NH₄⁺、NO₃⁻ → 有机氮 | 任何地方 | 植物、微生物 |
| 氨化（矿质化） | 有机氮 → NH₄⁺ | 任何地方 | 分解者 |
| 硝化 | NH₄⁺ → NO₂⁻ → NO₃⁻ | 好氧 | 氨氧化细菌与古菌、亚硝酸盐氧化菌、完全氨氧化（comammox）*Nitrospira* |
| 反硝化 | NO₃⁻ → NO₂⁻ → NO → N₂O → N₂ | 缺氧，需有机或无机供体 | 许多兼性细菌 |
| 异化性硝酸盐还原为铵（DNRA） | NO₃⁻ → NH₄⁺ | 缺氧，有机碳与硝酸盐之比高 | 许多细菌 |
| 厌氧氨氧化 | NH₄⁺ + NO₂⁻ → N₂ | 缺氧 | Brocadiales（Planctomycetota） |

固氮与两个产 N₂ 的过程——反硝化与厌氧氨氧化——把生物圈与大气库连接起来；其余过程则在生态系统内循环氮。厌氧氨氧化 Engelbert Broda 于1977年依据热力学预言，1990年代在废水反应器中被发现，如今被认为贡献了某些海洋缺氧区与沉积物 N₂ 产量的很大一部分，其份额相对反硝化在不同站点间差异极大。

人类已使进入陆地表面的固定氮的速率大约翻番，主要经由哈伯-博施（Haber–Bosch）法与豆科作物的种植。多余的氮大部分被硝化并作为硝酸盐淋失，污染地下水、造成湖泊与近岸海的**富营养化**，或被反硝化而释 N₂O。

::: example 硝化使土壤酸化 {#ex-nitrification-acid}
硝化的总反应为 NH₄⁺ + 2 O₂ → NO₃⁻ + 2 H⁺ + H₂O。一位农民每公顷施用100 kg 氮的铵态肥料，全部被硝化（且没有一株植物以铵的形式吸收）。(a) 每公顷产生多少摩 H⁺？(b) 中和它们需要多少碳酸钙（CaCO₃，100 g mol⁻¹，每个式单位中和两 H⁺）？
::: solution
(a) 100 kg 氮即$100{,}000/14 = 7{,}140$ mol；每个氮产生两 H⁺，即每公顷$14{,}300$ mol H⁺。

(b) $14{,}300/2 = 7{,}140$ mol CaCO₃，即$7{,}140\times100$ g $= 714$ kg 石灰。（植物吸收硝酸盐会消耗一部分酸，所以实际需要更少，但这一计算说明了为何施用铵态肥料的土壤会酸化、需要施石灰。）
:::
:::

::: example 给处理厂的反硝化菌“喂食” {#ex-denitrification}
某废水厂靠反硝化除硝酸盐，添加乙酸盐作电子供体：5 CH₃COO⁻ + 8 NO₃⁻ + 3 H⁺ → 10 HCO₃⁻ + 4 N₂ + 4 H₂O。(a) 检验电子平衡（乙酸盐碳从氧化态0升至+4；硝酸盐氮从+5降至0）。(b) 除去1 kg 硝态氮需要多少质量的乙酸盐（59 g mol⁻¹）？忽略用于细胞生长的乙酸盐。(c) 以化学需氧量（COD；1 mol 乙酸盐完全氧化需2 mol O₂）表示。
::: solution
(a) 每个乙酸盐（2个碳，平均氧化态0）氧化为2 HCO₃⁻ 时释放8个电子：$5\times8 = 40$ 个电子。每个硝酸根变为 ½N₂ 接受5个电子：$8\times5 = 40$。平衡。

(b) 1 kg 氮为71.4 mol 硝酸盐；需乙酸盐$= 71.4\times5/8 = 44.6$ mol，即$44.6\times59 = 2.6$ kg。

(c) $44.6\times2 = 89.3$ mol O₂ $= 89.3\times32$ g $= 2.86$ kg COD 每 kg 氮——设计此类处理厂所用的标准理论值（尚未计入生长）。厌氧氨氧化完全不需要有机供体，省下了这笔成本，这是它被用于现代富氮废水处理的原因之一。
:::
:::

## 硫循环

硫在硫酸盐（+6，海水中最丰富的形态，约28 mmol L⁻¹）、元素硫（0）与硫化物（−2）之间循环。缺氧沉积物中的**硫酸盐还原**产生 H₂S，在海洋沉积物中它是有机物矿化的主要途径之一（[[microbiology/microbial-metabolism]]）。向上扩散的硫化物被化学氧化或被**硫氧化菌**氧化——好氧界面处的化能无机营养菌如 *Beggiatoa* 与硫杆菌属（*Thiobacillus*），或光照可达缺氧水体处的不产氧光能营养菌（紫色与绿色硫细菌）。一些细菌把**中间价态化合物**如硫代硫酸盐或元素硫**歧化**为硫酸盐与硫化物。

在海洋沉积物中，脱硫弧菌科（Desulfobulbaceae）长达几厘米的丝状**电缆细菌**，通过沿其身体导电，把深处的硫氧化与表面的氧还原偶联起来（Christian Pfeffer、Lars Peter Nielsen 及同事，2012）——这种以电而非以化学物为媒介的代谢形式，直到近年才为人知。

硫也经微生物进入大气。许多海洋藻类合成二甲基巯基丙酸内盐（DMSP）作为渗透调节物质；细菌将其降解，部分生成**二甲基硫**（DMS），是大气硫的主要天然来源。Robert Charlson、James Lovelock 及同事（1987）提出，DMS 可通过形成充当云凝结核的气溶胶参与气候反馈回路（“CLAW 假说”）；后续工作发现，这一反馈即便存在，也比最初的设想更弱、更复杂。

::: quiz
哪两个过程共同作用，会导致土壤固定氮的净损失并进入大气？
- [ ] 固氮与氨化
- [x] 硝化随后反硝化
- [ ] 氨化随后同化
- [ ] 硝化随后同化
::: solution
硝化把好氧区的铵转为硝酸盐；反硝化在缺氧微域把硝酸盐还原 N₂（兼有一 N₂O），后者逃逸到大气。两者常在土壤与沉积物的好氧-厌氧界面处耦联。固氮是添加氮；氨化与同化则把氮留在系统内。
:::
:::

::: warning “万物无处不在”有其限度
Baas Becking 的格言（[[microbiology/microbial-world#def-enrichment]]）道出了某种真实：微生物散布极广，环境强力选择哪些能够生长。但测序已表明，许多微生物确有生物地理格局：群落的差异既随环境、也随距离而变；孤立热泉中有特有的谱系（不同大陆的 *Sulfolobus* 群体在遗传上彼此有别；Rachel Whitaker 及同事，2003）；无法耐受长途运输的生物则存在扩散限制。同样，宏基因组中存在某一过程的基因，并不表明该过程正在发生：基因必须表达、酶必须有活性、条件必须合适。用同位素直接测定速率，仍然不可或缺。
:::

## 微生物生态学家如何测定过程

微生物生态学把生物的鉴定与其所干之事的度量结合起来：

- **微传感器** 测 O₂、H₂S、pH、N₂O 与其他化学种，针尖仅几微米宽，能在生物体所处的尺度上测绘生物膜、沉积物与菌席中的剖面。
- **同位素示踪** 测定速率：用 ¹⁵N 标记的硝酸盐或铵区分反硝化与厌氧氨氧化；用 ¹⁴C 或 ¹³C 碳酸氢盐测 CO₂ 固定；用 ³⁵S 硫酸盐测定硫酸盐还原。
- **稳定同位素探针**（SIP）把功能与身份联系起来：给群落饲喂 ¹³C 标记底物，把掺入标记的生物的 DNA 或 RNA 因其较高密度而分离出来测序（Stefan Radajewski、J. Colin Murrell 及同事，2000，用利用甲醇的细菌）。
- **单细胞方法**，如能在亚微米分辨率绘制同位素分布的离子探 NanoSIMS，与 ISH 结合，可显示哪些单个细胞吸收了标记底物。
- **宏转录组学** 与 **宏蛋白质组学** 显示群落中哪些基因正在表达。

::: intuition 一枚行星尺度的氧化还原电池
碳、氮、硫的循环经电子彼此耦合。光合作用用光把它们分开：把还原态的碳（有机物）放在一处，把氧化态的化合物（O₂，并经由它产生硝酸盐与硫酸盐）放在另一处。其余每一个微生物过程，都是让电子从还原库流回氧化库的一种方式，沿途提取能量——发酵者、呼吸者与化能无机营养者各取一站。沉积物或分层湖泊的成层、硝化与反硝化的耦联、甲烷氧化菌与硫酸盐还原菌的联合群落，都是这一股流动的种种表现，由扩散在空间上组织起来。
:::

::: application 微生物生态学大显身手
废水处理是应用化的微生物生态学：活性污泥、生物膜反应器、硝化与反硝化工段以及厌氧消化器，都是为特定功能而装配、管理的群落，而厌氧氨氧化反应器如今能以更少的能耗、不加碳源除氮。**生物修复**利用微生物群落降解污染物：石油泄漏由氧化烃类的细菌（如 *Alcanivorax*）降解，添加氮与磷可刺激其生长；地下水中的氯化溶剂则在缺氧含水层中被 *Dehalococcoides* 脱氯。在农业中，给豆科作物接种高效根瘤菌，以及能减少硝酸盐淋失 N₂O 排放的硝化抑制剂，都依赖同一套知识。
:::

::: history
Winogradsky 与 eijerinck 以富集培养以及对化能无机营养菌与固氮菌的发现奠定了微生物生态学（1880年代–1900年代）。Thomas Brock 自1960年代起对黄石热泉的研究，把生态学思想带入了自然环境中的微生物。Hobbie 的落射荧光计数（1977）揭示了水中细菌的真实丰度，Azam 描述了微生物环（1983），Chisholm 及同事发现了原绿球藻（1988）。微电极（自1980年代）、环境 16S rRNA 测序（自1985年）、稳定同位素探针（2000）与宏基因组学（2004）给了这一领域现代工具。厌氧氨氧化（1995–1999）、厌氧甲烷氧化联合群落（2000）、comammox（2015）与电缆细菌（2012）的发现表明，元素循环的主要过程直到近年还不为人知。
:::

::: summary
- 微生物生活在由微米尺度梯度结构化的微环境中；群落含功能冗余的功能类群。
- 自然界多数微生物生活在生物膜中，嵌 EPS；发育从附着到成熟与扩散，部分由环二 GMP 与群体感应控制。
- 以速率$q$被消耗的底物可穿透生物膜至深度$\delta = \sqrt{2DC_0/q}$，分布为$C_0(1 - x/\delta)^2$；O₂ 通常只达几十到几百微米，留下缺氧、生长缓慢的内部。
- 微生物以互利共生（互营、交叉喂养）、偏利共生、竞争、拮抗与捕食相互作用；公共物品招来作弊者，而结构化群体中的亲缘关系有利于合作。
- 共生包括豆科-根瘤菌根瘤（黄酮、Nod 因子、类菌体）、热液口动物的化能合成共生生物、昆虫内共生菌、乌贼-*Vibrio* 发光器官、珊瑚与地衣。
- 碳：海洋微生物固定全球初级生产的一半左右；经微生物环、病毒分流与生物泵流转；细菌生长效率$\mathrm{BP}/(\mathrm{BP} + \mathrm{BR})$常为0.1–0.3。产甲烷菌制造甲烷，甲烷氧化菌消耗大部分甲烷。
- 氮：固氮、同化、氨化、硝化、反硝化、DNRA 与厌氧氨氧化；人类已使固定氮的输入大约翻番。
- 硫：硫酸盐还原、硫化物氧化（化能无机营养型与光能营养型）、歧化、电缆细菌 DMS 的产生。
- 速率用微传感器、同位素示踪、SIP 与 anoSIMS 测定；基因的存在本身并不能证明活性。
:::

## 习题

::: exercise 穿透深度 {level=1 check="100"}
用[[#eq-penetration]]，计算$C_0 = 250$ µmol L⁻¹、$D = 2000$ µm² s⁻¹、$q = 100$ µmol L⁻¹ s⁻¹ 时 O₂ 穿透深度（µm）。
::: solution
$\delta = \sqrt{2\times2000\times250/100} = \sqrt{10{,}000} = 100$ µm。
:::
:::

::: exercise 生长效率 {level=1 check="0.25"}
某湖中的细菌吸收12 µg C L⁻¹ d⁻¹ 的溶解有机碳，呼吸9 µg C L⁻¹ d⁻¹。其生长效率是多少？
::: solution
$\mathrm{BP} = 12 - 9 = 3$ µg C L⁻¹ d⁻¹，故$\mathrm{BGE} = 3/12 = 0.25$。
:::
:::

::: exercise 说出过程名称 {level=1}
说出下列氮循环过程的名称：(a) 蛋白质分解时出现铵；(b) 渍水土壤中硝酸盐消失，释 N₂O 与 N₂；(c) 缺氧反应器中铵与亚硝酸盐一同消失，产 N₂；(d) 通气良好的土壤中铵被转化为硝酸盐；(e) 富有机质的缺氧沉积物中硝酸盐被转化为铵。
::: solution
(a) 氨化。(b) 反硝化。(c) 厌氧氨氧化。(d) 硝化。(e) 异化性硝酸盐还原为铵（DNRA）。
:::
:::

::: exercise 平方根标度 {level=2}
(a) 用[[#prop-penetration]]，若表 O₂ 浓度减半，穿透深度改变几倍？(b) 若生物膜细胞的呼吸速率加倍呢？(c) 一根管道中有一块1 mm 厚、完全好氧的生物膜。这说明它的活性如何？
::: solution
(a) $\delta \propto \sqrt{C_0}$：按$\sqrt2$下降，降至原值的71 %。(b) $\delta \propto 1/\sqrt q$：同样降至71 %。(c) 在$C_0 = 250$ µmol L⁻¹、$D = 2000$ µm² s⁻¹ 下，完全穿透到1,000 µm 要求$q \le 2DC_0/\delta^2 = 2\times2000\times250/10^6 = 1$ µmol L⁻¹ s⁻¹—— 比[[#ex-penetration]]中活跃生物膜低五十倍。该生物膜必定基本没有活性（或 O₂ 的供应靠的是通道中的平流而非单靠扩散）。
:::
:::

::: exercise 生物膜中的作弊者 {level=2}
一株不制造铁载体 pyoverdine 的铜绿假单胞菌突变体，在缺铁液体培养物中与野生型混合时比野生型长得快，但单独培养时比野生型长得慢。(a) 解释这两个结果。(b) 预测在由单细胞奠基、克隆成片状分离生长的生物膜中会发生什么。(c) 这如何说明亲缘关系的作用？
::: solution
(a) 单独培养时，突变体得不到铁而长得差。与野生型混合时，它坐享野生型制造的 pyoverdine 而不付制造成本，于是超过生产者：一个利用公共物品的作弊者。(b) 在各自分离的克隆斑块中，pyoverdine 大多留在其生产者附近，于是野生型斑块受益于自身的铁载体，突变体斑块则受害；野生型的频率应会上升。(c) 当受益者很可能携带合作者的基因时——高亲缘关系，这里由空间结构造成——合作（制造共享之物）才受青睐，正如亲缘选择理论所预言。
:::
:::

::: exercise 甲烷收支 {level=2 check="0.1"}
稻田中，产甲烷菌产生50 mg CH₄ m⁻² d⁻¹，但好氧表层与根际好氧带中的甲烷氧化菌氧化掉其中45 mg CH₄ m⁻² d⁻¹。(a) 产生的甲烷有多大比例逃逸到大气？(b) 季中排水使产量降到20 mg CH₄ m⁻² d⁻¹，而氧化除去18。此时排放量是多少？排水后还可能更多地排放哪种别的气体？
::: solution
(a) $(50 - 45)/50 = 0.1$，故10 %逃逸。(b) $20 - 18 = 2$ mg CH₄ m⁻² d⁻¹，排放减少60 %。排水使氧气进入土壤，刺激硝化；当土壤复水时，或在缺氧微域中，积累硝酸盐的反硝化可释放更 N₂O—— 这是稻田排放管理中的一种权衡。
:::
:::

::: exercise 脱氮成本 {level=2 check="1.90"}
按化学计量式6 NO₃⁻ + 5 CH₃OH → 3 N₂ + 5 CO₂ + 7 H₂O + 6 OH⁻，计算反硝化1 kg 硝态氮所需甲醇（32 g mol⁻¹）的质量（kg，保留两位小数）。先检验电子平衡（甲醇碳从−2升至+4）。
::: solution
电子：甲醇提供$5\times6 = 30$个，硝酸盐接受$6\times5 = 30$个。1 kg 氮为71.4 mol 硝酸盐。需甲醇$71.4\times5/6 = 59.5$ mol，$59.5\times32 = 1{,}905$ g $= 1.90$ kg。实际上需要更多，因为一部分甲醇被同化进新细胞，一部分与任何存在的氧一起被呼吸掉。
:::

::: exercise 读一副微生物席 {level=3}
某高盐泻湖中一副成层的微生物席，从上到下为：厚1–2 mm 的绿色层；紫色层；散发硫化物气味的黑色层。日光下的微传感器剖面显示，O₂ 在1 mm 深处升至空气饱和度的三倍，在3 mm 处降为零，硫化物恰在其下出现；夜 O₂ 只穿透0.5 mm，硫化物几乎升到表面。(a) 指认各层可能的生物。(b) 解释昼-夜变化。(c) 为什么这样的菌席可能与地球最早的生态系统相似？什么化石结构被认为记录了它们？
::: solution
(a) 绿色：产氧蓝细菌（兼有硅藻）；紫色：利用透过绿色层的光与上扩散的硫化物的不产氧紫色硫细菌；黑色：产 H₂S 的硫酸盐还原菌，颜色来自硫化铁。(b) 光照下，蓝细菌光合作用产 O₂ 快于消耗，使表层过饱和，并把好氧-厌氧边界推向下方，在那里硫化物被化能无机营养菌与光能营养菌氧化。夜间光合作用停止，呼吸消耗表面附近 O₂，硫化物向上扩散——菌席在以一天为周期的绝大部分好氧与绝大部分缺氧之间切换，其中许多生物也相应切换代谢。(c) 在动物进化出牧食它们的能力之前，微生物席很可能覆盖了浅海海底；成层、矿化的菌席形成叠层石，在距今约35亿年的岩石中即有发现（最古老者尚有争议），是最早的生命证据之一（[[diversity-of-life/origin-of-life]]）。
:::

::: exercise 同位素区分途径 {level=3}
取缺氧区沉积物，在厌氧条件下与 ¹⁵NH₄⁺ 加未标记的 ¹⁴NO₂⁻ 一起培养。24 h 后，标记 N₂ 几乎全部为 ²⁹N₂（¹⁴N¹⁵N），³⁰N₂ 很少。第二次只用 ¹⁵NO₃⁻ 培养，标记 N₂ 大多为 ³⁰N₂。(a) 第一次培养中的 ²⁹N₂ 由哪个过程产生？为什么？(b) 第二次中的 ³⁰N₂ 由哪个过程产生？(c) 对海洋的氮收支而言，区分二者为何重要？
::: solution
(a) 厌氧氨氧化：它把一个来自铵的氮原子与一个来自亚硝酸盐的氮原子结合，故 ¹⁵NH₄⁺ 加 ¹⁴NO₂⁻ 给出 ¹⁴N¹⁵N。反硝化不利用铵，无法把铵中的 ¹⁵N 放 N₂。(b) ¹⁵NO₃⁻ 的反硝化把硝酸盐库中两个标记原子配对，给出 ³⁰N₂（若用标记的硝酸盐衍生亚硝酸盐与未标记铵进行厌氧氨氧化，则应给出 ²⁹N₂）。(c) 两者都移除固定氮，但其调控不同——反硝化需要有机物，厌氧氨氧化需要铵与亚硝酸盐——副产物也不同（反硝化可释 N₂O）。要预测氮损失对生产力变化或缺氧区扩张的响应，就必须知道哪个过程占主导。
:::
