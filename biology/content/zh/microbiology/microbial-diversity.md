整整一个世纪里，细菌的分类一直是一件令人沮丧的事。动物与植物能按解剖构造排列成一棵反映祖裔关系的树，而细菌能提供的只有寥寥几种形状、一种染色和一张生化反应清单。1960年代，荷兰裔美国微生物学 Cornelis van Niel 与他的学 Roger Stanier 得出结论：细菌的自然亲缘关系也许永远无法查明。二十年后，这些关系直接从细胞自身的分子中被读了出来——而这一结果推翻了生命的基本图景。核糖体 RNA 序列表明，原核生物包含两个域，二者彼此之间的差异之大全，相当于其中任何一个与真核生物之间的差异；它们的多样性大多从未在培养中被观察到；而当整个基因组被测序之后，又发现基因在微生物谱系之间移动得如此频繁，以至于它们的进化既是一张网，同样也是一棵树。

本章讲我们如何认识微生物的进化关系，以及它们究竟是一些什么。文中解释核糖体 RNA 为何成为通用的分子时钟，序列差异如何换算成距离，水平基因转移是什么、如何被检测，不进行有性繁殖的生物如何界定物种，以及宏基因组学如何从从未被培养过的生物中复原基因组。已命名各门的概览见 [[diversity-of-life/bacteria-archaea]]，域与真核生物起源之争见 [[diversity-of-life/classifying-life]]，建树方法见 [[evolution/phylogenetics]]，基因转移的机制见 [[genetics/microbial-genetics]]。

## 通用的分子时钟

要比较细菌、产甲烷菌与蘑菇这样迥异的生物，需要一个三者共有、功能相同、变化慢到足以在整个生命范围内比对、又快到足以区分近缘类群的性状。祖克尔坎德尔（Emile Zuckerkandl）与鲍林（Linus Pauling）（1965）曾提出，蛋白质与核酸的序列是“进化历史的文献”。乌斯（Carl Woese）选择了核糖体小亚基的 RNA。

::: definition 核糖体小亚基 RNA {#def-ssu}
**核糖体小亚基 RNA**（SSU rRNA）——细菌与古菌中为**16S rRNA**（约1,500个核苷酸），真核生物中为**18S rRNA**（约1,800个核苷酸）——是核糖体小亚基的 RNA 骨架，构成其解码中心。它存在于每一种细胞生物中，在所有细胞生物中功能相同，由普遍保守区与九个**可变区**（V1–V9）镶嵌而成：前者使远缘生物的序列得以比对，并充任通用 PCR 引物的结合位点；后者则在近缘类群之间存在差异。编码它的基因很少在谱系之间转移，因为 rRNA 必须与数十种核糖体蛋白质相互作用。
:::

乌斯 George Fox（1977）比较了多种细菌 16S rRNA 的 Nase T1 指纹图，发现产甲烷菌与其他细菌之间的差异，恰如它们与真核生物之间的差异一样大；他们称其为“古细菌”（archaebacteria），乌斯、Otto Kandler 与 ark Wheelis（1990）进而提出细菌、古菌与真核生物三个域（[[diversity-of-life/classifying-life#def-domains]]）。16S 基因的测序在1980年代成为常规，如今像 SILVA 这样的校订数据库中收藏着数亿条 16S 序列，其中大多数来自从未被培养过的生物。

### 从差异到距离

两条已比对的序列若在$p$比例的位点上不同，其分歧就已超过每位点$p$次替换，因为有些位点变过不止一次，有些变化又回复了原状。最简单的校正假设每个位点以相同的速率变化，且任一碱基被其他任何碱基替换的概率相同。

::: proposition Jukes–Cantor 距离 {#prop-jc-micro}
在 ukes–Cantor 模型下，在$p$比例的比对位点上不同的两条序列之间，每位点替换数的期望值为

$$
d = -\frac{3}{4}\ln\left(1 - \frac{4}{3}p\right),
$$ {#eq-jc-micro}

当$p$很小时它接近$p$，而当$p$趋近饱和值$3/4$——此时两条随机序列会有四分之一的位点纯靠机缘彼此相同——它便无界地增大。推导见[[evolution/phylogenetics#prop-jc]]；更贴近现实的模型允许碱基频率不相等、转换与颠换速率不同，以及速率随位点而变化（gamma 分布），这对 rRNA 尤其重要，因为其保守区与可变区的变化速率可相差好几个数量级。
:::

::: example 两条 16S 序列 {#ex-jc}
两个细菌分离株 16S rRNA 基因的比对含1,400个位点，其中42个不同。(a) 计算同一性、$p$ 与 ukes–Cantor 距离。(b) 对来自不同门的一对序列，$p = 0.25$，$d$ 是多少？(c) 为什么(a)中的校正可以忽略，而(b)中却相当可观？
::: solution
(a) 同一性为$1 - 42/1400 = 97.0\,\%$，故$p = 0.030$，$d = -0.75\ln(1 - 0.04) = -0.75\times(-0.0408) = 0.0306$次替换每位点，几乎与$p$相同。

(b) $d = -0.75\ln(1 - 0.3333) = -0.75\times(-0.405) = 0.304$，比$p$大约20 %。

(c) 变化的位点很少时，某一个位点变过两次的概率就很小。随着分歧加深，同一位点上的多重变化不断累积，观察到的差异就越来越低估真实的替换——而一旦$p$接近0.75，序列几乎不再携带关于其距离的信息。因此生命之树的深部分支主要依据 rRNA 的保守区、或保守蛋白质来估计，因为二十种氨基酸这套字母表饱和得更慢。
:::
:::

### 给生命之树定根

仅用 SSU rRNA 构建的树是不定根的：它显示哪些类群彼此最近，却不显示共同祖先落在哪里。两个研究组（Naoyuki Iwabe 及同事，以 Peter Gogarten 及同事，均为1989）用在最近共同祖先（LUCA）之前就已复制的基因解决了这个问题——翻译延伸因子 EF-Tu 与 EF-G，以及质子泵 ATP 酶的催化亚基与调节亚基。复制产生的每一份拷贝都可以为另一份的树定根。两项分析都把根置于细菌居一侧、古菌加真核生物居另一侧之间，这一位置至今仍为大多数分析所支持，尽管真核生物是否起源于古菌**内部**（两域之树）是另一个问题（[[diversity-of-life/classifying-life#prop-two-domains]]）。

::: warning 97 %的同一性定不出一个种
二十年间，16S rRNA 基因同一性至少97 %的序列被归入“操作分类单元”，视作物种的近似（Erko Stackebrandt 与 ernhard Goebel，1994）。但 16S 基因进化得太慢，基因组与生活方式迥异的生物也能共有几乎相同的 16S 序列：*E. coli*（大肠杆菌）与志贺菌属（*Shigella*）各菌种只差几个位点，而 *Bacillus*（芽孢杆菌属）与 *Streptococcus*（链球菌属）中的许多种用 16S 根本分不开。反过来说，一个基因组可能带有这个基因的好几个拷贝，彼此相差约一个百分点。如今约98.7 %的阈值只被用作**低于**它两个菌株几乎必为不同种的判定点（Pablo Yarza 及同事，2014），而不是定义；物种的划分靠的是全基因组比较。
:::

## 水平基因转移

在真核生物中，基因几乎全由亲代传给子代—— **纵向** 遗传。在原核生物中，它们还会在无亲缘关系的细胞之间传递，靠 **转化**（摄取游离 DNA）、**转导**（由噬菌体携带）与 **接合**（经细胞间的通道转移），其机制及其在作图中的用途见[[genetics/microbial-genetics#def-transfer]]。一些α-变形菌，如 *Rhodobacter capsulatus*，还会释放 **基因转移剂**——包装宿主基因组随机片段的类噬菌体颗粒（Barry Marrs，1974）。

::: definition 水平基因转移与移动遗传元件 {#def-hgt}
**水平（侧向）基因转移**（HGT）指从亲代以外的生物获得遗传物质。它主要由**移动遗传元件**介导：**质粒**，能独立复制，其中许多是可接合的；**转座子**与**插入序列**，在 DNA 分子内部与分子之间移动；**整合性接合元件**（ICE），可整合进染色体但也能切离并经接合转移；**前噬菌体**（已整合的噬菌体基因组）；以及**整合子**，在特定位点捕获无启动子的基因盒并由自身的启动子加以表达（Ruth Stokes 与 Ruth Hall，1989）。水平获得的、携带同一类功能基因的大片段称为**基因组岛**——致病岛、共生岛、耐药岛、代谢岛。
:::

转移来的基因要留存下来，DNA 必须进入细胞、躲过降解并得到维持。细胞用 **限制-修饰系统** 抵御外源 DNA—— 它切割缺少宿主甲基化模式的 DNA—— 还用 **CRISPR–Cas** 适应性免疫记录以往入侵者的片段并摧毁与之匹配的 DNA（[[microbiology/viruses]]）。进入细胞的线性 DNA 必须由同源重组整合，而同源重组需要大段几乎完全相同的序列；重组速率随序列分歧大致按指数下降（Ivan Matic、Miroslav Radman 及同事，1990年代，用 *E. coli* 与沙门氏菌属（*Salmonella*）；Jacek Majewski 与 Frederick Cohan，2000，用 *Bacillus*），部分原因是错配修复系统会剔除错配的异源双链 DNA。于是基因在近亲之间流动最自由，而远缘谱系之间的转移主要依赖无需同源即可整合的元件（转座子、噬菌体、整合子）。

### 检测被转移的基因

有几类特征能揭示一个基因是水平获得的：

- **分布的不连续**：见于某物种的少数菌株，却不见于其近亲；或见于某个远缘谱系，却不见于该生物的任何近亲。
- **系统发育不一致**：基因树与携带它的生物之树严重冲突——例如古菌中的某个基因与细菌同源基因聚在一起。
- **异常组成**：G+C 含量、密码子使用或寡核苷酸频率不同于基因组的其余部分，反映出供体的突变偏向。转移来的 DNA 会逐渐 **改良**（ameliorate）为新宿主的组成，故此信号随时间消退。
- **侧翼特征**：插入位点紧邻 tRNA 基因（常见的整合位点）、正向重复序列、整合酶或转座酶基因的残迹。

::: example 用组成识别基因组岛 {#ex-gc}
某细菌基因组的总 G+C 含量为51 %。一个10 kb 的窗口含3,800个 G 或 C 碱基。(a) 若碱基独立抽取且$P(\mathrm{G\ or\ C}) = 0.51$，10 kb 窗口中 G+C 比例的标准差是多少？观察到的窗口偏离均值多少个标准差？(b) 为什么这一计算夸大了水平转移的证据？(c) 你还会寻找哪些进一步的证据？
::: solution
(a) 对二项比例，$\mathrm{sd} = \sqrt{p(1 - p)/n} = \sqrt{0.51\times0.49/10{,}000} = 0.0050$。窗口的 G+C 比例为0.38，故位于均值以下$(0.51 - 0.38)/0.005 = 26$ 个标准差处。

(b) 真实基因组的异质性远超独立抽取所能产生的：G+C 随基因功能、密码子位置、蛋白质组成、DNA 链以及染色体上的位置而变化，因此窗口的真实散布会比二项值大好几倍。更好的零分布来自窗口在基因组自身上的观察散布。即便如此，在51 %的基因组中出现13个百分点的偏离仍属反常，值得追查。

(c) 窗口内的基因是否存在于近缘生物中；它们的系统发育是否把与远缘生物的关系聚在一起；窗口两侧是否有 tRNA 基因与正向重复、内部是否含整合酶或转座酶基因；以及其密码子使用是否与基因组中高表达的基因不同。
:::
:::

### 转移有多频繁？

基因组测序表明 HGT 无处不在。*E. coli* K-12 与肠出血性菌 O157:H7 共享约4.1 Mb 的共同骨架，但 O157:H7 EDL933 带有约1.34 Mb K-12 所没有的 “O-islands” DNA，其中包括志贺毒素的基因（位于前噬菌体上）和使其附着于肠细胞 III 型分泌系统的基因（Nicole Perna 及同事，2001）。超嗜热细菌 *Thermotoga maritima* 约四分之一的基因与古菌基因最相似（Karen Nelson 及同事，1999），与共享高温环境的生物之间曾发生广泛转移相吻合。抗生素耐药基因在一种药物引入后数年内便借助质粒与整合子传遍多个种与属（[[microbiology/antimicrobials]]），而霍乱弧菌（*Vibrio cholerae*）的霍乱毒素基因则由一条丝状噬菌 CTXφ 携带（Matthew Waldor 与 ohn Mekalanos，1996）。

结果是同一个物种的各菌株在基因含量上可以差异巨大。Hervé Tettelin 及同事（2005）比较了八株无乳链球菌（*Streptococcus agalactiae*）的基因组，引入了**泛基因组**：所有菌株共有的基因构成**核心基因组**，部分菌株携带的基因构成**附属基因组**。他们发现每测一个新基因组就会增加几十个从未见过的基因，总数毫无见顶的迹象。

::: proposition 泛基因组 Heaps 定律 {#prop-heaps}
在许多物种中，$N$个已测基因组中找到的不同基因家族数$P(N)$ 大致按幂律增长，

$$
P(N) \approx \kappa N^\gamma,
$$ {#eq-heaps}

其中$\kappa$ 与$\gamma$ 由数据拟合（Tettelin 及同事，2008，把每新增一个基因组带来的新基因数写作$\propto N^{-\alpha}$，故$\gamma = 1 - \alpha$）。若$0 < \gamma < 1$，泛基因组是**开放的**——每个新基因组都增加新基因，只是增速递减；若$\gamma \le 0$（$\alpha \ge 1$），它是**闭合的**，并趋近一个有限大小。这是一条**经验**规律，借自文本词汇总量增长的分析；其参数取决于基因组的取样方式，以及基因被归并成家族的聚类方式。
:::

::: example 拟合泛基因组 {#ex-heaps}
对某物种10个基因组的基因聚类得9,000个基因家族；再加90个基因组（共100个）后总数升至18,000。(a) 用这两点拟合[[#eq-heaps]]。(b) 泛基因组是开放的吗？(c) 预测1,000个基因组时的家族数，并说明这一预测为何不确定。
::: solution
(a) 取比值，$18{,}000/9{,}000 = (100/10)^\gamma$，故$\gamma = \log_{10}2 = 0.301$，$\kappa = 9{,}000/10^{0.301} = 4{,}500$。

(b) 是：$\gamma > 0$，新基因组会不断带来新家族；第$N$个基因组新增的家族数按$\gamma\kappa N^{\gamma - 1}$ 下降，在$N = 100$ 附近约为每个基因组54个家族。

(c) $P(1000) = 4{,}500\times1000^{0.301} = 36{,}000$。这一外推假设幂律在远离数据之处依然成立，并假设接下来900个基因组的取样与前100个一样；实际上已测基因组偏向临床或实验室菌株，而“同一家族”的聚类阈值也会改变拟合出的$\gamma$。
:::
:::

::: widget plot
f: 4000*x^g; 4000 + 0*x
x: 1, 500
y: 0, 60000
sliders: g=0.35:0:0.8:0.01
labels: \text{泛基因组 } \kappa N^\gamma; \text{一个基因组}
caption: 按 eaps 定律增长的泛基因组$P(N) = \kappa N^\gamma$，取$\kappa = 4{,}000$ 个基因家族（约一个基因组的大小），随已测基因组数$N$ 的变化。$\gamma = 0.35$ 时，500个基因组的泛基因组约有35,000个家族，是单个基因组的九倍。把$\gamma$ 调到0即得闭合泛基因组，其中所有菌株的基因相同；对像 *E. coli* 这样从与其他细菌和噬菌体共享的巨大基因池中获取基因的物种，则把它调到接近0.8。
:::

开放泛基因组是生活在多变环境中、自由交换基因的物种的典型情形，如 *E. coli* 与铜绿假单胞菌（*Pseudomonas aeruginosa*）；闭合泛基因组则见于孤立生境中的特化类群，如专性细胞内寄生的沙眼衣原体（*Chlamydia trachomatis*）。细菌为何携带这么多附属基因尚有争论：有些在特定生态位中具有适应性，有些是损耗宿主以自传的自私元件，还有些可能是中性乘客。

::: intuition 一棵织进了网的树
如果基因在谱系之间移动，微生物还有没有“生命之树”？答案有两个。对任何一个基因而言都存在一棵树，但不同的基因给出不同的树，没有任何单独一棵树能描述一个完整基因组的历史。然而有一组核心基因——负责翻译、转录与复制、与众多伙伴相互作用、只有作为协调的机器才能运转的那组——很少被转移（Ravi Jain、Maria Rivera 与 ames Lake 的“复杂性假说”，1999），用它们构建的树与 rRNA 树大体一致。所以微生物之树最好被想象成一棵承载这些核心基因的细胞谱系之树，一张转移之网织穿其间——在近亲之间与共同环境之中，网结最密。
:::

## 细菌的物种是什么？

生物学物种概念把物种定义为相互交配、与其他群体存在生殖隔离的自然群体（[[evolution/speciation]]）。原核生物无性繁殖，其间的重组只是偶发，且不限于种内，所以这一概念不能直接套用。实践中，物种是按操作性标准界定的：

- **DNA–DNA 杂交**（DDH）：基因组 DNA 复性程度至少达70 %的菌株，长期被视为同一种（Lawrence Wayne 及同事，1987）。
- 两个基因组共有基因的**平均核苷酸一致性**（ANI）如今取代了 DDH：约95–96 %的 ANI 对应70 %的 DDH，对数千个基因组的比较显示，ANI 值的分布在阈值附近出现空档，表明它反映真实的间断（Chirag Jain 及同事，2018）。
- **生态与进化概念** 把物种看作共享同一生态位、由周期性选择或重组维系在一起的菌株簇；Frederick Cohan 的“生态型”（ecotype）指适应性突变在其中发生清扫、荡涤多样性的群体。

名称遵循《国际原核生物命名法规》，该法规要求将模式菌株存入两个菌种保藏中心。由于大多数生物只知基因组，**SeqCode**（Brian Hedlund 及同事，2022）允许以一条基因组序列作为模式来有效发表名称；在此之前，未培养的生物只能获得临时的'*Candidatus*'名称。**基因组分类数据库**（GTDB；Donovan Parks 及同事，2018）依据由120个保守细菌（或53个古菌）蛋白质构建的树建立标准化分类，按相对进化分歧指定等级；其分类导致了近年来的许多名称改动，其版本随基因组的积累而更新（其2024年发布 R220 承认了超过100,000个物种簇，其中大多数没有有效公布的名称）。

::: quiz
两个 *Bacillus* 菌株的 16S rRNA 基因完全相同，但全基因组的平均核苷酸一致性只有85 %。哪项陈述最有依据？
- [ ] 它们是同一种，因为 16S 序列完全相同。
- [x] 它们是不同种；16S 基因变化太慢，不足以把它们分开。
- [ ] 必有一个基因组序列被污染了，因为 ANI 与 16S 总是相符。
- [ ] 它们是同一种，因为 ANI 不度量亲缘关系。
::: solution
85 %的 ANI 远低于约95 %的物种界线，说明基因组整体已明显分歧。16S rRNA 基因是基因组中进化最慢的基因之一，常常分不开同一属内的各个种；16S 序列完全相同，与基因组其他部位已分歧数百万年完全可以并存。
:::
:::

## 来自环境的基因组

不依赖培养的研究始于 16S rRNA 基因（[[microbiology/microbial-world]]）：Norman Pace 及同事自1985年起直接从天然样品中克隆并测序这些基因，Stephen Giovannoni 及同事（1990）在海水里发现了一个序列谱 SAR11，后来证明它是地球上最繁盛的生物类群之一——而它在十二年之后才被培养出来。如今，对成千上万个样品中 16S 基因经 PCR 扩增的片段（常 V4 区）做**扩增子测序**，已是标准的普查方法（[[diversity-of-life/bacteria-archaea]]）。

**鸟枪法宏基因组学**对样品中的全部 DNA 测序。Craig Venter 及同事（2004）测定了马尾藻海 DNA 的序列，找回一百多万个此前未知的基因；Gene Tyson、Jillian Banfield 及同事（2004）则组装出酸性矿山排水生物膜中占优势的少数几种生物的近完整基因组。组装复杂群落更难：来自数千物种的短读段先被组装成片段（**重叠群**），再须归并成基因组（**分箱**）。

::: definition 宏基因组组装基因组 {#def-mag}
**宏基因组组装基因组**（MAG）是从宏基因组组装得到、被推断来自同一种群的一组重叠群，推断依据通常是它们具有相同的序列组成（四核苷酸频率）与**覆盖度**（即测序深度；同一样品中同一个基因组的各部分覆盖度相同，跨样品的变化方式则相同）。MAG 代表的是一群近缘细胞的共识，而不是单个细胞。其质量由一组该谱系每个基因组都应存在的单拷贝标记基因来估计：**完整度**是其中存在的比例，**污染度**是重复标记基因的超出量（例如 CheckM；Parks 及同事，2015）。一份“高质量草图 ”MAG 的完整度须超过90 %、污染度须低于5 %，且含有 rRNA 与 tRNA 基因（Robert Bowers 及同事，2017）。
:::

覆盖度携带关于群落的定量信息。

::: proposition 覆盖度与丰度 {#prop-coverage}
设某宏基因组含$R$条长度为$L$的读段，群落含生物$i$的细胞$a_i$个，每个携带一份大小为$G_i$的基因组拷贝。若读段按 DNA 质量比例抽样，则来自生物$i$的读段数期望为$R\,a_iG_i/\sum_ja_jG_j$，其基因组的期望**覆盖度**为

$$
c_i = \frac{n_iL}{G_i} = \frac{RL\,a_i}{\sum_j a_jG_j}.
$$ {#eq-coverage}

因此覆盖度与细胞数成正比，$c_i/c_j = a_i/a_j$；而读段占比与$a_iG_i$成正比，会高估大基因组生物的丰度。
:::

::: example 数细胞还是数读段？ {#ex-coverage}
一个湖泊样品的三 MAG 的基因组大小与平均覆盖度如下：A，4.0 Mb、30×；B，2.0 Mb、10×；C，1.3 Mb、60×。(a) 以细胞分数计（限于这三者），各生物的相对丰度是多少？(b) 归到它们名下的读段中，各生物分别占多大比例？(c) 若天真地按读段计数，会把谁当作最丰富者？
::: solution
(a) 由[[#prop-coverage]]，细胞数之比为$30 : 10 : 60$，故 A 占细胞的30 %、B 占10 %、C 占60 %。

(b) 读段数（乘以读长）正比于覆盖度×基因组大小：A $30\times4.0 = 120$、B $10\times2.0 = 20$、C $60\times1.3 = 78$（单位为 Mb 序列量）。总和为218，故 A 占读段的55 %、B 占9 %、C 占36 %。

(c) 按读段计数，A 显得最丰富；按细胞计数，C—— 一个经过精简的小基因组贫营养菌——的丰度 A 的两倍。比较丰度之前，必须考虑基因组大小（扩增子调查中还有 16S 拷贝数）。
:::
:::

覆盖度还能度量生长。在增殖细胞群体中，复制起点附近的 DNA 比复制末端的 DNA 丰富$2^{C/\tau}$ 倍（[[microbiology/microbial-growth#prop-cooper]]），因此覆盖度沿基因组的斜率—— **峰谷比**（Tal Korem 及同事，2015）——无需培养即可揭示某个生物在样品中的生长速度。

```python
# 由 MAG 覆盖度求相对丰度，由峰谷比求生长（纯 Python）
import math

mags = {"A": (4.0e6, 30.0), "B": (2.0e6, 10.0), "C": (1.3e6, 60.0)}   # （基因组大小 bp，平均覆盖度）

total_cov = sum(c for g, c in mags.values())
total_seq = sum(g * c for g, c in mags.values())
for name, (g, c) in mags.items():
    print(name, "cells %.0f %%" % (100 * c / total_cov), "reads %.0f %%" % (100 * g * c / total_seq))

ptr = 1.6                     # 起点处覆盖度 / 末端处覆盖度
print("C/tau =", round(math.log2(ptr), 2))   # 0.68：复制时间约为倍增时间的2/3
```

**单细胞基因组学**走的是相反的路：分离单个细胞（用流式细胞术或微流控），将其 DNA 扩增后测序。所得基因组往往不完整，但无疑属于单个细胞。这些方法与宏基因组学结合，揭示出整段的树枝：候选门辐射类群（Patescibacteria）与 DPANN 古菌，细胞与基因组都极小，显得依赖其他生物；阿斯加德古菌，最初从深海沉积物中组装出来（Anja Spang、Thijs Ettema 及同事，2015），后来以'*Candidatus* Prometheoarchaeum syntrophicum' 之名培养成功（Hiroyuki Imachi 及同事，2020）；还有单次研究中数以千计 MAG—— 仅 arks 及同事2017年的调查，就从公共宏基因组中得到约8,000个。Laura Hug 及同事2016年的树（[[diversity-of-life/bacteria-archaea]]）主要就是由这类基因组绘成的。

## 微生物进化的形态

比较微生物基因组时，有几个主题反复出现。

**内共生。**线粒体起源于一种α-变形菌，质体起源于一种蓝细菌；两者都已把大多数基因转移给了宿主细胞核（[[cell-biology/organelles]]）。线粒体与质体的 16S 类 rRNA 落在细菌的 rRNA 之间，这曾是它们起源的决定性证据之一。

**基因组缩减。**寄居在宿主细胞内的细菌会丢掉不再需要的基因。蚜虫共生体布赫纳菌（*Buchnera aphidicola*）的基因组只有约0.64 Mb（Shuji Shigenobu 及同事，2000），木虱共生体'*Candidatus* Carsonella ruddii' 更是只有约0.16 Mb。经母系传递、经历狭窄瓶颈而又没有重组的小群体，会积累轻微有害的突变（穆勒棘轮；[[evolution/mutation-drift-gene-flow]]），其基因组变得富含 AT，蛋白质也更不稳定。自由生活的贫营养菌如 *Pelagibacter ubique*（1.3 Mb）基因组也小，原因却不同——巨大群体中选择造成的**精简**（streamlining），会把成本超过收益的任何 DNA 除去（Stephen Giovannoni 及同事，2005）。

**古老代谢。**生命最早的证据——约37亿年前岩石中同位素偏轻的碳，以及约35亿年前的推定叠层石——既属微生物也仍有争议。以地质事件校准的基因树表明，产甲烷作用、不产氧光合作用与固氮作用都很古老，而产氧光合作用出现于约24亿年前大氧化事件之前（[[diversity-of-life/origin-of-life]]）。依据细菌与古菌之间共享的基因推断 LUCA（最后普遍共同祖先），指向一种利用 H₂ 与 CO₂ 的厌氧生物（William Martin 及同事，2016），不过这一重建在很大程度上取决于如何处置被转移的基因。

::: application 用基因组追踪微生物
本章的方法如今已是日常工具。医院给细菌分离株测序以追踪传播：只差几个单核苷酸变异的菌株很可能属于同一起疫情，而无缘菌株之间相差数百个。公共卫生实验室用全基因组测序把食源性疾病病例与其来源联系起来，用废水宏基因组学监测整座城市的耐药基因。在生态学中，MAG 揭示哪些生物承担氮循环与碳循环的哪一步（[[microbiology/microbial-ecology]]）；在生物技术中，人们从宏基因组中挖掘新酶与抗生素生物合成基因簇（[[biotechnology]]）。
:::

::: history
祖克尔坎德尔与鲍林于1965年提出分子系统发育。乌斯 George Fox 于1977年借 16S rRNA 编目发现了古菌，乌斯的综述《Bacterial evolution》（1987）给出了 rRNA 树。Iwabe 及同事 Gogarten 及同事于1989年用旁系同源基因给树定根；乌斯、Kandler 与 heelis 于1990年为三个域命名。Pace 的课题组自1985年起从环境中给 rRNA 基因测序，Giovannoni 及同事于1990年发 SAR11。第一个细菌基因组——流感嗜血杆菌（*Haemophilus influenzae*）——由 obert Fleischmann、Venter 及同事于1995年测得，1990年代末与2000年代初的基因组比较揭示了水平转移的规模。泛基因组定义于2005年。环境基因组组装始于2004年，借助长读段与更好的分箱，如今一次大型调查就能复原数万个基因组。
:::

::: summary
- SSU rRNA（16S、18S）普遍存在、功能不变、由保守区与可变区镶嵌而成、极少被转移，因此成为揭示三域的分子时钟。
- 观察差异$p$ 须经多重替换校正，最简单的 Jukes–Cantor 距离$d = -\tfrac34\ln(1 - \tfrac43p)$；饱和限制了深部系统发育。生命之树用 LUCA 之前复制的基因定根。
- 经转化、转导、接合与基因转移剂发生的水平基因转移由质粒、转座子、ICE、前噬菌体与整合子承载，受限制-修饰、CRISPR 与同源需求的限制。检测靠分布的不连续、不一致的系统发育、异常组成与侧翼特征。
- 同一物种的菌株在基因含量上可差异巨大：核心基因组加附属基因组，泛基因组大小按$\kappa N^\gamma$ 增长（$\gamma > 0$ 为开放；经验规律）。
- 原核物种按操作性标准划分，如今主要靠基因组比较（ANI 约95–96 %）；98.7 %的 16S 同一性只是下限，不是定义。GTDB 与 eqCode 给基因组（包括未培养的）分类与命名。
- 宏基因组学按组成与覆盖度对重叠群分箱以复 MAG；覆盖度正比于细胞丰度，其沿基因组的斜率揭示生长速率。
- 基因组进化的特点有内共生、基因组缩减（共生体靠漂变，贫营养菌靠精简），以及一份古老代谢的、年代久远而尚无定论的记录。
:::

## 习题

::: exercise 同一性与距离 {level=1 check="0.0571"}
两条 16S 序列在1,400个比对位点中的77个上不同。计 Jukes–Cantor 距离（保留四位小数）。
::: solution
$p = 77/1400 = 0.0550$。$d = -0.75\ln(1 - 4\times0.055/3) = -0.75\ln(0.92667) = -0.75\times(-0.07616) = 0.0571$次替换每位点。
:::
:::

::: exercise 转移的特征 {level=1}
就下列各项观察，说明它是否提示水平转移，以及理由：(a) 在三个土壤细菌属的质粒上发现的一个汞抗性基因；(b) 一棵与 16S 树吻合的核糖体蛋白质基因树；(c) 某65 % G+C 基因组中一 G+C 为35 %的40 kb 区段，两侧有 tRNA 基因并携带一个整合酶基因；(d) 某物种全部200个已测菌株都存在的一个基因。
::: solution
(a) 是：可移动元件（质粒）加上跨属的不连续分布。(b) 否：与生物体树一致正是纵向遗传所预期的。(c) 是：异常组成、典型整合位点与整合酶基因都标志基因组岛。(d) 种内无转移证据——它是核心基因——不过物种的祖先也许曾获得过它。
:::
:::

::: exercise 由覆盖度求丰度 {level=1 check="0.25"}
肠道宏基因组中两种生物的基因组大小为6 Mb 与2 Mb，平均覆盖度为5×与15×。这两种生物的细胞中，第一种占多大比例？
::: solution
细胞正比于覆盖度：$5/(5 + 15) = 0.25$。（它贡献了两者读段的$5\times6/(5\times6 + 15\times2) = 30/60 = 50\,\%$。）
:::
:::

::: exercise 饱和 {level=2}
(a) $p$ 为多少 Jukes–Cantor 距离为每位点1.0次替换？(b) 两个序列的$p = 0.70 \pm 0.02$。计算$p = 0.68$ 与$0.72$ 时的$d$，并评论这对估计域的分歧意味着什么。
::: solution
(a) 由$1 = -0.75\ln(1 - 4p/3)$ 得$1 - 4p/3 = e^{-4/3} = 0.2636$，故$p = 0.75\times0.7364 = 0.552$。(b) $p = 0.68$：$d = -0.75\ln(1 - 0.9067) = -0.75\ln 0.0933 = 1.78$。$p = 0.72$：$d = -0.75\ln(0.04) = 2.41$。$p$ 的6 %不确定度造成$d$ 的35 %不确定度；近饱和时，序列差异几乎不携带谱系于何时分歧的信息，估计主要被模型（位点间速率变异、碱基组成）左右。因此深部分歧要靠进化慢的位点与保守蛋白质、配以周密的模型来估计。
:::
:::

::: exercise 开放的泛基因组 {level=2 check="1.2e4"}
某物种的泛基因组遵循$P(N) = 4{,}500\,N^{0.30}$。估计26个基因组中的基因家族数（两位有效数字）。第26个基因组大约新增多少家族？
::: solution
$P(26) = 4500\times26^{0.30} = 4500\times2.658 = 11{,}960 \approx 1.2\times10^4$。导数$dP/dN = 0.30\times4500\times N^{-0.70} = 1350\times26^{-0.70} = 1350\times0.1022 = 138$，即第26个基因组新增约138个家族（精确差值$P(26) - P(25)$ 约140）。
:::
:::

::: exercise MAG 的质量 {level=2}
土壤宏基因组的一个箱含104个预期单拷贝标记基因中的98个，其中9个存在两份拷贝。(a) 估计完整度与污染度。(b) 它达到“高质量草图”标准了吗？(c) 重复的标记基因可能作何解释？
::: solution
(a) 完整度$98/104 = 94\,\%$；污染度约$9/104 = 8.7\,\%$。(b) 否：污染度超过5 %（而且还需存在 rRNA 与 tRNA 基因）。(c) 可能是近缘种群（菌株异质性）的重叠群，或组成与覆盖度相似的无缘生物的重叠群，被分进了同一个箱；或者该生物确实复制了其中某些基因。利用多个样品间的覆盖度拆箱，或检验重复标记基因的系统发育，可以分辨这些情况。
:::
:::

::: exercise 物种边界 {level=2}
比较三个分离株。A 与 B：16S 同一性99.9 %、ANI 97.5 %。A 与 C：16S 同一性99.2 %、ANI 88 %。B 与 C：16S 同一性99.1 %、ANI 88.3 %。(a) 共有几个种？(b) 用97 %的 TU 方法能看出这一点吗？(c) 若 C 描述为一个新种，什么证据能提供支持？
::: solution
(a) 两个：A 与 B 是同一种（ANI 高于95–96 %），C 是另一种（ANI 近88 %）。(b) 不能：三者的 16S 同一性都高于97 %（也高于98.7 %），会被归进同一 OTU。(c) 对该属已描述物种所有成员的 ANI 一致地低于阈值（以及数 DDH 低于70 %）、在基因组树中占一个独立谱系的位置、表型或生态学差异，以及存入两个菌种保藏中心的模式菌株（按 CNP），或以一份高质量基因组为模式（按 eqCode）。
:::
:::

::: exercise 肠道中的生长 {level=3}
一份粪便宏基因组中，某拟杆菌属（*Bacteroides*）MAG 在复制起点附近的覆盖度为24×，在末端附近为16×。(a) 计算峰谷比与$C/\tau$。(b) 若$C$ 为60分钟，这对应多大的倍增时间？(c) 这一计算做了哪些假设？粪便样品为何可能低估结肠中的生长？
::: solution
(a) PTR $= 24/16 = 1.5$；$C/\tau = \log_2 1.5 = 0.585$。(b) $\tau = 60/0.585 = 103$分钟，约1.7小时。(c) 它假设平衡的指数生长、复制时间$C$ 恒定且不依赖于生长速率、种群是均一的；还假设覆盖度图式不受测序 GC 偏倚或缺失的扭曲。粪便细菌已离开近端结肠中活跃生长的区域；其 DNA 部分来自途中停止复制的细胞，所以粪便 PTR 会低估靠近定殖部位更快的生长速率。无论如何，多数肠道细菌在体内的$C$ 并不已知，因 PTR 多用于条件之间的比较，而不换算成倍增时间。
:::

::: exercise 解读基因树 {level=3}
一棵谷氨酰胺合成酶的树包含40种细菌与20种古菌的序列。大多数细菌序列构成一个进化枝，大多数古菌序列构成另一个，但有三个 *Thermotoga*（细菌）种的序列落在古菌进化枝内部、靠近 *Pyrococcus*，另有两株产甲烷菌的序列落 Bacillota 的一个细菌亚枝内。(a) 给出错置序列的两种解释。(b) 你将如何分辨它们？(c) 这一结果对用这类基因构建物种树意味着什么？
::: solution
(a) 水平转移——由热球菌传给 *Thermotoga* 的祖先，以及由某种细菌传给产甲烷菌——或系统发育假象：长枝吸引、嗜热生物共有的组成偏倚（rRNA 的 G+C、特殊的氨基酸），或隐藏的旁源（比较的是同一个复制基因的不同拷贝）。(b) 检验该位置是否得到强支持，对更优模型和剔除快速位点是否稳健；在基因组中寻找旁源拷贝；检查基因组上下文（该基因是否位于岛内、是否邻近移动元件基因、组成是否异常）；并查看同一区段的其他基因是否呈现同样的格局。(c) 易于转移的基因应从物种系统发育中剔除，或对其降权；物种树应改由许多彼此一致的串联核心基因来构建。
