像 *Escherichia coli*（大肠杆菌）这样一个细菌，是一个直径约一微米、长两个微米的圆柱体，体积大约一飞升。在那个体积里，它装着一个460万碱基对的基因组、数万个核糖体和约三百万个蛋白质分子，并把它们维持在内部渗透压之下——这压力能在瞬间撑破一个没有保护的膜。它靠旋转的螺旋推进器配一台旋转马达来游动，靠随时间比较浓度来朝食物转向，而有些物种能把自己变成一个经得起煮沸的孢子。这些能力无一例外地依赖于与真核细胞不同的结构。

本章由外向内描述细菌与古菌细胞的结构：形态、细胞质膜、细胞壁及其外的各层、用于运动与附着的附属结构、细胞质的内含物，最后是内生孢子。结尾讲古菌细胞如何不同。原核与真核细胞的一般蓝图在 [[cell-biology/cells-and-microscopy]]，膜在 [[cell-biology/membranes]]，两个原核域的被膜概览在 [[diversity-of-life/bacteria-archaea#def-envelope]]；这里深入细节，来解释这些细胞如何工作、抗生素与免疫系统又从何攻击它们。

## 形态与大小

大多数细菌是**球菌**、**杆菌**或**螺旋形细胞**。球菌分裂后可能成对留在一起（双球菌）、成链（链球菌，在一个平面上分裂）或成葡萄状簇（葡萄球菌，在若干平面上分裂）。弯曲的杆菌称弧菌，刚硬的螺旋细胞称螺旋菌，而内部有鞭毛的柔软螺旋细胞称螺旋体。其他形态还有具柄与出芽的细胞（*Caulobacter*、*Hyphomicrobium*）、分支的丝状体（*Streptomyces*），以及极端嗜盐古菌 *Haloquadratum walsbyi* 那种扁平的正方形细胞。

形态不是膨压的被动结果——膨压会让每个细胞都变成球形。形态由指导新壁材料插入位置的蛋白质构建并维持。在杆状细菌中，肌动蛋白同源物 **MreB** 的丝在膜下绕细胞周缘移动，引导把肽聚糖插入侧壁的酶；缺乏 MreB 的细胞变圆。微管蛋白同源物 **FtsZ** 在细胞中部形成一个环，招募分裂机器；而在 *Caulobacter crescentus* 中，一类类似中间纤维的蛋白质 crescentin 产生新月形（Nora Ausmees、Jeffrey Kuhn 与 Christine Jacobs-Wagner，2003年）。细菌细胞骨架在 [[cell-biology/cytoskeleton]] 有进一步描述。

形态为什么要紧？细胞通过表面吸收养分，却在其整个体积里使用它们，所以表面积与体积之比限制了生长速度（[[cell-biology/cells-and-microscopy#prop-sv]]）。拉长的形态还影响游动、附着，以及细胞被原生生物吃掉的难易。

::: example 杆与球 {#ex-rod}
把一个 *E. coli* 细胞建模成半径 $r = 0.5$ µm、两端各封以一个半球、总长2 µm 的圆柱体。计算它的体积、表面积与表面体积比，并与同体积的球体比较。
::: solution
圆柱部分的长度为 $2 - 2r = 1$ µm。体积：$\pi r^2 \times 1 + \tfrac43\pi r^3 = 0.785 + 0.524 = 1.309$ µm³，约1.3 fL。表面积：$2\pi r\times 1 + 4\pi r^2 = 3.142 + 3.142 = 6.283$ µm²。所以 $S/V = 4.80$ µm⁻¹。同体积的球体半径 $(3V/4\pi)^{1/3} = 0.679$ µm，$S/V = 3/0.679 = 4.42$ µm⁻¹。杆状细胞的单位体积表面多约9 %，而且当它以恒定宽度伸长生长时，其 $S/V$ 下降得很慢，趋于无限长圆柱的值 $2/r = 4$ µm⁻¹；而生长中的球体的 $S/V$ 按 $3/r$ 下降。
:::
:::

## 细胞质膜

细胞质膜是一层约8 nm 厚的磷脂双分子层，挤满了蛋白质（蛋白质占其质量一半以上）。细菌膜与真核生物一样，由酯键连到甘油-3-磷酸上的脂肪酸构成，但多数细菌缺乏固醇；许多含有**藿烷**——一类五环分子，被认为在排列与稳定脂双层方面扮演类似的角色。膜是细胞的通透屏障（[[cell-biology/membranes]]）；又因为原核生物没有线粒体与叶绿体，它也是呼吸与光合作用产生**质子动力势**的地方（[[biochemistry/oxidative-phosphorylation#prop-pmf]]），驱动 ATP 合成、物质运输与鞭毛马达。

细菌能在低至纳摩尔的浓度下吸收养分，其转运系统相应地多种多样：

- **次级转运蛋白** 利用既有的离子梯度：如乳糖通透酶 LacY 这样的同向转运体，把溶质的摄入与质子的内移偶联起来（[[cell-biology/membrane-transport#def-transporters]]）。
- **ABC 转运蛋白**水解 ATP。在革兰氏阴性菌中，许多这样的蛋白有一个周质结合蛋白，以高亲和力捕获底物并把它交给膜上的复合体。
- **基团转位** 在底物进入时把它修饰掉。在 **磷酸转移酶系统**（PTS；Werner Kundig、Sudhamoy Ghosh 与 Saul Roseman，1964年）中，一个来自磷酸烯醇式丙酮酸的磷酸基团沿一串蛋白质传递，并在糖类（如葡萄糖）穿膜时接到它身上，于是细胞摄入的是葡萄糖-6-磷酸，再也漏不出去。PTS 还向引起分解代谢物阻遏的调控网络报告葡萄糖的存在（[[molecular-biology/bacterial-gene-regulation#def-cap]]）。

## 细胞壁

### 肽聚糖

几乎所有细菌都被一层**肽聚糖**（murein）壁包围——一个单一的、巨大的、袋状分子，把整个细胞兜在里面 ——Wolfhard Weidel 与 Helmut Pelzer（1964年）称之为"袋状大分子"。

::: definition 肽聚糖 {#def-peptidoglycan}
**肽聚糖**是一类聚合物：交替的 *N*-乙酰氨基葡萄糖（NAG）与 *N*-乙酰胞壁酸（NAM）构成的聚糖链以β-1,4糖苷键相连，每个 NAM 的乳酸基上挂着一个短肽。在 *E. coli* 中，该肽是 L- 丙氨酸 –D- 谷氨酸–*meso*-二氨基庚二酸 –D- 丙氨酸（成熟壁中为四肽）；在 *Staphylococcus aureus* 与许多其他革兰氏阳性菌中，L- 赖氨酸取代二氨基庚二酸。相邻链上的肽被**交联**，通常从一条肽第4位的 D- 丙氨酸连到另一条肽第3位的二氨基氨基酸，或直接相连（*E. coli*），或经一个氨基酸桥相连（*S. aureus* 中的五个甘氨酸）。D- 氨基酸与二氨基庚二酸在自然界几乎别处不见。
:::

交联使壁成为一张向各个方向抗拉伸的共价网。它的合成横贯膜进行。在细胞质中，NAM 先接在脂质载体十一异戊烯基（细菌萜醇）磷酸上，加上五肽（以 D-Ala–D-Ala 结尾），再加上 NAG，形成**脂质 II**。翻转酶把脂质 II 移到膜外，**糖基转移酶**把它的二糖加到生长中的聚糖链上，**转肽酶**形成交联：转肽酶切开五肽末端的 D- 丙氨酸，把倒数第二个 D- 丙氨酸接到相邻肽的氨基上。因为成新肽键的能量就来自被切开的那个键，交联可以在细胞外没有 ATP 的情况下发生。

许多抗生素作用于这条通路（[[microbiology/antimicrobials]]）。β-内酰胺类如青霉素模拟肽的 D-Ala–D-Ala 末端，把转肽酶活性位点的丝氨酸酰化——这些转肽酶因此被称为**青霉素结合蛋白**（PBP）。万古霉素直接结合 D-Ala–D-Ala 末端，把两个反应都挡住。肽聚糖也受宿主攻击：存在于泪液、唾液与蛋清中的**溶菌酶**，水解 NAM 与 NAG 之间的β-1,4键。

### 顶住压力

细菌的细胞质远比它栖居的大多数环境浓，所以水倾向于流入。壁抵抗由此产生的**膨压**。两条物理学告诉我们这压力有多大、给壁加了多大的应力。

::: proposition 渗透压与壁应力 {#prop-turgor}
(a) 对稀溶液，可透水而不可透溶质的膜两侧的渗透压差由 van 't Hoff 定律给出，

$$
\Delta\Pi = \Delta c\,RT,
$$ {#eq-vanthoff}

其中 $\Delta c$ 是渗透活性粒子总浓度之差（渗透浓度，以 mol m⁻³ 计），$R = 8.314$ J mol⁻¹ K⁻¹，$T$ 为绝对温度。平衡时膨压 $P$ 等于 $\Delta\Pi$。

(b) 一个半径 $r$、壁厚 $t \ll r$ 的薄壁圆柱，内有超出压强 $P$，则承受周向（环向）应力与轴向应力

$$
\sigma_\theta = \frac{Pr}{t}, \qquad \sigma_z = \frac{Pr}{2t};
$$ {#eq-laplace}

球体则在各个方向承受 $\sigma = Pr/(2t)$。这些就是薄壳力学的拉普拉斯关系。
:::

::: proof
(b) 沿过轴的平面劈开一个长 $L$ 的圆柱。压力以等于 $P$ 乘以投影面积的力把两半推开，即 $P\times 2rL$；壁在总面积 $2tL$ 的两个切口边缘上抵抗它，所以 $\sigma_\theta\cdot 2tL = 2rLP$，得 $\sigma_\theta = Pr/t$。改沿垂直于轴的方向切开，端面受力为 $P\pi r^2$，抵抗它的壁面积为 $2\pi rt$，所以 $\sigma_z = Pr/(2t)$。对球体而言，过球心的每个平面都像第二次切。（(a) 由令两侧水的化学势相等得出；推导见[化学图集](/learn/chemistry/)。）
:::

::: example 壁要多结实？ {#ex-turgor}
设一种杆状细菌的细胞质在37 °C 下比其培养基浓0.1 osmol L⁻¹。(a) 膨压是多少，以帕与大气压计？(b) 若细胞半径0.5 µm、承力层像革兰氏阴性细胞那样厚4 nm，肽聚糖承受多大的环向应力？(c) 若像革兰氏阳性细胞那样厚30 nm 呢？
::: solution
(a) $\Delta c = 0.1$ osmol L⁻¹ $= 100$ mol m⁻³。$P = 100\times8.314\times310 = 2.58\times10^{5}$ Pa，约2.5 atm（1 atm = $1.013\times10^5$ Pa）。

(b) $\sigma_\theta = Pr/t = 2.58\times10^5\times0.5\times10^{-6}/(4\times10^{-9}) = 3.2\times10^{7}$ Pa，约32 MPa。

(c) $t = 30$ nm 时，$\sigma_\theta = 4.3$ MPa。

革兰氏阴性菌那层薄壁承受的应力与一根拉紧的橡皮筋相当，这就是革兰氏阴性菌忍受不了革兰氏阳性菌那样高膨压的原因。测得的膨压随方法与条件而异：对 *E. coli* 的估计从约0.3 atm（原子力显微镜；Yi Deng、Mingzhai Sun 与 Joshua Shaevitz，2011年）到几个大气压不等，而革兰氏阳性菌的经典估计要高一个数量级。
:::
:::

这压力也解释了为什么损伤壁的抗生素与酶能杀死生长中的细胞。若用溶菌酶在渗透浓度与细胞质相同的培养基（例如0.5 mol L⁻¹ 蔗糖）中除掉细胞壁，细胞会以球形的**原生质体**（革兰氏阳性）或**球形体**（革兰氏阴性，保留外膜）存活；到了稀培养基里，它们会涨破（**渗透裂解**）。细菌也感知并调节膨压：在含盐环境中它们吸收 K⁺ 并积累甘氨酸甜菜碱、脯氨酸、海藻糖之类的"相容性溶质"；被突然稀释时，则打开**机械敏感通道**（MscL、MscS）释放溶质。

### 革兰氏阳性与革兰氏阴性被膜

革兰氏染色（[[diversity-of-life/bacteria-archaea]]）按被膜构造把大多数细菌分开。

::: definition 革兰氏阳性与革兰氏阴性被膜 {#def-gram}
**革兰氏阳性**被膜有细胞质膜与一层厚而多层的肽聚糖壁（约20–80 nm），其间穿插**磷壁酸**——甘油磷酸或核糖醇磷酸的聚合物，或接在 NAM 上（壁磷壁酸），或以脂质锚在膜上（脂磷壁酸）。它们给壁强负电荷并结合阳离子。**革兰氏阴性**被膜的肽聚糖层很薄、只有几纳米厚，位于**周质空间**——细胞质膜与**外膜**之间的水相区室。外膜的内小叶是磷脂，外小叶是**脂多糖**（LPS）；它由 Braun 脂蛋白锚定在肽聚糖上，后者是 *E. coli* 中最丰富的蛋白质之一。
:::

LPS 有三个部分：**脂质 A**，一个连着约六个脂肪酸的葡糖胺二糖，把它锚在膜上；**核心寡糖**；以及 **O 抗原**，一条长而高度可变的重复糖单位链。脂质 A 就是细菌被裂解时在动物体内触发强烈先天免疫应答的"内毒素"；可变的 O 抗原则是区分 *E. coli* O157 之类菌株所用血清型的基础。二价阳离子把带负电的 LPS 分子桥接起来，而 EDTA 螯合这些阳离子会让外膜渗漏。

外膜是第二道通透屏障。小于约600道尔顿的亲水小分子，经**孔蛋白**（*E. coli* 的 OmpF 与 OmpC）形成的充水通道穿过去；更大的分子，如维生素 B₁₂ 与铁-铁载体复合物，则需要专门的外膜转运蛋白，其能量经 TonB 蛋白从细胞质膜供给。周质空间里有转运用的结合蛋白、降解养分与解毒抗生素的酶（β-内酰胺酶），以及把被膜蛋白折叠并输出的机器。外膜是许多能杀死革兰氏阳性菌的抗生素（如万古霉素）对革兰氏阴性菌无效的原因：它们到不了靶标。

还有两类被膜值得一提。**分枝杆菌**（及 Actinomycetota 中的近亲）的肽聚糖层与阿拉伯半乳聚糖相连，后者又带着**分枝菌酸**——极长（C₆₀–C₉₀）的分支脂肪酸，形成一层蜡样、类膜的表层（分枝膜）。这套被膜极不透水不透药，助成了 *Mycobacterium tuberculosis* 生长缓慢、对许多药物与消毒剂有抗性；分枝杆菌革兰氏着色不良，靠**抗酸染色**鉴定——即使用酸化的酒精洗脱，它们仍保留染料。**支原体**完全没有壁；它们小、形态多变、渗透脆弱，通常生活在渗透压受保护的宿主环境中，并对β-内酰胺类天然耐药。

## 壁外结构

许多原核生物在壁外分泌一些层次。**荚膜**是界限清楚、牢固附着的一层，通常是多糖（但 *B. anthracis* 的是聚 -D- 谷氨酸）；**黏液层**则松散得多。荚膜保持水分、防止干燥，帮助细胞黏到表面；在病原体中，它们帮助细胞逃避免噬——格里菲斯（Frederick Griffith）1928年的实验——有荚膜、有致病力的肺炎链球菌转化了无荚膜的菌株——靠的正是这一属性（[[genetics/microbial-genetics]]）。在附着于表面的群落里，细胞被包在多糖、蛋白质与 DNA 构成的**胞外聚合物**（EPS）中，它形成**生物膜**的基质（[[microbiology/microbial-ecology]]）。

**S-layer（表层）** 是单一蛋白质或糖蛋白排成的二维晶体阵列，像一领瓷砖的斗篷罩住细胞，其孔洞有几纳米宽。它们见于许多细菌与几乎所有古菌——在后者中它们往往就是唯一的壁。

## 附属结构：鞭毛、菌毛与运动

### 细菌鞭毛

许多细菌会游动。**鞭毛**是一根螺旋状丝，粗20 nm、可长达10–15 µm，由成千上万份鞭毛蛋白拷贝拼成，经一段柔韧的**钩形鞘**连到嵌在被膜里的**基体**。它不像真核鞭毛那样摆动；它旋转。

::: definition 鞭毛马达 {#def-motor}
**鞭毛马达**是细胞质膜里的一台旋转机器。**转子**（MS 环连同其细胞质面上的 C 环，即开关复合体）在多达约十二个**定子**单位（*E. coli* 的 MotA₅MotB₂）排成的环内转动；每个定子是一条质子通道，质子顺质子动力势流过，流动驱动旋转。革兰氏阴性菌的杆穿过肽聚糖与外膜时经过轴套，即 P 环与 L 环。有些细菌，如 *Vibrio* 属，其端生鞭毛用 Na⁺ 代替 H⁺。旋转可为逆时针（CCW）或顺时针（CW）——从细胞外看——方向由一个信号蛋白结合到 C 环上切换。
:::

鞭毛会旋转，由 Howard Berg 与 Robert Anderson（1973年）从结构上指出，并由 Michael Silverman 与 Melvin Simon（1974年）直接证实：他们用一根鞭毛把 *E. coli* 细胞拴在载玻片上，看着菌体旋转。*E. coli* 的马达在低负载下转速高达约每秒300转，每转约有一千个质子穿过；*Vibrio* 的 Na⁺ 驱动马达测得远超每秒1,000转。鞭毛自基部向外装配：其亚基经一条中央通道输出，靠一套专门的分泌系统，它与某些病原体用来向宿主细胞注射蛋白质的注射器（III 型分泌系统）同源（[[microbiology/microbes-and-hosts]]）。

鞭毛的排布各有定式：单端一根（**单生毛**，如 *Vibrio cholerae*）、一端或两端一丛（**丛毛**），或许多根散布周表（**周生毛**，如 *E. coli*）。螺旋体的鞭毛位于周质空间，其转动使整个菌体像开瓶器一样蠕动或旋转，这使它们能在黏液之类的黏稠介质中穿行。

### 低雷诺数下的生活

在细菌的尺度上游动，与我们经验中的任何事都不同。惯性力与黏性力之比由**雷诺数**度量

$$
\mathrm{Re} = \frac{\rho v L}{\eta},
$$

其中 $\rho$ 是流体密度，$v$ 是速度，$L$ 是泳动者的大小，$\eta$ 是黏度。人游泳时 Re 约 $10^6$；细菌只有 $10^{-5}$–$10^{-4}$。惯性可以忽略。Edward Purcell 在一篇著名的讲演（1977年）中指出：细菌若关掉马达，滑行还不足一个原子的直径；而往复运动——扇贝开合贝壳那种——在低 Re 下根本产生不了任何净位移。旋转的螺旋不是往复的，这就是它能奏效的原因。

::: example 游动的数字 {#ex-reynolds}
*E. coli* 以约30 µm s⁻¹ 游动，体长约2 µm。(a) 计算它在水中的雷诺数（$\rho = 1000$ kg m⁻³，$\eta = 10^{-3}$ Pa s）。(b) 一个小的养分分子的扩散系数 $D = 10^{-9}$ m² s⁻¹（1000 µm² s⁻¹）。沿直线游动的细菌，在多大的距离尺度上比该分子经扩散铺展得更快？用一维扩散时间 $t \approx x^2/2D$。(c) 走完1 mm，两者各需多久？
::: solution
(a) $\mathrm{Re} = 1000\times30\times10^{-6}\times2\times10^{-6}/10^{-3} = 6\times10^{-5}$。

(b) 游动时间 $x/v$ 与扩散时间 $x^2/2D$ 相等，当 $x = 2D/v = 2\times1000/30 = 67$ µm。比这更短的距离上扩散更快：细菌游不过它近邻处的分子，所以游动并不能靠搅动增加其表面养分的供应。

(c) 扩散：$(10^{-3})^2/(2\times10^{-9}) = 500$ s。游动：$10^{-3}/(30\times10^{-6}) = 33$ s。长距离上游动轻松取胜，所以运动能力的价值在于移动到食物更富集的*地方*——而这要求细胞知道那些地方在哪里。
:::
:::

### 趋化性：一种偏向的随机游走

游动的 *E. coli* 无法沿自己2 µm 的躯体测出浓度梯度——那点差别会淹没在噪声里。于是它改为随时间比较浓度。Howard Berg 与 Douglas Brown（1972年）用跟踪显微镜追踪单个细胞，证明 *E. coli* 在**奔跑**（run，约一秒，鞭毛逆时针转动聚成一束把细胞往前推）与**翻滚**（tumble，约十分之一秒，一个或多个马达切换到顺时针、束散架、细胞随机换向，平均偏转约68°）之间交替。当细胞碰巧朝吸引物梯度上坡游去时，翻滚被抑制、奔跑延长；下坡时奔跑则不延长。结果是一个偏向吸引物的随机游走。

这条信号通路是生物学中了解得最透的通路之一。跨膜的 **趋化受体**（甲基接受趋化蛋白，MCP）成簇聚在细胞一极，经衔接蛋白 CheW 控制组氨酸激酶 **CheA**。吸引物结合后，CheA 活性下降。CheA 磷酸化应答调节器 **CheY**；CheY-P 结合马达上的开关蛋白 FliM，促进顺时针转动，也就是翻滚。**CheZ** 使 CheY-P 去磷酸化，让信号保持短促。于是：吸引物 → CheA 活性降低 → CheY-P 减少 → 翻滚减少 → 奔跑变长。**适应性调节**——使时间比较成为可能的"记忆"——来自受体的 **CheR** 甲基化与 **CheB** 去甲基化（CheB 本身被 CheA 激活）：几秒之内，甲基化把受体活性重置到新浓度下的基线，所以细胞响应的是变化、而非绝对水平，其响应范围横跨约五个数量级的浓度。这是一个双组分系统（[[molecular-biology/bacterial-gene-regulation]]）作用在马达上，而不是作用在启动子上。

::: intuition 为什么要随时间比较？
一秒的奔跑行经约20–30 µm，十个以上体长，所以把"现在"的浓度与"一秒前"的比较，相当于比较这么远的两点——基线远大于细胞本身。细胞的记忆是化学的：受体的甲基化水平记录着过去几秒的平均浓度，受体的即时占据记录着当前。两者之差驱动马达。
:::

::: example 空间还是时间？ {#ex-gradient}
设吸引物浓度为1 µmol L⁻¹，并以每毫米10 %的比率上升。(a) 一个2 µm 长的细胞两端之间、以及一次25 µm 奔跑的起点与终点之间，浓度的相对差各是多少？(b) Howard Berg 与 Edward Purcell（1977年）证明，一个大小为 $a$ 的细胞计数 $T$ 时长内的分子，能以大约 $1/\sqrt{Dac T}$ 的相对精度测量浓度 $c$，至多差一个一阶因子。用 $D = 1000$ µm² s⁻¹、$a = 1$ µm、$T = 1$ s 估算它（1 µmol L⁻¹ 约合每 µm³ 600个分子）。哪一种比较是细胞靠得住能做的？
::: solution
(a) 相对梯度为每毫米 $0.1$，即每 µm $= 10^{-4}$。跨体：$2\times10^{-4}$，即0.02 %。一次奔跑：$25\times10^{-4} = 0.25\,\%$。

(b) $Dac T = 1000\times1\times600\times1 = 6\times10^5$，故精度约为 $1/\sqrt{6\times10^5} = 1.3\times10^{-3}$，即0.13 %。跨体0.02 %的差埋没在这种噪声里；一次奔跑0.25 %的差约为噪声的两倍，是能被检出的，若再对几秒作平均则更容易。沿奔跑作时间比较并不是 *E. coli* 的怪癖，而是对任何这么小的细胞来说物理学的必然。
:::
:::

### 菌毛与其他运动方式

**菌毛**（单数 pilus；又称 fimbriae）是纤细的蛋白质丝，通常比鞭毛更短、更多。许多菌毛的尖端带**黏附素**，结合宿主细胞或表面上的特异分子。**接合菌毛**在接合期间连接供体与受体细胞（[[genetics/microbial-genetics#def-f-factor]]）。**IV 型菌毛**可由 ATP 驱动的马达伸出与回缩；伸出—附着—回缩的反复循环把细胞一顿一顿地拉过表面，即**抽搐运动**（*Pseudomonas aeruginosa*、*Neisseria*）；IV 型菌毛也在自然转化中摄取 DNA。另一些细菌不用鞭毛也不用菌毛，靠被膜里的马达在表面上平滑滑行（*Myxococcus*、*Flavobacterium*）。

## 细胞内部

细菌的细胞质极其拥挤，大分子浓度达300–400 mg mL⁻¹。其主要成分是：

- **类核。** 染色体——4.6 Mb 的 DNA，在 *E. coli* 中是一条1.5 mm 长的环——经超螺旋与类核相关蛋白（如 HU、H-NS 与 Fis）压缩约一千倍，凝成一个无膜的不规则区域。许多细菌还携带 **质粒**：独立复制的小型环状（有时线状）DNA 分子，常带有抗生素耐药、毒素或特殊代谢的基因（[[microbiology/microbial-diversity]]）。有些细菌有线状染色体（*Borrelia*、*Streptomyces*）或多个染色体（*Vibrio cholerae* 有两个）。
- **核糖体。** 原核 70S 核糖体（30S 与 50S 亚基，含 16S、23S 与 5S rRNA）与真核 80S 核糖体差异足够大，可成为链霉素、四环素、红霉素之类抗生素的选择性靶标（[[molecular-biology/translation]]）。一个快速生长的 *E. coli* 细胞可含数万个核糖体。
- **包涵体。** **聚-β-羟基丁酸酯**（PHB）与其他聚羟基烷酸酯的颗粒贮存碳，是可生物降解生物塑料的基础；糖原贮存葡萄糖；**聚磷酸盐**（异染颗粒）贮存磷酸盐与能量；硫滴由 *Beggiatoa* 之类的硫化物氧化菌贮存。
- **气泡** 是中空的蛋白质圆柱，透气不透水，给水中蓝细菌与嗜盐古菌提供浮力，让它们调节自己在水层中的深度。
- **磁小体** 是磁铁矿（Fe₃O₄）或胶体硫铁矿（Fe₃S₄）的膜被晶体，成串排列，使 **趋磁细菌** 表现得像指南针的磁针（Richard Blakemore，1975年）。地磁场是倾斜的，沿场线游动就把它们带上或带下，前往它们生长得最好的低氧带。
- **细菌微区室**，多面体的蛋白质外壳，把酶围在其中。**羧酶体** 存在于蓝细菌与许多化能无机自养菌中，把 CO₂ 浓缩到 RuBisCO 周围，提高固碳效率。

原核细胞不是一袋酶。许多蛋白质定位在特定位置——趋化受体与某些分裂蛋白在一极，FtsZ 在中部——有些细菌还有精巧的内膜系统：蓝细菌的类囊体、硝化菌与甲烷氧化菌的膜堆，以及厌氧氨氧化菌在其中进行反应的区室。

## 内生孢子

养分耗尽时，*Bacillus*、*Clostridium* 及 Bacillota 中一些相关成员会形成**内生孢子**（芽孢）——在母细胞内建造起来的休眠细胞。内生孢子是已知最抗逆的生命结构。它们能在沸水中存活数小时，能耐受干燥、紫外与电离辐射、以及许多消毒剂，并可保持活力几十年乃至几百年。（关于在琥珀或盐晶中封存数千万至数亿年后复苏的报道仍有争议，因为污染极难排除。）

::: definition 内生孢子 {#def-endospore}
**内生孢子**是由营养细胞内经不对称分裂在其内部形成的休眠、非繁殖的细胞。从内向外依次为**核心**，含染色体、核糖体与酶，处于部分脱水状态并含大量**吡啶二羧酸钙**（约占孢子干重的10 %）；内膜；由疏松交联的肽聚糖构成的**皮层**；多层蛋白**衣壳**；有些物种还有一层外**外壁**。小分子酸可溶蛋白（SASP）结合并保护 DNA。条件适宜时孢子**萌发**，长出为一个营养细胞。
:::

*B. subtilis* 的产孢是一个发育程序的经典例子。细胞先在一极附近而非中部分裂，产生一个小的**前孢子**与一个大的**母细胞**；随后母细胞把前孢子**吞入**，使它被两层膜包围、躺在母细胞的细胞质里。两个区室表达不同的基因，受 RNA 聚合酶一组交替σ 因子的级联控制：每个σ 因子依次被另一个区室的信号激活——先是前孢子中的σ^F^，再是母细胞中的σ^E^，然后是前孢子中的σ^G^ 与母细胞中的σ^K^（以 Richard Losick 等为主的工作，始于1970年代）。母细胞建造皮层与衣壳，前孢子核心脱水并摄入吡啶二羧酸盐，最后母细胞裂解，释出成熟的孢子。整个过程约需八小时。

孢子的抗性有多个来源：核心含水量低，使蛋白质失去活动能力、免于热变性；SASP 改变 DNA 的构象，使紫外造成较不致命的损伤；衣壳把酶与许多化学品挡在外面；而萌发期间的 DNA 修复会修掉休眠中积累的损伤。内生孢子就是热灭菌必须用121 °C 加压蒸汽的原因（[[microbiology/antimicrobials]]），也是罐头食品要操心产孢细菌的原因。

::: warning 内生孢子不是繁殖
一个产孢的细菌只产一个孢子，一个孢子只萌发成一个细胞：数目没有增加。内生孢子是求生的策略，不是增殖的策略——不像真菌与 *Streptomyces* 的孢子，后者大量产生、散布生物体。另请注意"产孢"与"革兰氏阳性"不是一回事：多数革兰氏阳性菌（葡萄球菌、链球菌、乳酸菌）并不形成内生孢子。
:::

## 古菌细胞的不同

古菌在光学显微镜下看起来像细菌，且共享原核蓝图：无核，多数物种一个环状染色体，转录与翻译偶联，70S 核糖体。但在分子细节上，它们的被膜与附属结构是不同的，而它们处理信息的机器与真核生物相像。

| 特征 | 细菌 | 古菌 |
|---|---|---|
| 膜脂 | 脂肪酸经酯键连甘油-3-磷酸；双分子层 | 异戊二烯链经醚键连甘油-1-磷酸；二醚的双分子层，或单次跨膜四醚的单分子层 |
| 壁 | 肽聚糖（支原体与少数例外除外） | 从无肽聚糖；通常是 S-layer；一些产甲烷菌有假肽聚糖；也有其他多糖壁 |
| 运动 | 鞭毛，靠离子流驱动旋转 | 古菌鞭毛，靠 ATP 水解驱动旋转，与 IV 型菌毛同源 |
| 细胞分裂 | 几乎全为 FtsZ 型 | 许多用 FtsZ；*Sulfolobus* 与其近亲用与 ESCRT-III 相关的 Cdv 蛋白 |
| DNA 包装 | 类核相关蛋白 | 许多支系有组蛋白，或其他小的 DNA 结合蛋白 |
| 转录 | 一种 RNA 聚合酶，亚基少，用σ 因子 | 一种 RNA 聚合酶，亚基多，配 TATA 结合蛋白与 TFB，似真核 RNA 聚合酶 II |
| 对抗生素的敏感性 | 许多药靶向壁与核糖体 | 对β-内酰胺类与许多核糖体靶向药有抗性 |

**假肽聚糖**见于 *Methanobacterium* 与 *Methanothermobacter* 之类产甲烷菌，表面像肽聚糖，实由 NAG 与 *N*-乙酰塔糖胺醛酸以β-1,3（而非β-1,4）键相连，肽里是 L- 而非 D- 氨基酸；因此它对溶菌酶与青霉素免疫，并独立演化而来。许多嗜热嗜酸古菌的单次跨膜四醚脂形成单分子层，无法剥离成两片小叶，醚键又抗水解；合起来使膜在高温低 pH 下既稳定又对质子不通透。*Sulfolobus* 的分裂机器建立在真核 ESCRT-III 蛋白（执行膜的掐断）的同源物上（Ann-Christin Lindås 及同事，与 Rachel Samson 及同事，同为2008年），是把古菌与真核生物联系起来的特征之一（[[diversity-of-life/classifying-life#prop-two-domains]]）。

::: application 被膜上的靶标
细菌被膜是比任何其他结构被更多抗生素瞄准的靶：β-内酰胺类与糖肽类作用于肽聚糖合成，多黏菌素作用于外膜，达托霉素作用于革兰氏阳性菌的膜（[[microbiology/antimicrobials]]）。它也是先天免疫系统最先识别的东西：动物与植物中的受体检测 LPS、肽聚糖片段、脂蛋白与鞭毛蛋白——这些对细菌必需、而宿主没有的分子。被膜的差异解释了抗生素的"谱"（青霉素 G 对革兰氏阳性菌，多黏菌素对革兰氏阴性菌），以及分枝杆菌因分枝菌酸层而必须有自己专属药物的道理。几种细菌的疫苗是用荚膜多糖与蛋白质偶联制成的。临床的一面见[医学图谱：微生物学](/learn/medicine/lesson.php?c=microbiology&l=bacteria)。
:::

::: history
Ferdinand Cohn 描述了细菌的形态（1872年）与内生孢子（1876年），Hans Christian Gram 于1884年引入了他的染色法。壁的化学在1950—1960年代被阐明：Milton Salton 证明壁可以被分离与分析，James Park 发现肽聚糖的核苷酸前体在青霉素处理过的葡萄球菌中积累（1949–1952年），Jack Strominger 与 Donald Tipper 于1965年提出青霉素模拟 D-Ala–D-Ala 并阻断转肽作用。Weidel 与 Pelzer 于1964年把壁描述为一个单一的袋状分子。Berg 与 Anderson（1973年）、Silverman 与 Simon（1974年）证明鞭毛会旋转；Berg 与 Brown（1972年）描述了趋化性的奔跑-翻滚行为。Blakemore 于1975年发现趋磁细菌。2000年代以来的电子低温断层扫描，已在完整的细胞内以近天然状态看清了被膜与马达。
:::

::: summary
- 细菌大多为球菌、杆菌与螺旋形；形态由指挥壁合成的细胞骨架蛋白（MreB、FtsZ、crescentin）维持。
- 细胞质膜是通透屏障与能量保存的场所；运输使用离子梯度、ATP（ABC 转运蛋白）或基团转位（PTS）。
- 肽聚糖是一张单一的交联网，由 NAG–NAM 链与含 D- 氨基酸的肽构成，经脂质 II 由糖基转移酶与转肽酶合成（β-内酰胺类靶向的 PBP）。它抵抗膨压：$P = \Delta c RT$，环向应力 $\sigma_\theta = Pr/t$。
- 革兰氏阳性被膜有穿插磷壁酸的厚肽聚糖；革兰氏阴性被膜的薄肽聚糖位于周质空间，外覆含孔蛋白的 LPS 外膜。分枝杆菌有分枝菌酸；支原体无壁。
- 壁外有荚膜、黏液层与 S-layer。鞭毛是由 H⁺ 或 Na⁺ 驱动的旋转马达；趋化性经受体、CheA、CheY 与甲基化适应，把奔跑-翻滚的随机游走加以偏向。细菌游动的雷诺数约 $10^{-4}$。
- 菌毛负责附着、接合与抽搐运动。细胞质内含类核、质粒、70S 核糖体、贮存颗粒、气泡、磁小体与微区室。
- 内生孢子是休眠、极其抗逆的细胞，核心脱水且富吡啶二羧酸钙，由σ 因子级联形成；它们求的是生存，不是繁殖。
- 古菌有醚键连到甘油-1-磷酸上的异戊二烯脂，无肽聚糖，马达是 ATP 驱动的古菌鞭毛，信息处理机器似真核生物。
:::

## 习题

::: exercise 排布方式 {level=1}
从 (a) 成链的球菌、(b) 葡萄状簇的球菌、(c) 立方体状八个一包的球菌，你能对细胞分裂面推断出什么？
::: solution
(a) 分裂总在相互平行的平面上进行、细胞彼此相连（链球菌）。(b) 分裂沿若干随机平面（葡萄球菌）。(c) 分裂依次沿三个两两垂直的平面（如 *Sarcina*）。
:::
:::

::: exercise 渗透压 {level=1 check="3.87"}
某细菌的细胞质在37 °C 下比培养基的渗透浓度高0.15 osmol L⁻¹（取 $T = 310$ K）。膨压是多少，以 $10^5$ Pa 为单位？（保留两位小数。）
::: solution
$\Delta c = 150$ mol m⁻³，所以 $P = 150\times8.314\times310 = 3.87\times10^5$ Pa，约3.8 atm。
:::
:::

::: exercise 原生质体与球形体 {level=1}
预测下列各例先用0.5 mol L⁻¹ 蔗糖中的溶菌酶处理、再稀释到水中会发生什么：(a) *Bacillus subtilis*；(b) 经 EDTA 预处理的 *E. coli*；(c) *Mycoplasma*；(d) *Methanothermobacter*。
::: solution
(a) 在蔗糖中成为球形原生质体，稀释后胀破。(b) 在蔗糖中成为球形体（仍带部分外膜），稀释后胀破。(c) 溶菌酶无效，因为没有壁；但支原体本就渗透脆弱，稀释入水仍可能裂解。(d) 无效：假肽聚糖是β-1,3键，溶菌酶切不动，所以细胞在稀释后存活。
:::
:::

::: exercise 趋化性突变体 {level=2}
预测缺失下列各组分的 *E. coli* 突变体的游动行为（平滑游动、正常奔跑-翻滚、或持续翻滚）与趋化应答：(a) CheY，(b) CheZ，(c) CheR，(d) CheB。各用 CheY-P 水平来解释。
::: solution
(a) 没有 CheY-P：马达恒为逆时针，细胞平滑游动、从不翻滚；无趋化性。(b) CheY-P 不被去磷酸化而积累：马达大量时间处于顺时针，细胞不停翻滚；无趋化性。(c) 无甲基转移酶，受体停留在低甲基化状态——此状态 CheA 活性低：CheY-P 少，平滑游动，且无法适应。(d) 无甲基酯酶，受体过度甲基化——此状态 CheA 活性高：CheY-P 多，行为好翻滚，同样没有正常的适应。(c) 与 (d) 中，细胞能对突变作出响应，却不能重置，所以不能高效地爬上梯度。
:::
:::

::: exercise 球与杆的壁应力 {level=2 check="2"}
一个球菌与一个杆菌的半径、壁厚、膨压相同。杆菌的最大壁应力是球菌的最大壁应力的多少倍？在杆菌的哪个部位、沿什么方向，你预计壁最先破裂？
::: solution
球体各方向都是 $\sigma = Pr/(2t)$；杆的圆柱部分是 $\sigma_\theta = Pr/t$，大一倍。杆的侧壁应先破，沿轴方向撕裂开（环向应力会豁开一条纵向的口子）。这种各向异性许可解释为什么杆状细菌把聚糖链大致沿周向排布，以承当较大的应力。
:::
:::

::: exercise 马达的质子账 {level=2 check="1.2e5"}
若鞭毛马达每转约有1,200个质子穿过、转速为每秒100转，该马达每秒消耗多少质子？若质子动力势为150 mV，该马达耗散的功率是多少（瓦）？（每个质子穿膜释放能量 $e\,\Delta p$，$e = 1.6\times10^{-19}$ C。）
::: solution
$1200\times100 = 1.2\times10^{5}$ 质子每秒每马达。功率：$1.2\times10^5\times1.6\times10^{-19}\times0.15 = 2.9\times10^{-15}$ W，约3飞瓦。长多根鞭毛的细胞把能量预算中可观（虽小却真）的一块花在游动上，此外还有先建造鞭毛的更大开销；在营养丰富、混合良好的培养基中，细胞常下调鞭毛合成，鞭毛基因受到严格的调控。
:::
:::

::: exercise 一种偏向的随机游走 {level=2}
速度为 $v$、平均时长为 $\tau$ 的奔跑后方向完全随机化的随机游走，三维中的有效扩散系数为 $D_\mathrm{eff} = v^2\tau/3$。(a) 计算 $v = 20$ µm s⁻¹、$\tau = 1$ s 时的 $D_\mathrm{eff}$，与小分子（1000 µm² s⁻¹）和蛋白质（水中约100 µm² s⁻¹）的 $D$ 比较。(b) *E. coli* 的翻滚并不完全随机化方向：转向角余弦的平均值约0.33。公式变为 $D_\mathrm{eff} = v^2\tau/[3(1 - \alpha)]$，$\alpha$ 为余弦均值。重算一遍。(c) 趋化的细胞为什么需要一秒以上的奔跑，而不是0.01 s？
::: solution
(a) $D_\mathrm{eff} = 400\times1/3 = 133$ µm² s⁻¹，与一个蛋白质相当，比小分子低一个数量级。(b) $133/0.67 = 199$ µm² s⁻¹，约200。(c) 细胞必须比较间隔大于其测量噪声所能允许的浓度的两点；奔跑太短，行程不足一个亚微米，而天然梯度上这么短距离的浓度差，比起结合到受体上的分子数目的随机涨落实在太小。Berg 与 Edward Purcell（1977年）证明，化学感知的精度随计数分子的时间延长而改善，所以奔跑必须长到足以既计数又位移。
:::
:::

::: exercise 为什么难杀死 *Mycobacterium*？ {level=2}
列出分枝杆菌被膜的三个特点，各解释它如何助成对消毒剂与抗生素的抗性、以及缓慢生长。
::: solution
(1) 分枝菌酸形成蜡样、强疏水的外层（分枝膜），挡住亲水药物与消毒剂的进入。(2) 为数不多的孔蛋白又窄又稀，限制了亲水小分子的摄取——养分也在内，这与生长缓慢有关。(3) 肽聚糖-阿拉伯半乳聚糖-分枝菌酸复合体是一层厚厚的共价连接屏障，其合成代价高昂。抗分枝杆菌的药物常靶向这些独特成分（分枝菌酸、阿拉伯半乳聚糖）的合成，这也解释了它们为何对其他细菌无效。
:::

::: exercise 孢子与罐头 {level=3}
一家食品罐头厂加热罐头以杀死 *Clostridium botulinum* 的孢子。从内生孢子的结构出发，解释：(a) 为什么100 °C 煮沸不够、而要用121 °C 加压蒸汽；(b) 为什么酸性食品（pH 低于约4.6）可以在较低温度下加工；(c) 为什么产孢对于一种本已适合微生物生长的食品中的种群增长并无助益。
::: solution
(a) 部分脱水的核心被吡啶二羧酸钙稳定，蛋白质难以变性；杀死孢子需要更高温度或长得多的时间，而杀灭速率随温度陡升，所以121 °C 下数分钟能完成的事，100 °C 要几小时（动力学见 [[microbiology/antimicrobials]]）。(b) 在酸性食品中幸存的孢子在 pH 约4.6以下不能萌发、长殖并产毒，所以加工只需杀死营养细胞与耐酸生物的孢子。(c) 产孢把一个营养细胞变成一个孢子：数目不增加，生长也停摆。只有在环境即将变得不利时，这笔投资才划算。
:::

::: exercise 解读一份脂质分析 {level=3}
一株从 pH 2.5、80 °C 温泉中分离的新菌株，其膜脂水解后不释放脂肪酸，而得到与两个甘油分子相连的 C₄₀ 异戊二烯二醇。其 16S rRNA 基因与 *E. coli* 的有78 %一致性。它对青霉素与溶菌酶有抗性。(a) 它属于哪个域？(b) 它的膜是什么结构，这在其生境中有什么好处？(c) 你预计它有什么样的壁？
::: solution
(a) 古菌：没有脂肪酸，异戊二烯醚脂，16S rRNA 序列远离细菌序列，且抗壁靶向药物。(b) 两端都连甘油的 C₄₀ 链是单次跨膜的四醚，形成单分子层。醚键抗酸水解与耐热；单分子层对质子通透性低——对一个要把细胞质维持在近中性的 pH、而外界 pH 为2.5的细胞至关重要——且在高温下不会剥离成小叶。(c) 大概以糖蛋白 S-layer 作为唯一的壁，如 *Sulfolobus*；绝不会是肽聚糖。
:::
