近表层的一升海水中约含100亿个病毒颗粒，大致是每个细菌对应十个。病毒是地球上数量最多的生物实体——对其总数的估计在$10^{31}$量级——而且它们能感染每一种细胞生物，从细菌和古菌到鲸与树。在海洋中，据信它们每天杀死细菌群体中相当大的一部分，释放养分，并左右着碳与氮的循环。在实验室里，细菌病毒是分子生物学赖以奠基的“生物”：基因的本质、遗传密码、信 RNA 与基因调控，全都靠它们阐明。病毒还承载着世界遗传多样性的很大一部分——在病毒基因组中发现的基因，大多数在别处没有已知近亲。

然而病毒不是细胞。它没有代谢，不制 ATP，也没有核糖体；离开宿主它便毫无生气。本章描述病毒是什么、如何构建，如何分类、计数与培养，以及它们如何复制——先讲噬菌体，再讲动物与植物的病毒。还描述细胞抵御病毒的防线，以及病毒在生态与进化中的位置。噬菌体的遗传学见[[genetics/microbial-genetics]]，λ开关见[[molecular-biology/bacterial-gene-regulation]]，病毒作为人类疾病因子见[医学图谱](/learn/medicine/lesson.php?c=microbiology&l=viruses)。

## 什么是病毒？

::: definition 病毒 {#def-virus}
**病毒** 是一种感染因子，只在活的宿主细胞内利用宿主的核糖体、能量与前体物复制。其细胞外形式称 **病毒粒子（virion）**，由一个 DNA **或** RNA 基因组（单链或双链、线状或环状、一段或数段）外被蛋白质外壳—— **衣壳**——构成；基因组与衣壳合称 **核衣壳**。许多动物病毒、以及少数其他宿主的病毒还有 **包膜**，一种来自宿主膜、镶满病毒糖蛋白的脂膜。病毒粒子既不生长也不分裂：新的病毒粒子由感染细胞内分别制造的组件装配而成。
:::

病毒的尺度范围从圆环病毒——基因组为不足2,000个核苷酸的单 DNA，只编码两个蛋白——到阿米巴的“巨型病毒”：拟菌病毒（Mimivirus）有1.2 Mb 基因组，编码约一千个蛋白，其中还包括某些翻译因子 tRNA（Didier Raoult 及同事，2004）；潘多拉病毒（pandoravirus）的基因组可达约2.5 Mb（Nadège Philippe 及同事，2013）——比某些细菌的基因组还大。巨型病毒本身又可被更小的“噬病毒体”（virophage）寄生，如 putnik，它只能在同时感染巨型病毒的阿米巴内复制（Bernard La Scola 及同事，2008）。

还有更简单的感染因子。**类病毒**由 Theodor Diener 于1971年在马铃薯纺锤块茎病的病原中发现，是约250–400个核苷酸的裸露环状 RNA，不编码任何蛋白，由宿主的酶复制。**卫星**病毒与卫星核酸依赖辅助病毒。**朊粒**引起传染性海绵状脑病，根本不含核酸：它们是错误折叠的宿主蛋白形式，能以诱导的方式使正常的同类蛋白也发生错误折叠。

::: warning 病毒是活的吗？
这个问题没有事实上的答案；它取决于生命的定义（[[diversity-of-life/origin-of-life#def-life]]）。病毒经自然选择进化，有基因，由与细胞相同的分子构成；但它们没有代谢，离开细胞便如晶体一样惰性（斯坦利（Wendell Stanley）于1935年结晶了烟草花叶病毒）。更有用的看法是：被感染的细胞——“病毒细胞（virocell）”——才是病毒的活的形式，病毒粒子只是它的传播手段，正如种子之于植物。有两个误解值得避免：抗生素对病毒不起作用，因为病毒完全没有抗菌药物的靶标（[[microbiology/antimicrobials]]）；而且大多数病毒并不是人类的病原体——绝大多数感染细菌与古菌。
:::

## 病毒粒子的构建

小基因组编码不了许多蛋白，因此克里克与沃森（1956）推断，衣壳必定由一种或少数几种蛋白的大量拷贝按对称方式组装而成。已发现两种对称。

**螺旋**衣壳中，相同的亚基围绕基因组排成螺旋，形成杆状（烟草花叶病毒长约300 nm，含其外壳蛋白的2,130个拷贝）或柔性丝状（如 M13 等丝状噬菌体；流感与麻疹病毒在包膜内的核衣壳）。衣壳的长度由基因组的长度决定。

**二十面体**衣壳中，亚基排布在二十面体的表面上——二十面体是有20个三角面、12个顶点、具有五重、三重与二重对称轴的正规多面体。一个二十面体可由60个相同亚基建成，每面三个，每个亚基所处的环境完全相同。更大的衣壳使用更多亚基，此时它们不可能再全部处于相同的位置。

::: proposition 准等效与三角化数 {#prop-tnumber}
在卡斯帕（Donald Caspar）与克卢格（Aaron Klug）（1962）的理论中，二十面体衣壳由$60T$个处于略不相同（“准等效”）环境的蛋白亚基建成，排列为顶角处的12个**五聚体**与其余位置的$10(T - 1)$个**六聚体**。**三角化数**只取下列数值

$$
T = h^2 + hk + k^2, \qquad h, k = 0, 1, 2, \dots,
$$ {#eq-tnumber}

即$T = 1, 3, 4, 7, 9, 12, 13, \dots$，其中$(h, k)$是六角格点上从一个五重顶点到下一个五重顶点的步数。
:::

::: proof
设想把衣壳画在由壳体位置构成的平面六角格点上，再折成闭合的壳。闭合多面体的欧拉公式$V - E + F = 2$表明，由六边形与五边形铺成的闭合壳恰好需要12个五边形，无论它有多少六边形，而二十面体对称把它们放在12个顶点上。二十面体的每个三角面连接三个顶点，它们必须落在格点上，于是面的一条边是一个格矢$h\mathbf a + k\mathbf b$，其中$\mathbf a$与$\mathbf b$是互成60°、连接相邻格点的单位矢量。其长度的平方为$h^2 + 2hk\,(\mathbf a\cdot\mathbf b) + k^2 = h^2 + hk + k^2 = T$，而等边三角形面的面积正比于其边长的平方。最小的壳（$h = 1$，$k = 0$，$T = 1$）每面有3个亚基，于是一个放大$T$倍的面容纳$3T$个，20个面共容纳$60T$个。12个五聚体占去60个亚基，余下的$60(T - 1)$个组成$10(T - 1)$个六聚体。
:::

::: example 数衣壳蛋白 {#ex-capsid}
(a) $(h, k) = (1, 1)$与$(2, 1)$的衣壳各由多少个亚基与六聚体构成？(b) 噬菌 HK97 的头有$T = 7$，但它的一个顶点被门户蛋白（portal，DNA 经此装填）而不是五聚体占据。它含多少个主要衣壳蛋白亚基？(c) 病毒为什么用$T = 3$、由180个亚基构成的衣壳，而不用$T = 1$、由60个较大亚基构成的衣壳？
::: solution
(a) $(1, 1)$：$T = 3$，180个亚基，排为12个五聚体与20个六聚体。$(2, 1)$：$T = 7$，420个亚基，排为12个五聚体与60个六聚体。

(b) $420 - 5 = 415$个亚基：11个五聚体与60个六聚体。

(c) 给定大小的壳用更多、更小的亚基构建，编码衣壳蛋白的基因就可以更小，把更多基因组留给其他功能；一个小的基因重复多次是有限编码容量最经济的用法——这正是克里克与沃森最初的论证。由许多相同亚基装配也自带纠错：错折的亚基会被排除在外。
:::
:::

许多噬菌体，包 T4 与λ，把二十面体（或伸长的二十面体）**头**与螺旋**尾**结合起来，尾部常带可收缩的尾鞘、基板与识别宿主的尾丝。这些有尾噬菌体的双 DNA 由门户 ATP 驱动的马达装入预先建好的头中，对抗的是以几十个大气计的内部压（Douglas Smith、Carlos Bustamante 及同事，2001，用噬菌体φ29）。噬菌体头部中 DNA 紧密到接近晶体的堆积密度。

::: example DNA 装得有多紧？ {#ex-packing}
噬菌体λ把48.5 kb 的双 DNA 基因组装进内半径约27 nm 的头中。按每个碱基对650 Da，估计头 DNA 的浓度（mg mL⁻¹），并与 *E. coli*（大肠杆菌）类核中 DNA 浓度（约10–20 mg mL⁻¹）比较。
::: solution
DNA 质量：$48{,}502\times650 = 3.15\times10^7$ Da，即$3.15\times10^7/6.022\times10^{23} = 5.2\times10^{-17}$ g。半径27 nm 的球体积：$\tfrac43\pi(27\times10^{-7}\ \mathrm{cm})^3 = 8.2\times10^{-17}$ cm³（mL）。浓度：$5.2\times10^{-17}/8.2\times10^{-17} \approx 0.63$ g mL⁻¹ $= 630$ mg mL⁻¹—— 比类核中的浓约30–60倍，接 DNA 在液晶中的堆积。储存的能量有助于感染时 DNA 注入宿主。
:::
:::

包膜在核衣壳芽出宿主膜时获得——流感病毒 HIV 以质膜为出口，疱疹病毒与冠状病毒则用内膜。包膜糖蛋白结合新宿主细胞上的受体，并介导病毒膜与细胞膜的融合。包膜是脆弱的：去污剂、酒精与干燥使有包膜病毒失活远易于无包膜病毒。

## 病毒的分类

病毒没有任何一个基因能像 16S rRNA 那样把全部病毒放在同一棵树上，而且病毒几乎肯定有多个独立的起源。人们用两种互补的方式给病毒分类。

巴尔的摩（David Baltimore，1971）按基因组的性质及其产生信 RNA—— 每一种病毒都必须制造、以便被宿主核糖体翻译的唯一分子——的途径给病毒归类：

| 类 | 基因组 | 到 RNA 的途径 | 实例 |
|---|---|---|---|
| I | 双 DNA | 由宿主或病 RNA 聚合酶转录 | 噬菌 T4 与λ、疱疹病毒、痘病毒、巨型病毒 |
| II | 单 DNA | 转变 dsDNA 后再转录 | 噬菌体 φX174、M13、细小病毒、圆环病毒 |
| III | 双 RNA | 在衣壳内由病毒 RNA 依赖 RNA 聚合酶转录 | 轮状病毒、噬菌体φ6 |
| IV | 单 RNA，正链 | 基因组**本身**就 mRNA，直接翻译 | 脊髓灰质炎病毒、冠状病毒、烟草花叶病毒、噬菌 MS2 |
| V | 单 RNA，负链 | 由病毒粒子携带的病 RdRp 转录 | 流感、麻疹与狂犬病毒 |
| VI | 单 RNA，逆转录 | 逆转录 DNA、整合、转录 | HIV 等逆转录病毒 |
| VII | 双 DNA，逆转录 | 转录；经 NA 中间体复制 | 乙型肝炎病毒、花椰菜花叶病毒 |

巴尔的摩类别决定了病毒必须自带什么。正 RNA 基因组单独导入细胞即有感染性，因为核糖体可以立刻翻译它；负链或双 RNA 基因组则不然，因为细胞里没有能转录它的酶，所以这些病毒把自身 RNA 依赖 RNA 聚合酶包装在病毒粒子中。

国际病毒分类委员会（ICTV）维持一套正式的分类体系，等级从 **域（realm）** 下到种，且自2021年起把物种逐步改为双名法（如烟草花叶病毒改称 *Tobamovirus tabaci*）。域归集共享某个“特征”基因、被推断溯自共同祖先的病毒：例如 *Riboviria* 含有带 RNA 依赖的 RNA 聚合酶的 RNA 病毒（以及带逆转录酶的逆转录病毒），*Duplodnaviria* 包含有尾噬菌体与疱疹病毒——其主要衣壳蛋白共有 “HK97 折叠”，*Varidnaviria* 则含带“双果冻卷”衣壳蛋白的病毒，自腺病毒直到巨型病毒。这些关系所指向的深层亲缘——动物的疱疹病毒与细菌的有尾噬菌体相缘——是从蛋白质结构发现的，而结构在序列相似性早已消失之后仍保留着。

## 病毒的计数与培养

病毒用宿主细胞培养：噬菌体用细菌培养物，动物病毒用培养的细胞，植物病毒用植株或植物细胞。d'Herelle（1917）引进了**噬菌斑测定**，它至今仍是计数感染性噬菌体的标准方法：把噬菌体稀释液与过量的宿主细菌混在软琼脂中，倒在平板上。每个感染颗粒感染一个细胞，其子代感染邻近的细胞，培养之后，每个原始颗粒都在不透明的细菌菌苔上产生了一个透明圈，一个**噬菌斑**。计数以**噬菌斑形成单位**（PFU）表示，算法与涂布平板计数完全一样（[[microbiology/microbial-world#prop-plate-count]]）。能杀死培养细胞的动物病毒用细胞单层上的噬菌斑（空斑）测定计数。

并非每个颗粒都能形成噬菌斑。把颗粒计数（用电镜或流式细胞术）与 FU 比较得到**颗粒与 PFU 之比**，许多噬菌体接近1，而动物病毒常常达100以上，因为许多颗粒是有缺陷的，或未能完成感染。

噬菌体与细菌混合时，哪个细胞得到几个噬菌体全凭机会。

::: proposition 感染复数 {#prop-moi}
若按**感染复数**$m$（感染颗粒与细胞之比）把噬菌体加到细菌中，且吸附彼此独立、随机发生，则一个给定细胞吸附的噬菌体数服从均值为$m$的泊松分布。未感染、恰好感染一个、以及感染一个以上的细胞比例分别为

$$
P_0 = e^{-m}, \qquad P_1 = me^{-m}, \qquad P_{\ge 2} = 1 - e^{-m} - me^{-m}.
$$ {#eq-moi}
:::

这与孔板中细胞的泊松推理相同（[[microbiology/microbial-world#prop-mpn]]）；这一类比是精确的，因为每个噬菌体都独立地“选中”海量细胞中的一个。

x: 0, 6
y: 0, 1

caption: 未感染、单个感染与多个感染的细胞比例随感染复数$m$的变化，来自泊松分布。$m = 1$（竖线）时，37 %的细胞逃脱感染，37 %得到一个噬菌体，26 %得到两个以上。单个感染的比例在$m = 1$处最大；要使99 %的细胞感染，需要$m = \ln 100 = 4.6$，而此时几乎所有被感染的细胞都带有好几个噬菌体。
:::

### 一步生长曲线

埃利斯（Emory Ellis）与德尔布吕克（Max Delbrück）（1939）设计了定义噬菌体生活史的实验。以低复数感染细菌几分钟，然后除去未吸附的噬菌体，或把培养物稀释到子代难以再感染新细胞的程度，此后按时取样涂板。在一段**潜伏期**内，PFU 计数保持不变——每个被感染的细胞产生一个噬菌斑。随后计数骤然上升，仅一步，细胞裂解释出其子代，然后趋于平缓。最终计数与初始计数之比即平均**裂解量**。若定时把细胞人为破开（用氯仿），潜伏期的前一段根本找不到任何感染性噬菌体——这就是**隐蔽期**，此时入侵的病毒粒子已被拆散，而其子代尚未装配。

::: example 一步生长实验 {#ex-burst}
$2\times10^8$细胞 mL⁻¹ 的大肠杆菌以$m = 0.05$的噬菌 T4 感染。吸附后把培养物按$10^{-4}$稀释进37 °C 的新鲜培养基。25分钟以前涂板的样品得$1.0\times10^3$ PFU mL⁻¹；35分钟以后的样品得$2.0\times10^5$ PFU mL⁻¹。(a) 有多少细胞被感染？其中有多少被不止一个噬菌体感染？(b) 裂解量是多少？(c) 为什么要以低复数感染、然后再稀释？
::: solution
(a) $P_0 = e^{-0.05} = 0.951$，故$4.9\,\%$的细胞被感染：稀释前为$0.049\times2\times10^8 = 9.8\times10^6$个感染细胞 mL⁻¹，稀释后$\approx 10^3$ mL⁻¹，与感染中心的平台计数相符。被两个以上感染的比例为$1 - 0.951 - 0.05\times0.951 = 0.0012$，约占被感染细胞的2.5 %。

(b) 裂解量$= 2.0\times10^5/1.0\times10^3 = 200$个噬菌体每个被感染细胞。

(c) 低复数确保多数被感染的细胞只收到一个噬菌体，于是实验度量的是单次感染的产出。稀释确保释放的子代在实验期间很少遇到未感染的细胞，从而第二轮感染不会模糊那“一步”。
:::
:::

## 噬菌体的复制

### 裂解周期

毒力噬菌体（如 T4）的**裂解周期**有五个阶段：

1. **吸附。** 尾丝结合细胞表面的特异受体 ——T4 结合脂多糖或外膜蛋 OmpC，λ结合麦芽糖孔蛋 LamB，MS2 与 M13 结 F 菌毛。受体决定噬菌体的宿主范围。
2. **侵入。** T4 的尾鞘收缩，把内管穿过被膜，DNA 被注入；衣壳留在外面。证明进入细胞的只 DNA 的，正是赫希（Alfred Hershey）与蔡斯（Martha Chase）1952年的实验，用 ³²P 标 DNA、³⁵S 标记蛋白（[[genetics/genes-and-mutation]]）。
3. **合成。**“早期”噬菌体基因由宿 RNA 聚合酶转录，接管细胞：在 T4，它们降解宿主染色体、修饰聚合酶，并编码噬菌 DNA 复制所需的酶。“中期”与“晚期”基因编码衣壳蛋白与裂解蛋白。T4 的 NA 用葡萄糖基化的羟甲基胞嘧啶代替胞嘧啶，这使它免于噬菌体自身的核酸酶和许多宿主限制酶的切割。
4. **装配。** 头、尾与尾丝分别装配再连接；DNA 经门户马达装入头部。
5. **释放。** 在程序设定的时间，**造孔蛋白（holin）** 在细胞膜上穿孔，让 **内溶素** 得以到达并降解肽聚糖；在革兰氏阴性宿主中，**spanin** 继而把内膜与外膜融合，细胞胀裂。

37 °C 下 T4 的潜伏期约25分钟，裂解量约100–200。小 RNA 与单 DNA 噬菌体用一个抑制肽聚糖合成的蛋白裂解宿主。M13 等丝状噬菌体根本不杀死宿主：子代连续经被膜挤出，被感染的细胞仍继续生长，只是慢些——一种**慢性**感染。

### 溶原

**温和** 噬菌体可以有选择。感染之后，噬菌体λ可进入裂解周期，也可建立 **溶原**：其基因组在 *gal* 与 *bio* 操纵子之间的特异位点，由噬菌体整合酶催化的位点特异性重组整合进宿主染色体，作为 **前噬菌体** 随染色体一起复制。阻遏蛋白 CI 使裂解基因保持关闭，还使溶原菌对λ的叠加载感染产生免疫。裂解还是溶原的抉择及其维持，受[[molecular-biology/bacterial-gene-regulation]]所描述的遗传开关控制：感染复数高、生长条件差有利于溶原。当宿主 DNA 受损，SOS 反应中活化的 RecA 促进 CI 的自我切割，前噬菌体便被 **诱导**：它切离，进入裂解周期，抛弃一个命不久矣的宿主。

勒沃夫（André Lwoff）与 ntoinette Gutmann（1950）在微滴中追踪巨大芽孢杆菌（*Bacillus megaterium*）单个细胞历经多次分裂，证明溶原是可以遗传的稳定状态，并证明溶原菌可被紫外光诱导。前噬菌体很常见：许多细菌基因组含好几个完整或退化的前噬菌体，而且它们常携带改变宿主表型的基因，这种现象称为**溶原转换**。一些最重要的细菌毒素由前噬菌体编码：白喉毒素（在棒状噬菌体β上；Victor Freeman，1951）、霍乱毒素（在丝状噬菌 CTXφ 上）以及肠出血性大肠杆菌的志贺毒素。前噬菌体还能介导普遍性与特异性转导（[[genetics/microbial-genetics#def-transduction]]）。

::: quiz
一株对λ 溶原的大肠杆菌培养物经紫外光照射。一小时后培养物变清，并含有游离的λ 噬菌体。同样处理的非溶原培养物不变清。哪项解释正确？
- [ ] 紫外光直接杀死细菌，释放出原本在培养基中的噬菌体。
- [x] DNA 损伤触 SOS 反应；活化 RecA 促 CI 阻遏蛋白切割，前噬菌体被诱导进入裂解周期。
- [ ] 紫外光把前噬菌体诱变成毒力形式。
- [ ] 因为前噬菌体吸收紫外光，溶原菌对它更敏感。
::: solution
非溶原对照说明在这个剂量下变清并非直接杀伤所致。DNA 损伤 RecA 促进 CI 自切割诱导前噬菌体，是正常的响应：前噬菌体离开一个可能活不下来的宿主。这就是为什么许多前噬菌体会被损 DNA 的抗生素诱导。
:::
:::

## 防御与反防御

细菌与古菌常年遭受病毒的攻击，其基因组为防御留出了可观的篇幅：

- **受体改变。** 改变或掩蔽受体的突变带来抗性，往往有代价（当受体是营养转运蛋白时）；荚膜也能藏起受体。
- **限制-修饰。** 限制酶在特定序列切 DNA，除 DNA 被细胞自身的甲基转移酶甲基化，因此入侵的噬菌 DNA 常在表达之前即被切断（[[molecular-biology/molecular-tools#def-restriction]]）。
- **流产感染。** 被感染的细胞在噬菌体完成其周期之前自杀，保护其克隆同胞。
- **CRISPR–Cas 适应性免疫。**入侵 DNA 的短小片段（“间隔序列”）由 Cas1–Cas2 整合酶插入宿主染色体 CRISPR 阵列的重复序列之间。阵列被转录并加工成短的 CRISPR RNA，每条引导一个 Cas 核酸酶去切割带有匹配序列的 DNA（或 RNA）。于是，一次感染后幸存的细胞便记录下对它的记忆，并遗传给后代。间隔序列与噬菌体序列匹配，这一事实于2005年被注意到（Francisco Mojica 及同事；Christine Pourcel 及同事；Alexander Bolotin 及同事），而 Rodolphe Barrangou、Philippe Horvath 及同事（2007）用酸奶发酵剂所用的嗜热链球菌（*Streptococcus thermophilus*）证明，获得一个间隔序列即获得抗性，失去它则抗性消失。CRISPR 系统见于多数古菌基因组和相当一部分细菌基因组。Cas9 及其 CRISPR 核酸酶已成为基因组编辑工具（[[molecular-biology/molecular-tools#def-cas9]]）。

2018年以来的系统性搜索（Shany Doron、Rotem Sorek 及同事等）已发现数十种更多的防御系统，许多成簇于“防御岛”中，其中一些的组分与动物固有免疫蛋白有进化亲缘。噬菌体则逐一化解防御：改变其受体结合蛋白，修饰自身 DNA 碱基，并携带抑 Cas 蛋白的 **anti-CRISPR** 蛋白（Joe Bondy-Denomy、Alan Davidson 及同事，2013）。噬菌体与宿主之间的军备竞赛是双方多样性的主要驱动力之一。

## 动物与植物的病毒

动物病毒经历与噬菌体相同的阶段——吸附、侵入、脱壳、合成、装配、释放——只不过在真核细胞内，并加以利用的是细胞核、膜系统与内膜系统。

**吸附**依赖特异受体，受体决定病毒能感染哪些细胞、哪些物种。HIV 结合某些免疫细胞上的 CD4 与趋化因子受体（CCR5 或 CXCR4）；SARS-CoV-2 结合酶 ACE2。有包膜病毒的**侵入**是经受体结合或内体低 pH 触发，使病毒包膜与质膜融合，或内吞之后与内体膜融合。无包膜病毒经内吞进入，并穿破或瓦解内体膜。**脱壳**释放基因组。

**合成**取决于巴尔的摩类别。多数 DNA 病毒在细胞核内复制，转录用宿主 RNA 聚合酶 II；在细胞质中复制的痘病毒自带转录机器。脊髓灰质炎病毒等正链 RNA 病毒被翻译成一个大的多聚蛋白，经病毒蛋白酶切割成成熟蛋白，其中包括 RNA 依赖的 RNA 聚合酶，它在改造过的细胞质膜上经负链中间体复制基因组。负链 RNA 病毒自带聚合酶。**逆转录病毒**携带**逆转录酶**（特明（Howard Temin）与水谷敏（Satoshi Mizutani）以及巴尔的摩（David Baltimore）于1970年发现），把 RNA 复制成双链 DNA；病毒整合酶把这一 DNA 插入宿主染色体成为**前病毒**，随后如细胞基因一般被宿主聚合酶转录。感染过我们祖先生殖系的逆转录病毒，已在人类基因组中留下约8 %的内源性逆转录病毒序列。

**释放**：有包膜病毒以出芽释放，这不一定杀死细胞；无包膜病毒通常在细胞死亡裂解时释放。一些病毒建立**潜伏**感染——疱疹病毒以附加体形式持久存在于神经元或淋巴细胞中，伴随宿主终生，偶尔再激活——一些病毒则经整合、或经表达压制细胞周期调控的蛋白，可能参与致癌。

**植物病毒**面对的是细胞壁。它们经伤口进入，伤口常由取食并传播病毒的昆虫、线虫或真菌造成；它们在病毒**运动蛋白**的帮助下经胞间连丝在细胞间移动，再经韧皮部传遍全株。多数是正 RNA 病毒。植物主要 RNA 沉默防御它们，后者降解双链病 RNA；而病毒携带沉默抑制子。

### 易错的复制

RNA 依赖 RNA 聚合酶与逆转录酶没有校对功能，RNA 病毒的突变率约为每核苷酸每次细胞感染$10^{-6}$到$10^{-4}$（Rafael Sanjuán 及同事，2010），比细 DNA 基因组的突变率高出许多个数量级（[[genetics/genes-and-mutation#def-mutation-rate]]）。加上庞大的群体与短的世代时间，RNA 病毒进化得异常迅速，这就是流感疫苗必须更新、而 HIV 药物要联合使用的原因（[[microbiology/antimicrobials]]）。

::: proposition 每基因组突变数 {#prop-genome-mutation}
若长为$L$的基因组复制时每个位点的出错概率为$\mu$、彼此独立，则每份基因组拷贝的新突变数近似服从均值为$U = \mu L$的泊松分布，而一份拷贝不带任何新突变的概率为

$$
P(\text{无突变}) = (1 - \mu)^L \approx e^{-U}.
$$ {#eq-genome-mutation}
:::

::: example RNA 病毒有多忠实？ {#ex-mutation}
(a) 一个基因组10 kb 的正 RNA 病毒，每次复制每核苷酸的$\mu = 10^{-4}$。子代基因组中至少带一个新突变的比例是多少？(b) 冠状病毒基因组为30 kb，但其聚合酶复合体含一个校对外切酶，把错误率降到约$10^{-6}$。$U$是多少？(c) 解释为什么校对可能是如此大 RNA 基因组进化的先决条件。
::: solution
(a) $U = 10^{-4}\times10^4 = 1$，故$1 - e^{-1} = 63\,\%$的子代至少带一个新突变。

(b) $U = 10^{-6}\times3\times10^4 = 0.03$；97 %的子代无突变。

(c) 既然紧凑病毒基因组的大部分突变是有害的，$U$远高于1的基因组产生的子代大多有缺陷，而选择能维持遗传信息的基因组大小存在上限，与错误率成反比——曼弗雷德·艾根（Manfred Eigen）的**错误阈**（[[diversity-of-life/origin-of-life#prop-error-threshold]]）。若没有校对，30 kb 的基因组在$\mu = 10^{-4}$下$U \approx 3$，只有约5 %的子代无突变；冠状病毒的外切酶 RNA 病毒中独一无二，据信正是它成就了其异常长的基因组。
:::
:::

## 病毒在生态与进化中

在海洋中，病毒大规模裂解细菌与浮游植物；它们把细胞内含物以溶解有机质的形式释放、供其他细菌取用，从而把碳与养分从大型生物那里改道—— **病毒分流**（[[microbiology/microbial-ecology]]）。由于宿主丰富时噬菌体扩散最快，病毒裂解倾向于砍倒最成功的宿主（“杀死赢家”），这可能有助于维持微生物多样性。病毒还搬运基因：转导与溶原转换是水平转移的重要途径（[[microbiology/microbial-diversity#def-hgt]]），蓝细菌噬菌体还携带光合蛋白基因，使宿主的系统光合作用在感染期间得以维持。

病毒的起源尚未解决。三种经典假说——病毒溯自前细胞的复制子（病毒先）、溯自定义性感染的细胞基因组片段（逃逸）、溯自丢失了大部分基因的寄生细胞（简化）——并不互斥，不同的病毒类群可能以不同方式起源。衣壳折叠这类特征蛋白在三域一切生命的所有病毒间共享，表明某些病毒谱系极为古老，也许与细胞本身同样古老。

::: application 作为工具与疗法的病毒
发现噬菌体后不久，人们就用它们治疗细菌感染（d'Herelle，1919），噬菌体疗法在东欧部分地区沿用至今；随着耐药性的兴起，它正在受监管的临床研究中重新接受检验（[医学图谱](/learn/medicine/lesson.php?c=microbiology&l=antimicrobials)）。噬菌体展示（George Smith，1985）把抗体与多肽展示在噬菌体表面加以进化改良。改造过的复制缺陷病毒在基因治疗与疫苗中递送基因，而病毒的酶——逆转录酶、T7 RNA 聚合酶、噬菌体重组酶与整合酶——是分子生物学的标准试剂（[[molecular-biology/molecular-tools]]，[[biotechnology]]）。所有这些工作都受监管：可能增强某病原体传播力或毒力的研究须接受特别审查，涉及人类病原体的工作只能在防护等级合适的实验室进行。
:::

::: history
Ivanovsky（1892）与 eijerinck（1898）证明烟草花叶病的病原能通过截留细菌的滤器，Friedrich Loeffler 与 aul Frosch（1898）对牛口蹄疫作了同样的证明——那是第一种动物病毒。Frederick Twort（1915）与 d'Herelle（1917）发现了噬菌体。温德尔·斯坦利结晶了烟草花叶病毒（1935），Frederick Bawden 与 orman Pirie 证明它 RNA（1937），Helmut Ruska 及同事在电镜下拍摄了它（1939）。埃利斯与德尔布吕克的一步生长曲线（1939）开创了“噬菌体小组”，赫希与蔡斯（1952）证明噬菌体 DNA 携带遗传信息。勒沃夫描述了溶原（1950），卡斯帕与克卢格给出了衣壳结构原理（1962），特明与巴尔的摩发现了逆转录酶（1970）。菲尔斯（Walter Fiers）课题组测定 RNA 噬菌 MS2 的基因组（1976），桑格（Frederick Sanger）课题组测定 DNA 噬菌体 φX174 的基因组（1977）——这是有史以来第一批完整基因组。
:::

::: summary
- 病毒只在宿主细胞内复制；病毒粒子是蛋白质衣壳中 DNA 或 NA 基因组，有时另有宿主来源的包膜。基因组从不足2 kb 到约2.5 Mb；类病毒、卫星与朊粒更简单。
- 衣壳为螺旋或二十面体对称；二十面体衣壳含$60T$个亚基，排为12个五聚体与$10(T - 1)$个六聚体，$T = h^2 + hk + k^2$。有尾噬菌体 DNA 装到接近晶体的密度。
- 巴尔的摩类别（I–VII）依基因组类型与 mRNA 的途径定义；ICTV 的域按特征基因与蛋白质折叠聚类病毒。
- 噬菌体以噬菌斑形成单位计数；感染服从均值$m$（感染复数）的泊松分布。一步生长曲线揭示潜伏期、隐蔽期与裂解量。
- 裂解周期经吸附、注入、合成、装配，以及由造孔蛋白、内溶素 spanin 完成的裂解；λ 等温和噬菌体以前噬菌体形式整合，被 NA 损伤诱导，并可使其宿主发生（毒素基因的）溶原转换。
- 宿主的防御有受体改变、限制-修饰、流产感染、CRISPR–Cas 与许多其他系统；噬菌体以修饰 anti-CRISPR 化解。
- 动物病毒结合特异受体，经融合或内吞进入，按其类别复制；逆转录病毒以前病毒形式整合。RNA 病毒的突变率为$10^{-6}$–$10^{-4}$，每份基因组拷贝有$U = \mu L$个突变，基因组大小受错误阈限制。
- 病毒塑造微生物生态（病毒分流、杀死赢家）与进化（基因转移）；其起源多元且未定。
:::

::: exercise 三角化数 {level=1}
下列数值哪些是可能的三角化数：2，3，4，5，7，13，16？对每个可能的值，给出$(h, k)$与亚基数。
::: solution
$T = h^2 + hk + k^2$：3 = (1, 1)，180个亚基；4 = (2, 0)，240；7 = (2, 1)，420；13 = (3, 1)，780；16 = (4, 0)，960。2与5无法写成这种形式，故不可能。

::: exercise 巴尔的摩类别 {level=1}
把每种病毒归入其巴尔的摩类别，并说明病毒粒子中是否必须包装某种酶：(a) 一个病毒，其纯化 RNA 基因组注入细胞即可启动感染；(b) 一个病毒，基因组为负 RNA；(c) 一个病毒，基因组为单 RNA，且病毒粒子伴 DNA 聚合酶活性；(d) 一个病毒，基因组为环状单 DNA。
::: solution
(a) IV 类（正 RNA）：不需要酶，基因组就 mRNA。(b) V 类：必须包 RNA 依赖 RNA 聚合酶（转录酶），因为细胞没有。(c) VI 类（逆转录病毒）：逆转录酶，还有整合酶。(d) II 类：不需要酶；由宿 DNA 聚合酶合成互补链。
:::
:::

::: exercise 感染复数 {level=2 check="2.3"}
要使90 %的细胞感染，需要多大的感染复数（一位小数）？此时被感染的细胞中有几分之几带有两个以上噬菌体？
::: solution
$1 - e^{-m} = 0.9$，故$m = \ln 10 = 2.3$。$P_1 = 2.3\times0.1 = 0.23$，于是$P_{\ge2} = 0.9 - 0.23 = 0.67$；在被感染的细胞中，$0.67/0.9 = 74\,\%$是多个感染。
:::
:::

::: exercise 一次裂解 {level=2 check="150"}
细菌以低复数感染，稀释后取样。裂解前涂板得每0.1 mL 400 PFU；裂解后，$10^{-2}$稀释液得每0.1 mL 600 PFU。裂解量是多少？
::: solution
裂解前：$4\times10^3$ PFU mL⁻¹（感染中心）。裂解后：$600/(0.1\times10^{-2}) = 6\times10^5$ PFU mL⁻¹。裂解量$= 6\times10^5/4\times10^3 = 150$。
:::
:::

::: exercise 无突变的子代 {level=2 check="0.74"}
某病毒基因组长15 kb，每次复制每位点错误率为$2\times10^{-5}$。子代基因组不含新突变的比例是多少（两位小数）？
::: solution
$U = 2\times10^{-5}\times1.5\times10^4 = 0.3$，且$e^{-0.3} = 0.74$。
:::

::: exercise 裂解还是溶原 {level=2}
判断λ 在各情形下倾向于裂解还是溶原，并说明理由：(a) 以0.1的复数感染营养良好的细胞；(b) 以10的复数感染饥饿的细胞；(c) 用损 DNA 的抗生素处理溶原菌；(d) 用缺失 *cI* 基因的λ 突变体感染。
::: solution
(a) 倾向裂解：营养良好的细胞蛋白酶活跃，降解 *cI* 转录的激活蛋 CII，而单个噬菌体基因组产生 CII 少。(b) 溶原：饥饿降低蛋白酶活性（经 AMP 信号），且每个细胞中许多噬菌体基因组产生更 CII。就生物学而言，当宿主相对噬菌体稀少时，蛰伏在宿主体内好于释放找不到新细胞的子代。(c) 诱导：DNA 损伤活化 RecA 促 CI 切割，前噬菌体进入裂解周期。(d) 总是裂解：没 CI，噬菌体无法建立或维持阻遏；这类突变体形成清晰噬菌斑，而不是野生型λ 的浑浊噬菌斑。
:::
:::

::: exercise CRISPR 的记录 {level=2}
用噬菌体攻击一株嗜热链球菌，分离到抗性幸存株。测序显示，每株都在 CRISPR 阵列的前导端新获得一个间隔序列，且各间隔序列匹配噬菌体基因组的不同部位。(a) 解释新间隔序列为什么位于前导端。(b) 预测从一株抗性菌株中删除新间隔序列的效果。(c) 能逃逸该抗性株的噬菌体突变体带有的是点突变。你预期它们位于何处？
::: solution
(a) 新间隔序列插入含启动子的前导序列之旁，因此阵列是按时间排列的记录，最新的间隔序列在最前。(b) 该菌株将重新对噬菌体敏感（如 arrangou 及同事的实验），表明间隔序列正是抗性之因。(c) 位于与间隔序列匹配的**前间隔序列（protospacer）**，或紧邻其旁、Cas 核酸酶所必需的短**前间隔序列邻近基序（PAM）**；这些位置的错配会阻止切割。
:::

::: exercise 解读一步生长曲线 {level=3}
37 °C 下噬菌 T4 的一步生长实验中，感染中心计数至22分钟恒定于$5\times10^3$ PFU mL⁻¹，到32分钟升至$5.5\times10^5$ PFU mL⁻¹。平行样品经氯仿（可裂解细胞）处理后，12分钟以前检不出感染性噬菌体，到30分钟升至$5.5\times10^5$。(a) 潜伏期、隐蔽期与裂解量各是多少？(b) 为什么早期氯仿处理样品的计数低于未处理样品？(c) 在30 °C 下曲线会如何变化？为什么？
::: solution
(a) 潜伏期约22分钟（不用氯仿时首次上升的时间）；隐蔽期约12分钟（细胞内首次出现感染性子代的时间）；裂解量$5.5\times10^5/5\times10^3 = 110$。(b) 不加氯仿时，每个完整的被感染细胞无论内部如何都形成一个噬菌斑；加氯仿后细胞被破开，而隐蔽期细胞内没有感染性噬菌体——入侵颗粒已被拆解——计数便接近零。(c) 两个时期都会拉长，裂解量也可能改变，因为噬菌体复制的每一步都依赖宿主代谢，而代谢在低温下变慢（大约每降低10 °C 速率减半，[[microbiology/microbial-growth]]）。
:::

::: exercise 病毒与宿主的丰度 {level=3}
某近岸样品中，流式细胞术给出 mL $1.2\times10^7$个类病毒颗粒与$1.5\times10^6$个细菌细胞。24小时内，在把新生病毒移走的培养中，病毒数在最初降至$0.3\times10^7$后回升至 mL $0.9\times10^7$。(a) 病毒与细菌之比是多少？(b) 估计病毒的产生速率。(c) 若平均裂解量为30，每 L 每天有多少细菌被裂解？这占细菌现存量的几分之几？(d) 这一估计受哪些不确定性的影响？
::: solution
(a) $1.2\times10^7/1.5\times10^6 = 8$。(b) $(0.9 - 0.3)\times10^7 = 6\times10^6$病毒 mL⁻¹ d⁻¹。(c) $6\times10^6/30 = 2\times10^5$个细菌被裂解 mL⁻¹ d⁻¹，即每天占现存量$2\times10^5/1.5\times10^6 = 13\,\%$。(d) 自然界中的裂解量并不确定，且在不同宿主间差异很大；流式细胞术计数的是类病毒颗粒，其中有些没有感染性、有些根本不是病毒（膜囊泡、基因转移剂）；对样品的操作可能促进或抑制感染、可能诱导前噬菌体；而且计数中包含了感染真核浮游植物的病毒的产生量。
:::
