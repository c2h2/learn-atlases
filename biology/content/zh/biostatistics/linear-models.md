t 检验、方差分析与简单回归看上去是三种不同的工具，前面各章也是这样分开处理的。它们其实是一种工具。每一种都把响应建模为若干效应之和加上正态分布的噪声，每一种都用最小二乘拟合。把它们看成**一般线性模型**的特例，好处立竿见影：它可以同时纳入多个解释变量，混合数值变量与分类变量，检验交互作用，并对一个混杂因素校正某项比较。再往前推广一步到**广义线性模型**（generalized linear model，GLM），同一套机器就适用于根本不正态的响应——活或死、有或无、卵、物种或突变的计数。

本章以矩阵形式介绍线性模型，并展示 t 检验与方差分析如何装入其中；讲**多元回归**、**协方差分析**与**交互作用**；勾画为带分组结构的数据准备的**混合模型**；用布利斯（Chester Bliss）经典的杀虫剂数据（1935）展开 **logistic 回归**，用模拟的物种计数展开**泊松回归**；最后以**模型选择**收尾。矩阵代数见[数学图谱：回归](/learn/maths/lesson.php?c=statistics&l=regression)与[线性代数](/learn/maths/course.php?c=linear-algebra)。现代软件（R 的 `lm` 与 `glm`、Python 的 `statsmodels`）负责计算；这里的目标是理解所拟合的是什么、输出怎么读。

## 一般线性模型 {#general-linear-model}

::: definition 一般线性模型 {#def-glm-normal}
对响应 $y$ 的 $n$ 个观测、$p$ 个系数的**线性模型**是
$$
y_i = \beta_0 + \beta_1x_{i1} + \beta_2x_{i2} + \dots + \beta_{p-1}x_{i,p-1} + \varepsilon_i, \qquad \varepsilon_i \sim \Normal(0, \sigma^2) \text{ 相互独立},
$$
或矩阵形式 $\mathbf y = X\boldsymbol\beta + \boldsymbol\varepsilon$，其中**设计矩阵** $X$（$n \times p$）第一列为 1，之后每个解释变量一列。“线性”指对系数 $\beta_j$ 线性：$X$ 的各列可以是测量变量的幂、对数或乘积，也可以是为类别编码的**指示变量（哑变量）**。
:::

::: proposition 线性模型的最小二乘 {#prop-ls-matrix}
若 $X$ 列满秩，使 $\lVert \mathbf y - X\mathbf b\rVert^2$ 最小的系数为
$$
\hat{\boldsymbol\beta} = (X\T X)^{-1}X\T\mathbf y,
$$ {#eq-normal-equations}
其协方差矩阵为 $\sigma^2(X\T X)^{-1}$。残差方差 $s^2 = \mathrm{SS_{res}}/(n - p)$ 估计 $\sigma^2$；在 $H_0\colon\beta_j = 0$ 之下，每个系数除以其标准误服从 $t_{n-p}$；而两个**嵌套**模型（一个由另一个把 $q$ 个系数置零而得）用下式比较
$$
F = \frac{(\mathrm{SS_{res,reduced}} - \mathrm{SS_{res,full}})/q}{\mathrm{SS_{res,full}}/(n - p)},
$$ {#eq-nested-f}
简化模型为真时它服从 $F_{q,\,n-p}$。
:::

::: proof 正规方程的推导
$\lVert \mathbf y - X\mathbf b\rVert^2 = \mathbf y\T\mathbf y - 2\mathbf b\T X\T\mathbf y + \mathbf b\T X\T X\mathbf b$。它对 $\mathbf b$ 的梯度为 $-2X\T\mathbf y + 2X\T X\mathbf b$；置零得 $X\T X\mathbf b = X\T\mathbf y$，而满秩保证 $X\T X$ 可逆。协方差由 $\Var(A\mathbf y) = A\Var(\mathbf y)A\T$ 取 $A = (X\T X)^{-1}X\T$、$\Var(\mathbf y) = \sigma^2 I$ 得到。
:::

**类别作为列。** 有 $k$ 个水平的因子以 $k - 1$ 个指示列进入模型。用**处理编码**（R 的默认方式）时，一个水平是参照；每个指示变量属于该水平时取 1、否则取 0，所以它的系数就是该水平均值与参照均值之差。两样本 t 检验就是这样对单个指示变量的回归，$y = \beta_0 + \beta_1 g + \varepsilon$，$g = 0$ 或 1：$\hat\beta_0$ 是组 0 的均值，$\hat\beta_1$ 是均值之差，而它的 t 检验正是学生氏的合并方差检验（[[biostatistics/comparing-groups#prop-student]]）。单因素方差分析是对 $k - 1$ 个指示变量的回归，其 F 检验就是 [[#eq-nested-f]] 比较含指示变量的模型与只含截距的模型。[[biostatistics/comparing-groups]] 与 [[biostatistics/regression]] 中的一切都是线性模型。

## 多个解释变量 {#multiple-regression}

**多元回归**中，每个系数 $\beta_j$ 是一个**偏效应**：在*模型中其他变量保持恒定*的条件下，$x_j$ 每增加一个单位 $y$ 的期望变化。当解释变量彼此相关时，它可以与 $y$ 对 $x_j$ 单独回归的斜率非常不同，甚至符号相反。

这种敏感既是多元回归的威力，也是它的危险。它使我们能够校正混杂因素——在其他方面相似的单元之间估计一个变量的效应——同时也意味着变量一有增减，系数就会改变。解释变量高度相关（**共线性**）时，它们各自的效应难以分清：标准误变大、估计不稳定，尽管模型整体可能预测得很好。**方差膨胀因子** $\mathrm{VIF}_j = 1/(1 - R_j^2)$，其中 $R_j^2$ 来自把 $x_j$ 对其余解释变量回归，它说明共线性把 $\hat\beta_j$ 的方差夸大了多少；超过约 5 到 10 的数值提示出了问题。

### 协方差分析

当一个解释变量是分类的（处理或种群）、另一个是数值的（像体型这样的协变量）时，这个线性模型叫做**协方差分析**（analysis of covariance，ANCOVA）。它的经典用途是校正一个在组间不同的协变量之后再比较各组。

::: example 两个岛屿种群蜥蜴的体重 {#ex-ancova}
来自两个岛屿各种群的 12 只蜥蜴的吻肛长（SVL，mm）与体重（g）为**模拟**数据（Python，`random.seed(21)`；A 种群的 SVL 在 52–72 mm 上均匀分布，B 种群在 42–62 mm；A 的体重 $= -2 + 0.12\,\mathrm{SVL}$，B 多 $0.8$ g，再加标准差 0.45 g 的正态噪声）：

A: (55.3, 4.41), (65.8, 5.90), (64.7, 6.18), (61.6, 5.26), (56.3, 5.22), (67.9, 6.83), (68.2, 6.91), (62.2, 6.19), (62.1, 4.91), (56.7, 4.97), (52.1, 3.97), (59.4, 5.56)

B: (53.7, 5.29), (43.4, 4.12), (57.9, 5.97), (46.6, 4.15), (46.7, 4.46), (42.8, 3.63), (62.0, 7.18), (56.8, 5.43), (59.5, 5.96), (54.3, 4.55), (42.7, 3.29), (48.6, 4.28)

两个种群的体重是否有差异：(a) 忽略体型；(b) 在相同的 SVL 处？(c) 斜率是否相同？
::: solution
(a) 平均体重为 5.53 g（A）与 4.86 g（B）；Welch 检验给出 $t = -1.59$、$\nu = 21.1$、$P = 0.13$。B 种群看起来（若说有什么的话）反而更轻。

(b) 拟合 $\text{体重} = \beta_0 + \beta_1\,\mathrm{SVL} + \beta_2\,g_B + \varepsilon$，其中 $g_B = 1$ 表示 B 种群。最小二乘给出
$$
\widehat{\text{体重}} = -3.97 + 0.156\,\mathrm{SVL} + 0.854\,g_B,
$$
且 $\mathrm{SE}(\hat\beta_2) = 0.207$，$t = 4.12$，自由度 21，$P = 0.0005$，种群差的 95 % 区间为 0.42 到 1.28 g。在相同体长处，B 种群的蜥蜴约*重* 0.85 g。原始比较之所以误导，是因为 B 蜥蜴平均身长较短（SVL 均值 51.3 对 61.0 mm），而身长与体重高度相关：SVL 是一个混杂因素。模型解释了体重变异的 $R^2 = 0.88$，而只有种群时只有 0.10。

(c) 添加交互项 $\beta_3\,(\mathrm{SVL}\times g_B)$——它允许斜率随种群而变——只把 $\mathrm{SS_{res}}$ 从 3.182 降到 3.171；由 [[#eq-nested-f]]，$F_{1,20} = 0.065$，$P = 0.80$。没有证据表明斜率不同，所以 (b) 的平行线模型已经足够。（模拟所用的斜率是 0.12；估计值 0.156 ± 0.014 偏高一些，提醒我们单个模拟样本也会有波动。）
:::
:::

ANCOVA 的校正只与模型一样可靠：它假定与协变量的关系是线性的，并且（不含交互项时）是平行的，而且在协变量取值可能超出某一群取值范围的地方比较各组——这里几乎没有 B 蜥蜴有 A 蜥蜴的平均长度那么长。而且校正不能替代随机化：它消除的是所测协变量造成的混杂，消除不了岛屿之间其他任何差异造成的混杂（[[biostatistics/experimental-design#experiments]]）。

### 析因实验中的交互作用

两个因素之间的**交互作用**指一个因素的效应取决于另一个因素的水平。在线性模型中它用乘积项表示；在两因素方差分析中它有自己单独的平方和。

::: example 水与肥 {#ex-two-way}
一个 $2\times2$ 析因温室实验（假想数据），水分（低、高）与肥料（不施、施）的每种组合有 4 盆。干重（g）的格均值为：低水 10（不施肥）与 12（施肥）；高水 14 与 22。残差均方为 4.0，自由度 12。列出两因素方差分析表并加以解读。
::: solution
总均值为 14.5；水分均值为 11（低）与 18（高）；肥料均值为 12（无）与 17（有）。每个因素每个水平有 8 盆：

- $\mathrm{SS_{water}} = 8[(11 - 14.5)^2 + (18 - 14.5)^2] = 196$；
- $\mathrm{SS_{fert}} = 8[(12 - 14.5)^2 + (17 - 14.5)^2] = 100$；
- 每格的交互作用效应为（格均值 − 水分均值 − 肥料均值 + 总均值）$= \pm1.5$，故 $\mathrm{SS_{interaction}} = 4\times4\times1.5^2 = 36$。

| 来源 | SS | 自由度 | MS | $F$ | $P$ |
|---|---|---|---|---|---|
| 水分 | 196 | 1 | 196 | 49.0 | $1.4\times10^{-5}$ |
| 肥料 | 100 | 1 | 100 | 25.0 | 0.0003 |
| 水分 × 肥料 | 36 | 1 | 36 | 9.0 | 0.011 |
| 残差 | 48 | 12 | 4.0 | | |

交互作用是显著的：肥料在低水下增 2 g，在高水下增 8 g。肥料的“主效应”5 g 是两种迥然不同的情形的平均，单报它会误导。存在交互作用时，应解读每个因素在另一个因素各水平上的效应——画出交互作用图，每个水分水平一条线——而不是只报主效应。在低水条件下做的一次一因素实验，本来会得出肥料无足轻重的结论。
:::

### 随机效应与混合模型

当观测成组而来——缸中的鱼、小区里的植物、个体上的重复测量、批次间处理的样品——这些组常常是诸可能的组的一个随机样本，人们关心的与其说是其中每一个，不如说是它们引入的变异。**混合模型**把它们作为**随机效应**纳入，例如
$$
y_{ij} = \beta_0 + \beta_1x_{ij} + u_j + \varepsilon_{ij}, \qquad u_j \sim \Normal(0, \sigma_u^2), \quad \varepsilon_{ij} \sim \Normal(0, \sigma^2),
$$
其中 $u_j$ 是第 $j$ 缸的效应。模型估计缸间方差 $\sigma_u^2$ 与缸内方差 $\sigma^2$（二者之比即 [[biostatistics/experimental-design#eq-design-effect]] 的组内相关），并用正确的自由度、针对缸间变异来检验施于缸的处理。混合模型是对伪重复、重复测量与非平衡层叠数据的有原则的解法；它们用受限最大似然（REML）拟合，例如用 R 包 `lme4`（贝茨（Douglas Bates）及同事，2015）。其细节属于第二门课程。

## 广义线性模型 {#glm}

线性模型假定响应正态且方差恒定。许多生物学响应从根本上违反这一点：成活比例介于 0 与 1 之间，其方差在 0.5 处最大；计数是非负整数，其方差随均值增长。变换响应（$y$ 的反正弦或 $\log(y + 1)$）是旧的补救办法。奈尔德（John Nelder）与韦德伯恩（Robert Wedderburn）（1972）把一种更好的办法统一了起来。

::: definition 广义线性模型 {#def-glm}
**广义线性模型**有三个组成部分：

1. 一个**随机成分**：响应 $y_i$ 服从指数族中的一个分布——正态、二项、泊松、伽马等——均值为 $\mu_i$；
2. 一个**线性预测器** $\eta_i = \beta_0 + \beta_1x_{i1} + \dots + \beta_{p-1}x_{i,p-1}$；
3. 一个连接二者的**链接函数** $g$：$g(\mu_i) = \eta_i$。

系数用最大似然法估计，实际算法是迭代再加权最小二乘。模型的拟合程度用**偏差**（deviance）度量，$D = 2(\ell_\text{saturated} - \ell_\text{model})$，即完美拟合每个观测的模型与所拟合模型之间对数似然的缺口的两倍；嵌套模型用偏差的下降来比较，$q$ 个额外参数对应近似 $\chi^2_q$ 的下降（**似然比检验**）。
:::

正态线性模型是取正态分布与恒等链接的 GLM。在生物学中最重要的两个其他成员是 logistic 回归与泊松回归。

### logistic 回归

对二元响应——死或活、有或无、感染或未感染——或 $m$ 次试验中的成功计数，取二项分布配 **logit 链接**得
$$
\ln\frac{p}{1 - p} = \beta_0 + \beta_1x, \qquad\text{等价地}\qquad p = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}}.
$$ {#eq-logistic}
左边是对数优势比。拟合的概率描出一条介于 0 与 1 之间的 S 形曲线，而 $e^{\beta_1}$ 是 $x$ 每增加一个单位的**比值比**（[[biostatistics/categorical-data#def-or]]）。对剂量–反应曲线，杀死半数种群的剂量——**LD₅₀**（半数致死量）——在 $\eta = 0$ 处：$x_{50} = -\beta_0/\beta_1$。

::: example 布利斯的甲虫死亡数据 {#ex-bliss}
布利斯（Chester Bliss）（1935）让成年杂粉甲（*Tribolium confusum*）在八种浓度下暴露于气态二硫化碳五小时，计数死亡数：

| $\log_{10}$ 剂量（mg L⁻¹） | 1.6907 | 1.7242 | 1.7552 | 1.7842 | 1.8113 | 1.8369 | 1.8610 | 1.8839 |
|---|---|---|---|---|---|---|---|---|
| 甲虫数 | 59 | 60 | 62 | 56 | 63 | 59 | 62 | 60 |
| 死亡数 | 6 | 13 | 18 | 28 | 52 | 53 | 61 | 60 |

对死亡率与对数剂量拟合 logistic 回归，估计 LD₅₀，并考察拟合。
::: solution
最大似然（迭代再加权最小二乘，为本课计算，与这些数据的已发表分析一致，例如 Dobson 的 *An Introduction to Generalized Linear Models*）给出
$$
\operatorname{logit} \hat p = -60.72 + 34.27\,x,
$$
标准误为 5.18 与 2.91。斜率的 z 统计量为 $34.27/2.91 = 11.8$，对只含截距模型的似然比检验具有压倒性（偏差从 284.2 降到 11.23，下降 273.0，自由度 1）。

**解读。** $\log_{10}$ 剂量每增加 0.01（浓度增加 2.3 %），死亡的比值比乘以 $e^{0.3427} = 1.41$。LD₅₀ 在 $\log_{10}$ 剂量 $= 60.72/34.27 = 1.7717$ 处，即 $10^{1.7717} = 59.1$ mg L⁻¹；对数尺度上 delta 法标准误 0.0039，给出 95 % 区间 1.764 到 1.779，即 58.1 到 60.1 mg L⁻¹。

**拟合。** 残差偏差为 11.23，自由度 $8 - 2 = 6$（$P = 0.08$）。拟合的死亡数为 3.5、9.8、22.5、33.9、50.1、53.3、59.2 与 58.7：低剂量处观察到的死亡多于拟合，中部则偏少——这提示 logistic 曲线略嫌过于对称。布利斯本人用的是 **probit** 链接（正态分布函数的反函数）；一个不对称的链接，如互补 log–log，对这些数据的拟合明显更好。剂量组数很少时，判断形状的办法是把观察比例对拟合曲线作图。
:::
:::

::: warning "logistic 斜率是概率的变化"
logistic 系数是每单位 $x$ 的*对数优势比*的变化，$e^{\beta}$ 是比值比。每单位 $x$ 的*概率*变化并非常数：它在 $p = 0.5$ 处最大，为 $\beta p(1-p) = \beta/4$，在接近 0 或 1 时微乎其微。对布利斯的甲虫，对数剂量增加 0.01，在 LD₅₀ 附近使死亡率上升约 8.6 个百分点，而在死亡率 2 % 或 98 % 附近不足 1 个百分点。报告比值比，并且为了便于解读，在 $x$ 的相关取值处给出预测概率。
:::

### 泊松回归

对计数——每窝卵数、每个岛屿的物种数、每个宿主的寄生虫数、每个基因的突变数、每个转录本的读段数——取泊松分布配**对数链接**得
$$
\ln\mu = \beta_0 + \beta_1x, \qquad \mu = e^{\beta_0}e^{\beta_1x}.
$$ {#eq-poisson-reg}
效应是乘性的：$x$ 每增加一个单位，期望计数乘以**率比** $e^{\beta_1}$。当计数来自多寡不一的努力（诱捕夜数、测序深度、面积）时，努力量的对数以**偏移量**（offset）的身份进入——一个系数固定为 1 的项——从而使模型描述的是速率。

::: example 物种丰富度与岛屿面积 {#ex-poisson}
16 个面积（$A$，km²）不等的岛屿上陆禽物种数 $S$ 的计数为**模拟**数据（Python，`random.seed(3)`；$\log_{10}A$ 在 0–4 上均匀分布；$S$ 服从均值为 $\exp(1.2 + 0.55\log_{10}A)$ 的泊松分布）。各对 $(\log_{10}A, S)$ 为：

(0.95, 8), (2.18, 13), (1.48, 9), (2.42, 19), (2.50, 13), (0.26, 3), (0.05, 0), (3.35, 25), (1.04, 4), (0.94, 5), (3.98, 26), (1.88, 11), (3.35, 20), (1.91, 14), (2.56, 13), (0.60, 6)。

对 $S$ 关于 $\log_{10}A$ 拟合泊松回归，解读斜率，并检查过散布。
::: solution
最大似然给出 $\ln\hat\mu = 1.288 + 0.541\log_{10}A$，标准误 0.184 与 0.067；$z = 0.541/0.067 = 8.1$，偏差从 83.55（只含截距）降到自由度 14 上的 15.12，下降 68.4，自由度 1。

**解读。** 岛屿面积每增大十倍，期望物种数乘以 $e^{0.541} = 1.72$（95 % 区间 $e^{0.541 \pm 1.96\times0.067}$ = 1.51 到 1.96）。等价地，$\mu = e^{1.288}A^{0.541/\ln10} = 3.63A^{0.235}$：该模型正是经典的**种-面积幂律** $S = cA^z$，其中 $z = 0.235$，接近岛屿上典型的 0.2–0.35（[[ecology]]）。一个 100 km² 的岛屿期望有 $e^{1.288 + 2\times0.541} = 10.7$ 个物种。

**过散布。** 泊松模型假定方差等于均值。残差偏差（15.1）与皮尔逊统计量（11.7）都接近其 14 个自由度，给出散布度估计 $11.7/14 = 0.83$——没有过散布的证据，这正符合从泊松分布模拟出的数据。
:::
:::

真实的计数常常**过散布**：方差超过均值，因为存在未测的异质性或成群聚集（成群分布的寄生虫、斑块状的生境；比较 [[biostatistics/probability-distributions#poisson]]）。忽视过散布会使标准误太小、P 值过于乐观——伪重复的一个统计学亲戚。散布度估计（皮尔逊 χ² / 残差自由度）远大于 1 即提示有问题；补救办法是**准泊松**模型——它把标准误乘以散布度的平方根——或**负二项** GLM，它是 RNA 测序计数的标准模型（如 DESeq2 与 edgeR 包）。零过多时，可能需要零膨胀模型或障碍模型。

::: application 生物学各处的 GLM
logistic 回归把雏鸟成活对孵化日期建模，把物种的有无对生境变量建模（物种分布模型），把萌发概率对温度建模；在遗传学中，全基因组关联研究对每个变异做病例-对照关联分析。用 probit 或 logit 链接的剂量–反应分析在毒理学、农药测试与药理学中是标准做法（其临床用途属于[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)）。泊松回归与负二项回归为后代数、物种数、波动测试中的突变数、测序实验中的读段数等计数建模。生存时间用相关的模型分析——1972 年的 Cox 比例风险模型——在[医学图谱：临床医生的统计](/learn/medicine/lesson.php?c=epidemiology-ebm&l=statistics-for-clinicians)中讲述。
:::

## 模型选择 {#model-selection}

面对若干候选解释变量、交互作用与曲线项，我们应当报告哪个模型？两种大的哲学并存。

**嵌套模型的假设检验。** 用 F 检验（[[#eq-nested-f]]）或似然比检验把一个模型与一个更简单的模型比较，只在数据提出要求时保留一个项。当模型对应具体的科学假说（有交互作用吗？协变量要紧吗？）、且预先指定时，这是恰当的。

**信息准则。** 用一个奖励拟合、惩罚复杂性的准则，比较用同一数据拟合的任意一组模型。

::: definition 赤池信息准则 {#def-aic}
对有最大化的对数似然 $\hat\ell$ 和 $k$ 个待估参数的模型，
$$
\mathrm{AIC} = -2\hat\ell + 2k.
$$ {#eq-aic}
在用同一数据拟合的候选模型中，AIC 最小者被估计为对来自同一过程的新数据作出最好预测（赤池（Hirotugu Akaike），1973）。$\Delta\mathrm{AIC}$ 小于约 2 表示各模型得到的支持相当。小样本时更宜用校正的 $\mathrm{AIC_c} = \mathrm{AIC} + 2k(k+1)/(n - k - 1)$；贝叶斯信息准则 $\mathrm{BIC} = -2\hat\ell + k\ln n$ 对复杂性惩罚得更重。
:::

对 [[#ex-poisson]] 的岛屿数据，只含截距的模型的 AIC 为 148.7，含 $\log_{10}A$ 的模型的 AIC 为 82.3——后者好得多。添加 $\log_{10}A$ 的二次项把 AIC 进一步降到 79.7（$\Delta = 2.6$），二次项的似然比检验给 $\chi^2_1 = 4.63$、$P = 0.031$。然而数据是从线性模型模拟出来的。只有 16 个点时，一次偶然的起伏就足以让更复杂的模型胜出；一位报告“显著的曲线形种-面积关系”的生物学家，报告的其实是噪声。模型选择本身也受抽样误差支配，其结果应当视为暂定。

::: warning "逐步选择能找到重要变量"
按 P 值或 AIC 一次一个地增删变量的自动化逐步程序，被广泛使用，也被广泛批评。选出的模型依赖于步骤的顺序和数据的小改动；其系数偏离零而有偏；其标准误与 P 值无视选择过程因而太小；候选变量一多，它还可靠地“发现”纯属噪声的预测因子（惠廷厄姆（Mark Whittingham）及同事，*Journal of Animal Ecology*，2006）。更可取的做法是：事先凭生物学推理挑选少数几个模型，把它们全部报告出来，考虑模型平均，并用独立数据验证预测。
:::

::: quiz
对巢捕食（是/否）关于到林缘距离（m）的 logistic 回归给出每米 −0.02 的斜率。这是什么意思？
- [ ] 距林缘每远一米，被捕食的概率降低 0.02。
- [x] 距林缘每远一米，被捕食的比值比乘以 $e^{-0.02} = 0.98$；100 m 则乘以 $e^{-2} = 0.14$。
- [ ] 在任何距离上，每远一米被捕食的可能性都低 2 %。
- [ ] 没有 P 值，斜率无法解读。
::: solution
logistic 系数作用在对数优势比上。每米比值比下降约 2 %；100 m 之后降到原来的 14 %。概率的变化取决于你从曲线的哪个位置出发：在 $p = 0.5$ 附近最大，在 0 或 1 附近很小。
:::
:::

::: history
对多个未知量的最小二乘可追溯到勒让德（Adrien-Marie Legendre，1805）与高斯（Carl Friedrich Gauss，1809），而尤勒（George Udny Yule）在 19 世纪 90 年代与 20 世纪初把多元回归与偏相关发展出来用于社会与生物数据。费希尔的方差分析与协方差分析（1920–1930 年代）被认识到是对指示变量的回归的一种形式，这一观点在 1960 年代被系统化。布利斯在 1934–1935 年引入剂量–死亡率数据的 probit 分析，伯克森（Joseph Berkson）1944 年提倡 logit。奈尔德与韦德伯恩 1972 年把正态、二项、泊松等模型统一为广义线性模型，麦库拉格（Peter McCullagh）与奈尔德的 *Generalized Linear Models*（1983，第二版 1989）成为标准教科书。赤池 1973 年提出他的信息准则，莱尔德（Nan Laird）与韦尔（James Ware）1982 年的论文使随机效应模型对重复测量数据变得实用。伯纳姆（Kenneth Burnham）与安德森（David Anderson）的 *Model Selection and Multimodel Inference*（第二版，2002）在生态学家中普及了信息论方法。
:::

::: summary
- 一般线性模型 $\mathbf y = X\boldsymbol\beta + \boldsymbol\varepsilon$ 包含 t 检验、方差分析与回归；$\hat{\boldsymbol\beta} = (X\T X)^{-1}X\T\mathbf y$；嵌套模型用 F 检验比较。
- 因子以指示变量进入；系数是与参照水平之差。
- 多元回归的系数是偏效应；共线性夸大它们的方差（VIF）。
- ANCOVA 在协变量取值相同处比较各组：模拟的蜥蜴在相同 SVL 处相差 0.85 g，而原始均值指向相反方向。
- 交互作用意味着一个因素的效应取决于另一个；存在交互作用时解读简单效应。
- 带随机效应的混合模型处理分组数据与伪重复。
- GLM：分布 + 线性预测器 + 链接，用最大似然法拟合；偏差代替平方和。
- logistic 回归（logit 链接）：$e^\beta$ 是比值比；布利斯的甲虫，LD₅₀ = 59.1 mg L⁻¹。泊松回归（对数链接）：$e^\beta$ 是率比；检查过散布。
- 在少数有生物学理由的模型之间做选择；AIC $= -2\hat\ell + 2k$；不信任逐步选择。
:::

概率 0.8 对应的对数优势比（自然对数）是多少？
::: solution
$\ln(0.8/0.2) = \ln 4 = 1.386$。

::: exercise 一个率比 {level=1 check="1.72"}
在 [[#ex-poisson]] 的岛屿模型中，对 $\log_{10}A$ 的斜率为 0.5409。面积增大十倍时，期望物种数变化多少倍？保留三位有效数字。
::: solution
$e^{0.5409} = 1.72$。

::: exercise 数参数 {level=1 check="12"}
一个三水平因子与一个四水平因子交叉、且含交互作用的两因素方差分析模型，有多少个系数（包括截距）？
::: solution
截距 1，第一因子 $3 - 1 = 2$，第二因子 $4 - 1 = 3$，交互作用 $2\times3 = 6$：共 12 个，每个格均值一个。
:::

::: exercise 一个预测概率 {level=2 check="0.725"}
用布利斯的拟合模型 $\operatorname{logit}\hat p = -60.717 + 34.270x$，在 $\log_{10}$ 剂量 $x = 1.80$ 处预计有多大比例的甲虫死亡？保留三位小数。
::: solution
$\eta = -60.717 + 34.270\times1.80 = 0.969$；$\hat p = 1/(1 + e^{-0.969}) = 0.725$。
:::

::: exercise 比较 AIC {level=2 check="86"}
一个有 3 个参数的模型，其最大化的对数似然为 −40.0；用同一数据拟合的另一个有 5 个参数的模型为 −38.5。计算第一个模型的 AIC，并判断哪个模型更佳。
::: solution
AIC₁ $= 80 + 6 = 86$；AIC₂ $= 77 + 10 = 87$。较简单模型的 AIC 较低，低 1——两者支持相当，对数似然 1.5 的改进并不值得多花两个参数。
:::
:::

::: exercise 作为回归的 t 检验 {level=2}
两组各三株植物的高度为 4、5、6（组 0）与 7、8、9（组 1）。写出 $y = \beta_0 + \beta_1g + \varepsilon$ 的设计矩阵，计算 $\hat\beta_0$、$\hat\beta_1$ 与残差方差，并证明 $\beta_1$ 的 t 统计量等于学生氏的合并 t。
::: answer
$\hat\beta_0 = 5$，$\hat\beta_1 = 3$，$s^2 = 1$，$t = 3.67$。
:::
::: solution
$X$ 有三行 $(1, 0)$ 和三行 $(1, 1)$。正规方程给出 $\hat\beta_0 = \bar y_0 = 5$、$\hat\beta_1 = \bar y_1 - \bar y_0 = 3$。残差为 $-1, 0, 1, -1, 0, 1$，故 $\mathrm{SS_{res}} = 4$，$s^2 = 4/(6 - 2) = 1$。$(X\T X)^{-1}$ 的 $(2,2)$ 元为 $1/3 + 1/3 = 2/3$，所以 $\mathrm{SE}(\hat\beta_1) = \sqrt{2/3} = 0.816$，$t = 3/0.816 = 3.67$，自由度 4。学生氏检验：$s_p^2 = (2\times1 + 2\times1)/4 = 1$，$\mathrm{SE} = \sqrt{1\times(1/3 + 1/3)} = 0.816$，$t = 3.67$——完全相同。
:::
:::

::: exercise 过散布的计数 {level=3}
对 60 只田鼠所带蜱数关于田鼠体重的泊松回归，给出残差偏差 174、自由度 58，皮尔逊 χ² 为 180。(a) 估计散布度。(b) 若报告的体重系数标准误为 0.010、系数为 0.025，泊松模型下的 z 统计量和准泊松模型下的校正统计量各是多少？(c) 给出蜱计数可能过散布的两个生物学理由，以及一个更好的模型。
::: solution
(a) $180/58 = 3.10$：方差约为泊松模型假设的三倍。
(b) 泊松：$z = 0.025/0.010 = 2.5$（$P = 0.012$）。准泊松：标准误乘以 $\sqrt{3.10} = 1.76$，得 0.0176，$t = 1.42$，自由度 58（$P \approx 0.16$）。体重的显著效应原本主要是方差被低估的假象。
(c) 蜱是成群分布的：田鼠的行为、家域、免疫力与微生境不同——这些未测变量使某些田鼠重度染蜱；而且蜱成堆附着（同一卵块孵出的幼蜱）。更合适的是负二项 GLM——它把多余的方差明确建模——或以每只田鼠或每个捕点为随机效应的混合模型。
:::
:::

::: exercise 解读交互作用 {level=3}
一项研究杀虫剂对蜜蜂觅食的影响，对每小时访问花朵数关于杀虫剂（无、有）与温度（低温、高温）做两因素方差分析，交互作用显著。格均值为：低温无杀虫剂 30；低温有杀虫剂 28；高温无杀虫剂 50；高温有杀虫剂 32。(a) 计算每种温度下杀虫剂的效应及交互作用对比。(b) 一份新闻稿说“杀虫剂平均使觅食减少 20 %”。这是一个公允的概括吗？(c) 提出一个生物学解释和一个后续实验。
::: solution
(a) 杀虫剂效应：低温时 $-2$ 次访问 h⁻¹，高温时 $-18$。交互作用对比——这两个效应之差——为 $-18 - (-2) = -16$。
(b) 平均效应是每小时 $-10$ 次访问，对照的平均访问率为 40，即 25 %——但平均掩盖了主要发现：低温条件下几乎没有效应，高温条件下减少 36 %。应当报告条件效应。
(c) 高温条件也许会提高觅食活动、飞行代谢或杀虫剂摄入，于是一种亚致死性的神经毒性效应只有在蜜蜂最活跃时才成为限制因素。后续实验可以测试若干温度（把依赖性拟合成一条曲线）、测量杀虫剂残留与蜜蜂体温，并以群落（而不是个别蜜蜂）为实验单元，在温度区组内随机分配到各处理。
:::
