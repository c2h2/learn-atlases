孟德尔没有测量他的豌豆，而是数它们。圆或皱、黄或绿、紫花或白花——每一株植物或每一粒种子都落入一个类别，他的证据是一张计数表。许多生物学数据都是这种形式：群体样本中的基因型、诱捕器中的物种、实验中的存活者与死亡者、两种生境中感染与未感染的宿主、杂交后代的表型。这类数据谈均值和标准差毫无意义。问题关于**比例**：计数是否吻合某个假说预言的比例，两种分类之间是否有关联？

本章发展所需的工具：卡尔·皮尔逊（Karl Pearson）的 **χ² 适合度检验**（1900），用于孟德尔比例和拟合的泊松分布；用于列联表的 **χ² 独立性检验**；用于小样本的**费希尔精确检验**；以及度量关联强度的**比值比**（优势比）与**相对风险**。本章以一个悖论收尾——粗心合并表格的人都会撞上它。背后的一切概率模型——二项、多项与超几何——在 [[biostatistics/probability-distributions]]；相关的遗传学在 [[genetics/mendelian-inheritance]]。

## 适合度检验 {#goodness-of-fit}

设一个假说预言总体分为 $k$ 个类别，概率为 $p_1, \dots, p_k$（和为 1）——双因子杂交的 9 : 3 : 3 : 1，*Aa* × *Aa* 后代基因型的 ¼ : ½ : ¼，群体样本的哈迪-魏因贝格比例。一个 $n$ 个单元的样本给出观察计数 $O_1, \dots, O_k$。若假说为真，**期望计数**为 $E_i = np_i$，观察计数与它的差别只是抽样变异。皮尔逊的统计量度量总偏离。

::: definition χ² 适合度统计量 {#def-chisq}
$$
X^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i}.
$$ {#eq-chisq}
在零假设之下、且期望计数不太小时，$X^2$ 近似服从自由度为 $\nu = k - 1 - m$ 的 **χ² 分布**，其中 $m$ 是为计算各 $E_i$ 而从数据估计的参数个数。$X^2$ 值大是反对该假说的证据；P 值为 $\Prob(\chi^2_\nu \ge X^2)$。
:::

为什么除以 $E_i$？期望为 $E_i$ 的计数大致有接近 $E_i$ 的类泊松方差（多项分布下恰为 $np_i(1 - p_i)$），所以 $(O_i - E_i)/\sqrt{E_i}$ 近似是一个标准化偏差，而 $X^2$ 近似是若干个标准正态偏差的平方和。这些平方并不独立，因为计数之和必须为 $n$；这个约束拿走一个自由度，每个由数据估计的参数再拿走一个。推导见[数学图谱：假设检验](/learn/maths/lesson.php?c=statistics&l=hypothesis-testing)。

χ² 近似需要足够的期望计数。科克伦（William Cochran）（1954）广为使用的规则要求：没有期望计数低于 1，低于 5 的期望计数不超过 20 %。规则不满足时，合并相邻类别（如果生物学上讲得通），或改用精确检验。

::: example 孟德尔的双因子杂交 {#ex-dihybrid}
孟德尔用两对基因座均为杂合的圆黄种子长成的植株自交（*RrYy* × *RrYy*），数得 556 粒种子：圆黄 315、圆绿 108、皱黄 101、皱绿 32。检验其对自由组合所预言的 9 : 3 : 3 : 1 比例的吻合程度。
::: solution
期望计数为 $556\times(9, 3, 3, 1)/16 = 312.75$、104.25、104.25 与 34.75。于是
$$
X^2 = \frac{(315 - 312.75)^2}{312.75} + \frac{(108 - 104.25)^2}{104.25} + \frac{(101 - 104.25)^2}{104.25} + \frac{(32 - 34.75)^2}{34.75} = 0.0162 + 0.1349 + 0.1013 + 0.2176 = 0.470.
$$
没有估计任何参数（比例来自理论），故 $\nu = 4 - 1 = 3$。$\chi^2_3$ 的 5 % 临界值为 7.815，$\Prob(\chi^2_3 \ge 0.470) = 0.93$。数据与 9 : 3 : 3 : 1 吻合极好：如此大的偏离在 93 % 的此类实验中都会由机会产生。

请注意这个检验*没有*证明什么。结果不显著只表示数据与 9 : 3 : 3 : 1 相容；邻近它的其他比例也会同样吻合。未能拒绝不是证明。
:::
:::

::: widget distribution
dist: chisq
params: k=3
a: 7.815
b: 20
caption: 自由度为 $k = 3$ 的 χ² 分布，即 9 : 3 : 3 : 1 这类四类别比例下 $X^2$ 的零分布。7.815 之外的阴影右尾面积为 0.05：大于它的 $X^2$ 值在 5 % 水平拒绝假说。孟德尔双杂交的结果 $X^2 = 0.47$ 位于很靠左、面积最大的地方。χ² 分布的均值等于其自由度；把 $k$ 改为 1（3 : 1 比例），临界值变为 3.841；改为 10 则变为 18.3。
:::

::: warning "χ² 检验要用百分比，不要用计数"
χ² 统计量必须由实际计数算出。改用百分比（或任何换算尺度的数）会按缩放比例改变 $X^2$：315, 108, 101, 32 化成百分比得 $X^2 = 0.085$，而 5560 粒种子的相同比例会得 $X^2 = 4.70$。证据的强弱取决于数了多少个单元。同样出于这个原因，$X^2$ 不能用于质量或浓度这类测量值，也不能用于不是独立单元的计数（几粒种子被数了两次，或一只动物的许多细胞）。
:::

### 拟合一个分布：参数要付出自由度

::: example 马踢服从泊松分布吗？ {#ex-poisson-fit}
对博尔特凯维奇的数据（[[biostatistics/probability-distributions#ex-horse-poisson]]），在泊松分布之下、以 $\lambda = 0.61$（由数据估计）算得 0、1、2、3 与 ≥ 4 次死亡的期望频数为 108.67、66.29、20.22、4.11 与 0.71。检验其吻合程度。
::: solution
有两个期望计数低于 5，于是合并类别 2、3 与 ≥ 4：观察值 $22 + 3 + 1 = 26$，期望值 $20.22 + 4.11 + 0.71 = 25.04$。于是
$$
X^2 = \frac{(109 - 108.67)^2}{108.67} + \frac{(65 - 66.29)^2}{66.29} + \frac{(26 - 25.04)^2}{25.04} = 0.0010 + 0.0251 + 0.0367 = 0.063.
$$
类别共有 $k = 3$ 个，而有一个参数（$\lambda$）由数据估计，故 $\nu = 3 - 1 - 1 = 1$，$P = 0.80$。泊松分布拟合良好。若是忘了为 $\lambda$ 扣掉那个自由度，检验就会失之过宽，因为往数据上拟合一个参数，会让期望计数比一个真假说所能给的更接近观察值。
:::
:::

### 拟合得过头的时候

适合度检验通常是单侧的：只有大的 $X^2$ 才不利于假说。但*过小*的 $X^2$ 值也可疑，因为它意味着数据与假说的相符程度超出了抽样变异所允许的范围。1936 年费希尔把孟德尔各实验的 χ² 值合并，得到约 41.6，自由度 84：如此接近的吻合，重复一万次也难得一次。他提出数据经过调整，也许是知情的助手所为。争论延续至今：后来的分析（富兰克林（Allan Franklin）及同事收集于 *Ending the Mendel–Fisher Controversy*（《终结孟德尔-费希尔之争》，2008））表明，把有歧义的种子分类时的无意识偏向、决定何时停止计数、或挑选报告哪些实验，都可以在没有蓄意造假的情况下造成这一模式，而费希尔关于孟德尔程序的一些假设本身也可商榷。这段公案正是关于报告全部数据与全部实验之价值的生动教训。

## 列联表：独立性检验 {#independence}

常常每个单元同时按两个分类变量归类，问题是它们是否关联：两种生境中的感染频率不同吗？存活依赖于处理吗？种子形状与种子颜色独立吗？数据构成一张 $r \times c$ 计数 $O_{ij}$ 的**列联表**，行合计为 $R_i$，列合计为 $C_j$，总数为 $N$。

::: proposition 独立性 χ² 检验 {#prop-independence}
若行分类与列分类独立，则在给定边际之下，格 $(i, j)$ 的期望计数为
$$
E_{ij} = \frac{R_i\,C_j}{N},
$$ {#eq-expected}
而统计量 $X^2 = \sum_{i,j}(O_{ij} - E_{ij})^2/E_{ij}$ 近似服从自由度为 $(r - 1)(c - 1)$ 的 $\chi^2$。对格子为 $a, b$（第一行）与 $c, d$（第二行）的 $2\times2$ 表，它简化为
$$
X^2 = \frac{N(ad - bc)^2}{(a + b)(c + d)(a + c)(b + d)}.
$$ {#eq-chisq-2x2}
:::

::: proof 期望计数与自由度
独立之下，$\Prob(\text{第 } i \text{ 行且第 } j \text{ 列}) = \Prob(\text{第 } i \text{ 行})\Prob(\text{第 } j \text{ 列})$。以 $R_i/N$ 与 $C_j/N$ 估计这两个边际概率再乘以 $N$，即得 [[#eq-expected]]。表有 $rc$ 个格，故在给定 $N$ 之下有 $rc - 1$ 个自由比例；独立性模型由 $(r - 1) + (c - 1)$ 个自由边际比例确定。两者之差为 $rc - 1 - (r-1) - (c-1) = (r-1)(c-1)$。
:::

自由度有一个具体的含义：边际一旦固定，$2\times2$ 表只有一个自由格，因为其余三格由减法即得。

::: example 把自由组合作为列联表来检验 {#ex-mendel-independence}
把孟德尔双杂交的计数改写成形状对颜色的 $2\times2$ 表，检验这两个性状是否独立，不对其中任何一个假设 3 : 1 比例。
::: solution

| | 黄色 | 绿色 | 合计 |
|---|---|---|---|
| 圆 | 315 | 108 | 423 |
| 皱 | 101 | 32 | 133 |
| 合计 | 416 | 140 | 556 |

由 [[#eq-expected]] 得期望计数：圆黄 $423\times416/556 = 316.49$，圆绿 106.51，皱黄 99.51，皱绿 33.49。于是 $X^2 = 0.116$，自由度 $(2-1)(2-1) = 1$，$P = 0.73$（由 [[#eq-chisq-2x2]] 算得相同：$556(315\times32 - 108\times101)^2/(423\times133\times416\times140) = 0.116$）。

这个检验与 [[#ex-dihybrid]] 问的是一个不同、也更窄的问题。适合度检验一次检查三件事：形状的 3 : 1 比例、颜色的 3 : 1 比例、以及两者的独立性。列联表检验只检查独立性——圆粒中黄色的比例（315/423 = 0.745）与皱粒中相同（101/133 = 0.759）。这里两个检验一致；但若譬如皱粒存活较差，适合度检验可能不通过而独立性仍成立，列联表检验则能把问题定位出来。
:::
:::

对 $2\times2$ 表，耶茨（Frank Yates）（1934）提出一种**连续性校正**，把 $\lvert ad - bc\rvert$ 换成 $\lvert ad - bc\rvert - N/2$，以补偿计数的离散性。它使检验偏保守（P 值偏大），而在有了现代计算机的今天，小表更好的做法是费希尔精确检验。$X^2$ 的一个近亲是 **G 检验**（似然比检验），$G = 2\sum O\ln(O/E)$，有相同的渐近 χ² 分布；一些生物学家（索卡尔（Sokal）与罗尔夫（Rohlf））偏爱它，因为对嵌套假说 $G$ 值可以相加；对孟德尔双杂交数据 $G = 0.475$，与 $X^2 = 0.470$ 几乎相同。

## 费希尔精确检验 {#fisher-exact}

期望计数很小时，χ² 近似不可靠。费希尔展示了如何通过以表的边际为条件来精确计算 P 值。

::: proposition 费希尔精确检验 {#prop-fisher-exact}
在行合计 $R_1, R_2$ 与列合计 $C_1, C_2$ 固定（总数 $N$）的 $2\times2$ 表中，若行与列独立，左上格的计数 $a$ 服从**超几何分布**
$$
\Prob(a) = \frac{\binom{R_1}{a}\binom{R_2}{C_1 - a}}{\binom{N}{C_1}}.
$$ {#eq-hypergeometric}
双侧 P 值是所有（边际相同的）不比观察表更可能的表的概率之和。
:::

其逻辑就是 [[biostatistics/hypothesis-testing#ex-fisher-perm]] 中随机化检验的逻辑：若处理没有效应，$C_1$ 个"成功"无论落在哪个组都是同一批单元，而单元到组的随机分配会像从瓮中抽球一样把它们散布开。

::: example 品茶的女士 {#ex-tea}
在 *The Design of Experiments* 中，费希尔描述了一位女士（罗斯汉姆斯特德的藻类学家布里斯托（Muriel Bristol））声称能分辨是先倒的奶还是先倒的茶。他提议做一个实验：八杯，两种各四杯，以随机顺序奉上，并告诉她两种各四杯。若她并无此能力，四杯先倒奶的全部猜对的概率是多少？至少猜对三杯呢？
::: solution
她必须在 8 杯里选 4 杯；若无能力，$\binom84 = 70$ 种选法等可能，其中恰有一种全对：$P = 1/70 = 0.014$。她所选四杯中先倒奶的杯数服从超几何分布，即 [[#eq-hypergeometric]] 中 $R_1 = R_2 = C_1 = 4$：$\Prob(3) = \binom43\binom41/70 = 16/70$，故 $\Prob(\ge 3) = 17/70 = 0.243$。

全对的成绩在 5 % 水平显著；四杯中三对则什么也说明不了。费希尔用这个例子说明设计——杯数、随机化、告诉她 4 : 4 的构成——如何事先就决定了一个结果能够证明什么。若是六杯（3 + 3），即使全对也只有 $P = 1/20 = 0.05$。（据统计学家史密斯（H. Fairfield Smith）的记述——萨尔茨伯格（David Salsburg）在 *The Lady Tasting Tea*（《品茶者的测试》，2001）中转述——她八杯全部分对；费希尔的书没有报告结果。）
:::
:::

::: example 小样本实验的费希尔检验 {#ex-fisher-small}
二十只蝌蚪随机分为两组，各 10 只。一组接受某种抗真菌处理，随后两组都暴露于壶菌。处理组有一只、对照组有七只蝌蚪受到感染（假想数据）。比较 χ² 检验与费希尔精确检验。
::: solution

| | 感染 | 未感染 | 合计 |
|---|---|---|---|
| 处理 | 1 | 9 | 10 |
| 对照 | 7 | 3 | 10 |
| 合计 | 8 | 12 | 20 |

每行的期望计数为 4 与 6；四个中有两个低于 5，违背科克伦规则。由 [[#eq-chisq-2x2]] 得未校正 χ² 为 $20(1\times3 - 9\times7)^2/(10\times10\times8\times12) = 7.50$，$P = 0.0062$；加耶茨校正后 $X^2 = 5.21$，$P = 0.022$。

费希尔精确检验：边际为 10, 10, 8, 12，处理组感染数 $a = 0, 1, \dots, 8$ 的概率服从超几何分布。观察表（$a = 1$）的概率为 $\binom{10}{1}\binom{10}{7}/\binom{20}{8} = 10\times120/125\,970 = 0.0095$；加上概率与之相等或更小的表（$a = 0$、$a = 7$、$a = 8$）得双侧 $P = 0.020$。

未校正的 χ² 把证据夸大了三倍。应当报告精确检验：处理减轻感染的证据相当强。
:::
:::

## 度量关联的强度 {#effect-sizes}

P 值说明一个关联能否出于机会；它不说明关联有多强。对两组二元结局的 $2\times2$ 表，有两个标准度量。

::: definition 相对风险与比值比 {#def-or}
设 $p_1 = a/(a + b)$ 与 $p_2 = c/(c + d)$ 为组 1 与组 2 中出现结局的比例。**相对风险**（风险比）为 $\mathrm{RR} = p_1/p_2$。组 1 中该结局的**优势**（odds）为 $p_1/(1 - p_1) = a/b$，**比值比**（优势比）为
$$
\mathrm{OR} = \frac{a/b}{c/d} = \frac{ad}{bc}.
$$ {#eq-or}
独立之下两者都等于 1。比值比的近似 95 % 置信区间为 $\exp\!\left(\ln\mathrm{OR} \pm 1.96\sqrt{1/a + 1/b + 1/c + 1/d}\right)$（伍尔夫（Woolf），1955）。
:::

相对风险更易解读（"处理组蝌蚪的感染频率只有对照组的七分之一"），但比值比有两点技术上的好处：无论比较的是两组间的结局、还是两种结局间的组，它都是同一个数，因此可以从结局频率由设计固定的**病例-对照**样本中估计；而且它是 logistic 回归的自然参数（[[biostatistics/linear-models]]）。结局罕见时两者几乎相等。对蝌蚪而言，$\mathrm{RR} = 0.1/0.7 = 0.14$，$\mathrm{OR} = (1\times3)/(9\times7) = 0.048$，95 % 区间 0.004 到 0.56——正如二十只动物所必有的那样不精确。风险差、需治数以及这些度量在临床研究中的用法，在[医学图谱：疾病的度量](/learn/medicine/lesson.php?c=epidemiology-ebm&l=measuring-disease)中讨论。

::: quiz
一项野外调查中，有鱼池塘的 120 只蛙有 30 只携带某种寄生虫，无鱼池塘的 80 只有 10 只。哪句陈述正确？
- [ ] 比值比是 2.0，与相对风险相同。
- [x] 相对风险是 2.0（0.25 对 0.125），比值比是 2.33。
- [ ] 因为蛙不是随机分配的，不能作 χ² 检验。
- [ ] χ² 检验需要先把计数化成百分比。
::: solution
$p_1 = 30/120 = 0.25$，$p_2 = 10/80 = 0.125$，故 $\mathrm{RR} = 2.0$；优势为 $30/90 = 0.333$ 与 $10/70 = 0.143$，故 $\mathrm{OR} = 2.33$。只要结局常见，比值比就比相对风险离 1 更远。关联的 χ² 检验对调查数据是有效的，但观察性调查中的关联并不表明鱼导致寄生；有鱼的池塘可能在许多其他方面不同（[[biostatistics/experimental-design]]）。
:::
:::

### 配对分类数据

对同一批单元的前后两次分类——50 株植物每株在释放天敌前后的虫害有无，或一组匹配配对中每对的存活与否——不是独立样本。**McNemar 检验**（麦克内马尔（Quinn McNemar），1947）只用不一致配对：若 $b$ 个单元朝一个方向变化、$c$ 个朝另一个方向，则在 $H_0$ 之下每个不一致配对各以一半的机会取某一方向，而 $(b - c)^2/(b + c)$ 近似 $\chi^2_1$（或把 $b$ 精确地交给 $\Bin(b + c, \tfrac12)$ 检验）。它是配对 t 检验在分类数据中的对应物。

## 合并表格：辛普森悖论 {#simpson}

::: example 两块林地的幼苗成活 {#ex-simpson}
一位林学者在两块林地——一块好地、一块差地——检验一种种子包衣（假想数据）。幼苗成活情况：

| 林地 | 包衣 | 未包衣 |
|---|---|---|
| 好地 | 45 / 50（90 %） | 170 / 200（85 %） |
| 差地 | 120 / 200（60 %） | 25 / 50（50 %） |
| 两块地合并 | 165 / 250（66 %） | 195 / 250（78 %） |

包衣有益吗？
::: solution
在每一块林地，包衣幼苗都活*得更好*（90 对 85 %，60 对 50 %）。合并之后反而活*得更差*（66 对 78 %）。反转之所以发生，是因为多数包衣种播在了差地、多数未包衣种播在了好地：林地影响成活，又与处理相关，于是合并就把包衣的效应与林地的效应搅在一起。该看的比较是分林地的比较；包衣看来有益。尊重分层的合并检验，如 Cochran–Mantel–Haenszel 检验，或以林地为因素的 logistic 回归（[[biostatistics/linear-models]]），才是正确的分析——而正确的设计本应在每块林地以相等的比例随机分配包衣与未包衣种子（[[biostatistics/experimental-design]]）。
:::
:::

这就是**辛普森悖论**（辛普森（Edward Simpson）1951 年描述，更早由尤尔（Udny Yule）1903 年描述）：每个亚组中都存在的关联，合并亚组后可能消失甚至反转。它是**混杂**在分类数据中的面孔，混杂在临床数据中的处理见[医学图谱：偏倚与混杂](/learn/medicine/lesson.php?c=epidemiology-ebm&l=bias-confounding)。

::: warning "显著的 χ² 表明一个变量影响另一个变量"
独立性检验检出的是关联，不是因果，也不说明哪个变量依赖于哪个。种子形状与颜色之所以关联，可能是因为两对基因连锁，可能是一种表型影响了对另一种的判定，也可能是不同植株的种子被混在了一起。在观察性表格中，第三个变量（林地、年龄、季节、观测者）可以制造、掩盖或反转一个关联，辛普森悖论即是。因果结论需要随机化实验，或对混杂因素作审慎的因果论证。
:::

::: application 群体遗传学中的哈迪-魏因贝格检验
对一对等位基因的基因，取基因型样本 $n_{AA}$、$n_{Aa}$、$n_{aa}$，与哈迪-魏因贝格比例 $p^2 : 2pq : q^2$ 比较，其中 $p$ 由样本估计为 $(2n_{AA} + n_{Aa})/2n$。三个类别，减去一，再减去一个估计的参数，剩一个自由度。杂合子的缺失可能指示近交、群体结构（Wahlund 效应），而在现代基因分型中更常见的，是无效等位基因（null allele）一类技术故障；全基因组数据套件的常规做法是把偏离哈迪-魏因贝格平衡用作质控过滤。由于罕见变异的基因型计数很小，威金顿（Wigginton）、卡特勒（Cutler）与阿贝卡西斯（Abecasis）（2005）的精确检验——费希尔精确检验的对应物——已取代 χ² 近似。相关理论在 [[population-genetics/hardy-weinberg]] 中展开。
:::

::: history
卡尔·皮尔逊在 1900 年发表于 *Philosophical Magazine* 的一篇论文中引入了 χ² 适合度检验，它是现代统计学的奠基文献之一；他举的例子里包括韦尔登（Walter Weldon）数千次掷骰子的记录。他把同一个统计量用于列联表，但自由度算错了，而费希尔的更正（1922、1924）——估计的参数要减少自由度——开始了两人长期的争论。耶茨 1934 年提出了他的连续性校正。费希尔精确检验出现在 *Statistical Methods for Research Workers* 1934 年版中，品茶实验则在 *The Design of Experiments*（1935）；欧文（Joseph Irwin）与耶茨在大致相同时期独立导出了同一个检验。费希尔对孟德尔数据的批评发表于 1936 年。伍尔夫 1955 年给出了比值比的置信区间，曼特尔（Nathan Mantel）与亨塞尔（William Haenszel）1959 年给出了他们的分层检验。
:::

::: summary
- 适合度检验：$X^2 = \sum(O - E)^2/E$，$\nu = k - 1 - (\text{估计的参数个数})$；必须由计数计算，绝不用百分比。
- 孟德尔双因子杂交（315, 108, 101, 32）：对 9 : 3 : 3 : 1，$X^2 = 0.470$，$\nu = 3$，$P = 0.93$。
- 马踢数据对拟合泊松：$X^2 = 0.063$，$\nu = 1$，$P = 0.80$；每个估计的参数都要付出一个自由度。
- $r\times c$ 表的独立性：$E_{ij} = R_iC_j/N$，$\nu = (r-1)(c-1)$。
- 期望计数很小时（科克伦：无一低于 1，低于 5 的至多 20 %）用费希尔精确（超几何）检验；品茶女士须四杯全对（$P = 1/70$）。
- 报告关联的强度：相对风险 $p_1/p_2$ 与比值比 $ad/bc$，并附置信区间。
- 配对分类数据：对不一致配对作 McNemar 检验。
- 合并分层可能反转关联（辛普森悖论）；关联不是因果。
:::

## 练习

::: exercise 单因子比例 {level=1 check="0.263"}
孟德尔数得圆粒 5474 粒、皱粒 1850 粒。计算针对 3 : 1 假说的 $X^2$，保留三位有效数字。
::: solution
$E = 5493$ 与 1831。$X^2 = 19^2/5493 + 19^2/1831 = 0.0657 + 0.1972 = 0.263$，自由度 1（$P = 0.61$）。
:::
:::

::: exercise 一个期望计数 {level=1 check="24"}
在 $N = 200$ 的 $2\times3$ 表中，第一行合计 80，第二列合计 60。独立性之下格 (1, 2) 的期望计数是多少？
::: solution
$E_{12} = 80\times60/200 = 24$。
:::
:::

::: exercise 自由度 {level=1 check="6"}
一项调查把 400 头甲虫按物种（4 种）和生境（3 种）分类。χ² 独立性检验的自由度是多少？
::: solution
$(4 - 1)(3 - 1) = 6$。
:::
:::

::: exercise 比值比 {level=2 check="2.33"}
计算随堂测验中蛙调查（有鱼者 120 只中 30 只感染，无鱼者 80 只中 10 只）的比值比，保留三位有效数字。
::: solution
$\mathrm{OR} = (30\times70)/(90\times10) = 2100/900 = 2.33$。
:::
:::

::: exercise 性别比的二项检验 {level=2 check="0.115"}
一窝在海温下孵化的海龟卵 20 枚，产出雌性 14 只、雄性 6 只。计算针对 $H_0\colon$ 性别比 1 : 1 的精确双侧二项 P 值，保留三位有效数字。
::: solution
$H_0$ 之下 $X \sim \Bin(20, \tfrac12)$。$\Prob(X \ge 14) = \sum_{k=14}^{20}\binom{20}{k}/2^{20} = 60\,460/1\,048\,576 = 0.0577$，由对称性双侧 $P = 0.115$。（而且，同一窝卵共享母亲与巢穴，并非完全独立；这个检验说的是这一窝。）
:::
:::

::: exercise 哈迪-魏因贝格检验 {level=2}
200 株植物的样本含 *AA* 88、*Aa* 80、*aa* 32。估计 *A* 的等位基因频率 $p$，算出哈迪-魏因贝格期望计数，并检验吻合程度。
::: answer
$p = 0.64$；期望 81.92、92.16、25.92；$X^2 = 3.48$，自由度 1，$P = 0.062$。
:::
::: solution
$p = (2\times88 + 80)/400 = 256/400 = 0.64$，$q = 0.36$。期望：$200p^2 = 81.92$，$200\times2pq = 92.16$，$200q^2 = 25.92$。$X^2 = 6.08^2/81.92 + 12.16^2/92.16 + 6.08^2/25.92 = 0.451 + 1.604 + 1.426 = 3.48$。自由度 $3 - 1 - 1 = 1$，$P = 0.062$：杂合子缺失值得注意，但在 5 % 下不显著。解读之前应核查基因分型，并考虑群体结构的可能。
:::
:::

::: exercise 杯子太少 {level=3}
(a) 在费希尔 $2m$ 杯（两种各 $m$ 杯）的茶实验中，靠猜测得满分的成绩的概率是多少？(b) 使满分成绩在 1 % 水平显著的最小的 $m$ 是多少？(c) 费希尔的设计告诉了女士两种各四杯。倘若改为 8 杯各自独立地以概率 ½ 是先倒奶或先倒茶，她须逐杯判定。靠猜测得满分成绩的概率是多少？这个设计得到了什么，又失去了什么？
::: solution
(a) $1/\binom{2m}{m}$。
(b) $\binom63 = 20$（$P = 0.05$），$\binom84 = 70$（$P = 0.014$），$\binom{10}{5} = 252$（$P = 0.0040$）。故 $m = 5$，十杯。
(c) $(1/2)^8 = 1/256 = 0.0039$：相当于更多杯的信息量，因为每次判定都是一个独立的二元试验。得到的是满分成绩对应的更小的 P 值；失去的是两种杯数的随机性（完全可能 8 杯中有 7 杯先倒奶，使检验显得失衡），而且检验不再能控制一位倾向于说"先倒奶"的女士。费希尔的设计使分析只取决于她给杯子排序的能力，其边际则由实验者固定。
:::
:::

::: exercise 检出连锁 {level=3}
测交 *AaBb* × *aabb* 得后代 200 只：*AB* 62、*Ab* 38、*aB* 41、*ab* 59（表型类别）。(a) 检验其对未连锁基因所预期的 1 : 1 : 1 : 1 比例的吻合。(b) 在 $2\times2$ 表中检验两个基因座的独立性。(c) 估计重组率，并解释两个检验检出的东西为何可能不同。
::: solution
(a) 各类 $E = 50$；$X^2 = (144 + 144 + 81 + 81)/50 = 9.00$，自由度 3，$P = 0.029$。
(b) 表：行 *A*/*a*（100, 100），列 *B*/*b*（103, 97）。期望：51.5、48.5、51.5、48.5。由 [[#eq-chisq-2x2]]，$X^2 = 200(62\times59 - 38\times41)^2/(100\times100\times103\times97) = 200(3658 - 1558)^2/99\,910\,000 = 200\times4\,410\,000/99\,910\,000 = 8.83$，自由度 1，$P = 0.003$。
(c) 重组型是 *Ab* 与 *aB*：$(38 + 41)/200 = 0.395$，低于 0.5，故两基因座看来连锁，图距约 40（[[genetics/linkage-mapping]]）。四类别适合度检验把连锁的信号连同每个基因座上任何分离畸变一起摊到 3 个自由度上；$2\times2$ 检验集中到连锁唯一改变的东西——两个基因座之间的关联——因此检出它更有效力。这里两个检验都给出连锁的证据，但有针对性的检验强得多。
:::
