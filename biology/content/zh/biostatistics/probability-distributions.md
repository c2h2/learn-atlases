为什么两个杂合亲本的四个后代中有时根本没有隐性个体，而孟德尔的比例说四个中应有一个？为什么博尔特凯维奇的马踢死亡数遵循如此规律的模式，尽管每一次死亡都是一场意外？为什么那么多生物学测量值呈钟形？这些回答都来自概率——机会的数学。概率是一个统计模型陈述"若某假说为真，数据*将会*是什么样子"所用的语言，因此本课程中每一个估计、每一个检验都以它为基础。

本章介绍生物学中使用的概率法则、随机变量及其分布的概念，以及无处不在的三个分布：固定次数试验中成功数目的**二项分布**（binomial）、稀有独立事件计数的**泊松分布**（Poisson）、许多小效应之和的测量值的**正态分布**（normal）。带证明的严格理论在数学图谱：[概率空间](/learn/maths/lesson.php?c=probability&l=probability-spaces)、[离散随机变量](/learn/maths/lesson.php?c=probability&l=discrete-random-variables)、[连续随机变量](/learn/maths/lesson.php?c=probability&l=continuous-random-variables)与[极限定理](/learn/maths/lesson.php?c=probability&l=limit-theorems)。

## 概率法则 {#rules}

我们把一次观察——一个合子的基因型、一窝卵的数目、一只小鼠的体重——看作一次**随机试验**的结果：其结果不能精确预言，但可能出现的种种结果及其倾向可以描述。**事件**是若干结果的集合："后代为隐性表型"、"窝卵数超过五枚"。

::: definition 概率及其法则 {#def-probability}
**概率**给每个事件 $A$ 指派一个介于 0 与 1 之间的数 $\Prob(A)$，使必然事件的概率为 1，并且对不能同时发生的事件（**互斥**事件）概率可加：

$$
\Prob(A \text{ 或 } B) = \Prob(A) + \Prob(B) \quad \text{当 } A \text{ 与 } B \text{ 互斥}
$$

由此可得**逆事件法则** $\Prob(\text{非 } A) = 1 - \Prob(A)$ 与**一般加法法则** $\Prob(A \text{ 或 } B) = \Prob(A) + \Prob(B) - \Prob(A \text{ 且 } B)$。

在 $B$ 之下 $A$ 的**条件概率**（要求 $\Prob(B) > 0$）为
$$
\Prob(A \mid B) = \frac{\Prob(A \text{ 且 } B)}{\Prob(B)},
$$
于是 $\Prob(A \text{ 且 } B) = \Prob(A \mid B)\,\Prob(B)$（**乘法法则**）。若 $\Prob(A \mid B) = \Prob(A)$，等价地 $\Prob(A \text{ 且 } B) = \Prob(A)\Prob(B)$，则事件 $A$ 与 $B$ **独立**。
:::

概率可以解读为长期相对频率——巨大杂交中隐性表型后代的比例——也可以解读为信念的强度。法则是一样的；频率解读是本课程大多数经典方法采用的解读，贝叶斯解读在[数学图谱：贝叶斯推断](/learn/maths/lesson.php?c=statistics&l=bayesian)中展开。

孟德尔遗传学是概率的实验室。杂交 *Aa* × *Aa* 中，每个亲本以概率 ½ 传递 *A* 或 *a*，且与另一亲本无关（孟德尔第一定律，[[genetics/mendelian-inheritance]]）。由乘法法则，四种组合各有概率 ¼；由加法法则，杂合子（*Aa* 或 *aA*）的概率为 ½，显性表型（*AA* 或 *Aa*）的概率为 ¾。

::: example 一个家庭中的条件概率 {#ex-carrier}
一对表型正常的夫妇生下一个患隐性遗传病的孩子，因此双亲必均为杂合子 *Aa*。他们的第二个孩子表型正常。这第二个孩子是携带者（*Aa*）的概率是多少？
::: solution
在知道表型之前，孩子是 *AA* 的概率为 ¼，*Aa* 为 ½，*aa* 为 ¼。得知孩子正常就排除了 *aa*，即对事件"*AA* 或 *Aa*"（概率 ¾）取条件：
$$
\Prob(Aa \mid \text{正常}) = \frac{\Prob(Aa)}{\Prob(\text{正常})} = \frac{1/2}{3/4} = \frac23.
$$
答案不是 ½：知道表型会改变各基因型的概率。这是谱系分析所用推理的最简单例子。（真实家庭的遗传咨询属于[医学图谱：遗传学](/learn/medicine/course.php?c=genetics)。）
:::
:::

::: warning ""独立"就是"互斥""
互斥的两个事件不能同时发生，所以一个发生另一个就必然不发生——它们是所能见的*最依赖*的事件。独立指的是知道一个发生了并不能告诉你任何关于另一个的信息。不同染色体上的两个基因座自由组合；同一基因座上"这个配子携带 *A*"与"这个配子携带 *a*"两个事件互斥。独立事件的概率相乘；互斥事件的概率相加。
:::

逆事件法则的一个有用推论：某事在 $n$ 次独立的尝试中、每次概率 $p$、*至少*发生一次的概率是 $1 - (1 - p)^n$。若 1000 个独立基因座每个都有 0.1 % 的出错机会，至少出一个错的概率是 $1 - 0.999^{1000} = 0.632$，而不是 1。同样的算术用于统计检验，就是 [[biostatistics/hypothesis-testing]] 的多重检验问题。

## 随机变量及其分布 {#random-variables}

::: definition 随机变量、分布、均值与方差 {#def-random-variable}
**随机变量** $X$ 是由随机试验的结果决定的数值量。它的**概率分布**说明概率如何散布在其各取值上：

- 对**离散**随机变量，用概率函数 $\Prob(X = k)$；
- 对**连续**随机变量，用概率密度 $f(x)$，$\Prob(a \le X \le b) = \int_a^b f(x)\,dx$。

**期望值**（均值）为 $\mu = \E[X] = \sum_k k\,\Prob(X = k)$ 或 $\int x f(x)\,dx$；**方差**为 $\sigma^2 = \Var(X) = \E[(X - \mu)^2]$；$\sigma$ 为标准差。**累积分布函数**为 $F(x) = \Prob(X \le x)$。
:::

这些是 [[biostatistics/data-and-variation]] 中样本均值、样本方差与直方图的总体对应物：大样本的直方图近似概率分布，$\bar x$ 与 $s^2$ 近似 $\mu$ 与 $\sigma^2$。两条关于均值与方差的法则被不断使用：对常数 $a$、$b$，$\E[a + bX] = a + b\E[X]$，$\Var(a + bX) = b^2\Var(X)$；对任意随机变量 $\E[X + Y] = \E[X] + \E[Y]$；而对*独立*的随机变量 $\Var(X + Y) = \Var(X) + \Var(Y)$。独立量的方差可加；标准差不可加。

## 二项分布 {#binomial}

许多生物学计数是固定次数独立试验中的"成功"数目：一窝中的雌性后代、50 粒播种种子中发芽的、杂交后代中的隐性表型、样本中被感染的宿主。

::: definition 二项分布 {#def-binomial}
设有 $n$ 次独立的试验，每次以同一概率 $p$ 成功。成功数目 $X$ 服从**二项分布**（binomial distribution）$\Bin(n, p)$：
$$
\Prob(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \dots, n,
$$ {#eq-binomial}
其中 $\binom nk = \dfrac{n!}{k!\,(n-k)!}$ 是从 $n$ 次试验中选出哪 $k$ 次成功的方法数。
:::

这个公式由两部分组成：$p^k(1-p)^{n-k}$ 是含 $k$ 次成功的任何一个*特定*序列的概率（独立试验的乘法法则），$\binom nk$ 是这种序列的数目（加法法则）。假设与公式同等重要：$n$ 固定、独立、每次试验的 $p$ 相同。同一母亲的后代可能共享子宫环境；同一植株的种子可能共享基因型；同一池塘的宿主可能共享感染源。这些都会破坏独立性或恒定的 $p$，通常使计数比二项分布所预言的更可变——**过散布**，我们在 [[biostatistics/linear-models]] 中再谈。

::: proposition 二项分布的均值与方差 {#prop-binomial-moments}
若 $X \sim \Bin(n, p)$，则 $\E[X] = np$，$\Var(X) = np(1-p)$。因此成功比例 $\hat p = X/n$ 的均值为 $p$，方差为 $p(1-p)/n$。
:::

::: proof
把 $X$ 写成 $X = Y_1 + \dots + Y_n$，其中第 $i$ 次试验成功时 $Y_i = 1$，否则为 0。每个 $Y_i$ 的均值 $\E[Y_i] = 1\cdot p + 0\cdot(1-p) = p$；又因 $Y_i^2 = Y_i$，方差为 $\E[Y_i^2] - p^2 = p - p^2 = p(1-p)$。均值可加；由于试验独立，方差也可加，得 $np$ 与 $np(1-p)$。把 $X$ 除以 $n$，均值除以 $n$，方差除以 $n^2$。
:::

::: example 十个后代中的隐性个体 {#ex-binomial}
杂交 *Aa* × *Aa* 产下十个后代。写出其中隐性表型数目 $X$ 的分布、均值与标准差，并求 (a) 一个隐性也没有、(b) 五个及以上为隐性 的概率。
::: solution
$X \sim \Bin(10, \tfrac14)$。由 [[#eq-binomial]]，$k = 0, 1, \dots, 6$ 的概率为

| $k$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $\Prob(X = k)$ | 0.0563 | 0.1877 | 0.2816 | 0.2503 | 0.1460 | 0.0584 | 0.0162 |

其余取值之和为 0.0035。均值为 $np = 2.5$，标准差 $\sqrt{10\times0.25\times0.75} = 1.37$。

(a) $\Prob(X = 0) = 0.75^{10} = 0.0563$：约每十八个这样的家庭就有一个完全没有隐性后代。

(b) $\Prob(X \ge 5) = 0.0584 + 0.0162 + 0.0035 = 0.0781$。

恰好 2.5 个隐性个体是不可能的，甚至最可能的计数 2 出现的概率也不足 30 %。小家庭偏离孟德尔比例是家常便饭；这就是孟德尔要数以千粒的种子、[[biostatistics/categorical-data]] 要检验偏离是否大于机会所能产生的原因。
:::
:::

caption: [[#ex-binomial]] 的二项分布：*Aa* × *Aa* 的 $n = 10$ 个后代中隐性表型的数目。阴影柱为 $\Prob(5 \le X \le 10) \approx 0.078$；曲线是均值与标准差相同的正态近似。$n = 10$、$p = 0.25$ 时柱形明显偏态，曲线拟合很差。把 $n$ 增到 50 或 100，看柱形如何变对称、如何贴合正态曲线；把 $p$ 移向 0.5，贴合得更快。

## 泊松分布 {#poisson}

有些计数没有固定的试验次数：一代中一个基因内的突变数、一个样方中的幼苗数、一毫秒内到达一个光感受器的光子数、一个军团一年中被马踢死的人数。事件发生的机会很多，而每个机会的概率极小。

::: definition 泊松分布 {#def-poisson}
若计数 $X$ 满足
$$
\Prob(X = k) = \frac{e^{-\lambda}\lambda^k}{k!}, \qquad k = 0, 1, 2, \dots
$$ {#eq-poisson}
则它服从以 $\lambda > 0$ 为均值的**泊松分布**（Poisson distribution）。其均值与方差都等于 $\lambda$。它描述在时间或空间中以恒定平均速率彼此独立地发生的事件，$\lambda$ 即速率乘以所观察的时间、面积或体积。
:::

::: proposition 二项分布的泊松极限 {#prop-poisson-limit}
若 $X \sim \Bin(n, p)$，$n \to \infty$、$p \to 0$ 而 $np = \lambda$ 保持不变，则对每个 $k$，$\Prob(X = k) \to e^{-\lambda}\lambda^k/k!$。
:::

::: proof
取 $p = \lambda/n$，
$$
\binom nk p^k(1-p)^{n-k} = \frac{n(n-1)\cdots(n-k+1)}{n^k}\cdot\frac{\lambda^k}{k!}\cdot\left(1 - \frac\lambda n\right)^n\left(1 - \frac\lambda n\right)^{-k}.
$$
$k$ 固定、$n \to \infty$ 时，第一个因子趋于 1，第三个趋于 $e^{-\lambda}$，第四个趋于 1。
:::

泊松分布因此是稀有事件的法则。由于其方差等于均值，比值 $s^2/\bar x$ ——**离散指数**——是空间或时间格局的快速诊断。比值接近 1 与随机（泊松）发生相容；远大于 1 表明**聚集**（个体群集，如宿主身上的寄生虫或植株上的蚜虫）；远小于 1 表明**均匀**（如领域性鸟类彼此间隔，或幼苗相互竞争）。

::: example 马踢与泊松分布 {#ex-horse-poisson}
博尔特凯维奇的 200 个军团·年（[[biostatistics/data-and-variation#ex-horse-kicks]]）均值 0.61 人死亡。计算 $\lambda = 0.61$ 的泊松分布下的期望频率，与观察值 109、65、22、3、1 比较。
::: solution
$e^{-0.61} = 0.5434$。把 [[#eq-poisson]] 乘以 200：

| 死亡数 $k$ | 0 | 1 | 2 | 3 | 4 及以上 |
|---|---|---|---|---|---|
| 观察 | 109 | 65 | 22 | 3 | 1 |
| 期望 $200\,e^{-0.61}0.61^k/k!$ | 108.67 | 66.29 | 20.22 | 4.11 | 0.71 |

（最后一列是 200 减去其余各列之和，因而包含了所有 $k \ge 4$。）吻合之好令人瞩目，方差 0.611 几乎恰为均值。正式的适合度检验见 [[biostatistics/categorical-data]]。吻合并不意味着马按某种规律踢人；它意味着每一次死亡都是一个稀有事件，彼此独立，且在各军团各年间的速率大致恒定——正是泊松分布产生的条件。
:::
:::

::: application 波动试验：关于突变的泊松推理
1943 年，卢里亚（Salvador Luria）与德尔布吕克（Max Delbrück）追问：大肠杆菌（*Escherichia coli*）的噬菌体抗性突变体是在接触噬菌体后应激产生，还是在此之前随机产生。若抗性是接触时诱导的，每个与噬菌体一起涂板的细菌都有相同的、成为抗性的微小机会，平行培养物涂板的抗性菌落数目将服从泊松分布，方差约等于均值。若突变在每次培养物的生长过程中随机发生，一次发生在早期培养物中的突变会留下一个庞大的抗性后代克隆——"大奖"——计数的变异将远超泊松。卢里亚与德尔布吕克发现方差超过均值许多倍，这是突变自发的标志。本章使之常规化的方差与均值之比，为他们赢得了 1969 年诺贝尔生理学或医学奖的一部分，并开创了细菌遗传学。
:::

## 正态分布 {#normal}

::: definition 正态分布 {#def-normal}
若连续随机变量 $X$ 的密度为
$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x - \mu)^2}{2\sigma^2}\right), \qquad -\infty < x < \infty,
$$ {#eq-normal}
则它服从（高斯）正态分布（normal/Gaussian distribution）$\Normal(\mu, \sigma^2)$。其均值为 $\mu$，标准差为 $\sigma$。**标准正态分布**是 $\Normal(0, 1)$；其累积分布函数记作 $\Phi(z)$。
:::

曲线关于 $\mu$ 对称、呈钟形，拐点在 $\mu \pm \sigma$ 处。无论 $\mu$ 与 $\sigma$ 取何值，落在均值给定倍数个标准差之内的概率都相同：一个标准差内约 68.3 %，两个内 95.4 %，三个内 99.7 %。更准确地说，95 % 落在 $\pm1.960\sigma$ 之内——本课程大多数 95 % 区间背后的那个数。

::: proposition 标准化与正态变量之和 {#prop-normal}
若 $X \sim \Normal(\mu, \sigma^2)$，则 $Z = (X - \mu)/\sigma \sim \Normal(0, 1)$，于是 $\Prob(X \le x) = \Phi\big((x - \mu)/\sigma\big)$。若 $X_1$ 与 $X_2$ 独立且正态，则 $a X_1 + b X_2$ 正态，均值 $a\mu_1 + b\mu_2$，方差 $a^2\sigma_1^2 + b^2\sigma_2^2$。特别地，$n$ 个独立的 $\Normal(\mu, \sigma^2)$ 观测的均值恰为 $\Normal(\mu, \sigma^2/n)$。
:::

正态族对求和封闭的证明见[数学图谱：联合分布](/learn/maths/lesson.php?c=probability&l=joint-distributions)；均值与方差由上面的法则直接得出。量 $z = (x - \mu)/\sigma$ 是 **z 值**（z 分数）：观测偏离均值多少个标准差。

::: example *Iris setosa* 的萼片长度 {#ex-normal}
安德森 50 朵 *Iris setosa* 样本的萼片长度均值 5.006 cm、标准差 0.352 cm，分布大致正态。把它们当作总体值：(a) 多大比例的植株萼片长于 5.5 cm？(b) 中央 95 % 的植株长度介于哪两个值之间？
::: solution
(a) $z = (5.5 - 5.006)/0.3525 = 1.401$，$\Prob(Z > 1.401) = 1 - \Phi(1.401) = 0.081$：约 8 % 的植株。实际样本中长于 5.5 cm 的有 50 株中的 3 株（6 %），在 50 株样本的抽样变异意义下与此相容。

(b) $5.006 \pm 1.960\times0.3525 = 4.32$ 至 $5.70$ cm。这是针对单株的参考范围——是关于总体散布的陈述，不是关于均值精确度的陈述（对照 [[biostatistics/estimation]]）。
:::
:::

### 为什么那么多性状正态

正态分布不是自然法则，但只要一个量是许多小的、独立的贡献之和，它就会产生。这就是**中心极限定理**，其严格陈述见 [[biostatistics/estimation]]，证明见[数学图谱：极限定理](/learn/maths/lesson.php?c=probability&l=limit-theorems)。高尔顿造了一台机器演示它：小球逐排落下穿过一排排针，每排都被随机拨向左或右，最终堆成钟形。

::: widget galton
caption: 高尔顿板。每个小球在每一排针处都被随机向左或向右拨动，所以它最终落入的格子号就是向右拨动的次数——一个二项计数。随着小球累积，直方图趋近正态曲线。这是费希尔 1918 年解释连续变异的模型背后的道理：受许多微效基因（加上环境效应）相加影响的性状是许多小贡献之和，因而接近正态。
:::

费希尔 1918 年的论文"根据孟德尔遗传假设讨论亲属间的相关"使孟德尔的离散基因与高尔顿和皮尔逊测得的连续钟形变异达成和解：许多基因座，每个都按孟德尔方式分离，总和起来使表型呈正态分布。当这些微小效应*相乘*而非相加时——如生长率随时间复利——成为和的是性状的对数，性状就呈对数正态（[[biostatistics/data-and-variation#transformations]]）。

### 二项分布的正态近似

$n$ 大时，二项计数是许多独立的 0–1 变量之和，故由中心极限定理近似正态，均值 $np$，方差 $np(1-p)$。常用的经验规则要求 $np$ 与 $n(1-p)$ 都至少为 5 或 10。由于二项分布是离散的，用**连续性校正**可改进近似：$\Prob(X \le k)$ 用 $\Phi\big((k + 0.5 - np)/\sqrt{np(1-p)}\big)$ 近似。

::: example 孟德尔的圆粒与皱粒种子 {#ex-mendel-normal}
孟德尔单因子杂交的 7324 粒种子中，圆粒 5474、皱粒 1850。按 3 : 1 比例，期望的圆粒数是多少？标准差多大？观察计数有多不寻常？
::: solution
$X \sim \Bin(7324, \tfrac34)$，均值 $7324\times0.75 = 5493$，标准差 $\sqrt{7324\times0.75\times0.25} = 37.06$。观察计数距期望 $(5474 - 5493)/37.06 = -0.51$ 个标准差，是一个再平常不过的偏离：约 61 % 的样本朝某一方向的偏离至少这么大。3 : 1 比例吻合。（孟德尔的全部数据是否吻合得*太*好，是费希尔 1936 年提出的著名问题；见 [[biostatistics/categorical-data]]。）
:::
:::

::: quiz
对一片草地的样方计数均值为每样方 4.2 株，方差 12.8。这说明什么？
- [ ] 植物随机分布，因为计数是离散的。
- [x] 植物聚集分布：方差约为均值的三倍，超过泊松分布所给的值。
- [ ] 植物均匀分布，因为方差大于均值。
- [ ] 什么也说明不了，因为均值与方差的单位不同。
::: solution
泊松（随机）格局的方差等于均值；这里 $s^2/\bar x = 12.8/4.2 = 3.0$。超额的方差意味着有的样方植物很多、有的很少——群集，也许由于种子散布在母株近旁，或土壤斑块。均匀分布会使比值小于 1。（3.0 是否显著大于 1 取决于样方数目；统计量 $(n-1)s^2/\bar x$ 在泊松假设下近似服从自由度 $n - 1$ 的 χ² 分布。）
:::
:::

### 正态性检查

后面章节的许多方法假定数据或模型残差大致正态。最好的检查是图形的。**正态 Q–Q 图**（分位数-分位数图）把排序的观测对同样本量的正态分布所预测的分位数作图。正态数据落在一条直线附近；右偏使上端向上弯；厚尾产生 S 形；离群值在两端脱离直线。正式的检验（夏皮罗-威尔克（Shapiro-Wilk），1965，最常用）帮助有限：小样本几乎查不出什么，大样本则查出无伤大雅的微小偏离。所幸正如 [[biostatistics/estimation]] 所示，样本不太小时，关于均值的方法对中度的非正态是稳健的。

::: warning "生物数据服从正态分布"
许多并不服从：计数、比例、存活时间、浓度、多度，以及任何以零为硬下界且散布大的量，往往偏态；而各组的混合可以呈双峰。正态分布是一个待检验的模型，不是默认假定。常常近似正态的是许多观测的*均值*，无论底层分布什么形状——这是另一个命题。
:::

## 其他值得了解的分布 {#others}

还有几个分布在生物学中出现得足够频繁，值得辨认：

- **几何分布**（geometric distribution）计数到第一次成功所需的试验数；**指数分布**（exponential distribution）是其连续类似物：泊松过程中事件之间的等待时间，如一次放射性衰变、一个通道开放（[[cell-biology/membrane-transport]]）或一个突变之前的时间。它无记忆：下一秒发生事件的机会不依赖于已经等了多久。
- **负二项分布**（negative binomial distribution）是过散布计数的标准模型，如寄生虫负荷或 RNA 测序的读段计数，其方差 $\mu + \mu^2/k$ 超过均值。
- **超几何分布**（hypergeometric distribution）计数从一个有限总体中不放回抽样所获的成功数。它是费希尔精确检验（[[biostatistics/categorical-data]]）与基因组学基因集富集检验的基础。
- **t 分布**、**χ² 分布**与 **F 分布**是从正态样本算出的*统计量*的分布，而不是原始数据的模型；它们出现在 [[biostatistics/estimation]]、[[biostatistics/categorical-data]] 与 [[biostatistics/comparing-groups]] 中。

::: history
概率始于博弈：帕斯卡（Blaise Pascal）与费马（Pierre de Fermat）在 1654 年就赌博难题通信；雅各布·伯努利（Jacob Bernoulli）的 *Ars Conjectandi*（《猜度术》，1713）对我们现在称为贝努利试验的情形证明了第一个大数定律。棣莫弗（Abraham de Moivre）在 1733 年把正态曲线作为二项分布的近似找到；拉普拉斯（Pierre-Simon Laplace）与高斯（Carl Friedrich Gauss）在 1810 年前后把它发展为天文测量误差的法则。泊松（Siméon-Denis Poisson）在 1837 年把泊松分布作为二项分布的极限导出；博尔特凯维奇的 *Das Gesetz der kleinen Zahlen*（《小数目法则》，1898；英译 *The Law of Small Numbers*）以马踢数据使之闻名。孟德尔 1866 年关于 *Pisum sativum* 的论文，除其他外，是第一次用概率解释遗传。高尔顿在 *Natural Inheritance*（《自然遗传》，1889）中描述了他的跳珠板。费希尔 1918 年的论文把孟德尔遗传与连续性状的正态分布统一起来；卢里亚与德尔布吕克 1943 年的波动试验用计数的方差证明突变随机产生。
:::

::: summary
- 互斥事件的概率相加；独立事件的概率相乘；$\Prob(A \mid B) = \Prob(A \text{ 且 } B)/\Prob(B)$。$n$ 次独立尝试中至少发生一次的概率是 $1 - (1-p)^n$。
- 随机变量有均值 $\mu$、方差 $\sigma^2$ 的分布；均值恒可加，独立变量的方差可加。
- 二项分布 $\Bin(n, p)$：$n$ 次独立试验、恒定 $p$ 下的成功数；均值 $np$，方差 $np(1-p)$。
- 泊松分布：恒定速率的稀有独立事件；均值 = 方差 = $\lambda$。离散指数 $s^2/\bar x$ 诊断聚集（> 1）或均匀（< 1）。
- 正态分布 $\Normal(\mu, \sigma^2)$：许多小的独立效应之和；95 % 在 $\mu \pm 1.96\sigma$ 内；用 $z = (x - \mu)/\sigma$ 标准化。
- 大样本二项计数近似正态（用连续性校正）；乘性效应给出对数正态性状。
- 用图形（尤其是 Q–Q 图）而不是假定来检查分布假设。
:::

## 练习

::: exercise 四个显性后代 {level=1 check="0.316"}
杂交 *Aa* × *Aa* 的四个后代全部表现显性表型的概率是多少？保留三位小数。
::: solution
每个后代独立地以概率 ¾ 为显性表型，故概率为 $(3/4)^4 = 81/256 = 0.316$。
:::
:::

::: exercise 空的样方 {level=1 check="0.135"}
幼苗随机散布，平均每样方 2 株。一个样方一株都没有的概率是多少？保留三位小数。
::: solution
泊松分布 $\lambda = 2$：$\Prob(X = 0) = e^{-2} = 0.135$。
:::
:::

::: exercise 恰好两个隐性 {level=1 check="0.264"}
*Aa* × *Aa* 的五个后代中恰好两个为隐性表型的概率是多少？保留三位小数。
::: solution
$\binom52(0.25)^2(0.75)^3 = 10\times0.0625\times0.4219 = 0.264$。
:::
:::

::: exercise z 值的计算 {level=2 check="0.0228"}
某田鼠物种成年雄体的体重近似正态，均值 42 g、标准差 5 g。体重大于 52 g 的比例是多少？保留四位小数。
::: solution
$z = (52 - 42)/5 = 2.0$，$1 - \Phi(2.0) = 0.0228$：约 2.3 %。
:::
:::

::: exercise 发芽 {level=2}
一家种子商宣称其种子发芽率为 80 %。播种 20 粒，12 粒发芽。(a) 若宣称属实，发芽数目的均值与标准差是多少？(b) 由二项分布精确计算 $\Prob(X \le 12)$。(c) 发芽托盘里可能违背二项分布的哪条假设？它会使你的结论朝哪个方向改变？
::: answer
(a) 16 与 1.79；(b) 0.0321。
:::
::: solution
(a) $np = 16$，$\sqrt{20\times0.8\times0.2} = 1.789$。
(b) 在 $n = 20$、$p = 0.8$ 下把 [[#eq-binomial]] 对 $k = 0$ 至 12 求和得 0.0321。若宣称属实，只有约 3 % 的 20 粒盘会糟到这一步，因此该结果使宣称可疑。
(c) 独立性：同一托盘的种子共享水分、温度，可能还有真菌感染，命运相关。这使计数比二项分布所预言的更可变，因此 12 粒将不如 (b) 所示的那样令人惊讶。公正的做法是用几个托盘并分析托盘之间的变异。
:::
:::

::: exercise 带连续性校正的正态近似 {level=2}
某预期给 ¼ 隐性后代的杂交中，100 个后代含 18 个隐性。计算 $\Prob(X \le 18)$：(a) 精确值；(b) 用带连续性校正的正态近似；(c) 不加校正。
::: answer
(a) 0.0630；(b) 0.0667；(c) 0.0530。
:::
::: solution
$X \sim \Bin(100, 0.25)$，均值 25，方差 18.75，SD 4.330。
(a) 对 $k = 0$ 至 18 求和得 0.0630。
(b) $\Phi\big((18.5 - 25)/4.330\big) = \Phi(-1.501) = 0.0667$。
(c) $\Phi\big((18 - 25)/4.330\big) = \Phi(-1.617) = 0.0530$。
带校正的近似与精确值接近得多。在有软件的时代，精确的二项分布同样易算，应当优先。
:::
:::

::: exercise 同胞中的隐性携带者 {level=3 check="4/9"}
扩展 [[#ex-carrier]]：两个杂合亲本有两个表型正常的孩子。假设孩子之间独立，两个都是携带者的概率是多少？然后解释下面的说法："既然每个正常孩子是携带者的概率为 2/3，至少一个是携带者的概率就是 4/3。"
::: solution
每个孩子独立地以概率 $2/3$ 为携带者，故两者皆携带者的概率为 $(2/3)^2 = 4/9$。那种说法把并不互斥的事件的概率相加，会得出 4/3 这类无意义的结果。正确的是 $\Prob(\text{至少一个}) = 1 - \Prob(\text{都不是}) = 1 - (1/3)^2 = 8/9$，或用一般加法法则 $2/3 + 2/3 - 4/9 = 8/9$。
:::
:::

::: exercise 波动试验中的大奖 {level=3}
二十管平行培养的某种细菌涂布在选择培养基上，抗性菌落数如下：0、0、0、1、0、0、2、0、0、47、0、1、0、0、0、3、0、0、12、0（按卢里亚与德尔布吕克风格的假想计数）。(a) 计算均值与方差。(b) 若计数服从泊松分布，方差应是多少？(c) 说明该结果对抗性突变发生时间意味着什么，以及为什么零抗性培养物的数目仍然有用。
::: solution
(a) 计数之和为 66，故 $\bar x = 3.30$。$\sum x^2 = 1 + 4 + 2209 + 1 + 9 + 144 = 2368$，故 $s^2 = (2368 - 20\times3.3^2)/19 = (2368 - 217.8)/19 = 113.2$。
(b) 泊松模型下方差应约等于均值 3.3。观察方差约为其 34 倍。
(c) 巨大的超额方差来自两管"大奖"培养物（47 与 12），它们是生长早期发生的突变留下的后代。若抗性是涂板时诱导的，每个细胞都有相同的微小机会，计数应服从泊松分布。数据反与突变在生长过程中随机时刻、选择之前自发发生相符。零类有用，因为一管培养物没有抗性菌落仅当其生长过程中一次突变都没有发生；若突变*事件*数服从泊松模型，$\Prob(0) = e^{-m}$，于是零培养物比例 14/20 给出每管突变平均数 $m = -\ln(0.70) = 0.36$——卢里亚与德尔布吕克的"$p_0$ 法"。
:::
:::
