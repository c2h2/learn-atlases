多数生物学实验都以一个比较告终：处理对对照，突变体对野生型，一种生境对另一种生境，三种饲料，五个基因型。问题永远相同——组间的差异是否大于组内的差异？——本章发展回答它的几种主要工具。我们从两个独立组以及**学生氏**与 **Welch t 检验**开始，进而讨论多个组与**方差分析**（analysis of variance，ANOVA），处理*哪些*组不同的后续问题（事后检验与计划比较），最后以放弃正态性假设的**基于秩**的检验收尾。

贯穿全章的例子是统计学中最著名的数据组。1936 年，费希尔用安德森（Edgar Anderson）对三个 *Iris*（鸢尾属）物种——采自魁北克加斯佩半岛（Gaspé Peninsula）的 *I. setosa*、*I. versicolor* 与 *I. virginica*——各 50 朵花的测量数据引入了判别分析。这里我们只用四项测量中的一项：萼片长度。

| 物种 | $n$ | 均值（cm） | 标准差（cm） |
|---|---|---|---|
| *I. setosa* | 50 | 5.006 | 0.3525 |
| *I. versicolor* | 50 | 5.936 | 0.5162 |
| *I. virginica* | 50 | 6.588 | 0.6359 |

单样本与配对 t 检验已在 [[biostatistics/hypothesis-testing]] 中引入；双样本检验的理论在[数学图谱：假设检验](/learn/maths/lesson.php?c=statistics&l=hypothesis-testing)。

## 两个独立组 {#two-groups}

像达尔文玉米那样的配对数据，通过差值来比较。当两个组**独立**——彼此没有天然配对的不同个体——时，我们直接比较它们的均值。设两组均值为 $\bar x_1$、$\bar x_2$，标准差为 $s_1$、$s_2$，样本量为 $n_1$、$n_2$，则差 $\bar x_1 - \bar x_2$ 估计 $\mu_1 - \mu_2$，而因为两个均值独立，其方差相加：
$$
\Var(\bar X_1 - \bar X_2) = \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}.
$$
两种 t 检验的分别在于如何估计这个量。

::: proposition 学生氏双样本 t 检验 {#prop-student}
若两个总体都服从正态分布且具有**相同**的方差 $\sigma^2$，用**合并方差**
$$
s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2},
$$
来估计它，并使用
$$
t = \frac{\bar x_1 - \bar x_2}{s_p\sqrt{\dfrac{1}{n_1} + \dfrac{1}{n_2}}},
$$ {#eq-student}
它在 $H_0\colon\mu_1 = \mu_2$ 之下服从 $t_{n_1 + n_2 - 2}$。
:::

::: proposition Welch t 检验 {#prop-welch}
不假设方差相等时，使用
$$
t = \frac{\bar x_1 - \bar x_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}},
$$ {#eq-welch}
它在 $H_0$ 之下近似服从自由度为 **Welch–Satterthwaite** 值的 t 分布
$$
\nu = \frac{\left(s_1^2/n_1 + s_2^2/n_2\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1 - 1} + \dfrac{(s_2^2/n_2)^2}{n_2 - 1}},
$$ {#eq-welch-df}
一般不是整数。$\mu_1 - \mu_2$ 的 $1 - \alpha$ 置信区间为 $(\bar x_1 - \bar x_2) \pm t_{1-\alpha/2,\,\nu}\sqrt{s_1^2/n_1 + s_2^2/n_2}$。
:::

Welch 自由度介于 $\min(n_1, n_2) - 1$ 与 $n_1 + n_2 - 2$ 之间，当两个方差项相等时达到上限。样本量相等时，两个 t 统计量完全相同，只有自由度不同。当样本量*和*方差都不等时，学生氏检验可能错得离谱：若较小的样本来自变异性较大的总体，其Ⅰ 型错误率可达名义 $\alpha$ 的数倍。Welch 检验（韦尔奇（Bernard Welch），1947）在方差相等时几乎毫无损失，因此许多统计学家，以及鲁克斯顿（Graeme Ruxton）在 *Behavioral Ecology*（2006）一篇被广泛引用的短文，都建议把它作为默认选择。先检验方差是否相等再挑检验的做法并不可取：预备检验不可靠，而两阶段程序的错误率控制很差。

::: example versicolor 对 virginica {#ex-iris-t}
*I. versicolor* 与 *I. virginica* 的平均萼片长度是否不同？分别作学生氏检验与 Welch 检验，并给出差的 95 % 置信区间。
::: solution
差为 $6.588 - 5.936 = 0.652$ cm。

**学生氏。** $s_p^2 = (49\times0.5162^2 + 49\times0.6359^2)/98 = (0.2664 + 0.4043)/2 = 0.3354$，故 $s_p = 0.5791$，标准误为 $0.5791\sqrt{2/50} = 0.1158$。于是 $t = 0.652/0.1158 = 5.63$，自由度 98，$P = 1.7\times10^{-7}$。

**Welch。** 标准误为 $\sqrt{0.5162^2/50 + 0.6359^2/50} = 0.1158$——完全相同，因为 $n_1 = n_2$——故 $t = 5.63$ 依旧，但此时由 [[#eq-welch-df]] 得 $\nu = 94.0$，给出 $P = 1.9\times10^{-7}$。

95 % 区间（Welch）为 $0.652 \pm 1.986\times0.1158$，即 **0.42 到 0.88 cm**。*virginica* 的萼片平均长约半厘米，差的估计精度约 ±0.23 cm。每个物种 50 朵花，即使这样中等的差异（约一个种内标准差）也能被果断检出。
:::
:::

两个"显著"不同的组实际重叠多少？若两个标准差相同的正态总体相差 $d$ 个标准差，则从较高者随机取的一个个体超过从较低者随机取的一个个体的概率是 $\Phi(d/\sqrt2)$：$d = 0.5$ 时 0.64，$d = 1$ 时 0.76，$d = 2$ 时 0.92。

::: warning "有两列数字就用双样本检验"
决定检验的是设计，而不是电子表格的版式。同一批动物处理前后的测量、同一片叶的左右两侧、同盆的处理株与对照株，都是*配对*的，必须通过差值分析（[[biostatistics/hypothesis-testing#prop-t-test]]），或用包含配对项的模型分析。反过来说，两个无关的等量组并不因为能并排写成两列就成了配对。把配对数据当独立数据分析通常白白丢掉精度；把独立数据当配对分析则干脆是错的。
:::

## 多个组：方差分析 {#anova}

三个物种有三对两两比较，十个组则有 45 对。每对都用 $\alpha = 0.05$ 检验会抬高假阳性的机会（[[biostatistics/hypothesis-testing#multiple-testing]]）。**方差分析**先问一个总的问题：各组均值之间到底有没有差异？

::: definition 单因素方差分析模型与平方和 {#def-anova}
设有 $k$ 个组，组 $j$ 有 $n_j$ 个观测 $x_{ij}$，均值为 $\bar x_j$；共有 $N = \sum n_j$ 个观测，总均值为 $\bar x$。**单因素方差分析模型**为
$$
x_{ij} = \mu_j + \varepsilon_{ij}, \qquad \varepsilon_{ij} \sim \Normal(0, \sigma^2) \text{ 且相互独立},
$$
零假设为 $H_0\colon \mu_1 = \mu_2 = \dots = \mu_k$。定义**总**、**组间**与**组内**（误差、残差）平方和
$$
\mathrm{SS_T} = \sum_{j}\sum_{i}(x_{ij} - \bar x)^2, \quad \mathrm{SS_B} = \sum_j n_j(\bar x_j - \bar x)^2, \quad \mathrm{SS_W} = \sum_j\sum_i (x_{ij} - \bar x_j)^2 = \sum_j (n_j - 1)s_j^2,
$$
其自由度分别为 $N - 1$、$k - 1$ 与 $N - k$。**均方**为 $\mathrm{MS_B} = \mathrm{SS_B}/(k-1)$ 与 $\mathrm{MS_W} = \mathrm{SS_W}/(N-k)$。
:::

::: proposition 方差分析恒等式与 F 检验 {#prop-anova}
平方和恰好分解：$\mathrm{SS_T} = \mathrm{SS_B} + \mathrm{SS_W}$，自由度亦然。在模型之下，无论 $H_0$ 是否为真，$\mathrm{MS_W}$ 都是 $\sigma^2$ 的无偏估计，而 $\E[\mathrm{MS_B}] = \sigma^2 + \sum_j n_j(\mu_j - \bar\mu)^2/(k-1)$，其中 $\bar\mu$ 是各 $\mu_j$ 的加权平均。在 $H_0$ 之下，比值
$$
F = \frac{\mathrm{MS_B}}{\mathrm{MS_W}}
$$ {#eq-anova-f}
服从自由度为 $k - 1$ 与 $N - k$ 的 **F 分布**，$F$ 很大时拒绝 $H_0$。
:::

::: proof 平方和的分解
把 $x_{ij} - \bar x = (x_{ij} - \bar x_j) + (\bar x_j - \bar x)$ 写出并平方：
$$
\sum_j\sum_i (x_{ij} - \bar x)^2 = \sum_j\sum_i (x_{ij} - \bar x_j)^2 + \sum_j n_j(\bar x_j - \bar x)^2 + 2\sum_j(\bar x_j - \bar x)\sum_i (x_{ij} - \bar x_j).
$$
最后一项的内层和对每个组都为零，因为偏离本组均值的偏差之和为零（[[biostatistics/data-and-variation#prop-mean-median]]）。关于分布的陈述建立在正态变量二次型的科克伦（Cochran）定理之上，证明见[数学图谱：回归](/learn/maths/lesson.php?c=statistics&l=regression)。
:::

这里的逻辑正是名称的逻辑：我们分析*方差*，是为了了解*均值*。组内变异度量噪声。组间均值的变异包含同样的噪声（按组大小定标），外加任何真实的差异。零假设为真时，两个均方估计的是同一个东西，$F$ 接近 1；真实的差异使分子膨胀。

::: example 鸢尾萼片长度的方差分析 {#ex-iris-anova}
三个 *Iris* 物种的平均萼片长度是否不同？用汇总统计量列出方差分析表。
::: solution
总均值为 $(5.006 + 5.936 + 6.588)/3 = 5.8433$（各组 $n$ 相等）。于是
$$
\mathrm{SS_B} = 50\left[(5.006 - 5.8433)^2 + (5.936 - 5.8433)^2 + (6.588 - 5.8433)^2\right] = 50(0.70112 + 0.00860 + 0.55452) = 63.21,
$$
$$
\mathrm{SS_W} = 49(0.3525^2 + 0.5162^2 + 0.6359^2) = 49(0.12425 + 0.26643 + 0.40434) = 38.96.
$$

| 来源 | SS | 自由度 | MS | $F$ | $P$ |
|---|---|---|---|---|---|
| 物种 | 63.21 | 2 | 31.606 | 119.3 | $1.7\times10^{-31}$ |
| 残差 | 38.96 | 147 | 0.2650 | | |
| 总计 | 102.17 | 149 | | | |

$F_{2,147}$ 的 5 % 临界值为 3.06，所以物种间的差异确凿无疑。物种解释的总变异比例 $\mathrm{SS_B}/\mathrm{SS_T} = 63.21/102.17 = 0.62$，就是模型的 $R^2$（也称 $\eta^2$）：这 150 朵花萼片长度的变异中，62 % 在物种之间，38 % 在物种之内。（这些数值与完整数据组的标准分析一致，后者 $F = 119.26$。）
:::
:::

### 假设与稳健性

F 检验假设观测独立、残差服从正态分布且各组方差相等（**方差齐性**）。独立是最要紧的一条，任何检验都无法补救；它是设计问题（[[biostatistics/experimental-design]]）。由中心极限定理，中等组容量时正态性无关紧要。方差不等在组容量也不等时危害最大；一条有用的经验规则是：当最大组标准差超过约最小组的两倍时才需担心。用残差 $x_{ij} - \bar x_j$ 作图来检查假设：每组一个箱线图，再加一个 Q–Q 图（[[biostatistics/probability-distributions#normal]]）。若散布随均值增大，对数变换常能把两个问题一并解决（[[biostatistics/data-and-variation#transformations]]）；否则可用 **Welch 方差分析**——[[#prop-welch]] 的推广——它不假设方差相等。鸢尾数据的标准差介于 0.35 到 0.64，比值 1.8，且各组 $n$ 相等——可以接受。

## 哪些组不同？ {#post-hoc}

显著的 F 说明均值不全都相等；它不说明哪些不同。有两种策略，如何选择应当在看数据之前决定。

**计划比较（对比）。** 若设计本来就是为回答具体问题而建立的——每个处理对对照，或两个近缘种的平均对第三者——就直接检验那些比较。**对比**（contrast）是形如 $L = \sum c_j\mu_j$ 且 $\sum c_j = 0$ 的组合，用 $\hat L = \sum c_j\bar x_j$ 估计，标准误为 $\sqrt{\mathrm{MS_W}\sum c_j^2/n_j}$，用自由度为 $N - k$ 的 $t$ 检验。少数几个计划对比至多需要温和的多重性校正（例如 Holm 法，[[biostatistics/hypothesis-testing#prop-multiple]]）。

**事后比较。** 若问题是开放的——这些组中究竟谁和谁不同？——就要比较所有配对，而且程序必须控制全局的家族错误率。

::: proposition Tukey 诚实显著差 {#prop-tukey}
容量均为 $n$ 的 $k$ 个组，残差均方为 $\mathrm{MS_W}$、自由度 $\nu = N - k$，则一切两两差值的 $1 - \alpha$ 同时置信区间为
$$
(\bar x_i - \bar x_j) \pm q_{1-\alpha;\,k,\,\nu}\sqrt{\frac{\mathrm{MS_W}}{n}},
$$ {#eq-tukey}
其中 $q_{1-\alpha;\,k,\,\nu}$ 是**学生化极差分布**的上 $\alpha$ 分位点——各总体均值全相等时，$k$ 个均值的（最大均值 − 最小均值）/（标准误）的分布。两个均值的差若超过**诚实显著差** $\mathrm{HSD} = q\sqrt{\mathrm{MS_W}/n}$，即差异显著。$n$ 相等时家族错误率恰为 $\alpha$；$n$ 不等时，Tukey–Kramer 版本把 $\sqrt{\mathrm{MS_W}/n}$ 换成 $\sqrt{\mathrm{MS_W}(1/n_i + 1/n_j)/2}$，略偏保守。
:::

使用极差的逻辑：若 $k$ 个均值全相等，任何两两之差都不大于最大减最小，所以控制住极差，就同时控制住了每一对。

::: example 三个鸢尾物种的 Tukey 检验 {#ex-tukey}
用 [[#ex-iris-anova]] 的 $\mathrm{MS_W} = 0.2650$，对三个两两差值执行 Tukey 程序。
::: solution
$k = 3$、$\nu = 147$ 时 $q_{0.95;\,3,\,147} = 3.348$（对学生化极差分布作数值积分算得；表给 $\nu = 120$ 时 3.36、$\nu = \infty$ 时 3.31）。标准误为 $\sqrt{0.2650/50} = 0.07280$，故 $\mathrm{HSD} = 3.348\times0.07280 = 0.244$ cm。

| 比较 | 差（cm） | 95 % 同时置信区间 |
|---|---|---|
| *versicolor* − *setosa* | 0.930 | 0.686 到 1.174 |
| *virginica* − *setosa* | 1.582 | 1.338 到 1.826 |
| *virginica* − *versicolor* | 0.652 | 0.408 到 0.896 |

三个差都超过 0.244，所以每一对物种都不同。*virginica* − *versicolor* 的区间比 [[#ex-iris-t]] 中单个比较的 Welch 区间（0.42 到 0.88）略宽：这个宽度就是在 95 % 水平同时覆盖全部三个比较所付的代价。
:::
:::

还有其他事后程序用于其他目的：**Dunnett 检验**把每个处理与单一对照比较，为此目的比 Tukey 法更强；经 Holm 校正的两两 t 检验是通用替代品；费希尔的"最小显著差"（显著的 F 之后作未校正 t 检验）只在三个组时才能正确控制错误率。避开那些错误率定义不清的程序，也绝不要在看到哪个结果最显著之后再从中挑选。

::: quiz
一项研究比较五种肥料处理，每处理十盆，得到 $F_{4,45} = 1.8$、$P = 0.15$，随后报告"处理 C 与处理 A 显著不同（t 检验，$P = 0.03$）"。错在哪里？
- [ ] 没有错：t 检验比方差分析灵敏。
- [x] 看过数据之后，从十种可能的配对中挑出最极端的一对、不加校正地检验，会把假阳性率抬到远高于 5 %。
- [ ] t 检验本应用 45 个自由度，那样就显著了。
- [ ] 方差分析不能用于五个组。
::: solution
五个组有十对；即使所有均值相等，十对中的最大差也倾向于给出小的未校正 P 值。总体的 F 检验没有发现差异的证据，而因为看起来最大才被挑出来的事后比较，必须对照*最大*差的分布来判断——图基的程序做的正是这件事。只报告挑中的那个比较，就是分叉小径花园（[[biostatistics/hypothesis-testing#asa]]）。
:::
:::

许多实验涉及的不止一个因素——饲料*与*温度，基因型*与*性别。**多因素方差分析**把变异分解为各因素的主效应及其**交互作用**（一个因素的效应是否取决于另一个因素的水平），区组因素与重复测量还会增加更多项。这些全都是 [[biostatistics/linear-models]] 中线型模型的特例，产生它们的设计则在 [[biostatistics/experimental-design]]。

## 基于秩（非参数）的检验 {#nonparametric}

当样本小且数据明显偏态，或含有无法打发掉的离群值，或本身就是顺序评分时，基于**秩**的检验可以避开正态性假设。把每个观测换成它在合并数据中的秩（并列取平均秩），再对秩作检验。极端值此后只算"最大"，无论它实际有多大。

::: definition Wilcoxon 符号秩检验与 Mann–Whitney 检验 {#def-rank-tests}
**Wilcoxon 符号秩检验**（威尔科克森（Frank Wilcoxon），1945），用于配对数据或单样本：把绝对差值 $\lvert d_i\rvert$ 从 1 到 $n$ 排秩（略去零），设 $W_+$ 与 $W_-$ 为正、负差值所带秩之和（$W_+ + W_- = n(n+1)/2$）。在 $H_0$（差值关于零对称）之下，每个秩带正号或负号等可能，于是 $W_-$ 的均值为 $n(n+1)/4$，方差为 $n(n+1)(2n+1)/24$。

**Mann–Whitney U 检验**（曼（Henry Mann）与惠特尼（Donald Whitney），1947；等价于威尔科克森秩和检验），用于容量为 $n_1$ 与 $n_2$ 的两个独立样本：把全部 $n_1 + n_2$ 个观测合并排秩，设 $R_1$ 为样本 1 的秩和，计算 $U_1 = R_1 - n_1(n_1 + 1)/2$，它数的是（两样本各取一个的）配对中样本 1 的值较大的那些。在 $H_0$（两个样本来自同一分布）之下，秩的 $\binom{n_1+n_2}{n_1}$ 种分配等可能，$U_1$ 的均值为 $n_1n_2/2$，精确 P 值由枚举诸分配得到。
:::

::: example 达尔文玉米的符号秩检验 {#ex-wilcoxon}
对达尔文的十五个差值作 Wilcoxon 符号秩检验。
::: solution
按绝对值排序，差值为 6, 8, 14, 16, 23, 24, 28, 29, 41, **−48**, 49, 56, 60, **−67**, 75，秩为 1 到 15。负差值的秩是 10 与 14，故 $W_- = 24$，$W_+ = 120 - 24 = 96$。

$H_0$ 之下，$2^{15}$ 种符号模式等可能；逐一枚举，676 种给出 $W_- \le 24$，故双侧 P 值为 $2\times676/32\,768 = 0.041$。用正态近似，均值 $15\times16/4 = 60$、标准差 $\sqrt{15\times16\times31/24} = 17.61$，得 $z = (24 - 60)/17.61 = -2.04$，同样 $P = 0.041$。与 t 检验（$P = 0.050$）以及原始差值的费希尔随机化检验（$P = 0.053$）相比，秩检验给出的证据略强，因为两个大的负差值只按它们的秩计数。
:::
:::

::: example 蚂蚁寻饵，带一个离群值 {#ex-mann-whitney}
在 6 个林地样站与 7 个草地样站记录了蚂蚁发现饵料的时间（s）（假想数据）：林地 12, 19, 25, 31, 44, 210；草地 48, 55, 63, 70, 92, 130, 185。分别用 Welch t 检验与 Mann–Whitney 检验比较两种生境。
::: solution
**Welch。** 均值为 56.8 与 91.9 s，标准差为 75.8 与 49.5 s；$t = 0.97$，$\nu = 8.4$，$P = 0.36$。林地那个唯一迟钝的样站（210 s）抬高了林地的均值，而且更严重地抬高了它的标准差。

**Mann–Whitney。** 把 13 个时间合并排秩，林地样站的秩为 1, 2, 3, 4, 5 与 13，故 $R_1 = 28$，$U_1 = 28 - 21 = 7$：$6\times7 = 42$ 个林地-草地配对中只有 7 对是林地的时间更长。$\binom{13}{6} = 1716$ 种等可能的秩分配中，44 种给出 $U_1 \le 7$，故双侧精确 P 值为 $2\times44/1716 = 0.051$。

秩检验给出了强得多的证据（尽管在 0.05 下仍处于边缘）：林地蚂蚁找到饵料更快，因为六个林地样站中有五个快于每一个草地样站。对对数变换后的时间作 Welch 检验得 $P = 0.089$，介于两者之间。面对这样的数据，应当在收集数据之前根据对预期分布的了解选定分析——到达某事件的时间通常右偏——而不是三种都试、报告最小的 $P$。
:::
:::

单因素方差分析的秩对应物是 **Kruskal–Wallis 检验**（克拉斯卡尔（William Kruskal）与瓦利斯（Allen Wallis），1952）：$N$ 个观测分为 $k$ 组，秩和为 $R_j$，
$$
H = \frac{12}{N(N+1)}\sum_j\frac{R_j^2}{n_j} - 3(N+1),
$$ {#eq-kruskal}
组容量中等时它在 $H_0$ 之下近似 $\chi^2_{k-1}$。**Friedman 检验**对随机化区组做同样的事。

::: warning "非参数检验比较中位数且没有假设"
秩检验假设更少，不是没有假设。它们仍然要求观测独立。Mann–Whitney 检验检出的是一个组中的值是否倾向于大于另一个组（$\Prob(X > Y) \ne \tfrac12$）；只有当两个分布形状相同、仅相差一个平移时它才是中位数的检验，两个组中位数相等而散布或偏态不同时它也会拒绝。符号秩检验假设差值关于其中心对称。而且秩检验给出 P 值容易、给出效应量难；请同时报告一个估计，如霍奇斯-莱曼（Hodges–Lehmann）平移量，或干脆报告中位数及其置信区间。
:::

秩检验损失多少功效？少得惊人。数据当真服从正态时，Mann–Whitney 检验与符号秩检验相对于 t 检验的渐近相对效率为 $3/\pi = 0.955$——同样的功效大约需要多 5 % 的观测——而对厚尾分布它们可能强大得多。它们的弱点在极小的样本：可能的秩排法太少。每组三个观测时，Mann–Whitney 检验最小的可能双侧精确 P 值是 $2/\binom63 = 0.10$，所以它在 0.05 下*永远*不可能显著。对原始数值作**置换检验**，如费希尔对达尔文数据所做（[[biostatistics/hypothesis-testing#ex-fisher-perm]]），是另一个保留原始尺度的少假设选择。

::: application 实践中选择检验
实验室生物学中常见的工作流程——先对每组作正态性检验，再挑 t 检验或秩检验——并不可取：正态性检验在小样本时几乎没有什么功效，而那正是选择要紧的时候；而两阶段程序的错误率未知。更好的做法是在收集数据之前根据对测量的了解定下分析（计数、时间与浓度通常偏态；长度通常接近正态），先画数据，宁用 Welch 检验而不用学生氏，对乘性数据取对数变换，样本小而形状未知时用秩检验或置换检验。对计数与比例，[[biostatistics/categorical-data]] 与 [[biostatistics/linear-models]] 中的模型比上述任何一种都更贴合数据的性质。
:::

::: history
学生氏 1908 年的论文给出单样本检验；费希尔在 1920 年代导出了用合并方差的双样本检验，韦尔奇的异方差解出现在 1947 年（连同萨特思韦特（Franklin Satterthwaite）1946 年的自由度近似）。费希尔在罗斯汉姆斯特德发明了方差分析，用来分析田间农业试验；它见于 1923 年与麦肯齐（Winifred Mackenzie）合作关于马铃薯品种与肥料的一篇论文，并经 *Statistical Methods for Research Workers*（1925）推广；F 分布则由斯内德科（George Snedecor）1934 年制表并为致敬费希尔而命名。图基在 1949–1953 年间提出他的诚实显著差，邓内特（Charles Dunnett）在 1955 年提出他的多对一比较。威尔科克森是研究杀虫剂与杀菌剂的化学家，1945 年在一篇四页的论文中引入了符号秩与秩和检验；曼与惠特尼 1947 年给出 U 统计量及其分布；克拉斯卡尔与瓦利斯 1952 年发表他们的检验。费希尔 1936 年关于鸢尾数据的论文发表于 *Annals of Eugenics*，今天人们读它只为其中的统计；该刊刊名反映的那个时代、为现代学界所唾弃的优生学观点。
:::

::: summary
- 独立组：学生氏 t 检验合并方差；Welch 检验不合并，应当作为默认。$n$ 相等时两统计量一致，只有自由度不同。
- *I. versicolor* 对 *I. virginica* 萼片长度：差 0.652 cm，$t = 5.63$，95 % CI 0.42 到 0.88 cm。
- 单因素方差分析分解 $\mathrm{SS_T} = \mathrm{SS_B} + \mathrm{SS_W}$；$F = \mathrm{MS_B}/\mathrm{MS_W}$，自由度 $(k-1, N-k)$。鸢尾物种：$F_{2,147} = 119.3$，$R^2 = 0.62$。
- 对比要事先计划；两两比较用 Tukey 的 HSD（鸢尾：HSD = 0.244 cm，每一对都不同），多对一用 Dunnett 检验。
- 假设：独立性（要紧），残差正态（中等 $n$ 时稳健），方差相等（$n$ 不等时要紧）；用残差图检查。
- 秩检验——Wilcoxon 符号秩、Mann–Whitney、Kruskal–Wallis——抗离群值与偏态，数据正态时几乎不损功效，但仍假设独立，而且不只是中位数的检验。
:::

## 练习

::: exercise 合并方差 t 统计量 {level=1 check="1.70"}
两个独立的组各有 8 株幼苗，平均株高 20.0 与 23.0 cm，标准差 3.0 与 4.0 cm。计算学生氏合并方差 t 统计量，保留三位有效数字。
::: solution
$s_p^2 = (7\times9 + 7\times16)/14 = 12.5$；$\mathrm{SE} = \sqrt{12.5(1/8 + 1/8)} = 1.768$；$t = 3.0/1.768 = 1.70$，自由度 14（$P = 0.11$）。
:::
:::

::: exercise Welch 自由度 {level=1 check="13.0"}
对上一题的幼苗，计算 Welch–Satterthwaite 自由度，保留三位有效数字。
::: solution
$s_1^2/n_1 = 9/8 = 1.125$，$s_2^2/n_2 = 16/8 = 2.0$。于是 $\nu = 3.125^2/(1.125^2/7 + 2.0^2/7) = 9.766/(0.1808 + 0.5714) = 12.98$，即 13.0。$n$ 相等、方差只差一点时，Welch 在 14 个自由度中损失一个。
:::
:::

::: exercise 由汇总统计量算 F 比值 {level=1 check="5"}
三组甲虫各五头，平均质量为 10、12 与 14 mg，每组标准差 2 mg。计算方差分析的 F 统计量。
::: solution
总均值 12；$\mathrm{SS_B} = 5(4 + 0 + 4) = 40$，$\mathrm{MS_B} = 20$；$\mathrm{SS_W} = 3\times4\times4 = 48$，$\mathrm{MS_W} = 48/12 = 4$；$F = 20/4 = 5.0$，自由度 (2, 12)，$P = 0.026$——刚刚越过图中所示临界值 3.885。
:::
:::

::: exercise Kruskal–Wallis 统计量 {level=2 check="7.2"}
三个组各有三株植物，彼此完全不重叠：合并九个观测的秩中，A 组为 1, 2, 3，B 组为 4, 5, 6，C 组为 7, 8, 9。用 [[#eq-kruskal]] 计算 $H$。
::: solution
$R_A = 6$，$R_B = 15$，$R_C = 24$；$\sum R_j^2/n_j = (36 + 225 + 576)/3 = 279$。$H = \frac{12}{9\times10}\times279 - 30 = 37.2 - 30 = 7.2$。χ²₂ 近似给出 $P = 0.027$，但每组只有三个时该近似很差；精确置换 P 值（秩分给各组的 1680 种不同分配中有 6 种达到这样极端）为 $6/1680 = 0.0036$。
:::
:::

::: exercise 可能的最小 P 值 {level=2 check="0.1"}
Mann–Whitney 检验每组三个观测时，可能的最小双侧精确 P 值是多少？
::: solution
秩的分配有 $\binom63 = 20$ 种，等可能；最极端的一种（一组三个全低于另一组）在每个方向各出现一次，故 $P_{\min} = 2/20 = 0.10$。任何结果都不可能在 0.05 下显著——规划 $n = 3$ 的实验之前值得知道这一点。
:::
:::

::: exercise 减少花朵数的 Tukey 检验 {level=2}
设每个 *Iris* 物种只测了 10 朵花，均值与标准差不变。(a) 重新计算 $\mathrm{MS_W}$、$F$ 及其自由度。(b) 用 $q_{0.95;\,3,\,27} = 3.506$ 计算 HSD，并判断哪些对有别。
::: answer
(a) $\mathrm{MS_W} = 0.2650$，$F = 23.9$，自由度 (2, 27)；(b) HSD = 0.571 cm；三对全都不同。
:::
::: solution
(a) $\mathrm{MS_W}$ 是三个方差的平均，0.2650，与 $n$ 无关。$\mathrm{SS_B}$ 随 $n$ 缩放：$10\times1.26424 = 12.642$，故 $\mathrm{MS_B} = 6.321$，$F = 6.321/0.2650 = 23.9$，自由度 2 与 27——仍然压倒性。
(b) $\mathrm{HSD} = 3.506\sqrt{0.2650/10} = 3.506\times0.1628 = 0.571$ cm。差值 0.930、1.582 与 0.652 都超过它，尽管 *virginica* − *versicolor*（0.652）仅仅勉强超过。花朵更少时，最小的差将最先变得不显著。
:::
:::

::: exercise 伪配对 {level=3}
一位研究者测量同一棵树枝条上 12 张阳叶和 12 张阴叶的光合速率，把结果逐行写进电子表格的两列。(a) 一位同事对这些行作配对 t 检验。这为什么是错的？(b) 另一位作了双样本 Welch 检验。该检验对什么总体作推断，为什么它回答不了"这个物种的阳叶与阴叶有无差异"这个问题？(c) 什么样的设计能回答这个问题？
::: solution
(a) 各行不构成配对：阳枝的第 3 片叶与阴枝的第 3 片叶之间没有任何特殊关系。任意配行得到一个毫无意义的检验，其结果取决于录入的次序。
(b) Welch 检验比较的是这棵树的那两个*枝条*；它的 24 片叶只是子样本，任何差异都可能出自那根枝条的年龄、高度、损伤或维管供应，而不是光照。它只支持对这两个枝条的推断。用叶作为光照论断的重复是伪重复（[[biostatistics/experimental-design]]）。
(c) 取若干棵树（比如 10 到 15 棵），在每棵树上分别测阳枝与阴枝上的叶；把每根枝上的叶取平均，再跨树用配对检验比较阳与阴（树就是配对）。更好的做法是每棵树每种枝取多根，或对随机挑选的枝条作遮阴处理。
:::
:::

::: exercise 为什么不能做三个 t 检验？ {level=3}
(a) 若三个鸢尾物种的均值原本相等，而三个两两 t 检验彼此独立（其实并不完全独立），$\alpha = 0.05$ 下至少一个假阳性的概率是多少？(b) $k = 6$ 个组的实验有多少次两两比较，同样的计算给出什么？(c) 用语言解释为什么未校正两两检验的实际错误率比 (b) 给出的略低，却仍远高于 0.05，以及图基的程序如何处理这一问题。
::: solution
(a) $1 - 0.95^3 = 0.143$。
(b) $\binom62 = 15$ 次比较；$1 - 0.95^{15} = 0.54$。
(c) 两两检验共享数据（每个均值出现在 $k - 1$ 次比较中），又共享同一个 $\sigma$ 的估计，因此彼此正相关，至少一个假阳性的机会小于独立情形的数字——六个等容量组的模拟（每组十个，合并方差）给出约 0.35。但这仍约为名义率的七倍。图基的程序直接使用 $k$ 个均值之间*最大*标准化差的精确分布（学生化极差），于是各均值全相等时*任一*两两差超过 HSD 的概率恰为 $\alpha$。
:::
:::
