达尔文的十五对玉米给出平均身高差 20.9 个 1/8 英寸，有利异花授粉植株（[[biostatistics/data-and-variation#ex-darwin-location]]）。若他培育的是另外十五对，他会得到另一个数。能有多不同？杂交的真正优势——用无限的植株才能测出的那个——是接近 21，还是可能是零，或两倍大？样本的单个数值是一个**估计**，而估计若不给出精确度的陈述就毫无用处。

本章讲的就是这个陈述。它先谈样本应当如何取得，使统计量估计到我们意图估计的东西；然后引入统计量的**抽样分布**、度量其散布的**标准误**，以及使均值的抽样分布近似正态的**中心极限定理**；接着用学生氏 t 分布建立均值与比例的**置信区间**；最后以计算完成同样工作的自助法（bootstrap）作结。底层理论在数学图谱（[抽样](/learn/maths/lesson.php?c=statistics&l=sampling)、[估计](/learn/maths/lesson.php?c=statistics&l=estimation)与[置信区间](/learn/maths/lesson.php?c=statistics&l=confidence-intervals)）。

## 样本与总体 {#sampling}

统计量估计样本所取自总体的参数（[[biostatistics/data-and-variation#def-population]]）。可能出错的地方有两处，且截然不同。

::: definition 抽样误差、偏倚与精确度 {#def-bias}
估计的**抽样误差**是它与参数之差，随样本而变。若一个估计程序在重复抽样下平均而言是正确的，它是**无偏的**；若系统性地偏高或偏低，则是有偏的。若重复估计彼此聚得很拢，它是**精确的**。**准确性**要求两者兼备：小偏倚与高精确度。
:::

精确度随样本量提高；偏倚则不然。用会放走小鱼的网捕一千条鱼，得到的是错误平均长度的精确估计。偏倚的解药在抽样设计，而基本设计是**随机样本**：总体中每个单元有相同的机会被纳入，且各单元的选取彼此独立。

生物学家很少有一张可供抽取的总体名单，所以随机抽样采取实际的形式：样方按计算机产生的随机坐标放置，而不是从肩后抛出；从笼中选动物用随机数决定，而不是哪只先爬到手上（最慢或最大胆的那只）；田块从地图上随机选取。生物抽样中常见的偏倚来源包括：

- **方便抽样**：在道路、小径或站所附近取样，那里条件不同。
- **自愿者或探测偏倚**：采到的最易见、最易捕或最易诱捕的个体——贪捕的动物、显眼的植物、鸣唱的鸟。
- **长度偏倚抽样**：存活期长或体型大的单元更容易被一次快照逮住，如一次横断面调查会高估长期感染。
- **幸存者偏倚**：博物馆标本、化石与长期定位样地只记录了活到被测量的那部分。

总体有层块结构时，**分层随机抽样**——把总体划分为层（生境、年龄组）并在每层内随机抽样——能以同样的努力得到更精确的估计。其逻辑与实验中的区组化相同（[[biostatistics/experimental-design]]）。

## 抽样分布与标准误 {#sampling-distribution}

想象把一个研究重复许多次，每次取一个同样大小 $n$ 的新随机样本，每次算出样本均值 $\bar x$。这些均值的分布就是 $\bar x$ 的**抽样分布**。它不是数据的分布：它描述*估计*将会如何变动。

::: proposition 样本均值的均值与标准误 {#prop-se}
若 $X_1, \dots, X_n$ 是取自均值为 $\mu$、标准差为 $\sigma$ 的总体的独立观测，样本均值 $\bar X$ 的均值为 $\mu$，标准差为
$$
\sigma_{\bar X} = \frac{\sigma}{\sqrt n}.
$$ {#eq-se}
这就是**均值的标准误**。用样本估计它为 $\mathrm{SE}_{\bar x} = s/\sqrt n$。
:::

::: proof
$\E[\bar X] = \frac1n\sum\E[X_i] = \mu$。由独立性方差可加：$\Var\big(\sum X_i\big) = n\sigma^2$，故 $\Var(\bar X) = n\sigma^2/n^2 = \sigma^2/n$。
:::

平方根是样本量的关键。要把标准误减半，观测数须增至四倍；要缩小十倍，须增至一百倍。并注意独立性的假设：若观测相关——同一片叶上测十次、五缸鱼共用一套水系统——有效样本量小于 $n$，[[#eq-se]] 就过于乐观。这正是伪重复（pseudoreplication）的统计学内核（[[biostatistics/experimental-design]]）。

::: definition 标准差与标准误之别 {#def-sd-se}
**标准差** $s$ 描述个别观测的变异性；数据增多它并不收缩（它收敛到 $\sigma$）。**标准误** $s/\sqrt n$ 描述样本均值的不确定度；随 $n$ 增大它向零收缩。描述一个总体用标准差；描述一个估计的精确度用标准误（或更好的，置信区间）。
:::

## 中心极限定理 {#clt}

[[biostatistics/probability-distributions#prop-normal]] 已表明正态观测的均值恰为正态。出人意料的是，只要 $n$ 足够大，几乎*任何*观测的均值都近似正态。

::: proposition 中心极限定理 {#prop-clt}
若 $X_1, X_2, \dots$ 独立同分布，均值为 $\mu$、标准差 $\sigma$ 有限，则 $n$ 大时
$$
Z = \frac{\bar X - \mu}{\sigma/\sqrt n}
$$
的分布近似标准正态，无论各 $X_i$ 的分布是什么形状。确切地说，对每个 $z$，$n \to \infty$ 时 $\Prob(Z \le z) \to \Phi(z)$。
:::

证明（用特征函数）见[数学图谱：极限定理](/learn/maths/lesson.php?c=probability&l=limit-theorems)。"足够大"是多大？取决于总体距正态有多远：对称总体 $n = 10$ 通常足够；强偏态的总体，如寄生虫负荷或多度，$n$ 可能需要 30、50 以上。动手试一试。

::: widget clt
dist: skewed
n: 5
samples: 2000
caption: 两千个样本均值，每个由从一个右偏（对数正态）总体抽取的 $n$ 个观测算出，以直方图画出，并叠画中心极限定理所预言的、均值为 $\mu$、标准差为 $\sigma/\sqrt n$ 的正态曲线。$n = 5$ 时均值的直方图仍右偏。把 $n$ 增到 30，它变得近乎对称并逼近曲线，同时也按因子 $1/\sqrt n$ 变窄。切换到双峰总体或伯努利总体，可见即使极不正态的总体也给出近乎正态的均值。
:::

::: example 鱼样本的平均寄生虫负荷 {#ex-clt}
某湖中每条鱼的寄生虫数均值为 6、标准差为 9：多数鱼携带很少，少数携带极多，分布强右偏。一位研究者检查了 50 条鱼的随机样本。样本均值大于 8 的概率约是多少？这类样本的样本均值有 95 % 落在什么范围内？
::: solution
由 [[#prop-se]] 标准误为 $9/\sqrt{50} = 1.273$。由中心极限定理，$\bar X$ 近似 $\Normal(6, 1.273^2)$，尽管个别负荷远非正态。于是 $z = (8 - 6)/1.273 = 1.571$，$\Prob(\bar X > 8) \approx 1 - \Phi(1.571) = 0.058$。中央 95 % 的样本均值落在 $6 \pm 1.96\times1.273$，即 3.5 至 8.5。

两点提醒。偏态如此严重时，$n = 50$ 只是使正态近似勉强合理的下限；真实抽样分布仍略右偏，所以大均值比近似所说的略更可能出现。而若只抽 5 条鱼，标准误将为 4.0，近似毫无用处——一条重度感染的鱼就会左右整个均值。
:::
:::

中心极限定理正是正态分布统治统计学的原因，尽管很少有生物学变量是正态的。它适用于和也适用于均值，适用于比例（0–1 变量的均值），并以修正的形式适用于回归系数与许多其他估计量。

## 学生氏 t 分布 {#t-distribution}

若 $\sigma$ 已知，区间 $\bar x \pm 1.96\,\sigma/\sqrt n$ 将在 95 % 的样本中包含 $\mu$。但 $\sigma$ 永不可知；我们只有 $s$，而 $s$ 本身就有不确定性，小样本时尤甚。把 $\sigma$ 换成 $s$ 会使标准化均值比正态变量更可变，其正确分布由都柏林吉尼斯（Guinness）啤酒厂的化学家戈塞特（William Sealy Gosset）找到，他 1908 年以"Student"为笔名发表论文。

::: definition 学生氏 t 分布 {#def-t}
若 $X_1, \dots, X_n$ 是独立的 $\Normal(\mu, \sigma^2)$ 观测，均值 $\bar X$、标准差 $S$，则
$$
T = \frac{\bar X - \mu}{S/\sqrt n}
$$ {#eq-t}
服从**自由度为 $n - 1$ 的学生氏 t 分布**，记作 $t_{n-1}$。它关于零对称、呈钟形，但尾部比标准正态更厚；随自由度增大它趋于 $\Normal(0, 1)$。
:::

更厚的尾部是估计 $\sigma$ 付出的代价。双侧 95 % 临界值 $t_{0.975,\,\nu}$（每侧截去 2.5 %）显示这一代价下降之快：

| 自由度 $\nu$ | 1 | 2 | 5 | 10 | 14 | 30 | 100 | ∞ |
|---|---|---|---|---|---|---|---|---|
| $t_{0.975,\,\nu}$ | 12.706 | 4.303 | 2.571 | 2.228 | 2.145 | 2.042 | 1.984 | 1.960 |

两个观测时（$\nu = 1$）95 % 的乘数是极限值的六倍多；到 $\nu = 30$ 差别已小。（这些数值为本课由正则化不完全 β 函数算出，与标准表一致。）

::: widget distribution
dist: t
params: nu=3
normal: true
caption: 自由度为 $k$ 的学生氏 t 分布（Student's t distribution）的密度，叠加以标准正态曲线。$k = 3$ 时 t 曲线中部更低、尾部厚得多：$T$ 取极端值的可能性远大于正态分布的预言，因为小样本中 $s$ 有时远小于 $\sigma$。把 $k$ 增大到 30 附近，两条曲线便几乎无法区分。
:::

严格地说，t 分布要求数据正态。实践中 t 程序是**稳健的**：由中心极限定理，$n$ 超过约 15–30 后，除非严重偏态或有离群值，它们对中度非正态的数据也工作良好。对来自偏态总体的小样本，先变换数据（[[biostatistics/data-and-variation#transformations]]），或使用不假定正态的方法（[[biostatistics/comparing-groups]]）。

## 均值的置信区间 {#ci-mean}

::: definition 置信区间 {#def-ci}
置信水平 $1 - \alpha$（常取 95 %）的**置信区间**是由数据按某一程序算出的区间，该程序在重复抽样下以概率 $1 - \alpha$ 包含真参数。对正态总体的均值，$1 - \alpha$ 区间为
$$
\bar x \pm t_{1-\alpha/2,\; n-1}\,\frac{s}{\sqrt n}.
$$ {#eq-ci-mean}
:::

::: proof 区间为何有效
由 [[#eq-t]]，当 $t^* = t_{1-\alpha/2,\,n-1}$ 时 $\Prob\big(-t^* \le (\bar X - \mu)/(S/\sqrt n) \le t^*\big) = 1 - \alpha$。把不等式重新整理以解出 $\mu$，得 $\Prob\big(\bar X - t^*S/\sqrt n \le \mu \le \bar X + t^*S/\sqrt n\big) = 1 - \alpha$。概率陈述说的是随机端点，即在看数据之前算出的端点。
:::

::: example 达尔文的玉米：杂交优势的置信区间 {#ex-darwin-ci}
十五个差值（异花授粉减自花授粉，1/8 英寸）为 49, −67, 8, 16, 6, 23, 28, 41, 14, 29, 56, 24, 75, 60, −48。计算平均差的 95 % 置信区间，并算出 90 % 与 99 % 区间。
::: solution
由于每对栽于同一只花盆，自然的分析单元是同盆差值 $d$。由数据 $\bar d = 314/15 = 20.93$，$s_d = 37.74$，$\mathrm{SE} = 37.74/\sqrt{15} = 9.746$。$\nu = 14$：

- 95 %：$t^* = 2.145$，故 $20.93 \pm 2.145\times9.746 = 20.93 \pm 20.90$，得 **0.03 到 41.84**。
- 90 %：$t^* = 1.761$，得 3.77 到 38.10。
- 99 %：$t^* = 2.977$，得 −8.08 到 49.94。

以英寸计，95 % 区间为 0.004 至 5.2 英寸。数据与杂交优势从几乎没有到超过五英寸的任何值都相容。95 % 区间勉强不含零，正对应我们将在 [[biostatistics/hypothesis-testing]] 中得到的处于边缘的 P 值 0.0497；99 % 区间包含零。若不用 $t$ 而用正态乘数 1.96，将得 1.83 到 40.03 —— 太窄，低估了一个 15 对实验的不确定度。
:::
:::

95 % 是什么意思？不是说 $\mu$ 落在 0.03 与 41.84 之间的概率是 95 %：$\mu$ 是一个固定（未知）的数，它或者在那里或者不在那里。95 % 说的是*方法*：把达尔文的实验重复多次，每次按 [[#eq-ci-mean]] 计算一个区间，则 95 % 的区间会包含真平均差。我们的区间是其中之一，而我们不知道它是不是那走运的 95 %。（贝叶斯**可信区间**在给定先验下确有直接的概率解读；见[数学图谱：贝叶斯推断](/learn/maths/lesson.php?c=statistics&l=bayesian)。先验模糊时两种区间常在数值上接近。）

::: widget confidence

caption: 关于一个总体均值的五十个 95 % t 区间，每个来自一个新的 15 观测模拟样本；竖线是真均值。约 95 % 的区间覆盖它，未覆盖的被高亮。每个区间的中心与宽度都不同，因为 $\bar x$ 与 $s$ 都随样本变动。反复按 New sample 数一数未覆盖的区间；把方法切换到 z——它把正态乘数用于样本 $s$——注意未覆盖的会多于 5 %，而这正是学生氏 t 所纠正的错误。

::: warning "95 % 置信区间包含 95 % 的数据"
均值的置信区间说的是*总体均值*可能落在何处，它按 $1/\sqrt n$ 收缩。包含 95 % 个别观测的范围——参考范围，正态数据约为 $\bar x \pm 2s$——不随 $n$ 收缩。以达尔文的差值而言，均值的置信区间是 0.03 到 41.8，但个别配对从 −67 到 +75 不等，十五株自花授粉植株中有两株*高于*其异花授粉搭档。均值的显著优势并不意味着每株杂交植株都胜过每株自交植株。
:::

### 规划精确度

把 [[#eq-se]] 反解，可知要以 95 % 置信把均值估计到误差 $E$ 之内需要多少观测：近似为
$$
n \approx \left(\frac{1.96\,\sigma}{E}\right)^2,
$$ {#eq-n-precision}
其中 $\sigma$ 必须由预试验或文献猜一个。因为小 $n$ 时 t 乘数超过 1.96，所得结果应向上取整并加检验。为检验的功效而非区间宽度做规划，在 [[biostatistics/hypothesis-testing]] 与 [[biostatistics/experimental-design]] 中讨论。

::: example 要测量多少朵花？ {#ex-n-precision}
一位植物学家要以 95 % 置信把某鸢尾群体萼片长度的均值估计到 ±0.05 cm 之内。预试验数据提示标准差约 0.35 cm，与安德森的 *I. setosa* 相当。需要多少朵花？
::: solution
$n \approx (1.96\times0.3525/0.05)^2 = (13.82)^2 = 190.9$，故 191 朵。$\nu = 190$ 时 t 乘数为 1.973，会把数目提高到约 194；保险起见至少测 194 朵（再多留些余地，以防花朵受损）。若把误差减半至 ±0.025 cm，需四倍的数目，约 770 朵。
:::
:::

## 比例的置信区间 {#ci-proportion}

一个比例 $\hat p = x/n$ ——被感染宿主的比率、发芽种子的比率、具某表型后代的比率——是 0–1 变量的均值，故由 [[biostatistics/probability-distributions#prop-binomial-moments]] 与中心极限定理，它近似正态，标准误 $\sqrt{p(1-p)/n}$。

::: definition 比例的 Wald 区间与 Wilson 区间 {#def-ci-prop}
简单的 **Wald 区间**是 $\hat p \pm z^*\sqrt{\hat p(1 - \hat p)/n}$，95 % 时 $z^* = 1.96$。**Wilson 得分区间**（Edwin Wilson，1927）为
$$
\frac{\hat p + \dfrac{z^{*2}}{2n} \pm z^*\sqrt{\dfrac{\hat p(1-\hat p)}{n} + \dfrac{z^{*2}}{4n^2}}}{1 + \dfrac{z^{*2}}{n}}.
$$ {#eq-wilson}
:::

样本大且 $\hat p$ 不接近 0 或 1 时，Wald 区间没问题。小样本或极端比例时它表现糟糕：实际覆盖率可远低于 95 %，还可能低于 0 或高于 1。Wilson 区间由反转正态检验而非代入 $\hat p$ 得到，保持在 $[0, 1]$ 之内且覆盖率接近名义值；阿格雷斯基（Alan Agresti）与库尔（Brent Coull）（1998）等人推荐它与近似的 Agresti-Coull 区间用于日常。

::: example 一大多一小的两个比例 {#ex-ci-prop}
(a) 孟德尔在 7324 粒种子中记录皱粒 1850。给出皱粒比例的 95 % 区间。(b) 一次预调查中 20 只蛙有 3 只携带壶菌感染。给出患病率的 Wald 与 Wilson 95 % 区间。
::: solution
(a) $\hat p = 1850/7324 = 0.2526$，$\mathrm{SE} = \sqrt{0.2526\times0.7474/7324} = 0.00508$，故 Wald 区间为 $0.2526 \pm 0.0100$，即 **0.243 到 0.263**。$n$ 这么大时 Wilson 区间到小数点后三位与之相同。该区间宽宽地包含孟德尔期望值 ¼。

(b) $\hat p = 0.15$。Wald：$0.15 \pm 1.96\sqrt{0.15\times0.85/20} = 0.15 \pm 0.156$，即 −0.006 到 0.306 —— 一个不可能的负下限。Wilson：由 [[#eq-wilson]]，$z^{*2}/n = 0.1921$：中心 $(0.15 + 0.0960)/1.1921 = 0.2064$，半宽 $1.96\sqrt{0.006375 + 0.002401}/1.1921 = 0.1540$，得 **0.052 到 0.360**。二十只蛙只能说明患病率大概在 5 % 到 36 % 之间。
:::
:::

$n$ 个单元无一显示该性状时 $\hat p = 0$，Wald 区间塌缩成一个点。一个有用的近似——**三分法则**——说 95 % 上限约为 $3/n$：若 20 只蛙中找不到一只感染的，患病率仍可高达 15 %（Wilson 给 16 %）。小样本中的缺席是"不存在"的微弱证据。

## 自助法 {#bootstrap}

均值或比例的标准误有公式。中位数、比率、相关系数或多样性指数往往没有，或者所依赖的假设我们无法检验。埃夫龙（Bradley Efron）的**自助法**（bootstrap，1979）用计算估计抽样分布：把样本当作总体的替身，从中*有放回地*抽许多同大小的**重抽样**，对每次重抽样计算统计量，并用这些值的散布。

::: algorithm 百分位自助置信区间 {#alg-bootstrap}
1. 从数据 $x_1, \dots, x_n$ 中有放回地随机抽 $n$ 个值。
2. 对这次重抽样计算统计量 $\hat\theta^*$。
3. 重复步骤 1–2 很多次 $B$（比如 10,000 次）。
4. 这 $B$ 个值的标准差估计 $\hat\theta$ 的标准误，其 2.5 与 97.5 百分位数构成近似的 95 % 置信区间。
:::

```python
import random, statistics
d = [49, -67, 8, 16, 6, 23, 28, 41, 14, 29, 56, 24, 75, 60, -48]  # Darwin's differences
random.seed(1)
boot = sorted(statistics.median(random.choices(d, k=len(d))) for _ in range(10_000))
print(statistics.median(d), boot[249], boot[9749], statistics.stdev(boot))
# 24  14  49  8.05   -> median 24, 95% percentile interval 14 to 49, bootstrap SE about 8
```

对达尔文的差值，中位数为 24，自助标准误约 8，95 % 百分位区间从 14 到 49（确切数值取决于随机种子）。这个区间偏斜，反映了十五个差值凹凸不平的分布。同样的重抽样用于均值给出 1.5 到 37.9 的百分位区间，比 [[#ex-darwin-ci]] 的 t 区间略窄——简单百分位自助在小样本中的一个已知倾向。自助法不是魔法：$n = 15$ 时样本只是总体的粗略替身，它无力纠正有偏或不独立的样本。偏差校正与加速（BCa）区间等改进可提高其准确性。

::: quiz
一项研究报告 25 只鸟翅长的均值为 72.0 mm，95 % 置信区间 70.0 至 74.0 mm。哪句陈述正确？
- [ ] 总体中约 95 % 的鸟翅长在 70 到 74 mm 之间。
- [ ] 下一只被测量的鸟落在 70 到 74 mm 之间的概率是 95 %。
- [x] 该区间由一个在 95 % 的样本中捕获总体均值的方法产生；翅长的标准差约为 4.8 mm。
- [ ] 若重复研究，95 % 的新样本均值会落在 70 与 74 mm 之间。
::: solution
该区间约为 $\bar x \pm 2.06\,s/\sqrt{25}$，半宽 2.0 mm 给出 $s \approx 2.0\times5/2.064 = 4.8$ mm。个别鸟的变动范围因而约为 $72 \pm 9.7$ mm，远宽于该区间。最后一个选项也错：新的样本均值围绕 $\mu$ 波动，不围绕本样本的 $\bar x$，所以它们中不足 95 %（平均约 83 %）会落入这个特定区间。
:::
:::

::: application 标记-重捕估计种群大小
生态学家先标记 $M$ 只动物并放归，随后捕获 $n$ 只、其中 $m$ 只有标记，以此估计动物种群的大小 $N$。若第二次样本是随机的，标记比例 $m/n$ 估计 $M/N$，得到林肯-彼得森（Lincoln-Petersen）估计量 $\hat N = Mn/m$。它的假设就是本章的假设：封闭种群、标记不脱落，而且——至关重要的是——捕获机会均等，使重捕样本关于标记是随机的。贪捕或怯捕的动物都会使 $\hat N$ 偏高或偏低，与捕获多少动物无关。其标准误与置信区间可由 $m$ 的二项变异性导出；查普曼（Chapman）修正 $\hat N = (M + 1)(n + 1)/(m + 1) - 1$ 可在 $m$ 小时减小偏倚。种群数量估计在 [[ecology]] 与 [[conservation-biology]] 中展开。
:::

::: history
早在十九世纪初，标准误就在天文学中以"或然误差"之名使用，但总是用于大样本。戈塞特（William Sealy Gosset）为吉尼斯啤酒厂分析大麦与啤酒花的小规模实验时发现，正态理论给出的区间太窄；他 1908 年以"Student"笔名在 *Biometrika* 发表的论文 "The probable error of a mean"（《平均数的或然误差》）导出了 t 分布（部分靠模拟：把 3000 个罪犯指长与身高的测量值写在卡片上洗牌），而费希尔在 1920 年代给出了以自由度表述的一般证明与现代形式。奈曼（Jerzy Neyman）在 1937 年把置信区间形式化；威尔逊（Edwin Wilson）1927 年发表了他的比例区间。埃夫龙（Bradley Efron）1979 年引入自助法，是廉价计算使成为可能的最早统计方法之一。
:::

::: summary
- 偏倚是抽样方式的属性，样本再大也不减少它；随机抽样（以及分层随机抽样）是防线。
- $\bar x$ 的抽样分布均值为 $\mu$、标准误为 $\sigma/\sqrt n$（以 $s/\sqrt n$ 估计），前提是观测独立。
- 中心极限定理使大 $n$ 的均值近似正态，总体为何分布皆可，偏态总体收敛更慢。
- $\sigma$ 由估计代替时，$(\bar x - \mu)/(s/\sqrt n)$ 服从学生氏 $t_{n-1}$；95 % 区间为 $\bar x \pm t_{0.975,\,n-1}\,s/\sqrt n$。
- 达尔文的玉米：杂交优势均值 20.9 个 1/8 英寸，95 % 区间 0.03 到 41.8。
- 置信水平描述方法长期的成功，不是这个特定区间正确的概率；均值的置信区间比数据的散布窄得多。
- 比例宜用 Wilson 区间；$n$ 次中零成功时，95 % 上限约为 $3/n$。
- 自助法通过对数据有放回地重抽样来估计标准误与区间。
:::

## 练习

::: exercise 标准误 {level=1 check="1.5"}
36 只螺样本的壳长标准差为 9.0 mm。均值的标准误是多少（mm）？
::: solution
$9.0/\sqrt{36} = 9.0/6 = 1.5$ mm。
:::
:::

::: exercise 样本量增至四倍 {level=1 check="0.5"}
样本量增至四倍（其他不变）时，均值的标准误变为原来的多少倍？
::: solution
$\mathrm{SE} \propto 1/\sqrt n$，故变为 $1/\sqrt4 = 0.5$ 倍：减半。
:::
:::

::: exercise t 区间 {level=1}
十份池水样本的硝酸盐浓度均值 4.80 mg L⁻¹、标准差 0.90 mg L⁻¹。计算均值的 95 % 置信区间。
::: answer
4.16 到 5.44 mg L⁻¹。
:::
::: solution
$\mathrm{SE} = 0.90/\sqrt{10} = 0.2846$；$\nu = 9$，$t_{0.975,9} = 2.262$，故 $4.80 \pm 2.262\times0.2846 = 4.80 \pm 0.644$：4.16 至 5.44 mg L⁻¹。
:::
:::

::: exercise 零的上限 {level=2 check="0.05"}
60 个被抽样个体中未发现携带某一等位基因的个体。用三分法则，其携带者频率的近似 95 % 置信上限是多少？
::: solution
$3/n = 3/60 = 0.05$。数据与携带者频率高达约 5 % 相容。（该法则来自解 $(1 - p)^n = 0.05$，即 $p \approx -\ln(0.05)/n = 3.0/n$。）
:::
:::

::: exercise 比例的样本量 {level=2 check="385"}
要以 95 % 置信把大概率在 50 % 上下的患病率估计到 ±5 个百分点之内，必须抽样多少只动物？用 $n = z^{*2}p(1-p)/E^2$ 并向上取整。
::: solution
$n = 1.96^2\times0.25/0.05^2 = 3.8416\times0.25/0.0025 = 384.2$，故 385 只动物。因为 $p(1-p)$ 在 $p = 0.5$ 处最大，这是最坏情形；患病率接近 10 % 时约 139 只即可。
:::
:::

::: exercise 反求标准差 {level=2 check="4.50"}
一篇论文报告均值 31.2，95 % 置信区间 28.8 至 33.6，$n = 16$。设用 t 区间，样本标准差是多少？保留三位有效数字。
::: solution
半宽为 $2.4 = t_{0.975,15}\,s/\sqrt{16}$，$t_{0.975,15} = 2.131$，故 $s = 2.4\times4/2.131 = 4.50$。
:::
:::

::: exercise 去掉配对的达尔文数据 {level=3}
设达尔文的异交与自交植株当初没有同盆配对，两组是独立样本。(a) 用 $s_\mathrm{C} = 28.94$ 与 $s_\mathrm{S} = 16.41$ 计算两组均值之差的标准误 $\sqrt{s_\mathrm{C}^2/15 + s_\mathrm{S}^2/15}$。(b) 把它与配对标准误 9.746 比较，并解释差异。(c) 这对本实验中配对的价值有何提示？
::: solution
(a) $\sqrt{837.3/15 + 269.4/15} = \sqrt{55.82 + 17.96} = \sqrt{73.78} = 8.59$。
(b) 出人意料，不配对的标准误*小于*配对的。差值的方差为 $\Var(C) + \Var(S) - 2\Cov(C, S)$；只有搭档正相关、协方差项作减法时配对才有帮助。此处异交与自交高度的同盆相关竟为负（$r \approx -0.34$）：例如第 2 与第 15 对，一株极矮的异交植株与一株平常的自交植株同盆。配对方差 $37.74^2 = 1424.6$ 超过 $837.3 + 269.4 = 1106.7$。
(c) 本实验中同盆配对并未降低噪声——植株身高并非主要由同盆条件驱动。但分析必须服从设计：植株*确实*配对了，配对分析才是有效的，无论哪个标准误更小。费希尔本人的随机化分析（[[biostatistics/hypothesis-testing]]）就尊重配对。看了哪个 P 值更小再决定用哪种分析是作弊。
:::
:::

::: exercise 置信水平承诺了什么 {level=3}
某实验室惯常报告 95 % 置信区间。一年里它发表了来自独立研究的 200 个区间。(a) 预期有多少个*不*包含真值？这个数目的标准差是多少？(b) 该实验室随后只发表排除零的 40 个区间（其"阳性发现"）。解释为什么 95 % 覆盖的保证对发表的那一组不再成立，发表的区间会倾向于显示哪种错误。
::: solution
(a) 未命中的数目服从 $\Bin(200, 0.05)$：均值 10，标准差 $\sqrt{200\times0.05\times0.95} = 3.08$。约 4 到 16 个未命中都毫不足怪。
(b) 覆盖率是对每个研究都施行该程序这一做法的属性。因区间排除零而挑选区间，就是挑选估计碰巧远离零的样本，其中不成比例地包括机会放大了效应的样本。于是发表的区间将倾向于高估效应大小，其中一些研究的真效应其实为零（假阳性）。这就是"赢者诅咒"，也是 [[biostatistics/hypothesis-testing]] 与 [[biostatistics/experimental-design]] 讨论的可重复性问题的一部分。
:::
