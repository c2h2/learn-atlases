1886 年，高尔顿（Francis Galton）发表了 928 名成年子女与其父母的身高。高个子的父母有高个子的孩子，矮个子的父母有矮个子的孩子——但子女不及父母那样高或那样矮。比平均身高高出三英寸的父母，其子女平均只比平均高出约两英寸。高尔顿称之为“向平庸的回归”，而他画过其数据的那条直线，给定量生物学中最常用的工具起了名字。回归与相关描述两个数值变量如何一同变化：代谢率如何随体重标度，发育时间如何随温度下降，后代如何像其父母，酶活性如何取决于底物。

本章讲**相关系数**及其检验；**最小二乘回归直线**、它的解释与推断；线性模型的假设以及如何用**残差**检查它们，并以安斯库姆（Francis Anscombe）著名的四重奏为例；**变换**，特别是**异速生长标度**的 log–log 图；以及**回归到均值**的陷阱。相关理论在[数学图谱：回归](/learn/maths/lesson.php?c=statistics&l=regression)；多个解释变量同时进入模型、以及非正态的响应，在 [[biostatistics/linear-models]]。

我们的例证数据仍来自鸢尾数据：安德森（Edgar Anderson）测量、费希尔（Fisher）1936 年发表的 50 朵 *Iris setosa* 的萼片长度与萼片宽度，该数据随 R 软件发行。萼片长度的均值为 5.006 cm，萼片宽度为 3.428 cm。

## 散点图与相关 {#correlation}

第一步永远是**散点图**：每根轴放一个变量，每个单元画一个点。它显示任何关系的方向（正或负）、形态（直或弯）、强弱（点聚得多拢）以及任何异常的点。

::: definition 协方差与相关系数 {#def-correlation}
对 $n$ 对数据 $(x_i, y_i)$，记
$$
S_{xx} = \sum (x_i - \bar x)^2, \qquad S_{yy} = \sum (y_i - \bar y)^2, \qquad S_{xy} = \sum (x_i - \bar x)(y_i - \bar y).
$$
样本**协方差**为 $S_{xy}/(n-1)$，**皮尔逊相关系数**为
$$
r = \frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}.
$$ {#eq-r}
它介于 −1 与 +1 之间，仅当各点恰好落在一条直线上时等于 ±1；改变任一变量的单位或原点，它保持不变（若其中一个变量反向，则只改变符号）。
:::

相关度量的是*线性*关联的强弱。数值接近零并不意味着没有关系：一个完美的 U 形关系有 $r = 0$。数值接近 ±1 也不意味着关系是因果的，或是在数据范围之外仍是线性的。而且 $r$ 对离群值以及所抽样的 $x$ 的范围都敏感：把所研究体重的范围收窄，会降低代谢率与体重的相关，尽管底层的联系并没有改变。

::: proposition 相关的检验与估计 {#prop-r-test}
若各对数据是取自相关为 $\rho$ 的二元正态总体的随机样本，则在 $H_0\colon\rho = 0$ 之下，
$$
t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}}
$$ {#eq-r-test}
服从 $t_{n-2}$。求置信区间用**费希尔 z 变换** $z = \tfrac12\ln\frac{1+r}{1-r} = \operatorname{artanh} r$，它近似正态，标准误为 $1/\sqrt{n - 3}$；把区间 $z \pm 1.96/\sqrt{n-3}$ 用 $\tanh$ 变换回去。
:::

::: example *Iris setosa* 的萼片长度与宽度 {#ex-iris-r}
对 50 朵 *setosa*，$S_{xx} = 6.0882$（长度）、$S_{yy} = 7.0408$（宽度）、$S_{xy} = 4.8616$（cm²）。计算 $r$，检验 $\rho = 0$，并给出 95 % 置信区间。
::: solution
$r = 4.8616/\sqrt{6.0882\times7.0408} = 4.8616/6.5472 = 0.7425$。于是 $t = 0.7425\sqrt{48}/\sqrt{1 - 0.5514} = 5.144/0.6698 = 7.68$，自由度 48，$P = 6.7\times10^{-10}$。

区间：$z = \operatorname{artanh}(0.7425) = 0.9563$，标准误 $1/\sqrt{47} = 0.1459$；$z \pm 1.96\times0.1459$ 得 0.6704 到 1.2422，反变换得 **0.585 到 0.846**。区间关于 $r$ 不对称，而对一个以 1 为界的量本应如此。萼片长的花其萼片也宽，长度与宽度共享约 $r^2 = 55\,\%$ 的方差。
:::
:::

当数据远离二元正态、含有离群值，或是秩时，**斯皮尔曼等级相关** $r_s$（斯皮尔曼（Charles Spearman），1904）——对 $x$ 与 $y$ 的秩计算的皮尔逊 $r$——度量 $y$ 随 $x$ 增加（或减少）的一致程度，无论关系是否线性。肯德尔 $\tau$ 是一个相关的度量，基于一致对与不一致对。

## 最小二乘线 {#least-squares}

相关对称地对待两个变量。**回归**不然：它把一个**响应** $y$ 建模为**解释变量** $x$ 的函数，以描述 $y$ 如何随 $x$ 变化，或从 $x$ 预测 $y$。

::: definition 简单线性回归模型 {#def-regression}
**简单线性回归模型**为
$$
y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad \varepsilon_i \sim \Normal(0, \sigma^2) \text{ 相互独立},
$$ {#eq-model}
其中 $\beta_0$ 是**截距**（$x = 0$ 时 $y$ 的均值），$\beta_1$ 是**斜率**（$x$ 每增加一个单位，$y$ 的均值的变化），$\varepsilon_i$ 是第 $i$ 个单元对直线的偏离。$x_i$ 被视为固定且已知无误。
:::

::: proposition 最小二乘估计 {#prop-ls}
使**残差平方和** $\mathrm{SS_{res}} = \sum (y_i - b_0 - b_1x_i)^2$ 最小的直线 $\hat y = b_0 + b_1 x$ 满足
$$
b_1 = \frac{S_{xy}}{S_{xx}} = r\,\frac{s_y}{s_x}, \qquad b_0 = \bar y - b_1\bar x.
$$ {#eq-ls}
直线经过 $(\bar x, \bar y)$，**残差** $e_i = y_i - \hat y_i$ 之和为零，总变异分解为 $S_{yy} = \mathrm{SS_{reg}} + \mathrm{SS_{res}}$，且 $\mathrm{SS_{reg}}/S_{yy} = r^2$。残差方差 $s^2 = \mathrm{SS_{res}}/(n - 2)$ 估计 $\sigma^2$。
:::

::: proof
把 $\mathrm{SS_{res}}$ 的偏导数置零，得 $\sum (y_i - b_0 - b_1x_i) = 0$ 与 $\sum x_i(y_i - b_0 - b_1x_i) = 0$。第一式说残差之和为零，故 $\bar y = b_0 + b_1\bar x$；把 $b_0$ 代入第二式，再减去第一式的 $\bar x$ 倍，得 $\sum(x_i - \bar x)(y_i - \bar y) = b_1\sum(x_i - \bar x)^2$，即 $b_1 = S_{xy}/S_{xx}$。把 $y_i - \bar y = (\hat y_i - \bar y) + e_i$ 展开，并注意由两个正规方程交叉乘积之和为零，就得到分解，其中 $\mathrm{SS_{reg}} = b_1^2S_{xx} = S_{xy}^2/S_{xx} = r^2S_{yy}$。
:::

量 $R^2 = \mathrm{SS_{reg}}/S_{yy}$ 是**决定系数**，是 $y$ 的方差中被与 $x$ 的线性关系“解释”的比例；在简单回归中它等于 $r^2$。“解释”一词是统计意义上的，不是因果意义上的。

::: proposition 关于斜率与预测的推断 {#prop-slope-inference}
在模型 [[#eq-model]] 之下，斜率估计的标准误为 $\mathrm{SE}(b_1) = s/\sqrt{S_{xx}}$，且 $t = (b_1 - \beta_1)/\mathrm{SE}(b_1)$ 服从 $t_{n-2}$。对 $H_0\colon\beta_1 = 0$ 的检验与 [[#eq-r-test]] 中对 $\rho = 0$ 的检验完全相同。在取值 $x_0$ 处，**均值响应**的置信区间与新个体的**预测区间**分别为
$$
\hat y_0 \pm t^*\,s\sqrt{\frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}}, \qquad \hat y_0 \pm t^*\,s\sqrt{1 + \frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}},
$$ {#eq-pred}
95 % 时取 $t^* = t_{0.975,\,n-2}$。
:::

斜率的精度取决于 $S_{xx}$：把 $x$ 值铺开能得到比聚拢它们好得多的斜率估计，这是一个设计决策。[[#eq-pred]] 中两个区间都在 $\bar x$ 处最窄、离它越宽越阔；预测区间总是宽得多，因为它包含了个体绕直线的散布 $\sigma$。

::: example 萼片宽度对长度的回归 {#ex-iris-regression}
利用 [[#ex-iris-r]] 的 *setosa* 各和以及均值 5.006 与 3.428 cm，求宽度对长度的回归直线，检验斜率，并给出长度 5.5 cm 处的 95 % 置信区间与预测区间。
::: solution
$b_1 = 4.8616/6.0882 = 0.7985$，$b_0 = 3.428 - 0.7985\times5.006 = -0.569$，故
$$
\widehat{\text{宽度}} = -0.569 + 0.799\times\text{长度}.
$$
萼片长度每增加一厘米，宽度平均增加 0.80 cm。截距是长度为零的萼片的预测宽度，生物学上没有意义：$x = 0$ 远在数据之外。

$\mathrm{SS_{res}} = S_{yy} - b_1S_{xy} = 7.0408 - 0.7985\times4.8616 = 3.1587$，$s^2 = 3.1587/48 = 0.06581$，$s = 0.2565$ cm。$\mathrm{SE}(b_1) = 0.2565/\sqrt{6.0882} = 0.1040$，故 $t = 7.68$，与 $r$ 的完全一样，斜率的 95 % 置信区间为 $0.7985 \pm 2.011\times0.1040 =$ **0.589 到 1.008**。

$x_0 = 5.5$ 时，$\hat y_0 = -0.5694 + 0.7985\times5.5 = 3.822$ cm。由 $(x_0 - \bar x)^2/S_{xx} = 0.2440/6.0882 = 0.0401$：所有 5.5 cm 萼片的平均宽度的置信区间为 $3.822 \pm 2.011\times0.2565\sqrt{0.02 + 0.0401}$，即 **3.70 到 3.95 cm**；单朵新花的预测区间为 $3.822 \pm 2.011\times0.2565\sqrt{1.0601}$，即 **3.29 到 4.35 cm**，宽四倍。这些数字与 iris 数据该子集的标准软件输出一致。
:::
:::

::: warning "对 y 回归与对 x 回归给出同一条直线"
不然。$y$ 对 $x$ 的回归最小化竖直偏差，斜率为 $rs_y/s_x$；$x$ 对 $y$ 的回归最小化水平偏差，画在同一坐标上斜率为 $s_y/(rs_x)$。两者仅当 $\lvert r\rvert = 1$ 时重合。对 *setosa*，宽度对长度的斜率为 0.80；长度对宽度的斜率为 $4.8616/7.0408 = 0.69$，在宽度对长度的图上是一条斜率 $1/0.69 = 1.45$ 的直线。选哪个取决于问题：哪个变量要被预测，或哪个是响应。当两者都不是响应、都带测量误差时——许多异速生长研究如此——一条对称的直线，例如标准主轴（斜率 $\pm s_y/s_x$），可能更合适（沃顿（David Warton）及同事，2006）。
:::

## 假设与诊断 {#diagnostics}

[[#prop-slope-inference]] 的推断建立在四条假设之上，便于记作缩写 LINE：

- **L** 线性（Linearity）：在所研究的范围内，$y$ 的均值是 $x$ 的直线函数。
- **I** 独立（Independence）：残差相互独立（无同一个体的重复测量，无空间或时间自相关，无未经处理的共享系统发育）。
- **N** 正态（Normality）：残差服从正态分布（小样本的精确推断需要它；对大 $n$ 不那么要紧）。
- **E** 等方差（Equal variance）：残差方差在 $x$ 的一切取值处相同（方差齐性）。

它们谁也无法从 $r$、$R^2$ 或 P 值看出来。它们要靠残差的图形来判断。

::: definition 残差图、杠杆值与影响 {#def-diagnostics}
**残差图**把残差 $e_i$ 对拟合值 $\hat y_i$（或对 $x_i$）作图；模型合适时它是一条没有结构的水平带。弯曲显示非线性；漏斗形显示方差不等；远离零的孤立点是 $y$ 方向的**离群值**。观测 $i$ 的**杠杆值** $h_i = 1/n + (x_i - \bar x)^2/S_{xx}$ 度量它的 $x$ 值离其他观测多远，因而度量它能多有力地拖动直线。若去掉某个观测会使拟合直线明显改变，它就是**有影响的**；**Cook 距离** $D_i = \dfrac{e_i^2}{2s^2}\dfrac{h_i}{(1-h_i)^2}$ 综合了残差大小与杠杆值，接近 1 的数值值得仔细核查。
:::

::: example 安斯库姆四重奏 {#ex-anscombe}
1973 年，安斯库姆构造了四个数据集，每个 11 个点。四者皆有 $\bar x = 9$、$\bar y = 7.50$、$s_y^2 = 4.12$，最小二乘线都是 $\hat y = 3.00 + 0.500x$，$r = 0.816$，$R^2 = 0.67$，斜率检验都给出 $t = 4.24$、$P = 0.002$。描述残差图会揭示什么。
::: solution
对每个数据集分别计算回归，可确认这些摘要完全相同（精确到两三位小数）。图形却完全不同：

- **Ⅰ.** 有噪声的直线关系；残差成一条无结构的带。线性模型是恰当的。
- **Ⅱ.** 一条几乎没有散布的平滑曲线（开口向下的抛物线）；残差在中部为正、两端为负。关系是非线性的，二次拟合几乎完美。
- **Ⅲ.** 十个点几乎严格在一条直线上（$\hat y = 4.01 + 0.345x$，$r = 1.000$），外加 $x = 13$、$y = 12.74$ 处的一个离群值把拟合直线拖歪。它的残差远远高出其余各点。
- **Ⅳ.** 十个点在 $x = 8$，一个点在 $x = 19$。斜率完全由这个高杠杆值的单点（$h = 1$）决定；没有它，斜率根本无法估计。

只有在数据集 Ⅰ 中，回归摘要才名副其实。安斯库姆的讯息——把数据画出来——是回归最重要的一条法则。
:::
:::

在 *setosa* 数据中残差图相当均匀，但有一朵花（数据集中的第 42 号，长 4.5 cm、宽 2.3 cm）残差为 −0.72 cm，低于直线 2.8 个残差标准差，Cook 距离也最大（0.28）——显著但不喧宾夺主。这是一朵真实的花；连同它与不连它一起报告分析结果，可以看出结论并不依赖它。

当假设不成立时怎么办，取决于如何不成立：散布随均值增大或关系是乘性的，就变换 $y$（或两个变量）；关系弯曲，就添加曲线项或拟合非线性模型；响应是计数或比例，就用广义线性模型（[[biostatistics/linear-models]]）；数据不独立，就用混合模型或时间序列方法；跨物种的比较数据，则要用**系统发育比较方法**处理共享的祖先（费尔斯坦（Joseph Felsenstein）的系统发育独立对比，1985，以及系统发育广义最小二乘），因为近缘物种不是独立的数据点。

## 变换与异速生长 {#allometry}

许多生物学关系不是直线，而是**幂律**：$y = a x^b$。跨物种看，器官质量、代谢率、寿命、家域面积以及许多其他性状都以这种方式随体重标度，这一模式叫做**异速生长**（赫克斯利（Julian Huxley），1932）。取对数把幂律变成直线：
$$
\log y = \log a + b\log x.
$$
斜率 $b$ 是**标度指数**。$b = 1$ 时 $y$ 与 $x$ 成正比（**等速生长**）；$b < 1$ 是负异速生长，$b > 1$ 是正异速生长。对数还有第二个好处：生物学变异通常是乘性的，所以在对数尺度上绕直线的散布大致恒定，满足等方差假设。

::: proposition 代谢率的异速生长标度（一条经验规律） {#prop-kleiber}
跨哺乳动物（以及许多其他类群）的物种，基础代谢率 $B$ 随体重 $M$ 的标度近似为
$$
B = aM^b, \qquad b \approx 0.75,
$$ {#eq-kleiber}
即**克莱伯定律**（克莱伯（Max Kleiber），1932）。这是一项观察，不是定理。所估计的指数因物种、数据集与拟合方法而异：哺乳动物的估计值约为 0.67 到 0.75，且有证据表明指数在不同类群和不同体型范围之间有所不同；而解释普适值 3/4 的理论（例如 West、Brown 与 Enquist 1997 年的分支供应网络模型）仍有争议。
:::

::: example 拟合异速生长指数 {#ex-allometry}
以下 20 对 $(\log_{10} M, \log_{10} B)$（$M$ 以克计，$B$ 以瓦特计）为**模拟**数据（Python，`random.seed(7)`；$\log_{10}M$ 在 1 到 6 上均匀分布；$\log_{10}B = -1.6 + 0.72\log_{10}M$ 加标准差 0.12 的正态噪声），用以模仿一个哺乳动物数据集：

(2.62, 0.32), (1.75, −0.35), (4.25, 1.52), (1.36, −0.70), (3.68, 1.09), (2.83, 0.48), (1.29, −0.75), (3.54, 1.15), (1.19, −0.68), (3.17, 0.83), (1.35, −0.70), (1.45, −0.64), (3.12, 0.61), (5.13, 2.08), (1.62, −0.36), (2.12, −0.04), (4.14, 1.33), (5.74, 2.42), (3.89, 1.14), (2.98, 0.69)。

估计标度指数并给出 95 % 置信区间，并检验它是否与 3/4 和 2/3 有差异。
::: solution
在对数尺度上，$S_{xx} = 34.539$、$S_{xy} = 24.941$，故 $b = 24.941/34.539 = 0.722$，且 $\log_{10}a = 0.472 - 0.722\times2.861 = -1.594$，即 $B = 0.0255\,M^{0.722}$（W，$M$ 以 g 计）。残差标准差 $s = 0.0895$，$\mathrm{SE}(b) = 0.0895/\sqrt{34.539} = 0.0152$。由 $t_{0.975,18} = 2.101$，指数的 95 % 区间为 **0.690 到 0.754**。

对 $b = 0.75$：$t = (0.722 - 0.75)/0.0152 = -1.83$，$P = 0.084$。对 $b = 2/3$：$t = 3.64$，$P = 0.0019$。这些数据与 3/4 相容，与 2/3 不相容。拟合很好地恢复了模拟指数 0.72，而 $R^2 = 0.992$——这是横跨五个数量级的异速生长数据的典型情形，$x$ 的巨大范围使 $R^2$ 即使散布可观也很大。标准主轴斜率 $b/r = 0.725$ 几乎相同，因为相关如此之高。
:::

反变换需要小心。对数尺度上的拟合直线预测的是 $\log B$ 的均值，反变换回来是 $B$ 的几何平均数（近似为中位数），不是它的算术平均数（[[biostatistics/data-and-variation#transformations]]）。而且指数说的是性状*跨物种*如何变化；在种内，或在生长过程中，标度可以完全不同。

## 回归到均值 {#regression-to-mean}

高尔顿的观察有一个纯粹统计学的解释，它每天都骗到生物学家、医生和管理者。

::: proposition 回归到均值 {#prop-rtm}
若两次测量 $X$ 与 $Y$ 有相同的均值 $\mu$、相同的标准差和相关 $\rho < 1$，则 $X = x$ 的单元的 $Y$ 的期望值为
$$
\E[Y \mid X = x] = \mu + \rho(x - \mu)
$$
（对二元正态变量成立；一般而言它是最佳线性预测）。因第一次测量极端而被选中的单元，第二次测量平均而言会按因子 $\rho$ 变得不那么极端，即使什么都没有改变。
:::

原因是任何测量都是一半信号、一半噪声（测量误差、日间波动、环境的运气）。因极端值而被选中的单元，平均而言既真极端又有运气；重测时运气不会重现。高尔顿的高个子父母，一部分因为传给了子女的基因而高，一部分因为不遗传的环境与遗传效应而高，所以他们的子女向均值回归，回归的因子与身高的遗传率有关（[[population-genetics/quantitative-traits]]）。

::: example 一个虚假的处理效应 {#ex-rtm}
一位生态学家在 100 个样地测量巢捕食，选出捕食率最高的 10 个样地进行驱避处理，一年后发现这些样地上的捕食率下降了三分之一。样地之间捕食率的逐年相关是 0.5。驱避处理有效吗？
::: solution
凭这些证据不能。逐年相关为 0.5 时，即使不加处理，因极端捕食率而被选中的样地第二年平均也会退回总均值的一半路程（[[#prop-rtm]]）。若被选中的样地比如高出均值 30 个百分点，则期望它们第二年仍高出 15 个百分点——看起来已经是一大截下降。设计需要一个对照：照旧选出高捕食的样地，然后把其中一半随机分配接受驱避剂、另一半不接受，比较两组的变化（[[biostatistics/experimental-design]]）。回归到均值对两组的作用相同，会相互抵消。
:::
:::

::: quiz
一项对 40 个湖泊的研究发现，入侵贻贝的密度与水体透明度强相关（$r = 0.85$）。哪个结论站得住？
- [ ] 贻贝使水体透明度提高 85 %。
- [ ] 移除贻贝会使透明度下降，因为相关是显著的。
- [x] 在这些湖泊之间，贻贝密度与透明度有很强的线性关联，互相解释了约 72 % 的方差；因果还需要进一步的证据，例如来自实验的证据。
- [ ] $r$ 接近 1，所以关系必定是线性的。
::: solution
$r^2 = 0.72$。观察性数据中的相关不指明哪个变量影响哪个（透明的水也许利于贻贝，或贻贝通过滤食使水变透明——这其实是已知的机制，但这项研究无法证明它），也不能排除一个共同原因，例如低营养水平。高的 $r$ 可以由弯曲关系产生，而且 $r$ 不是百分比效应。
:::
:::

::: application 标准曲线
凡是用 Bradford 法测蛋白质、用荧光测 DNA、或用分光光度法测某种代谢物的实验室都要用回归：先对信号（吸光度、荧光）与已知浓度拟合一条**标准曲线**，再把未知样品从曲线上读出来——这是**反预测**，即从新的 $y$ 估计 $x$。估计的精度由 [[#eq-pred]] 反过来决定：在标准品的中心附近最好，一出标准品的范围就迅速变差，所以样品应当稀释到落在标准范围之内，绝不外推。许多测定只在有限范围内呈线性（吸光度会饱和，酶反应遵循米氏动力学），而看标准品的残差图正是判断线性到何处为止的办法。在定量 PCR 中，阈值循环数对 $\log_{10}$ 模板量回归的斜率给出扩增效率：斜率 −3.32 对应每个循环的完美倍增。
:::

::: history
高尔顿在 1877 年对香豌豆（*Lathyrus odoratus*）种子大小的遗传研究和 1886 年对人类身高的研究中引入了回归，并在 1888 年引入了相关系数。皮尔逊（Pearson）1896 年给出了 $r$ 的矩公式，他的合作者韦尔登（Weldon）把相关应用于虾与蟹的测量以研究自然选择。最小二乘本身更老：勒让德（Adrien-Marie Legendre）1805 年发表了它，高斯（Carl Friedrich Gauss）自称 1795 年即已掌握，两者都是为了天文学。斯皮尔曼的等级相关出现在 1904 年；费希尔 1915 年导出了 $r$ 的精确抽样分布，1921 年给出 z 变换；赫克斯利的 *Problems of Relative Growth*（《相对生长问题》）发表于 1932 年，与克莱伯关于体型与代谢的论文同年。安斯库姆的四重奏 1973 年发表于 *The American Statistician*；费尔斯坦的系统发育独立对比使跨物种的回归站住了脚，发表于 1985 年。
:::

::: summary
- 永远先画数据图。皮尔逊 $r = S_{xy}/\sqrt{S_{xx}S_{yy}}$ 度量线性关联；用 $t = r\sqrt{n-2}/\sqrt{1-r^2}$ 检验，用费希尔 z 给区间。对单调或等级数据用斯皮尔曼 $r_s$。
- 最小二乘：$b_1 = S_{xy}/S_{xx}$，$b_0 = \bar y - b_1\bar x$；$R^2 = r^2$；$\mathrm{SE}(b_1) = s/\sqrt{S_{xx}}$，自由度 $n - 2$。
- *Iris setosa*：宽度 $= -0.569 + 0.799\times$长度，$r = 0.743$，斜率 95 % 置信区间 0.59 到 1.01。
- 个体的预测区间比均值的置信区间宽得多；两者都在远离 $\bar x$ 处变宽；绝不外推。
- 假设（线性、独立、正态、等方差）用残差图、杠杆值与 Cook 距离检查——安斯库姆四重奏说明了为什么。
- 幂律 $y = ax^b$ 在 log–log 坐标上成为直线；代谢率的克莱伯指数接近 3/4 是一条经验规律，不是物理定律。
- 回归到均值使极端的单元在重测时变得不那么极端；只有随机对照能把它与真实效应分开。
:::

## 练习

::: exercise 由平方和求斜率 {level=1 check="2"}
某点集的 $S_{xy} = 24$、$S_{xx} = 12$。最小二乘斜率是多少？
::: solution
$b_1 = 24/12 = 2$。
:::
:::

::: exercise 由 R² 求 r {level=1 check="0.8"}
翅长对体重的回归得 $R^2 = 0.64$，斜率为正。相关系数是多少？
::: solution
$r = +\sqrt{0.64} = 0.8$，取斜率的符号。
:::
:::

::: exercise 一个预测值 {level=1 check="3.42"}
用 [[#ex-iris-regression]] 的 *setosa* 回归（$b_0 = -0.5694$、$b_1 = 0.7985$），预测萼片长度 5.0 cm 时的平均萼片宽度，保留三位有效数字。
::: solution
$-0.5694 + 0.7985\times5.0 = 3.42$ cm。
:::
:::

::: exercise 相关的检验 {level=2 check="2.89"}
27 只蜥蜴的奔行速度与后肢长度有 $r = 0.50$。计算检验 $H_0\colon\rho = 0$ 的 t 统计量，保留三位有效数字。
::: solution
$t = 0.50\sqrt{25}/\sqrt{1 - 0.25} = 2.5/0.866 = 2.89$，自由度 25，$P = 0.008$。
:::
:::

::: exercise 放大标度 {level=2 check="5.62"}
若代谢率按 $M^{0.75}$ 标度，体重增加十倍时代谢率增加多少倍？保留三位有效数字，并说明每克代谢率会发生什么。
::: solution
$10^{0.75} = 5.62$。每克代谢率按 $M^{-0.25}$ 标度，按因子 $10^{-0.25} = 0.56$ 下降：一克小鼠消耗能量远快于一克大象。
:::
:::

::: exercise 相关的置信区间 {level=2}
$n = 30$ 对数据 $r = 0.60$，用费希尔 z 变换计算 $\rho$ 的 95 % 置信区间。
::: answer
0.31 到 0.79。
:::
::: solution
$z = \operatorname{artanh}(0.60) = 0.6931$，$\mathrm{SE} = 1/\sqrt{27} = 0.1925$，故 $z \pm 1.96\times0.1925 = 0.3159$ 到 $1.0704$。反变换：$\tanh(0.3159) = 0.306$，$\tanh(1.0704) = 0.790$。30 对数据时，中等强度的样本相关与从弱到强的总体相关都相容。
:::
:::

::: exercise 读残差图 {level=3}
描述每个“残差对拟合值”图提示了什么，你会怎么做：(a) 残差随拟合值增大而散布变宽，成漏斗形；(b) 残差在低、高拟合值处为正，在中部为负；(c) 残差按测量顺序作图时，出现一长段正值、接着一长段负值；(d) 一条均匀的带，外加一个距零五个残差标准差的点。
::: solution
(a) 方差随均值增大——乘性变异、计数或浓度的典型表现。对 $y$ 作对数变换（幂律则对两个变量都变换），或改用带合适方差函数的模型（GLM，[[biostatistics/linear-models]]）；加权最小二乘是另一个选择。
(b) 弯曲：直线不合适。添加二次项、变换 $x$ 或 $y$，或拟合生物学提示的非线性模型（例如米氏方程）。
(c) 时间上不独立——仪器漂移、温度、学习中的观测者，或真正的时间自相关。检查测量规程；将来随机化测量顺序；并使用带相关误差的模型，或把时间作为协变量纳入。
(d) 可能的离群值。核对记录；若真实无误就保留，报告它的影响（杠杆值与 Cook 距离），并检查去掉它之后结论是否改变。
:::
:::

::: exercise 选择中的回归到均值 {level=3}
一位育种者测量 500 个品系的产量，选出前 5 %（均值高于群体均值 2.0 个标准差），第二年重新种植。品系产量的逐年相关为 0.4。(a) 第二年你期望入选品系高于群体均值多少个标准差？(b) 解释这为什么不意味着育种者的选择失败了，并把该相关与产量的遗传率联系起来。(c) 在选择之前，育种者如何能更准确地估计入选品系的“真实”优势？
::: solution
(a) 由 [[#prop-rtm]]，$0.4\times2.0 = 0.8$ 个标准差。
(b) 入选品系仍然优于平均：0.8 SD 是真实的、可重复的优势。它们第一年优势的其余 1.2 SD 不可重复——当年的天气、测量误差、运气。逐年相关是产量的**可重复性**；在数量遗传学中，父母与后代之间对应的这一量引出育种方程 $R = h^2S$，其中选择差 $S$ 只有可遗传的部分才传递下去（[[population-genetics/response-to-selection]]）。
(c) 重复：在选择之前把每个品系种在若干地块与地点（以及年份），使多次测量的均值与真实值的相关更高。有 $k$ 个独立重复地块时，均值的可靠性从 $\rho$ 升到 $k\rho/(1 + (k-1)\rho)$，与 [[biostatistics/experimental-design]] 的设计效应是同一套数学。
:::
