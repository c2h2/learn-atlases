再高明的分析也救不了一个设计糟糕的实验。若接受处理的植株都立在暖和的窗边、对照都在阴冷的门旁，若所谓“重复”只是一缸里的二十条鱼，若给结局打分的人知道哪些动物接受过处理，那么最精密的统计也只会对错误的问题给出精确的回答。费希尔（Ronald Fisher）1938 年说得直率：“实验做完之后才去请教统计学家，往往只是请他做一次尸检。他也许能说得出这个实验死于什么。”

这一章讲的是在任何数据存在之前所作的决定。它解释为什么实验能够确立因果关系，而观察研究却难以做到；陈述费希尔的三条原则——**重复**、**随机化**与**区组化**；讨论对照与盲法；定义实验单元以及生物学中最常见的设计错误——**伪重复**（pseudoreplication；赫伯特（Stuart Hurlbert），1984）；说明如何通过功效计算确定样本量；引入析因设计；最后谈已发表研究的可重复性以及改进它的种种做法。临床试验有其自身的伦理与法规，在[医学图谱：随机试验](/learn/medicine/lesson.php?c=epidemiology-ebm&l=randomised-trials)中讲述。

## 实验与观察 {#experiments}

在**观察性研究**中，研究者按变量自然发生的样子记录它们：有引入捕食者与没有引入捕食者的湖泊中鱼的寄生虫负荷、不同纬度哺乳动物的体型、肿瘤的基因表达谱。在**实验**中，研究者把处理分配给单元。这一区别之所以重要，是因为混杂。

::: definition 混杂 {#def-confounding}
**混杂变量**是这样一类变量：它与解释变量相关联，同时又影响响应，因而它的效应可能被误认为解释变量的效应。在对有捕食者与没有捕食者的湖泊作观察性比较时，湖泊的大小、深度或营养状况可能在这两类湖泊之间不同，并可能直接影响寄生虫。
:::

统计能够校正*测量过的*混杂因素（[[biostatistics/linear-models]]），却永远无法校正没有测量的，而在生物学中，可能的混杂因素的清单总是比已记录变量的清单更长。实验让机会决定哪个单元接受哪个处理，从而斩断解释变量与一切可能的混杂因素——无论是否测过——之间的联系。这就是为什么设计良好的实验支持因果结论，而观察性研究单凭自己通常只支持关联。观察性研究仍然必不可少——没有人能随机分配纬度、一个支系的进化历史或一个人的吸烟史——从观察性研究中谨慎地引出因果推断的方法，在[医学图谱：观察性研究](/learn/medicine/lesson.php?c=epidemiology-ebm&l=observational-studies)中发展。

::: warning "相关表明因果"
两个变量之间的关联，可能因为 $X$ 导致 $Y$，可能因为 $Y$ 导致 $X$，可能因为第三个变量同时导致两者，可能出于机会，也可能出自样本的选取方式。跨国家看，巧克力消费量与人均诺贝尔奖数相关；跨池塘看，蛙的丰度可能与蜻蜓的丰度相关，因为两者都取决于有没有鱼。只有当解释变量是随机分配的，关联才能直接读作因果——而且即便如此，也只对实际研究过的单元、条件和处理范围成立。
:::

## 实验单元与重复 {#units}

::: definition 实验单元、观测单元与重复 {#def-unit}
**实验单元**是处理独立施加于其上的最小实体：若施肥施到盆，盆就是实验单元；若控温控到缸，缸就是；若饲喂喂到笼，笼就是；若每只小鼠分别注射，小鼠就是。**观测单元**（评估单元）是对其取测量值的实体；它可以与实验单元相同，也可以更小（盆中的每株植物、缸中的每条鱼、培养皿中的每个细胞）。**重复**指把每个处理施加于若干个相互独立的实验单元。比较处理时的样本量是每个处理的实验单元数目，不是测量的数目。
:::

重复做两件事。它使同样处理的单元之间的变异——实验误差——得以估计，没有这一估计，任何检验或置信区间都算不出来。它还按因子 $1/\sqrt n$ 缩小每个处理均值的标准误（[[biostatistics/estimation#prop-se]]）。对同一个单元测量多次（**技术重复**）能减小测量误差，但对测量或减小单元之间的变异（**生物学重复**）毫无作用。同一次 RNA 抽提上样的三个孔，只是一个生物学重复。

### 伪重复

::: definition 伪重复 {#def-pseudoreplication}
**伪重复**（赫伯特，1984）指用推断统计来检验处理效应，而所用的数据来自这样的实验：其中或者处理没有重复（样本也许有），或者重复之间统计上不独立。赫伯特区分了：

- **简单伪重复**：每个处理只有一个实验单元，把每个单元取的若干样本当作重复；
- **时间伪重复**：对同一单元随时间重复测量，把各次测量当作独立的重复；
- **牺牲伪重复**：设计本来重复得当，但把一个处理内各单元的数据合并成一池，或把一个单元内的样本当作独立，从而抛弃了单元之间的真实变异。
:::

赫伯特调查了 1960 年至 1980 年代初发表于生态学的 176 项实验研究，发现其中 27 % 存在伪重复，而在用到推断统计的研究中这一比例为 48 %。这一问题在实验室生物学中同样常见：一个培养皿中的细胞、一个脑的切片、一笼动物，常常被当作独立的重复。

::: example 两缸鱼 {#ex-tanks}
为检验较暖的水是否降低褐鳟幼鱼的生长，一位研究者把 20 条鱼放入 12 °C 的一缸，20 条放入 16 °C 的另一缸，六周后用自由度为 38 的两样本 t 检验比较两组 20 条鱼的平均生长。哪里错了？这些数据能合法地说明什么？
::: solution
温度是施加到缸上的，所以缸是实验单元，而每个温度只有一缸：根本没有重复。两缸之间的任何差异——流速略有不同、光照、在房间中的位置、某一缸暴发疾病、各组内部的社会互动——都与温度完全混杂。一缸中的 20 条鱼共享这一切，所以它们的生长率并不独立，而 t 检验的误差项（同缸鱼之间的变异）并不包含真正的缸间重复会显示的缸与缸之间的变异。这个 P 值作为温度的检验毫无意义。

这些数据可以说明两缸不同，并描述每缸内部鱼的变异有多大。要检验温度，设计需要每个温度若干缸（比如 4 到 6 缸）、随机分配，分析应当使用缸均值（或用以缸为随机效应的混合模型，[[biostatistics/linear-models]]），并按缸数计算自由度。
:::
:::

这要紧到什么程度？若 $m$ 个观测单元共享一个实验单元，它们之间的相关（**组内相关**，即总方差中位于实验单元之间的部分）为 $\rho$，那么基于 $k$ 个、各含 $m$ 个观测单元的实验单元的处理均值的方差，相对于 $km$ 个独立观测会被夸大，其倍数为**设计效应**
$$
\mathrm{D_{eff}} = 1 + (m - 1)\rho,
$$ {#eq-design-effect}
而**有效样本量**为 $km/\mathrm{D_{eff}}$。把 $km$ 个观测当作独立来分析，会使标准误低估因子 $\sqrt{\mathrm{D_{eff}}}$，并抬高假阳性率。

::: example 盆里的植物 {#ex-design-effect}
一个肥料实验每个处理 10 盆、每盆 8 株，同盆植株株高的组内相关为 $\rho = 0.3$。每个处理的有效独立植株数是多少？若改为每盆 16 株，能多得到什么？
::: solution
$\mathrm{D_{eff}} = 1 + 7\times0.3 = 3.1$，所以 80 株只抵 $80/3.1 = 25.8$ 株独立植株。把它们当作 80 个独立重复来分析，会把标准误压低因子 $\sqrt{3.1} = 1.76$。

每盆 16 株时，$\mathrm{D_{eff}} = 1 + 15\times0.3 = 5.5$，160 株抵 $160/5.5 = 29.1$ 株。每盆的工夫翻倍，只多换来大约三株有效植株。当 $m \to \infty$ 时，有效样本量趋于 $k/\rho = 33$：只要只有 10 盆，再怎么增加子样本也好不到哪里去。提高精度的办法是增加盆数。
:::
:::

::: widget plot
f: 10*x/(1 + (x - 1)*r); 10/r
x: 1, 40
y: 0, 60
sliders: r=0.3:0.02:1:0.01
labels: \text{有效样本量}; \text{极限 } k/\rho
caption: 10 个实验单元（盆）的有效样本量随每盆观测单元数 $m$（横轴）增加而变化的曲线，组内相关 $\rho$ 由滑块 $r$ 设定。曲线为 $10m/(1 + (m-1)\rho)$，水平线是它的极限 $10/\rho$。$\rho = 0.3$ 时，每盆几株之后曲线即趋于平坦。把 $r$ 移向 1（同盆植株几乎完全一致），多余的植株几乎增添不了什么；移向 0.02，子样本就近乎独立。注意曲线始终不低于 10：只要分析得当，子样本无害。
:::

## 随机化 {#randomisation}

::: definition 随机化 {#def-randomisation}
**随机化**是用机会机制——随机数发生器，而不是实验者的判断或方便——把处理分配到实验单元，使每个单元接受每个处理的概率已知（通常相等），且与各单元自身的特征无关。
:::

随机化做三件事。它消除**选择偏倚**：实验者无法（无论有意无意）把最健康的动物分到受偏袒的处理。它把一切未控制变量——已知与未知的——的效应*平均而言*均匀地分配给各处理，使它们汇入误差而不是使比较产生偏倚。它还提供了检验的逻辑基础：[[biostatistics/hypothesis-testing#ex-fisher-perm]] 的随机化分布之所以有效，恰恰因为处理是随机分配的。

“随便”不是随机。用手从笼里“随手”抓小鼠，最先抓到的是最慢或最温顺的；把实验台上的前十株分给对照、后十株分给处理，是把处理与位置混杂；沿着一行交替安排处理，是把处理与任何周期性梯度混杂。用计算机产生分配方案，并保留随机种子：

```python
import random
random.seed(42)                        # 记录种子，使分配方案可审计
units = list(range(1, 21))             # 20 个盆，按实验台顺序编号
random.shuffle(units)
treated, control = sorted(units[:10]), sorted(units[10:])
print(treated)   # [5, 6, 7, 10, 13, 14, 15, 16, 19, 20]
print(control)   # [1, 2, 3, 4, 8, 9, 11, 12, 17, 18]
```

随机分配可能碰巧不均衡——这里处理的盆恰好聚在实验台的一端。对策不是重抽到“看起来随机”为止，而是预见到已知的变异来源，并对它们**设置区组**。

## 区组化 {#blocking}

::: definition 区组与随机完全区组设计 {#def-block}
**区组**是一组实验单元，预期它们彼此相似的程度高于与其他区组中的单元：田里一角的小区、一层架子上的植株、一窝里的小鼠、同一天处理的样品、实验台上同一位置的盆。**随机完全区组设计**中，每个区组包含每个处理一个（或同样多个）单元，处理在每个区组内分别随机化。区组之间的差异于是从处理的比较中被扣除。
:::

区组化是费希尔的第三条原则，“局部控制”。它之所以奏效，是因为处理的比较是在区组*内部*——单元相似的地方——进行的，区组之间的方差不进入误差。配对设计是最简单的区组设计，区组大小为 2：达尔文的异花授粉与自花授粉植株同栽一盆，比较在盆内进行。植株在实验台上的位置、小鼠的窝别、培养的批次、测量的日期，是实验室生物学中最常见的区组。规则是：**能区组化的就区组化，不能区组化的就随机化**。

::: proposition 配对所得的收益 {#prop-pairing}
设一对中两个成员响应的公共方差为 $\sigma^2$、相关为 $\rho$。对内差的方差为
$$
\Var(X_1 - X_2) = 2\sigma^2(1 - \rho),
$$
而两个独立单元为 $2\sigma^2$。因此配对把处理效应估计的方差乘以 $1 - \rho$，在给定功效下大致按同一因子减少所需的单元数，代价是误差自由度减半。
:::

::: proof
$\Var(X_1 - X_2) = \Var(X_1) + \Var(X_2) - 2\Cov(X_1, X_2) = 2\sigma^2 - 2\rho\sigma^2$。
:::

::: example 区组化省下多少？ {#ex-blocking}
某实验要在 $\alpha = 0.05$ 下达到 80 % 的功效，以检出半个标准差的处理效应（$d = 0.5$）。需要多少单元：(a) 两个独立组；(b) 成员相关 $\rho = 0.6$ 的配对；(c) $\rho = 0$ 的配对？
::: solution
(a) 由 [[biostatistics/hypothesis-testing#ex-power]]，每组 64 个：共 128 个单元。

(b) 配对检验是对差的单样本检验，差的标准差为 $\sigma\sqrt{2(1 - \rho)} = \sigma\sqrt{0.8} = 0.894\sigma$，所以差尺度上的标准化效应为 $0.5/0.894 = 0.559$。按 [[biostatistics/hypothesis-testing#prop-power]] 的精确非中心 t 计算，取 $\nu = n - 1$，得 28 对（功效 0.814）：56 个单元，不到原来的一半。

(c) $\rho = 0$ 时标准化效应为 $0.5/\sqrt2 = 0.354$，需要 65 对：130 个单元，比不配对的设计*略多*，因为配对花了自由度却没有降低噪声。只有当区组确实比全体单元更均一时，区组化才划算——达尔文的玉米恰好说明了这一点，其同盆相关竟为负（[[biostatistics/estimation]]）。
:::
:::

## 对照与盲法 {#controls}

处理效应是一项比较，而比较的可靠程度不超过对照的可靠程度。

- **阴性对照**接受处理中除活性成分外的一切：**溶媒对照**得到药物所溶解的溶剂，**假手术**包括麻醉与切口而不做手术操作，空载体对照转染的是质粒骨架。没有它，处理的效应就与抓取、注射、溶剂或手术本身的效应相混杂。
- **阳性对照**接受一个已知能产生该效应的处理。若它也失败，说明该测定本无能力检出效应，试验组的阴性结果就毫无意义。
- **同期对照**与处理同时、在同一条件下、随同处理一起随机化地进行。来自先前实验的历史对照，与其后发生的一切变化相混杂。

::: definition 盲法 {#def-blinding}
当接触单元、实施处理、测量结局或分析数据的人不知道哪个单元接受了哪个处理时，实验是**设盲**的（遮蔽的）。在人体研究中，当受试者与研究者都不知道分配方案时，是**双盲**的。
:::

盲法防护的是**观察者偏倚**，这种偏倚真实而且巨大。罗森塔尔（Rosenthal）与福代（Fode）1963 年告诉学生，他们的实验室大鼠被培育成走迷宫“聪明”或“愚笨”的品系；大鼠其实是随机分配的，但所谓聪明的大鼠表现更好。对脑卒中及其他领域动物实验的荟萃分析发现，未设盲、未随机化的研究报告的效应明显大于设盲、随机化的研究。给样品编号使打分的人分辨不出组别，花费低廉，而且对任何依赖判断的结局都应当是常规做法：行为评分、组织学、肉眼细胞计数、决定剔除哪只动物或哪个孔。

::: application 动物实验：3R 原则与报告规范
在许多国家，对脊椎动物（某些法域还包括头足类）的实验受到监管，例如英国 1986 年《科学程序（动物）法》与欧盟 2010/63/EU 指令，并遵循拉塞尔（William Russell）与伯奇（Rex Burch）1959 年提出的 **3R 原则**：尽可能用其他方法*替代*（replace）动物、*减少*（reduce）所用数量、*优化*（refine）程序以尽量减轻痛苦。好的设计服务于这三条：功效计算既避免功效不足研究的浪费，也避免功效过剩研究的多余；区组化减少所需的动物数（[[#ex-blocking]]）；而避免伪重复则避免了那些根本不可能回答其问题的实验。**ARRIVE 指南**（Animal Research: Reporting of In Vivo Experiments；克尔肯尼（Carol Kilkenny）及同事 2010，2020 年修订为 ARRIVE 2.0）要求论文报告实验单元、样本量计算、随机化、盲法以及一切剔除。
:::

## 确定样本量 {#sample-size}

样本量计算需要四个要素，都在实验开始之前确定：

1. **主要结局**以及将来分析它所用的检验；
2. **值得检出的最小效应**——这是一个生物学判断，不是对“会看到什么”的猜测；
3. **变异性**的估计，来自预试验、以往工作或文献；
4. 显著性水平（通常 0.05）与所希望的**功效**（通常 0.8 或 0.9）。

比较两个均值的计算已在 [[biostatistics/hypothesis-testing#prop-power]] 中完成。比较两个比例 $p_1$ 与 $p_2$ 时，每组所需数目的常用正态近似公式为
$$
n = \frac{\left(z_{1-\alpha/2}\sqrt{2\bar p(1 - \bar p)} + z_{1-\beta}\sqrt{p_1(1-p_1) + p_2(1-p_2)}\right)^2}{(p_1 - p_2)^2}, \qquad \bar p = \frac{p_1 + p_2}{2}.
$$ {#eq-n-prop}

::: example 规划一个成活实验 {#ex-n-prop}
一位保护生物学家预计约 50 % 的转运蝌蚪能在未处理的池塘中存活到变态，她想检出某种新栖息地处理带来的改进——提高到 70 %（或下降到 30 %）。要在 $\alpha = 0.05$ 下达到 80 % 的功效，每组需要多少只蝌蚪？这为什么可能是一个错误的问题？
::: solution
取 $p_1 = 0.5$、$p_2 = 0.3$：$\bar p = 0.4$；分子为 $(1.960\sqrt{0.48} + 0.842\sqrt{0.25 + 0.21})^2 = (1.358 + 0.571)^2 = 3.721$，分母为 $0.04$，故 $n = 93.0$——每组约 93 只（该计算是对称的，0.5 对 0.7 结果相同）。

但是处理是施于*池塘*的，不是施于蝌蚪的。若 93 只蝌蚪进一个处理池、93 只进一个对照池，这个实验就是伪重复的（[[#ex-tanks]]）。真正的问题是需要多少口池塘，这取决于成活率在池塘之间变异的幅度；蝌蚪水平的计算只是一个下限，只有当池塘之间没有差异时才成立。现实的设计也许每个处理用 6 到 10 口池塘，每口放 20 到 30 只蝌蚪。
:::
:::

对公式难以应付的复杂设计——混合模型、不寻常的分布、大量区组——最可靠的方法是**模拟**：按规划的设计与假定的效应和变异性生成许多人工数据，每一份都用将来分析真实数据所用的同一方法原样分析，数一数其中达到显著的份额。当变异性一无所知时，米德（Roger Mead）的**资源方程**为实验室实验提供了一条粗略法则：误差自由度 $E$ =（总单元数 − 1）−（处理自由度）−（区组自由度）应在 10 到 20 之间。四个处理、每个五只动物、不设区组，得 $E = 19 - 3 = 16$。

::: quiz
一位研究者要研究一种药物对神经元的作用。她用一个培养皿加药、另一个加溶媒，在每个皿里成像 300 个神经元。哪句陈述正确？
- [ ] 有 600 个神经元，这个实验的功效非常高。
- [ ] 神经元是实验单元，因为测量是在神经元上做的。
- [x] 培养皿是实验单元，而每个处理只有一个皿，所以药物的效应无法与两个皿之间的差异分开。
- [ ] 使用非参数检验可以解决这个问题。
::: solution
药是加到皿上的，所以皿是实验单元；每个处理一个皿，就没有重复。一个皿中的神经元共享它的培养条件、铺板密度与经历，所以它们的响应相关。任何检验的选择都找不回缺失的皿间变异。她需要每个处理若干个独立的皿，最好来自不同天制备的独立培养，以皿（或培养）均值为分析单元，或使用混合模型。
:::
:::

## 析因设计 {#factorial}

一次只检验一个因素既低效又会误导。**析因设计**把每个因素的每个水平与其他因素的每个水平相组合——两个温度 × 两种饲料给出四种处理组合——并把单元随机分配到所有组合。

析因设计有两大优点。第一，每个单元都为*每一个*因素提供信息：每格 $n$ 个单元的 $2\times2$ 设计中，每个主效应都由全部 $4n$ 个单元估计，所以一次实验顶得上两次同规模的单因素实验。第二，也是更重要的，它们揭示**交互作用**：一个因素的效应是否取决于另一个因素的水平。肥料也许只在水分充足时才增产；一个突变也许只在一种性别或一种遗传背景上有作用；捕食者也许只在缺乏避难所时才降低猎物的成活。一次一因素的实验发现不了这类依赖关系，还可能给出取决于另一因素被固定在哪个任意水平的误导性答案。其分析——带交互作用项的两因素方差分析——是一个线性模型（[[biostatistics/linear-models]]）。

其他设计把这些思想进一步扩展：**裂区设计**把一个因素施于大单元（整块田、生长箱），另一个因素施于其内的亚单元，因而有两个误差项；**重复测量设计**对同一单元在若干条件或时刻各测一次；**拉丁方**同时对两个变异来源设置区组；**交叉设计**让每个单元按随机顺序接受全部处理。

## 可重复性 {#reproducibility}

不能被重复的结果不是知识。过去十五年里，大规模重现已发表实验的努力发现，许多实验并不能重复。贝格利（Glenn Begley）与埃利斯（Lee Ellis）2012 年报告，安进（Amgen）公司的科学家只能证实 53 项“里程碑”式临床前癌症研究中 6 项的结果。开放科学合作组织（Open Science Collaboration，2015）重复了 100 项心理学实验，其中约 36 % 得到显著结果，而原研究中这一比例为 97 %。“可重复性计划：癌症生物学”（Timothy Errington 及同事，2021）设法重复了 23 篇高知名度论文的 50 个实验——更多的实验甚至无从尝试，因为方案与材料不可得——发现效应量的中位数比最初报告的小 85 %。

病因就是本课程一路遇到的那些：功效不足，它使显著的结果更常是假的、并且总是被夸大（[[biostatistics/hypothesis-testing#ex-fdr-prior]]）；灵活的分析与选择性的报告（P-hacking）；伪重复；随机化与盲法缺失；试剂未经验证（鉴定错误的细胞系、非特异抗体）；以及一个奖励新奇阳性发现的发表体系。补救办法同样是老相识：

- **预注册**：在收集数据之前，把假说、主要结局、样本量与分析计划登记在有公开时间戳的注册平台。**预注册报告**（registered reports）更进一步：期刊在结果出来之前就评审并接受研究设计。
- **足够的功效**，来自诚实的样本量计算。
- **随机化、盲法与同期对照**，并明确报告。
- **开放数据与代码**，使分析能被核查与重复；以及**详尽的方法**，使实验能被重复。
- **重复验证**关键结果，最好由独立实验室做出，然后才在其上继续建造。

::: history
费希尔在 1920 年代的洛桑（Rothamsted）农业试验站发展了实验设计的原则，面对的是几十年无法解读的田间试验；他 1926 年的论文 "The arrangement of field experiments" 引入了随机化、重复与区组化，而 *The Design of Experiments*（《实验设计法》，1935）把它们奉献给全部科学，例子有女士品茶与达尔文的玉米。耶茨（Frank Yates）在 1930 年代把析因设计与混杂设计推广于洛桑。首个现代随机临床试验——链霉素治疗肺结核——由英国医学研究理事会于 1948 年在布拉德福德·希尔（Austin Bradford Hill）的统计指导下发表。拉塞尔与伯奇 1959 年提出 3R 原则。赫伯特的 "Pseudoreplication and the design of ecological field experiments"（《伪重复与生态田间实验的设计》，*Ecological Monographs*，1984）命名了生态学中最常见的设计错误。约安尼迪斯（John Ioannidis）2005 年的论文、安进 2012 年的报告、2010 与 2020 两版 ARRIVE 指南，以及 2015 与 2021 年的重复计划，使可重复性成为生物学的核心关切。
:::

::: summary
- 实验随机分配处理，从而斩断与混杂因素的联系；观察性关联未必是因果。
- 实验单元是独立接受处理的东西；样本量是实验单元的数目，不是测量的数目。
- 伪重复（赫伯特 1984）把不独立的测量当作重复；$m$ 个子样本、组内相关 $\rho$ 时，设计效应为 $1 + (m-1)\rho$。
- 用计算机随机化；对已知的变异来源设置区组（“能区组化的就区组化，不能区组化的就随机化”）。配对把比较的方差乘以 $1 - \rho$。
- 使用阴性（溶媒、假手术）与阳性对照，且同期进行；让所有给结局打分的人都处于盲中。
- 样本量由最重要的最小效应、变异性、$\alpha$ 与功效确定；$d = 0.5$ 时每组 64 个，或对内相关 0.6 时 28 对。
- 析因设计一次估计多个因素并揭示交互作用。
- 预注册、足够的功效、随机化、盲法、开放数据与重复验证能提高可重复性。
:::

## 练习

::: exercise 数实验单元 {level=1 check="6"}
三台生长箱设为 15 °C，三台设为 25 °C；每台放 40 株幼苗，每株在五天里测一次株高。比较温度时有多少个实验单元？
::: solution
温度施加到箱上，所以实验单元有 $3 + 3 = 6$ 个。240 株幼苗与 1200 次测量是亚样本及其中的重复测量。
:::
:::

::: exercise 一个设计效应 {level=1 check="5.5"}
计算每簇 10 个观测、组内相关 0.5 时的设计效应。
::: solution
$1 + (10 - 1)\times0.5 = 5.5$。
:::
:::

::: exercise 资源方程 {level=1 check="12"}
一个实验有 5 个处理、4 个随机区组，每个区组内每个处理一只动物。米德的误差自由度 $E$ 是多少？
::: solution
共 20 个单元；处理占 $5 - 1 = 4$ 个自由度，区组占 $4 - 1 = 3$ 个，故 $E = 19 - 4 - 3 = 12$，落在 10 到 20 之内。
:::
:::

::: exercise 强相关的配对 {level=2 check="0.2"}
用双羔羊配对，双生之间生长的相关为 0.8。与无关羔羊相比，处理比较的方差乘以什么因子？
::: solution
乘以 $1 - \rho = 0.2$：对内差的方差只是无关羔羊之差的五分之一，所以同样的精度大约只需五分之一的羊。
:::
:::

::: exercise 比例的样本量 {level=2}
用 [[#eq-n-prop]] 求在 $\alpha = 0.05$ 下以 80 % 功效检出萌发率从 80 % 到 90 % 的变化所需的每组数目。
::: answer
每组约 199。
:::
::: solution
$\bar p = 0.85$；$1.960\sqrt{2\times0.85\times0.15} = 1.960\times0.5050 = 0.9898$；$0.842\sqrt{0.16 + 0.09} = 0.842\times0.5 = 0.4208$。分子 $(1.4106)^2 = 1.990$；分母 $0.01$；$n = 199$。高比例之间的小差异需要大样本——而如果种子播在穴盘里，实验单元是盘，不是种子。
:::
:::

::: exercise 认出实验单元 {level=2}
对每项研究，指出实验单元并说明设计是否有重复：(a) 一块田里 12 个小区，随机分配 6 个施氮，每个小区测 30 株植物；(b) 一个湖施肥、一个留作对照，一个夏天里各取 50 个水样；(c) 24 只小鼠分养在 8 个笼中、每笼 3 只，日粮按笼分配；(d) 40 个 *Drosophila* 培养瓶，随机取 20 个给药，每瓶计数 10 只蝇。
::: solution
(a) 小区；有重复，每处理 6 个（每小区的 30 株植物是子样本）。(b) 湖；每处理一个，无重复——50 个水样是简单伪重复与时间伪重复；这是一个案例研究，整体生态系统实验有时不得不如此，用“处理前—处理后—对照—影响”（BACI）方法并谨慎解读。(c) 笼；8 笼，所以（若每种日粮 4 笼）每个处理 4 个重复，不是 12。(d) 瓶；每处理 20 个，蝇是子样本。
:::
:::

::: exercise 设计一个更好的实验 {level=3}
一名学生想知道咖啡因是否影响 *Daphnia*（水蚤）的心率。她的计划：从全班共用的培养液里取 20 只 *Daphnia*，在池水里测每只的心率，然后把全部 20 只转入咖啡因溶液再测一遍，由她自己在显微镜下数心跳打分。列出这个计划的四个弱点，并提出一个改进的设计。
::: solution
弱点：(1) 没有同期对照——任何变化都可能出自抓取、转移、时间、显微镜灯下升温或测量顺序，而不是咖啡因；(2) 没有随机化——测量的顺序与时刻是固定的；(3) 没有盲——她知道哪次测量是“加咖啡因之后”，又在肉眼计数，这个结局易受观察者偏倚影响；(4) 全部 *Daphnia* 来自同一培养，结果只适用于该培养；可能还有整个操作时段内的温度漂移。
改进的设计：把 *Daphnia* 随机分到两组，一组转入咖啡因溶液，另一组转入同样手法处理的池水（溶媒对照）；两组都在处理前后测量，使分析比较组间心率的*变化*（或以处理前的值为协变量，[[biostatistics/linear-models]]）；请第二个人给培养皿编号，使打分者处于盲中；在整个时段中按随机顺序交替安排处理与对照个体，并控制温度；用不止一个培养的个体作区组；根据预试验与所关心的最小变化确定样本量；并预先规定分析方案。
:::
:::

::: exercise 能均衡，何必随机？ {level=3}
一位研究者争辩说随机化没有必要：她要测量 20 只大鼠的初始体重，并据此分配处理，使各组的平均体重完全相同。解释 (a) 这能做到什么，(b) 做不到什么，(c) 如何把均衡与随机化结合起来。
::: solution
(a) 它均衡了一个已知的预后变量——初始体重，这能提高精度。
(b) 它对未测量的变量——窝别、性情、健康状况、笼内位置——无能为力；而且选用哪一个均衡的分配方案仍是她的决定，这个决定可能（即使无意识地）与其他特征相关。它还取消了随机化检验的基础：分配方案的概率分布无从定义。
(c) 按体重设区组：把大鼠按初始体重排序，将体重相近的大鼠组成区组（10 对，或 5 个四只区组），在每个区组内随机分配处理。这样既得到体重上的均衡，又得到随机化对其余一切变量的保护，分析中也应纳入区组。或者，自由随机化，并在分析中把初始体重作为协变量纳入（协方差分析）。
:::
:::
