孟德尔定律对二倍体的基因有三个隐含前提：它们在细胞核内；它们成对存在（父母各一）且均等传递；后代的表型取决于它自己的基因型。每一个前提都有例外。有些基因在线粒体和叶绿体里，通常只由一个亲本传递。有些后代的表型由母亲的基因型而非自己的基因型决定。有些基因只表达两份亲本拷贝中的一份，表达哪份取决于它来自哪个性别的亲本。还有些遗传元件在均等分离上做手脚，或在基因组内四处移动。这些现象没有一个推翻孟德尔遗传学；它们之所以被辨认出来，恰恰因为所得结果无法用孟德尔规则解释；而每一个都让我们懂得细胞与分子水平上遗传是如何运作的。

本章考察非孟德尔式遗传的主要类型：母性效应、细胞器基因组的遗传、基因组印记，以及一组其他例外——减数分裂驱动、转座元件、细胞质共生体、朊粒与拟表型遗传。反复出现的主题是诊断：给定一组杂交，我们如何判断起作用的是哪种机制？关键工具是互交（[[genetics/mendelian-inheritance#def-generations]]）、该性状多世代的行为，以及越来越多的 DNA 序列。人类实例只讲到机制层面；临床方面属于[医学图谱](/learn/medicine/lesson.php?c=genetics&l=non-mendelian-inheritance)。

## 母性效应

椎实螺 *Lymnaea peregra*（今常归入萝卜螺属 *Radix*）的贝壳或向右旋（右旋，常见类型）或向左旋（左旋）。1923 年，阿瑟·博伊科特（Arthur Boycott）与西里尔·戴弗（Cyril Diver）报告了螺旋方向以异常方式遗传的杂交；同年阿尔弗雷德·斯特蒂文特（Alfred Sturtevant）作出了解释：旋向由一个核基因控制，显性等位基因 *D* 决定右旋、隐性 *d* 决定左旋，但个体螺壳的旋向由其*母亲*的基因型决定，而非其自己的基因型。

::: definition 母性效应 {#def-maternal-effect}
**母性效应**是母亲的基因型（或表型）对子代表型的影响，与子代自己的基因型无关。在**母性效应基因**中，母亲的核基因型决定她沉积进卵细胞的产物——信使 RNA 或蛋白质——这些产物在早期发育中起作用。基因本身在核内，按孟德尔方式分离；只有它的表型表达被推迟了一个世代。
:::

椎实螺中，螺旋的取向在胚胎第三次卵裂时确立，远在胚胎自己的基因表达之前，起作用的是卵子发生中沉积进卵的基因产物。2016 年，两个课题组鉴定出该基因编码一个形成素（formin，一种肌动蛋白组织蛋白）；在近缘种静水椎实螺（*Lymnaea stagnalis*）中它是 *Lsdia1*，左旋螺携带一个移码等位基因。

::: example 螺壳旋向的三代遗传 {#ex-snail}
一只基因型 *dd* 的左旋雌螺与一只右旋雄螺 *DD* 交配。F1 自交（螺为雌雄同体），每只 F2 螺再自交产生一个 F3 家系。F1、F2 与 F3 的旋向表型分别是什么？
::: solution
**F1**：全为 *Dd*，但它们的母亲是 *dd*，所以 F1 全部**左旋**，尽管携带显性等位基因。

**F2**：基因型按分离为 $DD : Dd : dd = 1:2:1$。它们的母亲（一只 F1 螺）是 *Dd*，所以 F2 全部**右旋**，包括 *dd* 的那四分之一。

**F3**：每只 F2 螺产生的家系，其表型由该 F2 螺的基因型决定：来自 *DD* 与 *Dd* 亲本的家系（占 F2 螺的 $\tfrac34$）全部右旋，来自 *dd* 亲本的家系（占 $\tfrac14$）全部左旋。孟德尔 $3:1$ 比出现了——不过出现在 F3 的*家系*之间，而不是 F2 的个体之间。

注意反交：*DD* 母本 × *dd* 父本得全部右旋 F1，因为母亲是 *DD*。互交结果在 F1 就不同，正如性连锁与细胞质性状那样；但往后的世代会揭示一个核基因。
:::
:::

母性效应基因在许多动物早期发育中居于核心。在黑腹果蝇中，母本的 *bicoid* 基因提供定位于卵前端的 mRNA；其蛋白形成梯度，规定胚胎的头-尾轴。来自 *bicoid*$^-$/*bicoid*$^-$ 母亲的胚胎没有头和胸部，无论其自身基因型如何。克里斯蒂安娜·纽斯林-福尔哈特（Christiane Nüsslein-Volhard）与埃里克·维绍斯（Eric Wieschaus）在 1970 年代末与 1980 年代的大规模突变筛选中找到了这类基因（[[developmental-biology]]）。

## 细胞器遗传

线粒体与叶绿体含有各自小的、通常为环状的基因组，是它们源于内共生细菌的遗迹（[[cell-biology/organelles]]）。每个细胞含许多拷贝——典型动物细胞有线粒体 DNA（mtDNA）分子数百至数千个——细胞器随细胞质分裂分配到子细胞，而不经有丝分裂纺锤体。

::: definition 细胞器（细胞质）遗传 {#def-organelle}
**细胞器遗传**（细胞质遗传或染色体外遗传）是位于线粒体或质体基因组中的基因的传递。它通常表现为**单亲遗传**，最常见的是经由卵细胞的**母系遗传**，因为雌配子提供合子细胞质的大部分，而父源细胞器常被排除或降解。含有两种以上细胞器基因型混合物的细胞或生物是**异质的**（heteroplasmic）；只含单一类型的是**纯质的**（homoplasmic）。混合细胞可经随机分配产生纯质的子代细胞，这一过程称为**营养体**（或细胞质）**分离**。
:::

最早的例子发现于 1909 年——孟德尔定律被重新发现后不久——科伦斯（Carl Correns）在紫茉莉（*Mirabilis jalapa*）中、鲍尔（Erwin Baur）在天竺葵（*Pelargonium*）中。斑叶的紫茉莉植株有的分枝全绿，有的全白（缺乏叶绿素），有的斑纹。科伦斯发现，种子的表型只取决于开花的那条分枝（母本），而不取决于提供花粉的分枝：白色分枝上的花得白色幼苗（会死亡），绿色分枝上的花得绿色幼苗，斑纹分枝上的花得绿色、白色或斑纹幼苗，与花粉无关。遗传完全是母系的。缺陷位于质体基因组，斑纹组织是异质的，经营养体分离分配为绿色与白色区段。相比之下，鲍尔在天竺葵中发现质体来自双亲——植物中双亲遗传的质体并不罕见。

::: example 在酵母中分辨核遗传与细胞质遗传 {#ex-petite}
1949 年，鲍里斯·埃夫鲁西（Boris Ephrussi）发现酿酒酵母（*Saccharomyces cerevisiae*）的某些菌落因不能呼吸而以微小的"小菌落"（petite）缓慢生长。有些小菌落源于核突变（"分离型"小菌落），另一些源于 mtDNA 的丢失或损伤（"中性型"小菌落）。将一个单倍体小菌落与另一交配型的野生型单倍体杂交，让二倍体产孢并解剖四分体。预测两类小菌落各自的四分体型式。
::: solution
**分离型（核）**小菌落：二倍体为杂合 *pet*$^-$/*pet*$^+$，并带有野生型亲本的正常线粒体，故呼吸正常。减数分裂时核等位基因 $2:2$ 分离（[[genetics/chromosomes-meiosis#ex-tetrads]]）：每个四分体有 2 个孢子为小菌落、2 个为野生型。

**中性型（细胞质）**小菌落：二倍体从野生型亲本得到正常线粒体（酵母接合子从双亲都继承线粒体），缺陷的 mtDNA 被丢失或被竞争掉。四个孢子都得到正常线粒体：小菌落 : 野生型 $= 0:4$。而在"抑制型"小菌落中，缺陷 mtDNA 反而占上风，许多二倍体及其孢子为小菌落：$4:0$ 四分体。四分体中非 $2:2$ 的分离，是非核遗传的标志。
:::
:::

玛丽与赫舍尔·米切尔（Mary and Hershel Mitchell）（1952）在脉孢菌（*Neurospora crassa*）中发现了类似的细胞质遗传慢生长突变体 *poky*，只经母本（原子囊壳）亲本传递。线粒体 DNA 本身由玛吉特与西尔万·纳斯（Margit and Sylvan Nass）1963 年发现：他们在电镜下看到鸡胚线粒体内部的 DNA 纤维。

### 人的线粒体 DNA

人的 mtDNA 是一个 16,569 bp 的环，由弗雷德·桑格（Fred Sanger）在剑桥的课题组于 1981 年测定。它携带 37 个基因：13 个编码呼吸链与 ATP 合酶的蛋白质，22 个转运 RNA 与 2 个核糖体 RNA。其余一千多种线粒体蛋白质都由核基因组编码并输入。mtDNA 按母系遗传：精子的线粒体在受精时进入卵细胞，但在早期胚胎中被主动清除。

线粒体突变遵循三条使其区别于核突变的规则。

1. **母系传递。** 患病女性可把突变传给她的全部孩子；患病男性一个也不传。
2. **异质性。** 母亲可同时携带突变与正常 mtDNA，其比例在各孩子之间、各组织之间都会变动。
3. **阈值。** 只有当突变 mtDNA 的比例超过某一阈值（常为 60–90 %）时组织才受累；需呼吸供能高的组织（脑、肌肉、心脏）阈值最高。

第一个致病 mtDNA 突变由道格拉斯·华莱士（Douglas Wallace）及同事于 1988 年在莱伯遗传性视神经病变——一种致中心视力丧失的疾病——的家系中鉴定；它是复合体 I 亚基 ND4 基因中的一个错义突变，通常为纯质。

::: intuition 线粒体瓶颈
一个人卵含数十万个 mtDNA 分子，然而一位母亲的孩子们异质性水平可以与她、也彼此相差悬殊——一个孩子几乎不带某突变，同胞却有大部 mtDNA 为突变型。解释是雌性生殖系中的**瓶颈**：mtDNA 分子数（或一起传递的分子组——分离单位数）在原始生殖细胞中降到很小的数目，随后再扩增。从混合群体中随机抽取少量单位，所得组成可以仅凭机会而与群体大不相同——与驱动小群体遗传漂变的抽样过程相同（[[population-genetics/genetic-drift]]）。
:::

::: proposition 瓶颈之后的异质性 {#prop-bottleneck}
设某母亲生殖系细胞有比例 $p$ 的突变 mtDNA，每只卵的 mtDNA 群体源自 $n$ 个分离单位的随机抽样（有放回抽取，随后扩增而不再改变）。则卵中突变单位数 $K$ 服从二项分布（$n$，$p$），卵的异质性水平 $h = K/n$ 满足

$$
\E[h] = p, \qquad \Var(h) = \frac{p(1-p)}{n},
$$ {#eq-bottleneck}

而一只卵超过阈值 $\theta$ 的概率为 $P(K \ge \lceil n\theta \rceil)$。若一条母系谱系中每一代都重复这一瓶颈，$t$ 代后 $h$ 的方差为 $p(1-p)\left[1 - (1 - 1/n)^t\right]$，趋于 $p(1-p)$：谱系终将变为纯质，成为突变型的概率为 $p$。
:::

::: proof
$n$ 个单位各自独立地以概率 $p$ 为突变型，故 $K$ 服从二项分布；$\E[K] = np$ 且 $\Var(K) = np(1-p)$，所以 $\E[h] = p$ 且 $\Var(h) = p(1-p)/n$。对重复瓶颈，设 $H_t = \E[h_t(1-h_t)]$。给定 $h_{t}$，下一代 $h_{t+1}$ 的均值为 $h_t$、方差为 $h_t(1-h_t)/n$，于是 $\E[h_{t+1}(1-h_{t+1}) \mid h_t] = h_t - (h_t^2 + h_t(1-h_t)/n) = h_t(1-h_t)(1 - 1/n)$。故 $H_t = p(1-p)(1-1/n)^t$。又因对所有 $t$ 有 $\E[h_t] = p$，$\Var(h_t) = \E[h_t^2] - p^2 = p - H_t - p^2 = p(1-p)\left[1 - (1-1/n)^t\right]$。
:::

::: example 超过阈值的孩子 {#ex-threshold}
一位女性生殖系有 40 % 突变 mtDNA。设瓶颈为 $n = 20$ 个分离单位，表型阈值为 60 %。(a) 其卵的异质性的均值与标准差是多少？(b) 其卵中有多大比例超过阈值？
::: solution
(a) $\E[h] = 0.40$，$\mathrm{SD}(h) = \sqrt{0.4\times0.6/20} = \sqrt{0.012} = 0.110$。

(b) 阈值要求 20 个单位中 $K \ge 12$ 为突变型。$P(K \ge 12) = \sum_{k=12}^{20}\binom{20}{k}0.4^k0.6^{20-k} = 0.057$。所以在此模型下约 6 % 的卵会超过阈值，尽管母亲本人在阈值之下。模型是简化——真实瓶颈大小要由数据估计、因突变而异，且选择可作用于突变 mtDNA——但它抓住了线粒体病风险难以对单个家庭做出预测的原因。生殖与临床问题属于临床遗传服务，不属于这一计算。
:::
:::

::: quiz
一个性状：患病的男性不传给任何孩子，而患病的女性传给全部孩子，且轻重不一。哪种机制最符合？
- [ ] X 连锁显性等位基因
- [ ] 母性效应的核基因
- [x] 线粒体突变
- [ ] 父源表达的印记基因
::: solution
母亲传给全部孩子、父亲一个不传、且轻重不一，是伴异质性的 mtDNA 遗传的特征。X 连锁显性等位基因会由患病男性传给他的全部女儿；母性效应基因会由父亲传给孙辈；父源表达的印记等位基因会在由男性而非女性传递时显效。
:::
:::

因为 mtDNA 按母系遗传、不与父源重组、突变比多数核 DNA 快，它记录母系谱系，已被广泛用于进化研究。丽贝卡·坎（Rebecca Cann）、马克·斯托金（Mark Stoneking）与阿兰·威尔逊（Allan Wilson）（1987）用它推断：今日全部人类 mtDNA 谱系都源自约 20 万年前存在于非洲的一个共同祖先分子，这一结论其后被全基因组数据修正（[[evolution]]）。这样一个 DNA 片段的共同祖先并不是群体的唯一祖先：当时存活的每个人都对基因组的其他部分有贡献。

::: warning "母系遗传与母性效应是一回事"
两者都使互交结果不同，但机制与往后的世代完全不同。**母性效应**性状由核基因控制；它延迟一个世代，但最终在家系之间呈现孟德尔比例，父亲会把等位基因传给孙辈。**母系遗传**（细胞器）性状由细胞器基因控制；它从不呈现孟德尔比例，不依赖父亲任何核等位基因，并且逐代都经雌性传递。在家系图中，有鉴别力的观察是：一个患病的*孙辈*能否把该性状追溯到它的*父系祖父*（核基因可能，mtDNA 不可能）。
:::

## 基因组印记

1984 年，两个课题组——詹姆斯·麦格拉思（James McGrath）与达沃尔·索尔特（Davor Solter），以及阿齐姆·苏拉尼（Azim Surani）、希拉·巴顿（Sheila Barton）与迈克尔·诺里斯（Michael Norris）——在小鼠受精卵之间移植原核，制造出两套基因组都来自母亲（**雌核发育**）或都来自父亲（**雄核发育**）的胚胎。两类都失败了。雌核发育胚胎的胚胎本体发育相对正常，但胎盘极少；雄核发育胚胎发育出胎盘组织，胚胎本体却很差。哺乳类需要一套母源加一套父源基因组。因此某些基因必定按继承自哪个性别亲本而表现不同。

::: definition 基因组印记 {#def-imprinting}
**基因组印记**是一个基因只表达两份亲本等位基因中的一份，表达哪份由传递它的亲本的性别决定。**母源表达**的基因只表达来自母亲的等位基因（父源等位基因被沉默，即被*印记*）；**父源表达**的基因相反。印记是一种表观遗传标记——主要是**印记控制区**处的 DNA 甲基化——在各性别的生殖系中建立，在子代的体细胞分裂中维持，又在子代自己的生殖系中按其性别被擦除并重设。
:::

小鼠与人已知的印记基因约 100–200 个，多成簇分布；印记见于胎盘哺乳类与有袋类，并在被子植物的胚乳中独立存在。最早的小鼠例子发现于 1991 年。托马斯·德基亚拉（Thomas DeChiara）、伊丽莎白·罗伯逊（Elizabeth Robertson）与阿吉里斯·埃夫斯特里亚季斯（Argiris Efstratiadis）发现，编码胰岛素样生长因子 2 的 *Igf2* 的突变等位基因，父源遗传时使仔体矮小，母源遗传时毫无效应：*Igf2* 是父源表达的。丹尼斯·巴洛（Denise Barlow）及同事发现，编码从循环中清除 IGF2 的受体的 *Igf2r* 是母源表达的。

::: proposition 印记等位基因的传递 {#prop-imprinted}
设功能丧失等位基因 $a$ 位于一个只由父源等位基因表达的基因中，$a$ 母源遗传时不产生效应。则后代当且仅当从父亲继承 $a$ 时表现突变表型。杂合父亲把它——以及该表型——传给一半孩子；杂合母亲把 $a$ 传给一半孩子，其中无一出现表型，但她的儿子们随后可把它传给患病的孙辈。对母源表达的基因，把"父亲"与"母亲"互换。
:::

::: proof
后代只有父源拷贝有活性。若父源拷贝是 $a$，该基因就没有有功能的功能拷贝（母源拷贝无论等位基因如何都沉默），表型为突变型；若父源拷贝是 $A$，则无论母源拷贝如何都正常。杂合亲本按分离以概率 $\tfrac12$ 传递 $a$，而印记在亲本生殖系中按亲本性别重设，所以女子的等位基因永远带着母源印记传递，男子的永远带着父源印记传递，与它们在亲本体内曾如何被印记无关。
:::

::: example 一个印记家系图 {#ex-imprinting-pedigree}
一名男子对一个父源表达基因的功能丧失等位基因是杂合的，但表型正常（因为他从母亲继承了该等位基因），他与一无血缘关系的女子育有四个孩子。(a) 某一指定孩子出现表型的概率是多少？(b) 他的女儿继承了该等位基因。她孩子出现表型的概率是多少？(c) 一个长家系会显示什么格局？
::: solution
(a) 父亲现在以父源印记传递等位基因，所以从他获得 $a$ 的孩子（概率 $\tfrac12$）没有有功能的拷贝，将出现表型：$\tfrac12$。

(b) 女儿本人有表型（她从父亲得到 $a$），但她以母源印记传递它：她获得 $a$ 的孩子（概率 $\tfrac12$）带着沉默的母源 $a$ 与来自其父亲的有活性父源等位基因，所以正常。概率 0。

(c) 该性状出现在携带者男子约一半孩子中，而不出现于携带者女子的任何孩子中，所以经女性传递时可隔代跳过，经男性传递时又再现——一个亲本来源效应，若不留意传递亲本的性别，会酷似不完全外显。
:::
:::

人 15 号染色体一个区段（15q11–q13）同时含有父源表达与母源表达的基因。父源贡献的丧失——经由父源 15 号染色体上的缺失，或**单亲二体**（两条 15 号染色体都继承自母亲，如罗伯特·尼科尔斯（Robert Nicholls）及同事 1989 年所证明）——导致普拉德-威利综合征；母源贡献的丧失，尤其是母源表达基因 *UBE3A* 的丧失，导致天使综合征。同一段缺失因传递亲本不同而产生两种不同的疾病。

印记为何进化尚有争论。最有影响的是大卫·黑格（David Haig）与马克·威斯托比（Mark Westoby）（1989）的**亲代冲突**（亲缘）假说，其出发点是：在母亲可能与多个父亲生育后代的物种中，父源继承的基因多为其携带者榨取更多母源资源便有所得，而母源继承的基因则克制索取、顾全母亲的其他后代便有所得。它预言父源表达的基因倾向促进生长（如 *Igf2*），母源表达的基因倾向抑制生长（如 *Igf2r*），观察常与之相符，尽管并非每个印记基因都符合。印记还使哺乳类不能经孤雌生殖繁殖。

## 孟德尔式传递的其他例外

还有若干现象破坏了公平、核内、双拷贝传递的规则。

- **减数分裂驱动。** 某些等位基因或染色体被传递到杂合子一半以上的配子中，违反均等分离。例子有小家鼠的 *t*-单倍型（[[genetics/chromosomes-meiosis]]）与黑腹果蝇（*Drosophila melanogaster*）的 *Segregation Distorter*（SD 系统）——后者杀死或致残携带对手同源体的精子；还有雌性减数分裂中"自私"着丝粒的驱动——它们优先进入卵细胞而非极体。驱动能使一个等位基因扩散，即使它降低适合度，这一主题见 [[evolution]]。
- **转座元件。** 1940 年代，麦克林托克在玉米中发现，*Dissociation*（*Ds*）元件使其自身所在处发生染色体断裂，并在第二个元件 *Activator*（*Ac*）的控制下从一处移到另一处，产生不稳定突变与斑驳籽粒；她于 1950–51 年描述了这一系统。转座元件后来在所有生物中都有发现，约占人基因组的 45 %。果蝇中，*P* 因子引起**杂种发育不良**——携带 *P* 因子的雄性与不携带的雌性交配，后代不育且突变率升高——一个依赖于母亲细胞质的非互交现象，因为把元件钳制住的有抑制作用的小 RNA（piRNA）是母源遗传的。
- **细胞质共生体。** 细胞内生活的细菌可以像细胞器一样母系遗传。沃尔巴克氏体（*Wolbachia*）见于很大比例的昆虫物种，它为自身的传递操纵繁殖：**细胞质不亲和**中，感染雄性与未感染雌性的胚胎死亡，于是感染雌性占优势。释放感染沃尔巴克氏体的蚊子正被用于抑制登革热病毒的传播（[[ecology]]）。特雷西·索恩伯恩（Tracy Sonneborn）在草履虫（*Paramecium*）中研究的"卡巴"颗粒（1940 年代）是一个早期例子：一个细胞质遗传的性状，后来查明是一种细菌共生体。
- **朊粒。** 酵母中，某些蛋白质能采取自我传播的聚集构象，把该蛋白的正常拷贝转变为同一形式。里德·威克纳（Reed Wickner）1994 年提出，非孟德尔性状 [PSI$^+$] 与 [URE3] 是蛋白质 Sup35 与 Ure2 的朊粒形式。这类性状经细胞质传递，与正常菌株杂交给 $4:0$ 四分体。
- **拟表型遗传。** 玉米中，亚历山大·布林克（Alexander Brink）1956 年描述了一种相互作用：*r1* 基因的一个等位基因可遗传地改变同一植株中另一个等位基因的表达，以致被改变的那个等位基因在分离出去之后也不再恢复原来的表达——一个可遗传的表观遗传改变，违反了等位基因从杂合子中不带改变地分离出来的原则。

::: application 线粒体置换与细胞器工程
因为 mtDNA 疾病经卵细胞质传递，人们发展出这样的技术：把患病女性卵或合子的核基因组转移到一根去核、带正常线粒体的供体卵中。英国经广泛的公众咨询与审查后，自 2015 年起在许可制度下允许这种**线粒体捐赠**；经此技术出生的儿童的首批报告于 2025 年发表。这一技术带来科学问题（少量突变 mtDNA 的伴随转移，它可能在瓶颈中增大）与伦理问题，受到严格监管。植物中，叶绿体的母系遗传被用于农业：线粒体基因引起的**细胞质雄性不育**使杂种种子生产免于人工去雄，而置于叶绿体基因组中的外源基因很少经花粉传递。
:::

::: history
科伦斯 1909 年描述了紫茉莉叶色斑纹的母系遗传，鲍尔同年描述了天竺葵质体的双亲遗传。博伊科特与戴弗 1923 年报告了椎实螺螺壳旋向的遗传，斯特蒂文特同年以母性效应作解释。埃夫鲁西 1949 年描述了酵母小菌落，玛丽与赫舍尔·米切尔 1952 年描述了脉孢菌的 *poky*，玛吉特与西尔万·纳斯 1963 年在线粒体中发现 DNA。麦克林托克 1950–51 年描述了玉米的 *Ac*/*Ds* 转座（1983 年诺贝尔奖）。人的线粒体基因组由斯蒂芬·安德森（Stephen Anderson）及同事在桑格实验室于 1981 年测定；华莱士的课题组 1988 年找到第一个致病 mtDNA 突变。麦格拉思与索尔特、苏拉尼课题组 1984 年在小鼠中证明双亲基因组不等效；最早的印记基因 1991 年被鉴定。
:::

::: summary
- 互交结果不同，提示性连锁、母性效应或细胞器遗传；由往后的世代加以区分。
- **母性效应**：母亲的核基因型经沉积进卵的产物决定子代表型（螺壳旋向、*bicoid*）。基因照常分离；孟德尔比例晚一个世代出现，出现在家系之间。
- **细胞器遗传**：线粒体与质体基因通常单亲传递（动物与许多植物为母系），不呈孟德尔比例，并从异质细胞经营养体分离。酵母细胞质小菌落给非 $2:2$ 四分体。
- 人 mtDNA（16,569 bp，37 个基因）母系遗传；异质性、生殖系瓶颈与阈值使传递多变。$n$ 个分离单位时，卵的异质性均值为 $p$、方差为 $p(1-p)/n$。
- **基因组印记**：生殖系 DNA 甲基化设定的亲本来源特异表达，每一代重设（*Igf2* 父源，*Igf2r* 母源；15q11–q13）。印记等位基因只在由一个性别的亲本传递时显效。
- 减数分裂驱动、转座元件、细胞质共生体（*Wolbachia*）、朊粒与拟表型遗传，是偏离公平、核内、孟德尔式传递的更多情形。
:::

## 练习

::: exercise 一只左旋螺 {level=1}
一只右旋螺只产左旋后代。这只螺的基因型是什么？关于它母亲的基因型你能说什么？
::: solution
这只螺必为 *dd*，因为只有 *dd* 母亲产生左旋后代。它本人为右旋，说明它的母亲至少带一个 *D*（*DD* 或 *Dd*）；既然它是 *dd*，母亲必为 *Dd*（而父亲携带 *d*）。
:::
:::

::: exercise 一条斑纹分枝 {level=1}
一株斑纹紫茉莉上，绿色分枝上的花用白色分枝来的花粉授粉。预计得到什么幼苗？若把交配反过来呢？
::: solution
遗传是母系的：绿色分枝上的花得到绿色幼苗，与花粉无关。反交中，白色分枝上的花得到白色幼苗（因缺乏叶绿素而死亡），与花粉无关。
:::
:::

::: exercise 异质性的散布 {level=1 check="0.1"}
一位女性有 50 % 突变 mtDNA。瓶颈为 $n = 25$ 个分离单位时，她卵的异质性水平的标准差是多少？
::: solution
由[[#eq-bottleneck]]，$\sqrt{0.5\times0.5/25} = \sqrt{0.01} = 0.1$。
:::
:::

::: exercise F3 家系 {level=2 check="1/4"}
在[[#ex-snail]]的螺杂交中，全部由左旋螺组成的 F3 家系占什么比例？
::: solution
来自 *dd* F2 亲本的 F3 家系为左旋：F2 中 $\tfrac14$ 是 *dd*，所以家系的 $\tfrac14$。
:::
:::

::: exercise 印记的孙辈 {level=2 check="1/4"}
一位女子的父亲在一个父源表达的基因中携带一个功能丧失等位基因（他从自己的母亲继承，本人未患病）。该女子的伴侣不携带此等位基因。她的儿子继承该等位基因的概率是多少？这样的儿子会患病吗？
::: solution
女子的父亲以概率 $\tfrac12$ 把等位基因传给她（若传给她，她因从父亲获得而患病）。她以概率 $\tfrac12$ 传给儿子，所以儿子携带它的概率为 $\tfrac12\times\tfrac12 = \tfrac14$。但儿子继承它时带的是母源印记：沉默的拷贝才是突变的那个，而他来自非携带者父亲的父源拷贝有活性。他不会患病。然而他自己的、从他继承该等位基因的孩子则会患病（[[#prop-imprinted]]）。
:::
:::

::: exercise 阈值概率 {level=2 check="0.172"}
一位女性有 50 % 突变 mtDNA，瓶颈为 $n = 10$ 个分离单位。她至少 70 % 突变 mtDNA 的卵占多大比例（保留三位小数）？
::: solution
至少 70 % 即 $K \ge 7$ 共 10。$P(K \ge 7) = [\binom{10}{7} + \binom{10}{8} + \binom{10}{9} + \binom{10}{10}]/2^{10} = (120 + 45 + 10 + 1)/1024 = 176/1024 = 0.172$。
:::
:::

::: exercise 诊断一种格局 {level=2}
一个植物性状显示如下：突变型与野生型品系互交，F1 像母本；两类互交的 F1 各自交，F2 全部像它们的 F1 母亲；以 F1 为母本与野生型回交六代，表型不变。（a）这是什么遗传？（b）如何排除母性效应？
::: solution
（a）母系（细胞质）遗传，大概是质体或线粒体基因：表型沿母系无限延续、从不分离，即便反复回交已把几乎整个核基因组换成野生型的（经典的"核置换"测验）。

（b）母性效应的核基因会在晚一个世代显示孟德尔分离：F2 植株*它们的*后代会互不相同，F3 家系间呈 $3:1$（或相近）比例。以野生型为父本反复回交，最终也会使母亲成为杂合或野生型，使后代表型改变。此处两者都不发生。
:::
:::

::: exercise 预测印记表型 {level=3}
小鼠中 *Igf2* 父源表达，*Igf2r*（其产物降解 IGF2、从而抑制生长）母源表达。两者的无效等位基因均可获得。预测下列仔体的体型（小、正常或大）：(a) 杂合 *Igf2*$^{+/-}$ 雄 × 野生型雌，继承无效等位基因的后代；(b) 野生型雄 × 杂合 *Igf2*$^{+/-}$ 雌，继承无效等位基因的后代；(c) 杂合 *Igf2r*$^{+/-}$ 雌 × 野生型雄，继承无效等位基因的后代。(d) 这些结果如何与亲代冲突假说相符？
::: solution
(a) 无效等位基因为父源，唯一表达的 *Igf2* 拷贝无功能：**小**仔体（德基亚拉及同事的发现）。

(b) 无效等位基因为母源，本来就沉默；父源拷贝有活性：**正常**。

(c) 无效 *Igf2r* 为母源，而母源拷贝正是表达的那份，于是没有有功能的受体降解 IGF2：**大**仔体（IGF2 活性过剩；小鼠中这一过度生长常在出生前即致死）。

(d) 父源表达的基因促进生长，母源表达的基因抑制生长，正如以下预言：父源继承的基因偏向榨取更多母源资源，母源继承的基因偏向有所保留。该理论对每个印记基因都作出这一定性预言；许多但并非全部印记基因符合，且存在其他假说。
:::
:::

::: exercise 解读一个线粒体家系 {level=3}
在一个患某种罕见线粒体病的家系中，一位患病女性有五个孩子：两个重度受累、两个轻度受累、一个正常；她的患病兄弟有四个孩子，无一患病。(a) 解释这两个观察。(b) 利用[[#prop-bottleneck]]解释为何她的孩子轻重不一。(c) 为何难为她女儿未来的孩子给出精确风险？
::: solution
(a) mtDNA 母系遗传，所以兄弟不把自己的任何 mtDNA 传给孩子们；女子则把她的传给全部孩子。

(b) 女子大概是异质的。她的卵经生殖系瓶颈拿到 mtDNA 的不同随机样本，所以孩子们突变 mtDNA 的比例不同，各组织的水平可能在阈值之上或之下、程度不一。每个孩子内部各组织之间的差异（来自其后发生的营养体分离）又加大了差别。

(c) 每位女儿生殖系的异质性水平无法确切知道（血液等可取组织可能与生殖系不同），有效瓶颈大小因突变与个体而异，选择可能有利于或不利于突变 mtDNA，阈值也不锐利。二项模型给出一系列可能结果的分布，而非确定预言。这样的家庭应由临床遗传服务提供咨询，而非此类计算。
:::
