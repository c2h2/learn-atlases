1945 年，几乎没有人认为细菌拥有与豌豆和果蝇同样意义上的基因。它们以二分裂繁殖，不显示减数分裂，也没有可见的染色体；它们的遗传看起来只是含糊的"适应"而已。十五年之内，细菌及其病毒却成了遗传学的首选生物。它们的基因可以作图，它们内部的突变可以在一只培养皿里从几十亿个细胞中选择出来，第一套基因调控系统也是在它们身上弄清楚的。理由很实际：大肠杆菌（*Escherichia coli*）培养物在丰富培养基中每 20–30 分钟翻倍，每毫升达到 $10^9$ 个细胞；细菌是单倍体，每个突变都得到表达；而借助选择培养基，可以在一亿个亲本中找出一个重组体。

本章描述基因如何在细菌之间移动——**转化**、**接合**与**转导**——以及每一过程如何被用来给基因作图；接着是噬菌体的遗传学；最后是部分二倍体在互补与调控分析中的用法。通篇讨论的都是实验室菌株，描述停留在原理层面：处理微生物的技术属于有教师指导的教学实验室，细菌遗传学的医学方面则属于[医学图谱](/learn/medicine/course.php?c=microbiology)。微生物作为生物体的生物学是 [[microbiology]] 的主题。

## 细菌基因组、表型与命名符号

大多数经典工作所用的实验室菌株大肠杆菌 K-12，其基因组是一个 $4.64\times10^6$ bp 的单一环状染色体，携带约 4300 个蛋白质编码基因。许多细菌还携带**质粒**：通常环状的小 DNA 分子，独立于染色体复制，携带的基因在某些环境中有用但并非必需，例如抗生素或重金属抗性基因、利用非常规营养物的基因，或向其他细胞转移 DNA 的基因。

细菌基因用三个斜体小写字母加一个表示特定基因的大写字母命名，如 *lacZ*、*lacY*、*trpA*；蛋白质写作首字母大写的正体：LacZ。表型写作首字母大写的正体：Lac$^+$（能利用乳糖）、Lac$^-$、Str$^\mathrm{r}$（链霉素抗性）、Str$^\mathrm{s}$（链霉素敏感）。基因型用斜体带上同样的上标：*lacZ*$^-$ 突变体是 Lac$^-$。营养缺陷型（[[genetics/genes-and-mutation#def-auxotroph]]）按其需要的营养物命名：*his*$^-$ 菌株需要组氨酸。

关键的实验工具是**选择培养基**：只有特定表型的细胞能在其上生长。基本培养基选择原养型；含抗生素的培养基选择抗性细胞；以乳糖为唯一碳源的培养基选择 Lac$^+$ 细胞。与影印培养（[[genetics/genes-and-mutation]]）结合，选择可以在 $10^8$ 个亲本中找出并计数极少数重组细胞。

::: definition 细菌的基因转移方式 {#def-transfer}
细菌不融合整套基因组。而是**供体**的一个 DNA 片段进入**受体**，使受体在所转移区段上成为暂时的**部分二倍体**（merozygote）。进入方式有三种：
- **转化**：摄取环境中的游离 DNA；
- **接合**：由接合质粒主导、经细胞直接接触的 DNA 转移；
- **转导**：被错误包装进噬菌体颗粒内的细菌 DNA 的转移。

供体片段（外源子）经同源重组并入受体的染色体（内源子）。因为线性片段必须在不开环的前提下接进环状染色体，并入需要**偶数次交换**，被选标记的两侧各一次；未并入的线性 DNA 被降解。
:::

::: intuition 细菌重组按对计数交换
在二倍体真核生物中，两个基因座之间任意奇数次交换就使产物成为重组型。而接受线性片段的细菌中，单次交换会把环状染色体打开成细胞无法维持的线状；存活的重组体需要片段与染色体之间两次（或四次、六次）交换。供体标记只有两侧各落一次交换才进入受体染色体；两个供体标记只有其间不落在交换时才一起遗传。两个标记共遗传的频率因此度量它们的接近程度。
:::

## 接合

1946 年，约书亚·莱德贝格（Joshua Lederberg）与爱德华·塔特姆（Edward Tatum）把大肠杆菌 K-12 的两株不同的多重营养缺陷型——一株需要苏氨酸、亮氨酸与硫胺素，另一株需要生物素、苯丙氨酸与半胱氨酸——混合后涂布在基本培养基上。任一菌株单独都不能生长，而一株菌三个突变同时回复的机会微乎其微；然而原养型菌落以约 $10^{-7}$ 的频率出现了。1950 年，伯纳德·戴维斯（Bernard Davis）证明：若两株菌分置于 U 形管两侧、由只透过培养基不透过细胞的滤板隔开，就不形成原养型——转移需要细胞接触。

::: definition F 因子、Hfr 菌株与 F′ 质粒 {#def-f-factor}
威廉·海斯（William Hayes）、卢卡·卡瓦利-斯福尔扎（Luca Cavalli-Sforza）与莱德贝格夫妇在 1950 年代初证明，转移是单向的，并由一个质粒——**育性因子 F**——控制。F$^+$ 细胞携带 F，充当供体；F$^-$ 细胞缺少它，充当受体。F$^+$ × F$^-$  杂交中，F 被复制并转移，受体因此变成 F$^+$，但染色体基因很少被转移。**Hfr**（高频重组）菌株中，F 已通过重组整合进细菌染色体；转移随即从整合的 F 内部的**转移起点**开始向染色体中进行，按固定次序线性地携带染色体基因。**F′ 质粒**是 F 因子从 Hfr 染色体切离时带走了一段染色体 DNA 的产物；得到它的细胞对该区段是稳定的部分二倍体。
:::

整个 Hfr 染色体在 37 ℃ 转移完约需 100 分钟，但交配对在此之前很久就已分开，所以靠近起点的基因进入许多受体，远离者进入的很少。受体很少收到转移链末端的那部分 F，因此通常仍是 F$^-$。

埃利·沃尔曼（Élie Wollman）与弗朗索瓦·雅各布（François Jacob）在 1955–57 年的**中断杂交**实验中利用了这一点。他们混合 Hfr 与 F$^-$ 细胞，间隔取样，在厨房搅拌器里剧烈搅动以拆开交配对，再把各样品涂布在依次选择各供体标记重组体的培养基上（同时用受体抗性的抗生素杀死 Hfr 供体）。每个供体基因在一个特征性的**进入时间**首先出现在重组体中，随后每个基因的重组体频率上升到一个平台，基因进入越晚，平台越低。

::: proposition 进入时间作图 {#prop-time-of-entry}
Hfr × F$^-$ 杂交中，供体基因按由整合的 F 的位置与取向决定的固定线性次序、以恒定速度进入受体。基因首次进入的时间度量它到转移起点的距离，两个基因进入时间之差度量它们在染色体上的距离。因此大肠杆菌染色体图以**分钟**计量，整个环 100 分钟，一分钟平均约相当于 46 kb。
:::

::: example 一个中断杂交实验 {#ex-interrupted}
一个 Hfr 菌株为 Str$^\mathrm{s}$，携带野生型等位基因 *azi*$^\mathrm{s}$（对叠氮化钠敏感）、*ton*$^\mathrm{s}$（对噬菌体 T1 敏感）、*lac*$^+$ 与 *gal*$^+$，以及标记 *thr*$^+$ *leu*$^+$，与一个 F$^-$ 菌株（Str$^\mathrm{r}$，*thr*$^-$ *leu*$^-$ *azi*$^\mathrm{r}$ *ton*$^\mathrm{r}$ *lac*$^-$ *gal*$^-$）杂交。按 Thr$^+$ Leu$^+$ Str$^\mathrm{r}$ 选择重组体（*thr* 与 *leu* 先进入），在不同时间中断的样品则针对未选择的供体标记计分。所选重组体中携带各供体等位基因的百分比为：

| 时间（min） | *azi*$^\mathrm{s}$ | *ton*$^\mathrm{s}$ | *lac*$^+$ | *gal*$^+$ |
|---|---|---|---|---|
| 5 | 0 | 0 | 0 | 0 |
| 10 | 12 | 3 | 0 | 0 |
| 15 | 70 | 31 | 0 | 0 |
| 20 | 88 | 70 | 16 | 0 |
| 30 | 91 | 80 | 38 | 21 |
| 60 | 91 | 80 | 40 | 25 |

给出基因次序，并估计进入时间与间隔。
::: solution
基因出现的次序是 *azi*、*ton*、*lac*、*gal*；把各上升曲线外推回零，得进入时间约 9、10–11、18 与 25 分钟。所以从起点起的次序是（*thr leu*）– *azi* – *ton* – *lac* – *gal*，其中 *azi*–*ton* 约 2 分钟，*ton*–*lac* 约 7 分钟，*lac*–*gal* 约 7 分钟。平台依次降低（91、80、40、25 %），因为交配对的自发拆开使晚进入的基因被转移的机会变小：这一**转移梯度**本身即使不中断也能给出近似的次序。选择早期标记 *thr* 与 *leu*，保证每个计分的细胞确实交配过；链霉素杀死供体。

::: example 拼出环状图 {#ex-circle}
四个 Hfr 菌株按下列次序转移基因（每个列表以最先转移的基因为首）：

- Hfr 1：*thr leu azi ton pro lac*
- Hfr 2：*pro ton azi leu thr thi*
- Hfr 3：*his trp gal lac pro ton*
- Hfr 4：*thi met str his trp gal*

::: solution
Hfr 1 给出区段 *thr–leu–azi–ton–pro–lac*。Hfr 2 按 *pro–ton–azi–leu–thr*（同一区段的反向）进行并继续到 *thi*，所以 *thi* 在 *thr* 之外。Hfr 3 给出 *his–trp–gal–lac–pro–ton*，所以 *gal*、*trp* 与 *his* 在 *lac* 之外。Hfr 4 给出 *thi–met–str–his–trp–gal*，把 *thi* 端与 *his* 端接起来。这些基因构成一个闭合的环：

*thr – leu – azi – ton – pro – lac – gal – trp – his – str – met – thi* –（回到 *thr*）。

F′ 质粒使细胞对基因组的某一部分成为二倍体，从而可以在细菌中做互补与显性测验。最著名的用法是弗朗索瓦·雅各布与雅克·莫诺（Jacques Monod）1959–61 年构建的 *lac* 基因部分二倍体。阻遏蛋白基因 *lacI* 以 *trans* 方式作用：任一拷贝上的野生型 *lacI*$^+$ 使两份拷贝都可诱导。操纵基因突变 *lacO*$^\mathrm{c}$ 只以 *cis* 方式作用：它只使同一 DNA 分子上的 *lacZ* 基因组成型表达。这些**顺式-反式**观察——[[genetics/genes-and-mutation#def-complementation]] 的逻辑用于调控——导致了操纵子模型，见 [[molecular-biology]]。

- [ ] 组成型，因为 *lacO*$^\mathrm{c}$ 是显性
- [x] 仅在诱导物存在时
- [ ] 完全不合成
- [ ] 一份拷贝组成型，另一份可诱导
::: solution
唯一有功能的 *lacZ* 基因紧挨野生型操纵基因，除非诱导物存在外，阻遏蛋白都结合其上。*lacO*$^\mathrm{c}$ 突变只影响同一 DNA 分子上的基因（*cis* 显性），而那个基因是 *lacZ*$^-$，它表达什么都是失活的。所以有功能酶的合成是可诱导的。
:::

## 转导

1952 年，诺顿·辛德（Norton Zinder）与约书亚·莱德贝格在肠道沙门氏菌鼠伤寒血清型（*Salmonella enterica* serovar Typhimurium，实验室菌株 LT2）中寻找接合，却发现基因可由噬菌体 P22 在菌株间携带，甚至能穿过拦截细胞的滤板——一种新的转移方式，**转导**。

::: definition 普遍性转导与局限性转导 {#def-transduction}
**普遍性转导**中，靠把头部装满来包装 DNA 的噬菌体（"满头"包装），在宿主染色体于感染中被切成片段后，偶尔把一个宿主染色体片段而不是自己的 DNA 装进头部。所得**转导颗粒**可把该片段注入新宿主，并在那里经重组并入。**任何**宿主基因都可被转导，概率大致相等。**局限性转导**中，在宿主染色体的特定位置整合（成为**前噬菌体**）的温和噬菌体偶尔不精确切离，把整合位点邻近的宿主基因一起带走——大肠杆菌噬菌体 λ 的情形是 *gal* 或 *bio* 基因——所以只有那些基因能被转导。
:::

大肠杆菌的噬菌体 P1 包装约 100 kb，约为染色体的 2 分钟。两个基因只有距离在此范围内才可能被**共转导**——由一个颗粒带进同一个受体；它们越近，一起被带上并并入的频率越高。

::: proposition 共转导的 Wu 公式 {#prop-wu}
设转导片段长度固定为 $L$、其端点在染色体上随机落下，其余情况下重组均匀，则距所选标记 $d \le L$ 的未选标记随行其后的频率 $C$ 近似为

$$
C = \left(1 - \frac{d}{L}\right)^3 .
$$ {#eq-wu}

标记重合时 $C = 1$，$d \ge L$ 时 $C = 0$。（T. T. Wu，1966；三次方源于"两个标记都要在片段上、且没有交换把它们分开"的双重要求。）
:::

这一公式是理想化的，但它与 P1 数据符合得足以把共转导频率换算成以分钟计的距离，并解释了共转导为何起初陡降：相距半个片段长的两个标记，只在 $(\tfrac12)^3 = 12.5\ \%$ 的所选转导子中被共转导。

::: widget plot
f: (1 - x/L)^3*H(L - x)
x: 0, 3
y: 0, 1
sliders: L=2:1:3:0.1
caption: Wu 公式 [[#eq-wu]]：两个标记的共转导频率对其距离（分钟），转导片段长 $L$ 分钟（噬菌体 P1 约为 2）。曲线陡降，在 $d = L$ 处降到 0：相距超过一个片段的标记永不被共转导。测得频率为 0.4 时读出距离——$L = 2$ 时约 0.53 min。
:::

::: example 三因子转导定基因次序 {#ex-transduction}
在 *a*$^+$ *b*$^+$ *c*$^+$ 菌株上增殖的 P1 用于转导 *a*$^-$ *b*$^-$ *c*$^-$ 菌株。100 个所选 *a*$^+$ 转导子中，未选标记为：*b*$^+$ *c*$^+$ 45，*b*$^+$ *c*$^-$ 20，*b*$^-$ *c*$^-$ 34，*b*$^-$ *c*$^+$ 1。(a) *b* 与 *c* 对 *a* 的共转导频率各是多少？(b) 基因次序是什么？(c) 取 $L = 2$ min，用 Wu 公式估计距离。
::: solution
(a) *a*–*b*：$(45 + 20)/100 = 0.65$。*a*–*c*：$(45 + 1)/100 = 0.46$。

(b) *b* 比 *c* 更近 *a*。要区分次序是 *a*–*b*–*c* 还是 *b*–*a*–*c*，看最罕见的类别 *a*$^+$ *b*$^-$ *c*$^+$。若 *b* 位于 *a* 与 *c* 之间，这一类别需要四次交换（两次带入 *a*$^+$，再两次排除 *b*$^+$ 同时纳入 *c*$^+$），所以应当极罕见——事实如此（100 中 1）。若 *a* 在中间，*a*$^+$ *b*$^-$ *c*$^+$ 只需两次交换，就不会是最罕见的类别。所以次序是 *a*–*b*–*c*。

(c) *a*–*b*：$d = 2(1 - 0.65^{1/3}) = 2(1 - 0.866) = 0.27$ min。*a*–*c*：$d = 2(1 - 0.46^{1/3}) = 2(1 - 0.772) = 0.46$ min。所以 *b*–*c* 约 0.19 min。罕见类别的论证与[[genetics/linkage-mapping#alg-three-point]]三点测交中双交换的论证相同，只是交换按对计数。
:::
:::

## 转化

自然转化由格里菲斯在肺炎链球菌中发现、并由艾弗里及其同事证明归因于 DNA（[[genetics/genes-and-mutation]]），只发生在少数细菌物种中——枯草芽孢杆菌（*Bacillus subtilis*）、流感嗜血杆菌（*Haemophilus influenzae*）、肺炎链球菌（*Streptococcus pneumoniae*）与奈瑟菌属（*Neisseria*）等——它们能进入一种**感受态**的生理状态：结合环境中的 DNA 片段，摄取其中一条链，并经重组把它并入。摄入的片段通常在 10–20 kb 量级，所以两个标记的**共转化**与共转导一样，说明它们极近。包括大肠杆菌在内的非自然感受态细菌，可以在实验室经化学处理或短促电脉冲使其摄取 DNA；这是用无害实验室菌株进行分子克隆的基础（[[biotechnology]]）。

转化中，单个标记的转移频率（在低浓度下）随 DNA 浓度成正比上升，而独立双转化体——两个标记在不同片段上——的频率随平方上升。因此共转化频率与 DNA 浓度成正比的两个标记必定在*同一*片段上，即是连锁的。

## 噬菌体的遗传学

噬菌体突变体可按**噬菌斑**（菌苔上噬菌体杀死细菌形成的清晰空斑）的外貌或宿主范围计分。马克斯·德尔布吕克（Max Delbrück）与阿尔弗雷德·赫希（Alfred Hershey）1946–49 年证明，当一个细菌同时被两个噬菌体突变体感染时，子代中出现重组噬菌体。

::: example 一次噬菌体杂交 {#ex-phage-cross}
以高感染复数用 T2 *h r*$^+$（宿主范围突变，正常噬菌斑）与 T2 *h*$^+$ *r*（正常宿主范围，快速裂解噬菌斑）同时感染大肠杆菌细胞。子代噬菌体涂布在可以区分全部四种基因型的混合菌苔上，1000 个噬菌斑分类如下：*h r*$^+$ 420，*h*$^+$ *r* 405，*h*$^+$ *r*$^+$ 90，*h r* 85。*h* 与 *r* 之间的重组频率是多少？噬菌体的重组有何特殊之处？
::: solution
重组体是 *h*$^+$ *r*$^+$ 与 *h r*：$(90 + 85)/1000 = 0.175$，即 17.5 %（17.5 个图距单位）。噬菌体重组不同于减数分裂之处，在于它发生在一个细胞内众多正在复制的噬菌体染色体组成的池中，这些染色体随机配对，经几轮反复重组；重组频率因此反映群体水平上的混合，而不是一次交换事件。噬菌体杂交所作的图与其他图一样按可加方式构建，但解读时需谨慎。噬菌体杂交也是本泽尔精细结构作图的基础（[[genetics/genes-and-mutation]]）。
:::
:::

**温和**噬菌体如 λ，既可以先增殖并裂解宿主（**裂解**周期），也可以作为前噬菌体整合进宿主染色体、随其一起复制（**溶原**），直到某种信号诱导它们切离并进入裂解周期。安德烈·勒沃夫（André Lwoff）1950 年在巨大芽孢杆菌（*Bacillus megaterium*）中刻画了溶原，埃丝特·莱德贝格（Esther Lederberg）1951 年在大肠杆菌 K-12 中发现了噬菌体 λ。决定裂解还是溶原的遗传开关，成为生物学中研究得最清楚的调控回路之一（[[systems-biology]]）。

::: application 水平基因转移与抗生素耐药
接合、转导与转化在自然界同样起作用，在菌株之间甚至物种之间移动基因——**水平基因转移**。1950 年代末在日本的志贺菌属（*Shigella*）中发现了同时携带多种抗生素抗性基因的质粒，此类质粒在细菌群体间的扩散，是抗生素耐药演变成全球公共卫生问题的核心原因。理解转移的遗传学，是监测、合理使用抗生素以及约束微生物工作的防护规则的基础；临床方面见[医学图谱](/learn/medicine/course.php?c=infectious-diseases)。比较基因组学表明，许多细菌基因组中相当大比例的基因是水平获得的（[[genomics]]）。
:::

::: history
莱德贝格与塔特姆 1946 年报告了大肠杆菌 K-12 的遗传重组，戴维斯 1950 年证明它要求细胞接触。海斯（1952–53）发现了由 F 因子控制的单向转移，卡瓦利-斯福尔扎分离出第一个 Hfr 菌株（1950）。德尔布吕克与威廉·贝利（William Bailey）、以及赫希，1946 年报告了噬菌体重组；赫希与拉奎尔·罗特曼（Raquel Rotman）1948–49 年为 T2 突变体作图。勒沃夫 1950 年描述了溶原，埃丝特·莱德贝格 1951 年发现 λ，辛德与莱德贝格 1952 年发现转导。沃尔曼与雅各布自 1955 年起进行中断杂交实验，1957 年报告大肠杆菌图的环状性；莫尔斯（Larry Morse）与埃丝特和约书亚·莱德贝格 1956 年描述了 λ 的局限性转导。帕迪（Arthur Pardee）、雅各布与莫诺 1959 年发表"PaJaMo"实验，雅各布与莫诺 1961 年发表操纵子模型。莱德贝格、比德尔与塔特姆分享 1958 年诺贝尔生理学或医学奖。
:::

::: summary
- 细菌单倍体、繁殖快、可用选择培养基筛查；基因写作 *lacZ*（基因）、LacZ（蛋白质）、Lac$^+$（表型）。
- DNA 经转化（游离 DNA）、接合（细胞接触、质粒主导）或转导（噬菌体颗粒）进入受体；重组进环状染色体需要偶数次交换。
- F$^+$ 转移 F；F 已整合的 Hfr 从一个起点按固定次序转移染色体基因。中断杂交给进入时间（图以分钟计，大肠杆菌 100 min）；彼此重叠的 Hfr 次序揭示环状染色体。F′ 质粒制造部分二倍体，用于互补与顺式-反式测验，如 *lac* 操纵子。
- 普遍性转导（P1、P22）可携带约 2 min 片段内的任何基因；共转导频率 $C \approx (1 - d/L)^3$（Wu）。局限性转导（λ）携带前噬菌体位点旁的基因。三因子杂交中最罕见的类别（四次交换）辨认中间的标记。
- 共转化频率与 DNA 浓度成正比，表明两个标记在同一片段上。
- 多重感染的噬菌体杂交给重组子代；温和噬菌体可作为前噬菌体整合（溶原）。
- 水平基因转移在自然界传播耐药性及其他性状。
:::

## 练习

::: exercise 分钟换算千碱基对 {level=1 check="232"}
取大肠杆菌染色体为 $4.64\times10^6$ bp、100 分钟，5 分钟的图距对应多少千碱基对？
::: solution
$4.64\times10^6/100 = 46{,}400$ bp 每分钟，所以 5 分钟是 $232{,}000$ bp $= 232$ kb。
:::
:::

::: exercise 哪种转移方式？{level=1}
对每个观察，说出基因转移的方式：(a) 拦住细胞但不拦噬菌体颗粒的滤板阻止转移，DNase 无影响；(b) 向培养基加 DNase 阻止转移；(c) 转移穿过拦细胞的滤板，DNase 无影响。
::: solution
(a) 接合（需要接触；DNA 在细胞内受到保护）。(b) 转化（游离 DNA 被 DNase 降解）。(c) 转导（噬菌体颗粒穿过滤板，头部保护其中的 DNA）。
:::
:::

::: exercise 噬菌体杂交中的重组 {level=1 check="0.12"}
噬菌体 *a b*$^+$ × *a*$^+$ *b* 杂交得 1000 个子代，其中 61 个为 *a*$^+$ *b*$^+$，59 个为 *a b*。重组频率是多少？
::: solution
$(61 + 59)/1000 = 0.12$。
:::
:::

::: exercise 换算共转导频率 {level=2 check="0.53"}
两个标记被 P1 共转导的频率为 0.40。用 Wu 公式、取 $L = 2$ min，估计它们的距离（分钟，保留两位小数）。
::: solution
$0.40 = (1 - d/2)^3$，所以 $1 - d/2 = 0.40^{1/3} = 0.737$，$d = 2(1 - 0.737) = 0.53$ min。
:::
:::

::: exercise Hfr 的取向 {level=2}
一个 Hfr 菌株最先转移 *pro*，然后 *lac* 在 8 min、*gal* 在 16 min 进入。第二个 Hfr 最先转移 *gal*，*lac* 在 8 min、*pro* 在 16 min 进入。关于两个菌株中 F 的位置与取向，你能说什么？
::: solution
两个菌株转移同一区段 *pro*–*lac*–*gal*，间隔相同，但方向相反。前者的 F 整合在紧挨 *pro*、远离 *lac* 的一侧，取向朝 *lac* 转移；后者的 F 整合在紧过 *gal* 处，取向朝 *lac* 转移。整合经 F 与散布在染色体上的若干插入序列元件之一之间的重组发生，所以不同 Hfr 菌株有不同的起点与方向。
:::
:::

::: exercise 按共转导排序 {level=2}
P1 转导中，*x* 与 *y* 共转导 0.60，*y* 与 *z* 共转导 0.30，*x* 与 *z* 共转导 0.05。最可能的次序是什么？用 Wu 公式（$L = 2$ min）核对距离。
::: solution
共转导最少的一对在两端：*x*–*y*–*z*。距离：*x*–*y*：$2(1 - 0.6^{1/3}) = 0.31$ min；*y*–*z*：$2(1 - 0.3^{1/3}) = 0.66$ min；*x*–*z*：$2(1 - 0.05^{1/3}) = 1.26$ min。和 $0.31 + 0.66 = 0.97$ 小于 1.26；考虑到公式粗糙与小频率的抽样误差，次序依然清楚，但距离表明 Wu 公式在实践中只是近似可加。
:::
:::

::: exercise 部分二倍体分析 {level=2}
对下列每个部分二倍体，说出有功能的 β-半乳糖苷酶是组成型合成、需诱导物才合成，还是不合成：(a) *lacI*$^-$ *lacZ*$^+$ / F′ *lacI*$^+$ *lacZ*$^+$；(b) *lacI*$^+$ *lacO*$^\mathrm{c}$ *lacZ*$^+$ / F′ *lacI*$^+$ *lacO*$^+$ *lacZ*$^-$；(c) *lacI*$^-$ *lacZ*$^-$ / F′ *lacI*$^-$ *lacZ*$^+$。
::: solution
(a) 可诱导：来自 F′ 的野生型阻遏蛋白以 *trans* 起作用，抑制两份拷贝；*lacI*$^+$ 对 *lacI*$^-$ 显性。(b) 组成型：有功能的 *lacZ*$^+$ 紧挨着阻遏蛋白无法结合的组成型操纵基因突变；*lacO*$^\mathrm{c}$ 是 *cis* 显性。(c) 组成型：两份拷贝都不产生有功能的阻遏蛋白，F′ 上的 *lacZ*$^+$ 持续表达。
:::
:::

::: exercise 解读梯度 {level=3}
一次不中断的 Hfr × F$^-$ 杂交中，五个供体标记的重组体频率如下（每 100 个 Hfr 细胞）：*a* 22，*b* 0.8，*c* 9，*d* 3.5，*e* 0.2。选择针对各标记分别进行。(a) 提出一个转移次序。(b) 为什么频率随进入时间大致呈几何级数下降？(c) 除进入时间外，还有什么因素能使某一标记在重组体中意外地稀少？
::: solution
(a) 按频率排序：*a*（22）> *c*（9）> *d*（3.5）> *b*（0.8）> *e*（0.2）：转移次序 *a*–*c*–*d*–*b*–*e*。

(b) 若交配对以每分钟恒定概率拆开，一对在时间 $t$ 之后仍连接的概率是 $e^{-kt}$；接受到某标记的受体比例因此随其进入时间指数下降，即随到起点的距离呈几何级数下降。若标记间距均匀，每个后继标记损失相似的因子。

(c) 经重组并入的效率可因区域而异，例如在转移片段末端附近（远侧可能没有第二次交换的余地），或受体在该区带有缺失或重排时。选择也在起作用：供体等位基因在选择培养基上降低生长的标记，其比例会偏低。
:::
:::

::: exercise 设计作图策略 {level=3}
大肠杆菌 K-12 中一个新的隐性突变 *new*$^-$ 造成某种营养需求。用本章的方法，概述如何先在染色体上粗略定位、再精确定位它。
::: solution
粗略：用一组起点不同且已知的 Hfr 菌株，与一个带可反选抗性标记的 F$^-$ *new*$^-$ 受体杂交，选择该营养需求上的原养型，看哪些 Hfr 菌株早期转移 *new*$^+$。用最佳 Hfr 做中断杂交，可把进入时间定到一两分钟之内，把 *new* 置于已知标记之间。精确：用该区段内带已知标记的菌株做 P1 转导，测定 *new*$^+$ 与各标记的共转导，用 Wu 公式把频率换算成距离，再用三因子杂交的罕见类别论证排定 *new* 相对于邻近标记的次序。最后用 F′ 质粒或克隆的 DNA 片段做互补来鉴定该基因，然后测其序列。（现今的做法常是直接对突变体全基因组测序找到突变，遗传作图用作验证。）
:::
