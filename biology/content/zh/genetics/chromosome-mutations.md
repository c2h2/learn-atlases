多数遗传变异在显微镜下是不可见的：三十亿碱基对中一个碱基对的改变不会使染色体看起来有任何不同。但有些突变大到可以看见。整条染色体可能增加或丢失，整组染色体可能加倍，或者一条染色体可能断裂后按新的方式接合，使一个区段丢失、重复、倒置或移位。这些**染色体突变**是人类在其物理本质上得到理解的第一批突变，比 DNA 被证明是遗传物质早了几十年；它们的遗传后果——异常的比例、不育、重组被抑制、隐性等位基因看似显性——是基因按固定线性顺序位于染色体上的最早的有力证据之一。

它们本身也极其重要。染色体数目的改变是人类妊娠丢失与几种众所周知疾病的最常见原因；多倍体塑造了被子植物的进化，并造就了许多作物，包括小麦、棉、马铃薯与香蕉；染色体重排既驱动癌变，也推动物种的分化。本章对染色体突变分类，解释每一种如何在减数分裂中或由染色体断裂产生，并展示每一种如何影响分离与重组。本章以 [[genetics/chromosomes-meiosis]] 与 [[genetics/linkage-mapping]] 为基础。

## 染色体数目的改变

::: definition 整倍体与非整倍体 {#def-aneuploidy}
设 $x$ 为一个物种一个基本染色体组的染色体数（**一倍体数**），$n$ 为其配子中的染色体数（对二倍体，$n = x$）。细胞或生物若含完整数目完整的染色体组，则为**整倍体**：一倍体（$x$）、二倍体（$2x$）、三倍体（$3x$）、四倍体（$4x$）等等；多于两套染色体组即**多倍体**。若染色体数目不是 $x$ 的整倍数——因为缺少或多出一两条染色体——则为**非整倍体**。对二倍体，非整倍体类型有**缺体**（$2n - 2$，某染色体的两条拷贝均缺）、**单体**（$2n - 1$）、**三体**（$2n + 1$）与**四体**（$2n + 2$，某染色体多出两条拷贝）。
:::

### 不分离

非整倍体通常起源于**不分离**：同源体（在减数分裂 I）或姐妹染色单体（在减数分裂 II）未能分开，布里吉斯在果蝇中已经展示过（[[genetics/sex-linkage-pedigrees]]）。一个相关的、现已知道在人卵细胞中常见的原因是减数分裂 I 中**姐妹染色单体提前分离**，其产物类似。带多余染色体的配子（$n + 1$）与正常配子受精得三体合子；缺少该染色体的配子（$n - 1$）受精得单体。

::: proposition 不分离产生的配子 {#prop-nondisjunction}
考察一次减数分裂中的一对同源体，其余染色体均正常分离。
1. 若同源体在**减数分裂 I** 未分开，四个产物全不正常：两个为 $n + 1$，各带*两条*同源体各一条染色单体（所以若亲本在该染色体着丝粒附近的基因座是杂合的，产物也是杂合的），两个为 $n - 1$。
2. 若一条同源体的姐妹染色单体在**减数分裂 II** 未分开，两个产物正常（$n$），一个为 $n + 1$、带同一条同源体的两条拷贝（着丝粒附近的基因座为纯合），一个为 $n - 1$。
:::

::: proof
(1) 减数分裂 I 不分离后，一个次级细胞得到两条已复制的同源体而另一个都没有。减数分裂 II 中，前者把四条染色单体两两分开，产生两个各含每条同源体一条染色单体的产物；后者产生两个没有该染色体的产物。(2) 减数分裂 I 正常，所以每个次级细胞各有一条已复制的同源体。减数分裂 II 失败的那个细胞中，两条姐妹染色单体进入同一个产物而另一个一无所有；另一个次级细胞正常分裂，得两个正常产物。姐妹染色单体除交叉以远的区段外完全相同，所以 $n+1$ 产物携带同一套着丝粒近侧等位基因的两份拷贝。
:::

两种情形——多余染色体的着丝粒附近为杂合还是纯合——这一遗传差异，连同 DNA 标记，可用来判定某次不分离发生在哪个性别的亲本、哪一次分裂。

::: example 男子的性染色体不分离 {#ex-nd-xy}
若一名男子的 X 与 Y 在减数分裂 I 未分开，会产生什么精子？若 Y 的染色单体在减数分裂 II 未分开呢？设正常（X）卵细胞受精，会产生什么合子？
::: solution
减数分裂 I：两个精子同时带 X 与 Y（XY），两个都不带（O）。与 X 卵结合得 XXY 与 XO 合子。Y 的减数分裂 II 不分离：带 X 的次级精母细胞正常分裂，得两个 X 精子；带 Y 的那个产生一个 YY 精子与一个 O 精子。合子：XX（正常）、XYY 与 XO。所以 XYY 只能来自父亲、发生在减数分裂 II；XXY 可来自父亲的减数分裂 I，也可来自母亲任何一次分裂（XX 卵与 Y 精子受精）。
:::
:::

### 人类的非整倍体

非整倍体在人类生殖中出现的频率高得惊人。很大比例的人卵细胞、以及体外受精产生的早期胚胎是非整倍体，其比例随母亲年龄急剧上升；大多数非整倍体胚胎不能着床或在早期丢失，约一半已确认的孕早期流产存在染色体异常。这些错误多数发生于母源减数分裂 I。一个合理的理由是：人卵细胞自出生前直到排卵都停滞在前期 I——迟至五十年后——而在此期间维系二价体的黏连蛋白得不到更新。

只有少数非整倍体能够存活到出生：基因较少的 21、18、13 号小染色体之三体，以及性染色体数目的改变——后者能被耐受，因为多余的 X 会失活（[[genetics/sex-linkage-pedigrees#def-dosage]]）而 Y 上基因很少。

| 核型 | 名称 | 出生时的大致频率 |
|---|---|---|
| 47,XX,+21 或 47,XY,+21 | 21 三体（唐氏综合征） | 约 1/700–1000 |
| 47,+18 | 18 三体 | 约 1/5000 |
| 47,+13 | 13 三体 | 约 1/10 000 |
| 47,XXY | 克兰费尔特综合征 | 约 1/600 男婴 |
| 47,XYY | — | 约 1/1000 男婴 |
| 47,XXX | X 三体 | 约 1/1000 女婴 |
| 45,X | 特纳综合征 | 约 1/2500 女婴 |

这些频率随群体的育龄结构与筛查常规而变化，应视为数量级。符号给出染色体总数、性染色体与任何改变。1959 年，热罗姆·勒琼（Jérôme Lejeune）、玛尔特·戈捷（Marthe Gautier）与雷蒙·蒂尔潘（Raymond Turpin）证明唐氏综合征源自多余的 21 号染色体；此前三年，蔡福-桑（Joe Hin Tjio）与阿尔伯特·莱文（Albert Levan）已确立人的正常染色体数目为 46。临床方面见[医学图谱](/learn/medicine/lesson.php?c=genetics&l=chromosomal-disorders)；此处只关心机制。

::: intuition 为什么多一个染色体会出问题而多一个等位基因不会
三体不引入任何新基因：它只是给一条染色体上的每个基因加上第三份拷贝。麻烦在于**剂量失衡**。许多蛋白质在复合物或通路中工作，其组分必须按一定比例合成；把几百个基因的剂量相对基因组其余部分提高 50 %，会同时扰乱其中许多平衡。这就是为什么基因较少的染色体三体比基因较多的轻，为什么单体（减少 50 %）通常比三体危害更大，为什么保持所有剂量成比例的整倍性多倍体常能被耐受而非整倍体不能。
:::

### 三体的分离

非整倍体是植物遗传学的有用工具。1920 年代，阿尔伯特·布莱克斯利（Albert Blakeslee）与约翰·贝林（John Belling）找到了曼陀罗 *Datura stramonium*（$2n = 24$）全部十二种原初三体，每种蒴果形状可辨。让基因与相应染色体的三体杂交，若出现异常比例，即可把该基因归到这条染色体上。

::: proposition 三体的配子 {#prop-trisomic}
基因型为 *AAa* 的三体，三条同源体随机地两条移向一极、一条移向另一极，且该基因座距着丝粒足够近、交换可以忽略，其配子为

$$
AA : Aa : A : a = 1 : 2 : 2 : 1 .
$$ {#eq-trisomic}

若 $n+1$ 与 $n$ 配子功能相同，与 *aa* 测交得显性 : 隐性 $= 5 : 1$。
:::

::: proof
标记染色体为 $A_1$、$A_2$、$a$。把它们分成一双一单的等可能分法有三种：$\{A_1A_2 \mid a\}$、$\{A_1a \mid A_2\}$、$\{A_2a \mid A_1\}$。每种产生一个双体配子与一个单体配子，所以六个配子 $A_1A_2$、$a$、$A_1a$、$A_2$、$A_2a$、$A_1$ 等可能，即 $AA : Aa : A : a = 1:2:2:1$。测交中只有 $a$ 配子（$\tfrac16$）产生隐性后代。
:::

实际上 $n+1$ 花粉往往不敌 $n$ 花粉的竞争，所以比例取决于哪个亲本三体；这本身是有用的诊断。

## 多倍体

::: definition 同源多倍体与异源多倍体 {#def-polyploid}
**同源多倍体**含同一物种的多套染色体组（例如同源四倍体 *AAAA*，此处每个字母已是整个基因组）。**异源多倍体**含两个或更多不同物种的染色体组，通常在杂交之后接着染色体加倍；含两个物种各两套染色体的异源四倍体又称**双二倍体**（amphidiploid）。加倍可以自发发生——经由未减数（$2n$）配子——也可用秋水仙素诱导：它阻断纺锤体形成，从而阻止染色体分开。
:::

**染色体组数为奇数的多倍体**通常不育，因为有三条拷贝的染色体在减数分裂中无法均分。三倍体中，每种类型的 $x$ 条染色体形成三价体（或一个二价体加一个单价体），随机地两条移向一极、一条移向另一极，且不同类型之间相互独立。

::: example 三倍体的平衡配子 {#ex-triploid}
栽培香蕉是三倍体，$2n = 3x = 33$（$x = 11$）。设每种染色体类型随机地、相互独立地两条移向一极、一条移向另一极，平衡配子（整倍体，含 $x$ 或 $2x$ 条染色体）占多大比例？
::: solution
配子平衡仅当它取得*每种*染色体类型的那一条拷贝（得 $x$）或每种类型的两条拷贝（得 $2x$）。每种类型独立地以概率 $\tfrac12$ 给出单拷贝，所以

$$
P(\text{平衡}) = \left(\tfrac12\right)^{11} + \left(\tfrac12\right)^{11} = 2^{-10} = \frac{1}{1024} \approx 0.001 .
$$

几乎所有配子都是非整倍体而无生机，这就是香蕉几乎不结实、必须无性繁殖的原因——也是这一作物遗传上一致、易感病害的原因。无子西瓜是用四倍体与二倍体杂交得到的三体，道理相同。
:::
:::

::: widget distribution
dist: binomial
params: n=11, p=0.5
a: 0
b: 0
caption: 在 $x = 11$ 种染色体类型的三倍体（如香蕉）中，配子取得多余（第二条）拷贝的类型数目服从 $n = 11$、$p = 1/2$ 的二项分布。只有两端的小柱——0（含 $x$ 条染色体的配子）与 11（含 $2x$ 条者）——是平衡的；0 处的阴影柱概率为 $1/2048$。改变 $n$，看育性如何随染色体数目增多而崩溃：$x = 3$ 时四分之一的配子是平衡的。
:::

**同源四倍体**通常可育，但其分离遵循与二倍体不同的规则。每条染色体有四条同源体，一个基因座上的等位基因可有五种剂量——*AAAA*（四式体 quadruplex）、*AAAa*、*AAaa*（二式体 duplex）、*Aaaa*、*aaaa*（零式体 nulliplex）。

::: proposition 同源四倍体的分离 {#prop-tetraploid}
基因型 *AAaa* 的同源四倍体，四条同源体随机两两配对成两个二价体（或一个四价体二二分离），且基因座距着丝粒很近，其二倍体配子为

$$
AA : Aa : aa = 1 : 4 : 1 .
$$

自交随后给 $\tfrac1{36}$ 的 *aaaa* 后代——若单个 *A* 即为显性，显隐性表型比为 $35 : 1$——与 *aaaa* 测交得 $5:1$。
:::

::: proof
配子随机接受四条染色体中的两条：$\binom42 = 6$ 对等可能。一对是 $AA$，一对是 $aa$，四条各含一个 $A$ 一个 $a$ 的组合给出 $Aa$。所以 $AA : Aa : aa = 1 : 4 : 1$。合子为 *aaaa* 仅当两个配子都是 $aa$：$(\tfrac16)^2 = \tfrac1{36}$。测交中只有 $aa$ 配子产生 *aaaa*：$\tfrac16$。
:::

::: example 二式体马铃薯自交 {#ex-duplex}
一株四倍体马铃薯对导致隐性块茎性状的等位基因 *a* 为二式体（duplex，*AAaa*）。在[[#prop-tetraploid]]的假设下，给出其自交后代中五种可能基因型的分布。
::: solution
每个配子带 2、1 或 0 份 *A*，概率分别为 $\tfrac16$、$\tfrac46$、$\tfrac16$。合子中 *A* 的份数是两个独立配子之和：

| 基因型 | *AAAA* | *AAAa* | *AAaa* | *Aaaa* | *aaaa* |
|---|---|---|---|---|---|
| 组合数 | $1\cdot1$ | $1\cdot4 + 4\cdot1$ | $1\cdot1 + 4\cdot4 + 1\cdot1$ | $4\cdot1 + 1\cdot4$ | $1\cdot1$ |
| 概率 | $\tfrac1{36}$ | $\tfrac8{36}$ | $\tfrac{18}{36}$ | $\tfrac8{36}$ | $\tfrac1{36}$ |

比例为 $1:8:18:8:1$。后代一半又是二式体，只有三十六分之一表现隐性性状——育种者要寻找它，需要种植一百多株实生苗才能相当有把握地找到若干株。
:::
:::

四倍体 F2 中隐性表型（$\tfrac1{36}$）比二倍体 F2（$\tfrac14$）罕见得多，这是马铃薯、紫花苜蓿等同源四倍体作物育种进展缓慢的原因之一。

**异源多倍体**是产生新植物物种的一条主要途径。1928 年，格奥尔基·卡尔佩琴科（Georgii Karpechenko）把萝卜 *Raphanus sativus*（$2n = 18$）与甘蓝 *Brassica oleracea*（$2n = 18$）杂交。F1 杂种有 18 条染色体，父母各 9 条，彼此没有可配对的同源体，几乎完全不育。在它的少数后代中出现了 36 条染色体的可育植株，由未减数配子产生：每条萝卜染色体有了萝卜的伙伴，每条甘蓝染色体有了甘蓝的伙伴，减数分裂于是正常。这株新植物 *Raphanobrassica*（萝卜甘蓝）是一个新种，与两个亲本都不能产生可育后代。（遗憾的是它长着甘蓝的根和萝卜的叶。）

普通小麦 *Triticum aestivum* 是异源六倍体，$2n = 6x = 42$，基因组记为 AABBDD。它约在一万年前的栽培中产生：一株四倍体小麦（AABB，本身是异源四倍体）与野生山羊草 *Aegilops tauschii*（DD）杂交。棉、油菜（canola）、咖啡与烟草也是异源多倍体。基因组测序表明，所有被子植物都源自经历过全基因组重复的祖先，有些不止一次；脊椎动物谱系在早期经历了两轮。动物中多倍体较少，可能因为它扰乱染色体性别决定；但在某些鱼类、两栖类（蛙 *Xenopus laevis*〔非洲爪蟾〕是异源四倍体）与许多孤雌生殖的无脊椎动物中存在。

::: application 多倍体作物
育种者利用多倍体获得大、壮与无子。许多观赏植物的同源四倍体花更大；三倍体甜菜、西瓜以及一些苹果与柑橘品种无子或高产；人工合成的异源多倍体小黑麦（小麦 × 黑麦）兼有小麦的谷物品质与黑麦的抗逆性。用秋水仙素处理幼苗或茎尖是使染色体数目加倍的经典方法。
:::

## 染色体结构的改变

结构重排始于染色体断裂——来自电离辐射、复制或修复的错误、或不同位点重复序列之间的重组。若断裂末端以错误的方式重接，结果就是**缺失**、**重复**、**倒位**或**易位**。

::: definition 结构型染色体突变 {#def-structural}
- **缺失**（deficiency）是染色体区段的丢失；可为**末端**缺失或**中间**缺失。
- **重复**是某区段存在两份；**串联**重复紧邻原来的拷贝。
- **倒位**是一个区段方向颠倒。不含着丝粒的为**臂内倒位**（paracentric），含着丝粒的为**臂间倒位**（pericentric）。
- **易位**是一个区段移到非同源染色体上。**相互易位**是两条非同源染色体交换区段；**罗伯逊易位**（着丝粒融合）是两条近端着丝粒染色体在着丝粒处或其附近相接，失去其短臂。

若没有遗传物质的得失（倒位与相互易位），重排是**平衡的**，否则是**不平衡的**。
:::

### 缺失与重复

缺失的杂合子对缺失区段内的基因只有一份拷贝。若正常同源体上其中一个基因携带隐性等位基因，隐性表型就会显现——**假显性**。因此可以用成套重叠的缺失来给基因做物理定位：一个隐性突变被且仅被移除了其基因座的缺失所暴露。果蝇幼虫唾液腺的巨大**多线染色体**显示约 5000 条带构成的可重复带型；缺失杂合子在正常同源体找不到配对伙伴之处形成可见的**缺失环**，这种"缺失作图"把数千个基因放到了细胞学图上。大缺失纯合时通常致死，杂合时也可因单倍剂量不足而有害；人的猫叫综合征由 5 号染色体短臂一部分（5p−）的缺失引起。

重复在进化上很重要，因为重复的基因可以在一份拷贝积累突变而另一份保持原有功能，从而获得新功能。脊椎动物的珠蛋白基因、色觉的视蛋白（[[genetics/sex-linkage-pedigrees]]）与 *Hox* 基因簇都起源于一次次连续重复，这一思想由大野乾（Susumu Ohno）在 *Evolution by Gene Duplication*（《基因重复与进化》，1970）中发展。

::: example 棒眼与不均等交换 {#ex-bar}
果蝇突变 *Bar* 把复眼缩小成一条窄棒。1925 年斯特蒂文特发现，*Bar* 纯合品系偶尔产生正常眼的果蝇或眼更小的"双棒"（double *Bar*）果蝇，且这些变化伴随着侧翼标记的重组。1936 年布里吉斯与穆勒各自独立地在多线染色体上看到，*Bar* 是 X 染色体一个小区段（16A 带）的串联重复。解释正常眼与双棒果蝇的由来，以及为什么 *B*/*B* 果蝇（每条染色体上重复的两份拷贝）与 *BB*/+ 果蝇（双棒对正常）都携带 16A 的四份拷贝而表型不同。
::: solution
*Bar*/*Bar* 雌蝇中，一条染色体上 16A 的两份串联拷贝可以与同源体上的拷贝错位配对——一条的第一份对另一条的第二份。错配区段内的一次交换（**不均等交换**）产生一条带三份拷贝（双 *Bar*）与一条带单份拷贝（正常，野生型）的染色体，两者对两侧的标记都是重组型，与观察完全一致。

*B*/*B* 每条 X 上两份拷贝，*BB*/+ 一条上三份、另一条上一份：两者都是四份。斯特蒂文特发现 *BB*/+ 眼更小。表型不仅取决于拷贝数，还取决于排列方式——**位置效应**，这是第一个被描述的位置效应。位置效应表明基因的表达可依赖其染色体邻域，这一思想在 [[genomics]] 中展开。
:::
:::

### 倒位

倒位杂合子有一条正常染色体和一条区段颠倒的染色体。为了在减数分裂中沿全长配对，两条同源体必须形成**倒位环**，其中一条染色体自身回折。环内的交换后果严重。

::: proposition 倒位杂合子中的交换 {#prop-inversion}
**臂内倒位**的杂合子中，倒位环内的一次单交换产生一条**双着丝粒**染色单体（有两个着丝粒），它在后期 I 形成桥并断裂，另产生一个**无着丝粒**片段，随后丢失；两者都带缺失。**臂间倒位**中，环内一次单交换产生两条各带一端重复、另一端缺失的染色单体。两种情形下，两条非交换染色单体都正常或带倒位，而重组产物不平衡，作为配子或合子通常无生机。倒位内部基因座间的重组型因此不能被回收：倒位起**交换抑制**的作用。
:::

这一结论只需把参与交换的两条染色单体沿倒位环追踪一遍即可得出；教科书作图使之十分直观，[[#exr-inversion]] 就要求你画出一个这样的图。果蝇中，雌性减数分裂把双着丝粒染色单体导向极体，所以臂内倒位造成的育性损失很小，但重组产物仍然不会出现在子代中。

交换抑制使倒位成为有力的工具。果蝇遗传学家用**平衡染色体**保存隐性致死突变：平衡染色体携带多个相互重叠的倒位（使任何重组子都不能存活）、一个自身的隐性致死（使平衡染色体纯合子死亡）与一个显性可见标记（使平衡染色体携带者可以辨认）。*lethal*/*balancer* 品系于是无需选择即可真实遗传。在自然界，倒位把等位基因的组合捆绑在一起：杜布赞斯基（Theodosius Dobzhansky）1930 年代起对拟暗果蝇 *Drosophila pseudoobscura* 倒位多态的研究表明，其频率随海拔与季节变化；现代基因组学则发现倒位把复杂性状的"超基因"（supergene）捆绑在一起，如袖蝶属 *Heliconius* 蝴蝶的拟态翅斑与火蚁群体的社会结构。

### 易位

相互易位的杂合子有两条正常染色体 N1 与 N2，和两条易位染色体 T1 与 T2，每条各带 N1 与 N2 的一部分。减数分裂 I 中，四条染色体配成十字形的**四价体**，可以按几种方式分离。

::: definition 易位的分离方式 {#def-translocation-seg}
- **交互分离**：N1 与 N2 移向一极，T1 与 T2 移向另一极。两个产物都平衡：一个正常，一个携带平衡易位。
- **邻近-1 分离**：每极各得一条正常与一条易位染色体，且着丝粒互不同源（N1 + T2 与 N2 + T1）。两个产物都不平衡，各带一个区段的重复与另一个区段的缺失。
- **邻近-2 分离**：同源着丝粒移向同一极。两个产物都不平衡。这通常是最罕见的模式。
:::

若交互分离与邻近-1 分离大致等频繁，约一半配子不平衡，易位杂合子**半不育**：植物约一半花粉败育、一半胚珠不能发育。易位还引起**假连锁**：两条非同源染色体上断点附近的基因表现如同连锁，因为在存活的（交互分离）产物中 N1 总与 N2 同行、T1 总与 T2 同行。

**罗伯逊易位**融合两条近端着丝粒染色体；失去的短臂只携带也在其他染色体上存在的重复核糖体 RNA 基因，所以携带者有 45 条染色体而表型正常。人中，涉及 21 号染色体的罗伯逊易位——最常见的是 rob(14;21)——占 21 三体病例的百分之几：携带者可产生一个既带融合的 14;21 染色体*又*带正常 21 号染色体的配子。哺乳类的染色体数目部分地经由罗伯逊融合进化——小家鼠标准核型有 40 条近端着丝粒染色体，而一些岛屿与阿尔卑斯山群体的染色体少至 22 条，正是反复融合的结果。

::: warning "平衡重排是无害的"
平衡倒位或平衡易位携带者有一套完整的基因，表型通常正常，但重排并非没有后果。携带者能以高比率产生不平衡配子，导致育性降低与不平衡后代；断点也可能使一个基因失能或使其与调控元件分离。反过来，不平衡重排未必肉眼可见：许多小缺失与小重复（拷贝数变异）只有借助基因组学方法才能发现，其中许多相当常见、看似无害。
:::

重排也是癌的核心事件。1960 年，彼得·诺维尔（Peter Nowell）与戴维·亨格福德（David Hungerford）在慢性粒细胞白血病患者的细胞中发现一条小染色体——**费城染色体**。珍妮特·罗利（Janet Rowley）1973 年证明它是 9 号与 22 号染色体相互易位 t(9;22) 的产物；1980 年代发现断点融合了 *BCR* 与 *ABL1* 两基因，产生一个酪氨酸激酶组成性激活的融合蛋白，驱动细胞增殖。这一融合蛋白成为最早被设计出的抗癌药物靶点之一。芭芭拉·麦克林托克（Barbara McClintock）更早（1938–41）对玉米断裂染色体的研究表明，断裂末端易于融合，形成双着丝粒染色体，在下次分裂时再次断裂——**断裂-融合-桥循环**——它产生更多重排，如今被认为是肿瘤基因组不稳定的来源之一。

::: quiz
一株植物对一个相互易位是杂合的，其约一半花粉粒皱缩无生机。哪种分离方式产生有活力的花粉？
- [x] 仅交互分离
- [ ] 仅邻近-1 分离
- [ ] 交互分离与邻近-1 分离
- [ ] 所有方式，因为花粉是单倍体产物
::: solution
只有交互分离给出平衡产物（N1 + N2 或 T1 + T2）。邻近-1 与邻近-2 产物带一个区段的重复与另一个区段的缺失，带缺失的花粉通常败育。一半花粉有活力意味着交互分离与邻近分离大约等频繁。
:::
:::

::: history
卡尔文·布里吉斯 1917 年描述了缺失、1919 年描述了重复；斯特蒂文特 1921 年发现第一个倒位（比较 *D. melanogaster* 与 *D. simulans* 的基因顺序），1925 年用不均等交换解释 *Bar*；布里吉斯与穆勒 1936 年证明 *Bar* 是多线染色体上可见的重复——多线染色体之于细胞遗传学的价值由西奥菲勒斯·佩因特（Theophilus Painter）1933 年展示。阿尔伯特·布莱克斯利（Albert Blakeslee）、约翰·贝林（John Belling）及同事 1920 年起描述了曼陀罗的三体；格奥尔基·卡尔佩琴科（Georgii Karpechenko）1928 年育成萝卜甘蓝。芭芭拉·麦克林托克（Barbara McClintock）1938–41 年描述了玉米的断裂-融合-桥循环。蔡福-桑（Joe Hin Tjio）与阿尔伯特·莱文（Albert Levan）1956 年确立人的染色体数目为 46；1959 年，热罗姆·勒琼（Jérôme Lejeune）、玛尔特·戈捷（Marthe Gautier）与雷蒙·蒂尔潘（Raymond Turpin）在唐氏综合征中发现 21 三体，查尔斯·福特（Charles Ford）及同事发现特纳综合征的 45,X 核型，帕特里夏·雅各布斯（Patricia Jacobs）与约翰·斯特龙（John Strong）发现克兰费尔特综合征的 47,XXY 核型。彼得·诺维尔（Peter Nowell）与戴维·亨格福德（David Hungerford）1960 年描述了费城染色体，珍妮特·罗利（Janet Rowley）1973 年认定它是 t(9;22)。
:::

::: summary
- 整倍体含整套染色体；非整倍体多或缺少一两条（单体 $2n-1$、三体 $2n+1$）。非整倍体主要起于不分离：减数分裂 I 时四个产物全不正常，减数分裂 II 时一半不正常。
- 非整倍体经剂量失衡而有害；人中它在卵细胞中常见（随母龄上升），但很少有哪种能存活到出生（21、18、13 三体与性染色体非整倍体）。
- 三体 *AAa* 给配子 $AA:Aa:A:a = 1:2:2:1$，测交比 $5:1$；同源四倍体 *AAaa* 给 $AA:Aa:aa = 1:4:1$，F2 为 $35:1$。
- 奇数倍多倍体几乎不育：$x$ 种染色体类型的三倍体产生平衡配子的概率为 $2^{1-x}$。异源多倍体（杂交加加倍）创造新种，如萝卜甘蓝与普通小麦（AABBDD）。
- 缺失暴露隐性等位基因（假显性）并可给基因定位；重复为新基因提供原料，可经不均等交换产生（*Bar*）。
- 倒位环内的交换产生不平衡产物，所以倒位杂合子抑制重组（平衡染色体、超基因）。
- 相互易位杂合子半不育，因为只有交互分离给出平衡配子；罗伯逊融合改变染色体数目；t(9;22) 之类的易位可驱动癌变。
:::

## 练习

::: exercise 数染色体 {level=1 check="47"}
一个二倍物种 $2n = 46$。三体有多少条染色体？
::: solution
$2n + 1 = 47$。
:::
:::

::: exercise 不分离的产物 {level=1 check="1/2"}
若两个次级细胞之一中有一对姐妹染色单体在减数分裂 II 未分开，这次减数分裂的四个产物中染色体组成正常的占几分之几？
::: solution
四个中两个，来自正常分裂的那个次级细胞：$\tfrac12$（[[#prop-nondisjunction]]）。
:::
:::

::: exercise 命名变异 {level=1}
判断下列各属于什么：(a) $2n - 1$；(b) $3x$；(c) 一条基因顺序为 ABCFEDGH（正常为 ABCDEFGH）、着丝粒在 A 与 B 之间的染色体；(d) 一条顺序为 ABCDEFEFGH 的染色体；(e) 两条在着丝粒处融合的近端着丝粒染色体。
::: solution
(a) 单体（非整倍体）。(b) 三倍体（整倍体多倍体）。(c) DEF 的倒位；着丝粒位于倒位区段之外，故为臂内倒位。(d) EF 的串联重复。(e) 罗伯逊易位。
:::
:::

::: exercise 四倍体测交 {level=2 check="5/6"}
同源四倍体 *AAaa*（染色体分离，基因座与着丝粒之间无交换）与 *aaaa* 杂交。若一个 *A* 即可表现显性，后代中显性表型占几分之几？
::: solution
*AAaa* 的配子为 $AA:Aa:aa = 1:4:1$（[[#prop-tetraploid]]）；只有 $aa$（$\tfrac16$）产生 *aaaa*。显性比例为 $\tfrac56$。
:::
:::

::: exercise 三体杂交 {level=2 check="1/36"}
三体植物 *AAa* 自交。设 $n$ 与 $n+1$ 配子经卵与花粉的功能相同，所有合子存活。后代中隐性表型占几分之几？
::: solution
隐性表型要求完全没有 *A*；[[#eq-trisomic]]的配子中只有单体配子 $a$（$\tfrac16$）不带 *A*。两个配子都必须是 $a$：$(\tfrac16)^2 = \tfrac1{36}$。（真实植物中 $n+1$ 花粉常处劣势，会使隐性比例增大。）
:::
:::

::: exercise 七种染色体类型的三倍体 {level=2 check="1/64"}
一个三倍体 $x = 7$。按[[#ex-triploid]]的假设，其配子中平衡的占几分之几？
::: solution
$2\times(\tfrac12)^7 = \tfrac1{64}$。
:::
:::

::: exercise 假显性作图 {level=2}
对某果蝇染色体区段的五个重叠缺失，用四个隐性突变 *a*–*d* 测试。"+"表示缺失杂合子表现野生型表型，"−"表示表现突变表型。

| | *a* | *b* | *c* | *d* |
|---|---|---|---|---|
| Df1 | − | + | − | + |
| Df2 | + | + | − | − |
| Df3 | − | − | + | + |
| Df4 | + | − | + | + |
| Df5 | − | + | + | + |

确定四个基因的顺序。
::: solution
"−"表示缺失移除了该基因。Df4 只移除 *b*，Df5 只移除 *a*，Df3 移除 *a* 与 *b*，Df1 移除 *a* 与 *c*，Df2 移除 *c* 与 *d*。由于缺失移除的是连续区段，*a* 必须同时与 *b*（Df3）和 *c*（Df1）相邻，所以 *a* 位于两者之间：*b*–*a*–*c*。Df2 移除 *c* 与 *d* 而不移除 *a*，所以 *d* 在 *c* 外侧：顺序为 *b*–*a*–*c*–*d*。
:::
:::

::: exercise 倒位杂合子中的重组 {#exr-inversion level=3}
一只果蝇雌蝇对一个臂内倒位是杂合的，倒位覆盖染色体上 B、C、D 三个基因座，该染色体正常顺序为 A–B–C–D–E，着丝粒在 A 之左；正常同源体携带隐性等位基因 *a b c d e*，倒位染色体为野生型（A–D–C–B–E）。(a) 画出倒位环并写出 C 与 D 之间一次单交换的产物。(b) 这些产物中哪些能在她的后代中回收？(c) 测交中，与正常雌蝇相比，你预计 A 与 E 之间、B 与 D 之间的重组频率如何？
::: solution
(a) 环中正常染色体按 着丝粒–A–B–C–D–E 行走，倒位的（着丝粒–A–D–C–B–E）自身回折，使其 B、C、D 与正常同源体的 B、C、D 并排。追踪 C 与 D 之间交换涉及的两条染色单体。一个产物从正常的着丝粒出发，走到交换点经历 A–B–C，然后沿倒位染色单体经 D 到 A 回到*它的*着丝粒：着丝粒–A–B–C–D–A–着丝粒，是一条缺 E 的**双着丝粒**染色单体。另一个产物连接剩下的部分，E–B–C–D–E，没有着丝粒：**无着丝粒**片段。未参与交换的两条染色单体是完整的正常染色体与倒位染色体。

(b) 只有非交换染色单体。无着丝粒片段丢失；而果蝇雌性中，双着丝粒桥把两条内侧染色单体留在减数分裂产物线性排列的中央，使它们不进入卵核——卵核得到两条外侧的非重组染色单体之一。所以育性几乎不降低。

(c) 被倒位内的交换隔开的任何两个基因座，其重组型都不能回收，所以 B 与 D 之间的重组基本为零；A 与 E 之间的重组则减少原先发生在 B–D 之内的那部分（倒位之外——A 与 B 之间或 D 与 E 之间——的交换仍产生重组型）。环内涉及同两条染色单体的双交换可以给出平衡产物，所以倒位内部仍可发生少量重组。
:::
:::

::: exercise 解读半不育 {level=3}
玉米中，一株约 50 % 花粉败育的植株以母本与正常植株杂交。其后代一半半不育、一半完全可育。隐性突变 *y*（幼苗黄化，位于 6 号染色体）与隐性 *gl*（亮叶，位于 7 号染色体）在正常植株中彼此间重组为 50 %，但在一个既半不育又对两者杂合的植株的测交中几乎看不到重组型。(a) 半不育最可能的解释是什么？(b) 解释 *y* 与 *gl* 之间的表观连锁。(c) 为什么后代一半半不育？
::: solution
(a) 该植株对 6 号与 7 号染色体之间的相互易位是杂合的；邻近分离给出不平衡配子，其中一半（或更多）败育。

(b) 这是假连锁。只有交互分离给出有活力的配子，所以两条正常染色体（6 与 7）一起走，两条易位染色体也一起走。若 *y* 与 *gl* 都在正常染色体上（易位染色体携带显性等位基因），且两个基因座位于断点附近、它们与断点之间的交换罕见，则有活力的配子几乎全是 *y gl* 或 + +。

(c) 交互分离给出的有活力配子或是 N6 + N7（正常），或是 T6 + T7（平衡易位），各占一半。与正常花粉受精后，后代一半是完全正常的纯合子、完全可育，另一半是易位杂合子、半不育。
:::
:::
