一个生物的基因远比染色体多——果蝇约 14 000 个蛋白编码基因分布在 4 条染色体上，人约 20 000 个在 23 条上。同一染色体上的基因不可能全部自由组合：若染色体整条完整地传递，一条染色体上的所有基因就会作为一个整体一起传递。事实上它们并不会完全一起传递，因为同源染色体在减数分裂中通过交叉互换交换片段（[[genetics/chromosomes-meiosis]]）。所以同一染色体上的基因是**连锁**的——一起传递的频率高于自由组合的预言——但不是绝对的。

1911 年，托马斯·亨特·摩尔根提出：两个基因在染色体上相距越近，交换落在它们之间、把它们分开的机会就越少。两年后，他的本科生阿尔弗雷德·斯特蒂文特（Alfred Sturtevant）意识到重组频率可以用作距离的度量，在一个晚上构建了第一张遗传图。本章展开这一思想：如何检测连锁，如何测定重组频率，它为什么不能超过 50 %，如何借助**作图函数**把它换算成图距，三点测交如何确定基因顺序并揭示**干扰**，以及在人类家系中如何用 **LOD 得分**检测连锁。

## 连锁与重组

连锁的最初迹象由威廉·贝特森（William Bateson）、伊迪丝·桑德斯（Edith Saunders）与雷金纳尔德·庞尼特（Reginald Punnett）于 1905 年发现。香豌豆中，涉及紫花对红花、长花粉粒对圆花粉粒的杂交得到的双因子 F2 比例远离 $9:3:3:1$，亲本组合大幅过剩。他们称之为"部分相引"（partial coupling），但未能解释。

::: definition 连锁、相型与重组频率 {#def-linkage}
若两个基因座在同一染色体上距离近到其等位基因不再独立传递，则它们是**连锁**的。双重杂合子中，等位基因可以排列为**相引相**（*cis*），两个显性（或两个野生型）等位基因在同一条同源体上，$\frac{A\ B}{a\ b}$；或**相斥相**（*trans*），$\frac{A\ b}{a\ B}$；这种排列称为**连锁相**。若一个配子携带的等位基因组合存在于个体从其双亲之一继承来的某一条同源体上，该配子为**亲本型**（非重组型），否则为**重组型**。两个基因座之间的**重组频率** $r$ 是重组型配子的比例。
:::

用横线书写基因型，如 $\frac{A\ B}{a\ b}$，表示两条同源体上下排列；常写成一行 *AB*/*ab*。未连锁的基因座，重组型与亲本型配子等频率，$r = \tfrac12$。连锁的基因座 $r < \tfrac12$。

::: definition 两点测交 {#def-testcross}
为测定 $r$，把双重杂合子与双重隐性纯合子 *ab*/*ab* 测交。每个后代从测交亲本得到 *ab*，所以后代的表型直接揭示杂合亲本提供的配子。$N$ 个后代中有 $R$ 个重组型时

$$
\hat r = \frac{R}{N}, \qquad \mathrm{SE}(\hat r) = \sqrt{\frac{\hat r(1-\hat r)}{N}} .
$$ {#eq-rhat}
:::

标准误差来自 $R$ 的二项分布（[[genetics/mendelian-inheritance#eq-binomial]]）。果蝇中杂合亲本必须是雌性，因为果蝇雄性没有减数分裂交换——这是摩尔根早期发现并加以利用的事实。

::: example 果蝇的两点杂交 {#ex-two-point}
隐性等位基因 *b*（黑身）与 *vg*（残翅）位于黑腹果蝇（*Drosophila melanogaster*）第 2 号染色体上。让野生型品系与黑身残翅品系杂交所得的雌蝇 *b*$^+$*vg*$^+$/*b vg* 与 *b vg*/*b vg* 雄蝇测交。1000 个后代为：野生型 412、黑身残翅 398、黑身正常翅 92、灰（野生型体色）残翅 98。(a) 两个基因座连锁吗？(b) 估计 $r$ 及其标准误差。
::: solution
(a) 若两基因座未连锁，四个类别应等频率（各 250）。这里两个类别大得多：它们是亲本型 *b*$^+$*vg*$^+$ 与 *b vg*，与预期一致，因为雌蝇从一个亲本得到 *b*$^+$*vg*$^+$、从另一个得到 *b vg*。对 $1:1:1:1$ 的 χ² 检验给 $X^2 = 384.9$，$\nu = 3$，$p < 10^{-80}$。检验连锁的更好方法是两基因座间的 $2\times2$ 独立性检验，即使某个突变体生活力降低它也不受影响；得 $X^2 = 384.4$，$\nu = 1$——连锁的证据确凿。

(b) 重组类别是黑身正常翅与灰身残翅：$R = 92 + 98 = 190$，所以 $\hat r = 0.190$，$\mathrm{SE} = \sqrt{0.19\times0.81/1000} = 0.012$。两基因座相距约 19 个图距单位。（第 2 号染色体上 *b* 与 *vg* 的公认图位是 48.5 与 67.0，相距约 18.5 个单位。）
:::
:::

::: warning "$r = 0.5$ 就说明两个基因在不同染色体上"
重组频率 50 % 只说明两个基因座自由组合。不同染色体上的基因座确实如此，但同一染色体上相距很远的基因座也如此——它们之间几乎总至少有一次交换。这样的基因座是**同线的**（syntenic，在同一染色体上）却不能被检出连锁，它们的同一条染色体归属只能靠作图一系列相邻基因座（每一对邻近者相互连锁）来证明。反过来，重组频率也不等于物理距离：它取决于交换发生的位置，而交换在染色体上的分布沿位置、也沿性别而变化。
:::

## 重组频率为什么不能超过一半

交换发生在四染色单体时期。每次交换只涉及每条同源体的一条染色单体，另外两条完好不动（[[genetics/chromosomes-meiosis]]）。所以在两个基因座之间恰有一次交换的一次减数分裂，产物为两条重组与两条亲本染色单体：*那次减数分裂的产物中*重组频率为 $\tfrac12$。两基因座之间没有交换的减数分裂则一个重组型也不产生。多次交换可以恢复亲本组合。

::: proposition 马瑟公式 {#prop-mather}
设两个基因座之间的交换所涉及的姐妹以外的染色单体对是随机选取、且彼此独立的（**无染色单体干扰**）。设 $p_0$ 为一次减数分裂在该区段内没有交换的概率。则

$$
r = \tfrac12\,(1 - p_0) .
$$ {#eq-mather}

特别地 $0 \le r \le \tfrac12$，且区段变长时 $r \to \tfrac12$。
:::

::: proof
以该区段内交换次数 $k \ge 1$ 为条件，追踪四条中随机选定的一条染色单体。每次交换以概率 $\tfrac12$ 涉及选定者（四条中有两条参加）。该染色单体对两端基因座成为重组型，当且仅当它参加了奇数次交换。无染色单体干扰时，它参加 $k$ 次交换的情况是 $k$ 个概率 $\tfrac12$ 的独立事件序列，参加次数服从二项分布 ($k$, $\tfrac12$)，而参加次数为奇数的概率为

$$
\sum_{j\ \text{奇数}} \binom{k}{j}\left(\tfrac12\right)^k = 2^{k-1}\left(\tfrac12\right)^k = \tfrac12 \qquad (k \ge 1),
$$

利用了 $\sum_{j\ \text{奇数}}\binom kj = 2^{k-1}$（$k$ 个对象的全部 $2^k$ 个子集恰有一半大小为奇数）。所以凡至少有一次交换的减数分裂，产生重组产物的概率都恰为 $\tfrac12$，没有交换的产生概率 $0$。取平均，$r = \tfrac12(1 - p_0) + 0\cdot p_0$。
:::

这就是 $\tfrac12$ 是上限的原因：无论发生多少次交换，四条染色单体链都是随机重排的，平均恰有一半成为重组型。

## 图距与作图函数

斯特蒂文特的思想是可加地定义距离。若交换如同散布在染色体上的点，区段内*交换的平均次数*就是可加的——A 到 C 区段内的次数等于 A 到 B 加上 B 到 C。重组频率并不可加，因为 A 与 C 之间的双交换是看不见的。

::: definition 图距 {#def-map-distance}
两个基因座之间的**图距** $d$ 是它们之间区段内每条染色单体的平均交换次数（等价于每次减数分裂平均交换次数的一半，因为每次交换只涉及四条染色单体中的两条）。图距以**摩尔根**（morgan，M）度量；一个**厘摩**（centimorgan，cM，也称**图距单位**）为 0.01 M。在双交换罕见的短区段中 $d \approx r$：1 cM 对应 1 % 的重组。
:::

**作图函数**给出 $r$ 作为 $d$ 的函数。最简单者假设交换随机发生、彼此独立。

::: proposition 霍尔丹作图函数 {#prop-haldane}
若交换沿染色体构成泊松过程（**无交换干扰**），且无染色单体干扰，则

$$
r = \tfrac12\left(1 - e^{-2d}\right), \qquad d = -\tfrac12\ln(1 - 2r),
$$ {#eq-haldane}

其中 $d$ 以摩尔根计。
:::

::: proof
按定义，区段内每条染色单体的平均交换次数为 $d$，所以每次减数分裂（每个二价体）的平均交换次数为 $2d$。若交换按泊松过程发生，一次减数分裂中区段内的交换次数服从均值 $2d$ 的泊松分布，一次也没有的概率为 $p_0 = e^{-2d}$。马瑟公式 [[#eq-mather]]给出 $r = \tfrac12(1 - e^{-2d})$。解出 $d$：$1 - 2r = e^{-2d}$，故 $d = -\tfrac12\ln(1 - 2r)$。
:::

$d$ 很小时 $e^{-2d} \approx 1 - 2d$，故 $r \approx d$；$d \to \infty$ 时 $r \to \tfrac12$。真实染色体表现出**正交换干扰**：一次交换会降低邻近处再发生交换的机会，所以短区段中的双交换比泊松模型预言的更罕见。1944 年印度数学家 D. D. 科桑比（D. D. Kosambi）提出的作图函数考虑了这一点：

$$
r = \tfrac12\tanh(2d), \qquad d = \tfrac14\ln\frac{1 + 2r}{1 - 2r} .
$$ {#eq-kosambi}

科桑比函数并非由交换的机制模型推导，而是为使干扰随距离以简单方式减弱而选取的，对许多生物都比霍尔丹函数拟合得更好。两者在距离很小时都与 $r \approx d$ 一致。给定 $r$ 时霍尔丹函数给出更大的距离，因为它假设有最多的双交换未被察觉。

|---|---|---|---|---|---|---|
| 霍尔丹 $d$（cM） | 5.3 | 11.2 | 25.5 | 45.8 | 80.5 | 115.1 |
| 科桑比 $d$（cM） | 5.0 | 10.1 | 21.2 | 34.7 | 54.9 | 73.6 |

::: example 重组频率的换算 {#ex-mapping}
两个基因座显示 30 % 的重组。分别在 (a) 朴素假设 $d = r$、(b) 霍尔丹函数与 (c) 科桑比函数下估计图距。

:::

## 斯特蒂文特的图谱与三点测交

斯特蒂文特（1913）使用了果蝇的六个 X 连锁隐性突变——黄体（*y*）、白眼（*w*）、朱红眼（*v*）、小翅（*m*）与痕迹翅（*r*），外加伊红眼（eosin，后来被证明是 *white* 的一个等位基因）——发现它们成对的重组频率可以排在一条直线上，距离近乎可加。他的图谱把 *y* 定在 0，*w* 在 1.0，*v* 在 30.7，*m* 在 33.7，*r* 在 57.6。短区段的近乎可加表明基因排成一条线；长区段的亏缺——相距远的基因之间的重组频率小于其间各短区段之和——揭示了双交换。

用三重杂合子的**三点测交**能在一次实验中同时确定基因顺序与两个距离，并直接度量干扰。

::: algorithm 三点测交的分析 {#alg-three-point}
1. 把八个表型类别归并为四个互交对（在三个基因座上完全互补的类别）。
2. 最大的一对是**亲本型**类别；它给出杂合子两条同源体上等位基因的排列。
3. 最小的一对是**双交换**类别。把它与亲本型类别比较：等位基因被换走的那个基因座在**中间**。
4. 按正确的基因顺序重写所有类别。其余两对分别是区段 I（第一个与中间基因座之间）与区段 II（中间与最后一个基因座之间）的单交换。
5. $r_\mathrm{I} = (\text{SCO}_\mathrm{I} + \text{DCO})/N$，$r_\mathrm{II} = (\text{SCO}_\mathrm{II} + \text{DCO})/N$——双交换在*两个*区段都是重组型。
6. **符合系数**为 $c = \dfrac{\text{观察 DCO}}{r_\mathrm{I}\,r_\mathrm{II}\,N}$，**干扰**为 $I = 1 - c$。
:::

::: example 第 2 号染色体上的三点杂交 {#ex-three-point}
对 *b*（黑身）、*vg*（残翅）与 *pr*（紫眼）三重杂合的雌蝇（来自野生型与三突变品系的杂交），与 *b pr vg* 雄蝇测交。2000 个后代为：

| 表型（*b*、*vg*、*pr*） | 数目 |
|---|---|
| + + + | 822 |
| *b vg pr* | 817 |
| + *vg* + | 118 |
| *b* + *pr* | 123 |
| *b* + + | 57 |
| + *vg pr* | 54 |
| *b vg* + | 4 |
| + + *pr* | 5 |

确定基因顺序、图距与干扰。
::: solution
互交对：(822, 817) 亲本型，+++ / *b vg pr*；(118, 123)；(57, 54)；(4, 5) 双交换。

顺序：双交换类别是 *b vg* + 与 + + *pr*。与亲本型 *b vg pr* 和 + + + 相比，只有 *pr* 的等位基因被换走，所以 *pr* 在中间：顺序为 *b*–*pr*–*vg*。

按此顺序重写的区段：(*b* + +, + *pr vg*) = 57 + 54 = 111，是 *b* 与 *pr* 之间的交换（区段 I）；(+ + *vg*, *b pr* +) = 118 + 123 = 241，是 *pr* 与 *vg* 之间的交换（区段 II）。

$$
r_{b\text{–}pr} = \frac{111 + 9}{2000} = 0.060, \qquad r_{pr\text{–}vg} = \frac{241 + 9}{2000} = 0.125 .
$$

所以 *b* 与 *pr* 相距 6.0 cM，*pr* 与 *vg* 相距 12.5 cM。直接测量的外侧基因座 *b* 与 *vg* 之间的重组频率是 $(111 + 241)/2000 = 0.176$，比之和 0.185 少 $2\times9/2000$：双交换对外侧基因座不是重组型。

无干扰时双交换的期望值：$0.060\times0.125\times2000 = 15$。观察值 9，所以 $c = 9/15 = 0.60$，$I = 0.40$：一个区段的交换使另一区段发生交换的机会降低了 40 %。
:::
:::

::: quiz
一次三点杂交中，亲本型类别为 *a B c* 与 *A b C*，双交换类别为 *a b c* 与 *A B C*。哪个基因在中间？
- [ ] A
- [x] B
- [ ] C
- [ ] 没有单交换的数目就无法确定
::: solution
比较 *a B c*（亲本型）与 *a b c*（双交换）：只有 B 的等位基因不同。双交换恰好只交换中间的片段，所以 B 在中间；顺序是 A–B–C（或 C–B–A）。
:::
:::

::: definition 交换干扰 {#def-interference}
**交换干扰**是同一次减数分裂中相邻区段交换之间的非独立性。它以符合系数 $c$（观察双交换除以期望双交换）与干扰 $I = 1 - c$ 度量。**正干扰**（$I > 0$，常见情形）指双交换少于期望；$I = 1$ 表示完全干扰。**负干扰**（$I < 0$，双交换过剩）见于某些真菌与噬菌体杂交中的极短区段。
:::

正干扰是交换通路的性质：一旦某个位点被指定为交换，邻近位点就受到抑制。这使交换分布均匀，并有助于保证每个二价体至少有一个交换（必备交叉）。其机制涉及联会复合体与交换促进蛋白，仍是活跃的研究领域。

## 人类作图：LOD 得分

人类遗传学家不能安排测交，只能顺其自然地使用家系，其中相型常常未知，只有少数减数分裂含信息。标准方法由牛顿·莫顿（Newton Morton）于 1955 年在亚伯拉罕·瓦尔德（Abraham Wald）序贯概率比检验的基础上建立，比较家系数据在连锁（重组频率 $r$）之下与不连锁（$r = \tfrac12$）之下的似然。

::: definition LOD 得分 {#def-lod}
对系谱数据 $D$ 与重组频率 $r$，**LOD 得分**（logarithm of the odds，优势比对数）为

$$
Z(r) = \log_{10}\frac{L(r)}{L(\tfrac12)},
$$ {#eq-lod}

其中 $L(r) = P(D \mid r)$ 为似然。相型已知的 $N$ 次减数分裂中有 $R$ 次重组时，$L(r) = r^R(1 - r)^{N-R}$，于是

$$
Z(r) = R\log_{10} r + (N - R)\log_{10}(1 - r) + N\log_{10} 2 .
$$ {#eq-lod-phase-known}

$r$ 的**最大似然估计**是使 $Z$ 最大的 $\hat r$（相型已知的数据 $\hat r = R/N$）。按惯例，LOD 最大值 $\ge 3$（支持连锁的比为 1000 : 1）视为连锁的显著证据；给定 $r$ 处 $Z \le -2$ 视为在该距离上不存在连锁的证据。独立家系的 LOD 得分可以相加。
:::

阈值取 3 看似苛刻，但之所以如此选择，是因为两个随机基因座连锁的先验概率很低（人的随机基因座对中只有百分之几近到足以连锁），所以需要强有力的证据才能得到相当高的连锁后验概率。$Z = 3$ 时实际的错误率约为 5 %。全基因组扫描要检验许多标记，阈值还要更高。

::: example 来自小样本家系的 LOD 得分 {#ex-lod}
一组家系兼有显性性状与 DNA 标记，其中相型已知且含信息的减数分裂 20 次，有 2 次重组。计算 $\hat r$ 与最大 LOD 得分。连锁证据显著吗？
::: solution
$\hat r = 2/20 = 0.10$。由[[#eq-lod-phase-known]]，

$$
Z(0.1) = 2\log_{10}0.1 + 18\log_{10}0.9 + 20\log_{10}2 = -2.000 - 0.824 + 6.021 = 3.20 .
$$

因 $3.20 \ge 3$，在约 10 cM 处有显著的连锁证据。作为对照 $Z(0.05) = 3.02$、$Z(0.2) = 2.88$，所以数据支持接近 10 cM 的距离，但不能精确锁定；近似支持区间是 $Z$ 与最大值相差不超过 1 的 $r$ 范围。注意 $Z(0) = -\infty$：哪怕一次重组就排除了 $r = 0$。
:::
:::

caption: [[#eq-lod-phase-known]] 给出的 LOD 得分对重组频率 $r$ 的曲线，对应相型已知、其中 $R$ 次重组的 $N$ 次减数分裂。曲线在 $\hat r = R/N$ 处达峰，在 $r = 0.5$ 处为零。水平线标出惯用阈值：连锁 $Z \ge 3$，排除 $Z \le -2$。$N = 20$、$R = 2$ 时峰值恰好越过 3；试试 $N = 10$、$R = 0$（$r \to 0$ 处峰值 3.0），并看看 $R/N$ 达到 0.2 或更大时需要多少次减数分裂。保持 $R \le N$。

```python
# LOD score for phase-known meioses and its maximum (no numpy needed)
from math import log10

def lod(r, N, R):
    """Z(r) = log10 L(r)/L(1/2) for N meioses with R recombinants, 0 < r <= 0.5."""
    return R * log10(r) + (N - R) * log10(1 - r) + N * log10(2)

N, R = 20, 2
grid = [i / 1000 for i in range(1, 501)]           # r from 0.001 to 0.5
best = max(grid, key=lambda r: lod(r, N, R))
print(best, round(lod(best, N, R), 2))             # 0.1 3.2
```

这一方法可推广到相型未知的家系（似然对两种可能相型取平均）、不完全外显、以及同时使用多个标记（多点连锁分析）。1980 与 1990 年代，采用 DNA 标记的连锁分析——依据戴维·博特斯坦（David Botstein）、雷·怀特（Ray White）、马克·斯科尔尼克（Mark Skolnick）与罗纳德·戴维斯（Ronald Davis）1980 年提出的以限制性片段长度多态性作标记的建议——定位了亨廷顿病（1983）、囊性纤维化（1985–89）与许多其他孟德尔疾病的基因，进而实现了它们的克隆。人类遗传图总长约 3600 cM（两性平均；雌性图约为雄性图的 1.6 倍），所以以 $3.1\times10^9$ bp 的基因组计，1 cM 平均约对应 1 Mb——但交换成簇分布于宽仅几千碱基的**热点**中，其在人与小鼠中的位置主要由蛋白质 PRDM9 决定，故遗传距离与物理距离的局部关系变化极大。群体中的连锁不平衡作图见 [[population-genetics/linkage-disequilibrium]]。

::: application 标记辅助育种
动植物育种者利用连锁来选择难以直接鉴定的基因。若一个抗病等位基因位于某 DNA 标记 2 cM 处，选择携带与抗性处于相引相的标记等位基因的幼苗，就有 98 % 的情形选到抗性等位基因，而无需让植株接触病原。两侧各用一个侧翼标记可进一步提高准确度，因为此时出错需要一次双交换。这样的**标记辅助选择**已被用于把抗病与品质基因导入水稻、小麦与玉米品系。
:::

::: history

B. S. 霍尔丹（J. B. S. Haldane）1919 年导出他的作图函数，D. D. 科桑比（D. D. Kosambi）1944 年发表了他的。哈里特·克莱顿（Harriet Creighton）与芭芭拉·麦克林托克（Barbara McClintock）在玉米中、库尔特·施特恩（Curt Stern）在果蝇中，于 1931 年证明遗传重组伴随着有可见标记的染色体片段的互换。牛顿·莫顿（Newton Morton）1955 年为人类连锁分析引入了序贯 LOD 得分检验。

::: summary
- 连锁的基因座一起传递的频率高于自由组合的预言。相型或为相引（*AB*/*ab*）或为相斥（*Ab*/*aB*）；重组型配子携带新的组合。
- 重组频率 $r$ 由测交以 $R/N$ 估计；其值介于 0 与 $\tfrac12$ 之间，因为四链时期的交换只使四条染色单体中的两条成为重组型（马瑟：$r = \tfrac12(1 - p_0)$）。
- 图距是每条染色单体的平均交换次数，以摩尔根计；短区段中 1 cM ≈ 1 % 重组。霍尔丹：$r = \tfrac12(1 - e^{-2d})$，由交换的泊松过程导出；科桑比：$r = \tfrac12\tanh(2d)$，计入了干扰。
- 三点杂交中亲本型类别最多、双交换最少；双交换中被换走的等位基因指出中间的基因。双交换在两个区段都计数。干扰 $I = 1 - c$，$c$ = 观察双交换/期望双交换。
- 人类家系中连锁以 LOD 得分 $Z(r) = \log_{10}[L(r)/L(\tfrac12)]$ 评估；$Z \ge 3$ 为显著，独立家系的得分可相加。
- 遗传距离与物理距离只在平均意义上相关（人约每 Mb 对应 1 cM），因为交换成簇于热点、且两性别不同。
:::

::: exercise 一个重组频率 {level=1 check="0.15"}
*AB*/*ab* × *ab*/*ab* 测交得后代 *AB* 425、*ab* 425、*Ab* 76、*aB* 74。$\hat r$ 是多少？
::: solution
重组型为 *Ab* 与 *aB*：$R = 150$，$N = 1000$，$\hat r = 0.15$，即 15 cM。
:::

::: exercise 相斥相杂合子的配子 {level=1 check="0.1"}
两个基因座相距 20 cM（设 $r = 0.20$）。*Ab*/*aB* 个体的配子中 *AB* 占多大比例？
::: solution
对相斥相杂合子而言 *AB* 是重组型。两种重组型 *AB* 与 *ab* 平分 $r = 0.20$，所以 *AB* 为 $0.10$。
:::

::: exercise 霍尔丹距离 {level=1 check="25.5"}
用霍尔丹作图函数，$r = 0.20$ 对应多少 cM 的图距（保留一位小数）？
::: solution
$d = -\tfrac12\ln(1 - 0.4) = -\tfrac12\ln0.6 = 0.2554$ M $= 25.5$ cM。
:::
:::

::: exercise 伴连锁的 F2 {level=2 check="0.16"}
相引相双重杂合子 *AB*/*ab* 两性别均有 $r = 0.20$，自交。后代中 *ab*/*ab* 占多大比例？
::: solution
*ab* 配子是亲本型，两性别中的频率均为 $(1 - r)/2 = 0.40$。*ab*/*ab* 合子需要两性的配子都是 *ab*：$0.40^2 = 0.16$，未连锁时则为 $\tfrac1{16} = 0.0625$。（若为相斥相杂合子则是 $0.10^2 = 0.01$；F2 中双重隐性类别的频率是植物中估计 $r$ 的标准方法。）
:::
:::

::: exercise 科桑比距离 {level=2 check="34.7"}
用科桑比作图函数把 $r = 0.30$ 换算成 cM 图距（保留一位小数）。
::: solution
$d = \tfrac14\ln\dfrac{1.6}{0.4} = \tfrac14\ln4 = 0.3466$ M $= 34.7$ cM。
:::

::: exercise 相型未知的三点测交 {level=2}
对隐性等位基因 *x*、*y*、*z* 三重杂合、相型未知的个体进行测交。1000 个后代为：*x* + *z* 360，+ *y* + 348，*x* + + 82，+ *y z* 78，*x y* + 64，+ + *z* 58，*x y z* 6，+ + + 4。(a) 写出杂合子的等位基因排列与基因顺序。(b) 计算图距。(c) 计算符合系数与干扰。
::: solution
(a) 亲本型类别（最大者）：*x* + *z* 与 + *y* +，故杂合子为 *x* + *z* / + *y* +。双交换（最小者）：*x y z* 与 + + +。比较 *x y z* 与 *x* + *z*，只有 *y* 被换走，所以 *y* 在中间：顺序 *x*–*y*–*z*，杂合子为 *x* + *z* / + *y* +。

(b) *x*–*y* 区段：该区段的交换把 *x* + *z* 变成 *x y* +、把 + *y* + 变成 + + *z*：$64 + 58 = 122$。*y*–*z* 区段：*x* + + 与 + *y z*：$82 + 78 = 160$。所以 $r_{xy} = (122 + 10)/1000 = 0.132$（13.2 cM），$r_{yz} = (160 + 10)/1000 = 0.170$（17.0 cM）。

(c) 期望双交换 $= 0.132\times0.170\times1000 = 22.4$；观察 10；$c = 0.45$，$I = 0.55$。
:::
:::

::: exercise 十个非重组的 LOD {level=2 check="3.01"}
十次相型已知的减数分裂中，性状基因座与标记之间没有发生重组。最大 LOD 得分是多少（保留两位小数）？在哪个 $r$ 处达到？
::: solution
$R = 0$ 时 $Z(r) = 10\log_{10}(1 - r) + 10\log_{10}2$，在 $r = 0$ 处最大：$Z_{\max} = 10\log_{10}2 = 3.01$。十次无重组的相型已知减数分裂恰好足以得到显著的连锁证据。
:::
:::

::: exercise 解读可加性失败 {level=3}
成对测交给出重组频率 $r_{AB} = 0.10$、$r_{BC} = 0.25$、$r_{AC} = 0.30$。(a) 基因顺序如何？(b) 解释为什么 $r_{AC} < r_{AB} + r_{BC}$。(c) 在霍尔丹函数下把各频率换算成图距，检验图距是否可加。结果对干扰说明什么？
::: solution
(a) 最大的频率在 A 与 C 之间，所以 B 在中间：A–B–C。

(b) 双交换——A–B 与 B–C 中各一次——在两个短区段都是重组型，却恢复了 A 与 C 的亲本组合，所以它们计入 $r_{AB}$ 与 $r_{BC}$ 而不计入 $r_{AC}$。

(c) $d_{AB} = -\tfrac12\ln0.8 = 11.2$ cM，$d_{BC} = -\tfrac12\ln0.5 = 34.7$ cM，$d_{AC} = -\tfrac12\ln0.4 = 45.8$ cM。由于 $11.2 + 34.7 = 45.8$，霍尔丹图距在此可加（舍入误差内）：事实上 $1 - 2r_{AC} = 0.4 = (1 - 2r_{AB})(1 - 2r_{BC}) = 0.8\times0.5$，正是无干扰蕴含的关系。所以数据不显示干扰的证据；一般有 $r_{AC} = r_{AB} + r_{BC} - 2c\,r_{AB}r_{BC}$，此处给出 $c = 1$；若有正干扰（$c < 1$），$r_{AC}$ 应大于 0.30。
:::
:::

::: exercise 设计连锁研究 {level=3}
怀疑某标记位于性状基因座约 10 cM 处（$r = 0.1$）。(a) $N$ 次相型已知的减数分裂在真实 $r$ 处的期望 LOD 得分为 $N[r\log_{10}(2r) + (1-r)\log_{10}(2(1-r))]$。说明其来源。(b) 期望 LOD 要达到 3 需要多少次相型已知的减数分裂？(c) 实际中为什么需要更多？
::: solution
(a) 每次减数分裂重组时贡献 $\log_{10}(2r)$，不重组时贡献 $\log_{10}(2(1-r))$（[[#eq-lod-phase-known]]取 $N = 1$）。在真实 $r$ 下，一次减数分裂以概率 $r$ 重组，所以每次减数分裂的期望贡献是 $r\log_{10}(2r) + (1-r)\log_{10}(2(1-r))$，各次减数分裂的期望可以相加。

(b) 每次：$0.1\log_{10}0.2 + 0.9\log_{10}1.8 = -0.0699 + 0.2297 = 0.1598$。所以 $N = 3/0.1598 = 18.8$：约 19 次减数分裂。

(c) 真实家系包含相型未知的减数分裂、不含信息（纯合）的标记、诊断不确定与不完全外显，这些都会降低每次减数分裂的信息量；而期望 LOD 为 3 意味着观察 LOD 达不到 3 的机会相当大。因此研究要用功效计算——常以模拟——来设计。
:::
