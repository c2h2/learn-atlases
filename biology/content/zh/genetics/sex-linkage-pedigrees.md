1910 年，托马斯·亨特·摩尔根（Thomas Hunt Morgan）在纽约哥伦比亚大学一间拥挤的实验室里饲养果蝇，发现一只雄蝇的复眼是白色的而不是平常的砖红色。他把它与红眼雌蝇杂交，再让子代互交，白眼在 F2 中重新出现，比例约为隐性性状的预期值——但只出现在雄性中。有一个基因的行为仿佛就拴在 X 染色体上。这只果蝇第一次把一个特定基因同一个特定染色体联系起来；而摩尔根的学生卡尔文·布里吉斯（Calvin Bridges）对其遗传例外的分析，把遗传的染色体学说从一个合理的假说变成了确立的事实。

本章讨论性染色体上基因的遗传、两种性别 X 染色体数目不同的生物所采用的补偿机制，以及**系谱**分析：对于人以及不能随意杂交的其他物种，性状的遗传方式只能从家系图推断。我们全程使用[[genetics/mendelian-inheritance]]的概率，并增添一件新工具——贝叶斯定理，用来根据亲属的信息更新基因型概率。

## 摩尔根的白眼果蝇

::: definition 性连锁 {#def-sex-linkage}
位于 X 染色体上的基因是**X 连锁**的；位于 Y（且 X 上没有对应者）的是**Y 连锁**的。ZZ/ZW 物种中位于 Z 或 W 染色体上的基因是**Z 连锁**或**W 连锁**的。异配性别（XY 雄性、ZW 雌性）只带 X 连锁（或 Z 连锁）基因的一份拷贝，对它们是**半合子**：携带什么等位基因就表达什么，无论显性隐性。因性连锁而使正交与反交结果不同的遗传称为**性连锁遗传**。
:::

X 连锁基因型把等位基因作为上标写在染色体符号上：按果蝇（*Drosophila*）惯例，隐性白眼等位基因为 $w$，野生型红眼等位基因为 $w^+$，所以白眼雄蝇是 $X^{w}Y$，杂合雌蝇是 $X^{w^+}X^{w}$，常缩写为 $X^+X^w$。

摩尔根的杂交如下。

1. **红眼 ♀ × 白眼 ♂**（$X^+X^+ \times X^wY$）。F1 全部红眼：女儿 $X^+X^w$，儿子 $X^+Y$（儿子的 X 来自母亲）。
2. **F1 × F1**（$X^+X^w \times X^+Y$）。F2 由红眼雌蝇 2459 只、红眼雄蝇 1011 只与白眼雄蝇 782 只组成。预期的类别是 $X^+X^+$ 与 $X^+X^w$（全部为红眼雌蝇，$\tfrac12$）、$X^+Y$（红眼雄蝇，$\tfrac14$）与 $X^wY$（白眼雄蝇，$\tfrac14$）。白眼雌蝇缺席，与预言一致。
3. **反交：白眼 ♀ × 红眼 ♂**（$X^wX^w \times X^+Y$），用其后进一步杂交得到的白眼雌蝇做亲本，得到红眼女儿（$X^+X^w$）与白眼儿子（$X^wY$）：儿子像母亲，女儿像父亲。这就是**交叉遗传**，是 X 连锁隐性等位基因的标志。

::: proposition X 连锁隐性等位基因的杂交 {#prop-xlinked}
设 $a$ 是 XX/XY 物种中某个 X 连锁基因的隐性等位基因，分离正常、生活力相同。则：
1. 儿子把 X 来自母亲、Y 来自父亲；女儿从每个亲本各得一条 X。
2. $X^AX^a \times X^AY$ 的女儿全部为显性表型（一半为携带者），儿子 $\tfrac12$ 为 $X^AY$、$\tfrac12$ 为 $X^aY$。
3. $X^AX^A \times X^aY$ 的子代全部为显性表型，所有女儿均为携带者。
4. $X^aX^a \times X^AY$ 得显性表型（携带者）的女儿与隐性表型的儿子。
5. $X^AX^a \times X^aY$ 的女儿与儿子各 $\tfrac12$ 显性、$\tfrac12$ 隐性。
:::

::: proof
雌性以概率 $\tfrac12$ 各产生携带其两条 X 之一的卵细胞；雄性产生带 X 的精子（生女儿）与带 Y 的精子（生儿子），各概率 $\tfrac12$。所以女儿的基因型是（母亲的随机一条 X，父亲的 X），儿子的是（母亲的随机一条 X，Y）。把母亲的两条 X 一一列出即得各种情形：例如情形 (2)，女儿为 $X^AX^A$ 或 $X^aX^A$——均为显性表型——儿子为 $X^AY$ 或 $X^aY$，概率各 $\tfrac12$。
:::

::: example X 连锁基因与常染色体基因同时考虑 {#ex-x-auto}
果蝇中，残翅（*vg*）是常染色体隐性性状。一只两个基因座均杂合的雌蝇 $X^+X^w\ vg^+/vg$ 与一只白眼、残翅雄蝇 $X^wY\ vg/vg$ 杂交。子代中 (a) 白眼、残翅雌蝇和 (b) 红眼、正常翅雄蝇各占什么比例？(c) 儿子中的表型比如何？
::: solution
两个基因座在不同染色体上，故自由组合，可以相乘。X 基因座上，每个子代等概率地是 $X^+X^w$（红眼 ♀）、$X^wX^w$（白眼 ♀）、$X^+Y$（红眼 ♂）、$X^wY$（白眼 ♂）之一，各 $\tfrac14$。常染色体基因座上，*vg*$^+$/*vg* × *vg*/*vg* 在两性别中均给正常 : 残翅 = $\tfrac12 : \tfrac12$。

(a) $\tfrac14\cdot\tfrac12 = \tfrac18$。(b) $\tfrac14\cdot\tfrac12 = \tfrac18$。(c) 儿子中红眼 : 白眼 = $1:1$，正常 : 残翅 = $1:1$，彼此独立，所以红正常 : 红残 : 白正常 : 白残 = $1:1:1:1$。此处女儿也按相同比值呈现同样四个类别，因为父亲携带 *w*；若父亲为红眼，则所有女儿都将是红眼。
:::
:::

::: example 检验摩尔根的 F2 {#ex-morgan}
检验摩尔根的 F2 计数（红眼雌 : 红眼雄 : 白眼雄 = 2459 : 1011 : 782）对 X 连锁下 $2:1:1$ 预期的符合度。若拟合不佳，找出偏差所在。
::: solution
$n = 4252$，所以 $E = 2126,\ 1063,\ 1063$。$X^2 = \dfrac{333^2}{2126} + \dfrac{52^2}{1063} + \dfrac{281^2}{1063} = 52.2 + 2.5 + 74.3 = 129.0$，$\nu = 2$；$p < 10^{-20}$。拟合很差。但问题出在数目而非模式：雌蝇多于雄蝇（$2459 : 1793$），雄蝇中白眼又少于红眼（$782 : 1011$，对 $1:1$ 检验得 $X^2 = 29.2$）。若白眼果蝇的生活力低于红眼——拥挤培养的突变果蝇的常见情形——两个偏差便都能解释。定性预言——没有白眼雌蝇——完全符合。这一教训具有一般性：χ² 检验拒绝的是一个精确的数值假说，而是否应拒绝遗传学模型，取决于哪条假设——此处为生活力相等——没有成立。
:::
:::

## 布里吉斯与不分离：染色体学说的证明

卡尔文·布里吉斯大规模重做白眼 ♀ × 红眼 ♂ 的杂交时发现，约每 2000 个子代中有 1 个例外：白眼女儿或红眼儿子，与[[#prop-xlinked]](4) 相违。例外的红眼儿子是不育的。布里吉斯在 1916 年提出，这些果蝇的母亲在减数分裂中两条 X 染色体偶尔没有分开——**不分离**——产生了带两条 X（$X^wX^w$）或不带 X（O）的卵细胞。

| 卵细胞 | 精子 $X^+$ | 精子 Y |
|---|---|---|
| $X^wX^w$ | $X^+X^wX^w$（通常死亡） | $X^wX^wY$：**白眼雌蝇** |
| O | $X^+O$：**红眼、不育雄蝇** | YO：死亡 |

这一假说做出了一个突出的预言：例外的白眼雌蝇应当携带一条 Y 染色体，例外的红眼儿子应当缺少 Y。布里吉斯在显微镜下检查它们的染色体，结果正是如此。他更进一步：XXY 雌蝇因为多了一条染色体，**次级不分离**的比率要高得多（百分之几）——因为 X 与 Y 有时互相配对而让另一条 X 随机走向一极——他预言并在其后代中找到了相应的例外子代。

::: intuition 布里吉斯的例外后代为何有决定性
摩尔根的杂交表明白眼基因的行为像一个 X 连锁基因。布里吉斯则表明：每当 X 染色体做出不寻常的事，白眼基因就做同样不寻常的事——而且染色体的异常可以直接看到。一个基因与一条染色体连不规则的行为都处处同步，很难再被视为两个不同的物理实体。他论文的标题——*Non-disjunction as proof of the chromosome theory of heredity*（《不分离作为遗传的染色体学说的证明》），发表于 *Genetics* 杂志第一卷（1916）——就是对结论的陈述。
:::

同样的机制——人减数分裂中 X 染色体的不分离——解释了核型为 47,XXY 或 45,X 的人的来源（[[genetics/chromosome-mutations]]）。果蝇中的这些结果还揭示了 Y 的不同作用：XO 果蝇为雄性，XXY 果蝇为雌性（[[genetics/chromosomes-meiosis]]）。

## 其他性连锁遗传方式

**Y 连锁**（全雄遗传）基因由父亲传给所有儿子，绝不传给女儿。局限于 Y 上的基因很少：人的 Y 染色体携带几十个蛋白编码基因，许多与睾丸决定（*SRY*）和精子生成有关。人的 X 与 Y 的两端是**假常染色体区**——两条染色体共有、在雄性减数分裂中配对并交换的短区段——其中的遗传方式几乎与常染色体基因相同。

**Z 连锁**则两性互换。事实上第一个性连锁的例子恰恰是在一种 ZW 物种——醋栗尺蛾 *Abraxas grossulariata*——中由伦纳德·唐卡斯特（Leonard Doncaster）与杰拉尔德·雷纳（Gerald Raynor）于 1906 年发现的，当时还没有人能解释它。鸡中，决定横斑羽的显性 Z 连锁等位基因 *B* 提供了一个简易的雏鸡性别鉴定法：非横斑公鸡（$Z^bZ^b$）与横斑母鸡（$Z^BW$）交配，得横斑儿子（$Z^BZ^b$）与非横斑女儿（$Z^bW$），出壳时凭头顶绒羽的白斑即可区分。

## 剂量补偿

在 XX/XY 物种中，雌性每个 X 连锁基因有两份拷贝而雄性只有一份。由于多数基因的表达量与拷贝数成正比，而 X 上携带着两性别都需要的许多基因（人约 800 个蛋白编码基因），剂量不均就会出问题。不同的类群用不同的方式解决了这个难题。

::: definition 剂量补偿 {#def-dosage}
**剂量补偿**是使 X 连锁基因的表达在两性别间均衡、以抵消其 X 染色体数目差异的任何机制。在**真兽类（有胎盘哺乳类）**中，雌性每个细胞的一条 X 在发育早期失活；在***Drosophila***（果蝇）中，雄性那条 X 的转录活性约为两倍；在***C. elegans***（秀丽隐杆线虫）中，雌雄同体的两条 X 都以一半的水平表达。
:::

1949 年，默里·巴尔（Murray Barr）与埃沃特·伯特伦（Ewart Bertram）注意到雌猫神经细胞核中有一个小而染色很深的结构，雄性则没有——**巴氏小体**。玛丽·莱昂（Mary Lyon）于 1961 年根据 X 连锁毛色基因杂合小鼠的斑驳毛皮提出：巴氏小体就是一条失活的 X 染色体。**莱昂假说**如今已获充分证实，包含四条。

1. 哺乳类雌性每个细胞中有一条 X 染色体失活：它凝缩为异染色质，其多数基因沉默。
2. 失活发生在胚胎发育早期（人约在胚胎着床前后）。
3. 每个细胞中选择失活哪条 X——母源的还是父源的——是随机的（小鼠胎盘等少数例外情况下优先失活父源 X）。
4. 选择一经做出，便由该细胞的所有后代细胞继承。

因此杂合雌性是一个**嵌合体**（mosaic），其细胞分为分别表达两种等位基因之一的斑块。猫的玳瑁与三花毛皮直接展示了这一点：X 连锁的 *Orange* 基因座有 *O*（橙色色素）与 *o*（黑色）两个等位基因，$X^OX^o$ 雌猫长出一块块橙色与黑色的毛。玳瑁色雄猫很罕见，且通常为 XXY。失活由长非编码 RNA ***XIST*** 启动：*XIST* 由将要失活的那条 X 转录，并在顺式（*cis*）将其包裹。某些基因——包括假常染色体区的基因——可以逃脱失活，这正是 X 染色体非整倍体者仍表现出症状的原因之一。

::: warning "携带者雌性不发病，因为每个细胞里正常等位基因是显性的"
杂合的哺乳类雌性在细胞层次并不是均一的杂合子：每个细胞只表达两个等位基因之一。她是否表现表型，取决于一个约一半细胞正常的嵌合体能否正常运作，以及每种 X 处于活跃状态的细胞比例——后者可能碰巧远离 $50 : 50$（"X 失活偏倚"）。对于分泌型产物（如凝血因子），正常细胞通常足以供应全身；而对于每条肌纤维都需要的蛋白质，嵌合体可能表现出斑块状的症状。
:::

## 人类 X 连锁性状及其频率

由于雄性是半合子，X 连锁隐性等位基因在所有携带它的雄性中表现表型，在雌性则只有纯合时才表现。

::: proposition X 连锁隐性性状的性别比 {#prop-xfreq}
设某 X 连锁隐性等位基因在随机交配群体中的频率为 $q$，两性别相同。则隐性表型的频率在雄性为 $q$、在雌性为 $q^2$，患病男性与患病女性之比为 $1/q$。
:::

::: proof
雄性从一位随机的母亲那里得到一条 X；它以概率 $q$ 携带该等位基因。雌性从每个亲本各得一条 X，随机交配下相互独立；两条都携带该等位基因的概率为 $q\cdot q = q^2$。比值为 $q/q^2 = 1/q$。
:::

红绿色觉缺陷主要由 Xq28 上串联排列的视蛋白基因 *OPN1LW* 与 *OPN1MW* 的重排引起，约 8 % 的北欧血统男性受累。取 $q \approx 0.08$，[[#prop-xfreq]]预言约 $0.08^2 = 0.64\ \%$ 的女性，与观察到的约 0.5 % 接近；男女之比为 $1/0.08 = 12.5$。对罕见的 X 连锁疾病——如甲型血友病（凝血因子 VIII 基因 *F8*）或杜氏肌营养不良（*DMD*）——$q$ 约为 $10^{-4}$ 量级，患病女性极为罕见。（临床方面归[医学图谱](/learn/medicine/lesson.php?c=genetics&l=mendelian-inheritance)。）

## 系谱分析

人不能安排婚配，家庭子女少，多数个体的基因型未知。遗传方式必须从**系谱**推断。系谱按标准符号绘制：方块为男性，圆圈为女性，填充符号为患者，横线连接配偶，纵线向下连到同胞，双横线表示近亲婚配（亲属之间），代数用罗马数字，个体在代内从左到右编号（II-3 是第 II 代第三人）。使这个家系受到关注的成员是**先证者**。

::: definition 主要遗传方式的判断标准 {#def-pedigree-criteria}
针对罕见、完全外显的性状：
- **常染色体隐性**：患者的父母通常无病（均为携带者）；性状常出现在同胞而不出现于其他各代（"水平"式）；两性别受累比例相同；父母近亲婚配比一般人群更常见。两个患者婚配只生患者子女。
- **常染色体显性**：每个患者的亲本之一必为患者（除非等位基因由新发突变产生）；性状代代出现（"垂直"式）；患者约一半子女受累；两性别均可受累并可传递，包括父传子。
- **X 连锁隐性**：受累男性远多于女性；患病男性经由无病的携带者女性互相关联（性状由男子经其女儿传给其半数外孙）；**无父传子**。
- **X 连锁显性**：患病男性把性状传给所有女儿而不传任何儿子；杂合患病女性传给半数无论性别的子女；患病女性约为患病男性的两倍。
- **Y 连锁**：仅男性受累，患病男性的所有儿子均受累。
- **线粒体**：由患病母亲传给其全部或多数子女，患病父亲从不传递（[[genetics/non-mendelian-inheritance]]）。
:::

推理的方式是排除。一对无病父母生出一个患病孩子这一实例，就排除显性遗传（在完全外显且无新突变的前提下）；一次父传子排除 X 连锁；一位无病父亲生出一个患病女儿排除 X 连锁隐性遗传。一个系谱通常仍与不止一种方式相容，这时我们说明哪一种更可能——"罕见性状"假设至关重要，因为常见等位基因的婚入者中携带者很多，隐性性状可能连续几代出现。

::: example 解读系谱 {#ex-pedigree}
一个家系中，一对正常的夫妇（I-1、I-2）有四个孩子：患病儿子 II-1、正常女儿 II-2、正常儿子 II-3 与患病女儿 II-4。II-2 与一个来自无亲缘关系家庭的正常男子结婚，育有三个正常孩子。这一罕见性状可能是什么遗传方式？
::: solution
无病父母生出患病孩子，排除常染色体显性与 X 连锁显性（在完全外显、无新突变的前提下）。无病父亲（I-1）生出患病女儿（II-4），排除 X 连锁隐性遗传，因为 $X^aX^a$ 的女儿必须有一位 $X^aY$、即患病的父亲。患病女儿排除了 Y 连锁，线粒体遗传则要求母亲患病。只有**常染色体隐性**相符：I-1 与 I-2 均为 *Aa*。II-2 与 II-3 各以概率 $\tfrac23$ 为携带者（[[genetics/mendelian-inheritance#prop-two-thirds]]）。
:::
:::

- [ ] 常染色体显性
- [ ] 常染色体隐性
- [x] X 连锁隐性
- [ ] 都不能排除
::: solution
儿子把 X 来自母亲而绝不来自父亲，所以 X 连锁性状不可能由父亲传给儿子。（X 连锁显性也因同样理由被排除。）常染色体显性很相符。常染色体隐性并未被严格排除，但那要求无亲缘关系的妻子是罕见等位基因的携带者，可能性很小。
:::
:::

### 贝叶斯风险计算

系谱常携带比简单孟德尔概率所能利用的更多信息。考虑一位女子，她的兄弟患某 X 连锁隐性病，因此她的母亲是携带者（因该病罕见，兄弟的等位基因几乎肯定来自母亲而非新突变）。在了解其他情况之前，她是携带者的概率为 $\tfrac12$。但设她已有三个儿子，全部正常。若她是携带者，每个儿子幸免的概率为 $\tfrac12$；若不是，则儿子正常是必然的。她的儿子们构成对她为携带者不利的证据，而贝叶斯定理说明不利多少。

::: proposition 贝叶斯携带者概率 {#prop-bayes-carrier}
设一位女子为某完全外显 X 连锁隐性等位基因的杂合携带者的先验概率为 $p_0$，她有 $k$ 个儿子且全部正常（无其他相关信息）。则她为携带者的后验概率为

$$
P(\text{携带者} \mid k \text{ 个正常儿子}) = \frac{p_0\,(\tfrac12)^k}{p_0\,(\tfrac12)^k + (1 - p_0)} .
$$ {#eq-bayes-carrier}

$p_0 = \tfrac12$ 时即为 $1/(1 + 2^k)$。假设：无新突变、完全外显、各儿子的遗传相互独立，且儿子的表型确知无误。
:::

::: proof
由贝叶斯定理，$P(C \mid D) = P(D \mid C)\,P(C)/P(D)$，其中 $C$ 为"是携带者"，$D$ 为数据。$P(D \mid C) = (\tfrac12)^k$，因为每个儿子独立地以概率 $\tfrac12$ 得到正常 X；$P(D \mid \bar C) = 1$。全概率公式给出 $P(D) = p_0(\tfrac12)^k + (1-p_0)\cdot1$，代入即得[[#eq-bayes-carrier]]。$p_0 = \tfrac12$ 时因子 $\tfrac12$ 相消：$\dfrac{(1/2)^k}{(1/2)^k + 1} = \dfrac{1}{1 + 2^k}$。
:::

::: example 三个正常的儿子 {#ex-bayes}
对上面描述的那位女子，$p_0 = \tfrac12$，三个儿子均正常，计算她为携带者的概率以及她的下一个儿子患病的概率。
::: solution
由[[#eq-bayes-carrier]]，$P(\text{携带者}) = 1/(1 + 2^3) = \tfrac19 \approx 0.111$。列成表：

| | 携带者 | 非携带者 |
|---|---|---|
| 先验概率 | $\tfrac12$ | $\tfrac12$ |
| 三个正常儿子的似然 | $\tfrac18$ | $1$ |
| 联合概率 | $\tfrac1{16}$ | $\tfrac12 = \tfrac8{16}$ |
| 后验概率 | $\tfrac{1}{9}$ | $\tfrac89$ |

她的下一个儿子患病的概率为 $\tfrac19\cdot\tfrac12 = \tfrac1{18} \approx 0.056$，而未考虑她儿子们的表型之前是 $\tfrac14$。这是一道条件概率练习；真实家系的风险评估要考虑多得多的因素，那是临床遗传服务的事务（[医学图谱](/learn/medicine/lesson.php?c=genetics&l=genetic-testing)）。
:::
:::

::: application 人类以外的系谱分析
系谱分析对不便测交的动物与植物同样重要：繁育计划中的濒危物种（以系谱簿追踪血统以尽量减少近交，[[conservation-biology]]）、家畜与伴侣动物（据亲属记录——越来越多地借助 DNA 检测——认定隐性疾病的携带者）、以及长寿的树木。同样的排除推理与贝叶斯更新逻辑都适用；在繁育计划中，这些推算常常在数以千计有亲缘关系的个体上自动进行。
:::

::: history
伦纳德·唐卡斯特（Leonard Doncaster）与杰拉尔德·雷纳（Gerald Raynor）1906 年描述了醋栗尺蛾的性连锁遗传，威廉·施皮尔曼（William Spillman）1908 年描述了鸡横斑羽的性连锁遗传，当时都没有染色体解释。托马斯·亨特·摩尔根（Thomas Hunt Morgan）1910 年 7 月在 *Science* 上报告了白眼雄蝇及其 X 连锁遗传（*Sex limited inheritance in* Drosophila，《果蝇中性限定的遗传》）。卡尔文·布里吉斯（Calvin Bridges）1916 年发表 *Non-disjunction as proof of the chromosome theory of heredity*（《不分离作为遗传的染色体学说的证明》）。默里·巴尔（Murray Barr）与埃沃特·伯特伦（Ewart Bertram）1949 年描述了性染色质小体，玛丽·莱昂（Mary Lyon）1961 年提出 X 染色体失活（*Gene action in the X-chromosome of the mouse*，《小鼠 X 染色体的基因作用》，发表于 *Nature*）。*XIST* 基因 1991 年由卡罗琳·布朗（Carolyn Brown）、亨廷顿·威拉德（Huntington Willard）及同事鉴定。人 X 与 Y 的假常染色体区于 1980 年代被表征，Y 连锁的性别决定基因 *SRY* 于 1990 年被鉴定。
:::

::: summary
- X 连锁基因由母亲传给儿子、由双亲传给女儿；雄性为半合子。X 连锁隐性性状表现交叉遗传，绝不由父亲传给儿子。
- 摩尔根的白眼果蝇（1910）把一个基因系到 X 染色体上；布里吉斯由 X 不分离得到的例外子代（1916）并经细胞学证实，证明了基因在染色体上。
- Y 连锁基因由父亲传给所有儿子；鸟类与蛾类的 Z 连锁基因呈现与 X 连锁基因相反的格局。
- 剂量补偿均衡 X 连锁基因的表达：哺乳类雌性随机 X 失活（莱昂假说；*XIST*；玳瑁猫式的嵌合），果蝇雄性 X 上调两倍，线虫雌雄同体两条 X 各减半。
- 等位基因频率为 $q$ 时，X 连锁隐性性状累及 $q$ 的男性与 $q^2$ 的女性。
- 系谱按常染色体与 X 连锁显、隐性的判断标准以排除法解读；一次观察（无病父母生出患病孩子、父传子）就能排除一种方式。
- 贝叶斯定理把先验基因型概率与亲属表型结合：先验 $\tfrac12$、$k$ 个正常儿子时携带者概率为 $1/(1+2^k)$。
:::

## 练习

::: exercise 白眼的儿子 {level=1 check="1/2"}
一只杂合红眼果蝇雌蝇（$X^+X^w$）与一只白眼雄蝇杂交。她的女儿中有几分之几是白眼？
::: solution
女儿从父亲得到 $X^w$，从母亲得到 $X^+$ 或 $X^w$，各概率 $\tfrac12$：一半为 $X^wX^w$（白眼），一半为 $X^+X^w$（红眼）。
:::

::: exercise 女性的色觉缺陷 {level=1 check="0.0036"}
某群体 6 % 的男性有 X 连锁隐性的色觉缺陷，随机交配下预期多大比例的女性有此缺陷？
::: solution
$q = 0.06$，故 $q^2 = 0.0036$，即 0.36 % 的女性（[[#prop-xfreq]]）。
:::
:::

::: exercise 雏鸡鉴雌雄 {level=1}
横斑鸡与非横斑鸡之间怎样的交配方式能使雏鸡出壳时凭羽色鉴别性别？为什么反交不行？
::: solution
非横斑公鸡（$Z^bZ^b$）× 横斑母鸡（$Z^BW$）：儿子 $Z^BZ^b$ 为横斑，女儿 $Z^bW$ 非横斑。反交——横斑公鸡（$Z^BZ^B$）× 非横斑母鸡（$Z^bW$）——所有雏鸡均为横斑（儿子 $Z^BZ^b$、女儿 $Z^BW$），羽色无法区分。
:::
:::

::: exercise 携带者的女儿 {level=2 check="1/8"}
一位女子的舅舅患甲型血友病（罕见的 X 连锁隐性病），因此她的外祖母被认定为携带者。她母亲与她本人都没有其他相关信息。她是携带者的先验概率是多少？她的第一个儿子患病的概率是多少？
::: solution
她母亲是携带者的概率为 $\tfrac12$；若是，她是携带者的概率又是 $\tfrac12$。所以 $p_0 = \tfrac14$。儿子患病的概率为 $\tfrac14\cdot\tfrac12 = \tfrac18$。（若她母亲有正常的儿子，就需要像[[#ex-bayes]]那样的贝叶斯修正，这些数字会更小。）
:::
:::

::: exercise 两个儿子的贝叶斯更新 {level=2 check="1/5"}
一位对某 X 连锁隐性等位基因先验携带概率为 $\tfrac12$ 的女子有两个正常的儿子。她为携带者的后验概率是多少？
::: solution
由[[#eq-bayes-carrier]]，$1/(1 + 2^2) = \tfrac15$。
:::

::: exercise 哪种遗传方式？ {level=2}
对下列每种罕见、完全外显的性状，说明哪些遗传方式（常显、常隐、X 显、X 隐）被排除，哪种最可能。(a) 一位患病男子与一位正常女子育有三个患病女儿和两个正常儿子。(b) 一对正常的表兄妹五个子女中有两个患病。(c) 一位患病女子与一位正常男子育有一个患病儿子、一个正常儿子、一个患病女儿和一个正常女儿。
::: solution
(a) 所有女儿患病而儿子全正常，与 **X 连锁显性**完全吻合：父亲把 X 给每个女儿而不给儿子。常染色体显性并未排除，但那样每个孩子患病概率为 $\tfrac12$ 且与性别无关，这一特定组合的概率是 $(\tfrac12)^5 = \tfrac1{32}$。两种隐性方式都要求无亲缘关系的母亲携带罕见等位基因；X 连锁隐性还须使患病女儿为 $X^aX^a$——只有她也是携带者才可能，那样一些儿子也应患病。X 连锁显性最可能。

(b) 无病父母生出患病孩子排除显性方式。近亲婚配指向**常染色体隐性**。若任何一个患病孩子是女儿（父亲正常），X 连锁隐性被排除；否则它可能成立，但近亲婚配对它并无意义。

(c) 患病母亲生出两性别都有患病孩子，**常染色体显性**与 **X 连锁显性**同样吻合；这个家系无法区分两者。无病父亲生出患病女儿排除 X 连锁隐性。常染色体隐性要求无亲缘关系的父亲是携带者：可能，但对罕见性状来说不大可能。区分常显与 X 显需要患病的*男性*：一位有患病儿子的患病男子排除 X 连锁。
:::
:::

::: exercise 玳瑁色雄猫 {level=2}
发现一只玳瑁色雄猫。(a) 它最可能的性染色体组成是什么？如何产生？(b) 这样的雄猫为什么通常不育？(c) 说出雄猫可能呈玳瑁色的另一种原因。
::: solution
(a) $X^OX^oY$——XXY 雄性，来自不分离产生的精子或卵细胞（$X^OY$ 精子配 $X^o$ 卵，或 $X^OX^o$ 卵配 Y 精子）。Y 使它成为雄性；两条 X 各随机失活一条，于是产生颜色斑块。

(b) XXY 雄性——如 47,XXY 的男子——精子生成通常受损。

(c) 作为两个胚胎融合形成的**嵌合体（chimera）**，一个胚胎携带 $X^O$、另一个携带 $X^o$（两者均为 XY）；或 *Orange* 基因在发育早期发生体细胞突变，产生嵌合。
:::
:::

::: exercise 布里吉斯的数据 {level=3}
白眼雌蝇与红眼雄蝇的杂交中，设母亲 X 染色体的初级不分离发生于 0.1 % 的减数分裂，产生数目相等的 XX 与 O 卵细胞，且 XXX 与 YO 合子死亡。(a) **存活**子代中例外的白眼雌蝇占几分之几？(b) 例外的红眼雄蝇呢？(c) 布里吉斯为什么不能只凭计数证明他的假说？什么观察一锤定音？
::: solution
(a) 卵细胞：$X^w$ 概率 0.999，$X^wX^w$ 概率 0.0005，O 概率 0.0005。精子 $X^+$ 与 Y 各 $\tfrac12$。合子：正常女儿 $X^+X^w$ $0.4995$，正常儿子 $X^wY$ $0.4995$；$X^+X^wX^w$ $0.00025$（死亡）；$X^wX^wY$ $0.00025$（白眼雌蝇）；$X^+O$ $0.00025$（红眼雄蝇）；YO $0.00025$（死亡）。存活者合计 $1 - 0.0005 = 0.9995$。例外白眼雌蝇：$0.00025/0.9995 = 2.5\times10^{-4}$，约四千分之一。

(b) 同样是 $2.5\times10^{-4}$，所以两类例外合占存活者约两千分之一，与布里吉斯的观察一致。

(c) 罕见的例外可能有别的解释，如新突变或混杂。该假说对染色体做出了不显然的预言：例外雌蝇应为 XXY，例外雄蝇应为 XO。布里吉斯在显微镜下看到了这些核型，还预言并在 XXY 雌蝇中发现了高比率的次级不分离，把遗传学观察与细胞学观察联在一起。
:::

::: exercise 解读一个大系谱 {level=3}
一个五代家系中出现一种罕见性状。16 位患者中 15 位是男性。每位患病男性的母亲均正常；四位患病男性留有后代，他们的 9 个儿子与 7 个女儿无一患病，但其中两位的女儿生了患病的儿子。(a) 提示哪种遗传方式？(b) 唯一的女性患者的父亲正常，她的母亲是患病男子的姐妹。为她的表型提出两种遗传学解释。(c) 患病男性的女儿是携带者的概率是多少？这样的携带者的儿子患病的概率又是多少？
::: solution
(a) X 连锁隐性：几乎只有男性患病，经由无病的女性传递，无父传子，且患病男性的女儿生患病儿子（经女儿的"外祖父传外孙"的经典格局）。

(b) 她很可能是杂合携带者（$X^AX^a$），因 X 失活严重偏倚——多数相关细胞中正常 X 失活——而表现出性状。另一种可能是她携带一个*de novo*（新发）突变等位基因，来自父亲的配子；或有染色体异常，如 45,X（单条 X）或 X;常染色体易位——后者迫使正常的 X 失活。（经遗传而纯合可以排除，因为她的父亲正常。）

(c) 患病男性把他的唯一一条 X 传给每个女儿，所以每个女儿都是必然携带者（概率 1）。她的每个儿子患病的概率为 $\tfrac12$。
:::
