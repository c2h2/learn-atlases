孟德尔的因子是抽象的东西：成对存在、在配子形成时分离、彼此独立组合。他完全不知道它们在细胞的哪个位置，也不可能知道，因为染色体在细胞分裂中的行为到 1870 与 1880 年代才被弄清楚。1900 年孟德尔的论文被重新发现时，细胞学家已经知道每个物种都有特征性的染色体数目，体细胞中染色体成对存在，而一种特殊的分裂使配子中的数目减半。三年之内，其中两位——沃尔特·萨顿（Walter Sutton）与西奥多·博韦里（Theodor Boveri）——指出染色体在减数分裂中的行为恰恰是孟德尔的因子必须如此的样子。**遗传的染色体学说**——基因位于染色体上——在十年后由 [[genetics/sex-linkage-pedigrees]] 所述的性连锁工作所证明。

本章按遗传学家的眼光描述染色体，追踪它们穿过减数分裂并展示减数分裂如何产生孟德尔的两条定律，然后转向一个物种内最醒目的染色体差异：决定性别的染色体。有丝分裂与细胞周期见 [[cell-biology/cell-cycle]]；我们视之为已知，集中讲减数分裂有何不同。

## 染色体与倍性

一条**染色体**是一个单一、非常长的 DNA 分子连同包装它的蛋白质（主要是组蛋白）。在细胞周期的大部分时间染色体呈伸展状态，无法逐个看见；在有丝分裂与减数分裂中它们凝缩成光学显微镜下可见的致密结构。DNA 复制后，每条染色体由两条相同的**姐妹染色单体**组成，沿长度由黏连蛋白相连，并在**着丝粒**——动粒装配的区域——处相接。线性染色体的末端由**端粒**封顶。

::: definition 倍性与同源染色体 {#def-ploidy}
含一个完整染色体组的细胞是**单倍体**；一个组中的染色体数目记为 $n$。含两个组的细胞是**二倍体**（$2n$），三个组是**三倍体**（$3n$），等等。二倍体中每对的两个成员——各来自一个亲本——是**同源染色体**（同源体）：它们按相同顺序携带相同的基因座，但不一定是相同的等位基因。性染色体以外的染色体是**常染色体**。**核型**是一个细胞染色体的全套组成，以凝缩染色体按大小与着丝粒位置配对排列的形式展示。
:::

着丝粒位置给染色体以特征形状：**中着丝粒染色体**（着丝粒近中部，两臂长度相近）、**亚中着丝粒染色体**、**近端着丝粒染色体**（着丝粒近一端）与**端着丝粒染色体**（在末端；正常人的染色体中没有，但小鼠染色体全为近端着丝粒至端着丝粒）。人染色体的臂命名为 *p*（短）与 *q*（长），轻度胰蛋白酶处理后吉姆萨染色（**G 显带**）使每条染色体呈现可重复的明暗带型，使各带可以从着丝粒向外编号——例如 7q31 是 7 号染色体长臂第 3 区第 1 带。

染色体数目差异极大，与生物的复杂程度没有简单的关系。

| 生物 | $2n$ |
|---|---|
| 跳蚁 *Myrmecia pilosula* | 2（雌性；雄性为单倍体，1 条） |
| 黑腹果蝇 *Drosophila melanogaster* | 8 |
| 拟南芥 *Arabidopsis thaliana* | 10 |
| 秀丽隐杆线虫 *Caenorhabditis elegans* | 12（雌雄同体；雄虫 11 条） |
| 豌豆 *Pisum sativum* | 14 |
| 玉米 *Zea mays* | 20 |
| 酿酒酵母 *Saccharomyces cerevisiae* | 32（二倍体；单倍体细胞 16 条） |
| 小家鼠 *Mus musculus* | 40 |
| 人 *Homo sapiens* | 46 |
| 犬 *Canis familiaris* | 78 |

有两个量随细胞周期变化，必须区分：染色体数目（按着丝粒计数）与 DNA 含量。一个未复制单倍体组的 DNA 含量称为 **1C**；G1 期的二倍体细胞为 $2C$，S 期后升至 $4C$，而染色体数目直到后期都保持 $2n$。

## 减数分裂

若配子与体细胞有同样多的染色体，有性生殖每一代都会使染色体数目加倍。**减数分裂**防止了这一点：一轮 DNA 复制接着两轮染色体分离，由一个二倍体核产生四个单倍体核。

::: definition 减数分裂 {#def-meiosis}
**减数分裂**是二倍体细胞产生单倍体产物所经的一对核分裂。**减数分裂 I**（**还原分裂**）中，同源染色体配对、经交叉互换片段，然后移向两极分离，而姐妹染色单体保持在一起。**减数分裂 II**（**均等分裂**）中姐妹染色单体分离，如同有丝分裂。从一个含 $4C$ DNA、$2n$ 条已复制染色体的细胞出发，减数分裂产生四个核，各含 $1C$、$n$ 条未复制染色体。
:::

各时期命名与有丝分裂相同，但前期 I 漫长而繁复——在酵母或植物中可持续数天；在人女性中它始于胎儿卵巢，停滞数年乃至数十年，直到排卵时减数分裂才恢复。

1. **前期 I。** 染色体凝缩（**细线期**）。同源体彼此找到并沿全长对齐（**联会**），借助一个蛋白质支架——**联会复合体**（**偶线期**）。每个联会配对（含四条染色单体）是一个**二价体**（或四分体）。在**粗线期**，联会完成，**交叉互换**发生：DNA 上程序性的双链断裂以同源体的非姐妹染色单体为模板修复，其中一些修复事件交换了两侧的片段。**双线期**联会复合体解体，同源体彼此拉开，仅在发生交叉处除外；这些接触点可见为**交叉**（chiasma，单数交叉点）。**终变期**染色体进一步凝缩，核膜破裂。
2. **中期 I。** 二价体排列在纺锤体上。每条同源体的两个姐妹动粒连到*同一*极（**单向定向**），两条同源体连到相反的两极。交叉连同其远侧臂上的黏连蛋白，在纺锤体的拉力下把同源体保持在一起。
3. **后期 I。** 染色体臂上的黏连蛋白被切割，交叉随之消解，同源体移向两极。着丝粒处的黏连蛋白受到保护（由蛋白质 shugoshin 及其相关磷酸酶），所以姐妹染色单体保持在一起。
4. **末期 I 与胞质分裂**产生两个细胞，各含 $n$ 条已复制染色体（$2C$）。下一次分裂之前没有 DNA 复制。
5. **减数分裂 II。** 每个细胞中，姐妹动粒连到相反两极；后期 II 切割着丝粒黏连蛋白，姐妹单体分开。四个产物各含 $n$ 条染色体（$1C$）。

::: warning "交叉发生在两条染色体之间、减数分裂开始之后"
两个细节常被记错。第一，交叉发生在 DNA 复制*之后*、四分体时期，每次交叉只涉及四条染色单体中的两条——每条同源体各一条。这就是一次两个基因座之间的交叉产生两条重组与两条非重组染色单体的原因，也是重组频率从不超过 50 % 的原因（[[genetics/linkage-mapping]]）。第二，同源体分离发生在后期 I，不是后期 II；第二次分裂分开的是姐妹染色单体，它们只在有交叉发生的地方才不同。
:::

交叉不只是变异的来源。多数生物每个二价体至少要有一次交叉（**必备交叉**），精确分离才有保障，因为正是交叉把同源体拉住、使它们能在纺锤体上双向定向。没有交叉的二价体错误分离的风险增高。黑腹果蝇（*Drosophila*）雄性完全没有减数分裂交叉，改用特殊的配对机制。

| | 有丝分裂 | 减数分裂 |
|---|---|---|
| 分裂轮数 | 1 | 2 |
| 同源体配对 | 无 | 有（前期 I） |
| 交叉互换 | 罕见 | 规律（通常每个二价体至少一次） |
| 第一次分裂中姐妹动粒 | 双向定向 | 单向定向 |
| 产物 | 2 个细胞，$2n$，遗传上相同 | 4 个细胞，$n$，遗传上不同 |
| 作用 | 生长、修复、无性生殖 | 形成配子或孢子 |

动物中减数分裂的产物是配子，但雌性中减数分裂是不均等的：卵子发生中分裂不对称，产生一个大的卵细胞和退化的小的**极体**，而精子发生中四个产物都成为精子。植物与真菌中减数分裂的产物是孢子，孢子长成单倍体生物（植物的配子体、真菌的单倍体细胞或菌丝体），后者之后经有丝分裂产生配子。

::: example 减数分裂全程的染色体与 DNA 计数 {#ex-counting}
黑腹果蝇 $2n = 8$，单倍体基因组约 $1.8\times10^8$ 碱基对（bp）。对从 G1 进入减数分裂的细胞，给出 (i) G1、(ii) 中期 I、(iii) 减数分裂 I 末每个细胞、(iv) 减数分裂每个产物中的染色体数目、染色单体数目与以 bp 计的 DNA 含量。
::: solution
按着丝粒计数染色体。

| 时期 | 染色体 | 染色单体 | DNA |
|---|---|---|---|
| G1 | 8 | 8 | $2C = 3.6\times10^8$ bp |
| 中期 I | 8（4 个二价体） | 16 | $4C = 7.2\times10^8$ bp |
| 减数分裂 I 末（每个细胞） | 4 | 8 | $2C = 3.6\times10^8$ bp |
| 减数分裂 II 的每个产物 | 4 | 4 | $1C = 1.8\times10^8$ bp |

染色体数目在减数分裂 I 减半；DNA 含量在每次分裂减半。减数分裂 I 末的细胞有单倍体的染色体数目，却有二倍体的 DNA 量。
:::

## 减数分裂解释孟德尔

萨顿与博韦里的洞见是，减数分裂的两个特征恰好对应孟德尔的两条定律。

::: proposition 孟德尔定律的减数分裂基础 {#prop-meiotic-basis}
1. **分离。** 杂合子 *Aa* 的两个等位基因位于一对同源体同一基因座上。因为同源体在后期 I 分离，每条的染色单体在后期 II 分离，减数分裂的每个产物恰好得到一个等位基因，一半产物得到 *A*。
2. **自由组合。** 对位于不同（非同源）染色体上的基因座，每个二价体在中期 I 纺锤体上的取向——哪条同源体朝向哪一极——是随机的，且与其他二价体的取向无关。因此 *A* 与 *B* 位于不同染色体的双重杂合子产生 *AB*、*Ab*、*aB*、*ab* 等比例的四种配子。
3. **染色体组合的数目。** 一个有 $n$ 对同源体的生物，在考虑交叉之前，其配子中母源与父源同源体可产生 $2^n$ 种不同组合，各概率 $(\tfrac12)^n$。
:::

::: proof
(1) 减数分裂的每个产物得到每对同源体的一条染色单体。一条同源体带 *A*、另一条带 *a*，则中期 I 的四条染色单体中两条带 *A*、两条带 *a*（交叉在染色单体之间交换片段，但不改变每个等位基因的拷贝数），所以每个产物以概率 $\tfrac12$ 得到 *A*。正确分离之所以有保障，是因为每次后期分离的两个产物各得一个伙伴。

(2) 若携带 A 基因座的二价体以 *A* 同源体朝向某一极的取向出现概率为 $\tfrac12$，而携带 B 的二价体独立取向，则到达该极的同源体四种组合等可能，各 $\tfrac12\cdot\tfrac12 = \tfrac14$。

(3) $n$ 个二价体独立取向，各有两种可能取向，每一极有 $2^n$ 种等可能组合。
:::

第 (2) 点解释了为什么位于*不同*染色体的基因座自由组合成立；同一染色体上的基因座一起传递，除非被交叉分开——这是 [[genetics/linkage-mapping]] 的主题。这一结论还以减数分裂正常为前提。罕见的**减数分裂驱动**系统违反均等分离：例如小家鼠的 *t*-单倍型，杂合雄鼠把它传给远超过 90 % 的后代。

直接的细胞学证据来自埃莉诺·卡罗斯（Eleanor Carothers）1913 年的工作。某种蝗虫有一对同源体明显**异型**——两个成员形状不同——且雄虫有一条未配对的 X 染色体。卡罗斯统计减数分裂 I 中该异型对相对于 X 的分离，两种取向出现次数相同：在显微镜下看到的染色体自由组合。

::: example 能产生多少种不同配子？ {#ex-gamete-number}
(a) 一个人（$n = 23$）一个配子中母源与父源染色体可有多少种组合（忽略交叉）？(b) 一个配子只含来自其父亲染色体的概率是多少？(c) 按此计数，一对夫妇可能产生多少种遗传上不同的合子？
::: solution
(a) $2^{23} = 8\,388\,608$，约 $8.4\times10^6$。

(b) $(\tfrac12)^{23} = 1.19\times10^{-7}$（严格说，男性中 X 与 Y 也作为一对分离，所以此计数适用于两性）。

(c) 每个亲本可产生 $2^{23}$ 种组合，所以两种配子类型的组合共 $2^{23}\times2^{23} = 2^{46} \approx 7.0\times10^{13}$。交叉使实际数目大得多：一次人的减数分裂平均约有 50 次交叉（女性多于男性），每次又可发生在许多位置。除同卵双胞胎外，从未有两个人基因组相同。
:::
:::

### 在四分体中观察分离

许多真菌中，一次减数分裂的四个产物留在一个囊——**子囊**——中，可以分别取出并培养。这种**四分体分析**直接展示分离。在出芽酵母酿酒酵母（*Saccharomyces cerevisiae*）中，对一个突变杂合的二倍体， 几乎每一个四分体都是每个等位基因各占两个孢子——**2 : 2 分离**，而不仅仅是平均如此。在面包霉脉孢菌（*Neurospora crassa*，由卡尔·林德格伦在 1930 年代、其后由比德尔与塔特姆研究，见 [[genetics/genes-and-mutation]]）中，产物按产生的先后排成一线，所以甚至能分辨两个等位基因是在第一次还是第二次减数分裂分离的——这一证据曾用于着丝粒作图。

::: example 四分体为何证明分离 {#ex-tetrads}
一个 *Aa* 杂合酵母二倍体被诱导形成孢子（sporulation），解剖 100 个子囊。(a) 若一个子囊的四个孢子只是从含等量 *A* 与 *a* 孢子的大池中独立抽取四次，恰好两个 *A* 两个 *a* 的子囊比例会是多少？(b) 实际上约 100/100 的子囊为 $2:2$。这说明减数分裂的什么？
::: solution
(a) 一个子囊中 *A* 孢子数将服从 $n = 4$、$p = \tfrac12$ 的二项分布：$P(2) = \binom42(\tfrac12)^4 = \tfrac6{16} = 0.375$。其余子囊将呈 $3:1$ 或 $1:3$（共 $\tfrac8{16}$）或 $4:0$ 或 $0:4$（$\tfrac2{16}$）。

(b) 分离不只是群体水平上 $\tfrac12$ 的频率；它在每次减数分裂内部都是精确的。一条复制后的同源体带 *A* 的两个拷贝，另一条带 *a* 的两个拷贝；两次分裂把这四条染色单体一一分配到每个产物。罕见的 $3:1$ 子囊确实存在，是**基因转换**——双链断裂修复过程中序列的非相互转移——的标志，见 [[molecular-biology]]。
:::
:::

## 性染色体与性别决定

1905 年，内蒂·史蒂文斯（Nettie Stevens）用黄粉虫 *Tenebrio molitor*（黄粉虫）研究，埃德蒙·威尔逊（Edmund Wilson）用真蝽类（半翅目 Hemiptera）研究，各自独立发现雌雄染色体可以不同。黄粉虫中雌虫有 20 条大染色体，而雄虫有 19 条大染色体和一条小染色体；一半精子带这条小染色体（今称 Y），一半带一条 X。性别于是在受精时由精子决定——这是特定染色体与特定性状之间第一个清楚的联系。

::: definition 性别决定系统 {#def-sex-systems}
- **XX/XY**：雌性有两条 X 染色体，为**同配性别**（所有卵都带 X）；雄性有 X 与 Y，为**异配性别**。哺乳类、黑腹果蝇（*Drosophila*）、许多植物（如白麦瓶草 *Silene latifolia*）。
- **XX/XO**：雌性 XX，雄性只有一条 X、无 Y。许多蝗虫，以及秀丽隐杆线虫（*C. elegans*，XX 雌雄同体，XO 雄虫）。
- **ZZ/ZW**：雌性异配（ZW），雄性同配（ZZ）。鸟类、蝶与蛾、许多蛇类。
- **单倍二倍性**：雄由未受精卵发育，为单倍体；雌由受精卵发育，为二倍体。蚁、蜂与胡蜂（膜翅目 Hymenoptera），以及一些螨与甲虫。
- **环境性别决定**：性别在发育中由环境设定，例如许多龟类与全部鳄类的卵孵化温度。
:::

::: proposition $1 : 1$ 性别比 {#prop-sex-ratio}
在 XX/XY（或 ZZ/ZW）系统中，若分离正常、带 X 与带 Y 精子受精能力相等、两性存活相等，则后代为雄为女各概率 $\tfrac12$，且各次受孕相互独立。
:::

::: proof
杂交是 XX × XY。雌性只产生 X 卵；雄性由 X–Y 对在减数分裂中像一对同源体一样分离，产生等比例的 X 与 Y 精子。随机结合给 XX 与 XY 各概率 $\tfrac12$，与 *aa* × *Aa* 完全一样。
:::

出生时的实际性别比略偏离 $1:1$——人约 105 男对 100 女——因为发育中假设并非严格满足。使性别比保持在 $1:1$ 附近的群体力量（费希尔原理）在 [[evolution]] 中讨论。

### X 与 Y 如何决定性别的

染色体差异与性别相关，并没有告诉我们它*如何*决定性别，而且答案在不同类群中不同。

在**哺乳类**中，雄性由 Y 染色体的存在决定，不论 X 的数目：染色体组成为 XXY 的人发育为男性，只有一条 X 而无 Y（XO）的发育为女性（[[genetics/chromosome-mutations]]）。Y 上的关键基因是 *SRY*（Y 染色体性别决定区），由安德鲁·辛克莱（Andrew Sinclair）、彼得·古德费洛（Peter Goodfellow）、罗宾·洛夫尔-巴奇（Robin Lovell-Badge）及同事于 1990 年鉴定。1991 年约翰·库普曼（John Koopman）及同事证明携带小鼠 *Sry* 基因转基因的 XX 小鼠发育为雄性。*SRY* 编码一个转录因子，在胚胎生殖腺的支持细胞中起作用，开启相关基因 *SOX9*，指导生殖腺发育为睾丸；睾丸继而产生使身体其余部分雄性化的激素。

在***Drosophila***（果蝇）中，Y 染色体是雄性生育力所必需，而非雄性身份所必需：XO 蝇是不育的雄蝇，XXY 蝇是可育的雌蝇。卡尔文·布里吉斯（Calvin Bridges，1921）研究了 X 染色体数目与常染色体组数不寻常的果蝇，得出结论：性别取决于 X 染色体对常染色体组的比率（X : A）：1.0 及以上为雌性，0.5 及以下为雄性，中间比率为中间性。分子水平上，早期胚胎评估几个 X 连锁"分子"基因的剂量；双份剂量开启 *Sex-lethal*（*Sxl*）基因，其蛋白控制一系列 RNA 剪接决定的级联，通向雌性发育。自 2000 年代以来，常染色体是否贡献可测量的"分母"受到质疑；清楚起作用的是 X 剂量。

鸟类的 **Z 与 W** 染色体与哺乳类的 X 与 Y 没有亲缘关系；它们由另一对常染色体演化而来。在鸡中，性别似乎取决于 Z 连锁基因 *DMRT1* 的剂量（雄性两份），而非显性的雌性决定 W 基因。性染色体已独立演化多次，这就是它们的行为在不同类群间差异如此之大的原因。

::: example 家庭与单倍二倍体 {#ex-sex-families}
(a) 一个 XX/XY 性别决定、性别比 $1 : 1$ 的物种中，五口之家所有孩子同一性别的概率是多少？(b) 一只 *Aa* 杂合的蜂王与一只携带 *A* 的雄蜂（drone）交配一次。她的女儿与儿子各有什么基因型，比例如何？
::: solution
(a) $P(\text{全女}) = P(\text{全男}) = (\tfrac12)^5 = \tfrac1{32}$，所以 $P(\text{同一性别}) = \tfrac2{32} = \tfrac1{16} = 0.0625$。

(b) 女儿由受精卵发育：每个从单倍体父亲得到 *A*（其精子全都相同，因为单倍体雄性的精子不发生减数分裂），从母亲得到 *A* 或 *a*：*AA* : *Aa* = $1:1$。儿子由未受精卵发育，只得到母亲的等位基因：*A* : *a* = $1:1$，且为半合子。
:::
:::

::: application 农业与保护中的性别鉴定与性染色体
了解性别决定系统有实用价值。因为鸟类是 ZZ/ZW，许多物种雏鸟的性别可以由 DNA 检测 W 连锁序列来确定——这对鹦鹉、鹤等雌雄外貌相同的鸟类的保护繁育很重要。家禽业中，Z 连锁的羽色与羽毛生长基因用于给一日龄雏鸡鉴雌雄，这一技术基于 [[genetics/sex-linkage-pedigrees]] 的性连锁遗传。对温度依赖性别的龟类，巢温对保护至关重要：变暖可产生强烈偏雌的孵化群体。
:::

::: history
奥斯卡·赫特维希（Oscar Hertwig，1876）证明海胆的受精涉及卵核与精子核的融合，爱德华·范贝内登（Edouard Van Beneden，1883）在线虫 *Parascaris*（当时称 *Ascaris*，蛔虫）中发现卵与精子各贡献相等、减半的染色体数目；奥古斯特·魏斯曼（August Weismann）在 1887 年论证每一代都必须有一次减数分裂。西奥多·博韦里（Theodor Boveri）用两个精子受精的海胆卵做的实验（1902）表明正常发育需要完整的一套染色体，且每条性质不同。研究蝗虫 *Brachystola magna* 的研究生沃尔特·萨顿（Walter Sutton）发表了 *On the morphology of the chromosome group in Brachystola magna*（1902）与 *The chromosomes in heredity*（1903），陈述了染色体与孟德尔因子之间的平行。克拉伦斯·麦克朗（Clarence McClung，1901–02）提出一条"副染色体"参与性别决定，内蒂·史蒂文斯（Nettie Stevens）与埃德蒙·威尔逊（Edmund Wilson）在 1905 年确立了 XY 与 XO 系统。埃莉诺·卡罗斯（Eleanor Carothers）在 1913 年观察到染色体的自由组合。联会复合体由蒙特罗斯·莫西（Montrose Moses）于 1956 年在螯虾精母细胞中首次描述，*SRY* 在 1990 年被鉴定。
:::

::: summary
- 染色体携带基因；二倍体有两套同源染色体组（$2n$），配子一套（$n$）。区分染色体数目（着丝粒）与 DNA 含量（C 值）。
- 减数分裂是一次复制接着两次分裂。减数分裂 I 中同源体配对（联会复合体）、在四分体时期交叉、单向定向并分离；减数分裂 II 中姐妹染色单体分离。产生四个单倍体产物。
- 交叉把同源体拉到一起直到后期 I；多数生物每个二价体需要一次必备交叉才能精确分离。
- 同源体的分离解释孟德尔第一定律；不同二价体的独立取向解释不同染色体上基因座的自由组合，每个配子 $2^n$ 种染色体组合。
- 真菌的四分体分析显示每次单独的减数分裂内部 $2:2$ 分离。
- 性别由 XX/XY、XX/XO、ZZ/ZW、单倍二倍或环境系统决定。哺乳类 Y 上的 *SRY* 触发睾丸发育；果蝇中经由 *Sxl* 读取的 X 剂量决定性别。
:::

## 练习

::: exercise 配子组合 {level=1 check="128"}
豌豆（$2n = 14$）一个配子中父源与母源染色体可有多少种不同组合（忽略交叉）？
::: solution
$n = 7$，所以 $2^7 = 128$。
:::
:::

::: exercise 中期 I 的染色单体 {level=1 check="92"}
人的初级精母细胞在中期 I 有多少条染色单体？
::: solution
细胞有 46 条染色体，每条已复制为两条染色单体：$46\times2 = 92$ 条染色单体，排成 23 个二价体（22 个常染色体二价体与 X–Y 对）。
:::
:::

::: exercise 有丝分裂还是减数分裂？ {level=1}
对每个陈述，说出它适用于有丝分裂、减数分裂 I、减数分裂 II，还是其中多个：(a) 姐妹染色单体分离；(b) 同源体配对；(c) 产物与母细胞染色体数目相同；(d) 存在交叉。
::: solution
(a) 有丝分裂与减数分裂 II。(b) 仅减数分裂 I。(c) 有丝分裂与减数分裂 II（减数分裂 II 以 $n$ 条染色体开始并以 $n$ 结束；它分开的是染色单体，不是同源体）。(d) 仅减数分裂 I（前期 I 至中期 I）。
:::
:::

::: exercise 单倍体计数 {level=2 check="1/16"}
一个生物 $2n = 8$。忽略交叉，它的某个配子只含来自其母亲染色体的概率是多少？
::: solution
$n = 4$ 个二价体各自独立取向，所以 $(\tfrac12)^4 = \tfrac1{16}$。
:::
:::

::: exercise DNA 含量 {level=2 check="4"}
一个细胞周期 G1 期的植物细胞有 8 pg DNA。由它产生的减数分裂 II 的每个产物有多少 DNA（pg）？
::: solution
G1 的二倍体细胞尚未复制，所以 $2C = 8$ pg，$C = 4$ pg。S 期后为 $4C = 16$ pg；减数分裂 I 后每个细胞 $2C = 8$ pg；减数分裂 II 的每个产物 $1C = 4$ pg。（把 8 pg 当作复制后的量 $4C$ 的同学会得 2 pg：要看清时期，因为 G1 在复制之前。）
:::
:::

::: exercise 蜜蜂的亲缘度 {level=2 check="3/4"}
一个蜂后只与一只雄蜂（drone）交配过。在某个基因座上随机选工人蜂的两个等位基因之一。她的同父同母姐妹携带从同一亲本传来的同一个等位基因拷贝（血缘同源相同）的概率是多少？
::: hint
以概率 $\tfrac12$ 选父源等位基因，以概率 $\tfrac12$ 选母源等位基因。
:::
::: solution
若所选的是父源等位基因（概率 $\tfrac12$），姐妹必有同一等位基因，因为单倍体父亲给所有女儿相同的基因组。若是母源的（$\tfrac12$），姐妹以概率 $\tfrac12$ 得到同一母源等位基因。总计 $\tfrac12\cdot1 + \tfrac12\cdot\tfrac12 = \tfrac34$，二倍体物种中同父母兄妹之间为 $\tfrac12$。姐妹之间这一高亲缘度是膜翅目工人阶级多次演化经典解释（存在争论）的一部分，见 [[behaviour]]。
:::
:::

::: exercise 核型中的染色体 {level=2}
一位细胞学家检查一新昆虫种雌性有丝分裂中期的细胞，看到 13 条染色体；雄性也显示 13 条，但雄性中有一对由两条大小明显不同的染色体组成，而雌性中所有染色体都能配对。(a) 这一描述有什么蹊跷？(b) 猜想该物种属于哪种性别决定系统，以及什么进一步观察可以证实。
::: solution
(a) 每条染色体都有配对的二倍体其染色体数目必为偶数；13 条在雌性不可能全部配对。要么漏数了一条，要么染色体重叠（压片中常见），要么该物种不是简单的二倍体。细胞学家应检查更多细胞。

(b) 若真实数目是两性别均为 14、仅雄性有一对异型，则为 XX/XY、雄性异配。证实：在雄性减数分裂中异型对应形成二价体并分离，所以一半次级精母细胞带大的、一半带小的那条染色体；雌性应显示一对同型。反之，若异型对出现在雌性，则为 ZZ/ZW 系统。
:::
:::

::: exercise 卡罗斯的检验 {level=3}
在卡罗斯研究的雄蝗虫中，单条 X 染色体（无 Y）在后期 I 移向一极，一对常染色体异型（成员 *L* 与 *S*，形状不同）。(a) 若染色体独立组合，次级精母细胞中应有多大比例同时含 X 与 *L*？(b) 设统计了含 X 的细胞 154 个，其中 79 个有 *L*、75 个有 *S*。检验独立组合假说。(c) 既然遗传杂交已经显示自由组合，这个实验为何重要？
::: solution
(a) 一半次级精母细胞含 X；这些之中，若该对的取向与 X 无关，一半含 *L*。所以全部次级精母细胞的 $\tfrac14$，即含 X 者的 $\tfrac12$。

(b) 在含 X 的细胞中预期 $77 : 77$。$X^2 = \dfrac{2^2}{77} + \dfrac{2^2}{77} = 0.104$，$\nu = 1$，$p = 0.75$。与自由组合一致。

(c) 杂交实验显示*基因*自由组合；这个实验显示*染色体*也以同样比例如此。这是对萨顿与博韦里所主张平行的直接物理证据，因而通向了染色体学说——最终以性连锁中特定基因与特定染色体的相关一锤定音。
:::
:::

::: exercise 必备交叉与分离 {level=3}
一个消灭交叉但仍允许同源体配对的酵母突变体中，许多孢子不能存活。(a) 解释原因。(b) 在存活孢子中，同一染色体臂上两个基因的等位基因会重组吗？(c) 果蝇雄性没有交叉却精确分离其染色体。它们一定有什么是酵母突变体所缺的？
::: solution
(a) 没有交叉，联会复合体解体后同源体便不被拉住。两条同源体于是在后期 I 可自由移向同一极（**不分离**），产生缺失某染色体的孢子；缺必需染色体的孢子不能存活。

(b) 不会：存活孢子中每条染色体完整地属于一个亲本类型（罕见的非交叉基因转换事件除外），所以同一染色体上的等位基因保持亲本组合。

(c) 一种不依赖交叉的替代配对机制，把同源体拉住直到后期 I：果蝇雄性中，特异蛋白质把同源体绑在一起（并在 rDNA 区的重复序列处把 X 与 Y 绑在一起），代替交叉点的作用。
:::
