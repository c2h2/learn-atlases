子女像父母，却不完全相同，兄弟姐妹之间也彼此有别。1900 年以前，多数博物学家用**融合遗传**来解释这一现象：认为双亲的遗传物质像两种颜料一样混合，子女因而介于两者之间。融合遗传有一个致命缺陷。若它为真，变异每一代减半，群体在几代之内就会变得均一，而在子代中消失的性状永远不可能在孙代中重现。然而性状确实会隔代出现，群体也始终保持变异。

答案由孟德尔（Gregor Mendel）——布尔诺（Brno）的一位奥斯定会修道士——在 1850 与 1860 年代通过杂交豌豆、并且——这是新颖之处——**计数**每一类后代而找到。他从比例推论：遗传由离散的颗粒携带，颗粒成对存在，在配子形成时干净地分离，并在受精时随机重新结合。本章建立孟德尔的两条定律、现代遗传学的词汇、使定律具有预测力的概率论，以及判断计数后代是否符合预期比例的 χ² 检验。本课程其后的一切——显性关系、染色体、连锁、系谱——都建立在这些基础之上。

## 孟德尔的实验系统

孟德尔选择豌豆 *Pisum sativum*（豌豆）理由充分。豌豆易于栽培，种商处可得许多品种。它们的花通常**自花授粉**（花粉在花开放之前使同一朵花的胚珠受精），但可以人工杂交：除去未成熟花的花药，再把另一株的花粉刷到其柱头上。最重要的是，孟德尔先花了两年确保他的品种**纯系**（true-breeding）——自花授粉的后代在所研究的性状上世代与自己完全相同。

随后他选了七个性状，每个性状有两个明显不同的类型：种子形状（圆滑或皱缩）、子叶颜色（黄色或绿色）、花色（紫色或白色）、豆荚形状（饱满或缢缩）、未熟豆荚颜色（绿色或黄色）、花的位置（腋生或顶生）、茎高（高茎或矮茎）。界限分明、非此即彼的性状意味着每株植物都能被明确归类，计数成为可能。

::: definition 杂交的世代 {#def-generations}
在遗传杂交中，亲本为 **P 代**。它们的子代是**子一代**，**F1**。F1 个体相互杂交（豌豆中则自花授粉）得 **F2**，依此类推。亲本在一个性状上不同的杂交是**单杂交**；在两个性状上不同的亲本之间的杂交是**双杂交**。**互交**互换亲本的性别（♀ 圆滑 × ♂ 皱缩，与 ♀ 皱缩 × ♂ 圆滑）。
:::

当孟德尔把纯系圆粒品系与纯系皱粒品系杂交，无论哪个亲本提供花粉，F1 的每一粒种子都是圆滑的。皱缩消失了。但当 F1 植株自花授粉，皱缩类型在 F2 中重新出现：圆滑 5474 粒，皱缩 1850 粒，比例 2.96 : 1。其余六个性状表现相同：一种类型（孟德尔称为**显性**）单独出现在 F1，另一种（**隐性**）在约四分之一的 F2 中重现。

| 性状 | 显性 | 隐性 | F2 显性 | F2 隐性 | 比例 |
|---|---|---|---|---|---|
| 种子形状 | 圆滑 | 皱缩 | 5474 | 1850 | 2.96 : 1 |
| 子叶颜色 | 黄色 | 绿色 | 6022 | 2001 | 3.01 : 1 |
| 花色 | 紫色 | 白色 | 705 | 224 | 3.15 : 1 |
| 豆荚形状 | 饱满 | 缢缩 | 882 | 299 | 2.95 : 1 |
| 豆荚颜色 | 绿色 | 黄色 | 428 | 152 | 2.82 : 1 |
| 花的位置 | 腋生 | 顶生 | 651 | 207 | 3.14 : 1 |
| 茎高 | 高茎 | 矮茎 | 787 | 277 | 2.84 : 1 |

需要解释的有三点：F1 的整齐一致、隐性类型在 F2 中不加改变地重现，以及每个实验中都徘徊在 3 : 1 附近的比值。

## 分离

孟德尔的解释，用现代语言说，如下。每株植物对每个性状携带两份遗传因子。两份可以相同，也可以不同。它们在配子形成时彼此**分离**（segregate），使每个配子只带一份，两份被选中的概率相等。受精随机结合两个配子，恢复成对状态。

::: definition 基本词汇 {#def-vocabulary}
- **基因**是影响性状的一个遗传单位；它在染色体上占据的位置是其**基因座**（位点，locus，复数 loci）。
- 一个基因的不同形式是其**等位基因**。
- 一个个体的**基因型**是它在所讨论基因座上的等位基因组成；其**表型**是可观察的性状。
- 二倍体在一个基因座上有两个相同等位基因者为**纯合**（*RR* 或 *rr*），有两个不同等位基因者为**杂合**（*Rr*）。杂合子也称为**杂种**，就单个基因座而言称**单杂种**。
- 若杂合子与该等位基因的纯合子表型相同，则此等位基因为**显性**；若其效应只在纯合状态可见，则为**隐性**。
:::

基因符号用斜体书写。按本章采用的经典教科书惯例，显性等位基因用大写字母，隐性等位基因用同一字母的小写：*R*（圆滑）与 *r*（皱缩）。"基因"一词常同时指基因座和某个特定等位基因（"皱粒基因"）；语境通常使含义清楚。不同生物有自己的书写惯例，随出现处介绍：黑腹果蝇（*Drosophila*）的等位基因按突变表型命名，野生型加上标加号（*w* 白眼，*w*$^+$ 红眼）；人的基因用斜体大写（*CFTR*），其蛋白质产物用正体（CFTR）。

::: proposition 孟德尔第一定律（分离定律） {#prop-segregation}
在二倍体中，一个基因座上的两个等位基因在配子形成期分离，每个配子各得其一；杂合子 *Aa* 产生 *A* 与 *a* 配子的概率各为 $\tfrac12$。若配子随机结合，杂交 *Aa* × *Aa* 的子代基因型为

$$
AA : Aa : aa = \tfrac14 : \tfrac12 : \tfrac14 ,
$$ {#eq-121}

若 *A* 显性，表型比为 $3 : 1$。

假设：均等分离（无减数分裂驱动）、各类配子的受精能力与存活相同、配子随机结合、各基因型至统计时点存活率相同。
:::

::: proof
设卵细胞携带的等位基因为 $X$，精子（花粉）携带的为 $Y$。由分离，$P(X = A) = P(X = a) = \tfrac12$，对 $Y$ 同样；由随机结合，$X$ 与 $Y$ 独立。于是

$$
\begin{aligned}
P(AA) &= P(X=A)\,P(Y=A) = \tfrac12\cdot\tfrac12 = \tfrac14,\\
P(aa) &= P(X=a)\,P(Y=a) = \tfrac14,\\
P(Aa) &= P(X=A)P(Y=a) + P(X=a)P(Y=A) = \tfrac14 + \tfrac14 = \tfrac12 ,
\end{aligned}
$$

其中杂合子由两种互斥途径产生。*A* 显性时，表型为显性的概率是 $\tfrac14 + \tfrac12 = \tfrac34$，为隐性的概率是 $\tfrac14$。
:::

**棋盘格（Punnett 方格）**由雷金纳尔德·庞尼特（Reginald Punnett）于 1900 年代初引入，正是这一计算的记账工具：一个亲本的配子标记行，另一个亲本的配子标记列，每格是一个合子，其概率为行概率与列概率之积。

| | *R* ($\tfrac12$) | *r* ($\tfrac12$) |
|---|---|---|
| ***R*** ($\tfrac12$) | *RR* ($\tfrac14$) 圆滑 | *Rr* ($\tfrac14$) 圆滑 |
| ***r*** ($\tfrac12$) | *Rr* ($\tfrac14$) 圆滑 | *rr* ($\tfrac14$) 皱缩 |

这一方案解释了全部三点观察。P 代品系是 *RR* 与 *rr*；F1 全为 *Rr*，因 *R* 显性而圆滑。隐性等位基因经过杂合子时未被改变，所以 *rr* 植株在 F2 重现。至于比值 $3:1$，由于[[#eq-121]]。

孟德尔豌豆的性状如今已在分子水平得到理解。种子性状的 *r* 等位基因在编码淀粉分支酶 I 的基因中带有约 0.8 kb 类转座子 DNA 的插入（Madan Bhattacharyya 及同事，1990）。缺乏此酶时，*rr* 种子合成的支链淀粉较少并积累蔗糖；发育时吸收更多水分，干燥时皱缩。*Rr* 中一个功能拷贝即足以进行正常淀粉合成，这就是 *R* 显性的原因——只丧失功能的等位基因的常见情形。

::: warning "显性"不意味着"常见"、"更强"或"更好"
显性描述的是杂合子的表型，仅此而已。它不涉及一个等位基因在群体中的频率，也不涉及它是否有利。人多指症的显性等位基因是罕见的；O 型血的隐性等位基因在许多群体中是 *ABO* 最常见的等位基因。显性等位基因也不会"压制"或"转变"隐性等位基因：在 *Rr* 中两个等位基因都在，并被原样传递。等位基因频率是 [[population-genetics/hardy-weinberg]] 的主题，在那里我们将看到显性本身并不能使一个等位基因扩散。
:::

### 检验分离：杂种后代测验与测交

假说预言的不只是 $3:1$ 表型比。它还预言 F2 圆粒植株有两类，*RR* 与 *Rr*，比例 $1:2$。孟德尔让 F2 植株自花授粉并对后代分类来检验这一点。565 株圆粒 F2 中，193 株只产生圆粒种子（纯系，*RR*），372 株产生圆粒与皱粒之比 $3:1$ 的后代（*Rr*）——比值 1 : 1.93。

::: proposition F2 中的条件基因型概率 {#prop-two-thirds}
在 *Aa* × *Aa* 的 F2 中，已知表型为显性的个体是杂合子的概率为 $\tfrac23$，是 *AA* 纯合子的概率为 $\tfrac13$。
:::

::: proof
由条件概率的定义与[[#eq-121]]，

$$
P(Aa \mid \text{显性}) = \frac{P(Aa)}{P(AA) + P(Aa)} = \frac{1/2}{1/4 + 1/2} = \frac23 .
$$
:::

这条"三分之二规则"是人色系谱分析（[[genetics/sex-linkage-pedigrees]]）中最常用的结果之一：双亲均为携带者时，患者健康的兄弟姐妹是携带者的概率是 $\tfrac23$，而不是 $\tfrac12$。

更快的基因型检验是**测交**：让未知基因型的个体与隐性纯合子杂交。因为 *aa* 亲本只提供 *a* 配子，后代的表型直接揭示被测亲本的配子：*AA* × *aa* 得全部显性后代，*Aa* × *aa* 得显性与隐性 $1:1$。F1 与任一亲本回交的杂交称为**回交**；测交是对隐性亲本的回交。

::: quiz
一只黑毛豚鼠与一只白毛豚鼠（白色为隐性）交配，产下一窝四只黑毛仔鼠。我们能得出什么结论？
- [ ] 黑毛亲本肯定是纯合子。
- [x] 黑毛亲本很可能是纯合子，但不能肯定。
- [ ] 黑毛亲本是杂合子。
- [ ] 什么都得不出，因为这窝仔鼠太少，看不到 3 : 1 的比例。
::: solution
若黑毛亲本是杂合子，每只仔鼠为黑毛的概率是 $\tfrac12$，四只全黑出现的概率是 $(\tfrac12)^4 = \tfrac1{16} \approx 0.06$。这一结果不太可能但完全可能发生，所以证据支持纯合但并未证明。反过来，只要出现一只白毛仔鼠就能证明杂合。杂合子测交的预期比例是 $1:1$，不是 $3:1$。
:::
:::

## 自由组合

孟德尔接着杂交在两个性状上不同的植株。纯系圆粒黄子叶（*RR YY*）与皱粒绿子叶（*rr yy*）杂交得圆粒黄子叶 F1（*Rr Yy*）。556 粒 F2 种子中，他数得圆黄 315、圆绿 108、皱黄 101、皱绿 32——接近 $9:3:3:1$。其中圆绿与皱黄两类是**重组型**：它们组合了原本分属不同亲本的性状。

::: proposition 孟德尔第二定律（自由组合定律） {#prop-assortment}
不同基因座上的等位基因在配子形成期彼此独立地分离。因此双重杂合子 *Aa Bb* 产生 *AB*、*Ab*、*aB*、*ab* 四种配子，概率各为 $\tfrac14$；杂交 *Aa Bb* × *Aa Bb*（*A* 与 *B* 显性）的表型为

$$
A\text{-}B\text{-} : A\text{-}bb : aaB\text{-} : aabb = 9 : 3 : 3 : 1 ,
$$ {#eq-9331}

其中 *A-* 表示"*AA* 或 *Aa*"。假设：每个基因座处如[[#prop-segregation]]所述，加上两个基因座相互独立。如我们将在 [[genetics/linkage-mapping]] 中看到的，这一定律对位于不同染色体上的基因座和同一染色体上相距很远的基因座成立，但对同一染色体上邻近的基因座不成立。
:::

::: proof
由独立性，双基因座配子的概率是单基因座概率之积，四种类型各具 $\tfrac12\cdot\tfrac12 = \tfrac14$。F2 中两个基因座的基因型于是相互独立，各自遵循[[#eq-121]]。基因座 A 表型为显性的概率是 $\tfrac34$，基因座 B 为 $\tfrac34$，所以

$$
P(A\text{-}B\text{-}) = \tfrac34\cdot\tfrac34 = \tfrac{9}{16},\quad
P(A\text{-}bb) = \tfrac34\cdot\tfrac14 = \tfrac{3}{16},\quad
P(aaB\text{-}) = \tfrac{3}{16},\quad
P(aabb) = \tfrac{1}{16}.
$$
:::

注意证明*没有*需要什么：一张 16 格的棋盘格。$4\times4$ 方格对两个基因座可行，但三个基因座要 64 格，四个要 256 格。乘法法则把任何多基因座问题化为一组单基因座问题。

::: intuition 自由组合如同两枚硬币
把双重杂合子的配子想象为同时抛两枚均匀硬币的结果，每个基因座一枚：正面给出大写字母等位基因，反面给出小写的。若两枚硬币独立，四种结果等概率，四种配子类型也就等概率。双杂交的棋盘格于是就是四枚硬币——每亲本两枚——的结果表。连锁，本课程后面会讲，就是两枚硬币被粘在一起、偶尔才分开的情况。
:::

## 遗传学中的概率

孟德尔定律是概率陈述，几乎每一个遗传计算都使用同样的三条法则。

::: definition 遗传学使用的概率法则 {#def-prob-rules}
- **乘法法则。** 若事件 $E$ 与 $F$ 独立，$P(E \text{ 且 } F) = P(E)\,P(F)$。不同未连锁基因座上的分离、两个亲本各自的配子、同一对父母的每个孩子，都是独立的。
- **加法法则。** 若 $E$ 与 $F$ 互斥，$P(E \text{ 或 } F) = P(E) + P(F)$。
- **条件概率。** $P(E \mid F) = P(E \text{ 且 } F)/P(F)$，即已知 $F$ 已发生时 $E$ 的概率。

对 $n$ 个独立后代的家庭，每个后代为某一类型的概率为 $p$，该类型的数目 $X$ 服从**二项分布**

$$
P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \dots, n .
$$ {#eq-binomial}
:::

二项系数 $\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}$ 计数 $k$ 个一种类型与 $n-k$ 个另一种类型后代的出生次序数目。这些法则在[数学图谱](/learn/maths/)与 [[biostatistics]] 中有完整展开；这里直接使用。

::: example 用分枝法解三因子杂交 {#ex-trihybrid}
考虑 *Aa Bb Cc* × *Aa Bb Cc*，三个基因座均未连锁，*A*、*B*、*C* 显性。(a) 子代中同时表现三个显性性状的比例是多少？(b) *Aa bb Cc* 的比例是多少？(c) 可能有多少种基因型、多少种表型？
::: solution
(a) 每个基因座独立地以概率 $\tfrac34$ 给出显性表型，所以 $P(A\text{-}B\text{-}C\text{-}) = (\tfrac34)^3 = \tfrac{27}{64} \approx 0.42$。

(b) $P(Aa) = \tfrac12$，$P(bb) = \tfrac14$，$P(Cc) = \tfrac12$，所以 $P(Aa\,bb\,Cc) = \tfrac12\cdot\tfrac14\cdot\tfrac12 = \tfrac1{16}$。

(c) 每个基因座有三种基因型（*AA*、*Aa*、*aa*）与两种表型，所以有 $3^3 = 27$ 种基因型与 $2^3 = 8$ 种表型。一般地，$n$ 个未连锁杂合基因座给 $2^n$ 种配子类型、$3^n$ 种基因型、$2^n$ 种表型（完全显性）以及棋盘格中 $4^n$ 个格；表型比是 $(3+1)^n$ 展开的各项——$n=3$ 时为 $27:9:9:9:3:3:3:1$。
:::
:::

::: example 两个携带者的孩子 {#ex-family}
囊性纤维化按常染色体隐性性状遗传，由基因 *CFTR* 的功能丧失等位基因引起。两个表型正常、均为杂合携带者的父母有四个孩子。(a) 恰好一个孩子患病的概率是多少？(b) 至少一个患病？(c) 前两个正常、后两个患病？
::: solution
每个孩子独立地以概率 $p = \tfrac14$ 患病。

(a) 由[[#eq-binomial]]，$P(X=1) = \binom41 (\tfrac14)(\tfrac34)^3 = 4\cdot\tfrac{27}{256} = \tfrac{108}{256} \approx 0.422$。

(b) $P(X \ge 1) = 1 - P(X = 0) = 1 - (\tfrac34)^4 = 1 - \tfrac{81}{256} = \tfrac{175}{256} \approx 0.684$。

(c) 指定顺序没有二项系数：$(\tfrac34)^2(\tfrac14)^2 = \tfrac{9}{256} \approx 0.035$。

$\tfrac14$ 独立地适用于*每个*孩子：已有一个患病孩子并不会使下一个患病的可能性变小——随机过程没有记忆。（这是教科书式的概率计算，不是临床建议；囊性纤维化的医学遗传学见[医学图谱](/learn/medicine/lesson.php?c=genetics&l=mendelian-inheritance)。）
:::
:::

::: widget distribution

b: 2

::: warning "三比一"是概率，不是配额
$3:1$ 的比例并不意味着每四个后代中恰好三个表现显性性状，也不意味着三个显性后代之后第四个"必定"是隐性。它是关于每个孩子各自独立的概率的陈述。小家庭和小样本常大幅偏离预期；只有大样本才接近该比例，即便如此也从不精确——孟德尔自己的比例就在 2.82 到 3.15 之间。要判断偏离是否大到不能归因于机会，我们需要统计检验。
:::

## 检验比例：χ² 适合度检验

孟德尔的 315 : 108 : 101 : 32 并不恰好是 $9:3:3:1$；也不可能恰好，因为 $556$ 不能被 16 整除。多大的差异应使我们怀疑假说？标准工具是卡尔·皮尔逊（Karl Pearson）（1900）提出的 χ² 适合度检验。

::: definition χ² 适合度统计量 {#def-chisq}
设 $n$ 个个体分为 $k$ 类，观察计数为 $O_1, \dots, O_k$，假说 $H_0$ 预言各类概率 $\pi_1, \dots, \pi_k$，从而有**期望计数** $E_i = n\pi_i$。统计量

$$
X^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}
$$ {#eq-chisq}

度量总体偏离。若 $H_0$ 为真且期望计数不太小（常用规则：每个 $E_i \ge 5$），$X^2$ 近似服从自由度 $\nu = k - 1$ 的 **χ² 分布**；因计数被约束为和为 $n$，自由度比类别数少一。**P 值**是 $H_0$ 之下出现至少与观察值一样大的 $X^2$ 的概率。
:::

使用偏差的平方是为了让正负偏差不互相抵消；除以 $E_i$ 是对每一项定标，因为偏差 10 在期望 30 的一类中比在期望 3000 的一类中更重要。（每一项近似为一个标准正态偏差的平方，$\nu$ 个这样的平方和服从自由度 $\nu$ 的 χ² 分布。）

::: algorithm χ² 适合度检验 {#alg-chisq}
1. 陈述遗传假说 $H_0$ 及其预言的类别概率。
2. 由总数 $n$ 计算期望计数 $E_i = n\pi_i$（绝不用百分比计算）。检查期望计数不太小；必要时合并类别。
3. 由[[#eq-chisq]]计算 $X^2$，自由度 $\nu = k - 1$（每从数据估计一个参数再减一）。
4. 求 P 值 $P(\chi^2_\nu \ge X^2)$，或把 $X^2$ 与所选显著性水平 $\alpha$（通常 0.05）的临界值比较：$\nu = 1$ 为 3.841，$\nu=2$ 为 5.991，$\nu = 3$ 为 7.815，$\nu = 4$ 为 9.488。
5. 若 $p < \alpha$，拒绝 $H_0$；否则结论是数据与 $H_0$ 一致——这与证明 $H_0$ 不同。
:::

::: example 孟德尔的双因子数据 {#ex-chisq-mendel}
检验孟德尔的计数——圆黄 315、圆绿 108、皱黄 101、皱绿 32——是否符合 $9:3:3:1$。
::: solution
$n = 556$，期望计数为 $556\times\tfrac9{16} = 312.75$，$556\times\tfrac3{16} = 104.25$（两次）与 $556\times\tfrac1{16} = 34.75$。于是

$$
X^2 = \frac{(315-312.75)^2}{312.75} + \frac{(108-104.25)^2}{104.25} + \frac{(101-104.25)^2}{104.25} + \frac{(32-34.75)^2}{34.75}
= 0.016 + 0.135 + 0.101 + 0.218 = 0.470 .
$$

$k = 4$ 类，$\nu = 3$。$\alpha = 0.05$ 的临界值是 7.815，远高于 0.470；精确 P 值为 $P(\chi^2_3 \ge 0.470) = 0.925$。如此大或更大的偏差在约 93 % 的此类实验中会仅由机会出现，所以数据与自由组合符合得非常好。
:::
:::

::: widget distribution

a: 7.815
b: 20
caption: 自由度为 $k$ 的 χ² 分布。$k = 3$（对应 $9:3:3:1$ 这类四类别比例）时，7.815 之外的阴影上尾面积为 0.05：落在此区域的 $X^2$ 值在 5 % 水平导致拒绝。孟德尔双杂交的值 0.470 位于很靠左、面积最大的地方。把 $k$ 改为 1（对应 $3:1$ 或 $1:1$ 比例），看临界值移到 3.841。
:::

::: example 显著的偏离 {#ex-chisq-reject}
一位学生杂交两株双杂合植株，在四个表型类别（顺序同[[#eq-9331]]）记录到 220 : 90 : 85 : 45。检验对 $9:3:3:1$ 的符合度。
::: solution
$n = 440$，所以 $E = 247.5,\ 82.5,\ 82.5,\ 27.5$。$X^2$ 的各项为 $3.056,\ 0.682,\ 0.076,\ 11.136$，得 $X^2 = 14.95$，$\nu = 3$，$p = 0.0019$。我们在 5 %（实为 1 %）水平拒绝 $9:3:3:1$ 的假说。几乎全部偏差来自双重隐性类：45 株而非 27.5 株。可能的解释不是统计学的而是生物学的：两个基因座以相引相（coupling）连锁（亲本组合过剩，见 [[genetics/linkage-mapping]]）、分类错误、或存活差异。检验只告诉我们起作用的大概不是机会。
:::
:::

```python
# chi-squared goodness of fit in plain Python (scipy.stats.chisquare does the same)
from math import exp, lgamma, log

def chisq_sf(x, df):
    """Upper tail P(chi2_df >= x) by the series for the regularised gamma function."""
    s, z = df / 2, x / 2
    term = total = 1 / s
    n = 1
    while term > 1e-15 * total:
        term *= z / (s + n); total += term; n += 1
    return 1 - total * exp(-z + s * log(z) - lgamma(s))

obs = [315, 108, 101, 32]                     # counts in the four classes
ratio = [9, 3, 3, 1]
n = sum(obs)
exp_ = [n * r / sum(ratio) for r in ratio]    # 312.75, 104.25, 104.25, 34.75
x2 = sum((o - e) ** 2 / e for o, e in zip(obs, exp_))
print(round(x2, 3), round(chisq_sf(x2, len(obs) - 1), 3))   # 0.47 0.925
```

::: warning χ² 检验做不到的事
- **它不能证明假说。** 大 P 值只说明数据不与 $H_0$ 矛盾；其他假说可能拟合得同样好，小样本时尤其如此。
- **它必须用于计数，不能用于百分比或比例。** $X^2$ 随样本量增大：同样的比例偏差在 40 个后代中不显著，在 4000 个中可能高度显著。
- **期望计数不能太小。** 若干 $E_i < 5$ 时 χ² 近似很差；应合并类别或改用精确检验（二项或多项）。
- **显著的结果不能说明哪个解释正确。** 它只说 $H_0$ 之下偏差不太可能出现，而不说为什么。
:::

## 孟德尔定律的遭遇

孟德尔的论文在 34 年间几乎毫无影响。为数不多的读者把它当作植物杂交这一专门领域的贡献，而非遗传理论；其中的代数论证对当时的生物学来说异乎寻常；而且植物学家卡尔·内格利（Carl Nägeli）建议孟德尔后来研究的山柳菊（*Hieracium*）似乎与其相矛盾——我们现在知道许多山柳菊不经受精就结实（无融合生殖），其后代是克隆。1900 年，三位植物学家胡戈·德弗里斯（Hugo de Vries）、卡尔·科伦斯（Carl Correns）与埃里希·冯·切尔马克（Erich von Tschermak）在各自杂交中报告了分离比，并提请人们注意孟德尔的工作。威廉·贝特森（William Bateson）在英国为其鼓吹，与庞尼特和伊迪丝·桑德斯（Edith Saunders）一起表明它同样适用于动物，并为新科学命名为**遗传学**（1905 年在一封信中；1906 年公开）。丹麦植物学家威廉·约翰森（Wilhelm Johannsen）在 1909 年引入 gene（基因）、genotype（基因型）与 phenotype（表型）三个词。

::: history
格雷戈尔·孟德尔（Gregor Mendel）（1822–1884）于 1865 年 2 月 8 日与 3 月 8 日两次在布吕恩（今捷克布尔诺）自然科学学会报告其结果；论文 *Versuche über Pflanzen-Hybriden*（《植物杂交试验》）发表于该会 1865 年卷的 *Verhandlungen*（1866 年出版）。1936 年，统计学家罗纳德·费希尔（Ronald Fisher）重新分析孟德尔的数据，认为总体上看它们与预期比例的符合之好超出了机会通常允许的程度——总体 χ² 过小——并且其中一组实验的结果与孟德尔自己的程序本不应得到的比例吻合（[[#exr-fisher]]）。争论延续至今：孟德尔可能在比例看起来对了时就停止计数，或助手知道预期结果，或该分析夸大了问题。没有人怀疑孟德尔的结论正确；它们已被验证了千万次。
:::

::: application 纯系与杂种种子
植物育种者至今仍每天使用孟德尔的逻辑。自交使每代杂合基因座的比例减半，所以自交六、七代后品系几乎完全纯合并真实遗传——这是小麦、水稻、大豆与豌豆纯系品种的基础。反过来，两个自交系杂交得到遗传上整齐的 F1，这正是玉米和许多蔬菜的商业**杂种种子**每年必须重新购买的原因：用收获的种子种出的 F2 发生分离、参差不齐。F1 杂种为何常比双亲更健壮（杂种优势）在 [[population-genetics/inbreeding]] 中讨论。
:::

::: summary
- 遗传是颗粒性的：二倍体的基因成对的等位基因存在，在杂合子中共处而不被改变，并被原样传递。
- **分离**：每个配子携带每一对等位基因中的一个，杂合子的每个等位基因概率 $\tfrac12$。*Aa* × *Aa* 给 *AA* : *Aa* : *aa* = 1 : 2 : 1，有显性时 3 : 1；显性后代中 $\tfrac23$ 为杂合子。
- **自由组合**：未连锁的基因座独立分离，双杂交 F2 给 9 : 3 : 3 : 1，一般地表型比为 $(3+1)^n$。
- 与隐性纯合子的**测交**揭示一个个体的配子：杂合子为 $1:1$。
- 独立事件用乘法法则，互斥事件用加法法则，部分信息用条件概率，家庭用二项分布。
- **χ² 适合度检验**把观察计数与假说下的期望计数比较：$X^2 = \sum (O-E)^2/E$，自由度 $k-1$。小 P 值拒绝假说；大 P 值未能拒绝，但什么也证明不了。
- 显性描述杂合子的表型；它不涉及频率或适合度。
:::

## 练习

::: exercise 测交 {level=1 check="1/2"}
一株杂合高茎豌豆（*Tt*）与矮茎植株（*tt*）杂交。某一特定后代是矮茎的概率是多少？
::: solution
*tt* 亲本只产生 *t* 配子；*Tt* 亲本以概率 $\tfrac12$ 各产生 *T* 与 *t*。后代从杂合亲本得到 *t* 时即为 *tt*（矮茎）：概率 $\tfrac12$。
:::
:::

::: exercise 四个隐性同时出现 {level=1 check="1/256"}
杂交 *Aa Bb Cc Dd* × *Aa Bb Cc Dd*，所有基因座未连锁，子代中 *aa bb cc dd* 的比例是多少？
::: solution
每个基因座 $P(aa) = \tfrac14$，基因座间独立，所以比例为 $(\tfrac14)^4 = \tfrac1{256}$。
:::
:::

::: exercise 类别计数 {level=1 check="27/64"}
三因子杂交的 F2（三个基因座均未连锁，完全显性）中，对三个性状都表现显性表型的植株比例是多少？
::: solution
$(\tfrac34)^3 = \tfrac{27}{64}$，同[[#ex-trihybrid]]。
:::
:::

::: exercise 单因子 χ² {level=2 check="1.33"}
一个 F2 群体有紫花 290 株、白花 110 株。就 $3:1$ 假说计算 $X^2$（保留两位小数），并在 5 % 水平陈述结论。
::: solution
$n = 400$，$E = 300$ 与 $100$。$X^2 = \dfrac{10^2}{300} + \dfrac{10^2}{100} = 0.333 + 1.000 = 1.33$，$\nu = 1$。因 $1.33 < 3.841$（$p = 0.25$），数据与 $3:1$ 一致。
:::
:::

::: exercise 四个中恰好一个 {level=2 check="0.422"}
两个隐性等位基因的杂合携带者有四个孩子。恰好一个孩子表现隐性表型的概率是多少（保留三位小数）？
::: solution
$\binom41(\tfrac14)(\tfrac34)^3 = \tfrac{108}{256} = 0.422$（[[#ex-family]]）。注意这一最可能的结果仍然不如"不发生"可能。
:::
:::

::: exercise 两个正常同胞 {level=2 check="1/9"}
一位女子与一位男子各自是某常染色体隐性遗传病患者的正常同胞；两家双亲均为正常携带者。两家均无其他相关家族史，且该病足够罕见，可忽略婚入的携带者。他们第一个孩子患病的概率是多少？
::: hint
对每位父/母使用[[#prop-two-thirds]]。
:::
::: solution
每位未来父/母是携带者的概率为 $\tfrac23$。孩子患病只有当双方都是携带者且从双方各得一个隐性等位基因：$\tfrac23\cdot\tfrac23\cdot\tfrac14 = \tfrac19$。（若把携带者概率误用 $\tfrac12$——一种常见错误——会得 $\tfrac1{16}$。）
:::
:::

::: exercise 解读拟合失败 {level=2}
双杂合 F2 中类别 *A-B-*、*A-bb*、*aaB-*、*aabb* 的计数为 152、39、53、6。(a) 检验对 $9:3:3:1$ 的符合度。(b) 再分别考虑两个基因座：检验 $A\text{-} : aa$ 比例与 $B\text{-} : bb$ 比例对 $3:1$ 的符合度。(c) 这些结果提示什么？
::: solution
(a) $n = 250$；$E = 140.625,\ 46.875,\ 46.875,\ 15.625$。$X^2 = 0.920 + 1.323 + 0.800 + 5.929 = 8.97$，$\nu = 3$，$p = 0.030$：在 5 % 水平拒绝 $9:3:3:1$。

(b) 基因座 A：显性 $152 + 39 = 191$，隐性 $53 + 6 = 59$；$E = 187.5,\ 62.5$；$X^2 = 0.065 + 0.196 = 0.26$，$p = 0.61$。基因座 B：显性 $152 + 53 = 205$，隐性 $39 + 6 = 45$；$X^2 = (205-187.5)^2/187.5 + (45-62.5)^2/62.5 = 1.633 + 4.900 = 6.53$，$p = 0.011$。

(c) 基因座 A 正常分离。基因座 B 显示 *bb* 植株短缺（45 而非 62.5），这造成了大部分失拟——尤其是 *aabb* 的短缺。一个合理的解释是 *bb* 生活力降低（或 *bb* 表型难以识别），而不是自由组合失效。按基因座拆分数据是定位偏差来源的标准做法；检验两个基因座间独立性的恰当方法会用列联表。
:::
:::

::: exercise F2 要多大？ {level=3 check="191"}
育种者必须种植多少株三因子杂交（*Aa Bb Cc* 自交，基因座未连锁）的 F2，才能至少有 95 % 的机会得到至少一株 *aa bb cc*？
::: solution
每株为 *aabbcc* 的概率 $(\tfrac14)^3 = \tfrac1{64}$。$n$ 株中一株都不是的概率 $(\tfrac{63}{64})^n$，需要 $(\tfrac{63}{64})^n \le 0.05$，即 $n \ge \ln 0.05/\ln(63/64) = 190.2$。所以需要 191 株——约为"预期"的 64 的三倍。
:::
:::

::: exercise 费希尔的质疑 {#exr-fisher level=3}
为了把 F2 中表现显性表型的植株归类为 *AA* 或 *Aa*，孟德尔对每株种植 10 个后代，若 10 个全部表现显性性状就把该株判为纯合子。(a) 一个杂合子被误判为纯合子的概率是多少？(b) 在这一程序下，显性 F2 植株预期有多大比例被判为纯合、多大比例被判为杂合？(c) 若干实验中孟德尔报告的比例非常接近 $1:2$。费希尔为何认为这可疑？
::: solution
(a) 杂合子自交后代每个表现显性表型的概率 $\tfrac34$，所以 10 个全部显性的概率 $(\tfrac34)^{10} = 0.0563$。

(b) 判为纯合：$\tfrac13 + \tfrac23(0.0563) = 0.371$；判为杂合：$\tfrac23(1-0.0563) = 0.629$——比值 $1:1.70$，不是 $1:2$。

(c) 若孟德尔使用这一程序，他的计数应在 $1:1.70$ 附近散布。它们却聚集在 $1:2$ 附近，即没有误判时的预期值；若计数确按所述方式收集，这是不太可能出现的。可能的解释包括实际使用了与所述不同的方案（例如识别的后代多于 10 个）、选择性报告或无意识偏倚。这一计算说明理解归类程序如何改变预期比例——这一点在任何遗传实验中都很重要。
:::
:::
