到 1915 年，遗传学已拥有异常完整的形式理论。基因在染色体上排成一线，可以用重组作图，也可以被突变改变，但没有人知道它们由什么构成、做什么事情。此后半个世纪，三个问题依次得到回答：基因*做*什么（它们决定蛋白质，常常是酶），它们*由什么构成*（DNA），以及以功能、突变和重组定义的经典基因如何对应 DNA 分子的一个片段。答案来自一系列极为优雅的实验，其中许多用真菌、细菌和病毒完成，遗传学由此变成了分子生物学。

本章沿这条路依次展开。我们会遇到一个基因一种酶假说与生化遗传学的逻辑、证明 DNA 是遗传物质的实验、为基因下操作性定义的**互补测验**、**点突变**的类型及其如何自发或诱发产生，以及表明突变随机产生而非应需要而生的**波动试验**。DNA 的复制、转录与翻译的化学在 [[molecular-biology]] 中处理；这里保持遗传学家的观点，即通过突变等位基因来认识基因。

## 基因做什么

第一个线索来自医学。1902 年，医生阿尔奇博尔德·加罗德（Archibald Garrod）研究黑尿酸尿症——一种罕见疾病，尿液因含尿黑酸而在放置后变黑——注意到它常出现在姑表或舅表亲婚配所生的孩子中，并按孟德尔隐性性状的方式行为。在《代谢的先天错误》（*Inborn Errors of Metabolism*，1908）中，他提出每一种此类疾病都因缺乏某种特定酶、使其底物积累所致。（黑尿酸尿症缺乏的酶——尿黑酸 1,2-双加氧酶——直到 1958 年才被鉴定。）加罗德的想法在此后三十年里几乎没有得到遗传学家的理会。

1941 年，乔治·比德尔（George Beadle）与爱德华·塔特姆（Edward Tatum）把问题反转过来。他们不从表型出发去寻找其生化基础，而是用 X 射线在面包霉脉孢菌（*Neurospora crassa*）中诱发突变，寻找不能合成某种必需营养物的突变体。野生型脉孢菌（**原养型**）能在只含糖、无机盐和维生素生物素的**基本培养基**上生长，并由此合成它所需的全部氨基酸与其他维生素。必须添加某种特定营养物才能生长的突变体——**营养缺陷型**——每一个都只带一个孟德尔式突变，阻断某条生物合成途径的一个步骤。因为脉孢菌在生命周期的大部分时间是单倍体，每个突变都得到表达，与野生型杂交在孢子中给 $1:1$ 分离（[[genetics/chromosomes-meiosis]]）。

::: definition 原养型、营养缺陷型与一个基因一种酶假说 {#def-auxotroph}
**原养型**能在基本培养基上生长；**营养缺陷型**需要补充一种野生型本可自制的营养物，因为某个突变阻断了它的合成。比德尔与塔特姆的**一个基因一种酶假说**称，每个基因控制一种酶的合成。它的现代形式是：多数基因编码一条多肽（若干条多肽可共同组成一种酶），另一些编码不被翻译的功能 RNA，如核糖体 RNA 与转运 RNA。
:::

::: example 由营养缺陷型的生长为途径排序 {#ex-pathway}
阿德里安·瑟布（Adrian Srb）与诺曼·霍罗维茨（Norman Horowitz）（1944）研究了需要精氨酸的脉孢菌突变体。设发现三类突变体。1 类在添加了鸟氨酸、瓜氨酸或精氨酸的基本培养基上生长；2 类在瓜氨酸或精氨酸上生长，但在鸟氨酸上不能；3 类只在精氨酸上生长。每个突变体只有一个阻断。(a) 推断鸟氨酸、瓜氨酸与精氨酸在途径中的次序以及每一类被阻断的步骤。(b) 你预计 2 类突变体会积累哪种中间物？
::: solution
(a) 在某一步被阻断的突变体能利用阻断*之后*的任何化合物生长，因为它能把该化合物转化为终产物，却不能利用阻断之前的化合物。3 类只被精氨酸拯救，所以它的阻断在最后一步，紧挨精氨酸之前。2 类被瓜氨酸而不被鸟氨酸拯救，所以阻断在鸟氨酸与瓜氨酸之间。1 类被三者都拯救，所以阻断在鸟氨酸之前。途径是

$$
\text{前体} \xrightarrow{\text{类 1}} \text{鸟氨酸} \xrightarrow{\text{类 2}} \text{瓜氨酸} \xrightarrow{\text{类 3}} \text{精氨酸}。
$$

(b) 2 类突变体不能把鸟氨酸转化为瓜氨酸，所以鸟氨酸（被阻断酶的底物）积累——与加罗德的尿黑酸完全同样的逻辑。"拯救一个突变体的化合物越多，它的阻断越早"这条规则是普遍的。
:::
:::

## 基因的化学物质

基因由 DNA 构成，是由细菌及其病毒的实验确立的。

1928 年，伦敦的军医弗雷德里克·格里菲斯（Frederick Griffith）研究肺炎链球菌 *Streptococcus pneumoniae* 的两种类型：有多糖荚膜、对小鼠致命的光滑型（S 型），与没有荚膜、不致死的粗糙型（R 型）。加热杀死的 S 型细菌无害，活的 R 型细菌也无害；但把两者混合注射的小鼠死亡，并且从中回收到了活的 S 型细菌。死的 S 型细胞中的某种东西可遗传地使 R 型细胞**转化**成了 S 型。1944 年，洛克菲勒研究所的奥斯瓦尔德·艾弗里（Oswald Avery）、科林·麦克劳德（Colin MacLeod）与麦克林·麦卡蒂（Maclyn McCarty）从 S 型菌株提取物中纯化了"转化因子"，证明其活性被降解 DNA 的酶破坏，而不被降解蛋白质或 RNA 的酶破坏，并且其化学与物理性质就是 DNA 的性质。许多科学家仍持怀疑态度，怀疑有蛋白质污染。

1952 年，阿尔弗雷德·赫希（Alfred Hershey）与玛莎·蔡斯（Martha Chase）利用噬菌体 T2——一种只由蛋白质与 DNA 组成、感染大肠杆菌（*Escherichia coli*）的病毒。他们用放射性硫（$^{35}$S，存在于甲硫氨酸与半胱氨酸中，DNA 中没有）标记噬菌体蛋白质，或用放射性磷（$^{32}$P，在 DNA 骨架中，蛋白质中没有）标记噬菌体 DNA，让噬菌体感染细菌，再用搅拌器搅动培养物，把细胞表面空的噬菌体蛋白质外壳剥离下来。大部分 $^{32}$P 进入细胞并传递给了子代噬菌体；大部分 $^{35}$S 留在外面的外壳里。进入细胞并指导新噬菌体形成的物质是 DNA。

次年，詹姆斯·沃森（James Watson）与弗朗西斯·克里克（Francis Crick）利用罗莎琳德·富兰克林（Rosalind Franklin）与莫里斯·威尔金斯（Maurice Wilkins）获得的 X 射线衍射数据，提出了 DNA 的双螺旋结构（1953）：其中互补的碱基配对（A 与 T，G 与 C）立刻提示了这个分子如何被复制，以及它如何能在自己的序列中携带信息。有些病毒的遗传物质是 RNA，海因茨·弗伦克尔-康拉特（Heinz Fraenkel-Conrat）与比阿特丽斯·辛格（Beatrice Singer）1957 年在烟草花叶病毒上证明了这一点。

::: warning "赫尔希-蔡斯实验单凭自己就证明了 DNA 是遗传物质"
这一实验有很强的提示性但并非决定性：约 20 % 的蛋白质标记也进入或留在了细胞上，单凭这一结果无法排除那部分蛋白质的作用。它的力量来自与艾弗里等转化实验（使用了纯化的 DNA）的一致性，以及一年后提出的 DNA 结构——它解释了遗传信息如何存储与复制。如此重要的科学结论通常都要依靠几条相互独立的证据，这一条也是如此。
:::

## 作为功能单位的基因：互补

如何判断两个表型相同的突变是否位于同一个基因内？作图有帮助但不能定论，因为两个基因可以靠得极近。决定性的检验是功能上的。

::: definition 互补测验 {#def-complementation}
给定表型相同的两个隐性突变 $m_1$ 与 $m_2$，在二倍体中，或在细菌或噬菌体的部分二倍体中，构建**反式双杂合体**，即一条同源染色体带 $m_1$、另一条带 $m_2$（$m_1\ {+}/{+}\ m_2$）。若它呈**野生型**表型，两个突变**互补**，被视为位于**不同基因**：每条同源体提供另一条所缺的功能。若它呈**突变**表型，则它们**互不互补**，位于**同一个基因**。互不互补的突变构成一个**互补群**，对应一个基因。
:::

逻辑很简单。若两个突变在不同基因上，反式双杂合体对每个基因各有一份功能拷贝，因而呈野生型（两者都是隐性）。若它们在同一个基因上，两条同源体都没有功能拷贝，表型即为突变型。**顺式双杂合体**（$m_1\ m_2/{+}\ {+}$，两个突变在同一条同源体上，另有一条野生型同源体）在两种情形下都是野生型，充当对照；正因如此，这一测验也叫*顺式-反式*测验，这一术语由西摩·本泽尔（Seymour Benzer）在 1950 年代引入，他把该测验所辨认的功能单位定义为**顺反子**。

::: example 用互补为突变分组 {#ex-complementation}
六个独立分离到的隐性突变 *1* 至 *6*，在通常开紫花的二倍体植物中全都导致白花。纯合突变株系间两两杂交，F1 花色如下（+ 紫，− 白）：

| | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| **1** | − | + | − | + | + | − |
| **2** | | − | + | − | + | + |
| **3** | | | − | + | + | − |
| **4** | | | | − | + | + |
| **5** | | | | | − | + |
| **6** | | | | | | − |

它们代表几个基因，每个基因里有哪些突变？
::: solution
− 表示互不互补：同一个基因。突变 1 与 3、6 互不互补，3 又与 6 互不互补，所以 {1, 3, 6} 是一个基因。突变 2 与 4 互不互补：{2, 4} 是第二个。突变 5 与其他所有突变都互补：{5} 是第三个。所以涉及三个基因——与一条三步的色素途径相一致，这类途径的两步版本见 [[genetics/extensions-of-mendel#ex-sweet-pea]]。（表格必须自洽：若 1 与 3 互不互补、1 与 6 也互不互补，3 与 6 却互补，就一定有问题——也许某个突变是横跨两个基因的缺失，或者出现了基因内互补。）
:::
:::

::: warning 互补不是重组
互补测验问的是子一代内的*功能*：反式双杂合体是否呈野生型表型？重组问的是*传递*：下一个世代能否从中回收野生型染色体？同一个基因内的两个突变互不互补，但若它们位于该基因内的不同位点，仍能重组出野生型基因。两种测验回答的问题不同，混为一谈会出错。互补测验还要求突变是隐性的：显性突变无论另一条同源体上的突变如何，反式双杂合体都是突变表型。
:::

::: quiz
黑腹果蝇（*Drosophila*）中两个各自导致白眼的隐性突变图距 0.01 cM。反式双杂合体是白眼。你能得出什么结论？
- [x] 它们很可能是同一个基因的等位基因。
- [ ] 它们在不同基因上，因为它们能重组。
- [ ] 它们在不同基因上，因为它们定位在不同位点。
- [ ] 什么也得不出来，因为顺式双杂合体还没有测验。
::: solution
反式双杂合体互不互补，意味着两条同源体都不能提供该功能，所以两个突变在同一个基因内。定位到不同位点只说明它们改变了基因内的不同碱基对；它们之间发生重组仍可再生出野生型基因。顺式双杂合体是对照（它应当是野生型），但若已知两个突变都是隐性的，得出结论并不需要它。
:::
:::

本泽尔 1955 至 1961 年对噬菌体 T4 *rII* 区的工作，展示了重组能把分辨率推到多低。*rII* 突变体在某种大肠杆菌菌株上形成大而边缘清晰的噬菌斑，却不能在另一菌株（菌株 K）上生长，于是即使几十亿子代噬菌体中极罕见的野生型重组体，也能通过接种到菌株 K 上检出。互补把 *rII* 突变体分成两个基因：*rIIA* 与 *rIIB*。在每个基因内部，本泽尔把数千个突变定位到数百个位点，最小的非零重组频率约为 0.01–0.02 %，相当于相邻的碱基对。他由此断定：基因是一列可突变的位点——即一段 DNA 的序列——而某些位点（**热点**）的突变率远高于其他位点。

## 点突变

::: definition 点突变的类型 {#def-point-mutation}
**点突变**改变一个或几个碱基对。
- **碱基替换**以一个碱基对取代另一个。**转换**以嘌呤换嘌呤、或以嘧啶换嘧啶（A·T ↔ G·C）；**颠换**以嘌呤换嘧啶或相反（A·T ↔ T·A，A·T ↔ C·G，G·C ↔ C·G，G·C ↔ T·A）。
- **插入**或**缺失**（**indel**）增加或去掉碱基对。

在蛋白质编码序列中，替换可以是**同义的**（沉默的：密码子仍编码同一氨基酸）、**错义的**（编码另一种氨基酸）或**无义的**（形成终止密码子，使蛋白质截短）。长度不是三的倍数的插入或缺失是**移码**，改变下游的每一个密码子。
:::

由给定碱基出发的十二种可能替换中，四种是转换，八种是颠换，所以若一切替换等概率，颠换应当以二比一多于转换。实际上多数基因组中转换更常见——人单核苷酸变异中转换与颠换之比约为 2。主要原因是化学性的：胞嘧啶自发脱氨基成尿嘧啶（能被高效修复），而 5-甲基胞嘧啶——在脊椎动物中常见于 CpG 位点——脱氨基成胸腺嘧啶，修复系统不易把它认作错误；结果是 C·G → T·A 转换。CpG 位点的突变率约为其他位点的十倍或更高，是突出的热点。

赫尔曼·穆勒（Hermann Muller）（1932）按突变等位基因对基因活性的影响对其进行分类，这一方案沿用至今：**无定型**（amorph，功能完全丧失，即**无效**等位基因）、**亚定型**（hypomorph，功能降低）、**超定型**（hypermorph，功能增强）、**反定型**（antimorph，显性负、与野生型对抗的等位基因）与**新定型**（neomorph，获得新功能）。无定型与亚定型通常是隐性的；其余几类通常是显性的（[[genetics/extensions-of-mendel]]）。

::: example 移码及其抑制 {#ex-frameshift}
一段编码序列为 `5'-ATG AAA CCC GGG TTT AAA-3'`，编码 Met–Lys–Pro–Gly–Phe–Lys。(a) 在第 1 与第 2 个密码子之间插入一个碱基 G 后，各密码子变成什么？(b) 若该突变体中一个单碱基缺失去掉第 5 个密码子的第 1 个碱基，其后的阅读框如何？(c) 1961 年克里克、布伦纳及同事如何用这类组合证明遗传密码以三个碱基一组阅读？
::: solution
(a) 序列变成 `ATG GAA ACC CGG GTT TAA A...`：Met–Glu–Thr–Arg–Val–终止。插入之后的每个密码子都改变了，并且此处出现了终止密码子。

(b) 突变体的第 5 个密码子是 `GTT`。去掉其中的 G 得 `ATG GAA ACC CGG TTT AAA`：从第 5 个密码子起阅读框恢复，只有第 2–4 个密码子改变。少数几个氨基酸错误的蛋白质可能仍有功能。

(c) 他们研究吖啶类诱发、位于噬菌体 T4 *rIIB* 基因的突变，发现突变分为两类：(+) 与 (−)。相距很近的一个 (+) 与一个 (−) 组合常能恢复功能，三个 (+) 或三个 (−) 的组合也能——但两个同类的组合不能。若突变增加或去掉一个碱基，而密码子从固定起点按不重叠的三个一组阅读，这正是预期的：三个插入使阅读框移动三位，从而恢复。密码子的细节见 [[molecular-biology]]。
:::
:::

## 突变如何产生

**自发突变**来自逃过校对与错配修复的 DNA 复制错误、自发的化学损伤——脱嘌呤（丢失嘌呤碱基）、胞嘧啶与 5-甲基胞嘧啶的脱氨基、8-氧鸟嘌呤之类的氧化损伤（它与腺嘌呤配对）——以及复制机器在重复序列中的滑移，后者增加或去掉重复单位。有些人类疾病，包括亨廷顿病与脆性 X 综合征，源于三核苷酸重复**扩展**超过某个阈值长度；扩展的重复不稳定，在传递中倾向于进一步增大，这解释了这些家系中观察到的、逐代发病更早或病情更重的早发现象（anticipation）。转座元件能在基因组内移动位置，也是突变的一个来源；芭芭拉·麦克林托克（Barbara McClintock）对它们的发现见 [[genetics/non-mendelian-inheritance]] 与 [[genomics]]。

::: definition 突变率 {#def-mutation-rate}
**突变率**是一次复制单位内发生突变的概率：每碱基对每次细胞分裂、每基因每世代，或每基因组每世代。它与**突变频率**不同，后者是群体中突变个体或细胞的比例，反映突变产生之后如何积累与增多。
:::

典型数值：大肠杆菌每碱基对每次复制约 $10^{-10}$；人每碱基对每世代约 $1.2\times10^{-8}$（由父母与子女测序估计，如冰岛 deCODE 课题组 2012 年及其后的工作）。人的二倍体基因组约含 $6.2\times10^9$ bp，所以每个孩子平均带有双亲都没有的新点突变约 $1.2\times10^{-8}\times6.2\times10^9 \approx 70$ 个，其中多数来自父亲，且数目随父龄上升，因为精子前体细胞在成年期持续分裂。绝大多数落在非编码 DNA 中，没有可检出的效应。

### 波动试验：突变是随机的

细菌接触病毒或抗生素后，会出现抗性突变体。突变是*应*选择因子*而生*（定向的"获得性"突变），还是在此之前随机产生、选择因子只是把它们显现出来？1943 年，卢里亚（Salvador Luria）与德尔布吕克（Max Delbrück）用大肠杆菌和噬菌体 T1，以一个统计学论证回答了这个问题。

::: proposition 卢里亚-德尔布吕克波动试验 {#prop-luria}
许多平行的小接种量培养物各自长到相同的终数 $N$，把每管培养物全部涂布在含选择因子的培养基上。
1. 若抗性由该因子**诱发**，则 $N$ 个细胞各自独立地以小概率变为抗性，每管抗性菌落数近似服从**泊松**分布，方差等于均值。
2. 若抗性突变在生长中**随机**产生，则早期世代的一个突变会产生一个抗性细胞的大克隆（"大奖"），晚期突变只产生一个或几个。每管抗性细胞数的方差就远大于均值。
3. 在随机突变之下，每管的突变*事件*数服从均值 $m$ 的泊松分布，所以没有抗性细胞的培养物比例 $p_0$ 满足 $p_0 = e^{-m}$，即 $m = -\ln p_0$。每次细胞分裂的突变率近似为 $\mu \approx m/N$。
:::

::: proof
(1) 在诱发模型下，抗性细胞数是 $N$ 个独立的 Bernoulli($p$) 试验之和，$N$ 大而 $p$ 小，近似服从均值 $Np$ 的泊松分布；其方差等于均值。(2) 在随机突变下，抗性细胞数是各突变事件产生的克隆大小之和，而涂板前 $g$ 代发生的突变建立的克隆有 $2^g$ 个细胞；早期事件罕见但克隆巨大，所以分布有很长的右尾，方差远超均值。(3) 由少数细胞长到 $N$ 个细胞的培养物总共约经历 $N$ 次细胞分裂；若每次分裂独立地以微小概率 $\mu$ 产生突变，事件数近似服从均值 $m = \mu N$ 的泊松分布。培养物恰无事件发生时才没有抗性细胞，其概率为 $e^{-m}$。
:::

::: example 波动试验的分析 {#ex-fluctuation}
二十管平行培养物各长到 $N = 2\times10^8$ 个细胞，噬菌体抗性菌落数如下：九管为 0；三管为 1；两管为 2；3、5、7、12、30 与 107 各一管。(a) 计算均值与方差并置评。(b) 估计每管的突变事件数与每次细胞分裂的突变率。
::: solution
(a) 菌落总数 $3 + 4 + 3 + 5 + 7 + 12 + 30 + 107 = 171$，均值 $171/20 = 8.55$。样本方差为 $585.5$，约为均值的 68 倍。若为诱发突变（泊松），方差与均值应大致相等；从一管培养物取样涂板只会显示泊松变异。如此巨大的方差，外加 107 这样偶见的大奖，正是选择之前随机突变所预言的。

(b) $p_0 = 9/20 = 0.45$，所以 $m = -\ln0.45 = 0.80$ 事件每管，$\mu \approx 0.80/(2\times10^8) = 4.0\times10^{-9}$ 每次细胞分裂。
:::
:::

莱德贝格夫妇——约书亚与埃丝特·莱德贝格（Joshua and Esther Lederberg）1952 年用**影印培养**（replica plating）直接证实了这一结论：把一块天鹅绒垫压到长满菌落的平板上，就把每个菌落的细胞转移到新平板的相同位置。抗性菌落在选择性复制平板上出现的位置，在各独立复制板之间彼此相同，表明抗性细胞在主平板接触选择因子之前就已存在于主平板上——而且可以从主平板上把它们回收出来，它们从未接触过选择因子。

::: warning "突变会在生物需要的时候发生"
波动试验与影印培养表明，赋予抗性的突变出现在接触选择它的因子之前，并且与之无关。突变相对于其有用性是随机的：环境可以改变突变的总体*速率*（辐射与某些胁迫使之升高），选择随后在变异中筛分，但环境不会把突变导向它们会有用的基因。这是进化理论的一块基石（[[evolution]]）。突变也并非总是有害：多数中性或近乎中性，许多有害，少数在特定环境中有利。
:::

### 诱发突变

1927 年，穆勒证明 X 射线能使黑腹果蝇的突变率提高许多倍，用的是一条专门构建的 X 染色体：新的隐性致死突变只需看某一类儿子的缺失即可检出。1928 年，刘易斯·斯塔德勒（Lewis Stadler）在大麦与玉米中证明了同样的事。第二次世界大战期间，爱丁堡的夏洛特·奥厄巴赫（Charlotte Auerbach）与约翰·罗布森（J. M. Robson）发现芥子气是诱变剂——这是发现的第一个化学诱变剂（战后 1946–47 年发表）。诱变剂的作用方式只有几种概括，在教科书图示的水平上：

- **碱基类似物**如 5-溴尿嘧啶，与正常碱基相似到足以在复制时被掺入，但配对摇摆不定，引起转换。
- **烷化剂**如乙基甲磺酸酯（EMS），给碱基加上烷基；O⁶-乙基鸟嘌呤倾向与胸腺嘧啶配对，所以 EMS 主要引起 G·C → A·T 转换，这就是它在拟南芥（*Arabidopsis*）、秀丽隐杆线虫（*C. elegans*）等实验生物中广泛用于制造突变体库的原因。
- **嵌入剂**如克里克与布伦纳使用的吖啶类，插进堆叠的碱基之间，在复制时引起小的插入与缺失——移码。
- **紫外光**把相邻嘧啶连成二聚体，其修复或跨越中的错误导致突变；**电离辐射**打断 DNA 链，引起缺失与重排（[[genetics/chromosome-mutations]]）。

::: application 检测诱变剂
因为突变是多数癌症的第一步，许多致突变的物质也致癌。埃姆斯试验（Ames test）由布鲁斯·艾姆斯（Bruce Ames）及同事于 1970 年代初建立，通过测量化合物把实验室沙门氏菌（*Salmonella*）菌株的 *his*$^-$ 营养缺陷型回复为原养型的频率，来筛查化学物质的诱变性，所用的品系其突变只能由特定类型的改变（碱基替换或移码）回复。测定时要添加肝脏酶提取液，因为许多物质要经代谢转化后才具有诱变性。这一试验便宜而快速，阳性结果会按化学品安全的监管框架把化合物标为需进一步研究；它是一种筛查，不是对人致癌性的证明。
:::

突变也可以被逆转。**回复突变**（回复）恢复原来的序列或与之等效的序列；**抑制突变**通过另一位点的第二次改变恢复表型。**基因内抑制突变**位于同一个基因——[[#ex-frameshift]] 中的第二个移码就是一例。**基因间抑制突变**位于另一个基因；经典的例子是突变的转运 RNA 基因，其反密码子把一个无义密码子读成氨基酸，使翻译能越过提前终止密码子继续下去。

::: history
加罗德 1902 年把黑尿酸尿症描述为隐性的"先天代谢错误"，并在 1908 年的一本书中发展了这一思想。格里菲斯 1928 年报告了肺炎链球菌的转化。穆勒 1927 年发表 *Artificial transmutation of the gene*（《基因的人工转变》）。比德尔与塔特姆的 *Genetic control of biochemical reactions in* Neurospora（《脉孢菌生化反应的遗传控制》）发表于 1941 年。卢里亚与德尔布吕克的波动试验发表于 1943 年；艾弗里、麦克劳德与麦卡蒂 1944 年确定转化因子是 DNA。赫希与蔡斯的搅拌器实验发表于 1952 年，莱德贝格夫妇的影印培养也是同年。沃森与克里克 1953 年提出双螺旋，部分依据罗莎琳德·富兰克林与雷蒙德·戈斯林、以及莫里斯·威尔金斯的 X 射线数据。本泽尔对 *rII* 的精细结构分析从 1955 年进行到 1961 年；弗朗西斯·克里克、莱斯利·巴尼特（Leslie Barnett）、西德尼·布伦纳（Sydney Brenner）与理查德·沃茨-托宾（Richard Watts-Tobin）关于密码子三联体性质的论文发表于 1961 年。
:::

::: summary
- 基因决定蛋白质（加罗德；比德尔与塔特姆的一个基因一种酶，现为一条多肽或功能 RNA）。阻断在途径不同步骤的营养缺陷型，可按哪些中间物能拯救它们而排序；被阻断步骤的底物会积累。
- 基因是 DNA（艾弗里、麦克劳德与麦卡蒂 1944；赫希与蔡斯 1952；双螺旋 1953）；有些病毒用 RNA。
- 互补测验为基因下操作性定义：反式双杂合体为野生型的两个隐性突变在不同基因上；互不互补意味着同一个基因。互补（功能）不同于重组（传递）。
- 本泽尔的 *rII* 作图表明，基因是一列可突变的位点，分辨率直到单个碱基对。
- 点突变是转换、颠换与 indel；在编码序列中是同义、错义、无义或移码。转换占多数，部分经由 CpG 热点处 5-甲基胞嘧啶的脱氨基。
- 突变率：大肠杆菌每 bp 每次复制约 $10^{-10}$；人每 bp 每世代约 $1.2\times10^{-8}$，每个孩子约 70 个新突变。
- 卢里亚-德尔布吕克波动试验（方差 ≫ 均值；$m = -\ln p_0$）与影印培养表明突变随机产生，不是应需要而生。
- 诱变剂包括碱基类似物、烷化剂（EMS：G·C → A·T）、嵌入剂（移码）、紫外与电离辐射；抑制突变以第二次突变恢复功能。
:::

## 练习

::: exercise 转换还是颠换？{level=1}
把下列替换各归类为转换或颠换：(a) A·T → G·C；(b) G·C → T·A；(c) C·G → T·A；(d) A·T → T·A。
::: solution
(a) 转换（嘌呤 A 换嘌呤 G）。(b) 颠换。(c) 转换（嘧啶 C 换嘧啶 T）。(d) 颠换。
:::
:::

::: exercise 预期的转换比例 {level=1 check="1/3"}
若一切可能的单碱基替换都等概率，替换中转换占什么比例？
::: solution
从任何碱基出发，转换有一种、颠换有两种，所以 $\tfrac13$ 的替换会是转换。人的变异中实测的转换比例约为 $\tfrac23$。
:::
:::

::: exercise 每个孩子的突变数 {level=1 check="74"}
取人的突变率为每碱基对每世代 $1.2\times10^{-8}$、二倍体基因组 $6.2\times10^9$ bp，一个孩子平均带有多少新点突变（取最接近的整数）？
::: solution
$1.2\times10^{-8}\times6.2\times10^9 = 74.4$，约 74——与测序研究中找到的 60–80 一致，数目强烈取决于父亲的年龄。
:::
:::

::: exercise 途径排序 {level=2}
四个脉孢菌突变体（1–4）需要化合物 G 才能生长。各突变体在添加了化合物 C、D、E、F 或 G 之一的基本培养基上测试（+ 生长，− 不生长）：

| | C | D | E | F | G |
|---|---|---|---|---|---|
| 1 | − | + | − | + | + |
| 2 | − | − | − | + | + |
| 3 | − | + | + | + | + |
| 4 | − | − | − | − | + |

给出化合物在途径中的次序与各阻断的位置。C 在何处？
::: solution
拯救一个突变体的化合物越多，它的阻断越早。突变体 4 只被 G 拯救（阻断紧挨 G 之前）。突变体 2 被 F 与 G 拯救（阻断在 F 之前）。突变体 1 被 D、F、G 拯救（阻断在 D 之前）。突变体 3 被 E、D、F、G 拯救（阻断在 E 之前）。所以途径是 E → D → F → G，阻断位置：3 在 E 之前，1 在 E 与 D 之间，2 在 D 与 F 之间，4 在 F 与 G 之间。C 不拯救任何突变体，所以它或者在一切阻断之前（在突变体 3 的步骤之前），或者根本不在途径上；这些数据无法分辨。
:::
:::

::: exercise 互补群 {level=2 check="2"}
五个隐性突变 *a*–*e* 导致同一表型。反式双杂合体中，*a*、*c*、*e* 彼此互不互补，*b* 与 *d* 互不互补，其余每一对都互补。它们代表几个基因？
::: solution
{*a*、*c*、*e*} 构成一个互补群，{*b*、*d*} 构成第二个，所以代表 2 个基因。注意该测验需要每一对的结果：若 *c* 与 *e* 彼此互补、却各自与 *a* 互不互补，最简解释就是 *a* 是影响两个相邻基因的缺失（或其他损伤）。
:::
:::

::: exercise 卢里亚-德尔布吕克估计 {level=2 check="1.51"}
一次波动试验中，50 管平行培养物有 11 管没有抗性细胞。估计每管突变事件的平均数（保留两位小数）。
::: solution
$p_0 = 11/50 = 0.22$，所以 $m = -\ln0.22 = 1.51$ 事件每管。
:::
:::

::: exercise 无义还是错义？{level=2}
密码子 `TGG`（Trp）经一次 G→A 转换突变。可能的结果是什么，各属于什么类型？上述诱变剂中最可能造成这些改变的是哪一种？
::: solution
第 2 位的 G→A 转换给出 `TAG`（终止），第 3 位给出 `TGA`（终止）：两者都是无义突变。（第 1 位是 T，不是 G。）G·C → A·T 转换是 EMS 的特征性改变，所以 EMS 最可能；互补链上 5-甲基胞嘧啶的脱氨基会自发造成同样的改变。
:::
:::

::: exercise 设计的解读 {level=3}
一位学生争辩说，卢里亚-德尔布吕克的结果也可以用"细菌接触噬菌体时变得抗性、但概率因管而异"来解释。(a) 这一替代为什么解释不了数据？(b) 影印培养如何把它排除？(c) 提出一个现代的基于测序的检验。
::: solution
(a) 若各管的诱发概率不同，计数将是若干泊松分布的混合，并显示额外方差——但这些培养物用同一储种、在同一培养基中生长、接受完全相同的处理，没有理由认为它们对诱发的敏感性存在管间的大差异。而且卢里亚-德尔布吕克分布的具体形状——包括大奖的长尾以及 $p_0$ 与均值之间的关系——都被随机突变模型定量地预言；从单管培养物取样的样本只显示泊松变异。

(b) 影印培养表明，抗性细胞在任何接触之前就存在于主平板的固定位置，并可在未接触选择因子的情况下从主平板回收。接触诱导不可能产生从未接触过该因子的抗性细胞。

(c) 对平行培养物的单菌落、以及选择之前取样的样本，测序抗性基因。随机突变之下，获大奖的培养物中许多抗性细胞将携带同一突变（一个克隆），不同培养物携带不同突变，而且借助深度测序应在接触之前就应以低频率检出该突变。
:::
:::

::: exercise 基因内的重组 {level=3 check="0.002"}
设一个长 2500 bp 的基因总图距为 5 个图距单位（其两端突变之间重组 5 %），重组沿它均匀发生，并在这样短的距离上可加。(a) 相邻碱基对的突变之间，预期的重组频率是多少（%）？(b) 本泽尔在 *rII* 内测得的最小重组频率约 0.01–0.02 %。他能检测如此罕见的事件，而在黑腹果蝇中低于约 0.1 % 的频率就难以测量，为什么？
::: solution
(a) $5\ \%/2500 = 0.002\ \%$ 每碱基对，即 $2\times10^{-5}$。按这一估计，本泽尔的最小值大约相当于 5–10 bp；考虑到重组并不均匀，它们与相邻或几乎相邻碱基对处的突变相一致——这是 DNA 序列本身设定的分辨极限。

(b) 只有野生型重组噬菌体能在大肠杆菌菌株 K 上生长，所以一张平板就从 $10^8$ 以上的子代噬菌体中选择出它们，低到约 $10^{-8}$ 的频率也能测。黑腹果蝇中每一只蝇都要饲养并肉眼计分，样本受限于数千至数万；本泽尔式选择系统才使精细结构作图成为可能。
:::
:::
