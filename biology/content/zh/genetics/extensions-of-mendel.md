孟德尔是幸运的，也是有眼光的。他挑的七个豌豆性状各由单个基因决定，一个等位基因对另一个完全显性，两种纯合子生活力相同，表型不受年景影响。多数性状并非如此。杂合子常常是中间型；一个基因可能有几十个等位基因；有些等位基因会致死；多个基因可能影响同一性状，以致一个掩盖另一个；同一基因型在不同环境可给出不同表型。早期的孟德尔主义者杂交其他生物时，遇到了 $1:2:1$、$2:1$、$9:3:4$、$9:7$、$12:3:1$ 这类比例，有几年它们似乎危及这个新理论。

并没有。只要考虑基因型被翻译成表型的种种方式，这些比例无一例外都能从孟德尔两条定律推出。本章逐一讨论这些扩展：显性关系及其分子基础、复等位基因与致死等位基因、外显率与表现度、基因间的相互作用（上位效应）、环境的作用，最后是连续变异的多基因性状——孟德尔式遗传与连续变异的统计学在此相遇。贯穿全章的规则是同一个：**分离与自由组合说的是基因型；我们数出来的比例说的是表型**，而从一到二的映射正是生物学进入的地方。

## 显性是表型之间的关系

::: definition 显性关系 {#def-dominance}
考虑一个带有等位基因 $A_1$ 与 $A_2$ 的基因座，以及三种基因型 $A_1A_1$、$A_1A_2$、$A_2A_2$ 的表型。
- 若 $A_1A_2$ 具有 $A_1A_1$ 的表型，则 $A_1$ 对 $A_2$**完全显性**。
- 若 $A_1A_2$ 介于两种纯合子之间，则两等位基因表现为**不完全显性**。
- 若 $A_1A_2$ 同时表现出两种纯合子的表型，则两等位基因**共显性**。
- **超显性**指杂合子落在两种纯合子的范围之外（例如比二者都大或都更适合）。
:::

不完全显性或共显性时，三种基因型有三种可区分的表型，所以 F2 表型比就是[[genetics/mendelian-inheritance#eq-121]]的基因型比 $1:2:1$。不完全显性的经典例子是金鱼草 *Antirrhinum majus* 的花色，由埃尔文·鲍尔（Erwin Baur）研究：红 × 白得粉红 F1，F2 约为红 : 粉 : 白 $1:2:1$。这*不是*融合，因为红与白的亲本类型在 F2 中原样重现。

共显性从分子表型看得最清楚。人的 MN 血型由基因 *GYPA* 的两个等位基因决定，该基因编码红细胞表面的血型糖蛋白 A；两等位基因在两个氨基酸上不同，分别定义 M 与 N 抗原。基因型 *MN* 的人细胞上兼有两种抗原，因此用抗体试验可以区分全部三种基因型。

::: intuition 为什么许多功能丧失等位基因是隐性的
多数基因编码酶或其他蛋白质，其产物需要的是某个数量而非精确数量。若一个功能等位基因产生正常量一半的酶，而一半已足够正常表型，该基因就是**单倍足效**的，功能丧失等位基因即为隐性——孟德尔的 *r* 等位基因（[[genetics/mendelian-inheritance]]）是一例。功能丧失等位基因之所以显性，要么因为一半产物不够（**单倍剂量不足**，结构蛋白与剂量敏感的调控因子常见），要么因为缺陷产物主动干扰正常产物（**显性负效应**，见于以多聚体工作的蛋白质：一个坏亚基可能毁掉整个复合体）。**功能获得**等位基因——使蛋白质过度活跃或在错误的地方活跃——通常是显性的。
:::

观察所处的层次决定显性关系。考虑 β-珠蛋白等位基因 *HBB*$^{S}$（常写作 Hb$^S$），它以缬氨酸置换血红蛋白 β 链第 6 位的谷氨酸。在蛋白质层次，两等位基因共显性：杂合子同时具有血红蛋白 A 与血红蛋白 S，可用电泳分开。在正常条件下红细胞的形状层次，正常等位基因为显性：杂合子通常细胞正常，特征性的镰状细胞病见于纯合子。在对重症*Plasmodium falciparum*（恶性疟原虫）疟疾的抗性层次，杂合子是最抗病的基因型——这一超显性的选择后果是 [[population-genetics/selection-models]] 中的核心例子。（临床方面归[医学图谱](/learn/medicine/course.php?c=genetics)。）

::: warning "显性等位基因通过关闭隐性等位基因来掩盖它"
杂合子中两个等位基因通常都在转录和翻译；隐性等位基因并未失活或被"压制"。显性是关于整个生物体表型的陈述，而该表型通常是两个等位基因共同输出的结果。同样出于这个原因，一个等位基因可以对一个表型显性、对另一个表型隐性，*HBB*$^{S}$ 即是。
:::

## 复等位基因

一个二倍体个体对一个基因至多携带两个等位基因，但一个群体可能携带许多。有 $k$ 个等位基因时，有 $k$ 种纯合子与 $\binom{k}{2} = k(k-1)/2$ 种杂合子，所以

$$
\text{基因型数目} = k + \frac{k(k-1)}{2} = \frac{k(k+1)}{2}.
$$ {#eq-genotypes}

**ABO 血型**系统由卡尔·兰德施泰纳（Karl Landsteiner）于 1900–01 年发现，是教科书式的例子。基因 *ABO* 编码一种糖基转移酶，把糖加到红细胞及其他细胞表面的糖类（H 抗原）上。$I^A$ 等位基因加 *N*-乙酰半乳糖胺（生成 A 抗原），$I^B$ 加半乳糖（B 抗原）；两种酶在少数几个氨基酸上不同，改变了所转移的糖。常见的 $i$（或 O）等位基因带一个移码缺失，不产生有活性的酶。于是 $I^A$ 与 $I^B$ 彼此共显性，二者对 $i$ 均为显性：

| 基因型 | $I^AI^A$、$I^Ai$ | $I^BI^B$、$I^Bi$ | $I^AI^B$ | $ii$ |
|---|---|---|---|---|
| 血型（表型） | A | B | AB | O |

三个等位基因给 $3\cdot4/2 = 6$ 种基因型，却只有四种表型。

**显性系列**是按显性排成序的等位基因集合。兔毛色是标准例子：全色（*C*）> 青吉拉（$c^{ch}$）> 喜马拉雅（$c^{h}$）> 白化（$c$），全为酪氨酸酶基因的等位基因。有些基因座的等位基因数目极其庞大。许多开花植物的自交不亲和 *S* 基因座在一个群体中就有几十个等位基因，因为携带花柱中已有等位基因的花粉会被拒绝，这有利于稀有等位基因；人的主要组织相容性（HLA）基因座已知等位基因数以千计。

::: example 血型杂交 {#ex-abo}
一个 A 血型的人，其母亲为 O 型，与一个 B 血型的人婚配，其父亲为 O 型。他们的子女可能有什么血型，比例如何？
::: solution
A 型亲本从 O 型母亲继承了 $i$，故为 $I^Ai$；同理 B 型亲本为 $I^Bi$。杂交 $I^Ai \times I^Bi$ 给

$$
I^AI^B : I^Ai : I^Bi : ii = \tfrac14 : \tfrac14 : \tfrac14 : \tfrac14 ,
$$

即 AB : A : B : O = $1:1:1:1$。一对亲本的子女出现四种等比例的表型，是共显性等位基因座位上两个不同双重杂合子相交的标志。
:::
:::

## 致死等位基因

1905 年，吕西安·居诺（Lucien Cuénot）发现黄毛鼠（*agouti* 基因座的显性等位基因 $A^Y$）从不真实遗传。黄 × 黄总是产生黄毛与非黄毛仔鼠，比例约为 $2:1$，而不是 $3:1$。威廉·卡斯尔（William Castle）与克拉伦斯·利特尔（Clarence Little）在 1910 年解释了这一结果：$A^YA^Y$ 胚胎在发育早期死亡，纯合子从出生过。黄 × 黄所产仔数相应少约四分之一。

::: proposition 隐性致死的 $2 : 1$ 比例 {#prop-lethal}
设等位基因 $L$ 有显性的可见效应且纯合致死。则在 $Ll \times Ll$ 存活后代中，

$$
Ll : ll = \tfrac23 : \tfrac13 ,
$$

所以可见表型以 $2:1$ 比例出现，且每个存活并表现显性表型的个体都是杂合子。
:::

::: proof
选择之前合子为 $LL : Ll : ll = \tfrac14 : \tfrac12 : \tfrac14$。以存活为条件（除去 $LL$），

$$
P(Ll \mid \text{存活}) = \frac{1/2}{1/2 + 1/4} = \frac23, \qquad P(ll \mid \text{存活}) = \frac{1/4}{3/4} = \frac13 .
$$
:::

分子解释出现在 1990 年代：$A^Y$ 等位基因是一个约 170 kb 的缺失，它移除了邻近基因 *Raly* 的大部分，并把 *agouti* 置于 *Raly* 启动子的控制之下。黄色毛皮来自 agouti 蛋白的过表达（显性功能获得）；胚胎致死来自 *Raly* 的丧失（隐性功能丧失）。一个突变，两种显性相反的表型——**基因多效性**（一个基因影响多个性状）的清楚实例。许多隐性致死等位基因在杂合子毫无可见效应，只因两个携带者的后代有四分之一不能发育而被发现。

::: example 检验 $2 : 1$ 对 $3 : 1$ {#ex-lethal}
两只短尾小鼠杂交产下短尾仔鼠 236 只、正常尾 124 只。检验以下假说：(a) 短尾是简单显性（$3:1$）；(b) 短尾为显性并伴隐性致死效应（$2:1$）。
::: solution
$n = 360$。(a) $E = 270,\ 90$：$X^2 = \dfrac{34^2}{270} + \dfrac{34^2}{90} = 4.28 + 12.84 = 17.13$，$\nu = 1$，$p \approx 3.5\times10^{-5}$。拒绝。(b) $E = 240,\ 120$：$X^2 = \dfrac{16}{240} + \dfrac{16}{120} = 0.067 + 0.133 = 0.20$，$p = 0.65$。数据与隐性致死一致。进一步的检验是测交：若短尾鼠全为杂合子，则每次短尾 × 正常杂交都应给 $1:1$，且短尾鼠永不真实遗传。
:::
:::

## 外显率、表现度与环境

即使在单个基因座，同一基因型也非总产生同一表型。

::: definition 外显率与表现度 {#def-penetrance}
一个基因型的**外显率**是该基因型个体中表现出相关表型的比例。比例为 1 时该基因型**完全外显**，否则为**不完全外显**。**表现度**是在表现者之中表型被表现的程度；**可变表现度**指患病个体在严重程度上彼此不同。
:::

不完全外显与可变表现度来自其他基因（**遗传背景**）、环境以及发育中的偶然事件。它们在系谱（[[genetics/sex-linkage-pedigrees]]）中很重要：不完全外显的显性等位基因可能看似隔代传递。

表型对环境的依赖用**反应规范**概括：一个基因型在一系列环境中产生的表型集合。喜马拉雅兔是生动的例子。$c^{h}$ 等位基因编码温度敏感的酪氨酸酶，只在约 33 °C 以下才有活性，所以色素只在较凉的末端形成——耳、鼻、脚与尾。若把背上的一块毛剃掉并在毛重新长出时保持该处低温，长出的毛是黑色的。暹罗猫携带类似的等位基因。同样的原理支撑着黑腹果蝇（*Drosophila*）、酵母与细菌中的**温度敏感突变**，这类突变对遗传学极其宝贵，因为改变温度就能开关突变表型。

::: warning "一个性状多少来自基因、多少来自环境？"
对个体而言，这个问题没有答案。喜马拉雅兔的黑耳朵既需要 $c^{h}$ 等位基因也需要寒冷环境；缺任何其一都不产生，因此把毛色拆成遗传部分与环境部分没有意义。**能够**度量的是：在特定群体与环境中，个体间的**变异**有多少与遗传差异相关联——即 [[population-genetics/quantitative-traits]] 的遗传率。一个性状在机制上可以完全由基因决定，仍会被环境彻底改变；人的苯丙酮尿症由苯丙氨酸羟化酶缺失引起，是遗传病而其后果取决于饮食的经典案例。
:::

## 基因间的相互作用

多数性状依赖多个基因。当两个基因座影响同一性状，它们的等位基因会以改变双杂合杂交 $9:3:3:1$ 的方式相互作用。基因型仍完全按孟德尔定律预言的方式分离组合；改变的是九个基因型类别如何归并进表型。

### 相互作用产生的新表型

威廉·贝特森（William Bateson）与雷金纳尔德·庞尼特（Reginald Punnett）在 1905–08 年发现鸡的冠形取决于两个基因座。玫瑰冠（*R-pp*） × 豌豆冠（*rrP-*）得 F1 为一种新类型胡桃冠，F2 为胡桃冠（*R-P-*） : 玫瑰冠（*R-pp*） : 豌豆冠（*rrP-*） : 单片冠（*rrpp*）＝ $9:3:3:1$。仍可区分四种表型，所以比例未变，但其中两种（胡桃冠与单片冠）任何亲本都没有：它们是相互作用的产物。

### 上位效应

::: definition 上位效应 {#def-epistasis}
**上位效应**是基因座间的相互作用，其中一个基因座的基因型掩盖或改变另一基因座基因型的表型效应。实施掩盖的基因座对其被掩盖者**上位**，被掩盖者为**下位**。在群体遗传学与数量遗传学中，该词用法更宽，指不同基因座对性状效应偏离可加性的任意情形。
:::

上位效应不同于显性。显性是*同一*基因座上两个等位基因之间的相互作用；上位效应是*不同*基因座等位基因之间的相互作用。

修饰后的比例都可以用同一方法导出。从双杂合 F2 的四个类别出发，

$$
A\text{-}B\text{-} : A\text{-}bb : aaB\text{-} : aabb = 9 : 3 : 3 : 1 ,
$$

依据生物学判断哪些类别表型相同，再把其概率相加。

::: proposition 修饰后的双因子比例 {#prop-epistasis}
对 *Aa Bb* × *Aa Bb* 的 F2（基因座未连锁，每个基因座完全显性）：
1. **隐性上位** —— *aa* 掩盖 B 基因座的效应 —— 得 $9:3:4$。
2. **重复隐性上位（互补基因）** —— 显性表型要求*两个*基因座至少各有一个显性等位基因 —— 得 $9:7$。
3. **显性上位** —— *A-* 掩盖 B 基因座的效应 —— 得 $12:3:1$。
4. **显性抑制** —— *A-* 抑制 *B-* 的效应，且 *aabb* 与被抑制类别表型相同 —— 得 $13:3$。
5. **重复显性基因** —— *任一*基因座的显性等位基因给同一表型 —— 得 $15:1$。
6. **具累加效应的重复基因** —— 任一基因座有一个显性等位基因给中间表型，两个基因座都有显性等位基因给极端表型 —— 得 $9:6:1$。
:::

::: proof
每种情形都是把 $9:3:3:1$ 的类别归并。

1. 隐性上位：*A-B-* 表现 B-显性表型（9），*A-bb* 表现 B-隐性表型（3），*aaB-* 与 *aabb* 均表现 *aa* 的被掩盖表型：$3 + 1 = 4$。故 $9:3:4$。
2. 互补基因：只有 *A-B-*（9）具显性表型；*A-bb*、*aaB-* 与 *aabb* 皆无：$3 + 3 + 1 = 7$。故 $9:7$。
3. 显性上位：*A-B-* 与 *A-bb* 共有由 *A-* 决定的表型：$9 + 3 = 12$；*aaB-*（3）与 *aabb*（1）由 B 基因座区分。故 $12:3:1$。
4. 显性抑制：*B-* 的表型只出现在 *aaB-*（3）；其余 $9 + 3 + 1 = 13$ 共享另一种表型。故 $13:3$。
5. 重复显性基因：凡至少含一个显性等位基因的类别 $9 + 3 + 3 = 15$，对 *aabb*（1）。故 $15:1$。
6. 累加：*A-B-*（9），*A-bb* 与 *aaB-* 合计（$3 + 3 = 6$），*aabb*（1）。故 $9:6:1$。

每种情形分母仍为 16，因为底层的基因型频率就是[[genetics/mendelian-inheritance#prop-assortment]]的频率。
:::

每一种归并都对应一种生物学机制，认出适用哪一种是有用的技能。

| 比例 | 机制 | 经典例子 |
|---|---|---|
| $9:3:4$ | 隐性上位 | 拉布拉多猎犬毛色；小鼠 agouti/白化 |
| $9:7$ | 同一途径的两步，缺一不可 | 香豌豆 *Lathyrus odoratus* 花色 |
| $12:3:1$ | 显性上位 | 夏南瓜 *Cucurbita pepo*（西葫芦）的果实颜色 |
| $13:3$ | 显性抑制基因 | 白来航鸡 × 白怀恩多特鸡的白色羽毛 |
| $15:1$ | 重复基因 | 荠菜 *Capsella bursa-pastoris* 荚果形状 |
| $9:6:1$ | 累加效应重复基因 | 夏南瓜果形（盘状 : 球状 : 长形） |

::: example 拉布拉多猎犬：$9 : 3 : 4$ {#ex-labrador}
拉布拉多猎犬的 *B* 基因座（基因 *TYRP1*）决定真黑素色素是黑色（*B-*）还是棕色（*bb*，"巧克力色"），*E* 基因座（黑素皮质素受体 1 基因 *MC1R*）决定真黑素是否沉积到毛中：*ee* 狗无论 *B* 基因型如何都是黄色。两只均为 *Bb Ee* 的黑狗产下许多仔犬。预期黑、巧克力、黄仔犬各占什么比例？黄色仔犬中 *bb* 占什么比例？
::: solution
黑色需要 *B-E-*：$\tfrac34\cdot\tfrac34 = \tfrac9{16}$。巧克力色是 *bbE-*：$\tfrac14\cdot\tfrac34 = \tfrac3{16}$。黄色是 *ee*，与 *B* 无关：$\tfrac14 = \tfrac4{16}$，由 *B-ee*（$\tfrac3{16}$）与 *bbee*（$\tfrac1{16}$）构成。比例为黑 : 巧克力 : 黄 = $9:3:4$。黄色仔犬中比例 $\dfrac{1/16}{4/16} = \tfrac14$ 为 *bb*。这些狗看起来与其他黄狗一样，但鼻与唇的色素是棕色而非黑色——*b* 等位基因并未完全隐匿，这就是仔细鉴定有时能分出四类的原因。
:::
:::

::: example 香豌豆的互补基因：$9 : 7$ {#ex-sweet-pea}
贝特森、桑德斯与庞尼特杂交香豌豆两个纯系白花品系，得到紫花 F1；F2 中紫花与白花之比接近 $9:7$。(a) 用一条生化途径解释该结果。(b) 一个 700 株的 F2 含紫花 382、白花 318。检验对 $9:7$ 与对 $1:1$ 的符合度。
::: solution
(a) 设紫色花青素色素分两步合成：无色前体 $\xrightarrow{\text{酶 A}}$ 无色中间物 $\xrightarrow{\text{酶 B}}$ 紫色，两种酶由两个未连锁基因座的显性等位基因编码。一个白花品系是 *AAbb*（阻在第 2 步），另一个是 *aaBB*（阻在第 1 步）。F1 为 *AaBb*，两种酶俱全：紫色。F2 中只有 *A-B-*（$\tfrac9{16}$）制造色素；其余十六分之七在一处或两处受阻。两个白花亲本相互**互补**——这是 [[genetics/genes-and-mutation]] 中互补测验的基础。

(b) 对 $9:7$：$E = 700\times\tfrac9{16} = 393.75$ 与 $306.25$；$X^2 = \dfrac{11.75^2}{393.75} + \dfrac{11.75^2}{306.25} = 0.351 + 0.451 = 0.80$，$\nu = 1$，$p = 0.37$：一致。对 $1:1$：$E = 350,\ 350$；$X^2 = \dfrac{32^2}{350}\times2 = 5.85$，$p = 0.016$：在 5 % 水平拒绝。注意样本较小时两个假说无法区分；相差不大的比例需要大的 F2 群体。
:::
:::

::: example 夏南瓜：$12 : 3 : 1$ {#ex-squash}
夏南瓜中，显性等位基因 *W* 使果实白色而不论第二个基因座的基因型如何；该基因座上 *ww* 植株中 *Y-* 给黄色、*yy* 给绿色果实。(a) *WwYy* 自交的 F2 比例如何？(b) 一株白色 F2 植株与 *wwyy* 测交，后代白果与黄果之比为 $1:1$，且无绿色。它的基因型是什么？
::: solution
(a) 白色：*W-*，$\tfrac34 = \tfrac{12}{16}$。黄色：*wwY-*，$\tfrac14\cdot\tfrac34 = \tfrac3{16}$。绿色：*wwyy*，$\tfrac1{16}$。比例 $12:3:1$。

(b) 测交后代是白色（*Ww…*）与否。一半白色说明该植株为 *Ww*。非白色的另一半全是黄色，所以每个携带 *w* 的配子也都携带 *Y*；既然完全没有绿果，该植株必为 *YY*。其基因型为 *WwYY*。（*WwYy* 植株会给白 : 黄 : 绿 = $2:1:1$；*WWY-* 植株只给白色。）
:::
:::

::: quiz
两个纯系白花品系杂交得全为有色花的 F1，F2 共 160 株，其中有色 89 株。哪种解释最符合？
- [ ] 单基因，有色为隐性
- [ ] 隐性上位，$9:3:4$
- [x] 两个互补基因，$9:7$
- [ ] 显性上位，$12:3:1$
::: solution
白 × 白得有色 F1，说明两个白花品系在两个不同基因上各有缺陷而互相互补；F2 预期于是为 $9:7$，即 $160\times\tfrac9{16} = 90$ 株有色——与 89 非常接近。单隐性基因不可能使两个基因型相同的白亲本产生有色 F1，而 $9:3:4$ 与 $12:3:1$ 预言三个表型类别。
:::
:::

## 连续变异：许多小效应基因

身高、体重、产奶量、蝇鬃毛数目连续变异，没有可数的离散类别。二十世纪初，这似乎把研究此类性状统计学的"生物统计学家"（追随弗朗西斯·高尔顿）与孟德尔主义者分开了。调和始于植物实验。

1909 年，赫尔曼·尼尔松-埃勒（Herman Nilsson-Ehle）杂交红粒与白粒小麦品种。有的杂交 F2 给 $3:1$（红 : 白），有的给 $15:1$，一个给 $63:1$；而且在"红"F2 植株中他能区分若干深浅。他提出籽粒颜色取决于若干基因座，每个都有一个"红"等位基因加入固定量的色素，于是颜色深浅只取决于红色等位基因的*数目*。$63:1$ 意味着 F2 中白粒比例 $\tfrac1{64} = (\tfrac14)^3$：三个分离的基因座。

::: proposition 可加性多基因模型 {#prop-polygene}
设一个性状由 $n$ 个未连锁基因座决定，每个基因座有一个给表型加常量 $a$ 的等位基因与一个不加的等位基因，无显性、无上位、无环境效应。在两个极端纯合子杂交的 F2 中，个体"加"等位基因的数目 $K$ 服从二项分布

$$
P(K = j) = \binom{2n}{j}\left(\tfrac12\right)^{2n}, \qquad j = 0, 1, \dots, 2n,
$$ {#eq-polygene}

表型取 $2n+1$ 个值，F2 中与任一亲本同样极端的比例各为 $(\tfrac14)^n$。
:::

::: proof
F1 在全部 $n$ 个基因座杂合。每个 F2 个体接收 $2n$ 个等位基因（每个基因座从双亲各一），由分离与自由组合，每个独立地以概率 $\tfrac12$ 为加等位基因。加等位基因的计数因此是 $2n$ 重、概率 $\tfrac12$ 的二项分布。不含加等位基因的亲本极端比例为 $(\tfrac12)^{2n} = (\tfrac14)^n$，含 $2n$ 个的极端亦然。
:::

两个基因座时五个表型类别比为 $1:4:6:4:1$；三个基因座时 $1:6:15:20:15:6:1$。随 $n$ 增大，分布逼近正态曲线；当环境变异把每个类别模糊进其邻类，台阶便完全消失。

::: widget galton
rows: 6
balls: 640
p: 0.5
caption: 把每个球读作三基因座可加性杂交的一个 F2 个体，每一排钉柱读作它的 $2n = 6$ 个等位基因位之一：向右弹落即"加"等位基因（概率 $1/2$）。各桶按加等位基因数目计数个体，[[#eq-polygene]] 预言其比应为 $1:6:15:20:15:6:1$。增加排数以模拟更多基因座，观察直方图逼近正态曲线；F2 个体中与亲本同样极端者仅 $4^n$ 分之一。
:::

1916 年，爱德华·伊斯特（Edward East）以烟草 *Nicotiana longiflora* 的花冠长度证实了该模型：长 × 短的 F1 居中且整齐，F2 变异大得多，在 F2 内选择得到均值不同的 F3 家系——若变异源于许多分离的孟德尔基因座加上环境噪声，这正是预期的样子。两年后罗纳德·费希尔（Ronald Fisher）在数学上证明，生物统计学家测得的亲属间相关可由多基因座的孟德尔式遗传推出（1918）。对这类**数量性状**的分析——方差剖析、遗传率与选择响应——是 [[population-genetics/quantitative-traits]] 与 [[population-genetics/response-to-selection]] 的主题。

::: application 育种与医学中的上位与显性
本章的修饰比例不是奇谈。在犬与家畜育种中，毛色基因座的隐性上位解释了为何两只黑毛亲本能有黄色后代。在植物育种中，抗病或花色的互补基因解释了为何两个平淡无奇的品系杂交有时得到惊人的 F1。在人类遗传学中，一个基因座上等位基因的效应可强烈依赖另一基因座的基因型（"修饰基因"），这是同一等位基因在不同家系中外显率与严重程度不同的原因之一；临床例子见[医学图谱](/learn/medicine/lesson.php?c=genetics&l=mendelian-inheritance)。
:::

::: history
卡尔·兰德施泰纳（Karl Landsteiner）于 1900–01 年描述了 ABO 血型。吕西安·居诺（Lucien Cuénot）在 1905 年报告黄毛鼠不真实遗传，威廉·卡斯尔（William Castle）与克拉伦斯·利特尔（Clarence Little）在 1910 年把 $2:1$ 比例归因于纯合子胚胎死亡。威廉·贝特森（William Bateson）、伊迪丝·桑德斯（Edith Saunders）与雷金纳尔德·庞尼特（Reginald Punnett）在向皇家学会进化委员会的报告中描述了鸡的冠形与白香豌豆的 $9:7$ 比例（1905–08）；贝特森至迟在 1909 年的《孟德尔遗传原理》（*Mendel's Principles of Heredity*）中已引入 epistatic（上位）一词。赫尔曼·尼尔松-埃勒（Herman Nilsson-Ehle）的小麦杂交（1909）与爱德华·伊斯特（Edward East）的烟草实验（1916）确立了连续性状的多因子假说，罗纳德·费希尔（Ronald Fisher）的论文《在孟德尔遗传假定下亲属间的相关》（*The correlation between relatives on the supposition of Mendelian inheritance*，1918）把孟德尔遗传学与生物统计学连在一起。理查德·沃尔特雷克（Richard Woltereck）在 1909 年创造了 Reaktionsnorm，即反应规范。
:::

::: summary
- 显性是杂合子与纯合子表型之间的关系：完全、不完全（杂合子中间型，F2 $1:2:1$）、共显（两种表型俱在）或超显。随所考察表型层次的不同而不同。
- 单倍足效基因的功能丧失等位基因为隐性；显性等位基因经由单倍剂量不足、显性负效应或功能获得起作用。
- 有 $k$ 个等位基因的基因座有 $k(k+1)/2$ 种基因型；ABO 有三个等位基因、六种基因型、四种表型。
- 带显性可见效应的隐性致死在存活者中给 $2:1$。
- 外显率（谁表现表型）与表现度（表现多强）取决于遗传背景、环境与机会；反应规范描述一个基因型在各环境中的表型。
- 上位把 $9:3:3:1$ 归并：$9:3:4$（隐性）、$9:7$（互补）、$12:3:1$（显性）、$13:3$、$15:1$、$9:6:1$。比例指向途径。
- 连续性状来自多基因小效应加环境：可加模型中 F2 加等位基因计数服从二项($2n$, ½)，各有比例 $(\tfrac14)^n$ 与双亲相似。
:::

## 练习

::: exercise 基因型计数 {level=1 check="10"}
一个基因在群体中有四个等位基因。该基因座在二倍体可能有多少种不同基因型？
::: solution
由[[#eq-genotypes]]，$4\cdot5/2 = 10$：四种纯合子与六种杂合子。
:::
:::

::: exercise 粉红金鱼草 {level=1 check="1/2"}
两株粉红金鱼草（红白等位基因不完全显性）杂交。其后代粉红比例是多少？
::: solution
粉红是杂合子，占杂合子 × 杂合子杂交后代的 $\tfrac12$（[[genetics/mendelian-inheritance#eq-121]]）。
:::
:::

::: exercise 一个家庭的血型 {level=1}
AB 血型者与 O 血型者生子女。子女可能有什么血型？AB 血型的父/母可能生 O 型孩子吗？
::: solution
$I^AI^B \times ii$ 给 $I^Ai$（A 型）与 $I^Bi$（B 型）等比例。子女不可能是 AB 型或 O 型。AB 血型亲本必传 $I^A$ 或 $I^B$，故不能有 O 型（$ii$）孩子——罕见的例外除外，如 *cis*-AB 等位基因（一条染色体携带能制造两种抗原的酶），或孟买血型（独立 *FUT1* 基因座上的 *hh* 基因型阻止 *ABO* 酶发挥作用的 H 物质形成）。
:::
:::

::: exercise 黄色检验 {level=2 check="2/3"}
黄毛鼠（$A^Ya$）相互交配。活产仔鼠中黄毛比例是多少？
::: solution
由[[#prop-lethal]]，存活者中 $\tfrac23$ 为 $A^Ya$（黄毛），$\tfrac13$ 为 $aa$。
:::
:::

::: exercise 黄色拉布拉多 {level=2 check="1/4"}
一只巧克力色拉布拉多（*bbEe*）与一只黄色拉布拉多（*Bbee*）交配。预期仔犬中黑色比例是多少？
::: solution
黑色需要 *B-E-*。由 *bb* × *Bb*，$P(B\text{-}) = \tfrac12$；由 *Ee* × *ee*，$P(E\text{-}) = \tfrac12$。所以 $P(\text{黑色}) = \tfrac14$。其余仔犬为巧克力色（*bbEe*，$\tfrac14$）与黄色（*ee*，$\tfrac12$）。
:::
:::

::: exercise 哪个比例？ {level=2}
一株盘状果南瓜与一株长形果南瓜杂交得盘状果 F1。F2 含盘状 89、球状 62、长形 9 株。(a) 提出一个遗传学解释并用 χ² 检验。(b) 基因型 *AAbb* 的球状 F2 植株与基因型 *aaBB* 的一株杂交，预期 F2 比例如何？
::: solution
(a) 三个类别且极端亲本类型稀少，提示 $9:6:1$：两个基因座，盘状 *A-B-*，球状 *A-bb* 或 *aaB-*，长形 *aabb*。$n = 160$，$E = 90,\ 60,\ 10$；$X^2 = \dfrac{1}{90} + \dfrac{4}{60} + \dfrac{1}{10} = 0.011 + 0.067 + 0.100 = 0.18$，$\nu = 2$，$p = 0.91$：拟合极好。（$9:3:4$ 假说给 $X^2 = 58$，被拒绝。）

(b) *AAbb* × *aaBB* 给盘状果的 *AaBb* F1——两个球状亲本产生盘状后代——F2 再次以 $9:6:1$ 分离。
:::
:::

::: exercise 几个基因座？ {level=2 check="4"}
两个自交系在一个数量性状上不同。一个 2048 株的 F2 中，约 8 株与每一亲本同样极端。按[[#prop-polygene]]的可加多基因模型，估计分离基因座的数目。
::: solution
与一个亲本同样极端的比例 $8/2048 = 1/256 = (\tfrac14)^4$，故 $n = 4$。实际上这一估计很粗：环境变异模糊类别，基因座效应不等，连锁会使极端类型更稀少。
:::
:::

::: exercise 解读 $13 : 3$ {level=3}
两个纯系白色鸡品种，一个为显性白色羽毛，一个为隐性白色，相互杂交。F1 全白，F2 含白羽 131 只、有色 29 只。(a) 提出一个两基因座的解释，给出亲本与有色 F2 个体的基因型。(b) 检验它。(c) 白色 F2 个体中，若与隐性白品种测交，有多大比例会产生一些有色后代？
::: solution
(a) 设 *C* 为有色所必需（*cc* 为隐性白），*I* 为色的显性抑制子。显性白品种为 *IICC*，隐性白品种 *iicc*；F1 *IiCc* 因 *I* 而白。有色 F2 个体为 *iiC-*（$\tfrac3{16}$）；其余（$\tfrac{13}{16}$）为白。

(b) $E = 160\times\tfrac{13}{16} = 130$ 与 $30$：$X^2 = \tfrac1{130} + \tfrac1{30} = 0.041$，$p = 0.84$。与 $13:3$ 一致。

(c) 与 *iicc* 测交只在被测个体能传递 *iC* 配子，即同时携带 *i* 与 *C* 时产生有色后代。白色 F2 基因型（共 $\tfrac{13}{16}$）中这些是 *IiCC*（$\tfrac2{16}$）与 *IiCc*（$\tfrac4{16}$）；*iicc* 为白但不携 *C*。故答案为 $\dfrac{2+4}{13} = \dfrac6{13}$。其余（*IICC*、*IICc*、*IIcc*、*Iicc*、*iicc*：$1+2+1+2+1 = 7$ 个十六分之一）只产生白色后代。
:::
:::

::: exercise 基因还是环境？ {level=3}
一个对某突变纯合的黑腹果蝇（*Drosophila*）品系在 25 °C 饲养时 70 % 的果蝇翅异常，在 18 °C 时 10 %；野生型果蝇在两个温度下均正常。(a) 描述该突变基因型的外显率。(b) 一位学生主张该异常"在 25 °C 有 70 % 是遗传的，在 18 °C 有 10 % 是遗传的"。解释哪里错了。(c) 对温度效应提出一个分子解释和一个检验实验。
::: solution
(a) 该基因型具有不完全的、温度依赖的外显率：25 °C 时 0.70，18 °C 时 0.10。

(b) 这两个数字是同一基因型在两种环境中的外显率，不是成因的份额。异常需要突变基因型（野生型果蝇从不表现）*并且*被较高温度促进；两者都是必要的成因，且各自的效应依赖对方（基因型-环境互作）。在突变品系内部所有果蝇基因型相同，所以它们之间的变异完全来自环境与发育机会，与基因无关。

(c) 该突变可能使蛋白质稳定性下降，以致在低温能正确折叠或工作而在高温不能（温度敏感等位基因）。一种检验是温度转变实验：在发育的不同阶段把果蝇在 18 °C 与 25 °C 之间转移，找出温度敏感时期，从而揭示基因产物在发育何时被需要。生化上可比较突变蛋白与野生型蛋白的热稳定性。
:::
