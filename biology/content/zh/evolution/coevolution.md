没有哪个物种是独自进化的。选择猎豹速度的环境里包括羚羊，而羚羊的速度又被猎豹选择；植物的化学防御被取食它的昆虫选择，昆虫的解毒酶又被植物选择；花的形状被它的传粉者选择，传粉者的口器又被花选择。当两条谱系互相施加选择时，每一方适应的目标都随另一方的适应而移动，其结果就是**协同进化**（coevolution）：不断升级的军备竞赛、永不落定的循环，以及亲密到谁也离不开谁的伙伴关系。

本章考察敌对者之间——捕食者与猎物、宿主与寄生虫——以及互利共生者之间的协同进化。我们使用 [[evolution/natural-selection]] 的选择模型，但让适合度依赖另一物种，这使得选择成为**频率依赖**的，并考察它为什么产生循环；我们考察军备竞赛与红皇后假说的证据，包括红皇后在解释有性生殖方面的作用；讨论毒力的进化；最后问互利共生如何抵制"作弊"。生态相互作用本身在 [[ecology]] 中讨论。

## 什么是协同进化

::: definition 协同进化 {#def-coevolution}
**协同进化**是相互作用物种之间的相互进化改变：一个物种响应另一物种的某性状而进化出某性状，接着第二物种又对第一物种的改变作出进化响应（Daniel Janzen，1980）。**成对（特异）协同进化**（pairwise coevolution）涉及两个物种；**弥散（群伙式）协同进化**（diffuse coevolution）则涉及共同施加选择的类群，如多种植食昆虫与多种植物。**协同成种**（cospeciation）是两个相互作用类群的谱系平行地分裂，以致两者的系统发育树彼此吻合。
:::

Janzen 的定义是刻意严格的。两个物种彼此适配，并不是协同进化的证据：一只蜂可以访问一朵为它而适应的花，而蜂自身并未适应那朵花。协同进化要求相互选择与相互响应的证据，这就是为什么它在进化迅速的系统中——细菌及其病毒、植物与其病原物——比在长寿的动物中更容易证实。

这一思想本身要古老得多。1862 年，在一本关于兰科传粉的书中，达尔文（Darwin）描述了马达加斯加的彗星风兰 *Angraecum sesquipedale*（大彗星风兰）：它的花蜜藏在约 30 厘米长的花**距**底部，并预言必定存在一种喙与距差不多长的蛾为它传粉。1903 年，天蛾 *Xanthopan morganii praedicta* 被描述——它的亚种名就是为纪念这一预言而取的——1990 年代终于拍到它访问这种兰花的镜头。长距受偏爱，因为喙差一点够不到花蜜的蛾必须把头抵向花朵，从而沾上花粉；长喙受偏爱，因为它能吸到更多花蜜。每一方都促成另一方的加长。

Paul Ehrlich 与 Peter Raven（1964）在对蝶类与其寄主植物的研究中把这一思想一般化。蝶的各科通常取食带有特征性化学防御的特定植物科——粉蝶亚科（Pierinae）取食十字花科及其近缘类群，后者制造硫苷（glucosinolates）。他们提出了"**逃离与辐射**"（escape-and-radiate）过程：一个植物谱系进化出新防御，"逃离"其植食者并发生分化；迟早某个昆虫谱系进化出破解防御的办法，又在新植物上辐射。粉蝶亚科与十字花目（Brassicales）的系统发育研究（Hanna Wheat 及同事，2007；Patrick Edger 及同事，2015）支持了硫苷与粉蝶使其失活的酶之间的这一图景。

## 捕食者与猎物之间的军备竞赛

北美西部的束带蛇 *Thamnophis sirtalis* 捕食粗皮蝾螈 *Taricha granulosa*，后者的皮肤含有河豚毒素（TTX），一种阻断电压门控钠通道的神经毒素（[[cell-biology/membrane-transport]]）。毒性最强的种群中的一只蝾螈，所含毒素就足以毒死许多条蛇。Edmund Brodie 子与孙发现，这些种群中的蛇对 TTX 的抵抗力比没有毒蝾螈地区的蛇高数百倍。抗性源于蛇骨骼肌钠通道 Na$_\mathrm{v}$1.4 上 TTX 结合位点的氨基酸替换（Shana Geffeney 及同事，2002、2005）。抗性是有代价的：抗性很强的蛇爬得更慢。就整个分布范围而言，蝾螈毒性与蛇抗性在某些地区相互匹配——协同进化的"热点"——在另一些地区则不匹配，那里一方已单独升级，或双方都根本没有升级。

这种地理格局是普遍的。John Thompson 的**协同进化地理镶嵌理论**（geographic mosaic theory of coevolution，1994、2005）提出：相互作用的强度甚至方向因地而异，于是相互选择在一些群体中很强、在另一些群体中不存在，而它们之间的基因流再把各种结局混合起来。因此协同进化最好跨多个群体研究，而不是在一个地方研究。

捕食者—猎物的军备竞赛也能在化石记录中读出。Geerat Vermeij 的**升级假说**（escalation，1987）指出，整个中生世碎壳捕食者（蟹、鳐、硬骨鱼）不断增加，腹足类也平行地演化出更厚、带棘、盘绕更紧的壳——"**中生代海洋革命**"。

### 生态背景

军备竞赛在种群动态的背景上展开，而种群动态本身就可能是循环的。关于捕食者与其猎物的最简单模型，由 Alfred Lotka（1925）与 Vito Volterra（1926）提出。

::: proposition Lotka–Volterra 捕食者–猎物模型 {#prop-lv}
设 $N$ 为猎物数、$P$ 为捕食者数。若无捕食者时猎物以速率 $r$ 指数增长，被杀速率 $aNP$；捕食者以效率 $b$ 把所食猎物转化为新捕食者，以速率 $m$ 死亡，则

$$
\frac{dN}{dt} = rN - aNP,\qquad \frac{dP}{dt} = baNP - mP.
$$ {#eq-lv}

内部平衡为 $N^* = m/(ba)$，$P^* = r/a$。其余一切正解都是环绕它的闭曲线循环，捕食者峰值约落后猎物峰值四分之一个周期。假设：猎物无密度依赖、线性（I 型）功能反应、无年龄结构、参数恒定——这使这些中性循环在结构上是脆弱的；若猎物有自我限制，循环便成为衰减螺旋。
:::

猎物的平衡点由*捕食者*的参数（$m$、$a$、$b$）决定，而捕食者的平衡点由猎物的增长率决定——一个反直觉的特征，对协同进化却要紧：若猎物进化出更快的生长，模型预言的是更多捕食者，而不是更多猎物。

::: widget phaseplane
f: r*x - a*x*y
g: b*a*x*y - m*y
x: 0, 600
y: 0, 150
sliders: r=0.5:0.1:1:0.05; a=0.01:0.005:0.02:0.001; b=0.1:0.05:0.3:0.01; m=0.2:0.1:0.5:0.01
points: 300, 50; 400, 50; 200, 20
caption: Lotka–Volterra 模型[[#eq-lv]]，横轴为猎物 $N$，纵轴为捕食者 $P$。默认参数下平衡点在 $N^* = m/(ba) = 200$、$P^* = r/a = 50$，即两条零增长线相交处。轨线是环绕它的闭合圈：猎物先增，然后捕食者，然后猎物崩溃，然后捕食者。点击可开启新轨线。增大猎物的增长率 $r$，注意平衡点*向上*移动（捕食者更多），而不是向右。
:::

::: example 捕食者与猎物的平衡 {#ex-lv}
对参数 $r = 0.5$ 每月、$a = 0.01$ 每捕食者每月、$b = 0.1$、$m = 0.2$ 每月，求平衡点。若猎物进化出使攻击率 $a$ 减半的防御，平衡点如何变化？
::: solution
$N^* = m/(ba) = 0.2/(0.1\times0.01) = 200$ 只猎物，$P^* = r/a = 0.5/0.01 = 50$ 只捕食者。把 $a$ 减半为 0.005，两者都加倍：$N^* = 400$，$P^* = 100$。猎物的防御有利于猎物种群，但它同时养活了多一倍的捕食者，而后者反过来选择着能够克服防御的捕食者：这是一场猎物每改进一分、对捕食者的选择压力就加大一分的军备竞赛。
:::
:::

## 宿主与寄生虫

寄生虫——包括病原物——通常比宿主世代更短、群体更大，且受到极强的感染选择。宿主则受到抗性选择。相互作用的遗传学决定动态，两个理想化模型框定了可能性。

::: definition 基因对基因与等位基因匹配相互作用 {#def-gfg}
在**基因对基因**（gene-for-gene）相互作用中——Harold Flor 于 1940–1950 年代在亚麻（*Linum usitatissimum*）与其锈菌 *Melampsora lini* 中发现——携带**抗性**等位基因 $R$ 的宿主认出携带相应**无毒**等位基因 $Avr$ 的病原物并加以抵抗；其余一切组合都导致感染。失去了 $Avr$ 的病原物（**毒性**，virulent）能感染该基因座上的所有宿主。在**等位基因匹配**（matching-alleles）相互作用中，感染需要"匹配"：一个寄生者基因型只能感染具有相应基因型的宿主，如同自我/非我识别系统；不存在能感染所有宿主的寄生者基因型。
:::

在两个模型中，宿主基因型的适合度取决于能感染它的寄生者基因型有多常见，寄生者基因型的适合度取决于它能感染的宿主有多常见。一个常见的宿主等位基因会成为能感染它的那些寄生者的目标，寄生者随之增多，于是这个常见宿主等位基因下降：**负频率依赖选择**，带有时间滞后。结果是等位基因频率的循环。

::: example 等位基因匹配选择的一代 {#ex-matching}
一个单倍体宿主有等位基因 $H_1$ 与 $H_2$，频率 $x = 0.7$ 与 $0.3$；一个寄生者有 $P_1$（只感染 $H_1$）与 $P_2$（只感染 $H_2$），频率 $y = 0.6$ 与 $0.4$。感染使宿主适合度降低 $s = 0.3$；寄生者遇到不能感染的宿主时适合度降低 $c = 0.5$。设每个宿主遇到一个随机寄生者，反之亦然，求一代之后的频率。
::: solution
宿主适合度：$H_1$ 遇到 $P_1$ 时被感染，故 $w_{H_1} = 1 - sy = 1 - 0.3\times0.6 = 0.82$；$w_{H_2} = 1 - s(1 - y) = 1 - 0.12 = 0.88$。由[[evolution/natural-selection#eq-haploid]]，

$$
x' = \frac{0.7\times0.82}{0.7\times0.82 + 0.3\times0.88} = \frac{0.574}{0.838} = 0.685.
$$

寄生者适合度：$P_1$ 遇到 $H_1$ 时成功，故 $w_{P_1} = (1 - c) + cx = 0.5 + 0.35 = 0.85$，$w_{P_2} = 0.5 + 0.15 = 0.65$。于是

$$
y' = \frac{0.6\times0.85}{0.6\times0.85 + 0.4\times0.65} = \frac{0.51}{0.77} = 0.662.
$$

常见的宿主等位基因 $H_1$ 下降，因为攻击它的寄生者常见；寄生者 $P_1$ 上升，因为它的宿主常见。迭代（见下）得到循环：$P_1$ 持续上升直到 $H_1$ 变得稀少，然后 $P_1$ 下降，$H_1$ 回升，如此往复。
:::
:::

把[[#ex-matching]]的模型迭代 60 代（用 Python，不含任何随机性），每 5 代给出 $(x, y)$ = (0.70, 0.60)、(0.53, 0.80)、(0.29, 0.71)、(0.24, 0.31)、(0.48, 0.12)、(0.77, 0.21)、(0.84, 0.70)、(0.61, 0.94)、(0.25, 0.92)、(0.10, 0.54)、(0.18, 0.08)、(0.53, 0.02)、(0.86, 0.07)。循环的周期约 30 代，且宿主循环领先寄生者循环（宿主等位基因在第 30 代达峰，寄生者等位基因在第 35 代）。注意其振幅在**增长**：在离散世代中振荡向外盘旋，直到某个等位基因几乎丢失——在真实群体中，那时漂变会把它移除。在连续时间中同一模型给出中性循环，如下图；突变、群体间迁移或抗性的代价可使循环稳定。

### 红皇后

1973 年，Leigh Van Valen 分析了化石属与科的延续时间，发现在一个类群内部，灭绝概率大致恒定，与一条谱系已经存在了多久无关（[[evolution/macroevolution]]）。谱系并没有越来越善于存活。他提出：每个物种的环境都在不断恶化，因为它的竞争者、捕食者与寄生虫都在进化，所以它必须不断进化，才能仅仅使自己的适合度保持不变——就像刘易斯·卡罗尔（Lewis Carroll）《镜中奇遇》（*Through the Looking-Glass*）中的红皇后对爱丽丝说的那样："你必须用尽全力奔跑，才能留在原地。"**红皇后假说**（Red Queen hypothesis）如今更宽泛地指敌对者之间无休止的协同进化。

最直接的检验来自繁殖迅速生物的实验。Angus Buckling 与 Paul Rainey（2002）把细菌 *Pseudomonas fluorescens* SBW25 与烈性噬菌体 $\Phi$2 共培养约 50 次传代，并冻存样品。用各时间点复苏的细菌检测过去、现在、未来的噬菌体（反之亦然）显示：细菌对过去的噬菌体更具抗性，噬菌体对过去的细菌感染性更强：这是一场双方的打击与防御范围都不断棘紧升级的军备竞赛。在水蚤大型溞（*Daphnia magna*）与其细菌寄生虫 *Pasteuria ramosa* 的系统中，Ellen Decaestecker 及同事（2007）从覆盖数十年的有年代记录的池塘沉积物层中孵化休眠卵、复苏寄生虫孢子，发现寄生虫对与其同时代的宿主感染力最强——红皇后循环的印记。

### 协同进化与有性生殖的维持

有性生殖是有代价的：一个既生儿子又生女儿的有性雌性，在其他条件相同时，其增长率只有只生女儿的无性雌性的一半（John Maynard Smith 的"雄性的两倍代价"，1978）。关于性为何仍然存在的诸主要解释之一，正是红皇后。若寄生虫追踪常见的宿主基因型，那么产生基因多样后代的宿主就使它的后代携带罕见基因型，从而逃脱感染（汉密尔顿，1980；Graham Bell，1982）。

证据来自自然与实验。在新西兰的湖泊中，淡水螺 *Potamopyrgus antipodarum* 兼有有性与无性群体；Curtis Lively（1987）发现，吸虫寄生虫多的地方雄性（亦即有性生殖）也更常见；后来的工作表明，常见的无性克隆受到不成比例的感染而随后衰落。Levi Morran 及同事（2011）操纵了秀丽隐杆线虫（*Caenorhabditis elegans*，可自交也可异交）的交配系统，并让群体暴露于细菌寄生虫 *Serratia marcescens*。被迫专性自交、面对协同进化寄生虫的群体在 20 代内被推向灭绝，而异交群体存续了下来；若寄生虫不被允许进化，异交的收益就微乎其微。

::: quiz
一个植物群体在基因对基因位点上带有抗性，其中带代价的抗性 $R$ 频率很高。它的病原物进化到失去相应的无毒等位基因 $Avr$，于是 $R$ 不再提供保护。接下来植物中 $R$ 的频率预计如何变化？
- [ ] 进一步上升，因为抗性总是受偏爱。
- [x] 下降，因为 $R$ 如今只带代价而不提供保护。
- [ ] 保持不变，因为病原物与植物如今已相互匹配。
::: solution
一旦病原物成为毒性型（缺 $Avr$），$R$ 不再提供抗性却仍带其代价（在无病时也降低适合度，这在许多植物抗性基因上已有实证），没有它的植株反而更好，于是 $R$ 下降。当 $R$ 变得稀少时，病原物缺 $Avr$ 的代价（若有）可能反而有利于重新获得它的病原物——于是产生循环。双方都有代价，才是基因对基因协同进化循环而不无限升级的原因。
:::
:::

### 毒力的进化

天真的预期是寄生虫应进化得无害，因为杀死宿主也毁掉寄生虫的家。进化理论反而预言：毒力（对宿主的伤害）进化到使寄生虫传播最大化的水平，而这取决于传播与伤害如何关联。这里只把它作为概念模型处理；医学的一面属于[医学图谱](/learn/medicine/)。

经典的自然实验是黏液瘤病毒：1950 年在澳大利亚（1952 年在欧洲）被释放，用于控制引入的欧洲兔（*Oryctolagus cuniculus*）。原始毒株杀死 99 % 以上的受感染兔。Frank Fenner 及同事每年采样田间毒株，并在标准实验兔中检测：几年之内多数毒株处于中等毒力，杀死约 70–95 % 的受感染兔但速度更慢，而毒力最强与最弱的毒株都很罕见。与此同时兔子进化出了抗性。解释在于传播：病毒由蚊和蚤从活兔的皮肤病灶传播，所以杀死宿主太快的毒株来不及传播，危害太小的毒株产生病灶少、也传播得差。

::: example 传播—毒力权衡 {#ex-tradeoff}
在一个寄生虫于宿主间传播的简单模型中，全感病群体中一次感染引起的新感染数为 $R_0 = \beta/(\alpha + d)$，其中 $\beta$ 为传播率，$\alpha$ 为寄生虫引起的附加宿主死亡率（其毒力），$d$ 为感染因其他原因终止的速率（宿主因他因死亡，或康复）。设传播随毒力上升但收益递减，$\beta = k\sqrt\alpha$。哪个毒力使 $R_0$ 最大？
::: solution
$R_0(\alpha) = k\sqrt\alpha/(\alpha + d)$。求导：

$$
\frac{dR_0}{d\alpha} = k\,\frac{\tfrac12\alpha^{-1/2}(\alpha + d) - \alpha^{1/2}}{(\alpha + d)^2} = k\,\frac{d - \alpha}{2\sqrt\alpha\,(\alpha + d)^2},
$$

在 $\alpha^* = d$ 处为零，其下为正、其上为负：最优值是中间的。若感染在其他情况下约持续 10 天（$d = 0.1$ 每天），模型预言毒力 $\alpha^* = 0.1$ 每天——寄生虫杀死宿主的速度应与感染因其他原因终止的速度相当。这个预言完全依赖权衡的形状：若传播不依赖宿主存活（如某些具有持久自由生活阶段的寄生虫），更高的毒力就可能受偏爱。Roy Anderson 与 Robert May（1982）用这一推理解释了黏液瘤的结果。
:::
:::

### 巢寄生

大杜鹃（*Cuculus canorus*）把卵产在其他鸟类的巢中，由宿主把杜鹃雏鸟养大，而雏鸟会把宿主的卵推出巢外。宿主进化出识别并弃去外来卵的能力，杜鹃则进化出模仿其宿主卵的卵。雌杜鹃分属宿主专化的宗（**宗**，gentes），每一宗产与单一宿主匹配的卵——芦苇莺、草地鹨、红尾鸲——而雄性在不同宗之间交配；这一性状似乎沿母系遗传（Nicholas Davies 及同事）。长期受寄生的宿主物种对不匹配卵的抛弃，比未受寄生的群体或物种更强烈；当前未受寄生但历史上受过寄生的宿主，可能保留抛弃行为——军备竞赛留下的痕迹。

## 互利共生

自然界最重要的相互作用中有许多是互利共生：每一方都从对方获益。约 80 % 的陆生植物与真菌形成菌根，真菌供应磷与氮以换取糖类；豆科植物在根瘤中容纳固氮根瘤菌；被子植物依赖动物传粉；造礁珊瑚依赖光合甲藻共生体；蚜虫依赖细菌 *Buchnera aphidicola*（布赫纳菌），后者合成蚜虫食汁中缺乏的必需氨基酸。线粒体与叶绿体是古代细菌互利共生者的后裔（[[cell-biology/organelles]]）。

**专性传粉互利共生**以最具专门化的形式展示协同进化。榕属（*Ficus*，无花果）约 750 个种中，每一个都由一种或少数几种微型榕小蜂传粉，而榕小蜂只在榕果内繁殖：雌蜂钻入幼果，为其中的花授粉并在部分花中产卵；其后代在形成虫瘿的花中发育，在果内交配，雌蜂带着花粉飞出。丝兰由丝兰蛾（*Tegeticula* 与 *Parategeticula*）传粉：雌蛾用特化的口器主动采集花粉，把它塞进花的柱头，再在子房中产卵；幼虫吃掉一部分、而非全部发育中的种子。

::: definition 作弊与制裁 {#def-sanctions}
互利共生中的**作弊者**（cheater）是只取利益不付代价的伙伴——取走花蜜而不传粉的访花者，拿走糖却不供应养分的共生体。互利共生只有在使作弊者处于劣势的机制存在时才稳定：**伙伴选择**（相互作用之前挑选合作的伙伴）、**制裁**（削减不合作伙伴的报酬），或**伙伴忠实反馈**（双方命运联动，伤害伙伴即伤害自己，如垂直传递的共生体）。
:::

制裁已被实验证实。丝兰会选择性中止含太多蛾卵的花，杀死其中的幼虫，于是每朵花产卵过多的蛾损失后代（Olle Pellmyr 与 Chad Huth，1994）。Toby Kiers 及同事（2003）把大豆根瘤置于无氮气氛中，使其中根瘤菌不能固氮，发现植物减少对这些根瘤的氧气供应，其中的根瘤菌繁殖减少：植物制裁不固氮的共生体。像 *Buchnera* 这样由母亲传给后代的垂直传递共生体，是伙伴忠实的范例：共生体的繁殖完全依赖宿主的繁殖，两者的系统发育树严丝合缝——蚜虫树与布赫纳菌树相互吻合，这是协同成种最清晰的例子（Nancy Moran 及同事，1993）。

::: example 检验协同成种 {#ex-cospeciation}
Mark Hafner 与 Steven Nadler（1988）比较了囊鼠（Geomyidae）与其啮虱（Trichodectidae）的系统发育树。设 8 对囊鼠–啮虱中，两棵树的比对调和显示 6 次协同成种事件（宿主与寄生虫谱系共同分裂的节点），而 1000 棵随机生成的啮虱树（逐一与囊鼠树调和）中只有 7 棵显示不少于 6 次协同成种。你能得出什么结论？还有哪些事件会使寄生虫树与宿主树不一致？
::: solution
随机树给出至少同样多协同成种事件的比例为 $7/1000 = 0.007$，置换检验的 P 值远低于 0.05：观测到的吻合程度远超随机，支持囊鼠与啮虱之间的反复协同成种。（这是 Roderic Page 的 TreeMap 等树的调和检验的逻辑；此处数字仅为示例。）宿主树与寄生树的不一致还可能来自**宿主转换**（寄生虫定殖不相关的宿主）、**同宿主成种**（寄生者在单一宿主谱系内成种，duplication）、**丢失**（一宿主谱系失去其一寄生虫谱系，sorting/extinction）与"错过搭车"（"missing the boat"，宿主谱系奠基时未带上其寄生虫）。啮虱由囊鼠亲子间的直接接触传播，这就解释了为什么转换罕见、协同成种常见。
:::
:::

::: warning "互利共生者是利他者"与"协同进化使伙伴臻于完美"
互利共生是相互利用：每个伙伴都被选择去最大化自身适合度，只在利他对自己有利时才利他。榕小蜂与丝兰蛾的幼虫吃掉的，正是母亲传粉所结的种子。许多互利共生带有剥削者——不传粉的榕小蜂、产卵却丢失了传粉行为的丝兰蛾（*Tegeticula intermedia*）、花蜜贼——条件改变时相互作用可向寄生滑动（在极肥沃的土壤中，菌根可能使植物入不敷出）。协同进化也不产生完美匹配：时间滞后、基因流和来自其他物种的选择冲突，使伙伴总是慢半拍。
:::

::: application 农业与医学中的协同进化
用单一主效抗性基因育种，是一场病原物通常取胜的基因对基因军备竞赛：一个新的抗性基因在大面积部署后，常在几年内就被毒性菌株破解（谷物锈病的"兴—衰"循环）。借鉴协同进化理论的战略包括：多个抗性基因同时部署（"基因聚合"）、品种混合，以及施加更弱、更弥散选择的数量抗性。噬菌体疗法——用噬菌体对抗细菌感染——必须面对 Buckling 与 Rainey 观察到的那一类细菌—噬菌体协同进化，混合噬菌体"鸡尾酒"就是应对之策。
:::

::: history
达尔文 1862 年预言了 *Angraecum sesquipedale* 的天蛾传粉者；该蛾于 1903 年被描述。Lotka 与 Volterra 于 1925–1926 年建立他们的捕食—猎物方程。Flor 从 1940 年代亚麻与亚麻锈病的杂交中提出基因对基因假说，并于 1956 年发表总结。Ehrlich 与 Raven 在他们 1964 年关于蝶与植物的论文中确立了"协同进化"的现代含义，Janzen 于 1980 年给出了严格定义。Van Valen 于 1973 年发表红皇后假说；汉密尔顿关于寄生虫维持有性生殖的理论出现于 1980 年；Anderson 与 May 关于毒力与传播的分析在 1982 年。Lively 的螺类研究发表于 1987 年，Thompson 的地理镶嵌理论在 1994 年，Buckling 与 Rainey 的噬菌体—细菌军备竞赛在 2002 年；Morran 及同事关于性与寄生虫的 *C. elegans* 实验于 2011 年跟进。
:::

::: summary
- 协同进化是相互作用物种之间的相互进化改变；物种彼此适配本身并不是它的证据。
- 捕食者—猎物的军备竞赛（束带蛇与带 TTX 的蝾螈）因地理而异：热点与冷点构成的地理镶嵌。
- Lotka–Volterra 动态：$N^* = m/(ba)$，$P^* = r/a$；猎物防御的改进可能增加捕食者数目。
- 宿主—寄生虫的遗传学从基因对基因（存在能感染一切宿主的基因型）到等位基因匹配（不存在通吃的感染型）不等；两者都产生负频率依赖选择与循环。
- 红皇后：敌对者必须不停进化才能留在原地；时移实验（*Pseudomonas*–噬菌体、*Daphnia*–*Pasteuria*）直接展示了它。寄生虫可以偏爱有性生殖，因为重组产生罕见基因型（*Potamopyrgus*、*C. elegans*）。
- 毒力在给定的权衡下进化到使传播最大化；$\beta \propto \sqrt\alpha$ 时 $R_0$ 在 $\alpha^* = d$ 处最大（澳大利亚的黏液瘤）。
- 互利共生（榕与榕小蜂、丝兰与丝兰蛾、根瘤菌、菌根、*Buchnera*）因伙伴选择、制裁与伙伴忠实而存续，并可协同成种。
:::

## 练习

::: exercise 捕食者—猎物的平衡 {level=1 check="40"}
在 Lotka–Volterra 模型[[#eq-lv]]中，$r = 0.8$ 每年、$a = 0.02$ 每捕食者每年，平衡时捕食者的数目是多少？
::: solution
$P^* = r/a = 0.8/0.02 = 40$。
:::
:::

::: exercise 平衡时的猎物 {level=1 check="250"}
若 $m = 0.5$ 每年、$b = 0.1$、$a = 0.02$，平衡时猎物的数目是多少？
::: solution
$N^* = m/(ba) = 0.5/(0.1\times0.02) = 0.5/0.002 = 250$。
:::
:::

::: exercise 等位基因匹配下的宿主适合度 {level=1 check="0.85"}
在[[#ex-matching]]的模型中取 $s = 0.25$，当感染宿主等位基因 $H_1$ 的寄生者等位基因 $P_1$ 频率为 0.6 时，$H_1$ 的适合度是多少？
::: solution
$w_{H_1} = 1 - sy = 1 - 0.25\times0.6 = 0.85$。
:::
:::

::: exercise 最优毒力 {level=2 check="0.05"}
在[[#ex-tradeoff]]的权衡模型中，感染因其他原因平均 20 天后终止。多大的毒力（每天）使 $R_0$ 最大？
::: solution
$d = 1/20 = 0.05$ 每天，而 $\alpha^* = d = 0.05$ 每天。
:::
:::

::: exercise 选择之后的一个宿主等位基因 {level=2 check="0.5"}
在 $s = 0.3$ 的等位基因匹配模型中，宿主等位基因 $H_1$ 频率 $x = 0.5$，寄生者等位基因 $P_1$ 频率 $y = 0.5$。一代后 $x$ 是多少？作何解释。
::: solution
$w_{H_1} = 1 - 0.15 = 0.85 = w_{H_2}$，故 $x' = 0.5\times0.85/0.85 = 0.5$。在 $(0.5, 0.5)$ 处，两个宿主等位基因被攻击的频率相同，寄生者亦然，两个频率都不变：这正是循环环绕其旋转的平衡点。
:::
:::

::: exercise 基因对基因的感染表 {level=2}
在一个基因座上，植物为 $R$（抗性）或 $r$，病原物为 $Avr$ 或 $avr$。(a) 写出感染结局的 2 × 2 表。(b) 若抗性有代价 $c$、毒性（缺 $Avr$）有代价 $k$，当 $R$ 常见时哪个病原物基因型受偏爱？当 $avr$ 常见时哪个植物基因型受偏爱？(c) 为什么这导致循环？
::: solution
(a) $R$ × $Avr$：抗病（不感染）。$R$ × $avr$：感染。$r$ × $Avr$：感染。$r$ × $avr$：感染。
(b) $R$ 常见时，$avr$ 病原物能感染多得多的宿主，虽有代价 $k$ 仍受偏爱。$avr$ 常见时，$R$ 不提供保护，纯粹是代价 $c$，于是 $r$ 植物受偏爱。
(c) $R$ 常见 → $avr$ 上升 → $R$ 失效 → $R$ 下降 → $R$ 植物稀少时，$avr$ 的代价 $k$ 超过其收益 → $Avr$ 上升 → $R$ 又有用 → $R$ 上升。双方的代价阻止任何一方的等位基因简单固定，时间滞后则使频率循环。
:::
:::

::: exercise 解读时移实验 {level=2}
从协同进化的培养物中在第 0、10、20、30、40 次传代取样细菌与噬菌体。每份细菌样品都对照各个时间点的噬菌体检测。第 20 代的细菌抵抗第 0、10 代噬菌体的比例为 100 %，对第 20 代为 60 %，对第 30、40 代为 20 %。(a) 这一格局说明什么？(b) "波动选择"（等位基因匹配型循环）的格局有何不同？(c) 为什么必须冻存样品？
::: solution
(a) 细菌抵抗过去的噬菌体、对未来噬菌体敏感：这是一场**军备竞赛**（定向升级），每一代噬菌体能感染的范围更宽、细菌的抵抗范围也在加宽，如同 Buckling 与 Rainey（2002）。
(b) 波动选择之下，寄生虫对*当代*宿主适应最好，对过去噬菌体的抵抗力不会积累：细菌可能对某些遥远过去的噬菌体重新变得敏感，因为旧基因型卷土重来。抗性的时间曲线应振荡而非单调上升。
(c) 检测要求同时复苏来自不同时代的生物，而这只有把样品在不继续进化的状态下保存才可能——实验里靠冻存细菌与噬菌体，自然界靠沉积物中的休眠阶段，如 *Daphnia* 与 *Pasteuria*。
:::
:::

::: exercise 有性生殖的两倍代价 {level=3}
(a) 一个群体由有性雌性及其配偶组成，每只雌性产 2 个存活后代（一半儿子一半女儿）。一个无性突变雌体产 2 个存活女儿，且都为无性。从 1000 只有性雌性中的 1 只无性雌体起步，若别无差异，多少代后无性雌性的数目超过有性雌性？(b) 参考频率依赖，解释协同进化的寄生虫如何能够抵消这一代价。
::: solution
(a) 有性雌性：每代 1000 只产 2000 个后代，其中 1000 只为女儿——有性雌性的数目保持 1000。无性者：$1\to2\to4\to\ldots$，每代加倍。$2^t > 1000$ 时无性者反超，即 $t = 10$ 代（$2^{10} = 1024$）。这就是两倍代价：无性者每代把自己的份额加倍。
(b) 无性克隆在遗传上是均一的，当它变常见时，它就是最常见的宿主基因型。适应它的寄生虫增多（负频率依赖），压低其适合度；而有性雌性产生基因多样、常常罕见的后代，得以逃脱感染。若寄生虫对常见克隆造成的死亡率超过一半，性虽有加倍代价仍能取胜。红皇后的观点预言：寄生虫多则性常见（如 *Potamopyrgus*），且该优势依赖于寄生虫的协同进化（如 Morran 的实验）。
:::
:::

::: exercise 互利共生中的作弊 {level=3}
一只丝兰蛾雌蛾在她已传粉的花中产卵。每条幼虫吃 10 粒种子。一朵花受粉后结 200 粒种子。植物中止任何含卵超过 6 粒的花，杀死其中全部幼虫。(a) 每朵花产多少卵使一只蛾从单朵花的后代最多？(b) 此时蛾吃掉种子总数的多大比例？(c) 若植物不能中止花朵，互利共生会怎样？
::: solution
(a) 幼虫存活在阈值处是全有或全无的：至多 6 粒卵全部存活；7 粒及以上全部死亡。只在单朵花中产卵的蛾，产 6 粒卵使存活幼虫最多（假设她能控制产卵量且没有别的蛾产在同一朵花上）。
(b) $6\times10 = 60$ 粒，占 200 粒的 30 %；植物留下 140 粒。
(c) 若不能中止花朵，蛾将被选择在一朵花中尽可能多产卵，吃掉大部分乃至全部种子；植物从传粉中的收益将萎缩到零甚至为负，相互作用将向寄生漂移。像花败育这样的制裁使过度剥削对蛾变得昂贵，从而稳定互利共生（Pellmyr 与 Huth，1994）。
:::
:::
