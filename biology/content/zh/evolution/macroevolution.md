前面各章的力量——选择、漂变、突变、基因流、物种形成——在群体之内、世代之间起作用。而生命的历史写在数亿年的时间尺度上：动物在寒武纪的出现，登陆，恐龙的兴衰，被子植物与哺乳类的辐射。**宏观进化**是物种层级之上的进化：各大类群与新构造的起源，跨越地质时间的进化速率与格局，以及多样性本身的动力学——为什么有些进化枝有数千个物种而其姊妹进化枝只有寥寥数个，为什么多样性屡经大灭绝而崩溃又复原。

一个核心问题是：宏观进化是否只是长时间积累起来的微观进化，还是在更大的尺度上会出现群体之内看不到的过程。多数进化生物学家的回答是：起作用的是同样的过程，但在进化枝的层级上涌现出新现象——成种与灭绝的差异、罕见灾变的影响、发育构型的长期后果。本章介绍地质年代表与化石记录的形状，度量进化的速率，把多样化建模为出生–死亡过程，讨论适应辐射与大灭绝，并追问进化上的新性状如何产生。全章运用 [[evolution/phylogenetics]] 的树思维。

## 地质年代表

地质年代表于十九世纪据岩石中化石的顺序建立（[[evolution/evidence-for-evolution]]）；放射性同位素定年后来赋予了绝对年龄。界线由国际地层委员会（ICS）在国际上统一定义，每条界线定在某一具体岩石剖面中的一个参考点（"金钉子"），其年龄随定年技术的进步而修订。

地球约在 45.4 亿年前形成；最受公认的最早生命证据（微体化石与叠层石，以及生物固存的同位素特征）约有 35 亿年，还有一些更早的主张但存在争议。在绝大部分历史中，生命都是微生物。真核生物在约 16 亿年前已确凿地出现在化石记录中；复杂的多细胞动物只在生命最后 10–15 % 的时间里才出现。

::: definition 作为数据的化石记录 {#def-record}
**化石记录**是对过去生命的一次抽样，受三种**偏倚**：**保存**（具硬体的、生活在沉积环境中的生物远更可能化石化为化石）、**岩石记录**（更年轻、分布更广的岩石产出更多化石）与**采集努力**。因此一个分类单元在记录中的首次出现晚于其真实起源，末次出现早于其真实灭绝（**Signor–Lipps 效应**，1982）。随时间变化的多样性靠统计穿过每个时间间隔的分类单元（种、属、科）数目来估计，并对不均匀的采样加以校正。
:::

化石的延续时间通常在属或科的层级上统计，因为它们的识别比种可靠。Sepkoski（John Sepkoski）关于海洋动物科与属首末出现的汇编（1982，2002）是多数经典多样性时间序列分析的基础。

## 进化的速率

进化有多快？对齿长这类测量值，霍尔丹（J。B。S。Haldane，1949）提出了一个单位：**达尔文**（darwin），即每一百万年按 $e$ 倍改变。

::: definition 达尔文与霍尔丹 {#def-rates}
若一个性状在 $\Delta t$ 百万年中从均值 $x_1$ 变到均值 $x_2$，以其**达尔文**（darwins）计的速率为

$$
r_\mathrm{d} = \frac{\ln x_2 - \ln x_1}{\Delta t}.
$$ {#eq-darwin}

以**霍尔丹**（haldanes，Philip Gingerich，1993）计的速率，是以该性状的合并标准差度量、每一代的改变量：

$$
r_\mathrm{h} = \frac{(\bar z_2 - \bar z_1)/s_p}{g},
$$

其中 $\bar z$ 为均值（常取性状自然对数的均值），$s_p$ 为群体内合并标准差，$g$ 为经历的世代数。
:::

::: example 马的牙齿进化得有多快？ {#ex-darwins}
在马约 3000 万年的进化史中，一枚臼齿的尺寸从 10 mm 增大到 25 mm（量级正确的示例性取整数值）。计算以达尔文计的速率。一个被移植到无捕食者溪流中的孔雀鱼（*Poecilia reticulata*）群体，10 年间把一个性状改变了 1.1 倍。比较两个速率。
::: solution
马：$r_\mathrm{d} = \ln(25/10)/30 = 0.916/30 = 0.031$ 达尔文，即 31 毫达尔文。

孔雀鱼：$\ln 1.1/10^{-5}\ \text{Myr} = 0.0953/10^{-5} = 9530$ 达尔文，快约 30 万倍。

这种反差很典型。在 David Reznick 于特立尼达做的移植实验中，孔雀鱼生活史性状的进化速率高达数千至数万达尔文（Reznick 及同事，1997），而化石谱系表现出的速率只有达尔文的几分之一。Gingerich（1983）表明，测得的速率大体与所测时间间隔的长度成反比。原因不是进化在长时间间隔上变慢，而是它会波动：长间隔上的改变是许多方向不同的改变的*净*结果，除以间隔便低估了每一步的速度。微观进化的速度按数量级算已足够解释化石记录中见到的任何改变。
:::
:::

### 间断平衡

1972 年，纳尔斯·埃尔德里奇（Eldredge）与古尔德（Stephen Jay Gould）提出：许多物种的化石记录显示出长期极少的形态改变（**停滞**），其间被与新种起源相关、地质上突然的转变打断——即**间断平衡**（punctuated equilibrium）——而非**种系渐变论**（phyletic gradualism）所设想的稳定转变。他们借用迈尔的周边物种形成模型解释这一图景：改变发生在小的隔离群体中，历时太短、范围太窄而成不了化石，新种随后扩散并原样存续。

这一想法引发了旷日持久的争论。对保存良好谱系的详细研究发现了两类格局的实例——浮游有孔虫某些谱系的渐进改变，以及苔藓动物中被快速改变打断的停滞（Alan Cheetham 对 *Metrarabdotos* 的研究，1986）——还有许多中间情形。一场历时 5 万年、"地质上突然"的改变可以包含数千代的寻常选择。这场争论的持久贡献，一是确认**停滞**很常见、需要解释（稳定选择、环境变迁时的生境追踪，以及波动选择的平均化，是主要候选），二是把注意力引到在物种的层级上起作用的过程。

## 多样化：成种减灭绝

一个进化枝的物种数目因物种形成（谱系分裂）与灭绝（谱系终止）而改变。最简单的模型把每条谱系处理为：单位时间之内，各自以恒定概率发生这两种事件。

::: proposition 多样化的出生–死亡模型 {#prop-birthdeath}
若每条谱系独立地以速率 $\lambda$（成种）分裂、以速率 $\mu$（灭绝）消亡，单位以每谱系每一百万年计，则自 $N_0$ 条起，时刻 $t$ 的期望谱系数为

$$
\E[N(t)] = N_0\,e^{(\lambda - \mu)t},
$$ {#eq-bd}

按**净多样化速率** $r = \lambda - \mu$ 指数增长。反过来，一个由 $t$ 百万年前单一谱系进化出 $N$ 个现生物种的进化枝（$t$ 为**干群年龄**），其净多样化速率的估计为 $\hat r = \ln N/t$；若 $t$ 为**冠群年龄**——即所有现生成员源出之两条谱系分裂的年龄——则 $\hat r = (\ln N - \ln 2)/t$（Susana Magallón 与 Michael Sanderson，2001，忽略了灭绝校正）。
:::

::: proof
令 $n(t) = \E[N(t)]$。在短区间 $\delta t$ 内，每条谱系以概率 $\lambda\,\delta t$ 分裂（加一），以概率 $\mu\,\delta t$ 死亡（减一），于是 $n(t + \delta t) = n(t) + (\lambda - \mu)n(t)\,\delta t$，得 $dn/dt = (\lambda - \mu)n$，解为 $n(t) = N_0e^{(\lambda - \mu)t}$。令 $n = N$ 并解出 $r$ 即得各估计量；自冠群年龄起有两条谱系起步，故 $N = 2e^{rt}$。
:::

::: example 快辐射与慢辐射 {#ex-diversification}
(a) 东非某湖的慈鲷包含约 500 个特有种，其冠群年龄估计约 200 万年。(b) 被子植物约含已描述种 30 万，冠群年龄约 1.4 亿年。试估计各自的净多样化速率，以及谱系数倍增时间。
::: solution
(a) $\hat r = (\ln 500 - \ln 2)/2 = (6.215 - 0.693)/2 = 2.76$，单位每谱系每 Myr；倍增时间 $\ln 2/\hat r = 0.25$ Myr。

(b) $\hat r = (\ln 300{,}000 - \ln 2)/140 = (12.61 - 0.69)/140 = 0.085$，单位每谱系每 Myr；倍增时间 8.2 Myr。

湖慈鲷的平均多样化速度比被子植物快 30 倍以上，尽管两者都是众口称道的辐射。两个数字都很粗略：冠群年龄不确定（被子植物的冠群年龄有争议，分子定年常早于最早的无歧义化石——约 130–135 Ma），物种数目只是约数，公式还假定速率恒定且无灭绝。计入灭绝会提高产生同样物种数所要求的成种速率。
:::
:::

各进化枝的物种丰富度差异极大。甲虫约有已描述种 40 万；其姊妹类群捻翅目（Strepsiptera，寄生于其他昆虫的"翅生虫"）只有约 600。由于姊妹群按定义同岁，这类反差指向多样化速率的差异。若在许多独立比较中都与更高多样化相关的性状，可称**关键创新**（key innovation）：被子植物的花距（Scott Hodges 与 Michael Arnold，1995，研究材料为耧斗菜 *Aquilegia*）、昆虫的植食性（Charles Mitter 及同事，1988），以及慈鲷的咽颌，都是被提出的实例。检验它们需要跨进化枝的重复，因为任何一对姊妹群之间都相差着许多性状。

**物种选择**（species selection；Steven Stanley，1975）指由*物种层级*的可遗传性状所致的谱系之间成种或灭绝的差异——例如地理分布区大小，它是物种的性质而非个体的性质。David Jablonski 对晚白垩世软体动物的研究表明：具浮游幼虫的物种（扩散广、分布区大）作为物种存续得更久，尽管行直接发育者成种更频繁。

### 灭绝与红皇后

曾经存在过的物种大多已灭绝；化石记录中海洋无脊椎动物的平均物种延续期为几百万年（估计范围约 1 至 10 Myr，随类群而异）。1973 年，Leigh Van Valen 把一个类群中至少存续到某一时间的属或科的比例作图，发现曲线在对数尺度上大体是直的：单位时间的灭绝概率大致恒定，与一个分类单元已经存在多久无关。这就是每条谱系恒定的灭绝速率 $\mu$ 的结果——存活到年龄 $t$ 的比例为 $e^{-\mu t}$。他的解释——**红皇后假说**——见 [[evolution/coevolution]]。

::: quiz
两个同岁的甲虫姊妹进化枝，一个有 2000 个种，另一个只有 20 个。在没有更多数据时，哪个结论站得住？
- [ ] 较大的那个进化枝灭绝率较低。
- [ ] 较大的那个进化枝成种率较高。
- [x] 较大的那个进化枝净多样化速率（$\lambda - \mu$）更高，或运气更好，或两者兼有。
- [ ] 较大的那个进化枝必定拥有关键创新。
::: solution
姊妹进化枝同岁，所以大小差异按[[#eq-bd]]意味着净多样化 $\lambda - \mu$ 的差异——但仅有计数无法把"成种更高"与"灭绝更低"分开，因为决定期望大小的只是两者之差。多样化还是随机的：即使速率相同，姊妹进化枝也可能凭机会相差数倍，类群尚小时尤甚。关键创新只是可能的原因之一，要靠重复比较来检验。
:::
:::

## 适应辐射

::: definition 适应辐射 {#def-radiation}
**适应辐射**（adaptive radiation）是一条谱系迅速多样化，形成占据多种生态位的许多物种，并伴随进化出使它们适应这些生态位的表型差异（Dolph Schluter，2000）。其判据是：共同祖先；表型与环境的关联；性状的适应价值（以性能或适合度证明）；快速的物种形成。
:::

辐射往往跟随**生态机会**而来：拓殖竞争者稀少的新地域（岛屿、湖泊），关键创新的进化，或者竞争者的灭绝。经典实例：

- **达尔文地雀**：约 18 个物种，源自最近几百万年间抵达加拉帕戈斯的一个祖先群体（辐射年龄的分子估计约在一至三百万年之间），喙适应于种子、昆虫、仙人掌花、芽乃至血液。Arkhat Abzhanov 及同事（2004、2006）表明，喙深与喙长的差异与发育中的喙里信号基因 *Bmp4* 与钙调蛋白的表达相关。
- **大安的列斯群岛的安乐蜥（*Anolis*）**：在古巴、伊斯帕尼奥拉、牙买加、波多黎各这四大岛上，安乐蜥各自独立进化出了同一套"生态形态型"（ecomorph：干-地型、枝栖型、冠巨栖型等），每一型的肢长比例与趾垫都适配其栖位，系统发育研究予以证明（Jonathan Losos 及同事，1998）。辐射是可重复的。
- **东非慈鲷**：维多利亚湖、马拉维湖、坦噶尼喀湖各有数百个种，食性从刮食藻类到食鱼鳞，体色用于配偶选择（[[evolution/sexual-selection]]）。
- **恐龙之后的哺乳类**：哺乳类在白垩纪末灭绝之前已存在了 1.5 亿年以上，大多体型很小；在古近纪的头一千万年里，真兽类各大类群迅速多样化，填补非鸟恐龙腾出的生态角色。

## 大灭绝

在稳定不变的背景灭绝之上，记录显示出几次灾难性损失的时段。Raup（David Raup）与 Sepkoski（1982）分析海洋科的数据，识别出五次超出背景的事件——"五大"灭绝。

| 事件 | 年龄（Ma） | 海洋物种损失估计 | 主流解释 |
|---|---|---|---|
| 奥陶纪末 | ≈ 444 | 约 85 % | 冰期与海平面下降，海洋化学变化 |
| 晚泥盆世 | ≈ 372（Kellwasser）与 ≈ 359（Hangenberg） | 约 75 % | 多期脉冲；海洋缺氧 |
| 二叠纪末 | 251.9 | 约 80–90 % | 西伯利亚暗色岩火山作用：增温、海洋酸化与缺氧 |
| 三叠纪末 | 201.4 | 约 75 % | 中大西洋岩浆岩省火山作用 |
| 白垩纪末 | 66.0 | 约 75 % | 小行星撞击（希克苏鲁伯），伴随德干暗色岩火山作用 |

（物种损失是从属的外推估计，研究之间互有出入；见 Jablonski，1994，及后来的综述.）

**二叠纪末**灭绝最大。Seth Burgess、Samuel Bowring 与沈树忠（Shu-zhong Shen）（2014）用华南火山灰层锆石的 U–Pb 定年把它定在 251.94 Ma，并表明主脉冲延续不足约 6 万年。它消灭了三叶虫（此前已式微）、层孔珊瑚与四射珊瑚，以及腕足动物与海百合的大多数类群，并改组了海洋生态系统：以腕足动物与有柄棘皮动物为主的古生代动物群，让位于以软体动物为主的中生代与新生代动物群。

**白垩纪末**灭绝最为人所知。Luis Alvarez、Walter Alvarez、Frank Asaro 与 Helen Michel（1980）在意大利古比奥（Gubbio）等地的界线黏土层中发现了富铱——地壳中稀见、陨石中常见的元素——的薄层，并提出小行星撞击假说。其后又找到冲击石英、球粒与海啸沉积；1991 年 Alan Hildebrand 及同事在尤卡坦半岛确认了时代相符、直径约 180 km 的深埋希克苏鲁伯（Chicxulub）陨石坑。这次灭绝清除了非鸟恐龙、翼龙、菊石与许多浮游生物类群；鸟类、哺乳类、鳄、龟与许多植物幸存。

大灭绝对进化重要在两点。它们不只是"更多的背景"：其中的幸存往往与平常年代预测幸存的性状无关（Jablonski，1986：预测白垩纪末幸存的是属而非种的地理分布区大小）。而且通过清除居支配地位的类群，它们为其他类群打开生态机会，古近纪的哺乳类即其一。历史受制于罕见事件的机缘。

::: example 要死掉多少物种才损失一半的属？ {#ex-rarefaction}
设一次灭绝以概率 $q$ 独立地杀死每个物种。(a) 一个含 $k$ 个种的属全部灭绝的概率是什么？(b) 对 $q = 0.9$，比较含 1、2、5、10 个种的属。(c) 解释为什么在属或科的层级上估计的灭绝会低估物种的损失。
::: solution
(a) 属只有 $k$ 个种全死才会消失：概率 $q^k$。

(b) $q = 0.9$ 时：$k = 1$：0.90；$k = 2$：0.81；$k = 5$：0.59；$k = 10$：0.35。90 % 的物种损失只杀死十分种属的三分之一。

(c) 只要一个高分类单元的任何一个种幸存，该单元就幸存，所以损失的属（乃至科）的比例小于种。Raup（David Raup，1979）由观察到的更高阶元的损失、利用每属种数的分布倒推，以这种"逆稀化法"估计二叠纪末事件可能杀死多达约 96 % 的海洋物种——这是上限；后来用更好数据得到的估计更接近 80–90 %。
:::
:::

x: 0, 1
y: 0, 1

labels: \text{属灭绝率 } q^k; \text{种灭绝率 } q
caption: 一个含 $k$ 个种的属灭绝的概率 $q^k$，对每个种死亡的概率 $q$ 绘制，假设彼此独立；对角线即物种损失本身。注意含多个种的属，曲线离对角线有多远：即使 $q = 0.8$，一个五种属仍有三分之二的时间幸存。真实的灭绝在一个属的种之间并不独立（近缘种共享性状与分布区），这会使属的损失更接近种的损失。
:::

::: warning "大灭绝只是运气不好"与"灭绝说明物种失败了"
灭绝是几乎一切谱系的最终命运；一个物种在平常年代灭绝，并不比它先前的成功更能说明低劣或优秀，因为两者都取决于会变化的环境。但灭绝也绝非纯粹随机：在背景年代，分布窄、体型大、特化的物种风险更高；而在大灭绝期间，某些性状（进化枝的地理分布广、耐受低氧、体型小）提高了幸存率。由人类活动驱动的当今物种损失速度快得让一些生物学家谈论"正在进行中的第六次大灭绝"；它是否会达到"五大"的规模，取决于接下来会发生什么（[[conservation-biology]]）。
:::

## 新性状的起源

羽毛、花、眼、四肢——新的构造如何产生？反复出现的答案有三个。

**修改与征用.** 新构造通常是旧构造的修改，往往伴随功能的改变（扩展适应；[[evolution/natural-selection]]）。羽毛在恐龙中作为丝状构造进化出来，可能用于保温或展示，远早于用于飞行。哺乳类中耳的听小骨原是颌骨。脊椎动物眼的晶状体晶状蛋白是被征用的代谢酶与应激蛋白。

**经由中间类型的逐步改良.** 达尔文针对"复杂的眼不可能进化出来"的非难，指出现生动物中眼的全部光谱：从感光斑到杯眼、针孔眼、具晶状体的眼，每一级都有用。Dan-Eric Nilsson 与 Susanne Pelger（1994）为一片扁平的感光细胞团向带梯度折射率晶状体的相机眼的转变建模，通过一连串各自提高空间分辨力的小改变完成。

::: example 进化一只眼要多久？ {#ex-eye}
Nilsson 与 Pelger 发现，从扁平的感光斑到聚焦相机的眼，所需的总改变相当于 1829 个连续各 1 % 的步骤。设每个性状的遗传率为 $h^2 = 0.5$，变异系数 1 %，选择很弱、每代使均值改变 0.005 %，整个转变需要多少代？
::: solution
总改变为因子 $1.01^{1829} = 8.0\times10^7$。按每代改变 0.005 %、即因子 1.00005，所需世代数为

$$
g = \frac{\ln(8.0\times10^7)}{\ln 1.00005} = \frac{18.20}{5.0\times10^{-5}} = 3.64\times10^5,
$$

约 36.4 万代——对世代时间一年的动物不过几十万年，地质上的一瞬.（每代 0.005 % 的改变量，由育种方程[[evolution/natural-selection#eq-breeder]]取刻意很弱的选择差——均值的 0.01 %——算出.）模型是刻意保守的；它说明所需时间不是严重障碍，而不是说眼在任何谱系中实际就是这样进化的。
:::
:::

**发育的改变.** 进化发育生物学（"evo-devo"）在 1980–1990 年代表明，果蝇与小鼠这样截然不同的动物共用一套发育调控基因"工具包"：*Hox* 基因规定头尾轴上的身份，成簇排列，顺序与它们所模式化的体段一致；*Pax6*，两者发育眼都必需——小鼠的 *Pax6* 在果蝇的腿与触角中异位表达可诱生额外的眼（Georg Halder、Patrick Callaerts 与 Walter Gehring，1995）；以及负责心脏的 *tinman*/*Nkx2.5*。这种**深层同源**意味着许多形态进化并非来自新基因，而来自旧基因表达的时间与地点的改变，常常经由**顺式调控**序列（增强子）的改变——只影响一种组织，从而避开有害的多效性。在三刺鱼（*Gasterosteus aculeatus*）中，淡水群体反复丢失骨盆后棘，正是由基因 *Pitx1* 的一个骨盆增强子的缺失所致，基因的其他功能完好无损（Yingguang Frank Chan 及同事，2010）。

**基因与基因组重复.** 大野赈（Susumu Ohno，《基因重复与进化》（*Evolution by Gene Duplication*），1970）论证重复的基因摆脱了约束，一个拷贝因而可获得新功能。脊椎动物进化早期发生过两轮全基因组复制，现已得到基因组比较的支持；硬骨鱼祖先中又发生了第三轮；哺乳类有四个 *Hox* 簇、昆虫只有一个，便是其遗踪。珠蛋白、视蛋白与许多其他基因家族都靠重复多样化。

::: application 宏观进化与当下
过去的格局关涉当下的生物多样性危机。化石记录显示，大灭绝之后多样性的复原需要数百万年，而幸存者并非随机样本。研究充分的类群（鸟、哺乳类、两栖类）过去几个世纪测得的灭绝速率，是化石估计的背景速率的数十到数百倍（Gerardo Ceballos 及同事，2015，但比较的是很不同类的数据，须持保留）。系统发育有助于确定保护优先序：失去一个无近亲的进化独特物种——如喙头蜥（*Sphenodon punctatus*），其所属的目在 2 亿多年前与其余爬行类分歧，它是该目仅存的代表——比失去众多近亲中的一个抹去的进化历史更多（[[conservation-biology]]）。
:::

::: history
居维叶（Cuvier）确立了灭绝（1796）与灾变性的动物群更替；达尔文以记录的不完全解释其缺环（1859）。Simpson 的《进化中的速率与模式》（*Tempo and Mode in Evolution*，1944）把古生物学带入现代综合进化论，并提出适应区与量子进化。霍尔丹 1949 年定义了达尔文单位。埃尔德里奇与古尔德 1972 年提出间断平衡；Van Valen 1973 年发表红皇后假说；Raup 与 Sepkoski 1982 年确认"五大"大灭绝；Alvarez 团队 1980 年提出白垩纪末撞击，1991 年希克苏鲁伯陨石坑的发现予以证实。Lewis（Edward Lewis）对果蝇双胸复合体的工作（1978）与同源异型盒的发现（William McGinnis、Michael Levine、Walter Gehring 及同事；Matthew Scott 与 Amy Weiner，1984）开创了进化发育生物学。布尔吉斯页岩动物群——1909 年由 Walcott（Charles Walcott）发现、1970 年代起经 Harry Whittington、Simon Conway Morris 与 Derek Briggs 重新诠释——与中国的澄江生物群（1984 年起），记录了寒武纪大爆发。
:::

::: summary
- 宏观进化关注物种层级之上的格局：各大类群与新性状的起源、地质时间上的速率、进化枝的多样化与灭绝。
- ICS 年代表（v2023/09）：寒武纪 538.8 Ma，二叠纪–三叠纪 251.9 Ma，白垩纪–古近纪 66.0 Ma，第四纪 2.58 Ma；界线年龄随定年进步而修订。
- 速率以达尔文（$\ln(x_2/x_1)/\Delta t$ 每 Myr）或霍尔丹（每代合并标准差）度量；表观速率随测量间隔增大而下降，而微观进化快得足以解释记录中的任何改变。停滞很常见（间断平衡）。
- 出生–死亡模型：$\E[N] = N_0e^{(\lambda-\mu)t}$；由冠群年龄的净多样化 $\hat r = (\ln N - \ln 2)/t$。关键创新与物种选择解释进化枝之间的差异。
- 适应辐射跟随生态机会（达尔文地雀、加勒比安乐蜥、慈鲷、古近纪哺乳类），且可以是可重复的。
- 五次大灭绝卓然突出；二叠纪末（251.9 Ma，与西伯利亚暗色岩火山作用相关）最大，白垩纪末（66.0 Ma）紧随希克苏鲁伯撞击。属比种更幸存（$q^k$）。
- 新性状经由征用、经由功能中间类型的逐步改良（一只眼约 $4\times10^5$ 代）、共用发育工具包的调控改变，以及基因与基因组重复而产生。
:::

## 练习

::: exercise 以达尔文计的速率 {level=1 check="0.0231"}
某谱系的体长在 3000 万年间从 20 cm 增至 40 cm。以达尔文计的速率是多少（三位有效数字）？
::: solution
$r_\mathrm{d} = \ln 2/30 = 0.6931/30 = 0.0231$ 达尔文。
:::
:::

::: exercise 由冠群年龄估计净多样化 {level=1 check="0.693"}
一个有 64 个现生物种的进化枝，冠群年龄 5 Myr。估计其净多样化速率，单位每谱系每 Myr（三位有效数字）。
::: solution
$\hat r = (\ln 64 - \ln 2)/5 = \ln 32/5 = 3.466/5 = 0.693$，单位每谱系每 Myr：谱系数每 $\ln 2/0.693 = 1$ Myr 倍增，从 2 到 64 倍增五次。
:::
:::

::: exercise 属的幸存 {level=1 check="0.0625"}
若每个物种以 0.5 的概率独立死亡，一个含 4 个种的属灭绝的概率是多少？
::: solution
$0.5^4 = 0.0625$。
:::
:::

::: exercise 进化枝的期望大小 {level=2 check="148"}
一个进化枝自 1 条谱系起步，$\lambda = 0.6$、$\mu = 0.1$，单位每谱系每 Myr。10 Myr 后的期望谱系数是多少（取整）？
::: solution
$\E[N] = e^{0.5\times10} = e^5 = 148.4$，约 148。
:::
:::

::: exercise 存活比例 {level=2 check="0.082"}
若某类群的属以每 Myr 0.25 的恒定速率灭绝，10 Myr 后幸存的比例是多少（三位小数）？
::: solution
$e^{-0.25\times10} = e^{-2.5} = 0.082$。
:::
:::

::: exercise 解读存活曲线 {level=2}
Van Valen 对许多类群把至少存活 $t$ 百万年的属数的对数对 $t$ 作图，得到直线。(a) 直线对一个属的灭绝概率意味着什么？(b) 一条随 $t$ 变平的曲线意味着什么？(c) 这一结果为什么出人意料？他如何解释？
::: solution
(a) $\ln(\text{survivors}) = \ln N_0 - \mu t$：每个属的灭绝速率 $\mu$ 恒定，与属的年龄无关。
(b) 年长的属灭绝率更低：谱系会随着年龄对灭绝的抵抗力增强（或者类群由高、低风险属混合组成，高风险者先死）。
(c) 人们本可能指望谱系随适应而越来越善于幸存，或指望其衰老。恒定的速率说明适应永远积累不成持久的优势，因为环境——尤其与之共同进化的其他物种——在每条谱系看来都在不断恶化：这就是红皇后假说。
:::
:::

::: exercise 比较两次辐射 {level=2}
加勒比四个岛上，安乐蜥各自进化出相似的生态形态型。系统发育分析显示，每岛上的各生态形态型之间，比各岛上同一生态形态型与别岛同一生态形态型之间亲缘更近。(a) 这对生态形态型的起源方式有何寓意？(b) 怎样的另一棵树会意味着每个生态形态型只起源一次？(c) 这一结果对进化的可预测性有何提示？
::: solution
(a) 每个生态形态型在每座岛上、由该岛上的祖先各自独立进化而来：趋同进化，重复了四次。
(b) 若每个生态形态型跨岛构成一个进化枝（所有枝栖型聚在一起，所有干-地型聚在一起），则每个形态型起源一次并扩散于各岛之间。
(c) 在相似的生态机会与相似的祖先之下，自然选择反复产生相似的结局——提示适应辐射在生态类型的层级上可以是决定论的，即使细节（以及哪个物种扮演哪个角色）受制于机缘。
:::
:::

::: exercise 检验关键创新 {level=3}
一位研究者提出花距是被子植物的关键创新。(a) 为什么只比较一个有距属与其无距姊妹属不够？(b) 描述一个更好的检验。(c) 若各研究都显示有距属更丰富，应考虑哪些替代解释？
::: solution
(a) 任何一对姊妹群都相差许多性状与历史；更丰富的进化枝可能凭机会更丰富（多样化是随机的），或因某个其他性状。
(b) 找出花距的许多次独立起源（借助系统发育），对每一次，把有距进化枝与其无距姊妹群（同岁）比较。若在显著多于随机的比较中有距进化枝更丰富（符号检验，或基于模型的多样化速率比较），关联便得到支持——Hodges 与 Arnold 在 *Aquilegia* 中、其他研究者在被子植物整体中正是如此发现的。
(c) 花距可能与别的因素相关（如专门的动物传粉、特定的生境或地理背景）；更丰富的进化枝可能被分类学家更爱细分；或者因果方向相反（因其他原因正在多样化的谱系里，花距进化得更频繁）。机制联系——距长的改变导致传粉者转变与生殖隔离——可加强论证。
:::
:::

::: exercise 由酶变晶状体蛋白 {level=3}
许多脊椎动物的晶状体蛋白与代谢酶或热激蛋白相同或几乎相同；在某些物种里，同一基因产物在其他组织中充当酶，在晶状体中却充当晶状体蛋白（"基因共享"，Joram Piatigorsky）。(a) 解释为什么这支持"征用"是通往新性状之路。(b) 若该基因发生重复，预期随时间会怎样？(c) 解释为什么这类新性状常常诉诸顺式调控的改变。
::: solution
(a) 一个既已存在、稳定且在高浓度下可溶的蛋白质，通过在晶状体里高水平表达而被征用进新角色（折射光线）；无须从头进化出任何新蛋白质。新性状起源于基因表达地点的改变，随后加以精制。
(b) 重复的一个拷贝可以专职化：一个为晶状体优化（稳定性、折射性质），另一个保留酶的功能，从而化解两种功能间的冲突（"逃离适应冲突"，即亚功能化）。实际确实如此：鸭的 δ-晶状体蛋白由重复的精氨基琥珀酸裂解酶基因编码，其中一个拷贝已基本丧失酶活性。
(c) 在新组织中表达一个基因，需要其调控序列（增强子）的改变；增强子可以具有组织特异性，不触动蛋白质及其余功能，从而避开蛋白质改变将在其发挥作用的一切地方带来的有害副作用（多效性）。
:::
:::
