自然选择是产生适应的唯一过程，但并不是唯一改变等位基因频率的过程。在[[evolution/natural-selection]]中我们列出过哈迪-魏因贝格平衡的诸假设；其中每一个不成立的假设都是一种进化力量。**突变**创造新的等位基因。**遗传漂变**——有限数量配子的抽样造成的随机改变——改变着每一个非无穷大群体的频率。**基因流**使等位基因在各群体之间移动。这三种力量不是枝节问题。突变是一切变异的最终来源；漂变主宰着大多数新突变——包括有利突变——的命运，并决定了物种 DNA 序列间的大部分差异；而基因流决定着各群体是分道扬镳还是浑然一体。

本章以第一课程的深度定量地处理每一种力量。我们建立漂变的赖特-费希尔模型，导出新突变最终被固定的概率——中性时为 $1/2N$，受青睐时约为 $2s$——并说明突变与漂变如何共同催生分子进化的中性学说与分子钟。包含扩散近似与并合理论的完整理论见 [[population-genetics]]。

## 突变

::: definition 突变与突变率 {#def-mutation}
**突变**是 DNA 序列的可遗传改变：**点突变**（一个碱基被另一个替换——**转换**指嘌呤之间或嘧啶之间的替换，**颠换**指嘌呤与嘧啶之间的替换）、小的**插入或缺失**（indel），或较大的结构改变（染色体片段的重复、缺失、倒位、易位；转座子插入；全基因组复制）。**突变率** $\mu$ 是一个位点（或基因）在一个配子中每世代发生突变的概率，以每碱基对每世代或每基因座每世代表示。
:::

动物中只有种系的突变才能遗传；而植物的种系设立很晚，生长中枝条上的体细胞突变可以进入花。突变率很低，而且在基因组大小相似的生物之间、按每个碱基计算惊人地接近：*E. coli* 与酵母每次复制约 $10^{-10}$ 到 $10^{-9}$，而从父母子女测序得到的结果是，人类每碱基对每世代约 $1.2\times10^{-8}$（Augustine Kong 及同事，2012，冰岛人群）。二倍体基因组约 $6.4\times10^9$ 碱基对，所以每人携带约 $6.4\times10^9\times1.2\times10^{-8} \approx 77$ 个新点突变，正落在测序所见的 60–80 这一范围内；多数来自父亲，且数目随父亲的年龄增长，因为精原细胞在整个成年期持续分裂。

功能序列中的大多数突变是有害的或近乎中性的；只有一小部分是利的。一个突变是好是坏取决于环境：使细菌对抗生素产生抗性的突变，在没有抗生素时通常会减慢其生长。

::: warning "突变总是有害的"与"突变在需要时才发生"
蛋白质编码与调控序列中的大多数突变有害或中性，但有利突变是每一种适应的原料，而且在许多基因组大量的非编码部分中，多数突变是中性的。同样，突变不是定向的：卢里亚（Salvador Luria）与德尔布吕克（Max Delbrück）的经典波动试验（1943）以及 Joshua 与 Esther Lederberg 的影印培养实验（1952）证明，抗性细菌在选择它们的那个因子接触*之前*就已出现，而不是应其需要而出现。突变相对于适合度是随机的——尽管它在其他意义上并非处处随机——有些位点，例如甲基化的 CpG 二核苷酸，突变率是其他位点的十倍以上。
:::

### 单靠突变是一种微弱的力量

设等位基因 $A$ 以每世代 $\mu$ 的速率突变为 $a$，此外别无力量作用。则 $p_{t+1} = p_t(1 - \mu)$，故

$$
p_t = p_0(1 - \mu)^t \approx p_0e^{-\mu t}.
$$ {#eq-mutpressure}

设每基因座每世代 $\mu = 10^{-5}$，则 $p$ 减半需 $\ln 2/\mu \approx 69{,}000$ 代。回复突变（$a\to A$，速率 $\nu$）给出平衡 $\hat p = \nu/(\mu + \nu)$，达到得同样慢。突变改变等位基因频率之慢，远甚于即便微弱的选择；它的重要性在于提供新的等位基因，供选择与漂变作用。

### 突变-选择平衡

有害等位基因由突变产生、被选择清除，并稳定在一个平衡上。

::: proposition 突变-选择平衡 {#prop-mutsel}
设 $A_2$ 由 $A_1$ 以速率 $\mu$ 突变产生，适合度为 $w_{11} = 1$、$w_{12} = 1 - hs$、$w_{22} = 1 - s$。若 $\mu \ll s$，则 $A_2$ 的平衡频率近似为

$$
\hat q \approx \frac{\mu}{hs}\quad (h \text{ 不接近 } 0),\qquad \hat q \approx \sqrt{\frac{\mu}{s}}\quad (h = 0,\ \text{完全隐性}).
$$ {#eq-mutsel}
:::

::: proof
平衡时，每一代被选择清除的等位基因数等于由突变新产生的数目，约为 $\mu p \approx \mu$（因 $q$ 很小）。由 [[evolution/natural-selection#eq-diploid-dp]]，选择使 $q$ 改变 $\Delta q = -pq[\,q(w_{22} - w_{12}) + p(w_{12} - w_{11})\,]/\bar w$。$q$ 小时，$p \approx 1$ 且 $\bar w \approx 1$：若 $h > 0$，杂合子项占主导，$\Delta q \approx -hsq$；令 $hsq = \mu$ 得 $\hat q = \mu/(hs)$。若 $h = 0$，只有纯合子受选择而 $\Delta q \approx -sq^2$；令 $sq^2 = \mu$ 得 $\hat q = \sqrt{\mu/s}$。
:::

$\mu = 10^{-5}$、$s = 0.1$ 时，完全隐性的等位基因平衡在 $\sqrt{10^{-4}} = 0.01$，比 $h = 0.1$ 者（$\hat q = 10^{-5}/0.01 = 0.001$）常见一百倍。隐性的有害等位基因躲在杂合子里，这就是我们每个人都携带好几个的原因，也是近交——把它们暴露为纯合子——会降低适合度的原因（[[population-genetics]]）。

## 遗传漂变

任何现实群体都是有限的。下一代的基因是当代基因的一个*样本*，抽样就带来机会。10 个个体的群体中，频率 0.5 的等位基因下一世代很容易变成 0.3 或 0.7；一百万个体的群体中，它会落在距 0.5 不足零点几个百分点的范围内。频率在世代之间的随机游走就是**遗传漂变**。

::: definition 赖特-费希尔模型 {#def-wf}
在**赖特-费希尔模型**中，大小恒为 $N$ 的二倍体群体（故一个基因座上有 $2N$ 个基因拷贝）以离析、不重叠的世代繁殖。每一代的 $2N$ 个拷贝都从前一代的基因库中有放回地独立抽取。若一个等位基因有 $i$ 个拷贝、频率 $p = i/2N$，则下一世代的拷贝数 $i'$ 服从二项分布：

$$
\Prob(i' = j) = \binom{2N}{j}p^j(1 - p)^{2N - j},\qquad j = 0, 1, \ldots, 2N.
$$ {#eq-wf}
:::

由二项分布的均值与方差，下一世代的频率 $p' = i'/2N$ 满足

$$
\E[p'] = p, \qquad \Var(p') = \frac{p(1 - p)}{2N}.
$$ {#eq-wf-var}

期望频率不变——漂变没有方向——但其方差为 $p(1 - p)/2N$：群体越小它越大。因为期望改变为零而方差不为零，频率便四处游走，直到撞上 0（等位基因**丢失**）或 1（**固定**）。两者都是吸收态：等位基因一旦消失，没有突变或迁移就再也回不来。

对每代两个个体、每个体两个拷贝的模型（$2N = 4$），它是拷贝数 $0, 1, 2, 3, 4$ 上的一个马尔可夫链，转移矩阵的每一行都是由[[#eq-wf]]给出的二项分布。

:::

::: proposition 中性等位基因的固定概率 {#prop-neutralfix}
在没有选择与突变的赖特-费希尔模型中，频率为 $p_0$ 的等位基因最终以概率 $p_0$ 被固定。特别地，一个以 $2N$ 个拷贝中的一个存在的新中性突变，被固定的概率为

$$
u = \frac{1}{2N}.
$$ {#eq-neutralfix}
:::

::: proof
两个论证，各有启发。

*对称性。* 最终，群体中全部 $2N$ 个拷贝都恰好源自当前存在的某个拷贝（把时间倒回，谱系不断并合，直到只剩一个祖先）。没有选择时，当前 $2N$ 个拷贝中的每一个都同样可能成为那个祖先，概率 $1/2N$。若那个祖先拷贝是它的 $i_0 = 2Np_0$ 个拷贝之一，该等位基因即被固定，其概率为 $i_0/2N = p_0$。

*鞅。* 由[[#eq-wf-var]]，$\E[p_{t+1} \mid p_t] = p_t$，故对一切 $t$ 都有 $\E[p_t] = p_0$。当 $t\to\infty$ 时，$p_t$ 以概率 $u$（固定）为 1，否则为 0，所以 $\E[p_\infty] = u$。于是 $u = p_0$。（严格化这一极限需要用到有界收敛定理。）
:::

其后果意义深远。每 $2N$ 个产生的中性突变中，平均有一个被固定，其余全部丢失。在大群体中，一个中性突变几乎不可能被固定——但产生的中性突变也多得多。而它一旦被固定，就要花很长时间：木村资生（Motoo Kimura）与太田朋子（Tomoko Ohta）1969 年用扩散近似证明，一个注定要固定的中性突变平均约需 $4N$ 代。

### 杂合度的丢失

漂变摧毁群体内的遗传变异。设 $H_t$ 为期望杂合度，即第 $t$ 代随机（不放回）抽取的两个基因拷贝是不同等位基因的概率。

::: proposition 漂变下杂合度的衰减 {#prop-hdecay}
在没有突变的赖特-费希尔模型中，

$$
H_t = H_0\left(1 - \frac{1}{2N}\right)^t \approx H_0e^{-t/2N}.
$$ {#eq-hdecay}
:::

::: proof
取第 $t + 1$ 代的两个不同拷贝。两者都是从第 $t$ 代的 $2N$ 个拷贝中独立抽出的，所以以概率 $1/2N$ 它们是同一个亲本基因的拷贝、彼此相同；以概率 $1 - 1/2N$ 它们来自两个不同的亲本拷贝，而后者以概率 $H_t$ 互不相同。于是 $H_{t+1} = (1 - 1/2N)H_t$。
:::

因此杂合度以约 $2N\ln 2 \approx 1.4N$ 代的半衰期衰减。50 个个体的群体约 70 代丢失一半变异；$10^6$ 的群体则要花一百多万代。

::: example 漂变的模拟 {#ex-wfsim}
下面的 Python 程序（仅用标准库）模拟 $N = 50$ 个二倍体个体的赖特-费希尔模型。它一次一个地引入 20,000 个新的中性突变，记录有多少被固定、各花了多久；然后跟踪 2000 个从 $p = 0.5$ 起步的 $N = 20$ 群体，对 $t$ 代之后的 $2pq$ 取平均。把输出与[[#eq-neutralfix]]和[[#eq-hdecay]]比较。

```python
import random

def wright_fisher(N, i0, rng):
    """Run neutral WF from i0 copies among 2N until loss or fixation."""
    i, g = i0, 0
    while 0 < i < 2 * N:
        p = i / (2 * N)
        i = sum(rng.random() < p for _ in range(2 * N))   # binomial(2N, p)
        g += 1
    return i == 2 * N, g

rng = random.Random(2026)
runs = [wright_fisher(50, 1, rng) for _ in range(20000)]
times = [g for fixed, g in runs if fixed]
print(len(times) / 20000, sum(times) / len(times))
```

输出（种子 2026）：20,000 个突变中固定了 207 个，比例为 **0.01035**，到固定的平均时间为 **193.9** 代。杂合度模拟（种子 11）在 10、20 与 40 代之后的 $2pq$ 均值为 0.385、0.299 与 0.175。
::: solution
理论：$u = 1/2N = 1/100 = 0.0100$。模拟比例 0.01035 的标准误为 $\sqrt{0.01\times0.99/20{,}000} = 0.0007$，与预测之差不到半个标准误。一个新突变的平均固定时间由扩散近似预测为 $-4N\,\frac{1 - p}{p}\ln(1 - p)$，取 $p = 1/2N$，则 $N = 50$ 时为 199 代，接近 $4N = 200$；模拟的 193.9 在抽样误差内相符（固定时间极为参差，而观察到的固定只有 207 次）。

至于杂合度，[[#eq-hdecay]] 取 $N = 20$ 预测 $0.5\times(39/40)^t$：$t = 10$、20、40 时为 0.388、0.301 与 0.182，与 0.385、0.299 和 0.175 相当吻合（每个模拟均值的标准误约为 0.003）。注意变异的丢失并不是因为哪个群体"有条不紊地变得杂合度更低"：每个重复各自游走，越来越多地撞上 0 或 1。
:::
:::

### 有效群体大小

现实群体违反赖特-费希尔的诸假设：两性数目可能不等，家系大小比二项分布更参差，群体大小随时间改变。所有这些效应都由**有效群体大小** $N_e$ 概括——即呈现同样多的漂变（例如同样的杂合度丢失速率）的理想赖特-费希尔群体的大小。在[[#eq-wf-var]]与[[#eq-hdecay]]中，把 $N$ 换成 $N_e$。

两个标准结果：

- 设繁殖雄性 $N_m$ 头、繁殖雌性 $N_f$ 头，则 $N_e = \dfrac{4N_mN_f}{N_m + N_f}$（赖特（Wright），1931）。下一代每个常染色体基因的一半都来自雄性，无论雄性多么少。
- 若大小在 $t$ 代之间波动，$N_e$ 是**调和平均数**：$\dfrac{1}{N_e} = \dfrac{1}{t}\sum_{i=1}^{t}\dfrac{1}{N_i}$，由其中最小的几个值主导。

::: example 瓶颈与多雌群 {#ex-ne}
(a) 一个象海豹群体有繁殖雄性 10 头、繁殖雌性 90 头。其有效大小是多少？(b) 一个群体一代为 1000，在一次瓶颈中跌到 10，随后恢复到 1000。三代之间的有效大小是多少？
::: solution
(a) $N_e = 4\times10\times90/(10 + 90) = 3600/100 = 36$，尽管繁殖个体有 100 头。雄性之间为交配展开的激烈竞争（[[evolution/sexual-selection]]）会大幅缩小 $N_e$。

(b) $1/N_e = \tfrac13(1/1000 + 1/10 + 1/1000) = \tfrac13(0.102) = 0.034$，故 $N_e = 29.4$。瓶颈的那一代起支配作用。1890 年代，捕猎使北象海豹 *Mirounga angustirostris* 只剩大约几十头；如今虽然恢复到数十万头，其遗传多样性仍极低。**奠基者效应**是同一现象，只不过发生在新群体由少数个体开创之时。
:::
:::

### 漂变与选择共同作用

每个等位基因，无论受不受青睐，都逃不过漂变。一个新的有利突变以单个拷贝起步，在选择来不及发挥作用的头几代里，它极有可能因偶然而丢失。

::: proposition 有利突变的固定概率 {#prop-haldane}
考虑一个新的突变，以单个拷贝存在，使其杂合携带者获得小的适合度优势 $s$（$0 < s \ll 1$；适合度为 $1$、$1 + s$ 与 $1 + 2s$），处于个体后代数目近似服从泊松分布的大群体中。它最终被固定的概率近似为

$$
u \approx 2s
$$ {#eq-haldane}

（霍尔丹（J. B. S. Haldane），1927）。更精确地，木村资生（1962）的扩散近似给出，对有效大小 $N_e = N$、初始频率 $p = 1/2N$ 的群体，

$$
u = \frac{1 - e^{-4Nsp}}{1 - e^{-4Ns}} = \frac{1 - e^{-2s}}{1 - e^{-4Ns}},
$$ {#eq-kimura}

当 $4Ns \gg 1$ 时它接近 $2s$，当 $4N\lvert s\rvert \ll 1$ 时接近中性值 $1/2N$。
:::

::: proof 霍尔丹的分支过程论证
在突变体仍然罕见时，它的拷贝几乎全在杂合子中，每个拷贝留下独立的、近似泊松分布、均值为 $1 + s$ 的拷贝数。设 $x$ 为一个拷贝的后裔最终灭绝的概率。该谱系灭绝，当且仅当它的 $k$ 个后代拷贝各自的谱系都灭绝，于是

$$
x = \sum_{k\ge0}\frac{e^{-(1+s)}(1 + s)^k}{k!}x^k = e^{-(1+s)(1 - x)}.
$$

记存活概率 $u = 1 - x$。则 $1 - u = e^{-(1+s)u}$。$u$ 小时，把指数展开到二阶：$1 - u \approx 1 - (1 + s)u + \tfrac12(1 + s)^2u^2$，得 $u \approx 2s/(1 + s)^2 \approx 2s$。突变一旦逃脱丢失、达到几百个拷贝，选择就几乎确定地把它带到固定，所以这个分支过程的存活概率就是固定概率。
:::

::: example 大多数有利突变会丢失 {#ex-beneficial}
一个突变在 $N = 100$ 的群体中给杂合子带来 5 % 的优势。按霍尔丹与木村资生，它被固定的机会各是多少？模拟给出什么？与中性突变比较。
::: solution
霍尔丹：$u \approx 2s = 0.10$。木村资生：$u = (1 - e^{-0.1})/(1 - e^{-20}) = 0.09516/1 = 0.0952$。精确求解分支过程方程 $1 - u = e^{-1.05u}$ 得 0.0937。在选择先于二项抽样的赖特-费希尔模拟中（种子 7，20,000 个新突变），固定的比例为 **0.0918**（标准误 0.002），与上述相符。中性突变的固定概率为 $1/200 = 0.005$；优势把固定的机会提高了约 19 倍——然而这样明确有利的突变仍有 90 % 以上会丢失。适应需要同一个有利突变发生多次，这在群体大时容易、群体会小时很难。
:::
:::

关键量是 $N_es$。当 $4N_e\lvert s\rvert \gg 1$ 时选择支配漂变；当 $4N_e\lvert s\rvert \ll 1$ 时漂变支配选择。同一个突变，在大群体中可有效受选择，在小群体中却几乎是有效中性的。太田朋子的**近中性学说**（1973）建立在此之上：许多突变是轻微有害的，$\lvert s\rvert$ 接近 $1/N_e$，所以小群体固定更多这样的突变，并且预期它们蛋白质的分子进化速率更快。

## 基因流

**基因流**是个体或配子（花粉、幼虫、孢子）扩散并随后繁殖造成的等位基因在群体之间的移动。它使群体均一化，对抗漂变与局部选择造成的分歧。

::: proposition 迁移的岛模型 {#prop-migration}
设一个群体（岛）每一代繁殖个体中的 $m$ 部分，是来自一个大源群体（大陆）的迁移者，源群体中等位基因频率 $p_M$ 恒定。则

$$
p_{t+1} = (1 - m)p_t + mp_M,\qquad p_t - p_M = (1 - m)^t(p_0 - p_M).
$$ {#eq-migration}
:::

::: proof
岛的下一代抽自这样的基因库：其 $1 - m$ 部分是本地的（频率 $p_t$），$m$ 部分是迁移来的（频率 $p_M$），由此得第一个方程。两边减去 $p_M$：$p_{t+1} - p_M = (1 - m)(p_t - p_M)$；迭代。
:::

与大陆的差每 $\ln 2/m$ 代减半——$m = 0.01$ 时只需 69 代。基因流是一股强大的均一化力量。

与漂变相平衡时，基因流设定群体间分化的水平。在赖特的岛模型中，许多大小为 $N$ 的群体以速率 $m$ 交换迁移者，分化的标准度量 $F_\mathrm{ST}$（总遗传方差中位于群体之间的部分所占的比例）达到平衡

$$
F_\mathrm{ST} \approx \frac{1}{1 + 4Nm}
$$ {#eq-fst}

（中性等位基因、$m$ 小、无突变）。引人注目的是，它依赖于每代迁移者的*数目* $Nm$，而不只依赖迁移率：约每代一个迁移者（$Nm = 1$，$F_\mathrm{ST} = 0.2$）就足以阻止中性等位基因在不同群体中固定到不同的等位基因，无论群体有多大。而面对*选择*，基因流也能淹没局部适应：一个局部受青睐、优势为 $s$ 的等位基因，要在接收迁移者的岛上存续，条件是 $m$ 不比 $s$ 大太多（[[evolution/speciation]]）。

::: quiz
某植物的两个群体各有 $N = 10^4$ 个个体，彼此每代各接受一个迁移者。第三对群体各有 $N = 100$，也每代交换一个迁移者。中性基因座达到平衡时，哪一对分化更大？
- [ ] 小的那一对，因为小群体中漂变更强。
- [ ] 大的那一对，因为一个迁移者占大群体的比例更小。
- [x] 都一样：一阶近似下二者的 $F_\mathrm{ST}$ 均 $\approx 1/(1 + 4Nm) = 0.2$。
::: solution
小群体中漂变更强，但一个迁移者在那里是更大的比例（$m = 0.01$ 对 $m = 10^{-4}$），两个效应恰好抵消：$F_\mathrm{ST}$ 取决于 $Nm$，这里都是 1。这就是赖特的著名结果。
:::
:::

## 分子进化的中性学说

到 1960 年代中期，蛋白质电泳与测序已经揭示了两个意外。其一，群体比预想的富含变异得多：Lewontin 与 Hubby（1966）发现 *Drosophila pseudoobscura* 约三分之一的酶基因座是多态的，同年 Harry Harris 在人中也发现同样水平的多态。其二，物种之间的氨基酸替换以大致恒定的每年速率累积。1968 年，木村资生提出：这些分子变异与变化大多是**选择中性**的、由突变与漂变支配；Jack King 与 Thomas Jukes 在 1969 年提出了同样的论证。

::: definition 替代 {#def-substitution}
**替代**是一个新突变在群体或物种中的固定，取代先前的等位基因。**替代速率** $k$ 是一条谱系上每位点（或每基因座）每世代（或每年）的替代数目。
:::

::: proposition 中性替代速率 {#prop-neutralrate}
若中性突变以每位点每世代 $\mu$ 的速率、在大小恒为 $N$ 的二倍体群体中产生，则中性突变的替代速率为

$$
k = 2N\mu\times\frac{1}{2N} = \mu,
$$ {#eq-neutralrate}

与群体大小无关。
:::

::: proof
每一代，群体的 $2N$ 个基因拷贝在该位点平均产生 $2N\mu$ 个新的中性突变。由[[#prop-neutralfix]]，每一个最终被固定的概率是 $1/2N$。长期固定速率就是两者之积。
:::

这就是**分子钟**的理论基础；分子钟由埃米尔·祖克尔坎德尔（Zuckerkandl）与鲍林（Pauling）（1962、1965）从"血红蛋白在不同物种间的差异大致与其分歧时间成比例"这一观察提出。如果大多数替代是中性的，它们就以突变率累积，而突变率在一条谱系上大致恒定，于是两个物种之间的差异数随两者分裂以来的时间线性增长。大群体产生更多突变，但每个被固定的机会更小；两个效应恰好抵消。

中性学说做出可检验的预测。

- **功能约束。** 越不重要的位点进化越快，因为其突变中有害的比例更少。密码子中的同义位点（不改变氨基酸的位点）进化快于非同义位点；假基因摆脱了一切约束，进化更快；在蛋白质中，表面残基快于活性部位。纤维肽在纤维蛋白原被活化时即被弃置，其进化比组蛋白 H4 快数百倍——组蛋白 H4 中几乎每个残基都举足轻重。
- **世代时间效应。** 若 $\mu$ 按世代计，短命生物的"年钟"应当更快。对 DNA 确实如此（啮齿类比灵长类快），对蛋白质则不然——太田朋子的近中性学说解释了这一格局，因为短命物种往往群体较大，其中轻微有害的突变固定得较少。
- **变异与替代是同一过程的两个阶段**：种内多态性是一群正在去往固定或丢失之路上的突变的一张快照。

中性学说是一个零假说，不是对选择的否认：适应性替代当然会发生，而且它们留下足迹。非同义与同义替代速率之比 $\omega = d_N/d_S$，对中性进化的编码序列约为 1，对大多数基因远小于 1（纯化选择清除大多数氨基酸改变），只有正选择反复青睐改变的场所才大于 1，如某些免疫与生殖蛋白。分子进化中有多大比例是适应性的，至今仍有争论：对 *Drosophila* 的估计提示，约一半氨基酸替换由正选择驱动，而在人科中这一比例要小得多。

::: example 用分子钟为一次分歧定年 {#ex-clock}
两个果蝇物种在一组基因的同义位点上有 2.0 % 不同（已对多重命中作校正）。设同义突变是中性的，以每位点每世代 $\mu = 3\times10^{-9}$ 发生，且每年 10 代。两个物种何时分歧？
::: solution
自两条谱系分裂以来，每条都以每位点每世代 $k = \mu$ 累积替代，所以 $T$ 代之后的期望分歧为 $d = 2\mu T$（两条谱系）。按年计的速率为 $\mu = 3\times10^{-8}$，于是

$$
T = \frac{d}{2\mu} = \frac{0.020}{2\times3\times10^{-8}\ \mathrm{yr^{-1}}} = 3.3\times10^5\ \text{年}.
$$

两条告诫。其一，遗传分歧其实始于物种分裂之前，因为祖先群体本已多态；两条序列的共同祖先，其时代平均比分裂早约 $2N_e$ 代，当 $N_e$ 相对于所测时间很大时这一点很重要（[[evolution/human-evolution]]）。其二，分子钟必须校准——用化石或实测的突变率——而且不同谱系的速率不同；现代方法允许这种"宽松的"（relaxed）分子钟（[[evolution/phylogenetics]]）。
:::
:::

::: application 保护生物学与小群体的遗传学
漂变与近交是濒危物种面临的实际问题。小的圈养或野生群体以每代 $1/2N_e$ 的速率丢失杂合度，固定轻微有害的等位基因，并因近交使隐性等位基因得以表现。佛罗里达美洲豹（*Puma concolor coryi*）到 1990 年代初衰落到约 20–30 头，伴有弯尾、心脏缺陷与精子质量低下；1995 年放归 8 头来自得克萨斯的雌性美洲豹以恢复基因流（"遗传拯救"），此后数量、杂合度与存活率都上升了。保护遗传学在 [[conservation-biology]] 中展开。
:::

::: history
苏厄尔·赖特（1931，《孟德尔群体中的进化》）与罗纳德·费希尔（1922、1930）创立了随机漂变理论；[[#def-wf]] 的二项模型以两人的名字共同命名。霍尔丹 1927 年导出固定概率 $2s$。赖特引入了有效群体大小与 $F$ 统计量（1931、1951）。木村资生在 1950 与 1960 年代把扩散方程用于基因频率，于 1962 年给出固定概率[[#eq-kimura]]。祖克尔坎德尔与鲍林提出分子钟（1962、1965）；Lewontin 与 Hubby 以及 Harris 测定了蛋白质多态性（1966）；木村资生（1968，《Nature》）与 King 和 Jukes（1969，《Science》，"非达尔文进化"）提出了中性学说；太田朋子补上了近中性学说（1973）。木村资生的《分子进化的中性学说》（*The Neutral Theory of Molecular Evolution*，1983）对这一主张作了总结，由它开启的旷日持久的"中性—选择"之争自此一直塑造着分子进化研究。
:::

::: summary
- 突变是变异的最终来源；人类每个碱基每世代的突变率约为 $10^{-8}$（每人约 60–80 个新突变）。仅靠突变压力改变频率极慢。
- 有害等位基因稳定在突变-选择平衡：$\hat q \approx \mu/(hs)$，完全隐性时为 $\sqrt{\mu/s}$。
- 漂变：在赖特-费希尔模型中，$\E[p'] = p$ 且 $\Var(p') = pq/2N$；杂合度按 $(1 - 1/2N)^t$ 衰减。
- 中性等位基因以等于其频率的概率被固定；一个新中性突变的固定概率为 $1/2N$，若固定则约需 $4N$ 代。
- 有效大小 $N_e$ 取代 $N$：两性不等时为 $4N_mN_f/(N_m + N_f)$，大小波动时取调和平均数。
- 一个新的有利突变以约 $2s$ 的概率被固定（霍尔丹）、$(1 - e^{-2s})/(1 - e^{-4Ns})$（木村资生）：大多数会丢失。当 $4N_e\lvert s\rvert \gg 1$ 时选择战胜漂变。
- 基因流：$p_t - p_M = (1 - m)^t(p_0 - p_M)$；$F_\mathrm{ST} \approx 1/(1 + 4Nm)$，所以约每代一个迁移者即可阻止中性分歧。
- 中性学说：替代速率 $k = \mu$，与 $N$ 无关；分子钟的基础。受约束的位点进化慢；$d_N/d_S > 1$ 是正选择的信号。
:::

## 练习

::: exercise 漂变的方差 {level=1 check="0.0025"}
$N = 50$ 个二倍体个体的赖特-费希尔群体中，某等位基因频率为 0.5。它下一代频率的方差是多少？
::: solution
$\Var(p') = pq/2N = 0.25/100 = 0.0025$（标准差为 0.05）。
:::
:::

::: exercise 中性突变的机会 {level=1 check="0.0005"}
有效大小为 1000 的二倍体群体中，一个新中性突变最终被固定的概率是多少？
::: solution
$1/2N_e = 1/2000 = 0.0005$。
:::
:::

::: exercise 两性不等的有效大小 {level=1 check="64"}
一个圈养群体有繁殖雄性 20 头、繁殖雌性 80 头。其有效大小是多少？
::: solution
$N_e = 4N_mN_f/(N_m + N_f) = 4\times20\times80/100 = 6400/100 = 64$，约为 100 头繁殖动物的三分之二。
:::
:::

::: exercise 突变-选择平衡 {level=2 check="0.002"}
一个完全隐性的有害等位基因 $s = 0.25$，以每世代 $\mu = 10^{-6}$ 由突变产生。其平衡频率约为多少？
::: solution
$\hat q \approx \sqrt{\mu/s} = \sqrt{4\times10^{-6}} = 0.002$。
:::
:::

::: exercise 杂合度减半 {level=2 check="34"}
有效大小为 25 的群体中，期望杂合度减半需要多少代（用精确公式，取最近整代）？
::: solution
$2N_e = 50$ 时，$(1 - 1/50)^t = 0.5$ 给出 $t = \ln 0.5/\ln 0.98 = 0.6931/0.02020 = 34.3$，所以约 34 代。近似式 $2N_e\ln 2 = 34.7$ 与之相符。
:::
:::

::: exercise 岛与大陆 {level=2 check="0.613"}
某岛群体的等位基因频率为 0.9；大陆为 0.2。$m = 0.1$（每代）且无其他力量时，5 代后岛上的频率是多少（保留三位小数）？
::: solution
由[[#eq-migration]]，$p_5 = 0.2 + (0.9)^5(0.9 - 0.2) = 0.2 + 0.5905\times0.7 = 0.2 + 0.413 = 0.613$。五代之内，岛已经走完了到大陆频率全程的约 40 %。
:::
:::

::: exercise 大群体中的有利突变 {level=2}
一个杂合优势为 $s = 0.01$ 的突变在 $N = 10^5$ 的群体中发生一次。(a) 估计它的固定概率。(b) 若向该等位基因的突变率为每基因拷贝每世代 $10^{-8}$，每代产生多少个这样的突变？预期要等多久才会出现一个注定要固定的？
::: solution
(a) $4Ns = 4000 \gg 1$，故 $u \approx 2s = 0.02$（木村资生的公式给出 $(1 - e^{-0.02})/(1 - e^{-4000}) = 0.0198$）。
(b) 每代新拷贝：$2N\mu = 2\times10^5\times10^{-8} = 0.002$。每代成功者：$0.002\times0.02 = 4\times10^{-5}$，所以期望等待时间为 $1/(4\times10^{-5}) = 25{,}000$ 代。来自新突变的适应可能受供给限制；在极大的群体（细菌、昆虫）中供给高得多，适应常常利用已存在的变异。
:::
:::

::: exercise 解读替代速率表 {level=3}
氨基酸替代速率的近似值（单位为每位点每年 $10^{-9}$）：纤维肽 8.3，血红蛋白 α 1.2，细胞色素 c 0.3，组蛋白 H4 0.01。(a) 在中性学说之下，既然每位点的突变率对这四个基因应当大致相同，是什么决定了这些差异？(b) 若把纤维肽视为几乎不受约束，则对每种蛋白质，有多大比例的氨基酸突变是中性的？(c) 对另一种蛋白质的高速率，什么观察会提示它是正选择而非约束放松所致？
::: solution
(a) 速率为 $k = f_0\mu$，其中 $f_0$ 是中性突变所占的比例；其余是有害的、被淘汰了。功能约束更多的蛋白质 $f_0$ 更小。
(b) 相对纤维肽：血红蛋白 α $1.2/8.3 = 0.14$；细胞色素 c $0.3/8.3 = 0.036$；组蛋白 H4 $0.01/8.3 = 0.0012$。也就是说，组蛋白 H4 中大约每 800 个氨基酸改变才有一个被容忍。
(c) 同一基因中非同义替代速率*高于*同义位点（$d_N/d_S > 1$）——中性至多使两者相等。进一步的证据：这种过剩集中在功能重要的位点（例如免疫受体的结合位点），以及多态性数据中选择清除的足迹。
:::
:::

::: exercise 用霍尔丹的论证求固定 {level=3}
(a) 对 $s = 0.1$ 数值求解 $1 - u = e^{-(1+s)u}$，并与 $2s$ 和 $2s/(1+s)^2$ 比较。(b) 若后代数的方差为 $\sigma^2$ 而非泊松值 $1 + s \approx 1$，结果推广为 $u \approx 2s/\sigma^2$。解释为什么少数个体留下极多后代的物种（方差大）中，选择相对于漂变更弱，并把它与有效群体大小联系起来。
::: solution
(a) 迭代 $u \leftarrow 1 - e^{-1.1u}$ 得 $u = 0.176$。比较 $2s = 0.2$ 与 $2s/(1+s)^2 = 0.165$：$s = 0.1$ 时简单近似高估约 13 %；$s = 0.01$ 时精确到约 1 %。
(b) 后代数方差高时，一个谱系的命运就更取决于运气：连受青睐的突变也更可能恰好落在一个没有留下后代的个体身上。存活率变为 $2s/\sigma^2$，更接近中性值。同样的高方差也使 $N_e$ 远小于实际计数的大小（如[[#ex-ne]]，雄性交配成功率的方差压低了 $N_e$），于是漂变相对于选择更强——两种描述是等价的。
:::
:::
