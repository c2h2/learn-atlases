达尔文把书名定为《物种起源》，但书里关于一个物种如何变成两个物种，说得却出奇地少。这个问题比看起来更难。自然选择与漂变改变着群体；但一个群体要分裂成各自独立进化的谱系，必须有东西阻止两部分的基因相互混合。物种之内，基因流是一股均一化的力量（[[evolution/mutation-drift-gene-flow]]）；物种之间，它被阻断。物种形成就是这种阻断——**生殖隔离**——的进化，而生命的多样性，已描述的约二百万个物种加上更多尚未描述的，正是它一而再、再而三地发生所积累的结果。

本章先问什么是物种——这比听起来不那么不言自明——以及为什么生物学家对不同用途使用多种物种概念。然后我们对隔离物种的屏障分类并度量它们，看它们如何作为分歧的副产品、经贝特森–杜布赞斯基–缪勒不亲和性而产生，并考察物种形成的地理格局——异域、周边、邻域与同域——及实例。最后谈多倍化与杂交导致的物种形成，以及基因组学关于伴随基因流的物种形成揭示了什么。

## 什么是物种？

野外自然学家在自己生活的地方辨认物种几乎从不费力：花园里的鸟、林子里的树落入界限分明的类型，中间类型很少。恩斯特·迈尔（Mayr）注意到，新几内亚阿尔法克山区居民所识别的物种，与西方鸟类学家的物种几乎一一对应。分明性是真实的。困难在于说*清楚*物种为什么分明，以及如何处理难题：外表相似但不杂交的群体、外表有别却杂交的群体、无性生殖的生物，以及化石。

::: definition 生物学物种概念 {#def-bsc}
"物种是实际或潜在在自然状态下相互交配的自然群体，并与其他这样的群体在生殖上相互隔离"（恩斯特·迈尔，1942）。在这一**生物学物种概念**（biological species concept，BSC）下，物种的定义性特征是与其他物种的生殖隔离：那些阻止或减少基因流的屏障，称为**隔离机制**或**生殖屏障**。
:::

生物学物种概念解释了物种为什么分明：基因流把一个物种维系在一起，它的缺失使物种得以各自分歧。它也把物种形成的问题准确地摆了出来：生殖隔离如何进化？但它有众所周知的局限。它无法用于无性生物（多数细菌，以及蛭形轮虫等无性动物）或化石；"潜在可以杂交"对于永不见面的群体无从检验；而许多公认的好种——栎、鸭、袖蝶（*Heliconius*）、许多植物——在自然界杂交并交换部分基因而不合并。

其他概念强调别的性质。

- **系统发育物种概念**：物种是具有祖裔格局的、可鉴定个体的最小集群（Joel Cracraft，1983）；一个常见变体是最小单系群（[[evolution/phylogenetics]]）。它适用于无性生物与化石，但倾向于承认多得多的物种，因为任何始终可区分的群体都够格。
- **形态学（表型）物种概念**：物种由形态上一贯的差异区分。这是博物馆分类学家与古生物学家实际使用的概念，而对**隐存种**——生殖隔离却外表无异的群体——它无能为力。对曾被视为一个新种的中美洲弄蝶 *Astraptes fulgerator*（在哥斯达黎加）做 DNA 条形码鉴定，揭示了至少十个物种，幼虫与寄主植物各不相同（Paul Hebert 及同事，2004）。
- **生态学物种概念**：物种是占据一个独特适应区的谱系（Leigh Van Valen，1976）。
- **进化物种概念与一般谱系概念**：物种是独立进化的集合种群谱系（George Gaylord Simpson，1961；Kevin de Queiroz，1998、2007）。按 de Queiroz 的看法，诸概念不是彼此竞争的定义，而是谱系在分歧过程中不同时刻获得的诸种**判据**——生殖隔离、可鉴定性、单系性、生态独特性。分歧早期的两个群体可能满足某些判据而不满足另一些；分歧由此而生。

::: warning "物种是界限分明的固定类别"
物种形成是一个需要时间的过程，常常要几十万年乃至几百万年，所以在任何时刻，总有一些群体对正走在过程中间：部分隔离、在接触带的杂交带内杂交，或被某些屏障而非另一些屏障隔离。这些中间情形不是物种概念的失败，而是进化的预言。**环种**常被引为空间上的例证——青藏高原四周的淡绿柳莺（*Phylloscopus trochiloides*）与加州中央谷地四周的剑螈（*Ensatina eschscholtzii*）：相邻的群体沿环带相互杂交，而两端的终结类型相遇时却不交配而共存（尽管细致的遗传学工作表明，两个环上的基因流都并非连续的）。
:::

## 生殖屏障

::: definition 合子前与合子后隔离 {#def-barriers}
**合子前屏障**在受精之前起作用：**生态（生境）隔离**（群体生活或繁殖在不同场所）、**时间隔离**（繁殖季或一天中的时刻不同）、**行为（性）隔离**（另一群体的配偶不被选择）、**机械隔离**（外生殖器或花不匹配）与**配子隔离**（精子或花粉不能完成受精）。**合子后屏障**在受精之后起作用：**杂种不活**（杂种死亡）、**杂种不育**（杂种存活但不繁殖，如骡）与**杂种衰败**（第一代杂种可育，但其后代孱弱或不育）。合子后屏障可以是**内在的**（在任何环境中都表达的开发不亲和），也可以是**外在的**（杂种居中，两个亲本生态位都不适应；或对配偶没有吸引力）。
:::

屏障沿生命史依序起作用，总隔离度是它们的综合。每一屏障都可通过比较异种交配与同种交配在该阶段的成功率来量化。一个广泛使用的指数（James Sobel 与 Gina Chen，2014）为

$$
RI = 1 - 2\,\frac{H}{H + C},
$$ {#eq-ri}

其中 $H$ 与 $C$ 为异种与同种交配在该阶段的成功频率（或速率）：$RI = 1$ 表示完全隔离，$0$ 表示没有隔离，负值表示异种交配反而更成功。若后起屏障只能作用于先前屏障放行的部分，则各自允许 $1 - RI_1, 1 - RI_2, \ldots$ 比例基因流的屏障，其总隔离度为

$$
RI_\mathrm{total} = 1 - \prod_i(1 - RI_i)
$$ {#eq-ritotal}

（适用于以基因流的比例性削减度量的屏障）。

::: example 量化沟酸浆属两个物种之间的隔离 {#ex-ri}
Justin Ramsey、Toby Bradshaw 与 Douglas Schemske（2003）测量了加州两种沟酸浆（*Mimulus*）——*Mimulus lewisii*（粉色，熊蜂传粉）与 *M. cardinalis*（红色，蜂鸟传粉）——之间的屏障。取同类别的示例数值：在混合小区内，一次造访某物种之后的传粉者访问中，80 % 仍访同一物种、20 % 转向另一物种；在同时带有混合花粉的柱头上，本物种花粉使 90 % 的种子受精；杂种种子的萌发与存活和纯种一样好。计算各阶段的隔离度与总隔离度。
::: solution
传粉者隔离：$RI_1 = 1 - 2\times0.2/(0.2 + 0.8) = 1 - 0.4 = 0.6$。

花粉竞争（一个配子屏障）：$RI_2 = 1 - 2\times0.1/(0.1 + 0.9) = 0.8$。

杂种活力：$RI_3 = 0$。

总计，由[[#eq-ritotal]]：$1 - (1 - 0.6)(1 - 0.8)(1 - 0) = 1 - 0.4\times0.2 = 0.92$。

花的颜色、形状与花蜜——吸引不同的传粉者——单独贡献最大。真实研究中，地理与生态分隔（两种生于不同海拔）贡献最大，传粉者隔离次之，总隔离度超过 99 %。普遍的教训——如今已在许多系统中重复——是生命史早期起作用的屏障常对总隔离贡献最大，因为后期屏障只能作用于所余无几的基因流。
:::
:::

### 霍尔丹法则

1922 年，霍尔丹（J. B. S. Haldane）指出："当两个不同动物类群杂交的 F₁ 子代中有一个性别缺如、稀少或不育时，那个性别就是异配性别。"哺乳类与果蝇中，不育或不活的杂种是雄性（XY）；以雌性为异配性别（ZW）的鸟类与蝶类中，则是雌性。**霍尔丹法则**（Haldane's rule）在数百个案例中成立。主要解释是**显性理论**（H. Allen Orr 与 Michael Turelli）：X（或 Z）染色体上隐性等位基因参与的不亲和性，在只有一条拷贝的异配性别中充分表达，在同配性别中则被掩盖。第二个因素，至少在果蝇的育性方面，是影响雄性育性的基因进化快（"雄性更快"进化）。

## 隔离如何进化：贝特森–杜布赞斯基–缪勒不亲和性

杂种不育曾是一个难题。若骡之所以不育，是因为马与驴的基因不能合作，那么祖先群体怎能不经过育性降低的阶段而变成马和驴？自然选择不可能偏爱一个使其携带者适合度降低的等位基因。

威廉·贝特森（Bateson，1909）、杜布赞斯基（Theodosius Dobzhansky，1936）与缪勒（Hermann Muller，1942）各自独立给出了答案。设祖先群体基因型为 $aabb$。一个隔离群体在第一个基因座上固定等位基因 $A$：$AAbb$ 完全适合。另一个在第二个基因座上固定 $B$：$aaBB$ 完全适合。两个群体都不曾经过任何不适合的基因型。但 $A$ 与 $B$ 从未在一起接受过检验；若它们相处不佳，杂种 $AaBb$ 的适合度就降低。隔离作为分歧的**副产品**进化，而不是因为它受偏爱。

::: definition 贝特森–杜布赞斯基–缪勒不亲和性 {#def-bdm}
**贝特森–杜布赞斯基–缪勒（BDM）不亲和性**，指在两个或多个基因座上、在不同群体中分歧了的等位基因之间的有害上位互作：这些等位基因在各自的遗传背景中功能正常，但一旦在杂种中相遇便降低适合度。
:::

BDM 不亲和性已在分子层面被鉴定。果蝇中，*D. melanogaster* 雌性与 *D. simulans* 雄性的杂种死亡，致死性依赖于 *D. melanogaster* 的杂种雄虫拯救（*Hybrid male rescue*，*Hmr*）等位基因与 *D. simulans* 的杂种致死拯救（*Lethal hybrid rescue*，*Lhr*）等位基因的相互作用——这两个基因编码在异染色质上相互作用的蛋白质（Daniel Barbash、Nicholas Brideau 及同事，2003–2006）。其中许多基因在正选择下快速进化，常常是在与自私遗传元件的遗传冲突中——这提示冲突可能是不亲和性的重要引擎。

Orr 在 1995 年指出一个重要推论。一条谱系中每一次新的替代，都可能与另一条谱系中已发生的替代不亲和，也可能与自己谱系中较早发生、却尚未与之共同检验过的替代不亲和。

::: proposition 雪球效应 {#prop-snowball}
设两条谱系自分裂以来共累积 $K$ 次替代，而任何一对尚未在同一基因组中共同检验过的衍生等位基因形成两基因座不亲和性的小概率为 $p$，则不亲和性数目的期望近似按

$$
I_K \approx p\,\frac{K(K - 1)}{2} \approx \frac{pK^2}{2},
$$ {#eq-snowball}

增长，快于与分歧程度的线性关系（Orr，1995）。若 $K$ 随时间线性增长，不亲和性的数目就随时间的平方增长。
:::

::: proof 要点
第 $K$ 次替代可能与两条谱系已有差异、且尚未在其自身遗传背景中检验过的位置上的衍生等位基因不亲和；在 Orr 的模型中，这一数目约为在先的 $K - 1$ 次替代的量级（更确切地说，是另一谱系中的那些，加上自身谱系中较早发生、尚未与新等位基因共同检验过的那些）。所以第 $K$ 次替代大约新增 $p(K - 1)$ 个不亲和性，$K$ 次替代之后的总数为 $p[1 + 2 + \cdots + (K - 1)] = pK(K - 1)/2$。
:::

::: widget plot
f: p*x*(x-1)/2; p*x
x: 0, 100
y: 0, 50
sliders: p=0.01:0.001:0.05:0.001
labels: \text{雪球式: } pK(K-1)/2; \text{线性: } pK
caption: 两基因座不亲和性数目的期望[[#eq-snowball]]对两条谱系间替代数 $K$ 的曲线，$p$ 为一对未检验的衍生等位基因互不相容的概率。作为对照的直线，是每次替代只固定新增不亲和性数时的样子。早期两者相似、隔离很弱；随后二次曲线陡然起飞。雪球效应预言隔离应先缓慢出现、再迅速累积——与来自果蝇及野生番茄（*Solanum*）的比较数据一致：渐渗系中检出的不亲和性数目随分歧程度快于线性增长（Matute 及同事，2010；Moyle 与 Nakazato，2010）。
:::

::: example 雪球效应的数字 {#ex-snowball}
设每一对未检验的衍生等位基因有千分之一的可能互不相容。10、100 与 1000 次替代之后，期望有多少个不亲和性？
::: solution
按[[#eq-snowball]]，$p = 0.001$：$K = 10$：$0.001\times45 = 0.045$；$K = 100$：$0.001\times4950 = 4.95$；$K = 1000$：$0.001\times499{,}500 = 499.5$。分歧程度增加十倍，不亲和性增加一百倍。即使单个的不亲和性很罕见，它们终将多到足以使杂种不活或不育。
:::
:::

## 物种形成的地理格局

物种形成按分歧群体之间的地理关系分类，因为地理决定分歧必须克服多大的基因流。

::: definition 物种形成的方式 {#def-modes}
**异域物种形成**（allopatric speciation）：群体在地理上被屏障分隔而分歧（**地理分隔**，vicariance，屏障把分布区分成两半；或**扩散**，dispersal，一个群体拓殖远方）。**周边物种形成**（peripatric speciation）：特例——由少数个体奠基的小型边缘群体发生分歧，漂变起作用（迈尔，1954）。**邻域物种形成**（parapatric speciation）：相邻群体之间在边界两侧有限的基因流下分歧，常沿环境梯度发生。**同域物种形成**（sympatric speciation）：在单一群体内部、没有地理分隔的分歧，隔离是在起初畅通的基因流面前进化出来的。
:::

**异域物种形成**在动物中被普遍接受为最常见的方式，因为地理隔离不付代价地消除基因流，选择与漂变造成的分歧再把隔离作为副产品带来。证据包括被地理屏障分开的**姊妹种**（彼此的最近亲）。约 300 万年前合龙的巴拿马地峡分隔了海洋群体；Nancy Knowlton 及同事（1993）研究了加勒比侧与太平洋侧外形几乎相同的鼓虾（*Alpheus*）物种对，发现多数对已大体或完全生殖隔离。这些对的遗传分歧程度不一，与一些对在最终合龙之前就已分隔相一致。

**周边物种形成**经由奠基者效应，为迈尔所强调；岛屿上的辐射——夏威夷的 *Drosophila*（果蝇）有数百种，许多只限于单个岛屿——常被引为例证。漂变本身的作用有争论：小群体漂变固然快，变异也少，而单独的奠基事件在实验室里很少能产生隔离。

### 伴随基因流的分歧

邻域与同域物种形成要求在基因流存在下分歧。正如 [[evolution/mutation-drift-gene-flow#prop-migration]] 所示，基因流使群体均一化得很快。只有选择能够抵抗它。

::: proposition 岛屿上的迁移-选择平衡 {#prop-migsel}
考虑岛屿上一个单倍体基因座，等位基因 $A$ 受局部偏爱（适合度 1，等位基因 $a$ 为 $1 - s$），并设每一代岛群体被大陆迁来者替换的比例为 $m$，大陆固定为 $a$。若迁移发生在选择之前，则岛上 $A$ 的平衡频率为

$$
\hat p = \frac{s - m}{s(1 - m)} \approx 1 - \frac{m}{s}\quad (m < s),
$$ {#eq-migsel}

而 $m \ge s$ 时 $A$ 丢失（$\hat p = 0$）。
:::

::: proof
迁移后，$p_m = (1 - m)p$。选择后，由[[evolution/natural-selection#eq-haploid]]（$a$ 处于劣势），$p' = p_m/(1 - s(1 - p_m))$。平衡时 $p' = p$；若 $p \ne 0$，两边除以 $p$ 得 $1 - s + s(1 - m)p = 1 - m$，故 $p = (s - m)/[s(1 - m)]$。仅当 $m < s$ 时它为正；否则唯一平衡是 $p = 0$。$m$ 与 $s$ 很小时，$p \approx (s - m)/s = 1 - m/s$。
:::

::: example 局部适应能在基因流下幸存吗？ {#ex-migsel}
一个黑色熔岩土壤的小岛上，深色体色等位基因 $A$ 相对浅色等位基因 $a$ 有 10 % 的存活优势，$a$ 固定于沙质大陆。若每代岛上繁殖个体的 1 % 是大陆迁移者，$A$ 的平衡频率是多少？5 % 呢？12 % 呢？用数值迭代校核第一种情形。
::: solution
由[[#eq-migsel]]，$s = 0.1$：$m = 0.01$ 时，$\hat p = 0.09/(0.1\times0.99) = 0.909$（近似式 $1 - m/s$ 给 0.90）。$m = 0.05$ 时，$\hat p = 0.05/(0.1\times0.95) = 0.526$。$m = 0.12 > s$ 时，内部平衡不存在，$A$ 丢失。在 Python 中从 $p = 0.99$ 起按"先迁移、后选择"迭代直到稳定，$m = 0.01$ 得 0.9091，$m = 0.05$ 得 0.5263；$m = 0.12$ 时频率趋零，与预言一致。基因流增加十倍——从 1 % 到 12 %——就把群体从几乎完全局部适应带到一无所有。
:::
:::

::: widget plot
f: max(0, (s - x)/(s*(1 - x)))
x: 0, 0.3
y: 0, 1
sliders: s=0.1:0.01:0.3:0.01
labels: \hat p
caption: 岛上受局部偏爱等位基因的平衡频率[[#eq-migsel]]对迁移率 $m$（横轴）的曲线，$s$ 为局部选择系数。迁移相对于选择很弱时，等位基因维持在高频；随 $m$ 增大几乎线性下降；一旦 $m \ge s$ 便完全丢失——基因流"淹没"了局部适应。增大 $s$，看阈值如何右移。因此，承受强分歧选择的基因座可以在基因组其余部分被基因流均一化的同时保持分化。
:::

这张图解释了在对分歧群体基因组测序中的一项关键观察：**分化基因组岛**——在其余区域分化度很低的背景上，群体之间分化很强的区段。承受分歧选择的基因座（及与其紧密连锁的基因座）抵御基因流，而基因组其余部分是共享的。于是伴随基因流的物种形成，要求基因组越来越多的部分被隔离——例如受选基因座同时影响交配，或配偶选择与局部适应在基因组上发生关联（染色体倒位内重组受抑有帮助）。

**生殖强化**。当两个在异域分歧过的群体重新接触、且杂种适合度低时，选择可以偏爱避开另一群体交配的个体，从而*加强*合子前隔离。这就是**生殖强化**（reinforcement），杜布赞斯基的想法。Jerry Coyne 与 Allen Orr 对果蝇物种对的比较（1989、1997）提供了经典证据：在同一遗传距离上，同域对（曾有机会被强化）之间的合子前隔离远强于异域对，而合子后隔离没有差别。鹟属（*Ficedula*）鸟类中也有生殖强化的记录：与白领鹟接触的斑鹟，演化出了与白领鹟差别更大的羽色。

### 同域物种形成

同域物种形成长期受到怀疑，因为它要求分裂选择强大到足以克服重组——重组时刻在拆散适应基因与配偶选择基因之间的联系。如今在少数研究充分的案例中它已被接受。

- **植食昆虫的宿主宗**。苹果实蝇 *Rhagoletis pomonella* 原产北美，原在山楂上繁殖。苹果由欧洲引入，19 世纪中叶在哈德逊河谷首次记录到它在苹果上（Benjamin Walsh，1867）。蝇在寄主果实上交配，所以选择寄主就是选择配偶；苹果比山楂成熟早，苹果宗的羽化也更早。Guy Bush（1969）及后来的 Jeffrey Feder 及同事表明，苹果宗与山楂宗在寄主偏好与羽化时间上有差异，在染色体倒位内的若干基因座上基因频率不同；两宗之间每代基因流以百分之几计。它们是否会完成物种形成，尚不可知。
- **火山口湖鱼类**。小型、与外隔绝、年轻、只经历过一次定殖的火山口湖提供了天然试验场。尼加拉瓜的阿波约湖是一个形成不足约 2.3 万年的火山口湖，Marta Barluenga 及同事（2006）在其中发现了一个慈鲷新种——细长的敞水区箭形慈鲷 *Amphilophus zaliosus*，由湖底的米达斯慈鲷 *A. citrinellus* 在湖内进化而来。更早也从喀麦隆的火山口湖描述过类似情形（Ulrich Schliewen 及同事，1994），尽管后来的基因组工作提示有些定殖可能不止一波。
- **多倍化**（见下）是最常见的"即时"同域物种形成形式。

::: quiz
两种亲缘关系很近的蛙在一个地区于同一池塘繁殖（同域），在别的地区则分居异地（异域）。它们鸣声的差异，在共存的地方比不共存的地方大得多。这一格局提示什么解释？
- [ ] 杂种不育在同域进化得更快。
- [x] 生殖强化：针对杂交的选择在同域加强了行为隔离。
- [ ] 漂变，它在同域更强。
- [ ] 由单一群体的同域物种形成。
::: solution
相遇群体的交配信号分歧大于分离群体的，是生殖强化（更一般地是**生殖性状置换**，reproductive character displacement）的印记。它要求杂种或杂交交配的适合度降低，从而使挑剔的个体留下更多后代。需要排除的另一种解释是：只有本来就足够不同的群体才能共存；生殖强化的预言是，同域的**交配性状**上的挑剔特异地更强——Coyne 与 Orr 对合子前（而非合子后）隔离的发现正是如此。
:::
:::

## 多倍化与杂交导致的物种形成

在植物中，一个新物种可以在一个世代内产生。**多倍体**具有两套以上的染色体组。**同源多倍体**由一个物种内部的基因组加倍产生；**异源多倍体**起源于两个物种的杂种，随后其基因组加倍。只含两个亲本各一套染色体的不育二倍体杂种，在减数分裂中染色体无法配对；加倍之后每条染色体有了伙伴，异源多倍体便可育（[[genetics]]）。它与两个亲本都生殖隔离，因为与亲本回交产生三倍体，而三倍体大多不育。

::: example 婆罗门参属的新物种 {#ex-tragopogon}
婆罗门参属（*Tragopogon*）的三个二倍体种——*Tragopogon dubius*、*T. pratensis* 与 *T. porrifolius*——各有 $2n = 12$ 条染色体，二十世纪初由欧洲引入美国西北部 Palouse 地区。1950 年，Marion Ownbey 在那里描述了两个他处不产的新种：*T. mirus* 与 *T. miscellus*。若它们是异源四倍体，你预期它们有多少条染色体？如何检验它们的起源？它们为什么与亲本生殖隔离？
::: solution
每个亲本的配子带 $n = 6$ 条染色体。杂种有 $6 + 6 = 12$ 条，父母各一套，无法配对；加倍得 $2n = 24$，每一亲本的两套完整俱全。两个新种确实都是 $2n = 24$。它们的起源可通过将其染色体与 DNA 和候选亲本比较来检验：*T. mirus* 结合了 *T. dubius* 与 *T. porrifolius* 的基因组，*T. miscellus* 结合了 *T. dubius* 与 *T. pratensis* 的。Douglas 与 Pamela Soltis 及同事的分子研究表明，两者都曾在不同小镇反复、独立地由其亲本形成。异源四倍体（配子 12 条）与二倍体亲本（6 条）的杂交产生 18 条染色体的三倍体，其配子不平衡，大多不育：四倍体以一个步骤、在几十年内就与亲本隔离了。
:::
:::

多倍化十分普遍：Troy Wood 及同事（2009）估计，被子植物约 15 % 的物种形成事件、蕨类约 31 % 涉及倍性增加。许多作物是多倍体——普通小麦（*Triticum aestivum*）是组合三个祖先基因组的六倍体，棉与甘蓝型油菜是异源四倍体。动物中多倍体物种形成较少，但见于某些蛙、鱼与昆虫；脊椎动物与硬骨鱼的祖先中也发生过全基因组复制（[[evolution/macroevolution]]）。

**同源倍性杂交物种形成**（homoploid hybrid speciation）——不改变染色体数目——更罕见、也更难证实。向日葵属中，Loren Rieseberg 及同事表明，美国西南部的三个种——*Helianthus anomalus*、*H. deserticola* 与 *H. paradoxus*——起源于 *H. annuus* 与 *H. petiolaris* 的杂种，且这些杂种物种占据双亲都不能忍受的极端生境（沙丘、荒漠、盐沼）；他们能在实验杂种系中重现与天然杂种物种类似的基因组组成（1996、2003）。2018 年，Sangeet Lamichhaney、Peter 与 Rosemary Grant 及同事报告，在达芙妮梅杰岛（Daphne Major），一个源自 1981 年一只外来雄性 *Geospiza conirostris* 与 *G. fortis* 雌鸟交配后代的杂种谱系，凭借其独特的鸣声与喙，在几个世代内就实现了生殖隔离。

::: application 保护立法中的物种概念
法律保护的是"物种"，所以物种概念有实际后果。美国《濒危物种法》允许保护脊椎动物的"独特种群片段"（distinct population segments），物种如何界定影响哪些群体够格。在系统发育概念之下把一个广布种拆成几个，会使拆出的每一个都变得稀有；合并群体则可能使独特的谱系得不到保护。杂交带来自己的难题：红狼（*Canis rufus*）与佛罗里达美洲豹都带有近缘类群的基因，保护政策不得不裁定这种混入是否使它们丧失资格。分子数据如今是这些裁定的核心（[[conservation-biology]]）。
:::

::: history
达尔文（1859）把物种视为界限分明的变种，并把物种形成看作分歧的副产品。霍尔丹 1922 年陈述了他的法则。杜布赞斯基的《物种形成的遗传学》（*Genetics and the Origin of Species*，1937）定义了隔离机制，并描述了不亲和性的杜布赞斯基–缪勒模型（贝特森 1909 年已有先见）；迈尔的《物种系统与起源》（*Systematics and the Origin of Species*，1942）提出了生物学物种概念与异域物种形成的论据。Ownbey 于 1950 年描述了 *Tragopogon* 的异源多倍体。Bush 关于 *Rhagoletis* 的工作（1969）重振了同域物种形成的论据。Coyne 与 Orr 对果蝇物种对的比较研究（1989、1997）及其专著 *Speciation*（2004）使该领域定量化；Orr 的雪球模型发表于 1995 年。2000 年代以来，不亲和性背后的基因（*Hmr*、*Lhr*、*Odysseus*、小鼠的 *Prdm9*）以及伴随基因流的分歧全基因组格局已被鉴定。
:::

::: summary
- 生物学物种概念以生殖隔离定义物种；系统发育、形态、生态与谱系概念强调别的判据，谱系在分歧的不同阶段逐一获得它们。
- 生殖屏障或为合子前（生境、时间、行为、机械、配子），或为合子后（不活、不育、衰败；内在或外在）。$RI = 1 - 2H/(H+C)$ 量化每一个；依次起作用的屏障按 $1 - \prod(1 - RI_i)$ 合成，且早期屏障常占主导。
- 霍尔丹法则：杂种不育或不活首及异配性别，主要用隐性 X 连锁不亲和性解释。
- 贝特森–杜布赞斯基–缪勒不亲和性使隔离作为分歧的副产品进化；其数目按约 $pK^2/2$ 滚雪球。
- 异域物种形成常见（如巴拿马两侧的鼓虾）；伴随基因流的分歧需要选择，局部受偏爱等位基因在 $m < s$ 时维持在 $\hat p \approx 1 - m/s$；生殖强化在同域加强合子前隔离。
- 同域物种形成有宿主宗（*Rhagoletis*）与火山口湖慈鲷的记录；多倍化一步产生新植物种（*Tragopogon*）；同源倍性杂交物种形成确有发生（*Helianthus*、达芙妮梅杰岛的雀类）。
:::

## 练习

::: exercise 一个隔离指数 {level=1 check="0.5"}
在配偶选择试验中，雌性与同种雄性交配的比率为 75 %，与异种雄性为 25 %。[[#eq-ri]]的行为隔离指数 $RI$ 是多少？
::: solution
$RI = 1 - 2\times0.25/(0.25 + 0.75) = 1 - 0.5 = 0.5$。
:::
:::

::: exercise 合并屏障 {level=1 check="0.97"}
三个屏障依次起作用，$RI$ 分别为 $0.7$、$0.5$ 与 $0.8$。总隔离度是多少？
::: solution
由[[#eq-ritotal]]，$1 - 0.3\times0.5\times0.2 = 1 - 0.03 = 0.97$。
:::
:::

::: exercise 异源多倍体的染色体数 {level=1 check="38"}
$2n = 18$ 的种与 $2n = 20$ 的种杂交，其后代基因组加倍。所得异源四倍体的染色体数（$2n$）是多少？
::: solution
配子分别带 9 条与 10 条染色体，杂种有 19 条；加倍得 $2n = 38$。（这正是甘蓝型油菜 *Brassica napus*（$2n = 38$）的起源：由 $2n = 20$ 的白菜 *B. rapa* 与 $2n = 18$ 的甘蓝 *B. oleracea* 杂交而来。）
:::
:::

::: exercise 雪球 {level=2 check="190"}
按[[#prop-snowball]]的计数，$K = 20$ 次替代之后，可供形成两基因座不亲和性的衍生等位基因对有多少对？
::: solution
$K(K - 1)/2 = 20\times19/2 = 190$。
:::
:::

::: exercise 基因流对抗选择 {level=2 check="0.8"}
一个局部受偏爱的等位基因在某岛上 $s = 0.05$，该岛接受来自固定了另一等位基因大陆的迁移，速率 $m = 0.01$。用[[#eq-migsel]]的近似式，其平衡频率是多少？
::: solution
$\hat p \approx 1 - m/s = 1 - 0.2 = 0.8$。（精确公式给 $(0.05 - 0.01)/(0.05\times0.99) = 0.808$。）
:::
:::

::: exercise 淹没 {level=2}
用[[#prop-migsel]]解释：物种分布边缘的外围群体，即使对局部适应的选择中等偏强，为什么仍可能无法适应局部条件？这对物种分布区界限的稳定性意味着什么？
::: solution
边缘群体往往很小，又不断接受来自更大的中心群体的迁入者，而中心群体适应的是中心条件。若迁入率 $m$ 超过偏爱局部适应等位基因的局部选择系数 $s$，这些等位基因就被淹没而丢失。即使在阈值以下，局部适应也是不完全的。适应不良使边缘群体保持弱小，它们便受到相对更多的基因流，这可能反过来强化适应的失败：来自中心的基因流能够稳定分布区界限（Mark Kirkpatrick 与 Nicholas Barton，1997 发展了这一假说）。另一方面，适度的基因流也提供遗传变异，所以净效应取决于两者的平衡。
:::
:::

::: exercise 鸟类中的霍尔丹法则 {level=2}
两个鸟种的杂交所得 F₁ 杂种中，雄性可育、雌性不育。(a) 这与霍尔丹法则一致吗？(b) 用显性理论解释。(c) 预言两个蝶种之间、两个哺乳种之间的杂交会看到什么。
::: solution
(a) 一致。鸟类的雌性是异配性别（ZW），不育的正是它们。
(b) 一个物种 Z 染色体上的隐性等位基因与另一物种常染色体等位基因的不亲和性，在只有一条 Z 的 ZW 雌性中充分表达；在 ZZ 雄性中，若另一条 Z 带有相容的显性等位基因，则被掩盖。
(c) 蝶类（鳞翅目）同样雌性为 ZW，所以应先是杂种雌性受害；哺乳类为 XY 雄性，所以应先是杂种雄性不育或不活（如骡、小鼠种间杂交，以及果蝇）。
:::
:::

::: exercise 生殖强化的数据 {level=3}
在一组物种对中，合子前隔离的平均值（标度 0–1）对遗传距离 $D$ 作图。异域对：从 $D = 0.1$ 时的 0.1 升到 $D = 1.0$ 时的 0.9。同域对：在 $D = 0.1$ 时已达 0.8。两组在每个 $D$ 上的合子后隔离相同。(a) 这支持什么假说？(b) 合子后隔离没有差别，为什么重要？(c) 提出一个不涉及生殖强化的替代解释，以及如何排除它。
::: solution
(a) 生殖强化：在杂交可能的同域，针对产生低适合度杂种的选择，在分歧早期就加强了合子前隔离。
(b) 生殖强化只作用于合子前隔离（避免浪费的交配）；若同域对的一切隔离都更大，则两组之间的一般差别（例如同域对比其遗传距离所示的更老）反而是更节省的解释。只有合子前隔离不同，恰恰指向一个以交配为目标的机制。
(c) "差异融合"：接触时没有强合子前隔离的物种对可能已经合并，留下的只是本来就有强隔离的——这是一道过滤器，而不是加强的过程。区分之法是在分布部分重叠的物种对内部检验：生殖强化预言*同一对*物种在同域部分的隔离强于异域部分，差异融合则不预言这一点。
:::
:::

::: exercise 这算一个物种吗？ {level=3}
相邻岛屿上的两个蜥蜴群体在体色上存在稳定的差异，且带有固定的线粒体 DNA 差异，但放在一起饲养时自由交配并产生可育杂种。(a) 在生物学、系统发育与形态学概念下，它们算独立物种吗？(b) 解释 de Queiroz 的一般谱系概念如何处理这一案例。(c) 你还会收集哪些数据？
::: solution
(a) 生物学概念：可能不算——它们"潜在可以杂交"，尽管圈养条件未必反映自然的配偶选择与野外的杂种适合度。系统发育概念：可以算，因为它们可鉴定地不同（体色与 mtDNA），且各自可能是单系的。形态学概念：若颜色差异稳定，则算。
(b) 一般谱系概念把它们视为独立进化的谱系（隔着海，基因流很少），并把诸判据看作分歧程度的证据。它们满足可鉴定性，但不满足生殖隔离；是否称其为物种，取决于要求多少独立进化的证据，许多生物学家会依用途把它们定为亚种或种。
(c) 多个核基因座的 DNA，检验它们是否在全基因组范围都是独立谱系（mtDNA 会误导，例如在选择清除之后）；岛屿之间基因流的估计；自然条件下的配偶选择与杂种适合度测定；以及生态差异的数据。
:::
:::
