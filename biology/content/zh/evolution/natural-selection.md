达尔文的伟大洞见在于：一个没有远见的过程，能够产生看起来经过设计的生物。鹰眼、金枪鱼的流线型身体与植物开花的时机，都与各自的功能如此契合，以至于几个世纪以来它们一直被当作设计者存在的证据。自然选择把这种契合解释为一种简单统计偏倚的累积结果：每一代中，碰巧携带着能改善其在所处环境中存活或繁殖的变异的个体，会留下更多后代，于是这些变异变得更常见。在数千代中不断重复，微小的偏倚便筑起复杂的适应。

本章把这一论证变成定量预测。我们先给出选择发生的条件，再建立在一个群体中追踪基因所需的群体遗传学工具：基因型频率与等位基因频率，以及哈迪-魏因贝格平衡（遗传平衡）——它描述一个不受任何力量作用的群体。我们把选择加到一个单倍体、然后又到一个二倍体群体上，看看显性、杂合子优势与选择的强度如何决定其进程。接着转向连续性状——喙深、体型——其中育种方程用遗传率从选择差预测响应。最后谈选择不能做什么。孟德尔遗传学假定已由 [[genetics]] 具备；更深的理论在 [[population-genetics]] 中展开。

## 达尔文的论证

《物种起源》的论证可以表述为三项观察与一个结论。

1. **变异。** 群体中的个体在性状上彼此不同。
2. **遗传。** 变异中有一部分是可遗传的：子女比无亲缘关系的个体更像自己的父母。
3. **差异繁殖。** 产生的后代多于能够存活并繁殖的数目，而在其所处的环境中，携带某些变异的个体比其他个体存活或繁殖得更好。

**结论：** 与更高繁殖成功相关的可遗传变异在世代之间频率上升，群体因而改变。若环境保持不变，群体就变得更适应它——它发生**适应**。

三个条件缺一不可。没有变异，便无可选择；没有遗传，幸存者的优势便传不下去（一群骡子可以被选择，却不能进化）；没有繁殖成功率的差异，频率只随机会改变。还要注意这一论证*不*需要什么：它不要求变异因需要而发生。突变的发生不问其是否有用，萨尔瓦多·卢里亚（Luria）与马克斯·德尔布吕克（Delbrück）1943 年对细菌噬菌体抗性的研究已经证明这一点（[[genetics]]）。选择是过程中非随机的部分；变异是随机的部分。

::: definition 适合度与选择系数 {#def-fitness}
一个基因型的**绝对适合度** $W$ 是该基因型的个体预期贡献给下一代的后代数（存活到生殖年龄的概率乘以繁殖力）。**相对适合度** $w$ 是绝对适合度除以一个参考基因型（通常是最适基因型）的绝对适合度，故参考基因型有 $w = 1$。相对适合度为 $w = 1 - s$ 的基因型的**选择系数** $s$ 度量其适合度的相对降低（或写作 $w = 1 + s$ 时，度量其优势）。**自然选择**是由可遗传表型的差异引起的个体存活与繁殖的差异。
:::

对频率的改变要紧的只有相对适合度：若每一基因型的绝对适合度都减半，群体缩小，其组成却不变。而且适合度是一个基因型*在特定环境中*的性质：黑色型的桦尺蠖在被烟灰熏黑的树皮上适合度更高，在长满地衣的树皮上则更低。

::: example 从野外普查求相对适合度 {#ex-fitness}
某甲虫群体中，绿色个体 80 % 存活到繁殖并平均每只产 50 粒卵；褐色个体 60 % 存活并平均每只产 60 粒。计算绝对适合度、相对适合度与选择系数。
::: solution
绝对适合度（每个新孵化个体的卵数）：绿色 $0.80\times50 = 40$，褐色 $0.60\times60 = 36$。以绿色为基准，褐色有 $w = 36/40 = 0.90$，故对褐色的选择系数 $s = 0.10$。褐色存活较差却产卵较多；这一权衡部分抵偿了损失——适合度必须把两个组分合在一起衡量。只测存活会得出大得多的劣势：$1 - 0.60/0.80 = 0.25$。
:::
:::

## 不受任何力量作用的群体：哈迪-魏因贝格

在说明选择能做什么之前，得先知道没有它会发生什么。早期的孟德尔派曾疑惑显性性状为什么不席卷群体；1908 年，数学家哈迪（G. H. Hardy）与医生魏因贝格（Wilhelm Weinberg）各自独立给出了答案。

考虑一个二倍体、有性生殖群体中一个常染色体基因座上的两个等位基因 $A_1$ 与 $A_2$。设 $P$、$H$、$Q$ 为基因型 $A_1A_1$、$A_1A_2$、$A_2A_2$ 的频率（$P + H + Q = 1$）。等位基因 $A_1$ 的频率为

$$
p = P + \tfrac12 H,
$$ {#eq-allele-freq}

因为每个个体带有两份拷贝，纯合子携带两份、杂合子携带一份；且 $q = 1 - p = Q + \tfrac12 H$。

::: proposition 哈迪-魏因贝格原理 {#prop-hw}
在一个个体数无穷（极大）、随机交配、世代离析且不重叠、无突变、无迁移、无选择、两个性别等位基因频率相同的群体中，经过一代随机交配后，基因型频率为

$$
f(A_1A_1) = p^2,\qquad f(A_1A_2) = 2pq,\qquad f(A_2A_2) = q^2,
$$ {#eq-hw}

无论亲本的基因型频率如何，而等位基因频率 $p$ 与 $q$ 世代保持不变。
:::

::: proof
随机交配下，形成一个合子等价于从配子库中独立地抽取两个配子。每个 $A_1A_1$ 亲本只产生 $A_1$ 配子，每个杂合子按相等比例产生 $A_1$ 与 $A_2$（孟德尔第一定律），所以 $A_1$ 在配子中的频率为 $P + \tfrac12H = p$。两次独立抽取以概率 $p^2$ 得 $A_1A_1$，以概率 $q^2$ 得 $A_2A_2$，以概率 $pq + qp = 2pq$ 得杂合子（$A_1$ 可以来自两个配子中的任一个）。在子代中，由[[#eq-allele-freq]]，$A_1$ 的频率为 $p^2 + \tfrac12(2pq) = p(p + q) = p$：没有改变。既然新的等位基因频率仍是 $p$，下一代的基因型又是 $p^2, 2pq, q^2$。
:::

哈迪-魏因贝格之于进化，犹如牛顿第一定律之于运动：它说只要没有东西作用于等位基因频率，它们就保持不变，并点出确实起作用的各"力"——选择、突变、迁移、漂变（有限群体大小）与非随机交配。它的实际用途有二。它让我们由等位基因频率计算基因型频率（反过来，对隐性性状，则由纯合子的频率求之）；而对它的偏离则揭示其诸假设之一不成立。

::: widget plot
f: x^2; 2*x*(1-x); (1-x)^2
x: 0, 1
y: 0, 1
labels: A_1A_1:\ p^2; A_1A_2:\ 2pq; A_2A_2:\ q^2
vlines: 0.5
caption: 哈迪-魏因贝格基因型频率对 $A_1$ 的等位基因频率 $p$ 的曲线。悬停可读数。注意杂合子频率 $2pq$ 在 $p = 0.5$ 处达到峰值 0.5；还注意当一个等位基因罕见时，它的几乎全部拷贝都在杂合子中：$p = 0.05$ 时，杂合子（$0.095$）几乎是 $A_1A_1$ 纯合子（$0.0025$）的 40 倍。这就是为什么只作用于罕见隐性等位基因纯合子的选择如此微弱。
:::

::: example 检验哈迪-魏因贝格比例 {#ex-hwtest}
在一个具有两个共显性等位基因的基因座上分型的 1000 个个体样本中，有 298 个 $A_1A_1$、489 个 $A_1A_2$ 与 213 个 $A_2A_2$。这些基因型频率与哈迪-魏因贝格比例一致吗？
::: solution
等位基因频率：$p = (2\times298 + 489)/2000 = 1085/2000 = 0.5425$，$q = 0.4575$。

期望计数：$A_1A_1$：$1000p^2 = 294.3$；$A_1A_2$：$1000\times2pq = 496.4$；$A_2A_2$：$1000q^2 = 209.3$。

$$
\chi^2 = \frac{(298 - 294.3)^2}{294.3} + \frac{(489 - 496.4)^2}{496.4} + \frac{(213 - 209.3)^2}{209.3} = 0.047 + 0.110 + 0.065 = 0.22.
$$

共三类，因总数固定为 1000 减一，又因 $p$ 由数据估计再减一：自由度 1。$\chi^2_1$ 的 5 % 临界值是 3.84，所以数据与哈迪-魏因贝格比例完全一致（$P \approx 0.64$）。注意相符并不证明这些假设成立：例如，作用于成体的选择可以在改变等位基因频率的同时，使基因型比例保持在哈迪-魏因贝格附近。χ² 检验本身见 [[biostatistics]]。
:::
:::

::: warning "显性等位基因会变得常见"
显性描述的是等位基因在杂合子表型中如何相互作用，而非它们有多常见。按[[#prop-hw]]，一个不影响适合度的显性等位基因停留在它原有的任何频率上。许多显性等位基因是罕见的（例如软骨发育不全的等位基因），许多隐性等位基因却很常见（O 型血的等位基因）。只有选择、漂变、突变或迁移会改变频率。
:::

## 单倍体群体中的选择

最简单的选择模型追踪一个单倍体生物——细菌，或任何生物的配子——具 $A$ 与 $a$ 两种类型，世代离析。

::: proposition 单倍体选择 {#prop-haploid}
设类型 $A$ 与 $a$ 的相对适合度为 $1 + s$ 与 $1$，$p_t$ 为第 $t$ 代 $A$ 的频率（无突变、无迁移、无漂变）。则

$$
p_{t+1} = \frac{p_t(1 + s)}{1 + sp_t}, \qquad \Delta p = p_{t+1} - p_t = \frac{s\,p_t(1 - p_t)}{1 + sp_t},
$$ {#eq-haploid}

而两种类型之比按几何级数增长：

$$
\frac{p_t}{1 - p_t} = \frac{p_0}{1 - p_0}(1 + s)^t.
$$ {#eq-haploid-ratio}
:::

::: proof
选择后两种类型的比例为 $p_t(1 + s) : (1 - p_t)$，总和为 $\bar w = p_t(1 + s) + (1 - p_t) = 1 + sp_t$，即群体的**平均适合度**。相除得第一个公式；减去 $p_t$ 得 $\Delta p = [p_t(1 + s) - p_t(1 + sp_t)]/\bar w = sp_t(1 - p_t)/\bar w$。至于比值，$p_{t+1}/(1 - p_{t+1}) = (1 + s)\,p_t/(1 - p_t)$；迭代即得。
:::

[[#eq-haploid]] 的三个特征贯穿整个群体遗传学。改变量正比于 $s$，选择的强度。它正比于 $p(1 - p)$，而这正是"携带 $A$"这一 0/1 指示量的方差：*选择需要变异*，任何一种类型罕见时选择都行动缓慢。而由于比值按几何级数增长，有利类型沿一条逻辑斯谛（S 形）曲线上升。

对[[#eq-haploid-ratio]]取对数，从频率 $p_0$ 升到 $p_t$ 所需的世代数为

$$
t = \frac{1}{\ln(1 + s)}\ln\!\left[\frac{p_t(1 - p_0)}{p_0(1 - p_t)}\right] \approx \frac{1}{s}\ln\!\left[\frac{p_t(1 - p_0)}{p_0(1 - p_t)}\right]\quad (s \ll 1).
$$ {#eq-haploid-time}

::: example 抗性突变扩散多快？ {#ex-resistance}
在低剂量抗生素暴露下的一个细菌群体中，一个抗性突变体相对于敏感细胞的相对适合度为 1.1。从一百万个细胞中的一个起步，需要多少代才能占到群体的一半？一个 $s = 0.01$ 的变体从 1 % 升到 99 % 又需要多久？
::: solution
由[[#eq-haploid-time]]，取 $s = 0.1$、$p_0 = 10^{-6}$、$p_t = 0.5$：

$$
t = \frac{\ln[0.5\times(1 - 10^{-6})/(10^{-6}\times0.5)]}{\ln 1.1} = \frac{\ln(999{,}999)}{0.09531} = \frac{13.82}{0.09531} = 145\ \text{代}.
$$

对每小时分裂一次的细菌，这大约是六天。$s = 0.01$、从 0.01 到 0.99：$t = \ln(99\times99)/\ln(1.01) = 9.190/0.009950 = 924$ 代（用 $1/s$ 的近似得 919）。哪怕 1 % 的优势——在任何单独一代中都小到看不出来——也能在不到一千代内把一个变体推到几近固定，而这只是地质时间中的一瞬。
:::
:::

## 二倍体群体中的选择

在二倍体中，选择作用于基因型，而一个等位基因会怎样，取决于它在杂合子中的表现。我们假定随机交配，使合子处于哈迪-魏因贝格比例，并让选择通过存活到成体的差异起作用。

::: proposition 一个基因座上的二倍体选择 {#prop-diploid}
设基因型 $A_1A_1$、$A_1A_2$ 与 $A_2A_2$ 的相对适合度为 $w_{11}$、$w_{12}$ 与 $w_{22}$，$p$ 为合子中 $A_1$ 的频率，合子处于哈迪-魏因贝格比例。则下一代中 $A_1$ 的频率为

$$
p' = \frac{p^2w_{11} + pq\,w_{12}}{\bar w}, \qquad \bar w = p^2w_{11} + 2pq\,w_{12} + q^2w_{22},
$$ {#eq-diploid}

而每代的改变量为

$$
\Delta p = \frac{pq\,[\,p(w_{11} - w_{12}) + q(w_{12} - w_{22})\,]}{\bar w} = \frac{pq}{2\bar w}\,\frac{d\bar w}{dp}.
$$ {#eq-diploid-dp}
:::

::: proof
选择后，各基因型的比例为 $p^2w_{11} : 2pq\,w_{12} : q^2w_{22}$，其和为 $\bar w$。幸存者中 $A_1$ 的频率是（由[[#eq-allele-freq]]）$A_1A_1$ 的份额加上杂合子份额的一半，即 $(p^2w_{11} + pq\,w_{12})/\bar w$。幸存者之间随机交配，在这一新的等位基因频率上恢复哈迪-魏因贝格比例。减去 $p = p\bar w/\bar w$：

$$
\Delta p = \frac{p^2w_{11} + pq\,w_{12} - p(p^2w_{11} + 2pq\,w_{12} + q^2w_{22})}{\bar w}.
$$

利用 $1 - p = q$，分子为 $p^2w_{11}q + pq\,w_{12}(1 - 2p) - pq^2w_{22} = pq[pw_{11} + (q - p)w_{12} - qw_{22}]$，整理即得第一个形式。至于第二个，把 $q = 1 - p$ 代入并对 $\bar w$ 求导：$d\bar w/dp = 2pw_{11} + 2(1 - 2p)w_{12} - 2qw_{22} = 2[p(w_{11} - w_{12}) + q(w_{12} - w_{22})]$。
:::

[[#eq-diploid-dp]] 的第二个形式说，等位基因频率朝着使平均适合度 $\bar w$ 增大的方向移动，速率正比于 $pq$。苏厄尔·赖特（Sewall Wright）1932 年把这想象成群体在攀登一座**适应景观**——一张以等位基因频率为底面、以平均适合度为高度的曲面；罗纳德·费希尔（Ronald Fisher）的**自然选择基本定理**（1930）给出了一个相关的表述：选择引起的平均适合度增长速率等于适合度中的加性遗传方差。两幅图景都只在简化假设（适合度恒定、随机交配、单一基因座）下严格成立，而真实的景观随环境与其他基因座的改变而改变。

### 显性与定向选择

把适合度写成下面的形式很方便：

$$
w_{11} = 1 + s,\qquad w_{12} = 1 + hs,\qquad w_{22} = 1,
$$

其中 $s$ 是 $A_1A_1$ 纯合子的优势，$h$ 是**显性系数**：若（就适合度而言）$A_1$ 是隐性的则 $h = 0$，是显性的则 $h = 1$，效应可加则 $h = \tfrac12$。代入[[#eq-diploid-dp]]，

$$
\Delta p = \frac{s\,pq\,[\,h + p(1 - 2h)\,]}{1 + s(p^2 + 2pqh)}.
$$ {#eq-dominance}

当 $A_1$ 罕见（$p \to 0$）时，$\Delta p \approx s\,h\,p$：等位基因的命运取决于它在杂合子中的效应，因为它几乎全部的拷贝都在杂合子中。一个受青睐的*隐性*等位基因（$h = 0$）罕见时 $\Delta p \approx sp^2$，起初增长极其缓慢。当 $A_1$ 常见（$q \to 0$）时，$\Delta p \approx s(1 - h)q$，正比于 $q$——若 $h = 1$ 则正比于 $q^2$：一个受青睐的显性等位基因难以清除最后的隐性拷贝，因为它们隐藏在杂合子中。

x: 0, 1
sliders: s=0.1:0.01:0.5:0.01; h=0.5:0:1:0.05

caption: 每代等位基因频率的改变（[[#eq-dominance]]），以受青睐等位基因 $A_1$ 的频率 $p$ 为横轴，优势 $s$ 与显性程度 $h$ 可调。$h = 0.5$（可加）时曲线近乎对称。把 $h$ 滑到 0（隐性），可见 $p$ 小时 $\Delta p$ 几乎为零；滑到 1（显性），曲线在 $p = 1$ 附近塌陷。把 $h$ 推到 1 以上（此处不允许），杂合子将成为最适——那正是下一节处理的情形。
:::

::: example 显性、可加与隐性等位基因的比较 {#ex-dominance}
一个新等位基因使纯合子获得 5 % 的优势（$s = 0.05$）。从 $p = 0.01$ 起数值迭代[[#eq-diploid]]到 $p = 0.99$ 得：可加（$h = 0.5$）377 代；显性（$h = 1$）2265 代；隐性（$h = 0$）2171 代。解释这一格局。
::: solution
可加等位基因在杂合子中始终享有 $s/2$ 的优势，稳定推进，如同 $s = 0.025$ 的单倍体情形：由[[#eq-haploid-ratio]]，$\ln(99^2)/\ln 1.025 \approx 372$ 代，与精确的二倍体迭代所得的 377 代很接近（微小差别来自平均适合度分母）。

显性等位基因在罕见时上升很快（杂合子已享有全部优势），但接近固定时，残余的 $A_2$ 几乎全在杂合子中，而杂合子与 $A_1A_1$ 适合度相同；选择只看得到罕见的 $A_2A_2$ 纯合子，其频率为 $q^2$，于是最后一段占据了大部分时间。

隐性等位基因的问题恰好相反：罕见时它几乎总在杂合子中，而杂合子不表现它的优势。它 2171 代中的大部分耗在低频处；一旦常见，固定得很快。霍尔丹（J. B. S. Haldane）1927 年指出，这使得有利隐性突变在异交群体中难以对适应作出贡献（"霍尔丹筛"）。
:::
:::

### 清除隐性致死等位基因

当 $A_2$ 是隐性致死（$w_{22} = 0$、$w_{11} = w_{12} = 1$）时，[[#eq-diploid]] 对 $q$ 化为 $q' = (pq)/(1 - q^2) = q/(1 + q)$。取倒数，$1/q' = 1/q + 1$，于是

$$
q_t = \frac{q_0}{1 + tq_0}, \qquad t = \frac{1}{q_t} - \frac{1}{q_0}.
$$ {#eq-lethal}

把一个致死等位基因从 $q = 0.1$ 降到 $0.01$ 需 $100 - 10 = 90$ 代，再从 $0.01$ 降到 $0.001$ 还要 900 代。罕见的隐性等位基因对选择几乎不可见。这就是为什么在优生学上通过阻止纯合子生育来消灭隐性遗传病的主张，不仅在伦理上站不住脚，在生物学上也是徒劳——庞尼特（R. C. Punnett）1917 年便已指出这一点。

### 杂合子优势与下显性

若杂合子是最适基因型（**超显性**，即杂合子优势），则没有哪个等位基因能固定：无论哪一个变得罕见，它的拷贝都主要处于占优势的杂合子中而受到青睐。

::: proposition 杂合子优势下的平衡 {#prop-overdominance}
设 $w_{11} = 1 - s$、$w_{12} = 1$、$w_{22} = 1 - t$，其中 $0 < s, t \le 1$。则等位基因频率存在一个内部平衡

$$
\hat p = \frac{t}{s + t},\qquad \hat q = \frac{s}{s + t},
$$ {#eq-overdominance}

它是稳定的：从 0 与 1 之间（不含端点）的任何起始频率出发，$p$ 都收敛于 $\hat p$。平衡时的平均适合度为 $\bar w = 1 - st/(s + t)$。
:::

::: proof
由[[#eq-diploid-dp]]，$\Delta p = pq[p(w_{11} - w_{12}) + q(w_{12} - w_{22})]/\bar w = pq(-sp + tq)/\bar w$。在 $(0, 1)$ 内部，当 $sp = tq = t(1 - p)$，即 $p = t/(s + t)$ 时它为零。$p < \hat p$ 时 $tq - sp > 0$，$p$ 增大；$p > \hat p$ 时减小：平衡稳定。在 $\hat p$ 处，$\bar w = 1 - s\hat p^2 - t\hat q^2 = 1 - (st^2 + ts^2)/(s + t)^2 = 1 - st/(s + t)$。
:::

教科书式的例子是在有恶性疟原虫 *Plasmodium falciparum* 疟疾流行的地区，β-珠蛋白基因的镰状细胞等位基因 $HbS$。安东尼·艾利森（Allison）1954 年证明，杂合子（*HbA/HbS*）对重型疟疾有部分抵抗力，而 *HbS/HbS* 纯合子患镰状细胞病，在没有医疗照护的条件下适合度大降。该等位基因在历史上疟疾流行的非洲、地中海地区、中东与印度频率高，在其他地方频率低，与模型吻合。

::: example 一个超显性平衡 {#ex-sickle}
取示例适合度 $w_{AA} = 0.88$（因疟疾而降低）、$w_{AS} = 1$、$w_{SS} = 0.20$。问 $S$ 的平衡频率、出生时杂合子的频率与平均适合度。
::: solution
按[[#prop-overdominance]]的记号，取 $A_1 = A$：$s = 0.12$，$t = 0.80$。于是 $\hat q_S = s/(s + t) = 0.12/0.92 = 0.130$，$\hat p_A = 0.870$。出生时杂合子：$2\hat p\hat q = 2\times0.870\times0.130 = 0.227$，几乎占群体的四分之一。平均适合度：$1 - st/(s + t) = 1 - 0.096/0.92 = 0.896$。从 $q_S = 0.01$ 起迭代[[#eq-diploid]] 200 代达到 $0.1304$，证实了稳定性。群体为此付出代价：每一代约 10 % 的潜在后代损耗于两类纯合子。杂合子优势维持了变异，却不会让群体达到一个全为杂合子的群体那样的适合度——也不可能达到，因为杂合子不能真实遗传。
:::
:::

若杂合子反而*最*不适合（**下显性**，$w_{12}$ 低于两个纯合子），内部平衡存在却不稳定，群体将固定频率超出阈值的那一个等位基因。下显性见于某些染色体重排，其杂合子产生不平衡的配子；它使此类重排难以建立，并在物种形成中起作用（[[evolution/speciation]]）。

维持变异的选择的其他形式包括**负频率依赖选择**——一种类型的适合度随其变稀而升高（植物中罕见的自交不亲和等位基因；针对已适应常见宿主的寄生虫的罕见宿主抗性类型——[[evolution/coevolution]]）——以及在空间或时间上变化的选择。

::: quiz
一个使纯合子适合度降低 10 % 的隐性等位基因频率为 0.01。大约它的多少比例的拷贝位于选择能够起作用的纯合子中？
- [ ] 约 50 %
- [ ] 约 10 %
- [x] 约 1 %
- [ ] 约 0.01 %
::: solution
位于纯合子中的拷贝：$2q^2$ 个，占总数 $2q^2 + 2pq = 2q$ 的比例为 $q = 0.01$，即约 1 %。其余 99 % 隐藏在杂合子中，选择（若是完全隐性）看不到它们。这就是针对罕见隐性等位基因的选择如此缓慢的原因。
:::
:::

## 连续性状上的选择

对适应要紧的多数性状——大小、形状、时机、生理——都连续变异，受许多基因与环境的影响（[[population-genetics]]）。我们用选择对性状分布的作用来描述这种选择。

::: definition 表型选择的模式 {#def-modes}
**定向选择**偏爱分布一端的个体，使均值移动。**稳定选择**偏爱中间值，减小方差（人类出生体重在二十世纪中叶是一个经典例子：当时过轻与过重的婴儿存活率都较低）。**分裂选择**偏爱两端、抑制中间，增大方差（非洲食籽雀 *Pyrenestes ostrinus*，大喙鸟与小喙鸟分别专食硬籽与软籽，Thomas Smith 在 1990 年代作了研究）。**选择差** $S$ 是繁殖个体的性状均值与选择前整个群体均值之差。
:::

选择差有多少会出现在下一代，取决于变异中有多少可以遗传。

::: proposition 育种方程 {#prop-breeder}
对受许多微效基因影响的性状，设亲代的选择差为 $S$，则**选择响应** $R$——子代均值的改变——为

$$
R = h^2 S,
$$ {#eq-breeder}

其中 $h^2$ 是**狭义遗传率**（遗传力），即表型方差 $V_P$ 中来自加性遗传效应 $V_A$ 的比例：$h^2 = V_A/V_P$。假设：子-亲回归是线性的，以对双亲均值的回归计斜率为 $h^2$；两代的环境相同；选择在同一代内发生（无世代重叠或延续效应）。
:::

[[#eq-breeder]] 背后的想法是：$h^2$ 是子代值对双亲均值回归的斜率。被选中的亲本偏离均值 $S$；它们的子女预期偏离斜率乘 $S$。遗传率的估计正是这样做的——由子-亲相似（或由亲属间的相似，或由响应本身，即**实际遗传率** $R/S$）。完整推导是[[population-genetics]]中数量遗传学的一部分。

格兰特夫妇的地雀提供了最有名的自然实例。1977 年达芙妮梅杰岛（Daphne Major）干旱期间，剩下的种子大多是又大又硬的；中地雀群体减少了约 85 %，幸存者的喙平均比干旱前的群体更深。子-亲回归早已表明喙深高度可遗传（Peter Boag，1983），幸存者的子女喙更深，正合[[#eq-breeder]]的预测（Peter Boag 与 Peter Grant，1981）。在 2004–2005 年后来的一次干旱中——彼时更大的竞争者 *Geospiza magnirostris* 已在岛上立足——选择方向相反，偏爱*更小*的喙（彼得·格兰特与罗丝玛丽·格兰特，2006）。

::: example 预测选择响应 {#ex-breeder}
采用与 *Geospiza fortis* 实测值同量级的示例数值：干旱前喙深均值为 9.4 mm；幸存者平均 9.9 mm；喙深的遗传率为 0.79。预测下一代的平均喙深。若 $h^2 = 0.2$ 又会是多少？
::: solution
$S = 9.9 - 9.4 = 0.5$ mm。由[[#eq-breeder]]，$R = 0.79\times0.5 = 0.395$ mm，所以预测的子女均值为 $9.4 + 0.4 = 9.8$ mm，上升约 4 %。若 $h^2 = 0.2$，响应只有 0.1 mm。对低遗传率的性状施加强选择，进化很少；同样的选择作用于高遗传率的性状，进化很多。（实测值见 Grant 与 Grant，《40 年的进化》（*40 Years of Evolution*），2014。）
:::
:::

::: warning "遗传率度量一个性状有多'遗传'"
遗传率是特定环境中特定群体的一个性质，一个方差之比——它不是关于一个体的性状有多少"由基因造成"的陈述。指数的数目几乎完全由基因决定，其遗传率却几乎为零，因为存在的变异几乎全（来自意外）是环境造成的。而且，两个组内各自的高遗传率，对两组*之间*差异的原因什么也不说。在育种方程中，$h^2$ 被恰好用于它所度量的东西：子女与被选中亲本相似到什么程度。
:::

## 桦尺蠖

很少有例子像桦尺蠖 *Biston betularia* 这样，把本章的各要素结合得如此好。典型型翅色浅而布满斑点；黑化型 *carbonaria* 几乎全黑，由一个显性等位基因控制。*carbonaria* 于 1848 年首次在曼彻斯特附近被记录；到 1895 年，那里约 98 % 的蛾是黑色的。霍尔丹 1924 年算出，如此快速的上升要求黑色型拥有约 50 % 的适合度优势——在当时这是一个令人震惊的大数值，因为许多生物学家曾假定自然选择微弱到观察不到。1950 年代，Bernard Kettlewell 用标记-释放-回收证明：典型型在未污染的林地中存活更好，*carbonaria* 则在污染林地中更好，而且鸟更多地取食显眼的那种类型。他的一些方法受到批评，但 Michael Majerus 在剑桥附近进行的七年实验（由 Laurence Cook 及同事于 2012 年遗著发表）证实了鸟类差异捕食。清洁空气立法之后，*carbonaria* 在整个英国衰退。2016 年，Arjen van't Hof 及同事鉴定出该突变：一个转座子插入 *cortex* 基因的一个内含子，单倍型的年代被定在约 1819 年。

::: application 育种与抗性管理中的选择
育种方程诞生于农业：家畜与作物育种者选择性状值高的亲本，并用 $h^2$ 预测增益。伊利诺伊州长期玉米选择实验始于 1896 年，已将籽粒的油脂与蛋白质含量改变到相当于原始标准差许多倍的程度，响应仍未耗尽。同样的定量推理预测害虫进化出抗性的快慢：非 Bt 作物的庇护所延缓对 Bt 毒素抗性的扩散，因为抗性通常是隐性的——所以只要庇护所提供大量敏感个体，罕见的抗性等位基因就停留在杂合子中，而杂合子会被毒素杀死——[[#eq-dominance]] 中取 $h \approx 0$。
:::

## 自然选择能做什么、不能做什么

**适应**是一个性状——或产生它的过程——因其当前功能曾受自然选择青睐而提高适合度。并非每个有用的性状都是这种严格意义上的适应，而且选择在许多方面受约束。

- **它只作用于现有变异。** 选择无法预知未来的需要，也无法产生一个尚未出现的变体。没有合适突变的谱系无力响应，这是环境剧变时物种灭绝的原因之一。
- **它是短视的。** 每一步都必须在当前环境中受青睐。群体单靠选择无法穿越适合度低谷去登上更高的峰（赖特的移衡说提出小亚群体的漂变能助一臂之力；其重要性有争论）。
- **它受历史约束。** 结构是对既有之物的修改。哺乳类的喉返神经从脑向下延伸到胸腔、绕过大动脉再回到喉——在长颈鹿中绕行了数米——因为在鱼类祖先中它从咽弓后方经过，而弓上的动脉随颈部进化移入了胸腔。
- **它面对权衡与遗传相关。** 现在花在繁殖上的资源，日后不能用于存活；影响多个性状的等位基因（**基因多效性**）不能只就其中一个效应进行选择。
- **它可能被其他力量对抗。** 来自其他环境的基因流，以及小群体中的漂变，都对抗局部适应（[[evolution/mutation-drift-gene-flow]]）。
- **它落后于变化的环境。** 一个群体适应的是其祖先遭遇过的条件。

古尔德（Stephen Jay Gould）与 Lewontin 1979 年警告不要奉行"适应主义纲领"——假定每个性状都是最优适应、再为它编一个故事。有些性状是其他性状的副产品（他们称之为**拱肩**（spandrels），取拱与拱之间因拱而存在、并非为其自身而设计的三角形空间之意）；有些是**扩展适应**（exaptation），即被征用去承担其原本并非为其而生的功能的构造（羽毛在飞行之前就进化出来了）。科学的回应是检验适应假说：借助系统发育比较物种（[[evolution/phylogenetics]]），在野外测量选择，以及实验。

::: warning "进化有目标"与"选择为物种的利益而作用"
自然选择没有远见，除了当前环境赋予的方向之外没有方向：它提高的是现在留下更多后代的变异的频率。没有通向更大复杂性或通向人类的倾向；寄生虫常常变得更简单。而在个体之间作用的选择，一般不会产生以个体为代价帮助物种的性状：一个使其携带者"为群体的利益"克制自身繁殖的基因，会被一个不克制的基因排挤掉——除非利益优先流向共享该基因的亲属。汉密尔顿（W. D. Hamilton，1964）证明，当 $rB > C$ 时利他行为可以在那种情况下进化，其中 $r$ 是亲缘关系，$B$ 是对接受者的利益，$C$ 是对行为者的代价（**亲缘选择**）。以群体利益为词的解释需要这种明确类型的论证。
:::

::: history
达尔文与华莱士 1858 年提出自然选择，但它被接受的过程很慢：融合遗传——当时被认为是性状传递的方式——会使变异每一代减半，让选择无物可选。孟德尔的工作（1866，1900 年被重新发现）解决了这个问题，但雨果·德弗里斯与威廉·贝特森等早期孟德尔派强调大突变，怀疑对微小变异的选择。哈迪与魏因贝格（1908）为群体遗传学奠基。协调来自三位数学家理论家：费希尔（《自然选择的遗传学理论》（*The Genetical Theory of Natural Selection*），1930），他证明连续变异源于许多孟德尔基因（1918），且对微小差异的选择是有效的；霍尔丹（《进化的原因》（*The Causes of Evolution*），1932，以及 1924 年起的一系列论文），他计算了选择下的变化速率；以及赖特（1931、1932），他强调漂变、群体结构与适应景观。杜布赞斯基（Theodosius Dobzhansky）的《物种形成的遗传学》（*Genetics and the Origin of Species*，1937）、迈尔（Ernst Mayr）的《物种系统与起源》（*Systematics and the Origin of Species*，1942）、赫克斯利（Julian Huxley）的《进化：现代综合》（*Evolution: The Modern Synthesis*，1942）与 Simpson 的《进化中的速率与模式》（*Tempo and Mode in Evolution*，1944）把遗传学与自然历史、系统学与古生物学合到一起，形成**现代综合进化论**。
:::

::: summary
- 自然选择需要影响存活或繁殖的性状具有可遗传的变异；变异随机发生，选择是非随机的那一部分。
- 适合度是期望后代数；相对适合度 $w$ 与选择系数 $s$ 决定频率的改变。
- 哈迪-魏因贝格：随机交配且没有任何进化力量时，一代后基因型频率为 $p^2$、$2pq$、$q^2$，等位基因频率不变。
- 单倍体选择：$\Delta p = sp(1 - p)/(1 + sp)$，比值 $p/(1-p)$ 每代乘以 $1 + s$，一次选择清除约需 $(1/s)\ln[\ldots]$ 代。
- 二倍体选择：$\Delta p = (pq/2\bar w)\,d\bar w/dp$；显性决定速度——罕见的隐性等位基因（无论有利有害）对选择几乎不可见，隐性致死基因只按 $q_0/(1 + tq_0)$ 下降。
- 杂合子优势在 $\hat q = s/(s+t)$ 维持一个稳定多态；下显性给出一个不稳定的。
- 连续性状的选择响应为 $R = h^2S$。
- 选择是短视的，只能利用现有变异与历史，面对权衡，且不为物种的利益作用。
:::

## 练习

::: exercise 隐性等位基因的携带者 {level=1 check="0.0392"}
某隐性性状在假定处于哈迪-魏因贝格比例的群体中每 2500 个个体出现 1 例。群体中有多大比例是该等位基因的杂合子？
::: solution
$q^2 = 1/2500$，故 $q = 0.02$、$p = 0.98$。杂合子：$2pq = 2\times0.98\times0.02 = 0.0392$，约 1/26——比纯合子常见约 98 倍。
:::

::: exercise 一个选择系数 {level=1 check="0.25"}
基因型 $A_1A_1$ 的存活概率为 0.8，$A_2A_2$ 为 0.6，两者繁殖力相同。以 $A_1A_1$ 为基准，对 $A_2A_2$ 的选择系数是多少？
::: solution
$w = 0.6/0.8 = 0.75$，故 $s = 1 - w = 0.25$。
:::

::: exercise 单倍体选择的一代 {level=1 check="0.118"}
一个相对适合度为 1.2 的单倍体类型频率为 0.1。一代后它的频率是多少（保留三位小数）？
::: solution
由[[#eq-haploid]]，$p' = 0.1\times1.2/(1 + 0.2\times0.1) = 0.12/1.02 = 0.118$。

$t = \ln(999{,}999)/\ln 1.1 = 13.8155/0.09531 = 145$ 代（同[[#ex-resistance]]）。

::: exercise 杂合子优势 {level=2 check="0.6"}
基因型 $A_1A_1$、$A_1A_2$ 与 $A_2A_2$ 的相对适合度为 0.8、1 与 0.7。$A_1$ 的平衡频率是多少？（留意哪个系数是哪个。）
::: solution
在[[#prop-overdominance]]中，$s = 0.2$ 是针对 $A_1A_1$ 的系数，$t = 0.3$ 是针对 $A_2A_2$ 的。于是 $A_1$ 的 $\hat p = t/(s + t) = 0.3/0.5 = 0.6$，$A_2$ 的 $\hat q = 0.4$。校核：$\Delta p \propto -sp + tq = -0.2(0.6) + 0.3(0.4) = 0$。正如应有的那样，纯合子较适（$A_1A_1$ 为 0.8，对 0.7）的那个等位基因在平衡时更常见。
:::

::: exercise 实际遗传率 {level=2 check="0.3"}
育种者选择平均体重比群体均值 30 g 高 2.0 g 的小鼠作亲本。在相同环境中，其子女平均 30.6 g。实际遗传率是多少？若选择差为 1.0 g，响应会是多少？
::: solution
$R = 30.6 - 30 = 0.6$ g，$S = 2.0$ g，所以实际遗传率 $h^2 = R/S = 0.3$。取 $S = 1.0$ g，预测响应为 $0.3\times1.0 = 0.3$ g。
:::

::: exercise 下显性 {level=3}
设 $w_{11} = 1 + s$、$w_{12} = 1$、$w_{22} = 1 + t$，$s, t > 0$（杂合子最不适）。(a) 用[[#eq-diploid-dp]]求内部平衡并证明它不稳定。(b) 一个新的染色体重排在一个大群体中以单个拷贝出现。解释它为什么几乎总是丢失——即使它的纯合子更适——以及它在小群体中如何仍可能被固定。
::: solution
(a) $\Delta p = pq[p(w_{11} - w_{12}) + q(w_{12} - w_{22})]/\bar w = pq(sp - tq)/\bar w$。它在 $\hat p = t/(s + t)$ 处为零。$p > \hat p$ 时 $sp - tq > 0$，$p$ 进一步增大；$p < \hat p$ 时减小：偏离会增长，所以平衡不稳定——群体若从 $\hat p$ 上方出发就固定 $A_1$，从下方出发就固定 $A_2$。
(b) 新重排从接近 $p = 0$ 处起步，远低于 $\hat p$，而且它几乎全部的拷贝都在较不适的杂合子中，所以选择会把它清除。在小群体中，随机的漂变（[[evolution/mutation-drift-gene-flow]]）可能凭机会把它带过 $\hat p$，此后选择便将它固定。这是物种间染色体差异得以产生的一种方式，也是这类差异能够促成生殖隔离的原因（[[evolution/speciation]]）。
:::

::: exercise 解读黑化数据 {level=3}
在一个桦尺蠖群体中，黑色表型（由显性等位基因 $C$ 引起）的频率在约 50 代内从 0.01 升到 0.98。(a) 在哈迪-魏因贝格比例下，起始与结束时 $C$ 等位基因的频率各是多少？(b) 用单倍体公式[[#eq-haploid-time]]作粗略参考，估计一个等位基因在这两个频率之间、50 代内上升所需的选择系数。(c) 为什么完整的二倍体处理（完全显性）会给出略有不同的答案？往哪个方向？
::: solution
(a) 非黑色（典型）表型是 $cc$，频率为 $q^2$。起始 $q^2 = 0.99$，$q = 0.99499$，故 $p_C = 0.00501$。结束 $q^2 = 0.02$，$q = 0.1414$，$p_C = 0.8586$。
(b) 对数几率的改变量为 $\ln[(0.8586/0.1414)/(0.00501/0.99499)] = \ln(6.072/0.005036) = \ln 1206 = 7.10$。除以 50 代，$\ln(1 + s) = 0.142$，故每个等位基因拷贝的 $s \approx 0.15$。
(c) 完全显性时杂合子享有全部优势，所以罕见的 $C$ 等位基因比相同纯合子优势下的可加模型上升更快，但在接近顶部时进展变慢，那时选择只看得到 $cc$ 纯合子。由于这里的终点频率并非极端，显性模型要求黑色型的表型优势约为按等位基因为值的近两倍，即 30 % 左右——与霍尔丹 1924 年"优势必定很大"的结论一致。（取 $h = 1$ 迭代[[#eq-dominance]]可证实这一量级。）
:::
