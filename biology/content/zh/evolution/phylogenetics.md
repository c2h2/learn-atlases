《物种起源》中唯一的插图是一幅分枝图。达尔文画它是为了说明：源自共同祖先的物种如何分歧、分枝并灭绝，从而使现生物成为一棵树的末端——其内部枝干就是它们已灭绝的祖先。**系统发育**（phylogeny）是关于某一特定类群这棵树的假说：哪些物种相互之间拥有更近的共同祖先。系统发育研究如今是几乎整个比较生物学的框架。它告诉我们一个性状进化了一次还是多次、性状以什么顺序出现、谱系多样化有多快、病毒何时在宿主之间跳跃，以及一个新测序的微生物在现生生物中归属于何处。

本章分为两部分。第一部分是*读树*——进化枝与性状的词汇，以及解读系统树时的常见错误。第二部分是*从数据建树*：简约法与 Fitch 算法、距离及其对多次替换的校正、UPGMA 与邻接法、似然法与贝叶斯方法的概要，以及如何评估置信度。我们将推导可能的树的数目，它说明建树为何在计算上困难；最后以分子定年以及基因树之所以有别于物种树的原因收尾。这些算法在 [[bioinformatics]] 中进一步发展。

## 阅读系统发育树

::: definition 系统发育树及其组成部分 {#def-tree}
一棵**系统发育树**（phylogenetic tree）是表示一组**分类单元**（物种、群体、基因或其他单元）进化关系的分枝图。分类单元是**叶**（末端、末端节点）；分枝点是**内部节点**，代表共同祖先；连线是**分支**（边）。**有根**树指定一个节点为**根**，代表全部分类单元的共同祖先，这使每条分支都有了时间方向；**无根**树只表示亲缘关系格局。在**二叉**（二分枝）树中，每个内部节点都有两个后裔；后裔更多的节点是**多分叉**，通常表示不确定性。分支长度可按变化量成比例绘制，也可按时间成比例绘制；若一棵树所有叶到根的时间距离都相等，则称其为**超度量**的。
:::

::: definition 单系与进化枝 {#def-clade}
**进化枝**（clade，单系群）是由一个祖先及其*全部*后裔组成的类群。**并系**群包含一个祖先及其部分而非全部后裔。**多系**群包含来自若干谱系的分类单元，却不包含它们最近的共同祖先。互为彼此最近亲的两个进化枝是**姊妹群**。
:::

传统的"爬行动物"——龟、蜥蜴、蛇、鳄——是并系的，因为鳄与鸟的共同祖先比与蜥蜴的更近：一个包含鳄与蜥蜴的进化枝必须也包含鸟。类似地，排除四足类的"鱼"是并系的，而"恒温动物"（鸟类加哺乳类）是多系的，因为内温性在两个谱系中各自独立进化。现代分类学遵循德国昆虫学家威利·亨尼希（Hennig）的主张（德文原著 *Grundzüge einer Theorie der phylogenetischen Systematik*，1950；英译本 *Phylogenetic Systematics*，1966），只命名进化枝。这就是为什么生物学家说鸟是恐龙、人说自己是鱼——就我们属于硬骨鱼（Osteichthyes）这个进化枝而言。

::: warning 把系统树读成阶梯
常见的错误有三个。(1) *沿叶横读*。叶沿纸面的排列顺序不携带任何信息：把任一节点处的两条分支旋转，得到的还是同一棵树。人在最右端的树并不意味着人最高等；末端的那个叶并不比其他叶更"衍生"。(2) *把节点数当进步*。现生物种同样古老——每一个都有一条从未间断的谱系通到根——而且没有任何现生物种是另一物种的祖先。"基部"谱系（如哺乳类中的鸭嘴兽）是早期分出去的谱系，不是原始物种：它同样进化了这么久。(3) *沿叶间距离判断亲缘*。亲缘关系由最近共同祖先决定：在一棵 ((frog, (lizard, (bird, crocodile))), mammal) … 的树上，鸟与鳄的亲缘关系比鳄与蜥蜴的更近，无论叶怎么画。
:::

### 性状、同源与同塑性

系统树由**性状**推断：解剖构造、DNA 位点、基因顺序。每个性状有若干**状态**（羽毛有或无；第 341 位是碱基 A、C、G 还是 T）。分支上的一次状态改变就是一个进化事件。

::: definition 衍征、祖征与共有衍征 {#def-apomorphy}
对给定的进化枝而言，**衍征**（apomorphy）是衍生性状状态，在该进化枝的祖先中出现；**祖征**（plesiomorphy）是祖先状态，从更早处继承而来。**共有衍征**（synapomorphy）是两个或多个分类单元因其从共同祖先继承而共享的衍生状态；**共有祖征**（symplesiomorphy）是共享的祖先状态；**自衍征**（autapomorphy）是某个分类单元独有的衍生状态。亨尼希的核心原则是：只有共有衍征才是把分类单元归入进化枝的证据。**同塑性**——并非源自共同祖先的相似（[[evolution/evidence-for-evolution#def-homology]]）——由**趋同**（独立获得）或**回复**（回到祖先状态）产生，会误导判断。
:::

毛发是哺乳类的共有衍征，把哺乳类联合成一个类群；但四肢为哺乳类与蜥蜴共享，在四足类之内只是共有祖征，对蜥蜴与哺乳类近还是与鸟近一无所知。要判断哪个状态是祖先的，我们使用**外群**（outgroup），即已知位于所研究类群（**内群**，ingroup）之外的分类单元：外群中的状态被视为祖先状态。外群也为系统树**定根**：根被放在通往外群的分支上。

## 可能的树有多少棵？

建树之前，先看看可供挑选的树有多少是有益的。

::: proposition 树的数目 {#prop-ntrees}
具有 $n \ge 3$ 个标记叶的不同无根二叉树的数目为

$$
U(n) = 1\times3\times5\times\cdots\times(2n - 5) = (2n - 5)!!,
$$ {#eq-unrooted}

而具有 $n \ge 2$ 个标记叶的有根二叉树的数目为

$$
R(n) = (2n - 3)!! = U(n + 1)。
$$ {#eq-rooted}
:::

::: proof
一棵有 $k$ 个叶的无根二叉树有 $k - 2$ 个内部节点（每个的度为 3）和 $2k - 3$ 条边：用归纳法，从唯一的 3 叶树（一个内部节点、3 条边）出发，每加入一个新叶，就把一条已有的边一分为二并添一条通到新叶的新边，这增加一个内部节点和两条边。

每一棵有 $k + 1$ 个叶的树都恰好以一种方式由有 $k$ 个叶的树得到：把叶 $k + 1$ 接到它的 $2k - 3$ 条边之一上；删去叶 $k + 1$（并把在其附着节点相交的两条边合并）就恢复出较小的树和那条边。于是 $U(k + 1) = (2k - 3)\,U(k)$，且 $U(3) = 1$：

$$
U(n) = 1\times3\times5\times\cdots\times(2(n - 1) - 3) = (2n - 5)!!.
$$

对于有根树：把一棵有 $n$ 个叶的无根树根植于它的 $2n - 3$ 条边之一，恰好给出每棵有根树一次，所以 $R(n) = (2n - 3)\,U(n) = (2n - 3)!!$。等价地，根就像一个额外的叶，故 $R(n) = U(n + 1)$。
:::

::: example 树空间的爆炸 {#ex-ntrees}
4、5、6、10、20 和 50 个分类单元各有多少棵无根树？
::: solution
由[[#eq-unrooted]]：$U(4) = 3$；$U(5) = 3\times5 = 15$；$U(6) = 15\times7 = 105$；$U(10) = 1\times3\times5\times\cdots\times15 = 2{,}027{,}025$；$U(20) = 35!! = 2.22\times10^{20}$；$U(50) = 95!! = 2.84\times10^{74}$（都在 Python 中精确计算乘积校核过）。50 个分类单元时，树的数目比地球上的原子数（约 $10^{50}$）还多。超过约十几个分类单元，检查每一棵树就不可能，所以系统发育程序使用启发式搜索：先构造一棵不错的起始树，然后在其得分改善的范围內重排（交换子树）。在简约或似然标准下寻找最优树是 NP 难的。
:::
:::

::: widget plot
f: log10(gamma(2*x - 3)/(2^(x - 2)*gamma(x - 1)))
x: 3, 60
y: 0, 100
labels: \log_{10} U(n)
caption: $n$ 个分类单元的无根二叉树数目 $(2n-5)!! = (2n-4)!/(2^{n-2}(n-2)!)$，以常用对数绘制，并通过 gamma 函数计算，使 $n$ 可连续变化。曲线上弯：对数的增长快于线性，大致按 $n\log_{10} n$ 增长。在 $n = 10$（约 6.3，即二百万棵树）、$n = 20$（20.3）与 $n = 50$（74.5）处悬停读数。
:::

## 简约法

**最大简约法**（maximum parsimony）的原则是：偏好解释数据所需性状状态改变次数最少的树。它由亨尼希的追随者为形态数据、并由 Joseph Camin 与 Robert Sokal（1965）及 James Farris（1970）为一般离散性状发展而来。它的逻辑是：若改变罕见，则使改变最少的树最可能正确。

一个性状在一棵给定树上所需的改变次数由 Fitch 算法（Walter Fitch，1971）求出。

::: algorithm 单个性状在有根二叉树上的 Fitch 简约法 {#alg-fitch}
1。给每个叶赋以只含其观察状态的集合。
2。从叶向根（后序）访问内部节点。对子代集合为 $S_1$ 与 $S_2$ 的节点：若 $S_1\cap S_2 \ne \varnothing$，赋 $S_1\cap S_2$；否则赋 $S_1\cup S_2$，并使改变计数加 1。
3。到达根时的计数，就是该性状在这棵树上所需的最少改变次数.（第二遍自顶向下的遍历为每个节点从其集合中选定一个状态，得到一个最简约的重建.）
4。**树长**是所有性状的计数之和；最简约的树是树长最小的那棵。对于无根树，把它根植于任意分支即可：计数与根植的位置无关。
:::

::: example 四个分类单元的简约法 {#ex-fitch}
四个分类单元的五个比对位点为：

| 位点 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| A | G | T | C | A | G |
| B | G | T | T | A | A |
| C | A | C | C | A | A |
| D | A | C | T | G | G |

求三棵无根树 T1 = AB|CD、T2 = AC|BD 与 T3 = AD|BC 各自的树长，以及最简约的树。
::: solution
对于四个分类单元，一个双状态位点是**简约信息位点**，仅当每个状态至少在两个分类单元中出现；此时它在分开其两对的那个树上需一次改变，在其余树上需两次。位点 1 与 2 把 AB 与 CD 分开；位点 3 把 AC 与 BD 分开；位点 5 把 AD 与 BC 分开。位点 4（只有 D 不同）在每棵树上都需一次改变，因此无助于抉择。

把位点 3 放到在两对之间定根的 T1 上校核：A{C} 与 B{T} 交集为空，所以它们的祖先得 {C, T}，计一次改变；C{C} 与 D{T} 同理，一次改变；在根处 {C, T} ∩ {C, T} = {C, T}，无改变。合计 2，正如预期。

树长：T1 $= 1 + 1 + 2 + 1 + 2 = 7$；T2 $= 2 + 2 + 1 + 1 + 2 = 8$；T3 $= 2 + 2 + 2 + 1 + 1 = 8$。最简约的树是 T1，((A,B),(C,D))，由两个位点支持，其余两棵树各得一位点的支持。可以设想的最小树长——每位点除第一种状态外每种状态各一次改变——为 5，所以 T1 的**一致性指数**为 $CI = 5/7 = 0.71$：它的七次改变中有两次是同塑的。
:::
:::

简约法简单，且不显式假定进化模型，但这正是它的弱点所在。当改变频繁时，两条长枝上的平行改变可能多过真正的共有衍征，于是简约法把长枝归并在一起——无论增加多少数据。Joseph Felsenstein（1978）证明了这种**长枝吸引**（long-branch attraction）：在某些枝长组合下，简约法是*统计不相容的*——它会收敛到错误的树。基于显式替换模型的方法表现更好。

## 距离法

距离法先把数据化为分类单元间成对距离的矩阵，再构造最契合该矩阵的树。两条比对序列间最简单的距离是 **p 距离**，即状态不同的位点比例。但它低估替换的数目，因为一个改变了两次的位点、或改变后又改回来的位点，可能只显示一个差异、或毫无差异。随着分歧加深，$p$ 趋于饱和。

::: proposition Jukes–Cantor 校正 {#prop-jc}
设每个位点以恒定速率改变，且当前碱基被其余三种碱基替换的概率相等（**Jukes–Cantor 模型**，Thomas Jukes 与 Charles Cantor，1969）。若 $d$ 是分开两条序列的期望每位点替换数，则差异位点的期望比例为

$$
p = \frac34\left(1 - e^{-4d/3}\right),
$$

所以由观察值 $p$ 估计的距离为

$$
d = -\frac34\ln\!\left(1 - \frac43p\right).
$$ {#eq-jc}
:::

::: proof
沿连接两条序列的路径跟踪一个位点，路径总长以期望替换数计为 $d$，令 $P(x)$ 为路径上距起点 $x$ 处的位点与起点碱基相同的概率。替换以每单位 $x$ 速率 1 发生。若当前碱基就是原来的那个（概率 $P$），任何替换都会改变它；若是其余三种之一（概率 $1 - P$），替换有 $\tfrac13$ 的概率换回原来的。于是

$$
\frac{dP}{dx} = -P + \frac13(1 - P) = \frac13 - \frac43P,
$$

初值 $P(0) = 1$。解为 $P(x) = \tfrac14 + \tfrac34e^{-4x/3}$。差异位点比例为 $p = 1 - P(d) = \tfrac34(1 - e^{-4d/3})$；由此解出 $d$。
:::

$p$ 小时 $d \approx p$；当 $p$ 趋于 $\tfrac34$——两条随机序列之间差异的期望比例——$d$ 趋于无穷，关于替换数目的信息荡然无存。$p = 0.1$ 时 $d = 0.107$；$p = 0.3$ 时 $d = 0.383$；$p = 0.5$ 时 $d = 0.824$；$p = 0.7$ 时 $d = 2.03$。更现实的模型允许转换与颠换速率不同（木村资生的两参数模型，1980）、碱基频率不等，以及位点间速率变异。

f: -0.75*ln(1 - 4*x/3); x
x: 0, 0.74
y: 0, 2.5
labels: d\ \text{(Jukes–Cantor)}; p
vlines: 0.75
caption: 由[[#eq-jc]]得到的 Jukes–Cantor 距离 $d$ 随观察到的差异位点比例 $p$ 的变化，并给出直线 $d = p$ 供比较。对亲缘关系很近的序列两者一致；$p = 0.3$ 时校正距离已经大 28 %；$p$ 逼近饱和值 0.75（虚线）时校正发散。注意观察值 $p$ 在区间最后一段变化何等微小：分歧极深的序列几乎不携带关于其距离的信息。

### UPGMA

由距离建树的最简单算法是 **UPGMA**（unweighted pair-group method with arithmetic mean，算术平均非加权类群法；Robert Sokal 与 Charles Michener，1958）。

::: algorithm UPGMA {#alg-upgma}
1。把每个分类单元看作一个大小为 1 的类群。
2。找距离 $d_{ij}$ 最小的两个类群 $i$ 与 $j$。把它们并到一个位于高度 $d_{ij}/2$ 的新节点之下（距离的一半，因为两条谱系各贡献一半）。
3。用新类群 $k$ 取代 $i$ 与 $j$，$k$ 到任一其他类群 $l$ 的距离取按大小加权的平均 $d_{kl} = (n_id_{il} + n_jd_{jl})/(n_i + n_j)$。
4。重复步骤 2–3，直到只剩一个类群。
:::

UPGMA 产生一棵超度量的有根树：它假定严格的分子钟，即所有谱系以同一速率进化。速率不等时它可能给出错误的树。

::: example 类人猿的 UPGMA 树 {#ex-upgma}
人（H）、黑猩猩（C）、大猩猩（G）与猩猩（O）之间全基因组的大致分歧度（比对位点百分比，取整，与基因组比较报道的量级相当）为：H–C 1.2；H–G 1.6；C–G 1.7；H–O 3.1；C–O 3.2；G–O 3.1。构造 UPGMA 树。
::: solution
步骤 1：最小的距离是 H–C，1.2。在高度 0.6 合并 H 与 C。（HC）到其余类群的距离：到 G，$(1.6 + 1.7)/2 = 1.65$；到 O，$(3.1 + 3.2)/2 = 3.15$。

步骤 2：余下最小的距离是（HC）–G，1.65。在高度 0.825 合并。（HCG）到 O 的距离：按大小加权，$(2\times3.15 + 1\times3.1)/3 = 3.133$。

步骤 3：在高度 1.567 合并（HCG）与 O。

这棵树是 (((H, C), G), O)：人与黑猩猩是姊妹种，大猩猩是它们的姊妹群，猩猩在其外——这一关系如今几乎得到全部基因组数据的支持。有了校准（比如猩猩的分歧约在 15 Myr），高度可化为时间，但这些数值忽略了祖先多态性与速率变异（[[#sec-dating]] 与 [[evolution/human-evolution]]）。
:::
:::

**邻接法**（neighbour joining；Naruya Saitou 与 Masatoshi Nei，1987）放宽了钟的假定。它不合并最近的成对，而是合并使

$$
Q_{ij} = (n - 2)\,d_{ij} - \sum_k d_{ik} - \sum_k d_{jk},
$$

最小的成对 $i, j$，这一判据校正了那些因自身分支很长而远离所有其他分类单元的分类单元。邻接法很快——几千条序列几秒内就能建成一棵树——且只要距离恰为可加的（等于沿树分支长度之和），它就给出正确的树。它被广泛用于构造起始树和处理大数据集。

## 似然法、贝叶斯推断与置信度

**最大似然法**（Felsenstein，1981）选择使观察数据概率最大的树与分支长度，前提是给定一个显式的替换模型，如 Jukes–Cantor 及其推广。一棵树的似然逐位点计算，用 Felsenstein 的**剪枝算法**对所有可能的祖先状态求和——这是一种自叶到根工作、类似 Fitch 算法的动态规划方法。似然法在其模型下是统计相容的，能应对速率不等，并使长枝吸引大为减轻。**贝叶斯**方法（例如实现在 MrBayes 中，John Huelsenbeck 与 Fredrik Ronquist，2001）把似然与先验分布结合，由马尔可夫链蒙特卡洛抽样，给出每棵树和每个进化枝的后验概率。

我们该对一个进化枝有多大信心？Felsenstein（1985）引入了**自助法**（bootstrap）：对读列的列进行有放回重抽样，生成许多同样大小的伪重复数据集，各建一棵树，记录包含该进化枝的重复百分比。**自助法支持度** 95 % 意味着几乎任何对位点的重抽样都能恢复该进化枝；50 % 意味着它取决于恰好抽到了哪些位点。自助法数值不是进化枝为真的概率；而且面对大规模基因组数据，即使有系统误差（错误的模型）在左右结果，几乎一切也能获得 100 % 支持度，所以不同数据与方法之间的一致比任何单个支持度数值更重要。

::: quiz
用 1000 个位点建成的一棵树给出进化枝 (X, Y)，自助法支持度 100 %。哪个结论站得住？
- [ ] 进化枝 (X, Y) 必然正确。
- [x] 在这些数据与此方法之下，该进化枝得到有力支持；若方法存在系统偏差（如长枝吸引），它仍可能是错的。
- [ ] 100 % 的位点支持 (X, Y)。
- [ ] X 是 Y 的祖先。
::: solution
自助法度量的是重抽样时数据给出该进化枝的一致性——是抽样变异性的度量，不是系统误差的度量。若 X 与 Y 都处在长枝上而模型不当，每个重复都可能以 100 % 支持度给出同一个错误答案。它也不意味着所有位点意见一致（清楚的多数就够了），姊妹分类单元也不是祖先后裔关系。
:::
:::

## 系统树的定年 {#sec-dating}

一棵以每位点替换数为分支长度的树，可以用**分子钟**（[[evolution/mutation-drift-gene-flow#prop-neutralrate]]）化为时间树。分子钟必须校准，通常用化石：若一个进化枝最老的化石可靠地定了年，该进化枝至少那么老，节点由此得到一个最小年龄。**宽松分子钟**（relaxed clock）方法（贝叶斯程序如 BEAST，Alexei Drummond 及同事，2006）允许速率在分支之间变异，并使用若干带不确定度的校准，如今已是标准做法。

::: example 一个化石校准的分子钟 {#ex-calibration}
严格钟下，物种 X 与 Y 相差校正距离每位点 0.080 次替换，化石记录把它们的分裂定在 20 Myr。物种 X 与 Z 相差 0.020。X 与 Z 何时分裂？每个谱系的替代速率是多少？
::: solution
严格钟下距离与时间成正比：$t_{XZ} = 20\times0.020/0.080 = 5$ Myr。每条谱系累积一半距离，所以每个谱系的速率是每位点每 Myr $0.080/(2\times20) = 0.002$ 次替换，即每位点每年 $2\times10^{-9}$。校准的误差会原样传导：若 X–Y 分裂实为 25 Myr，X–Z 就成 6.25 Myr。化石校准是最小年龄（第一个化石晚于分裂），所以其不确定度是单边的，贝叶斯定年方法对此明确建模。
:::
:::

### 基因树与物种树

单个基因的树未必是物种的树。当物种接连快速分裂时，祖先多态性可能在两次分裂的短暂间隔中存续，从三个物种抽到的基因拷贝可能以不同于物种分裂顺序的顺序溯祖。这就是**不完全谱系分选**（incomplete lineage sorting）。

对物种树为 ((A, B), C) 的三个物种，设两次物种形成事件之间的间隔为 $T$，以**溯祖单位**计（对有效大小为 $N_e$ 的祖先群体中的 $t$ 代，$T = t/2N_e$），溯祖理论（coalescent theory）给出基因树与物种树一致的概率为

$$
\Prob(\text{基因树} = \text{物种树}) = 1 - \tfrac23e^{-T},
$$ {#eq-ils}

两种不一致拓扑各有概率 $\tfrac13e^{-T}$（这一结果由 Richard Hudson、Fumio Tajima 以及 Pekka Pamilo 与 Masatoshi Nei 在 1980 年代导出）。$T$ 大时几乎全部基因一致；$T$ 小时多达三分之二不一致。

::: example 类人猿中的不一致 {#ex-ils}
Aylwyn Scally 及同事（2012）分析大猩猩基因组时发现，在约 30 % 的基因组中，人与黑猩猩并非最近亲（人与大猩猩聚组，或黑猩猩与大猩猩聚组）。这意味着多长的种间枝长 $T$？若祖先 $N_e$ 约 50,000、世代时间 20 年，这折合多少年？
::: solution
令 $\tfrac23e^{-T} = 0.30$ 得 $e^{-T} = 0.45$，$T = \ln(1/0.45) = 0.80$ 溯祖单位。于是 $t = 0.80\times2N_e = 0.80\times100{,}000 = 80{,}000$ 代，按 20 年的世代时间约合 160 万年。这正是基因组估计的人–大猩猩分裂与人–黑猩猩分裂之间间隔的量级。不完全谱系分选不是系统发育学的失败，而是一个信息之源：不一致基因的比例度量了物种形成之间的时间与祖先群体大小。由许多基因树估计物种树的方法（如 ASTRAL，Siavash Mirarab 及同事，2014）已把它考虑在内。
:::
:::

基因树不一致的其他成因包括**杂交与基因渐渗**（introgression，基因越过物种边界，如尼安德特人与现代智人之间——[[evolution/human-evolution]]）、**水平基因转移**（在细菌与古菌中常见，使原核生物的单棵"树"只是一种近似），以及**基因重复与丢失**（把一个基因与其旁系同源物（paralogue）的拷贝、而非其真正的直系同源物（orthologue）相比较）。

::: application 流行病学与法医学中的系统发育学
病毒基因组的系统发育树可以追溯疫情。沿疫情采集的序列连同其采样日期，可给出一棵按时间定标的树：其根定出起源，分枝速率估计增长，其地理格局显示扩散——这些方法已用于 HIV、埃博拉、流感与 SARS-CoV-2。HIV-1 M 组的起源被追溯为中非一次从黑猩猩溢出的跨种传播，大流行毒株的共同祖先被定年在二十世纪初（Michael Worobey 及同事，2008）。HIV 序列的系统发育分析也已被接受为刑事案件的证据，但须注意：一棵树能显示两种病毒亲缘很近，却不能显示传播的方向或途径。
:::

::: history
达尔文 1837 年在笔记中画过一棵树（"我认为"），《物种起源》（1859）中也有；恩斯特·海克尔（Haeckel）自 1866 年起绘制了详尽的生命之树。亨尼希的系统发育系统学（1950，1966 年译成英文）确立了共有衍征作为分类的基础，开启了 1970–1980 年代的"支序分类学"革命。Sokal 与 Michener 的 UPGMA（1958）来自数值分类学；Edwards 与 Cavalli-Sforza（1963–1964）为基因频率数据提出了简约法与似然法；Fitch 算法发表于 1971 年。卡尔·伍斯（Woese）与 George Fox 于 1977 年用核糖体 RNA 序列发现古菌，把生命之树改写为三域。Felsenstein 证明了简约法的不相容（1978）、使似然法变得可行（1981）并引入自助法（1985）；Saitou 与 Nei 的邻接法发表于 1987 年；贝叶斯系统发育学出现在约 1996–2001 年。2000 年代以来的基因组尺度数据（"系统发育组学"）解决了许多老问题，也揭示了基因树不一致的普遍程度。
:::

::: summary
- 系统发育是关于共同祖先的假说；进化枝（单系群）包含一个祖先及其全部后裔，并系群与多系群则不然。叶的顺序是任意的，没有现生物种是另一物种的祖先，"基部"不等于原始。
- 只有共享的衍生状态（共有衍征）指示进化枝；外群用于判定性状极性并为树定根；同塑性（趋同、回复）会误导。
- $n$ 个分类单元有 $(2n-5)!!$ 棵无根与 $(2n-3)!!$ 棵有根二叉树——10 个分类单元 $2\times10^6$ 棵，50 个 $3\times10^{74}$ 棵——所以树搜索是启发式的。
- 最大简约法最小化改变次数，计数用 Fitch 算法；它可能不相容（长枝吸引）。
- 距离必须校正多重替换：Jukes–Cantor $d = -\tfrac34\ln(1 - \tfrac43p)$。UPGMA 假定分子钟；邻接法不假定。
- 似然法与贝叶斯方法使用显式的替换模型；自助法支持度度量抽样变异性，不是系统误差。
- 分子定年需要校准与宽松分子钟；基因树可以不同于物种树，原因有不完全谱系分选（$\Prob(\text{一致}) = 1 - \tfrac23e^{-T}$）、基因渐渗、水平转移与旁系同源。
:::

## 练习

::: exercise 六个分类单元 {level=1 check="105"}
6 个分类单元有多少棵无根二叉树？
::: solution
$U(6) = 7!! = 1\times3\times5\times7 = 105$。
:::
:::

::: exercise 有根树 {level=1 check="105"}
5 个分类单元有多少棵有根二叉树？
::: solution
$R(5) = 7!! = 105$，与 $U(6)$ 相同，正如[[#eq-rooted]]所说：根充当第六个叶。
:::
:::

::: exercise 一个校正距离 {level=1 check="0.383"}
两条比对序列在 30 % 的位点上不同。它们的 Jukes–Cantor 距离是多少（三位小数）？
::: solution
$d = -0.75\ln(1 - 0.4) = -0.75\ln 0.6 = -0.75\times(-0.5108) = 0.383$ 次替换每位点。
:::
:::

::: exercise 一致性指数 {level=2 check="0.714"}
[[#ex-fitch]] 中最简约树的一致性指数是多少（三位小数）？
::: solution
最少可能的改变数：每个双状态位点一次，共 5。树长 7。$CI = 5/7 = 0.714$。
:::
:::

::: exercise 不一致的基因 {level=2 check="0.245"}
对物种树 ((A, B), C)、种间枝为 $T = 1$ 溯祖单位的情形，预期有多大比例的基因树与物种树不一致（三位小数）？
::: solution
由[[#eq-ils]]，不一致比例为 $\tfrac23e^{-1} = 0.6667\times0.3679 = 0.245$。
:::
:::

::: exercise 为一次分裂定年 {level=2 check="12"}
严格钟下，据化石于 30 Myr 前分裂的分类单元 P 与 Q 距离为 0.15；P 与 R 相差 0.06。P 与 R 何时分裂（单位 Myr）？
::: solution
$30\times0.06/0.15 = 12$ Myr。
:::
:::

::: exercise 五个分类单元的 Fitch 计数 {level=2 check="2"}
在有根树 (((A, B), C), (D, E)) 上，某位点的状态为 A: T、B: C、C: C、D: T、E: T。Fitch 算法计数几次改变？
::: solution
(A, B)：{T} ∩ {C} = ∅ → {T, C}，1 次改变。((A, B), C)：{T, C} ∩ {C} = {C}，无改变。(D, E)：{T}。根：{C} ∩ {T} = ∅ → {C, T}，1 次改变。合计 2.（一种重建：根与 D–E 谱系为 T，通往 ABC 进化枝的分支上一次 T→C 改变，通往 A 的分支上一次回复 C→T.）
:::
:::

::: exercise 分类中的类群 {level=2}
判断下列每个类群是单系的、并系的还是多系的，并说明理由：(a) 哺乳纲 Mammalia；(b) 传统意义的"爬行动物"（不包括鸟）；(c) "藻类"（陆生植物以外的光合真核生物）；(d) 不包括人的"类人猿"；(e) 包括鸟的恐龙总目 Dinosauria。
::: solution
(a) 单系的：现生哺乳类共同祖先的全部后裔。(b) 并系的：其共同祖先的后裔包括鸟，而鸟被排除在外。(c) 多系的：真核生物的光合作用在若干独立谱系中起源（绿藻与红藻经由初级内共生，褐藻、硅藻及其他经由不相关谱系中的次级内共生），所以这个类群略去了共同祖先的其他非光合后裔，也不共享一个光合祖先。(d) 并系的：人出自黑猩猩、大猩猩与猩猩共同祖先的血统；那个进化枝就是人科 Hominidae。(e) 单系的：鸟是兽脚类恐龙的后裔，包括它们之后 Dinosauria 成为一个进化枝。
:::
:::

::: exercise 长枝吸引 {level=3}
四个分类单元的真实树为 ((A, B), (C, D))。通往 A 与 C 的分支很长（替换很多），其余的很短。(a) 解释简约法为何可能偏好 ((A, C), (B, D))。(b) 为什么增加位点对简约法没有帮助？(c) 提出三种减轻这一问题的办法。
::: solution
(a) 长枝上发生许多替换，A 与 C 会偶然地独立获得相同状态（趋同）。这类平行改变制造出看似 (A, C) 共有衍征的位点。(A, B) 或 (C, D) 真正的共有衍征只在短内部枝上产生，数目很少。若趋同位点多过它们，简约法便偏好错误的树。
(b) 更多位点按同一比例增加两类位点，错误树的优势随数据一同增长：简约法在此统计不相容（Felsenstein，1978）。
(c) 使用基于模型的方法（似然法或贝叶斯法），配合允许多重替换与速率变异的替换模型；加入能打散长枝的分类单元（A 与 C 的近亲）；删除快速进化的位点或基因，或使用进化缓慢的性状（氨基酸、罕见的基因组改变）。
:::
:::

::: exercise 在计数基础上建树 {level=3}
(a) 利用[[#prop-ntrees]]证明中的递推，证明无根树数目对任何常数 $c$ 都比 $c^n$ 增长得快。(b) 若一台计算机每秒能评估 $10^9$ 棵树，评估 20 个分类单元的全部无根树要多久？(c) 解释子树剪除重接等启发式搜索为何仍能找到非常好的树。
::: solution
(a) $U(n + 1)/U(n) = 2n - 3$，无上界；对任何 $c$，一旦 $2n - 3 > c$，比值就超过 $c$，所以最终 $U(n)$ 超过 $c^n$（除去较小的因子，它大致按 $(2n/e)^{n}$ 增长）。
(b) $U(20) = 2.22\times10^{20}$ 棵树，按每秒 $10^9$ 棵需 $2.2\times10^{11}$ 秒，约 7,000 年。
(c) 树空间上的得分曲面不是随机的：相似的树（只差一次小重排）得分相似，所以从一棵好的起始树（例如由邻接法得到的）出发的局部搜索能高效地攀上高峰。多个起始树与更大的重排能降低困在局部最优上的风险。不保证找到全局最优树，但实践中不同的搜索通常收敛到同样少数几棵树上。
:::
