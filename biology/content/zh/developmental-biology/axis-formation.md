胚胎在能够造出一个头之前，必须先知道哪一端是前端。所有两侧对称的动物都有三条体轴：**前-后**（从头到尾）、**背-腹**（从背到腹）与**左-右**。它们建立得很早，往往在卵裂之前或卵裂期间，此后的一切模式都建立在它们之上。本章的问题是：一个近乎球形的卵如何获得这些轴，沿轴的细胞又是如何知道自己所在位置的。

两种截然不同的动物给出了最清楚的答案。在果蝇 *Drosophila melanogaster*（黑腹果蝇）中，轴是在母体的卵室里建立的，由母体安放在特定位置的分子设定，并在合胞体胚胎中被转录因子的浓度梯度读取。在脊椎动物中，卵的预置模式较少，轴由受精时的事件（蛙）、重力（鸡）或早期胚胎细胞之间的相互作用（小鼠）设定。两者都依赖于**位置信息**的观念：细胞获得一个取决于其位置的值，并按自己的遗传程序解读它。特化与核质比的概念见 [[developmental-biology/principles-of-development]] 与 [[developmental-biology/early-embryos]]。

## 母体效应基因

1980年，克里斯蒂安娜·纽斯林-福尔哈特（Christiane Nüsslein-Volhard）与埃里克·维绍斯（Eric Wieschaus）开始对 *Drosophila* 进行筛选，寻找扰动幼虫角质层图案的突变。某些基因的突变会产生异常胚胎——只要*母亲*是纯合突变体，无论胚胎自身的基因型如何都是如此。这些就是母体效应基因。

::: definition 母体效应基因 {#def-maternal-effect}
**母体效应基因**是这样一类基因：其产物在卵子发生期间于母体内合成并沉积到卵中，为胚胎发育所必需。胚胎的表型由其母亲的基因型决定：纯合突变雌性即使与野生型雄性交配，产生的胚胎也有缺陷；杂合雌性即使胚胎自身是纯合突变体，产生的胚胎也正常。
:::

对 *Drosophila* 母体效应突变的筛选主要由纽斯林-福尔哈特的组在1980年代的图宾根完成，结果发现前-后轴由三个彼此独立的系统组织起来，背-腹轴则由第四个系统组织：

| 系统 | 关键母体产物 | 定位部位 | 突变体表型 |
|---|---|---|---|
| 前部 | *bicoid* mRNA | 前极 | 缺失头部与胸部，代之以后部结构 |
| 后部 | *oskar*、*nanos* mRNA；极质 | 后极 | 缺失腹部；无生殖细胞（*oskar*） |
| 末端 | Torso 受体（均匀分布），在两极被激活 | 卵的两端 | 缺失最末端（前端器与尾节） |
| 背-腹 | Toll 受体（均匀分布），在腹侧被激活；Dorsal 蛋白 | 腹侧 | 胚胎背化（或腹化） |

要弄明白这些系统从何而来，我们必须从卵巢讲起。

## *Drosophila* 的卵室

一个卵在**卵室**中发育：一个卵母细胞经细胞质桥（环管）与15个**滋养细胞**相连——它们是它由同一个生殖系细胞经四次不完全分裂产生的姐妹细胞——整体被一层体细胞**卵泡细胞**包围。滋养细胞制造卵中大部分的 mRNA 和蛋白质，并把它们泵入卵母细胞。这两条轴由卵母细胞发给卵泡细胞的两个信号设定，同一种分子用了两次。

1. **前-后。**在卵子发生早期，卵母细胞位于卵室的后端，其细胞核产生 **Gurken** 的 mRNA——一种 TGF-α 样配体。Gurken 蛋白经距它最近的卵泡细胞的 EGF 受体（Torpedo）发出信号，赋予它们后部身份。这些细胞回信号给卵母细胞，后者重排其微管，使微管的负端大多位于前端、正端朝向后端。来自滋养细胞的 *bicoid* mRNA 由负端定向的马达蛋白动力蛋白运到前极并锚定在那里；*oskar* mRNA 由正端马达蛋白驱动蛋白运到后极。随后 Oskar 蛋白组装出**极质**，极质捕获 *nanos* mRNA，并含有生殖系的决定因子。
2. **背-腹。**随后卵母细胞的核移向一侧的前部位置，*gurken* mRNA 在其附近翻译，再次向覆盖其上的卵泡细胞发出信号，使它们成为背侧。在背侧卵泡细胞中，EGF 受体信号抑制 *pipe* 基因；未收到 Gurken 的腹侧卵泡细胞则表达它。那一侧就成为胚胎的腹侧。

卵产出时，其轴已由 mRNA 的位置以及卵壳内侧的一种胞外标记所定义。

## 前-后轴

### Bicoid，第一个形态发生素

**Bicoid** 是一种同源结构域转录因子。它的 mRNA 被保持在卵的前极，卵产出后便被翻译。蛋白经合胞体向后扩散并被降解，形成浓度梯度：前端高，到后半部降到几乎没有。沃尔夫冈·德里弗（Wolfgang Driever）与克里斯蒂安娜·纽斯林-福尔哈特于1988年用抗体证明了这一梯度的存在，并表明它是指令性的。携带较少 *bicoid* 拷贝的母体所产生的胚胎，其头部结构形成得更靠近前端；拷贝较多时，头部增大，头-胸边界向后移动。把 *bicoid* mRNA 注射到 *bicoid* 突变母体所产生的胚胎的中央，会在注射处长出头部结构，两侧伴以镜像对称的胸部结构。一种物质在不同位置以不同浓度规定不同命运——刘易斯·沃尔帕特（Lewis Wolpert）所称的形态发生素正是如此。

::: definition 形态发生素与位置信息 {#def-morphogen}
**形态发生素**是一种物质，它从一个局部化的源扩散开去，形成浓度梯度，并在远处*直接*对细胞起作用，以不同浓度规定不同命运。**位置信息**是细胞根据其相对于边界或源的位置所获得的值；细胞按自己的遗传程序**解读**它。沃尔帕特的**法国国旗模型**（1969）是标准的示意：形态发生素高于高阈值的细胞变蓝，介于高、低阈值之间者变白，低于低阈值者变红。
:::

Bicoid 以两种方式发挥作用。作为转录因子，它在胚胎前半部激活靶基因，首先是合子基因 *hunchback*；带有更高亲和力或更多 Bicoid 结合位点的启动子在更低浓度下就有响应，因而表达位置更靠后。作为 RNA 结合蛋白，它抑制均匀分布的母体 *caudal* mRNA 的翻译，于是 Caudal 蛋白形成方向相反的梯度，后端高。

### Nanos 与后部系统

后部系统以抑制的方式工作。*nanos* mRNA 被定位于极质，Nanos 蛋白与 RNA 结合蛋白 Pumilio 一起抑制母体 *hunchback* mRNA 的翻译——后者本来就遍布整个卵。于是母源 Hunchback 蛋白在前部产生而不在后部产生，强化了 Bicoid 激活合子 *hunchback* 所产生的梯度。没有 Nanos 的胚胎缺失腹部，因为 Hunchback 蛋白延伸得太靠后，抑制了腹部基因——而且值得注意的是，同时缺失母体 *hunchback* 与 *nanos* 的胚胎会发育出几乎正常的腹部，表明 Nanos 唯一必需的职责就是清除 Hunchback。

### 末端系统

**Torso** 受体酪氨酸激酶存在于整个卵膜上，但只在两端被激活——激活它的配体需借助 Torso-like 蛋白加工，后者由卵室两极的卵泡细胞产生。Torso 经 Ras–MAP 激酶通路（[[cell-biology/cell-signalling]]）发出的信号解除两极处合子基因 *tailless* 与 *huckebein* 所受的抑制，这两个基因随后规定不分节的最末端：前端的前端器与后端的尾节。

::: intuition 三个梯度，合并解读
到合胞体阶段末期，沿前-后轴的每个核都看到 Bicoid、Hunchback、Caudal 与末端信号的某种特定组合：前端 Bicoid 高、Hunchback 高、Caudal 低；后端 Bicoid 低、Hunchback 低、Caudal 高。没有任何单个梯度携带全部信息。下一层基因，即 [[developmental-biology/segmentation-hox]] 中的间隙基因，通过整合多种输入并相互抑制的增强子读出这些组合，把几条平滑的梯度锐化成一串彼此分明的结构域。
:::

## 形态发生素梯度的数学

像 Bicoid 这样的梯度如何形成，它又能携带多少信息？最简单的模型常被称为**合成-扩散-降解**（SDD）模型，它假定形态发生素在 $x = 0$ 处的源合成，以扩散系数 $D$ 扩散，并在各处以一阶速率常数 $k = 1/\tau$ 降解，其中 $\tau$ 为其平均寿命。

::: proposition 指数梯度 {#prop-sdd}
在一维情形，产生限于 $x = 0$ 处的源，扩散系数为 $D$，各处以平均寿命 $\tau$ 均匀地一阶降解，形态发生素浓度 $c(x, t)$ 满足

$$
\frac{\partial c}{\partial t} = D\frac{\partial^2 c}{\partial x^2} - \frac{c}{\tau} \qquad (x > 0).
$$ {#eq-sdd}

在稳态，对于远比 $\lambda$ 长的组织，其浓度为

$$
c(x) = c_0\,e^{-x/\lambda}, \qquad \lambda = \sqrt{D\tau},
$$ {#eq-gradient}

其中 $c_0$ 是源处的浓度，与产生速率成正比。**衰减长度** $\lambda$ 是浓度下降 $e$ 倍的距离。假设：$D$ 与 $\tau$ 恒定、降解线性、源强度固定，且形态发生场远比 $\lambda$ 长。
:::

::: proof
稳态时 $\partial c/\partial t = 0$，故 $D c'' = c/\tau$，即 $c'' = c/\lambda^2$，其中 $\lambda^2 = D\tau$。通解为 $c = A e^{-x/\lambda} + B e^{x/\lambda}$。远离源处浓度必须保持有界，故 $B = 0$，且 $A = c(0) = c_0$。（离开源的通量 $-Dc'(0) = Dc_0/\lambda$ 等于产生速率，这确定了 $c_0$。）
:::

由此得出三条推论，每一条都已在胚胎中经过检验。

**阈值变成位置。**靶基因在阈值浓度 $T$ 之上开启，在区域 $x < x_T$ 中表达，其中

$$
x_T = \lambda\ln\frac{c_0}{T}.
$$ {#eq-threshold}

**剂量以对数方式移动位置。**把形态发生素的产量乘以因子 $m$，$c_0$ 便乘以 $m$，每条边界都向后移动同样的距离 $\Delta x = \lambda\ln m$，与阈值无关。这正是德里弗与纽斯林-福尔哈特的 *bicoid* 剂量系列所检验的预言。

**噪声变成位置误差。**若细胞以相对误差 $\delta c/c$ 估计浓度，对应的位置误差为 $\delta x = \lambda\,\delta c/c$，因为对指数梯度而言 $\lvert dc/dx\rvert = c/\lambda$。

::: example Bicoid 梯度 {#ex-bicoid}
*Drosophila* 胚胎长约500 µm，Bicoid 梯度以 $\lambda \approx 100$ µm 衰减，约为卵长的20%（托马斯·格雷戈尔（Thomas Gregor）、埃里克·维绍斯、威廉·比亚莱克（William Bialek）及同事用活胚胎中的荧光 Bicoid 融合蛋白测得）。(a) 若 Bicoid 的寿命为 $\tau = 60$ min，SDD 模型需要多大的扩散系数？(b) *hunchback* 边界位于胚胎中部附近。Bicoid 在其前端浓度的什么比例处激活 *hunchback*？(c) 来自 *bicoid* 正常剂量两倍母体的胚胎，其边界应移动多少？
::: solution
(a) 由 $\lambda = \sqrt{D\tau}$，$D = \lambda^2/\tau = (100\ \mathrm{\mu m})^2/3600\ \mathrm{s} = 2.8\ \mathrm{\mu m^2\,s^{-1}}$。

(b) 取 $x_T = 250$ µm，由 [[#eq-threshold]] 得 $T/c_0 = e^{-x_T/\lambda} = e^{-2.5} = 0.082$：边界位于 Bicoid 降到其前端水平约8%之处。

(c) $\Delta x = \lambda\ln2 = 100\times0.693 = 69$ µm，向后，约为卵长的14%。

这个模型拟合得如何？Bicoid 扩散的测量结果曾很有争议。格雷戈尔及同事2007年的光漂白实验给出 $D \approx 0.3\ \mathrm{\mu m^2\,s^{-1}}$，这将使梯度在可用时间内远远伸展不了那么长；随后的荧光相关测量很快发现了移动快得多的组分，达好几个 µm² s⁻¹，与 (a) 一致。而在剂量实验中，Bicoid 靶基因的边界按预言的方向移动，但移动量常常略小于 $\lambda\ln m$，表明还有其他输入——后部系统与间隙基因的相互调控——也在为边界定位。简单模型抓住了尺度，而非每个细节。
:::
:::

### 锐利地解读梯度

若 *hunchback* 的表达只是简单地正比于 Bicoid 浓度，它会沿胚胎渐渐淡出。事实相反，它形成一条锐利的边界：在几个核之内，表达从高降到低。陡峭的阈值响应可用 Hill 函数描述（[[cell-biology/cell-signalling]]）：最大表达的分数为 $c^n/(T^n + c^n)$，其中 $n$ 为 Hill 系数。格雷戈尔及同事在2007年估计，*hunchback* 响应 Bicoid 的有效 Hill 系数约为5，这与其启动子上 Bicoid 结合位点的簇及其协同占据相符。

::: proposition 从指数梯度读出的边界宽度 {#prop-boundary-width}
若靶基因以系数为 $n$ 的 Hill 函数响应指数梯度 $c = c_0e^{-x/\lambda}$，其表达从最大值的90%降到10%所跨的距离为

$$
\Delta x_{90\to10} = \frac{\lambda\ln 81}{n} \approx \frac{4.4\,\lambda}{n}.
$$ {#eq-boundary-width}
:::

::: proof
表达 $E = 1/(1 + (T/c)^n)$，故 $E/(1-E) = (c/T)^n$，$\ln(c/T) = \tfrac1n\ln\bigl(E/(1-E)\bigr)$。由 $\ln c = \ln c_0 - x/\lambda$，$E = 0.9$ 与 $E = 0.1$ 两处位置相差 $\Delta x = \tfrac{\lambda}{n}\bigl(\ln 9 - \ln\tfrac19\bigr) = \tfrac{\lambda}{n}\ln81$。
:::

:::

::: example *hunchback* 边界有多锐利？ {#ex-boundary-width}
Bicoid 的 $\lambda = 100$ µm，*hunchback* 以 Hill 系数 $n \approx 5$ 响应。(a) *hunchback* 表达从90%降到10%跨过多大距离？(b) 若每个 Bicoid 分子独立作用（$n = 1$），宽度会是多少？(c) 两者各相当于多少个核间距（8 µm）？
::: solution
(a) 由 [[#eq-boundary-width]]，$\Delta x = 100\times\ln81/5 = 100\times4.394/5 = 88$ µm。

(b) $n = 1$ 时，$\Delta x = 439$ µm——几乎等于这条500 µm 胚胎的全长，也就谈不上边界了。

(c) 88/8 ≈ 11个核间距，而 $n = 1$ 时为55个。协同性把一条平滑的指数曲线变成某种可称为边界的东西，但单凭它，与胚胎实际达到的锐度相比仍差一个数量级。
:::
:::

即便 Hill 系数为5，在一条100 µm 的梯度上边界仍有约90 µm 宽，约十个核间距。第14周期中真实的 *hunchback* 边界比这更锐利，其边界在不同胚胎之间的定位精确度约为一个核间距，尽管 Bicoid 梯度本身的变异比这还大。贝尔纳·胡什曼扎德（Bernard Houchmandzadeh）、埃里克·维绍斯与斯坦尼斯拉斯·莱布勒（Stanislas Leibler）在2002年强调了这一点，由此推动了大量关于胚胎如何实现精确性的研究：靠时间上的平均、靠相邻核之间的交流，以及靠间隙基因之间的相互抑制——后者使其边界自我锐化。发育比任何单个分子步骤都更精确，这是一个反复出现的主题。

::: example 梯度能有多精确？ {#ex-positional-error}
设一个核以10%的相对误差测量其局部 Bicoid 浓度（源于几百个分子随机到达其 *hunchback* 增强子）。$\lambda = 100$ µm 时，由此产生的位置不确定度是多少？第14周期的核大约相距8 µm。单个梯度足以把一条边界规定到一个核以内吗？
::: solution
$\delta x = \lambda\,\delta c/c = 100\times0.10 = 10$ µm，略多于一个核间距。因此，以10%的精度读取单个梯度，可以把边界定到一至两个核以内——但前提是梯度本身在每个胚胎中完全相同，而事实并非如此。不同胚胎之间 Bicoid 含量10%的差异会使边界移动 $\lambda\ln1.1 = 9.5$ µm，又是一个核。约一个核的精确度已接近单个梯度所能达到的极限，而测得的边界精确度正是认为胚胎联合使用多种输入的理由之一。
:::
:::

::: warning 「每个梯度都是形态发生素梯度」
一种在组织中浓度有变化的分子未必是形态发生素。要够格，它必须远距离直接对细胞起作用（而不是经由其他信号中继传递），而且不同浓度必须规定不同命运。证明这一点需要实验：改变剂量看边界移动（[[#ex-bicoid]]）；制造不能接收该信号的细胞克隆，看它们以细胞自主的方式改变命运；或把它引入别处，看周围是否出现新的图样。许多梯度原来只是其他信号的渐次后果，而非指令性信号本身；还有许多图样的产生根本不需要长程形态发生素，而是靠局部相互作用（[[developmental-biology/organogenesis]]）。
:::

## *Drosophila* 的背-腹轴

卵泡细胞留下的 *pipe* 腹侧标记，是卵壳内层一种被硫酸化的蛋白质。受精后，它在胚胎与其外包膜之间的液体中触发一连串丝氨酸蛋白酶，最终只在腹侧把一种叫 Spätzle 的蛋白切割成活性配体。Spätzle 结合受体 **Toll**——Toll 存在于胚胎膜的任何部位。（Toll 在哺乳动物中的近亲，Toll 样受体，后来被发现是先天免疫的关键受体——这是一个著名的例子：一个发育基因揭示了一条在别处使用的通路。）

Toll 信号导致胞质抑制蛋白 Cactus 降解，使转录因子 **Dorsal** 得以进入细胞核。于是处处存在的 Dorsal 蛋白在腹侧位于核内、在背侧留在细胞质中，两者之间呈梯度过渡。齐格弗里德·罗特（Siegfried Roth）、戴维·斯坦因（David Stein）与纽斯林-福尔哈特，以及独立工作的露丝·斯图尔特（Ruth Steward），在1989年描述了这一核梯度。Dorsal 与哺乳动物转录因子 NF-κB 同源，Cactus 与其抑制蛋白 IκB 同源。

核内 Dorsal 梯度被具有不同阈值的靶增强子解读：

- 腹侧的高 Dorsal 激活 *twist* 与 *snail*，规定**中胚层**。
- 中间水平在腹外侧区域激活**神经外胚层**中的 *rhomboid* 与 *short gastrulation*（*sog*）等基因，神经外胚层形成腹神经索；在 Dorsal 最高处，Snail 抑制它们。
- Dorsal *抑制* *decapentaplegic*（*dpp*）与 *zerknüllt*（*zen*），所以它们只在背部的**背部外胚层**和羊膜丝中表达。

BMP 之一的 Dpp 随后在背部区域形成第二个更精细的梯度，该梯度受神经外胚层的 Sog 蛋白塑造：Sog 结合 Dpp 并帮助其向背侧运送。同一对分子——一个 BMP 及其拮抗剂——为脊椎动物的背-腹轴提供模式，只是轴上下颠倒（[[developmental-biology/gastrulation]]、[[developmental-biology/evo-devo]]）。

::: quiz
一只雌蝇对 *Toll* 的功能丧失突变是纯合的。它的配偶是野生型。胚胎会是什么样子？
- [ ] 正常，因为它们从父亲那里得到一份野生型 *Toll* 拷贝
- [x] 背化：所有细胞采取背侧命运，没有中胚层或腹神经索
- [ ] 腹化：所有细胞形成中胚层
- [ ] 缺失头部，如同 *bicoid* 突变体
::: solution
*Toll* 是母体效应基因：建立轴时所需的受体来自母体的 mRNA，此时胚胎自己的基因（包括父源拷贝）尚未激活。没有 Toll，Dorsal 到处都留在细胞质中，*twist* 与 *snail* 不被激活，*dpp* 与 *zen* 不受抑制：胚胎变成一根背侧表皮的管子。显性的功能获得性 *Toll* 等位基因到处发出信号，作用相反，使胚胎腹化。
:::
:::

## 脊椎动物的轴

### 蛙：精子设定背侧

*Xenopus*（非洲爪蟾）的卵有一条母体的**动物-植物轴**，表现为带色素的动物半球。卵子发生期间定位于植物极皮层的母体 mRNA 包括 *vegT*，它编码一种 T-box 转录因子，为形成内胚层及诱导中胚层所必需；以及 *vg1*，编码 TGF-β 家族的一个成员。

背-腹轴在受精时确立。精子进入动物半球，其中心粒在植物极皮层组织起一排平行的微管。皮层沿这些微管相对内部细胞质旋转约30°，朝精子入卵的对侧移动，那一侧成为**背侧**。皮层旋转把植物极组分——包括 Wnt 通路蛋白 Dishevelled 与配体 Wnt11的 mRNA——带到未来的背侧，它们在那里稳定 **β-catenin**（[[cell-biology/cell-signalling]]）。到囊胚期，β-catenin 位于背侧细胞的核中，此外别无他处。

证据是一系列简单的操作：

- 受精后不久对植物极施加紫外线，会破坏微管阵列并阻止皮层旋转。胚胎发育时没有背侧结构——没有头、脊索或神经管。
- 把这样的胚胎转动90°，让重力把细胞质推向皮层，就在转向上方的那一侧救出一条背侧轴。
- 氯化锂抑制糖原合酶激酶3，从而在各处稳定 β-catenin，使胚胎背化：它们长出扩大的头与环周的脊索。
- 耗竭母体 β-catenin mRNA 会阻止轴的形成（珍妮特·赫斯曼（Janet Heasman）、克里斯托弗·怀利（Christopher Wylie）及同事，1994）。

在背侧植物极细胞中，β-catenin 与植物极转录因子 VegT 及 Nodal 相关信号共同形成**纽维科普中心**，它以彼得·纽维科普（Pieter Nieuwkoop）命名——他在1969年证明，植物极细胞能诱导与之贴合的动物半球细胞形成中胚层。纽维科普中心诱导其上方的细胞成为**组织者**，即 [[developmental-biology/gastrulation]] 所描述的原肠形成的信号中心。

::: example 挽救经紫外线处理的胚胎 {#ex-uv}
*Xenopus* 卵在受精后30分钟于植物极接受紫外线照射。预测并解释每种情况的结果：(a) 不再作任何处理；(b) 在32-细胞期向一个植物极卵裂球注射 *β-catenin* mRNA；(c) 把同样的 mRNA 注射到一个动物极卵裂球；(d) 在32-细胞期短暂用氯化锂处理。
::: solution
(a) 没有皮层旋转，β-catenin 在任何一侧都不被稳定：没有纽维科普中心，没有组织者，胚胎呈辐射对称，只有腹侧命运（肠与腹侧中胚层，无轴）。

(b) 一个植物极细胞中的 β-catenin 在那一侧重建出一个纽维科普中心：胚胎形成一条以被注射细胞为中心的背侧轴。这表明皮层旋转通过稳定 β-catenin 起作用，而背侧可以放在任何地方。

(c) 含 β-catenin 的动物极细胞自己不能形成纽维科普中心，因为它们缺少与之协作的植物极因子（VegT、Nodal 相关信号）；结果至多是一条很弱或不完整的轴，取决于注入的物质扩散多远。

(d) 锂在所有细胞中稳定 β-catenin，于是整个植物极区域都变得像纽维科普中心：一个「背化」的胚胎，具有辐射状、过大的头和脊索，腹侧组织很少。效应的强弱取决于剂量与时间。
:::
:::

### 鸡与小鼠

鸡胚胎在卵黄之上形成一个盘，即胚盘。卵在母鸡输卵管的壳腺中旋转时，重力使胚盘倾斜，位于最上方的一侧成为后部。后缘的一弯新月形细胞——**科勒氏镰（Koller's sickle）**——及其上方的后边缘区，充当类似纽维科普中心的区域；**原条**就在那里形成，细胞将经它原肠形成。

小鼠胚胎没有可检测的母体轴。在植入前后，上胚层形成一个杯状的**卵柱**，外面覆以内脏内胚层。其顶端的一群细胞——**远端内脏内胚层**——迁移到一侧，成为**前内脏内胚层（AVE）**。AVE 分泌 Nodal 与 Wnt 的拮抗剂（Lefty1与 Cerberus 样蛋白），使相邻的上胚层保持前部身份；在对侧，Nodal 与 Wnt3信号得以自由诱导原条，原条标志后部。安妮·托马斯（Anne Thomas）与罗莎·贝丁顿（Rosa Beddington）在1996年证明，去除 AVE 会阻止前脑的形成。因此在小鼠中，前-后轴来自胚胎细胞之间的相互作用，而非母体的预置模式。

## 左-右轴

脊椎动物的心脏、肠、肝和肺不对称地摆放，尽管身体外面看起来对称。不对称在另外两条轴之后建立，约在体节形成之时；在小鼠，第一步是一种流体流动。脊索后端有一个小凹，即**结**，其细胞各带一根可动纤毛。纤毛从腹侧看顺时针旋转，又因向后倾斜，驱动覆盖结上方的液体向左流动。

Shigenori Nonaka、Nobutaka Hirokawa 及同事在1998年描述了这种**结流（nodal flow）**：缺乏马达蛋白 KIF3B 的小鼠，结上没有纤毛、没有流动，器官的左-右取向随机。2002年 Nonaka 及同事用人工右向电流逆转了培养中小鼠胚胎的流动，胚胎便发育出反向的不对称。流动如何被感知仍有争论：结边缘的冠状细胞带有不动纤毛，被认为通过机械方式或 Ca²⁺ 信号检测流动；而一个较早的设想是，流动把信号分子的囊泡带到左侧。

下游只在左侧，TGF-β 家族蛋白 **Nodal** 在侧板中胚层表达，连同其反馈抑制因子 **Lefty** 与转录因子 **Pitx2**，后者指挥器官的不对称形态发生。中线处的 Lefty1充当屏障，阻止 Nodal 扩散到右侧。并非所有脊椎动物都使用纤毛驱动的流动——鸡胚经亨森结周围的细胞运动打破对称——但左侧的 Nodal–Lefty–Pitx2模块广泛保守。

::: application 纤毛病与侧位异常
在人类中，原发性纤毛运动障碍——一种可遗传的可动纤毛缺陷——的患者约有一半有 *situs inversus*（内脏镜像反位）：没有结流，左-右轴随机设定，因而一半情况下是反的。这一关联最早由马内斯·卡塔格内（Manes Kartagener）在1930年代注意到，但只有在结流被发现之后才得到解释。侧位与纤毛疾病的临床特征由医学图谱（[医学图谱](/learn/medicine/)）介绍。
:::

::: history
特奥多尔·博韦里（Theodor Boveri）在1901年提出，海胆卵含有沿其动物-植物轴的梯度；梯度思想在1910年代由研究扁形动物与水螅的查尔斯·曼宁·柴尔德（Charles Manning Child）发展。刘易斯·沃尔帕特于1969年提出位置信息与法国国旗模型，1970年弗朗西斯·克里克（Francis Crick）证明扩散可以在数小时内、在早期胚胎的距离上建立梯度。分子时代始于1980年代纽斯林-福尔哈特组的母体筛选、德里弗与纽斯林-福尔哈特对 Bicoid 梯度的鉴定（1988年），以及核 Dorsal 梯度（1989年）。纽斯林-福尔哈特、维绍斯与爱德华·刘易斯（Edward Lewis）共获1995年诺贝尔生理学或医学奖，以表彰「关于早期胚胎发育的遗传控制方面的发现」。在脊椎动物中，皮层旋转的作用由约翰·格哈特（John Gerhart）及同事在1980年代阐明，β-catenin 的作用在1990年代，结流在1998年。
:::

::: summary
- 动物有前-后、背-腹和左-右三条轴，它们建立很早，供其后一切模式构建使用。
- 在 *Drosophila* 中，母体效应基因在卵室中建立各轴。卵母细胞的 Gurken 两次向卵泡细胞发出信号，先规定后部、再规定背侧；微管极性把 *bicoid* mRNA 放在前部，把 *oskar* 与 *nanos* mRNA 放在后部。
- Bicoid 形成前部梯度，激活合子 *hunchback* 并抑制 *caudal* 的翻译；Nanos 在后部抑制母体 *hunchback*；Torso 信号规定两端。
- 形态发生素远距离直接起作用，效应随浓度而异。在合成-扩散-降解模型中，$c = c_0e^{-x/\lambda}$，$\lambda = \sqrt{D\tau}$；边界位于 $x_T = \lambda\ln(c_0/T)$，剂量改变 $m$ 倍时移动 $\lambda\ln m$，位置误差为 $\lambda\,\delta c/c$。Bicoid 的 $\lambda \approx 100$ µm。
- 陡峭的（Hill 型）读取把边界锐化到宽度 $\lambda\ln81/n$；由于反馈与相互抑制，真实边界比单个梯度的预言更精确。
- 腹侧的 Toll 激活释放 Dorsal 进入腹侧核；核 Dorsal 梯度规定中胚层（*twist*、*snail*）、神经外胚层（*rhomboid*、*sog*），并通过抑制规定背部外胚层（*dpp*、*zen*）。
- 在 *Xenopus* 中，背离精子入卵的皮层旋转在背侧稳定 β-catenin，形成诱导组织者的纽维科普中心。在小鼠中，前内脏内胚层限制 Nodal 与 Wnt，使原条在后部形成。
- 在小鼠中，左-右不对称始于由旋转纤毛驱动的左向结流，导致左侧的 Nodal、Lefty 与 Pitx2。
:::

## 习题

::: exercise 衰减长度 {level=1 check="42.4"}
一种形态发生素的扩散系数为 $1\ \mathrm{\mu m^2\,s^{-1}}$，平均寿命30分钟。按 SDD 模型，其衰减长度 $\lambda$ 是多少 µm（三位有效数字）？
::: solution
$\lambda = \sqrt{D\tau} = \sqrt{1\times1800}\ \mathrm{\mu m} = 42.4$ µm。
:::
:::

::: exercise 阈值位置 {level=1 check="230"}
对梯度 $c = c_0e^{-x/\lambda}$，$\lambda = 100$ µm，浓度降到 $c_0$ 的10%之处距源多远（以 µm 计，三位有效数字）？
::: solution
$x = \lambda\ln(c_0/c) = 100\ln10 = 230$ µm。
:::
:::

::: exercise 母体表型 {level=1}
预测下列纯合突变母体所产胚胎的表型：(a) *bicoid*；(b) *nanos*；(c) *torso*；(d) *cactus*（功能丧失）。
::: solution
(a) 无头无胸；前端形成后部结构（第二个尾节）。(b) 无腹节，因为母源 Hunchback 在后部不受抑制。(c) 无前端器或尾节（不分节的两端）。(d) 腹化：没有 Cactus，Dorsal 进入所有核，整个胚胎形成腹侧命运（中胚层）。
:::
:::

::: exercise 一个剂量系列 {level=2 check="40.5"}
某胚胎的母体带有三个 *bicoid* 拷贝而非两个（产量为正常的1.5倍），若 $\lambda = 100$ µm，一条阈值边界应移动多少微米（三位有效数字）？朝哪个方向？
::: solution
$\Delta x = \lambda\ln1.5 = 100\times0.405 = 40.5$ µm，向后（朝浓度更低的方向），对每条阈值边界都如此。
:::
:::

::: exercise 更锐利的读取者 {level=2 check="44"}
一个靶基因通过 Hill 函数读取一条 $\lambda = 100$ µm 的梯度。若其表达要在10 µm——约一个核间距——内从90%降到10%，需要多大的 Hill 系数？取最接近的整数。
::: solution
由 [[#eq-boundary-width]]，$n = \lambda\ln81/\Delta x = 100\times4.394/10 = 43.9$，约44——远超单个因子协同结合所能达到的程度（典型值为1–5）。锐利的边界需要靶基因间相互抑制等额外机制。
:::
:::

::: exercise bicoid–nanos 双突变体 {level=2}
同时缺失母体 *hunchback* 与 *nanos* 的母体所产胚胎，腹部几乎正常。缺失 *bicoid* 的母体所产胚胎则缺失头与胸。利用这些观察，说明 Nanos 与 Bicoid 各自必需于什么，以及两个系统为何在逻辑上不对称。
::: solution
Nanos 唯一必需的功能，就是阻止母源 Hunchback 蛋白在后部产生；当母体 *hunchback* 缺失时，Nanos 便可有可无。所以后部系统完全靠抑制一个腹部命运的抑制因子来工作。相比之下，Bicoid 是指令性激活因子：它以浓度依赖的方式激活合子 *hunchback* 及其他前部基因，并抑制 *caudal* 的翻译；不存在这样一个靶子，去掉它就可使 Bicoid 变得不再必要。前部系统规定位置；后部系统清除障碍。
:::
:::

::: exercise 噪声造成的位置误差 {level=3}
一条 $\lambda = 50$ µm 的形态发生素梯度被以20%相对误差测量浓度的细胞读取。(a) 位置误差是多少？(b) 同一组织也可由两条方向相反的梯度提供模式，两端各一条，$\lambda = 50$ µm，各以相同的相对误差独立读取。在中部附近，合并两个位置估计可降低误差。若两个误差彼此独立且相等，误差降低多少倍？(c) 胚胎为何可能使用方向相反的梯度，如果蝇之于 Bicoid 与后部信号？
::: solution
(a) $\delta x = \lambda\,\delta c/c = 50\times0.2 = 10$ µm。

(b) 两个方差同为 $\sigma^2$ 的独立估计取平均，方差变为 $\sigma^2/2$，误差按因子 $\sqrt2$ 下降，约7.1 µm。

(c) 单条指数梯度在其源附近陡峭（信息量大），而远离源处浓度低，梯度平缓而有噪声，小的绝对误差就是大的相对误差。方向相反的梯度在全轴上都给出良好的信息，而且两个信号之比可以不随胚胎整体大小改变——这是模式随大小缩放的一种可能的途径。
:::
:::

::: exercise 器官不对称数据 {level=3}
一个突变小鼠品系中，100个胚胎里52个心脏向右环曲（正常方向），48个向左。第二个品系中，100个胚胎里3个向右环曲，97个向左。(a) 这些分布对各品系的缺陷有何提示？(b) 哪个品系可能缺少结上的可动纤毛，哪个品系的缺陷可能位于流动的下游？(c) 请为第一个品系提出一个实验，以区分你的各种假设。
::: solution
(a) 第一个品系中，侧位是随机的——52 : 48的分配与50 : 50一致（二项检验提不出反对它的证据）——所以这些胚胎失去了通常设定左-右轴的偏向，但仍产生不对称。第二个品系中，不对称一致地反转：偏向存在，但方向错了，表型类似经典的 *inv* 小鼠突变体。

(b) 失去可动纤毛或失去流动会消除偏向，产生随机的侧位（第一个品系，如 *Kif3b* 或 *iv* 突变体）。一致的反转意味着仍有某种东西检测或产生方向性信号，只是被读错了方向——例如异常的流动，或左侧下游信号级联的缺陷。

(c) 用微珠对第一个品系胚胎的结成像，看纤毛是否摆动、液体是否向左流动。若没有流动，检验人工左向流能否挽救正常的不对称。检查 *Nodal* 与 *Pitx2* 的表达：在流动缺陷的品系中，它们应当随机地出现在左侧、右侧、两侧或两侧皆无。
:::
:::
