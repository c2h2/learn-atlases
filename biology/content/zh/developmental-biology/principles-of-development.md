一枚蛙卵是一个直径约1.2 mm 的单个细胞。在室温下不到四天，它已变成一条会游泳的蝌蚪，有脑、眼、跳动的心脏、沿背部一排排重复的肌块、肠、肾和皮肤——为数极多、种类几十的细胞，各在其位。除了水、氧气和热量，没有任何东西从外面加入。建造蝌蚪的全部指令早已在卵里：在它的基因组里，也在母亲放入其细胞质的分子里。

这是如何发生的，正是**发育生物学**的课题。它有几个彼此不同的问题，本课程的各章逐一讨论。

- **分化。**一个细胞产生多种细胞类型——神经元、肌纤维、红细胞、晶状体细胞——它们在形状、所制造的蛋白质和功能上各不相同。
- **模式形成。**不同的细胞类型必须出现在正确的位置、按正确的比例：头在一端，指在肢的末端而不是在其半腰。
- **形态发生。**细胞层与细胞团折叠、移动、伸展、融合，产生三维形态——管道、层、腔和分支。
- **生长。**器官达到合适的大小，并且彼此成比例地生长。
- **繁殖与更新。**生殖系被留出来制造下一代；在许多组织中，干细胞终生不断制造新细胞。
- **进化。**发育的改变正是新形态进化的方式；最后一章 [[developmental-biology/evo-devo]] 将回到这一主题。

本章介绍贯穿所有这些问题的思想：胚胎的细胞共用一个基因组，却表达其中不同的部分；细胞一步步地朝向自己的命运走向定向，实验能够检测这些阶段；细胞之间通过信号相互指令；转录因子的网络把短暂的信号变成持久的细胞身份。章末我们介绍发现这些思想的实验生物。本章假定读者已具备 [[molecular-biology/eukaryotic-gene-regulation]] 的机制——转录因子、增强子和染色质——以及 [[cell-biology/cell-signalling]] 的信号通路知识。

## 一个基因组，许多种细胞类型

身体的细胞外观与行为迥异，发育的头号大问题便是它们是否*含有*不同的遗传物质。1880年代，奥古斯特·魏斯曼（August Weismann）提出它们确实如此：卵的细胞核含有身体每一部分的决定因子，这些因子在每次细胞分裂时被不均等地分配，于是肌肉细胞只保留肌肉决定因子。只有生殖系会保留全套。这一想法很自然，但它错了——而驳倒它花了七十年，因为那需要把一个已分化细胞的细胞核取出来，问它还能做什么。

### 核移植

罗伯特·布里格斯（Robert Briggs）与托马斯·金（Thomas King）1952年用豹蛙 *Rana pipiens* 建立了这一方法。他们除去未受精卵的核，用从囊胚——一个数千细胞的胚胎——的某个细胞中吸出的核取而代之。许多重建的卵发育成了正常蝌蚪。来自较晚阶段的核则越来越不成功，这起初似乎支持核潜能受限的看法。约翰·戈登（John Gurdon）用非洲爪蟾 *Xenopus laevis* 工作，从摄食期蝌蚪肠上皮——完全分化的细胞——取核，于1962年从其中一小部分得到游泳的蝌蚪；后来的工作得到了可育的成年蛙。一个成功的例子就足以说明问题：已分化细胞的核仍能指挥一只完整动物的发育，所以分化并没有去掉神经、皮肤或血液的基因。

在哺乳动物中，这一点同样得到了证明：伊恩·威尔穆特（Ian Wilmut）、基思·坎贝尔（Keith Campbell）及其同事1997年报道，1996年7月出生的一只羊——多利——由一只绵羊的卵发育而来，其核被一只6岁母羊乳腺培养细胞的核取代。效率极低（277枚重建卵中得到一只羊羔），而每个物种中绝大多数核移植胚胎都会死亡或发育异常，因为卵细胞质只能部分成功地重置供体核的基因表达状态（[[#ex-dolly]]）。

::: definition 基因组等价与差异基因表达 {#def-genomic-equivalence}
**基因组等价**是这样一条原理：除少数例外，生物体的每个体细胞都含有与合子相同的基因组。细胞之所以不同，在于它们表达各自不同的基因子集：分化就是**差异基因表达**，由转录因子、染色质以及 [[molecular-biology/eukaryotic-gene-regulation]] 中的其他调控机制控制。
:::

这些例外之所以有启发，恰恰因为它们是例外。脊椎动物发育中的淋巴细胞会剪切并重新连接其抗体和 T 细胞受体基因的片段（V(D)J 重组），因此每个 B 细胞或 T 细胞都带着一个重排过的位点。哺乳动物的红细胞把核整个排出。在线虫 *Parascaris*（特奥多尔·博韦里于1887年研究过它）以及某些昆虫、桡足类和七鳃鳗中，体细胞在发育早期丢弃一部分 DNA，而生殖系保留全部——**染色质减缩**。这些都不是细胞*一般地*变得不同的方式。

::: warning 「分化后的细胞已经丢掉了它们不用的基因」
肝细胞仍带有血红蛋白、视紫红质和骨骼肌肌球蛋白的基因；它只是不表达它们。核移植，以及2006年以来用转录因子把成年细胞重编程到多能性（[[developmental-biology/stem-cells-regeneration]]），都直接证明了这一点。细胞类型之间的差别，在于哪些基因是*可及而有活性的*——这一状态由转录因子和染色质承载，原则上可逆。
:::

::: example 多利的克隆效率有多低？ {#ex-dolly}
威尔穆特及同事用乳腺培养细胞的核重建了277枚绵羊卵，得到一只活羊羔。(a) 每枚重建卵的成功率是多少？(b) 若真实成功率恰为此值，要得到至少一只活羊羔有95%的概率，需要多少枚重建卵？(c) 这一低率对重编程有何提示？
::: solution
(a) $1/277 = 0.0036$，即0.36%。

(b) 把每枚卵当作成功概率 $p = 1/277$ 的独立试验。$n$ 次试验中全不成功的概率为 $(1-p)^n$，我们要求 $1 - (1-p)^n \ge 0.95$：

$$
n \ge \frac{\ln 0.05}{\ln(1 - p)} = \frac{-2.996}{-0.003617} = 828.
$$

所以约830枚卵。（成功率本身并不确定：277次试验中1次成功，真实比率完全可能高出或低出好几倍。）

(c) 几乎每一枚重建卵都失败了，尽管每一枚都含有完整的基因组。卵细胞质必须在几个细胞周期内重编程供体核——擦去一个乳腺细胞的染色质标记和转录因子占据状态，建立起合子的那一套——而它通常做得不完整。失败反映的是基因表达状态重置得不完全，而不是基因缺失；那一次成功说明基因都在。
:::
:::

## 命运、特化与定向

如果所有细胞都有相同的基因，细胞何时、如何决定自己将成为什么？我们需要精确的词语来描述决定的各个阶段，因为同一个细胞可以在通往某种命运的途中，却尚未对它定向。

一个细胞的**命运**只是它正常情况下会成为什么。测定命运的方法是在正常胚胎中标记细胞——用活体染料（瓦尔特·福格特1920年代的方法）、注射的荧光示踪物或遗传标记——再看它们的后裔最终落在哪里。**命运图谱**是一张标示每个区域未来的早期胚胎示意图。它记录的是正常发育，而不是细胞*能够*做什么的陈述。

::: definition 特化、决定与分化 {#def-commitment}
- 若一个细胞或组织被分离出来，在一种中性环境（不提供任何指令性信号的环境）中培养时，按照某种命运发育，则称它已为该命运**特化**。特化是可逆的：换一种环境就能改变结果。
- 若它即使被移植到胚胎的另一个区域、身处其他命运的细胞之间，仍按其命运发育，则称它已**决定**。决定是稳定的、通常不可逆的定向。
- 当它已成为可辨认的特化细胞类型——制造出神经元、肌纤维或软骨细胞的蛋白质并采取它们的结构——则已**分化**。分化通常在决定之后许多小时或数天才发生。
:::

[[#def-commitment]] 中的两种检验是操作性的：它们以实验所示的结果来定义定向，而答案可能取决于实验者把什么算作「中性」、又试了哪种新环境。尽管如此，这一区分仍是本学科最有用的一条。

::: example 施佩曼对未来神经板与表皮的互换 {#ex-spemann-1918}
1918年，汉斯·施佩曼（Hans Spemann）在两个蝾螈胚胎刚开始原肠形成时互换了组织块：把将变成神经板的区域的一块，放进将变成腹部表皮的区域，反之亦然。两个胚胎分属色素不同的物种，所以移植的细胞日后可以辨认。每块移植物都按其*新位置*发育：腹部的未来神经组织形成了表皮，神经区域的未来表皮形成了脑。在原肠形成末期做同样的互换时，每块移植物都按其*来源*发育：未来神经组织在腹部形成了一段神经管。关于这些细胞在这两个阶段的定向状态，你能得出什么结论？
::: solution
早原肠胚期，外胚层的命运（神经或表皮）尚未决定：移植的细胞采取与其新环境相适应的命运，所以它们的命运取决于所接收的信号。到晚原肠胚期，未来神经细胞已经决定：它们在陌生区域保持神经命运。在两个阶段之间，有某种东西告诉背侧外胚层成为神经。正是这一观察直接导致了组织者与神经诱导的发现（[[developmental-biology/gastrulation]]）。注意这个实验*没有*显示什么：它没有告诉我们早期的未来神经组织是否已经特化，而那需要一个分离实验。
:::
:::

细胞通过三种大体方式获得特化，多数胚胎三种都用。

1. **自主特化。**细胞继承**细胞质决定因子**——常定位于卵的特定区域的分子，多为 mRNA 或蛋白质——它们不依赖邻居地规定细胞的命运。将其分离后，它做自己在胚胎中本会做的事。埃德温·康克林（Edwin Conklin）1905年证明，在被囊动物 *Styela partita* 中，一块带黄色色素的卵细胞质区域——黄色新月——被将来形成幼虫尾部肌肉的细胞继承。将近一个世纪后，Hiroki Nishida 与 Kaichiro Sawada（2001）在海鞘 *Halocynthia roretzi* 中鉴定出一个决定因子：*macho-1* 的母体 mRNA，它编码一种锌指转录因子；去除它会消除主要尾肌，而在别处注射它则诱导异位肌肉。
2. **条件特化。**细胞的命运取决于它的位置，通过其他细胞的信号。将其分离后，它可能做别的事；将它移动后，它改变命运以适应新邻居。[[#ex-spemann-1918]] 中蝾螈早期的外胚层就是条件特化的。
3. **合胞体特化。**在 *Drosophila* 等昆虫的早期胚胎中，核分裂时不形成细胞膜，共处一个公共细胞质（**合胞体**）中，转录因子可以在核之间扩散，形成为其提供模式的浓度梯度（[[developmental-biology/axis-formation]]）。

严重依赖自主特化的胚胎有时被称为**镶嵌型**：除去一部分，幼体相应的部分就缺失。依赖条件特化的胚胎是**调整性**的：能够补偿细胞的去除或添加。这些词描述的是倾向，不是两类动物：海鞘胚胎是教科书中的镶嵌型胚胎，但它的脊索和神经系统是诱导出来的；小鼠胚胎高度调整性，但它的头几次细胞命运决定涉及细胞极性。

::: intuition 细胞知道自己继承了什么、身在何处
在任何时刻，细胞将成为什么取决于两类信息：它携带的（从卵继承的决定因子、从母细胞继承的转录因子与染色质状态）与它接收的（来自邻居、来自细胞外基质、来自机械力的信号）。自主特化与条件特化是这一平衡的两个极端。发育就是一场对话，其中继承的状态决定细胞能听到哪些信号，而信号改变被传递下去的状态。
:::

## 潜能与表观遗传景观

定向也可以由一个细胞*还能*成为什么来描述，即它的**潜能**。随着发育进行，潜能通常收窄。

::: definition 潜能 {#def-potency}
- **全能**细胞能产生生物体的每一种细胞，包括（哺乳类中的）胎盘等胚外组织。合子以及小鼠约4-细胞期以前的单个卵裂球是全能的。
- **多能**细胞能产生胚胎本体的每一种细胞类型（三个胚层和生殖系），但不能产生胚外滋养层；哺乳类胚泡的内细胞团及由其衍生的胚胎干细胞是多能的。
- **多潜能**细胞能产生相关一族的几种细胞类型——造血干细胞造出所有血液细胞类型。
- **单能**细胞只产生一种细胞类型，如精原干细胞。
:::

康拉德·沃丁顿（Conrad Waddington）用他的**表观遗传景观**（《基因的策略》（*The Strategy of the Genes*，1957））概括了这一思想：一个球沿一张有分叉山谷的表面滚下。球是细胞；山谷是发育路径；在每一个岔路口，一个小小的推力——一个信号——决定细胞进入哪条山谷；滚得越深，山谷之间的山脊越高，就越难改换。沃丁顿还用这张图解释**渠道化**，即正常发育对遗传与环境扰动的稳健性：深谷会在轻轻一推之后把球带回它的路径。

这张景观是一个比喻，但它有一个精确的版本：山谷是细胞基因调控网络的**稳定状态**，山脊是它们之间的屏障。下一节把它具体化。

## 诱导与感受性

条件特化要求细胞之间互相发出信号。其核心概念是诱导。

::: definition 诱导与感受性 {#def-induction}
**诱导**是一个细胞群（**诱导者**）改变另一个细胞群（**应答者**）发育命运的过程。应答细胞对信号作出反应的能力是其**感受性**。感受性本身是一种发育状态：它取决于细胞拥有正确的受体、信号转导组分和转录因子，而且通常只在有限的时间窗口内存在。
:::

经典的例子是脊椎动物眼的晶状体。视泡——脑的一个突出——接触头部外胚层，后者增厚并形成晶状体。施佩曼在1901年报道，破坏蛙 *Rana fusca* 的视泡会阻止晶状体形成；后来的工作表明，来自其他组织的更早信号会先把外胚层部分特化，而且只有头部外胚层有感受性作出应答。诱导常常是一连串信号而非单独一个，而应答既取决于信号，也取决于应答者的感受性。

诱导信号有两种。**指令性**信号告诉应答者采取几种命运中的哪一种——不同的信号，或同一信号的不同浓度，给出不同的命运。**许可性**信号则让一个已经特化的应答者得以执行它的程序，许多细胞外基质和存活因子即是如此。许多诱导是**相互性**的：应答者反过来向诱导者发出信号，正如输尿管芽与生肾间充质相互诱导形成肾（[[developmental-biology/organogenesis]]）。

值得注意的是，动物界几乎所有诱导相互作用都使用一小族信号家族的成员，每一族都在 [[cell-biology/cell-signalling]] 中描述过：

| 家族 | 受体类型 | 发育中的例子 |
|---|---|---|
| 成纤维细胞生长因子（FGF） | 受体酪氨酸激酶 | 中胚层维持、肢的长出、后部身体的延伸 |
| TGF-β 超家族：BMP、Nodal、activin | 受体丝氨酸/苏氨酸激酶 → Smad | 背-腹模式化、中胚层与内胚层诱导、左-右不对称 |
| Wnt | Frizzled + LRP5/6 → β-catenin | 后部与背侧身份、节段极性、干细胞龛 |
| Hedgehog（脊椎动物中为 Sonic hedgehog） | Patched / Smoothened → Gli | 神经管与肢的模式化、节段极性 |
| Notch / Delta | 接触依赖；被切割的 Notch 充当转录调控因子 | 侧向抑制、边界、分节时钟 |
| 视黄酸 | 核受体 | 后脑与躯干的前-后模式化 |

少数几条通路如何能产生如此多样的结果？因为对信号的反应取决于应答的细胞：同一个 Wnt 信号，在已含有一组转录因子的细胞里与在含有另一组转录因子的细胞里，激活的是不同的增强子。用分子的话说，感受性主要就是细胞在信号到来之前所拥有的那套转录因子。

有些诱导还要求应答细胞的最少数目。戈登（1988）发现，少数几个 *Xenopus* 动物帽细胞贴着植物组织培养时不能形成肌肉，而一个较大的细胞团能够，因为应答的细胞还必须彼此发出信号，以加强它们的新状态——**群落效应**。

::: quiz
早期胚胎 R 区的细胞单独在简单盐溶液中培养时形成软骨，但移植到同期另一胚胎的成皮区域时形成皮肤。哪种描述符合 R 区？
- [ ] 已决定为软骨，但尚未特化
- [x] 已特化为软骨，但尚未决定
- [ ] 已分化为软骨
- [ ] 全能
::: solution
在中性培养基中分离培养检验的是特化：R 单独培养时遵循软骨命运，所以它已特化为软骨。移植检验的是决定：在成皮环境中它改变了命运，所以它没有决定。它不可能是分化了的（它仍能形成皮肤）；而「全能」描述的是一个细胞所能产生的细胞类型的范围，这个实验除两种命运外并没有测量这一点。
:::
:::

## 基因调控网络与稳定的细胞状态

信号作用一阵便停止，而被它改变的细胞可能做一百年神经元。短暂的信号如何变成持久的身份？答案在于转录因子的线路。

**基因调控网络**（GRN）是这样一个集合：细胞内相互调控对方基因的一组转录因子与信号输入，连同它们借此发挥作用的增强子。埃里克·戴维森及同事绘制了最完整的例子之一，即海胆胚胎中规定内胚层与中胚层的网络，一个增强子一个增强子地绘制。这类网络含有反复出现的线路，其中两种可以解释细胞记忆：

- **正自调控。**转录因子激活自身的基因。一旦其浓度越过阈值，在诱导信号离去之后它仍能维持自己。MyoD，骨骼肌的主调控因子，激活自身基因；其伙伴 Myf5与下游因子肌细胞生成素使之得到强化。哈罗德·温特劳布（Harold Weintraub）的组在1987年证明，在培养的成纤维细胞中强制表达 MyoD，就把它们变成了肌肉细胞。
- **相互抑制。**两种转录因子各规定一种备选命运，彼此抑制对方的基因。细胞最终一高一低；哪一方取胜取决于最初的微小偏向，例如来自一个信号的偏向。例子包括红细胞与髓系命运抉择中的 GATA1与 PU.1，以及小鼠内细胞团中的 Nanog 与 Gata6（[[developmental-biology/early-embryos]]）。

两种线路都给出具有多个稳定状态的体系——**双稳态**——它是沃丁顿山谷的分子对应物。我们可以在最简单的相互抑制模型中看到这一点。设 $x$ 与 $y$ 为两种抑制因子的浓度，各以最大速率 $a$ 产生，被对方以陡峭度为 $n$ 的 Hill 函数抑制，并被一阶降解清除。在降解速率常数与抑制阈值皆为1的单位下，

$$
\frac{dx}{dt} = \frac{a}{1 + y^n} - x, \qquad \frac{dy}{dt} = \frac{a}{1 + x^n} - y.
$$ {#eq-toggle}

这就是蒂莫西·加德纳（Timothy Gardner）、查尔斯·坎特（Charles Cantor）与詹姆斯·柯林斯（James Collins）2000年用大肠杆菌 *E. coli* 中两种细菌抑制蛋白构建的「遗传转换开关」；同样的方程也描述一对相互抑制的命运决定因子（另见 [[systems-biology/switches-oscillators]]）。

::: proposition 对称转换开关的双稳态 {#prop-toggle}
系统 [[#eq-toggle]] 总有一个对称稳态 $x = y = x^*$，其中 $x^*(1 + x^{*n}) = a$。这一稳态不稳定；当且仅当

$$
\frac{a\,n\,x^{*\,n-1}}{(1 + x^{*n})^2} > 1,
$$ {#eq-toggle-condition}

系统才恰好还有另外两个稳定的不对称稳态（一个 $x$ 高 $y$ 低，另一个相反）。也就是说，当对称点处相互抑制的斜率超过降解速率时。$n = 1$ 时条件从不满足；$n = 2$ 时，当 $a > 2$ 它成立。假设：两个基因在所有参数上完全相同，抑制由 Hill 函数描述，降解为一阶。
:::

::: proof
在对称稳态，$x = a/(1 + x^n)$，故 $x^*(1+x^{*n}) = a$；左边从0增至 $\infty$，所以这样的 $x^*$ 恰有一个。令 $r(u) = a/(1+u^n)$，则 $r'(u) = -a n u^{n-1}/(1+u^n)^2$。在 $(x^*, x^*)$ 处的雅可比矩阵为

$$
J = \begin{pmatrix} -1 & r'(x^*) \\ r'(x^*) & -1 \end{pmatrix},
$$

特征值为 $-1 \pm \lvert r'(x^*)\rvert$（见 [线性系统](/learn/maths/lesson.php?c=ode&l=linear-systems)）。特征值 $-1 + \lvert r'(x^*)\rvert$ 为正，所以对称态恰在 $\lvert r'(x^*)\rvert > 1$ 时是一个鞍点，此即 [[#eq-toggle-condition]]。轨线是有界的（每个解都进入区域 $0 \le x, y \le a$），而在鞍的稳定流形（对角线 $x = y$）两侧，它们必须趋近某个稳态：这就是那两个不对称稳态。$n=1$ 时，利用 $a = x^*(1+x^*)$，$\lvert r'(x^*)\rvert = a/(1+x^*)^2 = x^*/(1+x^*) < 1$。$n = 2$ 且 $a = 2$ 时，$x^* = 1$，$\lvert r'\rvert = 2\cdot2\cdot1/4 = 1$；由于 $\lvert r'(x^*)\rvert$ 随 $a$ 增大，条件对一切 $a > 2$ 成立。
:::

:::

::: example 转换开关的稳态 {#ex-toggle}
对 [[#eq-toggle]]，取 $a = 3$ 且 $n = 2$，精确求出所有稳态，并判断对称的那个是否稳定。
::: solution
稳态满足 $x(1 + y^2) = 3$ 与 $y(1 + x^2) = 3$。两式相减，

$$
x - y + xy(y - x) = (x - y)(1 - xy) = 0,
$$

所以或者 $x = y$，或者 $xy = 1$。

*对称态：* $x(1 + x^2) = 3$，数值求解得 $x^* = 1.213$。

*不对称态：* 由 $xy = 1$，第一个方程化为 $x + xy\cdot y = x + y = 3$。所以 $x$ 与 $y$ 是 $t^2 - 3t + 1 = 0$ 的两个根：

$$
t = \frac{3 \pm \sqrt5}{2} = 2.618 \ \text{ 或 } \ 0.382 .
$$

不对称稳态为 $(2.618, 0.382)$ 与 $(0.382, 2.618)$。

*对称态的稳定性：* $\lvert r'(x^*)\rvert = 3\cdot 2\cdot 1.213/(1 + 1.213^2)^2 = 7.28/6.11 = 1.19 > 1$，所以由 [[#prop-toggle]]，它是一个鞍点，特征值为 $-1 \pm 1.19$，即 $0.19$ 与 $-2.19$。$x$ 与 $y$ 之间的任何微小差别都会增长，细胞将委身于两个不对称状态之一，在其中一个状态中一种因子的丰度约为另一种的七倍。
:::
:::

一般的教训是**协同性加反馈制造决定**。一个短暂的信号把细胞推过两座山谷之间的山脊，就会被永远记住，因为网络把细胞保持在它的新状态中。染色质修饰，例如 Polycomb 介导的沉默基因的抑制和 DNA 甲基化（[[molecular-biology/eukaryotic-gene-regulation]]），加上第二层可以经许多次细胞分裂传递的记忆。

## 细胞谱系与细胞数目

谁是谁的后裔？一个**细胞谱系**是胚胎各细胞的家谱，在透明胚胎中它可以直接追踪，也可以通过标记一个细胞并记录后来哪些细胞带有标记来重建。

::: definition 细胞谱系与克隆 {#def-lineage}
一个细胞的**谱系**是它的祖先及其所有后裔的集合。**克隆**是单个细胞的全部后裔的集合。若每个个体中都出现同样的分裂模式、细胞命运和细胞死亡，则该谱系是**恒定的**。
:::

线虫 *Caenorhabditis elegans* 有一个几乎恒定的谱系，它是唯一整个谱系已知的动物。约翰·苏尔斯顿（John Sulston）与罗伯特·霍维茨（Robert Horvitz）在1977年追出了胚后分裂，苏尔斯顿、艾因哈德·席伦贝格（Einhard Schierenberg）、约翰·怀特（John White）与尼科尔·汤姆森（Nichol Thomson）在1983年追出了胚胎期分裂，方法是在 Nomarski 微分干涉显微镜下观察活的胚胎与幼虫。在雌雄同体中，共产生1090个体细胞，其中131个经程序性细胞死亡死去，成体有959个体细胞核。执行这些死亡的基因（*ced-3*、*ced-4*、*ced-9*）原来正是保守细胞凋亡机制的创始成员（[[cell-biology/tissues-and-cell-death]]）。

即便在这样一个精确的动物中，恒定的谱系也不意味着自主特化：*C. elegans* 胚胎的许多命运是由位置恒定的细胞之间的信号设定的。谱系告诉你谁与谁相关；它不告诉你一个细胞为什么做它做的事。

::: example 细胞数目与分裂次数 {#ex-cell-number}
(a) 一个成年人体约含 $3\times10^{13}$ 个人体细胞（Sender、Fuchs 与 Milo 2016年的估计，按数目以红细胞为主）。从一个合子产生这么多细胞，至少需要多少轮分裂？(b) 在 *C. elegans* 中，雌雄同体产生的体细胞有多大比例死去？
::: solution
(a) 在每细胞皆分裂的 $k$ 轮之后，有 $2^k$ 个细胞。需要 $2^k \ge 3\times10^{13}$：

$$
k \ge \log_2(3\times10^{13}) = \frac{\ln(3\times10^{13})}{\ln 2} = \frac{31.03}{0.693} = 44.8,
$$

所以至少45轮。实际上许多谱系的分裂次数远多于此，因为细胞终生都在死亡并被替换：每天约产生 $2\times10^{11}$ 个红细胞，所以造血的谱系在不断分裂，而一个老年个体结肠上皮中的细胞可能位于数千次分裂的末端。

(b) $131/1090 = 0.12$：约每八个产生的细胞就有一个死去。程序性细胞死亡是建造身体的正常部分，不是失败的标志。
:::
:::

## 发育生物学的模式生物

少数几个物种被极深入地研究，因为对它们的实验各自出于不同原因很容易，也因为它们揭示的机制在分子水平上于动物之间共享，另在植物之间共享。实验生物的选择永远是在遗传学（需要世代短、子代多）与胚胎学（需要大而易得的胚胎）之间做权衡。

| 生物 | 世代时间（约） | 优势 |
|---|---|---|
| 果蝇 *Drosophila melanogaster* | 25 °C 下10天 | 一个世纪的遗传学；大规模突变筛选；合胞体早期胚胎；成虫盘；制造突变细胞克隆的工具 |
| 线虫 *Caenorhabditis elegans* | 3–4天 | 透明；恒定、完全已知的谱系；遗传学与 RNA 干扰易于操作；959个体细胞 |
| 斑马鱼 *Danio rerio* | 3–4个月 | 透明的胚胎在数天内于母体外发育；脊椎动物遗传学筛选；活体成像 |
| 爪蟾 *Xenopus laevis* 与 *X. tropicalis* | 1–2年（*X. laevis*）；不足一年（*X. tropicalis*） | 每次产卵数千枚的大卵；显微注射与移植；无细胞卵提取物；*X. tropicalis* 是二倍体，适合遗传学 |
| 鸡 *Gallus gallus* | 约6个月 | 透过蛋壳开窗即可接触胚胎；移植与珠子植入；基因电穿孔 |
| 小鼠 *Mus musculus* | 2–3个月 | 哺乳类遗传学；基因打靶与转基因；胚胎干细胞；母体内的发育难以观察 |
| 海胆与被囊动物 | 数月至一年 | 透明的胚胎；经典实验胚胎学；基因调控网络 |
| 拟南芥 *Arabidopsis thaliana* | 6–8周 | 植物遗传学；小基因组；分生组织与花发育（[[developmental-biology/plant-development]]） |

它们之间的比较才是重点。在筛选幼虫角质层缺陷时发现的黑腹果蝇分节基因，引出了小鼠和人的 Hox 基因；*C. elegans* 的细胞死亡基因引出了哺乳类的细胞凋亡通路；蝾螈的组织者被一个分子一个分子地在 *Xenopus* 和小鼠中重新找到。模式生物并非专是人的模型；它们是一扇扇窗户，通向进化反复复用的机制。

关于脊椎动物胚胎的实验受法规约束。在欧洲联盟、英国和许多其他司法辖区，受保护动物包括脊椎动物的较晚发育阶段（例如妊娠最后三分之一的哺乳类胎儿和能独立摄食的幼体），研究必须获得许可，并遵循威廉·拉塞尔（William Russell）与雷克斯·伯奇（Rex Burch）1959年提出的**替代、减少、优化**（「3R」）原则。对人类胚胎的研究另有更严格的规定，这一话题在 [[developmental-biology/stem-cells-regeneration]] 中有所触及。

::: application 发育与医学
约2–3%的人类出生受一种重大先天异常的影响（估计随人群和所用定义而异），其中许多由本课程所述信号通路和转录因子的突变引起，或由在发育的敏感窗口干扰它们的环境因子所致。对发育的机制性理解也是用干细胞培养替换细胞与组织等工作的基础。这些话题的临床方面属于医学图谱（[医学图谱](/learn/medicine/)）；我们在这里研究的是机制。
:::

::: history
对发育的研究源远流长——亚里士多德连续数日逐一打开母鸡的卵，描述了跳动的心脏——但十七、十八世纪的中心争论是在**预成论**与**后成论**之间：前者认为卵或精子中已存在一个微缩的生物、不过放大而已，后者认为形态由无定形的材料逐渐产生。卡斯帕·弗里德里希·沃尔夫（Caspar Friedrich Wolff）1759年对鸡胚的观察与卡尔·恩斯特·冯·倍尔（Karl Ernst von Baer）1827年哺乳类卵的发现连同他的比较胚胎学，都有利于后成论。实验胚胎学（Entwicklungsmechanik）始于威廉·鲁（Wilhelm Roux），他1888年用热针杀死两细胞蛙胚的一个细胞，得到半个胚胎；还有汉斯·德赖希（Hans Driesch），他1891年把海胆胚最初两个细胞摇散分开，发现每个都能形成完整的幼虫——这是对调整性的首次证明。鲁实验中死去的细胞仍附着在原处并影响着邻居；若蛙卵裂球被完全分开，且分裂面把卵的背侧决定因子一劈为二，则每个都能形成完整的胚胎。汉斯·施佩曼1910与1920年代的移植实验确立了诱导；以胚胎学家起家的托马斯·亨特·摩尔根（Thomas Hunt Morgan）创建了黑腹果蝇遗传学，到1970与1980年代，它最终鉴定出了发育所使用的那些基因。
:::

::: summary
- 发育包括分化、模式形成、形态发生、生长、生殖系与组织的更新，以及进化改变。
- 体细胞在基因组上是等价的（有 V(D)J 重组与染色质减缩等例外）；蛙（1952、1962）与绵羊（1996）的核移植表明，已分化的核保有其全部基因。细胞类型之间的差别在于差异基因表达。
- 命运图谱记录细胞通常成为什么。细胞在分离后仍循其命运发育即为特化，在移植后仍如此即为决定，成为特化细胞类型即为分化。
- 特化可以是自主的（如海鞘 *macho-1* mRNA 这样的细胞质决定因子）、条件的（来自邻居的信号）或合胞体的；镶嵌型与调整性胚胎位于一个光谱的两端。
- 潜能从全能经多能、多潜能收窄到单能；沃丁顿的景观把细胞命运描绘为山脊分隔的山谷。
- 诱导需要诱导者与有感受性的应答者；少数几个信号家族（FGF、TGF-β/BMP/Nodal、Wnt、Hedgehog、Notch、视黄酸）中介了几乎所有诱导，而感受性主要是先存的转录因子组合。
- 正自调控与相互抑制使细胞状态双稳；转换开关 $\dot x = a/(1+y^n) - x$，$\dot y = a/(1+x^n) - y$ 只有协同抑制时才双稳（$n > 1$，$n = 2$ 时需 $a > 2$）。
- 模式生物——*Drosophila*、*C. elegans*、斑马鱼、*Xenopus*、鸡、小鼠、拟南芥——在遗传学与胚胎学之间权衡，并揭示动物间或植物间共享的机制。
:::

## 习题

::: exercise 定向的词汇 {level=1}
就下列每一项陈述，说出定向的状态（特化、决定、分化），或者说信息不足。(a) 一个神经嵴细胞已迁入皮肤并正在制造黑色素。(b) 一块移植到腿芽上的鸡肢芽仍形成翅的结构。(c) 命运图谱显示一群细胞通常成为脊索。
::: solution
(a) 分化：它正在制造一种特化细胞类型（黑色素细胞）的产物。(b) 决定：它在陌生环境中保持翅的身份（未必已分化）。(c) 信息不足：命运图谱只记录正常发育，对特化或决定未置一词——那需要分离或移植实验。
:::
:::

要把一个细胞变成4096个细胞，需要几轮同步细胞分裂？
::: solution
$4096 = 2^{12}$，所以12轮。（在 *Xenopus* 中，前12次卵裂几乎同步；见 [[developmental-biology/early-embryos]]。）
:::

::: exercise 潜能 {level=1}
将下列细胞按潜能从大到小排序，并各用一句话说明它与下一位的区别：造血干细胞；小鼠合子；小鼠胚泡内细胞团的一个细胞；精原干细胞。

合子（全能：形成整个胚胎和胎盘）＞内细胞团细胞（多能：胚胎的每一种细胞类型，包括生殖系，但不包括滋养层）＞造血干细胞（多潜：所有血液细胞类型，但不包括其他组织）＞精原干细胞（正常生活中单能：只产生精子）。

::: exercise 克隆成功的机会 {level=2 check="0.0618"}
若在核移植实验中每枚重建卵都有独立的1%机会产生一只活体动物，那么277枚卵一只活体动物也没有的概率是多少（三位有效数字）？
::: solution
$(1 - 0.01)^{277} = e^{277\ln 0.99} = e^{-2.784} = 0.0618$。所以即使真实成功率为1%，这种规模的实验仍有近94%至少得到一只动物；277枚中1次成功并不能把成功率钉死。
:::

::: exercise 分离与移植 {level=2}
在两栖类胚胎的 P 区于三个时期接受检验。时期1：分离的 P 在盐溶液中只形成表皮，移植到背侧中胚层形成区则形成中胚层。时期2：分离的 P 形成肌肉，移植到腹侧表皮区则形成表皮。时期3：分离的 P 形成肌肉，移植到腹侧表皮区仍形成肌肉。描述 P 在各个时期的定向状态，并说明时期1与2之间一定发生了什么。
::: solution
时期1：P 尚未特化为肌肉（单独培养形成表皮，一种默认命运），也未决定（它会对中胚层形成环境作出反应）。时期2：P 已特化为肌肉（分离培养形成肌肉），但未决定（在新环境中它改变命运）。时期3：P 已决定为肌肉。在时期1与2之间，P 一定接收了一个诱导信号——很可能来自它在胚胎中紧邻的组织——使它特化为肌肉；在时期2与3之间，这一特化被稳定下来，例如通过其基因调控网络中的正反馈或群落效应。
:::

::: exercise 转换开关的临界强度 {level=2 check="1.19"}
对 Hill 系数 $n = 3$ 的转换开关 [[#eq-toggle]]，求使系统双稳的最小最大合成速率 $a$（三位有效数字）。*提示：*在临界点，对称稳态同时满足 $x(1+x^n) = a$ 与取等号的 [[#eq-toggle-condition]]。
::: hint
把 $a = x(1 + x^n)$ 代入稳定性条件，此时条件只含 $x$。
:::
::: solution
以 $a = x(1+x^n)$，条件 $a n x^{n-1}/(1+x^n)^2 = 1$ 化为

$$
\frac{n x^n}{1 + x^n} = 1 \quad\Longrightarrow\quad x^n = \frac{1}{n-1}.
$$

$n = 3$ 时，$x^3 = 1/2$，$x = 0.794$，且 $a = x(1 + x^3) = 0.794\times1.5 = 1.19$。一般地 $a_\mathrm{crit} = \dfrac{n}{n-1}(n-1)^{-1/n}$，$n = 2$ 时给出2，且随 $n$ 增大趋于1：抑制越陡，双稳越易达到。
:::

::: exercise 重访鲁与德赖希 {level=3}
鲁的半胚（1888）与德赖希的完整个体幼虫（1891）在当时被当作两条相反原则的证据。(a) 解释为什么鲁的结果并不能说明蛙胚是镶嵌型的。(b) 请设计一个用分开的蛙卵裂球的实验，检验卵的背侧是否含有形成完整个体所必需的决定因子。你会预言什么结果？
::: solution
(a) 在鲁的实验中，被杀死的卵裂球仍留在原位。活着的细胞仍「看见」一个邻居，并发育成它本会形成的那半个；它从未被单独检验，所以其调整潜能无从显露。镶嵌式的解释要求分离的卵裂球只能形成一部分，而鲁没有检验这一点。

(b) 在能把第一次分裂面相对于未来背侧（灰新月，或与未来背侧相对的精子入卵点）作出判断的胚胎中，于2-细胞期把两个卵裂球完全分开。预言：若第一次分裂面把背侧区域分给两个细胞，则每个分离的卵裂球都形成一个完整的、较小的胚胎；若分裂面把背侧一半与腹侧一半分开，则只有背侧细胞形成完整胚胎，腹侧那个形成一团没有轴性结构的腹化细胞团（一块「腹部块」）。这正是施佩曼用毛发套环缢缩蝾螈卵所观察到的，它同时显示了调整性与背侧决定因子的存在（[[developmental-biology/axis-formation]]）。
:::

::: exercise 解读一个核移植系列 {level=3}
在一个假设的蛙核移植系列中，重建卵形成游泳蝌蚪的百分比为：囊胚核35%，原肠胚核20%，尾芽期内胚层核6%，蝌蚪肠核1.5%。(a) 这一递减是否表明细胞分化时基因丢失了？(b) 给出两个与基因组等价相容的对递减的解释，并提出了一个可以区分它们的观察。
::: solution
(a) 不是。基因组等价预言*某些*来自每个阶段的核都能支持发育，而这正是数据所示：连肠核都有1.5%的成功，意味着那些核含有所需的全部基因。效率的递减并不显示基因丢失，因为一次成功就是保留的证据，而失败可以有许多原因。

(b) (1)**稳定的表观遗传记忆**：已分化的核带有染色质状态（抑制性组蛋白标记、DNA 甲基化、结合的转录因子），卵细胞质无法在胚胎必须启动自身基因组之前的几个短细胞周期内将其擦除；越老、越分化的核，这样的记忆越多。(2)**技术与细胞周期损伤**：分裂缓慢的已分化细胞的核被迫进入卵那极快的卵裂周期，遭受染色体断裂或 DNA 复制不完全。要区分二者，检查失败的胚胎：若 (2) 重要，它们应显示染色体异常（滞后染色体、断裂）；若 (1) 重要，它们的染色体应正常，但持续表达供体细胞的基因（例如肠标记），并未能激活胚胎基因。两种解释都有实验支持。
:::
