卵裂末期，胚胎是一个细胞构成的球或盘，内部几乎没有什么组织：将形成肠的细胞在外面，将形成脑的细胞与它们相邻。在接下来的几个小时里，这一切彻底改变。细胞层向内折叠，单个细胞脱落并爬入内部，表面铺展开来包被整个胚胎，组织变窄并伸长。当这一切结束时，胚胎有了三层——外面的**外胚层**、衬在原始肠腔内侧的**内胚层**，以及介于两者之间的**中胚层**——还有了一条这些层次沿之排列的体轴。这场改组就是**原肠形成**。「真正你一生中最紧要的时刻，不是出生、结婚或死亡，而是原肠形成。」刘易斯·沃尔帕特（Lewis Wolpert）在1986年这样写道，而玩笑之中有一层认真的意思：原肠形成把细胞安置到将要指导它们的邻居身旁，几乎此后每一次诱导都依赖它。

本章有两个部分。第一部分讲力学：构成全部原肠形成的那一小组细胞行为，以及它们在四类胚胎中如何组合。第二部分讲信号：**组织者**——1924年通过移植实验发现的——以及最终把组织者解释清楚的分子，它们后来被证明主要以*阻断*其他信号的方式起作用。我们建立在 [[developmental-biology/axis-formation]] 的轴与 [[developmental-biology/early-embryos]] 的囊胚之上。

## 胚层

::: definition 胚层 {#def-germ-layers}
**胚层**是原肠形成时在三胚层动物中建立的三个原始组织层。
- **外胚层**，外层，形成表皮及其衍生物（毛、羽毛、指甲、皮肤腺）、神经系统，以及在脊椎动物中，神经嵴和感觉器官的外胚层基板。
- **中胚层**，中层，形成脊索、肌肉、骨骼、真皮、心脏和血管、血液、肾和生殖腺（生殖细胞除外），以及肠的结缔组织。
- **内胚层**，内层，形成肠管道及其突出物的上皮衬里：肝、胰、肺、甲状腺和膀胱的上皮。
:::

刺胞动物（海葵、水母）和栉水母传统上被称为**二胚层**，只有外胚层和内胚层，而其他动物是**三胚层**的。物质由此移入胚胎内部的开口是**胚孔**。在**原口动物**（如昆虫、软体动物和环节动物）中，它通常参与形成口；在**后口动物**（棘皮动物、脊索动物）中，它成为肛门，口另行形成——不过跨物种的界限并不像经典定义所说的那样分明。

胚层是对组织来源的一种描述，而不是一条「每个器官只来自一层」的规则。多数器官都组合了两到三层的组织：肠有内胚层的衬里、中胚层的肌肉，以及来自神经嵴（外胚层）的肠神经系统。

::: warning 「每个胚层从一开始就有一固定的命运集」
胚层是原肠形成的产物；它们不是边界封闭的区室。起源于外胚层的脊椎动物**神经嵴**细胞形成面部的骨和软骨——本属中胚层典型的组织——这就是神经嵴有时被称为第四胚层的原因。在尾芽中，单个**神经外胚层-中胚层前体细胞**在原肠形成早已建出身体其余部分很久之后，仍同时产生脊髓（外胚层）和体节（中胚层）。而且在细胞移动并受到诱导之前，它们的命运取决于信号（[[developmental-biology/principles-of-development#ex-spemann-1918]]）。胚层身份是由信号和转录因子设定的一种状态，与其他状态一样，它可以被重编程。
:::

## 原肠形成的细胞行为

不同动物的原肠形成看起来多么不同，它都由为数不多的几类细胞行为构建而成。

::: definition 原肠形成的运动 {#def-movements}
- **内陷（invagination）**：上皮层的一个区域向内塌陷，如同一根手指按入软球。
- **内卷（involution）**：扩展中的外层翻过一个边缘，沿剩余外层细胞的内表面铺展开来。
- **内移（ingression）**：单个细胞离开上皮层，作为游离细胞迁入内部。
- **分层（delamination）**：一层裂成两层大致平行的层。
- **外包（epiboly）**：上皮层铺展——通常经由变薄——包被更深层或卵黄。
- **汇聚延伸（convergent extension）**：一个组织沿一个轴变窄、沿垂直轴伸长，通过细胞彼此插入实现。
:::

这些现象大多由两种细胞机制支撑。在**顶端收缩（apical constriction）**中，上皮细胞顶面一张由肌动蛋白和非肌型肌球蛋白 II 构成的收缩网络缩小其顶面面积，把柱状细胞变成楔形；一圈楔形细胞使细胞层弯曲。在**上皮-间质转化**（EMT）中，上皮细胞失去黏附（主要由 Snail 家族转录因子抑制 E-cadherin 实现）、失去顶-基底极性，变为可迁移的间质细胞；内移就是 EMT。这两种机制在器官发生中、不幸地也在癌细胞侵袭组织时再次出现。

::: proposition 用楔形细胞弯曲细胞层 {#prop-wedge}
考虑一层高度为 $h$ 的上皮，每个细胞顶宽为 $a$、基宽为 $b > a$，细胞的侧面呈放射状。于是这些细胞铺成一个圆弧：每个细胞张开的角度为

$$
\theta = \frac{b - a}{h},
$$

顶面的曲率半径为

$$
R = \frac{a\,h}{b - a}.
$$ {#eq-wedge}

一根顶面朝内的闭合管道，其周圈需要 $2\pi/\theta = 2\pi h/(b-a)$ 个这样的细胞。假设：细胞全同、侧面为直的放射面、细胞层可以自由弯曲（不被邻近组织牵制）。真实的内陷还取决于来自周围组织的力，所以这一公式给出的是尺度，而非形状的预言。
:::

::: proof
若一个细胞的顶面是半径为 $R$、张角为 $\theta$ 的弧，其长度为 $a = R\theta$。基底面在其外侧 $h$ 处，长度为 $b = (R + h)\theta$。两式相减得 $b - a = h\theta$，故 $\theta = (b-a)/h$，且 $R = a/\theta = ah/(b-a)$。一个整圆需要 $2\pi/\theta$ 个细胞。
:::

::: example 楔形细胞折叠细胞层 {#ex-wedge}
高20 µm、宽8 µm 的柱状上皮细胞把顶面收缩到2 µm，而保持基宽不变。(a) 每个细胞张开多大角度？顶面的曲率半径是多大？(b) 多少个这样的细胞能围成一根闭合管道？(c) 若收缩不那么剧烈，顶宽为6 µm，答案如何改变？
::: solution
(a) $\theta = (8 - 2)/20 = 0.30$ 弧度（17°）；由 [[#eq-wedge]]，$R = 2\times20/6 = 6.7$ µm。

(b) $2\pi/0.30 = 21$ 个细胞。

(c) $\theta = (8-6)/20 = 0.10$ 弧度，$R = 6\times20/2 = 60$ µm，闭合管道需要63个细胞。局限于窄带内的适度收缩只产生一条浅沟；深而窄的折叠需要对一列细胞的强烈收缩。*Drosophila* 腹沟的细胞强烈地、以脉冲方式收缩其顶面，一级一级棘轮式地收紧（亚当·马丁（Adam Martin）、马蒂亚斯·卡舒贝（Matthias Kaschube）与埃里克·维绍斯（Eric Wieschaus），2009）；它们还沿顶-基底轴缩短，这有助于把沟推入内部。
:::
:::

::: proposition 汇聚延伸保持面积不变 {#prop-ce}
若一个厚度恒定、体积恒定的组织从宽度 $w_0$ 变窄到宽度 $w$，它就从 $L_0$ 伸长到

$$
L = L_0\,\frac{w_0}{w}.
$$

当细胞保持形状时，横向穿过组织的细胞数按 $w/w_0$ 减少，沿向的细胞数按 $w_0/w$ 增多：细胞在变窄轴的方位上跨邻居**间插**（intercalate）。
:::

汇聚延伸由雷·凯勒（Ray Keller）及其同事在 *Xenopus* 背侧中胚层外植体中分析得最为透彻：细胞沿中-外侧方向变长，在其内侧端和外侧端伸出伪足，彼此爬入，于是组织即便被切离胚胎也会变窄伸长。细胞的极化依赖于**平面细胞极性**通路——Wnt 信号的一个分支，经 Dishevelled 和跨膜蛋白 Van Gogh-like 与 Frizzled 起作用——它在组织的平面内而非沿其顶-基底轴定向细胞。在 *Drosophila* 的胚带中（其在原肠形成期间长度增加不止一倍），间插则由上皮细胞间连接的重塑实现（肯尼思·欧文（Kenneth Irvine）与埃里克·维绍斯，1994；詹妮弗·扎伦（Jennifer Zallen）及其同事后来）。

::: example 脊索的汇聚延伸 {#ex-ce}
一条背侧中胚带宽200 µm、长100 µm，细胞约10 µm 直径。在原肠形成和神经胚形成期间它变窄到50 µm。(a) 假设厚度与体积恒定，它变多长？(b) 之前横向有多少个细胞、之后有多少？纵向有多少个细胞？
::: solution
(a) 由 [[#prop-ce]]，$L = 100\times200/50 = 400$ µm：伸长了四倍。

(b) 之前：横向20个细胞，纵向10个。之后：横向5个，纵向40个。细胞必定相互穿插了，大约横向每四个细胞就有一个改得沿纵向排在别人身后。在 *Xenopus* 脊索中终点极为典型：细胞最终像硬币一样叠起来，横向只有一个细胞。这里的数字是示例性的，但它们表明中-外侧间插如何在没有生长或细胞分裂的情况下产生大幅伸长。
:::
:::

## 四种胚胎的原肠形成

### 海胆

海胆的原肠形成最容易观察，因为胚胎透明，其囊胚只有一层细胞。它按清晰的阶段进行：

1. **初级间充质的内移。**植物极小裂球的后裔经历 EMT，失去与邻居和透明层的接触，进入囊胚腔。它们沿内壁迁移，在植物区定居成环，形成钙质的幼虫骨骼。
2. **内陷。**植物板变平并向内塌陷，形成一段短管——**原肠**（原始肠），其延伸约达囊胚腔的四分之一到三分之一。
3. **延伸。**原肠经其细胞的汇聚延伸而伸长。在其顶端，**次级间充质**细胞向动物半球的内表面伸出长长的丝状伪足，附着并收缩，把肠拉过去。杰夫·哈丁（Jeff Hardin）在1988年证明，用激光杀死这些细胞会使原肠停在不足全长之处。
4. **汇合。**原肠顶端与将形成口处的外胚层相遇，口在那里打开；胚孔成为肛门——后口动物的界定特征。

### *Xenopus*

两栖类的原肠形成始于**胚孔背唇**，位于精子入卵的对侧、赤道略偏下方。这里的**瓶形细胞**收缩顶面，形成一条缝。边缘区——动物区与植物区之间的赤道带——的细胞随后**内卷**：它们翻过背唇并向内迁移，沿囊胚腔顶的内表面行进，其表面覆有纤连蛋白。最先内卷的细胞成为咽内胚层和头部中胚层（**前脊索板**）；较晚的成为**脊索**，再后是体节和侧板中胚层。背唇向两侧和腹面扩展，直到绕含卵黄的植物细胞成一圈（**卵黄栓**），后者逐渐被包入。与此同时，动物帽经**外包**铺展——深细胞径向间插使其变薄——作为外胚层覆盖整个胚胎；内卷的背侧中胚层则经历**汇聚延伸**，使胚胎伸长。被内卷内胚层围起来的腔是原肠，囊胚腔则被挤没。

### 鸡

鸡的原肠形成发生在位于卵黄之上的一个扁平盘——上胚层——内，其下方为一层下胚层。一处增厚——**原条**——在后缘形成并沿中线向前延伸，其间上胚层发生大范围的「波罗乃兹」式运动。在其前端形成一结细胞——**亨森结（Hensen's node）**。上胚层细胞向原条移动，经历 EMT 并从其**内移**。最先通过的细胞取代下胚层，形成胚胎内胚层；后来的细胞在上胚层与内胚层之间铺展，成为中胚层。经亨森结内移的细胞形成前脊索板和脊索。随后结向后方**退行**，在其身后铺出脊索，而头部在其前方形成：鸡和所有其他脊椎动物一样，是从头到尾建成的。留在表面的上胚层细胞形成外胚层。

小鼠胚胎经同样的原条和结原肠形成，只不过是在其杯状卵柱的表面；人胚则在扁平盘上原肠形成，与鸡十分相似。

### *Drosophila*

在 *Drosophila* 中，原肠形成于受精后约3小时（25 °C）沿腹侧中线开始。一条约18个细胞宽的细胞带——表达 Dorsal 靶基因 *twist* 与 *snail* 的那些细胞——顶端收缩并内陷，形成**腹沟**；这些细胞随后经历 EMT，在外胚层之下铺展为中胚层。内胚层在前后两端内陷。随后，**胚带**——将形成分节身体的腹侧和侧外胚层——经汇聚延伸伸长，并包绕到卵的后端。

- [x] 内移，发生在上皮-间质转化之后

到达原条的上胚层细胞失去 E-cadherin 依赖的连接（在 Snail 家族转录因子的控制之下），作为单个间质细胞脱落，向下方的间隙迁移：这就是经 EMT 的内移。内陷移动一整张完整的层；外包把一层铺过表面；分层把一层裂成两层。

## 组织者

### 施佩曼与曼戈尔德

1924年，汉斯·施佩曼（Hans Spemann）与其研究生希尔德·曼戈尔德（Hilde Mangold）发表了一项移植实验，它成为胚胎学史上最著名的实验。使用蝾螈，曼戈尔德从一个无色素物种早期原肠胚的胚孔背唇切下一块，移植到一个有色素物种原肠胚的对侧——腹面。宿主发育出第二条身体轴，有时几乎是完整的第二个胚胎，与第一个腹腹相接。得益于色素的差异，每种组织的来源都能被追溯：移植的细胞大多形成脊索，而次级神经管和体节大多由宿主细胞形成——那些听之任之本会变成腹侧表皮和腹部中胚层的细胞。

::: definition 组织者 {#def-organiser}
**组织者**是早期原肠胚中一个区域——在两栖类即胚孔背唇——移植到另一胚胎的腹面时能诱导出一整条次级身体轴。它(1)自己形成前脊索板和脊索；(2)使邻近中胚层**背化**，诱导其形成体节而非腹侧中胚层；(3)诱导其上覆盖的外胚层形成神经系统（**神经诱导**）；(4)启动原肠形成的运动。对等的组织者是鸡的**亨森结**、小鼠的**结**和斑马鱼胚胎的**背胚鞘（shield）**。
:::

::: example 解读施佩曼-曼戈尔德移植 {#ex-organiser-graft}
在一道由背唇移植产生的次级轴中，脊索全部由无色素（供体）细胞构成，体节由无色素与有色素细胞混合构成，而神经管几乎全部由有色素（宿主）细胞构成。每一项观察各告诉你什么？
::: solution
脊索由移植物自己建成：组织者依自身被决定的命运**自我分化**，正如被决定的组织会做的那样。混杂的体节表明移植物招募了本会变成血液和外侧组织的宿主腹侧中胚层，使其形成背侧体节中胚层——背化。宿主来源的神经管表明宿主腹侧外胚层——本会变成腹部表皮——被诱导成为神经系统——神经诱导。因此该实验表明移植物组织化（organise）其邻居，而非简单地亲自建造这条轴，这就是施佩曼称其为组织者的原因。（曼戈尔德于1924年论文发表前去世；施佩曼获1935年诺贝尔生理学或医学奖。）
:::
:::

### 组织者分泌什么

组织者背后的分子有六十年时间一直未被认出。它们在1990年代初主要于 *Xenopus* 中被找到，方法是从在背唇中表达的基因、以及能使经紫外线腹化的胚胎恢复出一条轴的 mRNA 中进行筛选（[[developmental-biology/axis-formation#ex-uv]]）。组织者表达 **Goosecoid**（Ken Cho、爱德华·德罗伯特伊斯（Edward De Robertis）及同事，1991）之类的转录因子——把它的 mRNA 注射到腹侧即可诱导出次级轴——并且它分泌一套蛋白质，令人惊讶的是，它们几乎全都是其他信号的**拮抗剂**：

- **Noggin**（威廉·史密斯（William Smith）与理查德·哈兰（Richard Harland），1992）、**Chordin**（笹井芳树（Yoshiki Sasai）、德罗伯特伊斯及同事，1994）和 **Follistatin** 结合 BMP 蛋白，尤其是 BMP4，阻止它们激活自己的受体。
- **Cerberus**、**Dickkopf** 与 **Frzb** 抑制 Wnt 信号，而 Cerberus 还阻断 Nodal 和 BMP；形成头部需要在前部存在这些分子。

### 神经诱导与默认模型

在原肠胚的腹侧，BMP4在外胚层和中胚层各处表达。BMP4的信号指示外胚层成为表皮、中胚层采取腹侧命运（血液、侧板）。组织者通过分泌 BMP 拮抗剂保护背侧外胚层不受 BMP 作用，从而使其得以成为神经组织。

对此最有力的支持来自外胚层动物帽的实验。完整的动物帽单独培养形成表皮。但若把它的细胞分散开、彼此隔开保持几个小时，使它们分泌的 BMP 扩散掉，它们便形成神经组织（希尔德加德·格伦茨（Hildegard Grunz）与洛塔尔·塔克（Lothar Tacke），1989，以及其他人）。阿里·埃马蒂-布里瓦努（Ali Hemmati-Brivanlou）与道格拉斯·梅尔顿（Douglas Melton）于1994年证明，表达显性负性受体（阻断 activin 及相关配体的信号）的动物帽，没有任何组织者就变得成神经组织。这些结果导向**默认模型**：外胚层除非收到 BMP 信号就成为神经组织，而神经诱导在于*去除*一个抑制性信号。在鸡和小鼠中，FGF 信号及其作用时机也是必需的，所以默认模型如今被视为这一故事的重要部分，而非全部。

::: intuition 通过减法下达指令
组织者并不是把「神经」画到外胚层上；它使外胚层免受一个写着「表皮」的信号的作用。由于拮抗剂自组织者向外扩散，而 BMP 到处都在产生，结果是 BMP **活性**的梯度——背侧低、腹侧高——尽管 BMP mRNA 本身相当均匀。细胞读取这一活性梯度：低给出神经板，中等在其边缘给出神经嵴与外胚层基板，高给出表皮；在中胚层，低给出体节，较高给出间介中胚层，最高给出侧板和血液。同样的逻辑——BMP 与来自对侧的拮抗剂——为果蝇的背-腹轴提供模式，用的是 Dpp 和 Sog（[[developmental-biology/axis-formation]]），只是上下颠倒：蝇的神经索在腹侧，脊椎动物的在背侧。
:::

### 中胚层诱导与 activin 实验

中胚层本身在原肠形成之前由植物细胞诱导（纽维科普实验，[[developmental-biology/axis-formation]]）。在 *Xenopus* 中，植物转录因子 VegT 激活 **Nodal 相关**蛋白的基因——它们是 TGF-β 家族的配体，经 Smad2/3向边缘区发信号。高水平的 Nodal 信号（在 β-catenin 也发挥作用的背侧）诱导出组织者和背侧中胚层；较低水平诱导腹侧和外侧中胚层。

activin——一种经 Nodal 的同种受体起作用的 TGF-β 家族蛋白——给出了一个干净的证明：单个分子在不同浓度可以规定不同的命运。杰里米·格林（Jeremy Green）与吉姆·史密斯（Jim Smith）（1990）将分散的动物帽细胞暴露于不同浓度的 activin，发现低浓度激活腹侧中胚层的基因和泛中胚层基因 *Brachyury*（*Xbra*），而较高浓度激活 *goosecoid* 等背侧基因。史蒂文·戴森（Steven Dyson）与约翰·戈登（John Gurdon）（1998）走得更远，估计细胞响应的是被占据受体的绝对数目：每个细胞约100个被占据的受体（总数约5000个）对应 *Xbra*，约300个对应 *goosecoid*——受体占据的三倍之差分隔开两种命运。

::: example 从受体占据到浓度 {#ex-activin}
一个细胞有5000个 activin 受体，以解离常数 $K_\mathrm{d}$ 结合 activin。由 [[cell-biology/cell-signalling]] 的占据方程，$\theta = [\mathrm{L}]/(K_\mathrm{d} + [\mathrm{L}])$。(a) 当100个和300个受体被占据时，占据的分数是多少？(b) 以 $K_\mathrm{d}$ 为单位，这些占据度对应的 activin 浓度是多少？(c) 若 $K_\mathrm{d}$ 为1 nM（示例值），分隔 *Xbra* 与 *goosecoid* 应答的浓度是多少？
::: solution
(a) $100/5000 = 0.02$ 和 $300/5000 = 0.06$。

(b) 解出 $[\mathrm{L}]$：$[\mathrm{L}] = K_\mathrm{d}\,\theta/(1-\theta)$。$\theta = 0.02$ 时 $[\mathrm{L}] = 0.0204\,K_\mathrm{d}$；$\theta = 0.06$ 时 $[\mathrm{L}] = 0.0638\,K_\mathrm{d}$。

(c) 约20 pM 和64 pM：比为3.1。在如此低的占据度下，被占据受体的数目几乎与浓度成正比，所以浓度上的三倍台阶给出信号上的三倍台阶。细胞读取的是百分之几的占据度，远低于饱和，因此它们为更高的阈值留出了充足的动态范围。
:::
:::

::: application 类原肠胚与早期发育的干细胞模型
几百个小鼠胚胎干细胞的聚集体，在短暂暴露于 Wnt 通路激活剂后，会打破对称、伸长，并按有序的前-后序列表达三个胚层的基因；这些**类原肠胚（gastruloids）**（苏珊娜·范登布林克（Susanne van den Brink）、马丁内斯-阿里亚斯及同事，2014）以及由人类干细胞构建的类似模型，让研究者在培养皿中研究类似原肠形成的过程，并使用难以施于胚胎的遗传学与成像工具。它们缺少真实胚胎的许多特征（大多没有脑和胚外组织）。由于用人类细胞构建的模型引发伦理问题，它们的使用受人类干细胞研究相关法规与指南的约束，例如国际干细胞研究学会的指南。
:::

::: history
恩斯特·海克尔（Ernst Haeckel）于1872年创造了原肠胚（*gastrula*）一词，并提出所有动物都源自一个两层式的祖先——「原肠虫」（gastraea）。克里斯蒂安·潘德（Christian Pander）于1817年描述了鸡的三个胚层，卡尔·恩斯特·冯·倍尔（Karl Ernst von Baer）于1828年把这一概念推广到其他脊椎动物。瓦尔特·福格特（Walther Vogt）的两栖类原肠胚活体染料命运图谱（1925–29）显示了每种组织的来处。施佩曼与曼戈尔德的组织者论文发表于1924年；约翰内斯·霍尔茨弗里特（Johannes Holtfreter）1930年代的实验表明，即便是致死的组织者组织也能诱导，由此开始了针对诱导物质漫长的搜寻。分子意义上的组织者在1991–94年间随 Goosecoid、Noggin、Chordin 与 Follistatin 而被揭示，默认模型于1994年提出。雷·凯勒自1980年代起的外植体研究确立了汇聚延伸作为脊椎动物原肠形成驱动力的地位。
:::

::: summary
- 原肠形成把囊胚转变为三层式胚胎——外胚层、中胚层、内胚层——并把组织安置到将要诱导它们的邻居身旁。
- 它由内陷、内卷、内移、分层、外包和汇聚延伸构建，动力来自顶端收缩、上皮-间质转化和细胞间插。
- 高 $h$、顶宽 $a$、基宽 $b$ 的楔形细胞把细胞层弯到半径 $R = ah/(b-a)$；汇聚延伸保持面积不变，故 $L = L_0w_0/w$。
- 海胆经初级间充质内移与原肠内陷而原肠形成；蛙经胚孔唇内卷、外包和汇聚延伸；鸡和哺乳类经原条内移；果蝇经腹沟内陷与胚带伸展。
- 组织者（背唇；亨森结；结；背胚鞘）自我分化为脊索，使中胚层背化，诱导神经系统，并驱动原肠形成（施佩曼与曼戈尔德，1924）。
- 组织者蛋白大多是拮抗剂：Noggin、Chordin 与 Follistatin 结合 BMP；Cerberus、Dickkopf 与 Frzb 阻断 Wnt。摆脱 BMP 的外胚层成为神经组织（默认模型），产生一个为外胚层和中胚层提供模式的 BMP 活性梯度。
- Nodal 相关信号诱导中胚层；activin 实验表明受体占据的几倍变化（约100对300个受体）即可在命运之间做出选择。
:::

::: exercise 胚层来源 {level=1}
说出脊椎动物中下列结构各自由哪个胚层形成：(a) 眼的晶状体；(b) 肺的衬里；(c) 心肌；(d) 面骨；(e) 脊索；(f) 肝的上皮。
::: solution
(a) 外胚层（头部外胚层的一个基板）。(b) 内胚层。(c) 中胚层。(d) 外胚层，经神经嵴。(e) 中胚层（轴中胚层，来自组织者）。(f) 内胚层。
:::

::: exercise 说出运动 {level=1}
说出所描述的原肠形成运动：(a) 上皮变薄并铺过斑马鱼胚胎的卵黄；(b) 海胆植物极的细胞逐个离开上皮进入囊胚腔；(c) 一圈组织翻过胚孔唇，沿囊胚腔顶在内侧铺展；(d) 一个组织在变窄的同时伸长四倍，没有细胞分裂。
::: solution
(a) 外包。(b) 内移（初级间充质的）。(c) 内卷。(d) 汇聚延伸。

::: exercise 受体占据与命运 {level=2 check="3.13"}
在 activin 实验中，一个细胞有5000个受体，占据度从100个受体升到300个时，它从表达 *Xbra* 切换到表达 *goosecoid*。activin 浓度必须增大多少倍（三位有效数字）？

::: exercise 预测移植 {level=2}
预测并解释下列 *Xenopus* 实验的结果。(a) 在4-细胞期向一个腹侧卵裂球注射 *chordin* mRNA。(b) 在早原肠胚期去除组织者。(c) 一个动物帽完整培养；另一个分散为单个细胞三小时后再聚集。(d) 向背侧注射 *BMP4* mRNA。
::: solution
(a) 腹侧出现一条次级轴，带神经组织和体节：Chordin 在腹侧阻断 BMP，模拟组织者（尽管没有完整的头，那还需要 Wnt 与 Nodal 的拮抗剂）。(b) 腹化的胚胎，缺脊索、体节和神经系统，因为 BMP 再无对抗。(c) 完整的帽形成表皮；分散的细胞形成神经组织，因为它们分泌的 BMP 被稀释掉了——默认模型的证据。(d) 背侧结构减少（神经系统变小、背侧中胚层缺失），因为多余的 BMP 压倒了组织者的拮抗剂。
:::
:::

::: exercise 外胚层的阈值模型 {level=3}
在 BMP 活性图中，BMP 活性为 $A(x) = 1/(1 + Ce^{-x/\lambda})$，其中 $x$ 是距组织者的距离。神经板在 $A < 0.5$ 处形成。(a) 证明神经板延伸到 $x_N = \lambda\ln C$。(b) 若 $\lambda = 100$ µm、$C = 20$，它延伸多远？(c) 若组织者拮抗剂的产量加倍，神经板加宽多少？(d) 背侧注射了额外 *chordin* mRNA 的蛙胚为什么可能有一个扩大的神经系统？
::: solution
(a) $A < 0.5 \iff 1 + Ce^{-x/\lambda} > 2 \iff Ce^{-x/\lambda} > 1 \iff x < \lambda\ln C$。

(b) $x_N = 100\ln20 = 100\times3.00 = 300$ µm。

(c) $C$ 加倍给出 $x_N = \lambda\ln(2C)$，增加 $\lambda\ln2 = 69$ µm——与任何指数梯度相同的对数剂量依赖（[[developmental-biology/axis-formation]]）。

(d) 更多的 Chordin 在更宽的范围内阻断 BMP，使 BMP 活性在更腹侧的地方降入神经阈值之下，于是更多的外胚层成为神经板。这样的胚胎（以及 Noggin 过多的胚胎）确实发育出扩大的神经板和头部，而 BMP 的过表达有相反的效果。
:::
:::

::: exercise 解读激光消融实验 {level=3}
在海胆胚胎中，原肠通常内陷约达囊胚腔的三分之一，然后延伸抵达动物极。在顶端次级间充质细胞于第一阶段之后被激光消融的胚胎中，原肠到达约三分之二处便停止。在消融发生于内陷之前的胚胎中，仍形成一个短的原肠。(a) 关于每一阶段的受力，你能得出什么结论？(b) 还有什么观察可以支持汇聚延伸在原肠中的作用？
::: solution
(a) 第一阶段（内陷到约三分之一）不依赖次级间充质：它由植物板自身驱动——其细胞的顶端收缩和其他形状变化。从约三分之一到三分之二的延伸在没有顶端细胞的情况下发生，所以它由原肠壁自身通过细胞重排驱动。只有最后三分之一需要次级间充质的丝状伪足，由它们把顶端拉到动物极。这里原肠形成是数个独立机制依次作用的总和，每一个都可以通过移除其一加以检验。

(b) 在延伸期间计数原肠周圈的细胞：如果它由绕许多细胞变为绕少数细胞，而细胞总数大致不变、细胞分裂很少，那么伸长必定来自重排——汇聚延伸。标记单个细胞并追踪其邻居将直接显示间插。
:::
