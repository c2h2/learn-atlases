卵子是大多数动物所能造出的最大的细胞。海胆的卵直径约80 µm，蛙卵超过1毫米，鸡蛋的卵黄有几厘米。它装满了最初数小时或数天发育所需的材料——卵黄、核糖体、线粒体、母体 mRNA 和蛋白质——并且处于停滞状态，静待发动。受精同时做两件事：把父母双方的单倍体染色体组组合起来，并**激活**卵子，启动一个此前一直被抑制的代谢与发育程序。随后发生的是**卵裂**：一系列快速而不伴随生长的分裂，把巨大的细胞分成许多小细胞，并以中空的细胞球或细胞盘告终，即**囊胚**。

本章追随四个以极不相同方式完成这些最初步骤的动物——海胆、蛙 *Xenopus*（非洲爪蟾）、果蝇 *Drosophila*（黑腹果蝇）与小鼠——并归纳它们的共性。途中我们会遇到两个定量观念：卵子为什么必须在数秒内阻断多余的精子，以及胚胎如何「计数」自己的分裂以知道何时开启自身基因。特化与潜能的词汇见 [[developmental-biology/principles-of-development]]。

## 配子

精子和卵子是针对同一个问题的两种相反解法。**精子**为递送而精简：一个紧凑的单倍体核，一条由线粒体供能的鞭毛，其顶端是一个**顶体（acrosome）**——一个由高尔基体衍生的分泌囊泡，内含到达并结合卵子所需的酶和黏附蛋白。在多数动物中，精子还贡献一个中心粒，由它组织受精卵的第一个有丝分裂纺锤体。

**卵子**（卵母细胞）为储备给养而建。其细胞质含有卵黄——脂类和蛋白质，主要是在肝脏或脂肪体合成、从血液中摄取的卵黄蛋白原衍生蛋白——以及一批母体 mRNA 和蛋白质，它们将运转胚胎直到胚胎自身的基因开启。其质膜之下是**皮层（cortex）**，一张含有数千个膜结合**皮层颗粒**的肌动蛋白丝凝胶。质膜之外是一层胞外被膜：海胆和蛙的**卵黄膜（vitelline envelope）**，哺乳类的**透明带（zona pellucida）**。许多物种的卵子外面还有胶质（海胆、蛙）或卵泡细胞（哺乳类的卵丘）。

卵子与精子相遇时所处减数分裂的阶段各不相同：海胆的卵子已完成减数分裂，而蛙和多数哺乳类的卵子停滞在第二次减数分裂的中期，只有受精后才将其完成。

## 受精

::: definition 受精 {#def-fertilisation}
**受精**是精子与卵子的融合，包括：(1) 两者之间的接触与识别，确保它们是同一物种；(2) 精子入卵的调节，使只有一个精子核进入卵子；(3) 两个配子遗传物质的融合；(4) 卵子代谢的**激活**，启动发育。
:::

### 海胆：抵达并结合卵子

海胆把精卵排放到海水中，许多种的卵子可能遇到许多别的种的精子。因此种的特异性在多个步骤上被强制实现。卵子胶释放的肽类吸引并激活同种的精子——*Arbacia punctulata* 卵中的 resact 是研究得最充分的**趋化吸引物（chemoattractant）**。与卵胶的接触触发**顶体反应（acrosome reaction）**：顶体囊泡与精子质膜融合并释放内含物，肌动蛋白聚合推出一根**顶体突起**，一根几微米长的指状物。其表面带有**结合素（bindin）**，一种结合同种卵子卵黄膜上受体的蛋白。维克托·瓦奎耶（Victor Vacquier）的组于1977年证明，分离的结合素只凝集本种的卵而不凝集他种的卵；bindin 的序列在种间迅速分化，这有助于维持它们的生殖隔离。

随后精子与卵子的质膜融合，精子核与中心粒进入卵子。

### 多精入卵的阻断

在多数动物中，若两个精子进入一个卵子，胚胎便会死亡：在海胆中，多精入卵造成三倍体核，更糟的是多出一个中心粒，于是第一次分裂形成四极纺锤体，把染色体混乱地分配到四个细胞中。因此卵子具有防止多个精子融合的机制。

::: definition 多精入卵的快阻断与慢阻断 {#def-blocks}
- **快阻断（fast block）**是电学变化。精子融合后数秒内，海胆卵的静息膜电位（约 $-70$ mV）变为约 $+20$ mV，主要由 Na⁺ 内流所致。精子不能与去极化的卵膜融合。劳林达·贾菲（Laurinda Jaffe）于1976年证明，用电流把卵电位钳制为正可阻止受精，钳制为负则允许多精入卵。快阻断持续约1分钟且不完全：它减少而非消除后续的融合。哺乳类的卵子似乎不使用快速的电学阻断。
- **慢阻断（slow block）**是卵被膜的物理变化，即**皮层颗粒反应**。皮层颗粒与卵质膜融合，向质膜与卵黄膜之间的间隙释放酶和结构蛋白。在海胆中，一种蛋白酶切断膜与卵黄膜之间的连接并剪去已结合的精子；黏多糖吸入水分，把卵黄膜抬起；一种过氧化物酶将其交联成坚硬的**受精膜（fertilisation envelope）**。整个过程约需1分钟完成。
:::

哺乳类的卵子使用同类的慢阻断。小鼠透明带含三种糖蛋白（ZP1、ZP2和 ZP3；人卵还有第四种，ZP4）。现在认为精子结合在 ZP2的氨基端区域，受精后皮层颗粒释放的一种蛋白酶 ovastacin 切开 ZP2，使透明带不再结合精子（Avella、Baibakov 与 Dean，2014）。早先一个基于1980年代实验的模型把精子结合定位在 ZP3；这一问题表明，一个得到充分支持的教科书机制也是可以被修订的。在哺乳类的卵子中，皮层颗粒的外排还改变卵细胞膜本身。

::: example 阻断为什么必须快 {#ex-polyspermy}
设第一个精子与卵子融合之后，更多精子以平均速率 $r = 0.1\ \mathrm{s^{-1}}$ 随机继续融合，直到卵子得到保护，且在第一次融合后 $\tau$ 时刻保护完全。（这些数字是示例；真实速率取决于精子密度。）把后续的融合当作泊松过程。(a) 若只存在慢阻断，取 $\tau = 60$ s，多精入卵的概率是多少？(b) 若快阻断在 $\tau = 2$ s 完全，概率又是多少？(c) 你的答案对「为什么在高精子密度下，快阻断失效的海胆卵子会多精入卵」有何提示？
::: solution
对速率为 $r$ 的泊松过程，时间 $\tau$ 内额外融合的次数服从均值 $\lambda = r\tau$ 的泊松分布，至少发生一次的概率为 $1 - e^{-\lambda}$。

(a) $\lambda = 0.1\times60 = 6$，故 $P = 1 - e^{-6} = 0.998$：多精入卵几乎必然发生。

(b) $\lambda = 0.1\times2 = 0.2$，故 $P = 1 - e^{-0.2} = 0.18$。

(c) 多精入卵的概率取决于精子到达率与卵子未受保护时间两者的乘积。一个在数秒内关闭这一窗口的阻断，即使像真实的快阻断那样并不完美，也能大幅降低风险；在高精子密度下，仅靠慢阻断会毫无用处。当快阻断被阻止时，例如降低海水中的 Na⁺ 浓度，海胆的卵子确实会多精入卵。反之，在自然界常见、精子密度很低的情况下，$r$ 很小，即使阻断较慢风险也小——这与哺乳类相符：到达卵子的精子很少，依赖慢机制即可。
:::
:::

caption: 卵子受保护之前与其融合的额外精子数目，建模为均值 $\lambda = r\tau$（到达率 × 未受保护时间）的泊松分布。阴影柱（一个或多个额外精子）给出多精入卵的概率：$\lambda = 0.2$ 时约0.18，对应于2秒的快阻断。把 $\lambda$ 滑到6（同一速率下60秒的窗口），阴影区几乎覆盖整个分布。

### 卵子激活：钙波

皮层颗粒反应由胞质游离 Ca²⁺ 的升高触发。在海胆、鱼和蛙的卵子中，这一升高从精子入卵点开始，并以一道**波**的形式横贯卵子：Ca²⁺ 经 IP₃ 受体从内质网释放，提高邻近细胞质中的 Ca²⁺，刺激那里进一步释放，于是信号在行进途中自我再生（[[cell-biology/cell-signalling]]）。莱昂内尔·贾菲（Lionel Jaffe）的组于1978年首先用水母发光蛋白 aequorin 在青鳉的卵中成像了这样一道波；它以约12 µm s⁻¹ 横贯卵子。在波峰之后，皮层颗粒依次融合，受精膜自精子入卵点向对侧抬起。

Ca²⁺ 的升高不仅是慢阻断的触发物；它激活整个卵子。理查德·施泰因哈特（Richard Steinhardt）与戴维·埃佩尔（David Epel）于1974年证明，钙离子载体——无需精子即可让 Ca²⁺ 进入细胞质——能激活海胆的卵子：它们抬起受精膜，提高蛋白质合成速率，并开始 DNA 复制。在蛙和哺乳类中，Ca²⁺ 通过激活一种激酶引起维持停滞的细胞周期抑制因子降解，从而解除中期 II 的停滞。在哺乳类中，触发物由精子自身递送：一种精子特异的磷脂酶 **PLCζ**（Christopher Saunders、Anthony Lai 及同事，2002）在融合时进入卵子并产生 IP₃，而哺乳类的卵子以持续数小时的一串 Ca²⁺ 振荡而非单独一道波作为应答。

::: example 钙信号为什么必须自我再生 {#ex-calcium-wave}
一个 *Xenopus* 卵直径1.2 mm。(a) 若 Ca²⁺ 在缓冲细胞质中的有效扩散系数为 $D = 13\ \mathrm{\mu m^2\,s^{-1}}$（南希·奥尔布里顿（Nancy Allbritton）、托拜厄斯·迈耶（Tobias Meyer）与卢伯特·斯特赖尔（Lubert Stryer），1992），靠单纯扩散传布1.2 mm 需要多久？使用距离 $L$ 上一维扩散的特征时间 $t \approx L^2/2D$。(b) 与一道以10 µm s⁻¹ 行进的波所需的时间比较。
::: solution
(a) $t \approx L^2/2D = (1200\ \mathrm{\mu m})^2/(2\times13\ \mathrm{\mu m^2\,s^{-1}}) = 1.44\times10^6/26\ \mathrm{s} = 5.5\times10^4$ s，约15小时——而且届时浓度早已被稀释得几乎不剩什么。扩散时间随距离的**平方**增长（[热方程](/learn/maths/lesson.php?c=pde&l=heat-equation)），所以在一微米上很快，在一毫米上却慢得无可救药。

(b) 一道以10 µm s⁻¹ 行进的波横贯1.2 mm 需120秒，两分钟。行进的波走过的距离与时间成正比而非其平方根，因为每个区域被相邻区域触发时都会释放自己储存的 Ca²⁺。这就是一个点的信号如何能够几乎均匀而迅速地激活整个巨型细胞的道理。
:::
:::

### 原核的融合

入卵后，精子核去凝聚为**雄原核**，卵子完成减数分裂（若尚未完成），形成**雌原核**。在海胆中，精子的中心粒形成一个微管星体的核心，把两个原核拉到一起，二者融合形成合子的核。在哺乳类中，两个原核相互靠近并各自复制自己的 DNA；它们的核膜破裂，两组染色体在第一次有丝分裂的纺锤体上首次会合。

哺乳类的受精还有若干进一步的特点。精子必须先在雌性生殖道中经历**获能（capacitation）**——一组膜与信号的变化，没有它们精子便不能受精。融合需要一对特异的表面蛋白：精子上的 **Izumo1**（Naokazu Inoue、Masahito Ikawa 与 Masaru Okabe，2005），以及卵子上的它的受体 **Juno**（Enrica Bianchi、Gavin Wright 及同事，2014）。缺失 Izumo1的雄性与缺失 Juno 的雌性小鼠都不育，尽管它们的精子能正常结合卵子。

## 卵裂

::: definition 卵裂与囊胚 {#def-cleavage}
**卵裂**是受精后的一系列有丝分裂，其中合子的体积被分割成许多更小的细胞即**卵裂球（blastomere）**，而没有整体生长。它以**囊胚（blastula）**告终，通常是一个围绕着一个充液腔——**囊胚腔（blastocoel）**——的细胞球（在哺乳类中则是**胚泡（blastocyst）**，具有囊胚腔与内细胞团）。
:::

多数物种早期卵裂的细胞周期快得惊人——*Xenopus* 约30分钟，斑马鱼15分钟，合胞体的 *Drosophila* 胚胎不足10分钟——因为它们缺少间隙期 G1、G2：细胞在 DNA 合成与有丝分裂之间交替，由正是在这些卵中发现的周期蛋白依赖性激酶活性的振荡所驱动（[[cell-biology/cell-cycle]]）。既没有时间也没有必要生长；卵子已经把一切都储备好了。

::: proposition 卵裂期间的细胞大小与核质比 {#prop-cleavage-size}
若一个体积为 $V_0$、直径为 $d_0$ 的卵经 $k$ 次均等分裂且无生长，则得到 $2^k$ 个卵裂球，每个的体积与（对球形细胞而言的）直径为

$$
V_k = \frac{V_0}{2^k}, \qquad d_k = d_0\,2^{-k/3}.
$$ {#eq-cleavage-size}

由于每个细胞保留一个二倍体核，核 DNA 与细胞质体积之比按 $2^k$ 上升：每次分裂翻一倍。假设：均等分裂，无生长或物质损失。不均等卵裂与囊胚腔会改变细节，但不会改变每个卵中 DNA 总量的翻倍。
:::

::: example *Xenopus* 囊胚的细胞 {#ex-xenopus-cleavage}
一个直径1.2 mm 的 *Xenopus* 卵经历12次近乎同步的卵裂。(a) 共有多少个细胞？若它们是相等的球体，每个的直径是多大？(b) DNA 与细胞质之比增大了多少倍？(c) 若第一次卵裂需90分钟，其后11次每次需30分钟，第12次卵裂大约在受精后多久完成？
::: solution
(a) $2^{12} = 4096$ 个细胞；由 [[#eq-cleavage-size]]，$d_{12} = 1.2\ \mathrm{mm}\times2^{-12/3} = 1.2/16\ \mathrm{mm} = 75\ \mathrm{\mu m}$。（实际上动物半球的细胞比这更小，而含卵黄的植物半球的更大。）

(b) $2^{12} = 4096$ 倍：同一团细胞质中，胚胎的核 DNA 总量增加了4096倍。

(c) $90 + 11\times30 = 420$ 分钟，约7小时。真实的快慢强烈依赖温度；在22–23 °C 下，*Xenopus* 胚胎约6–7小时后到达下面即将描述的中囊胚转变。
:::
:::

### 中囊胚转变

在 *Xenopus* 快速的卵裂期间，胚胎自身的基因几乎不转录；胚胎靠母体的 mRNA 和蛋白质运转。第12次卵裂之后，这一切陡然改变。约翰·纽波特（John Newport）与马克·基希纳（Marc Kirschner）于1982年证明，在这一点上细胞周期变长并失去同步，出现间隙期，细胞变得可运动，胚胎自身基因的转录大规模开始。他们称之为**中囊胚转变（mid-blastula transition，MBT）**。

::: definition 中囊胚转变与母源-合子转换 {#def-mbt}
**母源-合子转换**是发育控制从储存在卵中的母体基因产物向合子自身基因产物的交接。它有两个组成部分：母体 mRNA 的清除（经由 microRNA、RNA 结合蛋白及其他机制）与合子转录的激活（**合子基因组激活**，ZGA）。在早期卵裂迅速的胚胎中，ZGA 的主波与细胞周期在**中囊胚转变**处的加长相重合。
:::

胚胎怎么知道自己已经分裂了12次？纽波特与基希纳的回答是，它度量的不是时间或分裂次数，而是**DNA 与细胞质之比**。他们用毛发套环缢缩受精卵，使一半获得细胞核并先于另一半开始分裂，结果每一半都在其细胞到达正常大小时经历 MBT，而不是在某个固定的时刻。向卵中注射额外 DNA 会使 MBT 提早发生。其思想是，卵细胞质中以固定量存在的某种母体因子——一个可滴定的转录或细胞周期加长的抑制物——被不断增多的 DNA 逐步吸收，当 DNA 取胜时，开关便翻动。候选的被滴定因子包括组蛋白（随着染色质的组装，卵中组蛋白的量相对 DNA 下降）以及其短缺会拉长 S 期的复制因子。

::: example 单倍体胚胎需要多分裂一次 {#ex-haploid}
布鲁斯·埃德加（Bruce Edgar）、卡罗琳·基勒（Carolyn Kiehle）与格罗尔德·舒比格（Gerold Schubiger）于1986年报道，单倍体的 *Drosophila* 胚胎（由贡献不出染色体的精子受精的卵发育而来）在细胞周期加长之前要多经历一次合胞体核分裂。解释为什么核质比模型恰好预测这一点，并预测四倍体胚胎会发生什么。
::: solution
在模型中，当胚胎中 DNA 的总量达到由卵中固定量的母体因子设定的阈值时，开关发生。有 $N$ 个核的二倍体胚胎含 $2N$ 套染色体；有 $N$ 个核的单倍体胚胎只含 $N$ 套。要达到同样的总量，单倍体胚胎需要多一倍的核——多分裂一轮。四倍体胚胎有 $N$ 个核却有 $4N$ 套染色体，所以它应当**提前**一轮达到阈值。这一实验之所以有力，是因为一个单纯数分裂次数、或测量经过时间的计数器会预测单倍体与二倍体胚胎毫无差别。（在某些物种中，包括斑马鱼，单个合子基因的计时由该比值控制，而转变的其他方面则依赖时间；机制并非处处相同。）
:::
:::

在其他动物中，基因组激活发生的时间大不相同：小鼠在2-细胞期，人类胚胎在4到8-细胞期，斑马鱼在10次卵裂之后，*Drosophila* 则约从第8个核周期起有一个小波、在第14次有一个大波，其先锋转录因子 **Zelda** 打开数百个早期基因的染色质。即使在「沉默」的胚胎中，也有少数基因早期转录，所以「MBT」标志的是速率上的巨大变化，而非一个绝对的开启开关。

## 卵裂的模式

卵裂的几何构型取决于两件事：有丝分裂纺锤体的排布（由卵及其细胞骨架遗传而来），以及阻碍分裂沟的卵黄的量与分布。缺卵黄的卵（**均黄型**，isolecithal：海胆、哺乳类）完全且相当均匀地卵裂；卵黄集中于植物半球的卵（**中等端黄型**，mesolecithal：两栖类）完全但不均等地卵裂；几乎全是卵黄的卵（**端黄型**，telolecithal：鱼、爬行类、鸟类）只在卵黄上方一个细胞质小盘内卵裂；而具中央卵黄的卵（**中黄型**，centrolecithal：昆虫）则在共同的细胞质内进行核分裂。

| 卵裂类型 | 卵黄 | 实例 |
|---|---|---|
| 完全辐射型 | 稀少或中等 | 海胆、两栖类 |
| 完全螺旋型 | 稀少 | 软体动物、环节动物、扁形动物 |
| 完全两侧型 | 稀少 | 被囊动物（海鞘类） |
| 完全旋转型 | 稀少 | 哺乳类、线虫 |
| 不完全盘状 | 浓密，占卵的大部分 | 鱼类、爬行类、鸟类 |
| 不完全表裂 | 中央 | 多数昆虫 |

在**完全卵裂**（holoblastic）中，分裂沟分割整个卵；在**不完全卵裂**（meroblastic）中只分割其中一部分。螺旋卵裂时纺锤体倾斜，使每一层细胞恰好坐落在下一层细胞之间的凹槽上（见 [[#exr-coiling]]）。

### 海胆

海胆的前两次卵裂是经裂的（贯穿动物极与植物极），第三次是纬裂。第四次是第一次不均等分裂：4个动物细胞经裂为8个相等的**中裂球**，而4个植物细胞纬裂且不均等，在植物极产生4个大的**大裂球**和4个小的**小裂球**。到128-细胞期，细胞形成单层的腔囊胚，长出纤毛，从受精膜中孵出并游动。

小裂球是自主特化继以诱导的一个突出例子。分离的小裂球在培养中形成幼虫骨骼，正如它们在胚胎中会做的那样。移植到另一个胚胎的动物极后，它们仍形成骨骼，并且诱导附近的动物细胞形成第二条肠——所以它们既自主特化，又是诱导者（斯文·赫尔斯塔迪乌斯（Sven Hörstadius）1930年代的移植实验）。它们的特化始于母体 β-catenin：它进入植物细胞的核，激活编码一种抑制物 Pmar1的基因。Pmar1抑制另一种抑制物 HesC——后者本会在全胚胎抑制骨骼形成基因：这是一个**双重阴性门控**，只在产生 Pmar1之处开启骨骼程序（保拉·奥利韦里（Paola Oliveri）、埃里克·戴维森（Eric Davidson）及同事，2002；HesC 是2007年在戴维森实验室被鉴定为靶标的）。

### 蛙

两栖类的卵有一个**动物半球**，含色素且相对无卵黄，以及一个富含卵黄的**植物半球**。它的卵裂是辐射型但不均等：第三次卵裂是纬裂但偏向动物极，产生4个小的动物端和4个大的植物端卵裂球，且动物半球分裂更快。囊胚腔在动物半球开敞。受精时，卵的皮层相对于细胞质旋转约30°，方向背离精子入卵点；这一**皮层旋转**把背侧决定因子移到精子入卵的对侧，固定了胚胎未来的背面（[[developmental-biology/axis-formation]]）。

### *Drosophila*：一个合胞体

*Drosophila* 的卵以不伴随细胞分裂的核分裂开始。合子核每8–10分钟分裂一次，共13个周期。在第7–9周期中，多数核向卵的周边迁移，于第10个周期到达周边，形成**合胞体囊胚盘**；后端极处的少数核早期被膜包围，形成**极细胞**，即生殖系；少数留在卵黄中。在第14周期——约持续一小时——膜在约6000个周边核之间向内生长，形成**细胞化囊胚盘**，约在25 °C 下受精后2.5–3小时。到细胞化之前，像转录因子 Bicoid 这样的蛋白可以在核之间扩散并形成梯度——即 [[developmental-biology/axis-formation]] 中的合胞体特化。

### 哺乳类

哺乳类的卵裂是动物界最慢的：每次分裂约12–24小时，且不同步，所以胚胎可能经历3-、5-和7-细胞期。小鼠合子的基因组在2-细胞期激活。在8-细胞期，卵裂球彼此贴平并最大化彼此的接触，这一过程称为**致密化**，由黏附蛋白 E-cadherin 介导。致密化使每个细胞具有朝外的外侧（顶侧）表面和与其他细胞接触的内侧（基底外侧）表面。在随后的分裂中，有些子细胞被完全置于胚胎内部，16-细胞的**桑葚胚**有少数内细胞被外细胞包围。

第一个命运决定由这一几何构型产生，这使它成为条件特化的一个精彩例子。

- **外部**细胞是有极性的，使 Hippo 信号通路保持失活；转录共激活因子 Yap 进入核，与转录因子 Tead4一起激活 *Cdx2*。这些细胞成为**滋养外胚层（trophectoderm）**，它向胚胎内泵入液体形成囊胚腔，日后构成胎盘的胚胎部分。
- **内部**细胞四面八方都被接触包围，激活 Hippo 信号，Yap 留在细胞质中，细胞继续表达多能性因子 Oct4（由 *Pou5f1* 编码）和 Sox2。它们形成**内细胞团**（ICM）（Noriyuki Nishioka、Hiroshi Sasaki 及同事，2009）。

到32-细胞期，即小鼠受精后约3.5天，胚胎成为一个**胚泡**：一个充满液体的滋养外胚层球，内细胞团位于一侧。随后第二个决定把 ICM 分为**上胚层**（表达 Nanog，将形成胚胎本体的全部）和**原始内胚层**（表达 Gata6，形成胚外膜，即卵黄囊内胚层）。起初两种命运呈「盐-胡椒」状散在混杂；上胚层前体分泌的 FGF4激活邻近细胞的 FGF 受体与 ERK 信号，使其偏向原始内胚层，而 Nanog 与 Gata6之间的相互抑制（一个类似 [[developmental-biology/principles-of-development#prop-toggle]] 的转换开关）把每个细胞解入一种命运；随后细胞分选为两层。小鼠胚泡在约第4.5天植入子宫壁；人胚泡在受精后约第5天形成，约第6–7天着床。

小鼠胚胎是高度调整性的。安杰伊·塔尔科夫斯基（Andrzej Tarkowski，1961）与贝阿特丽斯·明茨（Beatrice Mintz，1962）证明，两个除去透明带并推到一起的8-细胞小鼠胚胎，形成一个正常的囊胚和一只由两个胚胎的细胞构成的健康**嵌合体**小鼠。反之，一个小鼠2-细胞胚胎的单个卵裂球可以形成一个完整的囊胚。人的同卵双生由一个早期胚胎分裂而产生，显示出同样的调整能力。

::: quiz
在小鼠桑葚胚中，一个本应位于外部的细胞被实验性地造成缺乏 Tead4。它最可能变成什么？
- [ ] 滋养外胚层，因为它的位置在外部
- [x] 内细胞团，因为它不能开启 *Cdx2*
- [ ] 原始内胚层，因为 Gata6会被默认激活
- [ ] 它会死亡，因为外部细胞需要 Hippo 信号
::: solution
外部位置经由失活的 Hippo 信号、核内的 Yap 与 Tead4起作用，开启 *Cdx2* 和滋养外胚层程序。没有 Tead4，细胞便读不出自己的位置，于是表现得像内部细胞，保持 Oct4与 Sox2的表达——缺失 *Tead4* 的胚胎不能形成滋养外胚层和囊胚腔。原始内胚层是在稍后、在 ICM 内部被特化的。
:::
:::

::: warning 「受精卵是一张白纸」
人们容易认为卵子是一团未分化的材料，图式从胚胎自身的基因才开始建立。实际上卵子在受精前就高度有组织：它有动物-植物轴、被定位的 mRNA 和蛋白质，以及一个为早期卵裂引路的皮层结构。在 *Drosophila* 和 *Xenopus* 中，主要体轴由母体基因产物建立，而决定母体效应突变体表型的是母体的基因型，而非胚胎自身的。相比之下，哺乳类的卵子看起来远没有那么预先模式化，其早期命运在很大程度上由位置决定——这就是其胚胎如此高度调整性的原因。
:::

::: application 辅助生殖
本文所描述的生物学是体外受精的基础——卵子在体内之外被受精，早期胚胎培养到囊胚期后再移植入子宫；也是卵胞质内单精子注射的基础——把一个精子直接注入卵子，绕过了透明带和融合步骤，但仍依赖精子的 PLCζ 对卵子的激活。这些技术的临床实践，以及关于人类胚胎研究的规制（在许多国家限于发育的最初14天），属于医学图谱（[医学图谱](/learn/medicine/)）。
:::

::: history
奥斯卡·赫特维希（Oscar Hertwig）于1876年在海胆 *Toxopneustes lividus* 的卵中观察到，只有一个精子进入卵子，其核与卵核融合，从而确立了受精是两个核的结合。爱德华·范贝内登（Edouard van Beneden）于1883年在线虫 *Ascaris* 中证明，合子从双亲各获得等量的染色体。弗兰克·利利（Frank Lillie）1910年代对海胆精子与卵水的研究开启了对种识别分子的搜寻，让-克莱芒·当（Jean-Clément Dan）在1950年代描述了顶体反应。快阻断由劳林达·贾菲于1976年以电学方法发现；钙波由莱昂内尔·贾菲的组于1978年成像；中囊胚转变由纽波特与基希纳于1982年界定。第一个经体外受精孕育的孩子路易丝·布朗（Louise Brown）在罗伯特·爱德华兹（Robert Edwards）与帕特里克·斯特普托（Patrick Steptoe）的工作之后于1978年出生；爱德华兹获2010年诺贝尔生理学或医学奖。
:::

::: summary
- 精子为递送而建（核、鞭毛、顶体、中心粒）；卵子为给养而建（卵黄、母体 mRNA 和蛋白质、皮层颗粒、胞外被膜）。
- 受精包括识别、一个精子的受控入卵、遗传物质的融合与卵子激活。海胆的种特异性建立在趋化吸引物、顶体反应和结合素之上；哺乳类的则建立在透明带（精子结合 ZP2）与 Izumo1–Juno 这对融合蛋白之上。
- 多精入卵由快的电学阻断（海胆：数秒内去极化，从约 −70到 +20 mV）和慢阻断（皮层颗粒反应、受精膜）来阻止。多精入卵的风险按 $1 - e^{-r\tau}$ 伸缩。
- 胞质 Ca²⁺ 的升高——海胆、鱼、蛙中自我再生的波，哺乳类中由精子 PLCζ 触发的振荡——激活卵子。
- 卵裂分割卵子而不生长；每次分裂细胞体积减半，DNA 与细胞质之比翻倍。卵黄决定卵裂是完全型还是不完全型；纺锤体的取向给出辐射、螺旋、两侧或旋转型的模式。
- 中囊胚转变（*Xenopus* 在12次卵裂之后）由核质比触发：单倍体胚胎需要多分裂一次。
- 在小鼠中，8-细胞期的致密化与内/外位置经由 Hippo–Yap–Tead4被读取，将滋养外胚层（Cdx2）与内细胞团（Oct4、Sox2）分开；ICM 随后经 FGF4信号与相互抑制分裂为上胚层（Nanog）与原始内胚层（Gata6）。
:::

一个直径80 µm 的海胆卵经七次均等的球形卵裂。每个细胞的直径是多少 µm（三位有效数字）？
::: solution
由 [[#eq-cleavage-size]]，$d_7 = 80\times2^{-7/3} = 80\times0.198 = 15.9$ µm。（真实的128-细胞海胆胚胎是一个中空球，其细胞是扁的而非球形，但每个细胞的体积相同。）

::: exercise 多精入卵的阻断 {level=1}
对每一项实验结果，说出受累及的是哪一种多精入卵阻断。(a) 在 Na⁺ 极低的海水中受精的海胆卵常常是多精的。(b) ZP2不能被切开的鼠标卵，受精后其透明带上仍继续结合精子。(c) 用阻止皮层颗粒外排的药物处理的海胆卵受精正常，但额外的精子在一分钟后融合。
::: solution
(a) 快阻断，它依赖 Na⁺ 内流使膜去极化。(b) 哺乳类的慢阻断：皮层颗粒来源的 ovastacin 切开 ZP2，使透明带不再结合精子。(c) 慢阻断（皮层颗粒反应）：快阻断只保护约一分钟，之后若受精膜尚未形成，第二个精子便能融合。
:::

::: exercise 卵裂的模式 {level=1}
预测下列卵的卵裂类型（完全型或不完全型，及亚型）：(a) 鸟卵；(b) 卵黄很少的蜗牛卵；(c) 具中央卵黄的昆虫卵；(d) 小鼠卵。

::: exercise 多精入卵的概率 {level=2 check="0.259"}
用 [[#ex-polyspermy]] 的泊松模型，一个卵子在快阻断生效前的2秒内以 $0.15\ \mathrm{s^{-1}}$ 的速率暴露于额外精子。至少一个额外精子融合的概率是多少（三位有效数字）？
::: solution
$\lambda = 0.15\times2 = 0.3$；$P = 1 - e^{-0.3} = 1 - 0.741 = 0.259$。

::: exercise 扩散对抗波 {level=2 check="3.85"}
用 $t \approx L^2/2D$，取 $D = 13\ \mathrm{\mu m^2\,s^{-1}}$，Ca²⁺ 扩散10 µm 需要多少秒（三位有效数字）？与一道以10 µm s⁻¹ 行进的波走过同样距离所需的时间比较，并置评。
::: solution
$t = 10^2/(2\times13) = 100/26 = 3.85$ 秒，而波只需1秒。在10 µm 上，扩散与波不相上下；在1.2 mm 上（[[#ex-calcium-wave]]），扩散约需15小时，而波只需2分钟。因为扩散时间按 $L^2$ 伸缩，自我再生的波只在大细胞中必不可少——这就是小的哺乳类卵子能够使用几乎遍布全胞的振荡的原因。
:::
:::

::: exercise 缢缩的卵 {level=2}
一个受精的 *Xenopus* 卵被毛发套环缢缩，使一半含有合子核而另一半不含。有核的一半进行分裂；若干次分裂后，一个核挤过狭窄的桥进入另一半，后者随后也开始分裂，落后几个周期。用核质比模型预测哪一半先经历中囊胚转变，以及在多大的细胞大小。
::: solution
两半含有等量的细胞质，但开始分裂的时刻不同。模型说每一半都在其 DNA 与细胞质之比达到阈值时经历 MBT——也就是说，当它与 MBT 时的正常胚胎具有同样的每单位细胞质的核数、亦即同样的细胞大小时。先开始的那一半先达到阈值；被延迟的那一半后达到，但细胞大小相同。由于每一半只有整个卵一半的体积，每一半达到阈值时只有整个胚胎一半的细胞数（约2048而非4096），即计数上提前一次分裂。纽波特与基希纳这类实验表明，MBT 系于细胞大小，而非受精后的时间或分裂的次数。
:::

::: exercise 解读小鼠嵌合体 {level=3}
两个8-细胞小鼠胚胎，一个来自黑毛品系，一个来自白（白化）毛品系，被聚合培养到囊胚并移入代孕母亲。(a) 预期所得小鼠的毛色是什么？这说明8-细胞期卵裂球的发育潜能如何？(b) 实验的一个变体中，把黑毛品系的胚胎干细胞注入白毛品系的囊胚；所得嵌合体与白鼠交配的后代中，出现了一些黑色仔鼠。这说明干细胞如何？
::: solution
(a) 一只黑白色块相间的嵌合体（常呈条纹状，反映黑色素细胞前体沿身体的克隆式生长）。两个胚胎已调整发育形成了一个正常个体，所以8-细胞期的卵裂球并未决定朝向任何特定部分：两种来源的细胞都贡献给了内细胞团，进而贡献给许多组织。这一阶段哺乳类的胚胎是高度调整性的。

(b) 与白鼠交配所生的黑色仔鼠必定从一个源自被注入干细胞的生殖细胞获得了一套染色体。所以这些干细胞贡献给了嵌合体的生殖系：它们是多能性的，既能形成生殖细胞也能形成体细胞。这种「生殖系传递」检验正是用工程化的胚胎干细胞制作基因修饰小鼠品系的方法（[[molecular-biology/molecular-tools]]）。
:::

::: exercise 母体效应对螺旋方向的作用 {level=3 #exr-coiling}
在椎实螺 *Lymnaea peregra* 中，壳的螺旋方向或为右旋（顺时针方向，显性等位基因 $D$），或为左旋（$d$）。一只螺的螺旋方向由其母亲的基因型决定。(a) 一只 $dd$ 雌螺被一只 $DD$ 雄螺受精。它的后代是什么螺旋方向？其后代（由雌雄同体的 F₁ 自交产生的 F₂）又是什么螺旋方向？(b) 用卵裂解释这一结果。
::: solution
(a) F₁ 全部为 $Dd$ 但都是左旋，因为它们的母亲是 $dd$。每只 F₁ 螺由于是 $Dd$，都产生右旋的后代：F₂ 全部右旋，基因型比例为1 $DD$ : 2 $Dd$ : 1 $dd$。基因的3 : 1分离直到 F₃ 表型才显现：F₂ 中基因型为 $dd$ 的螺产生左旋后代，其余产生右旋后代。（阿尔弗雷德·斯特蒂文特于1923年提出了这一母体效应的解释。）

(b) 壳的旋向由螺旋型卵裂的卵在第三次卵裂时纺锤体的倾斜方向设定，而纺锤体的倾斜又由卵的细胞骨架设定——后者在卵子发生期间由母亲的基因产物构建。该基因在母亲体内发挥作用，而非在胚胎中。一个很好的候选基因编码一种 formin，即肌动蛋白组装蛋白；在近缘种 *Lymnaea stagnalis* 中，通过机械操作第三次卵裂可以翻转胚胎的旋向（黑田玲子（Reiko Kuroda）及同事，2009）。
