看看蜈蚣、蚯蚓或蛇的脊柱，你会看到同一套蓝图在重复：身体由一系列相似的单元构成，即**体节**。昆虫也是分节的——蝇的若干头节融合成一个头壳，三个胸节着生足和翅，腹节约八个——脊椎动物亦然，体现在椎骨、肋骨、脊神经和肋骨之间的肌肉中。分节带来两个彼此独立的问题。第一，连续的组织如何被划分为一系列大小与数目恰当的重复单元？第二，每个单元如何获得自己的**身份**，使一节长出翅而下一节长出平衡棒，或一枚椎骨长肋而下一枚不长？

答案来自两种生物。在 *Drosophila*（黑腹果蝇）中，一系列转录因子在约3小时内把合胞体胚胎细分为14条条纹，而一组选择基因——**Hox 基因**——赋予它们各自的身份。在脊椎动物中，称为**体节（somite）**的结构一对一对地从胚胎生长中的尾端分出，由一个分子时钟计时；同样是 Hox 基因，分成四个簇，赋予它们身份。Hox 基因由蝇与脊椎动物共有，这一发现是20世纪生物学最大的意外之一。启动这一过程的母体梯度见 [[developmental-biology/axis-formation]]。

## *Drosophila* 的分节层级

1980年，克里斯蒂安娜·纽斯林-福尔哈特（Christiane Nüsslein-Volhard）与埃里克·维绍斯（Eric Wieschaus）发表了一项遗传筛选的结果：筛选改变 *Drosophila* 幼虫齿带图案的合子突变——齿带是腹面角质层上的一排排小钩，每一体节一条带。突变体分为三类，区别在于其缺失图案部分的大小与间距。它们与母体基因和 Hox 基因一起构成一个层级，其中每一类基因受其上层的调控。

::: definition 分节基因的类别 {#def-segmentation-genes}
- **间隙基因（gap genes）**（*hunchback*、*Krüppel*、*knirps*、*giant*，加上末端基因 *tailless* 与 *huckebein*）沿前后轴在宽大的结构域中表达。突变体缺失数个相邻体节构成的区块——图案中的一个「间隙」。
- **配对规则基因（pair-rule genes）**（如 *even-skipped*、*fushi tarazu*、*hairy*、*runt* 与 *paired*）以7条条纹表达，每一条位于每隔一个的体节原基。突变体缺失隔一体节的相应部分，因此幼虫的体节数约为正常的一半。
- **节段极性基因（segment-polarity genes）**（如 *engrailed*、*wingless*、*hedgehog* 与 *patched*）以14条条纹表达，每一体节一条。突变体体节数目正常，但每一体节的一部分缺失，由其余部分的镜像重复取代。
:::

所有间隙与配对规则基因以及 *engrailed* 都编码转录因子，在胚胎仍是合胞体时即可直接相互调控。节段极性基因 *wingless* 与 *hedgehog* 编码分泌的信号——这是必要的，因为到它们发挥作用时（约在细胞化之际），细胞膜已将核隔开。

::: example 分节突变体的归类 {#ex-classify}
描述三只突变幼虫。将每只归入一个基因类别。(a) 幼虫有7条齿带而非14条，每条比正常更宽，缺失物质对应每隔一个的体节。(b) 幼虫体节数目正常，但每一体节裸露的后部缺失，齿带以反转方向重复，形成一片「草坪」状小齿。(c) 幼虫缺失胸部和第一腹节；头部与后腹部正常。
::: solution
(a) 配对规则：缺陷以两个体节为周期重复。（*fushi tarazu* 在日语中意为「体节太少」。）(b) 节段极性：每个体节都受影响，伴镜像重复——*wingless* 与 *hedgehog* 突变体即如此，而刺猬般竖立的小齿使 *hedgehog* 得名。(c) 间隙：缺失相邻体节的区块，如 *Krüppel* 突变体（德语意为「跛子」）缺失胸部与前腹部。
:::
:::

### 间隙基因：从梯度到结构域

间隙基因由母体梯度激活。Bicoid 在前半部激活 *hunchback*；高浓度的 Hunchback 抑制 *Krüppel*，较低浓度则允许或促进它，于是 *Krüppel* 在中部一条宽带中表达；*knirps* 在 Hunchback 低的更后部表达，*giant* 则在前、后各一条带中表达。至关重要的是，间隙基因**相互抑制**：Krüppel 与 Giant、Hunchback 与 Knirps 是相互抑制的一对对，相邻结构域只轻微重叠。相互抑制锐化边界，并使其在母体梯度变化时保持稳定，这正是 [[developmental-biology/axis-formation]] 中精确性之谜的部分答案。间隙基因的表达已被测量得极为精确，使它成为发育定量模型的一个经典试验场。

### 配对规则基因：来自增强子的条纹

宽大的间隙结构域如何产生7条狭窄条纹？结果表明并无任何重复性机制，而是靠组合的蛮力。初级配对规则基因 *even-skipped*（*eve*）拥有彼此独立的**条纹增强子**，每一个都是几百个碱基对的 DNA，驱动7条条纹中的一条或两条。斯蒂芬·斯莫尔（Stephen Small）、艾莉森·布莱尔（Alison Blair）与迈克尔·莱文（Michael Levine）在1992年证明，一个480碱基对的增强子连上报告基因后，只在第2条条纹中驱动表达。它由 Bicoid 与 Hunchback 激活——二者存在于整个前半部——并被侧前方的 Giant 与侧后方的 Krüppel 抑制。条纹形成于两个抑制结构域之间的窄缝，那里有激活物而无抑制物。

每条其他条纹都由自己的增强子解读间隙蛋白的不同组合而成，因此7条条纹是7个局部问题的7种不同解——一个不优雅的设计，但进化靠修修补补构建，它也展示了模块化的增强子如何让一个基因在不同位置被独立调控。次级配对规则基因如 *fushi tarazu* 随后解读初级基因，到合胞体阶段末期，配对规则蛋白共同定义出一套精确、重复、以单列细胞为分辨率的代码。

### 副体节与节段极性

7条 *eve* 条纹与7条 *ftz* 条纹交替排列，这14条条纹各自的前缘定义了一个称为**副体节（parasegment）**的单元的前界。阿方索·马丁内斯-阿里亚斯（Alfonso Martinez Arias）与彼得·劳伦斯（Peter Lawrence）于1985年指出，副体节而非体节才是 *Drosophila* 胚胎的基本单位：幼虫的每个体节由一个副体节的后部和下一个副体节的前部组成。

::: definition 副体节与区室 {#def-parasegment}
**副体节**是早期 *Drosophila* 胚胎的一个单元，包含一个体节的后区室与下一个体节的前区室；其前界由 *engrailed* 表达的条纹标示。**区室（compartment）**是一群细胞，其子代从不越过边界进入相邻区室，尽管并不存在物理屏障。安东尼奥·加西亚-贝利多（Antonio García-Bellido）、佩德罗·里波尔（Pedro Ripoll）与希内斯·莫拉塔（Ginés Morata）于1973年通过在翅上制造快速生长标记细胞的克隆发现了区室：无论克隆长到多大，从不出前、后半之间的边界。
:::

配对规则蛋白在每个副体节前部一个细胞宽处启动 *engrailed* 的表达，并在其紧邻前方的一列细胞中启动 *wingless*。随后这两列细胞相互维持：表达 Engrailed 的细胞分泌 Hedgehog，使相邻细胞继续产生 Wingless；而 Wingless 使 Engrailed 细胞继续表达 *engrailed* 与 *hedgehog*。这对相邻细胞间的正反馈在配对规则蛋白消失之后稳定了副体节边界，且两种信号为两侧的细胞提供模式，使每个体节极化。*engrailed* 还充当后区室的**选择基因（selector gene）**：表达它的细胞采取后部身份，而在后区室失去它的细胞表现得像前部细胞。

## Hox 基因：沿轴的身份

### 同源异变突变

1894年，威廉·贝特森（William Bateson）收集了**同源异变（homeosis）**的例子：身体一部分转变为另一部分的模样——触角位置长出腿的昆虫、多余的肋、花瓣取代雄蕊的花。它们的遗传基础是在 *Drosophila* 中弄清的。*Antennapedia* 基因的某些突变使其在头部表达，导致触角原的位置长出腿。*Ultrabithorax* 基因（*bithorax*、*postbithorax*）的突变组合把着生称为平衡棒的小形平衡器官的第三胸节转变为第二胸节的复制品，造出一只长四片翅的蝇。爱德华·刘易斯（Edward Lewis）在1970年代构建了这样一只蝇，他从1940年代起就研究这一区域——**双胸复合体（bithorax complex）**——并于1978年提出一个模型：一系列基因在越来越后的体节中逐级开启，每一个都在此前的身份之上叠加新的身份。

::: definition 同源异型基因与 Hox 基因 {#def-hox}
**同源异型基因（homeotic gene）**是指其突变使身体一部分转变为另一部分模样的基因（**同源异型转化**）。**Hox 基因**是编码同源结构域转录因子的一个同源异型基因家族，在染色体上排成一个或多个簇，沿前后轴在重叠结构域中表达；它们规定沿轴各位置的身份。在 *Drosophila* 中有8个，分属**触角足复合体（Antennapedia complex）**（*labial*、*proboscipedia*、*Deformed*、*Sex combs reduced*、*Antennapedia*）与**双胸复合体**（*Ultrabithorax*、*abdominal-A*、*Abdominal-B*）。
:::

Hox 基因本身并不建造结构；它们选择体节遵循哪个发育程序。例如第三胸节中的 *Ultrabithorax*（Ubx）抑制翅生长所需的基因，于是形成平衡棒；没有它，该体节就执行第二胸节的默认程序，长出翅。

### 共线性与后部优势

两条规则概括 Hox 基因的部署方式。

- **共线性。**基因在染色体上的顺序与其表达结构域沿身体的顺序一致：3′端的 *labial* 最在前部表达，5′端的 *Abdominal-B* 最在后部表达。在脊椎动物中，这种空间共线性还伴有**时间共线性**：3′基因比5′基因更早开启。
- **后部优势（posterior prevalence）。**当多个 Hox 基因在同一群细胞中表达时，较后（5′）的基因通常支配表型，常通过抑制较前的基因或凌驾其功能来实现。因此，缺失一个后部 Hox 基因会使其结构域朝前一个 Hox 基因规定的身份转化，而后部基因在前部体节的异位表达则使这些体节朝后部身份转化。

Hox 表达模式一旦由间隙与配对规则蛋白建立，就必须在其初始调控因子早已离开之后的数日、许多次细胞分裂中保持记忆。这一记忆由 **Polycomb** 组蛋白提供——它们使失活的 Hox 基因保持沉默——以及使激活的基因保持开启的 **Trithorax** 组——两者都是作为引起同源异型转化的突变体被发现的，如今都归入染色质调控因子之列（[[molecular-biology/eukaryotic-gene-regulation]]）。

::: example 预测 Hox 表型 {#ex-hox-phenotypes}
利用后部优势，预测下列处理引起的转化：(a) 第三胸节（T3）与第一腹节（A1）中 *Ultrabithorax* 的缺失；(b) *Ubx* 在整个胸部表达，包括 T2；(c) 胸部中 *Antennapedia* 的缺失。
::: solution
(a) 在 T3和 A1中，前邻的 Hox 基因是规定 T2身份的 *Antennapedia*。没有 Ubx，这些体节便发育为 T2：T3长出翅而非平衡棒，A1形成带足的 T2样体节。刘易斯那批四翅蝇携带的是只影响 T3的较弱突变。

(b) T2中的 Ubx 强加 T3身份，于是翅变成平衡棒样：一只长着四枚平衡棒、没有翅的蝇。

(c) 缺失 *Antennapedia* 使 T2与 T3受更靠前一个基因 *Sex combs reduced* 的影响，在幼虫中它们朝 T1（前胸）身份转化。在成虫中，腿盘内 *Antp* 突变细胞的克隆形成触角样结构，与把腿长到头上的显性功能获得性 *Antennapedia* 等位基因正好相反。
:::
:::

### 同源异型盒与脊椎动物的 Hox 簇

1984年，瓦尔特·盖林（Walter Gehring）所在的组（William McGinnis、Michael Levine 及同事）与马修·斯科特（Matthew Scott）所在的组（与 Amy Weiner 合作）发现 *Antennapedia*、*Ultrabithorax* 与 *fushi tarazu* 共有约180个碱基对的一段序列——**同源异型盒（homeobox）**——它编码一个由60个氨基酸组成的 DNA 结合结构域即**同源结构域（homeodomain）**，折叠成螺旋-转角-螺旋。以同源异型盒为探针，他们和其他人立即在蛙、鼠和人中找到了相关基因。

哺乳动物有39个 Hox 基因，分属4个簇（*HoxA* 至 *HoxD*），位于4条不同的染色体上。按序列相似性，这些基因归入13个**旁系同源群（paralogue group）**，每一群对应祖先簇中的一个位置，尽管没有任何单个簇保留全部13个。这4个簇起源于脊椎动物进化早期的两轮全基因组复制（[[developmental-biology/evo-devo]]）。脊椎动物 Hox 基因表现出与果蝇基因相同的共线性：旁系同源群1–3的基因在后脑和颈部表达，群9–13的基因在后腰、尾和四肢表达。

它们规定区域身份的证据来自敲除实验。缺失全部3个旁系同源群10基因（*Hoxa10*、*Hoxc10*、*Hoxd10*）的小鼠没有腰椎：胸部之后的每一枚椎骨都长肋，如同胸椎；缺失全部旁系同源群11基因的小鼠没有荐椎（丹尼·韦利克（Deneen Wellik）与马里奥·卡佩基（Mario Capecchi），2003）。单个基因的敲除通常只引起轻微转化，因为旁系同源基因共享功能。而在跨物种比较中，中胚层中 *Hoxc6* 表达的前界标示颈与胸的转变，无论这一转变落在小鼠的7枚颈椎之后还是鹅的17枚之后（安·伯克（Ann Burke）、克利福德·塔宾（Clifford Tabin）及同事，1995）。蛇类的胸段 Hox 密码几乎延伸到整个躯干，与其长长的带肋椎骨序列相符（马丁·科恩（Martin Cohn）与谢丽尔·蒂克尔（Cheryll Tickle），1999，在蟒蛇中）。

::: warning 「Hox 基因建造了体节的结构」
Hox 基因常被说成「腿的主基因」或「翅的基因」，但它们并不编码建造任何东西的指令。它们是选择基因：它们修饰数百个下游基因（*realisator* 基因，即**执行基因**）以及建造结构的信号通路的活性，在体节本可运行的一组程序中做出选择。因此，同一种 Hox 蛋白在不同组织、不同动物中可以有相当不同的效应。Ubx 把蝇的后翅变成平衡棒，而在蝴蝶中 Ubx 却表达于后翅——一片完整大小的翅——在那里它改变的是色彩图案而非抑制生长（斯科特·韦瑟比（Scott Weatherbee）、肖恩·卡罗尔（Sean Carroll）及同事，1999）；差别在于哪些靶基因拥有 Ubx 应答增强子。
:::

## 体节形成：脊椎动物的分节时钟

脊椎动物的分节方式不同。在原肠形成期间及其后，神经管和脊索两侧的轴旁中胚层各形成一条未分节的组织棒，即**前体节中胚层**（presomitic mesoderm，PSM）。在其前端，细胞块一对一对地分离出来，成为**体节**，节律严格；同时后端不断生长，并从尾芽为 PSM 持续供应新细胞。体节形成椎骨和肋（生骨节）、躯干和四肢的骨骼肌（生肌节）以及背部的真皮（生皮节）。体节总数是各物种的特征——鸡约50，小鼠约65，某些蛇超过300。

1976年，乔纳森·库克（Jonathan Cooke）与克里斯托弗·蔡曼（Christopher Zeeman）提出，体节由一个**时钟**——PSM 每个细胞中的振荡器——与一个**波前**——随轴生长沿 PSM 向后移动的成熟前沿——之间的相互作用产生。时钟每到达某一相位，波前刚刚掠过的细胞便被划分为一个体节。这一模型等待了20年才等到证据。

1997年，伊莎贝尔·帕尔梅里姆（Isabel Palmeirim）、多明戈斯·恩里克（Domingos Henrique）、戴维·伊什-霍罗威茨（David Ish-Horowicz）与奥利维耶·普尔基耶（Olivier Pourquié）在鸡中找到了证据。*c-hairy1*——*Drosophila* 配对规则基因 *hairy* 的近亲——的 mRNA 在 PSM 细胞中以90分钟的周期有节律地出现和消失，恰为形成一个体节所需的时间。由于较前细胞中的振荡滞后于较后细胞中的，表达表现为每个周期一次、自尾向头扫过的波。此后在几乎所有被研究的脊椎动物中都发现了大量周期基因，涉及 Notch、Wnt 和 FGF 通路。

::: definition 分节时钟与决定前沿 {#def-clock}
**分节时钟**是前体节中胚层细胞中的一种分子振荡器，由 Hes/Her 转录抑制因子以及 Notch、Wnt、FGF 通路组分的负反馈环构成。其周期等于形成一个体节所需的时间。**决定前沿**（波前）是 PSM 中细胞获得形成体节边界能力的位置；它由相互对抗的 FGF 与 Wnt 信号（后部高）和视黄酸（前部高）的梯度设定，并随轴伸长而后移。
:::

::: proposition 时钟与波前的关系 {#prop-clock-wavefront}
若决定前沿相对细胞以速度 $v$ 向后移动，时钟周期为 $T$，则每个体节的长度为

$$
S = vT.
$$ {#eq-somite-length}

若体节形成总历时 $t_\mathrm{seg}$ 且周期恒定，则体节数为 $N = t_\mathrm{seg}/T$。假设：时钟周期与前沿速度恒定（实际上两者都缓慢变化，且体节大小沿身体不同）。
:::

这一关系很简单，却能解释一些引人注目的实验。若西亚娜·杜布吕勒（Josiane Dubrulle）、迈克尔·麦格鲁（Michael McGrew）与普尔基耶在2001年证明，将浸有 FGF8的珠子植入鸡的 PSM 会使附近细胞保持未成熟，从而推移前沿，而靠近珠子形成的体节更小；用突变体或药物使时钟变慢，则体节更大。

::: example 鸡与小鼠的体节 {#ex-somites}
(a) 鸡的分节时钟周期为90分钟。若决定前沿相对 PSM 细胞以1.5 µm min⁻¹ 移动（示例值），每个体节多长？(b) 小鼠形成约65对体节，周期约2 h。体节形成大约历时多久？(c) 鸡形成约52对体节，周期90分钟。它的体节形成历时多久？
::: solution
(a) $S = vT = 1.5\times90 = 135$ µm。

(b) $t_\mathrm{seg} = NT \approx 65\times2\ \mathrm{h} = 130$ h，约5.4天。小鼠的体节形成确实约从胚胎第8天持续到第13.5天左右。

(c) $52\times1.5\ \mathrm{h} = 78$ h，3天多一点，与鸡的体节形成从孵化第2天进行到约第5天相符。（实际周期在这段时间内略有变化。）
:::
:::

### 时钟如何走动

振荡器的核心是一个带延迟抑制自身的基因。在斑马鱼中，*her1* 与 *her7*；在小鼠中，*Hes7*，都编码短寿的转录抑制因子，结合自身的启动子。抑制因子充足时转录停止；mRNA 与蛋白质在数分钟内降解；抑制解除，转录重新开始。影山良一（Ryoichiro Kageyama）的组于2002年证明，相关基因 *Hes1* 即使在培养的细胞中也以约2 h 的周期振荡，且其 mRNA 与蛋白质的半衰期各约20–25分钟。负反馈只有在存在延迟——这里是转录、剪接、输出 mRNA 和翻译蛋白质所需的时间——且组分不稳定时才会产生振荡。

::: proposition 延迟自抑制因子的周期（近似） {#prop-delay}
对一个通过总长 $\tau = T_\mathrm{m} + T_\mathrm{p}$ 的延迟（合成 mRNA 与蛋白质各自的延迟）抑制自身的基因，若抑制高度协同、且分子的降解相对延迟很快，则振荡周期约为

$$
T \approx 2\tau = 2(T_\mathrm{m} + T_\mathrm{p}).
$$

降解变慢会使周期进一步拉长。这一估计来自朱利安·刘易斯（Julian Lewis）2003年对斑马鱼 *her1/her7* 振荡器的模型，是数量级的指南，并非精确定律。
:::

::: example 估算斑马鱼的时钟 {#ex-delay}
一个约2 kb 的 *her* 基因以约每秒20个核苷酸的延伸速率转录；mRNA 的剪接、释放与输出到细胞质随后约需10分钟；约300个氨基酸的蛋白质以约每秒6个氨基酸翻译，再需约1分钟回到细胞核。（这些是代表性速率，并非该基因的实测值。）估算总延迟，以及由 [[#prop-delay]] 预测的周期，并与28 °C 时斑马鱼约30分钟的体节周期比较。
::: solution
转录：$2000/20 = 100$ s ≈ 1.7分钟。加工与输出：10分钟。故 $T_\mathrm{m} \approx 11.7$ 分钟。翻译：$300/6 = 50$ s ≈ 0.8分钟，再加约1分钟返回：$T_\mathrm{p} \approx 1.8$ 分钟。总延迟 $\tau \approx 13.5$ 分钟，预测周期为 $T \approx 2\tau = 27$ 分钟——接近观察到的30分钟。这一估计表明，时钟的节拍由平平常常的分子延迟设定，这就是它对温度和基因长度敏感的原因：其中内含子的加工占了延迟的大部分。
:::
:::

::: intuition 延迟抑制因子为什么会振荡
想象一个只能看到十分钟前温度的恒温器。房间变热后，加热器还要再开十分钟，冲过头；然后它关断，在房间已经太冷之后还要再关十分钟。系统就在太热与太冷之间以大约两倍于延迟的周期永远摆动。一个存在转录和翻译延迟的自抑制基因行为相同，前提是其产物被迅速清除；若产物寿命长，摆动便会衰减，系统稳定在一个恒定水平。
:::

人分节时钟的振荡已在由诱导多能干细胞衍生的前体节中胚层细胞中研究。2020年，Miki Ebisuya 与普尔基耶两所实验室报道其周期约5 h，而同等小鼠细胞约为2–3 h；生化反应速率（如蛋白质降解）的差异似乎能解释物种间节律差异的大部分。

::: application 分节缺陷
分节时钟与 Notch 通路基因的突变，如 *DLL3*、*MESP2*、*LFNG* 与 *HES7*，会导致人类脊柱的先天性疾病，椎骨融合、变形或缺失。对它们的鉴定直接依赖于本文所述小鼠与斑马鱼的时钟研究。临床方面的内容见医学图谱（[医学图谱](/learn/medicine/)）。
:::

::: history
威廉·贝特森在其《变异研究材料》（*Materials for the Study of Variation*，1894）中创造了「同源异变」（homeosis）一词。卡尔文·布里奇斯（Calvin Bridges）于1915年发现了第一个 *bithorax* 突变，爱德华·刘易斯从1940年代起分析双胸复合体，直至1978年的综合论述。纽斯林-福尔哈特与维绍斯的筛选（1980年发表）发现了间隙、配对规则与节段极性基因，这些基因在1980年代被克隆；刘易斯、纽斯林-福尔哈特与维绍斯分享1995年诺贝尔生理学或医学奖。同源异型盒于1984年被发现，它在脊椎动物中的存在当即提示了体型模式基因的深层保守。库克与蔡曼的时钟-波前模型（1976）在1997年 *c-hairy1* 周期表达被发现后得到证实。
:::

::: summary
- 分节把身体划分为重复单元，并赋予每个单元身份。
- 在 *Drosophila* 中，母体梯度在宽大结构域中激活间隙基因；间隙蛋白相互抑制，并通过条纹特异性增强子调控配对规则基因（*eve* 第2条条纹：由 Bicoid 与 Hunchback 激活，以 Giant 与 Krüppel 为界）；配对规则基因在14条条纹中激活节段极性基因。
- 副体节是基本单位；Engrailed（连同 Hedgehog）与 Wingless 在相邻细胞中相互维持并稳定边界。区室是谱系受限的细胞群体；*engrailed* 选择后区室身份。
- Hox 基因是成簇的同源结构域选择基因，规定体节身份。它们表现出空间（在脊椎动物中还有时间）共线性与后部优势；Polycomb 与 Trithorax 组蛋白维持其表达。
- 哺乳动物有4个簇、13个旁系同源群共39个 Hox 基因；旁系同源群的敲除使椎骨身份转化（如缺失 Hox10基因则无腰椎）。
- 体节由前体节中胚层经时钟与波前形成：体节长 $S = vT$，数目 $N = t_\mathrm{seg}/T$。时钟（斑马鱼约30分钟，鸡90分钟，小鼠2 h，培养的人细胞约5 h）依赖 Hes/Her 基因带延迟的负自身调控，周期约为延迟的两倍。前沿由 FGF/Wnt 与视黄酸梯度设定。
:::

## 习题

::: exercise 基因类别 {level=1}
将每个基因分配到分节层级中的一类，并给出其在胚盘期胚胎中的典型表达模式：*Krüppel*、*fushi tarazu*、*engrailed*、*bicoid*、*Abdominal-B*。
::: solution
*Krüppel*：间隙基因，中部一条宽大结构域。*fushi tarazu*：配对规则基因，7条条纹。*engrailed*：节段极性基因，14条窄条纹（每个副体节前部）。*bicoid*：母体坐标基因，前部梯度。*Abdominal-B*：双胸复合体的 Hox 基因，后腹部。
:::
:::

::: exercise 体节大小 {level=1 check="60"}
斑马鱼分节时钟的周期约30分钟。若决定前沿相对细胞以2 µm min⁻¹ 移动，每个体节多长（以 µm 计）？
::: solution
$S = vT = 2\times30 = 60$ µm。
:::
:::

::: exercise 数 Hox 基因 {level=1 check="13"}
若祖先脊椎动物的一个 Hox 簇有13个基因，经两次复制得到4个簇，那么哺乳动物的4个簇共含39个 Hox 基因，问其中丢失了多少个基因？
::: solution
$4\times13 - 39 = 52 - 39 = 13$ 个基因丢失。
:::
:::

::: exercise 延迟与周期 {level=2 check="40"}
在一个延迟自抑制模型中，转录、剪接并输出一个 mRNA 需15分钟，翻译蛋白质并使其返回细胞核需5分钟。用近似式 $T \approx 2(T_\mathrm{m} + T_\mathrm{p})$，以分钟为单位估算周期。
::: solution
$T \approx 2(15 + 5) = 40$ 分钟。在真实的振荡器中，mRNA 与蛋白质的降解速率也很重要，降解偏慢会使周期长于这一估计。
:::
:::

::: exercise 突变体中的条纹增强子 {level=2}
报告基因由 *eve* 第2条条纹增强子驱动。预测其在下列胚胎中的表达模式：(a) 缺失 *Krüppel*；(b) 缺失 *giant*；(c) 母亲缺失 *bicoid*；(d) 增强子上一个 Krüppel 结合位点被突变。
::: solution
(a) 条纹向后扩展，因为其后界由 Krüppel 抑制设定。(b) 条纹向前扩展，因为 Giant 设定前界。(c) 几乎无表达，因为 Bicoid（及由它激活的 Hunchback）是激活物。(d) 与 (a) 类似，向后扩展，但若增强子上还保留其他 Krüppel 位点，可能弱于完整突变体——该实验表明抑制直接通过增强子起作用。
:::
:::

::: exercise 蛇与体节 {level=2 check="4.85"}
玉米蛇形成约315个体节，小鼠约65个。若两者的体节形成相对于其总体发育速率持续相同时间，蛇的时钟相对于该速率必须比小鼠的快多少倍（三位有效数字）？
::: solution
$N = t_\mathrm{seg}/T$，故 $t_\mathrm{seg}$ 相等时，$T_\mathrm{mouse}/T_\mathrm{snake} = 315/65 = 4.85$。塞琳·戈麦斯（Céline Gomez）、普尔基耶与同事（2008）发现，蛇的时钟相对于发育速率确实比小鼠的快约4倍，产生许多小体节。
:::
:::

::: exercise 一道同源异变谜题 {level=3}
一只果蝇幼虫缺失整个双胸复合体（*Ubx*、*abd-A* 与 *Abd-B*）。(a) 它从 T3往后的体节会是什么样子，为什么？(b) 另一只幼虫缺失 *Polycomb* 功能。它的 Hox 基因起始正常，但后来所有体节都表达 *Abd-B* 和其他双胸基因。它会是什么样子？(c) 为什么第二个表型表明 Hox 基因的最初调控因子与其维持是可以分离的？
::: solution
(a) 从 T3到腹部末端的所有体节都像 T2一样发育（在 *Antennapedia* 作用之下），因为没有双胸基因，就没有规定更后身份的信号；刘易斯描述过这样的幼虫，具有一系列重复的中胸样体节。

(b) 按后部优势，表达得最靠后的基因 *Abd-B* 占支配地位：大多数体节朝后腹部身份（约 A8）转化。

(c) 在 *Polycomb* 突变体中，由间隙与配对规则蛋白设定的早期模式正常；缺陷只在后来出现——此时这些调控因子已经降解，本应保持沉默的 Hox 基因被去阻遏。因此建立与维持使用不同机制——瞬时的分节级联设定模式，Polycomb 组的染色质沉默则记住它。
:::
:::

::: exercise 解读一个 FGF 珠子实验 {level=3}
将浸有 FGF8的珠子植入鸡胚胎前部 PSM 旁。此后6小时内，该侧紧邻珠子形成的体节约为对照侧体节长度的一半；其后的体节正常，且体节总数不变。(a) 用时钟-波前模型解释这一结果。(b) 这6小时内在珠子旁形成了多少个体节，对照侧多少个？(c) 你认为体节总数为什么不变？
::: solution
(a) FGF 使 PSM 细胞保持未成熟。在珠子附近，决定前沿被拖住；随后当珠子的作用减弱或细胞移离珠子时，前沿迅速赶上：一段时间内，它在某些地方每个时钟周期扫过更多细胞，在另一些地方更少。在前沿每个周期只前进常规距离一半之处，$v$ 减半，于是 $S = vT$ 减半。

(b) 时钟不受影响，体节仍每90分钟形成一个：6 h/1.5 h = 两侧在同一时间各4个体节；珠子旁的那些较短。（真实实验中，珠子在处理侧产生小体节，稍后出现补偿性的大体节。）

(c) 体节数目由体节形成期间时钟周期的次数决定，$N = t_\mathrm{seg}/T$，而不由前沿移动的距离决定。改变前沿会局部改变体节大小，但只要时钟和总时长不变，数目就不变。
:::
:::
