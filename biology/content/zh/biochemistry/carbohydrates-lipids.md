蛋白质承担细胞的大部分工作，但建造并驱动它们的是另外三类分子。**糖类**是多数细胞最先燃烧的燃料，是种子与肝脏中的能量贮存，也是生物圈结构物质的主体：地球上纤维素比其他任何有机化合物都多。**脂质**构成每一层膜的屏障，比生物能制造的任何其他物质更密集地贮存能量，并充当激素与信号。**核苷酸**是 DNA 与 RNA 的单体、能量货币 ATP、携带电子与酰基的辅酶的核心，以及信号转导的第二信使。

本章按生物体用每一类分子做什么——贮存、建造、运输、识别、信号——来讨论它们，以及为什么特定的分子被选来完成特定的任务。结构化学（D-糖与 L-糖、成环与异头物、糖苷键、脂质堆积成胶束与双层、双螺旋的结构）在[化学图谱：糖类、脂质与生物膜](/learn/chemistry/lesson.php?c=biochemistry&l=carbohydrates-lipids)与[化学图谱：核酸](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)中处理；膜在 [[cell-biology/membranes]] 中展开。

## 糖

::: definition 单糖、双糖与多糖 {#def-sugars}
**单糖**是分子式为 $(\mathrm{CH_2O})_n$ 的多羟基醛（醛糖）或酮（酮糖），通常 $n = 3$–7：丙糖、戊糖（核糖）、己糖（葡萄糖、果糖、半乳糖）。在水中，戊糖与己糖大多以五元或六元环存在，并有两种形式（α 与 β **异头物**），区别在于原羰基碳上羟基的取向。两个单糖以**糖苷键**相连——从一个的异头碳到另一个的一个羟基，失去一分子水——形成**双糖**；长链形成**多糖**（聚糖），可以线性或有分支，可以是同聚物或杂聚物。
:::

### 为什么是葡萄糖？

D-葡萄糖是自然界最丰富的单糖，是脊椎动物血循环中的主要糖类，是淀粉、糖原与纤维素的构件，也是糖酵解的起点。若干性质使它胜任这一角色。

- **稳定性。** 在葡萄糖的 β-吡喃糖环中，每个庞大取代基（每个羟基与 CH₂OH）都可处于平伏位，使其成为最稳定的醛己糖。
- **反应性低。** 开链醛会非酶促地与蛋白质的氨基反应（糖基化，美拉德反应的第一步）。葡萄糖处于开链形式的时间比例极小，H. F. Bunn 与 P. J. Higgins（*Science* 213, 222, 1981）表明它与血红蛋白的反应比别的常见己糖慢——他们提出，这很可能是进化选定葡萄糖作血糖的一个原因。
- **可得性。** 葡萄糖是多数植物光合碳固定的直接产物，也是它们的贮存与结构聚合物的单体。

### 运输糖与贮存糖

生物体以比单体惰性更强的双糖运输糖。**蔗糖**（葡萄糖 α1↔β2 果糖）的两个异头碳都锁在键中，是非还原糖：化学上足够惰性，得以数百毫摩尔每升的浓度在植物韧皮部中运输（[[plant-biology/water-transport]]）。**海藻糖**（葡萄糖 α1↔α1 葡萄糖）也是非还原糖，是昆虫血淋巴中的主要糖类，是真菌与酵母的储备，也是抗干燥的保护剂（[[biochemistry/water-and-bonds]]）。**乳糖**（半乳糖 β1→4 葡萄糖）是哺乳动物乳汁中的糖。

::: example 蔗糖与韧皮部的压力 {#ex-phloem}
许多植物的韧皮部汁液含约 0.5 mol L⁻¹ 蔗糖（还有少量氨基酸与 K⁺）。(a) 把蔗糖当作理想溶质，它在 20 °C 贡献多大渗透压？(b) 若同样的碳以游离葡萄糖运输，渗透压会是多少？
::: solution
(a) 由 [[biochemistry/water-and-bonds#eq-vanthoff]]，$\Pi = 0.5\times0.08314\times293.15 = 12.2$ bar。(b) 每个蔗糖携带 12 个碳，相当于两个己糖，所以同样的碳以葡萄糖计为 1.0 mol L⁻¹，给出 24.4 bar。这种由叶片向韧皮部装载糖、在根与果实中卸糖产生的渗透压，驱动汁液的集流（Ernst Münch 1930 年提出的压力流假说；[[plant-biology/water-transport]]）。以双糖运输使每碳的渗透负荷减半，而且蔗糖是非还原糖，不会与沿途的蛋白质反应。
:::
:::

::: application 乳糖酶持续：受近期进化塑造的生化性状
哺乳动物幼崽用肠乳糖酶消化乳糖，乳糖酶的产生通常在断奶后下降。在一些人群中乳糖酶的产生延续到成年。在欧洲人中，这种**乳糖酶持续**主要关联于乳糖酶基因 *LCT* 上游约 14 kb、邻近基因 *MCM6* 内一个增强子中的单核苷酸改变（N. S. Enattah 及同事，2002）；在东非与中东游牧人群，同一增强子区域的不同变异有相同效应（S. A. Tishkoff 及同事，2007）。这些等位基因在过去数千年间伴随畜牧业扩散——是人类基因组中近期自然选择的最强信号之一，也是分子水平趋同进化的明显例子（[[evolution/human-evolution]]）。乳糖不耐受的临床方面见[医学图谱：消化](/learn/medicine/course.php?c=gastrointestinal)。
:::

## 多糖：贮存与结构

同一种单体——葡萄糖——既给出自然界最易消化、也给出最难消化的聚合物。差别完全在于糖苷键。

| 聚合物 | 单体与键型 | 生物 | 作用 |
|---|---|---|---|
| 直链淀粉 | 葡萄糖，α1→4，无分支螺旋 | 植物 | 贮存（淀粉） |
| 支链淀粉 | 葡萄糖，α1→4，约每 24–30 个残基一个 α1→6 分支 | 植物 | 贮存（淀粉） |
| 糖原 | 葡萄糖，α1→4，约每 8–12 个残基一个 α1→6 分支 | 动物、真菌、细菌 | 贮存 |
| 纤维素 | 葡萄糖，β1→4，直链氢键聚集成微纤维 | 植物、某些藻类与细菌、被囊动物 | 结构（细胞壁） |
| 几丁质 | N-乙酰氨基葡萄糖，β1→4 | 节肢动物、真菌 | 结构（外骨骼、细胞壁） |
| 肽聚糖 | N-乙酰氨基葡萄糖与 N-乙酰胞壁酸交替，由肽交联 | 细菌 | 结构（细胞壁） |

α1→4 键在相邻残基之间造成弯折，所以直链淀粉卷成疏松的螺旋，酶可从其两端进攻；β1→4 键使每个残基相对上一个翻转 180°，形成笔直、并排排列的链，氢键聚集成结晶微纤维，按重量比钢丝还强。多数动物没有能切割 β1→4 葡萄糖键的酶。牛、白蚁与许多其他食草动物靠肠道中的共生细菌、原生生物与真菌消化纤维素——一个键的生物化学就这样塑造了食草的生态学（[[microbiology/microbes-and-hosts]]）。

肽聚糖是 β-内酰胺类抗生素的作用靶标——它们阻断交联酶——也是溶菌酶的作用靶标——后者切割其糖链（Alexander Fleming，1922）；见 [[microbiology/antimicrobials]]。

### 糖原：经优化的油箱

为什么要把葡萄糖聚合成聚合物来贮存？因为细胞的渗透压取决于溶解颗粒的数目而非大小：肝细胞糖原中的葡萄糖若为游离态，浓度将达约 0.4 mol L⁻¹，会吸进水直到细胞胀破（[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=carbohydrates-lipids)中算过）。作为聚合物，它几乎不贡献渗透压。那又为什么要分支？糖原磷酸化酶与糖原合酶只作用于链的非还原端，所以末端越多，葡萄糖释放或贮存越快。

E. Meléndez-Hevia、T. G. Waddell 与 E. D. Shelton（*Biochemical Journal* 295, 477, 1993）把糖原当作工程问题来处理：选择链长与分支方式，使单位体积内能快速释放的葡萄糖最多，同时给酶留出空间。他们的模型是一棵分层树。

::: proposition 糖原的分层模型 {#prop-glycogen}
设每条链长 $g$ 个葡萄糖残基，每条内部链带 $r$ 个分支，分子共 $t$ 层，从连在糖原蛋白上的一条单链开始。则链数、葡萄糖残基数与外层（带非还原端的）链数分别为

$$
C_t = \frac{r^t - 1}{r - 1},\qquad G_t = g\,C_t,\qquad C_\mathrm{outer} = r^{t-1}.
$$ {#eq-glycogen}

对 $r = 2$，外层恰含全部葡萄糖的一半多，而脱支酶作用之前能被磷酸化酶释放的只有外层葡萄糖。假设：各链相同的规则树；真实糖原不规则，链长有一个范围。
:::

::: proof
第 1 层有 1 条链，第 2 层有 $r$ 条，第 $k$ 层有 $r^{k-1}$ 条；对 $k = 1,\dots,t$ 求几何级数得 $C_t = (r^t - 1)/(r - 1)$，最外层即 $k = t$。对 $r = 2$，外层链占总链数的比例为 $2^{t-1}/(2^t - 1)$，略大于 $1/2$。
:::

::: example 一个糖原分子有多大？ {#ex-glycogen}
Meléndez-Hevia 与同事发现最优值接近 $g = 13$、$r = 2$——与实测平均值吻合——而分子可长到约 12 层，再往外层就太拥挤、酶无法进入。一个 12 层的分子有多少葡萄糖残基和多少非还原端？其葡萄糖有多大比例能被磷酸化酶立即取用？
::: solution
$C_{12} = 2^{12} - 1 = 4095$ 条链，所以 $G_{12} = 13\times4095 = 53\,235$ 个葡萄糖残基，带 $2^{11} = 2048$ 个非还原端。外层含 $2048\times13 = 26\,624$ 个残基，即总数的 $26\,624/53\,235 = 50.0$%（磷酸化酶在离每个分支点几个残基处就停手，所以实际在脱支前释放的略少）。实测肌肉与肝糖原的“β-颗粒”直径约 20–30 nm，含糖约 55,000 个，与模型一致——这是能用优化论证预测的生物结构的一个漂亮例子。
:::
:::

### 糖作为信息：细胞表面的聚糖

真核细胞表面的多数蛋白质与许多脂质都携带分支寡糖（聚糖），在内质网与高尔基体中加上（[[cell-biology/protein-sorting]]）。因为糖可经多个羟基成键、可为 α 或 β、可有分支，少数几种单糖就能造出数量惊人的结构。聚糖参与折叠质量控制，充当细胞之间的识别信号、病毒与毒素的受体以及自身的标记。**ABO 血型**是一例。O 抗原本是一个基本寡糖；A 与 B 抗原用同一基因四种氨基酸有差的两种等位基因编码的糖基转移酶，在其上分别加上 N-乙酰氨基半乳糖或半乳糖；O 等位基因是一个移码突变，不编码有活性的酶（F. Yamamoto 及同事，1990）。其临床意义见[医学图谱：血液](/learn/medicine/course.php?c=blood)。

## 脂质

**脂质**以溶解度而非结构定义：它们是溶于非极性溶剂的那类生物分子。包括脂肪酸及其酯、磷脂与鞘脂、固醇、萜类与蜡。

::: definition 脂肪酸及其记号 {#def-fatty-acid}
**脂肪酸**是带一条长而不成支烃链的羧酸，碳数通常为偶数（12–24），因为它以两个碳为一单元构建（[[biochemistry/metabolic-integration]]）。链中不含碳–碳双键者为**饱和**，含一个者为**单不饱和**，含一个以上者为**多不饱和**；天然双键几乎总是 *cis*。记号 $18{:}2\ \Delta^{9,12}$ 表示 18 个碳、两个双键，分别始于从羧基碳（C-1）数起的第 9 与第 12 位碳。营养学家也从甲基端计数：**ω-3**（n-3）脂肪酸的最后一个双键始于离末端三个碳处。
:::

链长与不饱和度决定脂质的物理状态。*cis* 双键在链中造成约 30° 的折角，阻止紧密堆积，所以不饱和脂肪的熔点比同碳数的饱和脂肪低得多。

### 必需脂肪酸与 ω-3 食物网

动物能在 Δ⁹ 位插入双键（由硬脂酸制油酸），但脊椎动物不能在 Δ⁹ 以上朝甲基端插入双键，因为它们缺乏植物拥有的 Δ¹² 与 Δ¹⁵（ω-3）去饱和酶。因此它们必须从膳食获取亚油酸（18:2, ω-6）与 α-亚麻酸（18:3, ω-3）；George 与 Mildred Burr 在 1929 年发现，喂无脂膳食的大鼠出现缺乏症，可被亚油酸治愈。以这些前体，动物能制得更长的多不饱和酸：花生四烯酸（20:4, ω-6）、二十碳五烯酸（EPA，20:5, ω-3）与二十二碳六烯酸（DHA，22:6, ω-3），它们浓集于神经元与视网膜膜中。海洋食物网中多数 ω-3 脂肪酸的最终来源是微藻；鱼吃藻、以及吃吃藻动物的动物而积累它们。有些无脊椎动物，如线虫 *Caenorhabditis elegans*（秀丽隐杆线虫），确实有 ω-3 去饱和酶，说明脊椎动物的丧失是谱系特异的事件。

### 脂肪作为能量贮存

三酰甘油——三个脂肪酸酯化到甘油上——是动物与许多种子的主要能量贮存。它们优于糖原，理由有二。它们的碳更还原（每个碳的氧更少），氧化时每克释放更多能量；而且它们疏水，以几乎无水的液滴贮存，而糖原结合着自身质量数倍的水。

::: proposition 燃料的能量密度（经验） {#prop-energy-density}
完全氧化可得的代谢能约为脂肪 37 kJ g⁻¹、糖 17 kJ g⁻¹、蛋白质 17 kJ g⁻¹（即 Atwater 系数 9、4 与 4 kcal g⁻¹，自 W. O. Atwater 1890 年代的量热研究以来一直用于营养学）。细胞内的糖原水合约每克结合 3 g 水（估计范围约 2–4 g），所以贮存状态下水合糖原每克只产出 $17/(1+w)$ kJ，其中 $w$ 是水与糖原的质量比。这些是平均值；各种脂肪与糖相差百分之几。
:::

::: example 为什么我们贮存脂肪 {#ex-fat}
一个清瘦成年人贮存约 15 kg 三酰甘油与约 0.5 kg 糖原（肝与肌肉合计）。(a) 比较二者的能量。(b) 若脂肪中的能量改以水合糖原贮存（$w = 3$），这份贮备会有多重？
::: solution
(a) 脂肪：$15\,000\ \mathrm{g}\times37\ \mathrm{kJ\,g^{-1}} = 555$ MJ。糖原：$500\times17 = 8.5$ MJ——约为脂肪能量的 1.5%。按静息能量消耗约每天 8 MJ 计，糖原可维持约一天，脂肪可维持两个月。
(b) 水合糖原产出 $17/4 = 4.25\ \mathrm{kJ\,g^{-1}}$，所以 555 MJ 需要 $555\,000/4.25 = 131\,000$ g，即约 131 kg——单是贮存形式就几乎比整个人体重的一倍还多。按贮存状态计，脂肪的能量密度约为水合糖原的 8.7 倍，这对任何必须带着储备移动或飞行的动物都是决定性的。
:::
:::

这一优势对迁徙者最大。在从阿拉斯加到新西兰超过 11,000 km 的不降落飞行之前，斑尾塍鹬（*Limosa lapponica*）沉积的脂肪约达体重的一半，并缩小其消化器官（R. E. Gill 及同事，*Proceedings of the Royal Society B* 276, 447, 2009）。相形之下，糖原是在动员速度比重量更重要之处的首选燃料：用于肌肉的爆发性活动，以及肝对血糖的逐分钟调节。

### 膜与表面的脂质

膜脂质是两亲性的：真核生物中为甘油磷脂、鞘脂与固醇；细菌中大多为甘油磷脂，其中一些还制造**藿烷类化合物**（类固醇状的五环分子，其合成不需要氧）；古菌中为经醚键连到甘油上的异戊二烯链。古菌脂质所用的甘油磷酸立体异构体（sn-glycerol-1-phosphate）与细菌及真核生物者（sn-glycerol-3-phosphate）相反，且由不同的酶合成——“脂质分野”，这与第一批细胞及真核细胞如何起源有关（[[diversity-of-life/origin-of-life]]）。膜的结构、流动性与脂筏在 [[cell-biology/membranes]] 中讲述。

在生物体外表面，脂质形成防水层。**蜡**——长链脂肪酸与长链醇的酯——覆盖叶与昆虫的角质层，限制失水，并构成蜜蜂的巢脾。植物角质层连同其角质素聚合物与蜡，是植物征服陆地的创新之一（[[plant-biology/plant-cells-tissues]]）。

### 脂质作为信号

脂质也携带信息。**类固醇激素**（皮质醇、雌二醇、睾酮，以及昆虫的蜕皮激素蜕皮酮）以胆固醇为原料，作用于调控转录的核受体。**类花生酸**（前列腺素、血栓烷与白三烯）以花生四烯酸为原料，是炎症、凝血与生殖中的近程信号。膜磷脂酰肌醇被切割为第二信使二酰甘油与三磷酸肌醇（[[cell-biology/cell-signalling]]）。植物用脂质来源的激素茉莉酸抵御食草动物，用油菜素类固醇调节生长（[[plant-biology/plant-hormones]]）。

::: warning “脂肪只是惰性的能量贮存”
脂肪组织是活跃的器官。其脂肪被不断分解又再合成（人体贮存的三酰甘油中相当一部分在一年内周转），其脂肪酸释放受激素严格调控，脂肪细胞还分泌自己的激素（如瘦素），向脑报告脂肪库的大小。在冬眠哺乳动物与新生儿中，棕色脂肪组织燃烧脂肪产热（[[biochemistry/oxidative-phosphorylation]]）。把脂肪当作惰性沉积物，就错过了它生物学的绝大部分。
:::

## 核苷酸：单体、货币与辅酶

::: definition 核苷与核苷酸 {#def-nucleotide}
**核苷**是一个含氮碱基——嘌呤（腺嘌呤、鸟嘌呤）或嘧啶（胞嘧啶、胸腺嘧啶、尿嘧啶）——经 N-糖苷键连到核糖或 2′-脱氧核糖的 C-1′ 上。**核苷酸**是带一个或多个磷酸基（通常酯化在糖的 C-5′）的核苷：例如腺苷 5′-三磷酸（ATP）。在核酸中，核苷酸以 3′,5′-磷酸二酯键相连。
:::

核苷酸有四种角色。

1. **核酸的单体。** DNA 用 dA、dG、dC 与 dT；RNA 用 A、G、C 与 U（[[molecular-biology/dna-structure]]）。
2. **能量货币。** ATP 连接放能过程与需能过程；GTP 驱动蛋白质合成与信号开关；UTP 与 CTP 活化用于生物合成的糖与脂质（UDP-葡萄糖用于糖原，CDP-二酰甘油用于磷脂）。它们的能量学在 [[biochemistry/bioenergetics]] 中讲述。
3. **辅酶。** NAD⁺、NADP⁺、FAD 与辅酶 A 都含一个不参与其化学的腺苷二磷酸单元。H. B. White（1976）提出，这些是 RNA 世界的分子化石——在 RNA 世界里催化剂是 RNA，辅酶是连在 RNA 上的核苷酸。
4. **信号。** 环磷酸腺苷（cAMP）1957–58 年由 Earl Sutherland 在肝提取物中发现，是肾上腺素促进糖原分解的中介（1971 年诺贝尔生理学或医学奖），在动物中是第二信使，在细菌中是分解代谢物阻遏的调控因子。细菌以鸟苷四磷酸（ppGpp）报告饥饿——Michael Cashel 与 Jonathan Gallant 1969 年发现的“魔斑”——它关掉核糖体的合成；环二 GMP 控制游动与生物膜生活之间的切换。

::: example ATP 循环有多快？ {#ex-atp-turnover}
静息成人每分钟消耗约 0.25 L O₂。气体在标准状况下取 22.4 L mol⁻¹，每还原一个 O₂ 约生成 5 个 ATP（每对电子 2.5 个，[[biochemistry/oxidative-phosphorylation]]），估算每天的 ATP 周转。体内约有 25 L 细胞内水，ATP 约 4 mmol L⁻¹（摩尔质量 507 g mol⁻¹）。每个 ATP 分子每天循环多少次？若不重新合成，这个库能维持多久？
::: solution
每天 O₂：$0.25\times1440 = 360$ L，即 $360/22.4 = 16.1$ mol。生成的 ATP：每天 $16.1\times5 = 80$ mol，即 $80\times507 = 41\,000$ g——约 40 kg，超过体重的一半，每天在静息状态下如此。
库为 $25\times0.004 = 0.10$ mol（约 50 g），所以每个 ATP 每天循环约 $80/0.10 = 800$ 次。按静息速率，这个库可维持 $0.10/(80/86\,400) \approx 110$ s，而在工作的肌肉中只有几秒。ATP 是快速流通的货币，不是储备；储备是脂肪、糖原，以及管几秒钟的磷酸肌酸（[[biochemistry/bioenergetics]]）。
:::
:::

核苷酸的合成有两条路：**从头合成**，以氨基酸、CO₂、一碳单位与核糖 5-磷酸（经焦磷酸核糖）为原料；以及**补救合成**，回收核酸降解时释放的碱基与核苷。它们的分解产物被排出：嘌呤在人与其他类人猿、鸟类与爬行类（其祖先丧失或失活了尿酸氧化酶，或以尿酸为主要含氮废物）以尿酸告终，在多数其他哺乳动物则生成尿囊素或更进一步的产物（[[biochemistry/metabolic-integration]]）。因为快速分裂的细胞需要大量核苷酸，许多抗癌、抗病毒与抗菌药物是核苷酸类似物或核苷酸合成抑制剂——这里的逻辑属于生物学，用途则不是本题的关切。

::: quiz
关于葡萄糖贮存形式的说法哪个正确？
- [ ] 纤维素是植物的贮存多糖，动物不能消化它，因为它分支太多。
- [x] 糖原比支链淀粉分支更密，这给它更多非还原端以供快速动员。
- [ ] 淀粉与糖原被贮存，是因为聚合物比游离葡萄糖产生更多渗透压。
- [ ] 每克脂肪比糖原贮存更多能量，主要因为脂肪分子更大。
::: solution
糖原每 8–12 个残基一个分支，支链淀粉每 24–30 个，所以糖原为磷酸化酶与合酶提供更多末端。纤维素是结构多糖，无分支，因 β1→4 键而不可消化。聚合物比同质量单体产生的渗透压*低*得多。脂肪的优势来自其更还原的碳与不含结合水，而非分子大小。
:::
:::

### 糖与脂质的方法

糖类与脂质比蛋白质与核酸更难研究，因为它们不是模板合成的，结构也不能从基因读出。经典方法包括显色反应（碘把直链淀粉染成蓝黑色、糖原染成红棕色；过碘酸-Schiff 染色在组织切片上标记糖原）、薄层与气相色谱（脂肪酸以其挥发性甲酯分析），以及用专一酶偶联 NADH 或 NADPH、依 340 nm 吸光度测定的酶法测定（[[biochemistry/enzymes]]）。今天**脂质组学**与**糖类组学**用质谱一次勾勒数百种分子的谱，同位素示踪（¹³C-葡萄糖、²H₂O）结合质谱或核磁共振则测量活的生物体内贮存被制造与动用的速率。

::: history
费歇尔（Emil Fischer）在 1884–1894 年间弄清了葡萄糖及其异构体的构型（1902 年诺贝尔化学奖），Norman Haworth 在 1920 年代确立了糖的环结构（1937 年诺贝尔奖）。克洛德·贝尔纳 1857 年在肝中发现糖原，表明动物既消耗糖也制造糖。弗里德里希·米歇尔 1869 年从脓细胞中分离出“核质”——连同蛋白质的 DNA。Wilbur Atwater 1890 年代的人体量热实验给出了食物的能量值。George 与 Mildred Burr 1929 年发现必需脂肪酸。弗里茨·李普曼（Fritz Lipmann）“高能磷酸键”的概念（1941）使 ATP 成为细胞的货币，Sutherland 发现环磷酸腺苷（1957–58）开启了第二信使的研究。
:::

## 由此走向何处

本章的燃料在 [[biochemistry/glycolysis-tca]] 与 [[biochemistry/oxidative-phosphorylation]] 中燃烧，在 [[biochemistry/metabolic-integration]] 中制造与贮存；能量载体 ATP、NADH 与 NADPH 在 [[biochemistry/bioenergetics]] 中讲述。作用于它们的酶接着见 [[biochemistry/enzymes]]。

::: summary
- 葡萄糖是通用燃料：稳定、糖基化慢，是光合作用的产物。蔗糖与海藻糖是非还原双糖，为运输糖与保护糖；乳糖是乳汁中的糖，乳糖酶持续在畜牧人群中趋同进化而来。
- α1→4 葡萄糖聚合物（淀粉、糖原）是可消化的贮备；β1→4 聚合物（纤维素、几丁质）是结构多糖，需微生物共生体才能消化。
- 糖原的分支（$g \approx 13$、$r = 2$、至多 12 层、约 53,000 个葡萄糖）接近快速释放的最优；聚合物避免了游离葡萄糖的渗透负荷。
- 脂肪酸按链长与双键命名（$18{:}2\ \Delta^{9,12}$，ω-6）；*cis* 双键降低熔点。脊椎动物必须摄取亚油酸与 α-亚麻酸。
- 脂肪产出 37 kJ g⁻¹ 且以无水形式贮存；贮存状态的水合糖原约产出 4 kJ g⁻¹。清瘦成人脂肪贮存 555 MJ，糖原贮存 8.5 MJ。
- 核苷酸是核酸单体、能量货币（静息成人每天循环约 40 kg ATP）、辅酶的组成部分与第二信使（cAMP、ppGpp）。
:::

::: exercise 分支与动员 {level=2}
糖原合酶只把葡萄糖加到非还原端，糖原磷酸化酶只从非还原端移除。一种突变酶合成的糖原每 30 个残基而非每 13 个残基（如支链淀粉）分支一次。说理并预测对 (a) 葡萄糖释放的最大速率、(b) 聚合物的溶解度、(c) 给定大小分子贮存葡萄糖量的影响。
::: solution
(a) 分支更少意味着每个分子的非还原端更少，能同时起作用的酶分子更少，最大释放速率下降。(b) 长的不分支链倾向形成会堆积、结晶的螺旋（如直链淀粉与支链淀粉的外链，它们形成不溶性淀粉粒）；聚合物溶解度下降。事实上，人糖原累积病 IV 型中脱支酶缺乏产生分支稀少、不溶的糖原。(c) 更长的链在给定体积内装更多葡萄糖，所以贮存密度可以升高——这正是 Meléndez-Hevia 分析的密度与速度之间的权衡。贮存数月、动员缓慢的植物选了致密的形式（淀粉）；需要快速释放的动物选了分支的形式。
:::
:::

::: exercise 必需脂肪酸 {level=2}
脊椎动物细胞能以葡萄糖制油酸（18:1 ω-9），却不能制亚油酸（18:2 ω-6）。解释原因，以及为什么纯饱和脂肪加糖的膳食最终仍会导致缺乏——尽管细胞能使脂肪酸去饱和。为什么以几乎不含脂肪的草料为生的牛仍能获得必需脂肪酸？
::: solution
脊椎动物有 Δ⁹ 去饱和酶，把硬脂酸转为油酸，但没有 Δ¹² 或 Δ¹⁵ 去饱和酶，所以不能在链的甲基端一半引入双键；作用于近羧基端的去饱和酶（Δ⁵、Δ⁶）与延长酶能延长已有的 ω-6 与 ω-3 链，却不能创造 ω-6 或 ω-3 键。饱和脂肪与糖只提供只能变成 ω-9 或 ω-7 的链。牛吃草，草的叶绿体膜富含 α-亚麻酸（18:3 ω-3），所以低脂膳食也提供它（尽管瘤胃微生物氢化了其中大部分，这就是反刍动物脂肪相对饱和的原因）。
:::
:::

::: exercise 靠脂肪飞行 {level=3 check="15.4"}
一只迁徙涉禽携带 200 g 脂肪，以 60 km h⁻¹ 飞行，代谢功率 8.0 W（示例值）。(a) 用 37 kJ g⁻¹，若脂肪全部动用，它能飞多远（千公里，三位有效数字）？(b) 与携带同质量水合糖原（$w = 3$）的鸟相比，它能多飞多远？(c) 给出真实鸟飞不了 (a) 预测那么远的两个原因。
::: solution
(a) 能量 $200\times37 = 7400$ kJ。时间 $= 7.4\times10^6/8.0 = 9.25\times10^5$ s $= 257$ h。距离 $= 257\times60 = 15\,400$ km，即 15.4 千公里。
(b) 水合糖原给出 $4.25\ \mathrm{kJ\,g^{-1}}$，200 g 只支撑 $257/8.71 = 29.5$ h，约 1,770 km——脂肪使航程几乎增加九倍。
(c) 脂肪不能全部动用（有些是结构性的，抵达时必须留有储备）；有些蛋白质也被燃烧；鸟变轻后所需功率下降，但逆风与体温调节会使之升高；相对地面的飞行速度取决于风。这种能量核算经实测飞行动力修正后，确实能在合理范围内预测塍鹬观察到的不降落飞行。
:::

::: exercise 解读糖基化实验 {level=3}
在一次类似 Bunn 与 Higgins（1981）所报告的实验中，血红蛋白与等浓度的不同糖共孵，测定糖-蛋白质加合物的生成速率（以葡萄糖 = 1 的相对值；示例值）：葡萄糖 1、甘露糖 5、半乳糖 5、果糖 7、核糖 30、甘油醛 200。每种糖在平衡时处于开链（羰基）形式的百分比次序与之相同。(a) 什么假说把两组数据联系起来？(b) 对一个终身以约 5 mmol L⁻¹ 在血中循环的糖来说，这一性质为何要紧？(c) 提出一个进一步的实验，检验开链含量（而非别的性质）是否控制速率。
::: solution
(a) 糖基化始于开链羰基与蛋白质氨基反应生成席夫碱。若只有开链形式反应，速率正比于其浓度，所以开链形式多的糖糖基化更快。葡萄糖的 β-吡喃糖环很稳定，使它成为这些糖中开链形式最少的，反应最慢。(b) 糖基化缓慢而不可逆地损伤蛋白质；一种以毫摩尔浓度循环数十年的燃料必须尽可能不活泼，这使葡萄糖优于其他本可同样胜任燃料的糖。(c) 在同一温度直接测量每种糖的开链比例（例如用核磁共振或圆二色），检验每个开链分子的反应速率常数对所有糖是否相同；或比较大小相近但环稳定性不同的糖，如葡萄糖与其 2-脱氧类似物；或用锁定在环式上的修饰糖——它们不应反应。
:::
:::

::: exercise 解读熔点比较 {level=3}
据报道，驯鹿蹄与小腿下部的脂肪熔点低于体核附近的脂肪，且含更多不饱和脂肪酸。用熔点的图，(a) 解释组成如何影响熔点，(b) 解释这种差别为何适应，(c) 提出如何检验它是局部温度的响应还是固定的发育模式。
::: solution
(a) *cis* 双键使链弯折，妨碍它们堆积成固体，每个双键使熔点下降数十度（硬脂酸 70 °C，油酸 13 °C）。链较短者也熔点较低。(b) 站在雪地上的驯鹿，其小腿远离核心温度（逆流交换以保存热量）。饱和脂肪会在那里凝固，使组织僵硬；不饱和脂肪保持流体，使膜与衬垫保持功能。(c) 比较在冷暖条件下饲养动物的组织，或沿腿测量组成并对照实测组织温度；或在合适的动物模型中（经批准的伦理规程下）实验性地加温或冷却某一肢体区域，跟踪脂肪酸组成随时间的变化。对局部温度的响应会指向受调控的去饱和酶表达，正如膜的同黏适应。
:::
