到三羧酸循环终了时，一分子葡萄糖已被彻底拆解：它的六个碳都以 CO₂ 的形式离去，却只造出了四个 ATP（或 GTP）。其余的能量作为电子保存在十个 NADH 与两个 FADH₂ 上。**氧化磷酸化**把这些电子能量转化为 ATP：电子沿线粒体内膜（或细菌质膜）上的一系列载体传递给氧，每一步释放的能量用来把质子泵过膜；质子再流回一台旋转马达——ATP 合酶——由它制造 ATP。这一两阶段的机制——电子建立质子梯度，梯度制造 ATP——就是米切尔（Peter Mitchell）1961 年的化学渗透假说，它最初备受怀疑，如今已是生物学的统一原理之一。同样的机制在叶绿体与几乎所有细菌和古菌中制造 ATP，同样的梯度还驱动物质转运与细菌鞭毛的旋转。

呼吸链的热力学、质子动力势的组成与 ATP 合成的能量收支在[化学图谱：氧化磷酸化与光合作用](/learn/chemistry/lesson.php?c=biochemistry&l=oxidative-phosphorylation)中展开。本章侧重这一机制如何被确立、如何被研究，它在生物之间的差异——ATP 合酶的设计、质子动力势、电子受体——以及生物如何为了产热而有意把它解偶联。

## 呼吸链

1925 年，凯林（David Keilin）用手持分光镜检查昆虫的飞行肌和酵母，看到随组织氧化与脱氧而出现和消失的吸收带：**细胞色素**，一类携带电子的血红素蛋白。Warburg 已把还原氧的"呼吸酶"鉴定为一种被氰化物与一氧化碳抑制的铁-血红素蛋白（1931 年诺贝尔生理学或医学奖）。Eugene Kennedy 与 Albert Lehninger 1949 年用分级分离的大鼠肝证明，三羧酸循环与氧化磷酸化都发生在线粒体中。

::: definition 线粒体呼吸链 {#def-chain}
线粒体的**呼吸链**由内膜上的四个膜蛋白复合体与两个移动载体组成：

- **复合体 I**（NADH-泛醌氧化还原酶）把两个电子从 NADH 交给泛醌（Q），并把 4 个 H⁺ 泵过膜；
- **复合体 II**（琥珀酸脱氢酶，也是三羧酸循环的一个酶）把电子从琥珀酸经 FAD 交给 Q，不泵质子；
- **泛醌**（辅酶 Q）是脂溶性载体，以泛醇（QH₂）形式在膜内扩散，携带两个电子；
- **复合体 III**（细胞色素 $bc_1$）把电子从 QH₂ 交给细胞色素 c，并通过 **Q 循环**每两个电子向膜外侧释放 4 个 H⁺；
- **细胞色素 c** 是膜间隙中一种小的水溶性蛋白，一次只携带一个电子；
- **复合体 IV**（细胞色素 c 氧化酶）把 O₂ 还原为水，每个 O₂ 从基质消耗 4 个 H⁺，再泵出 4 个，即每两个电子泵出 2 个。

每一对电子，NADH 的氧化把约 **10 个 H⁺** 从基质移到膜间隙；琥珀酸的氧化经 Q 进入，移动 **6 个 H⁺**。
:::

各复合体按还原电位升序排列，从 NAD⁺/NADH（$E^{\circ\prime} = -0.32$ V）到 O₂/H₂O（$+0.82$ V），所以电子自发"下坡"流动，每氧化一摩尔 NADH 释放约 220 kJ。复合体 I、III 与 IV 会聚成**超复合体**（"呼吸体"），2010 年代以来可用冷冻电子显微镜看到，但它们对功能究竟有多大意义仍在争论。

该链部分由线粒体自己的基因组编码。人线粒体 DNA 长 16 569 个碱基对，编码 13 种蛋白质——全部是复合体 I、III、IV 与 ATP 合酶的亚基——外加翻译它们所需的 rRNA 与 tRNA；其余成分——70 多个亚基——由细胞核编码并输入（[[cell-biology/organelles]]、[[cell-biology/protein-sorting]]）。这种双重遗传控制是线粒体细菌祖先的遗产，也是线粒体疾病既可按母系遗传、也可按孟德尔方式遗传的原因（[[genetics/non-mendelian-inheritance]]）。

## 化学渗透假说

整个 1950 年代，生物化学家都在寻找一种"高能中间物"——一种磷酸化的化合物，类似糖酵解中的 1,3-二磷酸甘油酸，会把电子传递与 ATP 合成连接起来。一无所获。米切尔在 1961 年提出：并不存在这样的化合物；联系的纽带是质子跨一层对其不透性的膜形成的梯度。

::: proposition 质子动力势 {#prop-pmf}
质子梯度中储存的自由能以**质子动力势** $\Delta p$（以伏计）表示，即 H⁺ 的单位电荷的电化学势差。对从正电侧（P，外侧）流向负电侧（N，基质或细胞质）的质子，

$$
\Delta p = \Delta\psi + \frac{2.303\,RT}{F}\,\Delta\mathrm{pH},
$$ {#eq-pmf}

其中 $\Delta\psi = \psi_\mathrm{P} - \psi_\mathrm{N}$ 是膜电位（线粒体为外正），$\Delta\mathrm{pH} = \mathrm{pH}_\mathrm{N} - \mathrm{pH}_\mathrm{P}$；37 °C 时 $2.303RT/F = 61.5$ mV。一摩尔质子流回所释放的自由能为 $F\Delta p$。（这就是 [[cell-biology/membrane-transport#eq-dg-ion]] 对 H⁺ 的情形；各书的符号约定不同——这里当梯度能够驱动 ATP 合成时 $\Delta p$ 为正。）
:::

该理论做出了可检验的预言：膜必须完整而封闭；电子传递必须泵质子；人工强加的梯度应在没有电子传递的情况下驱动 ATP 合成；任何使膜对质子渗漏的东西都应把呼吸与磷酸化**解偶联**。每一条都得到了证实。

- **解偶联剂。** 脂溶性弱酸如 2,4-二硝基苯酚（DNP）与碳酰氰基对三氟甲氧基苯腙（FCCP）携带质子穿过膜，使 ATP 合成消失而呼吸加速——若它们使梯度短路，这正是预期的，此外很难解释，因为它们除携带质子的能力外毫无共同结构。
- **酸浴实验。** André Jagendorf 与 Ernest Uribe（1966）在暗处把菠菜叶绿体类囊体浸在 pH 4 的介质中，使其腔内达到 pH 4，然后迅速转入含 ADP 与磷酸的 pH 8 介质。它们造出了 ATP——在暗处，没有电子传递——完全由强加的 pH 梯度驱动。
- **重组实验。** Efraim Racker 与 Walther Stoeckenius（1974）构建了含两种互不相关生物的蛋白的人工脂质囊泡：来自古菌 *Halobacterium salinarum*（盐生盐杆菌）的光驱动质子泵细菌视紫红质，以及牛心线粒体的 ATP 合酶。照光后，囊泡制造了 ATP。这两种蛋白能共享的东西只有质子梯度。

米切尔晚年的大部分工作是在康沃尔郡一栋修缮老宅里的私人实验室完成的，他获得了 1978 年诺贝尔化学奖。

::: example 三种膜上的质子动力势 {#ex-pmf}
用 [[#eq-pmf]] 计算 37 °C 下的 $\Delta p$：(a) 一个进行呼吸的线粒体，$\Delta\psi = 160$ mV、$\Delta\mathrm{pH} = 0.75$；(b) 一个照光的叶绿体类囊体，$\Delta\psi = 10$ mV，腔内比基质酸 2.5 个 pH 单位；(c) 一种嗜碱菌 *Bacillus pseudofirmus*，在外部 pH 10.5 下生长，细胞质 pH 8.2，$\Delta\psi = 180$ mV（代表性数值）。
::: solution
(a) $160 + 61.5\times0.75 = 160 + 46 = 206$ mV，以电位为主。

(b) $10 + 61.5\times2.5 = 10 + 154 = 164$ mV，几乎全是 ΔpH。叶绿体让 Cl⁻ 与 Mg²⁺ 移动以消散电位，所以梯度以 pH 形式储存。

(c) 这里细胞质比外侧*更酸*，所以 $\Delta\mathrm{pH} = 8.2 - 10.5 = -2.3$，pH 项对抗 ATP 合成：$180 + 61.5\times(-2.3) = 180 - 141 = 39$ mV。然而这种细菌仍靠氧化磷酸化生长。嗜碱菌如何在如此小的总体质子动力势下制造 ATP——也许是让质子沿膜表面移动，或是其 ATP 合酶有所适应——是一个长期悬而未决的难题（Terry Krulwich 及同事对此做了重要研究）。许多嗜碱菌还用钠动力势进行转运与驱动鞭毛。
:::
:::

## ATP 合酶：一台旋转马达

利用质子梯度的酶 F₁F₀-ATP 合酶由两部分组成。膜内的 **F₀** 含一个 $c$ 亚基环与一个 **a** 亚基，两者共同构成质子的通路；伸入基质的 **F₁** 含三个催化 β 亚基与三个 α 亚基相间环绕中央柄——γ 亚基，它与 c 环相连。

1970 年代，Boyer 从同位素交换实验提出，三个催化部位轮流经过三种状态——开放、疏松与紧密——而梯度的能量不是用于形成 ATP（ATP 在紧密部位自发形成），而是用于把它释放：这就是**结合变构机制**。Walker 的牛 F₁ 晶体结构（J. P. Abrahams 及同事，1994）显示三个 β 亚基处于三种不同的构象，环绕一个不对称的 γ 亚基，正是 Boyer 的模型所要求的。1997 年，Hiroyuki Noji、Masasuke Yoshida、Kazuhiko Kinosita 及同事把一根荧光肌动蛋白丝接到嗜热芽孢杆菌 *Bacillus* 的 F₁ 的 γ 亚基上，把 α₃β₃ 环固定在玻璃表面，在显微镜下观察水解 ATP 时这根丝的旋转——逆时针，步长 120°。Boyer 与 Walker 分享 1997 年诺贝尔化学奖（与因钠泵获奖的 Jens Skou 共同）。

在合成方向，质子从 P 侧进入并结合到 c 亚基上，环转动，质子从 N 侧离开；转动的 γ 亚基迫使每个 β 亚基走完它的一轮循环。环每转一圈生成三个 ATP——每个 β 亚基一个——并需要与 c 亚基数同样多的质子。

::: proposition ATP 的质子代价 {#prop-stoich}
若某 ATP 合酶的 c 环有 $n$ 个亚基、每个亚基每转结合一个质子，则合成一个 ATP 需有 $n/3$ 个质子通过 F₀。在线粒体中，把 ATP 输出并把 ADP 与磷酸输入，每个 ATP 约再花一个质子（ATP/ADP 转位酶是致电的，磷酸与质子一起进入）。于是每对电子交给氧所合成的 ATP 数（**P/O 比**）为

$$
\text{P/O} = \frac{H^+_\text{pumped}}{n/3 + 1},
$$ {#eq-po}

其中线粒体内 NADH 的 $H^+_\text{pumped} = 10$，琥珀酸为 6。假设：泵与合酶完美偶联、没有质子漏，且泵的化学计量如所述。
:::

c 环的大小并不固定。脊椎动物线粒体为 8（牛 ATP 合酶，I. N. Watt 及同事，2010），酵母线粒体与 *E. coli* 为 10，细菌 *Ilyobacter tartaricus* 的钠驱动 ATP 合酶为 11，菠菜叶绿体为 14，蓝细菌 *Arthrospira*（螺旋藻 *Spirulina*）为 15；有些细菌的环更大。每种环大小都设定了质子与 ATP 之间不同的"齿比"：小环以较少的质子造出 ATP，但每一步需要更大的质子动力势；大环能在较弱的力下工作，代价是花更多的质子。

::: example 不同生物每个 NADH 的 ATP {#ex-po}
用 [[#eq-po]] 计算 (a) 牛线粒体（$n = 8$）与 (b) 酵母线粒体（$n = 10$）中 NADH 的 P/O 比。(c) 在叶绿体中，ATP 直接在基质中合成，无需输出。$n = 14$ 时每个 ATP 花多少质子？
::: solution
(a) $n/3 = 2.67$，加上转运的 1：每个 ATP 3.67 个 H⁺；P/O $= 10/3.67 = 2.73$。
(b) $10/3 + 1 = 4.33$ 个 H⁺ 每个 ATP；P/O $= 10/4.33 = 2.31$。
(c) $14/3 = 4.67$ 个 H⁺ 每个 ATP，没有转运代价。
动物线粒体中 NADH 连接底物的实测 P/O 比约为 2.5，琥珀酸约为 1.5，略低于理论的 2.73 与 1.64，因为一些质子漏回。这些非整数值一度颇有争议，如今由化学渗透机制自然推出；旧教材的 3 与 2 假设了整数的化学计量。按 2.5 与 1.5 计，一分子葡萄糖完全氧化约得 30–32 个 ATP（具体账目在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=oxidative-phosphorylation)中算）。
:::
:::

## 氧化磷酸化的测定

我们知道的许多内容来自一台简单的仪器：克拉克（Leland Clark）发明的**氧电极**（1956），它测量装有分离线粒体的搅拌槽中溶解 O₂ 的浓度。Britton Chance 与 G. R. Williams（1955）定义了标准的实验状态。

::: definition 呼吸状态、呼吸控制比与 P/O 比 {#def-states}
在以分离线粒体与可氧化底物进行的氧电极实验中，**状态 3** 是加入 ADP 后随之而来的快速呼吸，此时正在制造 ATP；**状态 4** 是 ADP 全部转为 ATP 之后较慢的呼吸，仅由质子漏回膜支撑。**呼吸控制比**（RCR）是状态 3 与状态 4 速率之比；高值（常为 4–10）表明线粒体偶联良好。**P/O 比**是状态 3 期间被磷酸化的 ADP 量与消耗的氧*原子*量之比。
:::

呼吸控制是化学渗透偶联在细胞层面的表现。当 ATP 有需求时，ADP 上升，ATP 合酶让质子流入，质子动力势略降，电子传递（本来受梯度的回压抑制）随之加速。需求下降时，梯度积累并使链减速。于是呼吸自动跟随 ATP 的使用，无须任何单独的信号。

::: example 解读氧电极记录 {#ex-electrode}
以谷氨酸加苹果酸呼吸的大鼠肝线粒体，在加入 ADP 之前以 20 nmol O₂ min⁻¹ 消耗 O₂。加入 250 nmol ADP 后，呼吸升至 120 nmol O₂ min⁻¹，在速率回落到 20 nmol O₂ min⁻¹ 之前共消耗 46 nmol O₂。计算 RCR 与 P/O 比，并说出加入 (a) 寡霉素、(b) 解偶联剂、(c) 氰化物后各会怎样。
::: solution
RCR $= 120/20 = 6.0$，是良好制备的典型值。P/O $= 250\ \text{nmol ADP}/(2\times46\ \text{nmol O}) = 250/92 = 2.72$——接近 NADH 连接底物的理论值（[[#ex-po]]）。（严格说，应先减去 ADP 爆发期间因漏所耗的氧，那会使 P/O 略升。）
(a) 寡霉素阻断 ATP 合酶的质子通道：状态 3 的呼吸降到状态 4 的速率，因为质子不能再经合酶流入。
(b) 解偶联剂使膜对质子渗漏：即使没有 ADP，呼吸也升到最大，且不制造任何 ATP。
(c) 氰化物阻断复合体 IV：无论再加什么，呼吸完全停止。按顺序使用这类抑制剂，可把细胞的呼吸剖析为 ATP 相关、漏与最大三部分——这正是现代活细胞胞外通量测定的基础。
:::
:::

经典的抑制剂及其作用部位是每个生物能量学实验室的工具：鱼藤酮（一种植物源杀虫剂）阻断复合体 I；抗霉素 A（来自 *Streptomyces*）阻断复合体 III；氰化物、叠氮化物与一氧化碳阻断复合体 IV；寡霉素阻断 F₀；苍术苷（来自蓟属植物）与米酵菌酸（来自细菌）阻断 ATP/ADP 转位酶。其中许多是生物用以对付竞争者与捕食者的天然毒素，这就是它们如此剧烈的原因。

## 为产热而解偶联

漏掉的质子梯度产生热而不是 ATP。生物已一再进化出有意这样做的办法。

### 棕色脂肪组织

**棕色脂肪组织**（BAT）挤满了线粒体（其细胞色素给了它颜色），是小型哺乳动物、从蛰伏中醒来的冬眠者和新生儿（包括人类婴儿）的加热器。它的线粒体内膜含有**解偶联蛋白 1**（UCP1，产热素），1970 年代由 David Nicholls 及同事与 Daniel Ricquier 鉴定，是一种载体，在交感神经刺激下由释放出的脂肪酸激活，让质子流回基质。于是链全速运转、氧化脂肪，能量以热的形式出现——**非战栗产热**。UCP1 存在于大多数胎盘哺乳动物，但已在若干谱系中独立失活，包括猪（J. Berg 及同事，*PLoS Genetics* 2, e129, 2006）——其仔猪出了名的怕冷——以及马、象与鲸（M. J. Gaudry 及同事，2017）；鸟类没有它，靠战栗与其他机制取暖。成年人在某些脂肪库中保留有活性的 BAT，2009 年正电子发射显像揭示了这一点，这一发现正在代谢研究中被深入研究（[医学图谱：内分泌](/learn/medicine/course.php?c=endocrine)）。

::: warning "解偶联剂是一种安全燃脂的办法"
2,4-二硝基苯酚在 1930 年代初曾被当作减肥药销售，因为它解偶联氧化磷酸化，能提高代谢率、燃烧脂肪。但它在引发不受控的高热的同时，也造成了白内障与许多死亡：化学性质子载体上没有恒温器，UCP1 却由神经系统开开关关。1938 年它在美国被撤市。受调控的生理性解偶联与不受调控的化学性解偶联之别正是要害；其临床毒理学属于[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)。
:::

### 会发热的花

植物有第二条产热之路。除了复合体 III 与 IV，植物线粒体还有一种**交替氧化酶**（AOX），把电子从泛醇直接交给 O₂，绕过两个泵质子的部位；它对氰化物不敏感。在寻常组织中，AOX 被认为充当安全阀，防止胁迫下链的过度还原。在一些花里，它制造热。巫毒百合（*Sauromatum guttatum*）的花序在开放当天升温超过 10 °C，使发臭的化合物挥发，吸引食腐昆虫来传粉；触发因素是水杨酸（I. Raskin 及同事，*Science* 237, 1601, 1987）。东方臭菘（*Symplocarpus foetidus*）在冬末空气接近或低于冰点时，把花序温度维持在 15–22 °C 达数周之久（R. M. Knutson，1974），莲（*Nelumbo nucifera*）则在很大范围的气温中把花温调在约 30 到 35 °C 之间，是真正的体温调节（R. S. Seymour 与 P. Schultze-Motel，*Nature* 383, 305，1996）。热有多少来自 AOX、有多少来自解偶联蛋白，因物种而异。

::: example 一朵莲花的功率 {#ex-lotus}
一朵莲在凉爽的夜晚调节温度时约产生 1.0 W 的热。若全部来自呼吸，这朵花每分钟必须消耗多少 O₂（20.1 kJ L⁻¹ O₂）？与静息成人 84 W 对应 250 mL min⁻¹ 相比较。
::: solution
$1.0\ \mathrm{J\,s^{-1}}\times60\ \mathrm{s} = 60$ J 每分钟 $= 0.060$ kJ，故 $0.060/20.1 = 0.0030$ L $= 3.0$ mL O₂ min⁻¹。按瓦特计，花与成人完全相同（$250/84 = 3.0$ mL min⁻¹ W⁻¹），本来就必须如此：呼吸产生的热只取决于燃料与消耗的 O₂。这朵花的花托只有几十克重，所以它的比质量呼吸速率可与小型飞行动物相比——这就是产热花的呼吸速率位居已测植物最高之列的原因。
:::
:::

## 无氧呼吸

线粒体使用 O₂，但呼吸——电子传递与质子（或钠）梯度偶联——远比大气氧古老。细菌与古菌用许多电子受体进行呼吸，可得的能量取决于供体与受体在还原电位标尺上相距多远。

| 受体电对 | $E^{\circ\prime}$ (V) | 生物（实例） |
|---|---|---|
| O₂/H₂O | +0.82 | 需氧生物、线粒体 |
| NO₃⁻/NO₂⁻ | +0.42 | *E. coli*、*Paracoccus* 等反硝化细菌 |
| Fe³⁺/Fe²⁺（铁矿物） | 约 0 到 +0.2，取决于矿物 | *Geobacter*、*Shewanella* |
| 延胡索酸/琥珀酸 | +0.03 | *E. coli*、寄生蠕虫 |
| SO₄²⁻/HS⁻ | −0.22 | *Desulfovibrio* |
| CO₂/CH₄ | −0.24 | 产甲烷古菌 |

::: example 每种受体给出多少能量？ {#ex-acceptors}
用 $\Delta G^{\circ\prime} = -nF\Delta E^{\circ\prime}$，取 $n = 2$，计算一对电子从 NADH（$E^{\circ\prime} = -0.32$ V）传给 O₂、传给硝酸根与延胡索酸所释放的标准自由能，以及从 H₂（$E^{\circ\prime} = -0.41$ V）传给硫酸盐。并与细胞中合成一个 ATP 所需的约 50 kJ mol⁻¹ 相比较。
::: solution
$\Delta G^{\circ\prime} = -2\times96.5\times\Delta E^{\circ\prime}$ kJ mol⁻¹：

- NADH → O₂：$\Delta E = 1.14$ V，$-219$ kJ mol⁻¹；
- NADH → 硝酸根：$\Delta E = 0.74$ V，$-143$ kJ mol⁻¹；
- NADH → 延胡索酸：$\Delta E = 0.35$ V，$-68$ kJ mol⁻¹；
- H₂ → 硫酸盐：$\Delta E = 0.19$ V，$-38$ kJ mol⁻¹。

氧每对电子约支撑四个 ATP 当量，硝酸根近三个，延胡索酸约一个，H₂ 还原硫酸盐不足一个——这就是硫酸盐还原菌与产甲烷菌生长缓慢、生活在热力学极限边缘的原因，也是化学渗透机制对其进化必不可少的原因，因为它能把一次电子传递偶联到 ATP 的几分之一。表的顺序也是在湖底沉积物或积水土壤中越往下受体被消耗尽的顺序：先氧，再硝酸根、铁与锰，再硫酸盐，最后是 CO₂（[[microbiology/microbial-metabolism]]、[[ecology]]）。
:::
:::

::: quiz
以琥珀酸呼吸的分离线粒体，先给 ADP，再依次给寡霉素与 FCCP。每一步氧消耗如何变化？
- [ ] ADP：下降；寡霉素：上升；FCCP：停止。
- [x] ADP：上升；寡霉素：回落到漏速率；FCCP：升到最大速率。
- [ ] ADP：不变；寡霉素：停止；FCCP：不变。
- [ ] ADP：上升；寡霉素：再上升；FCCP：停止。
::: solution
ADP 给出状态 3 呼吸。寡霉素阻断 ATP 合酶的质子通道，质子回到内侧的唯一路径是漏，呼吸减慢到状态 4 速率。FCCP 为质子跨膜开了一条新通道，使梯度消散；链摆脱回压，以最大速率运转，尽管不能制造任何 ATP。
:::
:::

::: application 活性氧
呼吸链中一小部分电子直接与 O₂ 反应生成超氧化物，主要在复合体 I 与 III，尤其在链高度还原、质子动力势高时。超氧化物及由它生成的过氧化氢是**活性氧**（ROS），会损伤脂类、蛋白质与 DNA，但也充当信号。早期的估计认为消耗的氧有 1–2 % 变成超氧化物，如今认为对活细胞中的线粒体高得太多；较近的估计低约一个数量级，且强烈依赖条件（M. D. Brand，2010）。轻度解偶联通过降低质子动力势来减少 ROS 的产生，这是 UCP 同源物在非产热组织中的一种可能功能。ROS 在衰老中的作用，一度是"自由基学说"的核心，如今被认为比最初设想的复杂得多。
:::

::: history
凯林于 1925 年描述了细胞色素；到 1928 年 Warburg 把呼吸酶鉴定为铁-血红素蛋白。Vladimir Engelhardt（1930）与 Herman Kalckar（1937）证明呼吸与磷酸化偶联，Severo Ochoa（1940）测定了 P/O 比。Kennedy 与 Lehninger 于 1949 年把氧化磷酸化定位到线粒体。Chance 与 Williams 于 1955 年定义了呼吸状态。米切尔于 1961 年提出化学渗透；Jagendorf 与 Uribe 的酸浴实验（1966）与 Racker 与 Stoeckenius 的重组实验（1974）支持了它，米切尔于 1978 年获诺贝尔奖。Boyer 的结合变构机制（1970 年代）、Walker 的 F₁ 结构（1994）与 Noji 及同事对旋转的观察（1997）解释了 ATP 合酶。大型呼吸复合体中最后一个——复合体 I——的结构由 Leonid Sazanov 的实验室于 2013–16 年完成。
:::

## 由此走向何处

这里制造的 ATP 支撑着本课程的其余一切；它的产生如何与各种组织的燃料供应相协调、不同燃料各产出多少 ATP，是 [[biochemistry/metabolic-integration]] 的主题。光合作用中的化学渗透——光驱动的电子传递、Z 方案与光合磷酸化——在 [[plant-biology/photosynthesis]] 中展开，线粒体的演化起源在 [[cell-biology/organelles]]。

::: summary
- 呼吸链（复合体 I–IV、泛醌、细胞色素 c）把电子从 NADH（$-0.32$ V）传给 O₂（$+0.82$ V），每 NADH 泵约 10 H⁺，每琥珀酸 6 个。
- 化学渗透（米切尔，1961）：质子动力势 $\Delta p = \Delta\psi + 61.5\,\Delta\mathrm{pH}$ mV 把电子传递偶联到 ATP 合成；由解偶联剂、酸浴实验与细菌视紫红质-ATP 合酶重组实验证实。
- 线粒体把 $\Delta p$（约 200 mV）主要以 $\Delta\psi$ 储存，叶绿体主要以 ΔpH 储存；嗜碱菌在总体 $\Delta p$ 仅约 40 mV 下生长。
- ATP 合酶是一台旋转马达（结合变构，Boyer；结构，Walker；1997 年观察到旋转）；$n$ 个 c 亚基时，每个 ATP 花 $n/3$ 个质子，输出再加 1 个；8–15 个亚基的 c 环给出因物种而异、非整数的 P/O 比（NADH 约 2.5，琥珀酸 1.5）。
- 氧电极测量状态 3 与状态 4、呼吸控制比与 P/O 比；抑制剂（鱼藤酮、抗霉素、氰化物、寡霉素、苍术苷）与解偶联剂可把链剖析开来。
- 受调控的解偶联产生热：胎盘哺乳动物棕色脂肪中的 UCP1，产热花中的交替氧化酶。
- 细菌与古菌用硝酸根、铁、延胡索酸、硫酸盐与 CO₂ 呼吸；受体的还原电位越低，每对电子可得的能量越少。
:::

::: exercise 琥珀酸的 P/O {level=1 check="1.64"}

::: exercise 梯度够强吗？ {level=2 check="2.59"}
线粒体中合成 ATP 约需 50 kJ mol⁻¹。若 $\Delta p = 200$ mV，至少需要多少个质子流回才能提供这一能量（三位有效数字）？与牛 F₀ 每个 ATP 的 2.67 个质子比较。
::: solution
每个质子提供 $F\Delta p = 96.485\times0.200 = 19.3$ kJ。最少 $= 50/19.3 = 2.59$ 个质子。$n = 8$ 时 F₀ 用 2.67 个，刚好够用——这与"最小的 c 环属于维持大质子动力势的生物"这一想法一致。
:::

::: exercise 一次氧电极实验 {level=2 check="1.47"}
以琥珀酸（加有鱼藤酮）呼吸的线粒体加入 200 nmol ADP；状态 3 呼吸爆发期间消耗 68 nmol O₂。P/O 比是多少（三位有效数字）？这一数值与理论一致吗？
::: solution
P/O $= 200/(2\times68) = 200/136 = 1.47$。牛线粒体的理论值是 1.64；实测略低，正是质子漏所预期的，且接近公认的 1.5。加鱼藤酮是为了阻断复合体 I，使琥珀酸（经延胡索酸与苹果酸）生成的 NADH 不致有所贡献。
:::
:::

::: exercise 新生儿的产热 {level=2}
一步一步解释：交感神经释放的去甲肾上腺素激活 UCP1，如何提高棕色脂肪组织的产热。为什么 ATP 合成下降时呼吸反而增加而不是停止？为什么棕色脂肪细胞还必须动用自己的脂肪库？
::: solution
去甲肾上腺素结合 β-肾上腺素能受体，升高 cAMP 并激活蛋白激酶 A，后者激活脂肪分解（激素敏感性脂肪酶等）。释放的脂肪酸激活 UCP1，让质子流回基质。质子动力势下降；因为呼吸本来受梯度回压的抑制（呼吸控制），链便加速、更快地氧化底物，原本用于制造 ATP 的自由能以热的形式释放。脂肪必须动员，因为它既是激活 UCP1 的信号，又是燃料（经 β氧化，[[biochemistry/metabolic-integration]]），以所需的高速率供应 NADH 与 FADH₂。
:::
:::

::: exercise 选择抑制剂 {level=2}
一位研究者想知道某细胞系氧消耗中 (a) 多少用于制造 ATP、(b) 多少源于质子漏、(c) 多少根本不经过线粒体、(d) 多少是链的备用容量。设计一套向测氧体系中的细胞依次加入的物质，并说明每个量如何计算。
::: solution
测量基础呼吸。加寡霉素：呼吸的下降量即 ATP 相关呼吸（a）；其余的线粒体呼吸在扣除（c）后是漏（b）。加解偶联剂（FCCP），滴定到给出最大速率的浓度：最大呼吸与基础呼吸之差是备用容量（d）。最后加鱼藤酮加抗霉素 A（或氰化物）阻断线粒体电子传递：残余的氧消耗是非线粒体的（c），来自其他氧化酶，要从其他各量中扣除。
:::
:::

::: exercise 解读 c 环的多样性 {level=3}
c 环的大小从 8（脊椎动物线粒体）到 15 甚至更大（一些蓝细菌与细菌）。(a) 用 [[#prop-stoich]] 与 ATP 合成的能量学，解释给定环大小所代表的权衡。(b) 叶绿体 $n = 14$，却产生与线粒体相近的质子动力势。它们的 ATP 合酶以每个 ATP 更高的质子代价运转；试问这为何有利。(c) 如何从实验上检验环大小是否由 c 亚基序列本身决定？
::: solution
(a) 每个 ATP 的自由能是固定的（活细胞内约 50 kJ mol⁻¹），但每个质子只提供 $F\Delta p$。小环（每个 ATP 的质子少）每个质子产 ATP 多，但只有当 $\Delta p$ 大到 $n/3$ 个质子能供 50 kJ 时才能工作；大环能在较小的 $\Delta p$ 下合成 ATP（更多质子分担工作），但产量较低。环大小因而把合酶调到生物所能维持的质子动力势、以及质子与 ATP 何者更为紧缺上。
(b) 叶绿体中，光充足时光驱动的电子传递大量供应质子，每个质子的产量就无足轻重了；大环让 ATP 合成能在较低的 ΔpH 下进行，这保护了光合机构（腔内过酸会损伤光系统 II，并用作启动光保护的信号），还改变了线性电子传递所产生 ATP 与 NADPH 之比——这一比值必须与卡尔文-本森循环所需的 3:2 相配，环式电子传递可助一臂之力（[[plant-biology/photosynthesis]]）。
(c) 在宿主中或在体外表达具有不同环大小生物的 c 亚基基因，或嵌合体与点突变体（尤其是相邻 c 亚基之间堆积残基的突变），再通过完整环的质谱或结构测定来确定装配后转子的环化学计量。这类研究表明，c 亚基序列在很大程度上决定环大小。
:::
:::

::: exercise 解读沉积物剖面 {level=3}
湖底沉积物的孔隙水测量显示，O₂ 在顶部几毫米内消失，硝酸根在顶部 1–2 cm 消失，随后 Fe²⁺ 出现，硫酸盐在 5 到 20 cm 之间下降，甲烷在约 20 cm 以下上升。(a) 用 [[#ex-acceptors]] 的能量产率解释这一序列。(b) 为什么硫酸盐还原在产甲烷开始之前停止，尽管两者都利用有机物中与 CO₂ 处于同一水平的电子？(c) 这对微生物类群之间的竞争说明了什么？若加入硫酸盐，剖面会怎样？
::: solution
(a) 有机物被微生物氧化，用的是产能最多的受体。氧产能最多，在近表面最先被消耗；一旦消失，硝酸根还原者胜过其他类群；然后是铁与锰还原者；再是硫酸盐还原者；只有硫酸盐耗尽后产甲烷菌才占优势，以 CO₂（与乙酸）为受体。(b) 硫酸盐还原者从 H₂ 或乙酸每对电子得到的能量多于产甲烷菌，所以能在更低的 H₂ 浓度下生长，把 H₂ 压在产甲烷菌所需的阈值之下；产甲烷只在硫酸盐带以下接管。(c) 这一序列反映的是基于热力学的竞争排斥：哪一类群能在最低的底物浓度下合成 ATP 就获胜。加入硫酸盐（如海水侵入淡水湿地时发生的那样）会把硫酸盐还原带延伸到更深处并抑制甲烷的产生——这一效应已在与湿地温室气体排放有关的研究中被考察过。
:::
:::
