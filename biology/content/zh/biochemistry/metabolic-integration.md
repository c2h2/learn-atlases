动物一天只进食几次，但它的脑每一秒都需要葡萄糖。一只候鸟不进食连飞一周。一只冬眠的地松鼠靠贮存的脂肪生活数月，体温接近冰点，每隔两周左右醒来复温。玉米植株在一种细胞中固定碳，在另一种细胞中把它变成糖；仙人掌只在夜间打开气孔。每一种情况下，代谢都不是一组彼此分离的途径，而是一个单一整合的系统，分工于特化、贮存并交换燃料的组织与器官（或细胞类型，或一天中的不同时间），由激素与神经协调。本章把本课程的各条途径合到一起。

我们先讲两条尚未详细讨论的途径——脂肪酸的氧化与合成，以及氨基酸的分解代谢连同其氮的处置——仍像此前那样从生物学家的一侧对待；它们的化学（β氧化、酮体生成、脂肪酸合酶、转氨作用与尿素循环）在[化学图谱：脂质与氮代谢](/learn/chemistry/lesson.php?c=biochemistry&l=lipid-nitrogen-metabolism)中。然后我们跟随一只哺乳动物经历进食、禁食与饥饿，看看具有极端需求的生物如何管理自己的燃料，最后以 C4 与 CAM 植物中光合代谢跨细胞的整合收尾。

## 脂肪酸：分解与合成

贮存在脂肪组织中的三酰甘油（[[biochemistry/carbohydrates-lipids]]）被脂肪酶动员，释放出的脂肪酸进入血液，与血清白蛋白结合运输。在骨骼肌、心肌、肝与许多其他组织中，脂肪酸在细胞质中被活化为脂酰辅酶A，经**肉碱穿梭**进入线粒体（外膜上的肉碱棕榈酰转移酶 I，CPT1，是受控步骤），并被**β氧化**拆解：每一轮以乙酰辅酶A 的形式移去两个碳，并各产生一个 FADH₂ 与一个 NADH。棕榈酸（16:0）完全氧化约得 106 个 ATP——每碳 6.6 个，而葡萄糖为每碳 5.3 个（[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=lipid-nitrogen-metabolism)）。

脂肪酸由另一条途径在另一个隔室中合成。来自线粒体的柠檬酸在细胞质中裂解为乙酰辅酶A，乙酰辅酶A 羧化酶（ACC）把它转变为丙二酰辅酶A——这是定趋步骤——脂肪酸合酶再以七轮缩合与还原、消耗 NADPH 造出棕榈酸（[[biochemistry/bioenergetics#ex-nadph]]）。

::: definition 脂肪酸合成与氧化的互反调控 {#def-malonyl}
**丙二酰辅酶A**是脂肪酸合成的第一个中间物，是**肉碱棕榈酰转移酶 I**的别构抑制剂，即准许长链脂肪酸进入线粒体氧化的那个酶（J. D. McGarry、G. P. Mannaerts 与 D. W. Foster，1977）。当乙酰辅酶A 羧化酶有活性时——如在胰岛素影响下进食糖类之后——丙二酰辅酶A 上升，脂肪酸合成进行而氧化被阻断，新造的脂肪酸便不会立即被烧掉。当 ACC 被磷酸化失活时（被 AMP 激活的蛋白激酶，或在胰高血糖素作用下的蛋白激酶 A），丙二酰辅酶A 下降，氧化被放开。
:::

这是一条一般的设计原理：相反的途径在空间或时间上分开，由同一批信号互反调控，于是细胞不会全速运转无效循环（[[biochemistry/enzyme-regulation]]）。Philip Randle 及同事（1963）展示了燃料之间的第二种相互作用：脂肪酸丰富时，它们在心肌与骨骼肌中的氧化抬高乙酰辅酶A、NADH 与柠檬酸，后者抑制丙酮酸脱氢酶与磷酸果糖激酶，于是组织烧脂肪而省葡萄糖——**葡萄糖-脂肪酸循环**。

### 正在燃烧哪种燃料？呼吸商

不同的燃料每产生一个 CO₂ 需要不同的氧量，因为它们所含氧的比例不同。这给了生理学家一种办法：测量呼吸，就能看出动物在使用哪种燃料。

::: proposition 呼吸商 {#prop-rq}
**呼吸商**RQ 是某燃料完全氧化时产生的 CO₂ 与消耗的 O₂ 之比（以摩尔或体积计）。由配平的方程，

$$
\mathrm{C_6H_{12}O_6} + 6\,\mathrm{O_2} \to 6\,\mathrm{CO_2} + 6\,\mathrm{H_2O}\ \ (\mathrm{RQ} = 1.00),\qquad
\mathrm{C_{16}H_{32}O_2} + 23\,\mathrm{O_2} \to 16\,\mathrm{CO_2} + 16\,\mathrm{H_2O}\ \ (\mathrm{RQ} = 16/23 = 0.70).
$$ {#eq-rq}

典型值为：糖类 1.0，脂肪约 0.70，蛋白质约 0.8（其氮以尿素排出）。整体动物的 RQ 在 0.7 到 1.0 之间表示混合物。假设：稳态，即肺或鳃处交换的气体反映组织处交换的气体（过度通气、酸碱变化与以碳酸氢根形式贮存 CO₂ 都会破坏这一假设），且完全氧化（由糖类净合成脂肪会使 RQ 高于 1）。
:::

::: example 燃料配比的分割 {#ex-rq}
一名静息者的非蛋白 RQ（按尿氮对蛋白质氧化作了校正后）为 0.85。用于氧化糖类的氧占几分之几？来自糖类的能量占几分之几？糖类与脂肪分别取 RQ = 1.00 与 0.696、每升 O₂ 21.1 与 19.6 kJ。
::: solution
设 $f$ 为用于糖类的 O₂ 分数。则 $1.00f + 0.696(1-f) = 0.85$，所以 $f = (0.85 - 0.696)/0.304 = 0.507$。来自糖类的能量 $= 21.1f/[21.1f + 19.6(1-f)] = 10.69/(10.69 + 9.67) = 0.525$。两种燃料各约提供一半能量。过夜禁食后 RQ 通常接近 0.8（更多脂肪）；剧烈运动时接近 1.0（主要是肌肉糖原）；冬眠哺乳动物接近 0.7（几乎纯脂肪）。
:::
:::

::: widget plot

x: 0.696, 1
y: 0, 1

caption: 燃料利用对非蛋白呼吸商（横轴）的曲线，依据 [[#prop-rq]]：氧中用于氧化糖类的比例（直线）与糖类提供的能量比例（曲线），糖类与脂肪分别用每升 O₂ 21.1 与 19.6 kJ。竖线是 [[#ex-rq]] 中 0.85 的 RQ。因为两种燃料每升 O₂ 释放的能量相近，两条曲线几乎重合；仅凭 RQ 就能较好地估计燃料配比。
:::

RQ 高于 1.0 出现在糖类转变为脂肪时，这不消耗 O₂ 而把富氧的碳作为 CO₂ 释放。育肥的鹅与鸭、启程前加油的候鸟都显示远高于 1 的 RQ；准备过冬的冬眠动物也一样。

## 氨基酸与氮的问题

蛋白质合成用不到的氨基酸不能贮存，于是被分解。多数氨基酸的第一步是**转氨作用**：依赖磷酸吡哆醛的转氨酶把氨基转给 α-酮戊二酸，生成谷氨酸。谷氨酸脱氢酶随后释放氨，碳骨架则进入中心途径——作为丙酮酸、草酰乙酸、α-酮戊二酸、琥珀酰辅酶A 或延胡索酸（**生糖**氨基酸，能为糖异生提供碳），或作为乙酰辅酶A 与乙酰乙酸（**生酮**；哺乳动物中只有亮氨酸与赖氨酸纯属生酮）。

氨才是问题。氨（NH₃/NH₄⁺）有毒：哺乳动物血液中低至零点几毫摩尔每升就扰乱脑功能。动物以三种主要方式解决了摆脱它的难题，而选择反映了水的可得性、发育与演化历史。

::: definition 排氮策略 {#def-nitrogen}
**排氨动物**主要以氨排氮：造它便宜，但必须随大量水迅速带走——多数水生无脊椎动物、真骨鱼类与水栖两栖类的幼体经鳃或皮肤把它散失掉。**排尿素动物**把它转化为**尿素** CO(NH₂)₂，毒性低得多、极易溶，代价是每个尿素约 4 个高能磷酸键：哺乳类、多数成年两栖类，以及鲨鱼与鳐鱼（它们还把尿素用作渗透溶质，[[biochemistry/water-and-bonds]]）。**排尿酸动物**把它转化为**尿酸**：尿酸溶解度差，可以近乎干膏状排出，能量代价更高——鸟类、多数爬行类与陆生昆虫。
:::

| 终产物 | 每分子 N 原子数 | 氮的质量分数 | 每克氮所需水量（约） |
|---|---|---|---|
| 氨 | 1 | 82 % | 300–500 mL |
| 尿素 | 2 | 47 % | 约 50 mL |
| 尿酸 | 4 | 33 % | 约 10 mL |

（水量数字是常被引用的近似值，例如见 K. Schmidt-Nielsen, *Animal Physiology*, 5th ed., 1997。）对水的需求解释了这种分布的大部分。尿酸是付不起水代价的动物的解决之道——昆虫与鸟类，体型小、蒸发散失多——并且，如李约瑟（Joseph Needham）1931 年所论证的，对发育在有壳而封闭（cleidoic）的卵中的胚胎也是如此：氨或尿素会在封闭空间里积累到中毒水平，而尿酸无害地沉淀出来。

::: example 排氮的水代价 {#ex-nitrogen}
估计排出 1.0 g 氮所需的水量：(a) 以尿素形式排入 0.60 mol L⁻¹ 的尿（在哺乳动物尿的浓度范围之内），(b) 以氨的形式，若一条鱼的体液能容忍流过其鳃的水中氨不超过 3 mmol L⁻¹。评论这一差别。
::: solution
(a) 每个尿素携带 2 个 N，故 1.0 g N $= 1.0/14.0 = 0.0714$ mol N $= 0.0357$ mol 尿素。按 0.60 mol L⁻¹ 需 $0.0357/0.60 = 0.060$ L，即 60 mL——与表中的数字一致。
(b) $0.0714$ mol NH₃ 按 0.003 mol L⁻¹ 需要 23.8 L 水。河里的鱼有源源不断流过鳃的水，这几乎不算代价；陆生动物永远供不起。把氨转化为尿素要花费能量，却把水省下数百倍；尿酸的额外代价再换来五倍左右。
:::
:::

这一策略可以在一生中或一个谱系内改变，表明它是受调控的，而不是固定不变的。蝌蚪排氨；变态时，在甲状腺激素的作用下，肝诱导尿素循环的酶，成体转为排尿素（P. P. Cohen 与 G. W. Brown，1960）。非洲肺鱼在干泥中夏眠时从排氨转为排尿素。海湾蟾鱼（*Opsanus beta*）是一种真骨鱼，制造尿素并阵发式地释放。龟类则各型俱全，从水栖种的排氨到沙漠陆龟的排尿酸。

**尿素循环**——哺乳动物的肝借此把氨、碳酸氢根与天冬氨酸的氨基合成为尿素——由克雷布斯（Hans Krebs）与 Kurt Henseleit 于 1932 年用大鼠肝切片发现：他们发现鸟氨酸催化性地促进尿素合成——这是有史以来描述的第一个代谢循环，比三羧酸循环早五年。其化学计量与代价在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=lipid-nitrogen-metabolism)中算出；尿素循环酶的遗传缺陷属于[医学图谱：遗传学](/learn/medicine/course.php?c=genetics)。

## 组织的分工

在哺乳动物中，每个主要组织都有其特征性的代谢谱，由它表达哪些酶与转运蛋白决定。

| 组织 | 主要燃料 | 贮备 | 特殊作用 |
|---|---|---|---|
| 脑 | 葡萄糖（成人每天约 120 g）；长期饥饿时用酮体 | 几乎没有 | 约占静息耗氧的五分之一；不能直接利用脂肪酸 |
| 红细胞 | 只能用葡萄糖，经糖酵解生成乳酸 | 无 | 没有线粒体 |
| 骨骼肌 | 葡萄糖、脂肪酸、酮体；爆发性活动时用糖原 | 糖原（共约 400 g），一些三酰甘油 | 缺乏葡萄糖-6-磷酸酶：其糖原只供自己 |
| 心脏 | 脂肪酸、乳酸、酮体、葡萄糖 | 少 | 几乎完全靠有氧 |
| 肝 | 氨基酸、脂肪酸 | 糖原（进食后约 100 g） | 释放葡萄糖；制造酮体、尿素、脂蛋白；是全身的"血糖恒定器" |
| 脂肪组织 | 葡萄糖、脂肪酸 | 三酰甘油（清瘦成人约 15 kg） | 释放脂肪酸与甘油；分泌瘦素 |

（成人的代表性数值；Nelson 与 Cox, *Lehninger Principles of Biochemistry*, 8th ed., 2021。）燃料经由交换循环在各组织间流动。

- **科里循环**（Carl 与 Gerty Cori，1929）：工作肌肉与红细胞经糖酵解产生的乳酸被运到肝，变回葡萄糖，再回到肌肉。
- **葡萄糖-丙氨酸循环**（Philip Felig，1970）：肌肉把氨基转给丙酮酸，输出丙氨酸；肝取其碳制造葡萄糖，取其氮制造尿素。

::: example 科里循环的代价 {#ex-cori}
肌肉每把一分子葡萄糖转化为 2 乳酸就取得 2 ATP。肝把 2 乳酸造回一分子葡萄糖要花相当于 6 ATP（4 ATP 与 2 GTP）。循环一遍对全身各部分的净代价是多少？为什么值得付出？
::: solution
净代价 $= 6 - 2 = 4$ 个 ATP 当量，每循环一分子葡萄糖。这一循环把工作中依赖氧的那部分从肌肉移到肝：剧烈运动时肌肉可以经糖酵解无氧地快速制造 ATP，而肝在有氧条件下工作，靠氧化脂肪酸支付再生葡萄糖的代价。它还回收乳酸的碳而不浪费，并让没有线粒体的红细胞完全靠葡萄糖生活。能量最终来自肝中氧化的脂肪。
:::
:::

## 进食、禁食与饥饿

贮存与动员之间的激素开关，由**胰岛素**（血糖升高时由胰腺 β 细胞释放，[[biochemistry/enzymes#ex-glucokinase]]）与反调节激素——**胰高血糖素**（血糖下降时由 α 细胞释放）、**肾上腺素**（应激与运动时）与**皮质醇**（长期禁食时）——之比设定。胰岛素经受体酪氨酸激酶起作用，使关键酶去磷酸化；胰高血糖素与肾上腺素经 cAMP 与蛋白激酶 A 起作用，使它们磷酸化（[[cell-biology/cell-signalling]]）。

| 酶 | 磷酸化的效应（胰高血糖素/肾上腺素） | 结果 |
|---|---|---|
| 糖原磷酸化酶 | 激活 | 糖原分解 |
| 糖原合酶 | 失活 | 无糖原合成 |
| PFK-2/FBPase-2（肝） | 激酶关闭、磷酸酶开启：2,6-二磷酸果糖下降 | 糖酵解减慢，糖异生升高 |
| 丙酮酸激酶（肝） | 失活 | 磷酸烯醇式丙酮酸留给糖异生 |
| 乙酰辅酶A 羧化酶 | 失活 | 脂肪酸合成停止，氧化放开 |
| 激素敏感性脂肪酶（脂肪组织） | 激活 | 释放脂肪酸 |

在数小时到数天的时间尺度上，同一批激素还通过调控转录改变酶的*数量*：禁食诱导磷酸烯醇式丙酮酸羧化激酶等糖异生酶；进食诱导葡萄糖激酶与生脂酶。这种组合——快速的共价开关加上基因表达的缓慢改变——正是 [[biochemistry/enzyme-regulation]] 所预测的多位点、多时程的控制。

### 禁食的阶段

George Cahill 及同事在 1960 年代对医学监护下禁食的志愿者所做的研究中，描述了随禁食推移人的燃料利用如何改变（G. F. Cahill, *New England Journal of Medicine* 282, 668, 1970）。

1. **吸收状态**（餐后数小时）：来自肠道的葡萄糖被所有组织利用；多余的部分在肝与肌肉中贮存为糖原，并转变为脂肪；氨基酸补充蛋白质。
2. **吸收后状态**（过夜）：肝经糖原分解、并日益经乳酸、甘油与氨基酸的糖异生维持血糖；肌肉与心肌转为使用脂肪酸。
3. **早期饥饿**（第 2–3 天）：肝糖原耗尽；来自动员肌肉蛋白所得氨基酸的糖异生供养大脑；肝把脂肪酸转变为**酮体**。
4. **长期饥饿**（数周）：酮体升到每升数毫摩尔，脑适应为从中取得大部分能量（O. E. Owen 及同事，*Journal of Clinical Investigation* 46, 1589, 1967），于是它的葡萄糖需求下降，蛋白质分解从每天约 75 g 降到约 20 g。

::: example 葡萄糖能维持多久？ {#ex-starvation}
一名成人的肝在餐后约含 100 g 糖原，脑每天约用 120 g 葡萄糖。(a) 仅靠肝糖原能供应大脑多久？(b) 一名清瘦成人有 15 kg 脂肪（37 kJ g⁻¹），禁食期间每天约消耗 8 MJ。若由脂肪供应全部这一能量，能维持多久？(c) 有了 (b)，脑转向酮体对生存为什么至关重要？
::: solution
(a) $100/120\times24 = 20$ h——不足一天，还不算其他葡萄糖用户。
(b) $15\,000\times37 = 555$ MJ，可维持 $555/8 = 69$ 天。
(c) 脂肪库能维持两个月，但脂肪酸不能转变为葡萄糖（[[biochemistry/glycolysis-tca#def-glyoxylate]]），而脑不能氧化脂肪酸。若脑继续每天需要 120 g 葡萄糖，来自蛋白质的糖异生就会在脂肪耗尽之前很久消耗掉肌肉与其他必需的蛋白质。酮体——在肝中由脂肪制造、被脑氧化——使脂肪能间接供养大脑、节省蛋白质，并把存活延长到由脂肪库设定的极限。（这是研究条件下禁食的生理学，不是养生指导；临床方面见[医学图谱](/learn/medicine/course.php?c=cell-biochemistry)。）
:::
:::

::: warning "糖耗尽时脂肪会变成糖"
在动物中，三酰甘油的脂肪酸链不能转变为葡萄糖，因为丙酮酸脱氢酶反应不可逆，而脊椎动物没有乙醛酸循环。只有甘油骨架（约占三酰甘油碳的 10 %）是生糖的。禁食期间制造的葡萄糖来自甘油、乳酸与氨基酸——也就是说，部分来自身体蛋白质。拥有乙醛酸循环的植物、真菌与细菌*能*把脂肪变成糖，萌发的油料种子正是如此。
:::

血糖的控制以及它出故障的疾病——尤其是糖尿病，其胰岛素缺乏或组织不能对其产生应答——是临床课题，见[医学图谱：内分泌](/learn/medicine/lesson.php?c=endocrine&l=diabetes)。

## 动物的代谢极端

比较生理学显示同样的途径被拉到极限。

- **冬眠。** 地松鼠等小型冬眠者把蛰伏中的代谢率降到基础率的几个百分点，体温降到接近 0–5 °C，几乎全靠脂肪生活（RQ 约 0.7）。代谢率下降的幅度超过了典型 $Q_{10}$ 下单纯降温所能造成的（[[biochemistry/enzymes#def-q10]]），所以代谢是被主动压低的。周期性觉醒由棕色脂肪组织使动物复温（[[biochemistry/oxidative-phosphorylation]]），消耗掉冬季能量预算的很大一部分。
- **迁徙。** 迁徙的鸟类主要用由脂肪组织经血液送来的脂肪酸为飞行肌供能，其速率远高于哺乳动物的肌肉，并有丰富的脂肪酸结合与转运蛋白相助。它们也分解一些蛋白质，也许是为了供应水与生糖碳。
- **昆虫飞行。** 昆虫飞行肌的代谢率位居已知最高之列。燃料因类群而异：蝇与蜂烧糖类（海藻糖与糖原）；蝗虫先靠糖类，长距离飞行时转为脂质（T. Weis-Fogh，1952）；舌蝇与科罗拉多马铃薯甲虫燃烧氨基酸脯氨酸，把它部分氧化为丙氨酸（E. Bursell，1960 年代），再由脂肪体循环回脯氨酸。
- **潜水。** 海豹与鲸把氧结合在肌肉的肌红蛋白上贮存，浓度比陆生哺乳动物高好几倍；长时间潜水时它们限制流向肌肉与内脏的血流，这些组织转向发酵，并在上浮后清除乳酸（[[animal-physiology/gas-exchange]]）。

## 植物中的整合：C4 与 CAM 光合作用

植物跨细胞、跨昼夜地整合代谢，最清楚的例子源于 Rubisco 对氧的弱点（[[biochemistry/enzymes#ex-rubisco]]）。在 **C3** 植物（大多数物种）中，CO₂ 由 Rubisco 在卡尔文-本森循环中固定——该循环由梅尔文·卡尔文（Melvin Calvin）、Andrew Benson、James Bassham 及同事在 1946 年到 1950 年代中期，通过把藻类 *Chlorella* 暴露于 ¹⁴CO₂ 数秒并用纸层析鉴定标记化合物而阐明；第一个稳定产物是三碳的 3-磷酸甘油酸（卡尔文获 1961 年诺贝尔化学奖）。在温暖干燥的条件下，气孔为保水而关闭、叶内 CO₂ 下降时，Rubisco 的加氧以及由它启动的光呼吸就变得昂贵。

::: definition C4 与 CAM 光合作用 {#def-c4}
在 **C4 光合作用**中，CO₂ 首先在叶肉细胞中被磷酸烯醇式丙酮酸（PEP）羧化酶固定：该酶利用碳酸氢根，没有加氧酶活性，对底物亲和力高，生成四碳酸草酰乙酸（故名"C4"），后者转变为苹果酸或天冬氨酸。C4 酸扩散进环绕叶脉的**维管束鞘**细胞，在那里脱羧，把 CO₂ 浓集到 Rubisco 周围，达到大气平衡水平的数倍；余下的三碳化合物回到叶肉细胞，由丙酮酸磷酸双激酶重新磷酸化为 PEP，代价是两个高能磷酸键。在**景天酸代谢**（CAM）中，同样的两次羧化分开在*时间*而非空间上：夜间气孔开放，CO₂ 被 PEP 羧化酶固定并以苹果酸的形式贮存在液泡中；白天气孔关闭，苹果酸脱羧，CO₂ 在关闭的气孔后面被 Rubisco 固定。
:::

C4 途径由 Hugo Kortschak 及同事在甘蔗中发现（1965），并由 Marshall Hatch 与 Roger Slack 阐明（1966）。它在被子植物中已独立进化 60 次以上（R. F. Sage 及同事，2011），见于玉米、甘蔗、高粱与粟等禾草以及若干双子叶植物科——一个复杂的代谢与解剖性状趋同进化的显著实例。C4 植物只约占植物物种的 3 %，却贡献了陆地初级生产的大约四分之一，主要是在热带草原。CAM 见于仙人掌、龙舌兰、凤梨、许多兰科与凤梨科植物，以及作为其名称由来的景天科。

::: example 一台 CO₂ 泵的能量代价 {#ex-c4}
卡尔文-本森循环每固定一个 CO₂ 需要 3 个 ATP 与 2 个 NADPH。C4 途径为再生 PEP 在每个 CO₂ 上外加 2 个 ATP。计算 C3 与 C4 植物制造一分子葡萄糖各需多少 ATP 与 NADPH，忽略光呼吸。然后说明 C4 植物何时反而占上风。
::: solution
每个葡萄糖六个 CO₂。C3：$6\times3 = 18$ 个 ATP 与 $6\times2 = 12$ 个 NADPH。C4：$6\times(3 + 2) = 30$ 个 ATP 与 12 个 NADPH——ATP 多三分之二。但在温暖条件下的 C3 叶片中，加氧速率可达羧化速率的三分之一甚至更多（[[biochemistry/enzymes#ex-rubisco]]），而每次加氧都在光呼吸中浪费 ATP 与 NADPH 并释放已固定的 CO₂。约 25–30 °C 以上、强光而胞间 CO₂ 低时，C3 植物光呼吸的代价超过 C4 泵的代价，C4 植物对光的利用更加有效。又因为同样的光合速率下它们能把气孔开得更窄，每固定一个 CO₂ 散失的水也更少。在凉爽遮阴的条件下，C3 植物获胜。C3 与 C4 禾草的地理分布正符合这一权衡。两类植物对光与 CO₂ 的响应曲线在 [[plant-biology/c4-and-cam]] 中展开。
:::
:::

::: quiz
完全禁食三周的哺乳动物，预期会出现下列哪种情形？
- [ ] 血糖接近零，因为肝糖原已耗尽。
- [ ] 脑的能量主要由血液运输的脂肪酸供应。
- [x] 血酮体升高，供应脑的大部分能量，且肌肉蛋白分解较禁食最初几天减少。
- [ ] 呼吸商接近 1.0，因为糖异生处于最高峰。
::: solution
血糖靠来自甘油、乳酸与氨基酸的糖异生维持在接近正常的水平。脑不能氧化脂肪酸，但禁食数周后它的大部分能量来自酮体，这降低了它的葡萄糖需求并节省蛋白质。以脂肪为主要燃料时，RQ 接近 0.7。
:::
:::

::: application 农业与保护生物学中的代谢
代谢的整合之重要远不止于生理学。反刍家畜靠其肠道微生物的发酵产物生活（[[biochemistry/glycolysis-tca]]）：它们的组织几乎不吸收葡萄糖，其肝几乎完全靠来自丙酸的糖异生制造血糖。世界上产量最高的作物——玉米、甘蔗、高粱——是 C4 植物，国际项目正试图把 C4 机制工程化地导入水稻以提高其产量（[[biotechnology]]）。保护生物学家用体况与脂肪库测量来判断候鸟能否完成旅程，而中途停歇补给地的丧失是鸻鹬类种群的主要威胁（[[conservation-biology]]）。
:::

克洛德·贝尔纳发现肝制造并贮存糖原并释放葡萄糖（1848–57）。Carl 与 Gerty Cori 于 1929 年描述了乳酸与葡萄糖在肌肉与肝之间的循环（1947 年诺贝尔生理学或医学奖，与 Bernardo Houssay 分享）。克雷布斯与 Henseleit 于 1932 年发现尿素循环。Frederick Banting 与 Charles Best 于 1921–22 年提取出胰岛素，C. P. Kimball 与 John Murlin 于 1923 年命名了胰高血糖素。卡尔文、Benson 与 Bassham 在 1946 年至 1950 年代中期阐明了光合碳循环。Owen 与 Cahill 于 1967 年显示饥饿中脑对酮体的利用；Randle 于 1963 年描述了葡萄糖-脂肪酸循环；McGarry 与 Foster 于 1977 年发现丙二酰辅酶A 对脂肪酸氧化的抑制。Kortschak（1965）与 Hatch 与 Slack（1966）发现了 C4 光合作用。
:::

本章结束了本课程，却也打开了好几门课程。支撑长期代谢适应的基因表达控制见 [[molecular-biology/eukaryotic-gene-regulation]] 与 [[molecular-biology/bacterial-gene-regulation]]；代谢的全网络模型、通量平衡分析及其工程应用见 [[systems-biology/metabolic-networks]]；能量平衡与体温调节的生理学见 [[animal-physiology/energy-metabolism]] 与 [[animal-physiology/thermoregulation]]；光合作用见 [[plant-biology/photosynthesis]]；微生物的代谢多样性见 [[microbiology/microbial-metabolism]]。

::: summary
- 脂肪酸在线粒体中氧化（经 CPT1 进入），在细胞质中由丙二酰辅酶A 合成；丙二酰辅酶A 抑制 CPT1，于是合成与氧化互反调控。Randle 循环使脂肪氧化得以节省葡萄糖。
- 呼吸商（糖类 1.0，脂肪 0.70，蛋白质约 0.8）揭示燃料配比；RQ 0.85 表示两种燃料各约提供一半能量。
- 氨基酸分解代谢产生的氨以氨（水生动物）、尿素（哺乳类、成年两栖类、鲨鱼；每克氮约 50 mL 水）或尿酸（鸟类、爬行类、昆虫；每克氮约 10 mL）排出；这一策略可在发育中改变。
- 组织各司其职：脑靠葡萄糖（每天 120 g）或酮体，红细胞靠糖酵解，肌肉有专用的糖原库，肝是血糖恒定器，脂肪组织是脂肪库；燃料经科里循环与葡萄糖-丙氨酸循环循环流动。
- 胰岛素对抗胰高血糖素与肾上腺素，在几分钟内通过（去）磷酸化切换酶，并在数小时内改变酶的数量。禁食时，肝糖原大约维持一天；脑转向酮体节省蛋白质，把存活延长到由脂肪设定的极限。
- 在动物中脂肪酸链不能变成葡萄糖；拥有乙醛酸循环的植物与微生物能。
- C4 植物先在叶肉细胞由 PEP 羧化酶固定 CO₂，再把它浓集到维管束鞘中 Rubisco 的周围（每个葡萄糖 30 而不是 18 个 ATP，但没有光呼吸）；CAM 把同样的步骤分到夜间与白天。
:::

更格卢鼠等沙漠啮齿动物能排出尿素约 1.2 mol L⁻¹ 的尿。在此浓度下排出 1.0 g 氮（以尿素计）需要多少毫升水（三位有效数字）？

::: exercise 哪个组织？ {level=2}
对每项观察，说出组织并解释其生物化学：(a) 它能把自己的糖原作为葡萄糖释放入血，但另一个糖原量多一倍的组织不能；(b) 它完全不能利用脂肪酸或酮体；(c) 它在餐后以依赖胰岛素的方式摄取葡萄糖，并把碳贮存为脂肪；(d) 迁徙之前它的 RQ 升到 1 以上。
::: solution
(a) 肝：它有葡萄糖-6-磷酸酶，能把糖原分解产生的 6-磷酸葡萄糖变为游离葡萄糖；肌肉没有，其糖原只在局部使用。(b) 红细胞：没有线粒体，不能进行 β氧化或氧化酮体，靠糖酵解生成乳酸生活。(c) 脂肪组织（就摄取而言还有肌肉）：胰岛素把 GLUT4 转运蛋白募集到质膜；脂肪细胞把葡萄糖变为 3-磷酸甘油，并与肝一起把它变为脂肪酸，贮存为三酰甘油。(d) 育肥鸟类的肝与脂肪组织：糖类净转化为脂肪时释放 CO₂ 而不消耗 O₂，所以整体 RQ 超过 1。
:::
:::

::: exercise 一份禁食的预算 {level=2}
禁食的头几天，人每天分解约 75 g 蛋白质，主要是为糖异生提供碳。(a) 若这持续下去，为什么是个问题？(b) 数周后蛋白质分解降到每天约 20 g。解释这一变化。(c) 在同一时期，尿中尿素与铵的排泄预计如何变化？为什么？
::: solution
(a) 身体蛋白质不是贮备而是功能性组织——肌肉、酶、抗体；每天损失 75 g 会在数周内耗尽关键功能，远早于脂肪用完。(b) 随着酮体升高，脑适应于氧化酮体，因而需要的葡萄糖少得多；糖异生随之下降，蛋白质分解也随之下降。(c) 尿素排泄随蛋白质分解平行下降。肾的铵排泄上升，因为肾排出 NH₄⁺ 以平衡酮体（酮酸）的酸负荷，以谷氨酰胺作为其氮源；在长期禁食中，肾也成为糖异生的重要部位。
:::

::: exercise 解读燃料切换实验 {level=3}
蝗虫被固定在系绳飞行仪上飞行，并采集淋巴液样品。最初 10 分钟，淋巴液海藻糖下降一半，整虫的 RQ 接近 1.0；30 分钟后海藻糖稳定在低水平，淋巴液二酰甘油上升数倍，RQ 降到约 0.75。把心侧体（一种神经内分泌腺）的激素提取物注射给静息的蝗虫，会使其淋巴液二酰甘油升高。(a) 描述这一燃料切换。(b) 对长距离飞行者来说它为何具有适应意义？(c) 激素实验提示了什么？需要什么对照实验？
::: solution
(a) 飞行始于糖类（海藻糖与肌肉糖原；RQ 1.0），转为脂质（RQ 接近 0.7–0.75），脂质以二酰甘油的形式由脂肪体动员。(b) 糖类随取随用但贮量小、且结合水；脂肪是高能量密度的贮备（[[biochemistry/carbohydrates-lipids]]），可供数小时的飞行，故尽早切换可节省糖类并利用脂肪。(c) 心侧体的一种激素（现已知为脂动激素，AKH，昆虫中胰高血糖素的类似物）从脂肪体动员脂质。对照：以相同体积注射另一种组织的提取物，或经热灭活的提取物，以证明效应特异地来自激素而不是注射应激；剂量-响应关系可使结论更有力。
:::

::: exercise C3 还是 C4？ {level=3}
两种禾草混生于一片温带草原。初春，物种 A 长得更快；盛夏，物种 B 长得更快。B 的叶中，叶脉被含叶绿体丰富的、大的维管束鞘细胞紧密环绕；A 则不然。给 B 一次 ¹⁴CO₂ 脉冲，5 秒内苹果酸与天冬氨酸即被标记；在 A 中，最先被标记的化合物是 3-磷酸甘油酸。(a) 哪个物种是 C4？给出三条证据。(b) 解释这一季节格局。(c) 预测实验性地把大气 CO₂ 加倍时两个物种会如何响应，为什么。
::: solution
(a) B 是 C4：花环结构（Kranz 解剖，维管束鞘显著）、最先标记的产物是 C4 酸而不是 3-磷酸甘油酸（Hatch 与 Slack 的判据）、以及在炎热条件下生长更好。(b) 早春凉爽时光呼吸有限，C3 物种免付 C4 泵每个 CO₂ 外加的 2 个 ATP，所以更有效率；盛夏炎热时，C3 的光呼吸上升，气孔关闭又降低胞间 CO₂，于是其 Rubisco 在高 CO₂ 下运转、每固定一个 CO₂ 失水更少的 C4 物种长得更快。(c) CO₂ 加倍应更利于 C3 物种，因为它提高其 Rubisco 的羧化与加氧之比（[[biochemistry/enzymes#eq-competition]]）并抑制光呼吸，而 C4 物种的 Rubisco 已接近 CO₂ 饱和。大气 CO₂ 升高的田间实验通常发现 C3 比 C4 植物的生长响应更大，尽管省水也让 C4 植物在干旱下有所获益。
:::
:::
