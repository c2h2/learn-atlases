活细胞是一个被维持在远离平衡状态的化学系统。相对于 ADP 与磷酸，其 ATP 的浓度比平衡时高出数亿倍；其 NADPH 几乎全处于还原态，而其 NAD⁺ 几乎全处于氧化态；其膜两侧相隔不过几纳米，离子却被维持在相差十倍乃至一万倍的浓度。细胞一旦停止摄入能量，这些状态没有不在几分钟内衰减的。薛定谔（Erwin Schrödinger）在《生命是什么》（*What Is Life?*，1944）中把这一点说得令人难忘：生物靠不断从环境中汲取秩序而存活。生物能量学就是对这股流动的记账——能量从何而来、以何种货币携带、又花向何处。

本课把热力学工具视为现成——吉布斯自由能、生化标准态、反应的偶联以及氧化还原电位与自由能的关系在[化学图谱：生物能量学](/learn/chemistry/lesson.php?c=biochemistry&l=bioenergetics)中展开——所要问的是它们对真实的细胞与整体的生物体能说明什么：不同的组织把 ATP 维持在离平衡多远处、肌肉如何缓冲它、细胞如何感知自身的能量状态、为什么会有两个烟酰胺辅酶的库，以及一个细胞的能量预算如何放大为一只动物的代谢率。

## 活细胞中的自由能

细胞中每一个反应的方向，都由其实际的自由能变化决定；它既取决于浓度，也取决于反应本身的性质。

::: proposition 实际自由能变化 {#prop-dg}
对细胞中的反应 $\mathrm{A} + \mathrm{B} \rightleftharpoons \mathrm{C} + \mathrm{D}$，每摩尔反应的自由能变化为

$$
\Delta G = \Delta G^{\circ\prime} + RT\ln Q,\qquad Q = \frac{[\mathrm{C}][\mathrm{D}]}{[\mathrm{A}][\mathrm{B}]},
$$ {#eq-dg}

其中 $\Delta G^{\circ\prime}$ 是 pH 7、其余各反应物均为 1 mol L⁻¹ 时的标准自由能变化（生化标准态），$Q$ 是实际浓度的**质量作用比**（严格说是活度；水、pH 7 的 H⁺ 与 Mg²⁺ 已并入 $\Delta G^{\circ\prime}$）。平衡时 $\Delta G = 0$，$Q = K'_\mathrm{eq} = e^{-\Delta G^{\circ\prime}/RT}$。37 °C 时 $RT\ln10 = 5.94\ \mathrm{kJ\,mol^{-1}}$：$Q$ 每变化十倍，$\Delta G$ 移动 5.94 kJ mol⁻¹。
:::

比值 $Q/K'_\mathrm{eq}$ 告诉我们一个反应在细胞中离平衡有多远。对组织代谢物浓度的测定（在不到一秒内用冷冻钳夹住组织中止代谢，再提取、测定）把代谢反应分为两类。大多数**接近平衡**，$Q$ 与 $K'_\mathrm{eq}$ 相差只在十倍上下（$|\Delta G|$ 为几个 kJ mol⁻¹）；其净方向由底物的供应与产物的移除决定，可以朝任一个方向进行。少数**远离平衡**，$Q$ 比 $K'_\mathrm{eq}$ 小若干个数量级；它们实际上是单向不可逆的，也正是代谢途径受调控的步骤（[[biochemistry/enzyme-regulation]]）。

::: example 静息与疲劳肌肉中 ATP 的自由能 {#ex-atp-muscle}
对 ATP 水解 $\mathrm{ATP} + \mathrm{H_2O} \to \mathrm{ADP} + \mathrm{P_i}$，取 $\Delta G^{\circ\prime} = -30.5\ \mathrm{kJ\,mol^{-1}}$。静息骨骼肌中，由 ³¹P NMR 与肌酸激酶平衡得 [ATP] = 8 mmol L⁻¹、游离 [ADP] = 13 µmol L⁻¹、[Pᵢ] = 3 mmol L⁻¹；剧烈运动至疲劳后的代表值为 [ATP] = 4 mmol L⁻¹、[ADP] = 200 µmol L⁻¹、[Pᵢ] = 25 mmol L⁻¹（示意值）。计算两种状态下 37 °C 的 $\Delta G$。
::: solution
静息：$Q = (13\times10^{-6})(3\times10^{-3})/(8\times10^{-3}) = 4.9\times10^{-6}$，所以 $\Delta G = -30.5 + 2.579\ln(4.9\times10^{-6}) = -30.5 - 31.5 = -62\ \mathrm{kJ\,mol^{-1}}$。

疲劳：$Q = (2\times10^{-4})(0.025)/(0.004) = 1.25\times10^{-3}$，所以 $\Delta G = -30.5 + 2.579\ln(1.25\times10^{-3}) = -30.5 - 17.2 = -48\ \mathrm{kJ\,mol^{-1}}$。

ATP 浓度只降了一半，但每个 ATP 所能提供的自由能减少了约 14 kJ mol⁻¹，因为 ADP 与 Pᵢ 升得太多。某些依赖 ATP 的过程——尤其是肌浆网的钙泵——逆梯度工作约需要 50 kJ mol⁻¹ 以上；$|\Delta G_\mathrm{ATP}|$ 的下降，连同 Pᵢ 对收缩蛋白的直接作用，被认为有助于造成肌肉疲劳。细胞中的"能量"不是 ATP 的多寡，而是 ATP/ADP·Pᵢ 比值离平衡有多远。
:::
:::

## ATP：货币及其储备

ATP 之所以是通用货币，因为它是中间环节：它的水解放能足以驱动大多数合成反应与物质转运，而 ADP 又能被分解代谢中的放能反应重新磷酸化。它正好居于磷酸烯醇式丙酮酸、1,3-二磷酸甘油酸等"高能"化合物与 6-磷酸葡萄糖等"低能"化合物之间，这使它能在这两者之间传递磷酰基。弗里茨·李普曼（Fritz Lipmann）在 1941 年阐明了这一思想，引入符号 ~P 表示"高能"磷酸键；这个说法指的是整个化合物水解的大负自由能，并不是说能量储存在某一个键中。

单独进行并不有利的反应，通过与 ATP 水解**偶联**、经由共同中间物（通常是被磷酸化的底物或酶）而被驱动，使总的自由能变化为各部分之和（[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=bioenergetics)）。在细胞条件下，每水解一个 ATP 就把被偶联反应的平衡比乘约 $e^{55/2.58} \approx 10^9$。

与自身的周转相比，ATP 库小得可怜：静息成人约两分钟即告罄（[[biochemistry/carbohydrates-lipids#ex-atp-turnover]]）。因此，ATP 需求可能骤然升高的组织要保留储备。

::: definition 磷酸原 {#def-phosphagen}
**磷酸原**（phosphagen）是氮上被磷酸化的胍基化合物（N-磷酰胍），在可兴奋细胞与运动细胞中充当可迅速动用的高能磷酸储备。磷酸原激酶把磷酰基可逆地转移给 ADP：

$$
\text{磷酸原-P} + \mathrm{ADP} + \mathrm{H^+} \rightleftharpoons \text{磷酸原} + \mathrm{ATP}.
$$ {#eq-phosphagen}

脊椎动物用**磷酸肌酸**（肌酸激酶）；大多数无脊椎动物，包括节肢动物与软体动物，用**磷酸精氨酸**（精氨酸激酶）；环节动物与某些其他无脊椎动物还用若干种其他磷酸原（phosphoglycocyamine、phosphotaurocyamine、phospholombricine）。
:::

磷酸肌酸于 1927 年在蛙肌中被发现，由剑桥的 Philip 与 Grace Eggleton 以及哈佛的 Cyrus Fiske 与 Yellapragada Subbarow 各自独立做出；Otto Meyerhof 与 Karl Lohmann 于 1928 年在甲壳类肌肉中发现了磷酸精氨酸；Lohmann 于 1934 年证明磷酸肌酸的作用是为 ATP 的再生。磷酸原在不同生物间的分布经 W. R. Ellington 综述（*Annual Review of Physiology* 63, 289, 2001）。磷酸原激酶彼此同源，所以磷酸原的多样性反映的是一个酶家族如何进化出对不同胍类底物的利用。

磷酸原有两项功能。其一是**缓冲** ATP：因为激酶反应接近平衡且其平衡常数有利于 ATP，磷酸肌酸被动用期间 ATP 浓度几乎保持不变，游离 ADP 维持在低位（从而使 $\Delta G_\mathrm{ATP}$ 保持较大值，[[#ex-atp-muscle]]）。其二，在体积大或细长的细胞中它们充当**穿梭体**：磷酸肌酸与肌酸比 ATP 与 ADP 更小、更丰富，在线粒体（线粒体肌酸激酶在此制造磷酸肌酸）与 ATP 的利用部位之间扩散。海胆精子长达几十微米的鞭毛就依赖这样的穿梭（R. M. Tombes 与 B. M. Shapiro，1985）。

::: example 短跑中 ATP 与磷酸肌酸能维持多久？ {#ex-sprint}
短跑运动员小腿肌肉静息时约含 ATP 8 mmol L⁻¹、磷酸肌酸 25 mmol L⁻¹（按细胞水计；代表值）。最大强度运动时水解 ATP 的速率约 3 mmol L⁻¹ s⁻¹（示意值）。若不再有其他 ATP 合成，(a) 仅靠 ATP、(b) 靠 ATP 加磷酸肌酸各能供应这一需求多久？
::: solution
(a) $8/3 = 2.7$ s。实际上 ATP 从不会低于静息水平的一半左右，所以可用的 ATP 勉强维持一秒。
(b) 每个磷酸肌酸再生一个 ATP，所以合计 $(8 + 25)/3 = 11$ s。这与观察相符：最大功率约能维持十秒——即一百米短跑的时长——此后必须由糖酵解（数秒到一分钟，[[biochemistry/glycolysis-tca]]）、进而由氧化磷酸化（数分钟到数小时）接棒，而功率逐级递减。三个系统的差别在于*容量*（ATP 总量）与*功率*（供应速率）：磷酸原高功率、低容量；氧化供能低功率、容量近乎无限。
:::
:::

::: warning "ATP 是能量贮库"
组织中的 ATP 约 4–8 mmol L⁻¹，只够维持其静息需求一两分钟、最大需求一两秒。ATP 是一种快速流通的*载体*，随用随再生；能量储存在脂肪、糖原与淀粉中，以及——仅以秒计——在磷酸原中。事实上，大多数细胞的 ATP 浓度在各种条件下都保持在惊人地恒定；变化的是通过它的通量。
:::

## 感知细胞的能量状态

ATP 浓度几乎不变，酶又怎么"知道"能量吃紧？靠另外两种腺嘌呤核苷酸。

::: definition 腺苷酸能量电荷 {#def-energy-charge}
Daniel Atkinson（1968）把**腺苷酸能量电荷**定义为腺苷酸池中处于 ATP 形态的摩尔分数，ADP 按半充电计：

$$
\mathrm{EC} = \frac{[\mathrm{ATP}] + \tfrac12[\mathrm{ADP}]}{[\mathrm{ATP}] + [\mathrm{ADP}] + [\mathrm{AMP}]}.
$$ {#eq-ec}

其值从 0（全为 AMP）到 1（全为 ATP）。细菌、酵母、植物与动物的生长中细胞一般把它维持在约 0.8 到 0.95 之间；能量电荷降到 0.5 以下的细胞通常死亡。它是一个有用的概括，不过酶响应的是各个核苷酸的浓度，而不是能量电荷本身。
:::

::: proposition AMP 作为能量紧缺的放大信号 {#prop-amp}
腺苷酸激酶使反应 $2\,\mathrm{ADP} \rightleftharpoons \mathrm{ATP} + \mathrm{AMP}$ 在多数细胞中接近平衡，$K = [\mathrm{ATP}][\mathrm{AMP}]/[\mathrm{ADP}]^2 \approx 1$。于是

$$
[\mathrm{AMP}] = K\frac{[\mathrm{ADP}]^2}{[\mathrm{ATP}]}.
$$ {#eq-amp}

由于 AMP 取决于 ADP 的*平方*，而 ATP 远大于 AMP，ATP 的一个小的分数下降就会引起 AMP 大得多的分数上升。假设：腺苷酸激酶处于平衡；在所考虑的时间尺度上腺苷酸总量恒定；且为游离（未与蛋白质结合的）浓度。
:::

::: example ATP 下降百分之十 {#ex-amp}
某细胞腺苷酸总量为 5.0 mmol L⁻¹，其中 ATP 4.50、ADP 0.454、AMP 0.046 mmol L⁻¹（与 $K = 1$ 时的 [[#eq-amp]] 相符）。能量需求升高，ATP 下降 10%，到 4.05 mmol L⁻¹。设腺苷酸激酶处于平衡、总池恒定，求新的 ADP 与 AMP 以及新的能量电荷。
::: solution
需要 ADP $= a$、AMP $= m$，满足 $a + m = 5.0 - 4.05 = 0.95$ 且 $m = a^2/4.05$。代入得 $a^2/4.05 + a - 0.95 = 0$，其正根为 $a = 0.794$，于是 $m = 0.156$ mmol L⁻¹。

ATP 下降 10%，ADP 上升 1.75 倍，AMP 上升 $0.156/0.046 = 3.4$ 倍。能量电荷只从 $(4.50 + 0.227)/5 = 0.945$ 降到 $(4.05 + 0.397)/5 = 0.889$。响应 AMP 的酶所看到的信号，按相对变化算比响应 ATP 的酶大三倍以上。这正是真核生物的主能量感受器由 AMP（以及 ADP）激活、而不是由 ATP 抑制的原因。
:::
:::

动物的 **AMP 激活的蛋白激酶**（AMPK）——酵母中为 Snf1，植物中为 SnRK1，彼此都是直系同源物——在 AMP 与 ADP 上升时被激活。它随即磷酸化数十个靶标，打开产生 ATP 的途径（葡萄糖摄取、脂肪酸氧化、线粒体新生），关掉消耗 ATP 的途径（脂肪酸、胆固醇与蛋白质的合成，细胞生长）。D. Grahame Hardie 称它为细胞的"油量表"。从酵母到植物到哺乳动物的保守性表明，以腺嘌呤核苷酸感知能量状态是极为古老的事。在细菌中，饥饿时扮演对应角色的部分是 ppGpp（[[biochemistry/carbohydrates-lipids]]）。

## 还原力的两种货币

能量还有第二种携带形式：电子。氧化食物时移走电子，由 NAD⁺（以 NADH 形式）与 FAD（以 FADH₂ 形式）携带到呼吸链；生物合成需要电子来还原前体，由 NADPH 供应。NAD⁺ 与 NADP⁺ 只相差腺苷核糖 2′ 位上的一个磷酸，这对它们的化学毫无影响，却使酶能把两者区分开。为什么要两套？

答案在于细胞把两个库维持在极不相同的氧化还原状态。1967 年，Dermot Williamson、Patricia Lund 与 Hans Krebs 利用乳酸脱氢酶（细胞质基质）与 β-羟丁酸脱氢酶（线粒体）催化的接近平衡反应，由大鼠肝的代谢物浓度算出了游离 NAD⁺/NADH 比值：细胞质基质约 700，线粒体只有约 8。Richard Veech、Leslie Eggleston 与 Krebs（1969）利用 NADP 连接的脱氢酶，发现细胞质游离 NADP⁺/NADPH 比值约为 0.01——NADP 池几乎全部处于还原态。

::: proposition 氧化还原电对的还原电位 {#prop-nernst}
像 NAD⁺/NADH 这样的电对（$n = 2$ 个电子）的实际还原电位为

$$
E = E^{\circ\prime} + \frac{RT}{nF}\ln\frac{[\mathrm{ox}]}{[\mathrm{red}]},
$$ {#eq-nernst-redox}

把 $n$ 个电子从供体电对转移到受体电对的自由能为 $\Delta G = -nF\Delta E$，其中 $\Delta E = E_\mathrm{acceptor} - E_\mathrm{donor}$。37 °C 时 $RT/2F = 13.4$ mV。（推导见[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=bioenergetics)；假设：活度等于游离辅酶的浓度，质子项已计入 pH 7 的 $E^{\circ\prime}$。）
:::

::: example 为什么 NADPH 是生物合成的还原剂 {#ex-nadph}
$E^{\circ\prime}$ 为：NAD⁺/NADH −0.320 V，NADP⁺/NADPH −0.324 V。用大鼠肝中测得的比值（细胞质 NAD⁺/NADH = 700，线粒体 NAD⁺/NADH = 8，细胞质 NADP⁺/NADPH = 0.01），计算 37 °C 的实际还原电位，以及细胞质中两个电子从 NADPH 转移到 NAD⁺ 所能提供的自由能。
::: solution
由 [[#eq-nernst-redox]]，取 $RT/2F = 0.01337$ V：

- 细胞质 NAD：$E = -0.320 + 0.01337\ln700 = -0.320 + 0.088 = -0.232$ V；
- 线粒体 NAD：$E = -0.320 + 0.01337\ln8 = -0.320 + 0.028 = -0.292$ V；
- 细胞质 NADP：$E = -0.324 + 0.01337\ln0.01 = -0.324 - 0.062 = -0.386$ V。

两个细胞质电对的 $E^{\circ\prime}$ 几乎相同，实际电位却相差约 0.15 V。把两个电子从 NADPH 转移给 NAD⁺ 将释放 $\Delta G = -2\times96.485\times0.153 = -29.5\ \mathrm{kJ\,mol^{-1}}$。细胞把 NADPH 保持成一个强还原剂，为驱动还原性生物合成（脂肪酸、甾醇、核苷酸）与抗氧化防御"充满电"，同时把细胞质的 NAD⁺ 大部分保持为氧化态，随时准备在糖酵解中接受电子。两个能被酶区分的库，使细胞能在同一隔室中同时进行氧化与还原，且各朝自己的方向推进。
:::
:::

同样的逻辑也解释了 NADPH 的主要来源：氧化磷酸戊糖途径、苹果酸酶、异柠檬酸脱氢酶（NADP 型），以及——在光合生物中——光系统 I，它直接还原 NADP⁺，使光驱动还原性的卡尔文-本森循环（[[plant-biology/photosynthesis]]）。线粒体**转氢酶**利用质子动力势把还原当量从 NADH 转移给 NADP⁺，使线粒体的 NADPH 库也保持还原。

::: quiz
某组织的腺苷酸浓度如下（mmol L⁻¹）：ATP 3.0，ADP 1.0，AMP 1.0。它的能量电荷是多少？你能对它做出什么预测？
- [ ] 0.85；处于正常的生长状态。
- [x] 0.70；能量处于紧张状态，AMP 激活的途径应强力开启。
- [ ] 0.60；不知道 Pᵢ 就算不出来。
- [ ] 0.50；已经死亡。
::: solution
$\mathrm{EC} = (3.0 + 0.5)/5.0 = 0.70$。低于健康细胞典型的 0.8–0.95，且 AMP 占池的 20% 而非通常的一两个百分点，AMPK 以及磷酸果糖激酶、糖原磷酸化酶等 AMP 激活的酶会被强烈激活。（另注意 $[\mathrm{ATP}][\mathrm{AMP}]/[\mathrm{ADP}]^2 = 3$，所以腺苷酸激酶并不处于 $K \approx 1$ 的平衡——这组数字描述的是一个瞬态。）
:::

## 从细胞到生物体：代谢率

整体生物体的生物能量学以其**代谢率**来度量，即它把化学能转化为热与功的速率。拉瓦锡（Antoine Lavoisier）与拉普拉斯（Pierre-Simon Laplace）1780 年通过测量量热计中一只豚鼠融化的冰与它呼出的 CO₂，证明呼吸就是一种缓慢的燃烧。Max Rubner（用犬，1894）以及 Wilbur Atwater 与 Francis Benedict（用人，约 1900 年）证明，产生的热与所氧化食物预期放出的热相等：热力学第一定律对动物成立。

直接量热很难，所以代谢率通常用**间接量热法**测量：测耗氧速率，再按每升 O₂ 放出的热量换算成能量——氧化糖类时约 21.1 kJ L⁻¹，氧化脂肪时 19.6 kJ L⁻¹，典型混合膳食约 20.1 kJ L⁻¹。CO₂ 产生量与 O₂ 消耗量之比即呼吸商，它揭示正在燃烧的是哪种燃料（[[biochemistry/metabolic-integration]]）。

::: example 由耗氧量求功率 {#ex-power}
一名静息成人每分钟消耗 O₂ 0.25 L。估算以瓦为单位的代谢率；若每个葡萄糖约生成 30 个 ATP，估算葡萄糖的氧化被捕获为 ATP 的效率（葡萄糖完全氧化的 $\Delta G$ 约 −2870 kJ mol⁻¹，细胞中 ATP 合成约 +55 kJ mol⁻¹）。
::: solution
代谢率 $= 0.25\ \mathrm{L\,min^{-1}}\times20.1\ \mathrm{kJ\,L^{-1}} = 5.03\ \mathrm{kJ\,min^{-1}} = 83.8$ W——约一只明亮白炽灯的功率，其中几乎最终都以热的形式释放。捕获效率：$30\times55/2870 = 0.57$，所以葡萄糖自由能的一半多一点被保存为 ATP；其余在制造 ATP 的反应与质子移动中散为热，而那正是让恒温动物保暖的热。
:::
:::

跨物种比较，代谢率随体质量的上升慢于体质量本身。

::: proposition 克莱伯定律（经验） {#prop-kleiber}
从鼠到牛，哺乳动物的基础代谢率 $B$ 近似为

$$
B \approx B_0\,M^{3/4},
$$ {#eq-kleiber}

其中 $M$ 以千克计，$B_0 \approx 3.4$ W kg⁻³ᐟ⁴（Max Kleiber，1932，约每 kg³ᐟ⁴ 每天 70 kcal）。这是一个经验规律，不是物理定律。最佳拟合指数因物种与统计方法而异；对哺乳动物数据的再分析给出的值约在 0.67 到 0.75 之间（例如 C. R. White 与 R. S. Seymour，2003），不同类群之间、静息与最大代谢率之间指数也不同。有理论从分支供给网络的几何导出 3/4（G. B. West、J. H. Brown 与 B. J. Enquist，1997），但争论犹存。
:::

::: example 小鼠与大象 {#ex-kleiber}
用 [[#eq-kleiber]] 估算一只 25 g 小鼠与一头 4000 kg 大象的基础代谢率，并比较它们每千克的代谢率。
::: solution
小鼠：$3.39\times0.025^{0.75} = 3.39\times0.0629 = 0.21$ W。大象：$3.39\times4000^{0.75} = 3.39\times503 = 1700$ W。每千克：小鼠 $0.21/0.025 = 8.5\ \mathrm{W\,kg^{-1}}$，大象 $1700/4000 = 0.43\ \mathrm{W\,kg^{-1}}$——相差二十倍，$(4000/0.025)^{1/4} = 20$。小鼠每克组织合成 ATP 的速率必须是大象每克组织的二十倍，这体现在它更快的心率与呼吸频率、更高的每克进食量与线粒体密度。代谢的标度关系及其对生理学与生态学的意义，在 [[animal-physiology/energy-metabolism]] 中展开。
:::
:::

::: application 测定野外的能量流动
双同位素标记水（doubly labelled water）法测量自由生活动物与人的能量消耗。受试者喝下同时含氢（²H）与氧（¹⁸O）重同位素的水。氢只随水排出体外；氧则既随水排出、也随 CO₂ 排出（因为碳酸酐酶使水中的氧与碳酸氢根的氧达到平衡）。两种同位素消除速率之差——在几天内取几次体样测定——给出 CO₂ 产生量，进而给出能量消耗。该方法由 Nathan Lifson 在 1950 年代为小动物引入，如今用于迁徙的鸟类、觅食的海豹与人群，并显示例如按体型校正后，狩猎采集者与工业化人群每天的总能量消耗相近（H. Pontzer 及同事，2012）。
:::

::: history
拉瓦锡与拉普拉斯的量热（1780）确认呼吸即燃烧。Julius Robert Mayer（1842）与 Hermann von Helmholtz（1847）都从生理学出发，提出了能量守恒。吉布斯（Josiah Willard Gibbs）于 1873–78 年定义了自由能。磷酸肌酸发现于 1927 年；ATP 由 Karl Lohmann 与 Fiske 和 Subbarow 各自独立地于 1929 年发现；肌酸激酶反应由 Lohmann 于 1934 年阐明。弗里茨·李普曼 1941 年的综述提出了高能磷酸键与 ATP 作为细胞货币的思想（1953 年诺贝尔生理学或医学奖，与克雷布斯分享）。克莱伯于 1932 年发表了他的代谢率标度。Atkinson 于 1968 年提出能量电荷；Williamson、Lund 与 Krebs 于 1967 年测定了区室化的 NAD⁺/NADH 比值。
:::

## 由此走向何处

这里记账的 ATP 与 NADH 在 [[biochemistry/glycolysis-tca]] 与 [[biochemistry/oxidative-phosphorylation]] 中制造；细胞的能量状态——通过 AMP、ATP、NADH 及其感受器——控制着这些途径，并在 [[biochemistry/metabolic-integration]] 中参与全身代谢的激素整合。离子梯度作为第二种能量货币的用法见于 [[cell-biology/membrane-transport]]。

::: summary
- 实际自由能变化 $\Delta G = \Delta G^{\circ\prime} + RT\ln Q$（37 °C 下 $Q$ 每变十倍 5.94 kJ mol⁻¹）决定反应的方向；多数步骤接近平衡，少数远离，远离的那些正是受调控的。
- $\Delta G_\mathrm{ATP}$ 在静息肌肉约 −62 kJ mol⁻¹，疲劳时降到约 −48 kJ mol⁻¹，主要因为 ADP 与 Pᵢ 升高。
- ATP 是每天循环数百次的载体；磷酸原（脊椎动物为磷酸肌酸，多数无脊椎动物为磷酸精氨酸）为其缓冲数秒，并在细胞内穿梭运送高能磷酸。
- 腺苷酸能量电荷维持在 0.8–0.95；由于 $[\mathrm{AMP}] = K[\mathrm{ADP}]^2/[\mathrm{ATP}]$，AMP 放大了 ATP 的小幅下降，AMPK/Snf1/SnRK1 负责感知。
- 细胞质 NAD⁺/NADH ≈ 700 而 NADP⁺/NADPH ≈ 0.01：两个库相差约 0.15 V，使 NAD⁺ 在分解代谢中接受电子，而 NADPH 驱动生物合成。
- 代谢率以耗氧量测量（每升约 20 kJ）；静息成人以约 84 W 运转，基础代谢率在哺乳动物间经验地按约 $M^{3/4}$ 标度。
:::

## 练习

::: exercise 十倍变化 {level=1 check="-36.4"}
某反应 $\Delta G^{\circ\prime} = -30.5\ \mathrm{kJ\,mol^{-1}}$。37 °C、$Q = 0.1$ 时 $\Delta G$ 是多少（三位有效数字）？
::: solution
$\Delta G = -30.5 + 2.579\ln0.1 = -30.5 - 5.94 = -36.4\ \mathrm{kJ\,mol^{-1}}$。
:::
:::

::: exercise 能量电荷 {level=1 check="0.9"}
计算 ATP 4.0、ADP 1.0、AMP 0 mmol L⁻¹ 的细胞的能量电荷。
::: solution
$(4.0 + 0.5)/5.0 = 0.90$。
:::
:::

::: exercise 小鼠的氧气 {level=1 check="37.8"}
用 [[#ex-kleiber]]，一只 25 g 小鼠的基础代谢率约 0.211 W。按 20.1 kJ L⁻¹，它每小时消耗多少毫升 O₂（三位有效数字）？
::: solution
$0.211\ \mathrm{J\,s^{-1}}\times3600\ \mathrm{s} = 760$ J 每小时 $= 0.760$ kJ。除以 20.1 kJ L⁻¹：0.0378 L，即每小时 37.8 mL——约每千克每小时 1.5 L O₂，按千克计约为静息成人值（0.21 L kg⁻¹ h⁻¹）的七倍。
:::
:::

::: exercise 工作心脏中的 ATP {level=2 check="-59.4"}
工作心肌中的代表值为 [ATP] = 6 mmol L⁻¹、游离 [ADP] = 40 µmol L⁻¹、[Pᵢ] = 2 mmol L⁻¹。计算 37 °C 下 ATP 水解的 $\Delta G$，以 kJ mol⁻¹ 计（三位有效数字；$\Delta G^{\circ\prime} = -30.5$ kJ mol⁻¹）。
::: solution
$Q = (4\times10^{-5})(2\times10^{-3})/(6\times10^{-3}) = 1.33\times10^{-5}$，且 $\ln Q = -11.23$，所以 $\Delta G = -30.5 + 2.579\times(-11.23) = -30.5 - 28.9 = -59.4\ \mathrm{kJ\,mol^{-1}}$。心脏持续不停地工作，把自己的 ATP 维持在几乎与静息骨骼肌一样远离平衡的状态。
:::
:::

::: exercise AMP 如何响应 {level=2 check="0.322"}
重做 [[#ex-amp]]，设 ATP 下降 20%，从 4.50 降到 3.60 mmol L⁻¹（总池 5.0 mmol L⁻¹，$K = 1$）。新的 AMP 浓度是多少 mmol L⁻¹（三位有效数字）？升高了几倍？
::: solution
ADP $a$ 与 AMP $m$ 满足 $a + m = 1.40$ 且 $m = a^2/3.60$。所以 $a^2/3.6 + a - 1.40 = 0$，得 $a = 1.078$、$m = 0.322$ mmol L⁻¹——从 0.046 升高七倍，而 ATP 只下降了 20%。
:::
:::

::: exercise 线粒体 NADH 的电位 {level=2 check="-0.292"}
用 [[#eq-nernst-redox]]，取 $E^{\circ\prime} = -0.320$ V，计算 37 °C、比值为 8 时线粒体 NAD⁺/NADH 电对的还原电位，以伏计，保留三位有效数字。线粒体的 NAD 比细胞质的 NAD 更还原，为什么有用？
::: solution
$E = -0.320 + 0.01337\ln8 = -0.320 + 0.0278 = -0.292$ V。更还原的基质 NADH 库（电位更负）使 NADH 把电子交给呼吸链时可用的自由能最大（O₂/H₂O 的 $E^{\circ\prime}$ = +0.816 V），并由三羧酸循环与β氧化的脱氢酶维持。细胞质的 NAD⁺ 保持氧化，糖酵解中的 3-磷酸甘油醛脱氢酶才能正向运转；电子由穿梭体带入线粒体，实际上是在电位上"爬坡"、付出很小代价的搬运。
:::
:::

::: exercise 磷酸原的选择 {level=2}
磷酸肌酸与磷酸精氨酸都是磷酸原。甲壳类肌肉中磷酸精氨酸可达 30–50 mmol L⁻¹。(a) 磷酸原有哪两项功能？(b) 以爆发方式工作的肌肉（龙虾的尾部翻转、猎豹的冲刺）为什么可能有特别大的磷酸原贮备？(c) 有些海洋蠕虫有好几种不同的磷酸原激酶。磷酸原激酶的同源性对这一多样性的由来有什么提示？
::: solution
(a) 作为 ATP 的时间缓冲，在需求骤增时由 ADP 再生 ATP 并使 ADP 保持低位（使 $\Delta G_\mathrm{ATP}$ 保持较大）；二是作为空间穿梭，把高能磷酸从线粒体运到利用部位。(b) 爆发动作在最初几秒内对 ATP 的需求快过糖酵解或呼吸所能供应的速度；磷酸原是唯一功率（ATP 再生速率）足够高的储备。(c) 这些激酶拥有共同祖先，所以不同的磷酸原经由一个激酶底物专一性的基因重复与分歧而产生，相应的胍类化合物由动物既有的代谢制造。一个谱系使用哪种磷酸原主要是进化历史问题，而非功能不同——尽管平衡常数、所释放的酸等性质在不同磷酸原之间确有几分差别。
:::
:::

::: exercise 解读能量消耗数据 {level=3}
双同位素标记水测得瘦体重相近的成人每日能量消耗如下（示意值）：狩猎采集者 10.5 MJ，农民 11.0 MJ，办公室职员 10.3 MJ——尽管狩猎采集者的体力活动高得多。(a) 这些结果有什么令人意外？(b) 提出两种生理学解释。(c) 要区分它们需要测量什么？(d) 这对理解能量平衡为什么重要——又为什么不能作为个人饮食建议的依据？
::: solution
(a) 若能量消耗只是基础代谢率加上活动量，更活跃的人应当消耗多得多；事实并非如此。(b) 身体可能"约束"总消耗，用减少其他方面的支出——例如免疫功能、与繁殖有关的过程、应激反应或非运动性活动——来补偿更高的活动量；或者更活跃的人可能运动得更有效率。(c) 基础代谢率（静息时间接量热）、具体活动的能量代价、其他耗能过程的指标（免疫与内分泌标志物），以及个体活动改变时的纵向测定。(d) 它提示群体之间能量平衡的差异更多由摄入而非消耗驱动，这与进化和公共卫生问题有关；但群体平均值对任何个体该吃什么、该做什么并不可靠地说明什么，那是临床指导的事（[医学图谱](/learn/medicine/)）。
:::
:::

::: exercise 被拉向正方向的反应 {level=3}
糖酵解的醛缩酶反应，1,6-二磷酸果糖 ⇌ 磷酸二羟丙酮 + 3-磷酸甘油醛，$\Delta G^{\circ\prime} = +23.8\ \mathrm{kJ\,mol^{-1}}$。(a) 37 °C 的 $K'_\mathrm{eq}$ 是多少？(b) 某细胞中 [FBP] = 30 µmol L⁻¹、[DHAP] = 140 µmol L⁻¹、[GAP] = 6 µmol L⁻¹（组织中所测类型数值的示意值）。计算 $\Delta G$，并判断该反应是接近还是远离平衡。(c) 一个标准自由能变化为正的反应为什么能承载大的正向通量？
::: solution
(a) $K' = e^{-23.8/2.579} = e^{-9.23} = 9.8\times10^{-5}$ mol L⁻¹。
(b) $Q = (1.4\times10^{-4})(6\times10^{-6})/(3\times10^{-5}) = 2.8\times10^{-5}$，所以 $\Delta G = 23.8 + 2.579\ln(2.8\times10^{-5}) = 23.8 - 27.0 = -3.2\ \mathrm{kJ\,mol^{-1}}$。$Q/K' \approx 0.3$：该反应接近平衡，与大多数组织中醛缩酶的测定结果一致。
(c) 因为一个分子变成两个，$Q$ 有浓度的量纲，在细胞的微摩尔浓度下它比 1 mol L⁻¹ 低好几个数量级，所以 $RT\ln Q$ 大而为负；而产物被糖酵解的后续步骤持续移走，使 $Q$ 保持在略低于 $K'$。标准自由能指的是所有物质都处于 1 mol L⁻¹，这对细胞毫不相干。近平衡步骤只要酶足够多，就能承载大的净通量。
:::
