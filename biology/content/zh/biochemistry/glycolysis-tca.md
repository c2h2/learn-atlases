地球上几乎所有生物都分解葡萄糖，而且几乎毫无例外，第一阶段都是同一条十步途径——**糖酵解**：它把葡萄糖裂成两分子丙酮酸，并把其中一点能量捕获为 ATP。接下来发生什么取决于生物和氧气。有氧时，多数生物通过**三羧酸循环**把丙酮酸彻底氧化为二氧化碳，把电子交给呼吸链。没有氧，它们必须以别的方式处置电子，而这些办法花样繁多——肌肉与酸奶中的乳酸、面包与啤酒中的乙醇和 CO₂、肠道里的酸与气体、瑞士奶酪的孔眼——这就是**发酵**的生物学。

各步的化学——醛缩酶、3-磷酸甘油醛脱氢酶及其他酶的机理、每个反应的热力学，以及三羧酸循环与糖异生的反应——在[化学图谱：糖酵解与三羧酸循环](/learn/chemistry/lesson.php?c=biochemistry&l=glycolysis-citric-acid)中有详述。本章把那些步骤视为已知，从外部看这些途径：它们在生命界的多样性、氧化还原平衡问题与解决它的多种发酵、ATP 的速率与产量之间的权衡、发现循环的实验，以及循环作为枢纽的角色——既燃烧燃料，也为生物合成供货。

## 糖酵解概览

::: proposition 糖酵解的总反应 {#prop-glycolysis}
Embden–Meyerhof–Parnas 途径把一分子葡萄糖转变为两分子丙酮酸，净反应为

$$
\text{葡萄糖} + 2\,\mathrm{NAD^+} + 2\,\mathrm{ADP} + 2\,\mathrm{P_i} \longrightarrow 2\,\text{丙酮酸} + 2\,\mathrm{NADH} + 2\,\mathrm{H^+} + 2\,\mathrm{ATP} + 2\,\mathrm{H_2O}.
$$ {#eq-glycolysis}

投入 2 个 ATP（由己糖激酶与磷酸果糖激酶-1），经底物水平磷酸化生成 4 个（由磷酸甘油酸激酶与丙酮酸激酶），净收益 2 ATP；一次氧化（由 3-磷酸甘油醛脱氢酶）生成 2 NADH。从糖原出发时，磷解直接给出 1-磷酸葡萄糖而不花 ATP，所以每个糖基单位的净收益是 3 ATP。
:::

该途径有一个**准备阶段**——葡萄糖被磷酸化两次，并裂成两个可互变的三碳磷酸糖——和一个**回报阶段**——每个三碳单元被氧化，其能量被捕获为 ATP。有三步远离平衡并受调控——己糖激酶、磷酸果糖激酶-1 与丙酮酸激酶（[[biochemistry/enzyme-regulation]]）；其余七步接近平衡，也服务于糖异生，后者用四个旁路酶绕开那些不可逆步骤。

糖酵解在细胞质中进行（在锥虫中，有一部分在进行类似过氧化物体、称为糖体（glycosomes）的细胞器中）。它不需要氧气，也不需要膜，速率从涓涓细流到滔滔洪水皆可运转，三个域的生物中都有——尽管如我们所见，形式并不总是相同。

### 主题变奏

Embden–Meyerhof–Parnas（EMP）途径并不是从葡萄糖到丙酮酸的唯一路线。

- **Entner–Doudoroff（ED）途径**，1952 年由 Nathan Entner 与 Michael Doudoroff 在 *Pseudomonas saccharophila* 中发现：把 6-磷酸葡萄糖氧化为 6-磷酸葡萄糖酸，脱水，再裂解为丙酮酸与 3-磷酸甘油醛。每分子葡萄糖只产 1 ATP，外加一个 NADH 与一个 NADPH。它在细菌中分布广泛，尤其是需氧菌；产乙醇的细菌 *Zymomonas mobilis* 以及蓝细菌与植物也使用它。
- **磷酸戊糖途径**氧化 6-磷酸葡萄糖，为生物合成制造 NADPH 与 5-磷酸核糖，而不是 ATP（[[biochemistry/bioenergetics]]）。
- **古菌**使用两种途径的改型，其中的酶与众不同：有的是依赖 ADP 而非 ATP 的糖激酶，有的是一种非磷酸解型的 3-磷酸甘油醛脱氢酶，从而跳过一步产 ATP。

为什么要用一条 ATP 产量减半的途径？A. Flamholz、R. Milo 及同事（*PNAS* 110, 10039, 2013）根据各步的动力学与热力学，计算了每条途径维持给定通量需要多少酶蛋白。ED 途径步数更少、热力学特征更有利，同样的葡萄糖通量所需蛋白少好几倍。主要靠呼吸产能、或受制于制造蛋白的成本而非 ATP 的生物，用 ED 更划算；依赖糖酵解 ATP 的生物（如厌氧菌）用 EMP 更划算。两条途径在细菌中的分布符合这一权衡。

## 氧化还原平衡问题与发酵

糖酵解有一个隐藏缺陷。3-磷酸甘油醛脱氢酶需要 NAD⁺，而细胞质中 NAD⁺ + NADH 总共只有约 1 mmol L⁻¹。若 NADH 不被再氧化，糖酵解会在数秒内停止。进行呼吸的细胞把它的电子送进线粒体、再交给氧（[[biochemistry/oxidative-phosphorylation]]）。没有外源电子受体时，电子必须交还给这条途径自身的某种有机产物。

::: definition 发酵 {#def-fermentation}
从生化意义上说，**发酵**是一种产能的分解代谢过程，其中某种有机化合物既作电子供体又作电子受体，没有 O₂、硝酸根或硫酸根之类的外源受体，也没有呼吸电子传递链。ATP 只由底物水平磷酸化生成。由于没有电子离开系统，产物合起来的氧化程度与底物恰好相同（工业上"发酵"一词用得更宽泛，指任何大规模微生物培养，不论需氧与否）。
:::

::: proposition 发酵中的电子平衡 {#prop-balance}
把一个分子的**可用电子**数，定义为它被完全氧化为 CO₂、H₂O 与 NH₃ 时让出的电子数：对含 $n_\mathrm{C}$ 个碳、$n_\mathrm{H}$ 个氢、$n_\mathrm{O}$ 个氧与 $n_\mathrm{N}$ 个氮的分子，可用电子为 $4n_\mathrm{C} + n_\mathrm{H} - 2n_\mathrm{O} - 3n_\mathrm{N}$，离子再算上其负电荷。葡萄糖有 24 个，乳酸（以乳酸计）12、乙醇 12、乙酸 8、琥珀酸 14、甲酸 2、H₂ 2、CO₂ 0。在发酵中，碳与可用电子同时守恒：一分子葡萄糖的产物共含 6 个碳与 24 个可用电子（减去掺入细胞物质的部分）。
:::

::: example 配平两种经典发酵 {#ex-balance}
检验 (a) 同型乳酸发酵葡萄糖 → 2 乳酸、(b) 酒精发酵葡萄糖 → 2 乙醇 + 2 CO₂ 的电子平衡与碳平衡。在每种发酵中，糖酵解产生的 NADH 是如何被再氧化的？
::: solution
(a) 碳：$6 = 2\times3$。电子：$24 = 2\times12$。乳酸脱氢酶用 NADH 把丙酮酸还原为乳酸，再生 NAD⁺：糖酵解的 2 个 NADH 恰好用来生成 2 分子乳酸。
(b) 碳：$6 = 2\times2 + 2\times1$。电子：$24 = 2\times12 + 2\times0$。丙酮酸脱羧酶脱去 CO₂ 生成乙醛，乙醇脱氢酶再用 NADH 把乙醛还原为乙醇。CO₂ 是氧化程度最高的产物，不携带可用电子，所以乙醇必须把它们全部带走——这就是每碳计乙醇比乳酸更还原的原因。

两种发酵都只产糖酵解的 2 ATP，约为呼吸产量的十五分之一，所以要获得同样的 ATP 供应，发酵细胞消耗葡萄糖必须快得多。
:::
:::

### 发酵一览

微生物找到了许多平衡账目的办法，各有其类群特征，且往往有实用价值。

| 发酵类型 | 葡萄糖的主要产物 | 生物 | 每葡萄糖 ATP |
|---|---|---|---|
| 同型乳酸发酵 | 2 乳酸 | *Lactococcus*、许多 *Lactobacillus*；动物肌肉 | 2 |
| 异型乳酸发酵 | 乳酸 + 乙醇 + CO₂ | *Leuconostoc*、一些乳杆菌（磷酸酮醇酶途径） | 1 |
| 酒精发酵 | 2 乙醇 + 2 CO₂ | *Saccharomyces* 等酵母（EMP）；*Zymomonas*（ED） | 2（酵母）、1（*Zymomonas*） |
| 混合酸发酵 | 乳酸、乙酸、乙醇、琥珀酸、甲酸（→ H₂ + CO₂） | *Escherichia coli*、*Salmonella* | 2–3 |
| 2,3-丁二醇发酵 | 2,3-丁二醇、乙醇、CO₂ | *Enterobacter*、*Serratia* | 2 |
| 丙酸发酵 | 丙酸、乙酸、CO₂（来自乳酸） | *Propionibacterium* | 不等 |
| 丁酸与溶剂发酵 | 丁酸、乙酸、H₂、CO₂；后期为丁醇与丙酮 | *Clostridium* | 至多 3 |

产量之所以不同，是因为有些途径能额外回收 ATP：由乙酰辅酶A 生成的乙酰磷酸可把磷酸基交给 ADP（乙酸激酶），所以排出乙酸与 H₂ 的生物比只产乳酸的产更多 ATP——但必须把电子作为 H₂ 排掉，而只有把 H₂ 保持在很低的分压下这才是有利的，通常要靠产甲烷菌之类耗氢伙伴来做到。这种伙伴关系是厌氧生态系统的核心，从牛的瘤胃到污水消化池都是如此（[[microbiology/microbial-metabolism]]）。

发酵产物是鉴定细菌的签名：临床实验室的甲基红试验与 Voges–Proskauer 试验能把混合酸发酵菌（如 *E. coli*，产酸多）与 2,3-丁二醇发酵菌（如 *Enterobacter*，产物中性）区别开来。它们也是食品微生物学的产品：乳酸菌把牛奶变成酸奶、把卷心菜变成酸菜；*Propionibacterium freudenreichii* 产生赋予艾门塔尔奶酪风味的丙酸，以及形成其孔眼的 CO₂；而 *Clostridium acetobutylicum* 的丙酮-丁醇发酵，由哈伊姆·魏茨曼在第一次世界大战期间开发用于供应炸药用的丙酮，是最早的规模化工业生物工艺之一。

酵母从 1.00 kg 葡萄糖最多能造出多少乙醇？放出多少体积的 CO₂（25 °C、1 atm，24.47 L mol⁻¹）？为什么实际发酵只能达到其 90%~95%？
::: solution
1.00 kg 葡萄糖是 $1000/180.16 = 5.55$ mol，得 $11.1$ mol 乙醇 $= 11.1\times46.07 = 511$ g——每克葡萄糖产 0.511 g，有时称为盖-吕萨克产率。CO₂ 也是 11.1 mol，即 $11.1\times24.47 = 272$ L。实际产量更低，因为一部分糖变成了酵母细胞、甘油（为再氧化生物合成中产生的 NADH 而生成）与微量产物，还有一部分乙醇蒸发了。
:::

## 动物体内的发酵

动物也发酵。当肌肉工作得比它的供氧更快时，糖酵解超过了线粒体的氧化，乳酸脱氢酶通过把丙酮酸还原为乳酸来再生 NAD⁺。短跑运动员的小腿肌肉可在一分钟内达到每千克 20–30 mmol 的乳酸浓度。乳酸并不是废物：它离开肌肉，被心脏与慢肌纤维氧化，或在肝中变回葡萄糖（科里循环，[[biochemistry/metabolic-integration]]）。

::: warning "乳酸使肌肉第二天酸痛"
运动时产生的乳酸以约一刻钟到一小时的半衰期从血中清除（取决于恢复期的活动量），到第二天早已消失。延迟性肌肉酸痛在未习惯的运动（尤其是离心收缩）之后一至三天达峰，它与肌纤维的显微损伤及随之而来的炎症有关，而与乳酸无关。乳酸生成是否连急性疲劳都有份，目前仍有争论：酸负荷主要来自 ATP 水解与整个糖酵解，乳酸生成本身反而消耗一个质子。下图模拟乳酸的清除。

有些动物能在完全无氧的情况下存活很长的时间，而缺氧大师们展示了发酵能被推向多远。

- **鲫鱼与金鱼**（*Carassius*）能在结冰后变得缺氧的池塘里存活数月。1980 年 E. A. Shoubridge 与 P. W. Hochachka 发现，金鱼以**乙醇**为终产物而非乳酸，并经鳃排出，酸便不会在体内积累。它们的肌肉线粒体带有一个丙酮酸脱氢酶的重复亚基，被征用去充当丙酮酸脱羧酶（C. E. Fagernes 及同事，2017）——这是该谱系全基因组复制之后一个新功能化的例子。它们还贮存极大量的肝糖原，并压低自己的代谢率。
- **锦龟**（*Chrysemys picta*）在冰下越冬时，能在低温、无氧条件下存活三至四个月。它们产生乳酸，并通过从龟壳与骨骼释放碳酸钙与碳酸镁、再把乳酸存入龟壳来加以缓冲（D. C. Jackson，2000）。
- **潮间带与寄生无脊椎动物**——退潮时暴露在外的贻贝、肠道里的寄生蠕虫——进行生成琥珀酸、丙酸与乙酸的发酵，每分子葡萄糖提取的 ATP 比乳酸发酵更多。

::: example 一条鱼能靠糖原活多久？ {#ex-anoxia}
一条 100 g 的鲫鱼贮存 5.0 g 糖原（肝与肌肉合计）。缺氧时它把糖原发酵为乙醇（每糖基 3 ATP，糖基摩尔质量 162 g mol⁻¹），并把 ATP 需求压低到每克鱼每小时 1.0 µmol ATP（示意值）。这些糖原能维持它多少天？
::: solution
糖基：$5.0/162 = 0.0309$ mol $= 30\,900$ µmol，给出 $3\times30\,900 = 92\,600$ µmol ATP。需求：$1.0\times100 = 100$ µmol h⁻¹。持续时间：$92\,600/100 = 926$ h $= 38.6$ 天。因此，要在自然界观察到的数月中存活，既需要极大的糖原贮备（鲫鱼的肝可有很大部分是糖原），也需要近冰点温度下的深度代谢抑制（[[biochemistry/enzymes#def-q10]]）。排出乙醇而不积累乳酸，避免了限制其他脊椎动物的酸负荷。
:::
:::

## 速率与产量：有氧时为什么还发酵？

1861 年路易·巴斯德注意到，通入空气时酵母的耗糖量远少于隔绝空气时——**巴斯德效应**：有氧时每分子葡萄糖产生的 ATP 约为无氧时的十五倍，所以需要得更少。但有些细胞反其道而行。面包酵母 *Saccharomyces cerevisiae* 只要葡萄糖充足，即使在充足氧气下也把葡萄糖发酵为乙醇（**Crabtree 效应**，得名于 Herbert Crabtree 1929 年对肿瘤的观察）；在葡萄糖上快速生长的 *E. coli* 会排出乙酸（"溢流代谢"）；1920 年代 Otto Warburg 发现许多肿瘤即使有氧也以高速率把葡萄糖变成乳酸（**Warburg 效应**；其在癌症中的作用见[医学图谱：病理学](/learn/medicine/lesson.php?c=pathology&l=cancer-biology)）。

为什么把可用 ATP 的十五分之十四白白浪费掉？几种彼此并不排斥的解释都有支持。

- **速率。** 按单位酶计，发酵产生 ATP 比呼吸更快，而呼吸需要大量投入线粒体蛋白与膜。T. Pfeiffer、S. Schuster 与 S. Bonhoeffer（*Science* 292, 504, 2001）提出：当细胞竞争共享资源时，高速率、低产量的策略可能胜出；而在收益能留在本地的空间结构化群体中，高产量策略才兴旺。
- **蛋白质组分配。** M. Basan 及同事（*Nature* 528, 99, 2015）证明，*E. coli* 是在呼吸的蛋白质成本超过发酵的那个生长速率上转向乙酸溢流的：同样的 ATP 用发酵来造需要更少的蛋白，从而把核糖体腾出来用于生长。
- **生态。** 酿酒酵母先造乙醇——很少有竞争者耐受得了——糖耗尽后再转为呼吸消耗它（"制造—积累—消耗"）。在 *Saccharomyces* 谱系中，Crabtree 效应似乎在约 1 亿年前一次全基因组复制之后演化出来，大致与肉质果实的扩散同时（J. Piškur 及同事，2006）。

## 从丙酮酸到乙酰辅酶A

在需氧细胞中，丙酮酸进入线粒体基质（经线粒体丙酮酸载体），并被**丙酮酸脱氢酶复合体**氧化脱羧——这是一个由三种酶、五种辅酶（焦磷酸硫胺素、硫辛酸、辅酶 A、FAD 与 NAD⁺）组成的巨大复合体：

$$
\text{丙酮酸} + \mathrm{CoA} + \mathrm{NAD^+} \longrightarrow \text{乙酰辅酶A} + \mathrm{CO_2} + \mathrm{NADH}.
$$

这个反应是不可逆的，其后果很大：动物不能把乙酰辅酶A 变回丙酮酸，所以不能从脂肪酸（其分解产物是乙酰辅酶A）净生成葡萄糖。该复合体受产物抑制（乙酰辅酶A、NADH）与磷酸化调控：丙酮酸脱氢酶激酶在能量与乙酰辅酶A 充裕时使它失活，一种磷酸酶使它复活，尤其响应于收缩肌肉中的 Ca²⁺ 与脂肪组织中的胰岛素。

## 三羧酸循环

### 它是如何被发现的

这一循环是从切碎组织的实验作出推断的典范。到 1930 年代中期，圣捷尔吉（Albert Szent-Györgyi）发现，微量的四碳二羧酸——琥珀酸、延胡索酸与苹果酸——就能刺激剁碎的家鸽胸肌（一种呼吸速率极高的组织）的耗氧量，其增量远超这些酸自身氧化所能解释的。它们起的是催化作用。1937 年，Carl Martius 与 Franz Knoop 证明柠檬酸可转变为 α-酮戊二酸，而后者早已被知可被氧化为琥珀酸。同样在 1937 年，克雷布斯与 William Arthur Johnson 在谢菲尔德证明柠檬酸同样起催化作用，并且加入草酰乙酸后肌肉中会*生成*柠檬酸——从而把已知反应连成一个循环。他们的关键证据用到了丙二酸——琥珀酸脱氢酶的竞争性抑制剂：在丙二酸中毒的肌肉中，加入延胡索酸、苹果酸或草酰乙酸都会导致*琥珀酸积累*，而这只有在四碳酸沿循环向前转化为琥珀酸（而不是直接转化）时才可能做到。（《自然》拒载了这篇论文；它发表在 *Enzymologia* 上。）克雷布斯与李普曼分享 1953 年诺贝尔生理学或医学奖，后者发现了辅酶 A——进入循环的乙酰基的载体。

::: example 延胡索酸的催化作用 {#ex-catalytic}
在一次类似圣捷尔吉所做的实验中，向剁碎的家鸽肌肉中加入 1.0 µmol 延胡索酸，其后两小时的耗氧量比不加补充物的对照多 12 µmol（示意值）。(a) 1.0 µmol 延胡索酸（C₄H₄O₄）完全氧化需要多少 O₂？(b) 多出的耗氧量意味着什么？(c) 丙二酸会如何改变结果？
::: solution
(a) $\mathrm{C_4H_4O_4} + 3\,\mathrm{O_2} \to 4\,\mathrm{CO_2} + 2\,\mathrm{H_2O}$：3.0 µmol O₂。
(b) 实测的耗氧增量是它的四倍，所以延胡索酸不可能只是燃料；它必然是在被再生的同时加快了组织中其他底物（丙酮酸，来自肌肉自身的糖类）的氧化——这正是循环所预言的催化角色：延胡索酸转变为草酰乙酸，后者接受一个乙酰基，一转之后又被再生。
(c) 丙二酸阻断琥珀酸脱氢酶，使循环断裂；对呼吸的刺激大部分消失，琥珀酸积累。加入的碳即使以延胡索酸（阻断位点的下游）的形式加入也最终成为琥珀酸，这表明它是绕过了循环、经过柠檬酸才到达琥珀酸的。
:::
:::

### 循环的整体

每一循环把一分子乙酰基（二碳）与草酰乙酸（四碳）缩合为柠檬酸（六碳），经八步以 CO₂ 的形式移除两个碳，并再生草酰乙酸。

::: proposition 三羧酸循环的化学计量 {#prop-tca}
循环每转一周进行

$$
\text{乙酰辅酶A} + 3\,\mathrm{NAD^+} + \mathrm{FAD} + \mathrm{GDP} + \mathrm{P_i} + 2\,\mathrm{H_2O} \longrightarrow 2\,\mathrm{CO_2} + 3\,\mathrm{NADH} + 3\,\mathrm{H^+} + \mathrm{FADH_2} + \mathrm{GTP} + \mathrm{CoA},
$$ {#eq-tca}

其中 FADH₂ 仍结合在琥珀酸脱氢酶（呼吸链的复合体 II）上；GTP 由许多组织中哺乳动物琥珀酰辅酶A 合成酶的 GTP 型同工酶生成（其他同工酶以及植物与细菌生成 ATP）。对一分子葡萄糖（两分子丙酮酸、两周转），丙酮酸脱氢酶一步加循环共给出 8 NADH、2 FADH₂ 与 2 GTP（或 ATP），并把全部六个碳以 CO₂ 释放。葡萄糖此时的大部分能量已储存在还原型载体中，待由氧化磷酸化转化为 ATP。
:::

注意，某一轮循环中以 CO₂ 释放的两个碳，并不是该轮以乙酰辅酶A 进入的那两个：同位素示踪显示，乙酰基的碳会先留在循环中，直到之后的若干轮才被释放（细节可在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=glycolysis-citric-acid)中查证）。该循环在柠檬酸合酶、异柠檬酸脱氢酶与 α-酮戊二酸脱氢酶三步受调控，调控因子是 NADH/NAD⁺ 与 ATP/ADP 比值以及 Ca²⁺，使其速率跟随对 ATP 的需求——这一偶联由呼吸控制完成（[[biochemistry/oxidative-phosphorylation]]）。

### 是枢纽，不只是熔炉

三羧酸循环是**两用（amphibolic）**的：既服务于分解代谢也服务于合成代谢。它的中间物是生物合成的起点。

- α-酮戊二酸 → 谷氨酸 → 谷氨酰胺、脯氨酸、精氨酸；
- 草酰乙酸 → 天冬氨酸 → 天冬酰胺，以及（在细菌与植物中）赖氨酸、甲硫氨酸、苏氨酸；还有嘧啶；
- 琥珀酰辅酶A → 卟啉（血红素、叶绿素）；
- 柠檬酸输出到细胞质 → 为脂肪酸与甾醇合成提供乙酰辅酶A。

每一个被抽提去做生物合成的分子（**抽提**，cataplerosis）都从循环中取走一个四碳单元，循环便会因缺乏草酰乙酸而枯竭。细胞用**回补（anaplerotic，"补料"）**反应重新装满它，动物中最重要的是丙酮酸羧化酶，它用丙酮酸与 CO₂ 生成草酰乙酸，并被乙酰辅酶A 别构激活（M. F. Utter 与 D. B. Keech，1960）：当乙酰辅酶A 积累时，循环正缺接受它所需的草酰乙酸。植物与许多细菌用磷酸烯醇式丙酮酸羧化酶达到同样的目的。

::: definition 乙醛酸循环 {#def-glyoxylate}
**乙醛酸循环**由 Hans Kornberg 与克雷布斯于 1957 年发现，是三羧酸循环的一个变体，绕过了它的两个脱羧步骤。异柠檬酸裂合酶把异柠檬酸裂解为琥珀酸与乙醛酸，苹果酸合酶再把乙醛酸与第二个乙酰辅酶A 缩合为苹果酸。净结果是由两分子乙酰辅酶A 合成一分子四碳二羧酸，而不以 CO₂ 损失碳。它存在于细菌、真菌、原生生物、植物（萌发油料种子中的乙醛酸循环体）与线虫，但不存在于脊椎动物。
:::

乙醛酸循环解释了生物之间的一个基本差别。一个 *E. coli* 细胞能在乙酸上生长，一颗萌发的向日葵种子能把贮存的油变成蔗糖供养幼苗，因为它们都能从乙酰辅酶A 制造草酰乙酸——进而经糖异生制造葡萄糖。脊椎动物不能：在寻常的三羧酸循环中，乙酰辅酶A 带入的两个碳恰好被失去的两个 CO₂ 抵消，草酰乙酸没有净增益。脂肪酸可以驱动一个禁食的哺乳动物，却不能为它的大脑提供葡萄糖（[[biochemistry/metabolic-integration]]）。

### 逆向运转的循环

1966 年，M. C. W. Evans、B. B. Buchanan 与 D. I. Arnon 发现，绿硫细菌 *Chlorobium* 通过倒转三羧酸循环来固定 CO₂，由还原型铁氧还蛋白驱动各步羧化：**还原性三羧酸循环**，除卡尔文-本森循环外已知的至少六种自养碳固定途径之一。它也存在热液环境一些深分支的细菌与古菌中。它的分布，以及许多厌氧生物只有一个不完整循环的两条臂（氧化到 α-酮戊二酸的氧化支与还原到琥珀酸的还原支）这一事实，使它成为某种古老代谢形式的候选者，或许与生命起源的化学有关（[[diversity-of-life/origin-of-life]]）。

::: quiz
一株突变酵母缺乏丙酮酸羧化酶。它在含氨基酸的丰富培养基中以葡萄糖生长，但在以葡萄糖与铵为唯一碳源和氮源的基本培养基中不能生长，除非加入天冬氨酸。为什么？
- [ ] 没有丙酮酸羧化酶它就不能进行糖酵解。
- [x] 它无法回补被抽提去做生物合成的草酰乙酸；天冬氨酸经转氨作用提供草酰乙酸，并提供由它合成的氨基酸。
- [ ] 它无法从丙酮酸制造乙酰辅酶A。
- [ ] 天冬氨酸对所有酵母都是必需氨基酸。
::: solution
丙酮酸羧化酶是酵母中主要的回补酶。在基本培养基上，细胞必须自己合成全部氨基酸，而源自草酰乙酸与 α-酮戊二酸的氨基酸会抽干循环。没有回补，循环维持不住，细胞也无法合成天冬氨酸族的氨基酸。加入的天冬氨酸经转氨作用变回草酰乙酸，两者同时得到恢复。在丰富培养基中氨基酸已由外界提供，从循环抽走的就少。
:::
:::

::: application 代谢通量分析
生物学家现在用稳定同位素标记的底物——通常是 ¹³C 标记在确定位置的葡萄糖——喂养活细胞，再用质谱或 NMR 测定标记在代谢物与蛋白质氨基酸之间的分布，从而测量活细胞内各途径的速率。由于每条途径都以特有的方式重排碳原子（ED 途径使葡萄糖 C-1 的标记出现在丙酮酸 C-1，EMP 途径则出现在丙酮酸 C-3），把标记模式拟合到化学计量模型，就能给出各分支的通量：多少葡萄糖走糖酵解、多少走磷酸戊糖途径，多少丙酮酸经羧化、多少经脱氢进入循环。¹³C 通量分析已被用于改造工业微生物，以及比较肿瘤与正常组织的代谢（[[systems-biology/metabolic-networks]]）。
:::

::: history
布赫纳的无细胞发酵（1897）使糖酵解得以研究。Arthur Harden 与 William Young 在 1905–06 年发现，酵母汁的发酵需要磷酸盐和一种耐热、可透析的"辅酶"（co-zymase，后来被证明含有 NAD⁺ 与其他辅因子）；Harden 与表征了辅酶的 Hans von Euler-Chelpin 分享 1929 年诺贝尔化学奖。Otto Meyerhof 证明肌肉由糖原生成乳酸（1922 年诺贝尔生理学或医学奖，与希尔分享），到 1940 年前后，Gustav Embden、Meyerhof、Jakub Parnas、Carl 与 Gerty Cori、Otto Warburg 及其他人的工作已确立了全部十个步骤。圣捷尔吉（1935）、Martius 与 Knoop（1937）、克雷布斯与 Johnson（1937）发现了三羧酸循环；李普曼在 1945–47 年发现了辅酶 A。Entner 与 Doudoroff 于 1952 年描述了他们的途径，Kornberg 与克雷布斯于 1957 年描述了乙醛酸循环，Evans、Buchanan 与 Arnon 于 1966 年描述了还原性循环。
:::

## 由此走向何处

这里产生的 NADH 与 FADH₂ 把葡萄糖的大部分能量带往 [[biochemistry/oxidative-phosphorylation]]，最终的 ATP 产量在那里计算。糖酵解、糖异生与循环在进食、禁食与运动时如何跨组织协调，是 [[biochemistry/metabolic-integration]] 的主题；微生物分解代谢的多样性在 [[microbiology/microbial-metabolism]] 中展开。

::: summary
- 糖酵解（EMP）在几乎一切细胞的细胞质中把葡萄糖变为 2 丙酮酸、2 ATP 与 2 NADH；Entner–Doudoroff 途径只产 1 ATP，但所需酶蛋白少好几倍——这是产量与成本的权衡。
- 糖酵解要持续，NADH 必须被再氧化。发酵以有机产物为电子受体；碳与可用电子守恒（葡萄糖 24 = 2 乳酸 × 12 = 2 乙醇 × 12 + 2 CO₂ × 0）。
- 微生物间的发酵各不相同（同型与异型乳酸、酒精、混合酸、2,3-丁二醇、丙酸、丁酸），并被用于鉴定细菌、制造食品与化学品；乙醇产量至多为每克葡萄糖 0.511 g。
- 动物在工作的肌肉中发酵生成乳酸；耐缺氧的鲫鱼借助一个新功能化的丙酮酸脱氢酶亚基制造乙醇；锦龟用龟壳缓冲乳酸。
- 有氧时仍发酵（Crabtree、溢流、Warburg 效应），是以产量换取速率与蛋白质组的经济性。
- 克雷布斯与 Johnson（1937）由家鸽肌肉中呼吸的催化刺激与丙二酸阻断推出三羧酸循环。每分子葡萄糖两轮循环给出 6 NADH、2 FADH₂ 与 2 GTP，另有丙酮酸脱氢酶的 2 NADH。
- 该循环是两用的：回补（丙酮酸羧化酶）补充被抽提去做生物合成的中间物。乙醛酸循环使细菌、真菌与植物能从乙酰辅酶A 制糖；脊椎动物没有它。一些自养生物倒转该循环来固定 CO₂。
:::

一个细胞要经乳酸发酵产生与完全氧化（每分子葡萄糖约 30 ATP）相同的 ATP，需要多消耗多少倍的葡萄糖？
::: solution

::: exercise 异型乳酸发酵的平衡 {level=1}
异型乳酸发酵把葡萄糖转变为乳酸 + 乙醇 + CO₂。检验碳平衡与电子平衡，并解释：尽管其中一分子乳酸是经寻常的糖酵解路线生成的，为什么产量只有每葡萄糖 1 ATP？
::: solution
碳：$3 + 2 + 1 = 6$。电子：$12 + 12 + 0 = 24$。*Leuconostoc* 之类的异型乳酸发酵菌没有醛缩酶；它们氧化 6-磷酸葡萄糖（生成 2 NADPH 或 NADH）并将其脱羧为一种磷酸戊糖，磷酸酮醇酶把它裂解为 3-磷酸甘油醛与乙酰磷酸。三碳糖转为乳酸（回报阶段净 2 ATP，减去第一次磷酸化投入的 1 ATP = 净 1），而乙酰磷酸必须被还原为乙醇，以再氧化氧化步骤中多出的 NADH，所以它的磷酸不能用来造 ATP。
:::
:::

::: exercise 甘蔗制乙醇 {level=2 check="2.69"}
一家酿酒厂发酵 5.0 吨蔗糖（摩尔质量 342.3 g mol⁻¹；每分子蔗糖水解为两分子己糖，己糖像葡萄糖一样被发酵）。最多能产乙醇多少吨（三位有效数字）？为什么每克产量高于 [[#ex-ethanol]] 的 0.511 g g⁻¹？
::: solution
$5.0\times10^6/342.3 = 14\,600$ mol 蔗糖给出 29 200 mol 己糖与 58 400 mol 乙醇，即 $58\,400\times46.07 = 2.69\times10^6$ g，也就是 2.69 t。每克蔗糖的产量为 $4\times46.07/342.3 = 0.538$ g g⁻¹，高于葡萄糖，因为水解加上了一分子水：342.3 g 蔗糖变成 360.3 g 己糖。
:::
:::

::: exercise 更冷池塘里的鲫鱼 {level=2 check="77.2"}
重做 [[#ex-anoxia]]，把 ATP 需求减半到 0.50 µmol g⁻¹ h⁻¹，这可能在较低温度下发生。糖原能维持多少天（三位有效数字）？
::: solution
$92\,600/50 = 1852$ h $= 77.2$ 天。代谢率减半使存活时间加倍；在 $Q_{10} = 2$ 时，温度下降 10 °C 即可实现，无须任何主动抑制。

::: exercise 回补与脂肪 {level=2}
长时间禁食时，哺乳动物的肝把大量脂肪酸氧化为乙酰辅酶A，但其中很大一部分被用来生成酮体，而不是全部送进三羧酸循环氧化。用本章的观念解释：(a) 为什么乙酰辅酶A 不能为哺乳动物的糖异生提供碳；(b) 为什么禁食肝中草酰乙酸稀缺；(c) 为什么酮体是有用的产物。
::: solution
(a) 乙酰辅酶A 通过与草酰乙酸缩合进入循环；得到的两个碳在草酰乙酸再生之前已作为两分子 CO₂ 失去，所以草酰乙酸（以及磷酸烯醇式丙酮酸与葡萄糖）没有净合成——哺乳动物没有乙醛酸循环。(b) 禁食时肝经糖异生制造葡萄糖，把草酰乙酸从线粒体中抽走（以苹果酸或天冬氨酸的形式）去造磷酸烯醇式丙酮酸，于是循环缺少接受乙酰辅酶A 的草酰乙酸。(c) 酮体（乙酰乙酸与 β-羟丁酸）是乙酰基的水溶性载体，由肝输出给脑、心与肌肉氧化，从而节省葡萄糖；生成它们还能在肝线粒体中再生辅酶 A（[[biochemistry/metabolic-integration]]）。
:::
:::

::: exercise 解读混合酸发酵 {level=3}
*E. coli* 厌氧生长时，每发酵 100 mmol 葡萄糖产生下列产物（经典研究中报道之类型数值的示意值）：乳酸 79.5、乙酸 38.7、乙醇 49.8、琥珀酸 10.7、甲酸 2.4、H₂ 75.0、CO₂ 88.0 mmol。(a) 计算碳的回收率与可用电子的回收率。(b) 推测失去的碳与电子去了哪里。(c) 为什么 H₂ 与 CO₂ 几乎等量生成，而留下的甲酸那么少？(d) 如果给细菌硝酸根作为电子受体，产物会怎样变化？
::: solution
(a) 碳：乳酸 238.5、乙酸 77.4、乙醇 99.6、琥珀酸 42.8、甲酸 2.4、CO₂ 88 = 548.7 mmol，在 600 中占 91%。电子：乳酸 954、乙酸 309.6、乙醇 597.6、琥珀酸 149.8、甲酸 4.8、H₂ 150、CO₂ 0 = 2165.8，在 2400 中占 90%。
(b) 进入细胞物质（按碳计，生物质的还原程度与糖类相近），以及未测定的微量产物；CO₂ 也可能被低估，因为一部分会以碳酸氢根的形式留在溶液里。
(c) 丙酮酸甲酸裂合酶把丙酮酸裂解为乙酰辅酶A 与甲酸；甲酸氢裂合酶再以 1:1 把甲酸裂解为 H₂ 与 CO₂，所以大部分甲酸被转化（而 CO₂ 的剩余过量来自其他反应）。(d) 供给硝酸根后，*E. coli* 进行呼吸：NADH 被把硝酸根还原为亚硝酸根的电子传递链再氧化，于是丙酮酸被进一步氧化为乙酰辅酶A 与 CO₂，还原性产物（乙醇、乳酸、琥珀酸、H₂）大多消失，ATP 产量升高，生长加快。

::: exercise 为什么要有循环？ {level=3}
乙酰辅酶A 原则上可以由一条线性途径氧化。根据本章与 [[biochemistry/enzyme-regulation]]，给出三条理由说明再生草酰乙酸的循环可能有何优势，以及一条细胞必须加以管理的缺点。
::: solution
优点：(1) 中间物的催化作用——一小池草酰乙酸与其他中间物就能处理无限量的乙酰基，细胞无须制造大量途径专属的中间物。(2) 二碳的乙酰基直接氧化在化学上很困难（在两个都没有活化基团的碳之间断裂 C–C 键）；把它接到草酰乙酸上，就能借助化学上容易的 β-酮酸脱羧来氧化。(3) 同样的中间物连接到许多合成途径与其他燃料（氨基酸从多处进入），使循环成为一个可用 NADH/NAD⁺ 与 ATP/ADP 比值整体调控的枢纽。缺点：为生物合成抽提中间物会使循环枯竭，所以回补反应必须加以调控以匹配抽提；若输入与输出不平衡，循环也可能枯竭或积累中间物。
