生长在丰富肉汤中的细菌，一旦在食物里发现异亮氨酸，几秒之内就会停止合成它。起跑瞬间的肌肉，能在不到一秒内把糖原分解速率提高数百倍。随着一餐被消化、一段禁食开始，肝脏从贮存葡萄糖切换为释放葡萄糖。如果酶只按底物决定的速率运转，这一切都不可能。代谢之所以运转，是因为关键酶的活性在被不断调整——被途径自身的分子、被通过信号通路发挥作用的激素与神经，也被细胞对每种酶含量的改变。

本章讲这些调控的机制，并提出一个看似简单实则棘手的问题：一条途径的通量改变时，是哪些酶在起作用？协同结合的物理化学——希尔方程以及 Monod–Wyman–Changeux 与 Koshland–Némethy–Filmer 模型，并以血红蛋白为例——在[化学图谱：蛋白质功能](/learn/chemistry/lesson.php?c=biochemistry&l=protein-function)中展开。本课以 [[biochemistry/enzymes]] 为基础。

## 改变酶促速率的四种方式

调控作用于不同的时间尺度，生物学家应当时刻分清哪一种正在起作用。

| 机制 | 时间尺度 | 实例 |
|---|---|---|
| 底物与产物浓度 | 毫秒 | 近平衡步骤的质量作用 |
| 别构效应物 | 毫秒到秒 | 终产物的反馈抑制；AMP 的激活 |
| 可逆共价修饰 | 秒到分钟 | 糖原磷酸化酶的磷酸化；叶绿体酶的氧化还原切换 |
| 改变酶的量 | 分钟到天数 | *lac* 基因的诱导；受调控蛋白质的降解 |

区隔化——把酶与底物分别留在不同细胞器、并控制它们之间的转运——又加了一层。真核生物中，脂肪酸合成在细胞质基质、脂肪酸氧化在线粒体，因此两者可以分别受调控（[[biochemistry/metabolic-integration]]）。

## 反馈抑制与别构

1956 年，H. Edwin Umbarger 发现大肠杆菌五步途径的终产物异亮氨酸会抑制该途径的第一个酶苏氨酸脱氨酶；同年 Richard Yates 与 Arthur Pardee 发现胞苷核苷酸抑制天冬氨酸氨甲酰转移酶（ATCase），即嘧啶合成的第一个调空酶。抑制剂与被抑制酶的底物在结构上毫不相似。莫诺（Jacques Monod）、Jean-Pierre Changeux 与 François Jacob 于 1963 年为此类调控创造了**别构**（allosteric，"另一位点"）一词。

::: definition 别构调控与反馈抑制 {#def-allostery}
**别构效应物**是通过结合活性位点以外的位点、经由蛋白质构象的改变来改变酶活性的分子。它可以是抑制剂或激活剂，不必与底物相似。**反馈抑制**是途径的终产物抑制途径早期的某个酶——通常是第一个**调空步骤**（committed step）的酶，该步骤之后的中间产物再无别的用途。**前馈激活**是早期代谢物激活较晚的酶。
:::

在调空步骤上反馈抑制是经济的：它从入口处叫停整条途径，因此中间产物不会积累，细胞已有的产物也不再耗费能量。分支途径使用更精巧的方案。大肠杆菌中，天冬氨酸是赖氨酸、甲硫氨酸与苏氨酸的前体，第一个酶天冬氨酸激酶以三种同工酶形式存在，各受一种不同的终产物抑制，于是某种氨基酸的过剩不致让细胞缺少其他氨基酸。

### 天冬氨酸氨甲酰转移酶：一个别构酶的模式

John Gerhart 与 Pardee 于 1962 年证明，ATCase 对其底物天冬氨酸的动力学呈 S 形；CTP 使曲线向更高的天冬氨酸浓度移动，ATP 使其向更低的移动；轻微加热或汞化合物使酶"脱敏"，既消除 S 形形状、也消除对 CTP 的响应，却不破坏活性。1965 年，Gerhart 与 Howard Schachman 把酶分成催化亚基与调节亚基：催化三聚体有活性但不受调控，当它们与调节二聚体重新组装成天然的 $\mathrm{c_6r_6}$ 复合体时调控恢复。调节位点与催化位点所在确实是不同的蛋白质。

生理上，CTP 与 ATP 的相反效应讲得通。CTP 报告嘧啶充裕；ATP 作为嘌呤，同时报告能量与嘌呤的供应，于是 ATCase 平衡核酸所需大致等量的两类核苷酸的生产。

::: intuition 别构为何有用
酶的活性位点受化学约束：它必须结合底物并稳定某一种过渡态。如果调控物也必须结合在那里，每个调控物都得长得像底物。别构打破了这一约束。因为信号通过构象变化传递，*任何*分子原则上都能调控*任何*酶——只要进化在其表面某处造出一个结合位点。莫诺称之为"任意性"原理：调控物与靶标之间的化学联系是任意的，因此调控网络可以自由连接生理所需的任何联系——正如在基因调控中，任何信号都能控制任何基因。
:::

### 协同性与敏感性

许多别构酶是位点间相互作用的寡聚体，一个位点结合底物会提高其余位点的亲和力。它们的速率曲线呈**S 形**而非双曲线，希尔（Archibald Hill）1910 年为氧与血红蛋白的结合提出了一个有用的经验描述。

::: proposition 希尔方程 {#prop-hill}
协同蛋白的分数饱和度（或分数速率）常可很好地表示为

$$
\theta = \frac{[\mathrm{S}]^{n_\mathrm{H}}}{K_{0.5}^{\,n_\mathrm{H}} + [\mathrm{S}]^{n_\mathrm{H}}},\qquad\text{等价地}\qquad \log\frac{\theta}{1-\theta} = n_\mathrm{H}\log[\mathrm{S}] - n_\mathrm{H}\log K_{0.5},
$$ {#eq-hill}

其中 $K_{0.5}$ 是给出半饱和的浓度，$n_\mathrm{H}$ 是**希尔系数**。$n_\mathrm{H} = 1$ 给出米氏双曲线；$n_\mathrm{H} > 1$ 表示正协同。该方程仅对 $n$ 个位点同时结合这一非物理的情形精确；对真实蛋白质，$n_\mathrm{H}$ 是陡峭度的经验度量，绝不超过结合位点的数目（血红蛋白：4 个位点，$n_\mathrm{H} \approx 2.8$）。机理模型——同步的 MWC 模型（Monod、Jeffries Wyman 与 Changeux，1965）与顺序的 KNF 模型（Koshland、George Némethy 与 David Filmer，1966）——由构象变化导出 S 形曲线，在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=protein-function)中讲述。
:::

::: example 协同性如何让响应变陡 {#ex-81}
对服从 [[#eq-hill]] 的蛋白质，要使 $\theta$ 从 0.1 升到 0.9，[S] 必须增大多少倍？设 $n_\mathrm{H}$ 分别为 1、2.8 与 4。
::: solution
由 [[#eq-hill]]，$\theta/(1-\theta) = ([\mathrm{S}]/K_{0.5})^{n_\mathrm{H}}$。$\theta = 0.9$ 时该比为 9；$\theta = 0.1$ 时为 1/9；二者之商为 81。所以 $([\mathrm{S}]_{0.9}/[\mathrm{S}]_{0.1})^{n_\mathrm{H}} = 81$，所需倍数为 $81^{1/n_\mathrm{H}}$：

- $n_\mathrm{H} = 1$：81 倍；
- $n_\mathrm{H} = 2.8$：$81^{1/2.8} = 4.8$ 倍；
- $n_\mathrm{H} = 4$：3 倍。

非协同酶需要底物变化 81 倍才能从 10% 活性走到 90% 活性；强协同酶只需三倍的变化。协同性把渐变输入变成近乎开关式的输出，是细胞实现**超敏感性**的几种方式之一。
:::
:::

x: 0, 10
y: 0, 1.05
sliders: n=2.8:1:6:0.1; K=3:0.5:8:0.1
labels: \text{希尔方程 } n_\mathrm{H} = n; \text{米氏方程}
hlines: 0.1; 0.9
caption: 由 [[#eq-hill]] 得到的分数活性 $\theta$ 对底物浓度（任意单位）的曲线，希尔系数 $n$ 与半饱和常数 $K$ 由滑块设定，并画出相同 $K$ 的双曲线作对照。水平线标出 $\theta = 0.1$ 与 $0.9$。调高 $n$，看两条线之间的浓度范围按 $81^{1/n}$ 缩小（[[#ex-81]]）；别构抑制剂通过增大 $K$ 起作用，把陡段向右移动。
:::

::: example 估算希尔系数 {#ex-hill-fit}
某别构酶在底物 2.0 mmol L⁻¹ 时以最大速率的 20% 运转，在 4.0 mmol L⁻¹ 时为 67%。设其服从 [[#eq-hill]]，估算 $n_\mathrm{H}$ 与 $K_{0.5}$。
::: solution
$\theta/(1-\theta)$ 在 2.0 mmol L⁻¹ 为 $0.2/0.8 = 0.25$，在 4.0 mmol L⁻¹ 为 $0.67/0.33 = 2.03$。二者之比为 8.12，由 [S] 加倍产生，所以 $n_\mathrm{H} = \log 8.12/\log 2 = 3.02$。再由 2.0 mmol L⁻¹ 时 $([\mathrm{S}]/K_{0.5})^{3.02} = 0.25$ 得 $K_{0.5} = 2.0\times0.25^{-1/3.02} = 3.17$ mmol L⁻¹。真实数据应作非线性回归拟合全部数据点，或作 $\log[\theta/(1-\theta)]$ 对 $\log[\mathrm{S}]$ 的图（希尔图），其在 $\theta = 0.5$ 附近的斜率即 $n_\mathrm{H}$。
:::
:::

## 共价修饰

别构响应的是细胞内的分子。要响应来自外部的信号——激素、神经递质、光——细胞使用可逆共价修饰，最常见的是磷酸化。

::: definition 可逆共价修饰 {#def-covalent}
当酶活性因化学基团的酶促连接而改变、又由第二种酶去除该基团而恢复时，称该酶受**可逆共价修饰**调控。最常见的是**蛋白激酶**以 ATP 对丝氨酸、苏氨酸或酪氨酸侧链的**磷酸化**，由**蛋白磷酸酶**逆转。其他包括赖氨酸的乙酰化、腺苷酰化、ADP-核糖基化，以及半胱氨酸二硫键的还原与氧化。
:::

Edmond Fischer 与 Edwin Krebs 于 1955 年研究兔骨骼肌糖原磷酸化酶时发现调控性磷酸化（1992 年诺贝尔生理学或医学奖）。Carl 与 Gerty Cori 早已发现磷酸化酶有活性较低的 *b* 型与活性较高的 *a* 型；Fischer 与 Krebs 证明 *b* 转为 *a* 需要 ATP 和第二种酶磷酸化酶激酶，后者把一个磷酸基连到单个丝氨酸（Ser14）上。如今已知人类基因组编码约 500 种蛋白激酶（G. Manning 及同事，2002），磷酸化蛋白质组学调查检测到人类的绝大多数蛋白质在不同时间被磷酸化。

### 级联与放大

肾上腺素到达肌肉细胞时，会引发一连串酶，每一种都激活下一种的多个拷贝（[[cell-biology/cell-signalling]]）：激素-受体复合体激活 G 蛋白，G 蛋白激活腺苷酸环化酶，后者制造环磷酸腺苷；cAMP 激活蛋白激酶 A；蛋白激酶 A 磷酸化并激活磷酸化酶激酶；磷酸化酶激酶再磷酸化糖原磷酸化酶，使其转为 *a* 型。同一个激酶还磷酸化糖原合酶并使其*失活*，于是糖原不会一边被合成一边被分解。

::: example 级联的放大 {#ex-cascade}
设（示意性地）级联的四个放大步骤——受体到 G 蛋白与腺苷酸环化酶、环化酶到 cAMP 与有活性的 PKA、PKA 到磷酸化酶激酶、磷酸化酶激酶到磷酸化酶——把信号分别放大 10、100、10 与 100 倍。一个被激素占据的受体能产生多少个磷酸化酶 *a* 分子？若每个的 $k_\mathrm{cat} \approx 50\ \mathrm{s^{-1}}$，它们每秒释放多少个 1-磷酸葡萄糖？
::: solution
放大倍数为 $10\times100\times10\times100 = 10^6$，即每个受体产生 $10^6$ 个磷酸化酶 *a* 分子，每个每秒释放约 50 个 1-磷酸葡萄糖，即每个受体每秒 $5\times10^7$ 个。每个细胞几百个被占据的受体因此能以极高速率动员糖原——若每个激素分子直接作用于酶，则需要无法计数的激素分子。级联还提供多个与其他信号整合的位点（神经刺激释放的 Ca²⁺ 直接激活磷酸化酶激酶，收缩与激素因此叠加），也提供多个关断位点：磷酸二酯酶降解 cAMP，磷酸酶去除磷酸基。
:::
:::

### 由修饰循环构成的开关

激酶与磷酸酶作用于同一蛋白质就构成循环，修饰态蛋白质的稳态分数取决于两者活性之比。Goldbeter 与 Koshland 于 1981 年证明，若两种酶都被其蛋白质底物饱和——工作于"零级"区——该循环就像一个陡峭的开关。

::: proposition 零级超敏感性（Goldbeter–Koshland） {#prop-gk}
设某蛋白质被最大速率 $V_1$、米氏常数 $K_1$ 的激酶转变为修饰态，又被 $V_2$ 与 $K_2$ 的磷酸酶转变回去，两者都服从米氏动力学。记 $u = V_1/V_2$，并把米氏常数对蛋白质总浓度归一，$J_1 = K_1/[\mathrm{P}]_\mathrm{T}$，$J_2 = K_2/[\mathrm{P}]_\mathrm{T}$。稳态下修饰态分数为

$$
f = \frac{2uJ_2}{B + \sqrt{B^2 - 4(1-u)uJ_2}},\qquad B = 1 - u + J_1 + uJ_2.
$$ {#eq-gk}

当 $J_1, J_2 \gg 1$（酶远未饱和）时，$f$ 是 $u$ 的双曲线函数，$J_1 = J_2$ 时形如 $u/(1+u)$。当 $J_1, J_2 \ll 1$（两者都饱和）时，$f$ 在 $u = 1$ 附近的窄范围内从近 0 跳到近 1。假设：酶的浓度远低于蛋白质底物、没有酶被禁锢在复合体中、且已达到稳态。
:::

::: widget plot
f: 2*x*k/((1 - x + k + x*k) + sqrt((1 - x + k + x*k)^2 - 4*(1 - x)*x*k)); x/(1 + x)
x: 0, 3
y: 0, 1.05
sliders: k=0.01:0.001:2:0.001
labels: \text{Goldbeter–Koshland, } J_1 = J_2 = k; \text{一级循环}
caption: 由 [[#eq-gk]] 得到的稳态下处于磷酸化态的蛋白质分数对激酶与磷酸酶活性比 $u = V_1/V_2$ 的曲线，取 $J_1 = J_2 = k$（滑块），并与酶未饱和循环的双曲线 $u/(1+u)$ 比较。$k = 0.01$（酶饱和）时，蛋白质随 $u$ 越过 1 从几乎全未修饰跳到几乎全修饰；把 $k$ 移向 2，开关就软化为渐变响应。
:::

零级超敏感性被认为能锐化许多信号响应，尽管在细胞中它要与其他机制——多位点磷酸化、正反馈与隔离——竞争"类开关行为的主要来源"之名（[[systems-biology/switches-oscillators]]）。

### 其他修饰

- **腺苷酰化。** Earl Stadtman 及同事在 1960 年代后期发现，处于氮同化枢纽的大肠杆菌谷氨酰胺合成酶（十二聚体）随 AMP 基团逐个连到其亚基上而逐渐失活，受细胞氮状态的调控。
- **氧化还原切换。** 在叶绿体中，卡尔文-本森循环的若干酶在光下被激活：它们二硫键被硫氧还蛋白还原，后者接受来自光系统 I 的电子；暗中它们被关闭，从而避免与氧化磷酸戊糖途径构成无效循环（B. B. Buchanan 及同事，自 1960 年代起）。
- **蛋白水解激活。** 消化蛋白酶以无活性的**酶原**（zymogen）形式合成（胰蛋白酶原、糜蛋白酶原），进入肠道经切割激活，从而保护制造它们的胰腺；血液凝固与补体是酶原激活的级联。这一开关不可逆：活性酶只能靠抑制剂或降解来关闭。

## 谁在控制通量？

生物化学教科书曾把每条途径都描述为有一个**限速步骤**，即一个决定通量的慢酶。这一想法诱人却常常错误，而看清其原因的方式，导致了定量生物学最有用的框架之一。

### 代谢控制分析

Henrik Kacser 与 Jim Burns（1973）以及各自独立的 Reinhart Heinrich 与 Tom Rapoport（1974）追问：把一个酶活性改变一小量，途径的稳态通量会改变多少。

::: definition 通量控制系数 {#def-control}
酶 $i$ 对途径稳态通量 $J$ 的**通量控制系数**，是通量的分数变化除以该酶活性 $E_i$ 的分数变化，取其他条件不变的小变化：

$$
C^J_{E_i} = \frac{\partial\ln J}{\partial\ln E_i} \approx \frac{\Delta J/J}{\Delta E_i/E_i}.
$$ {#eq-control}

系数为 1 表示该酶完全限速（其活性增加 10%，通量就提高 10%）；0 表示改变它对通量没有影响。控制系数是整个系统在某一特定稳态的性质，而不是单个酶的性质：同一个酶在一种组织或条件下控制很强，在另一种下可能几乎没有。
:::

::: proposition 加和定理 {#prop-summation}
对处于稳态的途径，其全部酶的通量控制系数之和为一：

$$
\sum_i C^J_{E_i} = 1.
$$ {#eq-summation}

假设：每个反应的速率与其酶的活性成正比，且系统的稳态由这些酶与固定的外部浓度（源与库）决定。
:::

::: proof 要点
设所有酶的活性都乘以同一因子 $(1+\varepsilon)$。于是在旧的代谢物浓度下每个速率都增大该因子，因此那些浓度仍是稳态，而通量就增大 $(1+\varepsilon)$ 倍。通量的分数变化 $\varepsilon$ 应等于每个酶的分数变化之效应的总和，$\sum_i C^J_{E_i}\,\varepsilon$。故 $\sum_i C^J_{E_i} = 1$。
:::

该定理有一个惊人的推论。若一条途径有十个酶，控制就由它们分享，平均系数只有 0.1。真正的限速步骤（$C = 1$）只有在其他所有酶的控制都为零时才可能，这很罕见。而且，由于一种酶活性的大幅提高会把控制转移到其他酶上，提高一种酶很少能大幅提高通量。

::: example 估算控制系数 {#ex-control}
培养细胞中，通过表达额外的基因拷贝把某酶活性提高 20%，途径通量上升 3%。估算其通量控制系数。若该途径另有五个控制大致相等的酶，它们的系数各是多少？
::: solution
由 [[#eq-control]]，$C \approx 0.03/0.20 = 0.15$（用对数则 $\ln1.03/\ln1.20 = 0.16$；小变化下两者一致）。由 [[#eq-summation]]，其余五个分享 $1 - 0.15 = 0.85$，各约 0.17。没有酶是限速的；控制是分布式的。这正是 Jürgen Heinisch、Fritz Zimmermann 及同事在 1980 年代对面包酵母逐一过表达糖酵解酶时的发现：没有一个能明显提高乙醇生成的速率。
:::
:::

::: warning "限速步骤就是最慢的酶"
在稳态途径中每个酶承载相同的通量，所以哪个都不比别的"慢"。最大活性相对通量而言较低的步骤可能有高控制，但控制还取决于每个酶的速率对其底物与产物的响应强度（其**弹性系数**）以及反馈。一个酶可能恰恰*因为*被反馈强烈调控而控制很小：其活性提高时，它的终产物上升又把它抑制回去。而且控制是稳态的性质——安静时控制通量的酶，运动时未必还在控制。"限速步骤"最好留给经测定证明确实控制系数接近 1 的步骤。
:::

那么，若不在一个限速酶上，调控到底作用于何处？受调控的酶通常是催化远离平衡步骤的酶（近平衡步骤只是跟随质量作用；通量-作用力关系见[化学图谱：糖酵解](/learn/chemistry/lesson.php?c=biochemistry&l=glycolysis-citric-acid)）。但控制分析表明，要大幅改变通量，最好是同时改变几个酶，例如一种激素磷酸化其中几个，或一次性诱导一条途径的全部基因。David Fell 称之为**多位点调节**（*Understanding the Control of Metabolism*，1997）；这解释了为什么基因表达程序通常把整条途径一起开启。

### 底物循环

在葡萄糖代谢的三个位点上，由不同酶催化的相反反应使同一对代谢物互相转换：6-磷酸果糖与 1,6-二磷酸果糖分别由磷酸果糖激酶-1（糖酵解）与 1,6-二磷酸果糖磷酸酶（糖异生）相互转换。两者同时运转只是水解 ATP，这样的一对曾被称为"无效循环"。Eric Newsholme 在 1970 年代论证，低速的循环是为敏感性付出的代价。

::: example 底物循环带来的敏感性 {#ex-cycle}
某组织中，循环的正方向反应以 10 个单位运转，逆方向 9 个单位，净通量为 1。某效应物把正方向速率提高 20%（到 12），逆方向不变。净通量改变几倍？与一个没有逆反应的途径比较。
::: solution
净通量从 $10 - 9 = 1$ 变为 $12 - 9 = 3$，一个酶变化 20% 就使净通量增高三倍（200%）。若没有逆反应，提高 20% 只使通量增加 20%。若效应物还抑制逆方向的酶（正如 2,6-二磷酸果糖激活 PFK-1 并抑制 1,6-二磷酸果糖磷酸酶），放大还要更大。代价是循环水解的 ATP，这里为 9 个单位。用同位素测定的肝中循环速率确实只占净通量的一小部分。
:::
:::

底物循环还可能产热。熊蜂在寒冷天气起飞前能加热其飞行肌，有些物种的飞行肌中 1,6-二磷酸果糖磷酸酶活性极高，Newsholme 及同事（1972）提出它与 PFK 构成循环以产生热量。后来的比较研究（J. F. Staples 及同事，2004）发现该酶活性在熊蜂各物种之间差异很大，并质疑与飞行肌战栗相比，这个循环究竟能产生多少热——这一假说仍有争议。

## 实例：磷酸果糖激酶

磷酸果糖激酶-1（PFK-1）把 6-磷酸果糖送入糖酵解，本章的大多数调控机制在这一个酶上都有体现。

- **ATP 的别构抑制。** ATP 是底物，但高浓度时它还结合一个调控位点，降低对 6-磷酸果糖的亲和力，于是能量充裕时酶变慢。柠檬酸报告三羧酸循环的燃料充裕，会增强这种抑制。
- **AMP 与 ADP 的激活。** 因为腺苷酸激酶反应（$2\,\mathrm{ADP} \rightleftharpoons \mathrm{ATP} + \mathrm{AMP}$）接近平衡，ATP 的小幅下降会造成 AMP 大幅的相对上升（[[biochemistry/bioenergetics]]），使 AMP 成为能量紧缺的灵敏信号。
- **经 2,6-二磷酸果糖的激素调控。** 1980 年，Émile Van Schaftingen、Louis Hue 与 Henri-Géry Hers 在鲁汶发现（其他实验室也几乎同时发现）这一代谢物，它是肝 PFK-1 最强的激活剂。其水平由一个双功能酶设定，该酶的激酶活性与磷酸酶活性因磷酸化而被切换，受胰高血糖素控制——于是激素通过一个别构效应物控制肝中的糖酵解与糖异生。
- **同工酶。** 哺乳动物有肌型、肝型与血小板型，调控性质各不相同。
- **进化变异。** 细菌的 PFK 受磷酸烯醇式丙酮酸的别构抑制；许多植物与原生生物在 ATP-PFK 之外还有可逆的、依赖焦磷酸的 PFK，以 PPᵢ 代替 ATP——管理同一代谢枢纽的另一种方式。

::: quiz
一条五酶途径，前四个酶的通量控制系数测得为 0.05、0.40、0.20 与 0.10。第五个酶的控制系数是多少？若只选一个酶作靶标来提高通量，哪个最好？
- [ ] 0.75；第五个酶。
- [x] 0.25；第二个酶，不过单独提高它得到的增益会低于正比。
- [ ] 不知道各酶的最大速率就无法确定。
- [ ] 1；途径中的每个酶都是限速的。
::: solution
由加和定理，$C_5 = 1 - (0.05 + 0.40 + 0.20 + 0.10) = 0.25$。第二个酶控制最多，所以对它作小幅提高会给出最大的通量分数增益（每 1% 约 0.4%）。但其活性升高时，控制会转移到其他酶，因此大幅提高收益递减。要大幅提高通量，应同时提高几个酶。
:::
:::

::: application 代谢工程
想让微生物或作物多产某种产物——氨基酸、生物燃料、药物前体——的代谢工程师，从控制分析学到了：过表达一个"限速"酶常常令人失望。成功的策略是解除反馈抑制（使用抗反馈的突变酶，如工业上谷氨酸棒杆菌（*Corynebacterium glutamicum*）生产赖氨酸的做法）、同时提高多个酶、删除竞争分支，并平衡 NADPH 与 ATP 等辅因子的供应（[[systems-biology/metabolic-networks]]，[[biotechnology]]）。
:::

::: history
希尔 1910 年为血红蛋白提出其方程。Carl 与 Gerty Cori 在 1930–40 年代描述了磷酸化酶的 *a* 型与 *b* 型，Fischer 与 Krebs 于 1955 年发现调控性磷酸化。反馈抑制由 Umbarger 与 Yates、Pardee 于 1956 年各自独立发现。莫诺、Changeux 与 Jacob 于 1963 年引入 allosteric（别构）一词，同步模型（Monod、Wyman 与 Changeux）随后于 1965 年提出，顺序模型（Koshland、Némethy 与 Filmer）于 1966 年。Gerhart 与 Schachman 于 1965 年把 ATCase 的催化亚基与调节亚基分开。Kacser 与 Burns（1973）以及 Heinrich 与 Rapoport（1974）创建了代谢控制分析；Goldbeter 与 Koshland 于 1981 年描述了零级超敏感性；2,6-二磷酸果糖发现于 1980 年。
:::

## 由此走向何处

这些机制在一切代谢受调控之处重现：[[biochemistry/glycolysis-tca]] 中的 PFK 与丙酮酸激酶，[[biochemistry/oxidative-phosphorylation]] 中的呼吸控制，以及 [[biochemistry/metabolic-integration]] 中整体生物体在贮存与动员之间的激素切换。它们的动力学——开关、振荡器与鲁棒性——在 [[systems-biology]] 中展开。

::: summary
- 酶活性的调控时间尺度从毫秒（底物、别构效应物）经分钟（共价修饰）到小时（酶量），并由区隔化调控。
- 终产物对调空步骤的反馈抑制（异亮氨酸之于苏氨酸脱氨酶；CTP 之于 ATCase）是别构的：效应物结合他处、通过构象起作用，因此任何代谢物都能调控任何酶。
- 协同性给出 S 形动力学，经验上由希尔方程描述；从 10% 活性到 90% 活性需要底物改变 $81^{1/n_\mathrm{H}}$ 倍。
- 激酶的磷酸化与磷酸酶的去磷酸化把酶与激素连接起来；级联以 $10^6$ 倍放大信号；饱和的修饰循环充当开关（Goldbeter–Koshland）。
- 代谢控制分析：通量控制系数 $C^J_{E_i} = \partial\ln J/\partial\ln E_i$ 之和为 1，因此控制通常被分享，单一"限速步骤"罕见。
- 底物循环以 ATP 为代价换来敏感性；PFK-1 集别构（ATP、AMP、柠檬酸）、经 2,6-二磷酸果糖的激素调控与同工酶于一身。
:::

## 练习

::: exercise 81 倍规则 {level=1 check="13.3"}
$n_\mathrm{H} = 1.7$ 的酶（如葡萄糖激酶）从最大速率的 10% 升到 90%，底物浓度须增大多少倍（三位有效数字）？
::: solution
$81^{1/1.7} = 13.3$。
:::
:::

::: exercise 控制求和 {level=1 check="0.3"}
一条四酶途径中，三个酶的通量控制系数为 0.1、0.2 与 0.4。第四个是多少？
::: solution
由 [[#eq-summation]]，$1 - 0.7 = 0.3$。
:::
:::

::: exercise 由两点求希尔系数 {level=2 check="2"}
某酶在底物 1.0 mmol L⁻¹ 时活性为 10%，在 3.0 mmol L⁻¹ 时为 50%。用 [[#eq-hill]] 求 $n_\mathrm{H}$（一位有效数字）。
::: solution
50% 时 $[\mathrm{S}] = K_{0.5} = 3.0$。10% 时 $\theta/(1-\theta) = 1/9 = (1/3)^{n_\mathrm{H}}$，所以 $n_\mathrm{H} = \ln 9/\ln 3 = 2.0$。
:::
:::

::: exercise 底物循环的放大 {level=2 check="4.9"}
某底物循环正方向速率 10、逆方向速率 9.5（任意单位）。效应物使正方向提高 10%、逆方向降低 10%。净通量增大几倍？与逆方向为 8 的循环比较。
::: solution
净通量从 $10 - 9.5 = 0.5$ 变为 $11 - 8.55 = 2.45$，增大 4.9 倍，来自两个酶各 10% 的变化。逆方向为 8 时，从 2 变为 $11 - 7.2 = 3.8$，只增大 1.9 倍。两个速率越接近（相对净通量的循环越多），放大就越大——花掉的 ATP 也越多：第一种情况下每 0.5 单位净通量对应 9.5 单位循环。
:::
:::

::: exercise 脱敏的 ATCase {level=2}
Gerhart 与 Pardee 发现，经汞化合物处理的 ATCase 失去对 CTP 与 ATP 的响应，动力学呈双曲线而非 S 形，$V_{\max}$ 与天然酶相近或更高。(a) 这说明 CTP 结合在何处、协同性源自何处？(b) 无效应物存在时，为什么脱敏酶在低天冬氨酸浓度下的活性可能高于天然酶？
::: solution
(a) CTP 结合在与活性位点分开的位点上（后来证实位于单独的调节亚基上），因为调控丧失后活性仍然存在；S 形动力学取决于完整复合体中亚基间的相互作用，去除调节亚基后这些作用即遭破坏。(b) 天然酶中，调节亚基稳定低亲和力的 T 态；无底物或 ATP 时多数分子处于该态，所以低天冬氨酸下活性低。游离的催化三聚体则类似高亲和力的 R 态，低底物下也有活性。别构酶在天然形式中常处于*受抑*状态；调控就是解除这种抑制。
:::
:::

::: exercise 激酶-磷酸酶开关 {level=2}
用 [[#eq-gk]]，取 $J_1 = J_2 = 0.01$，$u = 0.9$ 时修饰态分数约 0.08，$u = 1.1$ 时约 0.91。(a) 要把蛋白质从 8% 修饰切换到 91% 修饰，激酶与磷酸酶的活性比须变化几倍？(b) 与一个服从米氏动力学的单一结合位点比较。(c) 说出两种会削弱该开关的细胞情形。
::: solution
(a) 从 0.9 到 1.1，为 $1.1/0.9 = 1.22$ 倍——22% 的变化。(b) 双曲线响应大约需要 [[#ex-81]] 中的 81 倍变化，才能从 10% 走到 90%。(c) 酶未饱和（其 $K_\mathrm{m}$ 与底物蛋白质浓度相当或更大）、底物蛋白质的很大一部分被禁锢在酶复合体中（酶与底物浓度相近时）、或有额外反应移除或降解修饰态蛋白质。
:::
:::

::: exercise 解读酶滴定 {level=3}
用酶 X 的专一性不可逆抑制剂的递增浓度降低酶 X 的活性，同时测定某肝途径的通量：

| X 活性（正常值的百分比） | 100 | 80 | 60 | 40 | 20 |
|---|---|---|---|---|---|
| 通量（正常值的百分比） | 100 | 97 | 91 | 78 | 52 |

(a) 用头两个数据点估算正常活性下 X 的通量控制系数。(b) 随 X 被抑制，控制系数如何变化，为什么？(c) 一项遗传学研究发现，X 基因一个无效等位基因的杂合子（50% 的正常活性）其途径通量没有可检出的变化。这与数据一致吗？它解释了遗传学的什么普遍现象？
::: solution
(a) $C \approx (\Delta J/J)/(\Delta E/E) = (-3/100)/(-20/100) = 0.15$（用对数，$\ln0.97/\ln0.8 = 0.14$）。
(b) 在活性 40% 与 20% 之间，活性减半，通量从 78 降到 52：$C \approx \ln(52/78)/\ln(20/40) = 0.58$。随 X 被抑制控制上升，因为其余酶此时有闲置的能力，X 变得更限制。控制系数是某一特定状态的性质。
(c) 一致：活性 50% 时，表格预测通量约为正常值的 85–90%，这一变化与个体差异相比可能难以检出。这正是 Kacser 与 Burns 对**显性**的解释（1981）：因为控制在许多酶之间分享，多数酶的控制系数很小，所以一个酶减半（如失活等位基因的杂合子）对通量影响甚微，野生型等位基因表现为显性。因此，多数失活突变的隐性是代谢网络结构的结果，而不是某种特殊的显性修饰基因（[[genetics/extensions-of-mendel]]）。
:::
:::

::: exercise 设计抗反馈的途径 {level=3}
一家生物技术公司想让 *E. coli* 过量生产氨基酸苏氨酸。苏氨酸由天冬氨酸经分支途径合成（分支还通向赖氨酸与甲硫氨酸）；第一个酶天冬氨酸激酶以三种同工酶形式存在，其中一种（AK I）受苏氨酸抑制；高丝氨酸脱氢酶位于赖氨酸分支之后，也受苏氨酸抑制。(a) 为什么单纯增加 AK I 基因的拷贝带来的苏氨酸增产有限？(b) 提出能共同提高苏氨酸产量的三种遗传改造，并各用本章内容加以解释。(c) 改造后的细胞可能出现什么新问题？
::: solution
(a) 更多的酶会抬高苏氨酸，苏氨酸更强地抑制 AK I 与高丝氨酸脱氢酶，把大部分增益抵消掉；而且按控制分析，通量取决于许多酶，只提高一个只有很小的分数增益。
(b) (1) 用抗反馈的突变型取代 AK I 与高丝氨酸脱氢酶（例如以抗苏氨酸类似物的毒性筛选所得），解除别构刹车。(2) 同时过表达途径的多个酶（多位点调节），例如整个 *thr* 操纵子。(3) 削弱竞争分支（赖氨酸与甲硫氨酸合成）与苏氨酸的降解，并加强苏氨酸的外排。进一步的做法还可增加天冬氨酸以及脱氢酶步骤所用 NADPH 的供应。
(c) 失去反馈后，细胞可能把过多的碳、ATP 与 NADPH 转向苏氨酸而减慢生长，或陷入赖氨酸与甲硫氨酸的短缺；胞内高浓度的苏氨酸还可能抑制其他酶。工业菌株在产量与生长之间取得平衡，有时先让培养物长够，再开启生产。
:::
:::
