如果你能称量一个生长中的细菌的干重，其中一半以上会是蛋白质。蛋白质是代谢的催化剂，是膜上的泵与通道，是细胞骨架以及肌腱、毛发与丝纤维的构成纤维，是肌肉的马达，是信号转导的受体与开关，是免疫的抗体，也是开启与关闭基因的调控因子。它们全部以同一种方式构建：作为无分支的氨基酸链，首尾以肽键相连，折叠成——通常自行折叠成——精确执行其功能的三维形状。

本章从生物学家的角度看待蛋白质：把它们当作有进化历史的基因产物，在拥挤的细胞中被制造、折叠、获得帮助、受损与降解，并借助从凝胶到质谱仪与结构预测的一系列方法加以研究。氨基酸的化学——它们的酸碱行为、等电点、肽键的几何与折叠的热力学——在[化学图谱：氨基酸与蛋白质结构](/learn/chemistry/lesson.php?c=biochemistry&l=amino-acids-proteins)中展开，这里只链接而不重复。

## 用数字看蛋白质

在进入细节之前，先给几个数量级，取自 R. Milo 与 R. Phillips 的汇编（*Cell Biology by the Numbers*，2016）及其引用的来源。

- 一个 *Escherichia coli*（大肠杆菌）细胞干重约 0.3 pg，其中约 55% 是蛋白质，约有 4300 个蛋白质编码基因。
- 细胞质中蛋白质浓度约为每立方微米 200 万–400 万个分子，大分子（蛋白质、RNA、DNA）总浓度为 300–400 g L⁻¹（S. B. Zimmerman 与 S. O. Trach，1991）：细胞内部更像凝胶，而不是稀溶液。
- 一种典型蛋白质有 300–400 个氨基酸残基；最短的功能蛋白质只有几十个，而巨大的肌肉蛋白质肌联蛋白（titin）有超过 34,000 个。
- 丰度的跨度极大：在单个细胞中，最丰富的蛋白质（核糖体蛋白质、糖酵解酶、延伸因子 EF-Tu）有数万到数十万个拷贝，而许多调控因子只有几十个。

::: example 一个细菌中有多少个蛋白质分子？ {#ex-count}
取干重 0.30 pg、蛋白质比例 55%、平均长度 300 个残基、平均残基质量 110 Da（g mol⁻¹），估算一个 *E. coli* 细胞中的蛋白质分子数。
::: solution
蛋白质质量为 $0.55\times0.30\times10^{-12}\ \mathrm{g} = 1.65\times10^{-13}\ \mathrm{g}$。一个平均蛋白质的摩尔质量为 $300\times110 = 33\,000\ \mathrm{g\,mol^{-1}}$，即质量为 $33\,000/6.022\times10^{23} = 5.48\times10^{-20}\ \mathrm{g}$。分子数为 $1.65\times10^{-13}/5.48\times10^{-20} = 3.0\times10^6$——约三百万个蛋白质，即通常引用的数字。若细胞体积约 1 µm³，即每 µm³ 三百万个，落在上述范围的中间。
:::
:::

## 二十种氨基酸

::: definition α-氨基酸与残基 {#def-amino-acid}
**α-氨基酸**的同一个碳——α-碳——上连有一个氨基、一个羧基、一个氢原子和一个可变的**侧链**（R 基）。除甘氨酸（R = H）外，所有氨基酸的 α-碳都是立体中心，而蛋白质中的氨基酸全部为 **L** 构型。氨基酸连成链时各失去一分子水的成分，留下的单元称为**残基**。
:::

在生理 pH 下，游离氨基酸是偶极离子，带 $\mathrm{NH_3^+}$ 与 $\mathrm{COO^-}$；在蛋白质中只有链的两端带这些基团，电荷主要来自侧链。遗传密码是在侧链之间做出选择，把它们按家族来记最为有用。全文使用三字母与一字母符号（Leu, L）。

| 家族 | 氨基酸 | 侧链的生物学作用 |
|---|---|---|
| 非极性、脂肪族 | 甘氨酸（Gly, G）、丙氨酸（Ala, A）、缬氨酸（Val, V）、亮氨酸（Leu, L）、异亮氨酸（Ile, I）、甲硫氨酸（Met, M）、脯氨酸（Pro, P） | 蛋白质核心、跨膜段；Gly 柔性，Pro 刚性（螺旋破坏者） |
| 芳香族 | 苯丙氨酸（Phe, F）、酪氨酸（Tyr, Y）、色氨酸（Trp, W） | 核心与结合位点；Tyr 与 Trp 在 280 nm 吸收，用于测定蛋白质浓度 |
| 极性、不带电 | 丝氨酸（Ser, S）、苏氨酸（Thr, T）、半胱氨酸（Cys, C）、天冬酰胺（Asn, N）、谷氨酰胺（Gln, Q） | 氢键；Ser、Thr 与 Tyr 在信号转导中被磷酸化；Cys 形成二硫键 |
| 酸性 | 天冬氨酸（Asp, D）、谷氨酸（Glu, E） | 负电荷；结合金属；催化 |
| 碱性 | 赖氨酸（Lys, K）、精氨酸（Arg, R）、组氨酸（His, H） | 正电荷；结合 DNA 与磷酸基；His（$\mathrm{p}K_\mathrm{a}$ 近 6–7）充当质子传递体 |

（有些书把 Tyr、Trp 或 Cys 归入其他家族；界限并不分明。）可电离侧链的大致 $\mathrm{p}K_\mathrm{a}$ 值——Asp 与 Glu 约 4，His 约 6，Cys 约 8，Tyr 约 10，Lys 约 10.5，Arg 约 12.5——连同 [[biochemistry/water-and-bonds#eq-hh]] 告诉我们在任何隔室中它们的电荷。在折叠的蛋白质内部，这些值可移动数个单位，许多酶就依赖这样的移位基团。

这些氨基酸的用量并不均等。在 UniProtKB/Swiss-Prot 数据库中，亮氨酸约占全部残基的 10%，而色氨酸与半胱氨酸只占约 1%，这既反映遗传密码中各自密码子的数目，也反映合成它们的代价。

### 必需氨基酸与生物合成途径的进化

植物与大多数细菌、真菌都能以糖和无机氮合成全部二十种氨基酸。动物失去了许多途径，必须从食物获取相应的氨基酸。人类的九种**必需**氨基酸是 His、Ile、Leu、Lys、Met、Phe、Thr、Trp 与 Val；其他氨基酸在需求超过合成能力时是“条件必需”的。不同动物所需不同：家猫是专性肉食动物，也不能合成足够的精氨酸，一顿不含精氨酸的食物就能使其血氨升高，因为尿素循环停摆了（J. G. Morris 与 Q. R. Rogers，1978；见 [[biochemistry/metabolic-integration]]）。必需氨基酸大体是那些途径长、耗能高的——支链氨基酸与芳香族氨基酸——当饮食可靠地提供它们时，丢掉这些途径为动物省下相应的基因与酶。同样的逻辑解释了为何许多以贫瘠植物汁液为食的昆虫（如蚜虫）依赖为其合成必需氨基酸的共生细菌（*Buchnera aphidicola*）。

遗传密码还有两种额外成员。**硒代半胱氨酸**（Sec, U）以硒取代半胱氨酸的硫，在细菌、古菌与动物的某些 UGA 密码子处插入，人类约有 25 种蛋白质含有它；**吡咯赖氨酸**（Pyl, O）在某些产甲烷古菌（如 *Methanosarcina barkeri*）中于 UAG 处插入（2002 年）。它们有时被称为第 21 与第 22 种氨基酸（[[molecular-biology/translation]]）。

## 肽键与一级结构

氨基酸通过一个的羧基与下一个的氨基之间的缩合相连，形成称为**肽键**的酰胺。C–N 键具有部分双键性质，所以其周围六个原子共面，且几乎总取 *trans* 排布；只有绕每个 α-碳的两个键可以旋转，用扭转角 φ 与 ψ 描述。G. N. Ramachandran 与同事在 1963 年证明，位阻冲突禁绝了大多数 φ 与 ψ 组合，只留下少数允许区域——α螺旋与 β折叠所在的区域即在其中。（细节见[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=amino-acids-proteins)。）

::: definition 蛋白质结构的四个层次 {#def-levels}
蛋白质的**一级结构**是其氨基酸残基的序列，从游离氨基端（N-端）写到游离羧基端（C-端），连同任何共价交联（如二硫键）。**二级结构**是主链的局部规则构象，由主链氢键维系——主要是 α螺旋与 β折叠。**三级结构**是一条链的完整三维折叠。**四级结构**是复合体中若干条已折叠链（亚基）的排布。
:::

1951 年桑格（Frederick Sanger）与 Hans Tuppy，随后桑格与 E. O. P. Thompson，测定了牛胰岛素两条链的序列，并于 1955 年连同其二硫键完成了整个结构。这是第一个证明：一种蛋白质有单一而确定的序列——因而必定有某个东西（后来知道是基因）决定它。Pehr Edman 从 N-端逐个移除残基的方法（1950 年）在此后三十年间成为测定蛋白质序列的标准途径。今天几乎所有蛋白质序列都由 DNA 序列推得，蛋白质本身则由质谱鉴定与定量。

::: proposition 多肽的质量与长度（经验） {#prop-mass}
含 $n$ 个残基的蛋白质的摩尔质量近似为

$$
M \approx 110\,n\ \ \mathrm{g\,mol^{-1}},
$$ {#eq-mass}

所以 1 kDa 约对应 9 个残基。因子 110 Da 是按各氨基酸在蛋白质中出现频率加权的平均残基质量（残基质量从甘氨酸的 57 Da 到色氨酸的 186 Da 不等）。这是一个经验平均值：富含甘氨酸与丙氨酸的蛋白质更轻，而糖蛋白可以重得多。
:::

## 二级结构

1951 年，鲍林（Linus Pauling）、Robert Corey 与 Herman Branson 从平面肽的几何与主链 N–H 和 C=O 基团必须形成氢键的要求出发，预言了两种规则结构，此后它们几乎在每一种蛋白质中都被发现。

- **α螺旋**是右手螺旋，每圈 3.6 个残基，每残基沿轴上升 0.15 nm（螺距 0.54 nm）。每个 C=O 与沿链往前数第四个残基的 N–H 形成氢键，侧链指向外侧。
- **β折叠**由并排铺开的伸展股（每残基 0.32–0.34 nm）构成，股之间形成氢键，可平行或反平行。
- 转角与环往往富集 Gly 与 Pro，把它们连接起来并使链的方向折返。

螺旋与股是在内部满足主链氢键的紧凑方式，当链埋离水环境——蛋白质内部或膜内部——时这是必不可少的。约 20 个残基的螺旋正好横跨脂双层 3 nm 的烃核心，序列中约 20 个连续的疏水残基是膜蛋白质的特征，可由疏水性作图（hydropathy plot）找出（J. Kyte 与 R. F. Doolittle，1982；见 [[cell-biology/membranes]]）。**两亲性**螺旋每隔三四个位置有一个疏水残基，沿膜表面平铺，或彼此堆积成卷曲螺旋。

## 三级与四级结构：折叠类型、结构域与家族

1958 年肯德鲁（John Kendrew）与同事用 X 射线晶体学解析了第一个蛋白质结构：抹香鲸肌肉的肌红蛋白，一条 153 个残基的链折成八个 α螺旋环绕一个血红素基团。佩鲁茨（Max Perutz）的马血红蛋白结构随后于 1959–60 年完成——四条链（$\alpha_2\beta_2$）每条都折叠得像肌红蛋白（1962 年诺贝尔化学奖）。肌红蛋白令人意外的是它的不规则，但随着更多结构被解析，一些普遍规则浮现出来：非极性侧链堆在核心，几乎不留缝隙；极性与带电的排在表面；链被组织成一个或多个紧凑的**结构域**。

::: definition 结构域与同源性 {#def-domain}
**结构域**是多肽链的一部分，通常长 50–250 个残基，基本上独立于链的其他部分折叠成紧凑结构，常常有自己的功能（例如结合 ATP、DNA 或磷酸化肽段）。两个蛋白质或结构域若源自共同的祖先序列则是**同源的**；因物种形成而分化的不同物种中的同源物是**直系同源物**，由同一谱系内基因重复产生的是**旁系同源物**。同源性由统计显著的序列或结构相似性推断。
:::

结构域是蛋白质进化的单位。在演化时间里它们被重复、分歧，并通过编码它们的基因发生重组而被洗牌成新的组合，于是一个大的信号蛋白质可能是十几个结构域串成的珠链，而每个结构域都能在许多其他蛋白质中找到。分类数据库（SCOP、CATH）把已知的数十万个结构域归入几千个家族和少得多的若干折叠类型——这是有限的几种架构被反复使用与改造的证据。

结构比序列保守得多。Cyrus Chothia 与 Arthur Lesk 在 1986 年表明，序列分歧到约 30% 一致度的蛋白质仍共享同一折叠，结构的核心保守，而变化集中在表面的环上。肌红蛋白与血红蛋白的 α、β 链是一例：它们是早期脊椎动物一次古老基因重复产生的旁系同源物，只有约 25% 的一致度，却折叠得几乎相同（[[evolution/evidence-for-evolution]]）。

::: intuition 折叠类型为何保守
蛋白质表面的突变通常改变不大，因为表面残基主要与水接触。核心的突变——侧链像三维拼图一样互相嵌合之处——通常使折叠失稳而被选择清除，除非有一个补偿性变化跟随其后。于是数百万年间表面残基漂变，而核心残基与整体折叠长存，序列一致度比结构相似性衰减得更快。这也是结构预测能够从同源序列的多重比对成功的原因：在同源物之间共同变化的残基，很可能在结构上相互接触。
:::

许多蛋白质以复合体的形式发挥作用。**四级结构**使一个蛋白质能由一个小基因产物的若干拷贝构建（这节省遗传信息并允许质量控制：有缺陷的亚基在装配期间被淘汰），把催化亚基与调控亚基带到一起，并使协同性与别构成为可能（[[biochemistry/enzyme-regulation]]）。

### 内在无序蛋白质

并非每种蛋白质都只有单一折叠。相当一部分真核蛋白质含有**内在无序**的长片段：它们本身没有稳定结构，但在结合伙伴时折叠，或充当柔性的连接件与支架。在 2004 年一项分析中，J. J. Ward 与同事预测约三分之一的真核蛋白质含有超过 30 个残基的无序片段，而细菌与古菌中只有百分之几。无序区域富集带电与极性残基以及 Pro 与 Gly，缺乏庞大的疏水残基。它们在转录因子与信号蛋白质中很常见，携带磷酸化位点与短的结合模体，有些通过液-液相分离驱动无膜隔室的形成（[[cell-biology/organelles]]）。

## 试管中与细胞内的折叠

### 安芬森实验

1950 年代末，安芬森（Christian Anfinsen）与同事研究牛核糖核酸酶 A——一个含 124 个残基、四个二硫键的小酶。他们用 8 mol L⁻¹ 尿素把它完全去折叠，并用 β-巯基乙醇还原其二硫键，活性随之消失。当他们用透析缓慢除去两种试剂时，链重新折叠，105 种可能的配对中形成了正确的那四个二硫键，活性几乎全部恢复（Anfinsen、E. Haber、M. Sela 与 F. H. White，1961）。反过来，若先除去还原剂，使二硫键在链仍处于尿素中未折叠状态时就形成，大多数分子就“乱配”而失活；随后加入痕量还原剂又使它们重排为活性形式。

结论——**安芬森热力学假说**——是：氨基酸序列含有决定天然结构所需的全部信息，而天然结构（生理条件下的小球蛋白）是自由能最低的状态（1972 年诺贝尔化学奖）。天然态只比去折叠态稍微稳定一些，通常仅 20–60 kJ mol⁻¹——那是化学课里算过的一对相互抵消的大项之间的平衡。这种勉强稳定在生物学上有用：它让蛋白质能够屈挠、被调控、被降解。

::: warning “蛋白质折叠是因为序列是从某个三维模板复制来的”
细胞中没有任何东西复制蛋白质的形状。基因只决定序列；折叠由链与自身及水的相互作用自发产生，有时由分子伴侣协助——伴侣防止出错，却不编码结构。已知能传播一种*构象*的唯一生物因子是朊粒：错折的蛋白质把同样序列的正常折叠拷贝转变成它自己的形式——这一例外恰恰说明此事多么反常。
:::

### 分子伴侣与拥挤的细胞质

从核糖体新生的链面对的条件与安芬森稀薄的试管截然不同。大分子占细胞质体积的 20–30%，部分折叠的链带着暴露的疏水表面，彼此容易粘连聚集。因此细胞拥有**分子伴侣**，这个词由 R. A. Laskey 在 1978 年为核小体装配蛋白质核质蛋白引入，R. J. Ellis 在 1987 年将其推广。

::: definition 分子伴侣 {#def-chaperone}
**分子伴侣**是结合其他蛋白质的非天然形式（去折叠、部分折叠或错折形式）、阻止其聚集并促进其正确折叠或装配、而自身不成为最终结构一部分的蛋白质。许多伴侣利用 ATP 结合与水解的循环结合并释放其客户蛋白。许多是**热激蛋白**（Hsp），在胁迫使蛋白质去折叠时被诱导。
:::

两个系统说明了主要机制。**Hsp70**（细菌中为 DnaK）结合伸展链的短疏水域，把新生蛋白质与受胁迫损伤的蛋白质保持在可溶状态，ATP 水解后释放它们，使其反复获得折叠的机会。**伴侣蛋白**（*E. coli* 中的 GroEL 及其盖 GroES；线粒体中的 Hsp60；真核细胞质中的 TRiC/CCT）是桶状复合体，单条链可以在与外界隔开的封闭腔室内折叠。在 *E. coli* 中只有约 10% 的蛋白质需要 GroEL，但其中一些是必需的，而 GroEL 基因不能删除。分子伴侣还缓冲突变的影响：通过帮助失稳的变体折叠，Hsp90 能掩藏遗传变异，当伴侣过载时这些变异才显现（S. L. Rutherford 与 S. Lindquist，*Drosophila*，1998），有人提出这是影响进化潜力的机制。

### 周转：蛋白质既被合成也被降解

蛋白质不是永久之物。受损与错折的蛋白质，以及只需短暂起作用的调控蛋白质，会被降解——在真核生物中大多先被小蛋白质**泛素**的链标记，然后送入**蛋白酶体**（Aaron Ciechanover、Avram Hershko 与 Irwin Rose，2004 年诺贝尔化学奖），也经自噬在溶酶体中降解。细菌使用依赖 ATP 的蛋白酶，如 Lon 与 ClpXP。蛋白质的稳态含量由合成与两类损失的平衡决定。

::: proposition 降解与稀释 {#prop-turnover}
设某蛋白质以恒定速率 $\sigma$（单位时间单位细胞体积的分子数）合成，以一级速率常数 $k_\mathrm{deg}$ 降解，并被细胞生长以比生长速率 $\mu = \ln 2/T_\mathrm{d}$ 稀释，其中 $T_\mathrm{d}$ 为倍增时间。其浓度 $P$ 满足

$$
\frac{dP}{dt} = \sigma - (k_\mathrm{deg} + \mu)P,
$$ {#eq-turnover}

所以它以有效半衰期 $t_{1/2} = \ln 2/(k_\mathrm{deg} + \mu)$ 趋近稳态 $P^* = \sigma/(k_\mathrm{deg}+\mu)$。假设：指数（平衡）生长、合成恒定、一级降解。
:::

这解释了快速生长的细菌与动物细胞之间的一个基本差别。在每 30 分钟分裂一次的 *E. coli* 中，大多数蛋白质几乎不被降解，其浓度只靠稀释改变：合成被关闭的蛋白质每一代减半。在不分裂的动物细胞中，$\mu \approx 0$，周转只由降解决定；用同位素标记与质谱测定，小鼠成纤维细胞中蛋白质半衰期的中位数约 46 小时，范围从几分钟到几周（B. Schwanhäusser 及同事，*Nature* 473, 337, 2011）。有些蛋白质，如眼晶状体的晶体蛋白与软骨中的胶原蛋白，一生中几乎从不更换。

::: example 蛋白质的响应时间 {#ex-turnover}
一种在每 24 h 倍增一次的培养哺乳动物细胞中的蛋白质，其降解半衰期为 20 h。(a) 其有效半衰期是多少？(b) 若其合成速率加倍，升到新稳态水平的一半需要多长时间？
::: solution
(a) $k_\mathrm{deg} = \ln2/20 = 0.0347\ \mathrm{h^{-1}}$，$\mu = \ln2/24 = 0.0289\ \mathrm{h^{-1}}$；二者之和为 $0.0636\ \mathrm{h^{-1}}$，所以有效半衰期为 $0.693/0.0636 = 10.9$ h。
(b) [[#eq-turnover]] 是线性方程，其解以速率常数 $k_\mathrm{deg} + \mu$ 指数弛豫到新稳态，所以蛋白质在一个有效半衰期——10.9 h——内达到加倍水平的一半。这一要点是系统生物学的核心（[[systems-biology/gene-expression-dynamics]]）：蛋白质浓度的响应时间由它被移除的速度决定，而不是由它被合成的速度决定。因此必须快速变化的蛋白质，如细胞周期蛋白与许多转录因子，都是不稳定的。
:::
:::

### 极端环境中的蛋白质

适应极端温度的生物，其蛋白质显示了进化如何调校折叠的稳定性。1969 年 Thomas Brock 与 Hudson Freeze 从黄石国家公园一处热泉中分离出 *Thermus aquaticus*（水生栖热菌）；其 DNA 聚合酶在近 95 °C 仍稳定，使聚合酶链反应变得实用。*Pyrococcus furiosus*（激烈火球菌）之类古菌最适生长温度接近 100 °C，而 *Methanopyrus kandleri* 菌株 116 在实验室培养中曾在 122 °C 生长（K. Takai 及同事，2008）。它们的蛋白质与其中温同源物共享折叠类型，但往往表面离子对更多、环更短、核心堆得更紧、环中脯氨酸更多。嗜冷（低温适应）生物的酶则相反：结构更柔性，以稳定性为代价在低温下保持快速催化，因此许多在中等升温下就变性。稳定性与活性之间的权衡贯穿酶的进化（[[biochemistry/enzymes]]）。

## 方法：如何研究蛋白质

本章几乎所有知识都来自少数几种方法，每一种都是生物学家应当能够解读的。

**纯化。** 蛋白质按大小（凝胶过滤）、电荷（离子交换）、疏水性与专一性结合（亲和层析——今天常用基因引入的标签，如六个组氨酸，可结合镍）分离。纯度与得率通过测量每一步的活性来跟踪。

**凝胶电泳。** 在十二烷基硫酸钠聚丙烯酰胺凝胶电泳（SDS-PAGE；K. Weber 与 M. Osborn，1969；U. K. Laemmli，1970）中，蛋白质被变性并裹上洗涤剂十二烷基硫酸钠，后者使其单位质量带上几乎均匀的负电荷；在凝胶中它们按大小迁移，小的更快。

::: proposition SDS-PAGE 的校准（经验） {#prop-sds}
在由凝胶丙烯酰胺浓度设定的工作范围内，SDS 变性多肽的相对迁移率 $R_\mathrm{f}$（迁移距离除以染料前沿的距离）对摩尔质量的对数近似线性：

$$
\log_{10} M = a - b\,R_\mathrm{f}.
$$ {#eq-sds}

$a$ 与 $b$ 由同一凝胶上已知质量的对照品确定。这一关系是经验性的，对异常结合 SDS 的蛋白质会失效：很强的碱性或酸性蛋白质、膜蛋白质与高度糖基化的蛋白质常常在“错误”的大小处跑出。
:::

::: example 在凝胶上估量蛋白质大小 {#ex-sds}
116、97.4、66.2、45、31、21.5 与 14.4 kDa 的对照品相对迁移率为 0.14、0.21、0.33、0.46、0.58、0.71 与 0.84。一条未知带的 $R_\mathrm{f} = 0.52$。估算其质量。（拖动下图中的点，看一个放错位置的对照品对估算有多敏感。）
::: solution
质量取 $\log_{10}$ 得 2.064、1.989、1.821、1.653、1.491、1.332 与 1.158。过 $(R_\mathrm{f}, \log_{10}M)$ 的最小二乘直线为 $\log_{10}M = 2.252 - 1.302\,R_\mathrm{f}$，$R^2 = 0.9997$。在 $R_\mathrm{f} = 0.52$：$\log_{10}M = 2.252 - 0.677 = 1.575$，所以 $M \approx 37.6$ kDa。因为标度是对数的，$R_\mathrm{f}$ 差 0.01 就使估算改变约 3%；SDS-PAGE 给出的大小约准到 5–10%，足以认出一种蛋白质，不足以鉴定它。
:::
:::

**蛋白质印迹**（Western blotting）把分开的蛋白质转移到膜上，用抗体检测其中一种，从而在不同条件之间比较细胞提取物中某种特定蛋白质的量。

**质谱**如今主导蛋白质鉴定。蛋白质被电离——用电喷雾电离（ESI；John Fenn，1989）或基质辅助激光解吸（MALDI；田中耕一，1988，以及 Franz Hillenkamp 与 Michael Karas；Fenn 与田中耕一获 2002 年诺贝尔化学奖）——并测量每个离子的质荷比 $m/z$。在**蛋白质组学**中，蛋白质用胰蛋白酶消化，肽段经色谱分离并在仪器中碎裂，碎片质量与由基因组序列预测的质量比对，一次运行就能鉴定数千种蛋白质。

::: example 从电喷雾谱求质量 {#ex-esi}
电喷雾使一个蛋白质带上许多质子，产生一系列电荷为 $z$ 的峰，位于 $m/z = (M + z\,m_\mathrm{H})/z$，其中 $m_\mathrm{H} = 1.007$ Da 是质子质量。马的脱辅基肌红蛋白谱中两个相邻峰在 $m/z$ 1131.11 与 1060.48。求各自的电荷与质量 $M$。
::: solution
若 $p_1 = 1131.11$ 处的峰电荷为 $z$，$p_2 = 1060.48$ 处的峰电荷为 $z+1$，则 $zp_1 = M + zm_\mathrm{H}$ 且 $(z+1)p_2 = M + (z+1)m_\mathrm{H}$。相减得 $z(p_1 - p_2) = p_2 - m_\mathrm{H}$，所以

$$
z = \frac{p_2 - m_\mathrm{H}}{p_1 - p_2} = \frac{1059.47}{70.63} = 15.0.
$$

所以两峰为 $z = 15$ 与 16，$M = 15\times(1131.11 - 1.007) = 16\,951.5$ Da——即马肌红蛋白 153 个残基链除去血红素的质量。由单张谱图，质量可定到约 $10^4$–$10^5$ 分之一，足以检测单个磷酸化（+80 Da）或点突变。
:::
:::

**结构解析。** X 射线晶体学、核磁共振与约 2013 年以来的冷冻电子显微术，已在蛋白质数据库（Protein Data Bank）中积累超过 20 万个实验结构（截至 2024 年）。2020–21 年，AlphaFold2 网络（J. Jumper 及同事，*Nature* 596, 583, 2021）从序列预测单个结构域的结构，准确度常接近实验，其数据库现已收录超过 2 亿个预测结构，覆盖几乎所有已知蛋白质序列（2024 年诺贝尔化学奖由 Demis Hassabis 与 John Jumper 分享，另一半因蛋白质设计授予 David Baker）。这些方法在 [[structural-biology]] 中详述。

::: example 制造蛋白质要花多少能量？ {#ex-cost}
在核糖体上形成一个肽键约耗 4 个高能磷酸键：两个用于把氨基酸连到其 tRNA 上（ATP → AMP + PPᵢ），两个 GTP 用于进位与转位。估算制造一个 *E. coli* 细胞三百万个蛋白质（[[#ex-count]]）的能量代价，并与该细胞的 ATP 总预算比较——以葡萄糖生长时每次分裂约 $1.5\times10^{10}$ 个 ATP（示例值，在 Stouthamer 1973 年估计的范围内）。
::: solution
三百万个 300 残基的蛋白质含 $9\times10^8$ 个肽键，耗 $4\times9\times10^8 = 3.6\times10^9$ 个 ATP 当量——这还未计入合成氨基酸本身、校对与降解错误的代价。这约占示例总预算的四分之一；加上那些额外代价，蛋白质合成是生长细菌中最大的单项能量用途。因此细菌严格地把核糖体的生产调控到与生长速率相称，并在饥饿时最先关掉它。
:::
:::

::: quiz
从一种嗜热细菌及其嗜温近亲纯化一种蛋白质。哪个观察最令人意外？
- [ ] 嗜热菌的蛋白质表面盐桥更多。
- [ ] 两种蛋白质约 50% 序列一致度但折叠可叠合。
- [x] 两种蛋白质约 50% 序列一致度但折叠完全不同。
- [ ] 嗜热菌的酶在 25 °C 比嗜温菌的活性低。
::: solution
50% 一致度的同源物预期共享同一折叠（Chothia 与 Lesk，1986）；结构比序列保守得多。额外的盐桥与低温下较低活性是耐热蛋白质的典型特征，反映稳定性–活性的权衡。
:::

::: application 蛋白质作为靶标与工具
因为每种蛋白质都有一个精确的结合表面，多数药物都通过结合蛋白质起作用——酶、受体、通道与转运蛋白——而生物技术的多数产品也是蛋白质：胰岛素、抗体、洗涤剂与食品加工中的酶，以及分子生物学的聚合酶与核酸酶。蛋白质错折与聚集是一组人类疾病的基础，包括淀粉样蛋白病与朊粒病，其病理学见[医学图谱：病理学](/learn/medicine/course.php?c=pathology)。在农业中，蛋白质质量——必需氨基酸如赖氨酸的含量（谷类蛋白质中偏低）——塑造了动物与人的膳食，也是植物育种的目标，例如优质蛋白玉米。
:::

::: history
“protein”一词 1838 年由贝采利乌斯（Jöns Jacob Berzelius）创造，并经 Gerardus Mulder 使用。费歇尔（Emil Fischer）在 1902–07 年前后证明蛋白质是以酰胺键相连的氨基酸链，并命名了肽键；霍夫迈斯特（Franz Hofmeister）独立提出了同样的想法。萨姆纳（James Sumner）1926 年从刀豆结晶了脲酶，证明酶是蛋白质。随后是 Pehr Edman 的降解法（1950）、桑格的胰岛素序列（1951–55）与鲍林和科里的 α螺旋与 β折叠（1951）。安芬森对核糖核酸酶的复性（1961）确立了序列决定结构。肯德鲁的肌红蛋白（1958）与佩鲁茨的血红蛋白（1960）是第一批蛋白质结构。Laemmli 的凝胶系统（1970）、电喷雾与 MALDI 质谱（1988–89）与 AlphaFold2（2021）改变了研究蛋白质的方式。
:::

## 由此走向何处

折叠建出的结合表面成为 [[biochemistry/enzymes]] 的活性位点，本章的四级结构成为 [[biochemistry/enzyme-regulation]] 的别构机器。蛋白质合成后如何被分拣到各隔室见 [[cell-biology/protein-sorting]]；如何被合成见 [[molecular-biology/translation]]。

::: summary
- 蛋白质占细胞干重的一半以上；一个 *E. coli* 细胞约有 $3\times10^6$ 个蛋白质分子，大分子总浓度 300–400 g L⁻¹。
- 二十种 L-氨基酸（加上硒代半胱氨酸与吡咯赖氨酸）之别在于侧链；人类必须获取九种必需氨基酸，即合成途径最长的那些。
- 一级结构（序列，$M \approx 110n$ Da）、二级结构（α螺旋，每残基 0.15 nm；β折叠）、三级与四级结构；结构域是蛋白质进化的单位，折叠类型比序列保守得久得多。
- 安芬森证明序列决定结构；在拥挤的细胞中，分子伴侣（Hsp70、伴侣蛋白）防止聚集却不编码折叠。许多真核蛋白质有内在无序区域。
- 蛋白质水平由合成、降解与稀释决定：有效半衰期 $\ln2/(k_\mathrm{deg}+\mu)$ 决定响应时间。
- 方法：层析、SDS-PAGE（$\log M$ 对迁移率线性，经验性）、蛋白质印迹、ESI 与 MALDI 质谱、X 射线、核磁共振、冷冻电镜与 AlphaFold。
:::

::: exercise 一段螺旋与一条股 {level=1 check="3.0"}
20 个残基的片段作为 α螺旋长多少 nm？与其作为完全伸展 β股（每残基 0.34 nm）比较。
::: solution
作为螺旋，$20\times0.15 = 3.0$ nm——足以横跨脂双层的烃核心。作为股，$20\times0.34 = 6.8$ nm，长两倍以上；单条股不能单独横跨膜，因为其主链氢键得不到满足，这就是膜 β蛋白质形成由许多股组成的 β桶的原因。

::: exercise 侧链的电荷 {level=1}
用大致 $\mathrm{p}K_\mathrm{a}$ 值（Asp 3.9，His 6.0，Lys 10.5），说明各侧链在细胞质基质（pH 7.2）与溶酶体（pH 4.7）中的主要电荷。
::: solution
细胞质基质：Asp −1（去质子化），His 主要为中性（约 6% 质子化），Lys +1。溶酶体：Asp 仍主要为 −1（约 86% 去质子化，因为 $1/(1+10^{3.9-4.7}) = 0.86$），His 此时主要为 +1（95% 质子化），Lys +1。组氨酸是电荷在这两个隔室之间发生变化的残基，这就是 pH 感受蛋白质常常利用它的原因。
:::
:::

::: exercise 快速生长细菌中的有效半衰期 {level=2 check="27.3"}
在每 30 分钟倍增一次的 *E. coli* 中，一种蛋白质以 5 h 的半衰期降解。其有效半衰期是多少分钟（三位有效数字）？降解与稀释哪个更重要？
::: solution
$k_\mathrm{deg} = \ln2/300\ \mathrm{min} = 0.00231\ \mathrm{min^{-1}}$；$\mu = \ln2/30 = 0.0231\ \mathrm{min^{-1}}$。有效半衰期为 $0.693/0.02541 = 27.3$ 分钟。稀释比降解重要十倍：在快速生长的细菌中，只有半衰期以分钟计的蛋白质才受降解的明显影响。
:::
:::

::: exercise 解读电喷雾谱 {level=2 check="8565"}
牛泛素 ESI 谱中两个相邻峰在 $m/z$ 857.49 与 779.63。求电荷与蛋白质质量，精确到道尔顿（$m_\mathrm{H} = 1.007$ Da）。
::: solution
$z = (779.63 - 1.007)/(857.49 - 779.63) = 778.62/77.86 = 10.0$，所以两峰为 $z = 10$ 与 11。$M = 10\times(857.49 - 1.007) = 8565$ Da（已知平均质量为 8564.8 Da）。
:::

::: exercise 第二条带的大小 {level=2 check="53.9"}
用 [[#ex-sds]] 的校准直线估算 $R_\mathrm{f} = 0.40$ 处条带的质量（kDa，三位有效数字）。同一蛋白质从凝胶过滤柱在 108 kDa 对照品的位置洗脱。你能得出什么结论？
::: solution
$\log_{10}M = 2.252 - 1.302\times0.40 = 1.732$，所以 $M = 53.9$ kDa。凝胶过滤按大小分离天然蛋白质，所以约为亚基质量两倍的天然质量提示该蛋白质是两个相同 54 kDa 亚基的二聚体（凝胶过滤假定为球状形状，所以伸长的单体也可能跑出偏大的表观大小；用分析超离心或天然复合体的质谱可以区分二者）。
:::

::: exercise 安芬森的对照 {level=2}
在安芬森的实验中，(a) 为什么必须尿素与 β-巯基乙醇同时存在才能完全灭活核糖核酸酶？(b) 为什么先除去 β-巯基乙醇得到的是失活的“乱配”产物，而后再加入痕量 β-巯基乙醇又能挽救它？(c) 八个半胱氨酸随机形成四个二硫键全部正确的概率是多少？
::: solution
(a) 单独尿素能去折叠链，但四个二硫键把链的若干部分拴在一起；单独巯基乙醇无法进入折叠蛋白质内的所有二硫键。两者合用才得到完全去折叠、二硫键全还原的链。(b) 尿素仍在时链是伸展的，二硫键就在随机配对的半胱氨酸之间形成；乱配的蛋白质被困住，因为共价键不会自发重排。一点还原剂催化二硫键交换，让链尝试各种配对直到到达最稳定——即天然——的结构：这是天然态为热力学极小值的证据。(c) 八个半胱氨酸配对方式数为 $7\times5\times3\times1 = 105$，所以随机配对得到正确配对集合的概率为 $1/105 \approx 1\%$；乱配核糖核酸酶上观察到的约 1% 活性恢复与此相符。
:::

::: exercise 解读热激实验 {level=3}
酵母细胞从 25 °C 移入 37 °C。几分钟内，少数蛋白质的合成上升 10–50 倍（包括 Hsp70 与 Hsp104），而大多数蛋白质合成下降；预先这样处理的细胞在随后暴露于 50 °C 时的存活远好于未处理细胞。缺失 Hsp104 的突变体在 25 °C 与 37 °C 生长正常，但不能获得对 50 °C 的耐受。(a) 用蛋白质折叠解释热激反应。(b) 突变体的表型告诉你 Hsp104 的什么作用？(c) 细胞为何不一直把这些伴侣保持在高水平？
::: solution
(a) 热使勉强稳定的蛋白质失稳，暴露出会聚集的疏水表面。去折叠蛋白质的积累激活一个转录因子（酵母中的 Hsf1），诱导伴侣基因；伴侣结合去折叠蛋白质，阻止聚集，并使其复性或被靶向降解。(b) Hsp104 在适中温度生长时不需要，而在经受严重胁迫后存活时需要——这与其已知功能一致：把已经聚团的蛋白质解聚，在胁迫后挽救它们（Y. Sanchez 与 S. Lindquist，1990）。(c) 伴侣在诱导后是最丰富的蛋白质之一；合成它们要耗费 ATP 与本可用于生长的核糖体容量（见 [[#ex-cost]]），而过量的伴侣活性会干扰正常折叠、信号转导与降解。只在需要时诱导更划算。
:::
:::

::: exercise 为什么要形成寡聚体？ {level=3}
许多酶是同源寡聚体（两到十二个相同亚基），尽管单个亚基已含完整的活性位点。用本章与 [[biochemistry/water-and-bonds]] 的观念，给出选择可能偏好寡聚体的三个理由，以及检验寡聚化对某一酶是否重要的一个方法。
::: solution
(1) 遗传经济性与质量控制：一个大结构由一个短基因编码，有缺陷的亚基在装配时被排除。(2) 稳定性：亚基界面埋藏非极性表面（疏水效应），可稳定每个折叠并降低周转。(3) 调控：相互作用的亚基允许协同性与别构（[[biochemistry/enzyme-regulation]]），活性位点可建在界面上。(4) 避免聚集或形成有用的几何形状，如环与丝。一种检验：在界面处（由结构确定）引入阻止寡聚化而不触动活性位点的点突变，用凝胶过滤或天然质谱确认蛋白质是单体，然后比较表达该突变体的细胞的活性、稳定性、调控与生长。（有些寡聚体可能只是中性的——进化研究表明界面可因中性突变而固化，所以并非每个寡聚体都是适应。）
:::
