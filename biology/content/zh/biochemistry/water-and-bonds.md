每个细胞大部分是水。像 *Escherichia coli*（大肠杆菌）这样的细菌按质量约 70% 是水，人体约 60%，水母超过 95%，甚至干燥种子也保留几个百分点的水结合在蛋白质与糖上。水不是被动填充物。它是几乎所有生化反应发生的溶剂，是水解与光合作用中的反应物、呼吸的产物，并通过它形成和拒绝形成的氢键，成为折叠蛋白质、组装膜、把酶与底物结合在一起的力。它的酸碱化学用一个数字 pH 概括，决定细胞中每个可电离基团的电荷。

本章从生物学家的角度看待水与弱相互作用：在真实隔室、真实温度、生活在沙漠、深海与冰冻池塘的生物中。物理化学——氢键几何、介电质中的库仑定律、疏水效应的热力学与 Henderson–Hasselbalch 方程的推导——在[化学图谱：水与非共价相互作用](/learn/chemistry/lesson.php?c=biochemistry&l=water-noncovalent)中详细处理。这里我们陈述所需结果，并追问它们对生物意味着什么：隔室为何保持不同 pH、如何测量，细胞如何缓冲制造的酸，生物如何平衡水与溶质对抗严酷环境，以及弱键之弱为何正是生物学所需。

## 水作为生命介质

水分子是弯曲的（H–O–H 角约 104.5°）且强极性：氧带部分负电荷，每个氢带部分正电荷。每个分子可给出两个氢键并接受两个，所以液态水是不断重排的网络，每个分子平均有略少于四个氢键邻居，单个键在皮秒尺度断裂和重组。

::: definition 氢键 {#def-hbond}
**氢键**是共价结合于电负性**供体**原子（O–H、N–H）的氢与附近电负性**受体**原子（O、N）孤对之间的吸引，供体–受体距离约 0.27–0.31 nm，三原子近乎共线。气相中强度约 10–30 kJ mol⁻¹，但在水中两个溶质间的氢键大多替换各自与水形成的键，所以对复合物稳定性的**净**贡献通常只有几 kJ mol⁻¹。
:::

对生物重要的若干水性质来自这一网络。

- **高热容**（4.18 J g⁻¹ K⁻¹）缓冲生物与湖泊对温度骤变的反应。
- **高汽化潜热**（体温下约 2.4 kJ g⁻¹）使蒸发成为散热有效方式——出汗、喘气与蒸腾的基础。
- **4 °C 时密度最大**与冰密度较低意味着湖泊从上向下冻结，下方水保持液态，水生生命可越冬。
- **高介电常数**（25 °C 约 78）把相反电荷间的吸引比真空削弱约八十倍，这就是盐能溶解、蛋白质表面带电基团彼此只弱相互作用的原因。
- **内聚力与表面张力**让水在张力下作为连续柱被拉上高树的木质部（见 [[plant-biology/water-transport]]）。

::: example 保持凉爽需要多少水？ {#ex-sweat}
快步行走的人产生约 400 W 代谢热，其中（比如）100 W 在热天必须通过汗液蒸发散失。每小时多少克水必须蒸发？取皮肤温度下水的汽化潜热 2.42 kJ g⁻¹。
::: solution
蒸发一克移除 2420 J，所以 100 W（100 J s⁻¹）需要 $100/2420 = 0.0413\ \mathrm{g\,s^{-1}}$，即 $0.0413\times3600 = 149\ \mathrm{g}$ 每小时——约一杯水。滴落而非蒸发的汗几乎不散热，这就是潮湿空气（蒸发慢）使热难以忍受的原因。骆驼等沙漠哺乳动物让白天体温升高几度并把热存到凉爽夜晚，而不是蒸发水维持固定温度，从而降低这一成本（K. Schmidt-Nielsen，*Desert Animals*，1964）。
:::
:::

## 弱相互作用与生物学为何需要它们

共价键把分子原子连在一起；弱的**非共价**相互作用把分子彼此连接。四类重要，各有范围与对水的敏感性。

| 相互作用 | 水中典型净强度 | 范围与特征 |
|---|---|---|
| 氢键 | 2–6 kJ mol⁻¹ | 短、有方向 |
| 离子相互作用（盐桥） | 表面 1–6 kJ mol⁻¹，埋藏时更高 | 长程，被水与盐屏蔽 |
| 范德华接触 | 每原子对 0.4–4 kJ mol⁻¹ | 很短、无方向、沿表面可加和 |
| 疏水效应 | 每 Å² 埋藏非极性表面约 0.1 kJ mol⁻¹ | 熵驱动，由水推动 |

（数量级数值；如何估计见化学课。）37 °C 的热能 $RT = 2.58\ \mathrm{kJ\,mol^{-1}}$，与单个弱相互作用相当。这就是要点。单个弱键不断被热运动形成和破坏，所以分子能在生物学时间尺度相遇、结合、反应并分开。强而特异的结合通过在一个互补表面上叠加许多弱相互作用实现——酶活性部位的形状、抗体表面、DNA 双链的碱基对——使特异性和可逆性同时存在。

::: definition 疏水效应 {#def-hydrophobic}
**疏水效应**是水中非极性分子与表面聚集的倾向。它主要不是来自非极性基团间的吸引，而是来自水：非极性表面旁的水分子不能在所有方向形成完整氢键并变得更有序，埋藏表面释放它们，增加溶剂熵。室温下它主要是熵的；强度随埋藏非极性面积增长。
:::

疏水效应驱动蛋白质折叠（非极性侧链在核心，[[biochemistry/amino-acids-proteins]]）、磷脂自组装成双层（[[cell-biology/membranes]]）、核酸碱基堆积，以及许多蛋白质–蛋白质结合。

### 结合强度与特异性

两个分子黏得多强由解离常数衡量，它与自由能的联系是弱相互作用与生物特异性之间的汇率。

::: proposition 结合自由能与解离常数 {#prop-kd}
对平衡 $\mathrm{PL} \rightleftharpoons \mathrm{P} + \mathrm{L}$，解离常数 $K_\mathrm{d} = [\mathrm{P}][\mathrm{L}]/[\mathrm{PL}]$，结合标准自由能（相对 1 mol L⁻¹ 标准态）为

$$
\Delta G^\circ_\mathrm{bind} = RT\ln K_\mathrm{d}.
$$ {#eq-kd}

37 °C 时 $RT\ln 10 = 5.94\ \mathrm{kJ\,mol^{-1}}$，所以每增加 5.9 kJ mol⁻¹ 结合自由能就使 $K_\mathrm{d}$ 降低十倍。结合能相差 $\Delta\Delta G$ 的两个配体在等浓度下被区分 $e^{\Delta\Delta G/RT}$ 倍，若两者都与结合位点达到平衡。
:::

::: example 从结合能到特异性 {#ex-specificity}
(a) 一个转录因子以 $K_\mathrm{d} = 1\ \mathrm{\mu mol\,L^{-1}}$ 结合其 DNA 位点；链霉亲和素以 $K_\mathrm{d} \approx 10^{-14}\ \mathrm{mol\,L^{-1}}$ 结合生物素。计算 37 °C 下 $\Delta G^\circ_\mathrm{bind}$。(b) 异亮氨酰-tRNA 合成酶必须区分异亮氨酸与缬氨酸，后者少一个亚甲基。若额外 CH₂ 贡献约 5 kJ mol⁻¹ 疏水结合能，单靠结合能区分得多好？
::: solution
(a) 转录因子 $\Delta G^\circ = 2.579\ln(10^{-6}) = -35.6\ \mathrm{kJ\,mol^{-1}}$，生物素 $2.579\ln(10^{-14}) = -83\ \mathrm{kJ\,mol^{-1}}$——大致是十几个或更多弱相互作用之和，仍小于单个 C–C 共价键（约 350 kJ mol⁻¹）。

(b) $e^{5/2.579} = 6.95$：等浓度下缬氨酸约每七个异亮氨酸被选中一次。鲍林（Linus Pauling）在 1957 年提出这一论证并结论蛋白质合成不可能如此准确。Alan Fersht 等人在 1970 年代弄清的答案是**校正（editing）**：酶有第二个水解位点，移除错误活化的缬氨酸，把错误降到约几千分之一。单靠弱相互作用给特异性设限；生物学通过花费能量校对超越它，这一主题在 [[molecular-biology/translation]] 中展开。
:::
:::

## 生命体内的 pH

水轻微电离，$\mathrm{H_2O} \rightleftharpoons \mathrm{H^+} + \mathrm{OH^-}$，离子积 $K_\mathrm{w} = [\mathrm{H^+}][\mathrm{OH^-}] = 1.0\times10^{-14}$（25 °C）。**pH** 是氢离子活度的 $-\log_{10}$（实践中为 mol L⁻¹ 浓度）。由于蛋白质侧链、核苷酸磷酸与代谢物羧基在 pH 4–10 范围得失质子，pH 控制其电荷，并通过电荷控制其形状、结合与催化。

::: proposition Henderson–Hasselbalch 方程 {#prop-hh}
对酸解离常数 $K_\mathrm{a}$、$\mathrm{p}K_\mathrm{a} = -\log_{10}K_\mathrm{a}$ 的弱酸 HA，

$$
\mathrm{pH} = \mathrm{p}K_\mathrm{a} + \log_{10}\frac{[\mathrm{A^-}]}{[\mathrm{HA}]},
\qquad
f_\mathrm{HA} = \frac{[\mathrm{HA}]}{[\mathrm{HA}]+[\mathrm{A^-}]} = \frac{1}{1 + 10^{\,\mathrm{pH}-\mathrm{p}K_\mathrm{a}}}.
$$ {#eq-hh}

它来自对 $K_\mathrm{a} = [\mathrm{H^+}][\mathrm{A^-}]/[\mathrm{HA}]$ 取对数；推导与假设（稀溶液、活度用浓度替代）在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=water-noncovalent)。基团在 $\mathrm{pH} = \mathrm{p}K_\mathrm{a}$ 时半质子化，低一个单位时约 91% 质子化，高一个单位时约 9%。
:::

### 隔室保持不同 pH

真核细胞不是一种溶液而是许多种。每个隔室有特征 pH，由膜中的泵与泄漏维持，差异被利用。

| 隔室 | 典型 pH |
|---|---|
| 细胞质基质、细胞核、ER | 7.2 |
| 线粒体基质 | 约 8.0 |
| 高尔基体（顺面到反面） | 6.7 → 6.0 |
| 早期内体 | 6.3 |
| 晚期内体 | 5.5 |
| 溶酶体 | 4.7 |
| 植物液泡 | 约 5.5（某些果实中低得多） |
| 叶绿体基质（光照下） | 约 8 |

（动物数值来自 J. R. Casey、S. Grinstein 与 J. Orlowski，*Nature Reviews Molecular Cell Biology* 11, 50, 2010；植物数值近似。）V 型质子 ATP 酶酸化内膜系统（[[cell-biology/organelles]]）；呼吸链把质子泵出基质，使其碱性（[[biochemistry/oxidative-phosphorylation]]）；光照下光合电子运输把质子从叶绿体基质泵入类囊体腔。溶酶体低 pH 激活其酸性水解酶，并使它们泄漏到细胞质基质时安全失活；内吞途径沿途 pH 下降使受体释放货物；线粒体内膜与类囊体膜两侧的 pH 差是制造 ATP 的能量储备的一部分。

::: example 隔室中有多少游离质子？ {#ex-protons}
(a) 体积 1 fL（$10^{-15}$ L）、pH 7.5 的 *E. coli* 细胞中有多少游离氢离子？(b) 比较体积 2 pL、pH 7.2 的哺乳动物细胞。
::: solution
数目 $= 10^{-\mathrm{pH}}\times V \times N_\mathrm{A}$。

(a) $10^{-7.5}\times10^{-15}\times6.022\times10^{23} = 19$ 个游离质子。

(b) $10^{-7.2}\times2\times10^{-12}\times6.022\times10^{23} = 7.6\times10^4$。

细菌任一时刻只有几十个游离 H⁺，却在代谢中每秒制造和消耗数百万个质子。浓度之所以能保持稳定，只是因为几乎所有质子都结合在缓冲物上——细胞质基质的磷酸、羧酸与组氨酸——后者在微秒尺度上交换质子。“pH”在小隔室中是对少量涨落离子的时间平均，靠缓冲才有意义。
:::
:::

::: warning “中性意味着 pH 7”
中性意味着 $[\mathrm{H^+}] = [\mathrm{OH^-}]$，即 $\mathrm{pH} = \tfrac12\mathrm{p}K_\mathrm{w}$，而 $K_\mathrm{w}$ 强烈依赖温度：$\mathrm{p}K_\mathrm{w}$ 在 0 °C 为 14.94，25 °C 为 14.00，37 °C 为 13.6。因此中性水在 0 °C 为 pH 7.47，在体温下为 pH 6.8。哺乳动物细胞质基质 pH 7.2 比中性约碱 0.4 单位，并非“几乎中性”。温度依赖对体温变化的动物很重要（[[#ex-alphastat]]）。
:::

### 测量细胞内的 pH

我们如何知道表中数值？若干方法各有假设，彼此在约 0.1–0.2 单位内一致。

- **弱酸或弱碱的分布。** 若只有弱酸或弱碱的不带电形式穿膜，它在一侧积累到由 pH 差设定的程度（[[#prop-trapping]]）。1959 年 W. J. Waddell 与 T. C. Butler 测量弱酸 DMO（5,5-二甲基噁唑烷-2,4-二酮）在狗肌肉与血浆间的分布，并由此计算胞内 pH。
- **微电极。** 插入大细胞（蜗牛神经元、蛙肌肉、乌贼轴突）的 pH 敏感玻璃或液膜微电极在 1950–70 年代给出第一批直接读数。
- **³¹P 核磁共振。** 无机磷酸的共振频率（化学位移）依赖其质子化状态，反映 pH。因为 NMR 非侵入，它测量活肌肉或整个生物内的 pH——例如运动时显示乳酸与质子积累造成的酸化。
- **荧光指示剂。** BCECF 等染料荧光随质子化变化（p$K_\mathrm{a}$ 约 7），基因编码传感器如 pHluorin（绿色荧光蛋白的 pH 敏感变体，G. Miesenböck 及同事，1998）报告单细胞与各隔室的 pH。比率测量比较两个波长的荧光，消除染料量的影响。

::: proposition 弱碱被 pH 差截留 {#prop-trapping}
假设弱碱 B（共轭酸 BH⁺，$\mathrm{p}K_\mathrm{a}$）分布在 pH $\mathrm{pH}_1$ 与 $\mathrm{pH}_2$ 的两隔室，且只有中性形式 B 穿膜。平衡时两侧 [B] 相等，总浓度比为

$$
\frac{[\mathrm{B}]_{\mathrm{tot},1}}{[\mathrm{B}]_{\mathrm{tot},2}} = \frac{1 + 10^{\,\mathrm{p}K_\mathrm{a}-\mathrm{pH}_1}}{1 + 10^{\,\mathrm{p}K_\mathrm{a}-\mathrm{pH}_2}}.
$$ {#eq-trapping}

对弱酸指数改为 $\mathrm{pH}-\mathrm{p}K_\mathrm{a}$。假设：带电形式不可透，化合物无结合或代谢，膜电位（会作用于带电形式）可忽略。
:::

::: proof
每个隔室中，由 [[#eq-hh]]，$[\mathrm{BH^+}] = [\mathrm{B}]\,10^{\,\mathrm{p}K_\mathrm{a}-\mathrm{pH}}$，所以 $[\mathrm{B}]_\mathrm{tot} = [\mathrm{B}](1 + 10^{\,\mathrm{p}K_\mathrm{a}-\mathrm{pH}})$。两侧 [B] 相等时，总浓度比等于括号因子之比。
:::

::: example 弱碱在溶酶体中积累 {#ex-trapping}
一个可穿膜的胺 $\mathrm{p}K_\mathrm{a} = 9.0$ 被加到细胞中。估计其在溶酶体（pH 4.7）相对于细胞质基质（pH 7.2）的积累。
::: solution
由 [[#eq-trapping]]，比值为 $(1 + 10^{4.3})/(1 + 10^{1.8}) = 19\,954/64.1 = 311$。胺在溶酶体中浓缩约 300 倍。这种**离子截留**就是氯化铵与氯喹等弱碱在高浓度加入时升高溶酶体 pH 的原因（它们吸收 V-ATP 酶泵入的质子），也是酸性荧光染料标记酸性隔室、某些弱碱性药物在富含溶酶体的组织中积累的原因。同一原理反向运行，让 Waddell 与 Butler 从弱酸分布推断 pH。
:::
:::

::: quiz
一个 $\mathrm{p}K_\mathrm{a} = 4.5$、只有中性形式可透的弱酸加到分离线粒体周围介质中（基质 pH 8.0，介质 pH 7.2）。它在哪里积累？
- [x] 在基质，较碱的隔室。
- [ ] 在外面，较酸的介质。
- [ ] 两侧相等，因为中性形式平衡。
- [ ] 哪里都不积累，因为只有中性形式可透。
::: solution
对弱酸，带电形式是 A⁻，高 pH 时有利。中性 HA 平衡，每个隔室含 $[\mathrm{HA}](1 + 10^{\,\mathrm{pH}-\mathrm{p}K_\mathrm{a}})$；比值 $(1+10^{3.5})/(1+10^{2.7}) \approx 6.3$ 偏向基质。弱酸在碱性隔室积累，弱碱在酸性隔室——这就是基质 pH 与质子动力势的 pH 梯度部分的测量方式。
:::
:::

## 缓冲代谢产生的酸

代谢制造酸。每个葡萄糖转为两个乳酸释放两个质子；呼吸制造 CO₂，水合成碳酸；细胞 pH 下 ATP 水解每个 ATP 释放一小部分质子。工作的肌肉一分钟内可在一升细胞水中产生数十毫摩尔质子。没有缓冲，其 pH 会骤降数单位；实际上只降零点几个单位。

::: definition 缓冲容量 {#def-buffer}
溶液的**缓冲容量**为 $\beta = dB/d\,\mathrm{pH}$，即提高一个 pH 单位所需强碱量（mol L⁻¹），等价于降低一个单位所需强酸。对总浓度 $C$ 的弱酸–碱对，

$$
\beta = 2.303\,C\,\frac{K_\mathrm{a}[\mathrm{H^+}]}{(K_\mathrm{a} + [\mathrm{H^+}])^2},
$$ {#eq-beta}

在 $\mathrm{pH} = \mathrm{p}K_\mathrm{a}$ 时最大，$\beta_{\max} = 2.303\,C/4 = 0.576\,C$。生理学家以 mmol L⁻¹ 每 pH 单位测量组织缓冲容量，该单位有时以范斯莱克（Donald Van Slyke）之名称为 slyke。
:::

[[#eq-beta]] 有两个寓意。缓冲只在 $\mathrm{p}K_\mathrm{a}$ 约一个单位内有用，容量正比于浓度。细胞中哪些基团 $\mathrm{p}K_\mathrm{a}$ 接近 7？

- **无机磷酸**（$\mathrm{H_2PO_4^-}/\mathrm{HPO_4^{2-}}$，生理离子强度下 $\mathrm{p}K_\mathrm{a} \approx 6.9$）与有机代谢物的磷酸基。
- 蛋白质的**组氨酸侧链**（$\mathrm{p}K_\mathrm{a}$ 约 6–7，取决于环境）。血红蛋白每个四聚体有数十个组氨酸，红细胞中四聚体浓度约 5 mmol L⁻¹，是血液主要的非碳酸氢盐缓冲物。
- **咪唑二肽**如肌肽（β-丙氨酰组氨酸，$\mathrm{p}K_\mathrm{a}$ 近 6.8）及甲基化类似物鹅肌肽与鲸肌肽，在脊椎动物骨骼肌中达数十毫摩尔每千克，尤其在爆发无氧用力或长时间潜水的动物中丰富——金枪鱼等冲刺鱼与潜水鲸（H. Abe，*Biochemistry (Moscow)* 65, 757, 2000）。
- **碳酸氢盐**表观 $\mathrm{p}K$ 为 6.1，远离 7.4，却是最重要的细胞外缓冲物，因为它是**开放**系统：CO₂ 被肺（或鳃）移除，酸形式保持恒定。其详细处理与动脉血 pH 计算在[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=water-noncovalent)，临床解释在[医学图谱：肾](/learn/medicine/course.php?c=renal)。

::: example 磷酸缓冲隔室吸收酸 {#ex-buffer}
一个隔室含 20 mmol L⁻¹ 总无机磷酸（$\mathrm{p}K_\mathrm{a} = 6.86$），pH 7.20，无其他缓冲物。(a) $\mathrm{HPO_4^{2-}}$ 与 $\mathrm{H_2PO_4^-}$ 浓度是多少？(b) 加入 5 mmol L⁻¹ 强酸后 pH 是多少？(c) 完全没有缓冲时 pH 是多少？
::: solution
(a) $[\mathrm{HPO_4^{2-}}]/[\mathrm{H_2PO_4^-}] = 10^{7.20-6.86} = 2.19$，所以 $[\mathrm{HPO_4^{2-}}] = 20\times2.19/3.19 = 13.7$，$[\mathrm{H_2PO_4^-}] = 6.3$ mmol L⁻¹。

(b) 酸把 5 mmol L⁻¹ $\mathrm{HPO_4^{2-}}$ 转为 $\mathrm{H_2PO_4^-}$：比值变为 $8.7/11.3$，$\mathrm{pH} = 6.86 + \log_{10}(8.73/11.27) = 6.86 - 0.11 = 6.75$。

(c) 无缓冲时 5 mmol L⁻¹ H⁺ 给出 $\mathrm{pH} = -\log_{10}(0.005) = 2.3$。

缓冲把近五单位的灾难性下降变成不到半单位。真实细胞质基质由所有基团合计有数十 mmol L⁻¹ 每 pH 单位的缓冲容量，并较长期通过 Na⁺/H⁺ 交换器与碳酸氢盐运输蛋白把酸输出质膜（[[cell-biology/membrane-transport]]）。
:::
:::

::: application 胞内 pH 作为信号
细胞不仅防御 pH 还利用它。海胆卵受精后几分钟内通过 Na⁺/H⁺ 交换使细胞质基质碱化零点几个单位，这一上升帮助开启蛋白质合成与 DNA 复制（D. Epel 及同事，1970 年代）。酵母中葡萄糖耗尽时细胞质 pH 下降、加入时上升，变化通过 pH 敏感蛋白调节生长。植物保卫细胞、根毛与花粉管都显示与生长和信号相关的 pH 变化。pH 敏感蛋白通常把敏感性归于组氨酸或酸性残基簇，其 $\mathrm{p}K_\mathrm{a}$ 被调到生理范围附近。
:::

### 温度、pH 与变温动物的方案

对体温变化的动物，固定 pH 意味着其蛋白质电离状态变化，因为 $\mathrm{p}K_\mathrm{w}$ 与组氨酸 $\mathrm{p}K_\mathrm{a}$ 都随温度上升下降（约每 °C 0.02 单位）。1960–70 年代 Hermann Rahn 与 Robert Reeves 发现龟、蛙与鱼的血液和细胞 pH 随温度上升下降约每 °C 0.015–0.02 单位，使 pH 与中性保持恒定距离。Reeves 的 **alpha-stat（α 稳态）** 假说（1972）提出被调节的不是 pH 本身，而是蛋白质组氨酸咪唑基团的分数解离（α），使蛋白质净电荷——因而结构与功能——随温度变化保持恒定。冬眠哺乳动物与手术降温患者也有同样问题，临床策略长期争论（见[医学图谱](/learn/medicine/)）。

::: example 龟中的 alpha-stat 模式 {#ex-alphastat}
适应不同温度淡水龟的代表性动脉血 pH 为 10 °C 时 7.80、20 °C 时 7.63、30 °C 时 7.46（与 Howell、Rahn 及同事 1970 年报告的数据同类的示例值）。用这些温度下 $\mathrm{p}K_\mathrm{w} = 14.535$、14.167 与 13.833，比较 pH 与中性。
::: solution
中性 pH 为 $\tfrac12\mathrm{p}K_\mathrm{w}$：7.27、7.08 与 6.92。差值 $\mathrm{pH} - \mathrm{pN}$ 为 0.53、0.55 与 0.54——基本恒定。血 pH 斜率 $(7.46 - 7.80)/20 = -0.017$ 每 °C，几乎正是中性斜率 $-0.0176$ 每 °C。龟使血液保持比中性碱 0.54 单位；所有温度固定 pH 7.4 相对其蛋白质会意味着热时碱中毒、冷时酸中毒。
:::
:::

## 水平衡：渗透与相容溶质

水被动跨膜，朝溶解颗粒更多的一侧移动。因此生物必须控制其细胞中溶质总浓度——**渗透浓度（osmolarity）**——相对于周围，否则会膨胀或收缩。

::: proposition 渗透压的 van 't Hoff 关系 {#prop-vanthoff}
对含渗透活性颗粒总浓度 $c$（osmol L⁻¹）、由只透水的膜与纯水分隔的稀溶液，阻止水流入所需压力为

$$
\Pi = cRT,
$$ {#eq-vanthoff}

$R = 0.08314\ \mathrm{L\,bar\,mol^{-1}\,K^{-1}}$。对盐每个解离离子计数，所以 0.15 mol L⁻¹ NaCl 理想时给 $c \approx 0.30$ osmol L⁻¹。假设：理想稀溶液（真实溶液偏离，所以生物学家直接用冰点下降测渗透浓度）与完美半透膜。真实膜上，对也能穿膜的溶质，有效压力被 0 到 1 的反射系数降低。
:::

37 °C 时 1 osmol L⁻¹ 对应 $0.08314\times310.15 = 25.8$ bar。哺乳动物体液约 0.29–0.30 osmol L⁻¹，所以相对纯水渗透压约 7.7 bar——数倍大气压。动物细胞无壁，必须与周围等渗；植物、真菌与细菌细胞让水进入直到壁推回，产生**膨压**。

::: example 植物细胞中的膨压 {#ex-turgor}
内部渗透浓度 0.50 osmol L⁻¹ 的植物细胞处于 20 °C、0.05 osmol L⁻¹ 的土壤水中。若壁刚性且溶质不穿膜，平衡时产生多少膨压？
::: solution
平衡时壁压平衡渗透差：$\Delta\Pi = (0.50 - 0.05)\times0.08314\times293.15 = 11.0$ bar，即 1.1 MPa——约十一大气压，高于汽车轮胎。这种膨压支撑草本植物直立并驱动生长中的细胞扩张；水势结合渗透与压力项，在 [[plant-biology/water-transport]] 中展开。
:::
:::

### 相容与拮抗溶质

生活在咸、干或冷环境的生物提高内部渗透浓度——但不用盐，因为高浓度盐破坏蛋白质结构与功能。它们积累**相容溶质（osmolytes）**：能达高浓度而不扰动蛋白质的小有机分子。同样的少数化学类别在细菌、古菌、植物与动物中反复被采用（P. H. Yancey 及同事，*Science* 217, 1214, 1982）。

::: definition 相容与拮抗渗透调节物质 {#def-osmolyte}
**相容渗透调节物质**是细胞为平衡外部渗透浓度而积累、即使达数百毫摩尔每升也对大分子功能影响很小的溶质：多元醇（甘油、山梨醇、甘露醇）、糖（蔗糖、海藻糖）、游离氨基酸及衍生物（脯氨酸、牛磺酸、甘氨酸甜菜碱、ectoine）与甲胺类（氧化三甲胺，TMAO）。**拮抗**对由一个破坏蛋白质的溶质（尿素）与一个稳定它们的溶质（TMAO）组成，一起积累使其对蛋白质稳定性的效应相消。
:::

显著例子：

- **鲨、鳐与腔棘鱼**把体液略高于海水渗透浓度（约 1000 mOsm L⁻¹），主要靠尿素（数百毫摩尔每升）与甲胺类（主要是 TMAO，组织中约为尿素浓度一半）。单尿素会破坏其蛋白质；TMAO 拮抗它（Yancey 与 G. N. Somero，*Biochemical Journal* 183, 317, 1979）。
- **深海鱼类**按生活深度积累 TMAO，似乎是为了拮抗静水压对蛋白质折叠与结合的影响。因为 TMAO 也提高渗透浓度，趋势预测硬骨鱼在约 8000–8500 m 与海水等渗，这与鱼类观察到的最深深度相符（Yancey 及同事，*PNAS* 111, 4461, 2014）——一个生物地理限制的生化假说。
- **嗜盐古菌**如 *Halobacterium salinarum*（盐沼盐杆菌）走相反路线（“盐入”）：细胞质中积累数 mol L⁻¹ KCl，并进化出富含酸性残基、需要高盐才能折叠的蛋白质。
- **植物**在干旱或盐胁迫下积累脯氨酸与甘氨酸甜菜碱；**耐干燥**生物——许多种子、复活植物、卤虫囊——用蔗糖与海藻糖替代水，形成玻璃态保存膜与蛋白质。缓步动物则主要依赖内在无序蛋白而非海藻糖。
- **耐冻**木蛙（*Rana sylvatica*，现 *Lithobates sylvaticus*）在细胞外结冰时用肝糖原的葡萄糖灌满组织，限制细胞收缩；极地鱼类制造结合冰晶并阻止其生长的**抗冻蛋白**。

::: intuition 相容溶质为何相容
蛋白质被从其表面**排斥**的溶质稳定：这种溶质偏好水而非蛋白质，所以它偏爱最紧凑、暴露表面最少的折叠状态。结合肽骨架的尿素偏好相反，偏爱未折叠状态。TMAO、甘氨酸甜菜碱与海藻糖被强烈排斥。所以渗透调节物质的相容性不是惰性，而是与水及蛋白质表面弱相互作用的平衡，正是本章开头的那些相互作用。
:::

::: history
水的离子积由科尔劳施（Friedrich Kohlrausch）与 Adolf Heydweiller 在 1894 年从超纯水导电性测得。索伦森（Søren Sørensen）在哥本哈根 Carlsberg 实验室研究酶时于 1909 年引入 pH 标度，因为酶活性强烈依赖氢离子浓度；亨德森（Lawrence Henderson，1908）与哈塞尔巴尔赫（Karl Hasselbalch，1916）给出缓冲方程的现代形式，亨德森在血液酸碱平衡工作中。范托夫（Jacobus van 't Hoff）在 1887 年从普费弗（Wilhelm Pfeffer）人工膜测量推导渗透压定律。考兹曼（Walter Kauzmann） 1959 年综述认定疏水效应为蛋白质折叠主要力。Waddell 与 Butler 在 1959 年用弱酸分布测胞内 pH，Rahn 与 Reeves 在 1960–70 年代发展温度与 pH 的比较生理学。相容与拮抗溶质理论由 Yancey、Somero 及同事在 1979–82 年提出。
:::

## 由此走向何处

本章的弱相互作用折叠 [[biochemistry/amino-acids-proteins]] 的链、组装 [[biochemistry/carbohydrates-lipids]] 的脂质，并把底物固定到 [[biochemistry/enzymes]] 的酶上。隔室间的质子梯度在 [[biochemistry/oxidative-phosphorylation]] 中作为能量储备回归，工作肌肉产生的酸在 [[biochemistry/glycolysis-tca]] 中回归。

::: summary
- 水的氢键网络给它高热容、潜热与介电常数；生物用蒸发散热（100 W 约每小时 150 g 汗）。
- 弱相互作用（氢键、离子相互作用、范德华接触、疏水效应）各自与 $RT$ 相当；特异性来自许多共同作用，$\Delta G^\circ_\mathrm{bind} = RT\ln K_\mathrm{d}$，37 °C 下每十倍 5.9 kJ mol⁻¹，超出部分来自耗能校对。
- 隔室保持不同 pH（溶酶体 4.7、细胞质基质 7.2、基质 8.0），由弱酸分布、³¹P NMR 与荧光传感器测量；弱碱在酸性隔室被截留，因子 $(1+10^{\mathrm{p}K_\mathrm{a}-\mathrm{pH}_1})/(1+10^{\mathrm{p}K_\mathrm{a}-\mathrm{pH}_2})$。
- 缓冲在 $\mathrm{p}K_\mathrm{a}$ 约一个单位内有效，容量 $\beta_{\max} = 0.576\,C$；细胞中主要缓冲物是磷酸、蛋白质组氨酸与咪唑二肽，细胞外是开放碳酸氢盐系统。
- 中性 pH 依赖温度（37 °C 为 6.8）；变温动物让血 pH 跟随中性（alpha-stat）。
- 渗透压 $\Pi = cRT$（37 °C 每 osmol L⁻¹ 25.8 bar）；生物用相容渗透调节物质平衡它，用 TMAO 拮抗尿素，或（嗜盐菌）用适应盐的蛋白质。
:::

## 练习

::: exercise 溶酶体中的质子 {level=1 check="786"}
直径 0.50 µm 的球形溶酶体在 pH 4.7 时平均有多少游离氢离子？给最接近的整数。
::: solution
半径 $0.25\ \mathrm{\mu m} = 2.5\times10^{-7}\ \mathrm{m}$，所以 $V = \tfrac43\pi r^3 = 6.54\times10^{-20}\ \mathrm{m^3} = 6.54\times10^{-17}\ \mathrm{L}$。数目 $= 10^{-4.7}\times6.54\times10^{-17}\times6.022\times10^{23} = 786$。
:::
:::

::: exercise 接近中性的组氨酸 {level=1 check="0.240"}
组氨酸侧链 $\mathrm{p}K_\mathrm{a} = 6.0$。pH 6.5 时质子化比例是多少？三位有效数字。
::: solution
由 [[#eq-hh]]，$f = 1/(1+10^{6.5-6.0}) = 1/(1+3.162) = 0.240$。
:::
:::

::: exercise 盐水的渗透压 {level=1 check="7.74"}
把 0.15 mol L⁻¹ NaCl 视为完全解离且理想，计算 37 °C 下渗透压（bar，三位有效数字）。
::: solution
$c = 0.30$ osmol L⁻¹，所以 $\Pi = 0.30\times0.08314\times310.15 = 7.74$ bar。
:::

::: exercise 剧烈运动时出汗 {level=2 check="446"}
剧烈运动时自行车手必须通过蒸发散失 300 W。用 2.42 kJ g⁻¹ 潜热，每小时多少克汗必须蒸发（三位有效数字）？
::: solution
$300/2420 = 0.124\ \mathrm{g\,s^{-1}}$，乘 3600 s 得 446 g 每小时。由于许多汗滴落而非蒸发，实际出汗率更高，常超过每小时一升。
:::

::: exercise 植物液泡中的弱碱 {level=2 check="76.2"}
一个 $\mathrm{p}K_\mathrm{a} = 8.0$、只有中性形式可透的弱碱。在 pH 5.5 液泡中相对于 pH 7.5 细胞质基质浓缩多少倍（三位有效数字）？
::: solution
由 [[#eq-trapping]]，$(1 + 10^{2.5})/(1 + 10^{0.5}) = 317.2/4.162 = 76.2$。
:::

::: exercise 加酸后的缓冲 {level=2 check="6.75"}
重做 [[#ex-buffer]] 的 (b)，给出最终 pH 到两位小数。然后计算把同一缓冲 pH 降到 6.86 需要多少酸（mmol L⁻¹）。
::: solution
最终 pH 为 6.75，如例中。pH 6.86 时两形式相等，各 10 mmol L⁻¹；从 13.73 mmol L⁻¹ $\mathrm{HPO_4^{2-}}$ 起，需要 $13.73 - 10 = 3.7$ mmol L⁻¹ 酸。
:::
:::

::: exercise 多一个氢键 {level=2 check="6.95"}
药物设计者加入一个与靶标多形成氢键的基团，净贡献 5.0 kJ mol⁻¹。37 °C 下解离常数降低多少倍（三位有效数字）？为何实测改善可能更小？
::: solution
$K_\mathrm{d}$ 降低 $e^{5.0/2.579} = 6.95$ 倍。改善常更小，因为新基团必须先剥离它与水形成的氢键，可能限制分子柔性（熵成本），且轻微错位削弱键——水中氢键的净价值是所有交换后剩下的。
:::
:::

::: exercise 深海渗透浓度极限 {level=3 check="8.13"}
假设（示例性地）硬骨鱼组织渗透浓度随生活深度 $z$（km）按 $350 + 80z$ mOsm kg⁻¹ 上升，主要经 TMAO，海水为 1000 mOsm kg⁻¹。(a) 鱼在什么深度与海水等渗（三位有效数字）？(b) 解释这为何可能给硬骨鱼设深度限制，而鲨鱼在表面已等渗、在约 3000 m 以下几乎缺席。
::: solution
(a) $350 + 80z = 1000$ 给 $z = 650/80 = 8.13$ km。
(b) 硬骨鱼把体液保持在海水渗透浓度的三分之一并喝海水、在鳃排盐。若需要越来越多 TMAO 抗压稳定蛋白质，渗透浓度上升；超过等渗深度它们会渗透吸水并需新方式处理，或接受未稳定蛋白质。约 8.1–8.4 km 极限的预测与鱼类最深观察相符。鲨鱼用尿素与 TMAO 在表面附近已等渗，所以几乎没有空间再加 TMAO 而不变高渗；其深海稀少部分由此解释，但能量与其他因素（如油性、耗能高的肝）也被提出。这是有支持的假说，不是定论。
:::
:::

::: exercise 解读 ³¹P NMR 实验 {level=3}
人前臂肌肉的 ³¹P NMR 谱在静息与一分钟剧烈运动末记录。静息时无机磷酸（Pi）峰指示 pH 7.05，磷酸肌酸（PCr）峰大；运动后 Pi 峰大得多，PCr 下降约 60%，Pi 峰指示 pH 6.55。(a) 解释化学位移如何报告 pH。(b) 用 [[#eq-hh]] 取 $\mathrm{p}K_\mathrm{a} = 6.75$，计算各 pH 下 Pi 的 $\mathrm{HPO_4^{2-}}$ 形式比例。(c) 肌肉短时缓冲容量约 25 mmol L⁻¹ 每 pH 单位（示例）。净加入多少 mmol L⁻¹ 质子产生这一 pH 变化？(d) 给出两个生化质子来源及下降小于预期的一个原因。
::: solution
(a) $\mathrm{H_2PO_4^-}$ 与 $\mathrm{HPO_4^{2-}}$ 共振频率略不同，但相互转化远快于 NMR 时间尺度，所以出现一个位置为群体加权平均的峰。其位置因此跟随两形式比例，由 [[#eq-hh]] 报告 pH（在已知 pH 溶液中校准后）。
(b) $f_{\mathrm{HPO_4}} = 1/(1+10^{6.75-\mathrm{pH}})$：pH 7.05 时 $1/(1+10^{-0.30}) = 0.67$；pH 6.55 时 $1/(1+10^{0.20}) = 0.39$。
(c) $\Delta\mathrm{pH} = 0.50$，所以约 $25\times0.50 = 12.5$ mmol L⁻¹ 质子。
(d) 来源：糖酵解到乳酸（每个乳酸一个质子，[[biochemistry/glycolysis-tca]]）与净 ATP 水解。下降受限部分因为磷酸肌酸分解为肌酸**消耗**质子（肌酸激酶反应 $\mathrm{PCr} + \mathrm{ADP} + \mathrm{H^+} \to \mathrm{Cr} + \mathrm{ATP}$），部分因为乳酸与质子在运动中被输出细胞。
:::
:::
