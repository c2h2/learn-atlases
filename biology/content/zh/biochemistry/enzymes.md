如果没有催化剂，细胞中几乎每个化学反应都会慢到无法维持生命。乳清苷一磷酸的脱羧——合成嘧啶核苷酸的一步——在水中的未催化半衰期约 7800 万年；催化它的酶在毫秒内完成这项工作，速率提升约 $10^{17}$（A. Radzicka 与 R. Wolfenden，*Science* 267, 90, 1995）。酶使代谢成为可能，而因为它们各是一个基因的产物，代谢因而可控、可进化：细胞决定发生什么化学，靠的是决定制造哪些酶、让它们的活性达到多高。

本章讲生物学家如何使用和遇到酶：它们的活性如何测定、米氏参数在活细胞内意味着什么、同工酶如何让同一反应适应不同组织、酶如何进化到在宿主的温度下工作，以及抑制剂——天然毒素、除草剂、抗生素与药物——如何利用它们。催化的物理化学（过渡态结合、催化策略、丝氨酸蛋白酶的机理与 pH 效应）在[化学图谱：酶](/learn/chemistry/lesson.php?c=biochemistry&l=enzymes)中展开。

## 酶是什么

::: definition 酶、辅因子与活性位点 {#def-enzyme}
**酶**是生物催化剂，几乎总是蛋白质（有时是 RNA，即**核酶**），在不被消耗、不改变反应平衡常数的前提下提高某一专一反应的速率。底物结合在**活性位点**——一个常由序列上相距很远的残基形成的裂缝或口袋。许多酶需要非蛋白的**辅因子**：金属离子（Zn²⁺、Mg²⁺、Fe²⁺）或有机的**辅酶**（NAD⁺、FAD、辅酶 A、磷酸吡哆醛），后者可紧密结合（称为**辅基**）或像第二个底物那样结合又离去。
:::

酶同等程度地加速反应的两个方向，所以它不能使不利反应发生；它只让有利反应更快到达平衡。代谢反应的方向由热力学与浓度决定（[[biochemistry/bioenergetics]]），酶只决定反应是否发生、发生多快。

两个特征使酶区别于多数实验室催化剂。它们**专一**，常常对众多相似分子中的一种底物专一、对某一种立体异构体专一；费歇尔（Emil Fischer）1894 年锁钥的比喻抓住了这一点，Koshland 的诱导契合模型（1958）则承认底物结合会改变酶的形状而使之精细化。而且它们是**受调控的**（[[biochemistry/enzyme-regulation]]）。

国际生物化学与分子生物学联合会把酶分为七个大类，由 EC 编号的首位数字识别：氧化还原酶、转移酶、水解酶、裂合酶、异构酶、连接酶，以及（自 2018 年起）转位酶。

### 维生素多半是辅酶的组成部分

动物丧失了许多辅酶的合成能力，必须吃下它们的前体，即水溶性维生素。这就是“维生素”一词的生化含义。

| 维生素 | 辅酶 | 典型反应 |
|---|---|---|
| 硫胺素（B₁） | 焦磷酸硫胺素 | α-酮酸脱羧（丙酮酸脱氢酶） |
| 核黄素（B₂） | FAD、FMN | 氧化还原（琥珀酸脱氢酶） |
| 烟酸（B₃） | NAD⁺、NADP⁺ | 氧化还原（脱氢酶） |
| 泛酸（B₅） | 辅酶 A | 酰基转移 |
| 吡哆醇（B₆） | 磷酸吡哆醛 | 氨基酸转化（转氨酶） |
| 生物素（B₇） | 生物素，与酶结合 | 羧化 |
| 叶酸（B₉） | 四氢叶酸 | 一碳单位转移 |
| 钴胺素（B₁₂） | 腺苷钴胺素与甲基钴胺素 | 重排、甲基转移 |

钴胺素只由某些细菌与古菌制造；动物通过食物链或肠道微生物获取，植物既不制造也不需要它。这类依赖关系记录了代谢能力如何在生命树上分布。维生素缺乏的临床方面见[医学图谱：细胞生物学与生物化学](/learn/medicine/course.php?c=cell-biochemistry)。

## 测定酶活性

我们对酶动力学的全部了解来自**测定**：在受控条件下测量产物出现的速率或底物消失的速率。主力方法是**偶联分光光度测定**。NADH 在 340 nm 吸收而 NAD⁺ 不吸收，所以任何生成或消耗 NADH 的反应——或加入过量第二种酶与之偶联后变成这样的反应——都能在分光光度计中连续跟踪。

::: definition 酶活力与比活性 {#def-activity}
酶制剂的**活力**是在规定条件（温度、pH、饱和底物）下转化底物的速率。以**单位**报告：一个单位（U）在一分钟内转化 1 µmol 底物（SI 单位 katal 为 1 mol s⁻¹）。**比活性**是每毫克蛋白的活力（U mg⁻¹）；随着酶从其他蛋白质中纯化出来，比活性上升，纯化完成后保持恒定。
:::

::: example 偶联 NADH 测定 {#ex-assay}
乳酸脱氢酶（LDH）的活性通过它用 NADH 还原丙酮酸来测定：$\text{丙酮酸} + \text{NADH} + \text{H}^+ \to \text{乳酸} + \text{NAD}^+$。向含饱和丙酮酸与 NADH 的 1.00 mL 比色杯（光程 1.00 cm）中加入 10 µL 肌肉提取液，340 nm 吸光度每分钟下降 0.124。NADH 在 340 nm 的摩尔吸收系数为 $6220\ \mathrm{L\,mol^{-1}\,cm^{-1}}$。提取液的 LDH 活力是多少 U mL⁻¹？
::: solution
由朗伯-比尔定律，$\Delta A = \varepsilon\,\ell\,\Delta c$，所以 NADH 的消耗速率为

$$
\frac{\Delta c}{\Delta t} = \frac{0.124\ \mathrm{min^{-1}}}{6220\ \mathrm{L\,mol^{-1}\,cm^{-1}}\times1.00\ \mathrm{cm}} = 1.99\times10^{-5}\ \mathrm{mol\,L^{-1}\,min^{-1}} = 19.9\ \mathrm{\mu mol\,L^{-1}\,min^{-1}}.
$$

在 1.00 mL 中即 $0.0199\ \mathrm{\mu mol\,min^{-1}}$，即 0.0199 U，由 10 µL 提取液提供。所以提取液含 $0.0199/0.010 = 1.99$ U mL⁻¹。实际操作中要检验速率与所加提取液体积成正比——这是证明限速的是酶而不是其他组分的检验。
:::
:::

测定必须测量**初速率**——在底物耗尽、产物积累（可能抑制甚至逆转反应）或酶失活之前。本章每一项动力学分析都以同样的逻辑为基础。

## 米氏动力学

1913 年，米凯利斯（Leonor Michaelis）与 Maud Menten 研究酵母转化酶对蔗糖的水解，在不同蔗糖浓度下测定初速率，发现低浓度时速率与底物成正比上升，高浓度时则趋于平缓。他们用单一假设解释了它：酶先与底物形成复合物，再将其转化。

::: proposition 米氏方程 {#prop-mm}
对机理 $\mathrm{E} + \mathrm{S} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \mathrm{ES} \xrightarrow{k_\mathrm{cat}} \mathrm{E} + \mathrm{P}$，若 ES 的浓度恒定（拟稳态）且底物远过量于酶，则初速率为

$$
v = \frac{V_{\max}[\mathrm{S}]}{K_\mathrm{m} + [\mathrm{S}]},\qquad V_{\max} = k_\mathrm{cat}[\mathrm{E}]_\mathrm{T},\qquad K_\mathrm{m} = \frac{k_{-1} + k_\mathrm{cat}}{k_1},
$$ {#eq-mm}

其中 $[\mathrm{E}]_\mathrm{T}$ 为酶总浓度。假设：初速率（无产物，故无逆反应）、$[\mathrm{S}] \gg [\mathrm{E}]_\mathrm{T}$、单一底物（或其他底物饱和）与单一类型的活性位点。
:::

::: proof Briggs–Haldane 稳态
稳态时 ES 的生成与分解速率相等：$k_1[\mathrm{E}][\mathrm{S}] = (k_{-1} + k_\mathrm{cat})[\mathrm{ES}]$。以 $[\mathrm{E}] = [\mathrm{E}]_\mathrm{T} - [\mathrm{ES}]$ 代入并求解，得 $[\mathrm{ES}] = [\mathrm{E}]_\mathrm{T}[\mathrm{S}]/(K_\mathrm{m} + [\mathrm{S}])$，$K_\mathrm{m}$ 如前所给。速率为 $v = k_\mathrm{cat}[\mathrm{ES}]$，即 [[#eq-mm]]。（G. E. Briggs 与霍尔丹（J. B. S. Haldane）在 1925 年给出了这一稳态推导；米凯利斯与 Menten 当时假设的是 E、S 与 ES 处于平衡，那给出相同的形式，只是 $K_\mathrm{m} = k_{-1}/k_1$。）
:::

::: definition 转换数与专一性常数 {#def-kcat}
$k_\mathrm{cat}$，**转换数**，是饱和时一个活性位点每秒转化的底物分子数。$K_\mathrm{m}$，**米氏常数**，是 $v = V_{\max}/2$ 时的底物浓度；它度量酶“工作于”的底物浓度，仅当 $k_\mathrm{cat} \ll k_{-1}$ 时才等于 ES 的解离常数。比值 $k_\mathrm{cat}/K_\mathrm{m}$，**专一性常数**，是低底物浓度下游离酶与底物反应的二级速率常数，$v = (k_\mathrm{cat}/K_\mathrm{m})[\mathrm{E}][\mathrm{S}]$。它不能超过酶与底物靠扩散相遇的速率，约 $10^8$–$10^9\ \mathrm{L\,mol^{-1}\,s^{-1}}$。
:::

酶之间的跨度极大：碳酸酐酶每秒转换约 $10^5$–$10^6$ 个分子，而在光合作用中固定 CO₂ 的 Rubisco 每秒只有几个。磷酸丙糖异构酶的 $k_\mathrm{cat}/K_\mathrm{m}$ 接近扩散极限，被 W. J. Albery 与 J. R. Knowles（1976）称为催化上“完美”：让它更快也不会加快途径，因为酶几乎已与每个到达它的底物分子反应。

下图供你探索 [[#eq-mm]] 以及下面即将遇到的抑制剂的作用。

### 估算 $K_\mathrm{m}$ 与 $V_{\max}$

因为 [[#eq-mm]] 是双曲线，传统上把它线性化。取倒数得 Hans Lineweaver 与 Dean Burk（1934）的 **Lineweaver–Burk**（双倒数）图：

$$
\frac{1}{v} = \frac{K_\mathrm{m}}{V_{\max}}\,\frac{1}{[\mathrm{S}]} + \frac{1}{V_{\max}},
$$ {#eq-lb}

这是一条直线，截距为 $1/V_{\max}$，斜率为 $K_\mathrm{m}/V_{\max}$。它在一眼看出抑制剂如何作用方面仍然有用，但作为估算参数的方法很差，因为取倒数放大了最慢速率（在最低底物浓度测得）的误差。现代做法是用非线性最小二乘直接拟合 [[#eq-mm]]（[[biostatistics/regression]]）。

::: example 拟合初速率数据 {#ex-mm-fit}
某酶给出的初速率如下（µmol min⁻¹ mg⁻¹）：

| [S]（mmol L⁻¹） | 0.5 | 1 | 2 | 4 | 8 |
|---|---|---|---|---|---|
| $v$ | 10.3 | 16.4 | 25.4 | 32.8 | 40.4 |

用 Lineweaver–Burk 图估算 $K_\mathrm{m}$ 与 $V_{\max}$，并与直接非线性拟合比较，后者给出 $V_{\max} = 50.2$、$K_\mathrm{m} = 2.01$ mmol L⁻¹。
::: solution
倒数 $(1/[\mathrm{S}], 1/v)$ 为 $(2, 0.0971)$、$(1, 0.0610)$、$(0.5, 0.0394)$、$(0.25, 0.0305)$、$(0.125, 0.0248)$。过它们的最小二乘直线斜率为 0.0386，截距为 0.0206（在下图中试试）。所以 $V_{\max} = 1/0.0206 = 48.5$ µmol min⁻¹ mg⁻¹，$K_\mathrm{m} = 0.0386\times48.5 = 1.87$ mmol L⁻¹。

两种方法相差约 7% 以内，但双倒数拟合被最低 [S] 的点（最右侧）支配，那里 $v$ 的小误差变成 $1/v$ 的大误差。数据噪声更大时，不符可以严重得多。直接拟合对每个测得的速率同等加权，更可靠；双倒数图最好只留作展示。
:::
:::

## 生理环境中的酶

试管中测得的米氏参数，只有与细胞中底物浓度比较后才有生物学意义。若 $[\mathrm{S}] \ll K_\mathrm{m}$，速率大致与 [S] 成正比：酶对底物供应反应灵敏，且有富余能力。若 $[\mathrm{S}] \gg K_\mathrm{m}$，酶饱和，速率由酶的多少决定。B. D. Bennett 与同事测定 *E. coli* 中 100 多种代谢物的绝对浓度时（*Nature Chemical Biology* 5, 593, 2009）发现，在他们能比较的大多数酶-底物对中，底物浓度超过 $K_\mathrm{m}$——所以许多酶近饱和运转，细胞对通量的控制主要来自控制酶的量与活性，而非底物水平。

### 同工酶：一个反应，几种酶

许多反应在不同组织、隔室或发育阶段由不同而同源的酶催化——**同工酶**（C. L. Markert 与 F. Møller，1959），通常由旁系同源基因编码。它们不同的动力学性质使反应适应各组织的生理。

::: example 己糖激酶与葡萄糖激酶 {#ex-glucokinase}
多数哺乳动物组织用己糖激酶 I 磷酸化葡萄糖，其对葡萄糖的 $K_\mathrm{m} \approx 0.05$ mmol L⁻¹（且受产物 6-磷酸葡萄糖抑制）。肝细胞与胰腺分泌胰岛素的 β 细胞使用葡萄糖激酶（己糖激酶 IV），它在约 8 mmol L⁻¹ 葡萄糖处半饱和，动力学呈 S 形，$v/V_{\max} = [\mathrm{S}]^{1.7}/(8^{1.7} + [\mathrm{S}]^{1.7})$（代表性数值；[[biochemistry/enzyme-regulation]]）。计算两种酶在 5 与 10 mmol L⁻¹ 葡萄糖——大致是餐间与餐后的血糖浓度——的分数活性，并解释这一差别的生理意义。
::: solution
己糖激酶 I：$5/(0.05 + 5) = 0.990$ 与 $10/10.05 = 0.995$——两者都基本饱和。葡萄糖激酶：$5^{1.7}/(8^{1.7} + 5^{1.7}) = 0.310$ 与 $10^{1.7}/(8^{1.7} + 10^{1.7}) = 0.594$，几乎加倍。

己糖激酶 I 保证脑等组织以稳定速率摄取葡萄糖，不管血糖水平如何，只要它远高于 0.05 mmol L⁻¹。葡萄糖激酶的活性在血糖的生理范围内跟踪血糖浓度，这正适合两个必须*响应*葡萄糖的组织：餐后把多余葡萄糖贮存为糖原的肝，以及用磷酸化葡萄糖的速率作传感器决定释放多少胰岛素的 β 细胞。人葡萄糖激酶基因改变其动力学的变异，会改变身体调节到的血糖浓度（[医学图谱：内分泌](/learn/medicine/course.php?c=endocrine)）。
:::
:::

另一个经典例子是乳酸脱氢酶。其四聚体由两种亚基组成：H（以心肌为主）与 M（骨骼肌与肝）。H₄ 同工酶受高浓度丙酮酸的抑制更强，适合氧化乳酸的需氧心肌；M₄ 同工酶适合在爆发性活动中把丙酮酸还原为乳酸的厌氧肌肉（[[biochemistry/glycolysis-tca]]），尽管这一差别的生理重要性曾有争论。

### 相互竞争的底物与专一性

细胞内，酶常同时面对若干可能的底物。它作用于哪一个？

::: proposition 底物之间的竞争 {#prop-competition}
若两种底物 A 与 B 竞争遵循米氏动力学的同一酶的同一活性位点，它们转化速率之比为

$$
\frac{v_\mathrm{A}}{v_\mathrm{B}} = \frac{(k_\mathrm{cat}/K_\mathrm{m})_\mathrm{A}\,[\mathrm{A}]}{(k_\mathrm{cat}/K_\mathrm{m})_\mathrm{B}\,[\mathrm{B}]},
$$ {#eq-competition}

在任何浓度下——饱和与否皆然。因此竞争底物之间的甄别由专一性常数决定，而不单由 $K_\mathrm{m}$ 或 $k_\mathrm{cat}$ 决定。
:::

::: proof
两种底物都在时，游离酶被分享：按与 [[#prop-mm]] 相同的稳态论证，$[\mathrm{E}] = [\mathrm{E}]_\mathrm{T}/(1 + [\mathrm{A}]/K_\mathrm{A} + [\mathrm{B}]/K_\mathrm{B})$。每个速率为 $v_\mathrm{X} = (k_\mathrm{cat}/K_\mathrm{m})_\mathrm{X}[\mathrm{E}][\mathrm{X}]$，公共因子 $[\mathrm{E}]$ 在比值中约去。
:::

::: example Rubisco 的氧难题 {#ex-rubisco}
Rubisco 是卡尔文循环中固定 CO₂ 的羧化酶，也与 O₂ 反应，启动浪费的光呼吸过程。其 CO₂/O₂ **专一性因子** $S_{c/o} = (k_\mathrm{cat}/K_\mathrm{m})_{\mathrm{CO_2}}/(k_\mathrm{cat}/K_\mathrm{m})_{\mathrm{O_2}}$ 在许多 C3 植物中约为 90。25 °C 空气中生长的 C3 叶片的叶绿体里，溶解 CO₂ 约 8 µmol L⁻¹、O₂ 约 250 µmol L⁻¹（近似值）。羧化与加氧之比是多少？
::: solution
由 [[#eq-competition]]，$v_c/v_o = 90\times8/250 = 2.9$：大约每三次羧化有一次加氧。每次加氧都浪费能量，并在光呼吸中释放先前固定的 CO₂，所以温暖环境中的 C3 植物损失了潜在光合的相当一部分。这一个比值有巨大的进化后果。Rubisco 进化于大气 O₂ 很少的年代；O₂ 上升以来，其专一性似乎受专一性与 $k_\mathrm{cat}$ 之间权衡的限制（G. Tcherkez 及同事，2006）。C4 与 CAM 植物则把 CO₂ 浓集在 Rubisco 周围，使 $v_c/v_o$ 约提高十倍（[[biochemistry/metabolic-integration]]，[[plant-biology/c4-and-cam]]）。
:::
:::

## 温度与酶的进化

多数生物是变温动物，其酶在环境温度下工作。反应速率随温度陡升，直到酶开始去折叠。

::: definition 温度系数 {#def-q10}
速率的**温度系数** $Q_{10}$ 是温度升高 10 °C 时速率增大的倍数：$Q_{10} = (k_2/k_1)^{10/(T_2 - T_1)}$。对多数酶催化反应与整个变温动物的代谢率，在正常生理范围内 $Q_{10}$ 约为 2–3。它是经验总结，不是常数：它源于 Arrhenius 定律 $k = A\,e^{-E_\mathrm{a}/RT}$，即使 $E_\mathrm{a}$ 恒定，也随温度上升而缓慢下降。
:::

::: example 给蜥蜴升温 {#ex-q10}
某蜥蜴肌肉酶在 10 °C 的活性为 2.0（任意单位），$Q_{10} = 2.3$。(a) 它在 25 °C 的活性是多少？(b) 20 到 30 °C 之间 $Q_{10} = 2.3$ 对应多大的 Arrhenius 活化能？
::: solution
(a) $2.0\times2.3^{15/10} = 2.0\times3.49 = 6.98$，增大三倍半——这就是蜥蜴捕食前要晒太阳的原因。
(b) $\ln Q_{10} = (E_\mathrm{a}/R)(1/T_1 - 1/T_2)$，所以 $E_\mathrm{a} = 8.314\times\ln 2.3/(1/293.15 - 1/303.15) = 8.314\times0.833/1.125\times10^{-4} = 61.5\ \mathrm{kJ\,mol^{-1}}$。
:::
:::

生活在不同温度的物种已进化出适应各自温度的酶，这一领域由 Peter Hochachka 与 George Somero 开创（*Biochemical Adaptation*，2002）。有三条规律十分突出。

- **$K_\mathrm{m}$ 的保守。** 体温不同的物种的同源酶，当**各自在其体温下测定**时，$K_\mathrm{m}$ 往往相近，尽管在同一温度下测定时它们的 $K_\mathrm{m}$ 有差异。南极鱼、温带鱼与哺乳动物的乳酸脱氢酶是一例。把 $K_\mathrm{m}$ 保持在生理底物浓度附近，可同时保住催化速率与调控敏感性。
- **冷者 $k_\mathrm{cat}$ 更高。** 冷适应生物的酶在低温下的转换数常高于其暖适应同源物，部分抵消寒冷的减速效应——其手段是催化中运动的部位更柔性，代价是稳定性较低。
- **少数改变即可奏效。** 这类差别可以来自一个或几个氨基酸替换，常不在活性位点，而在运动性限制速率的部位。

::: warning “酶的最适温度就是其宿主生活的温度”
在短时测定中测得的最大活性温度，通常比生物体体温高几度甚至几十度，因为去折叠在测定时间尺度上很慢。选择所维持的是生物实际经历的温度下有充分的活性、调控与稳定性。把最适温度与栖息温度画等号，还忽略了较长时间暴露下、处于“最适”附近的酶可能被持续失活。
:::

## 抑制剂在生物学中

抑制剂既是研究酶的工具，也是它们生物学的一大半：植物与微生物用酶抑制剂自卫，许多除草剂、杀虫剂、抗生素与药物都是酶抑制剂。

::: proposition 可逆抑制 {#prop-inhibition}
设抑制剂 I 以解离常数 $K_\mathrm{i}$ 可逆结合游离酶，以解离常数 $K_\mathrm{i}'$ 结合酶-底物复合物。则

$$
v = \frac{V_{\max}[\mathrm{S}]}{\alpha K_\mathrm{m} + \alpha'[\mathrm{S}]},\qquad \alpha = 1 + \frac{[\mathrm{I}]}{K_\mathrm{i}},\quad \alpha' = 1 + \frac{[\mathrm{I}]}{K_\mathrm{i}'}.
$$ {#eq-inhibition}

**竞争性**抑制剂只结合游离酶（$\alpha' = 1$）：表观 $K_\mathrm{m}$ 升至 $\alpha K_\mathrm{m}$，$V_{\max}$ 不变。**反竞争性**抑制剂只结合 ES（$\alpha = 1$）：表观 $V_{\max}$ 与 $K_\mathrm{m}$ 都按 $\alpha'$ 下降。**混合性**抑制剂两者都结合；若 $K_\mathrm{i} = K_\mathrm{i}'$ 则称**非竞争性**，只有 $V_{\max}$ 下降。推导与诊断用的双倒数图见[化学图谱](/learn/chemistry/lesson.php?c=biochemistry&l=enzymes)。假设：[[#prop-mm]] 的假设，加上抑制剂快速可逆结合。
:::

::: example 竞争性抑制剂抑制多少？ {#ex-inhibitor}
$K_\mathrm{i} = 1.0$ µmol L⁻¹ 的竞争性抑制剂存在于 5.0 µmol L⁻¹，底物在其 $K_\mathrm{m}$。剩余速率是无抑制时的几分之几？要把速率恢复到 $V_{\max}$ 的一半需要多大底物浓度？
::: solution
$\alpha = 1 + 5/1 = 6$。当 $[\mathrm{S}] = K_\mathrm{m}$，$v/V_{\max} = K_\mathrm{m}/(6K_\mathrm{m} + K_\mathrm{m}) = 1/7 = 0.143$，而无抑制时为 0.5：剩余 $0.143/0.5 = 28.6$% 的未抑制速率。达到半最大速率需要 $[\mathrm{S}] = \alpha K_\mathrm{m} = 6K_\mathrm{m}$。在细胞中，被竞争性抑制步骤上游的酶常使底物积累，从而部分克服抑制——这是抑制剂对途径通量的影响通常小于其对纯化酶影响的原因之一（[[biochemistry/enzyme-regulation]]）。
:::
:::

**不可逆抑制剂**与酶共价反应。有些是酶自己活化的“自杀性”底物。青霉素——1928 年弗莱明（Alexander Fleming）在青霉菌 *Penicillium* 中发现——酰化交联细菌肽聚糖的转肽酶活性位点的丝氨酸，杀死生长中的细菌（[[microbiology/antimicrobials]]）。

在抑制剂的生物学利用中，最深刻的原理是**选择毒性**：抑制剂伤害依赖其靶标的生物，放过没有靶标的生物。

- **磺胺**是第一批合成抗菌药（多马克（Gerhard Domagk），1935），是对氨基苯甲酸的结构类似物，竞争性抑制细菌叶酸途径中的二氢蝶酸合酶。人不合成叶酸，从食物获取，所以没有这个靶标。
- **草甘膦**是世界范围内使用最广的除草剂，抑制莽草酸途径的 EPSP 合酶——植物、真菌与细菌以此合成芳香族氨基酸。动物没有这条途径——正是使 Phe 与 Trp 成为必需氨基酸的同一次丧失（[[biochemistry/amino-acids-proteins]]）。耐草甘膦作物携带细菌（*Agrobacterium* 菌株 CP4）的 EPSP 合酶，草甘膦与它结合很弱。
- **他汀**竞争性抑制 HMG-CoA 还原酶，即胆固醇合成的调空步骤；其临床用途见[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)。

耐药性按同样的规则进化：靶标部位突变使抑制剂亲和力下降得多而底物亲和力下降得少、靶标过量生产、破坏抑制剂的酶（β-内酰胺酶），或把抑制剂泵出的泵。

::: quiz
某酶的活性在多个底物浓度下有无化合物 X 各测一次。有 X 时，极高底物浓度下的速率与无 X 时相同，但要达到该速率的一半需要更多底物。X 是哪类抑制剂，它最可能如何结合？
- [x] 竞争性；它结合游离酶，可能在活性位点。
- [ ] 反竞争性；它只结合酶-底物复合物。
- [ ] 非竞争性；它在另一个位点与 E 和 ES 同等结合。
- [ ] 不可逆；它共价修饰活性位点。
::: solution
$V_{\max}$ 不变而表观 $K_\mathrm{m}$ 增大，是竞争性抑制的标志（[[#eq-inhibition]] 中 $\alpha > 1$、$\alpha' = 1$）；高底物可竞争过抑制剂。这通常意味着它结合在活性位点，常作为底物类似物；不过以排除底物的方式结合在别处也给出相同动力学。不可逆抑制剂会因去除有活性的酶而降低 $V_{\max}$。
:::
:::

::: application 工业与实验室中的酶
适应极端环境的生物的酶被用在出现那些条件的场合：*Thermus aquaticus* 与 *Pyrococcus* 的耐热 DNA 聚合酶用于聚合酶链反应；嗜冷菌的低温活性蛋白酶与脂肪酶用于低温洗涤剂的洗涤；淀粉酶与葡萄糖异构酶用淀粉制造高果糖浆。**定向进化**——围绕活性反复变异与选择，由 Frances Arnold 开创（2018 年诺贝尔化学奖）——为新底物与新条件调校这类酶，在实验室里重演塑造它们的自然过程（[[biotechnology]]）。
:::

::: history
Anselme Payen 与 Jean-François Persoz 1833 年从麦芽分离出消化淀粉的制剂淀粉酶（diastase）。巴斯德（Louis Pasteur）坚持发酵需要活的酵母；1897 年布赫纳（Eduard Buchner）证明磨碎酵母的无细胞汁能把糖发酵成乙醇，证明生命的化学可以在细胞外研究（1907 年诺贝尔化学奖）。Kühne 早在 1877 年创造了 enzyme 一词（“在酵母中”）。费歇尔 1894 年提出锁钥模型。米凯利斯与 Menten 于 1913 年发表其动力学，Briggs 与霍尔丹于 1925 年给出稳态推导，Lineweaver 与 Burk 于 1934 年给出他们的作图法。萨姆纳 1926 年结晶脲酶并证明它是蛋白质；Northrop 与 Stanley 结晶了胃蛋白酶与其他酶（1946 年诺贝尔奖，与萨姆纳分享）。同工酶得名于 1959 年。Thomas Cech（1982）与 Sidney Altman（1983）发现 RNA 也可以是酶（1989 年诺贝尔化学奖）。
:::

## 由此走向何处

酶受别构、共价修饰与数量变化的控制——这是 [[biochemistry/enzyme-regulation]] 的主题，该课还讨论一个酶对途径究竟施加多大控制。决定酶催化反应朝哪个方向进行的能量学在 [[biochemistry/bioenergetics]]。

::: summary
- 酶使反应加速最高达 $10^{17}$ 倍而不改变平衡；许多需要金属离子或辅酶，辅酶大多由维生素制成。
- 活性用初速率测定，常偶联 NADH（$\varepsilon_{340} = 6220\ \mathrm{L\,mol^{-1}\,cm^{-1}}$），以 µmol min⁻¹ 为单位；比活性随纯化上升。
- 米氏动力学：$v = V_{\max}[\mathrm{S}]/(K_\mathrm{m} + [\mathrm{S}])$；$k_\mathrm{cat}$ 是每个位点的转换数，$k_\mathrm{cat}/K_\mathrm{m}$ 是专一性常数（扩散极限 $10^8$–$10^9\ \mathrm{L\,mol^{-1}\,s^{-1}}$）。应直接拟合；双倒数图扭曲误差。
- 同工酶把一个反应调到各组织：己糖激酶 I 在血糖下饱和；葡萄糖激酶跟踪血糖。
- 竞争底物之间靠 $k_\mathrm{cat}/K_\mathrm{m}$ 甄别：C3 叶中 Rubisco 大约每三次羧化有一次加氧。
- $Q_{10} \approx 2$–3；来自不同气候物种的酶在各自体温下保守 $K_\mathrm{m}$，调整 $k_\mathrm{cat}$ 与柔性。
- 可逆抑制剂有竞争性、反竞争性与混合性；选择毒性（磺胺、草甘膦、青霉素）利用一种生物有而另一种没有的靶标。
:::

## 练习

::: exercise 最大速率的分数 {level=1 check="0.2"}
米氏酶在 $[\mathrm{S}] = K_\mathrm{m}/4$ 工作时，速率是 $V_{\max}$ 的几分之几？
::: solution
$v/V_{\max} = (K_\mathrm{m}/4)/(K_\mathrm{m} + K_\mathrm{m}/4) = (1/4)/(5/4) = 0.2$。
:::
:::

::: exercise 转换数 {level=1 check="250"}
一种纯酶（摩尔质量 50 kDa，每个分子一个活性位点）在饱和底物下的比活性为 300 U mg⁻¹。其 $k_\mathrm{cat}$ 是多少 s⁻¹？
::: solution
1 mg 是 $10^{-3}/50\,000 = 2.0\times10^{-8}$ mol 酶。300 U 是 $300\ \mathrm{\mu mol\,min^{-1}} = 5.0\times10^{-6}\ \mathrm{mol\,s^{-1}}$。$k_\mathrm{cat} = 5.0\times10^{-6}/2.0\times10^{-8} = 250\ \mathrm{s^{-1}}$。
:::
:::

::: exercise 一张纯化表 {level=1 check="400"}
一种酶经四步纯化，总蛋白与总活力如下：粗提取液 2000 mg、4000 U；硫酸铵级分 400 mg、3200 U；离子交换 40 mg、2400 U；亲和层析柱 2.0 mg、1600 U。计算每一步后的比活性、总纯化倍数与得率。
::: solution
比活性：2.0、8.0、60 与 800 U mg⁻¹。纯化倍数 $= 800/2.0 = 400$。得率 $= 1600/4000 = 40$%。若再增加一步不再提高比活性，酶很可能已纯（用 SDS-PAGE 检查，[[biochemistry/amino-acids-proteins#ex-sds]]）。
:::
:::

::: exercise 作为传感器的葡萄糖激酶 {level=2 check="1.91"}
用 [[#ex-glucokinase]] 的葡萄糖激酶速率方程，葡萄糖从 5 升到 10 mmol L⁻¹ 时其速率增大多少倍（三位有效数字）？己糖激酶 I 的速率增大多少倍？
::: solution
葡萄糖激酶：$0.594/0.310 = 1.91$。己糖激酶 I：$0.995/0.990 = 1.005$。只有葡萄糖激酶报告血糖的变化。
:::
:::

::: exercise 专一性与 Rubisco {level=2 check="28.8"}
C4 叶的维管束鞘细胞中，Rubisco 周围的 CO₂ 浓度约提高十倍到 80 µmol L⁻¹，而 O₂ 仍约 250 µmol L⁻¹。用 $S_{c/o} = 90$，羧化与加氧之比是多少（三位有效数字）？
::: solution
$v_c/v_o = 90\times80/250 = 28.8$，是 C3 值的十倍：加氧与光呼吸几乎被抑制。（实际上 C4 的 Rubisco 的 $S_{c/o}$ 往往略低于 C3 者而 $k_\mathrm{cat}$ 更高，与上述权衡一致：CO₂ 既已浓集，选择可以偏向速度而非专一性。）
:::
:::

::: exercise 寒冷中的 Q₁₀ {level=2 check="0.435"}
一种鱼酶的 $Q_{10} = 2.0$。水温从 20 °C 降到 8 °C，若无驯化，剩下 20 °C 时活性的几分之几（三位有效数字）？
::: solution
$2.0^{-12/10} = 2^{-1.2} = 0.435$。剩下的活性不足一半，这就是适应寒冷的鱼会增加关键酶的量或改用低温活性更高的同工酶的原因。
:::

::: exercise 诊断抑制剂 {level=2}
在若干 [S] 下测定某酶的初速率，无抑制剂与加入 2 µmol L⁻¹ 某抑制剂各一次。无抑制剂时 $V_{\max} = 100$、$K_\mathrm{m} = 1.0$ mmol L⁻¹；有抑制剂时表观 $V_{\max} = 50$、表观 $K_\mathrm{m} = 0.50$ mmol L⁻¹。(a) 这是哪类抑制？(b) 计算抑制常数。(c) 在双倒数图上两条线应是什么样子？
::: solution
(a) 两个参数按同样倍数（2）下降：反竞争性抑制，只结合 ES（$\alpha = 1$，$\alpha' = 2$）。(b) $\alpha' = 1 + [\mathrm{I}]/K_\mathrm{i}' = 2$，$[\mathrm{I}] = 2$ µmol L⁻¹，所以 $K_\mathrm{i}' = 2$ µmol L⁻¹。(c) 由 [[#eq-lb]]，斜率 $K_\mathrm{m}/V_{\max}$ 不变（1.0/100 = 0.5/50），而截距 $1/V_{\max}$ 加倍：两条平行线，有抑制的那条在上方。
:::
:::

::: exercise 解读温度适应研究 {level=3}
从南极鱼（体温 −1.9 °C）、温带鱼（约 15 °C）与哺乳动物（37 °C）纯化乳酸脱氢酶，在不同温度测定对丙酮酸的 $K_\mathrm{m}$（示例值，mmol L⁻¹）：

| 测定温度 | 0 °C | 15 °C | 37 °C |
|---|---|---|---|
| 南极鱼 | 0.15 | 0.24 | 0.55 |
| 温带鱼 | 0.10 | 0.16 | 0.36 |
| 哺乳动物 | 0.06 | 0.09 | 0.17 |

(a) 读出各物种在其体温下的 $K_\mathrm{m}$（南极鱼用 0 °C）。你看到什么规律？(b) 选择为何可能在体温下保守 $K_\mathrm{m}$？(c) 在 0 °C 测定的 $k_\mathrm{cat}$ 你预期如何？为什么？
::: solution
(a) 约 0.15（南极鱼，0 °C）、0.16（温带鱼，15 °C）与 0.17（哺乳动物，37 °C）：几乎相同，尽管同一温度下相差两到三倍。这就是 Hochachka 与 Somero 描述的在生理温度下 $K_\mathrm{m}$ 的保守。(b) 各脊椎动物肌肉中丙酮酸浓度相近；把 $K_\mathrm{m}$ 保持在生理底物浓度附近，酶就能对底物变化保持响应（既不饱和，也不在极小容量分数下工作），并保住催化效率。(c) 南极鱼酶在 0 °C 应有最高的 $k_\mathrm{cat}$，以更大的结构柔性补偿寒冷，且应最不耐热。同一温度下较高的 $K_\mathrm{m}$（结合较弱）是同一权衡的一部分：更柔性的酶结合较松但周转更快。
:::
:::

::: exercise 选择选择性靶标 {level=3}
请为一种应对哺乳类、鸟、鱼与昆虫无害的新除草剂寻找靶标。用选择毒性原理，(a) 说出两类好的候选植物酶并解释理由；(b) 解释为什么抑制一种与动物酶有近亲同源关系的植物酶仍可能有选择性；(c) 描述杂草进化出耐药性的两种方式，以及耐药性在提取物测定的酶动力学上将如何显现。
::: solution
(a) 动物没有的途径中的酶：芳香族氨基酸的莽草酸途径（草甘膦的靶标）、支链氨基酸合成（乙酰乳酸合酶，磺酰脲类除草剂的靶标）、光合作用（光系统 II，阿特拉津及相关除草剂的靶标）与类胡萝卜素合成。动物没有靶标，直接毒性低。(b) 同源酶结构有差别，尤其在调控与结合表面，所以抑制剂可被设计成对植物型结合得紧得多；植物与动物在吸收、代谢与排泄上的差别进一步增加选择性。植物特异的亚型或隔室（质体）也有帮助。(c) 靶标部位抗性：酶中削弱抑制剂结合的突变——在提取物中表现为 $K_\mathrm{i}$ 升高，理想情况下对天然底物的 $K_\mathrm{m}$ 几乎不变（否则该突变要付出适合度代价）。非靶标部位抗性：解毒增强（细胞色素 P450 或谷胱甘肽转移酶活性升高）、吸收或转运减少，或靶标基因扩增（如在耐草甘膦的 *Amaranthus palmeri* 中发现的 EPSP 合酶扩增），表现为提取物中靶标酶 $V_{\max}$ 升高而 $K_\mathrm{i}$ 不变。
:::
:::
