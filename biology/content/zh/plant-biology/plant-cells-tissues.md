把马铃薯块茎的一薄片、一层洋葱表皮或一张幼叶放到光学显微镜下，最先看到的不是细胞本身，而是它们的边界：壁的蜂巢。Robert Hooke 在1665年于软木中看到过同样的蜂巢，并把其中的隔室称为“细胞”；他看到的其实是空空的壁，生命的内含物早已消失。细胞壁是植物细胞的界定性特征。它让植物细胞能承受数倍于汽车轮胎的内部压力，它把每个细胞终身固定原位，它决定一个细胞能往哪个形状生长，而在木材中，它在细胞死亡之后仍作为承重的骨架留存。植物所固定、如今储存在陆地生物圈中的碳，大部分是壁物质：纤维素、半纤维素与木质素。

本章自下而上构建植物体。我们从区分植物细胞与 [[cell-biology/organelles]] 中动物细胞的三个特征——**细胞壁**、**质体**与大的中央**液泡**——以及**胞间连丝**讲起，胞间连丝是把相邻细胞的细胞质穿过细胞壁连接起来的通道。随后我们认识构成一切植物器官的那寥寥几种细胞类型，以及它们排布于其中的三个**组织系统**——皮组织系统、维管组织系统与基本组织系统。定量的主线是力学的：膨压如何拉伸细胞壁，为什么圆柱形细胞沿周向受到的应力是沿轴向的两倍，以及植物如何利用这一点来选择生长的方向。演化的背景——陆生植物如何从绿藻起源并获得角质层、气孔与维管组织——在 [[diversity-of-life/land-plants]]，我们在其上继续构建。

## 植物细胞的不同之处

叶片或幼茎的一个典型细胞，具有真核细胞所需的一切：细胞核、内质网、高尔基体（在植物中通常是许多各自分离的垛堆，即圆筒体 dictyosomes，在细胞质中移动）、线粒体、过氧化物酶体、核糖体，以及由微管与肌动蛋白丝组成的细胞骨架（[[cell-biology/organelles]]，[[cell-biology/cytoskeleton]]）。三项增补使它脱胎换骨。

1. 质膜之外有一个**细胞壁**，一种把纤维素纤维嵌在其他多糖与蛋白质基质中的复合材料。细胞壁抵抗细胞的内部压力并决定细胞的形状。
2. **质体**，一类有两层被膜与自身基因组的细胞器，由蓝细菌传下来（[[cell-biology/organelles#def-endosymbiosis]]）。叶绿体是光合作用的类型；其他类型储存淀粉、油脂或色素。
3. 一个大的**中央液泡**，以**液泡膜**为界，在成熟细胞中通常占细胞体积的80–90 %以上，把细胞质挤成贴着壁的一薄层。

植物细胞也缺少动物细胞有的一些东西：没有中心粒（微管从许多位点成核，没有单一的中心体），没有动物类型的中间丝，也没有胶原构成的细胞外基质；细胞壁在力学上取代了这一切的位置。

::: warning "植物有叶绿体而不是线粒体"
一个常见的错误是认为植物既然能光合作用就不进行呼吸。每个活植物细胞都有线粒体，昼夜不停地进行糖酵解、三羧酸循环与氧化磷酸化（[[biochemistry/oxidative-phosphorylation]]）。根、种子、花、果实与茎的非绿色细胞根本没有可用的叶绿体，完全依赖呼吸由叶片输入的糖。即使是叶子也在光中呼吸；在暗中它是氧气的净消费者。叶绿体制造糖；线粒体燃烧糖。
:::

## 细胞壁

### 初生壁、次生壁与胞间层

::: definition 初生壁、次生壁与胞间层 {#def-wall}
**初生壁**是细胞仍在生长时沉积的薄壁（通常0.1–1 µm）、可伸展的壁。它由嵌在水合的**半纤维素**与**果胶**基质中的**纤维素微纤丝**构成，另含少量结构蛋白。**胞间层**是细胞分裂时形成的富果胶层，把相邻细胞的初生壁粘在一起。生长停止后，许多细胞在初生壁内侧沉积**次生壁**：更厚、纤维素更丰、果胶更少，常分数层且各层微纤丝取向不同，并常在许多细胞类型中被**木质素**浸透。
:::

**纤维素**是葡萄糖残基以 β(1→4) 键相连的无分支链（[[biochemistry/carbohydrates-lipids]]）。由于每个残基相对其邻残基旋转180°，链是扁平笔直的，两缘排布羟基；相邻链以大量氢键彼此结合，堆叠成近乎结晶的**微纤丝**。每个葡萄糖给链长增加约0.515 nm。在开花植物的初生壁中，微纤丝直径约3 nm，据信含18条链（数目曾有争议，旧模型提出36条），每条的聚合度——葡萄糖残基数——达数千。微纤丝的比拉伸刚度可与钢相比，是壁复合材料的增强纤维，正如钢筋增强混凝土。

纤维素不像基质多糖那样在细胞内合成再输出。它在质膜上由**纤维素合酶复合体**纺出——冰冻断裂电镜下可见的六瓣玫瑰状结构，每瓣含若干 CESA 蛋白。每个 CESA 从细胞质取 UDP-葡萄糖，把一条正在伸长的葡聚糖链挤出膜外；一个复合体纺出的各链共同结晶成一根微纤丝。由于链被固定在壁中，复合体被向后推过膜，于是复合体会移动。2006年，Alex Paredez、Chris Somerville 与 David Ehrhardt 活体成像了带荧光标记的 CESA6（在 *Arabidopsis thaliana* 下胚轴细胞中），看到复合体沿着膜下皮层**微管**定义的轨道行进，速率为每分钟几百纳米。细胞器骨架就是这样引导微纤丝的取向，并通过微纤丝，正如我们将看到的，引导生长的方向。

::: example 纺出一条纤维素链要多久？ {#ex-cesa}
一个纤维素合酶复合体以约300 nm min⁻¹ 穿过膜。(a) 它的每条链每秒增加多少个葡萄糖残基？(b) 合成一条聚合度为8,000的链要多久，那条链有多长？
::: solution
(a) 每个残基给链增加0.515 nm，而复合体前进的距离正是它已沉积链的长度，所以每条链每分钟增加 $300/0.515 = 583$ 个残基，即每个 CESA 约**每秒10个葡萄糖残基**。

(b) 该链长 $8000\times0.515\text{ nm} = 4120\text{ nm} \approx 4.1$ µm，需要 $4120/300 = 13.7$ 分钟，约**14分钟**合成。微纤丝比任何单条链都长，因为各链的起点与终点彼此错开。作为对比，一个直径40 µm 的细胞周长为 $\pi\times40 = 126$ µm；缠绕它的一根微纤丝由许多相互搭接的链构成。
:::
:::

**基质**在高尔基体中合成，经分泌囊泡递送。除禾本科外，大多数开花植物的初生壁中主要的**半纤维素**是**木葡聚糖**（xyloglucan），一种带木糖侧链的 β(1→4)-葡聚糖主链，它结合到纤维素表面，可能在有限数目的位点上连接微纤丝。**果胶**是富含半乳糖醛酸的酸性多糖一族。最简单的是**同型半乳糖醛酸聚糖**（homogalacturonan），分泌时其羧基大多被甲基酯化；在壁中，果胶甲酯酶去掉甲基，解放出的羧酸根被 Ca²⁺ 交联成凝胶。禾本科及其近缘类的初生壁不同：果胶与木葡聚糖较少，葡萄糖醛酸阿拉伯木聚糖与杂键（1→3),(1→4)-β-葡聚糖较多。粗略地说，双子叶植物初生壁按干重约四分之一到三分之一是纤维素、四分之一是半纤维素、三分之一是果胶，蛋白质几个百分点；比例在不同组织与物种之间差异很大。

**木质素**是苯丙素单元（单木酚醇）的一种疏水聚合物，在壁中由过氧化物酶与漆酶聚合成不规则的交联网络。它填满多糖之间的空隙、驱替水分，使壁坚硬、防水且极难消化。木质素与维管植物共同进化；它让木质部输水细胞能抵抗水被拉过其中时的张力（[[plant-biology/water-transport]]），让树木能挺立100 m 高。另有两种疏水聚合物沉积在特定位置：**角质**（cutin）与蜡一起构成表皮外表面的角质层，**木栓质**（suberin）封闭木栓细胞与根的**内皮层**（endodermis）。

### 压力下的壁

植物细胞以渗透方式吸水，直到其壁向内的推力与水进入的渗透趋势相平衡。由此产生的细胞内静水压称为**膨压** $P$，典型为0.3–1 MPa（大气压的3–10倍），在保卫细胞中可超过2 MPa。它可由 van 't Hoff 渗透压与浓度的关系估算（[[biochemistry/water-and-bonds]]）；水势的完整处理在 [[plant-biology/water-transport]]。

::: example 由溶质浓度差估算膨压 {#ex-turgor}
一个细胞液含0.30 osmol kg⁻¹ 溶质，处于含0.05 osmol kg⁻¹ 溶质的组织水中。设它已达到平衡、溶液为稀溶液，估算其在20 °C 下的膨压。
::: solution
平衡时膨压与渗透压之差相抵。由 $\Delta c = 0.25$ osmol kg⁻¹ $\approx 250$ mol m⁻³，

$$
P = \Delta c\,RT = 250\times8.314\times293.15\ \text{Pa} = 6.09\times10^5\ \text{Pa} \approx 0.61\ \text{MPa},
$$

约六个大气压。（van 't Hoff 关系严格来说只适用于理想稀溶液；在这些浓度下对糖可精确到几个百分点，对渗透系数小于1的盐则差一些。）
:::
:::

这压力对壁施加多大的力？把伸长的植物细胞想成半径为 $r$、两端封闭的薄壁圆柱。

::: proposition 受压圆柱的壁应力 {#prop-hoop}
设半径为 $r$、壁厚 $t \ll r$ 的圆柱形细胞持有膨压 $P$（高于外部压力）。若壁沿厚度均匀承载，则绕圆周方向的壁内拉伸应力（**环向应力**）与沿轴向的（**轴向应力**）为

$$
\sigma_\text{hoop} = \frac{P\,r}{t}, \qquad \sigma_\text{axial} = \frac{P\,r}{2t}.
$$ {#eq-hoop}

对球形细胞，各个方向的应力相同，$\sigma = P\,r/(2t)$。
:::

::: proof
*环向应力。*沿过轴的平面把长 $L$ 的一段圆柱切成两半。压力作用于一半的内侧，把它推离另一半，合力等于 $P$ 乘以切口的投影面积，$P\cdot 2rL$。这个力由两条切缝处面积为 $tL$ 的壁带以应力 $\sigma_\text{hoop}$ 承担：$2tL\,\sigma_\text{hoop} = 2rLP$，故 $\sigma_\text{hoop} = Pr/t$。

*轴向应力。*横过轴切开圆柱。端帽上的压力以 $P\pi r^2$ 推进，由面积 $2\pi r t$ 的壁环（$t \ll r$ 时）承担：$2\pi r t\,\sigma_\text{axial} = \pi r^2 P$，故 $\sigma_\text{axial} = Pr/(2t)$。对球体，过心的同样切口在任何取向下都给出 $2\pi rt\,\sigma = \pi r^2 P$。
:::

假设很重要：壁必须相对于半径很薄、均匀，细胞必须大致为圆柱形。真实细胞有分担载荷的邻居、厚薄不匀的壁与角隅；但数量级，尤其是那个因子2，是稳健的。

::: example 生长中细胞壁的应力 {#ex-hoop}
生长茎中一个圆柱形细胞半径20 µm，初生壁厚0.2 µm，膨压0.6 MPa。求环向与轴向应力。
::: solution
由 [[#eq-hoop]]，$\sigma_\text{hoop} = 0.6\times20/0.2 = 60$ MPa，$\sigma_\text{axial} = 30$ MPa。壁虽只有五分之一微米厚，却承担着几十兆帕的应力——是膨压本身的一百倍，因为比值 $r/t = 100$ 把压力放大了。这就是植物细胞需要像纤维素这样强韧的纤维加强的壁的原因，也是稍稍松一松壁就能让细胞扩张的原因。
:::
:::

::: intuition 为什么细胞长长而不长粗
如果壁各个方向一样刚，圆柱形细胞会沿周向比沿轴向扩张得更多，因为环向应力是轴向应力的两倍：它会长胖。生长的植物细胞通常反其道而行，伸长许多倍而几乎不增粗。办法是把纤维素微纤丝主要沿圆周铺放，像桶上的箍。这些“箍”抵抗径向扩张，箍间的基质可以相互滑开，让生长沿轴进行。箍的取向听从引导纤维素合酶复合体的皮层微管。用除草剂 oryzalin 等破坏微管，新沉积的微纤丝便杂乱无章；细胞随即像气球一样膨大而不伸长。生长的方向，是壁如何建造的一个力学结果。
:::

扩张要求壁发生屈服。生长中的壁由**扩张蛋白**（expansins）松动——Simon McQueen-Mason 与 Daniel Cosgrove 于1992年在黄瓜下胚轴中发现的蛋白质，在酸性 pH 下有活性，据信能破坏纤维素与基质多糖之间的非共价结合，让壁在膨压的应力下蠕变。把质子泵入壁中——生长素促进这一点——因此能松动壁——即 [[plant-biology/plant-hormones]] 中讨论的**酸生长**响应。膨压与壁扩张性如何共同决定生长速率，是 [[plant-biology/plant-form]] 中 Lockhart 方程的主题。

## 质体与液泡

### 质体

一个植物的所有质体都从未分化细胞中小而不分化的**前质体**发育而来（或在某些组织中由一种成熟类型转化为另一种），并以分裂方式增殖。它们采取哪种形式取决于细胞及其环境。

::: definition 质体的类型 {#def-plastids}
- **叶绿体**在内部的**类囊体**膜系统中含有叶绿素，类囊体垛叠成**基粒**，由不垛叠的基质片层相连，执行光合作用。一个 *Arabidopsis* 叶肉细胞含一百个左右。
- **黄化质体**是暗中生长的幼苗的质体：含一个格网状膜结构的**前片层体**与叶绿素前体，照光后数小时内变为叶绿体。
- **淀粉体**储存淀粉，见于马铃薯块茎与谷粒胚乳等储藏器官；在根冠与茎内皮层中，致密的淀粉体在重力下沉降，充当重力感受器（[[plant-biology/plant-responses]]）。
- **有色体**积累类胡萝卜素色素，把成熟番茄、辣椒、胡萝卜与许多花瓣染成橙、黄或红。
- **白色体**是无色质体的统称，包括储脂的**造油体**。
:::

质体不只为光合作用而存在。每个植物细胞都依赖质体，因为质体是脂肪酸、多数氨基酸、嘌呤与嘧啶、叶绿素与血红素、以及类胡萝卜素及其衍生激素的合成场所。没有质体的细胞无法存活。叶绿体的结构与光反应在 [[plant-biology/photosynthesis]] 展开。

### 液泡

::: definition 液泡与液泡膜 {#def-vacuole}
成熟植物细胞的**中央液泡**是由**液泡膜**包围的单个大隔室。其腔被液泡膜上的两种质子泵——V 型 ATP 酶与液泡型 H⁺-焦磷酸酶——酸化至约 pH 5–5.5（柑橘果实低至 pH 2–3），由此产生的质子梯度驱动 H⁺ 偶联的反转运体积累离子、糖、有机酸与次生代谢物。**溶解性液泡**在承担这一职能之外兼具动物溶酶体的水解功能；**蛋白储存液泡**见于种子，储存贮藏蛋白。
:::

液泡身兼数职。它**储存**：K⁺ 与 Cl⁻ 之类的离子、糖、有机酸（CAM 植物的苹果酸，[[plant-biology/c4-and-cam]]）、色素（红色花瓣与秋叶的花青素溶在液泡里）、以及生物碱与硫苷之类的防御化合物——把它们与细胞质中会激活它们或为它们所毒的酶隔开。它**消化**：自噬把磨损的细胞器送进来。它还**充胀**细胞：通过积累溶质与水，它产生膨压，并用廉价的盐水糖水溶液占据大细胞的大部分体积，而不是用装满蛋白质与核糖体的昂贵细胞质。

::: example 细胞质有多薄？ {#ex-vacuole}
一个圆柱形叶细胞半径20 µm、长100 µm；其液泡占据其体积的90 %。若细胞质形成均匀一层贴着侧壁（忽略两端），那一层有多厚？
::: solution
细胞质占圆柱的 $10\,\%$，所以液泡是半径 $r - d$ 的圆柱，满足 $\pi(r-d)^2L = 0.9\,\pi r^2 L$。于是

$$
d = r\left(1 - \sqrt{0.9}\right) = 20\times(1 - 0.9487)\ \text{µm} = 1.03\ \text{µm}.
$$

活细胞质只是约一微米厚的薄膜，叶绿体（每个约5 µm 宽）就贴壁躺在其中。由此有两个推论。以10 µm² s⁻¹ 扩散的蛋白质穿过这层只需不到一秒，所以大的植物细胞在扩散上实际上是一薄片（[[cell-biology/cells-and-microscopy]]）。而且叶绿体坐在壁旁，即 CO₂ 到来之处，而不是埋在细胞中央。
:::
:::

液泡也是植物细胞不制造多少新细胞质却能长得这么快、这么大的办法。在根或茎中伸长的细胞把水吸进液泡，把体积扩大十倍到百倍，而细胞质的量增加得少得多。植物生长的能量开销主要在壁，而不在填满细胞。

## 胞间连丝：相连通的细胞质

植物细胞分裂时，新壁——**细胞板**——由高尔基囊泡在细胞中央组装而成，由**成膜体**（微管与肌动蛋白的阵列）引导，向外生长直到与母壁融合（[[cell-biology/cell-cycle]]）。被困在成形细胞板中的内质网丝 成为**胞间连丝**的核心。

::: definition 胞间连丝、共质体与质外体 {#def-symplast}
**胞间连丝**（plasmodesma，复数 plasmodesmata）是膜衬里的通道，直径通常20–50 nm，横穿细胞壁，把两个相邻细胞的质膜连成一个连续的膜。穿过其中心的是**联丝体**（desmotubule），一根由致密内质网构成的细管；联丝体与质膜之间的**胞质鞘**是分子在细胞间移动的通路。所有由胞间连丝相连的细胞的细胞质构成**共质体**（symplast）。质膜以外的一切——细胞壁、细胞间隙与死亡木质部输导分子的腔——构成**质外体**（apoplast）。
:::

胞间连丝让小分子——糖、氨基酸、离子、激素——在不穿膜的情况下从一细胞移到另一细胞。能自由穿过静息胞间连丝的最大分子——其**尺寸排阻极限**——常被引为约1 kDa，但它是被调控的。植物通过在通道颈部周围的壁中沉积多糖**胼胝质**（callose，一种 β(1→3)-葡聚糖）来收窄胞间连丝，又通过移除它来拓宽。在发育中与库组织中极限可以大得多，某些蛋白质——如 SHORT-ROOT 与 KNOTTED1 之类的转录因子，以及植物病毒用于扩散的病毒运动蛋白——能主动穿过。

::: example 什么能穿过胞间连丝？ {#ex-sel}
质量为 $M$（以道尔顿计）的球状蛋白的最小半径约为 $0.066\,M^{1/3}$ nm。据估计，静息胞间连丝的胞质鞘允许半径约1–1.5 nm 的颗粒通过。试比较蔗糖（342 Da；水动力学半径约0.5 nm）、一个1 kDa 的多肽与绿色荧光蛋白（GFP，27 kDa）。
::: solution
一个1 kDa 的分子 $r \approx 0.066\times1000^{1/3} = 0.66$ nm；蔗糖约0.5 nm；两者都可通过。GFP 有 $r \ge 0.066\times27000^{1/3} = 1.98$ nm（其真实水动力学半径更大，约2.4 nm，因为它不是完美球体且带有水化层），所以应当被静息胞间连丝排除。实验相符：Karl Oparka 及同事（1999）发现，在烟草叶片一个细胞中表达的 GFP 在幼嫩的输入（库）叶中自由地在细胞间扩散，但在成熟的输出（源）叶中停留在原地。尺寸排阻极限不是通道的固定属性，而随发育改变。
:::
:::

胞间连丝把植物划分为**共质体域**。成熟的保卫细胞失去它们的连丝，成为孤立者，从而能独立于邻居改变膨压。韧皮部的筛管分子经分支的胞间连丝与它们的伴胞相连，但在许多物种中，伴胞-筛管分子复合体与周围细胞几乎隔绝，这一事实对糖如何装载进韧皮部至为重要（[[plant-biology/water-transport]]）。

## 细胞类型

植物由惊人地少的细胞类型建成。植物学家按壁、并按成熟时是否存活来分门别类。

::: definition 基本细胞类型 {#def-cell-types}
- **薄壁组织**（parenchyma）细胞壁薄（仅初生壁），成熟时存活。它们进行光合作用（叶肉）、储存（马铃薯块茎、种子子叶）、分泌与愈合伤口，还能恢复分裂。植物柔软组织的大部分是薄壁组织。
- **厚角组织**（collenchyma）细胞存活、细长，初生壁不均匀加厚且富含果胶。它们支撑幼嫩、正在生长的器官——芹菜叶柄的“筋”就是厚角组织——因为它们的壁强韧而仍能伸展。
- **厚壁组织**（sclerenchyma）细胞有厚的、常木质化的次生壁，成熟时常常已死。**纤维**长而细（亚麻、大麻与黄麻的商品纤维）；**石细胞**短而不规则（梨果肉里的砂粒、桃核的硬壳）。
- **木质部**输导细胞——**管胞**与**导管分子**——是具木质化次生壁的延长细胞，成熟时死亡，留下输水的空管。管胞两端封闭，经**纹孔**——壁的薄区——传水；导管分子失去端壁（部分或全部），首尾相接成**导管**，可长达几厘米到几米。
- **韧皮部**输导细胞——**筛管分子**——存活但失去细胞核、液泡与多数细胞器；它们经开有扩大、胼胝质衬里孔洞的**筛板**首尾相接成**筛管**。在开花植物中，每个筛管分子由一个或数个**伴胞**——它的姐妹细胞——服侍，伴胞供给蛋白质与能量。
:::

注意两个维管组织的悖论。木质部经已死之细胞输导，其腔是空的，流动遇不到膜或细胞质；韧皮部经活细胞输导，因为正如我们将在 [[plant-biology/water-transport]] 看到的，韧皮部运输由输导分子进出糖的膜运输驱动。木质部细胞的死亡是程序性的：它继次生壁沉积而发生，涉及液泡破裂和水解酶释放以清空细胞内含物。

## 组织系统

细胞组成组织，组织归入三个系统，连续贯穿每个器官——根、茎、叶。这种连续性是植物解剖的简化思想之一：无论哪个器官，都能找到同样的三个系统，只是排布不同。

::: definition 三个组织系统 {#def-tissue-systems}
- **皮组织系统**是外表覆盖。在初生体中它是**表皮**，通常一层细胞厚，地上部分表面覆以**角质层**，并含特化的细胞——构成**气孔**的**保卫细胞**、**毛状体**（表皮毛），根中还有**根毛**。器官因次生生长而加粗之处，表皮被**周皮**取代，周皮由木栓构成。
- **维管组织系统**由**木质部**（把水与溶解的矿质从根向上运送）与**韧皮部**（把糖、氨基酸与信号从源运到库）以及伴生的薄壁组织与纤维组成。
- **基本组织系统**是其余的一切：多为薄壁组织，配有厚角组织与厚壁组织。在叶中它构成光合的**叶肉**；在茎与根中，构成**皮层**与**髓**。
:::

表皮是一个了不起的组织。它的外壁厚，覆盖着角质与蜡构成的、对水几乎不可透的角质层——叶的角质层导度通常比其开放气孔的导度低一到两个数量级。气体交换因此经过气孔进行：每个气孔是一个由两个**保卫细胞**夹护的孔，保卫细胞的膨压使其开闭。保卫细胞的壁加厚，微纤丝呈辐射状排列，像 [[#prop-hoop]] 中箍在细胞上的桶箍反过来放，于是膨压升高时细胞伸长并彼此弓开，孔即张开。气孔密度从每平方毫米叶面几十到几百不等；气孔如何调控在 [[plant-biology/water-transport]] 与 [[plant-biology/plant-hormones]] 中展开。

在根中，皮层的最内一层——**内皮层**——在其径向壁与横向壁中有一条木质素与木栓质的带，即**凯氏带**（Casparian strip），它阻断质外体。沿壁向内移动的水与溶质必须穿过一道内皮层的质膜才能到达木质部，这使根能控制自己吸收什么（[[plant-biology/mineral-nutrition]]）。

这些系统在根、茎、叶中如何排布、如何由分生组织产生，是 [[plant-biology/plant-form]] 的主题。这里先给出粗略蓝图：

| 器官 | 皮组织系统 | 维管组织系统 | 基本组织系统 |
|---|---|---|---|
| 幼根 | 具根毛的表皮，无角质层 | 中央圆柱（中柱），木质部与韧皮部相间成束，外围中柱鞘 | 皮层，以内皮层为最内层 |
| 幼茎 | 具角质层与气孔的表皮 | 维管束：双子叶植物成环，单子叶植物散生 | 束外为皮层，束内为髓 |
| 叶 | 上、下表皮，许多物种气孔多在下侧 | 叶脉（维管束），常为维管束鞘所环绕 | 叶肉：栅栏组织与海绵组织（均为薄壁组织） |

::: application 我们利用的壁
植物细胞壁是地球上最丰富的生物材料，也是最有用的材料之一。木材主要是次生壁：按干重约40–50 %纤维素、20–30 %半纤维素与20–30 %木质素，针叶材与阔叶材比例不同。纸是经过制浆除去大部分木质素后的纤维素纤维。棉纤维是种皮的一个表皮细胞，长达约3 cm，其次生壁几乎是纯纤维素。亚麻布来自亚麻的韧皮部纤维。在膳食中，细胞壁是**膳食纤维**，人的酶不能消化，但肠道细菌能发酵。而由于壁持有植物的大部分碳，把它们转化为燃料与化学品是生物技术的一大目标；障碍是木质素，它庇护纤维素免受酶的攻击。工程化改造植物使其少产木质素、或产出在温和化学处理下更易分解的木质素，是攻克这一“顽固性”问题的一条途径；然而木质素太少又会使木质部导管在张力下扁塌——*Arabidopsis* 的 *irregular xylem* 突变体正体现了这种折衷。
:::

::: history
Robert Hooke 在 *Micrographia*（1665）中描述并命名了软木中的细胞；Nehemiah Grew（*The Anatomy of Plants*，1682）与 Marcello Malpighi（*Anatome plantarum*，1675–1679）描述了植物组织——Grew 把“parenchyma”一词引入植物学。Robert Brown 于1831年在兰科表皮细胞中描述了细胞核。Anselme Payen 于1838年分离并命名了纤维素；Hugo von Mohl 于1846年把生命内含物命名为“protoplasm”（原生质）。Eduard Tangl 于1879年在胚乳细胞壁中看到胞质连丝，Eduard Strasburger 于1901年将其命名为胞间连丝。玫瑰状纤维素合酶复合体由 Malcolm Brown 等于1970至1980年代经冰冻断裂看到；第一个植物 *CESA* 基因于1996年在棉花中被鉴定（Pear 及同事）；对沿微管行进的 CESA 复合体的活体成像（Paredez、Somerville 与 Ehrhardt，2006）把细胞骨架与壁的建筑直接联系起来。
:::

## 小结与展望

::: summary
- 植物细胞有**细胞壁**、**质体**与**中央液泡**，并通过**胞间连丝**连通其细胞质。它们也有线粒体，不停地呼吸。
- **初生壁**是纤维素微纤丝嵌在半纤维素（双子叶植物为木葡聚糖）与果胶的基质中；**次生壁**更厚且常木质化。纤维素由 CESA 复合体在质膜上纺出，受皮层微管引导，每条链约每秒10个葡萄糖残基。
- 膨压（0.3–1 MPa）给圆柱壁施加环向应力 $Pr/t$ 与轴向应力 $Pr/2t$，达几十兆帕。横向的微纤丝使细胞伸长而非膨大；扩张蛋白与酸化松动壁以供生长。
- 质体——叶绿体、黄化质体、淀粉体、有色体、白色体——源自前质体，除光合作用外还合成脂肪酸、氨基酸、色素与激素前体。
- 酸性的液泡储存离子、糖、酸与防御化合物，消化细胞组分，占据细胞大部分体积，只留下约1 µm 厚的细胞质层。
- **共质体**（经胞间连丝相连的细胞质）与**质外体**（壁与死输导管）是运输的两条路径；胞间连丝的尺寸排阻极限受胼胝质调控。
- 细胞类型：薄壁组织、厚角组织、厚壁组织（纤维、石细胞）、木质部（管胞、导管分子；死细胞）与韧皮部（筛管分子伴以伴胞；活细胞）。它们构成贯穿每个器官的**皮**、**维管**与**基本**三个组织系统。
:::

有了细胞与其组织在手，[[plant-biology/plant-form]] 转向分生组织如何产生并排列它们，以及根、茎、叶的解剖。

::: exercise 环向应力 {level=1 check="50"}
一个圆柱形薄壁组织细胞半径25 µm，壁厚0.25 µm，膨压0.5 MPa。其壁的环向应力是多少 MPa？
::: solution
$\sigma_\text{hoop} = Pr/t = 0.5\times25/0.25 = 50$ MPa（[[#eq-hoop]]）。
:::
:::

::: exercise 平衡时的膨压 {level=1 check="0.74"}
一个细胞液为0.40 osmol kg⁻¹ 的细胞在25 °C 下与0.10 osmol kg⁻¹ 的溶液达成平衡。用 van 't Hoff 关系估算其膨压，以 MPa 计，保留两位小数。
::: solution
$P = \Delta c\,RT = 300\ \text{mol m}^{-3}\times8.314\times298.15 = 7.44\times10^5$ Pa $= 0.74$ MPa。
:::
:::

::: exercise 更满的液泡 {level=1 check="0.76"}
一个半径30 µm 的圆柱形细胞，液泡占据其体积的95 %。其侧壁贴衬的细胞质层有多厚，以 µm 计，保留两位小数？
::: solution
$d = r(1 - \sqrt{0.95}) = 30\times(1 - 0.97468) = 0.76$ µm。
:::
:::

::: exercise 指认部件 {level=1}
对下列各项，说出细胞类型或组织，并说明它属于皮、维管还是基本组织系统：(a) 芹菜茎中在它尚生长时支撑它的“筋”；(b) 梨里的砂粒；(c) 叶片下表面的孔及其周围的细胞；(d) 栎树木材中两端开放的管道；(e) 马铃薯块茎中储存淀粉的细胞。
::: solution
(a) 厚角组织（基本组织系统；芹菜的维管束旁也伴有靠近表皮的厚角组织束）。(b) 石细胞，厚壁组织的一种（基本）。(c) 气孔，由保卫细胞构成（皮）。(d) 导管，由导管分子构成（维管——木质部）。(e) 含淀粉体的贮藏薄壁组织（基本）。
:::

::: exercise 编织一条链 {level=2 check="14.7"}
一个纤维素合酶复合体以350 nm min⁻¹ 移动。合成一条聚合度为10,000的纤维素链需要多少分钟？保留一位小数。
::: solution
链长 $= 10000\times0.515 = 5150$ nm；时间 $= 5150/350 = 14.7$ 分钟。
:::

::: exercise 膨大的根 {level=2}
*Arabidopsis* 幼苗种在含 oryzalin（解聚微管）的培养基上。一天后，根伸长区的细胞停止伸长并径向膨大，根尖看上去成了球形。(a) 用 [[#prop-hoop]] 与纤维素的沉积解释这一结果。(b) 预言一个 CESA 复合体存在但无法受引导地沿微管移动的突变体的表型，并解释它的细胞为何仍能量产出纤维素。
::: solution
(a) 微管引导 CESA 复合体，使新微纤丝横向铺放。没有微管时，复合体仍合成纤维素，但取向随机。壁在力学上变得各向同性，于是较大的环向应力（$Pr/t$，轴向应力的两倍）占上风，细胞周向扩张超过轴向：径向膨大。
(b) 这样的突变体仍会合成纤维素（催化活性完好），但取向无序，导致类似而或许较轻的膨大表型与较短的器官。这类突变体已被找到——例如把 CESA 复合体连接到微管的蛋白质（纤维素合酶互作蛋白1，CSI1）的突变体——它们各向异性生长减弱而纤维素合成仍在。
:::
:::

::: exercise 解读 GFP 实验 {level=2}
在 [[#ex-sel]] 的实验中，GFP 在库叶中能在细胞间移动，在源叶中则不能。GFP 与一个23 kDa 蛋白的融合蛋白（共50 kDa）在库叶中也能移动。(a) 这对库组织胞间连丝的尺寸排阻极限说明了什么？(b) 设想植物在叶成熟时降低该极限的两种机制。(c) 一片经韧皮部输出糖的成熟叶，胞间连丝更受限为何可能有利？
::: solution
(a) 库组织的极限至少得有50 kDa——远高于教科书上的1 kDa——至少对这些靠扩散移动、无定向信号的蛋白质如此。极限由组织的发育状态设定。
(b) 在胞间连丝颈部周围沉积胼胝质可收窄胞质鞘；叶成熟过程中，简单胞间连丝被通道更窄的分支胞间连丝取代。（胞质鞘蛋白的改变与膜附着的紧密程度也被认为有关。）
(c) 源叶必须在其韧皮部维持高浓度蔗糖并阻止其漏回叶肉；限制韧皮部及其他细胞的共质体联系可让叶建立彼此分隔的区室，同时也限制了病毒以及在特定域中控制细胞身份的蛋白质与 RNA 的扩散。

::: exercise 球与圆柱 {level=2}
(a) 一个球形细胞与一个圆柱形细胞半径、壁厚与膨压相同。哪个的最大壁应力更大？大几倍？(b) 一个半径3 µm、壁厚0.1 µm 的类酵母球形细胞持有1 MPa 膨压；把它的壁应力与 [[#ex-hoop]] 比较，并解释小细胞为何可以壁薄。
::: solution
(a) 球中每个方向都承担 $Pr/2t$；圆柱中环向应力为 $Pr/t$，是它的两倍。同样尺寸下圆柱的应力更高。
(b) $\sigma = Pr/2t = 1\times3/(2\times0.1) = 15$ MPa，尽管膨压更高，却只有那株较大植物细胞60 MPa 环向应力的四分之一。应力随 $r/t$ 标度：小细胞能以薄壁持高压，大细胞则需要按比例更厚的壁。
:::

::: exercise 质壁分离 {level=3}
洋葱表皮细胞被装于一列蔗糖溶液中。在0.30 mol L⁻¹ 蔗糖及以上，原生质体收缩离开细胞壁（质壁分离）；在0.25 mol L⁻¹ 及以下则不然。(a) 阈值对细胞液的渗透压告诉你什么？为什么初始质壁分离是有用的测量点？(b) 估算20 °C 下细胞液的渗透压。(c) 在质壁分离的细胞中，膜索（Hechtian strands）仍在许多位点连着壁。可能是什么在锚定它们？这种锚定对遭遇干旱的细胞有何意义？
::: solution
(a) 初始质壁分离时，原生质体恰充满壁而不压壁，故膨压为零；此时外部溶液的渗透压等于细胞液的渗透压。在膨压为零处测量，剔除了未知的压力项。
(b) 把阈值取为约0.275 mol L⁻¹ 蔗糖（介于两浓度之间），$\Pi = cRT = 275\times8.314\times293.15 = 6.7\times10^5$ Pa ≈ 0.67 MPa（由系列间隔带来约 ±0.06 MPa 的不确定度）。
(c) 这些膜索附着于质膜与壁相连之处，很可能在胞间连丝处，也在膜蛋白（例如阿拉伯半乳聚糖蛋白或壁相关激酶）结合壁多糖之处。让膜与壁保持联系，或可帮助细胞在水分回归时不失水撕裂地重新扩张，保住胞间连丝的联系，并让细胞感知自己已与壁脱离接触——一种水分胁迫的信号。
:::

::: exercise 死管与活管 {level=3}
用你对膜与流动的了解解释：木质部输导管是死的、筛管分子是活的，各自为何是优势。你的回答应考虑 (a) 如果木质部导管充满细胞质、并在每个细胞两端被质膜横断，水流会怎样；(b) 韧皮部的流动由什么驱动，为什么那需要活细胞；(c) 筛管分子为何仍然失去细胞核与液泡。
::: solution
(a) 水穿膜必须经水通道蛋白或脂双层，与顺开放管道流动相比阻力巨大；而带有细胞骨架与细胞器的细胞质会大大增加黏性阻力。中空的死输导管，端壁穿孔或阙如，给张力驱动的蒸腾流水流提供了尽可能低的阻力；其木质化的壁还能抵抗张力下的扁塌，而这对于活的、膨压充盈的细胞的壁并无必要。
(b) 韧皮部流动由渗透产生的压力差驱动：糖在源处被主动装载进筛管分子，在库处被移除。主动装载需要膜与能量——质膜上的质子泵与蔗糖–H⁺ 同向转运体——而把糖留在输导管内需要完整、选择透过性的膜。所以输导管必须是活的。
(c) 细胞器与大液泡若留在腔内会阻碍流动；失去它们，筛管分子在保住质膜的同时逼近木质部的开放管几何。它所需的蛋白质与 ATP 由伴胞经胞间连丝供给——输导细胞与代谢细胞之间的分工。
:::
