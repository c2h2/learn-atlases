1700年萌发的一棵橡树，至今仍每年长出新的叶、新的根、新的木材与新的花。哺乳动物没有可比拟的事：其体型规划在胚胎中就绪，器官长到固定大小，成年后停止生长。植物一生都在生长，并不断建造新的器官。一株植物尽可以把大部分叶子让毛虫或霜冻夺去，然后重新长出；一侧被遮阴的植物会把新枝长到有光的地方，朝光生长。这种开放式的、模块化的生活方式之所以可能，是因为植物在每条枝与根的尖端、以及在加粗的茎与根周围的圆环里，保留着一团团胚胎性组织——**分生组织**。

本章讲分生组织如何造出植物体。我们从模块化生长的逻辑讲起，然后看茎尖与根尖分生组织、其中央的干细胞龛，以及使茎尖分生组织保持合适大小的反馈环。初生生长通向叶、茎、根的解剖，次生生长通向木材与树皮。两条定量线索贯穿全章：**Lockhart 方程**，它告诉我们给定膨压与细胞壁性质，细胞能以多快的速度生长；以及生长中的根与树干的运动学记账。细胞与组织本身在 [[plant-biology/plant-cells-tissues]] 中已经引入。

## 模块化、无限生长

种子植物的枝是单位的重复。每个单位称为**枝叶单元**（phytomer），由着生叶的**节**；**叶**本身；叶与茎夹角（叶腋）里的**腋芽**；以及其下方茎的**节间**组成。茎尖分生组织一个接一个地添加枝叶单元；每个腋芽含一个分生组织，它可以长成一枝由更多枝叶单元构成的侧枝，或长成一朵花。根系同样由反复的分枝建成，只是没有节与叶。

::: definition 分生组织 {#def-meristem}
**分生组织**是未分化、正在分裂的细胞区域，持续不断地为植物体产生新细胞，其中央维持着一小群缓慢分裂的**干细胞**，其子代要么留为干细胞，要么被推开而分化。枝与根尖端的**顶端分生组织**产生**初生**植物体：使植物伸长，并造出其叶、枝与侧根。**侧生分生组织**——**维管形成层**与**木栓形成层**（phellogen）——在茎与根内形成圆柱，产生使其加粗的**次生**植物体。禾本科节间与叶基部的**居间分生组织**让这些器官从下方向上伸长。
:::

由分生组织无限延续的生长是**无限生长**；器官建成即告停止的生长是**有限生长**。叶与花是有限器官：叶长到固定形状便停。枝与根是无限的——直到茎尖分生组织变成花，而花把它消耗掉。两者的平衡正是植物调控株型的方式，受基因与环境的控制（如 [[plant-biology/plant-responses]] 所述）。

::: warning 钉进树干的钉子
在地面上方1.5 m 处钉进树干的一枚钉子，几十年后仍在地面上方1.5 m——树长高时不会把它带上去。茎只在茎尖正下方那几厘米内伸长，即幼节间正在扩张之处；节间一旦成熟，就再不伸长。树干长高靠顶端添加新节间，加粗靠外侧添加木材。认为侧枝会随树长高而上升，出于同一种误解：侧枝看似上升，只是因为树干在下方加粗、而枝本身在生长。
:::

## 茎尖分生组织

茎尖分生组织（SAM）是一枚由细胞质浓密的小细胞构成的圆顶，直径因种而异，通常为50–250 µm，位于每条枝的尖端，被它自己造出的幼叶所包围。对其组织方式有两种互相交叠的描述。

- **层次。**在被子植物中，最外的一两层细胞只作**垂周**分裂（新壁垂直于表面），因而保持为彼此分明的薄层：最外的 **L1** 产生表皮，其下的 **L2** 产生皮下组织，并在花中产生配子。再下面的 **L3**，即原体，各向分裂，形成内部组织。（这种原套-原体结构由 Alexander Schmidt 于1924年描述。）由于各层在克隆上彼此分离，发生在某一层的一个突变可以产生周缘嵌合体，例如叶缘发白的植株，其 L2 缺乏叶绿素。
- **分区。**顶端是**中央区**，含缓慢分裂的干细胞；周围的**周边区**含分裂较快的细胞，叶原基自其中产生；下方的**肋区**产生茎的内部组织。

### 反馈环使分生组织维持平衡

如果干细胞分裂太慢，分生组织会被耗尽；太快，它又会生长没完。对 *Arabidopsis thaliana* 的遗传分析揭示了一个使其稳定的负反馈环。同源域转录因子 **WUSCHEL**（WUS）在干细胞下方一小群细胞——**组织中心**——中表达；WUS 蛋白经胞间连丝上行进入干细胞，把它们维持为干细胞。除其他作用外，它诱导 *CLAVATA3*（*CLV3*）的表达。CLV3 是一个被分泌的小肽（加工后12–13个氨基酸），向下扩散到组织中心，结合受体激酶——CLAVATA1 及相关受体——抑制 *WUS* 的转录。

::: definition WUS–CLV3 反馈环 {#def-wus-clv}
在茎尖分生组织中，组织中心产生的 **WUS** 促进干细胞身份与 **CLV3** 的表达；**CLV3** 肽经 CLAVATA1 及相关受体传信，抑制 *WUS*。干细胞数目增多使 CLV3 输出升高，从而压低 WUS，限制干细胞群体；减少则反向而行。这个环是负反馈，使干细胞数目大致恒定。
:::

突变体证实了这一逻辑。在 *clv3* 或 *clv1* 突变体中，对 *WUS* 的抑制失效，WUS 表达扩张，分生组织变得巨大——有时扁平成一道嵴，长出宽阔扇形化的茎与带多余器官的花。在 *wus* 突变体中，干细胞得不到维持：分生组织先长几片叶，随后终止。*clv3 wus* 双突变体表型似 *wus*，若 CLV3 经由抑制 WUS 起作用，这正是预期（WUS 为上位）。这一核心环由 Ulrike Schoof、Thomas Laux 及同事以及 Ulrike Brand、Rüdiger Simon 及同事于2000年确立；其外围网络后来纳入了其他受体、细胞分裂素信号（促进 WUS）与更多肽类，但反馈仍是其中心。

第二个要求是分生组织细胞保持未分化。I 类 **KNOX** 同源异型盒基因，如 *Arabidopsis* 的 *SHOOT MERISTEMLESS* 与玉米的 *KNOTTED1*，在整个分生组织中表达，而在叶原基形成处关闭；失去它们，分生组织取消；在叶中异位表达它们，则长出带裂片的、似分生组织的突起。KNOX 蛋白的部分作用机制是使分生组织中赤霉素保持低位、细胞分裂素保持高位（[[plant-biology/plant-hormones]]）。

::: application 分生组织基因与更大的番茄
栽培番茄的心室（子室）远比其野生祖先的两室为多，果实因此大得多。负有部分责任的两个突变，位于 *fasciated* 与 *locule number* 位点，影响的是 *CLV3* 与 *WUS* 的番茄同源基因：它们削弱反馈环，扩大花分生组织，产生更多心皮。Daniel Rodríguez-Leal、Zachary Lippman 及同事（2017）用 CRISPR–Cas9 在番茄 *CLV3* 启动子中制造了几十种不同的缺失，产生果实大小与心室数的一组梯度——这一工作示范了编辑调控序列可以为育种者生成数量变异。玉米同一通路中的突变（*fasciated ear2*，一个受体）增加果穗的行数。
:::

### 叶的形成

叶以**原基**的形式从周边区产生——原基是细胞的隆起，其位置由激素生长素的局部最大值设定。每个新原基把生长素从其周围抽走，下一个便尽可能远离已经形成的那些——这是叶的规则螺旋排列与对生排列背后的自组织机制，包括 [[diversity-of-life/land-plants]] 中分析过的黄金角叶序。原基很快获得极性：由 III 类 HD-ZIP 转录因子规定的**近轴**（adaxial）上侧，以及由 KANADI 与 YABBY 基因和小型 RNA 规定的**远轴**（abaxial）下侧。扁平的叶片在两者的边界处长出；失去其中一种身份的突变体长出辐射对称、针状的叶。

典型 C3 真双子叶植物如菜豆的成熟叶是一片薄板，仅几百 µm 厚：

- **上表皮**，角质层厚，气孔极少或没有；
- 一到两层柱状的**栅栏组织**细胞，满载叶绿体，吸收大部分光；
- **海绵组织**，不规则的细胞隔以大的**细胞间隙**，经气孔与外界相通——这就是 CO₂ 扩散至叶绿体的体内大气；
- **下表皮**，拥有大部分气孔；
- **叶脉**，即维管束，木质部朝上、韧皮部朝下，分支成极细的网络，几乎每个叶肉细胞离最近的叶脉不过几个细胞远。

禾本科及其他单子叶植物的叶通常具平行脉；真双子叶植物的叶具分支的网状脉。C4 植物把叶肉围绕叶脉排成环——即 [[plant-biology/c4-and-cam]] 的花环结构。

## 茎

幼茎中，节间伸长，把节彼此分开；维管组织由分生组织留下的原形成层索分化而来。在真双子叶植物与松柏类中，维管束排成一圈，每个束内木质部在内、韧皮部在外；圈内的基本组织是**髓**，圈外是**皮层**。在玉米等单子叶植物中，维管束散生于基本组织。真双子叶植物维管束的木质部与韧皮部之间，有一层保持分生能力的细胞，即**束中形成层**，日后可与束间的细胞连通，形成连续的维管形成层。

腋芽为**外起源**——由节上的表层发生——且常长期休眠。枝尖抑制其下腋芽的生长，这一现象称**顶端优势**；切去枝尖，其下的芽便萌发，这就是修剪使灌木更密的缘由。顶端优势涉及来自枝尖的生长素、来自根的细胞分裂素、独脚金内酯以及腋芽的糖供应；在 [[plant-biology/plant-hormones]] 中讨论。

## 根

### 根尖分生组织

根尖分生组织位于**根冠**正后方。根冠是一顶帽状细胞套，在根穿过土壤时保护分生组织、分泌润滑黏液、感受重力，并不断从内部更新、向外脱落。分生组织的中央是**静止中心**，一群极少分裂的细胞——Frederick Clowes 于1956年用放射性胸苷饲喂根、发现中央一个区域不掺入而得名。静止中心被各组织的干细胞（原始细胞）环绕，并使它们保持在干细胞状态：在 *Arabidopsis* 中，用激光杀死一个静止中心细胞，其旁的原始细胞便分化（Claudia van den Berg、Ben Scheres 及同事，1997）。

*Arabidopsis* 是便利的模式，因为其根简单：每个组织都只一层——从外向内为表皮、一层皮层、一层内皮层、中柱鞘与维管柱——每列细胞都可在显微镜下数清。两条转录因子通路规定这一干细胞龛：**PLETHORA** 蛋白，以静止中心为中心形成受生长素影响的梯度；以及 **SHORT-ROOT**–**SCARECROW** 通路——维管柱产生的 SHORT-ROOT 向外移动一个细胞，与 SCARECROW 一起规定内皮层与静止中心。

### 生长区域

根尖后方，生长中的根呈现一个区域序列，根尖前移时每个细胞都依次穿过：

::: definition 根的发育区域 {#def-root-zones}
- **根冠**，覆盖分生组织。
- **分生区**（分裂区）：细胞反复分裂，生长却很少。
- **伸长区**：细胞停止分裂，沿根轴扩张，通常十倍或更多，靠液泡吸水。根的长度增加几乎全部发生在这一段几毫米之内。
- **成熟区**（分化区）：细胞已达最终长度并分化；表皮细胞长出**根毛**，木质部成熟，内皮层形成**凯氏带**。
:::

由于各区与移动根尖的距离固定，根的生长部分处于稳态：细胞流其中而格局不变。这让我们能用简单记账把细胞产生与根的生长联系起来。

::: proposition 稳态生长器官中的细胞通量 {#prop-flux}
考虑某器官（根或禾本科叶）中的一列细胞，其生长速率恒定，分裂与扩张的格局稳定。以根尖为参照，细胞在分生组织产生，并以成熟长度 $\ell$ 离开生长区。若器官以速度 $v$（单位时间的长度）伸长，则每列细胞产生细胞的速率为

$$
F = \frac{v}{\ell}.
$$ {#eq-flux}

等价地，相邻两个细胞离开生长区的时间为 $\ell/v$。
:::

::: proof
稳态下，每列细胞在生长区内的数目恒定，故细胞离开该区（进入成熟区）的速率等于其产生的速率。每个离开的细胞给该列的成熟部分增加长度 $\ell$。由于生长区本身长度不变，器官的全部伸长就是成熟细胞的添加：$v = F\ell$。
:::

假设是生长平稳，且细胞在成熟后不增不减。这一结论之有力，在于无须追踪单个细胞：从伸长速率与成熟细胞长度的测量，就得到细胞产生速率；再由分生组织的细胞计数，得到平均细胞周期时间。

::: example 玉米根尖的细胞产生 {#ex-root-flux}
玉米主根以3.0 mm h⁻¹ 伸长，其成熟皮层细胞长200 µm。（a）每小时每列皮层产生多少个细胞？（b）若该列的分生组织部分含120个细胞，全部异步分裂、细胞周期同为 $T$，估算 $T$。
::: solution
（a）由 [[#eq-flux]]，$F = v/\ell = 3000\ \text{µm h}^{-1}/200\ \text{µm} = 15$ 个（每列、每小时）。

（b）$N$ 个细胞每 $T$ 小时各分裂一次的异步群体，其增长速率为每小时 $N\ln 2/T$ 个细胞（每个细胞贡献相对速率 $\ln2/T$）。稳态下分生组织大小恒定，故其产生的细胞必须全部离开：$N\ln2/T = F$。于是

$$
T = \frac{N\ln 2}{F} = \frac{120\times0.693}{15} = 5.5\ \text{h}.
$$

这一估计依赖可以检验的假设：分生组织的每个细胞都在分裂；没有分裂新增细胞列（玉米皮层中的平周分裂会新增）；生长平稳。当运动学估计与直接测得的细胞周期时间——例如用核苷酸类似物标记——不一致时，这些假设中有一个失效了——这正是该方法用来认识分生组织的方式。
:::
:::

### 根的解剖与侧根

在成熟区，根从外向内显示：**表皮**，具根毛，表面大大增加；薄壁组织构成的**皮层**，常有气腔；**内皮层**，其凯氏带阻断进入维管柱的质外体途径（[[plant-biology/mineral-nutrition]]）；**中柱鞘**，一层或多层保留分裂能力的细胞；以及**中柱**（维管柱），木质部束（真双子叶植物常呈星形排列）与韧皮部束相间。

侧根**内起源**，发生在母根内部深处：正对木质部极的几个中柱鞘细胞受生长素引发，分裂形成原基，穿过内皮层、皮层与表皮向外顶出。对照枝的分支：枝从表面形成的腋芽长出。植物的根系由反复的侧生分枝形成（禾本科还有茎节上发生的根），其形态——许多真双子叶植物占优势的**主根**，禾本科许多大小相似之根构成的**须根**系——由土壤水分与养分塑造：硝酸盐与磷酸盐所在之处，根就增殖。

::: quiz
一位研究者想在 *Arabidopsis* 幼苗上找到最幼嫩的根毛。她应该去哪里找？
- [ ] 根冠，那里细胞最幼嫩
- [ ] 分生区，那里细胞在分裂
- [ ] 伸长区的中部
- [x] 成熟区的开端，紧接伸长区之后
::: solution
根毛在表皮细胞停止伸长之后长出，位于成熟区的开端。越靠后的细胞越老（根尖已前移），所以离根尖最近的根毛最幼嫩。根毛从不发生在根冠、分生区或伸长区——若从仍在伸长的细胞长出，根毛会被拖过土壤而扯断。
:::
:::

## 生长：膨压对抗细胞壁

伸长区的细胞以多快的速度生长，由什么决定？细胞扩张靠吸水，吸水要求细胞内有水势梯度，而细胞壁必须屈服以容其扩张。James Lockhart（1965）把两者合并为一个简单模型。

::: proposition Lockhart 方程 {#prop-lockhart}
设生长细胞的壁仅在膨压 $P$ 超过**屈服阈值** $Y$ 时作不可逆延展，且延展速率与超出量成正比，比例常数 $\phi$ 称**壁扩张性**。若吸水不限速，体积的相对增长速率为

$$
\frac{1}{V}\frac{\dd V}{\dd t} = \begin{cases} \phi\,(P - Y), & P > Y,\\ 0, & P \le Y. \end{cases}
$$ {#eq-lockhart}

若吸水也受限，相对水力导度为 $L$、渗透动力为 $\Delta\pi$，则稳态生长下膨压落在 $Y$ 与 $\Delta\pi$ 之间，且

$$
\frac{1}{V}\frac{\dd V}{\dd t} = \frac{\phi L}{\phi + L}\,(\Delta\pi - Y).
$$ {#eq-lockhart-full}
:::

::: proof
第一个方程就是模型的定义：壁的行为像宾汉塑性体——屈服应力以下不流动，超出部分的流率与超出量成正比。（因为壁应力正比于 $P$，见 [[plant-biology/plant-cells-tissues#prop-hoop]]，应力的阈值就成了压强的阈值。）对第二个方程，水以相对速率 $L(\Delta\pi - P)$ 进入——外侧压强为零时，内外水势差即 $\Delta\pi - P$。稳态生长下，壁所容许的体积增加必等于吸入的水：$\phi(P - Y) = L(\Delta\pi - P)$。解得 $P = (\phi Y + L\Delta\pi)/(\phi + L)$，回代得 $\phi(P - Y) = \phi L(\Delta\pi - Y)/(\phi + L)$。
:::

该模型是现象学的：$\phi$ 与 $Y$ 不是分子层面的量，而是概括了决定壁蠕变难易的许多过程——扩张蛋白活性、果胶化学、壁的合成。植物通过改变它们来控制生长。生长素使壁酸化并抬高 $\phi$；在伸长区末端停止生长的细胞，并非因为膨压下降（膨压通常不变），而是因为壁变硬、$\phi$ 趋近于零。生长对阈值附近的膨压极其敏感，这就是轻度水分胁迫在影响光合作用之前就停止生长的原因。

::: example 生长速率与倍增时间 {#ex-lockhart}
生长中的下胚轴里一个细胞的膨压0.60 MPa，屈服阈值0.35 MPa，扩张性0.25 MPa⁻¹ h⁻¹。（a）求其相对生长速率与体积倍增所需时间。（b）干旱使膨压降到0.50 MPa，壁性质不变。生长速率下降的比例是多少？
::: solution
（a）由 [[#eq-lockhart]]，$\frac{1}{V}\frac{\dd V}{\dd t} = 0.25\times(0.60 - 0.35) = 0.0625$ h⁻¹。相对速率恒定时体积指数增长，$V = V_0e^{0.0625t}$，倍增于 $\ln 2/0.0625 = 11.1$ h。

（b）现在速率为 $0.25\times(0.50 - 0.35) = 0.0375$ h⁻¹；膨压只降17 %，速率却下降 $1 - 0.0375/0.0625 = 40\,\%$。因为只有超出 $Y$ 的部分驱动生长，阈值附近膨压的小变化便有大影响。
:::
:::

## 次生生长：木材与树皮

大多数真双子叶的乔木与灌木，以及全部松柏类，年复一年地加粗茎与根。单子叶植物一般不加粗：棕榈在长高之前靠初生生长达到全部树干直径，其树干不会以同样的方式随年龄加粗。

::: definition 维管形成层与次生组织 {#def-cambium}
**维管形成层**是木质部与韧皮部之间的圆柱状侧生分生组织。其细长的**纺锤状原始细胞**作**平周**分裂（新壁平行于表面），向内产生**次生木质部**（木材），向外产生**次生韧皮部**；其短小的**射线原始细胞**产生**射线**——辐射排列的薄壁组织薄片，横向运输水、糖与信号。**木栓形成层**（phellogen）最初在皮层、后在次生韧皮部中形成，向外产生**木栓**（phellem）——壁厚栓质化、已死之细胞——向内产生少量**栓内层**（phelloderm）。木栓、木栓形成层与栓内层合称**周皮**，取代表皮。**树皮**是维管形成层以外的一切：次生韧皮部与周皮。
:::

形成层造出的木质部远多于韧皮部，两者命运迥异。木质部累积：每年的木材加在上一年的外侧，老木材留在原地。韧皮部被压毁：较老的次生韧皮部被向外挤向树皮，随树干增宽而拉伸，最终随外树皮脱落。这就是树干几乎全是木材、只有最年轻最内层的韧皮部在输导、以及把树干周围一整圈树皮剥掉（**环剥**）会杀死树的原因：切口切断韧皮部，根断糖挨饿，数月或数年后死去——尽管木材还会继续向上输水一段时间。

四季分明的气候中，形成层春夏活动、冬季休眠。生长季早期产生**早材**，输导分子宽而壁薄；后期产生**晚材**，窄而壁厚。一年的致密晚材与翌年开阔的早材之间的陡变，形成**年轮**。树干增粗后，内部木材停止输导，常为树脂、树胶或单宁所填充而成为**心材**，色深而耐腐；外侧有功能的**边材**输送水分，并把淀粉贮于其活的射线与轴向薄壁组织。

一圈年轮代表多少木材？同宽的年轮，树干的越大，所含木材越多，因为它摊在更长的周长上。

::: example 年轮宽度与基部断面积增量 {#ex-bai}
某树树干（树皮以内）半径25 cm，最新年轮宽3 mm。求**基部断面积增量**——那年添加的木材横截面积——并与同样年轮宽度、半径5 cm 的幼树的增量比较。
::: solution
年轮是半径 $R - w$ 与 $R$ 之间的圆环，面积为 $\pi\left(R^2 - (R - w)^2\right)$。

对 $R = 25$ cm、$w = 0.3$ cm：$\pi(625 - 610.09) = 46.8$ cm²。对 $R = 5$ cm：$\pi(25 - 22.09) = 9.14$ cm²。

同样的年轮宽度，大树干代表的木材是幼树的五倍（比值接近 $25/5$，因为 $w \ll R$ 时面积约为 $2\pi R w$）。所以年轮随年龄变窄的树未必生长变慢；即使产木量恒定，年轮变窄也是预期。林学家问树木生长是快是慢时，因此分析的是基部断面积增量而非年轮宽度——并且还要校正年龄与大小的影响。
:::
:::

::: application 树轮：气候的记录
因为年轮宽度与木材密度取决于每个生长季的条件，年轮序列就是带年份的气候记录。**树轮年代学**——通过比对树、木材与亚化石木中宽窄轮的格局来断代——由天文学家 Andrew Ellicott Douglass 自二十世纪初在亚利桑那创立。借助重叠序列的交叉定年，利用中欧河床砾石与泥炭中保存的栎与松，年表已上推约12,000年；树轮还用来校准放射性碳测年。依年轮计数知的最老龄个体，是加利福尼亚的大盆地刺果松（*Pinus longaeva*），超过4,800岁（截至2026年）。年轮宽度与密度序列支撑着过去温度与干旱的重建，木材逐年记录的化学信息则记载着火山喷发与污染。
:::

## 树木的株型

树的分支并非任意。Leonardo da Vinci 在其笔记中记到：树在每个高度上，所有分支的总粗度等于树干的粗度。用现代语言表述：

::: proposition Leonardo 法则（经验规律） {#prop-leonardo}
直径 $d$ 的分支分成直径 $d_1, d_2, \dots, d_n$ 的子枝时，总横截面积近似守恒：

$$
d^{\,2} \approx d_1^{\,2} + d_2^{\,2} + \dots + d_n^{\,2}.
$$ {#eq-leonardo}

这是一条**观察到的规律**，不是定律：在许多树种中测得 $d^\Delta = \sum d_i^\Delta$ 的指数聚集在 $\Delta = 2$ 附近，但大致在1.8到2.3之间。
:::

有人提出过几种解释，彼此并不互斥。**管茎模型**（Shinozaki 及同事，1964）假定每个单位的叶面积由一段固定横截面、一路贯通到地面的输导木质部服务，故每次分枝处总面积守恒。力学模型假定分支以恒定安全裕度抵抗风载而建造，并证明这同样给出接近2的指数（Christophe Eloy，2011）。无论原因为何，这条法则表明树木的水力与力学设计受着约束——这一主题在 [[plant-biology/water-transport]] 中继续。

::: example 运用 Leonardo 法则 {#ex-leonardo}
直径10 cm 的一根分支分成两根相等的子枝。（a）按 Leonardo 法则，其直径应为多少？（b）另一根10 cm 粗的分支分成8 cm 与6 cm 的两根子枝。它守法则吗？
::: solution
（a）$10^2 = 2d_1^2$，故 $d_1 = 10/\sqrt2 = 7.07$ cm。

（b）$8^2 + 6^2 = 64 + 36 = 100 = 10^2$：严格守法则。注意两根7.07 cm 的子枝各有母枝一半的面积，但二者合计的周长（$2\times7.07\pi$）大于母枝的（$10\pi$）——即使木材面积守恒，分枝也增大了形成层与树皮运作所及的表面。
:::
:::

::: history
植物由少数持续存在的胚胎区域生长的思想，可追溯到 Caspar Friedrich Wolff（1759），他把生长的枝尖描述为未分化的。Carl Nägeli 于1858年为分生组织命名（*Meristem*，源自希腊语 *merizein*，分裂）；Johannes von Hanstein 于1868年提出枝尖的不同层分别产生表皮、皮层与中柱（组织原学说）；Alexander Schmidt（1924）提出了枝尖的原套-原体描述。Frederick Clowes 于1956年发现静止中心。James Lockhart 的方程（1965）提供了细胞生长的第一个定量模型，1970与1980年代借压力探针——可直接测量单个细胞的膨压——加以检验。在 *Arabidopsis* 中，*clavata* 突变体由 Steven Clark、Elliot Meyerowitz 及同事自1993年起表征，*WUSCHEL* 由 Thomas Laux 及同事于1996年鉴定，WUS–CLV3 反馈环于2000年确立。树轮年代学的开创者 A. E. Douglass 于1937年在图森建立了树轮研究实验室。
:::

## 小结

::: summary
- 植物靠**分生组织**添加模块化单位（**枝叶单元**：节、叶、腋芽、节间）终生生长。顶端分生组织造初生植物体；维管形成层与木栓形成层造次生植物体。
- 茎尖分生组织有克隆层次（L1、L2、L3）与分区（中央、周边、肋）。其干细胞由负反馈维持平衡：组织中心的 WUS 促进干细胞与 *CLV3*；CLV3 肽抑制 *WUS*。KNOX 基因使分生组织保持未分化。
- 叶原基在生长素最大值处形成，获得近轴-远轴极性，发育为表皮、栅栏与海绵组织及叶脉构成的叶片。
- 根尖分生组织有一个维持周围干细胞的静止中心；根冠之后依次是分裂、伸长与成熟区域。侧根起源于中柱鞘。稳态生长下，每列的细胞产生速率 $F = v/\ell$。
- **Lockhart 方程** $\frac{1}{V}\frac{dV}{dt} = \phi(P - Y)$ 把生长与超出屈服阈值的膨压联系起来；植物主要通过改变壁扩张性 $\phi$ 调节生长。
- 维管形成层向内造木材、向外造韧皮部；木材以年轮累积，韧皮部被压毁并随树皮脱落。基部断面积增量 $\pi(R^2 - (R-w)^2) \approx 2\pi Rw$ 在年轮宽度恒定时随半径增大。
- 分枝近似守恒横截面积（Leonardo 法则，一条经验规律）。
:::

整株植物的生长取决于水到达正在扩张的细胞与叶片。水如何经土壤、根、木质部与叶运输，糖如何经韧皮部回流，是 [[plant-biology/water-transport]] 的主题。

一个细胞的膨压0.70 MPa，屈服阈值0.40 MPa，壁扩张性0.30 MPa⁻¹ h⁻¹。其相对生长速率是多少（以 h⁻¹ 计）？
::: solution
$\phi(P - Y) = 0.30\times0.30 = 0.09$ h⁻¹（体积倍增时间 $\ln 2/0.09 = 7.7$ h）。

::: solution

::: exercise 树皮里有什么？ {level=1}
一棵20年生的栎树树干，从外表面向中心切去，列出由外向内切经的组织，并指出哪些是活的。
::: solution
外树皮（老周皮与死次生韧皮部；死）→ 木栓（phellem；死）→ 木栓形成层（活）→ 栓内层（活）→ 次生韧皮部，其中只有最内最年轻的一层输导（筛管存活，伴胞与薄壁细胞相伴）→ 维管形成层（活）→ 边材（输导管与纤维死；射线与轴向薄壁组织活）→ 心材（死）→ 最中心是初生木质部与髓的残余。注意“树皮”指维管形成层以外的一切。
:::
:::

::: exercise 分生组织突变体 {level=2}
（a）预测一株在整个枝尖过量表达 *CLV3* 的 *Arabidopsis* 植株的表型。（b）解释 *clv3 wus* 双突变体为何形似 *wus*，这告诉我们这两个基因的作用次序是什么。（c）*clv3* 突变体的花有四枚或更多心皮而非两枚。分生组织的缺陷为何影响心皮数？
::: solution
（a）过量的 CLV3 在整个区域抑制 *WUS*；没有 WUS，干细胞得不到维持，分生组织提前终止——*wus* 样表型（Brand 及同事，2000年确实观察到）。
（b）双突变体中，CLV3 的缺失本应扩张 WUS，可是没有可扩张的 WUS；表型就是失去 WUS 的表型。WUS 为上位：在这条通路中它作用于 CLV3 下游，CLV3 对分生组织的作用依赖 WUS。
（c）花分生组织使用同一个 WUS–CLV3 环。*clv3* 的花分生组织扩大、干细胞更多，因而在分生组织终止之前，有更多细胞供最内轮——心皮——形成；于是多出心皮。（花分生组织本身的终止需要心皮身份基因 *AGAMOUS* 抑制 *WUS*；见 [[plant-biology/plant-reproduction]]。）
:::
:::

::: exercise 环剥 {level=2}
一项果园实验中，初夏时从一棵苹果树的树干上剥去1 cm 宽的一圈树皮，直达木材部。（a）预测当季树上果实与其下根系接下来一年的命运。（b）树的水分供应为何还在继续？（c）果农有时在枝上做一个极窄的环剥，几周内即愈合。他们为何要这样做？
::: solution
（a）韧皮部被切断，叶的糖无法到达根。环剥上方糖积累，当季树上的果实往往更大更甜。断糖的根耗尽储备，终于死亡；根一失效，吸水随之失效，全树死亡，通常在一年到数年之内。
（b）水分经木质部（边材）输导，它在维管形成层以内，剥皮动不到它。
（c）窄而暂时的环剥把糖截留给那根枝的果与叶几个星期——提高坐果或果个——随后形成层以新韧皮部架桥弥合伤口，枝便存活。
:::
:::

::: exercise 膨压还是壁？ {level=2}
用压力探针测量豌豆上胚轴中生长中与不生长的细胞。生长区的细胞膨压0.55 MPa；区上方刚停止生长的细胞膨压0.58 MPa。（a）用 Lockhart 方程，这说明细胞停止生长是怎么回事？（b）如何检验你的解释？（c）生长素处理在20分钟内使生长区的生长速率提高50 %，而膨压不变。Lockhart 方程中哪个参数变了？可能的分子机制是什么？
::: solution
（a）膨压没有下降——反而略升——所以生长停止是因为壁变了：扩张性 $\phi$ 降到近于零，或屈服阈值 $Y$ 升到了 $P$ 之上，或两者兼有。生长的停止由壁硬化控制。
（b）直接测量壁的性质：例如蠕变试验（离体壁在恒定负载下、酸性与中性 pH、有无外加扩张蛋白时的延伸），或对完整组织施加受控的膨压变化（用渗透剂）并测量生长响应——由斜率得 $\phi$，由截距得 $Y$。
（c）$P$ 不变而 $\phi(P - Y)$ 提高了一半，所以 $\phi$ 增大了（或 $Y$ 下降）。生长素激活质膜 H⁺-ATP 酶，使壁酸化并激活扩张蛋白：酸生长（[[plant-biology/plant-hormones]]）。
:::
:::

::: exercise 生长的收支 {level=3}
用 [[#eq-lockhart-full]]：某细胞 $\phi = 0.3$ MPa⁻¹ h⁻¹，$Y = 0.3$ MPa，渗透动力 $\Delta\pi = 0.9$ MPa，相对水力导度 $L$。（a）求 $L = 0.3$ MPa⁻¹ h⁻¹ 与 $L = 3$ MPa⁻¹ h⁻¹ 时的稳态膨压与生长速率。（b）每种情形下限制生长的是壁还是水供应？（c）为何多数测量表明，供水良好组织中的生长细胞受壁限制？
::: solution
（a）$P = (\phi Y + L\Delta\pi)/(\phi + L)$。$L = 0.3$ 时：$P = (0.09 + 0.27)/0.6 = 0.60$ MPa；速率 $= \phi(P - Y) = 0.3\times0.30 = 0.090$ h⁻¹。$L = 3$ 时：$P = (0.09 + 2.7)/3.3 = 0.845$ MPa；速率 $= 0.3\times0.545 = 0.164$ h⁻¹。
（b）$\phi$ 与 $L$ 相等时两者共同限制：膨压坐在 $Y$ 与 $\Delta\pi$ 的正中。$L \gg \phi$ 时，膨压趋近 $\Delta\pi$，速率趋近 $\phi(\Delta\pi - Y) = 0.18$ h⁻¹：壁限制。（$L \ll \phi$ 时速率趋近 $L(\Delta\pi - Y)$，受水限制。）
（c）生长细胞的膨压通常与渗透含量相似的非生长细胞的值接近，即接近 $\Delta\pi$，这意味着 $L \gg \phi$。供应生长所需的水势梯度很小，通常为百分之几兆帕。然而干旱之下，水供应可以成为限制。
:::

::: exercise 单子叶的树干 {level=3}
一棵20 m 高的椰子树，树干的直径沿其大部分长度约30 cm；同样高度的栎树，基部树干可达60 cm 粗，向上渐细。（a）用分生组织解释这一差别。（b）用 Leonardo 法则与管茎模型解释栎树树干为何上细、棕榈为何不然。（c）棕榈面临栎树没有的什么问题？它如何应对？
::: solution
（a）棕榈没有维管形成层；其茎靠初生加厚分生组织在茎尖下方达到几乎全部粗度，此后只伸长不再加粗。栎树靠次生生长持续加粗，每年添一圈，所以最老的部分——基部——最粗。
（b）栎树反复分枝；按 Leonardo 法则，每次分枝守恒横截面积，故树干必须承载其上方全部分支的面积之和，随分支离去，其面积向上递减。管茎模型的解读是每片叶都需要自己一路到地的木质部通路。棕榈不分枝：顶端一丛冠叶由截面积恒定的树干供输。
（c）棕榈不能添加新木质部：那一段树干形成时造出的维管束，必须为棕榈可能长达几十年的全部生命输水，其损伤（栓塞、伤害）无法靠新木材修复。棕榈依赖许多冗余、散生的维管束、长命的活细胞与抗栓塞的木质部；其树干的机械加固也靠维管束中的纤维而非每年的木材。
:::
