植物没有神经系统，也没有血液，其各部分却步调一致。顶芽抑制其下的侧芽；感知到日照变短的叶片告诉茎尖开花；一旦根系缺水，叶片在几分钟内便关闭气孔；一个成熟的苹果会让邻近的果实也成熟。协调这些响应的信息由少数几种小分子携带，即**植物激素**（phytohormones），在纳摩尔浓度甚至更低即起作用，由多种组织合成，经扩散、专用转运体以及木质部与韧皮部运输，并由开启基因表达网络的受体感知。

本章按发现顺序介绍五种“经典”激素——**生长素**、**细胞分裂素**、**赤霉素**、**脱落酸**与**乙烯**——并更简要地介绍油菜素类固醇、茉莉酸类、水杨酸与独脚金内酯。对每一种，我们都问它如何合成、如何移动、如何被感知、有何作用。在机制层面浮现出一种惊人的统一性：若干激素受体不是激活一条通路，而是触发阻遏蛋白的降解。两条定量线索是生长素运输的化学——它源于质膜两侧的 pH 差——以及把激素浓度转化为效应的剂量-响应关系。受体与第二信使的一般逻辑见 [[cell-biology/cell-signalling]]；激素调节的生长过程已在 [[plant-biology/plant-form]] 中描述。

::: definition 植物激素 {#def-hormone}
**植物激素**是一类内源信号小分子，在极低浓度（典型为10⁻¹¹–10⁻⁶ mol L⁻¹）下结合特定受体，调节生长、发育或环境响应。与动物激素不同，植物激素一般不由专门的腺体制造；许多细胞都能合成它们，它们可以作用于合成它们的细胞、邻近细胞，或经运输后在远处起作用。
:::

::: warning 一种激素一个效应
人们很容易给每种激素安排单一的工作——“生长素使细胞伸长”“乙烯使果实成熟”“ABA 关闭气孔”。实际上每种激素几乎影响发育的每一个方面，且在不同组织或不同浓度下常朝相反方向（同一浓度促进茎的伸长却抑制根的伸长），多数响应又由数种激素共同控制。激素的作用取决于响应细胞的能力——它们表达哪些受体、转录因子与伙伴通路——不亚于取决于激素本身。请把激素看作由上下文解读的信号，而不是结果固定的开关。
:::

## 生长素

### 发现

第一种植物激素是跟踪一株弯曲的幼苗发现的。在 *The Power of Movement in Plants*（1880）中，Charles Darwin 与其子 Francis Darwin 报告：金丝雀虉草（*Phalaris canariensis*）的胚芽鞘只有顶端受光时才向单侧光弯曲，用小帽罩住顶端便不弯曲，而弯曲本身发生在顶端以下很远处。他们断定“某种影响由上部传到了下部”。Peter Boysen-Jensen（1913）证明这种影响能穿过明胶块却不能穿过云母片；Árpád Paál（1919）证明把切下的顶端偏心放到去顶的胚芽鞘上，黑暗中会引起弯曲，弯离顶端所在的一侧。Frits Went（1926–1928）把燕麦（*Avena*）胚芽鞘顶端放在琼脂块上以收集该物质，并证明把琼脂块偏心放到去顶胚芽鞘上，弯曲程度与块中物质量成正比——即 *Avena* 弯曲试验，第一个植物激素的定量生物测定。Fritz Kögl、Arie Haagen-Smit 与 Hanni Erxleben 于1934年从尿与真菌中鉴定出与**吲哚-3-乙酸**（IAA）活性相同的物质；后来证实 IAA 是植物的主要天然生长素。

### 合成与运输

IAA 主要由色氨酸经两步途径合成：TAA1 把色氨酸转化为吲哚-3-丙酮酸，YUCCA 黄素单加氧酶再把后者转化为 IAA。它主要在幼嫩生长的组织中合成——茎尖、幼叶、发育中的种子——根尖也有。从这里它以两种方式移动：经韧皮部快速而无方向地移动，以及经细胞到细胞缓慢而有方向地移动，即**极性生长素运输**，速率约5–20 mm h⁻¹，远快于扩散且方向固定——在茎中自茎尖向基部（基部定向），在根中于中柱内朝根尖。

极性运输的机制由一种弱酸的化学性质决定。IAA 的羧基 p$K_\mathrm{a}$ 约为4.8。在酸性的质外体（pH 约5.5）中，相当一部分呈不带电的 IAAH，能自由扩散穿过膜（也与质子一道被 AUX1/LAX 同向转运体摄入）。在细胞质（pH 约7）中，几乎全部以阴离子 IAA⁻ 形式存在，不能经扩散跨膜，于是被困住——除非有专一的输出载体把它放出去。

::: proposition 弱酸捕获 {#prop-trapping}
酸解离常数为 $K_\mathrm{a}$ 的弱酸 HA 分布于膜两侧的两个隔室，外侧 pH$_o$、内侧 pH$_i$。若只有不带电的 HA 能透过，且系统达到平衡，则内外总浓度之比为

$$
\frac{[\mathrm{HA}]_i + [\mathrm{A^-}]_i}{[\mathrm{HA}]_o + [\mathrm{A^-}]_o} = \frac{1 + 10^{\,\mathrm{pH}_i - \mathrm{p}K_\mathrm{a}}}{1 + 10^{\,\mathrm{pH}_o - \mathrm{p}K_\mathrm{a}}}.
$$ {#eq-trapping}
:::

::: proof
平衡时，能透过膜的不带电形式在两侧浓度相同：$[\mathrm{HA}]_i = [\mathrm{HA}]_o$。每一侧的亨德森-哈塞尔巴尔赫方程给出 $[\mathrm{A^-}] = [\mathrm{HA}]\,10^{\mathrm{pH} - \mathrm{p}K_\mathrm{a}}$（[[biochemistry/water-and-bonds]]）。于是两侧的总量都是 $[\mathrm{HA}](1 + 10^{\mathrm{pH}-\mathrm{p}K_\mathrm{a}})$，公因子 $[\mathrm{HA}]$ 在比值中相消。
:::

::: example 细胞将生长素富集多强？ {#ex-trapping}
取 IAA 的 p$K_\mathrm{a} = 4.8$，质外体 pH 5.5，细胞质 pH 7.0。（a）质外体 IAA 中有多大比例不带电？（b）若只有 IAAH 能跨膜，细胞会达到怎样的富集比？（c）对酸化到 pH 5.0的质外体重做（b）。
::: solution
（a）不带电分数 $= 1/(1 + 10^{5.5 - 4.8}) = 1/(1 + 5.01) = 0.17$。

（b）由 [[#eq-trapping]]，$(1 + 10^{2.2})/(1 + 10^{0.7}) = 159.5/6.01 = 26.5$。细胞把 IAA 富集约27倍，而没有任何泵直接作用于 IAA 本身——做功的是质膜 H⁺-ATP 酶维持的质子梯度。

（c）$159.5/(1 + 10^{0.2}) = 159.5/2.58 = 62$。进一步酸化细胞壁使富集增加一倍以上；而生长素本身促进细胞壁酸化，于是生长素吸收中存在正反馈。
:::
:::

:::

捕获解释了生长素如何进入细胞；它的*方向*则取决于它如何出去。因为 IAA⁻ 不能经扩散离开，它通过输出载体离开，主要是 **PIN-FORMED**（PIN）蛋白——它们定位于细胞的一面，例如茎维管组织细胞的下方（基部）一端。生长素于是从整个表面进入每个细胞，却只从一端出去，便沿着细胞列朝那个方向移动。这种极性生长素运输的**化学渗透模型**由 Philip Rubery 与 Alan Sheldrake 以及 John Raven 于1974–1975年提出，早于任何转运载体被发现；PIN 蛋白于1990年代末在 *Arabidopsis* 中被鉴定，名字来自 *pin1* 突变体那形似别针、不开花的花序——该突变体不能形成定位花器官所需的生长素最大值，因而开不出花。ABCB 转运体也输出生长素，但没有极性定位。

::: example 对抗扩散的极性运输 {#ex-transport}
（a）以10 mm h⁻¹ 的极性运输，生长素沿茎下行30 cm 需要多久？（b）同样时间内，若仅靠扩散（扩散系数 $5\times10^{-10}$ m² s⁻¹），它通常能扩散多远？
::: solution
（a）$300\ \text{mm}/10\ \text{mm h}^{-1} = 30$ h。

（b）在30 h $= 108{,}000$ s 内，一维扩散的均方根距离为 $\sqrt{2Dt} = \sqrt{2\times5\times10^{-10}\times108{,}000} = 1.0\times10^{-2}$ m，约1 cm——比极性运输少三十倍，而且没有方向。在分生组织的尺度上（100 µm，扩散几秒即可跨越）扩散没有问题；而在茎的长度上则需要有方向的主动过程。
:::
:::

PIN 蛋白可通过内吞与再循环的循环在几分钟内从细胞的一面移到另一面，其极性由磷酸化设定（激酶 PINOID 与磷酸酶 PP2A 拮抗地起作用）。这种可塑性使植物能够重定向生长素流：在向重力性与向光性中（[[plant-biology/plant-responses]]），PIN 蛋白重新定位到器官一侧，生长素在该侧积累，差异生长使器官弯曲。生长素还对自身运输反馈调节：运输生长素的细胞上调 PIN 并使其极性化，于是流被汇聚成狭窄的通道——这一机制（管道化，Tsvi Sachs 于1960与1970年代提出）被认为决定了叶片叶脉的格局，并使维管组织在受伤后重新连接。

### 感知与响应

细胞如何感知生长素？主要受体由两条线在2005年发现：Nihal Dharmasiri、Mark Estelle 及同事，以及 Stefan Kepinski 与 Ottoline Leyser。受体是 **TIR1**（TRANSPORT INHIBITOR RESPONSE 1）及其近亲 AFB 蛋白，即名为 SCF^TIR1^ 的泛素连接酶复合体的 F-box 亚基。晶体结构（Xu Tan、Ning Zheng 及同事，2007）显示生长素坐落在 TIR1 的口袋里，充当“分子胶”，增大其对第二个蛋白的亲和力。

::: definition 生长素信号模块 {#def-auxin-signalling}
无生长素时，**Aux/IAA** 蛋白结合到生长素响应基因启动子上的 **AUXIN RESPONSE FACTOR**（ARF）转录因子，并借助共阻遏物 TOPLESS 抑制它们。生长素结合 **TIR1/AFB** 并稳定其与 Aux/IAA 蛋白的结合；随后 SCF^TIR1^ 复合体使 Aux/IAA 泛素化，Aux/IAA 被蛋白酶体摧毁。释放的 ARF 激活（部分 ARF 则抑制）转录。TIR1/AFB 与 Aux/IAA 蛋白一道构成**共受体**：生长素结合的是这一对。
:::

*Arabidopsis* 有6个 TIR1/AFB 蛋白、29个 Aux/IAA 与23个 ARF，不同组合（对生长素的亲和力不同）在不同组织中表达——这是生长素作用如此多样的部分原因。有些生长素响应快得等不及基因表达：在根中，生长素在数秒内抑制生长；在茎中，它在数分钟内激活质膜 H⁺-ATP 酶。这些快速响应涉及 TIR1/AFB 信号的非转录分支与细胞表面 TRANSMEMBRANE KINASE（TMK）蛋白，是当前活跃的研究领域。

### 生长素做什么

**酸生长假说**（Achim Hager 及同事，以及 Robert Cleland 与 David Rayle 于1970–1971年前后提出）解释生长素如何促进茎的细胞伸长：生长素激活质膜 H⁺-ATP 酶（部分经由 SAUR 蛋白抑制原本会使泵失活的磷酸酶），酸化细胞壁，激活扩张蛋白并松弛细胞壁，于是膨压使细胞壁更快地伸展——用 Lockhart 的语言，生长素提高了扩展性 $\phi$（[[plant-biology/plant-form#prop-lockhart]]）。除伸长外，生长素还：

- 通过 PIN 介导的运输所产生的生长素最大值，在茎尖定位叶与花；
- 维持顶端优势：顶端来源的生长素经由细胞分裂素与独脚金内酯间接抑制腋芽萌发；
- 决定维管系统与胚胎轴的格局；
- 启动侧根与不定根——这正是合成生长素作为生根粉出售的原因；
- 介导向性（[[plant-biology/plant-responses]]）与果实的生长。

## 细胞分裂素

1955年，Carlos Miller、Folke Skoog 及同事从高压灭菌的鲱鱼精液 DNA 中分离出一种使培养中的烟草髓细胞分裂的物质，并将其命名为**激肽**（kinetin，6-呋喃甲基氨基嘌呤）——它是 DNA 的降解产物，并非天然激素。第一个天然细胞分裂素**玉米素**由 David Letham 于1963年从未成熟玉米籽粒中分离。细胞分裂素是腺嘌呤衍生物，在 N⁶ 氮上带有侧链；由异戊烯基转移酶合成（根癌农杆菌 *Agrobacterium tumefaciens* 的致瘤质粒上也带有这一酶，使其宿主组织增殖）。

Skoog 与 Miller（1957）作出了奠定植物组织培养的发现：生长素与细胞分裂素的*比值*决定一团未分化的烟草愈伤组织走向何方。生长素/细胞分裂素比值高使其形成根；比值低形成芽；中间比值则愈伤组织持续增殖。只要激素处理顺序得当，单个细胞就能再生出完整植株——这是植物微繁殖与转基因植物生产的基础。

细胞分裂素由内质网与质膜上的**组氨酸激酶受体**（*Arabidopsis* 中为 AHK2、AHK3 与 CRE1/AHK4）感知，磷酸基团经组氨酸磷酸转移蛋白中继到细胞核内的**响应调节蛋白**——一套**双组分系统**，遗传自质体的细菌祖先或一般而言的细菌信号系统。B 型响应调节蛋白是激活细胞分裂素响应基因（包括 A 型响应调节蛋白，后者抑制该通路构成负反馈环）的转录因子。细胞分裂素促进茎分生组织的细胞分裂（包括激活 *WUSCHEL*；[[plant-biology/plant-form#def-wus-clv]]），促进腋芽萌发，延缓叶片衰老；在根中则与生长素拮抗，限制根分生组织的大小。它们还参与调节豆科的结瘤。

## 赤霉素

日本稻农早就知道一种叫 *bakanae*（恶苗病，意为“徒长的傻瓜苗”）的病害：感病植株长得异常高大细弱，且不能结实。Eiichi Kurosawa 于1926年证明，该病病原菌（现称 *Fusarium fujikuroi*，当时称 *Gibberella fujikuroi*）的除菌滤液能重现症状；Teijiro Yabuta 与 Yusuke Sumiki 于1930年代分离出活性物质并将其命名为赤霉素。到1950年代，人们已清楚植物自身能合成赤霉素。赤霉素（GA）是二萜类化合物；已鉴定出130多种，其中只有少数如 GA₁ 与 GA₄ 有生物活性，其余是前体与失活形式。

GA 促进茎伸长、种子萌发、某些植物的成花转变以及花与果实的发育。其信号模块再次体现了“摧毁阻遏物”的主题。

::: definition 赤霉素-DELLA 模块 {#def-della}
**DELLA** 蛋白（以其保守序列 Asp-Glu-Leu-Leu-Ala 命名）是核内生长阻遏物，结合并抑制转录因子，包括 PHYTOCHROME-INTERACTING FACTORS。赤霉素结合可溶性受体 **GID1**（GIBBERELLIN INSENSITIVE DWARF1；Miyako Ueguchi-Tanaka、Makoto Matsuoka 及同事，2005），后者随即结合 DELLA 蛋白；GA-GID1-DELLA 复合体被 SCF 泛素连接酶识别（*Arabidopsis* 中由 F-box 蛋白 SLY1，水稻中为 GID2），DELLA 随即被降解。生长得以释放。
:::

这套逻辑解释了遗传学。不能合成 GA 的突变体（如 *Arabidopsis* 的 *ga1*）是矮生的，喷施 GA 可以救回。DELLA 蛋白改变、不能结合 GID1 的突变体也是矮生的，但 GA 救不回它们，且遗传上是显性的，因为稳定的突变 DELLA 即使在正常 DELLA 存在时也阻遏生长。这样的显性功能获得突变 *gai*（“GA 不敏感”）由 Nicholas Harberd 及同事在 *Arabidopsis* 中表征；而当 Jinrong Peng、Harberd 及同事（1999）克隆小麦的 *Reduced height*（*Rht*）基因时，发现它们编码带有同类突变的 DELLA 蛋白。

::: application 绿色革命
1960年代，小麦与水稻的新品种改变了亚洲与拉丁美洲的粮食生产。其关键性状是短而硬的秸秆。传统高秆品种施氮肥后长得更高并倒伏，损失籽粒；新的半矮秆品种可以被大量施肥，把额外的生长投入籽粒。Norman Borlaug 在墨西哥育成半矮秆小麦，于1970年获诺贝尔和平奖。两种矮化性状最终都被证明是赤霉素突变：小麦的 *Rht-B1b* 与 *Rht-D1b* 等位基因编码 GA 不敏感的 DELLA 蛋白（Peng 及同事，1999），水稻的 *semi-dwarf1*（*sd1*）等位基因则是 GA 合成酶 GA 20-氧化酶基因的失活突变（多个课题组，2002）。赤霉素也被直接使用：喷在无核葡萄上可拉长果穗梗、增大果粒；在酿造中，它加快大麦发芽以制麦芽。
:::

在萌发的谷粒中，胚产生的 GA 扩散到**糊粉层**——包裹粉胚乳的一层活组织——并诱导其分泌 α-淀粉酶等水解酶，为幼苗消化胚乳的淀粉与蛋白质——这是研究激素作用的经典系统（[[plant-biology/plant-reproduction]]）。

## 脱落酸

脱落酸（ABA）在1960年代初被发现了两次：Frederick Addicott 课题组作为促进棉铃脱落的“脱落素 II”，以及 Philip Wareing 课题组作为诱导悬铃木芽休眠的“休眠素”；1965年证明二者相同。它的名字反映了一个后来被证明很次要的脱落作用。ABA 是一种由质体内类胡萝卜素裂解产生的倍半萜；限速步骤由9-*cis*-环氧类胡萝卜素双加氧酶（NCED）催化，并被水分亏缺强烈诱导，因此干旱后一小时内叶片 ABA 水平可上升多倍。

ABA 是胁迫与休眠的激素。它关闭气孔，诱导保护细胞免于脱水的蛋白质与溶质的基因表达，维持种子休眠，并在种子成熟期间防止萌发（ABA 缺陷或不敏感的突变体表现出**胎生**：种子在穗上或果内萌发）。

其受体直到2009年才由两条线发现：Sang-Youl Park、Sean Cutler 及同事，以及 Yue Ma、Erwin Grill 及同事。受体是可溶的 **PYR/PYL/RCAR** 蛋白。通路再次靠移除抑制物工作。无 ABA 时，**A 支型 2C 蛋白磷酸酶**（PP2C，如 ABI1）使蛋白激酶 **SnRK2** 家族保持去磷酸化而失活。结合 PYR/PYL 的 ABA 产生一个结合面，与 PP2C 结合并抑制它；SnRK2 自磷酸化而激活；它们磷酸化离子通道、转录因子与酶。在保卫细胞中，SnRK2 的 OPEN STOMATA 1（OST1）磷酸化并开启阴离子通道 SLAC1；阴离子外流使膜去极化，K⁺ 经外向通道流出，水随之而去，气孔关闭（[[plant-biology/water-transport]]）。PP2C 的 *abi1-1* 突变使其不能结合受体，产生显性的 ABA 不敏植株，其气孔不关闭，且容易萎蔫。

## 乙烯

乙烯（C₂H₄）是一种气体。1901年，圣彼得堡的学生 Dimitry Neljubov 发现，实验室里煤气灯漏气使豌豆幼苗长得又短又粗、横倒生长，并鉴定出乙烯是照明煤气中的活性成分。在乙烯中黑暗萌发的幼苗表现出**三重反应**：下胚轴短而粗、顶端弯钩过度，以及（在 *Arabidopsis* 中）根短。Richard Gane（1934）证明成熟果实自身产生乙烯。乙烯由甲硫氨酸经 S-腺苷甲硫氨酸与**1-氨基环丙烷-1-甲酸**（ACC）合成，先后由 ACC 合酶与 ACC 氧化酶催化（该途径由 Douglas Adams 与 Shang Fa Yang 于1979年阐明）。ACC 合酶是主要的控制点，受创伤、淹水、生长素与成熟诱导。

乙烯受体是又一个意外。*Arabidopsis* 有五个（ETR1、ETR2、ERS1、ERS2、EIN4），与细菌组氨酸激酶同源，位于内质网膜上，以铜辅基结合乙烯。ETR1 是第一个被鉴定的植物激素受体（Caren Chang、Elliot Meyerowitz 及同事，1993）。这些受体是**负调控因子**：无乙烯时，它们激活激酶 CTR1，后者磷酸化并抑制蛋白 EIN2。乙烯把受体关掉；CTR1 失活；EIN2 的 C 端被切下并进入细胞核，稳定转录因子 EIN3 与 EIL1——这两个因子本被持续降解。遗传学与这一逻辑严丝合缝：*CTR1* 缺失导致组成型三重反应，*EIN2* 缺失导致完全不敏感，而同时缺失多个受体也导致组成型响应——因为正是受体的活性使通路保持关闭。

::: quiz
在 *Arabidopsis* 中，哪个突变体在黑暗且**没有**乙烯时会显示三重反应？
- [ ] *ein2* 功能缺失突变体
- [ ] 受体不能结合乙烯的显性 *etr1-1* 突变体
- [x] *ctr1* 功能缺失突变体
- [ ] 缺失 ACC 氧化酶的突变体
::: solution
CTR1 是负调控因子，由未被占据的受体保持活性；没有它，EIN2 不受抑制，无论有无乙烯通路都是开着的：组成型三重响应。*ein2* 与 *etr1-1* 植株不敏感（*etr1-1* 是显性的，因为即使有乙烯存在，其受体仍停留在信号的“断开”状态）。不能合成乙烯的植株对外源乙烯响应正常，但在没有乙烯时无响应。
:::
:::

乙烯协调**跃变型**果实（番茄、香蕉、苹果、鳄梨）的**果实成熟**——这类果实在成熟开始时出现呼吸与乙烯自催化合成的爆发；非跃变型果实（葡萄、柑橘、草莓）的成熟不依赖它。它促进叶、花与果实的脱落、衰老，促进淹水根中通气组织的形成，以及淹水水稻节间的伸长。一颗烂苹果确实坏一筐：它放出乙烯，触发邻居的成熟与乙烯产生。果实贮藏库通过低氧、低温与清除乙烯来控制成熟；气体1-甲基环丙烯不可逆地结合并封闭受体，用于使苹果保持坚脆数月。

::: example 果实贮藏库中的乙烯 {#ex-ethylene}
一个1,000 m³ 的密闭冷藏库存放10吨开始成熟的苹果，每千克以50 µL h⁻¹ 的速率产生乙烯。许多果实的成熟响应在乙烯浓度约0.1 µL L⁻¹（体积百万分之0.1）时被触发。（a）忽略泄漏与果实所占体积，库内空气的乙烯浓度上升多快？（b）若库内起初没有乙烯，多久达到阈值？
::: solution
（a）产生量：$10{,}000\ \text{kg}\times50\ \text{µL kg}^{-1}\,\text{h}^{-1} = 5.0\times10^{5}$ µL h⁻¹ $= 0.50$ L h⁻¹。库内存有 $10^{6}$ L 空气，因此浓度上升 $0.50/10^{6} = 5\times10^{-7}$，即**每小时0.5 µL L⁻¹**。

（b）$0.1/0.5 = 0.2$ h——约12分钟。少数成熟的果实会很快把整库的浓度抬到阈值以上，而乙烯在跃变型果实中诱导自身合成，响应随之蔓延。这就是商业贮藏库持续清除乙烯（通风、催化氧化或高锰酸钾洗涤）、保持低氧并把温度压近0 °C 以抑制其合成，或用1-甲基环丙烯封闭其感知的原因。
:::
:::

## 其他激素简述

- **油菜素类固醇**是植物甾体，1979年首次从甘蓝型油菜（*Brassica napus*）花粉中分离，促进细胞扩大与分裂。它们在细胞表面被富亮氨酸重复受体激酶 BRI1 感知，它使激酶 BIN2 失活，从而释放转录因子 BZR1 与 BES1。不能合成或不能感知它们的突变体是深绿色的矮秆。
- **茉莉酸类**来自脂肪酸亚麻酸，介导对咀嚼式口器昆虫与死营养型真菌的防御，并参与花粉发育。活性形式茉莉酸-异亮氨酸由 F-box 蛋白 COI1 与 JAZ 阻遏蛋白构成的共受体感知，JAZ 蛋白被摧毁——该模块与生长素的几乎完全平行。
- **水杨酸**介导对活体营养型病原体的防御与系统获得性抗性（[[plant-biology/plant-responses]]）；其感知涉及 NPR 蛋白。
- **独脚金内酯**源于类胡萝卜素，抑制分枝；从根中渗出时，吸引丛枝菌根真菌并触发寄生性列当的萌发（[[plant-biology/mineral-nutrition]]）。其受体 α/β-水解酶 D14 在传递信号的同时水解激素，并与 F-box 蛋白 MAX2 一起促进 SMXL 阻遏物的摧毁——又是阻遏物的降解。
- **肽类激素**，如 CLV3（[[plant-biology/plant-form#def-wus-clv]]）、系统素与调节结瘤的 CLE 肽，通过受体激酶起作用。

::: intuition 为何要摧毁阻遏物？
生长素、赤霉素、茉莉酸与独脚金内酯都以靶向阻遏物进行泛素介导的降解来传递信号，乙烯与 ABA 则以关掉负调控因子来传递。演化为何青睐这种迂回的设计？一个答案是速度与灵敏：半衰期短的阻遏物能被迅速清除，而响应基因已经待命，转录因子结合在旁静候。另一个是稳健性：“默认开着、除非主动关闭”的系统在某些情形下会安全失效，而阻遏可以由反馈维持（这些通路大多在被激活时诱导新阻遏物的合成，激素浓度下降后响应随即关闭）。还有模块性：真核生物共有的 SCF 泛素连接酶机制提供了把小分子与蛋白质周转相连的现成办法，被若干激素通路各自独立地招募。
:::

## 剂量与响应

细胞如何把激素浓度翻译成响应？对于以解离常数 $K_\mathrm{d}$ 结合受体的激素，受体占据率随浓度呈双曲线上升；下游的放大与协同常使响应更陡并相对于占据率移动（[[cell-biology/cell-signalling]]）。因此剂量-响应数据通常用经验的 Hill 函数描述。

::: proposition 剂量-响应曲线（经验式） {#prop-dose}
浓度为 $c$ 的激素所产生的响应 $R$ 通常描述为

$$
R = R_\text{min} + \frac{R_\text{max} - R_\text{min}}{1 + (\mathrm{EC_{50}}/c)^n},
$$ {#eq-dose}

其中 $\mathrm{EC_{50}}$ 是产生最大效应一半时的浓度，$n$（Hill 系数）是陡度。在对数浓度轴上曲线呈 S 形；响应从其范围的10 %升到90 %所需的浓度倍数为 $81^{1/n}$。这是拟合描述而非机制：$\mathrm{EC_{50}}$ 不必等于受体的 $K_\mathrm{d}$，$n$ 也不必等于任何结合位点数。
:::

::: example 组织中的激素浓度 {#ex-dose}
一个伸长的豌豆节间每克鲜重含20 ng IAA。（a）换算成近似的摩尔浓度（IAA 为175.2 g mol⁻¹；把1 g 组织当作1 mL）。（b）该组织对 IAA 的某响应有 $\mathrm{EC_{50}} = 300$ nmol L⁻¹、$n = 1$。组织的平均浓度产生最大响应的多大比例？（c）平均值为何可能误导？
::: solution
（a）$20\times10^{-9}\ \text{g}/175.2\ \text{g mol}^{-1} = 1.14\times10^{-10}$ mol 于1 mL 中，故约 $1.1\times10^{-7}$ mol L⁻¹，即114 nmol L⁻¹。

（b）由 [[#eq-dose]]，$R_\text{min} = 0$，$R/R_\text{max} = 1/(1 + 300/114) = 0.28$——约28 %。

（c）平均掩盖了梯度：生长素被富集于特定细胞与隔室（由 [[#ex-trapping]] 的捕获，细胞质浓度可比质外体高数十倍），且提取得到的 IAA 中可能有大量是结合态或被储存的。荧光生物传感器（如 DII-VENUS，一个与荧光蛋白融合的 Aux/IAA 结构域，在生长素被感知之处即被降解）显示，相邻细胞间的生长素水平可相差数倍。
:::
:::

一个经典观察是根对生长素远比茎敏感。在 Kenneth Thimann（1937）的剂量-响应曲线中，根伸长在极低的 IAA 浓度（约10⁻¹¹–10⁻¹⁰ mol L⁻¹）下被促进，超过则被抑制；而茎伸长被促进直到约10⁻⁵ mol L⁻¹，再高才被抑制。因此同一浓度可能既促进茎生长又抑制根生长——这一事实是向性解释的核心。

::: history
Darwin 与 Darwin（1880）由胚芽鞘顶端推知有一种可传递的影响；Boysen-Jensen（1913）、Paál（1919）与 Went（1926–1928）证明它是一种可扩散的物质；Kögl、Haagen-Smit 与 Erxleben（1934）鉴定了 IAA。Kurosawa（1926）把恶苗病追溯到一种真菌分泌物，即赤霉素的来源。Neljubov（1901）发现了乙烯的作用，Gane（1934）发现果实产生乙烯。Miller、Skoog 及同事（1955）发现了激肽，Skoog 与 Miller（1957）发现了控制器官发生的生长素-细胞分裂素比值。ABA 于1963–1965年被鉴定。受体时代始于1993年的 ETR1；生长素受体 TIR1（2005）、赤霉素受体 GID1（2005）、细胞分裂素受体 CRE1/AHK4（2001）、油菜素类固醇受体 BRI1（1997年鉴定，2005年确证为受体）、茉莉酸共受体 COI1–JAZ（2007）与 ABA 受体 PYR/PYL（2009）相继被发现，主要经由 *Arabidopsis* 的遗传筛选。
:::

## 小结

::: summary
- 植物激素是在极低浓度下起作用的信号小分子，由多种组织合成，在局部或远处起作用；其效应取决于上下文与相互作用。
- **生长素**（IAA）在幼嫩组织中由色氨酸合成，经极性运输移动：弱酸捕获（富集比 $(1 + 10^{\mathrm{pH}_i - \mathrm{p}K_a})/(1 + 10^{\mathrm{pH}_o - \mathrm{p}K_a}) \approx 27$，pH 5.5/7.0下）加上极性定位的 PIN 输出载体。TIR1/AFB-Aux/IAA 共受体触发 Aux/IAA 的摧毁，释放 ARF。生长素驱动酸生长、叶序、维管格局、侧根、顶端优势与向性。
- **细胞分裂素**（腺嘌呤衍生物）通过双组分组氨酸激酶通路起作用；与生长素的比值控制根与芽的再生；它们促进茎分生组织活性并延缓衰老。
- **赤霉素**结合 GID1，后者把 DELLA 阻遏物靶向降解；DELLA 与 GA 合成突变造就了绿色革命的半矮秆小麦与水稻。
- **ABA** 在干旱中升高并维持种子休眠；PYR/PYL 受体抑制 PP2C，激活 SnRK2 激酶，开启 SLAC1 阴离子通道以关闭气孔。
- **乙烯**（源自 ACC）经由内质网膜受体起作用，这些受体作为负调控因子，经 CTR1、EIN2 与 EIN3 传递；它引起三重反应、果实成熟与脱落。
- 油菜素类固醇、茉莉酸类、水杨酸、独脚金内酯与肽类补齐了整套；阻遏物的降解是反复出现的信号逻辑。
- 剂量-响应曲线在对数浓度下呈 S 形（$\mathrm{EC_{50}}$、Hill 系数）；根对生长素远比茎敏感。
:::

激素是植物内部的语言；光、重力、温度与侵袭才是植物必须响应的对象。[[plant-biology/plant-responses]] 描述环境如何被感知，以及激素如何把它转化为生长与发育。

::: exercise 赤霉素的遗传学 {level=2}
预测下列每个 *Arabidopsis* 基因型的高度，以及喷施 GA 能否恢复正常高度，并说明理由：（a）*ga1*（不能合成 GA）；（b）*gai*，显性，DELLA 蛋白缺失结合 GID1 的结构域；（c）缺失四种主要 DELLA 蛋白的四重功能缺失突变体；（d）*ga1* 与四重 DELLA 突变体结合。
::: solution
（a）矮生；喷 GA 可救回，GA 结合 GID1 并摧毁 DELLA。
（b）矮生；不能救回，因为突变 DELLA 不能被 GA-GID1 识别而不被降解；由于稳定的阻遏物即使在正常拷贝存在时也起作用，故为显性。
（c）高大（比野生型更高、细弱、早花）；对 GA 不敏感，因为 GA 的靶标已不存在，生长不受阻遏。
（d）与（c）一样高大：DELLA 缺失对上 GA 缺陷是上位性的，表明 GA 在该通路中的唯一作用是移除 DELLA。（此类双重及高阶突变体是去阻遏模型的关键证据。）
:::
:::

::: exercise 组织培养 {level=2}
烟草髓外植体被放在激素浓度不同（mg L⁻¹）的培养基上：（i）IAA 2.0、kinetin 0.02；（ii）IAA 2.0、kinetin 0.2；（iii）IAA 0.02、kinetin 1.0；（iv）不加激素。预测四周后各形成什么，并说明这些结果如何导出一个植物发育的一般原理。
::: solution
（i）生长素/细胞分裂素比值高（100）：形成根。（ii）比值10：未分化的愈伤组织增殖。（iii）比值0.02：形成芽。（iv）几乎不生长：髓细胞需要两种激素才能分裂。Skoog 与 Miller（1957）由此断定，器官形成不由特定的器官形成物质控制，而由两种激素在有能力的细胞上的平衡控制——这是一个定量的、组合式的原理，同样也构成根分生组织以及顶端优势中生长素与细胞分裂素拮抗的基础。
:::

::: exercise 会关掉的受体 {level=2}
*Arabidopsis* 有五个乙烯受体。（a）缺失其中任何一个受体几乎没有效应，但缺失四个受体的四重突变体显示组成型乙烯响应。用“无乙烯时受体激活 CTR1”的模型解释。（b）为什么阻止乙烯结合的 *etr1-1* 突变是显性的？（c）预测 *etr1-1 ctr1* 双重突变体的表型，并说明它揭示了基因的什么顺序。
::: solution
（a）每个未被占据的受体都帮助 CTR1 保持活性、使通路保持关闭。受体间部分冗余，失去一个仍有足够的受体活性；失去大部分则移除了激活 CTR1 的信号，于是 EIN2 被释放，即使没有乙烯响应也是开着的。
（b）突变受体不能结合乙烯，因而即使乙烯存在仍持续激活 CTR1，无论正常受体如何都把通路关闭：显性的不敏感表型。
（c）组成型响应，与 *ctr1* 相同：CTR1 作用于受体下游，没有它，受体的状态无关紧要。*ctr1* 对 *etr1-1* 是上位性的。
:::

::: exercise 切段中的极性运输 {level=2}
将一段10 mm 长的向日葵下胚轴放在含 ¹⁴C-IAA 的供体琼脂块与接受块之间。（a）供体块在形态学上端时，约一小时后放射性出现在接受块中；把切段倒置（供体块在形态学下端）则几乎看不到放射性出现。请解释。（b）向切段中加入 NPA（PIN 外流的抑制剂）会消除两种方向上的运输。这说明了什么？（c）若供体块在上端时，最早标记物在60分钟后出现在接受块中，估算运输速率。
::: solution
（a）极性生长素运输从茎细胞的顶端端移向基部端，因为 PIN 输出载体位于细胞的基部面。倒置的切段中供体块在基部端，IAA 无法朝原来的顶端输出，只发生缓慢扩散。
（b）极性运输需要输出载体；阻断载体使生长素被困在细胞内（能进入却不能出去）。
（c）$10\ \text{mm}/1\ \text{h} = 10$ mm h⁻¹（标记物前锋）——在5–20 mm h⁻¹ 的典型范围内。
:::

::: exercise 依 pH 梯度弯曲 {level=3}
单侧光照的胚芽鞘中，生长素横向移到遮阴侧，使遮阴侧生长素为受光侧的1.5倍。（a）用 [[#ex-dose]] 的剂量-响应（$\mathrm{EC_{50}} = 300$ nmol L⁻¹、$n = 1$），受光侧为100 nmol L⁻¹，比较两侧的生长响应。（b）若胚芽鞘是直径2 mm 的圆柱，受光侧伸长区的伸长速率为1.0 mm h⁻¹，它以每小时多少度的速率弯曲？把伸长速率之差当作相对响应之差的正比量处理。（c）为什么更陡的剂量-响应（更大的 $n$）会使向光性更灵敏？
::: solution
（a）受光侧：$1/(1 + 300/100) = 0.25$。遮阴侧（150 nmol L⁻¹）：$1/(1 + 300/150) = 0.333$。遮阴侧的响应是受光侧的 $0.333/0.25 = 1.33$ 倍。
（b）遮阴侧以 $1.33$ mm h⁻¹ 伸长；在宽度 $d = 2$ mm 上的差为 $\Delta v = 0.33$ mm h⁻¹。弯曲的弧段两侧长度差 $\Delta L$ 跨宽度 $d$ 时转过 $\theta = \Delta L/d$ 弧度，故弯曲速率为 $0.33/2 = 0.167$ rad h⁻¹ $= 9.5^\circ$ h⁻¹。（胚芽鞘的弯曲确实大约是这个量级——数小时内几十度。）
（c）$n$ 越大，EC₅₀ 附近响应随浓度变化越陡，两侧生长素相同比值便产生更大的生长差——同一信号的增益更大。代价是能检测出差异的浓度范围变窄。
:::

::: exercise 萎蔫叶片中的激素 {level=3}
盆栽植物的根暴露于干燥、含盐的溶液后30分钟内，叶片气孔导度减半，而此时尚检测不到叶片水势的任何下降。（a）提出两条信息能以如此快速度从根传到叶的途径。（b）一种叶片不能合成 ABA（但根能）的 *Arabidopsis* 突变体与嫁接实验已被用于检验关闭气孔的 ABA 在哪里合成。描述如何用一个野生型与 ABA 缺陷突变体之间的正反嫁接实验区分根源与叶源的 ABA。（c）若接于野生型根上的 ABA 缺陷穗的气孔仍然不能关闭，这意味着什么？
::: solution
（a）水力信号——木质部张力的变化几乎瞬间传播——在叶片中被感知（例如被保卫细胞或维管组织感知），触发局部 ABA 合成；或木质部汁液携带的化学信号，如 ABA、其结合物、汁液 pH 的变化或小肽（已有证据表明从根运到茎的 CLE 肽能诱导 *Arabidopsis* 叶片合成 ABA）。电信号或钙波也有可能。
（b）嫁接组合：野生型穗接突变体根；突变体穗接野生型根；以及各自自接作为对照。让根经历干旱，测定气孔关闭与叶片 ABA。若关闭需要穗中合成 ABA，则突变体穗即使接在野生型根上也不能关闭，而接在突变体根上的野生型穗正常关闭。
（c）这意味着根源的 ABA 不足以使气孔关闭，叶片必须响应来自根的信号自行合成 ABA——一些研究已得出这一结论，从而把重点放在来自根的水力或肽类信号上。
:::
