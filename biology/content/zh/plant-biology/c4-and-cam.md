Rubisco 是固定 CO₂ 的酶，凡使用卡尔文-本森循环的光合生物都靠它固碳。它在三十多亿年前就已演化出来，彼时的世界 CO₂ 充裕而几乎没有游离氧气。它的活性位点无法完美区分两种气体：既会把 CO₂ 加到核酮糖-1,5-二磷酸上，也会把 O₂ 加上去。在现代大气中，氧气占21 %而 CO₂ 仅约0.04 %，这一副反应是一笔沉重的消耗。在温暖日子里的小麦或水稻叶片中，大约每四个 RuBP 分子就有一个被加氧而不是被羧化，而回收这一产物既耗费能量，又把先前固定的 CO₂ 重新释放回空气。这一过程即**光呼吸**，在温暖条件下会使 C3 植物的光合下降五分之一到三分之一。

演化没能造出好得多的 Rubisco：对氧气排斥更强的酶反应更慢，而反应更快的选择性更差。于是，许多植物演化出了在 Rubisco 周围**浓缩 CO₂** 的办法。最重要的两种是**C4 光合作用**——在一种细胞中先进行一次羧化，把 CO₂ 交给另一种细胞中的 Rubisco——以及**景天酸代谢**（CAM）——夜间固定 CO₂，白昼在关闭的气孔后面向 Rubisco 释放。本章从 Rubisco 的动力学出发解释光呼吸，介绍 C3 光合作用的标准模型，然后描述 C4 与 CAM 方案在解剖、生化、能量与生态上的特点。本章直接建立在 [[plant-biology/photosynthesis]] 的光反应与卡尔文-本森循环之上。

## Rubisco 的两难

### 羧化还是加氧

CO₂ 与 O₂ 竞争结合 Rubisco 活性位点上同一形式的 RuBP 烯二醇。羧化产生两分子3-磷酸甘油酸（3-PGA）；加氧则产生一分子 3-PGA 与一分子**2-磷酸乙醇酸**（2-PG）——这是二碳化合物，卡尔文-本森循环无法利用，还会抑制该循环的几种酶。既然两种底物相互竞争，两反应速率之比可由竞争底物的动力学直接得到（[[biochemistry/enzymes]]）。

::: proposition 羧化与加氧之比 {#prop-specificity}
设 $V_c$ 与 $V_o$ 为羧化与加氧的最大速率，$K_c$ 与 $K_o$ 为 CO₂ 与 O₂ 的米氏常数。叶绿体中 CO₂ 与 O₂ 浓度为 $C$ 与 $O$ 时，两反应速率之比为

$$
\frac{v_c}{v_o} = S_{c/o}\,\frac{C}{O}, \qquad S_{c/o} = \frac{V_c\,K_o}{V_o\,K_c},
$$ {#eq-specificity}

其中 $S_{c/o}$ 是 Rubisco 的**特异性因子**。此处假定两种气体按米氏动力学竞争同一酶-RuBP 复合物。
:::

::: proof
对竞争同一酶形式的两种底物，每一种都是对方反应的竞争性抑制剂。羧化速率为 $v_c = V_c C/\bigl(C + K_c(1 + O/K_o)\bigr)$，加氧速率为 $v_o = V_o O/\bigl(O + K_o(1 + C/K_c)\bigr)$。把两个分母展开后都等于 $D/(K_cK_o)$，其中 $D = CK_o + OK_c + K_cK_o$，故 $v_c = V_cCK_o/D$、$v_o = V_oOK_c/D$。二者之比为 $V_cK_oC/(V_oK_cO)$。
:::

就 C3 陆生植物的 Rubisco 而言，在25 °C 下，若 $C$ 与 $O$ 以溶解浓度表示，$S_{c/o}$ 约为80–100。处于空气中的叶片，其叶绿体基质的溶解 CO₂ 浓度仅约8 µmol L⁻¹，因为 CO₂ 必须经气孔与叶肉细胞扩散进来并在途中不断被消耗；而溶解 O₂ 浓度约为258 µmol L⁻¹——高出三十倍。

::: example 有多少加氧？ {#ex-ratio}
取 $S_{c/o} = 90$、$C = 8$ µmol L⁻¹、$O = 258$ µmol L⁻¹。（a）求 $v_c/v_o$。（b）光呼吸中每两次加氧释放一个 CO₂。羧化固定的碳中有多大比例又损失掉了？
::: solution
（a）$v_c/v_o = 90\times8/258 = 2.79$：约每2.8次羧化对应一次加氧。

（b）每次羧化对应 $v_o/v_c = 0.358$ 次加氧，释放 $0.5\times0.358 = 0.18$ 个 CO₂。因此固定的碳中有**约18 %**又被损失掉，此外还有回收 2-PG 所耗的能量。温度更高时损失更大（见 [[#ex-temperature]]）。
:::
:::

### 光呼吸途径

2-磷酸乙醇酸由一条穿过三种细胞器的途径回收。在叶绿体中，它被去磷酸化为**乙醇酸**，进入**过氧化物酶体**并被氧化为乙醛酸（生成 H₂O₂，由过氧化氢酶分解）；乙醛酸再被氨基化为**甘氨酸**。甘氨酸进入**线粒体**，由甘氨酸脱羧酶复合体把两分子甘氨酸转为一分子**丝氨酸**，同时释放 **CO₂** 与 **NH₃**——光呼吸损失的 CO₂ 正是从这里放出的。丝氨酸回到过氧化物酶体，转化为羟基丙酮酸并还原为甘油酸，甘油酸重新进入叶绿体并被磷酸化为 3-PGA。氨必须由叶绿体中的谷氨酰胺合成酶与谷氨酸合酶重新固定，代价是 ATP 与还原型铁氧还蛋白（[[plant-biology/mineral-nutrition]]）；光呼吸的氨通量比植株对氮的净同化大许多倍。

因此，该途径把两分子 2-PG 所含四个碳原子中的三个送回卡尔文-本森循环，另一个以 CO₂ 形式损失。计入氨的再固定后，通常的账目是每次加氧花费约3.5个 ATP 与2个 NADPH 当量。光呼吸并非一无是处——它解除了 2-PG 的毒性，否则会毒害卡尔文-本森循环；而且途径有缺陷的突变体在正常空气中死亡，却能在加氧受抑制的高 CO₂ 下生长——但这是一项昂贵的补救，不是能自己挣回成本的适应。

### CO₂ 补偿点

CO₂ 下降时，加氧相对越来越频繁；到某个 CO₂ 浓度，光呼吸释放的 CO₂ 恰好与羧化固定的相抵。

::: definition CO₂ 补偿点 {#def-gamma}
**光呼吸 CO₂ 补偿点** $\Gamma^*$ 是羧化恰好平衡光呼吸 CO₂ 释放时的 CO₂ 浓度，即 $v_c = 0.5\,v_o$。由 [[#eq-specificity]]，

$$
\Gamma^* = \frac{0.5\,O}{S_{c/o}}.
$$ {#eq-gamma}

实际测得的叶片 **CO₂ 补偿点** $\Gamma$（净 CO₂ 交换为零处）比 $\Gamma^*$ 略高，因为光照下仍有线粒体呼吸。
:::

当 $O = 258$ µmol L⁻¹、$S_{c/o} = 90$ 时，$\Gamma^* = 0.5\times258/90 = 1.43$ µmol L⁻¹ 溶解 CO₂。25 °C 下 CO₂ 在水中的溶解度约为每大气压0.034 mol L⁻¹，因此这相当于气相摩尔分数 $1.43\times10^{-6}/0.034 = 42$ µmol mol⁻¹——接近 Carl Bernacchi 及同事（2001）在25 °C 下对烟草测得的42.75 µmol mol⁻¹。密封于光照小室中的 C3 叶片能把 CO₂ 降到约40–50 µmol mol⁻¹ 而不能再低；C4 叶片则几乎能把它降到零。

::: example 热天里的光呼吸 {#ex-temperature}
35 °C 下 Rubisco 的特异性因子下降（本例设为约65），且 CO₂ 相对 O₂ 的溶解度下降，于是叶绿体中 $C = 6.5$ µmol L⁻¹、$O = 220$ µmol L⁻¹。重新计算 $v_c/v_o$ 与固定碳损失的比例。
::: solution
$v_c/v_o = 65\times6.5/220 = 1.92$；损失为 $0.5/1.92 = 0.26$，即羧化的**26 %**，而25 °C 下为18 %。温度的两个效应——对酶特异性的影响与对两种气体相对溶解度的影响——朝同一方向推进。热而干的天气里气孔关闭，$C$ 进一步下降，损失还要更高。这正是温暖、干燥、强光照生境中 CO₂ 浓缩机制所受的选择压力。
:::
:::

## C3 光合作用的一个模型

C3 叶片的净 CO₂ 吸收如何依赖于其内部的 CO₂ 浓度？Graham Farquhar、Susanne von Caemmerer 与 Joseph Berry（1980）把 Rubisco 动力学与电子传递对 RuBP 的供应结合起来，得到了今天叶片光合作用的标准模型，从作物育种到全球气候模型都在使用。

::: proposition Farquhar–von Caemmerer–Berry 模型 {#prop-fvcb}
C3 叶片在胞间 CO₂ 浓度 $C$ 下的净 CO₂ 同化速率为两个限制中的较小者，再减去光下呼吸 $R_d$：

$$
A = \min(A_c, A_j) - R_d, \qquad A_c = \frac{V_{c\max}\,(C - \Gamma^*)}{C + K_c(1 + O/K_o)}, \qquad A_j = \frac{J\,(C - \Gamma^*)}{4C + 8\Gamma^*}.
$$ {#eq-fvcb}

$A_c$ 是**Rubisco 限制**速率，此时 RuBP 充足而限制来自酶的容量 $V_{c\max}$；$A_j$ 是**RuBP 再生限制**速率，此时电子传递速率 $J$ 限制了 NADPH 与 ATP 的供应。因子 $(C - \Gamma^*)$ 扣除了光呼吸损失。该模型把整片叶子当作一个大叶绿体；它忽略了细胞间隙与叶绿体之间的扩散阻力（或通过以叶绿体 CO₂ 代替 $C$ 将其计入），其最简形式还略去了高 CO₂ 下三碳糖磷酸利用的第三个限制。
:::

$A_j$ 的表达式来自电子需求：每一次羧化需要4个电子（2个 NADPH），每一次加氧在 RuBP 再生与氨的再同化上也要花费约4个，分母用 $v_o/v_c = 2\Gamma^*/C$ 把电子流换算为净 CO₂ 吸收。

::: example 一条 A–Ci 曲线 {#ex-fvcb}
25 °C 下的小麦叶片有 $V_{c\max} = 80$ µmol m⁻² s⁻¹、$J = 160$ µmol m⁻² s⁻¹、$R_d = 1.0$ µmol m⁻² s⁻¹。取 $K_c = 404.9$ µmol mol⁻¹、$K_o = 278.4$ mmol mol⁻¹、$O = 210$ mmol mol⁻¹、$\Gamma^* = 42.75$ µmol mol⁻¹（Bernacchi 及同事，2001）。求 $C = 280$ µmol mol⁻¹（当今空气的典型值）与 $C = 600$ µmol mol⁻¹ 时的 $A$，并说明各自受什么过程限制。
::: solution
首先，$K_c(1 + O/K_o) = 404.9\times(1 + 210/278.4) = 404.9\times1.754 = 710$ µmol mol⁻¹。

在 $C = 280$：$A_c = 80\times(280 - 42.75)/(280 + 710) = 80\times237.25/990 = 19.2$；$A_j = 160\times237.25/(1120 + 342) = 26.0$。较小者为 $A_c$：**Rubisco 限制**，$A = 19.2 - 1.0 = 18.2$ µmol m⁻² s⁻¹。

在 $C = 600$：$A_c = 80\times557.25/1310 = 34.0$；$A_j = 160\times557.25/(2400 + 342) = 32.5$。此时 $A_j$ 较小：**电子传递限制**，$A = 31.5$ µmol m⁻² s⁻¹。

两种限制在约 $C = 540$ µmol mol⁻¹ 处相交。低于它时，额外的 CO₂ 既提高羧化又抑制加氧，光合作用对 CO₂ 响应强烈。这就是大气 CO₂ 上升促进 C3 光合的原因——“CO₂ 施肥”效应——也是 C4 植物该效应较小的原因，因为其 Rubisco 早已饱和。
:::
:::

## C4 光合作用

### 途径

1950年代与1960年代初，夏威夷糖料种植者协会的研究者（Hugo Kortschak、Constance Hartt 与 George Burr，1965年发表），以及在苏联独立工作的 Yuri Karpilov 发现，给甘蔗或玉米叶片喂 ¹⁴CO₂ 数秒后，最早被标记的化合物不是 3-PGA，而是四碳的苹果酸与天冬氨酸。Marshall Hatch 与 Roger Slack（1966）在甘蔗中理清了这条途径，并证明它是一台与特化解剖相偶联的 CO₂ 泵。

::: definition C4 光合作用 {#def-c4}
**C4 光合作用**中，CO₂ 在两种细胞里被固定两次。

1. **叶肉**细胞中，碳酸酐酶把 CO₂ 转为碳酸氢盐，**磷酸烯醇式丙酮酸羧化酶**（PEPC）把它加到磷酸烯醇式丙酮酸（PEP）上，生成**草酰乙酸**，再被还原为**苹果酸**或经转氨生成**天冬氨酸**。PEPC 利用的是 HCO₃⁻ 而非 CO₂，对其底物亲和力高，且没有加氧酶活性。
2. C4 酸经胞间连丝扩散进**维管束鞘**细胞——它们围绕每个叶脉形成花环（**花环结构**，即 Kranz 解剖，Kranz 在德语中意为花环）——并在那里**脱羧**，释放 CO₂。
3. 位于维管束鞘的 Rubisco 与卡尔文-本森循环重新固定这一 CO₂，其浓度比空气高数倍——常被估计为约十倍。
4. 三碳残体（丙酮酸或丙氨酸）回到叶肉，由**丙酮酸磷酸双激酶**（PPDK）利用 ATP 再生 PEP，ATP 被裂解为 AMP。
:::

C4 植物按维管束鞘中主要脱羧酶分类：**NADP-苹果酸酶**（在叶绿体中；玉米、甘蔗、高粱）、**NAD-苹果酸酶**（在线粒体中；多种粟与苋科植物），或**磷酸烯醇式丙酮酸羧化激酶**（在细胞质中；一些热带禾草）。许多物种不止用一种。维管束鞘细胞的壁常有木栓质化，能减慢 CO₂ 逸出；NADP-ME 类型的维管束鞘叶绿体光系统 II 很少，产生的 O₂ 也少，进一步有利于羧化。

C4 光合作用不是一条独立造糖的途径：每种 C4 植物都用 Rubisco 与卡尔文-本森循环。C4 循环是外加的成分，是一台把 CO₂ 送给 Rubisco 的泵。

::: warning "C4 植物就是更优越"
C4 光合作用不是全面的改进，而是一种权衡。泵要耗能：PPDK 再生 PEP 时每泵送一个 CO₂ 多耗2个 ATP 当量，而被浓缩的 CO₂ 有一部分从维管束鞘漏回，必须重新泵送。在凉爽、荫蔽或高 CO₂ 条件下，光呼吸轻微，C3 植物同样高效或更高效。James Ehleringer 与 Olle Björkman（1977）对量子产额的经典测定表明，C4 植物的量子产额几乎不随温度变化，而 C3 植物的随温度（及光呼吸）上升而下降；在当时的 CO₂ 水平下，30 °C 以下 C3 植物的量子产额更高，以上则是 C4 植物。这就是为什么 C4 禾草主导热带稀树草原与暖季草地，而 C3 禾草主导温凉的温带草地，以及为什么随着大气 CO₂ 上升，交叉温度随之升高。
:::

::: example 泵的能量成本 {#ex-c4cost}
C4 叶片以卡尔文-本森循环（每个 CO₂ 3个 ATP 与2个 NADPH）加 C4 循环（每泵送一个 CO₂ 2个 ATP 当量）同化 CO₂。**泄漏率** $\varphi$ 指维管束鞘中释放的 CO₂ 漏回叶肉而未被固定的比例。若 $\varphi = 0.2$，每净固定一个 CO₂ 需花费多少 ATP？
::: solution
要在维管束鞘中固定一个 CO₂，由于五分之一会漏回，泵必须输送 $1/(1 - \varphi) = 1/0.8 = 1.25$ 个 CO₂。于是 C4 循环花费 $2\times1.25 = 2.5$ 个 ATP，总计 $3 + 2.5 = 5.5$ 个 ATP（及2个 NADPH）每 CO₂，而无光呼吸的 C3 叶片只需3个 ATP。C4 植物多付近一倍的 ATP，但避开了光呼吸——温暖条件下光呼吸让 C3 植物既耗能又耗碳。额外的 ATP 主要来自循环电子流（[[plant-biology/photosynthesis]]），这一过程在 C4 的维管束鞘叶绿体中被增强。
:::
:::

### 哪些是 C4 植物？

约8,100个物种是 C4 植物，约占维管植物物种数的3 %，但它们贡献了陆地总初级生产量（GPP）的大约四分之一——按 Christopher Still 及同事（2003）的估计约为23 %——因为它们主导热带与亚热带的草原和稀树草原。其中包括若干最高产的作物（玉米、甘蔗、高粱、珍珠粟与谷子）以及许多世界性恶性杂草。C4 光合作用在被子植物的至少19个科中独立演化过**60多次**（Rowan Sage 及同事，2011–2016），以禾本科（Poaceae）、莎草科（Cyperaceae）与苋科最为常见；它是复杂性状收敛演化最惊人的例子之一。现存的**C3–C4 中间类型**，如 *Flaveria* 属，显示了它如何逐步产生：先是甘氨酸脱羧酶被局限到维管束鞘，使光呼吸 CO₂ 在那里释放并在那里被重新捕获（“C2 光合作用”），随后 C4 酶从已有的持家功能中被招募，并在合适的细胞中上调。

分子定年把禾本科最早的 C4 起源放在约三千万年前的渐新世，当时大气 CO₂ 已降到低水平；C4 草原的扩张要晚得多，在晚中新世与上新世（约800万–300万年前），证据是化石土壤与食草哺乳动物牙齿釉质中碳同位素的转变（Thure Cerling 及同事，1997）。

少数植物在单个细胞内运行 C4 循环，把两次羧化分到细胞质的不同区域：中亚的藜科植物 *Bienertia* 与 *Suaeda aralocaspica*（Elena Voznesenskaya、Gerald Edwards 及同事，2001–2002）。

### 碳同位素区分 C3 与 C4

碳有两种稳定同位素，¹²C 与约1.1 %的 ¹³C。Rubisco 排斥 ¹³CO₂，固定它比固定 ¹²CO₂ 慢约2.9 %（29 ‰）；经气孔的扩散歧视4.4 ‰。PEPC 与 CO₂ 和碳酸氢盐之间的平衡相结合，歧视作用则小得多。同位素组成写作 $\delta^{13}$C，即 ¹³C/¹²C 相对标准的偏差，以千分比（‰）计。

::: proposition C3 植物的碳同位素歧视 {#prop-isotope}
对于 C3 叶片，相对空气对 ¹³C 的歧视 $\Delta$ 在很好的近似下为

$$
\Delta = a + (b - a)\,\frac{c_i}{c_a},
$$ {#eq-isotope}

其中 $a = 4.4$ ‰ 是扩散分馏，$b \approx 27$ ‰ 是 Rubisco 羧化的净分馏，$c_i/c_a$ 是胞间 CO₂ 与环境 CO₂ 之比（Graham Farquhar、Marion O'Leary 与 Joseph Berry，1982）。植物的同位素组成于是近似为 $\delta^{13}\mathrm{C}_\text{plant} \approx \delta^{13}\mathrm{C}_\text{air} - \Delta$。
:::

该式在两个极限之间插值：若气孔几乎关闭（$c_i \to 0$），进入的每个 CO₂ 分子都被固定，只有扩散产生分馏；若气孔充分敞开（$c_i \to c_a$），Rubisco 的偏好便完全显现。

::: example C3 植物的同位素印记 {#ex-isotope}
小麦叶片 $c_i/c_a = 0.7$；大气 CO₂ 的 $\delta^{13}$C $\approx -8.5$ ‰（2020年代的值；随贫 ¹³C 的化石碳进入大气，该值在缓慢下降）。估计叶片的 $\delta^{13}$C。干旱下气孔关闭到 $c_i/c_a = 0.4$ 时又会是多少？
::: solution
$\Delta = 4.4 + (27 - 4.4)\times0.7 = 4.4 + 15.8 = 20.2$ ‰，所以 $\delta^{13}\mathrm{C} \approx -8.5 - 20.2 = -28.7$ ‰。干旱下，$\Delta = 4.4 + 22.6\times0.4 = 13.4$ ‰，得 $\delta^{13}\mathrm{C} \approx -21.9$ ‰。

C3 植物的 $\delta^{13}$C 通常在约 −35 ‰ 到 −20 ‰ 之间，平均约 −27 ‰；C4 植物的 PEPC 几乎固定每个进入的 CO₂，其值聚集在 −12 ‰ 附近（−16 ‰ 到 −10 ‰）。由于 $c_i/c_a$ 反映气孔导度与光合作用的平衡，C3 植物的 $\delta^{13}$C 是其内在水分利用效率的记录（[[diversity-of-life/land-plants]]）；Graham Farquhar 与 Richard Richards 据此育出了水分利用效率更高的小麦品种，于2000年代初在澳大利亚推广。
:::
:::

::: application 膳食与历史中的同位素
玉米与甘蔗是 C4 而大多数其他作物是 C3，因此动物与人体组织的碳同位素记录了它们吃了什么。骨胶原分析显示玉米农业传入北美东部的时间（约900年以后膳食转向富 C4）；化石牙齿的同位素显示晚中新世非洲等地的食草哺乳动物何时从采食 C3 植物的嫩枝叶转向吃 C4 草；食品真伪实验室凭 C4 印记检出蜂蜜或果汁中掺入的蔗糖或玉米糖浆。与此同时，C4 作物的高生产力激发了把 C4 光合作用工程化导入水稻的尝试（国际 C4 稻米计划，2008年启动），这一目标需要酶与花环结构兼备，迄今尚未实现（截至2026年）。野心较小的策略是绕开光呼吸：Paul South、Amanda Cavanagh、Donald Ort 及同事（2019）在烟草中转入一条在叶绿体内代谢乙醇酸并阻断其外运的替代途径，在田间试验中发现生物量增加超过25 %。
:::

## 景天酸代谢

早在1815年，Benjamin Heyne 就注意到落地生根（*Bryophyllum calycinum*，现名 *Kalanchoe pinnata*，景天科的一种多肉植物）的叶片清晨味酸、午后几乎无味。夜间积累的酸是苹果酸，它是一种 CO₂ 浓缩机制的产物——这一机制的分离不在空间上（如 C4 光合作用），而在时间上。

::: definition 景天酸代谢 {#def-cam}
在**CAM** 中，气孔夜间开放，此时空气凉而湿，CO₂ 由 PEPC 固定为草酰乙酸并还原为**苹果酸**，被泵入液泡并以苹果酸的形式储存。白昼气孔关闭；苹果酸离开液泡并被脱羧（由苹果酸酶或磷酸烯醇式丙酮酸羧化激酶），释放的 CO₂ 被困在气孔关闭的叶片内，浓度数倍于空气，由 Rubisco 在卡尔文-本森循环中固定，所用的 ATP 与 NADPH 来自光反应。Barry Osmond（1978）区分了四个阶段：夜间吸收（I）；黎明时的过渡，伴有部分 C3 直接固定（II）；白昼脱羧、气孔关闭（III）；以及午后晚些苹果酸用尽后，气孔重新开放并进行 C3 直接固定（IV）。
:::

CAM 的最大优点是节水。叶片在夜间开放气孔，此时叶与空气之间的水汽压差小，每个 CO₂ 所损失的水远少于白天开放气孔者（[[plant-biology/water-transport#prop-transpiration]]）。典型的蒸腾比率——每累积一单位干物质所损失的水——C3 植物约为500、C4 约250、CAM 植物约50，变异幅度很大。代价是产能：CAM 植物一天能固定的 CO₂ 量受液泡夜间能储存多少苹果酸的限制，这就是 CAM 植物多为肉质、液泡大、生长缓慢的原因。

::: example 液泡能储存多少碳？ {#ex-cam}
一片 CAM 叶片厚2 mm，液泡占其体积的80 %。夜间，液泡汁中苹果酸浓度升高0.10 mol L⁻¹。（a）若每个苹果酸携带一个由 PEPC 固定的 CO₂，每平方米叶片储存多少 CO₂？（b）若这些 CO₂ 在第二天白昼的10小时内释放并再固定，所能支撑的 Rubisco 平均固定速率是多少？
::: solution
（a）每平方米叶片的液泡体积：$2\times10^{-3}\ \text{m}\times1\ \text{m}^2\times0.8 = 1.6\times10^{-3}$ m³ $= 1.6$ L。储存的苹果酸：$0.10\times1.6 = 0.16$ mol m⁻²，即0.16 mol CO₂ m⁻²。

（b）$0.16\ \text{mol}/36{,}000\ \text{s} = 4.4\times10^{-6}$ mol m⁻² s⁻¹ $= 4.4$ µmol m⁻² s⁻¹——约为 C3 作物叶片光饱和速率的五分之一到四分之一。更厚、更肉质的叶片储存更多；酸性物质还会在夜间把液泡 pH 降低一到两个单位，这正是 Heyne 尝到的味道。
:::
:::

CAM 见于约6 %的维管植物物种，横跨35个以上的科（Katia Silvera、Klaus Winter 及同事，2010）：仙人掌、龙舌兰、景天类、凤梨及其他凤梨科植物，还有许多附生兰科植物——它们栖身的树枝本身就是一种荒漠。它演化过许多次，甚至出现于水韭属（*Isoetes*）这类水生植物中：当溶解 CO₂ 尚未被竞争性藻类耗尽的夜间固定它（Jon Keeley，1981）。许多物种是**兼性**的：冰叶日中花 *Mesembryanthemum crystallinum* 水分充足时进行 C3 光合作用，受盐或干旱胁迫时切换到 CAM（Klaus Winter 与 Dieter von Willert，1972）。龙舌兰与梨果仙人掌等 CAM 植物正被研究用作对常规作物过于干旱的土地上的生物质来源。

::: quiz
一株植物的叶片肉质；其气孔正午关闭；其叶汁的 pH 在黎明时为4.0，黄昏时为5.6；其组织的 $\delta^{13}$C = −14 ‰。它最可能使用哪类光合作用？
- [ ] C3，因为其 δ¹³C 是 C3 植物的典型值
- [ ] C4，因为其 δ¹³C 是 C4 植物的典型值，且具有花环结构
- [x] CAM，因为其夜间积累酸、白昼关闭气孔；其 δ¹³C 反映夜间大部分 CO₂ 由 PEPC 固定
- [ ] 由这些数据无法判断
::: solution
夜间酸化（黎明 pH 低，随白昼苹果酸脱羧而升高）与白昼气孔关闭是 CAM 的标志。当大部分 CO₂ 由 PEPC 在夜间吸收时，同位素印记接近 C4（约 −10 ‰ 到 −20 ‰）；在 II、IV 阶段白昼直接吸收更多 CO₂ 的 CAM 植物数值更负，介于 C3 与 C4 之间。肉质与 CAM 对液泡储存的需求相伴。数据中没有任何迹象提示花环结构。
:::
:::

::: intuition 空间与时间
C4 与 CAM 光合作用使用同一批酶——碳酸酐酶、PEPC、苹果酸脱氢酶、脱羧酶、PPDK——解决同一个问题，策略却相反。C4 在**空间**上把两次羧化分开，在同时工作的两种细胞中进行；其泵持续运转，既提高 Rubisco 的效率也提高光合速率。CAM 在**时间**上把它们分开，在同一细胞内；其泵夜间运转以省水，而液泡的容量决定了白天的配额。这些酶在 C3 祖先中本就因其他用途而存在（PEPC 在每个植物细胞中都补充三羧酸循环的中间产物；[[biochemistry/glycolysis-tca]]），这是两种机制都能演化许多次的原因之一。
:::

::: history
1920年，Otto Warburg 发现氧气抑制小球藻（*Chlorella*）的光合作用——植物生理学中的“Warburg 效应”。John Decker（1955）观察到光照停止后 CO₂ 的爆发释放，从而揭示了烟草叶片的光呼吸；George Bowes、William Ogren 与 Richard Hageman（1971）证明同一种酶——核酮糖二磷酸羧化酶——也催化加氧，一举解释了两种效应；Rubisco 这个名字取自核酮糖二磷酸羧化酶/加氧酶，于1979年提出。乙醇酸途径由 Edward Tolbert 等在1960与1970年代查明。Kortschak、Hartt 与 Burr（1965）以及 Hatch 与 Slack（1966）在甘蔗中发现了 C4 光合作用，其建立在解剖学家 Gottlieb Haberlandt 于1880年代对花环结构的早期观察之上。Heyne 于1815年记录的昼夜酸节奏在二十世纪中叶由 Meirion Thomas、Sidney Ranson 等研究，他们给了它“景天酸代谢”这个名字。Farquhar、von Caemmerer 与 Berry 于1980年发表了他们的 C3 光合模型，Farquhar、O'Leary 与 Berry 于1982年发表了他们的同位素歧视理论。
:::

## 小结

::: summary
- Rubisco 在羧化 RuBP 的同时也加氧：$v_c/v_o = S_{c/o}\,C/O$，C3 植物中 $S_{c/o} \approx 90$。25 °C 的空气中约每3.8个 RuBP 有一个被加氧，约18 %的固定碳被损失；损失随温度升高与气孔关闭而增大。
- **光呼吸**经叶绿体、过氧化物酶体与线粒体回收2-磷酸乙醇酸，每两次加氧释放一个 CO₂ 与一个 NH₃；25 °C 下 $\Gamma^* = 0.5\,O/S_{c/o} \approx 42$ µmol mol⁻¹。
- **FvCB 模型**：$A = \min(A_c, A_j) - R_d$，低 CO₂ 时受 Rubisco 限制，高 CO₂ 时受 RuBP 再生限制。
- **C4**：PEPC 在叶肉固定 HCO₃⁻；C4 酸把 CO₂ 送到维管束鞘（花环结构），Rubisco 在高 CO₂ 下工作。成本：每个 CO₂ 约5–5.5个 ATP，但无光呼吸。演化过60多次；约占物种3 %、陆地 GPP 的23 %；在热、强光、干旱或低 CO₂ 条件下受青睐。
- 碳同位素：C3 有 $\Delta = a + (b - a)c_i/c_a$；δ¹³C ≈ −27 ‰（C3）、−12 ‰（C4），CAM 介于中间直至接近 C4。
- **CAM**：夜间 PEPC 固定与苹果酸储存，白昼在关闭的气孔后脱羧；水分利用效率极高，产能受液泡储存限制；约占物种6 %，常为兼性。
:::

光合作用受光与水通过植物内部信号的调节。协调整个生长与发育的化学信使——植物激素——是 [[plant-biology/plant-hormones]] 的主题。

::: exercise 羧化比率 {level=1 check="3.1"}
具有 $S_{c/o} = 100$ 的 Rubisco 在 CO₂ 8.0 µmol L⁻¹、O₂ 258 µmol L⁻¹ 的叶绿体中工作。求 $v_c/v_o$，保留一位小数。
::: solution
$100\times8.0/258 = 3.1$。
:::

::: exercise 补偿点 {level=1 check="1.29"}
设 $S_{c/o} = 100$、$O = 258$ µmol L⁻¹，以 µmol L⁻¹（溶解）计算 $\Gamma^*$，保留两位小数。
::: solution
$\Gamma^* = 0.5\times258/100 = 1.29$ µmol L⁻¹（25 °C 下气相约合38 µmol mol⁻¹）。
:::

::: exercise 同位素印记 {level=1 check="11.2"}
用 [[#eq-isotope]]，取 $a = 4.4$ ‰、$b = 27$ ‰，$c_i/c_a = 0.3$ 的 C3 叶片的 $\Delta$ 是多少？保留一位小数。
::: solution
$\Delta = 4.4 + 22.6\times0.3 = 11.2$ ‰。
:::

::: exercise 泄漏的维管束鞘 {level=2 check="6"}
某 C4 植物维管束鞘的泄漏率 $\varphi = 1/3$。若卡尔文-本森循环每个 CO₂ 花3个 ATP，泵送每个 CO₂ 花2个 ATP，每净固定一个 CO₂ 需花费多少 ATP？
::: solution
每固定一个 CO₂ 需泵送 $= 1/(1 - 1/3) = 1.5$ 个 CO₂；C4 循环成本 $= 2\times1.5 = 3$ 个 ATP；总计 $= 3 + 3 = 6$ 个 ATP 每 CO₂。
:::
:::

::: exercise 夜间储存 {level=2 check="3.3"}
一片厚1.5 mm 的 CAM 叶片，液泡占其体积的80 %，夜间积累0.10 mol L⁻¹ 苹果酸。若这支撑白昼10小时的 CO₂ 再固定，平均再固定速率是多少（以 µmol m⁻² s⁻¹ 计，保留一位小数）？
::: solution
液泡体积 $= 1.5\times10^{-3}\times0.8 = 1.2\times10^{-3}$ m³ $= 1.2$ L 每平方米；苹果酸 $= 0.12$ mol m⁻²；速率 $= 0.12/36000 = 3.3\times10^{-6}$ mol m⁻² s⁻¹ $= 3.3$ µmol m⁻² s⁻¹。
:::
:::

::: exercise Warburg 的实验 {level=2}
在含400 µmol mol⁻¹ CO₂ 的空气中、25 °C 与饱和光下测定小麦（C3）与玉米（C4）叶片，O₂ 分别为21 %或2 %。2 %的 O₂ 下小麦光合提高约30 %；玉米光合不变。（a）解释这两个结果。（b）预测两个物种在21 %与2 %的 O₂ 下的 CO₂ 补偿点。（c）为什么低 O₂ 对小麦的促进在更高温度下更明显？
::: solution
（a）降低 O₂ 会减少 Rubisco 的加氧（由 [[#eq-specificity]]，$v_c/v_o$ 上升十倍），因此小麦中光呼吸的 CO₂ 损失及其能量成本几乎消失。玉米中，维管束鞘的 Rubisco 本就在高 CO₂ 下工作，即使在21 %的 O₂ 下加氧也可忽略。
（b）小麦：21 %的 O₂ 下 $\Gamma \approx 40$–50 µmol mol⁻¹，随 O₂ 大致成比例下降（[[#eq-gamma]]），在2 %的 O₂ 下降至几个 µmol mol⁻¹。玉米：两者都接近零（几个 µmol mol⁻¹）。
（c）Rubisco 的特异性因子随温度下降，而 CO₂ 溶解度比 O₂ 下降得更快，所以高温下加氧占 Rubisco 活性的比例更大；去除 O₂ 因此能免除更大的损失。
:::
:::

::: exercise 读 A–Ci 曲线 {level=2}
在一系列胞间 CO₂ 浓度下测定两片叶。叶片 X：$C = 45$ µmol mol⁻¹ 时 $A = 0$；$A$ 平稳上升，在1000 µmol mol⁻¹ 处仍在上升。叶片 Y：$C = 3$ µmol mol⁻¹ 时 $A = 0$；$A$ 陡升，在150 µmol mol⁻¹ 以上达到平台。（a）哪片是 C3，哪片是 C4？（b）大气 CO₂ 从420翻倍到840 µmol mol⁻¹，哪片受益更多，为什么？（c）叶片 X 的曲线在约500 µmol mol⁻¹ 处斜率改变。用 FvCB 模型解释。
::: solution
（a）X 是 C3（补偿点接近 $\Gamma^*$，且对 CO₂ 持续响应）；Y 是 C4（补偿点接近零，在低 CO₂ 下饱和，因为 PEPC 与维管束鞘的泵已使 Rubisco 饱和）。
（b）X：当今空气中其胞间 CO₂ 约280，位于曲线的陡段，且受 Rubisco 限制；CO₂ 翻倍既提高羧化又抑制光呼吸。Y 在其胞间 CO₂（约150–200）下已经饱和，光合受益很小——不过水分利用效率的提高可能使其受益，因为在同化速率不变时可以部分关闭气孔。
（c）拐点以下由 $A_c$（Rubisco 容量）限制；拐点以上由 $A_j$（电子传递，即 RuBP 再生）限制，曲线变缓（[[#ex-fvcb]]）。
:::
:::

::: exercise 膳食考古 {level=2}
北美东部某遗址下葬于800年以前的人的骨胶原 $\delta^{13}$C 约 −21 ‰；同址1000年以后的约 −12 ‰。作为食物的动植物也作了测定：鹿胶原 −21 ‰、C3 植物约 −27 ‰、玉米约 −11 ‰。消费者的胶原通常比其膳食富集约5 ‰。（a）膳食发生了什么变化？（b）用两端元混合模型估计1000年以后膳食碳中来自玉米的比例。（c）主要的不确定性是什么？
::: solution
（a）膳食从 C3 来源（野生植物、鹿）转变为大量来自 C4 玉米。
（b）1000年以后的膳食 $\delta^{13}$C $\approx -12 - 5 = -17$ ‰。以 C3 端元 −27 ‰、玉米 −11 ‰计，玉米比例 $f$ 满足 $-17 = f(-11) + (1-f)(-27)$，故 $f = 10/16 = 0.63$：膳食碳约60 %来自玉米。800年以前：膳食 $\approx -26$ ‰，得 $f \approx 0.06$——几乎没有。
（c）膳食-胶原偏移量（随物种与膳食蛋白质含量而变）；胶原主要记录膳食蛋白质，蛋白质含量低的食物如玉米可能被低估；端元数值随植物生长条件与 C3 动物自身膳食而变化；其他 C4 食物（某些野生禾草、食玉米的动物）或海洋食物（其 δ¹³C 有重叠）也可能有贡献。
:::

::: exercise 变化中的大气 {level=3}
末次冰盛期大气 CO₂ 约180–200 µmol mol⁻¹，十八世纪约280，2020年代中期约420 µmol mol⁻¹。（a）用 [[#eq-fvcb]] 与 [[#ex-fvcb]] 的参数，并设 $c_i = 0.7c_a$，计算 $c_a = 190$、280与420 µmol mol⁻¹ 时的 $A_c$。（b）这对这些时期 C3 与 C4 植物之间的竞争平衡有何暗示？（c）在高 CO₂ 的世界里，C4 禾草为何仍可能主导热带稀树草原？
::: solution
（a）$c_i = 133$、196与294。$A_c = 80(c_i - 42.75)/(c_i + 710)$：133时 $80\times90.25/843 = 8.6$；196时 $80\times153.25/906 = 13.5$；294时 $80\times251.25/1004 = 20.0$ µmol m⁻² s⁻¹（尚未减去 $R_d$）。冰期 CO₂ 下的 C3 光合不足当今的一半。
（b）低 CO₂ 极有利于 C4 植物——其光合在 CO₂ 超过约150 µmol mol⁻¹ 后几乎不受 CO₂ 影响；此后 CO₂ 上升使优势转向 C3 植物，在凉爽条件下尤甚。C4 光合作用起源于低 CO₂ 的渐新世，以及 C4 草原在晚中新世的扩张，都符合这一图景，尽管中新世的扩张还涉及干旱、季节性与火。
（c）优势还取决于温度（高温下 C4 的量子产额保持更高）、干旱下的水分利用效率、贫瘠土壤上的氮利用效率，以及火与放牧——热带 C4 禾草对火与放牧高度适应，而火与放牧抑制树木与 C3 灌木。CO₂ 只是若干因素之一；草地高 CO₂ 实验表明，C3–C4 平衡的移动是温和的，并取决于水分与氮。
:::

::: exercise 设计更好的 Rubisco {level=3}
在不同来源的 Rubisco 之间，特异性因子较高的酶往往最大羧化速率较低（例如，一种红藻 Rubisco 的 $S_{c/o} \approx 2.5$ 倍于作物，但反应更慢）。（a）用 [[#eq-specificity]] 与 FvCB 模型，解释为什么用特异性更高但更慢的酶替换作物 Rubisco 既可能提高也可能降低光合。（b）在什么条件下，特异性更高的酶最有帮助？（c）为什么 C4 植物可能演化出特异性较低但转换数较高的 Rubisco？
::: solution
（a）特异性更高会降低 $\Gamma^*$ 并减少光呼吸损失，既提高低 CO₂ 下的 $A_c$（按单位酶计），也提高 $A_j$ 中 RuBP 的利用效率。但最大速率更低意味着同样的 $V_{c\max}$ 需要更多酶（以及氮）；若叶片无法制造更多酶，则在 Rubisco 是主要限制的 CO₂ 水平下 $A_c$ 反而下降。净效应取决于哪种限制在起作用，以及叶片能容纳多少酶。
（b）在光呼吸强烈而 RuBP 再生（光）限制的场合：高温、低胞间 CO₂（气孔关闭），以及弱光——电子的节省在那里最重要。
（c）维管束鞘中 CO₂ 高，无论特异性如何加氧都很罕见；对特异性的选择放松，而更快的酶让 C4 植物用更少的 Rubisco 蛋白达到高 $V_{c\max}$——这有助于其更高的氮利用效率。平均而言，C4 的 Rubisco 较之 C3 的 Rubisco，确有更高的转换数与更低的 CO₂ 亲和力。
:::
