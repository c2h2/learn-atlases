1640年代，佛兰德斯医生 Jan Baptist van Helmont 把一枝重5磅的柳枝栽进一只装了200磅干土的木盆，五年只浇雨水，然后把两者重新称重。柳树此时重约169磅；盆土只减轻了约2盎司。van Helmont 断定树是由水变成的。他只说对了一半：如今我们知道，干重的大部分来自空气中的二氧化碳，其余中相当一部分来自水。但那2盎司也很重要。它们就是矿质养分——氮（自然界中主要来自土壤有机质与微生物）、磷、钾、钙、铁以及另外十来种——缺了它们，没有一株植物能够生长；而在世界上的大多数生态系统与一切集约农业中，限制植物生长的正是它们的供应。

本章讲的正是这些元素。我们先看是什么使一种元素成为**必需元素**、每种元素有何作用、缺素症如何表现。随后追随养分从土壤走到根表——在那里，亏缺与扩散设定了极限——经泵、通道与载体穿过根的膜（它们的动力学可以测量），最终进入木质部。最后我们来认识延伸植物吸收范围的两大共生：**菌根**，真菌充当根的根；以及**固氮**，生活在根瘤里的细菌把大气中的 N₂ 变成氨。膜运输（[[cell-biology/membrane-transport]]）与把养分向上运走的蒸腾流（[[plant-biology/water-transport]]）是本章的前提。

::: warning "植物的食物来自土壤"
许多人正如 van Helmont 的同时代人一样，以为植物用土壤建造自身。实际上，植物干重的大部分——约45 %的碳、42 %的氧与6 %的氢——来自 CO₂ 与水。矿质元素合计只占干重的几个百分点。但它们不可或缺，而且由于土壤供应它们十分缓慢，它们通常比碳更能限制生长。一个相关的误解是植物可以直接吃“有机”肥料：除了少数例外（某些氨基酸与尿素可被吸收），根吸收的是无机离子——硝酸根、铵、磷酸根、钾——由微生物从有机质中释放出来。
:::

## 必需元素

我们怎能判断一株植物需要哪些元素？1860年代，Julius Sachs 与 Wilhelm Knop 把植物根系浸在成分已知的盐溶液中、完全不施土壤地栽培——最早的**水培**——并证明一小批元素就足以完成整个生命周期。后来的工作用上越来越纯的化学品与器皿，补充了那些需要量极微、此前是由杂质顺带提供的元素。

::: definition 必需元素 {#def-essential}
一种元素对一株植物是**必需**的，如果（Daniel Arnon 与 Perry Stout，1939）：（1）没有它，植物无法完成其生命周期；（2）它的功能不能被另一种元素替代；（3）它直接参与植物的代谢，或作为一种必需分子的组分，或作为一种必需的辅因子。需要量相对较大（约0.1 %干重以上）的必需元素称为**大量元素**；需要量小的（约100 mg kg⁻¹ 干重以下）称为**微量元素**。某些元素对一部分物种促进生长、却并非对所有物种都必需，如钠、硅、钴、硒，它们被称为**有益元素**。
:::

除碳、氢、氧之外，通常公认的必需矿质元素有十四种：大量元素氮、磷、钾、钙、镁、硫，微量元素铁、锰、锌、铜、硼、钼、氯、镍。镍是最后添上的一种，因 Patrick Brown、Ross Welch 与 Earle Cary 于1987年证明，缺镍栽培的大麦不能产生有活力的种子；镍是脲酶的辅因子。

### 缺素症状与移动性

每种元素的缺乏都产生特征性症状，而症状先出现在哪里，取决于该元素能否经韧皮部从老叶运往幼叶。氮、磷、钾、镁是**可移动**的：缺素的植株会从老叶中夺取它们——氮来自降解的 Rubisco 与叶绿体蛋白——所以症状先出现在老叶。钙、铁、硼是**不可移动**的：一旦沉积进叶片就留在那里，所以缺素最先表现在幼叶、生长尖端与果实。钙只能随木质部汁液进入器官，这就是蒸腾微弱的果实即使种在富钙土壤里也容易患钙缺素症的原因，如番茄的脐腐病与苹果的苦痘病。

常见症状有**褪绿**（发黄，源于叶绿素合成受阻或叶绿体降解），缺氮时往往均匀褪绿、缺镁与缺铁时发生在脉间；**坏死**（死斑），缺钾时见于叶缘；缺磷时叶色深绿或带紫，因为花青素积累；以及缺硼与缺钙时枝端死亡。

::: quiz
一茬番茄的幼叶叶脉之间发黄，老叶却保持绿色。哪种缺素最符合？
- [ ] 氮
- [ ] 镁
- [x] 铁
- [ ] 钾
::: solution
脉间褪绿指向铁或镁（两者都为叶绿素所必需）。它出现在*幼*叶，指向不可移动的元素：铁。镁可经韧皮部移动，所以其缺素先见于老叶；缺氮使老叶均匀褪绿；缺钾使老叶叶缘焦枯。缺铁常见于碱性石灰性土壤，那里的铁虽存在却不溶解。
:::
:::

## 从土壤到根表

土壤是矿物颗粒、有机质、水、空气与生物的混合物。黏粒与腐殖质带负电的表面把阳离子——K⁺、Ca²⁺、Mg²⁺、NH₄⁺——松散地保持在表面，它们可被其他阳离子交换；一捧土壤所能保持的阳离子总量就是它的**阳离子交换量**。根利用这一点：向土壤释放质子，把结合态的阳离子置换进土壤溶液。硝酸根等阴离子不被保持，随水自由移动，所以硝酸根极易从土壤淋失进入地下水。磷酸根恰相反：它在碱性土壤中与钙、在酸性土壤中与铁和铝形成不溶化合物，所以即使磷的总量很高，土壤溶液中通常也只有微摩尔浓度的磷酸根。

土壤 pH 控制着有效性。铁、锰、锌在高 pH 下变为不溶；铝在 pH 约5以下变得可溶且有毒，伤害根尖；磷酸根在微酸土壤、pH 6–7左右最有效。 

养分经两种过程到达根表。**质流**把溶解的离子随蒸腾拉向根部的水一起搬运；对许多土壤中的硝酸根、钙与镁，它满足了需求的大部分。**扩散**则随吸收耗尽根周的土壤、沿浓度梯度把离子带向根；对于溶液里浓度低且被强烈结合的磷酸根与钾，它是主要供应方式。养分在土壤中的扩散很慢，因为离子必须沿水膜中曲折的路径行进，并不断被颗粒吸附。

::: proposition 亏缺区能扩展多远？{#prop-depletion}
若一种养分在土壤中的有效扩散系数为 $D_e$（它已计入水路的曲折与在土壤颗粒上的吸附），则在时间 $t$ 内，亏缺区会从根表扩展到一个特征距离

$$
\ell \approx \sqrt{2D_e t}.
$$ {#eq-depletion}

这就是一维扩散的均方根位移（[[cell-biology/cells-and-microscopy]]）。湿润土壤中，硝酸根的有效扩散系数约为 $10^{-10}$ m² s⁻¹ 量级，磷酸根则在 $10^{-12}$ 到 $10^{-15}$ m² s⁻¹。
:::

::: example 硝酸根与磷酸根的亏缺区 {#ex-depletion}
估算一天之内根能从多远处吸取养分：硝酸根取 $D_e = 10^{-10}$ m² s⁻¹，磷酸根取 $D_e = 10^{-13}$ m² s⁻¹。
::: solution
一天内 $t = 86{,}400$ s。硝酸根：$\ell = \sqrt{2\times10^{-10}\times86400} = 4.2\times10^{-3}$ m，约4 mm。磷酸根：$\ell = \sqrt{2\times10^{-13}\times86400} = 1.3\times10^{-4}$ m，约0.13 mm。

根能从直径几毫米的土壤圆柱里取走硝酸根，所以相邻的根会为它相互竞争；磷酸根却只能取自仅十分之一毫米厚的鞘层，与根毛的长度相当。要得到更多磷酸根，植物就必须把新的根表面长进新的土壤——因此有了根毛、细根的簇，而最重要的是菌根真菌：其菌丝只有几微米粗，却能伸出亏缺区外几厘米。
:::
:::

## 穿过膜

离子到达根表后，进入表皮与皮层的质外体，并必须穿过一道质膜——最迟在内皮层，其凯氏带阻断质外体（[[plant-biology/plant-form]]）。进来之后，它们以共质体方式移向中柱，再由另一批转运体释放进木质部。

吸收的能量来自**质膜 H⁺-ATP 酶**：它把质子泵出细胞，使细胞质相对胞外负约 −120 mV 到 −200 mV，并使质外体比细胞质约酸1.5–2个 pH 单位。这一质子动力势以两种方式驱动吸收（[[cell-biology/membrane-transport]]）。

- **通道**让阳离子顺电化学梯度流动。由于细胞质如此负，K⁺ 即使土壤浓度远低于细胞内，也能经内向整流通道（如 *Arabidopsis* 的 AKT1）被动进入。
- **质子偶联同向转运体**把阴离子——硝酸根、磷酸根、硫酸根——以及糖或氨基酸逆膜电位运入细胞，每个分子伴随一个或多个顺梯度下行的质子。

::: example 钾何时能被动进入？{#ex-nernst-k}
一根表皮细胞的细胞质含100 mmol L⁻¹ K⁺，20 °C 下膜电位为 −180 mV。胞外 K⁺ 浓度低于多少时，K⁺ 便不能再经通道进入？
::: solution
只有当膜电位比钾的平衡电位 $E_K = \frac{RT}{F}\ln\frac{[K^+]_o}{[K^+]_i}$ 更负时，K⁺ 才经通道流入（能斯特方程，[[cell-biology/membrane-transport#prop-nernst]]）。极限在 $E_K = V_m$，于是

$$
[K^+]_o = [K^+]_i\exp\!\left(\frac{FV_m}{RT}\right) = 100\times\exp\!\left(\frac{-180}{25.3}\right)\ \text{mmol L}^{-1} = 0.080\ \text{mmol L}^{-1},
$$

式中 $RT/F = 25.3$ mV（20 °C）。通道能在胞外低至约80 µmol L⁻¹ 时仍供应 K⁺。低于此，吸收就需要主动的质子偶联转运体（在 *Arabidopsis* 中是 HAK5 转运体）。这与实验一致：在阻断高亲和力转运体的条件下，*akt1* 突变体幼苗在高 K⁺ 下生长正常、在低 K⁺ 下生长不良（Hirsch 及同事，1998）。
:::
:::

### 吸收动力学

1950年代，Emanuel Epstein 与 Carl Hagen 测定离体大麦根从不同浓度溶液中吸收放射性钾与铷的速率，发现吸收像酶反应一样上升并饱和。

::: proposition 米氏吸收 {#prop-mm-uptake}
若离子的吸收由可饱和的转运系统介导，且转运体与膜表面的离子处于快速平衡，则单位根重的吸收速率为

$$
v = \frac{V_{\max}\,c}{K_\mathrm{m} + c},
$$ {#eq-mm-uptake}

其中 $c$ 是胞外浓度，$V_{\max}$ 是最大速率（正比于活性转运体的数目），$K_\mathrm{m}$ 是半最大速率对应的浓度——与酶的米氏方程同形（[[biochemistry/enzymes]]）。该方程假定单一转运系统、溶液搅拌充分（根附近无亏缺）且无外排。
:::

Epstein 后来的测定（Epstein、Rains 与 Elzam，1963）在更宽的浓度范围内显示出第二个吸收相：对 K⁺ 的**高亲和力转运系统**（HATS），$K_\mathrm{m}$ 约20 µmol L⁻¹，在0.2 mmol L⁻¹ 以下即饱和；以及一直上升达数十毫摩尔的**低亲和力系统**（LATS）。如今知道“双等温线”反映的是不同的转运体与通道。就硝酸根而言，高亲和力转运体属于 NRT2 家族；转运体 NRT1.1（又称 NPF6.3）被磷酸化后便在低、高亲和力之间切换，并同时充当硝酸根传感器——一种**转受体**（Yi-Fang Tsay 及同事，1993–2009）。

::: example 双相吸收等温线 {#ex-dual}
一根以高亲和力系统（$V_{\max} = 10$ µmol g⁻¹ h⁻¹，$K_\mathrm{m} = 20$ µmol L⁻¹）和低亲和力系统（$V_{\max} = 20$ µmol g⁻¹ h⁻¹，$K_\mathrm{m} = 5$ mmol L⁻¹）吸收 K⁺。计算在10 µmol L⁻¹、100 µmol L⁻¹、1 mmol L⁻¹ 与10 mmol L⁻¹ 处的总吸收速率，以及各情形中高亲和力系统贡献的份额。
::: solution
浓度以 µmol L⁻¹ 表示，把 [[#eq-mm-uptake]] 的两项相加：

| $c$（µmol L⁻¹） | HATS | LATS | 总量（µmol g⁻¹ h⁻¹） | HATS 份额 |
|---|---|---|---|---|
| 10 | $10\times10/30 = 3.33$ | $20\times10/5010 = 0.04$ | 3.37 | 99 % |
| 100 | $10\times100/120 = 8.33$ | $20\times100/5100 = 0.39$ | 8.73 | 95 % |
| 1000 | $9.80$ | $20\times1000/6000 = 3.33$ | 13.1 | 75 % |
| 10000 | $9.98$ | $20\times10^4/1.5\times10^4 = 13.3$ | 23.3 | 43 % |

在土壤溶液典型的低浓度下，高亲和力系统几乎承担全部工作。浓度高时（施肥的田块或营养液）它已饱和，低亲和力系统接管。土壤中的根其表面通常面对的是微摩尔浓度，所以提高养分利用效率的努力大多瞄准高亲和力转运体。
:::
:::

### 铁：两种策略

铁在土壤中储量丰富，但在中性和碱性 pH 下几乎不溶，以 Fe³⁺ 的氧化物与氢氧化物存在。植物进化出两种获取方式。**策略 I** 为除禾草之外的所有开花植物所用：以 H⁺-ATP 酶酸化根际，释放能螯合 Fe³⁺ 的酚类化合物，以质膜上的铁螯合物还原酶（*Arabidopsis* 的 FRO2）把 Fe³⁺ 还原为更可溶的 Fe²⁺，再经转运体 IRT1 吸收 Fe²⁺。**策略 II** 为禾草所用：分泌**植物铁载体**——麦根酸类，一类强力结合 Fe³⁺ 的非蛋白氨基酸——并通过 YELLOW STRIPE 1家族转运体（最先在玉米中发现）把 Fe³⁺–植物铁载体复合体整体吸收。策略 II 在石灰性土壤上更有效，这正是禾草能耐受石灰性土壤的原因之一。

## 氮的同化

在有氧的农田土壤里，氮主要以硝酸根形式进入植物；在酸性、渍水或森林土壤里则主要以铵形式。硝酸根使用前必须还原：**硝酸还原酶**是一种胞质钼酶，用 NAD(P)H 把它还原为亚硝酸根；质体中的**亚硝酸还原酶**以还原型铁氧还蛋白把亚硝酸根还原为铵——每个氮原子共八个电子。铵无论是吸收来的还是还原产生的，过量都有毒，会立即通过**谷氨酰胺合成酶-谷氨酸合酶（GS–GOGAT）**循环并入氨基酸：谷氨酰胺合成酶消耗 ATP 把铵加到谷氨酸上生成谷氨酰胺；谷氨酸合酶把谷氨酰胺的酰胺基转移给2-氧戊二酸，产生两分子谷氨酸。谷氨酸与谷氨酰胺再把氮捐给所有其他氨基酸与核苷酸。叶中，硝酸根的还原部分依靠光合作用的还原力；根中则依靠呼吸。

## 菌根

大多数陆生植物并非单靠自己的根吸收养分。它们的根被真菌定殖，形成**菌根**（“菌之根”）：在这类互利共生中，真菌向植物供应矿质养分——尤其是磷酸根，还有氮、锌与水——并从植物得到糖与脂类（[[diversity-of-life/fungi]]）。

::: definition 菌根 {#def-mycorrhiza}
**菌根**是真菌与植物根之间在特化界面上交换养分与碳的共生结合。在**丛枝菌根**（AM）中，球囊菌亚门（Glomeromycotina）真菌长在根皮层之内，并在皮层细胞内形成高度分枝的**丛枝**，其外包被着植物的质膜，交换就在丛枝上进行。在**外生菌根**（ECM）中，担子菌门与子囊菌门的真菌在短根外面形成一层菌丝套即**菌鞘**（mantle），并在皮层细胞之间形成菌丝网即**哈氏网**（Hartig net），但不进入细胞。其他类型还包括欧石楠类菌根与兰科菌根。
:::

丛枝菌根最为常见：Mark Brundrett 与 Leho Tedersoo（2018）的概查估计，约72 %的维管植物物种形成丛枝菌根，约2 %形成外生菌根（但其中包括温带与北方森林的优势林木——松、栎、山毛榉、桦——以及东南亚的龙脑香），约10 %形成兰科菌根，1–2 %形成欧石楠类菌根，约7–8 %不形成菌根，包括十字花科（*Arabidopsis* 所属的科）的大多数成员。这一结合极为古老：4.07亿年前的莱尼燧石中，植物体内保存着丛枝状结构；形成它所需的植物基因在苔类及其近缘类群以及开花植物中都有发现，所以这一共生很可能帮助了植物登陆。

真菌菌丝从根伸出几厘米，远远超出 [[#ex-depletion]] 的磷酸根亏缺区；其直径之小使每投入一份碳就得到很大的表面。作为回报，植物向真菌供应糖，以及——2010年代的发现——脂肪酸，而 AM 真菌自己造不出脂肪酸；对这一代价的估计从几个百分点到植株光合产物的约五分之一不等。植物调控着这一伙伴关系：磷供应充足时，植物会抑制定殖；而且它们似乎会把更多的碳交给那些输送磷酸根更多的真菌定殖的根。

对话始于化学信号。根分泌**独脚金内酯**——一类源于类胡萝卜素的化合物，能刺激 AM 真菌的菌丝分枝（Kohki Akiyama、Hideo Hayashi 及同事，2005）——它们同时也是控制枝条分枝的植物激素（[[plant-biology/plant-hormones]]），还被寄生性列当（*Striga*）利用作萌发信号。真菌则以几丁质来源的信号回应，植物用受体激酶感知它们。根内，信号由一条**共同共生信号通路**接力——引人注目的是，它与下文即将介绍的根瘤共生共用这一通路：一种受体样激酶、细胞核上的离子通道、核内与核周钙离子浓度的振荡，以及解码这些振荡的钙与钙调蛋白依赖激酶（CCaMK）。

## 固氮

尽管大气中78 %是 N₂，氮却是最常限制植物生长的养分。N₂ 的三键如此稳定，以致自然界中只有一种酶能打断它：**固氮酶**，仅见于细菌与古菌。

::: proposition 固氮酶反应 {#prop-nitrogenase}
固氮酶是铁蛋白与钼铁蛋白构成的复合体，把分子氮还原为氨，并必然伴随放氢，其计量下限为

$$
\mathrm{N_2 + 8\,H^+ + 8\,e^- + 16\,MgATP \;\longrightarrow\; 2\,NH_3 + H_2 + 16\,MgADP + 16\,P_i}.
$$ {#eq-nitrogenase}

这一化学计量是经验性的：它是在最优条件下测得的下限，真实的细胞消耗更多 ATP 与电子。固氮酶会被氧不可逆地摧毁。
:::

::: example 固氮的能量代价 {#ex-nfix-cost}
以葡萄糖计，估算共生固氮的最小代价，假定供给固氮酶的每一对电子花费2.5个 ATP 当量（一个 NADH），且葡萄糖完全呼吸产生30个 ATP。答案用每固定一克氮需呼吸掉的碳的克数表示。
::: solution
每个 NH₃（[[#eq-nitrogenase]] 的一半）：8个 ATP 与4个电子。4个电子是2对，耗费 $2\times2.5 = 5$ 个 ATP 当量。合计：每个 N 共13个 ATP。所需葡萄糖：每 mol N 需 $13/30 = 0.43$ mol。碳：$0.43\times72$ g $= 31$ g C 对14 g N，即**每克氮2.2克碳**。

这是理论下限。实测代价——包括建造与维护根瘤、供养细菌、保护固氮酶免遭氧害——要高得多，通常达每克氮几克碳。从土壤中吸收同化硝酸根也耗能（还原每个 N 需8个电子），但要少些——这就是为什么硝酸根充足的豆科植物会抑制结瘤。
:::
:::

一些自生细菌能固氮，*Anabaena* 等蓝细菌则在**异形胞**中固氮——一种没有光系统 II、因而不产氧的特化细胞。但陆地上最大的生物固氮输入来自共生，首先是豆科（Fabaceae）与统称**根瘤菌**的细菌（*Rhizobium*、*Sinorhizobium*、*Bradyrhizobium*、*Mesorhizobium* 等属）。还有一类较小的木本植物，即放线菌结瘤植物，如桤木（*Alnus*），与放线菌 *Frankia* 形成根瘤。

::: definition 根瘤共生 {#def-nodule}
豆科-根瘤菌共生的发育分步进行。（1）豆科植物的根释放**黄酮类化合物**，激活细菌的 *nod* 基因。（2）细菌产生**Nod 因子**——其结构因伙伴而异的脂壳寡糖——由根毛上的 LysM 受体激酶感知。（3）根毛把附着的细菌卷绕起来，形成**侵入线**——一根由植物壁物质构成的管道，繁殖中的细菌沿它向内生长。（4）与此同时，皮层细胞分裂形成根瘤原基。（5）细菌从侵入线释放进根瘤细胞，被植物膜包被，并在**共生体**（symbiosome）内分化为固氮的**类菌体**。（6）植物向类菌体供应二羧酸（苹果酸、琥珀酸），得到氨并用 GS–GOGAT 同化之。
:::

根瘤以惊人的方式解决了固氮酶的氧难题。类菌体需要氧呼吸制造 ATP，固氮酶却会被氧摧毁。根瘤细胞挤满了**豆血红蛋白**——一种使有功能的根瘤内部呈粉红色的植物血红蛋白。它以高亲和力结合 O₂，把 O₂ 输送给类菌体的高亲和力末端氧化酶，同时把受感染细胞内的游离 O₂ 浓度压至纳摩尔量级；感染区外围那层排列紧密的细胞又构成屏障，限制氧扩散进根瘤。豆血红蛋白基因被沉默的植株形成的根瘤不固氮。植物还督察自己的伙伴：大豆植株会减少对那些不固氮细菌所在根瘤的氧气供应，这些细菌的繁殖也随之减少（Toby Kiers 及同事，2003）。

::: application 用固定的氮养活世界
二十世纪之前，农民只能通过施厩肥、与豆科作物轮作、或进口鸟粪与智利硝石来向土壤添加氮。1909年，Fritz Haber 证明氨可以在高温高压下、于铁催化剂上由 N₂ 与 H₂ 合成；到1913年，Carl Bosch 已在 BASF 把这一过程放大。**哈伯-博施过程**现在固定的氮多于所有自然陆地过程之和（David Fowler 及同事，2013年估计，哈伯-博施每年约120 Tg N，自然陆地固氮约58 Tg），据估计，靠合成肥料种植的作物养活着世界人口的约一半（Jan Willem Erisman 及同事，2008）。代价是巨大的：氨合成耗用世界能源供应的约1–2 %；施用的氮有很大一部分损失掉——硝酸根淋失入河流、驱动富营养化，以及以一氧化二氮这种强温室气体的形式逸出。因此人们致力于提高作物的氮利用效率、恢复豆科轮作，并怀着一个长期目标：把固氮共生——或干脆把固氮酶本身——工程化地引入谷类作物。
:::

::: history
Carl Sprengel（1828）与 Justus von Liebig（1840）主张植物从土壤吸取矿质元素，Liebig 使“生长受最稀少的必需养分限制”的思想（“最小养分律”，由 Sprengel 首先提出）广为流传。Julius Sachs（1860）与 Wilhelm Knop（1865）在营养液中栽培植物。Hermann Hellriegel 与 Hermann Wilfarth（1886年完成、1888年发表）证明，豆科植物——而非谷类——只有根部结瘤时才能在没有氮的砂土上生长，而土壤灭菌会阻止结瘤；Martinus Beijerinck 于1888年分离出根瘤菌。Albert Bernhard Frank 于1885年为菌根命名。Arnon 与 Stout（1939）给出了必需性的判据，Dennis Hoagland 的营养液成了实验室标准。Epstein 与 Hagen（1952）把酶动力学引入离子吸收。分子时代始于1990年代初首批植物养分转运体的克隆——1992年的 K⁺ 通道 KAT1 与 AKT1、1993年的硝酸根转运体 CHL1（NRT1.1）——以及 Jean Dénarié 及同事于1990年对 Nod 因子的鉴定。
:::

## 小结

::: summary
- 植物需要14种矿质元素：大量元素 N、P、K、Ca、Mg、S 与微量元素 Fe、Mn、Zn、Cu、B、Mo、Cl、Ni。必需性由 Arnon 与 Stout 的判据界定；需要量跨百万倍之广（N : Mo ≈ 10⁶个原子）。
- 韧皮部可移动元素（N、P、K、Mg）的缺素症状先见于老叶，不可移动元素（Ca、Fe、B）的先见于幼嫩组织。
- 养分经质流与扩散到达根；亏缺区按 $\ell \approx \sqrt{2D_et}$ 扩展——一天内硝酸根可达几毫米，磷酸根只有十分之一毫米。
- 质膜 H⁺-ATP 酶为吸收供能：阳离子经通道顺膜电位进入（−180 mV 下 K⁺ 在约80 µmol L⁻¹ 以上可被动进入），阴离子经 H⁺ 偶联同向转运。
- 吸收遵循米氏动力学；双等温线分出高亲和力与低亲和力系统。铁的获取靠还原（策略 I）或植物铁载体（策略 II，禾草）。
- 硝酸根被还原为铵（8个电子），经 GS–GOGAT 同化。
- 丛枝菌根（约72 %的物种）与外生菌根以糖与脂类为交换，扩展了根对磷酸根与氮的获取范围；独脚金内酯与共同共生信号通路启动它们。
- 固氮酶：$\mathrm{N_2 + 8H^+ + 8e^- + 16ATP \to 2NH_3 + H_2}$，对氧敏感；最小代价约每克氮2克碳。豆科根瘤经黄酮类化合物、Nod 因子与侵入线形成；豆血红蛋白缓冲 O₂。
:::

有了水与矿质养分的供应，植物便能做那使其成为植物的事：捕获光。[[plant-biology/photosynthesis]] 从光反应讲起。

::: exercise 诊断一茬作物 {level=2}
就下列每一种情形，说出最可能的缺素种类，并从移动性与功能两方面给出理由：（a）一片玉米地，老叶从叶尖沿主脉向下均匀褪成淡黄，幼叶却保持绿色；（b）芹菜在干旱的夏季、施足石灰的土壤上，生长中的心叶变黑；（c）碱性土壤上的燕麦，幼叶出现灰褐色斑点（一种称为灰斑病的病害）；（d）甘蓝的老叶叶缘焦枯成褐色。
::: solution
（a）氮：可移动（从老叶再转运），是叶绿素与蛋白质所必需；老叶先开始的均匀褪绿是经典征象。
（b）钙：不可移动，只能由木质部供应；干旱天气里，由蒸腾驱动的输送对被包被、蒸腾缓慢的组织（心叶）而言并不足够，即使土壤钙充足（黑心病）。
（c）锰：不可移动，高 pH 下不溶，是光系统 II 与超氧化物歧化酶所必需；燕麦灰斑病是经典的缺锰症。
（d）钾：可移动，故先见于老叶；随着主要渗透物 K⁺ 被撤走，叶缘干枯死亡。
:::
:::

一块小麦每公顷产8.0吨籽粒，按质量计含氮2.0 %。籽粒每公顷从田间带走多少千克氮？
::: solution
$8000\ \text{kg}\times0.020 = 160$ kg N ha⁻¹。（作物总吸收量更大，因为秸秆与根也含氮；而且作物对肥料的回收率往往只有施用量的一半左右——其余经淋失、反硝化与氨挥发损失，或留在土中。）

::: exercise 解读一个菌根实验 {level=2}
韭葱栽于灭菌的缺磷土壤，接或不接丛枝菌根真菌，磷添加设三个水平。八周后：无磷时，菌根植株地上部的质量为不接菌植株的4倍、磷含量为6倍；磷最高时两组没有差异，而真菌对根的定殖从根长的60 %降到10 %。（a）解释低磷时的结果。（b）解释高磷时收益与定殖的丧失。（c）为什么用灭菌土？要证明确实是磷酸根（而非真菌提供的别的东西）带来了生长收益，还应增设什么对照？
::: solution
（a）菌丝伸到根那层薄薄的磷酸根亏缺区之外（[[#ex-depletion]]），把磷酸根输送给植株；磷限制生长，所以生长随磷供应而增。
（b）磷充足时，单靠根就能吸收足够，真菌不再额外提供磷酸根，却仍然消耗碳；植物抑制定殖（磷充足会下调独脚金内酯释放与共生基因），于是真菌的收益与定殖双双下降。高磷时，菌根甚至可能因碳代价而略微降低生长。
（c）灭菌去除本地菌根真菌与其他微生物，使不接菌处理确实未被定殖。一个对照是给不接菌植株额外的磷酸根，使其磷含量与菌根植株相当：若其生长也随之相当，则收益来自磷酸根。向不接菌的盆中加入接种物滤液（真菌以外的微生物），可对照随接种物引入的其他生物。
:::

::: exercise 结瘤突变体 {level=2}
解释每种豆科突变体在没有固定氮的条件下生长的预期表型，并说明施加硝酸根能否挽救它：（a）缺识别 Nod 因子的 LysM 受体的突变体；（b）缺 CCaMK 的突变体；（c）根瘤缺豆血红蛋白的突变体；（d）即使在硝酸根存在下也形成远比正常多为的根瘤（超结瘤）的突变体。
::: solution
（a）根毛不卷曲、无侵入线，没有根瘤；氮饥饿（色淡、矮小）；硝酸根可挽救。由于该受体专一识别 Nod 因子，菌根形成正常。
（b）CCaMK 解码共同共生通路中的钙峰，故根瘤与丛枝菌根都不能形成；硝酸根可挽救（菌根缺陷则可由磷酸根挽救）。
（c）根瘤形成但呈白色、不固氮，因为游离 O₂ 使固氮酶失活（且类菌体的呼吸缺少高亲和力 O₂ 供应）；缺氮；硝酸根可挽救。
（d）系统性的**结瘤自动调控**有缺陷（一种来自地上部的反馈，涉及 CLE 肽与一种地上部受体激酶，限制根瘤数目），或硝酸根的抑制失效；植株常矮小，因为根瘤大量抽取碳。硝酸根不抑制这类突变体的结瘤。
:::

::: exercise Liebig 的木桶 {level=3}
Liebig 最小养分律主张：生长只受相对需求而言最稀缺之资源的限制，正如木桶的盛水高度由其最短的桶板决定。一项肥料试验给出如下籽粒产量（t ha⁻¹）：不施肥2.0；只施氮3.0；只施磷2.4；氮磷同施5.5。（a）Liebig 律会预言这种格局吗？（b）结果表明氮与磷如何共同限制生长？（c）试提出一个生理学理由，说明施氮为何能提高植物获取磷的能力。
::: solution
（a）在严格的 Liebig 限制下，添加限制养分可提高产量，直到另一种养分成为限制因子，而添加非限制养分没有作用。这里单施氮与单施磷都提高产量，合施的提高又超过各自单独效应之和（$+1.0 + 0.4 = 1.4$，而实测为 $+3.5$）。这不是 Liebig 的格局。
（b）作物受氮与磷的**共同限制**，且有协同作用：每种养分的效应取决于另一种养分的水平。生态系统施肥实验中共同限制很常见，这就是 Liebig 律被视为有用的初步近似而非定律的原因。
（c）氮能促进根与根毛的生长、合成更多磷酸根转运体与磷酸酶（富氮的酶，能把磷酸根从有机化合物中释放出来），并产出更多光合产物供养菌根真菌；因此氮供应改善磷的获取；反之亦然，磷支撑耗费 ATP 多的氮同化。
:::

::: exercise 何必要自己固氮？{level=3}
结合 [[#ex-nfix-cost]] 中的代价，解释（a）豆科植物为何常在缺氮土壤与火烧迹地上充当先锋植物；（b）土壤施氮后豆科植物为何竞争力下降；（c）即使完美实现，把谷类作物工程化为自己固氮为何不能让肥料变得免费。
::: solution
（a）缺氮土壤上，固氮提供了竞争者得不到的资源；当光照充足（开阔、受扰动的地点）而氮又是最强限制因子时，其碳代价负担得起。
（b）土壤氮充足时，吸收硝酸根或铵比固定 N₂ 便宜，豆科植物又会抑制结瘤；它们失去特殊优势，必须与往往更擅长获取土壤氮的禾草竞争。
（c）固氮的能量将来自作物自身的光合产物——每克氮至少约2克碳、实践中还要多出几倍——所以除非光合作用也同步改进，产量将因被挪走的碳而下降。氮的代价将由糖而非天然气支付，这仍可能划算，尤其对买不起肥料的农民，但并非免费。
:::
