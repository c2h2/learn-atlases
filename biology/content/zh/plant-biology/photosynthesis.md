每年，地球上的植物、藻类与蓝细菌把大约一千亿吨的碳从二氧化碳固定为有机物——这是陆地与海洋加在一起的净初级生产量——并释放出构成大气五分之一的氧气。光合作用是能量进入生物界的入口：你早餐里的糖、由远古森林与浮游生物形成的化石燃料、以及你用来燃烧它们并借此存活的氧气，都是它的产物。它的总反应式很简单，

$$
6\,\mathrm{CO_2} + 12\,\mathrm{H_2O} \xrightarrow{\ \text{光}\ } \mathrm{C_6H_{12}O_6} + 6\,\mathrm{O_2} + 6\,\mathrm{H_2O}, \qquad \Delta G^{\circ\prime} \approx +2870\ \text{kJ mol}^{-1},
$$

但在它背后是一台精巧非凡的机器：能捕获光子、并在不到十亿分之一秒内把能量汇入反应中心的色素天线；一种锰钙催化剂，能裂解水，而任何人造催化剂在室温下都不如它高效；一条为 ATP 合成泵送质子的电子传递链；还有一个由地球上最丰富的蛋白质领衔的酶循环，把 CO₂ 变成糖。

本章追随能量的足迹。我们先讲光与色素，再讲两个光系统以及从水到 NADP⁺ 电子传递的 **Z 方案**，还有 ATP 的化学渗透合成——与线粒体中相同的原理（[[biochemistry/oxidative-phosphorylation]]），只是由光来驱动。随后我们转向 **卡尔文-本森循环**（Calvin–Benson cycle）的化学计量与调控，并以整片叶子对光的响应及该过程的效率作结。一路上我们要把账算清：固定一个 CO₂ 分子需要多少光子、质子、ATP 与 NADPH。叶绿体的结构已在 [[plant-biology/plant-cells-tissues]] 中引入；Rubisco 与氧气反应造成的麻烦，以及 C4 与 CAM 的解决方案，是 [[plant-biology/c4-and-cam]] 的主题。

## 光与色素

光以光子而来，光子的能量由其波长决定。

::: proposition 光子的能量 {#prop-photon}
波长为 $\lambda$ 的光子具有能量 $E = hc/\lambda$，其中 $h = 6.626\times10^{-34}$ J s 为普朗克常数，$c = 2.998\times10^8$ m s⁻¹ 为光速。因此一摩尔光子（一个 **einstein**）携带

$$
E_\text{mol} = \frac{hcN_\mathrm{A}}{\lambda} = \frac{1.196\times10^{5}\ \text{kJ nm mol}^{-1}}{\lambda}.
$$ {#eq-photon}
:::

::: example 红光与蓝光光子的能量 {#ex-photon}
求680 nm（红光，被光系统 II 吸收）与450 nm（蓝光）处一摩尔光子的能量。
::: solution
由 [[#eq-photon]]，在680 nm 处 $E = 119{,}600/680 = 176$ kJ mol⁻¹，在450 nm 处 $E = 119{,}600/450 = 266$ kJ mol⁻¹。蓝光光子比红光光子多携带一半的能量，但正如我们将看到的，光合作用用不上这部分多余：被蓝光光子激发的叶绿素分子在约一皮秒内就弛豫到最低激发态，把盈余以热的形式散掉，因此每个被吸收的光子所做的光化学功都与一个红光光子相同。植物生理学家因此以光子通量来计量光——**光合有效辐射**（PAR）波段400–700 nm 内每平方米每秒的微摩尔光子数——而不是以能量通量。正午的全日照约为2000 µmol m⁻² s⁻¹ 的 PAR。
:::
:::

吸收光的色素结合在类囊体膜的蛋白质上。**叶绿素 a** 与 **叶绿素 b** 是四吡咯，中心有一个镁离子，一条长长的植醇尾把它们锚定在膜上；其共轭的单双键交替环在蓝光（约430–450 nm）与红光（约640–680 nm）强烈吸收，在绿光吸收很弱，这就是叶子看起来发绿的原因。**类胡萝卜素**（β-胡萝卜素和叶黄素类：叶黄素、花药黄质、玉米黄质与新黄质）吸收蓝绿光，把能量传给叶绿素，并且——更重要的是——通过淬灭叶绿素和单线态氧的危险激发态来保护这套装置。即便如此，叶片对绿光也并非透明：叶内的多重散射给绿光光子多次被吸收的机会，一片典型的叶子能吸收80–90 %的入射 PAR。

1882年，Theodor Engelmann 把一丝水绵（*Cladophora*，一种丝状藻）横放在显微镜下投影出的微小光谱上，周围是趋氧细菌，它们会朝氧气游去。细菌聚集在被红光与蓝光照射的那段丝体周围：这是光合作用第一个**作用光谱**，与叶绿素的吸收光谱吻合。

### 天线与反应中心

1932年，Robert Emerson 与 William Arnold 用短暂的饱和闪光照射小球藻（*Chlorella*），测量每次闪光产生的氧气。即使每个叶绿素分子都应当吸收了一个光子，大约每2,500个叶绿素才出现一个 O₂。既然每个 O₂ 需要若干个光子（约八个，稍后会看到），这意味着一次只有大约几百分之一的叶绿素能做光化学功；其余的充当**天线**，收集光并把能量传递出去。

::: definition 天线、反应中心与光合单位 {#def-antenna}
**光系统**是一种色素-蛋白质复合体，其中由几百个叶绿素与类胡萝卜素分子组成的**天线**由捕光蛋白持有，吸收光子并以共振能量传递的方式把激发能从一个分子传给下一个分子——总是朝着吸收波长略长、因而能量略低的色素——直到抵达**反应中心**。在那里，一对特殊的叶绿素利用这份能量把一个电子交给受体，形成一个电荷分离态。天线的反应中心一起构成一个**光合单位**。
:::

这个漏斗既快又高效。激发能每几百飞秒就在叶绿素之间跳跃一次，在几十到几百皮秒内到达反应中心，弱光下被吸收的光子有90 %以上都能产生电荷分离。天线让一个反应中心——一个昂贵而复杂的复合体——即使在微光中也能以合理的速率工作，因为它从大得多的面积上收集光子。植物中的主要天线是**捕光复合体 II**（LHCII），是地球上最丰富的膜蛋白，含有叶绿素 a、b 与类胡萝卜素。

## 串联的两个光系统

裂解水与还原 NADP⁺ 都是高难度任务。电对 O₂/H₂O 在 pH 7的标准氧化还原电位为 $+0.82$ V，NADP⁺/NADPH 的为 $-0.32$ V。让电子跨越这个跨度“上坡”移动会储存自由能，我们可以由氧化还原电位与自由能的标准关系算出（[[biochemistry/bioenergetics]]）。

::: proposition 电子转移的自由能 {#prop-redox}
当 $n$ 个电子从还原电位为 $E_\text{donor}$ 的供体电对转移到电位为 $E_\text{acceptor}$ 的受体电对时，

$$
\Delta G = -nF\,\Delta E, \qquad \Delta E = E_\text{acceptor} - E_\text{donor},
$$ {#eq-redox}

其中 $F = 96.485$ kJ mol⁻¹ V⁻¹ 为法拉第常数。向更正的受体转移是自发的（$\Delta G < 0$）；向更负的受体转移则需要输入能量。
:::

::: example 由水制 NADPH 需要多少能量？ {#ex-nadph}
求把两个电子从水转移到 NADP⁺ 所需的标准自由能，并与实际用到的四个红光光子的能量（每个电子两个）作比较。
::: solution
$\Delta E = E(\mathrm{NADP^+/NADPH}) - E(\mathrm{O_2/H_2O}) = -0.32 - 0.82 = -1.14$ V。由 [[#eq-redox]]，$\Delta G = -2\times96.485\times(-1.14) = +220$ kJ（每摩尔 NADPH）。四摩尔680 nm 光子提供 $4\times176 = 704$ kJ，所以约有31 %的光能被储存为 NADPH；还有更多以质子梯度的形式储存为 ATP。其余部分是为让每一步既快又不可逆所付的代价，以免分离的电荷重新复合。
:::
:::

人们发现，单独用红光照射时，波长超过约680 nm 处量子产额会降低（“红降”），而 Emerson 及同事（1957）表明，补上短波长光就能恢复它们——双束光合照产生的氧气多于各自单独照射之和（**Emerson 增益效应**）。Robin Hill 与 Fay Bendall（1960）对此作了解释：存在两个光系统，串联工作，各自由自己的光子驱动。按氧化还原电位的尺度画出来，电子的路径构成一个侧写的 Z。

::: definition 线性电子流的 Z 方案 {#def-zscheme}
在类囊体膜上：

1. **光系统 II**（PSII）吸收一个光子；其反应中心叶绿素 **P680** 经去镁叶绿素把一个电子交给结合的质体醌 Q_A 与 Q_B。被氧化的 P680⁺——约 +1.2 V，是最强的生物氧化剂——从一个酪氨酸取回一个电子，酪氨酸再从**放氧复合体**、一个 Mn₄CaO₅ 簇取一个。经过四次这样的步骤，该簇氧化两个水分子：$2\,\mathrm{H_2O} \to \mathrm{O_2} + 4\,\mathrm{H^+} + 4\,e^-$，把质子释放到类囊体**腔**中。
2. Q_B 接受两个电子并从基质带走两个质子后，以**质体醌醇**（PQH₂）的形式离开，进入膜的流动池。
3. **细胞色素 b₆f 复合体**氧化质体醌醇，把它的质子释放入腔，并把电子交给**质体蓝素**——腔中的一种小铜蛋白。通过 **Q 循环**，每对电子中有一个被循环回质体醌，于是每有一个电子到达质体蓝素，就有两个质子被移入腔中。
4. **光系统 I**（PSI）吸收一个光子；其反应中心叶绿素 **P700** 被激发到约 −1.2 V，并把一个电子经一串受体（叶绿素、植物醌与铁硫簇）交给基质中的**铁氧还蛋白**。P700⁺ 由质体蓝素重新还原。
5. **铁氧还蛋白–NADP⁺ 还原酶**（FNR）在基质中用两个还原型铁氧还蛋白把 NADP⁺ 还原为 NADPH。
:::

两步设计反映了一个极限：单一反应中心无法在从一个红光光子（1.8 eV）的能量中既产生足以裂解水的强氧化剂、又产生足以还原 NADP⁺ 的强还原剂，还要留下足够的余量让每一步都不可逆。每个电子用两个光子给出所需的跨度，其损耗换来的是速度与稳定性。

### 水氧化时钟

一个每吸收一个光子只收到一个电子空位的复合体，如何攒够四个来裂解两个水分子？Pierre Joliot 及同事（1969）给暗适应的叶绿体一串短闪光，测量每次闪光释放的氧气。头两次闪光几乎没有氧气；第三次出现一个爆发，此后每隔四次闪光一次，并随时间衰减。Bessel Kok（1970）解释了这一图样：放氧复合体在 S₀ 到 S₄ 五个状态间循环，每次闪光把它推进一步，而 O₂ 在 S₄ → S₀ 的转变时释放。暗中该复合体大多停在 S₁，所以第三次闪光使它到达 S₄。衰减来自偶发的漏击与双击。来自蓝细菌 *Thermosynechococcus vulcanus* 的 PSII 在1.9 Å 分辨率的结构（Yasufumi Umena、Jian-Ren Shen、Nobuo Kamiya 及同事，2011）显示该簇是一把变形的“椅子”：四个锰离子、一个钙与五个氧。

::: quiz
DCMU（diuron，一种除草剂）结合在光系统 II 的 Q_B 位点。分离的叶绿体在人工电子受体（针对任一光系统）存在下照光。哪种说法正确？
- [ ] DCMU 在任何电子受体下都停止 O₂ 释放，因为它阻断了光系统 I
- [x] DCMU 停止来自水的 O₂ 释放与 NADP⁺ 还原，但若人工供体向质体蓝素提供电子，PSI 仍能还原受体
- [ ] DCMU 对电子流没有影响，因为它作用于卡尔文循环
- [ ] DCMU 通过防止逆反应而增加 O₂ 释放
::: solution
DCMU 把质体醌从 Q_B 位点排走，电子无法离开 PSII：水的氧化以及 PSII 下游的一切停止。PSI 未受损；若人工供体（如还原型 DCPIP 加抗坏血酸）向质体蓝素喂电子，PSI 在光中仍能还原铁氧还蛋白或甲基紫精之类的受体。正是这类实验把 Z 方案解剖为两半。许多商品除草剂（莠去津、diuron）就作用在这个位点。
:::
:::

## 合成 ATP：光合磷酸化

光驱动的电子流在类囊体膜两侧建立起质子动力势：水的氧化和细胞色素 b₆f 复合体处的质体醌醇氧化把质子释放入腔，而质体醌与 NADP⁺ 的还原从基质取走质子。照光时腔内降至约 pH 5–6，基质升至约 pH 8；与线粒体不同，质子动力势的大部分在于 pH 差，因为抗衡离子的移动（Cl⁻ 入腔、Mg²⁺ 出腔）塌掉了大部分膜电位。质子经 **ATP 合酶**（CF₀CF₁）返回基质，其 CF₁ 头部伸向基质一侧，所以 ATP 正是合成在卡尔文-本森循环需要它的地方。

化学渗透机制在叶绿体中得到最漂亮的证明。André Jagendorf 与 Ernest Uribe（1966）把类囊体在暗中浸于 pH 4的缓冲液，使腔内变酸，然后突然转移到含 ADP 与磷酸的 pH 8缓冲液：它们在暗中合成了 ATP，驱动力只是人工 pH 梯度。

### ATP:NADPH 预算

ATP 合酶的旋转机构决定了每个 ATP 所需的质子数：转子每转一整圈合成三个 ATP，并泵送与其膜环 c 亚基数相同数目的质子。菠菜叶绿体的环有14个亚基（Holger Seelert 及同事，2000），给出每个 ATP $14/3 \approx 4.67$ H⁺。

::: example 线性电子流够用吗？ {#ex-budget}
每释放一个 O₂，线性电子流把4个电子从水移到 NADP⁺，产生2个 NADPH。(a) 每个 O₂ 有多少质子进入腔？(b) 按每个 ATP 14/3 H⁺，它们能做多少 ATP？(c) 卡尔文-本森循环每固定一个 CO₂ 需要3个 ATP 与2个 NADPH。线性流够吗？(d) 若亏空由围绕 PSI 的**循环电子流**补足——电子从铁氧还蛋白送回质体醌池，经细胞色素 b₆f 复合体每个电子泵2个 H⁺——每个 CO₂ 需要额外多少个光子？
::: solution
(a) 水的氧化向腔释放4个 H⁺；细胞色素 b₆f 处的 Q 循环每个电子移2个 H⁺，所以 $2\times4 = 8$。合计：**每个 O₂ 12 H⁺**。

(b) 每2个 NADPH 有 $12/(14/3) = 2.57$ 个 ATP，即每个 NADPH 1.29个 ATP。

(c) 循环需要每个 NADPH $3/2 = 1.5$ 个 ATP。线性流每个 CO₂ 短缺 $3 - 2.57 = 0.43$ 个 ATP。

(d) 缺口需要 $0.43\times14/3 = 2.0$ 个额外质子，即1个电子绕 PSI 循环一周，这需要 PSI **额外吸收1个光子**。线性流每个 CO₂ 需要8个光子（4个电子 × 2个光系统），总计约9个光子每 CO₂——接近在叶片与藻中测得的每 O₂ 9–10个光子的最低量子需求下限。这笔账解释了为什么曾被视为奇象的循环电子流其实必不可少：缺少主要循环途径的植物（在 *Arabidopsis* 中即 PGR5–PGRL1 途径与 NDH 复合体）生长不良，在波动光下尤甚。
:::
:::

::: intuition 为什么 ATP:NADPH 之比必须可调
一个以固定比率制造 ATP 与 NADPH 的细胞，一旦需求变化就会陷入困境。除卡尔文-本森循环外，叶绿体还要为蛋白质合成与修复、为淀粉与脂质合成以及蛋白质输入消耗 ATP，为亚硝酸与硫酸盐同化消耗还原力；光呼吸（[[plant-biology/c4-and-cam]]）每单位 NADPH 比碳固定需要更多 ATP。循环电子流只造 ATP 不造 NADPH，加上其他把电子交给氧的“阀门”，让叶绿体能随时调节这一比率。c 环化学计量在不同生物之间并不相同（已知 ATP 合酶中从8到17个亚基不等），这提醒我们该比率并非仅由化学决定，而是进化的调校。
:::

## 卡尔文-本森循环

光中制造的 ATP 与 NADPH 在基质中被消耗，用于还原 CO₂。这条途径由 Melvin Calvin、Andrew Benson、James Bassham 及同事在伯克利于1946至1954年间用新问世的放射性同位素 ¹⁴C 阐明。他们把 ¹⁴CO₂ 喂给光照下的小球藻与 *Scenedesmus* 悬浮液，时间从几秒到几分钟，再把细胞倒入热酒精中杀死，用二维纸层析分离标记化合物并在 X 光片上鉴定。几秒之后，大部分标记出现在一种化合物——**3-磷酸甘油酸**（3-PGA）中，标记在其羧基上。它的碳来自 CO₂ 加到一个五碳受体**核酮糖-1,5-二磷酸**（RuBP）上：关灯则 RuBP 下降而 3-PGA 上升，去除 CO₂ 则 RuBP 上升而 3-PGA 下降。

::: definition 卡尔文-本森循环的三个阶段 {#def-calvin}
1. **羧化。** 核酮糖-1,5-二磷酸羧化酶/加氧酶（**Rubisco**）把 CO₂ 加到 RuBP 上；不稳定的六碳中间体裂解为两分子 3-PGA。
2. **还原。** 3-PGA 被 ATP 磷酸化为1,3-二磷酸甘油酸，再被 NADPH 还原为**甘油醛-3-磷酸**（G3P），一种三碳糖磷酸——这是糖酵解若干步骤（[[biochemistry/glycolysis-tca]]）的逆过程，但使用 NADPH。
3. **再生。** 每六个三碳糖磷酸中的五个，经一系列转酮酶、醛缩酶与磷酸酶反应（以四、五、六、七碳糖磷酸为中间体）重排为三个五碳糖磷酸，再由**磷酸核酮糖激酶**用 ATP 磷酸化回 RuBP。
:::

::: proposition 卡尔文-本森循环的化学计量 {#prop-calvin}
循环三轮，

$$
3\,\mathrm{CO_2} + 9\,\mathrm{ATP} + 6\,\mathrm{NADPH} + 5\,\mathrm{H_2O} \longrightarrow \mathrm{G3P} + 9\,\mathrm{ADP} + 8\,\mathrm{P_i} + 6\,\mathrm{NADP^+},
$$ {#eq-calvin}

所以每固定一个 CO₂ 耗费 **3个 ATP 与2个 NADPH**。
:::

::: proof
3个 RuBP（15 C）与3个 CO₂（3 C）羧化得6个 3-PGA（18 C）。把6个全部还原需要6个 ATP 与6个 NADPH，得6个 G3P（18 C）。一个 G3P（3 C）是净产物；其余5个 G3P（15 C）重排为3个核酮糖-5-磷酸（15 C），把它们磷酸化为3个 RuBP 再花3个 ATP。总计：每3个 CO₂ 9个 ATP 与6个 NADPH。（磷酸的账：9个 ATP 给出9个 Pᵢ 当量，其中一个留在输出的 G3P 中。）
:::

产物三碳糖磷酸有两种去向。白天，一部分经**三碳糖磷酸/磷酸转运体**与磷酸交换运出叶绿体，在细胞质中用来合成**蔗糖**，即韧皮部输出的糖（[[plant-biology/water-transport]]）。一部分留在叶绿体中制成**淀粉**，夜间分解，为天亮前供应蔗糖与能量。*Arabidopsis* 会调节其夜间淀粉分解的速率，使约95 %的淀粉以恒定速率恰好在预期的天亮时刻用完——这是一道涉及生物钟的算术题（[[plant-biology/plant-responses]]）。

### Rubisco

Rubisco 是一种慢酶：在植物中，每个活性部位每秒只催化约2–5个反应，而典型酶是数百或数千。植物以量取胜。植物型 Rubisco 是一个十六聚体，八个大亚基由叶绿体基因组编码，八个短亚基由细胞核编码（分子质量约550 kDa，含八个活性部位）；它占叶片可溶性蛋白与叶片氮的很大份额，很可能是地球上最丰富的蛋白质。

::: example 一片叶子需要多少 Rubisco？ {#ex-rubisco}
一片叶子以20 µmol m⁻² s⁻¹ 的速率固定 CO₂。若每个 Rubisco 活性部位在叶片所处条件下以每秒1个反应运作（因 CO₂ 未饱和而低于其最大值），一平方米叶需要多少克 Rubisco？
::: solution
所需活性部位数为 $20$ µmol m⁻² $= 2.0\times10^{-5}$ mol m⁻²。每个550 kDa 的全酶有8个部位，所以每个部位折合 $550{,}000/8 = 68{,}750$ g mol⁻¹。质量 $= 2.0\times10^{-5}\times68{,}750 = 1.4$ g m⁻²。测得 C3 作物叶片的 Rubisco 含量通常为1–3 g m⁻²，占叶片总氮的相当份额。这就是氮肥能提高光合能力的原因，也是有 CO₂ 浓缩机制的植物（[[plant-biology/c4-and-cam]]）需要更少 Rubisco 与更少氮的原因。
:::
:::

### 循环的开关

卡尔文-本森循环只能在光中运行：若在夜间运行，它会消耗由储存的糖经氧化途径反向运行时本应留存的 ATP 与 NADPH。光通过若干方式把它接通。

- **基质的 pH 与 Mg²⁺。** 质子泵入腔使基质从约 pH 7升至8，Mg²⁺ 从腔移入基质。Rubisco、果糖-1,6-二磷酸酶与景天庚酮糖-1,7-二磷酸酶在较高 pH 与 Mg²⁺ 下更活跃。
- **硫氧还蛋白。** PSI 来的还原型铁氧还蛋白还原硫氧还蛋白，后者还原果糖-1,6-二磷酸酶、景天庚酮糖-1,7-二磷酸酶、磷酸核酮糖激酶等酶中的二硫键，使其活化（铁氧还蛋白-硫氧还蛋白系统，由 Bob Buchanan 及同事自1960年代起阐明）。暗中，二硫键重新形成。
- **Rubisco 的活化。** Rubisco 必须**被羧基化**——一个 CO₂ 分子（与底物不同）结合到一个赖氨酸上，由 Mg²⁺ 稳定——才有活性，而结合在未羧基化或已羧基化位点上的糖磷酸会抑制它。**Rubisco 活化酶**是一种依赖 ATP 的分子伴侣，能移除这些抑制物；其活性取决于 ATP/ADP 比率并受硫氧还蛋白调控，从而把 Rubisco 活性与光联系起来。活化酶怕热，这造成了高温下光合的衰退。

::: warning “光反应”与“暗反应”
旧书把卡尔文-本森循环叫作“暗反应”，许多学生因此以为它在夜间运行。事实并非如此：它依赖光反应的 ATP 与 NADPH，并由光通过基质 pH、Mg²⁺ 与硫氧还蛋白接通。进入黑暗几秒之内，其关键酶就开始失活。“不依赖光”只意味着循环中各反应本身不吸收光。用“光反应”（或类囊体反应）与“碳反应”（或基质反应）更不容易误导。
:::

## 一片叶子的光合作用

叶片净吸收 CO₂ 的速率 $A$ 取决于光、CO₂、温度与水。用气体交换系统测量，它对光子通量 $I$ 的响应有典型形态：暗中 $A$ 为负（呼吸释放 CO₂）；弱光下线性上升，其斜率由**量子产额** $\phi$（每个吸收的光子固定的 CO₂）决定；强光下饱和，此时卡尔文-本森循环与电子传递的能力成为限制。$A = 0$ 的光照水平称为**光补偿点**。

::: proposition 光响应曲线模型（经验式） {#prop-light}
叶片在吸收光子通量 $I$ 下的净 CO₂ 同化速率可由**非直角双曲线**很好地描述

$$
A = \frac{\phi I + A_\text{max} - \sqrt{(\phi I + A_\text{max})^2 - 4\theta\,\phi I A_\text{max}}}{2\theta} - R_d,
$$ {#eq-light}

其中 $\phi$ 为最大量子产额，$A_\text{max}$ 为光饱和总速率，$\theta$（介于0与1之间）为曲率参数，$R_d$ 为呼吸速率。这是一个拟合模型，不是机理定律；它是总速率 $P$ 的方程 $\theta P^2 - (\phi I + A_\text{max})P + \phi I A_\text{max} = 0$ 的较小根，是 $P = \phi I$（光限制）与 $P = A_\text{max}$（能力限制）两个极限之间的平滑过渡。$\theta = 1$ 时它变成“Blackman”式响应，$P = \min(\phi I, A_\text{max})$。
:::

::: example 读一条光响应曲线 {#ex-light}
一片阳叶的 $\phi = 0.05$，$A_\text{max} = 25$ µmol m⁻² s⁻¹，$\theta = 0.7$，$R_d = 1.0$ µmol m⁻² s⁻¹。(a) 估算其光补偿点。(b) 计算在200、500与1000 µmol m⁻² s⁻¹ 处的 $A$。(c) 同种的一片阴叶的 $A_\text{max} = 8$、$R_d = 0.3$ 而 $\phi$ 相同。比较两者的补偿点。
::: solution
(a) 弱光下 $P \approx \phi I$，所以补偿点约为 $R_d/\phi = 1.0/0.05 = 20$ µmol m⁻² s⁻¹。（精确求解 [[#eq-light]] 得20.3。）

(b) 代入 [[#eq-light]]：在200处 $A = 7.6$；在500处 $A = 15.2$；在1000处 $A = 19.6$ µmol m⁻² s⁻¹。曲线在远低于全日照处已经明显弯曲；光从500翻倍到1000，增益还不到三分之一。

(c) 阴叶：$0.3/0.05 = 6$ µmol m⁻² s⁻¹。阴叶的 Rubisco 较少、呼吸较低，在更弱的光下就能达到碳收支为正，但饱和速率低得多。量子产额是光化学本身的属性，在相同 CO₂ 与温度下几乎所有 C3 叶片都几乎相同。
:::
:::

### 光太多

全日照下叶片吸收的光子多于它能用。过剩的激发是危险的：处于激发态的叶绿素会把能量交给氧，生成高活性的单线态氧，而过度还原的电子载体产生超氧阴离子。植物在多个时间尺度上设防。几秒之内，腔的酸化启动**非光化学淬灭**（NPQ）：PsbS 蛋白感知腔内低 pH，把捕光复合体切换到以热的形式耗散激发能的状态；玉米黄质脱环氧化酶把花药黄质转化为**玉米黄质**，增强淬灭（**叶黄素循环**）。几分钟之内，捕光复合体在两个光系统之间重新分配（状态转换）。而持续地，PSII 不断受损——其 D1 蛋白被光破坏，速率与光强成正比——并由叶绿体合成新的 D1 来修复，这个修复循环贯穿整天运行，当胁迫严重时便会失效（**光抑制**）。由于 NPQ 在叶片从太阳移入阴凉时弛豫缓慢，Johannes Kromdijk、Stephen Long 及同事（2016）通过过表达 PsbS 与叶黄素循环两种酶的基因，把烟草改造成弛豫更快的品系，在田间试验中发现生长量增加了约15 %。

::: application 光合作用有多高效？
从量子需求可以算出上限。固定一个 CO₂ 在糖中储存约 $2870/6 = 478$ kJ；九个680 nm 光子提供 $9\times176 = 1584$ kJ，对吸收的红光效率为30 %。但太阳能量中只有约49 %落在 PAR 波段，其中又并非全被吸收，680 nm 当量以上的能量以热散失，呼吸与光呼吸还要消耗一部分产物。Xin-Guang Zhu、Stephen Long 与 Donald Ort（2008）估计，总太阳能量转化为生物量的理论最大效率，C3 植物约4.6 %、C4 植物约6 %，而观测到的最佳季节效率约2.4 %与3.7 %。典型作物全年达不到1 %。改进光合作用——通过更快的光保护、更好的 Rubisco、绕开光呼吸的途径与更好的冠层结构——如今是作物研究的主要目标。
:::

::: history
Joseph Priestley（1771）发现一枝薄荷能“复原”蜡烛燃尽的空气；Jan Ingenhousz（1779）表明这需要光与绿色组织；Jean Senebier（1782）表明需要“固定空气”（CO₂）；Nicolas-Théodore de Saussure（1804）表明水也被消耗。Julius Sachs 在1860年代表明淀粉在光中于叶绿体内形成。Cornelis van Niel 比较绿色植物与用 H₂S 而不用水的紫色硫细菌，于1931年提出光合作用的氧来自水；Samuel Ruben、Merle Randall、Martin Kamen 与 James Hyde 于1941年用重同位素 ¹⁸O 证实了它。Robin Hill（1937）表明分离的叶绿体在光中借助人工电子受体释放氧气（Hill 反应）。Daniel Arnon 及同事于1954年发现光合磷酸化；Calvin 获1961年诺贝尔化学奖，Peter Mitchell（化学渗透）获1978年，Johann Deisenhofer、Robert Huber 与 Hartmut Michel 因解析第一个光合反应中心的结构——来自紫色细菌 *Blastochloris viridis*（当时称 *Rhodopseudomonas viridis*）——获1988年诺贝尔奖。
:::

## 小结

::: summary
- 光子每摩尔携带 $E = hcN_\mathrm{A}/\lambda$：680 nm 处176 kJ mol⁻¹。叶绿素 a 与 b 吸收蓝光与红光；类胡萝卜素捕光并保护。光以光子通量计量，波段为400–700 nm 的 PAR。
- 几百个色素组成的天线把激发能汇入反应中心（Emerson 与 Arnold 的光合单位）。
- **Z 方案**：PSII（P680）在 Mn₄CaO₅ 簇处氧化水（S 态时钟，每第四个光子一个 O₂），还原质体醌；细胞色素 b₆f 借 Q 循环把电子交给质体蓝素；PSI（P700）还原铁氧还蛋白，FNR 制造 NADPH。把2个电子从水移到 NADP⁺ 储存220 kJ mol⁻¹（$\Delta G = -nF\Delta E$）。
- 质子梯度（主要是 ΔpH）驱动 CF₀CF₁ ATP 合酶；14个 c 亚基时每个 ATP 4.67 H⁺。线性流每2个 NADPH 给出12个 H⁺ 与2.57个 ATP；卡尔文循环每2个 NADPH 需要3个 ATP，故循环电子流补上差额——总计每个 CO₂ 约9个光子。
- **卡尔文-本森循环**：Rubisco 羧化 RuBP 得两分子 3-PGA；还原得三碳糖磷酸；再生恢复 RuBP。成本：每 CO₂ 3个 ATP 与2个 NADPH。三碳糖磷酸合成蔗糖（输出）与淀粉（夜间使用）。
- Rubisco 既慢（2–5 s⁻¹）又多；光通过基质 pH、Mg²⁺、硫氧还蛋白与 Rubisco 活化酶激活循环。
- 叶片光响应曲线以量子产额上升、在 $A_\text{max}$ 饱和、在补偿点 $\approx R_d/\phi$ 处穿过零。过剩的光由 NPQ 与叶黄素循环耗散；PSII 不断被修复。
:::

这套叙述中的弱点是 Rubisco，它还会与氧气反应。那要付出什么代价，C4 与 CAM 植物如何规避，是 [[plant-biology/c4-and-cam]] 的主题。

::: exercise 铁氧还蛋白到 NADP⁺ {level=1 check="-19.3"}
还原型铁氧还蛋白的 $E^{\circ\prime} = -0.42$ V。两个铁氧还蛋白还原 NADP⁺（$-0.32$ V）的 $\Delta G^{\circ\prime}$，以每摩尔 NADPH 计、保留一位小数是多少（kJ）？
::: solution
$\Delta E = -0.32 - (-0.42) = +0.10$ V；$\Delta G = -2\times96.485\times0.10 = -19.3$ kJ mol⁻¹。这步是下坡，FNR 要能工作就必须如此。
:::

::: exercise 另一种转子 {level=2 check="1.5"}
假设某叶绿体的 ATP 合酶的环有12个 c 亚基。线性流每 O₂ 仍给出12个 H⁺，线性流的 ATP:NADPH 之比是多少？
::: solution
每个 ATP $12/3 = 4$ 个 H⁺，所以12个 H⁺ 每2个 NADPH 造3个 ATP：比率1.5，恰是卡尔文-本森循环所需。用真实的 c₁₄ 环，比率是1.29，于是要靠循环流补足。
:::

::: exercise 量子需求 {level=2 check="10"}
弱光下，一片叶子吸收200 µmol 光子 m⁻² s⁻¹，其总 O₂ 释放（净 O₂ 释放加暗呼吸）为20 µmol m⁻² s⁻¹。每释放一个 O₂ 它用掉多少个光子？
::: solution
$200/20 = 10$ 个光子每 O₂（量子产额0.10个 O₂ 每光子），接近 [[#ex-budget]] 中理论的8–9，差额来自非光合色素的吸收与其他损耗。

::: exercise 解剖电子链 {level=2}
分离的类囊体在四种条件下照光，记录被测过程的速率。解释各结果。(a) 以铁氰化物为电子受体，有 O₂ 释放。(b) 铁氰化物加 DCMU，无 O₂ 释放。(c) 有 DCMU，以抗坏血酸加 DCPIP 为电子供体、甲基紫精为受体（它把电子交给 O₂），光中氧气被*消耗*。(d) 以水为供体、NADP⁺ 为受体，加 ADP 与磷酸，再加一个解偶联剂（使膜对质子通透）会停止 ATP 合成，却*加快* NADP⁺ 的还原速率。
::: solution
(a) 铁氰化物从链上（约在质体醌/PSI 附近）接受电子，PSII 因此能氧化水：Hill 反应。
(b) DCMU 阻断 Q_B 位点，电子无法离开 PSII，水的氧化停止。
(c) 抗坏血酸的电子经 DCPIP 在质体蓝素/细胞色素 b₆f 水平进入，位于 DCMU 阻断点的下游；PSI 把它们推给甲基紫精，后者还原 O₂（生成超氧阴离子，继而 H₂O₂）。O₂ 被消耗说明 PSI 独立于 PSII 工作。
(d) 解偶联剂耗散质子梯度。没有梯度 ATP 合酶不能造 ATP；但梯度本来会拖慢电子传递（高 ΔpH 限制细胞色素 b₆f 处质体醌醇的氧化——“光合控制”），移除它反而让电子流得更快。
:::
:::

::: exercise 闪光图样 {level=2}
暗适应的类囊体接受一连串短促的饱和闪光。(a) 解释为什么 O₂ 主要在第3、7、11、…次闪光释放。(b) 长时间黑暗后，约25 %的复合体处于 S₀、75 %处于 S₁。对每个群体，你会预期 O₂ 出现在哪些闪光？这种混合如何促成了振荡的衰减？(c) 若每次闪光有10 %的概率未能推进 S 态，你预期会怎样？
::: solution
(a) 放氧复合体必须先攒够四个氧化当量（S₀ → S₄）才释放 O₂ 并返回 S₀。暗适应的复合体停在 S₁，所以在第三次闪光及此后每隔四次到达 S₄。
(b) S₁ 复合体在第3、7、11…次闪光出 O₂；S₀ 复合体在第4、8、12…。两个群体步调错开，第3与第4次的产量因此混杂，振荡的反差被削平。
(c) 漏击逐渐使群体失步：几轮之后，复合体散布于所有 S 态，每闪的产氧量收敛于一个常数（每个复合体最大值的四分之一），于是振荡衰减殆尽。对衰减拟合可得出漏击概率（通常约10 %）。
:::

::: exercise 阳叶与阴叶 {level=2}
测量山毛榉冠层顶部与基部的叶片。阳叶：补偿点25 µmol m⁻² s⁻¹，约1200处饱和，$A_\text{max}$ 15；阴叶：补偿点5，约300处饱和，$A_\text{max}$ 5 µmol m⁻² s⁻¹。两者的量子产额都是0.05。(a) 从 Rubisco、电子传递能力与呼吸解释这些差异。(b) 在50 µmol m⁻² s⁻¹ 下哪片叶碳增益更多？在1000呢？(c) 一棵树造两种叶而不是一种，为何合理？
::: solution
(a) 阳叶单位面积在 Rubisco、电子载体与 ATP 合酶上投入更多氮（它们更厚，栅栏组织更多），抬高 $A_\text{max}$ 与饱和点，但也抬高呼吸——故补偿点更高。阴叶很薄，单位 Rubisco 的叶绿素更多（天线更大），能力小，呼吸低。
(b) 50时：阴叶，它已在自己补偿点之上；阳叶尚在自己的补偿点附近，几乎无增益甚至亏损。1000时：阳叶，它接近15的平台，而阴叶早在5处饱和。
(c) 投入光合能力的氮与碳，只有在光强足以利用它时才划得来。让能力匹配当地的光环境，能在给定氮投入下最大化整株冠层的碳增益——冠层光合模型预言了这种最优化，观测也大致相符。
:::

::: exercise 氧的来源 {level=3}
1941年，Ruben 及同事让 *Chlorella* 先在富 ¹⁸O 的水中、普通 CO₂ 下生长，再在普通水中、富 ¹⁸O 的碳酸氢盐/CO₂ 下生长。(a) 什么结果能表明光合的 O₂ 来自水？(b) 为什么总反应式左边写12个 H₂O 而右边6个，而不是左边只写6个？(c) 一个麻烦是溶液中的 CO₂ 与水之间氧原子会交换（碳酸酐酶催化）。这种交换会如何影响实验？如何减轻？
::: solution
(a) 两组实验中，释放 O₂ 的 ¹⁸O 富集度都应与水的相符，而不与 CO₂ 的相符。
(b) 6个 O₂ 的全部12个氧原子必须来自水，这就需要12个 H₂O；6个 CO₂ 的12个氧原子则进入糖（6个）与6个新生水分子。写成 $6\mathrm{CO_2} + 6\mathrm{H_2O} \to \mathrm{C_6H_{12}O_6} + 6\mathrm{O_2}$ 虽配平了原子，却掩盖了氧的来源。
(c) 交换倾向于把标记在 CO₂ 与水之间拉平，所以在长时间实验中，无论起初标记哪种化合物，O₂ 都会获得标记，使两者的区分模糊。缩短实验、在测 O₂ 的同时测底物池的标记、并在交换缓慢的条件下工作，可把问题降到最低；后来用时间分辨取样的质谱实验证实 O₂ 来自水。
:::

::: exercise 冠层的量子需求 {level=3}
盛夏的一块玉米地，叶面积指数为4（每平方米地面4 m² 叶），12小时白昼内叶片平均每平方米叶每秒固定10 µmol CO₂（总量）。(a) 计算每日总碳增益：以摩尔 CO₂、克碳与克干物质计（设每克干物质含0.45 g 碳），每平方米地面。(b) 这12小时内光合有效辐射平均1000 µmol m⁻² s⁻¹，冠层吸收其中90 %。冠层的表观量子需求——每个固定的 CO₂ 对应吸收的光子数——是多少？(c) 一株单叶玉米在弱光下每个 CO₂ 约需16个光子（C4 光合要额外 ATP；见 [[plant-biology/c4-and-cam]]）。冠层为何需要更多？
::: solution
(a) 每平方米地面 $10\times4 = 40$ µmol CO₂ s⁻¹；$12\times3600 = 43{,}200$ s 内共 $1.73$ mol CO₂ m⁻² day⁻¹，即 $20.7$ g 碳，或 $20.7/0.45 = 46$ g 干物质每平方米每天，这还没有扣除呼吸。（扣呼吸后，好玉米田20–40 g m⁻² day⁻¹ 的净生长速率与此相符。）
(b) 吸收的光子：$0.9\times1000 = 900$ µmol m⁻² s⁻¹；每个 CO₂ 的光子数 $= 900/40 = 22.5$。
(c) 最低需求只适用于光响应曲线的线性光限制段（[[#prop-light]]）。正午的冠层里，上层叶接近光饱和：它们多吸收的光子几乎不增加 CO₂ 固定，而被非光化学淬灭耗为热。只有遮阴的下层叶才在最低需求附近工作。让光铺洒到多层叶片上——高叶面积指数的冠层正是如此——会使冠层更接近最低值——这也是立叶作物品种（让光透入更深）产量更高的原因之一。
:::
