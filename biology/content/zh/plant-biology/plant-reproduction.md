我们吃的东西大多是植物繁殖的产物。小麦、水稻与玉米的籽粒是果实，每个含一粒种子；菜豆、豌豆与扁豆是种子；苹果、番茄、柑橘与黄瓜是果实；橄榄、向日葵与油菜的油则贮藏在种子与果实中，供养植物的下一代。每一样东西的背后都是一串被子植物特有的事件：花由茎尖分生组织形成；花粉经风或动物带到一朵亲和的花的柱头上；花粉管穿过雌蕊的组织，把两个精细胞送进胚囊；一个精细胞与卵细胞结合，另一个与中央细胞结合，这**双受精**同时产生胚与它的食物供应——胚乳；胚珠成为种子，子房成为果实；种子被散布、等待——有时好几年——在条件合适时萌发。

本章沿着这一序列展开。我们从花发育的遗传控制讲起——**ABC(E) 模型**是其总结——随后依次讲雌雄配子体的形成、传粉与防止自花授粉的机制、花粉管之旅、双受精与胚乳奇特的遗传学。最后讲种子与果实——它们的发育、休眠、寿命与散布——以及萌发。定量线索包括自交不亲和的遗传学、胚乳的倍性算术、风传播种子与贮藏中种子活力的衰减。世代交替与被子植物生活史的基本结构已在 [[diversity-of-life/land-plants]] 引入，光周期、温度与成花素对开花时间的调控在 [[plant-biology/plant-responses]]。

## 花的形成

当茎尖分生组织收到开花信号——经韧皮部运来的 FT 蛋白——它便成为花序分生组织，其侧面的原基不再形成叶，而成为**花分生组织**。两个转录因子 **LEAFY**（LFY）与 **APETALA1**（AP1）在 *Arabidopsis thaliana* 中赋予花分生组织身份：*lfy* 突变体中花被多叶的枝取代。与茎尖分生组织不同，花分生组织是**有限的**：它以同心圆方式产生固定的一套器官——**轮**（whorl）——然后停止。

一朵典型的花有四轮：最外是**萼片**（合称花萼），保护花蕾；**花瓣**（花冠），常着色以招引传粉者；**雄蕊**，每枚是着生于花丝顶端的花药，在其中产生花粉；中央是**心皮**，在许多物种中合生成**雌蕊**，由接受花粉的柱头、花柱与含**胚珠**的子房组成。这四类器官都是变态叶——Goethe 在1790年的洞见，遗传学予以证实：去掉决定花器官身份的基因，花就由叶构成。

### ABC(E) 模型

1980年代末，Elliot Meyerowitz 团队在 *Arabidopsis* 上与 Enrico Coen 团队在金鱼草（*Antirrhinum majus*）上研究了**同源异型突变体**——其中一类花器官被另一类取代。突变体分为三类，各影响相邻两轮；1991年，Coen 与 Meyerowitz 提出一个简单的组合模型来解释它们。

::: definition 花器官身份决定的 ABC(E) 模型 {#def-abc}
三类器官身份基因在花分生组织的重叠结构域中表达：**A** 在第1与第2轮，**B** 在第2与第3轮，**C** 在第3与第4轮。它们的组合指定器官：

- 仅 A → **萼片**（第1轮）；
- A + B → **花瓣**（第2轮）；
- B + C → **雄蕊**（第3轮）；
- 仅 C → **心皮**（第4轮）。

A 与 C 相互拮抗：A 活性在第1、2轮阻止 C，C 在第3、4轮阻止 A；一方失去，另一方便扩展到全部四轮。C 活性还终止花分生组织。**E** 类（SEPALLATA）基因与 A、B、C 一起在四轮中都是必需的；没有它们，一切器官都发育成萼片状的叶。在 *Arabidopsis* 中，A = *APETALA1* 与 *APETALA2*；B = *APETALA3* 与 *PISTILLATA*；C = *AGAMOUS*；E = *SEPALLATA1–4*。
:::

这些基因大多编码 **MADS-box** 转录因子，以四聚体的形式结合 DNA：A、B、C 与 E 蛋白的不同组合构成“花四聚体”（Günter Theißen，2001），分别识别各类器官的靶基因——组合密码的分子版本。

::: example 预测同源异型突变体 {#ex-abc}
用 [[#def-abc]]，预测下列突变体第1–4轮的器官：（a）B 类突变体（*ap3*）；（b）C 类突变体（*ag*）；（c）A 类突变体（*ap2*）；（d）*ap3 ag* 双突变体；（e）同时失去 A、B 与 C 活性的三突变体。
::: solution
（a）无 B：第1轮 A → 萼片；第2轮 A → 萼片；第3轮 C → 心皮；第4轮 C → 心皮。**萼片、萼片、心皮、心皮。**

（b）无 C 时 A 扩展到全部轮：第1轮 A → 萼片；第2轮 A + B → 花瓣；第3轮 A + B → 花瓣；第4轮 A → 萼片。又因 C 通常终止分生组织，花心继续产生更多轮：一座“花中有花”，**萼片、花瓣、花瓣**，如此重复不绝——许多园艺月季与山茶的重瓣花常源于 C 功能减弱。

（c）无 A 时 C 扩展：第1轮 C → 心皮；第2轮 B + C → 雄蕊；第3轮 B + C → 雄蕊；第4轮 C → 心皮。**心皮、雄蕊、雄蕊、心皮。**（*Arabidopsis* *ap2* 突变体的外层器官确为心皮状。）

（d）无 B、无 C，A 在全部轮：**每一轮都是萼片**，且生长无限。

（e）完全无器官身份：**每一轮都是叶**——Goethe“花是变态叶”的主张就此可见（Bowman、Smyth 与 Meyerowitz，1991）。

一张表推出四条预测，全部得到证实——这正是模型的力量所在。（A 功能后来被证明普适性最差：在金鱼草与许多其他物种中，与 *AP1* 和 *AP2* 对应的基因并不表现为明确的 A 类基因，A 功能仍有争议。）
:::
:::

C 功能同样终结这朵花。在分生组织中央表达的 *AGAMOUS* 在心皮起始后（经锌指蛋白 KNUCKLES）抑制 *WUSCHEL*，停止干细胞更新（[[plant-biology/plant-form#def-wus-clv]]）。这就是 *ag* 花生长无限的原因。

## 配子体

被子植物在微小的配子体中产生配子——雄配子体是花粉粒，雌配子体是**胚囊**——配子体在孢子体的花药与胚珠内形成（[[diversity-of-life/land-plants#def-alternation]]）。

**花粉。**每枚花药内，二倍体小孢子母细胞经减数分裂产生四个一组的单倍体小孢子四分体。每个小孢子经有丝分裂不对称地分成一个大的**营养细胞**与一个小的**生殖细胞**，后者被营养细胞吞入。生殖细胞再分裂一次形成**两个精细胞**：约30 %的被子植物科（包括禾本科与 *Arabidopsis*）在花粉释放前即完成（三细胞花粉），其余物种则在释放后于花粉管中完成（二细胞花粉）。花粉壁内层为纤维素与果胶，外层为**花粉外壁**（exine），由孢粉素构成，雕有各物种特有的纹饰——其特征之鲜明、质地之耐久，使化石花粉足以记录往昔的植被（孢粉学）。花药壁最内层的绒毡层滋养发育中的花粉，并在其表面沉积物质。

**胚囊。**每个胚珠中，一个二倍体大孢子母细胞经减数分裂；在最常见的安排中（*Polygonum* 型，见于约70 %的被子植物），四个大孢子中三个死亡，幸存的一个进行三轮不伴随成壁的有丝分裂，产生八个单倍体核。随后形成细胞壁，得到七细胞的胚囊：靠近胚珠开口（珠孔）的一端是**卵细胞**及其两侧的两个**助细胞**；中央是含两个**极核**的大**中央细胞**（许多物种中极核在受精前融合）；另一端是三个**反足细胞**。胚珠自身的二倍体组织——珠心与将来成为种皮的珠被——包在其外。

## 传粉

**传粉**是花粉从花药到柱头的转移；它与受精不是一回事，后者在其后数小时至数月才发生（某些栎属植物超过一年）。约87.5 %的被子植物物种由动物传粉（Jeff Ollerton、Rachael Winfree 与 Sam Tarrant，2011）——主要是昆虫，但也有鸟类、蝙蝠与其他哺乳动物——其余大多由风传粉（禾本科、许多温带树木如栎、桦与榛），偶尔由水传粉。花的性状常与传粉者相关：虫媒花多为蓝色或黄色，具紫外导纹与落脚平台；鸟媒花红色、筒状、无香而蜜丰；蝠媒花大而色淡、夜间开放、带霉味；风媒花小而无花瓣，花药外露、产生海量轻花粉，柱头呈羽状。这类**传粉综合征**是倾向而非规则——许多花被多种动物访问。

### 避免自花授粉

大多数花是**两性花**，兼具雄蕊与心皮，这使自花授粉轻而易举。自交有好处——在配偶或传粉者稀缺时保证繁殖——但若干代之后会导致**近交衰退**，即纯合有害隐性等位基因的后代适合度降低。植物进化出许多促进异交的途径：把两性在时间上分开（**雌雄异熟**：花药与柱头不同时成熟）或在空间上分开（**雌雄异位**；**花柱异长**，即 Darwin 研究过的报春花长柱型与短柱型；或一植株上雌雄花分开，**雌雄同株**，如玉米；或在不同植株上，**雌雄异株**，见于约6 %的物种，如冬青、柳与猕猴桃）。最精确的是遗传机制。

::: definition 自交不亲和性 {#def-si}
**自交不亲和性**（SI）指可育两性花植株识别并拒绝自身花粉（以及共享相同等位基因的植株花粉）的遗传控制能力，通常由单一的多等位 **S 位点**决定。

- 在**配子体型自交不亲和**（GSI）中，花粉的不亲和表型由其自身的单倍体基因型决定：若花粉的 *S* 等位基因与柱头两条 *S* 等位基因之一相同，即被拒绝。在茄科、蔷薇科与车前科，柱头产生一种细胞毒性核糖核酸酶（S-RNase），进入所有花粉管；带不匹配等位基因的花粉用 *S* 位点编码的 F-box 蛋白将其解毒，而自交花粉管死在花柱中。
- 在**孢子体型自交不亲和**（SSI）中，如十字花科，花粉的表型由产生它的那株二倍体的基因型决定，因为花粉外套蛋白 SCR/SP11 由花药的绒毡层合成。柱头受体激酶 SRK 结合同一单倍型的 SCR，在柱头表面启动排斥；等位基因间的显隐性关系使结局更为复杂。
:::

::: example 配子体型自交不亲和中的亲和性 {#ex-gsi}
在一个配子体型自交不亲和的物种中，预测下列交配（♀ × ♂）中能完成受精的花粉比例与后代基因型：（a）$S_1S_2 \times S_1S_2$；（b）$S_1S_2 \times S_1S_3$；（c）$S_1S_2 \times S_3S_4$。
::: solution
（a）父本产生数目相等的 $S_1$ 与 $S_2$ 花粉；两者都与柱头匹配而被拒绝：**0 %亲和**，不结籽。自花授粉与此交配相同。

（b）$S_1$ 花粉被拒绝；$S_3$ 花粉能生长。**50 %亲和**；后代从卵细胞得到 $S_1$ 或 $S_2$，从花粉得到 $S_3$：$S_1S_3$ 与 $S_2S_3$ 按1 : 1分离。后代不可能在 *S* 位点纯合，也不可能从花粉获得父本的 $S_1$ 等位基因。

（c）$S_3$ 与 $S_4$ 花粉都亲和：**100 %**；后代 $S_1S_3$、$S_1S_4$、$S_2S_3$、$S_2S_4$ 各占相等比例。
:::
:::

一个群体需要多少个 *S* 等位基因？若有 $k$ 个等位基因，一个植株带其中两个，而一粒随机花粉若携带其中之一即被拒绝。

::: proposition 配子体型 SI 下的亲和花粉 {#prop-gsi}
在一个有 $k$ 个等位基因、频率相等、每个植株都杂合（GSI 所强制）的群体中，随机选取的供体的一粒花粉与随机选取的柱头亲和的概率是

$$
p_\text{compatible} = 1 - \frac{2}{k}.
$$ {#eq-gsi}

稀有等位基因占优势，因为携带它的花粉几乎被所有柱头接受；这种**负频率依赖选择**使等位基因数目增加，直到与漂变相平衡（Sewall Wright，1939）。
:::

::: proof
一粒花粉携带一个等位基因，等可能为 $k$ 个中的任何一个（由对称性，因各等位基因频率相等）。柱头携带两个不同的等位基因。花粉若携带这两个之一即被拒绝，概率为 $2/k$，否则被接受。
:::

$k = 5$ 时，只有60 %的花粉亲和；$k = 30$ 时，93 %。茄科与十字花科的自然群体通常携带数十个 *S* 等位基因；古老的跨物种多态性表明，这些等位基因可维持数百万年——比物种本身还古老。

## 受精

### 花粉管之旅

落在可育柱头上的亲和花粉粒从柱头吸水、萌发并伸出一根**花粉管**——一个只在顶端生长的细胞，经由柱头与花柱的传导道被导向胚珠。花粉管是已知生长最快的细胞之一，玉米中约为每小时厘米量级，而其花粉管有时须穿越20–30 cm 长的玉米须。顶端生长依赖于顶端胞质 Ca²⁺ 的陡峭梯度、壁物质的胞吐以及细胞质流；营养核与精细胞在顶端附近随行，花粉管较老的部分被胼胝质塞封隔。

近胚珠处，花粉管循化学信号而行。在被子植物 *Torenia fournieri* 中——其胚囊突出于胚珠之外、可直接观察——Satohiro Okuda、Tetsuya Higashiyama 及同事（2009）证明，助细胞分泌小分子富半胱氨酸肽 **LURE**，吸引花粉管；用激光摧毁助细胞，吸引即消失。花粉管经珠孔进入胚囊，长入一个助细胞；该助细胞接纳花粉管，使之破裂并死亡，释放出两个精细胞。

### 双受精

::: definition 双受精 {#def-double}
在**双受精**中，一个精细胞与卵细胞融合，形成二倍体**合子**，发育为胚；另一个与中央细胞融合——中央细胞的核含两个极核——形成（通常为三倍体的）初生**胚乳**核，发育为胚乳，即种子的贮藏组织。双受精由 Sergei Nawaschin（1898，在 *Lilium* 与 *Fritillaria* 中）与 Léon Guignard（1899）各自独立发现。
:::

因此，*Polygonum* 型胚囊的胚乳中，每套父源基因组对应两套母源基因组：**2m : 1p**。这一比例意义重大，因为许多基因在胚乳中只表达双亲拷贝中的一份——**基因组印记**。印记基因在某一亲本的等位基因上被表观遗传标记（DNA 甲基化、Polycomb 组蛋白甲基化）沉默，这些标记在中央细胞或精子中建立。在 *Arabidopsis* 中，Polycomb 基因组 *MEDEA* 只从母源等位基因表达；凡母本携带 *medea* 的突变种子，胚乳过度增殖并败育，无论父本基因型如何。David Haig 与 Mark Westoby（1989）的**亲代冲突**（亲缘）理论提出，印记之所以进化，是因为父源基因有利于让其种子从母体多取资源，而母源基因有利于把资源在其种子间均匀分配；父源表达的基因倾向于促进胚乳生长，母源表达的基因则加以抑制。

::: example 不同倍性杂交与胚乳 {#ex-endosperm}
同种的二倍体（$2x$）与四倍体（$4x$）植株正反交。求（a）$2x$ ♀ × $2x$ ♂、（b）$4x$ ♀ × $2x$ ♂、（c）$2x$ ♀ × $4x$ ♂的胚与胚乳的倍性，以及胚乳中母源与父源基因组之比。你对种子发育作何预测？
::: solution
每个配子携带亲本染色体组的一半；中央细胞携带雌配子基因组的两份拷贝。

（a）卵细胞 $x$，中央细胞 $2x$，精子 $x$。胚 $2x$；胚乳 $3x$；比例 **2m : 1p**，正常。

（b）卵细胞 $2x$，中央细胞 $4x$，精子 $x$。胚 $3x$；胚乳 $5x$；比例 **4m : 1p**，母源过量。预测：胚乳小、提早细胞化、种子小。

（c）卵细胞 $x$，中央细胞 $2x$，精子 $2x$。胚 $3x$；胚乳 $4x$；比例 **2m : 2p** = 1 : 1，父源过量。预测：胚乳过度增殖而不能细胞化；常常种子败育。

这些正反交相反的效果——在玉米、*Arabidopsis* 与许多其他物种中均有观察到（不同倍性植株间杂交的**三倍体阻断**）——表明胚乳敏感的不是倍性本身，而是母源与父源基因组的平衡——若印记基因在此起作用，这正是预期。这一屏障促进了新多倍体与其二倍体亲本之间的生殖隔离。
:::
:::

## 种子

受精后，胚珠发育为**种子**，由三个起源与基因型不同的部分组成：**胚**（来自合子；二倍体，兼具父母基因组）；**胚乳**（来自受精的中央细胞；通常三倍体）；以及**种皮**（来自胚珠的珠被；纯粹的母本组织）。

**胚胎发生。**在 *Arabidopsis* 中，合子伸长并不对称分裂为一个小的**顶细胞**——几乎发育出整个胚——与一个较大的**基细胞**，后者形成**胚柄**——一根把胚推入胚乳并转运养料的柄——其最上方的一格（hypophysis）则参与根分生组织的形成。胚依次经历球形、心形与鱼雷形阶段，其间主轴（茎尖分生组织、下胚轴、根分生组织）、子叶与径向的组织层被建立——如同植物发育的许多环节，由生长素流导向（[[plant-biology/plant-hormones]]）。在豌豆、菜豆等许多真双子叶植物中，胚乳在种子发育期间被消耗，食物贮藏最终落在肥大的子叶里；而在禾谷类与蓖麻中，胚乳作为主要贮藏组织保留下来。

**成熟与干燥。**发育后期，种子积累贮藏物质——淀粉、蛋白贮藏液泡中的贮藏蛋白、油体中的油脂——随后在多数物种中**干燥**至含水量约5–15 %，进入代谢静息。成熟过程中 ABA 上升，诱导晚期胚胎发生丰富（LEA）蛋白与糖类，在干燥状态下保护膜与蛋白，并阻止提前萌发（胎生）。耐干燥的种子为**正常型**；**顽拗型**种子——如栎、鳄梨、可可与许多热带树木——一经干燥便死亡，无法在常规种子库中贮藏。

**休眠。**种子若在本来允许萌发的条件下不萌发，即为**休眠**。休眠把萌发在时间与空间上铺开，保证幼苗出现在正确的季节——冬季之后，或降雨之后——并保证第一批幼苗失手时仍有一些种子留在土中作为**种子库**。休眠可以由种皮强加（坚硬的种皮不透水，需经磨损或火烧打破），或由胚自身的生理决定——受维持休眠的 ABA 与促进萌发的赤霉素之间的平衡控制——并可由低温、温暖的干藏（后熟）、经由光敏色素起作用的光（[[plant-biology/plant-responses]]）、火烧后烟雾中的丁烯内酯类物质（karrikins）或硝酸根解除。

### 种子能活多久？

干燥的种子会老化：其膜、蛋白质与 DNA 累积损伤，活力下降。Richard Ellis 与 Eric Roberts（1980）发现，对在恒定含水量与温度下贮藏的正常型种子，一批种子中个体寿命的分布近似正态。

::: proposition 种子活力方程（经验性） {#prop-viability}
对恒定条件下贮藏的一批种子，贮藏期 $p$ 之后仍存活的种子比例为

$$
V(p) = \Phi\!\left(K_i - \frac{p}{\sigma}\right),
$$ {#eq-viability}

其中 $\Phi$ 是标准正态累积分布函数，$K_i$ 是该批种子初始活力在概率单位（probit，正态偏差）标度上的值，$\sigma$ 是种子死亡时间分布的标准差，取决于物种，并随贮藏温度与含水量的升高而急剧减小。半数种子死亡的时间为 $p_{50} = K_i\sigma$。这是一个拟合的经验关系，并非由机制推出。
:::

::: example 种子库的贮藏计划 {#ex-viability}
一批小麦种子的初始活力 $K_i = 2.5$ 概率单位（发芽率99.4 %），在该库的贮藏条件下 $\sigma = 10$ 年。（a）20年后发芽率是多少？（b）活力何时降到50 %？（c）该库的规矩是当活力降到初始值的85 %时更新样品（种下去收新种）。这批种子何时应更新？
::: solution
（a）$V = \Phi(2.5 - 20/10) = \Phi(0.5) = 0.69$：**69 %**。

（b）$K_i - p/\sigma = 0$ 时 $V = 0.5$，即 $p_{50} = K_i\sigma = 25$ 年。

（c）99.4 %的85 %为84.5 %，即 $\Phi(1.015)$。解 $2.5 - p/10 = 1.015$：$p = 14.9$ 年，故约**15年**后。头十年活力保持在95 %以上，随后降得越来越快，因为正态寿命分布的主体开始到达——这就是发芽率必须定期测定的原因：一批看似完全健康的种子，可能已临近曲线的陡段。
:::
:::

在理想条件下，种子可以维持极久。一枚出自马萨达遗址发掘、放射性碳测年为约2,000年前的海枣种子于2005年萌发（Sarah Sallon 及同事，2008）；一株 *Silene stenophylla* 则经组织培养，从西伯利亚永久冻土中保存了约32,000年的幼果组织再生而来（Svetlana Yashina 及同事，2012）。种子库利用的是同一物理学：斯瓦尔巴全球种子库（2008年启用）与英格兰韦克赫斯特的千年种子库，都在贮藏干燥至低含水量、冷冻于约−18 °C 的正常型种子；在此条件下，活力方程预言许多物种的种子寿命可达数十年至数百年。

::: application 种子、杂种与传粉者
现代农业依赖对植物繁殖的控制。**杂种**作物——绝大多数玉米、中国的大量水稻、高粱、向日葵与许多蔬菜——利用**杂种优势**，即自交系之间 F₁ 杂种的旺盛长势；要大规模生产杂交种子，育种者必须防止母本自花授粉：人工或机械去掉玉米的雄穗，或利用**细胞质雄性不育**——一种线粒体编码的花粉发育缺陷——配合细胞核恢复基因。杂种的种子不能真实遗传，故农户每年购买新种。按作物种类数计，约四分之三的全球主要粮食作物的生产得益于昆虫传粉，尽管按产量计它们约占作物产量的三分之一（Alexandra-Maria Klein 及同事，2007）；因此野生与家养传粉者的减少对水果、坚果与蔬菜供应的威胁大于主粮——后者大多风媒或自花授粉。而种子库——全世界1,700余个基因库收藏着约700万份样品（FAO，2010年代数据）——保存着作物及其野生近缘种的遗传多样性，以防丧失。
:::

## 果实与散布

**果实**是成熟的子房，有时连同其他花的部分；其壁即**果皮**（pericarp），由子房壁发育而来。果实的生长由受精触发，经发育中种子制造的激素（生长素与赤霉素）介导；不经受精而发育的果实为**单性结实**（无籽香蕉、某些黄瓜与番茄，以及经赤霉素处理的葡萄）。果实分为**肉质果**（浆果；核果，如樱桃与橄榄；梨果，如苹果，其果肉主要由花托发育而来）与**干果**；干果或**开裂**（开裂散籽：豆类的荚果、罂粟的蒴果、拟南芥的长角果），或**不开裂**（坚果、瘦果、禾本科的颖果即谷粒）。

种子与果实的散布靠**风**（蒲公英具冠毛的瘦果、槭与白蜡的翅果、兰科粉尘状的种子）、**水**（椰子）、**动物**——或被吃下（肉质果，种子经消化道后仍存活：endozoochory，体内传播），或挂在兽毛与鸟羽上（钩刺：epizoochory，体表传播），或由被油质体（elaiosomes）吸引的蚂蚁搬运——或**弹射**，靠爆发式开裂（荆豆的荚、凤仙花属 *Impatiens* 的蒴果、喷瓜）。散布减轻与亲本及同胞的竞争，逃离在亲本附近累积的病虫害，并拓殖新的地点。

风能载种子多远？一个简单的估计把种子看作在均匀的水平风中以恒定速度下落。

::: proposition 风传播距离的弹道估计 {#prop-dispersal}
一粒种子自高度 $H$ 释放，在速度为 $U$ 的稳定水平风中以其终端速度 $v_t$ 下落，其水平行程为

$$
d = \frac{H\,U}{v_t}.
$$ {#eq-dispersal}

假设为：种子立即达到终端速度；风不随高度变化且稳定；无垂直方向的气流。真实的近地面风减弱且湍动；上升气流能把轻的种子带走几公里，故此式描述的是典型距离，而非散布分布的长尾。
:::

::: example 槭、蒲公英与风 {#ex-dispersal}
（a）一枚槭树翅果（终端速度约1 m s⁻¹）在5 m s⁻¹ 的风中自15 m 高处释放。（b）一枚蒲公英瘦果（终端速度约0.3 m s⁻¹）在同一阵风里从0.3 m 高的花序上释放。估算散布距离。（c）为什么蒲公英传播的远距离纪录比你的估计大几个数量级？
::: solution
（a）$d = 15\times5/1 = 75$ m。

（b）$d = 0.3\times5/0.3 = 5$ m。

（c）弹道模型忽略了湍流。具冠毛瘦果极低的终端速度意味着，即便是温和的上升气流——阵风、暖地上空的热对流——也能超过它，把种子向上托举；一旦升空，便可飞行数公里。一项对蒲公英飞行的研究（Cathal Cummins、Naomi Nakayama 及同事，2018）表明，冠毛产生稳定的脱落涡环，极大提高单位刚毛面积的阻力，以极少的材料把终端速度保持在低位。对散布依赖罕见远距离事件的事件物种，决定其对气候变化的拓殖与迁移的，是分布的尾部而非典型距离。
:::
:::

## 萌发

**萌发**始于干种子吸水（**吸胀**），终于胚根（胚胎的根）突破种皮。吸水分**三期**：第一期，干种子组织极低的衬质势驱动的快速增长；第二期，一段平台，其间代谢、DNA 修复与蛋白质合成重启，非休眠种子还为细胞扩张做好准备；第三期，胚根生长带动的再度吸水——严格说已是萌发后的事件。萌发期间，赤霉素与 ABA 的平衡决定结局：GA 诱导削弱胚根周围组织（许多物种中为胚乳帽）的酶并促进胚的生长，ABA 则两者都反对。

萌发后，幼苗动用贮备。禾谷类籽粒中，胚产生的赤霉素扩散到**糊粉层**，后者向淀粉胚乳分泌 α-淀粉酶、蛋白酶与其他水解酶；释放出的糖与氨基酸被盾片（禾本科的子叶）吸收，供给生长中的幼苗。从1960年代起在大麦上弄清的离体糊粉层对 GA 的响应，成为研究激素作用的经典体系，也是麦芽工业的基础（[[plant-biology/plant-hormones]]）。在油料种子中，贮藏的三酰甘油经**乙醛酸循环体**——过氧化物酶体的一种专门形式——中的乙醛酸循环转化为糖——这条途径动物没有，所以我们无法用脂肪制造糖。

幼苗以两种方式出土：**子叶出土**萌发（菜豆、向日葵）中，下胚轴伸长，把子叶举出地面转绿；**子叶留土**萌发（豌豆、玉米）中，子叶留在土下，上胚轴（禾本科为胚芽鞘）把茎往上推。出土之后，幼苗在光中去黄化（[[plant-biology/plant-responses]]），循环重新开始。

::: warning 传粉不是受精，果实也不是蔬菜
两种混淆很常见。其一，**传粉**（花粉送达柱头）与**受精**（配子在胚囊中融合）是分立的事件，中间隔着从数分钟到数月的花粉管生长；传粉可以没有受精（花粉不亲和、花粉管生长失败），果实可以两者都不需要而发育（单性结实）。其二，植物学上的“果实”指成熟的子房，无论口味如何：番茄、黄瓜、辣椒、茄子、豆荚、谷粒与坚果都是果实；“蔬菜”是烹饪范畴，无植物学含义。反过来，草莓在植物学上不是浆果：红色的果肉是膨大的花托，真正的果实是其表面那些小瘦果。
:::

::: quiz
某植物的花只有萼片与心皮，心皮占据第3与第4轮。按 ABC 模型，缺失哪种基因功能？
- [ ] A
- [x] B
- [ ] C
- [ ] E
::: solution
花瓣（A + B）与雄蕊（B + C）都需要 B 功能。没有它，第2轮只有 A（萼片），第3轮只有 C（心皮）：萼片、萼片、心皮、心皮。这正是 *Arabidopsis* 的 *apetala3* 与 *pistillata* 突变体、金鱼草的 *deficiens* 与 *globosa* 的表型。
:::
:::

::: history
Rudolf Jakob Camerarius 于1694年证明了植物的有性现象：桑等雌雄异株物种的雌株没有花粉便不结籽。Joseph Gottlieb Kölreuter 完成了首次系统的植物杂交（1761–1766），并描述了昆虫传粉；Christian Konrad Sprengel 的 *The Secret of Nature Revealed*（1793）把花的结构解读为对传粉者的适应；Darwin 的 *On the Various Contrivances by which British and Foreign Orchids are Fertilised by Insects*（1862）与 *The Different Forms of Flowers on Plants of the Same Species*（1877）发展了这一主题。Giovanni Battista Amici 于1823–1824年观察到花粉管；Eduard Strasburger 于1884年描述了被子植物的受精；Nawaschin（1898）与 Guignard（1899）发现了双受精。Johann Wolfgang von Goethe 的 *Versuch die Metamorphose der Pflanzen zu erklären*（1790）提出花器官是变态的叶；ABC 模型（Coen 与 Meyerowitz，1991）、SEPALLATA 基因（Soraya Pelaz、Martin Yanofsky 及同事，2000）与花四聚体模型为这一思想赋予了分子形式。
:::

## 小结

::: summary
- 花分生组织（LFY、AP1）生长有限，产生四轮：萼片、花瓣、雄蕊、心皮。**ABC(E) 模型**：A → 萼片，A + B → 花瓣，B + C → 雄蕊，C → 心皮；A 与 C 相互拮抗；E（SEPALLATA）全程必需；C（AGAMOUS）还通过抑制 WUS 终止分生组织。多为以四聚体起作用的 MADS-box 蛋白。
- 花粉（雄配子体）：一个营养细胞加两个精细胞。胚囊（雌配子体，*Polygonum* 型）：卵细胞、两个助细胞、含两个极核的中央细胞、三个反足细胞。
- 约87.5 %的物种由动物传粉。异交由雌雄异熟、雌雄异位、花柱异长、雌雄异株与**自交不亲和**促进：配子体型（S-RNase；花粉等位基因与柱头两者之一相同即被拒绝）或孢子体型（SRK–SCR）。设等频等位基因有 $k$ 个，则 $1 - 2/k$ 的花粉亲和。
- 花粉管在顶端生长，由助细胞的 LURE 导向。**双受精**：精细胞 + 卵细胞 → 合子；精细胞 + 中央细胞 → 三倍体胚乳（2m : 1p）。印记使胚乳对亲本基因组比例敏感（三倍体阻断）。
- 种子：胚、胚乳、母本的种皮；成熟时积累贮备、LEA 蛋白、干燥；休眠由 ABA/GA 控制，由低温、后熟、光或烟雾解除。活力按 $\Phi(K_i - p/\sigma)$ 衰减；正常型种子可入库，顽拗型不能。
- 果实是成熟的子房；散布靠风（$d \approx HU/v_t$，另有一条湍流的长尾）、水、动物与爆发式开裂。
- 萌发：三期吸水、GA 对 ABA、胚根突破；禾谷类中由 GA 诱导的糊粉层水解酶、油料种子中由乙醛酸循环动用贮备。
:::

至此植物生活史完成。植物彼此之间、与动物及其物理环境之间的相互作用，以及它们在生态系统中的角色，在 [[ecology]] 中展开。

说出玉米粒中下列各结构的倍性及基因组的亲本来源：（a）胚；（b）胚乳；（c）果皮（玉米粒的最外层）；（d）糊粉层。

::: exercise 更多同源异型突变体 {level=2}
用 ABC(E) 模型，预测第1–4轮的花器官：（a）*ap2 pi* 双突变体（失去 A 与 B）；（b）B 基因在全部四轮表达的植株；（c）*AGAMOUS* 在全部四轮表达的植株；（d）*sep1 sep2 sep3* 三突变体。
::: solution
（a）无 A，C 扩展到全部轮；无 B，处处只有 C：**四轮全是心皮**。
（b）第1轮 A + B → 花瓣；第2轮 A + B → 花瓣；第3轮 B + C → 雄蕊；第4轮 B + C → 雄蕊：**花瓣、花瓣、雄蕊、雄蕊**。
（c）处处有的 C 抑制 A：第1轮 C → 心皮；第2轮 B + C → 雄蕊；第3轮 B + C → 雄蕊；第4轮 C → 心皮：**心皮、雄蕊、雄蕊、心皮**（类似 A 突变体）。
（d）无 E 功能时 B 与 C 基因无法发挥作用：**各轮均为萼片状器官**，且花生长无限（Pelaz 及同事，2000）。
:::

::: exercise 孢子体型自交不亲和 {level=2}
一个具孢子体型 SI 的 *Brassica* 物种中，*S* 等位基因在花粉中表现显隐性：$S_1$ 对 $S_2$ 为显性。以基因型 $S_1S_2$ 的植株为父本，授粉给基因型 $S_2S_3$ 的柱头，其中 $S_2$ 与 $S_3$ 共显性。（a）花粉的不亲和表型是什么？（b）此交配亲和吗？（c）与配子体型 SI 下的结果对比。
::: solution
（a）$S_1S_2$ 植株的所有花粉粒都带二倍体绒毡层制造的花粉外套；$S_1$ 显性，故无论携带 $S_1$ 还是 $S_2$，每粒花粉都表现 $S_1$ 表型。
（b）柱头表达 $S_2$ 与 $S_3$；花粉表型 $S_1$ 不匹配：**全部花粉亲和**，且一半后代从花粉获得 $S_2$。
（c）在 GSI 下，$S_2$ 花粉（基因型 $S_2$）会被 $S_2S_3$ 柱头拒绝，只有 $S_1$ 花粉成功：50 %亲和。
:::

::: exercise 不同倍性的种子 {level=2}
在 *Arabidopsis* 中，二倍体母本与六倍体父本杂交产生的种子几乎总是败育，而六倍体母本与二倍体父本杂交产生的种子虽小却可育。（a）计算两种交配胚乳中母源与父源基因组之比。（b）用亲代冲突理论解释该结果。（c）为什么父源表达的印记基因中的一个突变可能挽救二倍体 × 六倍体的种子？
::: solution
（a）二倍体 ♀ × 六倍体 ♂：中央细胞 $2x$（$x$ 的两份拷贝），精子 $3x$ → $2m : 3p$。六倍体 ♀ × 二倍体 ♂：中央细胞 $2\times3x = 6x$，精子 $x$ → $6m : 1p$。
（b）父源过量（2 : 3）过度刺激胚乳增殖并延迟细胞化，使胚饥饿——败育。母源过量（6 : 1）抑制胚乳生长——种子小，但足以存活。这种不对称符合如下观念：父源表达的基因促进、母源表达的基因抑制胚乳的资源获取。
（c）若过量的父源基因组是通过过度表达促进生长的父源表达基因导致败育，那么除去这样一个基因（来自父本）就会降低有效的父源剂量；这类上位突变（例如父源表达基因 *ADMETOS* 及其他基因中的突变）确实被发现能挽救 *Arabidopsis* 的三倍体种子。
:::

::: exercise 及时更新 {level=2 check="12.5"}
一批种子的 $K_i = 2.0$ 概率单位（初始活力 $\Phi(2.0) = 97.7$ %），贮藏中 $\sigma = 12$ 年。种子库在活力降到初始值的85 %时更新。已知 $\Phi(0.957) = 0.831$，问这批种子多少年后应更新？保留一位小数。
::: solution
阈值为 $0.85\times0.977 = 0.831 = \Phi(0.957)$。解 $2.0 - p/12 = 0.957$：$p = 12\times1.043 = 12.5$ 年。
:::

::: exercise 问题出在传粉者吗？ {level=3}
一片破碎化草地中一种自交不亲和的野生花卉，小群体中每朵花的结实数少于大群体。生态学家比较自然开放授粉的花与用足量远处植株花粉人工授粉的花。大群体中，开放授粉与人工授粉的花分别有70 %与75 %的胚珠结实；小群体中分别为30 %与72 %。（a）这一比较对“小群体结实率低的原因”说明了什么？（b）对自交不亲和物种的小群体中开放授粉为何失效，给出两个互不排斥的解释，一个生态的，一个遗传的。（c）如何在实验上区分二者？
::: solution
（a）人工授粉使小群体的结实率恢复到大群体水平（72 %对75 %），可见植株能结籽：其繁殖受**花粉限制**——要么到达的花粉太少，要么其中亲和的太少。
（b）生态的：小而隔离的斑块招引的传粉者访问少，到达的花粉少。遗传的：小群体因漂变丢失 *S* 等位基因；等位基因少时，到达的花粉中有很大比例不亲和（[[#eq-gsi]]：$k = 4$ 时只有一半亲和），且许多植株共享等位基因——“S-Allee 效应”。
（c）在大、小群体中分别统计传粉者访问次数与柱头上沉积的花粉粒数（生态解释预言花粉粒更少）。然后分别用小群体*内部*（多个供体）的花粉与大群体的花粉做人工授粉：若群体内花粉尽管量大结实率仍低，则是交配不亲和在起作用。对各群体做 *S* 位点基因分型可直接得到 $k$。
:::

::: exercise 规划一座种子库 {level=3}
对许多正常型种子，在恒定的低含水量下，贮藏温度每降低20 °C，Ellis–Roberts 参数 $\sigma$ 约增大十倍（数据范围内的经验法则）。一批种子在20 °C 下 $K_i = 2.5$、$\sigma = 10$ 年。（a）估计20 °C 与−20 °C 下的 $p_{50}$。（b）有哪些实际原因限制种子库实际能依赖此类预测多久？（c）为什么顽拗型种子不能以此方式保存？有哪些替代办法？
::: solution
（a）20 °C 下，$p_{50} = 2.5\times10 = 25$ 年。−20 °C（低40 °C）下，$\sigma \approx 10\times10^2 = 1000$ 年，故 $p_{50} \approx 2500$ 年——只是个理论数字。
（b）这一关系被外推到远超其检验时长（数十年）的范围；它随物种而变，也随同种不同批次而变（初始质量、收获条件）；低温下的行为可能改变（例如种子细胞质中的脂质结晶或玻璃化转变）；而实际事故——冻柜故障、污染、贴错标签——在长时段上比化学更重要。定期做发芽测定与更新仍然必不可少。
（c）顽拗型种子一旦干燥到冷冻所需的低含水量便会死亡，而在高含水量下不结冰害便无法冷冻。替代办法包括：田间基因库与植物园中的活体收藏、离体组织培养，以及经允许玻璃化的特殊处理后，把剥离的胚或茎尖在液氮中玻璃化保存。
:::
