盛夏的一天，一棵大树把几百升水从土壤运到叶片，逆重力举高几十米，经过比头发丝还细的管道，而没有任何泵。这些水几乎全部——远超过95 %——从叶片蒸发进入空气。近似地看，植物是一根连接湿润土壤与干燥空气的灯芯，叶片是湿的一端，蒸发的水在这里与二氧化碳交换。与此同时，第二股更小更慢的流以正压经韧皮部朝相反方向运行，把糖从叶片运到根、果实与生长点。

本章解释这两股流。我们从**水势**讲起——这个单一的物理量告诉我们水将往哪个方向移动——并把它应用到细胞、土壤与空气。然后我们追随水从土壤进入根、沿木质部而上、经气孔而出，并检视**内聚力-张力学说**核心处那个非凡的论断：木质部中的水处于负压之下，像绳子一样被拉紧，而植物最大的水力风险就是这根绳子断裂。最后我们转向韧皮部与驱动糖从源到库的**压力流动**机制。涉及的细胞——管胞、导管分子、筛管分子与伴胞——已在 [[plant-biology/plant-cells-tissues]] 引入，根与叶的解剖在 [[plant-biology/plant-form]]。

## 水势

当压力差推动时，水以整体流动的方式移动；当两处水的浓度——更准确地说是化学势——不同时，水以扩散与渗透的方式移动。植物生理学家把这些统统合并为一个量纲为压强的量：单位体积的水的化学势。

::: definition 水势 {#def-psi}
系统中水的**水势** $\Psi$，是其化学势 $\mu_w$ 与同温、同参考高度、大气压下的自由纯水的化学势之差，除以水的偏摩尔体积 $\bar V_w$（$18.0\times10^{-6}$ m³ mol⁻¹）：

$$
\Psi = \frac{\mu_w - \mu_w^{\circ}}{\bar V_w}.
$$

以帕斯卡（常以兆帕，MPa）计量。大气压下的纯水有 $\Psi = 0$。**在恒温下，水自发地从水势高的区域移向水势低的区域**，无论是通过扩散、渗透还是整体流动。
:::

植物体内溶液的水势可以拆成若干项，每一项对应改变水的化学势的一种方式。

::: proposition 水势的组成 {#prop-psi}
对植物细胞、木质部或土壤中的水，

$$
\Psi = \Psi_s + \Psi_p + \Psi_g \;(+\,\Psi_m),
$$ {#eq-psi}

其中

- **溶质（渗透）势** $\Psi_s = -cRT$，对总渗透浓度为 $c$ 的稀溶液（van 't Hoff 关系；[[biochemistry/water-and-bonds]]），恒为零或负；
- **压力势** $\Psi_p$ 是超出大气压的静水压——膨压为正的细胞与韧皮部中为正，蒸腾植株木质部中为负（张力）；
- **重力势** $\Psi_g = \rho_w g h$，参考面之上每米高度约 $+0.0098$ MPa；
- **衬质势** $\Psi_m$（主要用于土壤与细胞壁）计入水与表面及毛细管的结合，为负。
:::

溶质项为负，因为溶解的溶质稀释了水、降低了它的化学势；压力项可正可负。膨压充盈的细胞是两者的平衡：其溶质势把水往里拉，其壁往外推，与纯水平衡时 $\Psi_p = -\Psi_s$。

::: example 水将往哪个方向移动？ {#ex-psi-cell}
20 °C 下一个马铃薯块茎细胞，细胞液渗透浓度0.30 osmol kg⁻¹，膨压0.50 MPa。(a) 求其水势。(b) 一块薯片放入纯水中，另一块放入0.20 mol kg⁻¹ 蔗糖溶液中。每种情况下水往哪个方向移动？
::: solution
(a) $\Psi_s = -cRT = -300\ \text{mol m}^{-3}\times8.314\times293.15\ \text{J mol}^{-1} = -7.31\times10^5$ Pa $= -0.731$ MPa。由 $\Psi_p = +0.50$ MPa，$\Psi = -0.731 + 0.50 = -0.23$ MPa。

(b) 纯水 $\Psi = 0 > -0.23$ MPa，所以水进入细胞；细胞略微膨胀直到膨压升到约0.73 MPa，届时内部 $\Psi$ 达到零。0.20 mol kg⁻¹ 蔗糖的 $\Psi = \Psi_s = -0.487$ MPa $< -0.23$ MPa，所以水离开细胞：薯片失重变软，若膨压在达到平衡前降到零，细胞就发生质壁分离。把组织薯片称量于一列溶液、找出质量不变的浓度，是测量组织水势的经典方法。
:::
:::

植物体内外的水势跨过一个巨大的范围：

| 系统 | 典型 $\Psi$（MPa） |
|---|---|
| 大气压下的纯水 | 0 |
| 田间持水量的湿润土壤 | 约 −0.01至 −0.03 |
| 常规永久萎蔫点的土壤 | −1.5 |
| 供水充足作物正午的叶片 | −0.5至 −1.5 |
| 干旱中荒漠灌木的叶片 | −4至低于 −8 |
| 海水 | 约 −2.5 |
| 相对湿度98 %、20 °C 的空气 | −2.7 |
| 相对湿度50 %、20 °C 的空气 | −94 |

最后两行来自水蒸气的水势，由理想气体的化学势导出。

::: proposition 空气的水势 {#prop-psi-air}
水蒸气分压为 $e$ 的空气，在饱和蒸气压为 $e_s$ 的温度下，相对湿度 $h = e/e_s$，水势为

$$
\Psi_\text{air} = \frac{RT}{\bar V_w}\ln h .
$$ {#eq-psi-air}

20 °C 时，$RT/\bar V_w \approx 135$ MPa。
:::

::: proof
把水蒸气当理想气体，$\mu_w = \mu_w^\circ + RT\ln(e/e_s)$，其中 $\mu_w^\circ$ 是与同温纯液态水平衡的蒸气的化学势，按定义对应 $\Psi = 0$。除以 $\bar V_w$ 得 [[#eq-psi-air]]。取 $R = 8.314$ J mol⁻¹ K⁻¹、$T = 293.15$ K、$\bar V_w = 18.05\times10^{-6}$ m³ mol⁻¹，得 $RT/\bar V_w = 1.350\times10^8$ Pa。
:::

对数使空气成为压倒性的汇。相对湿度50 %时，$\Psi_\text{air} = 135\ln 0.5 = -94$ MPa，比叶片负上一百倍。即使近乎饱和的空气，在99 %时也有 $\Psi = -1.36$ MPa。驱动蒸腾的，是从叶到空气水势的陡降，而不是植物做的任何功。

::: warning "水从稀溶液流向浓溶液"
渗透常被讲成水朝溶质浓度高的方向移动。只有当压力与高度相等时这才是真的。水沿总水势的梯度下行，而压力可以压倒溶质。膨压高的细胞在稀溶液中，只要膨压足够高，就可能把水丢给它；木质部中的水从根向上到叶，尽管两端的木质部汁液几乎都是纯水，因为上面的张力更大；韧皮部中的糖水溶液则靠整体流动流向库，把溶质一并带走。判断水的去向之前，永远要把 [[#eq-psi]] 的所有项加总。
:::

## 从土壤到根

土壤水保持在颗粒间的孔隙与表面的薄膜中，其衬质势随土壤变干、剩余水退入更小的孔隙而变得更负。根吸水时，其周围的土壤变干，水从更远处流来；根毛把吸收面向土壤延伸，缩短了这段路径。

在根内，水可经三条路线到达木质部：穿过细胞壁（**质外体**途径）、经胞间连丝从一细胞到另一细胞（**共质体**途径）、或跨膜从一细胞到下一细胞（**跨细胞**途径）。在内皮层处，凯氏带阻断质外体途径，所以一切水与溶质都必须在某处穿过质膜（[[plant-biology/plant-cells-tissues]]）。水跨膜主要经**水通道蛋白**（aquaporins）——一种把水单列导通、却排斥离子与质子的通道蛋白。水通道蛋白由 Peter Agre 及同事于1992年在人红细胞中发现；Christophe Maurel、Maarten Chrispeels 及同事于1993年证明 *Arabidopsis* 的一个液泡膜蛋白就是水通道蛋白。*Arabidopsis* 有35个水通道蛋白基因，分为质膜（PIP）与液泡膜（TIP）等家族，植物通过门控它们来调节根的水力导度：缺氧使细胞质酸化，通过质子化一个组氨酸关闭 PIP——水淹植物萎蔫的原因之一。

因为内皮层迫使溶质跨膜，根得以在木质部中积累离子。当蒸腾微弱时——夜间、湿润空气中——泵入木质部的离子降低其水势，水随渗透而来，正的**根压**建立起来，通常至多零点几兆帕。根压造成**吐水**——湿润清晨从叶缘溢出的木质部汁液珠——以及 Stephen Hales 于1727年测量过的切断藤本植物的“伤流”。它在某些物种中或有助于重新充水栓塞的导管。但它太小，而且在包括大多数针叶树在内的许多物种中根本不存在，不可能把水举上树梢。

## 沿木质部而上：内聚力与张力

### 内聚力-张力学说

水如何到达100 m 高树的叶片？Henry Dixon 与 John Joly 于1894年提出、如今得到压倒性支持的答案是：水是被拉的。水从叶肉细胞湿润的壁蒸发进入叶内空气间隙。蒸发时，气-水界面退入细胞壁的细孔，在那里变弯；这些弯曲弯月面的表面张力把水拉住，并使身后的水处于负压。张力通过木质部连续的水柱传到根与土壤。水柱不断裂，是因为水分子以氢键互相吸引（[[biochemistry/water-and-bonds]]）：不含溶解气体与成核位点的纯水，抗张强度达几十兆帕乃至更高。

::: definition 蒸腾作用与土壤-植物-大气连续体 {#def-spac}
**蒸腾作用**是植物体水分散失为汽，主要来自叶片内表面、经气孔而出。水从土壤经根、木质部、叶到大气的路径称为**土壤-植物-大气连续体**。稳态下，同一通量通过每一段，而水势沿路径按各段的阻力成比例下降，如同电流通过串联电阻。
:::

三条证据支持该学说。第一，蒸腾植株木质部中的水处于张力之下：切断的茎吸入水或染料，Per Scholander 及同事（1965）的**压力室**直接测量它。带叶的短枝密封在室内，切口伸出；给室加压直到汁液恰在切口出现。平衡压力等于木质部中本有的张力，作物中典型为0.5–2 MPa，耐旱灌木中大得多。第二，白天茎的直径随张力升高而出现可测的收缩，夜间再膨胀。第三，流从顶端开始：晴朗早晨，汁液流先在小枝开始，早于树干基部。

所需张力有多大？水必须逆重力举高——每米0.0098 MPa——并被拉过木质部的阻力。

### 管道中的流动

::: proposition 哈根-泊肃叶定律 {#prop-poiseuille}
黏度为 $\eta$ 的液体在半径 $r$、长 $L$ 的圆柱管中，在压差 $\Delta P$ 下做定常层流，体积流率与平均流速为

$$
Q = \frac{\pi r^4}{8\eta}\,\frac{\Delta P}{L}, \qquad \bar v = \frac{Q}{\pi r^2} = \frac{r^2}{8\eta}\,\frac{\Delta P}{L}.
$$ {#eq-poiseuille}

假设是层流（在植物输导分子的低雷诺数下成立）、圆截面刚性管、牛顿流体与壁面无滑移。
:::

::: proof
考虑管内一半径 $s$ 的同轴流体圆柱。定常流中，两端压力 $\pi s^2\Delta P$ 与曲面上的黏性拖曳 $-2\pi sL\,\eta\,\dd u/\dd s$ 相平衡，其中 $u(s)$ 是半径 $s$ 处的速度。故 $\dd u/\dd s = -s\Delta P/(2\eta L)$，并由壁处 $u(r) = 0$，得 $u(s) = \frac{\Delta P}{4\eta L}(r^2 - s^2)$，抛物线型速度分布。积分得 $Q = \int_0^r 2\pi s\,u(s)\,\dd s = \frac{\pi\Delta P}{2\eta L}\left[\frac{r^2 s^2}{2} - \frac{s^4}{4}\right]_0^r = \frac{\pi r^4\Delta P}{8\eta L}$。
:::

半径的四次方是木质部设计的关键事实。导管粗一倍，同梯度下输水多十六倍。粗导管使栎、藤与木质藤本的木材如此导水通畅——也将表明，这同样使它脆弱。

::: example 导管与管胞 {#ex-poiseuille}
(a) 半径50 µm 的导管与半径10 µm 的管胞承受相同的压力梯度。按每根输导管与每单位腔截面积计，导管多输多少水？(b) 20 °C 的水（$\eta = 1.0\times10^{-3}$ Pa s）在半径40 µm 的导管中，在超出平衡重力所需之外的0.02 MPa m⁻¹ 压力梯度下流动。估算平均流速，以米每小时计。
::: solution
(a) 按每根输导管，比值 $(50/10)^4 = 625$。按单位腔面积，除以面积比 $(50/10)^2 = 25$：导管每单位面积输水多 $25$ 倍。由典型半径10–20 µm 的管胞建成的针叶材，单位面积的导水率远低于具导管的木材。（管胞两端也封闭，水必须经纹孔从一个到另一个，这增加阻力；我们已忽略之。）

(b) 由 [[#eq-poiseuille]]，$\bar v = \dfrac{(40\times10^{-6})^2}{8\times1.0\times10^{-3}}\times2\times10^{4} = 4.0\times10^{-3}$ m s⁻¹ $= 14$ m h⁻¹。测得的峰值树干液流速度，在具宽导管物种中为此量级，针叶树中每小时一米或更低。
:::
:::

### 绳的断裂：空穴与栓塞

张力下的水是亚稳态。若气泡进入输导管，管中的水从壁上弹回，导管充满水汽与空气，停止输导：它被**栓塞**了。气泡通常经**进气**（air-seeding）进入——从一个已栓塞的输导管穿过纹孔膜到相邻正常输导管。纹孔膜是一张多孔的初生壁片；跨越其孔之一的气-水弯月面，可抵抗由表面张力决定的压差。

::: proposition 孔的气入压力 {#prop-laplace}
半径 $r$ 的圆孔中气-水界面的半球形弯月面，可维持的压差为

$$
\Delta P = \frac{2\gamma}{r},
$$ {#eq-laplace}

其中 $\gamma \approx 0.072$ N m⁻¹ 为25 °C 水的表面张力。若孔两端的压差超过此值，空气即被拉过（杨-拉普拉斯方程；假设壁完全润湿，接触角为零）。
:::

::: example 孔要多细才行？ {#ex-laplace}
(a) 某物种木质部的纹孔膜最大孔半径约50 nm。多大的木质部张力会把邻近栓塞管中的空气拉过？(b) 叶中，蒸腾表面上的弯月面位于细胞壁基质约5 nm 半径的孔里。它们能支撑多大的张力？
::: solution
(a) $\Delta P = 2\times0.072/(50\times10^{-9}) = 2.9\times10^6$ Pa $= 2.9$ MPa。进气由两根输导管间纹孔膜中*最大*的孔决定，而每根导管有成千上万个纹孔，所以罕见的大孔最为要紧。这就是栓塞抗性纹孔膜结构相关的原因。
(b) $2\times0.072/(5\times10^{-9}) = 2.9\times10^7$ Pa $\approx 29$ MPa。叶肉细胞的壁基质能在远大于叶片所见张力的张力下留住水；蒸发就是这样能产生张力、又不让空气进入叶片木质部的。
:::
:::

植物木质部能耐的张力差异极大。标准度量是**脆弱性曲线**：茎暴露于递增张力下的导水率损失百分数（PLC），用离心、注气、X 射线显微断层或光学方法测量。导水率损失一半时的张力 $P_{50}$，从一些热带与河畔树木的约 −1 MPa，到一些荒漠灌木与针叶树的低于 −10 MPa。一个广泛使用的经验描述是木质部压力 $\Psi_x$ 的 S 形函数：

$$
\text{PLC} = \frac{100}{1 + \exp\bigl(a(\Psi_x - P_{50})\bigr)},
$$ {#eq-vc}

其中 $a$ 决定陡度（Norman Pammenter 与 Caroline Vander Willigen，1998）。

caption: 一条木质部脆弱性曲线，[[#eq-vc]]：导水率损失百分数（纵轴）对木质部压力（MPa，横轴；越左越负）。滑块 $p$ 设 $P_{50}$，即曲线穿过50 % 线处；$s$ 决定导水率崩塌的陡度。把 $p$ 从 −2.5（典型温带阔叶树）移到 −8（耐旱灌木），注意可耐受的张力范围延伸多远。植物的**安全幅度**是其通常经历的最负压力与 $P_{50}$（许多针叶树用88 % 损失处的 $P_{88}$）之间的距离。
:::

Brendan Choat 及同事（2012）对226种木本植物的调查发现，无论干湿地带的生物群系，多数物种都以不到1 MPa 的窄安全幅度运行：树木建造的木质部，对其常遇的干旱来说恰好够安全。这解释了干旱为何在许多森林中致树于死：当干旱把张力推过 $P_{50}$、逼近 $P_{88}$，失控的栓塞切断对冠层的供水，这一过程称为水力失效。效率与安全之间存在折衷，但很弱：粗导管导水好，但纹孔面积往往更多，漏孔的机会因此更多，而且更易因冻融而栓塞——因为溶于汁液的气体在冻结时，在更粗的输导管中形成更大的气泡。

## 经气孔而出

水汽经气孔以扩散离开叶片。通量取决于叶片饱和空气间隙与周围空气之间水汽浓度之差，以及气孔导度——开放孔有多宽、有多密的度量。

::: proposition 蒸腾速率 {#prop-transpiration}
单位叶面积的蒸腾速率 $E$（mol m⁻² s⁻¹）为

$$
E = g_s\,\frac{e_s(T_\text{leaf}) - e_a}{P_\text{atm}},
$$ {#eq-transpiration}

其中 $g_s$ 是气孔与边界层对水汽的总导度（mol m⁻² s⁻¹），$e_s(T_\text{leaf})$ 是叶温下的饱和蒸气压（假设叶内空气间隙饱和），$e_a$ 是空气的水汽压，$P_\text{atm}$ 是大气压。分子是**叶-空气蒸气压亏缺**（VPD）。这就是以摩尔分数写出的 Fick 定律（[[cell-biology/membrane-transport#prop-fick]]）。
:::

::: example 一棵树的日失水量 {#ex-transpiration}
一片叶的气孔导度为0.30 mol m⁻² s⁻¹，气压101.3 kPa，叶-空气蒸气压亏缺2.0 kPa。(a) 其蒸腾速率是多少？(b) 若此速率平均每天维持10小时，一株叶面积200 m² 的树每天蒸腾多少水？
::: solution
(a) 由 [[#eq-transpiration]]，$E = 0.30\times2.0/101.3 = 5.9\times10^{-3}$ mol m⁻² s⁻¹，即5.9 mmol m⁻² s⁻¹。

(b) 每平方米每天：$5.9\times10^{-3}\times18\ \text{g mol}^{-1}\times36{,}000\ \text{s} = 3.8$ kg。200 m² 共约770 kg——约770升。真实的树平均失水更少（最热时段气孔部分关闭，遮阴叶蒸腾较少），但大树一天几百升的用水是现实的。这一交换的水分利用效率——每固定一个 CO₂ 损失多少水分子——在 [[diversity-of-life/land-plants]] 中计算。
:::
:::

气孔是植物的控制阀。每个孔由两个**保卫细胞**夹护，其膨压决定孔径。开放时，保卫细胞经质膜 H⁺-ATP 酶把质子泵出——由蓝光经向光素（phototropin）类光受体激活；由此产生的超极化打开内向整流 K⁺ 通道，K⁺ 连同 Cl⁻ 与细胞内合成的苹果酸一起进入。水随之而来，膨压升到几兆帕，保卫细胞彼此弓开。关闭是逆过程：缺水胁迫下合成的激素脱落酸（abscisic acid）激活阴离子通道（SLOW ANION CHANNEL-ASSOCIATED 1，SLAC1），使膜去极化，K⁺ 经外向整流通道流出（[[plant-biology/plant-hormones]]）。气孔还响应 CO₂（胞间 CO₂ 升高时关闭）、湿度与生物钟。借它们，植物逐分钟用水换碳。

::: intuition 为什么微小的孔泄漏这么多
开放的气孔只占叶表面约1–3 %，然而气孔开放的叶片，蒸腾速率可达同面积自由水面的相当份额。Horace Brown 与 Fergusson Escombe（1900）解释了原因：从小孔向外扩散不正比于孔的面积，而是在很好近似下正比于孔的直径，因为分子在每孔周围一个半球壳内散开。因此许多小而疏朗的孔几乎和一个大开口同样有效——而且它们可以各自独立关闭。
:::

::: quiz
炎热的下午，向日葵的叶片萎蔫，而土壤是湿润的。哪个解释最可能？
- [ ] 根压失效了
- [ ] 空气的水势升到了叶的水势之上
- [x] 蒸腾快于水经根与木质部供应的速率，叶水势与膨压因此下降
- [ ] 水经渗透从叶片流回根
::: solution
蒸腾需求高时，通过土壤-植物-大气连续体的通量要求水势在根与木质部的阻力上大幅下降。叶水势下降，直到叶细胞失去膨压而萎蔫，尽管土壤里并不缺水；叶片傍晚常常恢复。根压在蒸腾的植物中不起作用，而除饱和外，空气的水势永远比叶负得多。
:::
:::

## 韧皮部：从源到库的压力流动

成熟叶（**源**）制造的糖运往根、生长的新梢、发育中的种子、果实与贮藏器官（**库**）。它们溶在筛管的汁液中运输，主要是蔗糖（有些科为棉子糖系寡糖或糖醇），浓度达每升几百毫摩尔，连同氨基酸、离子、激素、蛋白质与 RNA。幼小时是库的叶，成熟、胞间连丝改变后成为源（[[plant-biology/plant-cells-tissues]]）。

研究韧皮部的困难在于筛管处于高压之下，且受伤后数秒内就用蛋白质与胼胝质封闭筛板而做出反应，切进去就会扰乱想要测量的东西。John Kennedy 与 Tom Mittler（1953）找到了一个巧妙的绕过办法：蚜虫把口针刺入单个筛管分子取食；把麻醉的蚜虫从其口针上切下，汁液会在筛管自身压力下继续从口针渗出数小时，可以收集分析。

::: definition 压力流动（Münch）假说 {#def-munch}
在 Ernst Münch 于1930年提出的**压力流动假说**中，糖在源处装载进筛管分子，降低其溶质势；水经渗透从周围的木质部与组织进入，建立高膨压。在库处，糖被移除，水离开，膨压下降。由此产生的**压力梯度**驱动汁液——水与溶质一起——经筛管以整体流动从源流向库。筛管是管道；能量花在两端的糖的膜运输上。
:::

韧皮部流动的方向因此由糖在哪里装载与卸出决定，而不由重力决定：可以向上也可以向下，并随季节改变。用示踪剂测得的速度典型为0.3–1.5 m h⁻¹。

::: example 筛管中所需的压力梯度 {#ex-munch}
一根筛管半径10 µm；其汁液含蔗糖约0.5 mol L⁻¹，黏度约 $1.7\times10^{-3}$ Pa s。(a) 忽略筛板，多大的压力梯度能驱动0.5 m h⁻¹ 的平均速度？(b) 每单位筛管腔截面积的蔗糖质量通量是多少，以 g cm⁻² h⁻¹ 计？(c) 20 °C 下汁液的渗透压是多少？
::: solution
(a) 重排 [[#eq-poiseuille]]，$\Delta P/L = 8\eta\bar v/r^2 = 8\times1.7\times10^{-3}\times(0.5/3600)/(10^{-5})^2 = 1.9\times10^4$ Pa m⁻¹ $= 0.019$ MPa m⁻¹。筛板使阻力约增一倍，所以约0.04 MPa m⁻¹——10 m 上0.4 MPa。

(b) 蔗糖浓度为 $0.5\times342\ \text{g L}^{-1} = 171$ g L⁻¹ $= 0.171$ g cm⁻³；在50 cm h⁻¹ 下通量为 $0.171\times50 = 8.6$ g cm⁻² h⁻¹。许多植物测得的“比集运量”为此量级。

(c) $\Pi = cRT = 500\times8.314\times293 = 1.2$ MPa（计入其他溶质则更高）。源处约1 MPa 的筛管膨压，向库方向递减，足以驱动几米上的流动——与 Münch 的机制一致。在最高的树上、越过100 m 韧皮部它是否仍足够，曾受质疑；测量提示树木部分地以越往下筛管越粗、筛板孔越多来补偿。
:::
:::

### 装载与卸载

糖在源处如何进入筛管分子因植物而异，公认有三种策略。

1. **质外体装载。**叶肉细胞合成的糖共质体地向叶脉移动，然后经 **SWEET** 转运体（让蔗糖顺浓度梯度移动的单向转运体，由 Li-Qing Chen、Wolf Frommer 及同事于2012年发现）输出到细胞壁空间。从质外体，它逆陡峭梯度经**蔗糖–H⁺ 同向转运体**（SUC/SUT）进入伴胞与筛管分子，动力是质膜 H⁺-ATP 酶的质子梯度（[[cell-biology/membrane-transport]]）。*Arabidopsis*、糖甜菜与许多作物以此方式装载；缺少伴胞同向转运体 SUC2 的突变体矮小，叶中积累糖。
2. **聚合物截留的共质体装载。**葫芦科与 *Coleus* 中，蔗糖经胞间连丝扩散进特化的伴胞（传递细胞），在那里被转化为更大的糖：棉子糖与水苏糖。它们大到不能回扩散过窄的胞间连丝回到叶肉，却小到能穿过较宽的胞间连丝进入筛管分子：它们被困在韧皮部中。
3. **被动共质体装载。**许多树木中，叶肉糖浓度之高足以让蔗糖顺梯度经丰富的胞间连丝扩散进韧皮部，无需主动步骤。

在库处，蔗糖经共质体卸入生长组织，或在库被隔绝之处经质外体卸出（如发育中的种子，其胚与母体植物没有胞间连丝联系）。库细胞常用转化酶或蔗糖合酶把蔗糖拆为己糖，维持梯度。

::: application 干旱、灌溉与死亡的森林
农业用掉全球人类抽取的淡水的约70 %（FAO AQUASTAT），几乎全部用于作物的蒸腾。因此本章的物理学就是粮食生产的物理学：水分受限下的作物产量近似正比于蒸腾量乘水分利用效率，育种者寻找用水更高效、在恰当时机关闭气孔、或扎根更深的品种。在森林中，同样的物理解释干旱致死。2000与2010年代的严重干旱在美国西南部、加利福尼亚与中欧等地杀死数亿棵树，而水力失效——栓塞把导水率损失推过不可回返之点——是这些枯死事件最一致的生理学特征。$P_{50}$ 与安全幅度的测量，如今被用来预测干旱加剧时哪些物种与区域风险最大。
:::

::: history
Stephen Hales 的 *Vegetable Staticks*（1727）用称重盆栽植物测量蒸腾，用接在切断藤茎上的压力计测量根压。Henry Dixon 与 John Joly 于1894年提出内聚力学说；Eugen Askenasy 次年于德国得出类似结论。Horace Brown 与 Fergusson Escombe 于1900年分析了经小孔的扩散。Ernst Münch 于 *Die Stoffbewegungen in der Pflanze*（1930）中提出韧皮部的压力流动。Kennedy 与 Mittler 于1953年引入蚜虫口针技术，Per Scholander 的压力室（1965）使木质部张力可常规测量。John Milburn 与 Robert Johnson（1966）用贴在萎蔫叶片上的麦克风听到空穴的咔哒声。木质部处于张力之下的论断在1990年代受到 Ulrich Zimmermann 直接压力探针测量的挑战，后者似乎只显示小张力；随之而来的争论主要由离心与压力室实验朝支持内聚力-张力学说解决，磨砺了这一领域的方法。水通道蛋白1992年被发现、1993年在植物中找到；Peter Agre 因此分享2003年诺贝尔化学奖。
:::

## 小结

::: summary
- **水势** $\Psi = \Psi_s + \Psi_p + \Psi_g\,(+\Psi_m)$，其中 $\Psi_s = -cRT$、$\Psi_g \approx 0.0098$ MPa m⁻¹；水沿 $\Psi$ 从高往低移。
- 空气有 $\Psi = (RT/\bar V_w)\ln h$，50 %湿度下约 −94 MPa：干空气驱动蒸腾。
- 水经质外体、共质体与跨细胞途径进入根；凯氏带迫使它跨膜，主要经水通道蛋白。根压（零点几 MPa）造成吐水，但不能把水举上树。
- **内聚力-张力**：叶细胞壁中弯月面的蒸发使木质部水处于张力（压力室测量），经连续水柱传递。流动服从哈根-泊肃叶定律，$Q \propto r^4$：粗导管远比管胞导水。
- 木质部因**栓塞**失效，通常因经纹孔膜孔的进气，压差 $\Delta P = 2\gamma/r$。脆弱性曲线给出 $P_{50}$；多数树木以窄安全幅度运行，干旱以水力失效杀树。
- 蒸腾 $E = g_s\,\text{VPD}/P_\text{atm}$；保卫细胞以 K⁺ 与阴离子流控制 $g_s$，蓝光下开放，对 ABA、高 CO₂ 与干空气关闭。
- **韧皮部**运输是压力流动（Münch）：源处装载糖、库处卸出产生压力梯度。装载方式为质外体（SWEET 外流、SUC/SUT 同向）、聚合物截留的共质体、或被动。
:::

水带的不只是它自己：矿质养分溶在其中的，从土壤到根再到茎。植物如何获得它们，是 [[plant-biology/mineral-nutrition]] 的主题。

::: exercise 细胞的水势 {level=1 check="-0.34"}
25 °C 下一个细胞，细胞液渗透浓度0.30 osmol kg⁻¹，膨压0.40 MPa。求其水势，以 MPa 计，保留两位小数。
::: solution
$\Psi_s = -300\times8.314\times298.15 = -7.44\times10^5$ Pa $= -0.744$ MPa；$\Psi = -0.744 + 0.40 = -0.34$ MPa。

相对湿度60 %、20 °C 的空气，水势是多少 MPa（取最近整数）？
::: solution
$\Psi = 135.0\times\ln 0.6 = 135.0\times(-0.511) = -69$ MPa。

木质部输导管的半径加倍、压力梯度不变，流经它的体积流率增大几倍？

::: exercise 蒸腾速率 {level=1 check="5.2"}
30 °C 的一片叶（饱和蒸气压4.24 kPa）处于同温、相对湿度50 %、101.3 kPa 的空气中。其导度为0.25 mol m⁻² s⁻¹。求 $E$，以 mmol m⁻² s⁻¹ 计，保留一位小数。
::: solution
VPD $= 4.24 - 0.5\times4.24 = 2.12$ kPa。$E = 0.25\times2.12/101.3 = 5.2\times10^{-3}$ mol m⁻² s⁻¹ $= 5.2$ mmol m⁻² s⁻¹。
:::
:::

::: exercise 纹孔孔道 {level=2 check="7.2"}
针叶树的纹孔膜（具环缘纹孔，有 torus 与 margo）在跨膜压差大时由 torus 封闭；当空气被拉过半径20 nm 的缝隙时密封失效。压差多大时发生，以 MPa 计，保留一位小数？
::: solution
$\Delta P = 2\gamma/r = 2\times0.072/(20\times10^{-9}) = 7.2\times10^6$ Pa $= 7.2$ MPa。
:::
:::

::: exercise 读压力室 {level=2}
一位葡萄种植者用压力室测量叶水势。黎明前，叶片读数为 −0.2 MPa；下午2时，−1.4 MPa。一周无雨后，读数变为黎明前 −0.8 MPa、下午2时 −1.6 MPa。(a) 为什么黎明前的读数能较好地估计根区土壤水势？(b) 解读这一周的变化。(c) 正午读数变化比黎明前小。试解释。
::: solution
(a) 黎明前气孔关闭，蒸腾近乎零，几乎无流动，植物的水势与其根能到达的最湿土壤趋于平衡（减去一个小的重力项）。
(b) 土壤干了：根区水势从约 −0.2降到 −0.8 MPa。
(c) 葡萄藤应干燥土壤部分关闭了气孔（等水势行为，为某些葡萄品种典型），于是蒸腾以及沿植株的水势降落随之减小：正午从土壤到叶的降落在1.2到0.8 MPa 之间下降了。通过调节气孔，葡萄藤使自己的正午叶水势——以及木质部张力——不再大幅下降，以光合减少为代价保护了木质部免于栓塞。
:::
:::

::: exercise 一条脆弱性曲线 {level=2}
某物种的脆弱性曲线服从 [[#eq-vc]]，$P_{50} = -3.0$ MPa，$a = 2.0$ MPa⁻¹。(a) 在 −2.0 MPa 与 −4.0 MPa 处，导水率损失百分之多少？(b) 正常夏季木质部最低压力为 −2.2 MPa。相对 $P_{50}$ 的安全幅度是多少？(c) 窄安全幅度在变化的气候中为何危险？自然选择为何仍可能青睐它？
::: solution
(a) 在 −2.0：$100/(1 + e^{2(−2.0+3.0)}) = 100/(1 + e^{2}) = 100/8.39 = 11.9\,\%$。在 −4.0：$100/(1 + e^{-2}) = 100/1.135 = 88.1\,\%$。
(b) $-2.2 - (-3.0) = 0.8$ MPa。
(c) 比平常略严重的干旱就会把张力推过 $P_{50}$，那里栓塞加速（曲线在此最陡），水力失效可随即发生。更安全的木质部通常代价更高——木材更密、导管更小、纹孔膜更厚——导水更少，生长减慢；在对光的竞争里，长得更快、较不安全的设计在平常年份胜出。选择把安全度调校到历史上的干旱机制，而气候变化正在改变它。
:::
:::

::: exercise 蚜虫与环割 {level=2}
(a) 在柳茎上、一处树皮被环状剥除的环带上下，用蚜虫口针采集汁液。几天后，环带上下蔗糖浓度与渗出速率有何预期？(b) 口针技术不涉及切开筛管，为何重要？(c) 蚜虫口针的测量如何支持压力流动假说，而非筛管沿长度主动泵汁的机制？
::: solution
(a) 环割上方糖积累，浓度与膨压高，渗出旺盛；下方来自叶的供应被切断，糖被消耗，渗出减慢或停止。
(b) 切割会触发韧皮部蛋白与胼胝质的快速封闭以及朝切口的涌流；口针刺入单个筛管分子而不触发这些响应，并在其自然压力下取样。
(c) 汁液在剪断的口针上继续流出数小时，只由筛管内部膨压驱动：内含物处于正压之下，如 Münch 所预言，渗出速率与预期的压力驱动流相符。（用压力传感器接在口针上直接测得的）压力朝源处更高、朝库处更低，正如此假说所要求。
:::
:::

::: exercise 水分收支 {level=3}
晴朗下午，一棵30 m 的树有：土壤水势 −0.1 MPa；冠顶叶水势 −1.8 MPa；蒸腾3 L h⁻¹。(a) 仅支撑水柱对抗重力需要水势降落中的哪一部分？(b) 把路径当作单一电阻，估算树的水力导度（L h⁻¹ MPa⁻¹），不含重力分量。(c) 若干旱使土壤水势降到 −1.0 MPa，而树必须让叶片保持在 −2.0 MPa 以上以躲过栓塞，在导度不变的假设下，它能维持的最大蒸腾是多少？(d) 导度实际上还会下降，为什么？
::: solution
(a) $0.0098\times30 = 0.29$ MPa。
(b) 总降落 $1.7$ MPa；摩擦降落 $1.7 - 0.29 = 1.41$ MPa。导度 $K = 3/1.41 = 2.1$ L h⁻¹ MPa⁻¹。
(c) 允许的摩擦降落 $= (-1.0) - (-2.0) - 0.29 = 0.71$ MPa；最大蒸腾 $= 2.1\times0.71 = 1.5$ L h⁻¹，约为原来的一半——气孔必须部分关闭。
(d) 土壤变干时其导水率陡降（水退入小孔、根失去接触），而木质部张力接近阈值时造成一些栓塞；两者都进一步降低 $K$，所以安全的蒸腾速率还要低。
:::

::: exercise 高树的韧皮部 {level=3}
(a) 用 [[#ex-munch]] 的结果，估算让韧皮部汁液通过100 m 长、半径10 µm、筛板使阻力加倍的筛管所需的压力差。(b) 源汁的渗透压约1.5 MPa，库端膨压或许0.3 MPa。这一距离上压力流动可信吗？(c) 提出高树降低所需压力梯度的两种办法，并各说一个检验方法。
::: solution
(a) 按约每米0.04 MPa（0.019 MPa m⁻¹ 加倍），100 m 约需4 MPa。
(b) 源与库膨压之间可用的差只有约1.2 MPa——而且源膨压实际上低于汁液的渗透压，因为筛管与负水势的木质部水接触。按这些尺寸，压力流动会太慢，要慢三倍以上，达不到所需速度。
(c) 更粗的筛管：单位面积阻力按 $r^{-2}$ 下降（速度 $\propto r^2$），半径加倍可把所需梯度减少到四分之一。用沿茎测筛管半径来检验；对高树的研究发现筛管自树冠向下变宽、筛板孔变多。以更粗面积携更慢流：用更多筛管、在更低速度下运送同样的质量通量。用在不同高度测韧皮部截面积与运输速度（用 ¹¹C 之类示踪剂）检验。（第三种可能是沿途卸出再装载的接力运输，已有人提出，但更难检验。）
