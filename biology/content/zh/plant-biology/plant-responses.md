植物不能移动到更好的环境，只能立足身处之地做最好的打算。它以惊人的精确感知周围世界，并改变自己的生长方式。埋在土里的幼苗又长又白地伸展，直到见到光，随后几小时内张开叶片、合成叶绿素。处于他株荫下的植物察觉上方叶片造成的光成分变化，长高以图挣脱。许多植物能把夜长度量到一刻钟以内，从而在正确的季节开花；另一些则须先经历数周的冬季低温。被真菌攻击的植物认出真菌表面的分子，把感染封锁起来；被毛虫啃食的植物在全株制造毒素。

本章讲植物如何感知环境并作出响应。我们从最重要的信号——光讲起：感知其总量、颜色、方向与持续时间的光受体，以及由它们调控的响应——向光性、避荫反应与由暗到明的生长转变。然后是时间：生物钟、日长与开花的控制，包括对开花信号——成花素——的长期追寻。重力、温度，以及干旱、低温、盐与淹水等胁迫紧随其后，最后是植物的免疫系统。承载其中许多响应的激素，尤其是生长素、赤霉素、ABA 与乙烯，已在 [[plant-biology/plant-hormones]] 中引入。定量线索包括光敏色素的光平衡、日长的几何、生物钟的温度补偿与热时间。

## 感知光

植物既把光用作能量来源，也把它用作信息来源。作为信息，植物有若干光受体家族，每种都是结合了生色团的蛋白，各覆盖光谱的不同部分。

::: definition 植物的光受体 {#def-photoreceptors}
- **光敏色素**经线性四吡咯生色团（phytochromobilin）主要吸收红光（660 nm 附近）与远红光（730 nm 附近）。*Arabidopsis* 有五种：phyA–phyE。
- **隐花色素**（cry1、cry2）经黄素（FAD）生色团吸收蓝光与紫外-A 光；调控去黄化、光周期开花与生物钟。
- **向光素**（phot1、phot2）是被蓝光激活的蛋白激酶，带结合黄素（FMN）的 LOV 结构域；介导向光性、叶绿体运动与气孔开放。
- **ZEITLUPE** 家族蛋白（ZTL、FKF1、LKP2）是带 LOV 结构域的蓝光受体，控制钟蛋白与开花蛋白的降解。
- **UVR8** 经蛋白自身的色氨酸残基吸收紫外-B，触发紫外防护。
:::

### 光敏色素：光可逆开关

光敏色素的定义性性质先于其分子本身被发现。美国农业部的 Harry Borthwick、Sterling Hendricks 及同事（1952）发现，Grand Rapids 品种莴苣的种子短暂照红光后萌发，但若红闪光之后立即照远红光则不萌发；远红之后再照红，萌发恢复——如此经长串交替，只有最后一次闪光作数。他们推断存在一种以两种可互变形式存在的色素。Warren Butler 及同事于1959年在黄化幼苗中以光谱法检测到它，并将其命名为光敏色素。

光敏色素以吸收红光的形式 **Pr** 合成，它没有活性。吸收红光使其转变为吸收远红光的活性形式 **Pfr**；Pfr 迁入细胞核，与转录因子——主要是 **PHYTOCHROME-INTERACTING FACTORS**（PIF）——互作，触发它们的降解。吸收远红光使 Pfr 转回 Pr。暗中 Pfr 缓慢回到 Pr。由于两种形式的吸收光谱彼此交叠——Pfr 吸收一点红光，Pr 吸收一点远红光——任何光都产生两者的混合，而 Pfr 的比例报告红光与远红光子之比。

::: proposition 光敏色素的光平衡 {#prop-photoeq}
设光把 Pr 转为 Pfr 的一级速率常数为 $k_1$，把 Pfr 转为 Pr 的速率常数为 $k_2$；两者各正比于光子通量与被转化形式的吸收，并对全光谱求和。忽略合成、降解与暗逆转，活性形式光敏色素的比例趋近**光平衡**

$$
\varphi = \frac{[\mathrm{Pfr}]}{[\mathrm{Pr}] + [\mathrm{Pfr}]} = \frac{k_1}{k_1 + k_2},
$$ {#eq-photoeq}

弛豫时间为 $1/(k_1 + k_2)$。
:::

::: proof
$\dd[\mathrm{Pfr}]/\dd t = k_1[\mathrm{Pr}] - k_2[\mathrm{Pfr}]$，其中 $[\mathrm{Pr}] + [\mathrm{Pfr}] = P$ 为常数。令导数为零得 $k_1(P - [\mathrm{Pfr}]) = k_2[\mathrm{Pfr}]$，故 $[\mathrm{Pfr}]/P = k_1/(k_1 + k_2)$。线性方程的解以速率 $k_1 + k_2$ 指数趋近该值。
:::

::: example 日光与荫下的光敏色素 {#ex-photoeq}
考虑一个简化模型，其中红光（R）与远红光（FR）光子之比为 $\zeta$ = R : FR。每个红光光子，Pr 以相对效率1被转化，Pfr 以0.15被转化；每个远红光光子，Pfr 以相对效率1被转化，Pr 以0.025被转化。于是 $k_1 \propto \zeta + 0.025$，$k_2 \propto 0.15\zeta + 1$。求下列光照下的 $\varphi$：（a）纯红光；（b）纯远红光；（c）$\zeta = 1.2$ 的日光；（d）树冠荫下 $\zeta = 0.2$。
::: solution
由 [[#eq-photoeq]]，$\varphi = (\zeta + 0.025)/(1.15\zeta + 1.025)$。

（a）当 $\zeta\to\infty$，$\varphi \to 1/1.15 = 0.87$。即使饱和红光也仍留13 %的光敏色素为 Pr，因为 Pfr 也吸收红光。（b）$\zeta = 0$ 时，$\varphi = 0.025/1.025 = 0.024$。（c）$\zeta = 1.2$ 时，$\varphi = 1.225/2.405 = 0.51$。（d）$\zeta = 0.2$ 时，$\varphi = 0.225/1.255 = 0.18$。

叶片强烈吸收红光（叶绿素），却透射与反射远红光，故 R : FR 比在日光中约为1.1–1.2，在冠层下落到0.1–0.7。植物能把活性光敏色素的比例读作周围植被多少的度量——甚至在被遮荫之前：来自邻株的远红反射已经压低 R : FR。
:::
:::

### 光敏色素做什么

光敏色素控制植物几乎每一个生命阶段：小粒种子的萌发（它们应当只在近土表的有光处萌发）、幼苗的**去黄化**、**避荫反应**与开花。不同的光敏色素分工不同。**phyB** 在光中稳定，是 R : FR 的主要感受器：荫下其 Pfr 下降，PIF 积累，PIF 激活生长素合成与细胞伸长的基因，于是茎与叶柄伸长、叶片上举、分枝受抑、开花加速——**避荫反应综合征**；在农田里，它意味着植株更高更细、产量更低。**phyA** 在暗中生长的幼苗中含量丰富，但作为 Pfr 在光中迅速降解；它是使幼苗得以响应极弱光与冠层深处富远红光的那种受体。

在暗中生长的幼苗是**黄化**的：它把资源投入下胚轴（禾本科为中胚轴）的伸长以求见到光，子叶闭合、由顶端弯钩保护，具黄化质体而非叶绿体（[[plant-biology/plant-cells-tissues]]）。见到光后，光敏色素与隐花色素触发**光形态建成**：下胚轴伸长减慢，弯钩张开，子叶展开，合成叶绿素并发育叶绿体，基因表达发生大规模改变。暗中，E3 泛素连接酶 COP1 通过摧毁转录因子 HY5 等使光形态建成处于关闭状态；暗中生长的 *cop1* 突变体看上去像见光生长的幼苗。光使 COP1 失活，并把它从细胞核中移除。

### 向光性

向光性——朝光（在根则背光）的生长——由向光素介导。单侧蓝光在受光侧更多地激活 phot1，导致生长素重新分布到遮阴侧（**Cholodny–Went 假说**，由 Nikolai Cholodny 与 Frits Went 在1920年代各自独立提出），在那里促进伸长，使器官弯向光（[[plant-biology/plant-hormones]]）。横向再分配涉及 PIN 生长素外运载体，尤其是 PIN3：它在下胚轴内皮层细胞中的定位朝遮阴侧移动。向光素还在细胞中移动叶绿体——弱光下移向细胞表面以最大化吸收，强光下移到侧壁以避免伤害——并在蓝光下打开气孔（[[plant-biology/water-transport]]）。

## 重力

茎向上长，根向下长：**向重力性**。根的感受部位是根冠的**柱细胞**；茎中则是内皮层。两者都含**平衡石**——富含淀粉、致密的淀粉体（[[plant-biology/plant-cells-tissues#def-plastids]]），沉降到细胞的下方。根放倒时，平衡石在几分钟内落到新的下壁并被感知——感受机制尚未完全确定，但涉及 LAZY 蛋白：它随淀粉体移到质膜下方，招募 PIN 极性的调节因子。柱细胞的 PIN3 与 PIN7 重定位到下方，生长素被导向根的下侧，在那里，以其浓度会抑制根伸长的方式（根对生长素高度敏感）减慢生长：上侧生长更快，根遂向下弯曲。茎中，下侧积累的生长素促进生长，茎遂向上弯曲。切除根冠，向重力性消失而生长不止；*Arabidopsis* 的无淀粉突变体对重力敏感性降低——平衡石假说由此坐实。

::: quiz
水平放置的根向下弯曲，这是因为：
- [ ] 生长素在下侧被破坏，故下侧生长更快
- [x] 生长素在下侧积累，在该浓度下抑制根细胞的伸长，故上侧生长更快
- [ ] 下侧水更多，所以生长更快
- [ ] 重力把根尖往下拉，像绳端挂重物
::: solution
响应平衡石沉降，PIN 蛋白重定位，把生长素改道到下侧。根细胞对生长素如此敏感，以致额外的生长素抑制其伸长；生长素较少的上侧生长更快，根遂下弯。茎中同样的再分配促进下侧生长，使茎上弯。根的质量远不够大、组织远不够软，重力不可能把它机械地拉弯。
:::

## 时间：生物钟

1729年，法国天文学家 Jean-Jacques d'Ortous de Mairan 观察到，置于恒定黑暗中的含羞草（*Mimosa*）植株的叶仍按日以一日为周期开合。这是内源的**昼夜节律**钟的首次证明。植物用生物钟预期黎明与黄昏——日出前备好光合机构，把放香定刻在传粉者活动的时辰，整夜定量配给淀粉（[[plant-biology/photosynthesis]]）——而且，下文将见，用它度量日长。

::: definition 昼夜节律 {#def-circadian}
**昼夜节律**是满足以下条件的生物振荡：（1）在恒定条件下持续，具约24 h 的**自由运行周期**（典型为22–28 h）；（2）可被环境授时因子如光-暗与暖-冷周期**同步化**（重置）；（3）**温度补偿**：在生理范围内，与多数生化速率相反，其周期随温度的变化很小。
:::

*Arabidopsis* 生物钟的核心是一组相互咬合的转录反馈环。两个同源的晨间表达 MYB 转录因子 **CCA1** 与 **LHY** 抑制晚间表达的基因 **TOC1**（TIMING OF CAB EXPRESSION 1）及其他晚发基因；TOC1 及其近亲 PSEUDO-RESPONSE REGULATORS（PRR9、PRR7、PRR5）又在一日不同时刻抑制 *CCA1* 与 *LHY*；三个蛋白组成的“晚间复合体”在夜间抑制 PRR9 等。光经光敏色素与隐花色素重置生物钟，蓝光受体 ZTL 控制 TOC1 的降解。关键方法由 Andrew Millar、Steve Kay 及同事（1995）引入：他们在 *Arabidopsis* 中把一个钟控基因的启动子与萤火虫荧光素酶基因融合，拍摄幼苗节律性的微光，据此筛选周期改变的突变体——其中包括走得快的 *toc1*。

::: proposition 温度系数 {#prop-q10}
速率 $k$ 对温度的敏感程度以**温度系数**

$$
Q_{10} = \left(\frac{k_2}{k_1}\right)^{10/(T_2 - T_1)},
$$ {#eq-q10}

表示，即温度升高10 °C 速率增大的倍数。多数酶促与代谢速率的 $Q_{10}$ 介于2与3之间。对一个节律，“速率”是频率 $1/\tau$，其中 $\tau$ 为周期。
:::

::: example 钟的补偿有多好？ {#ex-q10}
*Arabidopsis* 叶片运动节律在12 °C 下自由运行周期24.4 h，在22 °C 下23.9 h。求钟频率的 $Q_{10}$，并与 $Q_{10} = 2.5$ 的酶比较。
::: solution
频率比为 $(1/23.9)/(1/24.4) = 24.4/23.9 = 1.021$；$T_2 - T_1 = 10$ °C，故 $Q_{10} = 1.02$。$Q_{10} = 2.5$ 的酶在22 °C 比在12 °C 快2.5倍；若钟由这类反应构成而没有补偿，其周期将从24.4 h 缩至约10 h。补偿由下述平衡达成：一些反应速率随温度升高，另一些反应速率同样升高、却对周期起相反的作用——这是网络的设计属性，而非任何单一组分的属性。
:::
:::

有钟重要吗？Antony Dodd、Alex Webb 及同事（2005）在20、24或28小时的人造光暗中，栽培自由运行周期长（28 h）或短（20 h）的 *Arabidopsis* 突变体。内部周期与外界循环匹配的植株固定更多碳、长得更大、存活更好——“昼夜节律共振”。

## 日长与开花

### 光周期现象

1920年，美国农业部的 Wightman Garner 与 Harry Allard 报告：烟草的一个新品种 Maryland Mammoth 在夏日田间长得巨大，却只在冬季温室中栽培时才开花；一个品种的大豆从春季起间隔播种，全部在夏末大致同一日期开花。他们用遮光棚人为缩短日长，证明这两种植物都是在日长降到临界值以下时开花。他们把这一现象称为**光周期现象**。

::: definition 光周期反应类型 {#def-photoperiod}
- **短日植物**（SDP）在夜长长于临界长度（亦即日长短于临界长度）时开花：菊、一品红、水稻、大豆、Maryland Mammoth 烟草、苍耳（*Xanthium*）。
- **长日植物**（LDP）在夜长短于临界长度时开花：*Arabidopsis*、小麦、大麦、菠菜、萝卜。
- **日中性植物**的开花与日长无关：番茄、黄瓜与玉米的许多栽培品种。

**专性**（定性）响应者，在错误光周期下根本不开花；**兼性**（定量）响应者只是被延迟。
:::

::: warning 短日植物量的是夜
“短日”“长日”的名称是历史遗留且误导人的。Karl Hamner 与 James Bonner（1938）用苍耳证明，植物度量的是**夜**的长度：给短日植物一个长夜、在正中用几分钟光打断，它不开花——尽管其白昼总长是短的——此为**暗期间断**。以一段黑暗打断长日则无同等效应。暗期间断以红光最有效，可被远红光逆转，牵涉光敏色素。种植者利用暗期间断：秋菊在中夜给温室照明一小时以维持营养生长，再关灯使其如期开花。
:::

因为开花取决于日长，而日长取决于纬度与日期，适居某一纬度的植物换到另一纬度可能开错了时候。日长可由简单天文学算出。

::: proposition 日长 {#prop-daylength}
在纬度 $\phi_\ell$、太阳赤纬为 $\delta$ 的一天，太阳位于几何地平之上的时间为

$$
D = \frac{2}{15^\circ}\arccos\!\left(-\tan\phi_\ell\,\tan\delta\right) \ \text{hours},
$$ {#eq-daylength}

其中 $\arccos$ 以度计（地球每小时转15°）。赤纬全年近似按 $\delta \approx 23.44^\circ\sin\!\bigl(360^\circ(n - 80)/365\bigr)$ 随日序 $n$ 变化（$n = 80$ 在三月春分附近）。当 $|\tan\phi_\ell\tan\delta| > 1$（至日前后的极圈以内）时，太阳不落或不升。大气折射与日面大小使实际观测的日长增加几分钟。
:::

::: proof
日正午后时角 $\omega$ 处，太阳高度角 $\alpha$ 满足 $\sin\alpha = \sin\phi_\ell\sin\delta + \cos\phi_\ell\cos\delta\cos\omega$（天球的球面三角）。日出与日落即 $\alpha = 0$，故 $\cos\omega_0 = -\tan\phi_\ell\tan\delta$。太阳在时角 $-\omega_0$ 到 $+\omega_0$ 之间位于地上，共 $2\omega_0$ 度，按每小时15° 即 $2\omega_0/15$ 小时。
:::

::: example 短日植物何时开始开花？ {#ex-daylength}
（a）求北纬51.5°（伦敦）在夏至与冬至的日长。（b）一个短日大豆品种在日长降到13 h 以下时开花。在40° N，夏季从哪个日期起满足该条件？
::: solution
（a）六月夏至 $\delta = 23.44^\circ$：$-\tan 51.5^\circ\tan 23.44^\circ = -1.257\times0.4335 = -0.545$；$\arccos(-0.545) = 123.0^\circ$；$D = 2\times123.0/15 = 16.4$ h。十二月冬至：$\arccos(0.545) = 57.0^\circ$，$D = 7.6$ h。（计入折射，伦敦的发表值约为16.6与7.8 h。）

（b）由 $D = 13$ h，$\omega_0 = 97.5^\circ$，故 $-\tan 40^\circ\tan\delta = \cos 97.5^\circ = -0.1305$，得 $\tan\delta = 0.1305/0.8391 = 0.1556$，$\delta = 8.84^\circ$。于是 $\sin\bigl(360^\circ(n - 80)/365\bigr) = 8.84/23.44 = 0.377$。夏至后赤纬下行经过 $8.84^\circ$ 时 $360^\circ(n-80)/365 = 180^\circ - 22.2^\circ$，即 $n - 80 = 160$，$n = 240$：约**八月28日**。大豆品种按光周期要求划分熟期组，每一组只在狭窄的纬度带种植；为40° N 育成的品种种到夏季日长更短的30° N，会开花过早、产量低。
:::
:::

### 外部巧合模型与成花素

植物如何度量日长？Erwin Bünning 于1936年提出，光周期现象以生物钟为基础：钟把一天分为需光时相与需暗时相，植物开花与否取决于光是否落在特定时相。这一**外部巧合**模型如今已在长日植物 *Arabidopsis* 中于分子层面得到理解。钟驱动基因 *CONSTANS*（*CO*）的表达，使其 mRNA 在黎明后约12–16小时达峰。CO 蛋白在暗中降解，而经 phyA、隐花色素与 FKF1 起作用的光使其稳定。只有在长日中，*CO* 表达的峰值才与光相遇，CO 蛋白遂在傍晚积累。CO 作为转录激活因子，随后在叶的韧皮部伴胞中开启 ***FLOWERING LOCUS T***（*FT*）。水稻是短日植物，同一批基因的线路接成反向响应，使水稻的 *FT* 同源基因 *Hd3a* 在短日下表达。

叶片感受日长、开花的却是茎尖，这一点早已暗示存在可移动的信号。Mikhail Chailakhyan 于1936年将其命名为**成花素**——他先在菊中证明需要经历诱导日的是叶而非茎尖；嫁接实验则表明，诱导叶嫁到未诱导植株上可使其开花，甚至跨物种、跨短日与长日植物。成花素的鉴定历经七十年而未果。2007年，Laurent Corbesier、George Coupland 及同事证明，与 GFP 融合的 FT 蛋白只在 *Arabidopsis* 叶的韧皮部伴胞中合成，却移动到茎尖；Shojiro Tamaki、Ko Shimamoto 及同事对水稻的 Hd3a 得到类似结果。FT 蛋白是一个小蛋白（约20 kDa），经韧皮部运到茎尖，在那里结合转录因子 FD，并与14-3-3蛋白一起激活 *APETALA1* 等花分生组织身份基因，把茎尖分生组织转变为花序分生组织（[[plant-biology/plant-reproduction]]）。成花素是一种蛋白质。

### 春化

许多温带植物——冬小麦、冬大麦、甜菜与甘蓝等二年生植物，以及冬性一年生的 *Arabidopsis* 株系——只有在长时间低温（典型为0–10 °C 附近数周）、继以春季长日之后才开花。这一**春化**要求保证其冬后春开，而非秋前抽薹。在 *Arabidopsis* 中，这一要求由 **FLOWERING LOCUS C**（*FLC*）设定：它是 *FT* 及其他开花基因的 MADS-box 阻遏蛋白，由 *FRIGIDA* 激活。开花迅速的天然株系，如常见的实验室品系，携带 *FRIGIDA* 的功能缺失等位基因或 *FLC* 的弱等位基因（Scott Michaels 与 Richard Amasino，1999）。长期低温以表观遗传方式沉默 *FLC*：Polycomb 组复合体把阻遏性组蛋白标记 H3K27me3 沉积到 *FLC* 位点上，从成核位点开始扩散；植株回到温暖环境后，沉默状态在细胞分裂中得以维持——一种对**冬的细胞记忆**。Caroline Dean、Martin Howard 及同事的实验表明，每个 *FLC* 拷贝的关闭都是全或无式的，关闭概率随低温持续时间增大；植株对更长冬季的渐进响应，是许多细胞中数字式决定的总和。这一记忆在每一代的生殖过程中被抹去，使种子从头开始。

## 温度与热时间

植物的发育既受日长驱动，也受温度驱动。由于发育速率在基点温度之上大致随温度线性增加，农学家以**热时间**度量发育年龄。

::: definition 热时间 {#def-thermal}
一段时间内累积的**热时间**是逐日平均温度超出基点温度 $T_b$ 部分之和，

$$
\Theta = \sum_{\text{days}} \max\!\left(0,\ \bar T_\text{day} - T_b\right),
$$ {#eq-thermal}

单位为**度日**（°C d）。当 $\Theta$ 达到品种的特征值时，植株到达某发育时期（出苗、开花、成熟）。该模型是经验性的：它假定发育速率在基点温度与最适温度之间对温度作线性响应，在最适温度以上失效——那里发育反而减慢。
:::

::: example 至吐丝所需的度日 {#ex-thermal}
某玉米品种（$T_b = 10$ °C）从播种到吐丝需要700 °C d。播种后头九天的日平均温度依次为14、18、22、25、27、24、20、12与9 °C。（a）已累积多少热时间？（b）若本季其余日子平均23 °C，还需多少天吐丝？
::: solution
（a）各天贡献：$4 + 8 + 12 + 15 + 17 + 14 + 10 + 2 + 0 = 82$ °C d。（9 °C 那天贡献为零。）

（b）还剩 $700 - 82 = 618$ °C d；每天 $23 - 10 = 13$ °C d，即 $618/13 = 47.5$，还需约48天。生长季若暖2 °C（平均25 °C，每天15 °C d），便会把它缩为41天——气候变暖缩短作物生育期、削减灌浆可用时间的一个原因。
:::
:::

植物也直接感受温度。一项引人注目的发现是 phyB 本身就是温度感受器：温暖加速 Pfr 向 Pr 的暗逆转，于是温度越高、有活性的 phyB 越少，PIF4 积累，茎伸长——*Arabidopsis* 幼苗的“温度形态建成”（Jae-Hoon Jung、Philip Wigge 及同事；Martina Legris、Jorge Casal 及同事；两项均为2016年）。同一分子同时报告光与温度。

## 胁迫

植物持续处于削减生长或威胁生存的条件下：干旱、盐害、淹水、低温、冰冻、高温与光过剩。它们的响应有共同要素——活性氧作为信号、钙瞬变、激素变化——但每种胁迫都有自己的感受器与通路。

- **干旱。**土壤变干时，ABA 在叶中积累，几分钟内关闭气孔（[[plant-biology/plant-hormones]]）；数小时至数天内，ABA 调控的转录因子诱导一批基因：编码相容性溶质（脯氨酸、甘氨酸甜菜碱、糖类）的基因——在不伤害酶的前提下降低渗透势（**渗透调节**）；编码脱水素等保护蛋白的基因；以及改变根生长的基因——根的生长比茎维持得更久，以便继续探水。
- **低温与冰冻。**温带植物在一段凉爽而不结冰的温度之后耐冻性增强（**冷驯化**）。在 *Arabidopsis* 中，降温后数小时内即被诱导的 CBF/DREB1 转录因子激活一个上百基因的调控子（Michael Thomashow 及同事，自1997–1998年）；其产物稳定膜与蛋白，抵御细胞壁中结冰把水从细胞中抽出所造成的脱水。
- **盐害。**钠在细胞质中有毒。植物限制其进入，经 Na⁺/H⁺ 反向转运体 SOS1 把它排出根细胞（由一条钙感知激酶通路激活——即 Jian-Kang Zhu 及同事阐明的“salt overly sensitive”通路），把它隔离进液泡，并限制其向茎的运输。
- **淹水。**被淹组织缺氧。乙烯在水中的扩散比在空气中慢10,000倍，因而滞留在渍水组织中，触发气道（通气组织，aerenchyma）的形成，并使深水水稻的节间迅速伸长，让叶片留在水面之上。携 *SUB1A* 基因的平原稻种采取相反策略：淹水期间抑制生长以节省能量，洪水退去后再恢复（Kenong Xu、David Mackill、Pamela Ronald、Julia Bailey-Serres 及同事，2006）。

::: application 为多变的气候育种
本章若干机制正被直接用于农业。*SUB1A* 经标记辅助回交导入流行稻种，使之能耐完全淹没两个星期；2009年起发布的 Sub1 品种，已由南亚与东南亚洪泛区的数百万农户种植。小麦中 *Ppd-D1* 基因的等位基因赋予的光周期不敏感性，使绿色革命的半矮秆小麦得以在很宽的纬度带种植。FT 通路中若干基因的日中性等位基因，使番茄、玉米与大豆可以种到远离其起源地纬度的地方。理解春化与热时间，帮助育种者把品种与气候模型预测的更短冬季、更暖夏季相匹配。而避荫反应把资源拨给茎，于是玉米等高密度栽培作物的育种者不知不觉间选择了更少响应邻居的植株。
:::

## 抵御病原体

植物没有循环的免疫细胞，也没有抗体，然而多数植物抗得住多数病原。其免疫系统是细胞自主的：每个细胞都能识别来犯者并作出响应。识别发生在两个层次（Jonathan Jones 与 Jeffery Dangl，2006，曾把它概括为“之字形模型”）。

::: definition 模式触发免疫与效应子触发免疫 {#def-immunity}
**模式触发免疫**（PTI）在细胞表面的**模式识别受体**（受体激酶与受体样蛋白）识别保守的**微生物相关分子模式**时被激活，如细菌鞭毛蛋白（其22肽表位 flg22 由受体 FLS2 识别）或真菌几丁质。**效应子触发免疫**（ETI）在胞内 **NLR** 受体（核苷酸结合、富亮氨酸重复蛋白）识别**效应子**时被激活——效应子是病原注入植物细胞以抑制 PTI 的蛋白——或径直识别效应子，或间接检测效应子在宿主蛋白上造成的改变（“守卫”这些蛋白）。ETI 通常更强，且常以**超敏反应**告终：受感染细胞快速、局限地死亡，使活体营养型病原失去活组织。
:::

ETI 的遗传学远早于其分子被发现。Harold Flor 在1940与1950年代研究亚麻与亚麻锈菌，发现植物中每一个抗性基因都对应病原中一个匹配的无毒基因，且只有当植株携带显性抗性等位基因、病原携带匹配的显性无毒等位基因时才表现抗病——**基因对基因**关系。如今已知抗性基因通常编码 NLR，无毒基因编码效应子。病原通过丢失或改变被识别的效应子来逃避 ETI；植物进化出新的 NLR；结果是这场军备竞赛在 NLR 基因中维持了巨大的多样性——一个植物基因组通常含几十到几百个 NLR 基因。

侵染还在受感染细胞之外触发响应。**系统获得性抗性**由水杨酸及其受体-调节蛋白（NPR 蛋白）介导，使远端叶片在数周内对一大谱系病原严阵以待。咀嚼式口器昆虫造成的创伤激活茉莉酸通路，在全株诱导蛋白酶抑制剂与有毒次生代谢物，并释放挥发性化合物，把昆虫的天敌与拟寄生物引来。以活细胞为食的活体营养型病原，主要靠水杨酸抵御；杀死细胞再取其残骸为食的死体营养型病原以及食草动物，则主要靠茉莉酸与乙烯，两条战线往往相互拮抗。

::: history
De Mairan 的 *Mimosa*（1729）揭示了生物钟。Darwin 与 Darwin（1880）研究了向光性与回旋运动，Cholodny–Went 假说（1926–1928）把向性归因于生长素的再分配。Garner 与 Allard（1920）发现光周期现象；Chailakhyan（1936）提出成花素，Bünning（1936）提出光周期现象的钟基理论；Hamner 与 Bonner（1938）表明夜的关键作用。Borthwick、Hendricks 及同事（1952）发现红光/远红光可逆性，Butler 及同事（1959）发现光敏色素本身。Flor 的基因对基因概念出自1940与1950年代。分子时代带来了首个被克隆的光敏色素基因（1985）、*CONSTANS*（1995）、荧光素酶生物钟筛选（1995）、FLS2（2000）、FT 即成花素（2007）与 phyB 的温度感受器功能（2016）。
:::

## 小结

::: summary
- **光受体**：光敏色素（红/远红）、隐花色素、向光素与 ZTL 家族（蓝光）、UVR8（紫外-B）。
- 光敏色素在无活性的 Pr 与有活性的 Pfr 之间切换；其光平衡 $\varphi = k_1/(k_1 + k_2)$（红光中约0.87，远红光中0.02）报告 R : FR 比，冠层会压低该比值。phyB 经 PIF 与生长素驱动避荫反应；phyA 介导极低照度与远红响应；光使 COP1 失活，从而放开光形态建成。
- 向光性（向光素）与向重力性（根冠柱细胞与茎内皮层中的平衡石）经 PIN 介导的生长素再分配起作用；根与茎因生长素敏感度不同而响应相反。
- **生物钟**（CCA1/LHY–TOC1/PRR 环）以接近24 h 的周期自由运行，由光与温度同步化，且温度补偿（$Q_{10} \approx 1$）。内部周期与外界匹配则生长更好。
- **光周期现象**：短日植物度量夜长（暗期间断阻止开花）。日长由 $D = (2/15)\arccos(-\tan\phi_\ell\tan\delta)$ 给出。*Arabidopsis* 中，钟驱动的 CO 与光外部巧合，在叶中诱导 **FT**；FT 蛋白经韧皮部运到茎尖（成花素）。
- **春化**以 Polycomb 标记表观遗传地沉默 FLC，是对低温的细胞自主、数字式的记忆。
- 发育遵循热时间 $\sum\max(0, \bar T - T_b)$；phyB 也感受温度。
- 胁迫响应：ABA 与渗透调节（干旱）、CBF 调控子（低温）、SOS 通路（盐）、乙烯与 SUB1A（淹水）。
- **免疫**：表面受体识别微生物模式的 PTI；NLR 识别效应子的 ETI（基因对基因），伴超敏反应；系统获得性抗性（水杨酸）与茉莉酸介导的抗食草动物防御。
:::

生活史的最后一环——花、传粉、受精与种子——是 [[plant-biology/plant-reproduction]] 的主题。

::: exercise 暗期间断与嫁接 {level=2}
（a）临界夜长10小时的短日植物，给予14小时黑暗、在第7小时后插入10分钟的红光中断。预测它是否开花并解释。（b）红光中断之后立即接以远红光，同样预测。（c）一株经诱导的苍耳上的一片叶，嫁接到保持长日的植株上，后者开了花。这说明了什么？（d）FT–GFP 融合蛋白的实验如何回答了（c）提出的问题？
::: solution
（a）不开：光中断把夜分成两段7小时，每段都短于临界的10小时，植物表现得如同处于短夜。
（b）开花：远红逆转红光对光敏色素的转化，中断被撤销。
（c）被诱导的叶产生了可传递的开花信号（成花素），它能越过嫁接愈合处、作用于未诱导的植株：感受（在叶）与响应（在茎尖）是分离的，且信号会移动。
（d）仅由伴胞特异启动子驱动、只在叶韧皮部伴胞中表达的 FT 蛋白，在茎尖被检测到，且足以诱导开花；在茎尖合成的 FT 并非必需。于是可移动信号包括 FT 蛋白本身，它经韧皮部运输。

::: exercise 冬的记忆 {level=2}
一个冬性一年生 *Arabidopsis* 株系在5 °C 分别接受0、2、4、6或8周低温，然后移入温暖的长日。开花时叶片数随低温延长逐步下降，从60叶（未受低温）到12叶（8周）。（a）用 *FLC* 解释这一结果。（b）单细胞成像显示，4周后约半数细胞中 *FLC* 完全关闭，其余完全开启。全株的渐进响应如何能从单细胞的全或无切换产生？（c）沉默状态为何经有丝分裂传递，却在种子中被重置？
::: solution
（a）低温逐步沉默 *FLC*，而 *FLC* 阻遏 *FT* 及其他成花促进因子；低温越长，*FLC* 越少，其后的长日中开花越早。
（b）每个 *FLC* 拷贝随机关闭，低温下单位时间的关闭概率一定；已关闭细胞的比例随低温持续时间上升，植株的响应反映跨细胞的平均 *FLC* 表达。概率渐变的数字开关，产生群体水平的模拟响应。
（c）Polycomb 介导的组蛋白甲基化（H3K27me3）在复制时被复制到子代染色质上，维持关闭状态；生殖过程中（配子发生与胚胎发生期间）*FLC* 被重新激活，故每一代都需要自己的冬天——必须如此，因为种子将在新的季节里成长。
:::

::: exercise 基因对基因 {level=3}
亚麻中，抗性基因 *L6*（显性等位基因 *L6*，隐性 *l6*）识别锈菌效应子 AvrL567（显性 *AvrL567*，隐性 *avrL567*，即不被识别的变体）。（a）补全 *L6*/–、*l6 l6* 两类植株感染携带 *AvrL567* 或 *avrL567* 的锈菌分离物后的结果表（抗病或染病）。（b）解释为什么携带单个 NLR 基因的新品种常在数年内被病原克服，并提出两种使抗性更持久的育种策略。（c）为什么 PTI 单独不能给植物持久的保护？
::: solution
（a）只有植株有 *L6* 且锈菌有 *AvrL567* 时才抗病：植株为 *L6*/–，锈菌携 *AvrL567* → 抗病；植株为 *L6*/–，锈菌携 *avrL567* → 染病；植株为 *l6 l6*，无论锈菌基因型 → 染病。
（b）只要该效应子并非必需，对病原的选择就有利于丢失或改变被识别效应子的变体；在大病原群体中，这类变体很快出现并扩散。策略：在一个品种中聚合识别不同效应子的若干 NLR（病原必须同时改变所有靶标）；瞄准病原致病力所必需的效应子；在不同田块或不同年份部署不同抗性基因；以及把 NLR 与量化的广谱抗性相结合。
（c）成功的病原已进化出抑制 PTI 的效应子；PTI 挡得住大多数潜在病原（未适应的微生物），但已适应的病原能克服它，ETI 正是植物对这种抑制的反制。
:::

::: exercise 节律共振 {level=3}
在 Dodd 及同事的实验中，周期20小时（*toc1* 型）与28小时（*ztl* 型）的突变体以及野生型（24小时）分别栽培于20、24与28小时的光暗周期（半明半暗）中。每种基因型在与其自身周期匹配的循环中固定碳最多。（a）从对黎明的预期与夜间淀粉的利用出发，设想错配的生物钟为何可能减少碳固定。（b）为什么必须在三种周期中检测全部三种基因型，而不只在24小时光暗中比较突变体与野生型？（c）对生物钟失能（无节律）的植株，你在三种周期中预期如何？
::: solution
（a）钟在黎明前预备光合基因，并把夜间淀粉的分解速率设定为恰好持续到预期的黎明。周期错配时，光合装置预备的时刻不对，气孔开放的时刻不对，淀粉或在黎明前耗尽（挨饿浪费生长时间），或剩余未用。
（b）只在24小时光暗中比较突变体与野生型，会把突变对周期的影响与突变的任何其他效应（多效性）混为一谈；采用完整的交叉设计，“共振”交互——每种基因型在其匹配的周期中表现最好——才能与突变体的一般缺陷区分开来。
（c）无节律的植株既不能预期黎明，也不能把淀粉分解定时于任何周期，故在三种周期中都应表现不佳，且没有偏好——无节律品系的实测正是如此。
:::
