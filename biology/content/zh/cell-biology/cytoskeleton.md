一个成纤维细胞在培养皿上爬行时，在前端推出薄薄的细胞质片，抓住表面，并把身体拉在身后。分裂的细胞构建纤维纺锤体，以惊人精度分离染色体，然后把自己掐成两半。神经元把囊泡沿轴突送出一米，精子细胞拍打尾部游动，而你手臂的肌肉在纤维彼此滑过时收缩。所有这些工作都由**细胞骨架**完成：一组蛋白质丝、制造与破坏它们的蛋白质，以及沿它们行走的马达蛋白。

这个名字暗示刚性支架，而这有误导。细胞骨架由不断添加和移除的亚基构成，因此一个结构可以在一个地方拆解、在另一个地方几分钟内重建。本章介绍三种纤维系统，解释纤维聚合如何被控制以及它如何推动，描述把 ATP 转化为沿纤维运动的马达，并把这些部件放进纤毛、肌肉与爬行细胞中。我们只需要少数定量概念：临界浓度、延伸速率、步长和力。细胞骨架在分裂中的作用在 [[cell-biology/cell-cycle]] 中讨论。

## 三种纤维

| | 肌动蛋白丝（微丝） | 微管 | 中间丝 |
|---|---|---|---|
| 亚基 | 肌动蛋白，42 kDa，结合 ATP | α/β-微管蛋白异二聚体，2 × 50 kDa，结合 GTP | 多家族：角蛋白、波形蛋白、神经丝蛋白、核纤层蛋白 |
| 结构 | 双链螺旋，宽约 7 nm | 13 条原丝构成的中空管，外径 25 nm | 截面 8 个四聚体的绳，宽约 10 nm |
| 极性 | 有：有刺（+）端与尖（−）端 | 有：正端与负端 | 无 |
| 马达 | 肌球蛋白 | 驱动蛋白、动力蛋白 | 无 |
| 典型作用 | 细胞皮层、突出、收缩、胞质分裂、微绒毛 | 长距离运输、纺锤体、纤毛、组织细胞质 | 机械强度；核纤层 |

肌动蛋白是真核细胞中最丰富的蛋白质之一——占总蛋白的百分之几，非肌肉细胞中浓度约 100 µmol L⁻¹——也是最保守的之一：酵母与人肌动蛋白序列约 90% 相同。每个亚基给纤维增加 2.75 nm，所以 1 µm 纤维含约 370 个亚基。微管每层 13 个微管蛋白二聚体增加 8 nm，每微米约 1600 个二聚体。

细菌两者都有同源物。FtsZ 是微管蛋白同源物，形成收缩分裂细菌的环；MreB 是肌动蛋白同源物，指导杆状细菌细胞壁合成；另一个肌动蛋白同源物 ParM 把质粒推开。它们在 1990 年代与 2000 年代初的发现表明细胞骨架比真核细胞更古老。相比之下，中间丝只见于动物（细菌 *Caulobacter* 中的 crescentin 等远亲）。

::: definition 聚合物极性、临界浓度与踏车运动 {#def-critical-concentration}
肌动蛋白丝与微管是**极性**聚合物：每个亚基朝向相同，因此两端在结构与动力学上不同。在每一端，亚基以正比于自由亚基浓度 $c$ 的速率 $k_\mathrm{on}c$ 加入，以不依赖 $c$ 的速率 $k_\mathrm{off}$ 离开。一端的**临界浓度**为 $C_\mathrm{c} = k_\mathrm{off}/k_\mathrm{on}$：高于它该端生长，低于它该端缩短。两端临界浓度不同时，存在一个 $c$ 范围，一端生长而另一端缩短；在两者平衡的稳态，亚基从一端穿过纤维到另一端，称为**踏车运动（treadmilling）**。
:::

## 聚合动力学

::: proposition 聚合物端的延伸速率 {#prop-elongation}
对结合速率常数 $k_\mathrm{on}$ 与解离速率常数 $k_\mathrm{off}$ 的一端，亚基净加入速率为

$$
\frac{dn}{dt} = k_\mathrm{on}c - k_\mathrm{off} = k_\mathrm{on}\,(c - C_\mathrm{c}),
$$ {#eq-elongation}

且该端以 $\delta\,(k_\mathrm{on}c - k_\mathrm{off})$ 前进，$\delta$ 是每个亚基增加的长度。假设：亚基一次一个加入和离开；自由亚基浓度 $c$ 恒定（大池）；在所考虑时间内端不改变状态，例如不水解其结合的核苷酸。
:::

对 ATP-肌动蛋白，Thomas Pollard 在 1986 年用从种子生长的纤维电镜测得，有刺端 $k_\mathrm{on} = 11.6\ \mathrm{\mu M^{-1}\,s^{-1}}$、$k_\mathrm{off} = 1.4\ \mathrm{s^{-1}}$，尖端 $k_\mathrm{on} = 1.3\ \mathrm{\mu M^{-1}\,s^{-1}}$、$k_\mathrm{off} = 0.8\ \mathrm{s^{-1}}$。

::: example 肌动蛋白丝长多快？ {#ex-actin-growth}
用 Pollard 常数计算：(a) 每端的临界浓度；(b) 在 10 µM ATP-肌动蛋白中每端生长速率（亚基每秒与纳米每秒）；(c) 纤维长度不变地踏车运动的浓度及踏车速率。
::: solution
(a) 有刺端：$C_\mathrm{c} = 1.4/11.6 = 0.12\ \mathrm{\mu M}$。尖端：$C_\mathrm{c} = 0.8/1.3 = 0.62\ \mathrm{\mu M}$。

(b) 有刺端：$11.6\times10 - 1.4 = 115\ \mathrm{s^{-1}}$，所以 $115\times2.75 = 315\ \mathrm{nm\,s^{-1}}$，约 0.3 µm 每秒。尖端：$1.3\times10 - 0.8 = 12\ \mathrm{s^{-1}}$，约 34 nm s⁻¹。有刺端生长快近十倍，这就是它被称为“正”端的原因。

(c) 两端净速率相加为零时总长度恒定：$(11.6 + 1.3)c = 1.4 + 0.8$，所以 $c_\mathrm{ss} = 2.2/12.9 = 0.17\ \mathrm{\mu M}$，位于两个临界浓度之间。此时有刺端每秒获得 $11.6\times0.17 - 1.4 = 0.58$ 个亚基，尖端失去同样多：在 1 µm 纤维有刺端加入的亚基约 $370/0.58 \approx 640\ \mathrm{s}$ 后到达尖端，约十分钟。
:::
:::

纯肌动蛋白中的踏车运动很慢；细胞用辅助蛋白大大加速它，如我们将在爬行细胞中看到。

::: intuition 为什么两端可以不同：核苷酸的成本
对简单平衡聚合物，两端*必须*有相同临界浓度：向任一端加亚基产生同一纤维，所以自由能变化因而 $k_\mathrm{off}/k_\mathrm{on}$ 相同。肌动蛋白与微管蛋白逃脱这一点，因为它们在聚合后水解核苷酸。亚基以 ATP-肌动蛋白（或 GTP-微管蛋白）加入，但从纤维较老部分离开时是 ADP-肌动蛋白（GDP-微管蛋白），后者结合更松。两端主要暴露的核苷酸状态不同，水解为踏车运动与微管的动态不稳定性付费。仅用 ADP-肌动蛋白测量时，两个临界浓度确实相等。
:::

### 成核

起始纤维比延伸难得多：两三个肌动蛋白亚基彼此结合很弱，所以自发成核慢，这让细胞决定纤维在哪里开始。它们用成核蛋白。**Arp2/3 复合体**（Laura Machesky 与 Thomas Pollard，1994，来自 *Acanthamoeba*）结合已有纤维侧面并以 70° 开始分支，构建爬行细胞前端的树状网络。**Formin 蛋白**位于生长无分支纤维的有刺端，如胞质分裂环与应力纤维中。微管由 **微管组织中心**的γ-微管蛋白环成核——动物细胞中主要是**中心体**，一对中心粒位于中心粒周围物质的云中——所以多数微管的负端靠近细胞中心，正端朝外。

其他蛋白质调节池与纤维：profilin 与胸腺素β4 结合自由肌动蛋白亚基（保持大量未聚合储备），加帽蛋白阻断有刺端，丝切蛋白（cofilin）切断并解聚较老的 ADP-肌动蛋白，许多交联蛋白把纤维束成束（微绒毛与丝状伪足）或连成凝胶（皮层）。

### 微管的动态不稳定性

1984 年 Tim Mitchison 与 Marc Kirschner 发现，从中心体在体外生长的微管并不稳定生长。单个微管缓慢生长一段时间，然后突然转为快速缩短——**灾难（catastrophe）**——然后有时转回——**救援（rescue）**。他们称之为**动态不稳定性**。原因是 GTP 帽：微管蛋白二聚体以其β亚基上的 GTP 加入并很快水解；只要端部带有 GTP-微管蛋白帽，晶格稳定，但若水解赶上加入，暴露的 GDP-微管蛋白原丝向外卷曲，微管解体。

动态不稳定性让细胞搜索空间。从中心体随机方向生长的微管探索细胞质，若其正端被捕获——被染色体上的动粒或皮层位点——则稳定，否则迅速撤回并由另一方向的新微管替代。Marileen Dogterom 与 Stanislas Leibler（1993）把这种搜索的统计给出紧凑形式。

::: proposition 动态不稳定微管的平均长度 {#prop-dogterom}
微管端以速度 $v_\mathrm{g}$ 生长、$v_\mathrm{s}$ 缩短，从生长转为缩短的速率为 $f_\mathrm{cat}$，转回为 $f_\mathrm{res}$。其平均漂移速度为

$$
J = \frac{v_\mathrm{g}f_\mathrm{res} - v_\mathrm{s}f_\mathrm{cat}}{f_\mathrm{cat} + f_\mathrm{res}}.
$$ {#eq-drift}

若 $J > 0$，微管无限生长（直到遇到细胞边缘）。若 $J < 0$，长度分布为指数分布，均值为

$$
\bar L = \frac{v_\mathrm{g}v_\mathrm{s}}{v_\mathrm{s}f_\mathrm{cat} - v_\mathrm{g}f_\mathrm{res}}.
$$ {#eq-mean-length}

假设：转换速率与速度恒定（不依赖长度与时间），微管在固定位点成核并在完全解聚后立即重生长，两个状态无记忆。
:::

::: proof 漂移速度
微管在平均时长 $1/f_\mathrm{cat}$ 的生长阶段与 $1/f_\mathrm{res}$ 的缩短阶段间交替，所以长期看它花 $f_\mathrm{res}/(f_\mathrm{cat}+f_\mathrm{res})$ 的时间生长、$f_\mathrm{cat}/(f_\mathrm{cat}+f_\mathrm{res})$ 的时间缩短。其平均速度是时间加权平均，$J = v_\mathrm{g}\cdot\frac{f_\mathrm{res}}{f_\mathrm{cat}+f_\mathrm{res}} - v_\mathrm{s}\cdot\frac{f_\mathrm{cat}}{f_\mathrm{cat}+f_\mathrm{res}}$。长度分布来自生长与缩短微管两个耦合平流方程的稳态解（Dogterom 与 Leibler，1993）；我们引用结果。
:::

::: example 微管的典型长度 {#ex-microtubule}
在代表性的间期细胞中，微管正端以 1.5 µm min⁻¹ 生长、以 20 µm min⁻¹ 缩短，$f_\mathrm{cat} = 0.01\ \mathrm{s^{-1}}$、$f_\mathrm{res} = 0.05\ \mathrm{s^{-1}}$（体内测量量级的示例值）。生长有界吗，平均长度是多少？
::: solution
换算速度：$v_\mathrm{g} = 0.025\ \mathrm{\mu m\,s^{-1}}$，$v_\mathrm{s} = 0.333\ \mathrm{\mu m\,s^{-1}}$。则

$$
J = \frac{0.025\times0.05 - 0.333\times0.01}{0.06} = \frac{0.00125 - 0.00333}{0.06} = -0.035\ \mathrm{\mu m\,s^{-1}} < 0,
$$

所以生长有界，且

$$
\bar L = \frac{0.025\times0.333}{0.00333 - 0.00125} = \frac{0.00833}{0.00208} = 4.0\ \mathrm{\mu m}.
$$

微管花六分之五时间生长，但平均很短，因为缩短快得多。把 $f_\mathrm{cat}$ 减半（[[#exr-catastrophe]]）使平均长度增至五倍，到 20 µm：转换速率的小变化使网络大变。细胞正用这一杠杆，通过促进或抑制灾难的蛋白质，在有丝分裂开始时重塑微管。
:::
:::

### 聚合可以推动

一个生长纤维的端抵住膜时，只要热涨落打开一个亚基长度的间隙，它仍能加入亚基。这种**布朗棘轮**机制（Charles Peskin、Garrett Odell 与 George Oster，1993，基于 Terrell Hill 的热力学）意味着聚合本身能做功。单纤维能产生的最大力由热力学得出：逆力 $F$ 加入一个亚基需做功 $F\delta$，所以纤维在 $F\delta = k_\mathrm{B}T\ln(c/C_\mathrm{c})$ 时停滞：

$$
F_\text{stall} = \frac{k_\mathrm{B}T}{\delta}\ln\frac{c}{C_\mathrm{c}}.
$$ {#eq-stall}

::: example 一条肌动蛋白丝能推多硬？ {#ex-stall}
估计 37 °C 下 10 µM ATP-肌动蛋白中有刺端生长的单条肌动蛋白丝的停滞力，并与马达蛋白的力比较。
::: solution
取 $C_\mathrm{c} = 0.12\ \mathrm{\mu M}$，$c/C_\mathrm{c} = 83$；$\delta = 2.75\ \mathrm{nm}$，$k_\mathrm{B}T = 4.28\ \mathrm{pN\,nm}$，

$$
F_\text{stall} = \frac{4.28}{2.75}\ln 83 = 1.56\times4.42 \approx 7\ \mathrm{pN}.
$$

这与单个驱动蛋白的停滞力相当（约 6 pN，见 [[#ex-kinesin]]）：聚合本身就是马达。该估计是上限，因为真实纤维端也涨落并可能弯曲；单纤维实测力约 1–10 pN。许多纤维的分支网络推动爬行细胞的前缘。
:::
:::

## 马达蛋白

马达蛋白水解 ATP，并用能量沿纤维运动，每一步偶联构象变化。存在三族。

::: definition 马达蛋白 {#def-motor}
**马达蛋白**是把 ATP 水解自由能转化为沿极性纤维有向机械功的酶，通过结合、构象变化（**动力冲程**）与释放的循环，偶联 ATP 结合、其水解以及 ADP 与磷酸释放。**肌球蛋白**在肌动蛋白上运动（多数朝有刺端）；**驱动蛋白**在微管上运动（多数朝正端）；**动力蛋白**在微管上朝负端运动。若单个分子不脱离地走许多步，马达是**持续性的**，如双头驱动蛋白-1 与肌球蛋白 V 始终保持至少一个头结合。
:::

驱动蛋白由 Ronald Vale、Thomas Reese 与 Michael Sheetz 在 1985 年发现，他们观察从乌贼 *Loligo pealei* 巨轴突挤出的细胞质中沿纤维运动的细胞器，并纯化负责的蛋白质。1990 年代单分子实验，尤其 Karel Svoboda、Steven Block 及同事（1993–94）的光阱测量，表明驱动蛋白-1 以**8 nm 步长**手递手行走——一个微管蛋白二聚体的长度——每步消耗一个 ATP，最高约 0.8 µm s⁻¹，并在约 6 pN 负载下停滞。

::: example 驱动蛋白的效率 {#ex-kinesin}
(a) 驱动蛋白-1 在 0.8 µm s⁻¹ 下每秒走多少步？(b) 在略低于其 6 pN 停滞力的负载下每步做多少功？(c) 与细胞中水解一个 ATP 分子约 55 kJ mol⁻¹ 的自由能比较，估计效率。
::: solution
(a) $800\ \mathrm{nm\,s^{-1}}/8\ \mathrm{nm} = 100$ 步每秒，因而约 100 ATP 每秒。

(b) $W = F\delta = 6\ \mathrm{pN}\times8\ \mathrm{nm} = 48\ \mathrm{pN\,nm} = 4.8\times10^{-20}\ \mathrm{J}$。

(c) 每分子，$55\times10^3/6.022\times10^{23} = 9.1\times10^{-20}\ \mathrm{J} = 91\ \mathrm{pN\,nm}$，约 $21\,k_\mathrm{B}T$。接近停滞时的效率为 $48/91 \approx 50\ \%$。马达蛋白是异常高效的机器——可与最好的自制发动机相比——因为它们在分子尺度上接近热力学可逆。
:::
:::

细胞用马达做许多事。驱动蛋白与细胞质动力蛋白沿微管运输囊泡、线粒体、mRNA 与病毒——在轴突中，驱动蛋白把货物从细胞体运出，动力蛋白把它带回，即**快速轴突运输**，解决了 [[cell-biology/cells-and-microscopy#ex-diffusion-times]] 的扩散问题。肌球蛋白 V 沿肌动蛋白以 36 nm 步幅运输货物。肌球蛋白 II 组装成双极粗丝，通过把反平行肌动蛋白丝拉在一起产生收缩，在肌肉与分裂细胞的收缩环中。

::: warning “马达蛋白靠消耗纤维来拉货物”——或“纤维是刚性轨道”
两个相反的误解很常见。马达不消耗或解聚它们行走的纤维（有些特化例外，如驱动蛋白-13，它解聚微管端而不行走）；能量来自 ATP。而“轨道”不是永久的：纤维本身是动态的，常在几分钟内周转，聚合与马达活动协作——爬行细胞前端，肌动蛋白聚合推动，而肌球蛋白 II 把网络向后拉。相关错误是认为细胞骨架只是结构性的：通过其马达与动态，它是细胞运动与组织的主要机器。
:::

## 纤毛与鞭毛

真核**纤毛**与**鞭毛**（同一结构，名称反映数量与长度）是围绕**轴丝**构建的鞭状质膜延伸：九条二联体微管环围绕中央一对——即“9 + 2”排列——锚定在**基体**，一个类似中心粒的结构。Ian Gibbons 在 1965 年于原生生物 *Tetrahymena* 的纤毛中发现驱动它们的马达**轴丝动力蛋白**（名称来自希腊语“力”）。附着于每条二联体的动力蛋白臂沿相邻二联体行走。1971 年 Keith Summers 与 Gibbons 表明，若海胆精子轴丝用蛋白酶短暂消化后给 ATP，二联体彼此滑过，轴丝伸长约数倍。完整轴丝中连接蛋白阻止自由滑动，所以滑动转为弯曲。

真核鞭毛与细菌鞭毛无关；细菌鞭毛是蛋白质 flagellin 的刚性螺旋丝，其基部由跨细菌膜的质子（或钠）梯度驱动的旋转马达转动。

多数脊椎动物细胞还有单个不动的**初级纤毛**，轴丝为“9 + 0”，充当信号天线：脊椎动物中 Hedgehog 途径（[[cell-biology/cell-signalling]]）在其中运作。纤毛缺陷导致一系列遗传病，即纤毛病（[医学图谱：遗传学](/learn/medicine/course.php?c=genetics)）。

## 肌肉：滑丝机制

骨骼肌是最有序的肌动蛋白–肌球蛋白系统。每条肌纤维是巨大的多核细胞，充满肌原纤维，即约 2–3 µm 长的重复**肌节**链。每个肌节由两侧 Z 盘锚定的细肌动蛋白丝组成，与中间约 1.6 µm 长的肌球蛋白 II 双极粗丝交错。1954 年两对研究者——Hugh Huxley 与 Jean Hanson 用兔肌肉的相差与电镜，Andrew Huxley 与 Rolf Niedergerke 用蛙纤维的干涉显微镜——独立表明收缩时纤维长度不变：它们彼此滑过，肌节缩短时重叠增加。

每个肌球蛋白头循环：结合肌动蛋白，释放磷酸，摆动杠杆臂完成约 5–10 nm 的动力冲程，释放 ADP，结合 ATP（这使它脱离——所以 ATP 耗尽时出现尸僵），并水解 ATP 重新上膛。收缩由肌质网释放的 Ca²⁺ 开启（[[cell-biology/organelles]]），Ca²⁺ 结合细丝上的肌钙蛋白并使原肌球蛋白离开肌球蛋白结合位点。纤维产生的力取决于多少头能触及肌动蛋白，因而取决于纤维重叠——[[#exr-length-tension]] 的长度–张力关系。人体肌肉生理在[医学图谱：肌肉](/learn/medicine/lesson.php?c=physiology&l=muscle)。

## 爬行细胞

许多动物细胞在表面爬行：愈合伤口的成纤维细胞、追捕细菌的中性粒细胞、延伸轴突的神经元生长锥、胚胎中迁移的细胞。爬行有四部分。

1. **突出。** 前缘推出扁平的**片状伪足**，由 Arp2/3 成核的树状肌动蛋白网络在其有刺端逆膜生长，如 [[#eq-stall]]；细指状的**丝状伪足**由 formin 制造的平行纤维束推出。网络踏车运动：前端组装，后方由丝切蛋白解聚，亚基循环。
2. **黏附。** 前端的跨膜**整合素**结合细胞外基质，并通过 talin、vinculin 等接头蛋白连接到肌动蛋白网络，形成作为离合器的黏着斑（[[cell-biology/tissues-and-cell-death]]）。
3. **收缩。** 细胞体与后部的肌球蛋白 II 收缩肌动蛋白网络，把细胞体向前拉向黏附。
4. **回缩。** 后部黏附释放，尾部跟随。

鱼表皮角质细胞以近恒定扇形约 10–20 µm 每分钟滑行，是受欢迎的模型，因为这些步骤同时稳定进行。Rho 家族小 GTP 酶信号——Rac 管片状伪足、Cdc42 管丝状伪足、Rho 管收缩（Alan Hall 与 Anne Ridley，1992）——协调它们并把细胞导向吸引物梯度，如中性粒细胞朝细菌肽移动。

::: application 作用于细胞骨架的药物
由于微管对有丝分裂纺锤体必需，扰动其动态的药物阻止分裂细胞。来自秋水仙的秋水仙碱结合微管蛋白二聚体并阻止聚合；它是 1960 年代鉴定微管蛋白的工具（Gary Borisy 与 Edwin Taylor，1967）。来自太平洋红豆杉树皮的紫杉醇（taxol）相反：结合微管并稳定它们（Peter Schiff、Jane Fant 与 Susan Horwitz，1979）。两种效应都阻断有丝分裂，紫杉烷与长春碱类用于癌症化疗（[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)）。对肌动蛋白，鬼笔环肽（来自毒鹅膏菌）稳定纤维，与荧光染料结合后是固定细胞中 F-肌动蛋白的标准染色；细胞松弛素加帽有刺端，红海海绵素（latrunculin）隔离单体，两者都用于研究检验某过程是否需要肌动蛋白动态。
:::

::: quiz
细胞用低剂量药物轻微降低微管灾难速率，但生长与缩短速度不变。按 [[#prop-dogterom]]，微管网络会怎样？
- [ ] 什么也不变，因为速度不变。
- [ ] 微管变短，因为可救援的缩短事件更少。
- [x] 微管平均变长，并可能从有界生长转为无界生长。

## 中间丝

中间丝因直径约 10 nm 得名，介于肌动蛋白丝与微管之间。其亚基是长纤维状蛋白，有中央α螺旋杆，成对盘绕；对以反平行方式结合成四聚体，所以纤维无极性，八个四聚体并排构成绳状纤维。中间丝不结合核苷酸，无马达，异常坚韧且可伸展，能拉到数倍长度而不破裂。它们给细胞与组织机械强度：上皮中的角蛋白（人有 54 个功能角蛋白基因）、间充质细胞中的波形蛋白、肌肉中的结蛋白、轴突中的神经丝，以及所有动物细胞中形成核纤层的**核纤层蛋白**。角蛋白丝锚定在桥粒与半桥粒，在上皮中把机械负载从细胞传到细胞。Elaine Fuchs 的团队在 1991 年表明表达突变角蛋白的小鼠在轻微摩擦下皮肤起疱，如人类单纯性大疱性表皮松解症，证明纤维的功能是机械的。

::: history
肌动蛋白由 Brunó Straub 在 Albert Szent-Györgyi 于塞格德的实验室中于 1942 年从肌肉纯化；Szent-Györgyi 表明肌动球蛋白线加 ATP 后收缩。滑丝理论来自 1954 年两篇 Huxley 论文，Andrew Huxley 的横桥模型随后于 1957 年出现。Keith Porter 等人在 1960 年代初的电镜中看到微管，此前戊二醛固定保存了它们，Gary Borisy 与 Edwin Taylor 在 1967 年鉴定微管蛋白为秋水仙碱结合蛋白。Ian Gibbons 在 1965 年命名动力蛋白，Ronald Vale、Thomas Reese 与 Michael Sheetz 在 1985 年发现驱动蛋白，Tim Mitchison 与 Marc Kirschner 在 1984 年描述动态不稳定性。单驱动蛋白步长的光阱测量（Svoboda、Schmidt、Schnapp 与 Block，1993）与单肌球蛋白动力冲程测量（Jeffrey Finer、Robert Simmons 与 James Spudich，1994）把马达蛋白变成定量机器。1998 年 Jan Löwe 与 Linda Amos 解出 FtsZ 结构并表明它是微管蛋白同源物，2001 年 Fusinita van den Ent、Amos 与 Löwe 对 MreB 与肌动蛋白做了同样的事。
:::

::: summary
- 细胞骨架有三种纤维系统：肌动蛋白丝（7 nm、极性、ATP）、微管（25 nm 中空管，13 条原丝，极性、GTP）与中间丝（10 nm、无极性、机械性）。细菌有肌动蛋白与微管蛋白同源物。
- 每个纤维端以 $k_\mathrm{on}c - k_\mathrm{off}$ 生长，临界浓度 $C_\mathrm{c} = k_\mathrm{off}/k_\mathrm{on}$；ATP-肌动蛋白有刺端 0.12 µM，尖端 0.6 µM。核苷酸水解使两端不同并允许踏车运动。
- 成核蛋白（Arp2/3、formin、γ-微管蛋白）与调节蛋白决定纤维何时何地形成；聚合可推动，每条纤维几皮牛。
- 微管显示动态不稳定性；平均长度 $\bar L = v_\mathrm{g}v_\mathrm{s}/(v_\mathrm{s}f_\mathrm{cat} - v_\mathrm{g}f_\mathrm{res})$ 对灾难速率非常敏感。
- 肌球蛋白（肌动蛋白）、驱动蛋白（正端）与动力蛋白（负端）把 ATP 转为逐步运动；驱动蛋白-1 走 8 nm 步，每步一个 ATP，在 6 pN 停滞力附近效率约 50%。
- 纤毛与鞭毛由动力蛋白驱动 9 + 2 微管二联体滑动而弯曲；肌肉由肌动蛋白与肌球蛋白丝滑动收缩，由 Ca²⁺ 开启。
- 爬行细胞由肌动蛋白聚合突出，经整合素黏附，用肌球蛋白 II 收缩并回缩尾部，由 Rho 家族 GTP 酶协调。
:::

::: exercise 哪种纤维系统？ {level=2}
培养成纤维细胞依次用四种药物处理。预测并说明哪些过程被阻断：(a) latrunculin（红海海绵素），隔离肌动蛋白单体；(b) 秋水仙碱，阻断微管蛋白聚合；(c) 肌球蛋白 II ATP 酶抑制剂（blebbistatin）；(d) 阻断动力蛋白的药物。考虑的过程：片状伪足突出、细胞体移位、有丝分裂、胞质分裂、高尔基体在中心体附近的聚集。
::: solution
(a) Latrunculin 停止肌动蛋白聚合，片状伪足立即停止；移位与胞质分裂（收缩环）失败。有丝分裂本身（染色体分离）可进行，但细胞不能分裂，产生双核细胞。
(b) 秋水仙碱解聚微管：纺锤体不能形成，细胞停于有丝分裂；高尔基体带由动力蛋白沿微管拉到中心体附近，此时碎裂并分散。爬行继续但失去方向（微管帮助极化细胞）。
(c) 肌球蛋白 II 抑制阻断胞质分裂以及移动细胞体和回缩尾部的收缩，而突出继续——细胞可能摊宽并长出长尾。
(d) 动力蛋白抑制分散高尔基体并破坏纺锤体组装与定位，所以有丝分裂受损；负端向内体运输停止。
:::
:::

::: exercise 更少灾难 {#exr-catastrophe level=3 check="20"}
把 [[#ex-microtubule]] 的灾难频率减半到 $f_\mathrm{cat} = 0.005\ \mathrm{s^{-1}}$，其他值不变。生长仍有界吗？新的平均长度是多少 µm？然后求生长变为无界的灾难频率。
::: solution
$J = (0.025\times0.05 - 0.333\times0.005)/0.055 = (0.00125 - 0.00167)/0.055 = -0.0076\ \mathrm{\mu m\,s^{-1}}$：仍有界。$\bar L = 0.00833/(0.00167 - 0.00125) = 0.00833/0.000417 = 20\ \mathrm{\mu m}$。

生长在 $v_\mathrm{s}f_\mathrm{cat} = v_\mathrm{g}f_\mathrm{res}$ 时变为无界，即 $f_\mathrm{cat} = 0.025\times0.05/0.333 = 0.00375\ \mathrm{s^{-1}}$。接近转变时平均长度发散：在 20 µm 细胞中，灾难速率的适度变化把短而搜索的微管网络变为到达细胞边缘的长微管。有丝分裂开始时，细胞把 $f_\mathrm{cat}$ 提高数倍，产生纺锤体的短而动态微管。
:::

::: exercise 低浓度下的聚合力 {level=3 check="3.3"}
用 [[#eq-stall]] 计算 1.0 µM 自由 ATP-肌动蛋白中单条肌动蛋白丝的停滞力（pN，两位有效数字），取 $C_\mathrm{c} = 0.12\ \mathrm{\mu M}$、$\delta = 2.75\ \mathrm{nm}$、$k_\mathrm{B}T = 4.28\ \mathrm{pN\,nm}$。为何细胞保持大量 profilin–肌动蛋白池，为何前缘网络要含许多纤维？
::: solution
$F = (4.28/2.75)\ln(1.0/0.12) = 1.556\times2.12 = 3.3\ \mathrm{pN}$。力只随浓度对数增长，但 $c$ 接近 $C_\mathrm{c}$ 时消失；大量聚合准备的亚基池（profilin–肌动蛋白，只加到有刺端）使所需处 $c/C_\mathrm{c}$ 高。片状伪足必须逆膜张力和摩擦以数纳牛量级的力推动，所以需要数百到数千条纤维一起推——Arp2/3 构建的密集分支网络。
:::

::: exercise 解读长度–张力曲线 {#exr-length-tension level=3}
Gordon、Huxley 与 Julian（1966）测量单条蛙肌纤维在不同肌节长度下的等长张力。张力在约 2.0 到 2.25 µm 间最大且恒定，随肌节拉长到约 3.65 µm 线性降至零，肌节短于 2.0 µm 时也下降。粗丝长 1.6 µm，中央裸露区约 0.15–0.2 µm 无肌球蛋白头；每条细丝约 1.0 µm 长。(a) 解释为何 3.65 µm 时张力为零。(b) 解释平台。(c) 提出短长度时张力下降的原因。(d) 为何该实验是滑丝与横桥理论的有力证据？
::: solution
(a) 3.65 µm 时，每个 Z 盘伸出的细丝（2 × 1.0 µm）加粗丝（1.6 µm）刚好不再重叠：$2\times1.0 + 1.6 = 3.6$ µm，加上 Z 盘厚度约 3.65 µm。没有肌球蛋白头能触及肌动蛋白，所以无力。
(b) 2.0 到 2.25 µm 间，粗丝上每个肌球蛋白头都重叠细丝；额外重叠只增加裸露区（无头），所以活动横桥数与张力恒定。肌节进一步拉长时，面向肌动蛋白的头数线性下降，张力也下降。
(c) 低于 2.0 µm 时两半的细丝在中间彼此重叠，干扰横桥形成；更短时粗丝碰到 Z 盘。
(d) 张力正比于纤维重叠，恰如力由沿重叠区分布的独立横桥产生的预测，与纤维本身缩短的理论不符。
:::
