一滴池塘水、从脸颊内侧刮下的样本和一片洋葱，看上去毫不相同，但在显微镜下三者都呈现为同一种单位：一小体积的含水、拥挤的化学体系，被一层膜包围，能够摄取物质与能量、复制自身并传递如何做到这一点的指令。这一单位就是**细胞**。我们所知的每个生物要么是单个细胞，要么是由一个细胞传下来的细胞群体，而生物学研究的一切——代谢、遗传、发育、行为、进化——几乎都发生在细胞内或细胞之间。

本章为课程奠定基础。我们陈述细胞学说并说明它如何被确立；比较原核与真核这两种细胞组织方案；然后做生物学教材常常跳过的事——给细胞配上数字。它们有多大、含有多少分子、一个分子从一侧到另一侧需要多久？这些数字解释了相当多的细胞生物学，包括细胞为什么小。最后我们看我们究竟如何看见细胞：限制光学显微镜的物理、绕过它的技巧，以及电子显微镜。

## 细胞学说

生物由细胞构成这一观念如此熟悉，以至于容易忽略它有多强的论断。从最早的显微镜到十九世纪中叶，大约花了两个世纪才把它拼合起来。

::: definition 细胞学说 {#def-cell-theory}
1. 每个活生物由一个或多个**细胞**构成。
2. 细胞是显示生命性质的最小单位：它通过代谢维持自身、对周围环境作出反应并繁殖。
3. 每个细胞都由已有细胞分裂产生。现今生物中的细胞不是由无生命物质组装而成。
:::

第三条的后果最深。如果每个细胞都来自更早的细胞，那么今天活着的每个细胞都位于一条可追溯到约四十亿年前最早生命的不间断谱系末端。在这种意义上，遗传是细胞的连续性；进化是沿其谱系的变化。

病毒是有教益的边界情形。病毒颗粒携带基因，并能指导自身复制，但只能在宿主细胞内、借助宿主的核糖体和代谢进行。它不能自行生长、代谢或分裂，因此按 [[#def-cell-theory]] 它不是细胞，多数生物学家也不把它算作独立的活生物——同时承认病毒会进化，而它们是否“活着”取决于所选定义。

::: quiz
成年哺乳动物的红细胞没有细胞核，也不能分裂。哪一陈述与细胞学说相容？
- [ ] 它不是细胞，因为它不能繁殖。
- [x] 它是细胞；它由前体细胞分裂而来，并在成熟过程中失去细胞核。
- [ ] 它表明细胞可以由无生命物质组装。
- [ ] 它与细胞学说矛盾，因此细胞学说必须被放弃。
::: solution
哺乳动物的红细胞源自骨髓中分裂的前体，并在成熟时排出细胞核。它们是终末分化细胞：学说要求每个细胞**来自**一个细胞，而不是每个细胞仍能分裂。许多特化细胞——多数神经元、骨骼肌纤维——也已停止分裂。
:::
:::

## 两种细胞组织方案

活细胞有两种结构方案，最重要的区别在于它们如何组织 DNA。

::: definition 原核细胞与真核细胞 {#def-pro-eu}
**原核细胞**没有细胞核：其染色体通常是单个环状 DNA 分子，位于细胞质中称为**拟核**的区域，并且一般没有膜包围的细胞器。细菌与古菌是原核生物。

**真核细胞**把染色体包在由双层膜即核膜包围的**细胞核**中，并含有膜包围隔室的内部系统（内质网、高尔基体、内体、溶酶体），以及线粒体；在植物与藻类中还有质体。动物、植物、真菌以及许多原生生物谱系是真核生物。
:::

下表比较两种方案的典型成员。数值是代表性的；真实细胞差异很大。

| 特征 | 原核生物（例如 *Escherichia coli*，大肠杆菌） | 真核生物（例如人成纤维细胞） |
|---|---|---|
| 典型线性尺寸 | 0.5–5 µm | 10–100 µm |
| DNA | 拟核中的一个环状染色体，外加质粒 | 细胞核中的若干线性染色体，缠绕在组蛋白上形成染色质 |
| 核糖体 | 70S | 细胞质基质中为 80S；线粒体与质体中类似 70S |
| 内部膜 | 通常没有（某些特化隔室） | 广泛：内质网、高尔基体、内体、溶酶体、过氧化物酶体 |
| 细胞骨架 | 肌动蛋白的同源物（MreB）、微管蛋白的同源物（FtsZ） | 肌动蛋白丝、微管、中间丝、马达蛋白 |
| 转录与翻译 | 在同一隔室中偶联 | 分离：RNA 在细胞核中制造，在细胞质基质中翻译 |
| 分裂 | 二分裂 | 有丝分裂（或减数分裂）与胞质分裂 |

两个警示使这张表保持诚实。第一，“原核生物”命名的是一种组织方案，而不是一个单一进化类群。1977 年乌斯（Carl Woese）与 George Fox 比较核糖体 RNA 序列，发现当时称为细菌的生物分为两个谱系，彼此之间的差异与它们各自同真核生物的差异一样大：**细菌**与**古菌**。古菌在显微镜下像细菌，但其膜脂不同（异戊二烯链通过醚键连接甘油，而不是通过酯键连接脂肪酸），细胞壁不同，转录与翻译机器更像真核生物。乌斯、Otto Kandler 与 Mark Wheelis 于 1990 年提出三域——细菌、古菌与真核生物。自 2015 年起描述的阿斯加德（Asgard）古菌基因组现在提示，真核生物从古菌内部产生，由一个古菌宿主与一个后来成为线粒体的细菌融合而成；这种两域图景被广泛但不普遍接受。我们在 [[cell-biology/organelles]] 中回到这次融合。

第二，“没有内部膜”是概括。蓝细菌有光合作用的类囊体膜，趋磁细菌形成膜包围的磁铁矿晶体，而浮霉菌和巨大的硫细菌 *Thiomargarita magnifica*（华丽硫珠菌）——一个约一厘米长的单细胞，由 Jean-Marie Volland 及其同事在 2022 年描述——其 DNA 周围有膜包围的隔室。细菌也有细胞骨架、蛋白质外壳的隔室如羧酶体，以及精确定位的蛋白质。原核细胞是有组织的；只是组织方式不同。

::: warning “原核生物是原始的”
人们容易把原核生物排在真核生物之下，当作更早、更简单的阶段。两者都是现代的：今天的细菌与古菌进化的时间与我们完全相同。它们主导地球的化学——固氮、硫循环，并承担全球光合作用与分解的大部分——栖息地从超过 100 °C 的热泉到深层地下。“结构上更简单”是公允的；“进化上更落后”则不是。
:::

尽管有差异，每个细胞都共享一个核心：分隔内外的质膜；作为遗传物质的 DNA，被读成 RNA 并在核糖体上以几乎相同的遗传密码翻译为蛋白质；作为能量货币的 ATP；以及一套共同的中心代谢反应。这一共享核心是所有生命来自共同祖先的最强证据。

## 细胞有多大？

数字锚定直觉。以下数值来自 Milo 与 Phillips 的 *Cell Biology by the Numbers*（2015）及其所依据的 BioNumbers 数据库；它们都是有真实分布的代表性数值。

| 细胞 | 特征尺寸 | 体积 |
|---|---|---|
| *Mycoplasma*（支原体，最小的自由生活细胞之一） | 直径 0.2–0.3 µm | ≈ 0.005–0.01 fL |
| *E. coli* | ≈ 1 µm × 2 µm | ≈ 1 fL |
| 出芽酵母 *Saccharomyces cerevisiae*（酿酒酵母，单倍体） | 直径 ≈ 4 µm | ≈ 40 fL |
| 人红细胞 | 7–8 µm 圆盘，厚 ≈ 2 µm | ≈ 90 fL |
| HeLa 细胞（培养的人细胞系） | 铺展时 15–20 µm | ≈ 3000 fL |
| *Xenopus laevis*（非洲爪蟾）卵母细胞 | 直径 ≈ 1.2 mm | ≈ 1 µL $= 10^9$ fL |

这里 $1\ \mathrm{fL} = 10^{-15}\ \mathrm{L} = 1\ \mathrm{\mu m^3}$，是一个值得记住的便利恒等式。线性尺寸跨越几千倍，体积跨越约 $10^{11}$ 倍。人体含有约 $3\times10^{13}$ 个人细胞——按数量约 84% 是红细胞——以及数量相当的细菌（Sender、Fuchs 与 Milo，2016）。

::: example *E. coli* 的体积与表面 {#ex-ecoli-volume}
把 *E. coli* 细胞建模为直径 1 µm、长 1 µm 的圆柱，两端各由一个同直径的半球封住，总长 2 µm。计算其体积、表面积与表面积–体积比。
::: solution
取半径 $r = 0.5\ \mathrm{\mu m}$、圆柱长 $L = 1\ \mathrm{\mu m}$，两个端帽合成一个球：

$$
V = \pi r^2 L + \tfrac43\pi r^3 = 0.785 + 0.524 = 1.31\ \mathrm{\mu m^3},\qquad
A = 2\pi r L + 4\pi r^2 = 3.14 + 3.14 = 6.28\ \mathrm{\mu m^2}.
$$

于是 $V \approx 1.3\ \mathrm{fL}$，$A/V = 4.8\ \mathrm{\mu m^{-1}}$。实测体积取决于生长速率（快速生长的细胞更大），范围约为 0.6 到 1.5 fL，所以“1 fL”是一个好的整数近似。每平方微米的膜只服务约 0.2 fL 的细胞质。
:::
:::

### 表面积与体积

为什么多数细胞如此小？一个原因是几何。

::: proposition 表面积–体积缩放 {#prop-sv}
半径为 $r$ 的球，表面积为 $4\pi r^2$，体积为 $\tfrac43\pi r^3$，所以

$$
\frac{A}{V} = \frac{3}{r}.
$$ {#eq-sv}

对于形状相同、按线性因子 $\lambda$ 缩放的一族细胞，面积按 $\lambda^2$ 增长，体积按 $\lambda^3$ 增长，因此 $A/V \propto 1/\lambda$。
:::

细胞输入的一切——营养、氧——以及输出的一切——废物、热——都必须穿过其表面，但其需求由细胞质的量决定，而细胞质随体积缩放。半径加倍，单位体积可用的膜就减半。某一维很大的细胞通过改变形状摆脱这一限制：神经元与真菌菌丝长而细，肠上皮细胞把顶端表面折成微绒毛，大型植物细胞把细胞质推到中央液泡周围的薄层中。

### 每个细胞的分子数

浓度与分子数通过体积相联系：$n = c V N_\mathrm{A}$，其中阿伏伽德罗常数 $N_\mathrm{A} = 6.022\times10^{23}\ \mathrm{mol^{-1}}$。在细胞中这一换算始终有用，因为许多重要分子以小数目存在。

::: example 细菌中的一纳摩尔 {#ex-nanomolar}
浓度 $1\ \mathrm{nmol\,L^{-1}}$ 在体积 1 fL 的 *E. coli* 细胞中对应多少分子？在 3000 fL 的 HeLa 细胞中呢？
::: solution
$$
n = cVN_\mathrm{A} = (10^{-9}\ \mathrm{mol\,L^{-1}})(10^{-15}\ \mathrm{L})(6.022\times10^{23}\ \mathrm{mol^{-1}}) = 0.60.
$$

在 *E. coli* 中，**1 nM 约为每个细胞一个分子**——一条值得记住的经验规则。以十拷贝存在的转录因子约为 17 nM，而“0.1 nM 的浓度”不是对单个细菌的有意义描述：这样的分子存在于十个细胞中的一个。在 HeLa 细胞中，同样的 1 nM 约为 $0.60\times3000 \approx 1800$ 个分子，而一个分子只对应 $0.6\ \mathrm{pM}$。
:::
:::

低拷贝数有真实后果。*E. coli* 的 lac 阻遏蛋白每细胞约有十个四聚体；当如此少的分子结合与解离 DNA 时，随机涨落使同一培养基中遗传相同的细胞行为不同。细胞间的变异即“噪声”，是 [[systems-biology]] 的主题。

在另一极端，一个 *E. coli* 细胞含有约 $3\times10^6$ 个蛋白质分子（总蛋白质浓度几毫摩尔），其细胞质拥挤：大分子占据其体积约 20–30%。细胞内部不是稀溶液，而是凝胶状、密集堆积的介质，蛋白质平均只相隔几纳米。

## 扩散：需要多长时间

细胞质中的分子被水分子冲击，随机行走。扩散在短距离上快，在长距离上慢得无望，而转折点大致在细胞尺度。

::: proposition 扩散粒子的均方位移 {#prop-diffusion}
扩散系数为 $D$、从原点出发的粒子，在时间 $t$ 后沿任一轴的均方位移为

$$
\langle x^2 \rangle = 2Dt,
$$ {#eq-msd}

在三维中 $\langle r^2\rangle = \langle x^2+y^2+z^2\rangle = 6Dt$。因此沿一轴扩散距离 $L$ 的典型时间为

$$
t \approx \frac{L^2}{2D}.
$$ {#eq-tdiff}

假设：介质均匀，粒子的步长彼此独立（无漂移、无结合、无障碍的随机行走），且 $t$ 远大于分子碰撞之间的时间。
:::

::: proof 随机行走
设粒子每 $\tau$ 秒走一步长度 $\delta$，向左或向右概率相等。经过 $N = t/\tau$ 步后，其位置为 $x = s_1 + \dots + s_N$，其中各 $s_i = \pm\delta$ 独立。则 $\langle x\rangle = 0$，且

$$
\langle x^2\rangle = \sum_i \langle s_i^2\rangle + \sum_{i\neq j}\langle s_i\rangle\langle s_j\rangle = N\delta^2 + 0 = \frac{\delta^2}{\tau}\,t.
$$

定义 $D = \delta^2/(2\tau)$ 即得 $\langle x^2\rangle = 2Dt$。沿三轴的运动独立，因此贡献相加为 $6Dt$。同样的结果也来自扩散（热）方程，其点源解是方差为 $2Dt$ 的高斯分布——见[数学图谱：热方程](/learn/maths/lesson.php?c=pde&l=heat-equation)。
:::

关键特征是距离只按时间的**平方根**增长：要走十倍远，需要一百倍时间。代表性分子的扩散系数（20–37 °C；来自 BioNumbers 与所引研究）为：水中的小代谢物如葡萄糖约 $600\ \mathrm{\mu m^2\,s^{-1}}$；水中的绿色荧光蛋白约 $90\ \mathrm{\mu m^2\,s^{-1}}$，但在哺乳动物细胞质中约 $25\ \mathrm{\mu m^2\,s^{-1}}$，在 *E. coli* 中为 $3$–$8\ \mathrm{\mu m^2\,s^{-1}}$（Elowitz 及其同事，1999）；膜中的脂质约 $1\ \mathrm{\mu m^2\,s^{-1}}$。

::: example 穿过细菌、穿过细胞、沿轴突 {#ex-diffusion-times}
用 [[#eq-tdiff]] 估计 $D = 10\ \mathrm{\mu m^2\,s^{-1}}$ 的蛋白质扩散所需时间：(a) 1 µm，穿过一个 *E. coli* 细胞；(b) 10 µm，穿过一个人细胞；(c) 1 m，即人腿中最长运动神经元轴突的长度。
::: solution
(a) $t = (1\ \mathrm{\mu m})^2/(2\times10\ \mathrm{\mu m^2\,s^{-1}}) = 0.05\ \mathrm{s}$。

(b) $t = 100/20 = 5\ \mathrm{s}$。

(c) $L = 10^6\ \mathrm{\mu m}$，所以 $t = 10^{12}/20 = 5\times10^{10}\ \mathrm{s}$，约 1600 年。

在细菌内部，扩散每秒混合细胞质许多次，不需要运输机器。穿过真核细胞需要数秒——对许多目的仍足够，但对另一些太慢。沿轴突则毫无用处：在细胞体中制造的蛋白质与细胞器必须由马达蛋白沿微管以约 $1\ \mathrm{\mu m\,s^{-1}}$ 运送，把旅程缩短到约十天（[[cell-biology/cytoskeleton]]）。
:::
:::

::: intuition 为什么扩散偏爱小尺度
把 [[#prop-sv]] 与 [[#prop-diffusion]] 结合起来。小细胞既有单位体积的大表面，又有短的内部距离，所以仅靠扩散就能供养自己。大细胞两者都没有优势；它必须保持薄，或投资于主动运输——马达、细胞质流动、多细胞动物的循环系统。真核细胞的许多特征，从细胞骨架到把反应聚在一起的内膜，都可读作“变大”问题的解决方案。
:::

## 看见细胞：光学显微镜

多数细胞低于肉眼的分辨极限，阅读距离处约 0.1 mm。光学显微镜把我们的视力扩展约一千倍，而它达到的极限不是由透镜质量决定，而是由光的波动性决定。

::: definition 分辨率与数值孔径 {#def-resolution}
成像系统的**分辨率**是两个点状物体仍能被区分的最小距离 $d$。物镜的**数值孔径**为 $\mathrm{NA} = n\sin\alpha$，其中 $n$ 是标本与透镜之间介质的折射率，$\alpha$ 是物镜收集的光锥半角。干式物镜的 $\mathrm{NA} < 1$；油浸物镜（$n \approx 1.52$）可达约 1.4–1.5。
:::

透镜不能把来自一个点的光聚焦到一个点。衍射把它扩散成模糊光斑，即点扩散函数，其宽度约为波长除以数值孔径。两个光斑重叠太多时便合并。

::: proposition 衍射极限（阿贝；瑞利） {#prop-abbe}
波长为 $\lambda$、数值孔径为 $\mathrm{NA}$ 的物镜，最小可分辨间距约为

$$
d_\text{Abbe} = \frac{\lambda}{2\,\mathrm{NA}}, \qquad d_\text{Rayleigh} = \frac{0.61\,\lambda}{\mathrm{NA}}.
$$ {#eq-abbe}

两种形式来自不同判据——阿贝（Ernst Abbe）的判据来自物镜仍能收集其衍射级的最细周期光栅，瑞利（Lord Rayleigh）的判据来自把一个点衍射图案的第一个暗环放在另一个点的中心——相差约 20%。两者都假设对非相干或部分相干光的常规（线性、远场）成像。
:::

推导属于光学；见[物理图谱：衍射](/learn/physics/lesson.php?c=optics&l=diffraction)。这里重要的是生物学后果。

::: example 光学显微镜能做到的最好程度 {#ex-abbe}
计算绿光（$\lambda = 500\ \mathrm{nm}$）在 (a) 干式物镜 $\mathrm{NA} = 0.25$ 与 (b) 油浸物镜 $\mathrm{NA} = 1.4$ 下的阿贝极限与瑞利极限。用 (b) 能否分辨：相距 1 µm 的两个线粒体；相距 30 nm 的两个核糖体；核膜的两层膜，相距约 40 nm？

(a) $d_\text{Abbe} = 500/(2\times0.25) = 1000\ \mathrm{nm}$；$d_\text{Rayleigh} = 0.61\times500/0.25 = 1220\ \mathrm{nm}$。

(b) $d_\text{Abbe} = 500/2.8 = 179\ \mathrm{nm}$；$d_\text{Rayleigh} = 305/1.4 = 218\ \mathrm{nm}$。

用 (b)，极限约为 0.2 µm。相距 1 µm 的线粒体容易分辨。核糖体（直径约 25 nm）与核膜的两层膜远低于极限：单个核糖体若被荧光标记仍可**检测**，但表现为 0.2 µm 宽的模糊斑，双层膜看起来像一条线。
:::

### 对比度

没有对比度，分辨率无用，而多数细胞几乎透明：其成分的折射率差别很小。三类方法提供对比度。

- **染色。** 固定并切片组织用染料着色，染料结合特定成分：苏木精把酸性结构如染色质染成蓝紫，伊红把多数蛋白质染成粉红。染色是组织学的基础，但需要杀死细胞。
- **光学对比。** 泽尔尼克（Frits Zernike）的**相差显微镜**（1930 年代；1953 年诺贝尔物理学奖）把光穿过细胞较密部分时受到的微小相位延迟转化为亮度差异，因此可观察活的、未染色细胞。**微分干涉对比**（DIC）用偏振光做类似的事，给细胞浮雕般的外观。
- **荧光。** 荧光团吸收某一波长的光并在更长波长发射；滤光片通过发射光并阻挡激发光，因此只有被标记的分子在暗背景上发光。荧光抗体（免疫荧光）标记固定细胞中的蛋白质。水母 *Aequorea victoria*（维多利亚多管发光水母）的**绿色荧光蛋白**由下村修（Osamu Shimomura）在 1962 年分离，Douglas Prasher 在 1992 年克隆，沙尔菲（Martin Chalfie）及其同事在 1994 年把它表达于 *E. coli* 与线虫 *Caenorhabditis elegans*（秀丽隐杆线虫）；钱永健（Roger Tsien）的实验室把它改造成一系列颜色。因为 GFP 由基因编码，它可以融合到几乎任何蛋白质上并在活细胞中追踪。下村修、沙尔菲与钱永健共享 2008 年诺贝尔化学奖。

**共聚焦显微镜**由明斯基（Marvin Minsky）于 1957 年申请专利，它在探测器前放置针孔，只记录来自焦平面的光；扫描光点可构建清晰的光学切片并叠成三维图像。双光子与光片显微镜进一步减少对活样本的损伤。

### 超越衍射极限

[[#prop-abbe]] 限制的是**常规**成像。自 1990 年代以来，若干方法打破了它——不是违反光学，而是利用荧光分子的性质：

- **STED**（受激发射损耗），由黑尔（Stefan Hell）与 Jan Wichmann 在 1994 年提出，用甜甜圈形光束关闭激发光点中心以外的荧光。
- **单分子定位**——PALM（Eric Betzig、Harald Hess 及其同事，2006）与 STORM（Xiaowei Zhuang 的团队，2006）——每次只开启一小部分稀疏、随机的荧光团。每个孤立分子给出衍射极限光斑，但该光斑**中心**的定位精度可远高于光斑宽度：用 $N$ 个检测光子，精度约为 $\sigma/\sqrt N$，其中 $\sigma$ 是光斑的标准差。数千帧合成一张图像。
- **膨胀显微镜**（Fei Chen、Paul Tillberg 与 Edward Boyden，2015）把标本嵌入可膨胀凝胶，并在用普通显微镜成像前将其物理膨胀约四倍。

这些方法在有利情况下现在可达 10–50 nm。贝齐格（Eric Betzig）、黑尔与莫纳（William Moerner）共享 2014 年诺贝尔化学奖。

## 电子显微镜

通往更小衍射极限的路是更短波长。经电势差 $V$ 加速的电子有德布罗意（de Broglie）波长 $\lambda = h/p$；由于所用电压下电子以光速的很大比例运动，动量必须包含相对论修正：

$$
\lambda = \frac{h}{\sqrt{2m_\mathrm{e}eV\left(1 + \dfrac{eV}{2m_\mathrm{e}c^2}\right)}}.
$$ {#eq-electron}

::: example 300 kV 电子的波长 {#ex-electron}
计算经 $V = 300\ \mathrm{kV}$ 加速的电子波长 $\lambda$，如现代冷冻电子显微镜中那样，并与绿光比较。
::: solution
取 $h = 6.626\times10^{-34}\ \mathrm{J\,s}$、$m_\mathrm{e} = 9.109\times10^{-31}\ \mathrm{kg}$、$eV = 4.807\times10^{-14}\ \mathrm{J}$，修正项为 $eV/(2m_\mathrm{e}c^2) = 4.807\times10^{-14}/(1.637\times10^{-13}) = 0.294$。于是

$$
\lambda = \frac{6.626\times10^{-34}}{\sqrt{2(9.109\times10^{-31})(4.807\times10^{-14})(1.294)}} = 1.97\times10^{-12}\ \mathrm{m} = 1.97\ \mathrm{pm}.
$$

这比 500 nm 光短约 250,000 倍。实践中电子透镜像差很大，只能使用很小的孔径，可达到的分辨率对材料约为 0.1 nm；对生物标本，主要受辐射损伤与标本制备限制，而不是波长。
:::
:::

第一台电子显微镜由鲁斯卡（Ernst Ruska）与克诺尔（Max Knoll）于 1931 年在柏林建造；鲁斯卡共享 1986 年诺贝尔物理学奖。把它用于细胞又花了二十年研究标本制备。由于电子束在真空中行进，并被任何厚度的物质散射，经典**透射电子显微镜**（TEM）使用化学固定、包埋在塑料中、切成 50–100 nm 厚并用重金属（锇、铀、铅）染色的标本。1945 年波特（Keith Porter）、克劳德（Albert Claude）与 Ernest Fullam 发表了第一张整个培养细胞的电子显微照片；1950 年代帕拉德（George Palade）、波特、Fritiof Sjöstrand 等人用薄切片描述内质网、核糖体、高尔基体与线粒体嵴。**扫描电子显微镜**（SEM）使电子束在金属涂覆的表面上逐行（光栅式）扫描并记录散射电子，给出鲜明的表面图像。

化学固定与染色会产生假象。**冷冻电子显微镜**通过极快冷冻标本（在液氮冷却的液乙烷中）使水形成玻璃而非冰晶，避免这些假象；这一方法由迪博歇（Jacques Dubochet）及其同事在 1980 年代初发展。由弗兰克（Joachim Frank）开创的对许多相同分子图像求平均的方法，以及约 2012 年引入的直接电子探测器，现在给出接近原子分辨率的蛋白质与复合物结构；亨德森（Richard Henderson）1990 年的细菌视紫红质结构是早期里程碑。迪博歇、弗兰克与亨德森共享 2017 年诺贝尔化学奖。**冷冻电子断层扫描**把同样思路用于整个冷冻细胞的薄区域，倾斜标本以在天然环境中重建分子机器。结构测定在 [[structural-biology]] 中讲授。

::: application 关联光与电子
光学与电子显微镜回答互补问题：荧光显示**哪种**分子在活细胞中的**哪里**以及如何移动，但分辨率为 0.2 µm；电子显微镜以纳米分辨率显示超微结构，但在死亡、固定或冷冻细胞中，且分子身份信息很少。**关联光与电子显微镜**用两种方式对同一细胞成像——例如在活细胞中定位一个稀有荧光事件，然后冷冻细胞并用冷冻电子断层扫描对该点成像。病理实验室仍对某些肾病与肌肉疾病使用活检的 TEM；临床方面属于[医学图谱：诊断病理学](/learn/medicine/lesson.php?c=pathology&l=diagnostic-pathology)。
:::

::: history
在《显微图谱》（*Micrographia*，1665）中，胡克（Robert Hooke）描述了他在薄软木切片中看到的小盒子并称之为“cells”（小室，“细胞”一词即源于此）；它们是死植物细胞的空壁。自 1673 年起，代尔夫特布料商列文虎克（Antonie van Leeuwenhoek） 致信伦敦皇家学会，描述透过他自己磨制的单透镜显微镜看到的“animalcules”（微小动物）——原生生物、精子，以及 1676 和 1683 年几乎肯定是细菌的东西。布朗（Robert Brown）在 1831 年命名兰花细胞中的细胞核。推广出现在 1838 年，施莱登（Matthias Schleiden）主张植物由细胞构成；1839 年施万（Theodor Schwann）在《显微镜研究》（*Mikroskopische Untersuchungen*）中把论断扩展到动物。两人仍认为细胞可以从无结构流体中结晶出来。雷马克（Robert Remak）对蛙胚胎分裂细胞的观察（1852）以及 菲尔绍（Rudolf Virchow）的《细胞病理学》（*Cellularpathologie*）及其口号 *omnis cellula e cellula*（1855–58）确立了细胞只能来自细胞；巴斯德（Louis Pasteur）1860 年代初的实验排除了微生物的自然发生。阿贝的成像理论（1873）与耶拿的蔡司（Carl Zeiss）工坊合作，解释了分辨率极限并导致油浸物镜。*procaryote* 与 *eucaryote* 两词由 Édouard Chatton 于 1925 年引入，Roger Stanier 与 Cornelis van Niel 于 1962 年给出其现代定义，比乌斯与 Fox 把原核生物分成两类早十五年。
:::

## 课程由此走向何处

有了本章的尺寸与时间尺度，课程余下部分向内走。[[cell-biology/membranes]] 与 [[cell-biology/membrane-transport]] 处理每个细胞共享的边界；[[cell-biology/organelles]] 与 [[cell-biology/protein-sorting]] 处理真核细胞的内部隔室及其间的运输；[[cell-biology/cytoskeleton]] 处理细胞如何获得形状并运动；[[cell-biology/cell-signalling]]、[[cell-biology/cell-cycle]] 与 [[cell-biology/tissues-and-cell-death]] 处理细胞如何感知、决定、分裂、合作与死亡。分子本身——蛋白质、核酸、脂质与代谢——是[化学图谱：生物化学](/learn/chemistry/course.php?c=biochemistry)的主题。

::: summary
- 细胞学说：所有生物由细胞构成，细胞是最小生命单位，每个细胞来自已有细胞。
- 原核细胞（细菌与古菌）没有细胞核，通常没有内部膜；真核细胞有细胞核、内膜系统与线粒体。古菌是独立的一域，真核生物可能从古菌内部产生。
- 细胞体积跨度约 $10^{11}$，从 $\approx0.01$ fL（*Mycoplasma*）经 $\approx1$ fL（*E. coli*）和 $\approx3000$ fL（HeLa 细胞）到 $\approx1$ µL（蛙卵母细胞）；$1\ \mathrm{fL} = 1\ \mathrm{\mu m^3}$。
- 表面积–体积比按 $3/r$ 下降；在 *E. coli* 中，1 nM 约为每细胞一个分子。
- 扩散距离按 $\sqrt{t}$ 增长：$\langle x^2\rangle = 2Dt$。扩散穿过细菌需毫秒到数十毫秒，穿过动物细胞需数秒，但沿轴突需数百年。
- 光学显微镜受衍射限制，$d \approx \lambda/(2\,\mathrm{NA}) \approx 0.2\ \mathrm{\mu m}$；荧光（含 GFP）、共聚焦与超分辨方法扩展了它能显示的内容。
- 电子显微镜使用皮米波长；冷冻电镜与冷冻断层扫描可在无化学固定下成像蛋白质与整个细胞。
:::

## 练习

::: exercise 表面积–体积比 {level=1 check="1.5"}
一个球形酵母细胞半径为 2 µm。计算其表面积–体积比（µm⁻¹），并与 [[#ex-ecoli-volume]] 中 *E. coli* 的值比较。
::: solution
由 [[#eq-sv]]，$A/V = 3/r = 3/2 = 1.5\ \mathrm{\mu m^{-1}}$，约为 *E. coli* 值 $4.8\ \mathrm{\mu m^{-1}}$ 的三分之一。每平方微米酵母质膜服务约 0.67 fL 细胞质，而 *E. coli* 中约 0.2 fL。
:::
:::

::: exercise 一个衍射极限 {level=1 check="200"}
计算波长 520 nm、数值孔径 1.3 的物镜的阿贝极限 $d = \lambda/(2\,\mathrm{NA})$，以纳米为单位。
::: solution
$d = 520/(2\times1.3) = 520/2.6 = 200\ \mathrm{nm}$。
:::
:::

::: exercise 从拷贝数到浓度 {level=1 check="166"}
体积 1 fL 的 *E. coli* 细胞含有某蛋白质的 100 个拷贝。其浓度是多少 nmol L⁻¹（三位有效数字）？
::: solution
$c = n/(VN_\mathrm{A}) = 100/(10^{-15}\times6.022\times10^{23}) = 1.66\times10^{-7}\ \mathrm{mol\,L^{-1}} = 166\ \mathrm{nM}$，与 [[#ex-nanomolar]] 的经验规则一致（每 nM 约 0.6 个分子）。
:::
:::

::: exercise 一个代谢物穿过细胞 {level=2 check="0.4"}
$D = 500\ \mathrm{\mu m^2\,s^{-1}}$ 的代谢物在直径 20 µm 的细胞一侧释放。用 [[#eq-tdiff]] 估计它扩散到另一侧的时间（秒）。为什么这只是估计？
::: solution
$t \approx L^2/(2D) = 400/1000 = 0.4\ \mathrm{s}$。公式给出均方根位移达到 $L$ 的时间；个别分子到达的时间分布很宽，有些早得多，有些晚得多。真实细胞质拥挤、含膜与结合位点，且不均匀，因此有效扩散系数往往比水中小数倍。
:::
:::

::: exercise 它被分辨了吗？ {level=2}
两个荧光标记的蛋白质相距 150 nm，位于用 1.4 NA 油浸物镜、发射波长 500 nm 成像的细胞中。(a) 常规荧光图像能分辨它们吗？(b) 学生把数字图像放大十倍以分开它们，这有用吗？(c) 提出一种能分开它们的方法，并解释为什么它不受 [[#prop-abbe]] 限制。
::: solution
(a) 不能。阿贝极限为 179 nm，瑞利极限为 218 nm（见 [[#ex-abbe]]）；在 150 nm 处两个光斑合并为一个拉长的模糊斑。
(b) 不能。放大不增加光学未收集的信息；这是空放大。
(c) 单分子定位（PALM 或 STORM）会在不同时间开启两个荧光团，使每个单独出现；每个孤立光斑的中心可定位到数十纳米或更好，因此可测量它们的间距。STED 也可行，通过缩小有效激发光斑。两者都利用荧光团在明暗状态间切换的能力，而常规成像不用这一点。
:::
:::

::: exercise 分类一个未知细胞 {level=2}
从热泉新分离的微生物有以下性质：细胞约 1 µm；电镜中无核膜；70S 核糖体；膜脂由异戊二烯链通过醚键连接甘油构成；有一个多亚基、类似真核 RNA 聚合酶 II 的 DNA 依赖性 RNA 聚合酶。它最可能属于哪一域？哪一观察排除真核生物，哪些指向不是细菌？
::: solution
它最可能是古菌。无细胞核与 70S 核糖体显示原核组织，排除真核生物。醚键连接的异戊二烯脂质是古菌膜的标志（细菌与真核生物用酯键连接的脂肪酸），多亚基、类似真核生物的 RNA 聚合酶也是古菌特征。大小与栖息地不能诊断：许多细菌也生活在热泉。决定性的现代检验是其 16S 核糖体 RNA 序列，如乌斯与 Fox 的工作。
:::
:::

::: exercise 单分子定位的精度 {level=2 check="3.2"}
一个荧光分子给出标准差 $\sigma = 100\ \mathrm{nm}$ 的图像光斑。忽略背景与像素大小，用 $N$ 个检测光子定位其中心的精度约为 $\sigma/\sqrt N$。$N = 1000$ 时精度是多少纳米？要达到 1 nm 精度需要多少光子？
::: solution
$100/\sqrt{1000} = 100/31.6 = 3.2\ \mathrm{nm}$。要达到 1 nm，$\sqrt N = 100$，所以 $N = 10^4$ 个光子。精度只按光子数的平方根改善——与均值的标准误同样的统计——因此明亮、耐光的荧光团很重要。实践中背景噪声与有限像素大小使真实精度差数倍，而且标记物的大小（抗体约 10 nm）进一步限制**蛋白质**定位的准确度。
:::
:::

::: exercise 靠氧扩散供能的细胞能有多大？ {level=3 check="49"}
半径为 $R$ 的球形细胞通过扩散摄取氧，并在整个体积中均匀消耗，速率 $q$（单位体积单位时间的摩尔数）。稳态下内部浓度满足 $D\nabla^2 c = q$，表面浓度保持为 $c_\mathrm{s}$。
(a) 证明 $c(r) = c_\mathrm{s} - \dfrac{q}{6D}(R^2 - r^2)$ 满足方程与边界条件，其中球对称下 $\nabla^2 c = \dfrac{1}{r^2}\dfrac{d}{dr}\left(r^2\dfrac{dc}{dr}\right)$。
(b) 由此求中心不缺氧的最大半径。
(c) 用 $D = 2000\ \mathrm{\mu m^2\,s^{-1}}$（水中的氧）、$c_\mathrm{s} = 0.2\ \mathrm{mmol\,L^{-1}}$ 和示例消耗率 $q = 1\ \mathrm{mmol\,L^{-1}\,s^{-1}}$ 以微米为单位求值。
::: hint
对 (b)，要求 $c(0) \ge 0$。
:::
::: solution
(a) $dc/dr = qr/(3D)$，所以 $r^2\,dc/dr = qr^3/(3D)$，其导数为 $qr^2/D$；除以 $r^2$ 得 $\nabla^2 c = q/D$，符合要求。在 $r = R$ 处括号为零，$c = c_\mathrm{s}$。

(b) 浓度在中心最低，$c(0) = c_\mathrm{s} - qR^2/(6D)$。非负条件为 $R \le R_\text{max} = \sqrt{6Dc_\mathrm{s}/q}$。

(c) 浓度单位相同，所以 $R_\text{max} = \sqrt{6\times2000\times0.2/1}\ \mathrm{\mu m} = \sqrt{2400}\ \mathrm{\mu m} = 49\ \mathrm{\mu m}$。

答案只按 $q^{-1/2}$ 依赖 $q$，因此即使假设消耗率变化十倍，$R_\text{max}$ 也只变约 3 倍。远大于约 0.1 mm 的活跃呼吸细胞难以仅靠扩散供氧，大于几毫米的多细胞动物需要循环系统。昆虫通过气管把空气直接送到组织，推高这一限制。

::: exercise 解读尺寸分布 {level=3}
实验室测量指数增长培养中 1000 个 *E. coli* 细胞的体积，发现约为 0.7 到 1.5 fL，新生细胞集中在低端，即将分裂的细胞集中在高端。同一菌株在更丰富的培养基中平均体积约两倍。(a) 解释为什么即使每个细胞都在完全相同大小分裂，增长群体也必含尺寸分布。(b) 体积对培养基的依赖对在 [[#ex-nanomolar]] 等计算中使用“1 fL”意味着什么？(c) 若在更丰富的培养基中每细胞蛋白质拷贝数加倍，其浓度改变了吗？
::: solution
(a) 每个细胞从出生尺寸长到约两倍后再分裂为两个子细胞，因此任一时刻群体都含介于两者之间的各阶段细胞——体积约两倍范围——即使细胞间没有变异。（真实细胞的分裂尺寸也有变异。）
(b) “1 fL”是数量级数值，足以估计，但在特定条件下可能差两倍或更多。把拷贝数换算为浓度的计算应使用所问条件的实测体积。
(c) 不一定。若体积也加倍，浓度 $n/(VN_\mathrm{A})$ 不变。拷贝数与浓度必须区分：生化速率依赖浓度，而噪声与结合事件数依赖拷贝数。
:::
