肝细胞没有眼睛或耳朵，却能在几秒内知道其主人受惊：经血液到达它的肾上腺素使它分解糖原并释放葡萄糖。细菌朝它能感知的微摩尔浓度糖游去。胚胎中的细胞根据从邻居收到多少信号蛋白来决定成为神经还是皮肤。这些都是**细胞信号转导**：细胞检测信号，把它转化为内部变化，并作出反应——改变代谢、基因表达、形状或运动，或决定分裂或死亡。

信号通路可能看起来像无穷无尽的缩写清单。本章试图展示底下的逻辑。少数受体类型把外部信号转为内部信号；少数第二信使与蛋白质修饰携带并放大它；几种反复出现的回路设计——开关、放大器、适应与反馈——塑造反应。我们还给信号配上数字：受体结合多强、涉及多少分子、信号开关多快，以及输入的渐变如何产生全或无决定。[[cell-biology/membrane-transport]] 的离子通道与 [[cell-biology/protein-sorting]] 的运输在这里作为信号系统的一部分再现。

## 信号、受体与反应

::: definition 细胞间信号传递的方式 {#def-signal-modes}
- **内分泌**信号（激素）经血液运到远处靶细胞。
- **旁分泌**信号作用于邻近细胞，距离数十到数百微米。
- **自分泌**信号作用于释放它们的细胞本身。
- **接触依赖**（邻分泌）信号通过信号细胞表面展示的分子起作用，所以只有直接接触的细胞反应。
- **突触**信号是神经递质在特化连接处释放到单个靶细胞，间隙约 20 nm。
:::

无论哪种方式，靶细胞只有拥有该信号的**受体**才反应。多数信号分子是亲水的——蛋白质、肽、氨基酸衍生物——不能穿膜，所以受体是细胞表面蛋白。小的疏水信号如类固醇激素、甲状腺激素与视黄素穿膜并结合**胞内受体**，在动物中主要是**核受体**：结合配体后直接调控基因的转录因子。溶解气体一氧化氮扩散穿膜并在数秒内激活可溶酶鸟苷酸环化酶；其半衰期为秒，所以只局部作用（Robert Furchgott、Louis Ignarro 与 Ferid Murad，1998 年诺贝尔生理学或医学奖）。

细胞表面受体分三大类。

::: definition 细胞表面受体的类别 {#def-receptor-classes}
1. **离子通道偶联受体**（配体门控通道）结合配体时打开孔，在毫秒内改变膜电位；神经–肌肉突触的烟碱乙酰胆碱受体是经典例子。
2. **G 蛋白偶联受体**（GPCR）是跨膜七次的单多肽。配体结合改变其形状，使它在胞质面激活三聚体 **G 蛋白**，后者再调控酶或通道。
3. **酶偶联受体**本身是酶或与酶结合。最大的类群**受体酪氨酸激酶**（RTK）有胞质激酶结构域，配体使两个受体靠近时被激活。
:::

GPCR 是最大的膜受体家族：人基因组编码约 800 个，近一半是嗅觉受体，它们响应光、气味、味道、激素、神经递质与脂质。约三分之一的已批准药物作用于 GPCR。Robert Lefkowitz 与 Brian Kobilka 因相关工作共享 2012 年诺贝尔化学奖；Kobilka 的实验室在 2007 年解出 β₂-肾上腺素能受体结构，2011 年解出其与激活 G 蛋白的复合物。

## 结合：多少信号才够？

第一步是配体 L 与受体 R 结合形成复合物 LR。分析与酶结合底物或蛋白结合氧相同（[化学图谱：蛋白质功能](/learn/chemistry/lesson.php?c=biochemistry&l=protein-function)）。

::: proposition 受体占据比例 {#prop-occupancy}
对在浓度 $[\mathrm{L}]$ 的自由配体平衡中、有单一结合位点的受体，被占据的受体比例为

$$
\theta = \frac{[\mathrm{LR}]}{[\mathrm{R}] + [\mathrm{LR}]} = \frac{[\mathrm{L}]}{K_\mathrm{d} + [\mathrm{L}]},
$$ {#eq-occupancy}

其中 $K_\mathrm{d} = [\mathrm{L}][\mathrm{R}]/[\mathrm{LR}] = k_\mathrm{off}/k_\mathrm{on}$ 是**解离常数**，即占据一半受体时的配体浓度。假设：结合已平衡；每个受体一个独立位点；配体大量过剩，结合不耗尽它。
:::

::: proof
记 $R_\mathrm{T} = [\mathrm{R}] + [\mathrm{LR}]$ 为总受体。由 $K_\mathrm{d}$ 定义，$[\mathrm{R}] = K_\mathrm{d}[\mathrm{LR}]/[\mathrm{L}]$，所以 $R_\mathrm{T} = [\mathrm{LR}](K_\mathrm{d} + [\mathrm{L}])/[\mathrm{L}]$，$\theta = [\mathrm{LR}]/R_\mathrm{T} = [\mathrm{L}]/(K_\mathrm{d}+[\mathrm{L}])$。
:::

信号受体紧密结合配体：$K_\mathrm{d}$ 通常为 $10^{-11}$–$10^{-8}$ mol L⁻¹（皮摩尔到纳摩尔），而酶与底物为微摩尔到毫摩尔。血液激素浓度相应很低。注意尺度：按 [[cell-biology/cells-and-microscopy#ex-nanomolar]]，单个动物细胞周围 1 pL 液体中 1 nM 只有约 600 个分子。

::: example 占据与备用受体 {#ex-occupancy}
一个生长因子受体 $K_\mathrm{d} = 1\ \mathrm{nM}$。(a) 在 0.1、1 与 10 nM 配体时占据比例是多少？(b) 许多组织中最大反应只在少数受体被占据时达到。假设 5% 受体被占据时反应达半最大，配体浓度是多少？
::: solution
(a) 由 [[#eq-occupancy]]，$\theta = 0.1/1.1 = 0.091$；$1/2 = 0.50$；$10/11 = 0.91$。从 10% 到 90% 占据需配体增加 81 倍：$\theta/(1-\theta) = [\mathrm{L}]/K_\mathrm{d}$，所以 $[\mathrm{L}]_{90}/[\mathrm{L}]_{10} = 9/(1/9) = 81$。

(b) 解 $\theta = 0.05$：$[\mathrm{L}] = K_\mathrm{d}\,\theta/(1-\theta) = 1\times0.05/0.95 = 0.053\ \mathrm{nM}$。反应在半最大时浓度比 $K_\mathrm{d}$ 低二十倍。这类细胞被称为有**备用受体**：下游机器在受体饱和前早已饱和，使细胞比单看结合亲和力更敏感。药理学家在 1950–60 年代从大部分受体被不可逆阻断仍能达最大反应的实验推断出备用受体（[[#exr-spare]]）。
:::
:::

## G 蛋白偶联受体与第二信使

### G 蛋白开关

三聚体 G 蛋白由 α、β、γ 亚基组成。静息时 Gα 结合 GDP，三亚基在一起。激活的受体作为**鸟苷酸交换因子**：使 Gα 释放 GDP，细胞质中更丰富的 GTP 结合替代，Gα·GTP 与 Gβγ 分离。两部分都可调控靶。Gα 在数秒到数分钟后水解 GTP——有 RGS 蛋白帮助时更快——并与 Gβγ 重新结合，结束信号。

::: intuition GTP 酶作为计时器
三聚体 G 蛋白、小 GTP 酶（Ras、Rab、Ran、Arf、Rho）与翻译因子共享机制：结合 GTP 时开，结合 GDP 时关，由交换因子开启，由自身缓慢 GTP 酶活性关闭，常被 GTP 酶激活蛋白加速。因为开关自行关闭，它像计时器：每个激活分子保持开启一个特征时间，信号只持续到受体继续开启新分子。不能水解 GTP 的突变体是永不走完的计时器——致癌 Ras 的缺陷。
:::

不同 Gα 家族靶不同。**Gs** 刺激腺苷酸环化酶，从 ATP 制造**环 AMP**（cAMP）；**Gi** 抑制它；**Gq** 激活磷脂酶 C-β；视网膜中的 **Gt**（转导素）激活 cGMP 磷酸二酯酶。Martin Rodbell 在 1971 年表明大鼠肝膜中激素作用于腺苷酸环化酶需要 GTP；Alfred Gilman 的团队在 1980 年用缺乏 Gs 的小鼠淋巴瘤突变体（*cyc⁻*）纯化 Gs；他们共享 1994 年诺贝尔生理学或医学奖。

::: definition 第二信使 {#def-second-messenger}
**第二信使**是胞内小分子或离子，其浓度在受体激活后迅速变化，并把信号传给靶蛋白。主要第二信使是 cAMP、cGMP、Ca²⁺、肌醇 1,4,5-三磷酸（IP₃）与二酰甘油（DAG）。它们快速扩散，单个酶分子可制造大量，且被迅速移除，所以放大信号并使其在细胞内扩散。
:::

### 环 AMP

Earl Sutherland 与 Theodore Rall 在 1957–58 年研究肾上腺素与胰高血糖素如何使肝分解糖原时发现 cAMP：激素作用于肝膜产生热稳定因子，即使无细胞提取物也能激活糖原磷酸化酶。这是第一个第二信使（Sutherland，1971 年诺贝尔生理学或医学奖）。cAMP 主要通过**蛋白激酶 A**（PKA）作用：两个 cAMP 结合每个调节亚基并释放催化亚基，后者磷酸化靶蛋白的丝氨酸与苏氨酸。在肝中，PKA 磷酸化并激活磷酸化酶激酶，后者磷酸化并激活糖原磷酸化酶——Edwin Krebs 与 Edmond Fischer 在 1950 年代发现调控性蛋白磷酸化的级联（1992 年诺贝尔生理学或医学奖）。PKA 也进入细胞核并磷酸化转录因子 CREB，所以同一信号既改变代谢（数秒）也改变基因表达（数十分钟）。磷酸二酯酶降解 cAMP，磷酸酶逆转磷酸化，结束反应。

::: example 级联中的放大 {#ex-amplification}
一个激活受体在其活性寿命中以示例速率激活 10 个 Gs 分子；每个 Gαs·GTP 使腺苷酸环化酶活性足够久以制造 100 个 cAMP；每个释放的 PKA 催化亚基在信号终止前磷酸化 100 个靶分子。两个 cAMP 释放一个催化亚基（四个结合 R₂C₂ 全酶释放两个）。每激活一个受体磷酸化多少靶分子？
::: solution
受体 → 10 个 G 蛋白 → $10\times100 = 1000$ 个 cAMP → $1000/2 = 500$ 个催化亚基 → $500\times100 = 5\times10^4$ 个磷酸化靶。若每个磷酸化靶是酶（如磷酸化酶激酶与磷酸化酶），放大会继续。真实增益小于这种乘法，因为每步被失活对抗且分子必须彼此找到；但放大是几百个激素分子能改变整个细胞代谢的原因。（这里数字是示例，非实测。）
:::
:::

### 钙、IP₃ 与 DAG

**Gq** 激活磷脂酶 C-β，把膜脂 PI(4,5)P₂（[[cell-biology/membranes]]）切成两个第二信使：可溶 **IP₃** 扩散到 ER 并打开 IP₃ 受体 Ca²⁺ 通道，以及留在膜中的 **DAG** 与 Ca²⁺ 一起激活**蛋白激酶 C**（Yasutomi Nishizuka 的团队，1977–79）。Hans Streb、Robin Irvine、Michael Berridge 与 Irene Schulz 在 1983 年表明 IP₃ 从大鼠胰腺腺泡细胞的胞内储备释放 Ca²⁺。

**钙**是最广泛的胞内信使。细胞质游离 Ca²⁺ 由质膜与 ER 的泵保持在约 100 nmol L⁻¹，而外部约 1–2 mmol L⁻¹，ER 腔数百微摩尔（[[cell-biology/membrane-transport#ex-nernst]]）。打开任一膜的 Ca²⁺ 通道使它在毫秒内升约十倍。其许多效应主要由 Ca²⁺ 结合蛋白介导，尤其是**钙调蛋白**，结合四个 Ca²⁺ 后激活 CaM 激酶 II 等激酶、钙调磷酸酶等磷酸酶以及许多其他酶。Ca²⁺ 触发肌肉收缩、突触囊泡与激素外排、受精与淋巴细胞激活。信号常编码为 Ca²⁺ 浓度的振荡或波，其频率携带信息。

::: example 多少钙离子构成钙信号？ {#ex-calcium}
一个细胞质体积 2 pL。(a) 100 nM 时细胞质中有多少游离 Ca²⁺？(b) 若每个游离 Ca²⁺ 约有 100 个结合在缓冲蛋白上（代表性缓冲比），把游离浓度升到 1 µM 需多少离子进入细胞质？
::: solution
(a) $n = (10^{-7})(2\times10^{-12})(6.022\times10^{23}) = 1.2\times10^5$ 个离子。

(b) 游离浓度须升 0.9 µM，但每个额外游离离子伴随 100 个结合离子，所以总增加为 $0.9\times101 = 91\ \mathrm{\mu M}$，即 $(9.1\times10^{-5})(2\times10^{-12})(6.022\times10^{23}) = 1.1\times10^8$ 个离子。缓冲使 Ca²⁺ 信号局部而短暂：经通道进入的离子在不到一微米内被捕获，所以 Ca²⁺ 在开放通道附近形成“微域”——这就是必须在毫秒内融合的突触囊泡紧贴钙通道的原因。
:::
:::

## 受体酪氨酸激酶与 Ras–MAP 激酶途径

表皮生长因子（EGF，Stanley Cohen 在 1962 年从小鼠唾液腺发现，使新生小鼠提前睁眼）与神经生长因子（Rita Levi-Montalcini；两人共享 1986 年诺贝尔生理学或医学奖）等生长因子通过受体酪氨酸激酶作用。配体结合使两个受体靠近；每个激酶结构域磷酸化伙伴的酪氨酸。磷酸酪氨酸是含 **SH2 结构域**蛋白的对接位点（Tony Pawson 的发现），它们在激活受体上组装信号复合体。

一个接头蛋白 Grb2 把交换因子 Sos 带到膜上，在那里激活小 GTP 酶 **Ras**。Ras·GTP 启动三激酶接力，即 **MAP 激酶级联**：Raf（一种 MAP 激酶激酶激酶）磷酸化并激活 MEK（MAP 激酶激酶），后者在苏氨酸与酪氨酸上磷酸化并激活 ERK（MAP 激酶）。ERK 磷酸化许多细胞质蛋白，并在细胞核中磷酸化开启细胞增殖所需基因的转录因子。该途径在 1980 年代末与 1990 年代初从三个方向拼合：哺乳动物细胞的癌基因研究、*Drosophila* 眼发育的遗传筛选（*sevenless* 受体与 *Son of sevenless*），以及 *C. elegans* 外阴发育的遗传筛选（*let-23*、*sem-5*、*let-60*）——保守信号的显著证明。

把 Ras 锁在 GTP 结合状态的突变，如 1982 年从膀胱癌细胞系分离的第一个人癌基因中密码子 12 的甘氨酸到缬氨酸改变，使途径无需生长因子就保持开启。突变 *RAS* 基因是人癌症最常见的驱动之一（[[cell-biology/cell-cycle]]；[医学图谱：癌症生物学](/learn/medicine/lesson.php?c=pathology&l=cancer-biology)）。

其他酶偶联受体类似但用不同接力：细胞因子受体激活相关 **JAK** 激酶，后者磷酸化直接进入细胞核的 **STAT** 转录因子；TGF-β 受体是丝氨酸/苏氨酸激酶，磷酸化 **Smad** 蛋白；许多 RTK 招募的 **PI 3-激酶** 在膜中制造 PI(3,4,5)P₃，激活激酶 Akt 促进细胞存活与生长。

## 开关与决定

许多细胞反应不是渐变的，而是开关式的：蛙卵母细胞要么成熟为卵要么不；细胞要么决定分裂要么不。平滑变化的输入如何给出全或无输出？

::: proposition Hill 函数（协同性的经验描述） {#prop-hill}
随输入 $x$ 呈 S 形上升的反应 $R$ 常被描述为

$$
R = \frac{x^{n}}{K^{n} + x^{n}},
$$ {#eq-hill}

其中 $K$ 是半最大反应时的输入，$n$ 是 **Hill 系数**。$n = 1$ 时即 [[#eq-occupancy]]。给出 90% 与 10% 最大反应的输入比为 $x_{90}/x_{10} = 81^{1/n}$：$n = 1$ 时为 81，$n = 4$ 时为 3。$n > 1$ 的反应称为**超敏**。Hill 函数是描述，不是机制：表观 $n$ 可来自协同结合、多位点磷酸化、接近饱和的酶（零级超敏，Albert Goldbeter 与 Daniel Koshland，1981）、级联或正反馈，$n$ 不必是整数。
:::

::: proof 90%–10% 之比
由 [[#eq-hill]]，$R/(1-R) = (x/K)^n$，所以 $x = K\,(R/(1-R))^{1/n}$。则 $x_{90}/x_{10} = (9/(1/9))^{1/n} = 81^{1/n}$。
:::

Chi-Ying Huang 与 James Ferrell 在 1996 年测量 *Xenopus* 卵母细胞提取物中 MAP 激酶级联的反应：随顶部激酶（MAP 激酶激酶激酶 Mos）增加，MEK 的表观 Hill 系数约 1.7，ERK（MAPK）约 4.9，而单酶作用于单点会给出约 1。级联的每一层要求靶被磷酸化两次，从而锐化反应。在完整卵母细胞中，Ferrell 与 Eric Machleder（1998）表明对孕酮的群体反应看似渐变，但每个卵母细胞要么全开要么全关——渐变平均值掩盖开关式个体，因为正反馈使决定**双稳态**且不可逆。

计算 Hill 系数 1、1.7 与 4.9 的输入比 $x_{90}/x_{10}$。
::: solution
$81^{1/1} = 81$；$81^{1/1.7} = 13.3$；$81^{1/4.9} = 2.45$。双曲反应从 10% 到 90% 需输入变化 81 倍；Huang 与 Ferrell 提取物中的 MAP 激酶只需约 2.5 倍。叠加超敏步骤把生长因子或激素的渐升变成接近二元的决定。
:::
:::

### 关闭信号：时间尺度与适应

信号只有能结束才有用。以速率 $s$ 产生、以一级过程速率常数 $k$ 移除的活性信号分子浓度 $x$ 满足 $dx/dt = s - kx$。

::: proposition 信号分子的反应时间 {#prop-response-time}
若 $t = 0$ 时以恒定速率 $s$ 开启生产，从 $x = 0$ 开始，

$$
x(t) = \frac{s}{k}\left(1 - e^{-kt}\right),
$$ {#eq-response}

趋近稳态 $s/k$，时间常数 $1/k$；在 $t_{1/2} = \ln 2/k$ 即分子半衰期时达到稳态一半，在 $\ln 10/k \approx 3.3\,t_{1/2}$ 时达到 90%。若生产停止，$x$ 按 $e^{-kt}$ 衰减。假设：恒定生产、一级移除、无反馈。
:::

caption: 信号分子在 $t = 0$ 到 $t = 30$ 分钟（竖线）以恒定速率制造，然后完全停止，并一级移除；滑块设定其半衰期 $t_{1/2}$（分钟）。纵轴是浓度占稳态 $s/k$ 的比例。短半衰期时分子快速升至平台并在信号停止后快速消失；长半衰期时它在 30 分钟内达不到稳态，之后还滞留很久。改变生产速率只会缩放曲线。
:::

令人意外的后果是：信号的速度由它被*移除*多快决定，而不是制造多快：长半衰期分子无论合成速率如何，开启与关闭都慢。因此信号系统快速销毁信使——磷酸二酯酶在数秒内水解 cAMP，乙酰胆碱酯酶在突触约一毫秒内破坏乙酰胆碱，许多转录因子与信号蛋白在数分钟内周转。许多系统还会**适应**：持续刺激产生会消退的反应，即使刺激仍在，所以细胞响应信号的*变化*。GPCR 被 GPCR 激酶磷酸化并结合**抑制蛋白（arrestin）**而脱敏，后者使它们与 G 蛋白解偶联并驱动内吞；趋化细菌通过甲基化受体适应，使其在五个数量级范围内比较当前与近期浓度。

::: warning “一个信号，一个反应”
同一信号常在不同细胞中产生不同反应，同一细胞也常用一条通路处理许多信号。乙酰胆碱使骨骼肌收缩（经离子通道受体），减慢心脏（经 Gi 偶联受体打开 K⁺ 通道），并使唾液腺分泌（经 Gq 偶联受体）。细胞做什么取决于它有哪些受体、接力蛋白与靶基因——取决于其历史与身份——而不只取决于信号。同样，通路不是孤立线性链：它们共享组分并互相调节（“交叉对话”），把它们画成分离箭头是简化。
:::

## 发育信号通路

一组在动物中保守的少数通路控制发育与组织维持中的细胞命运：**Wnt**、**Hedgehog**、**Notch**、**TGF-β/BMP**、核受体与 RTK 通路。它们主要经 *Drosophila* 遗传学发现——*wingless* 与 *hedgehog* 命名突变幼虫——并在不同组织中反复使用。**Notch** 是接触依赖受体：邻近细胞跨膜配体 Delta 的结合触发 Notch 蛋白水解切割，释放的胞内结构域进入细胞核调控基因。因为一个细胞的 Notch 信号抑制该细胞的 Delta 生产，邻近细胞被驱向相反命运，这一机制称为**侧向抑制**，产生昆虫与脊椎动物神经前体的盐和胡椒式图案。从源头扩散并在不同浓度指定不同命运的旁分泌信号是**形态发生素**；其范围由扩散与移除的平衡设定。

::: example 旁分泌信号能走多远？ {#ex-gradient}
分泌蛋白从一排源细胞扩散离开，有效扩散系数 $D = 20\ \mathrm{\mu m^2\,s^{-1}}$，并以一级速率常数 $k = 1/600\ \mathrm{s^{-1}}$ 被移除（受体摄取与降解）。稳态下 $D\,d^2c/dx^2 = kc$，衰减解为 $c(x) = c_0e^{-x/\lambda}$，$\lambda = \sqrt{D/k}$。计算 $\lambda$。浓度下降一百倍的距离是多少？
::: solution
$\lambda = \sqrt{20\times600}\ \mathrm{\mu m} = \sqrt{12\,000} = 110\ \mathrm{\mu m}$。下降一百倍需 $x = \lambda\ln100 = 110\times4.6 = 500\ \mathrm{\mu m}$，约几十个细胞直径。信号寿命加倍只把范围扩大 $\sqrt2$。实测形态发生素梯度——如早期 *Drosophila* 胚胎中 Bicoid 转录因子或翅盘中的 Dpp 蛋白——衰减长度为数十到约一百微米，与此简单图景相符，尽管这种梯度在组织中如何形成仍在积极研究（[[developmental-biology]]）。
:::
:::

::: quiz
一个细胞系的 GPCR 偶联 Gs。你把不可水解的 GTP 类似物（GTPγS）加到透化细胞中。有激素和无激素时 cAMP 生产会怎样？
- [ ] 什么也不变：G 蛋白需要激素才活跃。
- [x] cAMP 生产上升并保持高位，无激素时缓慢、有激素时快得多，因为结合 GTPγS 的 Gαs 不能自行关闭。
- [ ] cAMP 下降，因为 GTPγS 直接抑制腺苷酸环化酶。
- [ ] cAMP 短暂上升后回到基线，因为受体脱敏。
::: solution
GTPγS 替代 GTP 结合 Gα 但不能水解，所以每个装载它的 Gαs 无限保持活性。无激素时缓慢自发核苷酸交换逐渐激活 Gαs；激素结合的受体催化交换并大大加速。Rodbell、Gilman 等人的这类实验表明 G 蛋白自身的 GTP 水解终止信号。受体脱敏在这里不重要，因为 G 蛋白永不关闭。
:::
:::

::: history
Ernest Starling 与 William Bayliss 在 1902 年发现促胰液素（secretin）后创造“hormone”一词，John Newport Langley 在 1905 年提出肌肉细胞上的“感受物质”（receptive substance）。Earl Sutherland 发现 cAMP（1957–58）引入第二信使；Edwin Krebs 与 Edmond Fischer 对糖原磷酸化酶的工作（1955–59）表明磷酸化调控酶；Martin Rodbell（1971）与 Alfred Gilman（1980）揭示 G 蛋白。Stanley Cohen 在 1962 年分离 EGF，并与 Graham Carpenter 等人在 1978–80 年表明其受体是磷酸化酪氨酸的蛋白激酶（Tony Hunter 与 Bartholomew Sefton 在 1979–80 年于病毒癌蛋白中发现酪氨酸磷酸化）。第一个人类癌基因，突变 *HRAS*，由 Robert Weinberg、Mariano Barbacid 与 Michael Wigler 的团队在 1982 年分离。Michael Berridge 及同事在 1983 年鉴定 IP₃ 为释放 Ca²⁺ 的信使。Ronald Evans 与 Pierre Chambon 在 1985–86 年克隆第一批类固醇激素受体，揭示核受体家族，Kobilka 的 β₂-肾上腺素能受体晶体结构（2007、2011）显示 GPCR 如何激活其 G 蛋白。
:::

::: summary
- 信号经内分泌、旁分泌、自分泌、接触依赖或突触途径作用；细胞只有拥有受体才反应。疏水信号结合胞内（核）受体；亲水信号结合细胞表面受体。
- 表面受体有离子通道偶联、G 蛋白偶联（人约 800 个）与酶偶联（尤其受体酪氨酸激酶）。
- 占据为 $\theta = [\mathrm{L}]/(K_\mathrm{d}+[\mathrm{L}])$；信号 $K_\mathrm{d}$ 为 pM–nM。备用受体使反应比结合更敏感。
- G 蛋白与小 GTP 酶是自终止开关。Gs/Gi 调控 cAMP 与 PKA；Gq 激活磷脂酶 C，产生 IP₃（释放 Ca²⁺）与 DAG（激活 PKC）。细胞质 Ca²⁺ 从约 100 nM 升至约 1 µM，大量缓冲，主要通过钙调蛋白作用。
- RTK 招募 SH2 结构域蛋白；Ras 激活 Raf–MEK–ERK 级联；组成型活跃 Ras 是常见癌症驱动。
- 超敏反应（Hill 系数 $n > 1$；$x_{90}/x_{10} = 81^{1/n}$）与正反馈把渐变输入转为开关式决定，如 *Xenopus* 卵母细胞的 MAP 激酶级联。
- 信号速度由其移除决定：$x(t) = (s/k)(1-e^{-kt})$；适应与脱敏使细胞响应变化。旁分泌与形态发生素信号达到距离 $\lambda = \sqrt{D/k}$。
:::

## 练习

::: exercise 占据 {level=1 check="0.75"}
$K_\mathrm{d} = 1\ \mathrm{nM}$ 的受体在 3 nM 自由配体时被占据多少比例？
::: solution
$\theta = 3/(1 + 3) = 0.75$。
:::
:::

::: exercise 一个 Hill 反应 {level=1 check="0.941"}
反应按 [[#eq-hill]] 取 $n = 4$。输入为 $K$ 的两倍时产生最大反应的多少比例（三位有效数字）？
::: solution
$R = 2^4/(1 + 2^4) = 16/17 = 0.941$。
:::
:::

::: exercise 双曲反应的范围 {level=1 check="81"}
对简单结合曲线（$n = 1$），配体浓度必须增加多少倍才能把占据从 10% 升到 90%？
::: solution
$81^{1/1} = 81$（见 [[#ex-occupancy]]）。
:::
:::

::: exercise 等待稳态 {level=2 check="33.2"}
一个转录因子被信号诱导并以 10 分钟半衰期降解。合成开始后多少分钟达到新稳态的 90%（三位有效数字）？
::: solution
由 [[#prop-response-time]]，$t_{90} = \ln 10/k = t_{1/2}\ln10/\ln2 = 10\times3.32 = 33.2\ \mathrm{min}$。要使反应更快，细胞须更快降解蛋白（并更快制造以保持相同稳态）。
:::
:::

::: exercise 小细胞中的钙离子 {level=2 check="6.02"}
1.0 pL 细胞质在 1.0 µM 时有多少游离 Ca²⁺？以 $10^5$ 为单位、三位有效数字作答。
::: solution
$10^{-6}\times10^{-12}\times6.022\times10^{23} = 6.02\times10^5$。
:::
:::

::: exercise 短寿命信号的范围 {level=2 check="93.0"}
一个旁分泌信号 $D = 10\ \mathrm{\mu m^2\,s^{-1}}$，在组织中半衰期 10 分钟（600 s）。计算衰减长度 $\lambda = \sqrt{D/k}$（µm，三位有效数字）。
::: solution
$k = \ln2/600 = 1.155\times10^{-3}\ \mathrm{s^{-1}}$，所以 $\lambda = \sqrt{10/1.155\times10^{-3}} = \sqrt{8656} = 93.0\ \mathrm{\mu m}$。
:::
:::

::: exercise 解读剂量–反应实验 {#exr-spare level=2}
离体平滑肌条对激动剂的收缩在不可逆拮抗剂永久灭活一部分受体前后测量。处理前反应在 2 nM 激动剂时半最大。处理后最大反应不变，但曲线右移，半最大在 20 nM。更强处理后曲线进一步右移，最大值降至 60%。(a) 解释为何第一次处理不降低最大值。(b) 这说明占据与反应的关系如何？(c) 能否从未处理组织的半最大浓度估计 $K_\mathrm{d}$？解释。
::: solution
(a) 组织有备用受体：最大反应只需一部分受体被占据。移除一些意味着需要更高激动剂浓度占据足够剩余受体，但最大值仍可达。只有移除太多、剩余受体全占据仍不够时最大值才下降。
(b) 反应是占据的饱和函数——下游机器在受体饱和前饱和——所以反应与占据不成比例。
(c) 不能。有备用受体时半最大浓度（2 nM）低于 $K_\mathrm{d}$；它测量整个系统的敏感性，而非结合亲和力。比较部分受体灭活前后的曲线（Robert Furchgott 的方法）可估计 $K_\mathrm{d}$，通过找等反应浓度并拟合占据方程。
:::
:::

::: exercise 来自级联的开关 {level=3}
两个激酶串联。第一个活性 $y$ 是输入的双曲函数，$y = x/(1 + x)$。第二个活性 $z$ 是 $y$ 的超敏函数：$z = y^2/(0.25 + y^2)$（即 $n = 2$、半最大在 $y = 0.5$）。(a) 输入 $x$ 多少时第二个激酶半最大？(b) 计算 $x = 0.5$ 与 $x = 2$ 时的 $z$ 并评论。(c) 解释为何让每一层都超敏而非只有最后一层，会产生更锐的整体反应。
::: solution
(a) $z = 1/2$ 当 $y = 0.5$，即 $x/(1+x) = 0.5$，所以 $x = 1$。
(b) $x = 0.5$：$y = 0.333$，$y^2 = 0.111$，$z = 0.111/0.361 = 0.31$。$x = 2$：$y = 0.667$，$y^2 = 0.444$，$z = 0.444/0.694 = 0.64$。输入四倍变化使 $z$ 从 31% 到 64%，而 $y$ 从 33% 到 67%——并不更锐，因为第一层的双曲反应压缩了第二层操作的输入范围。
(c) 级联的整体敏感性大致是各层局部敏感性（对数增益）的乘积。若每一层在相关范围都有 $n > 1$ 的 Hill 式反应，其效应相乘，如 Huang 与 Ferrell 的测量中表观 $n$ 从 MEK 约 1.7 升到下游 MAPK 约 4.9。由双曲层喂给单一超敏步骤获得的锐化较小。
:::
:::

::: exercise 渐变还是全或无？ {level=3}
蛙卵母细胞用不同浓度孕酮处理，数小时后通过每浓度汇集 20 个卵母细胞测量显示 ERK 激活的比例：它在十倍浓度范围内从 0 平滑升到 100%。(a) 提出两种单卵母细胞层面的解释。(b) 什么实验能区分？(c) 若开关是双稳态，卵母细胞已反应后洗去孕酮会怎样？
::: solution
(a) 要么每个卵母细胞渐变反应（中等剂量时每个有中等 ERK 活性），要么每个卵母细胞在其自身阈值上全或无反应，而阈值因细胞而异，所以汇集平均平滑上升。
(b) 测量单个卵母细胞的 ERK 激活。Ferrell 与 Machleder（1998）这样做，发现中等剂量时每个卵母细胞要么完全激活要么完全不激活——双峰分布——所以第二种解释正确。
(c) 双稳态开关有记忆：一旦开启，正反馈使它在刺激移除后仍开启，所以卵母细胞会保持激活（成熟不可逆）。仅超敏（非双稳态）的系统会重新关闭。
:::
