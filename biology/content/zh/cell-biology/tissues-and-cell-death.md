单个细胞可以独自生活；组织是一个社会。在你的肠衬里，细胞由连接结构彼此结合，封住细胞间缝隙，使肠内容物留在身体外；它们躺在自己分泌的细胞外基质片上；它们由小坑底部的干细胞产生，几天内向上迁移，然后在绒毛顶端死亡并脱落——每天数百亿个。多细胞生命依赖细胞以正确方式黏在一起、构建并读取周围材料、在需要替换时分裂，并在接到指令时死亡。

本章是课程最后一章，从单个细胞跨到组织。我们看连接细胞的连接结构、包围它们的细胞外基质、更新组织的干细胞与出生和死亡之间的平衡算术，最后看**细胞死亡**的程序——尤其是细胞凋亡——如何干净地移除细胞。[[cell-biology/cell-signalling]] 的信号、[[cell-biology/cytoskeleton]] 的细胞骨架与 [[cell-biology/cell-cycle]] 的细胞周期在这里汇合。

## 细胞连接

动物组织大致有两类。在**上皮**中，细胞紧密堆成片，由连接结构彼此结合并附着于下方**基底层**；它们衬里身体的每个表面与腔。在**结缔组织**——骨、软骨、腱、真皮——细胞散布在丰富的细胞外基质中，基质承担大部分机械负载。连接结构在上皮中看得最清楚。

::: definition 细胞连接的类别 {#def-junctions}
- **封闭连接**——脊椎动物中为**紧密连接**——在顶面附近把邻近细胞封在一起，使分子不能在其间泄漏，并把质膜的顶面与基底面结构域分开。它们由跨膜蛋白 **claudin（密蛋白）** 与 occludin 的链构成。
- **锚定连接**把一个细胞的细胞骨架连接到邻居或基质。**黏着连接**通过**钙黏蛋白（cadherin）**连接相邻细胞的肌动蛋白丝；**桥粒**通过桥粒钙黏蛋白连接中间丝（角蛋白）；**黏着斑**与**半桥粒**分别通过**整合素**把肌动蛋白丝与中间丝连接到细胞外基质。
- **成通道连接**——动物的**间隙连接**、植物的**胞间连丝**——连接相邻细胞的细胞质，让离子和小分子直接通过。
- **传递信号的连接**包括化学突触以及 Notch 与 Delta 信号所经的接触（[[cell-biology/cell-signalling]]）。
:::

### 钙黏蛋白与细胞分选

钙黏蛋白是单次跨膜蛋白，其胞外部分由重复结构域组成，只有 Ca²⁺ 结合到它们之间时才变硬。Masatoshi Takeichi 在 1977 年发现培养细胞通过 Ca²⁺ 依赖机制彼此黏附，且该机制受 Ca²⁺ 保护而免于蛋白酶消化，随后鉴定 E-钙黏蛋白（上皮）与 N-钙黏蛋白（神经）。多数钙黏蛋白**同亲性**结合：一个细胞的钙黏蛋白结合另一个细胞同种钙黏蛋白。细胞内，钙黏蛋白通过β-连环蛋白（β-catenin）与α-连环蛋白连接到肌动蛋白丝，所以由黏着连接结合的细胞片形成机械连续网络——周向肌动蛋白带收缩能把整个上皮片折成管，如脊椎动物神经管形成。

同亲性黏附解释一个经典观察。1907 年 Henry Van Peters Wilson 表明，把海绵挤压通过细布成单细胞悬液后，它们重新聚成海绵；两种海绵的细胞混合时，它们分选成不同聚集体。1955 年 Philip Townes 与 Johannes Holtfreter 解离两栖胚胎组织并混合：细胞起初随机聚集，然后分选，表皮在外、中胚层与神经组织在内，重现接近正常排列。Malcolm Steinberg 的**差异黏附假说**（1963）提出细胞群体像不混溶液体，分选以最大化黏附键强度，最具凝聚力的组织在中间。表达不同数量或类型钙黏蛋白的细胞正这样分选。（后来 Carl-Philipp Heisenberg 等人的工作表明，肌动球蛋白产生的皮层张力与黏附本身贡献相当。）

### 间隙连接

间隙连接是一簇通道，每个由两个**连接子（connexon）**——连接蛋白 connexin 的六聚体，各由一个细胞贡献——在约 3 nm 窄间隙两侧对接。约 1.2–1.5 nm 宽的充水孔让无机离子和约 1 kDa 以下的分子通过——糖、氨基酸、核苷酸、cAMP、IP₃——但不让蛋白质或核酸通过。间隙连接使细胞电耦合（心肌细胞，使收缩波传播；某些神经元，即“电突触”）和代谢耦合。细胞质 Ca²⁺ 升高或 pH 下降时它们关闭，把受损细胞与邻居隔离。无脊椎动物用无关的蛋白家族 innexin 达到同样目的。

::: warning “组织中的细胞只是粘在一起”
黏附不是被动胶水。连接结构是动态结构，不断组装和重塑，与细胞骨架和信号通路相连。例如β-连环蛋白既是黏着连接的结构组分，又是 Wnt 通路的关键转录效应物；整合素与钙黏蛋白传递力并告诉细胞周围有多硬。当上皮细胞失去 E-钙黏蛋白而变得可迁移——**上皮–间充质转化**——它们改变基因表达、形状与行为，在正常发育（原肠形成、神经嵴）与癌扩散中都是如此。
:::

## 细胞外基质

**细胞外基质**（ECM）是细胞分泌到周围空间的蛋白质与多糖网络。在骨中它矿化而坚硬；在腱中呈绳状；在软骨中是弹性凝胶；在角膜中透明；在基底层中是薄而坚韧的片。四组分子构成它。

- **胶原**，哺乳动物中最丰富的蛋白质（约占总蛋白四分之一）。人有 28 种。纤维状胶原（I、II、III 型）形成高抗拉强度的纤维；IV 型形成基底层的片状网络。
- **糖胺聚糖**（GAG）与**蛋白聚糖**：长、无分支、带负电的多糖——透明质酸、硫酸软骨素、硫酸乙酰肝素——常附着于核心蛋白。它们吸引阳离子与水，形成抗压缩的水合凝胶。
- **弹性蛋白**，形成橡胶状纤维，使皮肤、肺与动脉回弹。
- **黏附糖蛋白**如**纤连蛋白**与**层粘连蛋白**，把细胞连接到基质，并把基质组分彼此连接。纤连蛋白通过三肽 Arg-Gly-Asp（**RGD**）结合整合素，由 Michael Pierschbacher 与 Erkki Ruoslahti 在 1984 年鉴定。

::: example 一个胶原分子有多长？ {#ex-collagen}
I 型胶原每条α1链的三螺旋区含 1014 个氨基酸，每第三个位置为甘氨酸（重复 Gly-X-Y，X 与 Y 常为脯氨酸与羟脯氨酸）。三螺旋中每个残基使分子前进 0.286 nm。(a) 一条链的螺旋区有多少甘氨酸？(b) 三螺旋有多长？(c) 为何每第三个残基必须是甘氨酸？
::: solution
(a) $1014/3 = 338$ 个 Gly-X-Y 三联体，所以 338 个甘氨酸。

(b) $1014\times0.286\ \mathrm{nm} = 290\ \mathrm{nm}$，与实测胶原分子长约 300 nm、直径约 1.5 nm 一致——异常长而细的杆。

(c) 三螺旋中三条链绕共同轴，且每条链每第三个残基位于内侧，紧贴另外两条链。只有侧链为氢原子的甘氨酸能放在那里。单个甘氨酸被更大残基替换会局部破坏螺旋；I 型胶原中这类替换导致脆骨病成骨不全。脯氨酸羟化稳定螺旋，需要维生素 C，所以其缺乏（坏血病）削弱结缔组织；临床方面在[医学图谱](/learn/medicine/course.php?c=musculoskeletal)。
:::
:::

胶原以可溶前体原胶原分泌，两端有前肽阻止其在细胞内组装；它们在外面被切除，分子随后自组装成错开的纤维，由赖氨酰氧化酶共价交联。纤维由制造它们的细胞定向——腱中沿张力线成平行束，皮肤中成编织纹——并由基质金属蛋白酶重塑。

### 整合素：读取基质

细胞通过**整合素**附着基质，即α与β亚基的异二聚体（人有 18 个α与 8 个β亚基，形成 24 种不同整合素）。整合素是双向开关。其胞外头可折叠且低亲和，或伸展且高亲和；细胞内细胞骨架接头 talin 结合β亚基尾使其伸展（**由内向外激活**），外部基质结合促进内部肌动蛋白与信号蛋白组装（**由外向内信号**）。经 talin 与 vinculin 连接到肌动蛋白的整合素簇形成**黏着斑**，既传递爬行细胞的牵引力（[[cell-biology/cytoskeleton]]），又经黏着斑激酶（FAK）与 Src 等激酶发信号。多数正常细胞需要整合素信号才能存活与分裂：失去基质，上皮细胞通过称为**失巢凋亡（anoikis）**的凋亡形式死亡——癌细胞必须逃避的控制才能扩散。

植物用不同方案解决同样问题：细胞由**细胞壁**之间富含果胶的中间层黏合，细胞壁由纤维素微纤维在半纤维素与果胶基质中构成，并通过壁中膜衬里的**胞间连丝**连接邻近细胞质。因为植物细胞不能移动，植物发育依赖定向分裂与扩张而非迁移（[[plant-biology]]）。

## 干细胞与组织更新

许多成年组织持续更新：小肠上皮每 3–5 天，人皮肤表皮每几周，红细胞每 120 天。其他如大部分脑与心肌更新很少。

::: definition 干细胞与潜能 {#def-stem-cell}
**干细胞**是既能**自我更新**——分裂产生更多干细胞——又能产生分化细胞类型的细胞。干细胞按**潜能**分类，即能产生的细胞类型范围：**全能**细胞（合子与哺乳动物早期卵裂球）能形成整个生物包括胚外组织；**多能**细胞（囊胚内细胞团细胞、胚胎干细胞）能形成身体所有细胞类型；**多潜能**细胞（造血干细胞）能形成一种组织的几种细胞类型；**单能**细胞只有一种。干细胞常很少分裂并产生**过渡扩增细胞**，后者在分化前分裂有限次数。
:::

成年干细胞的存在由 James Till 与 Ernest McCulloch 在 1961 年于多伦多证明。他们把骨髓细胞注入造血系统被照射摧毁的小鼠，发现脾上结节，每结节数与注入细胞数成比例；1963 年与 Andrew Becker 用染色体标记表明每个结节是一个细胞的克隆，含多种血细胞谱系。胚胎干细胞由 Martin Evans 与 Matthew Kaufman 以及独立地由 Gail Martin 在 1981 年从鼠囊胚获得，1998 年 James Thomson 及同事从人胚胎获得——这项工作在多数国家受监管，因为它使用人胚胎。

两个发现表明分化可逆。1962 年 John Gurdon 把蛙 *Xenopus laevis* 蝌蚪肠细胞的核移植到去核卵，得到游泳蝌蚪，有些长成成体：分化细胞核仍含制造整个动物所需的全部遗传信息。2006 年 Kazutoshi Takahashi 与 Shinya Yamanaka 通过引入仅四个转录因子（Oct3/4、Sox2、Klf4 与 c-Myc）把鼠成纤维细胞重编程为**诱导多能干细胞（iPS 细胞）**。Gurdon 与 Yamanaka 共享 2012 年诺贝尔生理学或医学奖。

### 稳态的算术

稳态组织必须使制造细胞的速度恰好等于丢失速度。对干细胞群体，这给干细胞如何分裂施加精确约束。

::: proposition 干细胞命运的平衡 {#prop-stem-balance}
假设干细胞每次分裂以概率 $p$ 产生两个干细胞、以概率 $q$ 产生两个分化细胞、以概率 $1 - p - q$ 产生各一个（不对称分裂），且各分裂独立。每次分裂产生的干细胞期望数为

$$
2p + 1\cdot(1 - p - q) + 0\cdot q = 1 + p - q,
$$ {#eq-stem}

所以 $n$ 轮分裂后干细胞期望数乘以 $(1 + p - q)^n$。只有 $p = q$ 时群体平均维持；$p > q$ 则指数增长，$p < q$ 则耗尽。假设：命运独立同分布；所有干细胞同速分裂；无干细胞死亡或其他损失。
:::

两种策略满足 $p = q$。每次分裂可不对称（$p = q = 0$），如许多无脊椎动物干细胞。或分裂可对称但群体层面平衡（$p = q > 0$）：单个干细胞随机漂移，一些谱系扩张、另一些丢失。小鼠肠的谱系追踪——用可遗传荧光标记单个干细胞——在 2010 年（Hugo Snippert、Hans Clevers 及同事；Carlos Lopez-Garcia、Allon Klein、Benjamin Simons 与 Douglas Winton）表明隐窝干细胞遵循第二模式：每个隐窝约 14–16 个等能干细胞（由 *Lgr5* 标记），数周到数月一个克隆通过**中性漂移**接管隐窝。下图显示需要多小的失衡就能使干细胞群体增长或衰退。

caption: 干细胞期望数（相对起始数）在 $x$ 轮分裂后为 $(1+p-q)^x$，$p$ 是分裂产生两个干细胞的概率，$q$ 是产生零个的概率（[[#prop-stem-balance]]）。默认 $p = 0.30$、$q = 0.28$ 时，仅两个百分点失衡使群体在 50 次分裂中增长约 2.7 倍；把 $q$ 设大于 $p$ 可看到衰退。稳态要求 $p = q$ 精确相等，所以组织反馈必须调节干细胞命运。

::: example 替换红细胞 {#ex-rbc}
成人约有 $2.5\times10^{13}$ 个红细胞，每个存活约 120 天。新红细胞必须以什么速率制造？若每个定向祖细胞经一系列过渡扩增分裂产生约 $2^{12}$ 个红细胞（示例数字），每秒多少祖细胞进入途径？
::: solution
稳态下制造等于移除：$2.5\times10^{13}/(120\times86\,400\ \mathrm{s}) = 2.4\times10^6$ 个细胞每秒。每祖细胞 $2^{12} = 4096$ 个细胞，所以每秒约 $2.4\times10^6/4096 \approx 600$ 个祖细胞开始分化。过渡扩增意味着相对少量、少分裂的干细胞与早期祖细胞能维持巨大产出——且其中一个的突变会传给许多后代。
:::
:::

组织大小由反馈调节。以速率 $s$ 产生、每细胞速率 $d$ 死亡的组织细胞总数 $N$ 满足 $dN/dt = s - dN$，趋近稳态 $N^* = s/d$，时间常数 $1/d$——形式上与 [[cell-biology/cell-signalling#prop-response-time]] 的信号分子相同。真实组织感知自身大小并调整 $s$ 与 $d$：大鼠肝三分之二切除后，剩余肝细胞重新进入周期并在约一周内恢复原质量，然后停止。细胞死亡与分裂一样是控制的一部分。

::: example 稳态更新上皮 {#ex-steady-tissue}
一组肠隐窝产生的细胞供给一个绒毛。假设每小时供给 $s = 300$ 个新细胞（示例数字），每个细胞到绒毛后以对应平均寿命 4 天的恒定单位时间概率脱落。稳态时绒毛上皮含多少细胞，突然失去一半细胞后多久恢复？
::: solution
每细胞损失率 $d = 1/(96\ \mathrm{h})$，所以 $N^* = s/d = 300\times96 = 28\,800$ 个细胞。损失后 $N(t) = N^* + (N_0 - N^*)e^{-dt}$：缺口以时间常数 $1/d = 96$ h 衰减，所以上皮在 $96\ln2 \approx 67$ h 后回到一半，在 $96\ln20 \approx 290$ h（约 12 天）内回到 5% 以内——除非组织感知损失并增加 $s$，如真实受伤上皮那样。
:::
:::

## 程序性细胞死亡

::: definition 细胞凋亡与坏死 {#def-apoptosis}
**细胞凋亡**是遗传控制的细胞死亡形式，细胞缩小、染色质浓缩、DNA 在核小体间被切割、质膜起泡，并破裂为膜包围的**凋亡小体**，暴露磷脂酰丝氨酸，被邻近细胞或吞噬细胞迅速吞入，不泄漏内容物也不引发炎症。相比之下，**坏死**是细胞与细胞器肿胀、质膜破裂、释放内容物并触发炎症的死亡；它长期被视为意外，但若干形式现在已知受调控。
:::

细胞凋亡一词——希腊语“脱落”，如树叶——由 John Kerr、Andrew Wyllie 与 Alastair Currie 在 1972 年引入，他们在许多正常与病变组织中识别出相同特征形态，并主张它是与有丝分裂互补的受控主动过程。

细胞凋亡是正常生活的一部分。发育中的脊椎动物神经系统里许多类神经元约一半死亡，那些未从靶标获得足够存活因子的（导致 Rita Levi-Montalcini 发现 NGF 的“神经营养假说”）。哺乳动物与鸟类胚胎的指头由其间细胞死亡分开；蝌蚪尾部在变态时由它移除；无用或自反应受体的淋巴细胞被它清除。成年中它平衡分裂以保持组织大小，并移除受损、感染与潜在危险的细胞。

### 线虫中的死亡

细胞凋亡的遗传学来自线虫 *Caenorhabditis elegans*。John Sulston 与 Robert Horvitz 在 1970 年代通过在显微镜下观察活胚胎与幼虫，追踪线虫每个细胞的完整谱系；雌雄同体中产生 1090 个体细胞，恰好 131 个死亡，总是相同细胞在相同时间（Sulston 与 Horvitz，1977；Sulston 及同事，1983）。Horvitz 的实验室随后分离出这些死亡不发生的突变体。Hilary Ellis 与 Horvitz（1986）发现两个基因 *ced-3* 或 *ced-4*（细胞死亡异常）中任一个缺失，所有 131 个细胞都存活；Michael Hengartner、Ellis 与 Horvitz（1992）发现 *ced-9* 缺失使许多本应存活的细胞死亡、杀死胚胎，且这种额外死亡需要 *ced-3* 与 *ced-4*。因此 CED-9 是杀死机器的抑制剂，CED-3 与 CED-4 是其中部件，EGL-1（后来发现）是 CED-9 的抑制剂。Sydney Brenner 在 1960 年代选择 *C. elegans* 为模型；Brenner、Horvitz 与 Sulston 共享 2002 年诺贝尔生理学或医学奖。

::: example 数 *C. elegans* 中的死亡 {#ex-elegans}
*C. elegans* 雌雄同体产生的体细胞中多少比例通过程序性死亡死亡，多少存活？*ced-3* 功能缺失突变体中预期多少体细胞，这种线虫近乎正常的外观说明什么？
::: solution
$131/1090 = 12.0\ \%$ 死亡；成体中 $1090 - 131 = 959$ 个体细胞存活。*ced-3* 突变体中所有 131 个存活，所以约 1090 个体细胞。这样的线虫可存活且看起来几乎正常；有额外细胞，其中一些分化为功能神经元。线虫的程序性死亡精确但在实验室条件下 在很大程度上并非必需——而哺乳动物中相应 caspase 缺失造成小鼠脑发育严重缺陷，说明途径重要性在不同生物中不同。
:::
:::

### 哺乳动物的机器

线虫基因有哺乳动物对应物，几乎同时被发现。

- **Caspase**（半胱天冬酶，半胱氨酸依赖的天冬氨酸导向蛋白酶）是执行者：CED-3 是一种 caspase（Junying Yuan、Horvitz 及同事，1993）。Caspase 以无活性前体制造。**起始 caspase**（caspase-8、caspase-9）通过在接头平台上聚集而被激活，并切割与激活**执行 caspase**（caspase-3、caspase-7），后者切割数百种细胞蛋白——核纤层蛋白、细胞骨架蛋白、随后使 DNA 碎裂的核酸酶的抑制剂——产生凋亡特征。因为每个 caspase 激活许多其他 caspase，级联自我放大且不可逆。
- **Bcl-2 家族**对应 CED-9 与 EGL-1。Bcl-2 本身是作为人滤泡淋巴瘤染色体易位激活的基因被发现；David Vaux、Suzanne Cory 与 Jerry Adams 在 1988 年表明它促进细胞*存活*而非增殖，揭示一类新癌基因。家族含抗凋亡成员（Bcl-2、Bcl-xL）、促凋亡效应物（Bax、Bak）与响应胁迫并倾斜平衡的**仅含 BH3 蛋白**（Bid、Bim、Puma、Noxa）。
- **Apaf-1** 对应 CED-4，组装**凋亡体**。

有两条主要途径：

1. **内在（线粒体）途径**响应内部损伤——DNA 损伤经 p53（[[cell-biology/cell-cycle]]）、生长因子撤回、ER 胁迫。仅含 BH3 蛋白激活 Bax 与 Bak，后者在线粒体外膜形成孔（**线粒体外膜通透化**）。**细胞色素 *c*** 从膜间隙逃到细胞质，在那里结合 Apaf-1 并触发轮状凋亡体组装，激活 caspase-9。Xiaodong Wang 的团队在 1996 年于人细胞无细胞提取物中发现细胞色素 *c*——呼吸链的电子载体——是 caspase 激活所需：一个线粒体蛋白的双重角色，令人注目。
2. **外在（死亡受体）途径**响应其他细胞信号。Fas 配体与 TNF 等配体结合靶细胞的**死亡受体**，后者招募接头 FADD 与 procaspase-8 进入死亡诱导信号复合体，激活 caspase-8。免疫细胞用这条路线杀死感染或异常细胞。

### 其他受调控死亡形式

细胞凋亡不是唯一程序。**坏死性凋亡（necroptosis）**在 caspase-8 被抑制时触发，由激酶 RIPK1 与 RIPK3 及成孔蛋白 MLKL 介导，使细胞破裂。**焦亡（pyroptosis）**在免疫细胞应对感染时依赖 caspase-1 及相关 caspase 切割 gasdermin D，后者在质膜成孔并释放炎症信号。**铁死亡（ferroptosis）**由 Scott Dixon、Brent Stockwell 及同事在 2012 年命名，由铁依赖的膜脂过氧化造成，由谷胱甘肽过氧化物酶 4 防止。这些裂解性死亡提醒免疫系统，而凋亡通常无声。**自噬**（[[cell-biology/organelles]]）主要是生存机制，但在某些情境伴随或促成死亡。

::: quiz
哪种实验观察最能区分培养中的凋亡细胞与坏死细胞？
- [ ] 细胞已死。
- [x] 过程早期细胞外表面暴露磷脂酰丝氨酸，而质膜仍排斥不透染料，且 DNA 被切成约 200 bp 倍数的片段。
- [ ] 细胞的线粒体停止制造 ATP。
- [ ] 细胞已从培养皿脱落。
::: solution
凋亡细胞暴露 PS（用结合它的荧光 annexin V 检测），而膜仍完整，排斥碘化丙啶等染料；DNA 在核小体间切成“梯状”片段。坏死细胞早期失去膜完整性并允许染料进入。死亡、ATP 丢失与脱落两者都发生。培养中晚期凋亡细胞若未被吞噬，最终也失去膜完整性（“次级坏死”），所以时序重要。
:::
:::

::: application 细胞死亡与疾病
凋亡太少促癌与自身免疫；太多促成神经退行及中风与心梗的组织损伤。肿瘤细胞通过过表达 Bcl-2 或丢失 p53 逃避死亡，模拟仅含 BH3 蛋白的药物（“BH3 模拟物”，如 venetoclax）恢复细胞死亡能力；其临床用途见[医学图谱：癌症生物学](/learn/medicine/lesson.php?c=pathology&l=cancer-biology)，组织细胞损伤与坏死见[医学图谱：细胞损伤](/learn/medicine/lesson.php?c=pathology&l=cell-injury)。许多病毒携带阻断其所感染细胞凋亡的基因，说明该程序在防御中多么重要。
:::

## 回顾

本课程从细胞作为膜包围的小拥挤体积开始，到细胞合作、专门化、彼此替换并为整体利益死亡结束。同样几条原则贯穿每章：制造膜的疏水效应；储存能量并传递信号的电化学梯度；导向蛋白质的分选信号；构建与运动的动态聚合物与马达；做决定的开关、反馈与计时器；以及设定一切能多快发生的扩散、结合与生长算术。后续课程把这些思想引向不同方向：[[molecular-biology]] 进入编码机器的基因，[[microbiology]] 进入独自生活的细胞，[[developmental-biology]] 进入细胞如何构建胚胎，[[animal-physiology]] 进入组织如何作为器官运作。

::: summary
- 紧密连接（claudin）封住上皮并分开顶面与基底面膜；黏着连接（钙黏蛋白–连环蛋白–肌动蛋白）与桥粒（钙黏蛋白–角蛋白）机械连接细胞；黏着斑与半桥粒通过整合素把细胞连到基质；间隙连接（连接蛋白）让约 1 kDa 以下的离子与分子通过。
- 同亲性、Ca²⁺ 依赖的钙黏蛋白结合与皮层张力把细胞分选成组织（差异黏附）。
- ECM 由胶原（Gly-X-Y 三螺旋长约 300 nm）、蛋白聚糖与 GAG、弹性蛋白、纤连蛋白（RGD）与层粘连蛋白构成；整合素读取它，双向传力与发信号；失去基质的细胞通过失巢凋亡死亡。
- 干细胞自我更新并分化；潜能从全能到单能。稳态要求对称更新与对称分化的概率相等（$p = q$）；肠干细胞在群体层面通过中性漂移实现。
- 组织以巨大速率替换细胞（成人每秒约 240 万红细胞），通过过渡扩增分裂，并通过出生与死亡的反馈调节大小。
- 凋亡是 caspase 控制的死亡：内在（Bcl-2 家族、Bax/Bak、细胞色素 *c*、Apaf-1、caspase-9）与外在（死亡受体、FADD、caspase-8）途径。它无声、不炎性，不同于坏死、坏死性凋亡、焦亡与铁死亡。
- *C. elegans* 遗传学（1090 个体细胞中 131 个死亡；*ced-3*、*ced-4*、*ced-9*）揭示保守的死亡程序。
:::

::: exercise 一个小失衡 {level=2 check="1.63"}
干细胞以 $p = 0.30$（两个干细胞）与 $q = 0.25$（两个分化细胞）分裂。10 轮分裂后干细胞期望数变化多少倍（三位有效数字）？
::: solution
由 [[#eq-stem]]，$(1 + 0.30 - 0.25)^{10} = 1.05^{10} = 1.63$。5 个百分点偏差在十次分裂中产生 63% 扩张；在一生许多分裂中，一个干细胞后代中的这种偏差会形成大克隆——突变在癌症发生很久前就能在组织中被选择的一条途径。
:::

::: exercise 缩小组织 {level=2 check="69.3"}
损伤停止产生后，细胞群体以每细胞每天 0.010 的速率死亡。降到初始大小一半需多少天（三位有效数字）？
::: solution
$N(t) = N_0e^{-dt}$，所以 $t_{1/2} = \ln2/d = 0.693/0.010 = 69.3$ 天。

::: exercise 分选 {level=2}
一个通常不黏附的细胞系两群被改造表达 E-钙黏蛋白：A 群高水平，B 群低水平。它们用不同染料标记、混合并允许聚集。(a) 按差异黏附假说预测一天后的排列。(b) 若 A 表达 E-钙黏蛋白而 B 表达相似水平的 N-钙黏蛋白，预期什么结果？(c) 如何检验 Ca²⁺ 是否必需，什么结果能确认钙黏蛋白介导分选？
::: solution
(a) 更具凝聚力的 A 群形成中心核，被 B 包围，像表面张力更高的液滴在较低者内部——如 Steinberg 团队用钙黏蛋白转染细胞发现（Steinberg 与 Takeichi，1994）。
(b) 同亲性结合预测 A 与 B 分选成不同聚集体或结构域，每种细胞优先黏附同类（实践中 E-与 N-钙黏蛋白可弱结合，所以分选可能不完全）。
(c) 在无 Ca²⁺ 介质中重复（例如用螯合剂）：钙黏蛋白失去刚性构象，细胞应不聚集或分选。针对 E-钙黏蛋白的阻断抗体应对 A 群有同样效果，加回 Ca²⁺ 应恢复聚集。
:::

::: exercise 凋亡还是坏死？ {level=2}
细胞用三种试剂处理，4 小时后用 annexin V（结合暴露的磷脂酰丝氨酸）与碘化丙啶（PI，只进入质膜受损细胞的 DNA 染料）染色。各类细胞百分比如下：

| 处理 | annexin⁻ PI⁻ | annexin⁺ PI⁻ | annexin⁺ PI⁺ |
|---|---|---|---|
| 无 | 95 | 3 | 2 |
| 试剂 X | 40 | 50 | 10 |
| 试剂 Y | 45 | 5 | 50 |
| 试剂 X + caspase 抑制剂 | 90 | 5 | 5 |

(a) 哪种试剂致凋亡，哪种致坏死？(b) 最后一行说明什么？(c) 为何还要更晚时间点观察试剂 X？
::: solution
(a) 试剂 X 产生许多 annexin⁺ PI⁻ 细胞——PS 暴露但膜完整——早期凋亡特征。试剂 Y 主要产生 annexin⁺ PI⁺ 细胞，无大量 annexin⁺ PI⁻ 中间态：膜早期受损，如坏死（膜通透后 annexin V 也染内层 PS）。
(b) 抑制 caspase 阻止 X 效应，确认死亡是 caspase 依赖的凋亡。
(c) 培养中未被吞噬的凋亡细胞最终失去膜完整性并变 PI⁺（次级坏死），所以 4 小时 annexin⁺ PI⁻ 细胞之后应移入双阳性类；跟踪时程可区分原发坏死（双阳性群体直接出现）。
:::

::: exercise 排列死亡途径中的基因 {level=3}
在 *C. elegans* 中：*ced-3* 与 *ced-4* 功能缺失（lf）突变体无程序性死亡；*ced-9* lf 突变体作为胚胎死亡，伴大量异位细胞死亡；*ced-9* 功能获得（gf）突变阻断程序性死亡；*ced-9(lf); ced-3(lf)* 双突变体可存活且无细胞死亡。(a) 双突变表型说明 *ced-9* 与 *ced-3* 的作用顺序如何？(b) CED-9 是死亡的激活物还是抑制剂？(c) 写出与数据相符的最简途径，并指出哺乳动物 Bcl-2、Apaf-1 与 caspase-9 蛋白的位置。
::: solution
(a) 双突变体显示 *ced-3* 表型（无死亡）：*ced-3* 对 *ced-9* 上位，所以 *ced-3* 下游作用。失去 *ced-9* 造成的异位死亡需要 *ced-3*。
(b) 抑制剂：失去它造成过多死亡，过度激活它阻断死亡。
(c) CED-9 ⊣ CED-4 → CED-3 → 死亡（EGL-1 ⊣ CED-9 在上游，在注定死亡的细胞中触发）。哺乳动物中 Bcl-2 家族抗凋亡蛋白对应 CED-9，Apaf-1 对应 CED-4，caspase-9（与下游执行者）对应 CED-3；哺乳动物途径在 Bcl-2 与 Apaf-1 之间加入线粒体步骤——Bax/Bak 与细胞色素 *c* 释放。
:::
:::

::: exercise 隐窝中的中性漂移 {level=3 check="0.0625"}
肠隐窝含 $N = 16$ 个等价干细胞，通过中性漂移随机彼此替换。(a) 时间零标记的一个特定干细胞的后代最终占据整个隐窝的概率是多少？(b) 若 1000 个隐窝各诱导一个标记，约多少隐窝会完全被标记？(c) 给干细胞竞争优势的突变如何改变答案，为何与癌症早期有关？
::: solution
(a) 中性漂移下每个干细胞最终成为整个隐窝祖先的概率相同，为 $1/N = 1/16 = 0.0625$。（这与大小为 $N$ 的群体中中性等位基因的固定概率相同，是 [[population-genetics]] 的结果。）
(b) 约 $1000/16 \approx 63$ 个隐窝；其余克隆丢失。单克隆标记隐窝比例数周上升后稳定在此值，这就是估计每隐窝干细胞数的方法。
(c) 有优势的克隆（替换邻居多于被替换）固定概率大于 $1/N$，所以突变克隆更常更快接管隐窝。与癌症相关的突变，如抑癌基因 *Apc* 丢失，正给出这种优势，完全突变的隐窝是肠肿瘤形成的第一步——自然选择在一个身体的细胞之间运作。
:::
