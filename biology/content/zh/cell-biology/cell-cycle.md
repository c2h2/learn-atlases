“每个细胞来自细胞”：细胞学说的第三条（[[cell-biology/cells-and-microscopy#def-cell-theory]]）隐藏着一项苛刻任务。要由一个细胞造出两个细胞，细胞必须使质量加倍、把整个基因组精确复制一次、把两份拷贝分开使每个子细胞得到一套完整基因组，然后才分裂。完成这些事件顺序的过程就是**细胞周期**。人体含约 $3\times10^{13}$ 个细胞，是约 45 轮加倍的结果；成年人每天有数百亿细胞分裂以替换丢失的细胞。每一次分裂都必须准确：染色体分离错误或错误时间分裂可能杀死细胞，或使它走上癌症之路。

本章解释周期各阶段、有丝分裂与胞质分裂的机制，以及由**周期蛋白依赖性激酶**构成的生化振荡器如何编排它们。然后看**检查点**如何在出错时暂停周期，以及控制失败如何导致癌症。途中我们用简单模型回答定量问题：增长培养中多少比例细胞处于有丝分裂、复制基因组需要多久，以及细菌如何比复制其染色体更快地分裂。

## 周期的阶段

::: definition 真核细胞周期的阶段 {#def-phases}
真核细胞周期由**间期**与 **M 期**组成。间期分为 **G1**（有丝分裂与 DNA 合成之间的间隙）、**S 期**（DNA 合成，染色体复制）与 **G2**（S 与有丝分裂之间的间隙）。**M 期**包括**有丝分裂**，即复制染色体（姐妹染色单体）分离到两个细胞核，以及**胞质分裂**，即细胞质分裂。停止分裂的细胞从 G1 离开周期进入称为 **G0** 的静息状态，许多细胞可从那里重新进入。
:::

这些名称来自 1953 年，Alma Howard 与 Stephen Pelc 给 *Vicia faba*（蚕豆）根尖喂放射性磷酸，并用放射自显影发现 DNA 只在间期一段有限时间合成，两侧由间隙与有丝分裂分开。持续时间差异极大。培养中典型增殖人细胞周期约 24 小时：G1 约 11 小时、S 约 8 小时、G2 约 4 小时、M 约 1 小时（Alberts《Molecular Biology of the Cell》第 7 版）。出芽酵母在丰富培养基中约 90 分钟分裂。*Xenopus laevis*（非洲爪蟾）早期胚胎经历十二个约 30 分钟的快速周期，*Drosophila*（果蝇）早期胚胎经历不到十分钟的周期，跳过间隙期，利用卵中储备交替 S 与 M。

::: example 多少次分裂制造并维持身体？ {#ex-doublings}
(a) 若人体 $3\times10^{13}$ 个细胞由受精卵同步加倍、无细胞死亡建成，需要多少轮分裂？(b) Ron Sender 与 Ron Milo（2021）估计成年人每天替换约 $3.3\times10^{11}$ 个细胞，主要是血细胞与肠上皮。这占身体细胞多少比例，每秒多少次分裂？
::: solution
(a) $\log_2(3\times10^{13}) = \log_2 3 + 13\log_2 10 = 1.58 + 43.19 = 44.8$，约 45 次加倍。真实发育涉及大量细胞死亡与不等增殖，所以许多谱系分裂次数更多。

(b) $3.3\times10^{11}/3\times10^{13} \approx 1.1\ \%$ 每天。每次分裂产生一个额外细胞，所以每秒约需 $3.3\times10^{11}/86\,400 \approx 3.8\times10^6$ 次分裂——每一次都是下文控制必须捕捉的错误机会。
:::
:::

## 有丝分裂与胞质分裂

有丝分裂由弗莱明（Walther Flemming）在 1882 年从蝾螈幼虫固定染色细胞中描述并命名。它通常分为阶段，但过程连续。

1. **前期。** 复制染色体**浓缩**，每条可见为两条姐妹染色单体，沿长度尤其**着丝粒**处由蛋白质环**黏连蛋白（cohesin）**维系；浓缩由凝聚蛋白（condensin）复合体驱动。S 期复制的两个**中心体**分开，并成核**有丝分裂纺锤体**的微管（[[cell-biology/cytoskeleton]]）。
2. **前中期。** 核膜破裂（动物与植物细胞；许多真菌与原生生物保留它，即“开放”与“封闭”有丝分裂）。纺锤极的微管通过动态不稳定性生长与缩短，直到其正端被**动粒**捕获——每个着丝粒上的蛋白质组装体。
3. **中期。** 每对姐妹动粒附着到相反极（**双向定向**），染色体排列在纺锤赤道，处于张力下。
4. **后期。** 黏连蛋白在所有染色体上突然同时被切割，姐妹分离，被拉向相反极（**后期 A**，由动粒–微管缩短），同时两极分开（**后期 B**，由极间微管滑动和星体微管拉动）。
5. **末期。** 染色体到达两极并去浓缩，核膜围绕每一套重新形成。

动物细胞的**胞质分裂**由质膜下细胞赤道处组装的肌动蛋白与肌球蛋白 II **收缩环**完成，其位置由后期纺锤指定。环收缩形成卵裂沟，直到剩下窄桥，最终断开（**断离**）。植物细胞在刚性壁内不能掐成两半；由微管与肌动蛋白结构**成膜体**引导高尔基体来源囊泡到赤道，在那里融合，从中心向外构建新壁**细胞板**。

::: warning “有丝分裂等于细胞分裂”——以及“染色体由两极的马达拉动”
有丝分裂是细胞核分裂；胞质分裂是细胞分裂。它们通常一起发生但可解偶联：早期 *Drosophila* 胚胎、肝与心肌的细胞进行有丝分裂而无胞质分裂，产生多核或多倍体细胞。第二个误解是染色体被纺锤极上的马达拖走。实际上后期 A 的力主要来自动粒本身，它抓住正在解聚的微管端并随其缩短被带走——Gary Gorbsky、Paul Sammak 与 Gary Borisy 在 1987 年表明，染色体向极移动时微管蛋白在动粒端丢失。
:::

## 每个阶段多长？增长培养的年龄分布

观察单个细胞——现在可用延时显微数天——是测阶段时长最直接的方法。经典方法是对非同步增长培养的固定样本计数各阶段细胞比例——M 期的**有丝分裂指数**，S 期用短脉冲 DNA 前体标记的比例。把比例换算成时长需要一点群体生物学。

::: proposition 指数增长群体的年龄分布 {#prop-age}
假设每个细胞恰在年龄 $T$（周期时间）时分成两个，群体稳态指数增长。则年龄 $a$ 的细胞密度为

$$
n(a) = \frac{2\ln 2}{T}\,2^{-a/T}, \qquad 0 \le a < T,
$$ {#eq-age}

所以年龄在 $a_1$ 与 $a_2$ 之间的细胞比例为

$$
f = 2^{1-a_1/T} - 2^{1-a_2/T}.
$$ {#eq-phase-fraction}

新生细胞数是即将分裂细胞的两倍。假设：所有细胞周期时间相同（无变异），无细胞死亡或离开周期，且群体增长足够久达到稳定年龄分布。
:::

::: proof
在加倍时间 $T$ 的指数增长中，时间 $s$ 的出生率正比于 $e^{\lambda s}$，$\lambda = \ln2/T$。时间 $t$ 年龄 $a$ 的细胞出生于 $t - a$，所以 $n(a) \propto e^{\lambda(t-a)} \propto 2^{-a/T}$。归一化，$\int_0^T 2^{-a/T}\,da = \frac{T}{\ln2}(1 - \tfrac12) = \frac{T}{2\ln2}$，给出 [[#eq-age]]。从 $a_1$ 到 $a_2$ 积分 $n(a)$ 得 $2(2^{-a_1/T} - 2^{-a_2/T})$，即 [[#eq-phase-fraction]]。
:::

::: example 多少比例细胞处于有丝分裂？ {#ex-mitotic-index}
对 24 小时人周期（G1 11 小时、S 8 小时、G2 4 小时、M 1 小时），计算指数增长培养中各阶段细胞比例，并与简单比例（时长除以 24 小时）比较。
::: solution
用 [[#eq-phase-fraction]] 以出生起算年龄（M 占最后一小时，年龄 23–24 小时）：

$$
\begin{aligned}
f_\mathrm{G1} &= 2^{1} - 2^{1-11/24} = 2 - 1.456 = 0.544,\\
f_\mathrm{S} &= 2^{1-11/24} - 2^{1-19/24} = 1.456 - 1.155 = 0.300,\\
f_\mathrm{G2} &= 2^{1-19/24} - 2^{1-23/24} = 1.155 - 1.029 = 0.126,\\
f_\mathrm{M} &= 2^{1-23/24} - 1 = 0.029.
\end{aligned}
$$

简单比例是 0.458、0.333、0.167 与 0.042。因为年轻细胞比年老细胞多，早期阶段被高估、晚期被低估：2.9% 的有丝分裂指数比 M 占周期的 4.2% 低约 30%。忽略年龄分布会高估从快照比例测得的 G2 与 M 时长。
:::
:::

## S 期复制基因组

DNA 复制从**复制起点**开始，并从每个起点向两个方向推进，形成两个**复制叉**。生物化学属于 [[molecular-biology]]；这里重要的是时序，以及把基因组每一部分复制一次且仅一次的问题。

::: example 复制细菌染色体 {#ex-ecoli-replication}
*E. coli*（大肠杆菌）有 $4.64\times10^6$ bp 的单个环状染色体，一个起点。37 °C 下复制叉每秒约 1000 个核苷酸。复制需要多久？同一细菌在丰富培养基中每 20 分钟可分裂。怎么可能？
::: solution
两个复制叉各复制半个环：$t = 4.64\times10^6/(2\times1000) = 2320\ \mathrm{s} \approx 39\ \mathrm{min}$。这个约 40 分钟的 **C 期**比 20 分钟加倍时间更长。

答案由 Stephen Cooper 与 Charles Helmstetter 在 1968 年发现，即**多叉复制**：细胞在上一轮复制完成前开始新一轮。分裂在复制轮结束后约恒定 **D 期**约 20 分钟发生，所以起始必须在所服务分裂前 $C + D \approx 60$ 分钟——在 20 分钟周期中即三代之前。快速生长细胞出生时染色体已在复制，有时每条上有几对复制叉。
:::
:::

真核染色体大得多，复制叉更慢（哺乳动物细胞通常每分钟 1–3 kb），所以需要许多起点。

::: example 人细胞需要多少起点？ {#ex-origins}
二倍体人细胞有 $6.4\times10^9$ bp DNA，S 期 8 小时，复制叉约每分钟 2 kb。若所有起点在 S 期开始时启动，最少需要多少起点？
::: solution
每个起点给两个复制叉，各复制 $2000\ \mathrm{bp\,min^{-1}}\times480\ \mathrm{min} = 9.6\times10^5$ bp。最少起点数：

$$
N = \frac{6.4\times10^9}{2\times9.6\times10^5} \approx 3300.
$$

实际上每个 S 期约 30,000–50,000 个起点启动，平均每 50–300 kb 一个。有这么多且同时启动，基因组可在远不到一小时内复制完；S 期持续 8 小时是因为起点按时间程序启动——基因丰富、活跃区域早，异染色质晚——且每个起点只在轮到它时启动。
:::
:::

真核细胞如何保证每个起点每周期只启动一次？起点在 G1 由 MCM 解旋酶装载而**许可**（作为无活性双六聚体，借助起点识别复合体、Cdc6 与 Cdt1）。S 期中激酶活性把装载的 MCM 转为活性解旋酶，同一激酶活性阻止新 MCM 装载。因此许可（低 CDK 活性）与启动（高 CDK 活性）在时间上分开，直到细胞通过有丝分裂且 CDK 活性再次下降，起点才能重新许可。这一方案在 *Xenopus* 卵提取物与酵母中由 Ronald Laskey、John Diffley、Bruce Stillman 等人弄清，把复制与驱动整个周期的 CDK 活性振荡联系起来。

## 控制系统：周期蛋白与 CDK

### 来自蛙卵、酵母与海胆的线索

三条实验路线在 1980 年代末汇合。

- **细胞融合与卵提取物。** 1970 年 Potu Rao 与 Robert Johnson 融合不同阶段的 HeLa 细胞：有丝分裂细胞与间期细胞融合时，间期细胞核立即浓缩染色体，表明 M 期细胞含显性细胞质诱导物。一年后 Yoshio Masui 与 Clement Markert 在*Rana pipiens*（豹蛙）卵母细胞上表明，成熟卵的细胞质注入未成熟卵母细胞使其进入 M 期。他们称该活性为**促成熟因子**（MPF）。
- **酵母遗传学。** 自 1970 年哈特韦尔（Leland Hartwell）分离出芽酵母温度敏感 *cdc*（细胞分裂周期）突变体，它们在特定阶段停滞——每个细胞在限制温度下以相同特征形态停滞——并定义 G1 中的承诺点 **Start**。裂殖酵母 *Schizosaccharomyces pombe*（粟酒裂殖酵母）中，纳斯（Paul Nurse）鉴定 *cdc2*（1975–76），其缺失阻断周期，其显性突变等位基因（*wee*）使细胞在小尺寸分裂；1987 年 Melanie Lee 与纳斯表明人基因（现称 *CDK1*）可替代裂殖酵母 *cdc2*。控制机器已保守十亿年。
- **周期蛋白。** 1982 年亨特（Tim Hunt）及同事在 Woods Hole 海洋生物实验室研究海胆 *Arbacia punctulata* 受精卵，注意到一种持续制造但在每次分裂时突然被破坏的蛋白质；他们命名为**周期蛋白（cyclin）**（Evans 及同事，1983）。

1988 年 Manfred Lohka、Marianne Hayes 与 James Maller 从 *Xenopus* 卵纯化 MPF，发现它是 Cdc2 激酶与周期蛋白的复合物。Andrew Murray 与 Marc Kirschner 在 1989 年表明，在 *Xenopus* 卵提取物中仅合成周期蛋白就足以驱动重复周期。哈特韦尔、亨特与纳斯共享 2001 年诺贝尔生理学或医学奖。

::: definition 周期蛋白依赖性激酶 {#def-cdk}
**周期蛋白依赖性激酶**（CDK）是丝氨酸/苏氨酸蛋白激酶，只在结合调节亚基**周期蛋白**时有活性。周期蛋白水平在细胞周期中升降，所以每个周期蛋白–CDK 复合物活性振荡，不同复合物——G1/S 周期蛋白、S 周期蛋白与 M 周期蛋白及其 CDK（脊椎动物中 G1 的周期蛋白 D 与 CDK4/6，G1/S 的周期蛋白 E 与 CDK2，S 的周期蛋白 A 与 CDK2，G2 与 M 的周期蛋白 A、B 与 CDK1）——磷酸化不同靶以触发相继事件。CDK 活性还受抑制性与激活性磷酸化及 **CDK 抑制蛋白**（CKI）控制。
:::

### 构建振荡器

上升的 **M-CDK**（周期蛋白 B–CDK1）活性触发有丝分裂事件：磷酸化核纤层蛋白（破坏核膜）、凝聚蛋白、微管相关蛋白及许多其他蛋白。进入有丝分裂由**正反馈**变得突然。周期蛋白 B–CDK1 在 G2 以无活性形式积累，被 Wee1 激酶对 CDK1 的抑制性磷酸化挡住；G2/M 转变时磷酸酶 Cdc25 移除它。活性 CDK1 磷酸化并激活 Cdc25、抑制 Wee1，所以少量活性 CDK1 制造更多活性 CDK1——如 [[cell-biology/cell-signalling]] 描述的开关。

退出有丝分裂由**蛋白酶解**变得突然且不可逆。**后期促进复合体/周期体**（APC/C），一种由 M-CDK 与蛋白 Cdc20 激活的泛素连接酶，标记两个关键蛋白供蛋白酶体销毁：**分离抑制蛋白（securin）**，其丢失释放蛋白酶**分离酶（separase）**切割黏连蛋白并启动后期（Frank Uhlmann 与 Kim Nasmyth，1999），以及 M 周期蛋白本身，其销毁使细胞离开有丝分裂。由于 M-CDK 延迟激活自己的摧毁者，系统是**负反馈振荡器**——海胆中“出现又消失”的周期蛋白是这一回路的可见痕迹。

::: intuition 由开关与延迟刹车构成的振荡器
想象马桶水箱。水（周期蛋白）稳定流入；水位达到阈值时，开关（经 Cdc25 与 Wee1 的正反馈）把 CDK1 完全打开，有丝分裂开始，APC/C（冲水）排空水箱，销毁周期蛋白并重置开关。然后水箱重新注水。正反馈使每次转变锐利并阻止系统在阈值附近摇摆；带延迟的负反馈使其重复。带延迟负反馈的双稳态开关产生稳健的**弛豫振荡**，John Tyson、Béla Novák 与 James Ferrell 对这种设计的数学模型重现了蛙卵提取物的行为。
:::

G1 中周期必须被**启动**，这是细胞倾听外部世界之处。动物细胞中，经 Ras–MAP 激酶途径作用的生长因子（[[cell-biology/cell-signalling]]）诱导周期蛋白 D 转录。周期蛋白 D–CDK4/6 开始磷酸化**视网膜母细胞瘤蛋白**（Rb），未磷酸化的 Rb 结合并抑制 **E2F** 转录因子。部分磷酸化的 Rb 释放一些 E2F，开启周期蛋白 E 与 S 期蛋白基因；周期蛋白 E–CDK2 进一步磷酸化 Rb，释放更多 E2F——另一个正反馈回路。细胞不再需要生长因子完成周期的点即**限制点**，由 Arthur Pardee 在 1974 年从培养成纤维细胞实验定义；分子上它接近 E2F 的开关式释放（Guang Yao、Lingchong You 及同事，2008）。出芽酵母的 Start 是类似决定，由不同蛋白以相同逻辑做出。

## 检查点

::: definition 检查点 {#def-checkpoint}
**检查点**是延迟细胞周期转变直到先前事件正确完成的控制机制，通过感知缺陷并向周期机器发送抑制信号。该术语由哈特韦尔与 Ted Weinert 在 1989 年引入。
:::

三个检查点了解最清楚。

- **DNA 损伤检查点**（G1、S 与 G2）。受损或未复制的 DNA 激活激酶 ATM 与 ATR，后者激活激酶 Chk1 与 Chk2。这些阻断 Cdc25（阻止 CDK 激活因而阻止进入 S 或 M）并稳定转录因子 **p53**，后者通常数分钟内被销毁。稳定的 p53 诱导 CDK 抑制剂 **p21**（停止周期）、DNA 修复基因，若损伤严重则凋亡。Weinert 与哈特韦尔 1988 年对酵母 *rad9* 突变体的研究——它们在 X 射线照射后不停滞并因此死亡——是细胞主动延迟分裂以允许修复的第一个遗传证明（[[#exr-rad9]]）。
- **纺锤体组装检查点**（中期）。单个未附着纺锤的动粒产生“等待后期”信号，由蛋白 Mad2、BubR1 与 Bub3 构成（在微管被破坏时未能停滞的突变体酵母筛选中发现：Rong Li 与 Andrew Murray，以及 Andrew Hoyt 及同事，1991），抑制 APC/C–Cdc20。只有每个动粒附着并处于张力下，信号才熄灭、后期才被允许——一条未附着染色体能拖住整个细胞。
- **G1/S 大小与生长检查。** 细胞在生长足够、且（在多细胞生物中）收到生长信号之前，不会承诺进入分裂。

::: quiz
细胞用 nocodazole（诺考达唑）处理，一种解聚微管的药物。多数细胞最终停滞于浓缩染色体和高周期蛋白 B 水平。为什么？
- [ ] 没有微管就不能制造周期蛋白 B。
- [x] 没有纺锤体，动粒未附着，纺锤体组装检查点抑制 APC/C–Cdc20，所以周期蛋白 B 与 securin 不被销毁。
- [ ] Nocodazole 直接抑制 CDK1。
- [ ] DNA 损伤检查点使细胞停滞，因为染色体断裂。
::: solution
未附着动粒产生抑制 APC/C 的检查点信号。因此周期蛋白 B 稳定，CDK1 保持活性，细胞停留在有丝分裂状态。这种停滞在实验中用于收集有丝分裂细胞，癌症治疗中的纺锤体毒物（[[cell-biology/cytoskeleton]]）通过触发它作用于分裂细胞；被扣在有丝分裂中数小时的细胞最终死亡或“滑出”有丝分裂。
:::
:::

## 控制失败时：癌症

癌症是细胞群体逃脱分裂、存活与位置控制的疾病。在细胞层面，它由两类基因突变累积产生。

- **原癌基因**促进增殖。一个拷贝的功能获得突变——使蛋白过活跃或错误时间产生——把它变成**癌基因**。例子有突变 *RAS*（[[cell-biology/cell-signalling]]）、扩增的 *MYC* 与过表达的周期蛋白 D。
- **抑癌基因**抑制增殖或促进修复与死亡。两个拷贝都丢失时它们促癌。*RB1*、*TP53*（编码 p53，约一半人类癌症中突变）与 *CDKN2A*（编码 CDK4/6 抑制剂 p16）是核心例子。

克努森（Alfred Knudson）在 1971 年对儿童眼癌视网膜母细胞瘤的分析解释了差异。遗传病例肿瘤更早出现且常在双眼；散发病例更晚且单眼。克努森提出需要两次“打击”：遗传病例每个细胞出生时已有一个缺陷拷贝，只需再一个突变；散发病例需同一细胞两个独立突变。1986 年 *RB1* 基因克隆时，肿瘤中两个拷贝确实都丢失或突变。

从正常细胞到肿瘤的途径通常涉及少数驱动基因突变，经数年累积，加上本应阻止 DNA 受损或染色体异常细胞分裂的检查点缺陷——这就是 p53 或纺锤体检查点丢失加速过程的原因。哈纳汉（Douglas Hanahan）与温伯格（Robert Weinberg）的“癌症标志”（2000，2011 与 2022 更新）把这些变化组织为少数获得能力，包括持续增殖信号、逃避生长抑制、抵抗细胞死亡与复制永生。癌症的病理、诊断与治疗属于[医学图谱：癌症生物学](/learn/medicine/lesson.php?c=pathology&l=cancer-biology)。

::: application 细胞周期抑制剂与分裂的极限
由于 G1 机器在癌症中常被破坏，它成为药物靶：CDK4/6 抑制剂使 Rb 不磷酸化，用于某些乳腺癌（[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)）。正常人体细胞则有内置分裂极限。海弗利克（Leonard Hayflick）与 Paul Moorhead 在 1961 年发现培养人成纤维细胞在约 40–60 次加倍后停止并进入永久停滞，即**复制性衰老**。一个原因是染色体保护端**端粒**在缺乏端粒酶的细胞每次复制时缩短；短端粒被识别为 DNA 损伤并触发 p53 依赖的停滞。多数癌细胞重新激活端粒酶，是复制永生的一条途径。
:::

::: history
弗莱明在 1882 年描述有丝分裂，博韦里（Theodor Boveri）对染色体数目异常的海胆卵研究使他在 1902 与 1914 年提出肿瘤可来自染色体组成异常的细胞。Alma Howard 与 Stephen Pelc 在 1953 年定义 G1、S 与 G2。Potu Rao 与 Robert Johnson 的细胞融合实验（1970）、Yoshio Masui 与 Clement Markert 的 MPF（1971）、哈特韦尔的 *cdc* 突变体（自 1970）、Arthur Pardee 的限制点（1974）、纳斯的 *cdc2*（1975–76）与亨特的周期蛋白（1982–83）在 MPF 被纯化并发现含 Cdc2 与周期蛋白 B（1988）时汇合。克努森在 1971 年提出两次打击模型；第一个抑癌基因 *RB1* 由 Stephen Friend、温伯格、Thaddeus Dryja 及同事在 1986 年克隆，p53 在 1979 年多实验室发现为结合 SV40 大 T 抗原的蛋白，1989 年被认定为抑癌基因。哈特韦尔与 Ted Weinert 在 1989 年引入检查点概念。
:::

::: summary
- 真核细胞周期为 G1 → S → G2 → M；典型人细胞约 24 小时（G1 11、S 8、G2 4、M 1 小时）。细胞从 G1 离开到 G0。
- 有丝分裂：前期（浓缩、纺锤形成）、前中期（核膜破裂、动粒捕获）、中期（双向定向）、后期（黏连蛋白切割、姐妹分离）、末期；胞质分裂由动物收缩环或植物细胞板完成。
- 指数增长培养中年龄密度 $n(a) \propto 2^{-a/T}$，所以快照比例高估早期阶段：24 小时周期中 1 小时 M 期的有丝分裂指数是 2.9%，不是 4.2%。
- *E. coli* 约 40 分钟复制 4.6 Mb 染色体，并通过多叉复制更快分裂；人细胞每周期按时间程序启动 30,000–50,000 个起点，每周期许可一次。
- 周期蛋白–CDK 复合物驱动周期。正反馈（Cdc25、Wee1；Rb–E2F）使转变像开关；APC/C 销毁 securin 与周期蛋白使后期与有丝分裂退出不可逆；合在一起形成弛豫振荡器。
- 检查点（DNA 损伤经 ATM/ATR–p53–p21；纺锤体组装经 Mad2–Bub；G1/S 的生长与大小）在条件合适前延迟转变。
- 癌症由原癌基因（功能获得、显性）与抑癌基因（两个拷贝丢失、克努森两次打击）突变累积，加上检查点丢失造成。
:::

## 练习

::: exercise 有丝分裂指数 {level=1 check="0.0353"}
用 [[#eq-phase-fraction]]，20 小时周期指数增长群体中处于周期末尾 1 小时 M 期的比例是多少（三位有效数字）？
::: solution
$f_\mathrm{M} = 2^{1-19/20} - 2^{0} = 2^{0.05} - 1 = 0.0353$（简单值会是 0.05）。
:::
:::

::: exercise 加倍到万亿 {level=1 check="39.9"}
从一个细胞造出 $10^{12}$ 个细胞需要多少次加倍（三位有效数字）？
::: solution
$\log_2 10^{12} = 12\log_2 10 = 12\times3.322 = 39.9$。指数增长很快：四十次分裂足够；人体 $3\times10^{13}$ 个细胞只需约 45 次，但现实中分裂次数更多得多，因为细胞也死亡并被替换。
:::
:::

::: exercise 较慢的复制叉 {level=1 check="48.3"}
若 *E. coli* 复制叉以每秒 800 个核苷酸移动（较低温度下），从单个起点复制 $4.64\times10^6$ bp 染色体需多少分钟（三位有效数字）？
::: solution
$4.64\times10^6/(2\times800) = 2900\ \mathrm{s} = 48.3\ \mathrm{min}$。
:::
:::

::: exercise 由有丝分裂指数求时长 {level=2 check="1.36"}
24 小时周期的指数增长培养中，4.0% 细胞处于有丝分裂。用 [[#eq-phase-fraction]] 求 M 期时长（小时，三位有效数字）。
::: solution
$f_\mathrm{M} = 2^{t_\mathrm{M}/T} - 1 = 0.040$，所以 $t_\mathrm{M} = T\log_2 1.04 = 24\times0.0566 = 1.36\ \mathrm{h}$。简单估计 $0.04\times24 = 0.96$ h 会短 30%。
:::
:::

::: exercise 最少起点 {level=2 check="5930"}
一个细胞系有 $6.4\times10^9$ bp DNA，S 期 6.0 小时，复制叉速度每分钟 1.5 kb。若所有起点在 S 期开始时启动，最少需要多少起点（三位有效数字）？
::: solution
$N = 6.4\times10^9/(2\times1500\times360) = 5930$。
:::
:::

::: exercise 解读细胞融合 {level=2}
Rao 与 Johnson 融合不同阶段的 HeLa 细胞。(a) G1 细胞与 S 期细胞融合时，G1 核提前开始 DNA 合成。(b) G2 细胞与 S 期细胞融合时，G2 核不再复制 DNA；S 核继续。(c) 有丝分裂细胞与任何间期阶段细胞融合时，间期核提前浓缩染色质。用本章控制系统解释每个结果。
::: solution
(a) S 期细胞质含可扩散的 DNA 合成激活物（S-CDK 活性及相关因子）；G1 核已许可（起点载有装载的 MCM 解旋酶），所以能响应。
(b) G2 核已复制，起点不再许可；它直到通过有丝分裂才能再复制。这表明“每周期一次”是细胞核的性质（其起点状态），而不只是细胞质的——许可模型的基础。
(c) M 期细胞质含显性有丝分裂诱导物——MPF、周期蛋白 B–CDK1——作用于任何核。G1 核浓缩为单染色单体，G2 核为成对染色单体，S 核为破碎、“粉状”外观的染色质，因为复制未完成。
:::
:::

::: exercise 多叉复制 {level=3}
在 Cooper–Helmstetter 模型中，一轮复制需 $C = 40$ 分钟，之后 $D = 20$ 分钟分裂。(a) 加倍时间 $\tau = 60$ 分钟时，起始在周期何时发生，新生细胞有几个起点？(b) $\tau = 30$ 分钟时，起始发生在所服务分裂前几代？(c) 解释为何快速生长细菌比慢生长细菌更大、每细胞含更多 DNA。
::: solution
(a) 起始在分裂前 $C + D = 60$ 分钟，即上一次分裂时刻（出生）。新生细胞有一个起点，立即启动；它出生时染色体刚开始复制。
(b) $(C + D)/\tau = 60/30 = 2$ 代之前。某周期末分裂的起始发生在前一周期开始、在母细胞中。新生细胞染色体已复制一半，有两个起点同时启动，所以起始后含四个起点。
(c) 每细胞 DNA 含量按周期平均大致以 $2^{(C+D)/\tau}$ 增加，因为短 $\tau$ 时更多复制轮重叠；每个起点起始时的细胞质量约恒定（William Donachie，1968），所以起点更多的细胞更大。两者随生长速率一起增大。
:::
:::

::: exercise 一个检查点突变体 {#exr-rad9 level=3}
Weinert 与哈特韦尔（1988）用 X 射线照射出芽酵母。DNA 受损的野生型细胞在 G2 停滞数小时后才分裂；*rad9* 突变体不停滞，带着断裂染色体分裂并大多死亡。(a) 这说明 *RAD9* 的正常功能是什么？(b) 若 *rad9* 细胞照射后用延迟有丝分裂数小时的微管毒物处理再释放，存活显著增加。解释。(c) 为何这一结果对检查点概念重要？
::: solution
(a) 修复 DNA 并不需要 *RAD9*；它的作用是**延迟**分裂直到修复完成：它是感知损伤并抑制进入有丝分裂的监视系统的一部分。
(b) 药物给了突变体检查点本应提供的时间。修复酶（*rad9* 细胞仍有）在人工延迟期间修复断裂，所以细胞存活。
(c) 它把控制与执行分开：周期顺序不仅由每个事件物理依赖前一事件强制，也由专门控制强制，这些控制可被突变移除而不废除事件本身。此类控制丢失使细胞遗传不稳定，把检查点与癌症联系起来。
:::
:::

::: exercise 两次打击 {level=3}
在一个群体中，给定视网膜细胞在发育中一个 *RB1* 拷贝发生功能丧失突变的概率为 $\mu$（很小），每眼有 $N$ 个易感细胞。(a) 解释若 $N\mu$ 约为 1，每个细胞出生时已有一个缺陷拷贝的孩子很可能发生肿瘤，且常不止一个。(b) 解释出生时两个拷贝都正常的孩子为何极不可能发生。(c) 克努森观察到遗传病例每眼肿瘤数服从均值约 3 的泊松分布。遗传病例中一只眼无肿瘤的概率是多少？
::: solution
(a) 每个细胞已有一个打击；肿瘤只需再一个，每细胞概率 $\mu$。每眼期望肿瘤数 $N\mu$ 约为 1–3，所以多数这样的孩子至少发生一个肿瘤，常多个，常双眼。
(b) 同一细胞需两个打击，概率约 $\mu^2$，期望数 $N\mu^2 = (N\mu)\mu$，因 $\mu$ 小而极小。因此散发肿瘤罕见、单个、单侧且较晚。
(c) 泊松均值 $m = 3$，$P(0) = e^{-3} = 0.050$：约 5% 眼无肿瘤，与少数携带者不受影响（不完全外显）的观察一致。这种关于速率与计数的推理属于 [[biostatistics]]；不涉及临床判断。
:::
:::
