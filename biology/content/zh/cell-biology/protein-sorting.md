一个人细胞制造约一万种不同的蛋白质，而几乎所有蛋白质都在同一个地方开始生命：细胞质基质中的核糖体上。然而每一种都必须到达十几个目的地中的正确一个——细胞质基质本身、细胞核、线粒体基质或某个膜、过氧化物酶体、内质网、高尔基体、溶酶体、质膜或细胞外部。送到细胞质基质而非溶酶体的消化酶会无用甚至有害；永远到不了细胞表面的受体无法接收信号。每种蛋白质如何找到路？

答案在 1960 到 1990 年代被弄清，有一条令人满意的逻辑。每种蛋白质携带自己的地址，通常是称为**分选信号**的一小段氨基酸序列。细胞质基质或细胞器膜上的受体读取地址，专门机器要么把蛋白质穿膜，要么把它包装进在隔室间旅行的囊泡。本章沿三条主要路线追踪蛋白质：进入细胞核的门控运输，穿膜进入内质网、线粒体、叶绿体与过氧化物酶体的转位，以及经分泌与内吞途径的囊泡运输。这些隔室已在 [[cell-biology/organelles]] 中介绍。

## 分选信号与三种运输方式

::: definition 分选信号 {#def-sorting-signal}
**分选信号**是蛋白质中把它导向特定位置的某种特征。多数是**信号序列**：通常 3–80 个氨基酸的连续片段，常（但不总是）在 N 端，在起作用后可被**信号肽酶**切除。其他是**信号斑块**：由序列上相距很远、在蛋白质折叠时聚集的残基形成，或共价修饰如溶酶体酶的甘露糖-6-磷酸标签。没有分选信号的蛋白质留在细胞质基质。
:::

下表列出最著名的信号；序列是单字母氨基酸代码的典型例子。“正”指富含赖氨酸（K）与精氨酸（R）。

| 目的地 | 信号 | 例子 |
|---|---|---|
| 内质网 | N 端信号肽：正电残基，然后 6–15 个疏水残基的核心，最后切割位点 | 许多分泌蛋白 |
| 保留在 ER 腔 | C 端 KDEL | BiP 与其他 ER 分子伴侣 |
| 细胞核 | 短的碱性核定位信号（NLS） | `PKKKRKV`（SV40 大 T 抗原） |
| 从细胞核输出 | 富含亮氨酸的核输出信号 | — |
| 线粒体基质 | N 端两亲性螺旋，一面带正电荷 | 多数基质蛋白 |
| 过氧化物酶体 | C 端三肽（PTS1） | `SKL` |
| 溶酶体 | 高尔基体中加到信号斑块上的甘露糖-6-磷酸 | 溶酶体水解酶 |

蛋白质在隔室间以三种根本不同的方式移动：

1. **门控运输**通过核孔复合体，连接拓扑等价的两个空间——细胞质基质与核质；折叠蛋白质乃至整个核糖体亚基都能通过。
2. **跨膜运输**由蛋白质转位器把未折叠的链穿过膜送入拓扑不同的空间：ER 腔、线粒体、叶绿体。（过氧化物酶体不寻常，它输入折叠蛋白质。）
3. **囊泡运输**在内膜系统的拓扑等价隔室之间——ER、高尔基体、内体、溶酶体、质膜——膜包围的载体从一个隔室出芽并与下一个融合，携带腔内容物与膜蛋白。

## 进出细胞核

1984 年 Daniel Kalderon、Alan Smith 及同事表明，猴病毒 SV40 大 T 抗原中单个氨基酸改变就使蛋白质留在细胞质而非细胞核，而七残基序列 `PKKKRKV` 附到无关细胞质蛋白上能把它带入细胞核。这一**核定位信号**被输入蛋白-α识别，后者结合输入蛋白-β；输入蛋白-β 与衬里核孔的 FG 重复相互作用，把复合体带过。

方向来自小 GTP 酶 **Ran**。Ran 的鸟苷酸交换因子（RCC1）结合染色质，所以细胞核中的 Ran 载有 GTP；GTP 酶激活蛋白（RanGAP）在细胞质中，所以那里的 Ran 转为 Ran-GDP。Ran-GTP 在细胞核结合输入蛋白并使其释放货物；它与输出蛋白及其货物结合，并在细胞质中其 GTP 水解时释放两者。因此每种运输受体在一侧装载、另一侧卸载，把货物逆坡移动的能量——核蛋白积累远高于细胞质浓度——最终来自维持 Ran-GTP 梯度的 GTP 水解。

::: intuition Ran 作为指南针
受体本身不知道自己在哪一侧。Ran-GTP 知道：细胞核中很多，细胞质中很少。输入蛋白被设计成遇到 Ran-GTP 就放下货物，输出蛋白被设计成在那里拾起货物。一种小蛋白质的梯度把穿过核孔的无向扩散变成有向运输，正如糖的浓度梯度能驱动 [[cell-biology/membrane-transport]] 中的同向转运蛋白。
:::

## 进入内质网：信号假说

目的地为分泌途径的蛋白质在仍在制造时进入 ER。它们携带地址的想法由 Günter Blobel 与 David Sabatini 在 1971 年提出，并由 Blobel 与 Bernhard Dobberstein 在 1975 年检验：小鼠骨髓瘤细胞的免疫球蛋白轻链 mRNA 在无细胞系统中翻译时，产物比分泌蛋白长约 20 个残基；翻译时若存在来自 ER 的微粒体，延伸部分被切除，蛋白质进入囊泡内部，受到保护而不被加入的蛋白酶消化。Blobel 获 1999 年诺贝尔生理学或医学奖。

::: definition 信号假说与共翻译转位 {#def-signal-hypothesis}
目的地为分泌途径的蛋白质携带 N 端**信号肽**。它从核糖体出来后，**信号识别颗粒**（SRP，六种蛋白质与 7S RNA 的复合体）结合它和核糖体，暂停延伸。SRP 把复合体送到 ER 膜上的**SRP 受体**，把核糖体交给 **Sec61 转位子**，一个蛋白质传导通道。链在合成时被穿过转位子送入 ER 腔，信号肽被信号肽酶切除，SRP 由 GTP 水解回收。这条路线称为**共翻译转位**。
:::

Peter Walter 与 Blobel 在 1980–81 年纯化 SRP；Tom Rapoport 的实验室鉴定 Sec61，并在 2004 年解出其古菌同源物的结构——一个沙漏形通道，有可向脂双层侧向打开的侧门。

::: example 与核糖体赛跑 {#ex-translation-time}
哺乳动物核糖体每秒加约 5.6 个氨基酸（在鼠胚胎干细胞中由核糖体分析测得：Nicholas Ingolia、Liana Lareau 与 Jonathan Weissman，2011）。(a) 制造 500 残基蛋白质需要多久？(b) 核糖体出口隧道容纳约 30–40 个残基，所以残基 1–25 的信号肽在约 60–70 个残基聚合后完全暴露。这是起始后多久，为什么 SRP 暂停延伸重要？
::: solution
(a) $500/5.6 \approx 89\ \mathrm{s}$，约一分半。

(b) $70/5.6 \approx 12.5\ \mathrm{s}$。若翻译直接继续，蛋白质的很大部分可能在核糖体找到转位子之前已在细胞质基质中制造并开始折叠；折叠的结构域不能通过 Sec61。延伸暂停争取时间，在链仍短时到达 ER 膜。（细菌每秒翻译 15–20 个残基，许多分泌蛋白反而由分子伴侣保持未折叠并在翻译后输出。）
:::
:::

### 膜蛋白与拓扑

转位子也插入膜蛋白，其方向在通过时决定。足以跨双层的疏水片段——约 20 个残基，如 [[cell-biology/membranes#ex-tm-helix]]——从 Sec61 侧门滑入脂质。

- 被切除的 N 端信号肽，后面跟一个疏水**停止转移**片段，给出 N 端在腔、C 端在细胞质基质的单次跨膜蛋白（I 型；LDL 受体是例子）。
- 未被切除的内部疏水**信号锚**序列可任一向插入；两侧电荷决定方向。正电残基更多的一侧留在细胞质基质——von Heijne 的正电荷在内规则。
- 多次跨膜蛋白把连续疏水片段交替作为起始转移与停止转移序列插入，把链来回缝合。

由于 ER 蛋白的腔结构域在囊泡运输后最终位于质膜外侧（[[cell-biology/organelles#def-organelle]] 的拓扑等价），转位子做出的决定固定了每个细胞表面受体的方向。

极端 C 端有单一疏水片段的蛋白质——**尾锚定蛋白**——不能使用 SRP，因为片段只在翻译完成后出现。它们在从核糖体释放后被捕获，并由独立系统插入（酵母中的 GET 途径，哺乳动物中的 TRC）。

### ER 中的折叠与质量控制

ER 腔是蛋白质折叠隔室。其分子伴侣 BiP（Hsp70 家族成员）结合新出现的链；蛋白质二硫键异构酶形成并重排二硫键，氧化性腔有利于它；位于转位子旁的寡糖转移酶把预组装的 14 糖寡糖（Glc₃Man₉GlcNAc₂）加到序列 **Asn-X-Ser/Thr** 中的天冬酰胺上，X 是除脯氨酸外的任何氨基酸。这种**N 连接糖基化**既帮助折叠，也作质量控制标签：葡萄糖残基逐一修剪，未正确折叠的蛋白质被识别暴露疏水表面的酶重新加葡萄糖，再次结合凝集素分子伴侣钙连蛋白与钙网蛋白尝试折叠。

永远不折叠的蛋白质被逆向转位到细胞质基质，泛素化并由蛋白酶体降解——**ER 相关降解**（ERAD）。当未折叠蛋白积累快于处理，三种 ER 膜传感器（IRE1、PERK、ATF6）触发**未折叠蛋白反应**，减慢翻译、增加分子伴侣与 ERAD 组分，若胁迫未缓解则触发凋亡。UPR 主要在酵母中由 Peter Walter 与 Kazutoshi Mori 在 1990 年代弄清。

::: example 寻找糖基化位点 {#ex-sequon}
腔片段 `MNGTLSNPSADNKTVWNASQ` 中哪些天冬酰胺是潜在 N 糖基化位点？
::: solution
找 N 后接除 P 外的任何残基，再接 S 或 T。从 M = 1 编号：N2–G–T 符合；N7–P–S 不符合（X 为脯氨酸）；N12–K–T 符合；N17–A–S 符合。所以三个序列位点：Asn2、Asn12 与 Asn17。并非每个位点都被使用——非常靠近 C 端或在链折叠后被埋藏的位点可能被跳过——但缺少位点就排除 N 糖基化。
:::
:::

## 进入线粒体、叶绿体与过氧化物酶体

这些细胞器在翻译后从细胞质基质输入已完全合成的蛋白质。多数线粒体基质蛋白有 15–50 个或更多残基的 N 端**前序列**，折叠成一面带正电、另一面带疏水残基的两亲性α螺旋。**TOM** 复合体（外膜转位酶）的受体识别它，链以未折叠形式穿过 TOM，然后穿过内膜的 **TIM23** 复合体。内膜的膜电位（基质为负）电泳拉动正电前序列，基质 Hsp70 由 ATP 驱动把链其余部分棘轮拉入；基质加工肽酶随后切除前序列。其他路线使用 TIM22、SAM 复合体与 MIA 二硫键接力，把载体蛋白插入内膜、β桶插入外膜、小蛋白插入膜间隙。叶绿体使用类似的 **TOC** 与 **TIC** 复合体及 N 端转运肽；类囊体蛋白随后经从蓝细菌祖先继承的途径穿过另一层膜。

过氧化物酶体输入其基质蛋白为*折叠*状态，甚至作为寡聚体，使用受体 PEX5，它识别 C 端 `SKL` 信号（PTS1；Stephen Gould、Suresh Subramani 及同事，1987–89），以及一种仍不完全理解的转位机制。

::: warning “信号序列被切除，所以它们不是蛋白质的一部分”
有些被切除，有些不被切除，区别重要。ER 信号肽与线粒体前序列通常被移除；核定位信号不，因为蛋白质必须在每次有丝分裂后能回到细胞核，那时核膜破裂、内容物与细胞质混合。KDEL ER 保留信号和过氧化物酶体 SKL 也保留。第二个错误是认为足以定位的信号总是必需：许多蛋白质有冗余信号，删除一个可能影响很小。
:::

## 分泌途径

蛋白质进入 ER 后，以囊泡继续移动。路线由 George Palade 与 James Jamieson 在 1960 年代于豚鼠胰腺腺泡细胞中追踪，这些细胞分泌大量消化酶。他们给组织切片短脉冲放射性氨基酸（$^3$H-亮氨酸），然后“追踪”未标记氨基酸，并在电镜下用放射自显影追踪新制造蛋白。脉冲后几分钟标记在粗面 ER 上；数十分钟内到达高尔基体区域及其*反式*侧的浓缩液泡；约两小时后在酶原颗粒中，准备分泌。Palade 与 Albert Claude、Christian de Duve 共享 1974 年诺贝尔生理学或医学奖。

脉冲–追踪实验有简单的数学描述，是后来所有膜运输动力学研究的基础。

::: proposition 串联的两个隔室 {#prop-compartments}
假设标记蛋白以一级过程离开隔室 A（ER），速率常数 $k_1$，进入隔室 B（高尔基体），并以 $k_2 \neq k_1$ 离开 B 去 C（颗粒或细胞表面）。开始全部标记在 A，时间 $t$ 时各隔室的分数为

$$
A(t) = e^{-k_1 t}, \qquad B(t) = \frac{k_1}{k_2 - k_1}\left(e^{-k_1 t} - e^{-k_2 t}\right), \qquad C(t) = 1 - A(t) - B(t).
$$ {#eq-compartments}

$B$ 在 $t^* = \ln(k_2/k_1)/(k_2 - k_1)$ 达峰。假设：每个隔室充分混合（每个分子单位时间离开概率相同），速率常数不随时间或蛋白量变化，且无降解。
:::

::: proof
$dA/dt = -k_1A$，$A(0) = 1$，给出 $A = e^{-k_1t}$。然后 $dB/dt = k_1A - k_2B = k_1e^{-k_1t} - k_2B$。乘以积分因子 $e^{k_2t}$，$\frac{d}{dt}(Be^{k_2t}) = k_1e^{(k_2-k_1)t}$；以 $B(0) = 0$ 积分得 $Be^{k_2t} = \frac{k_1}{k_2-k_1}(e^{(k_2-k_1)t} - 1)$，即 [[#eq-compartments]]。令 $dB/dt = 0$ 得 $k_1e^{-k_1t^*} = k_2e^{-k_2t^*}$，所以 $t^* = \ln(k_2/k_1)/(k_2-k_1)$。求解此类线性常微分方程见[数学图谱：一阶方程](/learn/maths/course.php?c=ode)。
:::

::: example 解读脉冲–追踪 {#ex-pulse-chase}
一个膜糖蛋白以 20 分钟半时间离开 ER，并以 10 分钟半时间通过高尔基体。高尔基体中的量何时达峰，此时脉冲的多少比例在那里？
::: solution
$k_1 = \ln2/20 = 0.0347\ \mathrm{min^{-1}}$，$k_2 = \ln2/10 = 0.0693\ \mathrm{min^{-1}}$。则 $t^* = \ln 2/(0.0693 - 0.0347) = 0.693/0.0347 = 20\ \mathrm{min}$。此时 $A = e^{-0.693} = 0.5$，$B = \frac{0.0347}{0.0347}(0.5 - 0.25) = 0.25$。标记蛋白的四分之一在高尔基体峰值时在那里；一半仍在 ER，四分之一已离开。

实践中隔室按生物化学区分：糖蛋白的糖链只有在*中间*高尔基体修饰后才抵抗内切糖苷酶 H，所以“Endo H 抗性”比例测量了通过该点的量。
:::
:::

### 囊泡：包被、Rab 与 SNARE

囊泡运输的每一步包括出芽、靶向与融合。

**出芽**由在供体膜胞质面组装的**包被蛋白**驱动，它们使膜弯成芽并选择货物。**COPII** 包被形成从 ER 到高尔基体的囊泡；**COPI** 包被把物质从高尔基体送回 ER 并在高尔基体扁囊间运输；**网格蛋白**与接头蛋白（反式高尔基网络中的 AP1，质膜上的 AP2）形成多面体篮，把货物从高尔基体运到内体、从质膜向内运。小 GTP 酶——COPII 的 Sar1，COPI 与 AP1 的 Arf1——在其 GTP 结合形式开启包被组装。网格蛋白包被的芽由**动力蛋白**掐断，这种 GTP 酶在芽颈周围组装成环。

逃出的 ER 居民被送回：携带 C 端 **KDEL** 序列的可溶腔蛋白被高尔基体中的 KDEL 受体结合，并由 COPI 囊泡带回（Sean Munro 与 Hugh Pelham，1987）。

**靶向**使用 **Rab** GTP 酶——人中有 60 多种，每种标志一个隔室——及其招募的系绳蛋白，在正确目的地捕获囊泡。

**融合**由 **SNARE** 蛋白驱动。囊泡上的 v-SNARE 与靶膜上的 t-SNARE 拉链般合成四螺旋束，把两层双层拉近直到融合。ATP 酶 NSF 及其接头 SNAP 随后撬开复合体以供再利用。SNARE 假说来自 James Rothman 的生物化学（Thomas Söllner 及同事，1993）；Randy Schekman 更早通过分离酵母 *Saccharomyces cerevisiae* 的温度敏感 *sec*（分泌缺陷）突变体鉴定途径基因（Peter Novick、Charles Field 与 Schekman，1980）；Thomas Südhof 表明 Ca²⁺ 传感器 synaptotagmin 如何触发突触囊泡快速融合。三人共享 2013 年诺贝尔生理学或医学奖。

::: intuition 高尔基体的两种模型
货物如何通过高尔基体堆？在**囊泡运输**模型中，扁囊稳定，各有自己的酶，货物乘 COPI 囊泡向前跳。在**扁囊成熟**模型中，新扁囊在*顺式*面形成并自身穿过堆，当 COPI 囊泡把常驻酶*向后*携带时改变身份。大型货物如原胶原杆（长 300 nm），装不进 60–80 nm 囊泡，难以用第一模型解释；酵母高尔基体扁囊成熟时变色的活体成像（Benjamin Glick 与 Akihiko Nakano 的实验室，2006）强烈支持第二模型用于酵母。动物细胞中两种过程可能都运作。
:::

### 反式高尔基网络的分选

在高尔基体末端，蛋白质被分进三条主流：经**组成型分泌**到质膜，这在所有细胞中连续进行；进入**分泌颗粒**作**调节型分泌**，货物以浓缩形式储存直到信号——通常是细胞质基质 Ca²⁺ 上升——触发融合（激素、消化酶、神经递质）；以及到**内体与溶酶体**。

溶酶体水解酶在*顺式*高尔基体被一种酶标记，该酶识别其折叠表面的信号斑块，把 GlcNAc-磷酸加到甘露糖残基上；第二种酶移除 GlcNAc，露出**甘露糖-6-磷酸**（M6P）。在反式高尔基网络，M6P 受体结合它们并装入网格蛋白囊泡运到内体，酸性 pH 在那里释放酶，受体回到高尔基体。极化上皮细胞还有进一步分选步骤，把蛋白质分到顶面与基底面。

::: application 分选失败时：I 细胞病
在遗传性溶酶体贮积病黏脂贮积症 II，即**I 细胞病**，制造 M6P 标签的 GlcNAc 磷酸转移酶有缺陷。Elizabeth Neufeld 及同事在 1960 年代末与 1970 年代初发现，患者成纤维细胞把溶酶体水解酶分泌到培养基而非保留，且这些细胞的溶酶体充满未消化物质（“包涵细胞”）。健康细胞能通过细胞表面 M6P 受体从培养基摄取分泌的酶——这一发现后来支撑了几种溶酶体贮积病的酶替代疗法。一个缺陷的分选酶因此错送数十种不同水解酶。临床方面属于[医学图谱：遗传学](/learn/medicine/course.php?c=genetics)。
:::

## 内吞

细胞通过**内吞**摄取物质：质膜内陷并掐下一个含细胞外液与表面结合分子的囊泡。大颗粒——细菌、死细胞——由**吞噬**吞入，依赖肌动蛋白，主要在巨噬细胞与中性粒细胞等特化细胞中。液体由**胞饮**摄取，包括大而不规则的**大胞饮体**和小囊泡。了解最清楚的路线是经网格蛋白包被小窝的**受体介导内吞**。

Michael Brown 与 Joseph Goldstein 在 1970 年代研究人细胞如何摄取低密度脂蛋白（LDL）携带的胆固醇时发现它。家族性高胆固醇血症患者的培养成纤维细胞不能结合 LDL，或能结合但不能内化；第二类受体不能聚集在包被小窝中，因为受体胞质尾突变，该尾携带被接头识别的内化信号 NPxY。Brown 与 Goldstein 共享 1985 年诺贝尔生理学或医学奖。（临床方面：[医学图谱](/learn/medicine/course.php?c=cell-biochemistry)。）

进入后，内吞囊泡与**早期内体**融合，轻度酸性（pH 约 6.0–6.5）的分选站。许多受体在那里释放配体并经循环内体返回表面；LDL 受体约每 10–20 分钟往返一次。未被循环的物质随内体成熟——获得不同 Rab 与磷酸肌醇、变得更酸、积累内部囊泡——成为与溶酶体融合的**晚期内体**。转铁蛋白受体说明酸如何被利用：携带两个 Fe³⁺ 的转铁蛋白在中性 pH 结合受体；在内体中酸释放铁，但无铁转铁蛋白仍结合受体，两者返回表面，中性 pH 下脱铁转铁蛋白被释放。

::: example 内吞移动多少膜？ {#ex-endocytosis}
巨噬细胞每小时摄取约其体积 25% 的液体，这要求它们每分钟内化约 3% 的质膜（Alberts 第 7 版，引用 Ralph Steinman 及同事 1976 年的测量）。对质膜 1000 µm² 的细胞，每秒多少个直径 100 nm 的囊泡？
::: solution
内化膜：$0.03\times1000 = 30\ \mathrm{\mu m^2\,min^{-1}}$。直径 0.1 µm 的球形囊泡面积为 $\pi d^2 = 4\pi(0.05)^2 = 0.0314\ \mathrm{\mu m^2}$。所以

$$
\frac{30}{0.0314} \approx 950\ \text{囊泡每分钟} \approx 16\ \text{每秒}.
$$

整个表面约半小时内被内化，但细胞不缩小：膜以同样速率经外排返回表面。内吞与外排是平衡循环，不是单向交通。
:::
:::

::: quiz
一个溶酶体酶在其 N 端融合了不能被 SRP 识别的突变 ER 信号肽。蛋白质最可能最终在哪里？
- [ ] 在溶酶体，因为它仍有甘露糖-6-磷酸信号斑块。
- [ ] 被分泌，因为它缺少 M6P 标签。
- [x] 在细胞质基质，因为它从未进入 ER，因此从未被标记或分选。
- [ ] 在细胞核，因为没有信号的蛋白质默认去那里。
::: solution
分选是分层的。M6P 标签在高尔基体加上，蛋白质只有经 ER 才能到达那里；没有功能性 ER 信号，它被制造并留在细胞质基质，即默认目的地。细胞核需要 NLS（小蛋白可扩散进入，但不会积累在那里）。这一逻辑——每个信号只有在前一步发生后才有作用——正是用突变表型排列途径步骤的方式。
:::
:::

::: history
Keith Porter、Albert Claude 与 Ernest Fullam 在 1945 年看到“内质网”，George Palade 在 1955 年描述核糖体（“Palade 颗粒”）；Palade 与 James Jamieson 的脉冲–追踪工作发表于 1966–67 年。Günter Blobel 与 David Sabatini 在 1971 年提出信号假说，Blobel 与 Bernhard Dobberstein 在 1975 年检验它。酵母分泌缺陷 *sec* 突变体由 Peter Novick、Charles Field 与 Randy Schekman 在 1980 年描述。Elizabeth Neufeld 对 I 细胞成纤维细胞的发现与 Stuart Kornfeld 的生物化学导致甘露糖-6-磷酸途径（1970 年代到 1980 年代初）。Brown 与 Goldstein 关于 LDL 受体的论文从 1974 年出现，包被小窝途径在他们与 Richard Anderson 1976–77 年的工作中成像。Kalderon、Smith 及同事在 1984 年鉴定 SV40 NLS；James Rothman 在 1980 年代的高尔基体运输无细胞实验导致 NSF 与 SNAP，并在 1993 年导致 SNARE 假说。
:::

::: summary
- 蛋白质携带分选信号——信号序列、信号斑块或修饰——被受体读取并导向细胞核、ER、线粒体、叶绿体、过氧化物酶体或囊泡途径；无信号的蛋白质留在细胞质基质。
- 核输入与输出让折叠蛋白经孔通过，使用输入蛋白与输出蛋白；Ran-GTP 梯度给出方向。
- 分泌与膜蛋白共翻译进入 ER：SRP 结合信号肽与核糖体，把它们送到 Sec61，信号被切除。疏水停止转移与信号锚序列，按正电荷在内规则读取，设定膜蛋白拓扑。
- ER 折叠蛋白质（BiP、PDI、Asn-X-Ser/Thr 上的 N 糖基化、钙连蛋白循环），通过 ERAD 销毁错折叠的蛋白质，并通过 UPR 发出胁迫信号。
- 线粒体与叶绿体在翻译后经 TOM/TIM 与 TOC/TIC 输入未折叠蛋白；过氧化物酶体用 PTS1（SKL）输入折叠蛋白。
- 囊泡以 COPII、COPI 或网格蛋白包被出芽，由 Rab 与系绳靶向，经 SNARE 融合。脉冲–追踪动力学由串联一级隔室描述。
- 在反式高尔基网络，蛋白质被分到组成型或调节型分泌，或（经甘露糖-6-磷酸）到溶酶体；内吞经内体返回膜与受体，循环其中多数。
:::

::: exercise 匹配地址 {level=1}
每种蛋白质应去哪个隔室？(a) N 端 18 个残基、含 10 个疏水残基核心，并有 C 端 KDEL 的蛋白质。(b) 含内部序列 `PKKKRKV` 且无其他信号的蛋白质。(c) N 端富含精氨酸的两亲性螺旋的蛋白质。(d) 以 `SKL` 结尾的蛋白质。(e) 有 N 端信号肽且无其他信号的蛋白质。
::: solution
(a) ER 腔：信号肽把它带入，KDEL 若它逃到高尔基体则将其取回。(b) 细胞核。(c) 线粒体基质。(d) 过氧化物酶体基质。(e) 经组成型途径分泌：分泌途径中无保留或分选信号的可溶蛋白默认离开细胞。
:::

::: exercise ER 出口 {level=1 check="0.125"}
若蛋白质以半时间 20 分钟的一级过程离开 ER，60 分钟后脉冲还剩多少比例在 ER？
::: solution
$A(60) = e^{-k_1\cdot60}$，$k_1 = \ln2/20$，即 $(1/2)^{60/20} = 0.125$。
:::

::: exercise 高尔基体何时达峰？ {level=2 check="13.9"}
对 [[#prop-compartments]] 模型取 $k_1 = 0.05\ \mathrm{min^{-1}}$、$k_2 = 0.10\ \mathrm{min^{-1}}$，隔室 B 的标记量何时达峰（分钟，三位有效数字）？
::: solution
$t^* = \ln(k_2/k_1)/(k_2 - k_1) = \ln 2/0.05 = 13.9\ \mathrm{min}$。
:::

::: exercise 囊泡出芽速率 {level=2 check="22.1"}
质膜 2000 µm² 的细胞每分钟内化 3%，囊泡直径 120 nm。每秒多少个囊泡出芽（三位有效数字）？
::: solution
每分钟膜：$60\ \mathrm{\mu m^2}$。囊泡面积：$\pi(0.12)^2 = 0.04524\ \mathrm{\mu m^2}$。每分钟囊泡：$60/0.04524 = 1326$；每秒 $22.1$。

::: exercise 用 sec 突变体排列途径 {level=2}
酵母温度敏感 *sec* 突变体在 25 °C 正常分泌，但在 37 °C 停止分泌并积累膜。A 类突变体（如 *sec12*）积累 ER；B 类（如 *sec7*）积累高尔基体扁囊；C 类（如 *sec1*）积累分泌囊泡。(a) 每类阻断哪一步？(b) 37 °C 下 *sec12 sec7* 双突变体积累 ER 而非高尔基体，这说明步骤顺序如何？(c) 为何需要温度敏感等位基因？
::: solution
(a) A 类阻断 ER 到高尔基体运输（Sec12 激活 COPII 出芽的 Sar1）；B 类阻断离开高尔基体；C 类阻断分泌囊泡与质膜融合（Sec1 属于与 SNARE 协同的 SM 蛋白家族）。
(b) 双突变体显示更早阻断的表型。若货物不能离开 ER，它永远到不了高尔基体，所以高尔基体积累（需要先有 ER 出口）不能出现。这是**上位效应**分析：较早步骤的表型掩盖较晚步骤，顺序 ER → 高尔基体 → 囊泡 → 质膜由此得出。Novick、Field 与 Schekman 在 1980–81 年正是用这一逻辑。
(c) 分泌对生长必需（细胞必须增加膜与壁），所以无效突变体会死亡、无法研究。温度敏感等位基因让细胞在 25 °C 生长并在 37 °C 显示缺陷。
:::
:::

::: exercise 推断膜蛋白拓扑 {level=3}
一个新发现的人蛋白质有 420 个残基，被切除的 N 端信号肽（残基 1–22），Asn85 与 Asn390 处有 N 糖基化序列位点，以及一个 21 残基疏水片段（残基 300–320）后接序列 `RRKLK`。(a) 预测拓扑：N 与 C 端在哪里，哪些位点可被糖基化？(b) 设计用微粒体与蛋白酶的实验检验预测。(c) 若两个位点都被糖基化，你会得出什么？
::: solution
(a) 信号肽把 N 端送入 ER 腔；疏水片段作停止转移锚，其后正电簇留在细胞质基质，所以 C 端在细胞质基质。这是 I 型蛋白，残基 23–299 在腔中（最终在细胞外），321–420 在细胞质基质。只有 Asn85 在腔中可被糖基化；Asn390 在细胞质基质，寡糖转移酶不作用。
(b) 在含微粒体的无细胞系统中翻译蛋白质，然后加蛋白酶（有和无洗涤剂）。若预测正确，蛋白酶移除胞质 C 端 100 个残基，但腔结构域受保护，除非洗涤剂打开囊泡；C 端抗体失去信号，N 端结构域抗体不失。糖苷酶处理会显示一个聚糖。
(c) C 端区域也必须在腔中：也许疏水片段不停止转移（可能太短或太极性而留在膜中），使蛋白质在腔中可溶；或第二个未注意的疏水片段重新插入链。预测方法需要修正。
:::
:::

::: exercise 解读交叉纠正实验 {level=3}
两种不同溶酶体贮积病患者的成纤维细胞各自积累未消化物质。把两细胞系在同一培养皿中培养，两者都变正常。加入正常细胞的培养基也能纠正任一细胞系——但如果培养基用移除甘露糖-6-磷酸上磷酸的酶处理，或加入高浓度游离 M6P，则不能。(a) 解释共培养结果。(b) 最后两个观察说明纠正因子是什么？(c) I 细胞病患者的成纤维细胞不能被另一名 I 细胞病患者的培养基纠正，但其培养基含大量溶酶体酶。解释。
::: solution
(a) 每个细胞系缺少不同的溶酶体酶。细胞通常分泌一小部分新制造的溶酶体酶，邻近细胞摄取并送入溶酶体。共培养时每个细胞系供应另一个缺少的酶。
(b) 摄取依赖酶上的 M6P 标签（移除磷酸即废除）和细胞表面 M6P 受体（游离 M6P 竞争它们）。纠正因子是带 M6P 标签的溶酶体酶。
(c) I 细胞病中制造标签的磷酸转移酶缺失，所以细胞分泌*无标签*的水解酶。这些酶有活性但不能结合 M6P 受体，因此不能被另一细胞摄取——包括另一 I 细胞成纤维细胞。正常细胞的培养基含带标签的酶，能纠正它们。（这就是 Neufeld 实验的逻辑。）
:::
