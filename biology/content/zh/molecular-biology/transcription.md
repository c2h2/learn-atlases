基因在被转录之前什么也不做。转录把一条 DNA 链上的一段抄录成 RNA，它是基因表达的第一步，也是受调控最重的一步。每个细胞制造数千种不同的 RNA，数量从每个细胞几个分子到数万个不等。它靠的是选择 RNA 聚合酶从哪里起始、多久起始一次、移动多快、在哪里停止。细菌用一种 RNA 聚合酶加少数几种辅助蛋白做这一切。真核生物使用三种核内聚合酶，各有各的一组因子，工作在包装成染色质的 DNA 上。

本章描述转录的机器与转录循环：在启动子上的起始、延伸与终止，先看细菌——那里的基本逻辑最清楚——再看真核生物。起始的频率如何被阻遏蛋白、激活蛋白与染色质控制，是 [[molecular-biology/bacterial-gene-regulation]] 与 [[molecular-biology/eukaryotic-gene-regulation]] 的主题。RNA 之后发生什么，是 [[molecular-biology/rna-processing]] 的主题。

## 基本反应

::: definition 转录及其术语 {#def-transcription}
**转录**是由**依赖 DNA 的 RNA 聚合酶**以一条 DNA 链为模板合成 RNA。聚合酶把核糖核苷三磷酸（ATP、GTP、CTP、UTP）加到生长中 RNA 的 3′ 端，所以 RNA 按 5′→3′ 生长，模板链被按 3′→5′ 读取。**模板链**（又称反义链或非编码链）与 RNA 互补。**编码链**（有义链或非模板链）与 RNA 具有相同序列，只是以 T 代 U，按惯例基因序列按编码链书写。**转录单元**从编号为 $+1$ 的**起始位点**延伸到终止子。**上游**（编码链的 5′ 侧）位置按负数编号，没有 0 位；**下游**位置按正数编号。**启动子**是 RNA 聚合酶结合并起始转录的 DNA 序列。与 DNA 聚合酶不同，RNA 聚合酶不需要引物。
:::

一种短命的、把信息从基因带到核糖体的 RNA——**信使 RNA**——的存在于 1961 年被确立。布伦纳（Sydney Brenner）、雅各布（François Jacob）与梅塞尔森（Matthew Meselson）证明，噬菌体感染的大肠杆菌会制造新的 RNA，并与原有的核糖体结合；格罗（François Gros）、吉尔伯特（Walter Gilbert）及同事在未感染细胞中检测到不稳定的 RNA。早在 1959–60 年，韦斯（Samuel Weiss）与格拉德斯通（Leonard Gladstone）、胡维茨（Jerard Hurwitz）与史蒂文斯（Audrey Stevens）已在细菌提取物中发现 RNA 聚合酶。

::: example 哪条链是模板？ {#ex-strands}
某基因编码链的一部分读作 `5'-ATGGCTTACGGA-3'`。(a) 写出模板链（5′→3′）。(b) 写出从这一区域转录出的 RNA。(c) RNA 聚合酶沿模板链向哪个方向移动？
::: solution
(a) 模板链是编码链的反向互补：`5'-TCCGTAAGCCAT-3'`。

(b) RNA 的序列与编码链相同，只是以 U 代 T：`5'-AUGGCUUACGGA-3'`。

(c) RNA 按 5′→3′ 生长，与模板反向平行，所以聚合酶沿模板按 3′→5′ 读取。也就是说，它从 (a) 中所写模板序列的 3′ 端向其 5′ 端移动，等同于沿编码链按 5′→3′ 移动。下游就是移动的方向。
:::
:::

## 细菌的转录

### RNA 聚合酶与 σ

大肠杆菌 RNA 聚合酶的**核心酶**有五个亚基，α₂ββ′ω，总重约 400 kDa。两个大亚基 β 与 β′ 形成蟹钳状，活性部位——一个由 β′ 的天冬氨酸固定的 Mg²⁺ 离子——位于两亚基之间裂隙的底部。核心酶能转录，但起始位点是随机的。特异起始需要一个 **σ 因子**，它把核心酶变成**全酶**。伯吉斯（Richard Burgess）、特拉弗斯（Andrew Travers）、邓恩（John Dunn）与鲍茨（Ekkehard Bautz）1969 年发现了 σ：纯化聚合酶的一个组分不能正确转录噬菌体 T4 的 DNA，直到把含 σ 的组分加回去才行。

大肠杆菌有七个 σ 因子。管家因子 σ⁷⁰（RpoD）指导大多数基因的转录。替代 σ 因子识别不同的启动子，在特定条件下开启一批基因：σ³²（RpoH）对应热激，σ³⁸（RpoS）对应稳定期与胁迫，σ⁵⁴（RpoN）对应氮限制，等等。枯草芽孢杆菌（*Bacillus subtilis*）中，一个 σ 因子级联通向孢子形成的各个阶段。更换 σ 因子是重编程一个细菌细胞转录的最简单方式。

### 启动子

::: definition σ⁷⁰ 启动子元件 {#def-promoter}
典型的大肠杆菌 σ⁷⁰ 启动子有两个六聚体（写在编码链上），中心分别位于起始位点上游约 10 与 35 bp 处：
- **−10 元件**（Pribnow 盒），共有序列 `TATAAT`；
- **−35 元件**，共有序列 `TTGACA`；
- 两者被 17 bp 的**间隔区**隔开（有功能的启动子为 15–19 bp，17 bp 最佳）。

有些启动子还有**延伸 −10**（紧邻 −10 元件上游的 `TG`）与 **UP 元件**——位于 −35 上游、被 α 亚基 C 端结构域结合的 A·T 富集序列。σ⁷⁰ 的区 4 结合 −35 元件，区 2 结合 −10 元件；起始位点通常是 −10 元件下游 6–8 bp 处的一个嘌呤。**共有序列**是许多启动子中每个位置上最常见的碱基。天然启动子很少与之完全匹配，越接近共有序列的启动子通常越强。
:::

普里布诺（David Pribnow，1975）与沙勒（Heinz Schaller）及同事（1975）通过比较最初几个启动子的序列注意到了 −10 元件，随着更多启动子被测序，−35 元件随之显露。突变证实了这一模型。朝共有序列方向的改变（**加强启动子**突变）增加转录，背离它的改变（**削弱启动子**突变）减少转录。例如，*lac* 启动子的 −10 元件很弱（`TATGTT`）。*lacUV5* 突变体带着两个把它变成 `TATAAT` 的改变，强到不再需要激活蛋白 CAP（[[molecular-biology/bacterial-gene-regulation]]）。

```python
# 给 σ-70 启动子元件打分：间隔区 15-19 bp 的最佳 -35 / -10 组合
M35, M10 = "TTGACA", "TATAAT"

def matches(a, b):
    return sum(x == y for x, y in zip(a, b))

def best_promoter(seq):
    best = None
    for i in range(len(seq) - 6):                     # -35 六聚体的起点
        for spacer in range(15, 20):
            j = i + 6 + spacer                        # -10 六聚体的起点
            if j + 6 > len(seq):
                break
            score = matches(seq[i:i+6], M35) + matches(seq[j:j+6], M10) - abs(spacer - 17)
            if best is None or score > best[0]:
                best = (score, seq[i:i+6], spacer, seq[j:j+6])
    return best

# 虚构的上游序列（5'->3'，编码链）
promoters = {
    "strong":  "GCATTTGACATTTATCCGCTCACAATTTATAATGGCATCG",
    "weak":    "GCATTTTACACTTTATGCTTCCGGCTCGTATGTTGTGTGG",
    "spacer":  "GCATTTGACATTTATCCGCTCACAATCGTTATAATGGCAT",
}
for name, s in promoters.items():
    score, m35, sp, m10 = best_promoter(s)
    print(f"{name:7s} -35 {m35} ({matches(m35, M35)}/6)  spacer {sp}  -10 {m10} ({matches(m10, M10)}/6)  score {score}")
```

脚本打印：

```
strong  -35 TTGACA (6/6)  spacer 17  -10 TATAAT (6/6)  score 12
weak    -35 TTTACA (5/6)  spacer 18  -10 TATGTT (4/6)  score 8
spacer  -35 TTGACA (6/6)  spacer 19  -10 TATAAT (6/6)  score 10
```

打分规则是每个匹配碱基一分、间隔区每偏离 17 bp 一个碱基对扣一分，它只是结合能的粗略替身。要点在逻辑而不在数字。两个六聚体必须按正确的间距同时存在，因为结合它们的两个 σ 结构域相距固定距离；而间隔区的长度还决定两个元件绕螺旋的相对夹角（[[molecular-biology/dna-structure#ex-helical-phase]]）。真实的启动子预测使用由许多已知启动子构建的位置权重矩阵（[[bioinformatics/gene-finding]]）。

### 起始的逐步过程

起始是一串可区分、可测量的步骤：

1. **闭合复合体。** 全酶以双链 DNA 的形式结合启动子，接触 −35 与 −10 元件。
2. **异构化为开放复合体。** 聚合酶解开约 13 bp（从约 −11 到 +2），把模板链放入活性部位。σ 区 2 在 −10 处非模板链的碱基翻出时将其俘获。不需要 ATP：结合能与 DNA 超螺旋驱动打开（[[molecular-biology/dna-structure#prop-topology]]）。
3. **初始转录。** 聚合酶停留在启动子上合成短 RNA，同时把下游 DNA 拉进自身（**挤压**（scrunching），卡帕尼迪斯（Kapanidis）、列维亚金（Revyakin）及同事 2006 年在单分子中观察到）。这些 RNA 中许多长 2 到约 10 个核苷酸的被释放（**流产起始**），循环往复。
4. **启动子逃逸。** RNA 达到约 10–15 个核苷酸后，挤压积累的应力得到释放，聚合酶断开与启动子的接触，堵住 RNA 出口通道的 σ 环袢被移开。σ 随后通常被释放，尽管并不总是立即如此。

::: proposition 启动子强度的两步模型 {#prop-mcclure}
设 RNA 聚合酶全酶 $R$ 以缔合常数 $K_B$ 快速、可逆地结合启动子 $P$ 形成闭合复合体 $RP_c$，后者以速率常数 $k_f$ 异构化为开放复合体 $RP_o$：
$$
R + P \;\underset{}{\overset{K_B}{\rightleftharpoons}}\; RP_c \;\xrightarrow{\;k_f\;}\; RP_o .
$$
若结合比异构化更快达到平衡，闭合复合体的占据分数为 $\theta = K_B[R]/(1 + K_B[R])$，每个启动子形成开放复合体的速率为
$$
v = k_f\,\theta = \frac{k_f\,[R]}{[R] + 1/K_B}.
$$ {#eq-mcclure}
所以启动子强度有两个可分的成分：亲和力（$K_B$）与异构化（$k_f$）。突变或调节因子可以改变其中任何一个。这一模型（麦克卢尔（William McClure），1980）忽略了流产循环、异构化的逆反应以及启动子逃逸所需的时间。
:::

::: example 两种类型的强启动子 {#ex-mcclure}
启动子 A 的 $K_B = 2\times10^7\ \mathrm{M^{-1}}$、$k_f = 0.05\ \mathrm{s^{-1}}$；启动子 B 的 $K_B = 2\times10^6\ \mathrm{M^{-1}}$、$k_f = 0.5\ \mathrm{s^{-1}}$。这些是在体外测得范围内的示意值。取游离全酶浓度为 50 nM。(a) 计算每个启动子的 $v$，以及两次开放复合体之间的平均时间。(b) 游离全酶浓度加倍时，哪个启动子获益更大？(c) 一个能接触聚合酶的激活蛋白使它对启动子的亲和力增加十倍。它会更明显地激活哪个启动子？
::: solution
(a) 对 A，$1/K_B = 50$ nM，所以 $\theta = 50/(50 + 50) = 0.5$，$v = 0.05\times0.5 = 0.025\ \mathrm{s^{-1}}$：每 40 s 一个开放复合体。对 B，$1/K_B = 500$ nM，所以 $\theta = 50/550 = 0.091$，$v = 0.5\times0.091 = 0.045\ \mathrm{s^{-1}}$：每 22 s 一个。B 是更强的启动子，尽管结合弱十倍。

(b) 100 nM 时：A 的 $\theta = 100/150 = 0.667$，$v = 0.033\ \mathrm{s^{-1}}$，增加 33 %；B 的 $\theta = 100/600 = 0.167$，$v = 0.083\ \mathrm{s^{-1}}$，增加 83 %。B 远未饱和，所以几乎线性地响应聚合酶浓度。

(c) 结合紧十倍使 A 的 $1/K_B$ 变为 5 nM，所以 $\theta = 50/55 = 0.91$，$v = 0.045\ \mathrm{s^{-1}}$，提高 1.8 倍。B 的 $1/K_B$ 变为 50 nM，所以 $\theta = 0.5$，$v = 0.25\ \mathrm{s^{-1}}$，提高 5.5 倍。靠募集起作用的激活蛋白，对受结合限制的启动子帮助最大。一个加快异构化的激活蛋白则会更大程度地帮助 A。两类激活蛋白都已为人知，$K_B$ 与 $k_f$ 的动力学测量能把它们区分开来。
:::
:::

sliders: kf=0.5:0.01:1:0.01; Kd=500:5:1000:5

### 延伸

逃逸之后，**延伸复合体**极其稳定：可以转录数万个碱基而不脱落。其内部约 9–10 bp 的 RNA–DNA 杂合双链坐在活性部位裂隙中，转录泡约 12–14 个核苷酸，RNA 从出口通道离开，模板链在聚合酶后方与编码链重新配对。细菌 RNA 聚合酶平均每秒移动约 50 个核苷酸（Alberts，第 7 版），在 rRNA 基因上更快。它并不平滑地移动。它会在特定序列处停顿，这给 RNA 折叠或核糖体赶上留出时间；它有时还会**回退**，向后滑动使 RNA 的 3′ 端离开活性部位。因子 GreA 与 GreB（真核生物中为 TFIIS）刺激聚合酶自身切割回退的 RNA，在活性部位中生成一个新的 3′ 端。同样的切割提供了一种校对形式。RNA 聚合酶不如复制型 DNA 聚合酶准确，每个核苷酸的错误率约为 $10^{-5}$，这可以容忍，因为 RNA 寿命短、而且拷贝数多。

在细菌中，转录与翻译是**偶联**的：核糖体在 mRNA 尚合成之中就结合上去开始翻译。米勒（Oscar Miller）、哈姆卡洛（Barbara Hamkalo）与托马斯（Charles Thomas）1970 年在裂解大肠杆菌的电镜照片中看到了这一点。DNA 纤维上带着长度递增的 RNA 链，每条 RNA 上缀满核糖体。偶联是衰减与极性的基础——极性指无义突变对操纵子下游基因的影响（[[molecular-biology/bacterial-gene-regulation]]）。

::: example 读一张米勒铺展图 {#ex-miller}
在快速生长的大肠杆菌核糖体 RNA 操纵子的电镜照片中，约 5.5 kb 的操纵子上覆盖着 RNA 聚合酶，平均间隔约 85 bp，呈现出米勒（Oscar Miller）与比蒂（Barbara Beatty）1969 年在两栖类 rRNA 基因上首先看到的"圣诞树"图样。(a) 操纵子上有多少个聚合酶？(b) 若聚合酶以 85 nt s⁻¹ 移动，多久有一个新的聚合酶起始？(c) 每个转录本的完成需要多长时间？（间隔与速度是示意值，量级与 rRNA 操纵子相当。）
::: solution
(a) $5500/85 \approx 65$ 个聚合酶。

(b) 稳态下，聚合酶离开末端的速率等于它们在起点进入的速率。每个聚合酶一秒移动 85 nt，所以相邻两个聚合酶相隔一秒的行程：约每秒起始一次，接近一个启动子可能的最大值。

(c) $5500/85 = 65$ s。细胞有七个 *rrn* 操纵子，其中几个靠近起点，并在快速生长中以多拷贝存在（[[molecular-biology/dna-replication#prop-ori-ter]]），所以每个世代可以制造数千个核糖体。
:::
:::

### 终止

细菌以两种方式终止转录。

- **内在（Rho 非依赖）终止。** 终止子是一段 G·C 富集的反向重复，其后在编码链上是一条约 7–9 个 T 的连续序列。转录出的反向重复恰在聚合酶到达 T 串时于出口通道中折成 RNA **发夹**。发夹破坏 RNA–DNA 杂合双链的上游部分，而剩下的 rU·dA 杂合双链是碱基配对最弱的双链，于是 RNA 被释放。终止效率取决于发夹的稳定性和 T 串的长度。
- **Rho 依赖终止。** **Rho** 是一种六聚体环状解旋酶，结合新生 RNA 上富含 C、无结构的区段（*rut* 位点）。它利用 ATP 沿 RNA 按 5′→3′ 移动，直到遇到聚合酶——通常此时聚合酶已经停顿——把 RNA 拉出。因为 Rho 需要裸露的 RNA，正在翻译的核糖体会保护 mRNA。因此 Rho 终止未经翻译的 RNA 上的转录，包括过早终止密码子下游的 RNA，这就解释了极性。

::: quiz
一个突变改变了内在终止子中一串 T 上游紧邻的序列，使 RNA 再也无法形成发夹。会发生什么？
- [ ] 转录更早停止，因为聚合酶会在突变处停顿。
- [x] 终止大大减弱，聚合酶通读到下游 DNA 中。
- [ ] 无事发生，因为仅凭 T 串就足够了。
- [ ] 终止现在需要 Rho，但仍发生在同一位置。
::: solution
两个元件都必需。发夹恰在聚合酶坐在弱配对的 T 串上之时使杂合双链失稳；没有发夹，仅凭 rU·dA 杂合双链不能有效地释放 RNA，所以聚合酶会继续。如果下游有一个合适的 *rut* 位点而且 RNA 未经翻译，Rho 可能在某处终止，但不会特异地停在这个位置。
:::
:::

## 真核生物的转录

### 三种核内 RNA 聚合酶

罗德尔（Robert Roeder）与拉特（William Rutter）1969 年用层析法从海胆与大鼠肝提取物中分离出三种核内 RNA 聚合酶。它们的不同在于所转录的东西，以及对**α-鹅膏蕈碱**——毒鹅膏（*Amanita phalloides*，死亡帽菇）的毒素——的敏感性。

| 聚合酶 | 主要产物 | α-鹅膏蕈碱 |
|---|---|---|
| RNA 聚合酶 I | 大 rRNA 前体（哺乳动物中为 45S），加工为 18S、5.8S 与 28S rRNA | 不敏感 |
| RNA 聚合酶 II | 前体 mRNA（pre-mRNA）；大多数小核 RNA（snRNA）；microRNA 的前体；许多长非编码 RNA | 高度敏感（1 μg mL⁻¹ 或更低即被阻断） |
| RNA 聚合酶 III | tRNA、5S rRNA、U6 snRNA、7SL RNA 及其他小 RNA | 中等敏感（较高浓度） |

植物还有另外两种聚合酶 IV 与 V，由聚合酶 II 进化而来，专门制造指导转座子 DNA 甲基化的小 RNA。所有真核聚合酶共享一个与细菌酶同源的核心。Pol II 有 12 个亚基，其中最大的 Rpb1 对应于 β′。酵母 Pol II 的结构（克拉默（Patrick Cramer）、布什内尔（David Bushnell）与罗杰·科恩伯格（Roger Kornberg），2001）显示出与细菌酶惊人相似的钳、裂隙和活性部位。科恩伯格因真核转录的结构基础获 2006 年诺贝尔化学奖。

Rpb1 有一个细菌中没有对应物的特征。它的 **C 端结构域（CTD）**是一条串联重复的尾巴，重复单元为七肽 `YSPTSPS`（Tyr-Ser-Pro-Thr-Ser-Pro-Ser）：出芽酵母中 26 个重复，人 52 个。Pol II 加入启动子时 CTD 未磷酸化。丝氨酸 5 在起始时磷酸化，丝氨酸 2 则在延伸过程中逐渐磷酸化。磷酸化模式不断变化——有时称为 **CTD 码**——在不同阶段募集不同的蛋白质：早期募集加帽酶，延伸期募集剪接因子，接近终点了募集切割与多聚腺苷酸化机器。RNA 加工就是这样与转录偶联的（[[molecular-biology/rna-processing]]）。

### 核心启动子与通用转录因子

纯化的 Pol II 能结合 DNA，却不能从启动子起始。它需要**通用转录因子**（GTF），命名为 TFIIA、TFIIB、TFIID、TFIIE、TFIIF 与 TFIIH，由罗德尔组及其他人自 1970 年代末起用生物化学方法鉴定。

::: definition 核心启动子与前起始复合体 {#def-pic}
**核心启动子**是通用机器得以组装的最小序列，大约从 −40 到 +40。其元件包括约 −30 处的 **TATA 盒**（共有序列 `TATAWAWR`，W 为 A 或 T，R 为嘌呤）、跨起始位点的**起始子**（Inr）、约 +30 处的下游启动子元件（DPE），以及 TATA 盒两侧的 TFIIB 识别元件。没有一个元件是普遍存在的。只有少数人的启动子有 TATA 盒，许多启动子位于 **CpG 岛**——起始位点分散的 G·C 富集区。**前起始复合体**（PIC）在体外按确定的顺序组装：
1. **TFIID** 结合核心启动子。它的 **TATA 结合蛋白**（TBP）在小沟中结合 TATA 盒，使 DNA 弯曲约 80°。它的 TBP 相关因子（TAF）接触 Inr 与 DPE。
2. **TFIIA** 与 **TFIIB** 加入；TFIIB 在 TBP 与聚合酶之间搭桥，并帮助选定起始位点。
3. **Pol II** 与 **TFIIF** 一道到来。
4. **TFIIE** 与 **TFIIH** 加入。TFIIH 有两个依赖 ATP 的活性：它的易位酶 XPB 打开 DNA（与细菌聚合酶不同，Pol II 需要 ATP 来熔解启动子），它的激酶 CDK7 磷酸化 CTD 的丝氨酸 5。
:::

TBP 被三种聚合酶共同使用。它的马鞍形结构（伯利（Stephen Burley）、西格勒（Paul Sigler）及同事，1993）解释了那个弯曲。DNA 背向蛋白质弯曲，小沟被加宽，两个苯丙氨酸侧链在 TATA 盒的两端插入碱基对之间。选择 A·T 富集的 TATA 序列，因为它是以这种方式最容易变形的序列，这是读取 DNA 形状而非碱基边缘的一个例子（[[molecular-biology/dna-structure]]）。

在细胞中，结合在增强子上的激活蛋白帮助 PIC 上到启动子，约 25–30 个亚基的大型 **Mediator**（中介复合体）在激活蛋白与 Pol II 之间搭桥，修饰或重塑核小体的辅激活蛋白也参与其中。这些是 [[molecular-biology/eukaryotic-gene-regulation]] 的主题。这里的要点是：GTF 是必需的，但并不充分。在染色质模板上，没有激活蛋白时它们几乎不产生转录。

::: warning "每个真核基因都有一个 TATA 盒"
TATA 盒是最先被发现的核心启动子元件，至今仍是最常被画出的那一个，但它是例外而非常态。对起始位点的全基因组研究（例如 FANTOM 联盟）发现只有约 10–20 % 的人启动子有 TATA 盒，且多为组织特异、高度受调控、在单一锐利位置起始的基因。大多数管家基因没有 TATA 盒，而是有几个起始位点散布在 50–100 bp 范围内的 CpG 岛启动子。没有 TATA 盒的启动子仍然需要 TBP，只是经由 TAF 和其他蛋白募集而来。许多启动子还是**双向的**，向相反方向产生一段短而不稳定的 RNA。
:::

### 暂停、延伸与终止

在后生动物中，Pol II 常常开始转录，然后在起始位点下游 20–60 个核苷酸处停住。这种**启动子近端暂停**由因子 DSIF 与 NELF 维持。当激酶 **P-TEFb**（CDK9–cyclin T）磷酸化 DSIF、NELF 与 CTD 丝氨酸 2 时，暂停被解除。暂停是在果蝇（*Drosophila*）的热激基因中发现的（利斯（John Lis）及同事，1980 年代），那里一个暂停的聚合酶等待热激信号。给占位聚合酶作图的全基因组方法显示，相当大一部分基因上都有它，所以从暂停中释放是一个主要的受调控步骤。

延伸中的 Pol II 必须穿过核小体。像 **FACT** 这样的组蛋白分子伴侣帮助它把组蛋白移开再放回，其身后的组蛋白则被 H3K36 甲基化标记，以防止基因内部的错误起始。在哺乳动物细胞中测得的延伸速率约为每分钟 1–4 kb，基因之间以及沿基因都有变化。

::: example 一个长基因要花多长时间？ {#ex-long-gene}
人抗肌萎缩蛋白基因（*DMD*）跨约 2.4 Mb（Alberts，第 7 版，表 4-1）；其 mRNA 约 14 kb。(a) 以 3 kb min⁻¹ 的延伸速率，一轮转录需要多久？(b) 以 2 kb min⁻¹ 呢？(c) 转录出的 RNA 有多大比例最终进入 mRNA？
::: solution
(a) $2.4\times10^6/3000 = 800$ min，即 13.3 h。

(b) $2.4\times10^6/2000 = 1200$ min，即 20 h。坦尼森（Christopher Tennyson）、克拉穆特（Henry Klamut）与沃顿（Ronald Worton）1995 年在人肌肉细胞中的测量约为 16 h，在此范围内。一个转录本因此可能占用大半个细胞周期才能完成，这正是超长基因容易与复制叉相撞的原因之一。

(c) $14/2400 = 0.6\ \%$。转录本的 99 % 以上是内含子，经剪接被除去（[[molecular-biology/rna-processing]]）。
:::
:::

Pol II 的终止与 mRNA 的 3′ 加工偶联。当聚合酶转录出**多聚腺苷酸化信号**（`AAUAAA` 及下游一个 G/U 富集元件）时，结合在 CTD 上的切割与多聚腺苷酸化机器切开 RNA。上游片段成为 mRNA。仍连在聚合酶上的下游片段没有帽，被核酸外切酶 **Xrn2** 按 5′→3′ 降解。在**鱼雷模型**中，Xrn2 追上聚合酶并把它赶下模板，通常在下游几 kb 处。聚合酶读过该信号时的构象改变（**别构模型**）也有贡献，现在认为两者共同起作用。Pol I 在被终止蛋白结合的特定终止序列处终止。Pol III 像细菌的内在终止子一样，在编码链的一串 T 残基处终止，但不需要发夹。

### Pol I 与 Pol III 启动子

Pol I 只转录 rRNA 基因，它们在核仁组织区以数百个串联拷贝存在。它的启动子由起始位点处的核心元件和上游控制元件组成，被因子 UBF 与 SL1（其中含 TBP）结合。Pol III 启动子有三种类型。1 型（5S rRNA 基因）与 2 型（tRNA 基因）的**内部启动子**位于转录区内。5S 基因中这是被 TFIIIA 结合的内部控制区；tRNA 基因中这是被 TFIIIC 结合的 A 盒与 B 盒。TFIIIC 随后把含 TBP 的 TFIIIB 安放到起始位点上游，为聚合酶定位。3 型启动子（U6 snRNA）在基因上游，带 TATA 盒。布朗（Donald Brown）实验室 1980 年在非洲爪蟾（*Xenopus*）的 5S 基因中发现内部启动子：逐步缺失越来越大的片段，发现必需区段位于基因内部。

::: example 转录本中的错误 {#ex-rna-errors}
取 RNA 聚合酶 II 的错误率为每个核苷酸 $10^{-5}$（体内测量得到的数量级数字）。(a) 长 1500 个核苷酸的 mRNA 中有多大比例至少含有一个错误？(b) 若错误率为 $10^{-4}$ 呢？(c) 为什么细胞能容忍比 DNA 复制高十万倍的错误率？
::: solution
(a) $1 - (1 - 10^{-5})^{1500} = 0.015$：约 1.5 % 的转录本带有一个错误。

(b) $1 - (1 - 10^{-4})^{1500} = 0.139$：约 14 %。

(c) mRNA 中的一个错误只影响它在被降解前所合成的少数几个蛋白质分子，而同一基因的其他转录本是正确的。DNA 中的错误则会遗传给每一个子代细胞和由该基因转录的每一条 RNA。RNA 的错误还被高得多的翻译错误率（每个密码子约 $10^{-4}$，[[molecular-biology/translation]]）所稀释。
:::
:::

::: application 靶向转录的药物与毒素
抗生素**利福平**结合细菌 RNA 聚合酶的 β 亚基（在 RNA 出口通道中），阻止延伸超过 2–3 个核苷酸。它不影响真核聚合酶，所以具有选择性。耐药性来自 *rpoB* 基因中改变结合袋的突变，这些突变是细菌遗传学中研究最多的突变之一。**放线菌素 D** 插入 DNA 之间，阻断一切聚合酶。它在实验室中用来终止转录、测定 mRNA 半衰期。**α-鹅膏蕈碱**在活性部位附近结合 Pol II，阻断易位；这就是死亡帽菇如此危险的原因——摄入毒素的肝细胞会停止制造 mRNA。这些药物的临床应用见医学图谱（[/learn/medicine/](/learn/medicine/)）。
:::

::: history
雅各布（François Jacob）与莫诺（Jacques Monod）1961 年提出了一种不稳定的信使，同年布伦纳、雅各布与梅塞尔森（Matthew Meselson），以及格罗、吉尔伯特及同事证实了它。韦斯与格拉德斯通（1959）、胡维茨与史蒂文斯（1960）已发现依赖 DNA 的 RNA 聚合酶。伯吉斯、特拉弗斯及同事 1969 年发现了 σ；同年罗德尔与拉特分离出三种真核核内聚合酶，米勒与比蒂拍下了正在转录的 rRNA 基因。普里布诺 1975 年描述了 −10 元件。布朗组 1980 年发现 Pol III 的内部启动子，罗德尔组自 1980 年起着手界定通用转录因子。克拉默、布什内尔与罗杰·科恩伯格 2001 年报道了酵母 RNA 聚合酶 II 的结构。
:::

::: summary
- RNA 聚合酶以按 3′→5′ 读取的 DNA 为模板，不经引物合成 5′→3′ 的 RNA。基因序列按编码链书写；位置从起始位点的 $+1$ 起编号。
- 细菌聚合酶核心酶（α₂ββ′ω）需要 σ 才能在启动子起始。σ⁷⁰ 启动子在 −35 处为 `TTGACA`、−10 处为 `TATAAT`，相隔约 17 bp；替代 σ 因子识别别的启动子。
- 起始经过闭合复合体、开放复合体（约 13 bp 熔解、不需 ATP）、伴随挤压的流产起始，最后是启动子逃逸。启动子强度综合了亲和力（$K_B$）与异构化（$k_f$）：$v = k_f[R]/([R] + 1/K_B)$。
- 延伸具有持续合成能力（细菌中约 50 nt s⁻¹），伴随停顿与回退。在细菌中它与翻译偶联。
- 内在终止子是 G·C 富集发夹加一条 T 串。Rho 是一种 RNA 解旋酶，在未经翻译的 RNA 上终止。
- 真核生物有 Pol I（rRNA）、Pol II（mRNA、大多数 snRNA、miRNA 前体）与 Pol III（tRNA、5S rRNA、U6），以对 α-鹅膏蕈碱的敏感性区分。Pol II 的 CTD（`YSPTSPS` 重复）在起始时于 Ser5 磷酸化、延伸时于 Ser2 磷酸化，协调 RNA 加工。
- Pol II 前起始复合体在核心启动子（TATA、Inr、DPE；有 TATA 的是少数）上组装，需要 TFIID（TBP 使 DNA 弯曲约 80°）、TFIIA、B、F、E 与 H（后者用 ATP 熔解 DNA 并磷酸化 CTD）。体内还需要 Mediator 与激活蛋白。
- 启动子近端暂停及其由 P-TEFb 介导的释放是一个主要控制点。延伸约 1–4 kb min⁻¹。终止与多聚腺苷酸化偶联（鱼雷模型与别构模型）。
:::

一条模板链读作 `3'-TACCGATTA-5'`。给出 RNA 与编码链，均按 5′→3′。

RNA：`5'-AUGGCUAAU-3'`。编码链：`5'-ATGGCTAAT-3'`。

::: exercise 启动子打分 {level=1 check="9"}
用 Python 清单中的打分规则（与 `TTGACA` 和 `TATAAT` 每个匹配碱基一分，间隔区每偏离 17 bp 一个碱基对扣一分），给一个 −35 为 `TTGATA`、间隔区 16 bp、−10 为 `TAAAAT` 的启动子打分。
::: solution
`TTGATA` 与 `TTGACA` 在 6 个位置中匹配 5 个（只有第五位不同），`TAAAAT` 与 `TATAAT` 匹配 5 个（只有第三位不同）。间隔区罚分为 $|16 - 17| = 1$，所以得分为 $5 + 5 - 1 = 9$，介于清单中"弱"与"强"两个例子之间。
:::

::: exercise 起始频率 {level=1 check="120"}
一个启动子平均每 0.5 s 起始一次。它每分钟起始多少个转录本？
::: solution
$60/0.5 = 120$ 个每分钟。
:::

::: exercise 启动子的占据 {level=2 check="0.29"}
用 [[#eq-mcclure]]，取 $1/K_B = 250$ nM、游离全酶为 100 nM，启动子有多大时间比例处于闭合复合体状态（两位小数）？
::: solution
$\theta = 100/(100 + 250) = 0.286 \approx 0.29$。
:::

::: exercise α-鹅膏蕈碱与三种聚合酶 {level=2}
将细胞核与标记核苷酸一起孵育，分别不加毒素、加 1 μg mL⁻¹ α-鹅膏蕈碱、加 300 μg mL⁻¹ α-鹅膏蕈碱。掺入 RNA 的量为对照的 100 %、55 % 与 30 %。(a) 核内 RNA 合成中三种聚合酶各占多少？(b) 预言每种情况下会缺少哪些 RNA 种类。
::: solution
(a) 低浓度只抑制 Pol II，所以 Pol II 占 $100 - 55 = 45\ \%$。高浓度还抑制 Pol III，它占 $55 - 30 = 25\ \%$。抗药的其余 30 % 是 Pol I。（数字为示意；在生长细胞中，Pol I 通常占 RNA 合成总量的很大份额，因为 rRNA 如此丰富。）(b) 1 μg mL⁻¹ 时，pre-mRNA 与 Pol II 依赖的 snRNA 合成停止；300 μg mL⁻¹ 时，tRNA 与 5S rRNA 合成也停止；45S 前体 rRNA 合成在两种浓度下都继续。
:::
:::

::: exercise 背景中的削弱启动子突变 {level=2}
一个突变使某启动子的 −10 元件由 `TATAAT` 变为 `TATGAT`。体内转录下降十倍。体外闭合复合体的结合常数不变，但异构化速率下降十倍。(a) 用起始的各个步骤解释这一结果。(b) 为什么预期 −10 突变尤其影响异构化？
::: solution
(a) 突变不影响全酶的结合（$K_B$ 不变），但使 DNA 的打开变慢（$k_f$ 降低），所以开放复合体的形成速率、进而转录，按同一比例下降。(b) −10 元件正是 DNA 熔解开始的地方：σ 区 2 在 −10 元件的非模板链碱基翻出时将其俘获，尤其是保守的 −11 位 A 与 −7 位 T。−10 元件中的取代会干扰这种链俘获，而链俘获是异构化的一部分；−35 元件则主要贡献于最初结合。
:::
:::

::: exercise 转录与复制的冲突 {level=3}
在大肠杆菌中，高表达基因（包括 rRNA 操纵子）的取向大多是沿复制叉移动的方向转录。(a) 为什么复制叉与 RNA 聚合酶的正面对撞可能有害？(b) 用 [[molecular-biology/dna-structure#prop-topology]] 解释，当复制叉与聚合酶迎面相向而行时，两者之间的 DNA 超螺旋会发生什么。(c) 预言把染色体中某个 rRNA 操纵子倒位的效果。
::: solution
(a) 以约 1000 nt s⁻¹ 移动的复制体要么从后方追上、要么迎面遇上以约 50–90 nt s⁻¹ 移动的 RNA 聚合酶。同向相遇可以由复制体取代或绕过聚合酶解决；正面相遇则更严重地使复制叉停顿，而停滞的叉可能断裂，引起重组、突变与缺失。

(b) 两台机器都解开 DNA，并把正超螺旋推到自己前方。迎面相向而行时，彼此都在不断缩小的中间区域中制造正超螺旋，使它越来越过旋、越来越抗拒继续解旋；拓扑异构酶（促旋酶）必须迅速除去这些超螺旋。同向而行时，聚合酶后方的负超螺旋部分抵消叉前方的正超螺旋。

(c) 把 rRNA 操纵子倒位成沿复制迎面转录，会拖慢穿过它的叉，增加其附近叉停顿与重组的频率，并降低生长速度，特别是在 rRNA 转录旺盛的丰富培养基中。这类实验（在大肠杆菌与枯草芽孢杆菌中）已被完成，显示的正是这些效应，支持细菌染色体中的基因取向已被塑造以避免正面冲突的选择观点。
:::
:::

::: exercise 解读暂停数据 {level=3}
果蝇细胞中占位 Pol II 的全基因组图谱显示，某热激基因起始位点下游 30–50 nt 处有一个锐峰，基因内部几乎没有信号。热激两分钟后，信号已深入基因内部 5 kb；10 分钟后整条 10 kb 的基因都被覆盖。(a) 热激之前该基因处于什么状态？(b) 估算延伸速率。(c) 热激前加入一种抑制 CDK9 的药物。预言结果。
::: solution
