每次细胞分裂都始于一次基因组的复制，而且这次复制必须几乎完美。一个人细胞在几小时内复制 $6.2\times10^9$ 个碱基对，平均留下的未纠正错误不足一个。大肠杆菌在四十分钟内复制它的 460 万个碱基对，每个复制叉每秒掺入一千个核苷酸。这两种细胞都从确定的位置起始复制，确保基因组的每一部分只被复制恰好一次，并复制完成染色体的末端。执行这一切的蛋白质——**复制体**——是生物学中最快、最精确的机器之一。

dNTP 加成的化学、聚合酶的两种金属离子机制，以及链只能按 5′→3′ 方向延伸的原因，在化学图谱（[核酸、复制](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)）中讲解。本章采取生物学家的视角。我们先看证明 DNA 如何被复制的那个实验，然后逐个蛋白质地搭建复制叉，在细菌与真核生物中跟随它从起点走到终点，最后讨论线性染色体额外带来的两个问题：每个周期只许可每个起点一次，以及复制染色体的末端。

## 半保留复制

沃森与克里克在 1953 年那篇论文的结尾写道，他们提出的特异配对"立刻提示了一种可能的复制机制"。如果两条链分开、各自充当模板，那么每个子代分子都含一条旧链与一条新链：复制是**半保留**的。当年还认真考虑过另外两种可能。**全保留**复制中，亲代双链保持完整，另外整个造出一条全新的双链。**弥散**复制中，新旧 DNA 在每个子代分子的两条链上相互穿插——马克斯·德尔布吕克（Max Delbrück）曾提出这一模型，以回避长双螺旋解旋的困难。

加州理工学院的梅塞尔森（Matthew Meselson）与斯塔尔（Franklin Stahl）在 1958 年区分了这三种可能。他们让大肠杆菌在多代培养中以 $^{15}\mathrm{NH_4Cl}$ 为唯一氮源，使全部 DNA 都含重同位素，然后把细胞转移到 $^{14}\mathrm{N}$ 培养基中，间隔取样。提取 DNA，在浓氯化铯溶液中离心至平衡——氯化铯在离心场中形成密度梯度。每种 DNA 停在浮力密度与溶液密度相等之处，条带用紫外吸收照相记录。

::: proposition 三种模型的预言 {#prop-meselson-stahl}
设全重 DNA 的浮力密度为 $\rho_H$，全轻 DNA 为 $\rho_L$。在梅塞尔森与斯塔尔的实验中 $\rho_L = 1.710\ \mathrm{g\,cm^{-3}}$，$\rho_H - \rho_L = 0.014\ \mathrm{g\,cm^{-3}}$。在轻培养基中生长 $n$ 代后：
1. **半保留**：亲代链从不离开它们所进入的杂合双链。比例为 $2^{1-n}$ 的 DNA 是杂合的，密度为 $(\rho_H+\rho_L)/2 = 1.717\ \mathrm{g\,cm^{-3}}$，其余是轻的。$n \ge 1$ 时不再有重 DNA。
2. **全保留**：比例为 $2^{-n}$ 的 DNA 是全重的，其余全是轻的。永远不会出现杂合 DNA。
3. **弥散**：所有分子的组成相同，所以只有一条带，位于 $\rho_L + (\rho_H - \rho_L)\,2^{-n}$，随代数逐渐向轻的位置移动。

在三种模型中，**质量加权平均**密度都相同，即 $\rho_L + (\rho_H - \rho_L)2^{-n}$，因为重氮的总量固定，而 DNA 总量每代加倍。模型之间的差别仅在于重物质如何在分子之间分配。
:::

::: proof
数单链。开始时共有 $S$ 条重链。$n$ 代后共有 $2^n S$ 条链，其中 $S$ 条是重的。半保留复制下，每条重链从第一轮起就与一条轻链配对，所以在总共 $2^{n-1}S$ 个双链中有 $S$ 个杂合双链，比例为 $2^{1-n}$。全保留复制下，原来的 $S/2$ 个重双链完好地保留在 $2^{n-1}S$ 个双链之中，比例为 $2^{-n}$。弥散复制下，每条链都含相同比例 $2^{-n}$ 的重核苷酸。每种情形下重氮的平均比例都是 $2^{-n}$，而浮力密度与它成线性关系。
:::

命题末尾的那一点正是使实验具有决定性的地方。测量还剩多少重氮无法分辨三种模型；按密度把**分子**分开才可以。梅塞尔森与斯塔尔发现，一代后只有一条杂合密度的带，这就排除了全保留复制。约两代后，杂合 DNA 与轻 DNA 的量相等。弥散复制本应预言只有一条居中的带，所以那条带的缺失排除了这一模型。加热杂合 DNA 使它分成重组分与轻组分，表明杂合分子的两个"亚基"各是单一密度的完整链。（它们是否为一个双螺旋的两条互补链，该实验本身并未证明——它鉴定的是密度亚基；后来的实验证实了这一点。）

```python
# Meselson-Stahl：在两种模型下追踪每一个双链分子经过三代
from collections import Counter

def semiconservative(duplexes):
    # 每个双链解开；每条旧链获得一个新的轻链伙伴 'L'
    return [(s, 'L') for d in duplexes for s in d]

def conservative(duplexes):
    # 亲代双链保持完整；旁边另造一个全新的轻双链
    return [x for d in duplexes for x in (d, ('L', 'L'))]

def density(d, light=1.710, heavy=1.724):          # g/cm^3，Meselson & Stahl 1958
    return light + (heavy - light) * d.count('H') / 2

for model in (semiconservative, conservative):
    dna = [('H', 'H')]                              # 一个完全被 15N 标记的双链分子
    print(model.__name__)
    for g in range(1, 4):
        dna = model(dna)
        bands = Counter(round(density(d), 3) for d in dna)
        print(' gen', g, {k: f"{v / len(dna):.3f}" for k, v in sorted(bands.items())})
```

运行后打印每条带中 DNA 的比例（键为密度，单位 g cm⁻³）：

```

 gen 2 {1.71: '0.500', 1.717: '0.500'}
 gen 3 {1.71: '0.750', 1.717: '0.250'}
conservative
 gen 1 {1.71: '0.500', 1.724: '0.500'}
 gen 2 {1.71: '0.750', 1.724: '0.250'}
 gen 3 {1.71: '0.875', 1.724: '0.125'}
```

::: example 定量解读梅塞尔森–斯塔尔的胶 {#ex-meselson}
梅塞尔森与斯塔尔报告的各样品，其取样时间用转移后经过的世代数表示（由培养物的生长测得）：0、0.3、0.7、1.0、1.1、1.5、1.9、2.5、3.0 与 4.1 代。假设为照片做的密度扫描给出杂合带中的 DNA 比例为：1.0 代时 1.00，1.9 代时 0.54，4.1 代时 0.12。(a) 与半保留模型的预言比较。(b) 全保留模型在 1.9 代时的预言是什么？(c) 弥散模型的带在 1.9 代时会位于何处？(d) 培养物是非同步生长的，细胞随时都在复制。为什么 $n \ge 1$ 之后，公式 $2^{1-n}$ 对非整数的 $n$ 依然适用？
::: solution
(a) 半保留的预言是 $2^{1-n}$：$n = 1.0$ 时 $2^{0} = 1.00$，$n = 1.9$ 时 $2^{-0.9} = 0.536$，$n = 4.1$ 时 $2^{-3.1} = 0.117$。数据与之高度吻合。（本例题的数据是与已发表照片相符的示意值，不是梅塞尔森与斯塔尔的原始数字。）

(b) 全保留复制会预言 1.9 代时有 $2^{-1.9} = 0.27$ 的 DNA 位于密度 1.724 的重带、0.73 是轻的，根本没有任何杂合带。

(c) $1.710 + 0.014\times2^{-1.9} = 1.710 + 0.0038 = 1.714\ \mathrm{g\,cm^{-3}}$：一条介于杂合与轻之间的带。

(d) 在指数生长的培养物中，DNA 总量按 $2^n$ 连续增加，而旧链的数目固定。一旦每条亲代链都至少被复制过一次（$n \approx 1$ 时实质上已成立），每条旧链就都位于一个杂合双链中，于是杂合 DNA 是一个恒定的质量（等于亲代链总质量的两倍），其比例为 $2 \cdot 2^{-n} = 2^{1-n}$，与 $n$ 是否为整数无关。$n = 1$ 之前，部分亲代双链尚未复制，重 DNA 与杂合 DNA 共存——梅塞尔森与斯塔尔在 0.3 与 0.7 代正是这样观察到的。
:::

半保留复制很快也在真核生物中得到证明。J. 赫伯特·泰勒（J. Herbert Taylor）、菲利普·伍兹（Philip Woods）与沃尔特·休斯（Walter Hughes）（1957）用氚标记的胸苷标记蚕豆（*Vicia faba*）根尖染色体，用放射自显影追踪标记：在标记中经过一轮后两条姐妹染色单体都被标记；再在无标记培养基中经过一轮后，每对中只有一条被标记。1963 年，约翰·凯恩斯（John Cairns）用氚标记胸苷标记大肠杆菌 DNA，铺展完整染色体并用放射自显影拍照。他看到一个环状分子已部分复制成 θ 形——这是正在复制的染色体的第一幅直接图像。

## 复制叉

在**复制叉**处，亲代双链被解开，两条链都被复制。由于两条链反向平行而聚合酶只能延伸 3′ 端，一条子链——**前导链**——朝叉连续生长，另一条——**滞后链**——则以离开叉方向生长的**冈崎片段**不连续地合成。冈崎令治（Reiji Okazaki）与冈崎恒子（Tsuneko Okazaki）及同事 1968 年发现这些片段：他们让大肠杆菌（有的经 T4 噬菌体感染，有的没有）脉冲标记几秒钟，大部分标记最先出现在 1000–2000 个核苷酸长的短片段中，这些片段随后被连接成长 DNA。真核生物的冈崎片段较短，为 100–200 个核苷酸，大致相当于一个核小体重复长度。

::: definition 复制叉的核心蛋白质 {#def-fork}
- **解旋酶**利用 ATP 解开亲代双链。复制型解旋酶是由六个亚基组成、套在一条链上并沿其移动的环：细菌中的 DnaB 沿滞后链模板按 5′→3′ 方向移动，真核生物中的 CMG 复合体（Cdc45–MCM2-7–GINS）沿前导链模板按 3′→5′ 方向移动。
- **单链 DNA 结合蛋白**（细菌中为 SSB，真核生物中为 RPA）覆盖暴露的单链，防止其形成二级结构并保护它们。
- **引发酶**合成短的 RNA 引物——细菌中约 10–12 个核苷酸（DnaG）——因为 DNA 聚合酶不能从头起始链。真核生物中，聚合酶 α–引发酶复合体合成约 10 个核苷酸的 RNA 引物，再用约 20 个核苷酸的 DNA 将其延伸。
- **复制型 DNA 聚合酶**以高速度、高忠实性与高持续合成能力延伸引物：大肠杆菌中为 DNA 聚合酶 III；真核生物中前导链为聚合酶 ε，滞后链为聚合酶 δ。
- **滑动夹**套在 DNA 上，把聚合酶拴在 DNA 上：细菌中为二聚体的 **β 夹**，真核生物中为三聚体的 PCNA（增殖细胞核抗原）。**夹装载器**（细菌中的 γ 复合体，真核生物中的 RFC）利用 ATP 打开环，把它装载到引物-模板连接处。
- 引物被去除并被替换：细菌中由 DNA 聚合酶 I（依靠其 5′→3′ 外切酶活性）与 RNase H 完成；真核生物中由聚合酶 δ 的链置换配合瓣状核酸内切酶 FEN1 完成。**DNA 连接酶**封闭切口（细菌中依赖 NAD⁺，真核生物中依赖 ATP）。
- **拓扑异构酶**除去叉前方产生的正超螺旋（[[molecular-biology/dna-structure#prop-topology]]）。
:::

阿瑟·科恩伯格（Arthur Kornberg）1956 年在大肠杆菌提取物中发现 DNA 聚合酶 I，证明在试管中利用脱氧核苷三磷酸与模板就能合成 DNA。Pol I 最终被证明不是主要的复制酶。1969 年，保拉·德卢西亚（Paula DeLucia）与约翰·凯恩斯分离到一个突变体 *polA1*，它几乎没有 Pol I 活性却仍能复制其染色体。不过它对 DNA 损伤敏感，而对真正复制酶的寻找导致了 Pol III。

**持续合成能力**（processivity）——聚合酶在脱落前掺入的核苷酸数目——是速度的关键。单独的 Pol III 核心酶每次结合只加约十个核苷酸。被 β 夹扣住后，它能连续结合并合成几万个核苷酸，足以合成整条前导链。脱落的聚合酶必须靠扩散重新找到 3′ 端，这很慢，所以夹子把一个行动迟缓的酶变成了快速的酶。在滞后链上，每个冈崎片段合成结束时都必须释放夹子，并在下一个引物上装载一个新的，夹装载器每隔一两秒就要完成一次这样的装载。

在大肠杆菌中，**全酶**的两三个 Pol III 核心酶由夹装载器的 τ 亚基彼此连接，而夹装载器又与解旋酶结合。因此前导链与滞后链的合成耦联在一个复合体之中。要使滞后链的合成与前导链朝同一个总体方向，滞后链模板被认为被环出成环，这样聚合酶在它上面按 5′→3′ 方向移动，而整个复制体随叉前进。这就是布鲁斯·艾伯茨（Bruce Alberts）及同事（1980 年代）的**长号模型**——因随每个片段生长又被释放的那个环而得名。2017 年以来的单分子实验表明，这种耦联比这一图景暗示的更松散。两个聚合酶以变化的速度移动、各自独立地停顿，而且聚合酶之间频繁交换，所以复制体最好被视为一个动态的装配体，而非一台刚性的机器。

::: warning "滞后链是按 3′→5′ 方向复制的"
每种 DNA 聚合酶都把核苷酸只加到 3′-OH 上，所以每条新链——无论前导链还是滞后链——都按 5′→3′ 方向生长，每条模板都被按 3′→5′ 方向读取。滞后链的特别之处在于每个片段都*离开*叉生长，所以必须在新的引物上反复重新启动合成。任何生物中都没有能按 3′→5′ 方向合成 DNA 的聚合酶；化学原因见化学图谱：每根键所需的能量来自即将掺入的核苷三磷酸，若朝另一方向生长，这份能量就只能在链的末端白白丢失。
:::

::: example 每个基因组的冈崎片段数 {#ex-okazaki}
(a) 估计大肠杆菌每轮复制产生多少个冈崎片段，取片段平均长 1500 个核苷酸。(b) 对一个二倍体人细胞重复计算，片段长 150 个核苷酸。(c) 大肠杆菌中每个叉的移动速度约为 1000 nt s⁻¹。每个叉每隔多久必须合成一个新的滞后链引物？
::: solution
(a) 新合成的 DNA 有一半是滞后链。每轮复制细胞合成 $2\times4.64\times10^6$ 个核苷酸的新 DNA，其中 $4.64\times10^6$ 个在滞后链上，所以有 $4.64\times10^6/1500 \approx 3.1\times10^3$ 个片段。

(b) 一个二倍体人细胞合成 $2\times6.2\times10^9$ 个新核苷酸，其中 $6.2\times10^9$ 个在滞后链上，得 $6.2\times10^9/150 \approx 4\times10^7$ 个片段。每个片段都需要一个引物、切除引物、一个新的 PCNA 夹和一次连接，所以每个 S 期都要发生数千万次这样的步骤。

(c) 1500 个核苷酸的片段需要 $1500/1000 = 1.5$ s 合成完，所以引发酶在每个叉处大约每隔 1.5 s 就要工作一次。
:::
:::

## 起点、终点与细菌细胞周期

复制始于**复制起点**——起始蛋白质在那里打开双链并装载解旋酶。大肠杆菌染色体只有一个起点，***oriC***，长约 245 bp。它含有几个 9 bp 的起始蛋白质 **DnaA** 结合位点，以及一个由三个 13 聚体重复构成的 A·T 富集区，易于解链。结合 ATP 的 DnaA 在起点上形成一根丝状体，使 DNA 受力并打开 A·T 富集区，负超螺旋对此有帮助。装载器 DnaC 随后把两个 DnaB 解旋酶环分别放到两条单链上，各朝一个方向，引发酶 DnaG 起始最初的引物。两个叉以相反方向离开 *oriC*，所以复制是**双向**的；它们在大约正对起点处的一片终止区相遇。在那里，结合在 ***ter*** 位点上的 **Tus** 蛋白质充当单向闸门：叉可以从一侧穿过 Tus-*ter* 复合体，从另一侧则被挡住，从而把叉困在终止区。拓扑异构酶 IV 解开两条子代染色体。

起始被若干机制限制为每个细胞周期一次。刚复制过的 *oriC* 是**半甲基化**的：Dam 甲基化酶甲基化 `GATC` 序列中的腺嘌呤，而 *oriC* 中有很多这样的位点，但复制刚结束时只有旧链被甲基化。SeqA 蛋白质结合半甲基化的 *oriC* 并把它扣留约三分之一个细胞周期。与此同时，DnaA-ATP 被转化为无活性的 DnaA-ADP，部分通过与 β 夹偶联的机制完成。

::: proposition 生长群体中的起点/终点比 {#prop-ori-ter}
设复制完全条染色体所需时间为 $C$，指数生长的非同步群体的倍增时间为 $\tau$。则靠近起点的序列拷贝数与靠近终点的序列拷贝数之比为
$$
\frac{\text{ori}}{\text{ter}} = 2^{C/\tau}.
$$ {#eq-ori-ter}
位于从起点到终点路径上分数距离 $m$ 处的基因（*oriC* 处 $m = 0$，*ter* 处 $m = 1$），相对于终点的相对拷贝数为 $2^{(1-m)C/\tau}$。这里假定叉速恒定且群体处于稳定的指数生长。
:::

::: proof
靠近起点的序列在起始时即被复制，靠近终点的序列则要到 $C$ 之后叉到达时才被复制。在稳定指数生长中，群体中任何序列的拷贝数按 $2^{t/\tau}$ 增长，所以在某一时刻复制终点所产生的那些拷贝，是在 $C$ 之前起始的，而当时群体（从而起点的数目）比现在小 $2^{C/\tau}$ 倍。因此起点与终点之比为 $2^{C/\tau}$。位于分数距离 $m$ 处的基因在起始后 $mC$ 时被到达，所以它的拷贝落后起点 $2^{mC/\tau}$、领先终点 $2^{(1-m)C/\tau}$。
:::

::: example 多叉复制 {#ex-multifork}
37 °C 的大肠杆菌中，$C \approx 40$ min，从复制结束到分裂的时间 $D$ 约为 20 min（斯蒂芬·库珀（Stephen Cooper）与查尔斯·黑姆斯特勒（Charles Helmstetter），1968）。(a) 每 20 min 倍增、以及每 60 min 倍增的培养物中，ori/ter 比各是多少？(b) 若复制需要 40 min，细胞怎么可能每 20 min 分裂一次？(c) 今天你会如何测量这一比值？
::: solution
(a) 由 [[#eq-ori-ter]]：$\tau = 20$ min 时 $2^{40/20} = 4$；$\tau = 60$ min 时 $2^{40/60} = 1.59$。

(b) 一条染色体的复制必须在其所服务的那次分裂之前 $C + D = 60$ min 就起始。若细胞每 20 min 分裂一次，起始就必须在三代之前开始——此时上一轮的复制尚未结束。因此快速生长的细胞中，染色体上同时存在相差几代的复制叉（**多叉复制**），一个起点每细胞可有四个或八个拷贝，而终点只有一或两个。

(c) 对培养物的总 DNA 测序，把读段深度沿染色体作图。覆盖度从 *oriC* 到 *ter* 指数下降，两端的比值给出 $2^{C/\tau}$。微生物组研究正用这一方法在不培养的情况下估计样品中细菌的生长速度。起点附近的基因——如大肠杆菌的许多核糖体 RNA 操纵子——在快速生长中获得剂量增加，这有助于细胞在最需要的时候最快制造核糖体。
:::
:::

## 真核染色体的复制

真核染色体长而为线性，从多个起点复制。两个事实确定了数量级。真核生物的叉慢，哺乳动物细胞中约每分钟 1–3 kb（大约每秒 20–50 个核苷酸），推测是因为它们还必须拆卸并重新装配核小体。而人细胞的 S 期约持续 8 小时。

::: example 一个人细胞需要多少个起点？ {#ex-origins}
一个二倍体人细胞在 8 h 的 S 期中复制 $6.2\times10^9$ bp，叉速为 50 nt s⁻¹。(a) 若全部起点都在 S 期一开始就起始、每个叉都连续运行直到与另一个相遇，双向起点的最小数目是多少？(b) 测量表明，每个人类 S 期约有 30000–50000 个起点起始（综述如 Fragkos 等，2015）。为什么实际数目远大于最小值？
::: solution
(a) 每个起点产生两个叉，8 h 内共复制 $2\times50\times(8\times3600) = 2.88\times10^6$ bp。最小数目为 $6.2\times10^9/2.88\times10^6 \approx 2.2\times10^3$ 个起点。

(b) 起点并非同时起始：基因组的不同区域在特征性的时间复制，常染色质早、异染色质晚，所以许多叉只运行 S 期的一部分时间。叉还会在障碍处停顿、停滞，如紧密结合的蛋白质、转录中的聚合酶与受损碱基。大量被许可的起点冗余存在——其中许多保持**休眠**，只在邻近的叉停滞时才启用——使整个过程具有稳健性：两个停滞的叉之间未复制的空隙，可以由二者之间的一个休眠起点起始来补救。
:::
:::

在酿酒酵母中，起点是有定义的 DNA 序列，即**自主复制序列**（ARS），各含一个 11 bp 的核心共有序列，被**起点识别复合体**（ORC，六个亚基 Orc1–6）识别；基因组约有 400 个这样的位点。在动物中，起点不由共有序列定义。ORC 结合 DNA 时几乎没有序列偏好，起点由染色质环境决定：开放的、缺少核小体的区域，常在启动子与富 G 序列附近。

::: definition 起点的许可与起始 {#def-licensing}
真核复制分两步、彼此分开地进行。
1. **许可**（M 期末与 G1 期）：ORC 与蛋白质 Cdc6、Cdt1 一起，把 MCM2-7 解旋酶核心作为无活性的**双六聚体**装载到起点 DNA 上，套在双链之外。被许可的起点载有**前复制复合体**。只有周期蛋白依赖性激酶（CDK）活性低时才可能装载。
2. **起始**（S 期）：Dbf4 依赖性激酶 DDK（Cdc7–Dbf4）磷酸化 MCM，S 期 CDK 磷酸化更多因子，募集 **Cdc45** 与 **GINS** 复合体。它们与 MCM 一起构成有活性的 **CMG 解旋酶**。双六聚体分成两个 CMG，各在一条链上，彼此穿过、朝相反方向移动。随后聚合酶 ε、δ 与 α–引发酶、PCNA 与 RFC 被募集。

因为解旋酶装载要求低 CDK 活性、而激活要求高 CDK 活性，所以一旦 S 期开始，任何起点都不能再次被许可。因此每个起点每个细胞周期至多起始一次。在后生动物中，蛋白质 **geminin**（从 S 期到有丝分裂抑制 Cdt1）提供了又一道屏障。
:::

装载与激活的分离——主要在 1990 年代以后于酿酒酵母中阐明（约翰·迪夫利（John Diffley）、布鲁斯·斯蒂尔曼（Bruce Stillman）、斯蒂芬·贝尔（Stephen Bell）等），2015 年用纯化的蛋白质体系重建（Yeeles 等）——是"DNA 每个细胞周期只复制一次"这一规则的分子基础。它受周期蛋白与 CDK 的调控，是 [[cell-biology/cell-cycle]] 细胞周期控制系统的一部分。许可出错时，片段会被重复复制，产生扩增与基因组不稳定性。

在每个叉的后面，染色质必须重建。亲代组蛋白由与复制体结合的分子伴侣传递给子代双链。每个子代大约得到一半旧组蛋白——连同它们的修饰——空缺的位置由新合成的组蛋白填补，由 **CAF-1** 装配；CAF-1 结合 PCNA。旧组蛋白随后充当模板来修饰新组蛋白，这是染色质状态遗传的核心问题（[[molecular-biology/eukaryotic-gene-regulation]]）。

## 忠实性

复制的忠实性分三个层次逐步建立，每一层次都把上一层次的精确度再乘上一个因子。

::: proposition DNA 复制的忠实性 {#prop-fidelity}
在大肠杆菌中，染色体复制的错误率是三个因子的乘积（Alberts 等，《Molecular Biology of the Cell》，表 5-1）：

| 步骤 | 剩余错误 |
|---|---|
| 聚合酶对核苷酸的选择（5′→3′ 聚合） | $10^5$ 中 1 |
| 3′→5′ 外切酶校对 | $10^2$ 中 1 |
| 链定向的错配修复 | $10^3$ 中 1 |
| **合计** | $10^{10}$ 中 1 |

这些因子相乘，因为每个阶段都对上一阶段留下的错误独立作用。大肠杆菌中测得的突变率与此相符：用全基因组测序做的突变累积实验给出每碱基对每代约 $2\times10^{-10}$（Lee 等，2012）。
:::

聚合酶的选择既依赖碱基对的几何形状，也依赖氢键。活性部位在即将掺入的核苷酸周围闭合，检查新生碱基对是否具有沃森-克里克配对的形状。错配的核苷酸会减慢闭合步骤与化学反应步骤，从而有时间解离。**校对**依赖第二个活性部位。错配的 3′ 末端是一个不好的引物，所以它会解链并被转移到 3′→5′ 外切酶位点（Pol III 的 ε 亚基；Pol δ 与 ε 的固有结构域），在那里被切掉。使外切酶失活的突变会大幅提高突变率。在大肠杆菌中，影响 ε 亚基的 *mutD*（*dnaQ*）诱变株使它上升好几个数量级。**错配修复**见 [[molecular-biology/dna-repair-recombination]]。RNA 引物本身的合成没有校对，这是它必须被除去并替换为 DNA 的原因之一。

::: example 每次分裂的错误数 {#ex-errors}
(a) 用 [[#prop-fidelity]] 的合计错误率，大肠杆菌基因组复制一次预计有多少个错误？(b) 二倍体人基因组复制一次呢？(c) 一个菌株缺少错配修复。答案如何变化？
::: solution
(a) $4.64\times10^6\times10^{-10} = 4.6\times10^{-4}$：大约每 2000 次分裂有一个细胞出错。

(b) $6.2\times10^9\times10^{-10} = 0.62$ 个错误每次分裂。（人复制的忠实性也在同一量级。）

(c) 没有错配修复时，错误率为 $10^{-5}\times10^{-2} = 10^{-7}$，高出千倍：大肠杆菌每次复制 0.46 个错误，人每次分裂约 620 个。带 *mutS* 或 *mutL* 突变的细菌可见到这种量级的诱体表型；人细胞中错配修复的丢失产生某些癌症中可见的全基因组范围的不稳定性。
:::
:::

## 线性染色体的末端

线性染色体有一个环状染色体没有的问题。当滞后链最末端最后一个引物被除去时，没有聚合酶能填补它留下的空缺，因为上游没有可延伸的 3′-OH。因此每轮复制都会使染色体缩短。詹姆斯·沃森（1972）与阿列克谢·奥洛夫尼科夫（Alexey Olovnikov，1971–73）描述了这一**末端复制问题**，奥洛夫尼科夫还把它与伦纳德·海弗里克（Leonard Hayflick，1961）的发现联系起来：正常成人二倍体纤维细胞在体外只能分裂有限的次数。

::: definition 端粒与端粒酶 {#def-telomerase}
**端粒**是线性真核染色体的末端：短而 G 富集重复序列的串联阵列——脊椎动物为 `TTAGGG`（四膜虫（*Tetrahymena*）为 `TTGGGG`，拟南芥（*Arabidopsis*）为 `TTTAGGG`）——人类中长达数千碱基对，末端是富含 G 链的一条单链 3′ 突出。**端粒酶**是一种核糖核蛋白逆转录酶，能延伸 3′ 突出端。其蛋白质亚基（TERT）以自身 RNA 亚基（TR，又称 TERC）中的一段短模板区为模板，逐个添加重复序列。互补链随后由聚合酶 α–引发酶补齐。端粒由一个蛋白质复合体结合——哺乳动物中为 **shelterin**（端粒保护复合体）——它把末端藏起来躲开 DNA 损伤应答，使末端不被当作双链断裂处理。
:::

伊丽莎白·布莱克本（Elizabeth Blackburn）与约瑟夫·加尔（Joseph Gall）（1978）在纤毛虫嗜热四膜虫（*Tetrahymena thermophila*）携带核糖体 RNA 基因的迷你染色体末端发现了端粒重复序列。杰克·绍斯塔克（Jack Szostak）与布莱克本（1982）证明，四膜虫端粒能稳定酵母中的线性质粒，并带上了它们自己的重复序列。卡罗尔·格雷德（Carol Greider）与布莱克本（1985）在四膜虫提取物中发现了端粒酶活性——一种向引物上添加 `TTGGGG` 重复序列的酶——并于 1989 年鉴定了它的 RNA 模板。三人分享了 2009 年诺贝尔生理学或医学奖。

::: example 数到端粒的极限 {#ex-telomere}
人的成纤维细胞端粒在没有端粒酶的体外培养中每次分裂约丢失 50–100 bp（Harley、Futcher 与 Greider，1990，测得约每次分裂 50 bp）。假设端粒起始长 10 kb，当最短的端粒缩短到约 5 kb 时细胞停止分裂。(a) 按每次分裂 50 bp 与 100 bp，各能分裂多少次？(b) 为什么缩短量大于一个 RNA 引物的长度？（这些起始长度与临界长度是示意值；真实数值因细胞类型与个体而异。）
::: solution
(a) $(10\,000 - 5000)/50 = 100$ 次分裂（每次 50 bp），$5000/100 = 50$ 次（每次 100 bp）。第二个数字与海弗里克观察到的 40–60 次群体倍增相当接近。

(b) 仅最后一个引物造成的损失只是每端一条链上约 10 个核苷酸。端粒缩短得多，是因为 C 富集链在复制后也被核酸酶**切除加工**（resection），以生成保护性端帽所需的 3′ 突出端；而且重复的端粒 DNA 中的氧化损伤与叉的问题会造成更多丢失。
:::
:::

端粒酶在生殖系、许多干细胞群体和大多数癌细胞中有活性——癌细胞通过重新表达 *TERT* 逃避分裂极限，少数肿瘤则通过基于重组的机制（端粒长度交替延长）逃避。大多数体细胞活性很低。小鼠端粒很长、许多组织中端粒酶活跃，所以"端粒时钟"并不是衰老的普适计时器。端粒生物学与人类健康和疾病的关系见医学图谱（[/learn/medicine/](/learn/medicine/)）。

::: quiz
一个酵母突变体缺少端粒酶的 RNA 亚基。许多代之后你预计什么结果？
- [ ] 第一个细胞周期立即死亡，因为染色体末端根本无法复制。
- [x] 数十代内端粒逐渐缩短，随后出现生长危机，少数幸存者靠重组延长端粒。
- [ ] 没有影响，因为酵母染色体是环状的。
- [ ] 端粒变长，因为端粒蛋白端帽不再受端粒酶限制。
::: solution
每次分裂只丢失一点端粒 DNA，所以细胞正常生长，直到端粒变得临界地短；然后细胞停滞（衰老）。维多利亚·伦德布拉德（Victoria Lundblad）与杰克·绍斯塔克（1989）在染色体为线性的酿酒酵母中描述了端粒酶亚基基因 *EST1* 突变体的这种"端粒持续缩短"（ever shorter telomeres）表型；删除 RNA 亚基基因 *TLC1* 时也会看到同样现象（米丽娅姆·辛格（Miriam Singer）与丹尼尔·戈特施林（Daniel Gottschling），1994）。会出现靠同源重组维持端粒的幸存者，与人某些癌症中的端粒长度交替延长类似。
:::
:::

::: application 实验室中的聚合酶
使聚合酶成为优秀复制酶的性质也使它们成为工具。水生栖热菌（*Thermus aquaticus*）的耐热聚合酶（Taq）是聚合酶链反应的基础，而带校对外切酶的酶（如 Pfu）用于需要精确的场合。逆转录病毒的逆转录酶把 RNA 复制成互补 DNA。桑格测序所用的荧光双脱氧核苷酸利用了聚合酶对 3′-OH 的需求，DNA 连接酶在克隆中连接片段。这些都在 [[molecular-biology/molecular-tools]] 中展开。
:::

::: history
詹姆斯·沃森与弗朗西斯·克里克 1953 年提出半保留复制。阿瑟·科恩伯格及同事 1956 年报告了大肠杆菌 DNA 聚合酶 I（1959 年诺贝尔生理学或医学奖，与塞韦罗·奥乔亚（Severo Ochoa）分享）。J. 赫伯特·泰勒、菲利普·伍兹与沃尔特·休斯 1957 年证明了蚕豆（*Vicia faba*）染色体的半保留分配，梅塞尔森与斯塔尔 1958 年发表 *The replication of DNA in* Escherichia coli（《大肠杆菌 DNA 的复制》）。约翰·凯恩斯 1963 年拍下了呈 θ 形复制中的大肠杆菌染色体。弗朗索瓦·雅各布、西德尼·布伦纳与弗朗索瓦·屈赞（François Cuzin）1963 年提出复制子模型，其中起始因子作用于复制子序列。冈崎令治及同事 1968 年描述了不连续合成的短片段，保拉·德卢西亚与约翰·凯恩斯 1969 年分离到 *polA1* 突变体，斯蒂芬·库珀与查尔斯·黑姆斯特勒 1968 年弄清了大肠杆菌细胞周期中复制的时间安排。伊丽莎白·布莱克本与约瑟夫·加尔 1978 年描述了端粒重复序列，卡罗尔·格雷德与布莱克本 1985 年发现了端粒酶。约瑟夫·耶尔斯（Joseph Yeeles）、约翰·迪夫利及同事 2015 年用纯化的酵母蛋白质重建了受调控的真核起点起始。
:::

::: summary
- 复制是半保留的。梅塞尔森与斯塔尔（1958）在一代后只看到杂合 DNA，两代后杂合与轻 DNA 等量；杂合比例按 $2^{1-n}$ 下降。三种模型预言的平均密度相同，所以按密度分辨分子才是关键。
- 在叉处，六聚体解旋酶解开 DNA，SSB 或 RPA 覆盖单链，引发酶合成 RNA 引物，被夹子结合的复制型聚合酶将其延伸。前导链连续合成；滞后链以冈崎片段合成（细菌中 1–2 kb，真核生物中 100–200 nt），经加工并被连接。
- 持续合成能力来自夹装载器装载的滑动夹（β 夹、PCNA）。细菌叉的移速约 1000 nt s⁻¹，真核叉约 1–3 kb min⁻¹。
- 大肠杆菌从 *oriC*（起始蛋白质 DnaA）双向复制，止于 Tus-*ter* 终止区。快速生长的细胞在上一轮结束前就起始新一轮，产生 $2^{C/\tau}$ 的 ori/ter 比。
- 真核生物使用大量起点：每个人类 S 期数万个。MCM 双六聚体在 G1 装载（许可，低 CDK），在 S 期作为 CMG 被激活（DDK 与 CDK），所以每个起点每个周期起始一次。
- 忠实性约为每次复制每 bp $10^{-10}$，是碱基选择（$10^{-5}$）、校对（$10^{-2}$）与错配修复（$10^{-3}$）的乘积。
- 线性染色体每次分裂都缩短（末端复制问题与末端加工）。端粒酶是一种自带 RNA 模板的逆转录酶，延伸端粒重复序列；shelterin 保护末端。
:::

## 练习

::: exercise 杂合比例 {level=1 check="0.125"}
在梅塞尔森–斯塔尔实验中，于 $^{14}$N 培养基中培养 4 代后，有多少比例的 DNA 位于杂合带？
::: solution
$2^{1-4} = 2^{-3} = 0.125$。其余 0.875 是轻的。
:::
:::

::: exercise 弥散带的密度 {level=1 check="1.7135"}
按弥散模型，在轻培养基中培养 2 代后，DNA 会在什么浮力密度处成带（g cm⁻³，保留四位小数）？设 $\rho_L = 1.710$，$\rho_H = 1.724$。
::: solution
$1.710 + 0.014\times2^{-2} = 1.710 + 0.0035 = 1.7135\ \mathrm{g\,cm^{-3}}$。
:::
:::

::: exercise 细菌染色体的复制时间 {level=1 check="45"}
一个细菌有一条 5.4 Mb 的环状染色体，由一个起点双向复制，叉速为 1000 nt s⁻¹。复制需要多长时间（分钟）？
::: solution
每个叉复制 $2.7\times10^6$ bp，需 $2.7\times10^6/1000 = 2700$ s，即 45 min。
:::
:::

::: exercise 热变性步骤说明了什么 {level=2}
一代之后，梅塞尔森与斯塔尔加热杂合 DNA，它分成了重与轻密度两个组分。(a) 这说明了什么？在弥散模型下又会显示什么？(b) 为什么该实验单凭自己无法证明这两个亚基就是沃森-克里克双螺旋的两条链？
::: solution
(a) 杂合分子由两个亚基组成，一个完全是重的、一个完全是轻的，所以亲代物质以完整的亚基形式被保留。弥散复制下每个亚基都会含新旧材料的混合物，变性后只会得到一条中等密度的带。(b) 该实验只按密度检测亚基；它们的大小与化学本质并未测定。1958 年的 DNA 被剪切成长度不明的片段，亚基原则上本可以是双链分子的配对体之类。亚基是单条多核苷酸链这一点，后来由物理研究以及把变性产物鉴定为单链 DNA 予以证实。
:::
:::

::: exercise 快速生长中的基因剂量 {level=2 check="2.83"}
一个 $C = 45$ min 的培养物每 30 min 倍增一次。(a) ori/ter 比是多少（保留两位小数）？(b) *oriC* 与 *ter* 中点处一个基因相对于 *ter* 处一个基因的拷贝数是多少？
::: solution
(a) 由 [[#eq-ori-ter]]，$2^{C/\tau} = 2^{45/30} = 2^{1.5} = 2.83$。

(b) 取 $m = 0.5$，$2^{(1-m)C/\tau} = 2^{0.75} = 1.68$。等价地说，它的拷贝数是起点的 $2^{-0.75} = 0.59$ 倍：剂量沿染色体的每一臂指数下降。
:::
:::

::: exercise 诱变株 {level=2}
三个大肠杆菌突变体的自发突变率升高：突变体 A 缺少 Pol III 的 3′→5′ 外切酶，突变体 B 缺少 MutS，突变体 C 缺少 Dam 甲基化酶。用 [[#prop-fidelity]] 估计 A 与 B 突变率上升的预期幅度，并解释为什么 C 也是诱变株。
::: solution
A：失去校对大约去掉 $10^2$ 这一因子，但实际上升更大（*mutD* 诱变株可达 $10^3$–$10^4$ 倍），因为复制错误的大量涌出会压垮错配修复。B：失去错配修复去掉了 $10^3$ 这一因子，所以预期上升约 100 到 1000 倍，*mutS* 菌株的实测结果也是如此。C：大肠杆菌的错配修复利用半甲基化的 `GATC` 位点辨认新链；没有 Dam 甲基化，两条链都没有标记，修复就无法分辨新旧，约一半的"纠正"会用错的碱基替换对的碱基。因此 *dam* 突变体是诱变株，只是较弱。
:::
:::

::: exercise 解读 DNA 纤维实验 {level=3}
人细胞先接受 20 分钟一种胸苷类似物（红色）的脉冲，再接着接受 20 分钟另一种（绿色）的脉冲。然后把单条 DNA 分子铺展在玻璃上染色。(a) 一条分子显示一段 30 μm 的红色，随后是 28 μm 的绿色。按拉伸 DNA $1\ \mu\mathrm{m} = 2.6$ kb 计算，叉速是多少 kb 每分钟？(b) 另一条分子显示绿-红-绿，中间是一段短的红色轨迹。这代表什么？(c) 用一种减慢叉速的药物治疗后，你看到多得多的只有绿色的轨迹。解释之。
::: solution
(a) 红色轨迹记录了 20 min 的叉移动：$30\ \mu\mathrm{m}\times2.6\ \mathrm{kb}\,\mu\mathrm{m}^{-1} = 78$ kb，20 min 内即 3.9 kb min⁻¹；绿色轨迹给出 $28\times2.6/20 = 3.6$ kb min⁻¹，所以叉的移动速度约为 3.6–3.9 kb min⁻¹，处于哺乳动物叉通常范围的上端或略高。

(b) 绿-红-绿的图式是一个在第一轮脉冲期间起始的起点：两个叉从它向外移动，红色标记最初的 20 min，绿色标记两个叉随后的移动。（红色段以起点为中心。）

(c) 只有绿色的轨迹是在第二轮脉冲期间才起始的起点。用药后这样的起点更多，说明细胞因叉变慢而启用了额外的（休眠）起点作为补偿，以按时完成复制。
:::
:::

::: exercise 端粒酶与模板 {level=3}
人端粒酶 RNA 的模板区是 `3'-CAAUCCCAAUC-5'`。(a) 说明它如何指导向一个以 `...TTAGGG-3'` 结尾的染色体末端添加 `TTAGGG` 重复。(b) 一个突变的端粒酶 RNA 模板为 `3'-CAAUCCCCAUC-5'`。预言会被添加的重复序列，以及你如何检测它。(c) 为什么端粒酶延伸 G 富集链时不需要一个单独的引发酶？
::: solution
(a) 从模板的 3′ 端编号：`C1 A2 A3 U4 C5 C6 C7 A8 A9 U10 C11`。染色体末端 `...TTAGGG-3'` 与 `3'-A2 A3 U4 C5 C6 C7-5'` 配对，端粒酶抄写模板余下的部分（`A8 A9 U10 C11`），添加 `TTAG`。随后酶转位：新的末端 `...GTTAG-3'` 在模板的 3′ 端重新与 `3'-C1 A2 A3 U4 C5-5'` 配对，抄写 `C6` 到 `C11` 添加 `GGTTAG`。此后每个循环都添加 `GGTTAG`，在连续序列中即恰好再多一个 `TTAGGG` 重复。

(b) 突变模板为 `C1 A2 A3 U4 C5 C6 C7 C8 A9 U10 C11`。抄写 `C6` 到 `C11` 现在添加的是 `GGGTAG` 而不是 `GGTTAG`，所以重复序列由 `TTAGGG` 变为 `GTAGGG`。改变的产物在下一个循环中与模板 3′ 端的配对也更差，所以持续合成能力可能下降。新的重复序列可通过对端粒 DNA 测序或用针对它的探针检测。Guo-Liang Yu、伊丽莎白·布莱克本及同事（1990）在四膜虫中恰好做了这一实验，证明 RNA 在活细胞内就是模板；携带突变重复序列的细胞端粒也异常、分裂很差，因为端粒结合蛋白质识别的是重复序列本身。

(c) 端粒酶以自身 RNA 为模板延伸一个已存在的 3′ 末端——染色体末端的突出端；它需要引物（每种聚合酶都需要），而染色体末端提供了它。另一条 C 富集链随后由聚合酶 α–引发酶补齐，那才需要一个引发酶。
:::
