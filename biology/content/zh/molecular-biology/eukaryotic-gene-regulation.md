同一个人的神经元与肝细胞携带同一套基因组，然而一个制造神经递质受体，另一个制造白蛋白与尿素循环的酶。细胞的差别不在于它们拥有哪些基因，而在于它们使用哪些基因。核移植证明了这一点。戈登（John Gurdon）（1962）用肠细胞核置换过的卵得到了会游泳的非洲爪蟾（*Xenopus laevis*）蝌蚪。1996 年，维尔穆特（Ian Wilmut）及同事用成年乳腺细胞的核克隆出了绵羊多莉（1997 年报道）。高桥和利（Kazutoshi Takahashi）与山中伸弥（Shinya Yamanaka）（2006）仅表达四个转录因子，就把小鼠成纤维细胞重编程为多能干细胞。分化细胞保留着自己的基因，而表达哪些基因的选择可以被重置。

真核生物在每一步控制基因表达：染色质、转录、RNA 加工、输出、翻译，以及 mRNA 与蛋白质的稳定性。本章集中讨论承担大部分工作的几步，内容包括转录因子及其结合的增强子、染色质与 DNA 甲基化如何使基因更可及或不可及并把这种状态跨细胞分裂地记忆下来，以及转录后沉默基因的小 RNA。[[molecular-biology/bacterial-gene-regulation]] 中的细菌原理——阻遏蛋白与激活蛋白、合作性与募集——在这里全部重现，但多了三个新特点：真核生物的调控 DNA 常常远离它所控制的基因；每个基因上有许多因子共同作用；绕在核小体上的 DNA 默认处于被阻遏状态。

## 转录因子

::: definition 序列专一性转录因子 {#def-tf}
**序列专一性转录因子**（TF）是一种结合短 DNA 序列模因（通常 6–12 bp）、改变附近基因转录速率的蛋白质。大多数转录因子是**模块化**的：**DNA 结合结构域**（DBD）识别模因，一个或多个**效应结构域**要么激活转录（**激活结构域**，常为酸性或谷氨酰胺富集、本质无序），要么抑制转录。许多转录因子还有二聚化结构域和结合调控配体的结构域。人细胞约有 1600 个转录因子（Lambert 等，2018），按其 DBD 的结构分类。
:::

模块化由布伦特（Roger Brent）与普塔什内（Mark Ptashne）于 1985 年证明。酵母激活蛋白 **Gal4** 结合上游激活序列（UAS~G~）并激活半乳糖基因。他们把 Gal4 的激活结构域接到细菌阻遏蛋白 LexA 的 DNA 结合结构域上，这个杂合蛋白就激活了一个把 UAS 换成 LexA 结合位点的酵母基因。两个功能可以分开、可以互换。检测蛋白质–蛋白质相互作用的**酵母单杂交**方法（菲尔兹（Stanley Fields）与宋（Ok-Kyu Song），1989）正是利用了这一点：DBD 融合一个蛋白、激活结构域融合另一个蛋白，只有当两个蛋白彼此结合时才重建出一个激活蛋白。

DNA 结合结构域的主要家族各把一个 α 螺旋插入大沟（[[molecular-biology/dna-structure#def-bdna]]）：

- **同源结构域**：一个 60 个氨基酸的螺旋-转角-螺旋结构域，由 *Hox* 基因的同源盒编码，这些基因给动物体轴分区（[[developmental-biology/segmentation-hox]]）。
- **C₂H₂ 锌指**：约 30 个氨基酸绕一个锌离子折叠。每个指读约 3 bp，带有指阵列的蛋白质可读长的位点。这是人最大的一个家族，有几百个成员。
- **碱性亮氨酸拉链**（bZIP；如 AP-1、Fos–Jun）与**碱性螺旋-环-螺旋**（bHLH；如 MyoD）：二聚体，卷曲螺旋或螺旋-环-螺旋把两个碱性 DNA 结合螺旋握在一起，不同的配对因而产生专一性不同的因子。
- **核受体**，作用于类固醇与甲状腺激素、维甲酸等：一个含锌的 DBD 与一个配体结合结构域。激素结合改变受体的构象及其与辅激活蛋白的相互作用。糖皮质激素受体在配体结合时从细胞质移入细胞核。

::: example 结合位点多得用不完 {#ex-sites}
某转录因子精确识别一个 8 bp 的模因。(a) 在碱基频率相等的随机序列中，单倍体人基因组（$3.1\times10^9$ bp，两条链）里预期有多少个匹配？(b) 若是 10 bp 的模因呢？(c) 全基因组结合实验（染色质免疫沉淀结合测序，ChIP-seq）通常发现一个转录因子结合在几千到几万个位点。这一比较意味着什么？
::: solution
(a) $2\times3.1\times10^9/4^8 = 6.2\times10^9/65\,536 \approx 9.5\times10^4$ 个匹配。

(b) $6.2\times10^9/4^{10} \approx 5.9\times10^3$。

(c) 即使是长模因也会偶然出现几千次，而且转录因子还结合不完美的匹配。所以大多数潜在位点并不在某一特定细胞中被占据，许多被占据的位点也没有可检出的效应。决定占据与功能的是上下文：染色质的可及性、附近结合着哪些其他转录因子（增强子中成簇的位点）、以及合作性相互作用。只凭模因匹配预测调控多半会失败。这有时被称为"徒劳定理"（沃瑟曼（Wyeth Wasserman）与桑德林（Albin Sandelin），2004）。
:::
:::

## 增强子

::: definition 增强子 {#def-enhancer}
**增强子**是一段能提高启动子转录的 DNA 区段，通常几百个碱基对长。它的工作与方向无关，并且作用距离可变、常常很大（从不足一千个碱基到超过一兆个碱基），可以位于所控制基因的上游、下游或内含子之中。增强子含有几个转录因子的成簇结合位点，它在某一细胞中的活性取决于这些因子中有哪几个存在且有活性。**沉默子**是以同样不依赖距离的方式起阻遏作用的元件。**绝缘子**是放在增强子与启动子之间就能阻断二者通讯的元件，其中许多被 CTCF 结合。
:::

增强子由巴纳吉（Julian Banerji）、拉斯科尼（Sandro Rusconi）与沙夫纳（Walter Schaffner）于 1981 年发现。来自病毒 SV40 的一段 72 bp 重复序列放到携带兔 β-珠蛋白基因的质粒上，在培养细胞中使 β-珠蛋白的转录提高约 200 倍，而且正放反放都行，放在距基因几千个碱基对处也行。1983 年，在免疫球蛋白基因中发现了组织特异增强子，只在产抗体的细胞中有活性（利根川进（Susumu Tonegawa）组；巴纳吉、奥尔森与沙夫纳）。作用距离的一个极端例子是驱动后部肢芽中 *Sonic hedgehog*（*Shh*）的 **ZRS** 增强子：它位于另一个基因的内含子中，距 *Shh* 约一兆个碱基（莱蒂斯（Laura Lettice）、希尔（Robert Hill）及同事，2003）。其中单个碱基的改变会使人、小鼠和猫多出指头（轴前多指）。

增强子靠成环在这样远的距离上起作用。结合在增强子上的蛋白质接触启动子，由 **Mediator**（中介复合体）以及依赖凝聚素（cohesin）把染色质折叠成环和域来帮忙（[[molecular-biology/dna-structure]]）。增强子–启动子的接触大体被限制在同时包含二者的拓扑结构关联域内，被 CTCF 结合的边界限定了增强子能够到哪些启动子。在全基因组范围内，活跃增强子的识别特征是开放的染色质、组蛋白 H3 第 4 位赖氨酸单甲基化（H3K4me1）与第 27 位赖氨酸乙酰化（H3K27ac），以及被转录成短**增强子 RNA**。

### 组合式控制：eve 条纹 2 增强子

多细胞生物的每个基因都必须在特定模式中表达。这种模式由增强子上整合许多输入产生。研究得最好的例子来自果蝇早期发育（[[developmental-biology/segmentation-hox]]）。成对规则基因 *even-skipped*（*eve*）在胚胎中表达为七条横纹，每条纹（或每对纹）由自己的增强子驱动。**条纹 2 增强子**是一个约 480 bp 的最小元件（斯莫尔（Stephen Small）、布莱尔（Alexander Blair）与莱文（Michael Levine），1992），含两个激活蛋白和两个阻遏蛋白的结合位点：

- **Bicoid** 与 **Hunchback**，存在于胚胎前半部的激活蛋白；
- **Giant**，一个在条纹 2 正前方一带表达的阻遏蛋白；
- **Krüppel**，一个在胚胎中部、条纹 2 正后方表达的阻遏蛋白。

增强子只在两个激活蛋白都在、两个阻遏蛋白都不在的地方有活性，那是一个只有几个细胞宽的窄纹。结合在增强子里的阻遏蛋白只在短距离上起作用（**短距抑制**，约 100 bp 以内），所以每个条纹增强子尽管都靠近同一个基因，也能彼此独立地受调控。

::: example 解读条纹 2 的逻辑 {#ex-eve}
设早期胚胎的前–后轴上（0 % = 前端），Bicoid 与 Hunchback 存在于 0 至 50 %，Giant 存在于 20 至 35 % 及 75 至 90 %，Krüppel 存在于 42 至 60 %。（位置为示意图。）(a) 条纹 2 增强子在哪里有活性？(b) 预言从增强子除去 Giant 结合位点的效应，以及 *Krüppel*⁻ 胚胎的效应。(c) 胚胎为什么用几个各自独立的条纹增强子而不是一个？
::: solution
(a) 增强子需要激活蛋白（0–50 %）、无 Giant（在激活域内，35 % 至 75 % 无 Giant）且无 Krüppel（42 % 以下无）。三者的交集是 35–42 %：一条单独的纹。

(b) 没有 Giant 位点，前缘边界消失，表达沿 Giant 域向前扩展到激活的前限（0–42 %，或许受其他阻遏蛋白限制）。斯莫尔、布莱尔与莱文在报告基因中使用突变位点时看到的前部扩展正是如此。*Krüppel*⁻ 胚胎中，后缘边界朝激活剂的极限 50 % 向后移动，使条纹后部变宽。

(c) 彼此独立的模块化增强子让每条纹由不同组合的阻遏边界来定位，而短距抑制防止一个增强子上的阻遏蛋白沉默其他增强子。模块化增强子还允许进化在不影响基因其他地方表达的前提下改变它在某一组织或区域中的表达（[[developmental-biology/evo-devo]]）。
:::
:::

### 激活蛋白如何工作

激活蛋白主要靠**募集**工作，与细菌中一样（[[molecular-biology/transcription#ex-mcclure]]），只不过真核生物中被募集的东西更多样。激活结构域接触中介复合体、TFIID 与前起始复合体的其他组分，增加它们在启动子上的装配。它们还募集修饰染色质的**辅激活蛋白**：**组蛋白乙酰转移酶**（HAT，如 p300/CBP 与 SAGA 复合体）和依赖 ATP 的**染色质重塑复合体**（SWI/SNF），后者滑动或逐出核小体。它们还可通过募集 P-TEFb 释放暂停的聚合酶（[[molecular-biology/transcription]]）。阻遏蛋白的作用方式有与激活蛋白竞争位点、遮蔽激活结构域，或募集**辅阻遏蛋白**，如组蛋白去乙酰化酶（HDAC）与 Groucho/TLE 蛋白。

::: proposition 靠募集激活 {#prop-recruitment}
考虑一个转录机器的基础占据 $P$ 很低的弱启动子，以及一个以解离常数 $K_A$ 结合近旁位点的激活蛋白 $A$。当二者都结合时，它们之间的吸引相互作用使双重结合状态的统计权重乘以因子 $\omega > 1$。把四种状态（空、仅 $P$、仅 $A$、二者皆结合）的统计权重求和，并取启动子占据很低，则**激活倍数**（有激活蛋白时的表达除以无激活蛋白时的表达）为
$$
\text{FC} = \frac{1 + \omega\,[A]/K_A}{1 + [A]/K_A}.
$$ {#eq-recruitment}
它从 $[A] \ll K_A$ 时的 1 升到激活蛋白位点饱和时的最大值 $\omega$。若 $\omega$ 对应一个相互作用自由能 $\Delta G_\text{int} < 0$，则 $\omega = e^{-\Delta G_\text{int}/RT}$，所以 37 °C 时区区 $-10\ \mathrm{kJ\,mol^{-1}}$ 的接触就给出 $\omega \approx 50$。这一模型（如 Bintu 等，2005）假定平衡结合，且转录正比于启动子的占据。
:::

::: proof
令 $p = [P]/K_P$ 与 $a = [A]/K_A$ 为单一结合状态的统计权重，则四种状态的权重为 $1$（空）、$p$、$a$ 与 $\omega pa$（二者皆结合）。启动子被占据的概率为 $(p + \omega pa)/(1 + p + a + \omega pa)$。对弱启动子，$p \ll 1$ 且 $\omega p a \ll 1 + a$，所以它近似为 $p(1 + \omega a)/(1 + a)$。无激活蛋白时（$a = 0$）它是 $p$。两式相除即得 [[#eq-recruitment]]。
:::

::: example 能激活多少？{#ex-recruitment}
一个激活蛋白与转录机器的相互作用 $\omega = 50$。(a) 求 $[A]/K_A$ 为 0.1、1、10 与 100 时的激活倍数。(b) 两个彼此独立的激活蛋白饱和时各给 $\omega = 50$，且都接触转录机器。两个都饱和时预期多少激活倍数？(c) 这为什么说明带有多个位点的增强子很有用？
::: solution
(a) 由 [[#eq-recruitment]]：$a = 0.1$ 得 $(1 + 5)/1.1 = 5.5$；$a = 1$ 得 $51/2 = 25.5$；$a = 10$ 得 $501/11 = 45.5$；$a = 100$ 得 $5001/101 = 49.5$。激活在 $\omega = 50$ 处饱和。

(b) 若两个接触彼此独立、在自由能上相加，权重相乘：$\omega_1\omega_2 = 2500$ 倍。（真实的激活蛋白常表现出这类协同，直到启动子接近完全占据，此时弱启动子近似失效。）

(c) 权重相乘意味着一组弱相互作用能给出大而全或无的响应，但只有当*所有*因子都在场时才行。因此增强子中的几个位点就像一个 AND 门，正如 eve 条纹 2 增强子那样，并允许对输入组合作出锐利的响应。
:::
:::

## 染色质与基因调控

核小体上的 DNA 比裸露 DNA 的可及性低得多。在体外，核小体强烈阻遏大多数启动子的转录，而这种阻遏可被激活蛋白解除。染色质因而不是被动的包装材料，而是调控系统的一部分（[[molecular-biology/dna-structure#def-nucleosome]]）。

### 组蛋白修饰

组蛋白的 N 端尾巴携带许多共价修饰，由"写入"酶添加、由"擦除"酶除去、由其他蛋白质的"读取"结构域识别。

::: definition 主要的组蛋白标记 {#def-histone-marks}
修饰残基按组蛋白、残基与修饰来书写：H3K27ac 是组蛋白 H3 第 27 位赖氨酸的乙酰化；H3K4me3 是第 4 位赖氨酸的三甲基化。
- 赖氨酸**乙酰化**（由 HAT 添加；由 HDAC 除去）中和其正电荷，由**溴结构域**读取。它与活跃的启动子和增强子相关联（如 H3K27ac、H3K9ac）。
- **H3K4me3** 标记活跃（以及待命）的启动子；**H3K4me1** 标记增强子。
- **H3K36me3** 由随延伸中的 Pol II 同行的甲基转移酶添加，标记正在转录的基因本体。
- **H3K27me3** 由 **Polycomb 阻遏复合体 2**（PRC2）添加，标记受 Polycomb 系统沉默的基因，常是在该细胞中关闭的发育调控基因。
- **H3K9me3** 由 SUV39H1 等甲基转移酶添加，被 **HP1** 的**染色质结构域**结合，标记组成型异染色质与被沉默的转座子。
:::

奥尔弗里（Vincent Allfrey）及同事 1964 年提出组蛋白乙酰化与转录相联系。当布朗内尔（James Brownell）、艾利斯（David Allis）及同事（1996）从四膜虫纯化出一个组蛋白乙酰转移酶、发现它正是酵母转录辅激活蛋白 Gcn5 的同源物时，这一联系才有了机制。同年施赖伯（Stuart Schreiber）的小组发现一种组蛋白去乙酰化酶与酵母一种转录阻遏蛋白同源。辅激活蛋白与辅阻遏蛋白原来是修饰染色质的酶。

施特拉尔（Brian Strahl）与艾利斯 2000 年提出，标记的组合构成一套**组蛋白密码**，被蛋白质读取而产生特定结果。标记在多大程度上*导致*而非*反映*转录状态，仍有争论。有些标记显然是指令性的：把 HP1 或 PRC2 拴到一个基因上就足以使其沉默，而且拴系撤除后沉默仍可维持。另一些，如 H3K4me3 与 H3K36me3，似乎主要作为转录的结果被写下，帮助转录高效而忠实。

有些转录因子称为**先锋因子**（肝发育中的 FoxA 与 GATA 因子，扎雷特（Kenneth Zaret）研究；山中因子 Oct4、Sox2 与 Klf4），能结合核小体 DNA 上自己的位点。它们打开关闭的染色质，让其他因子得以结合。在发育与重编程中启动新的基因表达程序需要它们。

### Polycomb 与 Trithorax：基因表达的记忆

在果蝇中，**Polycomb 组**基因的突变会使 *Hox* 基因——发育早期由瞬时调控因子在正确体节开启——在后来的发育中错在别的体节活动。果蝇因此发生体节转换，例如在腿上多长出性梳，*Polycomb* 即由此得名（刘易斯（Edward Lewis），1978）。**Trithorax 组**的突变引起相反现象：*Hox* 基因在本该开放的地方得不到维持。两组蛋白在初始信号消失之后的许多次分裂中分别维持关闭与开放状态。Polycomb 复合体（PRC2 写 H3K27me3，PRC1 压缩染色质）是阻遏的细胞记忆，Trithorax 蛋白（包括 H3K4 甲基转移酶）是活性的记忆。两套系统在哺乳动物与植物中都保守。在植物中，长期低温后 Polycomb 对开花阻遏蛋白 *FLC* 的沉默，是某些植物开花前必须经历冬天的**春化**的分子基础（[[plant-biology/plant-responses]]）。

### DNA 甲基化

在脊椎动物与植物中，胞嘧啶可在 5 位碳上甲基化，生成**5-甲基胞嘧啶**（5mC）。在哺乳动物中这几乎只发生在 **CpG** 二核苷酸上，体细胞中约 70–80 % 的 CpG 是甲基化的。例外是大多数启动子处的 **CpG 岛**，它们通常未甲基化。启动子 CpG 岛的甲基化与稳定的沉默相关联，如失活的 X 染色体、印记基因（[[genetics/non-mendelian-inheritance]]）与转座子。甲基化的 DNA 被带甲基-CpG 结合结构域的蛋白质结合，后者募集 HDAC 与其他阻遏活性。

::: definition 维持性甲基化与从头甲基化 {#def-dna-methylation}
因为 CpG 是回文的，甲基化的 CpG 两条链都被甲基化。复制之后，新链未甲基化，该位点是**半甲基化**的。**DNMT1** 由识别半甲基化 CpG 的蛋白质 UHRF1 募集到复制叉，甲基化新链从而复制出模式：**维持性甲基化**。**DNMT3A** 与 **DNMT3B** 甲基化未甲基化的位点（**从头甲基化**），在发育中建立新模式（冈本（Masaki Okano）、李恩（En Li）及同事，1999）。甲基化的去除或是被动的——复制而不维持，——或是主动的——由 **TET** 酶把 5mC 氧化为 5-羟甲基胞嘧啶及后续产物，再由碱基切除修复切去（塔希利亚尼（Mamta Tahiliani）、拉奥（Anjana Rao）及同事，2009）。里格斯（Arthur Riggs），以及霍利迪（Robin Holliday）与帕格（John Pugh），在 1975 年各自独立提出了维持机制。
:::

::: example 维持有多忠实？{#ex-maintenance}
设 DNMT1 在每个复制后以概率 $m$ 重新甲基化每个半甲基化 CpG，彼此独立，且没有从头甲基化。(a) 若 $m = 0.95$，一个起初完全甲基化的 CpG 组在 10 次分裂后有多大比例仍两条链都甲基化？若 $m = 0.99$ 呢？(b) 哺乳动物细胞中实测的每位点维持保真度约为每次分裂 0.95–0.99。这对甲基化模式如何稳定维持意味着什么？(c) 为什么含许多 CpG 的启动子可能比其中任何一个 CpG 都稳定？
::: solution
(a) 每次分裂一个位点以概率 $m$ 幸存，一旦失去便不再恢复：$0.95^{10} = 0.60$，$0.99^{10} = 0.90$。

(b) 仅靠维持，甲基化会在几十次分裂中侵蚀殆尽。真实细胞中的稳定性依赖从头甲基转移酶，也依赖 DNA 甲基化与阻遏性组蛋白标记之间的反馈——后者把甲基转移酶募集回大都已甲基化的区域。

(c) 启动子的沉默取决于该区域的甲基化密度，而非任何一个 CpG。单个位点的错误，由把甲基转移酶募集到大都已甲基化区域（以及把去甲基化酶募集到大都未甲基化区域）来纠正，所以区域状态作为双稳态性质得以维持，尽管个别位点在闪烁。这类集体模型比单纯的每位点复制更能解释甲基化的稳定性。
:::
:::

::: warning "表观遗传意味着跨世代的环境经验遗传"
在分子生物学中，**表观遗传**指跨*细胞分裂*遗传、而不改变 DNA 序列的表达变化，如得以维持的 DNA 甲基化、Polycomb 沉默与 X 失活。在生物体内，这种细胞记忆是有充分根据的。从亲代经生殖系把后天获得的表观状态遗传给子代则是另一回事。这在植物（稳定的甲基化变异，*拟等位基因*）与线虫（基于小 RNA、可维持几代的沉默）中有明确记录。在哺乳动物中，甲基化会两次被擦除并重设——在早期胚胎与原始生殖细胞中——而环境诱导状态跨世代遗传的证据有限且有争论。不要把"表观遗传"读作"由祖辈的经历遗传而来"。
:::

## 小 RNA 的调控

1993 年，罗莎琳德·李（Rosalind Lee）、费恩鲍姆（Rhonda Feinbaum）与安布罗斯（Victor Ambros）发现，线虫的发育时序基因 *lin-4* 编码的不是蛋白质，而是一条 22 个核苷酸的 RNA，与 *lin-14* mRNA 3′ 非翻译区中的序列部分互补。同一期 *Cell* 上，怀特曼（Bruce Wightman）、哈（Ilho Ha）与鲁夫昆（Gary Ruvkun）证明这些位点是 *lin-4* 阻遏 LIN-14 蛋白所必需的。此后七年，这看起来只是线虫的一桩奇闻。到 2000 年发现了第二条线虫小 RNA *let-7*（莱因哈特（Brenda Reinhart）、鲁夫昆及同事），并且发现它从果蝇到人的序列都保守（帕斯奎内利（Amy Pasquinelli）及同事）。不到一年，人们就从动物与植物中克隆出几百条这样的 **microRNA**（miRNA）。安布罗斯与鲁夫昆获 2024 年诺贝尔生理学或医学奖。

与此同时，1998 年，法厄（Andrew Fire）、徐思群（SiQun Xu）、蒙哥马利（Mary Montgomery）、科斯塔斯（Steven Kostas）、德赖弗（Samuel Driver）与梅洛（Craig Mello）证明，向线虫注入**双链 RNA**，比其任何一条单链都强得多的沉默相同序列的基因。每个细胞几个分子就够，而且沉默会扩散到整个动物并传至其子代。注入与肌肉基因 *unc-22* 匹配的 dsRNA，产生 *unc-22* 突变体的抽搐表型。这一 **RNA 干扰**（RNAi）解释了先前的困惑，如转基因矮牵牛中色素基因的"共抑制"（纳波利（Carolyn Napoli）与乔根森（Richard Jorgensen），1990）。法厄与梅洛获 2006 年诺贝尔奖。图施尔（Thomas Tuschl）的小组 2001 年证明，合成的 21 个核苷酸双链——**小干扰 RNA**（siRNA）——能在哺乳动物细胞中沉默基因，而不引发长 dsRNA 会引起的干扰素应答。

::: definition microRNA 的产生与作用 {#def-mirna}
在动物中，miRNA 基因由 Pol II 转录成含茎环的 **pri-miRNA**。核内的 **Microprocessor**（加工复合体，RNase III 酶 **Drosha** 与 DGCR8）切下约 60–70 个核苷酸的 **pre-miRNA** 茎环，由 Exportin-5 运出。在细胞质中，**Dicer** 切掉环部，留下约 22 bp 的双链。其中一条链——成熟的 miRNA——装载进 **Argonaute**（AGO）蛋白，形成 **RNA 诱导的沉默复合体**（RISC）。miRNA 通过碱基配对引导 AGO 找到靶 mRNA，主要靠其**种子区**（seed），即其 5′ 端起第 2–8 位核苷酸，位点通常在 3′ UTR。结合后募集一些蛋白质（GW182/TNRC6），引起 mRNA 的去腺苷酸化、去帽与降解，并抑制其翻译。相比之下，siRNA 与靶子完全配对，于是 AGO2 把它剪断（**切割**，slicing）。
:::

```python
# 在 3' UTR 中查找 microRNA 种子匹配位点（canonical 8mer、7mer-m8、7mer-A1、6mer）
def revcomp_rna(s):
    return s[::-1].translate(str.maketrans("ACGU", "UGCA"))

def seed_sites(mirna, utr):
    m8 = revcomp_rna(mirna[1:8])          # 与 miRNA 第 2-8 位核苷酸配对
    m6 = revcomp_rna(mirna[1:7])          # 与第 2-7 位配对
    found = []
    for i in range(len(utr) - 5):
        if utr.startswith(m8 + "A", i):
            found.append((i, "8mer"))
        elif utr.startswith(m8, i):
            found.append((i, "7mer-m8"))
        elif utr.startswith(m6 + "A", i + 1) and not utr.startswith(m8, i):
            found.append((i + 1, "7mer-A1"))
        elif utr.startswith(m6, i + 1) and not utr.startswith(m8, i):
            found.append((i + 1, "6mer"))
    return m8, found

let7a = "UGAGGUAGUAGGUUGUAUAGUU"             # 人 let-7a，5'->3'
utr = ("AAGCUUCCUACCUCAUUGGAACUGGACUACCUCGAAUUUUACCUCAGGCAAUUACCUCUU"
       "GGCCAUAAACUACCUCAAUUUGCA")            # 一个虚构的 3' UTR
m8, sites = seed_sites(let7a, utr)
print("seed (nt 2-8):", let7a[1:8], "| site (7mer-m8):", m8)
for pos, kind in sites:
    print(f"  position {pos:3d}: {kind}")
```

输出（位置从 UTR 的 0 数起）：

```
seed (nt 2-8): GAGGUAG | site (7mer-m8): CUACCUC
  position   7: 8mer
  position  26: 7mer-m8
  position  39: 7mer-A1
  position  52: 6mer
  position  69: 8mer
```

位点类型的命名遵循巴特尔（David Bartel）实验室的惯例。**8mer** 与第 2–8 位核苷酸配对且第 1 位对面是 A，**7mer-m8** 与 2–8 配对，**7mer-A1** 与 2–7 加上那个 A 配对，**6mer** 与 2–7 配对。它们的效力按此顺序递减。这里虚构的 UTR 有五个位点。一个天然靶标通常有一个或几个，单个位点的阻遏通常温和，常不到两倍。miRNA 对靶标的可测效应大部分是 mRNA 水平的下降（郭惠丽、巴特尔及同事，2010）。

::: example 一个种子有多专一？{#ex-seed}
(a) 在随机序列中，一个 7 个核苷酸的种子位点出现在给定位置的概率是多少？(b) 一条随机 1000 个核苷酸的 3′ UTR 至少含有一个位点的概率是多少？(c) 20 000 条带这种 UTR 的人 mRNA 中，大约有多少条会偶然携带一个位点？(d) 比较基因组学显示，超过 60 % 的人蛋白质编码基因带有至少在一种 miRNA 上跨哺乳动物保守的位点（弗里德曼（Robin Friedman）、巴特尔及同事，2009）。为什么保守是关键证据？
::: solution
(a) $4^{-7} = 6.1\times10^{-5}$。

(b) $1 - (1 - 4^{-7})^{1000} = 0.059$，约 6 %。（简单估计 $1000\times4^{-7} = 0.061$ 之所以接近，是因为位点罕见。）

(c) 每个 miRNA 种子仅凭偶然就约有 $20\,000\times0.059 \approx 1200$ 条 mRNA。

(d) 偶然匹配预计在几千个基因中都有，所以一个基因组里的位点说明不了什么。一个在几千万年前分歧、周围 UTR 序列已经改变的物种的同源 UTR 中保留下来的位点，是被选择保留下来的，这意味着该相互作用有意义。因此，保守的靶向关系，连同加入或移除某个 miRNA 时测量 mRNA 与蛋白质变化的实验，是靶标预测的主要依据。
:::
:::

动物还有 **piRNA**（PIWI 相互作用 RNA），长 24–31 个核苷酸，不经 Dicer 产生，在生殖系中与 Argonaute 的 PIWI 亚家族结合。它们通过剪切转座子的转录物、并把阻遏性染色质标记与 DNA 甲基化引导到转座子拷贝上，来沉默转座子。果蝇中的**杂种发育不良**——带 *P* 因子的品系与不带 *P* 因子的品系杂交产生不育后代——可以由某一个品系母源生殖系中缺乏 *P* 元件的 piRNA 来解释（[[molecular-biology/dna-repair-recombination]]）。在植物与裂殖酵母中，小 RNA 引导重复序列处异染色质的形成，于是 RNA 沉默从细胞质回达到染色质。

**长非编码 RNA**（lncRNA）是长于 200 个核苷酸、没有蛋白质编码潜力的转录物，在人的注释中有几万个。少数有确证的功能。**Xist**（约 17 kb）包裹产生它的那条 X 染色体，募集沉默复合体使之失活。许多其他 lncRNA 表达量很低，它们的功能——如果有的话——尚在研究。一条转录物的存在并不是它有功能的证据。

## 翻译调控与 mRNA 稳定性

许多响应必须快过新转录所能允许的速度，于是细胞调节已有 mRNA 的翻译与降解。

- **铁。** 缺铁时，**铁调节蛋白**（IRP）结合**铁反应元件**（IRE）——铁蛋白 mRNA 5′ UTR 中的茎环，结合后阻断翻译；以及转铁蛋白受体 mRNA 的 3′ UTR，结合后保护它免于降解。缺铁因此减少储铁、增加吸铁。铁充足时，IRP 失去 RNA 结合活性（IRP1 变成含铁硫簇的乌头酸酶），上述效应反转。
- **全局控制。** 氨基酸饥饿、内质网中未折叠的蛋白质、病毒感染等胁迫激活激酶，磷酸化 **eIF2α**，减少三元复合物的形成与全局翻译。矛盾的是，它们增加少数几种 mRNA 的翻译，如带有短上游 ORF 的 *ATF4*。营养与生长信号经激酶 mTOR 起作用：mTOR 磷酸化并使 **4E-BP** 失活，释放 eIF4E 用于依赖帽的起始（[[molecular-biology/translation]]）。
- **mRNA 稳定性。** 3′ UTR 中的 AU 富集元件被去稳定蛋白结合，使许多细胞因子与转录因子的 mRNA 寿命很短，转录一停，其蛋白质生产很快停止。

::: proposition mRNA 的稳态与响应时间 {#prop-steady-state}
设某 mRNA 以恒定速率 $k$（单位时间的分子数）合成，以一阶速率常数 $\delta = \ln2/t_{1/2}$ 降解，$t_{1/2}$ 为其半衰期。其数目 $m$ 满足 $dm/dt = k - \delta m$，于是
$$
m(t) = \frac{k}{\delta} + \left(m_0 - \frac{k}{\delta}\right)e^{-\delta t}, \qquad m^* = \frac{k}{\delta}.
$$ {#eq-steady-state}
稳态水平正比于合成速率乘以半衰期。$k$ 发生任何改变后，$m$ 以指数方式趋向新的稳态，并在一个半衰期内走完一半路程。**响应时间由降解速率决定，而非合成速率。**细胞的生长稀释相当于加在 $\delta$ 上。同样的方程适用于蛋白质。
:::

::: example 稳定的与不稳定的信使 {#ex-half-life}
两个基因以相同速率转录，每小时 10 个 mRNA 分子。基因 A 的 mRNA 半衰期 30 min，基因 B 的 10 h。（小鼠成纤维细胞中 mRNA 半衰期的中位数约为 9 h，范围很宽；施万豪瑟（Björn Schwanhäusser）及同事，2011。）(a) 求两种 mRNA 各自的稳态数目。(b) 两者转录都停止。降到各自稳态的四分之一各需多久？(c) 哪种设计适合必须迅速关闭的信号蛋白质基因，哪种适合管家酶？
::: solution
(a) 对 A，$\delta = \ln2/0.5\ \mathrm{h} = 1.39\ \mathrm{h^{-1}}$，所以 $m^* = 10/1.39 = 7.2$ 个分子。对 B，$\delta = 0.0693\ \mathrm{h^{-1}}$，所以 $m^* = 144$。

(b) 四分之一意味着两个半衰期：A 需 1 h，B 需 20 h。

(c) 不稳定的 mRNA（A）响应快，代价是水平低或转录速率高，适合其活性必须跟踪当前信号的信号与调控蛋白质。稳定的 mRNA（B）廉价地给出高水平并缓冲波动，适合管家蛋白质。细胞用合成来购买速度，这一权衡在 [[systems-biology/gene-expression-dynamics]] 中有进一步讨论。
:::
:::

::: application 作为工具与药物的小 RNA 和染色质
用 siRNA 或短发夹 RNA 做 RNAi，成为在培养细胞与线虫、果蝇等模式生物中降低所选基因表达的标准方法。在 CRISPR 筛在很大程度上取代它们之前，全基因组 RNAi 筛鉴定了许多细胞过程的基因（[[molecular-biology/molecular-tools]]）。化学稳定的 siRNA 递送至肝脏，自 2018 年起已获批为药物（patisiran，用于遗传性转甲状腺素蛋白淀粉样变性），DNA 甲基转移酶抑制剂与组蛋白去乙酰化酶抑制剂也已用于某些血液肿瘤。临床方面属于医学图谱（[/learn/medicine/](/learn/medicine/)）。在农业上，RNAi 已被用于培育抗病毒作物、改变苹果与马铃薯褐变等性状，受转基因生物法规管理（[[biotechnology/agricultural-biotechnology]]）。

戈登 1962 年用分化细胞的核移植得到蛙，山中伸弥组 2006 年做出诱导多能干细胞（两人分享 2012 年诺贝尔奖）。奥尔弗里 1964 年把组蛋白乙酰化与转录相联系。里格斯，以及霍利迪与帕格，1975 年提出维持性甲基化；刘易斯 1978 年描述了 Polycomb 表型与 *bithorax* 复合体。巴纳吉、拉斯科尼与沙夫纳 1981 年发现增强子。布伦特与普塔什内 1985 年证明转录因子的模块化。斯莫尔、布莱尔与莱文 1992 年剖析了 eve 条纹 2 增强子；罗莎琳德·李、费恩鲍姆与安布罗斯，以及怀特曼、哈与鲁夫昆，1993 年描述了第一个 microRNA。布朗内尔、艾利斯及同事 1996 年鉴定出一个作为辅激活蛋白的组蛋白乙酰转移酶。法厄、梅洛及同事 1998 年发现 RNA 干扰；图施尔组 2001 年把 siRNA 引入哺乳动物细胞。
:::

::: summary
- 分化细胞保留其基因组（核移植、iPS 细胞）；它们的不同在于表达哪些基因。
- 转录因子是模块化的：一个 DNA 结合结构域（同源结构域、锌指、bZIP、bHLH、核受体）加效应结构域。模因匹配的数目远多于被结合位点的数目，所以上下文决定功能。
- 增强子是转录因子位点的簇，不依赖方向、在远距离上靠绝缘子（CTCF）划界的域内成环起作用。激活蛋白与短距阻遏蛋白的组合产生精确模式，如 eve 条纹 2 增强子。
- 激活蛋白募集中介复合体、通用机器、HAT 与重塑复合体。在简单平衡模型中，激活倍数为 $(1 + \omega a)/(1 + a)$，在 $\omega$ 处饱和，独立的接触相乘。
- 组蛋白标记区分活跃启动子（H3K4me3）、增强子（H3K4me1、H3K27ac）、基因本体（H3K36me3）、Polycomb 沉默（H3K27me3）与异染色质（H3K9me3/HP1）。Polycomb 与 Trithorax 跨分裂维持关闭与开放状态。
- CpG 甲基化由 DNMT1 在半甲基化位点复制，由 DNMT3A/B 设定，由 TET 酶与复制去除。它沉默启动子、转座子、印记基因与失活的 X 染色体。
- miRNA（Drosha、Dicer、AGO）靠种子区配对（第 2–8 位核苷酸）阻遏靶标，主要通过 mRNA 降解；siRNA 剪断完全配对的靶标；piRNA 在生殖系沉默转座子。
- 翻译与 mRNA 降解同样受调控（IRE/IRP、eIF2α、mTOR–4E-BP、AU 富集元件）。mRNA 的稳态水平是 $k/\delta$，响应时间是一个半衰期。
:::

## 练习

::: exercise 模因频率 {level=1 check="370"}
在一个 3.1 Gb 的基因组中，两条链都算，一个 12 bp 的模因按偶然预期会出现多少个匹配（取最接近的整数）？
::: solution
$4^{12} = 16\,777\,216$，所以期望数是 $6.2\times10^9/1.678\times10^7 = 369.6 \approx 370$。即使 12 bp 的位点比大多数转录因子模因都长，按偶然也预期出现几百次。
:::
:::

::: exercise 稳态 {level=1 check="433"}
一个 mRNA 以每小时 50 个分子的速率合成，半衰期 6 h。它的稳态数目是多少（取最接近的整数）？
::: solution
$\delta = \ln2/6 = 0.1155\ \mathrm{h^{-1}}$，所以 $m^* = 50/0.1155 = 432.8 \approx 433$。
:::
:::

::: exercise 激活倍数 {level=1 check="11"}
用 [[#eq-recruitment]]，$\omega = 21$、$[A] = K_A$，激活倍数是多少？
::: solution
$(1 + 21)/(1 + 1) = 11$。

::: exercise 维持性甲基化 {level=2 check="0.82"}
若每个甲基化的 CpG 每次分裂以 0.98 的概率被维持、失去后不再恢复，10 次分裂后有多大比例仍被甲基化（两位小数）？

$0.98^{10} = 0.817 \approx 0.82$。

::: exercise 增强子捕获的结果 {level=2}
一个携带最小启动子融合 *lacZ* 的转座子随机插入果蝇基因组。不同的插入株系在不同组织显示 β-半乳糖苷酶：一个在翅缘，另一个在眼。(a) 解释为什么这个自身没有增强子的报告基因会呈现种种模式。(b) 如何鉴定其增强子被"捕获"的基因？(c) 为什么这些株系作为工具也很有用？
::: solution
(a) 最小启动子被插入位点附近的任何增强子激活，而增强子可以在远距离、任一方向起作用；每个株系报告的是自己所在位置增强子的活性，常常复现附近某个基因模式的一部分。

(b) 定位插入位点（测侧翼 DNA 序列），列出周围域内的基因，用原位杂交把它们的表达与报告模式比较；候选基因的突变——可用转座子的不精确切离制造——可检验功能。

(c) 每个株系标记一个组织或细胞类型；若把报告基因换成一个转录激活蛋白如 Gal4，该株系就能在所标记的组织中驱动接在 UAS~G~ 后面的任何克隆基因（布兰德（Andrea Brand）与佩里蒙（Norbert Perrimon）1993 年的 Gal4/UAS 系统）。
:::
:::

::: exercise 铁的调控 {level=2}
预言下列细胞中铁蛋白与转铁蛋白受体的蛋白质水平（高或低）：(a) 缺铁；(b) 载铁；(c) 表达一个不论铁如何都结合 IRE 的突变 IRP。分别解释。
::: solution
(a) 低铁：IRP 结合 IRE。铁蛋白的翻译被阻断（5′ IRE）：铁蛋白低。转铁蛋白受体 mRNA 被稳定（3′ IRE）：受体高。细胞吸收铁而几乎不储存。

(b) 高铁：IRP 放开 IRE。铁蛋白被翻译：高。受体 mRNA 被降解：低。

(c) IRP 组成型结合：不论铁的供应如何，铁蛋白低而转铁蛋白受体高，所以细胞不断输入铁而不储存，导致细胞质铁超载。
:::
:::

::: exercise 设计一个 RNAi 实验 {level=3}
你向线虫注射对应其某个基因第 3 号外显子的 dsRNA，在子代中观察到胚胎致死。(a) 要把表型归因于这个基因的丢失，需要什么对照？(b) 该基因有一个旁系同源基因，两者在第 3 号外显子的核苷酸一致性为 85 %。这如何让解释变复杂，你该怎么办？(c) 为什么线虫中的 RNAi 影响子代并在组织间扩散，而哺乳动物细胞系中的合成 siRNA 只在那一个细胞中起作用？
::: solution
(a) 注射不相干的 dsRNA（例如来自线虫基因组中不存在的基因，如 GFP），以对照注射与 dsRNA 本身的效应；用同一基因另一区段的第二条不重叠的 dsRNA，应得到相同表型；测定靶 mRNA（RT-qPCR）确认敲低；如有条件，与遗传的功能缺失突变体比较。

(b) 长 dsRNA 会被切成许多 siRNA，85 % 的一致性下其中一些会在 20 个以上核苷酸上与旁系同源基因完全匹配，所以两个基因可能都被沉默；表型可能反映其中任一个或两个的丢失。应改用两基因有差异区段（如 3′ UTR）的 dsRNA，分别检验两者的敲低，或使用突变体。

(c) 线虫有 RNA 依赖的 RNA 聚合酶，能以靶 mRNA 为模板制造次级 siRNA，放大信号；还有 dsRNA 转运蛋白（SID-1），把沉默 RNA 在细胞间及进入生殖系运输；于是沉默可经小 RNA 遗传若干代。哺乳动物细胞既无放大步骤也无系统性运输，所以合成的 siRNA 随细胞分裂被稀释，只在转染的细胞中起几天作用。
:::
:::

::: exercise 解读 ChIP-seq 与 RNA-seq 的比较 {level=3}
在小鼠胚胎干细胞中，2000 个发育调控基因的启动子同时带有 H3K4me3 与 H3K27me3（"双价"），以低水平表达。当细胞分化为神经元时，集合中的神经基因失去 H3K27me3 并被高水平表达，而集合中的非神经基因失去 H3K4me3 并保持沉默。(a) 这些观察对双价标记的作用有什么提示？(b) 为什么这一相关不能证明标记控制表达？(c) 提出一个检验因果的实验。
::: solution
(a) 双价启动子似乎处于待命状态：被 Polycomb（H3K27me3）保持沉默，但同时因 H3K4me3 处于一种状态，一旦选定合适的谱系就能被迅速激活，否则被完全沉默。双价性的解除伴随着谱系的决定。

(b) 标记可能跟随转录的变化而非导致它：谱系特异转录因子的激活也许随之除去 H3K27me3，沉默也许导致 H3K4me3 丢失。时间上的相关不能揭示方向。

(c) 直接操纵标记并观察表达是否随之改变：删除或抑制 PRC2（如 *Eed* 或 *Ezh2* 敲除），问双价基因在干细胞中是否去阻遏；或用催化失活的 Cas9 融合 PRC2 组分、或一种 H3K27me3 特异的去甲基化酶，拴系到单个双价启动子上，测定该基因的转录。若表达改变恰与标记在该位点的改变同步发生，则标记在该位点是因果的。
:::
