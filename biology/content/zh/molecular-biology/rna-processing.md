在细菌中，mRNA 的 5′ 端一从聚合酶中出来，就可供翻译了。转录还在进行，核糖体就已结合上去。真核基因则不然。它的前体转录物在 5′ 端加上帽，其大部分长度被切出并丢弃，在 3′ 端被切开并接上 poly(A) 尾，有时还要被编辑，而且必须先运出细胞核，核糖体才能看到它。这一切都在 RNA 尚合成之中时发生。每一步都提供一个控制点，而这些步骤上的不同选择使一个基因能产生几种不同的蛋白质。

本章沿着一张前体 mRNA（pre-mRNA）从头走到尾，从加帽到输出。最详细讨论的是剪接：它的化学、剪接体、自我剪接内含子与可变剪接。然后讨论 3′ 端形成、RNA 编辑、摧毁缺陷 mRNA 的质量控制，以及核糖体 RNA 与转运 RNA 的加工。RNA 聚合酶 II 的转录——其 C 端结构域协调其中许多事件——见 [[molecular-biology/transcription]]。

## 断裂基因

1977 年，两个研究人细胞中腺病毒晚期 mRNA 的组发现了谁也没有预料到的东西。麻省理工学院的贝尔热（Susan Berget）、穆尔（Claire Moore）与夏普（Phillip Sharp），以及冷泉港的周文（Louise Chow）、杰利纳斯（Richard Gelinas）、布罗克（Thomas Broker）与罗伯茨（Richard Roberts），把 mRNA 与其来源的病毒 DNA 杂交，并在电镜下观察杂交体。他们看到的不是连续的双链，而是 mRNA 与 DNA 的几个分离区段配对，其间夹着未配对的 DNA 环。mRNA 的 5′ 端（"前导序列"）由相隔数千碱基对编码的片段拼合而成。几个月之内，在细胞自身的基因——如 β-珠蛋白与卵清蛋白——中也发现了同样的情况。吉尔伯特（Walter Gilbert）为保留下来的区段取名**外显子**，为被除去的取名**内含子**（1978）。夏普与罗伯茨分享 1993 年诺贝尔生理学或医学奖。

::: definition 外显子、内含子与 pre-mRNA {#def-intron}
**断裂基因**转录出的**前体 mRNA（pre-mRNA）**含有留在成熟 RNA 中的**外显子**和被**剪接**除去的**内含子**。边界是位于内含子 5′ 端的 **5′ 剪接位点**（供体）与位于其 3′ 端的 **3′ 剪接位点**（受体）。在绝大多数核 pre-mRNA 内含子中，内含子以 `GU` 开始、以 `AG` 结束（**GU–AG 规则**）。脊椎动物更完整的共有序列，5′ 剪接位点为 `AG|GURAGU`（| 表示边界，R 为嘌呤），3′ 剪接位点为 `YAG|G`，其上游是**嘧啶富集区**和一个位于上游约 18–40 个核苷酸处、含有**分支点腺苷**的**分支点序列** `YNYURAY`（在酵母共有序列 `UACUAAC` 中该腺苷加下划线，它是最后一个 A）。
:::

外显子与内含子不只是脊椎动物的奇闻。在所检查的一切真核生物中都有内含子，尽管出芽酵母只有约 280 个基因带内含子（总共约 6000 个），而且大多数只有一个。一个人的典型蛋白质编码基因约有十个外显子，平均每个约 150 bp，其间是平均几千碱基对长的内含子（Alberts，第 7 版，表 4-1）。编码序列是内含子海洋中的一个小岛。

## 剪接的化学

::: proposition 两次转酯反应完成剪接 {#prop-splicing}
核 pre-mRNA 内含子与 Ⅱ 组自我剪接内含子经两次连续的**转酯反应**被除去：
1. 分支点腺苷的 2′-OH 进攻 5′ 剪接位点处的磷酸。5′ 外显子带着一个游离的 3′-OH 被释放，内含子的 5′ 端通过一个 **2′–5′ 磷酸二酯键**连到分支点 A 上，形成一个**套索**中间体（分支 A 于是有三个磷酸二酯键：2′、3′ 与 5′）。
2. 5′ 外显子的 3′-OH 进攻 3′ 剪接位点处的磷酸，把两个外显子以正常的 3′–5′ 键连接起来，并把内含子以套索形式释放。套索随后被去分支并降解。

每一步都是一种磷酸二酯键换成另一种，所以磷酸二酯键总数不变，化学本身不消耗 ATP。剪接体消耗的 ATP 驱动的是其构象重排，不是成键。
:::

套索于 1984 年由几组实验室（帕杰特（Padgett）、科纳尔斯卡（Konarska）、格拉博夫斯基（Grabowski）、哈代（Hardy）与夏普；拉斯金（Ruskin）、克雷纳（Krainer）、马尼亚蒂斯（Maniatis）与格林（Green）；多姆迪（Domdey）、阿贝尔森（Abelson）及同事在酵母中）鉴定：体外释放的内含子 RNA 在胶上迁移异常，并且有一端抗核酸外切酶。因为化学上这不过是键的简单交换、原则上可逆，所以它可以由 RNA 催化。

### 自我剪接内含子：RNA 作为催化剂

1982 年，切赫（Thomas Cech）实验室发现，纤毛虫四膜虫（*Tetrahymena thermophila*）大 rRNA 前体中的内含子在试管中不需要任何蛋白质就能自行除去，只需要 Mg²⁺ 与一个鸟苷核苷酸。第一个亲核试剂是鸟苷的 3′-OH 而不是分支 A，所以内含子以线性分子的形式释放（随后环化）。这是第一个**核酶（ribozyme）**。它与奥尔特曼（Sidney Altman）关于核糖核酸酶 P 的 RNA 亚基是 tRNA 加工催化剂的发现（格雷耶-高田（Cecilia Guerrier-Takada）、奥尔特曼及同事，1983）一道，表明 RNA 可以是酶。切赫与奥尔特曼分享 1989 年诺贝尔化学奖。

**Ⅰ 组内含子**使用一个外源鸟苷。**Ⅱ 组内含子**发现于真菌与植物的细胞器基因以及某些细菌中，使用分支 A 并形成套索，与核内含子完全一样。Ⅱ 组内含子与剪接体共享化学机制和催化结构的部分。剪接体的 snRNA U6 像 Ⅱ 组内含子的结构域 V 那样协调催化金属离子（Fica 等，2013）。因此剪接体被认为是自我剪接的 Ⅱ 组内含子在蛋白质协助下的后裔，也许是侵入了早期真核生物基因组——来自线粒体的细菌祖先——的一个内含子。

### 剪接体

::: definition 剪接体 {#def-spliceosome}
核 pre-mRNA 内含子由**剪接体**除去。剪接体是一个动态复合体，由五个**小核核糖核蛋白（snRNP：U1、U2、U4、U5 与 U6，每种是一条 snRNA 加上蛋白质）**和一百多种其他蛋白质组成。它在每个内含子上按有序途径重新组装：
1. **U1 snRNP** 与 5′ 剪接位点碱基配对；蛋白质 SF1 结合分支点，**U2AF** 结合嘧啶富集区与 3′ 剪接位点的 AG（E 复合体）。
2. **U2 snRNP** 取代 SF1，并与分支点碱基配对，使分支点 A 从双链中鼓出，其 2′-OH 作为亲核试剂就位（A 复合体）。
3. **U4/U6·U5 三 snRNP** 加入（B 复合体）。由 RNA 解旋酶消耗 ATP 驱动的大规模重排释放 U1 与 U4。随后 U6 与 5′ 剪接位点以及 U2 配对，形成催化核心（B^act^ 与 C 复合体）。U5 抓住两个外显子。
4. 进行两次转酯反应。剪接好的 mRNA 被释放，套索与 snRNP 被释放并回收。
:::

是 RNA–RNA 碱基配对界定剪接位点，这一点由补偿性突变证明。庄艳（Yan Zhuang）与韦纳（Alan Weiner）（1986）发现，一个阻断剪接的 5′ 剪接位点突变，可以被 U1 snRNA 中一个恢复碱基配对的相应突变抑制。这些重排使剪接体动作缓慢，所以每个内含子的剪接要花数十秒到几分钟。它们也给剪接体提供了许多校对检查点，因为解旋酶可以剔除一个匹配不佳的中间体。**次要剪接体**以 U11、U12、U4atac 与 U6atac 取代 U1、U2、U4 与 U6，但共享 U5，除去一类共有序列不同、约占人内含子 0.5 % 的罕见内含子（最初依其末端二核苷酸称为 AT–AC 内含子）。冷冻电镜（约 2015 年起，施一公（Yigong Shi）、永井雅司（Kiyoshi Nagai）与吕尔曼（Reinhard Lührmann）等的组等）现已以近原子分辨率捕捉到循环中的大多数阶段。

::: example 剪接一张 pre-mRNA {#ex-splice}
一张玩具 pre-mRNA 由外显子 1（9 nt）、内含子 1（30 nt）、外显子 2（60 nt）、内含子 2（29 nt）与外显子 3（53 nt，含正常终止密码子和 3′ 非翻译区）组成。内含子 1 是 `GUAAGUAUCCUUACUAACUUUUCCUUUCAG`。(a) 找出它的 5′ 与 3′ 剪接位点二核苷酸、分支点和嘧啶富集区。(b) 成熟 mRNA 有多长？外显子 2 与外显子 3 的连接点位于哪个位置（以起始密码子的 A 为 0 起计）？(c) 若分支点 A 突变为 G，你预言会发生什么？（真实的人内含子很少短于约 70 nt；这里为清楚起见缩短了。）
::: solution
(a) 它以 `GU`（5′ 剪接位点，`GUAAGU`，与共有序列 `GURAGU` 完美匹配）开始，以 `AG`（3′ 剪接位点，`CAG`）结束。序列 `UACUAAC` 是酵母型分支点，分支点 A 是其中最后一个 A。其后是富含嘧啶的 `UUUUCCUUUC`，然后是末端 `AG`。

(b) 成熟 mRNA 长 $9 + 60 + 53 = 122$ nt。外显子 2 与外显子 3 的连接点在 $9 + 60 = 69$ nt 之后，即位置 69。

(c) 第一次转酯反应需要分支 A 的 2′-OH。若 A 被 G 取代，U2 snRNA 的配对与第一步会严重受损。剪接体可能以附近一个效率较低的隐秘分支点（通常是一个 A）来凑合；否则内含子保留，转录本被降解或未剪接输出。在酵母中，这类突变阻断第一步，pre-mRNA 积累。
:::
:::

```python
# 剪接一张玩具 pre-mRNA，并应用无义介导降解的 50 个核苷酸规则
STOPS = {"UAA", "UAG", "UGA"}

def splice(pre, introns):
    """introns: (start, end) 列表，0 基，右开；每个都必须形如 GU...AG"""
    exons, pos = [], 0
    for s, e in sorted(introns):
        assert pre[s:s+2] == "GU" and pre[e-2:e] == "AG", "not a GU-AG intron"
        exons.append(pre[pos:s])
        pos = e
    exons.append(pre[pos:])
    return exons

def nmd_check(exons):
    mrna = "".join(exons)                     # 翻译从位置 0（AUG）开始
    stop = next(i for i in range(0, len(mrna) - 2, 3) if mrna[i:i+3] in STOPS)
    last_junction = sum(len(x) for x in exons[:-1])
    return stop, last_junction, last_junction - stop > 50

ex1 = "AUGGCCAAG"                                              # 9 nt
in1 = "GUAAGUAUCCUUACUAACUUUUCCUUUCAG"                         # 30 nt，分支点 UACUAAC
ex2 = "GAUUCUGGAAAGCCGACCUGCGUGCUAUCUGGUACCAUCGUUUCGGAGGCAAAGAUCUGG"  # 60 nt
in2 = "GUGAGUCCUGCUAACCCUUUCUCUCCCAG"                          # 29 nt
ex3 = "GCUGGUGCAGCCCAAGGACGGCAAGUUCAGCGGCACUAAGCCACGAAUAAAGC"   # 终止密码子 UAA，然后是 3' UTR
introns = [(9, 39), (99, 128)]

variants = [("normal", ex2), ("mutant A", ex2[:3] + "UAG" + ex2[6:]), ("mutant B", ex2[:30] + "UGA" + ex2[33:])]
for name, e2 in variants:
    pre = ex1 + in1 + e2 + in2 + ex3
    exons = splice(pre, introns)
    stop, junction, nmd = nmd_check(exons)
    print(f"{name:8s}: exons {[len(x) for x in exons]}, stop at {stop}, "
          f"last junction at {junction}, NMD predicted: {nmd}")
```

```
normal  : exons [9, 60, 53], stop at 105, last junction at 69, NMD predicted: False
mutant A: exons [9, 60, 53], stop at 12, last junction at 69, NMD predicted: True
mutant B: exons [9, 60, 53], stop at 39, last junction at 69, NMD predicted: False
```

最后两行预告了下面要解释的无义介导降解规则。突变体 A 的提前终止密码子位于最后一个外显子连接点上游 57 个核苷酸处，预计其 mRNA 会被降解。突变体 B 的提前终止密码子只在上游 30 个核苷酸处，所以它的 mRNA 预计会逃脱降解，并合成一个截短的蛋白质。

## 可变剪接

若每个内含子都被除去、每个外显子都被保留，剪接就只是一桩杂务。实际上许多 pre-mRNA 能以一种以上的方式剪接，而且这种选择是受调控的。

::: definition 可变剪接的方式 {#def-alternative}
- **盒式外显子（cassette exon）**：在某些 mRNA 中被包含，在另一些中被跳过。
- **互斥外显子**：两个或多个外显子中恰有一个被包含。
- 外显子内的**选择性 5′ 或 3′ 剪接位点**改变其长度。
- **内含子保留**：一个内含子留在 mRNA 中。
- 选择性**启动子**（首外显子）与选择性**多聚腺苷酸化位点**（末外显子）改变 mRNA 的两端。严格说这些是转录与 3′ 加工上的选择，但它们与剪接组合在一起。

一个盒式外显子的 **剪接入比例**（PSI，Ψ）是该基因的 mRNA 中包含它的比例。
:::

::: proposition 由 RNA-seq 连接读段估计 PSI {#prop-psi}
设 $I$ 为跨过包含一个盒式外显子的两个连接点（上游外显子到盒式外显子、盒式外显子到下游外显子）的测序读段数，$E$ 为跨过单一跳过连接点（上游外显子直连下游外显子）的读段数。若读段按每种异构体的连接点数成比例抽样，且每个连接点产生读段的机会均等，则
$$
\hat\Psi = \frac{I/2}{I/2 + E}.
$$ {#eq-psi}
因子 2 校正的是包含异构体有两个连接点、而跳过异构体只有一个。这个估计假定各个连接点的可比对性相同，并忽略落在外显子主体内的读段。
:::

可变剪接在脊椎动物中极其普遍。2008 年的两项 RNA-seq 研究（潘群（Qun Pan）、布伦科（Benjamin Blencowe）及同事；王恩歌（Eric Wang）、伯奇（Christopher Burge）及同事）发现证据表明，约 95 % 的人多外显子基因产生一种以上的剪接形式，其中许多在不同组织之间有别。这些异构体中有多少合成功能上有区别的蛋白质，就不太清楚了。许多只是次要的，有些很可能只是细胞容忍的错误。蛋白质组学检出的可变蛋白质形式远比 RNA-seq 检出的 mRNA 少。

剪接位点的选择由外显子与内含子中的序列调控，即**外显子与内含子剪接增强子和沉默子**，由蛋白质结合。**SR 蛋白**带有富含丝氨酸-精氨酸二肽的结构域，通常结合外显子增强子并促进附近位点的使用，办法是帮助 U1 与 U2AF 结合。**hnRNP** 蛋白通常结合沉默子并起抑制作用。神经元中 NOVA 与 RBFOX 这类组织特异调控因子，以及通用因子的相对浓度，进而决定每种细胞类型的剪接模式。因为剪接与转录同时发生，Pol II 的延伸速率也重要：一个慢速聚合酶给较弱的上游剪接位点更多时间，赶在下游更强的竞争者被转录出来之前被识别（动力学偶联）。

::: example 果蝇的性别决定 {#ex-sxl}
在黑腹果蝇（*Drosophila melanogaster*）中，性别由一个可变剪接级联决定（见 [[developmental-biology]]）。雌性特有的蛋白质 Sex-lethal（Sxl）结合 *transformer*（*tra*）的 pre-mRNA，阻断一个 3′ 剪接位点的使用。在没有 Sxl 的雄性中，该位点被使用，mRNA 中含有一个终止密码子，所以没有功能性 Tra 蛋白。雌性使用下游另一个 3′ 位点，产生有功能的 Tra。Tra 与 Tra-2 一起结合 *doublesex*（*dsx*）pre-mRNA 中的一个外显子剪接增强子，激活一个雌性特异的外显子，产生 Doublesex 的雌性形式。没有 Tra 时，默认剪接产生雄性形式。(a) 预言对 *tra* 一个缺失突变纯合的 XX 蝇的表型。(b) 预言用一个转基因组成表达 Tra 蛋白的 XY 蝇的表型。(c) 哪些步骤涉及剪接抑制子，哪些涉及激活子？
::: solution
(a) XX *tra*⁻ 蝇能制造 Sxl 却不能制造 Tra，所以 *dsx* 按默认（雄性）模式剪接：它们外表发育为雄性（它们不育，因为生殖系还受其他基因影响）。斯特蒂文特（Alfred Sturtevant）1945 年描述了这一个使性别转化的突变。

(b) Tra 与 Tra-2 一起激活雌性 *dsx* 外显子，所以组成表达 Tra 的 XY 蝇在体细胞中发育为雌性。

(c) Sxl 充当剪接抑制子：它阻断 *tra* 以及它自己 pre-mRNA 中的一个 3′ 剪接位点，并通过一个正反馈环维持雌性中 Sxl 的生产。Tra 与 Tra-2 充当激活子：它们把 SR 蛋白募集到 *dsx* 的一个增强子上，促进一个弱的雌性特异 3′ 剪接位点的使用。
:::
:::

::: example Dscam 基因 {#ex-dscam}
果蝇基因 *Dscam*（唐氏综合征细胞黏附分子）含有四个互斥外显子簇：外显子 4 有 12 种选择，外显子 6 有 48 种，外显子 9 有 33 种，外显子 17 有 2 种（施穆克（Dietmar Schmucker）、普珀斯基（Larry Zipursky）及同事，2000）。(a) 能造出多少种不同的 mRNA？(b) 这与蝇基因组约 14 000 个蛋白质编码基因相比如何？(c) 这么多异构体有什么用？
::: solution
(a) 不同簇上的选择彼此独立，所以组合数为 $12\times48\times33\times2 = 38\,016$。

(b) 一个基因所能编码的不同蛋白质异构体数目，比基因组中的基因总数还多出一倍以上。（外显子 4、6 与 9 编码三个免疫球蛋白结构域的部分；外显子 17 编码跨膜结构域。）

(c) 每个神经元表达一小组随机的异构体。Dscam 蛋白只与其他膜上与自身完全相同的异构体结合，所以同一个神经元的分支相互识别并排斥（"自我回避"），而带有不同异构体的不同神经元的分支则可以重叠。异构体的多样性赋予每个细胞一个分子身份。
:::
:::

::: warning "可变剪接解释了为什么基因数目相同的果虫与人，人更复杂"
人有约 20 000 个蛋白质编码基因，线虫（*C. elegans*）也有大约同样多，而可变剪接在脊椎动物中更普遍。人们很容易下结论说，剪接弥补了"复杂度"上的差距。证据并不支持这么简单的一套说法。许多可变异构体稀少或只限于某组织，其蛋白质产物常常检不到。生物体的复杂程度还取决于调控 DNA、基因调控网络、蛋白质相互作用以及许多别的东西。可变剪接确实在特定基因中增添了重要的功能多样性——*dsx* 与 *Dscam* 便是明证——但数异构体不是复杂度的度量。
:::

::: quiz
对一个盒式外显子，脑组织的 RNA-seq 给出跨过两个包含连接点的读段 300 条、跨过跳过连接点的读段 50 条。估计的 PSI 是多少？
- [ ] 0.86
- [x] 0.75
- [ ] 0.50
- [ ] 0.14
::: solution

:::

## 5′ 帽与 3′ 端

::: definition 帽与 poly(A) 尾 {#def-cap-polya}
- **5′ 帽**是一个 7-甲基鸟苷，通过一条不寻常的 **5′–5′ 三磷酸**桥连到 RNA 的第一个核苷酸上，即 m⁷GpppN。在脊椎动物中，第一个（常常还有第二个）转录核苷酸的核糖还发生 2′-O-甲基化。帽在 RNA 只有约 20–30 个核苷酸长时就已加上，执行反应的酶被募集到 Pol II 的 Ser5 磷酸化 CTD 上：一个 RNA 三磷酸酶、一个鸟苷酰转移酶和一个甲基转移酶。
- **poly(A) 尾**在 pre-mRNA **切割**之后添加。**切割与多聚腺苷酸化特异性因子**（CPSF）结合位于切割位点上游 10–30 个核苷酸处的信号 `AAUAAA`（或其变体如 `AUUAAA`）。切割刺激因子（CstF）结合下游一个 G/U 富集元件。切割后，**poly(A) 聚合酶**在哺乳动物中加入约 200–250 个腺苷酸（酵母的尾更短），核内 poly(A) 结合蛋白控制其数目。后生动物的组蛋白 mRNA 是一个例外：它们以茎环结构结尾，而不是 poly(A) 尾。
:::

帽保护 mRNA 免于 5′→3′ 核酸外切酶，为它打上输出的标记，并在细胞质中募集翻译起始因子 eIF4E（[[molecular-biology/translation]]）。poly(A) 尾与细胞质 poly(A) 结合蛋白（PABP）结合，保护 3′ 端，同时也促进翻译。PABP 与结合在帽上的起始因子 eIF4G 相互作用，于是 mRNA 形成一个闭合环。多数 mRNA 的降解始于 poly(A) 尾的缩短（**去腺苷酸化**），随后是去帽与 5′→3′ 降解，或者由外切体进行 3′→5′ 降解。许多基因有一个以上的多聚腺苷酸化位点。**可变多聚腺苷酸化**改变 3′ 非翻译区的长度，连同 microRNA 与调控蛋白的结合位点一起改变（[[molecular-biology/eukaryotic-gene-regulation]]）。

::: example 剪接效率重要吗？ {#ex-splice-accuracy}
设一个基因的每个内含子以概率 $p$ 被正确剪接，彼此独立。(a) 一个有 10 个内含子的基因，若 $p = 0.99$，其转录本有多大比例在每一个内含子上都正确？若 $p = 0.999$ 呢？(b) 拥有最多外显子的人基因 *TTN*（连蛋白）有 360 多个外显子。要让它一半的转录本完美无缺，需要多大的 $p$？(c) 评述细胞如何应付这一点。
::: solution
(a) $0.99^{10} = 0.904$，$0.999^{10} = 0.990$。

(b) 需要 $p^{360} = 0.5$，所以 $p = 0.5^{1/360} = 0.99808$：每个内含子的错误率须低于 0.2 %。

(c) 这个算术说明了为什么每个内含子的剪接都必须高度准确，以及为什么错误必须在事后被抓出来。有缺陷的 mRNA——尤其是带提前终止密码子的——被无义介导的 mRNA 降解除去。外显子定义（因子横跨短外显子两端把它们识别出来）与转录同时进行的剪接——内含子按被合成的次序依次除去——使长基因不至于失控。即便如此，任何一个基因总有一部分转录本是错误剪接的。
:::
:::

## 编辑、输出与质量控制

### RNA 编辑

**RNA 编辑**以剪接以外的方式在转录之后改变 RNA 的序列。哺乳动物中有两类很常见。

- **C 变 U 编辑。** 载脂蛋白 B（apolipoprotein B）mRNA 在小肠中被胞苷脱氨酶 **APOBEC1** 编辑，把一个 C 变为 U，使 2153 号密码子 `CAA`（Gln）变成一个终止密码子 `UAA`。肝脏制造全长 4536 个氨基酸的 apoB-100。小肠用同一个基因制造 apoB-48，即其 N 端的 48 %（陈良（Lawrence Chan）与斯各特（James Scott）两实验室，1987）。
- **A 变 I 编辑。** **ADAR** 酶（作用于 RNA 的腺苷脱氨酶）把 RNA 双链区域的腺苷变为肌苷。核糖体把肌苷读作 G，所以编码序列内的编辑可以改变氨基酸。在哺乳动物脑中，谷氨酸受体亚基 GluA2（基因 *GRIA2*）几乎每一条转录本都在一个位点被编辑，把一个谷氨酰胺密码子（`CAG`）变为精氨酸（`CIG`，读作 `CGG`）。这个"Q/R 位点"使通道对 Ca²⁺ 不通透（斯普伦格尔（Rolf Sprengel）、泽堡（Peter Seeburg）及同事，1991）。不能编辑这个位点的小鼠幼年即死于癫痫发作，而把基因组中该密码子改为精氨酸密码子可以挽救这一表型。

最大规模的编辑见于锥虫的线粒体，其中一些 mRNA 插入或删除了数百个尿苷，由与转录物配对的短**向导 RNA**引导（本内（Rob Benne）及同事 1986 年发现）。

### 输出与无义介导的降解

只有完全加工好的 mRNA 才离开细胞核。剪接在每个外显子-外显子连接点上游约 20–24 个核苷酸处往 mRNA 上安放一个**外显子连接复合体**（EJC）（勒伊尔（Hervé Le Hir）、穆尔（Melissa Moore）及同事，2000）。EJC、帽结合蛋白与 **TREX** 复合体募集输出受体 NXF1–NXT1，后者带着 mRNA 穿过核孔复合体（[[cell-biology/protein-sorting]]）。未剪接的 pre-mRNA 被结合在其剪接位点上的蛋白截留，并被核外切体（exosome）降解。

::: definition 无义介导的 mRNA 降解（NMD） {#def-nmd}
**无义介导的 mRNA 降解（NMD）**降解含有提前终止密码子的 mRNA。在哺乳动物中，第一轮（"先驱"）翻译期间，核糖体沿 mRNA 移动时逐一把 EJC 赶下。若它停在一个位于**最后一个外显子-外显子连接点上游约 50–55 个核苷酸以外**的密码子处，就至少还有一个 EJC 留在下游。那个 EJC 通过结合在终止核糖体上的蛋白质 UPF1，把 mRNA 标记为迅速降解。位于最后一个外显子内、或在最后一个连接点上游约 50 个核苷酸以内的终止密码子不会留下 EJC，也不触发 NMD（纳吉（Elisabeth Nagy）与马夸特（Lynne Maquat），1998）。
:::

NMD 塑造突变影响表型的方式。一个基因较早处的无义或移码突变通常导致 mRNA 丢失，所以该等位基因表现为无效等位基因，典型地为隐性。最后一个外显子中的提前终止能逃脱 NMD，产生一个截短蛋白质，它可能表现显性负效应。NMD 也调控正常基因。一些可变剪接事件故意引入一个提前终止密码子来关闭基因，这一策略称为**偶联 NMD 的可变剪接**，许多剪接调控因子就是这样控制自身水平的。

## 核糖体 RNA 与转运 RNA 的加工

三种最大的真核 rRNA 在**核仁**中由一条 Pol I 转录物——**45S 前体 rRNA**（人约 13 kb）——剪切而来。核酸内切酶与外切酶按确定的次序把它加工成 18S、5.8S 与 28S rRNA，它们与核糖体蛋白质以及单独转录的 5S rRNA 装配。加工途中约有一百个核苷酸被修饰，由与 rRNA 配对的**小核仁 RNA**（snoRNA）引导。**C/D 盒 snoRNA** 指导核糖的 2′-O-甲基化，**H/ACA 盒 snoRNA** 指导尿苷转变为假尿苷。许多 snoRNA 编码在其他基因的内含子里，经剪接与加工释放。在细菌中，16S、23S 与 5S rRNA 以及常常还有 tRNA，由 RNase III 与其他核酸酶从每个 *rrn* 操纵子的一条转录物上切下。

转运 RNA 以两端都带有额外序列的前体形式合成。**RNase P** 的 RNA 亚基是催化剂，切去 5′ 前导序列。3′ 尾区被修剪，末端氨基酸所连接的 3′ 端 `CCA` 由 CCA 添加酶加上（在真核生物中它不是由基因编码的）。许多碱基被修饰（假尿苷、二氢尿苷、某些反密码子摆动位置上的肌苷；[[molecular-biology/translation]]）。一些 tRNA 基因在反密码子旁边含一个短内含子，它不由剪接体除去，而由专门的 tRNA 剪接核酸内切酶与连接酶处理。

::: application 剪接与治疗
约 10–15 % 引起人类遗传病的突变影响剪接——破坏一个剪接位点、创造一个新的、或改变一个增强子或沉默子。这使剪接成为一个治疗靶点。**反义寡核苷酸**是能与 pre-mRNA 配对的短修饰核酸，可以阻断一个剪接位点或一个沉默子。诺西那生（nusinersen）2016 年获批用于脊髓性肌萎缩症：它阻断 *SMN2*（缺陷基因 *SMN1* 的旁系同源基因）外显子 7 之后内含子中的一个沉默子，使外显子 7 得以包含，从而合成功能性 SMN 蛋白。用于杜氏肌营养不良某些类型的跳外显子寡核苷酸使一个发生移码的外显子被跳过，恢复 *DMD* 的阅读框，产生一个较短但部分有功能的抗肌萎缩蛋白。也有改变剪接的小分子获批。临床方面见医学图谱（[/learn/medicine/](/learn/medicine/)）。其分子原理正是本章的主题。
:::

::: history
贝尔热、穆尔与夏普，以及周文、杰利纳斯、布罗克与罗伯茨，1977 年在腺病毒中发现断裂基因；5′ 帽早两年已由沙特金（Aaron Shatkin）、古渕康弘（Yasuhiro Furuichi）及同事等在用病毒与细胞 mRNA 的工作中标征。吉尔伯特 1978 年创造了 intron 与 exon 两个词。斯泰茨（Joan Steitz）及同事 1980 年提出 U1 snRNA 通过碱基配对识别 5′ 剪接位点。切赫组 1982 年报道了四膜虫自我剪接内含子，奥尔特曼组 1983 年报道了 RNase P 的催化 RNA。包括夏普、马尼亚蒂斯与格林、阿贝尔森在内的几个实验室 1984 年鉴定了套索。庄艳与韦纳 1986 年用补偿性突变证明了 U1–5′ 剪接位点配对，同一年本内组发现了锥虫的 RNA 编辑。纳吉与马夸特 1998 年提出了 NMD 的 50 个核苷酸规则。
:::

::: summary
- 真核 pre-mRNA 被加帽（m⁷GpppN，在约 20–30 nt 时加上）、剪接、切割并多聚腺苷酸化（`AAUAAA`，哺乳动物约 200–250 个 A），全部与转录同时发生，由 Pol II CTD 协调。
- 内含子经两次转酯反应除去：分支点 A 的 2′-OH 进攻 5′ 剪接位点（套索中间体），然后 5′ 外显子的 3′-OH 进攻 3′ 剪接位点。磷酸二酯键无净增减。多数内含子是 GU…AG。
- 剪接体（U1、U2、U4/U6、U5 snRNP 加许多蛋白质）靠 RNA–RNA 配对识别剪接位点，靠 ATP 驱动的解旋酶重排，以 U6 为催化核心。它很可能源自 Ⅱ 组自我剪接内含子。Ⅰ 组内含子使用鸟苷。核酶证明 RNA 可以是催化剂。
- 可变剪接（盒式外显子、互斥外显子、选择性位点、内含子保留）影响大多数人多外显子基因，由结合增强子与沉默子的 SR 蛋白、hnRNP 与组织特异因子调控。由连接读段得到的 PSI 为 $(I/2)/(I/2 + E)$。
- RNA 编辑改变编码信息：apoB mRNA 的 C→U（apoB-48）、GluA2 的 A→I（Q/R 位点）。
- 外显子连接复合体为剪接过的 mRNA 打上输出标记，并使终止密码子位于最后一个外显子连接点上游约 50–55 nt 以外的 mRNA 发生无义介导降解。
- rRNA 从长前体上切下，并在 snoRNA 指引的位点被修饰；tRNA 被修剪（RNase P）、加上 3′ CCA、被修饰，有时由另一套独立的酶系统剪接。
:::

## 练习

::: exercise 成熟 mRNA 的长度 {level=1 check="1850"}
一个基因有四个长 250、400、300 与 900 nt 的外显子，其间由长 2.1、5.6 与 0.8 kb 的三个内含子隔开。成熟 mRNA（不含 poly(A) 尾）有多长？
::: solution
$250 + 400 + 300 + 900 = 1850$ nt；内含子（$8.5$ kb）被除去。
:::
:::

::: exercise 剪接中的键 {level=1}
除去一个内含子时打破多少个磷酸二酯键、形成多少个？为什么剪接成键不需要能量？
::: solution
打破两个（在 5′ 与 3′ 剪接位点），形成两个（2′–5′ 分支键与外显子-外显子键）。每一步都是把一种键换成自由能相近的另一种键的转酯反应，所以反应几乎能量中性；ATP 是被剪接体的解旋酶用于组装、重排与校对的，不是用于化学反应。
:::
:::

::: exercise 数异构体 {level=1 check="8"}
一个基因有三个独立调控的盒式外显子。仅凭这些选择它能产生多少种 mRNA 异构体？
::: solution
每个盒式外显子独立地要么包含、要么跳过：$2^3 = 8$ 种异构体。
:::
:::

::: exercise 由读段求 PSI {level=2 check="0.6"}
对一个盒式外显子，RNA-seq 给出跨过两个包含连接点的读段 120 条、跨过跳过连接点的读段 40 条。估计 PSI。
::: solution
$\hat\Psi = (120/2)/(120/2 + 40) = 60/100 = 0.6$。
:::
:::

::: exercise ApoB-48 {level=2 check="0.474"}
ApoB-100 有 4536 个氨基酸，编辑把 2153 号密码子变为终止密码子。apoB-48 含全长蛋白的多少比例（三位小数）？
::: solution
蛋白质止于第 2152 号残基：$2152/4536 = 0.474$，约 47–48 %，apoB-48 由此得名。
:::
:::

::: exercise 预言 NMD {level=2}
一个基因有五个外显子，在 mRNA 中长（依次）150、120、90、200 与 600 nt；起始密码子始于外显子 1 的第 50 位，正常终止密码子在外显子 5。用 50 个核苷酸规则，预言下列每个无义突变 mRNA 是否会被 NMD 降解，并给出终止密码子（第一个核苷酸）在 mRNA 中从 1 数起的位置：(a) 在外显子 2，mRNA 位置 200；(b) 在外显子 4，位置 520；(c) 在外显子 4，位置 400；(d) 在外显子 5，位置 700。
::: solution
最后一个外显子-外显子连接点（外显子 4 与 5 之间）位于 $150 + 120 + 90 + 200 = 560$ nt 之后。若终止密码子位于 560 号位上游 50 nt 以外，即大约位置 510 以前，则预期发生 NMD。(a) 200：上游 360 nt——NMD。(b) 520：上游 40 nt——无 NMD；合成截短蛋白。(c) 400：上游 160 nt——NMD。(d) 700：在最后一个外显子内——无 NMD。因此若截短蛋白干扰正常蛋白，突变 (b) 可能有显性效应，而 (a) 与 (c) 表现为无效等位基因。
:::
:::

::: exercise 解读一个剪接位点突变 {level=3}
某患者的成纤维细胞在一个基因内含子 6 的第一个核苷子上携带杂合改变，`GU` → `AU`。用外显子 5 与 8 中的引物做 RT-PCR，得到正常的 450 bp 产物和另外两条：330 bp 与 510 bp。外显子 6 长 120 nt，内含子 6 进入内含子 60 nt 处有一段 `GUGAGU`。(a) 解释每一种产物。(b) 哪种异常产物预计能逃脱 NMD？为什么它仍可能有害？(c) 提出一个不用患者材料、可证实这一解释的实验。
::: solution
(a) 突变破坏了内含子 6 的 5′ 剪接位点。450 bp 产物来自正常等位基因。330 bp 产物（$450 - 120$）缺少外显子 6：剪接体跳过失去供体位点的外显子，把外显子 5 接到外显子 7。510 bp 产物（$450 + 60$）是使用一个隐秘 5′ 剪接位点（`GUGAGU`，与共有序列匹配良好）的结果，该位点位于内含子进入 60 nt 处，使外显子 6 延长了 60 nt。

(b) 两种异常产物都保持阅读框（120 与 60 都是 3 的倍数），所以都不一定含有提前终止密码子；若插入的 60 个核苷酸框内没有终止密码子，510 bp 产物会逃脱 NMD，编码一个多 20 个氨基酸的蛋白质，而 330 bp 产物编码一个少 40 个氨基酸的蛋白质。两者都可能错误折叠或表现显性负效应。（若内含子序列中确有一个框内终止密码子，510 bp 的 mRNA 就会受 NMD。）

(c) 一个**迷你基因**测定：把外显子 5–7 连同其内含子（正常与突变版本）克隆进报告质粒，导入培养细胞，用 RT-PCR 分析剪接产物。进一步的检验是在突变型迷你基因中再突变那个隐秘位点，看 510 bp 产物是否消失。
:::

::: exercise 一个自我调控的剪接调控因子 {level=3}
一种 SR 蛋白结合它自己 pre-mRNA 一个选择性外显子中的增强子。包含该外显子会在最后一个外显子连接点很上游处引入一个提前终止密码子。(a) 画出这个反馈环，并说明它是正反馈还是负反馈。(b) 若该基因被复制加倍，预言蛋白质稳态水平的变化。(c) 为什么进化可能偏爱这样的环？
::: solution
(a) SR 蛋白增多 → "毒性"外显子（poison exon）的包含增多 → 含提前终止密码子的 mRNA 增多 → NMD 增多 → SR 蛋白减少。这是负反馈。

(b) 基因加倍起初使 pre-mRNA 加倍，但增多的蛋白质增加毒性外显子的包含，于是更大比例的 mRNA 被销毁；蛋白质的稳态水平上升远不到两倍（稳态调节）。已对多种 SR 蛋白与 hnRNP 证明存在这种自身调控，而毒性外显子是脊椎动物基因组中最保守的序列之一。

(c) 剪接调控因子作用于数千个靶标，其水平必须维持在狭窄范围内；负自身调控可以缓冲转录与基因剂量的波动，使整个剪接网络稳健。（对比转录因子的负自身调控，见 [[systems-biology/network-motifs]]。）
