当少数几种酶与物理方法使人们能够在选定的位点切割 DNA、把片段连接起来、成倍扩增它们、读出序列并看到它们在哪里表达时，分子生物学就从一门关于基因的理论变成了一门关于基因的实验科学。这些工具几乎全是从自然界借来的：限制酶来自防御噬菌体的细菌，连接酶与聚合酶来自 DNA 复制，逆转录酶来自逆转录病毒，绿色荧光蛋白来自一种水母，Cas9 来自细菌的适应性免疫系统。每一个都是先作为生物学被理解，之后才成为工具。

本章解释每种工具的工作原理以及它所测量的东西。内容包括限制酶与酶切作图、凝胶电泳、克隆、聚合酶链反应及其算术、测序、印迹与杂交、报告基因，以及用 CRISPR–Cas9 进行基因组编辑。讲解是概念性、定量的，停留在切割、扩增并测序无害 DNA 的教学实验课的层次。生产方法、合成生物学与基因工程的监管在 [[biotechnology/recombinant-dna]]、[[biotechnology/genome-editing]] 与 [[biotechnology/biosafety-ethics]] 中进一步展开。

## 限制酶

1950 年代初，卢里亚（Salvador Luria）与休曼（Mary Human），以及贝尔塔尼（Giuseppe Bertani）与韦格尔（Jean Weigle）注意到，一种噬菌体在某种细菌上增殖后，往往在另一种细菌上长得很差。少数获得成功的噬菌体随后在新菌株上长得好，可一旦再经过旧菌株传代就又不行了。阿伯（Werner Arber）在 1960 年代用**宿主控制的限制与修饰**解释了这一现象：细菌携带一种在特定序列切割 DNA 的酶，以及一个与之配对的甲基化酶，后者修饰自身 DNA 中的相同序列，使之不被切割。来自不含该甲基化酶的菌株的噬菌体 DNA 会被摧毁。1970 年，史密斯（Hamilton Smith）与威尔科克斯（Kent Wilcox）纯化了第一种在确定序列切割的酶——来自流感嗜血杆菌（*Haemophilus influenzae*）的 HindII。丹娜（Kathleen Danna）与纳森斯（Daniel Nathans）1971 年用这类酶把病毒 SV40 的 DNA 切成特定片段并为其作图。阿伯、史密斯与纳森斯分享 1978 年诺贝尔奖。

::: definition Ⅱ 型限制性内切核酸酶 {#def-restriction}
**Ⅱ 型限制性内切核酸酶（限制酶）**识别一段特定的 DNA 序列——通常长 4–8 bp 且呈**回文**（两条链各按 5′→3′ 读起来相同）——并在该序列内部或紧邻它的固定位置切割两条链。两次切割的位置不同，产物就带有不同的末端：**5′ 突出末端**（EcoRI 切在 `G^AATTC`，留下 5′-`AATT` 的单链末端）、**3′ 突出末端**（PstI，`CTGCA^G`）或**平末端**（EcoRV，`GAT^ATC`）。带突出末端又称**黏性末端**，同一种酶产生的黏性末端可以相互碱基配对。酶的名称来自其来源生物：EcoRI 是取自大肠杆菌（*Escherichia coli*）菌株 RY13 的第一种此类酶。
:::

::: proposition 限制位点的期望间隔 {#prop-site-frequency}
在四种碱基以概率 $p_A, p_C, p_G, p_T$ 独立出现的序列中，某个特定 $k$ bp 识别序列从给定位置开始的概率是其各位碱基概率的乘积。碱基频率相等时为 $4^{-k}$，所以位点平均每 $4^k$ bp 出现一次：识别 4 bp 的酶约每 256 bp 一个位点，识别 6 bp 的每 4096 bp，识别 8 bp 的每 65 536 bp。真实基因组偏离这一期望：碱基组成不均等，一些短序列的丰度偏低或偏高。例如，`CG` 在脊椎动物 DNA 中比随机期望约低四倍，所以识别序列中含 `CG` 的酶切割人 DNA 的频率很低。
:::

::: example 噬菌体 λ 的片段 {#ex-lambda}
噬菌体 λ 长 48502 bp 的基因组是标准的长度 marker。(a) 按随机序列预计应有多少个 EcoRI 位点？(b) λ 实际上有 5 个 EcoRI 位点。酶切得到 21226、7421、5804、5643、4878 与 3530 bp 的片段。验证这些片段合计构成整个基因组，并解释为什么是六个片段而不是五个。(c) 为什么 5804 与 5643 bp 的片段在琼脂糖凝胶上可能难以分开？
::: solution
(a) $48\,502/4096 = 11.8$ 个——随机 6 bp 序列的期望位点数。5 个偏低，却算不上异常；在选择压力下，噬菌体倾向于避开其宿主限制酶所识别的位点。

(b) 各片段之和为 $21\,226 + 7421 + 5804 + 5643 + 4878 + 3530 = 48\,502$ bp。λ DNA 在噬菌体颗粒内是线性的，所以切五刀得六段。若分子是环状的，五刀只得五段。

(c) 二者只差 161 bp，约 3 %。0.7 % 琼脂糖凝胶在此大小区间的分辨率只有百分之几，所以它们跑成一簇紧邻的双条带或一条粗带。
:::
:::

## 按大小分离 DNA：凝胶电泳

DNA 沿全长带负电，每个磷酸基团约一个电荷，所以荷质比几乎与大小无关。在自由溶液中，电场里一切 DNA 的迁移速度几乎相同。在**琼脂糖**凝胶（适用于约 0.1–25 kb 的片段）或**聚丙烯酰胺**凝胶（适用于几个到约 1000 bp 的片段）中，凝胶基质充当分子筛，长分子比短分子跑得慢。在可用的范围内，迁移距离与长度的对数近似成线性。电泳结束后用能结合双螺旋的荧光染料为 DNA 显色，在紫外灯下可见条带。超过约 50 kb 的片段在稳恒电场中都以极限速度迁移。分离它们需要**脉冲场凝胶电泳**（戴维·施瓦茨（David Schwartz）与查尔斯·坎托（Charles Cantor），1984）：电场方向周期性改变，大分子重新取向所需的时间更长。

::: example 依据 marker 梯带估计片段大小 {#ex-gel}
一条 marker 梯带的迁移距离如下（厘米）：10 000 bp 在 2.00，5000 bp 在 2.75，3000 bp 在 3.31，2000 bp 在 3.75，1000 bp 在 4.50。一个未知 PCR 产物跑在 3.60 cm 处。估计它的大小：(a) 在对数坐标上于最近的两个 marker 之间插值；(b) 用全部五个 marker 对距离拟合 $\log_{10}(\text{大小})$ 的直线。
::: solution
(a) 未知片段位于 3000 bp（3.31 cm）与 2000 bp（3.75 cm）之间，在从 2000 到 3000 的途中占 $(3.75 - 3.60)/(3.75 - 3.31) = 0.341$ 的分数。对数坐标上 $\log_{10}\text{大小} = \log_{10}2000 + 0.341(\log_{10}3000 - \log_{10}2000) = 3.301 + 0.341\times0.176 = 3.361$，所以大小约 2300 bp。

(b) 对五个点做最小二乘拟合给出 $\log_{10}\text{大小} = 4.799 - 0.3997\,d$，在 $d = 3.60$ 处为 3.360，大小约 2290 bp。两个估计相差不到 0.2 %。两者都不应报告得优于几个百分点，因为凝胶迁移率还取决于 DNA 的构象与上样量。回归分析见 [[biostatistics/regression]]。
:::
:::

### 酶切作图

**酶切图谱**标出几种酶的切割位点在 DNA 分子上的位置。它的构建方法是分别用每种酶单独酶切、用酶的两两组合双酶切，然后追问哪种位点排布能解释所有片段的大小。其逻辑如同拼图。每一个单酶切片段都必须恰好分割成双酶切的片段，而且各片段之和必须等于分子的全长。

```python
# 对线性或环状 DNA 找出限制位点并预测片段大小
import re

ENZYMES = {'EcoRI': ('GAATTC', 1), 'BamHI': ('GGATCC', 1), 'HindIII': ('AAGCTT', 1)}
# 值：(识别序列，在上链跳过这么多个碱基后的切割位置)

def cut_positions(seq, enzyme):
    site, offset = ENZYMES[enzyme]
    # 用先行断言，使相互重叠的位点都能被找到；三种酶的位点都是回文的，
    # 所以只搜一条链就能找到全部位点
    return [m.start() + offset for m in re.finditer('(?=' + site + ')', seq)]

def fragments(seq, enzymes, circular=False):
    cuts = sorted(p for e in enzymes for p in cut_positions(seq, e))
    if not cuts:
        return [len(seq)]
    if circular:
        sizes = [b - a for a, b in zip(cuts, cuts[1:])] + [len(seq) - cuts[-1] + cuts[0]]
    else:
        ends = [0] + cuts + [len(seq)]
        sizes = [b - a for a, b in zip(ends, ends[1:])]
    return sorted(sizes, reverse=True)

# 一段虚构的 60 bp 序列，含一个 EcoRI 位点和两个 BamHI 位点
seq = "ATGCGAATTCTTAGGCCATGGATCCAAATTTGGGCCCTTAAGGATCCTTGACAAGTTAAC"
print(len(seq), cut_positions(seq, 'EcoRI'), cut_positions(seq, 'BamHI'))
for enz in (['EcoRI'], ['BamHI'], ['EcoRI', 'BamHI']):
    print('+'.join(enz), 'linear:', fragments(seq, enz), 'circular:', fragments(seq, enz, True))
```

输出（位置指在上链从 0 数起的切点；大小以 bp 计）：

```
60 [5] [20, 42]
EcoRI linear: [55, 5] circular: [60]
BamHI linear: [22, 20, 18] circular: [38, 22]
EcoRI+BamHI linear: [22, 18, 15, 5] circular: [23, 22, 15]
```

这段示例序列使两个一般性的道理变得一目了然。单个切点会打开环而不改变它的长度，却把线性分子一分为二。而在双酶切中，含有 EcoRI 位点的那个 38 bp 的 BamHI 环状片段被切成 23 + 15，而 22 bp 的片段原封不动。根据凝胶数据为位点定位，靠的正是这一推理。

::: example 给质粒作图 {#ex-map}
一个环状质粒给出下列片段（kb）：EcoRI 单独酶切，5.0；BamHI 单独酶切，3.2 与 1.8；EcoRI + BamHI 双酶切，2.0、1.8 与 1.2。画出图谱。
::: solution
EcoRI 从环上得到单个 5.0 kb 片段，所以质粒长 5.0 kb、只有一个 EcoRI 位点；把它放在 0 处。BamHI 给出两个片段，所以有两个 BamHI 位点，沿环一个方向相距 1.8 kb，另一个方向相距 3.2 kb。双酶切中 1.8 kb 片段完好保存，所以 EcoRI 位点不在其中；3.2 kb 片段被切成 2.0 + 1.2，所以 EcoRI 位点位于其内，距一个 BamHI 位点 1.2 kb，距另一个 2.0 kb。图谱是：EcoRI 在 0，BamHI 在 1.2，BamHI 在 3.0（1.2 + 1.8），回到 EcoRI 在 5.0（3.0 + 2.0）。镜像排布（BamHI 在 2.0 与 3.8）是沿反方向读同一个环。要固定相对于某个基因的取向，需要第三种酶，或一个相对某个不对称特征的位置已知的单切酶。
:::
:::

## 构建重组 DNA

::: definition 分子克隆 {#def-cloning}
**克隆**一个 DNA 片段，指把它插入一个**载体**——一种能在宿主细胞中复制的 DNA 分子——并培养一个克隆细胞群体，其中每个细胞都携带同一个重组分子。一个典型的质粒载体带有**复制起点**、一个**选择标记**（通常是抗生素抗性基因，使得只有吸收了质粒的细胞才能在选择培养基上生长）和一个带有唯一限制位点的**多克隆位点**。用同样的酶切割片段与载体，把它们相容的末端退火，由 **DNA 连接酶**连接，再经**转化**把产物导入感受态大肠杆菌细胞。
:::

最早的重组 DNA 分子是 1972 年在伯格（Paul Berg）实验室做成的（戴维·杰克逊（David Jackson）、罗伯特·西蒙斯（Robert Symons）与伯格把 SV40 与 λ DNA 拼接起来）。1973 年，科恩（Stanley Cohen）、张安尼（Annie Chang）、博耶（Herbert Boyer）与赫林（Robert Helling）用 EcoRI 切开质粒并重接，他们的重组质粒在大肠杆菌中复制，并使两个亲本的抗性都得以表达。对潜在危险的担忧促使科学家发起自愿暂停，继而召开了 1975 年的阿西洛马（Asilomar）会议。会议的建议——一套与所评估风险相匹配的物理与生物学防护体系——成为美国国立卫生研究院（1976）等官方指南的基础。今天的实验室克隆使用无法在实验室外存活、已被削残的大肠杆菌 K-12 菌株，并在机构的生物安全监管下进行。

几项改进使克隆成为常规操作：

- **α 互补筛选。** 在 pUC 质粒一类载体中，多克隆位点位于 *lacZ* 基因的一段片段内部，该片段编码 β-半乳糖苷酶的 α 肽。只有当载体的 *lacZα* 完整时，携带互补片段的宿主细胞才能产生有活性的酶，而有活性的酶能使生色底物 X-gal 变蓝。插入片段会破坏 *lacZα*，所以携带重组质粒的菌落呈**白色**，携带空载体的呈蓝色。
- **cDNA。** 真核基因含有内含子（[[molecular-biology/rna-processing]]），细菌无法将其除去。要在细菌中表达真核蛋白质，人们克隆**互补 DNA（cDNA）**——用**逆转录酶**以成熟 mRNA 为模板合成的 DNA 拷贝；该酶是 1970 年分别由特明（Howard Temin）与水谷敏（Satoshi Mizutani）以及巴尔的摩（David Baltimore）在 RNA 肿瘤病毒中发现的。
- **文库。** **基因组文库**是一组克隆的集合，它们合起来包含整个基因组；**cDNA 文库**代表某种组织的 mRNA。找到某个克隆的办法是用标记探针杂交，或凭借它赋予的功能。
- **不依赖序列的组装。** Gibson 组装（2009）一类方法用核酸外切酶、聚合酶与连接酶在一管中连接带重叠末端的片段，克隆从此不再依赖合适的限制位点。

## 聚合酶链反应

聚合酶链反应（PCR）由穆利斯（Kary Mullis）于 1983 年在塞特斯（Cetus）公司构想，并由斋木（Randall Saiki）、穆利斯及同事于 1985 年首次发表。它在体外一遍又一遍地复制选定的 DNA 片段。它需要两条**引物**——约 18–25 个核苷酸、与靶两端分别位于两条链上的序列互补的寡核苷酸——以及一种 DNA 聚合酶。每个**循环**有三步：

1. 约 95 °C **变性**，使两条链分开。
2. 在比引物熔解温度低几度的温度（通常 50–65 °C）**退火**，让引物与各自的靶序列配对。（熔解温度的计算见化学图谱[核酸](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)。）
3. 约 72 °C **延伸**，让聚合酶把每条引物延伸穿过靶区。

使 PCR 成为实用技术的突破，是水栖热菌（*Thermus aquaticus*）的**耐热** DNA 聚合酶；这种细菌是布罗克（Thomas Brock）于 1960 年代从黄石国家公园一处热泉中分离出来的。Taq 聚合酶能挺过变性步骤，因此不必每个循环都重新添加，而且它的工作温度高，使引物起始更特异（Saiki 等，1988）。

::: proposition PCR 的扩增 {#prop-pcr}
1. 若每个循环复制当时存在的模板分子的一个比例 $E$（$0 \le E \le 1$，**效率**），那么 $n$ 个循环后产物分子数为
$$
N_n = N_0\,(1 + E)^n ,
$$ {#eq-pcr}
完全效率时即 $N_0\,2^n$。
2. 从一个双链模板分子出发、效率完全时，$n$ 个循环后两端*都*由引物界定的双链（靶长度产物）数目为
$$
2^n - 2n .
$$ {#eq-pcr-exact}
最早的这类分子出现在第 3 个循环。
3. 在实时（定量）PCR 中，产物达到固定检测水平的**阈值循环** $C_t$ 满足 $C_t = \text{常数} - \log_{1+E} N_0$。因此 $C_t$ 对 $\log_{10}N_0$ 作图是一条斜率为 $-1/\log_{10}(1+E)$ 的直线，于是
$$
E = 10^{-1/\text{斜率}} - 1 .
$$ {#eq-qpcr}
$E = 1$ 时斜率为 $-3.32$：模板减半多一个循环，稀释十倍多 3.32 个循环。

只有当引物、核苷酸与聚合酶过量时，指数增长才能持续。反应后期扩增减速进入**平台期**，这就是定量使用指数期的 $C_t$、而不是最终产量的原因。
:::

::: proof
(1) 每个循环把 $N$ 个分子变成 $N + EN = (1+E)N$；迭代 $n$ 次即得 [[#eq-pcr]]。

(2) $n$ 个循环后共有 $2^n$ 个双链。每个双链由上一轮的一条模板链与在它上面新合成的链组成。称一条链为**长链**，如果它从引物开始、却是以最初的那条链为模板复制出来的，因而越过了另一侧的引物位点。每条最初的链每个循环产生一条长链，所以 $n$ 个循环后共有 $2n$ 条长链。一个双链不是靶长度，当且仅当它含有一条最初的链或一条长链。这些就是含最初两条链的 2 个双链（各与刚在其上合成的长链配对），以及以早先循环的一条长链为模板的 $2(n-1)$ 个双链，总共 $2n$ 个双链。其余每个双链的两端都由引物界定，所以这样的双链有 $2^n - 2n$ 个。验证：$n = 1$ 与 $n = 2$ 时为 0，$n = 3$ 时为 $8 - 6 = 2$。

(3) 当 $N_0(1+E)^{C_t} = N_t$ 时产物达到阈值 $N_t$，即 $C_t = \log_{1+E}N_t - \log_{1+E}N_0 = \text{常数} - \log_{10}N_0/\log_{10}(1+E)$。对 $\log_{10}N_0$ 的斜率是 $-1/\log_{10}(1+E)$；解出 $E$ 即得 [[#eq-qpcr]]。
:::

::: example 有多少产物，纯度如何？ {#ex-pcr}
一个 PCR 从 10 个拷贝的 500 bp 靶序列出发。(a) 30 个循环后，效率 100 % 与 95 % 时各有多少拷贝？(b) 从一个模板双链出发，30 个循环后恰为靶长度的双链占什么比例？(c) $10^{10}$ 个 500 bp 产物的拷贝代表多少 DNA 质量？每个碱基对取 650 g mol⁻¹。
::: solution
(a) $10\times2^{30} = 1.07\times10^{10}$；$10\times1.95^{30} = 5.0\times10^{9}$。每个循环损失 5 % 的效率，30 个循环后产量就减半，所以效率至为关键。

(b) $(2^{30} - 60)/2^{30} = 1 - 5.6\times10^{-8}$：几乎都是。长产物只按线性增长。

(c) 一个拷贝重 $500\times650/(6.022\times10^{23}) = 5.4\times10^{-19}$ g，所以 $10^{10}$ 个拷贝重 $5.4\times10^{-9}$ g，约 5 ng。这在与染色的凝胶上清晰可见，而起始量只有约 $5\times10^{-18}$ g。
:::
:::

::: example 从标准曲线求效率 {#ex-qpcr}
质粒标准品的十倍稀释系列，在 $10^6$、$10^5$、$10^4$ 与 $10^3$ 个拷贝时给出阈值循环 15.1、18.6、22.1 与 25.6。(a) 扩增效率是多少？(b) 一个未知样品给出 $C_t = 20.0$。它含有多少个拷贝？
::: solution
(a) 每稀释十倍 $C_t$ 升高 3.5 个循环，所以对 $\log_{10}N_0$ 的斜率为 $-3.5$，$E = 10^{1/3.5} - 1 = 0.93$，即 93 %。效率大约在 90–105 % 之间通常都可接受。

(b) 直线为 $C_t = 15.1 + 3.5(6 - \log_{10}N_0)$，所以 $\log_{10}N_0 = 6 - (20.0 - 15.1)/3.5 = 6 - 1.40 = 4.60$，得 $N_0 = 4.0\times10^4$ 个拷贝。
:::
:::

caption: PCR 指数期产物分子数的常用对数对循环数的曲线，$\log_{10}N = \log_{10}N_0 + n\log_{10}(1+E)$（[[#eq-pcr]]），起始拷贝数为 $N_0$。水平线是一条任意的检测阈值；每条曲线与它的交点所在循环即 $C_t$。$E = 1$ 时把 $N_0$ 增为十倍，交点提前 3.3 个循环。降低 $E$，交点推迟，而且对 $N_0$ 更敏感。真实反应会弯入平台期，这个指数模型没有把它包括在内。
:::

PCR 使研究微量样品中的 DNA 成为可能。它被用来扩增待克隆或待测序的基因、检测特定序列（如诊断与法医检测）、逆转录后测定 mRNA 水平（RT-qPCR），以及扩增古代 DNA。灵敏是它的强项也是它的软肋：单个污染分子可以和靶标一样被扩增，所以不含模板的对照必不可少。

::: warning "循环越多产物越多，所以应尽可能多跑循环"
扩增只在试剂过量时才是指数的。当产物达到每个反应约 $10^{11}$–$10^{12}$ 个拷贝时，引物与核苷酸成为限制因素，聚合酶饱和，产物链彼此重新退火而不是与引物退火。多跑的循环增加不了多少特异产物，却给错误引发留出更多时间，于是非特异条带与引物二聚体不断积累。因此最终产量是起始量的糟糕度量：模板相差十倍的两个样品可以得到相同的平台。定量 PCR 使用阈值循环，在扩增仍是指数时读数。
:::

## 读取 DNA：测序

1977 年发表了两种 DNA 测序方法。马克萨姆（Allan Maxam）与吉尔伯特（Walter Gilbert）使用碱基特异的化学切割。桑格（Frederick Sanger）、尼克兰（Steve Nicklen）与库尔森（Alan Coulson）使用链终止核苷酸。桑格法胜出，桑格与吉尔伯特（与伯格）分享 1980 年诺贝尔化学奖。

::: definition 链终止（桑格）测序 {#def-sanger}
在四种正常 dNTP 与少量**双脱氧核苷三磷酸（ddNTP）**同时存在时，DNA 聚合酶延伸一条与单链模板退火的引物；ddNTP 缺少 3′-OH。一旦掺入 ddNTP，延伸便告终止。产物是一组长度嵌套的链，每条链终止于模板指定该 ddNTP 所含碱基的位置。以单核苷酸分辨率按长度分开产物，记下每条链末端是哪种 ddNTP，就从引物起按 5′→3′ 读出了序列。在现代形式中，每种 ddNTP 携带一种不同的荧光染料，产物在一根毛细管中分离。读段通常长 600–1000 个核苷酸。
:::

读长不仅受分离的限制，也受统计的限制。如果在每个指定 G 的位置，链以小概率 $q$ 接受 ddG，那么越过 $k$ 个这样的位置继续延伸的链的比例为 $(1 - q)^k$。取 $q = 0.01$，约 78 % 的链越过 25 个 G 位置，所以信号铺满整个读长却逐渐淡去；ddNTP 与 dNTP 的比例经过调校，以平衡近处与远处的信号。

**高通量**（"二代"）测序方法自 2000 年代中期发展起来，并行测定数百万至数十亿条 DNA 片段。应用最广的方案（Illumina 边合成边测序）把片段在玻璃表面扩增成簇，用可逆终止的荧光核苷酸每个循环读一个碱基，读长约 100–300 个碱基。**单分子长读长**方法读取单个分子，长度达数十 kb 以上：或实时观察聚合酶掺入荧光核苷酸（Pacific Biosciences），或测量 DNA 穿过蛋白质纳米孔时流过的电流（Oxford Nanopore）。长读长使组装重复区域成为可能。2022 年完成的第一个端粒到端粒的人基因组序列就靠了它们。测定一个人基因组的费用从 2001 年的约 US\$1 亿降到 2016 年前后的约 US\$1000；据 NHGRI 的估计与厂商的数字，到 2024 年已降到几百美元。基因组组装与分析见 [[genomics/sequencing-genomes]] 与 [[bioinformatics/assembly-variants]]。

::: example 测序要测多深？ {#ex-coverage}
在 Lander–Waterman 模型中，读段随机落在基因组上。若读段总长是基因组长的 $c$ 倍（**覆盖度**或深度），覆盖某个给定碱基的读段数近似服从均值为 $c$ 的泊松分布。(a) 覆盖度 5× 与 30× 时，基因组完全未被覆盖的比例各是多少？(b) 对 30× 的 3.1 Gb 人基因组，这会留下多少个碱基未被覆盖？(c) 为什么真实项目在 30× 时仍有缺口？
::: solution
(a) 读段数为零的概率是 $e^{-c}$：5× 时 $e^{-5} = 6.7\times10^{-3}$，约 0.7 % 的碱基被漏掉；30× 时 $e^{-30} = 9.4\times10^{-14}$。

(b) $3.1\times10^9\times9.4\times10^{-14} = 3\times10^{-4}$ 个碱基：实际上一个也没有。

(c) 读段并非随机放置：GC 含量极端的区域扩增与测序都差，而比一个重复单元短的读段无法唯一地置于重复之内。30× 时剩下的缺口来自这些偏差，而非抽样，这就是完成人基因组需要长读长（long read）的原因。
:::
:::

## 检测特定分子：杂交与印迹

许多技术依赖碱基配对的专一性：一条标记的单链**探针**能在数百万条其他序列中找到它的互补序列并与之退火。

- **Southern 印迹**（萨瑟恩（Edwin Southern），1975）：在凝胶上分开的 DNA 片段经变性后转移（"印迹"）到膜上，再与标记探针孵育。该方法显示携带某一序列的限制片段的大小。它曾被用于检测基因重排与限制性片段长度多态性。
- **Northern 印迹**（阿尔温（James Alwine）、肯普（David Kemp）与斯塔克（George Stark），1977，得名于一个玩笑）对 RNA 做同样的事，显示一个转录本在不同组织中的大小与丰度。
- **Western 印迹**（托宾（Harry Towbin）及同事，1979；伯内特（W. Neal Burnette）于 1981 年如此命名）把凝胶电泳分开的蛋白质转移到膜上，用抗体检测其中一种。
- **原位杂交**在固定的细胞或组织中检测某个序列，显示一个基因在哪里表达、或一个序列位于染色体的何处。荧光探针用于 FISH。
- **基因芯片**（1990 年代）把数千条探针固定在载片上，与标记 cDNA 杂交，一次测量许多基因的表达。在多数用途上它已被直接对 cDNA 测序（**RNA-seq**）取代。

## 观察基因何时何处发挥作用：报告基因

**报告基因**编码一种易于检测的产物，被置于所研究的调控序列的控制之下，或与所研究的蛋白质框内融合。常用报告物有 *lacZ*（β-半乳糖苷酶，用 X-gal 检测）、萤火虫**荧光素酶**（催化荧光素发光，可定量测量），以及来自水母 *Aequorea victoria*（维多利亚多管发光水母）的**绿色荧光蛋白**（GFP）。GFP 带来的变革最大，因为它在活细胞中不需任何外加底物就能发光。下村修 1962 年分离出它。普里希纳（Douglas Prasher）1992 年克隆了它的基因，沙尔菲及同事 1994 年把它在大肠杆菌与秀丽隐杆线虫（*C. elegans*）中表达，证明它不需要任何其他水母因子。此后钱永健的实验室改造出更亮的变体与别的颜色。下村修、沙尔菲与钱永健分享 2008 年诺贝尔化学奖。报告基因检测是定义增强子与启动子的方法（[[molecular-biology/eukaryotic-gene-regulation]]），荧光蛋白融合是在活细胞中追踪蛋白质运动的方法（[[cell-biology/cells-and-microscopy]]）。

::: quiz
把一只只在果蝇肌肉中表达的基因的启动子与增强子区连到 GFP 的编码序列上，制成转基因果蝇。GFP 出现在肌肉中，出乎意料的是也出现在肠。哪个结论最受支持？
- [ ] 该基因在肠也有表达。
- [x] 该片段含有能够在肠驱动表达的序列；内源基因是否在肠表达，必须直接检验，例如用原位杂交。
- [ ] GFP 在肌肉中有毒，并跑到了肠。
- [ ] 实验失败了，因为报告基因必须完全复现内源表达模式。
::: solution
报告基因显示的是被克隆的调控序列在其插入所处环境中能够做什么。脱离正常的位置，它们可能缺少邻近的沉默子或绝缘子，或受到插入位点附近增强子的影响。额外的肠表达可能反映这类环境影响，所以内源基因的表达必须直接检验；检测几个独立插入有助于排除位置效应。
:::
:::

## 编辑基因组：CRISPR–Cas9

近十年最强大的工具同样来自细菌免疫。许多细菌与古菌携带 **CRISPR** 阵列（成簇规律间隔短回文重复序列），1987 年由石野良纯（Yoshizumi Ishino）及同事在大肠杆菌中首先注意到。2005 年，包括莫西卡（Francisco Mojica）课题组在内的三个组注意到，重复序列之间的间隔序列与噬菌体和质粒的序列匹配。巴拉古（Rodolphe Barrangou）、霍尔瓦特（Philippe Horvath）及同事（2007）在乳品细菌嗜热链球菌（*Streptococcus thermophilus*）中证明，新的间隔序列取自入侵的噬菌体，并使细胞对它产生抗性。阵列被转录并加工成短的 **CRISPR RNA（crRNA）**，每条 crRNA 把一种 Cas 核酸酶引导去摧毁与其间隔序列匹配的 DNA。

2012 年，伊内克（Martin Jinek）、齐林斯基（Krzysztof Chylinski）、丰法拉（Ines Fonfara）、豪尔（Michael Hauer）、杜德纳（Jennifer Doudna）与夏庞蒂埃（Emmanuelle Charpentier）证明，化脓性链球菌（*Streptococcus pyogenes*）的 Cas9 蛋白配上两条 RNA，即可切割与 20 个核苷酸引导序列匹配的任何 DNA。这两条 RNA 是一条 crRNA 与一条反式激活 crRNA（tracrRNA），二者可以融合成一条单一的**向导 RNA**。数月之内，张锋与丘奇（George Church）各自带领的组就用这套系统编辑了人与小鼠细胞（Cong 等与 Mali 等，2013）。夏庞蒂埃与杜德纳获 2020 年诺贝尔化学奖。

::: definition Cas9 的机制 {#def-cas9}
化脓性链球菌 **Cas9** 是一种 RNA 引导的核酸内切酶。装载一条**向导 RNA**——其 5′ 端带一段 20 个核苷酸的**间隔序列**——之后，它在 DNA 上搜索**原型间隔序列邻近基序（PAM）**，即非靶链上的 `5'-NGG-3'`。找到 PAM 后，它解开邻近的 DNA，并从靠近 PAM 的"种子"区开始，检验间隔序列是否与靶链配对。若 20 个核苷酸的大部分都匹配，**HNH** 核酸酶结构域切割靶链（与向导配对的那条），**RuvC** 结构域切割另一条链。结果是在 PAM 上游（5′ 侧）3 bp 处出现一个平端**双链断裂**。随后细胞修复这个断裂（[[molecular-biology/dna-repair-recombination]]）：NHEJ 常留下破坏基因的小插入或缺失，而以提供的模板进行的同源定向修复则可以引入精确的改变。
:::

对 PAM 的要求是细菌区分自我与非我的关键。CRISPR 阵列中的间隔序列旁边没有 PAM，所以 Cas9 不切割细胞自己的阵列。它同时也限制了编辑：靶点必须紧邻一个 `NGG`，随机 DNA 每条链平均每 16 bp 出现一个，两条链合起来每 8 bp 一个。工程化的 Cas9 变体识别别的 PAM；别的 Cas 酶（如 Cas12a，PAM 富含 T、切割产生交错末端）扩大了选择。**碱基编辑器**与**引导编辑器**把一个只切单链的 Cas9 与一种脱氨酶或逆转录酶融合，不经双链断裂就能改变碱基。

::: example 20 个核苷酸向导的特异性 {#ex-specificity}
(a) 在碱基频率相等的随机序列中，一个特定的 20 个核苷酸的靶后面紧跟 `GG`，在一条链上每个位置出现的概率是多少？(b) 在一个二倍人人基因组（$6.2\times10^9$ bp，两条链都算）中，按机会预计有多少个完全匹配？(c) Cas9 能容忍几个错配，特别是在离 PAM 远处。与给定的 20 联体相差不超过三个错配的序列有多少个？紧邻 `NGG` 的这样的近似匹配按机会预计有多少个？这对向导设计意味着什么？
::: solution
(a) $4^{-20}\times4^{-2} = 4^{-22} = 5.7\times10^{-14}$，每条链每个位置。

(b) 二倍体基因组两条链共有 $2\times6.2\times10^9$ 个位置，但两套单倍体几乎完全相同，所以按一个单倍体基因组的两条链计 $6.2\times10^9$ 个位置：$6.2\times10^9\times5.7\times10^{-14} = 3.5\times10^{-4}$ 个偶然匹配。因此在随机 DNA 中，靶序列的唯一性基本上是必然的。

(c) 至多三个错配的 20 联体的数目是 $\sum_{k=0}^{3}\binom{20}{k}3^k = 1 + 60 + 1710 + 30\,780 = 32\,551$。这样的近似匹配紧邻 `GG` 的期望数是 $32\,551\times3.5\times10^{-4} \approx 11$。所以一条完全匹配唯一的向导仍可能有若干带几个错配的脱靶位点，而充满重复序列的真实基因组的只会更多。因此要用软件在基因组中搜索近似匹配来挑选向导，并对编辑过的细胞测序检查。（随机序列的计算只是一条基线。）
:::
:::

::: application 基因组编辑：用途、限度与规则
Cas9 及其近亲被用来敲除细胞系与模式生物的基因、制造模拟人类变异的精确突变、用向导文库并行筛查数千个基因，以及培育作物。第一个基于 CRISPR 的疗法——治疗镰状细胞病与 β-地中海贫血（在患者体外编辑其自身血液干细胞的 *BCL11A* 的一个调控序列）——于 2023 年在英国与美国获批；临床事宜属于医学图谱。编辑人生殖系、使改变可以遗传，在多数国家被禁止或不被允许。2018 年一对胚胎经过编辑的双胞胎出生，受到国际谴责，负责任的科学家被判监禁。对生物体的基因组编辑受各国生物安全与转基因生物法律监管；任何能造成危害的材料的工作都受生物安保规则约束。伦理与监管框架见 [[biotechnology/biosafety-ethics]]。
:::

::: history
阿伯于 1960 年代描述了限制与修饰，史密斯与威尔科克斯 1970 年纯化了序列特异的酶 HindII。特明与水谷敏、巴尔的摩 1970 年发现了逆转录酶。杰克逊、西蒙斯与伯格 1972 年制成了第一个重组 DNA，科恩、张安尼、博耶与赫林 1973 年把质粒 DNA 克隆进大肠杆菌。1975 年召开重组 DNA 阿西洛马会议，同年萨瑟恩发表了印迹法。桑格、尼克兰与库尔森，以及马克萨姆与吉尔伯特，1977 年发表了 DNA 测序方法。穆利斯 1983 年构想出 PCR；斋木及同事 1985 年发表其首次应用，1988 年发表 Taq 聚合酶的应用（穆利斯：1993 年诺贝尔化学奖，与发展定点诱变的迈克尔·史密斯分享）。沙尔菲及同事 1994 年引入 GFP 作为报告基因。伊内克、杜德纳、夏庞蒂埃及同事 2012 年描述了 Cas9 的可编程切割。
:::

::: summary
- Ⅱ 型限制酶在短的、通常呈回文的位点切割，产生黏性或平末端。长为 $k$ 的位点在随机序列中约每 $4^k$ bp 出现一次。酶切图谱由单酶切与双酶切推得。
- 凝胶电泳按大小分离 DNA；迁移率大致与 $\log(\text{大小})$ 成线性，未知片段的大小从 marker 梯带读出。
- 克隆用连接酶把片段接到载体上并在大肠杆菌中繁殖，选择载体（抗性）、筛选插入（蓝白斑）。逆转录酶制作的 cDNA 没有内含子。
- PCR 扩增两条引物之间的靶：$N = N_0(1+E)^n$。从一个模板起，靶长度双链的数目为 $2^n - 2n$。qPCR 用阈值循环定量，$E = 10^{-1/\text{斜率}} - 1$（100 % 效率时斜率 $-3.32$）。
- 桑格测序读取链终止产物的嵌套系列；高通量与长读长方法并行测定数百万个分子。理想化模型中，覆盖度 $c$ 留下比例 $e^{-c}$ 的碱基未被采到。
- Southern、Northern 与 Western 印迹在按大小分离后分别检测 DNA、RNA 与蛋白质；原位杂交显示位置。报告基因（*lacZ*、荧光素酶、GFP）报告调控活性。
- Cas9 带 20 nt 向导在 `NGG` PAM 旁切割 DNA，在距 PAM 3 bp 处造成平端断裂。NHEJ 修复破坏基因；同源定向修复引入精确编辑。必须检查在近似匹配处的脱靶切割，而人胚胎生殖系编辑在多数司法辖区被禁止。
:::

EcoRI 切 `G^AATTC`，MfeI 切 `C^AATTG`。(a) 画出每种酶留下的末端。(b) EcoRI 末端能与 MfeI 末端连接吗？(c) 连接处能被其中任何一种酶再切吗？
::: solution
(a) 两者都留下 `AATT` 的 5′ 突出：EcoRI 给出 `5'-G` 与 `5'-AATTC...`；MfeI 给出 `5'-C` 与 `5'-AATTG...`。(b) 能：突出末端完全相同且互补，所以能退火并被连接。(c) 杂合连接处读作 `GAATTG`（另一侧为 `CAATTC`），既不是 `GAATTC` 也不是 `CAATTG`，所以两种酶都不能再切它。这种相容却不能重生的末端在克隆中被用来刻意消灭一个位点。
:::

::: exercise 由斜率求效率 {level=2 check="1.10"}
一条 qPCR 标准曲线的斜率为每十倍稀释 $-3.1$ 个循环。表观效率 $E$ 是多少（两位小数）？什么可能解释大于 1 的值？
::: solution
$E = 10^{1/3.1} - 1 = 1.10$，表观为 110 %。对特异产物而言，高于 100 % 在物理上不可能；通常指示浓标准品中有抑制剂（推迟高投入时的 $C_t$、压平曲线）、稀释系列的移液误差，或低投入时引物二聚体信号的贡献。
:::

::: exercise 第二个作图问题 {level=2}
一条 7.0 kb 的线性 DNA 给出：HindIII 单独酶切，4.0 与 3.0 kb；XhoI 单独酶切，5.5 与 1.5 kb；HindIII + XhoI，3.0、2.5 与 1.5 kb。构建图谱。解不止一个吗？
::: solution
每种酶各切一次（线性分子给出两个片段）。把 HindIII 放在距左端 4.0 kb 处（片段 4.0 与 3.0）。双酶切保留 3.0 与 1.5 kb 片段，并把 4.0 kb 的 HindIII 片段切成 2.5 + 1.5，所以 XhoI 位点在 4.0 kb 片段内，距其一端 1.5 kb。若 XhoI 在距左端 1.5 kb 处，XhoI 片段将是 1.5 与 5.5——正确。若它在距左端 2.5 kb 处（距 HindIII 位点 1.5 kb），XhoI 片段将是 2.5 与 4.5——错误。所以图谱是：左端——XhoI 在 1.5——HindIII 在 4.0——右端在 7.0（或从另一端读出的镜像）。除取向外解是唯一的。
:::

::: exercise 读一张桑格图谱 {level=2}
一个用染料标记终止物的桑格反应，按片段长度递增依次给出对应下列颜色的峰：ddA、ddT、ddG、ddG、ddC、ddA、ddT。(a) 新合成链的序列（5′→3′）是什么？(b) 模板链的序列（5′→3′）是什么？(c) 为什么长片段的峰更小更宽？
::: solution
(a) 最短的片段终止在离引物最近处，所以新链（在引物之后）读作 `5'-ATGGCAT-3'`。

(b) 模板是其反向互补链：`5'-ATGCCAT-3'`。

(c) 越过逐个位置继续延伸的链的比例按 $(1-q)^k$ 几何下降，所以在远处终止的分子更少；而在毛细管电泳中，相差一个核苷酸的两条链之间的分辨率随长度增加而下降（一个核苷酸的差异占长度的比例变小），所以峰变宽并相互重叠。
:::

::: exercise 挑选 Cas9 靶点 {level=3}
下面是一个外显子编码链（5′→3′）的一部分：`ATGCCTGAAGCTTGGACCATCGTAGCAGGTCTTAAG`。(a) 找出这条链上每一个 `NGG`，并对每个上游在序列内尚有 20 个核苷酸的位点，给出 20 个核苷酸的原型间隔序列与切割位点。(b) 要寻找另一条链上的靶点，应在本链上寻找什么基序？找出一个。(c) 为什么你可能偏爱切割位点位于编码序列较早处的靶点？
::: solution
(a) 从 1 开始编号，这条链在位置 13–15 处有 `TGG`，在 27–29 处有 `AGG`。`TGG` 上游只有 12 个核苷酸，在给定序列内不够一个 20 个核苷酸的原型间隔序列。对 `AGG`，原型间隔序列是位置 7–26，`GAAGCTTGGACCATCGTAGC`，向导 RNA 将携带同样的序列（以 U 代 T）。Cas9 在 PAM 上游 3 bp 处切割，即位置 23 与 24 之间：`GAAGCTTGGACCATCGT^AGC AGG`。

(b) 另一条链上的 `NGG` 在本链上显示为 `CCN`，此时原型间隔序列是本链上 `CCN` *下游*的 20 个核苷酸，向导与它们的反向互补序列匹配。本链在 4–6 处有 `CCT`，17–19 处有 `CCA`。`CCA` 之后只有 17 个核苷酸，而 `CCT` 之后跟着位置 7–26。向导序列是那一串的反向互补，`GCTACGATGGTCCAAGCTTC`，切割点在距 PAM 3 bp、位置 9 与 10 之间。这里恰好同一段 20 bp 可以从两条链作为靶点，两个切割位点相距 14 bp。

(c) 编码序列较早处的移码插入或缺失更可能产生严重截短、失去功能的蛋白质，并触发 mRNA 的无义介导降解（[[molecular-biology/rna-processing]]）；靠近 3′ 端的插入或缺失可能留下大部分完整而有功能的蛋白质。
:::

::: exercise 解读编辑后的 Western 印迹 {level=3}
一批培养的细胞用 Cas9 与一条靶向某基因外显子 2 的向导处理。靶区测序显示 70 % 的等位基因被编辑，全部是移码。用抗该蛋白质 C 末端的抗体做的 Western 印迹显示一条正常大小的带，强度为对照的 40 %。由单个细胞克隆出的克隆没有带。(a) 40 % 与 70 % 的移码等位基因相符吗？(b) 为什么许多实验需要单细胞克隆？(c) 在断定该克隆的表型由蛋白质丢失引起之前，还应检查什么？
::: solution
(a) 若等位基因独立地被编辑，仍有 $0.3$ 的等位基因编码正常蛋白质；若蛋白质产量与有功能的等位基因成正比，群体将显示约为对照的 30 %。40 % 与之接近——差异可能反映编辑之前就已存在的蛋白质仍在（稳定的蛋白质需要时间被稀释掉）、替代的起始密码子，或把移码跳过的外显子跳跃。

(b) 群体是不同基因型细胞（未编辑、杂合、不同插入或缺失）的混合物；来自单个细胞的克隆在两个等位基因上都有确定的基因型，因而可以研究完全丢失的效应。

(c) 基因组其他位置的脱靶编辑（对预测的近似匹配位点测序检查，或使用第二条独立的向导与克隆）；与编辑无关的克隆间差异（比较几个独立克隆）；以及回复实验——从一个不被向导切割的构建体重新表达该蛋白质，若表型由敲除引起，它应当使表型逆转。
:::
