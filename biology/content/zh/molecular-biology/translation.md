翻译是核酸的信息变成蛋白质化学的一步。核糖体一次读 mRNA 的三个核苷酸，把对应的氨基酸连接起来——细菌中每秒约 20 个，大约每一万次出错一次。做这件事的分子本身也大多是 RNA。把密码子与氨基酸对应起来的密码在所有生物中都几乎相同，这是地球上所有生命共享一个共同祖先的一条有力证据。

本章先确立遗传密码：它如何被破译、它的结构、阅读框，以及如何用计算机翻译序列。然后逐一追踪这些分子：转运 RNA 与装载它们的酶、核糖体，以及蛋白质合成的起始、延伸与终止，并关注速度、准确性与能量代价。肽键与氨酰-tRNA 形成的化学见化学图谱（[核酸、翻译](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)）。点突变与移码从遗传学家的角度在 [[genetics/genes-and-mutation]] 中引入。

## 破译密码

到 1950 年代末，事情已经清楚：蛋白质在核糖体上制造，它们的氨基酸序列由基因决定，并且一定有一种中间体把氨基酸运到模板上。克里克（Francis Crick）的**接头假说**（1955）提出每种氨基酸对应一种小 RNA，而这些接头最终被证明就是转运 RNA。多少个核苷酸决定一种氨基酸？两个核苷酸只有 $4^2 = 16$ 种组合，不够 20 种氨基酸；三个给出 $4^3 = 64$ 种，绰绰有余。

三联体的第一批实验证据来自遗传学。1961 年，克里克、巴尼特（Leslie Barnett）、布伦纳（Sydney Brenner）与沃茨-托宾（Richard Watts-Tobin）把噬菌体 T4 *rIIB* 基因中由吖啶诱发的移码突变组合起来。一个或两个插入破坏功能，但三个邻近的插入（或三个缺失）使功能恢复（[[genetics/genes-and-mutation#ex-frameshift]]）。这表明密码从一个固定的起点按不重叠的三个一组读下去，并且大多数三联体编码氨基酸，从而使密码具有**简并性**。

密码子的含义来自生物化学。1961 年，美国国立卫生研究院的尼伦伯格（Marshall Nirenberg）与马泰（Heinrich Matthaei）把人工合成的 RNA 加到能合成蛋白质的大肠杆菌提取物中。Poly(U) 指导多聚苯丙氨酸的合成，所以 `UUU` 编码 Phe。Poly(C) 给出多聚脯氨酸，poly(A) 给出多聚赖氨酸。科拉纳（Gobind Khorana）的小组接着合成了具有确定重复序列的 RNA：poly(UC) 按 `UCU CUC UCU…` 读，得到 Ser–Leu 交替的产物。1964 年，尼伦伯格与莱德（Philip Leder）发现三核苷酸本身就能使相应的氨酰-tRNA 结合到核糖体上，从而可以逐个指定密码子。到 1966 年，全部 64 个密码子都已指派完毕。霍利（Robert Holley）1965 年测定了第一个 tRNA 序列——酵母 tRNA^Ala^。霍利、科拉纳与尼伦伯格分享 1968 年诺贝尔生理学或医学奖。

::: proposition 标准遗传密码的性质 {#prop-code}
1. **三联体、不重叠**：每个密码子由三个核苷酸组成，从起始密码子起连续读取，无间隔、无重叠。
2. **简并**：64 个密码子中，61 个是**意义密码子**，编码 20 种氨基酸；3 个是**终止密码子**（`UAA`、`UAG`、`UGA`）。Leu、Ser 与 Arg 各有 6 个密码子；Val、Pro、Thr、Ala 与 Gly 各 4 个；Ile 3 个；Phe、Tyr、His、Gln、Asn、Lys、Asp、Glu 与 Cys 各 2 个；Met 与 Trp 各 1 个。编码同一氨基酸的密码子（**同义**密码子）通常只在第三位不同。
3. **起始**：`AUG`（Met）是通常的起始密码子；细菌中 `GUG` 与 `UUG` 有时也充当起始。
4. **使误差最小**：仅差一个碱基的密码子通常编码同一种氨基酸或化学性质相似的氨基酸。因此点突变或误读常常无害。特别是，密码子第二位的嘧啶对应疏水氨基酸。
5. **几乎通用**：细菌、古菌与几乎所有真核生物的核基因使用同一套密码，只有少数已知变异。在脊椎动物线粒体中，`UGA` 编码 Trp，`AGA` 与 `AGG` 不读作 Arg。在支原体（*Mycoplasma*）中，`UGA` 编码 Trp。在一些纤毛虫中，`UAA` 与 `UAG` 编码 Gln。
:::

::: warning "遗传密码就是基因组"
"遗传密码"一语常被宽泛地用来指一个生物的 DNA 序列，如"测定一个人的遗传密码"。严格地说，遗传密码是*词典*，是把密码子与氨基酸对应起来的规则，它对几乎每种生物都（几乎）相同。在不同生物和不同个体之间不同的是用它写成的*正文*：基因组序列。把这两者分开可以避免混淆。突变改变的是正文而不是密码；变异的密码——如线粒体中的——改变的才是词典。
:::

### 阅读框与开放阅读框

一个核苷酸序列在每条链上都可以有三种**阅读框**，共六种，取决于从哪里开始读。其中至多一种（如果有的话）编码蛋白质。**开放阅读框**（ORF）是从一个起始密码子开始、一直运行到下一个框内终止密码子为止的一段。在基因组序列中寻找基因，很大程度上靠寻找长的 ORF（[[bioinformatics/gene-finding]]），因为随机序列中终止密码子出现得很频繁。

::: example 随机情况下 ORF 有多长？{#ex-orf}
在碱基频率相等的随机序列中，(a) 一个给定密码子是终止密码子的概率是多少？(b) 读到（并包括）第一个终止密码子为止的密码子段的平均长度是多少？(c) 一段 100 个密码子的随机序列不含终止密码子的概率是多少？(d) 一个已测序的细菌基因组含有一个长 300 个密码子的 ORF。它很可能是真基因吗？
::: solution
(a) $3/64 = 0.047$。

(b) 读到（并包括）第一个终止密码子的密码子数目服从成功概率 $3/64$ 的几何分布，均值 $64/3 = 21.3$ 个密码子。

(c) $(61/64)^{100} = 0.0082$。

(d) 一段给定的 300 密码子序列不含终止的概率是 $(61/64)^{300} = 5.6\times10^{-7}$。一个几百万碱基对的基因组在六个框中共约有 $10^7$ 个可能的片段，所以偶然出现几个这样的 ORF 是可能的。不过真实的细菌基因组并非随机：它们的碱基组成与密码子使用都有偏向，而且大多数长 ORF 确实是基因。与已知蛋白质的相似性、核糖体结合位点、符合该基因组的密码子使用这类证据可以对问题作出判断。在 GC 含量高的基因组中，终止密码子（A/T 富集）更罕见，偶然出现的长 ORF 更常见。
:::
:::

```python
# 标准遗传密码、六框翻译与最长开放阅读框
from itertools import product

BASES = "TCAG"
AA = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
CODE = {"".join(c): aa for c, aa in zip(product(BASES, repeat=3), AA)}   # 64 个密码子

def revcomp(s):
    return s[::-1].translate(str.maketrans("ACGT", "TGCA"))

def translate(s, frame=0):
    return "".join(CODE[s[i:i+3]] for i in range(frame, len(s) - 2, 3))

def longest_orf(s):
    """两条链上最长的 ATG...终止：(以密码子计的长度、含终止, 链, 框, 蛋白质)。"""
    best = (0, None, None, "")
    for strand, seq in (("+", s), ("-", revcomp(s))):
        for f in range(3):
            prot = translate(seq, f)
            for i, aa in enumerate(prot):
                if aa == "M":
                    j = prot.find("*", i)
                    if j != -1 and j - i + 1 > best[0]:
                        best = (j - i + 1, strand, f, prot[i:j+1])
    return best

counts = {}
for aa in CODE.values():
    counts[aa] = counts.get(aa, 0) + 1
print("sense codons:", 64 - counts["*"], "| stops:", counts["*"])
print("codons per amino acid:", dict(sorted(counts.items(), key=lambda kv: -kv[1])))

dna = "CCATGGCTGAAACCTTCAAGTGGCTGATTGAGTAATCCTTCAGCCATTTAGCCAGG"
for strand, seq in (("+", dna), ("-", revcomp(dna))):
    for f in range(3):
        print(strand, f, translate(seq, f))
print("longest ORF:", longest_orf(dna))
```

这个 64 个字母的字符串是按 `TTT, TTC, TTA, TTG, TCT, …, GGG` 顺序写出的标准密码表。输出如下，`*` 表示终止：

```
sense codons: 61 | stops: 3
codons per amino acid: {'L': 6, 'S': 6, 'R': 6, 'P': 4, 'T': 4, 'V': 4, 'A': 4, 'G': 4, '*': 3, 'I': 3, 'F': 2, 'Y': 2, 'C': 2, 'H': 2, 'Q': 2, 'N': 2, 'K': 2, 'D': 2, 'E': 2, 'W': 1, 'M': 1}
+ 0 PWLKPSSG*LSNPSAI*P
+ 1 HG*NLQVAD*VILQPFSQ
+ 2 MAETFKWLIE*SFSHLAR
- 0 PG*MAEGLLNQPLEGFSH
- 1 LAKWLKDYSISHLKVSAM
- 2 WLNG*RITQSAT*RFQPW
longest ORF: (11, '+', 2, 'MAETFKWLIE*')
```

这 56 bp 的序列是特意写成含有一个短基因的：框 +2 中的 `ATG GCT GAA ACC TTC AAG TGG CTG ATT GAG TAA`，脚本把它找了进来。注意框 −1 在这一小段上根本没有终止，而框 −0 里有一个 `M` 其后没有终止：这是一条跑出序列末端的 ORF。短的、看起来随机的序列常常含有这样的小片段，这就是为什么长度和其他证据在基因预测中如此重要。

## 转运 RNA 及其装载

::: definition 转运 RNA {#def-trna}
**转运 RNA**是长约 76 个核苷酸（范围 70–90）的 RNA。它的二级结构是由四个碱基配对茎与三个环组成的**三叶草**，折叠成长约 7 nm 的 **L 形**三级结构（酵母 tRNA^Phe^，1974 年由里奇（Alexander Rich）、金宋厚（Sung-Hou Kim）及同事与克卢格（Aaron Klug）的小组分别解析）。L 的一端是**反密码子**，即反密码子环中与密码子反平行配对的三个核苷酸。另一端是 3′ 末端序列 `CCA`，其末端腺苷经 2′- 或 3′-OH 以**氨酰酯**键携带氨基酸。tRNA 含有许多修饰核苷，如假尿苷、二氢尿苷、肌苷与甲基化碱基。
:::

由于每条 tRNA 必须能与它读取的所有密码子配对，而意义密码子有 61 个，人们也许预期有 61 种 tRNA。克里克 1966 年意识到，密码子第三位（密码子的 3′ 端）与反密码子第一位（5′ 端）之间的配对不必严格遵守 Watson–Crick 规则。这就是**摆动假说**。

::: proposition 摆动配对 {#prop-wobble}
在反密码子第一位（与密码子第三位配对）处，允许下列配对：

| 反密码子第一个碱基（5′） | 所读密码子的第三个碱基（3′） |
|---|---|
| C | G |
| A | U（自然界罕见；A 通常被修饰为 I） |
| G | C、U |
| U | A、G（修饰过的 U 会限制或扩展这一范围） |
| I（肌苷） | U、C、A |

密码子的前两个位置严格配对。结果是一条 tRNA 至多能读三个同义密码子，61 个意义密码子原则上最少只需 32 种 tRNA（31 种氨基酸的 tRNA 加起始 tRNA）就能读完。脊椎动物线粒体只用 22 种，靠未修饰的 U 读出一个密码子家族的全部四个密码子。
:::

**氨酰-tRNA 合成酶**把每种氨基酸接到它对应的 tRNA 上。大多数生物有 20 种，每种氨基酸一种，分属结构上毫无亲缘关系的两大类，每类十种。每种酶催化一个两步反应。首先氨基酸被 ATP 活化为氨酰腺苷酸，释放焦磷酸。然后氨酰基转移到 tRNA 上：
$$
\text{aa} + \text{ATP} + \text{tRNA} \rightarrow \text{aa-tRNA} + \text{AMP} + \text{PP}_\text{i}.
$$
翻译的准确性取决于这一步，因为核糖体只检查密码子–反密码子配对，不检查氨基酸。1962 年，沙佩维尔（François Chapeville）、李普曼（Fritz Lipmann）、本泽尔（Seymour Benzer）及同事证明，半胱氨酸-tRNA^Cys^ 经化学转化为丙氨酸-tRNA^Cys^ 后，会在半胱氨酸密码子处插入丙氨酸。一旦装载完成，核糖体就相信这条 tRNA。合成酶通过反密码子与其他识别元件认识各自的 tRNA，如 tRNA^Ala^ 受体茎中的一个 G·U 对。有些合成酶还有**编辑**功能。异亮氨酰-tRNA 合成酶无法把较小的缬氨酸完全排除在活化部位之外，于是在第二个装得下缬氨酸、装不下异亮氨酸的部位水解被错误活化的缬氨酸（弗斯特（Alan Fersht）的"双筛"）。由此产生的错误率约为 4 万分之一。

## 核糖体

::: definition 核糖体 {#def-ribosome}
**核糖体**是由两个亚基组成的核糖核蛋白机器。细菌的 **70S** 核糖体（2.5 MDa）由 **30S** 亚基（16S rRNA，约 1540 个核苷酸，21 种蛋白质）与 **50S** 亚基（23S rRNA，约 2900 个核苷酸，5S rRNA 与约 33 种蛋白质）组成。其质量的约三分之二是 RNA。真核生物的 **80S** 核糖体（哺乳动物约 4 MDa）有 **40S** 亚基（18S rRNA，约 33 种蛋白质）与 **60S** 亚基（28S、5.8S 与 5S rRNA，约 47 种蛋白质）。小亚基结合 mRNA 并对它**解码**。大亚基在**肽基转移酶中心**催化肽键形成，并有一条新链穿出的**出口通道**。tRNA 占据横跨两个亚基的三个位点：**A**（氨酰位）、**P**（肽酰位）与 **E**（出口位）。
:::

肽基转移酶中心由 RNA 构成。诺勒（Harry Noller）的小组（1992）发现，除去大部分蛋白质之后，50S 亚基仍保留肽基转移酶活性。决定性的证据来自 2000 年：古菌 *Haloarcula marismortui* 50S 亚基的原子结构（班（Nenad Ban）、尼森（Poul Nissen）、汉森（Jeffrey Hansen）、摩尔（Peter Moore）与斯泰茨（Thomas Steitz））显示活性部位约 1.8 nm 范围内没有任何蛋白质。核糖体是一种核酶。30S 亚基的结构（拉马克里希南（Venki Ramakrishnan）与约纳特（Ada Yonath）的小组，2000）展示了解码如何进行。16S rRNA 的两个腺嘌呤 A1492 与 A1493 翻出，在密码子–反密码子双螺旋的前两个位置检查其小沟，因为那里只有 Watson–Crick 几何形状容得下。拉马克里希南、斯泰茨与约纳特分享 2009 年诺贝尔化学奖。

## 蛋白质合成的步骤

### 起始

在细菌中，30S 亚基在**核糖体结合位点**结合 mRNA。起始密码子上游约 5–10 个核苷酸处一条嘌呤富集的 **Shine–Dalgarno 序列**（共有序列 `AGGAGG`）与 16S rRNA 3′ 端的嘧啶富集序列配对（谢恩（John Shine）与达尔加诺（Lynn Dalgarno），1974）。这把起始密码子安置在 P 位。起始 tRNA 携带的是 **N-甲酰甲硫氨酸**（fMet-tRNA^fMet^），由起始因子 IF2 携 GTP 送来，而 IF1 与 IF3 阻止 50S 亚基过早加入并帮助选定起始密码子。50S 亚基加入后，IF2 水解其 GTP，因子离开。由于每个起始密码子都有自己的核糖体结合位点，细菌 mRNA 可以是**多顺反子**，携带几个基因，各自独立起始。

真核生物的起始利用 5′ 帽。**eIF4F** 复合体结合帽：eIF4E 结合 m⁷G，eIF4A 是 RNA 解旋酶，eIF4G 是支架蛋白，同时也结合 poly(A) 结合蛋白。它募集 **43S 前起始复合体**——一个携带 eIF1、eIF1A、eIF3、eIF5 与 eIF2·GTP·Met-tRNA~i~ 三元复合物的 40S 亚基。该复合体沿 5′ 非翻译区按 5′→3′ **扫描**，直到找到一个处在良好上下文中的 `AUG`（通常也是第一个）。脊椎动物中的最优上下文是 `GCCRCCAUGG`（科扎克（Marilyn Kozak），1986–87），其中 −3 位的嘌呤与 +4 位的 G 最重要。AUG 被识别触发 eIF2 水解 GTP。随后 eIF5B 把 60S 亚基接合进来。因此大多数真核 mRNA 实际上是单顺反子。例外者使用**内部核糖体进入位点**（IRES）——最初在小核糖核酸病毒中发现的有特定结构的 RNA，不需帽就能募集核糖体。通过 eIF2 磷酸化与帽结合蛋白的调节因子对起始的控制，是一个主要的调控靶点（[[molecular-biology/eukaryotic-gene-regulation]]）。

### 延伸

每个延伸循环加一个氨基酸。用细菌的术语表述：

1. **解码。**氨酰-tRNA 与 **EF-Tu** 及 GTP 形成三元复合物到达 A 位（真核生物中为 eEF1A）。若反密码子与密码子正确配对，解码中心闭合，EF-Tu 水解其 GTP 并离开，tRNA **适应**——把它的氨酰端摆进肽基转移酶中心。
2. **肽键形成。**A 位氨酰-tRNA 的 α-氨基进攻 P 位肽酰-tRNA 的酯羰基。生长中的链转移到 A 位 tRNA 上，长出一个残基，P 位 tRNA 则被卸去酰基。rRNA 的催化主要靠为底物定位，P 位 tRNA 末端腺苷的 2′-OH 参与质子转移。
3. **移位。****EF-G** 与 GTP（真核生物中为 eEF2）结合，把 mRNA 与 tRNA 各移动一个密码子。肽酰-tRNA 移入 P 位，去酰基的 tRNA 移入 E 位并从中离开，A 位为下一个密码子空出。

链从 N 端向 C 端生长，mRNA 按 5′→3′ 被读取。这两个方向性由丁齐斯（Howard Dintzis）1961 年对网织红细胞中血红蛋白的定时标记确立。37 °C 时细菌核糖体每秒加上约 15–20 个氨基酸，真核核糖体每秒几个（Alberts，第 7 版）。许多核糖体同时翻译一条 mRNA，沿它排成**多聚核糖体**，所以一条 mRNA 能同时制造几十个蛋白质。

::: proposition 肽键的能量代价 {#prop-energy}
每个加进蛋白质的氨基酸花四个磷酐键：
- 装载 tRNA 花 **2** 个（ATP → AMP + PP~i~，继以 PP~i~ 的水解）；
- 解码时 EF-Tu 水解 **1** 个 GTP；
- 移位时 EF-G 水解 **1** 个 GTP。

每个蛋白质在起始与终止上还多花几个，被拒的氨酰-tRNA（校对）再加一点。因此一个含 $n$ 个残基的蛋白质约花 $4n$ 个高能磷酸键，使蛋白质合成成为生长中的细菌细胞里最大的能量消耗者。
:::

::: example 快速生长的细胞需要多少核糖体？{#ex-ribosomes}
一个快速生长的大肠杆菌细胞每 20 min 翻倍，约含 $3\times10^6$ 个蛋白质分子，平均长度约 300 个残基（数量级数值，取自 BioNumbers 数据库）。(a) 每个世代细胞必须形成多少个肽键？(b) 若每个核糖体每秒加 20 个氨基酸且所有核糖体始终在工作，需要多少个核糖体？(c) 每个世代这要花多少个高能磷酸键？(d) 实测数目在这一生长速率下约为每个细胞 50 000–70 000 个。这一比较说明了什么？
::: solution
(a) $3\times10^6\times300 = 9\times10^8$ 个肽键。

(b) 一个核糖体 1200 s 形成 $20\times1200 = 2.4\times10^4$ 个键，所以 $9\times10^8/2.4\times10^4 \approx 3.8\times10^4$ 个核糖体即可。

(c) 由 [[#prop-energy]]，每个细胞每个世代 $4\times9\times10^8 = 3.6\times10^9$ 个磷酐键。

(d) 实测值略高于最低需求，与任一时刻总有一部分核糖体闲置或正在起始相符。更重要的是，核糖体本身主要由蛋白质与 RNA 构成、也必须先被制造出来，所以快速生长需要在翻译机器上投入巨大。这就是核糖体 RNA 操纵子是细胞中转录最强的基因（[[molecular-biology/transcription#ex-miller]]）、核糖体含量随生长速率成正比上升的原因。
:::
:::

### 准确性与动力学校对

单靠一次密码子–反密码子配对，本身无法把正确的 tRNA 与近正确 tRNA（差一个位置）区分到百倍以上。正确配对与错配之间的自由能差太小。核糖体通过两次检查、并在两次检查之间使用一个不可逆步骤，达到每个密码子约 $10^{-4}$ 的错误率。

::: proposition 动力学校对 {#prop-proofreading}
设正确与不正确的底物以相同的缔合速率结合一个位点，但解离速率相差 $1/f$ 倍（不正确的解离更快），其中 $f = e^{-\Delta\Delta G/RT} < 1$，$\Delta\Delta G$ 为结合自由能之差。若产物直接由结合态生成，错误分率最好也只有约 $f$。但若结合之后跟一个**不可逆**的、消耗能量的步骤（如 GTP 水解），生成一个新的中间态，两种底物在产物生成之前都能从中再次解离，那么两步鉴别相乘，错误分率可降到约 $f^2$。这一改进要用能量和时间来支付，因为正确的底物也会被拒掉一些。（霍普菲尔德（John Hopfield），1974；尼尼奥（Jacques Ninio），1975。）
:::

在翻译中，两次检查是 EF-Tu 水解 GTP 之前对三元复合物的初始选择，和此后的**校对**——未能适应的近正确 tRNA 在此被拒。同一原理也解释了 DNA 复制的准确性、氨酰-tRNA 合成酶与某些信号过程。

::: example 翻译要多准确？{#ex-accuracy}
(a) 37 °C、$\Delta\Delta G = 12\ \mathrm{kJ\,mol^{-1}}$ 时，单步鉴别与带校对的两步各自最好的错误分率是多少？(b) 按每个密码子 $10^{-4}$ 的错误率，300 个残基、1000 个残基的蛋白质中有多大比例是无错合成的？约 34 000 个残基的连蛋白呢？(c) 为什么翻译能容忍比复制更高的错误率？（$\Delta\Delta G$ 为示意值。）
::: solution
(a) $f = \exp[-12\,000/(8.314\times310)] = e^{-4.66} = 9.5\times10^{-3}$：一步约 1 % 的错误。两步给出 $f^2 = 9\times10^{-5}$，接近实测的 $10^{-4}$。

(b) $(1 - 10^{-4})^{300} = 0.97$，$(1 - 10^{-4})^{1000} = 0.90$，$(1 - 10^{-4})^{34\,000} \approx e^{-3.4} = 0.03$。几乎每一条连蛋白分子都带着至少一个错误氨基酸。

(c) 大多数替换能被容忍，尤其换成相似氨基酸的——密码的结构使这类替换很常见。一个错误的蛋白质只是众多拷贝之一，会被稀释和降解。错误不会遗传。更高的准确性会让翻译变慢、耗能更多，所以观察到的速率是速度、成本与准确性之间的折中。
:::
:::

### 终止与核糖体循环

当终止密码子到达 A 位时，没有 tRNA 与之匹配。取而代之的是一个**释放因子**结合上去：细菌中 RF1 读 `UAA` 与 `UAG`，RF2 读 `UAA` 与 `UGA`；真核生物中单个 eRF1 读全部三个。释放因子是模拟 tRNA 外形的蛋白质。一个保守的 Gly-Gly-Gln（GGQ）基序伸入肽基转移酶中心，安置一个水分子去水解肽酰-tRNA 的酯键，把合成完成的链释放出来。GTP 酶 RF3（真核生物中为 eRF3）帮助因子循环。随后核糖体被拆分为亚基——细菌中由核糖体循环因子与 EF-G，真核生物中由 ABCE1——准备下一轮。

::: example 翻译一条消息 {#ex-translate}
一条 mRNA 读作 `5'-GGAGGUAACAUAUGUUCCGUAGCUGGUAAGCC-3'`。(a) 找出 Shine–Dalgarno 序列与起始密码子。(b) 翻译这条 ORF。(c) 下列每个改变对蛋白质有什么效应：`UUC` → `UUU`；`UGG` → `UAG`；删除 `CGU` 的第一个 `C`？
::: solution
(a) 5′ 端的 `GGAGG` 是 Shine–Dalgarno 序列；下游第一个 `AUG` 位于第 12–14 位（从 1 数起），`GGAGG` 的末端与 AUG 的 A 之间有六个核苷酸。（它前面是 `AUA`，不是起始密码子。）

(b) 从 AUG 读起：`AUG UUC CGU AGC UGG UAA` 给出 Met–Phe–Arg–Ser–Trp–终止。

(c) `UUC` → `UUU` 是同义的（都是 Phe）。`UGG` → `UAG` 是无义的：蛋白质止于 Ser 之后，失去 Trp。删除 `CGU` 的 C 给出 `AUG UUC GUA GCU GGU AAG CC...`：Met–Phe–Val–Ala–Gly–Lys–…——移码，从此每个密码子都被改变，并越过原来的终止密码子一直读下去，直到在新框中遇到另一个终止密码子。
:::
:::

## 主题变奏

**扩展密码。**另有两种氨基酸以专门的机制插入。**硒代半胱氨酸**——"第 21 种氨基酸"——见于谷胱甘肽过氧化物酶等酶类，由 `UGA` 编码。只有当 mRNA 含有一个茎环（SECIS 元件）、募集专用的 tRNA 与延伸因子时，它才被读作硒代半胱氨酸。**吡咯赖氨酸**在某些产甲烷古菌与细菌中由 `UAG` 编码。在实验室中，经过工程改造、不与宿主自身体系交叉反应的合成酶与 tRNA 配对（**正交**对）可以在重新指派的终止密码子处插入非天然氨基酸。

**重编码。**有些 mRNA 指示核糖体偏离标准规则。在**程序性移码**中，一个"滑动"序列后面跟一个假结或茎环，使一部分核糖体后退一个核苷酸。HIV 等逆转录病毒和冠状病毒借此以固定比例从一条 mRNA 制造两种蛋白质；细菌释放因子 RF2 通过 +1 移码调控自身的合成。

**翻译偶联事件。**链从出口通道伸出时，分子伴侣帮助它折叠，酶切除起始的 Met（细菌中是甲酰基），真核生物中**信号识别颗粒**结合 N 端信号序列，把核糖体与 mRNA 送到内质网——分泌途径的开始（[[cell-biology/protein-sorting]]）。

::: application 靶向核糖体的抗生素
细菌与真核核糖体之间的差异使许多抗生素能够有选择地停止细菌的蛋白质合成。它们的结合位点已在核糖体结构中定位。**链霉素**与其他氨基糖苷类结合 30S 解码中心，引起误读。**四环素类**阻断氨酰-tRNA 结合 A 位。**氯霉素**结合肽基转移酶中心。**红霉素**等大环内酯类阻断出口通道。**嘌呤霉素**模拟氨酰-tRNA 的末端，被接到生长链上造成提前释放，而且对所有核糖体都起作用，所以它是实验室工具而非药物。耐药性常来自结合位点处 rRNA 的甲基化或突变。线粒体核糖体与细菌的相像，正是某些药物有副作用的原因。临床应用与耐药性在 [[microbiology/antimicrobials]] 与医学图谱中讨论。
:::

::: quiz
一条 tRNA 的反密码子是 `5'-GAA-3'`。按摆动规则，它能读哪些密码子？
- [x] `UUC` 与 `UUU`（Phe）
- [ ] `GAA` 与 `GAG`（Glu）
- [ ] `CUU` 与 `CUC`（Leu）
- [ ] 仅 `UUC`
::: solution
反平行配对：反密码子 5′-G-A-A-3′ 与密码子 3′-C-U-U-5′ 配对，即 Watson–Crick 配对下的密码子 `5'-UUC-3'`。反密码子第一个碱基 G 还可以在密码子第三位与 U 形成摆动配对，所以 `UUU` 也能被读。两者都编码苯丙氨酸。把密码子写成与反密码子同方向（`GAA`）是最常见的错误。
:::

::: history
克里克 1955 年提出接头假说，1966 年提出摆动假说。扎姆奇尼克（Paul Zamecnik）、霍格兰（Mahlon Hoagland）及同事 1956–58 年发现了 tRNA 与氨基酸的活化。1961 年，尼伦伯格与马泰证明 poly(U) 编码多聚苯丙氨酸，克里克、巴尼特、布伦纳与沃茨-托宾证明密码以三联体读取，丁齐斯确立了从 N 端到 C 端的合成方向。尼伦伯格与莱德的三核苷酸结合实验（1964）与科拉纳的人工多聚物在 1966 年前完成了密码表的编制。霍利 1965 年测定了第一个 tRNA 序列。谢恩与达尔加诺 1974 年确定了核糖体结合序列——同年 tRNA 的三维结构被解析；霍普菲尔德提出动力学校对。班、尼森、摩尔、斯泰茨及同事 2000 年证明肽基转移酶中心是 RNA；拉马克里希南与约纳特的小组同年解析了 30S 亚基。
:::

::: summary
- 遗传密码是三联体、不重叠、简并的：61 个意义密码子编码 20 种氨基酸，3 个终止密码子（`UAA`、`UAG`、`UGA`），以 `AUG` 起始。它使误差最小、几乎通用，在线粒体和少数生物中有变异。
- 每条序列有六个阅读框。随机序列平均每 21 个密码子出现一个终止，所以长 ORF 提示基因。
- tRNA（约 76 nt，三叶草与 L 形）把氨基酸载在 3′ `CCA` 上。密码子第三位的摆动使约 32 种 tRNA 就能读 61 个密码子。
- 氨酰-tRNA 合成酶（两大类）用 ATP 装载 tRNA。核糖体信任已装载的氨基酸，所以合成酶的准确性（有编辑辅助）设定了错误率的底线。
- 核糖体（70S = 30S + 50S；80S = 40S + 60S）是核酶。小亚基解码（A1492/A1493 检查密码子–反密码子几何形状）；大亚基的 rRNA 形成肽键。
- 起始：细菌靠 Shine–Dalgarno 配对与 fMet-tRNA；真核生物靠帽结合、扫描与 Kozak 上下文。延伸：EF-Tu 送来氨酰-tRNA，肽基转移，EF-G 移位（A → P → E）。终止：带 GGQ 基序的释放因子水解肽酰-tRNA。
- 每个肽键花四个磷酐键。准确性（每密码子约 $10^{-4}$）来自动力学校对：被 GTP 水解分开的两步鉴别相乘（$f \to f^2$）。
- 硒代半胱氨酸与吡咯赖氨酸通过重编终止密码子扩展了密码；程序性移码与 IRES 是进一步的偏离；许多抗生素作用于细菌核糖体。
:::

::: exercise 数密码子 {level=1 check="61"}
标准遗传密码中有多少个意义密码子？
::: solution
$64 - 3 = 61$。

::: exercise 反向翻译 {level=1 check="216"}
有多少条不同的 mRNA 编码序列（不含终止密码子）能编码肽段 Met–Leu–Ser–Trp–Arg？
::: solution
把每个残基的密码子数目相乘：Met 1、Leu 6、Ser 6、Trp 1、Arg 6，所以 $1\times6\times6\times1\times6 = 216$。简并性使从蛋白质序列设计 DNA 探针很困难；探针设计者偏爱 Met 与 Trp 富集的区段。

::: exercise 一个蛋白质的能量 {level=1 check="1200"}
忽略起始、终止与校对，合成一个 300 个氨基酸的蛋白质要用多少个高能磷酸键？
::: solution
每个残基四个：$4\times300 = 1200$。（严格说，第一个残基没有由肽键连入，但它的装载要花两个；这些小的修正就在被忽略的起始代价之内。）

::: exercise 一个错义、一个无义与一个移码 {level=2}
编码序列 `5'-ATG AAA TGG CTT TAC GGA TAA-3'` 编码一个短肽。(a) 翻译它。(b) 第三个密码子中的哪个单碱基置换会创造一个终止密码子，可能是哪几个终止？(c) 给出在第一个密码子之后插入一个 A 的效应。
::: solution
(a) Met–Lys–Trp–Leu–Tyr–Gly–终止。

(b) `TGG` → `TAG`（第 2 位 G→A）或 `TGA`（第 3 位 G→A）：两者都是无义突变，使肽段止于 Lys 之后。

(c) `ATG A AAA TGG CTT TAC GGA TAA` 变为 `ATG AAA ATG GCT TTA CGG ATA A..`：Met–Lys–Met–Ala–Leu–Arg–Ile–…——移码；原来的终止密码子不再在框内。
:::

在碱基频率相等的随机序列中，48 个连续密码子不含终止密码子的概率是多少（两位小数）？
::: solution

::: exercise 一个密码子家族所需的最少 tRNA 数 {level=2}
用 [[#prop-wobble]] 的摆动规则，读出四个甘氨酸密码子 `GGU`、`GGC`、`GGA`、`GGG` 至少需要多少条 tRNA，它们的反密码子各是什么？脊椎动物线粒体如何只用一条就做到？
::: solution
两条：反密码子 `5'-GCC-3'`（摆动位的 G 读 C 与 U，即 `GGC` 与 `GGU`）与 `5'-UCC-3'`（U 读 A 与 G，即 `GGA` 与 `GGG`）。或者 `5'-ICC-3'` 读 U、C 与 A，只需第二条 tRNA 专读 `GGG`。脊椎动物线粒体使用摆动位为未修饰 U 的一条 tRNA，在这种情形下它可以与全部四种碱基配对（"超级摆动"），读完整个家族。
:::

::: exercise 解读趾印实验 {level=3}
在**趾印法**（toeprinting）测定中，逆转录酶从退火在下游的引物开始抄写 mRNA；结合在 mRNA 上的核糖体在距其 P 位密码子第一个核苷酸约 15–16 个核苷酸处使酶停止，得到一条 cDNA 带。对一条起始密码子位于 101–103 位的细菌 mRNA：(a) 30S 亚基加起始 tRNA 时，在 AUG 的 A 起 +16 处出现一条强带；只有 30S 亚基时无带。请解释。(b) 一个 Shine–Dalgarno 序列 `AGGAGG` 变为 `ACCACC` 的突变体，即使有起始 tRNA 也无带。请解释。(c) 一个专门化的核糖体中 16S rRNA 3′ 端的补偿性突变，为突变 mRNA（而不是野生型）恢复了这条带。这说明了什么？
::: solution
(a) +16 的带表明形成了一个 AUG 位于 P 位的 30S 起始复合体；只有当起始 tRNA 存在并与 AUG 配对时它才形成，所以稳定复合体需要 P 位中的密码子–反密码子配对。

(b) 没有 Shine–Dalgarno 配对，30S 亚基不能稳定结合在这个核糖体结合位点，所以不形成起始复合体。

(c) 抗 Shine–Dalgarno 序列发生互补改变的 16S rRNA 只与突变体配对、不再与野生型序列配对，从而只为突变 mRNA 恢复了结合。这一补偿性突变实验（由许（Anna Hui）与德博尔（Herman de Boer）1987 年完成）证明 Shine–Dalgarno 相互作用是 mRNA 与 16S rRNA 之间的碱基配对，这类"正交核糖体"现已被用于合成生物学。
:::
:::

::: exercise 解读错误掺入数据 {level=3}
对在大肠杆菌中表达的重组蛋白做质谱，发现其天冬酰胺密码子 `AAU` 中有 0.2 % 的位置该残基变成了赖氨酸；而 `AAC` 密码子上的这种替换很罕见。用摆动规则和密码的结构解释这一现象，并提出如何改造表达系统来减少这一错误。
::: solution
Lys 由 `AAA` 与 `AAG` 编码；Asn 由 `AAU` 与 `AAC` 编码。把 `AAU` 误读为 Lys 要求一条 tRNA^Lys^（反密码子 `UUU`，摆动位为修饰过的 U）在密码子第三位与 U 配对——一个类似摆动配对的 G·U 型错配，相对能被容忍，而与 C 配对则是一种更不稳定的错配。若 Asn-tRNA（反密码子 `GUU`，读两个密码子）成为限制因素——高表达重组基因的密码子使用与大肠杆菌不同时就会如此——近正确的 Lys-tRNA 对 A 位的竞争就更成功，错误随之上升。补救办法：在合成基因中全程使用 `AAC` 密码子（对基因重编密码）、降低表达速率，或给宿主补充针对限制密码子的额外 tRNA 基因。
:::
