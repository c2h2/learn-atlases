一个人类细胞中装着约 2 米长的 DNA，而细胞核只有大约 10 微米宽。这些 DNA 必须被压缩十万倍以上，可每一个基因仍要能被读取它的蛋白质接触到。而且每次分裂时，整个基因组都必须先解开、复制、再重新包装，并且不能打结。分子生物学正是从这一物理问题开始的。一条又长又僵硬、带负电荷的聚合物如何被折叠、扭转与包裹，决定了其中哪些部分可以被读取，而执行这些折叠的蛋白质本身就是基因调控的工具。

本章从双螺旋出发，追问它的几何形状对结合它的蛋白质意味着什么。随后把 DNA 当作一个拓扑对象来处理：连环数、超螺旋以及改变它们的拓扑异构酶；最后讨论染色质：核小体、间期与有丝分裂染色体的高级折叠，以及细菌类核。核苷酸的化学、碱基互补配对、双螺旋稳定性与熔解在化学图谱（[核酸](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)）中讲解，基因由 DNA 构成的证据见 [[genetics/genes-and-mutation]]。本章建立在这两者之上。

## 双螺旋：蛋白质的作用表面

沃森与克里克 1953 年的模型由两条反向平行的多核苷酸链绕同一根轴盘绕而成。糖-磷酸骨架在外侧，碱基在内部配对：A 与 T，G 与 C。这一模型有两点对分子生物学家最为重要。第一，一条链的序列决定了另一条链的序列，因此任何一条链都可充当模板。第二，双螺旋的外表面并不均一。由于一个碱基对的两条糖苷键都从碱基对的同一侧伸出，骨架在双螺旋一侧的距离比另一侧更近，于是两条宽窄不同的沟绕其盘旋。

::: definition B-DNA 及其沟 {#def-bdna}
**B-DNA** 是混合序列 DNA 在生理盐浓度的水溶液中形成的右手双螺旋。它在溶液中约为每圈 **10.5 个碱基对**，每个碱基对沿轴上升 **0.34 nm**（所以螺距约 3.6 nm），直径约 **2 nm**。碱基对几乎垂直于螺旋轴。双螺旋有一条**大沟**，约 2.2 nm 宽、相当深，还有一条**小沟**，约 1.2 nm 宽。任一条链都按 5′→3′ 方向书写，两条链走向相反（反向平行）。
:::

每圈 10.5 个碱基对这一数值来自溶液测定（詹姆斯·王（James Wang），1979，依据是把不同长度的 DNA 片段插入闭合环后连环数的变化）。早期纤维衍射图中每圈 10 个碱基对只是近似值。DNA 不是刚性杆，但在短距离上它是刚硬的：其**持久长度**——方向保持相关的距离——在生理盐浓度下约为 50 nm，即 150 个碱基对。要比这弯曲得更剧烈——核小体正是这样——需要付出自由能，而这笔能量必须由使其弯曲的蛋白质支付。

沟中暴露的碱基对边缘带有氢键供体与受体，以及胸腺嘧啶的甲基。在**大沟**中，这些基团的排布方式对四种碱基对取向（A·T、T·A、G·C、C·G）各不相同，因此插进大沟的蛋白质侧链无需打开双螺旋就能读出序列。在小沟中，A·T 与 T·A 几乎无法区分，G·C 与 C·G 也一样。纳德里安·西曼（Nadrian Seeman）、约翰·罗森伯格（John Rosenberg）与亚历山大·里奇（Alexander Rich）在 1976 年指出了这一点。这就是为什么大多数序列特异性 DNA 结合蛋白——如细菌阻遏蛋白与 [[molecular-biology/eukaryotic-gene-regulation]] 中的真核转录因子——把一根 α 螺旋插进大沟。结合小沟的蛋白质——如 [[molecular-biology/transcription]] 中的 TATA 结合蛋白——往往读取的是 DNA 的*形状*（狭窄的小沟、易于弯曲的序列），而不是单个碱基。

还存在其他双螺旋形式。**A-DNA** 在脱水条件下更稳定，RNA 双链与 DNA-RNA 杂合双链也采取这种构象；它是右手螺旋，更宽（约 2.6 nm），每圈约 11 个碱基对，碱基对相对螺旋轴倾斜，大沟深而窄。**Z-DNA** 由交替的嘌呤-嘧啶序列（如 `(CG)n`）在高盐或负超螺旋下形成，是每圈约 12 个碱基对的左手螺旋，骨架呈锯齿形。已发现特异结合 Z-DNA 的蛋白质，但细胞内究竟形成多少 Z-DNA 仍不确定。

::: example 在双螺旋的哪一侧？ {#ex-helical-phase}
某个 DNA 结合蛋白的两个拷贝结合在一段平直 B-DNA 上中心相距 $d$ 个碱基对的两个位点。只有当两个位点朝向双螺旋的同一侧时，两个蛋白质才会相互接触，从而协同结合。按每圈 10.5 bp 计算 $d = 21$、$26$ 与 $63$ bp 时两个位点之间的夹角，并说明哪些间距无需弯曲或扭转 DNA 就能实现接触。
::: solution
每个碱基对使双螺旋转动 $360^\circ/10.5 = 34.3^\circ$，所以两个位点之间的夹角为 $34.3^\circ\times d$，按 $360^\circ$ 取模读数。

- $d = 21$：$21/10.5 = 2.0$ 圈整，所以夹角为 $0^\circ$，两个位点在同一面。
- $d = 26$：$26/10.5 = 2.476$ 圈。小数部分 0.476 圈合 $171^\circ$，所以两个位点几乎在相对的两面。要在如此短的距离上接触，就得把中间的 DNA 扭转将近半圈，这是高代价的。
- $d = 63$：$63/10.5 = 6.0$ 圈，所以两个位点又在同一面。但二者相距 21.4 nm，只有当中间的 DNA 成环弹出时两个蛋白质才可能接触。

正是这类实验——把两个操纵基因之间的间距逐个碱基对地改变——表明 λ 噬菌体与 *lac* 阻遏蛋白的阻遏强度随约 10.5–11 bp 的周期起伏。这是这些蛋白质靠形成 DNA 环发挥作用的最佳证据之一（[[molecular-biology/bacterial-gene-regulation]]）。
:::
:::

## 基因组有多长？

与容纳它们的细胞相比，基因组是巨大的，这些数字解释了为什么包装不可避免。

::: example 基因组长度与压缩倍数 {#ex-length}
(a) 大肠杆菌（*Escherichia coli*）K-12 染色体有 $4.64\times10^6$ bp。按 B-DNA 计它有多长？与一个约 2 μm 长的细胞相比如何？(b) 人 1 号染色体约有 $2.49\times10^8$ bp（GRCh38 组装）。它的 DNA 有多长，在一条约 10 μm 长的有丝分裂染色体中被压缩了多少倍？(c) 一个二倍体人细胞核装着多少 DNA？
::: solution
(a) $4.64\times10^6\times0.34\ \mathrm{nm} = 1.58\times10^6\ \mathrm{nm} = 1.58\ \mathrm{mm}$，约为细胞长度的 800 倍。

(b) $2.49\times10^8\times0.34\ \mathrm{nm} = 8.5\times10^7\ \mathrm{nm} = 85\ \mathrm{mm}$。每条有丝分裂染色单体含一个 DNA 分子，所以线性压缩为 $85\ \mathrm{mm}/10\ \mu\mathrm{m} \approx 8.5\times10^3$，在 $10^4$ 量级。（染色体长度是近似值；有丝分裂染色体的长度随制备而异。）

(c) 约 $6.2\times10^9$ bp 的二倍体基因组相当于 $6.2\times10^9\times0.34\ \mathrm{nm} = 2.1\ \mathrm{m}$ 的 DNA，装在一个直径约 5–10 μm 的细胞核里。
:::
:::

真核生物之间的基因组大小相差可达一千倍以上，而且与生物体的复杂程度只有松散的关联。洋葱（*Allium cepa*）每个单倍体基因组的 DNA 约是人的五倍。这一不匹配曾被称为 **C 值悖论**，其解释很简单：大基因组中多出的 DNA 大多是重复序列——尤其是转座元件（[[molecular-biology/dna-repair-recombination]]）——而不是更多的基因。人类大约有 20000 个蛋白质编码基因（GENCODE，2024 年数据），编码序列只占基因组的约 1.5 %。

## DNA 拓扑学

闭合环状 DNA——或末端被蛋白质固定的长线性分子——有一个自由线性分子没有的性质：它的两条链以确定的次数相互穿套，而这个次数不切断单链就无法改变。**连环数**（linking number）$Lk$、**扭转数**（twist）$Tw$ 与**扭曲数**（writhe）$Wr$（三者满足 $Lk = Tw + Wr$）以及超螺旋密度 $\sigma = (Lk - Lk_0)/Lk_0$ 的定义见化学图谱（[核酸、长度与拓扑](/learn/chemistry/lesson.php?c=biochemistry&l=nucleic-acids)）。这里把它们重述为生物学家需要的工作规则。

::: proposition DNA 拓扑学的规则 {#prop-topology}
对一条 $N$ 个碱基对的共价闭合双链 DNA：
1. $Lk$ 是整数，在任何不切断单链的形变下保持不变。它是扭转数与扭曲数之和，$Lk = Tw + Wr$，二者可以连续地相互转化。
2. 松弛分子的 $Lk_0 = N/h$，其中 $h \approx 10.5$ bp 每圈。$Lk < Lk_0$ 的分子是**负超螺旋**（$\sigma < 0$），$Lk > Lk_0$ 的是**正超螺旋**。
3. **Ⅰ 型拓扑异构酶**切断一条链，让双链旋转或把另一条链穿过缺口，再把缺口重新封闭，每一轮事件使 $Lk$ 改变 $\pm1$。**Ⅱ 型拓扑异构酶**切断两条链，把另一段双链穿过断口后再封闭，每一轮事件使 $Lk$ 改变 $\pm2$，并消耗 ATP。
4. 超螺旋的自由能近似与 $\sigma$ 的平方成正比，$\Delta G \propto N\sigma^2$，因此随超螺旋程度急剧上升。负超螺旋降低了局部解开双链所需的额外自由能。
:::

规则 3 由凝胶电泳直接证明。超螺旋分子构象紧密、在胶上跑得快，$Lk$ 相差 1 的分子会分成 **拓扑异构体** 梯带。用 Ⅰ 型酶处理得到间距为 1 的梯带，而 Ⅱ 型酶以 2 为步长改变分布。规则 4 解释了为什么负超螺旋有助于复制起点与启动子打开。当解链泡形成时，解旋不足的分子中储存的部分张力得到释放，因此起始复制或转录所需的自由能更少。

拓扑异构酶不是可有可无的。两个问题使它成为必需。

1. **复制叉或聚合酶前方的解旋。** 复制或转录 DNA 必须把两条链分开，每通过 10.5 个碱基对就去掉一圈扭转。如果前方的 DNA 不能自由旋转——因为它太长或被锚住——这种解旋就会在机器前方堆积**正超螺旋**、在后方留下**负超螺旋**。这就是勒罗伊·刘（Leroy Liu）与詹姆斯·王（James Wang）（1987）的双超螺旋域模型。在大肠杆菌中，**DNA 促旋酶**——马丁·盖勒特（Martin Gellert）及其同事 1976 年发现的一种 Ⅱ 型酶——除去正超螺旋并利用 ATP 引入负超螺旋。真核生物的拓扑异构酶 I 与 Ⅱ 可松弛两种符号的超螺旋。
2. **解开子代分子间的连环。** 当两个复制叉相遇时，两个子代双链仍然相互缠绕（**连环体**，catenated）。只有 Ⅱ 型酶能把它们分开——让一个双链穿过另一个：大肠杆菌中的拓扑异构酶 IV 与真核生物中的拓扑异构酶 Ⅱ。没有它，姐妹染色单体在有丝分裂时无法分离。

::: application 拓扑异构酶作为药物靶点
因为拓扑异构酶靠制造瞬时断裂来工作，一种在 DNA 被切断时把酶困住的药物，就把酶变成了 DNA 损伤的来源。喹诺酮类抗生素（如环丙沙星（ciprofloxacin））困住细菌的促旋酶与拓扑异构酶 IV。喜树碱（camptothecin）衍生物困住人拓扑异构酶 Ⅰ，依托泊苷（etoposide）与阿霉素（doxorubicin）困住拓扑异构酶 Ⅱ；它们用于癌症化疗，其中分裂最快的细胞受害最重。这些药物的临床使用属于医学图谱（[/learn/medicine/](/learn/medicine/)）。这里的要点是机制性的：药物靶标是酶-DNA 中间体，而这只有在拓扑异构酶会切断 DNA 的前提下才可能。
:::

::: quiz
一个松弛的闭合环状质粒用某种酶与 ATP 处理。在胶上，产物跑成一条 $Lk$ 值相差 2、且都低于 $Lk_0$ 的拓扑异构体梯带。它最可能是什么酶？
- [ ] 大肠杆菌拓扑异构酶 I
- [x] DNA 促旋酶
- [ ] 人拓扑异构酶 I
- [ ] DNA 连接酶
::: solution
以 2 为步长改变 $Lk$ 需要双链断裂与穿链，所以该酶是 Ⅱ 型拓扑异构酶。从松弛 DNA 引入**负**超螺旋需要耗能，促旋酶正是借助 ATP 做到这一点的 Ⅱ 型酶。Ⅰ 型酶以 1 为步长改变 $Lk$，而且在没有能源的情况下只能松弛 DNA。连接酶只封闭切口；在嵌入剂或结合蛋白存在时封闭带切口的环虽能把超螺旋固定下来，但不会以 2 为步长。
:::
:::

## 核小体

在真核生物中，第一级包装是核小体。它的发现在 1973–75 年间来自多个方向。迪恩·休伊什（Dean Hewish）与利·伯戈因（Leigh Burgoyne）发现，大鼠肝细胞核内的一种核酸酶把染色质切成单位长度整数倍的片段。阿达·奥林斯与唐纳德·奥林斯（Ada and Donald Olins），以及克里斯托弗·伍德科克（Christopher Woodcock），在铺开的染色质电镜照片上看到了"串珠"结构。罗杰·科恩伯格（Roger Kornberg）（1974）提出，该结构单位是约 200 bp 的 DNA 与四种核心组蛋白各两个分子的结合体。

::: definition 核小体、核心颗粒与连接 {#def-nucleosome}
**核小体核心颗粒**是 147 bp 的 DNA 以左手超螺旋绕**组蛋白八聚体**约 1.65 圈；八聚体是一个直径约 11 nm、高 5.5 nm 的盘。八聚体由中央的 (H3–H4)₂ 四聚体加两侧的两个 H2A–H2B 二聚体组成。每种组蛋白都有一个**组蛋白折叠**结构域（与 DNA 结合）和一条从颗粒中伸出、大量发生修饰的柔性 N 端**尾巴**。相邻核心颗粒之间由**连接 DNA** 相连，通常 20–80 bp。**核小体重复长度**（核心加连接）在酿酒酵母中约 165 bp，在大多数动物细胞中约 185–200 bp。**连接组蛋白** H1 结合在 DNA 进出核心颗粒之处。一串核小体宽约 10 nm，即 **10 nm 纤维**。
:::

核心颗粒的原子结构由卡罗琳·吕格（Karolin Luger）、蒂莫西·里奇蒙德（Timothy Richmond）及同事于 1997 年解析。DNA 约每 10 bp 与八聚体接触一次——此处其小沟朝向内侧——共约 14 个接触区，涉及伸入小沟的精氨酸侧链、螺旋偶极以及与磷酸之间的氢键。组蛋白富含赖氨酸与精氨酸，其正电荷中和了 DNA 的大部分电荷。接触发生在骨架而非碱基上，所以组蛋白几乎能结合任何序列。易于弯曲的序列——例如每隔 10 bp 使小沟朝向八聚体的 A·T 富集台阶——更受偏好，而某些序列——例如长的 poly(dA·dT) 序列——则抗拒缠绕。

::: example 解读微球菌核酸酶梯带 {#ex-mnase}
细胞核用微球菌核酸酶短暂消化——这种酶切割连接 DNA 远快于切割八聚体上的 DNA——然后纯化 DNA 并跑胶。在约 195、390、585 与 780 bp 处出现条带。长时间消化后只剩 147 bp 一条带。(a) 核小体重复长度是多少？(b) 平均连接长度是多少？(c) 设全基因组都取这一重复长度，一个二倍体人细胞核中有多少个核小体？
::: solution
(a) 各条带是 195 bp 的整数倍：1、2、3 和 4 个核小体连同各自的连接。重复长度为 195 bp。

(b) 长时间消化把连接切净，只留下受保护的 147 bp 核心，所以平均连接为 $195 - 147 = 48$ bp。

(c) $6.2\times10^9/195 = 3.2\times10^7$，约 3000 万个核小体。即 $2.5\times10^8$ 个核心组蛋白分子，约每 25 bp DNA 一个组蛋白分子。因此组蛋白基因以多拷贝存在，其表达与 S 期的 DNA 复制相偶联（[[cell-biology/cell-cycle]]）。
:::
:::

### 核小体与超螺旋

把 DNA 以左手超螺旋包绕在八聚体上会引入负的扭曲数。如果让一条闭合环状 DNA 组装上核小体，并用拓扑异构酶把其间未缠绕的 DNA 松弛掉，那么除去组蛋白后 DNA 将呈负超螺旋。这样测得每个核小体约束约 $-1$ 的连环数变化，尽管 DNA 只绕了约 1.65 圈超螺旋。这一差异曾被称为*连环数悖论*，其来源是缠绕在八聚体上的 DNA 也略微过旋（约每圈 10.2 bp，游离时为 10.5 bp），抵消了扭曲数的一部分。所以真核 DNA 总体上是负超螺旋的，但超螺旋大多是**约束态**的——被约束在核小体上——不像细菌的那样可以自由驱动链的分离。

::: example 给迷你染色体数核小体 {#ex-minichromosome}
病毒 SV40 的环状 DNA 长 5243 bp，在宿主细胞核内像迷你染色体一样被包装。在一种能松弛未缠绕 DNA 的 Ⅰ 型拓扑异构酶存在下去蛋白，再用电泳分析纯化的 DNA，测得其平均连环数亏损约为 $\Delta Lk = -24$。(a) 估计核小体数目。(b) 去蛋白后 DNA 的超螺旋密度是多少？(c) 这与核小体重复长度一致吗？
::: solution
(a) 每个核小体约束 $\Delta Lk \approx -1$，所以约有 24 个核小体。

(b) $Lk_0 = 5243/10.5 = 499.3$，所以 $\sigma = -24/499.3 = -0.048$。

(c) $5243/24 = 218$ bp 每个核小体，落在重复长度的通常范围内。实际上 SV40 在其起点与启动子周围有一个几百个碱基对长的无核小体区，所以分子其余部分的重复略短。这段自由区正是调控蛋白质结合之处——这是核小体位置控制 DNA 可及性的第一个提示（[[molecular-biology/eukaryotic-gene-regulation]]）。
:::
:::

核小体并非固定不动。**染色质重塑复合体**——如 SWI/SNF、ISWI 与 INO80——利用 ATP 沿 DNA 滑动八聚体、把八聚体逐出或交换组蛋白变体。**组蛋白分子伴侣**在复制与转录过程中装配与拆卸核小体。组蛋白变体会改变核小体的性质：H2A.Z 标记启动子，H3.3 不依赖复制地沉积在转录中的区域，**CENP-A** 在着丝粒处取代 H3，并在此指定动粒的位置。组蛋白尾巴的共价修饰——如乙酰化、甲基化、磷酸化与泛素化——改变核小体彼此以及与别的蛋白质之间的相互作用。这些将在 [[molecular-biology/eukaryotic-gene-regulation]] 中讨论。

## 核小体之上：染色体的折叠

10 nm 纤维只把 DNA 压缩约六倍：大约每 11 nm 的核小体对应约 200 bp、68 nm 长的 B-DNA。还需要多得多的折叠。

几十年来，教科书把 **30 nm 纤维**画成下一级结构：规则的核小体螺旋阵列——或是单排的螺线管（约翰·芬奇（John Finch）与阿龙·克鲁格（Aaron Klug），1976），或是双排的锯齿形。纯化的染色质在中等盐浓度并有 H1 时确实容易在体外形成这样的纤维。但它们在活细胞的间期细胞核中是否存在，就远没有那么清楚了。对玻璃化细胞核的冷冻电镜与对体内染色质的电子断层扫描（ChromEMT；霍恩·欧（Horng Ou）、克洛达·奥谢（Clodagh O'Shea）及同事，2017）发现的是宽 5–24 nm、以不同密度堆积的无序核小体链，而不是规则的 30 nm 纤维。截至 2026 年的当前看法是：规则的 30 nm 纤维即使在大多数间期细胞中存在，也只是局部的、瞬时的。

::: warning "DNA 按固定层级包装：10 nm 纤维、30 nm 纤维、环、染色体"
这一整齐的阶梯是一个方便的概括，而不是已确立的结构。10 nm 纤维与核小体是确定的。30 nm 纤维在体外和少数特殊细胞核（如某些精子与有核红细胞）中有充分证据，但在大多数间期细胞中并看不到。对于高级折叠，更好的描述方式是随细胞周期与基因活性变化的环与结构域，而不是一层层固定的螺旋。当你遇到那张阶梯示意图时，请把核小体以上的各级读作假说。
:::

在核小体之上，证据最充分的组织原则是**环**。两类环状蛋白质复合体——**SMC**（染色体结构维持蛋白）复合体**黏连蛋白（cohesin）**与**凝聚蛋白（condensin）**——能挤出 DNA 环：结合在 DNA 上的复合体利用 ATP 从一侧或两侧收拢 DNA，使环扩大。凝聚蛋白的环挤出在 2018 年的单分子实验中被直接观察到（Ganji 等）。**染色质构象捕获**及其全基因组形式 **Hi-C**（Lieberman-Aiden 等，2009）把空间上邻近的 DNA 片段交联起来，统计每对位点被连接的频率。它显示间期基因组被划分为约 0.1–1 Mb 的**拓扑关联结构域**（TAD），域内接触频繁；这些结构域常以结合着蛋白质 **CTCF** 的位点为边界。一个得到广泛支持的模型是：黏连蛋白挤出环，直到遇到以特定取向结合的 CTCF 为止。在更大的尺度上，活跃与不活跃的染色质分离为不同的**区室**，每条染色体在细胞核中占据自己的**染色体疆域**。细节属于 [[genomics/nuclear-organisation]]。

在有丝分裂中，凝聚蛋白把每条染色单体压缩成一根坚硬的棒，由绕中央轴排列的嵌套环构成，比间期再压缩约 10 到 20 倍。拓扑异构酶 Ⅱ 与凝聚蛋白合作，除去姐妹染色单体之间的连环体，使它们能在后期分离（[[cell-biology/cell-cycle]]）。

### 常染色质与异染色质

在光学显微镜下，间期细胞核显示出染色较浅的区域——**常染色质**——与保持凝聚、染色较深的区域——**异染色质**（埃米尔·海茨（Emil Heitz），1928）。常染色质含大多数活跃的基因。**结构异染色质**位于着丝粒周围与端粒，主要由重复序列构成，基因贫乏，在所有细胞中都处于凝聚状态。在人类，着丝粒由 171 bp 的 α-卫星重复序列成串排列而成，延伸达数 Mb。**兼性异染色质**在某些细胞中凝聚而在另一些细胞中不凝聚；雌性哺乳动物失活的 X 染色体是经典例子（[[genetics/non-mendelian-inheritance]]）。异染色质的特征是特定的组蛋白修饰（组蛋白 H3 第 9 位赖氨酸三甲基化 H3K9me3——在结构异染色质中被蛋白质 HP1 结合；Polycomb 抑制的兼性异染色质中的 H3K27me3），在脊椎动物中还有 DNA 甲基化。一个基因因染色体重排被移到异染色质附近时，可在某些细胞中被沉默而在另一些细胞中活跃，产生镶嵌现象，称为**位置效应花斑**（穆勒，1930，黑腹果蝇的 *white* 基因），这表明异染色质可以沿染色体扩展。

::: intuition 一座会重排书架的图书馆
把染色质想象成一座图书馆：书不仅被上架，还被捆成一捆一捆，而捆扎方式随使用情况改变。经常查阅的书放在开架上（常染色质：核小体间距较大、尾巴乙酰化）。这个细胞用不到的书被紧紧捆好放在地下室（异染色质）。图书管理员（重塑复合体、修饰酶）能解开书捆、搬动书捆，并留下标记（组蛋白标记）告诉下一位管理员该做什么。因此，读取一个基因，首先得能够到它。
:::

## 细菌类核

细菌没有组蛋白（有趣的是，古菌有：许多古菌把 DNA 绕在类组蛋白蛋白质上，形成与核小体同源的伸展结构）。大肠杆菌的染色体形成一个致密体——**类核**——占据细胞质中一个没有膜围绕的确定区域。三个因素使它折叠。第一是**负超螺旋**，由促旋酶与拓扑异构酶 I 的平衡维持在 $\sigma \approx -0.06$；其中约一半是自由的，另一半被蛋白质约束。第二是**类核相关蛋白质**：HU 与 IHF 使 DNA 急剧弯曲，H-NS 桥联 DNA 片段并沉默 A·T 富集的外源基因，Fis 在快速生长的细胞中含量丰富。第三是**大分子拥挤**与细菌的 SMC 复合体 MukBEF。染色体被划分为数百个约 10 kb 的独立超螺旋结构域，所以单个切口只松弛一个结构域——亚伯拉罕·沃塞尔（Abraham Worcel）与埃伦·比尔吉（Ellen Burgi）1972 年首先据此推断，后来的研究予以证实。自由的超螺旋使细菌中启动子的活性对细胞的能量状态敏感，因为促旋酶消耗 ATP。

::: example 有多少自由超螺旋？ {#ex-nucleoid}
设大肠杆菌染色体为 $4.64\times10^6$ bp，总体 $\sigma = -0.06$，其中一半被蛋白质约束。(a) $Lk_0$ 是多少？(b) 总 $\Delta Lk$ 是多少，其中多少不受约束？(c) 若染色体形成 400 个独立结构域，每个结构域不受约束的 $\Delta Lk$ 是多少？
::: solution
(a) $Lk_0 = 4.64\times10^6/10.5 = 4.42\times10^5$。

(b) $\Delta Lk = -0.06\times4.42\times10^5 = -2.65\times10^4$。其中一半，约 $-1.3\times10^4$，不受约束。

(c) $-1.3\times10^4/400 \approx -33$，每个结构域约 11.6 kb。一个结构域中的切口释放那 33 圈，其余结构域不受影响，这就是细菌能够承受复制与修复中频繁发生的单链断裂的原因。
:::
:::

::: history
詹姆斯·沃森（James Watson）与弗朗西斯·克里克（Francis Crick）1953 年提出双螺旋，其模型建构依据罗莎琳德·富兰克林与雷蒙德·戈斯林拍摄的 X 射线照片以及莫里斯·威尔金斯的工作。埃米尔·海茨 1928 年区分了常染色质与异染色质，赫尔曼·穆勒 1930 年描述了黑腹果蝇的位置效应花斑。杰罗姆·维诺格拉德（Jerome Vinograd）及同事 1965 年在多瘤病毒 DNA 中发现超螺旋。迪恩·休伊什与利·伯戈因的核酸酶梯带（1973）、阿达与唐纳德·奥林斯的串珠电镜照片（1974）以及罗杰·科恩伯格的八聚体模型（1974）确立了核小体；皮埃尔·乌代（Pierre Oudet）与皮埃尔·尚邦（Pierre Chambon）及同事 1975 年为其命名。詹姆斯·王 1971 年发现了第一个拓扑异构酶——大肠杆菌 ω 蛋白（拓扑异构酶 I）；马丁·盖勒特、水口清志（Kiyoshi Mizuuchi）及同事 1976 年发现了 DNA 促旋酶。卡罗琳·吕格、蒂莫西·里奇蒙德及同事 1997 年以 2.8 Å 分辨率解析了核小体核心颗粒；埃雷兹·利伯曼-艾登（Erez Lieberman-Aiden）、约布·德克尔（Job Dekker）及同事 2009 年建立了 Hi-C。
:::

::: summary
- B-DNA 是右手双螺旋，每圈约 10.5 bp，每碱基对上升 0.34 nm，直径 2 nm。大沟暴露的氢键供体与受体排布方式可区分全部四种碱基对，所以大多数序列特异性蛋白质读取大沟；小沟主要报告形状。
- 相隔整数个螺旋圈数的位点朝向双螺旋的同一面。因此协同结合与 DNA 成环依赖于约 10.5 bp 周期的间距。
- 基因组的长度为毫米级（细菌）到米级（人二倍体），必须压缩约 $10^3$ 到 $10^4$ 倍或更多。
- 在闭合 DNA 中，$Lk = Tw + Wr$ 除非断链否则不变。Ⅰ 型拓扑异构酶改变 $Lk$ 的幅度为 1，Ⅱ 型为 2。促旋酶利用 ATP 引入负超螺旋；拓扑异构酶 Ⅱ 与 IV 解开子代分子的连环。复制叉与聚合酶的移动在前方制造正超螺旋、后方留下负超螺旋。
- 核小体核心是 147 bp 绕组蛋白 H2A、H2B、H3 与 H4 的八聚体缠绕 1.65 圈；重复长度约 165–200 bp；每个核小体约束 $\Delta Lk \approx -1$。
- 核小体之上，染色体组织为黏连蛋白与凝聚蛋白形成的环、以 CTCF 为边界的 TAD、区室与染色体疆域。规则的 30 nm 纤维在体外可见，在间期细胞核中很少见。
- 异染色质处于凝聚状态、基因贫乏，以 H3K9me3 或 H3K27me3 与 DNA 甲基化为标志；它可以扩展并沉默基因。
- 细菌类核由超螺旋、类核相关蛋白质与 SMC 复合体折叠成许多独立的结构域。
:::

## 练习

::: exercise λ 噬菌体的长度 {level=1 check="16.5"}
λ 噬菌体 DNA 有 48502 bp。按 B-DNA 计，它的长度是多少微米（保留一位小数）？
::: solution
$48\,502\times0.34\ \mathrm{nm} = 16\,491\ \mathrm{nm} = 16.5\ \mu\mathrm{m}$。它被装进直径约 0.06 μm 的头部，长度上压缩了近 300 倍，靠的是 ATP 驱动的包装马达，而不是缠绕 DNA 的蛋白质。
:::
:::

::: exercise 螺旋圈数 {level=1 check="100"}
一段 1050 bp 的线性 B-DNA 片段含有多少圈螺旋？
::: solution
$1050/10.5 = 100$ 圈。
:::
:::

::: exercise 连环数变不变？ {level=1}
说出下列每个事件是否改变闭合环状 DNA 的 $Lk$，改变多少：(a) DNA 被蛋白质弯成一个环；(b) 大肠杆菌拓扑异构酶 I 作用一次；(c) 促旋酶作用一次；(d) DNA 上出现一个切口；(e) 某种蛋白质结合并解开 10.5 bp，不切断链。
::: solution
(a) 不变：弯曲改变扭曲数、也许还有扭转数，但 $Lk$ 不变。(b) $+1$（它一次穿一条链地松弛负超螺旋）。(c) $-2$。(d) 分子不再闭合，$Lk$ 无定义：DNA 松弛了。(e) $Lk$ 不变：$Tw$ 减少约 1，分子其他部位的 $Wr$ 增加约 1 作为补偿，产生一个补偿性的正超螺旋。
:::
:::

::: exercise 从梯带求连接长度 {level=2 check="18"}
酿酒酵母染色质的微球菌核酸酶酶切给出 165、330 与 495 bp 的梯带，延长酶切时间得到 147 bp。平均连接长度是多少 bp？
::: solution
重复长度为 165 bp，所以连接为 $165 - 147 = 18$ bp。短连接是酵母的典型特征——它的连接组蛋白很少——这使酵母染色质不如动物的紧密。
:::
:::

::: exercise 酵母基因组中的核小体 {level=2 check="73000"}
酿酒酵母（*Saccharomyces cerevisiae*）的核基因组约 $1.21\times10^7$ bp。取重复长度 165 bp、核小体覆盖整个基因组，一个单倍体细胞含有多少个核小体（精确到千位）？为什么实际数目要低一些？
::: solution
$1.21\times10^7/165 = 73\,333$，约 73000 个。实际数目更低（实测约 60000–70000），因为启动子、起点与其他调控区域缺少核小体，而 rRNA 串联重复序列这类高转录基因也部分没有核小体。
:::
:::

::: exercise 报告质粒的超螺旋 {level=2 check="-19"}
一个 4000 bp 的质粒从大肠杆菌中分离出来时 $\sigma = -0.050$。取每圈 10.5 bp，$\Delta Lk$ 是多少（取最接近的整数）？
::: solution
$Lk_0 = 4000/10.5 = 381.0$，所以 $\Delta Lk = -0.050\times381.0 = -19.05 \approx -19$。
:::
:::

::: exercise 设计操纵基因的间距 {level=3}
你想让同一个阻遏蛋白的两个拷贝各结合一个约 20 bp 的操纵基因，并在平直的 DNA 上靠相互接触实现协同。阻遏蛋白可以容忍绕螺旋轴最多 $\pm 40^\circ$ 的错位。(a) 中心到中心的间距在 18 到 35 bp 之间，哪些可以用？(b) 若在超过约 150 bp 的间距处改为靠形成环来协同，情况有什么变化？(c) 为什么预期很长的环的周期性更弱？
::: solution
(a) 每 bp 转 $34.3^\circ$，间距 $d$ 处的转角为 $34.3^\circ d$ 对 $360^\circ$ 取模。21 bp（2 圈）与 31.5 bp（3 圈）附近的同面间距合格：20 bp 为 $-34^\circ$，21 bp 为 $0^\circ$，22 bp 为 $+34^\circ$；31 bp 为 $-17^\circ$，32 bp 为 $+17^\circ$；30 bp 为 $-51^\circ$，33 bp 为 $+51^\circ$，超出容忍范围。所以是 20、21、22、31 与 32 bp；实际上间距小于约 20 bp 也会被排除，因为两个 20 bp 的操纵基因会重叠。

(b) 在长间距处 DNA 必须弯成环。两个位点同面时成环最容易，所以协同性仍以 10.5 bp 为周期振荡，但其平均水平取决于弯曲的代价：短环（远小于 150 bp 的持久长度）代价高昂，成环概率在几百 bp 处升到最大，之后随着两端相遇的可能性变小而缓慢下降。

(c) 一个长环可以靠整段长度上轻微的扭转来吸收错位，分摊到许多碱基对上时代价很小。所以周期性随环变长而衰减，*lac* 与 λ 系统的实验中都观察到了这一点。
:::
:::

::: exercise 解读 Hi-C 图谱 {level=3}
在一个 2 Mb 区域的 Hi-C 图谱中，0–0.8 Mb 与 0.8–2 Mb 两个区块内部接触频繁，区块之间接触稀少。0.8 Mb 处的一个 CTCF 位点朝向第二个区块。(a) 解释这一模式。(b) 用基因组编辑删除该 CTCF 位点后，跨过 0.8 Mb 的接触增加。这说明什么？(c) 在编辑后的细胞中，1.0 Mb 处的一个基因在一个原本沉默的组织中开始表达，而已知 0.6 Mb 处有一个增强子。提出一个解释和一个对照实验。
::: solution
(a) 该区域被划分为两个拓扑关联结构域，边界在 0.8 Mb。每个域内 DNA 片段经常相遇；跨越边界则很少。

(b) 该 CTCF 位点是边界所必需的。在环挤出模型中，挤出环的黏连蛋白被合适取向的 CTCF 拦下；没有它，环就跨过 0.8 Mb 延伸，两个域部分合并。

(c) 0.6 Mb 的增强子原先被限制在第一个域内，现在能够接触并激活 1.0 Mb 处的基因（"增强子劫持"；这类边界缺失是人类与小鼠某些发育性肢体畸形的原因）。对照：用从该基因启动子出发的染色质构象捕获证明其与 0.6 Mb 的接触增加；在 CTCF 缺失的背景下删除或失活该增强子，检验基因表达是否消失；回补 CTCF 位点（或以倒位方向插入，预期效果应差得多）是进一步的检验。
:::

::: exercise 超螺旋与启动子打开 {level=2}
解释为什么一个在松弛 DNA 上很弱的启动子在负超螺旋 DNA 上可以变得有活性，并预测一种抑制促旋酶的抗生素对其活性的影响。
::: solution
打开一个约 13 bp 的转录泡会去掉约 1.2 圈扭转。在闭合的负超螺旋分子中，去掉扭转使扭曲数变得不那么负，释放储存的张力，因此链分离的自由能代价更低；在松弛 DNA 上，打开同样的泡会制造新的张力。所以难以打开的启动子受益于负超螺旋。抑制促旋酶会让拓扑异构酶 I 把染色体松弛掉，$\sigma$ 变得更不负，这类启动子的表达随之下降。（实际上大肠杆菌会进行稳态调节：松弛促进促旋酶基因的转录、抑制拓扑异构酶 I 的转录。）
