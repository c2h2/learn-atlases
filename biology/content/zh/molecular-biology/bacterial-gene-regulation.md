一个大肠杆菌细胞约有 4300 个蛋白质编码基因，但在任一时刻，它只制造其中一部分基因的产物，而且数量相差悬殊。利用乳糖的酶，在没有乳糖时几乎不存在，加入乳糖后几分钟内就出现。合成色氨酸的酶，只在细胞无法从外界获得色氨酸时才制造。热、饥饿、拥挤、噬菌体攻击，各自开启自己的一批基因。细菌生活在变化迅速的环境中，它们的成功有赖于同样迅速地开启和关闭基因。既然细菌大多数基因在转录水平受调控，而且从 DNA 到蛋白质的链条又短又快，细菌的基因调控就以最清楚的形式展示了控制的逻辑。

本章围绕 **lac 操纵子**展开：雅各布（François Jacob）与莫诺（Jacques Monod）就是在这套系统里发现了基因如何受调控，对它的分析是遗传学推理的典范。接着看 CAP 的激活、*trp* 操纵子中的阻遏与衰减、λ 开关，以及 RNA 的调控：核糖开关与小 RNA。转录机器本身见 [[molecular-biology/transcription]]；开关、振荡器与反馈等调控回路的动力学见 [[systems-biology/gene-expression-dynamics]]。

## 原理

::: definition 操纵子与控制方式 {#def-operon}
**操纵子**是相邻基因的一整群，从一个启动子转录成一条**多顺反子** mRNA，因而受共同的调控，连同控制它们的调控位点。当**阻遏蛋白**结合在启动子附近的**操纵基因**上阻止转录时，调控是**负**的。当启动子附近结合的**激活蛋白**是转录所必需时，调控是**正**的。若一个小分子（**诱导物**，通常是该途径的底物）开启表达，系统就是**可诱导的**；若一个小分子（**辅阻遏物**，通常是该途径的终产物）关闭表达，系统就是**可阻遏的**。操纵基因与启动子这类序列只作用于它们所在的那条 DNA 分子（以 ***cis*** 方式）。阻遏蛋白与激活蛋白等可扩散的产物可以作用于细胞内任何一份拷贝（以 ***trans*** 方式）。
:::

四种组合都有实例。*lac* 操纵子受负调控、可诱导：它的阻遏蛋白被诱导物失活。*trp* 操纵子受负调控、可阻遏：它的阻遏蛋白被色氨酸激活。*ara* 操纵子（阿拉伯糖利用）通过 AraC 蛋白受正调控、可诱导。用底物调控分解代谢酶、用产物调控合成代谢酶，正是细菌代谢的经济逻辑：有活可干时才制造酶。

## lac 操纵子

### 基因

::: definition 大肠杆菌的 lac 操纵子 {#def-lac}
***lac* 操纵子**含三个结构基因：***lacZ***，编码 **β-半乳糖苷酶**（LacZ），把乳糖水解为葡萄糖与半乳糖，还有一部分乳糖转化为其异构体**别乳糖**；***lacY***，编码**乳糖通透酶**（LacY），把一个质子连同乳糖一起摄入细胞；***lacA***，编码硫代半乳糖苷转乙酰酶。它们从启动子 ***lacP*** 按 *lacZ lacY lacA* 的顺序转录。上游是单独转录的基因 ***lacI***，编码 **Lac 阻遏蛋白**（LacI）——一个结合操纵基因的四聚体。主操纵基因 ***O1*** 与起始位点重叠（中心在 +11）。两个辅助操纵基因分别位于 −82（***O3***）与 *lacZ* 内部的 +412（***O2***）。天然诱导物是别乳糖；**IPTG**（异丙基硫代-β-D-半乳糖苷）是**无底物诱导物**（gratuitous inducer），能诱导操纵子本身却不被代谢。
:::

符号遵循细菌遗传学习惯（[[genetics/microbial-genetics]]）：基因用小写斜体（*lacZ*），蛋白质用大写正体（LacZ），上标给出等位基因：*lacZ*⁺、*lacZ*⁻、*lacI*^s^（超阻遏蛋白）、*lacO*^c^（操纵基因组成型）。

没有诱导物时，一个细胞只有几个 β-半乳糖苷酶分子。加入诱导物几分钟后，β-半乳糖苷酶以未诱导时约一千倍的速率被制造，很快就占细胞蛋白的百分之几。时间进程本身就是证据：诱导在几分钟内开始，移去诱导物后又同样迅速地停止，这说明基因与蛋白质之间有一个不稳定的中间体。这正是促使雅各布与莫诺提出信使 RNA 的观察之一。

### 遗传学分析

雅各布与莫诺自 1957 年起在巴斯德研究所与帕迪（Arthur Pardee）合作，分离出不论有无诱导物都一直制造 *lac* 酶的突变体：它们是**组成型**的。突变分为两类。一类定位在 *lacI*，另一类靠近 *lacZ*，就在雅各布与莫诺称为操纵基因的那个位点。为了弄清各自的作用，他们构建部分二倍体——一份 *lac* 区段在染色体上，另一份在 F′ 质粒上（[[genetics/microbial-genetics]]）——然后问哪个等位基因是显性，以及一个突变是否只作用于同一条 DNA 分子上的基因。

```python
# 雅各布-莫诺逻辑：lac 部分二倍体的 β-半乳糖苷酶，有无诱导物
# 一份拷贝是一个 dict：I 取 {'+','-','s'}（阻遏蛋白基因），O 取 {'+','c'}（操纵基因），Z 取 {'+','-'}

def repressor_present(copies, inducer):
    """细胞里有没有有活性的阻遏蛋白？lacI+ 的阻遏蛋白被诱导物失活；
    lacI^s（超阻遏蛋白）不能结合诱导物。阻遏蛋白会扩散：以 trans 方式作用。"""
    kinds = {c['I'] for c in copies}
    return 's' in kinds or ('+' in kinds and not inducer)

def beta_gal(copies, inducer):
    """凡 Z+ 且操纵基因未被占据的拷贝，都生产 β-半乳糖苷酶。"""
    R = repressor_present(copies, inducer)
    return any(c['Z'] == '+' and (c['O'] == 'c' or not R) for c in copies)

def parse(g):
    """'I+ O+ Z-' -> {'I': '+', 'O': '+', 'Z': '-'}"""
    return {t[0]: t[1:] for t in g.split()}

genotypes = ["I+ O+ Z+", "I- O+ Z+", "I+ O+ Z- / I- O+ Z+", "I+ Oc Z- / I+ O+ Z+",
             "I+ Oc Z+ / I+ O+ Z-", "Is O+ Z+ / I+ O+ Z+", "Is Oc Z+ / I+ O+ Z+"]
print(f"{'genotype':24s} {'no inducer':>11s} {'inducer':>8s}")
for g in genotypes:
    copies = [parse(x) for x in g.split('/')]
    row = ['+' if beta_gal(copies, ind) else '-' for ind in (False, True)]
    print(f"{g:24s} {row[0]:>11s} {row[1]:>8s}")
```

程序把操纵子模型编成两条规则。在 β-半乳糖苷酶高速合成的地方打印 `+`，在基础水平的地方打印 `-`：

```
genotype                  no inducer  inducer
I+ O+ Z+                           -        +
I- O+ Z+                           +        +
I+ O+ Z- / I- O+ Z+                -        +
I+ Oc Z- / I+ O+ Z+                -        +
I+ Oc Z+ / I+ O+ Z-                +        +
Is O+ Z+ / I+ O+ Z+                -        -
Is Oc Z+ / I+ O+ Z+                +        +
```

::: example 解读部分二倍体表 {#ex-merodiploid}
按模型解释表的每一行，并说明每一行揭示了相关基因或位点的什么性质。
::: solution
1. 野生型：无诱导物时阻遏蛋白封锁 *lacO*；诱导物使其失活。可诱导。
2. *lacI*⁻：没有有功能的阻遏蛋白，操纵基因从不被占据。组成型。
3. *lacI*⁺ *lacZ*⁻ / *lacI*⁻ *lacZ*⁺：由 *lacI*⁺ 拷贝制造的阻遏蛋白扩散出去，阻遏*另一条*分子上的 *lacZ*⁺ 基因。二倍体是可诱导的，所以 *lacI*⁺ 对 *lacI*⁻ 是显性、以 *trans* 方式作用：*lacI* 编码可扩散的产物。
4. *lacO*^c^ *lacZ*⁻ / *lacO*⁺ *lacZ*⁺：唯一的 *lacZ*⁺ 基因挨着正常操纵基因，所以可诱导。*lacO*^c^ 突变对另一条分子上的 *lacZ* 基因不起作用。
5. *lacO*^c^ *lacZ*⁺ / *lacO*⁺ *lacZ*⁻：现在 *lacZ*⁺ 基因挨着突变操纵基因，尽管细胞里有有活性的阻遏蛋白，它仍是组成型的。第 4、5 两行合起来说明 *lacO*^c^ 是 **cis 显性**：它只影响同一条 DNA 分子上的基因，正如一个不产生产物的位点所预期的。（雅各布与莫诺还测定了 LacY 与 LacA，它们的行为与 LacZ 一样，说明一个操纵基因控制全部三个基因。）
6. *lacI*^s^ / *lacI*⁺：超阻遏蛋白不能结合诱导物，所以一直留在两个操纵基因上。不可诱导，并以 *trans* 方式对 *lacI*⁺ 显性。
7. *lacI*^s^ 与 *cis* 位置的 *lacO*^c^ *lacZ*⁺：突变操纵基因连超阻遏蛋白也不能结合，所以那个 *lacZ* 基因组成型表达。操纵基因组成型突变对 *lacI*^s^ **上位**，这把操纵基因排在控制途径中阻遏蛋白的下游。
:::
:::

由这些实验，雅各布与莫诺于 1961 年提出了**操纵子模型**（*Genetic regulatory mechanisms in the synthesis of proteins*（《蛋白质合成的遗传调控机制》），*Journal of Molecular Biology*）。调节基因制造阻遏蛋白，阻遏蛋白作用于操纵基因，控制串联的结构基因的转录；诱导物通过使阻遏蛋白失活起作用。模型的每一个元件后来都在生物化学上得到证实。吉尔伯特（Walter Gilbert）与穆勒-希尔（Benno Müller-Hill）（1966）凭放射性 IPTG 结合纯化了 Lac 阻遏蛋白：每个细胞只有约十个阻遏蛋白四聚体，他们不得不用过表达菌株。1967 年他们证明它结合 *lac* DNA，并可被 IPTG 解离。吉尔伯特与马克萨姆（Allan Maxam）1973 年测定了操纵基因的序列：一段二十几个碱基对、具有接近两重对称性的区段，它结合阻遏蛋白并因此受保护而不被核酸酶降解。雅各布与莫诺和勒沃夫（André Lwoff）分享 1965 年诺贝尔生理学或医学奖。

::: warning "显性突变就是能制造酶的突变"
这些测验中的显隐性说的是部分二倍体里的表型，不是哪个等位基因"更强"。*lacI*⁺ 对 *lacI*⁻ 显性，因为功能阻遏蛋白以 *trans* 供给两份拷贝；然而 *lacI*^s^ 对 *lacI*⁺ 显性，而且有些 *lacI* 突变（*lacI*^−d^）并不产生有功能的阻遏蛋白，却对 *lacI*⁺ 显性：它们编码的亚基会掺入野生型亚基形成没有活性的混合四聚体（**显性负效应**，穆勒-希尔组作了分析）。而 *lacO*^c^ 只在 *cis* 中显性。给突变扣显性或隐性的帽子之前，先说清楚记分的是哪个表型、在哪个部分二倍体里、等位基因处于 *cis* 还是 *trans*。
:::

### 阻遏蛋白如何工作

Lac 阻遏蛋白是相同亚基（360 个氨基酸）组成的四聚体，以二聚体的二聚体形式形成。每个二聚体以一个**螺旋-转角-螺旋**基序插入大沟结合一个操纵基因（[[molecular-biology/dna-structure#def-bdna]]）。诱导物结合每个亚基的核心后使其变形，两个 DNA 结合结构域再也握不住操纵基因的两个半位点，对操纵基因的亲和力下降约一千倍。由于四聚体有两个 DNA 结合二聚体，它可以同时结合 O1 和一个辅助操纵基因，把它们之间的 DNA 成环。成环提高了阻遏蛋白在 O1 处的局部浓度，从而加强阻遏。厄勒（Stefan Oehler）、穆勒-希尔及同事（1990）发现，除去两个辅助操纵基因，阻遏减弱一个数量级以上。三个操纵基因齐全时阻遏约为千倍。改变操纵基因间距的实验表明，当各操纵基因位于螺旋同一面时最易于成环（[[molecular-biology/dna-structure#ex-helical-phase]]）。

::: proposition 阻遏蛋白的阻遏倍数 {#prop-repression}
设阻遏蛋白以解离常数 $K_d$ 结合它的操纵基因，它在细胞内的游离浓度为 $[R]$，并假设只有操纵基因空出时才发生转录。平衡时，操纵基因有如下比例的时间处于游离状态：
$$
\frac{1}{1 + [R]/K_d}
$$ {#eq-repression}
所以**阻遏倍数**（无阻遏蛋白时的表达除以有阻遏蛋白时的表达）为 $1 + [R]/K_d$。在体积为 $V$ 的细胞中，一个分子对应浓度 $1/(N_A V)$，$V = 1$ fL——约大肠杆菌的体积——时约为 1.7 nM。模型假定结合处于平衡、只有一个操纵基因、无非特异结合，并且操纵基因一旦空出启动子就全速工作。
:::

::: example 十个分子能阻遏多少？{#ex-repression}
一个体积 1 fL 的细胞含有 10 个阻遏蛋白四聚体，取阻遏蛋白对 O1 的体内有效 $K_d$ 为 0.1 nM（示意值）。(a) [[#eq-repression]] 预言的阻遏倍数是多少？(b) 诱导物使阻遏蛋白的亲和力下降一千倍，此时达到最大表达的多少？(c) 为什么真实的阻遏比这个单操纵基因的估计更强，而真实的诱导水平却接近全开？
::: solution
(a) $[R] = 10\times1.66\ \mathrm{nM} = 16.6$ nM，所以阻遏倍数为 $1 + 16.6/0.1 = 167$。

(b) $K_d = 100$ nM 时，操纵基因有 $1/(1 + 16.6/100) = 0.86$ 的比例时间处于游离状态，所以表达达到最大值的 86 %。

(c) O1 与辅助操纵基因之间的成环使阻遏蛋白在 O1 处的有效局部浓度远高于 16.6 nM，把阻遏提高到约千倍。另一方面，与染色体其余部分的非特异结合会降低游离阻遏蛋白浓度，而且诱导后的阻遏蛋白亲和力下降得足够多，几乎总是不在操纵基因上。把非特异结合与成环都包括进来的更精细的热力学模型（例如 Bintu 等，2005）能很好地预言实测的阻遏水平。
:::
:::

### 诱导是合作的，而且可以全或无

操纵子对诱导物的响应是 S 形的，不是双曲线的。每个阻遏蛋白四聚体必须结合不止一个诱导物分子才放开 DNA，而摄入乳糖需要 LacY——它本身就是这个操纵子的产物。

::: proposition Hill 函数 {#prop-hill}
当响应需要 $n$ 个配体分子合作结合时，配体浓度 $x$ 处最大响应的分数常用 **Hill 函数**描述：
$$
f(x) = \frac{x^n}{K^n + x^n},
$$ {#eq-hill}
其中 $K$ 是给出半最大响应的浓度，$n$ 是 **Hill 系数**，度量陡峭程度。响应从最大的 10 % 升到 90 % 所需的浓度范围 $x_{90}/x_{10} = 81^{1/n}$：$n = 1$ 时 81 倍，$n = 2$ 时 9 倍，$n = 4$ 时 3 倍。Hill 函数是一种经验描述。$n$ 一般不等于结合位点数，尽管在简单平衡模型中它不能超过位点数。IPTG 诱导 *lac* 的实测 Hill 系数约为 2。
:::

::: proof
令 $f = x^n/(K^n + x^n)$ 并解出 $x$：$x = K\,[f/(1-f)]^{1/n}$。于是 $x_{90} = K\cdot9^{1/n}$，$x_{10} = K\cdot(1/9)^{1/n}$，所以 $x_{90}/x_{10} = 81^{1/n}$。
:::

::: example 估计 Hill 系数 {#ex-hill}
在携带 *lac* 报告基因的一群细胞中，20 μM IPTG 时表达为最大的 10 %，60 μM 时为 90 %。(a) 估计 Hill 系数与 $K$。(b) 预言 30 μM 时的表达。(c) 群体平均值为什么可能给出误导性的 Hill 系数？（数字为示意值。）
::: solution
(a) 由 [[#prop-hill]]，$x_{90}/x_{10} = 81^{1/n}$，所以 $3 = 81^{1/n}$，$n = \ln81/\ln3 = 4$。于是 $K = x_{10}\cdot9^{1/n} = 20\times9^{0.25} = 34.6$ μM，即 20 与 60 的几何平均。

(b) $f = 30^4/(34.6^4 + 30^4) = 8.1\times10^5/(1.44\times10^6 + 8.1\times10^5) = 0.36$。

(c) 如果单个细胞是双稳态的——要么全开要么全关——群体平均反映的就是被诱导细胞的*比例*，而不是每个细胞的分级响应。这时平均曲线可以比阻遏蛋白对诱导物的响应陡得多（或平缓得多）。除去乳糖通透酶，或让细胞预先载入诱导物后，单细胞响应是分级的，其 Hill 系数约为 2。用流式细胞术或荧光报告物显微成像测单个细胞，可以区分两种情形。
:::
:::

诺维克（Aaron Novick）与韦纳（Milton Weiner）（1957）发现了更奇怪的事。在低浓度无底物诱导物中，单个细胞要么完全诱导、要么未诱导，中间类型很少，而且诱导状态可遗传许多代。原因是**正反馈**。已诱导的细胞有通透酶，高效摄入诱导物并保持诱导；未诱导的细胞几乎没有通透酶，摄入很少。群体是**双稳态的**。这类开关及双稳态的数学见 [[systems-biology/switches-oscillators]]。

### 正调控：CAP 与分解代谢阻遏

大肠杆菌在葡萄糖与乳糖的混合培养基中生长时，先利用葡萄糖。只有葡萄糖耗尽、经过一段停顿之后，才转而利用乳糖。莫诺在 1942 年的博士论文中描述了这种**二相生长**（diauxie），这正是他研究 *lac* 的起点问题。解释的一部分是 *lac* 受**分解代谢激活蛋白**（CAP，又称 CRP，即 cAMP 受体蛋白）的正调控。

::: definition CAP 与分解代谢阻遏 {#def-cap}
**CAP** 是一个二聚体激活蛋白，只有结合**环腺苷酸**（cAMP）时才结合 DNA。在 *lac* 处，CAP–cAMP 结合中心在 −61.5 的位点，把 DNA 弯曲约 90°，接触 RNA 聚合酶某个 α 亚基的 C 端结构域，帮助聚合酶结合弱启动子 *lac*（**I 类激活**，靠募集）。在其他启动子处 CAP 结合在更近的约 −41.5，并同时接触 σ（**II 类**）。葡萄糖充足时，葡萄糖转运系统使腺苷酸环化酶保持无活性、cAMP 处于低水平，所以 CAP 无活性，即使有乳糖，*lac* 也转录很弱。此外，葡萄糖转运蛋白 EIIA^Glc^ 在摄糖过程中去磷酸化，会抑制 LacY（**诱导物排阻**），把乳糖挡在细胞外。这些效应合起来构成**分解代谢阻遏**。
:::

1990 年代的测量（稻田（Toshifumi Inada）、相叶（Hiroji Aiba）及同事，1996）提示，在大肠杆菌中对 *lac* 的葡萄糖效应大部分来自诱导物排阻，而不是 cAMP 的下降。只讲 cAMP 的教科书故事是不完整的。*lac* 启动子因此像一个 **AND 门**：只有乳糖存在（阻遏蛋白放开）*且*葡萄糖缺如（CAP 开启、诱导物放行）时，才强烈表达。

::: quiz
在乳糖加葡萄糖的培养基中生长时，哪个菌株会以高水平表达 β-半乳糖苷酶？
- [ ] 野生型
- [ ] 缺失腺苷酸环化酶的菌株（*cya*⁻）
- [x] *lac* 启动子带着 *lacUV5* 突变（使 −10 元件与共有序列一致）的菌株
- [ ] 携带 *lacI*^s^ 的菌株
::: solution
*lacUV5* 启动子不靠 CAP 也能很好地结合 RNA 聚合酶，所以大体上不受分解代谢阻遏的影响；有乳糖使阻遏蛋白失活（且胞外乳糖浓度高时诱导物排阻也不那么完全），它就能表达。野生型受分解代谢阻遏；*cya*⁻ 菌株没有 cAMP、因而没有有活性的 CAP，在任何条件下 *lac* 都表达很差；*lacI*^s^ 不可诱导。
:::
:::

## trp 操纵子：阻遏与衰减

*trp* 操纵子编码从分枝酸合成色氨酸的五个酶（*trpE*、*D*、*C*、*B*、*A*）。它受两种彼此独立的控制，都以色氨酸为信号。

**阻遏。** **Trp 阻遏蛋白**（TrpR）只有结合了色氨酸——**辅阻遏物**——才结合与启动子重叠的 *trp* 操纵基因。色氨酸高意味着阻遏蛋白有活性、转录很少。这提供约 70 倍的控制范围。

**衰减。** 亚诺夫斯基（Charles Yanofsky）及同事在 1970 年代发现，缺少阻遏蛋白的 *trpR*⁻ 菌株仍受色氨酸约十倍的控制。第二种机制位于启动子与 *trpE* 之间长 162 个核苷酸的**前导区**。前导区编码一个 14 个氨基酸的**前导肽**，其中含两个相邻的色氨酸密码子，而且它的 RNA 可以按不同方式折叠。

::: definition trp 前导区的衰减 {#def-attenuation}
*trp* 前导 RNA 含 1–4 四个区段，可以配成 1:2 与 3:4，或配成 2:3。**3:4 发夹**后面跟着一串 U 残基，是一个内在**终止子**（**减弱子**，attenuator）。**2:3 发夹**是**抗终止子**，它阻止 3:4 形成。由于细菌的翻译与转录偶联，核糖体紧跟在 RNA 聚合酶后面翻译前导肽，而前导肽的 Trp 密码子位于区段 1 中：
- 装载了色氨酸的 tRNA^Trp^ **充足**时，核糖体读过 Trp 密码子，恰在区段 3 与 4 刚被合成时到达区段 2。区段 2 被覆盖，**3:4 终止子**形成，转录在结构基因之前停止。
- 装载了色氨酸的 tRNA^Trp^ **缺乏**时，核糖体停在 Trp 密码子上，覆盖区段 1。区段 2 得已在合成时与 3 配对，形成 **2:3 抗终止子**，于是 3:4 无法形成，转录继续进入 *trpE*。
- 若根本没有核糖体装载上来，1:2 与 3:4 形成，转录终止。
:::

两种控制的总范围是二者之积：阻遏约 70 倍，衰减约 8–10 倍，合计约 600–700 倍。衰减感知的是装载好的 tRNA 而不是色氨酸本身，因此追踪的是细胞合成蛋白质的真实能力。衰减在肠细菌的氨基酸合成操纵子中很常见。*his* 操纵子的前导区编码连续七个组氨酸密码子，*leu* 与 *thr* 操纵子也以类似方式工作，其中一些衰减就是唯一的控制。

::: example 预言衰减 {#ex-attenuation}
在 *trpR*⁻ 菌株中预言下列每种情况下 *trp* 结构基因是否被转录（大多数 RNA 聚合酶越过减弱子读下去）：(a) 色氨酸浓度高；(b) 色氨酸饥饿；(c) 色氨酸与精氨酸双饥饿，已知前导肽在两个 Trp 密码子之后紧跟着一个精氨酸密码子；(d) 一个把两个 Trp 密码子变成 Leu 密码子的突变，在色氨酸饥饿下；(e) 一个破坏前导肽核糖体结合位点的突变，在色氨酸饥饿下。
::: solution
(a) 核糖体越过 Trp 密码子并覆盖区段 2；形成 3:4；终止。转录很少。

(b) 核糖体停在 Trp 密码子上；形成 2:3；抗终止。结构基因被转录。

(c) 核糖体先停在更靠前的 Trp 密码子上，所以结果与 (b) 相同：抗终止。（Arg 密码子只在色氨酸充足而精氨酸缺乏时才有影响：紧随其后的 Arg 密码子处停顿也会使区段 2 部分空出，给出一些抗终止。）

(d) 色氨酸饥饿时核糖体不再停顿，因为没有 Trp 密码子了；它覆盖区段 2；形成 3:4。衰减不再响应色氨酸。（它改而响应亮氨酸。）

(e) 没有核糖体翻译前导区，所以 1:2 与 3:4 形成；不论色氨酸如何都终止。转录很低，表明前导区的翻译对抗终止是必需的。
:::
:::

## λ 开关

噬菌体 λ 感染大肠杆菌后，要么裂解生长，制造约一百个子代并裂解细胞，要么把 DNA 作为**前噬菌体**整合进染色体（[[molecular-biology/dna-repair-recombination]]）、随宿主一起复制，这种状态称为**溶原**。普塔什内（Mark Ptashne）的小组在 1960–80 年代弄清了这一选择如何作出并如何维持，它成了遗传开关的典范。

两种阻遏蛋白争夺三个相邻的操纵基因 O~R~1、O~R~2 与 O~R~3，它们与两个背向的启动子 P~R~（裂解基因，以 *cro* 开始）和 P~RM~（λ 阻遏蛋白基因 *cI*）重叠。**λ 阻遏蛋白**（CI）最紧地结合 O~R~1，并借助二聚体之间的接触合作地结合 O~R~2。结合在那里，它既阻遏 P~R~，又通过接触 RNA 聚合酶*激活*自己的启动子 P~RM~。浓度高时它还结合 O~R~3 阻遏自身，把自己的水平维持在很窄的范围内。**Cro** 先结合 O~R~3 阻遏 P~RM~，浓度更高时再结合其余位点。溶原中，CI 压住裂解基因并维持自身表达，这一状态由子代细胞继承。宿主 DNA 受损时，被激活的 RecA 刺激 CI 自我切割（如对 SOS 反应中的 LexA，[[molecular-biology/dna-repair-recombination]]）。P~R~ 由此去阻遏，Cro 被制造并接管，前噬菌体被**诱导**进入裂解生长。在几百个碱基对里，这个开关集合作结合、正负自身调控与相互阻遏于一身——双稳态记忆的全部原料。

## RNA 的调控

并非所有调节因子都是蛋白质。

::: definition 核糖开关 {#def-riboswitch}
**核糖开关**是 mRNA 上一个有结构的功能区，通常位于 5′ 非翻译区，直接结合一个小代谢物并改变下游基因的表达。它由**适配体**（aptamer）与**表达平台**组成：前者以高专一性结合配体，后者按是否结合配体折叠成不同结构。在细菌中，配体结合典型地要么形成内在终止子（终止转录），要么把 Shine–Dalgarno 序列锁进发夹（阻断翻译起始）。也有一些反而激活表达。
:::

布雷克（Ronald Breaker）的小组 2002 年描述了第一批核糖开关——分别结合硫胺素焦磷酸、黄素单核苷酸与辅酶 B~12~——此前他们注意到这些分子合成基因的上游有保守的 RNA 结构。现已知针对 40 多种配体的核糖开关，包括氨基酸（赖氨酸、甘氨酸）、碱基（鸟嘌呤、腺嘌呤）、金属离子与信号核苷酸。它们主要见于细菌。有一类硫胺素焦磷酸核糖开关也存在于真菌与植物中，在那里控制剪接。核糖开关就像没有核糖体参与的衰减：代谢物自己决定 RNA 怎么折叠。因为核糖开关不存在于人体，其中一些正被探索作为抗生素靶点。

细菌还使用**小调控 RNA**（sRNA），通常长 50–300 个核苷酸，与靶 mRNA（常在核糖体结合位点附近）碱基配对，阻断翻译或促进降解。许多依赖 RNA 分子伴侣 **Hfq**。例如缺铁时 sRNA RyhB 产生，抑制那些非必需的含铁蛋白的 mRNA，把铁省给必需的蛋白。[[molecular-biology/molecular-tools]] 中的 CRISPR 系统也是 RNA 引导的调控系统，只不过针对外源 DNA 而不是细胞自己的基因。

## 感知外界：双组分系统与群体感应

许多细菌调节系统响应细胞外的信号。**双组分系统**由一个膜**感知组氨酸激酶**与一个胞质**响应调节蛋白**组成：激酶检测到信号后在一个组氨酸上自磷酸化，磷酸基团再转移到响应调节蛋白上（转天冬氨酸上）。磷酸化的调节蛋白通常是 DNA 结合转录因子。大肠杆菌约有 30 对该系统。例如 EnvZ–OmpR 按培养基渗透压调整外膜孔蛋白，PhoR–PhoB 响应磷酸盐限制。

**群体感应**让细菌按种群密度调控基因。生活在夏威夷短尾乌贼发光器中的海洋细菌 *Vibrio fischeri*，其 LuxI 酶制造可扩散的**酰基高丝氨酸内酯**。细胞密度高时它积累起来，结合激活蛋白 LuxR，开启生物发光的 *lux* 基因。只有细菌多到发光有用时，光才被制造。群体感应控制许多群体行为，包括生物膜形成，见 [[microbiology/microbial-ecology]]。

::: application 细菌调控元件在生物技术中
这些系统的元件是实验室控制基因表达的标准工具箱。重组蛋白质通常用大肠杆菌从 *lac* 启动子或杂合 *tac* 启动子表达——LacI 抑制到加入 IPTG 为止——或从噬菌体 T7 启动子表达，而 T7 RNA 聚合酶基因本身置于 *lacUV5* 控制之下。阿拉伯糖诱导系统（AraC–P~BAD~）与四环素诱导系统（TetR）可作分级控制，四环素系统还改造后用于哺乳动物细胞。合成生物学中，LacI、TetR 与 λ CI 等阻遏蛋白被接成开关（toggle switch，Gardner、Cantor 与 Collins，2000）与振荡器（Elowitz 与 Leibler 的抑制器，2000）。见 [[biotechnology/protein-production]] 与 [[biotechnology/synthetic-biology]]。
:::

::: history
莫诺 1942 年描述了二相生长。诺维克与韦纳 1957 年报道全或无诱导；帕迪、雅各布与莫诺 1959 年发表"PaJaMo"实验，证明可诱导的等位基因是显性的、其产物在细胞质中起作用。雅各布与莫诺 1961 年提出操纵子模型，1965 年与勒沃夫共获诺贝尔奖。吉尔伯特与穆勒-希尔 1966 年纯化了 Lac 阻遏蛋白；同年普塔什内纯化了 λ 阻遏蛋白（1967 年发表）。祖拜（Geoffrey Zubay）及同事，以及帕斯坦（Ira Pastan）与珀尔曼（Robert Perlman）1970 年证明 cAMP 与 CAP 激活 *lac* 转录。亚诺夫斯基组自 1970 年代中期起描述了 *trp* 操纵子的衰减；布雷克组 2002 年报道了核糖开关。
:::

::: summary
- 操纵子是共同转录的基因连同共享的调控位点。控制可正（激活蛋白）可负（阻遏蛋白在操纵基因），可诱导（底物开启）可阻遏（产物关闭）。位点以 *cis* 作用，可扩散产物以 *trans* 作用。
- *lac* 操纵子（*lacZYA*）受 LacI 阻遏——结合 O1 的四聚体（成环还用到 O2 与 O3）——被别乳糖或 IPTG 诱导。部分二倍体证明 *lacI* 以 *trans* 作用，*lacO*^c^ 是 cis 显性，*lacI*^s^ 反式显性且不可诱导，*lacI*^−d^ 为显性负。
- 最简单平衡模型的阻遏倍数为 $1 + [R]/K_d$；每飞升一个分子约为 1.7 nM。成环与非特异结合会修正它。
- 诱导是合作的（Hill 系数约 2；10–90 % 范围跨 $81^{1/n}$ 倍），并可因 LacY 提供正反馈而成为双稳态。
- CAP–cAMP 靠募集 RNA 聚合酶激活 *lac*。分解代谢阻遏合并了低 cAMP 与诱导物排阻，所以 *lac* 是"有乳糖、无葡萄糖"的 AND 门。
- *trp* 操纵子受 TrpR 阻遏（约 70 倍）与衰减（约 10 倍）控制：前导区 Trp 密码子处的核糖体停顿使 2:3 抗终止子胜过 3:4 终止子。
- λ 开关靠 CI 与 Cro 在 O~R~1–3 的合作结合选择并记忆溶原或裂解；RecA 刺激的 CI 切割诱导前噬菌体。
- 核糖开关（适配体加表达平台）与依赖 Hfq 的 sRNA 以 RNA 调控。双组分系统与群体感应把转录与外界信号连接起来。
:::

## 练习

::: exercise 组成型还是可诱导？{level=1}
对下列每个单倍体大肠杆菌基因型，说出 β-半乳糖苷酶是无诱导物时合成、有诱导物时合成、两者皆是还是两者皆非：(a) *lacI*⁺ *lacO*⁺ *lacZ*⁺；(b) *lacI*⁻ *lacO*⁺ *lacZ*⁻；(c) *lacI*^s^ *lacO*⁺ *lacZ*⁺；(d) *lacI*⁺ *lacO*^c^ *lacZ*⁺。
::: solution
(a) 仅有诱导物时。(b) 两者皆非（没有有功能的 *lacZ*）。(c) 两者皆非（不可诱导）。(d) 两者皆是（组成型）。
:::
:::

::: exercise 阻遏倍数 {level=1 check="51"}
游离浓度 20 nM 的阻遏蛋白以 $K_d = 0.4$ nM 结合它的操纵基因。[[#eq-repression]] 预言阻遏倍数是多少？
::: solution
$1 + 20/0.4 = 1 + 50 = 51$ 倍。
:::
:::

::: exercise 联合控制 {level=1 check="700"}
若阻遏对 *trp* 操纵子有 70 倍的控制范围，衰减独立地有 10 倍范围，合起来的范围是多少？
::: solution
独立相乘的控制取乘积：$70\times10 = 700$ 倍。
:::
:::

::: exercise 诱导的陡峭度 {level=2 check="3"}
$n = 2$ 的 Hill 函数，要把表达从最大的 50 % 提到 90 %，诱导物浓度必须升高多少倍？
::: solution
$x_{50} = K$，$x_{90} = K\cdot9^{1/2} = 3K$，所以升高 3 倍。
:::
:::

::: exercise 更多部分二倍体 {level=2}
预言下列各菌株中 β-半乳糖苷酶与通透酶的合成（无诱导物与有诱导物）：(a) *lacI*⁺ *lacO*^c^ *lacZ*⁻ *lacY*⁺ / *lacI*⁺ *lacO*⁺ *lacZ*⁺ *lacY*⁻；(b) *lacI*^s^ *lacO*⁺ *lacZ*⁺ *lacY*⁺ / *lacI*⁻ *lacO*^c^ *lacZ*⁻ *lacY*⁺；(c) *lacI*^−d^ *lacO*⁺ *lacZ*⁺ / *lacI*⁺ *lacO*⁺ *lacZ*⁺。
::: solution
(a) β-半乳糖苷酶只来自第二份拷贝（正常操纵基因）：可诱导。通透酶只来自第一份拷贝（*lacO*^c^）：组成型。这一例表明操纵基因只控制 *cis* 上的基因。

(b) β-半乳糖苷酶只来自第一份拷贝，其正常操纵基因无论有无诱导物都被超阻遏蛋白占据：不合成。通透酶来自带 *lacO*^c^ 的第二份拷贝：组成型，因为超阻遏蛋白不能结合组成型操纵基因。

(c) *lacI*^−d^ 亚基在混合四聚体中毒害野生型亚基，所以几乎不形成有活性的阻遏蛋白：两个 *lacZ* 基因都组成型（或近似组成型）表达。这就是显性负表型。
:::

大肠杆菌在含少量葡萄糖与大量乳糖的培养基中生长。生长曲线显示 3 h 指数生长（每 40 min 倍增），接着 40 min 停顿，然后以 60 min 倍增时间再次指数生长。(a) 用分子语言解释每个阶段。(b) 预言 *lacI*⁻ 突变的曲线。(c) 预言 *crp*⁻（缺 CAP）突变的曲线。
::: solution
(a) 第一阶段：利用葡萄糖；*lac* 被阻遏（葡萄糖造成诱导物排阻与低 cAMP），乳糖不被摄入。停顿：葡萄糖耗尽；cAMP 升高，诱导物排阻解除，少量乳糖经仅有的几个通透酶分子进入，生成别乳糖并诱导操纵子；酶积累起来。第二阶段：以乳糖生长，慢一些，因为在这一培养基中乳糖单位时间提供的能量比葡萄糖少。

(b) *lacI*⁻ 突变体组成型表达 *lac*，尽管葡萄糖仍通过 CAP 降低其表达、并仍通过诱导物排阻挡住乳糖摄入；但停顿会更短甚至消失，因为葡萄糖耗尽时酶已在细胞里。

(c) 没有 CAP，野生型 *lac* 启动子很弱，葡萄糖耗尽后细胞诱导 *lac* 很吃力：延滞期长，以乳糖生长缓慢。

::: exercise 设计一个核糖开关检验 {level=3}
你在某个细菌赖氨酸合成基因的 5′ UTR 中发现一个保守的 RNA 结构，其后跟着一个发夹与一串 U 残基。(a) 提出它调控该基因的方式。(b) 用报告基因设计实验，检验是否是赖氨酸本身（而不是某种蛋白质）控制表达。(c) 如何直接证明这段 RNA 结合赖氨酸？
::: solution
(a) 赖氨酸核糖开关：赖氨酸充足时结合适配体，稳定一种让下游终止子（发夹加 U 串）得以形成的结构，于是转录在编码序列之前停止；赖氨酸缺乏时形成另一种抗终止子结构，基因得以转录。

(b) 把 5′ UTR 融合到 *lacZ*（或 GFP），在高、低赖氨酸培养基中测量表达。要证明不需要蛋白质，可用体外转录系统：纯化的 RNA 聚合酶、DNA 模板与不同浓度的赖氨酸——若在体外没有任何其他蛋白质时赖氨酸增加 U 串处的终止，就是 RNA 直接感受赖氨酸。适配体中消除赖氨酸结合的点突变应使体内表达变成组成型，而恢复结构的补偿性突变应恢复调控。

(c) 测定赖氨酸（或标记类似物）与纯化 RNA 的结合，例如 in-line probing（配体引起的柔性核苷酸自发切割变化）、等温滴定量热或平衡透析，并用相关氨基酸检验专一性。
:::

::: exercise 解读一个 λ 突变体 {level=3}
形成清晰噬菌斑（斑中没有溶原存活）的 λ 突变体分属三个基因：*cI*、*cII* 与 *cIII*。*cI*⁻ 突变体从不能形成溶原；*cII*⁻ 与 *cIII*⁻ 突变体很少形成溶原，但一旦形成，溶原就是稳定的。*vir* 突变体即使在 λ 溶原菌的菌苔上——它们对普通 λ 免疫——也形成清晰噬菌斑。(a) 这些结果对 CI、CII 与 CIII 的角色有什么提示？(b) 为什么 λ 溶原对 λ 的再感染免疫？(c) 你预计 *vir* 突变位于何处？
::: solution
(a) CI（λ 阻遏蛋白）对溶原的建立与维持都是必需的。CII 与 CIII 只对建立溶原必需：CII 激活启动 *cI* 第一轮转录的启动子（P~RE~），CIII 保护 CII 免于降解；CI 一旦制造出来，就从 P~RM~ 维持自身合成，不再需要 CII。

(b) 溶原中含有 CI，它以 *trans* 方式结合任何入侵 λ DNA 的操纵基因，阻遏其裂解基因。

(c) 位于操纵基因（O~R~ 与 O~L~）中：阻止 CI 结合的多重突变使裂解启动子对阻遏蛋白免疫——顺式作用的操纵基因组成型突变，λ 中 *lacO*^c^ 的对应物。
:::
