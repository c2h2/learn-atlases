1856年，Alfred Russel Wallace 从巴厘岛航行到龙目岛，两岛同属马来群岛，之间隔着一条约35 km 宽的海峡。巴厘岛上的鸟类与爪哇和亚洲大陆相同——拟啄木鸟、啄木鸟与鹎。他注意到，龙目岛上许多这样的鸟不见了，取而代之的是凤头鹦鹉、吸蜜鸟与其他具有澳洲亲缘的鸟类。他后来画在巴厘岛与龙目岛之间、并北穿加里曼丹与苏拉威西岛之间的这条线，分隔开两大动物区系——它们已各自演化数千万年，直到近来才相遇。Wallace 线是一条生命分布的界线，任何气候或植被的地图都预言不到它。

**生物地理学**研究生物在地球表面的分布；相关的**宏观生态学**研究物种的多度、分布与多样性在大尺度上的统计格局。两者都在寻找格局背后的过程，而这些过程作用于两类时间尺度：生态过程——气候、扩散、拓殖与灭绝——作用于数年至数千年；历史过程——大陆漂移、成种与谱系的长程移动——作用于数百万年。本章涵盖最大的生态单位**生物群系**，以及世界被历史地划分为各生物地理界；**物种-面积关系**，生态学中少数近乎普适的格局之一；**岛屿生物地理学平衡理论**；以及多样性的**纬度梯度**。前面各章提供构件：气候来自 [[ecology/organisms-environment]]，初级生产来自 [[ecology/ecosystem-energetics]]，群落装配来自 [[ecology/communities]]。谱系的演化历史在 [[evolution/macroevolution]] 与 [[evolution/speciation]] 中处理。

## 生物群系

::: definition 生物群系 {#def-biome}
**生物群系**是依据优势植被的生活型——森林、草原、灌丛、荒漠、冻原——来识别的主要陆地生态系统类型，凡是气候条件相似之处就会出现。生物群系由结构与功能界定，而非由物种界定：北美洲与非洲南部的荒漠同属一个生物群系，尽管它们的植物大多彼此远缘。
:::

生物群系的分布追随气候，尤其是年均温与降水。Robert Whittaker（1975年）把主要生物群系画在以这两个量为轴的坐标空间中：

- **热带雨林** — 全年高温多雨（降水通常超过约2000 mm）；高大、常绿、多层的森林，是各生物群系中物种丰富度最高的（亚马逊、刚果盆地、东南亚）。
- **热带季节性林与稀树草原** — 高温、干季漫长；落叶林，或散布着树木的草原，在许多地方由火与大型食草动物维持。
- **热荒漠** — 降水低（常在250 mm 以下）、蒸发强，中心位于哈得来环流下沉支所在的南北纬30°附近；多肉植物、旱季落叶灌木与短暂的一年生植物。
- **温带草原** — 冬季寒冷、夏季炎热，降水中等且主要落在夏季（prairies、steppes 与 pampas）；土壤深厚肥沃。
- **地中海灌木林** — 冬暖湿、夏热干，见于南北纬30–40°的大陆西岸（加利福尼亚、智利、南非好望角、澳大利亚西南端与地中海盆地）；常绿、适应火的灌木。
- **温带落叶林** — 夏季温暖、冬季寒冷，全年有雨；树木冬季落叶。
- **温带雨林** — 温和且极湿（北美太平洋西北岸、智利南部、新西兰）；巨大的针叶树或常绿阔叶树。
- **北方针叶林（taiga）** — 冬季漫长酷寒、夏季短；由少数几种针叶树占据优势，土壤酸性、分解缓慢。
- **冻原** — 寒冷到树木无法生长；低矮灌木、莎草、苔藓与地衣覆于永冻土之上。

有两点要注意。其一，温度与降水并非全部故事：季节性、火、土壤与放牧同样起决定作用——例如，一个中等降水地区是稀树草原还是森林便由它们决定，同一气候在不同地方可以支持两者之一。其二，生物群系之间的边界是渐变的，且大部分陆地已被改造为农田、牧场与城市——有时被当作**人为生物群系**（anthromes），即被人类塑造的生物群系。

不同大陆上相似气候中生活型的相似，是**趋同进化**的一个显著例子。美洲茎干多肉的仙人掌与非洲多肉的大戟属植物长得惊人地相像，尽管它们的花泄露了彼此的远缘；五个地中海气候区的灌木共有小而坚韧的常绿叶。

### 生物地理界

生物群系反映当今的气候；其中物种的身份则反映历史。Philip Sclater（1858年，针对鸟类）与 Wallace（*The Geographical Distribution of Animals*，1876年）把世界划分为若干**生物地理界**——古北界、新北界、新热带界、埃塞俄比亚界（热带非洲界）、东洋界（印度-马来亚界）与澳洲界——它们的动物区系之所以彼此不同，是因为海洋、荒漠与山脉的屏障使它们相互隔离。Ben Holt 及同事2013年的一项更新，基于超过21 000种两栖类、鸟类与哺乳类的分布与系统发育关系，承认11个界，大体证实了 Wallace 的方案。

这些差异可用大陆的历史来解释。1960年代被接受的板块构造理论表明，南方各大陆曾组成**冈瓦纳**超大陆，直到它在中生代期间瓦解，这就解释了为什么肺鱼、南青冈（*Nothofagus*）、有袋类与平胸鸟类的分布能横跨如今被大洋分隔的各大陆。一个谱系占据彼此分离的地区，可以经由**地理分隔**（vicariance）（原本连续的分布被一道新屏障分开，如张开的大洋），也可以经由**扩散**越过既有的屏障。分子定年表明两者都重要：许多本被认为是地理分隔造成的格局，实际上定年在大陆分离很久之后的扩散事件——正如猴子与啮齿类从非洲跨大西洋到达南美洲。

## 物种-面积关系

面积越大，物种越多。这也许是生态学中最古老、支持最充分的概括：Hewett Watson 1859年就植物指出了它，Olof Arrhenius 1921年把它量化为一个幂律。

::: proposition 物种-面积关系 {#prop-sar}
在很大的面积范围内，面积 $A$ 中所发现的物种数 $S$ 近似为

$$
S = cA^z ,
$$ {#eq-sar}

或取对数，

$$
\log S = \log c + z\log A ,
$$ {#eq-sar-log}

即在双对数坐标上一条斜率为 $z$ 的直线。经验上，群岛中岛屿的 $z$ 典型地介于约0.2与0.35之间；而在连续大陆区域内逐级增大的嵌套样本中通常更低，约0.1–0.2。这是一条**经验规律**，不是定律：该关系并不总是幂函数（半对数与 sigmoid 形式常常拟合得同样好或更好），而 $c$ 与 $z$ 取决于类群、地区与取样设计。
:::

三个过程造成了这一关系。较大的面积包含更多**生境**，各有其物种。较大的面积容纳更大的**种群**，更不容易灭绝。而较大的面积是从区域库中对个体取到的更大的**样本**，所以即便随机放置个体，较大的面积也会产生较多的物种。要区分这些是困难的；它们大概都在起作用。

由 [[#eq-sar]] 可得一条简单的经验法则。面积乘以10，物种数乘以 $10^z$；取 $z = 0.3$ 时即 $10^{0.3} \approx 2$。Philip Darlington 在1957年注意到，对西印度群岛的爬行类与两栖类，岛屿面积增大十倍，物种数大约翻倍。

::: example Darlington 法则 {#ex-darlington}
若面积增大十倍使物种数翻倍，$z$ 是多少？一座比另一座大100倍的岛上，你预期物种多出多少倍？大1000倍呢？
::: solution
由 [[#eq-sar]]，$S_2/S_1 = (A_2/A_1)^z$。取 $A_2/A_1 = 10$、$S_2/S_1 = 2$，得 $10^z = 2$，故 $z = \log_{10}2 = 0.301$。对大100倍的岛，$100^{0.301} = 4.0$ 倍的物种；对大1000倍的岛，$1000^{0.301} = 8.0$。面积每增大一个数量级，丰富度再翻一倍：物种数随面积的增长极为缓慢，这就是为什么即便极大的面积也只含有有限数目的物种，而小斑块仍能保有广大区域中相当大一部分的物种。
:::
:::

::: example 拟合物种-面积曲线 {#ex-sar}
一个（假想）群岛七个岛屿上爬行类与两栖类的物种数如下：

| 面积（km²） | 3 | 25 | 120 | 800 | 4500 | 30 000 | 110 000 |
|---|---|---|---|---|---|---|---|
| 物种 | 5 | 12 | 17 | 35 | 49 | 95 | 128 |

估计 $z$ 与 $c$，并预测一座10 000 km² 岛屿上的物种数。
::: solution
对两个变量取 $\log_{10}$，用最小二乘法拟合直线 [[#eq-sar-log]]（下方代码），得斜率 $z = 0.303$、截距 $\log_{10}c = 0.607$，故 $c = 4.05$，且 $R^2 = 0.99$。对10 000 km² 的预测是

$$
S = 4.05\times10\,000^{0.303} = 4.05\times16.3 = 66\ \text{种}.
$$

这些岛屿的 $z \approx 0.3$，遵循 Darlington 法则：面积十倍，物种两倍。
:::
:::

```python
import math

area    = [3, 25, 120, 800, 4500, 30000, 110000]   # island area, km^2
species = [5, 12, 17, 35, 49, 95, 128]             # species of reptiles and amphibians

x = [math.log10(a) for a in area]                  # log10 A
y = [math.log10(s) for s in species]               # log10 S
n = len(x)
mx, my = sum(x) / n, sum(y) / n
z = sum((xi - mx) * (yi - my) for xi, yi in zip(x, y)) / sum((xi - mx) ** 2 for xi in x)
c = 10 ** (my - z * mx)                            # S = c * A^z
print(f"z = {z:.3f}, c = {c:.2f}")
print(f"predicted S for 10 000 km^2: {c * 10_000 ** z:.0f}")
# z = 0.303, c = 4.05
# predicted S for 10 000 km^2: 66
```

::: application 物种-面积曲线与生境丧失
如果物种-面积关系描述一个面积能容纳多少物种，它也应当能预测生境被破坏时最终将失去多少物种。把面积从 $A$ 缩到 $A'$，预期物种数按 $(A'/A)^z$ 缩减。取 $z = 0.25$，失去90 %的生境会留下其物种的 $0.1^{0.25} = 0.56$：最终失去44 %——远少于90 %，但已极多。这一推理支撑着许多由毁林造成的灭绝估计。但它必须谨慎使用。生境丧失后的灭绝并非即时：物种可以在长期根本养不活它们的残块中继续存续几十年——这是一笔日后才偿还的**灭绝债务**。整体的关系未必适用于其中一部分的丧失；一些分析（何芬芳（Fangliang He）与 Stephen Hubbell，2011年）认为，把通常的物种-面积曲线反过来使用会高估灭绝，而另一些分析则发现，对局限于所丧失生境中的物种而言它是低估。生境丧失与破碎化在 [[conservation-biology/fragmentation]] 中处理。
:::

::: example 预测灭绝与一笔灭绝债务 {#ex-debt}
一个地区在过去50年间失去了原有森林的80 %。它原有100种只在那里发现的林鸟，而该区林鸟的物种-面积指数为 $z = 0.2$。物种-面积关系预言这些物种中最终会有多少丧失？迄今为止只有5种灭绝。这说明什么？
::: solution
剩余面积是原来的20 %，故预期保留的物种分数为 $0.2^{0.2} = 0.725$，预期损失为 $100\times(1 - 0.725) = 27.5$，约28种。既然迄今只有5次灭绝，那么若预言不错，约23种可能已“注定”灭绝却仍在场——一笔灭绝债务。这一数字充满不确定（$z$ 的值、“剩余森林与原初森林一样好”的假设、以及关系的形状都有影响），但它表明：在剩余森林中采取保护行动，如重新连接斑块与恢复生境，仍能阻止那些尚未发生的灭绝。
:::
:::

## 岛屿生物地理学平衡理论

岛屿为何拥有它们所拥有的那些物种数？Robert MacArthur 与 Edward Wilson 在1963年提出，并在其著作 *The Theory of Island Biogeography*（1967年）中发展：岛上的物种数反映新种的迁入与已在物种的灭绝之间的**动态平衡**。

考虑一座靠近大陆的岛，大陆上有一个能到达该岛的 $P$ 个物种的物种库。岛空无一物时，每个到来的物种都是新的，新种的迁入率达到最高。随着岛屿被填满，越来越多的到达者属于已在的物种，*新*种的迁入率随之下降，当全部 $P$ 个物种都在场时降为零。与此同时，在场的物种越多，会灭绝的就越多，而且它们分享岛上的资源、每个种群都更小，所以灭绝率随物种数上升。

::: proposition MacArthur–Wilson 平衡 {#prop-ibt}
设新种的迁入率随在场物种数 $S$ 线性下降，灭绝率线性上升：

$$
I(S) = I_0\left(1 - \frac{S}{P}\right), \qquad E(S) = E_0\,\frac{S}{P},
$$ {#eq-ibt-rates}

其中 $I_0$ 是一座空岛的迁入率，$E_0$ 是全部 $P$ 个物种都在场时的灭绝率。于是

$$
\frac{dS}{dt} = I(S) - E(S)
$$ {#eq-ibt}

只有一个稳定平衡

$$
\hat S = \frac{I_0}{I_0 + E_0}\,P ,
$$ {#eq-ibt-eq}

在平衡处，物种仍以**周转率** $I(\hat S) = E(\hat S) = I_0E_0/(I_0 + E_0)$ 持续到达并灭绝。岛屿以时间常数 $P/(I_0 + E_0)$ 指数地趋近 $\hat S$。因为**较大**岛屿上灭绝率较低（种群较大），**较近**岛屿上迁入率较高，模型预测大而近的岛比小而远的岛物种更多。
:::

::: proof
令 $I(S) = E(S)$：$I_0 - I_0S/P = E_0S/P$，故 $S(I_0 + E_0)/P = I_0$，得 [[#eq-ibt-eq]]。周转率为 $E(\hat S) = E_0\hat S/P = I_0E_0/(I_0 + E_0)$。把 [[#eq-ibt]] 写成

$$
\frac{dS}{dt} = I_0 - \frac{I_0 + E_0}{P}\,S
$$

可见它具有 [[ecology/nutrient-cycles#prop-box]] 单箱模型的形式，输入为 $I_0$、周转率 $k = (I_0 + E_0)/P$；因此它以时间常数 $1/k = P/(I_0 + E_0)$ 指数地趋近 $\hat S = I_0/k$，且平衡是稳定的。抬高 $E_0$（岛更小）或压低 $I_0$（岛更远）都会降低 $\hat S$。
:::

线性速率是一种简化；MacArthur 与 Wilson 把两条曲线画成上凸的，因为最先到达的物种往往是最擅长扩散者，最先灭绝的往往是最稀者。定性预测不依赖曲线的确切形状。

::: example 近与远、大与小 {#ex-ibt}
大陆物种库保有 $P = 100$ 种鸟。一座近岸小岛有每年 $I_0 = 5$ 种与每年 $E_0 = 2$ 种。(a) 求它的平衡物种数与周转率。(b) 一座远海小岛有 $I_0 = 1$ 与同样的 $E_0$；一座近岸大岛有 $I_0 = 5$ 与 $E_0 = 0.5$。求它们的平衡。(c) 一场飓风把岛上所有的鸟一扫而空之后，近岸小岛要多久才能恢复到距平衡三分之二处？
::: solution
(a) $\hat S = 5\times100/(5 + 2) = 71.4$ 种。周转率：$I_0E_0/(I_0 + E_0) = 10/7 = 1.43$ 种每年——平衡时，每年大约有一两个物种消失并被替换。

(b) 远海小岛：$\hat S = 1\times100/3 = 33.3$。近岸大岛：$\hat S = 500/5.5 = 90.9$。距离与面积各自都能显著改变平衡。

(c) 时间常数是 $P/(I_0 + E_0) = 100/7 = 14.3$ 年，即弥合 $1 - e^{-1} = 63$ %——大约三分之二——差距所需的时间。飓风之后，这座岛需要十几年才能恢复其大部分物种——而它新的物种名单未必与旧的相同。
:::
:::

### 检验理论

最直接的检验是 Daniel Simberloff 与 Edward Wilson（1969年）在佛罗里达群岛做的实验。他们选取若干座红树小岛（每座只是一丛树，宽11–25 m），调查其上的节肢动物，用帐篷罩住每座岛，以溴甲烷熏蒸以除去每一种节肢动物，然后追踪再拓殖。大约一年之内，多数岛屿回到了大致原有的物种数，最近的岛最终物种最多、最远的最少；但物种名单与熏蒸之前相差很大，物种持续到达又消失——正如平衡理论所预言：稳定的数目，变化的组成。

自然实验同样支持该理论。1883年喀拉喀托火山喷发把岛上残存的生物杀绝之后，植物、鸟类与昆虫在其后数十年间再拓殖该岛，定居鸟类的物种数在几十年内趋于平稳，而物种的身份持续变化。该理论已被推广到大陆上的生境“岛屿”——山顶、湖泊、被农田环绕的森林斑块——但有一个重要的告诫：生境岛四周的“海”很少是完全敌对的，物种可以在周围的基质中生活、穿行其中、并从其中拓殖。

::: warning "平衡理论解释一切岛屿动物区系"
该理论假设岛屿由大陆物种库拓殖而来，且岛上的演化可以忽略。在偏远的岛屿与群岛——夏威夷、加拉帕戈斯、马达加斯加——许多物种是经由岛上的成种而产生的，物种数反映的是数百万年间拓殖与分化的历史，而不只是生态平衡。较新的理论，如 Robert Whittaker 及同事的“一般动态模型”（2008年），加入了成种与火山岛的地质生命周期。平衡理论是一个强有力的第一模型，而非最终的解释；而假定每一座岛都处于平衡，本身就是一个有待检验的假说。
:::

::: quiz
按照平衡理论，哪座岛应当拥有最多的物种？
- [ ] 远离大陆的小岛
- [ ] 靠近大陆的小岛
- [ ] 远离大陆的大岛
- [x] 靠近大陆的大岛
::: solution
距离近抬高迁入曲线，面积大压低灭绝曲线；两者都把平衡 [[#eq-ibt-eq]] 推向更多的物种。靠近大陆的大岛兼得两项优势。而一座近岸小岛与一座远离大陆的大岛相比孰多，取决于两种效应的相对强弱。
:::
:::

## 纬度多样性梯度

多数生物类群在热带比在高纬度更多样。一公顷亚马逊低地雨林可以含有250种以上的树，而欧洲或北美的一公顷温带森林通常不足20种；秘鲁雨林一棵树上的蚂蚁物种比北欧一些整个国家还多。这一梯度对鸟类、哺乳类、两栖类、爬行类、鱼类、多数昆虫、植物与许多海洋类群都成立，无论陆生还是海生，尽管存在例外（有些类群，如蚜虫、叶蜂与一些海鸟，在中纬度或高纬度最为丰富）。它由 Humboldt 与 Wallace 描述，是生物学中最古老的未解格局之一。

已有几十个假说被提出。可以按它们所诉诸的过程来分组。

- **面积与时间。** 热带是最大的生物群系，而在过去五千万年中地球较暖的大部分时期，热带气候向赤道两侧延伸到远得多的地方。谱系因此在热带气候中拥有更多的面积与更多的时间去分化。又由于多数支系起源于热带、且许多未曾演化出对寒冷的耐受（**热带生态位保守性**），相对少有的支系拓殖了高纬度。
- **能量与生产力。** 更多的能量（太阳辐射、温暖）与更高的生产力或许能支持更多的个体、从而支持更多的物种；而更高的温度或许会加快代谢、世代更替以及分子演化与成种的速率。
- **分化速率。** 热带或许成种更快，或许灭绝更慢。若干类群的系统发育与化石分析提示热带的净分化速率更高，尽管证据因类群与方法而异。
- **气候稳定性。** 热带气候在过去数百万年的冰期旋回中一直更为稳定，而那些旋回反复把高纬度物种从其分布的大片区域中逐出。
- **生物相互作用。** 热带中专性天敌、病原与竞争者的强大压力或许能在局地维持多样性（[[ecology/competition]] 的 Janzen–Connell 效应），并促进成种。

这些假说并不互斥，且作用于不同的尺度：有的解释热带地区为何在演化时间中积累更多物种，有的解释一公顷热带土地上为何能共存更多物种。多数生态学家现在认为，历史（面积、时间与生态位保守性）与分化速率解释了区域梯度的大部分，而局地机制对其加以调制；Gary Mittelbach 及同事在2007年的一项综合强调了演化方面的解释。丰富度的类似梯度也随海拔出现，常常在中段海拔而非山脚达到峰值。

::: intuition 两个要素：一个地区产生多少物种，一个地方能容纳多少
任何局地群落的丰富度都受两面限制。从上方，受区域物种库限制——在其历史中于该地区演化出来或到达那里的物种，正是面积、时间与分化速率发挥作用之处。从下方，受 [[ecology/competition]] 与 [[ecology/predation-parasitism]] 的局地过程限制，它们决定其中有多少物种能在一个给定的地方共存。纬度梯度在两个尺度上都出现，而它的解释需要两者兼备。
:::

## 宏观生态学

**宏观生态学**一词由 James Brown 与 Brian Maurer 在1989年引入，它在大尺度上寻找横跨许多物种的统计规律，常使用整个动物区系的体型、分布区与多度的数据。它的格局包括：

- **多度与分布区大小正相关**：局地多度的物种往往也分布广泛，局地稀有的物种往往分布区狭小。从生态位宽度到抽样，几个机制都能产生这一格局。
- **Bergmann 法则**（1847年）：在内温动物的亲缘类群内，个体在较冷的气候中往往较大。作为趋势，它在许多鸟类与哺乳类中成立，或许是因为较大的身体相对体积而言表面积较小、散热较慢；但它有许多例外，且也有人提出过别的解释（如食物可得性）。
- **Rapoport 法则**：分布区大小在高纬度往往更大，至少在北半球的一些类群中如此。它的普遍性已受到质疑。
- **多度随体型的标度**：跨物种而言，种群密度随体重而下降；结合代谢标度（[[ecology/ecosystem-energetics]]），这意味着种群所利用的能量随体型的变异，小于两个量各自的变异——这是 John Damuth 在1981年提出的论证，至今仍有争论。

::: application 设计保护区
平衡理论很快被应用于设计自然保护区——它们是变了质的土地之海中的生境岛屿。它建议保护区应当大（灭绝率低）、彼此靠近或以廊道相连（迁入率高）、并且紧凑。此后便是一场旷日持久的争论：同等总面积下，**一个大还是几个小**保护区（“SLOSS”之争）能保护更多物种？若干个小保护区若能取到不同的生境，合计或许容纳更多物种，而一个大的则更好地保护那些需要大面积、或在边缘易受影响的物种。答案取决于物种与景观；这个问题已让位于对保护区网络、连通性与周边景观作用的更精细分析。这些是 [[conservation-biology/protected-areas]] 的主题。
:::

::: history
Alexander von Humboldt 的植物地理学工作（1805–1807年）沿海拔与纬度梯度把植被与气候联系起来，十九世纪 Augustin Pyramus de Candolle 与 Joseph Hooker 发展了植物地理学。Charles Darwin 与 Alfred Russel Wallace 都把生物地理学用作演化的关键证据；Wallace 的 *The Geographical Distribution of Animals*（1876年）创立了动物地理学并确立了各生物地理界。Alfred Wegener 的大陆漂移说（1912年）直到1960年代以板块构造的形式才被接受，使历史生物地理学焕然一新。Olof Arrhenius（1921年）与 Frank Preston（1962年）定量描述了物种-面积关系；MacArthur 与 Wilson 的平衡理论（1963年、1967年）及其由 Simberloff 与 Wilson（1969年）完成的检验，使生物地理学成为一门实验与理论的科学；而 Brown 与 Maurer 的宏观生态学（1989年）把大型数据集带入了大陆格局的研究。
:::

## 由此引向何处

生物地理学把生态学与演化、与保护连接起来。各生物地理界背后的历史过程与谱系的分化在 [[evolution/macroevolution]] 与 [[evolution/speciation]] 中处理；气候变化对物种分布的影响，以及物种-面积关系与岛屿理论在保护生物多样性中的运用，在 [[conservation-biology/fragmentation]]、[[conservation-biology/protected-areas]] 与 [[conservation-biology/invasions-climate]] 中展开。

::: summary
- **生物群系**（[[#def-biome]]）由植被结构界定、追随气候（温度、降水、季节性），并受火、土壤与放牧调制；相似的气候产生趋同的生活型。
- **生物地理界**反映历史：板块构造、地理分隔与扩散。Wallace 线分隔亚洲与澳洲的动物区系。
- **物种-面积关系** $S = cA^z$（[[#prop-sar]]）是一条经验规律，岛屿的 $z$ 约0.2–0.35，大陆样本更低；当 $z \approx 0.3$ 时，面积增大十倍物种约翻倍。它被谨慎地用于预测生境丧失后的灭绝。
- **岛屿生物地理学**（[[#prop-ibt]]）：丰富度是迁入（近岛更高）与灭绝（大岛更低）之间的动态平衡 $\hat S = I_0P/(I_0 + E_0)$，伴随持续的周转；以红树岛清除动物相的实验检验。
- **纬度多样性梯度**提出的成因众多——面积与时间加上热带生态位保守性、能量、分化速率、气候稳定性与生物相互作用——作用于区域与局地两个尺度。
- **宏观生态学**研究大尺度的统计格局：多度-分布区关系、Bergmann 与 Rapoport 法则，以及多度随体型的标度。
:::

## 习题

::: exercise 面积加倍 {level=1 check="2^0.3"}
对一条 $z = 0.3$ 的物种-面积关系，面积加倍时物种数增加到多少倍？
::: solution
$S_2/S_1 = 2^{0.3} = 1.23$：增加23 %。
:::
:::

::: exercise 加倍物种所需的面积 {level=1 check="16"}
取 $z = 0.25$，面积须增大多少倍才能使物种数加倍？
::: solution
我们需要 $k^{0.25} = 2$，故 $k = 2^{1/0.25} = 2^4 = 16$。
:::
:::

::: exercise 平衡物种数 {level=1 check="60"}
一座岛空旷时每年获得新种 $I_0 = 3$ 种，整个物种库都在场时灭绝率为每年 $E_0 = 2$ 种，而物种库保有 $P = 100$ 个物种。平衡物种数是多少？
::: solution
$\hat S = 3\times100/(3 + 2) = 60$。
:::
:::

::: exercise 生境丧失 {level=1 check="1 - 0.5^0.3"}
一片森林失去一半面积。取 $z = 0.3$，其物种最终预期有多大比例会丧失？
::: solution
$1 - 0.5^{0.3} = 1 - 0.812 = 0.188$，约19 %。
:::
:::

::: exercise 平衡时的周转 {level=2}
对上一题中的岛，计算平衡时的周转率与趋近平衡的时间常数。若这座岛距大陆远上一倍、使 $I_0$ 减半，平衡、周转率与时间常数将如何改变？
::: solution
周转率：$I_0E_0/(I_0 + E_0) = 6/5 = 1.2$ 种每年。时间常数：$P/(I_0 + E_0) = 100/5 = 20$ 年。

$I_0 = 1.5$ 时：$\hat S = 150/3.5 = 42.9$；周转率 $3/3.5 = 0.86$ 种每年；时间常数 $100/3.5 = 28.6$ 年。较远的岛物种更少、周转更慢，从干扰中恢复所需的时间也更长。
:::
:::

::: exercise 生物群系还是生物地理界？ {level=2}
亚利桑那与纳米比亚的荒漠气候相似、植被外观相似，却几乎没有共同的物种。日本与新英格兰的森林共享着许多树木的属。(a) 用生物群系与生物地理界解释这些观察。(b) 东亚与北美东部的森林为何共享如此多的属？
::: solution
(a) 亚利桑那与纳米比亚处于同一生物群系（热荒漠），它以气候与生活型界定，所以两地的植物趋同于相似的形态（多肉、小叶、刺）。但它们属于演化历史彼此不同的不同界，所以物种——以及许多科——各不相同。日本与新英格兰既同处温带落叶林生物群系*之中*，*又*同属全北区，其区系在过去一度相连。

(b) 在新生代早期与中期较温暖的气候下，一片大致连续的温带森林环绕北半球，经由白令地区与北大西洋的陆桥而相连。后来的变冷与冰期把它割裂，在两个气候相似的地区留下了亲缘相近的属（木兰、鹅掌楸、山核桃与檫木）——这是 Asa Gray 在十九世纪首先强调的一处著名的间断分布。
:::
:::

::: exercise 解读一个清除动物相的实验 {level=2}
在一类 Simberloff–Wilson 式实验中，一座岛在熏蒸前有39种节肢动物。再拓殖使其在1、3、6、9与12个月后分别有8、20、30、36与38种；但满一年在场的38种里，只有24种属于最初的39种。(a) 这支持平衡理论吗？(b) 粗略估计趋近平衡的时间常数。(c) 物种组成重叠之低，有助于排除对“回到38种”的哪一种替代解释？
::: solution
(a) 支持。物种数回落到接近先前的数值，符合由岛屿的大小与距离设定的平衡；而组成不同，符合持续的周转与动态的（而非固定的）平衡。

(b) 在3个月与6个月计数之间插值，从0到约39种的差距在3到6个月之间弥合了63 %（约25种）——大约4个月，所以时间常数约为4个月。（把 $S(t) = \hat S(1 - e^{-t/\tau})$ 拟合到所有数据点会给出更好的估计。）

(c) 即每座岛屿都持有一个由其特定生境决定、并且只会自我重建的固定物种集合。若果真如此，回来的应当是同样的物种。组成不同表明，受到调控的是物种数目而非物种身份——正如理论所预言——尽管组成的一部分变化也可能反映到达次序上的偶然。
:::
:::

::: exercise 纬度梯度 {level=3}
一项研究发现，在鸟类的各支系中，起源于热带者至今仍大多限于热带，且一个区域内最古老的支系大多属于热带。(a) 这支持纬度梯度的哪一个假说？为什么？(b) 什么样的额外证据能够表明热带与温带的分化速率也不同？(c) 为什么关于物种共存的局地实验，无论做得多么精细，都可能无法解释区域梯度？
::: solution
(a) 热带生态位保守性结合时间与面积假说：起源于热带的谱系在热带有很长的时间进行分化，而很少有哪个演化出拓殖高纬度所需的耐寒性，于是热带地区积累了更多的物种。古老的支系属于热带、年轻的属于温带的格局与此相符。

(b) 用带年代的系统发育（或化石记录）估计热带与温带谱系的成种与灭绝速率，表明热带的净分化更高、且与可用时间的多少无关——例如，比较两个区域中年龄相近的姐妹支系。

(c) 区域物种库限定了可用的物种数；局地的共存机制决定其中有多少能在小片地方上共同生活。实验能够显示一公顷热带土地能容纳多少物种，却不能显示热带为何在数百万年间产生了如此众多的物种——那是关于成种、灭绝、扩散与历史的问题，局地实验无从回答。
:::
:::

::: exercise 一座生境岛 {level=3}
一处自然保护区是被农田环绕的一片1000 ha 的森林斑块。研究表明，该区森林鸟类的 $z = 0.25$，而原有100 000 ha 的连续森林曾容纳120个物种。(a) 物种-面积关系为该保护区在平衡时预言多少个物种？(b) 一次调查发现，孤立20年之后保护区里有95个物种。请解释这一点。(c) 提出两条由岛屿生物地理学理论启示的管理措施，并说明各自改变哪一个参数。
::: solution
(a) $S = 120\times(1000/100\,000)^{0.25} = 120\times0.01^{0.25} = 120\times0.316 = 38$ 种。

(b) 保护区容纳的物种远多于其平衡预言，这表明存在一笔**灭绝债务**：许多物种仍在场，但种群太小、无法存续，预期将随时间消失（另一种可能是，农田基质提供的生境与连通性超出假设，或物种-面积关系高估了损失；长期监测可以区分这些解释）。

(c) 用廊道或踏脚石把保护区与其他森林连接起来，会抬高迁入率（$I_0$），挽救衰退中的种群；扩大保护区、或在其周边恢复森林，会压低灭绝率（$E_0$）。使周边的土地对生物更加宜居（树篱、农林复合经营），则两者兼顾。
:::
:::
