一条红鲑在不列颠哥伦比亚省一条砾石溪流中孵化，在湖里度过一两年，迁入太平洋，在那里生长两三年，然后溯回它出生的河流，产一次卵，并在数周内死亡。同纬度的一株栎树要几十年才结出第一批橡子，此后几个世纪里以波动的丰歉持续结籽。一只田鼠出生后几周内就开始繁殖，且很少活过一年；一只信天翁要到五岁或更晚才开始繁殖，到六十岁可能仍在育雏。这些是不同的**生活史**：一生之中生长、繁殖与存活的不同时间表。

为什么它们会不同？每个生物的能量与物质供应都有限——这些资源来自 [[ecology/organisms-environment]] 中描述的资源——投入某一功能的便无法用于另一功能。自然选择（[[evolution/natural-selection]]）偏爱那种在给定环境风险下最大化个体所留下后代数的分配。生活史理论追问这一分配是什么：后代多大、多少，何时开始繁殖，繁殖一次还是反复，以及生物为何衰老。本章摆出约束生活史的权衡，逐一讲解预测选择如何解决它们的经典模型，并以衰老的进化理论收尾。精确度量存活与繁殖时间表所需的生命表在下一章 [[ecology/population-growth]] 中展开。

## 生活史性状与分配法则

::: definition 生活史与生活史性状 {#def-life-history}
**生活史**是一个生物从出生到死亡的生长、发育、繁殖与存活时间表。**生活史性状**是这张时间表的组成成分：出生大小、生长速率、成熟年龄与大小、后代的数量、大小与性别比、繁殖频率、各年龄的繁殖努力、年龄特异性存活与寿命。若每个个体只繁殖一次然后死亡，该物种为**一次繁殖**；若反复繁殖，则为**多次繁殖**。
:::

一次繁殖见于太平洋鲑属（*Oncorhynchus*）、蜉蝣、许多一年生植物、章鱼，以及龙舌兰（*Agave*）和多种竹类等长寿植物——它们间隔数十年才开一次花，有些物种甚至要一个多世纪，然后死亡。多次繁殖在多数脊椎动物、多年生植物与许多无脊椎动物中是常态。一年生植物就定义而言是一次繁殖的；多年生植物两种都可能。

共同的线索是资源有限。Richard Levins 与 Martin Cody 在1960年代把这称为**分配法则**：投入某一功能（如繁殖）的能量与物质，无法再投入另一功能（如生长或维持）。

::: definition 权衡与繁殖努力 {#def-tradeoff}
**权衡**是适合度的两个组分之间因二者都取自有限资源（或因一方使生物暴露于另一方所规避的风险）而产生的负关系：一方的增加只能以另一方的损失为代价。**繁殖努力**是生物的资源（或其在某一时期能量预算）中分配于繁殖的比例。当前繁殖造成的未来存活或繁殖力的降低，是**繁殖代价**。
:::

在生活史理论中占主导的三项权衡是：当前繁殖与未来存活或繁殖之间、后代的数量与大小之间、以及繁殖与生长之间（对适合度随体型增大而增大的生物而言，这同时也是当前与未来繁殖之间的权衡）。

### 度量权衡

权衡比人们预期的更难察觉。在一个自然种群的个体之间，繁殖与存活常常*正*相关：状态好的、或领地好的个体既繁殖更多也存活更好。这种获取量的变异掩盖了分配层面的底层权衡。破解之道是实验：随机改变个体的繁殖努力，再度量其后果。

鸟类的窝雏数操纵实验正是这样做的。在荷兰对红隼（*Falco tinnunculus*）的一项研究中，Cor Dijkstra、Serge Daan 及同事（1990）在雏鸟孵化后不久在巢间转移雏鸟，制造了增大、减小与对照三类窝。养育增大窝的亲鸟更辛苦地工作，它们存活到下一个繁殖季的比例低于养育减小窝的亲鸟。对许多鸟类的类似实验都发现了繁殖代价，尽管代价的大小差异极大，有时表现为未来繁殖力的降低而非存活的降低。

::: warning "负相关证明权衡存在；无相关则证伪权衡"
繁殖与存活之间的观测相关混合了两种效应：个体在*获取*上的差异（使相关为正）与个体在*分配*上的差异（使相关为负）。一个成员主要因获取量而异的种群，即使每个个体都面临很强的权衡，也会显示正相关；一个成员主要因分配而异的种群则显示负相关。两种格局本身都不能告诉我们权衡的情况。需要实验操纵，或在相同条件下饲养的各基因型之间的比较。
:::

## 后代多少，个体多大？

一个繁殖预算固定的亲代，可以产生许多小的后代，或少量大的后代。小的后代便宜但存活差；大的存活好但昂贵。什么大小使亲代的适合度最大？

::: proposition 后代大小的 Smith–Fretwell 模型 {#prop-smith-fretwell}
设亲代把固定数量 $R$ 的资源分配给繁殖，在大小为 $s$ 的后代（每只后代的资源量）之间平均分配，故产生 $n = R/s$ 个后代。设 $f(s)$ 为大小为 $s$ 的一个后代的适合度——比如说它存活到繁殖的概率——它是一个递增函数，在某一最小大小以下为零，并在 $s$ 大时趋于平缓。则亲代的适合度为

$$
W(s) = \frac{R}{s}\,f(s),
$$ {#eq-sf}

并在满足下式的后代大小 $s^*$ 处取最大值

$$
f'(s^*) = \frac{f(s^*)}{s^*},
$$ {#eq-sf-opt}

即从原点出发的直线与曲线 $f(s)$ 相切之处。最优大小 $s^*$ 不依赖 $R$：多余的资源应花在更多同样大小的后代上，而不是更大的后代上。
:::

::: proof
求导，$W'(s) = R\left[\dfrac{f'(s)}{s} - \dfrac{f(s)}{s^2}\right] = \dfrac{R}{s^2}\bigl[s f'(s) - f(s)\bigr]$。内部极大值要求 $W'(s^*) = 0$，即 $s^* f'(s^*) = f(s^*)$，式 [[#eq-sf-opt]]。量 $f(s)/s$ 是从原点到点 $(s, f(s))$ 的直线的斜率；这一条件说该斜率等于曲线的斜率，故直线在该处与曲线相切。由于 $R$ 只以常数因子出现在 $W$ 中，它不影响最大值的位置。
:::

该模型由 Christopher Smith 与 Stephen Fretwell 于1974年发表。其假设值得列出：所有后代大小相同；亲代的总投入 $R$ 固定；后代的适合度只取决于其自身大小；亲代自身的存活不受它如何分配 $R$ 的影响。图形条件与最优觅食理论（[[behaviour/foraging]]）中反复出现的边际值论证相同：最优点在于再向一个后代投入一单位资源的边际收益，等于每单位投入的平均收益。

::: example 从原点引出的切线 {#ex-sf}
设后代的适合度为 $f(s) = 1 - s_0/s$（$s > s_0$ 时），否则为零：一个后代至少需要 $s_0$ 单位资源才有存活的可能，且随着变大其存活趋近于1。求最优后代大小。对 $s_0 = 2$ mg 与 $R = 200$ mg，比较后代为3、4和6 mg 时亲代的适合度。
::: solution
这里 $f'(s) = s_0/s^2$，最优性条件 [[#eq-sf-opt]] 变为

$$
\frac{s_0}{s^2} = \frac{1 - s_0/s}{s} \quad\Longrightarrow\quad \frac{s_0}{s} = 1 - \frac{s_0}{s} \quad\Longrightarrow\quad s^* = 2s_0 .
$$

由 $s_0 = 2$ mg，得 $s^* = 4$ mg。于是：

| 大小 $s$（mg） | 数量 $n = R/s$ | 后代的适合度 $f(s)$ | 亲代的适合度 $W = nf$ |
|---|---|---|---|
| 3 | 66.7 | 0.333 | 22.2 |
| 4 | 50 | 0.500 | 25.0 |
| 6 | 33.3 | 0.667 | 22.2 |

4 mg 的后代给亲代留下25只存活的后代；做得更小或更大都更少。注意在最优点处，每只后代只有50 %的存活概率：最大化亲代的适合度并不意味着最大化每只后代的适合度。
:::
:::

::: widget plot

x: 0, 20
y: 0, 1.2
sliders: s0=2:0.5:6:0.25
tangent: 6

caption: Smith–Fretwell 模型对 $f(s) = 1 - s_0/s$ 的图形，横轴为后代大小 $s$。第一条曲线是一个后代的适合度；第二条是亲代的适合度 $W = (R/s)f(s)$，经缩放使其最大值为1。拖动切线沿 $f$ 移动：当其延长线穿过原点时，你正处在最优大小 $s^* = 2s_0$ 处，恰在 $W$ 的峰值处。改变 $s_0$，注意最优值成比例地移动。
:::

最优后代大小与亲代预算无关这一预言在某些类群中得到了证实——在一个种群内，许多鱼类与昆虫中更大或营养更好的雌性产更多而非更大的卵——但在其他类群中没有：许多物种中较大的母亲也产生较大的后代，这表明模型的某些假设（例如后代的适合度不依赖母亲自身的大小或环境）在那里不成立。

### 窝卵数

David Lack 在1940年代研究鸟类时提出了相关的问题：一只鸟应产多少枚卵。他的假说（1947）是：窝卵数经自然选择调整到亲鸟平均所能养大的最大幼鸟数；超过某一点，多出的雏鸟吃不饱，存活的幼鸟总数反而更少。产生存活幼鸟最多的窝是 **Lack 窝**，即最高产窝。

::: example 最高产窝 {#ex-lack}
在一个鸣禽种群中，雏鸟存活到独立的概率随窝卵数 $c$ 按 $p(c) = 1 - 0.08c$ 下降。最高产窝是多少？
::: solution
存活幼鸟的期望数为 $Y(c) = c\,p(c) = c(1 - 0.08c) = c - 0.08c^2$。令 $dY/dc = 1 - 0.16c = 0$ 得 $c = 6.25$。窝卵数是整数，故比较 $Y(6) = 6\times0.52 = 3.12$ 与 $Y(7) = 7\times0.44 = 3.08$：最高产窝是6枚卵。
:::
:::

当最高产窝与鸟类实际产下的窝相比较时——最著名的例子是牛津附近怀亚姆林的大山雀（*Parus major*），Lack 的小组及其后继者自1947年起就在跟踪那里的巢箱——最常见的窝通常**略小于**最高产窝。主要的解释是繁殖代价：Lack 的论证只计入当年的幼鸟，而养育一窝大的雏鸟可能降低亲鸟的存活或它们次年的繁殖成功，如红隼实验所示。计入整个一生，最优窝卵数低于最高产窝。其他贡献因素包括产卵本身的代价、对季末食物状况的不确定性，以及大窝养出的幼鸟较轻、离巢后存活较差。

## 何时繁殖，繁殖多频繁

### 未来的价值

一个生物应当现在繁殖，还是先生长等待？它应当把所有资源投入一次繁殖，还是分摊开来？答案取决于它再次存活繁殖的机会与现在繁殖的价值相比如何。

LaMont Cole 在1954年尖锐地提出了这个问题。他指出，对一个以离散年份增长的种群，一年生植物只需多产**一粒种子**，就能获得与一个在其他方面完全相同的多年生植物完全相同的增长率——这粒“种子”代表的就是多年生亲本自己存活到下一年。如果多年生习性如此廉价就能匹敌，为什么多年生植物如此普遍？解答来自 Eric Charnov 与 William Schaffer 在1973年的工作：成株与种子的存活并不相同。

::: proposition 一年生对多年生：Cole 悖论的解决 {#prop-cole}
考虑一个每年计数一次、恰在种子萌发之前的植物种群。设 $c$ 为一粒种子存活到次年成为繁殖成株的概率，$p$ 为成株从一年存活到下一年的概率。一个产生 $B_a$ 粒种子后死亡的一年生植物，其每年增长率为

$$
\lambda_a = cB_a ;
$$

一个每年产生 $B_p$ 粒种子、自身以概率 $p$ 存活的多年生植物则有

$$
\lambda_p = cB_p + p .
$$

二者适合度相等当且仅当

$$
B_a = B_p + \frac{p}{c}.
$$ {#eq-cole}

一年生必须比多年生的年产籽量多 $p/c$ 粒种子才能打平。当成株存活相对幼体存活较高时（$p/c$ 大），多年生（多次繁殖）习性受偏爱；当幼体几乎与成株存活得一样好时，一年生（一次繁殖）习性只需少量额外产量即可取胜。
:::

::: proof
每个一年生成株在次年被其存活幼苗所取代，平均 $cB_a$ 个。每个多年生成株的次年后代为来自其种子的 $cB_p$ 个新成株，加上它自己（概率 $p$）。这些就是每年的增长率；令 $\lambda_a = \lambda_p$ 并解出 $B_a$ 即得 [[#eq-cole]]。Cole 原始的论证隐含地取了 $c = p = 1$，于是 $p/c = 1$：多一粒种子。
:::

::: example 这种植物该是一年生的吗？ {#ex-cole}
一种草地多年生草本每年产30粒种子，成株的年存活率为0.8；种子成为成株的概率为0.02。一个一年生突变体必须产生多少粒种子才能与之匹敌？在一个幼苗容易建立（$c = 0.4$）而成株很少度过冬天（$p = 0.2$）的干扰生境上，答案如何变化？
::: solution
由 [[#eq-cole]]，在草地上 $B_a = 30 + 0.8/0.02 = 30 + 40 = 70$：一年生必须把多年生的产籽量提高一倍以上，而如果多年生还在把资源投入根系与贮藏器官，这几乎不可能。在干扰生境上，$B_a = 30 + 0.2/0.4 = 30.5$：一年生只需多产半粒种子，而它把全部资源投入繁殖就能轻松做到。模型预言一年生植物见于受干扰的开阔生境，多年生见于稳定、拥挤的植被——这与观测大体相符。
:::
:::

同样的逻辑适用于动物。太平洋鲑面临一次极其昂贵而危险的、通往产卵场的洄游；一旦到达，存活下来重复这一过程的概率如此之低，以至于把一切投入一次产卵受到偏爱。大西洋鲑（*Salmo salar*）的洄游通常没那么艰苦，是多次繁殖的，尽管许多个体仍然只繁殖一次。

::: quiz
下列哪种情形最有利于一次繁殖（一次繁殖之后再无繁殖、随即死亡）？
- [ ] 成株存活率高而幼体存活率低
- [x] 成株存活相对幼体存活较低，或每次繁殖有巨大的固定代价
- [ ] 成株很少死亡的稳定环境
- [ ] 任何长寿的生物
::: solution
由 [[#eq-cole]]，存活下来再次繁殖的优势值 $p/c$ 个后代；当成株存活 $p$ 相对幼体存活 $c$ 很低时，这一优势很小，把一切投入一次繁殖就能取胜。每次繁殖的巨大固定代价——如鲑的洄游——有类似的效果，因为它使反复繁殖变得昂贵。长寿不是关键：龙舌兰与竹类长寿而一次繁殖，在数十年积累资源之后进行单次大规模繁殖。
:::
:::

### 成熟年龄与死亡率的角色

推迟成熟使生物得以长得更大，而如果适合度随体型增大而增大，繁殖时就能产生更多后代。代价是繁殖前死亡的风险，以及更长的世代时间。因此理论预言：**高成体死亡率偏爱早期成熟与高繁殖努力**，而高幼体死亡率（相对成体）偏爱较晚成熟与较低的努力，因为成体有很好的机会再次繁殖。

最好的自然检验来自特立尼达北岭溪流中的孔雀鱼（*Poecilia reticulata*）。瀑布把许多溪流分成上下两段：下段的孔雀鱼与一种大型捕食性丽鱼（*Crenicichla*）共存，后者主要吃成年孔雀鱼；上段唯一的捕食者是小型鳉鱼（*Rivulus*，现 *Anablepsoides*），主要吃幼鱼。David Reznick、John Endler 及同事自1970年代后期起证明，来自高捕食地点的孔雀鱼成熟更早、体型更小，把更多体重投入繁殖，每窝产生更多而更小的后代——把这些鱼在实验室中饲养后差异依然存在，所以它们是遗传的。1976年，孔雀鱼从一个高捕食地点被移到一个原先没有孔雀鱼、只有 *Rivulus* 生存的瀑布之上河段。Reznick 及同事约11年后（1990年）取样它们的后代，发现它们已进化出在更大体型时的较晚成熟，正如理论所预言——对野外生活史进化的最早测量之一。

### r–K 连续谱及其被取代

1967年，Robert MacArthur 与 Edward Wilson 对比了两种选择：不拥挤种群中的选择偏爱高内禀增长率 $r$（发育快、早繁殖、许多小后代）；接近其容纳量 $K$ 的拥挤种群中的选择偏爱竞争能力与资源利用效率（发育慢、晚繁殖、较少而更大的后代）。Eric Pianka（1970）把这整理成 **r-选择**与 **K-选择**物种一系列相关性状的清单。参数 $r$ 和 $K$ 即 [[ecology/population-growth]] 中逻辑斯谛模型的参数。

作为对一种宽泛格局的描述，这一方案仍然有用——一条**快-慢连续谱**，小鼠、一年生杂草与许多昆虫位于一端，大象、信天翁与栎树位于另一端——但作为解释它已大体被取代。其困难在于：密度依赖可以作用于成体或幼体，后果相反；而孔雀鱼研究及其他研究表明，生活史对*年龄特异性死亡率*的响应方式并非 r–K 方案所能预言：高成体死亡率偏爱“类似 r ”的性状，无论种群密度如何。现代生活史理论建立在追踪选择如何通过每一年龄特异性存活率与繁殖力起作用的人口学模型之上。对植物，Philip Grime 的（1977）竞争者、耐胁迫者与杂草分类（CSR 方案）补上了 r–K 方案所缺的第二根轴——胁迫。

::: warning "r-选择物种的环境容纳量低"
这些标签指的是一个种群经历过哪种选择，而不是它的数目。“K-选择”的物种可以稀少，“r-选择”的物种可以丰富——杂草与蚜虫达到巨大的密度。这些性状也并不总是像教科书清单所暗示的那样相关联；许多物种兼有“快”与“慢”的性状。快-慢连续谱描述的是跨物种的一种统计倾向，主要由体型驱动。
:::

## 衰老

多数生物随年龄而衰退：死亡率上升，繁殖力下降。这种**衰老**从进化的观点看令人困惑，因为它降低适合度。选择为何没有将其消除？

::: definition 衰老 {#def-senescence}
**衰老**是生物生理功能随年龄的衰退，在外部危险恒定的条件下，在种群水平上表现为年龄特异性死亡率上升、成年期的年龄特异性繁殖力下降。若一个物种的这些比率在所观察的成年寿命期内没有明显变化，则称其表现出**可忽略的衰老**。
:::

现代答案从一个事实出发：在自然界，无论生物是否衰老，它们都会死于外部原因——捕食者、疾病、意外、饥饿。由于个体在各个年龄都因这种**外因死亡率**而损失，越到高龄，仍存活、并可能被在该处起作用的基因所影响的个体越来越少。

::: proposition 选择力随年龄的下降 {#prop-force}
设个体以恒定的年概率 $m$ 死于外部原因，因此一个同生群存活到年龄 $x$ 的比例为

$$
l_x = (1 - m)^x .
$$ {#eq-lx-const}

一个只在 $x$ 岁以后才表现效应的基因，只影响携带它的个体中的 $l_x$ 这一比例；在一个大小恒定的种群中，作用于一项年龄 $x$ 处繁殖力或存活的微小变化的选择强度，与 $l_x$ 成正比（与活到该年龄的概率成正比，对存活而言还与尚未来临的繁殖成正比）。因此选择力随年龄下降，且外因死亡率越高，下降越快。
:::

这是 William Hamilton（1966）所证明结果的一个启发式概括，他从种群动力学方程组证明：适合度对年龄特异性存活的敏感度在繁殖开始之后随年龄单调下降。两种机制随后使衰老得以进化。

- **突变积累**（Peter Medawar，1952）。效应限于晚年的有害突变只受到很弱的负选择，可以漂变到可观的频率，于是生物携带着一批晚期作用的缺陷负荷。
- **拮抗多效性**（George Williams，1957）。一个改善早期繁殖力或存活、却在后来伤害生物体的等位基因总体上受偏爱，因为早期收益被多得多的个体所感受，晚期代价则不是。于是衰老是青春活力的代价。

第三种观点，Thomas Kirkwood 的**一次性体细胞**理论（1977），把拮抗多效性重新表述为一个分配问题：投入身体修复与维持的资源无法用于繁殖，而当外因死亡率高时，维持一副为长寿而建造的身体并不划算。

::: example 一个晚期基因受到多强的选择？ {#ex-force}
在一种外因年死亡率为30 %的小型鸟类中，同生群存活到10岁的比例是多少？与一种外因年死亡率为5 %的海鸟比较。
::: solution
由 [[#eq-lx-const]]，对小型鸟类 $l_{10} = 0.7^{10} = 0.028$：不足百只中有3只活到能被一个在10岁起作用的基因所影响，无论它做什么。对海鸟，$l_{10} = 0.95^{10} = 0.60$：60 %存活。因此，一个从10岁起作用的有害突变在海鸟中所受的选择约强21倍。理论预言外因死亡率低的物种衰老更慢——事实如此：与体型相似的小型鸣禽相比，长寿的海鸟衰老缓慢。
:::
:::

### 检验理论

理论作出一个可检验的比较预测：外因死亡率较低的种群或物种应进化出更慢的衰老。Steven Austad（1993）比较了佐治亚州萨佩洛岛上的弗吉尼亚负鼠（*Didelphis virginiana*）与大陆上的负鼠；该岛已孤立数千年，没有哺乳类捕食者。岛上动物按若干生理指标衰老更慢，寿命也更长。在哺乳动物中，蝙蝠与鸟类——能飞离许多捕食者——比相同体型的地栖哺乳动物长寿得多。在果蝇（*Drosophila melanogaster*）中，只用老年雌蝇产下的卵建立每一代的选择实验，在几十代之内就产生了寿命更长、早期繁殖力更低的品系，正如拮抗多效性所预言。

并非每个物种以同样的方式衰老。有些在长期观察中死亡率随年龄的上升很少或检测不到——实验室里的淡水刺胞动物水螅（*Hydra*），野外一些长寿的龟和树——当生物持续生长、适合度随年龄上升、选择力下降较缓时，这与理论相符。究竟哪些分子过程驱动各谱系的衰老，它们与这些进化解释的关系如何，仍是一个活跃的研究领域。

::: warning "生物衰老是因为身体磨损了"与"衰老为年轻个体腾出空间"
磨损是真实的，但它不能解释为什么有些生物能修复磨损而另一些不能：修复是可能的（种系不在世代间衰老），所以问题在于选择为何没有偏爱更多的修复。而衰老也不是“为了物种的利益”、为年轻个体让路的适应——那种论证需要组间选择压过组内选择，而且它无法解释为什么衰老速率追随外因死亡率。衰老之所以进化，是因为选择太弱、无法阻止它，或者因为它是那些在生命早期受偏爱的基因的副作用。
:::

::: application 渔业中的生活史
高强度捕捞提高成体死亡率的方式，正是孔雀鱼溪流中捕食者的方式。在许多商业捕捞的鱼群中，成熟年龄与大小几十年来一直在下降；一个研究充分的例子是纽芬兰与拉布拉多外海的北方鳕鱼，在1990年代初崩溃之前，它正以越来越小的年龄与越来越小的体型成熟。这类变化有一部分是可塑的（种群变稀后生长加快），但控制了生长的分析表明其中部分是进化的，是对捕捞所施加选择的一种响应。由捕捞引起的向早成熟、小体型的进化可能降低产量并减缓鱼群的恢复，这一点如今已在渔业管理中被讨论。这些效应背后的种群动力学在 [[ecology/population-growth]] 中展开，其保护后果见 [[conservation-biology/small-populations]]。
:::

::: history
Darwin 在《物种起源》中注意到，产卵多的物种在生命的某个阶段遭受巨大损失。作为定量学科的生活史理论始于 LaMont Cole 的论文 “The population consequences of life history phenomena”（1954），该文提出了 Charnov 与 Schaffer 于1973年解决的悖论。David Lack 关于鸟类窝卵数的工作（1947）与 Peter Medawar 的演讲 *An Unsolved Problem of Biology*（1952）出自同一时期，随后是 George Williams 的拮抗多效性理论（1957）、William Hamilton 关于选择力的分析（1966）、MacArthur 与 Wilson 的 r 和 K 选择（1967），以及 Smith–Fretwell 的后代大小模型（1974）。对该理论的野外检验——如 David Reznick 与 John Endler 自1970年代后期起对特立尼达孔雀鱼的工作，以及 Steven Austad 的岛屿负鼠（1993）——随后出现。
:::

## 由此引向何处

生活史决定种群模型由之建立的年龄特异性出生率与死亡率。[[ecology/population-growth]] 展示如何在生命表中度量这些比率，以及它们如何综合成一个种群的增长率。捕捞与其他改变死亡率的收获在那里和 [[conservation-biology/small-populations]] 中处理；繁殖行为的进化，包括交配系统与亲代抚育，见 [[behaviour/mating-systems]]。

::: summary
- 生活史是生长、繁殖与存活的时间表；生物为**一次繁殖**（繁殖一次）或**多次繁殖**（反复繁殖）（[[#def-life-history]]）。
- 有限的资源强加**权衡**（[[#def-tradeoff]]）：当前与未来繁殖、后代的数量与大小、繁殖与生长。相关数据可能掩盖它们；窝雏数操纵等实验揭示了**繁殖代价**。
- **Smith–Fretwell 模型**（[[#prop-smith-fretwell]]）预言最优后代大小在从原点出发的直线与后代适合度曲线相切之处，与亲代的预算无关。
- Lack 的**最高产窝**通常大于最常见的窝，主要因为对亲代未来的代价。
- **Cole 悖论**及其解决（[[#prop-cole]]）：一年生必须比多年生多产 $p/c$ 个后代；成体存活相对幼体存活偏低偏爱一次繁殖。
- 高成体死亡率偏爱早期成熟与高繁殖努力（特立尼达的孔雀鱼）。r–K 方案描述了快-慢连续谱，但已被年龄特异性的人口学理论取代。
- **衰老**之所以进化，是因为选择力随年龄下降（[[#prop-force]]）：通过突变积累、拮抗多效性与一次性体细胞。外因死亡率低偏爱更慢的衰老。
:::

## 习题

::: exercise 最优后代大小 {level=1 check="6"}
在后代适合度为 $f(s) = 1 - s_0/s$（$s > s_0$）的 Smith–Fretwell 模型中，当最小可行大小为 $s_0 = 3$ mg 时，最优后代大小是多少？
::: solution
由 [[#ex-sf]]，$s^* = 2s_0 = 6$ mg。
:::
:::

::: exercise 最高产窝 {level=1 check="5"}
若一窝 $c$ 枚卵中每只雏鸟的存活概率为 $p(c) = 1 - 0.1c$，最高产窝是多少？
::: solution
$Y(c) = c - 0.1c^2$，$dY/dc = 1 - 0.2c = 0$ 在 $c = 5$ 处；$Y(5) = 2.5$，大于 $Y(4) = Y(6) = 2.4$。
:::
:::

::: exercise Cole 悖论 {level=1 check="6"}
对种子到成株存活为 $c = 0.1$、成株存活为 $p = 0.6$ 的植物，一年生每年必须比多年生的产量多产多少粒种子，二者才有相等的适合度？
::: solution
由 [[#eq-cole]]，$p/c = 0.6/0.1 = 6$ 粒种子。
:::
:::

::: exercise 存活到5岁 {level=1 check="0.328"}
在外因年死亡率恒为20 %的条件下，同生群存活到5岁的比例是多少？给出三位小数。
::: solution
$l_5 = 0.8^5 = 0.328$。
:::
:::

::: exercise 一年生竞争者 {level=2 check="120"}
一种多年生植物每年产30粒种子，从一年到下一年的存活概率为0.9，其种子成为成株的概率为0.01。一年生必须产多少粒种子才能与之匹敌？
::: solution
$B_a = 30 + 0.9/0.01 = 30 + 90 = 120$。在高成株存活、低幼体存活之下，多年生习性受到强烈偏爱。
:::
:::

::: exercise Smith–Fretwell 最优值的几何 {level=2}
由 [[#eq-sf]] 证明：若亲代的预算 $R$ 加倍，最优后代大小不变，并说明亲代会如何处置多余的资源。然后设想一个更富饶的环境使后代适合度曲线移动为 $f(s) = 1 - s_0/s$ 但 $s_0$ *更小*。最优值如何变化？
::: solution
$W(s) = (R/s)f(s)$；$R$ 加倍使每个 $s$ 处的 $W$ 加倍，因而最大值的位置不变。亲代会以同样大小的后代多产一倍。若 $s_0$ 变小（后代存活所需更少，例如因为食物充裕），最优值 $s^* = 2s_0$ 也随之变小：模型预言在温和环境中后代更小、更多，在幼体面临严酷条件的地方后代更大——例如许多鱼类与昆虫在幼体食物稀缺的地方产更大的卵，正是这一格局。
:::
:::

::: exercise 解读一个窝雏数实验 {level=2}
在山雀一个种群的实验中，随机地把一些巢的雏鸟减少两雏、保持不变、或增加两雏。第二年再次繁殖的雌性比例相应为0.62、0.55和0.41；离巢幼鸟数为6.8、8.1和8.9。(a) 这些结果表明什么？(b) 为什么必须操纵窝雏数，而不能比较自然的小窝与大窝？(c) 若一只养育增大窝、存活下来再次繁殖的雌性与其余存活者的繁殖成功相同，且每只存活雌性未来平均每年养育8只幼鸟，那么只计今年与明年，增大的窝是否优于不变的窝？
::: solution
(a) 养育更多幼鸟增加了今年离巢的数目，却降低了雌性明年繁殖的机会：繁殖代价。

(b) 自然产大窝的雌性可能状态更好或领地更好，那样的话它们会既养更多幼鸟又存活更好；这一比较会把获取与分配混为一谈。随机操纵切断了那种关联。

(c) 不变：$8.1 + 0.55\times8 = 8.1 + 4.4 = 12.5$。增大：$8.9 + 0.41\times8 = 8.9 + 3.28 = 12.18$。计入明年，增大的窝表现更差：今年多出的0.8只离巢鸟抵不过明年损失的1.12只，这与最常见的窝卵数低于最高产窝相符。
:::
:::

::: exercise 孔雀鱼与捕食者 {level=2}
来自高捕食地点（其中捕食者主要吃成体）的孔雀鱼被移到一个低捕食地点（其中另一种捕食者主要吃幼体）。预测成熟年龄、成熟大小、繁殖努力与后代大小应当如何进化，解释每个预言，并说明要证明这些变化是进化而非可塑的，你需要做什么。
::: solution
在新地点，成体死亡率更低，而幼体死亡率相对较高。预言：成熟推迟且在更大体型时（繁殖前死亡的风险更低，而较大的雌性繁殖力更高），每次的繁殖努力更低（成体很可能再次繁殖，所以未来繁殖更有价值），后代更少而更大（较大的幼体更能活过吃幼体的捕食者）。要证明变化是进化的，把两个种群的后代在相同的实验室环境中饲养两代，食物相同、没有捕食者：仍然持续存在的差异就是遗传的。Reznick 及同事发现的正是如此。
:::
:::

::: exercise 拮抗多效性的数值 {level=3}
在一个大小恒定的种群中，个体每年以概率0.5存活，而在年龄 $x = 1, 2, 3, \ldots$ 时存活的每个个体当年产生一个后代，于是按 $l_x = 0.5^x$，后代一生产量的期望为 $R_0 = \sum_{x\ge1} l_x \cdot 1 = 1$。一个新等位基因使1岁时的繁殖力提高10 %，但在其携带者进入8岁时将其杀死。(a) 计算后代一生产量期望的增益与损失。(b) 该等位基因受偏爱吗？(c) 若年存活率为0.9，你的答案将如何变化？
::: solution
(a) 增益：$l_1\times0.1 = 0.5\times0.1 = 0.05$ 个后代。损失：8岁起的全部繁殖，$\sum_{x\ge8}0.5^x = 0.5^8/(1-0.5) = 0.0078$ 个后代。

(b) 净变化为 $+0.042$，约为一生产量的4 %提高：该等位基因将扩散，尽管它造成8岁死亡。这就是拮抗多效性。

(c) 当 $l_x = 0.9^x$ 时，$R_0 = \sum_{x\ge1}0.9^x = 9$（对大小恒定的种群本应需要更低的繁殖力，但要紧的是比较本身）。增益：$0.9\times0.1 = 0.09$。损失：$\sum_{x\ge8}0.9^x = 0.9^8/0.1 = 4.30$。相对于 $R_0$，增益为1 %，损失为48 %；该等位基因受到强烈的负选择。低外因死亡率使晚年代价变得要紧，因此成体存活率高的物种应进化出更慢的衰老。
:::
:::

::: exercise 岛屿负鼠 {level=3}
Austad 发现无捕食者岛屿上的负鼠比大陆上的负鼠衰老更慢。(a) 解释衰老的进化理论为何预言这一点。(b) 提出两项一项严谨的研究必须排除的替代解释，以及如何排除。(c) 据报告岛屿上的负鼠产仔数也更小。这与一次性体细胞理论一致吗？
::: solution
(a) 外因死亡率更低意味着更多个体存活到老年，因此对晚期有害效应的负选择更强（受影响的个体更多），而用晚期代价换取早期收益的等位基因也就不那么受偏爱。选择应产生更慢的衰老。

(b) 这一差异可能是环境性的而非遗传的——例如岛上气候更温和、疾病更少或食物更好；把两地动物养在一起的同园比较可以检验这一点。若两个种群取样方式不同，衰老的度量也可能有偏（例如大陆上最老的个体很少被活捉）；对已知年龄的两地动物测量同样的生理指标（Austad 用的是尾腱胶原交联）会有所帮助。

(c) 一致：一次性体细胞理论预言维持与繁殖之间存在权衡，因此对持久身体的更多投入应伴随每次繁殖更低的产量。产仔数更小伴随更慢的衰老，正是预期的组合，尽管对两个种群的单次比较无法确立机制。
:::
:::
