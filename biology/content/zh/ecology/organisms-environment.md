巨柱仙人掌生长于亚利桑那州与墨西哥西北部的索诺兰沙漠，但在其北、东两侧不远处戛然止步，且向上不超过整日持续严霜出现的海拔左右。藤壶 *Chthamalus stellatus* 密布苏格兰西部岩岸的上带，而在低几十厘米、看起来条件更宜的地方几乎绝迹。木蛙每年冬天在阿拉斯加冻透全身，春天又融化复苏；温度高出几度的珊瑚会排出其藻类而饥饿致死。这些事实每一个都关乎某种生物能生活在哪里、有多少——生物的**分布与多度**，正是生态学的对象。

生态学整体追问生物为何现身于其现身之地、数量为何是其数量、以及它们在那里做什么。答案有几个层次：个体的生理学、种群的动态、物种之间的相互作用、以及生态系统中能量与物质的流动。本章作为开篇，从最底层开始，谈一个生物及其面对的环境。我们区分作用于生物的物理**条件**与它所消耗的**资源**，描述气候如何在整个地球上设定二者的格局，量化性能如何依赖温度，最后谈**生态位**——这个概念把生物的需求与其在世界中的位置系在一起，其后关于竞争、捕食与群落的各章将不断回到它。塑造这里讨论的每一种耐受与需求的自然选择，见 [[evolution/natural-selection]]。

## 条件与资源

生物与其物理和生物环境的相互作用有两种根本不同的方式。有些环境因素作用于生物而自身不被消耗；另一些则被吸收和消耗，以至一个生物拿走的，另一个生物便得不到。

::: definition 条件与资源 {#def-conditions-resources}
**条件**是环境的物理或化学特征——温度、相对湿度、pH、盐度、水流、风速、某种污染物的浓度——它影响生物的性能，但不被生物消耗或耗竭。**资源**是被生物消耗、致使其可用于其他生物的数量减少的东西：植物的光与二氧化碳、矿质养分、水、食物、氧气，以及巢穴或岩石上的一席之地之类的空间。
:::

这一区分很重要，因为只有资源才能被**竞争**。并排生长的两株植物体验着同样的气温，一株的体验不会削减另一株的；但上层叶片吸收的每一个光子，下层叶片都得不到，一条根吸收的每一个硝酸根离子，其邻株便失去了。因此资源把利用它的生物的命运联结起来，其供给会被消耗压低——这正是 [[ecology/competition]] 中竞争模型的基础。

有些因素兼具二者。水对于吸收它的植物是资源，而流过溪床的水流对于 攀附在石头上的蜉蝣稚虫是条件。氧气是动物的资源，然而池塘中其浓度会被它们的呼吸拉低，而拉低后的浓度又对其中一切生物起着条件的作用。这一分类说的是某一因素与某一生物之间的关系，不是因素本身的属性。

::: quiz
对一株长在山毛榉林林下的幼苗，以下哪些是资源（按 [[#def-conditions-resources]] 的意义）？选出所有符合的选项。
- [x] 到达林下的光
- [ ] 气温
- [x] 土壤中的硝酸盐
- [ ] 土壤 pH
- [x] 土壤水
::: solution
光、硝酸盐和水被吸收并被消耗：邻株用掉它们，幼苗能得到的就少了。气温和土壤 pH 是条件——它们影响幼苗生长，但幼苗不消耗它们，邻株也不因它们而竞争（尽管生物可以改变条件，如根际使土壤酸化）。
:::
:::

## 气候如何设定舞台

地球上条件与资源的大尺度格局，由太阳能的输入以及重新分配它的大气与海洋环流设定。

**太阳辐射与纬度。** 太阳在大气层顶垂直于光线的面上提供约1361 W m⁻²（“太阳常数”）；对整个球面和昼夜平均，这是四分之一，约340 W m⁻²。赤道附近正午太阳全年很高，能量集中在小面积上；越向极地，同一光束斜射地表，铺开在更大面积上，并穿过更厚的大气。由于地球自转轴相对其轨道倾斜约23.4°，最直日晒的纬度一年中在南、北回归线之间移动，产生了**季节**——赤道附近微弱，高纬度极端。

**大气环流。** 赤道受热上升的空气在上升中膨胀冷却，以热带雨林的大雨降出其水分。干燥的空气随后在高处向极地流动，在南北纬30°附近下沉，并在下降中增温、吸收水分：**哈得来环流**的下沉支，正是撒哈拉、阿拉伯、卡拉哈里、澳大利亚内陆等大火热的沙漠靠近那些纬度的原因。赤道附近上升气流与降雨的带状区，即热带辐合带，追随太阳南北移动，使许多热带地区一年分干湿两季而非冷暖两季。

**海洋与山脉。** 水的热容量高，故沿海气候比同纬度的大陆内部温和，而洋流在数千公里间搬运热量：墨西哥湾流与北大西洋暖流使西北欧比同纬度的加拿大东部暖好几度。山脉迫使潮湿空气抬升，冷却后在迎风坡降雨，背风面留下**雨影区**——内华达山脉和喀斯喀特山脉以东的美国西部干旱内陆，或安第斯山脉以东的巴塔哥尼亚草原。

**海拔。** 上升的空气膨胀并冷却。标准大气中，温度每升高一千米下降约6.5 °C（实际的**直减率**随湿度、季节和地点而变，大致在4到9.8 °C km⁻¹ 之间）。因此攀登一座山，就是让生物经历一串类似向极地旅行所遇的气候，而山上的植被带呼应着 [[ecology/biogeography]] 中描述的随纬度更替的生物群系序列。

::: example 一个物种必须向高处迁移多远 {#ex-lapse}
一种高山植物在一座山上其分布下界在1800 m，由夏季温度设定。山体大致呈锥形，山顶在2800 m。若区域气候在直减率维持6.5 °C km⁻¹ 不变的情况下增温1.5 °C，下界移动多少？该物种原有面积还剩几分之几？
::: solution
某一给定温度现在出现在更高处，高出

$$
\Delta h = \frac{1.5\ \text{°C}}{6.5\ \text{°C km}^{-1}} = 0.231\ \text{km} \approx 231\ \text{m},
$$

故下界从1800 m 移到约2031 m。对锥形山体，海拔 $h$ 以上的水平面积是一个圆，其半径正比于到山顶的剩余高度 $H - h$。因此面积按 $(H - h)^2$ 缩放，剩余比例为

$$
\left(\frac{2800 - 2031}{2800 - 1800}\right)^2 = \left(\frac{769}{1000}\right)^2 \approx 0.59.
$$

增温1.5 °C 便移除了该物种约41 %的生境，尽管它失去的垂直带仅231 m 宽。真实的山不是锥形，植物也不会即刻追随等温线，但这一几何是普遍的：靠近山顶的生境随其上移而缩小，而已经接近山顶的物种无处可去。
:::
:::

**微气候。** 生物所体验的气候可能与区域气候大不相同——后者是高出短草1.5 m 的气象站记录的气候。北半球山丘的南坡比北坡接受更多阳光；晴天下一块深色岩石上方几毫米的空气可比一米高处暖20 °C；腐烂原木内部或洞穴内部对热和冷都有缓冲。小型生物就生活在这些微气候中，许多动物以行为在其中选择——一只在日晒与阴影间往返的蜥蜴，能在气温波动二十度的日子里把自己的体温维持在几度之内。

## 对条件的响应：耐受与性能

一个生物的性能——生长速率、存活、繁殖力，或一只蜥蜴冲刺的速度——如何依赖温度这样的条件？

::: definition 耐受范围与性能曲线 {#def-tolerance}
对某一给定条件，生物的**性能曲线**把某项性能的度量对条件的水平作图。性能在**最适点**处最高，向两侧下降。**耐受范围**是生物能够生存的条件范围；其中较窄的范围允许生长，更窄者允许繁殖。生存的界限称为**临界最低**与**临界最高**（对温度为 $CT_\mathrm{min}$ 与 $CT_\mathrm{max}$）。
:::

每个物种对每个因素都有一个两端有界限的耐受范围，这一思想由 Victor Shelford 于1913年作为“耐受定律”提出。外温动物（体温随环境走的动物）的温度性能曲线有特征性的不对称形状：性能随温度缓慢上升，达到最适，然后在几度之内崩塌，因为蛋白质与膜开始失效。因此最适点远较临界最低靠近临界最高，这带来一个不受欢迎的后果：高过最适的一点点增温的代价，远大于低于最适同等幅度的降温。

::: widget plot
f: if(x < To, exp(-((x - To)/w)^2), max(0, 1 - ((x - To)/d)^2))
x: 0, 50
y: 0, 1.1
sliders: To=30:15:40:0.5; w=8:3:15:0.5; d=6:2:12:0.5
labels: \text{相对性能}
caption: 模型的温度性能曲线：性能（相对其最大值）对体温（°C）。$T_o$ 是最适点，$w$ 设定性能在偏冷一侧上升的平缓程度，$d$ 是从最适点到性能降为零的临界最高的距离。注意默认参数的不对称：低于最适6 °C 处的性能仍有最大的约57 %，而高出6 °C 处性能为零。调小 $d$ 以模拟生活在接近其上限的热带外温动物。
:::

生活在热带的外温动物，其体温常已接近其最适点与临界最高，**热安全边界**很小，而许多温带物种当前生活在低于其最适的体温。因此，跨纬度比较昆虫和蜥蜴温度性能曲线的研究得出的结论是：对给定的增温幅度，热带外温动物可能比温带的更脆弱，尽管这类预测取决于动物能在多大程度上利用荫蔽、微气候与行为来缓冲自身。

### 温度与生物学过程的速率

在耐受范围内，多数生物学速率随温度上升，因为其底层的化学反应速率如此。一个方便的概括是温度系数。

::: proposition 温度系数 Q₁₀ {#prop-q10}
若某过程的速率 $R$ 每升高10 °C 乘以同一因子 $Q_{10}$，则

$$
R(T) = R(T_0)\,Q_{10}^{\,(T - T_0)/10}, \qquad Q_{10} = \left(\frac{R_2}{R_1}\right)^{10/(T_2 - T_1)},
$$ {#eq-q10}

其中 $R_1$ 与 $R_2$ 是在温度 $T_1$ 与 $T_2$ 测得的速率。对大多数生物在约5至35 °C 之间的代谢过程，$Q_{10}$ 介于约2与3之间。
:::

这是一种**经验描述**，不是定律。取对数，$\ln R$ 是 $T$ 的直线，斜率为 $(\ln Q_{10})/10$，在中等范围内是不错的近似；范围更宽时 $Q_{10}$ 本身会变，高温处下降、越过最适点后崩塌，性能曲线所示的那样。更具机制性的 Arrhenius（Boltzmann）形式 $R \propto e^{-E/kT}$，$T$ 以开尔文计、$E$ 为活化能，是代谢生态学理论的基础，但它同样是对一个范围内平均行为的描述，而非任何单一生物的机制。反应速率的化学见 [Chemistry Atlas](/learn/chemistry/course.php?c=kinetics)，酶见 [[biochemistry/enzymes]]。

::: example 蜥蜴代谢的 Q₁₀ {#ex-q10}
一只蜥蜴在体温20 °C 时每小时消耗0.20 mL 氧气，在30 °C 时为0.52 mL h⁻¹。计算 $Q_{10}$，并预测35 °C 时的耗氧量。
::: solution
区间恰为10 °C，故 $Q_{10} = 0.52/0.20 = 2.6$。由 [[#eq-q10]]，

$$
R(35) = R(30)\times 2.6^{(35 - 30)/10} = 0.52 \times 2.6^{0.5} = 0.52\times 1.612 = 0.84\ \text{mL h}^{-1}.
$$

预测的可靠程度只相当于恒定 $Q_{10}$ 的假设：若35 °C 已接近蜥蜴的最适点，真值可能更低。
:::
:::

一个实际的推论是，外温动物的发育取决于累积的温暖而非日历时间。对许多昆虫和植物，发育速率大致正比于温度高出**发育起点温度** $T_\mathrm{th}$ 的部分，而完成一个阶段需要恒定的**热常数** $K$，以**度日**计量：一度日就是在高于起点1 °C 中度过的一天。这一线性模型是在温度范围中段成立的近似；它被常规地用于确定害虫的羽化和作物的开花时机。

::: example 度日与世代数 {#ex-degree-days}
一种蚜虫的发育起点为10 °C，从出生到繁殖需要250度日。在恒定15 °C 和20 °C 下发育各需多久？一个生长季长150天、平均温度18 °C；其中容纳多少代？若季节增温2 °C 呢？
::: solution
15 °C 下每天贡献 $15 - 10 = 5$ 度日，故发育需 $250/5 = 50$ 天。20 °C 下每天贡献10，故需25天：增温5 °C 使世代时间减半。

整个季节累积的度日为 $150\times(18 - 10) = 1200$，足以完成 $1200/250 = 4.8$ 代。增温2 °C 后季节累积 $150\times 10 = 1500$ 度日，即6代。由于每一代都使种群倍增，对一代数量增长数倍的昆虫而言，多出的1.2代可能意味着季末种群大得多——这是增温影响害虫暴发的途径之一。
:::
:::

真实的温度是波动的，度日逐日累加。最简单的方法使用每日最高与最低气温的平均值：

```python
import numpy as np

t_max = np.array([22, 25, 19, 17, 24, 28, 26])   # daily maximum, °C (shape: 7 days)
t_min = np.array([ 9, 12, 10,  6, 11, 15, 14])   # daily minimum, °C
threshold = 10.0                                  # developmental threshold, °C

daily_mean = (t_max + t_min) / 2
degree_days = np.clip(daily_mean - threshold, 0, None)   # no development below threshold
print(degree_days)          # [ 5.5  8.5  4.5  1.5  7.5 11.5 10. ]
print(degree_days.sum())    # 49.0 degree-days in the week
```

平均法会低估那些日均低于阈值而午后温暖的日子的发育；更精细的方法对一条拟合于最低与最高气温之间的正弦曲线积分。

### 应对极端

生物以三种大致的方式处置其偏好范围之外的条件。它们可以在生理上**耐受**：木蛙 *Rana sylvatica*（在某些分类系统中为 *Lithobates sylvaticus*）靠给细胞装载葡萄糖，挺过其大部分身体水分结冰。它们可以在时间或空间上**避开**：通过休眠（种子、细菌芽孢、昆虫的滞育）、冬眠、或迁徙。它们也可以像内温动物对温度、海水鱼对盐分所做的那样，**调节**其内部状态以对抗外部状态；体温调节的生理学见 [[animal-physiology/thermoregulation]]。

生命所能耐受的极端令人惊叹。一些古菌在热液喷口100 °C 以上生长——2008年报道 *Methanopyrus kandleri* 的一株在高压下于122 °C 繁殖——而一些细菌和藻类在0 °C 以下的盐水中生长。极少有真核生物能在约60 °C 以上完成其生活史。这些是可能性的边缘；多数物种耐受的范围要窄得多，其限定不在于蛋白质能存活什么，而在于在特定地方生活的权衡。

::: warning "生物适应它们被发现之处的条件"
人们容易假设一个物种生活的条件必定是其最适条件。往往并非如此。本章后文讨论的藤壶和植物生活在竞争者与捕食者允许的地点，那里可能远离其生理最适；物种可以在其种群正在下降的地方维持一时；许多物种尚未追踪上最近的气候变化。自然界中所占据的条件范围是生理、相互作用与历史的组合——基础生态位与现实生态位的区分在本章后文将讲得精确。
:::

### 驯化与局部适应

耐受并非固定。在一个个体的一生中，被移到新条件的个体常在数日到数周内调整其生理——**驯化**（实验室内）或**气候驯化**（野外）——例如改变其膜脂的成分或酶的异构型。跨代地，生活在不同条件下的广布物种的种群常会进化出遗传差异：它们成为**生态型**。经典的证明来自 Jens Clausen、David Keck 和 William Hiesey，他们从1930年代起，把沿加利福尼亚内华达山脉样带采集的蓍（*Achillea*）及其他植物的克隆，种在三个海拔的共同园中。高海拔的植株矮小，且即使种在低海拔仍保持矮小，表明种群间的差异大部分是遗传的，同时有一部分是可塑的。这类共同园与交互移植实验至今仍是区分局部适应与可塑性的标准方法。

## 资源

资源是生物为生长和繁殖所消耗的东西。对绿色植物，它们是太阳辐射、二氧化碳、水和矿质养分；对动物，它们是作为食物的其他生物——活的或死的——连同水、氧气和空间。

**太阳辐射。** 植物利用波长400–700 nm 的辐射，即**光合有效辐射**（PAR）。叶片的光合速率随辐照度上升而后饱和，而荫蔽下生长的植物比阳生叶在更低的辐照度下饱和、却更有效率地利用弱光。光是一种奇特的资源：它无法储存，到达时未被捕获的光子便损失了，而其供给随云层和被风吹动的叶片逐秒变化。光响应曲线及其对 C₃ 与 C₄ 光合作用的依赖见 [[plant-biology/photosynthesis]]。

**水。** 植物每当吸收二氧化碳就通过气孔失水，故水与碳的得失不可分。土壤变干时土壤水被保持得越来越紧，其可利用性以**水势**度量，即以兆帕计的负压力；按惯例，许多作物在土壤水势降到约 −1.5 MPa 时永久萎蔫，尽管沙漠植物能从干得多的土壤中榨取水分。水分在植物体内的运动见 [[plant-biology/water-transport]]。

**矿质养分。** 氮、磷、钾、硫、钙、镁、铁和其他十几种必须从土壤（水生植物则从水）中吸收。它们在空间和时间上分布不均，其经由生态系统的循环是 [[ecology/nutrient-cycles]] 的主题。

**食物。** 对异养生物，资源是其他生物的身体，其品质差异极大。植物组织富碳而贫氮——叶片碳氮质量比通常为20至50，木材达数百，而动物组织约为5至8——并有纤维素、木质素和毒素设防。动物猎物的营养更接近捕食者，但必须捕获。

### 多种资源的结合

当一个生物需要多种资源时，它们的供给如何共同决定其生长？

::: definition 必需资源与可替代资源 {#def-essential}
若两种资源彼此不能取代，则它们是**必需的**（互补的）：生长受相对需求而言最少的那种限制，正如氮和磷之于植物。若一种可以顶替另一种，它们是**可替代的**：一种的减少可以用更多的另一种来补偿，正如两种种子之于雀类。也存在中间情形：资源可能部分可替代，或是**互补的**——就混合比单独任一种产生更多生长而言。
:::

对必需资源，十九世纪的农业化学家注意到，添加某种养分只有当它就是最缺的那种时才会提高作物产量。这一思想与 Justus von Liebig 相关联，他在1840年使之流行（此前 Carl Sprengel 已作陈述），并被称为**Liebig 最小律**：控制生长的不是可利用资源的总量，而是相对需求最稀缺的那一种。

::: example 最小律 {#ex-liebig}
一块田所能供应的氮、磷、钾分别达到小麦达到8 t ha⁻¹ 目标产量所需的80 %、45 %和120 %。按最小律，预期产量是多少？若 (a) 增施钾肥，(b) 把磷补到全部需求，会怎样？
::: solution
产量由最缺的养分磷决定，为45 %：约 $0.45\times 8 = 3.6$ t ha⁻¹。

(a) 增施本已过剩的钾不改变什么：仍是3.6 t ha⁻¹。

(b) 磷达到100 %后，氮成为限制因子，为80 %：产量升到 $0.80\times 8 = 6.4$ t ha⁻¹，而不是8。随着每一个限制被解除，限制因子随之转移。
:::
:::

最小律是一个有用的初步模型，但自然不那么整齐。植物会调整其分配，土壤养分短缺时多长根、光照短缺时多长叶，于是几种资源往往一起变得受限；而且 Stanley Harpole 及同事2011年的一项荟萃分析汇总了陆地、淡水与海洋系统中数百个养分添加实验，发现氮和磷一起添加常常比单独任一种更强烈地增加生产者的生物量，这一格局称为**共同限制**。

## 生态位

现在我们有了本章最重要概念的全部要素。一个物种只有当那里的条件处于其耐受范围之内、且它需要的资源可得时，才能在某地生活。所有这类需求的集合定义了它的生态位。

这个词有过三种含义。Joseph Grinnell 于1917年写加州弯嘴嘲鸫时，用它指限制一个物种分布的栖地需求。Charles Elton 在 *Animal Ecology*（1927）中用它指物种在其群落中的功能角色——它吃什么、被什么吃。G. Evelyn Hutchinson 于1957年给出了今天使用的定义，把前两者都吸收进来。

::: definition Hutchinson 生态位 {#def-niche}
考虑影响一个物种的每一种条件与资源，各作为一个 $n$ 维空间的一根轴。该物种的**基础生态位**是此空间中，在没有其他物种时其种群能够增长、或至少维持自身——即出生至少抵得上死亡——的区域（“$n$ 维超体积”）。**现实生态位**是基础生态位中，该物种在竞争者、捕食者、寄生虫和互利共生者存在时实际占据的部分。
:::

关于这一定义有三点值得挑明。第一，生态位以**种群增长**定义，而非个体存活：个体可能在某种条件下存活，而其种群不能存续。第二，它是**物种**的属性，不是地方的属性：生态位是一组需求，而栖地是这些需求得到满足之处。一个有用的说法是：栖地是一个物种的“地址”，生态位是它的“职业”。第三，生态位一次只能画出一两根轴，但它拥有的维数与起作用的因素一样多。有一个条件（如温度）时生态位是一个区间；有两个（温度和湿度）时是一个平面区域；有三个时是一个体积。

### 野外的基础生态位与现实生态位

基础生态位与现实生态位之别最清楚的证明，是 Joseph Connell 发表于1961年的一个藤壶实验。在克莱德湾坎布雷岛的米尔普特岩岸，小型藤壶 *Chthamalus stellatus* 的成体占据高潮区上方的岸带，位于大型藤壶 *Balanus balanoides*（今 *Semibalanus balanoides*）所带之上。然而 *Chthamalus* 的幼体也沉降在更低处。Connell 在低区的部分石头上移除 *Balanus*，另一些石头保留。在移除 *Balanus* 之处，*Chthamalus* 存活良好；在其保留之处，*Balanus* 使幼小的 *Chthamalus* 窒息、掏挖其下并从上方压碎它。相反，在上带，*Balanus* 在低潮时因干晒而死，而 *Chthamalus* 能耐受干晒。

解释是：*Chthamalus* 的基础生态位向下延伸进入 *Balanus* 之带，但竞争把它的现实生态位限制在岸上高处；与此同时，*Balanus* 被排斥于岸上高处之外是由于一个物理条件、而非竞争者。正是这一格局——上界由物理胁迫设定、下界由生物相互作用设定——此后在世界各地的岩岸上都有发现。

::: quiz
在 Connell 的实验中，*Balanus* 被移除后 *Chthamalus* 在低区的存活表明了什么？
- [ ] *Chthamalus* 比 *Balanus* 更适应低区
- [x] 低区位于 *Chthamalus* 的基础生态位之内，它因 *Balanus* 而被排斥于低区之外
- [ ] *Balanus* 无法在低区存活
- [ ] 干晒设定了 *Chthamalus* 的下界
::: solution
移除竞争者揭示了 *Chthamalus* 单独生活时*能够*存续之处：它的基础生态位包括低区。在 *Balanus* 存在时它在那里无法存活，故其现实生态位更窄。实验并未说明 *Chthamalus* 比 *Balanus* 更适应低区——两者同在时 *Balanus* 在那里取胜。
:::
:::

现实生态位通常小于基础生态位，但并非总是。**促进作用**——一个物种为他人改善条件——能把一个物种扩展进它单独无法占据的地方：在新英格兰的盐沼，灯心草遮蔽土壤、降低其盐度，使其他植物能在原本失败的地方生长。而当个体不断从附近高产的种群到来时，一个物种也可能完全出现在其基础生态位之外：**汇**种群中死亡超过出生，只靠来自**源**种群的迁入补充而存续，这是 Ronald Pulliam 于1988年发展的思想。因此，一个物种被发现地点的清单，既多于、也少于它的基础生态位。

::: intuition 作为过滤器的生态位
把一个区域的全部物种想象成某个地点的潜在定殖者之池。该地点的条件是第一道过滤器，只放行其耐受范围包含这些条件的物种。其资源是第二道过滤器。已存在的物种及其竞争、捕食和互利共生效应是第三道。而扩散决定哪些物种得以到达该地点。我们在那里发现的是通过了全部四道过滤的东西——这就是为什么一个物种的存在同时告诉我们关于这四者的信息，而一个物种的缺席却不特别告诉我们其中任何一个的信息。
:::

### 绘制生态位与预测分布

由于基础生态位在环境空间中定义、而物种分布区在地理空间中定义，二者可以由制图联系起来。**物种分布模型**（或生态位模型）把一个物种被发现的记录与其所在地的环境变量——通常是气候、土壤和土地覆被——联系起来，并把拟合的关系投影回地图，预测条件适宜之处。这类模型被广泛用于预测入侵物种可能扩散到哪里，或未来气候下一个物种气候适宜的范围将位于何处。

解读它们必须小心。对一个物种出现之处拟合的模型，描述的是更接近其现实生态位而非基础生态位的东西，因为记录已经反映了竞争者、捕食者、扩散障碍与历史；而且它假定在当前条件下拟合的关系在新的条件组合下依然成立。一种互补的方法从生理学生态位——测得的耐受与能量收支——出发，追问一个种群可以在何处存续；把两者结合是一个活跃的研究领域。

::: application 物种在移动
若物种的分布部分由气候设定，增温的气候就应当移动它们。I-Ching Chen 及同事2011年发表的一项涵盖众多生物类群研究的荟萃分析估计，物种分布区以每十年约17 km 的中位速率向高纬度移动、以约11 m 每十年的速率向高海拔移动，而在增温更快的地区移动更快。响应在物种间差异极大——有的没有移动，有的朝“错误的”方向移动——当分布由相互作用和扩散以及温度耐受共同设定时，这正是可以预期的。这些移动、以及 [[#ex-lapse]] 中算出的山顶附近生境萎缩的保护后果，在 [[conservation-biology/invasions-climate]] 中讨论。
:::

::: history
当 Ernst Haeckel 于1866年创造 *Oekologie* 一词、指生物与其周围环境关系的研究时，生态学成为一门有名姓的科学，但博物学家们早已记录物种住在何处。Alexander von Humboldt 于1807年发表的安第斯钦博拉索山剖面显示，植被带依海拔对着温度排列，实际上是第一幅植物分布对某一条件的地图。Liebig 最小律（1840）和 Shelford 耐受定律（1913）给出了关于资源与条件如何限制生物的第一批一般性表述。生态位被定义了三次：Joseph Grinnell（1917）作为物种的栖地需求，Charles Elton（1927）作为其在群落中的角色，G. Evelyn Hutchinson（1957）作为 $n$ 维超体积。Joseph Connell 的藤壶实验（1961）使基础生态位与现实生态位的区分成为野外实验之事、而非定义之事。
:::

## 由此引向何处

本章描述了一个生物需要什么、能耐受什么。下一章 [[ecology/life-histories]] 追问生物如何在生长、存活与繁殖之间分配其获得的资源。[[ecology/population-growth]] 接着从个体转向种群——生态位正是在那个尺度上定义的——而 [[ecology/competition]] 以生态位重叠为基础，追问相互竞争的物种何时能够共存。

::: summary
- 生态学研究生物的多度与分布，以及决定它们的相互作用。
- **条件**（温度、pH、盐度）影响生物而不被消耗；**资源**（光、水、养分、食物、空间）被消耗，因而可以被争夺（[[#def-conditions-resources]]）。
- 气候由太阳辐射的纬度梯度、地轴倾角（季节）、大气环流（赤道多雨、30°附近荒漠）、海洋、山脉（雨影区）与海拔（每 km 约冷6.5 °C）设定。生物生活在可与区域气候大不相同的微气候中。
- 性能曲线升至最适点而后下降；对外温动物它们是不对称的，在最适点上方不远处崩塌。生物学速率通常 $Q_{10} \approx 2$–3（[[#prop-q10]]，一条经验规律），外温动物的发育可以用度日模拟。
- 生物对极端或耐受、或避开、或调节；耐受在一生中通过驯化改变，跨代通过局部适应（生态型）改变。
- 必需资源作为一阶近似按 Liebig 最小律结合；共同限制很常见。
- **基础生态位**是种群能够存续的条件-资源空间中的区域；**现实生态位**是有其他物种存在时所余的部分（[[#def-niche]]）。Connell 的藤壶显示竞争限制了现实生态位；促进作用可以扩展它，源-汇动态可以把物种置于其外。
:::

## 习题

::: exercise 温度系数 {level=1 check="2"}
一株幼苗的呼吸速率在15 °C 时为3.0 μmol CO₂ g⁻¹ h⁻¹，在25 °C 时为6.0 μmol CO₂ g⁻¹ h⁻¹。计算 $Q_{10}$。
::: solution
区间为10 °C，故 $Q_{10} = 6.0/3.0 = 2$。
:::
:::

::: exercise 预测速率 {level=1 check="17.33"}
某过程的 $Q_{10} = 2.5$，在20 °C 时速率为10个单位。设 $Q_{10}$ 恒定，26 °C 时的速率是多少？保留两位小数。
::: solution
由 [[#eq-q10]]，$R(26) = 10\times 2.5^{(26-20)/10} = 10\times 2.5^{0.6} = 10\times 1.733 = 17.33$ 个单位。
:::
:::

::: exercise 度日 {level=1 check="40"}
一种甲虫的发育起点为8 °C，热常数为400度日。在恒定18 °C 下发育需要多少天？
::: solution
18 °C 下每天贡献 $18 - 8 = 10$ 度日，故发育需 $400/10 = 40$ 天。
:::
:::

::: exercise 山上的温度 {level=1 check="12.25"}
一座山附近海平面的夏季平均气温为22 °C。用直减率6.5 °C km⁻¹，估计1500 m 处的夏季平均气温。
::: solution
$22 - 1.5\times 6.5 = 22 - 9.75 = 12.25$ °C。
:::
:::

::: exercise 条件还是资源？ {level=2}
把下列各项就所指生物归类为条件或资源，并为你觉得含糊的情形给出理由：(a) 老树中的巢洞之于啄木鸟；(b) 盐度之于河口蟹；(c) 水中溶解的氧之于鳟鱼；(d) 风速之于山脊上的一棵树；(e) 花蜜之于熊蜂。
::: solution
(a) 资源：一对用掉的巢洞另一对便得不到，故巢位可以被争夺（空间是资源）。(b) 条件：蟹的存在不改变盐度。(c) 资源：呼吸消耗氧气，并降低其他鱼可得的浓度，尤其在温暖静止的水中；但它的浓度对于那些并不大量耗竭它的动物又类似条件，这就是氧气有时被同时归为两类的原因。(d) 条件：风影响树的生长与形状但不被消耗。(e) 资源：一只蜂取走的花蜜，下一只便得不到。
:::
:::

::: exercise 三种养分的 Liebig 最小律 {level=2}
一块草地能按最大生物量10 t ha⁻¹ 所需，分别供应60 %、90 %和75 %的氮、磷和钾。按 Liebig 最小律，预测生物量：(a) 现状；(b) 施氮补足需求之后；(c) 施氮和钾之后。什么样的结果会提示共同限制？
::: solution
(a) 氮最受限：$0.60\times10 = 6$ t ha⁻¹。(b) 钾成为限制因子：7.5 t ha⁻¹。(c) 磷成为限制因子：9 t ha⁻¹。在严格的 Liebig 限制下，对原草地单独施磷不会有影响。若实验发现单独施磷提高了生物量，或氮和磷一起施加的提高超过各自单独效应之和，则植物处于共同限制——例如因为群落中含有受不同养分限制的物种，或因为额外的磷使植物吸收更多的氮。
:::
:::

::: exercise 解读移除实验 {level=2}
在一片岩岸上，两种海藻占据相邻的带：物种 U 在上潮间带，物种 L 在低处。一位生态学家把物种 L 从低区的样方中清除，并把物种 U 移植进去；又把物种 L 移植到上带。一年后：U 在清除过的低区样方中存活良好，在未清除的低区样方中存活差；移植到上带的 L 无论是否移除 U 都在数周内死亡。用基础生态位和现实生态位解释这些结果。
::: solution
L 缺席时 U 能生活在低区，故低区在 U 的基础生态位之内；U 的现实生态位被 L 限制在上带（通过竞争或其他负相互作用）。L 即使没有 U 在上带也死亡，故其上界由一个物理条件设定——可能是低潮时的干晒或高温——而非 U。这与 Connell 在藤壶中发现的不对称相同：上界由物理胁迫设定，下界由生物相互作用设定。
:::
:::

::: exercise 热安全边界 {level=3}
两个蜥蜴物种有相同形状的温度性能曲线。热带的物种 T 最适体温为33 °C，临界最高为38 °C，野外典型体温为32 °C。中纬度的物种 M 最适为33 °C，临界最高为41 °C，野外体温为26 °C。(a) 各自的热安全边界（$CT_\mathrm{max}$ 减去野外温度）是多少？(b) 用性能曲线的不对称形状，解释若野外体温升高3 °C，哪个物种的性能可能提高、哪个可能下降。(c) 给出两个真实结果可能不同的理由。
::: solution
(a) T：$38 - 32 = 6$ °C。M：$41 - 26 = 15$ °C。

(b) 26 °C 的 M 在其最适之下；增温3 °C 使其到29 °C，更靠近最适，故其性能上升。32 °C 的 T 就在其最适之下；升到35 °C 把它带过最适、到了陡峭的下降侧，高出最适2 °C、距其临界最高3 °C，故其性能下降，可能急剧下降，而在炎热的日子可能超过其临界最高。同样的增温帮助温带物种、伤害热带物种。

(c) 蜥蜴以行为调节体温，可以靠荫蔽或在较凉时段活动来压低体温（尽管这以觅食时间为代价）；热耐受可以通过气候驯化或进化而改变；而且增温在时间上不均匀，故极端值可能比均值更要紧。与其他物种的相互作用——它们同样响应温度——也可能改变结果。

::: exercise 山上的生境丧失 {level=3 check="1.9"}
一种高山生物生活在2400 m 以上，其所在的山近似一个锥形，山顶在3400 m。其下界以6.5 °C km⁻¹ 的直减率追随温度。区域增温多少 °C（保留一位小数）会使其可利用面积减半？设山顶不构成限制。
::: hint
对锥形山体，海拔 $h$ 以上的面积正比于 $(H - h)^2$。
:::
::: solution
下界以上的面积正比于 $(3400 - h)^2$。使其减半需要 $(3400 - h')^2 = \tfrac12(1000)^2$，故 $3400 - h' = 1000/\sqrt2 = 707$ m，$h' = 2693$ m。下界必须上升293 m，对应增温 $0.293\times 6.5 = 1.9$ °C。
:::
:::

::: exercise 生态位还是栖地？ {level=3}
一种鱼被发现于一个湖中，经反复取样，栖息在湖中的种群每年死亡超过出生。(a) 该物种如何在湖中存续？(b) 湖在其基础生态位之内吗？(c) 对一位把该湖作为“该物种的栖地”加以保护的保护管理者，这为何重要？
::: solution
(a) 该种群必须靠迁入维持，例如来自某条出生超过死亡的溪流或一个相连的湖：湖是**汇**，而另一个种群是**源**。

(b) 不在。基础生态位由种群至少能维持自身的条件定义；湖中出生抵不上死亡，故湖在其生态位之外，尽管该物种在那里被发现。

(c) 只保护汇不能保护该物种；若源种群衰退或通道被切断，湖中的种群将缩减至灭绝。一个物种的存在并不是一个地方能供养它的证明，管理必须识别并保护源。测定人口学比率（出生与死亡）而非仅凭存在与否，才是区分源与汇的方法。
:::
:::
