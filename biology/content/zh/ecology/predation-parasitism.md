近两个世纪里，哈得逊湾公司在加拿大北部各地向猎人收购毛皮，并仔细记录每年收到的各物种毛皮数。当 Charles Elton 和 Mary Nicholson 于1942年分析猞猁的进货记录时，他们发现了一个规律得惊人的循环：猞猁数量以约十年的周期上升与崩溃，遍及数千公里的森林，而其主猎物雪鞋兔的多度略先于它们涨落。为什么两个种群会一同振荡？为什么周期恰是那样？

这关乎**消费者**：取食其他活生物体的生物。本章涵盖其主要类型——捕食者、植食动物、拟寄生者与寄生虫——以及它们产生的动力学。我们从 Lotka–Volterra 捕食者-猎物模型及其循环开始，加入捕食者摄食率饱和这一现实特征（**功能反应**），并发现这样一个模型：循环源于失稳，而富集猎物的环境反而可能摧毁系统。我们考察实验室与野外的实验（包括对雪鞋兔的长期工作）就真实循环揭示了什么。然后处理植食，最后是寄生虫与病原体，引入基本繁殖数 $R_0$ 和流行病的 SIR 模型。[[ecology/population-growth]] 的单物种模型是起点，相平面方法已在 [[ecology/competition]] 中用于竞争。捕食者与寄生虫所驱动的进化军备竞赛在 [[evolution/coevolution]] 处理。

## 消费者的类型

::: definition 捕食者、啃食者、拟寄生者与寄生虫 {#def-consumers}
**消费者**通过取食其他活生物体（或其部分）获取能量和养分。四个大类按每个个体一生中攻击多少受害生物、以及受害生物是否死亡来区分。

- **真捕食者**杀死其猎物，通常在攻击后几乎立即杀死，且一生中杀死许多猎物：猞猁、蜘蛛、食种子的啮齿动物。
- **啃食者**（包括大多数植食动物）一生攻击许多受害生物，但每个只取食一部分，很少使其死亡：绵羊、树上的毛虫、吸血的蚊子。
- **拟寄生者**——多为小型蜂类和蝇类——把卵产在单个宿主（通常是昆虫）体内或体表，其幼虫随后吃食宿主身体，将其杀死。
- **寄生虫**从一个或少数宿主获取资源，通常与之密切共同生活，伤害但不一定杀死它们。**微型寄生虫**（病毒、细菌、原生生物）在宿主体内增殖，通常按受感染宿主数计数；**大型寄生虫**（蠕虫、虱、蜱）在宿主体内生长，但以释放感染阶段的方式繁殖，按每宿主计数。
:::

这些类别边界模糊——蚊子对宿主是啃食者、却是寄生虫的传播媒介，许多植食昆虫表现得像单一植物上的寄生虫——但它们的动力学不同，下面的模型一次只针对一个类别设计。

## Lotka–Volterra 捕食者-猎物模型

最简单的模型由 Alfred Lotka（1925）和 Vito Volterra（1926）提出，描述一个猎物种群 $N$ 和一个捕食者种群 $P$。Volterra 的动机来自他未来的女婿、海洋生物学家 Umberto D'Ancona 带给他的一个难题：第一次世界大战期间，亚得里亚海的捕捞减少时，意大利各港口卸下的渔获中捕食性鱼类的比例上升了。

::: proposition Lotka–Volterra 捕食者-猎物模型 {#prop-lvpp}
设无捕食者时猎物以速率 $r$ 指数增长，并以正比于与捕食者相遇率的速率 $aNP$ 被杀死，其中 $a$ 为**攻击率**。设每个被杀死的猎物增加 $b$ 个新捕食者（转化效率），捕食者以恒定的个体平均死亡率 $m$ 死亡。则

$$
\frac{dN}{dt} = rN - aNP, \qquad \frac{dP}{dt} = baNP - mP .
$$ {#eq-lvpp}

内部平衡为

$$
N^* = \frac{m}{ba}, \qquad P^* = \frac{r}{a},
$$ {#eq-lvpp-eq}

而其余一切满足 $N, P > 0$ 的解都是环绕它的闭循环，循环上量

$$
V(N, P) = baN - m\ln N + aP - r\ln P
$$ {#eq-lvpp-v}

保持不变。小循环的周期约为 $2\pi/\sqrt{rm}$，捕食者峰值落后猎物峰值四分之一个周期。假设：除捕食外两个物种均无密度依赖、线性（I 型）功能反应、无年龄结构或时间滞后、闭锁且充分混合的种群。
:::

::: proof
平衡由令各方程在 $N, P > 0$ 时为零得出：$r = aP$ 且 $baN = m$。为证 $V$ 沿解保持不变，求导：

$$
\frac{dV}{dt} = \left(ba - \frac{m}{N}\right)\frac{dN}{dt} + \left(a - \frac{r}{P}\right)\frac{dP}{dt}
= \frac{baN - m}{N}\,N(r - aP) + \frac{aP - r}{P}\,P(baN - m) = 0 .
$$

$V$ 在 $(N^*, P^*)$ 处有唯一极小值，向各方向离开它都增大，故其水平曲线是环绕平衡点的闭圈，解沿其运行。对小振荡，在平衡点线性化得 Jacobian $\begin{pmatrix} 0 & -aN^* \\ baP^* & 0\end{pmatrix}$，其特征值为 $\pm i\sqrt{ba^2N^*P^*} = \pm i\sqrt{rm}$：纯振荡，角频率为 $\sqrt{rm}$，故周期 $2\pi/\sqrt{rm}$。
:::

模型的预言在两处令人意外。第一，猎物平衡 $N^*$ 完全由*捕食者*的参数决定，而捕食者平衡 $P^*$ 由猎物的增长率决定。富集猎物的环境（提高 $r$）产生更多捕食者，而不是更多猎物。第二——这是 Volterra 对 D'Ancona 的回答——任何按数量比例杀死猎物和捕食者的因素，如无差别捕捞，都降低 $r$ 并提高 $m$，从而把平均数量*推向猎物*（$N^*$ 上升而 $P^*$ 下降）。减少捕捞则有相反效果，这正是战时渔获所显示的。同一原理解释了为什么广谱杀虫剂会使虫害更糟：它们杀死害虫的天敌也杀死害虫本身，把平衡推向害虫一边。

::: example 捕食者-猎物循环的平衡与周期 {#ex-lvpp}
一个猎物种群有 $r = 1.0$ 每年；捕食者的攻击率 $a = 0.01$ 每捕食者每年，转化效率 $b = 0.2$，死亡率 $m = 0.4$ 每年。求平衡及小振荡的近似周期。若一种疾病把捕食者的死亡率提高到每年0.6，平衡如何变化？
::: solution
由 [[#eq-lvpp-eq]]，$N^* = 0.4/(0.2\times0.01) = 200$ 个猎物和 $P^* = 1.0/0.01 = 100$ 个捕食者（每单位面积）。小循环的周期为 $2\pi/\sqrt{rm} = 2\pi/\sqrt{0.4} = 9.9$年——接近猞猁-雪鞋兔循环的周期，尽管这种吻合本身证明不了什么。

当 $m = 0.6$ 时，$N^* = 0.6/0.002 = 300$，而 $P^*$ 保持100。该疾病没有减少捕食者的平均数目，却让猎物变多了。
:::
:::

### 模型的毛病

[[#prop-lvpp]] 的中性循环是数学上的奇趣而非现实的预言。因为每条轨线都是闭的，扰动会把系统永久移到另一条循环上；没有任何东西使它回到特征的振幅。具有这种性质的模型称为**结构不稳定**：对它的形式几乎任何改变、无论多小，都会摧毁中性循环。若让猎物自我限制（逻辑斯谛增长），循环就成为向稳定平衡点的衰减螺旋。其他改变则产生增长的振荡。要作出预言，我们需要更现实的成分，而最重要的是捕食者的摄食率如何依赖猎物密度。

## 功能反应与数值反应

::: definition 功能反应与数值反应 {#def-responses}
捕食者的**功能反应**是每个捕食者单位时间吃掉的猎物数与猎物密度之间的关系。**数值反应**是捕食者数目（通过繁殖、存活或迁入）对猎物密度变化的响应。C. S. Holling（1959）区分了功能反应的三种类型：

- **I 型：** 摄食率随猎物密度线性上升（直至上限），如 Lotka–Volterra 模型——滤食性动物的典型。
- **II 型：** 摄食率以减速的速率上升后趋于平顶，因为每个捕获的猎物都需要处理时间——最常见的一类。
- **III 型：** 摄食率在低猎物密度时上升缓慢、然后加速、最后平顶：一条 S 形曲线，产生于捕食者转向其他猎物、或在猎物稀少时搜索效率下降。
:::

Holling 以一个成为经典的实验导出了 II 型曲线：一名蒙眼助手用手指敲击桌面上散放的砂纸片来找到它们，找到一张便拾起一张。因为每张片子拾取都要花时间，每分钟找到的张数随片子变密而趋于平。

::: proposition Holling 圆盘方程 {#prop-holling}
设捕食者以这样的速率搜索：猎物密度为 $N$ 时每单位搜索时间可找到 $aN$ 个猎物；而每个捕获的猎物需要**处理时间** $h$（追逐、制服、吃掉并消化），其间不能搜索。则每个捕食者单位时间吃掉的猎物数为

$$
f(N) = \frac{aN}{1 + ahN} .
$$ {#eq-holling}

低密度时 $f(N) \approx aN$（I 型）；当 $N \to \infty$，$f(N) \to 1/h$；达到最大速率一半在 $N = 1/(ah)$。
:::

::: proof
在总时间 $T$ 内，设捕食者吃掉 $E$ 个猎物。其中 $hE$ 用于处理，$T - hE$ 用于搜索，其间找到 $aN(T - hE)$ 个猎物。令 $E = aN(T - hE)$ 求解：$E(1 + ahN) = aNT$，故 $E/T = aN/(1 + ahN)$。令 $f(N) = 1/(2h)$ 得 $2ahN = 1 + ahN$，即 $N = 1/(ah)$。
:::

::: example II 型功能反应 {#ex-holling}
一只瓢虫每小时在0.2 m² 的面积内搜寻蚜虫（$a = 0.2$ m² h⁻¹），处理每只蚜虫需0.5 h。在密度为每平方米10和50只蚜虫时它每小时各吃多少只？其最大摄食率是多少？
::: solution
由 [[#eq-holling]]，$ah = 0.2\times0.5 = 0.1$ m²。当 $N = 10$：$f = 0.2\times10/(1 + 0.1\times10) = 2/2 = 1$，每小时1只蚜虫。当 $N = 50$：$f = 10/(1 + 5) = 1.67$每小时。由处理时间决定的最大值是 $1/h = 2$每小时；其一半在 $N = 1/(ah) = 10$每平方米蚜虫处达到。猎物密度增加五倍而摄食只增加了三分之二：捕食者饱和了。每个捕食者吃掉的猎物种群比例 $f(N)/N$ 每小时从0.10*降至*0.033——高密度下，猎物的个体平均被捕食风险反而更低。
:::
:::

II 型反应是失稳的。因为猎物的个体平均风险 $f(N)/N$ 随猎物增多而下降，增长的猎物种群会摆脱控制。III 型反应在低猎物密度时是稳定的，因为那里的个体平均风险随猎物密度而*上升*；这能保护稀有猎物免于灭绝，并通过捕食者转换猎物帮助维持猎物物种的多样性。

## 具有饱和的捕食者-猎物模型

把逻辑斯谛猎物增长与 II 型功能反应结合，便得到 Michael Rosenzweig 和 Robert MacArthur（1963）的模型，它是现代捕食者-猎物理论的标准起点。

::: proposition Rosenzweig–MacArthur 模型与富集悖论 {#prop-rm}
设猎物逻辑斯谛增长，捕食者以 II 型功能反应摄食：

$$
\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right) - \frac{aNP}{1 + ahN}, \qquad
\frac{dP}{dt} = \frac{baNP}{1 + ahN} - mP .
$$ {#eq-rm}

捕食者的零增长等斜线是竖直线

$$
N^* = \frac{m}{a(b - mh)}
$$ {#eq-rm-nstar}

（这要求 $b > mh$，捕食者才能增长），而猎物的等斜线是驼峰形曲线 $P = \frac{r}{a}\left(1 - \frac NK\right)(1 + ahN)$，其峰位于 $N = \tfrac12\left(K - \tfrac{1}{ah}\right)$。若 $N^* < K$，则当捕食者等斜线与猎物等斜线相交于驼峰右侧时内部平衡**稳定**，相交于左侧时**不稳定**——被一个稳定的极限环环绕。提高 $K$ 使驼峰右移，从而能把稳定平衡变成振幅增长的极限环。
:::

::: proof
捕食者方程在 $baN/(1 + ahN) = m$ 时为零，即 $baN = m + mahN$，得 [[#eq-rm-nstar]]。猎物方程（$N > 0$）在 $r(1 - N/K) = aP/(1 + ahN)$ 时为零，得前述曲线——它是 $N$ 的开口向下抛物线，其导数 $\frac{r}{a}\left[-\frac1K(1 + ahN) + ah\left(1 - \frac NK\right)\right]$ 在 $N = \frac12(K - 1/(ah))$ 处为零。在平衡点处，$\partial\dot P/\partial P = 0$（捕食者的个体平均增长在其等斜线上为零，且不依赖 $P$），故 Jacobian 的迹为 $\partial\dot N/\partial N$，行列式为 $-(\partial\dot N/\partial P)(\partial\dot P/\partial N)$，其值为正，因为更多的捕食者降低猎物增长、更多的猎物提高捕食者增长。因此稳定性由 $\partial\dot N/\partial N$ 的符号决定。写 $\dot N = NF(N, P)$，在猎物等斜线上 $F = 0$，则 $\partial\dot N/\partial N = N\,\partial F/\partial N$；沿等斜线对 $F(N, P(N)) = 0$ 求导得 $dP/dN = -F_N/F_P$，而 $F_P < 0$，故 $F_N$ 的符号就是等斜线斜率的符号。迹在驼峰的下降侧为负（稳定）、在上升侧为正（不稳定）。由 Poincaré–Bendixson 定理，这一有界系统中环绕不稳定平衡的轨线趋于一个极限环。
:::

Rosenzweig 把这一后果称为**富集悖论**（1971）：向系统添加养分——提高猎物的容纳量——可能使其失稳，产生两个种群周期性跌至极低数目、面临灭绝风险的大振荡。与 Lotka–Volterra 的中性循环不同，**极限环**有特征的振幅和周期，系统在扰动后回到它，这使它成为自然界有规律循环的更好候选解释。

::: example 富集会摧毁这一系统的稳定性吗 {#ex-rm}
在上图的缩放模型中（$r = a = h = 1$，$b = 0.5$，$m = 0.2$），求 $N^*$ 以及平衡稳定时最大的 $K$。
::: solution
由 [[#eq-rm-nstar]]，$N^* = 0.2/(1\times(0.5 - 0.2\times1)) = 0.2/0.3 = 0.667$。猎物等斜线的驼峰在 $N = \tfrac12(K - 1/(ah)) = (K - 1)/2$ 处达峰。稳定要求 $N^*$ 在峰的右侧：$0.667 > (K - 1)/2$，即 $K < 2.33$。$K = 2$ 时 Jacobian 的迹为 $-0.067$（稳定）；$K = 3$ 时迹为 $+0.089$（不稳定，带极限环）。把猎物的环境富集50 %，系统就从稳态切换到循环。
:::
:::

富集悖论在自然界有多常见？恒化器中以藻为食的轮虫之类的实验室系统显示出了营养供应改变时从平衡到循环的预言转变，一些富集的湖泊也表现出更强的浮游生物波动；但许多富集的自然系统并未失稳，大概因为存在不可食的猎物、庇护所、捕食者干扰等简单模型所没有的特征。

## 实验室与野外的捕食者-猎物动力学

### 庇护所与空间

Gause 在1930年代试图用纤毛虫 *Didinium nasutum*（捕食者）与 *Paramecium caudatum*（猎物）产生捕食者-猎物循环。在简单培养中，*Didinium* 吃光了所有 *Paramecium* 然后饿死：双方都灭绝。当沉淀物提供庇护所让部分猎物得以隐藏时，捕食者灭绝而猎物恢复。只有当他间隔加入两个物种的几个个体、模拟迁入时，才得到反复的振荡。

Carl Huffaker（1958）把它发展成了一个关于空间的实验。他用取食橙子的植食性螨 *Eotetranychus sexmaculatus* 和捕食性螨 *Typhlodromus occidentalis*，在橙子与橡皮球的阵列中实验。当供食用的橙子彼此邻近时，捕食者很快找到并消灭猎物。当他给部分橙子涂蜡、用凡士林屏障阻碍捕食者扩散、并提供木柱让猎物（而非捕食者）能借丝线弹射飞离时，系统历经数次振荡而存续：猎物种群先于捕食者拓殖橙子，捕食者找到它们、在局部将其消灭然后移向别处。存续与否取决于系统是一个由动力学异步的局部斑块组成的**集合种群**——这一主题在保护生物学中再次出现（[[conservation-biology/fragmentation]]）。

### 雪鞋兔循环

雪鞋兔（*Lepus americanus*）与加拿大猞猁（*Lynx canadensis*）的十年循环是捕食者-猎物循环的教科书例子，但究竟是谁驱动谁？兔可能因为食物而循环——高密度时它们在冬天过度啃食灌木——也可能因为捕食者，而捕食者中不仅包括猞猁，还有郊狼、猫头鹰和苍鹰。Charles Krebs 及同事1986–1994年在育空地区克卢恩湖用大片有围栏与无围栏的林地检验了这一点，每块约一平方公里，分别排除哺乳动物捕食者、添加食物、或两者兼施，并设对照。排除捕食者与添加食物各自都提高了兔的密度，而两者结合的提高远超任何单一处理。他们的结论（1995）是：循环源于食物与捕食的相互作用，其中捕食是兔死亡的主导直接原因；后来的工作表明，甚至捕食的*风险*也通过母体的应激激素压低兔在下降期的繁殖。猞猁则追随兔而定。因此该循环是嵌入一条三级食物链之中的捕食者-猎物相互作用。

::: warning "捕食者控制其猎物"——以及"猎物的循环必由捕食者引起"
捕食者对其猎物数目的影响常常很小：当捕食者主要取食本也会死亡的个体——病弱的、饥饿的、或没有领地的多余幼体——捕食是**补偿性的**，移走捕食者变化不大。而循环可以由其他机制造成：食物（植物-植食者相互作用）、寄生虫、一个物种内部的滞后密度依赖（[[ecology/population-growth]]）、或母体效应。捕食者是否调节某一特定的猎物种群，是一个要靠移除或排除实验来回答的经验问题，正如克卢恩的工作所做的那样。
:::

## 植食

植食动物吃植物，而植物与动物猎物相比，在改变动力学的方面有所不同。植物很少被啃食者杀死；它失去部分组织，往往能靠分生组织和贮藏物质再生而**补偿**，因此给定的植食量对植物适合度的影响可以从严重到可忽略。植物也有化学和物理防御——坚硬的细胞壁、低氮含量、刺和毛、以及生物碱、单宁和氰苷等次生化合物——而且许多防御是**诱导的**，只在遭受攻击后才产生或增多。

因此多数植食动物面对的是量大而质差的食物。这一观察是 Nelson Hairston、Frederick Smith 和 Lawrence Slobodkin（1960）“世界是绿色的”这一论点的根基：植食者被其捕食者而非其食物所抑制；反驳意见是绿色世界的大部分不可口，而证据的权衡在不同生态系统之间有所不同，见 [[ecology/communities]]。

::: application 生物防治
利用天敌防治害虫直接建立在捕食者-猎物理论之上。一个著名的早期成功是澳洲瓢虫（*Novius cardinalis*，长期被称为 *Rodolia cardinalis*，1888–1889年自澳大利亚引入）对吹绵蚧（*Icerya purchasi*）的防治：这种澳大利亚昆虫一度毁灭加利福尼亚的柑橘园；几年之内吹绵蚧就被压到很低的数目，并大体保持至今。好的防治天敌往往是专食性的，搜索效率高、数值反应迅速，能够把害虫维持在低而稳定的密度——理论提示这需要攻击聚集或空间结构之类的特征，如 Huffaker 的螨类实验。生物防治也有风险：引入的广食性捕食者，如澳大利亚的甘蔗蟾蜍和夏威夷及加勒比地区的獴，伤害了本地物种，因此现代项目在释放前会检验寄主专一性。
:::

## 寄生虫与病原体

寄生虫是地球上数目最多的消费者；多数自由生活的物种都携有好几种寄生虫。它们的动力学用追踪处于不同感染状态的宿主、而非追踪寄生虫数目的模型来描述。

### 基本繁殖数

::: definition 基本繁殖数 {#def-r0}
对一种微型寄生虫，**基本繁殖数** $R_0$ 是一个受感染的宿主被引入其余宿主全部易感的种群后所引起的平均新感染数。只有当 $R_0 > 1$ 时，感染才能在种群中扩散。
:::

$R_0$ 是 [[ecology/population-growth#prop-r0]] 净生殖率在流行病学中的对应物：那里计算的是个体一生中的后代数，这里计算的是感染在其传染期内引起的感染数。注意它不是病原体独有的属性：它取决于宿主种群——其密度、其接触格局及其免疫状态。

经典模型由 William Kermack 和 Anderson McKendrick 于1927年建立，把宿主种群分为**易感**（$S$）、**感染且有传染性**（$I$）与**康复且免疫**（$R$）三类。

::: proposition SIR 模型 {#prop-sir}
在流行病期间没有出生与死亡的闭锁宿主种群中，设 $\beta$ 为传播率（每易感-感染对每单位时间，$S$、$I$、$R$ 取种群的分数）而 $\gamma$ 为康复率，于是 $1/\gamma$ 是平均传染期。则

$$
\frac{dS}{dt} = -\beta SI, \qquad \frac{dI}{dt} = \beta SI - \gamma I, \qquad \frac{dR}{dt} = \gamma I ,
$$ {#eq-sir}

并且

$$
R_0 = \frac{\beta}{\gamma}.
$$ {#eq-sir-r0}

只有当 $R_0 S > 1$ 时流行病才增长；感染数在易感分数降至 $S = 1/R_0$ 时达峰。若种群中至少有以下比例

$$
p_c = 1 - \frac{1}{R_0}
$$ {#eq-herd}

具有免疫力，则传入的感染无法扩散。假设：充分混合的种群、恒定的比率、康复后终身免疫、无潜伏期。
:::

::: proof
完全易感种群（$S \approx 1$）中的一个感染宿主以速率 $\beta$ 传染他人，平均持续 $1/\gamma$ 时间，故 $R_0 = \beta/\gamma$。由第二个方程 $dI/dt = \gamma I(R_0S - 1)$，当 $R_0S > 1$ 时为正，当 $S = 1/R_0$ 时为零；由于 $S$ 只减不增，$I$ 在 $S$ 越过 $1/R_0$ 时达峰。若感染传入前已有比例 $p$ 免疫，则 $S \le 1 - p$，当 $R_0(1 - p) < 1$、即 $p > 1 - 1/R_0$ 时感染无法增长。
:::

::: example 宿主种群中的流行病 {#ex-sir}
一种野生啮齿动物的病原体平均传染期为10天（$\gamma = 0.1$ 每天），$\beta = 0.3$ 每天。求 $R_0$、流行病高峰时的易感分数、以及为防止扩散种群中必须免疫的比例。
::: solution
$R_0 = 0.3/0.1 = 3$。流行病在 $S = 1/3$ 时达峰。临界免疫比例为 $p_c = 1 - 1/3 = 2/3 \approx 67$ %。数值解（见下）显示，从0.1 %感染出发，约30 %的种群在疫情高峰（约第38天）时被感染，而在疫情燃尽之前总感染约94 %——超过67 %的阈值，因为疫情会越过其停止增长之点。
:::
:::

```python
beta, gamma = 0.3, 0.1        # transmission and recovery rates (per day)
S, I, R = 0.999, 0.001, 0.0   # fractions of a host population
dt, peak = 0.1, (0.0, 0.0)    # time step (days); (time, size) of epidemic peak

for step in range(int(300 / dt)):          # 300 days, Euler steps
    new_inf = beta * S * I * dt
    new_rec = gamma * I * dt
    S, I, R = S - new_inf, I + new_inf - new_rec, R + new_rec
    if I > peak[1]:
        peak = (step * dt, I)

print(f"R0 = {beta / gamma:.1f}")
print(f"peak: {peak[1]:.3f} infected at day {peak[0]:.0f}")
print(f"never infected: {S:.3f}, infected overall: {R + I:.3f}")
# R0 = 3.0
# peak: 0.302 infected at day 38
# never infected: 0.059, infected overall: 0.941
```

若传播取决于感染宿主的*密度*而非其比例，则 $R_0 = \beta' N/\gamma$ 随宿主密度 $N$ 增长，于是存在**宿主密度阈值** $N_T = \gamma/\beta'$，低于它病原体无法存续。这就是通过扑杀控制野生动物疫病的理论基础；尽管实践中扑杀可能扰乱社会结构、增加群间接触，反而适得其反，人们对英国獾与牛结核病曾如此论证。这些模型的人类应用——疫苗接种规划与人类疾病的流行病学——属于流行病学，在 [医学图谱](/learn/medicine/) 中讨论。

::: quiz
在充分混合的宿主种群中，对一种 $R_0 = 4$ 的病原体，为防止流行病必须免疫的最小比例是多少？
- [ ] 25 %
- [ ] 50 %
- [x] 75 %
- [ ] 100 %
::: solution
由 [[#eq-herd]]，$p_c = 1 - 1/R_0 = 1 - 1/4 = 0.75$。免疫达75 %时，每次感染平均引起 $4\times0.25 = 1$ 次新感染，故感染无法增长；超过该比例，感染便消失。
:::
:::

### 寄生虫能调节其宿主吗？

以密度依赖方式降低宿主存活或繁殖的寄生虫能调节宿主种群、甚至驱动循环，Roy Anderson 和 Robert May 在1978年起的一系列论文中论证了这一点。一个清晰的野外检验涉及不列颠荒原上的红松鸡（*Lagopus lagopus scotica*），其数量以约四到八年的周期循环，以及生活在松鸡肠道内、降低其繁殖成功率的一种线虫 *Trichostrongylus tenuis*。Peter Hudson、Andrew Dobson 和 David Newborn（1998）在预计将发生崩溃的年份用驱虫药处理实验种群中的松鸡；受处理的种群没有崩溃，而未处理的对照种群崩溃了，表明寄生虫是那些种群中循环所必需的。

寄生虫还中介其他物种之间的相互作用。分享一个捕食者的两个猎食物种、或分享一种寄生虫的两个宿食物种，可以在不竞争任何资源的情况下相互伤害：一个物种的增加养活了更多捕食者或寄生虫，它们转而攻击另一个物种。Robert Holt 将这种现象命名为**表观竞争**（1977）。[[ecology/competition]] 中提到的一例是灰松鼠携带、使红松鼠受害的松鼠痘病毒。

::: history
Lotka 的 *Elements of Physical Biology*（1925）和 Volterra 对亚得里亚海渔获的分析（1926）引入了捕食者-猎物方程；Alexander Nicholson 和 Victor Bailey 针对昆虫宿主与拟寄生者的离散时间模型（1935）表明这类相互作用倾向于产生振幅增长的振荡。Gause 的原虫实验（1934–1935）与 Huffaker 的螨类实验（1958）显示了庇护所和空间结构的作用。Holling 的功能反应（1959）与 Rosenzweig 和 MacArthur 的图解分析（1963）使捕食者-猎物理论转向现实的机制，Rosenzweig 的富集悖论随后于1971年提出。Kermack 和 McKendrick 的 SIR 模型（1927）创建了数学流行病学，Anderson 和 May 自1970年代末起将其与生态学连接起来。长期的野外实验——Krebs 在克卢恩的兔研究（1986–1994）与 Hudson 的松鸡研究（发表于1998年）——检验了实际驱动循环的是哪些机制。
:::

## 由此引向何处

消费者-资源相互作用把物种联结成**食物网**，而捕食者的效应可以级联传递若干营养级——这是 [[ecology/communities]] 的主题，该书还处理相互作用的第三大类，互利共生。通过消费者的能量流动在 [[ecology/ecosystem-energetics]] 中定量。捕食与寄生的进化侧面——军备竞赛、红皇后、以及毒力的进化——在 [[evolution/coevolution]]。

::: summary
- 消费者包括**真捕食者**、**啃食者**、**拟寄生者**与**寄生虫**（微型与大型）（[[#def-consumers]]）。
- **Lotka–Volterra** 捕食者-猎物模型（[[#prop-lvpp]]）的平衡为 $N^* = m/(ba)$、$P^* = r/a$，中性循环周期约为 $2\pi/\sqrt{rm}$；富集猎物增加的是捕食者而非猎物；无差别的死亡率有利于猎物（Volterra 原理）。中性循环在结构上不稳定。
- **功能反应**（[[#def-responses]]）分为 I、II、III 型。Holling 的圆盘方程 $f(N) = aN/(1 + ahN)$（[[#prop-holling]])在 $1/h$ 处饱和；II 型是失稳的，III 型在低密度时是稳定的。
- 在 **Rosenzweig–MacArthur** 模型（[[#prop-rm]]）中，当捕食者等斜线切过猎物驼峰的下降侧时平衡稳定；富集能产生**极限环**（富集悖论）。
- 实验显示了庇护所与空间结构的重要性（Gause、Huffaker），以及兔循环源于食物与捕食的共同作用（克卢恩）。
- 植食动物很少杀死植物；植物会补偿并防御自身。
- 对病原体，SIR 模型中 $R_0 = \beta/\gamma$（[[#prop-sir]]）；感染只在 $R_0 > 1$ 时扩散，在 $S = 1/R_0$ 时达峰，并在 $1 - 1/R_0$ 的比例免疫时被阻止。寄生虫能调节宿主（红松鸡）并引起**表观竞争**。
:::

::: exercise 捕食者-猎物的平衡 {level=1 check="250"}
在 Lotka–Volterra 模型中，猎物有 $r = 0.5$ 每年，捕食者有 $a = 0.002$、$b = 0.4$、$m = 0.2$ 每年。求猎物平衡 $N^*$。
::: solution
$N^* = m/(ba) = 0.2/(0.4\times0.002) = 0.2/0.0008 = 250$。

::: exercise 最大摄食率 {level=1 check="12"}
一只苍鹭捕获每条鱼后平均需要5分钟处理。按 Holling 圆盘方程，它每小时最多吃多少条鱼？
::: solution
最大值为 $1/h = 1/(5\ \text{min}) = 12$，即每小时12条鱼。
:::

::: exercise 群体免疫阈值 {level=1 check="0.8"}
一种野生动物病原体有 $R_0 = 5$。为防止暴发，种群中必须免疫的比例是多少？
::: solution
$p_c = 1 - 1/5 = 0.8$。
:::

::: exercise 振荡周期 {level=1 check="2*pi/sqrt(0.25)"}
对 $r = 0.5$、$m = 0.5$ 每年的 Lotka–Volterra 模型，小振荡的近似周期是多少年？
::: solution
$2\pi/\sqrt{rm} = 2\pi/\sqrt{0.25} = 2\pi/0.5 = 12.6$年。

::: exercise 由数据推断功能反应 {level=2}
在一次实验室实验中，被提供不同密度蚊幼虫的捕食性蝽在24小时内吃掉的数目如下：密度为每容器5只时吃4只，20时吃11只，50时吃15只，100时吃17只。(a) 这是哪一类功能反应？(b) 从数据粗略估计处理时间。(c) 变形 [[#eq-holling]]，证明 $1/f$ 是 $1/N$ 的线性函数，并说明如何用它估计 $a$ 和 $h$。
::: solution
(a) II 型：摄食量以减速的速率上升并似乎趋于平顶。

(b) 摄食量趋近的最大值略高于每24小时17只，或许是20，故 $h \approx 24/20 = 1.2$，即每只幼虫1.2小时（粗略估计；渐近线尚未达到）。

(c) 取倒数，$\dfrac{1}{f} = \dfrac{1 + ahN}{aN} = \dfrac{1}{a}\cdot\dfrac1N + h$。$1/f$ 对 $1/N$ 的图是一条直线，斜率为 $1/a$、截距为 $h$。（这与酶的 Lineweaver–Burk 图是同一种变换，也有同样的弱点：它给低密度处噪声大的测量以很大权重。用非线性最小二乘直接拟合曲线更好；而且因为试验期间猎物被消耗，常用一种称为 Rogers 随机捕食者方程的校正。）
:::
:::

::: exercise Volterra 原理 {level=2}
在 Lotka–Volterra 模型中，设渔场每年按相同比例 $F$ 移除猎物和捕食者。证明平衡变为 $N^* = (m + F)/(ba)$、$P^* = (r - F)/a$，并结合 D'Ancona 的观察与杀虫剂的使用加以解释。
::: solution
方程变为 $dN/dt = (r - F)N - aNP$、$dP/dt = baNP - (m + F)P$，故模型形式不变，只是 $r \to r - F$、$m \to m + F$。平衡为 $N^* = (m + F)/(ba)$（比未捕捞时高）与 $P^* = (r - F)/a$（更低）。按数量比例杀死两类的捕捞把群落推向猎物；战争期间捕捞减少，平衡便推向捕食性鱼类，正如 D'Ancona 所见。同时杀死害虫与其捕食者的杀虫剂同样抬高害虫的平衡、压低其捕食者的——害虫可能在喷药后再度暴发。
:::
:::

::: exercise 平衡稳定吗 {level=2}
在 $a = 0.5$、$h = 0.4$、$b = 0.3$、$m = 0.06$ 的 Rosenzweig–MacArthur 模型中（每单位时间；猎物与捕食者用相同单位），求 $N^*$。容纳量 $K$ 在哪些范围内平衡稳定，在哪些范围内捕食者根本无法存续？
::: solution
$N^* = m/(a(b - mh)) = 0.06/(0.5\times(0.3 - 0.024)) = 0.06/0.138 = 0.435$。猎物驼峰在 $\tfrac12(K - 1/(ah)) = \tfrac12(K - 5)$ 处达峰。稳定要求 $0.435 > (K - 5)/2$，即 $K < 5.87$。捕食者存续仅当平衡落在猎物的范围之内，即 $N^* < K$，故 $K > 0.435$。$0.435 < K < 5.87$ 时平衡稳定；$K > 5.87$ 时为极限环；$K < 0.435$ 时捕食者灭绝。
:::

::: exercise 宿主密度阈值 {level=2 check="40"}
一种鹿的病原体具有密度依赖传播：在密度为 $N$（每平方公里鹿数）且几乎全部易感的种群中，每头受感染的鹿每天以 $\beta'N$ 的速率传染其他个体，其中 $\beta' = 0.005$ 每头鹿每天平方公里。感染平均持续5天。鹿的密度（每平方公里）低于多少时病原体无法存续？
::: solution
$\gamma = 1/5 = 0.2$ 每天，$R_0 = \beta'N/\gamma$。阈值为 $R_0 = 1$：$N_T = \gamma/\beta' = 0.2/0.005 = 40$，即每平方公里40头鹿。
:::

::: exercise 解读寄生虫去除实验 {level=3}
在 Hudson 的松鸡实验中，用驱虫药处理的种群没有崩溃，而对照种群崩溃了。(a) 为什么在*预计*会崩溃时处理松鸡、并设未处理的对照很重要？(b) 这一结果是否说明寄生虫是全部红松鸡种群循环的原因？(c) 设想一种机制，说明降低繁殖成功率的寄生虫如何能产生循环而非稳定的调节。
::: solution
(a) 在预计崩溃之时处理，检验的是寄生虫导致崩溃这一特定预言；同时受监测的对照表明否则崩溃本会发生（即当年条件并非异常有利），于是差异可归因于处理。

(b) 不是。它只说明寄生虫是那些受处理种群崩溃所必需的。其他松鸡种群，例如寄生虫传播较低的地区、或捕食者与领域行为占主导的种群，可能因其他原因循环，或根本不循环。

(c) 寄生虫负荷随时间滞后累积：松鸡繁盛时，感染性幼虫在荒原上累积， 蠕虫负荷峰值在一年或更久之后出现，在松鸡种群可能已经在下降时才压低其繁殖。这种滞后的密度依赖效应产生振荡，如同 [[ecology/population-growth#eq-delay]] 的延迟逻辑斯谛。
:::

::: exercise 表观竞争 {level=3}
两种蚜虫生活在不同植物上，故不共享食物，但被同一种广食性拟寄生者攻击。第二种蚜虫拓殖该地区之前，第一种很常见。(a) 用 Lotka–Volterra 捕食者-猎物的平衡，解释第二种蚜虫的到来为何可能使第一种减少。(b) 如何用实验检验这种减少是否源于表观竞争？
::: solution
(a) 在 Lotka–Volterra 模型中猎物平衡由捕食者决定：$N^*$ 是捕食者恰好能自我替补时的猎物密度。有了两种猎物，捕食者由两者共同养活；第二种蚜虫供养了更多拟寄生者，抬高了捕食者密度，后者随后更猛烈地攻击第一种蚜虫。共享天敌时，平衡需求较低的猎物种群能把另一个压下去——这是天敌中介的 $R^*$ 规则类比，有时称为 $P^*$ 规则。

(b) 移除第二种蚜虫（或在某些样方中将其排除），比较拟寄生者密度与第一种蚜虫的存活和种群增长同对照样方的差异；或者在有、无第二种蚜虫的地区分别用笼网在某些样方中排除拟寄生者。若第二种蚜虫只在拟寄生者存在时才伤害第一种，该效应便是表观竞争。
:::
