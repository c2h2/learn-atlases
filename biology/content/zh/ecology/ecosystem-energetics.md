Raymond Lindeman 在1936至1938年间研究明尼苏达州的雪松沼泽湖（Cedar Bog Lake）——一个正被泥炭填满的小而浅的湖。他没有列出湖中的物种，而是追问：以阳光形式被其植物与藻类捕获而进入湖中的能量有多少，其中有多少传给了取食它们的动物，多少传给了取食那些动物的动物，又有多少沿途损失。他的论文 “The trophic-dynamic aspect of ecology” 在他27岁逝世之后的1942年发表，把整个生态系统当作一台转化能量的机器，并表明沿食物链每上一级，大部分能量便告消失。

本章采取 Lindeman 的观点。**生态系统**——Arthur Tansley 于1935年引入的术语——是一个群落连同其物理环境，被视作一个能量流经、物质循环的单一系统。我们将定义初级生产量及其限制因子——从陆地上的阳光与水到海洋中的养分与铁；追踪能量进入消费者与分解者；推导营养级之间的传递效率；并解释为什么这一效率限制了食物链的长度和一个生态系统能承载的顶级捕食者数量。我们要测量其能量流动的食物网已在 [[ecology/communities]] 中介绍，光合作用与呼吸作用的生物化学见 [[plant-biology/photosynthesis]] 与 [[biochemistry/bioenergetics]]。物质循环作为生态系统生态学的另一半，是 [[ecology/nutrient-cycles]] 的主题。

## 能量流动，物质循环

生态系统中几乎所有的能量都以阳光的形式进入，经光合作用被固定为有机化合物的化学能，随生物相互取食而在生物之间传递，并以热的形式离开——每一步都由呼吸释放。能量不能被循环利用：由热力学第二定律，每次转化都会把一部分降级为热，而生物无法用热来做功。因此生态系统需要持续的能量输入。相比之下，化学元素——碳、氮、磷——从环境中被摄取，沿同样的食物链传递，再由分解作用返回环境，供再次利用。**能量流动；物质循环。**

例外颇有启发。深海热液喷口生态系统——1977年在加拉帕戈斯裂谷发现——靠的不是阳光而是**化能合成**：细菌与古菌氧化喷口流体中的硫化氢、甲烷或氢，利用这些能量固定二氧化碳，养活了由管虫、蛤与虾组成的稠密群落。但即便在那里，细菌氧化硫化物所用的氧最终也来自表层的光合作用。

::: warning "生态系统中的能量是被循环利用的"
养分被循环利用，能量则不然。当分解者分解一片落叶时，它释放出氮与磷供植物再次利用，但叶中有机化合物的能量被分解者用掉并以热的形式散失。没有任何生物能利用那份热来建造生物量。因此每个生态系统都依赖来自外部的持续能量供应——阳光，或喷口流体的化学能——却可以在同一批原子上无限运转。
:::

## 初级生产量

::: definition 初级生产量 {#def-production}
**总初级生产量**（GPP）是一个生态系统中自养生物以光合作用或化能合成固定碳（或能量）的速率。其中一部分被自养生物自身用于呼吸（$R_a$，**自养呼吸**）。余下的部分

$$
\text{NPP} = \text{GPP} - R_a ,
$$ {#eq-npp}

是**净初级生产量**，即新的植物生物量产生的速率，是其他所有生物可利用的能量。**净生态系统生产量**是 NPP 减去异养生物的呼吸 $R_h$（消费者与分解者）：

$$
\text{NEP} = \text{NPP} - R_h = \text{GPP} - R_a - R_h ;
$$ {#eq-nep}

当生态系统在积累有机质（碳汇）时它为正，在损失有机质（碳源）时为负。生产量是一个*速率*，以单位面积单位时间表示 ——g C m⁻² yr⁻¹、g 干物质 m⁻² yr⁻¹ 或 kJ m⁻² yr⁻¹—— 并且必须与**现存生物量**（某一时刻存在的量，g m⁻²）区分开。
:::

GPP 大约有一半被植物自身呼吸掉；在拥有巨量现存生物量需要维持的热带森林中，这一比例略高，而在某些作物中略低。生产量（流量）与生物量（存量）之别处处要紧。一片温带森林每平方米的生物量达数十千克干物质，而 NPP 每年每平方米只有约一千克；开阔大洋的浮游植物现存生物量微乎其微，但每年生产出自身生物量的许多倍，因为每个细胞大约每天分裂一次，且几乎一产生就被吃掉。生产量与生物量之比是生物量平均**周转时间**的倒数。

### 有多少，分布在何处

结合卫星对海洋水色与陆地植被绿度的测量与模型的估计把全球 NPP 定为每年约105 Pg C（1 Pg = 10¹⁵ g），陆地（约56 Pg C）与海洋（约49 Pg C）几乎平分——依据是 Christopher Field 及同事（1998）被广泛引用的一项分析。海洋以不足地球植物生物量1 %的浮游植物实现了这一点，因为浮游植物周转极快。

按单位面积计，生产量在不同生态系统之间差异巨大。下表是 Robert Whittaker 于1975年汇编的 NPP 近似均值，单位为 g 干物质 m⁻² yr⁻¹；数值粗略，较新的估计在细节上有所不同，但排序经受了时间考验：

| 生态系统 | NPP（g 干物质 m⁻² yr⁻¹） |
|---|---|
| 藻床与礁 | 2500 |
| 热带雨林 | 2200 |
| 河口 | 1500 |
| 温带落叶林 | 1200 |
| 北方森林 | 800 |
| 耕地 | 650 |
| 温带草原 | 600 |
| 大陆架 | 360 |
| 冻原与高山 | 140 |

| 荒漠与半荒漠灌丛 | 90 |

开阔大洋是单位面积生产量最低的生态系统之一——一片「荒漠」——但由于它覆盖地球约三分之二的面积，其总生产量非常可观。

### 什么限制初级生产量

在陆地上，NPP 主要受**水**与**温度**限制——通过生长季的长短与光合速率起作用——其次受**养分**、尤其是氮与磷的限制。就全球而言，NPP 与实际蒸散量密切相关——实际蒸散量是从土壤蒸发并经植物蒸腾散失的水量，它综合了水分供应与可用于蒸发的能量——正如 Michael Rosenzweig 于1968年所示。在一个区域内，NPP 常随年降水近乎线性上升，草原与荒漠尤甚。

::: example 草地中的降水利用效率 {#ex-rain}
沿一条降水梯度在七个草地样地测定了地上 NPP：

| 年平均降水量（mm） | 200 | 300 | 400 | 500 | 600 | 700 | 800 |
|---|---|---|---|---|---|---|---|
| 地上 NPP（g m⁻² yr⁻¹） | 90 | 140 | 170 | 240 | 260 | 330 | 350 |

估计每毫米降水带来的生产量增量，并预测年降水450 mm 处的样地的 NPP。
::: solution
最小二乘回归给出 $\text{ANPP} = 2.5 + 0.446\times\text{MAP}$，$R^2 = 0.99$。年降水每增加一毫米，地上生产量约增加0.45 g m⁻²，即这些草地的**降水利用效率**。在450 mm 处，预测值为 $2.5 + 0.446\times450 = 203$ g m⁻² yr⁻¹。（外推到极湿的样地并不明智，因为养分、光、温度等其他因素会转而成为限制。）
:::
:::

在海洋中，在**真光层**（通常为上部50–200 m）以下，光限制生产量，而在其内限制生产量的是养分。由于有机颗粒下沉，养分被带出表层水并在深层再生；因此，在深层水被带到表层之处——大陆西岸外的**上升流**区、南极周围、以及接受河流输入养分的近岸水域——生产量最高，而在永久分层的中央环流中最低。氮是海洋中最常见的限制养分，但在一些大片区域（南大洋、赤道与亚北极太平洋），硝酸盐丰富而浮游植物稀少。John Martin 在1980年代末提出，这些**高营养盐-低叶绿素**区域受**铁**限制，因为铁是光合作用与氮同化所需酶的组分，且主要由风成粉尘输入。自1993年起的一系列开阔大洋铁添加实验，始于赤道太平洋的 IronEx I，都引发了浮游植物水华，证实了铁限制。

### 光合效率

植物把阳光转化为生物量的效率有多高？只有约45 %的太阳辐射处于光合有效波段（400–700 nm），其中并非全部被吸收，而碳固定、光呼吸与植物呼吸的光化学与生物化学过程又各分走一份。

::: example 作物的效率 {#ex-efficiency}
一块麦田一年接受1800 MJ m⁻² 的光合有效辐射，并产生每平方米1500 g 干物质的总 NPP（地上部与根）。按植物干物质的能量含量为18 kJ g⁻¹，入射 PAR 的百分之多少储存在 NPP 中？
::: solution
NPP 中的能量为 $1500\times18 = 27\,000$ kJ $= 27$ MJ m⁻²。效率为 $27/1800 = 0.015$，即入射 PAR 的1.5 %——占总太阳辐射的比例约为此值的一半。施肥充足、水分适宜的作物是效率最高的生态系统之一；在全球平均，由于干旱、寒冷季节、养分不足与冠层不完全闭合，自然植被储存的太阳能远低于其接收量的1 %。
:::
:::

### 生产量的测定

在陆地上，NPP 可通过收获一年产生的生物量来估计（根系难以做到，一年中被植食者取食和凋落损失的部分也难以做到），可通过跟踪树木茎的生长，或用**涡度相关**塔测定生态系统与大气间的 CO₂ 交换——这类塔根据冠层之上风与 CO₂ 浓度的湍流波动连续测量净生态系统交换；全世界已运行了数百个这样的站点，通过 FLUXNET 等网络协调。在水中，生产量通过放射性或稳定同位素标记碳的吸收、或明瓶与暗瓶中氧的变化来测定。在全球尺度上，卫星依据红光与近红外波段的反射率测定绿色植被吸收的光的比例（归一化植被指数，NDVI），并依据海洋水色测定表层水的叶绿素浓度，再由模型把它们转化为 NPP 的估计。

## 次级生产量与能量的去向

异养生物——消费者与分解者——利用初级生产者固定的能量。它们产生新生物量即**次级生产量**。要追踪能量流经一个消费者的去向，就要列出它的能量收支。

::: definition 消费者的能量收支 {#def-budget}
动物**消耗**的能量（$C$）中，一部分未被肠道吸收、随粪便以**排出**能量 $F$ 的形式损失。其余部分被**同化**，$A = C - F$（严格地说，其中一部分随后又随尿以含氮废物的形式损失，这里忽略不计）。同化的能量要么用于**呼吸** $R$——维持、活动，以及内温动物的产热——要么用于**生产** $P$ 新组织、配子与后代：

$$
C = F + A, \qquad A = R + P .
$$ {#eq-budget}

由这些流量可定义三种效率：**同化效率** $A/C$、**生产效率**（净生长效率）$P/A$ 与**总生长效率** $P/C$。
:::

这些效率在不同动物与不同食物之间有系统差异。**同化效率**取决于食物品质：取食动物组织的肉食动物约同化其食物的80 %，取食种子与幼叶的植食动物为50–80 %，而取食成熟叶、草或木质者常仅20–50 %，因为纤维素与木质素难以消化，大量食物未经同化随粪便排出。**生产效率**主要取决于代谢：内温动物（鸟类与哺乳类）把同化的大部分能量用于维持体温，只有百分之几转化为新组织；而外温动物，尤其是无脊椎动物，能把百分之几十转化为生产量。体面积对体积比高的小型内温动物的生产效率是所有动物中最低的。

::: example 毛虫与田鼠的能量收支 {#ex-budget}
一条毛虫吃下含200 J 的叶，排出含120 J 的粪，呼吸50 J；一只田鼠吃下含200 J 的种子，排出60 J，呼吸136 J。计算两者的同化效率、生产效率与总生长效率。
::: solution
毛虫：$A = 200 - 120 = 80$ J，故 $A/C = 40$ %；$P = 80 - 50 = 30$ J，故 $P/A = 37.5$ %、$P/C = 15$ %。

田鼠：$A = 200 - 60 = 140$ J，故 $A/C = 70$ %；$P = 140 - 136 = 4$ J，故 $P/A = 2.9$ %、$P/C = 2$ %。

田鼠对食物的消化远好于毛虫，但同化量中变成新组织的却少得多，因为它几乎把全部同化能都花在维持体温与活动上。按每克食物计，外温动物产生的生物量是它的七倍。
:::
:::

### 营养级之间的传递

一个营养级的生产量并非全部被下一级吃掉：有些未被取食便死去，流向分解者。把这一点与消费者的各种效率结合，便得到整个传递的效率。

::: proposition 营养传递效率 {#prop-te}
设 $P_n$ 为第 $n$ 营养级的生产量。定义**消费效率** $\text{CE} = I_{n+1}/P_n$，即第 $n$ 级的生产量中被第 $n+1$ 级摄入的比例；**同化效率** $\text{AE} = A_{n+1}/I_{n+1}$；以及**生产效率** $\text{PE} = P_{n+1}/A_{n+1}$。于是**营养传递效率**——一级的生产量中变为下一级生产量的比例——为

$$
\text{TE} = \frac{P_{n+1}}{P_n} = \text{CE}\times\text{AE}\times\text{PE}.
$$ {#eq-te}

若每一步的传递效率都相同、均为 $\text{TE}$，则第 $n$ 营养级（初级生产者位于第1级）的生产量为

$$
P_n = P_1\,\text{TE}^{\,n-1}.
$$ {#eq-pyramid}
:::

::: proof
三个比值逐项相消：$\dfrac{I_{n+1}}{P_n}\cdot\dfrac{A_{n+1}}{I_{n+1}}\cdot\dfrac{P_{n+1}}{A_{n+1}} = \dfrac{P_{n+1}}{P_n}$。从 $k = 1$ 到 $k = n - 1$ 反复应用 $P_{k+1} = \text{TE}\,P_k$ 即得 [[#eq-pyramid]]。
:::

实践中 TE 有多大？Lindeman 的估计与许多后来的估计常被概括为“10 %法则”，Daniel Pauly 与 Villy Christensen（1995）对水生食物网模型的汇编发现平均传递效率约为10 %，尽管各系统之间离散很大。这条法则是**经验性概括**、并非定律：传递效率的范围从低于1 %（例如从草原植物到大型哺乳动物植食者，它们只吃掉植物生产量的一小部分）直到某些由取食易消化猎物的外温动物主导的水生食物链中的20 %以上。

caption: 第 $n$ 营养级的生产量（kJ m⁻² yr⁻¹），设生产者的生产量为 $P_1$、每次传递的效率为 TE，$P_n = P_1\,\mathrm{TE}^{\,n-1}$。标记的点对应 TE = 10 %：第1级为10 000，植食动物为1000，肉食动物为100，顶级肉食动物为10。把 TE 提高到20 %，看看到达第4级的能量多了多少——多了八倍。即便如此，曲线仍表明第四、五级之外所剩无几。
:::

::: example 能有多少顶级捕食者？ {#ex-pyramid}
某湖泊浮游植物的净生产量为10 000 kJ m⁻² yr⁻¹。各级传递效率均为 $\text{CE} = 0.5$、$\text{AE} = 0.6$、$\text{PE} = 0.3$。第4营养级的食鱼鱼类可利用的生产量有多少？一条狗鱼每年约需2000 kJ 的猎物生产量才能维持；10公顷的湖水能养活多少条狗鱼？
::: solution
由 [[#eq-te]]，$\text{TE} = 0.5\times0.6\times0.3 = 0.09$。由 [[#eq-pyramid]]，$P_4 = 10\,000\times0.09^3 = 7.29$ kJ m⁻² yr⁻¹—— 不足初级生产量的0.1 %。第4级的鱼是狗鱼的猎物，故狗鱼（第5级）将由这部分生产量维持：10 ha 即 $10^5$ m²，猎物生产量为 $7.29\times10^5$ kJ yr⁻¹，约可维持 $7.29\times10^5/2000 \approx 360$ 条狗鱼——实际上会更少，因为狗鱼无法捕获猎物的全部生产量，还必须与其他捕食者及分解者分享。
:::
:::

### 食物链为何很短

[[#eq-pyramid]] 表明能量沿食物链呈几何级数衰减。TE = 10 %时，第4级获得初级生产量的0.1 %，第6级只有0.001 %。Charles Elton（1927）据此论证，这解释了食物链为何简短、大型捕食者为何稀少、以及生物的数量或生物量为何通常形成逐级递减的**金字塔**。**能量假说**预言，越高产的生态系统中食物链应越长。

证据并不一致。在某些类群的生态系统中，例如湖泊，食物链长度随**生态系统大小**（湖泊的体积）增加的幅度大于随生产力的幅度，正如 David Post 及同事于2000年所报道的，这也许是因为大型生态系统能维持更大、更稳定的顶级捕食者种群和更多样的生境。在积水树洞等可操纵生产力的小容器中进行的实验表明，生产力主要在低端起作用——极其贫瘠的生境只能支撑较少的营养级。干扰也可能缩短食物链，因为顶级捕食者恢复缓慢。食物链长度很可能由能量、生态系统大小、干扰以及捕食者吃掉猎物所需的体型共同决定。

### 生态金字塔

由 [[#prop-te]]，能量流（生产量）金字塔总是正置的。**数量**金字塔则未必：一棵栎树能养活数千条毛虫。**生物量**金字塔在陆地上通常正置，但在开阔大洋中常常**倒置**：浮游动物的现存生物量超过其所食浮游植物的。这之所以可能，是因为浮游植物周转极快——浮游动物每天吃掉的大约就是当天新长出来的——而浮游动物寿命更长、会积累生物量。只要记住生产量（速率）与生物量（存量）的区别，这一悖论便不复存在。

::: quiz
一个湖中，浮游动物的生物量大于其所食浮游植物的生物量。哪种说法解释得最好？
- [ ] 浮游动物的生产效率高于浮游植物
- [ ] 浮游动物必然主要取食浮游植物以外的东西
- [x] 浮游植物的周转时间要短得多，故小的现存生物量能支撑更大的生产量
- [ ] 热力学第二定律不适用于水生生态系统
::: solution
生物量是存量，生产量是速率。浮游植物大致每天分裂一次，且几乎一长出来就被吃掉，因此尽管其年生产量比浮游动物的生产量大许多倍，现存生物量却很小。生产量金字塔仍然正置；倒置的只是生物量金字塔。
:::
:::

## 分解者与碎屑途径

大多数净初级生产量在生物活着时并没有被吃掉。在森林、草原以及许多湖泊与河流中，大部分 NPP 以落叶、死根、木质部和未被取食的藻类的形式死去，进入**碎屑食物链**，由**碎屑食者**（蚯蚓、鼠妇、马陆与许多昆虫幼虫）和**分解者**（真菌与细菌）取食。植食动物及其捕食者的**牧食食物链**通常处理的份额较小，只有在某些系统中才高得多：在开阔大洋中，浮游动物吃掉大部分浮游植物生产量；而在被重度啃食的草原上，大型植食动物能吃掉一半以上的地上生产量。

分解者群落极其多样——一克土壤中含有数千种细菌和数米长的真菌菌丝——其呼吸 $R_h$ 是 [[#eq-nep]] 中从 NPP 减去的主要项。处于平衡的森林中，NEP 长期接近于零：分解释放的 CO₂ 与树木固定的大致相当。NEP 为正的生态系统会积累有机质，如生长的树木、泥炭或沉积物。泥炭地中积水与低温使分解变慢，就这样积累了世界土壤碳的很大一部分；分解的过程及其对温度、湿度与凋落物质量的依赖见 [[ecology/nutrient-cycles]]。

::: intuition 作为经济体的生态系统
把 GPP 想作一个家庭的收入，$R_a$ 是这个家庭自身的开销；剩下的 NPP 就是它的储蓄，是其他所有生物所能借用的全部。消费者与分解者靠这笔储蓄过活，每一环只把没花在自己开销上的部分传给下一环。能量在经济体中顺流而下，每一步都被花掉。只有当总支出 $R_a + R_h$ 小于收入 GPP 时，生态系统才会积累财富——有机质。
:::

## 能量、体型与人类利用

由于代谢率随体重标度，动物的能量收支强烈依赖体型。跨物种看，哺乳类与鸟类的静止代谢率近似按 $M^{3/4}$ 增加（Kleiber 定律；见 [[animal-physiology/energy-metabolism]]）——这是一条其确切幂指数与解释仍有争议的经验规律。一个结果是：单位体质量的小型动物比大型动物需要更多能量，因此同样多的食物能支撑的大型动物总生物量多于小型动物，但个体数要少得多。

::: application 人类对初级生产量的占用与渔业
人类占用了地球初级生产量中很大且不断增长的份额。一项被广泛引用的估计（Helmut Haberl 及同事，2007）把人类对 NPP 的占用——以作物、木材与饲料形式收获的生产量，加上因土地利用用低产系统取代自然植被而损失的生产量——定为2000年陆地潜在 NPP 的约四分之一。剩下的部分支撑所有其他陆生物种。

同样的能量学推理也适用于海洋。Pauly 与 Christensen（1995）利用营养级与10 %的传递效率估计，1990年代初的世界渔业需要约8 %的全球水生初级生产量，而在大多数渔获来自其中的高产的上升流与陆架系统中，这一份额要大得多。沿食物链每低一环，可用的食物约乘以十：一吨金枪鱼这样的顶级捕食者（营养级约4）意味着约一千吨浮游生物生产量的消耗，而一吨鳀鱼（约第3级）约对应一百吨。渔业一直在逐步移除大型捕食者，这一趋势被称为 “fishing down marine food webs”（Pauly 及同事，1998）。对保护的影响见 [[conservation-biology/people-and-policy]]。
:::

生态系统中能量的流动可以用几行代码来追踪，这使探索效率的变化如何逐级传递变得容易：

```python
P1 = 10_000.0                 # net primary production, kJ m^-2 yr^-1
CE, AE, PE = 0.5, 0.6, 0.3    # consumption, assimilation, production efficiencies

P = P1
for level in range(1, 6):     # trophic levels 1 (producers) to 5
    print(f"level {level}: production {P:10.2f} kJ m^-2 yr^-1")
    P *= CE * AE * PE         # transfer efficiency TE = 0.09 per step
# level 1: production   10000.00 kJ m^-2 yr^-1
# level 2: production     900.00 kJ m^-2 yr^-1
# level 3: production      81.00 kJ m^-2 yr^-1
# level 4: production       7.29 kJ m^-2 yr^-1
# level 5: production       0.66 kJ m^-2 yr^-1
```

::: history
食物链与数量金字塔的思想来自 Charles Elton 的 *Animal Ecology*（1927），而*生态系统*一词来自 Arthur Tansley（1935）。Raymond Lindeman 的营养动力学论文（1942）部分在 G. Evelyn Hutchinson 指导下完成，使能量流成为生态系统生态学的组织原则；Howard 与 Eugene Odum 测量了整体生态系统的能量流，包括 Enewetak 环礁的珊瑚礁（1955），Eugene Odum 的教科书 *Fundamentals of Ecology*（1953）推广了这一方法。国际生物学计划（1964–1974）测定了世界各地生态系统的初级生产量，为 Whittaker 的汇编之类的工作提供了数据。1970年代末起，卫星使全球生产量估计成为可能；1990年代起，涡度相关塔站网连续测定生态系统的碳交换。
:::

## 由此引向何处

作为初级生产量固定的碳是全球循环的一部分，该循环联结着生态系统、海洋与大气；限制生产量的氮与磷也一同在 [[ecology/nutrient-cycles]] 中追踪。生产量的地理格局是 [[ecology/biogeography]] 中生物群系分布的基础。个体动物能量利用的生理学见 [[animal-physiology/energy-metabolism]]。

::: summary
- 能量流经生态系统并以热的形式散失；物质循环。几乎所有生态系统都由太阳能驱动；热液喷口则由化能合成驱动。
- **NPP = GPP − $R_a$** 与 **NEP = NPP − $R_h$**（[[#def-production]]）。生产量是速率，生物量是存量；二者之比即周转率。
- 全球 NPP 约105 Pg C yr⁻¹，陆地与海洋大致平分。按单位面积计，礁、沼泽与热带雨林最高产；荒漠与开阔大洋最低产。
- 陆地上，生产量主要受水、温度与养分限制；海洋中受光、氮、磷限制——而在高营养盐-低叶绿素区域还受铁限制。植物只储存入射光的约1 %。
- 消费者的能量收支为 $C = F + A$、$A = R + P$（[[#def-budget]]）；肉食动物同化效率高，内温动物的生产效率低。
- **营养传递效率** $\text{TE} = \text{CE}\times\text{AE}\times\text{PE}$（[[#prop-te]]），常在10 %上下（经验值，变异很大）；生产量按 $P_1\,\text{TE}^{n-1}$ 递减，这有助于解释食物链简短与顶级捕食者稀少。在生产者周转快的地方，生物量金字塔可以倒置。
- 许多生态系统中大多数 NPP 经**碎屑**途径流向分解者。
:::

## 习题

::: exercise 净初级生产量 {level=1 check="900"}
一片森林的总初级生产量为2000 g C m⁻² yr⁻¹，自养呼吸为1100 g C m⁻² yr⁻¹。它的 NPP 是多少？
::: solution
$\text{NPP} = 2000 - 1100 = 900$ g C m⁻² yr⁻¹。
:::
:::

::: exercise 净生态系统生产量 {level=1 check="-50"}
一片泥炭地的 NPP 为300 g C m⁻² yr⁻¹；排水后其异养呼吸为350 g C m⁻² yr⁻¹。它的 NEP 是多少，是碳源还是碳汇？
::: solution
$\text{NEP} = 300 - 350 = -50$ g C m⁻² yr⁻¹：为负，故排水后的泥炭地是碳源，随分解加快把储存的碳释放到大气中。
:::
:::

::: exercise 同化效率 {level=1 check="0.25"}
一只蝗虫吃下含400 J 的草，排出300 J。它的同化效率是多少？
::: solution
$A = 400 - 300 = 100$ J，故 $A/C = 100/400 = 0.25$。
:::
:::

::: exercise 一个营养金字塔 {level=1 check="40"}
初级生产量为40 000 kJ m⁻² yr⁻¹，每级传递效率均为10 %。第4营养级的生产量是多少？
::: solution
$P_4 = 40\,000\times0.1^3 = 40$ kJ m⁻² yr⁻¹。
:::
:::

::: exercise 周转时间 {level=2}
某湖浮游植物的现存生物量为2 g C m⁻²，其 NPP 为400 g C m⁻² yr⁻¹。浮游动物的生物量为5 g C m⁻²，其生产量为40 g C m⁻² yr⁻¹。(a) 计算各自的周转时间。(b) 用文字画出生物量金字塔与生产量金字塔。(c) 解释为什么只有其中一个是倒置的。
::: solution
(a) 周转时间 = 生物量/生产量：浮游植物 $2/400 = 0.005$ yr，约1.8天；浮游动物 $5/40 = 0.125$ yr，约46天。

(b) 生物量：浮游动物（5）高于浮游植物（2）——倒置。生产量：浮游植物（400）高于浮游动物（40）——正置，级间传递为10 %。

(c) 生产量是流量，沿食物链必须递减，因为每一级只能凭从下一级获得的能量生产。生物量是存量：周转快的一级，其存量可以小于取食它的周转慢的一级。
:::
:::

::: exercise 植食者的各种效率 {level=2}
一只鹿每年吃下3000 MJ 植物性物质，排出1200 MJ，并随尿液与甲烷损失150 MJ；它呼吸1600 MJ。(a) 计算其同化效率（把尿液与甲烷损失计入未同化）、生产量与生产效率。(b) 它所在的种群消耗其生活森林 NPP 的5 %。从植物到鹿的传递效率是多少？其余的 NPP 怎么样了？
::: solution
(a) 可供代谢的同化能：$3000 - 1200 - 150 = 1650$ MJ，同化效率为 $1650/3000 = 55$ %。生产量 $1650 - 1600 = 50$ MJ，故 $\text{PE} = 50/1650 = 3.0$ %。

(b) $\text{TE} = \text{CE}\times\text{AE}\times\text{PE} = 0.05\times0.55\times0.030 = 0.00083$，不足0.1 %。大部分 NPP 从未被鹿吃掉：它以凋落物落下或死去，被碎屑食者与分解者消耗，或被昆虫植食者吃掉。大型内温植食动物把森林生产量转化为自身的效率极低。
:::
:::

::: exercise 食物链上吃得更低 {level=2}
在传递效率为10 %时，营养级3上的一吨鱼生产量约需100吨初级生产量。(a) 营养级4.2上的一吨鱼需要多少初级生产量？(b) 若传递效率为15 %，一吨第3级鱼需要多少？(c) 用你的答案解释为什么对渔业所用初级生产量份额的估计并不确定。
::: solution
(a) $1/0.1^{4.2 - 1} = 10^{3.2} = 1585$ 吨。

(b) $1/0.15^{2} = 44.4$ 吨。

(c) 所需初级生产量同时以指数方式依赖于营养级与传递效率：TE 从10 %改为15 %，第3级鱼的需求便减少一半以上，且级别越高效应越大。由于两个量都不确定且因生态系统而异，对渔业所用份额的估计可相差两倍或更多。
:::
:::

::: exercise 铁施肥 {level=3}
在高营养盐-低叶绿素区域进行的铁添加实验引发了浮游植物水华。(a) 这为什么表明初级生产量受铁限制？(b) 有人提议给南大洋施加铁肥以从大气中移除 CO₂。要使之成立，产生的额外有机碳必须发生什么？(c) 给出两个该提议有争议的生态学理由。
::: solution
(a) 这些区域硝酸盐与磷酸盐丰富而浮游植物生物量低。若仅添加铁就能提高生产量，铁必定是限制因子（按 Liebig 最小律的意义；见 [[ecology/organisms-environment]]）。

(b) 要长期从大气移除 CO₂，额外的有机碳必须在被呼吸之前沉入深海（冬季混合深度以下）或进入沉积物。若水华在表层水中被吃掉并呼吸掉，CO₂ 会在数周或数月内返回大气。实验发现，水华碳中只有一部分被输出到深层，其比例不定且通常很小。

(c) 大尺度施肥可能改变浮游植物的物种组成（有利于某些可能具毒性的物种），在额外有机物分解的深层耗尽氧气，并减少处于洋流下游生态系统的可用养分；而且固存了多少碳难以核实。国际公约（《伦敦公约》及其议定书）把海洋施肥限制于正当的科学研究。
:::
:::

::: exercise 食物链长度 {level=3}
有两种假说解释食物链长度：能量假说（生产力越高的生态系统食物链越长）与生态系统大小假说（越大的生态系统食物链越长）。(a) 设计一项能区分两者的湖泊比较研究。(b) 利用 [[#eq-pyramid]] 解释为什么能量假说只预言生产力对食物链长度的弱效应。(c) 生态系统大小为什么重要？
::: solution
(a) 测量食物链长度（例如顶级捕食者的营养位置，可由稳定氮同位素估计，其值每上升一个营养级约增加3–4 ‰），选择使生产力与大小相互独立变化的众多湖泊——包括小而高产的湖与大而低产的湖。然后拟合一个同时含两个预测变量的模型，问哪个解释的变异更多。

(b) 每增加一级都要求前一级的生产量乘以 TE（约0.1）：在生产量不变时多支撑一级，初级生产量须约高十倍。湖泊之间的生产力大约相差一两个数量级，因此能量假说在整个跨度上至多预言一两个额外的级别，而且多出的任何一级都可能被传递效率的变化抵消。

(c) 大型生态系统容纳更大的顶级捕食者种群，不易因偶然事件灭绝；它们包含更多样的生境，允许更多物种与更多级别；而且整体上也更少受干扰。顶级捕食者还需要大面积才能找到足够的猎物，因此小型生态系统可能根本小到不足以支撑它们。
:::
:::
