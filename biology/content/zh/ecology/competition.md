1930年代初，俄国生物学家 Georgii Gause 在装有细菌培养液的试管中培养两种纤毛虫（*Paramecium*）。单独培养时，*P. aurelia* 与 *P. caudatum* 各自沿 [[ecology/population-growth]] 的逻辑斯谛曲线增长并趋于平稳。一起培养时，两者起初都增长，但随后 *P. caudatum* 衰退并消失，每一次都是如此。两个物种并没有打斗，谁也不吃谁。它们吃的是同一种细菌，而 *P. aurelia* 更擅长获取它。

Gause 的试管给出了**竞争**最简单的图景：一种因与他人共享有限资源而使双方都受害的相互作用。本章既处理种内竞争——上一章所研究密度依赖的根源，也处理种间竞争——它引出了生态学最古老的问题之一：如果物种相互竞争，为什么最强的竞争者没有排除掉所有其他物种？我们建立竞争的 Lotka–Volterra 模型，精确找出它何时预言共存；接着看竞争资源的机制性理论；然后转向野外的证据——资源分割、特征置换与移除实验——以及在变化的世界中使竞争者得以共存的机制。资源与条件之别、基础生态位与现实生态位，来自 [[ecology/organisms-environment]]。

## 竞争是什么

::: definition 竞争 {#def-competition}
**竞争**是由对供给有限资源的共同需求引起、并至少使其中一些个体的存活、生长或繁殖降低的个体间相互作用。若个体属于同一物种，竞争是**种内**的；若属于不同物种，则是**种间**的。在**资源竞争**（exploitative competition）中，个体只通过耗竭共享资源发生间接相互作用；在**干扰竞争**中，个体发生直接相互作用，阻止其他个体获得资源——通过攻击、领地行为、覆压或化学抑制。
:::

两种形式常常同时出现。藤壶为浮游生物进行资源竞争，却为空间进行干扰竞争，Connell 实验中的 *Balanus* 会压碎并掏挖其下的 *Chthamalus*。守卫领地的鸟相互干扰对方获取食物；植物在地下为水与养分进行资源竞争，在地上则相互遮阴。有些植物进行化学干扰，释放抑制邻株的化合物（化感作用），尽管要在野外令人信服地证明这一点出了名地困难。

竞争常常是**不对称的**：大植物对小植物的影响，远大于反过来，因为大植物在小植物得到光之前就把它截住了。拥挤苗圃里许多个体受压制、只剩少数大个体居于其上，正是对光的不对称竞争造成的。

## 种内竞争

同一物种的成员，其需求在所有生物中几乎定义上最为相似，而种内竞争是调节种群的负密度依赖的主要来源。它的效应表现为密度依赖的死亡、繁殖力下降、生长变慢与体型变小。

在植物中，对大小的效应格外引人注目。同龄植物群体生长的过程中，较大的个体压制较小的个体，后者死亡，群体自行变稀。把经历这种**自疏**的群体的平均植株质量的常用对数对密度作图，依田恭司（Kyoji Yoda）及同事（1963）发现各点趋于一条斜率约 $-3/2$ 的直线：平均质量 $\bar w \propto N^{-3/2}$。这一“−3/2幂律”曾被广泛引述为生态学为数不多的定律之一；后来的再分析表明，不同物种与条件下斜率变化相当大，还有人从代谢标度论证了 $-4/3$ 的斜率。最好的处理是把带有一个特征性却可变的斜率的规律当作**经验规律**，而不是定律。

::: example 幼苗群体的自疏 {#ex-thinning}
一个密集的松苗群体每 m² 有1000株，平均质量0.5 g。假设它遵循自疏线 $\bar w = cN^{-3/2}$，当竞争把群体变稀至每 m² 100株时，平均植株质量是多少？总生物量发生了什么变化？
::: solution
把该关系在两个密度处相除，消去常数 $c$：

$$
\bar w_2 = \bar w_1\left(\frac{N_2}{N_1}\right)^{-3/2} = 0.5\times(0.1)^{-3/2} = 0.5\times31.6 = 15.8\ \text{g}。
$$

总生物量 $B = N\bar w$ 按 $N^{-1/2}$ 缩放：从 $1000\times0.5 = 500$ g m⁻² 升到 $100\times15.8 = 1580$ g m⁻²。十株植物中有九株死了，群体的重量却增加了三倍以上——存活者的生长快于死亡者的损失。若改用 $-4/3$ 的斜率，平均质量将是 $0.5\times10^{4/3} = 10.8$ g：预言对幂指数很敏感，这是把它当作经验规律的原因之一。
:::
:::

一个相关的观察是：超过某个播种密度后，植物群体单位面积的总产量与播种密度大致无关：更多的植株只是意味着更小的植株（“终产量恒定法则”）。

## 种间竞争：Lotka–Volterra 模型

两个物种竞争同一资源，我们应当如何建模？最简单的做法由 Alfred Lotka（1925）与 Vito Volterra（1926）各自独立采用：从 [[ecology/population-growth#prop-logistic]] 的逻辑斯谛方程出发，加上另一物种的效应。在逻辑斯谛模型中，项 $N/K$ 度量一个种群把环境用掉了多少。如果物种2的个体也在耗竭物种1的环境、每个个体的耗竭相当于 $\alpha_{12}$ 个物种1个体，那么物种1的有效拥挤程度就是 $(N_1 + \alpha_{12}N_2)/K_1$。

::: proposition Lotka–Volterra 竞争方程 {#prop-lv-competition}
两个种群 $N_1$ 与 $N_2$ 按下式竞争：

$$
\frac{dN_1}{dt} = r_1N_1\left(\frac{K_1 - N_1 - \alpha_{12}N_2}{K_1}\right), \qquad
\frac{dN_2}{dt} = r_2N_2\left(\frac{K_2 - N_2 - \alpha_{21}N_1}{K_2}\right),
$$ {#eq-lvc}

其中 $r_i$ 与 $K_i$ 是物种 $i$ 单独存在时的内禀增长率与环境容纳量，**竞争系数** $\alpha_{ij}$ 是物种 $j$ 对物种 $i$ 生长的个体平均效应，以其相对于物种 $i$ 对自身效应的大小来度量。若 $\alpha_{12}\alpha_{21} \neq 1$，两个物种共存的平衡为

$$
N_1^* = \frac{K_1 - \alpha_{12}K_2}{1 - \alpha_{12}\alpha_{21}}, \qquad N_2^* = \frac{K_2 - \alpha_{21}K_1}{1 - \alpha_{12}\alpha_{21}}。
$$ {#eq-lvc-eq}

假设：对每个物种取逻辑斯谛模型的假设（无年龄结构、参数恒定、瞬时密度依赖），且竞争者的效应与其密度成线性关系并恒定。
:::

::: proof
在两物种共存的平衡处，两个括号都为零：$N_1 + \alpha_{12}N_2 = K_1$ 且 $\alpha_{21}N_1 + N_2 = K_2$。把 $N_2 = K_2 - \alpha_{21}N_1$ 代入第一个方程得 $N_1(1 - \alpha_{12}\alpha_{21}) = K_1 - \alpha_{12}K_2$，于是得 $N_1^*$；由对称性得 $N_2^*$。
:::

模型的参数是现象学的：$\alpha_{12}$ 说出物种2使物种1受害*多少*，却不说*为什么*。这既是它的弱点（它对机制毫无解释），也是它的强处（它适用于任何竞争机制，至少在平衡附近如此）。

### 等斜线与四种结局

对这个模型最好的理解方式是在**相平面**上作图，横轴为 $N_1$，纵轴为 $N_2$。物种1的**零增长等斜线**（nullcline）是 $dN_1/dt = 0$（除 $N_1 = 0$ 外）的点的集合：

$$
N_1 + \alpha_{12}N_2 = K_1 ,
$$

一条从 $N_1$ 轴上的 $(K_1, 0)$ 到 $N_2$ 轴上 $(0, K_1/\alpha_{12})$ 的直线。在其下方与左方，物种1增长；在其上方与右方，物种1下降。同样，物种2的等斜线从 $(0, K_2)$ 到 $(K_2/\alpha_{21}, 0)$，物种2在其下方增长。

::: proposition Lotka–Volterra 竞争的结局 {#prop-lvc-outcomes}
对于参数为正的系统 [[#eq-lvc]]，结局取决于两条等斜线的相对位置，等价地取决于把每个竞争系数与环境容纳量之比相比较的结果：

1. $\alpha_{21} < K_2/K_1$ 且 $\alpha_{12} > K_1/K_2$：物种2的等斜线位于物种1的之外；**物种2总是取胜**，物种1被排除。
2. $\alpha_{12} < K_1/K_2$ 且 $\alpha_{21} > K_2/K_1$：**物种1总是取胜**。
3. $\alpha_{12} < K_1/K_2$ 且 $\alpha_{21} < K_2/K_1$：等斜线相交，内部平衡 [[#eq-lvc-eq]] **稳定**：两个物种**共存**。
4. $\alpha_{12} > K_1/K_2$ 且 $\alpha_{21} > K_2/K_1$：等斜线相交，但内部平衡是不稳定的鞍点；**胜者是哪一个物种取决于起始密度**。

在对称情形 $K_1 = K_2$ 下，稳定共存的条件是 $\alpha_{12} < 1$ 且 $\alpha_{21} < 1$：**每个物种对自身生长的限制必须大于它对另一物种的限制**。
:::

::: proof
等斜线的位置由它们的截距决定。物种1的等斜线在 $K_1$ 处交 $N_1$ 轴、在 $K_1/\alpha_{12}$ 处交 $N_2$ 轴；物种2的分别在 $K_2/\alpha_{21}$ 与 $K_2$ 处相交。

考虑情形3。此时 $K_1/\alpha_{12} > K_2$（物种1的等斜线在 $N_2$ 轴上高于物种2的）且 $K_2/\alpha_{21} > K_1$（物种2的在 $N_1$ 轴上超出物种1的），故两条直线在正象限内相交，且 [[#eq-lvc-eq]] 的两个分子都是正的，分母也是（$\alpha_{12}\alpha_{21} < (K_1/K_2)(K_2/K_1) = 1$）。在边界平衡 $(K_1, 0)$ 处，物种2的个体平均增长为 $r_2(K_2 - \alpha_{21}K_1)/K_2 > 0$，故它能入侵；同样，物种1能入侵 $(0, K_2)$。每个物种在稀有之时都能增长，轨线收敛于内部平衡点。（形式地说，内部平衡处 Jacobian 的迹为负、行列式为正，等于 $r_1r_2N_1^*N_2^*(1 - \alpha_{12}\alpha_{21})/(K_1K_2)$，故两个特征值的实部都为负。）

在情形4中，不等号反向：两个物种都不能入侵对方的平衡，行列式为负，内部点是一个鞍点，其稳定流形把平面分成两个吸引域。在情形1与2中，等斜线不在正象限内相交，每条轨线都走向占优物种唯一的边界平衡。在情形3中令 $K_1 = K_2$ 即得 $\alpha_{12} < 1$、$\alpha_{21} < 1$。
:::

对称条件是竞争理论的核心教训。当**种内竞争强于种间竞争**时，两个物种共存：当个体伤害本物种成员甚于伤害另一物种成员时。当两个物种的需求不同、以致每个物种主要受另一物种很少利用的资源限制时，就会发生这种情况——也就是说，当它们的生态位不同时。

::: example 谁是胜者？ {#ex-lvc}
物种1有 $K_1 = 100$，物种2有 $K_2 = 80$（每样方个体数），$\alpha_{12} = 0.5$，$\alpha_{21} = 0.6$。判定竞争的结局与平衡密度。若条件改变使 $\alpha_{21}$ 升到1.0，会发生什么？
::: solution
两个比值是 $K_1/K_2 = 1.25$ 与 $K_2/K_1 = 0.8$。由于 $\alpha_{12} = 0.5 < 1.25$ 且 $\alpha_{21} = 0.6 < 0.8$，这是情形3：稳定共存。由 [[#eq-lvc-eq]]，

$$
N_1^* = \frac{100 - 0.5\times80}{1 - 0.5\times0.6} = \frac{60}{0.7} = 85.7, \qquad
N_2^* = \frac{80 - 0.6\times100}{0.7} = \frac{20}{0.7} = 28.6 。
$$

两个物种都被压到各自容纳量之下，物种2被压得更低得多。

若 $\alpha_{21} = 1.0 > 0.8$ 而 $\alpha_{12}$ 仍低于1.25，我们处在情形2：物种1取胜。形式地说，$N_2^* = (80 - 100)/(1 - 0.5) = -40 < 0$，这不是生物学上可能的平衡；系统走向 $N_1 = 100$、$N_2 = 0$。
:::
:::

::: example 估计竞争系数 {#ex-alpha}
在单物种培养中，粉甲达到每瓶200只的容纳量。在达到稳定平衡的混合培养中，它与每瓶100只的第二物种共处时稳定在每瓶120只。估计 $\alpha_{12}$。
::: solution
在共存平衡处，[[#eq-lvc]] 中物种1的括号为零：$K_1 - N_1^* - \alpha_{12}N_2^* = 0$。于是

$$
\alpha_{12} = \frac{K_1 - N_1^*}{N_2^*} = \frac{200 - 120}{100} = 0.8 。
$$

物种2的每个个体降低物种1生长的程度，相当于0.8个物种1个体。这一方法假定 Lotka–Volterra 模型描述了该相互作用；实践中，这样估计出的系数常随密度变化，是模型的线性假设不成立的征兆。
:::
:::

### 竞争排斥原理

需求过于相似的物种不能无限期共存——这一结论被称为**竞争排斥原理**或 Gause 原理，是 Garrett Hardin 在1960年以“完全竞争的物种不能共存”这一口号命名的。Gause 曾用他的 *Paramecium* 阐明过它：在同一培养基中 *P. aurelia* 排除了 *P. caudatum*；但当他把 *P. caudatum* 与 *P. bursaria* 放在一起时，两者共存了——*P. bursaria* 主要取食管底的酵母细胞，*P. caudatum* 取食上层水中的细菌。

作为一种陈述，这一原理近乎循环论证：只要两个物种共存，人们总能找出它们之间的*某种*差异，并宣称它们的生态位不同。它的科学内容在于本章各模型所提供的定量版本——需要多大的差异、沿哪些轴、在什么条件下。

::: quiz
在对称的 Lotka–Volterra 模型（$K_1 = K_2$）中，哪个条件给出稳定共存？
- [ ] $\alpha_{12} = \alpha_{21} = 1$
- [x] $\alpha_{12} < 1$ 且 $\alpha_{21} < 1$
- [ ] $\alpha_{12} > 1$ 且 $\alpha_{21} > 1$
- [ ] $\alpha_{12} < 1$ 且 $\alpha_{21} > 1$
::: solution
共存要求每个物种对自身生长的抑制大于对另一物种的抑制：$\alpha_{12}, \alpha_{21} < 1$（[[#prop-lvc-outcomes]]，情形3）。若两者都超过1，种间竞争强于种内竞争，起始占优的物种获胜（情形4）。若一个低于1、一个高于1，则总有一个物种必胜。若两者都等于1，两个物种生态上完全相同，模型有一整条中性的平衡线；实际上漂变最终会消灭其中一个。
:::
:::

## 为资源而竞争：R* 法则

Lotka–Volterra 模型没有说明物种竞争*的对象*是什么。David Tilman 在 Robert MacArthur 工作的基础上，于1970与1980年代发展出一个把资源本身纳入建模的机制性理论。其核心结果很简单。

::: proposition R* 法则 {#prop-rstar}
设若干物种受同一资源的限制，其浓度 $R$ 因它们的消耗而下降；每个物种 $i$ 的个体平均增长率 $\mu_i(R)$ 随 $R$ 上升，并具有恒定的个体平均损失率 $m_i$（死亡，或从恒化器中被冲出）。每个物种单独存在时把资源压低到其增长恰好抵偿损失的水平，即由下式定义的浓度 $R_i^*$：

$$
\mu_i(R_i^*) = m_i 。
$$ {#eq-rstar}

在竞争的平衡状态下，**$R^*$ 最低的物种排除所有其他物种**，因为它把资源压到其他物种无法抵偿损失的水平以下。若生长服从 Monod（Michaelis–Menten）型 $\mu_i(R) = \mu_{\max,i}\,R/(K_{s,i} + R)$，具有最大生长速率 $\mu_{\max,i}$ 与半饱和常数 $K_{s,i}$，则

$$
R_i^* = \frac{K_{s,i}\,m_i}{\mu_{\max,i} - m_i}。
$$ {#eq-rstar-monod}

假设：单一限制资源、充分混合而生境供给恒定的系统、平衡条件。
:::

::: proof
物种 $i$ 单独存在时，只要 $\mu_i(R) > m_i$ 就增长，消耗资源并压低 $R$，直到 $\mu_i(R) = m_i$：那便是 $R_i^*$。若物种1有 $R_1^* < R_2^*$，则在物种1设定的平衡处，$R = R_1^*$ 且 $\mu_2(R_1^*) < \mu_2(R_2^*) = m_2$（因为 $\mu_2$ 是增函数），于是物种2衰退；反过来，物种1能入侵物种2的平衡，因为 $\mu_1(R_2^*) > m_1$。对 Monod 型，把 $\mu_{\max}R/(K_s + R) = m$ 解出 $R$：$\mu_{\max}R = mK_s + mR$，故 $R^* = K_sm/(\mu_{\max} - m)$。
:::

::: example 胜者未必是生长最快者 {#ex-rstar}
两种浮游植物在稀释率 $m = 0.25$ 每天的恒化器中竞争磷酸盐。物种 A 有 $\mu_{\max} = 1.0$ 每天、$K_s = 2.0$ μmol L⁻¹；物种 B 有 $\mu_{\max} = 0.6$ 每天、$K_s = 0.5$ μmol L⁻¹。谁取胜？
::: solution
由 [[#eq-rstar-monod]]，

$$
R_A^* = \frac{2.0\times0.25}{1.0 - 0.25} = 0.667\ \mu\text{mol L}^{-1}, \qquad R_B^* = \frac{0.5\times0.25}{0.6 - 0.25} = 0.357\ \mu\text{mol L}^{-1}。
$$

物种 B 的 $R^*$ 更低而取胜，尽管当磷酸盐充足时物种 A 的生长几乎快一倍。当资源充足时（例如养分脉冲之后刚刚），A 超过 B；在平衡时，要紧的是利用稀缺资源生长的能力。这是快速生长与竞争能力之间一个反复出现的权衡的一个版本。
:::
:::

caption: [[#ex-rstar]] 中两种浮游植物的个体平均生长率（每天）对磷酸盐浓度 $R$（μmol L⁻¹）的图，损失率 $m$ 为水平线。每个物种的 $R^*$ 是其曲线与直线的交点处；交点更靠左的物种取胜。当 $m = 0.25$ 时，尽管 A 的最大值更高，B 先与直线相交。把 $m$ 调到约0.47以上，注意交点的次序反转，于是 A 成为胜者。
:::

对**两种**必需资源，理论预言：如果每个物种是不同资源的更好竞争者（对其 $R^*$ 更低）、每个物种相对更多地消耗限制*自身*的资源，且两种资源的供给比处于中间，两个物种就能稳定共存。Tilman 在1977年用两种淡水硅藻 *Asterionella formosa* 与 *Cyclotella meneghiniana* 在硅酸盐与磷酸盐上检验了这一点：*Asterionella* 是磷酸盐方面更好的竞争者，*Cyclotella* 是硅酸盐方面更好的竞争者；随着供给中硅酸盐对磷酸盐之比的变化，培养中的结局从一个物种占主导、经共存、变为另一物种占主导，与预言大体相符。同样的推理可延伸到草地中植物对氮与光的竞争——这是 Tilman 在明尼苏达州雪松溪长期实验的主题。

## 来自自然的证据

实验室培养表明竞争*能够*排除物种。自然界中的物种真的在竞争吗？竞争塑造群落吗？

### 移除与添加实验

最直接的证据来自野外实验：移除一个物种（或添加一个物种），度量另一个物种的响应，正如 Connell 对藤壶所做的那样。Joseph Connell 与 Thomas Schoener 在1983年发表的、覆盖数百项研究的综述，在其中一大部分研究里发现了种间竞争的证据；植物与固着海洋动物之间比植食性昆虫之间更常见，后者常常因捕食者与拟寄生者而被压制在远低于耗尽食物水平的密度之下。竞争普遍却不普遍适用，其强度随地点与年份而变化。

### 资源分割

共存的物种常常在彼此之间分割资源。在一项发表于1958年的经典研究中，Robert MacArthur 发现在新英格兰同一片云杉上取食昆虫的5种林莺（*Setophaga*，当时称 *Dendroica*）在树的不同部位觅食：有的靠近顶部，有的靠近底部，有的在外侧小枝，有的近树干——并且在觅食行为与繁殖时间上也有差异。这种**资源分割**与“竞争塑造了这些物种的生态位”相一致，但它本身并不能证明这一点：物种的不同也许另有原因。Connell 把用过去的竞争来解释现今差异的做法称为“过去竞争的幽灵”——貌似合理，却难以检验。

::: warning "现在没有竞争说明竞争并不重要"——及其反面
今天利用不同资源的两个物种之所以如此，*可能正因为*过去的竞争把它们推开——通过进化，或通过排除居间的物种；现在找不到竞争，并不能说明竞争曾经不重要。反过来，发现共存物种彼此有差异，也不能证明是竞争造成了这些差异——物种因许多原因而不同。关于竞争的主张，对现在需要实验（移除或添加），对过去需要进化方面的证据，如特征置换。
:::

### 特征置换

如果竞争偏爱分歧，那么两个物种在共同分布（**同域**）之处，差异应当大于各自单独分布（**异域**）之处。这一格局——**特征置换**——由 William Brown 与 Edward Wilson 在1956年描述。一个著名的例子是加拉帕戈斯群岛的地雀：在中地雀（*Geospiza fortis*）与小地雀（*G. fuliginosa*）共同分布的岛屿上，它们的喙大小截然不同；而在只有一个物种存在的岛屿上，它的喙居于中间大小，正如 David Lack 于1947年所指出的。

最直接的证明来自 Peter 与 Rosemary Grant 在达芙妮梅杰岛上的长期研究。大地雀 *G. magnirostris* 于1982年拓殖该岛并增长。2004–2005年严重干旱期间，在取食大而硬的种子上与 *G. magnirostris* 重叠的大喙 *G. fortis* 死亡惨重，存活下来的 *G. fortis* 喙更小。下一代继承了较小的喙——一次由竞争引起的、可测量的进化转变，发表于2006年。对喙的自然选择及其测量见 [[evolution/natural-selection]]。

::: intuition 为什么相似的物种不能共享一切
想象两种食种子的鸟，它们的喙适应同一大小范围的种子。每个物种吃掉的每一粒种子都是另一个的损失，于是每个物种受另一物种的伤害与受本物种的伤害一样大（$\alpha \approx 1$），稍强的竞争者获胜。现在让它们偏好不同：一个最善于取食小种子，另一个善于大种子。每个物种此时主要耗竭*自己*的种子，于是自身的数目对自己的限制大于对方的数目（$\alpha < 1$）。同样的方程，先前预言排除，如今预言共存。生态位差异使种内竞争强于种间竞争——而这正是共存所需要的。
:::

## 竞争者如何共存

上面的平衡模型要求生态位差异才能共存。但许多群落中的物种数似乎远超可区分的资源数。Hutchinson 在1961年指出了“浮游生物悖论”：数十种浮游植物在一个湖中共存，看上去全都竞争同样几种养分与光。还有若干机制有助于解释这样的多样性。

- **波动的环境。** 如果条件在竞争排除完成之前改变，占优竞争者的身份就可能不断变化，没有物种获胜。Hutchinson 本人对浮游生物悖论的解释就属于这一类。
- **干扰。** 火灾、风暴、啃食与波浪作用反复腾出空间。如果好的竞争者是差的拓殖者，而好的拓殖者是差的竞争者（**竞争-拓殖权衡**），两者就能在处于不同恢复阶段的斑块景观中存续。干扰在群落中的作用见 [[ecology/communities]]。
- **天敌。** 最常攻击最常见物种的捕食者或病原体，能防止后者排除其他物种。这一频率依赖机制被认为有助于维持热带森林的树木多样性（Janzen–Connell 假说），并将在 [[ecology/predation-parasitism]] 中展开。
- **储存效应。** 长寿命的阶段——种子库中的种子、长寿的成体——让一个物种能够“储存”丰年的收益、熬过歉年，于是各受不同年份偏爱的物种得以共存。Peter Chesson 在1980年代使之形式化。

Chesson 更一般的框架（2000年），今称**现代共存理论**，区分竞争者之间的两类差异。**稳定化**的生态位差异使每个物种更强烈地限制自身，让物种在稀有时占优（在 Lotka–Volterra 模型中，$\alpha < 1$）。**适合度差异**（更确切地应称为平均竞争能力差异）偏爱某一个物种，无论其频率如何（在模型中，即不相等的 $K$）。共存要求稳定化差异大到足以克服适合度差异——这正是 [[#prop-lvc-outcomes]] 的不等式所说的：随着 $K_1/K_2$ 偏离1，竞争系数必须更小才能共存。

::: application 农业与入侵中的竞争
杂草主要通过竞争光、水与养分降低作物产量；给定杂草密度造成的产量损失可以用竞争模型描述，而密播或窄行种植的作物更快封闭冠层、抑制杂草。在间作中，生态位差异的逻辑被有意识地利用：禾谷类与豆科植物混种，常比同等面积分别单种产量更高，因为豆科植物自行固氮，而两者部分地利用不同资源。竞争也决定生物入侵的结局：入侵的灰松鼠（*Sciurus carolinensis*）通过对食物的竞争——灰松鼠更能利用橡实——以及经松鼠痘病毒的表观竞争（灰松鼠携带它而几乎无害，红松鼠感染却致命），在英国大部分地区取代了本地的红松鼠（*S. vulgaris*）。入侵在 [[conservation-biology/invasions-climate]] 中进一步讨论。
:::

::: history
Darwin 在《物种起源》（1859）中论证，亲缘关系近的物种之间竞争最剧烈，因为它们的习性相似。Lotka–Volterra 方程（1925–1926）给了它一个数学形式，Gause 的书 *The Struggle for Existence*（1934）用原生动物与酵母检验了它。Thomas Park 自1940年代起用粉甲（*Tribolium*）进行的长期系列实验表明，胜者可能取决于温度与湿度——在某些条件下甚至取决于偶然。Joseph Connell 的藤壶（1961）与 Robert MacArthur 的林莺（1958）把这一问题带进了野外，而 Hutchinson 的生态位（1957）与其“浮游生物悖论”（1961）为讨论定了框架。1970与1980年代关于竞争在多大程度上塑造群落的争论，催生了更严格的野外实验与零模型；而 David Tilman 的资源比率理论（1982）与 Peter Chesson 的共存理论（2000）给竞争分别带来了机制性与一般性的框架。
:::

## 由此引向何处

竞争是物种之间三种基本相互作用之一；[[ecology/predation-parasitism]] 处理第二种——一个物种取食另一个，并发现捕食者能使竞争者共存，也能间接相互排除（表观竞争）。[[ecology/communities]] 把所有相互作用放在一起，包括第三种——互利共生，并追问它们如何决定哪些物种共同出现。

::: summary
- **竞争**是通过共享限制资源造成的相互伤害的相互作用，分为**资源竞争**或**干扰竞争**（[[#def-competition]]）；它常常是不对称的。
- 种内竞争产生密度依赖；在植物中它产生自疏，近似（且经验地）$\bar w \propto N^{-3/2}$。
- **Lotka–Volterra 竞争模型**（[[#prop-lv-competition]]）在逻辑斯谛模型上加上竞争者的效应 $\alpha_{ij}N_j$。它的四种结局（[[#prop-lvc-outcomes]]）由 $\alpha_{12}$ 与 $K_1/K_2$、$\alpha_{21}$ 与 $K_2/K_1$ 的比较决定。稳定共存要求**种内竞争强于种间竞争**。
- **竞争排斥原理**：完全竞争的物种不能共存。
- 对单一限制资源，最低 **R\*** 的物种取胜（[[#prop-rstar]]）；若每个物种是其中一个资源的更好竞争者，两个物种可在两个资源上共存。
- 野外证据来自移除实验、资源分割与**特征置换**（加拉帕戈斯地雀）；过去的竞争难以证明。
- 许多物种的共存还取决于波动、干扰、天敌与储存效应；现代共存理论权衡稳定化生态位差异与适合度差异。
:::

## 习题

::: exercise 等斜线的截距 {level=1 check="125"}
在 $K_1 = 100$、$\alpha_{12} = 0.8$ 的 Lotka–Volterra 竞争模型中，物种1的零增长等斜线在何处与 $N_2$ 轴相交？
::: solution
在 $N_1 = 0$ 处，$\alpha_{12}N_2 = K_1$，故 $N_2 = K_1/\alpha_{12} = 100/0.8 = 125$。
:::
:::

::: exercise 对称平衡 {level=1 check="500/9"}
两个物种有 $K_1 = K_2 = 100$、$\alpha_{12} = \alpha_{21} = 0.8$。求物种1的平衡密度。
::: solution
由 [[#eq-lvc-eq]]，$N_1^* = (100 - 0.8\times100)/(1 - 0.64) = 20/0.36 = 55.6$。两个物种的平衡相同，且由于两个系数都低于1，它是稳定的。
:::
:::

::: exercise 一个 R* 值 {level=1 check="5/7"}
一种细菌在葡萄糖上生长，$\mu_{\max} = 0.8$ h⁻¹、$K_s = 5$ mg L⁻¹，恒化器稀释率为0.1 h⁻¹。计算它的 $R^*$，以 mg L⁻¹ 计。
::: solution
$R^* = K_sm/(\mu_{\max} - m) = 5\times0.1/(0.8 - 0.1) = 0.5/0.7 = 0.714$ mg L⁻¹。
:::
:::

::: exercise 判定结局 {level=2}
对下列每种情形，判定 Lotka–Volterra 竞争的结局：(a) $K_1 = 150$、$K_2 = 120$、$\alpha_{12} = 0.6$、$\alpha_{21} = 0.5$；(b) $K_1 = K_2 = 100$、$\alpha_{12} = 1.3$、$\alpha_{21} = 1.2$；(c) $K_1 = 100$、$K_2 = 200$、$\alpha_{12} = 0.4$、$\alpha_{21} = 1.5$。对 (a)，求平衡。
::: solution
(a) $K_1/K_2 = 1.25 > 0.6$ 且 $K_2/K_1 = 0.8 > 0.5$：稳定共存。$N_1^* = (150 - 0.6\times120)/(1 - 0.3) = 78/0.7 = 111.4$；$N_2^* = (120 - 0.5\times150)/0.7 = 45/0.7 = 64.3$。

(b) 两个系数都超过 $K_1/K_2 = K_2/K_1 = 1$：内部平衡不稳定；胜者取决于起始密度。

(c) $K_1/K_2 = 0.5$，而 $\alpha_{12} = 0.4 < 0.5$，故物种1能入侵物种2的平衡；$K_2/K_1 = 2$，而 $\alpha_{21} = 1.5 < 2$，故物种2能入侵物种1的平衡。又是稳定共存，尽管物种2每个个体受害更深——它更高的容纳量作了补偿。
:::
:::

::: exercise 哪种浮游植物取胜？ {level=2}
在一个损失率恒为每天0.2的湖中，三种藻竞争硝酸盐：X（$\mu_{\max} = 1.2$ d⁻¹，$K_s = 4$ μmol L⁻¹）、Y（$\mu_{\max} = 0.5$ d⁻¹，$K_s = 1$）、Z（$\mu_{\max} = 0.3$ d⁻¹，$K_s = 0.2$）。平衡时谁取胜？大量硝酸盐输入之后，预计哪个物种会短暂占主导？若损失率升到0.28 d⁻¹，排序会怎样？
::: solution
$R^*_X = 4\times0.2/1.0 = 0.8$；$R^*_Y = 1\times0.2/0.3 = 0.667$；$R^*_Z = 0.2\times0.2/0.1 = 0.4$ μmol L⁻¹。Z 的 $R^*$ 最低，在平衡时取胜。硝酸盐脉冲之后，$\mu_{\max}$ 最高的 X 生长最快、短暂占主导。当 $m = 0.28$：$R^*_X = 1.12/0.92 = 1.22$；$R^*_Y = 0.28/0.22 = 1.27$；$R^*_Z = 0.056/0.02 = 2.8$。此时 X 取胜：高损失率偏爱生长快者，因为生长慢者即便资源充足也几乎不能抵偿损失。竞争的结局取决于环境。
:::
:::

::: exercise 解读移除实验 {level=2}
在一片草地中，一位生态学家从一些样方中移除一种优势禾草，并在对照样方中保留它。两年后，一种草本植物在移除样方中的生物量是对照的3.5倍，但每株的种子产量没有差异。在第二个实验中，移除优势禾草但保留其枯枝落叶；草本植物只增加了1.4倍。关于禾草影响该草本的机制，你得出什么结论？
::: solution
禾草强烈抑制该草本的生长（移除后增加3.5倍），故两者竞争或发生负相互作用。保留枯枝落叶抵消了大部分增益，说明抑制的大部分不是通过活体植株、而是通过枯落物起作用——例如遮蔽幼苗、物理阻碍出苗，或释放抑制性化学物质。剩余的1.4倍效应，可能是活体禾草对光、水或养分的资源竞争。每株种子产量缺乏变化提示：该草本的响应主要经由植株的数目或大小，而非每株的繁殖力。
:::
:::

::: exercise 是特征置换吗？ {level=2}
在两种蜥蜴共同分布的岛屿上，它们的平均体长是52 mm 与78 mm。在只有其中一种存在的岛屿上，平均值是62 mm 与68 mm。(a) 这提示特征置换吗？(b) 给出两个需要排除的替代解释。(c) 什么样的长期观察能提供最有力的证据？
::: solution
(a) 是：两个物种在同域之处的差异（26 mm）大于异域之处（6 mm），与“竞争在共现处偏爱分歧”相符。

(b) 同时有两个物种的岛屿可能与只有一个物种的岛屿存在系统差异（面积、食物供给、气候），于是体型差异可能是对环境——而非对竞争者——的可塑或适应响应。或者，也许只有本来就有差异的物种对才能够共存（生态筛选），不经过同域进化也能产生这一格局。

(c) 在一个物种拓殖另一个物种已占据的岛屿之后观察到进化改变——正如 Grant 夫妇在 *G. magnirostris* 到来之后于 *Geospiza fortis* 中所观察到的——再加上该变化可遗传、以及竞争者会降低与其相似个体适合度的证据。
:::
:::

::: exercise 入侵判据 {level=3}
证明：在 Lotka–Volterra 竞争模型中，物种2能在处于容纳量的物种1种群中于稀少时增长，当且仅当 $\alpha_{21} < K_2/K_1$。用这一“相互可入侵性”判据重新推导稳定共存的条件，并解释为什么入侵性比等斜线的位置是更一般的判据。
::: solution
当物种2稀少（$N_2 \approx 0$）时，物种1处在 $N_1 = K_1$，物种2的个体平均增长为 $r_2(K_2 - 0 - \alpha_{21}K_1)/K_2$，它为正当且仅当 $K_2 > \alpha_{21}K_1$，即 $\alpha_{21} < K_2/K_1$。由对称性，物种1能入侵物种2的平衡当且仅当 $\alpha_{12} < K_1/K_2$。稳定共存（情形3）恰是每个物种都能入侵对方的情形；由一个物种排除，是只有它能入侵的情形；两稳的情形4则是两者都不能入侵的情形。

入侵性判据可以推广到等斜线弯曲的模型、超过两个物种的模型，以及环境波动的模型（此时问的是稀物种的长期平均增长率是否为正）。它是现代共存理论的基础。
:::
:::

::: exercise 适合度差异与生态位差异 {level=3}
在 Lotka–Volterra 模型的对称版本中，令 $\alpha_{12} = \alpha_{21} = \alpha$ 且 $0 < \alpha < 1$。证明共存要求 $\alpha < K_1/K_2 < 1/\alpha$。把 $1 - \alpha$ 解释为生态位差异，把 $K_1/K_2$ 解释为适合度之比，并解释为什么生态位非常相似的物种也必须竞争能力非常相似才能共存。这对两个 $\alpha = 0.9$ 的物种意味着什么？
::: solution
两个入侵条件是 $\alpha < K_1/K_2$（物种1入侵）与 $\alpha < K_2/K_1$，即 $K_1/K_2 < 1/\alpha$（物种2入侵）。合起来：$\alpha < K_1/K_2 < 1/\alpha$。

若 $\alpha$ 接近1（生态位差异 $1 - \alpha$ 很小），区间 $(\alpha, 1/\alpha)$ 在1附近很窄，故适合度之比必须接近1。随着生态位差异增大（$\alpha \to 0$），区间变宽，适合度悬殊的竞争者也能共存。对 $\alpha = 0.9$，共存要求 $0.9 < K_1/K_2 < 1.11$：两个容纳量必须相差约10 %以内。小的生态位差异只能稳定小的适合度差异——这正是现代共存理论的核心思想。
