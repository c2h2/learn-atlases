1965–1966年的冬天，林务人员在新罕布什尔州白山山脉的 Hubbard Brook 实验林里砍倒了一个小集水域里的所有树木，让木材就地堆放，并在接下来的三年里喷洒除草剂阻止任何萌发。自1963年起，Gene Likens、Herbert Bormann 及其同事就在这片集水域和相邻的、保持原状的集水域里测量随雨雪进入和随溪流流出之物，每个集水域都排过不透水的基岩，使溪流带走流失的一切。砍伐之后，清空的集水域的溪流流量升高，其硝酸盐浓度升高数十倍，一度远超饮用水标准；钙、钾及其他养分也大量流失。没有活的植物吸收它们，分解所释放的养分便径直被冲走。

Hubbard Brook 实验表明，生态系统的活植被正是把养分固定在原处的那道关口。本章追踪这些养分——除水中氢与氧之外生物体所需的化学元素——在生态系统的有生命部分与无生命部分之间走过的路径。与能量不同——能量流经系统并以热的形式散失（[[ecology/ecosystem-energetics]]）——元素被一遍又一遍地利用。我们把一个循环描述为一组库与通量，并推导元素在库中的滞留时间；研究**分解**，即把元素从死有机质中释放出来的过程；然后追踪生物学的三大循环——碳、氮与磷——包括人类活动如何改变了每一个。执行其中许多转化的微生物在 [[microbiology/microbial-ecology]] 与 [[microbiology/microbial-metabolism]] 中描述。

## 库、通量与滞留时间

::: definition 生物地球化学循环 {#def-cycle}
**生物地球化学循环**是化学元素在生物与大气、水、土壤和岩石之间移动的诸路径的集合。它以**库**（或称储库）——每个组分（如大气、植物生物量或土壤有机质）所含该元素的量，单位如 Pg（10¹⁵ g）——和**通量**——库之间转移的速率，单位如 Pg yr⁻¹——来描述。元素在库中的**滞留时间**是库的大小除以进入它的总通量（若在稳态，也等于除以其流出的总通量）：一个原子在库中度过的平均时间。
:::

在生态系统的尺度上，区分**输入**（以气体、尘埃、雨和雪的形式来自大气，来自岩石的风化，对氮而言还有生物固氮）、植物、动物、微生物与土壤之间的**内部循环**，以及**输出**（随溪水流失、淋洗进入地下水、以气体形式、或随收获的物质）是有用的。在成熟森林中，内部循环远大于输入与输出：一棵树每年吸收的氮，大部分来自去年凋落物的分解，而非来自新的输入。Hubbard Brook 的砍伐在吸收这一步打破了内部循环，输出随之飙升。

对库的最简单模型是一个单箱：输入恒定，损失与存量成正比。

::: proposition 单箱模型 {#prop-box}
设一库含某元素 $X$，接受恒定输入通量 $I$，并以与其大小成正比的速率 $kX$ 失去该元素，**周转率** $k$（单位时间的倒数）。于是

$$
\frac{dX}{dt} = I - kX ,
$$ {#eq-box}

其从 $X(0) = X_0$ 出发的解为

$$
X(t) = \frac{I}{k} + \left(X_0 - \frac{I}{k}\right)e^{-kt}.
$$ {#eq-box-sol}

库趋近**稳态** $X^* = I/k$，此时输入等于输出，而滞留时间为

$$
\tau = \frac{X^*}{I} = \frac1k .
$$ {#eq-residence}

趋近稳态的时间常数也是 $1/k$：一次扰动之后，在时间 $1/k$ 内约63 %的差距被弥合，在 $3/k$ 内为95 %。
:::

::: proof
该方程是线性的；令 $Y = X - I/k$ 后它化为 $dY/dt = -kY$，故 $Y = Y_0e^{-kt}$，即得 [[#eq-box-sol]]。当 $t \to \infty$ 时 $X \to I/k$。稳态时输出 $kX^*$ 等于输入 $I$，且 $X^*/I = 1/k$。经过时间 $1/k$，剩余差距为 $e^{-1} = 37$ %；经过 $3/k$，为 $e^{-3} = 5$ %。
:::

[[#eq-residence]] 的两个推论在本章反复出现。滞留时间长的库反应缓慢：其稳态大小随输入的变化成正比地改变，但到达新的稳态需要几倍的滞留时间。而改变输入或改变周转率都能同样地改变库的大小：若凋落物落得更多*或*分解变慢，土壤碳都会增加。

## 分解

::: definition 分解与矿化 {#def-decomposition}
**分解**是死有机质（**碎屑**：死亡植物组织、动物遗体、粪便）经可溶化合物的**淋溶**、碎屑食者的**破碎**、以及主要由真菌与细菌酶促的**化学改变**而发生的瓦解。**矿化**是把元素从有机形态转化为无机形态——有机氮变铵、有机磷变磷酸盐、有机碳变 CO₂——使其重新可供植物利用。**固持**是其逆过程：微生物把无机养分吸收进自身的生物量。
:::

分解速率取决于三组因素：**物理环境**（温暖湿润时最快，低温、干旱与积水使其减慢，积水会排斥氧气）；**凋落物的质量**（富氮、少木质素与酚类化合物的凋落物分解快，而木质化的、富含木质素的或贫瘠的凋落物分解慢）；以及**分解者群落**，包括能降解木质素的真菌、以及把凋落物破碎并拌入土壤的蚯蚓及其他碎屑食者的存在与否。分解者本身就是一个多样的群落；参见 [[microbiology/microbial-ecology]]。

关于凋落物的质量损失，Jerry Olson 在1963年给出了一个简单而广泛使用的描述。

::: proposition 凋落物的指数衰变 {#prop-olson}
若单位时间内有剩余凋落物的固定比例发生分解，则时间 $t$ 后剩余的质量为

$$
X_t = X_0\,e^{-kt},
$$ {#eq-olson}

其中 $k$ 为**分解常数**。凋落物的半衰期为 $\ln2/k$，其平均滞留时间为 $1/k$。对年凋落输入为 $I$ 的森林地表，凋落物的稳态质量为 $I/k$（[[#prop-box]]），因此 $k$ 可以估计为年凋落量与凋落物层质量之比。这一单指数模型只是一个近似：凋落物含有以不同速率分解的组分，所以分解往往先快（淋溶与糖的损失）后慢（木质素与腐殖化物质）。
:::

::: example 两片森林地表的枯落物 {#ex-decay}
温带森林中栎树落叶以 $k = 0.5$ 每年分解。(a) 2年后还剩几分之几？半衰期是多少？(b) 到损失95 %的质量需要多久？(c) 若某森林的年凋落量为400 g m⁻²、其平均 $k$ 为0.25 yr⁻¹，凋落物层的稳态质量是多少？对一个凋落量相同、$k = 3$ yr⁻¹ 的热带森林作一比较。
::: solution
(a) $X_2/X_0 = e^{-0.5\times2} = e^{-1} = 0.37$；半衰期为 $\ln2/0.5 = 1.39$ 年。

(b) 需要 $e^{-0.5t} = 0.05$，故 $t = \ln20/0.5 = 6.0$ 年。

(c) 温带：$I/k = 400/0.25 = 1600$ g m⁻²。热带：$400/3 = 133$ g m⁻²。输入相同，热带地表的凋落物只有十二分之一，因为每片叶子只持续几个月而不是几年。这就是为什么热带雨林的土壤常出人意料地含有很少有机质，为什么生态系统养分资本的大部分存在于活植被之中——而森林一旦被砍伐，后果便十分严重。
:::
:::

### 矿化还是固持？

分解究竟为植物*释放*养分，还是把养分*锁住*于微生物体内，取决于凋落物中碳与养分之比。微生物需要氮来建造自身的生物量，其生物量的碳氮比很低（细菌约5–10，真菌稍高），并且会把所消耗碳的很大一部分呼吸掉。若凋落物所含的氮少于微生物处理其碳所需，它们便从土壤中吸收无机氮（固持），与植物竞争；若含得更多，多余部分便以铵的形式释放（矿化）。

::: example 临界 C:N 比 {#ex-cn}
土壤微生物生物量的 C:N 比为8，碳利用效率为0.4（其吸收的碳有40 %变成生物量，60 %被呼吸掉）。分解既不释放也不吸收无机氮的凋落物 C:N 比是多少？C:N = 80的麦秸会带来净矿化还是净固持？
::: solution
考虑100 g 凋落物碳。微生物把40 g 转化为生物量，需要 $40/8 = 5$ g 氮。若凋落物恰好供给这么多，其 C:N 便是 $100/5 = 20$。一般而言，临界比为（微生物 C:N）/（碳利用效率）$= 8/0.4 = 20$。

C:N = 80的麦秸每100 g 碳只供给 $100/80 = 1.25$ g 氮，远低于所需的5 g，所以微生物会固持土壤中的无机氮。因此翻压麦秸会暂时减少作物可用的氮。随分解进行，碳被呼吸掉，剩余物料的 C:N 下降，直到越过临界值，净矿化开始。
:::
:::

## 碳循环

碳是有机质的元素，其循环与能量流动相耦合：光合作用在捕获能量的同时固定碳，呼吸则把两者都释放出来。

全球碳循环的主要库，近似如下（以 Pg C 计；数值取自政府间气候变化专门委员会 AR6（2021年）评估的约整，并对大气作了更新）：

| 库 | 碳（Pg C） |
|---|---|
| 大气（以 CO₂ 形式，2024–2025年约425 ppm） | 约900 |
| 陆地植被 | 450–650 |
| 土壤（表层一米，不含永冻土） | 约1500–2400 |
| 永冻土 | 约1400 |
| 表层海洋 | 约900 |
| 中层与深海（主要为溶解无机碳） | 约37 000 |
| 化石燃料储量 | 约1000 |

最大的年通量是大气与陆地植被之间的交换——全球 GPP 约120–130 Pg C yr⁻¹，经植物与土壤呼吸及火灾返回——以及大气与海洋之间 CO₂ 的总交换，每个方向约80–90 Pg C yr⁻¹。在工业时代之前，这些大通量几乎平衡，大气 CO₂ 浓度数千年来保持在约280 ppm，南极冰中封闭的气泡即表明了这一点。

::: example 一个碳原子在空气中停留多久？ {#ex-residence}
大气含有约900 Pg C。它与陆地植被交换约120 Pg C yr⁻¹（以 GPP 计），与海洋交换约90 Pg C yr⁻¹。碳原子在大气的滞留时间是多少？这是否意味着加入大气的多余 CO₂ 会在那样短的时间内消失？
::: solution
流出大气的总通量约 $120 + 90 = 210$ Pg C yr⁻¹，故由 [[#eq-residence]]，滞留时间为 $900/210 \approx 4$ 年。单个 CO₂ 分子几年之内就会与陆地或海洋完成交换。

但这*并不*意味着多余部分会在几年内被移除。交换是双向的：被吸收的分子会被呼吸与脱气返回的分子顶替。移除*多余部分*的是大通量之间那一点微小的*净*差，它受远更缓慢的过程支配——表层水向深海的混合（几个世纪）、碳酸盐沉积物的溶解（几千年）与岩石风化（几十万年）。因此所加入 CO₂ 的扰动时长远长于单个分子的滞留时间：排放中相当一部分会在大气中停留好几个世纪。混淆这两个时间尺度是一个常见错误。
:::
:::

### 人类对碳循环的扰动

自1958年 Charles David Keeling 在夏威夷 Mauna Loa 开始连续测量以来，大气 CO₂ 浓度年年上升，从约315 ppm 升到2024年年均约425 ppm（NOAA）。上升之上叠加着一个几 ppm 的季节振荡，即北半球植被的“呼吸”——它在北半球夏季吸收 CO₂，冬季释放。上升的起因是化石燃料燃烧与水泥生产，以及土地利用变化，主要是毁林。

全球碳计划每年汇编的碳预算说明所排放的碳去了哪里。2014–2023年的平均（Global Carbon Budget 2024）显示，化石燃料与工业排放约10 Pg C yr⁻¹，土地利用变化约1 Pg C yr⁻¹。其中约5 Pg C yr⁻¹ 积累在大气中，海洋吸收约3 Pg C yr⁻¹，陆地生态系统吸收约3 Pg C yr⁻¹（这些数字并不恰好相加；其差即“预算失衡”，度量着我们的不确定性）。自然汇迄今已移走人类排放的一半多一点。随着气候变暖它们是否还会如此——例如，变暖是否加速土壤呼吸、永冻土的融化是否释放其碳——是气候预估的核心问题之一。

::: example 空中滞留分数 {#ex-airborne}
某年人类活动排放11 Pg C，大气 CO₂ 浓度上升2.45 ppm。已知大气 CO₂ 每1 ppm 对应2.12 Pg C，留在大气中的排放占多大分数？
::: solution
大气的增量为 $2.45\times2.12 = 5.2$ Pg C。**空中滞留分数**为 $5.2/11 = 0.47$：排放的47 %留在空气里，其余53 %（约5.8 Pg C）被海洋与陆地吸收。空中滞留分数的年际变异很大——厄尔尼诺年陆地汇会减弱——但其长期平均值一直保持在约40至50 %之间。
:::
:::

::: warning "海洋和森林会把我们排放的一切吸收掉"
陆地与海洋的汇是对 CO₂ 浓度升高的响应，不是固定的服务。海洋的吸收受表层水向深海缓慢混合的限制，并随海水变暖、碳酸盐化学改变而减小（正是同一套化学使海洋在吸收 CO₂ 时变得更酸）。陆地汇取决于 CO₂ 与氮沉降对植物生长的刺激、森林的更新、以及火与干旱的状况，而这些都会改变。模型预估，在高排放情景下自然汇吸收的*分数*会下降。
:::

## 氮循环

氮是每种氨基酸与核苷酸的组分，并且是水之外最常限制陆地植物生长与海洋浮游植物生长的资源。矛盾的是，大气的78 %是双氮分子 N₂——但 N₂ 的三键强到只有少数生物能够打断。

主要转化如下；它们大多由微生物执行。

- **固氮**：在固氮酶的催化下把 N₂ 还原为氨，固氮酶仅见于某些细菌与古菌。有的固氮者自生（海洋中的蓝细菌、土壤中的 *Azotobacter*）；有的共生——豆科植物根瘤中的根瘤菌、桤木根中的 *Frankia*、地衣中的蓝细菌，以及水生蕨类 *Azolla* 中的蓝细菌。固氮酶遇氧失活，且这一过程耗能巨大，每固定一个 N₂ 至少消耗16 ATP。闪电也固定少量。
- **氨化**：分解过程中有机氮释放铵（NH₄⁺），属矿化的一部分。
- **硝化**：铵被氧化为亚硝酸盐（NO₂⁻）、再成硝酸盐（NO₃⁻），由利用所释能量的化能自养细菌与古菌执行。人们长期认为这需要两类生物；2015年发现了 *Nitrospira* 属细菌能单独完成全程氧化（“comammox”）。硝酸盐在土壤中移动性强，极易淋失。
- **同化**：植物与微生物吸收铵与硝酸盐。
- **反硝化**：硝酸盐经亚硝酸盐、一氧化氮与一氧化二氮（N₂O）被还原为 N₂，由积水土壤与沉积物中以硝酸盐替代氧进行呼吸的细菌执行。它把固定氮送回大气。
- **厌氧氨氧化**（anammox）：铵与亚硝酸盐反应生成 N₂，1990年代在一座污水处理厂中被发现，如今已知它造成了海洋沉积物与最低含氧带氮损失的很大一部分。

生物固氮与反硝化是巨大的大气 N₂ 库与生物所利用的少量**活性氮**（其余一切形态）库之间的门户。在未受扰动的生态系统中，它们长期大致相抵。

### Haber–Bosch 法及其后果

1909年，Fritz Haber 演示了如何在催化剂上以高温高压把 N₂ 与氢合成氨，Carl Bosch 将此工艺放大到工业规模；第一座工厂1913年在德国投产。经 Haber–Bosch 法制成的合成化肥如今支撑着人类口中很大一部分人的食物生产。连同固氮作物的种植与燃烧释放的氮氧化物，人类活动每年制造的活性氮已与陆地上一切自然过程的总和相当甚至更多。这些氮大量没有进入食物：它以硝酸盐淋入河流与地下水，以氨和氮氧化物散入大气并沉降到别处，或被反硝化，一部分变成 N₂O——一种强温室气体，同时还损耗平流层臭氧。

其生态后果包括河流、湖泊与近海的**富营养化**（藻类过量生长，随其分解氧气耗尽），近岸水域季节性的**缺氧区**（“死区”），如密西西比河口的墨西哥湾北部，土壤与淡水酸化，以及因氮沉降偏爱速生种而使贫瘠生境丧失植物物种。这些属于 [[conservation-biology/invasions-climate]] 所处理的人类影响。

::: application 豆科、轮作与化肥
农民早在根瘤菌被发现（Hermann Hellriegel 与 Hermann Wilfarth，1886年）之前就懂得，种苜蓿、蚕豆或豌豆会使土壤对下一茬作物更肥沃。结瘤有效的豆科作物每年可固定达100 kg N ha⁻¹ 量级或更多，其中一部分留在其根与残茬里。与豆科轮作、谷物与豆科间作，仍是低投入农业的核心；而农业中的氮利用效率——施用的氮最终进入收获物的分数，常远低于一半——是减少污染的一大靶点。
:::

## 磷循环

磷是核酸、ATP 与磷脂所必需的。与碳、氮不同，它没有显著的气相，因此不能从空气中被“固定”：除随尘埃沉降的少量输入外，生态系统中的一切磷归根结底来自岩石中磷灰石之类磷酸盐矿物的**风化**。其全球循环因此大体是**沉积型**的：从岩石风化的磷被河流送入海洋，沉积于沉积物，只有当沉积物被抬升成新岩石时才回到陆地，历时数百万年。在生态系统内部，它在生物、土壤有机质与溶液之间快速循环，但在土壤中它还被铁、铝氧化物与钙强烈束缚，使其大部分对植物不可用。

因为磷来自岩石，其供应随土壤年龄而变。Thomas Walker 与 Keith Syers 在1976年提出一个土壤发育模型：新鲜岩石上的幼龄土壤富矿物磷而缺氮（氮必须靠固氮从大气积累），而极老、强烈风化的土壤已因淋失失去大部分磷，其余又被锁在不可用的形态里。Peter Vitousek 及同事对夏威夷一系列不同年龄熔岩流的研究证实了这一预言：年轻熔岩流（几百岁）上的森林受氮限制，最老熔岩流（约400万年）上的受磷限制。许多古老、强烈风化的景观——包括大片的澳大利亚与老土上的低地热带森林——都缺磷。

### 磷与富营养化

在淡水中，磷通常是限制藻类生长的养分。最著名的示范是 David Schindler 在安大略省西北部实验湖区（Experimental Lakes Area）主持的全湖实验。1973年，有两个湖盆的226号湖被一道塑料帘隔成两半。一半接受碳、氮与磷；另一半只接受碳与氮。几周内，接受磷的那半爆发了浓密的藻类水华，另一半则没有。那座湖一半亮绿一半深蓝的航拍照片成了环境科学的标志，并促使北美与欧洲的政府限制洗涤剂中的磷酸盐、在污水处理厂除磷。

### 化学计量：Redfield 比

生物体需要大致固定比例的元素。Alfred Redfield 在1934年指出，海洋浮游生物中碳、氮、磷原子之比约 $106 : 16 : 1$，与深海水中溶解的硝酸盐对磷酸盐之比接近——因为深水的养分主要来自浮游生物的分解。这一 **Redfield 比**是个平均值，物种与条件之间变异可观，但它为诊断哪种养分短缺提供了一把标尺：溶解无机 N:P 比远低于16的水可能受氮限制，远高于16则受磷限制。

::: example 哪种养分限制藻类？ {#ex-redfield}
一湖含溶解无机氮20 μmol L⁻¹、磷酸盐0.5 μmol L⁻¹。一处沿海潟湖含氮5 μmol L⁻¹、磷酸盐1 μmol L⁻¹。以 Redfield 比为指南，二者中哪种养分可能限制藻类生长？若藻类按16 : 1吸收养分直到其一耗尽，每升湖水能养活多少藻类碳？
::: solution
湖的 N:P $= 20/0.5 = 40$，远高于16：磷很可能先耗尽。潟湖为 $5/1 = 5$，低于16：氮很可能受限。

湖中0.5 μmol 的 P 会配用 $16\times0.5 = 8$ μmol 的 N，剩下12 μmol 的 N 未被利用。藻类每升可含 $106\times0.5 = 53$ μmol 碳，约0.64 mg C L⁻¹。加氮不会提高这个数；加磷会——正如226号湖。
:::
:::

::: quiz
为什么磷循环与氮、碳循环根本不同？
- [ ] 植物不需要磷
- [x] 磷没有显著的大气气相，因此主要从岩石的风化进入生态系统
- [ ] 磷在生态系统内部不被再循环
- [ ] 磷被根瘤细菌从空气中固定
::: solution
碳与氮都有巨大的大气库（CO₂ 与 N₂），生物可通过光合作用或固氮取用。磷几乎没有，所以其最终来源是岩石风化，生态系统的损失只能极缓慢地得到补充。在生态系统内部，它像其他养分一样被高效再循环。
:::
:::

::: history
元素在生物与环境之间循环的思想可追溯到十八、十九世纪的化学家——Antoine Lavoisier、Justus von Liebig 与 Jean-Baptiste Boussingault，后者在1830年代证明豆科从空气中获得氮。Sergei Winogradsky（1880–1890年代）发现了化能自养细菌，包括硝化菌；Hellriegel 与 Wilfarth（1886年）证明豆科根瘤固氮。Vladimir Vernadsky 的 *The Biosphere*（1926年）把生命描绘成塑造地球化学的地质力量。Redfield 的比值（1934年）、Keeling 自1958年的 CO₂ 记录、Hubbard Brook 自1963年的小集水域研究、Schindler 自1968年在实验湖区的全湖实验，奠定了定量生物地球化学。碳与氮的全球收支及其受人类改变的情况，自1990年代起由大型国际协作组编制。
:::

## 由此引向何处

养分供应设定了 [[ecology/ecosystem-energetics]] 中讨论的初级生产量的限度，气候与土壤的全球格局塑造着 [[ecology/biogeography]] 中的生物群系。气候变化、氮沉降与富营养化作为生物多样性的威胁，在 [[conservation-biology/invasions-climate]] 中处理；受损生态系统的恢复在 [[conservation-biology/restoration]]。

::: summary
- 养分在生物与非生物库之间循环；一个循环由**库**与**通量**描述（[[#def-cycle]]）。在单箱模型 $dX/dt = I - kX$ 中，库趋近 $X^* = I/k$，**滞留时间**为 $1/k$（[[#prop-box]]）。
- **分解**（[[#def-decomposition]]）经**矿化**释放养分；它受气候、凋落物质量与分解者群落控制。凋落物质量常近似按 $e^{-kt}$ 衰变（[[#prop-olson]]）。C:N 高于临界值（约20–30）的凋落物引起净**固持**。
- **碳**：大气（约900 Pg C）与陆地及海洋交换约200 Pg C yr⁻¹，故一个分子停留约4年，但多余部分会持续几个世纪。CO₂ 已从280 ppm 升到约425 ppm（2024年）；人类排放约一半已被陆地与海洋吸收。
- **氮**：固氮、氨化、硝化、反硝化与厌氧氨氧化，大多源于微生物；人为固氮（Haber–Bosch 法、豆科、燃烧）如今与陆地自然固氮相当或过之，造成富营养化、缺氧与 N₂O 排放。
- **磷**没有气相；它来自岩石风化，老土壤会变得受磷限制。磷通常限制淡水藻类（226号湖）。**Redfield 比** C:N:P = 106:16:1养分限制的指南。
:::

## 习题

::: exercise 滞留时间 {level=1 check="10"}
一湖含磷500 t，从集水区获得50 t yr⁻¹，又以同样的量随出水与沉积损失。湖中磷的滞留时间是多少年？
::: solution
$\tau = 500/50 = 10$ 年。

::: exercise 凋落物的半衰期 {level=1 check="ln(2)/0.2"}
松针以 $k = 0.2$ yr⁻¹ 分解。其半衰期是多少年？
::: solution
$\ln2/0.2 = 3.47$ 年。

::: exercise 稳态凋落物层 {level=1 check="2000"}
某北方针叶林年凋落量300 g m⁻²，分解常数0.15 yr⁻¹。凋落物层的稳态质量是多少 g m⁻²？
::: solution
$I/k = 300/0.15 = 2000$ g m⁻²。

::: exercise 从 ppm 到拍克 {level=1 check="2.12*140"}
大气 CO₂ 浓度已从工业时代前的约280 ppm 升至约420 ppm。以每 ppm 2.12 Pg C 计，大气增加了多少碳（以 Pg C 计）？
::: solution
$(420 - 280)\times2.12 = 140\times2.12 = 297$ Pg C。

::: exercise 临界 C:N {level=2 check="33.33"}
真菌分解者的生物量 C:N 为10，碳利用效率为0.3。凋落物的 C:N 高于何值时它们会固持氮？给出两位小数。
::: solution
临界比为 $10/0.3 = 33.33$。真菌的生物量 C:N 高于细菌、碳利用效率低于细菌，因此能分解 C:N 更高的凋落物而不固持氮——这也是真菌主导木材与贫瘠凋落物分解的原因之一。
:::
:::

::: exercise 解读 Hubbard Brook 实验 {level=2}
Hubbard Brook 的2号集水域林木砍尽、萌发被抑之后，溪水硝酸盐急剧升高，钙与钾的损失也随之升高。(a) 解释去除植被为何增加硝酸盐输出，并指出所涉的微生物过程。(b) 钙与钾的损失为何也随之增加？(c) 为什么要与一个未处理的参照集水域作比较，而不只是比较处理前后？
::: solution
(a) 分解与矿化继续（实际上加速了，因为没有树木蒸腾，土壤更暖更湿），产生铵，硝化细菌与古菌把铵氧化为硝酸盐。没有植物吸收，硝酸盐——一种移动性强的阴离子——便积累并淋入溪流，而增大的水流（没有蒸腾）带出更多。

(b) 硝化释放氢离子；它们把钙、钾阳离子从土壤颗粒的交换位点上置换下来，硝酸盐的淋失为维持电中性又把这些阳离子一并带走。没有植物吸收，阳离子也无从被截留。

(c) 溪水的化学随天气逐年变化；只作前后比较会把一个多雨的年份误当作处理效应。与同期调查的参照集水域作比较能扣除这类变异（前后-对照-影响设计）。
:::
:::

::: exercise 海洋中的养分限制 {level=2}
三个站位的海水有下列溶解无机氮与磷酸盐浓度（μmol L⁻¹）：(A) 氮0.1，磷0.05；(B) 氮25，磷1.6，叶绿素极低；(C) 氮2，磷0.5。就每一站推测什么限制浮游植物生长，以及如何检验。
::: solution
(A) N:P = 2，且两种养分都极低：可能受氮限制，典型于分层的亚热带环流（磷也接近受限）。检验：向培养的水样中加氮、加磷、两者都加，测定叶绿素的增长。

(B) N:P = 15.6，接近 Redfield，但两种养分都丰富而叶绿素低：高营养盐-低叶绿素区，可能受铁限制（或受牧食或光限制）。像 IronEx 那样用加铁来检验。

(C) N:P = 4：可能受氮限制，磷酸盐相对过剩。用加氮与加磷检验；固氮蓝细菌在此可能占了便宜。
:::
:::

::: exercise 土壤碳与变暖 {level=3}
某土壤碳库处于稳态，来自凋落物的输入 $I = 300$ g C m⁻² yr⁻¹，周转率 $k = 0.02$ yr⁻¹。(a) 库的大小与滞留时间各是多少？(b) 变暖使 $k$ 增加10 %而 $I$ 不变。新的稳态是多少？每平方米损失多少碳？(c) 若变暖同时提高植物生产力使 $I$ 上升10 %，结果如何？(d) 用 [[#eq-box-sol]] 粗略估计，损失掉(b) 中所失之碳的一半需要多久？
::: solution
(a) $X^* = I/k = 300/0.02 = 15\,000$ g C m⁻²；滞留时间 $1/k = 50$ 年。

(b) $k = 0.022$：$X^* = 300/0.022 = 13\,636$ g C m⁻²，损失1364 g C m⁻²（9 %），以 CO₂ 释放入大气——对变暖的正反馈。

(c) $X^* = 330/0.022 = 15\,000$：无净变化。结局取决于生产力与分解哪个对变暖响应更大，这正是土壤碳响应不确定的原因。

(d) 趋近新稳态的时间常数为 $1/k = 1/0.022 = 45$ 年；一半的变化在 $\ln2/0.022 = 31.5$ 年内发生。变暖所致的土壤碳损失以数十年计的尺度展开。
:::
:::

::: exercise 全湖实验 {level=3}
Schindler 在226号湖的实验中，一湖盆接受碳、氮与磷，另一湖盆接受碳与氮。(a) 为什么两边都加碳？(b) 为什么一个隔开成两半的湖比两个不同的湖更有说服力？(c) 该设计的主要弱点是什么？实验湖区其他湖泊的历史如何弥补它？(d) 后来在另一座湖的实验，施磷而氮逐渐减少，发现固氮蓝细菌增多。这对管理为何重要？
::: solution
(a) 曾有科学家主张，湖中限制藻类的是碳而非磷（因为溶解 CO₂ 少）。两湖盆都加碳就排除了这种可能，于是任何差异只能归于磷。

(b) 两湖盆共享气候、地质、历史与生物区系；比较两个分开的湖会把处理与它们之间的一切其他差异混杂在一起。

(c) 每个处理只有一个重复（n = 1），所以原则上结果可能反映两湖盆之间某种未知的差异。这一弱点因效应的巨大与一致、以及实验湖区其他湖泊随时间与其他湖泊的重复得到缓解——那些湖对加磷的反应相似。

(d) 只削减氮输入未必能减轻富营养化，因为只要磷可用，固氮蓝细菌就能从大气补足所缺的氮。因此对湖泊而言，控制磷必不可少。（在近岸与海洋系统，氮常更受限，故两者都可能需要控制。）
:::
