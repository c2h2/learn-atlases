在1798年，Thomas Malthus 就提出：人类种群若不加约束，便会以几何级数增长——倍增，然后再倍增——而供养它的食物无法跟上，因此增长迟早必然被饥荒、疾病或“道德约束”所遏制。Charles Darwin 于1838年读了《人口原理》（*Essay on the Principle of Population*），从中认出了驱动自然选择的生存斗争。Malthus 的论断有两半，它们正是本章的两半：任何种群都有指数增长的能力，而任何种群都无法长久地如此增长。

A **population** 是同一物种在同一时刻生活在同一区域、并有可能相互交配的个体群体。种群生态学追问其大小如何变化、为何变化。我们从记账开始——出生、死亡与迁移——以及**生命表**：它记录存活与繁殖如何依赖年龄，并把它们综合为一个增长率。然后我们导出指数增长与逻辑斯谛增长的模型，追问**密度依赖**是什么、如何检测，并理解调节中的时间滞后如何产生振荡、循环乃至混沌。[[ecology/life-histories]] 中讨论过其进化的生活史性状是这里的原材料：我们在此把它们当作给定，追问它们产生怎样的种群动力学。贯穿全章的数学是一阶差分方程与微分方程；如不熟悉，可参阅 Maths Atlas 中的[一阶方程](/learn/maths/lesson.php?c=ode&l=first-order)。

## 种群的记账

时刻 $t$ 大小为 $N_t$ 的种群因四种过程而变化：出生 $B$、死亡 $D$、迁入 $I$ 和迁出 $E$。在一个时间步内，

$$
N_{t+1} = N_t + B - D + I - E .
$$ {#eq-bide}

在**闭锁**种群中（无迁移），只有出生和死亡起作用。除以 $N_t$，每个个体的变化是个体平均出生率减去个体平均死亡率。此后的一切都关乎这些个体平均比率如何依赖年龄、依赖时间、并依赖种群自身的密度。

## 生命表

不同年龄的个体死亡或繁殖的机会并不相同。一株栎树幼苗今年死亡的可能性远高于四十年的大树，而且只有大树能结橡子。要预测种群的增长，我们需要逐年龄的这些比率。

::: definition 生命表 {#def-life-table}
**生命表**为每个年龄级 $x$（以年等单位计）列出以下内容：

- $n_x$：年龄级 $x$ 开始时同生群中存活的个体数；
- $l_x = n_x/n_0$：**存活率**：活到年龄 $x$ 的新生个体比例（故 $l_0 = 1$）；
- $d_x = n_x - n_{x+1}$：年龄级 $x$ 期间死亡的个体数，以及 $q_x = d_x/n_x$，**年龄特异性死亡率**；
- $m_x$（常写作 $b_x$）：**年龄特异性繁殖力**：年龄为 $x$ 的个体产生的平均后代数（对有性繁殖的物种通常按每只雌性产生的女儿数计）。

**同生群**（动态）生命表追踪一个同生群从出生到最后一名成员死亡；**静态**（或时间特定）生命表则假定出生率与死亡率恒定，由种群在某一时刻的年龄结构、或由一个样本的死亡年龄来估计 $l_x$。
:::

对能标记追踪的一年生植物和昆虫，同生群生命表不难编制；对长寿动物，静态生命表往往是唯一的选择。一个经典的静态生命表由 Edward Deevey 于1947年编制，材料是阿拉斯加盘羊（*Ovis dalli*）的死亡年龄——由 Adolph Murie 于1930年代通过其收集的头骨角上的生长轮估计而来。

把 $\log l_x$ 对年龄作图得到**存活曲线**，Raymond Pearl 于1928年引入的三种理想化形状被用来描述它们。**I 型**曲线中，死亡率直到老年之前都很低、然后陡升——医疗保健良好国家的人类、圈养中的许多大型哺乳动物。**II 型**曲线死亡率恒定，故 $\log l_x$ 沿直线下降——许多成年鸣禽大致如此。**III 型**曲线早期死亡率极高、此后很低——牡蛎、多数鱼类和树木，它们产生海量后代而其中极少存活。真实的存活曲线通常是混合的，常见早期 III 型、晚期 I 型，但三种形状是一套有用的词汇。

### 从生命表到增长率

::: proposition 净生殖率与世代时间 {#prop-r0}
由生命表的存活率 $l_x$ 与繁殖力 $m_x$ 两列，**净生殖率**——一名新生个体一生产生的平均后代数——为

$$
R_0 = \sum_x l_x m_x ,
$$ {#eq-r0}

而**同生群世代时间**——母亲产下其后代时的平均年龄——为

$$
T_c = \frac{\sum_x x\, l_x m_x}{R_0}.
$$ {#eq-gen-time}

种群若 $R_0 > 1$ 则增长、若 $R_0 < 1$ 则收缩。其每世代的倍增数为 $R_0$，故每单位时间的内禀增长率近似为

$$
r \approx \frac{\ln R_0}{T_c}.
$$ {#eq-r-approx}
:::

::: proof
新生个体以概率 $l_x$ 存活到年龄 $x$，若存活，则在该年龄产生 $m_x$ 个后代；对所有年龄求和期望贡献即得 [[#eq-r0]]。权重 $l_x m_x/R_0$ 构成随机选取的一个后代出生时母亲年龄的分布，故 [[#eq-gen-time]] 是其均值。若每个世代把种群乘以 $R_0$ 而一个世代历时 $T_c$，则 $N$ 按 $R_0^{t/T_c} = e^{(t/T_c)\ln R_0}$ 增长，即得 [[#eq-r-approx]]。这是近似的，因为世代重叠：年轻母亲的后代在年长母亲完成繁殖之前就开始繁殖。
:::

一个具有固定生命表的种群，其精确的增长率——一旦其年龄结构稳定下来——是 Leonhard Euler 于1760年导出、Alfred Lotka 在二十世纪初重新发现的一个单一方程的根。

::: proposition 欧拉–Lotka 方程 {#prop-euler-lotka}
具有恒定年龄特异性存活率 $l_x$ 与繁殖力 $m_x$ 的种群最终按增长率 $r$ 指数增长（或每单位时间乘以因子 $\lambda = e^r$），并具有固定的**稳定年龄分布**，其中 $r$ 是下式的唯一实根

$$
\sum_x e^{-rx}\, l_x m_x = 1 .
$$ {#eq-euler-lotka}
:::

::: proof
设 $B_t$ 为时刻 $t$ 的出生数。当前的出生来自 $x$ 个时间单位前出生、存活下来并在年龄 $x$ 繁殖的个体：$B_t = \sum_x B_{t-x}\, l_x m_x$。试取 $B_t = B_0 e^{rt}$：除以 $B_0 e^{rt}$ 得 $1 = \sum_x e^{-rx}l_x m_x$。左端是 $r$ 的严格减函数，从 $+\infty$ 降到 $0$（只要存在年龄 $x > 0$ 处至少一个正的 $l_x m_x$），故恰有一个实根。种群从任意初始年龄结构都实际趋于这一指数增长，这是更新理论的一个定理（或对下述 Leslie 矩阵而言，是 Perron–Frobenius 定理）；我们在此接受它。
:::

由 [[#eq-euler-lotka]] 注意，$r > 0$ 当且仅当 $\sum l_x m_x = R_0 > 1$，因为在 $r = 0$ 处左端等于 $R_0$。再注意：年幼时产生的后代价值更高：它们被 $e^{-rx}$ 打折。这就是为什么在增长的种群中选择如此强烈地偏爱早期繁殖——这一观点见 [[ecology/life-histories]]。

::: example 一个生命表 {#ex-life-table}
一个1000只田鼠的同生群自出生起被追踪。每个年龄年头开始时的存活数与每只雌性在各年龄产生的女儿平均数为：

| 年龄 $x$（年） | $n_x$ | $l_x$ | $m_x$ | $l_x m_x$ | $x\,l_x m_x$ |
|---|---|---|---|---|---|
| 0 | 1000 | 1.00 | 0 | 0 | 0 |
| 1 | 400 | 0.40 | 2 | 0.80 | 0.80 |
| 2 | 200 | 0.20 | 3 | 0.60 | 1.20 |
| 3 | 80 | 0.08 | 3 | 0.24 | 0.72 |
| 4 | 20 | 0.02 | 2 | 0.04 | 0.16 |
| 5 | 0 | 0 | — | — | — |

计算 $R_0$、$T_c$、近似的 $r$ 和精确的 $r$。
::: solution
对列求和，$R_0 = 0.80 + 0.60 + 0.24 + 0.04 = 1.68$：每只新生雌性平均留下1.68只女儿，故种群增长。世代时间为 $T_c = (0.80 + 1.20 + 0.72 + 0.16)/1.68 = 2.88/1.68 = 1.71$年。近似式 [[#eq-r-approx]] 给出 $r \approx \ln 1.68/1.71 = 0.519/1.71 = 0.303$每年。

为求精确值，我们数值求解 $\sum e^{-rx}l_x m_x = 0.80e^{-r} + 0.60e^{-2r} + 0.24e^{-3r} + 0.04e^{-4r} = 1$（代码见下）：$r = 0.320$每年，故 $\lambda = e^{0.320} = 1.377$——一旦年龄结构稳定，种群每年约乘以1.38。该近似低估 $r$ 约5 %，因为它忽略了世代重叠。

死亡率为 $q_0 = 600/1000 = 0.60$、$q_1 = 0.50$、$q_2 = 0.60$、$q_3 = 0.75$：第一年高，第二年较低，此后随年龄上升。
:::
:::

```python
import math

x  = [0, 1, 2, 3, 4]               # age class (years)
lx = [1.0, 0.4, 0.2, 0.08, 0.02]   # survivorship from birth
mx = [0, 2, 3, 3, 2]               # daughters per female of age x

def euler_lotka(r):
    """Left side of the Euler-Lotka equation minus 1."""
    return sum(math.exp(-r * a) * l * m for a, l, m in zip(x, lx, mx)) - 1

lo, hi = -1.0, 2.0                 # bracket for r (per year)
for _ in range(60):                # bisection: halve the bracket 60 times
    mid = (lo + hi) / 2
    if euler_lotka(mid) > 0:
        lo = mid                   # sum too large: r must be bigger
    else:
        hi = mid
r = (lo + hi) / 2
print(f"r = {r:.4f} per year, lambda = {math.exp(r):.4f}")
# r = 0.3202 per year, lambda = 1.3774
```

### 种群投影：Leslie 矩阵

生命表可以改造成向未来投影种群的机器。设 $n_t$ 为时刻 $t$ 各年龄级个体数的向量。每年，年龄 $i$ 的个体产生 $F_i$ 个新生儿，并以概率 $P_i$ 存活到下一个年龄级。以 Patrick Leslie 于1945年引入的矩阵形式，

$$
\begin{pmatrix} n_0 \\ n_1 \\ n_2 \end{pmatrix}_{t+1} =
\begin{pmatrix} F_0 & F_1 & F_2 \\ P_0 & 0 & 0 \\ 0 & P_1 & 0 \end{pmatrix}
\begin{pmatrix} n_0 \\ n_1 \\ n_2 \end{pmatrix}_{t} ,
\qquad n_{t+1} = A\,n_t .
$$ {#eq-leslie}

无论初始向量如何，经过足够多步后，种群每步按因子 $\lambda$ 增长，其中 $\lambda$ 是 $A$ 的主特征值，而各年龄级的比例趋于相应的特征向量——稳定年龄分布。（线性代数见 Maths Atlas 中的[特征值](/learn/maths/lesson.php?c=linear-algebra&l=eigenvalues)。）

::: example 用 Leslie 矩阵投影 {#ex-leslie}
一种小型哺乳动物有三个年龄级。新生儿（$n_0$）不繁殖，以概率 $P_0 = 0.5$ 存活到1岁；一岁个体每只产生 $F_1 = 2$ 个新生儿，并以 $P_1 = 0.4$ 存活到2岁；两岁个体产生 $F_2 = 1.5$ 个新生儿，随后死亡。从100个新生儿开始，投影该种群三年，并求 $\lambda$ 与稳定年龄分布。
::: solution
这里 $F_0 = 0$。从 $n_0 = (100, 0, 0)$ 出发：

- 第1年：$(2\cdot0 + 1.5\cdot0,\; 0.5\cdot100,\; 0.4\cdot0) = (0, 50, 0)$，总数50；
- 第2年：$(2\cdot50,\; 0,\; 0.4\cdot50) = (100, 0, 20)$，总数120；
- 第3年：$(1.5\cdot20,\; 0.5\cdot100,\; 0) = (30, 50, 0)$，总数80。

起始种群远离稳定年龄分布，故总数波动。就长期增长而言，特征方程 $\det(A - \lambda I) = 0$ 即 $\lambda^3 = F_1P_0\lambda + F_2P_0P_1 = 1.0\lambda + 0.3$，其正根为 $\lambda = 1.125$（试算或二分：$1.125^3 = 1.424$，而 $1.125 + 0.3 = 1.425$）。种群最终每年增长12.5 %，$r = \ln\lambda = 0.118$。稳定年龄分布正比于 $(1, P_0/\lambda, P_0P_1/\lambda^2) = (1, 0.444, 0.158)$，即62 %新生儿、28 %一岁个体和10 %两岁个体。继续投影可证实其：到第12年，向量为 $(190.8, 80.4, 30.8)$，比例为0.63、0.27、0.10。
:::
:::

矩阵模型是应用种群生态学的主力工具。分级可以是阶段（种子、莲座、开花植株）而非年龄，而 $\lambda$ 对每个矩阵元素的**敏感度**告诉管理者哪个生命表参数最重要。Deborah Crouse、Larry Crowder 和 Hal Caswell（1987）对红海龟的著名应用表明，若不提高海洋中大个体幼龟和成龟的存活率，仅保护产卵滩上的卵无法拯救衰退的种群——这促成了美国对拖网虾船加装海龟逃逸装置的要求。

## 指数增长

若每个个体都有相同且恒定的个体平均比率，种群便指数增长。对在离散季节繁殖的种群与出生死亡连续发生的种群，分别使用两个版本。

::: proposition 几何级数增长与指数增长 {#prop-exponential}
(a) **离散世代。** 若世代 $t$ 的每个个体被世代 $t+1$ 的 $\lambda$ 个个体取代，则 $N_{t+1} = \lambda N_t$ 且

$$
N_t = N_0\,\lambda^t .
$$

(b) **连续增长。** 若个体平均出生率 $b$ 与死亡率 $d$ 恒定，且 $r = b - d$ 为**内禀增长率**，则

$$
\frac{dN}{dt} = rN, \qquad N(t) = N_0 e^{rt}.
$$ {#eq-exp}

当 $\lambda = e^r$ 时，两者在整数时刻一致。若 $r > 0$（$\lambda > 1$）则种群增长，**倍增时间**为 $t_d = \ln 2/r$；若 $r < 0$ 则下降。假设：无迁移、个体平均比率恒定（无密度依赖、无环境波动）、以及稳定年龄分布（或无年龄结构）。
:::

::: proof
(a) 迭代 $N_{t+1} = \lambda N_t$。(b) 在短区间 $\Delta t$ 内有 $bN\,\Delta t$ 个出生和 $dN\,\Delta t$ 个死亡，故 $\Delta N = (b - d)N\,\Delta t$；令 $\Delta t \to 0$ 得微分方程，其解经变量分离为 $\ln N = rt + \text{常数}$，即 $N = N_0e^{rt}$。令 $N_0e^{rt_d} = 2N_0$ 得 $t_d = \ln 2/r$。
:::

指数增长是种群生态学的零模型，相当于牛顿第一定律或 Hardy–Weinberg 平衡比例：它说的是没有任何东西限制增长时会发生什么。它只是短暂地实现于正在拓殖空旷生境的种群：新鲜培养基中的细菌（见 [[microbiology/microbial-growth]]）、入侵新大陆的物种、1944年被引入白令海圣马修岛的驯鹿——它们从29头增长到1963年的约6000头，然后崩溃到几十头。

::: example 倍增时间 {#ex-doubling}
(a) 一个蚜虫种群以每天 $r = 0.25$ 增长。其倍增时间是多少？30天里乘以多少？(b) 2024年世界人口约82亿，以每年略低于1 %的速度增长（联合国，*World Population Prospects 2024*）。若按每年恒定1 %，其倍增时间应是多少？
::: solution
(a) $t_d = \ln 2/0.25 = 0.693/0.25 = 2.77$天。30天里种群乘以 $e^{0.25\times30} = e^{7.5} \approx 1800$。

(b) $t_d = 0.693/0.01 = 69$年。（“70法则”：倍增年数约等于70除以百分比增长率。）事实上人类人口增长自1960年代以来一直在放缓，当时达到峰值——每年超过2 %，而联合国2024年的预测认为人口将在2080年代达到约103亿的峰值；恒定增长只是一个方便的计算，不是预测。
:::
:::

## 增长的上限：逻辑斯谛模型

没有种群能长久指数增长。随着变得拥挤，每个个体的资源下降，出生减少或死亡上升。把这一点纳入的最简单方式，是让个体平均增长率随密度线性下降，并在上限 $K$ 处降到零。

::: proposition 逻辑斯谛方程 {#prop-logistic}
若个体平均增长率随种群大小从 $N = 0$ 处的 $r$ 线性下降到 $N = K$ 处的零，则

$$
\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right),
$$ {#eq-logistic}

其中 $K$ 为**环境容纳量**。对 $0 < N_0$ 其解为

$$
N(t) = \frac{K}{1 + \left(\dfrac{K - N_0}{N_0}\right)e^{-rt}},
$$ {#eq-logistic-sol}

一条 S 形（sigmoid）曲线，若 $N_0 < K$ 则上升至 $K$（若 $N_0 > K$ 则下降至 $K$）。平衡点 $N^* = K$ 稳定而 $N^* = 0$ 不稳定。当 $N = K/2$ 时种群增长最快，速率为 $rK/4$。假设：无年龄结构的闭锁种群、恒定的 $r$ 和 $K$、以及密度对个体平均增长的瞬时线性效应。
:::

::: proof
方程可分离。写出 $\dfrac{dN}{N(1 - N/K)} = r\,dt$ 并用部分分式，$\dfrac{1}{N(1-N/K)} = \dfrac1N + \dfrac{1}{K - N}$，故 $\ln\dfrac{N}{K - N} = rt + c$。于是 $\dfrac{N}{K - N} = \dfrac{N_0}{K - N_0}e^{rt}$；解出 $N$ 即得 [[#eq-logistic-sol]]。当 $t\to\infty$，$e^{-rt}\to0$ 且 $N\to K$。增长率 $f(N) = rN - rN^2/K$ 是开口向下的抛物线，$f'(N) = r - 2rN/K = 0$ 在 $N = K/2$ 处，此处 $f = rK/4$。在 $N = K$ 附近，$f'(K) = -r < 0$，故小偏离收缩（稳定）；在 $0$ 附近，$f'(0) = r > 0$，故偏离增大（不稳定）。
:::

逻辑斯谛方程由 Pierre-François Verhulst 于1838年提出，并由 Raymond Pearl 和 Lowell Reed 于1920年重新发现，他们将其拟合到美国人口普查人口。其最好的实验室拟合来自微生物：Georgii Gause 在1930年代初的酵母与 *Paramecium* 培养物沿漂亮的 S 形曲线增长。

::: widget slopefield
f: r*y*(1 - y/K)
x: 0, 25
y: -10, 160
sliders: r=0.5:0.1:1.5:0.05; K=100:40:140:5
points: 0, 5; 0, 40; 0, 150
caption: 逻辑斯谛方程作为方向场，横轴为时间 $t$（此处以天计），纵轴为种群大小 $N$。每条从 $K$ 以下开始的解曲线都是 S 形，在穿过 $N = K/2$ 处最陡；从 $K$ 以上开始的曲线下降到它。点击可开始一条新解曲线，并可改变 $r$（逼近的快慢）和 $K$（终点所在）。直线 $N = 0$ 是不稳定平衡：任何正种群都会离开它。
:::

::: example 酵母培养物的逻辑斯谛增长 {#ex-logistic}
一个培养物以每单位体积 $N_0 = 10$ 个细胞开始，$r = 0.5$ 每小时，$K = 1000$。达到容纳量之半需要多久？最大增长速率是多少？
::: solution
在 [[#eq-logistic-sol]] 中令 $N(t) = K/2$ 要求 $\left(\frac{K - N_0}{N_0}\right)e^{-rt} = 1$，故

$$
t = \frac1r\ln\frac{K - N_0}{N_0} = \frac{1}{0.5}\ln 99 = 2\times4.595 = 9.19\ \text{小时}.
$$

此处的增长速率即最大值，$rK/4 = 0.5\times1000/4 = 125$，即每小时每单位体积125个细胞。
:::
:::

::: warning "环境容纳量是环境的固定属性"
$K$ 是模型的一个参数，不是自然常数。一个环境所能供养的个体数，取决于逐年变化的可用资源、种群自身对这些资源的影响、以及捕食者、寄生物和竞争者。真实种群会在任何固定 $K$ 附近波动、越过它或永远达不到它。同样，逻辑斯谛模型假定个体平均增长随密度*线性*下降只是一种方便；数据常显示非线性和滞后的响应。
:::

## 密度依赖与种群调节

逻辑斯谛模型体现了一个更一般的思想：个体平均出生率与死亡率取决于种群自身的密度。

::: definition 密度依赖与调节 {#def-density-dependence}
个体平均人口学比率若在种群密度变化时改变，则它是**密度依赖的**：个体平均出生率随密度上升而下降、或个体平均死亡率随密度上升而上升（**负**密度依赖），或相反（**正**密度依赖，即**阿利效应**）。效应不随密度改变的因素——例如一场严霜，无论种群大小都杀死相同比例——是**密度无关的**。若负密度依赖使种群在偏离平衡点或有界范围后趋于回到其中，则该种群是**受调节的**。
:::

只有密度依赖的过程能调节种群；密度无关的过程能使其波动、有时剧烈，却不能把它约束在范围之内。这是二十世纪中叶一场长期争论的核心。Alexander Nicholson 在澳大利亚研究丽蝇，主张密度依赖（例如通过食物竞争）才是把种群保持在范围内的力量。Herbert Andrewartha 和 Charles Birch 研究了阿德莱德玫瑰上的蓟马 *Thrips imaginis*——其逐年数量仅凭天气就能很好地预测——之后主张密度无关因素决定了多度。现代的结论是两者都重要：天气驱动了许多种群年间变动的大部分，而密度依赖——常常作用微弱或只在高密度时起作用——使它们不至漂向灭绝或无穷。

### 检测密度依赖

直接的检验是把种群的个体平均增长率对其密度作图。对逻辑斯谛，个体平均增长率是一条直线，

$$
\frac{1}{N}\frac{dN}{dt} = r - \frac{r}{K}N ,
$$ {#eq-percapita}

截距为 $r$，与横轴的截距为 $K$。用普查数据，一个区间上的个体平均增长率估计为 $\ln(N_{t+1}/N_t)$。

::: example 由普查数据估计 r 和 K {#ex-regression}
一系列以不同密度设置的实验缸中的水蚤种群给出了如下个体平均增长率（每天）：

| $N$（每缸数百个） | 0.5 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 | 3.5 | 4.0 | 4.5 |
|---|---|---|---|---|---|---|---|---|---|
| 个体平均增长率 | 0.46 | 0.41 | 0.33 | 0.29 | 0.26 | 0.19 | 0.16 | 0.11 | 0.04 |

拟合一条直线并估计 $r$ 和 $K$。
::: solution
增长率 $y$ 对 $N$（以百计）的最小二乘回归给出 $y = 0.502 - 0.1007N$，$R^2 = 0.99$。由 [[#eq-percapita]]，截距为 $r \approx 0.50$每年，直线在 $N = 0.502/0.1007 = 4.98$百处降为零，故 $K \approx 500$每缸个体。负斜率是负密度依赖的标志。回归本身见 [[biostatistics/regression]]；用野外普查数据存在一个统计陷阱：测量 $N_t$ 的误差会同时出现在两个轴上，可能产生虚假的负斜率，因此对时间序列检验密度依赖需要专门的方法。
:::
:::

### 阿利效应

在极低密度下，个体平均增长可能随密度*增加*：个体可能找不到配偶、无法相互授粉、无法压垮宿主的防御、或无法依靠群体抵御捕食者。这种正密度依赖称为**阿利效应**，得名于在1930年代描述它的 Warder Clyde Allee。一个简单的模型是

$$
\frac{dN}{dt} = rN\left(\frac{N}{A} - 1\right)\left(1 - \frac{N}{K}\right), \qquad 0 < A < K ,
$$ {#eq-allee}

其中低于**阿利阈值** $A$ 的种群衰减至灭绝，高于它的种群增长趋向 $K$。阿利效应在保护上很重要，因为被削减到阈值以下的种群即使原有威胁消除后仍可能继续下降；在入侵物种治理上也很重要，因为消灭一小支入侵种群的大部分可能就足够了。

::: widget plot
f: r*x*(1 - x/K); r*x*(x/A - 1)*(1 - x/K)
x: 0, 120
sliders: r=0.5:0.1:1:0.05; K=100:60:120:5; A=20:5:50:1
hlines: 0
labels: \text{逻辑斯谛}; \text{含阿利效应}
caption: 种群增长速率 $dN/dt$（个体每单位时间）对种群大小 $N$ 的图。曲线位于轴上方的地方种群增长；下方则收缩。对逻辑斯谛，增长在 $N = K/2$ 处最快；有阿利效应时，阈值 $A$ 以下增长率为负，小种群因而衰至灭绝。把 $A$ 向 $K$ 调高，注意正增长区域如何缩小。
:::

## 时间滞后、循环与混沌

逻辑斯谛模型假定密度瞬时影响增长。现实中存在延迟：食物充足时产下的卵孵化成幼虫时食物已短缺；植物对上一年的养分吸收作出反应。调节中的延迟使种群越过其平衡点而振荡。

### 离散世代

许多生物——一年生植物、温带昆虫——每年在离散的季节繁殖一次，密度的效应在一个世代与下一个世代之间起作用。一个广泛使用的模型是 William Ricker（1954）为鱼类资源开发的：

$$
N_{t+1} = N_t\exp\!\left[r\left(1 - \frac{N_t}{K}\right)\right].
$$ {#eq-ricker}

其平衡点为 $N^* = K$，但其稳定性取决于 $r$。在 $K$ 附近线性化，小偏离 $\varepsilon_t = N_t - K$ 每代乘以 $1 - r$。若 $0 < r < 1$，种群平滑地趋于 $K$；若 $1 < r < 2$，它越过 $K$ 并以衰减振荡趋近；若 $r > 2$，偏离增大，种群进入稳定的2点循环，随 $r$ 进一步增大又出现4点循环，如此经倍周期级联直至 $r$ 超过约2.69时的**混沌**。在混沌区，种群非周期地波动，两条从几乎相同大小出发的轨线迅速发散，使得长期预测不可能，尽管模型完全确定。

sliders: r=1.5:0.5:3:0.01

caption: 以 $K$ 为单位度量种群的 Ricker 模型（故 $N^* = 1$），以蛛网图绘制：曲线是 $N_{t+1}$ 对 $N_t$，阶梯沿世代追踪种群。$r = 1.5$ 时种群螺旋收向 $K$。把 $r$ 调过2可见2周期，调过约2.53见4周期，约2.7以上为混沌。分岔图展示了每个 $r$ 值对应的长期种群大小。
:::

Robert May 在1974年发表于 *Science* 的一篇论文和1976年发表于 *Nature* 的综述《具有极复杂动力学的简单数学模型》中引起了生态学家对这一行为的注意，该综述也帮助开启了更广的混沌研究。波动不定未必由环境不定引起的这一认识，改变了人们解读种群数据的方式。混沌在真实种群中有多普遍仍有争论：多数野外种群似乎处于稳定或衰减区的动力学，但 Robert Costantino、Jim Cushing 及其同事在1990年代的实验中，已在粉甲（*Tribolium*）的实验室种群中、以及在一个长期维持的围隔海洋浮游生物群落中证实了混沌动力学。

### 连续时间加延迟

在连续时间中，George Evelyn Hutchinson 于1948年提出，当前影响增长的密度是 $\tau$ 一段时间之前的密度：

$$
\frac{dN}{dt} = rN(t)\left(1 - \frac{N(t - \tau)}{K}\right).
$$ {#eq-delay}

对这个时滞微分方程的分析表明：当 $r\tau < 1/e \approx 0.37$ 时 $K$ 被无振荡地趋近；当 $1/e < r\tau < \pi/2$ 时为衰减振荡；而当 $r\tau > \pi/2 \approx 1.57$ 时种群进入稳定循环（极限环），其周期约为延迟的四倍。乘积 $r\tau$——反应速度乘以延迟——才是要害：对早已过时的条件反应迅速的种群会振荡。Nicholson 的绵羊丽蝇 *Lucilia cuprina* 实验室种群——成虫食物受限——表现出周期约35–40天的持续循环，May 等人后来用这一模型作了解释。

::: quiz
在 Ricker 模型 [[#eq-ricker]] 中，哪种改变会使种群*更*可能振荡或表现出混沌行为？
- [x] 提高内禀增长率 $r$
- [ ] 提高环境容纳量 $K$
- [ ] 把密度依赖的强度降为零
- [ ] 从更小的种群开始
::: solution
稳定性只取决于 $r$，通过小偏离每代乘以的因子 $1 - r$。大的 $r$ 意味着强过补偿：略高于 $K$ 的种群会跌到它下方很远处，反之亦然。$K$ 只是设定尺度，初始大小只影响瞬态。没有密度依赖就根本没有平衡点——种群指数增长。
:::
:::

::: intuition 过补偿
把密度依赖想象成恒温器。好的恒温器按温度偏离设定点的比例作出反应并立即行动。若它反应过度——房间偏低一度就把暖气开到最大——房间就会过冲，系统便振荡。延迟也有同样的效果：等到暖气起效，房间已经过热。高繁殖率的种群（$r$ 大）是反应过度的恒温器；调节作用于上一季密度的种群是延迟的恒温器。两者都振荡。
:::

::: application 收获与最大持续产量
若种群逻辑斯谛增长，其增长速率在 $N = K/2$ 处最大，为 $rK/4$（[[#prop-logistic]]）。原则上，一个渔场或森林可以按这一速率被无限期收获，办法是把种群维持在容纳量之半：**最大持续产量**（MSY）。若 $r = 0.5$ 每年、$K = 1000$ t，则 MSY 为每年125 t。这一概念是二十世纪渔场管理的核心，而其失败颇有教益。若收获是略高于 MSY 的固定配额，种群将衰减至灭绝；若资源量被高估，或 $r$、$K$ 因环境变化而下降，按估计的 MSY 设定的配额就会过度捕捞；而真实资源有年龄结构、时间滞后和阿利效应，这些都是逻辑斯谛模型所忽略的。秘鲁鳀渔场在1972年——一个厄尔尼诺年——的崩溃，以及纽芬兰外海的北方鳕鱼于1992年关闭商业捕捞，都是标准的警示。现代管理采用更审慎的目标并明确计入不确定性；被收获种群和小种群的保护见 [[conservation-biology/small-populations]]。
:::

::: history
Malthus 的《人口原理》（1798）和 Verhulst 的逻辑斯谛方程（1838）是关于种群增长最早的数学表述。Raymond Pearl 自1920年起推广逻辑斯谛方程，Pearl 还引入了存活曲线的三种类型（1928）。欧拉–Lotka 方程可追溯到欧拉（1760），由 Alfred Lotka 在1907至1920年代的文章奠定坚实基础；Patrick Leslie 于1945年引入矩阵形式。1930年代，Georgii Gause 在微生物培养中检验了逻辑斯谛增长，Warder Clyde Allee 描述了正密度依赖。1950年代 Nicholson 与 Andrewartha、Birch 之间关于密度依赖作用的争论为此后数十年的野外研究定了议程，而 Robert May 关于混沌的工作（1974–1976）改变了对种群波动的解读。
:::

## 由此引向何处

单物种模型是后两章的构件。[[ecology/competition]] 把两个逻辑斯谛方程耦合起来，每个种群的增长都受另一物种密度的削减；[[ecology/predation-parasitism]] 则把猎物增长与捕食者消耗耦合起来，产生与此处不同的循环。收获、小种群与灭绝风险在 [[conservation-biology/small-populations]] 展开，疾病传播的动力学在 [[ecology/predation-parasitism]]。

::: summary
- 种群因出生、死亡、迁入和迁出而变化（[[#eq-bide]]）。
- **生命表**（[[#def-life-table]]）逐年龄给出存活率 $l_x$ 与繁殖力 $m_x$；$R_0 = \sum l_x m_x$，世代时间 $T_c = \sum x l_x m_x/R_0$，$r \approx \ln R_0/T_c$（[[#prop-r0]]）。精确的 $r$ 解**欧拉–Lotka 方程** $\sum e^{-rx}l_xm_x = 1$（[[#prop-euler-lotka]]）。存活曲线分为 I、II、III 型。
- **Leslie 矩阵**投影年龄结构种群；其主特征值是 $\lambda$，特征向量是稳定年龄分布。
- 个体平均比率恒定时，种群**指数**增长：$N = N_0e^{rt}$，倍增时间 $\ln2/r$（[[#prop-exponential]]）。
- **逻辑斯谛**模型 $dN/dt = rN(1 - N/K)$ 给出升至稳定容纳量的 S 形增长，$K/2$ 处最快（[[#prop-logistic]]）；它是一个带有强假设的模型，不是定律。
- **密度依赖**（[[#def-density-dependence]]）是调节所必需的；它表现为个体平均增长随密度而下降。**阿利效应**使小种群衰退。
- 滞后或过补偿的密度依赖产生衰减振荡、循环与**混沌**（Ricker 模型 $r > 2$；Hutchinson 延迟模型 $r\tau > \pi/2$）。
:::

## 习题

::: exercise 净生殖率 {level=1 check="1.1"}
一个同生群生命表有 $l_1 = 0.5$、$l_2 = 0.3$、$l_3 = 0.1$，繁殖力 $m_1 = 1$、$m_2 = 2$、$m_3 = 0$（且 $m_0 = 0$）。计算 $R_0$。
::: solution
$R_0 = 0.5\times1 + 0.3\times2 + 0.1\times0 = 0.5 + 0.6 = 1.1$，故种群缓慢增长，每代约10 %。
:::

::: exercise 倍增时间 {level=1 check="ln(2)/0.04"}
一个种群以 $r = 0.04$ 每年指数增长。其倍增时间是多少年？
::: solution
$t_d = \ln 2/0.04 = 17.3$年。
:::
:::

::: exercise 最大持续产量 {level=1 check="250"}
一个逻辑斯谛增长的鱼类资源有 $r = 0.4$ 每年、$K = 2500$ t。其最大持续产量是多少吨每年？
::: solution
$rK/4 = 0.4\times2500/4 = 250$，即每年250 t，办法是把资源维持在 $K/2 = 1250$ t。
:::
:::

::: exercise 从 λ 到 r {level=1 check="ln(1.5)"}
一个一年生植物种群每年乘以 $\lambda = 1.5$。等价的连续速率 $r$（每年）是多少？
::: solution
$r = \ln\lambda = \ln1.5 = 0.405$每年。
:::
:::

::: exercise 逻辑斯谛的时间 {level=2 check="ln(9)/0.2"}
一个 $r = 0.2$ 每年、$K = 500$ 的逻辑斯谛增长种群从 $N_0 = 50$ 开始。多少年后达到250？
::: solution
由 [[#eq-logistic-sol]]，当 $e^{-rt} = N_0/(K - N_0) = 50/450 = 1/9$ 时 $N = K/2$，故 $t = \ln 9/0.2 = 2.197/0.2 = 11.0$年。
:::
:::

::: exercise 解读存活曲线 {level=2}
在对数纵轴上草绘你预期的存活曲线：(a) 一个栎树种群，(b) 一组羽化后的成年鸣禽同生群，(c) 动物园中一种大型哺乳动物的种群。对 (a)，解释这一形状为何意味着种群的绝大部分繁殖来自极少数出生的个体，以及这对终生繁殖成功率的方差意味着什么。
::: solution
(a) III 型：$\log l_x$ 头几年陡降（多数橡子和幼苗死亡），然后趋平。(b) 大致 II 型：一条直线，年死亡率恒定。(c) I 型：直到老年前平坦，然后陡降。(a) 中，只有熬过早期阶段的极少数个体才繁殖，且此后繁殖数十年：几乎每个出生的个体终生繁殖成功率为零，而少数个体成功巨大。终生繁殖成功率的方差因此巨大，这也使有效种群远小于普查大小——这是 [[population-genetics/genetic-drift]] 的主题之一。
:::
:::

::: exercise Leslie 矩阵 {level=2}
一种植物有两个阶段：幼体（0岁）和成体。幼体以概率0.25存活成为成体且不繁殖。成体每只每年产生3个幼体，并以概率0.5存活。写出投影矩阵，求 $\lambda$，并判断种群是否增长。哪种改变更能提高 $\lambda$：把幼体存活率提高到0.35，还是把成体繁殖力提高到4？
::: hint
成体保持为成体，故矩阵为 $\begin{pmatrix} 0 & F \\ P_J & P_A\end{pmatrix}$。其特征值解 $\lambda^2 - P_A\lambda - FP_J = 0$。
:::
::: solution
$A = \begin{pmatrix} 0 & 3 \\ 0.25 & 0.5 \end{pmatrix}$。特征方程为 $\lambda^2 - 0.5\lambda - 0.75 = 0$，故 $\lambda = \tfrac12\left(0.5 + \sqrt{0.25 + 3}\right) = \tfrac12(0.5 + 1.803) = 1.151$。种群每年增长约15 %。

取 $P_J = 0.35$：$\lambda^2 - 0.5\lambda - 1.05 = 0$，$\lambda = \tfrac12(0.5 + \sqrt{4.45}) = \tfrac12(0.5 + 2.110) = 1.305$。取 $F = 4$：$\lambda^2 - 0.5\lambda - 1.0 = 0$，$\lambda = \tfrac12(0.5 + \sqrt{4.25}) = \tfrac12(0.5 + 2.062) = 1.281$。把幼体存活率提高到0.35带来更大的增幅——幼体存活率提高40 %对比繁殖力提高33 %，而两者在方程中只以其乘积 $FP_J$ 进入。
:::

::: exercise 存在密度依赖吗 {level=2}
十年间，一种小型哺乳动物的密度（每公顷）依次为：12, 30, 18, 25, 21, 24, 22, 23, 22, 23。计算前三个区间的 $\ln(N_{t+1}/N_t)$，并描述整个序列的格局。你认为它显示什么动力学？对 Ricker 模型中的 $r$ 有何提示？
::: solution
$\ln(30/12) = 0.92$、$\ln(18/30) = -0.51$、$\ln(25/18) = 0.33$。种群小时个体平均增长率高、大时为负；种群过冲（12 → 30），然后欠冲（30 → 18），摆动越来越小，收敛到每公顷约22–23。这是围绕平衡点的衰减振荡，在 Ricker 模型中发生于 $1 < r < 2$——强但不混沌的过补偿。10个点的序列很短，而密度估计的误差可能夸大表观的密度依赖。
:::
:::

::: exercise 阿利阈值 {level=3}
对 $A = 20$、$K = 100$ 的阿利模型 [[#eq-allee]]：(a) 列出平衡点并指出哪些稳定；(b) 一个150的种群被收获削减到15，接下来会怎样？(c) 一位保护管理者可以消除一个降低 $K$ 的威胁，或向种群转移个体。当 $N < A$ 时哪个更紧迫，为什么？
::: solution
(a) $dN/dt = 0$ 在 $N = 0$、$N = A = 20$ 和 $N = K = 100$。对 $0 < N < 20$，$(N/A - 1) < 0$ 而 $(1 - N/K) > 0$，故 $dN/dt < 0$；对 $20 < N < 100$ 两个括号都为正而 $dN/dt > 0$；100以上 $dN/dt < 0$。故0和100稳定而20不稳定。

(b) 从150出发，种群本应下降到100，但在15时它低于阈值：即使停止收获，它也会衰至灭绝。

(c) 在 $A$ 以下，提高 $K$ 不改变增长率的符号（种群仍然下降），而转移足够多的个体使 $N$ 超过 $A$ 则使其增长。增殖放归是紧迫的；消除威胁同样必要，以保住长期的环境容纳量。
:::
:::

::: exercise 延迟与振荡 {level=3}
一个种群遵循 Hutchinson 的延迟逻辑斯谛 [[#eq-delay]]，$r = 0.3$ 每周。(a) 延迟 $\tau$（以周计）在什么范围内它无振荡地趋于 $K$、以衰减振荡趋近、以及进入持续循环？(b) 若 $\tau = 8$ 周时发生循环，周期大约多长？(c) 从生物学上解释为什么控制稳定性的是乘积 $r\tau$，而不是单独的 $r$ 或 $\tau$。
::: solution
(a) $r\tau < 1/e$ 时单调趋近：$\tau < 0.368/0.3 = 1.23$周。$1.23 < \tau < (\pi/2)/0.3 = 5.24$周时为衰减振荡。$\tau > 5.24$周时为持续循环。

(b) 周期约为 $4\tau = 32$周（这是阈值附近的近似；$r\tau$ 更大时周期会略增）。

(c) $r$ 度量种群每单位时间变化多快；$\tau$ 是其关于密度的信息过时多久。在延迟期间，种群在调节作出反应之前大致变化 $e^{r\tau}$ 倍。增长缓慢而延迟长的种群，与增长快而延迟短的种群，失稳程度相同：要害是种群在密度赶上它之前能改变多少。
:::
