1963年，Robert Paine 开始从华盛顿州太平洋海岸 Mukkaw Bay 的一段岩礁海岸上移走海星。每隔几周，他都把大约8 m 长、2 m 高的一片区域里他能找到的每一只 *Pisaster ochraceus* 撬下来，扔回海中。在相邻的一片对照区里他不去动它们。几个月内，海星的主要猎物——贻贝 *Mytilus californianus*——开始在被清空的区域上蔓延，压过并挤走了藤壶、帽贝、石鳖与海藻。到1966年，移除区的物种数已从15降到8。移除一种只吃群落中少数几种的捕食者，竟使群落的多样性减半。

Paine 的实验表明群落中的物种是相互联结的：一个物种的效应可以经由其他物种传到它从未触碰的物种。本章把**群落**当作整体来处理。我们先说明如何度量它的多样性；然后引入第三大类相互作用**互利共生**，并把相互作用组装成**食物网**，谈其中的关键种与营养级联，并追问复杂性能否使群落更稳定；我们随时间跟踪群落在干扰之后经由**演替**的恢复；最后以本章标题中的问题作结：是什么控制着一个群落容纳多少物种？作为成对构件的竞争与捕食，已在 [[ecology/competition]] 与 [[ecology/predation-parasitism]] 中处理。

## 什么是群落？

::: definition 群落、丰富度与多样性 {#def-community}
生态**群落**是在同一空间与时间中共现、并可能相互作用的不同物种诸种群的集合。实践中，群落通常由一个类群（一片林子的鸟类群落）或一处地点（一片岩池的群落）来界定。**物种丰富度** $S$ 是存在的物种数。**物种多样性**把丰富度与**均匀度**——个体（或生物量）在物种之间分布的均匀程度——结合起来。给定属于每一物种 $i = 1, \ldots, S$ 的个体比例 $p_i$：

- **Shannon 指数**为 $H' = -\sum_i p_i\ln p_i$；
- **Simpson 指数**为 $D = \sum_i p_i^2$，即随机（有放回）抽取的两个个体属于同一物种的概率；多样性以 $1 - D$（Gini–Simpson 指数）或 $1/D$ 报告；
- **Pielou 均匀度**为 $J = H'/\ln S$，当所有物种同等丰富时它等于1。
:::

两个指数都按丰度给物种加权，但方式不同：Simpson 指数被最常见的物种主导，Shannon 指数给稀有种更大的权重，而丰富度对每一物种都同等计数，无论多么稀少。比较两者的一个有用办法，是把每个指数转化为一个**有效物种数**——产生同样数值所需的同等丰富物种的数目：Shannon 为 $e^{H'}$，Simpson 为 $1/D$。这些“Hill 数”由 Mark Hill 于1973年引入，单位相同（物种），可以直接比较。

::: example 比较两个群落 {#ex-diversity}
两块样地各有100头甲虫、4个物种。样地 A 的计数是25、25、25与25；样地 B 是85、5、5与5。计算各自的丰富度、Shannon 指数、Gini–Simpson 指数、均匀度与有效物种数。
::: solution
两者的 $S = 4$。

样地 A：每个 $p_i = 0.25$，故 $H' = -4\times0.25\ln0.25 = \ln4 = 1.386$；$D = 4\times0.25^2 = 0.25$，故 $1 - D = 0.75$；$J = 1.386/\ln4 = 1$；有效物种数 $e^{1.386} = 4.0$ 与 $1/D = 4.0$。

样地 B：$H' = -(0.85\ln0.85 + 3\times0.05\ln0.05) = -(0.85\times(-0.1625) + 3\times0.05\times(-2.996)) = 0.138 + 0.449 = 0.588$；$D = 0.85^2 + 3\times0.05^2 = 0.7225 + 0.0075 = 0.73$，故 $1 - D = 0.27$；$J = 0.588/1.386 = 0.42$；有效物种数 $e^{0.588} = 1.80$ 与 $1/D = 1.37$。

两块样地丰富度相同，但样地 B 的多样性低得多：按 Shannon 度量，它像一个由1.8个同等常见物种组成的群落；按 Simpson 度量，像1.4个的群落。Simpson 的值更低，因为它被极常见的物种主导。
:::
:::

因为稀有种很容易被漏掉，观察到的丰富度取决于取样强度：计数的个体越多，发现的物种越多。为了使比较公平，使用**物种累积曲线**（发现的物种数对个体数或样本数）与**稀疏化**（在共同样本量下比较群落），统计估计量则外推到存在而未见的物种数。

## 互利共生

::: definition 互利共生与其他相互作用 {#def-mutualism}
物种之间成对的相互作用可以按每一方对另一方适合度或种群增长之效应的符号来分类：**竞争** $(-,-)$、**捕食、植食与寄生** $(+,-)$、**互利共生** $(+,+)$、**偏利共生** $(+,0)$ 与**偏害共生** $(-,0)$。若某一伙伴离了它就活不下去或不能繁殖，该互利共生对它便是**专性**的；如果可以，便是**兼性**的。当伙伴们一生中大部分时间紧密共居时，这种关系称为**共生**，此词兼指寄生性与互利性的联合。
:::

互利共生无处不在。绝大多数陆生植物与真菌形成**菌根**，真菌延伸了植物的根系、供给磷与其他养分，换取糖类。豆科植物在根瘤中寄居固氮**根瘤菌**（[[ecology/nutrient-cycles]]）。造礁珊瑚依赖其组织中虫黄藻科（Symbiodiniaceae）的光合甲藻；水温过高时伙伴关系瓦解，珊瑚排出藻类而“白化”，高温若持续它们便饥饿而死。**传粉**与动物**种子扩散**涉及大多数有花植物。从白蚁到牛的植食动物，肠道中都含有微生物群落，没有它们就无法消化纤维素（见 [[microbiology/microbes-and-hosts]]）。

互利共生可以方便地按所交换之物分类：资源换资源（菌根）、资源换服务（传粉——花蜜为运送花粉付酬），或服务换服务（清洁鱼从较大的鱼身上清除寄生虫，而后者不吃它）。服务换资源的一个经典例子是中美洲的牛角金合欢（*Vachellia cornigera*，旧称 *Acacia cornigera*）：它为 *Pseudomyrmex* 属蚂蚁提供中空的刺作巢，并供以富含蛋白质的食物体；蚂蚁则攻击植食动物并清除与之竞争的植被。Daniel Janzen 在1966年证明，被除去了蚂蚁的金合欢遭受严重植食，且生长不良。

互利共生不是心怀善意的伙伴之间的合作安排：每一方都受选择以最小代价获取最大利益，而互利共生易受**作弊者**侵害——咬穿花朵取食花蜜却不传粉的花蜜窃贼，或取走碳却很少固氮的根瘤菌。它们的稳定性取决于伙伴选择与制裁等机制，这些机制连同互利共生者的协同进化在 [[evolution/coevolution]] 中处理。

互利共生对种群动态有何作为？若给 [[ecology/competition#prop-lv-competition]] 的 Lotka–Volterra 竞争方程加上正的相互作用项，使每一物种都*抬高*另一物种的增长，则当互利利益较弱（$\alpha_{12}\alpha_{21} < 1$）时，诸种群在高于两个承载量之处达到稳定平衡；而利益很强时便无限制地增长——Robert May 所谓的“互惠施惠的狂欢”。真实的互利共生受其他极限约束——利益会饱和，或者每一方都受制于对方所提供不了的某物——因此互利共生的模型需要饱和的利益。

## 食物网

### 营养结构

**食物链**以线性序列描述谁吃谁，物种在其中的位置是它的**营养级**：初级生产者（植物、藻类、光合细菌）构成第1级，植食动物第2级，食植食动物的肉食动物第3级，如此类推。分解者与碎屑食者取食来自各级的死物质。真实的取食关系构成**食物网**：多数消费者吃好几类猎物，许多在不止一个级别上取食（**杂食**），还有的吃本物种的成员。

::: definition 食物网的描述量 {#def-food-web}
一个含 $S$ 个物种（或“营养种”——捕食者与猎物皆相同的物种群）与 $L$ 条取食联系的食物网，用它的**连接密度** $L/S$——每物种的平均联系数——与**连接度** $C = L/S^2$——一切可能的有向联系中被实现的分数——来描述。**食物链的长度**是从基础物种到顶级捕食者的联系数；消费者的营养位置是1加上其猎物营养位置的平均值（以其在食谱中的重要性加权）。
:::

食物链很短。在多数食物网中，最长的链有4到6个环节，大部分能量只经过两三个环节。一种流行的解释是能量学的——每次传递只传下去约10 %的能量，故所剩不足以再供养一个级别——此说及其证据在 [[ecology/ecosystem-energetics]] 中讨论；但链长与生产力的相关很弱，生态系统的大小与干扰的历史也起作用。

::: example 食物网的连接度 {#ex-connectance}
一项溪流食物网研究解析出25个营养种与75条取食联系。计算连接密度与连接度。若第二个含100个物种的食物网有同样的连接密度，它的连接度是多少？
::: solution
连接密度 $L/S = 75/25 = 3$ 条联系每物种；连接度 $C = L/S^2 = 75/625 = 0.12$。第二个食物网有 $L = 3\times100 = 300$ 条联系，$C = 300/10\,000 = 0.03$。若食物网变大时连接密度保持不变，连接度便与 $S$ 成反比下降。对解析良好的食物网的汇编表明，大致恒定的是连接度（最常介于约0.05与0.3之间）而非连接密度，故较大的食物网每物种有较多联系。
:::
:::

### 关键种与营养级联

Paine 为 *Pisaster* 创造了**关键种**一词：其移除所引起的群落改变远与它的丰度或生物量不相称，正如抽去拱顶石会使拱坍塌。Mukkaw Bay 的机制是海星优先取食竞争上的优势者贻贝，防止它垄断空间，从而让较弱的竞争者得以存续。这就是**关键种捕食**：捕食者通过捕食优势竞争者而提高多样性。

当捕食者控制植食动物、植食动物控制植物时，顶级捕食者的效应便抵达植物：**营养级联**。最著名的例子涉及北太平洋的海獭（*Enhydra lutris*）。James Estes 与 John Palmisano（1974）比较了阿留申群岛上已从毛皮贸易中恢复海獭的岛屿与海獭仍缺席的岛屿。有海獭之处，海胆小而稀少，海藻林繁盛；无海獭之处，海胆众多，把海带啃成“海胆荒地”。1990年代虎鲸开始吃海獭之后，海獭数量下降，海胆增多，海藻减少，正如级联所预言（Estes 及同事，1998）。

::: definition 自上而下与自下而上的控制 {#def-top-down}
当一个种群的数量主要由其消费者（捕食者、寄生物、植食者）设定时，它处于**自上而下的控制**之下；当主要由其资源设定时，则处于**自下而上的控制**之下。**营养级联**是跨过一个以上营养级传播的自上而下效应，例如捕食者增多，减少了植食动物，从而使植物增多。
:::

自上而下与自下而上控制的相对重要性各有不同。级联在水生系统中最强——在湖泊中，添加食鱼鱼类可以减少食浮游生物鱼类、增多浮游动物、使水体清水脱离藻类，这一技术称为**生物操纵**——也强在物种少而相互作用强的系统中。在陆地上，证据常较弱也更有争议。1995–1996年灰狼（*Canis lupus*）重新引入黄石国家公园之后，马鹿的数量与行为发生变化，一些山杨与柳树重新萌发，这被广泛呈现为营养级联；但研究者们持续争论植被变化中究竟多少由狼造成，而非由其他捕食者、狩猎、气候与溪流改变了的水文造成。

有些物种对群落影响巨大，靠的不是取食而是改造物理环境：河狸在溪流筑坝，珊瑚与树木创造结构，蚯蚓翻拌土壤。它们被称为**生态系统工程师**。

::: warning "关键种就是最丰富或最重要的那些物种"
关键种以与其丰度远不相称的效应来定义。只因数量多而效应大的物种——森林里的优势树、造礁的珊瑚——最好称为**优势**种或**基础**种。而关键种地位是一个物种*在特定群落中*的属性：*Pisaster* 是在贻贝称王的迎浪岩岸上的关键捕食者，但在别的地方，移除它的效应要小得多。
:::

### 复杂性与稳定性

物种多、联系多的复杂群落比简单群落更稳定吗？1950年代的生态学家，尤其是 Robert MacArthur 与 Charles Elton，主张是的：能量路径越多，任何一个物种的损失或波动就应当越不要紧。1972年 Robert May 以数学检验了这一论证，却得出相反的结论。

::: proposition May 的稳定性判据 {#prop-may}
考虑 $S$ 个物种的群落在一个平衡处，线性化使小偏离 $x$ 按 $dx/dt = Ax$ 演化。设每一物种自我调节（$A$ 的对角元等于 $-1$），且每一个非对角的相互作用以概率 $C$（连接度）存在，若存在，则从均值为零、标准差为 $\sigma$ 的分布中随机抽取。那么对大 $S$，只要

$$
\sigma\sqrt{SC} < 1
$$ {#eq-may}

平衡就几乎必定稳定；若 $\sigma\sqrt{SC} > 1$，则几乎必定不稳定。
:::

这一结果出自随机矩阵理论：由于自我调节，$A$ 的随机部分的特征值散布在复平面内以 $-1$ 为中心、半径 $\sigma\sqrt{SC}$ 的圆盘上，故稳定性要求半径小于1。此处不加证明。它的寓意是：在一个*随机装配*的群落中，物种更多、联系更多或相互作用更强，都会使稳定更不可能。

::: example 应用 May 的判据 {#ex-may}
一个模型群落有50个物种，连接度0.1，相互作用强度的标准差为 $\sigma = 0.4$（相对于自我调节）。它可能是稳定的吗？若物种数加倍，结果如何？
::: solution
$\sigma\sqrt{SC} = 0.4\sqrt{50\times0.1} = 0.4\sqrt5 = 0.894 < 1$：稳定。100个物种时，$0.4\sqrt{10} = 1.26 > 1$：不稳定。要使较大的群落在同样连接度下稳定，相互作用强度须降到 $\sigma = 1/\sqrt{10} = 0.32$ 以下。
:::
:::

May 的结果并未表明真实的复杂群落是不稳定的——它们显然在持续存在。它表明的是它们不是随机的：真实的食物网具有随机矩阵所没有的结构。弱相互作用多而强相互作用少、成对出现而符号相反的捕食者-猎物联系、内部强相互作用而彼此弱连接的分室、以及由体型造成的谁吃谁的模式，都倾向于提高稳定性。“复杂性-稳定性之争”已转变为研究真实食物网的哪些非随机特征允许如此众多的物种共存。稳定性的不同度量（对变化的抵抗力、扰动后返回的速度、总生物量的变异）也会给出不同的答案：草地实验发现，更多样的植物群落*总*生物量的年际变异更小，即使各个物种波动更大。

## 演替

当冰川退却、熔岩流冷却或农田被弃耕，裸地被一系列物种拓殖，它们在一到几百年间接替彼此。群落组成这种方向性的变化是**演替**。

::: definition 初生与次生演替 {#def-succession}
**初生演替**发生在没有先前土壤或生物遗产的表面——新火山岩、沙丘、退缩冰川暴露的地面。**次生演替**跟在移走植被但留下土壤、种子与根的干扰之后：弃耕的农田、火后或砍后的森林。演替早期的物种称为**先锋种**；一个不再方向性地变化（尽管其个体在替换）的群落传统上称为**顶级群落**。
:::

在阿拉斯加东南部的 Glacier Bay，自十八世纪末以来冰体退了约100 km，暴露出一系列已知年龄的表面。自 William Cooper 在1910年代起，生态学家利用这一**时间序列**——以不同年龄的地点代表同一次演替的各阶段——来描述初生演替：从蓝细菌与地衣的垫层，经仙女木（*Dryas*）与柳树，到固氮桤木的灌丛，再到北美云杉，最后是云杉-铁杉林，历时约两个世纪。土壤氮与有机质沿此序列增加。

### 演替的机制

Frederic Clements（1916）把演替视为一个“超级有机体”的发育：其中每一阶段为下一阶段铺路，整体朝向一个由气候决定的顶级群落前进。Henry Gleason（1926）则主张**个体论**的观点：每一物种按其自身的耐受与扩散来响应条件，群落是松散的、变动的集合，而非整合的单位。证据支持了 Gleason：诸物种沿梯度各有其独立的分布，同一地点可因哪些物种最先到达而遵循不同的路径。

Joseph Connell 与 Ralph Slatyer（1977）把物种替代的可能机制提炼为三个模型。

- **促进。** 早期物种以让环境更适合后来者的方式改变环境——施入氮、建造土壤、提供荫蔽——后来者只有在此之后才能定殖。
- **耐受。** 后期物种不受早期物种影响；它们同时或更晚到来，只是生长更慢，最终因能耐受更低的资源水平而占据优势。
- **抑制。** 早期物种使环境对后来者*更不*适宜，占据着这块地方直到它们死亡或受损；后来物种只在此时取而代之。

这些并不互斥。在 Glacier Bay，F. Stuart Chapin 及同事（1994）的一项实验研究发现，桤木既促进云杉——向土壤施氮——又抑制云杉——竞争光与水；对云杉的净效应取决于演替阶段与所测的性能。

### 作为马尔可夫链的演替

一个简单而出人意料的有用的模型把演替当作**马尔可夫链**。Henry Horn（1975）对普林斯顿附近一片森林中的每一种林冠树，记录了其下生长的幼树的种，并把这些记录用作一棵某种的树死亡时被另一种替换的概率。若替换概率恒定，森林的组成便收敛到一个不依赖起始组成的**平稳分布**——一个统计学上的顶级群落。

::: example 森林演替的马尔可夫模型 {#ex-markov}
一片林中有三种树——桦树（先锋种）、槭树与山毛榉——一棵林冠树死亡时被各种替换的概率为

| 现存的树 | → 桦树 | → 槭树 | → 山毛榉 |
|---|---|---|---|
| 桦树 | 0.05 | 0.50 | 0.45 |
| 槭树 | 0.05 | 0.30 | 0.65 |
| 山毛榉 | 0.05 | 0.15 | 0.80 |

从一个纯桦树的林分出发，求一代与两代树之后的组成，以及平稳组成。
::: solution
一代之后林分为 $(0.05, 0.50, 0.45)$，即第一行。两代之后，把该行向量乘以矩阵：
桦树 $= 0.05(0.05 + 0.50 + 0.45) = 0.05$；槭树 $= 0.05\times0.50 + 0.50\times0.30 + 0.45\times0.15 = 0.025 + 0.15 + 0.0675 = 0.2425$；山毛榉 $= 0.05\times0.45 + 0.50\times0.65 + 0.45\times0.80 = 0.0225 + 0.325 + 0.36 = 0.7075$。

对平稳分布 $\pi$，我们需要 $\pi = \pi P$。每一物种都以0.05的概率被桦树替换，故 $\pi_\text{birch} = 0.05$。对槭树，$\pi_m = 0.05\times0.50 + 0.30\pi_m + 0.15\pi_b$，其中 $\pi_b = 0.95 - \pi_m$，得 $0.85\pi_m = 0.1675$、$\pi_m = 0.197$、$\pi_b = 0.753$。无论起始状态如何，森林收敛到约5 %桦树、20 %槭树与75 %山毛榉。桦树之所以存续，只因为有些空隙被它拓殖——在现实中，是干扰造成的空隙。
:::
:::

states: Birch; Maple; Beech

### 干扰

干扰——任何移走生物并打开空间的离散事件，如火、风暴、洪水或大型动物的践踏——在局部重置演替，并造成处于不同阶段的斑块构成的镶嵌体。Connell（1978）提出了**中度干扰假说**：在中等频率或强度的干扰下多样性应当最高，因为干扰太少时竞争优势者会排斥其他物种，干扰太多时只有少数拓殖迅速的先锋种幸存。这一想法有直观的吸引力，也符合某些数据，如 Wayne Sousa 1979年在加利福尼亚海岸研究的、大小不同（从而被浪掀翻的频率不同）的砾石上藻类的多样性。但调查发现，干扰与多样性的单峰关系只是观察到之模式的少数，理论工作也表明通常的口头论证本身并不能保证共存；几位生态学家主张，此假说的简单形式应当放弃。

## 什么控制着物种数？

群落中的物种数是作用在极不相同尺度上的诸过程的结果。

- **区域物种库。** 群落只能包含存在于区域中、且能够到达它的物种。非洲东非大裂谷的一个湖因那里的爆发式物种形成而拥有数百种慈鲷鱼；苏格兰一个相似的湖却不能。区域库中的大尺度格局——纬度梯度与物种-面积关系——是 [[ecology/biogeography]] 的主题。
- **扩散与偶然。** 哪些物种最先到达可以决定哪些得以存续（**优先效应**），所以相似环境中的群落可因偶然与历史而不同。
- **环境过滤。** 此地的条件与资源排除了生态位不包括它们的物种（[[ecology/organisms-environment]]）。
- **相互作用。** 竞争能排斥物种；捕食、干扰与生态位差异能容许更多物种共存（[[ecology/competition]]）。
- **生产力。** 生产力与多样性的关系在局地尺度上常呈单峰形——极贫瘠之地多样性低，极肥沃之地又下降，少数竞争种占优势（如1856年建立的洛桑（Rothamsted）Park Grass 实验的长期施肥小区所见）——但它随尺度与系统而异，荟萃分析发现了各种形状。

对基于生态位之解释的一个有影响的对立面，是 Stephen Hubbell（2001）的**生物多样性中性理论**：它问，若一切物种的一切个体在生态上彼此等价，群落的组成只因随机的出生、死亡、扩散与物种形成而改变，那么群落组成的格局有多少能由此解释？中性模型出奇地好地再现了某些格局，尤其是热带树木群落中物种多度的分布，这表明与此类格局相匹配只是任何特定机制的弱证据。很少有生态学家认为群落真是中性的；该理论充当一个零模型，生态位差异必须对照它来证明。

::: quiz
在 Paine 的实验中，移除一个捕食者*减少*了物种数。为什么？
- [ ] 海星是其他物种的互利共生者
- [x] 海星优先吃优势竞争者贻贝，贻贝在海星缺席时把其他物种排斥于空间之外
- [ ] 海星为许多物种提供了食物
- [ ] 移除海星增加了干扰
::: solution
*Pisaster* 主要吃贻贝 *Mytilus californianus*，它是岩石上空间的最强竞争者。捕食者通过压制贻贝，让较弱的竞争者——藤壶、帽贝、石鳖、藻类——得以存续。没有它，贻贝便接管一切并把它们排斥在外。这就是关键种捕食：捕食者对其猎物本会竞争掉的诸物种的间接正效应。
:::
:::

::: application 生物多样性与生态系统功能
物种的丧失对生态系统的运作要紧吗？自1990年代以来的大型实验——明尼苏达州 Cedar Creek 的草地实验、横跨8个欧洲国家的 BIODEPTH 实验、德国的 Jena 实验——把从区域库随机抽取的、数量不等的植物物种播入小区。物种越多，小区平均生产更多生物量、捕获更多可用的氮、总生产力的年际变异越小，且这些效应随时间增强。有两个机制起作用：**互补性**，以不同方式利用资源的物种在一起能利用其中更多；以及**选择**（或抽样），多样的混播更可能包含某个高生产力的物种。这些结果支持着因其功能而保护生物多样性的论点，这是 [[conservation-biology/biodiversity]] 的主题。把它们用于物种非随机丧失的天然生态系统，是一个活跃的研究领域。
:::

::: history
Karl Möbius 在1877年把一片牡蛎礁描述为“biocoenosis”——一个群落。二十世纪初，Frederic Clements 的植物演替超级有机体观（1916）占统治地位，直到 Henry Gleason 的个体论概念（1926）以及后来 Robert Whittaker 在1950年代对山地植被的梯度分析，表明物种是个别分布的。Charles Elton 的 *Animal Ecology*（1927）引入了食物链、数量金字塔与作为角色的生态位。Robert Paine 的海星移除实验（1966）与关键种思想、Estes 与 Palmisano 的海獭（1974）、Connell（1978）的中度干扰假说，把实验与野外比较带进了群落生态学，而 Robert May 的 *Stability and Complexity in Model Ecosystems*（1973）引发了复杂性-稳定性之争。Stephen Hubbell 的中性理论（2001）与1990、2000年代的生物多样性-生态系统功能实验，是此后最有影响的一些进展。
:::

## 由此引向何处

食物网也是能量与养分的通道：[[ecology/ecosystem-energetics]] 测量流经营养级的能量流，[[ecology/nutrient-cycles]] 追踪化学元素穿过生产者、消费者与分解者。设定区域库的大尺度物种丰富度格局在 [[ecology/biogeography]]，群落的保护在 [[conservation-biology/restoration]]。

::: summary
- **群落**是一地中相互作用之诸种群的集合；其多样性结合**丰富度**与**均匀度**，以 **Shannon**（$H' = -\sum p_i\ln p_i$）与 **Simpson**（$D = \sum p_i^2$）指数度量，最好以有效物种数（$e^{H'}$、$1/D$）比较（[[#def-community]]）。
- 相互作用按符号分类（[[#def-mutualism]]）。**互利共生**——菌根、根瘤菌、珊瑚与其藻类、传粉、蚁-植物防御——分布广泛且易受作弊者侵害；简单的互利共生模型需要饱和的利益。
- **食物网**以连接密度与连接度描述（[[#def-food-web]]）；食物链是短的。
- **关键种**的效应远与丰度不相称（Paine 的 *Pisaster*）；**营养级联**把自上而下的效应跨过级别传递（海獭、海胆与海带）（[[#def-top-down]]）。
- **May 的判据** $\sigma\sqrt{SC} < 1$（[[#prop-may]]）表明随机的复杂群落趋于不稳定；真实食物网因其非随机结构而得到稳定。
- **演替**（[[#def-succession]]）分初生与次生；物种经促进、耐受与抑制相互替代（Connell–Slatyer）；马尔可夫模型预言平稳组成。Gleason 的个体论观已取代 Clements 的超级有机体。
- 物种数受区域库、扩散与历史、环境过滤、相互作用、干扰与生产力的控制；中性理论提供一个零模型。
:::

## 习题

::: exercise Shannon 指数 {level=1 check="ln(5)"}
一个群落有5个物种，各种20个个体。它的 Shannon 指数 $H'$ 是多少？
::: solution
每个 $p_i = 0.2$，故 $H' = -5\times0.2\ln0.2 = \ln5 = 1.609$。
:::
:::

::: exercise Simpson 指数 {level=1 check="0.7"}
一个群落有4个物种，比例为0.4、0.3、0.2与0.1。计算 Gini–Simpson 指数 $1 - D$。
::: solution
$D = 0.16 + 0.09 + 0.04 + 0.01 = 0.30$，故 $1 - D = 0.70$（且 $1/D = 3.33$ 个有效物种）。
:::
:::

::: exercise 连接度 {level=1 check="0.15"}
一个食物网有20个物种与60条联系。它的连接度 $L/S^2$ 是多少？
::: solution
$C = 60/400 = 0.15$。
:::
:::

::: exercise 相互作用的分类 {level=1}
按效应的符号 $(+,+)$、$(+,-)$、$(-,-)$、$(+,0)$ 或 $(-,0)$，分类每一相互作用：(a) 蜱在鹿身上吸血；(b) 一丛兰长在树枝上而不伤害树；(c) 两种山雀吃同一批毛虫；(d) 蜜蜂采花蜜并为花传粉；(e) 大象在去水边的路上踩坏草地。
::: solution
(a) $(+,-)$，寄生。(b) $(+,0)$，偏利共生（一种附生植物）。(c) $(-,-)$，竞争。(d) $(+,+)$，互利共生。(e) $(-,0)$，偏害共生：草受害而大象不受影响。
:::
:::

::: exercise 有效数量 {level=2}
对 [[#ex-diversity]] 样地 B 的群落，一次调查漏掉了三个稀有种，只记录了那个常见种。它的丰富度、Shannon 指数与 Simpson 有效物种数是多少？这对各度量对取样不足的敏感性说明了什么？
::: solution
只记录到一个物种时，$S = 1$、$H' = 0$ 与 $1/D = 1$。真值是 $S = 4$、$H' = 0.588$（有效物种数1.80）与 $1/D = 1.37$。丰富度下降75 %，Shannon 有效物种数下降44 %，Simpson 有效物种数下降27 %。丰富度对漏掉稀有种最敏感，Simpson 最不敏感，因为它被常见种主导。这就是丰富度必须在等取样强度下比较（稀疏化）、或用顾及未见物种的方法估计的原因。
:::
:::

::: exercise 一个马尔可夫演替 {level=2}
一片草地可处于两个状态：草（G）或灌丛（S）。每过十年，一块草地以0.2的概率变成灌丛，一块灌丛以0.3的概率被烧掉并回到草。(a) 写出转移矩阵。(b) 求灌丛地的平稳比例。(c) 若防火使燃烧概率降到0.05，新的平稳比例是多少？
::: solution
(a) $P = \begin{pmatrix} 0.8 & 0.2 \\ 0.3 & 0.7\end{pmatrix}$，行为“从”，列为“到”（G, S）。

(b) 平稳时流相抵：$0.2\pi_G = 0.3\pi_S$，且 $\pi_G + \pi_S = 1$。故 $\pi_S = 0.2/(0.2 + 0.3) = 0.4$。

(c) $\pi_S = 0.2/(0.2 + 0.05) = 0.8$。抑制火使平衡时的灌丛覆盖加倍，这一格局见于许多由火维持的草地与稀树草原。
:::
:::

::: exercise 稳定性与多样性 {level=2 check="0.25"}
在 May 的模型中，一个群落有连接度 $C = 0.2$ 与相互作用强度 $\sigma = 0.5$。(a) 它可能稳定的最大物种数是多少？(b) 在同样连接度下，允许80个物种稳定共存的最大相互作用强度 $\sigma$ 是多少？（答案框取(b)。）
::: solution
(a) 稳定要求 $\sigma\sqrt{SC} < 1$，即 $S < 1/(\sigma^2C) = 1/(0.25\times0.2) = 20$ 个物种。(b) 对 $S = 80$，$\sigma < 1/\sqrt{80\times0.2} = 1/\sqrt{16} = 0.25$。
:::
:::

::: exercise 解读一个级联 {level=2}
在一系列实验池塘中，一位生态学家向一半池塘添加捕食性鱼类。一个夏天之后，与无捕食鱼的池塘相比，有捕食鱼的池塘小型食浮游生物鱼更少、大型浮游动物（*Daphnia*）更多、叶绿素浓度（浮游植物）更低。(a) 以营养级联解释这些结果。(b) 预测向所有池塘添加养分的效果。(c) 若浮游植物以大型群居蓝细菌为主，级联为什么可能更弱？
::: solution
(a) 捕食鱼吃食浮游生物鱼；食浮游生物鱼少了，大型浮游动物便逃脱捕食而增多；浮游动物多了便把浮游植物吃下去，于是叶绿素下降。顶级捕食者的效应以正负交替的符号沿链而下：对食浮游生物鱼为 $-$，对浮游动物为 $+$，对浮游植物为 $-$。

(b) 养分增加浮游植物的生长（自下而上）。在无捕食者的池塘里，浮游动物被压制，额外的生产应主要表现为浮游植物增多；在有捕食者的池塘里，更多的部分可能传给浮游动物。两类池塘的叶绿素大概都会更多，两者之差取决于浮游动物能够响应的程度。

(c) 大型群体难以被浮游动物吃（且有些蓝细菌有毒），所以食草者的增加对它们影响不大。在任何一级，不可食或有防御的猎物都会削弱级联。
:::
:::

::: exercise 促进还是抑制？ {level=3}
在一次冰碛物上的初生演替中，一位生态学家以三个处理栽种云杉幼苗（一个后期演替种）：(i) 裸地，(ii) 桤木灌丛下，(iii) 已去除桤木但留下其枯落物的小区。五年之后，存活率分别为20 %、50 %与70 %，生长量（高生长）分别为8 cm、3 cm 与15 cm。(a) 这些结果支持 Connell–Slatyer 的哪些机制？(b) 处理(iii)显示了桤木之效应的哪个组分？(c) 桤木对云杉的净效应是什么？它会如何随时间改变？
::: solution
(a) 促进与抑制都有。与裸地相比，桤木下与其枯落物中存活率更高，指示促进；与裸地相比，活桤木下生长更低，指示活植物的抑制。

(b) 处理(iii)把桤木对土壤的效应（枯落物添加氮与有机质）与活植物的效应（遮荫、根系竞争）分离开来。既有土壤之利又无竞争时，云杉在存活与生长两方面都最好：桤木的促进经土壤起作用，其抑制经竞争起作用。

(c) 在桤木之下，存活更高而生长更慢；净效应取决于哪个对进入林冠更重要。早期，对定殖的促进可能占上风；后期，随着桤木灌丛老化死亡，从竞争中被释放的云杉受益于被改良的土壤。正负效应如此随时间改变的混合，正是 Chapin 及同事在 Glacier Bay 的发现。
:::
:::

::: exercise 是不是关键种？ {level=3}
在一次移除实验中，生态学家移走了一种蟹，它占泥滩动物生物量的2 %。两年后，无脊椎动物的物种数从24降到15，被蟹吃的一种穴居虾增加了十倍。在第二个实验中，他们移走了一种螺，它占动物生物量的40 %，物种数从24降到20。(a) 为每一物种计算一个简单的其重要性指数：物种数的比例变化除以它的生物量占比。(b) 其中哪个（若有）是关键种？(c) 为蟹的效应提出一个机制。
::: solution
(a) 蟹：比例变化 $(24 - 15)/24 = 0.375$；除以0.02得18.75。螺：$(24 - 20)/24 = 0.167$；除以0.40得0.42。（这是 Mary Power 及同事1996年“群落重要性”指数的一个简单版本。）

(b) 蟹的效应接近其生物量份额的19倍：一个关键种。螺的效应小于它的份额：它更宜称为优势种，其损失只有温和的效应。

(c) 与 *Pisaster* 一样，蟹可能控制着一个优势竞争者或一个生态系统工程师：从捕食中被释放的穴居虾可能把沉积物扰动得如此剧烈，以致敏感的物种被掩埋或被排挤。检验这一点需要例如在移除蟹的同时移除虾。
:::
:::
