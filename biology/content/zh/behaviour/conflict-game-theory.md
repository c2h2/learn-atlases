在苏格兰西海岸外鲁姆岛的秋季发情期里，一只占有数头母鹿的马鹿（*Cervus elaphus*）雄鹿受到另一只雄鹿的挑战。随之而来的通常不是搏斗。两只雄鹿相互吼叫，常常持续数分钟，挑战者一边逼近；接着，若谁都不退，它们便并肩平行行走，相隔几米，相互打量；只有当这仍不能了事，它们才会抵角相推。大多数挑战在吼叫或行走阶段便告结束，一只雄鹿退走。从1970年代起研究鲁姆岛鹿群的 Tim Clutton-Brock 与 Steve Albon 发现，吼叫频率更高的雄鹿也往往赢得打斗，而挑战者通常从吼得过它的雄鹿面前退走。打斗确实发生，而且危险——雄鹿会受伤，有时是永久性的——但它们是例外。

为什么那么多动物争斗靠展示而非升级的打斗来解决？1970年代以前，一个常见的回答是克制防止受伤，从而有利于物种。John Maynard Smith 与 George Price 在1973年证明，答案其实在于策略相互作用的逻辑：当一个行为的收益取决于其他个体做什么时，选择青睐那些在其所塑造的种群中表现出色的策略。本章借鹰鸽博弈、策略频率的动力学、占有者与入侵者之间的不对称争斗、战斗能力的评估以及消耗战博弈，来展开他们的框架——进化博弈论与**进化稳定策略**。这些方法将在交流、交配策略与合作中再次用到。

## 策略与稳定性

在 [[behaviour/foraging]] 的最优性模型中，一个决策的收益只取决于环境。而在争斗中，它取决于对手做什么。这一情形下的行为规则称为**策略**，而"最优"的恰当含义也随之改变。

::: definition 进化稳定策略 {#def-ess}
设 $E(I, J)$ 为采用策略 $I$ 的个体对抗采用 $J$ 的对手时的期望收益（以适合度为单位）。若当种群中几乎所有成员都采用 $I$ 时，没有任何稀有突变策略 $J$ 能够入侵，则称 $I$ 为**进化稳定策略（ESS）**。在一个大规模、随机配对争斗的种群中，这要求对每个 $J \neq I$，

$$
E(I, I) > E(J, I),
$$

或

$$
E(I, I) = E(J, I) \quad\text{and}\quad E(I, J) > E(J, J).
$$ {#eq-ess}

第一个条件是说，$I$ 对抗自身比突变策略对抗 $I$ 更好；第二个条件在突变策略对抗 $I$ 表现同样好时才需要，它说的是 $I$ 对抗稀有突变型比后者彼此对抗更好。（Maynard Smith 与 Price，1973。）
:::

这些条件背后的道理是：稀有突变型几乎总是遇到驻留者。因此它的适合度实质上就是 $E(J, I)$，而驻留者的适合度是 $E(I, I)$。只有当二者相等时，突变型与驻留者、突变型与突变型之间那些罕见的相遇才决定结局。

进化稳定策略是经济博弈论中**纳什均衡**——一个针对自身的最佳回应——加上一个额外稳定性条件的精化。但解释不同。经济学中的参与者会推理；而在进化博弈中，策略是遗传的，收益是适合度，策略的"选择"由选择做出。这里假定 [[behaviour/studying-behaviour#def-optimality]] 的表型赌注：策略能真实遗传。

## 鹰鸽博弈

Maynard Smith 与 Price 设想了两种策略之间围绕价值为 $V$（以适合度单位计）的资源的争斗。**鹰**不断升级并战斗，直到自己受伤或对手退走。**鸽**进行展示，但若对手升级便立即退走。两只鹰相遇，各有一半机会获胜；失败者付出伤害代价 $C$。两只鸽相遇时彼此展示，各有一半机会得到资源（这里忽略展示的任何代价）。

::: definition 鹰鸽博弈的收益 {#def-hawkdove}
行策略对抗列策略的收益为

| | 鹰 | 鸽 |
|---|---|---|
| **鹰** | $\tfrac12(V - C)$ | $V$ |
| **鸽** | $0$ | $\tfrac12 V$ |
:::

::: proposition 鹰鸽博弈的进化稳定策略 {#prop-hawkdove}
1. 若 $V \ge C$，鹰是进化稳定策略：鹰种群不能被鸽入侵。
2. 鸽从来不是进化稳定策略：鸽种群中的一个鹰突变体得到 $V > V/2$。
3. 若 $V < C$，进化稳定策略是一个**混合策略**：以如下概率选鹰

$$
p^* = \frac{V}{C},
$$ {#eq-pstar}

或等价地说，形成鹰占比例 $V/C$ 的稳定多态。
:::

::: proof
(1) $E(H, H) = (V - C)/2$ 且 $E(D, H) = 0$。若 $V > C$，则 $E(H, H) > E(D, H)$，[[#eq-ess]] 的第一个条件成立。若 $V = C$，二者都等于0，而由于 $E(H, D) = V > V/2 = E(D, D)$，第二个条件成立。

(2) $E(D, D) = V/2 < V = E(H, D)$，第一个条件不成立，第二个条件也用不上。

(3) 在一个有比例 $p$ 的遭遇对象为鹰的种群中，期望收益为

$$
W_H(p) = p\,\frac{V - C}{2} + (1 - p)V, \qquad W_D(p) = (1 - p)\,\frac{V}{2}.
$$

二者之差为 $W_H - W_D = \tfrac12(V - pC)$，当 $p < V/C$ 时为正，当 $p > V/C$ 时为负。所以当鹰比 $V/C$ 更稀时它们表现更好并增多，当更普及时表现更差并减少：$p^* = V/C$ 是两种策略表现相同的唯一频率。对混合策略 $I$（以概率 $p^*$ 选鹰），任何备择策略 $J$ 对抗 $I$ 都表现相同，因此稳定性取决于 [[#eq-ess]] 的第二个条件；可以验证，对一个以概率 $q \neq p^*$ 选鹰的突变型，$E(I, J) - E(J, J) = \tfrac{C}{2}(p^* - q)^2 > 0$。所以 $I$ 是进化稳定策略。
:::

::: example 一处巢址的争夺 {#ex-hawkdove}
一处巢址值 $V = 50$ 适合度单位，输掉一场升级打斗的代价为 $C = 100$。(a) 进化稳定策略是什么？(b) 处于进化稳定策略的种群中每场争斗的平均收益是多少，与鸽种群相比如何？(c) 种群为何不能停留在更高的收益上？
::: solution
(a) $V < C$，所以进化稳定策略是以概率 $p^* = 50/100 = 0.5$ 选鹰。

(b) 在 $p^* = 0.5$ 处，两种策略收益相同：$W_D = (1 - 0.5)\times 25 = 12.5$，且 $W_H = 0.5\times(-25) + 0.5\times50 = 12.5$。全鸽种群每场争斗可得 $V/2 = 25$，是它的两倍。

(c) 鸽种群并不稳定：鹰突变体对抗鸽可得 $V = 50$，于是鹰入侵并扩散，直到 $p = 0.5$。进化稳定策略不是使种群福利最大化的策略；它是不能被稀有备择策略击败的策略。这正是进化博弈论的核心教训，也是"为了物种的利益"式克制解释失败的原因。
:::
:::

### 从收益到动力学

进化稳定策略是一个静态条件。一个起点不在其上的种群会怎样？若每种策略频率的增长速率正比于其相对种群平均收益的超额收益，鹰的频率 $p$ 将按**复制子方程**变化：

$$
\frac{dp}{dt} = p(1 - p)\,\bigl(W_H(p) - W_D(p)\bigr) = \tfrac12\,p(1 - p)(V - pC).
$$ {#eq-replicator}

它的平衡点位于 $p = 0$、$p = 1$ 与 $p = V/C$；当 $V < C$ 时，内部平衡稳定而另外两个不稳定。无论起始混合如何（纯鸽或纯鹰除外），种群都收敛于进化稳定策略频率。对这样的两策略博弈，进化稳定策略与复制子动力学的稳定平衡一致；策略更多时，二者可能分离，动力学可能出现循环。

### 混合策略与多态

混合进化稳定策略可以两种方式实现：每个个体以概率 $V/C$ 选鹰，或比例 $V/C$ 的个体总是选鹰。在最简单的模型中两者等价，但它们预言的东西不同——个体一致性对个体随机性——并且可以由观察区分。**交替繁殖策略**是研究充分的例子。在蓝鳃太阳鱼（*Lepomis macrochirus*）中，一些雄鱼长大、筑巢并向雌鱼求偶，另一些则早熟而小，冲进巢中为卵受精（"偷精者"）。Mart Gross 表明两种生活史共存，并论证它们的一生成就相近，正如频率依赖所预言。在侧斑蜥蜴（*Uta stansburiana*）中，Barry Sinervo 与 Curtis Lively（1996）描述了三种喉色的雄性形态、各有不同的交配策略——占据大领地的攻击性橙色个体、守护单个雌性的蓝色个体、以及黄色"偷精"个体——它们的频率多年循环，每种形态克制一种而输给第三种，类似石头-剪刀-布游戏。

::: warning 进化稳定策略不是对种群最好的
进化稳定策略不必最大化平均适合度，而且常常做不到。在 $V < C$ 的鹰鸽博弈中，处于进化稳定策略的每个个体所得都低于全鸽种群（[[#ex-hawkdove]]）。选择作用于策略之间的相互较量，一种剥削他者的策略会扩散，即使整个种群因此受损。反过来，观察到争斗中的克制，并不意味着它为保护物种而进化；它意味着在那个种群中，升级对个体不划算。
:::

## 不对称争斗

真实的对手很少完全相同。它们在体型、对资源的看重程度和角色上各不相同——一方往往已经占有。不对称可以与收益**相关**（较大的动物更可能获胜；占有的个体可能因为熟悉领地而更看重它），也可以**无关**——只是角色上的差异，与战斗能力或价值无关。Maynard Smith 表明，即使是不相关的不对称也能决定争斗的结局。

::: proposition 君子策略 {#prop-bourgeois}
设每场争斗都发生在占有者与入侵者之间，每个个体处于每种角色的机会均等，且不论角色如何，收益都是鹰鸽博弈的收益。**君子**策略——作为占有者时选鹰，作为入侵者时选鸽——在 $V < C$ 时是进化稳定策略。它对抗自身的收益为 $E(B, B) = V/2$，而 $E(H, B) = (3V - C)/4$，$E(D, B) = V/4$。
:::

::: proof
对抗君子对手时，君子个体一半的争斗中是占有者（对手退走，得 $V$），一半中是入侵者（它退走，得0）：$E(B, B) = V/2$。鹰作为占有者遇到退走的君子入侵者（得 $V$）；作为入侵者，它遇到应战的君子占有者（期望收益 $(V - C)/2$）。所以 $E(H, B) = \tfrac12 V + \tfrac14(V - C) = (3V - C)/4$。鸽作为占有者遇到同样选鸽的君子入侵者（得 $V/2$）；作为入侵者，它从君子占有者面前退走（得0）：$E(D, B) = V/4$。现在，$E(B, B) > E(H, B)$ 当且仅当 $2V > 3V - C$，即 $C > V$；且恒有 $E(B, B) = V/2 > V/4 = E(D, B)$。所以当 $V < C$ 时，君子对两种纯策略都满足 [[#eq-ess]] 的第一个条件。
:::

::: example 占有者与入侵者 {#ex-bourgeois}
取 [[#ex-hawkdove]] 的巢址争夺，$V = 50$、$C = 100$，并设每场争斗都在占有者与入侵者之间进行。比较君子种群中君子、鹰与鸽的收益，并把君子种群的平均收益与鹰鸽混合进化稳定策略处的收益相比较。
::: solution
由 [[#prop-bourgeois]]，$E(B, B) = 25$，$E(H, B) = (150 - 100)/4 = 12.5$，$E(D, B) = 12.5$。两种纯策略都不如君子，所以君子稳定。君子种群每场争斗得25——与全鸽种群相同，是混合进化稳定策略处所获12.5的两倍——因为打斗从不升级，争斗也不在对称展示中浪费时间。一条对双方都可观察的任意规则，把一场昂贵的博弈变成了无成本的博弈。
:::
:::

君子比鹰鸽混合进化稳定策略更好，因为不发生升级的打斗：每场争斗都按占有者获胜的约定解决，代价 $C$ 从不需要支付。逻辑上，反向约定——入侵者获胜——同样稳定，但它在实践中自我瓦解，因为这样占有关系会在每次相遇时易手；曾有人为极少数物种提出过这种建议，但很少见。

"占有者获胜"的约定在自然界广泛存在，但检验它是否真的任意却很困难。Nick Davies（1978）研究了占据林地晒日光光斑、并在光斑上等待雌蝶的雄性林眼蝶（*Pararge aegeria*）。当入侵者到来，会有一段短暂的螺旋飞行，而定居者总是保住光斑。当 Davies 让两只互不知晓的雄蝶进入同一光斑，使每只都"认为"自己是占有者时，其后的螺旋飞行持续得久得多。后来的研究（Darrell Kemp、Christer Wiklund 等）提示，定居者也可能体温更高、动机更强或素质更高，因此这一不对称并非纯粹约定性的。总体教训不变：占有是强有力的线索，但它是任意约定还是价值与战斗能力的关联物，必须逐例检验。

::: quiz
雄蝶 A 拥有一块领地；体型略大的雄蝶 B 前来入侵。在哪种情形下你最预期 B 升级而非退走？
- [ ] 领地价值不大且打斗危险时
- [x] 领地相对于打斗代价非常值钱，且 B 的体型优势给它很大的获胜机会时
- [ ] 只要 B 体型更大，不论价值与代价
- [ ] 永不，因为占有者总是获胜
::: solution
升级的期望收益——价值 $V$ 乘获胜概率——超过期望代价时才划算。$V/C$ 比值高与获胜机会大，都有利于升级。君子约定只在 $V < C$ 时稳定；当资源相对代价非常值钱（例如一只老年雄蝶的最后一次繁殖机会），约定便会瓦解。仅凭体型不能决定，而且占有者并非总能赢。
:::
:::

::: example 较弱者何时该战？{#ex-escalate}
一只入侵者估计自己若升级获胜的概率为 $w$。获胜得到值 $V$ 的领地；失败付出伤害代价 $C$；退走则无得无失。(a) $w$ 取何值时它应当升级？(b) 当 $V = 50$、$C = 100$ 时，阈值是多少？(c) 若这是它最后一次繁殖机会，$V = 300$ 呢？
::: solution
(a) 升级的期望收益为 $wV - (1 - w)C$，当 $w > C/(V + C)$ 时超过0（退走的收益）。

(b) $w > 100/150 = 0.67$：入侵者只有在相当有把握获胜时才该战。

(c) $w > 100/400 = 0.25$：当资源的价值远高于风险时，连自认必败者也该战。这就是年老或饥饿、几乎没有什么可损失的个体"亡命之徒"式升级的逻辑——它们的残余繁殖价值（代价 $C$ 最终代表之物）很小。这一计算也说明了准确评估 $w$ 为何宝贵：它让争斗双方都能避开自己会输的打斗。
:::
:::

### 评估与战斗能力

Geoff Parker（1974）引入了**资源持有潜力**（resource-holding potential，RHP）：个体在升级打斗中获胜的能力，由体型、武器、体况与技巧决定。若争斗双方能评估彼此的 RHP，较弱者就应不战而退；当双方差异大时争斗应很快解决，差异小时才升级。Magnus Enquist 与 Olof Leimar 的**序贯评估模型**（1983）把它形式化了：争斗经过信息与代价递增的各个阶段，只要"自己更强"的证据仍无定论，每个参与者就继续坚持。模型预言势均力敌的对手之间争斗持续最久、升级得最高——这是在从慈鲷到蜘蛛的许多物种中都能见到的格局。

什么使展示具有信息价值？只有当展示无法伪造时，它才可靠地揭示 RHP：马鹿雄鹿的吼叫所需的肌肉和耐力与打斗相同，而 Clutton-Brock 与 Albon 发现，疲惫或体况差的雄鹿吼叫频率下降。在欧洲蟾蜍（*Bufo bufo*）中，雄蟾会试图把情敌从抱对雌蟾背上掀下。Nick Davies 与 Tim Halliday（1978）发现，较大雄蟾鸣声的音调更低，因为较大的雄性声带更大；当他们向正发起攻击的雄蟾播放一只被镇静的雄蟾身旁音箱发出的低音或高音鸣声时，低沉的鸣声更能吓退攻击者。这些是**指标**的例子——其形式与所标示的品质在物理上绑定的信号——将在 [[behaviour/communication]] 中更充分地讨论。

## 消耗战博弈

许多争斗完全不涉及身体打斗：两个对手只是展示，直到一方放弃。获胜者是坚持更久的一方，而双方都支付与争斗时长成正比的代价。Maynard Smith（1974）称之为**消耗战博弈**。它有一个非凡的解。

::: proposition 消耗战博弈 {#prop-attrition}
两个参与者争夺价值 $V$ 的资源。各自选择坚持多久，单位时间的代价为 $k$；坚持更久的一方赢得 $V$，双方都支付 $k$ 乘以争斗时长（即两个坚持时间中较短者）。没有纯策略是进化稳定策略。进化稳定策略是一个混合策略，其中坚持时间 $x$ 取自指数分布

$$
f(x) = \frac{k}{V}\,e^{-kx/V}, \qquad x \ge 0,
$$ {#eq-attrition}

均值为 $V/k$：个体平均应准备支付与资源价值相等的代价。在进化稳定策略处，每个坚持时间都获得相同的期望收益，即为零。
:::

::: proof
没有纯坚持时间 $m$ 是稳定的：对一个总在 $m$ 退出的种群，一个坚持得稍久的突变体以极小的额外代价赢得每场争斗，而一个立即退出的突变体避免了代价 $km$（当 $km > V/2$ 时，它胜过了驻留者的 $V/2 - km$）。对混合策略，设对手的坚持时间 $Y$ 有密度 $f$ 与生存函数 $S(x) = P(Y > x) = e^{-kx/V}$。坚持时间 $x$ 的焦点个体在 $Y < x$ 时获胜，得 $V - kY$；在 $Y > x$ 时落败，付 $kx$。其期望收益为

$$
E(x) = \int_0^x (V - ky)f(y)\,dy - kx\,S(x).
$$

求导，$E'(x) = (V - kx)f(x) - kS(x) + kxf(x) = Vf(x) - kS(x)$，当 $f(x) = (k/V)S(x)$——恰为指数分布 [[#eq-attrition]]——时它对每个 $x$ 都为零。所以 $E(x)$ 是常数，又因 $E(0) = 0$，它处处为零。每个策略对抗进化稳定策略都表现相同；证明进化稳定策略对抗任何稀有备择策略都优于备择策略对抗自身（[[#eq-ess]] 的第二个条件）即可完成证明（Bishop 与 Cannings，1978）。
:::

结果惊人：在对称消耗战中，资源的全部价值平均而言都在展示代价中耗散。它还作出一个初看古怪的预言：个体的坚持时间应当不可预测——如果对手能准确预测你何时退出，它就会再多坚持一点点。

::: example 牛粪堆前的等待 {#ex-attrition}
在一场争夺值 $V = 10$ 单位资源的消耗战中，展示每分钟代价 $k = 1$ 单位。(a) 进化稳定策略处的平均坚持时间是多少？(b) 坚持超过10分钟、超过20分钟的个体比例各是多少？(c) 在采用进化稳定策略的种群中，恰好坚持5分钟的个体的期望收益是多少？
::: solution
(a) 均值为 $V/k = 10$ 分钟。

(b) $P(X > x) = e^{-kx/V} = e^{-x/10}$，所以 $P(X > 10) = e^{-1} = 0.37$，$P(X > 20) = e^{-2} = 0.14$。

(c) 为零，与进化稳定策略处每个坚持时间的收益一样。对抗在5分钟内退出的对手（概率 $1 - e^{-0.5} = 0.39$）它赢得10减去对手坚持的代价；对其余对手，它损失5个单位的展示。得失恰好相抵——对200 000场随机争斗的模拟在抽样误差范围内证实了这一点。（牛粪堆是向 Geoff Parker 的粪蝇（*Scathophaga stercoraria*）研究致意：雄蝇在牛粪堆上等待雌性，离开的决策在各种停留时间上带来相等的交配成就——混合进化稳定策略同样的"收益相等"标志，尽管那是一场对场博弈而非配对争斗。）
:::
:::

不对称同样改变消耗战。若一个参与者更看重资源，或支付的代价更低，它就应该坚持更久；在不对称消耗战中，进化稳定策略往往是处境更有利的一方无限期坚持、另一方立即退出——这是不靠打斗而快速达成和解的另一条路径。

::: application 行为之外的博弈论
进化博弈论早已传播到动物争斗之外。同样的逻辑——收益取决于策略频率，以及对抗入侵的稳定性——解释了产抗生素菌株与抗药菌株的共存、分泌共享酶的微生物种群中的合作与欺骗、肿瘤内部相互竞争的癌细胞种群的动力学、以及病原体的毒力。在渔业与野生动物管理中，它有助于预言：移除体型最大、最好斗个体的收获，如何改变残存种群中行为类型的频率。
:::

::: history
R. A. Fisher 的性比论证（1930）与 W. D. Hamilton 对不可击败性比的分析（1967），早在这一术语被引入生物学之前就使用了博弈论推理。Maynard Smith 与 Price 的《The logic of animal conflict》（*Nature*, 1973）引入了进化稳定策略，用的是"鹰"与"鼠"策略之间的争斗；鹰鸽之名在此后不久成为标准。Maynard Smith 1974年发表于 *Journal of Theoretical Biology* 的论文分析了消耗战，Parker 同年引入了资源持有潜力，Maynard Smith 与 Parker 在1976年处理了不对称争斗。Peter Taylor 与 Leo Jonker 在1978年建立了复制子动力学。Maynard Smith 的《Evolution and the Theory of Games》（1982）总结了这一理论。
:::

::: summary
- 当收益取决于他者做什么时，选择青睐进化稳定策略：一个当它常见时不能被稀有突变型入侵的策略（$E(I, I) > E(J, I)$，或相等而 $E(I, J) > E(J, J)$）。
- 在鹰鸽博弈中，若 $V \ge C$，鹰是进化稳定策略；若 $V < C$，进化稳定策略是以概率 $V/C$ 选鹰。处于进化稳定策略的种群所得低于全鸽种群。
- 复制子动力学 $\dot p = \tfrac12 p(1 - p)(V - pC)$ 把种群带向进化稳定策略频率。
- 混合进化稳定策略可实现为多态：太阳鱼中的交替繁殖策略、侧斑蜥蜴中循环的形态。
- 不对称能决定争斗结局：君子（占有者战、入侵者退）在 $V < C$ 时是进化稳定策略，并完全避免升级。占有究竟是任意约定还是价值的关联物，必须检验。
- 参与者通过无法伪造的展示评估资源持有潜力（马鹿的吼叫、蟾蜍鸣声的音调）；势均力敌的争斗持续最久。
- 消耗战中，坚持时间服从均值为 $V/k$ 的指数分布，每个坚持时间收益相同，资源价值在展示中耗散。
:::

## 练习

::: exercise 鹰的频率 {level=1 check="0.2"}
在 $V = 2$、$C = 10$ 的鹰鸽博弈中，处于进化稳定策略时多大比例的遭遇以鹰来打？
::: solution
$p^* = V/C = 2/10 = 0.2$。
:::
:::

::: exercise 纯鹰 {level=1}
证明当 $V = 10$、$C = 6$ 时鹰是进化稳定策略。鹰种群每场争斗的收益是多少？
::: solution
$E(H, H) = (10 - 6)/2 = 2 > E(D, H) = 0$，所以鸽不能入侵。每只鹰平均每场争斗得2——一半打斗获胜（得10），一半落败（付出6）。
:::
:::

::: exercise 进化稳定策略处的收益 {level=1 check="4"}
当 $V = 10$、$C = 50$ 时，处于鹰鸽进化稳定策略的种群中个体每场争斗的平均收益是多少？
::: solution
$p^* = 0.2$，两种策略都得 $W_D = (1 - 0.2)\times10/2 = 4$。（全鸽种群可得5。）
:::
:::

::: exercise 消耗战中的坚持 {level=2 check="exp(-1.5)"}
在 $V = 20$、每分钟代价 $k = 2$ 的消耗战中，进化稳定策略处多大比例的个体坚持超过15分钟？
::: solution
平均坚持时间为 $V/k = 10$ 分钟，且 $P(X > 15) = e^{-15/10} = e^{-1.5} \approx 0.223$。
:::
:::

::: exercise 君子对抗鹰 {level=2}
取 $V = 4$、$C = 6$。计算 $E(B, B)$、$E(H, B)$ 与 $E(D, B)$，并证明君子对抗两种纯策略都是进化稳定策略。然后计算 $E(H, H)$ 与 $E(B, H)$；君子能入侵鹰的种群吗？
::: solution
$E(B, B) = V/2 = 2$；$E(H, B) = (3V - C)/4 = 6/4 = 1.5$；$E(D, B) = V/4 = 1$。两者都低于2，所以君子能抵抗入侵。在鹰种群中，$E(H, H) = (4 - 6)/2 = -1$。君子突变体只遇到鹰：作为占有者它应战，平均得 $-1$；作为入侵者它退走，得0，所以 $E(B, H) = -0.5 > -1$。君子能入侵鹰种群。（鸽在这里也能入侵鹰，因为 $E(D, H) = 0 > -1$。）
:::
:::

::: exercise 一个复制子平衡 {level=2 check="0.4"}
对 $V = 4$、$C = 10$ 的复制子方程 [[#eq-replicator]]，求内部平衡并证明它稳定。
::: solution
$dp/dt = \tfrac12 p(1-p)(4 - 10p) = 0$ 于 $p = 0.4$。当 $p$ 略低于0.4，$4 - 10p > 0$，$p$ 增大；略高于它，$p$ 减小。该平衡吸引附近的轨线，所以稳定。
:::
:::

::: exercise 解读争斗数据 {level=2}
在一项针对某种领地鱼的研究中，定居者在与入侵者的争斗中赢得85 %。定居者平均比入侵者大5 %。体型差异很大的鱼之间的争斗持续几秒；体型相近的鱼之间的争斗持续数分钟，且更常涉及撕咬。(a) 85 %这个数字能说明定居者靠任意约定获胜吗？(b) 争斗持续时间对评估有何提示？(c) 设计一个试验来分离居留效应与体型效应。
::: solution
(a) 不能。定居者更大，而且可能更看重领地（它们熟悉其资源）或动机更强，所以这一不对称与 RHP 和价值混杂在一起。(b) 这一格局——RHP 差异大时争斗短暂、相近时漫长且升级——正是序贯评估博弈之类评估模型的预言：只要谁更强尚不确定，参与者就继续坚持。(c) 把体型配对的个体成对组合，随机指定哪个成为定居者（让它先进入水箱定居）；或者让入侵者比定居者大出不同的幅度，检验定居者获胜的概率是否随入侵者的体型优势而下降。若体型相同的一对中定居者获胜，则居留本身（或它带来的东西，例如对场地的了解）起了作用。
:::
:::

::: exercise 混合策略还是多态？{level=3}
某物种中"攻击型"遭遇的频率稳定在30 %。解释你如何判断这是每个个体在30 %的遭遇中升级，还是30 %的个体总是升级。这一区分为何可能在进化上重要？
::: solution
标记个体并跟踪它们的多次争斗。混合策略下，每个个体的升级频率应当接近0.3，围绕它有二项变异，且过去的行为不应预言未来的行为。多态下，个体应当前后一致——有些几乎总是升级，另一些几乎从不——个体频率呈双峰分布，重复性高，并且（若这一多态是遗传的）亲子之间存在相似。这一区分之所以重要，是因为遗传多态由等位基因上的频率依赖选择维持，其频率随世代依复制子动力学变化，而混合策略可以在一生中改变；条件策略（体型较大时升级，或饥饿时升级）是第三种可能——个体行为不同是因为它们状态不同，而非基因型不同。
:::
:::

::: exercise 昂贵的展示 {level=3}
修改鹰鸽博弈，使两只鸽相遇时各先付出展示代价 $D$，然后（随机）一只获胜。写出收益矩阵，并求 $V < C$ 时鹰的进化稳定策略频率。当 $D$ 增大时会怎样？
::: solution
$E(D, D) = V/2 - D$；其余收益不变。鹰的频率为 $p$ 时，$W_H = p(V - C)/2 + (1 - p)V$ 且 $W_D = (1 - p)(V/2 - D)$。令二者相等：

$$
p\,\frac{V - C}{2} + (1 - p)V = (1 - p)\Bigl(\frac{V}{2} - D\Bigr) \quad\Longrightarrow\quad p\,\frac{V - C}{2} + (1 - p)\Bigl(\frac{V}{2} + D\Bigr) = 0,
$$

所以 $p^* = \dfrac{V + 2D}{C + 2D}$。当 $D = 0$ 时它就是 $V/C$；随着 $D$ 增大，$p^*$ 上升并趋向1。昂贵的展示使鸽更不划算，于是更多争斗升级——这也是选择可能青睐廉价的争斗解决方式（如约定，或可靠的 RHP 指标）的一个原因。
:::
