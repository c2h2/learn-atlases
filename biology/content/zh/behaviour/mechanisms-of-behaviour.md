把一只果蝇幼虫放到一碟酵母膏上，观察它摄食。有些幼虫边吃边爬过很长的距离，在食物上四处游走；另一些则守在小片区域里。Marla Sokolowski 在1980年描述了黑腹果蝇（*Drosophila melanogaster*）的这一差异，把两种类型称为**漫游者** (rovers) 与**静息者** (sitters)，并证明这一差异的大部分对应于单个基因，她将其命名为 *foraging*（*for*）。该基因编码一种 cGMP 依赖性蛋白激酶（PKG）；漫游者神经系统中的 PKG 活性高于静息者。二十年后，蜜蜂中的同源基因被发现，在去巢外觅食的工蜂脑中的表达水平，高于在巢内哺育幼蜂的年轻工蜂——而给蜜蜂喂食一种激活 PKG 的药物，会使它们提前开始觅食。

这些结果令人兴奋，因为它们把行为与分子联系起来；也暗藏凶险，因为它们诱使人说出"一个负责觅食的基因"这样的话。本章谈的是 Tinbergen 的前两个问题（[[behaviour/studying-behaviour#def-four-questions]]）：产生行为的机制，以及行为如何发育。我们先看基因——它们的贡献如何被测量，单个基因的效应何意味、又何不意味——再看激素，它把动物的内部状态与环境同其行为连接起来；然后看检测刺激并产生动作的神经回路，用的几个系统从感觉器官到动作的路径已被了解。最后以发育收尾：先天与习得的旧二分法为何失败，以及取而代之的是什么。细胞神经科学见 [[neuroscience/synapses]] 与 [[neuroscience/sensory-systems]]；内分泌生理学见 [[animal-physiology/endocrine-control]]。

## 基因与行为

没有任何基因以它编码蛋白质的那种方式"编码"行为。基因编码的是构建与运行神经系统、肌肉与内分泌腺的 RNA 与蛋白质；行为是这些系统在环境中做的事。尽管如此，个体之间行为的差异常常部分地由它们基因的差异造成，而这正是行为遗传学所度量的。

::: definition 行为的遗传变异 {#def-behgen}
当个体的基因型（在一定的环境范围内）能预言其行为时，该行为在一个种群中就表现出**遗传变异**。其程度以**遗传力** $h^2 = V_A/V_P$ 度量，即表型方差中源于加性遗传方差的比例（[[population-genetics/quantitative-traits]]），可由亲属间的相似或从对选择的响应来估计。大效应基因的鉴定靠**杂交**与**作图**（数量性状基因座、关联分析），并以**操纵**检验：突变、敲除、RNA 干扰敲低、转基因表达或基因编辑。
:::

行为的遗传力通常为中等偏低。野生动物中行为与个性状（大胆性、探索性、攻击性、迁徙性躁动）的遗传力估计常落在0.1–0.4左右，平均低于形态性状——部分因为行为的测量误差更多、随情境的变化更大。遗传力是一个种群在一种环境中的属性，而不是一个性状的属性：它对一个个体的行为有多大程度"由基因决定"什么也不说。

选择实验显示出同样遗传变异的实际作用。把最活跃、攻击性最强或最喜探索的个体与最不活跃、攻击性最弱或最不爱探索的个体分别繁殖几代，各品系通常会彼此分歧。

::: proposition 育种方程 {#prop-breeder}
若对一个群体这样进行选择：以其表型均值超出群体均值 $S$（**选择差**）的个体作亲代，则下一代均值的期望变化（**响应**）为

$$
R = h^2 S.
$$ {#eq-breeder}

假设：加性遗传效应（显性或上位互作不贡献于亲子相似）、代际间环境恒定、无基因型-环境相关，以及选择作用于表型本身而非某个相关性状。推导见 [[population-genetics/response-to-selection]]。
:::

::: example 对探索行为的选择 {#ex-selection}
在一个圈养大山雀群体中，造访新奇房间里人工树的时间均值为120 s、标准差40 s（示意数字）。最快的探索者平均时间70 s，被放在一起繁殖。若探索速度的遗传力为0.3，其后代的期望平均探索时间是多少？若 $h^2$ 与 $S$ 保持不变，这样的选择大约多少代能把均值减半？
::: solution
选择差为 $S = 70 - 120 = -50$ s，故 $R = 0.3\times(-50) = -15$ s，后代的期望均值为 $120 - 15 = 105$ s。要把均值减半（到60 s），需要改变60 s，照此速率需 $60/15 = 4$ 代。实践中，随着均值下降、方差变化，以秒计的 $S$ 会缩小，而遗传方差被消耗时 $h^2$ 也可能下降，所以响应通常减速。（荷兰 Piet Drent 与合作者建立的大山雀探索行为真实选择系，在几代之内就发生了分歧，与处于这个范围的遗传力相符。）
:::
:::

### 大效应基因

大多数行为变异是多基因的，但少数几个大效应基因已被鉴定，它们的宝贵之处在于为某种行为提供了分子抓手。

*foraging* 基因是经典案例。漫游者与静息者品系之间的杂交表明，这一差异大体表现为单个孟德尔基因座的分离，漫游者等位基因（*for*^R^）对静息者等位基因（*for*^s^）为显性。Kevin Osborne 与合作者 (1997) 证明，该基因座编码 PKG，静息者的 PKG 活性较低，而给静息者果蝇加进一个漫游者型的基因拷贝会使它们行为得像漫游者。两个等位基因在自然种群中共存，且幼虫密度高时漫游者占优，密度低时静息者占优——一个由频率或密度依赖的选择维持行为多态性的案例。

::: example 漫游者-静息者杂交 {#ex-rover}
一个漫游者品系与一个静息者品系杂交；F1 代幼虫全是漫游者。在 F2 代中，290只被记为漫游者、110只被记为静息者（示意计数）。这些数据与单个完全显性基因座一致吗？
::: solution
单个基因座且 *for*^R^ 显性预言3 : 1的比例，即400只之中300只漫游者与100只静息者。χ² 统计量为

$$
\chi^2 = \frac{(290 - 300)^2}{300} + \frac{(110 - 100)^2}{100} = 0.333 + 1.000 = 1.33,
$$

自由度 $2 - 1 = 1$，得 $p = 0.25$ ([[biostatistics/categorical-data]])。数据与3 : 1假说一致。一致不是证明：接近3 : 1的比例也可能由一个主基因座加修饰基因产生，而处在两类界限之间的幼虫会被错分。真正确立 *for* 就是那个基因的，是分子工作，而不是这个比例。
:::
:::

在社会性昆虫中，同一个基因家族再次出现。Yehuda Ben-Shahar、Gene Robinson 与合作者 (2002) 发现，蜜蜂（*Apis mellifera*）的觅食蜂比同日龄哺育蜂脑内 *for* 的同源基因（*Amfor*）表达更高，而用一种激活 PKG 的 cGMP 类似物处理年轻蜜蜂，会使它们过早开始觅食。在这里，该基因的角色是**调节一种行为转变的时间**——所有工蜂都要经历这种转变——而不是制造个体之间固定的差异。

在哺乳类中，最著名的例子涉及田鼠的配对结合。草原田鼠（*Microtus ochrogaster*）形成持久的配对结合；近缘的草地田鼠（*M. pennsylvanicus*）则没有固定配偶。两个物种的差异在于脑内神经肽血管加压素与催产素受体的分布。Miranda Lim、Larry Young 与合作者 (2004) 用病毒载体在雄性草地田鼠的腹侧苍白球提高血管加压素 V1a 受体基因的表达，这些雄鼠随后对熟悉的雌性伙伴产生了偏好——配对结合的一个组分。一个基因、一个脑区的表达改变，改变了一种社会行为。

::: warning "一个负责配对结合的基因"
田鼠实验这类结果常被报道为发现了"一夫一妻制的基因"。它们实际表明的是：在田鼠脑与环境其余一切保持不变的前提下，改变一个基因在一个部位的表达可以改变一种行为。同一受体参与许多行为；血管加压素受体分布的变异并不能预言所有田鼠乃至啮齿类的交配制度；后来的工作发现，用基因编辑做出的缺乏功能性催产素受体基因的草原田鼠，仍能形成配对结合（Hephzibah Berendzen 与合作者，2023）。一个基因可以对某种行为是*必要*的——在某遗传背景下敲除它即消除该行为——而并不*充分*，也可以不是造成该行为自然变异的基因。类比一辆汽车：拔掉火花塞车就停了，但火花塞不是"负责驾驶的基因"。
:::

::: quiz
一只缺乏基因 *X* 功能拷贝的敲除小鼠，对入侵者毫无攻击性。哪个结论站得住？
- [ ] 基因 *X* 是负责攻击的基因
- [ ] 小鼠攻击性的自然变异由基因 *X* 的变异引起
- [x] 在这一遗传背景与这一测试中，基因 *X* 的产物是正常攻击行为所必需的
- [ ] 攻击性是先天的
::: solution
敲除显示的是某一遗传背景与测试中的必要性。它不表明 *X* 专属于攻击（这些小鼠也许病了、嗅不到入侵者、或整体活动减少——对照必须排查这些），也不表明攻击性的自然变异涉及 *X*，更不表明任何关于"先天性"的事。后续工作会检验其他行为、其他遗传背景与自然等位基因。
:::
:::

## 激素与行为

激素以从几分钟到几个季节的时间尺度，把动物的生理与环境同行为连接起来。内分泌学的第一个实验就是一个行为实验：1849年，Arnold Berthold 给幼公鸡去势，它们此后不再发育出鸡冠、打鸣与好斗；把一颗睾丸移植进被去势鸟的腹腔后，雄性特征与行为又发育起来。既然移植的睾丸没有任何神经支配，那必定是它分泌入血的某种东西在起作用。

激素大致以两种不同的方式作用于行为。

::: definition 组织化效应与激活化效应 {#def-orgact}
激素的**组织化**效应，是在发育的敏感期内对神经系统结构造成的永久改变，它决定成体日后对激素与刺激的反应。激素的**激活化**效应，是成体中某种行为发生概率的暂时改变，其持续大致与激素存在的时间相若。这一区分由 Charles Phoenix、Robert Goy、Arnold Gerall 与 William Young 于1959年提出，依据是这样的实验：出生前接触过睾酮的雌性豚鼠，成年后在成体激素处理下，雌性典型的性行为减少而雄性典型的增多。
:::

这一区分是有用的初步近似；青春期那些部分带组织化性质的激素效应，以及成年脑的结构变化——比如鸣禽在睾酮之下控制鸣唱的核团的季节性生长——都使这条界线变得模糊。

激素对靶细胞的作用取决于激素与受体的结合，而结合是浓度的饱和函数。描述剂量-反应关系的一种常用形式是 Hill 函数。

::: proposition 饱和的剂量-反应 {#prop-hill}
若反应正比于被结合的受体的比例，且结合具有 Hill 系数 $n$ 的协同性，则对激素浓度 $H$ 的反应为

$$
\frac{\text{response}}{\text{maximum response}} = \frac{H^n}{K^n + H^n},
$$ {#eq-hill}

其中 $K$ 是给出半最大反应的浓度。当 $n = 1$（简单结合）时曲线是双曲的；当 $n > 1$ 时它是 S 形的、像开关。这是一个经验描述：真实的行为剂量-反应曲线也可以是非单调的（倒 U 形），因为高剂量会激活别的受体或反馈回路。
:::

::: widget plot
f: x^n/(k^n + x^n)
x: 0, 10
y: 0, 1.05
sliders: k=2:0.5:8:0.1; n=1:1:6:0.5
labels: \text{最大反应的比例}
hlines: 0.5
caption: Hill 剂量-反应函数 [[#eq-hill]] 对激素浓度（任意单位）。移动 $k$ 可平移阈值；增大 $n$ 可使反应更像开关。当 $n=1$ 时，浓度从 $k$ 加倍到 $2k$，反应从0.5升到0.67；当 $n=4$ 时，同样的加倍把反应升到0.94。陡峭的曲线意味着：循环激素在阈值附近的小变化会引起行为的大变化，而在饱和点以上再加激素也无济于事。
:::

饱和这一点对一个经典发现至关重要。去势能消除啮齿类的大部分雄性性行为，补充睾酮可以恢复——但完整雄鼠之间性行为的个体差异并不被它们的睾酮水平预言，因为几乎所有完整雄鼠的水平都落在曲线的饱和段上。一个激素可以是某种行为所必需的，而它的自然变异却解释不了行为中的变异。

::: example 饱和与个体差异 {#ex-saturation}
假设一只雄鼠在一次测试中爬跨接受交配的雌鼠的概率是 $H^2/(1 + H^2)$，其中 $H$ 是以半最大浓度为单位计的循环睾酮水平。完整雄鼠的数值从 $H = 3$ 一直到 $H = 6$；去势雄鼠的 $H \approx 0.2$。试比较两组之间以及完整范围两端之间的预期行为。
::: solution
$H = 0.2$ 时：$0.04/1.04 = 0.04$。$H = 3$ 时：$9/10 = 0.90$。$H = 6$ 时：$36/37 = 0.97$。去势把概率从约0.9–0.97降到0.04，效应惊人；而在完整范围内，两倍的睾酮差异只改变行为7个百分点，很容易被其他变异来源淹没。拿完整雄鼠做相关研究的人会错误地断言睾酮与性行为"关系不大"；操纵实验则表明它是必需的。
:::
:::

### 激素、行为与社会环境

激素不只是引起行为；行为与社会经验也会改变激素。Daniel Lehrman 在1950年代与1960年代对斑鸠（*Streptopelia risoria*）的研究揭示了一条相互作用的链条：雄鸟的求偶刺激雌鸟卵巢分泌雌激素，雌激素使其筑巢；筑巢与孵卵又刺激孕酮随后催乳素的分泌，催乳素使双亲为幼鸽分泌嗉囊乳。行为的每一个阶段都为下一阶段铺垫了激素条件。

在许多鸟类中，雄鸟的睾酮在建立领地或受到挑战时急剧升高，在给雏鸟喂食时下降。John Wingfield 与合作者 (1990) 把这一模式形式化为**挑战假说**：在社会性挑战之下，睾酮会升高到繁殖基线之上，在雄鸟参与育幼的物种中尤其如此，因为高睾酮促进攻击、却干扰育幼。在双亲育幼的物种（如暗眼灯草鹀 *Junco hyemalis*）给雄鸟埋植睾酮，增加了鸣唱与领域行为、减少了对雏鸟的喂食，与权衡相符。

社会地位能在几天之内重组大脑。在非洲慈鲷 *Astatotilapia burtoni* 中，只有少数雄鱼占有领地；它们体色鲜艳、繁殖活跃，而从属雄鱼体色暗淡、睾丸退化。Russell Fernald 的团队表明，当从属雄鱼获得接管领地的机会时，下丘脑中产生促性腺激素释放激素（GnRH）的神经元会增大，而这些神经元中即刻早期基因的表达在地位改变后数分钟之内就升高。社会机会驱动内分泌的变化，内分泌的变化随后支撑起行为。

::: application 内分泌干扰物与行为
由于激素在敏感期组织行为，环境中模拟或阻断激素的化学品就能改变行为。鱼类、两栖类与鸟类暴露于雌激素类化合物——来自含合成雌激素（避孕药所用）的污水排放物，或来自工业化学品——已被联系到实验室与野外研究中求偶与生殖行为的改变，某些情况下还联系到种群数量下降。其机制就是上文描述的组织化与激活化效应，这正是化学品评价中越来越多地纳入行为测试的原因（毒理学本身在本课程之外）。
:::

## 神经机制

**神经行为学** (neuroethology) 研究自然行为的神经基础。它的成功来自选择那些神经系统可及、而行为明显适应某一特定问题的动物。反复出现的是三个问题：神经系统如何挑出相关的刺激，如何作出决定，如何产生动作。

### 筛选世界

每种动物只感知其物理环境的一个切片——Jakob von Uexküll 在1909年称之为它的 *Umwelt*。蜂看得到紫外；蝮蛇探测红外；许多鱼类能感知电场；蝙蝠与蛾类生活在超声的世界里。在其 *Umwelt* 之内，动物的神经系统提取出那些要紧的特征。

特征提取的经典案例是欧洲蟾蜍（*Bufo bufo*）的捕食。Jörg-Peter Ewert 在1970年代与1980年代表明，蟾蜍会转向并猛啄一根沿长轴移动的暗色长条（"虫"形），却无视甚至回避同一根垂直于长轴移动的长条（"反虫"形）。从脑内记录时，他发现视顶盖中有些神经元的反应与行为偏好相符，而丘脑/顶盖前区中有些神经元对"反虫"刺激反应最强，并抑制顶盖。经典习性学的行为信号刺激（[[behaviour/studying-behaviour#def-fap]]）对应的正是特定神经元群体的调谐。

### 蛾与蝙蝠

在神经元水平上对捕食者-猎物相互作用最完整的论述，是 Kenneth Roeder 在1960年代对夜蛾科蛾类所做的工作。食虫蝙蝠靠回声定位觅食，发出极强的超声脉冲。许多蛾有简单的耳，胸廓每侧一只，每只只有两个听觉感受细胞，A1 与 A2。A1 敏感，对微弱超声起反应；A2 只对强声起反应。Roeder 发现，蛾会背离微弱的超声——远处的蝙蝠；而当声音强烈、如同蝙蝠近在咫尺时，便做出无规则的翻滚、盘旋或急速俯冲。由于每只耳的反应与声源方向有关，蛾能够对远处的蝙蝠转开。

::: example 谁先听见谁？ {#ex-moth}
一只蝙蝠发出的鸣声，在其口部0.1 m 处测得的声压级为110 dB（示意但写实的数值）。声波球面扩散，距离每加倍损失6 dB，即距离 $r_0$ 与 $r$ 之间相差 $20\log_{10}(r/r_0)$ dB。假设蛾的 A1 细胞在高于50 dB 时起反应（示意阈值）。（a）忽略空气吸收，蛾最早能在多远处首次听到蝙蝠？（b）40 kHz 上下的超声还被空气吸收，约每米1 dB，视湿度而定。这会如何改变答案？（c）为什么蝙蝠要晚得多才发现蛾？
::: solution
（a）需要 $110 - 20\log_{10}(r/0.1) = 50$，故 $\log_{10}(r/0.1) = 3$，$r = 100$ m。

（b）计入吸收后，声级为 $110 - 20\log_{10}(r/0.1) - 1\times(r - 0.1)$。数值求解得 $r \approx 16$ m：在远距上吸收占主导，这正是蝙蝠要用如此之强的鸣声的原因。

（c）蝙蝠听到的是*回声*，它把距离走了两遍、被衰减了两遍，并在从只有一两厘米宽的目标上反射时失去了大部分能量。它对一只蛾的探测距离因此至多几米。在数十米外就听到蝙蝠的蛾，有时间在自己被发现之前转开——这就是 Roeder 对"简单的耳为何如此有效"的解释。军备竞赛仍在继续：有些蝙蝠改用蛾耳较不敏感的频率或强度鸣叫，而有些灯蛾会发出咔哒声去干扰或警告蝙蝠（[[behaviour/communication]]）。
:::
:::

### 运动的产生

许多节律性行为——行走、游泳、飞行、呼吸、咀嚼——由**中枢模式发生器** (central pattern generators) 产生：脊髓或神经节中的神经元网络，无需节律性输入即可生成节律性模式，而感觉反馈对其进行调整。Donald Wilson 于1961年证明，切断来自翅膀的感觉神经后，蝗虫飞行的运动模式仍然存在，只是频率较低。蟹与龙虾的胃贲门神经节只有约30个神经元，它成了这类网络如何工作、以及神经调质如何将其重新配置以产生不同节律的模型。

在另一个极端，是由少数几个大神经元介导的逃逸反应。鱼类后脑中的成对 **Mauthner 细胞**接收来自内耳与侧线的感觉输入，一旦发放，便触发身体对侧肌肉的强力收缩，把鱼体弯成 C 形，并在数毫秒之内把它弹离刺激。螯虾的弹尾逃逸由巨纤维以同样的方式驱动。这些系统最接近 Irving Kupfermann 与 Klaudiusz Weiss (1978) 提出的**指令神经元** (command neuron) 概念：一个神经元的活动对某种行为既必要又充分。大多数行为并不组织得这么简单；决定分布在神经元群体之中，而同一回路在不同神经调质状态下可以产生不同的行为（[[neuroscience/motor-systems]]）。

### 时钟

许多行为由内部的时钟计时。在恒定条件下饲养的动物继续表现出活动的日节律，周期接近但并不恰好是24 h——一种**自由运行** (free-running) 的节律——在自然界中它被光与其他线索（授时因子）**同步** (entrained) 到24 h。

::: example 自由运行的节律 {#ex-freerun}
一只在恒定黑暗中饲养的小鼠，每晚转轮活动的开始时间每天大约提前30分钟。它的自由运行周期 $\tau$ 是多少？10天后，其活动起始相对外界白天漂移了多少？
::: solution
每个周期都提前30分钟开始，意味着每个周期比24 h 短30分钟：$\tau = 23.5$ h。10天后，活动起始已向前漂移了 $10\times0.5 = 5$ h。节律由内部产生（否则它会一直锁在外界白天上，或者消失），而其周期并不恰好是24 h，这就是每天需要光来重置它的原因。夜行性啮齿类在恒定黑暗中，$\tau$ 通常略小于24 h。
:::
:::

分子时钟首先是被遗传学打开的。Ronald Konopka 与 Seymour Benzer (1971) 对诱变的果蝇筛选羽化与活动节律的变异，找到了同一个 X 连锁基因 *period*（*per*）的三个等位基因：一个使周期约19 h，一个约28 h，一个使节律消失。*per* 基因与其伙伴（它们构成一个转录-翻译反馈环）在1980年代与1990年代被克隆；Jeffrey Hall、Michael Rosbash 与 Michael Young 因这项工作分享了2017年的诺贝尔生理学或医学奖。相关的时钟基因运行着哺乳类的节律，主钟位于下丘脑的视交叉上核，此外大多数组织中也各有时钟。时钟还能让动物在用太阳作罗盘时补偿太阳的移动（[[behaviour/migration-navigation]]），年计时则为迁徙与繁殖定时。

## 行为如何发育

经典习性学家区分**先天**行为——无需学习机会即可出现——与**习得**行为。Daniel Lehrman 于1953年对 Lorenz 的批评，以及 Patrick Bateson 后来的工作，说明了这一二分法为何承受不起压在它身上的重量。每种行为都由基因与环境的相互作用发育而来，环境包括卵内或子宫内的环境。"剥夺"实验在缺少某种经验的条件下降养动物，只能表明*那种*经验并非必需，而不能表明行为一般地不依赖经验。鸟的胚胎在出壳之前就能听到声音；哺乳类在子宫里就经验到母亲的激素与食物。

::: definition 发育可塑性与反应规范 {#def-plasticity}
**发育可塑性** (developmental plasticity) 是一个基因型在不同环境中发育出不同表型的能力。一个基因型的**反应规范** (reaction norm) 是其表型随环境变量而变的函数。行为的遗传变异于是对应于反应规范的差异；当反应规范不平行时，就存在**基因型-环境互作** (genotype-environment interaction)，此时哪个基因型表现得"更多"取决于环境。**敏感期** (sensitive period) 是发育中的一个阶段，在此期间某种特定经验产生异常之大或异常持久之久的效应。
:::

"这一行为有多大比例归于基因、多大比例归于环境？"这一问题，只有对种群中的*差异*才有有意义的回答（[[#def-behgen]]），对一个体的行为则永远没有。一个有用的类比（Bateson 提出）是烘焙：问一块蛋糕的味道有几分来自面粉、几分来自烤炉，是毫无意义的。

### 可塑性的两个例子

沙漠蝗（*Schistocerca gregaria*）存在两种形态。散居型蝗虫在低密度时隐蔽而不彼此接近；群居型蝗虫结成虫群，活跃、相互吸引、体色不同。拥挤能在几小时之内把散居型行为转变为群居型。Michael Anstey、Stephen Rogers、Malcolm Burrows 与合作者 (2009) 表明，拥挤——确切说是其他蝗虫对后足的机械刺激，以及对它们的视与嗅——引发胸神经节中血清素的一波激增；阻断血清素可阻止行为的群居化，而施加它则能诱导群居化。同一个基因型，依密度在两种截然不同的行为表型之间切换。

母体行为也会塑造后代的发育。实验室大鼠的母亲在舔舐与梳理幼仔的多少上存在稳定的个体差异。Michael Meaney 的团队发现，高舔理母鼠的成年后代应激反应较低，而且它们自己做了母亲后，对幼仔的舔理也更多。由于差异可能出自基因，决定性的实验是**交叉寄养** (cross-fostering)：出生于低舔理母亲、而由高舔理养母抚养的幼仔，发育得像高舔理母亲的后代。Ian Weaver 与合作者 (2004) 把这一效应与被充分舔理的幼仔海马中糖皮质激素受体基因启动子上 DNA 甲基化的降低联系起来——这是一种表观遗传机制，经验可以不改变基因而跨代传递。

::: example 解读一个交叉寄养实验 {#ex-crossfoster}
大胆品系与羞怯品系小鼠的幼仔在出生时被交叉寄养，使每只幼仔都由某一品系的母亲抚养。成年后，测定它们进入新奇场地的潜伏期（越短＝越大胆）。平均潜伏期（示意，单位秒）如下：

| 幼仔品系（行），养母（列） | 大胆养母 | 羞怯养母 |
|---|---|---|
| 大胆 | 40 | 70 |
| 羞怯 | 100 | 130 |

这些结果说明了什么？你还想要什么进一步的对照？
::: solution
在同一抚养环境内，大胆品系幼仔比羞怯品系快60 s：存在一个60 s 的遗传（或产前）效应。在同一品系内，由羞怯养母抚养会增加30 s：一个30 s 的出生后母体效应。两个效应相加（两行之间与两列之间的差都相同），所以这一范围内不存在基因型-环境互作。幼仔的品系仍包含了子宫环境，所以"遗传"效应可能有部分是产前的；胚胎移植（把胚胎植入另一品系的母亲）能把遗传效应与产前母体效应分开。把幼仔移交给同品系另一养母的寄养对照组，可以核查寄养这一操作本身是否改变行为。
:::
:::

发育可塑性不是遗传控制的失灵，而常常本身就是一种适应。当环境在各代之间不可预测地变化、而生命早期可得的线索能预言动物将要面对的条件时，选择就偏爱把表型匹配到线索上的反应规范。学习（[[behaviour/learning-cognition]]）是这种可塑性最灵活的形式：它贯穿一生，把行为调整到基因无法预见的条件上。

::: history
Berthold 的去势实验（1849）开创了内分泌学。1930年代至1950年代的习性学家主张大部分行为是先天的，这一立场在1953年遭到 Lehrman 的挑战。Phoenix、Goy、Gerall 与 Young 于1959年提出了组织化-激活化区分。Roeder 的《Nerve Cells and Insect Behavior》(1963) 帮助创建了神经行为学，而 Konopka 与 Benzer 的 *period* 突变体（1971）打开了果蝇行为的遗传学，Sokolowski 的漫游者-静息者研究（1980）亦然。分子与基因组方法——从1990年代起的小鼠敲除、田鼠中的病毒基因转移（2004）、2000年代中期的光遗传学、2010年代在非模式物种中的基因编辑——此后使在行为中的动物体内操纵特定基因与神经元成为可能。
:::

::: summary
- 基因通过它们所构建与运行的神经、内分泌与肌肉系统影响行为；行为表现出可遗传的变异（常常 $h^2 \approx 0.1$–$0.4$），并依 $R = h^2 S$ 响应选择。
- 大效应基因——果蝇与蜜蜂的 *foraging*、田鼠的血管加压素 V1a 受体——为行为提供了分子抓手，但敲除与转基因实验显示的是情境中的必要性，而不是某个基因"负责"某一行为。
- 激素在敏感期有组织化效应，在成体有激活化效应；剂量-反应曲线会饱和，所以一个激素可以是必需的，却不解释个体差异。
- 行为与社会情境对激素有反作用（斑鸠、挑战假说、慈鲷中的地位）。
- 神经行为学把行为与回路连接起来：蟾蜍的特征检测器、蛾只有两个细胞的耳、中枢模式发生器、Mauthner 细胞的逃逸，以及分子层面的昼夜节律钟。
- 先天-习得二分法失败了：每种行为都通过基因-环境互作发育。反应规范、敏感期、蝗的相变与母体效应（交叉寄养）展示了其中的机制。
:::

## 练习

::: exercise 组织化还是激活化？ {level=1}
给每种效应归类：（a）在子宫内夹在两个雄兄弟之间发育的雌鼠，成年后更具攻击性；（b）去势的雄金丝雀停止鸣唱，给予睾酮后又恢复；（c）控制鸣唱的核团 HVC 在春季的季节性生长。
::: solution
（a）组织化：产前暴露于邻近雄性胎儿的睾酮，永久地改变后来的行为。（b）激活化：行为跟随成体内激素的有无。（c）一个模糊案例——由睾酮驱动的成年脑的结构变化，秋天激素水平下降时会逆转；它通常被归为激活化，但涉及组织化式的重建。
:::
:::

::: exercise 一个行为杂交的 χ² {level=1 check="1.333"}
某个 F2 代的400只果蝇中有290只漫游者与110只静息者。对3 : 1假说计算 χ² 统计量（保留三位小数）。
::: solution
期望值为300与100：$\chi^2 = 100/300 + 100/100 = 1.333$，自由度1（$p \approx 0.25$）。
:::
:::

::: exercise 时钟的漂移 {level=1 check="9"}
一只夜行动物在恒定黑暗中的自由运行周期为24.6 h。15天后，其活动起始相对钟表时间漂移了多少小时？
::: solution
每个周期比24 h 长0.6 h，故15天后起始晚了 $15\times0.6 = 9$ h。
:::
:::

::: exercise 对选择的响应 {level=2 check="0.6"}
某行为的遗传力为0.3。所选亲代的均值比群体均值高2个单位。一代中的期望响应是多少？
::: solution
$R = h^2 S = 0.3\times2 = 0.6$ 个单位。
:::

::: exercise 开关式的反应 {level=2 check="0.2"}
用 Hill 函数 [[#eq-hill]]，$n = 2$，激素处于半最大浓度之半（$H = K/2$）时，期望的最大反应比例是多少？在 $H = 2K$ 时又是多少？
::: solution
当 $H = K/2$：$(1/4)/(1 + 1/4) = 0.2$。当 $H = 2K$：$4/(1 + 4) = 0.8$。浓度四倍的变化把反应从20 %带到80 %。
:::
:::

::: exercise 必要但不负责 {level=2}
敲除小鼠的基因 *Y* 会消除营巢行为。在一个野生种群中，小鼠巢的大小差异很大，但测序并未发现 *Y* 上的变异。这里存在矛盾吗？哪些类型的基因或因素可以解释营巢行为的自然变异？
::: solution
没有矛盾。敲除表明 *Y* 对营巢是必需的；群体数据表明 *Y* 没有变异，因此无法解释差异。自然变异可以来自其他小效应基因座（Lynch 对家鼠营巢的选择系对选择稳步响应，提示多基因变异）、影响 *Y* 表达而非其序列的调控变异、环境（温度、材料、经验）、或母体效应。一个行为所必需的基因，与使个体在该行为上彼此不同的基因，常常是两套不同的基因。
:::
:::

::: exercise 解读一张反应规范的表 {level=2}
两个品系的鱼分别养在低密度与高密度下，并测定攻击性（每10 min 的咬击次数）：品系 A 为5（低）、15（高）；品系 B 为10（低）、8（高）。描述反应规范。说品系 B "遗传上更具攻击性"有意义吗？
::: solution
品系 A 的攻击性随密度急剧上升；品系 B 的大致持平并略降。两条反应规范相交：低密度下 B 更强，高密度下 A 更强。这是一个基因型-环境互作，所以"某个品系遗传上更具攻击性"这种说法只有在指定环境之后才有意义。在一种环境中估计的遗传力无法预言另一种环境。
:::
:::

::: exercise 听觉距离 {level=3 check="31.6"}
在 [[#ex-moth]] 中，忽略吸收，假设一只更安静的蝙蝠在0.1 m 处以90 dB 鸣叫，而蛾的阈值是40 dB。蛾最早在多远处能听到它（以米计，三位有效数字）？一只以110 dB 鸣叫的蝙蝠，蛾又会在远多少处听到？这对鸣声强度的军备竞赛意味着什么？
::: solution
需要 $90 - 20\log_{10}(r/0.1) = 40$，故 $\log_{10}(r/0.1) = 2.5$，$r = 0.1\times10^{2.5} = 31.6$ m。一只110 dB 的蝙蝠给出 $r = 0.1\times10^{3.5} = 316$ m（不计吸收）——远上十倍，因为每20 dB 把距离乘以十。（吸收会把两者都大大缩短，如 [[#ex-moth]]。）更响的鸣声让蝙蝠能在更远处发现猎物，但也更早地向有耳的蛾告警，所以鸣声强度上的选择取决于两者之间的平衡。有些捕食有耳蛾类的蝙蝠鸣叫异常之轻，如宽耳蝠（*Barbastella barbastellus*）（Holger Goerlitz 与合作者，2010），把蛾能听到它们的距离压到接近它们探测到蛾的距离。
:::
:::

::: exercise 设计一个激素实验 {level=3}
雌性斑胸草雀不会鸣唱。你想知道，这是因为雌鸟的脑在发育期间被组织得不同，还是因为成年雌鸟缺乏睾酮。设计实验以区分两者，并说出每种假说预言的结果。
::: solution
**激活化假说**：给成年雌鸟睾酮（配以假埋植对照）。若鸣唱出现且类似雄鸟的鸣唱，则差异是激活化的。**组织化假说**：在孵化后不久、鸣唱系统发育的敏感期内，用雌二醇（或用睾酮，它在脑中经芳香化酶转化为雌二醇）处理雌鸟，然后成年时分别在有无睾酮的条件下测试。若只有早期处理过的雌鸟发育出雄性大小的鸣唱核团，且成年给予睾酮时会鸣唱，则差异是组织化的。这类经典实验（Mark Gurney 与 Masakazu Konishi，1980）发现，早期雌二醇使雌性鸣唱系统雄性化，成年后的睾酮随后引出鸣唱，而未经早期处理的雌鸟仅靠成年期睾酮很少产生鸣唱——这是组织化效应的证据，此外还需要激活。（后来的工作表明，并非全部性别差异都能由激素造成，这提示脑中性染色体基因的直接作用。）
