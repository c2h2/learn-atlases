在不列颠哥伦比亚省曼德特岛的海滩上，西北鸦（*Corvus caurinus*）在退潮时取食蛾螺。一只乌鸦捡起一只蛾螺，几乎垂直飞起，把它丢到岩石上，反复如此直到螺壳摔碎。Reto Zach 在1970年代研究了它们，注意到乌鸦颇有选择性——只取最大的蛾螺——而且丢下的高度相当稳定，约为5米。他亲自站上梯子丢蛾螺，发现大蛾螺比小蛾螺更容易碎，而摔碎所需的丢掷次数随高度增加而下降，起初降得陡、随后只缓缓下降。飞得更高要消耗能量；从更低处丢下则意味着更多次丢掷。乌鸦所用的高度，接近于使摔碎一只蛾螺所需攀爬的总高度最小化的那个高度。

这些乌鸦体现了本章的路数。觅食是一组决策——吃什么、在哪里搜索、停留多久、承担多大风险——其后果是可以建模的。**最优觅食理论**追问：在给定的约束下，怎样的决策能使某种与适合度相关的货币最大化，再把预言与动物实际所为之事作比较（[[behaviour/studying-behaviour#def-optimality]]）。我们建立它的两个经典模型——猎物（食性）模型，以及连同 Charnov 边际价值定理的斑块模型——然后处理风险敏感性觅食、摄食与避敌之间的权衡、以及群体中的觅食，终于理想自由分布。起点的功能反应来自 [[ecology/predation-parasitism]]。

## 货币与约束

::: example 丢蛾螺的乌鸦 {#ex-crows}
设从高度 $h$ 米（$h > 1$）丢下一只大蛾螺、摔碎它所需的平均丢掷次数为 $N(h) = 1 + 16/(h - 1)$——这是一条示意曲线，具有 Zach 实测的形状。若摔碎一只蛾螺的代价与攀爬的总高度成正比，$H(h) = h\,N(h)$，乌鸦应采用哪个高度？
::: solution
$H(h) = h + \dfrac{16h}{h - 1}$。求导，$\dfrac{dH}{dh} = 1 + 16\,\dfrac{(h-1) - h}{(h-1)^2} = 1 - \dfrac{16}{(h - 1)^2}$，当 $(h - 1)^2 = 16$ 时其值为零，即 $h^* = 5$ m。在 $h^* = 5$ 处，$N = 5$ 次丢掷、$H = 25$ m；从3 m 丢下，一只乌鸦需9次丢掷（27 m）；从12 m 丢下则约需2.5次丢掷（29 m）。代价曲线在其极小值附近很平缓，所以确切的高度关系不大——但太低与太高的丢掷显然更糟。Zach 研究的乌鸦所用的高度，接近他所实测的代价曲线的最低点。
:::
:::

这个例子展示了每个觅食模型的要素：一个**决策变量**（高度）、一种**货币**（攀爬的总高度，是每只蛾螺所耗能量的替身），以及**约束**（蛾螺的破碎曲线，由物理学决定）。最常用的货币是**净能量摄入的长期平均速率**，其理由是：其他条件相同时，获取能量更快的动物就有更多时间与能量去做别的事情，例如避开捕食者或繁殖。另一些货币——效率（每耗一单位能量所获的能量）、熬过一个夜晚的概率，或养分平衡——在别的场合更为合适，而选对货币本身就是这门科学的一部分。

速率货币建立在一个对付搜索与处理交替进行的觅食者的基本方程之上。

::: proposition Holling 圆盘方程 {#prop-holling}
一只觅食者搜索猎物，在单位搜索时间内以 $\lambda$ 的速率遭遇猎物；每个猎物给出净能量 $e$，耗时处理 $h$（*追捕、制服、吃掉*）。在用于搜索与处理的总时间 $T = T_s + T_h$ 里，它遭遇 $\lambda T_s$ 个猎物，且 $T_h = \lambda T_s h$。于是它的能量摄入平均速率为

$$
R = \frac{\lambda T_s e}{T_s + \lambda T_s h} = \frac{\lambda e}{1 + \lambda h}.
$$ {#eq-holling}

这就是 Holling 的 II 型功能反应（C. S. Holling, 1959），按每个觅食者表述。假设：搜索期间的遭遇是一个泊松过程，搜索与处理互斥，且 $e$、$h$ 与 $\lambda$ 恒定。
:::

## 吃什么：猎物模型

一只觅食者遭遇若干种猎物。它应当遇到什么吃什么，还是忽略某些种类，以便花更多时间搜索更好的种类？设猎物类型 $i$ 给出能量 $e_i$、耗时处理 $h_i$，遭遇速率为 $\lambda_i$。

::: definition 收益率 {#def-profitability}
一个猎物类型的**收益率**（profitability）是 $e_i/h_i$，即单位处理时间所获得的能量。猎物按收益率**排序**：$e_1/h_1 > e_2/h_2 > \dots$。
:::

::: proposition 最优食性 {#prop-diet}
为使能量摄入的长期速率最大化，觅食者应当总是取食排名最高的猎物，并按排名次序逐个加入猎物类型。当且仅当某类型的收益率超过仅靠更高级类型所能获得的摄入速率时，它才应当把类型 $j$ 纳入食谱：

$$
\frac{e_j}{h_j} > \frac{\sum_{i<j}\lambda_i e_i}{1 + \sum_{i<j}\lambda_i h_i}.
$$ {#eq-diet}

由此得出三条推论：（1）每个猎物类型在遭遇时要么总是被取食、要么总是被忽略（**零一律**）；（2）一个类型是否入选取决于*更高级*类型的丰度，而不取决于它自身的丰度；（3）随着更好的猎物变得更丰富，食谱变窄。
:::

::: proof
设食谱由猎物类型的集合 $D$ 构成，[[#eq-holling]] 的多猎物版本给出速率 $R_D = \sum_{i\in D}\lambda_i e_i / (1 + \sum_{i\in D}\lambda_i h_i)$。记 $A = \sum_{i<j}\lambda_i e_i$、$B = 1 + \sum_{i<j}\lambda_i h_i$，则不含类型 $j$ 的速率为 $A/B$。加入 $j$ 得 $(A + \lambda_j e_j)/(B + \lambda_j h_j)$。它超过 $A/B$ 当且仅当 $B(A + \lambda_j e_j) > A(B + \lambda_j h_j)$，即 $B\lambda_j e_j > A\lambda_j h_j$，亦即 $e_j/h_j > A/B$。公因子 $\lambda_j$ 相消，这就是类型 $j$ 自身的丰度不出现的原因。此外，含前 $j$ 个类型的速率是按处理耗时加权的收益率的平均，所以若某个类型未通过检验，每个排名更低的类型——其 $e/h$ 更小——也通不过。
:::

其中的直觉是机会成本。当你遇到一个差劲的猎物时，吃掉它就要付出它的处理时间，而这段时间本可以用来搜索更好的东西。这是否划算，取决于你多快能遇到更好的东西——取决于更好猎物的丰度——而不取决于差猎物有多常见。

::: example 鸻鹬该吃小蠕虫吗？ {#ex-diet}
一只鸻鹬以每秒搜索 $\lambda_1$ 的速率遭遇大蠕虫（每个20 J，处理时间10 s），以速率 $\lambda_2 = 0.02$ s⁻¹ 遭遇小蠕虫（5 J，5 s）。（a）给猎物排序。（b）若 $\lambda_1 = 0.01$ s⁻¹，这只鸟应当吃小蠕虫吗？它的摄入速率是多少？（c）大蠕虫的遭遇速率高于多少时它应当忽略小蠕虫？
::: solution
（a）收益率：大蠕虫 $20/10 = 2$ J s⁻¹，小蠕虫 $5/5 = 1$ J s⁻¹；大蠕虫排第一。

（b）只吃大蠕虫得 $R_1 = \lambda_1 e_1/(1 + \lambda_1 h_1) = 0.2/1.1 = 0.182$ J s⁻¹。小蠕虫的收益率1 J s⁻¹ 超过这个值，所以应当纳入。两类都吃时的速率为 $(0.2 + 0.1)/(1 + 0.1 + 0.1) = 0.25$ J s⁻¹。

（c）当 $R_1 > 1$ 时应当专食，即 $20\lambda_1/(1 + 10\lambda_1) > 1$，亦即 $10\lambda_1 > 1$：$\lambda_1 > 0.1$ s⁻¹，即每10 s 的搜索遇到一只大蠕虫。这个阈值不依赖于 $\lambda_2$。
:::
:::

这个模型由 John Krebs、Jan Erichsen、Michael Webber 和 Eric Charnov（1977）用大山雀（*Parus major*）做了检验：在室内鸟舍中给它们提供大小两块黄粉虫，黄粉虫放在一条绕过窗口的运动传送带上，实验者从而能精确控制遭遇速率。大块稀少时，鸟两种都取；大块常见到模型预言专食化时，鸟变得挑剔，而且如预言的那样，这一情形不论小块的密度如何都会发生。但切换并非全或无：在它们"本应"完全忽略小块的时候，仍会继续取食一些小块。这样的**部分偏好**在多数检验中都能发现。它们通常归因于辨别的代价与取样：从不尝试较差猎物的觅食者，无法察觉其价值的变化。在不同大小的贻贝中做选择的滨蟹（*Carcinus maenas*）（Roger Elner 和 Roger Hughes, 1978）偏好收益率最高的大小，并在这些大小稀缺时拓宽食谱，同样带有部分偏好。

## 在哪里、待多久：斑块模型

食物通常是成斑块的，而斑块会随觅食者的利用而耗竭：一只蜜蜂会吸干一个花簇里的花，一只山雀在一根枝条上搜索得越久，找到的昆虫越少。觅食者必须决定何时转向新的斑块，并接受一段一无所获的转移时间。

::: definition 收益函数与转移时间 {#def-gain}
**收益函数** $g(t)$ 是在斑块中度过时间 $t$ 后累积获得的能量。对耗竭中的斑块，它递增且上凸：$g(0) = 0$，$g'(t) > 0$ 且 $g''(t) < 0$，于是瞬时收益速率 $g'(t)$——**边际率**——随在斑块中的时间而下降。**转移时间** $\tau$ 是在斑块之间移动的平均时间。
:::

::: theorem 边际价值定理 {#thm-mvt}
在斑块全同、收益函数为 $g$、转移时间为 $\tau$ 的环境中，使长期收益速率最大化的停留时间 $t^*$

$$
R(t) = \frac{g(t)}{\tau + t}
$$

满足

$$
g'(t^*) = \frac{g(t^*)}{\tau + t^*} = R^*.
$$ {#eq-mvt}

当斑块中的边际收益速率降到整个环境所能达到的最佳平均速率时，觅食者就应当离开斑块。因此，停留时间随转移时间而增加；而且（在有若干种斑块类型时）每种斑块都在相同的边际速率处被离开。（Eric Charnov, 1976。）
:::

::: proof
$R$ 在 $t > 0$ 上可微，且 $R'(t) = \dfrac{g'(t)(\tau + t) - g(t)}{(\tau + t)^2}$。在内点极大处 $R'(t^*) = 0$，即得 [[#eq-mvt]]。为看出解是极大且唯一，记 $\phi(t) = g'(t)(\tau + t) - g(t)$。则 $\phi(0) = g'(0)\tau > 0$ 且 $\phi'(t) = g''(t)(\tau + t) < 0$，故 $\phi$ 递减；若 $\phi$ 变为负（当 $g'$ 趋于零时确实如此），它恰好穿过零点一次，而 $R$ 在这一点之前上升、之后下降。

关于对 $\tau$ 的依赖：对 $\phi(t^*; \tau) = 0$ 作隐函数求导。$\partial\phi/\partial\tau = g'(t^*) > 0$ 且 $\partial\phi/\partial t = g''(t^*)(\tau + t^*) < 0$，故 $dt^*/d\tau = -(\partial\phi/\partial\tau)/(\partial\phi/\partial t) > 0$。路程越长，停留越久。
:::

这定理由一个著名的图解形式。在原点右侧画出 $g(t)$，在左侧标出转移时间 $\tau$。停留时间为 $t$ 时所得的速率，就是从 $(-\tau, 0)$ 到曲线上点 $(t, g(t))$ 的直线的斜率。这样的直线中最陡的一条正是与曲线相切的那条；其切点就是 $t^*$，其斜率就是 $R^*$。

:::

::: example 耗竭斑块中的停留时间 {#ex-mvt}
一只觅食者在一个斑块中的收益为 $g(t) = 10(1 - e^{-0.2t})$（以食物单位计，$t$ 以分钟计），斑块之间的转移耗时 $\tau = 5$ min。求最优停留时间与所得的收益速率。若 $\tau = 10$ min，两者如何变化？
::: solution
这里 $g'(t) = 2e^{-0.2t}$，而 [[#eq-mvt]] 化为 $2e^{-0.2t}(t + 5) = 10(1 - e^{-0.2t})$。它没有闭式解；数值求解（二分法）得 $t^* = 5.73$ min。于是收益为 $g(5.73) = 6.82$ 单位，速率 $R^* = 6.82/10.73 = 0.636$ 单位/min，等于 $g'(t^*) = 2e^{-1.146} = 0.636$，正如同定理所要求。

当 $\tau = 10$ 时，同样的程序给出 $t^* = 7.53$ min，收益7.78，$R^* = 0.444$。转移时间加倍使停留延长约30 %，并使总速率降低。注意觅食者*没有*做什么：它不会待到斑块被取空，也不会一俟摄入开始下降就离开。
:::
:::

定性预言——路程越长，停留越久——已在许多物种中得到证实。Richard Cowie（1977）让大山雀在室内鸟舍中于人工树上觅食，黄粉虫碎块藏在盛满木屑的杯子中；他用难开或易开的杯盖来操纵转移时间。转移更费力时，鸟在每个斑块停留更久，计入转移的能量代价后接近定量预言。Alex Kacelnik（1984）研究了把大蚊幼虫衔回给雏鸟的欧洲椋鸟（*Sturnus vulgaris*）；从巢到取食地的每次往返都是一个收益递减的"斑块"，因为嘴里已满是猎物的鸟更难再抓到更多。他用一台按递增间隔投放黄粉虫的喂饵器证明：喂饵器离巢越远，椋鸟收集的载荷越大，正如定理的**中心点**（central place）版本所预言。总体而言，定量拟合良好但不完美：动物往往比预言多停留片刻，这可能反映了速率之外的货币、对斑块质量的不确定，或对延迟奖励的折扣。

::: warning "最优"并不意味着完美，模型也不是说动物在进行计算
最优性模型预言的是在其假设之下选择会偏爱什么。并不指望动物去解方程；它们使用机制——诸如"固定时间没有捕获就离开"或"两次捕获的间隔超过阈值就离开"这样的经验法则——在其正常环境中逼近最优。偏离预言并不是"动物犯了错"，而是表明模型的货币或约束并不完备，或者机制未能完全实现最优策略。模型的价值正在于它使这些偏离变得可见、可解释。
:::

::: quiz
根据边际价值定理，若一只蜜蜂所在环境中所有的斑块都变得更富（每条收益曲线同乘以同一个大于1的因子），而转移时间不变，它花在每个花斑块上的时间会怎样？
- [ ] 增加，因为每个斑块能提供的更多
- [ ] 减少，因为蜜蜂可以更有本钱挑剔
- [x] 不变
- [ ] 取决于遭遇捕食者的速率
::: solution
若 $g(t)$ 换成 $k\,g(t)$，条件 [[#eq-mvt]] 化为 $k g'(t^*) = k g(t^*)/(\tau + t^*)$，而 $k$ 相消：最优停留时间不变，只有速率以因子 $k$ 上升。若斑块变富的方式改变了收益曲线的*形状*——例如它们耗竭得更慢——或者只有部分斑块改变，预言就会改变：整体更富的环境抬高 $R^*$，所以觅食者应当更早离开较贫的斑块。
:::
:::

## 风险敏感性觅食

到目前为止，货币一直是一个平均值。但平均值掩盖了方差，而对有些动物来说，方差事关生死。冬天，一只小鸟必须在黄昏前获得足够的能量，才能熬过一个漫长而寒冷的夜。假设它可以在一个产量固定而确定的取食地，与一个均值相同但产量可变的取食地之间做选择。

::: example 一夜求生 {#ex-risk}
一只鸟需要在天黑前获得至少10单位能量才能存活。恒定地点恰好给出 $\mu$ 单位；可变地点给出的量服从正态分布，均值为 $\mu$，标准差为2。当（a）$\mu = 11$ 与（b）$\mu = 9$ 时，哪个地点使其存活概率最大？
::: solution
（a）当 $\mu = 11$ 时，恒定地点保证存活（概率1）。在可变地点，存活要求收益 $X$ 超过10：$P(X > 10) = P(Z > (10 - 11)/2) = P(Z > -0.5) = 0.69$。这只鸟应当**风险规避**，选择恒定地点。

（b）当 $\mu = 9$ 时，恒定地点保证死亡。可变地点给出 $P(X > 10) = P(Z > 0.5) = 0.31$。这只鸟应当**风险偏好**，押注于可变地点。

这就是**能量收支法则**：期望收益超过需求时（正预算）风险规避，不敷需求时（负预算）风险偏好。（在正态近似下，当 $\mu > R$ 时，超过需求 $R$ 的概率在 $(\mu - R)/\sigma$ 最大时最大，这有利于小的 $\sigma$；当 $\mu < R$ 时则有利于大的 $\sigma$；David Stephens, 1981。）
:::
:::

caption: [[#ex-risk]] 中可变地点所获的能量，均值为9单位而需求为10。阴影面积约为0.31，是熬过夜晚的概率——相比之下，恰好给出9单位的恒定地点处该概率为零。增大 $\sigma$ 可见这个赌注变得更好；把均值调到11可见方差此时把阴影面积压到恒定地点所提供的确定存活之下。
:::

Thomas Caraco、Steven Martindale 和 Thomas Whittam（1980）给黄眼灯草鹀（*Junco phaeonotus*）在种子数固定的托盘与均数相同而种子数可变的托盘之间做选择。能量收支为正的鸟偏好固定选项；当实验者压低鸟的收支（降低温度或使其短缺食物）时，它们转向可变选项。后来的检验在不同物种间结果不一，而一个重要格局浮现出来。当可变选项在*数量*上不同时，动物通常风险规避；当其在奖励的*延迟*上不同时，它们通常风险偏好（Alex Kacelnik 和 Melissa Bateson, 1996）。比起能量收支，这一格局更好地由动物如何感知并记忆数量与间隔——误差与量级成正比——来解释，这提醒我们机制塑造选择。

## 食物还是安全

一只只顾最大化摄入速率而无视捕食者的觅食者，不可能留下许多后代。真实的觅食决策是在能量与被吃的风险之间权衡，而这种权衡塑造了动物在哪里取食、有多警戒、以及何时停口。

### 警戒与群体

成群取食的动物每个个体花在扫视捕食者上的时间更少，却往往更安全。有两种效应在起作用。在**多眼效应**（many-eyes effect；Harry Pulliam, 1973）中，只要任一成员发现捕食者，群体就发现了它；在**稀释效应**（dilution effect）中，袭击一个群体的捕食者只吃掉一个个体，因此每个成员的风险随群体大小而下降。

::: example 多眼 {#ex-vigilance}
群体中每个动物在随机时刻以0.3的概率抬头警戒，彼此独立。捕食者出现时，一个五只个体的群体中至少一只是警戒状态的概率是多少？若要保持群体的发现概率等于一只单独个体警戒50 %的时间，每个个体的警戒可以低到多少？
::: solution
没有一个个体警戒的概率是 $0.7^5 = 0.168$，所以至少一个警戒的概率为 $1 - 0.168 = 0.832$。要让五只的群体比得上一只单独个体（$0.5$），需要 $1 - (1 - p)^5 = 0.5$，即 $(1 - p)^5 = 0.5$，$p = 1 - 0.5^{1/5} = 0.129$。每只动物都能把警戒从50 %砍到约13 %而群体发现捕食者一样频繁——从而腾出多得多的时间取食。个体是否真正受益，取决于信息能否从发现者迅速传给其他个体，而这并不总能做到。
:::
:::

模型预言个体警戒随群体大小而下降，这是鸟类和哺乳类中最被一致观察到的格局之一。但它引出一个难题：如果有别者在放哨，任何个体又凭什么要放哨？警戒是一种公共物品，每个个体都受到搭便车的诱惑；博弈论模型（[[behaviour/conflict-game-theory]]）预言一个进化稳定的警戒水平，它低于对群体最好的水平。

### 捕食风险的代价

一只觅食的动物应当在留下的好处不再超过其代价时离开斑块——而代价包括捕食风险。Joel Brown（1988）把这变成了一种野外方法。若一只动物在其收获速率降到其代谢代价、捕食代价与错失机会代价之和时离开一个食物斑块，那么遗留食物的密度——**放弃密度**（giving-up density, GUD）——就度量了这些代价。把混入沙中的种子托盘安置在不同的地方；次晨清点剩下的种子。开阔天空下比掩蔽处更高、月明之夜比黑暗之夜更高的 GUD，量化了动物认为每种情境有多危险——这就是所谓的**恐惧景观**。

对先生长后繁殖的动物，例如仔鱼，浮现出一条一般法则。James Gilliam 的分析（与 Earl Werner 一起发表于1984年）表明，在某些条件下，以活到某个体型的机会最大化为目标的动物，应选择使死亡率与生长率之比 $\mu/g$ 最小的生境。Werner 和同事发现，在大口黑鲈存在时，小的蓝鳃太阳鱼（*Lepomis macrochirus*）留在水生植被中——那里食物较差但捕食较低——只有当它们长得太大、鲈鱼吞不下时，才转移到较富的开阔水域。

::: application 觅食理论在保护与管理中的应用
最优觅食模型有助于预言动物对环境变化的响应。建立在猎物模型与斑块模型之上、并计入鸟类能量需求的鸻鹬类在河口滩涂上取食的模型，已在英国和法国被用来预言：若滩涂因开发而丧失、或贝类采捕移走猎物，将有多少鸟饿死——这些预言已同观察到的死亡率对照检验。放弃密度被用于度量掩蔽处对猎物的有效性，并评估重新引入的捕食者如何改变其猎物的行为。
:::

## 群体中的觅食

当许多觅食者利用同样的斑块时，一个斑块对一个个体的价值就取决于还有多少他者在场。Stephen Fretwell 和 Henry Lucas 在1970年给出了由此产生的分布的最简单模型。

::: proposition 理想自由分布 {#prop-ifd}
设觅食者是**理想的**（每个都知道每个斑块的价值）且**自由的**（每个都能无偿迁往任何斑块），资源以恒定速率 $Q_i$ 进入斑块 $i$，并在其中的 $n_i$ 个觅食者之间平均分配，于是每个获得 $Q_i/n_i$。那么平衡时没有任何个体能靠移动提高自己的摄入，这要求所有被占据斑块中的摄入相等：

$$
\frac{Q_1}{n_1} = \frac{Q_2}{n_2} = \dots, \qquad\text{so}\qquad \frac{n_i}{N} = \frac{Q_i}{\sum_j Q_j}.
$$ {#eq-ifd}

各斑块中觅食者的数目同资源输入速率成正比——**输入匹配**。这一平衡是 [[behaviour/conflict-game-theory]] 意义上的进化稳定状态。
:::

::: example 两个喂饵处的刺鱼 {#ex-ifd}
三十条刺鱼在一个水箱里，食物（水蚤）在水箱一端的投放速率是另一端的两倍。理想自由分布预言什么？若两端速率对调，会发生什么？
::: solution
由 [[#eq-ifd]]，鱼应按输入成比例分布：富的一端 $30\times\tfrac23 = 20$ 条，贫的一端 $10$ 条。于是每条鱼获得的相同，因为 $2Q/20 = Q/10$。若速率对调，预言也随之对调。Manfred Milinski（1979）用六条三刺鱼做了这个实验，发现鱼在几分钟内就按接近预言的2 : 1比例分布，并在输入互换后重新分布。
:::
:::

偏离理想自由分布的情形颇有信息量。若个体在竞争能力上有差异，分布按总竞争权重而不是按数目匹配输入。若动物并不"理想"——它们需要时间了解斑块价值——或不"自由"——占优个体排斥他者——斑块往往**匹配不足**：较贫的斑块里有比预言更多的个体，这是许多实验中发现的格局。群体觅食者还面临进一步的选择：自己寻找食物（**生产者**，producing），还是利用他者找到的食物（**窃取者**，scrounging）；每种策略的稳定频率取决于对方有多常见，这是一个频率依赖问题，留待下一章处理。

::: history
Robert MacArthur 和 Eric Pianka（《On optimal use of a patchy environment》）与 John Emlen（《The role of time and energy in food preference》）同发表于 *The American Naturalist*，时值1966年，开创了最优觅食理论。Holling 的圆盘方程源自1959年。Charnov 的边际价值定理（1976）与形式化的猎物模型（Charnov, 1976，以及他人）给了理论其经典形式；Krebs、Charnov、Cowie 和合作者用大山雀做的实验检验随后发表于1977年。Caraco 的灯草鹀（1980）与 Stephens 的能量收支法则（1981）引入了风险，而 Stephens 与 Krebs 的《Foraging Theory》（1986）总结了头二十年。此后理论被扩展到纳入捕食风险、信息与学习，其预言已在熊蜂、滨蟹、蝙蝠和狒狒等迥然不同的动物中检验。
:::

::: summary
- 最优觅食模型指定一个决策、一种货币（常常是净能量摄入的长期速率）与约束；Holling 圆盘方程给出速率 $\lambda e/(1 + \lambda h)$。
- 猎物模型按收益率 $e/h$ 对猎物排序；一个类型只有当其收益率超过靠更好类型所能获得的速率时才被纳入。纳入与否与其自身丰度无关，而好猎物常见时食谱变窄。检验显示部分偏好。
- 边际价值定理：当边际收益速率降到环境的最佳平均速率时离开耗竭中的斑块，$g'(t^*) = g(t^*)/(\tau + t^*)$。转移时间更长意味着更长的停留，中心点处更大的载荷。
- 风险敏感性觅食：能量收支为正时风险规避，为负时风险偏好。对可变的数量动物通常风险规避，对可变的延迟则通常风险偏好。
- 觅食在食物与捕食之间权衡：群体警戒与稀释、放弃密度与恐惧景观，以及对生长中的动物的 $\mu/g$ 法则。
- 理想自由分布预言输入匹配，$n_i/N = Q_i/\sum Q_j$，已在刺鱼中得到证实；不平等的竞争者与不完美的信息导致匹配不足。
:::

## 练习

::: exercise 收益率 {level=1 check="1.5"}
一个猎物给出30 J，处理耗时20 s。它的收益率是多少（以 J s⁻¹ 计）？
::: solution
$30/20 = 1.5$ J s⁻¹。
:::
:::

::: exercise 单一猎物类型 {level=1 check="0.5"}
一个捕食者以0.05 s⁻¹ 的搜索速率遭遇猎物；每个猎物给出20 J，处理耗时20 s。它的能量摄入速率是多少（以 J s⁻¹ 计）？
::: solution
由 [[#eq-holling]]，$R = 0.05\times20/(1 + 0.05\times20) = 1/2 = 0.5$ J s⁻¹。
:::
:::

::: exercise 输入匹配 {level=1 check="12"}
四十只鸭在两个池塘取食，面包以每分钟3块和7块的速率抛入。理想自由分布预言条件较差的池塘里有几只鸭？
::: solution
$40\times3/10 = 12$ 只在条件较差的池塘，28只在条件较好的池塘。
:::
:::

::: exercise 专食还是广食？ {level=2 check="0.025"}
一个捕食者遇到猎物 A（60 J，20 s）与猎物 B（10 J，10 s）。猎物 A 的遭遇速率（每秒搜索）高于多少时它应当忽略 B？
::: solution
A 的收益率为3 J s⁻¹，B 的为1 J s⁻¹，所以 A 排第一。忽略 B 当 $60\lambda_A/(1 + 20\lambda_A) > 1$，即 $40\lambda_A > 1$，故 $\lambda_A > 0.025$ s⁻¹——每40 s 的搜索遇到一只 A。恰好在此速率下，只吃 A 得 $1.5/1.5 = 1$ J s⁻¹，等于 B 的收益率。
:::
:::

::: exercise 群体中的警戒 {level=2 check="0.159"}
一个四只个体的群体中，每个动物以概率 $p$ 独立地保持警戒。$p$ 取什么值（三位有效数字）能使至少一只警戒的概率为50 %？
::: solution
$1 - (1 - p)^4 = 0.5$ 给出 $(1 - p)^4 = 0.5$，$p = 1 - 0.5^{1/4} = 1 - 0.8409 = 0.159$。
:::
:::

::: exercise 解读一个斑块实验 {level=2}
大山雀被训练在室内鸟舍中觅食，其中每个斑块以递减的速率产出猎物。处理1中斑块间的转移时间为5 s；处理2中为20 s。平均停留时间为15 s 与31 s。边际价值定理（按速率最大化）的预言值是12 s 与24 s。（a）结果在定性上支持定理吗？（b）试举三条理由说明鸟为何可能比预言停留更久。
::: solution
（a）支持：停留时间随转移时间而增加，正如定理所预言，且增加的比例也相近。（b）可能的理由：（1）货币不是净速率——若转移相对搜索在能量上昂贵，净速率最大化所预言的停留就比毛速率的更长；（2）鸟并不确切知道收益函数，而使用一条按典型斑块校准的经验法则（例如放弃时间）；（3）鸟对未来打折扣，看重即时收益高于延迟收益，这有利于留在当前的斑块中；（4）转移途中的捕食风险使转移的代价高于其历时所显示者。
:::
:::

::: exercise 另一条收益曲线下的停留时间 {level=2 check="sqrt(20)"}
在一个斑块中累积收益为 $g(t) = 10t/(t + 4)$，转移时间 $\tau = 5$。用 [[#eq-mvt]] 精确求 $t^*$。
::: hint
计算 $g'(t) = 40/(t+4)^2$ 并解 $g'(t)(t + 5) = g(t)$。
:::
::: solution
$\dfrac{40(t + 5)}{(t + 4)^2} = \dfrac{10t}{t + 4}$ 给出 $40(t + 5) = 10t(t + 4)$，即 $4t + 20 = t^2 + 4t$，故 $t^2 = 20$，$t^* = \sqrt{20} = 2\sqrt5 \approx 4.47$。于是速率为 $g(t^*)/(t^* + 5) = (44.7/8.47)/9.47 \approx 0.557$。
:::
:::

::: exercise 有风险的选择 {level=3}
一只鼩鼱必须在接下来的一小时内获得40单位能量，否则将饿死。A 地产出服从正态分布的量，均值为36、标准差为3；B 地的均值34、标准差8。（a）哪个地点给出更好的存活机会？（b）速率最大化者会选哪个？（c）这对货币的选择说明了什么？
::: solution
（a）存活需要 $X > 40$。在 A 地，$P(Z > (40 - 36)/3) = P(Z > 1.33) = 0.091$。在 B 地，$P(Z > (40 - 34)/8) = P(Z > 0.75) = 0.227$。B 更好：收支为负时，可变地点是更好的赌注，尽管其均值更低。（b）速率最大化者会选均值更高的 A。（c）当存活取决于在有限时间内达到一个阈值时，最大化均值与最大化适合度并不相同；恰当的货币是满足需求的概率，而它可能偏爱均值更低、方差更高的选项。
:::
:::

::: exercise 食性模型被推翻了吗？ {level=3}
在一次对猎物模型的检验中，预言的从"两种猎物都吃"到"只吃大型猎物"的切换发生在一个遭遇速率区间上，而不是在单一阈值处，且在阈值之上鸟仍会取食其遇到的小猎物的15 %。一位批评者说零一律已被推翻，最优觅食理论应当抛弃。评析这一论证。
::: solution
零一律是一个带有特定假设的模型的预言：对猎物完美的识别、对遭遇速率完备的知识、取样的代价为零、环境恒定。数据推翻的是那个版本；它们并不推翻"选择塑造了食性选择以提高摄入速率"这一假说。部分偏好可以由纳入了下列情形的改良模型预言：识别猎物的错误、为追踪猎物价值变化而需要取样，或个体之间阈值的变异（若不同个体在不同的遭遇速率处切换，群体平均就逐渐变化）。有用的回应是让这些改良模型相互对检——例如测量辨别的错误，或检验当环境变得更稳定时部分偏好是否减弱。猎物模型的定性预言（食谱随好猎物的丰度而变窄、与差猎物的丰度无关）得到了支持，这是模型抓住了主要权衡的相当实质的证据。
:::
:::
