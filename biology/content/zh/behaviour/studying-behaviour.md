一只出壳几小时的银鸥雏鸟，会啄亲鸟喙的尖端，亲鸟便为它吐出食物。它为什么啄？这个问题不止一个答案，而答案之间并非对手。雏鸟啄，是因为一种特定的视觉图形——一支细长、向下指的黄色鸟喙近尖端处的一个红点——经由其视觉与运动系统的回路触发了一次啄击动作。它啄，是因为它出壳时带着一份粗糙版本的反应，在最初几天里随练习而变得精准。它啄，是因为啄得有效的雏鸟得到喂食而存活，不啄的则没有。它以一种与近缘鸥类共享的方式啄，是因为这一反应继承自共同祖先，又在各谱系中各自改变了。Niko Tinbergen 在1940年代末与 Albert Perdeck 一起研究这些雏鸟，他主张：对任何行为的完整理解都需要全部四个答案。

本章提出这一框架以及建立在它之上的实践方法。我们从 Tinbergen 的四问以及近因与终极解释的区分讲起。然后看这一框架由之成长的经典习性学——信号刺激与固定行为模式——以及行为如何被描述与度量：行为谱、取样与记录规则、以及观察者的可靠性。后半部分关于推断：实验、对照、盲观察、伪重复，以及跨物种检验进化假说的比较方法。最后我们以最优性模型与适应主义推理的逻辑收尾——本课程其余部分将不断用到它们——并以研究动物的伦理作结。进化方面的工具出自 [[evolution/natural-selection]]。

## Tinbergen 的四问

1963年，Tinbergen 在 *Zeitschrift für Tierpsychologie* 上发表《On aims and methods of ethology》。他提出，当生物学家对着一件行为问"为什么？"时，其实是在四个不同的问题中问一个。

::: definition Tinbergen 的四问 {#def-four-questions}
对行为的解释回答四个问题之一：

1. **机制（因果）**：什么内部与外部因素使行为发生——在个体中起作用的刺激、感觉器官、神经回路、激素、基因？
2. **发育（个体发生）**：行为如何在个体一生中产生并变化，经由其基因、环境与经验（包括学习）的相互作用？
3. **功能（存活价值、适应意义）**：行为如何有助于个体及其亲属的存活与繁殖——它是*为了什么*，就选择为何维持它而言？
4. **进化（系统发育）**：行为在谱系的历史中如何产生、从什么祖先状态产生，又如何变化？

问题1与2关于个体，称为**近因**；问题3与4关于进化时间尺度上的种群，称为**终极**。问题1与3可以问行为现在如何（静态）；问题2与4问它何以至此（历史的）。
:::

近因-终极的区分由 Ernst Mayr 在1961年作了鲜明的划分，那是一篇发表于 *Science* 的短文《Cause and effect in biology》。Mayr 的例子是一种莺的秋季迁徙：它离开，是因为日照变短触发了生理变化（一个近因），也是因为赶在冬天之前离开的祖先得以存活繁殖，而留下的那些饿死了（一个终极原因）。Tinbergen 的贡献是把 Mayr 的每一类再分成静态与历史两半，得到四个格子：

| | 静态（行为现状） | 历史（如何形成） |
|---|---|---|
| **近因** | 机制 | 发育 |
| **终极** | 功能 | 进化 |

::: example 关于鸣唱的四答 {#ex-song}
一只雄性大山雀（*Parus major*）春天清晨在领地内的栖枝上鸣唱。基于对鸣禽的了解，为 Tinbergen 的每一个问题各给一个答案。
::: solution
**机制。** 日益变长的日照刺激性腺激素释放与睾酮水平升高；睾酮及其代谢物雌二醇作用于前脑中一套相互连接的核团（鸣唱系统，包括 HVC 与 RA 核），后者驱动鸣管与呼吸系统的肌肉。听到对手的歌声会增加鸣唱。

**发育。** 鸣禽的鸣唱是习得的。在已被详细研究的物种中，如白冠带鹀（*Zonotrichia leucophrys*），年轻的雄鸟在生命早期的敏感期内记住从成鸟处听到的歌声，然后练习，通过听觉反馈使其发出的声音匹配记住的模板，直至鸣唱"定型"。大山雀也会从邻居处学习各自的鸣唱类型。

**功能。** 歌声保卫领地并吸引配偶。John Krebs (1977) 移走牛津附近怀亚姆林林中占区的雄性大山雀，用扬声器取而代之：播放大山雀歌声的领地被新雄鸟重新占领的速度，慢于播着对照声音或无声的扬声器的领地。

**进化。** 这类发声学习仅见于三个鸟类类群——鸣禽、鹦鹉与蜂鸟——系统发育分析表明它进化过不止一次（究竟是两次还是三次仍有争论，因为鹦鹉与鸣禽是姐妹群）。在鸣禽内部，鸣唱结构与库容量已在各谱系之间分歧，部分是在性选择之下。

这四个答案无一可以取代其他。对晨鸣的完整说明需要全部四个。
:::
:::

::: warning "真正的原因是……"
行为生物学中最常见的混淆，是把对不同问题的答案当作相互竞争的。"鸟鸣不是为了吸引配偶，而是因为睾酮水平高"把机制与功能混为一谈，并假装其一能排除另一。两者皆真。两个解释只有在回答*同一个*问题时才彼此竞争："歌声主要服务于领地防御"与"歌声主要服务于求偶"是真正的备选，可以相互检验。遇到一场关于行为的争论时，先问双方各在回答四问中的哪一个。
:::

::: quiz
一项研究表明，缺乏 *Fosb* 基因功能拷贝的小鼠无法把幼崽搬回巢中。这主要回答 Tinbergen 四问中的哪一个？
- [x] 机制
- [ ] 发育
- [ ] 功能
- [ ] 进化
::: solution
它鉴定出一个基因，其产物在个体内是执行该行为所必需的——一个近因的因果解释。（Jennifer Brown 与合作者于1996年报道了这一结果。）它对搬运幼崽为何受选择偏好（功能）、搬运如何发育、以及它如何进化，都未置一词；不过，如果该敲除只在生命早期移除基因时才扰乱行为，那它也将涉及发育。
:::
:::

注意，"功能"指的是能解释选择为何维持该行为的那个效应，而不是它恰好具有的任何效应：歌声也会使雄鸟暴露给雀鹰，但那是代价，不是功能。四问虽在逻辑上互异，却彼此启发——如果歌声保卫领地，就预期其机制会对对手作出反应；如果歌声是习得的，文化传递便在基因之上叠加了第二套遗传系统。

## 经典习性学：信号刺激与行为模式

四问脱胎于**习性学** (ethology)，即1930年代至1950年代由 Konrad Lorenz、Niko Tinbergen、Karl von Frisch 及其学生在欧洲发展起来的行为的生物学研究。他们在自然或近自然条件下研究动物，比较近缘物种，并寻找构成行为的单元。

::: definition 信号刺激与固定行为模式 {#def-fap}
**信号刺激** (sign stimulus)（由另一只动物给出时称**释放者** (releaser)）是环境中简单而特定的特征，在动物能感知的所有特征中，它能引发某一特定行为。**固定行为模式**（fixed action pattern，现多称**模式行为** (modal action pattern)，以承认其可变性）是一种刻板、种属典型的动作序列，一经触发便倾向于执行完毕，即使刺激已被移走。比自然刺激引发更强反应的刺激是**超常刺激** (supernormal stimulus)。
:::

经典的例子至今富有教益。

- **雏鸥的啄击。** Tinbergen 与 Perdeck (1950) 给初孵的银鸥（*Larus argentatus*）雏鸟呈现成鸟头部的硬纸板模型并计数啄击。头部的颜色几乎无关紧要；喙上红点的有无与对比度、喙的形状及其向下的指向则极为重要。一根细红棒、近尖端处带有白环，比亲鸟头部的逼真模型引发更多啄击——一个超常刺激。
- **雁的滚卵。** 灰雁（*Anser anser*）会用喙把滑出巢的卵拨回。Lorenz 与 Tinbergen (1938) 发现，如果在动作中途取走卵，鹅常常会在喙下空无一物时仍完成整套归位动作，而依赖卵的反馈的横向修正则停止了。
- **刺鱼的攻击性。** 处于繁殖状态、喉部与腹部发红的三刺鱼（*Gasterosteus aculeatus*）雄鱼，会更容易攻击腹面涂红的粗糙模型，而非不含红色的精确模型。

习性学家曾以由信号刺激释放的"驱力"的液压模型解释这类结果。这些模型不再被接受为神经机制，"先天"与"习得"行为的严格分立也被证明站不住脚（[[behaviour/mechanisms-of-behaviour]]）。但那些发现依然成立：动物有选择地只回应可用信息的一小部分，而许多行为模式像解剖结构一样种属典型、同样可用于比较。

四问的功能面在此期间也被实验检验。红嘴鸥（*Chroicocephalus ridibundus*）在雏鸟出壳后叼走空蛋壳，带离鸟巢。Tinbergen 与合作者 (1962) 在坎布里亚郡兰格拉斯的沙丘上摆出单独的卵，一些旁边放着空壳，一些不放。附近有壳的卵更容易被小嘴乌鸦与银鸥发现并取走，而且效果随壳放得越远而越弱。破碎蛋壳的白色内面显然把捕食者引向本已伪装良好的卵与雏鸟，这就解释了选择为何偏好移除它——也解释了为何（亲鸟一旦离巢，雏鸟便暴露于同类相食的邻居之前）鸥在出壳后要等上一两个小时才把壳移走。

::: history
Darwin 一生持续写作行为，《The Expression of the Emotions in Man and Animals》(1872) 把展示与表情当作进化的性状来处理。年轻的习性学在1930年代成形：Lorenz 于1935年描述了印记，并于1938年与 Tinbergen 一起分析了滚卵；Tinbergen 的《The Study of Instinct》(1951) 成为其教科书。与此同时，von Frisch 正在破译蜜蜂的舞蹈。Lorenz、Tinbergen 与 von Frisch 分享了1973年的诺贝尔生理学或医学奖。同一个十年里，重心转向功能：**行为生态学**与**社会生物学**兴起（E. O. Wilson 的《Sociobiology》，1975），建立在 Hamilton 的亲缘选择（1964）、Maynard Smith 与 Price 的博弈论（1973）以及最优觅食理论之上。
:::

## 描述行为

在检验关于行为的任何命题之前，你必须能够可靠地说出它何时发生。这听起来琐碎，实则不然：行为是连续不断的动作之流，把它划分为范畴需要影响此后一切结果的决断。

::: definition 行为谱、事件与状态 {#def-ethogram}
**行为谱** (ethogram) 是一个物种（或一项研究涉及的）行为模式的目录，每一条都配有任何受训观察者都能套用的精确操作性定义。范畴要么是**事件** (events)——持续时间可忽略的行为，如一次啄击或一声鸣叫，以**频率**（单位时间的次数）度量——要么是**状态** (states)——持续时间可观的行为，如摄食或休息，以**持续时间**、处于其中所花费的**时间比例**、以及**时块** (bout) 的数量与长度度量。行为的**潜伏期** (latency) 是从定义好的起点（如一次试验开始）到其首次出现的时间。
:::

好的行为谱范畴按*动物做什么*（结构："头部降至肩高以下、喙接触基质"）或*它达成什么*（结果："把一个物体移动至少一个体长"）来定义，绝不按推断的动机（"饿""怕"）。若将作时间比例分析，范畴应互斥；若每一时刻都必须归类，则应穷尽（设"其他"或"看不见"之类的范畴即可保证）。

### 取样与记录规则

你无法注视一切。Jeanne Altmann 1974年的论文《Observational study of behavior: sampling methods》把每项观察研究必须做出的选择条分缕析，她的术语放之四海而皆准。

::: definition 取样与记录规则 {#def-sampling}
**取样规则**规定看谁、何时看：
- **自由取样** (ad libitum)——记录任何可见且看似相关的内容（适合预试验，用于分析有偏）；
- **焦点取样** (focal)——注视一个个体设定时长，记录它的全部行为；
- **扫描取样** (scan)——在设定时刻，快速记录群内每个个体的行为；
- **行为取样** (behaviour)——注视整群，记录某一类行为的每次发生（适合打斗或交配之类稀有而显眼的事件），以及涉及了谁。

**记录规则**规定行为如何被记录：
- **连续记录**——记录每一次发生及其起止时刻，给出真实的频率、持续时间与序列；
- **瞬时记录**——把观察时段划分为样本区间，在每个区间结束的瞬时，观察者记录该行为是否正在发生；
- **一零记录**——观察者记录该行为在每个样本区间内是否发生过。
:::

连续记录是金标准，但除非拍下视频事后评分，它一次只能对一个个体、少数几个范畴可行。瞬时记录给出处于某状态的时间比例的无偏估计，只要区间相对典型时块长度足够短。一零记录快捷但有偏：它计的是*该行为发生于其中的区间数*，既非频率也非持续时间。

扫描样本以比例给出时间分配：若猫鼬在120次扫描中有42次在觅食，则 $\hat p = 0.35$，二项标准误 $\sqrt{\hat p(1-\hat p)/n} = 0.044$ ([[biostatistics/estimation]])。该标准误假设相邻扫描相互独立。如果觅食时块比扫描间隔更长，相邻扫描抓到的就是同一个时块，有效样本量便小于120，真实的不确定性更大；应把取样间隔拉得比典型时块更宽，或以天或个体作为重复的单位。

::: example 一零记录如何误导 {#ex-onezero}
在一次10分钟的焦点观察中，时段划分为二十个30 s 的区间，一只鸟做了六次梳羽时块、每次5秒，且各落在不同的区间。试比较：真实的梳羽时间比例、一零得分、以及瞬时记录的期望值。
::: solution
真实比例是 $6\times5/600 = 0.05$。一零得分是梳羽发生于其中的区间占比，$6/20 = 0.30$——高了六倍。若在每个区间末尾做瞬时记录，样本点落入梳羽时块的概率等于梳羽的时间比例，因此期望得分是 $0.05$（尽管只有二十个样本点，得分常会是0、0.05或0.10）。一零得分高估短时频繁的行为、低估长时行为（一次持续整场的时块得分1.0，与出现频繁二十倍但短暂的行为得分相同）。有人偶尔把一零得分当作"行为发生了多少"的指数为之辩护，但它们混淆了频率与持续时间，且依赖于所选的区间长度。
:::
:::

序列与数量同样重要。连续行为的记录可以概括为：在固定时间步内从每个状态转移到每个其他状态的概率，得到一个**Markov 链**模型。其平稳分布预言长期的时间分配，而停留在状态 $i$ 的概率 $p_{ii}$ 在时块随机终止时给出 $1/(1 - p_{ii})$ 步的平均时块长度——一个可以用观测到的时块长度来检验的预言。真实的时块常偏离这一几何分布（例如，刚开始摄食的动物比已经摄食一阵的动物更不容易停下），而这种偏离本身就对机制富有启发。

::: widget markov
matrix: 0.8,0.15,0.05; 0.3,0.6,0.1; 0.1,0.1,0.8
states: Forage; Vigilant; Rest
start: 0
steps: 30
caption: 一个三状态模型，每30秒对动物行为取样一次（概率为示意值）。运行这条随机行走，把处于各状态的步数占比与平稳分布比较——平稳分布这里是0.5觅食、0.25警戒与0.25休息。平均时块长度为 $1/(1-p_{ii})$：觅食与休息为5步，警戒为2.5步。增加步数，可见模拟的时间分配趋于收敛。
:::

### 观察者及其可靠性

行为数据的好坏不超过观察者的分类水准。两个观察者为同一录像评分应当一致；同一观察者数周后重评也应与自己一致。原始的一致率百分比会夸大可靠性，因为两个随机分类的观察者有时也会碰巧一致。**Cohen 的 κ** 对此作了校正。

::: proposition Cohen 的 κ {#prop-kappa}
若两个观察者把同样的 $n$ 个项目分入 $k$ 个范畴，记 $p_o$ 为观察到的一致比例，并记 $p_e = \sum_i r_i c_i / n^2$ 为机遇期望的一致比例，其中 $r_i$ 与 $c_i$ 是第一、二观察者放入范畴 $i$ 的项目数。则

$$
\kappa = \frac{p_o - p_e}{1 - p_e}.
$$ {#eq-kappa}

完全一致时 $\kappa = 1$；就各观察者使用各范畴的频率而言，一致不优于机遇时 $\kappa = 0$。约定俗成（且带有任意性）的准则把 $\kappa$ 高于约0.6视为相当可靠，高于0.8视为极佳。
:::

期望一致 $p_e$ 假设在边缘频率给定之下两观察者的分类相互独立：两者都选范畴 $i$ 的概率是 $(r_i/n)(c_i/n)$。

::: example 两名观察者的一致性 {#ex-kappa}
两名观察者独立地为同样的100帧一只鹿的视频评分：觅食（F）、警戒（V）或休息（R）：

| A（行），B（列） | F | V | R | 合计 |
|---|---|---|---|---|
| F | 40 | 5 | 1 | 46 |
| V | 4 | 25 | 3 | 32 |
| R | 1 | 2 | 19 | 22 |
| 合计 | 45 | 32 | 23 | 100 |

计算一致百分比与 Cohen 的 κ。
::: solution
一致位于对角线上：$40 + 25 + 19 = 84$，故 $p_o = 0.84$。机遇期望的一致是

$$
p_e = \frac{46\times45 + 32\times32 + 22\times23}{100^2} = \frac{2070 + 1024 + 506}{10\,000} = 0.36.
$$

于是 $\kappa = (0.84 - 0.36)/(1 - 0.36) = 0.48/0.64 = 0.75$。一致性相当可靠但未达极佳；多数分歧涉及"警戒"，提示其定义（例如头部必须抬起多久）在正式研究之前需要收紧。
:::
:::

可靠性不等于效度：观察者可能对"警戒"＝抬头姿态达成完美一致，即使它把抬头咀嚼也算了进去。效度的证明是该测量按应有的方式行事——警戒的鹿应更早发现模型捕食者。

知晓假说或处理的观察者也倾向于朝预期的方向评分（**观察者偏倚**），而动物能读出观察者。1904年，柏林的马 Clever Hans 似乎以蹄击地回答算术题；Oskar Pfungst 表明 (1907)，Hans 是对提问者微小的无意识动作作出停击反应，而当提问者不知道答案时 Hans 便失败。尽可能盲评，并确保动物读不到实验者。

## 实验与推断

观察揭示模式；实验检验对模式的解释。假设歌库更大的大山雀占据更好的领地。这一相关可能因为歌声库能吓退对手，可能因为高质量的雄鸟兼有大歌库和好领地（出于某种别的原因），也可能因为好的领地（食物更多）使雄鸟得以发育或表现出更大的歌库。只有操纵——像 Krebs 用扬声器那样，给一些领地加播歌声、另一些减播——才能区分这些。

::: warning 相关不是因果，即使在野外
在无扰动的种群中观察到行为与收益的关联，并不能表明行为导致收益。动物不是被随机分配到行为上的：状态较好的个体通常样样都做得更多。亲代抚育是一个经典案例：更频繁喂食幼雏的亲鸟养大更多后代，可能是因为喂食本身，也可能是因为它们在其他方面是更好的亲代、或占据着更富饶的领地。雏数操纵（把雏鸟在巢之间移动，使亲鸟抚养多于或少于其所产卵数的雏）切断亲代质量与雏数之间的联系，是检验这类假说的标准手段。
:::

除任何实验的常规要素（[[biostatistics/experimental-design]]）——随机分配、对照、重复——之外，行为实验还需要：除研究因素外其余一切均匹配的对照（Krebs 的对照是真扬声器播一段声音）、平衡的处理顺序（因为动物会习惯化、会学习），以及关注动物自身的状态（饥饿、季节、等级），后者常常比处理更重要。

### 选择测试

许多关于行为的问题以选择的形式提出：雌蟋蟀是靠近播同种歌声的扬声器，还是播异种歌声的那个？蜂落在蓝花上还是黄花上？每个个体只选择一次、个体彼此独立时，选择其一的个体数在无偏好零假设下服从二项分布。

::: example 一个双选择回放测试 {#ex-binomial}
二十只雌性蟋蟀各被释放一次，位置在两个扬声器的正中间，一个播放同种歌声，另一个播近缘种的歌声，两侧随机安排。十五只扑向同种歌声。这是偏好的证据吗？
::: solution
零假设是每只雌虫以概率 $\tfrac12$ 独立选择任一个扬声器，选择同种歌声的只数 $X$ 服从 $\mathrm{Bin}(20, \tfrac12)$。结果在偏同种方向上至少与15同样极端的概率是

$$
P(X \ge 15) = \frac{1}{2^{20}}\sum_{k=15}^{20}\binom{20}{k} = \frac{15\,504 + 4845 + 1140 + 190 + 20 + 1}{1\,048\,576} = \frac{21\,700}{1\,048\,576} = 0.0207.
$$

若对任一种歌声的偏好都会有意义，就应做双侧检验，把此值加倍：$p = 0.041$。在约定的5 %水平上，我们将拒绝零假设，断定雌虫偏好同种歌声。这一结论依赖于各次试验相互独立——每只雌虫只测一次、扬声器位置随机化、两段歌声以同一响度播放——使偏好指向歌声本身，而非响度或方位。
:::
:::

::: widget distribution
dist: binomial
params: n=20, p=0.5
a: 15
b: 20
caption: [[#ex-binomial]] 的零分布：若20只雌虫随机选择，扑向同种扬声器的只数。阴影尾部 $X \ge 15$ 的概率约为0.021。把 $p$ 改为0.75，可看雌虫若真的四分之三选择同种歌声时的分布：此时阴影区约占概率的0.62——即以15只及以上拒绝的单侧检验的功效。
:::

说明的最后一点值得强调。若只有20只雌虫、真实偏好为75 %，实验检出偏好的概率也只有约62 %；这样的研究得出"不显著"并不能说明多少。研究之前从合理的效应量出发计算功效，才是决定测试多少只动物的方法（[[biostatistics/hypothesis-testing]]）——而在动物研究中这既是统计要求也是伦理要求，因为功效不足的研究用了动物，却答不了自己的问题。

### 伪重复

::: definition 伪重复 {#def-pseudo}
**伪重复** (pseudoreplication)（Stuart Hurlbert，1984）指把非独立的测量当作独立重复用于统计检验。重复的单位必须是处理被独立施加其上的单位：若一段录音放给二十只鸟听，实验就只有一个"歌声"重复（外加对它作出响应的二十次测量），而不是二十个。
:::

伪重复在行为研究中流行成灾，因为个体被反复测量、同群共享环境、刺激的制作昂贵。Donald Kroodsma (1989) 指出，许多鸟声回放实验对每种歌声类型只用了一段录音，于是任何响应差异都可能源于那段录音的某种偶然特性，而非歌声类型。解决办法是：使用大量独立的刺激（每只鸟听不同的样本）、分析前先在每个个体内部对重复测量取平均，或使用显式表达嵌套结构的统计模型（以个体或刺激为随机效应的混合模型）。

## 比较方法

实验检验一个物种之内的功能。关于进化——以及许多关于功能——的问题靠比较物种来检验。若精子竞争偏好更大的睾丸，那么雌性与多个雄性交配的物种，其睾丸相对体型应大于不这样做的物种。这一预言已在灵长类、鸟类、蝴蝶与鱼类中得到证实。但跨物种的比较有一个统计陷阱。

::: definition 系统发育非独立性 {#def-nonindep}
物种不是独立的数据点。近缘物种因从共同祖先继承了性状而彼此相似，因此许多物种之间的两性状相关可能只反映少数几次进化事件，每一次都被整个进化枝继承。**系统发育比较方法**显式地带入系统发育来分析数据，使每一次独立的进化变化只计一次。
:::

Joseph Felsenstein 1985年的论文《Phylogenies and the comparative method》表明未加校正的分析会误导到何种地步，并提出**系统发育独立对比** (phylogenetically independent contrasts)：姐妹群之间（以及树内更深处的重建祖先值之间）的差值，以枝长标准化后，在进化的布朗运动模型下相互独立。现代方法（系统发育广义最小二乘）推广了这一思想。用最简单的姐妹对形式即可看清其原理。

::: example 数独立的进化变化 {#ex-contrasts}
八个鸟种构成四对姐妹种。每对之中，一种集群营巢，另一种独居。研究者测量配对外父权率（雏鸟由社会父亲以外的雄鸟作父的比例）。示意数据如下：

| 对 | 集群 | 独居 |
|---|---|---|
| 1 | 22 | 12 |
| 2 | 15 | 9 |
| 3 | 8 | 7 |
| 4 | 30 | 18 |

把每对当作一次独立比较，检验"集群营巢提高配对外父权"的假说。
::: solution
每对内部，两个物种共享了直到分歧点的全部历史，因此两者之差反映的是分歧*之后*的进化，独立于其他各对。四个差值（集群减独居）为 $+10, +6, +1, +12$：全为正。若集群营巢没有效应，零假设下每个差值正负等可能，故四个全正的概率是 $(\tfrac12)^4 = 0.0625$（单侧符号检验）。数据有所提示，但未达5 %显著，研究需要更多独立的配对。

把八个物种当作八个独立点会夸大证据。而且，若所有集群物种同属一个进化枝、所有独居物种同属另一个，那么无论取样多少物种，这一比较也只立于一次进化变化之上。
:::
:::

比较方法依赖准确的系统发育与一个性状进化模型，且它显示的是关联而非因果；当它与种内的实验彼此印证时最有说服力。

## 功能、适应与最优性

本课程大部分在问 Tinbergen 的第三个问题。其逻辑是**最优性建模**的逻辑：如果自然选择塑造了某种行为，我们就可以通过算出——在动物面临的约束下——什么形式会使适合度最大，来预言其行为形态，并与动物的实际行为比较。

::: definition 最优性模型的要素 {#def-optimality}
一个最优性模型给出：
1. **决策**——被假定受选择的性行为变量（吃什么猎物、在斑块停留多久、是否打斗）；
2. **货币**——被假定最大化的量，作为适合度的代理（能量摄入速率、越冬存活概率、养大的后代数）；
3. **约束**——动物能做或能知的限度（处理时间、转移时间、记忆、知觉误差），以及决策与环境如何决定货币。

当一项决策的收益取决于其他个体做什么时，最优解就被**进化稳定策略**取代（[[behaviour/conflict-game-theory]]）。
:::

Alan Grafen (1984) 把这类模型背后的工作假设称为**表型赌注** (phenotypic gambit)：我们建模行为时*当作*它受一套简单的遗传系统控制、任何策略都可能进化，而忽视遗传的细节。这是一场赌注，赌的是遗传细节很少阻碍种群抵达被预言的最优。这场赌注常常兑现；而当它落空时，落空本身也富有启发。

最优性模型检验关于选择的假说；它们并不证明动物是最优的。若预言失败，可能是货币、约束或适应假定错了，查明是哪一种才是科学工作。Stephen Jay Gould 与 Richard Lewontin (1979) 批评"适应主义纲领"总用一个失败的适应故事替换另一个，而不考虑副产品、历史与约束。对策是把适应假说定量化，并预先说出什么结果会将其证伪。

::: warning "为了物种的利益"
在1960年代之前，许多生物学家以群体或物种的收益解释行为：动物克制攻击以免伤害物种，或限制繁殖以免过度利用食物（V. C. Wynne-Edwards 在1962年为此辩护）。George Williams 的《Adaptation and Natural Selection》(1966) 说明了这类解释为何通常失败：一个克制基因身处不克制者之间会被多育者淹没而丢失，无论它对物种有何影响。行为通过对个体及其亲属的繁殖成功的作用而进化（[[behaviour/cooperation]]）。
:::

::: intuition 作为决策者的动物
当一只椋鸟"决定"离开一个斑块，这句简语的意思是：选择偏爱了某些机制——也许是"两分钟未捕获就离开"之类的经验法则——它们的产出在它们所进化的环境里近似一台理性计算器。这让我们不知机制也能预言行为，只有当我们忘记机制在新环境中可能失灵时，它才会误导。
:::

## 研究动物的伦理

大多数国家对动物行为研究实行规范。William Russell 与 Rex Burch 的《The Principles of Humane Experimental Technique》(1959) 提出了 **3Rs**：**替代** (replacement)（尽可能用非动物方法）、**减少** (reduction)（能回答问题的最少动物数，这要求功效分析）与**优化** (refinement)（尽量减小痛苦，例如用回放与模型代替活的对手）。动物行为研究协会与动物行为学会发布联合指南，并在 *Animal Behaviour* 上定期修订。野外工作中，环志、标签与颈圈可能改变行为或存活，观察者也可能把捕食者引到巢边；好的做法是测量这些效应，而非假定它们不存在。

::: application 保护与福利中的行为
行为谱与时间分配被用于监测农场、实验与动物园动物的福利，其中异常的重复行为（刻板行为）标示条件不良。保护生物学中，人工繁殖的动物常常缺少野外所需的行为，已有多个物种尝试了放归前训练其识别捕食者。许多保护问题都是行为机制（例如对人造光的趋向）与其在改变后的环境中不再能服务的功能之间的错配。
:::

::: summary
- Tinbergen 的四问——机制、发育、功能与进化——互为补充；解释只有在回答同一问题时才相互竞争。机制与发育是近因的，功能与进化是终极的（Mayr，1961）。
- 经典习性学发现了信号刺激、释放者、模式行为与超常刺激，并开创了关于功能的野外实验，如鸥的移壳。
- 行为谱以操作性定义行为范畴；事件以频率度量，状态以持续时间与时间比例度量。
- Altmann 的取样规则（自由、焦点、扫描、行为）与记录规则（连续、瞬时、一零）决定了什么可被估计；一零得分混淆频率与持续时间。
- Cohen 的 $\kappa = (p_o - p_e)/(1 - p_e)$ 度量超出机遇的观察者可靠性；盲评可防观察者偏倚（Clever Hans）。
- 带匹配对照的实验把因果与相关分开；选择测试以二项分布分析，功效应事先计算。
- 伪重复——把非独立的测量当重复——必须避免；重复的单位是被独立处理的单位。
- 物种并非独立；比较检验要数独立的进化变化（独立对比、姐妹对比较）。
- 最优性模型给出决策、货币与约束；它们检验关于选择的假说，并以表型赌注为依托。"为了物种的利益"式的解释通常失败。
:::

## 练习

::: exercise 哪个问题？ {level=1}
按每句话所回答的 Tinbergen 问题为其归类。（a）执行摇摆舞的蜜蜂工蜂，脑内某些基因的表达升高。（b）摇摆舞见于 *Apis* 属所有种，但露巢营巢的小蜜蜂的舞跳在水平面上。（c）在若干生境中，舞被实验扰乱的群体采集的食物更少。（d）年轻的工蜂只有在巢内工作并跟随其他舞者一段时间之后才开始跳舞。
::: solution
（a）机制（个体内的近因）。（b）进化：该性状在 *Apis* 属内的比较分布关系到它的起源；小蜜蜂的水平舞常被解释为接近祖先状态，而在黑暗的垂直巢脾上跳舞、以重力代表太阳方位，是后来导出的。（c）功能：对采集食物的效应就是存活价值。（d）发育：行为如何在个体的一生中产生。
:::
:::

::: exercise Cohen 的 κ {level=1 check="0.8"}
两名观察者在200次分类中有90 %一致，由其范畴频率算出的机遇期望一致为50 %。Cohen 的 κ 是多少？
::: solution
$\kappa = (0.9 - 0.5)/(1 - 0.5) = 0.4/0.5 = 0.8$。
:::
:::

::: exercise 时块长度 {level=1 check="100"}
每10秒观察一只动物一次。若它正在休息，则10秒后它仍在休息的概率是0.9，与其已休息多久无关。一个休息时块的平均长度是多少秒？
::: solution
每步以恒定的概率0.9继续，时块的步数服从几何分布，均值 $1/(1 - 0.9) = 10$ 步，即 $10\times10 = 100$ s。
:::
:::

::: exercise 一个小选择测试 {level=2 check="0.0107"}
十条雌鱼各测一次，其中九条在喉部发红的雄鱼旁停留的时间多于在无红喉雄鱼旁。计算无偏好零假设下单侧二项检验的 $p$ 值（三位有效数字）。
::: solution
$P(X \ge 9) = \left[\binom{10}{9} + \binom{10}{10}\right]/2^{10} = 11/1024 = 0.0107$。双侧则 $p = 0.0215$。
:::
:::

::: exercise 来自扫描的标准误 {level=2 check="0.0324"}
在200次独立的扫描样本中，一只鸟有60次处于警戒。估计其警戒时间比例及标准误（三位有效数字）。
::: solution
$\hat p = 0.3$ 且 $\mathrm{SE} = \sqrt{0.3\times0.7/200} = \sqrt{0.00105} = 0.0324$，得到近似的95 %区间 $0.30 \pm 0.064$。
:::
:::

::: exercise 选择一个设计 {level=2}
你想知道（a）一群12只狒狒一天中多大比例在摄食，（b）成年雄性交斗有多频繁，以及（c）一只母猴离开其幼仔之前的精确行为序列。为每一问选择取样与记录规则并说明理由。
::: solution
（a）全天定时做扫描取样配瞬时记录：以极小的代价为全部十二只动物给出无偏的时间分配。（b）打斗稀有而显眼：行为取样覆盖全群，对每次打斗及其参与者做连续记录，并记下观察时数以便计算速率。（c）对母亲做焦点取样并连续记录（最好用视频），使每个动作的顺序与时刻都被捕获。
:::
:::

::: exercise 找出伪重复 {level=2}
为检验知更鸟对陌生者歌声的响应是否强于对邻居歌声，研究者录下一段邻居歌声与一段陌生者歌声，以随机顺序把两段都放给30只占区雄鸟听。对陌生歌声的响应显著更强（$p < 0.01$，30只雄鸟的配对检验）。解释为何这不能确立结论，并重新设计实验。
::: solution
每一类只有一个样本，而所谓"邻居"的录音实际上最多只是30只中一两只的邻居；对其余个体而言，它不过是又一个陌生者。即便撇开这点，任何差异也可能源于这两段特定录音的某个特征（长度、响度、录音质量、歌曲类型），而非熟悉度。设计必须让每只雄鸟听自己邻居的歌声与一段陌生歌声，两者以同样的方式录制与剪辑，不同的雄鸟配不同的邻居与陌生录音，响度匹配并在同一位置随机顺序播放。这样，30只雄鸟就是"熟悉对陌生"比较的30次独立重复。
:::
:::

::: exercise 姐妹对比较 {level=3 check="1/32"}
五对相互独立的灵长类姐妹种在交配制度上不同：每对中一种的雌个体在一个发情期内与多个雄个体交配，另一种则否。五对之中，多雄种的睾丸相对体重都更大。若交配制度没有效应，这一结果的单侧符号检验概率是多少？为什么这比把全部十个物种的相对睾丸质量对交配制度做普通最小二乘回归更好？
::: solution
每对贡献一次独立比较，零假设下为正的概率为 $\tfrac12$，故 $P = (\tfrac12)^5 = 1/32 = 0.031$。对十个物种做普通最小二乘回归会把它们当作独立，但姐妹种共享大部分历史；若更大的睾丸与多雄交配曾经在某个大进化枝的早期一起进化过一次，该进化枝内每个物种都会同时带着这两个性状，回归就把一次进化事件数了许多次。姐妹对检验只数每次分歧之后独立发生的变化。（完整分析会对整棵树用独立对比或系统发育最小二乘，相对睾丸大小取相对体重 log–log 回归的残差。）
:::

::: exercise 一零记录 {level=3 check="6"}
在 [[#ex-onezero]] 中，一零得分高估梳羽时间比例多少倍？若把样本区间减半到15秒（四十个区间），而每个时块仍落在不同的区间里，一零得分会是多少？由此得出什么一般教训？
::: solution
一零得分为0.30，真实比例为0.05，高估6倍。区间变为四十个时得分为 $6/40 = 0.15$，高估3倍。得分依赖于所选的区间长度，只有当区间相对时块足够短时它才逼近真实比例——而此时一零记录已经变成了连续记录。一零得分不应解读为持续时间，用不同区间得到的得分彼此不可比较。
:::
