肯尼亚安博塞利的绿猴 (*Chlorocebus pygerythrus*) 遭到豹、猛雕与蟒蛇的猎食，而每一种捕食者都要求一种不同的逃脱方式。面对豹，安全的地方是爬到高处的树上、伸出的细枝上；面对雕，安全的地方是灌木之下，因为雕是在树梢处发动袭击的；面对蛇，猴群会站立起来查看四周的草地。Thomas Struhsaker 在1960年代就已注意到，绿猴针对三类捕食者发出的报警信号在声学上各不相同。1980年，Robert Seyfarth、Dorothy Cheney 与 Peter Marler 在没有任何捕食者在场时，从隐藏的扬声器播放这些叫声的录音。听到"豹"报警的猴群跑上了树，听到"雕"报警的抬头张望并跑进掩蔽处，而听到"蛇"报警的则低头查看。叫声本身就携带了足够让听者选出恰当逃脱方式的信息。

本章追问动物如何通讯、为何通讯。我们从定义——信号与线索的区分——以及接收者的问题：如何在嘈杂的世界中提取信息。接着我们考察信号的来源，以及它们的构造如何适应其传播所经的环境。本章的核心是**诚实性**问题：当信号发出者与接收者的利益冲突时，信号凭什么应当被相信？我们考察昂贵信号与累赘、无法作假的指示信号、共同利益与社会性强制，然后是欺骗与拟态——它们之所以能够存续，正是因为诚实是常态。最后以蜜蜂的舞蹈作结，那是除我们自己的物种之外已知最精致的符号信号。配偶选择的背景见 [[evolution/sexual-selection]]。

## 信号、线索与信息

::: definition 信号与线索 {#def-signal}
**信号**是改变另一生物行为的一个动作或一种结构，它正因为有这个效应才进化出来，并且它之所以有效，是因为接收者的反应同样进化过 (John Maynard Smith 与 David Harper, 2003)。**线索**是世界的任何特征——有生命的或无生命的——动物能用来指导自己的行为、却并非为这一用途进化出来的特征——哺乳动物呼出的二氧化碳为蚊子引路，但这种哺乳动物并没有为了吸引蚊子而进化出呼吸。**胁迫**是靠强力而非通过进化出的反应改变另一个体的行为（把竞争对手挤到一边不是信号）。
:::

这个定义是功能性的：使一个东西成为信号的，是双方的进化历史。同一个动作在一个情境中是线索，在另一个情境中可以是信号。老鼠在落叶中的窸窣声对猫头鹰是线索；鼠崽把母亲唤到身边来的吱吱声是信号。

通讯常被描述为**信息**的传递——即接收者对世界某种状态（信号发出者的品质、它的意图、捕食者的存在）不确定性的降低。若在信号存在的条件下该状态的概率、与没有信号时不同，这个信号就携带信息。John Krebs 与 Richard Dawkins (1984) 强调了另一面：信号之所以进化，是因为它们以有利于信号发出者的方式改变接收者的行为，他们称之为**操纵**；而接收者则进化出抵制操纵、从中榨取自己所能得到的真实信息的倾向（**读心**）。两种视角都不可缺少。一个信号只有在响应它平均来说对接收者有回报时才能维持，所以信号之所以携带信息，是因为否则接收者就会停止响应。

### 接收者的问题

每个信号都是在背景噪声——其他声音、变化的光线、其他动物的信号——之下到达的，接收者必须判断是否有信号存在、它意味着什么。为雷达与人类知觉心理学发展出来的**信号检测理论**描述了这一权衡。

::: proposition 击中与虚报 {#prop-sdt}
设接收者的感觉系统产生一个内部反应 $X$：只有噪声时它服从均值为0、标准差为1的正态分布；信号存在时它服从均值为 $d'$、标准差不变的正态分布。若接收者只要 $X$ 超过阈值 $t$ 就作出反应，则

$$
P(\text{hit}) = P(X > t \mid \text{signal}) = 1 - \Phi(t - d'), \qquad P(\text{false alarm}) = P(X > t \mid \text{noise}) = 1 - \Phi(t),
$$ {#eq-sdt}

其中 $\Phi$ 是标准正态分布函数。降低阈值会同时提高击中率与虚报率；只有更大的分离度 $d'$（更醒目的信号，或更好的感觉器官）才能让两者同时改善。最优阈值取决于信号出现的频繁程度，以及漏掉信号和虚报各自的代价。
:::

::: example 反应的阈值 {#ex-sdt}
一只雌蛙在其他种类的合唱声中倾听同种雄蛙的叫声。她对噪声的内部反应均值为0，对同种叫声的反应均值为 $d' = 2$，两者标准差均为1。(a) 若她只要反应超过 $t = 1$ 就接近，她的击中率与虚报率各是多少？(b) 若她把阈值提高到 $t = 1.5$，会发生什么？(c) 为什么在密集、嘈杂的合唱声中，雌蛙的阈值预期更高？
::: solution
(a) 由[[#eq-sdt]]，$P(\text{hit}) = 1 - \Phi(-1) = 0.841$，$P(\text{false alarm}) = 1 - \Phi(1) = 0.159$。

(b) 在 $t = 1.5$ 处，$P(\text{hit}) = 1 - \Phi(-0.5) = 0.691$，$P(\text{false alarm}) = 1 - \Phi(1.5) = 0.067$。虚报减少到不到一半，代价是漏掉近三分之一的真实叫声。

(c) 若异种声音远比同种叫声常见，低阈值下大多数反应都会是虚报，而每次虚报都要付出时间与暴露于捕食者的代价；这时高阈值合算。相反，在配偶稀少之处，错过一只雄蛙代价高昂，低阈值合算。最优阈值随基准比率与代价而变——与贝叶斯定理同构的逻辑 ([[behaviour/learning-cognition#ex-bayes]])。
:::
:::

## 信号从何而来

信号是从原本就已具有信息性的行为或结构进化而来的。Niko Tinbergen 与 Julian Huxley 把这一过程称为**仪式化**：一个原本服务于其他功能的动作——准备起飞、攻击、理羽、取食——变得夸张、刻板，并常与醒目的色彩结合，因为接收者把它当作线索来响应，而随后作用在表演者身上的选择又放大了它的效应。许多威胁展示是攻击的、可辨认的意图运动；许多求偶展示包含来自取食或筑巢的动作。比较方法显示出了这些台阶：在鸭类中，Konrad Lorenz 跨物种地把展示从简单的理羽动作一直追溯到精致而刻板的展示。

信号也能利用接收者已有的**感官偏向**——在另一种情境（如寻找食物）中进化出来的偏好——正如在 [[evolution/sexual-selection]] 中针对 túngara 蛙与剑尾鱼所论述的那样。在水螨 *Neumania papillator* 中，Heather Proctor (1991) 发现，雄螨通过以雌螨的猎物桡足类所产生振动频率振动腿来进行求偶；饥饿的雌螨更可能作出响应。

### 面向环境的设计

信号必须从发送者传到接收者，而环境塑造着它们的构造。在森林里，高频被树叶散射，快速重复被回声模糊；Eugene Morton (1975) 发现，热带森林的鸟类比起开阔生境的鸟类，往往以更低频率、以更纯净更富乐音的音符鸣唱，这一格局被称为**声学适应假说**（许多但并非全部后续比较研究支持它）。城市噪声以低频为主，而一些城市鸟类种群——如大山雀——的鸣唱频率更高 (Hans Slabbekoorn 与 Margriet Peet, 2003)。

John Endler 的**感官驱动**假说 (1992) 把信号、感觉器官与生境纳入单一框架：光照或声音环境塑造接收者的感觉，感觉塑造最有效的信号，信号进而塑造配偶选择乃至物种形成。在维多利亚湖 *Pundamilia* 属的丽鱼中，Ole Seehausen 与合作者 (2008) 发现，雄鱼在清澈的浅水中呈蓝色、在更深、红移的水中呈红色，视觉色素基因 *LWS* 在种群间相应地不同，而雌鱼偏爱在其光环境中最醒目的雄鱼体色。

## 诚实性问题

当信号发出者与接收者利益一致时——蜜蜂把同巢伙伴招募到食物源、亲代向自己的后代报警——诚实信号不构成难题。但许多信号是在利益冲突的双方之间传递的。雄鸟不管是不是好配偶都想被选中；竞争者不管强不强都想被相信是强的；雏鸟想要食物，比亲代愿意给的更多。接收者凭什么应当相信信号？信号发出者又为何不夸大？如果夸大，接收者就会进化出对信号的无视，信号就会消失。因此，利益冲突双方之间的信号之所以能维持，就要求信号平均而言是可靠的。做到这一点有几种途径。

### 昂贵信号与累赘

Amotz Zahavi 的**累赘原理**（handicap principle，1975）提出，信号之所以可靠，是因为它们代价高昂：只有高品质个体才付得起把信号做足的成本。这一思想长期遭到抵制，部分原因是其文字表述似乎意味着任何昂贵性状都可以。Alan Grafen (1990) 用一个形式化模型证明，诚实的昂贵信号可以是进化稳定的，条件是：同一信号的成本对低品质个体更高——更确切地说，加大信号的*边际*成本相对于边际收益对它们更大。这样，每个信号发出者的最佳策略就是以一个能揭示其品质的水平发出信号。

::: proposition 诚实昂贵信号的一个简单模型 {#prop-handicap}
信号发出者分为高品质与低品质。若接收者把一个信号发出者当作高品质对待，该发出者获得收益 $b$；否则一无所获。发出信号对高品质个体的成本为 $c_H$，对低品质个体为 $c_L$。若

$$
c_H < b < c_L,
$$ {#eq-separating}

就存在一个稳定的**分离均衡**：高品质个体发出信号，低品质个体不发，于是信号是诚实的，接收者最好相信它。若 $b > c_L$，低品质个体发信号也有利可图，信号便不再具有信息性。关键假设是成本随品质而变；诚实由成本的差异维持，而不是由成本本身维持。
:::

::: example 欺骗何时合算？{#ex-handicap}
高品质雄鸟能以相当于4只后代能量的代价长出长尾；低品质雄鸟长同样的尾要付出12只后代的代价。雌鸟优先与长尾雄鸟交配，这使长尾雄鸟平均多获10只后代。(a) 尾是诚实信号吗？(b) 若环境的变化——比如食物增多——把低品质雄鸟的代价降到8，会发生什么？
::: solution
(a) 对高品质雄鸟，长尾的收益是 $10 - 4 = 6 > 0$；对低品质雄鸟，$10 - 12 = -2 < 0$。条件[[#eq-separating]]成立：只有高品质雄鸟才会长长尾，于是尾长可靠地指示品质，雌鸟偏爱它是有利的。

(b) 当 $c_L = 8$ 时，低品质雄鸟同样会长尾，获利 $10 - 8 = 2$。于是所有雄鸟都长着长尾，信号不再区分品质，偏好带给雌鸟的收益随之消失。随着时间推移，预期或者偏好减弱（使 $b$ 变小），或者信号升级到一个对低品质雄鸟再度过于高昂的水平——更长的尾。这正是诚实信号系统能够漂向更大夸张程度的一种途径。
:::
:::

当信号连续变化时，同样的逻辑依然成立。若强度为 $s$ 的信号带来的收益与 $s$ 成正比（接收者对更强的信号反应更大），而成本对品质更低的发出者上升得更陡，那么每个发出者的最优强度都随其品质而增大，信号便揭示了品质。

::: widget plot

x: 0, 8

caption: 低品质（$q = 1$）与高品质（$q = 2$）信号发出者以强度 $s$ 发出信号时的净收益 $bs - s^2/q$，其中接收者的反应与 $s$ 成正比，而成本 $s^2/q$ 对低品质者更陡。每条曲线在 $s^* = bq/2$ 处达到峰值：$b = 4$ 时低品质在 $s = 2$、高品质在 $s = 4$ 处取最优。一个低品质个体若模仿高品质信号（$s = 4$），所得将是0而不是4。改变 $b$，两个最优点都会移动，但高品质的最优点始终两倍于低品质的——信号仍然是诚实的。
:::

关于信号成本随状况而变的证据，来自操纵状况的实验。在许多鸟类中，基于类胡萝卜素的红色与黄色羽毛取决于食物与寄生虫负载：Geoffrey Hill (1991) 发现，家朱雀 (*Haemorhous mexicanus*) 中羽色更红的雄鸟受雌性偏爱，也更善于喂养雏鸟，而且换羽新羽的红色程度取决于食物中的类胡萝卜素。雏鸟的乞食是一个不那么显然的例子：乞食在能量上便宜，但大声乞食会把捕食者引到巢边，这一代价可能大到足以让乞食如实反映需求。

### 指示信号

有些信号之所以可靠，是因为它们在物理上就不可能作假。这些**指示信号**通过与品质相连的制造机制——而不是通过成本——与其所揭示的品质绑定在一起。大蟾蜍低沉的鸣声（[[behaviour/conflict-game-theory]]）是体型的指示信号，因为较大的雄体声带较大。在马鹿中，雄鹿吼声中共振峰（声道的共振频率）的间隔取决于声道长度，而后者与体型相关；David Reby 与 Karen McComb (2003) 表明，共振峰间隔能预测雄鹿体型，而且雄鹿对共振峰间隔更低的播放录音作出的反应，就像对更大的对手一样。吼叫时雄鹿压低喉头、拉长声道，从而夸大外表体型——但这有解剖学的极限，所以在量程顶端，这个指示信号依然可靠。

### 共同利益与亲缘关系

当信号发出者与接收者有亲缘关系、或以其他分享利益的，信号可以既不昂贵又诚实。John Maynard Smith 的**菲利普·西德尼爵爷博弈**（Sir Philip Sidney game，1991）建模了这样一个处境：一个有需求的个体可以向持有资源的亲属发出自己需要帮助的信号。只要亲缘关系足够近，无成本或低成本的诚实信号就能稳定，因为一个发出者若夺走亲属更需要的资源，就会损失自身的广义适合度（[[behaviour/cooperation]]）。蜜蜂舞蹈、亲缘成群时发出的报警信号、社会性昆虫的招募信号，都是共同利益支撑诚实性的例子。

### 社会性强制

关于支配地位的信号——**地位标记**——可以生产上毫无成本而仍然诚实，只要欺骗者会受到惩罚。在欧洲马蜂 *Polistes dominula* 中，雌性面部黑色的斑纹个体可变，并能预测支配等级。Elizabeth Tibbetts 与 James Dale (2004) 给一些黄蜂涂改了面部，改变它们的表观地位：标记显示的地位高于其真实格斗能力的黄蜂，遭到了其他个体比对照更多的攻击。信号的成本不在其生产，而在它招来的挑战，而只有真正强大的个体才承受得起。

::: warning "动物发信号是为了分享信息"与"发信号意味着意图"
信号并非为了他人或群体的利益传递信息而进化；它们因为有利于信号发出者而进化，并因为响应它们对接收者有回报而维持。在利益分歧之处，信号被期望诚实到成本、约束或强制所允许的程度——不多不少。同样没有必要假设信号发出者意在传递信息或欺骗，或接收者理解意义：一只绿猴的豹报警信号可以是功能上指称的（它可靠地预示一类捕食者并引发恰当反应），而鸣叫者无需拥有"豹"的概念或警告的意图。是否确有动物有意地发信号，是一个经验问题，正用关于类人猿与某些鸟类的精心设计实验加以研究。
:::

## 欺骗

诚实不必完美。因为接收者会对通常可靠的信号作出反应，偶尔的欺骗可以是合算的——只要它保持稀少到响应总体上仍有回报。

**贝氏拟态**以 Henry Walter Bates（1862，在亚马孙蝴蝶中首先描述）命名，出现在可食的物种 resemble 有毒或危险的模型之时。已经学会回避模型的捕食者（[[behaviour/learning-cognition]]）也会回避拟态者。这种保护是频率依赖的：相对于模型，拟态者越常见，捕食者把该色斑体验为可食的机会就越多，其回避就越弱。**缪氏拟态**（Fritz Müller, 1878）则相反，是两个都有防御的物种彼此相似，共同分担教育捕食者的成本——一种跨物种分享的诚实信号。

::: example 捕食者何时应当攻击警戒色斑？{#ex-mimic}
一只鸟遇到一只带警戒色斑的昆虫。这类昆虫中的一定比例 $m$ 是可食的拟态者，值 $B = 1$ 单位能量；其余是有毒的模型，取食它们要付出 $C = 4$ 单位的代价（毒素的效应）。若鸟无法区分二者，何时攻击合算？
::: solution
攻击的期望收益为 $mB - (1 - m)C = m - 4(1 - m) = 5m - 4$，当 $m > 0.8$ 时为正。只要拟态者占带此斑昆虫不足80 %，鸟就应回避所有带斑个体，拟态者因此受到保护。若拟态者变得更常见，攻击便合算，保护随之瓦解。一般地，阈值为 $m > C/(B + C)$：模型越毒，拟态者在更高频率下仍受保护。这种频率依赖解释了为什么贝氏拟态者往往比其模型稀少，也解释了为什么一些拟态蝴蝶是多型的、不同色型拟态不同的模型。
:::
:::

欺骗也发生在同种之内以及捕食者与猎物之间。*Photuris* 属的雌性萤火虫会以 *Photinus* 属雌性闪光的模式回应 *Photinus* 属雄性的求偶闪光，把凑近的雄虫吃掉——这就是 James Lloyd 在1965年描述的**攻击性拟态**。在卡拉哈里，叉尾卷尾 (*Dicrurus adsimilis*) 跟随狐獴等觅食者，在捕食者接近时发出真实的报警信号；但当一只狐獴捕获食物时，它们也会发出虚假的报警信号，趁狐獴逃走夺走食物。Tom Flower 与合作者 (2014) 表明，卷尾会模仿包括狐獴在内的其他物种的报警信号，并且当目标不再响应一个重复的假警报时，它们便换用另一种信号类型——利用了目标的习惯化。这一系统之所以稳定，是因为卷尾的警报通常是真的，所以作出响应平均而言对狐獴仍有回报。

::: application 害虫防治与保护中的信号
理解信号有实用价值。蛾类害虫的人工合成性信息素被用于扰乱交配（让果园充满信息素，使雄虫找不到雌虫）或以诱捕器监测种群，这一方法已用于防治苹果园中的苹果蠹蛾与许多其他作物害虫。用痛苦叫声的录音回放驱鸟利用了报警信号，尽管习惯化限制了它的效果。反过来，人为噪声与光污染会干扰信号——掩蔽鸣唱、扰乱萤火虫的展示与蛾类对性信息素的追踪——并已被纳入保护评估。
:::

## 蜜蜂的舞蹈

非人类动物中最令人惊叹的信号是蜜蜂的摇摆舞，由 Karl von Frisch 在1940年代破译。一只从富饶食物源返回蜂巢的采集蜂，在黑暗的垂直巢脾上跳舞：她一边摆动腹部一边笔直向前跑，绕回起点，左右交替地重复，画出八字形。其他蜜蜂紧贴着她的身体跟随。

Frisch 证明，舞蹈编码了食物的位置。摇摆跑相对于垂直向上方向的**方向**，对应食物相对于太阳方位角的方向：笔直向上的摇摆跑意为"朝太阳飞"，偏垂直右侧60°的跑动意为"在太阳右侧60°的方向飞"。摇摆跑的**持续时间**随与食物的距离增加，大致线性；确切的标定在不同蜜蜂品系之间有差异，并取决于蜜蜂飞行中经历的视觉流。跟随舞蹈的蜜蜂随后在所指位置附近搜索，靠舞者携带的食物气味来识别食物。

::: example 解读一次舞蹈 {#ex-dance}
在某一天太阳方位角为150°（南偏东）的时刻，一只采集蜂的摇摆跑指向巢脾上垂直向上方向顺时针40°。食物在罗盘方位的哪个方向？一小时后太阳方位角移到了165°；报告同一食物源的舞者应当如何定向她的跑动？
::: solution
摇摆跑偏离垂直方向的角度，等于食物方向偏离太阳方位角的角度，转向一致。食物位于 $150° + 40° = 190°$，正南略偏西。一小时后，食物仍在190°，此时位于太阳右侧 $190° - 165° = 25°$：舞者应当把跑动定在垂直方向顺时针25°。跳舞的蜜蜂会随着太阳移动改变自己的角度，靠内在钟加以补偿（[[behaviour/mechanisms-of-behaviour]]）——这与导航中使用的时间补偿太阳罗盘相同（[[behaviour/migration-navigation]]）。
:::
:::

招募者是否真的利用舞蹈信息，曾在1960年代引起争论，当时 Adrian Wenner 主张单靠气味就能解释招募。James Gould (1975) 用一个巧妙的办法平息了争论：让舞者指示一个假位置——他利用有明亮光源时蜜蜂按光源方向跳舞这一事实，遮住了舞者的单眼，使她们对光不再有反应而跟随者有——结果招募者飞向舞蹈所指之处，而不是舞者取食之地。Joe Riley 与合作者 (2005) 后来用谐波雷达追踪招募者，确认它们按所指方向飞行、大致飞到所指距离，然后靠气味与视觉寻找食物。

舞蹈之所以诚实，是因为舞者与招募者分享利益：一巢之中的工蜂是姐妹，她们从群体的成功中获得广义适合度（[[behaviour/cooperation]]）。舞蹈也用于选址：当一团蜂群寻找新的巢穴空腔时，侦查蜂为找到的地点跳舞，对更好的地点跳得更起劲，当足够多的侦查蜂为同一个地点跳舞时，蜂群便做出决定——Thomas Seeley 与合作者描述了这一集体决策。

::: history
Darwin 的 *The Expression of the Emotions in Man and Animals*（1872）把展示当作进化的性状来处理，Julian Huxley 对凤头鸊鷉的研究（1914）引入了仪式化。Frisch 对蜜蜂舞蹈的破译始于1940年代，结于 *Tanzsprache und Orientierung der Bienen*（1965；英译本1967年）。Bates 于1862年、Müller 于1878年描述拟态。现代信号理论始于 Zahavi 的累赘原理（1975）、Krebs 与 Dawkins 关于操纵与读心的文章（1984）与 Grafen 的诚实信号形式化模型（1990）；John Maynard Smith 与 Harper 的 *Animal Signals*（2003）集其大成。Seyfarth、Cheney 与 Marler（1980）的绿猴报警信号回放实验开启了指示性信号的研究。
:::

::: summary
- 信号因其对接收者的效应而进化，接收者的反应也同样进化过；线索是并非为传递信息而进化的信息。
- 接收者面临击中与虚报的权衡（信号检测理论）；只有更醒目的信号或更好的感官能使两者同时改善。
- 信号源于对具信息性动作的仪式化，也源于对感官偏向的利用；其构造适应传播环境（声学适应、感官驱动）。
- 在利益冲突的双方之间，信号平均而言可靠，其机制有随品质而变的成本（累赘；$c_H < b < c_L$ 时诚实）、无法作假的指示信号、共同利益与亲缘关系，以及社会性强制（地位标记）。
- 欺骗在低频率下得以维持：只要贝氏拟态者稀小到捕食者坚持回避仍有收益（$m < C/(B + C)$），它们就受到保护；攻击性拟态与虚假报警利用了接收者的反应。
- 蜜蜂摇摆舞编码相对太阳方位角的方向，以摇摆持续时间编码距离；误导舞蹈实验与雷达追踪证实招募者确实利用这些信息。
:::

## 练习

::: exercise 信号还是线索？{level=1}
判断下列各例：(a) 吸引秃鹫的腐尸气味；(b) 繁殖期雄棘鱼红色的腹部；(c) 兔子听到的狐狸的脚步声；(d) 毒箭蛙鲜艳的警戒色。
::: solution
(a) 线索：腐尸并非为吸引秃鹫而进化出来。(b) 信号：这种颜色因其对雌性与竞争雄鸟的影响而进化出来。(c) 线索。(d) 信号：警戒色因捕食者学会回避而进化出来，而捕食者的回避学习是一种进化出的反应。
:::
:::

::: exercise 击中与虚报 {level=1 check="0.933"}
在[[#prop-sdt]]中取 $d' = 2$、阈值为 $t = 0.5$，击中率是多少（保留三位小数）？
::: solution
$1 - \Phi(0.5 - 2) = 1 - \Phi(-1.5) = 0.933$。虚报率为 $1 - \Phi(0.5) = 0.309$。
:::
:::

::: exercise 拟态阈值 {level=1 check="0.75"}
在[[#ex-mimic]]中，若取食一个模型的代价为3、一个拟态者值1，则拟态者所占比例高于多少时，捕食者就应当发动攻击？
::: solution
$m > C/(B + C) = 3/4 = 0.75$。
:::
:::

::: exercise 解读一次舞蹈 {level=2 check="290"}
太阳方位角为230°。一只采集蜂的摇摆跑指向垂直向上方向顺时针60°。食物在罗盘方位的哪个方向（度数）？若跑动指向逆时针60°，食物又会在哪里？
::: solution
偏垂直向右的跑动表示食物在太阳方位角的右侧（顺时针方向）：$230° + 60° = 290°$，大致是西偏北。偏逆时针60°的跑动则表示 $230° - 60° = 170°$。
:::
:::

::: exercise 诚实还是不诚实？{level=2}
在一个种群中，高品质雄鸟发出展示的成本为3，低品质雄鸟为5，而发出展示的雄鸟通过雌性偏好获得收益4。(a) 该展示是诚实的吗？(b) 若雌性进化出更强的偏好，把收益提高到6，会发生什么？接下来可能进化出什么？
::: solution
(a) $c_H = 3 < b = 4 < c_L = 5$：只有高品质雄鸟展示，所以展示是诚实的。(b) 当 $b = 6 > c_L$ 时，低品质雄鸟也会展示，信号不再区分品质。雌性对它不再有收益，作用在偏好上的选择随之减弱；另一种可能是雄鸟升级展示，直到其成本对低品质雄鸟重新超过收益。诚实信号要求收益落在两种类型的成本之间。
:::
:::

::: exercise 解读一次回放实验 {level=2}
研究者把某只绿猴个体的报警信号录音播放给它的群体听。播放该叫声时，猴群反应强烈。而当这只个体的叫声在此前几天里被反复播放、且始终没有捕食者出现之后，群体对这只个体叫声的反应减弱了，但对另一只个体同类叫声的反应没有减弱。这表明了什么？
::: solution
猴群在跟踪各个鸣叫者的可靠性：当某个鸣叫者的警报被证明不可靠时，它们对其习惯化，但并不泛化到其他鸣叫者。这意味着它们凭声音识别个体，并按各自的经验调整对每个鸣叫者的反应——这是信号可能不可靠时预期出现的、接收者对"操纵"的抵制的一种形式。Cheney 与 Seyfarth 在1988年报告了绿猴的这类结果。
:::
:::

::: exercise 地位标记 {level=2}
解释为什么一个生产上毫无成本的地位标记仍可以是诚实信号。什么样的实验结果会推翻社会性强制的解释？
::: solution
成本来自他人的反应：标记所显示的地位高于其格斗能力的个体，会招来更多挑战而落败，以受伤或失去资源的形式付出代价。只有能为自己的标记撑腰的个体才因展示它而得利。若被实验性夸大标记的个体并*没有*遭到更频繁的挑战（或受到挑战却未受惩罚），并且能够在无力捍卫的情况下获得高地位的好处，社会性强制的解释就被推翻了；那时便没有什么能阻止欺骗，而标记随进化时间会预期失去其信息性。
:::
:::

::: exercise 不同基准比率下的检测阈值 {level=3}
一只捕食者扫描一块田地，在比例为 $\pi$ 的扫描中猎物存在。它的内部反应服从[[#prop-sdt]]，其中 $d' = 2$。攻击真正猎物获益10，在猎物不存在时攻击代价为2（浪费能量并暴露自己）。对阈值 $t = 0.5$、$1$ 与 $1.5$，分别计算 $\pi = 0.1$ 与 $\pi = 0.5$ 时每次扫描的期望收益。每种情形下哪个阈值最优？
::: solution
每次扫描的期望收益为 $\pi\cdot10\cdot P(\text{hit}) - (1 - \pi)\cdot2\cdot P(\text{FA})$，其中击中率与虚报率按 $0.933, 0.309$（$t = 0.5$）、$0.841, 0.159$（$t = 1$）与 $0.691, 0.067$（$t = 1.5$）取值。

$\pi = 0.1$：$t = 0.5$：$0.933 - 1.8\times0.309 = 0.377$；$t = 1$：$0.841 - 1.8\times0.159 = 0.555$；$t = 1.5$：$0.691 - 1.8\times0.067 = 0.571$。最高的阈值最优。

$\pi = 0.5$：$t = 0.5$：$5\times0.933 - 0.309 = 4.36$；$t = 1$：$4.21 - 0.16 = 4.05$；$t = 1.5$：$3.46 - 0.07 = 3.39$。最低的阈值最优。

猎物稀少时，低阈值下大多数反应都是虚报，所以保守的阈值合算；猎物常见时，错过它们的损失超过偶尔的虚报。因此接收者的阈值应当跟踪基准比率——而稀少的信号发出者（如贝氏拟态者）反而能从接收者的保守中获益。
:::
:::

::: exercise 拟态与频率 {level=3}
只要贝氏拟态者不足携带同一警戒色斑昆虫的80 %，它就受到保护（[[#ex-mimic]]）。解释为什么作用于拟态者的选择仍可能使它远远稀少于该阈值，并解释为什么一些拟态物种是多型的、各色型模拟不同的模型。
::: solution
该阈值假设捕食者对频率有完美的知识、且只作一次决策；真实的捕食者从经验中学习，随着遇到越来越多带此斑的可食昆虫，其回避会逐步减弱。因此每一个新增的拟态者都会稍稍降低所有带此斑者（拟态者与模型）受到的保护——针对常见拟态者的频率依赖选择，远早于阈值就已起作用。模拟另一种较少被利用的模型的拟态者可以摆脱这一成本，所以模拟其他模型的稀有色型受到青睐；这种负频率依赖能够维持多态性，如非洲的拟态凤蝶 *Papilio dardanus*，其雌性模拟若干种味道不佳的物种。
:::
:::
