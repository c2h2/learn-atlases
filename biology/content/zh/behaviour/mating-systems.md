林岩鹨 (*Prunella modularis*) 是欧洲花园与树篱中一种褐色、其貌不扬的小鸟——而正如 Nick Davies 在1980年代于剑桥大学植物园所发现的，它的两性生活的多变程度令人吃惊。在同一个种群中，有的雌鸟与一只雄鸟共同生活（一夫一妻制），有的雄鸟与两只雌鸟（一雄多雌制），有的雌鸟与两只雄鸟（一雌多雄制），还有些由两只或三只雄鸟与两只或三只雌鸟组成的群体共享配偶（多雄多雌制）。这些安排不是物种的特征，而是冲突的结果。在食物稀少的地方，雌鸟的领域更大，大得一只雄鸟无法独自守卫，于是第二只雄鸟得以进入；优势（α）雄鸟试图看住雌鸟、垄断交配，而从属的 β 雄鸟则趁优势雄鸟不在时设法与雌鸟交配。雌鸟呢，她反过来主动从 β 雄鸟那里争取交配——而 β 雄鸟喂雏的多少，与他所占交配的份额成正比，这一份额由对幼鸟做 DNA 指纹分析推算得出。交配系统，正是每个个体为最大化自身繁殖成功而作为的结果。

本章解释这类系统如何产生。我们先定义交配系统——区分社会安排与基因上的亲子关系——并用 Emlen 与 Oring 的生态理论说明多配偶制何时可能。我们详细讨论一雄多雌制阈值模型，然后是雌性防御型一雄多雌制与求偶场、一雌多雄制以及雌性从多次交配中获得的收益，再到精子竞争的定量理论。后半章转向亲代抚育：哪个性别抚育、为什么，以及抚育在两性的之间、亲代与子代之间、同胞兄弟姐妹之间制造的冲突。性选择的基本理论——异配生殖、贝特曼梯度、操作性比与配偶选择——见 [[evolution/sexual-selection]]，此处假定读者已掌握；配偶间的通讯见 [[behaviour/communication]]。

## 交配系统：社会性与遗传性

::: definition 交配系统 {#def-mating}
一个种群的**交配系统**描述每个性别的个体在一个繁殖季有多少配偶、配偶关系如何形成与维持：
- **一夫一妻制**——每个雄性与每个雌性各有一个配偶（以一个繁殖季为限或终生）；
- **一雄多雌制**——一些雄性与多个雌性交配，每个雌性只有一个雄性；
- **一雌多雄制**——一些雌性与多个雄性交配，每个雄性只有一个雌性；
- **多雄多雌制**——群体内若干雄性与若干雌性互为配偶；
- **混交制**——两性个体都与多个对象交配，没有持久的配对关系。

**社会性交配系统**描述谁与谁共同生活、共同繁殖；**遗传性交配系统**——由亲缘分析揭示——描述实际上的父源与母源。
:::

社会性交配系统与遗传性交配系统的区分，随着1980年代末 DNA 指纹分析的出现变得至关重要。许多长期被认为忠贞一夫一妻的鸟类，结果频频出现**配对外父权**（extra-pair paternity，EPP）：雏鸟的生物学父亲并非其社会性配偶。Simon Griffith、Ian Owens 与 Katherine Thuman 对社会性单配制鸟类的2002年综述发现，多数被研究物种都有配对外后代，平均约11 %的后代、19 %的巢至少含一只配对外雏鸟。有些物种，如澳大利亚的壮丽细尾鹩莺 (*Malurus cyaneus*)，远超过一半的后代出自配对之外；而另一些，如许多海鸟，几乎没有。

::: example 配对外雏鸟是随机散布的吗？{#ex-epp}
在一种社会性一夫一妻的鸣禽中，11 %的雏鸟是配对外的，每巢有五只雏鸟。若每只雏鸟独立地有11 %的概率是配对外的，多大比例的巢会至少含一只配对外雏鸟？实际观察到的比例是19 %。这一差别说明了什么？
::: solution
全部五只雏鸟都在配对内的概率是 $0.89^5 = 0.558$，于是应有 $1 - 0.558 = 0.44$ 的巢至少含一只配对外雏鸟。观察到的19 %远低于此：配对外雏鸟聚集在比偶然预期更少的巢里。一些雌鸟产下好几只配对外后代，多数则一只都没有。这一格局表明，配对外父权取决于雌性（或她的社会性配偶，或她的领域与邻居），而不是每枚卵独立的偶然——这正是雌性选择配对外配偶的模型的预言，例如与低品质雄鸟配对的雌鸟转向与更好的邻居进行配外交配。
:::
:::

::: warning "一夫一妻就是忠贞"与"雄性殷勤，雌性矜持"
社会性一夫一妻并不意味着遗传上的一夫一妻：在多数社会性单配制的鸟类中，一些后代由其他雄鸟所生，而且往往是因为雌性寻求配外交配。"殷勤的雄性与矜持的雌性"这一刻板印象，来自对 Bateman 与 Trivers 的简化解读，它无视了许多物种的雌性多次交配、主动争取交配并从中获益的事实。性选择的方向与强度取决于生态与操作性比（[[evolution/sexual-selection]]），而不取决于某一性别的固定本性。
:::

## 交配系统的生态学

为什么有的物种一雄多雌、另一些一夫一妻？Stephen Emlen 与 Lewis Oring (1977) 提出，答案在于**多配偶制的环境潜力**：一个性别的个体能在多大程度上垄断另一性别的多个成员，而这取决于资源与配偶在空间和时间上的分布。

- 当雌性、或雌性所需的资源**在空间上聚集成块**时，一只雄性可以一次守住了多个：**资源防御型一雄多雌制**（一只雄鸟占据食物或巢址丰富的领域，几只雌鸟迁入其中）或**雌性防御型一雄多雌制**（一只雄性直接看守一群雌性，如象海豹与马鹿）。
- 当雌性**分散**而且接受交配的时间**不同步**时，一只雄鸟可以先后找到并与多个交配；当她们分散而接受交配**同步**时，他就做不到，于是一夫一妻更可能出现。
- 当资源与雌性都无法经济地防卫时，雄性可能在传统地点**求偶场**展示，雌性来到这里交配。

多配偶制的潜力只有在个体能够利用它时才会实现。当双亲都在场才能养活后代时——例如雏鸟是晚成的、必须高频喂食——离巢的雄鸟会失去自己的后代，于是即使环境允许一雄多雌，带双亲抚育的一夫一妻仍可能受青睐。

### 一雄多雌制阈值模型

假设雄鸟防卫质量不同的领域，雌鸟一只接一只到来、选择定居之处。一只雌鸟可以与一只劣质领域上的未配雄鸟结对，或成为一只已配雄鸟在优质领域上的第二配偶。她为什么要接受第二个选项——要知道她必须分享雄鸟的帮助与领域的资源？Jared Verner 与 Mary Willson (1966) 以及 Gordon Orians (1969) 给出了答案。

::: proposition 一雄多雌制阈值 {#prop-polygyny}
设雌鸟在质量为 $q$ 的领域上的繁殖成功：作为唯一雌鸟时为 $W_m(q)$，作为次配雌鸟时为 $W_s(q) = W_m(q) - D$，其中 $D > 0$ 是分享雄鸟与领域的代价。若她以次配雌鸟身份定居于质量 $q_1$ 的领域优于作为唯一雌鸟定居于质量 $q_2$ 的领域，则

$$
W_m(q_1) - D > W_m(q_2),
$$

所要求的领域质量之差 $W_m(q_1) - W_m(q_2) > D$，就是**一雄多雌制阈值**。当领域质量差异足够大、而分享的代价小时，预期出现一雄多雌。假设：雌鸟自由选择、知晓领域质量，且一配雌鸟无法阻止次配雌鸟迁入。
:::

::: example 选择领域 {#ex-threshold}
在一个沼泽鸟类种群中，雌鸟预期的离巢雏鸟数为 $W_m = 0.5q$，其中 $q$ 是领域内羽化成虫昆虫的密度（任意单位），成为次配雌鸟的代价为 $D = 1.5$ 只雏鸟。一只已配雄鸟占有 $q = 12$ 的领域；最好的未配雄鸟占有 $q = 8$ 的领域。下一只雌鸟应定居在哪里？若已配雄鸟完全不喂雏，以致分享他的代价很小（$D = 0.5$），答案会如何改变？一配雌鸟又会偏好什么？
::: solution
作为优质领域上的次配雌鸟，她预期 $0.5\times12 - 1.5 = 4.5$ 只雏鸟；跟着那只未配雄鸟，则是 $0.5\times8 = 4$ 只。她应当成为第二配偶。阈值的质量差为 $D/0.5 = 3$ 个单位；这里的质量差是4。

当 $D = 0.5$ 时，次配选项给出5.5，仍然更优，而阈值只有1个单位——雄鸟贡献的抚育越少，一雄多雌越容易成立。然而一配雌鸟会因次配雌鸟的到来而受损（如果她自己的成功因分享而下降），于是她可能试图通过攻击前来的待配雌鸟来阻止。该模型预测的是*次配*雌鸟的抉择；雌性之间的冲突是结局的一部分，正如在林岩鹨中。
:::
:::

sliders: d=1.5:0:4:0.1
labels: \text{一配雌鸟 } W_m(q); \text{次配雌鸟 } W_m(q) - D

:::

对该模型的检验结果好坏参半。在红翅黑鹂 (*Agelaius phoeniceus*) 中，与更"一雄多雌"的雄鸟配对的雌鸟，往往与单配雌鸟表现得一样好——如果雌鸟按领域质量作选择，这正是模型所预测的。在斑姬鹟 (*Ficedula hypoleuca*) 中，Rauno Alatalo 与合作者发现，次配雌鸟养大的后代少于单配雌鸟；那里的雄鸟占有两块相隔很远的领域，研究者认为雌鸟可能是**被欺骗**而与一只已配雄鸟定居的，因为她们无法察觉他已经婚配。一雄多雌制阈值模型是一个关于雌性选择的假说，它的假设——自由选择、信息完备——必须逐一核查。

### 求偶场

在求偶场上，雄鸟防卫不含任何资源的微小展示领域，雌性前来访问、选择、交配，然后独自把后代养大。求偶场见于鸟类（艾草松鸡、黑琴鸡、流苏鹬、娇鹟、极乐鸟）、哺乳动物（一些羚羊，如乌干达赤羚，以及某些种群的黇鹿）、蛙类与昆虫。交配通常极度偏斜：少数雄鸟——常是位于求偶场中部附近的——获得多数交配。雄鸟为何聚集，至今仍有争论。按**热点**假说，雄性聚集在雌性最常被遇到的地方；按**热靶**假说，较不吸引人的雄性定居在有魅力的雄性旁边以截取路过的雌性；按**雌性偏好**假说，雌性愿意在聚集的雄性之间挑选，因为这降低她们搜寻的成本与被捕食的风险。证据因物种而异，几个过程可能共同起作用。

**求偶场悖论**是理论的一个难题：若雌性始终选择同样少数几只雄鸟，被偏爱性状中的加性遗传变异应当被耗尽，选择便不再带来遗传收益——然而雌性仍在继续选择。提出的解决方案包括状态依赖性（许多基因影响状况，雄鸟的装饰性状反映它们全部，于是变异被突变不断刷新；Locke Rowe 与 David Houle, 1996），以及寄生虫驱动的"哪个基因型最好"的波动。

## 一雌多雄制与多次交配

就社会性体制而言，一雌多雄制——一只雌鸟拥有数只雄鸟配偶、每只照料一窝——是罕见的。它见于水雉、瓣蹼鹬与一些滨鹬：雌鸟把一窝窝卵产给一只接一只的雄鸟，由它们独自孵化，而作用在雌性身上的性选择相应强烈（[[evolution/sexual-selection]]）。但从遗传学上说，**雌性的多次交配**极为常见。既然一次交配通常已提供足够的精子，雌鸟为什么要与多个雄鸟交配？

已有人提出并检验过几类收益。

- **直接收益**：婚配礼、进入雄鸟领域内资源的途径、来自数只雄鸟的抚育帮助（如林岩鹨），或确保足够的精子。
- **遗传收益**："向上换配"，得到优于社会性配偶的雄鸟；增加后代的遗传多样性；让数只雄鸟的精子竞争、并让雌性在生殖道内对精子进行**隐秘雌性选择**，从而回避遗传不相容的代价，包括近交。
- **避免抵抗的代价**：当雄鸟骚扰雌鸟时，交配可能比抵抗更便宜（"便利型一雌多雄制"）。

在若干物种中已有支持遗传收益的实验证据。Tom Tregenza 与 Nina Wedell (2002) 发现，与数只雄鸟交配的双斑蟋 (*Gryllus bimaculatus*) 雌虫，其孵化率高于被同等次数地与同一只雄虫交配的雌虫；Jeanne Zeh 与 David Zeh 则论证，一雌多雄制是针对遗传不相容的保险。代价包括时间、能量、被捕食与疾病传播的风险，以及交配中雄鸟造成的伤害（[[evolution/sexual-selection]]，论性冲突）。

### 精子竞争

当雌性多次交配时，雄鸟之间的竞争在交配之后继续（[[evolution/sexual-selection]]）。每份精液雄鸟应当投入多少？Geoff Parker 的模型把受精当作一场**抽签**：每条精子是一张奖券，一只雄鸟获得受精的份额与他贡献的精子数成正比。

::: proposition 精子竞争抽签中的精液投入 {#prop-raffle}
设 $n$ 只雄鸟各与一只雌鸟交配，争夺总价值为 $V$ 的卵的受精权；一只在精子上投入 $s$ 的雄鸟，面对总共投入 $S$ 的对手，能获得 $s/(s + S)$ 的受精份额，并付出成本 $cs$（以失去的未来交配计）。在对称的进化稳定策略（ESS）上，每只雄鸟投入

$$
s^* = \frac{V}{c}\cdot\frac{n - 1}{n^2}.
$$ {#eq-raffle}

没有竞争时（$n = 1$；现实中存在受精所需的最低量）投入为零；竞争者为两只时投入最高；$n$ 进一步增大时投入缓慢下降，因为每一份追加的精子买到的份额越来越小。假设：抽签公平（无首发或末位优先，无隐秘选择），雄鸟无法精确评估对手数目，且成本是线性的。
:::

::: proof
焦点雄鸟的收益为 $W(s) = V\,s/(s + S) - cs$。于是 $W'(s) = V S/(s + S)^2 - c$。在对称进化稳定策略上所有雄鸟都投入 $s^*$，故 $S = (n - 1)s^*$，而焦点雄鸟的最优反应必须是 $s = s^*$：$V(n - 1)s^*/(ns^*)^2 = c$，即得[[#eq-raffle]]。$W''(s) = -2VS/(s + S)^3 < 0$，所以这是极大值。
:::

该模型区分了精子竞争的**风险**（该雌鸟与另一只雄鸟交配的概率）与**强度**（竞争精液的份数）：风险提高最优投入，而强度超过两只后降低投入。比较检验在很大程度上支持第一个预言：在灵长类、鸟类、蛙类、鱼类与蝴蝶中，雌性更常与数只雄鸟交配的物种，其睾丸相对体型的比例更大 (Paul Harvey 与 Alexander Harcourt；Tim Birkhead 与 Anders Møller)。在粪蝇 *Scathophaga stercoraria* 中，Parker 发现最后交配的雄鸟使随后产下的卵大多数受精；雄蝇在交配后守卫雌蝇，这降低了被后来者取代的机会。

::: example 测量末位雄鸟优先 {#ex-p2}
Parker 用**不育雄技术**估计精子优先权：先让雌蝇与一只正常雄蝇交配，再与一只经照射不育的雄蝇交配，后者使受精的卵不能发育。这样交配过的雌蝇产下的卵中，18 %孵化；而与两只正常雄蝇交配的雌蝇产下的卵，90 %孵化。估计 $P_2$，即第二位雄鸟使卵受精的比例。
::: solution
经照射的第二只雄蝇使卵受精者不孵化；正常的第一只雄蝇使卵受精者以正常的90 %的比率孵化。若比例 $1 - P_2$ 由第一只受精，则孵化率为 $0.90(1 - P_2) = 0.18$，故 $1 - P_2 = 0.2$、$P_2 = 0.8$。第二位雄蝇使约80 %的卵受精。（该技术假设照射精子正常竞争，这可通过颠倒交配顺序加以检验：颠倒后 $P_2$ 用孵化率除以对照孵化率来估计。）
:::
:::

x: 1, 12

## 亲代抚育

亲代抚育——以增加亲代代价来提高后代存活率的任何行为——的变异极为悬殊。在具抚育的鱼类中，多数由雄鱼独自抚育；在鸟类中，约五分之四的物种是双亲抚育 (Andrew Cockburn, 2006)；在哺乳动物中，雌性总是哺乳，只有少数物种的雄性提供帮助，且主要是社会性单配制的物种（按 Dieter Lukas 与 Tim Clutton-Brock 2013年的分析，不足十分之一的哺乳动物物种）。由谁来抚育，由什么决定？

::: definition 亲代投资与抚育 {#def-care}
**亲代抚育**是亲代提高其子代适合度的任何行为。**亲代投资** (Robert Trivers, 1972) 是以其代价来度量的抚育：对某个后代的任何投资，提高了该后代存活的几率，同时以亲代投资于其他后代——现在或将来的——的能力为代价。因此这是一种**机会成本**，它因性别与生态而不同。
:::

各种解释中反复出现三个因素。

1. **机会成本。** 抚育的亲代会放弃其他交配。在一侧性别潜在生殖速率高（通常是雄性）的地方，抚育对它更贵，除非抚育能大幅改善后代存活，否则离开受青睐。
2. **与后代的关联。** 在体外受精的鱼类中，雄鱼常常正在防卫一块雌鱼将产卵于其上的领域，因此他本在场，可以几乎不加代价地护卵；雌鱼产卵后即离开。体内受精时，卵或幼体在雌体体内，雄性可能早已离去。
3. **亲子确定性。** 父权不确定的雄性从抚育中得利较少。这一预言并不像看上去那么直接：如果在一个雄鸟可能留下的所有后代中父权同等不确定，那么抚育当前一窝与任何其他选择同样有价值。在种内，一些鸟类（如林岩鹨）与鱼类会按其父权份额调节抚育，另一些则不然。

这些因素整合进抚育的博弈论模型，其中每个亲本的最优策略取决于另一个的选择 (John Maynard Smith, 1977)。

::: proposition 亲代抚育博弈 {#prop-caregame}
设 $P_0$、$P_1$ 与 $P_2$ 为无亲代抚育、一双亲抚育与双亲抚育时一窝的存活概率（$P_0 < P_1 < P_2$）。离开的雄鸟可通过新的交配获得一份额外的窝，其比例为 $p$。若雌鸟抚育，则雄鸟也应抚育，条件是

$$
P_2 > P_1(1 + p),
$$ {#eq-care}

否则应当离开。以雌鸟自己的机会成本写出的类似条件，决定她的抉择。稳定的结局包括双亲抚育、由任一侧行单亲抚育，以及（当 $P_0$ 不比 $P_1$ 小很多时）双方都离开。
:::

::: example 抚育还是离开？{#ex-care}
在某种鸟中，一窝雏鸟在无亲代时以0.1的概率存活，单亲时为0.5，双亲时为0.8。若雌鸟抚育，当雄鸟离开后获得第二窝的概率为 (a) $p = 0.4$ 与 (b) $p = 0.8$ 时，他应当抚育吗？(c) 哪些生态变化会有利于雄鸟离开？
::: solution
(a) 抚育给出 $P_2 = 0.8$ 窝；离开给出 $P_1(1 + p) = 0.5\times1.4 = 0.7$。雄鸟应当抚育。

(b) 离开给出 $0.5\times1.8 = 0.9 > 0.8$：雄鸟应当离开。

(c) 任何抬高 $p$ 的因素——雌性偏多的操作性比、雌性非同步可交配的漫长繁殖季——或降低第二个亲本的价值（$P_2 - P_1$）的因素，例如丰富食物使单亲足以喂大一窝，或自行觅食的早成雏鸟。这些正是鸟类中一雄多雌制与单亲抚育出现的条件，与 Emlen 与 Oring 的生态理论一致。
:::
:::

::: application 保护与人工繁育中的交配系统
交配系统影响有效大小，因为一雄多雌制与求偶场繁殖把繁殖集中于少数雄体，加强了遗传漂变（[[evolution/mutation-drift-gene-flow]]）。为求偶场繁殖或一雄多雌制的物种制定的人工繁育计划，例如新西兰的鸮鹦鹉 (*Strigops habroptilus*)，通过管理配对使各雄性的贡献比自然状态下更均匀。求偶场的干扰——例如北美西部艾草松鸡求偶场附近的能源开发——会降低到场率与繁殖，保护求偶场场地已成为这类物种保护规划的重点。
:::

### 家庭内部的冲突

抚育制造冲突。亲代与子代的利益并不完全一致，Robert Trivers (1974) 曾指出这一点。亲代与其所有后代的亲缘关系相同（二倍体物种中为 $\tfrac12$），应当以总量最大化为目标分配投资。每个后代与自身的亲缘度为1，而与同父同母的同胞亲缘度只有 $\tfrac12$，因此它更看重自身收益而非同胞的，并会设法得到比亲代愿意给的更多。

::: proposition 亲代冲突 {#prop-poc}
设一份亲代投资给当前后代带来收益 $B$，给亲代未来的后代造成代价 $C$（以后代存活为单位）。从亲代的角度，当 $B > C$ 时投资应当继续。从当前后代的角度，当

$$
B > r\,C,
$$

投资应当继续，其中 $r$ 是它与未来后代的亲缘度（同父同母的同胞为 $r = \tfrac12$，同父异母或同母异父为 $\tfrac14$）。在 $rC < B < C$ 的范围内，后代想要的投资多于亲代愿意给的：这就是**亲代冲突**区。这一论证是 Hamilton 法则的应用（[[behaviour/cooperation]]）。
:::

断奶冲突是经典例子：当母亲开始拒绝哺乳时，幼年哺乳动物常常抗议，而理论预言，当未来的弟妹更可能是同母异父（由另一父亲所生）的半同胞时，断奶冲突应当更激烈。同样的逻辑预言**同胞竞争**。在一些猛禽、鹭类与鲣鸟中，雏鸟非同步孵化，先孵出的会攻击、有时杀死后孵出的（**同胞相残**），在食物短缺时尤甚。Douglas Mock 对牛背鹭 (*Bubulcus ibis*) 与大白鹭的研究表明，当食物以小份、可独占的形式送入时，雏鸟打斗更多。亲代通常不加干预；晚孵出的雏鸟可以充当初孵者失败时的保险。

对抚育最惊人的利用是**巢寄生**。大杜鹃 (*Cuculus canorus*) 把卵产在别的鸟类的巢中，孵化出的雏鸟把宿主的卵推出巢外、独自被养大。宿主进化出弃去与自己卵不符之卵的能力，杜鹃则进化出卵的拟态作为回应，不同宿主特异性的宗 (gentes) 所产的卵分别与其各自的宿主相匹配——一场由 Nick Davies 与 Michael Brooke 自1980年代起研究的协同进化军备竞赛（[[evolution/coevolution]]）。

::: quiz
在一种哺乳动物中，母亲前后两窝通常有不同的父亲。与前后两窝通常有同一父亲的物种相比，你预期其断奶冲突的强度如何？
- [x] 更强，因为后代与未来同胞的亲缘度更低
- [ ] 更弱，因为母亲对每窝的投资更少
- [ ] 相同，因为母亲与自己的所有后代亲缘度相同
- [ ] 更强，因为父亲帮助更多
::: solution
父亲不同时，前后窝后代是半同胞（$r = \tfrac14$ 而不是 $\tfrac12$）。后代要求追加投资的门槛降到 $B > C/4$，冲突区随之加宽（$C/4 < B < C$ 而不是 $C/2 < B < C$）。母亲的最优值不变，因为她与自己所有后代的亲缘度都是 $\tfrac12$，无论其父亲是谁。
:::
:::

::: history
Darwin 在 *The Descent of Man*（1871）中讨论过多配偶制。David Lack 的 *Ecological Adaptations for Breeding in Birds*（1968）对交配系统与亲代抚育做了综述。Verner 与 Willson (1966) 以及 Orians (1969) 提出一雄多雌制阈值模型；Trivers 提出了亲代投资（1972）与亲代冲突（1974）；Emlen 与 Oring 的生态学分型发表于1977年，Maynard Smith 对亲代抚育的博弈论分析也在同年。Parker 关于粪蝇与精子竞争的工作始于1970年。Alec Jeffreys 于1985年建立的 DNA 指纹分析，自1980年代末起因揭示配对外父权而彻底改变了这个领域；Davies 的林岩鹨研究（*Dunnock Behaviour and Social Evolution*，1992）展示了交配系统如何从利益冲突中产生。Clutton-Brock 的 *The Evolution of Parental Care*（1991）把抚育理论集成了体系。
:::

::: summary
- 交配系统（一夫一妻制、一雄多雌制、一雌多雄制、多雄多雌制、混交制）描述社会性安排；亲缘分析揭示遗传性交配系统，配对外父权常聚集于部分巢中。
- Emlen 与 Oring：资源与可交配雌性在时空上的分布设定多配偶制的潜力；对双亲抚育的需要可以使物种保持一夫一妻。
- 一雄多雌制阈值模型：若已配雄鸟领域的优势超过分享的代价，雌鸟就应接受已配雄鸟，$W_m(q_1) - D > W_m(q_2)$；检验既有支持，也发现欺骗。
- 求偶场是无资源的展示雄鸟的聚合，交配高度偏斜；求偶场悖论关乎为遗传收益而进行的择偶如何得以维持。
- 雌性常见多次交配，为直接收益、遗传收益（向上换配、多样性、相容性）或为避免骚扰。
- 在精子竞争抽签中，精液投入在两个竞争者时达峰（$s^* \propto (n - 1)/n^2$）；竞争风险提高投入；末位优先权用不育雄虫测量。
- 谁抚育取决于机会成本、与后代的关联和亲子确定性；在抚育博弈中，雄鸟抚育的条件是 $P_2 > P_1(1 + p)$。
- 亲代冲突在 $rC < B < C$ 时出现；同胞竞争与同胞相残、以及巢寄生，是关于抚育的进一步冲突。
:::

## 练习

::: exercise 交配系统的分类 {level=1}
判断下列各例：(a) 一只雄性象海豹在沙滩上守卫40只雌性的群体，并使其中大多数产下幼崽；(b) 一只雌性红瓣蹼鹬把一窝卵产给一只雄鸟、由他孵化，然后再把第二窝产给另一只；(c) 在一个橡啄木鸟群体中，数只雄性与数只雌性共同繁殖并共享亲权；(d) 一对天鹅连续多年共同繁殖。
::: solution
(a) 雌性防御型（后宫制）一雄多雌制。(b) 序列性一雌多雄制，伴性角色反转。(c) 多雄多雌制。(d) 社会性一夫一妻制，长期；遗传性一夫一妻需亲缘分析确认。
:::

若11 %的雏鸟是配对外的、每巢有四只雏鸟，那么当配对外父权在各雏鸟之间相互独立时，多大比例的巢至少含一只配对外雏鸟（保留三位小数）？
::: solution
$1 - 0.89^4 = 1 - 0.627 = 0.373$。

在抽签模型[[#eq-raffle]]中，三只雄鸟竞争时 $s^*c/V$ 是多少？
::: solution
$(3 - 1)/3^2 = 2/9 \approx 0.222$。

::: exercise 末位雄鸟优先 {level=2 check="0.75"}
先与正常雄虫交配、再与经照射雄虫交配的雌虫，其后孵化率为20 %；只与正常雄虫交配的雌虫孵化率为80 %。估计 $P_2$。
::: solution
$0.80(1 - P_2) = 0.20$，故 $1 - P_2 = 0.25$、$P_2 = 0.75$。
:::

::: exercise 一雄多雌制阈值 {level=2 check="2"}
一只雌鸟在质量为 $q$ 的领域上的成功为 $W_m = 0.4q$，作为次配雌鸟的代价为 $D = 0.8$ 只离巢雏鸟。已配雄鸟的领域质量须超出未配雄鸟多少单位，该雌鸟才会偏好已配雄鸟？
::: solution
她偏好他的条件是 $0.4q_1 - 0.8 > 0.4q_2$，即 $q_1 - q_2 > 0.8/0.4 = 2$ 个单位。
:::

::: exercise 雄鱼抚育的抉择 {level=2}
在一种鱼中，卵在无抚育时的存活概率为0.2，单亲抚育时为0.6；第二个亲代不再增益（0.6）。雄鱼可以在护巢的同时吸引另一只雌鱼，而雌鱼若离开，有0.5的概率再次产卵。哪个性别应当抚育？解释为什么在体外受精的鱼类中仅由雄性抚育如此普遍。
::: solution
由于第二个亲代没有增益（$P_2 = P_1 = 0.6$），至多只有一个亲代应当抚育。护巢并不妨碍雄鸟吸引进一步前来产卵的雌鱼，所以抚育几乎不使他损失交配。雌鱼抚育的机会成本是再次产卵的0.5的机会：若她离开而雄鱼抚育，她期望 $0.6\times(1 + 0.5) = 0.9$ 窝，而她自己抚育是 $0.6$。所以雌鱼应当离开、雄鱼应当抚育。体外受精的鱼类中仅由雄性抚育很普遍，是因为守卫巢域的雄鱼可以一边继续求偶、一边同时护守多窝，而抚育会断送雌鱼进一步产卵的机会。
:::
:::

::: exercise 断奶冲突区 {level=2}
用[[#prop-poc]]，求同父同母同胞与同母异父（或同父异母）同胞各自的亲代冲突区（以 $B/C$ 的范围表示）。哪种情形预言的冲突更多，为什么？
::: solution
亲代希望在 $B/C > 1$ 时投资；同父同母的同胞在 $B/C > \tfrac12$ 时；同母异父的同胞在 $B/C > \tfrac14$ 时。冲突区分别是 $\tfrac12 < B/C < 1$ 与 $\tfrac14 < B/C < 1$。半同胞的冲突区更宽：后代对给未来同胞的代价打更大的折扣，因为它与它们共享的基因更少。
:::
:::

::: exercise 解读一项移除实验 {level=3}
在一种社会性一夫一妻的鸟类中，研究者在孵化后从部分巢中移走雄鸟。没有雄鸟的巢平均离巢2.1只雏鸟；对照巢离巢3.4只。在另一个物种中，移除只使离巢数从3.2降到3.0。(a) 这些结果对两种物种中雄鸟抚育的价值告诉你什么？(b) 你预期哪个物种的一雄多雌制更普遍，为什么？(c) 移除实验有什么弱点？
::: solution
(a) 在第一个物种中，雄鸟的抚育显著提高巢的成功（$P_2/P_1 = 3.4/2.1 = 1.62$）；在第二个物种中增益很小（$3.2/3.0 = 1.07$）。(b) 一雄多雌制应在第二个物种中更常见：离开的（或再娶一只雌鸟的）雄鸟在第一窝中损失很小，所以按[[#eq-care]]，即使很小的额外交配机会（$p > 0.07$）也使离开合算。在第一个物种中，只有 $p > 0.62$ 时离开才合算。(c) 移除可能改变雌鸟的行为（她可能部分地以更多喂食来补偿，从而低估完整配偶对中雄鸟的贡献；或她可能承受应激），而被移除雄鸟的领域可能被其他雄鸟入侵；移除的效应并不必然等同于雄鸟自然缺席的效应。
:::
:::

::: exercise 配偶守卫模型 {level=3}
交配后，雄鸟可以守卫雌鸟一段时间（失去用于其他交配的时间）或者离开。若他离开，她在产卵前再配的概率为 $m$，那样他只使她的卵中的 $1 - P_2$ 受精。守卫可防止再配，但意味着他放弃一份新交配的 $g$。证明守卫在 $m P_2 > g$ 时合算，并据此预言守卫何时应更常见。
::: solution
离开：他使当前雌鸟卵的比例 $1 - mP_2$ 受精（以概率 $m$ 她再配而他失去 $P_2$），加上一只新雌鸟的卵的 $g$，以一窝为单位：$1 - mP_2 + g$。守卫：他使当前雌鸟的卵全部受精、别无所得：$1$。守卫合算当 $1 > 1 - mP_2 + g$，即 $mP_2 > g$。守卫应在以下情形受青睐：雌鸟很可能再配的地方（$m$ 高，如雄鸟充裕或操作性比偏雄时），末位优先强烈（$P_2$ 高，如粪蝇）的地方，以及新配偶难寻（$g$ 低，如繁殖季晚期）的地方。Parker 研究的粪蝇 $P_2$ 高、每堆牛粪上搜寻的雄蝇众多，因此如预言所示在交配后守卫雌蝇。
:::
