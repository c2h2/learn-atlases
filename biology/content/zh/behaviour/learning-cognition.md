帝王斑蝶 (*Danaus plexippus*) 的幼虫取食某些马利筋，会把能令脊椎动物呕吐的强心苷类毒素贮存在体内。1960年代，Lincoln Brower 与合作者把这类帝王斑蝶投喂给从未见过它们的圈养冠蓝鸦 (*Cyanocitta cristata*)。一只蓝鸦会一口夺过蝴蝶吃下，数分钟后剧烈呕吐。此后它一见到帝王斑蝶就拒而避之，往往仅需一次经历——而且它还会拒绝副王蛱蝶等外形与帝王斑蝶相似的蝴蝶。一顿难吃的饭，就长久地改变了这只蓝鸦的行为，而且改得目标精准：它回避的是橙黑相间的蝴蝶，而不是笼子、实验人员或一天中的某个时刻。

本章讨论经验如何改变行为。我们从最简单的学习形式——习惯化与敏感化——以及印记开始，继而处理联想学习的两大形式，经典条件作用与操作性条件作用，并以 Rescorla–Wagner 模型和匹配律作为其定量的核心。蓝鸦的选择性厌恶引出学习的生物学约束的思想，以及学习能力是对特定生态问题的适应的思想，正如贮食鸟类那样。我们随后转向社会学习与动物传统，转向认知的研究——工具使用、记忆、自我识别——以及选择究竟何时应当偏爱学习这一问题。神经元的可塑性机制见 [[neuroscience/plasticity-learning]]；发育背景见 [[behaviour/mechanisms-of-behaviour]]。

## 学习是什么

::: definition 学习 {#def-learning}
**学习**是由特定经验导致的、行为（或行为潜能）的相对持久的改变，不包括成熟、损伤、疲劳或感觉适应引起的改变。**非联想**学习因重复暴露而改变对单一类型刺激的反应：**习惯化**是对并无重大后果的重复刺激的反应下降；**敏感化**是在强烈或有害刺激之后反应的增强。**联想**学习把事件联系起来：在**经典（巴甫洛夫）条件作用**中，一个原先中性的刺激变得能预示生物学上有意义的刺激；在**操作性（工具性）条件作用**中，一种行为依其后果而变得更频繁或更不频繁。
:::

习惯化是分布最广的学习形式，见于每一种受试过的动物，其适应意义显而易见：一只见草动就逃的动物将永远无法取食。它靠两项检验与疲劳或感觉适应相区分。这种反应的下降是**刺激特异**的（对不断有人走过已经习惯化的草原犬鼠，仍会响应一条狗），而且表现出**去习惯化**：一个新异的或强烈的刺激能恢复对原刺激的反应，而如果感受器或肌肉只是耗竭了，就不会出现这一点。在海兔 *Aplysia californica* 中，Eric Kandel 与合作者把鳃缩回反射的习惯化与敏感化追溯到感觉神经元与运动神经元之间已鉴定突触上递质释放的改变——Kandel 因这项工作与人分享2000年诺贝尔生理学或医学奖。

::: application 保护与旅游中的习惯化
保护区内的动物会对车辆、船只与游客发生习惯化，这使观察成为可能，但也会使它们更容易遭受盗猎者的伤害或发生碰撞，并可能掩盖慢性应激。反过来说，用反复出现的噪音把动物从农田、机场或风力发电机旁吓走的尝试，通常在几天后就失效，因为动物会习惯化；当威慑手段多变、不可预测，或与真实后果配对时（把一个中性刺激变成一个条件刺激），它能维持更久。
:::

### 印记

Konrad Lorenz 的小鹅把他当作母亲一样追随，使印记闻名于世。在**亲子印记**中，属于早成性幼鸟物种（雁、鸭、鸡）的幼鸟学会它孵化后不久遇到的一个物体的特征，此后便追随它并设法留在其近旁。在**性印记**中，生命早期的经验影响动物日后偏爱作为配偶的个体类型。

Lorenz 描述印记（1935）为发生在一个界限分明的**关键期**内、且不可逆。后来的工作弱化了这两个论断。绿头鸭 (*Anas platyrhynchos*) 雏鸟亲子印记的**敏感期**在孵化后头一天左右达到高峰，但它的结束部分由印记过程本身决定：一旦雏鸟形成了依恋，它就开始回避新异物体，从而限制了进一步的印记。与群养雏鸟相比，隔离饲养的雏鸟可以晚些发生印记。Klaus Immelmann (1972) 把斑胸草雀 (*Taeniopygia guttata*) 雄鸟交给白腰文鸟义亲抚养；成年后，它们即使在与同种个体相处过一段时间之后，仍然更偏向于向白腰文鸟雌鸟求偶——性印记可以非常稳定。

印记是一种带有强烈先天倾向的学习：雏鸟已准备好在一生中的某一个时刻去学习某一类事物的信息，而一位天然的母亲是远比一只箱子或一位生物学家更有效的刺激。Patrick Bateson 提出，性印记使动物能够选择与其父母和同胞相似但并不相同的配偶——一种最优远交，既避免近交，也避免与过于不同的个体交配。在可以挑选时，日本鹌鹑对表亲的偏好胜过同胞或无亲缘关系的个体 (Bateson, 1982)。

## 经典条件作用

Ivan Pavlov 在二十世纪初研究狗的唾液分泌时发现，狗会对规律地先于食物出现的刺激开始分泌唾液。按他的术语，一个**非条件刺激**（US，食物）引发一个**非条件反应**（UR，唾液分泌）；经过若干次配对后，一个原先中性的**条件刺激**（CS，一种声音）开始引发**条件反应**（CR）。若随后反复呈现 CS 而不给 US，CR 便下降——**消退**——但消退并不是遗忘：休息之后反应可以恢复（自发恢复），或在一个新的情境中恢复。

条件作用并非只是配对。Leon Kamin (1969) 训练大鼠：先让一个声音（CS A）伴随轻微电击，直到声音抑制了它们的压杆。然后，他把声音与一个灯光（CS X）一起呈现，随后是同一电击。单独测试时，灯光几乎不产生条件反应，尽管它此前已与电击配对了多次。只经历过复合试验的对照大鼠则对灯光反应强烈。对声音的先前学习**阻断**了对灯光的学习。看来，动物只在 US *出人意料*时才学习——当它尚未被预测到时。

Robert Rescorla 与 Allan Wagner (1972) 把这一洞见变成了一个模型。

::: proposition Rescorla–Wagner 模型 {#prop-rw}
设 $V_i$ 为条件刺激 $i$ 的联想强度，$\lambda$ 为 US 所能支撑的最大联想强度（若 US 缺席则 $\lambda = 0$）。在每次试验上，每个在场 CS 的强度改变为

$$
\Delta V_i = \alpha_i\beta\,\Bigl(\lambda - \sum_{j\ \text{present}} V_j\Bigr),
$$ {#eq-rw}

其中 $\alpha_i$ 与 $\beta$（介于0与1之间）是 CS 与 US 的学习率参数。方括号中的项是**预测误差**：实际发生之事与全部在场刺激所预测之事之差。对于从 $V_0 = 0$ 起、恒定 $\alpha\beta = c$ 的单一 CS，$n$ 次试验后的强度为

$$
V_n = \lambda\bigl(1 - (1 - c)^n\bigr).
$$ {#eq-rw-curve}
:::

::: proof
对于单一 CS，[[#eq-rw]]给出 $V_{n+1} = V_n + c(\lambda - V_n)$，于是 $\lambda - V_{n+1} = (1 - c)(\lambda - V_n)$。与渐近值的距离每试验缩小为 $1-c$ 倍；从 $\lambda - V_0 = \lambda$ 出发，$n$ 次试验后它为 $\lambda(1-c)^n$，即得[[#eq-rw-curve]]。在消退期间，$\lambda = 0$，同样的论证给出 $V_n = V_0(1 - c)^n$。
:::

该模型是一条从预测误差中学习的规则——与机器学习中的 "delta rule" 以及哺乳动物脑中多巴胺神经元所报告的时序差分学习是同一原理（Wolfram Schultz 与合作者，1997）。它直接解释了阻断：一旦 $V_A \approx \lambda$，复合试验上的预测误差近乎为零，于是 X 几乎一无所得。

::: example 习得与阻断 {#ex-rw}
设 $\lambda = 1$，且每个 CS 的 $c = \alpha\beta = 0.3$。(a) 单一 CS 与 US 配对三次后 $V$ 是多少？$V$ 要超过0.9需要配对多少次？(b) 在一个阻断设计中，CS A 先被训练到 $V_A = 0.95$；然后 A 与 X 一起与 US 呈现。第一次复合试验上 X 获得多少？其最终强度是多少？与从一开始就只接受复合试验的对照组比较。
::: solution
(a) 由[[#eq-rw-curve]]，$V_3 = 1 - 0.7^3 = 1 - 0.343 = 0.657$。需要 $0.7^n < 0.1$，即 $n > \ln 0.1/\ln 0.7 = 6.46$，故配对7次。

(b) 第一次复合试验上预测误差为 $1 - (0.95 + 0) = 0.05$，故 $\Delta V_X = 0.3\times0.05 = 0.015$。此后每次试验 A 与 X 获得同样多，学习在 $V_A + V_X = 1$ 时停止；X 最终得到剩余0.05的一半，即 $V_X = 0.025$。对照组两者从零起步、获得同样多，最终停在 $V_A = V_X = 0.5$。灯光被阻断了：它的最终强度只有对照组的二十分之一。
:::
:::

::: widget plot
f: 1 - (1 - c)^x; v*(1 - c)^x
x: 0, 20
y: 0, 1.05
sliders: c=0.3:0.05:0.9:0.05; v=1:0:1:0.05
labels: \text{习得 } V_n; \text{消退，起点 } V_0 = v
caption: Rescorla–Wagner 学习曲线[[#eq-rw-curve]]，横轴为试验序号。上升的曲线是 $\lambda = 1$ 时的习得；下降的曲线是 $\lambda = 0$ 时从初始强度 $v$ 出发的消退。增大 $c = \alpha\beta$（显著的 CS、强烈的 US）可见学习在几次试验内饱和——正如蓝鸦的一次性厌恶；减小它则可见缓慢、渐进的学习。每条曲线都是负加速的：最大的变化出现在第一次试验，此时意外程度最大。
:::

Rescorla–Wagner 模型并非故事的全部——例如，它并不预测事先在无后果的情况下暴露于 CS 会减慢后来对其建立的条件作用（**潜在抑制**），而且它把消退当作学习的抹除，这与自发恢复相矛盾——但它仍是联想学习模型的参照点。

## 操作性条件作用

Edward Thorndike (1898) 把饥饿的猫放进问题箱，猫可以通过拉环或压杆逃出并获得食物。它们逃出的时间随试验逐渐减少，Thorndike 将此概括为**效果律**：跟随在令人满意的后果之后的行为变得更可能出现。B. F. Skinner 后来研究了大鼠和鸽子压杆或啄键的操作性行为，奖赏（强化物）按**程序**发放：在固定或可变次数的反应之后（比率程序），或在固定或可变的时间之后（间隔程序）。可变程序产生稳定、且对消退有极强抵抗性的反应，因为奖赏的缺席不再那么出人意料。

当动物可以在两个备选之间选择、而每个备选各按自己的变间隔程序获得奖赏时，会出现一种醒目的规律性。

::: proposition 匹配律 {#prop-matching}
Richard Herrnstein (1961) 发现，在两个键之间选择的鸽子这样分配它们的啄击：对每个键的反应比例与从该键获得的奖赏比例相匹配：

$$
\frac{B_1}{B_1 + B_2} = \frac{R_1}{R_1 + R_2},
$$ {#eq-matching}

其中 $B_i$ 是备选 $i$ 上的反应率，$R_i$ 是该备选上的奖赏率。这是一条经验规律，而非推导结果。真实数据常出现系统性偏离（**低匹配**，即偏好不如预测的那么极端，十分常见），泛化形式 $B_1/B_2 = b\,(R_1/R_2)^s$ 用偏置 $b$ 与敏感系数 $s$ 来描述它。
:::

::: example 两个程序上的匹配 {#ex-matching}
一只鸽子每小时啄约1500次。一个键平均每小时给食40次，另一个键每小时20次，各按变间隔程序（食物在随机时刻变得可用，并等待下一次啄击）。按匹配律，鸽子应如何分配它的啄击？为什么在这类程序上匹配接近最优？
::: solution
匹配预测把 $40/(40 + 20) = 2/3$ 的啄击给富键，即每小时约1000次给它、500次给另一个键。在变间隔程序上，当鸟在啄富键时，贫键上的食物正在积累，所以偶尔访问贫键有很高概率得到奖赏；把全部时间花在富键上会错过这些奖赏。在很宽的分配范围内，获得的总食物量几乎不变，而匹配接近最大值。并行程序上的匹配，是"学习规则可以逼近最优取食"这一思想的出发点之一 ([[behaviour/foraging]])。
:::
:::

## 生物学约束与适应性特化

早期的学习理论假定，任何可检测的刺激都能同样好地与任何后果相联系，任何反应都能同样好地被任何奖赏强化。蓝鸦与帝王斑蝶暗示事实并非如此，而一项1966年发表的实验使这一论点一锤定音。

John Garcia 与 Robert Koelling 给口渴的大鼠喝既加了调味、又伴随闪光和咔哒声的水（"明亮、吵闹、美味的水"）。对其中一些大鼠，饮水之后是疾病（由 X 照射或毒素引起）；对另一些，则是足部电击。在后来的测试中，被致病的大鼠回避的是*味道*，而不回避光和声；被电击的大鼠回避的是*光和声*，而不回避味道。味觉易于与疾病相联系，声光线索易于与疼痛相联系，反过来则不行。味觉厌恶还能在食物与疾病间隔数小时的情况下形成，而经典条件作用理论曾认为这是不可能的。

::: warning "学习是通用的"
认为动物平等地擅长学习任何东西——因此大鼠在压杆箱里的学习能告诉我们一般意义上的学习——这一思想在1960年代与1970年代被放弃了。学习受动物所**就绪**（prepared）去建立哪些联想的约束，而这些先天倾向适合它的生态。大鼠取食多种食物且不能呕吐，因此极易学会味觉厌恶；鹌鹑靠视觉挑选食物，因此极易学会对有色水的厌恶。以商业方式训练动物的 Keller 与 Marian Breland 在1961年描述了受训把硬币投进箱子的浣熊如何转而去"清洗"硬币，而猪开始拱硬币——本能的取食处理行为侵入了训练出的反应（"The misbehavior of organisms"）。学习在一种进化的架构之内运作。
:::

### 贮食鸟类的空间记忆

如果学习能力是适应，那么面临更难学习问题的物种就应该更擅长学习。贮食鸟类提供了最清楚的检验。一只克拉克星鸦 (*Nucifraga columbiana*) 在一个秋天可能把数以万计的松子藏进数千个分散的贮食点，并在数月之后、积雪之下，利用地标找回其中的许多只。沼泽山雀与黑顶山雀把种子贮存数天到数周。在空间记忆的实验室测试中，星鸦胜过贮食较少的近缘鸦类 （Alan Kamil、Russell Balda 与合作者）。而 John Krebs、David Sherry 与合作者 (1989) 发现，在雀形目各科之间，贮食物种的海马——一个参与空间记忆的脑区——相对于脑与身体体积的比例高于不贮食物种，这是一项带有系统发育对照的比较 ([[behaviour/studying-behaviour#def-nonindep]])。

## 社会学习与动物传统

动物也彼此学习，这能使新行为在种群中的扩散远比基因改变更快。

::: definition 社会学习的机制 {#def-social}
**社会学习**是受另一只动物或其产物的观察或互动影响的学习。其主要机制按认知要求由低到高大致排列为：
- **局部增强**——其他个体的存在把动物引向一个地点，它在那里自行学习；
- **刺激增强**——其他个体把它的注意引向一个物体；
- **观察性条件作用**——它从其他个体的反应中学到一个联想（例如，某种捕食者是危险的）；
- **模拟**——它学会一个行动所能达到的结果，并以自己的手段复现该结果；
- **模仿**——它复制行动本身的形式。

**教学**发生在这样一个个体身上：它在幼稚个体面前改变自己的行为，自身付出某种代价，且以帮助幼稚个体学习的方式行事 （Tim Caro 与 Marc Hauser 的1992年定义）。
:::

一个著名的行为扩散事例是英国蓝山雀 (*Cyanistes caeruleus*) 打开奶瓶盖的行为：1921年在南安普敦首次报道，1949年由 James Fisher 与 Robert Hinde 记录了它在全国的扩散。其扩散格局——相距遥远的地方出现新的爆发点，随后是局部扩散——提示独立发明与社会传播，而传播可能经由局部增强或刺激增强，而不是模仿。

关于野外社会学习的决定性实验来得晚得多。Lucy Aplin、Ben Sheldon 与合作者 (2015) 训练怀亚姆林 (Wytham Woods) 数个亚群中的少数大山雀，让它们以向左或向右滑门的方式打开一个谜箱。被训练的技术沿各个亚群的社会网络扩散，而且鸟儿会顺从当地通行的技术，即使两种技术同样好用；在原来的许多鸟已经死亡之后，当地传统仍延续到第二年。在哺乳动物中，Alex Thornton 与 Katherine McAuliffe (2006) 表明，狐獴 (*Suricata suricatta*) 的助手会教幼崽处理蝎子：它们把死了或瘫软的蝎子给年幼的幼崽，把完好无损的蝎子给较大的幼崽，而被实验性地给予瘫软蝎子的幼崽改进处理技巧的速度更快。

社会学习与个体学习在新行为扩散时留下不同的痕迹。

::: proposition 扩散曲线 {#prop-diffusion}
在一个由 $T$ 个个体组成的群体中，设 $N(t)$ 为已获得该行为的个体数。若每个幼稚个体以恒定速率 $a$ 独立地学会它（社会性的学习，asocial），

$$
N(t) = T\bigl(1 - e^{-at}\bigr),
$$

它起初上升最快。若幼稚个体只向已学会者学习，速率与已知者所占比例成正比，$\dfrac{dN}{dt} = s\,N\,\dfrac{T - N}{T}$，得到 logistic

$$
N(t) = \frac{T}{1 + \bigl(T/N_0 - 1\bigr)e^{-st}},
$$ {#eq-logistic-diffusion}

一条起步缓慢的 S 形曲线。假设：充分混配的群体、恒定的速率、不遗忘。真实的扩散把两者混合起来，而现代的**基于网络的扩散分析**检验获得是否沿社会网络的连接分布，这比凭曲线形状来判断更可靠。
:::

::: example 达到半数群体的时间 {#ex-diffusion}
在一个100只的群体中，一只动物发明了一种行为。(a) 若它以每天 $s = 0.5$ 的速率仅作社会性扩散，何时已有50只获得？(b) 若相反，每只动物以每天 $a = 0.07$ 的速率自行学习，何时已有50只获得？
::: solution
(a) 由[[#eq-logistic-diffusion]]，取 $N_0 = 1$，当 $99e^{-0.5t} = 1$ 时 $N = 50$，故 $t = \ln 99/0.5 = 9.19$ 天。(b) $1 - e^{-0.07t} = 0.5$ 给出 $t = \ln 2/0.07 = 9.90$ 天。两种机制几乎同时到达中点，所以仅此一点无法把它们分开；曲线的形状可以，更好的办法是看获得是否跟随社会联系。
:::
:::

有些动物种群在许多行为上彼此不同，这些差异无法用基因或生态来解释。Andrew Whiten 与合作者 (1999) 汇总了七个长期黑猩猩 (*Pan troglodytes*) 研究地点的观察，识别出39种行为模式——用石头砸开坚果、钓白蚁、咬叶展示——它们在有些地点已成惯例，而在生态上容得下它们的另一些地点却不存在。这样的**传统**是动物文化主张的基础。它们是否涉及那种让人类文化得以逐代积累改进的高保真模仿，尚有争论；多数证据表明，累积性文化在其他动物中稀少或微弱。

## 动物认知

**认知**指动物获取、加工、储存信息并据以行动的机制——知觉、学习、记忆与决策。动物认知的研究追问动物能够表征与计算什么，以及它是如何进化的。这个领域有一条比它的任何具体发现都更古老的方法论规则。

::: definition Morgan 的准则 {#def-morgan}
"在任何情况下，如果一个行为可以解释为心理序列中较低位置的官能的行使结果，我们就不得把它解释为较高位置的官能的行使结果" (C. Lloyd Morgan, *An Introduction to Comparative Psychology*, 1894)。用现代的话说：优先采用能说明数据的、最简单的机制，并设计能把简单解释与复杂解释区分开来的实验。
:::

三条研究线索说明了这种方法。

**工具使用与问题解决。** 新喀鸦 (*Corvus moneduloides*) 用小枝和树叶制造并使用工具，从缝隙中探取昆虫 (Gavin Hunt, 1996)。在 Alex Weir、Jackie Chappell 与 Alex Kacelnik (2002) 的一项实验室研究中，一只名叫 Betty 的雌鸦面对一根直铁丝和放在管中的一桶食物，把铁丝弯成钩状，用它提起小桶。这一结果很有名，但对它的解释是谨慎的：后来的观察表明，这类乌鸦在野外就会弯曲和塑形植物材料，因此这一行为可能借助的是已有的行为库，而不是凭空产生的洞察。

**情景-*样*记忆。** 人类记得具体的过去事件——什么事、在哪里、何时。Nicola Clayton 与 Anthony Dickinson (1998) 让西丛鸦 (*Aphelocoma californica*) 贮藏蜡螟幼虫——它们更偏爱这种食物，但它会变质——以及花生，后者可以存放。在允许4小时后找回贮藏品时，丛鸦先到贮藏过幼虫的地点寻找；过了124小时——在训练中幼虫此时已不可食用——它们转而寻找花生。丛鸦的行为需要关于贮藏了什么、在哪里贮藏、以及距现在多久之前的信息。由于我们无从知道一只丛鸦是否在意识中"重新经历"过去，作者称之为情景-*样* (episodic-like) 记忆，这是对 Morgan 准则的一次审慎运用。

**自我识别。** Gordon Gallup (1970) 让黑猩猩先熟悉镜子，然后在麻醉状态下用只有镜中才能看见的无臭染料在其眉部做标记。醒来后，它们一面照镜子一面去触摸那个标记；猴子则不会。此后，镜像自我识别已见于类人猿、可能还有大象、海豚与喜鹊，以及一种鱼——裂唇鱼 (*Labroides dimidiatus*；Masanori Kohda 与合作者，2019)——但后者有争议。这一鱼类结果令研究者分为两派：要么标志测试的要求比人们以为的低，要么它所揭示的能力比想象的更普遍。无论哪种情形，这项测试究竟测量什么，仍是一个有争论的问题。

::: warning 拟人化及其反面
根据表面相似性把人的思想归诸动物（拟人化）曾误导过许多观察者——"聪明的汉斯"会"数数" ([[behaviour/studying-behaviour]])。但是，当证据支持动物可能与我们共享认知能力时却拒绝考虑这一点，同样是错误的 (Frans de Waal 称之为 "anthropodenial")。一个相关的错误是把各物种排列在一条以人类为顶端的单一智慧阶梯上。认知能力是特化的：星鸦的空间记忆在其领域内胜过人类，而蜜蜂用我们所没有的偏振光罗盘导航。有产出的问题不是"这个物种有多聪明？"而是"这只动物利用什么信息、如何利用，来解决它的生态所提出的难题？"
:::

::: quiz
一只狗看到食物藏在两只杯子中的一只下面。随后当一个人指向那只正确的杯子时，狗选择它的次数高于偶然。以下哪项一旦发现，将对"狗理解此人有意告知它"的主张构成最严重的削弱？
- [ ] 与人接触很少的幼犬也会跟随指点
- [x] 当此人背对狗、并未注意狗而指向杯子时，狗选择正确杯子的次数同样高
- [ ] 由人抚养长大的狼也会在一定程度上跟随指点
- [ ] 狗在第一次试验上选择正确杯子就高于偶然水平
::: solution
如果狗不论此人是否注意都跟随手臂，那么更简单的机制——活动的手臂引起的刺激增强，或手臂与食物之间习得的联想——就能解释这一结果，而无须归诸对意图的理解。其他结果涉及这种能力如何发育（幼犬、人工养育的狼），或排除了测试内逐试验的学习，但都不能区分简单解释与复杂解释。这正是 Morgan 准则的运用。
:::
:::

## 学习何时应当进化？

学习是有代价的：它需要神经组织，需要时间，而且动物在学习过程中会犯错。一个由基因规定的固定反应更廉价、而且立即正确——如果世界可以预测的话。David Stephens (1991) 分析了学习何时合算，答案取决于两种可预测性。如果环境在各代之间相同，编码在基因组里的固定反应就是最好的。如果环境在一个生命周期内变化得太快、以致过去的经验毫无用处，学习也毫无用处。学习在一个中间状态最受青睐：最佳行为在各代之间变化（所以基因无法追踪它），但在一个生命周期内又足够稳定，使经验能够预测未来。

一只会学习的动物面临一个统计问题：如何从有限的经验中估计世界的状态。贝叶斯更新是规范解，而许多学习规则对它加以逼近。

::: example 学习一个斑块的质量 {#ex-bayes}
一只鸟对在一个新斑块中搜索时找到食物的概率 $\theta$ 毫无信息：它的先验是均匀的，即 beta 分布 $\mathrm{Beta}(1, 1)$。它搜索10次，其中6次找到食物。它关于 $\theta$ 的后验分布是什么？后验均值呢？
::: solution
给定 beta 先验 $\mathrm{Beta}(a, b)$，在 $n$ 次试验中成功 $k$ 次，后验为 $\mathrm{Beta}(a + k, b + n - k)$（beta 与二项分布共轭）。这里后验是 $\mathrm{Beta}(7, 5)$，均值为 $7/12 = 0.583$。这一估计被从原始频率 $0.6$ 略微拉向先验均值 $0.5$，而且在仅仅十次搜索之后它仍带有不确定性。决定是否留下的取食者不仅应权衡估计值，还应权衡它的不确定性——也许再多采样一会儿再离开、或者偶尔到其他斑块采样是合算的（利用与探索之间的权衡）。
:::
:::

:::

::: history
Darwin 的学生 George Romanes 搜集了关于动物智慧的轶事（1882）；Lloyd Morgan 的准则（1894）正是对它们的反动。Thorndike 的问题箱（1898）与 Pavlov 的条件作用研究开启了学习的实验研究，而 Skinner 的操作性方法主导了二十世纪中期的心理学。与此同时，行为学家研究了印记 (Lorenz, 1935) 与鸣唱学习 （William Thorpe 与 Peter Marler，1950–1970年代）。两个传统在1960与1970年代交汇：Garcia 与 Koelling (1966) 等人表明学习受生物学约束，而 Kamin (1969) 与 Rescorla 与 Wagner (1972) 把条件作用重新表述为从预测误差中学习。比较认知的现代领域自1980年代起成长起来，把实验室实验与野外研究及系统发育比较结合起来。
:::

::: summary
- 学习是行为因经验而发生的持久改变。习惯化具有刺激特异性并表现出去习惯化；敏感化增强反应。
- 印记是带有强烈先天倾向的学习，其敏感期的结束部分取决于学习本身；性印记影响后来的配偶选择。
- 在经典条件作用中，CS 变得能预示 US。Rescorla–Wagner 规则 $\Delta V = \alpha\beta(\lambda - \sum V)$ 从预测误差中学习，给出负加速曲线 $V_n = \lambda(1 - (1 - c)^n)$，并解释了阻断。
- 在操作性条件作用中，后果改变反应率；在并行程序下，反应比例大致匹配奖赏比例（匹配律）。
- 学习受到约束并且是特化的：味觉-疾病联想 (Garcia 与 Koelling)、本能漂移、贮食鸟类的空间记忆与海马大小。
- 社会学习从局部增强直到模仿与教学；传统沿社会网络扩散（大山雀），并在种群之间存在差异（黑猩猩）。
- 关于认知的主张要通过设计能排除更简单解释的实验来检验（Morgan 准则）：工具制造、情景样记忆、镜像自我识别。
- 当最佳行为在各代之间变化、而在一个生命周期内可以预测时，学习会进化；贝叶斯更新描述了从有限经验出发的最优学习。
:::

## 练习

::: exercise 习惯化还是疲劳？{level=1}
一只螺在被敲击时缩回壳内。以一分钟为间隔敲击20次后，它不再缩回。请描述两项检验，以表明这是习惯化而不是肌肉疲劳或感觉适应。
::: solution
(1) 刺激特异性：施加一个不同的刺激（例如，在另一处触碰，或一滴水）。若螺缩回，说明效应器并未疲劳。(2) 去习惯化：给予一个强烈的新异刺激，然后给予原来的敲击。若对敲击的缩回恢复了，说明反应的下降并非由于耗竭的感受器或肌肉。休息后的自发恢复与习惯化和疲劳都相容，所以诊断力较差。
:::
:::

::: exercise Rescorla–Wagner 曲线 {level=1 check="0.672"}
设 $\lambda = 1$、$c = 0.2$，从零开始经过五次条件作用试验后的联想强度是多少（保留三位小数）？
::: solution
$V_5 = 1 - 0.8^5 = 1 - 0.328 = 0.672$。
:::
:::

::: exercise 匹配 {level=1 check="0.25"}
一只大鼠每小时从杠杆1获得15次强化、从杠杆2获得45次，按并行的变间隔程序。在严格匹配下，它的压杆应以多大比例给杠杆1？
::: solution
$15/(15 + 45) = 0.25$。
:::
:::

::: exercise 消退 {level=2 check="0.343"}
一个 $V = 1$ 的 CS 反复呈现而不给 US，$c = 0.3$。按 Rescorla–Wagner 模型，三次消退试验后它的强度是多少？说出一项表明消退并不只是习得之逆过程的发现。
::: solution
$\lambda = 0$，故 $V_3 = (1 - 0.3)^3 = 0.343$。但消退之后，CR 可以在一段延迟之后（自发恢复）、当动物在不同情境中被测试时（更新），或在一次无信号 US 之后（重建）重新出现。这些表明，消退涉及压制反应的新学习，而不是原有联想的擦除，而该模型没有捕捉到这一点。
:::
:::

::: exercise 遮隐 {level=2}
两个刺激，一个响亮的声音 A（$\alpha_A = 0.5$）与一个昏暗的灯光 X（$\alpha_X = 0.1$），总是一起呈现，随后是 US，$\beta = 1$、$\lambda = 1$。用[[#eq-rw]]求 A 与 X 的最终强度。该模型对一个与强刺激复合训练的弱 CS 作出什么预测？
::: solution
每次试验两者都改变 $\alpha_i(1 - V_A - V_X)$，故始终有 $\Delta V_A/\Delta V_X = 0.5/0.1 = 5$，且 $V_A = 5V_X$。学习在 $V_A + V_X = 1$ 时停止，故 $V_X = 1/6 \approx 0.17$、$V_A = 5/6 \approx 0.83$。显著的刺激**遮隐**了弱刺激，而弱刺激若单独训练本会达到1。遮隐在实验上确能观察到，正如模型所预测。
:::
:::

::: exercise 经验之后的后验 {level=2 check="5/7"}
一个对某斑块成功率持 $\mathrm{Beta}(2, 2)$ 先验的取食者，在10次搜索中的8次找到了食物。它的后验均值是多少？
::: solution
后验为 $\mathrm{Beta}(2 + 8, 2 + 2) = \mathrm{Beta}(10, 4)$，均值为 $10/14 = 5/7 \approx 0.714$，略低于原始频率0.8，因为先验把它拉向0.5。
:::
:::

::: exercise 解读一项味觉厌恶实验 {level=2}
鹌鹑和大鼠被给予蓝色的酸水，随后被引起轻微不适。事后，鹌鹑回避蓝色水的强度大于回避酸水；大鼠回避酸水的强度大于回避蓝色水。这表明了什么？它可能与两个物种的生态有何关联？
::: solution
最容易与不适建立联想的线索因物种而异：鹌鹑是颜色，大鼠是味道。学习的内容被物种的生态所**预设**——鹌鹑作为昼行性鸟类主要凭视觉识别食物，而大鼠作为夜行性取食者更依赖味觉与嗅觉 （Hardy Wilcoxon 与合作者在1971年报道了这一对比）。这反对通用学习，而支持"什么与什么相联系"的适应性特化。
:::
:::

::: exercise 一个扩散实验 {level=3}
一种新的取食技术在两个种群中分别由一只鸟引入。在种群 A 中，获得该技术的鸟在联结网络中与更早获得者的联系平均比偶然的更紧密；在种群 B 中，获得的顺序与网络位置无关，而累积获得数从一开始就陡升。解释这两种格局，并说明为什么扩散曲线的形状本身是薄弱的证据。
::: solution
种群 A 显示出基于网络的传播：获得跟随社会联系，这是社会学习的特征。种群 B 提示个体学习（鸟各自独立发现该技术）——减速曲线与网络效应的缺失彼此一致。曲线形状本身证据薄弱，因为 S 形可以在没有社会学习的情况下出现（如果个体间的个体学习速率不同，或学习机会随时间增多——例如鸟逐渐发现觅食器），而在异质网络中的社会学习也未必给出清晰的 S 形。基于网络的扩散分析检验社会传播的独特预测——传播应沿网络分布——这就是它更受青睐的原因。
:::
:::

::: exercise 何时学习 {level=3}
考虑三个物种：(a) 一种拟寄生蜂，其唯一的寄主物种每一代都出现在同一种植物上；(b) 一种鸟，其最佳食物逐年变化、但每次持续数月不变；(c) 一种以花蜜为食的昆虫，生活在报酬最高的花种每隔几分钟就不可预测地更替的生境中。对每一个物种，预测固定偏好与学习哪一个应受青睐，并用 Stephens 的论证为你的答案辩护。
::: solution
(a) 固定偏好：正确答案每一代都相同，所以由基因规定的反应更廉价、而且立即正确。(b) 学习：最佳食物在各代之间不同，所以基因无法追踪它，但它在这只鸟的一生中保持稳定，所以经验能预测不久的未来。(c) 既非对某种花的强学习，也非固定偏好；如果报酬在学习的时间尺度上不可预测，过去的经验用处很小，而应青睐某种泛化的策略（按可得性比例访问花朵，或具有极短的记忆）。顺带一提，真实的拟寄生蜂往往确实会学习与寄主相关的气味，这表明其寄主植物比情形 (a) 所假设的更具变异性。
:::
:::
