在内华达山脉的草甸上，当一只贝克丁地松鼠（*Urocitellus beldingi*）看到白鼬或郊狼逼近时，它可能会直起身子发出尖厉的报警鸣叫。鸣叫是危险的：Paul Sherman 在1970年代于 Tioga Pass 观察有标记的松鼠，发现鸣叫者被捕食者潜近并杀死的情况比不鸣叫者更多。然而并非所有松鼠都同样鸣叫。成年雌鼠留在出生地附近繁殖，因而生活在母亲、女儿和姐妹之间，它们比扩散他乡、与无亲缘邻居为伍的雄鼠鸣叫得多得多。近旁有近亲的雌鼠比没有近亲的雌鼠鸣叫更多。Sherman 1977年的论文得出结论：报警鸣叫之所以受青睐，是因为它提醒了亲属。

帮助他人而自身付出代价的行为，是社会进化的核心难题。Darwin 就把它视为其理论的一个潜在困难，尤其是在蚂蚁与蜜蜂的不育工蚁身上——它们根本不繁殖。本章解释这种行为如何进化。我们先按对行为者与接受者的适合度效应给社会行为分类，然后展开 W. D. Hamilton 的亲缘选择理论与汉密尔顿规则，包括亲缘关系的计算，以及亲缘识别与合作繁殖的证据。接着转向非亲属之间的合作——互惠、重复囚徒困境，以及执行的作用——最后讨论真社会性，即蚂蚁、蜜蜂、胡蜂、白蚁和少数其他动物身上最极端的合作形式。[[behaviour/conflict-game-theory]] 的博弈论与 [[behaviour/mating-systems]] 的家庭冲突将贯穿全章使用。

## 社会行为的分类

::: definition 按适合度效应分类的社会行为 {#def-social-acts}
社会行为对行为者与接受者都有终生的适合度效应。按这些效应的符号分类（Hamilton, 1964；Stuart West、Ashleigh Griffin 与 Andy Gardner, 2007）：

| | 接受者获益 | 接受者受损 |
|---|---|---|
| **行为者获益** | 互利 (+/+) | 自私 (+/−) |
| **行为者受损** | 利他 (−/+) | 恶意 (−/−) |

**合作**是使另一个个体受益、并且至少部分因这种受益而进化的行为；它既包括互利行为，也包括利他。进化意义上的**利他**以其终生适合度后果来定义，而非以意图定义。
:::

互利行为不造成特殊难题：一起捕猎的狮子每头可能比单独捕猎捕获更多。自私行为是默认的预期。利他与恶意需要解释，因为一个让携带者付出代价去帮助另一个个体的基因，其频率似乎理应下降。解决之道来自从基因而非个体出发思考。

## 亲缘选择

### 汉密尔顿规则

Hamilton 的洞见（1964）在于：一个基因不仅可以通过提高其携带者的繁殖来增加自身频率，还可以通过帮助其他携带其拷贝的个体来做到这一点。亲属共享某个基因的可能性高于种群中的随机个体，因为他们从共同祖先继承了拷贝。

::: definition 亲缘系数 {#def-relatedness}
行为者与接受者之间的**亲缘系数** $r$ 是二者相对于种群平均水平的遗传相似程度的度量：在最简单的情形下，它是接受者的一个基因与行为者同一位点上的一个基因血缘同源的概率，超出两个随机种群个体间该概率的部分。在二倍体远交种群中，亲子与全同胞的 $r = \tfrac12$；半同胞、祖孙、舅甥的 $r = \tfrac14$；一代堂/表兄弟姐妹的 $r = \tfrac18$。更一般地，$r$ 是接受者该性状的遗传值对行为者遗传值的回归系数。
:::

对简单的系谱，$r$ 的计算是追踪经由共同祖先连接两个个体的各条下降路径，路径上每经过一代乘以 $\tfrac12$，再对各条路径求和。全同胞由两条路径相连（经母亲与经父亲），每条两步：$2\times(\tfrac12)^2 = \tfrac12$。

::: theorem 汉密尔顿规则 {#thm-hamilton}
若一个基因使其携带者实施某种社会行为——使行为者损失 $c$ 个后代，同时使接受者多得 $b$ 个后代——则该基因受选择青睐的条件是

$$
r\,b > c,
$$ {#eq-hamilton}

其中 $r$ 是接受者相对于行为者的亲缘关系。等价地说，该行为提高了行为者的**内含适合度**：它自身的繁殖，加上它对其他个体繁殖的效应，每一项都按亲缘关系加权。假设：成本与收益可相加（没有很强的非加性相互作用），选择是弱的，且 $r$ 衡量所讨论位点上行为者与接受者之间的遗传关联。
:::

::: proof {collapsed}
一个概要，循 Price 方程的逻辑。设个体以频率 $p_i$ 携带一个帮助基因（在二倍体中为0、½或1）。设每个个体的适合度为 $w_i = w_0 - c\,p_i + b\,p_i'$，其中 $p_i'$ 是对 $i$ 施加行为的个体（其社会伙伴）中的基因频率。一代中平均基因频率的变化正比于基因频率与适合度之间的协方差，$\Delta\bar p \propto \mathrm{Cov}(p_i, w_i) = -c\,\Var(p_i) + b\,\mathrm{Cov}(p_i, p_i')$。当 $b\,\mathrm{Cov}(p_i, p_i')/\Var(p_i) > c$ 时它为正值。比值 $\mathrm{Cov}(p_i, p_i')/\Var(p_i)$ 是伙伴基因频率对焦点个体基因频率的回归——即亲缘关系 $r$——于是得到 $rb > c$。这里的亲缘关系是相互作用者之间的统计关联；它可以来自共同血统，正如亲属之间，也可以来自任何其他使帮助者更可能与帮助者相互作用的机制。
:::

这条规则有三个变量，每一个都可测量。它不仅解释利他（对亲属的收益超过成本），也解释自私何时应当有所收敛（一个使亲属损失 $b$、使自身获益 $c$ 的行为，当 $rb > c$ 时受抑制）——这正是亲子冲突（[[behaviour/mating-systems#prop-poc]]）背后的逻辑。

caption: 汉密尔顿规则。对一个使行为者损失 $c$ 个后代的行为，曲线显示对亲缘度为 $r$（横轴）的接受者所需达到的收益 $b$ 门槛，高于它帮助便受青睐。竖线标出一代堂/表亲（$\tfrac18$）、半同胞（$\tfrac14$）与全同胞或后代（$\tfrac12$）。当 $c = 1$ 时，帮助全同胞需要 $b > 2$，帮助半同胞需要 $b > 4$，帮助表亲需要 $b > 8$。当 $r \to 0$ 时所需收益无界增长：对非亲属的利他无法用亲缘选择解释。

::: example 一次报警鸣叫 {#ex-alarm}
一只地松鼠的报警鸣叫使其被杀的风险提高0.05（以期望损失的后代数计，$c = 0.05$）。它使近旁四个亲属中每一个的存活率提高到足以各自多得0.03个后代。(a) 如果这四个是她的女儿或姐妹，鸣叫受青睐吗？(b) 如果她们是表亲？(c) 这对雄鼠的鸣叫有何预言？
::: solution
(a) $r = \tfrac12$ 时，$rb = \tfrac12\times4\times0.03 = 0.06 > 0.05$：鸣叫受青睐。（对若干接受者的收益可相加。）

(b) $r = \tfrac18$ 时，$rb = 0.015 < 0.05$：鸣叫不受青睐。

(c) 雄鼠扩散离开出生地，因此其近旁的松鼠大多与之无亲缘关系；汉密尔顿规则预言它们应当很少鸣叫，Sherman 的观察正是如此。这一分析假定鸣叫的唯一收益属于其他个体。备择假说——例如鸣叫者直接受益，比如使捕食者放弃追捕——则预言无论亲缘关系如何都应鸣叫，可通过比较近旁有无亲属个体的鸣叫率来检验。
:::
:::

::: warning 亲缘选择不要求动物知道或计算亲缘关系
汉密尔顿规则描述的是帮助基因在何种条件下扩散。它并不意味着动物会计算 $r$、认识其亲属、或有意帮助他们。亲缘偏好的帮助可以由简单规则产生——帮助与你一起长大的个体，或住在你出生地附近的个体——这些规则之所以有效，是因为在该物种的正常环境中，这样的个体通常是亲属。亲缘选择也不是"为家庭利益的选择"：这条规则讲的是基因的扩散，并且凡 $r < 1$ 之处，它同样预言家庭内部的冲突。
:::

### 识别亲属

要让亲缘选择青睐辨别——对亲属的帮助多于非亲属——动物必须能够分辨二者，无论直接或间接。已知的机制有三种。**空间线索**：帮助巢内的任何一个个体，许多鸟类正是如此（这正是杜鹃能利用它们的原因）。**熟悉**：把与你一起长大的个体当作亲属。**表型匹配**：将他者与一个从自身或已知亲属习得的模板相比较。Warren Holmes 与 Paul Sherman（1982）在贝克丁地松鼠幼崽出生后不久，在不同窝之间做了交叉抚养。一起长大的松鼠不论有无亲缘都把彼此当作同胞——这是熟悉——但在分开抚养的无亲缘松鼠中，全姐妹彼此间的攻击性低于半姐妹，表明它们还能认出素未谋面的亲属，想来是靠表型匹配。

### 合作繁殖

在约9 %的鸟类物种和更少的哺乳类物种中，有些个体帮助其他个体繁殖，通常是喂养并非自己所生的幼体。帮手常常是留在亲代领地里的长大后代，帮助抚养年幼的弟妹。两个问题随之而来：为何留下而不离开，又为何帮忙而非无所事事？

**生态约束**假说（Stephen Emlen，1982）回答第一个问题：年轻成体之所以留下，是因为繁殖空缺稀少——所有好的领地都已被占据——独立繁殖的机会因而很低。Jan Komdeur 对塞舌尔苇莺（*Acrocephalus sechellensis*）的实验是经典检验。在库曾岛上，所有适宜生境都被占据，许多年轻鸟留下做帮手。当 Komdeur 把一些鸟转移到未被占据的岛上（1988年起，作为一项保护计划的一部分），岛上的鸟便独立繁殖；而当移走繁殖鸟在库曾岛制造出空缺时，帮手便离开去填补它们。在高质量领地上——其帮助能养大更多幼鸟——的帮手更可能留下。

在许多物种中，亲缘选择回答第二个问题。Stephen Emlen 与 Peter Wrege（1988）发现，肯尼亚的白额蜂虎（*Merops bullockoides*）生活在大家族世系中，它们会在可及的最亲近亲属的巢边帮忙。但在有些物种，帮助也带来直接收益——经验、继承领地的机会、或在群体中被接纳——而在某些合作繁殖者中，帮手与其喂养的幼体常常并无亲缘关系。

::: example 繁殖还是帮助？{#ex-helper}
一只一岁的鸟可以 (a) 离开并尝试繁殖：找到空领地的概率是0.3，繁殖的一对能养大2个后代，一岁鸟与它们的亲缘度为 $\tfrac12$；或 (b) 留下帮助其父母，使父母的繁殖成功率多出0.8只离飞的幼鸟，即它的同窝全同胞。在这个繁殖季，哪个选项带来更高的内含适合度？若空缺变得普遍（概率0.7），答案会如何变化？
::: solution
(a) 离开：$0.3\times2\times\tfrac12 = 0.3$ 个后代当量。(b) 帮助：$0.8\times\tfrac12 = 0.4$ 个同胞当量，而同胞与后代等值，因为两种情形下 $r = \tfrac12$。帮助更优。当空缺概率为0.7时，离开得 $0.7\times2\times\tfrac12 = 0.7 > 0.4$：一岁鸟应当离开。这正是 Komdeur 制造出空生境时观察到的变化：帮手离开去繁殖。注意，完整的分析还应加上未来收益——帮手继承领地的机会，以及它在各选项下的存活。
:::
:::

## 非亲属之间的合作

亲缘选择无法解释给予无亲缘个体的帮助。其他机制可以做到。在**副产品互利**中，帮助直接使行为者受益，对他人的受益只是附带——例如个体一起捕猎是因为每只捕获更多。在**互惠**中，帮助日后得到回报。在**执行**中，伙伴或第三方惩罚不合作者，或奖励合作者。

### 互惠与囚徒困境

Robert Trivers（1971）提出，如果行为得到回报，非亲属之间的利他就可能进化——"互惠利他"——条件是个体反复相互作用，并且能够区别对待那些不回报者。这一问题可由**囚徒困境**刻画。两个参与者各自选择合作 (C) 或背叛 (D)。行参与者的收益为

| | C | D |
|---|---|---|
| **C** | $R$（回报） | $S$（受骗者收益） |
| **D** | $T$（诱惑） | $P$（惩罚） |

其中 $T > R > P > S$（且 $2R > T + S$）。无论对方做什么，背叛的收益都更高，所以在单次相遇中，相互背叛是唯一的进化稳定策略——尽管双方合作都会更好。然而在**重复**博弈中，同一对个体反复相遇，每一轮之后还有下一轮的概率为 $w$。

::: proposition 以牙还牙与未来的阴影 {#prop-tft}
在重复囚徒困境中，**以牙还牙**（TFT：首轮合作，此后复制伙伴的上一步）若满足下式，则不能被**总是背叛**（ALLD）入侵：

$$
w > \frac{T - R}{T - P}.
$$ {#eq-tft}

在 TFT 参与者组成的种群中，每个 TFT 参与者在一局博弈中获得 $R/(1 - w)$，而一个 ALLD 突变体获得 $T + wP/(1 - w)$。
:::

::: proof
轮数的期望为 $1 + w + w^2 + \dots = 1/(1 - w)$。两个 TFT 参与者每轮都合作：收益 $R/(1 - w)$。ALLD 对阵 TFT 首轮得 $T$，此后 TFT 转为背叛，双方在随后各轮都只得 $P$：$T + wP + w^2P + \dots = T + wP/(1 - w)$。当 $R/(1 - w) > T + wP/(1 - w)$，即 $R > T(1 - w) + wP$，亦即 $w(T - P) > T - R$ 时，TFT 能抵抗入侵，这正是 [[#eq-tft]]。（TFT 严格说来不是进化稳定策略，因为 TFT 种群可以漂移到"总是合作"，ALLD 随后便能入侵；但它对 ALLD 是稳定的。）
:::

::: example 关系必须维持多久？{#ex-tft}
取 $T = 5$、$R = 3$、$P = 1$、$S = 0$，即 Robert Axelrod 在其计算机锦标赛中使用的数值。(a) 怎样的延续概率 $w$ 能使 TFT 对抗 ALLD 保持稳定？(b) 当 $w = 0.9$ 时，比较 TFT 种群中 TFT 与 ALLD 的收益。(c) 为什么预期互惠主要见于稳定群居的长寿命动物？
::: solution
(a) $w > (5 - 3)/(5 - 1) = 0.5$：关系的平均期望延续必须超过两轮。

(b) TFT：$3/0.1 = 30$。ALLD：$5 + 0.9\times1/0.1 = 14$。与合作者合作，远比一次性剥削它们划算。

(c) 互惠要求与同一批伙伴反复相互作用（高 $w$），并能够认出它们、记住其过去的行为。这些条件在稳定群居的长寿命动物——灵长类、蝙蝠、某些鸟类——中成立，而在相遇短暂且匿名之处落空。
:::
:::

:::

Axelrod 与 Hamilton（1981）发表于 *Science*，他们让博弈论者提交的策略在计算机锦标赛中相互对弈，证明 TFT 出奇地成功——厚道（从不首先背叛）、有报复性且宽恕。后来的分析发现，在有噪声的环境中——着法有时会被误读——更宽厚的策略，如"慷慨以牙还牙"或"赢留输换"（Martin Nowak 与 Karl Sigmund，1993），表现更佳。

自然界中互惠的确凿证据出人意料地稀少。最好的例子是吸血蝠（*Desmodus rotundus*）的食物分享：若两三个夜晚未能进食，它们就会死去。Gerald Wilkinson（1984）发现，吃饱的蝙蝠会把血反刍给没吃到的同栖者，且分享主要发生在亲属之间和经常相伴的个体之间。Gerald Carter 与 Wilkinson（2013）在圈养条件下证明，一只蝙蝠过去对某伙伴的捐献，比亲缘度更能预言它日后从该伙伴处得到的帮助。许多其他被认为的例子，细查之下都被证明是互利或亲缘选择。

### 执行与伙伴选择

当伙伴对欺骗作出反应时，合作也能维持。在珊瑚礁上，裂唇鱼（*Labroides dimidiatus*）吃客户鱼体表的寄生虫，却更喜欢吃客户的保护性黏液——这是欺骗。Redouan Bshary 与 Alexandra Grutter 证明，客户鱼会以驱赶清洁者或转而光顾另一个清洁站来回应欺骗；而在有潜在客户注视时，清洁者会更守规矩。客户鱼选择清洁者的能力——一个**生物市场**——加上惩罚，使欺骗有所收敛。植物与微生物之间同样如此：若豆科植物根瘤中的根瘤菌固定的氮很少，豆科植物就会减少对该根瘤的氧气供应（Toby Kiers 及同事，2003）：这是一种制裁。

## 真社会性

::: definition 真社会性 {#def-eusocial}
一个物种若具备 (1) **生殖分工**——一些个体（工体）很少或完全不繁殖，而另一些个体（王后与王）繁殖；(2) **世代重叠**——后代帮助其亲代；以及 (3) **对幼体的合作照料**——即为**真社会性**。在最先进的类型中，工体在形态上截然不同且永久不育。
:::

真社会性见于全部蚂蚁与全部白蚁，见于某些蜜蜂与胡蜂，见于某些蚜虫与蓟马，见于 *Synalpheus* 属的鼓虾，见于裸滨鼠（*Heterocephalus glaber*；Jennifer Jarvis 于1981年将其描述为真社会性）与达马拉滨鼠。在膜翅目（蚁、蜂与胡蜂）内部，真社会性独立进化了多次——蚁类一次，蜂类与胡蜂类各不止一次。

### 单倍二倍体假说

膜翅目是**单倍二倍体**：雌性由受精卵发育而来，为二倍体；雄性由未受精卵发育而来，为单倍体。Hamilton（1964）注意到一个推论。雄性能把自己整套基因组传给每个女儿，所以同父的两个姐妹共享其父源基因的全部，平均共享其母源基因的一半。她们的亲缘度为 $\tfrac12\times1 + \tfrac12\times\tfrac12 = \tfrac34$，高于母亲与其女儿之间的 $\tfrac12$。这样一来，工体抚养姐妹比抚养女儿能传递更多自身基因——这是通向真社会性的一种倾向。

这个论证有个缺陷，Robert Trivers 与 Hope Hare（1976）指了出来。工体也抚养兄弟，而她们与兄弟的亲缘度只有 $\tfrac14$（兄弟没有来自父亲的基因）。在性别比相等时，工体与其同胞的平均亲缘度为 $\tfrac12(\tfrac34 + \tfrac14) = \tfrac12$，与对其自身后代的相同。只有当工体能把群体的投入偏向姐妹时，这一优势才会重现。Trivers 与 Hare 预言，在由单只、仅交配一次的蜂王领导的群体中，工体应当偏好雌对雄3 : 1的投入比（即她们亲缘度之比），而蜂王对儿子与女儿亲缘度相同，偏好1 : 1。在蚁类各物种间，此类群体中的投入比偏向雌性，更接近工体的最优值——这是工体控制性别分配的证据，也是对亲缘选择理论的一次确认。Liselotte Sundström（1994）后来对木蚁 *Formica truncorum* 的研究发现，单交蜂王群体中的工体会把投入偏向雌性，而多交蜂王（姐妹间亲缘度较低）群体中的工体则不会，正如预言。

::: proposition 膜翅目姐妹间的亲缘度 {#prop-haplo}
在一个由一只蜂王领导的单倍二倍体群体中，蜂王与 $k$ 只雄蜂交配，每只使同等比例的工体出生，则两个工体之间的平均亲缘度为

$$
\bar r = \frac14 + \frac{1}{2k},
$$ {#eq-haplo}

该式在 $k = 1$ 时为 $\tfrac34$，$k = 2$ 时为 $\tfrac12$，并随 $k$ 增大而趋于 $\tfrac14$。工体与兄弟的亲缘度无论 $k$ 为何都是 $\tfrac14$。
:::

::: proof
两个工体在每个位点以 $\tfrac12$ 的概率共享母源基因，贡献 $\tfrac12\times\tfrac12 = \tfrac14$（每个个体从母亲继承半套基因组）。她们有 $1/k$ 的概率同父，此时其父源一半完全相同，贡献 $\tfrac12\times1$；否则其父源基因无亲缘（假定诸父无亲缘）。总和为 $\tfrac14 + \tfrac12\cdot\tfrac1k$。兄弟只继承母源基因；兄弟的一个基因与从工体母源一半中取出的一个基因相同的概率是 $\tfrac12$，而工体基因组一半为母源，故在以命换命的度量下为 $\tfrac14$。
:::

蜜蜂蜂王与许多雄蜂交配——通常超过十只——所以工蜂与其姐妹的平均亲缘度接近 $\tfrac14 + \tfrac1{2k} \approx 0.3$，*低于*其对自己后代的亲缘度。仅凭单倍二倍体无法解释工蜂为何保持不育。

::: example 工体监管 {#ex-policing}
工蜂有卵巢，能产未受精卵，孵化成雄蜂。一个工体应更希望群体养大蜂王的儿子（她的兄弟），还是其他工体的儿子（她的侄子）？对 $k = 1$ 与 $k = 15$ 位父亲，利用对兄弟 $\tfrac14$、对全姐妹之子 $\tfrac38$、对半姐妹之子 $\tfrac18$ 的亲缘度进行计算。
::: solution
当有 $k$ 位父亲时，随机另一个工体是全姐妹的概率为 $1/k$，因此对一个工体所生雄性的平均亲缘度为 $\tfrac1k\cdot\tfrac38 + (1 - \tfrac1k)\cdot\tfrac18 = \tfrac18 + \tfrac1{4k}$。

$k = 1$ 时：$\tfrac18 + \tfrac14 = \tfrac38 > \tfrac14$——工体应偏好侄子，并容忍工体繁殖。

$k = 15$ 时：$\tfrac18 + \tfrac1{60} = 0.142 < 0.25$——工体应偏好兄弟，并移走其他工体的卵。转折点在 $k = 2$。Francis Ratnieks 在1988年作出了这一预言，Ratnieks 与 Kirk Visscher（1989）证明，蜜蜂工蜂确实会移走其他工蜂产的卵而留下蜂王的卵——**工体监管**。因此，尽管许多工蜂卵巢活跃，蜂群中极少有雄性是工蜂之子。在这个物种中，是监管而非高亲缘度迫使多数工蜂不育。
:::
:::

### 单配制与真社会性的起源

如果姐妹之间的高亲缘度并非要害，那么什么是？Jacobus Boomsma（2007）提出，关键条件是创建群体的蜂王的终身**单配**：唯有如此，一个雌体自己的后代与其同胞才同等宝贵（无论在二倍体还是单倍二倍体物种中，二者 $r = \tfrac12$），于是帮助带来的哪怕一点点效率增益，也会让汉密尔顿规则偏向留下与帮助。William Hughes、Benjamin Oldroyd、Madeleine Beekman 与 Francis Ratnieks（2008）重建了蚁、蜂、胡蜂系统发育树上的交配系统，发现单配在每个真社会性谱系中都是祖先状态；多配（如蜜蜂）是在工体不可逆地特化之后才进化出来的。白蚁是二倍体，其群体由一雄一雌的单配配偶创建。因此当前的观点是：真社会性起源于单配家庭，出现在使帮助非常有效的生态条件下——一个可防卫、价值高的巢；可共享的食物——其进化机制是亲缘选择。

::: warning 真社会性与群体选择
真社会性群体有时被称为"超级有机体"，一些作者主张它们的进化需要群体选择而非亲缘选择（Martin Nowak、Corina Tarnita 与 E. O. Wilson，2010）。该领域绝大多数研究者回应（Patrick Abbot 与130多位合作者，2011）：内含适合度理论能解释数据，并作出备择模型做不到的可检验预言——性比冲突、工体监管、单配格局。正确表述时，多层次（群体）选择与亲缘选择只是对同一基因频率变化的不同划分方式，二者对同样的假设作出同样的预言；错误的是那种较老的观点，即性状进化是因为它们以个体的内含适合度为代价使群体受益。
:::

::: quiz
某种胡蜂的群体由仅交配一次的单只蜂王创建，但在一些种群中蜂王与三只雄蜂交配。你预期在哪种种群中，工体会把群体投入更强地偏向雌性？
- [x] 蜂王仅交配一次的种群
- [ ] 蜂王与三只雄蜂交配的种群
- [ ] 没有差别，因为工体与所有同胞的亲缘度相同
- [ ] 蜂王与三只雄蜂交配的种群，因为工体更多
::: solution
只有一位父亲时，工体与姐妹的亲缘度为 $\tfrac34$，与兄弟为 $\tfrac14$，偏好3 : 1的投入比。有三位父亲时，姐妹亲缘度降为 $\tfrac14 + \tfrac16 = \tfrac5{12}$，偏好的投入比为 $(5/12)/(1/4) = 5 : 3$。蜂王多配时，工体偏好的雌性偏向更弱——这正是 Sundström 在木蚁中发现的格局。
:::
:::

::: application 微生物与医学中的合作
亲缘选择理论适用于微生物。许多细菌分泌公共物品——酶、搜刮铁的铁载体、生物膜基质——惠及邻近细胞。Ashleigh Griffin、Stuart West 与 Angus Buckling（2004）以铜绿假单胞菌（*Pseudomonas aeruginosa*）证明，当种群保持高亲缘度时，产铁载体的合作者在竞争中胜过不产载体的作弊者，亲缘度低时则败给它们。作弊突变体在慢性感染中出现，这启发了引入作弊者以削弱致病菌群的策略（目前尚属概念，细节属于医学研究）。在保护方面，合作繁殖者如非洲野犬（*Lycaon pictus*）需要最低群体规模才能成功猎食和育幼，因此小群体遭受阿利效应，这是重引入规划中的一个考量。
:::

::: history
Darwin 在《Origin》(1859) 中把社会昆虫的不育品级称为"我曾觉得无法克服的唯一特殊困难"，并提出选择可以作用于家庭。J. B. S. Haldane 在1955年说，他愿为"两个兄弟或八个表亲"冒生命危险。Hamilton 1964年发表于 *Journal of Theoretical Biology* 的论文给出了内含适合度的一般理论。Trivers 提出互惠利他（1971），并与 Hare 一起提出性比检验（1976）。E. O. Wilson 的《The Insect Societies》(1971) 与《Sociobiology》(1975) 集成了这一领域。Axelrod 与 Hamilton 的重复囚徒困境分析发表于1981年，Ratnieks 与 Visscher 发现工体监管在1989年，单配祖征的系统发育证据在2008年。
:::

::: summary
- 社会行为按对行为者与接受者的适合度效应分类：互利、自私、利他与恶意。利他与恶意需要专门解释。
- 汉密尔顿规则：当 $rb > c$ 时社会行为受青睐，其中 $r$ 为亲缘度；行为进化以最大化内含适合度。亲缘度由系谱计算（全同胞 $\tfrac12$，半同胞 $\tfrac14$，表亲 $\tfrac18$）。
- 亲缘辨别利用空间线索、熟悉或表型匹配；地松鼠的报警鸣叫与蜂虎的帮助遵循亲缘度。
- 独立繁殖的生态约束（塞舌尔苇莺的转移实验）以及帮助带来的亲缘选择收益与直接收益，促成合作繁殖。
- 在非亲属之间，合作可由互利、互惠与执行维持。重复囚徒困境中，当 $w > (T - R)/(T - P)$ 时 TFT 抵抗 ALLD；吸血蝠与清洁鱼提供了证据。
- 单倍二倍体使全姐妹亲缘度为 $\tfrac34$，兄弟却只有 $\tfrac14$；工体控制的性比偏雌，如 Trivers 与 Hare 所预言。多配降低姐妹亲缘度（$\tfrac14 + 1/2k$），并有利于工体监管。
- 真社会性出现在创建者终身单配的谱系中，处于使帮助高效的生态条件下——与亲缘选择一致。
:::

## 练习

::: exercise 亲缘度 {level=1 check="1/8"}
在一个远交的二倍体种群中，一个个体与其一代堂/表亲的亲缘系数是多少？
::: solution
一代堂/表亲共享一对祖父母。有两条路径（经祖母与经祖父），每条四步（上到父母，上到祖父母，下到叔伯姑舅姨，下到表亲）：$2\times(\tfrac12)^4 = \tfrac18$。
:::
:::

::: exercise 汉密尔顿规则 {level=1}
一个行为使行为者损失1个后代，使一个半同胞多得3个后代。它受青睐吗？
::: solution
$rb = \tfrac14\times3 = 0.75 < c = 1$：不受青睐。若对象是全同胞则受青睐（$\tfrac12\times3 = 1.5 > 1$）。
:::
:::

::: exercise 未来的阴影 {level=1 check="2/3"}
在 $T = 7$、$R = 5$、$P = 4$、$S = 0$ 的囚徒困境中，TFT 抵抗 ALLD 入侵的最小延续概率 $w$ 是多少？
::: solution
$w > (T - R)/(T - P) = (7 - 5)/(7 - 4) = 2/3$。
:::
:::

::: exercise 有几个父亲的姐妹 {level=2 check="5/12"}
一只膜翅目蜂王与三只雄蜂交配，每只使同等数目的工体出生。她的两个工体之间的平均亲缘度是多少？
::: solution
由 [[#eq-haplo]]，$\tfrac14 + \tfrac1{2\times3} = \tfrac14 + \tfrac16 = \tfrac5{12} \approx 0.417$。
:::
:::

::: exercise 监管阈值 {level=2}
利用 [[#ex-policing]] 的结果，证明只要蜂王与两只以上雄蜂交配，工体就应偏好蜂王的儿子而非其他工体的儿子。
::: solution
当 $\tfrac14 > \tfrac18 + \tfrac1{4k}$，即 $\tfrac18 > \tfrac1{4k}$，即 $k > 2$ 时，工体偏好兄弟。$k = 2$ 时两者相等（$\tfrac18 + \tfrac18 = \tfrac14$）。
:::
:::

::: exercise 帮助还是繁殖 {level=2}
一只年轻雄鸟可以帮助其父母，使父母多养大1.2个全同胞；或离开并以概率 $p$ 繁殖，成功则养大2.5个后代。$p$ 高于何值时他应当离开？若其父母离异，他将帮助母亲与一位新继父，养大的是半同胞，答案如何变化？
::: solution
帮助得 $1.2\times\tfrac12 = 0.6$；离开得 $p\times2.5\times\tfrac12 = 1.25p$。当 $p > 0.6/1.25 = 0.48$ 时他应当离开。半同胞情形下，帮助得 $1.2\times\tfrac14 = 0.3$，故 $p > 0.24$ 时他应当离开。在一些合作繁殖者中，如长尾山雀与白额蜂虎，当幼体亲缘较疏时，帮手确实更不可能帮忙。
:::
:::

::: exercise 解读吸血蝠数据 {level=2}
在一个吸血蝠圈养群体中，轮流对每只蝙蝠禁食，并记录喂食它的捐献者。就所有配对而言，一只蝙蝠对某伙伴的捐献量与亲缘度相关（$r$ 介于0与0.5之间），且与它此前从该伙伴处所得到的量相关得更强。在同时包含两者的模型中，既往所得解释的变异远多于亲缘度。这些结果说明了什么？应考虑哪种备择解释？
::: solution
它们表明分享部分由互惠维持——蝙蝠给予那些曾给过它们的——而不只靠亲缘选择，尽管亲缘也有贡献。一种备择解释是：捐献与所得都受第三个因素驱动——经常相伴的蝙蝠（同栖、互相理毛）既给得多也得得多，所以既往所得可能反映的是相伴，而非对帮助的条件性回应。要证明帮助是条件性的，需要操纵伙伴是否帮过忙的试验（例如，阻止一只蝙蝠向某特定伙伴捐献，观察该伙伴是否相应减少捐献）。
:::
:::

::: exercise 一项性比检验 {level=3}
在某种蚁中，蜂王仅交配一次；有王群体对雌性与雄性的投入比为3 : 1。也发现无王群体，其中工体产雄。解释3 : 1之比为何支持投入由工体控制，并预言若蜂王与两只雄蜂交配、各使半数工体出生，工体偏好的投入比是多少。
::: solution
蜂王与儿子和女儿的亲缘度相等（$\tfrac12$），偏好均等投入1 : 1。工体与姐妹的亲缘度为 $\tfrac34$，与兄弟为 $\tfrac14$，偏好按这两个亲缘度之比投入，即3 : 1。所观察到的3 : 1与工体的最优值吻合，意味着工体控制分配（例如选择性抚养雌性幼虫，或杀死雄性幼虫）。有两位父亲时，姐妹亲缘度为 $\tfrac14 + \tfrac14 = \tfrac12$，工体偏好 $(1/2)/(1/4) = 2 : 1$。（这些"偏好比例"来自 Trivers 与 Hare 的论证：每一方应按亲缘度成比例分配投入，其前提是平衡种群中两性的繁殖价值相当。）
:::
:::

::: exercise 互惠如何起步？{level=3}
在一个全体为 ALLD 参与者的种群中，出现一个 TFT 突变体。解释为何它不能入侵，即使 $w$ 很高。尽管如此，互惠如何能够建立起来？
::: solution
稀有的 TFT 只会遇到 ALLD 参与者：它首轮得 $S$，此后各轮得 $P$，共 $S + wP/(1 - w)$，低于 ALLD 参与者的 $P/(1 - w)$，于是遭受选择淘汰。ALLD 也是进化稳定策略。若 TFT 参与者彼此相互作用的频率高于随机相遇，TFT 便能扩散——例如突变体聚集成簇（因为亲属比邻而居，使伙伴间亲缘度为正），或种群结构（小群体、扩散受限）把 TFT 参与者聚集到一起。设 TFT 遇到另一个 TFT 的概率为 $\rho$，则当 $\rho\,R/(1 - w) + (1 - \rho)(S + wP/(1 - w)) > P/(1 - w)$ 时 TFT 可以入侵。亲缘结构因而能使互惠起步，此后由重复相互作用将其维持——这是各种合作机制如何协同的一个例子。
:::
:::
