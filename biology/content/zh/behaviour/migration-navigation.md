2007年八月末，一只携带卫星发射器、被研究人员称为 E7 的雌性亚种斑尾塍鹬（*Limosa lapponica baueri*）离开阿拉斯加西海岸，飞越太平洋向南而去。约八天后，她降落在新西兰，行程约11,700公里，途中从未停下来觅食、饮水或休息。跟踪她和其他塍鹬的 Robert Gill 及同事在2009年报告，这种不间断飞行是此种群的常态，而后来的跟踪记录到塍鹬不间断飞行超过13,000公里。离开阿拉斯加之前，这些鸟已把脂肪养到占体重一半以上，同时其消化器官萎缩；它们飞越了没有地标的海洋，抵达了它们要去的地方。

迁徙在 Tinbergen 的每一个层次上都提出问题（[[behaviour/studying-behaviour#def-four-questions]]）。动物怎么知道该往哪走？又怎么知道自己身在何处？初次上路的年轻动物如何找到一个它从未见过的目的地？为什么要迁徙，迁徙者又该携带多少燃料？迁徙路线能以多快的速度进化？本章先讲定向的类型与地图-罗盘模型，然后处理动物使用的各种罗盘——太阳、星辰、地磁场与偏振光——以及昆虫的航位推算。随后转向更困难的地图问题：位移实验、嗅觉地图与磁地图，以及尚不知晓的部分。后半部分关乎迁徙的生态与进化：成本与收益、最优燃料负荷、黑头林莺迁徙方向的遗传学，以及气候变化的影响。[[behaviour/foraging]] 的觅食理论在迁徙者于停歇地做出的决策中再度出现。

## 定向的类型

::: definition 迁徙 {#def-migration}
**迁徙**是持久的、有方向的移动，它把动物带离其当前的家域；在此期间，动物不为那些会令其他类型移动停下来的资源（比如它本来会停下来吃的食物）所动，而移动之后通常或返回，或在新范围内定居。它通常是季节性的，并伴随生理准备（育肥、激素与器官的变化）与迁徙性躁动。迁徙不同于**扩散**（从出生地到繁殖地的一次性移动），也不同于家域之内的**觅食**移动。
:::

Donald Griffin（1955）区分了三个层次的定向能力，至今仍然有用：

::: definition 陆标导航、罗盘定向与真正导航 {#def-navigation}
**陆标导航**是依靠熟悉的地标寻路。**罗盘定向**是借助罗盘保持固定方向，而不参照目标的位置。**真正导航**是从不熟悉的地方朝目标启程的能力，它既需要**地图**（确定相对目标的位置），也需要**罗盘**（选择并保持方向）。Gustav Kramer 的**地图-罗盘**模型（1953）提出，归巢动物先用地图确定家的方向，再用罗盘朝那个方向飞。
:::

另一种对幼年迁徙者很重要的策略是**向量导航**（也称"时钟-罗盘"定向）：按遗传程序规定的、一条或多条罗盘方向，飞行遗传程序规定的一段时长，从而在完全不知道自己身处何地的情况下，把动物大致带到其种群的越冬地。

## 罗盘

### 太阳罗盘

1940年代末1950年代初，Kramer 在迁徙季把欧洲椋鸟（*Sturnus vulgaris*）养在圆形笼中；笼养的迁徙者会在本该迁徙的时候坐立不安（**迁徙性躁动**，*Zugunruhe*），并把跳跃的方向朝向迁徙方向。在天空可见时，椋鸟定向正确；阴天时定向变差。当 Kramer 用镜子把太阳的视位置移动90°时，鸟的定向也移动了约90°。它们在把太阳当作罗盘。

可是太阳在动。它的方位角（罗盘方位）一天之中在变化，从早晨的约略正东，经正午的南方（北半球），到傍晚的约略正西。要把它用作罗盘，动物必须知道一天中的时刻，并用自己的昼夜钟补偿太阳的移动（[[behaviour/mechanisms-of-behaviour]]）。这在**时钟漂移**实验中得到证明，最早由 Klaus Schmidt-Koenig 于1958年在信鸽上进行。被饲养在与自然日相位差6小时的光暗周期中数日的鸽子，其昼夜钟被重新设定；放飞后，它们飞行方向与对照的偏离，大致相当于太阳在6小时里转过的角度。

::: example 预测时钟漂移的偏角 {#ex-clockshift}
北半球的鸽子经历6小时的变慢漂移（它们的主观黎明比真实黎明晚6小时），并在鸽舍以南的一处场地于真实正午放飞。设太阳方位角平均每小时移动约15°，从6:00的90°移到正午的180°。(a) 鸽子将朝哪个方向飞？(b) 若改为变快6小时呢？
::: solution
鸟想朝北飞（0°，家的方向）。(a) 真实正午太阳在方位角180°处。鸟的内钟读作6:00，此时它们预期太阳在约90°处。若在6:00朝北飞，鸟会飞在太阳逆时针90°的方位——太阳在90°时即0°。把同样的角度应用于位于180°的真实太阳，就把鸟送到了 $180° - 90° = 90°$，即东方。偏角是正确方向顺时针90°。(b) 变快时，内钟读作18:00，此时预期太阳在约270°处；于是北在太阳顺时针90°，鸟便按 $180° + 90° = 270°$ 飞，即西方——正确方向逆时针90°。

实际上，偏角常常比预言的小，因为太阳方位角并非匀速移动（夏季正午前后与低纬度处移动得更快），也因为鸽子还使用别的罗盘线索，如磁场。然而偏角的方向始终与预言一致，这表明太阳罗盘是时间补偿的。
:::
:::

时间补偿太阳罗盘分布广泛：鸟类、鱼类、海龟与许多昆虫都有。在北美东部的君主斑蝶种群——它们迁徙数千公里到墨西哥中部的山区越冬——用于太阳补偿的钟部分位于触角中：Christine Merlin、Robert Gegear 与 Steven Reppert（2009）证明，切除触角或用遮光漆涂抹触角的君主斑蝶不能正确定向，而用清漆涂触角的个体定向正常。

### 星罗盘

许多鸣禽在夜间迁徙。Stephen Emlen（1967）在天象馆里测试靛彩鹀（*Passerina cyanea*），使用内衬记录脚印纸张的漏斗形笼。在天象馆的星空下，鸟朝着恰当的迁徙方向定向；星星关掉后便不然。遮盖特定星座的实验表明，鸟利用的是天极周围约35°范围内恒星的图案——即北极星一带——而不是任何单颗恒星。最引人注目的是，Emlen（1970）在天象馆让星空绕猎户座的参宿四而非北极星旋转，并在这样的天空下饲养幼年彩鹀。秋天，这些鸟定向时仿佛参宿四就标着北。彩鹀并非生来认识星座；它们在巢中幼小时学习天空的哪一部分是旋转中心，而那定义了北。

### 磁罗盘

Wolfgang 与 Roswitha Wiltschko 在1972年证明，笼养的欧洲知更鸟（*Erithacus rubecula*）在没有视觉线索时朝迁徙方向定向，而当用亥姆霍兹线圈改变笼周围的磁场时，其定向随之改变。他们的关键发现是，知更鸟的罗盘是一个**倾角罗盘**。反转场的水平分量（使磁北指南）会反转鸟的定向，这是任何罗盘应有的表现；但只反转垂直分量也同样反转定向，这却是极性罗盘（如人类的磁针）不会有的表现。鸟分辨的是"极地方向"（场线陡峭地俯入地面）与"赤道方向"，而不是南与北。

机制尚无定论。关于鸟类罗盘的主流假说是视网膜中一种依赖光的**自由基对**机制：隐花色素蛋白（很可能是 Cry4）中一个对磁场敏感的化学反应，受场相对眼的方向的影响。显示弱射频场会扰乱罗盘的实验支持自由基对机制；Jingjing Xu、Henrik Mouritsen、Peter Hore 及同事（2021）证明，纯化的知更鸟 Cry4 能形成对磁场敏感的自由基对。另有提议认为，检测场强依靠以含铁磁铁矿颗粒为基础的另一套系统，尽管鸽喙中曾被认为是磁铁矿受体的候选结构后来被证明是巨噬细胞。除鸟类外，许多动物已知具有磁罗盘，包括海龟、鲑鱼、蝾螈、滨鼠与昆虫。

::: intuition 为什么携带好几个罗盘？
每个罗盘都有弱点：太阳会被云遮蔽，而且用它需要一个准确的钟；星星只在夜间、晴朗天气下可见；磁罗盘只给出倾角的轴向，在磁极与磁赤道附近并不可靠，而且磁北与真北之差（磁偏角）因地点而异。使用多个罗盘并让它们彼此校准——例如用日落时地平线附近的偏振光图样重新校准磁罗盘——能得到一个稳健的系统。鸟如何排定各罗盘的优先次序并彼此校准，仍有争论，因为不同实验给出了相互矛盾的结果。
:::

### 航位推算

沙漠蚁（*Cataglyphis*）在北非炎热、地貌单调的盐碱地上单独觅食，离巢数十米乃至数百米沿曲折的路径游荡，找到食物后便径直跑回巢。它们靠**航位推算**（dead reckoning）做到这一点：持续累加已行路径每一段的距离与方向，因此总是"知道"指向巢的向量。方向来自以天空偏振光图样为基准的天体罗盘，蚁与蜂用复眼背缘区特化的感光细胞探测它（Rüdiger Wehner 的工作）；距离则来自计步器。Matthias Wittlinger、Rüdiger Wehner 与 Harald Wolf（2006）给到达喂食器的蚁的腿粘上高跷，或把它们腿截短；踩高跷的蚁归途跑过巢前，短腿蚁则未及巢，正如它们靠步数计距的预言。

::: proposition 归家向量 {#prop-homevector}
若动物的去程由位移 $\mathbf{d}_1, \mathbf{d}_2, \dots, \mathbf{d}_n$（平面内的向量）的各段组成，则它相对巢的位置为 $\mathbf{D} = \sum_i \mathbf{d}_i$，而**归家向量**为 $-\mathbf{D}$。以分量（东、北）表示，第 $i$ 段长 $\ell_i$、罗盘方位 $\theta_i$（自北顺时针度量），

$$
D_E = \sum_i \ell_i\sin\theta_i, \qquad D_N = \sum_i \ell_i\cos\theta_i,
$$

归家的距离为 $\sqrt{D_E^2 + D_N^2}$，而家的方位即 $(-D_E, -D_N)$ 的方向。每一段所估方向或长度的误差会累积，所以航位推算在漫长而蜿蜒的路径上准确性下降，动物便依赖目标附近的地标。
:::

::: example 直线回巢 {#ex-pathintegration}
一只沙漠蚁先向北走10米，再向东走20米，再向南走5米，然后找到了食物。直线回巢的路程有多长、方位是多少？
::: solution
位移求和：东 $0 + 20 + 0 = 20$ 米，北 $10 + 0 - 5 = 5$ 米。蚁相对巢位于 $(20, 5)$。归家向量是 $(-20, -5)$：距离 $\sqrt{400 + 25} = \sqrt{425} = 20.6$ 米，方位 $\operatorname{atan2}(-20, -5) = 256°$（自北顺时针度量），西偏南一点。一只在刚拾起食物时被实验者移走的蚁，会从被释放之处沿256°方位跑20.6米，然后以越来越大的圈搜索——表明它遵循的是向量而非任何地标。
:::
:::

## 地图

除非动物知道自己相对家的位置，否则罗盘对归巢毫无用处。揭示罗盘定向与真正导航之别的经典实验是在野生迁徙鸟类上做的。

每年秋天，繁殖于波罗的海周边的椋鸟向西南偏西穿过荷兰，到英格兰南部、法国北部与比利时越冬。1950年代，A. C. Perdeck 在荷兰的迁徙途中捕获约11,000只椋鸟，为它们环志，并用飞机运到瑞士放飞。环志鸟的回收显示出年龄组间的鲜明差别。第一次迁徙的幼鸟继续向西南偏西飞，仿佛仍身在荷兰，结果落在法国与西班牙——其种群正常越冬范围之外。成鸟则对位移作出校正，向西北飞，飞向正常的越冬地。Perdeck 1958年的论文表明，幼鸟使用向量导航（一个罗盘方向），而有经验的成鸟拥有地图。后来用带标记鸟类做的位移实验，如白冠带鹀横贯北美大陆的位移（Kasper Thorup、Martin Wikelski 及同事，2007），得到了同样的结果。

地图如何运作？两种假说得到的支持最多。

**嗅觉地图。** Floriano Papi 及同事（1972年起）发现，被剥夺嗅觉的信鸽——切断嗅神经或麻醉嗅黏膜——从不熟悉的地点归巢很差，而其罗盘定向完好。人们认为，鸽子在鸽舍学会气味与带来这些气味之风向的关联，构建大气化学物质梯度的地图。这一想法长期充满争议，部分因为不同鸽群的结果不一，但对海鸟的跟踪实验（被剥夺嗅觉的鹱在海上无法归巢，而对照鸟能）使它得到延伸。

**磁地图。** 地磁场在地表有系统的变化：从磁赤道向两极，强度增大，倾角变陡。

::: proposition 偶极场的倾角与强度 {#prop-dipole}
把地场近似为与自转轴对齐的偶极场，则在磁纬度 $\lambda$ 处，**倾角** $I$（场线与水平面成角向下）与总**强度** $F$ 满足

$$
\tan I = 2\tan\lambda, \qquad F = F_0\sqrt{1 + 3\sin^2\lambda},
$$ {#eq-dipole}

其中 $F_0$ 是磁赤道处的强度（约30 μT）。两极的强度是赤道的两倍。实际场大幅偏离偶极场，并以年为尺度缓慢变化（长期变化），所以等倾线与等强度线并不平行于纬线，而且在许多地区二者成角相交，这在原理上允许一个双坐标地图。
:::

::: example 作为纬度线索的倾角 {#ex-inclination}
利用 [[#eq-dipole]]，求磁纬度30°与50°处的倾角，以及50°附近每度纬度的倾角变化。若海龟能察觉零点几度的倾角差异，仅凭倾角能把它在纬度上定位到多精确？
::: solution
30°处：$\tan I = 2\tan30° = 1.155$，$I = 49.1°$。50°处：$\tan I = 2\tan50° = 2.384$，$I = 67.2°$。在49.5°与50.5°之间，$I$ 变化约0.72°，所以一度纬度（约111 km）对应约0.7°的倾角。若动物能察觉比如说0.2°（一个示意值）的差异，仅凭倾角就能把它在纬度上定位于约30公里之内——但只沿南北轴。经度需要第二个坐标，如强度，其等值线与倾角的等值线成角。
:::
:::

人工磁场中的动物实验支持多个物种具有磁地图。Kenneth Lohmann 及同事测试了来自佛罗里达的幼年蠵龟（*Caretta caretta*），它们孵化后随洋流在北大西洋马尾藻海周围周游。暴露于环流边缘某处（例如葡萄牙近海北部）磁场下的幼龟，朝能把它们留在环流之内的方向游动。暴露于捕获地以北337 km 处地点磁场下的幼年绿海龟（*Chelonia mydas*）向南游，而暴露于同等距离之南地点磁场下的个体向北游（Lohmann 及同事，2004）。被向东物理位移约1000公里的欧亚芦苇莺（*Acrocephalus scirpaceus*）调整了自己的定向以作补偿（Nikita Chernetsov、Dmitry Kishkinev 与 Henrik Mouritsen，2008）；而在后来一项只改变笼周磁偏角的"虚拟位移"实验中，它们重新定向，仿佛真的被位移了（Chernetsov 及同事，2017），提示磁偏角可充当东西方向的线索。磁地图有多普遍、其背后是何种感觉，都是活跃的问题。

::: warning "动物知道自己在去哪"与"迁徙是天生的"
初次上路的幼年迁徙者通常不知道自己的目的地：它们遵循一条遗传的向量，而这只有在它们从惯常之地出发时才奏效，Perdeck 的幼椋鸟正是如此。成鸟拥有从经验学来的地图。反过来，说迁徙"天生如此"，忽略了幼鸟要学习夜空哪一部分是北（Emlen 的彩鹀）、要拿各罗盘彼此校准，而且在鹤与雁等某些物种中还要向亲代学习路线。与一切行为一样，迁徙程序经由遗传倾向与经验的相互作用发育而成（[[behaviour/mechanisms-of-behaviour]]）。
:::

::: quiz
某种迁徙鸟的幼鸟在首次迁徙前于繁殖地被捕起，向东运走1000公里后在秋天放飞。若它按遗传向量导航，最终会到哪里？
- [ ] 其种群正常的越冬地
- [x] 正常越冬地以东约1000公里处
- [ ] 放飞地点，因为它们在那里无法定向
- [ ] 回到繁殖地
::: solution
向量导航是从出发之地飞完遗传的方向与遗传的距离。整条路线随位移平移，所以这些鸟会落在正常越冬地以东约1000公里处，正如 Perdeck 的幼椋鸟落在其正常越冬地之西南。有地图的成鸟则会校正。
:::
:::

## 为何迁徙、迁徙多远

迁徙代价高昂：旅程的能量消耗、途中风暴、天敌与饥饿的风险、以及花在赶路而非繁殖上的时间。当利用一地季节性丰饶的资源、并逃离另一地季节性匮乏的好处，超过这些成本时，迁徙便受青睐。许多种群是**部分迁徙**的：有些个体迁徙，有些不迁。一个个体迁徙与否，常取决于其体况、年龄、性别或等级，故这一决策是一种条件策略；例如在欧洲乌鸫与欧洲知更鸟中，雌鸟与幼鸟比成年雄鸟更可能迁徙，而成年雄鸟能受益于提早占据繁殖领地。

### 育肥与迁徙速度

长距离迁徙者在飞行与**中途停歇**之间交替，停歇期间取食并储存脂肪。离开一处停歇地之前，迁徙者该装载多少燃料？Thomas Alerstam 与 Åke Lindström（1990）把这当作一个最优化问题来处理。

::: proposition 迁徙者的航程 {#prop-range}
由空气动力学理论，携带燃料负荷 $f$（燃料质量占去脂体重的比例）的鸟，其飞行航程近似为

$$
Y(f) = c\Bigl(1 - \frac{1}{\sqrt{1 + f}}\Bigr),
$$ {#eq-range}

其中 $c$ 是一个取决于鸟的体型、形状与飞行效率的常数。航程随燃料负荷增大，但收益递减，因为燃料增加的重量本身也要背负。这是一个在简化假设下导出的近似（飞行速度相对最适值保持恒定，脂肪是唯一燃料）。
:::

要使迁徙的**总时间**最短的迁徙者——对争抢最佳繁殖领地的鸟而言是合理的——应选择其出发燃料负荷，使总体**迁徙速度**最大：单位总时间飞行的距离，其中计入育肥所花的时间。若脂肪以恒定速率 $k$（每天占去脂体重的比例）沉积，且初始有一段安定期 $t_0$，则问题恰呈边际价值定理（[[behaviour/foraging#thm-mvt]]）的形式：当每单位育肥时间的航程边际增益降到总体迁徙速度时，迁徙者就应离开。

::: example 该携带多少燃料？{#ex-fuel}
(a) 利用 [[#eq-range]]，若一只鸟把燃料负荷从 $f = 0.5$ 加倍到 $f = 1.0$，航程增大几倍？(b) 一只时间最省的迁徙者在 $t_0 = 3$ 天的安定期之后，以每天去脂体重 $k = 0.04$ 的速率沉积脂肪。以燃料为单位度量时间（$kt_0 = 0.12$），迁徙速度正比于 $Y(f)/(f + 0.12)$。求最优出发燃料负荷。(c) 若安定期更长，最优值应如何变化？
::: solution
(a) $Y(0.5)/c = 1 - 1/\sqrt{1.5} = 0.184$ 且 $Y(1.0)/c = 1 - 1/\sqrt2 = 0.293$；二者之比为1.60。燃料加倍，航程只增加60 %。

(b) 数值最大化 $(1 - 1/\sqrt{1 + f})/(f + 0.12)$ 得 $f^* \approx 0.41$：鸟应在燃料达到去脂体重约41 %时出发。（这正是从 $(-0.12, 0)$ 引出的直线与航程曲线相切之点，与斑块模型如出一辙。）

(c) 更长的安定期相当于斑块间更长的转移时间；最优停留时间——亦即出发燃料负荷——随之增大。当 $kt_0 = 0.3$ 时，最优值为 $f^* \approx 0.66$。同样，理论预言处在燃料沉积速率更高之地的鸟应以更大的燃料负荷出发；通过在停歇地补充食物进行的实验已在若干物种中证实了这一预言。
:::
:::

### 迁徙行为的进化

迁徙行为可以快速进化。Peter Berthold 及同事在德国南部 Radolfzell 的马克斯·普朗克研究站，通过对黑头林莺（*Sylvia atricapilla*）的长期选育计划表明，迁徙性躁动的量、出现时机与迁徙方向都可遗传；几代人工选择就从部分迁徙的种群育出了迁徙与非迁徙品系。将经西南路线（穿西班牙）迁徙与经东南路线（穿巴尔干）迁徙的种群的黑头林莺杂交，子代呈现居中的、向南的定向（Andreas Helbig，1991）。

最戏剧性的一例发生在自然界。自1960年代以来，越来越多的黑头林莺到不列颠与爱尔兰越冬，而不再去地中海周边。Berthold、Helbig 及同事（1992）捕获在英国越冬的黑头林莺，在德国的鸟舍里繁殖，并在定向笼中测试它们的后代：从未迁徙过的幼鸟定向西北偏西——从中欧到不列颠的方向——而不是像伊比利亚越冬的德国鸟的后代那样定西南。一条有遗传基础的新迁徙路线在约30年间便进化了出来。较温和的冬季、英国庭院里的喂鸟、以及较短旅程带来的更早归抵繁殖地，大概都有利于它；后来的工作发现，在同一区域繁殖的英国越冬个体与伊比利亚越冬个体倾向于同自己迁徙类型的配偶交配——这也许是分化的开端。

::: application 迁徙、气候变化与保护
迁徙者依赖好几个地方，也依赖时间。许多长距离迁徙者靠内部的年钟与日长决定离开热带越冬地的时机，而这些并不追踪繁殖地的变暖。在荷兰，Christiaan Both 与 Marcel Visser（2001）发现，斑姬鹟（*Ficedula hypoleuca*）自非洲抵达的日期，没有像其雏鸟赖以生存的毛虫春季高峰那样提前；在毛虫高峰提前最多的地区，鹟的种群在二十年间下降了约90 %（Both 及同事，2006）。迁徙者还暴露于中途停歇地的生境丧失——黄海潮间带滩涂，东亚-澳大利亚迁飞区塍鹬及其他涉禽关键的加油之地，自二十世纪中叶以来已失去大片面积——以及夜间同灯火建筑的碰撞；一些城市正通过迁徙高峰熄灯来减少碰撞。从光定位器到卫星与无线电标签的跟踪技术（包括自动接收机网络 Motus），如今已能研究个体动物完整的年周期，这对保护它们至关重要。
:::

::: history
Aristotle 相信有些鸟是冬眠或变形而来，而非迁徙，这一观念延续到了十八世纪。环志由 Hans Christian Mortensen 于1899年在丹麦引入，揭示了迁徙路线。Kramer 于1950年前后证明了椋鸟的太阳罗盘，并于1953年提出了地图-罗盘模型；Schmidt-Koenig 的鸽子时钟漂移实验与 Perdeck 的椋鸟位移实验随后于1958年发表。Franz 与 Eleonore Sauer 在1950年代研究了莺类的星空定向，Emlen 的彩鹀天象馆实验发表于1967与1970年。Wiltschko 夫妇于1972年证明了知更鸟的倾角罗盘，Papi 也在同年提出嗅觉地图。Berthold 的黑头林莺研究自1970年代起，揭示了迁徙行为的遗传基础。2000年以来，微型化跟踪揭示了早先的研究者只能推断的旅程——塍鹬横贯太平洋的不间断飞行、北极燕鸥从一极到另一极的迁徙。
:::

::: summary
- 迁徙是持久的、有方向的、季节性的移动，伴有生理准备。定向能力从借地标的陆标导航，经罗盘定向，直到需要地图与罗盘的真正导航。
- 太阳罗盘是时间补偿的：时钟漂移的鸽子偏转约为每小时漂移15°（北半球变慢的漂移为顺时针）。君主斑蝶用的是触角中的钟。
- 夜迁的鸟在巢中幼小时学习天空旋转中心，并将其用作星罗盘（Emlen 的彩鹀）。
- 鸟类的磁罗盘是倾角罗盘，其基础很可能是隐花色素中依赖光的自由基对。
- 沙漠蚁用偏振光罗盘与计步器推算航路，算出归家向量 $-\sum\mathbf{d}_i$。
- 位移实验把向量导航（幼鸟）同拥有地图的真正导航（成鸟）分开。候选地图利用气味与地磁场（$\tan I = 2\tan\lambda$，$F = F_0\sqrt{1 + 3\sin^2\lambda}$），并有鸽、鹱、海龟与莺类的实验支持。
- 最优育肥理论把出发燃料负荷当作斑块停留时间来处理；航程按 $1 - (1 + f)^{-1/2}$ 递减收益式上升。
- 迁徙方向可遗传并能在数十年内进化（英国越冬的黑头林莺）；气候变化给长距离迁徙者造成时间错配。
:::

## 练习

::: exercise 定向的类型 {level=1}
试分类：(a) 一只蜜蜂用蜂巢入口附近熟悉的树返回蜂巢；(b) 笼中一只知更鸟在春天朝东北跳，无论笼子放在哪里；(c) 一只成鸽在被放飞于100公里外一个陌生地点后径直飞回家。
::: solution
(a) 陆标导航。(b) 罗盘定向：不参照任何目标地保持一个固定方向。(c) 真正导航，需要地图也需罗盘。
:::

::: exercise 时钟漂移 {level=1 check="60"}
设太阳方位角每小时移动15°，一只漂移4小时的鸽子应偏离正确方向多少度？
::: solution
$4\times15° = 60°$。
:::

::: exercise 航程与燃料 {level=1 check="0.423"}
利用 [[#eq-range]]，燃料负荷为去脂体重两倍（$f = 2$）时的 $Y(f)/c$ 是多少？保留三位小数。
::: solution
$1 - 1/\sqrt3 = 1 - 0.577 = 0.423$。与 $f = 1$（0.293）相比，让体重增至三倍而非两倍，航程只增加44 %。
:::
:::

::: exercise 归家向量 {level=2 check="sqrt(41)"}
一只蚁向东走4米，再向北走3米，再向西走8米，再向北走2米。它离巢多少米？
::: solution
东：$4 - 8 = -4$；北：$3 + 2 = 5$。距离 $\sqrt{16 + 25} = \sqrt{41} \approx 6.40$ 米。归家向量指向 $(4, -5)$，方位 $\operatorname{atan2}(4, -5) \approx 141°$，东南。
:::
:::

::: exercise 赤道与两极的倾角 {level=2}
利用 [[#eq-dipole]]，磁赤道与磁极处的倾角各是多少？解释倾角罗盘为何在磁赤道失灵，以及跨越赤道的迁徙者必须怎么做。
::: solution
在 $\lambda = 0$，$\tan I = 0$，故 $I = 0$：场线是水平的。$\lambda = 90°$ 时，$\tan I \to \infty$，故 $I = 90°$：场线是垂直的。倾角罗盘靠场线俯入的方向分辨"极地方向"与"赤道方向"；在磁赤道场线不俯，于是罗盘只给出一条没有极性的轴。跨赤道迁徙者必须在越过赤道时切换自己的磁场取向（一路朝"赤道方向"飞，过赤道后再朝"极地方向"），或者在那里依靠别的罗盘。一项对庭园林莺的实验提示，经历水平的场正是触发这一转变的条件。
:::
:::

::: exercise 解读位移实验 {level=2}
一个迁徙种群的成鸟与幼鸟在秋季迁徙途中被捕起，向东北位移800公里后放飞。回收显示，幼鸟继续沿该种群正常的迁徙方向飞行，而成鸟飞向正常的越冬地。(a) 这说明了什么？(b) 成鸟校正后的方向为何可能不完美？(c) 若成鸟也继续沿正常方向飞行，你会得出什么结论？
::: solution
(a) 幼鸟使用向量导航（一个遗传的罗盘方向）；成鸟使用真正导航，它需要一张至少经由一次迁徙的经历学到的地图。(b) 在其未曾经历的区域，它们的地图可能不准；放飞处的线索（气味、磁场梯度）可能更弱或含混；放飞后的风漂移也会影响航迹。(c) 说明成鸟在此情形下也像幼鸟一样依靠罗盘方向——要么它们的地图不延伸到放飞地点，要么这次位移超出了其地图起作用的范围。这并不表明成鸟根本没有地图。
:::
:::

::: exercise 最优出发燃料负荷 {level=2}
参照切线作图，解释为什么在燃料沉积速率高的停歇地，时间最省的迁徙者应以比贫瘠之地更大的燃料负荷出发——尽管在贫瘠之地达到任一给定的负荷要耗时更久。
::: solution
以沉积的燃料为单位度量时间时，安定时间 $t_0$ 在切线作图中对应原点左侧 $kt_0$ 的距离。沉积速率 $k$ 越高，这一点就越靠左（以燃料单位计的安定期越"长"），从它引出的切线就越平，且切于航程曲线的更高燃料负荷处。直观地说，在富饶之地，每一天添上的燃料很多，多留一阵、装满再走是划算的；在贫瘠之地，多留的日子添得很少，尽早带着较少的燃料离开、寄望前方有更好的落脚处才是划算的。此外，利用富饶之地的迁徙者总体迁徙速度也更高。
:::
:::

::: exercise 黑头林莺实验 {level=3}
Berthold 及同事繁殖了在英国越冬的黑头林莺，并在定向笼中测试其鸟舍养大的后代，发现西北偏西的定向。(a) 后代在德国鸟舍中饲养、不与任何成鸟接触，为何重要？(b) 哪些额外证据能表明这一变化是遗传的，而非母方或早期环境效应？(c) 既然英国比伊比利亚更冷，选择为何可能有利于在英国越冬？
::: solution
(a) 为了排除从亲代学习路线或有路线经验：后代从未迁徙，也从未与任何类型的成鸟在一起过，所以它们的定向反映其遗传程序（加上共同的饲养效应，而后者对各组都是相同的）。(b) 杂交与共同园实验：英国越冬鸟与伊比利亚越冬鸟杂交的后代应表现出居中的定向；由另一类型养父母抚育的英国越冬鸟的后代应保持其定向；而且这一差异应在鸟舍中延续数代。Helbig 对西南迁徙者与东南迁徙者的杂交正显示了这样的居中遗传。(c) 可能的优势：旅程更短、死亡率更低；庭院喂鸟器上食物丰富；春天更早归抵繁殖地——英国越冬的鸟对高纬度更早开始的日长增长作出反应而最先抵达，从而得到最好的领地与配偶——与相同越冬类型个体的选型交配更强化了这一点。
:::

::: exercise 这是导航吗？{level=3}
绿海龟在阿松森岛上产卵，那是一小块陆地，离它们位于巴西近海的索饵场约2000公里。请提出两个关于它们如何找到该岛的假说，并设计一个能区分它们的实验或观察。
::: solution
假说1，磁地图：幼龟孵化时对其出生海滩的磁特征（倾角与强度）发生印记，日后沿磁场梯度向它导航。假说2，嗅觉或化学线索：海龟借助随盛行水流自岛上被带下来的化学线索归巢，也许先靠磁地图大致到达正确的区域。区分二者：给一些海龟绑上小磁铁（对照组携带同尺寸的非磁性重物），用卫星标签跟踪它们的洄游——若磁铁妨碍了最后的抵近，则磁线索重要；或分别跟踪被置于岛屿上游与下游处放流的海龟，因为气味假说预言在上游——没有任何气味羽能到达之处——归巢更差。（Paolo Luschi、Susanne Åkesson 及同事做过这类磁铁与跟踪实验；结果表明水或风中携带的线索在最后的抵近中有作用，不过问题仍无定论。）
:::
