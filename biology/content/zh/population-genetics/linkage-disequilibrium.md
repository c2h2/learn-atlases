到目前为止，我们一次追踪一个基因座。但基因位于染色体上，而染色体作为一个整体被传递，只被每次减数分裂中的少数几次交叉切开（[[genetics/linkage-mapping]]）。因此，相邻两个基因座上的等位基因并非每一代都被独立重新洗配，群体中某些特定组合——**单倍型**——会比等位基因频率的乘积所预言的更常见或更罕见。这种非随机关联称为**连锁不平衡**（LD），它在基因组中无处不在：近期突变的周围、刚被选择扫到高频率的基因附近、两个群体混合之后，以及仅仅作为有限群体中漂变的结果。

LD 的重要性有三方面。它是一部历史记录，从中可以读出重组率、选择清除、群体大小与混合的年代。它是一个工具：全基因组关联研究之所以可行，是因为被分型的标记与其未被分型的致病变异处于 LD 之中。它还使其他分析变得复杂，因为处于 LD 的基因座并不独立。本章定义 LD 的度量，展示重组如何瓦解它，解释它如何产生，并展示它如何被使用。

## 单倍型与度量 D

考虑两个基因座，第一个上有等位基因 $A$、$a$，第二个上有 $B$、$b$。一个配子（或一条单倍型——一条染色体的等位基因组合）携带四种组合之一：$AB$、$Ab$、$aB$、$ab$。设其频率为 $x_{AB}$、$x_{Ab}$、$x_{aB}$、$x_{ab}$，而等位基因频率 $p_A = x_{AB} + x_{Ab}$、$p_B = x_{AB} + x_{aB}$，且 $p_a = 1 - p_A$、$p_b = 1 - p_B$。

若两个基因座上的等位基因是独立组合的，则会有 $x_{AB} = p_Ap_B$，如此等等。对独立性的偏离用一个数来度量。

::: definition 连锁不平衡系数 {#def-d}
基因座 $A$ 与 $B$ 之间的**连锁不平衡**为

$$
D = x_{AB} - p_Ap_B = x_{AB}x_{ab} - x_{Ab}x_{aB}.
$$ {#eq-d}

于是 $x_{AB} = p_Ap_B + D$、$x_{ab} = p_ap_b + D$、$x_{Ab} = p_Ap_b - D$、$x_{aB} = p_ap_B - D$。若 $D = 0$，则两基因座处于**连锁平衡**。
:::

$D$ 的两个表达式相等：把四个单倍型频率用 $D$ 表示并代入，$x_{AB}x_{ab} - x_{Ab}x_{aB} = (p_Ap_B + D)(p_ap_b + D) - (p_Ap_b - D)(p_ap_B - D) = D(p_Ap_B + p_ap_b + p_Ap_b + p_ap_B) = D$。这个名字起得不巧：连锁不平衡可以存在于不连锁的基因座之间（位于不同染色体上），而连锁的基因座可以处于连锁平衡。叫作配子阶段不平衡（"gametic phase disequilibrium"）更准确，但很少使用。

$D$ 的符号取决于我们把哪些等位基因标记为 $A$ 与 $B$，其可能范围取决于等位基因频率，这使得原始数值难以比较。常用的标准化度量有两个。

::: definition D′ 与 r² {#def-dprime}
**Lewontin 的 $D'$**（Richard Lewontin，1964）按给定等位基因频率下 $D$ 的最大可能幅值对其标准化：

$$
D' = \frac{D}{D_\mathrm{max}},\qquad D_\mathrm{max} = \begin{cases}\min(p_Ap_b,\ p_ap_B) & D > 0,\\ \min(p_Ap_B,\ p_ap_b) & D < 0.\end{cases}
$$ {#eq-dprime}

$\lvert D'\rvert = 1$ 意味着四种单倍型中至少一种缺失。两基因座在同一单倍型上等位基因状态的**相关系数平方**（每个等位基因编码为0或1）为

$$
r^2 = \frac{D^2}{p_Ap_ap_Bp_b}.
$$ {#eq-r2}

$r^2 = 1$ 意味着只存在两种单倍型，因此一个基因座上的等位基因能完美地预测另一个基因座上的等位基因。
:::

两种度量回答不同的问题。$D'$ 问的是自等位基因产生以来两基因座之间是否发生过重组（或反复突变）：一个新突变产生于一条单倍型上，在一次交叉把它移到另一条背景上之前，总有一种单倍型缺失且 $\lvert D'\rvert = 1$，无论等位基因频率如何。$r^2$ 问的是一个基因座对另一个预测得多么好，这才是关联研究要紧的事；若等位基因频率悬殊，即使 $\lvert D'\rvert = 1$ 它也可以很小。

::: example 由单倍型计数度量 LD {#ex-measures}
在200条已定相染色体的样本中，两个 SNP 的单倍型计数为 $AB$ 90、$Ab$ 30、$aB$ 20、$ab$ 60。计算 $D$、$D'$ 与 $r^2$，并检验两基因座是否处于连锁平衡。
::: solution
单倍型频率：$x_{AB} = 0.45$、$x_{Ab} = 0.15$、$x_{aB} = 0.10$、$x_{ab} = 0.30$。等位基因频率：$p_A = 0.60$、$p_B = 0.55$。

$D = 0.45 - 0.60\times0.55 = 0.12$；验证：$0.45\times0.30 - 0.15\times0.10 = 0.135 - 0.015 = 0.12$。

由于 $D > 0$，$D_\mathrm{max} = \min(0.60\times0.45,\ 0.40\times0.55) = \min(0.27, 0.22) = 0.22$，故 $D' = 0.12/0.22 = 0.55$。

$r^2 = 0.12^2/(0.60\times0.40\times0.55\times0.45) = 0.0144/0.0594 = 0.242$。

对 $n$ 个单倍型的2×2列联表，独立性检验的χ²统计量等于 $nr^2$（[[biostatistics/categorical-data]]）：$\chi^2 = 200\times0.242 = 48.5$，自由度为1，$P < 10^{-10}$。两基因座处于强 LD，且 $AB$ 与 $ab$ 过多。然而 $D' = 0.55$ 表明四种单倍型都以可观的频率存在，所以它们之间发生过重组或反复突变；而 $r^2 = 0.24$ 意味着一个 SNP 只解释另一个位点上约四分之一的变异。
:::
:::

## 重组瓦解 LD

哈迪-魏因贝格比例经一代随机交配即告恢复（[[population-genetics/hardy-weinberg]]）。连锁平衡却不是，因为一条染色体上的两个等位基因结伴同行，除非一次交叉把它们分开。

::: proposition 连锁不平衡的衰减 {#prop-decay}
在无选择、突变或迁移的大随机交配群体中，若两基因座间的重组率为 $c$（$0 \le c \le \tfrac12$），则

$$
D_{t+1} = (1 - c)D_t,\qquad D_t = (1 - c)^tD_0 \approx D_0e^{-ct}.
$$ {#eq-decay}

等位基因频率不变，而 $D \to 0$。
:::

::: proof
第 $t$ 代产生的一个配子要么是非重组的（概率 $1 - c$），此时它是亲本两条单倍型之一的拷贝，因而为 $AB$ 的概率是 $x_{AB}(t)$；要么是重组的（概率 $c$），此时它的 $A$ 基因座等位基因与 $B$ 基因座等位基因来自亲本的两条不同单倍型。随机交配下，那两条单倍型是来自群体的独立随机抽取，所以重组配子为 $AB$ 的概率是 $p_Ap_B$。于是

$$
x_{AB}(t + 1) = (1 - c)\,x_{AB}(t) + c\,p_Ap_B.
$$

两边同减 $p_Ap_B$（它不改变）即得 $D_{t+1} = (1 - c)D_t$。
:::

不连锁的基因座 $c = \tfrac12$，$D$ 每代减半：不同染色体上基因座之间的 LD 几代之内即被抹去。对紧密连锁的基因座它则持续存在。$c = 0.01$（约1 cM，在人中约一兆碱基）时半衰期为 $\ln 2/c \approx 69$ 代；$c = 10^{-4}$（约10 kb）时约为7,000代——大约200,000年的人类历史。

x: 0, 100
y: 0, 0.25
sliders: D0=0.12:0:0.25:0.01; c=0.05:0.001:0.5:0.001
labels: D_t,\ c; D_t,\ c = 1/2
caption: 连锁不平衡的衰减[[#eq-decay]]：初始 $D_0$（默认0.12，即[[#ex-measures]]中的值）在重组率 $c$ 下的衰减，与不连锁基因座（$c = \tfrac12$）对照——后者的不平衡几代即消失。把 $c$ 降到0.005（半厘摩），可见100代后仍有60 %的初始不平衡留存。整个衰减过程中等位基因频率毫不改变：改变的只是等位基因在染色体上的组合方式。
:::

::: intuition 为什么哈迪-魏因贝格一代就够而连锁平衡不够
随机交配随机地配对配子，所以它立即把个体携带哪两条*单倍型*随机化。但它对单倍型自身的组成无能为力。只有重组——在双杂合子的减数分裂内部——能从旧单倍型造出新单倍型，且只有比例为 $c$ 的配子是重组的。单个基因座上的平衡关乎基因型，每一代都重新组建；基因座之间的平衡关乎单倍型，而单倍型是被继承的。
:::

### 从基因型到单倍型

实验分型通常报告每个个体在每个基因座上的基因型，而不报告哪些等位基因位于同一条染色体上。对一个或两个基因座纯合的个体，相型是已知的。含糊的情形是**双杂合子** $AaBb$，它可能携带 $AB/ab$（相引）或 $Ab/aB$（相斥）。单倍型频率仍可用最大似然估计，借助**期望最大化（EM）算法**（Laurent Excoffier 与 Montgomery Slatkin，1995，以及其他工作）：猜测单倍型频率；用它们计算每个双杂合子处于相引的概率 $x_{AB}x_{ab}/(x_{AB}x_{ab} + x_{Ab}x_{aB})$（E 步，假定单倍型对符合哈迪-魏因贝格比例）；用这些期望数目重新清点单倍型（M 步）；如此迭代。

```python
INDEX = {'AB': 0, 'Ab': 1, 'aB': 2, 'ab': 3}

def em_haplotypes(counts, iters=50):
    """counts[(gA, gB)]: number of individuals carrying gA copies of A and gB of B.
    Returns estimated frequencies of haplotypes [AB, Ab, aB, ab]."""
    x = [0.25] * 4                                  # starting guess
    for _ in range(iters):
        n_hap = [0.0] * 4                           # expected haplotype counts
        for (gA, gB), n in counts.items():
            if gA == 1 and gB == 1:                 # double heterozygote: AB/ab or Ab/aB?
                cis, trans = x[0] * x[3], x[1] * x[2]
                f = cis / (cis + trans)             # E-step: P(phase AB/ab | genotype)
                for h, w in ((0, f), (3, f), (1, 1 - f), (2, 1 - f)):
                    n_hap[h] += n * w
            else:                                   # at most one heterozygous locus: phase known
                alleles_A = 'A' * gA + 'a' * (2 - gA)
                alleles_B = 'B' * gB + 'b' * (2 - gB)
                for a, b in zip(alleles_A, alleles_B):
                    n_hap[INDEX[a + b]] += n
        x = [h / sum(n_hap) for h in n_hap]         # M-step
    return x

counts = {(2, 2): 202, (2, 1): 135, (2, 0): 22,
          (1, 2): 90,  (1, 1): 300, (1, 0): 90,
          (0, 2): 10,  (0, 1): 60,  (0, 0): 90}
print([round(v, 3) for v in em_haplotypes(counts)])   # [0.45, 0.15, 0.1, 0.3]
```

这个程序清单中999个个体的基因型计数是由单倍型频率 $0.45, 0.15, 0.10, 0.30$ 生成的，算法把它们找了出来，尽管其中300个个体——几乎三分之一——是相型未知的双杂合子。现代定相程序把这一思想推广到一次处理数千个连锁 SNP，利用的是群体中单倍型是有限数目的祖先单倍型的嵌合体这一事实。

## LD 从何而来

既然重组总是侵蚀 LD，为什么还有 LD 存在？有几个过程在不断产生它。

**突变。** 一个新突变产生于一条染色体上，所以它最初与该染色体上所有其他基因座的等位基因完全关联：与每一个连锁的多态性都是 $\lvert D'\rvert = 1$。这一关联只随重组把新等位基因移上其他背景而衰减。因此年轻等位基因被长单倍型环绕；年老等位基因的则短。

**漂变。** 在有限群体中，单倍型频率像等位基因频率一样漂变，所以即使中性基因座之间也会出现随机关联。在漂变产生 LD 与重组摧毁 LD 之间的平衡上，John Sved（1971）证明了

$$
\E[r^2] \approx \frac{1}{1 + 4N_ec},
$$ {#eq-sved}

因此中性基因座之间 LD 的典型强度取决于乘积 $4N_ec$，即**群体重组率** $\rho$。（在 $n$ 条染色体的样本中，抽样误差给期望 $r^2$ 加上大约 $1/n$，小样本时这很要紧。）William Hill 与 Alan Robertson 早在1968年就分析过漂变产生的 LD 的动力学。

::: example 10,000个体的群体中的 LD {#ex-sved}
一个 $N_e = 10^4$、重组率为每兆碱基1 cM（每碱基对 $c \approx 10^{-8}$）的物种中，相距10 kb 的两个 SNP 之间的期望 $r^2$ 是多少？相距100 kb 呢？若 $N_e$ 为 $10^6$ 又会是多少？
::: solution
在10 kb 处，$c = 10^4\times10^{-8} = 10^{-4}$ 且 $4N_ec = 4$，故 $\E[r^2] \approx 1/5 = 0.20$。在100 kb 处，$c = 10^{-3}$ 且 $4N_ec = 40$，故 $\E[r^2] \approx 1/41 = 0.024$。当 $N_e = 10^6$ 时，$4N_ec$ 大100倍，10 kb 处的 $\E[r^2]$ 约为 $0.0025$：LD 在几百个碱基对之内衰减殆尽。这就是为什么 $N_e$ 为 $10^4$ 量级的人类的关联研究可以用几十万到几百万个标记，而在群体极大的物种——如 *Drosophila* 或许多异花授粉的植物——LD 的作用范围太短，那种办法行不通；反过来，有效大小很小或有效重组很少的驯化动物与自交植物，则表现出跨越兆碱基的 LD。
:::
:::

x: 0, 200

sliders: N=10000:1000:100000:1000; M=1000:100:100000:100

:::

**混合与群体结构。** 当等位基因频率不同的两个群体混合时，凡是两者间频率不同的基因座对之间都会出现 LD，无论连锁与否，因为某一祖先来源的个体在两个基因座上都带着该祖先来源的典型等位基因。

::: proposition 混合造成的 LD {#prop-admixture}
若一个群体由两个源群体按比例为 $c_1$ 与 $c_2 = 1 - c_1$ 混合而成，两源群体各处于连锁平衡、等位基因频率为 $p_{A,i}$ 与 $p_{B,i}$（$i = 1, 2$），则混合后立即有

$$
D = c_1c_2\,(p_{A,1} - p_{A,2})(p_{B,1} - p_{B,2}).
$$ {#eq-admixture}

此后随机相互交配，按[[#prop-decay]]，$D$ 以每代 $c$ 的速率衰减。
:::

::: proof
混合体中 $x_{AB} = c_1p_{A,1}p_{B,1} + c_2p_{A,2}p_{B,2}$，而 $p_A = c_1p_{A,1} + c_2p_{A,2}$，$p_B$ 类似。展开 $x_{AB} - p_Ap_B$ 并利用 $c_1 - c_1^2 = c_2 - c_2^2 = c_1c_2$：

$$
D = c_1c_2\,(p_{A,1}p_{B,1} + p_{A,2}p_{B,2} - p_{A,1}p_{B,2} - p_{A,2}p_{B,1}) = c_1c_2(p_{A,1} - p_{A,2})(p_{B,1} - p_{B,2}).
$$
:::

由于混合 LD 以由 $c$ 决定的速率衰减，它沿遗传距离延伸的远近就给混合定年。不连锁基因座之间它几乎立刻消失；相距 $d$ Morgans 的基因座之间，$t$ 代后它大致按 $e^{-dt}$ 衰减。对全基因组的这一衰减进行拟合即可估计 $t$——把人类历史上从几代前到几千年前的混合事件定年的那类方法背后的原理即是如此（Po-Ru Loh 及同事，2013，以及其他工作）。现今非洲人之外的现代人从尼安德特人继承的染色体片段的长度，随每一代重组而缩短，曾被用同样的方法把那一次混合定年为数万年前（Sriram Sankararaman 及同事，2012；[[evolution/human-evolution]]）。

::: example 两群体混合产生的 LD {#ex-admix}
两个群体的等位基因频率为 $p_A = 0.9$、$p_B = 0.8$（群体1）与 $p_A = 0.1$、$p_B = 0.2$（群体2），各自处于连锁平衡。它们以相等数量合并并随机交配。若两基因座相距10 cM（$c = 0.1$），混合后立即以及10代后的 $D$ 是多少？若不连锁呢？
::: solution
由[[#eq-admixture]]，$D = 0.5\times0.5\times(0.9 - 0.1)(0.8 - 0.2) = 0.25\times0.8\times0.6 = 0.12$。混合体中 $p_A = p_B = 0.5$，故 $D_\mathrm{max} = 0.25$、$D' = 0.48$。$c = 0.1$ 时经10代，$D = 0.12\times0.9^{10} = 0.042$。不连锁基因座，$D = 0.12\times0.5^{10} = 1.2\times10^{-4}$，基本为零。不连锁基因座之间的 LD 是极近代混合的标志，或者是样本中持续存在的结构的标志（针对基因座对的"Wahlund effect"）。
:::
:::

::: example 混合事件的定年 {#ex-date}
在一个混合群体中，标记对之间由混合诱导的平均 LD 按其遗传距离 $d$ 进行测量。相距约1 cM 的标记对（$d = 0.01$ M）比相距约5 cM 的（$d = 0.05$ M）大3.3倍。设一次混合脉冲随后随机交配，以每代29年计，估计它发生在何时。
::: solution
$t$ 代后，距离 $d$（以 Morgans 计）处的 LD 正比于 $(1 - c)^t \approx e^{-dt}$（$d$ 小时），且比例常数在所有距离上相同——由[[#eq-admixture]]决定。于是 $0.05$ M 处与 $0.01$ M 处的 LD 之比为 $e^{-0.04t} = 1/3.3 = 0.30$，故

$$
t = \frac{-\ln 0.30}{0.04} = \frac{1.20}{0.04} = 30\ \text{代},
$$

约870年。取比值可消去未知的振幅——它取决于混合比例与等位基因频率差。实际方法对许多距离、成千上万个标记对拟合整条衰减曲线，而一条不是单一指数的曲线则揭示出数次脉冲或持续的基因流。
:::
:::

**选择。** 选择以两种方式产生 LD。若适合度取决于两个基因座上等位基因的组合（**上位效应**），受青睐的组合就会互相关联；这在紧密连锁的基因座之间维持 LD，如控制蝴蝶拟态多型或报春花属植物花柱异长的超级基因，它们由倒位或极低的重组维系在一起。而一个基因座上的选择会把连锁的中性变异一并拖走——这是最重要的情形，我们现在就来讨论。

## 搭车与选择清除

当一个有利的新突变产生并扩散至固定时，它所在的那段染色体也随之扩散。碰巧位于那条原始单倍型上的中性等位基因频率也跟着上升——它们在**搭车**——而该区域的变异被扫荡殆尽。John Maynard Smith 与 John Haigh 于1974年描述了这一现象。

受影响区域有多大？按[[population-genetics/selection-models]]中的清除时间，取 $p_0 \approx 1/2N$ 并计入漂变主导的缓慢早期阶段，一个选择系数为 $s$（纯合子优势）的加性等位基因从单个拷贝清除至固定约需 $(4/s)\ln(2N_es)$ 代。在重组率为 $c$ 处的一个中性位点，若一次交叉在该单倍型尚稀少时把它从受青睐的单倍型上移走，它就逃脱了清除。粗略地说，$c$ 远小于 $s/\ln(2N_es)$ 的位点会被拖走并失去变异，而 $c$ 远大于它的位点几乎不受影响。$s = 0.01$、$N_e = 10^4$ 时，$\ln(2N_es) = \ln 200 = 5.3$，因此多样性强烈下降的区域的 $c$ 为 $0.002$ 量级，在人类中约几十万碱基。清除会留下特征性的信号：

1. 选择位点周围**多样性降低**，并随距离恢复。
2. **罕见变异过剩**——新突变在被扫荡的单倍型上积累——以及区域边缘**高频衍生等位基因的过剩**，由 Tajima 的 $D$ 等统计量检测（[[population-genetics/neutral-theory]]）。
3. 当清除是近期的或未完成时存在**又长又高频的单倍型**，因为重组来不及瓦解它。Pardis Sabeti 及同事（2002）把它变成了**扩展单倍型纯合度**检验：一个高频且单倍型异常长的等位基因必然年轻；而若它既年轻又常见，它就是快速上升的——比漂变所能允许的更快。

在整个基因组上，反复清除的累积效应（连同**背景选择**——随有害突变一并去除连锁的中性变异）是核苷酸多样性与局部重组率之间的正相关，最早由 David Begun 与 Charles Aquadro（1992）在 *D. melanogaster* 中展示。突变率解释不了这一格局，连锁的选择却能：重组稀少的区域受连锁位点上选择的影响更强。

::: application 乳糖酶持续与选择的信号
多数哺乳动物断奶后失去消化乳糖的能力，因为乳糖酶基因 *LCT* 的表达下降。在许多欧洲、非洲与中东祖先来源的人中，表达持续到成年（乳糖酶持续），其原因是 *LCT* 上游一个增强子内的几个不同变异，它们位于相邻基因 *MCM6* 之中。欧洲最常见的变异——*LCT* 上游13,910 bp 处的一个 `C`→`T` 改变——位于一条单倍型上，该单倍型在北欧以高频不间断地延伸超过一兆碱基（Todd Bersaglieri 及同事，2004）——对该频率的等位基因而言长得远远超出预期，是人类基因组中近期正向选择最强的信号之一。古 DNA 显示这一变异在欧洲早期农夫中很罕见，主要是在最近几千年内上升的。具有相似效应的不同变异在东非游牧群体中独立扩散（Sarah Tishkoff 及同事，2007）：同一调控区域上选择造成的趋同进化。
:::

## LD 在基因组分析中

**关联研究。** 全基因组关联研究（GWAS）在众多个体中检验标记与某性状的关联（[[genomics/association-studies]]）。致病变异通常不在被分型的标记之中；它是通过与它处于 LD 的一个邻近标记被检测到的。若致病变异的效应为 $\beta$、标记与它的相关为 $r^2$，则标记上的关联信号被稀释：要以同样的统计功效检测到它，需要约 $1/r^2$ 倍的个体数（Jonathan Pritchard 与 Molly Przeworski，2001）。这催生了国际 HapMap 计划（2005）与用于捕获常见变异的**标签 SNP** 的挑选。同样的 LD 使人们难以确定一个关联区域中许多相关变异里哪一个是致病的——即**精细定位**问题——也解释了为什么在一个群体中发现的关联在不同 LD 格局的其他群体中常常不能完全重复。

**重组图谱。** 由于 LD 随距离的衰减取决于 $4N_ec$，样本中的 LD 格局可用来估计细尺度的重组率。这类基于 LD 的图谱，连同精子中的直接测量（Alec Jeffreys 及同事，2001），表明人类的重组集中在宽1–2 kb 的**热点**中，热点之间隔着重组稀少的长区域，这造成 LD 的区块状格局。2010年，三个研究组证明结合特定 DNA 模体的蛋白质 PRDM9 决定了人类与小鼠中大多数热点的位置。

**历史。** LD 格局记录群体历史。经历过瓶颈的群体——如离开非洲的那些——其 LD 延伸的距离比非洲群体更长，与后者更大的长期有效大小一致。不同距离基因座之间 LD 的水平甚至可用来估计 $N_e$ 随时间的改变，因为远距基因座之间的 LD 反映近期的 $N_e$，近距基因座之间的 LD 反映更古老的 $N_e$。

::: warning "连锁不平衡意味着基因座是连锁的"与"LD 意味着变异互作"
LD 是群体中的一种统计关联。它可由混合、样本中的群体结构或选择在**不连锁**的基因座之间产生，而紧密连锁的基因座之间它可以不存在。LD 也不意味着变异在功能上互作，或其中任何一个影响性状：在关联研究中，与致病变异强 LD 的标记表现出关联，而自己不发挥任何作用。而连锁——染色体上的物理邻近，在家系中依共分离来度量（[[genetics/linkage-mapping]]）——是基因组的属性，在每个群体中都相同，而 LD 则随群体而变。
:::

::: quiz
GWAS 中与某疾病关联的一个 SNP 与真正的致病变异的 $r^2 = 0.2$。与对致病变异本身分型相比，要以同样的统计功效检测到该关联，大约需要几倍的个体数？
- [ ] 0.2倍
- [ ] 2倍
- [x] 5倍
- [ ] 25倍
::: solution
标记上的关联检验统计量相对致病变异处按因子 $r^2$ 缩小，所以同一功效所需的样本量按 $1/r^2 = 5$ 缩放。标记不完备正是稀有变异研究需要测序而非芯片的原因之一——稀有变异常与常见标记 SNP 相关很弱。
:::
:::

::: history
Herbert Jennings（1917）与 Robert Robbins（1918）对模型交配系统证明了连锁基因座之间的关联按重组决定的速率衰减。Richard Lewontin 与小岛研一（1960）在一项二基因座选择的研究中引入了系数 $D$，Lewontin 于1964年定义了 $D'$；William Hill 与 Alan Robertson（1968）分析了漂变产生的 LD 并在此背景下引入了 $r^2$，John Sved（1971）把它的期望与 $N_ec$ 联系起来。Maynard Smith 与 Haigh 的搭车论文（1974）以及 Kaplan、Hudson 与 Langley 对清除的并合处理（1989）开创了基因组范围的选择搜寻。人类基因组中单倍型区块与重组热点的发现（Mark Daly 及同事，以及 Alec Jeffreys 及同事，2001年）、HapMap 计划（2005）与最早的全基因组关联研究（2005年起）使 LD 成为人类遗传学的核心工具。
:::

::: summary
- 连锁不平衡 $D = x_{AB} - p_Ap_B = x_{AB}x_{ab} - x_{Ab}x_{aB}$ 度量单倍型上等位基因的关联（[[#def-d]]）；$D'$ 把它缩放到其最大值，$r^2 = D^2/(p_Ap_ap_Bp_b)$ 是相关系数的平方（[[#def-dprime]]）。对 $n$ 个单倍型，$\chi^2 = nr^2$ 检验 $D = 0$。
- 随机交配一代不能去除 LD；重组能够，速率为 $c$：$D_t = (1 - c)^tD_0$（[[#prop-decay]]）。
- 单倍型频率可由未定相的基因型用 EM 算法估计。
- LD 由新突变产生（最初 $\lvert D'\rvert = 1$）、由漂变产生（$\E[r^2] \approx 1/(1 + 4N_ec)$）、由混合产生（$D = c_1c_2\Delta p_A\Delta p_B$，[[#prop-admixture]]）、由上位性选择产生，也由搭车产生。
- 一次选择清除在 $c$ 为 $s/\ln(2N_es)$ 量级的区域内降低多样性，并留下长的高频单倍型；连锁的选择使多样性与重组率相关。
- LD 使关联研究成为可能（统计功效依 $r^2$ 缩放），揭示重组热点，并记录瓶颈与混合的年代。
:::

## 习题

::: exercise 计算 D {level=1 check="0.05"}
两个基因座的单倍型频率为 $x_{AB} = 0.35$、$x_{Ab} = 0.15$、$x_{aB} = 0.25$、$x_{ab} = 0.25$。计算 $D$。
::: solution
$p_A = 0.5$、$p_B = 0.6$，故 $D = 0.35 - 0.30 = 0.05$。验证：$0.35\times0.25 - 0.15\times0.25 = 0.0875 - 0.0375 = 0.05$。
:::
:::

::: exercise LD 的衰减 {level=1 check="0.0625"}
两个不连锁基因座（$c = \tfrac12$）$p_A = p_B = 0.5$，从最大可能的不平衡 $D_0 = 0.25$（只存在 $AB$ 与 $ab$ 两种单倍型）出发。两代随机交配后 $D$ 是多少？
::: solution
$D_2 = 0.25\times0.5^2 = 0.0625$。
:::
:::

::: exercise 半衰期 {level=1 check="693"}
$c = 0.001$ 的基因座之间的 LD 减半需要多少代（按 $\ln 2/c$ 取最接近的整数）？
::: solution
$\ln 2/0.001 = 693$ 代（精确值 $\ln 0.5/\ln 0.999 = 692.8$）。
:::
:::

::: exercise D′ 与 r² {level=2}
对第一道习题的单倍型频率，计算 $D'$ 与 $r^2$，并在400个单倍型的样本中检验 LD。
::: solution
$D > 0$，故 $D_\mathrm{max} = \min(p_Ap_b, p_ap_B) = \min(0.5\times0.4, 0.5\times0.6) = 0.20$、$D' = 0.25$。$r^2 = 0.0025/(0.5\times0.5\times0.6\times0.4) = 0.0025/0.06 = 0.0417$。400个单倍型中，$\chi^2 = 400\times0.0417 = 16.7$，自由度为1，$P \approx 4\times10^{-5}$：LD 显著，但很弱。
:::
:::

::: exercise 期望 r² {level=2 check="1/11"}
一个 $N_e = 5000$ 的群体中，按 Sved 公式，$c = 5\times10^{-4}$ 的中性基因座之间的期望 $r^2$ 是多少？
::: solution
$4N_ec = 4\times5000\times5\times10^{-4} = 10$，故 $\E[r^2] \approx 1/11 = 0.091$。
:::
:::

::: exercise 混合 LD {level=2 check="0.0256"}
一个群体由80 %的群体1（$p_A = 0.7$、$p_B = 0.6$）与20 %的群体2（$p_A = 0.3$、$p_B = 0.2$）混合形成，两者各处于连锁平衡。混合后立即的 $D$ 是多少？
::: solution
由[[#eq-admixture]]，$c_1c_2 = 0.8\times0.2 = 0.16$，且 $(0.7 - 0.3)(0.6 - 0.2) = 0.16$，故 $D = 0.16\times0.16 = 0.0256$。不相等的混合比例会减小不平衡：$c_1c_2$ 的最大值为 $\tfrac14$，在比例相等时达到。
:::
:::

::: exercise 数据中的清除 {level=2}
来自一个群体的100条染色体的样本中，一个300 kb 的区域含5个分离位点，而对重组率相似的300 kb 窗口，全基因组平均为120。在该区域的中心，一个频率0.9的衍生等位基因坐在一条单倍型上，其所有携带者在250 kb 内完全相同。(a) 这提示什么假说？(b) 应排除哪些替代解释？(c) 如何检验这条单倍型相对于其频率是否异常地长？
::: solution
(a) 一次近期的、接近完成的选择清除：一个受青睐的等位基因迅速升到90 %，把它的原始单倍型一并带上，并去除了连锁的变异。

(b) 该区域突变率低；强背景选择（若该区域基因密集且重组低）；分型或比对的伪象（例如重复区域中的低覆盖度）；近期的瓶颈——尽管瓶颈会影响整个基因组而不只是一个区域。局部偏低的重组率也会产生更长的单倍型。

(c) 把它的扩展单倍型纯合度与全基因组其他同频率等位基因的比较（或与重组率和群体史相匹配的中性模拟比较）。单倍型比同频率的其他等位基因长得多的等位基因，相对于其频率而言异常年轻，这指示快速上升——Sabeti 检验的逻辑。
:::
:::

::: exercise 样本结构产生的 LD {level=3}
一位生物学家从两个亚群体各取相等数量的个体，二者在两个不连锁基因座上有差异：亚群体1中 $p_A = 0.8$、$p_B = 0.7$；亚群体2中 $p_A = 0.2$、$p_B = 0.3$。各亚群体都处于连锁平衡。(a) 合并样本中会发现什么 LD？(b) 为什么它在同类连续样本中不会衰减？(c) 这对关联研究意味着什么，问题如何处理？
::: solution
(a) 合并等价于不相互交配的混合：$D = 0.25\times0.6\times0.4 = 0.06$，且 $r^2 = 0.06^2/(0.5\times0.5\times0.5\times0.5) = 0.058$。

(b) 两亚群体互不交配，所以重组从不把两种祖先来源混在一起；关联被每次的样本合并重新造出。若按亚群体分层分析，它就消失。

(c) 在关联研究中，均值在亚群体之间有差异的性状（出于环境或遗传原因）会与两者之间频率有差异的每一个等位基因表现出关联——群体分层造成的假阳性。研究用全基因组基因型的主成分、纳入基因组亲缘度的混合模型、或基于家系的设计来校正这一点（[[genomics/association-studies]]）。
:::
:::

::: exercise 新突变的单倍型 {level=3}
一个新突变 $A$ 一次产生于一条染色体上，该染色体在连锁位点上带着等位基因 $B$，$c = 0.01$；$p_B = 0.4$。该突变经50代漂变到频率 $p_A = 0.1$。(a) 它刚产生后，$A$ 与 $B$ 之间的 $D'$ 与 $r^2$ 是多少（用等位基因频率表示）？(b) 解释为什么50代后 $D'$ 应约为 $(1 - c)^{50} \approx 0.6$，即使 $p_A$ 已经改变。(c) 为什么 $D' = 1$ 时 $r^2$ 仍低？
::: solution
(a) 最初只存在单倍型 $AB$（一个拷贝）、$aB$ 与 $ab$，所以 $x_{Ab} = 0$ 且 $D = p_A - p_Ap_B = p_A(1 - p_B) = p_Ap_b$，当 $p_A$ 很小时它等于 $D_\mathrm{max} = \min(p_Ap_b, p_ap_B)$：$D' = 1$。$r^2 = D^2/(p_Ap_ap_Bp_b) = p_Ap_b/(p_ap_B) = (p_A/p_a)(0.6/0.4)$，$p_A$ 极小时它极小。

(b) 考虑带 $A$ 的染色体中带 $B$ 的比例。它从1出发，每一代中重组把比例为 $c$ 的 $A$ 染色体移到随机背景上，而随机背景带 $B$ 的概率为 $p_B$。所以 $A$ 染色体上相对于 $p_B$ 的 $B$ 过剩量，无论 $p_A$ 如何漂变，每代按 $(1 - c)$ 衰减（漂变改变 $A$ 的拷贝数，但抽取时不理会背景）。过剩量为 $D/p_A$，其最大值为 $p_b$；二者之比 $D'$ 衰减到约 $0.99^{50} = 0.61$。

(c) $r^2$ 度量一个基因座对另一个的预测程度。$p_A = 0.1$、$p_B = 0.4$ 时，即使完全关联（$D' = 1$）也仍有大多数带 $B$ 的染色体不带 $A$，所以知道一条染色体带 $B$ 对判断它是否带 $A$ 几乎无话可说。稀有变异与常见标记的 $r^2$ 通常很低，无论其历史如何。
:::
