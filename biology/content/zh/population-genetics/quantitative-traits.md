身高、产奶量、开花时间、喙深、血压：农业、进化与人类生物学中重要的多数性状并不落入孟德尔式的类别。它们连续变异，在家族中出现却没有简单的比例，并且对环境有反应。二十世纪初，这似乎把“生物统计学家”——用统计方法度量亲属间相似的一派——与研究离散性状的孟德尔学派对立起来。这场冲突的解决，靠的是证明连续变异正是许多小效应的孟德尔基因座加上环境变异所产生：Wilhelm Johannsen 的菜豆纯系（1903）把可遗传变异与环境变异区分开来，Herman Nilsson-Ehle（1909）用几个基因座解释了小麦籽粒颜色的渐变，Edward East（1916）对烟草花长作了同样的工作，而罗纳德·费希尔（R. A. Fisher）1918年的论文从数学上表明，许多基因座上的孟德尔遗传所预言的，恰恰是生物统计学家测得的亲属之间的相关。

单个基因座的遗传模型在[[genetics/extensions-of-mendel]]中引入，育种方程则在[[evolution/natural-selection]]中。本章建立把两者联系起来的理论，遵循费希尔以及 D. S. Falconer 教科书的框架。我们定义基因型值；把一个性状的遗传方差分解为加性与显性组分，这需要等位基因平均效应的概念；推导亲属之间的协方差；并用它们估计遗传率。然后我们考察遗传率意味着什么、不意味着什么，并看现代基因组学研究如何证实了费希尔关于高度多基因性状的图景。用这套理论预测选择之下的进化，是[[population-genetics/response-to-selection]]的主题。

## 表型值及其组分

::: definition 表型值、基因型值与环境偏差 {#def-pge}
一个个体的**表型值** $P$（其测得的性状值）写成一个**基因型值** $G$——该基因型的个体在群体诸环境中的平均表型——与一个均值为零的**环境偏差** $E$ 之和：

$$
P = G + E,\qquad V_P = V_G + V_E + 2\Cov(G, E).
$$ {#eq-pge}

若基因型随机分布于环境之上，则 $\Cov(G, E) = 0$。若环境的效应在基因型之间不同，就会出现一个额外的**基因型-环境互作**方差 $V_{G\times E}$。
:::

这个分解是一个统计学的分解，相对于一个群体和一组环境而有定义。它并不是说一个性状在每个个体之中是由遗传的一部分和环境的一部分“构成”的——这一点我们还会回来谈。

### 单个基因座：基因型值

考虑一个基因座，等位基因 $A_1$（频率 $p$）与 $A_2$（频率 $q$）处于哈迪-魏因贝格比例。基因型值从两个纯合子的中点起度量：

| 基因型 | $A_1A_1$ | $A_1A_2$ | $A_2A_2$ |
|---|---|---|---|
| 频率 | $p^2$ | $2pq$ | $q^2$ |
| 基因型值 | $+a$ | $d$ | $-a$ |

这里 $a$ 是两个纯合子之差的一半，$d$ 是杂合子的**显性偏差**：$d = 0$ 意味着加性（无显性），$d = a$ 意味着 $A_1$ 完全显性，$\lvert d\rvert > a$ 超显性。群体均值为

$$
M = a(p^2 - q^2) + 2pqd = a(p - q) + 2pqd.
$$ {#eq-mean}

第一项是纯合子的贡献，第二项是杂合子的贡献。我们在[[population-genetics/inbreeding]]见过这个公式，其中近交把杂合子项化为 $2pqd(1 - F)$。

## 平均效应与育种值

亲本传下去的是等位基因而不是基因型：子代从每个亲本各得一份等位基因，而另一份就来自另一位亲本。要从亲本预测子代，我们需要一个等位基因的**平均效应**——携带它在一个群体中平均改变表型多少。

::: definition 基因替换的平均效应、育种值与显性偏差 {#def-alpha}
**基因替换的平均效应**是在群体中以 $A_1$ 等位基因数（0、1或2）对基因型值作最小二乘回归的斜率 $\alpha$。其值为

$$
\alpha = a + d(q - p).
$$ {#eq-alpha}

一个基因型的**育种值**（加性遗传值）$A$ 是这一回归所预测的值，从群体均值起度量：$A_{11} = 2q\alpha$，$A_{12} = (q - p)\alpha$，$A_{22} = -2p\alpha$。**显性偏差** $D$ 是残差，$G - M - A$。
:::

::: proposition 单个基因座的加性与显性方差 {#prop-va}
随机交配下，一个基因座的基因型方差分解为互不相关的加性部分与显性部分：

$$
V_G = V_A + V_D,\qquad V_A = 2pq\,\alpha^2 = 2pq\,[a + d(q - p)]^2,\qquad V_D = (2pqd)^2.
$$ {#eq-va}
:::

::: proof
令 $X \in \{0, 1, 2\}$ 为 $A_1$ 等位基因的数目；在哈迪-魏因贝格比例下，$X$ 服从2次试验、概率 $p$ 的二项分布，所以 $\E[X] = 2p$ 且 $\Var(X) = 2pq$。$G$ 与 $X$ 的协方差为

$$
\Cov(G, X) = p^2\cdot a\cdot2 + 2pq\cdot d\cdot1 + q^2\cdot(-a)\cdot0 - M\cdot2p.
$$

利用 $M = a(p - q) + 2pqd$：$2p^2a + 2pqd - 2pa(p - q) - 4p^2qd = 2pqa + 2pqd(1 - 2p) = 2pq[a + d(q - p)]$。回归斜率为 $\alpha = \Cov(G, X)/\Var(X) = a + d(q - p)$，即[[#eq-alpha]]。回归所解释的方差为 $\alpha^2\Var(X) = 2pq\alpha^2 = V_A$，而最小二乘残差与预测变量不相关，所以 $V_G = V_A + V_D$，其中 $V_D$ 是残差的方差。直接计算：$A_1A_2$ 的残差是 $d - M - (q - p)\alpha$，纯合子类似；代数化简为 $D_{11} = -2q^2d$、$D_{12} = 2pqd$、$D_{22} = -2p^2d$，其方差为 $p^2\cdot4q^4d^2 + 2pq\cdot4p^2q^2d^2 + q^2\cdot4p^4d^2 = 4p^2q^2d^2(q^2 + 2pq + p^2) = (2pqd)^2$。
:::

随机交配下，平均效应也等于（[[population-genetics/selection-models]]的）**平均超额**：把每份等位基因拷贝都计入时，$A_1$ 携带者与 $A_2$ 携带者的平均表型之差。[[#eq-va]]有两个特征关乎其后的一切。

- **显性贡献于加性方差。** 即使是完全显性的等位基因也有 $\alpha \neq 0$，除非 $p = 0$ 或 $1$；替换它时对群体均值的效应，才是子代所继承的东西。加性方差并不是“由加性基因造成的方差”。
- **方差组分依赖等位基因频率。** 同一个基因座，同样的 $a$ 与 $d$，在不同 $p$ 的群体中贡献大不相同的 $V_A$ 与 $V_D$。一个罕见的隐性等位基因对两者几乎都没有贡献；因此遗传率是一个群体的属性，而不是一个性状的属性。

::: example 单个基因座的方差组分 {#ex-va}
某基因座影响小鼠体重：$A_1A_1$ 平均20 g，$A_1A_2$ 18 g，$A_2A_2$ 10 g。$A_1$ 的频率为0.4。求 $a$、$d$、均值、平均效应、$V_A$ 与 $V_D$，并验证它们相加等于 $V_G$。
::: solution
中点为15 g，所以 $a = 5$ g，$d = 3$ g（$A_1$ 部分显性）。由[[#eq-mean]]，$M = 5(0.4 - 0.6) + 2\times0.24\times3 = -1 + 1.44 = 0.44$ g，高于中点，即15.44 g。由[[#eq-alpha]]，$\alpha = 5 + 3\times(0.6 - 0.4) = 5.6$ g。于是 $V_A = 2\times0.4\times0.6\times5.6^2 = 0.48\times31.36 = 15.05$ g²，$V_D = (0.48\times3)^2 = 2.07$ g²。

直接计算：$V_G = 0.16(20 - 15.44)^2 + 0.48(18 - 15.44)^2 + 0.36(10 - 15.44)^2 = 0.16\times20.79 + 0.48\times6.55 + 0.36\times29.59 = 3.33 + 3.15 + 10.65 = 17.13$ g²，等于 $15.05 + 2.07$。尽管该基因座表现出明显的显性，大部分遗传方差（88 %）仍是加性的。
:::
:::

### 许多基因座

对一个受许多基因座影响的性状，只要各基因座处于连锁平衡且不互作，加性方差与显性方差就跨基因座相加。基因座之间的相互作用（**上位效应**）加上**互作方差** $V_I$，它本身又可分解为加性×加性、加性×显性以及更高阶的项：

$$
V_G = V_A + V_D + V_I.
$$ {#eq-vg}

一个值得注意的经验规律是：即使基因的作用在单个基因座的水平上涉及强显性与上位，群体中的大部分遗传方差通常也是*加性*的，因为罕见与常见的等位基因主要通过其平均效应起作用（William Hill、Michael Goddard 与 Peter Visscher，2008）。这是加性模型在育种中如此好用的原因之一。

## 亲属之间的相似

亲属彼此相似，是因为他们共享血缘同源相同的等位基因（[[population-genetics/inbreeding]]）。亲属表型之间的协方差，就是估计方差组分的工具。

::: proposition 亲属之间的遗传协方差 {#prop-cov}
在一个非近交、随机交配的群体中，若无上位效应、亲属之间无共享环境，则两个亲属 $X$ 与 $Y$ 表型的协方差为

$$
\Cov(P_X, P_Y) = 2f_{XY}\,V_A + \Delta_{XY}\,V_D,
$$ {#eq-cov}

其中 $f_{XY}$ 是其亲缘系数，$\Delta_{XY}$ 为二者在一个基因座上两份等位基因均血缘同源相同的概率。特别地：

| 亲缘关系 | $2f_{XY}$ | $\Delta_{XY}$ | 协方差 |
|---|---|---|---|
| 亲子 | $\tfrac12$ | 0 | $\tfrac12V_A$ |
| 半同胞 | $\tfrac14$ | 0 | $\tfrac14V_A$ |
| 全同胞 | $\tfrac12$ | $\tfrac14$ | $\tfrac12V_A + \tfrac14V_D$ |
| 同卵双生子 | 1 | 1 | $V_A + V_D$ |
| 子代与中亲 | — | — | $\tfrac12V_A$ |
:::

::: proof
我们证明亲子这一关键情形；其余情形由血缘同源相同的概率类似地得出。考虑一个基因座。子代的基因型值为 $G_O = A_O + D_O$，其育种值是它所得两份等位基因（各来自一位亲本）的平均效应之和。从亲本 $X$ 所得的那份等位基因是 $X$ 两份等位基因中的随机一份，所以在给定 $X$ 的条件下，其期望平均效应是 $X$ 育种值的一半：$\E[A_O \mid X] = \tfrac12A_X + \tfrac12\E[A_\text{另一亲本}] = \tfrac12A_X$。显性偏差取决于两份等位基因的组合，而子代的组合是新的（一份等位基因来自与 $X$ 无亲缘关系的另一位亲本），所以 $D_O$ 与 $X$ 的基因型不相关。于是 $\Cov(G_X, G_O) = \Cov(A_X + D_X, \tfrac12A_X) = \tfrac12V_A$，用到 $\Cov(A, D) = 0$。环境偏差按假定互不相关。对全同胞，两份等位基因均血缘同源相同的概率为 $\tfrac14$（每个亲本都把同一份传给了两个子代），此时他们共享显性偏差，贡献 $\tfrac14V_D$。对中亲值 $\bar P = \tfrac12(P_M + P_F)$，$\Cov(\bar P, P_O) = \tfrac12(\tfrac12V_A + \tfrac12V_A) = \tfrac12V_A$。
:::

### 遗传率

::: definition 遗传率 {#def-h2}
**广义遗传率**是 $H^2 = V_G/V_P$，一切遗传差异所造成的表型方差的比例。**狭义遗传率**是

$$
h^2 = \frac{V_A}{V_P},
$$ {#eq-h2}

即加性遗传方差所占的比例。它决定亲子之间的相似与选择响应；除另有说明，“遗传率”指的就是它。（Jay Lush 于1937年引入了这些术语。）
:::

由于中亲值的方差为 $\tfrac12V_P$（随机交配且双亲不相关），子代对中亲值的回归斜率为

$$
b_{O\bar P} = \frac{\Cov(\bar P, P_O)}{\Var(\bar P)} = \frac{\tfrac12V_A}{\tfrac12V_P} = h^2,
$$ {#eq-regression}

而子代对单个亲本的回归斜率为 $\tfrac12h^2$。这是估计遗传率最直接的方式；1886年弗朗西斯·高尔顿正是在没有任何遗传理论的情况下，用它首次定量了人类身高的“回归到均值”：高个父母的子女高，但不如其父母那样极端，其程度为因子 $h^2$。

::: example 由亲子回归求遗传率 {#ex-po}
在一个歌带鹀群体中（数值为示意），中亲跗蹠长度的方差为0.31 mm²，中亲与子代跗蹠长度的协方差（子代养在与亲本相同的地区）为0.22 mm²。估计 $h^2$。仅对父亲的子代回归斜率预期是多少？哪些因素会使估计有偏？
::: solution
$h^2 = 0.22/0.31 = 0.71$。对一个亲本的回归斜率应约为 $0.35$。

偏倚：亲子之间的共享环境（领地质量、亲本提供的食物）使协方差膨胀；**配偶外父子关系**——在鸣禽中常见——意味着一些社会父亲并非遗传父亲，从而降低父-子协方差（母-子回归不受影响）；母性效应（卵的大小、育幼投入）使母-子协方差膨胀。交叉抚育实验——在巢之间交换卵——把遗传效应与抚养效应分开，而基于系谱的“动物模型”则一次利用全部亲缘关系。
:::
:::

下面这个程序模拟一个由100个基因座的随机效应决定的加性性状、孟德尔传递、并设定环境噪声使 $h^2 = 0.5$，然后在2,000个家系中把子代对中亲值回归，以检验[[#eq-regression]]。

```python
import random, statistics as st

def simulate(n_fam=2000, loci=100, h2=0.5, seed=1):
    """Additive polygenic trait; returns slope of offspring on mid-parent."""
    rng = random.Random(seed)
    p = [rng.uniform(0.1, 0.9) for _ in range(loci)]
    effect = [rng.gauss(0, 1) for _ in range(loci)]
    def genome():                                   # two allele indicators per locus
        return [(rng.random() < pi, rng.random() < pi) for pi in p]
    def g_value(gen):
        return sum(e * (a + b) for e, (a, b) in zip(effect, gen))
    VA = sum(2 * pi * (1 - pi) * e * e for pi, e in zip(p, effect))   # additive variance
    sd_e = (VA * (1 - h2) / h2) ** 0.5                                # environmental SD
    mid, kid = [], []
    for _ in range(n_fam):
        mum, dad = genome(), genome()
        child = [(rng.choice(m), rng.choice(d)) for m, d in zip(mum, dad)]   # Mendelian transmission
        P = [g_value(x) + rng.gauss(0, sd_e) for x in (mum, dad, child)]
        mid.append((P[0] + P[1]) / 2)
        kid.append(P[2])
    return st.covariance(mid, kid) / st.variance(mid)

print(round(simulate(), 3))    # 0.536
```

估计斜率0.54与真实值 $h^2 = 0.5$ 在其约0.03的标准误内相符。

### 双生子与其他设计

在人类中实验是不可能的，而家庭内部共享环境，所以遗传率靠比较同一环境中不同亲缘级别的亲属来估计。**经典双生子设计**比较同卵双生子（MZ，共享其全部基因）与异卵双生子（DZ，平均共享一半）；两类双胞胎都共享其家庭环境。若 $c^2$ 是由于共享家庭环境的方差比例、且忽略显性，则相关为 $r_\mathrm{MZ} = h^2 + c^2$ 与 $r_\mathrm{DZ} = \tfrac12h^2 + c^2$，于是

$$
h^2 \approx 2(r_\mathrm{MZ} - r_\mathrm{DZ}),\qquad c^2 \approx 2r_\mathrm{DZ} - r_\mathrm{MZ},\qquad e^2 = 1 - r_\mathrm{MZ}
$$ {#eq-twins}

（**Falconer 公式**）。这里的 $h^2$ 包含任何显性与上位效应，因为同卵双生子也共享这些。该设计假定：共享环境对 MZ 对与 DZ 对的相似程度相同；不存在选型交配（选型交配会抬高 $r_\mathrm{DZ}$）；不存在基因-环境互作；这些假定是它的主要弱点，估计要靠其他设计——如领养研究，以及如今的基因组方法——来检验。

::: example 一项双生子研究 {#ex-twins}
对某性状，同卵双生子之间的相关为0.80，异卵双生子之间为0.45。估计 $h^2$、$c^2$ 与 $e^2$。$r_\mathrm{DZ} > \tfrac12r_\mathrm{MZ}$ 与 $r_\mathrm{DZ} < \tfrac12r_\mathrm{MZ}$ 各暗示什么？
::: solution
$h^2 = 2(0.80 - 0.45) = 0.70$，$c^2 = 0.90 - 0.80 = 0.10$，$e^2 = 0.20$。由于 $r_\mathrm{DZ} = 0.45 > 0.40 = \tfrac12r_\mathrm{MZ}$，提示存在共享家庭环境。反之若 $r_\mathrm{DZ}$ 低于 $\tfrac12r_\mathrm{MZ}$，Falconer 公式会给出 $c^2 < 0$，这是不可能的；通常的解释是非加性遗传方差（显性或上位），同卵双生子完全共享它而异卵双生子只部分共享（$\tfrac14V_D$）。注意 $e^2$ 包含测量误差，而测量误差常常相当可观。
:::
:::

### 用近交系进行实验分解

在植物与实验动物中，环境方差可以被直接度量。高度近交系的个体遗传上相同，所以其表型方差就是 $V_E$；两个近交系之间 F1 的表型方差亦然，因为其所有个体都是同一个杂合基因型。F2 发生分离，方差为 $V_G + V_E$。这就是 Johannsen 在其菜豆纯系中使用过的逻辑。

::: example 近交系及其杂交 {#ex-lines}
某植物两个近交系的平均株高为20 cm 与8 cm，各方差2.0 cm²；其 F1 方差2.1 cm²；F2 方差6.0 cm²。估计 F2 的遗传方差与广义遗传率。若所有基因座以加性方式作用、不连锁、且每个效应相同，高株系含有全部“+”等位基因，估计基因座数目。
::: solution
$V_E \approx (2.0 + 2.0 + 2.1)/3 = 2.03$ cm²，所以 $V_G(\mathrm{F2}) = 6.0 - 2.03 = 3.97$ cm²，$H^2 = 3.97/6.0 = 0.66$。

对 $n$ 个效应相等的加性基因座、两系在每个基因座相差 $2a$，亲本差为 $2na = 12$ cm，而 F2 的遗传方差为 $n\cdot\tfrac12a^2$（每个基因座以 $2pq\alpha^2$ 贡献，$p = \tfrac12$、$\alpha = a$）。于是 $(2na)^2/(8\,V_G) = 4n^2a^2/(4na^2) = n$，即 **Castle–Wright 估计量**：$n = 12^2/(8\times3.97) = 144/31.8 = 4.5$。由于效应不等、连锁、以及“+”等位基因在两系之间的散布都会使估计偏小，它是一个*最少*的有效基因座数。现代 QTL 定位与基因组学研究发现的基因座通常远多于这类估计。
:::
:::

## 遗传率意味着什么、不意味着什么

::: warning 遗传率并不是“一个性状有多遗传”
- **它是一个特定群体与环境中诸方差的比。** 改变环境——减小其变异，或改变等位基因频率——$h^2$ 就会变。一个性状在均一环境中遗传率可以很高，在多变的环境中可以很低。
- **它对个体什么也不说。** “遗传率为0.8”并不意味着一个人身高的80 %来自基因；分解式[[#eq-pge]]只对个体之间的变异有定义。
- **高遗传率不意味着性状无法改变。** 人类身高在群体内高度可遗传，然而二十世纪间，随着营养与健康状况的改善，许多国家的平均身高增加了约10 cm 以上——这是一种作用于每个基因型的环境变化。
- **群体之内的遗传率对群体之间的差异什么也不说。** Lewontin（1970）的比喻：把一份遗传上有变异的种子混播在两块田里，一块土肥、一块土瘠。每块田内，株高的差异可能主要是遗传的，但两块田*之间*平均株高的差异则完全是环境的。
:::

::: quiz
在一个所有牛都喂同一种饲料的牛群中，产奶量的遗传率为0.3。农场主改喂更好的饲料，使每头牛的产奶量提高15 %。遗传率大约会怎样？
- [ ] 升高，因为牛现在表达了更多其遗传潜力。
- [ ] 降为零，因为这一改变是环境性的。
- [x] 若饲料按比例提高了所有基因型、且环境变异不变，则大致不变。
- [ ] 环境改变之后它无法定义。
::: solution
遗传率取决于方差，而不取决于均值。均一的改进取动每一个数值而不改变遗传与环境变异的相对贡献（按比例的增加把 $V_A$ 与 $V_E$ 按同一因子缩放）。若新饲料与基因型发生互作——对不同牛只的帮助不同——$V_A$ 或 $V_{G\times E}$ 就可能改变，$h^2$ 随之而变。
:::
:::

### 基因型-环境互作与反应规范

当基因型对环境反应不同时，一个基因型的效应无法用一个数来概括。一个基因型的**反应规范**是其表型作为环境的函数。Jens Clausen、David Keck 与 William Hiesey（1940年代）把在加州不同海拔采集的蓍草 *Achillea* 的无性系种在海平面、中海拔与高山三个地点的种植园中；无性系按株高的排名在园与园之间常常改变。当反应规范交叉时，$V_{G\times E}$ 很大，而“最好”的基因型取决于环境——这对植物育种是核心问题，品种要在许多地点试验。

### 阈值性状

有些性状是离散的——有或无——却像数量性状一样遗传：苏厄尔·赖特（1934）研究过的豚鼠趾数，牛产双胎，以及许多常见疾病的易感性。**易患性-阈值模型**（Falconer 于1965年发展）假定存在一个底层的连续、正态分布的**易患性**，受许多基因与环境因素影响，当易患性超过阈值时性状出现。于是受累者比例决定阈值的位置，而患病个体亲属中增高的频率度量易患性的遗传率。

::: widget distribution
dist: normal
params: mu=0, sigma=1
a: 2.326
b: 5
caption: 易患性-阈值模型。易患性正态分布（标准化为均值0、标准差1），易患性高于阈值——此处位于2.326个标准差处——的个体表现出该性状：阴影面积是群体的1 %。患病个体的亲属的易患性整体上移，移动量正比于易患性的遗传率与他们的亲缘度，所以其中位于同一阈值之外的比例更大。移动阈值 $a$ 可见发病率如何依赖它的位置：均值易患性只移动半个标准差，就把超过2.326的发病率从1 %提高到约3 %。
:::

## 寻找基因：从 QTL 到全基因组关联研究

费希尔1918年的模型假定有“极多”基因座，但在二十世纪的大部分时间里，数量性状背后的基因是未知的。**数量性状基因座**（QTL）定位——在近交系之间的杂交中（自1980年代起，借助分子标记）——定位了基因组中效应显著的区段，其中一些在单基因的水平上被鉴定：例如基因 *tb1*（*teosinte branched1*），其调控序列的改变促成了玉米与其祖先类蜀黍（teosinte）相比分枝的减少（John Doebley 及同事，1997）。但杂交只能检出于亲本系之间存在差异、且效应足够大的基因座。

在远交群体中，**全基因组关联研究**（GWAS）在大样本中检验数十万到数百万个 SNP（[[genomics/association-studies]]）。它们表明，绝大多数数量性状都是惊人地**多基因**。人类身高是研究得最好的例子：双生子与家系研究估计其遗传率约为0.8；一项2022年发表的、涵盖540万人的研究（Loïc Yengo 及同事）鉴定出约12,000个独立关联 SNP，它们合起来解释了欧洲血统人群约40–45 %的表型方差，而在其他血统人群中解释得更少。家系估计与 SNP 估计的遗传率之间的差距（“遗传率缺失”）大部分归因于尚未检出的许多小效应变异、芯片捕获不好的罕见变异、以及标记与因果变异之间不完备的 LD；一部分则可能反映家系估计中的偏倚。

::: application 育种中的基因组预测
育种者一直用源自系谱的加性关系矩阵，从亲属的表型估计育种值（[[population-genetics/inbreeding]]）。自 Theo Meuwissen、Ben Hayes 与 Michael Goddard 2001年的提议以来，他们日益采用**基因组预测**：数万个标记的效应在一个有表型的参考群体中被联合估计，而一头幼畜或一株幼苗的育种值仅凭其基因型即可预测。在约2009年起采用它的奶牛育种中，这极大地缩短了世代间隔，因为公牛不再需要等上好几年去等女儿的产奶记录——而正如[[population-genetics/response-to-selection]]中的育种方程所示，更短的世代间隔直接加快每年的选择响应。
:::

::: history
弗朗西斯·高尔顿的《自然遗传》（*Natural Inheritance*，1889）与皮尔逊（Karl Pearson）的相关方法奠定了遗传的生物统计研究；高尔顿在1886年描述了回归到均值。Johannsen（1903）、Nilsson-Ehle（1909）与 East（1916）以实验表明连续变异具有孟德尔基础。费希尔的《在孟德尔遗传假定下亲属之间的相关》（"The correlation between relatives on the supposition of Mendelian inheritance"，1918）引入了方差分解与平均效应，而赖特的通径分析（1921）给出了平行的处理。Jay Lush 的《动物育种方案》（*Animal Breeding Plans*，1937）把遗传率带入育种。Oscar Kempthorne 与 C. Clark Cockerham 在1950年代把亲属之间的协方差推广到包含上位效应。Falconer 的《数量遗传学导论》（*Introduction to Quantitative Genetics*，1960）成为标准教科书。2007年以来，GWAS 与用无关个体对遗传率所作的基因组估计（Jian Yang、Peter Visscher 及同事，2010）直接检验了无限微效模型，并在很大程度上证实了费希尔的图景。
:::

::: summary
- 表型 $P = G + E$，$V_P = V_G + V_E$（加上协方差与互作项）（[[#def-pge]]）。
- 单基因座值为 $a$、$d$、$-a$ 时：均值 $M = a(p - q) + 2pqd$；平均效应 $\alpha = a + d(q - p)$（[[#def-alpha]]）；$V_A = 2pq\alpha^2$，$V_D = (2pqd)^2$（[[#prop-va]]）。显性贡献于 $V_A$，且两者都依赖等位基因频率。
- 跨基因座，$V_G = V_A + V_D + V_I$；实践中大部分遗传方差是加性的。
- 亲属协方差为 $2f_{XY}V_A + \Delta_{XY}V_D$：亲子 $\tfrac12V_A$，全同胞 $\tfrac12V_A + \tfrac14V_D$，同卵双生子 $V_A + V_D$（[[#prop-cov]]）。
- $h^2 = V_A/V_P$ 是子代对中亲值回归的斜率（[[#def-h2]]）；在强假定下双生子给出 $h^2 \approx 2(r_\mathrm{MZ} - r_\mathrm{DZ})$；近交系与 F1 度量 $V_E$。
- 遗传率是群体与环境特异的方差之比：不是个体的属性，不是可变性的度量，对群体之间的差异保持沉默。
- 反应规范描述基因型-环境互作；阈值性状用一个正态的易患性建模。
- GWAS 表明数量性状高度多基因；已知 SNP 解释遗传率的一部分。
:::

## 习题

::: exercise 基因型值 {level=1 check="-0.4"}
某基因座 $A_1A_1 = 12$、$A_1A_2 = 10$、$A_2A_2 = 8$（无显性）且 $p = 0.4$。从中点度量的群体均值是多少？
::: solution
中点为10，所以 $a = 2$ 且 $d = 0$。由[[#eq-mean]]，$M = a(p - q) = 2\times(0.4 - 0.6) = -0.4$：群体均值为9.6。直接验证：$0.16\times12 + 0.48\times10 + 0.36\times8 = 1.92 + 4.80 + 2.88 = 9.60$。
:::
:::

::: exercise 加性方差 {level=1 check="1.92"}
对上一题的基因座，计算 $V_A$。
::: solution
$\alpha = a = 2$，所以 $V_A = 2\times0.4\times0.6\times4 = 1.92$。无显性时 $V_G = V_A$。
:::
:::

::: exercise 由双生子求遗传率 {level=1 check="0.5"}
某性状 $r_\mathrm{MZ} = 0.6$ 且 $r_\mathrm{DZ} = 0.35$。用 Falconer 公式估计 $h^2$。
::: solution
$h^2 = 2(0.6 - 0.35) = 0.5$；$c^2 = 0.7 - 0.6 = 0.1$；$e^2 = 0.4$。
:::
:::

::: exercise 一个隐性等位基因的贡献 {level=2}
在某完全显性的基因座上（$a = d = 1$），计算 $p = 0.9$、$0.5$ 与 $0.1$ 时的 $V_A$ 与 $V_D$，其中 $p$ 为显性等位基因的频率。哪个等位基因频率使 $V_A$ 最大？在那里 $V_G$ 的多大比例是加性的？
::: solution
$\alpha = 1 + (q - p) = 2q$，所以 $V_A = 2pq(2q)^2 = 8pq^3$，$V_D = 4p^2q^2$。
- $p = 0.9$：$V_A = 8\times0.9\times0.001 = 0.0072$，$V_D = 4\times0.81\times0.01 = 0.0324$。
- $p = 0.5$：$V_A = 8\times0.5\times0.125 = 0.5$，$V_D = 0.25$。
- $p = 0.1$：$V_A = 8\times0.1\times0.729 = 0.583$，$V_D = 0.0324$。

$V_A = 8pq^3$ 在 $d/dq[(1 - q)q^3] = 3q^2 - 4q^3 = 0$ 处最大，即 $q = 0.75$、$p = 0.25$：$V_A = 8\times0.25\times0.4219 = 0.844$，$V_D = 4\times0.0625\times0.5625 = 0.141$，所以 $V_G$ 的86 %是加性的。当隐性等位基因罕见（$p = 0.9$）时，本就不多的遗传方差中大部分是显性方差。
:::
:::

::: exercise 半同胞设计 {level=2 check="0.4"}
在一个林业试验中，树木按半同胞家系种植（同一母亲，父本不同且未知）。家系均值之间的方差相当于2.5 m² 的半同胞协方差，而树高的表型方差为25 m²。估计 $h^2$。
::: solution
$\Cov_\mathrm{HS} = \tfrac14V_A$，所以 $V_A = 10$ m²，$h^2 = 10/25 = 0.4$。半同胞设计的吸引力在于显性不贡献于协方差；但母性效应会。
:::
:::

::: exercise Castle–Wright {level=2 check="8"}
两个近交系的均值相差16个单位。其 F2 的遗传方差为4个平方单位。用 Castle–Wright 估计量估计最少的基因座数。
::: solution
$n = (\mu_1 - \mu_2)^2/(8V_G) = 256/32 = 8$。
:::
:::

::: exercise 解读遗传率的变化 {level=2}
某鱼群体重在孵化场条件下遗传率为0.4，在野外为0.15。给出两个并不互斥的解释。
::: solution
(1) 野外的环境方差更大（食物、温度、密度多变），所以即使 $V_A$ 不变，$V_E$ 更大也使 $h^2 = V_A/V_P$ 更小。(2) 基因型-环境互作：在均一的孵化场条件下生长好的基因型，可能与在野外生长好的并非同一批，这会改变 $V_A$ 并添加 $V_{G\times E}$。不同的等位基因频率（若孵化场群体受过选择或发生过漂变）也会改变 $V_A$。这个对比说明遗传率不是性状的固定属性。
:::
:::

::: exercise 全同胞协方差 {level=3}
(a) 解释为什么全同胞在一个基因座上以概率 $\tfrac14$ 两份等位基因均血缘同源相同、以概率 $\tfrac12$ 共享一份、以概率 $\tfrac14$ 一份也不共享。(b) 由[[#eq-cov]]推导全同胞协方差 $\tfrac12V_A + \tfrac14V_D$。(c) 一项研究中，全同胞相关为0.35，亲子相关为0.25。它们对 $V_D$ 或共享环境暗示了什么？
::: solution
(a) 每个亲本把自己的两份等位基因之一传给每个同胞；同胞们以概率 $\tfrac12$ 从母亲那里得到同一份、以概率 $\tfrac12$ 从父亲那里得到同一份，两者独立。两份都是：$\tfrac14$；恰一份：$\tfrac12$；一份皆无：$\tfrac14$。

(b) 亲缘系数 $f_{XY}$ 是从每个同胞各随机取的一份等位基因血缘同源相同的概率。若他们两份等位基因均血缘同源相同（概率 $\tfrac14$），两次随机取样血缘同源相同的概率为 $\tfrac12$（两次都取到同一亲本传下的那份时）；若共享一份（概率 $\tfrac12$），两次取样必须都取到共享的那些，概率 $\tfrac14$；若一份皆无，则为0。所以 $f_{XY} = \tfrac14\cdot\tfrac12 + \tfrac12\cdot\tfrac14 = \tfrac14$，即[[population-genetics/inbreeding]]中通径计数所得的值。于是 $2f_{XY} = \tfrac12$ 且 $\Delta_{XY} = \tfrac14$，[[#eq-cov]]给出 $\Cov = \tfrac12V_A + \tfrac14V_D$。

(c) 亲子相关给出 $\tfrac12h^2 = 0.25$，$h^2 = 0.5$。若只有加性方差在作用，全同胞相关也应为0.25。多出的0.10等于 $\tfrac14V_D/V_P + c^2$，其中 $c^2$ 是同胞共享环境（同一母亲、同一巢或同窝）造成的方差。若 $c^2 = 0$，则 $V_D/V_P = 0.4$，这将异常地大；共享环境是更可能的解释，而两者只能靠更多种类的亲属关系来分开。
:::
:::

::: exercise 一个阈值计算 {level=3}
一种先天性疾病影响群体的1 %。在易患性标准化为方差1的易患性-阈值模型下，阈值位于均值上方2.326个标准差处。(a) 若一组亲属的均值易患性比群体均值高0.5个标准差（方差相同），他们中有多大比例受累？(b) 定性地解释为什么在给定的遗传率下，亲属发病率与群体发病率之比在更罕见的疾病中更大。
::: solution
(a) 阈值现在位于亲属均值上方 $2.326 - 0.5 = 1.826$ 个标准差，所以受累比例为 $1 - \Phi(1.826) = 0.034$：即3.4 %，是群体发病率的三倍多。（实际中亲属间的方差也略有减小，这是 Falconer 方法的一个精化。）

(b) 正态密度在尾部陡峭下降。均值易患性的给定上移，使分布跨过一个远在尾部的阈值的份额，成比例地大于跨过中部阈值处的份额：移动0.5可使发病率从1 %升到3.4 %（3.4倍），而对位于1个标准差处的阈值只从16 %升到31 %（约2倍）。因此，罕见的阈值性状即使在易患性遗传率中等时，也表现出强烈的家族聚集。
:::
:::
