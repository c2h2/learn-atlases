查尔斯·达尔文把同种植物自交与异交的植株并排种了一行又一行，种了十一年，并于1876年以《植物界的异交与自交效应》（“The Effects of Cross and Self Fertilisation in the Vegetable Kingdom”）为题发表了结果。在他测试的57个物种中的大多数里，异交的植株更高、更健壮、也更丰产。他发现了**近交衰退**，并猜想它对自己的家庭也有意义：他娶了自己的姑表妹艾玛·韦奇伍德。解释要等到孟德尔遗传学。亲属之间的交配使一个个体的两份基因拷贝更可能成为同一祖先基因的拷贝，因此产生纯合子；纯合使隐性有害等位基因暴露；于是适合度下降。

本章要把这一论证定量。我们把近交系数定义为血缘同源相同的概率，看它如何改变基因型频率，并由系谱以及对自交之类规则的交配系统对它加以计算。然后我们区分近交与选型交配——后者只影响参与配偶选择的基因座——并推导近交对性状均值的影响——近交衰退及其镜像杂种优势的基础。最后我们看到基因组数据如今如何直接度量近交。哈迪-魏因贝格比例（[[population-genetics/hardy-weinberg]]）始终是基线，而有限群体中的漂变（[[population-genetics/genetic-drift]]）将被证明是一种近交。

## 血缘同源相同

一个基因的两个拷贝同为同一等位基因可以有两个不同的原因。它们可能**状态相同**：相同的 DNA 序列，无论其历史如何。也可能**血缘同源相同**（identical by descent，IBD）：二者都是共同祖先中同一个基因的拷贝，且传递中没有发生突变。血缘同源相同蕴含状态相同（在无限等位基因观点下，忽略祖先以来的突变）；反过来则不然。

血缘同源相同总是相对于一个**基础群体**而言：我们假装某较早一代中的基因彼此都无亲缘关系，而问此后的传承。既然一个物种中任意两个基因回溯得足够远都会共享祖先（[[population-genetics/genetic-drift]]），“近交的”就意味着“比参照更有亲缘关系”——参照即基础群体。

::: definition 近交系数与亲缘系数 {#def-f}
个体 $X$ 的**近交系数** $F_X$ 是 $X$ 一个随机常染色体基因座上两份基因拷贝相对基础群体血缘同源相同的概率。两个个体 $X$ 与 $Y$ 的**亲缘系数**（或称共祖系数）$f_{XY}$ 是同一基因座上从 $X$ 随机取一份基因拷贝、从 $Y$ 随机取一份，二者血缘同源相同的概率。子代的近交系数等于其双亲的亲缘系数：$F_O = f_{MP}$。
:::

最后这个陈述成立，是因为子代从每个亲本各随机得到一份基因拷贝——恰是定义 $f_{MP}$ 的那一对（Gustave Malécot 于1948年用这些概率术语表述了理论；赖特1922年的原始定义是结合配子间的相关，二者等价）。

::: proposition 近交下的基因型频率 {#prop-genotypes-f}
在一个等位基因频率为 $p$（且 $q = 1 - p$）、每个个体都有近交系数 $F$、且非血缘同源相同的基因独立抽取的群体中，

$$
f(A_1A_1) = p^2(1 - F) + pF = p^2 + Fpq,\qquad f(A_1A_2) = 2pq(1 - F),\qquad f(A_2A_2) = q^2 + Fpq.
$$ {#eq-genotypes-f}

等位基因频率不变，杂合度按因子 $1 - F$ 缩减。
:::

::: proof
以概率 $F$，一个个体的两份拷贝血缘同源相同，因而是同一等位基因：$A_1A_1$ 的概率为 $p$，$A_2A_2$ 的概率为 $q$。以概率 $1 - F$，它们是独立抽取：$A_1A_1$ 的概率为 $p^2$，杂合的概率为 $2pq$，$A_2A_2$ 的概率为 $q^2$。相加，$f(A_1A_1) = Fp + (1 - F)p^2 = p^2 + Fpq$，其余类似。等位基因频率为 $p^2 + Fpq + \tfrac12\cdot2pq(1 - F) = p^2 + pq = p$。
:::

这正是[[population-genetics/hardy-weinberg#def-fis]]中用固定指数写出的比例：近交是正的 $F_\mathrm{IS}$ 的一个成因。

x: 0, 1

:::

### 罕见隐性与近亲婚配

罕见纯合子的相对增加是问题的关键。由[[#eq-genotypes-f]]，近交下隐性纯合子频率与其哈迪-魏因贝格频率之比为

$$
\frac{q^2 + Fpq}{q^2} = 1 + F\,\frac{p}{q},
$$ {#eq-ratio}

$q$ 很小时它非常大。对一个 $q = 0.01$ 的等位基因，表兄妹的子女（$F = 1/16$，下文推导）之比为 $1 + 0.0625\times99 = 7.2$。等位基因越罕见，患病纯合子中双亲有亲缘关系者的比例就越大——Archibald Garrod 于1902年对黑尿症作出过这一观察，这帮助他认识到这是一种隐性孟德尔性状。这是群体遗传学的内容；临床遗传学与遗传咨询见[医学图谱](/learn/medicine/)。

## 由系谱计算近交

要计算一个个体的 $F$，我们追踪它的两个基因可能由同一个祖先基因传承下来的诸条通路。

::: proposition 通径计数 {#prop-paths}
设 $X$ 的父母为 $M$ 与 $P$。对 $M$ 与 $P$ 的每个共同祖先 $A$，以及每条从 $M$ 上溯到 $A$ 再下到 $P$、且不两次经过同一个体的不同通路，设 $n_1$ 为从 $M$ 到 $A$ 的世代数、$n_2$ 为从 $P$ 到 $A$ 的世代数。则

$$
F_X = \sum_{\text{paths}}\left(\tfrac12\right)^{n_1 + n_2 + 1}(1 + F_A).
$$ {#eq-paths}
:::

::: proof
考虑一条通路。$X$ 从 $M$ 得到的基因经 $n_1$ 次传递源自 $A$，每次传递以概率 $\tfrac12$ 传下双亲两份基因中指定的一份；$P$ 的基因经 $n_2$ 次传递同理。固定 $A$ 的两份基因中的一份；沿这条通路，到达 $X$ 的两个基因都是 $A$ 的基因拷贝的概率为 $(\tfrac12)^{n_1 + n_2}$。在此条件下，两个拷贝独立地来自 $A$ 的两份基因：它们以概率 $\tfrac12$ 是 $A$ 同一份基因的拷贝，以概率 $\tfrac12$ 是 $A$ 两份不同基因的拷贝，而后一种情形它们仍以概率 $F_A$ 血缘同源相同。所以贡献为 $(\tfrac12)^{n_1 + n_2}\cdot\tfrac12(1 + F_A)$。不同的通路描述互斥的传承路线，所以其概率相加。
:::

::: example 常见亲属关系 {#ex-pedigree}
设所有祖先都非近交，计算 (a) 半同胞、(b) 全同胞、(c) 表兄妹、(d) 舅甥（一位舅舅与其外甥女）结合的子女的近交系数。
::: solution
(a) 半同胞共享一个亲本 $A$；$n_1 = n_2 = 1$，一条通路：$F = (\tfrac12)^3 = 1/8$。

(b) 全同胞共享双亲，各给出一条 $n_1 = n_2 = 1$ 的通路：$F = 2\times(\tfrac12)^3 = 1/4$。

(c) 表兄妹共享两位祖父母；每条通路 $n_1 = n_2 = 2$：$F = 2\times(\tfrac12)^5 = 1/16$。

(d) 舅舅与外甥女的亲本是全同胞，所以共同祖先是舅舅的双亲（外甥女的祖父母）。从舅舅一侧，$n_1 = 1$；从外甥女一侧，$n_2 = 2$。两条通路：$F = 2\times(\tfrac12)^4 = 1/8$。

每种情形中父母双方的亲缘系数都是同一个数：半同胞 $1/8$、全同胞 $1/4$、表兄妹 $1/16$、舅甥 $1/8$。由同样的规则，亲子间的亲缘系数为 $1/4$，一个个体与自身的亲缘系数为 $\tfrac12(1 + F)$。
:::
:::

对大型系谱，通径计数被**表算法**取代：按出生顺序列出个体，用递推 $f_{XY} = \tfrac12(f_{MY} + f_{PY})$ 填满一个亲缘系数矩阵，其中 $M$ 与 $P$ 是 $X$ 的父母，且 $Y$ 不是 $X$ 的后代。这个矩阵的两倍就是动物育种者用于预测育种值（[[population-genetics/quantitative-traits]]）、动物园管理者用于选配（[[population-genetics/genetic-drift]]）的**加性关系矩阵**。

::: warning "近交意味着群体很小"与"亲属共享一半基因"
系谱意义的近交是个体的属性，可以在大群体中通过亲属间的交配发生；反过来，小群体即使随机交配也会变得近交，因为人人都会沾亲（[[population-genetics/genetic-drift]]）。而“同胞共享一半基因”是血缘同源相同概率的简称，它是相对基础群体度量的：在给定的基因座上，全同胞共享0、1或2份血缘同源相同的拷贝，概率分别为 $\tfrac14$、$\tfrac12$、$\tfrac14$，而两个无亲缘关系的人在其基因组的绝大部分上是*状态相同*的。有关的量是亲缘系数与亲缘度（$2f_{XY}$），实际共享围绕它们的期望上下波动。
:::

## 规则的近交系统

### 自交

许多植物（以及一些动物，如线虫 *Caenorhabditis elegans* 和红树鳉 *Kryptolebias marmoratus*）自交。自交的杂合子产生 $\tfrac14A_1A_1 : \tfrac12A_1A_2 : \tfrac14A_2A_2$，所以其后代一半是纯合子；纯合子只产生纯合子。因此杂合度每代减半：

$$
1 - F_t = \left(\tfrac12\right)^t(1 - F_0).
$$ {#eq-selfing}

就同一性而言，自交的子代从一个亲本得到两份独立的基因拷贝，所以 $F' = \tfrac12(1 + F)$，即该亲本与自身的亲缘系数；迭代即得[[#eq-selfing]]。自交七代之后，原始杂合度只剩下不到1 %——作物与模式生物的近交系正是这样育成的。

多数自交亲和的植物只有部分时间自交。

::: proposition 部分自交下的平衡 {#prop-partial}
在一个比例为 $S$ 的后代由自交产生、其余由随机异交产生的大群体中，近交系数满足 $F' = \tfrac S2(1 + F)$ 并趋于

$$
\hat F = \frac{S}{2 - S}.
$$ {#eq-partial}

反过来，观测到的平衡 $F$ 蕴含自交率 $\hat S = 2F/(1 + F)$。
:::

::: proof
自交的子代近交为 $\tfrac12(1 + F)$，其中 $F$ 是亲本的值；异交的子代的两个基因来自无亲缘关系的随机亲本（在大群体中），近交为0。取平均，$F' = \tfrac S2(1 + F) + (1 - S)\cdot0$。平衡时 $F = \tfrac S2(1 + F)$，所以 $F(1 - S/2) = S/2$ 且 $F = S/(2 - S)$。解出 $S$ 得 $S = 2F/(1 + F)$。逼近是比率为 $S/2$ 的几何级数，所以几代之内即达平衡。
:::

::: example 部分自交的植物 {#ex-selfing}
(a) 某植物群体60 %的种子自交。平衡近交系数是多少？在一个 $p = 0.5$ 的基因座上，有多大比例的个体是杂合的？(b) 另一个群体中，对许多基因座取平均的 $F_\mathrm{IS}$ 为0.3。估计其自交率。
::: solution
(a) $\hat F = 0.6/1.4 = 0.43$，杂合子为 $2pq(1 - F) = 0.5\times0.571 = 0.29$ 而非0.5。

(b) $\hat S = 2\times0.3/1.3 = 0.46$。这一“间接”估计假定近交平衡且 $F_\mathrm{IS}$ 全部由自交造成（双亲近交以及样本内的 Wahlund 效应也有贡献）。植物群体遗传学家将它与由子代阵列作出的直接估计相比较——在子代阵列中，母本种子的基因型能揭示哪些是自交的。自然界中 $S$ 的取值横跨从0（自交不亲和的物种）到接近1（如以自交为主的 *Arabidopsis thaliana*）的全幅。
:::
:::

### 同胞交配与有限群体

若每个个体都与一个全同胞交配，$F$ 的递推涉及前两代。两个同胞的亲缘系数取决于其父母的亲缘系数以及父母自身的近交，结果是（[[#exr-sibs]] 要求给出推导）

$$
F_t = \tfrac14\left(1 + 2F_{t-1} + F_{t-2}\right).
$$ {#eq-sibs}

从 $F_0 = F_{-1} = 0$ 出发，这给出 $F = 0.25, 0.375, 0.5, 0.594, 0.672, \ldots$ 杂合度 $1 - F_t$ 最终每代按因子 $(1 + \sqrt5)/4 = 0.809$ 下降，所以同胞交配每代去除剩余杂合度的约19 %，而自交去除50 %。在大小为 $N$ 的随机交配群体中，近交以每代 $1/2N_e$ 的速率累积，$F_t = 1 - (1 - 1/2N_e)^t$（[[population-genetics/genetic-drift]]）：在一个50个个体的群体中，即使随机交配，$F$ 约10代就达到 $0.1$——相当于祖孙交配一代。

## 选型交配

近交是亲属间的交配。**选型交配**是表型相似的个体间的交配，无论有无亲缘关系；**反选型交配**是相异个体间的交配。

这一区分要紧，因为近交对基因组的每个基因座影响均等（它关乎家谱），而选型交配只影响用于选择配偶的性状所涉及的基因座，以及与它们相关的基因座。考虑对一个共显基因座按基因型的完全选型交配：$A_1A_1$ 只与 $A_1A_1$ 交配，$A_1A_2$ 与 $A_1A_2$ 交配，$A_2A_2$ 与 $A_2A_2$ 交配。纯合的交配产生纯合子；杂合的交配产生一半杂合子。于是杂合子的频率每代减半——与自交相同，但只在这个基因座上。若一个等位基因是显性的，以致 $A_1A_1$ 与 $A_1A_2$ 无法区分、彼此自由交配，杂合子就下降得慢得多。两种情形下等位基因频率都不变，除非这种交配格局还使某些类型得到的配偶更少，那时它就成为一种性选择（[[evolution/sexual-selection]]）。

对多基因性状，正选型交配会在影响该性状的众多基因座之间积累相关，增大该性状在群体中的遗传方差。人类在身高与受教育程度之类性状上有适度的选型交配，这对如何从群体数据估计遗传力与遗传相关是有影响的（[[population-genetics/quantitative-traits]]）。

反选型交配维持变异。开花植物的自交不亲和系统强制实行它：携带某个 *S* 等位基因的花粉不能给带同一等位基因的植株授粉，这有利于稀有等位基因，并在许多物种中维持几十个之多（[[population-genetics/selection-models]]）。哺乳动物是否偏好 MHC 基因型相异的配偶，在小鼠和人中都有研究，结果不一。

::: quiz
哪种观察能把作为群体杂合子缺失之成因的近交与选型交配区分开？
- [ ] 缺失提高了罕见隐性表型的频率。
- [ ] 等位基因频率历代保持不变。
- [x] 缺失在所有基因座上相似，包括那些与选择配偶所依据的性状无关的基因座。
- [ ] 杂合子比哈迪-魏因贝格预言的少。
::: solution
近交使亲属交配，它对基因组每个基因座一视同仁地提高血缘同源相同。选型交配只在影响配偶选择所用性状的基因座（及与之关联的基因座）造成缺失。两者都造成杂合子缺失和更多罕见隐性纯合子，且两者本身都不改变等位基因频率。
:::
:::

## 近交衰退与杂种优势

### 近交对性状均值的影响

考虑一个影响数量性状或适合度组分的基因座，基因型值 $A_1A_1$ 为 $+a$、$A_1A_2$ 为 $d$、$A_2A_2$ 为 $-a$（自两个纯合子的中点起度量；$d$ 度量显性程度，[[population-genetics/quantitative-traits]]）。

::: proposition 近交使均值随 F 线性改变 {#prop-depression}
在基因型频率[[#eq-genotypes-f]]下，该性状的群体均值为

$$
M_F = a(p - q) + 2pqd(1 - F) = M_0 - 2pqd\,F.
$$ {#eq-depression}

对许多以加性方式影响该性状的基因座，$M_F = M_0 - 2F\sum_i p_iq_id_i$：若显性偏差 $d_i$ 以正为主（方向性显性），均值随 $F$ 线性下降；若没有显性，则完全不变。
:::

::: proof
$M_F = a(p^2 + Fpq) + d\cdot2pq(1 - F) - a(q^2 + Fpq) = a(p^2 - q^2) + 2pqd(1 - F)$，且 $p^2 - q^2 = (p - q)(p + q) = p - q$。在 $F = 0$ 时这是 $M_0 = a(p - q) + 2pqd$，故 $M_F = M_0 - 2pqdF$。对具加性（非上位）效应的各基因座求和即得多基因座形式。
:::

因此近交衰退需要**显性**，具体而言要求杂合子平均更接近“较好”的纯合子。两种遗传机制可以造成它。按**部分显性假说**，群体携带许多低频的部分隐性有害等位基因（由突变-选择平衡维持，[[population-genetics/mutation-migration]]），近交使之暴露。按**超显性假说**，在许多基因座上杂合子比两种纯合子都更适合，而近交降低杂合度本身。两者的预言不同：有害隐性可以在近交系中被选择**净化**，而超显性会使适合度持续下降、无从恢复；而不同近交系之间的杂交在两种机制下都恢复适合度。大多数证据——一些长期近交系适合度的恢复、新突变的性质、以及基因组学研究——支持部分隐性的有害突变是主因，超显性只居次要地位（Deborah Charlesworth 与 John Willis，2009）。

::: example 隐性致死造成的近交衰退 {#ex-lethal}
某群体在突变-选择平衡上携带频率 $q = 0.01$ 的隐性致死等位基因。$F = 0$ 时以及表兄妹的子女中，有多大比例的合子死于它？若基因组含有100个这样的基因座、每个都有同一频率，表兄妹的子女相对无亲缘双亲的子女的期望存活率是多少？
::: solution
$F = 0$ 时纯合子比例为 $q^2 = 10^{-4}$。$F = 1/16$ 时为 $q^2 + Fpq = 10^{-4} + 0.0625\times0.0099 = 7.19\times10^{-4}$，增加7.2倍。跨100个独立基因座，存活率为 $\prod(1 - f_i)$：$F = 0$ 时 $(1 - 10^{-4})^{100} = 0.990$；$F = 1/16$ 时 $(1 - 7.19\times10^{-4})^{100} = 0.931$。相对存活率为 $0.931/0.990 = 0.940$，降低6 %。每个基因座加上比例为 $Fpq$ 的额外死亡，而 $\ln 0.940 = -0.062 \approx -100\times\tfrac{1}{16}\times0.0099$：存活率的对数随 $F$ 线性下降，对这些致死基因座斜率为 $\sum_i p_iq_i \approx \sum_i q_i = 0.99$。这一线性是下一节的基础。
:::
:::

### 致死当量

[[#eq-depression]]的线性提示了一个实用的度量。Newton Morton、James Crow 与 Hermann Muller（1956）把近交系数为 $F$ 的子代的存活率写成

$$
S_F = e^{-(A + BF)},\qquad \ln S_F = -A - BF,
$$ {#eq-lethal-eq}

其中 $A$ 代表与近交无关的死亡，$B$ 是每配子的**致死当量**数：一组有害等位基因，其纯合效应合计平均造成一次死亡（一个完全致死等位基因，或两个各以50 %的概率致死的等位基因，如此等等）。每个基因座约以 $q_is_i$ 贡献于 $B$，所以 $B = \sum_i q_is_i$，而 $2B$ 是每个二倍体个体的致死当量数。$B$ 作为 $-\ln S$ 对不同近交系数家系的 $F$ 的回归斜率来估计。

::: example 估计致死当量 {#ex-b}
某圈养群体中，无亲缘双亲的子代幼年存活率为0.90，全同胞双亲的子代为0.60。估计每配子与每二倍体基因组的致死当量数，并预测表兄妹的子女的存活率。
::: solution
由 $F = 0$：$\ln 0.90 = -A$，故 $A = 0.105$。由 $F = 0.25$：$\ln 0.60 = -0.511 = -A - 0.25B$，故 $B = (0.511 - 0.105)/0.25 = 1.62$ 个致死当量每配子，每二倍体基因组约3.2个。对 $F = 1/16$：$S = \exp(-0.105 - 1.62/16) = \exp(-0.207) = 0.81$。对许多圈养哺乳动物种的估计（Katherine Ralls、Jonathan Ballou 与 Alan Templeton，1988）给出幼年存活方面每二倍体基因组几个致死当量；把整个生活史的全部适合度组分计入的估计，以及来自野生群体的估计，往往高出得多。
:::
:::

:::

### 净化

近交使隐性有害等位基因在纯合状态下暴露于选择，所以长期近交的群体可能已失去其中许多。这种**净化**对致死和严重有害的隐性很有效——它们在几代紧密近交之内即被消除——但对轻度有害的等位基因效率很低，它们在小群体中被漂变固定与被清除掉的一样容易。实验——包括 *Drosophila* 的长期近交和许多圈养群体——表明净化会发生，但通常只去除近交衰退的一部分；小群体反而积累固定了轻度有害等位基因的**漂变负荷**，群体内部的任何选择都无法去除它——只有基因流能够。

### 杂种优势

近交衰退的反面是**杂种优势**：近交系之间的杂交恢复到、常常超过无近交群体的长势，因为一个系的显性等位基因掩盖了另一个系的隐性等位基因。George Shull 与 Edward East 于1908年在玉米中各自独立地描述了这一现象，Donald Jones 提出了双交法（1918），使杂种玉米自1930年代起在美国商业化。如今大多数玉米与许多蔬菜都用 F1 杂种种子种植，而这种种子必须每年重新生产，因为 F2 发生分离并丢失部分杂种优势。

::: application 濒危群体中的近交
苏必利尔湖皇家岛上的狼群约在1949年由极少数从大陆踏冰而来的个体奠基。此后与外界隔绝，群体变得高度近交；脊椎畸形变得常见，持续衰退之后到2016年只剩两只亲缘关系很近的狼。基因组测序显示，与大陆狼相比，它们有很长的纯合片段和过量纯合的强有害变异（Jacqueline Robinson 及同事，2019）。2018年起，大陆的狼被转移到岛上。同一项研究还说明一个微妙之处：长期狭小的群体，如加州海峡群岛的岛狐，可以高度纯合却已净化掉许多强有害等位基因。保护计划因此直接监测亲缘度与近交，避免亲属间交配，并用基因流缓解近交衰退（[[conservation-biology/conservation-genetics]]）。
:::

## 用基因组度量近交

系谱给出的是*期望*近交系数。基因组中血缘同源相同的实际比例围绕它波动，因为重组把染色体打碎成长短随机、共同传递的片段：同一桩表兄妹婚配的两个子女，其基因组中自合（autozygous）的比例可以相差很大。密集的基因型或序列数据使我们能够直接度量实际近交程度。

::: definition 纯合片段 {#def-roh}
**纯合片段**（ROH）是个体基因组上一段通常超过1 Mb、每个变异位点都纯合的长片段。长的 ROH 产生于一个染色体片段的两份拷贝源自一位较近的共同祖先时（自合，autozygosity）。**基因组近交系数**为 $F_\mathrm{ROH} = L_\mathrm{ROH}/L$，即超过所选最小长度的 ROH 总长除以所覆盖的常染色体基因组长度。
:::

ROH 的长度揭示共同祖先生活的年代。经 $g$ 代前的祖先共享的片段经历过 $2g$ 次减数分裂中的重组，所以其期望长度约为 $100/(2g)$ cM：长片段（超过10 Mb）提示近代近交，如双亲是表兄妹；而许多短片段反映较早的共享祖先和远古的小群体大小。在人类群体中，ROH 长度的分布能把近代近亲婚配的群体与经历古代瓶颈的群体区分开（[[genomics/human-variation]]）；在家畜中，$F_\mathrm{ROH}$ 已在近交管理中取代了系谱 $F$。

::: intuition 为什么近交不是“坏基因”
近交不创造有害等位基因，也不改变等位基因频率。它改变的是等位基因的组合方式，使更多等位基因进入纯合子。每个无近交群体都携带着罕见隐性变异的隐蔽负荷，其中几乎全都在杂合子中、不造成伤害。近交揭示这一负荷；远交又把它藏起。一代近交前后群体的遗传素质是相同的——不同的只是其表型——直到选择作用于暴露的纯合子并改变频率，那就是净化。
:::

::: history
达尔文关于自交与异交的实验（1876）记录了植物中的近交衰退。1900年之后，苏厄尔·赖特在美国农业部用豚鼠研究近交，从1915年起分析那些自1906年以来通过兄妹交配维持近交的品系。他1921年发表于 *Genetics* 的系列论文“交配系统”（“Systems of mating”）与1922年的论文“近交与亲缘系数”（“Coefficients of inbreeding and relationship”）定义了本章所用的 $F$ 与通径法。Gustave Malécot（1948）把理论重述为血缘同源相同的概率。Shull 与 East 于1908年在玉米中发现了杂种优势。Morton、Crow 与 Muller（1956）利用近亲婚配的数据引入致死当量。约自2006年起，密集的 SNP 芯片使人能够直接看到纯合片段，基因组时代由此开始。
:::

::: summary
- $F$ 是一个个体某基因座上两个基因相对基础群体血缘同源相同的概率；子代的 $F$ 是其双亲的亲缘系数（[[#def-f]]）。
- 近交下基因型频率为 $p^2 + Fpq$、$2pq(1 - F)$、$q^2 + Fpq$；等位基因频率不变。罕见隐性纯合子按因子 $1 + Fp/q$ 增加（[[#prop-genotypes-f]]）。
- 通径计数：$F_X = \sum(\tfrac12)^{n_1 + n_2 + 1}(1 + F_A)$；半同胞 $1/8$、全同胞 $1/4$、表兄妹 $1/16$（[[#prop-paths]]）。
- 自交使杂合度每代减半；比率为 $S$ 的部分自交给出 $\hat F = S/(2 - S)$（[[#prop-partial]]）；同胞交配每代降低杂合度约19 %；有限群体为 $1/2N_e$。
- 选型交配只影响与性状有关的基因座；近交影响整个基因组。
- 近交使性状均值改变 $-2F\sum pqd$：衰退需要方向性显性（[[#prop-depression]]）。它主要由部分隐性的有害等位基因造成；存活率遵循 $\ln S = -A - BF$，$B$ 为每配子的致死当量数。
- 净化能去除强有害的隐性而不能去除轻度的；杂种优势是杂交中近交衰退的逆转。
- 纯合片段度量实际近交程度，并借其长度度量近交发生的时代（[[#def-roh]]）。
:::

## 习题

::: exercise 半同胞 {level=1 check="0.125"}
两个半同胞的子女的近交系数是多少？设其共同亲本非近交。
::: solution
一个共同祖先，$n_1 = n_2 = 1$：$F = (\tfrac12)^3 = 1/8$。
:::
:::

::: exercise 近交下的基因型 {level=1 check="0.42"}
一个群体 $F = 0.25$、$A_2$ 的等位基因频率 $q = 0.6$，$A_2A_2$ 的频率是多少？
::: solution
$q^2 + Fpq = 0.36 + 0.25\times0.4\times0.6 = 0.36 + 0.06 = 0.42$。
:::
:::

::: exercise 三代自交 {level=1 check="0.875"}
一个 $F = 0$ 的群体完全自交三代。$F$ 是多少？
::: solution
$1 - F_3 = (\tfrac12)^3 = 0.125$，故 $F_3 = 0.875$。
:::
:::

::: exercise 一个近交的共同祖先 {level=2 check="17/128"}
两个半同胞交配。他们的共同亲本 $A$ 自己是表兄妹的子女（$F_A = 1/16$）。他们孩子的近交系数是多少？
::: solution
有一条通路，经 $A$，$n_1 = n_2 = 1$。由[[#eq-paths]]，$F = (\tfrac12)^3(1 + F_A) = \tfrac18\times\tfrac{17}{16} = 17/128 \approx 0.133$。祖先自身的近交提高了它传下的两个基因血缘同源相同的概率——即便它们来自它的两份不同基因。
:::
:::

::: exercise 由 F 求自交率 {level=2 check="2/3"}
一个处于近交平衡的植物群体 $F = 0.5$。估计其自交率。
::: solution
$S = 2F/(1 + F) = 1/1.5 = 2/3$。
:::
:::

::: exercise 近亲婚配与一个罕见等位基因 {level=2 check="63.4375"}
一个隐性等位基因的频率 $q = 0.001$。表兄妹的子女中纯合子的频率比无亲缘双亲的子女中高出几倍？
::: solution
由[[#eq-ratio]]，$1 + Fp/q = 1 + 0.0625\times0.999/0.001 = 1 + 62.44 = 63.44$。对极罕见的隐性等位基因，只要群体中有一点近亲婚配，大多数纯合子就是亲缘双亲的子女。
:::
:::

::: exercise 由数据估计致死当量 {level=2}
某动物园的羚羊群体中，按近交系数分的幼年存活率为：$F = 0$，0.85；$F = 0.125$，0.72；$F = 0.25$，0.62。(a) 把 $\ln S$ 对 $F$ 拟合直线，估计 $A$ 与 $B$。(b) 衰退与模型一致吗？(c) 拥有这个群体的动物园为什么可能连表兄妹间的交配也要避免？
::: solution
(a) $\ln S$：$-0.163$、$-0.329$、$-0.478$。过这三点的最小二乘直线（[[biostatistics/regression]]）斜率为 $-1.26$、截距为 $-0.165$。故 $B \approx 1.26$ 个致死当量每配子（每二倍体基因组约2.5个），$A \approx 0.165$。

(b) 一致：$\ln S$ 在抽样误差内随 $F$ 线性变化，正如[[#eq-lethal-eq]]对独立基因座的预言。

(c) 对表兄妹，$F = 1/16$ 使存活率乘以因子 $e^{-1.26/16} = 0.92$，仅幼年存活一项就损失8 %，而近交衰退通常还影响繁殖力和成年存活。在许多代之中，避免近亲交配也会减缓小群体中近交的累积。
:::
:::

::: exercise 全同胞交配 {#exr-sibs level=3}
(a) 证明：双亲 $M$ 与 $P$ 的亲缘系数为 $f_{MP}$、近交系数为 $F_M$ 与 $F_P$ 的两个全同胞 $X$ 与 $Y$ 的亲缘系数为 $f_{XY} = \tfrac14\bigl[\tfrac12(1 + F_M) + \tfrac12(1 + F_P) + 2f_{MP}\bigr]$。(b) 由此对一个每代都以全同胞交配维持的品系推导[[#eq-sibs]]。(c) 从 $F_0 = F_{-1} = 0$ 出发计算 $F_4$。
::: solution
(a) 从 $X$ 随机取的一个基因以各 $\tfrac12$ 的概率来自 $M$ 或 $P$，$Y$ 同理。两者都来自 $M$（概率 $\tfrac14$）：它们是 $M$ 的随机基因，血缘同源相同的概率等于 $M$ 与自身的亲缘系数，即 $\tfrac12(1 + F_M)$。两者都来自 $P$：$\tfrac12(1 + F_P)$。各取一份（概率 $\tfrac12$）：$f_{MP}$。相加即得公式。

(b) 第 $t$ 代个体的近交为 $F_t = f_{XY}$，其双亲 $X$ 与 $Y$（第 $t - 1$ 代）是全同胞。它们的父母 $M$ 与 $P$ 属第 $t - 2$ 代，故 $F_M = F_P = F_{t-2}$；而 $M$ 与 $P$ 的亲缘系数 $f_{MP}$ 等于其子女 $X$ 与 $Y$ 的近交系数，即 $F_{t-1}$。于是 $F_t = \tfrac14[\tfrac12(1 + F_{t-2})\cdot2 + 2F_{t-1}] = \tfrac14(1 + 2F_{t-1} + F_{t-2})$。

(c) $F_1 = \tfrac14$、$F_2 = \tfrac14(1 + \tfrac12) = 0.375$、$F_3 = \tfrac14(1 + 0.75 + 0.25) = 0.5$、$F_4 = \tfrac14(1 + 1 + 0.375) = 0.59375$。
:::
:::

::: exercise 净化还是超显性？ {level=3}
一位植物育种家用自交维持一个通常异交物种的50个系，历时10代。适合度在前三代急剧下降；20个系灭绝；在30个幸存系中，平均适合度此后在余下的世代中部分恢复。幸存系之间杂交产生的 F1 与原无近交群体一样健壮。(a) 这些结果支持对近交衰退的哪个假说，为什么？(b) 为什么恢复可能只是部分的？(c) 若干脆忽略灭绝的系，实验的结论为什么会有偏？
::: solution
(a) 近交系内适合度的部分恢复表明发生了净化，而只有当近交衰退源于（部分）隐性有害等位基因——它们一旦纯合就能被选择去除——净化才可能；若为纯粹的超显性，适合度会随杂合度下降而继续下降，无从恢复。F1 杂交中适合度的恢复是两个假说都预言的，不足以分辨。

(b) 轻度有害的等位基因不能被有效地净化，可能在一个系内被漂变固定（漂变负荷），一些超显性基因座也可能有贡献。净化还需要好几代的选择。

(c) 灭绝的系是携带最多有害等位基因的系；幸存者是一个经过选择的子集。忽略它们会低估近交衰退，并使净化看起来比实际更有效——一种幸存者偏倚。
:::
:::
