1896年，Cyril Hopkins 在伊利诺伊农业试验站取来一个开放授粉玉米品种的163个果穗，测量其籽粒的油分与蛋白质含量，并开始选择：每代中，含油量最高的果穗被播种，用以建立“高油”品系的下一代，含油量最低者建立“低油”品系的下一代，蛋白质方面则有平行的品系。这个实验已持续了一个多世纪。100代之后，高油品系含油约22 %，而原始群体中大致为5 %左右，低油品系则降到了1 %上下（John Dudley 与 Robert Lambert，2004）——变化达原始标准差的许多倍，而且高油品系仍在响应。对数量性状的选择能使群体远远超出其最初的变异范围。

多快，又能持续多久？我们在[[evolution/natural-selection]]中见过的育种方程 $R = h^2S$，由[[population-genetics/quantitative-traits]]的遗传率预测一代的响应。本章把它发展成为选择数量性状的工作理论：通过选择强度来表达的选择差、每年的响应、定义自然界中选择的适合度与表型之间的协方差、选择梯度与带有相关响应的多元 Lande 方程、实际遗传率、以及漂变与突变为长期响应设定的极限。结尾是一个来自野生群体的谜题：持续选择之下、可遗传、却不进化的性状。

## 育种方程

::: proposition 育种方程 {#prop-breeder}
设某性状的表型方差为 $V_P$、狭义遗传率为 $h^2$。若被选来繁殖的亲本的均值表型高出群体均值 $S$（**选择差**），且子代对中亲表型的回归是线性的，则下一代均值的期望改变量——**响应** $R$——为

$$
R = h^2S.
$$ {#eq-breeder}
:::

::: proof
由[[population-genetics/quantitative-traits]]，子代表型对中亲表型的回归斜率为 $h^2$：$\E[P_O \mid \bar P] = \mu + h^2(\bar P - \mu)$。若被选亲本之间随机交配，则其中亲值的均值偏离 $\mu$ 达 $S$；把线性回归对被选的配对取平均，得到子代均值 $\mu + h^2S$。线性是关键假定：当育种值与表型联合正态分布时它精确成立，这对高度多基因的性状是不错的近似（“无限微效模型”），而对受少数大效应基因座影响或有很强的非加性效应的性状则会失效，此时回归可能是弯曲的。
:::

这些假定值得逐一列出，因为每一个都会在某个地方失效：两代的环境相同（或只改变均值，这可通过一条不选的对照品系在实验中加以控制）；选择只通过所测的表型起作用；没有母性效应；世代不重叠；且 $h^2$ 指的是发生选择的那个群体。这个方程预测*一代*的响应；在多代之上 $h^2$ 本身就在变。

### 选择强度

选择差取决于亲本被选择的强度以及性状的变异程度。在**截断选择**中——育种中的常见做法——阈值之上的个体全部保留，阈值之下的全部淘汰。

::: proposition 截断选择下的选择强度 {#prop-intensity}
若性状服从标准差为 $\sigma_P$ 的正态分布，且选留数值最高的比例 $p$，则选择差为 $S = i\sigma_P$，其中**选择强度**为

$$
i = \frac{\varphi(x)}{p},
$$ {#eq-intensity}

$x$ 是以标准差为单位的截断点（$p = 1 - \Phi(x)$），$\varphi$ 与 $\Phi$ 是标准正态密度函数与分布函数。于是响应为

$$
R = i\,h^2\sigma_P = i\,h\,\sigma_A.
$$ {#eq-response-i}
:::

::: proof
对标准正态变量 $Z$，被选个体的均值为 $\E[Z \mid Z > x] = \frac{1}{p}\int_x^\infty z\varphi(z)\,dz$。由于 $\varphi'(z) = -z\varphi(z)$，积分为 $[-\varphi(z)]_x^\infty = \varphi(x)$。所以标准化的选择差为 $\varphi(x)/p$，以性状自身的单位计则 $S = i\sigma_P$。代入[[#eq-breeder]]得 $R = ih^2\sigma_P$；由于 $h^2\sigma_P = (\sigma_A^2/\sigma_P^2)\sigma_P = h\sigma_A$，第二个形式随之成立。
:::

几个数值：选留前一半给出 $i = 0.80$；前20 %，$i = 1.40$；10 %，$1.75$；5 %，$2.06$；1 %，$2.67$。随着选择变得更极端，选择强度只缓慢增加，而繁殖个体的数目——从而有效群体大小——却在下降，这是我们要回头再谈的一种权衡。

对育种者而言，每代响应不是全部，他关心的是每年的改变。若 $L$ 是**世代间隔**（子女出生时亲本的平均年龄），则年响应为

$$
\frac{R}{L} = \frac{i\,h^2\sigma_P}{L}.
$$ {#eq-annual}

当两性以不同的强度被选择时，$i$ 换为平均强度 $(i_m + i_f)/2$，$L$ 换为两性的平均世代间隔——每个性别都贡献下一代基因的一半。

::: example 选择肉鸡 {#ex-broiler}
在一个肉鸡品系中，六周龄体重的标准差为100 g、遗传率为0.4。(a) 若两性中最重的20 %被留作亲本，每代的期望响应是多少？(b) 若只选雄性（前20 %）、雌性随机使用，又是多少？(c) 若世代间隔为1年，而提前繁殖可把它缩短到0.75年，代价是改选雄性的前30 %而非20 %（雌性仍随机），哪个方案的年增益更大？
::: solution
(a) 每代 $R = 1.40\times0.4\times100 = 56$ g。

(b) $i = (1.40 + 0)/2 = 0.70$，所以 $R = 0.70\times0.4\times100 = 28$ g。

(c) 方案(b)：每年 $28$ g。提前繁殖：$p = 0.3$ 时截断点为 $x = 0.524$，$\varphi(x) = 0.348$，所以 $i_m = 0.348/0.3 = 1.16$，$i = 0.58$。于是每代 $R = 0.58\times0.4\times100 = 23.2$ g，即每年 $23.2/0.75 = 31$ g。尽管选择更弱，缩短世代间隔仍然胜出。这类计算驱动着每个现代育种方案的设计，也解释了为什么基因组预测——它使选择非常年幼的个体成为可能——加快了遗传增益（[[population-genetics/quantitative-traits]]）。
:::

## 作为协方差的选择

自然界中没有人做截断。个体在存活与繁殖上连续地不同，选择由适合度与表型之间的关系来描述。令 $w$ 为**相对适合度**（绝对适合度除以其均值，故 $\bar w = 1$）。以每个个体的适合度加权的选择后均值表型为 $\E[wz]$，所以选择差为

$$
S = \E[wz] - \E[z] = \Cov(w, z),
$$ {#eq-robertson-price}

因为 $\E[w] = 1$。这个简单的恒等式（Alan Robertson，1966；George Price，1970）说的是，选择差*就是*相对适合度与性状之间的协方差。Price 把它推广为任一个性状均值跨一代改变的精确方程，$\Delta\bar z = \Cov(w, z) + \E[w\,\Delta z]$，其中第二项汇集亲代与子代之间性状的改变（传递）。当适合度在整代上定义时，第一项是选择，第二项是其他一切。

对育种值应用同一恒等式便得到响应：$R = \Cov(w, A)$，即适合度与该性状加性遗传值的协方差（**选择第二定理**，Robertson 1966）。若适合度只通过表型依赖于该性状，且育种值对表型线性回归，则 $\Cov(w, A) = h^2\Cov(w, z) = h^2S$，重新得到育种方程。但若一个未测量的环境因素同时影响性状与适合度——营养好的个体既更大又生育力更强——那么 $S$ 可以很大而 $\Cov(w, A)$ 为零，育种方程便会高估响应。这是下文要讨论的停滞谜题的主要解释之一。

### 选择梯度

选择差把选择的强度与性状的方差混在一起。**选择梯度**去掉了方差：

$$
\beta = \frac{S}{V_P} = \frac{\Cov(w, z)}{\Var(z)},
$$ {#eq-gradient}

即相对适合度对该性状回归的斜率。有了它，$R = h^2S = V_A\beta$。

当有多个相关的性状时，对一个性状的选择差包含通过它与其余性状的相关而起的间接选择。Russell Lande 与 Stevan Arnold（1983）给出了分离它们的方法：把相对适合度同时对所有测得的性状回归，

$$
w = \alpha + \sum_j\beta_jz_j + \tfrac12\sum_{j,k}\gamma_{jk}z_jz_k + \varepsilon,
$$ {#eq-lande-arnold}

其中线性系数 $\boldsymbol\beta$ 度量直接作用于每个性状的**定向选择**，二次系数 $\gamma$ 度量曲率：$\gamma_{jj} < 0$ 表示稳定选择，$\gamma_{jj} > 0$ 表示分裂选择，而 $j \neq k$ 的 $\gamma_{jk}$ 是偏爱特定组合的相关选择。用向量形式，选择差的向量为 $\mathbf S = \mathbf P\boldsymbol\beta$，其中 $\mathbf P$ 是表型方差-协方差矩阵。Joel Kingsolver 及同事（2001）汇编了来自野生群体的数千个估计：标准化为 $\beta\sigma_P$ 的定向梯度通常约为0.15–0.2的量级，带有一条更强取值的长尾，而稳定选择比通常设想的更少也更弱。

## 多变量响应与相关性状

当同一批等位基因影响两个性状（**基因多效性**），或影响它们的等位基因处于连锁不平衡（[[population-genetics/linkage-disequilibrium]]）时，两个性状便遗传相关。此时对一个性状的选择会改变其他性状。

::: proposition Lande 方程 {#prop-lande}
对表型协方差矩阵为 $\mathbf P$、加性遗传协方差矩阵为 $\mathbf G$ 的性状向量，在与育种方程相同的假定下，均值向量对一代选择的响应为

$$
\Delta\bar{\mathbf z} = \mathbf G\mathbf P^{-1}\mathbf S = \mathbf G\boldsymbol\beta.
$$ {#eq-lande}

（Russell Lande，1979。）单个性状时这化为 $R = V_A\beta = h^2S$。
:::

::: proof
在多元正态下，子代育种值向量（从而子代表型向量，因为环境偏差平均为零）对亲本表型向量的回归是线性的，对中亲的系数矩阵为 $\mathbf G\mathbf P^{-1}$：中亲表型与子代的协方差为 $\tfrac12\mathbf G$，而中亲表型的方差为 $\tfrac12\mathbf P$，所以多元回归矩阵为 $\tfrac12\mathbf G(\tfrac12\mathbf P)^{-1} = \mathbf G\mathbf P^{-1}$。把它用于被选亲本的均值偏差 $\mathbf S$，即得[[#eq-lande]]；而由多元梯度的定义，$\mathbf P^{-1}\mathbf S = \boldsymbol\beta$。
:::

对两个性状 $x$ 与 $y$，只对 $x$ 进行选择（截断选择，强度 $i$）时，$y$ 的**相关选择响应**为

$$
\mathrm{CR}_y = i\,h_xh_y\,r_A\,\sigma_{P_y},
$$ {#eq-correlated}

其中 $r_A$ 是两个性状之间的加性遗传相关，$h_x$、$h_y$ 是其遗传率的平方根（Falconer 的形式）。它可能是有利的，也可能不是：对肉鸡快速生长的选择伴随着腿部与心血管健康以及繁殖方面的相关改变，对奶牛产奶量的选择伴随着受精率的下降，两者都经由不利的遗传相关。

::: example 对一个性状的选择会移动另一个性状 {#ex-lande}
两个标准化的性状有表型方差1与表型协方差0.5；其加性遗传方差为0.5与0.4，遗传协方差0.3。选择产生选择差 $\mathbf S = (0.6, 0)$：被选个体在性状1上高于均值，在性状2上恰为均值。预测两个性状的响应。
::: solution
$\mathbf P = \begin{pmatrix}1 & 0.5\\ 0.5 & 1\end{pmatrix}$，$\mathbf P^{-1} = \frac{1}{0.75}\begin{pmatrix}1 & -0.5\\ -0.5 & 1\end{pmatrix}$，所以

$$
\boldsymbol\beta = \mathbf P^{-1}\mathbf S = \begin{pmatrix}0.8\\ -0.4\end{pmatrix},\qquad \Delta\bar{\mathbf z} = \mathbf G\boldsymbol\beta = \begin{pmatrix}0.5 & 0.3\\ 0.3 & 0.4\end{pmatrix}\begin{pmatrix}0.8\\ -0.4\end{pmatrix} = \begin{pmatrix}0.28\\ 0.08\end{pmatrix}.
$$

尽管被选个体在性状2上没有选择差，它仍响应 $+0.08$，而性状1响应0.28，而不是单变量预测的 $h^2S = 0.5\times0.6 = 0.30$。梯度揭示了发生了什么：选择直接偏爱性状1（$\beta_1 = 0.8$），又直接*不利于*性状2（$\beta_2 = -0.4$）；性状2上选择差为零，是因为对它的直接选择抵消了通过它与性状1的表型相关而起的间接选择。遗传相关与表型相关不同，所以遗传响应不会抵消。一次只测一个性状上的选择可能会误导。
:::
:::

```python
from statistics import NormalDist

def intensity(p):
    """Selection intensity for truncation selection of the top fraction p of a normal trait."""
    x = NormalDist().inv_cdf(1 - p)        # truncation point in SD units
    return NormalDist().pdf(x) / p

for p in (0.5, 0.2, 0.1, 0.05, 0.01):
    print(p, round(intensity(p), 3))      # 0.798, 1.4, 1.755, 2.063, 2.665

# Lande equation for two traits (example above): dz = G P^-1 S
P = [[1.0, 0.5], [0.5, 1.0]]
G = [[0.5, 0.3], [0.3, 0.4]]
S = [0.6, 0.0]
det = P[0][0] * P[1][1] - P[0][1] * P[1][0]
Pinv = [[P[1][1] / det, -P[0][1] / det], [-P[1][0] / det, P[0][0] / det]]
beta = [sum(Pinv[r][c] * S[c] for c in range(2)) for r in range(2)]
dz = [sum(G[r][c] * beta[c] for c in range(2)) for r in range(2)]
print([round(b, 3) for b in beta], [round(d, 3) for d in dz])   # [0.8, -0.4] [0.28, 0.08]
```

::: example 一个相关响应 {#ex-correlated}
一位育种者对猪的生长速率进行选择，留前20 %（$i = 1.40$）。生长的 $h^2 = 0.4$；背膘厚度的 $h^2 = 0.25$、表型标准差10 mm，而生长与背膘的遗传相关为 $-0.5$。每代背膘的期望相关响应是多少？
::: solution
由[[#eq-correlated]]，$\mathrm{CR} = 1.40\times\sqrt{0.4}\times\sqrt{0.25}\times(-0.5)\times10 = 1.40\times0.632\times0.5\times(-0.5)\times10 = -2.2$ mm 每代。这里相关响应是有利的（猪更瘦）。同一个方程还显示，对相关性状的**间接选择**何时能胜过直接选择：为改进 $x$ 而选 $y$，响应为 $i\,h_xh_yr_A\sigma_{P_x}$，与直接选择时的 $i\,h_x^2\sigma_{P_x}$ 相比，当 $h_yr_A > h_x$ 时更优——例如当 $x$ 难以测量或只在一个性别中表达时。
:::
:::

## 实验中的响应：实际遗传率

在选择实验中，逐代把累计响应对累计选择差作图。若遗传率恒定时育种方程成立，则各点落在一条过原点、斜率为 $h^2$ 的直线上：**实际遗传率**。一条平行之不选的对照品系，或双向的发散选择，可去除环境趋势。

::: example 实际遗传率 {#ex-realised}
在一个为高窝重而选的小鼠品系中，五代的累计选择差为2.0、4.1、6.0、8.2与10.1 g，累计响应（相对于不选的对照）为0.7、1.2、2.0、2.6与3.1 g。估计实际遗传率。
::: solution
累计响应对累计选择差、过原点拟合的斜率为 $\sum S_tR_t/\sum S_t^2 = 70.95/226.06 = 0.31$；带截距的普通回归也给出0.31。实际遗传率约为0.3。与基础群体中由亲属得到的估计相比较，是对模型的检验；随着遗传率下降，实际值在后期世代往往更低，而两个方向的选择响应常常**不对称**，原因包括近交衰退、大效应基因，以及自然选择在某个方向上对抗人工选择。
:::
:::

## 长期响应

选择能持续改变一个性状多久？在无限微效模型中，遗传方差每代只被选择略微削减（**Bulmer 效应**：选择在影响该性状的基因座之间造成负的 LD，使 $V_A$ 减少一个不大的量，而重组会部分恢复它；Michael Bulmer，1971），响应可以无限持续下去。当基因座数目有限、群体有限时，有两个过程会限制它：受偏爱的等位基因被固定，而漂变随机地固定或丢失等位基因。

::: proposition Robertson 上限 {#prop-robertson}
对于加性效应小的等位基因，从有效大小为 $N_e$ 的群体最初存在的变异中所能获得的选择总响应约为

$$
R_\infty \approx 2N_e\,R_1,
$$ {#eq-robertson}

其中 $R_1$ 是第一代的响应（Alan Robertson，1960）。响应大致按 $R_t \approx R_1(1 - 1/2N_e)^t$ 衰减，半衰期约为 $1.4N_e$ 代。
:::

::: proof 启发性论证
对一个受偏爱的等位基因只有很小选择优势的基因座，每代贡献的响应正比于其加性方差 $2pq\alpha^2$，而漂变每代把它乘以因子 $1 - 1/2N_e$（[[population-genetics/genetic-drift]]），弱选择则只略微改变 $p$。于是总响应是几何和 $R_1\sum_t(1 - 1/2N_e)^t = 2N_eR_1$。对效应较大的等位基因（$N_es$ 大），决定其命运的是选择而非漂变，达到极限之时就是它们被固定之时；此时极限与最初响应之比介于 $2N_e$ 与一个由受偏爱等位基因固定所决定的、小得多的值之间。
:::

caption: Robertson 模型下选择的累计响应（曲线），其中每代响应随漂变侵蚀加性方差而衰减；作为对照的是每代恒为 $R_1$ 的响应（直线）。曲线趋近极限 $2N_eR_1$（默认 $N_e = 20$、$R_1 = 0.5$ 时为20个单位）。增大 $N_e$，曲线就更久地贴着直线，并到达更高的平台：更大的繁殖群体能维持更长的响应。实际的长期实验常常超出预测的极限，因为新突变会追加方差。
:::

实际的经验是：极强的选择只用到很少的亲本，增益快但早早进入平台；较大的 $N_e$ 配上温和的选择，长远看增益更多。Robertson 证明，若要使最终的极限最大化、且只利用现有变异，最优是选留群体的一半左右。

**新突变**使长期响应得以继续。每代由突变输入的新加性方差 $V_M$，在很广的性状与生物类群范围内约为环境方差 $V_E$ 的 $10^{-3}$ 倍（**突变遗传率**，Michael Lynch，1988综述）。在有效大小为 $N_e$ 的群体中，仅由突变与漂变维持的平衡加性方差约为 $2N_eV_M$，所以一个 $N_e$ 为几百的群体可以无限期地维持几十个百分点的遗传率。这与伊利诺伊州玉米品系中延续100代的响应，以及果蝇鬃毛数与小鼠体重的长期选择相一致。

## 自然界中的选择与进化

育种方程诞生于农业，但它却是预测野生环境中进化的标准模型。它的预测在带系谱的长期野外研究中受到检验，而它们常常以一种有特点的方式落空。

**停滞悖论。** 野生群体中的许多性状可遗传，且处于持续一致的定向选择之下——体型较大常与更高的存活率和繁殖力相关——然而其均值数十年不变，甚至朝相反方向改变。Juha Merilä、Ben Sheldon 与 Loeske Kruuk（2001）综述了这类情形，包括圈颈姬鹟与马鹿的体型。解释包括以下几条。

- **性状与适合度之间的环境协方差。** 如上文关于 $\Cov(w, A)$ 的讨论，条件好能使个体既大又适合度更高，而体型与适合度之间并无任何遗传联系。用动物模型与系谱在育种值上（而非在表型上）估计的选择梯度常常弱得多。
- **变化的环境。** 响应可能被反方向的环境改变所掩盖——例如，食物状况恶化使体型在表型上变小，而遗传值却在增加。
- **对相关性状的选择。** 与焦点性状遗传相关、却未被测定的性状，可能处于反向的选择之下（[[#ex-lande]]的逻辑）。
- **波动的选择。** 在若干年中测得的选择，换到别的年份可能反向，正如达尔文地雀喙的大小（[[evolution/natural-selection]]）。

**进化的速率。** 表型变化以**霍尔丹**（haldanes）计，即每代多少个标准差（Philip Gingerich，1993）。当代群体中在几代之内观察到的变化可以有霍尔丹的几分之一；化石记录中在数千或数百万年上测得的速率要慢许多个数量级，这不是因为进化变慢了，而是因为长期变化是对方向波动的平均（[[evolution/macroevolution]]）。

::: warning "对性状的选择意味着性状会进化"
选择是一代之内的表型过程；进化是跨代的遗传改变。一个处于强选择之下的性状，若没有加性遗传方差，若其与适合度的协方差是环境性的而非遗传性的，或若对遗传相关性状的选择朝另一方向拉，它就不会进化。反过来，一个不受直接选择的性状，可能作为相关响应而进化。育种方程与 Lande 方程使这些区分变得明确：只有 $\mathbf G\boldsymbol\beta$——遗传变异乘以直接选择，对所有相关性状求和——才是进化。
:::

::: quiz
一个鸟类群体在20年间每年都表现出对翅长的正向选择差，翅长的遗传率为0.4，然而平均翅长不变。哪个解释与这些数据*最*不相符？
- [ ] 状态好的鸟翅更长、存活率也更高，且出于非遗传的原因。
- [ ] 翅长与另一个处于反向选择之下的性状遗传相关。
- [ ] 20年间环境发生了变化，使表型翅长下降而育种值上升。
- [x] 选择差为正时，育种方程预测没有响应。
::: solution
育种方程每年都预测正向响应，$R = 0.4S$，这正是该观察成为一个悖论的原因。前三个选项都是有据可查的解释：性状与适合度之间的环境协方差、相关选择、以及环境变化掩盖遗传变化。区分它们需要在育种值上估计选择，并长期追踪预测的育种值。
:::
:::

::: application 多性状育种
育种者很少想只改变一个性状。他们把多个性状组合成一个**选择指数**——表型（或如今是基因组预测值）的加权和，以求使某个经济总和上的响应最大化；这套理论由 H. Fairfield Smith（1936）为植物、Lanoy Hazel（1943）为动物发展起来，是[[#eq-lande]]的直接应用。自2000年代起把受精率、健康与寿命纳入奶牛的选择指数，已经止住并部分扭转了只选产奶量造成的受精率下降。同样的多元思维被用于保护生物学，以预判群体能否足够快地适应变化的气候，这取决于 $\mathbf G$ 以及选择的方向相对于性状间遗传相关的方向。
:::

::: history
植物与动物育种者选择了几千年却没有理论。高尔顿的回归（1886）与皮尔逊（Karl Pearson）的相关（1896）提供了统计方法；费希尔1918年的论文则给出了遗传学解释。Jay Lush 的《动物育种方案》（*Animal Breeding Plans*，1937）把育种方程表述为其基本的现代形式，而选择强度与每年响应在1940–1950年代由 Lush、Gordon Dickerson 等人确立。Alan Robertson 在爱丁堡的工作给出了选择的极限（1960）与第二定理（1966）；George Price 的协方差方程（1970）与 Russell Lande 的多元理论（1979），连同 Lande 与 Arnold 的回归方法（1983），把育种的框架带进了进化生物学。始于1896年的伊利诺伊州长期选择实验，仍是对一个数量性状进行的时间最长的选择实验。
:::

::: summary
- 育种方程 $R = h^2S$ 来自斜率为 $h^2$ 的子代对中亲的线性回归；它要求线性（多基因性状下近似良好）与恒定的环境（[[#prop-breeder]]）。
- 截断选择下 $S = i\sigma_P$，其中 $i = \varphi(x)/p$：取前一半为0.80，前20 %为1.40，前5 %为2.06；$R = ih^2\sigma_P = ih\sigma_A$；年响应 $R/L$（[[#prop-intensity]]）。
- 选择差是相对适合度与性状的协方差（Robertson–Price）；响应是适合度与育种值的协方差，当性状与适合度出于环境原因协变时它更小。
- 选择梯度 $\beta = S/V_P$ 度量直接选择；Lande–Arnold 回归在相关性状之间分离定向（$\beta$）与二次（$\gamma$）选择。
- 多元响应：$\Delta\bar{\mathbf z} = \mathbf G\boldsymbol\beta$（Lande，[[#prop-lande]]）；相关响应 $\mathrm{CR}_y = ih_xh_yr_A\sigma_{P_y}$。
- 实际遗传率是累计响应对累计选择差的斜率。
- 由现有变异获得的响应受限于约 $2N_eR_1$（Robertson，[[#prop-robertson]]）；新突变（$V_M \approx 10^{-3}V_E$）维持长期响应。
- 在野外，处于选择之下的可遗传性状常常不按预测进化（停滞），原因是环境协方差、相关选择、波动的选择与变化的环境。
:::

## 习题

::: exercise 单独一代 {level=1 check="3"}
某性状的 $h^2 = 0.3$。被选亲本平均高出群体均值10个单位。期望的响应是多少？
::: solution
$R = 0.3\times10 = 3$ 个单位。
:::
:::

::: exercise 强度与响应 {level=1 check="14"}
一个群体的前20 %（$i = 1.40$）因某性状而被选，该性状的表型标准差为20个单位、遗传率为0.5。期望的响应是多少？
::: solution
$R = 1.40\times0.5\times20 = 14$ 个单位。
:::
:::

::: exercise 一个选择梯度 {level=1 check="0.25"}
在某表型方差为8 mm² 的性状上测得选择差2 mm。选择梯度是多少？
::: solution
$\beta = S/V_P = 2/8 = 0.25$ 每 mm（以相对适合度计）。
:::
:::

::: exercise 只选一个性别 {level=2 check="0.38"}
在一个羊群中，留公羊的前10 %（$i = 1.755$）与母羊的前50 %（$i = 0.798$）用于繁殖。有效的选择强度是多少？若剪毛量的 $h^2 = 0.25$、$\sigma_P = 1.2$ kg，每代的期望响应是多少（保留两位小数）？
::: solution
$i = (1.755 + 0.798)/2 = 1.2765$，所以每代 $R = 1.2765\times0.25\times1.2 = 0.38$ kg。增益的大部分来自公羊：繁殖所需的雄性远少于雌性，所以雄性可以被选强得多。
:::
:::

::: exercise 相关响应与直接选择 {level=2}
性状 $x$（难以测量）有 $h_x^2 = 0.1$；性状 $y$（易于测量）有 $h_y^2 = 0.5$，两者的遗传相关为 $r_A = 0.7$。在选择强度相等时，为改进 $x$ 而选 $y$ 是否更优？优多少倍？
::: solution
间接响应与直接响应之比：$\dfrac{ih_xh_yr_A\sigma_{P_x}}{ih_x^2\sigma_{P_x}} = \dfrac{h_yr_A}{h_x} = \dfrac{0.707\times0.7}{0.316} = 1.57$。对 $y$ 的间接选择对 $x$ 的响应比直接选择 $x$ 多约57 %。
:::
:::

::: exercise Robertson 上限 {level=2 check="25"}
一个被选品系的 $N_e = 25$，第一代响应为0.5个单位。按 Robertson 上限，仅凭现有变异的总响应预期是多少？
::: solution
$R_\infty \approx 2N_eR_1 = 50\times0.5 = 25$ 个单位，以约 $1.4\times25 = 35$ 代的半衰期逼近。
:::
:::

::: exercise 解读一个选择实验 {level=2}
两个重复的果蝇品系为增大翅长而选择30代，每系各20对亲本。两者都稳定响应约15代，然后在不同水平上进入平台。把进入平台的品系间杂交并恢复选择时，响应又重新开始。解释每一项观察。
::: solution
早期稳定的响应使用的是现有的加性方差。当 $N_e$ 在40上下或更小时，漂变很快侵蚀方差（每代 $1/2N_e \approx 1.25$ %，且考虑到家系大小的方差还会更快），而中等效应的受偏爱等位基因被固定；当加性方差所剩无几时便到达平台。重复品系在不同水平上进入平台，是因为漂变在各系中固定了不同的等位基因集——一些受偏爱的等位基因被偶然丢失。品系间杂交把在一个品系中固定、却在另一个品系中丢失的等位基因聚到一起，恢复了加性方差，于是响应重启。（反向的自然选择——例如长翅果蝇生育力下降——也能在方差仍有剩余时造成平台；此时放松选择会看到均值的回归。）
:::
:::

::: exercise 截断选择的强度 {level=3}
(a) 利用[[#eq-intensity]]，证明 $x$ 大时截断选择的强度近似为 $x + 1/x$。（提示：$x$ 大时 $1 - \Phi(x) \approx \varphi(x)(1/x - 1/x^3)$。）(b) 把这个近似与前1 %的精确值2.665（$x = 2.326$）比较。(c) 解释为什么把选留比例从1 %降到0.1 %只使响应提高约25 %，而亲本数目却减少到十分之一。
::: solution
(a) $i = \varphi(x)/[1 - \Phi(x)] \approx 1/(1/x - 1/x^3) = x/(1 - 1/x^2) \approx x(1 + 1/x^2) = x + 1/x$。

(b) $2.326 + 1/2.326 = 2.756$，比2.665高约3 %；$x$ 越大，近似越好。

(c) $p = 0.001$ 时，$x = 3.090$，$i \approx 3.367$（精确值），而 $p = 0.01$ 时为2.665：增益26 %。与此同时 $N_e$ 降为十分之一，使漂变与近交增强到十倍，而按 Robertson 上限，来自现有变异的长期极限也降为十分之一。极端选择是一种糟糕的长期策略。
:::
:::

::: exercise 野外中对相关性状的选择 {level=3}
在一个蜥蜴群体中，把相对适合度（一年的存活）对标准化的体型 $z_1$ 与标准化的冲刺速度 $z_2$ 回归，两者的表型相关为0.6。选择差为 $S_1 = 0.30$ 与 $S_2 = 0.18$。(a) 计算选择梯度。(b) 哪个性状处于直接选择之下？(c) 若 $\mathbf G = \begin{pmatrix}0.4 & 0.1\\ 0.1 & 0.3\end{pmatrix}$，预测每个性状的响应。
::: solution
(a) $\mathbf P = \begin{pmatrix}1 & 0.6\\ 0.6 & 1\end{pmatrix}$，$\mathbf P^{-1} = \frac{1}{0.64}\begin{pmatrix}1 & -0.6\\ -0.6 & 1\end{pmatrix}$。$\beta_1 = (0.30 - 0.6\times0.18)/0.64 = 0.192/0.64 = 0.30$；$\beta_2 = (0.18 - 0.6\times0.30)/0.64 = 0/0.64 = 0$。

(b) 只有体型处于直接选择之下；冲刺速度上的正选择差完全是间接的，通过它与体型的相关。

(c) $\Delta\bar{\mathbf z} = \mathbf G\boldsymbol\beta = (0.4\times0.30,\ 0.1\times0.30) = (0.12, 0.03)$ 个标准差。预测冲刺速度会略微进化，但只通过它与体型的遗传相关（0.1/√(0.4 × 0.3) ≈ 0.29），它弱于表型相关——所以响应远小于其选择差所暗示的。
:::
