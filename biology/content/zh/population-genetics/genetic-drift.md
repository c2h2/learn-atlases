每个群体都是有限的，所以每一代的基因都是上一代基因的一个样本，而样本会因偶然不同于其所从抽出的总体。进化课程已经介绍了这些后果（[[evolution/mutation-drift-gene-flow]]）：在赖特-费希尔模型中，等位基因频率没有期望改变，但每代的方差为 $pq/2N$；杂合度每代按因子 $1 - 1/2N$ 衰减；新的中性突变以概率 $1/2N$ 被固定；真实群体用一个有效大小 $N_e$ 来描述。本章正经地建立漂变的理论。我们将追踪等位基因频率的方差在多个世代、多个重复群体之间的增长，并在一个经典实验中看到它；引入莫兰模型以及到达固定与丢失时间的扩散结果；然后把问题倒转过来，向时间*之后*回望——去看一份基因样本的谱系。这个后向视角——**并合理论（coalescent）**——正是现代群体遗传学把理论与 DNA 序列连接起来的方式。最后更充分地讨论有效群体大小以及它的估计意味着什么。

## 跨世代的漂变

### 方差在增长，期望保持不变

设 $p_t$ 为 $N$ 个二倍体个体（即 $2N$ 个基因拷贝）的赖特-费希尔群体第 $t$ 代中等位基因 $A$ 的频率，无选择、突变或迁移。漂变是随机过程，所以 $p_t$ 是随机变量：可以把它想成许多重复群体——都从 $p_0$ 出发——中某一个群体的频率。

::: proposition 漂变下等位基因频率的均值与方差 {#prop-var}
在中性赖特-费希尔模型中，对所有 $t \ge 0$，

$$
\E[p_t] = p_0,\qquad \Var(p_t) = p_0q_0\left[1 - \left(1 - \frac{1}{2N}\right)^t\right] \approx p_0q_0\left(1 - e^{-t/2N}\right).
$$ {#eq-var}

当 $t \to \infty$ 时方差趋于 $p_0q_0$，即以概率 $p_0$ 取值1、否则取值0的那个量的方差：每个重复群体最终不是固定就是丢失。
:::

::: proof
给定 $p_t$，第 $t + 1$ 代中 $A$ 的拷贝数服从以 $2N$ 次抽样、概率 $p_t$ 的二项分布，故 $\E[p_{t+1}\mid p_t] = p_t$ 且 $\Var(p_{t+1}\mid p_t) = p_tq_t/2N$。取期望得 $\E[p_{t+1}] = \E[p_t] = \cdots = p_0$。

对于方差，考虑 $h_t = \E[p_tq_t]$。在 $p_t$ 给定的条件下，

$$
\E[p_{t+1}q_{t+1}\mid p_t] = \E[p_{t+1}\mid p_t] - \E[p_{t+1}^2\mid p_t] = p_t - \left(\frac{p_tq_t}{2N} + p_t^2\right) = p_tq_t\left(1 - \frac{1}{2N}\right),
$$

于是 $h_t = p_0q_0(1 - 1/2N)^t$。最后 $\Var(p_t) = \E[p_t^2] - p_0^2 = \E[p_t] - h_t - p_0^2 = p_0q_0 - h_t$。
:::

量 $2h_t$ 是期望杂合度，因此[[#eq-var]]就是[[evolution/mutation-drift-gene-flow]]的杂合度衰减换了一副面孔：从群体*内部*杂合度中失去的东西，作为*重复群体之间*的方差重新出现。丢失的比例

$$
F_t = 1 - \left(1 - \frac{1}{2N}\right)^t,
$$ {#eq-ft}

是第 $t$ 代的两个基因拷贝同为第0代同一个祖先基因拷贝的概率，也就是有限群体大小造成的**近交系数**（[[population-genetics/inbreeding]]）。用它，$\Var(p_t) = p_0q_0F_t$ 且 $H_t = H_0(1 - F_t)$：封闭群体中的漂变是一种近交。

### Buri 的果蝇

对这些预言最著名的检验是 Buri 1956年发表的实验。他建立了107个重复的黑腹果蝇 *Drosophila melanogaster* 群体，每个群体由16只果蝇（8雄8雌）奠基，它们对眼色基因 *brown* 的两个等位基因 $bw$ 与 $bw^{75}$ 是杂合的，所以每个品系都从 $p_0 = 0.5$ 出发。每一代他随机从每个品系选出8雄8雌建立下一代，共19代。由于两个等位基因对眼色的效应共显，他能够直接计数等位基因频率。

107个品系上 $p$ 的分布表现正如理论所料：起始时在0.5处有一个峰，逐代铺开，约第10代前后变得几乎平坦，然后随着越来越多的品系丢失或固定 $bw^{75}$ 而在 $p = 0$ 与 $p = 1$ 两类堆高。平均频率保持在0.5附近。然而铺开的*速率*比 $N = 16$ 的预期更快。用[[#eq-var]]或杂合度的衰减拟合数据给出 $N_e \approx 11.5$：即使在精心控制的实验室群体中，每只果蝇后代数的偶然差异也使有效大小小于亲本数目。

::: example 重复品系之间的散布 {#ex-buri}
在一个像 Buri 那样 $N_e = 11.5$、$p_0 = 0.5$ 的品系体系中，19代之后品系间 $p$ 的期望方差与标准差是多少？相对起始值的期望杂合度是多少？若 $N_e$ 为16呢？

取 $2N_e = 23$：$F_{19} = 1 - (22/23)^{19} = 1 - 0.430 = 0.570$。于是 $\Var(p_{19}) = 0.25\times0.570 = 0.143$（标准差0.38），杂合度降到 $1 - F = 43$ %的初始值。$N_e = 16$ 时：$F_{19} = 1 - (31/32)^{19} = 0.453$，方差0.113（标准差0.34），杂合度为初始值的55 %。保留杂合度上12个百分点的差别，正是有效大小得以被估计的原因。注意两种情形下方差都相当大：标准差超过三分之一意味着，对16个亲本随机抽样19代之后，各品系散布在整个0到1的范围里。
:::
:::

### 世代重叠：莫兰模型

赖特-费希尔模型一次性地替换整个群体。莫兰（Patrick Moran，1958）提出了一个适合世代重叠生物的替代方案：每个时间步，随机选定一个个体繁殖，再随机选定一个个体（可能就是亲本本身）死亡。对 $N$ 个个体的单倍体群体，$A$ 个体的数目在每次事件中改变 $+1$、$-1$ 或 $0$，且

$$
\Prob(+1) = \Prob(-1) = \frac{i}{N}\cdot\frac{N - i}{N},
$$

于是每次事件中频率改变的方差为 $2pq/N^2$。一个“世代”是 $N$ 次事件，其间方差累积到约 $2pq/N$，是 $N$ 个单倍体拷贝的赖特-费希尔值 $pq/N$ 的两倍。因此大小为 $N$ 的莫兰群体的漂变如同大小为 $N/2$ 的赖特-费希尔群体：它的有效大小是普查数量的一半。中性等位基因的固定概率仍然是它的频率（同一个鞅论证），多数结果把 $N$ 换成 $N_e$ 即可沿用。这阐明了那条一般法则：**繁殖细节只通过有效大小影响漂变。**

## 到达固定与丢失的时间

漂变要多久？赖特-费希尔模型的马尔可夫链难以精确分析，但当 $N$ 很大、每代改变很小时，等位基因频率表现得像一个连续的**扩散**过程，每代平均改变 $M(p)$、方差 $V(p) = pq/2N_e$。木村资生在1950与1960年代发展了这一近似，此前费希尔与赖特已较早使用过它；下面的结果是它最常被引用的几个推论，这里不给出推导地列出，推导需要后向科尔莫戈洛夫方程（见参考文献中的 Hartl 与 Clark，或 Ewens）。

::: proposition 中性漂变下的平均时间 {#prop-times}
在有效大小为 $N_e$ 的群体中，初始频率为 $p$ 的中性等位基因，扩散近似给出下面的时间（单位：代）：

$$
\bar t(p) = -4N_e\bigl[p\ln p + q\ln q\bigr]\quad\text{（直到固定或丢失）},
$$ {#eq-tabs}

$$
\bar t_1(p) = -\frac{4N_e\,q\ln q}{p}\quad\text{（直到固定，给定固定）},\qquad \bar t_0(p) = -\frac{4N_e\,p\ln p}{q}\quad\text{（直到丢失，给定丢失）}.
$$ {#eq-tcond}

对于新突变，$p = 1/2N$：$\bar t_1 \approx 4N_e$ 代，而 $\bar t_0 \approx 2(N_e/N)\ln(2N)$ 代。
:::

两个特征值得注意。第一，时间正比于 $N_e$：大群体中漂变缓慢，而**群体遗传学中的时间自然以 $N_e$ 代来度量**。第二，新突变的命运极端不对称。在 $N_e = N = 10^4$ 的群体中，一个新的中性突变以概率 $1 - 1/(2\times10^4)$ 丢失，通常就在 $2\ln(2\times10^4) \approx 20$ 代之内；偶然固定下来的那一个平均要用 $4\times10^4$ 代才做到。进化课程中对 $N = 50$ 的模拟得到平均固定时间194代，与预测的 $\approx 4N = 200$ 相当。

::: example 多态要多久才消失？ {#ex-times}
一个有效大小500、世代时间2年的隔离群体中，某等位基因的频率为0.5。平均而言，该基因座多久变为单态？若它最终固定，那平均要花多久？
::: solution
由[[#eq-tabs]]，$\bar t(0.5) = -4\times500\times(0.5\ln0.5 + 0.5\ln0.5) = 2000\ln 2 = 1386$ 代，约2,800年。由对称性，给定固定与给定丢失两个条件下的时间相等：[[#eq-tcond]] 给出 $\bar t_1(0.5) = -4\times500\times0.5\ln0.5/0.5 = 2000\times0.693 = 1386$ 代。一个中等频率的多态在几百个个体的群体中能持续几千年，但撑不过地质时间；在一个百万规模的群体里，它会持续数百万年。
:::
:::

## 向后看：并合理论

前向的模型问群体中的等位基因会怎样。然而数据是以一份 DNA 序列*样本*的形式到来的，而序列之间由谱系相联：沿时间往回走，它们的祖先谱系彼此并合——**coalesce**——直到只剩下一个共同祖先。Kingman（1982）证明，在赖特-费希尔模型及许多其他模型下，当样本相对群体很小时，这一谱系具有简单而普适的形式。并合理论自此成为模拟与解释序列变异的主要工具（Richard Hudson 与 Fumio Tajima 于1983年把它用于序列数据）。

### 两个基因

取当代两个不同的基因拷贝。在赖特-费希尔模型中，每个拷贝从前一代的 $2N$ 个拷贝中独立、均匀地选定父代基因，所以它们拥有同一父代的概率为 $1/2N$。若没有，那么再往前一代的情形完全相同，如此等等。

::: proposition 两个基因的并合时间 {#prop-pair}
在 $2N$ 个拷贝的赖特-费希尔群体中，两个基因拷贝回溯到共同祖先的世代数 $T_2$ 服从几何分布

$$
\Prob(T_2 = t) = \frac{1}{2N}\left(1 - \frac{1}{2N}\right)^{t-1},\qquad \E[T_2] = 2N,
$$ {#eq-pair}

$N$ 大时它近似为均值为 $2N$ 代的指数分布：$\Prob(T_2 > t) \approx e^{-t/2N}$。
:::

$t$ 代之内两个基因*尚未*并合的概率 $(1 - 1/2N)^t$，恰是[[#eq-ft]]的保留杂合度 $1 - F_t$：前向与后向的描述说的是同一件事。

现在加上每基因每代 $\mu$ 的中性突变。一个位点上两条序列不同，当且仅当自共同祖先以来任何一条分支上发生过突变。两条分支的总长为 $2T_2$，所以两者差异数的期望为 $2\mu\E[T_2] = 4N\mu$。记作

$$
\theta = 4N_e\mu,
$$ {#eq-theta}

即**群体突变率**，于是 $\E[\pi] = \theta$（每位点，$\mu$ 按每位点计）。核苷酸多样性估计的是有效大小与突变率的乘积，而不是其中任何一个。

::: example 人类的有效大小 {#ex-human-ne}
人类的核苷酸多样性约为每位点 $\pi = 0.001$，由父母子女三个体（trio）测定的突变率约为每位点每代 $\mu = 1.2\times10^{-8}$。估计长期有效群体大小，以及一个典型中性位点的两个拷贝到共同祖先的期望回溯时间。
::: solution
由 $\pi = 4N_e\mu$，$N_e = 0.001/(4\times1.2\times10^{-8}) \approx 21{,}000$。于是 $\E[T_2] = 2N_e \approx 42{,}000$ 代，以每代25–30年计约一百万年。这个 $N_e$ 是跨越数十万年的长期平均，并由（作为调和平均数的）小数值时期主导；它不是普查估计，与2026年在世的80多亿人相比小得微不足道。已发表的人类 $N_e$ 估计大多在 $10^4$ 量级，且依赖于所假定的突变率：若用较早的系统发育估计 $\mu \approx 2.5\times10^{-8}$，同样的 $\pi$ 给出 $N_e \approx 10{,}000$。因此，一个典型人类基因的两个拷贝，早在智人 *Homo sapiens* 约300,000年前起源之前很久，就已共享一个祖先（[[evolution/human-evolution]]）。
:::
:::

### $n$ 个基因的样本

有了 $n$ 个基因拷贝，$k$ 条谱系中任一对 $\binom k2$ 都可能并合。当 $k$ 相对 $N$ 很小时，一代之内发生一次并合的概率约为 $\binom k2/2N$，而同时发生两次并合的概率可以忽略。以 $2N$ 代为单位度量时间，结果便与 $N$ 无关。

::: definition Kingman 并合模型 {#def-coalescent}
从有效大小为 $N_e$ 的群体中抽取的 $n$ 个中性基因拷贝的谱系，近似为如下过程。从 $k = n$ 条谱系开始，等待一个服从速率 $\binom k2$ 的指数分布的时间 $T_k$（以 $2N_e$ 代为单位）；然后均匀随机地选定一对谱系并把它们并合；令 $k \to k - 1$ 并重复，直到 $k = 1$，即**最近共同祖先**（MRCA）。以代计，$\E[T_k] = \dfrac{4N_e}{k(k-1)}$。中性突变随后以每代 $\mu$ 的泊松过程放置在分支上。
:::

树的形状（哪些谱系相互并合）与时间相互独立，突变过程又与这两者独立——这正是中性的根本简化。选择或群体结构则会改变树本身。

::: proposition 并合模型的性质 {#prop-coalescent}
对 $n$ 个基因的样本，以代计，

$$
\E[T_\mathrm{MRCA}] = 4N_e\left(1 - \frac1n\right),\qquad \E[T_\mathrm{total}] = 4N_e\sum_{i=1}^{n-1}\frac1i = 4N_e\,a_n,
$$ {#eq-tmrca}

其中 $T_\mathrm{total}$ 是全部分支的总长。样本中分离位点数的期望为

$$
\E[S] = \mu\,\E[T_\mathrm{total}] = \theta\,a_n.
$$ {#eq-es}
:::

::: proof
$T_\mathrm{MRCA} = \sum_{k=2}^nT_k$ 且 $\E[T_k] = 4N_e/[k(k-1)] = 4N_e\left(\frac{1}{k-1} - \frac1k\right)$；该和望远镜式相消，得 $4N_e(1 - 1/n)$。当有 $k$ 条谱系时，树上有 $k$ 条正在生长的分支，所以 $T_\mathrm{total} = \sum_k kT_k$ 且 $\E[T_\mathrm{total}] = \sum_{k=2}^n 4N_e/(k - 1) = 4N_ea_n$。在无限位点模型下（每个突变都发生在新位点），树上的每一个突变都造成一个分离位点，而突变数的期望是 $\mu$ 乘以总枝长。
:::

[[#eq-es]] 是 Watterson 估计量 $\theta_W = S/a_n$ 的基础，该估计量在[[population-genetics/hardy-weinberg]]中引入。以下三个推论值得消化。

- **最深的分支占支配。** $\E[T_2] = 2N_e$——只剩最后两条谱系的那段时间——对任何 $n$ 都至少占 $\E[T_\mathrm{MRCA}]$ 的一半。增添更多序列只是在现代附近添些短枝，根的年代几乎不变：$\E[T_\mathrm{MRCA}]$ 在 $n = 2$ 时是 $2N_e$，而只有当 $n \to \infty$ 才趋近 $4N_e$。
- **变异随样本量增长很慢。** $a_n$ 随 $\ln n$ 增长，所以序列多十倍，分离位点只大约多一倍。
- **谱系非常参差。** 即使群体大小固定，单个位点的并合时间也有很大的方差，所以由单个位点得到的估计不精确。精度来自对许多拥有独立谱系的不连锁位点取平均。

### 模拟并合理论

并合理论的模拟极其便宜，因为只追踪样本的祖先，而不是整个群体。下面这段使用标准库的 Python 程序生成 $n = 10$ 个基因、$\theta = 5$ 的谱系，并记录 MRCA 的年代、总枝长与分离位点数。

```python
import random, math

def coalescent(n, theta, rng):
    """One neutral genealogy of n genes; times in units of 2N generations.
    Returns (T_MRCA, total branch length, number of segregating sites)."""
    t_mrca, length = 0.0, 0.0
    for k in range(n, 1, -1):
        rate = k * (k - 1) / 2             # pairs of lineages that can coalesce
        t = rng.expovariate(rate)          # waiting time while k lineages exist
        t_mrca += t
        length += k * t
    lam = theta / 2 * length               # mutation rate per 2N generations = 2N*mu = theta/2
    S, x = 0, rng.expovariate(1.0)
    while x < lam:                         # Poisson(lam) by exponential gaps
        S += 1
        x += rng.expovariate(1.0)
    return t_mrca, length, S

rng = random.Random(42)
runs = [coalescent(10, 5.0, rng) for _ in range(100000)]
for i, name in enumerate(["T_MRCA", "length", "S"]):
    vals = [r[i] for r in runs]
    m = sum(vals) / len(vals)
    v = sum((x - m) ** 2 for x in vals) / (len(vals) - 1)
    print(f"{name}: mean {m:.3f}, sd {math.sqrt(v):.3f}")
```

程序输出（种子42）：$T_\mathrm{MRCA}$ 均值1.802、标准差1.074；总枝长均值5.661、标准差2.476；$S$ 均值14.160、标准差7.259。把均值与[[#prop-coalescent]]比较，并解释为什么 $S$ 的标准差如此大。
::: solution
以 $2N_e$ 代为单位，[[#eq-tmrca]] 给出 $\E[T_\mathrm{MRCA}] = 2(1 - 1/10) = 1.8$ 与 $\E[T_\mathrm{total}] = 2a_{10} = 2\times2.829 = 5.658$，与1.802和5.661吻合。[[#eq-es]] 给出 $\E[S] = \theta a_{10} = 5\times2.829 = 14.14$，与14.16吻合。

$S$ 的方差有两个来源：给定树时突变数的泊松变异，以及树本身的变异。Watterson（1975）证明 $\Var(S) = \theta a_n + \theta^2\sum_{i=1}^{n-1}1/i^2$，这里为 $14.14 + 25\times1.540 = 52.64$，标准差7.26——正是模拟所发现的。其中大部分来自谱系（$\theta^2$ 项），这就是为什么从同一个位点增加更多序列不会使 $\theta$ 的估计精确多少，而增加更多独立位点可以。
:::
:::

## 有效群体大小

一个群体的普查数量与其实际承受的漂变量往往大不相同。**有效群体大小** $N_e$ 是以同样的速率发生漂变的理想赖特-费希尔群体的大小。由于“漂变速率”可以用几种方式度量——群体之间方差的增加、近交的增加、杂合度的衰减，或并合的速率——就有几种定义（方差有效大小、近交有效大小与并合有效大小）。群体大小恒定时它们彼此一致；大小变化时它们可能不同，而并合有效大小正是序列数据所估计的那个。

::: proposition 有效大小的标准公式 {#prop-ne}
对世代离散的二倍体群体：

1. **两性比例不等**，繁殖的雄性 $N_m$ 头、雌性 $N_f$ 头：$N_e = \dfrac{4N_mN_f}{N_m + N_f}$。
2. **大小波动** $N_1, \ldots, N_t$：$\dfrac{1}{N_e} = \dfrac1t\displaystyle\sum_{i=1}^t\dfrac{1}{N_i}$（调和平均数）。
3. **家系大小的方差**：繁殖个体数 $N$ 恒定，每个个体对下一代配子贡献数的方差为 $V_k$（均值为2）时，

$$
N_e = \frac{4N - 2}{V_k + 2}.
$$ {#eq-ne-vk}
:::

第1与第2条已在[[evolution/mutation-drift-gene-flow]]中使用过。第3条（由赖特于1938年给出，这一形式归于 James Crow）把另外两条作为繁殖成功方差的特例包含在内。在赖特-费希尔模型中，每个个体的配子数近似服从均值为2的泊松分布，所以 $V_k \approx 2$ 且 $N_e \approx N$。若每个个体恰好贡献两个后代（$V_k = 0$）——正如拉平家系大小的圈养繁殖计划——则 $N_e \approx 2N$：漂变减半，因为唯一剩下的抽样是家系内部的孟德尔分离。在多数自然群体中 $V_k$ 远大于2：少数个体留下许多后代，而许多个体一个也不留。

::: example 繁殖成功极不均等的群体 {#ex-vk}
一个100条繁殖鱼组成的群体中，存活到繁殖的后代数每亲本均值为2、方差为6。有效大小是多少？若一个孵化场把家系大小拉平呢？
::: solution
由[[#eq-ne-vk]]，$N_e = (400 - 2)/(6 + 2) = 49.75$，约为普查数量的一半。家系大小均等时，$V_k = 0$ 且 $N_e = 398/2 = 199$，约为普查数量的两倍。把贡献拉平的孵化场使有效大小变为这里假定的野生型繁殖下的四倍。反过来的情形也会发生：由少数亲本产生大量放流后代的孵化场计划，会极大地**降低**其所放养的野生群体的有效大小（Ryman–Laikre 效应，1991）。
:::
:::

$N_e$ 相对普查数量 $N$ 有多大？Richard Frankham（1995）对野生动物近200个估计的综述发现，当所有因素（大小波动、性别比、家系方差）都计入时，$N_e/N$ 平均只有约0.1。繁殖力巨大而繁殖成功的方差同样巨大的海洋鱼类，比值可以再低好几个数量级。这正是保护遗传学以 $N_e$ 而非个体计数为工作依据的主要原因（[[conservation-biology/small-populations]]）。它还解释了一个由 Lewontin 于1974年命名的长期谜题的一部分：物种之间遗传多样性的差异，远小于普查数量之间的差异。连锁的选择对大群体的多样性削减得更多，据信它解释了其余部分的很大一块（[[population-genetics/neutral-theory]]）。

### 瓶颈与奠基者事件

一时性的大小缩减对变异有两种不同的影响。它按瓶颈期每代 $1 - 1/2N_b$ 的比例削减杂合度——对短的瓶颈来说这是很小的损失；但它能有效地消灭罕见等位基因，因为频率为 $p$ 的等位基因以概率 $(1 - p)^{2N_b}$ 不出现在 $2N_b$ 个奠基者基因之中。Nei、Maruyama 与 Chakraborty（1975）证明，瓶颈之后的迅速增长使等位基因数目的减少远甚于杂合度的减少，而且靠突变恢复杂合度需要 $1/\mu$ 量级的世代数。

::: example 十个奠基者 {#ex-founders}
一个新岛屿群体由随机取自大陆大群体的10个二倍体个体奠基。(a) 预期保留大陆杂合度的多大比例？(b) 大陆频率为0.05的一个等位基因在奠基者中缺失的概率是多少？(c) 频率为0.01的呢？
::: solution
(a) 抽样 $2N_b = 20$ 个基因一代，保留 $1 - 1/20 = 95$ %的杂合度。

(b) $(1 - 0.05)^{20} = 0.358$：这类等位基因有超过三分之一丢失。

(c) $(0.99)^{20} = 0.818$：频率1 %的等位基因大多丢失。奠基者保住了大部分杂合度——杂合度由常见等位基因主导——却丢失了大部分罕见等位基因。于是奠基者群体可能表现出某些碰巧存在于奠基者中的罕见等位基因的不寻常频率——这一模式在许多与世隔绝的人类社区以及动植物的岛屿群体中都能看到。
:::
:::

sliders: Nb=10:1:100:1

::: warning "漂变只在极小的群体中才要紧"
漂变在每一个有限群体中都起作用，其效应按 $1/N_e$ 缩放，而不按普查数量缩放。许多有数百万个体的物种，有效大小只有几千。即使漂变在单独一代中很弱，对选择系数满足 $\lvert s\rvert \ll 1/N_e$ 的等位基因它也是支配力量——这包括全部突变中的很大一部分——而它在 $N_e$ 代之内的累积效应从不微小。反过来，漂变也不是有方向的“力”：它平均而言既不使群体变差，也不使等位基因变稀；它使它们的频率波动。
:::

::: quiz
其他条件不变，哪种改变会**提高**一个40只动物圈养群体的有效大小？
- [ ] 让优势的一对产生大部分后代，因为它们最健康。
- [ ] 让群体大小在80与10之间循环波动。
- [x] 让每只动物贡献的后代数均等。
- [ ] 只用5雄与35雌。
::: solution
家系大小均等使 $V_k$ 趋于0，由[[#eq-ne-vk]]把 $N_e$ 提高到 $2N - 1 = 79$ 附近。繁殖集中会抬高 $V_k$ 并压低 $N_e$；在80与10之间循环给出约18的调和平均数；而5雄35雌给出 $4\times5\times35/40 = 17.5$。
:::
:::

::: application 小群体的遗传管理
动物园与保护计划利用本章的理论来减缓小群体多样性的丢失：均等化家系大小与性别比，使 $N_e$ 尽可能大；按与群体其余成员的平均亲缘度选择繁殖对（使代表性不足的奠基者基因得到扩散）；以及在群体之间转移个体。一个常用的经验法则旨在100年内保留90 %的奠基者杂合度。由[[#eq-ft]]，设世代长度为 $L$ 年，这要求 $(1 - 1/2N_e)^{100/L} \ge 0.9$；$L = 10$ 年时给出 $N_e \ge 48$，而圈养条件下 $N_e/N$ 常常只有0.1–0.3，因此普查数量需要达到几百。这些思想在[[conservation-biology/conservation-genetics]]中进一步发展。
:::

::: intuition 同一过程的两种视角
沿时间向前，漂变是等位基因频率的随机游走，终结于0或1。沿时间向后，它是谱系的并合：两个基因回溯到同一父代的概率为每代 $1/2N$。两种视角是同一个陈述——杂合度恰好以基因对并合的速率丢失。后向视角对数据要高效得多，因为一个样本的历史只涉及寥寥几条祖先谱系而不是整个群体，而且中性突变可以在谱系建好之后再放置上去。
:::

::: history
费希尔（1922）与赖特（1931）各自独立地分析了随机遗传漂变——有人称之为“苏厄尔·赖特效应”，而赖特不喜欢这个名称——两人合力导出了二项抽样模型、杂合度衰减速率，以及突变、迁移与选择之下等位基因频率的分布。赖特在1931年引入了有效群体大小，1938年给出家系方差公式。Buri 的107个 *Drosophila* 品系（1956）在实验上证实了这些预言。莫兰在1958年提出了他的世代重叠模型；木村资生从1955年起系统化了扩散近似，并与太田朋子在1969年导出了到达固定的平均时间。谱系视角由 J. F. C. Kingman 的《并合理论》（“The coalescent”，1982）严格化，Richard Hudson（1983）与 Fumio Tajima（1983）把它应用于 DNA 序列样本，开启了由序列数据作推断的现代。
:::

::: summary
- 中性漂变下 $\E[p_t] = p_0$ 且 $\Var(p_t) = p_0q_0F_t$，其中 $F_t = 1 - (1 - 1/2N)^t$：群体内部失去的方差在群体之间重现（[[#prop-var]]）。Buri 的果蝇证实了这一点，16个亲本给出 $N_e \approx 11.5$。
- 莫兰模型（世代重叠）有 $N_e = N/2$；繁殖细节只通过 $N_e$ 影响漂变。
- 频率为 $p$ 的多态大约持续 $-4N_e(p\ln p + q\ln q)$ 代；一个固定下来的中性突变约需 $4N_e$ 代，而大多数在约 $2\ln(2N)$ 代内丢失（[[#prop-times]]）。
- 向后看，两个基因每代以概率 $1/2N_e$ 并合，均值为 $2N_e$ 代；$n$ 个基因以每 $2N_e$ 代 $\binom k2$ 的速率并合（[[#def-coalescent]]）。
- $\E[T_\mathrm{MRCA}] = 4N_e(1 - 1/n)$ 且 $\E[S] = \theta a_n$，其中 $\theta = 4N_e\mu$；$\E[\pi] = \theta$（[[#prop-coalescent]]）。
- 性别比不等、大小波动（调和平均数）与家系大小的方差都会缩小 $N_e$，$N_e = (4N - 2)/(V_k + 2)$；野生群体中 $N_e/N$ 通常约为0.1。
- 瓶颈丢失罕见等位基因远快于丢失杂合度。
:::

## 习题

::: exercise 50代之后的方差 {level=1 check="0.0987"}
在 $N = 50$ 的赖特-费希尔群体中，某等位基因起始于 $p_0 = 0.5$。50代之后各重复群体中其频率的方差是多少（保留四位小数）？
::: solution
$\Var(p_{50}) = 0.25\,[1 - (1 - 1/100)^{50}] = 0.25\times(1 - 0.605) = 0.0987$。
:::

::: exercise 一对拷贝的共同祖先 {level=1 check="20000"}
在 $N_e = 10{,}000$ 的群体中，一个中性基因座上两个基因拷贝回溯到共同祖先的期望世代数是多少？
::: solution
$\E[T_2] = 2N_e = 20{,}000$ 代（以每代25年计约500,000年）。
:::

::: exercise 家系大小的方差 {level=1 check="33"}
一个由50个繁殖成体组成、大小恒定的群体，每个个体对下一代的配子贡献数的方差为4。它的有效大小是多少？
::: solution
$N_e = (4\times50 - 2)/(4 + 2) = 198/6 = 33$。
:::
:::

::: exercise 期望的分离位点数 {level=2 check="20.8333"}
从一个整个基因座 $\theta = 4N_e\mu = 10$ 的群体中取一个中性基因座的五条序列。期望有多少个分离位点？
::: solution
$a_5 = 1 + \tfrac12 + \tfrac13 + \tfrac14 = 2.0833$，故 $\E[S] = 10\times2.0833 = 20.83$。
:::
:::

::: exercise 由多样性估计有效大小 {level=2 check="200000"}
某物种的沉默位点核苷酸多样性为 $0.004$，突变率为每位点每代 $5\times10^{-9}$。估计 $N_e$。
::: solution
$N_e = \pi/(4\mu) = 0.004/(2\times10^{-8}) = 2\times10^5$。这假定沉默位点是中性的、群体大小恒定、且 $\mu$ 准确；每个假设都是误差来源。
:::
:::

::: exercise 丢失一个罕见等位基因 {level=2 check="0.3487"}
一个群体由取自大源群体的5个个体重建，源群体中某等位基因的频率为0.1。该等位基因在奠基者中缺失的概率是多少（保留四位小数）？
::: solution
奠基者携带 $2\times5 = 10$ 个基因拷贝，故概率为 $0.9^{10} = 0.3487$。
:::
:::

::: exercise 由实验估计 Ne {level=2}
在以每代16个亲本维持的重复品系中，平均杂合度在19代内从0.500降到0.215。(a) 估计 $N_e$。(b) 给出它小于16的两个生物学理由。
::: solution
(a) $(1 - 1/2N_e)^{19} = 0.215/0.500 = 0.430$，故 $1 - 1/2N_e = 0.430^{1/19} = 0.9565$，得 $2N_e = 23.0$、$N_e \approx 11.5$——Buri 的估计。

(b) 每个亲本的后代数超出泊松期望的变异（有些果蝇繁殖力更强或交配更成功，或它们的幼虫在拥挤的培养瓶里存活更好），以及 *brown* 等位基因或与其连锁的位点上的选择，都会加剧频率的改变。有效雌雄数目不等也会拉低 $N_e$。
:::
:::

::: exercise 树的一半是最后两条谱系 {level=3}
(a) 证明只剩两条谱系的期望时间占期望 MRCA 时间的比例为 $\E[T_2]/\E[T_\mathrm{MRCA}] = \dfrac{n}{2(n - 1)}$，并对 $n = 2$、10和50求值。(b) 解释为什么对同一个群体多测一些个体几乎无法提高 MRCA 年龄的估计精度，而什么才能提高。
::: solution
(a) $\E[T_2] = 2N_e$ 且 $\E[T_\mathrm{MRCA}] = 4N_e(1 - 1/n) = 4N_e(n - 1)/n$，所以比例为 $n/[2(n - 1)]$：$n = 2$ 时为1，$n = 10$ 时为0.556，$n = 50$ 时为0.510。它永不低于二分之一。

(b) 根的年龄由 $T_2$——最后两条谱系的等待时间——主导，它是均值为 $2N_e$ 的指数分布，且无论 $n$ 是多大方差都一样大：中等规模的样本已经以高概率包含了根处两个分支的后代，额外的序列只是在末端附近增添短枝。精度来自拥有各自谱系的许多独立位点，或来自对 $\mu$ 与 $N_e$ 更好的了解。
:::
:::

::: exercise 一个循环波动的群体 {level=3}
一个田鼠群体在丰年的10,000与灾年的100之间交替（一年一代）。(a) 计算它的有效大小。(b) 丢失一半杂合度需要多少代？(c) 与大小恒为算术平均数的群体比较。
::: solution
(a) $1/N_e = \tfrac12(10^{-4} + 10^{-2}) = 0.00505$，故 $N_e = 198$。

(b) $t_{1/2} \approx 2N_e\ln 2 = 274$ 代。

(c) 算术平均数为5,050，给出 $t_{1/2} \approx 7{,}000$ 代。灾年占支配：循环波动的群体丢失多样性的速度，约为按其平均大小所做预期的25倍。
:::
:::

::: exercise 莫兰模型 {level=3}
$N$ 个个体的单倍体莫兰模型中，每次事件独立且均匀随机地选定一个个体繁殖、一个个体死亡。(a) 证明类型 $A$ 的频率 $p = i/N$ 以概率 $pq$ 改变 $+1/N$、以概率 $pq$ 改变 $-1/N$，其余情形不变。(b) 证明每次事件中 $p$ 改变的方差为 $2pq/N^2$，从而 $N$ 次事件（一代）的方差约为 $2pq/N$。(c) 由此证明莫兰模型的漂变如同大小为 $N/2$ 的赖特-费希尔单倍体群体，并给出一个固定下来的新中性突变期望所需的世代数。
::: solution
(a) 若一个 $A$ 繁殖而一个 $a$ 死亡，则 $A$ 的计数上升，概率 $p\cdot q$；若一个 $a$ 繁殖而一个 $A$ 死亡，则下降，概率 $q\cdot p$。

(b) 平均改变为0，故方差为 $\E[(\Delta p)^2] = 2pq\cdot(1/N)^2 = 2pq/N^2$。在 $N$ 次事件中 $p$ 改变很小，各方差相加：$N\times2pq/N^2 = 2pq/N$。

(c) 大小为 $M$ 的单倍体赖特-费希尔群体每代方差为 $pq/M$，当 $M = N/2$ 时它等于 $2pq/N$。$M$ 个拷贝的单倍体赖特-费希尔群体中新突变的条件固定时间约为 $2M$ 代（即二倍体的 $4N_e$，此处 $2N_e = M$），所以这里约为 $2\times N/2 = N$ 代，即 $N^2$ 次生-死事件。
:::
:::
