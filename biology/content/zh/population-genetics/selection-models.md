自然选择是唯一与生物体运作的有效程度存在系统关系的进化力量，群体遗传学的创立在很大程度上正是为了理解它。进化课程已经导出了基本方程——单倍体中的选择、单基因座的二倍体递推、显性、隐性致死与杂合子优势（[[evolution/natural-selection]]）。本章把它们推得更远。我们分开适合度的各个成分，并追问要使这些模型成立"适合度"必须是什么意思；用等位基因的边际适合度改写动力学，使多个等位基因和一般性结果一目了然；用连续时间近似得到闭式的选择清除耗时；系统地分析平衡及其稳定性；以单基因座形式认识费希尔（Fisher）的基本定理；再加上自然界中要紧的两个复杂情形——频率依赖性选择与波动的环境。最后谈选择如何度量。

全书假定群体足够大、漂变可以忽略，随机交配且世代离散。漂变在[[population-genetics/genetic-drift]]中加入，而两者的交互作用是后续课程的主要主题之一。

## 适合度意味着什么

一个个体对下一代的贡献，是生命周期若干阶段的乘积：从合子存活到成体（**存活率**）、获得配偶（**交配成功**）、产生配子或后代（**繁殖力**或育性）。选择可以作用于其中任何一个阶段，也可以作用于配子之间或基因组本身。

::: definition 适合度的成分与适合度的度量 {#def-fitness-components}
对基因型 $G$，**绝对适合度** $W_G$ 是这一代中一个基因型为 $G$ 的合子对下一代合子的期望贡献数，两代都在生命周期的同一阶段计数。设存活率 $v_G$（存活到繁殖的概率）、交配成功 $m_G$ 与繁殖力 $f_G$ 相互独立，则 $W_G = v_Gm_Gf_G$。**相对适合度**是对选定的参考基因型有 $w_G = W_G/W_\mathrm{ref}$。连续时间下，**马尔萨斯适合度**是每一代的人均增长率 $r_G = \ln W_G$，而选择只取决于差 $r_G - r_\mathrm{ref}$。
:::

这个定义有三个值得指出的推论，因为粗心的论证常常违反它们。

- **适合度必须在一个完整世代上、在同一阶段计数。** 对一个基因型数到成体的幸存者、对另一个却数卵，或对不同长度的时间测适合度，得到的比较毫无意义。
- **只有相对适合度决定频率的改变**（方程只依赖适合度之比），但绝对适合度决定群体能否存续。一个群体完全可以在相对表现上不断变好的同时，数量一路下降到灭绝。
- **简单模型假定适合度是个体基因型的属性。** 若繁殖力取决于*配对*——例如某两种特定基因型之间的交配生育力较低——选择就作用于交配组合，合子可能偏离哈迪-魏因贝格比例。这类育性选择需要更精细的模型（经典案例是 Rh 血型基因座的母胎不相容）。

### 个体之下的水平的选择

孟德尔第一定律本身就是一个假设。**减数分裂驱动**（分离畸变）发生在杂合子把一个等位基因传给多于半数配子之时。小家鼠 *Mus musculus* 的 *t* 单倍型可被杂合雄性传给多达90 %乃至更多的后代，黑腹果蝇 *D. melanogaster* 的 *Segregation Distorter* 系统同样杀死携带敏感染色体的精子。这类"自私"元件即使降低携带者的适合度也能扩散，这一点我们在下面的警告中再谈。工程化的基因驱动利用的正是同一原理（[[biotechnology]]）。

## 用边际适合度书写的动力学

[[evolution/natural-selection]]的二倍体递推可以写成一个既使含义清晰、又能立刻推广到多个等位基因的形式。

::: definition 等位基因的边际适合度 {#def-marginal}
在具有等位基因频率 $p_1, \ldots, p_k$ 与基因型适合度 $w_{ij}$ 的随机交配群体中，等位基因 $A_i$ 的**边际适合度**是携带它的各基因型的平均适合度，以 $A_i$ 的一份拷贝发现自己处于各基因型的概率加权：

$$
w_i = \sum_{j} p_j\,w_{ij}.
$$ {#eq-marginal}

平均适合度为 $\bar w = \sum_i p_iw_i = \sum_{i,j}p_ip_jw_{ij}$。
:::

一份 $A_i$ 拷贝与群体中的一个随机配子配对，后者以概率 $p_j$ 携带 $A_j$；所以 $w_i$ 就是这份拷贝所处的个体的期望适合度。

::: proposition 边际适合度形式的单基因座选择 {#prop-marginal}
合子阶段处于哈迪-魏因贝格比例、随机交配下的存活选择，

$$
p_i' = p_i\,\frac{w_i}{\bar w},\qquad \Delta p_i = \frac{p_i\,(w_i - \bar w)}{\bar w}.
$$ {#eq-marginal-dp}

两个等位基因时，记 $\alpha = w_1 - w_2$ 为边际适合度之差，

$$
\Delta p = \frac{pq\,\alpha}{\bar w},\qquad \alpha = p(w_{11} - w_{12}) + q(w_{12} - w_{22}).
$$ {#eq-alpha}
:::

::: proof
合子中，每个有序对基因型 $A_iA_j$ 的频率为 $p_ip_j$（纯合子为 $p_i^2$，杂合子为 $2p_ip_j$）。选择后，幸存者中 $A_i$ 的频率是幸存基因拷贝中 $A_i$ 所占的比例。每个有序对贡献自己的第一份拷贝；第一份拷贝为 $A_i$ 的权重是 $\sum_j p_ip_jw_{ij} = p_iw_i$，总权重为 $\sum_ip_iw_i = \bar w$。故 $p_i' = p_iw_i/\bar w$。两个等位基因时，$\bar w = pw_1 + qw_2$ 且 $w_1 - \bar w = q(w_1 - w_2)$，得 $\Delta p = pq(w_1 - w_2)/\bar w$；且 $w_1 - w_2 = pw_{11} + qw_{12} - pw_{12} - qw_{22}$。
:::

[[#eq-marginal-dp]]说，**一个等位基因上升当且仅当它的携带者平均而言比群体更适合**。因此所有等位基因共存的内部平衡正是所有边际适合度相等的点。量 $\alpha$——$A_1$ 携带者与 $A_2$ 携带者平均适合度之差——称为 $A_1$ 的（适合度）**平均超额**。随机交配下它等于用 $A_1$ 替换 $A_2$ 的**平均效应**，这一概念在数量遗传学中再次出现（[[population-genetics/quantitative-traits]]）。

### 连续时间与选择清除耗时

当选择很弱（$s \ll 1$）时，等位基因频率每代改变很小，可以把差分方程换成微分方程。在参数化 $w_{11} = 1 + s$、$w_{12} = 1 + hs$、$w_{22} = 1$ 下，$\alpha = s[h + p(1 - 2h)]$ 且 $\bar w \approx 1$，于是

$$
\frac{dp}{dt} \approx s\,p\,q\,[\,h + p(1 - 2h)\,].
$$ {#eq-continuous}

用部分分式可以对三个经典情形积分。

::: proposition 选择清除的持续时间 {#prop-sweep}
在[[#eq-continuous]]下，受青睐等位基因的频率从 $p_0$ 升到 $p_1$ 所需的世代数为，其中 $L = \ln\dfrac{p_1q_0}{p_0q_1}$：

$$
t \approx
\begin{cases}
\dfrac{2}{s}\,L & h = \tfrac12\ \text{（加性）},\\[2ex]
\dfrac{1}{s}\left(L + \dfrac{1}{p_0} - \dfrac{1}{p_1}\right) & h = 0\ \text{（隐性）},\\[2ex]
\dfrac{1}{s}\left(L + \dfrac{1}{q_1} - \dfrac{1}{q_0}\right) & h = 1\ \text{（显性）}.
\end{cases}
$$ {#eq-sweep}
:::

::: proof
分离变量：$t = \int_{p_0}^{p_1}\frac{dp}{s\,pq\,[h + p(1-2h)]}$。$h = \tfrac12$ 时被积函数为 $\frac{2}{s}\cdot\frac{1}{pq}$，而 $\frac{1}{pq} = \frac1p + \frac1q$ 的积分为 $\ln\frac{p}{q}$。$h = 0$ 时为 $\frac{1}{s}\cdot\frac{1}{p^2q}$，而 $\frac{1}{p^2q} = \frac{1}{p^2} + \frac{1}{p} + \frac{1}{q}$ 的积分为 $-\frac1p + \ln\frac pq$。$h = 1$ 时为 $\frac1s\cdot\frac{1}{pq^2}$，而 $\frac{1}{pq^2} = \frac{1}{q^2} + \frac1p + \frac1q$ 的积分为 $\frac1q + \ln\frac pq$。代入上下限即得[[#eq-sweep]]。
:::

附加项 $1/p_0$ 与 $1/q_1$ 正是显性的两处瓶颈的标记：受青睐的隐性等位基因在罕见时是隐形的，而受青睐的显性等位基因找不到藏在杂合子里的最后那些隐性拷贝。

::: example 检验连续近似 {#ex-sweep}
一个新等位基因给纯合子带来5 %的优势（$s = 0.05$）。若是加性、隐性或显性，从 $p = 0.01$ 升到 $0.99$ 各需多久？与离散递推的精确迭代（给出377、2171和2265代）比较。
::: solution
这里 $L = \ln\frac{0.99\times0.99}{0.01\times0.01} = \ln 9801 = 9.190$。

- 加性：$t \approx (2/0.05)\times9.190 = 368$ 代（精确377）。
- 隐性：$t \approx 20\,(9.190 + 100 - 1.010) = 2164$（精确2171）。
- 显性：$t \approx 20\,(9.190 + 100 - 1.010) = 2164$（精确2265）。

前两个情形近似的误差不超过3 %。显性等位基因的近似偏短5 %：这次清除的大部分时间耗在 $p = 1$ 附近，那里平均适合度接近 $1 + s = 1.05$ 而不是1，我们丢掉的因子 $1/\bar w$ 让离散过程慢了约5 %。隐性等位基因则把大部分时间耗在 $p = 0$ 附近，那里 $\bar w \approx 1$，近似极好。这两种情形的大部分时间都花在 $1/p_0$ 或 $1/q_1$ 项上——即慢速阶段——而逻辑斯蒂部分 $L$ 只占约9 %。
:::
:::

## 平衡及其稳定性

对两个等位基因，[[#eq-alpha]]的平衡点是 $p = 0$、$p = 1$，以及使 $\alpha(\hat p) = 0$ 的内部 $\hat p$，即 $w_1 = w_2$。$\alpha$ 对 $p$ 是线性的，所以至多有一个内部平衡（除非诸适合度全都相等）：

$$
\hat p = \frac{w_{22} - w_{12}}{w_{11} - 2w_{12} + w_{22}},
$$ {#eq-interior}

它落在0与1之间当且仅当 $w_{12}$ 同时大于两个纯合子的适合度（超显性）或同时小于两者（下显性）。

要判断一个平衡是否稳定，我们线性化。对以 $\hat p$ 为不动点的离散映射 $p' = f(p)$，若 $\lvert f'(\hat p)\rvert < 1$ 则局部稳定，若 $\lvert f'(\hat p)\rvert > 1$ 则不稳定，且当 $0 < f'(\hat p) < 1$ 时逼近是单调的（差分方程见[数学图谱](/learn/maths/)）。

::: proposition 单基因座平衡的稳定性 {#prop-stability}
对适合度为 $w_{11}, w_{12}, w_{22}$ 的两个等位基因：

1. $w_{12} < w_{22}$ 时 $p = 0$ 稳定，$w_{12} > w_{22}$ 时不稳定；$w_{12} < w_{11}$ 时 $p = 1$ 稳定，$w_{12} > w_{11}$ 时不稳定。$p = 0$ 附近，$p' \approx (w_{12}/w_{22})\,p$。
2. 内部平衡[[#eq-interior]]在超显性下稳定，在下显性下不稳定。其附近有

$$
p' - \hat p \approx \left(1 - \frac{\hat p\hat q\,(2w_{12} - w_{11} - w_{22})}{\bar w(\hat p)}\right)(p - \hat p).
$$ {#eq-stability}
:::

::: proof
（1）$A_1$ 罕见时，它的拷贝几乎全在杂合子中，所以 $w_1 \approx w_{12}$ 且 $\bar w \approx w_{22}$；由[[#eq-marginal-dp]]，$p' \approx p\,w_{12}/w_{22}$，当 $w_{12} > w_{22}$ 时增长，否则缩小。$p = 1$ 的情形对称。

（2）记 $\Delta p = g(p) = pq\,\alpha(p)/\bar w$。由于 $\alpha(\hat p) = 0$，导数在 $\hat p$ 处为 $g'(\hat p) = \hat p\hat q\,\alpha'(\hat p)/\bar w(\hat p)$，其中 $\alpha'(p) = w_{11} - 2w_{12} + w_{22}$。于是 $f'(\hat p) = 1 + g'(\hat p)$，即[[#eq-stability]]。超显性下 $\alpha' < 0$，故 $f'(\hat p) < 1$。它还非负：取 $w_{12} = 1$、$w_{11} = 1 - s$、$w_{22} = 1 - t$（$0 < s, t \le 1$），有 $\hat p\hat q(s + t) = st/(s + t) = 1 - \bar w(\hat p)$，所以 $f'(\hat p) = 1 - (1 - \bar w)/\bar w = (2\bar w - 1)/\bar w$，由 $\bar w \ge \tfrac12$ 落在 $[0, 1)$ 内。平衡稳定且被单调逼近。下显性下 $\alpha' > 0$ 且 $f'(\hat p) > 1$：不稳定。
:::

结果（1）是**入侵判据**，值得单独记住：一个罕见等位基因能否进入群体，只取决于它的杂合子与住家纯合子相比如何。若 $p = 0$ 与 $p = 1$ 都不稳定，则每个等位基因都能入侵对方，群体被维持在一个**保护性多态**之中。

::: example 大鼠的华法林抗性 {#ex-warfarin}
抗凝血剂华法林从1950年代起被大量用于对付挪威大鼠 *Rattus norvegicus*，英国等地的抗性群体在大约十年内就出现了。抗性源自 *Vkorc1* 基因的变体，该基因编码华法林的靶酶。抗性纯合子对维生素 K 的膳食需求要高得多，所以在施用华法林的地方，两种纯合子都吃亏：敏感大鼠被毒死，抗性纯合子则维生素 K 缺乏。取施用华法林时的实例适合度 $w_{SS} = 0.68$、$w_{SR} = 1$、$w_{RR} = 0.37$。求平衡、检验其稳定性，并给出平均适合度。
::: solution
在 $w_{11} = 1 - s$、$w_{12} = 1$、$w_{22} = 1 - t$ 且 $A_1 = S$ 的记法下：$s = 0.32$、$t = 0.63$。由[[#eq-interior]]（或[[evolution/natural-selection]]），$\hat p_S = t/(s + t) = 0.63/0.95 = 0.663$ 且 $\hat q_R = 0.337$。那里的平均适合度为 $\bar w = 1 - st/(s + t) = 1 - 0.2016/0.95 = 0.788$。

稳定性方面，$2w_{12} - w_{11} - w_{22} = s + t = 0.95$，由[[#eq-stability]]

$$
f'(\hat p) = 1 - \frac{0.663\times0.337\times0.95}{0.788} = 1 - 0.269 = 0.731.
$$

由于 $0 < 0.731 < 1$，平衡稳定且被单调逼近；偏离每代约缩小27 %。模型预言只要继续使用华法林，抗性就保持多态，停用后便下降——两者都在1970年代研究的威尔士大鼠群体中得到证实。灭鼠随后改用第二代抗凝血剂，而后者又选择了新的 *Vkorc1* 变体：这是抗性进化管理的一个教训。
:::
:::

::: example 一个下显性的染色体重排 {#ex-underdominance}
相互易位使杂合子的育性降低，因为它们产生一些不平衡的配子。设 $w_{11} = 1$（易位纯合子，完全可育且适应略好）、$w_{12} = 0.8$、$w_{22} = 0.9$（标准纯合子）。求阈值，并说明在一个大群体中作为单个拷贝出现的易位会怎样。
::: solution
由[[#eq-interior]]，$\hat p = (0.9 - 0.8)/(1 - 1.6 + 0.9) = 0.1/0.3 = 1/3$。由于 $w_{12}$ 低于两个纯合子，这一平衡不稳定：$p > 1/3$ 时易位走向固定，$p < 1/3$ 时丢失。新的易位起始频率接近0，由[[#prop-stability]]，那里 $p' \approx (0.8/0.9)\,p$，它被淘汰，尽管群体若固定了它会更适合（$\bar w = 1$ 对 $0.9$）。在大群体中选择无法越过山谷；在小群体中，漂变偶尔能把重排推过阈值（[[population-genetics/genetic-drift]]），这是染色体重排在群体小且分成许多亚群物种中固定得更频繁的原因之一。同样的阈值逻辑被用于为害虫防治提出的"下显性"基因驱动：它们只有释放在阈值之上才扩散，因而停留在局部。
:::

## 平均适合度与费希尔的基本定理

[[evolution/natural-selection]]中二倍体递推的第二种形式 $\Delta p = \frac{pq}{2\bar w}\frac{d\bar w}{dp}$ 说，$p$ 沿曲线 $\bar w(p)$ 往上爬。平衡点是 $\bar w$ 取驻留之处：超显性下是峰，下显性下是谷。把 $\bar w$ 对 $p$ 作图，画出的正是苏厄尔·赖特（Sewall Wright）的单个基因座的**适应景观**。

::: widget plot
f: 1 - s*x^2 - t*(1 - x)^2
x: 0, 1
sliders: s=0.32:-0.5:0.9:0.01; t=0.63:-0.5:0.9:0.01
labels: \bar w(p)
caption: 平均适合度 $\bar w = (1-s)p^2 + 2pq + (1-t)q^2 = 1 - sp^2 - tq^2$ 对 $A_1$ 的频率 $p$ 的曲线，适合度与蛛网图相同。选择之下 $p$ 向高处移动。$s, t > 0$ 时曲线在 $\hat p = t/(s+t)$ 有一个单峰，即稳定平衡，其高度为 $1 - st/(s+t)$——低于1，因为群体不可能只由杂合子组成。$s, t < 0$ 时曲线中间是谷、两端是两个峰：群体沿着自己所在的那面坡爬上去，即使最后落在较低的峰上。
:::

平均适合度增长有多快？对两个等位基因，平均超额 $\alpha$ 定义了**适合度的加性遗传方差**

$$
V_A = 2pq\,\alpha^2,
$$ {#eq-va-fitness}

即用个体所携带 $A_1$ 的拷贝数对适合度作线性回归所能解释的适合度方差（这一定义对任意性状的展开见[[population-genetics/quantitative-traits]]）。

::: proposition 费希尔的基本定理，单基因座形式 {#prop-fisher}
随机交配、恒定存活选择下的两个等位基因，对 $\Delta p$ 取一阶，

$$
\Delta\bar w \approx \frac{V_A}{\bar w} = \frac{2pq\,\alpha^2}{\bar w}.
$$ {#eq-fisher}

等位基因对适合作用加性时结果精确。这一模型下平均适合度永不下降。
:::

::: proof
由于 $\bar w$ 是 $p$ 的二次函数且 $d\bar w/dp = 2\alpha$（把 $\bar w = p^2w_{11} + 2pqw_{12} + q^2w_{22}$ 在 $q = 1 - p$ 下求导，并与[[#eq-alpha]]比较），

$$
\Delta\bar w = 2\alpha\,\Delta p + \tfrac12\bar w''(\Delta p)^2 = \frac{2pq\,\alpha^2}{\bar w} + O\bigl((\Delta p)^2\bigr),
$$

其中用了 $\Delta p = pq\alpha/\bar w$。加性适合度下 $\bar w$ 对 $p$ 线性（$\bar w'' = 0$），结果精确。首项永不取负；修正量为 $s^2$ 阶，所以弱选择下只要 $V_A > 0$，$\bar w$ 就增大。（单基因座任意恒定适合度、任意数目等位基因下 $\bar w$ 永不下降的精确结论，由 P. A. G. Scheuer 与 S. P. H. Mandel 于1959年证明，H. P. Mulholland 与 C. A. B. Smith 又独立证明了它，J. F. C. Kingman 在1961年作了推广。）
:::

罗纳德·费希尔（Ronald Fisher）在1930年用文字表述了他的定理——"任何生物在任何时候适合度的增长速率，等于它那时候适合度中的遗传方差"——并称它之于生物学犹如热力学第二定律之于物理学那样基本。它的准确含义争论了几十年。George Price（1972）与 Anthony Edwards 表明，费希尔指的只是由等位基因频率的改变造成的*部分*变化，而把"环境"（包括显性、上位互作以及其他基因型的频率）保持不变。在这一解读下定理精确而普遍；平均适合度的*总*变化可以为负，因为随着群体进化，环境在变坏。

::: warning “选择最大化平均适合度”与“选择为物种的利益服务”
适应景观的图景只在单个基因座、适合度恒定、随机交配时精确成立。适合度随频率变化时，选择在进行而平均适合度可以下降（下一节有一个例子）；两个以上基因座存在连锁，或非随机交配时，$\bar w$ 未必被最大化；[[#ex-underdominance]]中，选择把群体按在较低的峰上。选择通过个体的繁殖成功与等位基因的传递起作用，而不是为群体的利益：使分离扭曲的减数分裂驱动因子因为被更频繁地传递而扩散，即使它降低育性，而原则上这样的因子能把群体引向灭绝。一些工程化的基因驱动正是被设计来做这件事的。
:::

## 频率依赖性选择

一个基因型的适合度常常取决于它有多常见。**负频率依赖性选择**（稀有的更适合）不需要任何杂合子优势就能维持多态；**正频率依赖性选择**（常见的更适合）则消灭多态。

经典的负频率依赖案例有植物的自交不亲和等位基因：携带某 *S* 等位基因的花粉不能给携带同一等位基因的植株授精，于是稀有的等位基因找到更多可亲和的配偶（苏厄尔·赖特在1939年分析过这一现象）；针对已适应最常见宿主基因型的寄生虫与病原体（[[evolution/coevolution]]）；以及坦噶尼喀湖吃鳞的慈鲷 *Perissodus microlepis*，其嘴向左或向右扭曲。Michio Hori（1993）发现，较常见的类型捕食较不成功，因为猎物鱼学会了护卫更常受袭的那一侧；十年观察中两个变型围绕二分之一振荡。正频率依赖见于警戒色：捕食者学会避开常见的图案，于是不常见的图案被攻击得更多（[[evolution/coevolution]]）。

一个单倍体模型能展示要点。设类型 $A$（频率 $p$）与类型 $a$ 的适合度为

$$
w_A = 1 + b\left(\tfrac12 - p\right),\qquad w_a = 1 - b\left(\tfrac12 - p\right),\qquad 0 < b \le 2,
$$

于是每种类型稀有时都干得更好。这时 $p' = p\,w_A/\bar w$ 在 $p = \tfrac12$ 处有内部平衡，那里两者适合度相等。在其附近，记 $p = \tfrac12 + \varepsilon$，有 $p' \approx \tfrac12 + \varepsilon(1 - b/2)$，所以映射的斜率为 $1 - b/2$，介于0与1之间：平衡稳定（[[#exr-fds]]）。注意平均适合度 $\bar w = pw_A + qw_a = 1 - 2b(p - \tfrac12)^2$ 在这一对称模型中于平衡处*最大*，但在非对称的频率依赖下，平衡未必是 $\bar w$ 最大之处——选择使各类型的适合度相等，而不是使平均者最大。

## 变化环境中的选择

适合度随年份因气候、食物和捕食者而变化。长期来看哪种类型获胜？

::: proposition 几何平均适合度 {#prop-geometric}
单倍体群体中，设类型 $A$ 与 $a$ 在第 $t$ 代的适合度为 $w_A(t)$ 与 $w_a(t)$。则 $T$ 代之后

$$
\frac{p_T}{q_T} = \frac{p_0}{q_0}\prod_{t=0}^{T-1}\frac{w_A(t)}{w_a(t)},
$$ {#eq-geometric}

所以 $A$ 长期取代 $a$ 当且仅当它适合度的**几何平均**超过 $a$ 的，$\bigl(\prod_t w_A(t)\bigr)^{1/T} > \bigl(\prod_t w_a(t)\bigr)^{1/T}$，或者说 $\ln w_A - \ln w_a$ 的平均为正。
:::

::: proof
每一代有 $p_{t+1}/q_{t+1} = (p_t/q_t)\,w_A(t)/w_a(t)$，因为在比值中 $\bar w$ 相消。对所有 $t$ 连乘。比值随 $\sum_t[\ln w_A(t) - \ln w_a(t)]$ 的符号无限增大或缩到零，即取决于哪个几何平均较大。
:::

由于几何平均恒小于算术平均，且适合度越参差相差越大，**适合度的方差是有代价的**。丰年极好、坏年极差的基因型，可能输给平均成就较低但更平稳的对手。

::: example 冒险的策略输了 {#ex-geometric}
在丰歉年交替的生境中，单倍体类型 $A$ 丰年适合度1.5、歉年0.6；类型 $a$ 两种年份都是1.0。哪一型获胜？从 $p = 0.5$ 出发，20年后 $A$ 的频率是多少？
::: solution
$A$ 的算术平均适合度：$(1.5 + 0.6)/2 = 1.05$，高于 $a$ 的。但其几何平均为 $\sqrt{1.5\times0.6} = \sqrt{0.90} = 0.949 < 1$。由[[#eq-geometric]]，每两年把 $p/q$ 乘 $0.90$，所以10对年之后 $p/q = 0.9^{10} = 0.349$，$p = 0.349/1.349 = 0.26$。类型 $A$ 正在下降并将丢失。这就是**风险对冲**的逻辑：荒漠一年生植物让一部分种子延迟萌发之类的性状降低了算术平均适合度，但也降低了它的方差，从而可能提高几何平均适合度。二倍体中，只要杂合子的几何平均适合度最高——哪怕单独任何一年它都不是最适合的——时间波动甚至能维持一个多态（J. B. S. Haldane 与 S. D. Jayakar，1963）。
:::
:::

::: quiz
一种一年生植物的两个基因型在四年中的适合度为：基因型 $X$ 是 $(2, 2, 0.25, 2)$，$Y$ 是 $(1.2, 1.2, 1.2, 1.2)$。四年间谁的频率上升？
- [ ] $X$，因为它的平均适合度（1.56）更高。
- [x] $Y$，因为它的几何平均适合度更高。
- [ ] 都不上升：选择波动时频率会回到出发的地方。
- [ ] 取决于年份的次序。
::: solution
$X$ 的乘积为 $2\times2\times0.25\times2 = 2$，几何平均 $2^{1/4} = 1.19$。$Y$ 的乘积为 $1.2^4 = 2.07$，几何平均 $1.2$。四年里比值 $X/Y$ 乘以 $2/2.07 = 0.96$，所以无论年份次序如何（乘积与次序无关），$Y$ 都略有上升。一年的灾难抵得过三个丰年。
:::
:::

## 选择的度量

百分之几的选择系数在单独一代中看不见，但在许多代中，或在受控的竞争中，可以测出。

**从时间序列。** 单倍体群体中，[[evolution/natural-selection]]证明了 $\ln(p/q)$ 每代增加 $\ln(1 + s) \approx s$。对加性效应的二倍体（$h = \tfrac12$），[[#eq-continuous]]给出 $\frac{d}{dt}\ln\frac pq = \frac{1}{pq}\frac{dp}{dt} = \frac s2$，所以 logit 以斜率 $s/2$ 线性上升。于是把 $\ln(p_t/q_t)$ 对 $t$ 回归即可估计选择系数。

::: example 从等位基因频率估计 s {#ex-logit}
在一个约每月一代的害虫群体中监测一个抗杀虫剂等位基因：第0代 $p = 0.050$；第20代 $0.108$；第40代 $0.203$；第60代 $0.372$。设对适合度的效应是加性的，估计选择系数。
::: solution
logit $\ln(p/q)$ 依次为 $-2.944$、$-2.111$、$-1.368$ 与 $-0.524$。logit 对世代的最小二乘斜率（[[biostatistics/regression]]）为每代 $0.0400$。加性效应下斜率是 $s/2$，故 $s \approx 0.080$：抗性纯合子的适合度比敏感纯合子高约8 %，杂合子高约4 %。（若该生物是单倍体，斜率将是 $\ln(1 + s)$，得 $s = 0.041$。）两点提醒：每个 $p$ 的抽样误差在严格分析中应当计入（按各 logit 的精度加权），而 logit 尺度上是不是直线本身也是对模型的检验——logit 弯曲说明存在显性或选择的变化。
:::
:::

**竞争实验。** 在微生物进化实验中，一个进化系与其祖先（用一个中性标记区分）混合培养。若竞争中两个群体由 $N_A(0)$ 长到 $N_A(1)$、由 $N_B(0)$ 长到 $N_B(1)$，则 $A$ 的相对适合度是两者实际实现的马尔萨斯参数之比，

$$
w = \frac{\ln[N_A(1)/N_A(0)]}{\ln[N_B(1)/N_B(0)]},
$$ {#eq-lenski}

即 Richard Lenski 及其同事（1991）在大肠杆菌 *E. coli* 长期进化实验中使用的度量。

::: example 一个竞争测定 {#ex-assay}
一个进化的 *E. coli* 克隆与其标记祖先各按 $5\times10^6$ 个细胞混合，生长一天。结束时进化型有 $1.0\times10^9$ 个细胞，祖先型有 $5.0\times10^8$ 个。进化克隆的相对适合度是多少？
::: solution
进化克隆增长200倍，祖先增长100倍。由[[#eq-lenski]]，$w = \ln 200/\ln 100 = 5.298/4.605 = 1.15$。竞争中进化克隆的增长率高15 %。在那项长期实验中，相对祖先的适合度起初迅速上升，然后越来越慢，但数万代内没有出现明显的高原（Michael Wiser、Noah Ribeck 与 Lenski，2013）。
:::
:::

**在野外**，选择由已知基因型的标记个体的存活或繁殖成就、由跨生命阶段的频率变化、或由既往选择留下的 DNA 变异模式来估计（[[population-genetics/linkage-disequilibrium]]、[[population-genetics/neutral-theory]]）。连续性状上的选择由适合度对表型的回归来估计（[[population-genetics/response-to-selection]]）。

::: application 抗性的管理
杀虫剂、除草剂、抗生素和抗凝血剂都是选择因子，本章的模型指导它们的使用。由于抗性等位基因的适合度依赖环境，药剂缺席处抗性通常有代价（那里 $w_{RR} < w_{SS}$），而处理与未处理的生境或时期混合起来，恰好产生上文分析过的空间或时间上变化的选择。*Bt* 作物避难所依赖的是 *Bt* 毒素抗性为隐性（$h \approx 0$），于是抗性尚罕见时占多数的杂合子会被杀死。药物轮换与联合用药旨在让每种抗性基因型的几何平均适合度小于1。降低抗性代价的补偿突变在细菌中被反复观察到，它们能使药剂撤除后抗性继续存在。
:::

::: history
对选择的最早定量处理，是数学家 H. T. J. Norton 计算的显性基因与隐性基因变化速率表，发表于 Reginald Punnett 的《蝴蝶的拟态》（*Mimicry in Butterflies*，1915）。霍尔丹（J. B. S. Haldane）的系列论文《自然选择与人工选择的数学理论》（共十部分，1924–1934）导出了本章的大部分单基因座结果，包括显性与隐性等位基因清除的耗时，以及黑化桦尺蛾选择优势的一个估计。罗纳德·费希尔（Ronald Fisher）的《自然选择的遗传学理论》（*The Genetical Theory of Natural Selection*，1930）提出了基本定理与平均效应；苏厄尔·赖特的适应景观出现在1932年。单基因座平均适合度永不下降的证明（1959）与 Kingman 的多等位基因平衡分析（1961）完成了确定性的单基因座理论。霍尔丹与 Jayakar 关于波动选择的论文发表于1963年，George Price 的协方差表述（1970、1972）澄清了费希尔定理究竟说了什么。
:::

::: summary
- 适合度在一个完整世代上综合了存活率、交配成功与繁殖力；只有相对适合度决定频率的改变（[[#def-fitness-components]]）。
- 等位基因的边际适合度 $w_i = \sum_jp_jw_{ij}$ 是其携带者的平均适合度；$\Delta p_i = p_i(w_i - \bar w)/\bar w$，两个等位基因时 $\Delta p = pq\alpha/\bar w$，平均超额 $\alpha = w_1 - w_2$（[[#prop-marginal]]）。
- 弱选择时 $dp/dt \approx spq[h + p(1-2h)]$；加性等位基因的清除约需 $(2/s)\ln\frac{p_1q_0}{p_0q_1}$ 代，隐性或显性的则长得多（[[#prop-sweep]]）。
- 内部平衡只在超显性或下显性下存在；它在超显性下稳定，在下显性下不稳定（一个阈值）。罕见等位基因若其杂合子比住家纯合子更适合即可入侵（[[#prop-stability]]）。
- 平均适合度以速率 $V_A/\bar w$ 上升（费希尔定理，[[#prop-fisher]]），但选择一般既不最大化 $\bar w$，也不为群体的利益行事。
- 负频率依赖维持多态；在波动的环境中，几何平均适合度较大的类型获胜（[[#prop-geometric]]）。
- 选择可由 logit 时间序列（单倍体斜率 $s$，加性二倍体 $s/2$）与竞争测定（马尔萨斯参数之比）来度量。
:::

## 习题

::: exercise 边际适合度 {level=1 check="0.027"}
基因型适合度为 $w_{11} = 1$、$w_{12} = 0.95$ 与 $w_{22} = 0.8$，且 $p = 0.5$。计算 $w_1$、$w_2$、$\bar w$ 与 $\Delta p$（保留三位小数）。
::: solution
$w_1 = 0.5\times1 + 0.5\times0.95 = 0.975$；$w_2 = 0.5\times0.95 + 0.5\times0.8 = 0.875$；$\bar w = 0.5\times0.975 + 0.5\times0.875 = 0.925$。于是 $\Delta p = pq(w_1 - w_2)/\bar w = 0.25\times0.1/0.925 = 0.027$。检验：$\Delta p = p(w_1 - \bar w)/\bar w = 0.5\times0.05/0.925$ 给出同一值。
:::
:::

::: exercise 一个超显性平衡 {level=1 check="0.25"}
适合度为 $w_{11} = 0.7$、$w_{12} = 1$ 与 $w_{22} = 0.9$。$A_1$ 的平衡频率是多少？
::: solution
取 $s = 0.3$ 与 $t = 0.1$，$\hat p = t/(s + t) = 0.1/0.4 = 0.25$。用[[#eq-interior]]检验：$(0.9 - 1)/(0.7 - 2 + 0.9) = -0.1/-0.4 = 0.25$。
:::
:::

::: exercise 从竞争求相对适合度 {level=1 check="0.7"}
一次竞争测定中，一个突变体由 $10^6$ 长到 $10^{8.1}$ 个细胞，而它的竞争者由 $10^6$ 长到 $10^{9}$。突变体的相对适合度是多少？
::: solution
突变体增长 $10^{2.1}$ 倍，竞争者增长 $10^{3}$ 倍。由[[#eq-lenski]]，$w = \ln(10^{2.1})/\ln(10^{3}) = 2.1/3 = 0.7$（对数的底相消）。突变体生长慢30 %——在无药条件下测定的有代价抗性突变的典型情形。
:::
:::

::: exercise 一个阈值 {level=2 check="0.25"}
适合度为 $w_{11} = 1$、$w_{12} = 0.7$ 与 $w_{22} = 0.8$。求内部平衡，判断它是否稳定，并预测从 $p = 0.3$ 和从 $p = 0.2$ 出发的结果。
::: solution
$\hat p = (0.8 - 0.7)/(1 - 1.4 + 0.8) = 0.1/0.4 = 0.25$。杂合子最不适合，所以平衡不稳定。从 $p = 0.3$，$\alpha = 0.3\times0.3 + 0.7\times(-0.1) = 0.02 > 0$，$A_1$ 走向固定；从 $p = 0.2$，$\alpha = 0.06 - 0.08 = -0.02 < 0$，$A_1$ 丢失。
:::
:::

::: exercise 隐性清除 {level=2 check="1026"}
一个受青睐的隐性等位基因 $s = 0.1$，从 $p = 0.01$ 升到 $p = 0.5$。用[[#eq-sweep]]估计世代数（取最接近的整数）。
::: solution
$L = \ln\frac{0.5\times0.99}{0.01\times0.5} = \ln 99 = 4.595$。于是 $t \approx \frac{1}{0.1}(4.595 + 100 - 2) = 10\times102.595 = 1026$ 代。同样 $s$ 的加性等位基因只需 $(2/0.1)\times4.595 = 92$ 代。隐性者的时间几乎全部耗在低频处。
:::
:::

::: exercise 风险对冲 {level=2}
一种荒漠一年生植物中，每年让所有种子萌发的基因型在湿年适合度3、旱年0.1；让一半种子休眠的基因型湿年1.6、旱年0.6。湿年与旱年同样常见。长期来看哪个基因型获胜？哪个的算术平均适合度更高？
::: solution
算术平均：$(3 + 0.1)/2 = 1.55$ 对 $(1.6 + 0.6)/2 = 1.1$，所以全萌发的基因型平均更高。几何平均：$\sqrt{0.3} = 0.548$ 对 $\sqrt{0.96} = 0.980$。由[[#prop-geometric]]，休眠的基因型获胜，因为两种类型之比每对两年朝它变化 $0.3/0.96 = 0.31$ 倍。（两个几何平均都小于1，所以这个例子里群体也会衰退；真实群体受密度调节，这改变绝对值而不改变这里相对适合度的比较。）
:::
:::

::: exercise 读 logit 图 {level=2}
在一个污染区记录了一种蛾的黑色型50年的频率，它受一个显性等位基因控制。它的 logit $\ln(p/q)$ 起初陡升，随后趋平，尽管黑色型始终比浅色型存活更好。(a) 这与恒定的选择相容吗？(b) 用[[#eq-sweep]]或[[#eq-continuous]]解释。
::: solution
(a) 相容。所画的是*表型*频率或等位基因频率的 logit；对一个显性等位基因，恒定的选择并不给出 logit 直线。

(b) $h = 1$ 时，$\frac{d}{dt}\ln\frac pq = \frac{1}{pq}\frac{dp}{dt} = sq$。显性等位基因罕见时 $q \approx 1$，logit 以速率 $s$ 上升；当它变常见，$q \to 0$，斜率降到零。选择没有变，但它只作用于不断缩小的 $aa$ 纯合子——唯一表型有异的个体。logit 直线只对单倍体或加性等位基因才有预期。
:::

::: exercise 费希尔定理的检验 {level=3}
取加性适合度 $w_{11} = 1.2$、$w_{12} = 1.1$、$w_{22} = 1.0$ 与 $p = 0.3$。(a) 计算 $\bar w$、$\alpha$、$\Delta p$ 与 $V_A$。(b) 直接算出新的平均适合度，把 $\Delta\bar w$ 与 $V_A/\bar w$ 比较。(c) 在 $p = 0.3$ 对超显性适合度 $w_{11} = 0.9$、$w_{12} = 1$、$w_{22} = 0.8$ 重复这一比较，并解释小小的出入。
::: solution
(a) $\bar w = 0.09\times1.2 + 0.42\times1.1 + 0.49 = 1.06$（等价地 $1 + 0.2p$）。$w_1 = 0.3\times1.2 + 0.7\times1.1 = 1.13$，$w_2 = 0.3\times1.1 + 0.7 = 1.03$，$\alpha = 0.10$。$\Delta p = 0.21\times0.1/1.06 = 0.01981$。$V_A = 2\times0.21\times0.01 = 0.0042$。

(b) $\bar w' = 1 + 0.2\times0.31981 = 1.063962$，故 $\Delta\bar w = 0.003962$，而 $V_A/\bar w = 0.0042/1.06 = 0.003962$：完全相同，正如[[#prop-fisher]]对加性适合度所说。

(c) $\bar w = 0.09\times0.9 + 0.42 + 0.49\times0.8 = 0.893$。$\alpha = 0.3(0.9 - 1) + 0.7(1 - 0.8) = 0.11$。$\Delta p = 0.21\times0.11/0.893 = 0.025868$。$V_A/\bar w = 2\times0.21\times0.0121/0.893 = 0.005691$。由 $p' = 0.325868$，$\bar w' = 0.106190\times0.9 + 2\times0.325868\times0.674132 + 0.454454\times0.8 = 0.095571 + 0.439357 + 0.363563 = 0.898491$，故 $\Delta\bar w = 0.005491$。直接变化略小，因为这里 $\bar w$ 是凹的（$\bar w'' = 2(w_{11} - 2w_{12} + w_{22}) = -0.6$），而二阶项 $\tfrac12\bar w''(\Delta p)^2 = -0.0002$ 说明了差额。
:::
:::

::: exercise 频率依赖性选择 {#exr-fds level=3}
在 $w_A = 1 + b(\tfrac12 - p)$、$w_a = 1 - b(\tfrac12 - p)$、$0 < b \le 2$ 的单倍体模型中：(a) 证明 $\bar w = 1 - 2b(p - \tfrac12)^2$；(b) 证明映射 $p' = pw_A/\bar w$ 在 $p = \tfrac12$ 处的斜率为 $1 - b/2$，从而平衡是稳定的；(c) 对 $b = 1$，从 $p = 0.9$ 出发计算 $p'$。
::: solution
(a) 记 $u = \tfrac12 - p$，则 $\bar w = p(1 + bu) + (1 - p)(1 - bu) = 1 + bu(2p - 1) = 1 - 2bu^2$。

(b) 令 $p = \tfrac12 + \varepsilon$，于是 $u = -\varepsilon$。则 $p' = (\tfrac12 + \varepsilon)(1 - b\varepsilon)/(1 - 2b\varepsilon^2) = \tfrac12 + \varepsilon - \tfrac12 b\varepsilon + O(\varepsilon^2)$。斜率为 $1 - b/2$，当 $0 < b \le 2$ 时落在 $[0, 1)$ 内，所以偏离缩小：平衡稳定，且被单调逼近。

(c) $u = -0.4$、$w_A = 0.6$、$w_a = 1.4$、$\bar w = 0.9\times0.6 + 0.1\times1.4 = 0.68$、$p' = 0.54/0.68 = 0.794$。常见的类型迅速失分。
:::
