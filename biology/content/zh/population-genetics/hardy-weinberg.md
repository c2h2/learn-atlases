任意挑出两个同种的人、两棵栎树或两只果蝇，把它们的基因组并排读取，会在数百万个位点上发现差异。这些变异是进化的原材料，是育种者、法医科学家和遗传流行病学家利用的信号，也是重建群体历史所依据的记录。群体遗传学从描述变异开始：变异有多少，如何在个体之间分布，以及在没有任何力量作用于它时它会如何表现？

最后一个问题的答案就是**哈迪-魏因贝格原理**，[[evolution/natural-selection]]中已就一对等位基因的单个基因座推导过它。在本章中，我们将它还原为它本来的样子：一个*零模型*。我们先建立贯穿全书的变异度量——等位基因频率与基因型频率、杂合度、核苷酸多样性——以及估计它们时的抽样误差。然后把哈迪-魏因贝格原理推广到多个等位基因和 X 连锁基因，精确说明它达到的速度，并学会用真实样本对它进行检验。之后的每一章各加入一个过程——选择、漂变、突变、迁移、近交——并追问群体偏离这一基线的程度。

## 描述遗传变异

### 群体中的基因座、等位基因与基因型

一个**基因座**可以是一个完整的基因、一个单独的核苷酸位置、一段微卫星重复序列，或任何其他可识别的 DNA 片段。它在群体中存在的不同形式就是它的**等位基因**：在单核苷酸多态性（SNP）上，等位基因是两个碱基，比如 `C` 和 `T`；在微卫星上，它们是重复长度；在一个基因上，它们可以由完整序列（**单倍型**）或由电泳能够分开的蛋白质变体来定义。二倍体的每个个体携带两份拷贝，即它的**基因型**。

::: definition 基因型频率与等位基因频率 {#def-frequencies}
考虑一个有等位基因 $A_1, \ldots, A_k$ 的基因座，它处于 $N$ 个个体的二倍体群体中，其中 $N_{ij}$ 个个体具有基因型 $A_iA_j$（$i \le j$ 时 $N_{ij}$ 计一次）。**基因型频率**为 $P_{ij} = N_{ij}/N$。$A_i$ 的**等位基因频率**是 $2N$ 个基因拷贝中 $A_i$ 所占的比例：

$$
p_i = \frac{2N_{ii} + \sum_{j\neq i} N_{ij}}{2N} = P_{ii} + \tfrac12\sum_{j\neq i}P_{ij},
$$ {#eq-allele-count}

因为纯合子携带其等位基因的两份拷贝而杂合子携带一份。等位基因频率之和为1。两个等位基因时记 $p = p_1$ 且 $q = p_2 = 1 - p$。
:::

等位基因频率总能由基因型频率算出，反过来却不行：一个由50 %的 $A_1A_1$ 与50 %的 $A_2A_2$ 组成的群体，和一个100 %为 $A_1A_2$ 的群体，都有 $p = 0.5$。基因型频率携带着关于等位基因*如何*被打包进个体的额外信息，而这种打包正是哈迪-魏因贝格原理所预测的东西。

### 变异有多少？

在1960年代之前，没有人知道一个典型的基因是只有一个常见等位基因加少数几个罕见突变体，还是有许多频率居间的等位基因。这个问题由蛋白质**凝胶电泳**解决，它能分开电荷不同的酶变体。1966年，Lewontin 与 Hubby 调查了拟果蝇 *Drosophila pseudoobscura* 的18个基因座，发现约30 %是多态的，平均每个个体约在12 %的位点上杂合；同年 Harris 在人类中发现了相当的水平。电泳只能看到改变电荷的氨基酸替换，所以这些都是低估。1983年，Kreitman 测定了黑腹果蝇 *Drosophila melanogaster* 的乙醇脱氢酶基因 *Adh* 的11个拷贝，发现43个多态性核苷酸位点，其中只有一个改变了蛋白质。此后测序使直接测量变异成为常规。

::: definition 遗传变异的度量 {#def-variation}
对于从群体中抽取的一份基因拷贝样本：

- 若一个基因座最常见的等位基因频率低于某个约定的界限（通常为0.99或0.95），该基因座就是**多态的**。**多态位点比例**是一个粗略的汇总指标。
- 一个基因座上的**期望杂合度**或**基因多样性**是随机抽取的两个基因拷贝是不同等位基因的概率：

$$
H = 1 - \sum_{i=1}^{k}p_i^2.
$$ {#eq-heterozygosity}

  由 $n$ 个基因拷贝的样本，无偏估计为 $\hat H = \frac{n}{n - 1}\bigl(1 - \sum \hat p_i^2\bigr)$。**观测杂合度** $H_\mathrm{obs}$ 是杂合个体所占的比例。
- 对于长度为 $L$ 的 DNA 序列，**核苷酸多样性** $\pi$ 是随机抽取的两条序列之间每位点的平均差异数（Nei 与 Li，1979）。**分离位点数** $S$ 是样本中可变的位置数目。
:::

$H$ 仅由等位基因频率定义，因此它可以对单倍体以及对基因型未知的基因座计算；它等于一个随机交配群体所应有的杂合度。核苷酸多样性是其每位点版本，对所有序列对取平均。

序列样本的两个汇总指标 $\pi$ 与 $S$ 之间的关系，由我们在 [[population-genetics/genetic-drift]] 与 [[population-genetics/neutral-theory]] 中发展的理论给出。这里先注意一个有用的事实：在 $n$ 条序列的样本中，分离位点数随 $n$ 增长（序列越多，捕获罕见变异的机会越多），而 $\pi$ 不然。为了比较两者，Watterson（1975）把 $S$ 除以常数 $a_n = \sum_{i=1}^{n-1} 1/i$；当群体处于中性平衡时，所得的 $\theta_W = S/a_n$ 与 $\pi$ 估计同一个量。

::: example 一个小样本的核苷酸多样性 {#ex-pi}
从五个个体（每人一份拷贝）获得某个基因的五条30碱基对的序列：

```
seq1  ATGCTAGCATTACGGATCCAGTTACGCATG
seq2  ATGCTAGCGTTACGGATCCAGTTACGCATG
seq3  ATGCTAGCATTACGAATCCAGTTACGCATG
seq4  ATGCCAGCGTTACGGATCCAGTTACGTATG
seq5  ATGCTAGCATTACGGATCCAGTTACGCATG
```

求 $S$、每条序列与每位点的 $\pi$，以及每位点的 Watterson $\theta_W$。
::: solution
可变位置是第5（`T`/`C`）、9（`A`/`G`）、15（`G`/`A`）和27（`C`/`T`）位，故 $S = 4$。

共有 $\binom52 = 10$ 个序列对。计数差异：seq1–seq2 为1，seq1–seq3 为1，seq1–seq4 为3，seq1–seq5 为0，seq2–seq3 为2，seq2–seq4 为2，seq2–seq5 为1，seq3–seq4 为4，seq3–seq5 为1，seq4–seq5 为3。总和为18，所以成对差异的平均数为 $18/10 = 1.8$，于是

$$
\pi = \frac{1.8}{30} = 0.060\ \text{每位点}.
$$

由 $n = 5$，$a_5 = 1 + \tfrac12 + \tfrac13 + \tfrac14 = 2.083$，故 $\theta_W = 4/2.083 = 1.92$ 每条序列，即每位点 $0.064$。两个估计很接近。（这样小的样本只是一个演示：真实的估计要用数千个位点。人类的核苷酸多样性约为 $0.001$——基因组的两份拷贝大约每一千个位点差一个——而黑腹果蝇的数值要高出好几倍。）
:::
:::

### 频率的估计及其精度

真实的频率由样本估计。若对 $n$ 个二倍体个体分型，$p_i$ 的自然估计是**等位基因计数**（基因计数）估计：在分得的 $2n$ 个基因中数出 $A_i$ 的拷贝数，再除以 $2n$。当基因型被直接观察到时，这也是最大似然估计（[[biostatistics/estimation]]）。

::: proposition 等位基因频率的抽样方差 {#prop-se}
若 $n$ 个二倍体个体样本中的 $2n$ 个基因拷贝，是从等位基因 $A$ 频率为 $p$ 的群体中的独立抽取——当群体处于哈迪-魏因贝格比例时这一点成立——则等位基因计数估计 $\hat p$ 是无偏的，且

$$
\Var(\hat p) = \frac{p(1 - p)}{2n},\qquad \mathrm{SE}(\hat p) \approx \sqrt{\frac{\hat p(1 - \hat p)}{2n}}.
$$ {#eq-se}
:::

::: proof
此时 $A$ 拷贝数 $X$ 服从以 $2n$ 为试验次数、成功概率为 $p$ 的二项分布，故 $\E[X] = 2np$ 且 $\Var(X) = 2np(1 - p)$。除以 $2n$ 得 $\E[\hat p] = p$ 与 $\Var(\hat p) = p(1 - p)/2n$。用 $\hat p$ 代替 $p$ 即得标准误的估计。
:::

独立性假设很重要。若群体中纯合子过多（如近交时，[[population-genetics/inbreeding]]），一个个体内的两份拷贝正相关，真实方差更大，为 $p(1 - p)(1 + F)/2n$，其中 $F$ 度量这种相关。

::: example 250人样本中的一个 SNP {#ex-se}
在一个 SNP（等位基因为 `C` 与 `T`）上对250人分型：90个 `CC`、110个 `CT`、50个 `TT`。估计 `C` 的频率，并给出近似的95 %置信区间。
::: solution
`C` 的拷贝数：$2\times90 + 110 = 290$，共 $500$ 份，故 $\hat p = 0.580$。由[[#eq-se]]，

$$
\mathrm{SE} = \sqrt{\frac{0.58\times0.42}{500}} = 0.0221,
$$

近似的95 %区间为 $0.580 \pm 1.96\times0.0221 = 0.580 \pm 0.043$，即 $(0.537, 0.623)$。要把区间宽度减半，需要的人数要增加四倍。标准误取决于所抽样的*基因拷贝*数，而不取决于群体大小——只要群体相对样本来说足够大。
:::
:::

::: widget distribution

a: 24

normal: true
caption: 真实频率为 $p$ 的等位基因，在 $n$ 个所抽基因拷贝中的拷贝数的抽样分布（这里 $n = 100$，即50个二倍体个体）。阴影直条——24至36个拷贝——是距真实值 $p = 0.3$ 约 $\pm 0.06$ 以内的估计，大致就是[[#eq-se]]预测的95 %范围，因为 $\sqrt{0.3\times0.7/100} = 0.046$。增大 $n$，看分布按 $1/\sqrt n$ 收窄；一旦 $np$ 与 $n(1-p)$ 都超过约10，正态曲线就成为极好的近似。

## 哈迪-魏因贝格原理

### 两等位基因情形简述

两个等位基因的推导见[[evolution/natural-selection]]：随机交配下，下一代的合子由配子库中独立抽取的两个配子形成，库中 $A_1$ 的频率为 $p$，因此基因型按 $p^2 : 2pq : q^2$ 的比例出现，且等位基因频率不变。那一论证中有两点贯穿本章全部内容。

1. **随机交配等价于单个基因座上配子的随机结合**。不论个体是随机选择配偶，还是配子在水中随机相遇，合子的基因型都是从配子库中的一次独立对抽。（这一等价只对单个基因座成立；对两个基因座，在达到连锁平衡之前它不成立——[[population-genetics/linkage-disequilibrium]]。）
2. **孟德尔分离保持等位基因频率。** 杂合子均等地传递它的两个等位基因，所以配子库与亲代有相同的等位基因频率。任何破坏这一点的因素——选择、减数分裂驱动、突变、迁移、抽样——都是一种进化力量。

### 多个等位基因

测序表明大多数基因座有不止两个等位基因：人类主要组织相容性复合体的 HLA 基因有数千个等位基因，一个微卫星在一个群体中可能有二十个重复长度等位基因。

::: proposition 多个等位基因的哈迪-魏因贝格比例 {#prop-hw-multi}
设一个常染色体基因座有等位基因 $A_1, \ldots, A_k$，频率为 $p_1, \ldots, p_k$，在两性中相同，群体非常大、随机交配，且没有选择、突变或迁移。则经过一代随机交配后

$$
f(A_iA_i) = p_i^2,\qquad f(A_iA_j) = 2p_ip_j\quad(i \neq j),
$$ {#eq-hw-multi}

且等位基因频率在之后各代仍为 $p_1, \ldots, p_k$。杂合子的比例为 $1 - \sum_i p_i^2 = H$，共有 $k$ 种纯合基因型和 $k(k-1)/2$ 种杂合基因型。
:::

::: proof
一个合子接受两个独立抽取的配子，每个携带 $A_i$ 的概率为 $p_i$。两者都是 $A_i$ 时合子为 $A_iA_i$，概率 $p_i^2$。第一个是 $A_i$ 且第二个是 $A_j$，或反之，则合子为无序基因型 $A_iA_j$，概率 $2p_ip_j$。这些概率之和为 $(\sum_ip_i)^2 = 1$。由[[#eq-allele-count]]，子代中 $A_i$ 的频率为 $p_i^2 + \tfrac12\sum_{j\neq i}2p_ip_j = p_i\sum_j p_j = p_i$，所以再一轮随机交配给出相同比例。
:::

等位基因很多时，杂合度可以接近1：$k$ 个等频率等位基因时 $H = 1 - k(1/k)^2 = 1 - 1/k$，所以十个等频率的等位基因会使90 %的个体成为杂合子。这正是法医实验室与亲子鉴定使用高度多态微卫星的原因：每一个都很可能区分两个人。

::: example ABO 血型 {#ex-abo}
ABO 基因座有三个等位基因：$I^A$ 与 $I^B$ 互为共显性，且都对 $i$（O 型血）为显性。一个大样本中的表型频率为 O 0.45、A 0.40、B 0.11、AB 0.04。假定哈迪-魏因贝格比例，估计三个等位基因频率 $p$（$I^A$）、$q$（$I^B$）与 $r$（$i$）。
::: solution
由[[#eq-hw-multi]]，各表型的期望频率为 O $r^2$、A $p^2 + 2pr$、B $q^2 + 2qr$、AB $2pq$。由于表型 A 与 O 在基因型水平上无法区分，我们不能直接计数等位基因；转而利用比例的结构（Felix Bernstein 的方法，1925）。

- O 型：$r^2 = 0.45$，故 $r = \sqrt{0.45} = 0.6708$。
- O 与 A 合计：$p^2 + 2pr + r^2 = (p + r)^2 = 0.45 + 0.40 = 0.85$，故 $p = \sqrt{0.85} - r = 0.9220 - 0.6708 = 0.2511$。
- O 与 B 合计：$(q + r)^2 = 0.56$，故 $q = \sqrt{0.56} - r = 0.7483 - 0.6708 = 0.0775$。

三个估计之和为 $0.9995$，接近1，且预测的 AB 频率 $2pq = 0.039$ 与观察值0.04相符：数据与哈迪-魏因贝格拟合良好。（实践中，这一微小差异可由校正消除，或者更好的做法，由带 EM 算法的最大似然消除；EM 背后的基因计数思想由 Cedric Smith 于1957年用于 ABO。Bernstein 在1924–25年对 ABO 数据的分析在历史上很重要：它表明血型由单一基因座上的三个等位基因决定，而不是此前与之竞争的假设——两个基因座。）
:::
:::

### 平衡达得有多快？

两等位基因的表述“经过一代”假定等位基因频率在雄性中与雌性中相同。若不相同——例如一个群体的奠基者雄性来自一个来源而雌性来自另一个来源——那么一代使两者相等，第二代产生哈迪-魏因贝格比例。若雄性以频率 $p_m$ 提供配子、雌性以 $p_f$，则子代中 $A_1A_1$ 的频率为 $p_mp_f$，$A_2A_2$ 为 $q_mq_f$，杂合子为 $p_mq_f + q_mp_f$，而子代两性的等位基因频率都是 $(p_m + p_f)/2$。它们之间随机交配便在该频率上给出哈迪-魏因贝格比例。

对 X 染色体上的基因，逼近要慢些，因为两性遗传方式不同。在哺乳动物和果蝇 *Drosophila* 中，雄性唯一的 X 来自母亲，而雌性的两条 X 各来自父母之一（性连锁遗传：[[genetics/sex-linkage-pedigrees]]）。

::: proposition X 连锁基因座的平衡 {#prop-xlinked}
设 $q_m$ 与 $q_f$ 是 X 连锁等位基因 $a$ 在雄性与雌性中的频率，随机交配且无其他力量。则

$$
q_m' = q_f,\qquad q_f' = \tfrac12(q_m + q_f).
$$ {#eq-xlinked}

加权平均 $\bar q = \tfrac13 q_m + \tfrac23 q_f$ 恒定（雌性携带全部 X 染色体的三分之二），而差 $d = q_f - q_m$ 满足 $d' = -\tfrac12 d$，所以它每代减半并变号：

$$
q_f(t) = \bar q + \tfrac13 d_0\left(-\tfrac12\right)^t,\qquad q_m(t) = \bar q - \tfrac23 d_0\left(-\tfrac12\right)^t.
$$ {#eq-xlinked-sol}

平衡时 $q_m = q_f = \bar q$，雌性具有哈迪-魏因贝格比例 $\bar p^2 : 2\bar p\bar q : \bar q^2$，而患病（半合子 $a$）雄性的频率为 $\bar q$。
:::

::: proof
儿子的 X 来自母亲，母亲的 X 携带 $a$ 的概率为 $q_f$。女儿的 X 一条来自父亲（$a$ 的概率 $q_m$）、一条来自母亲（概率 $q_f$）；她的 $a$ 拷贝期望数目为两条中的 $q_m + q_f$。这就给出[[#eq-xlinked]]。于是 $\bar q' = \tfrac13q_f + \tfrac23\cdot\tfrac12(q_m + q_f) = \tfrac13 q_m + \tfrac23 q_f = \bar q$，且 $d' = \tfrac12(q_m + q_f) - q_f = -\tfrac12(q_f - q_m)$。联立 $q_f - q_m = d$ 与 $\tfrac13q_m + \tfrac23 q_f = \bar q$ 解出 $q_f$ 与 $q_m$ 即得[[#eq-xlinked-sol]]。
:::

::: example 由两个来源奠基的群体 {#ex-xlinked}
一个群体的奠基雌性的某个 X 连锁基因座上都携带等位基因 $A$，而奠基雄性全部携带 $a$（$q_f = 0$，$q_m = 1$）。追踪四代之内两性中 $a$ 的频率，并给出平衡值。
::: solution
由[[#eq-xlinked]]：第1代，$q_m = 0$，$q_f = 0.5$；第2代，$q_m = 0.5$，$q_f = 0.25$；第3代，$q_m = 0.25$，$q_f = 0.375$；第4代，$q_m = 0.375$，$q_f = 0.3125$。差 $q_f - q_m$ 依次为 $-1, 0.5, -0.25, 0.125, -0.0625$。平衡值为 $\bar q = \tfrac13\times1 + \tfrac23\times0 = \tfrac13$：三分之一的雄性将表达 $a$ 表型，而雌性 $a/a$ 的频率为 $\tfrac19$。
:::
:::

对于罕见的 X 连锁隐性等位基因，$\bar q$ 的患病雄性与 $\bar q^2$ 的患病雌性意味着患病雄性要常见得多：若每12名男性中有1人患病（$\bar q \approx 0.08$），则约每160名女性中有1人患病。这正是 X 连锁性状的家系模式在群体水平的对应。（这类疾病的临床方面见医学图谱，[/learn/medicine/](/learn/medicine/)。）

::: quiz
在一个常染色体基因座上，一个新混合群体中雄性的等位基因频率为 $p_m = 0.8$，雌性为 $p_f = 0.4$。关于它们的子代，哪个说法正确？
- [ ] 子代对 $p = 0.6$ 处于哈迪-魏因贝格比例。
- [x] 子代两性中等位基因频率都是0.6，但杂合子多于哈迪-魏因贝格预测；下一代将处于哈迪-魏因贝格比例。
- [ ] 等位基因频率将在两性之间振荡好几代。
- [ ] 子代儿子中等位基因频率为0.8，女儿中为0.4。
::: solution
子代基因型为：$A_1A_1$，$0.8\times0.4 = 0.32$；$A_2A_2$，$0.2\times0.6 = 0.12$；杂合子 $0.56$。对 $p = 0.6$ 的哈迪-魏因贝格比例应给出 $0.36, 0.48, 0.16$，所以杂合子过剩。两性——儿子与女儿——的等位基因频率都是 $0.32 + 0.28 = 0.6$，因为常染色体在两性的遗传方式相同，再多一代随机交配即得哈迪-魏因贝格比例。两性间的振荡是 X 连锁情形。
:::
:::

## 作为零模型的哈迪-魏因贝格原理

该原理列出了什么也不会发生的条件：群体无限大、随机交配、无选择、无突变、无迁移、孟德尔分离、两性频率相等。任何真实群体都不会严格满足所有条件。它的价值在于两种用途：在偏离很小时由等位基因频率预测基因型频率，以及在偏离很大时检测出偏离。

### 检验一个样本

要检验一个样本是否符合哈迪-魏因贝格比例，我们从样本估计 $p$，算出期望的基因型计数，再用 χ² 拟合优度检验把它们与观察计数比较，如[[genetics/mendelian-inheritance]]与[[evolution/natural-selection]]所示。$k$ 个等位基因时有 $k(k+1)/2$ 个基因型类别和 $k - 1$ 个独立估计的等位基因频率，所以检验的自由度为

$$
\mathrm{df} = \frac{k(k+1)}{2} - 1 - (k - 1) = \frac{k(k-1)}{2}
$$

自由度——两个等位基因时为1，三个时为3。当期望计数很小时（罕见等位基因、小样本），χ² 近似很差，改用**精确检验**，它枚举具有观察等位基因计数的所有基因型表（Janis Wigginton、David Cutler 与 Gonçalo Abecasis 在2005年给出了快速算法）。

用一个数来概括偏离是有用的。

::: definition 固定指数 {#def-fis}
对于一个观测杂合度为 $H_\mathrm{obs}$、哈迪-魏因贝格期望杂合度为 $H_\mathrm{exp} = 1 - \sum\hat p_i^2$ 的样本，**固定指数**为

$$
F = 1 - \frac{H_\mathrm{obs}}{H_\mathrm{exp}}.
$$ {#eq-fis}

$F > 0$ 表示杂合子缺失，$F < 0$ 表示过剩。两个等位基因时，基因型频率总可以写成 $p^2 + Fpq$、$2pq(1 - F)$、$q^2 + Fpq$。
:::

当样本来自单个群体时，$F$ 记作 $F_\mathrm{IS}$，是群体内非随机交配造成的偏离（[[population-genetics/inbreeding]]）；当若干亚群体的样本被合并时，部分缺失由合并本身造成（[[population-genetics/mutation-migration]]）。两个等位基因时，它与 χ² 统计量有个漂亮的联系：$\chi^2 = n\hat F^2$，其中 $n$ 是所抽样体的个体数。

::: example 杂合子缺失 {#ex-hwtest}
一个地点的200只蜗牛样本中有60个 $A_1A_1$、70个 $A_1A_2$、70个 $A_2A_2$。检验哈迪-魏因贝格比例并计算 $F$。
::: solution
$\hat p = (2\times60 + 70)/400 = 0.475$，$\hat q = 0.525$。期望计数：$200\hat p^2 = 45.125$，$200\times2\hat p\hat q = 99.75$，$200\hat q^2 = 55.125$。于是

$$
\chi^2 = \frac{(60 - 45.125)^2}{45.125} + \frac{(70 - 99.75)^2}{99.75} + \frac{(70 - 55.125)^2}{55.125} = 4.904 + 8.873 + 4.014 = 17.79,
$$

自由度1：$P \approx 2.5\times10^{-5}$，远超3.84这一5 %临界值。固定指数为 $F = 1 - 70/99.75 = 0.298$，且确实 $n F^2 = 200\times0.298^2 = 17.79$。杂合子存在严重缺失。

什么能造成它？自花授粉或亲缘交配（蜗牛中有很多自交的雌雄同体）；一个不知不觉混合了等位基因频率不同的两个群体的样本（Wahlund 效应，[[population-genetics/mutation-migration]]）；抽样之前针对杂合子的选择；或者一个技术假象——一个未能扩增产物的无效等位基因（null allele），使其杂合子被记分为纯合子。检验告诉我们有东西偏离了零模型，而没告诉我们是什么。
:::
:::

::: warning "样本符合哈迪-魏因贝格比例说明诸假设成立"
与哈迪-魏因贝格比例相符是弱证据。随机交配每代都恢复比例，所以选择、漂变、突变和迁移都能改变等位基因频率，而每代合子的基因型比例仍接近 $p^2 : 2pq : q^2$。只作用于成体的选择只在幸存者中造成偏离，而且这些偏离往往很小：在 $p = 0.5$ 时三种基因型0.9、1.0和0.9的存活率，只把幸存者中的杂合子频率从0.50变到约0.53，几百个个体的样本无法检测。反过来，未通过检验并不能指明哪个假设失效。哈迪-魏因贝格原理是用来检验的零模型，不是对群体的描述。
:::

::: warning "平衡意味着1 : 2 : 1的比例"
1 : 2 : 1的比例是两个杂合子杂交的结果（[[genetics/mendelian-inheritance]]）。哈迪-魏因贝格比例是 $p^2 : 2pq : q^2$，只有当 $p = 0.5$ 时才等于1 : 2 : 1。一个处于平衡、$p = 0.9$ 的群体有81 %的 $A_1A_1$、18 %的杂合子和1 %的 $A_2A_2$；没有任何力量把它推向0.5。
:::

### 零模型的用途

**由等位基因频率求基因型频率，以及反过来。** 对于常染色体隐性表型，只有纯合子可辨认，但若群体接近哈迪-魏因贝格，我们就能估计 $q = \sqrt{f(aa)}$，并由此得到杂合携带者的频率。

::: example 隐性等位基因的携带者 {#ex-carriers}
某常染色体隐性疾病在一个群体中影响每2,500次出生中的1例（这一发病率的数量级见于某些北欧裔群体中囊性纤维化的报道）。估计等位基因频率、携带者频率，以及处于携带者体内的隐性等位基因比例。
::: solution
$q^2 = 1/2500$，故 $q = 0.02$，$p = 0.98$。携带者（杂合子）频率为 $2pq = 2\times0.98\times0.02 = 0.0392$，约每25人1人。$a$ 的拷贝在杂合子与纯合子中的数目比为 $2pq : 2q^2 = p : q$，所以全部 $a$ 等位基因中有 $p = 0.98$ 的比例位于不表达该疾病的携带者体内。每25人有1人携带一个每2,500人才表达一次的等位基因。

这一计算假定哈迪-魏因贝格比例。近亲婚配会使纯合子频率升到 $q^2$ 之上（[[population-genetics/inbreeding]]），而一个“疾病”往往涉及该基因的许多不同等位基因，群体模型把它们归并为 $a$。这类估计用于群体筛查政策，但个体风险评估属于临床遗传学（医学图谱）。
:::
:::

::: widget plot
f: x^2 + F*x*(1-x); 2*x*(1-x)*(1-F); (1-x)^2 + F*x*(1-x)
x: 0, 1
y: 0, 1
sliders: F=0:0:1:0.01
labels: A_1A_1; A_1A_2; A_2A_2
caption: 基因型频率对 $A_1$ 的等位基因频率 $p$ 的曲线，用[[#def-fis]]的固定指数 $F$ 书写。$F = 0$ 时这些就是哈迪-魏因贝格抛物线 $p^2$、$2pq$、$q^2$；悬停可读数。增大 $F$，杂合子曲线降至 $2pq(1-F)$，每个纯合子各增加 $Fpq$；$F = 1$ 时群体只由纯合子组成，比例为 $p$ 与 $q$。注意等位基因频率在每个 $F$ 都相同——偏离哈迪-魏因贝格比例只是把等位基因重新打包进基因型，而不改变它们的频率。
:::

**基因型数据的质量控制。** 在大规模分型研究中，来自单个群体的样本里某个基因型计数严重偏离哈迪-魏因贝格的 SNP，通常意味着技术问题：某个探针对一个等位基因失效，或者一个重复区域内两个基因座被记为一个。在关联研究之前检验每个 SNP 并剔除偏离极端者，是一道常规的过滤工序（[[genomics/association-studies]]）。

::: application 法医 DNA 指纹
法医 DNA 指纹记录一个人在一组高度多态的微卫星（短串联重复）基因座上的基因型。随机选取一个无亲缘关系的人具有相同指纹的概率，其算法是在每个基因座内应用[[#eq-hw-multi]]——纯合子 $p_i^2$，杂合子 $2p_ip_j$——再跨基因座相乘，这假定各基因座独立（连锁平衡）。20个基因座时，这个乘积通常小得不可思议。由于真实群体存在亚分化且亲属共享等位基因，美国国家研究委员会1996年的报告建议用群体结构校正（参数 $\theta$，本质上就是 $F_\mathrm{ST}$，[[population-genetics/mutation-migration]]）来修正单基因座公式，使估计偏保守。这些数字的可信度取决于背后的零模型和等位基因频率数据库，这一点在1990年代的法庭上曾被长篇争辩。
:::

::: example 多少种基因型，多少杂合子？ {#ex-count}
一个微卫星有六个等位基因，频率为0.30、0.25、0.20、0.10、0.10和0.05。可能有多少种基因型？随机交配群体中有多大比例是杂合子，最常见的单一基因型是什么？
::: solution
共有 $6$ 种纯合和 $6\times5/2 = 15$ 种杂合基因型，合计21种。$\sum p_i^2 = 0.09 + 0.0625 + 0.04 + 0.01 + 0.01 + 0.0025 = 0.215$，故 $H = 0.785$：几乎五分之四的人是杂合子。最大的单一基因型频率是两个最常见等位基因的杂合子 $2\times0.30\times0.25 = 0.15$，大于最常见的纯合子 $0.30^2 = 0.09$。等位基因多时，杂合子占支配地位。
:::
:::

### 用代码计算

下面这段使用标准库的 Python 程序完成本章的两项常规计算：对基因型计数做哈迪-魏因贝格 χ² 检验，以及为一组比对好的序列计算 $\pi$、$S$ 与 $\theta_W$。

```python
import math
from itertools import combinations

def hw_test(n11, n12, n22):
    """Chi-squared test of Hardy-Weinberg proportions, two alleles (1 df)."""
    n = n11 + n12 + n22
    p = (2 * n11 + n12) / (2 * n)
    q = 1 - p
    expected = [n * p * p, n * 2 * p * q, n * q * q]
    chi2 = sum((o - e) ** 2 / e for o, e in zip((n11, n12, n22), expected))
    F = 1 - n12 / expected[1]
    pval = math.erfc(math.sqrt(chi2 / 2))        # upper tail of chi-squared with 1 df
    return p, chi2, pval, F

def diversity(seqs):
    """Segregating sites, pi per site, Watterson's theta per site."""
    L, n = len(seqs[0]), len(seqs)
    S = sum(len(set(col)) > 1 for col in zip(*seqs))
    pairs = list(combinations(seqs, 2))
    pi = sum(sum(a != b for a, b in zip(x, y)) for x, y in pairs) / len(pairs) / L
    a_n = sum(1 / i for i in range(1, n))
    return S, pi, S / a_n / L

print(hw_test(60, 70, 70))     # (0.475, 17.79, 2.5e-05, 0.298)
```

对[[#ex-hwtest]]的蜗牛数据运行 `hw_test`，可复现 $\hat p = 0.475$、$\chi^2 = 17.79$、$P = 2.5\times10^{-5}$ 与 $F = 0.298$；对[[#ex-pi]]的序列运行 `diversity`，得 $S = 4$、$\pi = 0.060$ 与 $\theta_W = 0.064$。

::: intuition 为什么一代就足够
基因型频率是等位基因配对方式的属性；等位基因频率是基因库的属性。随机交配彻底抛弃旧的配对，从基因库中随机抽出新的配对，所以不论亲代的基因型比例如何，子代的比例只取决于基因库。既然孟德尔分离使基因库保持不变，一轮随机交配就足够了。两个基因座则不同：那里同一染色体上等位基因的*组合*除非被重组打破就完整地遗传，所以随机交配不会立刻把它们随机化，趋近平衡是渐进的（[[population-genetics/linkage-disequilibrium]]）。
:::

## 人类的变异

人类的遗传变异在基因组尺度上演示了本章的诸度量。1000 Genomes 计划2015年对26个群体2,504人的分析发现：一个典型的基因组与参考序列在410万至500万个位点上不同，其中绝大多数是 SNP；全样本中的大多数变异是罕见的，而任意两个人之间的大部分差异来自常见变异。核苷酸多样性很低，两份拷贝之间约一千个碱基对差一个，与黑猩猩等许多其他物种相比是小了——这是长期有效群体大小很小的一个信号（[[population-genetics/genetic-drift]]）。此后更大规模的测序工作已经编目了数亿个变异位点；这样的计数随样本量逐年增长（截至2026年，参见 gnomAD 及类似数据库的当前发布版本，[[genomics/human-variation]]）。

这些变异在各群体之间的分布方式是群体结构问题，见[[population-genetics/mutation-migration]]。关键发现——Lewontin 于1972年首先从蛋白质数据报告、并被基因组序列证实——是人类遗传变异中的大多数，约85–90 %，存在于任何一个局部群体内部，只有很小一部分区分来自不同大陆的群体。等位基因频率在地理上渐变，人类群体遗传学要用群体、祖源和地理来描述，而不是“种族”。

::: history
1902年，统计学家 George Udny Yule 提出异议说，若短指畸形是孟德尔显性性状，它理应上升到使四分之三的人都表现出它。William Castle 于1903年表明，随机交配下频率在一个特例中保持不变，Karl Pearson 于1904年对一个由纯系组成的初始群体求出了平衡。一般解在1908年被独立发现两次。无法回答 Yule 之问的 Punnett，把问题转给了他的板球球友、数学家 G. H. 哈迪（Hardy），哈迪的短信《混合群体中的孟德尔比例》（*Mendelian proportions in a mixed population*）于1908年7月发表于 *Science*，并附注说这是“一个非常简单的观点”。六个月前，即1908年1月13日，斯图加特医生威廉·魏因贝格（Weinberg）在一场关于人类遗传的讲座中报告了同样的结果；在1943年 Curt Stern 提请注意之前，它在德国之外几乎不为人知，此后该原理便以两人的名字共同命名。魏因贝格还推导了 X 连锁情形和多个等位基因的效应，并开创了研究人类家系与双生子的遗传方法。对变异存在的测量——1966年的电泳、1983年从群体中取样的第一批基因序列——把这一原理从理论基线变成了实证群体遗传学的起点。
:::

::: summary
- 变异由等位基因频率与基因型频率（[[#def-frequencies]]）、期望杂合度 $H = 1 - \sum p_i^2$ 描述；对序列，还有核苷酸多样性 $\pi$、分离位点 $S$ 与 Watterson 的 $\theta_W = S/a_n$（[[#def-variation]]）。
- 哈迪-魏因贝格下，等位基因计数估计 $\hat p$ 对 $n$ 个二倍体个体的方差为 $p(1-p)/2n$；精度取决于所抽样基因拷贝数。
- 随机交配且无进化力量时，基因型一代后达到 $p_i^2$ 与 $2p_ip_j$（两性等位基因频率不等时为两代），等位基因频率保持不变（[[#prop-hw-multi]]）。
- X 连锁基因座两性频率围绕常数 $\bar q = \tfrac13 q_m + \tfrac23 q_f$ 振荡，差每代减半（[[#prop-xlinked]]）。
- 偏离用 χ²（自由度 $k(k-1)/2$）或精确检验来检验，并用 $F = 1 - H_\mathrm{obs}/H_\mathrm{exp}$ 概括；两个等位基因时 $\chi^2 = nF^2$。
- 与哈迪-魏因贝格比例相符并不表明诸假设成立；偏离也不说明哪个失效。该原理是零模型，用途是预测基因型频率（隐性基因携带者、法医匹配概率），以及标记非随机交配、群体结构和分型错误。
:::

## 习题

::: exercise 等位基因计数 {level=1 check="0.6"}
100株植物的样本中有36个 $A_1A_1$、48个 $A_1A_2$、16个 $A_2A_2$。$A_1$ 的频率是多少？
::: solution
$\hat p = (2\times36 + 48)/200 = 120/200 = 0.6$。（这些计数恰是 $p = 0.6$ 的哈迪-魏因贝格比例 $0.36 : 0.48 : 0.16$。）
:::
:::

::: exercise 三个等位基因的基因多样性 {level=1 check="0.62"}
一个基因座有三个等位基因，频率为0.5、0.3和0.2。随机交配下的期望杂合度是多少？
::: solution
$H = 1 - (0.25 + 0.09 + 0.04) = 1 - 0.38 = 0.62$。
:::
:::

::: exercise 携带者频率 {level=1 check="0.0198"}
一个常染色体隐性表型在随机交配群体中每一万个体中出现1例。估计杂合携带者的频率（保留四位小数）。
::: solution
$q = \sqrt{10^{-4}} = 0.01$，$p = 0.99$，故 $2pq = 0.0198$——约每50人1人。
:::
:::

::: exercise 一个 χ² 检验 {level=2}
对400人在一对共显性等位基因 $M$ 与 $N$ 的血型系统上分型，有100个 $MM$、220个 $MN$、80个 $NN$。在5 %水平检验哈迪-魏因贝格比例并计算 $F$。
::: solution
$\hat p_M = (200 + 220)/800 = 0.525$。期望：$400\times0.525^2 = 110.25$，$400\times2\times0.525\times0.475 = 199.5$，$400\times0.475^2 = 90.25$。于是

$$
\chi^2 = \frac{10.25^2}{110.25} + \frac{20.5^2}{199.5} + \frac{10.25^2}{90.25} = 0.953 + 2.107 + 1.164 = 4.22,
$$

自由度1。它超过3.84，所以在5 %水平拒绝哈迪-魏因贝格比例（$P \approx 0.04$）。$F = 1 - 220/199.5 = -0.103$：杂合子**过剩**，且 $nF^2 = 400\times0.0106 = 4.22$ 如预期。杂合子过剩可来自亲代两性等位基因频率不等、抽样前对杂合子有利的选择，或群体之间的交配而非群体内部交配；由于 $P \approx 0.04$ 而一项典型研究要做许多检验，偶然也不无可能。
:::

::: exercise X 连锁性状 {level=2 check="0.0064"}
平衡时，一个随机的 X 连锁色觉变异在某个随机交配群体的8 %的男性中表达。预期有多大比例的女性表达它？
::: solution
平衡时患病雄性的频率为 $\bar q = 0.08$，患病女性为 $\bar q^2 = 0.0064$，约每156人1人。（真实的色觉缺陷涉及两个连锁基因 *OPN1LW* 与 *OPN1MW* 的多个等位基因，所以观察到的女性频率与这一单等位基因计算略有出入。）
:::

::: exercise 多等位基因的基因型 {level=2 check="55"}
一个有10个等位基因的二倍体基因座可能有多少种不同基因型？其中多少是杂合的？哈迪-魏因贝格比例的 χ² 检验有多少个自由度？
::: solution
$10\times11/2 = 55$ 种基因型，其中 $10\times9/2 = 45$ 种是杂合的。检验有 $k(k-1)/2 = 45$ 个自由度：54个独立类别减去9个估计的等位基因频率。类别如此多时，大多数期望计数很小，宜用精确检验。
:::

::: exercise 样本设计 {level=2 check="1050"}
在哈迪-魏因贝格比例下，要估计一个接近0.3的等位基因频率并使标准误为0.01，必须对多少个二倍体个体分型？
::: solution
由[[#eq-se]]，$pq/2n = 0.01^2$，故 $n = 0.3\times0.7/(2\times10^{-4}) = 1050$ 个个体（2,100个基因拷贝）。
:::

::: exercise 合并两个池塘 {level=3}
一位生物学家从两个池塘各取等量的蛙，作为一个样本分析。池塘1中等位基因 $A$ 的频率为0.9，池塘2中为0.3；每个池塘都处于哈迪-魏因贝格比例。(a) 合并样本中的基因型频率是多少？(b) 由合并后的等位基因频率，哈迪-魏因贝格会预测多大的杂合度？(c) 计算合并样本的 $F$ 并证明它等于 $\Var(p)/(\bar p\bar q)$，其中 $\Var(p)$ 是 $p$ 在两个池塘之间的方差。
::: solution
(a) 池塘1：$AA$ 0.81，$Aa$ 0.18，$aa$ 0.01。池塘2：0.09、0.42、0.49。合并（平均）：$AA$ 0.45、$Aa$ 0.30、$aa$ 0.25。

(b) 合并的 $\bar p = 0.45 + 0.15 = 0.6$，所以哈迪-魏因贝格预测 $2\bar p\bar q = 0.48$ 的杂合子。

(c) $F = 1 - 0.30/0.48 = 0.375$。两个池塘之间 $p$ 的方差为 $\tfrac12[(0.9 - 0.6)^2 + (0.3 - 0.6)^2] = 0.09$，且 $0.09/(0.6\times0.4) = 0.375$。杂合子缺失完全由合并造成——两个池塘都没有近交。这就是 Wahlund 效应，[[population-genetics/mutation-migration]]中 $F_\mathrm{ST}$ 的基础。
:::

::: exercise 两性频率不同 {level=3}
一个奠基群体中，某常染色体基因座雄性中等位基因频率 $p_m = 0.8$，雌性中 $p_f = 0.4$。(a) 给出第一代子代的基因型频率，并与相同等位基因频率下的哈迪-魏因贝格比例比较。(b) 证明一般地，第一代杂合子频率比 $2\bar p\bar q$ 多 $\tfrac12(p_m - p_f)^2$，其中 $\bar p = (p_m + p_f)/2$。
::: solution
(a) $A_1A_1$：$0.8\times0.4 = 0.32$；$A_2A_2$：$0.2\times0.6 = 0.12$；$A_1A_2$：$0.8\times0.6 + 0.2\times0.4 = 0.56$。等位基因频率 $0.32 + 0.28 = 0.6$；哈迪-魏因贝格应给出 $0.36, 0.48, 0.16$。杂合子多了8 %，而 $\tfrac12(0.4)^2 = 0.08$。

(b) 记 $p_m = \bar p + \delta$，$p_f = \bar p - \delta$，$\delta = (p_m - p_f)/2$。杂合子频率为 $p_m(1 - p_f) + p_f(1 - p_m) = p_m + p_f - 2p_mp_f = 2\bar p - 2(\bar p^2 - \delta^2) = 2\bar p\bar q + 2\delta^2$，而 $2\delta^2 = \tfrac12(p_m - p_f)^2$。下一代两性频率都是 $\bar p$ 时，多余部分消失。
:::

::: exercise 解读一项基因型调查 {level=3}
一项研究对某城市1,000个人的500,000个 SNP 分型，并在5 %水平检验每个 SNP 的哈迪-魏因贝格比例。(a) 若每个 SNP 真的都处于哈迪-魏因贝格比例，预计有多少个通不过？(b) 数百个 SNP 以 $P < 10^{-10}$ 通不过，几乎全都表现出严重的杂合子缺失。为什么分型错误比近交或群体结构更可能？(c) 另有少数表现出严重的杂合子**过剩**，较稀等位基因几乎无纯合子。给出一个解释。
::: solution
(a) 500,000的约5 %，即25,000个 SNP，纯属偶然。在这种规模上5 %阈值对质量控制毫无用处；研究采用 $10^{-6}$ 之类的阈值。

(b) 近交和群体结构大致均等地影响基因组的每一个位点，造成全基因组范围内小幅的杂合子缺失，而不是少数位点上的极端偏离。单个 SNP 上的巨大缺失指向位点特异性的假象：例如探针结合位点下的一个变异使一个等位基因无法被检出，于是杂合子被误判为纯合子。

(c) 几乎人人都有的“杂合子”可源于探针与基因组中两个不同位点——一个重复片段或一个旁系同源基因——匹配，而它们在该位置上不同，于是每个人都显示两种碱基。这类 SNP 会被标记并剔除。（真实的杂合子过剩若如此极端，需要极强的超显性选择，而这很罕见。）
:::
