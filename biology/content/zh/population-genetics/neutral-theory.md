1968年，木村资生（Motoo Kimura）做了一个计算。从血红蛋白、细胞色素 c 与其他蛋白质中氨基酸改变的速率出发，他外推到整个哺乳动物基因组，估计一条哺乳动物谱系大约每两年就固定一个核苷酸替换。倘若这些替换中每一个都由自然选择驱动，按霍尔丹（J. B. S. Haldane）1957年提出的论证，群体就得付出高得不可思议的“选择代价”——以遗传死亡计。木村资生得出结论：大多数替换在选择上必定是中性的，由漂变固定。来自选择代价的论证后来被证明比初看时更弱，但它所支持的假说——**分子进化的中性学说**——成了分子进化的零模型，也是 DNA 中一切选择检验的出发点。

进化课程已经给出了核心结果（[[evolution/mutation-drift-gene-flow]]）：中性替换速率等于突变率，$k = \mu$，这是分子钟的基础；受功能约束的位点进化更慢；而 $d_N/d_S > 1$ 是正选择的信号。本章建立这些结论背后的定量机制。我们将推导受选择突变的替换速率与近中性学说；对观测差异作多重替换校正；估计 $d_N$ 与 $d_S$；批判地审视这个钟；然后认识把种内变异与种间分歧作比较的主要检验——Tajima 的 $D$、HKA 检验与 McDonald–Kreitman 检验。最后我们来看这些检验已经说明了什么、争论处于什么状态。

## 替换速率

**替换**是一个新突变沿一条谱系的固定（[[evolution/mutation-drift-gene-flow]]）。在普查大小为 $N$ 的二倍体群体中，一个位点（或一个基因）每一代产生 $2N\mu$ 个新突变，每个都以概率 $u$ 被固定。于是长期的替换速率为

$$
k = 2N\mu\,u.
$$ {#eq-k}

对中性突变，$u = 1/2N$ 且 $k = \mu$。对选择系数为 $s$ 的突变（加性的，杂合子适合度 $1 + s$、纯合子 $1 + 2s$），木村资生的扩散结果（[[population-genetics/genetic-drift]]）给出 $u = (1 - e^{-4N_es/2N})/(1 - e^{-4N_es})$。

::: proposition 受选择突变的替换速率 {#prop-k-selected}
若 $N_e = N$ 且 $\lvert s\rvert$ 很小，则选择系数为 $s$ 的突变的替换速率相对于中性速率之比为

$$
\frac{k}{\mu} = \frac{4N_es}{1 - e^{-4N_es}} = \frac{S}{1 - e^{-S}},\qquad S = 4N_es.
$$ {#eq-k-ratio}

$S \to 0$ 时它为1，$S$ 为大正数时近似为 $S$，$S$ 为大负数时近似为 $\lvert S\rvert e^{-\lvert S\rvert}$。
:::

::: proof
取 $p = 1/2N$、$s$ 很小，$1 - e^{-2s} \approx 2s$，所以 $u \approx 2s/(1 - e^{-4Ns})$。于是 $k/\mu = 2Nu = 4Ns/(1 - e^{-4Ns})$。$S \to 0$ 时，$1 - e^{-S} \approx S$，比值趋于1。$S$ 为大正数时，$e^{-S} \to 0$，比值 $\approx S$。$S = -\lvert S\rvert$ 时，$1 - e^{\lvert S\rvert} \approx -e^{\lvert S\rvert}$，比值 $\approx \lvert S\rvert e^{-\lvert S\rvert}$。
:::

要紧的是标度选择系数 $S = 4N_es$。$s = -10^{-5}$ 的突变在 $N_e = 10^4$ 的群体中实际上是中性（$S = -0.4$，替换速率为中性的81 %），但在 $10^6$ 的群体中则受到强烈选择排斥（$S = -40$，几乎从不固定）。有利突变比中性突变固定得快得多——但只有极小比例的突变是有利的。

### 近中性学说

太田朋子（1973）提出，有一大类突变既不强烈有害也不恰好中性，而是*轻度*有害，其 $\lvert S\rvert$ 为1量级。它们的命运取决于群体大小：在小群体中它们表现得中性而被固定；在大群体中选择把它们清除。近中性学说预言：

- **小群体中蛋白质进化更快。** $N_e$ 较小的谱系应固定更多轻度有害的氨基酸改变，抬高 $d_N/d_S$。比较基因组学大体支持这一点：$d_N/d_S$ 在长期群体较小的物种（如大型哺乳动物）中往往高于群体较大的物种（如啮齿类与 *Drosophila*），尽管这一效应不大且与其他性状混杂。
- **蛋白质钟的世代时间效应弱于沉默位点。** 世代短的物种往往群体较大；它们每年更快的突变在一定程度上被对轻度有害氨基酸改变的更强纯化选择所抵消，使蛋白质钟按年计比沉默位点钟更规则。
- **对同义位点的弱选择。** 在 $N_e$ 极大的生物中，如 *E. coli*、酵母与 *Drosophila*，与丰富 tRNA 相匹配的偏好密码子使用得更频繁，尤其在高表达基因中——这是 $S$ 为1量级的选择，只在大群体中可见（Michael Bulmer，1991；Hiroshi Akashi，1995；以及其他人）。

::: example 轻度有害突变 {#ex-nearly}
一类氨基酸突变在纯合形式下的选择系数 $s = -5\times10^{-5}$（[[#prop-k-selected]]的加性参数化中的 $s$）。比较它们相对于中性突变的替换速率：在 $N_e = 10^4$ 的哺乳动物中，在 $N_e = 10^6$ 的昆虫中。
::: solution
哺乳动物：$S = 4\times10^4\times(-5\times10^{-5}) = -2$，所以 $k/\mu = -2/(1 - e^{2}) = -2/(-6.389) = 0.31$。昆虫：$S = -200$，所以 $k/\mu \approx 200e^{-200} \approx 10^{-85}$，即为零。同样的突变在哺乳动物中以中性速率的三分之一被固定，在昆虫中则从不固定。若一种蛋白质的突变包含许多这类轻度有害改变，哺乳动物谱系将表现出更高的 $d_N/d_S$——不是因为选择偏爱改变，而是因为选择太弱、无法阻止改变。
:::
:::

## 度量分歧

### 多重替换与 Jukes–Cantor 校正

比对两条同源序列并计数它们彼此不同的位点比例 $\hat p$ 时，我们低估了已发生的替换数，因为一个位点可能变过多次（两次改变，或一次改变加一次回复，可能只留下一个差异或一个也不留）。最简单的校正假设每个碱基以相同速率变为其余三种之一。

::: proposition Jukes–Cantor 距离 {#prop-jc}
设替换在每个位点以泊松过程发生，三种可能改变的概率相等，并令 $d$ 为分开两条序列的每位点期望替换数（自共同祖先起沿两条谱系相加）。则两条序列在某个位点彼此不同的概率为

$$
p = \tfrac34\left(1 - e^{-4d/3}\right),
$$

反解即得 **Jukes–Cantor 距离**（Thomas Jukes 与 Charles Cantor，1969）

$$
\hat d = -\tfrac34\ln\left(1 - \tfrac43\hat p\right).
$$ {#eq-jc}
:::

::: proof
沿一条路径从一条序列出发、经过它们的共同祖先、回到另一条序列；替换沿这条路径发生，总速率使期望替换数为 $d$。令 $P(t)$ 为期望长度 $t$ 的路径末端碱基与起点碱基相同的概率。短区间 $dt$ 内的一次替换事件（概率 $dt$）把一个相同的位点变成不同碱基，并以 $\tfrac13$ 的概率把一个不同的位点变回起始碱基。于是 $dP/dt = -P + \tfrac13(1 - P) = \tfrac13 - \tfrac43P$，结合 $P(0) = 1$，得 $P(t) = \tfrac14 + \tfrac34e^{-4t/3}$。不同的概率为 $p = 1 - P(d) = \tfrac34(1 - e^{-4d/3})$；解出 $d$ 即得[[#eq-jc]]。
:::

校正对很小的 $\hat p$ 可以忽略（$\hat p < 0.05$ 时 $\hat d \approx \hat p$），在 $\hat p = 0.3$ 时相当可观（$\hat d = 0.38$），而当 $\hat p$ 趋近随机序列之间的差异 $\tfrac34$ 时距离变为无穷：饱和位点不再携带任何关于时间的信息。更现实的模型允许转换比颠换更频繁（Kimura 的两参数模型，1980）、碱基组成不等以及位点间速率变异；它们在 [[bioinformatics/phylogenetic-inference]] 与 [[evolution/phylogenetics]] 中讨论。

x: 0, 0.74
y: 0, 2
labels: \hat d\ \text{(Jukes–Cantor)}; \hat p
vlines: 0.75
caption: Jukes–Cantor 距离[[#eq-jc]]（曲线）对观测的差异位点比例 $\hat p$，并给出未校正距离 $\hat d = \hat p$（直线）以便比较。悬停可读数。差异在约10 %以内时校正很小；超过50 %后它迅速增大，并在 $\hat p = 0.75$——两条序列彼此已完全随机——处发散。注意这对来自饱和位点的估计意味着什么：$\hat p$ 的小误差会产生 $\hat d$ 的巨大误差。
:::

### 同义与非同义分歧

要比较一个蛋白编码基因中不同类别位点的速率，我们需要知道每类改变有多少次机会。在 Masatoshi Nei 与 Takashi Gojobori（1986）的方法中，密码子被逐个检验：每个位置上三种可能改变中，保持氨基酸不变的比例计入**同义位点** $L_S$，其余计入**非同义位点** $L_N$。（例如，四重简并密码子——如丙氨酸的 `GCN`——的第三个位置贡献一个完整的同义位点。）观察到的同义与非同义差异 $S_d$ 与 $N_d$ 以类似方式计数，于是

$$
p_S = \frac{S_d}{L_S},\quad p_N = \frac{N_d}{L_N},\qquad d_S = -\tfrac34\ln\left(1 - \tfrac43p_S\right),\quad d_N = -\tfrac34\ln\left(1 - \tfrac43p_N\right),
$$

比值为 $\omega = d_N/d_S$。现代分析在密码子替换模型下用最大似然估计 $\omega$（Nick Goldman 与 Ziheng Yang，1994），它能让 $\omega$ 在位点与谱系之间变化。

::: example 一个 d_N/d_S 比值 {#ex-dnds}
两条比对好的、长1,000个核苷酸的直系同源编码序列含750个非同义位点与250个同义位点。它们之间有15个非同义与25个同义差异。计算 $d_N$、$d_S$ 与 $\omega$ 并解释。
::: solution
$p_N = 15/750 = 0.020$ 且 $p_S = 25/250 = 0.100$。Jukes–Cantor：$d_N = -0.75\ln(1 - 0.0267) = 0.0203$；$d_S = -0.75\ln(1 - 0.1333) = 0.1073$。于是 $\omega = 0.0203/0.1073 = 0.19$。

非同义改变大约以同义速率的五分之一被固定。若同义改变接近中性，该基因约80 %的氨基酸突变被纯化选择所去除——这是典型格局。对整个基因及其历史取平均的 $\omega$ 是偏保守的：少数位点或单一谱系上的正选择可能被别处的强约束掩盖，这就是要用位点特化与分支特化模型去寻找它的原因。检测到 $\omega > 1$ 的经典例子包括 MHC I 类分子的抗原结合位点（Austin Hughes 与 Masatoshi Nei，1988），以及牛与叶猴胃中的溶菌酶——它们趋同进化以消化前肠中的细菌（Caro-Beth Stewart、Allan Wilson 及同事，1987）。
:::
:::

## 批判地审视分子钟

中性学说预言一个钟：中性位点每代以速率 $\mu$ 滴答；而对某一类位点——其突变中比例为 $f_0$ 的部分是中性的——则以 $f_0\mu$ 滴答。实际中这个钟以三种方式显得不规则。

- **谱系效应。** 每年突变率随世代时间、代谢率与 DNA 修复而异；啮齿类每年沉默位点钟比灵长类更快，而灵长类内部，猿——尤其是人——比猴更慢。
- **过度散布。** 即使在同一谱系内，若替换是泊松过程，其方差也应等于均值。John Gillespie 与其他人（自1970年代起，并在《分子进化的起因》（*The Causes of Molecular Evolution*，1991）中）发现，对许多蛋白质而言，**离散指数**——各谱系替换数之间的方差除以其均值——远高于1。间歇性选择、近中性学说下波动的群体大小、以及变化的约束都能造成这一点。
- **定标。** 钟只有在速率已知时才给出时间——速率来自化石或其他已定年的事件，或来自实测的突变率——而这两者可能不一致。用基于家系的突变率测定人-黑猩猩分歧年代，得到的时间比化石定标的系统发育速率给出的更早；这一分歧靠更好的世代时间与祖先群体大小估计花了数年才解决（[[evolution/human-evolution]]）。

因此现代系统发育方法使用**松弛分子钟**，让速率在一个统计模型内于分支之间变化（[[evolution/phylogenetics]]）。这个钟仍然不可或缺，但是作为一个统计工具，而不是定律。

## 用多态性数据检验中性

中性学说不仅对物种之间的分歧作预言，也对物种内部的变异、以及两者如何相关联作预言。检验把观察到的格局与**标准中性模型**的预言相比较：在恒定大小、处于平衡的单个随机交配群体中、无限位点模型下的中性突变。

### 位点频率谱与 Tajima 的 D

在标准中性模型下，并合理论（[[population-genetics/genetic-drift]]）不仅预言分离位点的数目，也预言它们的频率。在 $n$ 条序列中，突变（衍生）等位基因恰好出现在 $i$ 条拷贝中的位点数期望为

$$
\E[\xi_i] = \frac{\theta}{i},\qquad i = 1, \ldots, n - 1,
$$ {#eq-sfs}

于是单拷贝位点是最常见的类，而每个频率类的稀有程度与其计数成反比（Yun-Xin Fu，1995）。对 $i$ 求和给出 $\E[S] = \theta a_n$，与前面一样。$\theta$ 的不同估计量对这些类的权重不同：Watterson 的 $\theta_W = S/a_n$ 对所有分离位点一视同仁，而 $\pi$ 给中间频率的位点以最大权重（有 $i$ 条衍生拷贝的位点为成对差异数贡献 $i(n - i)$）。在中性下两者的期望都是 $\theta$；频率谱上的偏离使二者分离。

::: definition Tajima 的 D {#def-tajima}
对 $n$ 条序列、$S$ 个分离位点、平均成对差异数为 $\hat\pi$ 的样本，**Tajima 的 $D$**（Fumio Tajima，1989）为

$$
D = \frac{\hat\pi - S/a_n}{\sqrt{e_1S + e_2S(S - 1)}},
$$ {#eq-tajima}

其中分母在标准中性模型下估计分子的标准差，常数取 $a_1 = a_n = \sum_{i=1}^{n-1}1/i$，$a_2 = \sum_{i=1}^{n-1}1/i^2$，$b_1 = \frac{n+1}{3(n-1)}$，$b_2 = \frac{2(n^2 + n + 3)}{9n(n-1)}$，$c_1 = b_1 - \frac{1}{a_1}$，$c_2 = b_2 - \frac{n+2}{a_1n} + \frac{a_2}{a_1^2}$，$e_1 = c_1/a_1$，$e_2 = c_2/(a_1^2 + a_2)$。
:::

在标准中性模型下 $D$ 接近0。**负的 $D$** 意味着罕见变异过剩：选择清除之后（新突变出现在被扫荡的单倍型上、频率很低）、对轻度有害变异的纯化选择之下（使之保持罕见）、或群体扩张之后（星状谱系、长外枝）都预期如此。**正的 $D$** 意味着中间频率的变异过剩：平衡选择之下（旧等位基因维持在中间频率）、群体收缩之后、或样本汇集了许多有分化的亚群体时预期如此。

::: example 计算 Tajima 的 D {#ex-tajima}
某群体一个基因的10条序列含 $S = 16$ 个分离位点，平均成对差异数为 $\hat\pi = 3.0$。第二个基因同样 $n = 10$、$S = 16$，但 $\hat\pi = 8.5$。分别计算两者的 $D$ 并解释。
::: solution
对 $n = 10$：$a_1 = 2.829$，$a_2 = 1.540$，$b_1 = 11/27 = 0.4074$，$b_2 = 2\times113/810 = 0.2790$，$c_1 = 0.4074 - 0.3535 = 0.0539$，$c_2 = 0.2790 - 12/28.29 + 1.540/8.003 = 0.2790 - 0.4242 + 0.1924 = 0.0472$，$e_1 = 0.0191$，$e_2 = 0.0472/9.543 = 0.00494$。分母为 $\sqrt{0.0191\times16 + 0.00494\times240} = \sqrt{0.305 + 1.186} = 1.221$，且 $\theta_W = 16/2.829 = 5.66$。

基因1：$D = (3.0 - 5.66)/1.221 = -2.17$。基因2：$D = (8.5 - 5.66)/1.221 = +2.33$。

基因1分离位点多而成对多样性少，所以其变异大多罕见——与近期的选择清除、纯化选择或群体增长相一致。基因2的变异处于中间频率——与平衡选择、或来自有结构群体的样本相一致。在标准中性模型下，超过约 $\pm2$ 的值很不寻常，但显著性应按一个现实群体历史下的并合模拟来判断；而且群体历史影响所有基因座而选择只影响特定基因座，所以最强的证据来自把某个基因与同一样本中 $D$ 的全基因组分布相比较。
:::
:::

```python
import math

def tajimas_d(n, S, pi):
    """Tajima's D from sample size n, segregating sites S and mean pairwise differences pi."""
    a1 = sum(1 / i for i in range(1, n))
    a2 = sum(1 / i ** 2 for i in range(1, n))
    b1 = (n + 1) / (3 * (n - 1))
    b2 = 2 * (n * n + n + 3) / (9 * n * (n - 1))
    c1 = b1 - 1 / a1
    c2 = b2 - (n + 2) / (a1 * n) + a2 / a1 ** 2
    e1, e2 = c1 / a1, c2 / (a1 ** 2 + a2)
    return (pi - S / a1) / math.sqrt(e1 * S + e2 * S * (S - 1))

print(round(tajimas_d(10, 16, 3.0), 2), round(tajimas_d(10, 16, 8.5), 2))   # -2.17 2.33
```

### 多态性与分歧的比较

中性学说把物种内的变异与物种间的分歧联系起来：两者都正比于中性突变率。有两个检验利用了这一点。

**HKA 检验**（Richard Hudson、Martin Kreitman 与 Montserrat Aguadé，1987）比较几个基因座。在中性下，每个基因座的种内多态性（$\propto 4N_e\mu_i$）与种间分歧（$\propto 2T\mu_i$）依赖同一个基因座特异的突变率 $\mu_i$，所以多态性与分歧之比在每个基因座上应相同。多态性相对于其分歧而言太少的基因座提示近期有过选择清除；太多的则提示平衡选择。

**McDonald–Kreitman 检验**把同样的逻辑用于一个基因内部的两类位点，于是突变率、谱系与群体历史都被两类共享。

::: proposition McDonald–Kreitman 检验 {#prop-mk}
把来自两个物种的序列样本中的变异位点分为**多态的**（种内变异）或**固定的**（种间不同、各种内恒定），并分为**非同义的**（N，替换）或**同义的**（S）。若非同义突变要么中性、要么强烈有害（从不固定，也从不以可观频率多态），则

$$
\frac{D_N}{D_S} = \frac{P_N}{P_S}
$$

其期望成立，其中 $D$ 计固定差异，$P$ 计多态。固定的非同义差异过剩，$D_N/D_S > P_N/P_S$，指示适应性替换。**适应性非同义替换的比例**估计为

$$
\alpha = 1 - \frac{D_SP_N}{D_NP_S}.
$$ {#eq-mk-alpha}
:::

::: proof
若比例为 $f$ 的非同义突变是中性的、其余强烈有害，则非同义位点上的固定差异与多态都只由中性部分产生，速率正比于 $fL_N\mu$；而同义位点（假定为中性）两者都按正比于 $L_S\mu$ 的速率产生。谱系与分歧时间对两类的影响相同，所以 $D_N/D_S = P_N/P_S = fL_N/L_S$。适应性替换加到 $D_N$ 上，但对 $P_N$ 的贡献可忽略，因为受青睐的突变很快穿过多态阶段。若 $D_N$ 超过它的中性期望 $D_SP_N/P_S$，则超出比例 $1 - D_SP_N/(D_NP_S)$ 估计非同义替换中适应性部分的占比。
:::

::: example Drosophila 的 Adh 基因 {#ex-mk}
John McDonald 与 Martin Kreitman（1991）对12条 *D. melanogaster*、6条 *D. simulans* 与12条 *D. yakuba* 的乙醇脱氢酶基因 *Adh* 测序。他们发现7个固定与2个多态的替换（非同义）差异，以及17个固定与42个多态的同义差异。检验其对中性的偏离并估计 $\alpha$。
::: solution
2×2表如下：

| | 固定的 | 多态的 |
|---|---|---|
| 替换 | 7 | 2 |
| 同义 | 17 | 42 |

在中性下，替换与同义之比在两列中应相同。固定差异之间它为 $7/17 = 0.41$，而多态之间为 $2/42 = 0.048$。对这个表作费希尔精确检验（[[biostatistics/categorical-data]]）得 $P \approx 0.007$。由[[#eq-mk-alpha]]，$\alpha = 1 - (17\times2)/(7\times42) = 1 - 34/294 = 0.88$：按照这份证据，这些物种在 *Adh* 上的氨基酸替换大多数是适应性的。（**中性指数** $(P_N/P_S)/(D_N/D_S) = 0.12$ 表达的是同一件事。）这个单一基因的结果开启了在整个基因组范围应用该检验的进程。
:::
:::

MK 检验也有自身的陷阱。轻度有害的非同义突变以多态形式分离却很少固定，使 $P_N$ 膨胀、把 $\alpha$ 向下偏置；剔除罕见多态，或对适合度效应分布建模（Adam Eyre-Walker 与 Peter Keightley，以及其他人），能减小这一偏置。在近中性学说下，分歧时代至今的群体大小变化可能造成任一方向的偏置。

::: quiz
某个基因的 MK 表中有 $D_N = 10$、$D_S = 20$、$P_N = 15$、$P_S = 30$。你能得出什么结论？
- [ ] 有适应性进化的强证据，因为 $D_N = 10$ 很大。
- [x] 数据符合中性期望：固定位点与多态位点的 N : S 比值相同（1 : 2），且 $\alpha = 0$。
- [ ] 有平衡选择的证据，因为 $P_N > D_N$。
- [ ] 什么也得不出来，因为这个检验需要同义与非同义位点数目相等。
::: solution
$D_N/D_S = 0.5 = P_N/P_S$，所以 $\alpha = 1 - (20\times15)/(10\times30) = 0$。绝对数值取决于位点数与分歧时间；只有比值的比较才有信息量，而它不要求位点数相等，因为位点计数相消。
:::
:::

## 检验告诉我们的结论

半个世纪的数据对木村资生提出的问题给出了细致入微的回答。

- **功能序列中的大多数新突变是有害的**，而在我们这样的基因组中那一大块非功能部分里，大多数多态与替换是中性的或接近中性。纯化选择是对蛋白质的支配性选择形式（大多数基因 $\omega \ll 1$）。
- **适应性替换在某些物种中很常见。** 基于 MK 的估计表明，*Drosophila* 物种之间约一半的氨基酸替换是适应性的（Nick Smith 与 Adam Eyre-Walker，2002，及其后的研究），其他一些大群体物种的数值相似或更高，但在人科物种中要低得多——正如近中性学派对有效大小小的物种所预言的。
- **连锁选择塑造全基因组的多样性。** 在重组低、基因密度高的区域多样性较低，原因是选择清除与背景选择（[[population-genetics/linkage-disequilibrium]]）。这有助于解释 Lewontin 悖论——物种间多样性的变异远小于群体大小的变异——因为连锁选择在群体较大的物种中去除的多样性更多（Russell Corbett-Detig、Daniel Hartl 与 Timothy Sackton，2015），尽管它并不能解释全部。

这些发现究竟意味着中性学说被“推翻”还是被“证实”，仍在争论，部分争论关乎定义：Andrew Kern 与 Matthew Hahn（2018）主张直接选择与连锁选择无处不在，中性学说不该再是基因组变异的默认解释；而 Jeffrey Jensen 及同事（2019）回应说，加上纯化选择与群体历史的中性学说仍是合适的零模型，许多所谓的选择特征其实与群体历史混杂。没有争议的是：中性学说提供了检测选择所依据的零假设，而且它的预言定量到足以接受检验。

::: warning "中性意味着不重要"与"检验显著就证明有选择"
中性突变是对适合度的效应之小、以致在某给定大小的群体中选择无法决定其命运的突变，$\lvert 4N_es\rvert \ll 1$——它未必是对表型没有效应的突变；而且在小群体中中性的突变在大群体中未必中性。反过来，拒绝标准中性模型也不是选择的证明：群体扩张、瓶颈、结构与混合（admixture）都会扭曲频率谱与 LD，突变率的变异也会影响多态性-分歧的比较。稳健的推断要把候选基因与同一群体历史下的全基因组分布相比较，或者使用 MK 这类在所比较的两类之间共享群体历史的检验。
:::

::: application 中性学说在医学与保护中的应用
约束的逻辑被用来解读人类变异：其中功能缺失变异比按突变率的期望稀少得多的基因（“受约束”基因，在 gnomAD 之类的大型数据库中度量）很可能是必需基因，其中的新突变在罕见遗传病诊断中被优先关注（[[genomics/human-variation]]，临床方面见医学图谱）。在病原物中，沿系统发育分支的 $d_N/d_S$ 能识别处于免疫驱动正选择之下的蛋白质，指导疫苗抗原的选择；以采样日期定标的分子钟可以追踪流行病的传播。在保护中，中性多样性度量 $N_e$ 与连通性，而适应性基因座上的变异指导该保护哪些群体或混合哪些群体的决策。
:::

::: history
Emile Zuckerkandl 与 Linus Pauling 在1962–65年提出了分子钟；木村资生（1968，*Nature*）以及 Jack King 与 Thomas Jukes（1969，*Science*）提出了中性学说；Jukes 与 Cantor 在1969年发表了他们的距离。太田朋子与木村资生在1971年讨论了钟的恒定性，太田朋子在1973年提出了近中性学说。使用 DNA 多态性的第一批检验跟在 Kreitman 1983年的 *Adh* 序列之后：HKA 检验（1987）、Tajima 的 $D$（1989）与 McDonald–Kreitman 检验（1991）。木村资生的《分子进化的中性学说》（*The Neutral Theory of Molecular Evolution*，1983）与 Gillespie 的《分子进化的起因》（*The Causes of Molecular Evolution*，1991）分别陈述了争论的两方。2000年代以来，来自许多物种的基因组规模数据使这些检验能一次应用于数千个基因，问题从“分子进化是中性的吗”转向“每一类改变中有多大比例由各过程驱动”。
:::

::: summary
- 替换速率为 $k = 2N\mu u$；对中性突变 $k = \mu$；有选择时 $k/\mu = S/(1 - e^{-S})$，$S = 4N_es$（[[#prop-k-selected]]）。$\lvert S\rvert \lesssim 1$ 的突变是近中性的；其命运取决于 $N_e$。
- 近中性学说预言小群体中蛋白质进化更快、$d_N/d_S$ 更高，以及只在大群体中可见的对密码子使用的弱选择。
- 观测差异需作多重替换校正：$\hat d = -\tfrac34\ln(1 - \tfrac43\hat p)$（Jukes–Cantor，[[#prop-jc]]）；$\omega = d_N/d_S$ 使用同义与非同义位点的计数。
- 分子钟过度散布且依赖谱系；需要松弛分子钟与谨慎的定标。
- 中性位点频率谱为 $\E[\xi_i] = \theta/i$；Tajima 的 $D$ 比较 $\pi$ 与 $S/a_n$（[[#def-tajima]]）：选择清除或扩张之后为负，平衡选择或收缩之下为正。
- HKA 在不同基因座之间比较多态性与分歧；McDonald–Kreitman 在一个基因内部的不同位点类之间比较两者，$\alpha = 1 - D_SP_N/(D_NP_S)$（[[#prop-mk]]）。
- 纯化选择占支配；适应性替换在大 $N_e$ 的物种中常见；连锁选择塑造多样性。选择在多大程度上遍及基因组仍有争论，但中性学说是零模型。
:::

## 习题

::: exercise 校正后的距离 {level=1 check="0.3831"}
两条序列在30 %的比定位点上不同。Jukes–Cantor 距离是多少（保留四位小数）？
::: solution
$\hat d = -0.75\ln(1 - 0.4) = -0.75\times(-0.5108) = 0.3831$，每位点0.3831个替换。
:::
:::

::: exercise 相对替换速率 {level=1 check="0.5820"}
$4N_es = -1$ 的突变，其替换速率相对于中性的是多少（保留四位小数）？
::: solution
$k/\mu = -1/(1 - e^{1}) = -1/(-1.7183) = 0.5820$。
:::
:::

::: exercise 适应性替换的比例 {level=1 check="0.6"}
一个 MK 表有 $D_N = 20$、$D_S = 40$、$P_N = 8$、$P_S = 40$。估计 $\alpha$。
::: solution
$\alpha = 1 - (40\times8)/(20\times40) = 1 - 320/800 = 0.6$。
:::
:::

::: exercise 饱和 {level=2}
(a) 证明小 $\hat p$ 时 Jukes–Cantor 距离近似为 $\hat p + \tfrac23\hat p^2$。(b) 观测 $\hat p$ 为多少时，校正使距离比未校正的多出10 %？(c) 为什么分歧年代久远的基因——例如哺乳动物与鱼类共有的那些——的同义位点对定年用处不大？
::: solution
(a) $-\ln(1 - x) = x + x^2/2 + \cdots$，取 $x = \tfrac43\hat p$：$\hat d = \tfrac34(\tfrac43\hat p + \tfrac{16}{18}\hat p^2 + \cdots) = \hat p + \tfrac23\hat p^2 + \cdots$。

(b) $\tfrac23\hat p^2 \approx 0.1\hat p$ 给出 $\hat p \approx 0.15$；精确解 $\hat d = 1.1\hat p$ 得 $\hat p = 0.13$。

(c) 同义位点进化快；数亿年间已改变多次，于是 $\hat p$ 趋近 $\tfrac34$（考虑碱基组成偏倚则更低），距离估计变得极不精确或无穷。进化慢的非同义位点或氨基酸序列在这样的时间尺度上仍保留信息。
:::
:::

::: exercise 近中性边界 {level=2 check="0.000025"}
在 $N_e = 10^4$ 的群体中，$s$ 的量级低于多少时突变表现得实际中性（$4N_e\lvert s\rvert < 1$）？
::: solution
$\lvert s\rvert < 1/(4\times10^4) = 2.5\times10^{-5}$。
:::
:::

::: exercise 在全基因组范围解读 Tajima 的 D {level=2}
对人类某群体5,000个基因的调查中，大多数基因的 Tajima 的 $D$ 为负，全基因组均值约 $-0.5$；少数基因 $D < -2.5$，另有一些 $D > 2$。(a) 为什么向负值的全体移动是群体历史的证据而不是选择的证据？(b) 对分布尾部的基因你会得出什么结论？
::: solution
(a) 选择作用于特定基因，而群体大小的改变改变所有基因座的谱系。罕见变异的全基因组过剩是群体增长的标志——与人类群体近期的扩张相一致。

(b) 在这一背景下，分布尾部是选择的候选：强负 $D$ 对应近期选择清除或纯化选择，强正 $D$ 对应平衡选择（HLA 基因是经典例子）。其显著性应针对经验的基因组分布、或在按全基因组拟合的群体历史模型下的模拟来判断，并由其他证据（单倍型长度、$F_\mathrm{ST}$、功能）证实。
:::
:::

::: exercise d_N/d_S 的计算 {level=2}
一对序列有600个非同义与200个同义位点，其间有24个非同义与16个同义差异。计算使用与不使用 Jukes–Cantor 校正的 $\omega$，并说明哪种解读更合适。
::: solution
$p_N = 0.04$，$p_S = 0.08$。未校正 $\omega = 0.5$。校正后：$d_N = -0.75\ln(1 - 0.0533) = 0.0411$，$d_S = -0.75\ln(1 - 0.1067) = 0.0846$，$\omega = 0.486$。校正使 $\omega$ 略有下降，因为进化更快的同义位点经历了更多重替换。无论哪种，$\omega \approx 0.5$ 都表示平均而言中等强度的纯化选择，但不能排除一部分位点上的正选择——那需要位点特化模型。
:::
:::

::: exercise MK 检验与轻度有害突变 {level=3}
假设有中性与强烈有害的非同义突变之外的一类轻度有害突变，它们贡献许多多态（大多罕见）却几乎没有固定差异。(a) 这会使 $\alpha$ 的估计朝哪个方向偏？(b) 解释为什么剔除频率低于例如10 %的多态能减小偏置。(c) 若两个物种分歧以来群体大幅扩张，轻度有害突变可能如何使检验朝相反方向偏置？
::: solution
(a) 它使 $P_N$ 膨胀，于是 $D_SP_N/(D_NP_S)$ 增大、$\alpha$ 被低估（甚至可能变负，暗示并不存在的多态过剩）。

(b) 轻度有害变异被选择压到低频，所以在罕见多态中占比过高；中性变异则分布于所有频率。剔除罕见多态会去除其中不成比例的一部分轻度有害变异，使 $P_N/P_S$ 更接近中性突变的比值。（对适合度效应分布建模的方法把这一点处理得更严格。）

(c) 若祖先群体很小，轻度有害突变表现得近中性而有部分被固定，抬高了 $D_N$；在如今的大群体中，它们被有效地选择排除、只贡献很少多态。于是 $D_N/D_S$ 相对于 $P_N/P_S$ 升高，而并无任何适应性进化，$\alpha$ 被高估。
:::
:::

::: exercise 钟过度散布了吗？ {level=3}
一种蛋白质沿五条同龄的独立谱系分别累积了12、20、8、25与15个氨基酸替换。(a) 计算离散指数（方差除以均值）。(b) 若替换服从泊松过程，它的期望值是多少？(c) 给出两个使数值远高于这一期望的原因。
::: solution
(a) 均值 $= 80/5 = 16$。样本方差 $= [(-4)^2 + 4^2 + (-8)^2 + 9^2 + (-1)^2]/4 = (16 + 16 + 64 + 81 + 1)/4 = 178/4 = 44.5$。指数 $= 44.5/16 = 2.8$。

(b) 1，因为泊松变量的方差等于其均值。（只有五条谱系时估计噪声很大；泊松模型下，$4\times$ 指数即 $11.1$，近似服从4自由度的 χ²，得 $P \approx 0.025$。）

(c) 不同谱系每年的突变率不同（世代时间、修复效率）；某些谱系上正选择的间歇发生；或群体大小的改变——它在近中性学说下改变轻度有害突变沿不同谱系的固定速率。谱系共享也会违反这里假定的独立性。
:::
