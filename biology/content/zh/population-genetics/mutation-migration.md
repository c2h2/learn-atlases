漂变若不加抵消会摧毁变异：每个封闭群体最终都会变成单态的。然而自然群体充满变异，同种相邻群体彼此之间的相似程度通常远高于漂变单独所能允许的程度。两种力量可以解释这一点。**突变**在群体内部创造新等位基因，**迁移**（基因流）则把其他群体的等位基因带进来。本章把两者都放在与漂变和选择的平衡中处理。我们先给出突变的标准模型，求出一个给定大小的群体在平衡时容纳多少变异；定义突变负荷；然后转向空间。真实的物种被划分为互相交换迁移个体的地方群体，我们需要度量这种结构的工具：Wahlund 效应与苏厄尔·赖特的 F-统计量。最后以岛屿模型和台阶模型收尾——它们预言给定的基因流量下应期望多大的分化——并以迁移-选择平衡作结。

基本的结果——单独的突变压力，突变-选择平衡 $\hat q \approx \mu/hs$ 或完全隐性时的 $\sqrt{\mu/s}$，岛屿模型 $p_t - p_M = (1-m)^t(p_0 - p_M)$，以及 $F_\mathrm{ST} \approx 1/(1 + 4Nm)$——都在[[evolution/mutation-drift-gene-flow]]中。这里我们推导并推广它们。

## 突变模型

一次突变对等位基因身份做了什么，取决于我们能观察到什么。三种理想化覆盖了大多数用途。

::: definition 突变模型 {#def-mutation-models}
- **无限等位基因模型**（木村资生与 James Crow，1964）：每一次突变都创造出一个前所未见的等位基因。适用于以长序列区分等位基因的情形，此时两次独立突变几乎绝不会产生同一个等位基因。
- **无限位点模型**（木村资生，1969）：每一次突变都发生在样本历史中此前从未突变过的核苷酸位点上。当每位点的 $\theta$ 很小时它适用于 DNA 序列，此时一个位点上的多次命中很罕见。
- **逐步突变模型**（太田朋子与木村资生，1973）：等位基因是整数（微卫星的重复单元数），每次突变增加或去掉一个单元。因此不同的谱系可能经由不同的路线到达同一个等位基因（**同塑性**）。
- **$k$ 等位基因模型与有限位点模型**：等位基因或碱基是一个固定集合，突变在其中发生，因此回复突变与平行突变都有可能。
:::

这个选择会影响预言。不同种类基因座的突变率也相差悬殊：人的点突变约为每碱基对每代 $10^{-8}$，一个典型基因（对其所有位点求和）中功能缺失突变约为每代 $10^{-5}$–$10^{-6}$，而许多微卫星约为每代 $10^{-3}$–$10^{-4}$ 的量级，其重复序列在复制中容易发生滑移。

## 突变与漂变：有多少变异？

漂变以每代 $1/2N_e$ 的速率去除杂合度；突变则创造杂合度。用无限等位基因模型，借助同一概率可以很容易地导出这个平衡。

设 $F$ 为随机取自群体的两个基因拷贝**状态相同**（同一等位基因）的概率。向前追溯一代，两个拷贝是同一个父代基因的拷贝的概率为 $1/2N_e$，否则它们是两个不同基因的拷贝，后者以概率 $F$ 相同。在无限等位基因模型下，只有当两个拷贝在那一代都没有突变时它们才保持相同，其概率为 $(1 - \mu)^2$；任何突变都会使它们永远不同。

::: proposition 突变-漂变平衡，无限等位基因 {#prop-iam}
在每基因每代突变率为 $\mu$ 的无限等位基因模型下，

$$
F' = \left[\frac{1}{2N_e} + \left(1 - \frac{1}{2N_e}\right)F\right](1 - \mu)^2,
$$ {#eq-iam-rec}

而在平衡时，对小的 $\mu$ 与大的 $N_e$，

$$
\hat F \approx \frac{1}{1 + 4N_e\mu} = \frac{1}{1 + \theta},\qquad \hat H = 1 - \hat F \approx \frac{\theta}{1 + \theta}.
$$ {#eq-iam}
:::

::: proof
该递推来自上面的论证。令 $F' = F = \hat F$ 并求解：$\hat F[1 - (1 - 1/2N_e)(1 - \mu)^2] = (1 - \mu)^2/2N_e$。只保留 $\mu$ 与 $1/N_e$ 的一阶项（并略去其乘积），$1 - (1 - 1/2N_e)(1 - \mu)^2 \approx 2\mu + 1/2N_e$ 且 $(1 - \mu)^2 \approx 1$，故 $\hat F \approx (1/2N_e)/(2\mu + 1/2N_e) = 1/(1 + 4N_e\mu)$。
:::

平衡只通过 $N_e$ 与 $\mu$ 的乘积 $\theta = 4N_e\mu$ 依赖于二者——这正是并合理论下决定 $\pi$ 的那个群体突变率（[[population-genetics/genetic-drift]]）。这是中性理论的一个普遍特征：平衡时群体中变异的量度量的是 $\theta$，而不是 $N_e$ 或 $\mu$ 中的任何一个。

对微卫星来说，逐步模型更现实。太田朋子与木村资生（1973）证明，此时的平衡杂合度为

$$
\hat H_\mathrm{SMM} = 1 - \frac{1}{\sqrt{1 + 2\theta}},
$$ {#eq-smm}

它总是小于无限等位基因的值，因为突变能够重新创造出已经存在的等位基因。

::: example 两类基因座的杂合度 {#ex-mutdrift}
某物种的 $N_e = 10^4$。(a) 在一个中性突变率为每代 $10^{-5}$ 的蛋白质基因座上，期望的平衡杂合度是多少？(b) 在一个 $\mu = 5\times10^{-4}$ 的微卫星上，两个突变模型各给出多少？(c) 逼近平衡需要多久？
::: solution
(a) $\theta = 4\times10^4\times10^{-5} = 0.4$；$\hat H = 0.4/1.4 = 0.29$。

(b) $\theta = 20$。无限等位基因：$20/21 = 0.95$。逐步模型：$1 - 1/\sqrt{41} = 1 - 0.156 = 0.84$。微卫星比同一基因组中的蛋白质位点变异得多，因为其突变率高出五十倍，这正是廉价测序时代之前它们成为亲权鉴定与群体研究首选标记的原因。

(c) 由[[#eq-iam-rec]]，与平衡的偏差每代约按因子 $1 - 2\mu - 1/2N_e$ 缩小，因此时间尺度为 $1/(2\mu + 1/2N_e)$：对蛋白质基因座是 $1/(2\times10^{-5} + 5\times10^{-5}) \approx 14{,}000$ 代，对微卫星约为1,000代。到达平衡的时间尺度由漂变与突变中较快的一方决定——但对蛋白质基因座而言那仍是 $N_e$ 代的量级，而大小在那段时间内发生过改变的群体并不处于平衡。
:::
:::

### 一个样本中有多少个等位基因？

在无限等位基因模型下，Warren Ewens（1972）求出了一个 $n$ 个基因样本中等位基因数目及其频率的分布（**Ewens 抽样公式**）。它最常用的推论是期望的不同等位基因数目，

$$
\E[K] = \sum_{i=0}^{n-1}\frac{\theta}{\theta + i}.
$$ {#eq-ewens}

其逻辑是家谱式的：追溯样本的谱系，每个事件要么是一次并合、要么是一次突变，而按向前顺序第 $(i+1)$ 个基因以概率 $\theta/(\theta + i)$ 是一个新等位基因。当 $\theta = 2$、$n = 50$ 时，$\E[K] = 7.0$；样本量加倍只多出约1.4个等位基因。Ewens 还证明，给定 $K$ 时，等位基因的*频率*在中性下不再携带关于 $\theta$ 的信息——这是 Ewens–Watterson 检验的基础，它考察一个样本的频率相对于其等位基因数目是否过于均匀（提示平衡选择）或过于偏斜。

## 突变与选择：突变负荷

有害突变以它们产生的速率被选择去除，稳定在平衡 $\hat q \approx \mu/(hs)$，完全隐性时为 $\sqrt{\mu/s}$（[[evolution/mutation-drift-gene-flow]]）。它们让群体付出多少代价？

::: definition 遗传负荷 {#def-load}
一个群体的**遗传负荷**是其平均适合度相对于最适基因型的比例降低：$L = (w_\mathrm{max} - \bar w)/w_\mathrm{max}$。**突变负荷**是突变-选择平衡下反复产生的有害突变造成的负荷。
:::

::: proposition Haldane–Muller 原理 {#prop-load}
在单个基因座的突变-选择平衡上，突变以率 $\mu$ 产生适合度为 $1$、$1 - hs$、$1 - s$ 的有害等位基因，则突变负荷为

$$
L \approx 2\mu\quad(h \text{ 不接近 } 0),\qquad L \approx \mu\quad(h = 0),
$$ {#eq-load}

与 $s$ 无关。对许多基因座求和，设每个二倍体基因组每代有害突变总率为 $U$，并假定各基因座对适合度以乘法方式作用，则对部分显性突变，平均适合度约为 $e^{-U}$。
:::

::: proof
对 $h > 0$：$\bar w \approx 1 - 2pq\,hs \approx 1 - 2\hat q\,hs$（纯合子可忽略）。由 $\hat q = \mu/(hs)$，$L = 2\hat q\,hs = 2\mu$。对 $h = 0$：$\bar w = 1 - s\hat q^2$ 且 $\hat q^2 = \mu/s$，故 $L = \mu$。许多各带负荷 $2\mu_i$ 的基因座以乘法方式作用时，$\bar w \approx \prod_i(1 - 2\mu_i) \approx e^{-\sum 2\mu_i} = e^{-U}$，其中 $U = \sum_i 2\mu_i$ 是每个二倍体合子的新突变数。
:::

这一结果由 Haldane 于1937年导出，Hermann Muller 在1950年以“我们的突变负荷”为题对它做过讨论。它违反直觉：一个严重有害的突变并不比一个轻度有害的突变造成更大的负荷。严重的突变在平衡时更稀少，但每个拷贝造成的损害更大；两种效应相消，因为在平衡时，每一个新突变拷贝最终都必须造成一次“遗传死亡”（一个个体未能留下后代）才能被去除。轻度有害的突变持续更久、散布在更多个体中，可能也更难清除。对 $U$ 的估计并不确定；对果蝇属 *Drosophila* 和人类，一般认为其量级是每个合子一个或更多有害突变，那意味着可观的负荷。物种如何承受这一点——靠软选择、突变间的协同上位，还是有性重组——是进化遗传学的一个长期悬而未决的问题。

## 群体结构

### Wahlund 效应

多数物种并非单一随机交配的群体。设一个样本取自若干亚群体，每个亚群体各自符合哈迪-魏因贝格比例，但等位基因频率不同。合并后的样本将比由合并后的等位基因频率按哈迪-魏因贝格所预言的含有更少的杂合子。Sten Wahlund 于1928年描述了这一效应。

::: proposition Wahlund 效应 {#prop-wahlund}
设一个群体由权重为 $c_i$（$\sum c_i = 1$）、等位基因频率为 $p_i$ 的亚群体组成，每个亚群体各自符合哈迪-魏因贝格比例，并设 $\bar p = \sum c_ip_i$ 且 $\sigma_p^2 = \sum c_i(p_i - \bar p)^2$。则在合并群体中

$$
f(A_1A_1) = \bar p^2 + \sigma_p^2,\qquad f(A_1A_2) = 2\bar p\bar q - 2\sigma_p^2,\qquad f(A_2A_2) = \bar q^2 + \sigma_p^2.
$$ {#eq-wahlund}
:::

::: proof
$f(A_1A_1) = \sum c_ip_i^2 = \bar p^2 + \sigma_p^2$，因为 $p_i^2$ 的平均数等于平均数的平方加上方差。类似地 $f(A_2A_2) = \sum c_iq_i^2 = \bar q^2 + \sigma_p^2$（$q_i = 1 - p_i$ 的方差与 $p_i$ 的相同）。杂合子的频率是余下的部分，$1 - \bar p^2 - \bar q^2 - 2\sigma_p^2 = 2\bar p\bar q - 2\sigma_p^2$。
:::

杂合子的缺失为 $2\sigma_p^2$，因此用[[population-genetics/hardy-weinberg#def-fis]]的记号，合并样本的 $F = \sigma_p^2/(\bar p\bar q)$。这不是可以打发的伪象：它有真实的后果。若两个各有罕见隐性性状的隔离群体合并并随机交配，患病纯合子的频率将*下降*，从 $\bar q^2 + \sigma_p^2$ 降到 $\bar q^2$。

### F-统计量

苏厄尔·赖特（1951）把结构化群体对哈迪-魏因贝格比例的偏离分解为两部分：一部分源于亚群体内部的非随机交配，一部分源于亚群体之间的差异。

::: definition 赖特的 F-统计量 {#def-fstats}
在一个划分为亚群体的群体中，设 $H_I$ 为亚群体内个体的平均观测杂合度，$H_S$ 为亚群体内哈迪-魏因贝格期望杂合度的平均值（对 $2p_iq_i$ 取平均），$H_T = 2\bar p\bar q$ 为整个群体若随机交配时的期望杂合度。则

$$
F_\mathrm{IS} = 1 - \frac{H_I}{H_S},\qquad F_\mathrm{ST} = 1 - \frac{H_S}{H_T},\qquad F_\mathrm{IT} = 1 - \frac{H_I}{H_T},
$$ {#eq-fstats}

且它们满足

$$
1 - F_\mathrm{IT} = (1 - F_\mathrm{IS})(1 - F_\mathrm{ST}).
$$ {#eq-fprod}

$F_\mathrm{IS}$ 度量亚群体内部的非随机交配（近交、自交），$F_\mathrm{ST}$ 度量亚群体之间的分化，$F_\mathrm{IT}$ 度量整个群体中个体对随机交配的总体偏离。
:::

乘积法则[[#eq-fprod]]是显然的：$\frac{H_I}{H_T} = \frac{H_I}{H_S}\cdot\frac{H_S}{H_T}$。而由 Wahlund 的论证，对两个等位基因

$$
F_\mathrm{ST} = \frac{H_T - H_S}{H_T} = \frac{\sigma_p^2}{\bar p\bar q},
$$ {#eq-fst-var}

即亚群体间等位基因频率的方差，除以其最大可能值 $\bar p\bar q$（每个亚群体都固定时达到）。$F_\mathrm{ST}$ 的取值范围从0（频率完全相同）到1（每个亚群体各固定一个等位基因）。实践中，这些量在估计时要对所抽样的亚群体数和个体数有限这一事实加以校正；Bruce Weir 与 Clark Cockerham（1984）的估计量是标准做法。对复等位基因座，Nei 的 $G_\mathrm{ST}$ 是杂合度的类似比值；对高度多态的基因座，即使是完全隔离的群体它也接近不了1，因为 $H_S$ 本身就接近1——在比较不同研究时这是一个要紧的限制。

::: example 三个亚群体 {#ex-fstats}
某植物三个大小相等的亚群体中等位基因频率为0.2、0.5与0.8，观测杂合度为0.24、0.42与0.28。计算 $F_\mathrm{IS}$、$F_\mathrm{ST}$ 与 $F_\mathrm{IT}$，验证乘积法则，并作出解释。
::: solution
亚群体内的期望杂合度为 $2\times0.2\times0.8 = 0.32$、$0.50$ 与 $0.32$，故 $H_S = 0.38$。观测值：$H_I = (0.24 + 0.42 + 0.28)/3 = 0.3133$。合并：$\bar p = 0.5$，$H_T = 0.5$。于是

$$
F_\mathrm{IS} = 1 - \frac{0.3133}{0.38} = 0.175,\qquad F_\mathrm{ST} = 1 - \frac{0.38}{0.50} = 0.24,\qquad F_\mathrm{IT} = 1 - \frac{0.3133}{0.50} = 0.373.
$$

验证：$(1 - 0.175)(1 - 0.24) = 0.825\times0.76 = 0.627 = 1 - 0.373$。而由[[#eq-fst-var]]，$\sigma_p^2 = (0.09 + 0 + 0.09)/3 = 0.06$，且 $0.06/(0.5\times0.5) = 0.24$，恰如所应。

解释：亚群体内部有可观的近交（$F_\mathrm{IS} = 0.175$，相当于部分自交，[[population-genetics/inbreeding]]），亚群体之间有很强的分化（$F_\mathrm{ST} = 0.24$）；相对于单一随机交配群体，总的杂合子缺失为37 %。单个基因座的估计噪声很大；实际研究对许多基因座取平均，而 $F_\mathrm{ST}$ 异常的基因座是局部选择的候选。
:::
:::

## 迁移与漂变

### 平衡时的岛屿模型

赖特的**岛屿模型**考虑无限多个亚群体（“岛屿”），各有大小 $N$，每代有其基因的比例 $m$ 以自整个集合抽出的迁移个体的形式到来（因此整个集合的频率 $\bar p$ 保持恒定）。漂变使各岛屿分化；迁移把它们拉回一起。

::: proposition 迁移-漂变平衡 {#prop-island}
在中性等位基因、无突变的无限岛屿模型中，取自同一岛屿的两个基因血缘同源相同的概率 $F$ 满足

$$
F' = \left[\frac{1}{2N} + \left(1 - \frac{1}{2N}\right)F\right](1 - m)^2,
$$ {#eq-island-rec}

而在平衡时，对小的 $m$，

$$
\hat F_\mathrm{ST} \approx \frac{1}{1 + 4Nm}.
$$ {#eq-island}
:::

::: proof
下一代岛屿上的两个基因两者都源于本地的概率为 $(1 - m)^2$；若其中任何一个是迁入者，它来自无限集合、与另一个没有亲缘关系（相对总群体的同一概率为0）。在两者都源于本地的条件下，它们是同一父代基因拷贝的概率为 $1/2N$，否则以概率 $F$ 相同。这就得到[[#eq-island-rec]]，其形式与[[#eq-iam-rec]]相同，只是 $m$ 取代了 $\mu$：迁移与突变一样，引入了非血缘同源相同的基因。平衡如前所述。
:::

该递推把动力学挑明：$F_\mathrm{ST}$ 以每代约 $2m + 1/2N$ 的速率逼近平衡。迁移扮演的正是[[#prop-iam]]中突变扮演的角色，但它通常强得多：$m$ 常常在 $10^{-3}$ 以上，而每个基因座的 $\mu$ 不超过 $10^{-5}$。

::: example 每代一个迁移个体 {#ex-nm}
(a) 各有50个个体的岛屿每代通过迁移交换其基因的1 %。平衡 $F_\mathrm{ST}$ 是多少？100代之后接近到什么程度？(b) 一项对某物种的调查在中性标记上测得 $F_\mathrm{ST} = 0.05$。若岛屿模型适用，这意味着每代多少个迁移个体？
::: solution
(a) $4Nm = 2$，故 $\hat F_\mathrm{ST} \approx 1/3$。从0开始迭代[[#eq-island-rec]]给出精确平衡0.330：10代后 $F = 0.086$，50代后0.257，100代后0.314——已走完95 %的路程。逼近速率 $2m + 1/2N = 0.03$ 预言约33代的时间常数，与此一致。

(b) 解 $0.05 = 1/(1 + 4Nm)$：$Nm = (1/0.05 - 1)/4 = 4.75$ 个迁移个体每代。这类间接估计应当极其谨慎地对待（Michael Whitlock 与 David McCauley，1999）：它们假定平衡、各岛屿大小相等、迁移来自公共基因池、中性且没有突变，而这些在自然界都不怎么成立。$F_\mathrm{ST}$ 最好看作对分化的描述；由它导出的 $Nm$ 只是某个模型之下的“有效迁移个体数”。
:::
:::

x: 0, 10

caption: 岛屿模型的平衡 $F_\mathrm{ST}$ 对每代迁移个体数 $Nm$（[[#eq-island]]）的曲线。标记线 $Nm = 1$ 给出 $F_\mathrm{ST} = 0.2$。注意曲线在零附近有多陡：每代迁移个体从0.1增至1，$F_\mathrm{ST}$ 就从0.71降到0.2，而从1增至10只降到0.024。少量的基因流就能阻止群体固定不同的中性等位基因；再多则收效甚微。
:::

### 距离隔离

真实的迁移是局域的：相邻群体比相距遥远的群体交换更多迁移个体。在**台阶模型**（木村资生与 George Weiss，1964）中，一条直线或方格上的局部群体只与邻居交换迁移个体。于是两个局部群体之间的 $F_\mathrm{ST}$ 随二者之间的距离增大，这一格局称为**距离隔离**（赖特，1943）。在连续分布的群体中，赖特的**邻域大小** $N_b = 4\pi D\sigma^2$ 起着 $Nm$ 的作用，其中 $D$ 是个体密度，$\sigma^2$ 是亲子间沿一个轴的距离的方差。François Rousset（1997）证明，在二维情形，样本对之间 $F_\mathrm{ST}/(1 - F_\mathrm{ST})$ 应随两者距离的对数近似线性增大，斜率为 $1/(4\pi D\sigma^2)$——这一关系使得仅凭遗传数据就能估计扩散参数。

人类的遗传变异非常符合距离隔离。人类群体之间的遗传分化随地理距离逐渐增大，而杂合度沿古迁移的可能路线随与东非的距离减小，这与人类扩散到全世界时经历的一系列奠基者事件一致（Sohini Ramachandran 及同事，2005）。以其他哺乳动物的标准衡量，人类群体之间的分化很低：大陆群体之间 $F_\mathrm{ST}$ 的大多数估计为0.05–0.15的量级，而且大多数遗传变异存在于地方群体内部。无论是数据还是理论都不支持把人类划分为彼此分明的“种族”；变异用地理、祖先来源和群体来描述（[[genomics/human-variation]]）。

::: warning "F_ST 度量的是基因流的速率"
$F_\mathrm{ST}$ 是对等位基因频率目前差异的概括总结。它由迁移塑造，但也由漂变塑造——而漂变依赖于 $N_e$；由群体分开以来的时间塑造，因为平衡可能需要数千代；由高度多态基因座上的突变塑造；也由选择塑造。两个最近分开、此后没有基因流的群体可能有低的 $F_\mathrm{ST}$，而两个由可观基因流相连的群体若非常小，其值也可能很高。把 $F_\mathrm{ST}$ 换算成迁移率需要一个模型，而群体分开并分化的模型（例如用并合方法估计）常常比平衡岛屿模型拟合得更好。
:::

## 迁移与选择

基因流与局部适应相对抗。考虑一个岛屿，其上等位基因 $a$ 不利，针对它的选择系数为 $s$（为简单起见考虑单倍体），但每代有其基因的比例 $m$ 来自一个固定了 $a$ 的大陆。若 $m$ 相对于 $s$ 很小，岛上 $a$ 的频率将稳定在迁移带来的量与选择去除的量相抵之处：

$$
\hat q \approx \frac ms\qquad (m < s).
$$ {#eq-migsel}

若 $m$ 超过 $s$，迁移将**淹没**选择，$a$ 将占领全岛。同样的平衡在连续空间中产生一个**渐变群**，即跨越一条环境边界的等位基因频率梯度；J. B. S. Haldane（1948）与 Montgomery Slatkin（1973）证明，其宽度为 $\sigma/\sqrt s$ 的量级，其中 $\sigma$ 是每代扩散距离。因此狭窄的渐变群意味着相对于扩散能力的选择很强。

::: example 岛上的水蛇 {#ex-snakes}
在伊利湖西部的岛屿上，许多北部水蛇 *Nerodia sipedon* 是无横带的，这被认为使它们在石灰岩湖岸上不那么显眼，而在大陆上几乎全部都有横带；横带受单个基因座的部分控制（Richard King 与 Robert Lawson 在1990年代研究过）。(a) 若岛上的蛇受到每代 $s = 0.05$ 针对有横带等位基因的选择（按单倍体近似），且每代有岛上基因的1 %来自大陆，则有横带等位基因的平衡频率是多少？(b) 若迁移为每代10 %会怎样？
::: solution
(a) 由[[#eq-migsel]]，$\hat q \approx 0.01/0.05 = 0.2$。（迭代精确模型——先迁移、后单倍体选择——给出0.19。）选择使有横带等位基因保持稀少但无法将其消除，所以有横带的蛇在岛上得以存续——与观察相符。

(b) $m = 0.1 > s = 0.05$ 时，迁移淹没选择，有横带等位基因将升至高频，消除局部适应。无横带蛇的持续存在意味着岛上的选择相对于基因流是强的。对两者的野外估计都支持这一点。
:::
:::

::: application 保护生物学：基因流、拯救与远交
生境破碎化把一个群体变成许多小群体，每个都因漂变丢失变异并变得近交（[[conservation-biology/fragmentation]]）。岛屿模型表明，即便是温和的基因流——常被引用的经验法则是每代一个迁移个体，实际中应更多——也能阻止相互隔离的斑块固定不同的等位基因。有意转移个体可以恢复变异与适合度（“遗传拯救”），佛罗里达山狮即是如此（[[evolution/mutation-drift-gene-flow]]）。另一侧的风险是**远交衰退**：若迁入者带着适应其他条件的等位基因或不相容的基因组合；当群体只分开几百代且生活在相似环境中时，它通常很小（Richard Frankham 及同事，2011）。
:::

::: quiz
一位生物学家把取自五个隔离池塘的甲虫样本合并，发现在每个基因座上都有强烈的杂合子缺失，但在每个池塘内部，基因型符合哈迪-魏因贝格比例。哪种说法正确？
- [ ] 甲虫存在近交。
- [x] $F_\mathrm{IS} \approx 0$ 但 $F_\mathrm{ST} > 0$；缺失是合并了有分化的池塘造成的 Wahlund 效应。
- [ ] 选择必定在每个池塘中都对杂合子不利。
- [ ] 检验无效，因为这些池塘本应合在一起分析。
::: solution
每个池塘内部基因型符合哈迪-魏因贝格比例，所以不存在近交（$F_\mathrm{IS} \approx 0$）。合并造成的缺失源于各池塘等位基因频率不同：由[[#prop-wahlund]]，缺失为 $2\sigma_p^2$，它出现在每个基因座上，因为所有基因座共享同一群体结构。选择只会影响特定基因座，而不是全部。
:::
:::

::: history
群体结构由 Sten Wahlund 于1928年对合并样本的分析引入群体遗传学。苏厄尔·赖特发展了岛屿模型（1931）、距离隔离（1943）与 F-统计量（1951，“The genetical structure of populations”），其动力部分来自他的“shifting balance”理论，该理论认为细分的群体比未细分的群体更好地探索适应景观。Gustave Malécot 在1940年代的法国独立发展了同一概率方法。突变方面，Haldane（1935）由突变-选择平衡估计了人类的血友病突变率——这是第一个人类突变率——并提出了突变负荷的思想（1937），Muller 在1950年使它闻名。木村资生与 Crow 的无限等位基因模型（1964）、木村资生与 Weiss 的台阶模型（1964）、太田朋子与木村资生的逐步突变模型（1973）以及 Ewens 抽样公式（1972）完成了群体内部与群体之间变异的经典中性理论。
:::

::: summary
- 突变模型：无限等位基因、无限位点、逐步（微卫星）、有限等位基因或位点（[[#def-mutation-models]]）。
- 突变-漂变平衡：无限等位基因下 $\hat H \approx \theta/(1+\theta)$，逐步突变下 $1 - 1/\sqrt{1 + 2\theta}$，其中 $\theta = 4N_e\mu$（[[#prop-iam]]）。样本中等位基因的期望数目为 $\sum_{i=0}^{n-1}\theta/(\theta + i)$。
- 一个基因座的突变负荷约为 $2\mu$（完全隐性时为 $\mu$），与 $s$ 无关（Haldane–Muller，[[#prop-load]]）；整个基因组上 $\bar w \approx e^{-U}$。
- 合并有分化的亚群体造成 $2\sigma_p^2$ 的杂合子缺失（Wahlund，[[#prop-wahlund]]）。
- $F_\mathrm{IS}$、$F_\mathrm{ST}$ 与 $F_\mathrm{IT}$ 对非随机交配的偏离进行分解；$1 - F_\mathrm{IT} = (1 - F_\mathrm{IS})(1 - F_\mathrm{ST})$ 且 $F_\mathrm{ST} = \sigma_p^2/(\bar p\bar q)$（[[#def-fstats]]）。
- 岛屿模型中 $F_\mathrm{ST} \approx 1/(1 + 4Nm)$，以 $2m + 1/2N$ 的速率逼近；距离隔离使分化随距离增长。
- 迁移-选择平衡给出 $\hat q \approx m/s$；当 $m > s$ 时基因流淹没局部选择，渐变群宽度为 $\sigma/\sqrt s$ 的量级。
:::

## 习题

::: exercise 突变-漂变杂合度 {level=1 check="0.5"}
对一个遵循无限等位基因模型的基因座，$N_e = 5000$、$\mu = 5\times10^{-5}$。平衡杂合度是多少？
::: solution
$\theta = 4\times5000\times5\times10^{-5} = 1$，故 $\hat H = 1/2 = 0.5$。
:::
:::

::: exercise 由 F_ST 求迁移个体数 {level=1 check="1"}
在岛屿模型下，$F_\mathrm{ST} = 0.2$ 对应每代多少个迁移个体 $Nm$？
::: solution
$1 + 4Nm = 5$，故 $Nm = 1$。
:::
:::

::: exercise 乘积法则 {level=1 check="0.28"}
一个结构化群体中 $F_\mathrm{IS} = 0.1$、$F_\mathrm{ST} = 0.2$。$F_\mathrm{IT}$ 是多少？
::: solution
$1 - F_\mathrm{IT} = 0.9\times0.8 = 0.72$，故 $F_\mathrm{IT} = 0.28$。
:::
:::

::: exercise 由等位基因频率求 F_ST {level=2 check="0.16"}
两个大小相等的群体中某等位基因的频率为0.3与0.7。$F_\mathrm{ST}$ 是多少？
::: solution
$\bar p = 0.5$，$\sigma_p^2 = \tfrac12(0.04 + 0.04) = 0.04$，故 $F_\mathrm{ST} = 0.04/0.25 = 0.16$。等价地 $H_S = 2\times0.3\times0.7 = 0.42$，$H_T = 0.5$，$1 - 0.42/0.5 = 0.16$。
:::
:::

::: exercise 突变负荷 {level=2}
(a) 某基因座以每代 $2\times10^{-6}$ 的速率突变为部分显性有害等位基因。该基因座的突变负荷是多少？若该等位基因的纯合效应 $s$ 加倍，它如何改变？(b) 若一个基因组有20,000个这样的基因座、每个都有这一突变率，那么相对无突变基因型的平均适合度是多少？
::: solution
(a) $L \approx 2\mu = 4\times10^{-6}$，$s$ 加倍时不变：该等位基因频率减半，但每个拷贝的代价加倍。

(b) $U = 20{,}000\times2\times(2\times10^{-6}) = 0.08$ 个新突变每二倍体合子，故 $\bar w \approx e^{-0.08} = 0.92$，负荷为8 %。
:::
:::

::: exercise 计数等位基因 {level=2 check="7.04"}
用[[#eq-ewens]]求 $\theta = 2$ 时50个基因样本中等位基因的期望数目（保留两位小数）。
::: solution
$\E[K] = \sum_{i=0}^{49}2/(2 + i) = 2\left(\tfrac12 + \tfrac13 + \cdots + \tfrac{1}{51}\right) = 2(H_{51} - 1) = 2\times(4.5188 - 1) = 7.04$，其中 $H_{51} = \sum_{j=1}^{51}1/j$ 是调和数。
:::
:::

::: exercise 迁移对抗选择 {level=2}
一个在大陆上有利的等位基因在岛上有害，那里针对它 $s = 0.02$（单倍体近似）。该岛每代有其基因的0.5 %来自固定了该等位基因的大陆。(a) 预言它在岛上的平衡频率。(b) 多大的迁移率会淹没局部适应？
::: solution
(a) $\hat q \approx m/s = 0.005/0.02 = 0.25$。

(b) 超过约 $m = s = 0.02$（每代2 %）的迁移会淹没选择，该等位基因将在岛上趋于固定。
:::
:::

::: exercise 一项调查的解读 {level=3}
沿一条200 km 的河谷对某种蝾螈的八个群体采集了微卫星与 SNP 数据。由微卫星估计的成对 $F_\mathrm{ST}$ 对同样的群体对总是低于由 SNP 估计的值，且两者都随群体间河道距离稳定增大。(a) 为什么微卫星可能给出更低的 $F_\mathrm{ST}$？(b) 随距离的增大表明了什么？(c) 为什么用[[#eq-island]]把每个成对 $F_\mathrm{ST}$ 换算成迁移个体数是不明智的？
::: solution
(a) 微卫星因其高突变率而高度多态（$H_S$ 接近1），而基于杂合度比值的分化度量在群体内多样性高时无法接近1：粗略地有 $F_\mathrm{ST} \le 1 - H_S$。当 $\mu$ 相对 $m$ 不小，突变也进入同一性的计算。SNP 的 $H_S$ 低，不受这种限制。

(b) 距离隔离：基因流主要发生在相邻群体之间，所以遗传分化随距离积累，如台阶模型所预言。

(c) 岛屿模型假定迁移来自公共基因池而非邻居之间；假定平衡、大小相等、中性且突变可忽略。存在距离隔离时，合适的分析是把 $F_\mathrm{ST}/(1 - F_\mathrm{ST})$ 对距离回归（Rousset 方法），它估计的是邻域大小，而不是每对群体之间的迁移率。
:::
:::

::: exercise 合并两个群体 {level=3}
两个大小相等的隔离群体中某隐性等位基因的频率为 $q_1 = 0.02$ 与 $q_2 = 0.18$，各自符合哈迪-魏因贝格比例。(a) 在任何相互交配发生之前，两个群体合并中隐性纯合子的频率是多少？(b) 若它们合并为一个随机交配群体，它将变成多少？(c) 用 Wahlund 效应解释这一结果。
::: solution
(a) $\tfrac12(0.02^2 + 0.18^2) = \tfrac12(0.0004 + 0.0324) = 0.0164$。

(b) $\bar q = 0.10$，故随机交配后 $\bar q^2 = 0.0100$。

(c) 差 $0.0064$ 恰为 $\sigma_q^2 = \tfrac12(0.08^2 + 0.08^2) = 0.0064$，正如[[#eq-wahlund]]所预言。亚群体结构使纯合子频率高于具有相同等位基因频率的随机交配群体；合并群体消除了这一多余部分，于是隐性表型变得更少见，尽管没有任何等位基因频率发生改变。
:::
