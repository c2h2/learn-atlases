力是推或拉，是力学的第一个概念。本图谱中的一切——起重机吊臂中的应力、机翼上的升力、把卫星保持在轨道上的推力、一个螺栓必须承受的载荷——都是关于力的陈述，而每一个这样的陈述都始于同样的两个问题：**它有多大，指向哪个方向**。没有方向的数字不是力，没有数字的方向也不是力。

静力学研究不发生加速的物体。它不是随后的更令人兴奋的动力学的一个特例：它是力学中工程使用最多的部分，因为一座桥、一个建筑框架、一个压力容器的支座、一台机床床身、一架停在地面的飞机都被要求处于平衡，而且因为由平衡求出的力正是材料力学的强度章节和设计章节随后必须承受的载荷。本章建立这套记账法：力是什么、力如何相加、一个力如何分解为分量，以及一个多力力系如何用一个合力代替。

这里建立的矢量语言在 [[dynamics/newtons-laws]]、[[mechanics-of-materials/axial-loading]] 以及每一篇航空航天章节中原样使用，因此这笔投资只需付出一次，此后整部图谱都会用到它。

## 力、矢量与单位

::: definition 力 {#def-force}
**力**是一个物体对另一个物体的作用，它能够改变所作用的物体的运动状态，或使其变形。对刚体的外力学而言，一个力由四个要素完全描述：其**大小**、其**作用线**、其**指向**（沿该线的哪个方向）及其**作用点**。按传递方式，力分为两类：**接触力**，产生于物体接触之处（梁下的辊轴、钩上的缆索、壁面上的流体压强）；以及**体积力**或**超距力**，它在整个物体内作用而无须接触（重量、地球引力，更广泛地说还有静电力与磁力）。分布在面积上的接触力是**分布力**；当面积与物体相比很小时，理想化为作用在一点的**集中力**。
:::

力的大小是一个**标量**：一个带单位但没有方向的数字。温度、质量、时间、能量和体积都是标量。**矢量**既有大小**又有**方向，并服从下面的力的平行四边形法则。我们把矢量写成黑体——$\mathbf{F}$、$\mathbf{r}$、$\mathbf{v}$——其大小写成斜体——$F = \lvert \mathbf{F} \rvert$。两个矢量当大小相等、方向平行且指向相同时相等；因此矢量是一个**自由矢量**，只要保持大小和方向不变，可以在空间任意移动。力不是自由的：对刚体而言，沿其自身作用线滑移是允许的（这就是**力的可传性原理**，也正是力成为**滑移矢量**的原因），但把它移到作用线之外会改变它产生的力矩，是不允许的。

::: definition 力的单位与量纲 {#def-units}
在国际单位制中，力学使用的基本单位是米 $\mathrm{m}$（长度）、千克 $\mathrm{kg}$（质量）和秒 $\mathrm{s}$（时间）。力由牛顿（Newton）第二定律 $\mathbf{F} = m \mathbf{a}$ 导出：**牛顿**是使一千克质量获得一米每二次方秒加速度的力，
$$
1\ \mathrm{N} = 1\ \mathrm{kg \cdot m / s^{2}} .
$$
因此力的量纲为 $\mathsf{F} = \mathsf{M L T^{-2}}$。工程中常用的倍数单位是千牛 $1\ \mathrm{kN} = 10^{3}\ \mathrm{N}$、兆牛 $1\ \mathrm{MN} = 10^{6}\ \mathrm{N}$ 和毫牛。质量 $m$ 在地球表面的重量为 $W = m g$，其中 $g = 9.81\ \mathrm{m/s^{2}}$，所以 $100\ \mathrm{kg}$ 的质量重 $981\ \mathrm{N}$，即 $0.981\ \mathrm{kN}$。
:::

质量与重量的区别值得精确地说一次，因为它是起重和结构作业中真实事故的根源。质量是物体的属性，以千克度量，在月球上与在地球上相同。重量是引力作用在该质量上的力，以牛顿度量，在月球上约为地球值的 $1.62\ \mathrm{m/s^{2}} / 9.81\ \mathrm{m/s^{2}} \approx 17\%$。工作说明书中的“$500\ \mathrm{kg}$ 的载荷”是一个质量，其重量为 $4.90\ \mathrm{kN}$；而起重机械的额定值则是一个力。在美制单位中，力是磅力 $\mathrm{lbf}$，质量是斯勒格（slug），$1\ \mathrm{lbf} = 4.4482\ \mathrm{N}$；较早的英国文献使用吨力，$1\ \mathrm{tf} = 9.807\ \mathrm{kN}$。绝不在同一个计算中混用单位制。

::: warning 舍入与有效数字
工程数据只精确到两三位有效数字：名义 $10\ \mathrm{kN}$ 的载荷就是 $10\ \mathrm{kN}$，不是 $10.000\ \mathrm{kN}$。计算过程中保留四五位数字，把**答案**舍入到三位，这是本图谱和标准教材的约定。忽视这一点会产生两种错误。第一种是报告 $R = 871.7797887\ \mathrm{N}$ 这样的合力，而输入数据只支持 $872\ \mathrm{N}$，这诱使读者相信并不存在的数字。第二种是过早舍入：如果在三力问题中先把每个分量舍入到两位再求和，最终角度可能移动一度以上。把未舍入的数留在计算器里，只对你写下来的数舍入。
:::

## 力的合成：平行四边形法则

::: proposition 力的平行四边形加法法则 {#def-parallelogram}
作用于一点的两个力 $\mathbf{F}_1$ 与 $\mathbf{F}_2$ 合起来与单个力 $\mathbf{F}_R$ 等效，后者由以 $\mathbf{F}_1$ 与 $\mathbf{F}_2$ 为邻边的平行四边形的对角线表示。若 $\theta$ 为两力之间的夹角，
$$
F_R = \sqrt{F_1^{2} + F_2^{2} + 2 F_1 F_2 \cos\theta} ,
$$
合力与 $\mathbf{F}_1$ 的夹角 $\phi$ 由对力三角形应用正弦定理给出，
$$
\frac{F_1}{\sin\phi} = \frac{F_R}{\sin(180^\circ - \theta)} .
$$
相加次序无关紧要：$\mathbf{F}_1 + \mathbf{F}_2 = \mathbf{F}_2 + \mathbf{F}_1$。
:::

::: proof
把原点取在作用点，令 $\mathbf{F}_1$ 沿 $x$ 轴，写出 $\mathbf{F}_1 = (F_1, 0)$ 与 $\mathbf{F}_2 = (F_2 \cos\theta, F_2 \sin\theta)$。其矢量和为
$$
\mathbf{F}_R = (F_1 + F_2 \cos\theta,\; F_2 \sin\theta),
$$
于是
$$
F_R^{2} = F_1^{2} + 2 F_1 F_2 \cos\theta + F_2^{2}\cos^{2}\theta + F_2^{2} \sin^{2}\theta = F_1^{2} + F_2^{2} + 2 F_1 F_2 \cos\theta ,
$$
这正是两边为 $F_1$、$F_2$、夹角为 $180^\circ - \theta$ 的三角形的余弦定理——同一个三角形，其封闭边就是平行四边形的对角线。合力与 $x$ 轴夹角的正切为 $F_2 \sin\theta / (F_1 + F_2 \cos\theta)$，这就是正弦定理的表述。交换律是显然的，因为每个分量中标量加法可交换；而由于 $(\mathbf{F}_1 + \mathbf{F}_2) + \mathbf{F}_3$ 与 $\mathbf{F}_1 + (\mathbf{F}_2 + \mathbf{F}_3)$ 的分量相同，加法还满足结合律。因此整个平行四边形作图不过是写成几何形式的分量相加，这就是它能毫无困难地推广到任意多个力和三维空间的原因。
:::

这条法则是关于力的实验事实，不是一条几何定理；在它被写下来之前已经被验证了几个世纪：两个人成角度拉一根绳子，产生的拉力方向他们谁都没有朝那个方向拉，这就是原因。

::: example 螺栓上的两个力 {#ex-two-forces}
铸件凸耳上作用两个力：$F_1 = 400\ \mathrm{N}$ 与 $F_2 = 600\ \mathrm{N}$，其作用线夹角为 $60^\circ$。求合力及其相对于 $600\ \mathrm{N}$ 力的方向。
::: solution
由余弦定理，
$$
F_R = \sqrt{400^{2} + 600^{2} + 2 \times 400 \times 600 \times \cos 60^\circ}
     = \sqrt{160\,000 + 360\,000 + 240\,000} = \sqrt{760\,000} = 872\ \mathrm{N}.
$$
方向由力三角形求得：与 $600\ \mathrm{N}$ 边相对的角是 $180^\circ - 60^\circ = 120^\circ$，若 $\phi$ 是合力与 $600\ \mathrm{N}$ 力之间的夹角，则
$$
\sin\phi = \frac{400 \sin 120^\circ}{871.8} = 0.3971, \qquad \phi = 23.4^\circ .
$$
合力与 $400\ \mathrm{N}$ 力之间的夹角为 $36.6^\circ$，两角之和为 $60^\circ$，正如应当的那样。

**合理性检验。**合力位于两力之间，靠近较大的那个力，正如应当的那样。它小于代数和 $1000\ \mathrm{N}$，大于差 $200\ \mathrm{N}$，即 $\theta = 0$ 与 $\theta = 180^\circ$ 两个极限情形。而在 $\theta = 60^\circ$ 时，$872\ \mathrm{N}$ 接近垂直力情形的值 $\sqrt{400^2 + 600^2} = 721\ \mathrm{N}$ 但略大，因为 $60^\circ < 90^\circ$ 意味着两力互相帮忙更多。
:::
:::

::: quiz
两个大小均为 $300\ \mathrm{N}$ 的力作用于一点。两力夹角为多少时合力也是 $300\ \mathrm{N}$？
- [ ] $60^\circ$
- [x] $120^\circ$
- [ ] $90^\circ$
- [ ] $180^\circ$
::: solution
$F_R^{2} = 300^2 + 300^2 + 2 \times 300^2 \cos\theta = 300^2$ 要求 $2 + 2\cos\theta = 1$，所以 $\cos\theta = -1/2$，$\theta = 120^\circ$。两个相等的力互成 $120^\circ$，与它们的合力构成一个等边三角形——这个结果值得记住，因为它出现在三杆节点和对称三索起吊中。
:::
:::

## 力的分量

用平行四边形法则相加既优雅又缓慢。实用的方法是用沿选定坐标轴的两个或三个**分量**代替每个力，使矢量相加变成几个数字的求和。

::: definition 平面内的正交分量 {#def-components-2d}
设 $x$ 与 $y$ 为互相垂直的坐标轴，力 $\mathbf{F}$ 位于其平面内，其作用线与 $x$ 轴成角 $\theta$（逆时针度量）。其分量为
$$
F_x = F \cos\theta, \qquad F_y = F \sin\theta, \qquad \mathbf{F} = F_x \mathbf{i} + F_y \mathbf{j},
$$
反之 $F = \sqrt{F_x^{2} + F_y^{2}}$，$\theta = \arctan(F_y / F_x)$，$\theta$ 所在的象限由 $F_x$ 与 $F_y$ 的符号确定。分量是标量，可以为负；大小 $F$ 永远为正。
:::

角度必须从余弦分量所参照的那个轴量起，而且必须是**力与该轴之间的夹角**，不是图中为别的用途给出的角。当坡度写成“1 比 4”或斜率时，分量由三角形得出，而不是由斜率的反正切得出：沿斜率 $1:4$ 的直线作用的力 $F$，其水平分量为 $4F/\sqrt{17}$，竖直分量为 $F/\sqrt{17}$。

::: example 沿倾斜坐标轴分解 {#ex-inclined-axes}
一个 $500\ \mathrm{N}$ 的力与 $x$ 轴成 $60^\circ$。把它沿两个方向分解：$u$ 轴与 $x$ 轴成 $20^\circ$，$v$ 轴与 $x$ 轴成 $110^\circ$，并校核答案。
::: solution
这里两个坐标轴恰好垂直（$110^\circ - 20^\circ = 90^\circ$），所以分量为
$$
F_u = 500 \cos(60^\circ - 20^\circ) = 500 \cos 40^\circ = 383\ \mathrm{N}, \qquad
F_v = 500 \cos(60^\circ - 110^\circ) = 500 \cos 50^\circ = 321\ \mathrm{N}.
$$
在 $x$–$y$ 中重新合成以校核：
$$
F_x = 383 \cos 20^\circ + 321 \cos 110^\circ = 359.9 - 109.9 = 250\ \mathrm{N}, \qquad
F_y = 383 \sin 20^\circ + 321 \sin 110^\circ = 131.0 + 301.5 = 433\ \mathrm{N},
$$
而 $250^{2} + 433^{2} = 250\,000 \approx 500^{2}$，且 $\arctan(433/250) = 60^\circ$。原来的力被恢复出来。

若两轴不垂直，分量就不再是投影，不能用余弦求出。这时必须封闭力三角形：画 $\mathbf{F}$，从其箭头端画两条分别平行于两轴的直线；对所得三角形应用正弦定理即得两个分量。实际上，写出两个单位矢量 $\mathbf{u}$ 与 $\mathbf{v}$，解联立方程组
$$
F_x = F_u u_x + F_v v_x, \qquad F_y = F_u u_y + F_v v_y .
$$
当一根压杆和一根拉杆以斜角交于节点时，刚架分析做的就是这件事；这就是为什么“沿杆件分解并求解”总是安全的，而“乘以最接近的那个角的余弦”则不是。
:::
:::

::: definition 方向余弦与直线的单位矢量 {#def-direction-cosines}
在空间中，设力 $\mathbf{F}$ 与 $x$、$y$、$z$ 轴的夹角为 $\theta_x$、$\theta_y$、$\theta_z$。其**方向余弦**为
$$
l = \cos\theta_x, \qquad m = \cos\theta_y, \qquad n = \cos\theta_z, \qquad \mathbf{F} = F(l\, \mathbf{i} + m\, \mathbf{j} + n\, \mathbf{k}),
$$
且满足 $l^{2} + m^{2} + n^{2} = 1$。若作用线通过 $A(x_A, y_A, z_A)$ 与 $B(x_B, y_B, z_B)$，则从 $A$ 到 $B$ 的位置矢量为
$$
\mathbf{r}_{AB} = (x_B - x_A)\mathbf{i} + (y_B - y_A)\mathbf{j} + (z_B - z_A)\mathbf{k}, \qquad
r_{AB} = \lvert \mathbf{r}_{AB} \rvert ,
$$
沿它的**单位矢量**为 $\mathbf{u}_{AB} = \mathbf{r}_{AB} / r_{AB} = (l, m, n)$。因此从 $A$ 指向 $B$、大小为 $F$ 的力为
$$
\mathbf{F} = F\, \mathbf{u}_{AB} = F\, \frac{\mathbf{r}_{AB}}{r_{AB}} .
$$
:::

::: proof
矢量的三个分量是它在各轴上的正交投影，所以 $F_x = F \cos\theta_x$，如此等等，这就是第一个结论。矢量的大小是其分量平方和的平方根，所以 $F^{2} = F^{2}(l^{2} + m^{2} + n^{2})$，除以 $F^{2}$ 即得 $l^{2} + m^{2} + n^{2} = 1$。这个恒等式对每一道三维计算都是有用的校核：如果三个方向余弦的平方和不等于一，其中必有一个符号错了。它还表明三个角中只有两个是独立的——空间中的直线有两个自由度，不是三个。
:::

::: example 三维中桅杆拉索的力 {#ex-mast-stay}
一根竖直桅杆立在甲板上，顶部在 $B(0, 0, 6)\ \mathrm{m}$。一根拉索从 $B$ 连到甲板上的眼板 $C(2, -3, 0)\ \mathrm{m}$，张紧至 $840\ \mathrm{N}$。把拉索作用在桅杆顶部的力写成直角坐标矢量，并求其坐标方向角。
::: solution
拉力把桅杆顶拉向甲板眼板，所以相关矢量从 $B$ 指向 $C$：
$$
\mathbf{r}_{BC} = (2 - 0)\mathbf{i} + (-3 - 0)\mathbf{j} + (0 - 6)\mathbf{k}
               = 2 \mathbf{i} - 3 \mathbf{j} - 6 \mathbf{k}\ \mathrm{m},
$$
$$
r_{BC} = \sqrt{2^{2} + 3^{2} + 6^{2}} = \sqrt{49} = 7.00\ \mathrm{m}, \qquad
\mathbf{u}_{BC} = 0.2857 \mathbf{i} - 0.4286 \mathbf{j} - 0.8571 \mathbf{k}.
$$
于是
$$
\mathbf{F} = 840\, \mathbf{u}_{BC}
           = 240 \mathbf{i} - 360 \mathbf{j} - 720 \mathbf{k}\ \mathrm{N}.
$$
方向角由方向余弦得出：
$$
\theta_x = \arccos 0.2857 = 73.4^\circ, \quad
\theta_y = \arccos(-0.4286) = 115.4^\circ, \quad
\theta_z = \arccos(-0.8571) = 149.0^\circ .
$$

**合理性检验。**$0.2857^{2} + 0.4286^{2} + 0.8571^{2} = 0.0816 + 0.1837 + 0.7346 = 1.000$。$z$ 分量为负且最大，因为拉索陡峭地向下；$y$ 分量为负，因为眼板在 $-y$ 一侧；竖直分量 $720\ \mathrm{N}$ 是桅杆顶必须承受的向下拉力，占拉索张力的 $86\%$。图纸上看起来“几乎竖直”的拉索，其竖直载荷并不几乎等于张力，比值是 $6/7 = 0.857$，不是 $1$。
:::
:::

## 力系的合力

::: proposition 共点力系的合力 {#def-resultant}
作用于一点的力系 $\mathbf{F}_1, \mathbf{F}_2, \dots, \mathbf{F}_n$ 与单个力等效，称为**合力**
$$
\mathbf{F}_R = \sum_{i=1}^{n} \mathbf{F}_i
= \left(\sum_i F_{ix}\right) \mathbf{i}
+ \left(\sum_i F_{iy}\right) \mathbf{j}
+ \left(\sum_i F_{iz}\right) \mathbf{k}.
$$
对于各力**不**汇交于一点的力系，合力仍是这个矢量和，但其作用线不能仅由矢量和确定：一般力系简化为一个力和一个力偶，这是 [[statics/moments-couples]] 的主题。
:::

::: example 三个共面力的合力 {#ex-three-coplanar}
一块节点板上作用三个力：$500\ \mathrm{N}$ 沿 $30^\circ$、$700\ \mathrm{N}$ 沿 $130^\circ$、$600\ \mathrm{N}$ 沿 $250^\circ$，所有角度都从 $+x$ 轴逆时针度量。求合力。
::: solution
分解每个力，列成表格以免符号出错：

| 力 | $x$ 分量 $(\mathrm{N})$ | $y$ 分量 $(\mathrm{N})$ |
|---|---|---|
| $500\ \mathrm{N}$，$30^\circ$ | $500\cos 30^\circ = +433.0$ | $500\sin 30^\circ = +250.0$ |
| $700\ \mathrm{N}$，$130^\circ$ | $700\cos 130^\circ = -450.0$ | $700\sin 130^\circ = +536.2$ |
| $600\ \mathrm{N}$，$250^\circ$ | $600\cos 250^\circ = -205.2$ | $600\sin 250^\circ = -563.8$ |
| **求和** | $-222.2$ | $+222.4$ |

于是
$$
F_R = \sqrt{(-222.2)^{2} + (222.4)^{2}} = 314\ \mathrm{N}.
$$
参考角为 $\arctan(222.4 / 222.2) = 45.0^\circ$，但 $F_x < 0$ 且 $F_y > 0$ 把合力置于第二象限，所以
$$
\theta = 180^\circ - 45.0^\circ = 135.0^\circ .
$$

**合理性检验。**三个力的大致位置虽不精确、但近似对称地互隔 $120^\circ$，所以预期一个比其中任何一个都小得多的合力；相对于 $500$–$700\ \mathrm{N}$ 的力，$314\ \mathrm{N}$ 是合理的。如果答案接近 $1800\ \mathrm{N}$，首先该找的就是符号错误。
:::
:::

::: warning 大小不相加
本章最常见的错误是对不共线的力写 $F_R = F_1 + F_2$。正确的表述是 $\mathbf{F}_R = \mathbf{F}_1 + \mathbf{F}_2$，这是一个矢量方程，它意味着 $F_R \le F_1 + F_2$，仅当两力同向时取等号。相关的错误是把一个力各分量的大小相加并称其为该力：$F_x + F_y$ 不是 $F$，只有 $\sqrt{F_x^2 + F_y^2}$ 才是。有疑问时，把矢量首尾相接画出来；如果算术答案看起来不像草图，那么其中之一错了。
:::

::: example 使螺栓平衡的第四个力 {#ex-fourth-force}
一个螺栓上作用三个力：$\mathbf{F}_1 = 200 \mathbf{i}\ \mathrm{N}$、$\mathbf{F}_2 = 300 \mathbf{j}\ \mathrm{N}$ 与 $\mathbf{F}_3 = (-150 \mathbf{i} - 150 \mathbf{j})\ \mathrm{N}$。求使合力为零的第四个力。
::: solution
质点平衡要求 $\sum \mathbf{F} = \mathbf{0}$，所以
$$
\mathbf{F}_4 = -(\mathbf{F}_1 + \mathbf{F}_2 + \mathbf{F}_3)
= -\left[(200 - 150)\mathbf{i} + (300 - 150)\mathbf{j}\right]
= -50 \mathbf{i} - 150 \mathbf{j}\ \mathrm{N}.
$$
其大小与方向为
$$
F_4 = \sqrt{50^{2} + 150^{2}} = 158\ \mathrm{N}, \qquad
\theta = \arctan\frac{-150}{-50} = 71.6^\circ \text{ 在 } -x \text{ 轴下方},
$$
即从 $+x$ 逆时针度量 $\theta = 251.6^\circ$。

**合理性检验。**把四个力逐分量相加得 $200 - 150 - 50 = 0$ 与 $300 - 150 - 150 = 0$。第四个力指向第三象限，与前三个力的合力相反，这正是“把它们平衡掉”的含义。
:::
:::

## 投影：点积

::: definition 标量积与沿一条线的分量 {#def-dot}
两个矢量的**标量积**（点积）为
$$
\mathbf{A} \cdot \mathbf{B} = A_x B_x + A_y B_y + A_z B_z = A B \cos\theta ,
$$
其中 $\theta$ 是两矢量的夹角。它是一个标量，满足交换律，对垂直矢量为零。力 $\mathbf{F}$ 沿单位矢量为 $\mathbf{u}$ 的一条直线的分量是投影
$$
F_u = \mathbf{F} \cdot \mathbf{u},
$$
方向为 $\mathbf{u}_1$ 与 $\mathbf{u}_2$ 的两条直线的夹角为 $\theta = \arccos(\mathbf{u}_1 \cdot \mathbf{u}_2)$。
:::

投影是回答工程师真正会问的关于结构上的力的两个问题的工具：其中有多少**沿着**这根杆件拉，有多少**顶进**那个支座。只有沿杆分量在二力杆中做轴向的功；只有垂直分量会剪切一个螺栓或弯曲一根梁。

::: proof
令 $\mathbf{A}$ 沿 $x$ 轴，于是 $\mathbf{A} = (A, 0, 0)$，$\mathbf{A} \cdot \mathbf{B} = A B_x$。而 $B_x$ 是 $\mathbf{B}$ 在 $x$ 轴上的投影，即 $B \cos\theta$，其中 $\theta$ 是两矢量的夹角。因此在该特殊坐标系中 $\mathbf{A} \cdot \mathbf{B} = A B \cos\theta$。分量求和的定义与 $AB\cos\theta$ 在坐标轴旋转下都不变——前者因为它是两个矢量的缩并，代入旋转公式即可验证——所以在一种坐标系中相等意味着在所有坐标系中相等。令 $\mathbf{A} = \mathbf{B}$ 得 $A^{2} = A_x^{2} + A_y^{2} + A_z^{2}$，即求大小的勾股公式，这是同一不变性的一个特例。
:::

::: example 两根拉索之间的夹角与沿桅杆的载荷 {#ex-two-stays}
桅杆顶 $B(0, 0, 6)\ \mathrm{m}$ 用两根拉索系于甲板眼板 $C(2, -3, 0)\ \mathrm{m}$ 与 $D(0, 5, 0)\ \mathrm{m}$。求两拉索之间的夹角，以及若每根拉索张力为 $840\ \mathrm{N}$ 时桅杆顶部受到的总向下力。
::: solution
两个单位矢量，从桅杆顶指向甲板，为
$$
\mathbf{u}_{BC} = \frac{2 \mathbf{i} - 3 \mathbf{j} - 6 \mathbf{k}}{7}
               = 0.2857 \mathbf{i} - 0.4286 \mathbf{j} - 0.8571 \mathbf{k},
$$
$$
\mathbf{r}_{BD} = 0 \mathbf{i} + 5 \mathbf{j} - 6 \mathbf{k}\ \mathrm{m}, \qquad
r_{BD} = \sqrt{25 + 36} = 7.81\ \mathrm{m}, \qquad
\mathbf{u}_{BD} = 0 \mathbf{i} + 0.6402 \mathbf{j} - 0.7682 \mathbf{k}.
$$
它们的标量积为
$$
\mathbf{u}_{BC} \cdot \mathbf{u}_{BD}
= 0 - (0.4286)(0.6402) + (-0.8571)(-0.7682)
= -0.2744 + 0.6584 = 0.3840 ,
$$
所以两拉索之间的夹角为 $\theta = \arccos 0.3840 = 67.4^\circ$。

每根拉索的向下力是其张力在向下竖直方向 $-\mathbf{k}$ 上的投影：
$$
F_{z,BC} = 840 \times 0.8571 = 720\ \mathrm{N}, \qquad
F_{z,BD} = 840 \times 0.7682 = 645\ \mathrm{N},
$$
在任何顶部施转载荷之外，桅杆顶受到总共 $1365\ \mathrm{N}$ 的向下拉力。水平分量——$BC$ 给出 $+x$ 方向的 $240\ \mathrm{N}$，$BD$ 给出 $+y$ 方向的 $360\ \mathrm{N}$——并不抵消：桅杆顶承受 $\sqrt{240^2 + 360^2} = 433\ \mathrm{N}$ 的侧向载荷，需要第四根拉索或稳定索来平衡它。

**合理性检验。**两根拉索都比 $45^\circ$ 陡——它们的竖直落差 $6\ \mathrm{m}$ 超过水平投影 $\sqrt{13} = 3.6\ \mathrm{m}$ 和 $5\ \mathrm{m}$——所以每根的竖直拉力应大于水平拉力，$720 > 240$、$645 > 360$ 证实了这一点。两索夹角 $67.4^\circ$ 小于从平面图上可能猜到的 $90^\circ$，因为它们都向同一甲板高度向下倾斜。
:::
:::

::: history
力的合成长期以来只是作为规则被表述，而未被证明。力的平行四边形出现在达·芬奇（Leonardo da Vinci）1500年前后的一份手稿中，并印刷发表于斯台文（Stevin）1586年的《水重原理》（*De Beghinselen des Waterwichts*）与《静力学要素》（*Staticorum*），其中斜面上物体的平衡通过将重力分解为沿斜面与垂直斜面的分量来求解——这是静力学中第一次系统地使用分解。伐里农（Varignon）于1687年——牛顿（Newton）《原理》出版之年——发表了《新力学纲要》（*Projet d'une nouvelle méchanique*），并证明了至今以他名字命名的合力矩定理；牛顿本人在《原理》中的推论 I 就是平行四边形法则，表述为两个速度的合成。按伐里农自己的说法，他1687年的论文是在牛顿的书出版后几周内提交给法国科学院的；两人一起把静力学建立在矢量的基础上，比“矢量”一词由哈密顿（Hamilton）于1843年创造、$\mathbf{i}$、$\mathbf{j}$、$\mathbf{k}$ 记号由吉布斯（Gibbs）与赫维赛德（Heaviside）在1880年代固定下来早了一个半世纪。对工程师的实际后果是：十九世纪的图解静力学——按比例画在纸上的力多边形，兰肯（Rankine）、库尔曼（Culmann）与1860年代伟大的桥梁工程师们用它——可以被算术取代，然后在二十世纪被矩阵和计算机方法取代，本图谱中每一个刚架都用后者分析。
:::

## 后续内容

本章的矢量运算在 [[statics/particle-equilibrium]] 中原样使用，那里 $\sum \mathbf{F} = \mathbf{0}$ 成为工作工具；在 [[statics/moments-couples]] 中叉积又加入进来。同样的分量在 [[mechanics-of-materials/stress-transformation]] 中作为应力分量重新出现，在 [[dynamics/work-energy]] 中作为沿路径分解的力重新出现，在 [[aerodynamics/thin-airfoil-theory]] 中作为气动升力和阻力重新出现。这里用到的矢量代数——位置矢量、点积与叉积、空间直线的几何——在数学图谱中有详细展开（见[三维中的矢量](/learn/maths/lesson.php?c=multivariable)），牛顿定律背后的物理见[力学](/learn/physics/lesson.php?c=mechanics)。

::: summary
- 力有大小、作用线、指向和作用点；对刚体它是滑移矢量，把它移出作用线会改变问题。
- 力以牛顿度量，$1\ \mathrm{N} = 1\ \mathrm{kg \cdot m / s^{2}}$；重量是力 $W = mg$，不是质量。
- 力按平行四边形法则相加，那其实是改头换面的分量相加；大小不相加。
- 把力分解为正交分量时，角度从所参照的轴量起，并用 $F_x$ 与 $F_y$ 的符号校核答案所在的象限。
- 在空间中，沿 $AB$ 的力是 $F \mathbf{r}_{AB} / r_{AB}$，其方向余弦满足 $l^{2} + m^{2} + n^{2} = 1$。
- 汇交力系的合力是其各力的矢量和；投影 $\mathbf{F} \cdot \mathbf{u}$ 给出沿任一条选定直线的分量。
:::

## 习题

::: exercise 两个力的合力 {level=1 check="1044"}
$600\ \mathrm{N}$ 与 $800\ \mathrm{N}$ 两个力作用于一点，夹角为 $120^\circ$。求合力的大小。（力以 N 计。）
::: solution
$F_R = \sqrt{600^{2} + 800^{2} + 2 \times 600 \times 800 \times \cos 120^\circ}
     = \sqrt{360\,000 + 640\,000 - 480\,000} = \sqrt{520\,000} = 1044\ \mathrm{N}$。
两力之间的角是钝角，所以合力只比较大者略大——两力部分抵消。
:::
:::

::: exercise 重量与质量 {level=1 check="4.90"}
一台质量为 $500\ \mathrm{kg}$ 的机器由一根竖直缆索起吊。机器静止悬挂时缆索的张力是多少？（力以 kN 计。）
::: solution
静止时加速度为零，所以缆索张力等于重量：
$T = mg = 500 \times 9.81 = 4905\ \mathrm{N} = 4.90\ \mathrm{kN}$。
若机器以 $1.5\ \mathrm{m/s^{2}}$ 向上加速，张力变为 $m(g + a) = 500 \times 11.31 = 5.66\ \mathrm{kN}$，多了百分之十七——这就是为什么起升机械的额定起重量在加速起吊时要折减。
:::
:::

::: exercise 斜线上的分量 {level=1 check="779"}
一根张力为 $900\ \mathrm{N}$ 的拉索与它所系结的竖直杆成 $30^\circ$。求沿杆方向的分量。（力以 N 计。）
::: solution
拉索与杆之间的夹角为 $30^\circ$，所以沿杆的分量为
$$
F_\parallel = 900 \cos 30^\circ = 779\ \mathrm{N},
$$
而垂直于杆、使其弯曲的分量为 $900 \sin 30^\circ = 450\ \mathrm{N}$。拉索既压缩杆又弯曲杆，而控制弯曲应力的正是 $450\ \mathrm{N}$，尽管它是两个分量中较小的那个。
:::
:::

::: exercise 方向余弦 {level=2}
一个 $1200\ \mathrm{N}$ 的力沿从 $A(1, 2, 2)\ \mathrm{m}$ 到 $B(5, 6, -2)\ \mathrm{m}$ 的直线作用。求其分量与坐标方向角。
::: solution
$\mathbf{r}_{AB} = 4 \mathbf{i} + 4 \mathbf{j} - 4 \mathbf{k}\ \mathrm{m}$，$r_{AB} = \sqrt{3 \times 16} = 6.93\ \mathrm{m}$，所以 $\mathbf{u}_{AB} = 0.5774 \mathbf{i} + 0.5774 \mathbf{j} - 0.5774 \mathbf{k}$，且
$$
\mathbf{F} = 1200 \times 0.5774\, (\mathbf{i} + \mathbf{j} - \mathbf{k})
           = 693 \mathbf{i} + 693 \mathbf{j} - 693 \mathbf{k}\ \mathrm{N}.
$$
方向角为 $\theta_x = \theta_y = 54.7^\circ$，$\theta_z = 125.3^\circ$。三个方向余弦大小相等，因为该直线与三个坐标轴等倾，且 $3 \times 0.5774^{2} = 1.000$，符合要求。
:::
:::

::: exercise 空间中的合力 {level=2 check="5.74"}
三个力作用于一点：$\mathbf{F}_1 = (3 \mathbf{i} - 2 \mathbf{j} + 4 \mathbf{k})\ \mathrm{N}$、$\mathbf{F}_2 = (-\mathbf{i} + 5 \mathbf{j} - 2 \mathbf{k})\ \mathrm{N}$ 与 $\mathbf{F}_3 = (2 \mathbf{i} + \mathbf{j} - 3 \mathbf{k})\ \mathrm{N}$。求合力的大小。（力以 N 计。）
::: solution
$\mathbf{F}_R = (3 - 1 + 2)\mathbf{i} + (-2 + 5 + 1)\mathbf{j} + (4 - 2 - 3)\mathbf{k} = 4 \mathbf{i} + 4 \mathbf{j} - \mathbf{k}\ \mathrm{N}$，且
$$
F_R = \sqrt{4^{2} + 4^{2} + 1^{2}} = \sqrt{33} = 5.74\ \mathrm{N}.
$$
诱人的错误答案是三个大小之和，$\sqrt{29} + \sqrt{30} + \sqrt{14} = 5.39 + 5.48 + 3.74 = 14.6\ \mathrm{N}$；大小不相加。还要注意这里合力远小于任何一个单独的力，因为三者部分抵消。
:::
:::

::: exercise 两根缆索之间的夹角 {level=2 check="51.3"}
两根缆索从同一点沿 $(4, -3, -6)$ 与 $(0, 5, -12)$ 方向离开，单位为米。求它们之间的夹角。（角度以度计。）
::: solution
两个方向的长度都恰好方便，$r_1 = \sqrt{16 + 9 + 36} = 7\ \mathrm{m}$，$r_2 = \sqrt{25 + 144} = 13\ \mathrm{m}$。于是
$$
\cos\theta = \frac{4 \times 0 + (-3)(5) + (-6)(-12)}{7 \times 13}
           = \frac{-15 + 72}{91} = \frac{57}{91} = 0.6264, \qquad
\theta = 51.2^\circ .
$$
注意求夹角时无需分别把两个矢量单位化，只要把两个长度都除出来即可；漏除一个长度是常见的疏忽。
:::
:::

::: exercise 设计：三索起吊 {level=3}
一台重 $18\ \mathrm{kN}$ 的机器由三根缆索起吊，缆索系于其上方的同一个吊环。在图纸平面内，三根缆索从吊环沿 $90^\circ$（竖直）、$200^\circ$ 与 $320^\circ$ 离开，角度从 $+x$ 轴逆时针度量。确定每根缆索的张力。这种布置合理吗？
::: solution
设张力为 $T_1$（竖直，沿 $90^\circ$）、$T_2$（沿 $200^\circ$）与 $T_3$（沿 $320^\circ$）。吊环的平衡给出
$$
\textstyle \sum F_x = T_2 \cos 200^\circ + T_3 \cos 320^\circ = -0.9397 T_2 + 0.7660 T_3 = 0 ,
$$
$$
\textstyle \sum F_y = T_1 + T_2 \sin 200^\circ + T_3 \sin 320^\circ - 18
= T_1 - 0.3420 T_2 - 0.6428 T_3 - 18 = 0 .
$$
第一个方程给出 $T_2 = 0.8152\, T_3$。代入第二个，
$$
T_1 = 18 + 0.3420 \times 0.8152\, T_3 + 0.6428\, T_3 = 18 + 0.9216\, T_3 .
$$
两个方程三个未知数，所以系统是**超静定的**：张力取决于各缆索的伸长，无法仅由静力求出。若两根斜索松弛（$T_2 = T_3 = 0$），竖直缆索承受全部 $18\ \mathrm{kN}$；若两者都张紧以分担载荷，比如 $T_3 = 8\ \mathrm{kN}$，则 $T_2 = 6.52\ \mathrm{kN}$，$T_1 = 25.4\ \mathrm{kN}$——竖直缆索承受的**多于**重量，因为另外两根向下拉吊环。

这就是设计教训。$200^\circ$ 与 $320^\circ$ 的两根缆索都位于水平面**以下**，所以它们只能把吊环往下拉，竖直缆索必须承受重量加上它们的向下分量。合理的三索起吊把三根缆索都放在吊环上方，在平面内互隔 $120^\circ$ 对称布置，每根与竖直方向成相同的角 $\beta$，于是由对称性每根承受 $W / (3 \cos\beta)$，水平分量互相抵消。取 $\beta = 30^\circ$，每根张力为 $18/(3 \times 0.866) = 6.93\ \mathrm{kN}$，吊钩上的载荷就是完整的 $18\ \mathrm{kN}$，不会更多。
:::

::: exercise 推导 {level=3}
证明：若一个力 $\mathbf{F}$ 分解为沿两条夹角为 $\theta$（不是 $90^\circ$）的坐标轴的分量，则沿第一条轴的分量大小为
$$
F_u = \frac{F \sin(\theta - \alpha)}{\sin \theta}
$$
其中 $\alpha$ 是从第一条轴到力的角。证明当 $\theta = 90^\circ$ 时该式化为 $F \cos\alpha$，并讨论 $\theta \to 0$ 时发生什么。
::: solution
封闭力三角形：$\mathbf{F} = F_u \mathbf{u} + F_v \mathbf{v}$，其中 $\mathbf{u}$ 与 $\mathbf{v}$ 是沿两轴的单位矢量。从原点沿第一条轴画 $F_u \mathbf{u}$，再从它的箭头端画 $F_v \mathbf{v}$ 到 $\mathbf{F}$ 的箭头端。这个三角形的三个内角是：原点处为 $\alpha$（第一条轴与 $\mathbf{F}$ 之间）；$\mathbf{F}$ 的箭头端处为 $\theta - \alpha$（$\mathbf{F}$ 与第二条轴方向之间的角，因为第二条轴与第一条轴成 $\theta$）；余下的顶点处为 $180^\circ - \theta$。正弦定理给出
$$
\frac{F_u}{\sin(\theta - \alpha)} = \frac{F}{\sin(180^\circ - \theta)} = \frac{F}{\sin\theta},
$$
即所求结果。

当 $\theta = 90^\circ$ 时化为 $F_u = F \sin(90^\circ - \alpha) = F \cos\alpha$，正是正交公式，正如应当。当 $\theta \to 0$ 时两轴趋于平行，$\sin\theta \to 0$，除非 $\alpha \to 0$，否则 $F_u \to \infty$。这种发散不是一个奇趣，而是一个警告：两根几乎平行的杆件交于一个节点，它们合起来无法抵抗一个具有垂直于它们的分量的力，它们承受的力会变得极其巨大。这就是为什么支撑结构绝不会用两根几乎共线的杆件代替第三个方向来布置，也是为什么[[#ex-two-forces]]中 $\theta = 180^\circ$ 附近的平坦曲线与这里看到的发散是同一现象的两面。
:::
