桁架是一种奢侈：每根杆件都是二力杆，每个节点都是销钉，一切都能靠计数求解。真实结构却不肯配合。自行车车架的管材在节点之间会弯曲。一台反铲挖掘机有八根连杆、三个液压缸和一个铲斗，而它能挖出的载荷由杠杆决定，不由钢材的强度决定。一把剪刀施加两牛顿的手指力就能切开纸。这些全是**刚架**与**机器**，而它们的分析方法与上一章桁架的完全相同，只多了一个改变一切的补充：截断一根杆件时，截面上既承受力**又**承受力矩。

**刚架**是销接或刚接的装配体，至少含有一根在三个或更多点受力的杆件，因而那根杆件会弯曲。**机器**是设计来传递并改变力、且约束恰好允许运动的刚架。两者的分析都是拆开：为每根杆件画受力图，暴露出销钉力与截面力矩，然后求解。方程数目增长很快，这套方法的纪律性全在记账上。

::: warning 牛顿第三定律就是整套方法
拆开刚架时，杆件 1 在销钉处作用于杆件 2 的力出现在杆件 2 的图上，而等值反向的力出现在杆件 1 的图上。一张图按**相同**的假定指向画、另一张图把它反过来画，并把分量标注清楚以免忘记。刚架分析中最常见的失败不是方程写错，而是同一个销钉力在两根杆件上画成了同一方向，这使得装配起来的系统不平衡，得出的答案恰好差两倍销钉力。如果整体校核不通过，先查这里。
:::

## 刚架：会弯曲的杆件

::: definition 刚架、机器与多力杆 {#def-frame}
**多力杆**指受力作用点有三个或更多（包括支座力与销钉力）的杆件，因此它不可能是二力杆，必须同时承受剪力、弯矩和轴力。**刚架**是刚性杆件的连接装配体，其中至少一根是多力杆，并保持固定的构形。**机器**是至少有一个自由度的刚架，设计用来把力或运动从输入传到输出。对 $n$ 根杆件的平面装配体，每根给出三个平衡方程，独立约束分量数为 $c$，则
$$
\text{静定} \iff 3 n = c, \qquad
\text{机构} \iff 3 n > c, \qquad
\text{超静定} \iff 3 n < c .
$$
:::

::: proposition 刚架的计数 {#prop-frame-counting}
连接 $k$ 根杆件的一个销钉传递两个力分量，而不是 $2 k$ 个；单根杆件内部的铰是力矩释放，增加一个条件；刚节点传递两个力和一个力矩，平面内四个分量。两杆之间的辊轴或滑块贡献一个；两杆之间的固定连接贡献三个。把所有支座和所有连接的约束分量加起来得 $c$，与 $3 n$ 比较。
:::

::: proof
每根隔离的杆件是平面内的刚体，因此带有三个独立的标量平衡方程，$n$ 根杆件给出 $3 n$ 个方程。每个约束消除一个相对运动并引入一个未知力分量，所以未知数共 $c$ 个。相等意味着方程唯一确定未知数，前提是约束矩阵满秩；约束多于方程会留下自相平衡（多余）的力；少于方程则留下带自由运动的机构。销钉规则成立，是因为无摩擦销钉不能传递力矩，其内力是一个单一的矢量：无论汇交多少根杆件，销钉都在一侧杆件组与另一侧杆件组之间交换一个力，总共两个分量。因此连接三根杆件的销钉在杆 1 与杆 2 之间引入两个未知数、在这一对与杆 3 之间再引入两个——共四个，不是六个——这正是幼稚计数出错的地方。
:::

::: algorithm 刚架的分析 {#alg-frame}
1. **计数。**计算 $3 n$ 与 $c$。若 $3 n > c$ 装配体会运动；若 $3 n < c$ 它超静定，本方法无法完成。
2. **寻找二力杆。**任何只在两个销钉处受载的杆件——无中间载荷、无外加力偶、重量可忽略——无论形状如何都沿两销连线传力。把它换成这一个未知大小，计数中每根这样的杆件就少一个未知数。
3. **取整体装配体**，从外部约束力求出能求的部分。
4. **拆开。**为每根杆件画受力图。在每个销钉处，一根杆件上画 $B_x$、$B_y$，另一根上画 $- B_x$、$- B_y$，两张图上都明确画出指向。
5. **逐杆求解**，从未知数最少的杆件开始。在未知作用线相交处取矩。
6. **校核**，用尚未使用的方程验证某根杆件或整个装配体的平衡。
:::

::: example L 形刚架 {#ex-lframe}
刚性 L 形杆件 $ABC$ 在 $B$ 处折弯：$A(0, 0)$、$B(4, 0)$、$C(4, 3)$，尺寸均以米计。它在 $A$ 处铰接，在 $C$ 处带水平辊轴（只约束水平运动）。$AB$ 中点作用竖直向下载荷 $20\ \mathrm{kN}$，$C$ 处作用 $+ x$ 方向水平载荷 $10\ \mathrm{kN}$。求约束力。
::: solution
三个约束力分量——销钉处的 $A_x$、$A_y$ 和辊轴处的 $C_x$——对三个方程，所以刚架静定。整体杆件就是分离体；没有东西可以拆。

对 $A$ 取矩，每个力用 $M_O = x F_y - y F_x$：
$$
\textstyle \sum M_A = \big[2 \times (-20) - 0\big] + \big[4 \times 0 - 3 \times C_x\big] + \big[4 \times 0 - 3 \times 10\big] = 0
$$
$$
-40 - 3 C_x - 30 = 0 \quad\Longrightarrow\quad C_x = -23.33\ \mathrm{kN},
$$
所以辊轴以 $23.33\ \mathrm{kN}$ 往回拉。于是
$$
\textstyle \sum F_x = A_x + C_x + 10 = A_x - 23.33 + 10 = 0 \quad\Longrightarrow\quad A_x = 13.33\ \mathrm{kN},
$$
$$
\textstyle \sum F_y = A_y - 20 = 0 \quad\Longrightarrow\quad A_y = 20.0\ \mathrm{kN}.
$$
销钉约束力大小 $\sqrt{13.33^{2} + 20.0^{2}} = 24.1\ \mathrm{kN}$。

**校核**，对 $C(4, 3)$ 取矩：
$$
\textstyle \sum M_C = \big[(0 - 4) \times 20 - (0 - 3) \times 13.33\big] + \big[(2 - 4)(-20) - (0 - 3) \times 0\big] + \big[(4 - 4) \times 0 - (3 - 3) \times 10\big]
$$
$$
= (-80 + 40) + 40 + 0 = 0 . \checkmark
$$
**合理性检验。**$C$ 处的 $10\ \mathrm{kN}$ 与跨中的 $20\ \mathrm{kN}$ 都使杆件绕 $A$ 顺时针转动，$C$ 处辊轴必须抵住它们；$C_x$ 的符号说明它沿 $- x$ 拉，正是几何所要求的。销钉承担辊轴未承担的全部水平载荷和全部竖直载荷，所以它是第一个要设计的部件。
:::
:::

::: example 含二力杆的两杆刚架 {#ex-twomember}
杆件 $AB$ 与 $BC$ 在 $B$ 销接。$A(0, 0)$ 是铰，$C(7, 4)\ \mathrm{m}$ 是铰，$B(3, 4)\ \mathrm{m}$。$AB$ 中点作用竖直载荷 $15\ \mathrm{kN}$。求约束力和 $B$ 处的销钉力。
::: solution
**计数。**两根杆件，$3 n = 6$ 个方程。支座处两个铰给 4 个分量，$B$ 处销钉给 2 个，所以 $c = 6$。静定。

**找出二力杆。**杆件 $BC$ 只在 $B$、$C$ 两点受载，所以其力沿 $BC$，而 $BC$ 是水平的。这一个观察把 $C$ 处的两个未知数换成一个，并立即给出 $C_y = 0$。

**杆件 $BC$。**两端各受沿 $BC$ 的力 $b$。

**杆件 $AB$。**受力：$(0, 0)$ 处的 $\mathbf{A} = (A_x, A_y)$，$(1.5, 2)$ 处的载荷 $(0, -15)$，以及来自 $BC$ 的力——若 $b$ 为 $BC$ 的拉力，则该力在 $B(3, 4)$ 处为 $(-b, 0)$。对 $A$ 取矩：
$(-b, 0)$ 作用于 $(3, 4)$ 的矩为 $x F_y - y F_x = 3 \times 0 - 4 \times (-b) = 4 b$，载荷的矩为 $1.5 \times (-15) = -22.5$。于是
$$
\textstyle \sum M_A = -22.5 + 4 b = 0 \quad\Longrightarrow\quad b = 5.625\ \mathrm{kN}.
$$
于是
$$
\textstyle \sum F_x = A_x - b = 0 \quad\Longrightarrow\quad A_x = 5.625\ \mathrm{kN}, \qquad
\sum F_y = A_y - 15 = 0 \quad\Longrightarrow\quad A_y = 15.0\ \mathrm{kN}.
$$
$A$ 处约束力为 $\sqrt{5.625^{2} + 15.0^{2}} = 16.0\ \mathrm{kN}$，$C$ 处约束力为水平 $5.625\ \mathrm{kN}$，$B$ 处销钉传递 $5.625\ \mathrm{kN}$。

**校核。**杆件 $BC$ 两端承受等值反向的 $5.625\ \mathrm{kN}$ 轴力而别无其他，所以它受压 $5.625\ \mathrm{kN}$，其三个方程全部满足。杆件 $AB$ 在 $A$ 处承受 $16.0\ \mathrm{kN}$、在 $B$ 处承受 $5.625\ \mathrm{kN}$、在中点承受 $15\ \mathrm{kN}$：它是一根**梁**，它会弯曲。其最大弯矩在载荷作用点，由水平分量得 $M = 5.625 \times 2 = 11.25\ \mathrm{kN\,m}$，再加上竖直分量的弯曲——这是一根桁架分析会完全漏掉的杆件。
:::
:::

::: example 带拱顶铰的门式刚架 {#ex-portal}
门式刚架在 $A(0, 0)$ 与 $C(6, 0)$ 处铰接，在 $B(0, 4)$ 与 $D(6, 4)$ 处刚接，在梁的中点 $E(3, 4)$ 设内部铰。$B$ 处作用水平载荷 $10\ \mathrm{kN}$，梁上 $x = 4\ \mathrm{m}$ 处作用竖直载荷 $40\ \mathrm{kN}$。求约束力。
::: solution
**计数。**三根杆件（两根柱、一根梁），$3 n = 9$ 个方程；支座给 4 个分量，两个刚节点各给 4 个，铰给 2 个，合计 $c = 4 + 4 + 4 + 2 = 14$。按这个计数是五次超静定——但这个计数错了，因为两根柱在端部连接之间不受载荷，因此是二力杆。把每根柱当作一个单一未知数，$c$ 各减 3，得 $c = 8$ 对 $3 n = 9$……干净的办法是把刚架看成由一个铰连接的刚性 L 形两半，给出 $3 \times 2 = 6$ 个方程与 $c = 2 + 2 + 2 = 6$：静定。

**整体。**
$$
\textstyle \sum M_A = 6 C_y - 4 \times 40 - 4 \times 10 = 0
\quad\Longrightarrow\quad
C_y = \frac{200}{6} = 33.33\ \mathrm{kN}, \qquad A_y = 6.67\ \mathrm{kN}.
$$
**右半，对铰 $E(3, 4)$ 取矩。**右半在 $(6, 0)$ 承受 $C = (C_x, 33.33)$，在 $(4, 4)$ 承受 $40\ \mathrm{kN}$ 载荷：
$$
\textstyle \sum M_E^{\text{右}} = \big[3 \times 33.33 - (-4) C_x\big] + \big[1 \times (-40)\big] = 100 + 4 C_x - 40 = 0
\quad\Longrightarrow\quad
C_x = -15.0\ \mathrm{kN}.
$$
**水平平衡。**
$$
\textstyle \sum F_x = A_x + C_x + 10 = A_x - 15 + 10 = 0 \quad\Longrightarrow\quad A_x = 5.0\ \mathrm{kN}.
$$
**对左半校核**，对 $E$ 取矩：$(0, 0)$ 处的约束力 $(5.0, 6.67)$ 给出 $(-3)(6.67) - (-4)(5.0) = -20.0 + 20.0 = 0$，而 $B(0, 4)$ 处的 $10\ \mathrm{kN}$ 沿过 $E$ 标高的水平线作用，所以它对 $E$ 之矩为零。总和 $0$。$\checkmark$

**合理性检验。**水平推力在 $C$ 处为 $15\ \mathrm{kN}$、在 $A$ 处为 $5\ \mathrm{kN}$，不相等是因为 $10\ \mathrm{kN}$ 的水平载荷从 $A$ 一侧进入。去掉那个载荷，两个推力就等值反向——即上一章三铰拱的纯推力。
:::

## 机器：机械效益

::: definition 机器、机械效益与效率 {#def-machine}
机器把输入力（**驱动力** $P$）传递为输出力（**载荷** $Q$）。其**机械效益**（力比）为
$$
\mathrm{MA} = \frac{Q}{P} .
$$
其**速度比**（或位移比）是驱动力作用点移动距离与载荷移动距离之比，$\mathrm{VR} = v_{\text{in}} / v_{\text{out}}$。对无摩擦、无储能储存的理想机器，虚功给出 $P v_{\text{in}} = Q v_{\text{out}}$，所以
$$
\mathrm{MA}_{\text{ideal}} = \mathrm{VR}, \qquad
\eta = \frac{\mathrm{MA}}{\mathrm{VR}} \le 1 .
$$
:::

::: proposition 由几何求理想机械效益 {#prop-virtual}
任何连杆机构的理想机械效益等于驱动力作用点速度与载荷作用点速度之比，该比值可由虚功方程或约束方程求导得到。对力臂为 $a$ 与 $b$ 的杠杆，$\mathrm{MA} = a / b$；对有 $n$ 段绳索承担载荷的简单滑轮组，$\mathrm{MA} = n$；对如例 6 那样半角为 $\theta$ 的肘节，$\mathrm{MA} = 1 / (2 \tan \theta)$。
:::

::: proof
给机器一个与其约束相容的虚位移。因为它是理想的——无摩擦，动能与应变能无变化——总虚功为零：
$$
P\, \delta_{\text{in}} - Q\, \delta_{\text{out}} = 0
\quad\Longrightarrow\quad
\frac{Q}{P} = \frac{\delta_{\text{in}}}{\delta_{\text{out}}} = \mathrm{VR}.
$$
对绕一点转动的杠杆，两力臂扫过角度 $\delta \phi$，其端点移动 $a\, \delta \phi$ 与 $b\, \delta \phi$，得 $\mathrm{MA} = a / b$。对滑轮组，若载荷上升 $\delta$，则 $n$ 段绳索各缩短 $\delta$，所以驱动力端放出 $n \delta$ 的绳索：$\mathrm{MA} = n$。对肘节，载荷作用点水平移动 $x = 2 a \cos \theta$，驱动力作用点竖直移动 $y = a \sin \theta$，所以 $\mathrm{d}y / \mathrm{d}x = - \tan \theta$，$\mathrm{MA} = \delta_{\text{in}} / \delta_{\text{out}} = 1 / (2 \tan \theta)$——当 $\theta \to 0$ 时无界增长。这就是肘节能以任何手都产生不了的力夹紧的原因，也是它变得自锁的原因：超过某个角度后摩擦角超过机构角，任何载荷都无法把它顶回去。
:::

::: example 断线钳 {#ex-cutters}
一把断线钳手柄长 $400\ \mathrm{mm}$，钳口自销钉量起长 $50\ \mathrm{mm}$。每个手柄施加 $250\ \mathrm{N}$ 的握力。求螺栓所受的力和销钉中的力。
::: solution
取一个手柄为分离体。它是以销钉为支点的杠杆，在 $400\ \mathrm{mm}$ 处受 $250\ \mathrm{N}$ 握力，在 $50\ \mathrm{mm}$ 处受钳口反力 $J$：
$$
\textstyle \sum M_{\text{销}} = 250 \times 400 - J \times 50 = 0
\quad\Longrightarrow\quad
J = \frac{100\,000}{50} = 2000\ \mathrm{N}.
$$
螺栓被两个钳口夹住，各推 $2000\ \mathrm{N}$，所以螺栓受压 $2000\ \mathrm{N}$，断线钳的两个臂各通过销钉传递 $2000\ \mathrm{N}$。机械效益为 $2000 / 250 = 8.0$，等于力臂之比 $400 / 50 = 8.0$，正如虚功论证所要求。

**销钉校核。**每个手柄在钳口处施加 $2000\ \mathrm{N}$、在握把处接受 $250\ \mathrm{N}$，所以销钉必须以约 $2000 - 250 = 1750\ \mathrm{N}$ 的剪力补上差额；销钉处于**双剪**，每个剪切面承担 $1750 / 2 = 875\ \mathrm{N}$。直径 $6\ \mathrm{mm}$ 的销钉每个剪切面面积 $28.3\ \mathrm{mm^{2}}$，剪应力 $30.9\ \mathrm{MPa}$，对淬硬钢来说很宽裕。

**合理性检验。**直径 $6\ \mathrm{mm}$ 的硬钢螺栓在双剪下约以 $\pi \times 6^{2} / 4 \times 400 / 2 = 22.6\ \mathrm{kN}$ 被剪断，所以钳口处 $2\ \mathrm{kN}$ 远不足以剪断它——这就是断线钳手柄做成 $600$ 到 $1200\ \mathrm{mm}$ 的原因，也是同样 $50\ \mathrm{mm}$ 钳口的 $900\ \mathrm{mm}$ 工具给出 $\mathrm{MA} = 18$、$4.5\ \mathrm{kN}$ 的原因。
:::
:::

::: example 肘节压力机 {#ex-toggle}
肘节压力机有两根等长 $a$ 的连杆，在公共端 $B$ 销接，外端 $A$、$C$ 铰接于约束在水平线上的辊轴。竖直驱动力 $P = 500\ \mathrm{N}$ 作用于 $B$，$C$ 顶压工件。当连杆与水平的夹角（半角）$\theta$ 为 $10^{\circ}$ 时求输出力，再求 $2^{\circ}$ 时的值。
::: solution
两根连杆都是二力杆。在节点 $B$，两杆与水平各成 $\theta$ 角且都受压 $F$：
$$
\textstyle \sum F_x = F_{BC} \cos \theta - F_{BA} \cos \theta = 0 \quad\Longrightarrow\quad F_{BA} = F_{BC} = F,
$$
$$
\textstyle \sum F_y = - 2 F \sin \theta - P = 0 \quad\Longrightarrow\quad F = - \frac{P}{2 \sin \theta} .
$$
在 $C$ 处，连杆沿 $B$ 到 $C$ 的方向以力 $F$ 顶推，其水平分量为 $F \cos \theta$。所以工件受到的水平推力为
$$
Q = - F \cos \theta = \frac{P}{2 \tan \theta} .
$$
$\theta = 10^{\circ}$ 时，
$$
Q = \frac{500}{2 \times 0.17633} = 1418\ \mathrm{N}, \qquad \mathrm{MA} = 2.84 ;
$$
$\theta = 2^{\circ}$ 时，
$$
Q = \frac{500}{2 \times 0.034921} = 7159\ \mathrm{N}, \qquad \mathrm{MA} = 14.3 .
$$
**合理性检验。**$Q$ 按 $1 / \tan \theta$ 增长，并在连杆趋直时发散，这正是肘节的特征。同一个公式说明了肘节为何变得**自锁**：当销钉处的摩擦角超过 $\theta$ 时机构卡死，因为载荷自身的推力此时是使铰接合而不是使其松开。真实的肘节夹具都设计成略微过中心，使松开位置的 $\theta$ 恰好越过 $90^{\circ}$，夹具便不会在振动下打开。
:::

::: example 滑轮组 {#ex-pulley}
重 $2.4\ \mathrm{kN}$ 的载荷由承担动滑轮的四段绳索的滑轮组提升。求理想驱动力，并求滑轮组整体效率为 88% 时的实际驱动力。
::: solution
绳索段数 $n = 4$，$\mathrm{VR} = 4$，理想驱动力为
$$
P_{\text{ideal}} = \frac{Q}{n} = \frac{2400}{4} = 600\ \mathrm{N}.
$$
滑轮组效率 $\eta = 0.88$ 时，
$$
P_{\text{actual}} = \frac{Q}{n \, \eta} = \frac{2400}{4 \times 0.88} = 682\ \mathrm{N},
$$
比理想值高 $14\%$。实际给出的机械效益为 $Q / P = 3.52$，而速度比为 $4$。

**合理性检验。**滑轮组是高效率的机器，损失主要来自绳索绕过滑轮时弯曲的刚度而非销钉摩擦——这就是钢丝绳比同强度的纤维绳损失更多效率的原因，也是一年用一次的滑轮组会卡死、效率远差于 88% 的原因。真实机器中四段绳索并**不**承受相等的张力：它们从载荷端向驱动力端逐级递减，最靠近载荷的那段受力最大。
:::
:::

::: warning 理想机械效益不是机器实际给出的
$\mathrm{MA} = \mathrm{VR}$ 只对理想机器成立。减速比 95 比 1 的蜗杆传动效率可能低于 40%，所以其实际机械效益**小于**速度比，甚至可能小于一——一个耗费的驱动力比它输出的还多的"力放大器"。反过来，$\eta < 1$ 且 $\mathrm{VR} > 1 / (1 - \eta)$ 的机器**自锁**：它不能被反驱动。对蜗杆驱动的卷扬机这是优点，对本该松开的连杆机构则是灾难。绝不要想当然地认为一个机构会在载荷下松开；校核那个不等式，或者把几何设计成过中心。
:::

::: history
机器的静力学始于希腊力学学者列举的五种简单机械——杠杆、轮轴、滑轮、楔与螺旋——载于约公元前 300 年的《机械问题》（*Mechanica*）一书，该书长期被归于亚里士多德（Aristotle），今知为逍遥学派的汇编。亚历山大的希罗（Hero of Alexandria）、阿波罗尼奥斯（Apollonius），尤其是阿基米德（Archimedes），为杠杆给出了证明；阿基米德（Archimedes）的《论平面图形的平衡》（*On the Equilibrium of Planes*，约公元前 260 年）用一个天平论证导出重心结果，那实际上就是虚功论证，只差没有名字。虚速度原理的明确表述见于吉多巴尔多·德尔·蒙蒂（Guidobaldo del Monte）的《力学全书》（*Mechanicorum liber*，1577年）与伽利略（Galileo）的《力学》（*Le mecaniche*，1600年），后者写道"省下来的力恰好是损失掉的速度"——即 $\mathrm{MA} = \mathrm{VR}$ 这一恒等式的文字版。德萨古利耶（John Theophilus Desaguliers）在其《实验哲学教程》（*Course of Experimental Philosophy*，1725年）中给出了力比与速度比关系的第一次清晰发表，而效率概念连同"机械力"及其实测效率的说法，由特雷德戈尔德（Thomas Tredgold）在《木工与建筑语言基本原理》（*Elementary Principles of Carpentry and the Language of Architecture*，1820年）和莫兹利（Moseley）在 1829 年的《实用力学》（*Practical Mechanics*）中形式化，两者都由给磨坊与矿井的齿轮和绳索定尺寸的实际需要驱动。
:::

::: quiz
一台机器速度比为 20，效率为 30%。它的机械效益是多少？
- [ ] 60
- [x] 6
- [ ] 20
- [ ] 0.015
::: solution
$\mathrm{MA} = \eta \times \mathrm{VR} = 0.30 \times 20 = 6$。大减速比的蜗杆传动很容易低到这种程度，而所需驱动力是 $Q / 6$ 而不是 $Q / 20$：仅按速度比设计机器，执行器会选型小三倍以上。另注意 $\eta < 0.5$ 时蜗杆传动自锁，这往往正是选用它的原因。
:::
:::

## 后续内容

拆刚架求出的内力成为 [[mechanics-of-materials/axial-loading]] 与 [[mechanics-of-materials/bending-stress]] 中的截面载荷。机构运动学——这里用到的速度比——在 [[mechanisms/velocity-analysis]] 中展开，连接刚架的销钉、键与螺栓的设计在 [[machine-design/fasteners-joints]]。$3 n < c$ 的超静定刚架需要 [[solid-mechanics/energy-methods]] 或 [[finite-element-method/direct-stiffness]]。

::: summary
- 刚架至少含一根多力杆，因而承受剪力与弯矩；机器有一个自由度，传递力。
- 用 $3 n$ 个方程对 $c$ 个约束分量计数；先识别二力杆，因为每根省掉两个未知数。
- 拆开刚架时，销钉力在两根杆件上等值反向出现——两张都画，并加标注。
- 理想机械效益等于速度比，可由虚功求得：杠杆给 $a / b$，滑轮组给 $n$，肘节给 $1 / (2 \tan \theta)$。
- 效率使机械效益低于速度比；低效率机器可能自锁，这有时是所求，有时是隐患。
:::

## 习题

::: exercise 二力杆 {level=1 check="1600"}
一把断线钳手柄长 $320\ \mathrm{mm}$，钳口长 $40\ \mathrm{mm}$。每个手柄握力 $200\ \mathrm{N}$，钳口力是多少？（答案以 N 计。）
::: solution
对销钉取矩：$J = 200 \times 320 / 40 = 1600\ \mathrm{N}$。机械效益 $8.0$，等于力臂之比。
:::

::: exercise 肘节 {level=1 check="2858"}
对例 6 的肘节压力机，$P = 500\ \mathrm{N}$、$\theta = 5^{\circ}$ 时输出力是多少？（答案以 N 计。）
::: solution
$Q = P / (2 \tan \theta) = 500 / (2 \times 0.08749) = 2858\ \mathrm{N}$。角度减半，力大约加倍，这正是肘节的全部意义。
:::

::: exercise 刚架约束力 {level=2}
T 形杆件在 $A(0, 0)$ 铰接，在 $B(3, 4)$ 带水平辊轴；横臂从 $(3, 4)$ 延伸到 $(5, 4)$。$(5, 4)$ 处作用竖直向下载荷 $12\ \mathrm{kN}$。求约束力。
::: solution
对 $A$ 取矩：$B$ 处辊轴在 $4\ \mathrm{m}$ 高度提供水平力 $B_x$，载荷力臂 $5\ \mathrm{m}$：
$$
\textstyle \sum M_A = -4 B_x - 5 \times 12 = 0 \quad\Longrightarrow\quad B_x = -15.0\ \mathrm{kN}.
$$
于是 $A_x = 15.0\ \mathrm{kN}$、$A_y = 12.0\ \mathrm{kN}$，销钉约束力 $\sqrt{15.0^{2} + 12.0^{2}} = 19.2\ \mathrm{kN}$。辊轴力大于施加载荷，因为其力臂更短——常见的权衡，也是短力臂需要大执行器的原因。
:::
:::

::: exercise 机器：踏板 {level=2 check="1000"}
制动踏板以转轴为支点。驾驶员的脚在距轴 $200\ \mathrm{mm}$ 处施加 $350\ \mathrm{N}$，主缸推杆接在轴另一侧距轴 $70\ \mathrm{mm}$ 处，垂直于踏板臂。求推杆力。（答案以 N 计。）
::: solution
对轴取矩：$F \times 70 = 350 \times 200$，所以 $F = 1000\ \mathrm{N}$。机械效益 $2.86$。汽车踏板特意做成踏板与推杆之间约 4 到 6 的传动比，再乘以制动助力器 2 到 3 倍的真空助力，因为驾驶员能持续舒适施加的只有约 $500\ \mathrm{N}$，而 $0.7 g$ 的制动减速度需要制动片处数千牛顿。
:::

::: exercise 带滑轮的刚架 {level=2}
刚架在角点 $B(0, 3)\ \mathrm{m}$ 处装一无摩擦滑轮，半径 $0.2\ \mathrm{m}$。绳索绕过滑轮，一段竖直悬挂 $5\ \mathrm{kN}$ 载荷，另一段水平通到 $W(4, 3)$ 处的绞盘。刚架在 $A(0, 0)$ 铰接，在 $C(4, 0)$ 处为竖直辊轴。求约束力和滑轮销钉的力。
::: solution
绳索张力处处为 $5\ \mathrm{kN}$（无摩擦滑轮）。滑轮销钉感受两段绳索的拉力：悬挂段的 $(0, -5)$ 与水平段的 $(5, 0)$，所以销钉载荷为
$$
\sqrt{5^{2} + 5^{2}} = 7.07\ \mathrm{kN}
$$
方向 $45^{\circ}$，再加上绳索自身的偏移——两段拉力沿距滑轮中心 $0.2\ \mathrm{m}$ 的直线作用，其合力通过中心，这就是无摩擦滑轮的销钉载荷可以取在中心的原因。

对刚架，用绳索对刚架的作用代替绳索：在 $B(0, 3)$ 处 $5\ \mathrm{kN}$ 向下、$5\ \mathrm{kN}$ 水平。
两段绳索的拉力沿偏离滑轮中心一个滑轮半径的直线作用：竖直段位于 $x = -0.2\ \mathrm{m}$，水平段位于 $y = 3.2\ \mathrm{m}$。于是
$$
\textstyle \sum M_A = 4 C_y + (-0.2)(-5) - 3.2 \times 5 = 4 C_y + 1.0 - 16.0 = 0
\quad\Longrightarrow\quad
C_y = 3.75\ \mathrm{kN},
$$
$$
A_y = 5 - 3.75 = 1.25\ \mathrm{kN}, \qquad A_x = -5.0\ \mathrm{kN}.
$$
**合理性检验。**绳索偏离滑轮中心使力矩改变 $1.0\ \mathrm{kN\,m}$，约 $6\%$——这里虽小，却是正确答案与错误答案之间的差别，也是滑轮的力作用线必须画在绳索实际所在之处、而不是滑轮中心处的原因。
:::
:::

::: exercise 设计：机器铰接处的销钉 {level=3}
例 5 的断线钳中，销钉在双剪下传递 $1750\ \mathrm{N}$。按许用剪应力 $100\ \mathrm{MPa}$ 选择销钉直径，并校核 $10\ \mathrm{mm}$ 厚钳臂中的挤压应力。
::: solution
每个剪切面承担 $875\ \mathrm{N}$，所以
$$
A_{\text{req}} = \frac{875}{100} = 8.75\ \mathrm{mm^{2}}
\quad\Longrightarrow\quad
d = \sqrt{\frac{4 \times 8.75}{\pi}} = 3.34\ \mathrm{mm}.
$$
取 $d = 6\ \mathrm{mm}$，这由操作需要和标准规格决定而非由应力决定，实际剪应力为 $875 / 28.27 = 30.9\ \mathrm{MPa}$。

$10\ \mathrm{mm}$ 钳臂的挤压发生在投影面积 $d t = 6 \times 10 = 60\ \mathrm{mm^{2}}$ 上，钳口侧载荷 $2000\ \mathrm{N}$：
$$
\sigma_b = \frac{2000}{60} = 33.3\ \mathrm{MPa}.
$$
**设计点评。**销钉应力远低于许用值，接头由**挤压和钳臂的弯曲**控制，而不是销钉。断线钳钳臂在钳口与钳身交接处屈服失效，这就是该处锻出圆角、且只对钳口淬火的原因。增大销钉直径毫无作用；在圆角处加厚钳臂才有效。
:::
:::

::: exercise 机器：螺旋千斤顶 {level=3}
螺旋千斤顶采用方牙螺纹，中径 $r = 15\ \mathrm{mm}$，导程 $L = 6\ \mathrm{mm}$，载荷 $20\ \mathrm{kN}$。取螺纹摩擦因数 $\mu = 0.12$，求举升载荷所需力矩与下降载荷所需力矩，并判断千斤顶是否自锁。
::: solution
方牙螺纹是缠在圆柱上的斜面：展开一圈得到水平长度 $2 \pi r$、升高 $L$ 的斜坡，所以螺旋升角为
$$
\tan \alpha = \frac{L}{2 \pi r} = \frac{6}{2 \pi \times 15} = 0.06366, \qquad \alpha = 3.64^\circ,
$$
摩擦角为 $\phi = \arctan 0.12 = 6.84^\circ$。举升载荷的力矩为
$$
T_{\text{raise}} = Q r \tan(\alpha + \phi)
= 20\,000 \times 0.015 \times \tan(10.48^\circ)
= 300 \times 0.1849 = 55.5\ \mathrm{N\,m},
$$
下降的力矩为
$$
T_{\text{lower}} = Q r \tan(\phi - \alpha)
= 300 \times \tan(3.20^\circ) = 300 \times 0.0559 = 16.8\ \mathrm{N\,m}.
$$
两者皆正，所以载荷无法自行驱动螺杆下降：千斤顶**自锁**，即条件 $\phi > \alpha$，等价于 $\mu > L / (2 \pi r)$。

**合理性检验。**举升效率为
$$
\eta = \frac{\tan \alpha}{\tan(\alpha + \phi)} = \frac{0.0637}{0.1849} = 34\ \text{百分比},
$$
这是动力螺杆的典型值，也解释了千斤顶为何需要长的加力杆：$300\ \mathrm{mm}$ 的加力杆给出 $55.5 / 0.300 = 185\ \mathrm{N}$ 的手动力，相当舒适，而 $100\ \mathrm{mm}$ 的杆需要 $555\ \mathrm{N}$，无人能持续。滚珠丝杠千斤顶能挽回那 66% 损失的大部分，代价是失去自锁、需要制动器。
:::

::: exercise 推导 {level=3}
对半角为 $\alpha$、两面摩擦因数均为 $\mu$ 的楔块，推导在载荷 $Q$ 下楔入所需的力，并证明当 $\tan \alpha < \mu$ 时楔块自锁。将结果用于斜度 $1:8$、$\mu = 0.25$、$Q = 10\ \mathrm{kN}$ 的斜楔。
::: solution
每个面承受法向反力 $N$ 和与楔块运动方向相反的摩擦力 $\mu N$。对一个面分别沿垂直于楔轴和沿楔轴分解，把楔块取为分离体，其背面受载荷 $Q$、沿其轴受驱动力 $P$，
$$
Q = 2 \left( N \cos \alpha - \mu N \sin \alpha \right), \qquad
P = 2 \left( N \sin \alpha + \mu N \cos \alpha \right),
$$
所以
$$
P = Q \, \frac{\sin \alpha + \mu \cos \alpha}{\cos \alpha - \mu \sin \alpha}
= Q \, \frac{\tan \alpha + \mu}{1 - \mu \tan \alpha} = Q \tan(\alpha + \phi), \qquad \tan \phi = \mu .
$$
要**拔出**楔块，摩擦力反向，得 $P_{\text{release}} = Q \tan(\phi - \alpha)$，当 $\phi > \alpha$，即 $\mu > \tan \alpha$ 时该值为负——也就是说楔块自己锁住，必须往外拔。这就是**自锁**条件。

对 $1:8$ 斜度，$\tan \alpha = 1 / 8 = 0.125$，$\alpha = 7.125^{\circ}$，$\mu = 0.25$ 时 $\phi = 14.04^{\circ}$：
$$
P = 10 \times \tan(21.16^{\circ}) = 10 \times 0.387 = 3.87\ \mathrm{kN}.
$$
由于 $\phi = 14.04^{\circ} > \alpha = 7.13^{\circ}$，楔块自锁，机械效益为 $Q / P = 2.58$。把斜度减半到 $1:16$，得 $\alpha = 3.58^{\circ}$，$P = 10 \tan(17.62^{\circ}) = 3.17\ \mathrm{kN}$，$\mathrm{MA} = 3.15$——是更好的机器，但好得有限，而自锁裕度增大，这就是需要敲开的连接处不用锥销的原因。
:::
