起重吊钩吊着一台发动机静止不动。三根缆索以不同角度离开吊钩，起重机的卷扬机向上拉。每根缆索承受多少？这个问题有完整的答案，尽管没有任何东西在动——答案来自一行代数：力的矢量和必须为零。

这就是本章的全部内容。当一个物体处于平衡时，它受到的合力消失；而对一个小到可以当作**质点**处理的物体，这是唯一可用的条件。这听起来简单得撑不起一章，事实也确实如此——但本领不在条件本身，而在把力画对。静力学中几乎每一个错误答案都来自一张错误的受力图：一个没有画出的约束力、一根被假设成受压的缆索、一个放错位置的重力、一根被当作梁处理的二力杆。因此本章花在**画**图上的时间与解方程一样多。

::: warning 静力学不是研究不动的东西的学问
平衡意味着**加速度**为零，不是速度为零。以恒定 $8\ \mathrm{kn}$ 被拖航的船、以终端速度下落的降落伞、定高平飞的飞机都处于平衡，它们的力用与求桥墩的力完全相同的方程求出。反过来，一个瞬时静止的物体未必处于平衡：抛体在最高点速度为零而重力照旧，加速度为 $9.81\ \mathrm{m/s^{2}}$。判据永远是 $\sum \mathbf{F} = \mathbf{0}$，绝不是“它在动吗？”。
:::

## 质点模型与受力图

::: definition 质点与平衡 {#def-particle}
**质点**是其大小对所进行的力计算无关紧要的物体：它受到的所有力都可以认为作用于一点，因此不出现力矩条件。吊环、滑轮、螺栓、吊钩、一束缆索的绳结，以及为续航计算而整体处理的飞机，都是这种意义上的质点。一个不是质点的**刚体**还需要力矩条件，这是 [[statics/rigid-body-equilibrium]] 的主题。当且仅当作用在质点上所有力的矢量和消失时，质点处于**平衡**，
$$
\sum \mathbf{F} = \mathbf{0}
\qquad\Longleftrightarrow\qquad
\textstyle \sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0 .
$$
这就是牛顿（Newton）第一定律，对质点而言它既必要又充分。
:::

::: proposition 作为计算规则的牛顿第一定律 {#prop-first-law}
若质点在惯性系中静止或作匀速运动，则它受到的合力为零；反之，若它受到的合力为零，则它静止或作匀速运动。按分量计，平面问题给出两个独立的标量方程，空间问题给出三个，所以**至多**能求出两个或三个未知的大小或方向。
:::

::: proof
常质量质点的牛顿第二定律是 $\sum \mathbf{F} = m \mathbf{a}$。平衡按定义就是 $\mathbf{a} = \mathbf{0}$ 的情形，于是 $\sum \mathbf{F} = \mathbf{0}$；反过来成立是因为 $m \neq 0$。独立方程的个数等于矢量方程独立分量的个数，因为单位矢量 $\mathbf{i}$、$\mathbf{j}$、$\mathbf{k}$ 线性无关：若 $A_x \mathbf{i} + A_y \mathbf{j} + A_z \mathbf{k} = \mathbf{0}$，依次与每个单位矢量作点积即得 $A_x = A_y = A_z = 0$。两个方程至多决定两个未知数，这就是为什么四个缆索悬挂的吊环无法仅由静力求解——这个事实对重物吊装有真实的后果，习题中将讨论。
:::

受力图之后的一切都是机械的。把图画对却不是，下面的步骤值得每次严格按此顺序执行。

::: algorithm 质点的受力图 {#alg-fbd}
1. **分离质点。**选择你要研究平衡的那个点——通常是几个已知力和未知力交汇之点——把它单独画出，与一切脱离。
2. **画出作用在它上面的每一个力**，方向按邻件拉它或推它的方向。缆索、绳索和链条沿自身直线**离开**质点拉，从不推。光滑表面沿其法线**朝外**推，背离表面。弹簧被拉伸时拉，被压缩时推。重力竖直向下作用于质点。
3. **给每个力加标签**：大小未知就标符号，已知就标数值和单位。标出确定每条作用线方向的角，用题目给出的角，不要用你自己算出的、可能算错的角。
4. **选择坐标轴并画在图上。**选得让尽可能多的未知数落在轴上；斜面问题就取一根轴沿斜面。
5. **把每个力写成沿这些轴的分量**，然后写出 $\sum F_x = 0$ 与 $\sum F_y = 0$（空间问题再加 $\sum F_z = 0$）。
6. **求解，然后校核**：未知数的符号与假设的指向是否一致？当某个角趋于 $0$ 或 $90^\circ$ 时答案的变化是否合理？单位对不对？
:::

::: warning 缆索只能拉；压杆却可以推
最常见的单个错误是让缆索受压。柔性的缆索、绳索或链条只能沿自身长度承受拉力，所以如果解出负的张力，物理结论是这根缆索**松弛**、不承受任何东西——于是必须把它从模型中去掉重新求解，几何也随之改变。两端铰接的直二力杆（压杆、拉杆、连杆）可以承受正负两种号，负的“压力”只意味着它受拉。不要把负的缆索张力默默当作答案接受下来。
:::

## 平面内的二力与三力

两个未知数、两个方程，平面质点问题就是一对联立线性方程。两种特殊情形值得一眼认出。

::: proposition 特殊力系 {#prop-special}
**二力质点。**若平衡的质点只受两个力，则这两个力大小相等、指向相反、作用线重合。

**对称三力质点。**若质点受三个力，其中两个力与它们夹角的平分线各成相等的角 $\beta$，第三个力沿该平分线，则两个斜力大小相等，为 $F = P / (2 \cos\beta)$，其中 $P$ 是第三个力。

**拉密（Lami）定理。**若三个力 $\mathbf{F}_1$、$\mathbf{F}_2$、$\mathbf{F}_3$ 使质点保持平衡，$\mathbf{F}_2$ 与 $\mathbf{F}_3$ 之间的夹角为 $\alpha_1$（其余循环类推），则
$$
\frac{F_1}{\sin\alpha_1} = \frac{F_2}{\sin\alpha_2} = \frac{F_3}{\sin\alpha_3} .
$$
:::

::: proof
对两个力，$\mathbf{F}_1 + \mathbf{F}_2 = \mathbf{0}$ 给出 $\mathbf{F}_2 = -\mathbf{F}_1$，一句话同时说明三个性质。对对称情形，取平分线为 $y$ 轴：垂直于它的分量是 $\pm F \sin\beta$，自动抵消；沿它的分量给出 $2 F \cos\beta - P = 0$。对拉密（Lami）定理，把三个力首尾相接封闭：$\sum \mathbf{F} = \mathbf{0}$ 意味着它们构成一个三角形，而该三角形的内角是 $\pi - \alpha_1$、$\pi - \alpha_2$、$\pi - \alpha_3$，因为三角形的每条边都平行于某个力并沿其指向画出，而相邻两边之间的角是两力之间夹角的补角。对该三角形用正弦定理得 $F_1 / \sin(\pi - \alpha_1) = F_2 / \sin(\pi - \alpha_2) = F_3 / \sin(\pi - \alpha_3)$，而 $\sin(\pi - \alpha) = \sin\alpha$。拉密定理是三力情形下的一般事实——封闭的力多边形提供与分量同样多的方程——当三个力和三个角已知时，它比分量法更快。
:::

::: example 光滑斜面上由缆索保持的载荷 {#ex-incline}
一台质量 $200\ \mathrm{kg}$ 的机器放在与水平面成 $30^\circ$ 的光滑平面上，由一根平行于平面的缆索保持。求缆索张力和法向约束力。
::: solution
机器是受三个力的质点：重力 $W = 200 \times 9.81 = 1962\ \mathrm{N}$ 竖直向下，缆索张力 $T$ 沿斜面向上，法向约束力 $N$ 垂直于平面背离平面。平面光滑，所以没有摩擦——这个假设必须由题目文字说明并在图上表明。

取 $x$ 沿平面（向上为正），$y$ 垂直平面。重力分解为沿 $x$ 的 $-W \sin 30^\circ$ 和沿 $y$ 的 $-W \cos 30^\circ$；$T$ 与 $N$ 落在轴上。于是
$$
\textstyle \sum F_x = T - W \sin 30^\circ = 0 \quad\Longrightarrow\quad T = 1962 \times 0.500 = 981\ \mathrm{N},
$$
$$
\textstyle \sum F_y = N - W \cos 30^\circ = 0 \quad\Longrightarrow\quad N = 1962 \times 0.866 = 1699\ \mathrm{N}.
$$

**合理性检验。**当平面放平（$\theta \to 0$）时张力趋于零、约束力趋于全重；当平面变陡（$\theta \to 90^\circ$）时张力趋于重力、约束力趋于零。两个极限都对。约束力大于重力沿平面的分量，且按舍入误差 $981^{2} + 1699^{2} = 1962^{2}$，因为这两个分量正是重力沿直角方向的分解。
:::
:::

::: example 两根吊索起吊一块墙板 {#ex-two-slings}
一块重 $5\ \mathrm{kN}$ 的预制墙板由两根吊索挂在同一个起重吊钩上。两吊索与水平面分别成 $60^\circ$ 与 $30^\circ$，位于过吊钩竖直线的两侧。求每根吊索的张力。哪一根受力更大，大多少？
::: solution
吊钩是质点。它受三个力：墙板的重力 $W = 5\ \mathrm{kN}$ 向下，较陡吊索（与水平成 $60^\circ$）的张力 $T_1$，另一侧较缓吊索（$30^\circ$）的张力 $T_2$。取 $x$ 水平、$y$ 竖直，
$$
\textstyle \sum F_x = T_1 \cos 60^\circ - T_2 \cos 30^\circ = 0, \qquad
\sum F_y = T_1 \sin 60^\circ + T_2 \sin 30^\circ - 5000 = 0 .
$$
第一个方程给出 $T_1 = T_2 \cos 30^\circ / \cos 60^\circ = 1.732\, T_2$。代入第二个，
$$
1.732\, T_2 \times 0.8660 + 0.5000\, T_2 = 1.500\, T_2 + 0.500\, T_2 = 2.000\, T_2 = 5000,
$$
所以
$$
T_2 = 2500\ \mathrm{N} = 2.50\ \mathrm{kN}, \qquad
T_1 = 1.732 \times 2500 = 4330\ \mathrm{N} = 4.33\ \mathrm{kN}.
$$
**较陡**的吊索比缓的多承担 $73\%$，独自承担全部重量的 $87\%$。

**合理性检验。**两个张力是一个直角力三角形的两条直角边，重力是斜边，因为两吊索相隔 $60^\circ + 30^\circ = 90^\circ$：$\sqrt{4330^{2} + 2500^{2}} = 5000\ \mathrm{N}$。这是一个有用的设计事实——当两根吊索互相垂直时，每根的力是 $W$ 乘以其与水平夹角的正弦或余弦，所以任何一根都不超过 $W$，但两根之和（此处为 $6.83\ \mathrm{kN}$）超过 $W$。
:::
:::

::: quiz
一幅质量 $4\ \mathrm{kg}$ 的画用一根绳子挂在钉子上，绳子的两半各与水平成 $30^\circ$。绳中的张力是多少？
- [ ] $20\ \mathrm{N}$
- [x] $39\ \mathrm{N}$
- [ ] $68\ \mathrm{N}$
- [ ] $78\ \mathrm{N}$
::: solution
重量为 $W = 4 \times 9.81 = 39.2\ \mathrm{N}$，绳子的两半提供相加等于它的竖直分量：$2 T \sin 30^\circ = 39.2$，所以 $T = 39.2\ \mathrm{N}$，数值上恰等于重量，因为 $\sin 30^\circ = 0.5$。把绳拉得越平，张力按 $1 / \sin\theta$ 无限制增长：$10^\circ$ 时是 $113\ \mathrm{N}$，$2^\circ$ 时是 $562\ \mathrm{N}$。受载的绳子无论张力多大都不可能被拉得完全笔直，这就是晾衣绳要下垂的原因，也是索屋顶需要预张力或浅曲线的原因。
:::
:::

## 重力、弹簧与光滑表面

质点问题中反复出现三类力，每类各有一条规则。

**重力。**地球表面附近质量为 $m$ 的物体受到 $W = m g$ 的重力，方向竖直向下、作用于质心。对质点而言质心就是质点本身，所以重力施加在那里。受力图中重力总是画成**朝页面下方**，无论物体所在的平面或结构是什么方位。

**弹簧。**刚度为 $k$（单位 $\mathrm{N/m}$）的线性弹簧施加 $F = k s$，其中 $s$ 是相对无应力长度的伸长量。弹簧拉伸时把两端互相拉近，压缩时把两端互相推开。弹簧不是缆索：螺旋弹簧可以承受正负两种号。注意以 $\mathrm{N/mm}$ 计的刚度在数值上比以 $\mathrm{N/m}$ 计的小 $10^{3}$ 倍，混用两者是经典的算术错误。

**光滑表面与接触。**无摩擦的表面或销只能推，且沿接触处的公法线推。与光滑曲面接触的销钉或棱角沿过接触点的半径方向推。若有摩擦，它沿切线方向作用，阻碍即将发生的滑动，其大小不能预先知道——它取平衡所要求的任何值，直到极限 $\mu N$ 为止。本章的问题都无摩擦；其余的在 [[statics/friction]] 中处理。

::: example 弹簧抵住光滑墙壁的滚子 {#ex-spring-roller}
一个重 $500\ \mathrm{N}$ 的滚子靠在光滑竖直墙上，由一根连接其中心、刚度 $2.5\ \mathrm{kN/m}$、已伸长 $40\ \mathrm{mm}$ 的水平弹簧保持。求墙处的约束力。
::: solution
滚子受三个力：重力 $500\ \mathrm{N}$ 向下，墙的约束力 $N$ 水平离开墙，弹簧力 $F_s$ 水平朝向墙。竖直方向的平衡必须由某个力来满足，而 $N$ 和水平弹簧都没有竖直分量——所以按如此描述的布置是不可能的，真实的布置要么弹簧倾斜，要么滚子还放在地面上。取标准版本：滚子放在光滑地面上并接触光滑竖直墙，水平弹簧介于滚子与固定点之间。

于是地面提供竖直约束力 $R_f = 500\ \mathrm{N}$，水平方向
$$
\textstyle \sum F_x = N - F_s = 0 .
$$
弹簧伸长 $s = 40\ \mathrm{mm} = 0.040\ \mathrm{m}$，于是
$$
F_s = k s = 2500 \times 0.040 = 100\ \mathrm{N}, \qquad N = 100\ \mathrm{N}.
$$
墙以 $100\ \mathrm{N}$ 回推，地面以 $500\ \mathrm{N}$ 支撑。

这个例子的要点在于那次失败的开头。数力就是逐个邻件地问：“它接触吗？如果我把它移开，这个物体会动吗？”——如果某个必需的力方向在图上缺失，那么错的是图，不是答案。
:::
:::

## 三维中的平衡

在空间中质点给出三个方程，所以可以求三个未知数。方法不变：用每条直线的单位矢量把每个力表示为直角坐标矢量，求和，令每个分量为零。

::: example 空间中的三索支承 {#ex-3d-cables}
一个 $6\ \mathrm{kN}$ 的载荷悬挂在 $A(0, 0, 0)$，由三根缆索支承于 $B(3, 0, 4)\ \mathrm{m}$、$C(-3, 2, 4)\ \mathrm{m}$ 与 $D(0, -3, 4)\ \mathrm{m}$。求每根缆索的张力。
::: solution
质点是 $A$ 处的吊环。它受的力是载荷 $(0, 0, -6000)\ \mathrm{N}$ 和三个从 $A$ 指向锚固点的张力。单位矢量为
$$
\mathbf{u}_{AB} = \frac{3 \mathbf{i} + 4 \mathbf{k}}{\sqrt{9 + 16}} = 0.600 \mathbf{i} + 0.800 \mathbf{k}, \qquad r_{AB} = 5.00\ \mathrm{m},
$$
$$
\mathbf{u}_{AC} = \frac{-3 \mathbf{i} + 2 \mathbf{j} + 4 \mathbf{k}}{\sqrt{9 + 4 + 16}} = -0.557 \mathbf{i} + 0.371 \mathbf{j} + 0.743 \mathbf{k}, \qquad r_{AC} = 5.39\ \mathrm{m},
$$
$$
\mathbf{u}_{AD} = \frac{-3 \mathbf{j} + 4 \mathbf{k}}{\sqrt{9 + 16}} = -0.600 \mathbf{j} + 0.800 \mathbf{k}, \qquad r_{AD} = 5.00\ \mathrm{m}.
$$
令和的三个分量为零：
$$
\textstyle \sum F_x:\; 0.600\, T_{AB} - 0.557\, T_{AC} = 0 ,
$$
$$
\textstyle \sum F_y:\; 0.371\, T_{AC} - 0.600\, T_{AD} = 0 ,
$$
$$
\textstyle \sum F_z:\; 0.800\, T_{AB} + 0.743\, T_{AC} + 0.800\, T_{AD} - 6000 = 0 .
$$
前两个给出 $T_{AB} = 0.928\, T_{AC}$ 与 $T_{AD} = 0.619\, T_{AC}$。代入第三个，
$$
(0.800 \times 0.928 + 0.743 + 0.800 \times 0.619)\, T_{AC} = (0.743 + 0.743 + 0.495)\, T_{AC} = 1.981\, T_{AC} = 6000 ,
$$
$$
T_{AC} = 3029\ \mathrm{N}, \qquad T_{AB} = 2812\ \mathrm{N}, \qquad T_{AD} = 1875\ \mathrm{N}.
$$

**合理性检验。**三个张力都是正的，所以三根缆索都张紧，布置成立。竖直分量必须相加等于载荷：$0.800 \times 2812 + 0.743 \times 3029 + 0.800 \times 1875 = 2250 + 2250 + 1500 = 6000\ \mathrm{N}$。水平分量按构造成对抵消。三个张力之和 $7716\ \mathrm{N}$ 超过载荷 $29\%$——这就是缆索不竖直的代价，也是使缆索保持竖直的吊梁总是比多肢吊索更轻的原因。
:::
:::

::: warning 三个方程，三个未知数——不能再多
空间中的质点恰好给出三个独立的方程。四个缆索悬挂的吊环有四个未知张力，无法求解：它是**超静定的**，实际的张力取决于每根缆索在固定时被拉伸了多少。这不是方法的失败，而是结构的属性，工程师的对策要么是补充条件（刚度相等加一个协调方程，即 [[mechanics-of-materials/axial-loading]]），要么是安排几何使多余的缆索成为不必要。绝不要“对第四个轴取矩”来得到第四个方程：对汇交力系，任何力矩方程都是三个力方程的组合，什么也添加不了。
:::

::: history
共点力平衡条件最早由斯台文（Stevin）在1586年针对斜面正确表述，他的《称量技艺原理》（*De Beghinselen der Weeghconst*）通过把斜面想象成一条闭合的链条环——所谓 *clootcrans*，即一串小球编成的花环——并论证它不可能转动，从而解决了斜面上重物的问题，这是一个极为优雅的平衡论证。伽利略（Galileo）约1600年写成的《力学教程》（*Le mecaniche*）用接近虚功的论证处理了简单机械，伐里农（Varignon）1687年的《新力学纲要》（*Projet d'une nouvelle méchanique*）把力的合成整理成本书使用的形式。静力学作为一套自成体系的学说，在19世纪初的法国取得了教科书形式：潘索（Poinsot）1803年的《静力学教程》（*Éléments de statique*，多次再版）与泊松（Poisson）1811年的《力学论》（*Traité de mécanique*）。作为一个有名称、需要画出的步骤，受力图还要更年轻，是20世纪工程教学的产物；本章坚持画出它，是因为分离这一步才使这门学科成为力学而不是小聪明。
:::

## 后续内容

质点方程是 [[statics/rigid-body-equilibrium]] 中刚体方程的特例，后者加上力矩条件；[[statics/trusses]] 的节点按设计就是质点，节点法就是把本章用十遍。有摩擦的接触在 [[statics/friction]]。同样的平衡方程用于一个既非质点又非刚体的物体，就成为 [[fluid-mechanics/control-volume-analysis]] 与 [[solid-mechanics/linear-elasticity]] 的控制方程。

::: summary
- 质点是其大小对力计算无关紧要的物体；其平衡条件是 $\sum \mathbf{F} = \mathbf{0}$，平面给出两个方程，空间给出三个。
- 受力图才是工作本身：分离质点，画出邻件施加的每一个力，标注已知与未知，选择坐标轴，分解。
- 缆索只能拉；负的缆索张力意味着缆索松弛，必须从模型中移除。
- 光滑表面与销沿公法线推；弹簧服从 $F = k s$，可拉可推；重力是向下的 $mg$。
- 受两个力时体系是平凡的；受三个力时，拉密定理或力三角形比分量法更快。
- 质点给出的方程数等于它的维数，所以未知数多于方程意味着超静定问题，而不是漏了什么技巧。
:::

## 习题

::: exercise 二力平衡 {level=1 check="981"}
一个 $100\ \mathrm{kg}$ 的质量挂在单根竖直缆索上。缆索张力是多少？（力以 N 计。）
::: solution
质量只受两个力，所以它们等值、反向、共线：$T = mg = 100 \times 9.81 = 981\ \mathrm{N}$。
:::
:::

::: exercise 斜面 {level=1 check="1699"}
一台 $200\ \mathrm{kg}$ 的机器放在与水平面成 $30^\circ$ 的光滑平面上。法向约束力是多少？（力以 N 计。）
::: solution
垂直于平面方向，$N = W \cos 30^\circ = 1962 \times 0.866 = 1699\ \mathrm{N}$。沿平面的分量 $W \sin 30^\circ = 981\ \mathrm{N}$ 必须由缆索、挡块或摩擦来平衡；缺少其中之一，机器就不处于平衡。
:::
:::

::: exercise 对称吊索 {level=1 check="2453"}
一台质量 $500\ \mathrm{kg}$ 的机器由两根相同的竖直吊索起吊。每根的张力是多少？（力以 N 计。）
::: solution
由对称性每根吊索承担一半重量，$T = mg / 2 = 500 \times 9.81 / 2 = 2453\ \mathrm{N}$。

把吊索倾斜到与水平成 $60^\circ$，每根承担 $mg / (2 \sin 60^\circ) = 2832\ \mathrm{N}$；倾斜到 $30^\circ$，每根承担 $4905\ \mathrm{N}$，即全部重量。三种情形下起重吊钩承受的总力都是 $4905\ \mathrm{N}$。
:::
:::

::: exercise 平面内三根缆索 {level=2}
一个 $15\ \mathrm{kN}$ 的载荷在吊环处由三根缆索支承。一根竖直向上连到吊钩，一根沿 $210^\circ$ 向左下，一根沿 $320^\circ$ 向右下，角度从 $+x$ 轴逆时针度量。求三个张力。
::: solution
设 $T_1$ 为竖直缆索（沿 $90^\circ$），$T_2$ 沿 $210^\circ$，$T_3$ 沿 $320^\circ$。吊环的平衡：
$$
\textstyle \sum F_x = T_2 \cos 210^\circ + T_3 \cos 320^\circ = -0.8660\, T_2 + 0.7660\, T_3 = 0 ,
$$
$$
\textstyle \sum F_y = T_1 + T_2 \sin 210^\circ + T_3 \sin 320^\circ - 15 = T_1 - 0.5000\, T_2 - 0.6428\, T_3 - 15 = 0 .
$$
两个方程三个未知数：系统是超静定的。下面两根缆索都在吊环以下，只能把它往下拉，所以除非特意张紧，它们就会松弛，得 $T_2 = T_3 = 0$、$T_1 = 15\ \mathrm{kN}$。若确实张紧使 $T_3 = 6\ \mathrm{kN}$，则 $T_2 = 0.8845 \times 6 = 5.31\ \mathrm{kN}$，$T_1 = 15 + 2.65 + 3.86 = 21.5\ \mathrm{kN}$——卷扬缆索于是比载荷多承担 $43\%$。

工程结论是：吊肢低于吊点的多肢吊索是糟糕的设计：它使卷扬绳的受力超过它所起的重量。
:::
:::

::: exercise 拉密定理 {level=2 check="1785"}
一个 $500\ \mathrm{kg}$ 的滚筒放在与水平面成 $20^\circ$ 的光滑平面上，由水平力 $P$ 保持。求 $P$。（力以 N 计。）
::: solution
三个力：重力 $W = 500 \times 9.81 = 4905\ \mathrm{N}$ 向下，水平力 $P$，以及垂直于平面的法向约束力 $N$。$N$ 与竖直方向成 $20^\circ$，按水平和竖直方向分解，
$$
N \cos 20^\circ = W, \qquad N \sin 20^\circ = P
\quad\Longrightarrow\quad
P = W \tan 20^\circ = 4905 \times 0.3640 = 1785\ \mathrm{N}.
$$
由拉密定理，同样的答案来自 $P / \sin(160^\circ) = W / \sin(110^\circ)$，因为三个力之间的夹角是 $90^\circ$（$P$ 与 $W$ 之间）、$160^\circ$（$W$ 与 $N$ 之间）和 $110^\circ$（$N$ 与 $P$ 之间）——这是一个有用的交叉校核。注意**水平**的保持力需要的值大于沿平面方向的力所需的 $W \sin 20^\circ = 1678\ \mathrm{N}$。
:::
:::

::: exercise 空间平衡 {level=2}
一个 $4\ \mathrm{kN}$ 的载荷悬挂在原点，由缆索支承于 $B(2, 0, 4)\ \mathrm{m}$、$C(-2, 3, 4)\ \mathrm{m}$ 与 $D(0, -3, 4)\ \mathrm{m}$。求三个张力。
::: solution
单位矢量：$\mathbf{u}_{AB} = (2, 0, 4)/4.472 = (0.447, 0, 0.894)$；$\mathbf{u}_{AC} = (-2, 3, 4)/5.385 = (-0.371, 0.557, 0.743)$；$\mathbf{u}_{AD} = (0, -3, 4)/5 = (0, -0.600, 0.800)$。方程为
$$
0.447\, T_{AB} - 0.371\, T_{AC} = 0, \qquad
0.557\, T_{AC} - 0.600\, T_{AD} = 0, \qquad
0.894\, T_{AB} + 0.743\, T_{AC} + 0.800\, T_{AD} = 4000 .
$$
由前两个，$T_{AB} = 0.8305\, T_{AC}$，$T_{AD} = 0.9283\, T_{AC}$。代入，
$$
(0.7425 + 0.7430 + 0.7426)\, T_{AC} = 2.228\, T_{AC} = 4000
\quad\Longrightarrow\quad
T_{AC} = 1795\ \mathrm{N},
$$
$$
T_{AB} = 1491\ \mathrm{N}, \qquad T_{AD} = 1666\ \mathrm{N}.
$$
校核：竖直分量为 $1333 + 1334 + 1333 = 4000\ \mathrm{N}$，符合要求。这里三根缆索恰好几乎平均分担，这是这一几何的特性，不是普遍规律。
:::
:::

::: exercise 设计：吊索角度 {level=3}
一台 $20\ \mathrm{kN}$ 的发电机用双肢吊索起吊，两肢各长 $3\ \mathrm{m}$，分别系在发电机上相距 $2\ \mathrm{m}$ 的两个吊点上，上端汇于中点上方的一个卸扣。求每肢与水平的夹角、每肢的张力以及卸扣上的力。然后对 $1.5\ \mathrm{m}$ 长的吊肢重复计算。
::: solution
吊肢 $L = 3\ \mathrm{m}$、半间距 $1\ \mathrm{m}$ 时，与水平的夹角为
$$
\theta = \arccos \frac{1}{3} = 70.5^\circ, \qquad \sin\theta = 0.943 .
$$
每肢承担 $T = W / (2 \sin\theta) = 20\,000 / (2 \times 0.943) = 10\,600\ \mathrm{N} = 10.6\ \mathrm{kN}$，卸扣承受完整的 $20\ \mathrm{kN}$。

吊肢 $L = 1.5\ \mathrm{m}$ 时，$\cos\theta = 1 / 1.5 = 0.667$，$\theta = 48.2^\circ$，$\sin\theta = 0.745$，
$$
T = \frac{20\,000}{2 \times 0.745} = 13\,400\ \mathrm{N} = 13.4\ \mathrm{kN},
$$
高出 $27\%$，而卸扣上的力不变，仍是 $20\ \mathrm{kN}$。

设计教训是：缩短吊索会急剧增大吊索中的力，对吊点却毫无助益；而**水平**分量——两种情形下分别为 $T \cos\theta = 3\,540\ \mathrm{N}$ 与 $8\,940\ \mathrm{N}$——会把发电机的吊耳向内挤压，这是吊耳必须设计考虑的载荷，却很容易被忘记，因为它不出现在起吊总重里。吊装规程把吊索与水平的夹角保持在约 $60^\circ$ 以上，或者使用使吊肢竖直的扁担梁。
:::
:::

::: exercise 推导 {level=3}
一个半径 $R$、重 $W$ 的轮子靠在高度 $h < R$ 的路缘石上。证明：作用于中心、恰好使轮子离开地面的最小**水平**力为 $P = W \sqrt{R^{2} - (R - h)^{2}} / (R - h)$，并求出任意方向的最小力。对 $R = 0.3\ \mathrm{m}$、$h = 0.05\ \mathrm{m}$、$W = 400\ \mathrm{N}$ 计算两者。
::: solution
轮子恰好离地时，地面的约束力消失，只剩三个力：过中心的向下重力 $W$，作用于中心的水平力 $P$，以及路缘石的约束力——对光滑棱角，它沿路缘边缘 $A$ 到中心 $C$ 的直线作用。对 $A$ 取矩，消去路缘石的约束力。$A$ 到过 $C$ 的竖直线的垂直距离为 $\sqrt{R^{2} - (R - h)^{2}}$，$A$ 到 $P$ 的水平作用线的垂直距离为 $R - h$。于是
$$
P (R - h) = W \sqrt{R^{2} - (R - h)^{2}}
\qquad\Longrightarrow\qquad
P = W\, \frac{\sqrt{R^{2} - (R - h)^{2}}}{R - h} .
$$
当 $h \ll R$ 时这是 $P \approx W \sqrt{2 R h} / R = W \sqrt{2 h / R}$：矮路缘需要的力小，同一个路缘，大轮比小轮省力。

当力垂直于 $AC$ 时最小，即与水平成 $\arcsin\!\big(\sqrt{R^{2} - (R-h)^{2}}/R\big)$ 向上，其大小为
$$
P_{\min} = \frac{W \sqrt{R^{2} - (R - h)^{2}}}{R} .
$$
对 $R = 0.3\ \mathrm{m}$、$h = 0.05\ \mathrm{m}$：$\sqrt{R^{2} - (R-h)^{2}} = \sqrt{0.09 - 0.0625} = 0.1658\ \mathrm{m}$，所以
$$
P_{\text{水平}} = 400 \times \frac{0.1658}{0.25} = 265\ \mathrm{N}, \qquad
P_{\min} = 400 \times \frac{0.1658}{0.30} = 221\ \mathrm{N}
$$
方向与水平成 $\arcsin(0.1658/0.30) = 33.6^\circ$ 向上。在轮轴上水平推比沿最佳方向推多费 $20\%$ 的力——这是过路缘时独轮车是**抬**过去而不是推过去的原因之一，另一个原因是抬起来根本不给路缘面加载。

这里用到的对点取矩一步，只有当所有力汇交时才适用于质点，那种情况下它什么也添加不了；对轮子这样的延展物体，它是必不可少的一步，属于 [[statics/rigid-body-equilibrium]]。
:::
