一切建造起来的东西都搁在别的东西上，而在每个接触面上都有一个沿表面的力，如果你从未听说过摩擦，没有任何方程能预言它。梯子能立在光滑地面上，恰恰因为地面不光滑。带能传递功率，只因为它被夹紧在滑轮上。螺栓保持拧紧，螺母不自行松脱，汽车能停下，人能走路，楔块把搁板垫平。摩擦就是原因，它是初等静力学中唯一一个大小不由平衡给出、只被平衡限定范围的力。

就这一个差别——一个不等式而不是一个方程——改变了整个学科的性质。摩擦问题有一**范围**的答案，而有趣的问题都在范围的端点：驱动物体所需的最小力、制动器能保持的最大载荷、墙把自身基础侧向推出之前的最陡坡度。把这些算对，是能用与会滑的设计之间的差别；算错通常是用错了摩擦因数或法向力。

::: warning 摩擦力不是 $\mu N$，它最多是 $\mu N$
整个静力学中最常见的错误，是在物体并未处于滑动临界状态时写下 $F = \mu N$。静摩擦力取平衡所要求的任何值，从零到极限 $\mu_s N$ 为止。放在水平桌面上的物块有 $F = 0$，而不是 $F = \mu_s N$。永远写 $F \le \mu_s N$，**只有**当题目说"即将滑动""恰好推动""运动临界"时，或当你有意在求极限值时，才把不等号换成等号。用 $F = \mu_s N$ 去解一个非临界问题，得到的答案不只是错的，而是物理上不可能的。
:::

## 干摩擦定律

::: definition 干（库仑）摩擦 {#def-friction}
两个干燥表面以法向力 $N$ 压在一起并有滑动趋势时，彼此施加一个与相对运动或其趋势相反的切向**摩擦力** $F$。库仑摩擦的经验定律是
$$
F \le \mu_s N \ \text{（静摩擦）}, \qquad F_k = \mu_k N \ \text{（动摩擦）}, \qquad \mu_k \lesssim \mu_s ,
$$
其中 $\mu_s$、$\mu_k$ 为静、动摩擦因数。**摩擦角** $\phi$ 定义为
$$
\tan \phi = \mu ,
$$
$N$ 与 $F$ 的合力位于以公法线为轴、半顶角为 $\phi$ 的**摩擦锥**之内。
:::

::: proposition 摩擦锥与安息角 {#prop-repose}
重 $W$ 的物体放在与水平面成 $\theta$ 角的斜面上，即将滑动时
$$
\tan \theta = \mu_s ,
$$
所以**安息角**等于摩擦角。更一般地，受力 $P$ 作用的物体处于平衡，当且仅当 $P$ 与 $W$ 的合力在每个接触处都落在摩擦锥之内。
:::

::: proof
把重力沿斜面与垂直斜面分解。平衡给出 $F = W \sin \theta$ 与 $N = W \cos \theta$，所以不滑条件 $F \le \mu_s N$ 化为 $W \sin \theta \le \mu_s W \cos \theta$，即 $\tan \theta \le \mu_s$，滑动临界时取等号。重量消掉了，这就是安息角不依赖物体质量的原因——这一事实最早由德·拉伊尔（de la Hire）记录、由牛顿（Newton）证实——也是一堆沙子无论是一杯还是一车都保持同样坡度的原因。对一般表述，接触面能提供任何切向与法向分量满足 $F \le \mu_s N$ 的合力，这恰好是与法线成角不超过 $\phi = \arctan \mu_s$ 的方向集合：一个锥。平衡可能，当且仅当其余各力能被该锥内的一个接触力平衡掉。
:::

::: algorithm 运动临界问题 {#alg-friction}
1. 决定**哪个接触先滑动**、**朝哪个方向**。若有多个接触，这就是问题的未知数，每个候选都必须试。
2. 画受力图，摩擦力画成**与即将发生的相对运动相反**的方向——不是与外加力相反，也不是与物体整体运动相反。
3. **只在滑动的接触处**令 $F = \mu N$；其他接触处的摩擦力保留为未知量 $F \le \mu N$，除非它们也处于临界。
4. 解平衡方程。
5. 校核假设：验证每个非临界接触处 $F \le \mu N$，并验证假定的滑动方向给出正的 $F$。若任一条不成立，则是另一个接触起控制作用，必须换假设重解。
:::

::: example 斜面上的物块受水平推 {#ex-incline-push}
质量 $50\ \mathrm{kg}$ 的物块放在倾角 $15^{\circ}$ 的斜面上。静摩擦因数 $\mu_s = 0.35$。求使物块开始沿斜面上移的最小水平力 $P$，并判断物块是否会自行下滑。
::: solution
**会自行下滑吗？**安息角为 $\phi = \arctan 0.35 = 19.29^{\circ}$，而 $15^{\circ} < 19.29^{\circ}$，所以物块静止。等价地，所需摩擦力为 $W \sin 15^{\circ} = 490.5 \times 0.2588 = 127.0\ \mathrm{N}$，而可用摩擦力为 $\mu_s W \cos 15^{\circ} = 0.35 \times 490.5 \times 0.9659 = 165.8\ \mathrm{N}$。它静止着，摩擦能力还有 $77\%$ 没有用上。

**沿斜面上移的最小水平推力。**在沿斜面上移的临界状态，摩擦力沿斜面向下并达到极限。沿斜面与垂直斜面分解，$P$ 水平：
$$
\textstyle \sum F_{\text{法向}} = N - W \cos 15^{\circ} - P \sin 15^{\circ} = 0 ,
$$
$$
\textstyle \sum F_{\text{沿面}} = P \cos 15^{\circ} - W \sin 15^{\circ} - \mu_s N = 0 .
$$
把 $N = W \cos 15^{\circ} + P \sin 15^{\circ}$ 代入第二式，
$$
P \left( \cos 15^{\circ} - \mu_s \sin 15^{\circ} \right) = W \left( \sin 15^{\circ} + \mu_s \cos 15^{\circ} \right)
\quad\Longrightarrow\quad
P = W \tan(\theta + \phi) ,
$$
$$
P = 490.5 \times \tan(34.29^{\circ}) = 490.5 \times 0.6819 = 334\ \mathrm{N}.
$$
**合理性检验。**沿斜面**向上**推需要 $334\ \mathrm{N}$，对抗 $490.5\ \mathrm{N}$ 的重量；若平行于斜面推，只需 $W \sin 15^{\circ} + \mu_s W \cos 15^{\circ} = 127.0 + 165.8 = 292.8\ \mathrm{N}$。水平推力差 $14\%$，因为它的一部分把物块压向斜面，增大了必须克服的摩擦。这是一条一般规律：**向下压一个物体比向上拉它更难移动**，所以吸尘器是推的，雪橇是拉的。
:::
:::

::: example 即将滑动的梯子 {#ex-ladder}
长 $6\ \mathrm{m}$、重 $200\ \mathrm{N}$ 的梯子 $AB$ 靠在光滑竖直墙上，与水平地面成 $60^{\circ}$。地面摩擦因数 $\mu = 0.4$。一个重 $700\ \mathrm{N}$ 的人沿梯子往上爬。梯子滑动之前他能爬到多高？
::: solution
受力：$A$ 处水平的墙面约束力 $N_w$（墙光滑，该处无竖直摩擦），$B$ 处地面法向约束力 $N_f$ 与摩擦力 $F$，梯子自重 $200\ \mathrm{N}$ 作用于中点，人的 $700\ \mathrm{N}$ 作用在距 $B$ 沿梯 $x$ 处。

竖直平衡：
$$
\textstyle \sum F_y = N_f - 200 - 700 = 0 \quad\Longrightarrow\quad N_f = 900\ \mathrm{N}.
$$
滑动临界时地面摩擦达到极限：
$$
F = \mu N_f = 0.4 \times 900 = 360\ \mathrm{N}, \qquad
\textstyle \sum F_x = F - N_w = 0 \quad\Longrightarrow\quad N_w = 360\ \mathrm{N}.
$$
对 $B$ 取矩，逆时针为正，梯子与地面成 $60^{\circ}$：
$$
\textstyle \sum M_B = N_w \times 6 \sin 60^{\circ} - 200 \times 3 \cos 60^{\circ} - 700 \, x \cos 60^{\circ} = 0
$$
$$
360 \times 6 \times 0.8660 = 200 \times 3 \times 0.5 + 700 \, x \times 0.5
\quad\Longrightarrow\quad
1870.6 = 300 + 350 \, x
$$
$$
x = \frac{1570.6}{350} = 4.49\ \mathrm{m}\ \text{沿梯子向上，即全长的}\ 75\ \text{百分比}.
$$
**校核。**人站在 $6\ \mathrm{m}$ 梯子上方 $4.49\ \mathrm{m}$ 处，所以其到 $B$ 的水平距离为 $4.49 \cos 60^{\circ} = 2.24\ \mathrm{m}$，对 $B$ 之矩为 $700 \times 2.24 = 1570\ \mathrm{N\,m}$，与上式相符。

**合理性检验。**若墙粗糙，梯子会更安全；若 $\mu$ 降到 $0.3$，$N_w$ 为 $270\ \mathrm{N}$，$x = 1150 / 350 = 3.29\ \mathrm{m}$，只有全长的 $55\%$。"四分之一"梯子法则——梯脚离墙的距离取工作高度的四分之一——给出 $\tan \theta = 4$，$\theta = 76^{\circ}$，而在此角度下人在顶端所需的 $\mu$ 只有 $0.25$，舒适地低于 $0.4$。
:::
:::

## 楔块

::: definition 楔块及其力平衡 {#def-wedge}
半角为 $\alpha$ 的楔块把一个轴向力变成一个大得多的横向力。两面摩擦因数均为 $\mu$、背面承受载荷 $Q$ 时，将其楔入所需的轴向力为
$$
P = Q \, \frac{\tan \alpha + \mu}{1 - \mu \tan \alpha} = Q \tan(\alpha + \phi), \qquad \tan \phi = \mu ,
$$
而将其**退出**所需的力为 $Q \tan(\phi - \alpha)$。当 $\phi > \alpha$，即 $\mu > \tan \alpha$ 时，楔块**自锁**——载荷不会把它顶出来。
:::

::: proof
每个面承受法向反力 $N$ 和指向阻碍楔块楔入方向的摩擦力 $\mu N$。对楔块分解——其轴水平、两面与轴成 $\alpha$ 角——两个面合起来给出横向反力 $2(N \cos \alpha - \mu N \sin \alpha)$ 和轴向阻力 $2(N \sin \alpha + \mu N \cos \alpha)$。令横向反力等于 $Q$、轴向力等于 $P$，两式相除，
$$
\frac{P}{Q} = \frac{\sin \alpha + \mu \cos \alpha}{\cos \alpha - \mu \sin \alpha}
= \frac{\tan \alpha + \mu}{1 - \mu \tan \alpha} = \tan(\alpha + \phi),
$$
其中用到了 $\mu = \tan \phi$ 的正切加法公式。退出运动时摩擦力反向，得 $\tan(\phi - \alpha)$，当 $\phi > \alpha$ 时为负：那时载荷必须被**顶住**，楔块自己锁住自己。令 $\mu = 0$ 得 $P = Q \tan \alpha$，即理想楔块，其机械效益 $1 / \tan \alpha$ 可以把楔块做薄而任意增大——但只能增大到自锁条件和表面屈服开始起作用的程度为止。
:::

::: example 楔入与保持楔块 {#ex-wedge}
斜度 $1:8$、两面 $\mu = 0.25$ 的楔块被楔入承受 $Q = 10\ \mathrm{kN}$ 的机器底脚之下。求楔入力、拔出所需的力和机械效益。
::: solution
半角满足 $\tan \alpha = 1 / 8 = 0.125$，所以 $\alpha = 7.125^\circ$，摩擦角 $\phi = \arctan 0.25 = 14.04^\circ$。

**楔入。**
$$
P_{\text{in}} = Q \tan(\alpha + \phi) = 10 \tan(21.16^\circ) = 10 \times 0.3871 = 3.87\ \mathrm{kN},
$$
机械效益为 $Q / P_{\text{in}} = 2.58$。

**拔出。**摩擦力此时反向，所以
$$
P_{\text{out}} = Q \tan(\phi - \alpha) = 10 \tan(6.91^\circ) = 10 \times 0.1212 = 1.21\ \mathrm{kN}.
$$
因为 $\phi = 14.04^\circ > \alpha = 7.125^\circ$，楔块**自锁**：载荷不能自行把它顶出，必须施加 $1.21\ \mathrm{kN}$ 的拉力才能拔出。这个拉力就是楔块释放机构必须克服的力，它等于楔入力的 $31\%$——$3.87$ 与 $1.21\ \mathrm{kN}$ 之间的不对称，就是楔块作为夹具的全部用处。

**合理性检验。**斜度减半到 $1:16$，得 $\alpha = 3.576^\circ$，$P_{\text{in}} = 10 \tan(17.62^\circ) = 3.17\ \mathrm{kN}$，斜度减半只改善 $18\%$，因为在这些角度下摩擦占主导：若 $\mu = 0$，同一楔块只需 $1.25\ \mathrm{kN}$。同时自锁裕度从 $\phi - \alpha = 6.9^\circ$ 增大到 $10.5^\circ$，所以更细的楔块锁得更紧。真实的垫片与填塞楔块做得尽可能细，只要空间允许——正是这个原因。
:::
:::

## 带摩擦

::: theorem 欧拉-艾特尔魏因（绞盘）公式 {#thm-capstan}
柔性带在半径不变的圆形滑轮或绞盘上绕经角度 $\beta$（以弧度计），摩擦因数 $\mu$，即将滑动时紧边张力 $T_1$ 与松边张力 $T_2$ 满足
$$
\frac{T_1}{T_2} = e^{\mu \beta} .
$$
该关系与滑轮半径无关，也与张力沿包弧如何变化无关；对槽角为 $2 \gamma$ 的 V 形槽，把 $\mu$ 换成 $\mu / \sin \gamma$。
:::

::: proof
考虑对应圆心角 $\mathrm{d} \theta$ 的带微段，一侧张力 $T$，另一侧 $T + \mathrm{d} T$，单位弧长法向压力 $p$。微段的径向平衡（忽略质量）给出
$$
p\, \mathrm{d} \theta = 2 T \sin \frac{\mathrm{d} \theta}{2} \approx T\, \mathrm{d} \theta \quad\Longrightarrow\quad p = T ,
$$
按单位半径计。滑动临界的切向平衡给出
$$
(T + \mathrm{d} T) - T = \mu p\, \mathrm{d} \theta = \mu T\, \mathrm{d} \theta
\quad\Longrightarrow\quad
\frac{\mathrm{d} T}{T} = \mu\, \mathrm{d} \theta .
$$
从松边积分到紧边，$\ln (T_1 / T_2) = \mu \beta$，即所求结果。注意 $p = T$ 意味着法向压力正比于张力，所以高张力端压得更紧、单位角度产生更多摩擦——这就是比值是指数而非线性的原因，也是半径消掉的原因。对 V 形槽，楔的作用使法向力倍增：$2 N \sin \gamma = p'\, \mathrm{d} \theta$，于是单位法向载荷的摩擦变为 $\mu / \sin \gamma$，槽角 $34^{\circ}$、$\mu = 0.3$ 的槽表现得像 $\mu = 0.3 / \sin 17^{\circ} = 1.03$。
:::

::: example 平带传动 {#ex-belt}
平带从直径 $300\ \mathrm{mm}$、转速 $1200\ \mathrm{rev/min}$ 的滑轮传递功率。包角 $160^{\circ}$，$\mu = 0.3$。若紧边张力为 $500\ \mathrm{N}$，求松边张力、传递的转矩和功率。
::: solution
包角 $\beta = 160 \times \pi / 180 = 2.7925\ \mathrm{rad}$，所以
$$
e^{\mu \beta} = e^{0.3 \times 2.7925} = e^{0.8378} = 2.311 .
$$
于是
$$
T_2 = \frac{T_1}{2.311} = \frac{500}{2.311} = 216\ \mathrm{N},
$$
有效（净驱动）张力为
$$
T_1 - T_2 = 500 - 216 = 284\ \mathrm{N}.
$$
滑轮上的转矩为
$$
\mathcal{T} = (T_1 - T_2) r = 284 \times 0.150 = 42.6\ \mathrm{N\,m},
$$
带速为
$$
v = \pi d n / 60 = \pi \times 0.300 \times 1200 / 60 = 18.85\ \mathrm{m/s},
$$
所以功率为
$$
\mathcal{P} = (T_1 - T_2) v = 284 \times 18.85 = 5350\ \mathrm{W} = 5.35\ \mathrm{kW}.
$$
**合理性检验。**$T_1$ 与 $T_2$ 皆正，所以带是张紧的。比值 $T_1 / T_2 = 2.31$ 是打滑之前的最大可用值；在更低比值下运行是正常的，而且必须张紧带使满载时 $T_2$ 保持为正——松边一旦松弛就会颤动甩打。另注意 $18.85\ \mathrm{m/s}$ 时离心拉力已不可忽略：它不增加传递的力却减小夹紧力，速度超过约 $25\ \mathrm{m/s}$ 后它主导设计。
:::
:::

## 螺旋摩擦

::: proposition 动力螺杆的力矩 {#prop-screw}
中径 $r$、导程 $L$ 的方牙螺杆承受轴向载荷 $Q$，牙侧摩擦因数 $\mu$，所需推进力矩为
$$
\mathcal{T} = Q r \tan(\alpha + \phi), \qquad
\tan \alpha = \frac{L}{2 \pi r}, \quad \tan \phi = \mu ,
$$
下降时需以 $Q r \tan(\phi - \alpha)$ 的力矩**顶住**。当 $\mu > L / (2 \pi r)$ 时螺杆自锁，举升效率为
$$
\eta = \frac{\tan \alpha}{\tan(\alpha + \phi)} .
$$
:::

::: proof
展开螺纹一圈：螺旋线变成水平长度 $2 \pi r$、升高 $L$ 的直斜坡，其倾角 $\alpha = \arctan(L / 2 \pi r)$。载荷 $Q$ 坐在这个斜坡上，螺纹必须提供水平力 $H$ 把它推上去。这正是例 1 的斜面问题，只是 $P$ 换成 $H$、$W$ 换成 $Q$，所以 $H = Q \tan(\alpha + \phi)$，力矩为 $H r$。下降时摩擦力反向，得 $Q \tan(\phi - \alpha)$；该值为负时螺杆自锁，即 $\phi > \alpha$，取正切即 $\mu > L / (2 \pi r)$。效率是理想力矩除以实际力矩：$\eta = Q r \tan \alpha / (Q r \tan(\alpha + \phi))$。对牙侧角为 $\beta$ 的 V 形螺纹或爱克母（Acme）螺纹，同样公式成立，只需把 $\mu$ 换成 $\mu / \cos \beta$，这就是爱克母螺纹（$\beta = 14.5^{\circ}$）比方牙螺纹摩擦多约 $3\%$、米制 ISO 螺纹（$\beta = 30^{\circ}$）多 $15\%$ 的原因。
:::

::: example 螺旋千斤顶 {#ex-jack}
螺旋千斤顶采用中径 $15\ \mathrm{mm}$、导程 $6\ \mathrm{mm}$ 的方牙螺纹，承受 $20\ \mathrm{kN}$，$\mu = 0.12$。求举升载荷的力矩、使其下降所需的力矩和效率。
::: solution
$$
\tan \alpha = \frac{6}{2 \pi \times 15} = 0.06366 \quad\Longrightarrow\quad \alpha = 3.64^{\circ},
\qquad
\phi = \arctan 0.12 = 6.84^{\circ},
$$
$$
\mathcal{T}_{\text{raise}} = 20\,000 \times 0.015 \times \tan(10.48^{\circ})
= 300 \times 0.1850 = 55.5\ \mathrm{N\,m},
$$
$$
\mathcal{T}_{\text{lower}} = 300 \times \tan(3.20^{\circ}) = 300 \times 0.0559 = 16.8\ \mathrm{N\,m} \quad (\text{必须施加此力矩才能使其下降}),
$$
$$
\eta = \frac{\tan 3.64^{\circ}}{\tan 10.48^{\circ}} = \frac{0.0637}{0.1850} = 34.4\ \text{百分比}.
$$
**合理性检验。**三分之二的功损失在螺纹里，这是动力螺杆的典型特征，也是滚珠丝杠能挽回其中大部分的原因——代价是失去自锁，所以滚珠丝杠千斤顶需要制动器。由于 $\mu = 0.12 > L / (2 \pi r) = 0.0637$，千斤顶在零力矩下保持载荷，这是对任何举升人员设备的最低安全要求。
:::
:::

::: warning 用哪个摩擦因数，用哪个法向力
三种错误反复出现。第一，该用静摩擦因数时用了动摩擦因数，或反之：$\mu_k$ 用于已在滑动的物体，通常比 $\mu_s$ 低 $10$ 到 $40\%$，所以"保持"的设计必须用 $\mu_s$，"制动距离"的设计必须用两者之间的某个值。第二，把法向力当成重量：在斜面上、V 形槽里、螺栓预紧之下或带式制动器中，$N$ 与 $m g$ 毫无关系。第三，使用在清洁实验室里对同类材料测得的目录值，而真实表面是有油的、锈蚀的、涂漆的或润滑脂的——$\mu$ 降低 $30\%$，楔块的保持能力、带的传递功率和螺栓预应力的保持能力同样降低 $30\%$。永远按表面状态所能给出的 $\mu$ 的**下界**设计摩擦，永远不要依据你没有测量或没有规定的数值。
:::

::: history
达·芬奇（Leonardo da Vinci）约1493年写道"物体运动产生的摩擦，其他条件相同时，与物体的重量和形状成已知比例"，并记录了摩擦与表观接触面积无关、与载荷成正比——这通常是阿蒙顿（Amontons）三条定律中的两条，他于1699年重新发现并宣布于科学院（Académie des Sciences）。库仑（Coulomb）的《简单机械理论》（*Théorie des machines simples*，1785年）加入了静摩擦与动摩擦的区分以及对滑动速度的无关性，来自绳索与雪橇实验，也是这一名称的由来。绞盘公式由欧拉（Euler）在《航海学》（*Scientia navalis*，1749年）中导出，意大利工程师艾特尔魏因（Eytelwein）于1808年独立得到；特雷德戈尔德（Tredgold）1820年以英文发表并应用于带传动，这就是它有时被称为特雷德戈尔德（Tredgold）公式的原因。用几何角度代替 $\mu$ 的楔块与螺杆摩擦角方法，出自威利斯（Robert Willis）1841年的《机构原理》（*Principles of Mechanism*），直到十九世纪九十年代被解析公式取代之前，它一直是标准设计工具。
:::

::: quiz
一个物块被 $5\ \mathrm{N}$ 的水平力保持静止在水平桌面上。静摩擦因数为 $0.5$，法向力为 $100\ \mathrm{N}$。摩擦力是多少？
- [ ] $50\ \mathrm{N}$
- [x] $5\ \mathrm{N}$
- [ ] $45\ \mathrm{N}$
- [ ] 零
::: solution
$5\ \mathrm{N}$。平衡要求摩擦力恰好平衡外加力；$\mu_s N = 50\ \mathrm{N}$ 只是**极限**，物块只用了它的十分之一。在这里写 $F = \mu_s N = 50\ \mathrm{N}$ 会给出 $45\ \mathrm{N}$ 的合力和一个并不存在的加速度。只有当题目说物块处于滑动临界时，答案才是 $50\ \mathrm{N}$。
:::
:::

## 后续内容

轴承处的摩擦成为 [[machine-design/bearings]] 的润滑理论。摩擦转矩是 [[machine-design/clutches-brakes-belts]] 的载荷工况，螺栓摩擦是 [[machine-design/fasteners-joints]] 中螺栓预紧力如此不确定的原因。摩擦诱发的振动——尖啸、颤振、粘滑——出现在 [[vibrations/two-degrees-of-freedom]] 和机械加工中。

::: summary
- 静摩擦是一个不等式，$F \le \mu_s N$；等号只在滑动临界成立，用在别处是范畴错误。
- 摩擦角 $\phi = \arctan \mu$ 与摩擦锥把摩擦问题变成几何，安息角等于摩擦角。
- 楔块、螺杆与斜面都是同一个计算：$P = Q \tan(\alpha + \phi)$，$\phi > \alpha$ 时自锁。
- 带摩擦对包角呈指数，$T_1 / T_2 = e^{\mu \beta}$，与半径无关；V 形槽把 $\mu$ 乘以 $1 / \sin \gamma$。
- 动力螺杆是缠在圆柱上的斜面，通常自锁，效率通常低于 $50\%$。
- 按真实表面状态 $\mu$ 的下界设计，并永远先认定哪个接触先滑动。
:::

## 习题

::: exercise 安息角 {level=1 check="19.3"}
板条箱与卡车车厢地板间的静摩擦因数为 $0.35$。卡车驶上坡道而板条箱不滑动，坡道的最大坡度是多少度？（答案以度计。）
::: solution
$\theta_{\max} = \arctan 0.35 = 19.3^{\circ}$，与箱子的质量无关。实际中坡道限制在约 $10^{\circ}$，因为潮湿或油污的地板可能只给 $\mu = 0.2$（$11^{\circ}$），而且在坡道上制动还会增加一个摩擦力必须同时提供的减速度分量。
:::
:::

::: exercise 拉与推 {level=1 check="293"}
$50\ \mathrm{kg}$ 的物块被平行于斜面的力以匀速沿 $15^{\circ}$ 斜面上拖，$\mu = 0.35$。求该力。（答案以 N 计。）
::: solution
$P = W (\sin 15^{\circ} + \mu \cos 15^{\circ}) = 490.5 (0.2588 + 0.35 \times 0.9659) = 490.5 \times 0.5969 = 293\ \mathrm{N}$。以高于斜面 $15^{\circ}$ 的角度拉会略微减小此值，因为竖直分量减轻了法向力；以低于斜面同样角度推则会升到 $334\ \mathrm{N}$。
:::
:::

::: exercise 带 {level=1 check="2.31"}
例 6 的平带，比值 $T_1 / T_2$ 是多少？（比值保留两位小数。）
::: solution
$e^{\mu \beta} = e^{0.3 \times 2.7925} = 2.31$。把包角从 $160^{\circ}$ 增到 $200^{\circ}$，比值升到 $e^{1.047} = 2.85$，角度增加 $25\%$ 换来 $23\%$ 的增益——这就是为什么先加张紧轮增大包角、而不是先把带加宽。
:::
:::

::: exercise 楔块 {level=2}
顶角 $10^{\circ}$、两面 $\mu = 0.3$ 的楔块用于顶起 $5\ \mathrm{kN}$ 的载荷。求楔入力，并判断楔块是否自锁。
::: solution
半角 $\alpha = 5^{\circ}$，摩擦角 $\phi = \arctan 0.3 = 16.70^{\circ}$。于是
$$
P = 5 \tan(21.70^{\circ}) = 5 \times 0.3980 = 1.99\ \mathrm{kN}.
$$
由于 $\phi = 16.70^{\circ} > \alpha = 5^{\circ}$，楔块自锁：载荷不能把它顶出，机械效益为 $5 / 1.99 = 2.51$。若把楔块退出来，只有约 $40\%$ 的功可以收回，所以楔块是糟糕的机器、却是出色的夹具——而它的用途恰恰如此。
:::
:::

::: exercise 带式制动器 {level=2}
带式制动器的制动鼓直径 $500\ \mathrm{mm}$，制动带包绕 $270^{\circ}$，$\mu = 0.3$，松边张力 $200\ \mathrm{N}$。求保持转矩；若同一制动带用于槽角 $40^{\circ}$ 的 V 形槽制动鼓，转矩又是多少。
::: solution
$\beta = 270^{\circ} = 4.712\ \mathrm{rad}$，所以
$$
T_1 = 200 \, e^{0.3 \times 4.712} = 200 \times 4.111 = 822\ \mathrm{N},
$$
$$
\mathcal{T} = (T_1 - T_2) r = (822 - 200) \times 0.250 = 155.5\ \mathrm{N\,m}.
$$
在 $40^{\circ}$ V 形槽上，有效摩擦因数为 $\mu / \sin 20^{\circ} = 0.3 / 0.342 = 0.877$，得
$$
T_1 = 200 \, e^{0.877 \times 4.712} = 200 \times 60.6 = 12\,120\ \mathrm{N}, \qquad
\mathcal{T} = 11\,920 \times 0.250 = 2980\ \mathrm{N\,m},
$$
大十九倍。指数关系使 $\mu$ 的微小变化产生巨大的效果：这就是带式制动器自增力、可能猛烈咬死的原因，也是需要平稳释放载荷的场合很少使用 V 形槽制动器的原因。
:::
:::

::: exercise 螺杆 {level=2}
M24 螺栓（$d = 24\ \mathrm{mm}$，螺距 $3\ \mathrm{mm}$）螺纹摩擦因数 $\mu = 0.15$、头部支承面摩擦因数 $\mu_c = 0.15$，拧紧到 $20\ \mathrm{kN}$ 的预紧力。用中径 $r_2 = 10.9\ \mathrm{mm}$、牙侧角 $30^{\circ}$ 估算力矩，并求传入螺纹的力矩比例。
::: solution
螺纹力矩，有效摩擦因数取 $\mu / \cos 30^{\circ} = 0.1732$：
$$
\tan \alpha = \frac{3}{2 \pi \times 10.9} = 0.04382, \quad \alpha = 2.51^{\circ}, \qquad
\phi = \arctan 0.1732 = 9.83^{\circ},
$$
$$
\mathcal{T}_{\text{thread}} = 20\,000 \times 0.0109 \times \tan(12.34^{\circ}) = 218 \times 0.2188 = 47.7\ \mathrm{N\,m}.
$$
头部（支承面）摩擦，有效半径取 $0.7 d = 16.8\ \mathrm{mm}$：
$$
\mathcal{T}_{\text{head}} = 0.15 \times 20\,000 \times 0.0168 = 50.4\ \mathrm{N\,m}.
$$
总力矩 $\mathcal{T} = 98\ \mathrm{N\,m}$，其中只有 $49\%$ 用于拉伸螺栓；其余浪费在头部之下。

**设计点评。**这是螺栓连接的中心事实。头部摩擦变化 $10\%$ 使总力矩变化 $5\%$，而预紧力纹丝不动；**螺纹**摩擦变化 $10\%$ 却使预紧力变化约 $10\%$。由于干燥、润滑与上蜡螺纹之间 $\mu$ 相差一倍，用扭力扳手拧紧的预紧力散布达 $\pm 30\%$，所以关键接头采用扭角法（转角法）拧紧或测量伸长量。
:::
:::

::: exercise 哪个先滑动 {level=3}
重 $W_1 = 200\ \mathrm{N}$ 的物块放在粗糙水平桌面（$\mu_1 = 0.25$）上，其上粗糙面（$\mu_2 = 0.4$）上再放重 $W_2 = 100\ \mathrm{N}$ 的第二物块。水平力 $P$ 作用于下方物块。求运动即将发生时的 $P$，并描述运动形态。
::: solution
两种机构可能：两物块一起沿桌面滑动，或上方物块在下方物块上滑动。

**情形 A，两物块一起滑动。**桌面上的法向力 $= 300\ \mathrm{N}$，极限摩擦 $= 0.25 \times 300 = 75\ \mathrm{N}$，$P = 75\ \mathrm{N}$。校核上方物块能否被带走：它需要水平力 $m_2 a$ 才能与下方物块一起加速，而运动临界时加速度为零，所以它什么都不需要，界面所需摩擦力为 $0 \le \mu_2 \times 100 = 40\ \mathrm{N}$。校核通过。

**情形 B，上方物块在下方物块上滑动。**这要求界面在 $40\ \mathrm{N}$ 达到极限，而这意味着上方物块必须在下方物块被拉动时以 $40 / (100 / 9.81) = 3.92\ \mathrm{m/s^{2}}$ 加速——但桌面的 $75\ \mathrm{N}$ 摩擦在任何需要相对滑动的机构达到之前就已到达。

所以运动在 $P = 75\ \mathrm{N}$ 即将发生，两物块一起运动。若 $P$ 改作用于**上方**物块，答案就变了：上方物块在 $P = 40\ \mathrm{N}$ 时就在下方物块上滑动，因为 $40\ \mathrm{N}$ 小于推动整体所需的 $75\ \mathrm{N}$。推哪个物块决定了哪个接触起控制作用，同一结构把载荷移动半米就可能以两种方式之一失效。
:::
:::

::: exercise 推导 {level=3}
推导内半径 $r_i$、外半径 $r_o$ 的平环推力轴承承受轴向载荷 $W$、摩擦因数 $\mu$ 时的旋转力矩，先假设接触压强均匀，再假设磨损均匀。对 $r_i / r_o = 0.6$ 与 $r_i / r_o = 0.8$ 比较两者，并解释推力瓦与离合器摩擦面为什么做得相对其半径很窄。
::: solution
考虑半径 $r$、宽 $\mathrm{d} r$ 的环形微元，承受压强 $p$。其法向力 $\mathrm{d} N = 2 \pi r p\, \mathrm{d} r$，摩擦力矩 $\mathrm{d} \mathcal{T} = \mu r\, \mathrm{d} N = 2 \pi \mu p r^{2}\, \mathrm{d} r$。

**压强均匀**，$p$ 为常数。则 $W = \pi p (r_o^{2} - r_i^{2})$，所以 $p = W / \pi (r_o^{2} - r_i^{2})$，
$$
\mathcal{T} = 2 \pi \mu p \frac{r_o^{3} - r_i^{3}}{3}
= \frac{2}{3} \mu W \frac{r_o^{3} - r_i^{3}}{r_o^{2} - r_i^{2}} .
$$

**磨损均匀**，磨损率正比于 $p v = p \omega r$，故 $p r = c$ 为常数。则 $W = \int 2 \pi r c\, \mathrm{d} r = 2 \pi c (r_o - r_i)$，所以 $c = W / 2 \pi (r_o - r_i)$，
$$
\mathcal{T} = 2 \pi \mu c \frac{r_o^{2} - r_i^{2}}{2} = \mu W \frac{r_o + r_i}{2} .
$$
对跑合后的轴承，均匀磨损是符合实际的假设，它定义了**摩擦半径** $r_f = (r_o + r_i) / 2$。

$r_i / r_o = 0.6$ 时，压强均匀给出 $\mathcal{T} / \mu W r_o = \tfrac{2}{3} (1 - 0.216) / (1 - 0.36) = 0.925$，磨损均匀给出 $(1 + 0.6) / 2 = 0.800$：相差 $16\%$。$r_i / r_o = 0.8$ 时两者为 $0.903$ 与 $0.900$，相差 $0.4\%$ 以内。因此两个假设只对窄环带一致，宽推力瓦必须按磨损而不是按压强分析——这就是离合器和推力垫圈做得相对其半径很窄的原因，这样设计力矩才可预测。
:::
