一座桥式桁架有三四十根直杆，在销钉处连接，其中每一根只沿自身长度方向传递力，此外不承受任何东西。这一个设计决策——把载荷放在节点上——就把一个结构变成了一组联立线性方程组，而求解它只需要上一章的平衡条件。这就是为什么从1840年代起铁制铁路桥就能用纸笔分析，远早于超静定刚架能够被常规求解的年代。

两种方法包办全部工作。**节点法**逐个隔离每个销钉并解两个方程；它系统、繁琐，也是求出每根杆件内力的唯一办法。**截面法**把桁架一刀截断，把每一侧当作刚体，三个方程对三根被切断的杆件；它很快，也是在不解出整个桁架的情况下求某一根特定杆件内力的办法。两者合起来能回答一个静定桁架提出的所有问题，而知道该伸手拿哪一种就是这门手艺的大半。

::: warning 只有载荷作用在节点上，桁架杆件才只承受轴力
整套方法都依赖于载荷作用在销钉上、杆件自重可忽略或已分摊到其端节点这一假设。在上弦跨中挂一个载荷，那根上弦就成了梁：它会弯曲，桁架分析给出的"轴力"只是故事的一部分。真实的桁架桥在节点之间存在**弦杆弯曲**，还有桥面梁、纵梁与横梁，它们存在的全部意义就是把桥面载荷在到达桁架之前化成节点载荷。分析桁架时，你分析的是理想化模型；设计者的工作是让理想化成立，并校核节点之间因理想化而被忽略的弯曲。
:::

## 理想桁架、静定性与计数法则

::: definition 理想桁架与简单桁架 {#def-truss}
**理想桁架**是由直的、无重的二力杆在无摩擦销钉处连接而成、所有载荷都作用在销钉上的装配体。其杆件只承受均匀轴向拉力或压力。**简单桁架**由一个三角形出发、反复添加两根杆件和一个节点构成；每个简单桁架都是几何不变且静定的。**组合桁架**把两个或更多简单桁架连接起来；**复杂桁架**两者都不是。设杆件数为 $m$、节点数为 $j$、约束力分量数为 $r$，平面桁架静定当且仅当
$$
m + r = 2 j ,
$$
$m + r > 2j$ 时超静定，$m + r < 2j$ 时为机构。
:::

::: proposition 计数法则 {#prop-counting}
平面桁架在其 $j$ 个销钉处各有两个独立的平衡方程，对 $m$ 个杆件内力和 $r$ 个约束力分量共给出 $2 j$ 个方程。它静定当且仅当 $m + r = 2 j$ **并且**杆件与约束的布置使不残留任何独立机构。条件 $m + r = 2 j$ 必要而不充分。
:::

::: proof
每个销钉是一个质点，所以给出 $\sum F_x = 0$ 与 $\sum F_y = 0$ 而没有力矩方程——按定义销钉不能传递力矩。未知数是 $m$ 个轴力（每根杆件一个，因为二力杆的作用线已知后其力就完全由大小确定）加上 $r$ 个约束力分量。计数即得所述条件。布置有缺陷时充分性失效：两个正方形节间并排的桁架（$j = 6$，一铰一辊，$r = 3$），若第一节间有两根斜杆而第二节间没有，则 $m = 9$，$m + r = 12 = 2 j$，然而第二节间可以作为机构自由剪切变形，第一节间却内部多余；平衡矩阵奇异。计数法则是快速筛查，决定性的检验是 $2 j \times (m + r)$ 平衡矩阵是否满秩——这正是计算机检查的东西，也是为什么对任何杆件数超过十几根的桁架，值得用手算静定性检验换成秩检验。
:::

::: algorithm 凭观察找零力杆 {#alg-zero}
在解任何东西之前，先划掉不受力的杆件。三条规则几乎能找到全部：

1. **未受载节点上两根不共线杆件。**两者都为零。
2. **未受载节点上两根共线杆件加第三根。**第三根为零；两根共线杆件内力相等。
3. **载荷沿两根杆件之一的作用线作用的节点上的两根杆件。**另一根为零，第一根承受载荷。

去掉零力杆会简化几何并暴露出更多零力杆。尽管如此它们仍保留在结构中：它们防止受压弦杆屈曲，载荷改变时它们会受力，而且去掉它们会使一个静定桁架在另一种载荷工况下变成机构。
:::

::: example 识别零力杆 {#ex-zero}
下面分析的普拉特（Pratt）桁架有上弦 $7\text{–}8\text{–}9\text{–}10\text{–}11$，跨中一根竖杆 $3\text{–}9$ 在节点 9 与上弦相接。节点 9 不受载且上弦在此是直的，所以规则 2 适用：竖杆 $3\text{–}9$ 内力为零，杆件 $8\text{–}9$ 与 $9\text{–}10$ 内力相等。完整解证实了这两点：$F_{3\text{–}9} = 0$ 且 $F_{8\text{–}9} = F_{9\text{–}10} = -168.75\ \mathrm{kN}$。
:::

## 节点法

::: algorithm 节点法 {#alg-joints}
1. 由整个桁架的平衡方程解出外部约束力。
2. 划掉零力杆。
3. 选一个**未知杆件内力至多两个**的节点——简单桁架上总是某个支座节点。画它的受力图，每根未知杆件都画成**受拉**，即**背离**节点。
4. 写 $\sum F_x = 0$ 与 $\sum F_y = 0$，解这两个方程。负结果表示杆件受压。
5. 移到相邻节点；每根已解出的杆件在那里成为已知力。重复直到全部求出。
6. 用一个未用过的节点校核，或验证每个节点处的杆件内力构成封闭力系。
:::

::: example 节点法：端节间 {#ex-joints}
本章通用的普拉特桁架跨度 $18\ \mathrm{m}$，分六个 $3\ \mathrm{m}$ 节间，高 $4\ \mathrm{m}$。下弦节点 0 至 6 位于 $x = 0, 3, \dots, 18\ \mathrm{m}$，上弦节点 7 至 11 位于 $x = 3, 6, \dots, 15\ \mathrm{m}$、高 $4\ \mathrm{m}$ 处；端斜杆 $0\text{–}7$ 与 $6\text{–}11$ 倾斜，每个上弦节点由一根竖杆与其正下方的下弦节点相连，斜杆 $7\text{–}2$、$8\text{–}3$、$10\text{–}3$ 与 $11\text{–}4$ 向跨中倾斜向下。它在五个内部下弦节点各承受 $50\ \mathrm{kN}$ 向下载荷。支座为节点 0 处的铰和节点 6 处的竖直辊轴。求杆件 $0\text{–}7$、$0\text{–}1$、$1\text{–}7$ 与 $7\text{–}2$ 的内力。
::: solution
**支座约束力。**由对称性，或对 0 取矩，
$$
R_0 = R_6 = \frac{5 \times 50}{2} = 125\ \mathrm{kN}\ \text{向上}, \qquad R_{0x} = 0 .
$$
**节点 0。**两个未知数，$F_{0\text{–}1}$（水平）与 $F_{0\text{–}7}$（沿端柱，其方向为 $(3, 4) / 5 = (0.6, 0.8)$）。两者都画成受拉，背离节点：
$$
\textstyle \sum F_y = 125 + 0.8 F_{0\text{–}7} = 0
\quad\Longrightarrow\quad
F_{0\text{–}7} = -156.25\ \mathrm{kN} \quad (156.25\ \mathrm{kN}\ \text{受压}),
$$
$$
\textstyle \sum F_x = F_{0\text{–}1} + 0.6 F_{0\text{–}7} = F_{0\text{–}1} - 93.75 = 0
\quad\quad\Longrightarrow\quad
F_{0\text{–}1} = +93.75\ \mathrm{kN} \quad (\text{受拉}).
$$
**节点 1。**杆件 $0\text{–}1$ 与 $1\text{–}2$ 水平，$1\text{–}7$ 竖直，$50\ \mathrm{kN}$ 向下作用：
$$
\textstyle \sum F_y = F_{1\text{–}7} - 50 = 0 \quad\Longrightarrow\quad F_{1\text{–}7} = +50.0\ \mathrm{kN} \quad (\text{受拉}),
$$
$$
\textstyle \sum F_x = F_{1\text{–}2} - F_{0\text{–}1} = 0 \quad\Longrightarrow\quad F_{1\text{–}2} = +93.75\ \mathrm{kN} \quad (\text{受拉}).
$$
**节点 7。**杆件 $0\text{–}7$（从 7 到 0 的方向为 $(-0.6, -0.8)$）、$7\text{–}8$（水平，$+x$）、$1\text{–}7$（竖直，$(0, -1)$）与 $7\text{–}2$（方向 $(0.6, -0.8)$）：
$$
\textstyle \sum F_y = -0.8 F_{0\text{–}7} - F_{1\text{–}7} - 0.8 F_{7\text{–}2} = 125 - 50 - 0.8 F_{7\text{–}2} = 0
\quad\Longrightarrow\quad
F_{7\text{–}2} = +93.75\ \mathrm{kN} \quad (\text{受拉}),
$$
$$
\textstyle \sum F_x = -0.6 F_{0\text{–}7} + F_{7\text{–}8} + 0.6 F_{7\text{–}2} = 93.75 + F_{7\text{–}8} + 56.25 = 0
\quad\quad\Longrightarrow\quad
F_{7\text{–}8} = -150.0\ \mathrm{kN} \quad (\text{受压}).
$$
**合理性检验。**端柱受压、斜杆 $7\text{–}2$ 受拉，这正是普拉特（Pratt）布置：斜杆只按受拉设计，因而做得细长。上弦受压、下弦受拉，对像深梁一样工作的承受重力载荷的桁架本应如此。
:::
:::

## 截面法

::: algorithm 截面法 {#alg-sections}
1. 解外部约束力。
2. 用一条直线把桁架截开，穿过内力待求的**至多三根杆件**，使三个截面力不共点、不平行。
3. 画较简单一侧的受力图，每根被截杆件画成受拉。
4. 对其余两根被截杆件作用线的交点取矩——这直接给出第三根，没有联立方程。对每根重复。
5. 若三根被截杆件中有两根平行，则用垂直于它们的 $\sum F$ 求第三根。
6. 用截面上的 $\sum F_x = 0$ 与 $\sum F_y = 0$ 校核。
:::

::: example 截面法：中央节间 {#ex-sections}
对同一桁架，求上弦 $8\text{–}9$、斜杆 $8\text{–}3$ 与下弦 $2\text{–}3$ 的内力。
::: solution
竖直截开第三个节间，穿过杆件 $8\text{–}9$、$8\text{–}3$ 与 $2\text{–}3$，保留左半部分，它包含节点 0、1、2、7 与 8，在 $x = 0$ 处承受向上的 $R_0 = 125\ \mathrm{kN}$，在 $x = 3\ \mathrm{m}$ 与 $x = 6\ \mathrm{m}$ 处承受向下的 $50\ \mathrm{kN}$。

**下弦 $2\text{–}3$。**上弦与斜杆都通过节点 $8(6, 4)$，所以对 8 取矩，二者都消掉。节点 2 处的 $50\ \mathrm{kN}$ 载荷竖直通过 $x = 6$，与节点 8 的横坐标相同，所以它对 8 之矩为零：
$$
\textstyle \sum M_8 = 4 F_{2\text{–}3} - 125 \times 6 + 50 \times 3 = 4 F_{2\text{–}3} - 750 + 150 = 0
\quad\Longrightarrow\quad
F_{2\text{–}3} = +150.0\ \mathrm{kN} \quad (\text{受拉}).
$$
**斜杆 $8\text{–}3$。**上弦与下弦都水平，所以沿竖直方向分解。除载荷外只有斜杆有竖直分量：
$$
\textstyle \sum F_y = 125 - 50 - 50 - \frac{4}{5} F_{8\text{–}3} = 0
\quad\Longrightarrow\quad
F_{8\text{–}3} = \frac{25 \times 5}{4} = +31.25\ \mathrm{kN} \quad (\text{受拉}).
$$
**上弦 $8\text{–}9$。**斜杆与下弦都通过节点 $3(9, 0)$：
$$
\textstyle \sum M_3 = -125 \times 9 + 50 \times 6 + 50 \times 3 - 4 F_{8\text{–}9} = -1125 + 300 + 150 - 4 F_{8\text{–}9} = 0
$$
$$
F_{8\text{–}9} = \frac{-675}{4} = -168.75\ \mathrm{kN} \quad (168.75\ \mathrm{kN}\ \text{受压}).
$$
**校核。**竖直方向：$125 - 50 - 50 - 0.8 \times 31.25 = 25 - 25 = 0$。水平方向：$150.0 - 168.75 + 0.6 \times 31.25 = 150.0 - 168.75 + 18.75 = 0$。两者都闭合，所以截面部分处于平衡，三个力正确。

**合理性检验。**弯矩类比：桁架作为梁在 $x = 6\ \mathrm{m}$ 处的弯矩为 $125 \times 6 - 50 \times 3 = 600\ \mathrm{kN\,m}$，弦杆力偶为 $150.0 \times 4 = 600\ \mathrm{kN\,m}$。弦杆内力 $=$ 梁弯矩 $\div$ 桁架高度，与深梁完全一样——这是桁架设计中最快的估算，也是更高的桁架是更轻的桁架的原因。
:::

## 设计推论：普拉特、豪、沃伦与 K 形

::: proposition 桁架形式由内力分布决定 {#prop-truss-forms}
平行弦桁架在重力载荷下，弯矩与剪力分别在跨中和支座附近最大，所以
$$
F_{\text{弦杆}} = \frac{M(x)}{h}, \qquad F_{\text{斜杆，竖杆}} = \frac{V(x)}{\sin\theta} ,
$$
其中 $h$ 为桁架高度，$\theta$ 为斜杆与水平的夹角。因此弦杆内力在跨中达到峰值，斜杆内力在端部达到峰值。选择几何形式使高应力斜杆受**拉**，得到**普拉特（Pratt）桁架**（斜杆向跨中下倾）；使其受压，得到**豪（Howe）桁架**；使其交替，得到**沃伦（Warren）桁架**，其斜杆在移动载荷下变号；用两根斜杆分割节间，得到 **K 形桁架**，以更多杆件为代价减小竖杆的弯曲。
:::

::: proof
截开一个节间并沿竖直方向分解：截面承担的剪力 $V(x)$ 必须由被截斜杆的竖直分量承担，因为弦杆水平。截到一根斜杆时 $V = F \sin\theta$，给出第二个关系；弦杆水平时，截面上的 $\sum F_x = 0$ 使两根弦杆内力等值反向，对一根弦杆的销钉取矩给出 $M = F_{\text{弦杆}} h$，即第一个关系。两者对任何铰接、节点加载的平行弦桁架都是精确的，两者也都解释了观察到的内力分布：$M$ 是类似抛物线、在跨中达到峰值的曲线，而 $V$ 从支座处的最大值逐级下降，所以靠近端部的斜杆承担最多。细长受压杆在正比于 $EI / L^{2}$ 的载荷下屈曲，所以使高载荷斜杆成为只受拉杆件——如普拉特（Pratt）桁架所做——允许它们做成细杆，而受压杆件则通过在节点处设置侧向约束保持短细。正是这一考虑，而不是美学，决定了1850年后一个世纪里大多数铁桥与钢桥铁路桁架的形式。
:::

::: example 普拉特斜杆的设计校核 {#ex-diag-design}
示例桁架的端斜杆 $7\text{–}2$ 承受 $93.75\ \mathrm{kN}$ 拉力。其长度为 $\sqrt{3^{2} + 4^{2}} = 5.0\ \mathrm{m}$。选择一根圆杆，并按 $140\ \mathrm{MPa}$ 的工作应力校核。
::: solution
所需截面面积为
$$
A_{\text{req}} = \frac{93.75 \times 10^{3}}{140} = 669.6\ \mathrm{mm^{2}} .
$$
直径 $30\ \mathrm{mm}$ 的圆杆有 $A = \pi \times 30^{2} / 4 = 706.9\ \mathrm{mm^{2}}$，比所需多 $5.6\%$，是满足要求的最轻标准规格。其应力为 $93\,750 / 706.9 = 132.6\ \mathrm{MPa}$，受载后的伸长为
$$
\delta = \frac{F L}{A E} = \frac{93\,750 \times 5000}{706.9 \times 200\,000} = 3.32\ \mathrm{mm} .
$$
**合理性检验。**$5\ \mathrm{m}$ 长度上 $3.3\ \mathrm{mm}$ 的伸长是 $6.6 \times 10^{-4}$ 的应变，远在弹性范围内，且小到不会显著改变桁架内力分布。$25\ \mathrm{mm}$ 圆杆给出 $A = 490.9\ \mathrm{mm^{2}}$、应力 $191\ \mathrm{MPa}$，超限 $36\%$——所以小一号规格明显不对，选型并不勉强。
:::
:::

::: warning 三根被截杆件，三个方程——但仅当它们独立
三根被截杆件共点或平行时，截面法会悄无声息地失效。若三个作用线交于一点，对该点的三个力矩方程都平凡满足，方程组奇异；若三者平行，沿它们的 $\sum F$ 只给出三个未知数的一个方程。曲弦桁架的节间是常见的陷阱：截四根杆件，对两个弦杆交点用两个力矩方程；或者截过斜杆交叉的节间，并记住两根交叉斜杆共同承担节间剪力，除非有意把其中一根做得松弛，否则这是超静定的。
:::

::: history
铰接桁架的解析理论在十九世纪中叶由铁路推动而确立。威廉·豪（William Howe）1840年取得其桁架专利，木斜杆受压、熟铁竖杆受拉；托马斯·普拉特与凯莱布·普拉特（Thomas and Caleb Pratt）1844年取得专利，把布置反过来，使长斜杆受拉而可以用铁杆制作——结构形式追随材料的一个直接例证。曾于1841年取得铁弓弦桁架专利的斯奎尔·惠普尔（Squire Whipple）出版了《桥梁建造》（*A Work on Bridge Building*，尤蒂卡，1847年），这是对静定桁架杆件内力的第一个正确的一般分析；为圣彼得堡—莫斯科铁路设计豪式桁架的茹拉夫斯基（Dmitrii Zhuravskii，Jourawski）大约同时独立得到类似结果。截面法由当时在汉诺威高等工业学校任教的奥古斯特·里特（August Ritter）在其《铁屋架与铁桥结构的初等理论与计算》（*Elementare Theorie und Berechnung eiserner Dach- und Brücken-Constructionen*，1862年）中提出；麦克斯韦（James Clerk Maxwell）1864年的论文给出了互等力图，以及 $j$ 个节点的平面杆系需要 $2 j - 3$ 根杆才能刚性的计数法则。
:::

::: quiz
一个平面桁架满足 $m + r > 2 j$。这意味着什么？
- [ ] 它是机构
- [x] 它是超静定的
- [ ] 它是静定的
- [ ] 它必含零力杆
::: solution
未知数多于方程：桁架**超静定**，杆件内力取决于各杆件的相对刚度。多余的杆件并不浪费——它们提供冗余度，使一根杆件的损失不会使桁架倒塌，这正是现代桁架桥有意建成超静定的原因。机构满足 $m + r < 2 j$。
:::
:::

## 后续内容

桁架杆件内力成为 [[mechanics-of-materials/axial-loading]] 中的轴向载荷与 [[mechanics-of-materials/buckling]] 中的屈曲校核。$m + r > 2 j$ 的超静定桁架需要 [[solid-mechanics/energy-methods]] 的能量法和 [[finite-element-method/direct-stiffness]] 的矩阵直接刚度法。同样的计数论证用于刚接刚架见 [[statics/frames-machines]]，一座完整桥面系统的载荷路径在 [[statics/centroids-distributed-loads]] 中算出。

::: summary
- 理想桁架的杆件铰接、无重、二力，只在节点受载；每根杆件承受均匀轴力。
- 静定性靠计数：平面桁架 $m + r = 2 j$，必要而不充分——布置还必须不退化。
- 零力杆凭观察找出，尽管在所考虑载荷工况下不受力，仍保留在结构中。
- 节点法每个销钉解两个方程，从未知数至多两个处开始。
- 截面法至多截三根杆件，在其余两根交点处取矩；弦杆内力 $= M / h$，斜杆内力 $= V / \sin \theta$。
- 桁架形式由这两个关系决定：让高载荷斜杆受拉，让受压杆件保持短细。
:::

## 习题

::: exercise 静定性 {level=1 check="19"}
一个平面桁架有 11 个节点，采用一个铰支座和一个辊轴支座且静定。它有多少根杆件？
::: solution
$m + r = 2 j$，$r = 3$、$j = 11$，得 $m = 22 - 3 = 19$ 根杆件。
:::
:::

::: exercise 零力杆 {level=1 check="1"}
在例题的普拉特桁架中，在给定对称重力载荷下有多少根杆件内力恰好为零？（只数凭观察即为零的杆件。）
::: solution
一根：跨中竖杆 $3\text{–}9$，因为节点 9 不受载且上弦在此是直的。完整解给出 $F_{3\text{–}9} = 0$ 且 $F_{8\text{–}9} = F_{9\text{–}10}$。在把车轮放到节点 9 的移动载荷下该杆件不再为零，这就是它仍然被制造安装的原因。
:::
:::

::: exercise 节点法 {level=1 check="156.3"}
对例题的 $18\ \mathrm{m}$ 普拉特桁架，端柱 $0\text{–}7$ 的内力大小是多少？（答案以 kN 计。）
::: solution
在节点 0，$\sum F_y = 125 + 0.8 F_{0\text{–}7} = 0$ 给出 $F_{0\text{–}7} = -156.25\ \mathrm{kN}$，即 $156.3\ \mathrm{kN}$ 受压。端柱是桁架中受压最重的杆件，也是最可能控制设计的杆件。
:::
:::

::: exercise 截面法 {level=2 check="168.8"}
对同一桁架，求跨中左侧节间的上弦杆件 $8\text{–}9$ 的内力。（答案以 kN 计，取大小。）
::: solution
竖直截开节点 8 与 9 之间的节间，即穿过杆件 $8\text{–}9$、$8\text{–}3$ 与 $2\text{–}3$，保留左半部分。斜杆 $8\text{–}3$ 与下弦 $2\text{–}3$ 交于节点 $3(9, 0)$，所以对该点取矩。左侧有 $x = 0$ 处向上的 $R_0 = 125\ \mathrm{kN}$，以及 $x = 3\ \mathrm{m}$ 与 $x = 6\ \mathrm{m}$ 处向下的 $50\ \mathrm{kN}$：
$$
\textstyle \sum M_3 = -125 \times 9 + 50 \times 6 + 50 \times 3 - 4 F_{8\text{–}9} = -1125 + 300 + 150 - 4 F_{8\text{–}9} = 0
$$
$$
F_{8\text{–}9} = \frac{-675}{4} = -168.75\ \mathrm{kN}, \qquad 168.8\ \mathrm{kN}\ \text{受压}.
$$
**用梁类比校核。**$x = 9\ \mathrm{m}$ 处的简支梁弯矩为 $M = 125 \times 9 - 50 \times 6 - 50 \times 3 = 675\ \mathrm{kN\,m}$，$M / h = 675 / 4 = 168.75\ \mathrm{kN}$。两者一致，这是校核任何弦杆内力最快的办法。力矩求和中漏掉两个节间载荷之一，会得到 $975 / 4 = 244\ \mathrm{kN}$ 或 $825 / 4 = 206\ \mathrm{kN}$，都错得离谱——截面与矩心之间的载荷必须全部计入。
:::
:::

::: exercise 确定桁架高度 {level=2}
一座公路桥桁架须跨越 $30\ \mathrm{m}$，承受 $60\ \mathrm{kN/m}$ 的均布设计载荷。若弦杆工作应力为 $150\ \mathrm{MPa}$，求使最大弦杆内力保持在 $2000\ \mathrm{kN}$ 以下所需的桁架高度，以及相应的弦杆面积。
::: solution
最大梁弯矩为
$$
M = \frac{w L^{2}}{8} = \frac{60 \times 30^{2}}{8} = 6750\ \mathrm{kN\,m}.
$$
由 $F_{\text{弦杆}} = M / h$ 且 $F_{\text{弦杆}} \le 2000\ \mathrm{kN}$，
$$
h \ge \frac{6750}{2000} = 3.375\ \mathrm{m}.
$$
取 $h = 3.5\ \mathrm{m}$，得弦杆内力 $1929\ \mathrm{kN}$，所需弦杆面积 $1929 \times 10^{3} / 150 = 12\,860\ \mathrm{mm^{2}}$，相当于壁厚 $12\ \mathrm{mm}$ 的 $300\ \mathrm{mm}$ 方形空心截面（约 $13\,800\ \mathrm{mm^{2}}$）。跨高比为 $30 / 3.5 = 8.6$，在平行弦桥梁桁架常见的约 $8$ 到 $12$ 的范围内；重载铁路桁架位于该范围中较高（跨高比较小）的一端，因为载荷更重、挠度限值更严。
:::
:::

::: exercise 沃伦桁架 {level=2}
跨度 $12\ \mathrm{m}$、高 $3\ \mathrm{m}$ 的沃伦（Warren）桁架有四个 $3\ \mathrm{m}$ 节间，每个节间由一根 $45^{\circ}$ 的斜杆穿过，斜杆方向交替，在三个内部节点各承受 $80\ \mathrm{kN}$。求靠近支座的斜杆与中央斜杆的内力，并解释为什么中央那根在移动载荷下可能变号。
::: solution
约束力各为 $120\ \mathrm{kN}$。第一个节间的剪力为 $120\ \mathrm{kN}$，由一根与水平成 $\theta = \arctan(3 / 3) = 45^{\circ}$ 的斜杆承担，所以
$$
F_{\text{斜杆}} = \frac{V}{\sin\theta} = \frac{120}{0.7071} = 169.7\ \mathrm{kN} \quad (\text{受压或受拉，取决于斜杆的朝向}).
$$
跨中剪力因对称而为零，所以在此对称载荷下中央斜杆不受力——但一个车轮刚放在跨中左侧会在该处产生小的正剪力，刚放在跨中右侧则产生小的负剪力。因此中央斜杆**变号**，必须既按受压杆又按拉杆设计。

这就是移动载荷下沃伦（Warren）桁架与普拉特（Pratt）桁架的区别：沃伦桁架的斜杆交替且变号，所以全部都必须抗屈曲；普拉特桁架的斜杆布置成重力载荷下的斜杆永远受拉，只有反斜杆（counter）变号，而反斜杆常常被省略。移动载荷下普拉特桁架需要在剪力可能变号的中部节间设反斜杆，十九世纪铁路桁架里的"反斜杆"杆件正是为此而设。
:::
:::

::: exercise 组合桁架 {level=3}
一个组合桁架由两个简单桁架经一个销和一根链杆连接而成。陈述它静定的条件，并解释为什么一个节间内有两根交叉斜杆的格构式腹架是一次超静定的。
::: solution
每个简单桁架有 $m_i = 2 j_i - 3$ 根杆件。在一个公共销处连接两者（于是 $j = j_1 + j_2 - 1$）并加一根链杆，得 $m = m_1 + m_2 + 1 = 2 j - 3$，所以支座为一铰一辊（$r = 3$）时 $m + r = 2 j$。组合桁架静定的条件是该链杆不残留相对运动——其作用线不得通过公共销，否则两半可以绕它相对转动。

一个节间内有两根交叉斜杆的腹架比 $m + r = 2 j$ 多一根杆件：节间剪力按取决于两根斜杆相对刚度的比例分配，而平衡只给出 $F_1 \sin \theta_1 + F_2 \sin \theta_2 = V$，两个未知数一个方程。标准的工程出路是宣布一根斜杆**松弛**——一根在极小压力下就屈曲的细杆——让另一根承担全部剪力。这不是对超静定解的近似，而是一个不同的结构，且只有当松弛杆确实不能受压时才合法。两根斜杆都粗壮时，如支撑刚架，两者都必须求解，工具是 [[solid-mechanics/energy-methods]] 或 [[finite-element-method/direct-stiffness]]。
:::
:::

::: exercise 推导 {level=3}
证明：对任何高为 $h$、在下弦节点加载的平行弦桁架，第 $k$ 节点处受载一侧弦杆的内力为 $F_k = M_k / h$，其中 $M_k$ 是该点的简支梁弯矩，且节间斜杆的内力为 $V_k / \sin \theta$。由此证明，在下弦节点加载的桁架，其弦杆的总轴向应变能在 $h / L$ 的最低阶上等于同跨度承受相同载荷的梁的应变能。
::: solution
截开第 $k$ 节间，对被截的两根非弦杆件的交点取矩——对截一根斜杆的平行弦桁架，该点就是另一根弦杆的销钉——精确给出 $F_k h = M_k$，因为斜杆与另一根弦杆都通过该点，而两根弦杆的力构成力臂为 $h$ 的力偶。沿竖直方向分解截面给出 $F_{\text{斜杆}} \sin \theta = V_k$，因为弦杆水平、竖直方向无贡献。

对能量，位置 $x$ 处的弦杆内力为 $F(x) = M(x) / h$，其伸长为 $\delta = F \, \mathrm{d}x / (A E)$，所以两根弦杆的应变能为
$$
U_{\text{truss}} = 2 \int_0^L \frac{F(x)^{2}}{2 A E}\, \mathrm{d}x
= \frac{1}{A E h^{2}} \int_0^L M(x)^{2}\, \mathrm{d}x .
$$
同跨度、把同样总面积 $2 A$ 的弦杆放在力臂 $h$ 处的梁，其截面惯性矩 $I \approx 2 A (h / 2)^{2} = A h^{2} / 2$，弯曲应变能为
$$
U_{\text{beam}} = \int_0^L \frac{M(x)^{2}}{2 E I}\, \mathrm{d}x
= \int_0^L \frac{M(x)^{2}}{E A h^{2}}\, \mathrm{d}x ,
$$
两者完全相同。因此桁架是一根翼缘承担全部弯曲、腹板承担全部剪力的梁，这个恒等式对弦杆部分是精确的。修正项是腹杆的应变能，即桁架的剪切变形，相对量级为 $(h / L)^{2}$；这就是为什么细长桁架（$h / L$ 小）用梁理论近似得很好，而高桁架还需计入腹杆变形，也是细长桁架的挠度通常用梁弯矩除以一个等效 $EI$ 来估算的原因。
:::
