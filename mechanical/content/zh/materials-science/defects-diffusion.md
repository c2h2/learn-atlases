完美晶体是不可能的，而且不是因为制造不完美。不含空位的晶体的自由能高于含少量空位的晶体，因为把空位混合到格点位置上贡献了一个熵项，在任何高于绝对零度的温度下都没有焓能胜过它。铝在其熔点的空位平衡浓度是四千个格点中有一个，而本课的一切工程后果——扩散、蠕变、烧结、析出、硬化、辐照肿胀、涡轮叶片在一万小时后失效——都源于晶格布满缺陷、因而原子会移动这一事实。

扩散是钢齿轮能外硬内韧的原因，是半导体掺杂剂停在它被注入的地方而不是设计意图所在的原因，是阴极清洗产生的氢原子使高强紧固件脆化的原因，也是铀燃料芯块肿胀的原因。它由一个指数式$D = D_0 \exp \left( - Q / RT \right)$支配，其激活能由缺陷浓度和跃迁频率决定，其后果跨越从室温下铁中的氢到熔点下铁中的铁的三十个数量级。

::: warning 扩散是指数的，所以对它的直觉一文不值
$580\ {}^{\circ}\mathrm{C}$的渗碳处理要用十小时才能在齿轮上渗出一毫米深的渗层；同样的处理在$900\ {}^{\circ}\mathrm{C}$只要四十分钟。炉用热电偶百分之十的误差使渗层深度改变百分之二十，百分之二十的误差使它改变四十四。反过来，一种在$500\ {}^{\circ}\mathrm{C}$一周内可测地扩散的材料在$20\ {}^{\circ}\mathrm{C}$可能完全静止，而按高温试验作线性外推的设计师会判一种本来很好的合金死刑、批准一种本来不行的。由此得出三条规则。**绝不把阿伦尼乌斯线外推到它测得时所覆盖的温度范围之外**，因为机理的改变——从晶格扩散到晶界扩散，从本征外到本征内，从空位到间隙——会使直线弯曲，而且通常向下弯。**如果扩散物种是氢、锂、钠或铁中的碳，绝不要假设扩散过程在室温下被冻结**，这几种在环境温度下都移动得足够快，能在数周内产生后果。**也绝不要相信没有校核边界条件就算出的扩散距离**，因为表面浓度恒定的处理渗层深度按$\sqrt{D t}$变化，总含量恒定的处理也按$\sqrt{D t}$变化但常数完全不同——两者之间差三倍，这正是通过的齿轮与报废的齿轮之间的区别。
:::

## 点缺陷

::: definition 点缺陷及其名称 {#def-point}
**空位**是格点上缺了一个原子；**自间隙原子**是一个同类多余原子被塞进通常不被占据的位置。**弗伦克尔（Frenkel）缺陷**是一个原子离开自己的格点进入间隙位置所产生的空位-间隙对，在阳离子较小的离子晶体中常见（溴化银）。**肖特基（Schottky）缺陷**是保持电中性的成对阳离子和阴离子空位（氯化钠）。**杂质**若替换基体原子则为**置换式**，若坐在空穴中则为**间隙式**；铁中的碳、氮、氢、硼、氧和碳全部是间隙式的，它们的原子比所占据的空穴大$30$%到$40\ \%$，这就是钢的全部强度所在。
**能量学。**一个空位花费焓$\Delta H_f^{V}$，为$0.5$到$3\ \mathrm{eV}$，其中约一半是断键，一半是近邻的弛豫。自间隙原子贵三到四倍，因为它必须推开四个近邻，所以其平衡浓度低$10^{8}$倍，且主要作为辐照产物存在。空位的**形成体积**约为半个原子体积，这就是为什么从再结晶温度以上淬火能使空位凝聚成位错环和层错四面体。
:::

::: proof 为什么空位不可避免 {#proof-vacancies}
取一个含$N$个原子格点、含$n$个空位的晶体。焓为$n \Delta H_f$，而由玻尔兹曼公式和$\left( \begin{array}{c} N \ n \end{array} \right)$种排布，组态熵为
$$
S = k \ln \frac{N !}{n ! \left( N - n \right)!} \approx - N k \left[ c \ln c + \left( 1 - c \right) \ln \left( 1 - c \right) \right], \qquad c = \frac{n}{N} .
$$
因此每格点的自由能为
$$
g (c ) = c \Delta H_f + k T \left[ c \ln c + \left( 1 - c \right) \ln \left( 1 - c \right) \right] .
$$
熵项的导数是$k T \ln \left( c / \left( 1 - c \right) \right)$，当$c \rightarrow 0$时趋于$- \infty$，所以在原点$\mathrm{d} g / \mathrm{d} c < 0$，**无论**$\Delta H_f$**取何值**：添加最初的空位总是降低自由能，因为混合熵的发散比焓的上升更陡。令导数为零并求解，
$$
\boxed{ c = \exp \left( - \frac{\Delta H_f}{k T} \right) }
$$
这里忽略了空位-空位相互作用，并把振动熵归入前置因子。$\checkmark$
**推广。**同样的论证适用于任何点缺陷和任何稀溶质：平衡态是**无序**态，而任何工艺（分子束外延、低温沉积、离子束合成）造出的无缺陷材料在热力学上都不稳定，一旦温度高到原子能移动就会获得自己的缺陷。实践中重要的推论是**淬火**冻结高温浓度，因为$c$从熔点到室温下降十个数量级，而在金属冷透之前空位无处可去。
:::

::: definition 扩散与菲克定律 {#def-fick}
**扩散通量**正比于浓度梯度，
$$
J = - D \frac{\partial C}{\partial x} \quad \left[ \mathrm{mol\, m^{- 2}\, s^{- 1}} \right] ,
$$
把它与质量守恒$\partial C / \partial t = - \partial J / \partial x$结合，对常数$D$得**菲克第二定律**
$$
\frac{\partial C}{\partial t} = D \frac{\partial^{2} C}{\partial x^{2}}
$$
一维问题的两个典型解是：
**表面浓度恒定**$C_s$渗入初始浓度为$C_0$的半无限固体：
$$
\frac{C (x , t ) - C_0}{C_s - C_0} = \operatorname{erfc} \frac{x}{2 \sqrt{D t}} .
$$
**瞬时面源**，单位面积$M$个原子：
$$
C (x , t ) = \frac{M}{\sqrt{\pi D t}} \exp \left( - \frac{x^{2}}{4 D t} \right) ,
$$
其宽度按$\sqrt{D t}$增长，峰值按$1 / \sqrt{D t}$下降，而总面积不变。
两种情形下扩散距离都是
$$
x \sim 2 \sqrt{D t} ,
$$
扩散距离$x$所需的**特征时间**为$t \approx x^{2} / (4 D)$——一个平方律，这就是薄的东西能达到平衡而厚的东西永远不能的原因。
:::

::: widget plot

x: -4, 4

labels: t = t0; t = 4 t0
caption: 瞬时面源在两个时刻的高斯扩展。时间变为四倍时峰值高度减半、宽度加倍，因为曲线下的面积——扩散总质量——守恒。这就是扩散推进工序失去对结深控制的原因：分布没有陡峭的前沿，掺杂剂降到本底浓度以下的深度按$\sqrt{t}$增长，而表面浓度按$1 / \sqrt{t}$下降。
:::

::: definition 温度依赖与三条经验法则 {#def-arrhenius}
$$
D = D_0 \exp \left( - \frac{Q}{R T} \right),
$$
其中$Q$为扩散激活焓。对**空位机理的自扩散**，激活焓是空位形成焓与迁移焓之和，$Q = \Delta H_f + \Delta H_m$，而在整个金属界有三条经验规律成立：
$$
Q_{\mathrm{self}} \approx 18 R T_m , \qquad D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}, \qquad D \left( T_m \right) \approx 10^{- 13}\ \mathrm{m^{2} / s} .
$$
第三条值得注意：**每种金属在自己的熔点都以约$10^{- 13}\ \mathrm{m^{2} / s}$扩散**，从锌到钨都是，这就是烧结规程按绝对熔点的分数给出、而对比温度$T / T_m$是冶金学家唯一使用的温度的原因。间隙扩散的$Q$为$0.1$到$1.2\ \mathrm{eV}$，不含空位项，因此快$10^{4}$到$10^{10}$倍；室温下铁中的氢以$2 \times 10^{- 8}\ \mathrm{m^{2} / s}$扩散，比$1000\ {}^{\circ}\mathrm{C}$下铁中的铁快一百倍。
:::

::: example 平衡空位与淬火空位 {#ex-vacancies}
铝的空位形成焓为$0.66\ \mathrm{eV}$。给出$200\ {}^{\circ}\mathrm{C}$、熔点$660\ {}^{\circ}\mathrm{C}$以及淬火到$20\ {}^{\circ}\mathrm{C}$之后的平衡浓度。
::: solution
**在$200\ {}^{\circ}\mathrm{C} = 473\ \mathrm{K}$：**
$$
c = \exp \left( - \frac{0.66}{8.617 \times 10^{- 5} \times 473} \right) = 9.3 \times 10^{- 8}
$$
一千一百万个格点中一个空位。
**在$660\ {}^{\circ}\mathrm{C} = 933\ \mathrm{K}$：**
$$
c = \exp \left( - 8.19 \right) = 2.7 \times 10^{- 4}
$$
每$3700$个格点一个，即每立方米$1.6 \times 10^{25}$个空位，而格点有$6.0 \times 10^{28}$个。
**淬火到$20\ {}^{\circ}\mathrm{C}之后：**$293\ \mathrm{K}$的平衡值为$7 \times 10^{- 12}$，但空位在淬火中来不及扩散到湮灭源，所以金属保留**四到五个数量级的过饱和**。下一次在$150$到$200\ {}^{\circ}\mathrm{C}$时效时，过饱和通过形成位错环而崩溃，这些环在电子显微镜下可见，是几纳米大的完整棱柱性间隙或空位环。

**校核。**熔点下每立方米的空位数$1.6 \times 10^{25}$对应每立方米$1.6 \times 10^{25} \times 1.66 \times 10^{- 29} = 2.7 \times 10^{- 4}\ \mathrm{m^{3}}$的体积——与浓度相同的分数，理当如此，且等于慢冷试样与淬火试样之间**实测**的密度差，这正是$c$最初被测量的方法。$\checkmark$

**合理性检验。**淬火空位法把$c$测到几个百分点，要求淬火足够快，使金属在扩散变慢之前穿过扩散快的温度区间。对铝，水冷就够；对$\Delta H_f = 2\ \mathrm{eV}$的难熔金属，淬火中点处的浓度已经很低，方法失效，这就是钨和钼的空位数据来自膨胀法和正电子湮灭而不是密度的原因。
:::

::: example 齿轮渗碳 {#ex-carburising}
一个$0.1\ \%\mathrm{C}$的钢齿轮在$1000\ {}^{\circ}\mathrm{C}$渗碳，气氛使表面保持$1.0\ \%\mathrm{C}$。要在深度$1\ \mathrm{mm}$处达到$0.4\ \%\mathrm{C}$需要多长时间？十小时后渗层深度是多少？
::: solution
**扩散系数。**对$\gamma$-铁中的碳，$D_0 = 2.3 \times 10^{- 5}\ \mathrm{m^{2} / s}$，$Q = 148\ \mathrm{kJ / mol}$：
$$
D = 2.3 \times 10^{- 5} \exp \left( - \frac{148{,}000}{8.314 \times 1273} \right) = 1.94 \times 10^{- 11}\ \mathrm{m^{2} / s} .
$$
**自变量所需的值。**边界条件为$C_s = 1.0$、$C_0 = 0.1$，目标$C_x = 0.4$：
$$
\frac{C_x - C_0}{C_s - C_0} = \frac{0.3}{0.9} = 0.333 = \operatorname{erfc} (z )
\quad\Longrightarrow\quad
z = 0.595 .
$$
**时间。**由$x = 2 z \sqrt{D t}$：
$$
t = \frac{x^{2}}{4 z^{2} D} = \frac{10^{- 6}}{4 \times 0.354 \times 1.94 \times 10^{- 11}} = 3.64 \times 10^{4}\ \mathrm{s} = 10.1\ \mathrm{h} .
$$
**灵敏度。**温度误差$10\ {}^{\circ}\mathrm{C}$使$D$改变$\exp \left[ 17{,}800 \times 6.1 \times 10^{- 6} \right] = 1.12$，即$D$变百分之十一，固定时间下渗层深度变**百分之五点半**。固定深度下$D$同样的百分之十一使所需时间变百分之十一，而漂移二十度的炉子给整炉每个齿轮的渗层深度加上百分之十一。

**校核。**十小时后扩散距离为$2 \sqrt{D t} = 2 \times 8.4 \times 10^{- 4} = 1.68\ \mathrm{mm}$，$0.4\ \%$等值线的深度为$0.595 \times 1.68 = 1.00\ \mathrm{mm}$ $\checkmark$

**合理性检验。**时间的平方根是渗碳经济学的全部：渗层深度加倍需要四倍的时间、四倍的炉时，这就是工业界烧得热（$900$到$950\ {}^{\circ}\mathrm{C}$，接近$\gamma$到$\alpha$的上限）的原因，也是**低压渗碳**用几毫巴的乙炔以三分之一时间达到同样渗层的原因——不是提高$D$（那是材料性质），而是把表面碳势提高到过程变为扩散控制而非反应控制。一个无论跑多久都快不起来的渗碳循环是**表面限制**的，诊断结论是碳势太低，而不是温度不够。
:::
:::

::: example 为什么淬火有效：碳在两种铁中 {#ex-two-irons}
碳在$\alpha$-铁和$\gamma$-铁中都扩散。已知在$\alpha$中$D_0 = 6.2 \times 10^{- 7}\ \mathrm{m^{2} / s}$、$Q = 80\ \mathrm{kJ / mol}$，在$\gamma$中$D_0 = 2.3 \times 10^{- 5}\ \mathrm{m^{2} / s}$、$Q = 148\ \mathrm{kJ / mol}$，在$\gamma$到$\alpha$的转变温度$912\ {}^{\circ}\mathrm{C}$比较两者，并解释其冶金学后果。
::: solution
**在$1185\ \mathrm{K}$：**
$$
D_\alpha = 6.2 \times 10^{- 7} \exp \left( - 8.11 \right) = 1.84 \times 10^{- 10}\ \mathrm{m^{2} / s},
\qquad
D_\gamma = 2.3 \times 10^{- 5} \exp \left( - 15.01 \right) = 6.9 \times 10^{- 12}\ \mathrm{m^{2} / s} .
$$
碳在**堆垛更密的铁中扩散快二十七倍**，正是那个违反直觉的结果。
**为什么。**激活焓是从近旁原子之间挤过去所需的能量，而BCC铁中沿$\left\langle 110\right\rangle$方向原子之间的窗口比FCC中沿$\left\langle 110\right\rangle$的窗口大，因为BCC根本不是密堆结构——它是一种孔洞大但数量少的结构，而FCC是密堆、孔洞小。致密度$0.68$对$0.74$说的是**平均**情况，而BCC间隙位置只有$0.019\ \mathrm{nm}$宽，碳却是$0.077\ \mathrm{nm}$，所以碳坐在严重畸变的位置里，容易移动。
**后果。**淬火时奥氏体通过**无扩散**切变形变成马氏体，因为碳来不及移动：在$D_\alpha = 10^{- 10}\ \mathrm{m^{2} / s}$下，一秒内的扩散距离是$2.7 \times 10^{- 5}\ \mathrm{m}$，二十七微米，而对几微米大的铁素体晶粒或珠光体团来说这绰绰有余——这就是薄试样水冷后仍会得到一些珠光体的原因，也是钢的淬透性是扩散距离与板条间距之间一场比赛的原因。

**校核。**$\gamma$-铁在$912\ {}^{\circ}\mathrm{C}$一秒内的扩散距离为$2 \sqrt{6.9 \times 10^{- 12}} = 5.3\ \mu\mathrm{m}$，而该过冷度下珠光体的片层间距为$0.1\ \mu\mathrm{m}$——所以珠光体**能**形成，也确实形成，只要给它几秒。在$550\ {}^{\circ}\mathrm{C}$，$D_\gamma$已下降$700$倍，一秒内扩散距离为$0.19\ \mu\mathrm{m}$，与贝氏体铁素体板的间距相当，这就是那里的转变远比珠光体慢、又远比马氏体快的原因。$\checkmark$

**合理性检验。**同样的二十七倍不对称解释了为什么渗碳钢尽管$\gamma$区溶解度低（$\gamma$中$1.4\ \%$碳对$\alpha$中$0.02\ \%$）仍在$\gamma$区渗碳——因为浓度驱动力远远补偿了较低的$D$。它也解释了为什么**渗氮**在$\alpha$区的$500\ {}^{\circ}\mathrm{C}$进行，那里氮扩散快并形成硬质氮化物，在更低温度下得到更硬更薄的渗层且毫无淬火变形。
:::

::: example 互扩散与柯肯达尔效应 {#ex-kirkendall}
纯铜与纯镍的扩散偶在$1000\ {}^{\circ}\mathrm{C}$退火，界面上有一排惰性钼标记。标记朝哪个方向移动？十小时后移动多少？
::: solution
**扩散系数。**在$1273\ \mathrm{K}$，$D_{\mathrm{Cu}\rightarrow \mathrm{Ni}} \approx 7 \times 10^{- 14}$，$D_{\mathrm{Ni}\rightarrow \mathrm{Cu}} \approx 4 \times 10^{- 14}\ \mathrm{m^{2} / s}$：铜进入镍的速度约为镍进入铜的两倍。
**后果。**净原子通量指向铜一侧，铜侧因此失去晶面并**收缩**，所以标记——它们随晶格一起移动——移向铜内。这就是**柯肯达尔（Kirkendall）效应**，若两个扩散系数相等它就不可能出现，而相等正是菲克原始处理的假设。
**孔洞。**收缩侧留下的空位过饱和凝聚成沿原界面的一排孔洞，在显微镜下是一条孔隙带，将成为疲劳裂纹的起点。
**数学。**达肯（Darken）方程给出标记速度和依赖成分的互扩散系数：
$$
\tilde{D} = D_B N_A + D_A N_B , \qquad
v = \left( D_A - D_B \right) \frac{\mathrm{d} \ln C_A}{\mathrm{d} x} ,
$$
而**马塔诺-玻尔兹曼（Matano-Boltzmann）法**通过绕马塔诺面（净通量为零的面）积分，从单个扩散偶的成分分布中提取$\tilde{D} (C )$。

**校核。**取$\Delta D = 3 \times 10^{- 14}\ \mathrm{m^{2} / s}$、成分梯度为每$50\ \mu\mathrm{m}$一个原子分数，$v = 3 \times 10^{- 14} \times 2 \times 10^{4} = 6 \times 10^{- 10}\ \mathrm{m / s}$，十小时标记位移$22\ \mu\mathrm{m}$——光学上容易测量，且恰与铜-镍扩散偶报道的量相符。$\checkmark$

**合理性检验。**柯肯达尔效应不是实验室里的奇闻；它是两种不同合金之间的**扩散焊**界面会有一条孔洞带（除非在压力下完成连接）的原因，也是人们刻意制造纳米尺度**柯肯达尔孔洞**来掏空金属纳米壳用于催化的原因。它还是铜与锡-银合金的钎焊接头在两侧长出厚度不等的金属间化合物层、且接头失效在金属间化合物而不是在钎料中的原因。
:::

::: example 设计 {#ex-design-barrier}
硅上的铜互连线必须加扩散阻挡层，使得在$450\ {}^{\circ}\mathrm{C}$下六十分钟内到达硅的铜少于一个单层的百分之一。在$50\ \mathrm{nm}$厚的钽膜、$\mathrm{TiN}$膜和$\mathrm{Ta_2 O_5}$膜之间做选择。
::: solution
**要求。**一侧为恒定源、另一侧为完美湮灭源时，厚$L$的薄膜的透过分数近似为
$$
f \approx \frac{2 \sqrt{D t}}{L} \exp \left( - \frac{L^{2}}{4 D t} \right) \quad \text{当} \ L \gg 2 \sqrt{D t} .
$$
记$u = L^{2} / \left( 4 D t \right)$，这就是$f = \mathrm{e}^{- u} / \sqrt{u}$，$f < 10^{- 2}$要求$u > 4.0$。取$L = 50\ \mathrm{nm}$、$t = 3600\ \mathrm{s}$，
$$
D < \frac{L^{2}}{4 u t} = \frac{2.5 \times 10^{- 15}}{4 \times 4.0 \times 3600} = 4 \times 10^{- 20}\ \mathrm{m^{2} / s}
$$
在$450\ {}^{\circ}\mathrm{C} = 723\ \mathrm{K}$。
**候选者。**取$D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}$，$Q$取实测值：
$$
\begin{array}{l c c}
\text{阻挡层} & Q\ \left[ \mathrm{eV} \right] & D \left( 723\ \mathrm{K} \right)\ \left[ \mathrm{m^{2} / s} \right] \\
\text{钽，晶界路径} & 1.2 & 4 \times 10^{- 14} \\
\mathrm{Ta_2 O_5} & 2.4 & 2 \times 10^{- 22} \\
\mathrm{TiN} & 3.0 & 1 \times 10^{- 26}
\end{array}
$$
**选择。**钽差六个数量级而不合格，因为铜沿其柱状晶界扩散，激活能约$1.2\ \mathrm{eV}$；纯钽阻挡层被放弃正是为此。五氧化二钒超出两个数量级而合格，氮化钛超出七个，而实际使用的是氮化钛，因为它同时也是粘附层，并为其下的钨栓提供扩散阻挡。
**真实规格。**阻挡层不是靠这个计算验收，而是靠**应力迁移**和**电迁移**试验，而失效模式根本不是体扩散：是铜沿阻挡层与通孔壁之间的**界面**泄漏，这就是现代答案是**钽/氮化钽双层**——Ta润湿铜，$\mathrm{TaN_x}$堵住界面路径——反应溅射沉积总厚$25\ \mathrm{nm}$的原因。

**设计评注。**三条教训可以推广。**失效的阻挡层，其失效路径不是设计所针对的那条**，而纳米晶溅射膜中晶界和界面扩散比晶格扩散快$10^{6}$到$10^{12}$倍。**非晶或纳米晶阻挡层胜过结晶柱状阻挡层**，原因正在于此，而工业界1990年代从CVD转向PVD阻挡膜在把膜做成非晶之前一无所获。而且**扩散阻挡层同时也是一层力学层**，所以它的厚度由$25\ \mathrm{nm}$处的台阶覆盖和粘附决定，而不是由扩散计算决定——后者有两纳米氮化钛就满足了。
:::
:::

::: history
固体扩散这一实验事实被确立了两次，而两次都不被相信。**罗伯特·海尔（Robert Hare）**1826年把一根金圆柱焊在一根铅圆柱上，在温和加热下保持五年，发现每种金属都在另一种里面；**威廉·弗里斯顿（William Freeston）**1878年向曼彻斯特文学与哲学学会宣读了同一个实验，得到同样的结论，两人都被当作奇闻。**威廉·钱德勒·罗伯茨-奥斯顿（William Chandler Roberts-Austen）**1896年通过切分金-铅扩散偶并称重各层做出了第一批定量测量，画出了第一条阿伦尼乌斯线。**卡尔·瓦格纳（Carl Wagner）**在1938年的一系列论文中给出了金属互扩散的现代理论形式，而**欧内斯特·柯肯达尔与A. E. 斯米格尔卡斯（Ernest Kirkendall and A. E. Smigelskas）**1947年的论文报道了惰性标记实验，证明两个本征扩散系数不同——这是瓦格纳的理论早已允许、而多数冶金学家拒绝承认了十年的结果，因为它意味着晶格不是固定的。**莱纳斯·鲍林（Linus Pauling）**1929年关于离子晶体的规则确定了肖特基能和弗伦克尔能的量级。**C. 马塔诺（C. Matano）**1933年分析互扩散偶的方法与**E. 玻尔兹曼（E. Boltzmann）**1894年的相似变换由**马塔诺**合并为一个至今仍是标准的作图。**F. A. 科特雷尔（F. A. Cottrell）**1953年的《位错与晶体中的塑性流动》（*Dislocations and Plastic Flow in Crystals*）把空位-位错联系变成普通教科书内容，而**A. D. 克莱尔（A. D. Le Claire）**1963年发表在《金属物理进展》（*Progress in Metal Physics*）上的晶界扩散综述，是过去六十年每一项测量都对照检查的基准文献。
:::

## 后续内容

本课的空位浓度是[[materials-science/phase-transformations]]中析出动力学的迁移率项，例4中铁中碳的不对称是[[materials-science/phase-diagrams]]中铁-碳相图按亚稳渗碳体而非稳定石墨绘制的原因，扩散距离$\sqrt{Dt}$是[[materials-science/failure]]中蠕变孔洞的长度尺度，而使钢变强的间隙碳，与[[materials-science/dislocations-strengthening]]中使钢在成形后时效的，是同一个原子。

::: summary
- 晶体必须含空位：混合熵在浓度为零时发散，所以自由能极小在$c = \exp \left( - \Delta H_f / k T \right)$，熔点下约四千个格点一个，室温下则没有。
- 扩散距离按$\sqrt{Dt}$变化，所以处理时间加倍换来百分之四十的深度，四倍才使深度加倍。
- 自扩散服从三条普适规律：$Q \approx 18 R T_m$、$D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}$，以及每种金属在熔点$D \approx 10^{- 13}\ \mathrm{m^{2} / s}$。
- 间隙原子比空位扩散快$10^{4}$到$10^{10}$倍，碳在开放结构的BCC铁中比在密堆FCC铁中快二十七倍。
- 本征扩散系数不同，所以晶格本身在移动：柯肯达尔效应、标记运动和界面孔洞证明菲克的对称图像不完整。
- 器件相关温度下的真实扩散走晶界和界面，不走晶格，按晶格扩散设计的阻挡层会差十三个数量级而失效。
:::

::: quiz
一个渗碳循环达到规定渗层深度所用的时间是规程要求的两倍，而炉温已核实无误。最可能的原因是什么？
- [x] 过程受表面反应限制：碳势太低，供不起所需的通量
- [ ] 扩散系数低于表列值
- [ ] 钢太纯净
- [ ] 装炉的零件靠得太近
::: solution
如果温度对，$D$就对，剩下的唯一杠杆是表面边界条件。一个加时间也快不起来的渗碳循环是表面缺碳，解决办法是提高碳势或气流量，而不是温度——在固定的低碳势下提高温度，只会得到更深、更软、含碳更低的渗层。
:::
:::

::: exercise 铜中的空位 {level=2}
铜的$\Delta H_f = 1.11\ \mathrm{eV}$，熔点$1085\ {}^{\circ}\mathrm{C}$。给出熔点的平衡空位浓度和每立方米的个数。
::: solution
$$
c = \exp \left( - \frac{1.11}{8.617 \times 10^{- 5} \times 1358} \right) = 8.4 \times 10^{- 5} ,
$$
每立方米$8.5 \times 10^{28}$个格点，$n_v = 7.1 \times 10^{24}\ \mathrm{m^{- 3}}$。
**合理性检验。**一万两千个格点一个空位，是铝在自己熔点处数值的五分之一，因为铜的熔点更高、键更强；退火铜试样与淬火铜试样的密度差为$8.4 \times 10^{- 5}$，即每立方厘米$0.7\ \mathrm{mg}$，用一台好天平可以称出，这正是当初得到这个数字的方法。

::: exercise 渗层深度 {level=2}
一种钢按例2渗碳，但在$900\ {}^{\circ}\mathrm{C}$。给出扩散系数和达到同样$0.4\ \%$碳深度$1\ \mathrm{mm}$所需的时间。
::: solution
$$
D = 2.3 \times 10^{- 5} \exp \left( - \frac{148{,}000}{8.314 \times 1173} \right) = 5.9 \times 10^{- 12}\ \mathrm{m^{2} / s} ,
$$
比$1000\ {}^{\circ}\mathrm{C}$的值低$3.3$倍，所以时间按同一因子升到$33\ \mathrm{h}$。
**合理性检验。**一百度换来三倍的时间，这是把渗碳烧到$\gamma$单相区允许的最高温的全部理由，也是反对它的全部理由，因为$912\ {}^{\circ}\mathrm{C}$是碳钢的$\alpha$到$\gamma$边界，越过它表面会随碳势升高而熔化。工业界的折中是$900$到$930\ {}^{\circ}\mathrm{C}$，并在循环结束时把碳势降下来。
:::

::: exercise 扩散推进 {level=2}
硼注入在硅片表面放置一个面源掺杂剂。在$D = 10^{- 17}\ \mathrm{m^{2} / s}$的温度下扩散推进一小时后，若本底浓度要求掺杂剂降到峰值以下$10^{4}$倍，给出结深。
::: solution
由$C / C_{\max} = \exp \left( - x^{2} / 4 D t \right) = 10^{- 4}$：
$$
x = 2 \sqrt{9.21\, D t} = 2 \sqrt{9.21 \times 10^{- 17} \times 3600} = 1.15\ \mu\mathrm{m} .
$$
**合理性检验。**峰值浓度本身按$1 / \sqrt{t}$下降，所以更长的扩散推进使分布在“深”与“浅”两个意义上又深又浅，这就是现代器件使用**快速热处理**——$1050\ {}^{\circ}\mathrm{C}$十秒而不是$900\ {}^{\circ}\mathrm{C}$三十分钟——的原因，它把损伤扩散掉，而平方律使结留在原处。
:::

::: exercise 推导 {level=3}
用相似变换推导表面浓度恒定时菲克第二定律的误差函数解，并说明扩散距离为什么必须是$\sqrt{Dt}$。
::: solution
**先作标度论证。**在$\partial C / \partial t = D \partial^{2} C / \partial x^{2}$中两边必须有相同量纲，所以$x^{2} / t \sim D$，而问题中包含的唯一长度是$\sqrt{D t}$。因此解只能依赖单一变量$\eta = x / \left( 2 \sqrt{D t} \right)$，偏微分方程必然化为常微分方程。
**化简。**取$C (x , t ) = C_0 + \left( C_s - C_0 \right) \left[ 1 - f (\eta ) \right]$，$\eta = x / \left( 2 \sqrt{D t} \right)$，
$$
\frac{\partial C}{\partial t} = \left( C_s - C_0 \right) \left( - f^{\prime} \right) \left( - \frac{\eta}{t} \right),
\qquad
\frac{\partial^{2} C}{\partial x^{2}} = \left( C_s - C_0 \right) \left( - f^{\prime\prime} \right) \frac{1}{4 D t} ,
$$
代入$\partial C / \partial t = D \partial^{2} C / \partial x^{2}$得
$$
f^{\prime\prime} + 2 \eta f^{\prime} = 0
\quad\Longrightarrow\quad
f^{\prime} = A \mathrm{e}^{- \eta^{2}}
\quad\Longrightarrow\quad
f = A \int_0^{\eta} \mathrm{e}^{- u^{2}} \mathrm{d} u + B .
$$
**常数。**$x = 0$处$C \rightarrow C_s$要求$f (0 ) = 0$，所以$B = 0$；$x \rightarrow \infty$处$C \rightarrow C_0$要求$f (\infty ) = 1$，而$\int_0^{\infty} \mathrm{e}^{- u^{2}} \mathrm{d} u = \sqrt{\pi} / 2$，所以$A = 2 / \sqrt{\pi}$。于是$f = \operatorname{erf} \eta$，
$$
\boxed{ \frac{C - C_0}{C_s - C_0} = 1 - \operatorname{erf} \eta = \operatorname{erfc} \eta } . \quad \checkmark
$$
**合理性检验。**相似解形式是为什么在两个不同时刻测得的扩散分布对$x / \sqrt{t}$作图会坍缩成一条曲线，而这种坍缩是过程为**扩散控制**而非表面反应限制的标准实验检验。不坍缩的分布要么受反应限制，要么$D$依赖浓度，两者由马塔诺作图区分。同样的相似结构支配[[materials-science/failure]]蠕变的导热问题和任何瞬态导热，这就是误差函数带着同一张数表出现在五门不同工程学科中的原因。
:::
:::

::: exercise 设计 {level=3}
一枚镍基高温合金叶片涂有$300\ \mu\mathrm{m}$的铝化物扩散涂层，必须在$1000\ {}^{\circ}\mathrm{C}$下$10{,}000\ \mathrm{h}$后表面仍保持$8\ \%$（重量）的铝。已知该温度下涂层中$D_{\mathrm{Al}} = 10^{- 18}\ \mathrm{m^{2} / s}$，判断涂层是否足够厚，并说明还有什么决定它的寿命。
::: solution
**扩散距离。**
$$
2 \sqrt{D t} = 2 \sqrt{10^{- 18} \times 3.6 \times 10^{7}} = 12\ \mu\mathrm{m} .
$$
**结论。**涂层中的铝在一万小时里移动了十二微米；涂层比扩散距离厚二十五倍，穿过它的扩散不是杀死它的机理。
**杀死它的是什么。**三件事，按决定失效的频繁程度排序。热循环中的**氧化皮剥落**，它机械地剥掉涂层，这就是规格取涂层的热循环寿命而不是等温寿命的原因。与基体的**互扩散**，它把$\beta$-NiAl涂层变成脆的$\delta$-Ni₂Al₃，更重要的是耗尽基体的铝和铬、让基体自己氧化。还有**基体自己的耗尽区**，那是一个用基体低得多的扩散系数、扩散距离却长得多的扩散问题，因为基体是一毫米厚而不是一微米。
**设计。**涂层够厚；寿命由热循环规格和活性元素效应决定——几十ppm的钇或铪，把氧化皮钉扎在金属上，使循环寿命提高五倍。

**合理性检验。**这里的算术与下面这条算术相同：热障涂层的陶瓷层，$100\ \mu\mathrm{m}$厚、$D = 10^{- 20}\ \mathrm{m^{2} / s}$，在$10^{4}\ \mathrm{h}$内只在$1.2\ \mu\mathrm{m}$的距离上完成氧的平衡——这就是热障涂层的失效总是在**热生长氧化物**界面、从不在陶瓷内部的原因。涂层系统中的扩散从来不在涂层本身；在两个界面和它们之间那层薄氧化物。
:::
