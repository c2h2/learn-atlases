完美晶体是不可能的，而且不是因为制造不完美。不含空位的晶体的自由能高于含少量空位的晶体，因为把空位混合到格点位置上贡献了一个熵项，在任何高于绝对零度的温度下都没有焓能胜过它。铝在其熔点的空位平衡浓度是四千个格点中有一个，而本课的一切工程后果——扩散、蠕变、烧结、析出、硬化、辐照肿胀、涡轮叶片在一万小时后失效——都源于晶格布满缺陷、因而原子会移动这一事实。

扩散是钢齿轮能外硬内韧的原因，是半导体掺杂剂停在它被注入的地方而不是设计意图所在的原因，是阴极清洗产生的氢原子使高强紧固件脆化的原因，也是铀燃料芯块肿胀的原因。它由一个指数式$D = D_0 \exp \left( - Q / RT \right)$支配，其激活能由缺陷浓度和跃迁频率决定，其数值从铁中的氢到铁中的铁（都在室温下）跨越约四十个数量级。

::: warning 扩散是指数的，所以对它的直觉一文不值
在$1000\ {}^{\circ}\mathrm{C}$约七个半小时就能在齿轮上渗出一毫米渗层的渗碳处理，在$900\ {}^{\circ}\mathrm{C}$需要约二十五小时（[[#ex-carburising]]与习题7）。在$1000\ {}^{\circ}\mathrm{C}$下热电偶仅仅低读$10\ {}^{\circ}\mathrm{C}$，就使$D$改变百分之十二，$20\ {}^{\circ}\mathrm{C}$的误差使它改变百分之二十五。反过来，一种在$500\ {}^{\circ}\mathrm{C}$一周内可测地扩散的材料在$20\ {}^{\circ}\mathrm{C}$可能完全静止，而按高温试验作线性外推的设计师会判一种本来很好的合金死刑、批准一种本来不行的。由此得出三条规则。**绝不把阿伦尼乌斯线外推到它测得时所覆盖的温度范围之外**，因为机理的改变——从晶格扩散到晶界扩散，从本征外到本征内，从空位到间隙——会使直线弯曲，而且通常向下弯。**如果扩散物种是氢、锂、钠或铁中的碳，绝不要假设扩散过程在室温下被冻结**，这几种在环境温度下都移动得足够快，能在数周内产生后果。**也绝不要相信没有校核边界条件就算出的扩散距离**，因为表面浓度恒定的处理和总含量恒定的处理，渗层深度都按$\sqrt{D t}$变化，但乘在前面的常数不同：浓度降到表面值一半处的深度，前者（误差函数分布）为$0.95 \sqrt{D t}$，后者（高斯分布）为$1.67 \sqrt{D t}$，把两者搞混正是通过的齿轮与报废的齿轮之间的区别。
:::

## 点缺陷

::: definition 点缺陷及其名称 {#def-point}
**空位**是格点上缺了一个原子；**自间隙原子**是一个同类多余原子被塞进通常不被占据的位置。**弗伦克尔（Frenkel）缺陷**是一个原子离开自己的格点进入间隙位置所产生的空位-间隙对，在阳离子较小的离子晶体中常见（溴化银）。**肖特基（Schottky）缺陷**是保持电中性的成对阳离子和阴离子空位（氯化钠）。**杂质**若替换基体原子则为**置换式**，若坐在空穴中则为**间隙式**；铁中的碳、氮、氢、硼和氧全部是间隙式的。它们的原子对所占据的空穴来说大得多——BCC铁中八面体间隙的半径为$0.019\ \mathrm{nm}$，而碳为$0.077\ \mathrm{nm}$——由此造成的畸变是钢的强度的一个主要来源。
**能量学。**一个空位花费焓$\Delta H_f^{V}$，为$0.5$到$3\ \mathrm{eV}$，大致与熔点成正比。自间隙原子贵二到四倍，因为它必须把近邻推开，所以其平衡浓度与空位浓度相比可以忽略，主要作为辐照产物存在。从接近熔点淬火保留下来的空位可以凝聚成位错环，在低层错能金属中还可凝聚成层错四面体。
:::

::: proof 为什么空位不可避免 {#proof-vacancies}
取一个含$N$个原子格点、含$n$个空位的晶体。焓为$n \Delta H_f$，而由玻尔兹曼公式和$\binom{N}{n}$种排布，组态熵为
$$
S = k \ln \frac{N !}{n ! \left( N - n \right)!} \approx - N k \left[ c \ln c + \left( 1 - c \right) \ln \left( 1 - c \right) \right], \qquad c = \frac{n}{N} .
$$
因此每格点的自由能为
$$
g (c ) = c \Delta H_f + k T \left[ c \ln c + \left( 1 - c \right) \ln \left( 1 - c \right) \right] .
$$
熵项的导数是$k T \ln \left( c / \left( 1 - c \right) \right)$，当$c \rightarrow 0$时趋于$- \infty$，所以在原点$\mathrm{d} g / \mathrm{d} c < 0$，**无论**$\Delta H_f$**取何值**：添加最初的空位总是降低自由能，因为混合熵的发散比焓的上升更陡。令导数为零并求解，
$$
\boxed{ c = \exp \left( - \frac{\Delta H_f}{k T} \right) }
$$
这里忽略了空位-空位相互作用，并把振动熵归入前置因子。$\checkmark$
**推广。**同样的论证适用于任何点缺陷和任何稀溶质：平衡态是**无序**态，而任何工艺（分子束外延、低温沉积、离子束合成）造出的无缺陷材料在热力学上都不稳定，一旦温度高到原子能移动就会获得自己的缺陷。实践中重要的推论是**淬火**冻结高温浓度，因为$c$从熔点到室温下降许多个数量级——铝接近八个（[[#ex-vacancies]]）——而在金属冷透之前空位到达不了湮灭源。
:::

::: definition 扩散与菲克定律 {#def-fick}
**扩散通量**正比于浓度梯度，
$$
J = - D \frac{\partial C}{\partial x} \quad \left[ \mathrm{mol\, m^{- 2}\, s^{- 1}} \right] ,
$$
把它与质量守恒$\partial C / \partial t = - \partial J / \partial x$结合，对常数$D$得**菲克第二定律**
$$
\frac{\partial C}{\partial t} = D \frac{\partial^{2} C}{\partial x^{2}}
$$
一维问题的两个典型解是：
**表面浓度恒定**$C_s$渗入初始浓度为$C_0$的半无限固体：
$$
\frac{C (x , t ) - C_0}{C_s - C_0} = \operatorname{erfc} \frac{x}{2 \sqrt{D t}} .
$$
**瞬时面源**，单位面积$M$个原子：
$$
C (x , t ) = \frac{M}{\sqrt{\pi D t}} \exp \left( - \frac{x^{2}}{4 D t} \right) ,
$$
其宽度按$\sqrt{D t}$增长，峰值按$1 / \sqrt{D t}$下降，而总面积不变。
两种情形下扩散距离都是
$$
x \sim 2 \sqrt{D t} ,
$$
扩散距离$x$所需的**特征时间**为$t \approx x^{2} / (4 D)$——一个平方律，这就是薄的东西能达到平衡而厚的东西永远不能的原因。
:::

::: widget plot
f: exp(-x*x); 0.5*exp(-x*x/4)
x: -4, 4
y: 0, 1.05
labels: t = t0; t = 4 t0
caption: 瞬时面源在两个时刻的高斯扩展。时间变为四倍时峰值高度减半、宽度加倍，因为曲线下的面积——扩散总质量——守恒。这就是扩散推进工序失去对结深控制的原因：分布没有陡峭的前沿，掺杂剂降到本底浓度以下的深度按$\sqrt{t}$增长，而表面浓度按$1 / \sqrt{t}$下降。
:::

::: definition 温度依赖与三条经验法则 {#def-arrhenius}
$$
D = D_0 \exp \left( - \frac{Q}{R T} \right),
$$
其中$Q$为扩散激活焓。对**空位机理的自扩散**，激活焓是空位形成焓与迁移焓之和，$Q = \Delta H_f + \Delta H_m$，而在整个金属界有三条经验规律成立：
$$
Q_{\mathrm{self}} \approx 18 R T_m , \qquad D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}, \qquad D \left( T_m \right) \approx 10^{- 13}\ \mathrm{m^{2} / s} .
$$
第三条值得注意：**每种金属在自己的熔点都以约$10^{- 13}\ \mathrm{m^{2} / s}$扩散**，从锌到钨都是，这就是烧结规程按绝对熔点的分数给出、而对比温度$T / T_m$是冶金学家唯一使用的温度的原因。间隙扩散的$Q$为$0.1$到$1.2\ \mathrm{eV}$，不含空位项，因此快$10^{4}$到$10^{10}$倍；室温下BCC铁中的氢以约$10^{- 8}\ \mathrm{m^{2} / s}$扩散，比$1000\ {}^{\circ}\mathrm{C}$下铁中的铁（$\approx 10^{- 16}\ \mathrm{m^{2} / s}$）快约$10^{8}$倍。
:::

::: example 平衡空位与淬火空位 {#ex-vacancies}
铝的空位形成焓为$0.66\ \mathrm{eV}$。给出$200\ {}^{\circ}\mathrm{C}$、熔点$660\ {}^{\circ}\mathrm{C}$以及淬火到$20\ {}^{\circ}\mathrm{C}$之后的平衡浓度。
::: solution
**在$200\ {}^{\circ}\mathrm{C} = 473\ \mathrm{K}$：**
$$
c = \exp \left( - \frac{0.66}{8.617 \times 10^{- 5} \times 473} \right) = 9.3 \times 10^{- 8}
$$
一千一百万个格点中一个空位。
**在$660\ {}^{\circ}\mathrm{C} = 933\ \mathrm{K}$：**
$$
c = \exp \left( - 8.19 \right) = 2.7 \times 10^{- 4}
$$
每$3700$个格点一个，即每立方米$1.6 \times 10^{25}$个空位，而格点有$6.0 \times 10^{28}$个。
**淬火到$20\ {}^{\circ}\mathrm{C}$之后：**$293\ \mathrm{K}$的平衡值为$\exp \left( - 26.1 \right) = 4.4 \times 10^{- 12}$，但空位在淬火中来不及扩散到湮灭源，所以金属保留**过饱和**；若高温空位全部保留下来，过饱和度为$2.7 \times 10^{- 4} / 4.4 \times 10^{- 12} \approx 6 \times 10^{7}$——接近八个数量级。随后时效时，过剩空位迁移到湮灭源、加速溶质扩散，并有一部分凝聚成几纳米大的空位环，可在电子显微镜下看到。

**校核。**熔点下每立方米的空位数$1.6 \times 10^{25}$乘以原子体积$1 / \left( 6.0 \times 10^{28} \right) = 1.66 \times 10^{- 29}\ \mathrm{m^{3}}$，得$2.7 \times 10^{- 4}$——与浓度相同的分数，理当如此。正是这部分额外体积使高温试样的宏观长度比其X射线点阵常数增长得稍快，比较两者（西蒙斯与巴卢菲1960年的差分膨胀法）是测定$c$的标准绝对方法。$\checkmark$

**合理性检验。**铝在熔点处实测的空位浓度约为$10^{- 3}$量级，是这个估计的几倍，因为完整的表达式还带有来自形成振动熵的前置因子$\exp \left( S_f / k \right)$，金属中$S_f$约为一到两个$k$。这个简单公式给出了正确的数量级，更有用的是给出了正确的温度依赖关系。
:::
:::

::: example 齿轮渗碳 {#ex-carburising}
一个$0.1\ \%\mathrm{C}$的钢齿轮在$1000\ {}^{\circ}\mathrm{C}$渗碳，气氛使表面保持$1.0\ \%\mathrm{C}$。要在深度$1\ \mathrm{mm}$处达到$0.4\ \%\mathrm{C}$需要多长时间？十小时后渗层深度是多少？
::: solution
**扩散系数。**对$\gamma$-铁中的碳，$D_0 = 2.3 \times 10^{- 5}\ \mathrm{m^{2} / s}$，$Q = 148\ \mathrm{kJ / mol}$：
$$
D = 2.3 \times 10^{- 5} \exp \left( - \frac{148{,}000}{8.314 \times 1273} \right) = 1.94 \times 10^{- 11}\ \mathrm{m^{2} / s} .
$$
**自变量所需的值。**边界条件为$C_s = 1.0$、$C_0 = 0.1$，目标$C_x = 0.4$：
$$
\frac{C_x - C_0}{C_s - C_0} = \frac{0.3}{0.9} = 0.333 = \operatorname{erfc} (z )
\quad\Longrightarrow\quad
\operatorname{erf} (z ) = 0.667, \quad z = 0.684 .
$$
**时间。**由$x = 2 z \sqrt{D t}$：
$$
t = \frac{x^{2}}{4 z^{2} D} = \frac{10^{- 6}}{4 \times 0.468 \times 1.94 \times 10^{- 11}} = 2.75 \times 10^{4}\ \mathrm{s} = 7.6\ \mathrm{h} .
$$
**灵敏度。**温度误差$10\ {}^{\circ}\mathrm{C}$使$D$改变因子$\exp \left[ 17{,}800 \times \left( 1 / 1263 - 1 / 1273 \right) \right] = \exp \left( 0.111 \right) = 1.12$，即$D$变百分之十二，固定时间下渗层深度变**百分之六**。固定深度下所需时间同样变百分之十二；而漂移二十度的炉子使$D$变百分之二十五，使整炉每个齿轮的渗层深度变百分之十二。

**十小时后的渗层深度。**$2 \sqrt{D t} = 2 \sqrt{1.94 \times 10^{- 11} \times 36{,}000} = 2 \times 8.36 \times 10^{- 4} = 1.67\ \mathrm{mm}$，$0.4\ \%$等值线位于$z \times 1.67 = 0.684 \times 1.67 = 1.14\ \mathrm{mm}$。

**校核。**深度之比应为时间之比的平方根：$\sqrt{10 / 7.6} = 1.15$，而$1.14 / 1.00 = 1.14$ $\checkmark$

**合理性检验。**时间的平方根是渗碳经济学的全部：渗层深度加倍需要四倍的时间、四倍的炉时，这就是工业界在炉子寿命和奥氏体晶粒长大允许的范围内尽量烧热（气体渗碳通常$900$到$950\ {}^{\circ}\mathrm{C}$，真空炉更高）的原因，也是用几毫巴乙炔的**低压渗碳**能缩短周期的原因——一部分靠温度更高，一部分靠强渗-扩散交替使表面保持接近碳饱和，使过程受扩散控制而不是受表面反应限制。一个无论跑多久都快不起来的渗碳循环是**表面限制**的，诊断结论是碳势太低，而不是温度不够。
:::
:::

::: example 为什么淬火有效：碳在两种铁中 {#ex-two-irons}
碳在$\alpha$-铁和$\gamma$-铁中都扩散。已知在$\alpha$中$D_0 = 6.2 \times 10^{- 7}\ \mathrm{m^{2} / s}$、$Q = 80\ \mathrm{kJ / mol}$，在$\gamma$中$D_0 = 2.3 \times 10^{- 5}\ \mathrm{m^{2} / s}$、$Q = 148\ \mathrm{kJ / mol}$，在$\gamma$到$\alpha$的转变温度$912\ {}^{\circ}\mathrm{C}$比较两者，并解释其冶金学后果。
::: solution
**在$1185\ \mathrm{K}$：**
$$
D_\alpha = 6.2 \times 10^{- 7} \exp \left( - 8.11 \right) = 1.84 \times 10^{- 10}\ \mathrm{m^{2} / s},
\qquad
D_\gamma = 2.3 \times 10^{- 5} \exp \left( - 15.01 \right) = 6.9 \times 10^{- 12}\ \mathrm{m^{2} / s} .
$$
碳在**堆垛更密的铁中扩散快二十七倍**，正是那个违反直觉的结果。
**为什么。**激活焓是在跃迁鞍点处从相邻铁原子之间的缝隙挤过去所需的能量。FCC铁的间隙**更大**——八面体间隙半径为$0.052\ \mathrm{nm}$，BCC中只有$0.019\ \mathrm{nm}$，这就是奥氏体溶碳量比铁素体高一百倍的原因——但相邻间隙之间的通道很窄。在致密度较低的BCC晶格中，八面体间隙彼此靠得近、相互之间的通道相对开阔，所以$Q$为$80$而不是$148\ \mathrm{kJ / mol}$。溶解度与迁移率是两个不同的问题，答案恰好相反。
**后果。**在$912\ {}^{\circ}\mathrm{C}$，碳在铁素体中一秒内移动$2 \sqrt{1.84 \times 10^{- 10} \times 1} = 2.7 \times 10^{- 5}\ \mathrm{m}$，即二十七微米——远多于形成一片珠光体片层所需的不到一微米。奥氏体之所以能通过**无扩散**切变转变为马氏体，只是因为快速淬火在一两秒内带着钢穿过扩散快的温度区间，降到碳在转变时间尺度内无法移动的温度。钢的淬透性是冷却速度与扩散距离之间的一场比赛。

**校核。**$\gamma$-铁在$912\ {}^{\circ}\mathrm{C}$一秒内的扩散距离为$2 \sqrt{6.9 \times 10^{- 12} \times 1} = 5.2\ \mu\mathrm{m}$，而珠光体片层间距为$0.1$到$1\ \mu\mathrm{m}$量级——所以只要给几秒，珠光体**能**形成。在$550\ {}^{\circ}\mathrm{C}$（$823\ \mathrm{K}$），$D_\gamma$已下降$740$倍到$9.3 \times 10^{- 15}\ \mathrm{m^{2} / s}$，一秒内扩散距离为$0.19\ \mu\mathrm{m}$，仍与细珠光体的片层间距相当，这就是该温度接近转变曲线“鼻尖”的原因；远低于此温度，扩散距离远小于任何片层间距，无扩散的马氏体转变便取而代之。$\checkmark$

**合理性检验。**尽管$D$低二十七倍，钢仍在$\gamma$区渗碳，因为奥氏体在渗碳温度下能溶解$1\ \%$以上的碳，而铁素体至多$0.022\ \%$，大得多的浓度差远远补偿了较低的$D$。它也解释了为什么**渗氮**在$\alpha$区的$500\ {}^{\circ}\mathrm{C}$进行，那里氮扩散快并形成硬质氮化物，在更低温度下得到更硬更薄的渗层且毫无淬火变形。
:::

::: example 互扩散与柯肯达尔效应 {#ex-kirkendall}
纯铜与纯镍的扩散偶在$1000\ {}^{\circ}\mathrm{C}$退火，界面上有一排惰性钼标记。标记朝哪个方向移动？十小时后移动多少？
::: solution
**扩散系数。**在$1273\ \mathrm{K}$，$D_{\mathrm{Cu}\rightarrow \mathrm{Ni}} \approx 7 \times 10^{- 14}$，$D_{\mathrm{Ni}\rightarrow \mathrm{Cu}} \approx 4 \times 10^{- 14}\ \mathrm{m^{2} / s}$：铜进入镍的速度约为镍进入铜的两倍。
**后果。**离开铜侧的铜原子多于到达的镍原子，所以净原子通量指向镍一侧，并由指向铜一侧的净空位通量平衡。铜侧失去晶面并**收缩**，镍侧获得晶面并膨胀，而标记——它们随晶格一起移动——移向铜一侧。这就是**柯肯达尔（Kirkendall）效应**；若两个本征扩散系数相等，它就不会出现。
**孔洞。**收缩侧留下的空位过饱和凝聚成沿原界面的一排孔洞，在显微镜下是一条削弱接头的孔隙带。
**数学。**达肯（Darken）方程给出标记速度和依赖成分的互扩散系数：
$$
\tilde{D} = D_B N_A + D_A N_B , \qquad
v = \left( D_A - D_B \right) \frac{\partial N_A}{\partial x} ,
$$
其中$N_A$、$N_B$为原子分数；而**玻尔兹曼-马塔诺（Boltzmann–Matano）法**通过绕马塔诺面（净通量为零的面）积分，从单个扩散偶的成分分布中提取$\tilde{D} (C )$。

**校核。**取$\Delta D = 3 \times 10^{- 14}\ \mathrm{m^{2} / s}$、成分梯度为每$50\ \mu\mathrm{m}$一个原子分数，$v = 3 \times 10^{- 14} \times 2 \times 10^{4} = 6 \times 10^{- 10}\ \mathrm{m / s}$，若梯度保持不变，十小时标记位移为$6 \times 10^{- 10} \times 36{,}000 = 2.2 \times 10^{- 5}\ \mathrm{m} = 22\ \mu\mathrm{m}$——光学上容易测量。（这里的扩散系数只是用于说明的数量级。）$\checkmark$

**合理性检验。**柯肯达尔效应不是实验室里的奇闻；它是两种不同合金之间的**扩散焊**界面会有一条孔洞带（除非在压力下完成连接）的原因，也是人们刻意制造纳米尺度**柯肯达尔孔洞**来掏空金属纳米壳用于催化的原因。它还是铜与锡-银合金的钎焊接头在两侧长出厚度不等的金属间化合物层、且接头失效在金属间化合物而不是在钎料中的原因。
:::
:::

::: example 设计 {#ex-design-barrier}
硅上的铜互连线必须加扩散阻挡层，使得在$450\ {}^{\circ}\mathrm{C}$下六十分钟内到达硅的铜少于一个单层的百分之一。在$50\ \mathrm{nm}$厚的钽膜、$\mathrm{TiN}$膜和$\mathrm{Ta_2 O_5}$膜之间做选择。
::: solution
**要求。**一侧为恒定源、另一侧为完美湮灭源时，厚$L$的薄膜的透过分数近似为
$$
f \approx \frac{2 \sqrt{D t}}{L} \exp \left( - \frac{L^{2}}{4 D t} \right) \quad \text{当} \ L \gg 2 \sqrt{D t} .
$$
记$u = L^{2} / \left( 4 D t \right)$，这就是$f = \mathrm{e}^{- u} / \sqrt{u}$，$f < 10^{- 2}$要求$u > 3.9$；取$u = 4.0$。取$L = 50\ \mathrm{nm}$、$t = 3600\ \mathrm{s}$，
$$
D < \frac{L^{2}}{4 u t} = \frac{2.5 \times 10^{- 15}}{4 \times 4.0 \times 3600} = 4 \times 10^{- 20}\ \mathrm{m^{2} / s}
$$
在$450\ {}^{\circ}\mathrm{C} = 723\ \mathrm{K}$。
**候选者。**取$D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}$，并取各膜最快路径的示意性激活能：
$$
\begin{array}{l c c}
\text{阻挡层} & Q\ \left[ \mathrm{eV} \right] & D \left( 723\ \mathrm{K} \right)\ \left[ \mathrm{m^{2} / s} \right] \\
\text{钽，晶界路径} & 1.2 & 4 \times 10^{- 14} \\
\mathrm{Ta_2 O_5} & 2.4 & 2 \times 10^{- 22} \\
\mathrm{TiN} & 3.0 & 1 \times 10^{- 26}
\end{array}
$$
**选择。**钽差六个数量级（$4 \times 10^{- 14}$对$4 \times 10^{- 20}$）而不合格，因为铜沿其柱状晶界以低激活能扩散。五氧化二钽以两个数量级的余量合格，但它是绝缘体，会挡在通孔的电流路径上；氮化钛以六个数量级的余量合格且导电，所以按这些数字应选它。
**真实规格。**阻挡层不是靠这个计算验收，而是靠**应力迁移**和**电迁移**试验，而失效模式根本不是体扩散：是铜沿阻挡层与通孔壁之间的**界面**泄漏，这就是现代答案是**钽/氮化钽双层**——Ta润湿铜，$\mathrm{TaN_x}$堵住界面路径——反应溅射沉积总厚$25\ \mathrm{nm}$的原因。

**设计评注。**三条教训可以推广。**失效的阻挡层，其失效路径不是设计所针对的那条**，而在这些温度下，细晶溅射膜中的晶界和界面扩散比晶格扩散快许多个数量级。**没有贯通柱状晶界的非晶或纳米晶阻挡层胜过柱状阻挡层**，原因正在于此。而且**扩散阻挡层同时也是一层力学层**，所以它的厚度由连续性、台阶覆盖和粘附决定，而不是由体扩散计算决定——取$D = 1 \times 10^{- 26}\ \mathrm{m^{2} / s}$，后者只要$L = \sqrt{4 u D t} = 0.03\ \mathrm{nm}$就满足了，还不到一个原子层。
:::
:::

::: history
生理学家**阿道夫·菲克（Adolf Fick）**1855年在苏黎世仿照傅里叶热传导定律提出了他的定律，依据的是盐在水中扩散的实验。固态金属中扩散的第一批定量测量出自**威廉·钱德勒·罗伯茨-奥斯汀（William Chandler Roberts-Austen）**，他在1896年报道了金向固态铅中的扩散。**雅科夫·弗伦克尔（Yakov Frenkel）**1926年引入空位-间隙对，**卡尔·瓦格纳（Carl Wagner）**与**瓦尔特·肖特基（Walter Schottky）**1930年引入离子晶体中的成对空位。**路德维希·玻尔兹曼（Ludwig Boltzmann）**1894年的相似变换，由**马塔诺（Chujiro Matano）**在1933年发展为从单个扩散偶提取依赖浓度的扩散系数的标准方法。**欧内斯特·柯肯达尔（Ernest Kirkendall）**与**爱丽丝·斯米格尔斯卡斯（Alice Smigelskas）**1947年的论文报道，放在铜-黄铜扩散偶界面上的钼丝在退火中发生了移动；**劳伦斯·达肯（Lawrence Darken）**1948年的分析用不相等的本征扩散系数解释了这一移动——许多冶金学家起初抵制这个结果，因为它意味着扩散并不是原子的简单交换。**R. O. 西蒙斯（R. O. Simmons）**与**R. W. 巴卢菲（R. W. Balluffi）**1960年通过比较长度变化与点阵常数变化，直接测定了铝的平衡空位浓度；**艾伦·科特雷尔（Alan Cottrell）**的《晶体中的位错与塑性流动》（*Dislocations and Plastic Flow in Crystals*，1953）和**J. C. 费希尔（J. C. Fisher）**1951年的晶界扩散模型，把缺陷和快速扩散通道纳入了标准图像。
:::

## 后续内容

本课的空位浓度是[[materials-science/phase-transformations]]中析出动力学的迁移率项，[[#ex-two-irons]]中碳在铁中的扩散系数决定了[[materials-science/phase-diagrams]]中铁-碳相图共析反应的时间尺度，扩散距离$\sqrt{Dt}$是[[materials-science/failure]]中蠕变孔洞的长度尺度，而使钢变强的间隙碳，与[[materials-science/dislocations-strengthening]]中使钢在成形后时效的，是同一个原子。

::: summary
- 晶体必须含空位：混合熵在浓度为零时发散，所以自由能极小在$c = \exp \left( - \Delta H_f / k T \right)$，铝在熔点下约四千个格点一个，室温下则少到可以忽略。
- 扩散距离按$\sqrt{Dt}$变化，所以处理时间加倍换来百分之四十的深度，四倍才使深度加倍。
- 自扩散服从三条普适规律：$Q \approx 18 R T_m$、$D_0 \approx 10^{- 5}\ \mathrm{m^{2} / s}$，以及每种金属在熔点$D \approx 10^{- 13}\ \mathrm{m^{2} / s}$。
- 间隙原子比空位扩散快$10^{4}$到$10^{10}$倍，碳在开放结构的BCC铁中比在密堆FCC铁中快二十七倍。
- 本征扩散系数不同，所以晶格本身在移动：柯肯达尔效应、标记运动和界面孔洞证明菲克的对称图像不完整。
- 器件相关温度下的真实扩散走晶界和界面，不走晶格，按晶格扩散设计的阻挡层可能差六个数量级甚至更多而失效。
:::

::: quiz
一个渗碳循环达到规定渗层深度所用的时间是规程要求的两倍，而炉温已核实无误。最可能的原因是什么？
- [x] 过程受表面反应限制：碳势太低，供不起所需的通量
- [ ] 扩散系数低于表列值
- [ ] 钢太纯净
- [ ] 装炉的零件靠得太近
::: solution
如果温度对，$D$就对，剩下的唯一杠杆是表面边界条件。一个加时间也快不起来的渗碳循环是表面缺碳，解决办法是提高碳势或气流量，而不是温度——在固定的低碳势下提高温度，只会得到更深、更软、含碳更低的渗层。
:::
:::

::: exercise 数量级 {level=1 check="7.8"}
取$Q_{\mathrm{self}} \approx 18 R T_m$，金属在绝对熔点一半处的自扩散系数比在熔点处小几个数量级？（输入比值的$\log_{10}$。）
::: solution
$D \left( T_m \right) / D \left( T_m / 2 \right) = \exp \left( 36 - 18 \right) = \mathrm{e}^{18} = 6.6 \times 10^{7}$，$\log_{10} \mathrm{e}^{18} = 18 / 2.303 = 7.8$——接近八个数量级，这就是蠕变和扩散在约$0.4 T_m$以上才重要、在其下几乎无关紧要的原因。

::: exercise 铜中的空位 {level=2}
铜的$\Delta H_f = 1.11\ \mathrm{eV}$，熔点$1085\ {}^{\circ}\mathrm{C}$。给出熔点的平衡空位浓度和每立方米的个数。

c = \exp \left( - \frac{1.11}{8.617 \times 10^{- 5} \times 1358} \right) = \exp \left( - 9.49 \right) = 7.6 \times 10^{- 5} ,
$$
每立方米$8.5 \times 10^{28}$个格点，$n_v = 6.4 \times 10^{24}\ \mathrm{m^{- 3}}$。
**合理性检验。**一万三千个格点一个空位，约为铝在自己熔点处数值的四分之一：比值$\Delta H_f / k T_m$对铜为$9.5$，对铝为$8.2$。相应的密度亏缺是$8.93\ \mathrm{g / cm^{3}}$的$7.6 \times 10^{- 5}$，即每立方厘米$0.68\ \mathrm{mg}$。

一种钢按例2渗碳，但在$900\ {}^{\circ}\mathrm{C}$。给出扩散系数和达到同样$0.4\ \%$碳深度$1\ \mathrm{mm}$所需的时间。
::: solution

D = 2.3 \times 10^{- 5} \exp \left( - \frac{148{,}000}{8.314 \times 1173} \right) = 5.9 \times 10^{- 12}\ \mathrm{m^{2} / s} ,

比$1000\ {}^{\circ}\mathrm{C}$的值低$3.3$倍，所以时间按同一因子从$7.6$升到$25\ \mathrm{h}$。

::: exercise 扩散推进 {level=2 check="1.15"}
硼注入在硅片表面放置一个面源掺杂剂。在$D = 10^{- 17}\ \mathrm{m^{2} / s}$的温度下扩散推进一小时后，若本底浓度要求掺杂剂降到峰值以下$10^{4}$倍，给出结深。（以µm为单位输入深度。）
::: solution
由$C / C_{\max} = \exp \left( - x^{2} / 4 D t \right) = 10^{- 4}$：
$$
x = 2 \sqrt{9.21\, D t} = 2 \sqrt{9.21 \times 10^{- 17} \times 3600} = 1.15\ \mu\mathrm{m} .
$$
**合理性检验。**峰值浓度本身按$1 / \sqrt{t}$下降，所以更长的扩散推进使分布更深但更低，这就是现代器件使用**快速热处理**——约$1050\ {}^{\circ}\mathrm{C}$几秒钟，而不是较低温度下几十分钟——的原因，它退火消除注入损伤，同时使$D t$、从而结深保持很小。
:::

::: exercise 推导 {level=3}
用相似变换推导表面浓度恒定时菲克第二定律的误差函数解，并说明扩散距离为什么必须是$\sqrt{Dt}$。
::: solution
**先作标度论证。**在$\partial C / \partial t = D \partial^{2} C / \partial x^{2}$中两边必须有相同量纲，所以$x^{2} / t \sim D$，而问题中包含的唯一长度是$\sqrt{D t}$。因此解只能依赖单一变量$\eta = x / \left( 2 \sqrt{D t} \right)$，偏微分方程必然化为常微分方程。
**化简。**取$C (x , t ) = C_0 + \left( C_s - C_0 \right) \left[ 1 - f (\eta ) \right]$，$\eta = x / \left( 2 \sqrt{D t} \right)$，
$$
\frac{\partial C}{\partial t} = \left( C_s - C_0 \right) \left( - f^{\prime} \right) \left( - \frac{\eta}{2 t} \right),
\qquad
\frac{\partial^{2} C}{\partial x^{2}} = \left( C_s - C_0 \right) \left( - f^{\prime\prime} \right) \frac{1}{4 D t} ,
$$
代入$\partial C / \partial t = D \partial^{2} C / \partial x^{2}$得
$$
f^{\prime\prime} + 2 \eta f^{\prime} = 0
\quad\Longrightarrow\quad
f^{\prime} = A \mathrm{e}^{- \eta^{2}}
\quad\Longrightarrow\quad
f = A \int_0^{\eta} \mathrm{e}^{- u^{2}} \mathrm{d} u + B .
$$
**常数。**$x = 0$处$C \rightarrow C_s$要求$f (0 ) = 0$，所以$B = 0$；$x \rightarrow \infty$处$C \rightarrow C_0$要求$f (\infty ) = 1$，而$\int_0^{\infty} \mathrm{e}^{- u^{2}} \mathrm{d} u = \sqrt{\pi} / 2$，所以$A = 2 / \sqrt{\pi}$。于是$f = \operatorname{erf} \eta$，
$$
\boxed{ \frac{C - C_0}{C_s - C_0} = 1 - \operatorname{erf} \eta = \operatorname{erfc} \eta } . \quad \checkmark
$$
**合理性检验。**相似解形式是为什么在两个不同时刻测得的扩散分布对$x / \sqrt{t}$作图会坍缩成一条曲线，而这种坍缩是过程为**扩散控制**而非表面反应限制的标准实验检验。不坍缩的分布要么受反应限制，要么$D$依赖浓度，两者由马塔诺作图区分。同样的相似结构支配向半无限固体的瞬态导热，这就是误差函数带着同一张数表出现在多门工程学科中的原因。
:::
:::

::: exercise 设计 {level=3}
一枚镍基高温合金叶片涂有$300\ \mu\mathrm{m}$的铝化物扩散涂层，必须在$1000\ {}^{\circ}\mathrm{C}$下$10{,}000\ \mathrm{h}$后表面仍保持$8\ \%$（重量）的铝。已知该温度下涂层中$D_{\mathrm{Al}} = 10^{- 18}\ \mathrm{m^{2} / s}$，判断涂层是否足够厚，并说明还有什么决定它的寿命。
::: solution
**扩散距离。**
$$
2 \sqrt{D t} = 2 \sqrt{10^{- 18} \times 3.6 \times 10^{7}} = 12\ \mu\mathrm{m} .
$$
**结论。**涂层中的铝在一万小时里移动了十二微米；涂层比扩散距离厚二十五倍，穿过它的扩散不是杀死它的机理。
**杀死它的是什么。**三件事，按决定失效的频繁程度排序。热循环中的**氧化皮剥落**，它机械地剥掉涂层，这就是规格取涂层的热循环寿命而不是等温寿命的原因。与基体的**互扩散**，它随着铝的流失把$\beta$-NiAl涂层逐渐转变为$\gamma^{\prime}$-Ni₃Al，更重要的是耗尽基体的铝和铬、让基体自己氧化。还有**基体自己的耗尽区**，那是一个用基体低得多的扩散系数、扩散距离却长得多的扩散问题，因为基体是一毫米厚而不是一微米。
**设计。**涂层够厚；寿命由热循环规格和活性元素效应决定——少量的钇或铪改善氧化皮的附着，使其循环寿命成倍提高。

**合理性检验。**同样的算术提醒我们，不要以为陶瓷面层是扩散阻挡层。热障涂层所用的氧化钇稳定氧化锆是氧离子导体，很容易让氧通过，所以其下的粘结层照样氧化，这类涂层通常在粘结层与陶瓷之间的**热生长氧化物**处或其附近失效。涂层系统的寿命由界面决定。
:::
