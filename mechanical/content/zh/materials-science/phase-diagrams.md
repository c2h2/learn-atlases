相图是一张自由能极小值地图。图上每一条线都是使两次公切线作图给出同一答案的温度与成分的轨迹，每一个区域都是同一曲面的同一种弯曲，而液相线、固相线、固溶线与共晶线这一整套精巧的装置，只是一个条件的二维投影：每一种组元在每个含有它的相中的化学势都相等。

这就是相图如此有用、也如此被误用的原因。它们是平衡地图，而几乎每一个工程过程——铸造、焊接、热处理、时效、烧结、高温服役——都是对平衡的偏离，偏离的程度才是有意思的部分。一个熔池在几秒内凝固，其冷却速率是相图作者从未考虑过的，它留下的偏析芯组织就是相图的答案减去本该发生的扩散。一个时效合金是故意在错误的温度上读相图。而一支室温下的工具钢里含有平衡相图所不容的渗碳体，因为渗碳体是亚稳的，而且一百年来一直如此。

::: warning 先读坐标轴，再读相区
四个错误造成了相图对设计师的大部分伤害。**在多数工程相图上成分以重量百分数计，而在多数物理相图上以原子百分数计**，两者相差一个$M_B / M_A$因子——对$\mathrm{Al - 12\ \%\ Si}$，硅的原子分数是$12.2$百分数，而不是$12$除以什么数；对钨合金，这个差别达到百分之五十。**相图是一个大气压下的截面**，所以任何含挥发性组元的体系——锂、镁、锌、锰、氮、氧——在真空或渗氮气氛中进行工艺时都会移动，而$\mathrm{TiAl}$合金的氮含量根本不在$\mathrm{Ti - Al}$相图上。**每一条线都是平衡线**，所以每秒一度的冷却速率会把转变过冷几十度，把边界放到相图没有放的地方；[[materials-science/phase-transformations]]的连续冷却转变图才是那个修正，也是热处理工人实际使用的那张图。而且**相区不是组织**：相图告诉你相分数和成分，对相的形状、间距与连续性——性质真正所在之处——却一字不提。共晶组织与包晶组织可以有一样的相分数，蠕变强度却差五倍。
:::

## 平衡与相律

::: definition 平衡条件与相律 {#def-phase-rule}
对$C$个组元、$P$个相处于平衡的系统，温度、压力以及每种组元的化学势都是均匀的：
$$
T^{\alpha} = T^{\beta}, \quad p^{\alpha} = p^{\beta}, \quad
\mu_{i}^{\alpha} = \mu_{i}^{\beta} \quad \text{对每个 } i .
$$
每个相由$C - 1$个独立成分变量加上$T$和$p$描述，而每一个化学势相等条件消去一个自由度。这个计数就是**吉布斯相律**
$$
F = C - P + 2 ,
$$
在定压下——所有工程相图都是这样画的——$F = C - P + 1$。
**怎么读。**二元相图的单相区有$F = 2$：温度和成分都自由。两个共存相有$F = 1$：固定温度，结线就固定了两个成分。二元系中三个相有$F = 0$：共晶是一个**不变**点，在一个温度、一个成分上，这就是共晶合金像金属一样铸造、像液体一样凝固的原因。二元系中四个相不可能在平衡下共存。
:::

::: definition 公切线作图与杠杆定律 {#def-lever}
在温度$T$下，平衡相组合是自由能曲线$G^{\alpha} (x )$与$G^{\beta} (x )$的**公切线**：切线在各自的相成分处接触每条曲线，而两个切点之间的任何总成分都会通过沿$G$图上一条直线分裂成两相来降低自由能。公切线作图的结线端点就是相界成分，整个二元相图就是这些作图的一叠堆叠。
对总成分$x_0$、处于两相区且相成分为$x_{\alpha}$与$x_{\beta}$的合金，**质量守恒**给出相分数
$$
f_{\alpha} = \frac{x_{\beta} - x_0}{x_{\beta} - x_{\alpha}}, \qquad
f_{\beta} = \frac{x_0 - x_{\alpha}}{x_{\beta} - x_{\alpha}}, \qquad f_{\alpha} + f_{\beta} = 1 ,
$$
这就是**杠杆定律**：一个相的分数是支点*另一侧*结线长度除以整条结线。它就是质量守恒的陈述，别无其他，所以它在重量百分数坐标的重量相图上按重量百分数成立，在原子百分数坐标的原子相图上按原子百分数成立，而在两者混用时绝不成立。
:::

::: definition 同晶系、枝晶偏析与休姆-罗瑟里规则 {#def-isomorphous}
晶体结构相同、原子半径相差在百分之十五以内、电负性相近、化合价相同的两个元素形成**连续固溶体**——铜镍、金银、镍铜、钼钨——相图是液相线与固相线之间的一个透镜形区域，任何地方都没有不变反应。
平衡冷却一个同晶合金得到均匀固体。以任何实际速率冷却则产生**枝晶偏析**：先凝固的固体比最后凝固的富高熔点组元，而固相中的扩散太慢，抹不平这个梯度。因此一个$50\ \%$的铜镍枝晶轴心含镍$60\ \%$、表面含镍$40\ \%$，而最后凝固的液体富低熔点组元富到可以在平衡固相线以下凝固，并在下次重新加热时产生**开始熔化**。解药是在固相线以下做十到四十小时的**均匀化退火**，这也是锻制压力容器壳体在淬火前先做均匀化的原因。
:::

::: definition 共晶、包晶与偏晶 {#def-eutectic}
$$
\textbf{共晶:} \quad L \rightleftharpoons \alpha + \beta
\qquad
\textbf{包晶:} \quad L + \alpha \rightleftharpoons \beta
\qquad
\textbf{偏晶:} \quad L_1 \rightleftharpoons \alpha + L_2
$$
共晶是系统的最低熔点成分，在单一温度下凝固成一种**两相交织组织**，其片层间距由冷却速率通过扩散距离$\sqrt{D t}$决定——$\mathrm{Al - Si}$共晶中典型为$0.5$到$2\ \mu\mathrm{m}$，快凝组织中为$0.1\ \mu\mathrm{m}$。包晶比看上去慢，因为新相$\beta$在旧相$\alpha$**周围**形成，随后必须**穿过$\beta$**扩散生长，而穿过$\beta$生长更慢；所以包晶合金的铸态在平衡固相线以下很远仍保留未溶解的$\alpha$，这正是镍基高温合金或铜锡铸锭的偏析与中心疏松的根源。
**同成分**熔化，$\text{化合物} \rightarrow L$成分不变，在液相线上给出一个峰（工程系中的$\mathrm{Mg_2 Si}$、$\mathrm{Ni_3 Al}$、$\mathrm{Ti_3 Al}$）；**异成分**熔化在加热时分解化合物，原地留下一个包晶或偏晶反应。
:::

caption: 一个双势阱形式的示意自由能曲线，它产生共晶。在两个极小值之间任何总成分处的平衡相组合是连接两个极小值的直线——公切线——而相成分就是切点。切线水平之处，两相稳定性相同，系统处于共晶。曲线中心处的曲率变为正之处，单相固体对任何成分涨落失稳，无需形核势垒即可分解：那就是[[materials-science/phase-transformations]]的调幅分解线。

::: definition 活度与液相线的形状 {#def-activity}
组元的化学势为$\mu_{i} = \mu_{i}^{\circ} + RT \ln a_i$，其中$a_i = \gamma_{i} x_{i}$是**活度**，而平衡要求每种组元的活度在两相中相等——不是浓度相等。**正规溶液**的
$$
\Delta G_{\mathrm{mix}} = \Omega\, x \left( 1 - x \right) + R T \left[ x \ln x + \left( 1 - x \right) \ln \left( 1 - x \right) \right] ,
$$
$\Omega$为交互作用参数，仅熵项一项就保证在稀薄极限处$\Delta G_{\mathrm{mix}} < 0$，这就是**每一种**固体都溶解一些**其他每一种**固体的原因。相分离要求$\Omega$压过熵，而在$x = 0.5$处$\mathrm{d}^{2} G / \mathrm{d} x^{2} = 0$的条件给出**临界固溶温度**
$$
T_{c} = \frac{\Omega}{2 R} ,
$$
所以$\Omega = 17\ \mathrm{kJ / mol}$给出$T_{c} = 749\ {}^{\circ}\mathrm{C}$，而$\Omega$接近零的铜镍系在其固相线以上的所有温度完全互溶。
**凝固点降低。**对稀理想溶液，液相线自熔点的下降为
$$
\ln \left( 1 - x_{B} \right) = - \frac{\Delta H_f}{R} \left( \frac{1}{T} - \frac{1}{T_{m}} \right) ,
$$
它只需要熔化焓，就能把铝硅共晶预测到三度以内。
:::

::: example 读取二元相图 {#ex-cuni}
一个$50\ \%$铜-$50\ \%$镍合金缓慢冷却。给出最初固体的成分、$1300\ {}^{\circ}\mathrm{C}$下的固相分数、最后液体的成分，并说明真实的铸造组织含有什么。
::: solution
**最初固体。**$50\ \%$Ni处的液相线为$1345\ {}^{\circ}\mathrm{C}$；该温度下固相线成分为$62\ \%$Ni。所以第一批枝晶臂是**$62\ \%$的镍**，比熔体富十二个点。
**在$1300\ {}^{\circ}\mathrm{C}$。**结线从固相线成分$42\ \%$Ni延伸到液相线成分$58\ \%$Ni，所以
$$
f_L = \frac{50 - 42}{58 - 42} = 0.50 ,
$$
恰好一半是固体，两相相差十六个镍点。
**最后液体。**平衡下总成分$50\ \%$处的固相线在$1280\ {}^{\circ}\mathrm{C}$达到。在任何实际冷却速率下，最后的液体是$1300\ {}^{\circ}\mathrm{C}$结线上$58\ \%$Ni的成分甚至更低熔的成分，它在枝晶臂之间最后凝固。
**真实组织。**一片带偏析芯的枝晶阵列，镍含量从轴线处的$62\ \%$降到臂界处的$40\ \%$，在$200\ \mu\mathrm{m}$的距离上偏析二十二个点；凝固区间平衡相图说是$65$度，电子探针说是$90$。

**校核。**偏析幅度按枝晶臂的佩克莱数标度，并随臂间距趋于零而消失，这就是以每小时一厘米生长的**单晶**铸件均匀而砂型铸件不均匀的原因，也是均匀化时间按**枝晶臂间距的平方**变化的原因：$t \approx \lambda_{2}^{2} / D$，对$\lambda_{2} = 200\ \mu\mathrm{m}$、$1200\ {}^{\circ}\mathrm{C}$下$D = 10^{- 14}\ \mathrm{m^{2} / s}$，得$4 \times 10^{6}\ \mathrm{s}$，四十五小时。$\checkmark$

**合理性检验。**四十五小时的均匀化正是大型铜镍合金或镍合金铸锭的工业实践，也是工业界五十年来转向**真空电弧重熔**的原因——后者靠快速冷却把枝晶做小，而不是等着扩散去抹平它们。
:::

::: example 自我预测的共晶 {#ex-alsi}
由铝的熔化焓预测铝硅系的共晶温度，并与实测的$577\ {}^{\circ}\mathrm{C}$比较。
::: solution
**成分。**按重量$12.6\ \%$的硅是
$$
x_{\mathrm{Si}} = \frac{12.6 / 28.1}{12.6 / 28.1 + 87.4 / 26.98} = 0.122 \text{原子} .
$$
**凝固点降低。**取$\Delta H_f = 10.7\ \mathrm{kJ / mol}$、$T_{m} = 933\ \mathrm{K}$，
$$
\ln \left( 1 - 0.122 \right) = - 0.130 = - \frac{10{,}700}{8.314} \left( \frac{1}{T} - \frac{1}{933} \right)
\quad\Longrightarrow\quad
T = 853\ \mathrm{K} = 580\ {}^{\circ}\mathrm{C} .
$$
**比较。**实测共晶为$577\ {}^{\circ}\mathrm{C}$，只差三度，而模型只有**一个**参数、没有可调常数。
**为什么灵。**铝和硅电负性接近，液体近乎理想，所以$\gamma_{\mathrm{Al}} \approx 1$，理想表达式就是全部答案。同样的计算用于铅锡得$170\ {}^{\circ}\mathrm{C}$，实测$183\ {}^{\circ}\mathrm{C}$，差十三度，因为铅锡液体的$\Omega \approx 3.5\ \mathrm{kJ / mol}$，锡在共晶处的活度系数为$1.4$。

**校核。**共晶成分由两条液相线的交点决定，理想表达式的富铝液相线在$12.4$原子百分数处到达富硅分支，实测为$12.6$——成分误差百分之二。$\checkmark$

**合理性检验。**液体近乎理想正是$\mathrm{Al - Si}$成为如此优良的铸造合金的原因：凝固区间窄，$12.6\ \%$处一个不变点，共晶能自己补缩。问题在**形貌**而不在相图——共晶硅长成脆性薄片——解药是百万分之五的钠或锶添加，它毒化硅的双晶面生长，把薄片变成珊瑚状。这是一张对性质一字不提的相图和一个决定性质的组织。
:::

::: example 仔细读取铁碳相图 {#ex-fe-c}
给出$0.40\ \%$碳钢在共析温度稍上方和稍下方的相及其分数，以及$1.0\ \%$碳工具钢在室温下的相。渗碳体凭什么画在相图上？
::: solution
**在$727\ {}^{\circ}\mathrm{C}$稍上方。**$0.40\ \%$C的奥氏体加$0.022\ \%$C的先共析铁素体：
$$
f_{\alpha} = \frac{0.76 - 0.40}{0.76 - 0.022} = 0.49 , \qquad f_\gamma = 0.51 .
$$
**在$727\ {}^{\circ}\mathrm{C}$稍下方。**奥氏体已变成**珠光体**，一种层片状铁素体-渗碳体交织组织，所以相分数不变，但组织现在是两个组成物：$49\ \%$白色的先共析铁素体和$51\ \%$暗色的珠光体，这正是抛光并用硝酸酒精侵蚀的1040钢在显微镜下的样子。
**室温总渗碳体。**$\mathrm{Fe_3C}$含$6.67\ \%$C、铁素体含$0.022\ \%$，
$$
f_{\mathrm{Fe_3 C}} = \frac{0.40 - 0.022}{6.67 - 0.022} = 0.057 ,
$$
所以低碳钢按质量$94\ \%$是铁素体，渗碳体以极少的量干了极大的事。
**$1.0\ \%$工具钢。**$f_{\mathrm{Fe_3 C}} = \left( 1.0 - 0.022 \right) / 6.648 = 0.147$，其中$5.6$百分数是珠光体里的共析渗碳体，$9.1$百分数是**先共析渗碳体**，沉积在原始奥氏体晶界上——一个连续的脆性网络，这就是$1.0\ \%$钢切削加工前要球化处理的原因，也是过热的、带渗碳体网络的工具无法用任何热处理挽救的原因。
**渗碳体为什么在图上。**铁碳平衡是$\mathrm{Fe} + \mathrm{C}$（石墨）；渗碳体是**亚稳**的。稳定相图只比亚稳相图低几毫焦，而转变为石墨需要碳的形核，慢到普通碳钢在$20\ {}^{\circ}\mathrm{C}$放一百年仍是$\mathrm{Fe - Fe_3 C}$。硅加到百分之二就催化石墨化，把相图变成稳定的——这正是**铸铁**有石墨、可切削，而**钢**不是的原因。

**校核。**共析成分$0.76\ \%$与共析温度$727\ {}^{\circ}\mathrm{C}$是现代数值；旧的$0.80\ \%$与$723\ {}^{\circ}\mathrm{C}$出现在每一本1980年以前的手册里，它们把$0.40\ \%$钢的先共析分数从$0.49$移到$0.53$。$\checkmark$

**合理性检验。**先共析铁素体$0.49$的分数，就是热轧态1040屈服强度$390\ \mathrm{MPa}$而1080有$490$的原因：珠光体分数从$51$百分数升到$95$百分数，而珠光体的强度由其**片层间距**决定，片层间距由穿过共晶的冷却速率决定，而不由相图决定。相图给出分数；加工给出间距；性质主要是间距。

::: example 纳米尺度溶解度与吉布斯-汤姆孙效应 {#ex-gibbs-thomson}
在$473\ \mathrm{K}$下，半径为$50$、$10$和$2\ \mathrm{nm}$的析出物，其界面能为$0.5\ \mathrm{J / m^{2}}$、摩尔体积为$10^{- 5}\ \mathrm{m^{3} / mol}$，周围基体的平衡基体浓度被提高多少倍？
::: solution
$$
\frac{c_{r}}{c_{\infty}} = \exp \left( \frac{2 \gamma V_{m}}{r R T} \right) ,
\qquad
\frac{2 \gamma V_{m}}{R T} = \frac{2 \times 0.5 \times 10^{- 5}}{8.314 \times 473} = 2.54 \times 10^{- 9}\ \mathrm{m} .
$$
$$
\begin{array}{c c}
r\ \left[ \mathrm{nm} \right] & c_{r} / c_{\infty} \\
50 & 1.05 \\
10 & 1.29 \\
2 & 3.6
\end{array}
$$
**后果。**一个$2\ \mathrm{nm}$的析出物所处的基体相对远场**过饱和三点五倍**，所以同一温度下任何后续保温中它会重新溶解，而大颗粒在长大——**奥斯特瓦尔德熟化**，也是一个峰值时效合金在温炉里放一周比按时效正确九小时的同一合金更软的原因。
**另一个后果。**同一个倍数也是铝铜合金中**GPB区**能保持四倍平衡溶质、薄的共格析出物具有相图不允许的成分、以及相图对每次时效处理第一个小时保持沉默的原因。

**校核。**吉布斯-汤姆孙长度$2 \gamma V_{m} / R T$在$473\ \mathrm{K}$为$2.5\ \mathrm{nm}$，在$950\ \mathrm{K}$为$1.2\ \mathrm{nm}$，所以这是一个纳米尺度现象，在任何温度下颗粒尺寸超过约$50\ \mathrm{nm}$都可忽略——这正是平衡相图停止成为有用工程文件的长度尺度。$\checkmark$

**合理性检验。**同样这个$2.5\ \mathrm{nm}$的长度支配枝晶尖端的**毛细**修正、弥散相的粗化、粉末压坯的烧结应力。它是纳米晶合金相界移动的原因，是薄膜固相线低于块样固相线的原因，也是相图是一份**大颗粒**文件、在一百纳米以下必须修正的原因。

::: example 设计 {#ex-design-weld}
一个Al-Mg-Si的6061-T6支架用4043（Al-12Si）焊丝焊接。预测焊缝横截面上的组织、强度分布和破坏位置。
::: solution
**母材。**6061靠$\beta^{\prime\prime}\ \mathrm{Mg_2 Si}$强化，其固溶线在$460\ {}^{\circ}\mathrm{C}$附近，所以固溶处理温度为$530$到$540\ {}^{\circ}\mathrm{C}$——高到足以溶解$\mathrm{Mg_2 Si}$，又远低于$555\ {}^{\circ}\mathrm{C}$的铝镁硅共晶。其时效温度为$177\ {}^{\circ}\mathrm{C}$。
**焊接热循环。**TIG焊缝在熔合区峰值达$2000\ {}^{\circ}\mathrm{C}$，并以每秒一到十度的速率穿过$500\ {}^{\circ}\mathrm{C}$。把支架分成四个区：
1. **熔合区。**4043焊丝，亚共晶，在$577$到$610\ {}^{\circ}\mathrm{C}$区间内凝固，先共晶$\alpha$-Al枝晶，其间是共晶硅。铸态、未时效，其$\mathrm{Mg_2 Si}$无法析出，因为镁已跑进共晶的粗大$\mathrm{Mg_2 Si}$片里。强度$110\ \mathrm{MPa}$。
2. **柱状铸造织构区。**柱状晶从母材质点外延生长，具有强$\left\langle 100\right\rangle$织构，并易沿最后凝固的中心线产生**热裂纹**。
3. **热影响区，过时效。**峰值温度$200$到$530\ {}^{\circ}\mathrm{C}$：$\beta^{\prime\prime}$析出物粗化为$\beta^{\prime}$，再变成平衡$\beta\ \mathrm{Mg_2 Si}$，合金不可逆地失去强度。这是一条$5$到$8\ \mathrm{mm}$宽的带，是整个构件里最弱的金属。
4. **热影响区，固溶态。**峰值温度$530$到$555\ {}^{\circ}\mathrm{C}$：析出物完全溶解，该区软得像T4板材，但冷却到室温时发生**淬火时效**，在室温放一周恢复三分之一的强度。
**破坏。**在**过时效热影响区**，$150$到$170\ \mathrm{MPa}$，而母材为$276\ \mathrm{MPa}$——损失$40\ \%$，6061-T6的MIG焊接头效率被引用为$0.5$到$0.6$，正是这个原因。
**设计对策。**在时效**之前**指定焊接：在T4状态下成形并焊接，然后对整个构件做固溶加时效——这就是自行车架用T6管材TIG焊接后再时效的原因，也是再时效能恢复$85\ \%$接头强度的原因。构件太大时，在**5000系**母材上用**5000系**或**4000系**焊丝，它根本不有时效强化，什么也不损失。

**设计评注。**这个例子教的一般规则是：**焊缝会毁掉其一厘米范围内的热处理，任何焊丝都修不好这一点**。三个诚实的选项是：在软状态下焊接再对构件重新热处理；使用不可热处理强化合金；或者设计接头使热影响区不是危险截面。不诚实的是在焊接图上给构件指定母材的T6性能。

## 后续内容

本讲的平衡相分数，在施加上冷却速率后就变成[[materials-science/phase-transformations]]的转变动力学；例5的析出物是[[materials-science/dislocations-strengthening]]的奥罗万障碍；例4的渗碳体网络是[[materials-science/failure]]的裂纹路径；例6的焊缝热影响区是施加于冷却半空间的[[mechanics-of-materials]]残余应力问题。

::: summary
- 相图是自由能曲线叠上公切线作图的地图；相律$F = C - P + 1$数的是在一个相消失之前你可以改变什么。
- 杠杆定律只是质量守恒，且只在坐标轴所用的单位下成立。
- 同晶系冷却时产生枝晶偏析，均匀化所需时间等于枝晶臂间距的平方除以扩散系数。
- 共晶是不变的，在单一温度凝固，承载性质的是它的间距——而不是分数。
- 单参数理想凝固点降低把铝硅共晶预测到三度以内；铅锡需要活度系数。
- 在约一百纳米以下，吉布斯-汤姆孙项使相图失效，而每次时效处理都发生在那里。
:::

::: quiz
一个成分恰好为共晶的合金缓慢冷却。哪个说法正确？
- [x] 它在单一温度凝固，两个固相同时生成长成交织组织
- [ ] 它在液相线与固相线之间的整个区间内凝固
- [ ] 一个相先生成，另一个填满最后的液体
- [ ] 没有过冷它就无法凝固
::: solution
在共晶成分处，液体在定压下$F = 0$，所以在单一温度同时转变为两个固相。这正是共晶合金可铸造的原因——它没有糊状区，所以能把液体补缩到最后凝固的地方，不会在截面中间形成缩孔。
:::

::: exercise 枝晶偏析 {level=2}
一个铜镍枝晶的臂间距为$100\ \mu\mathrm{m}$。估计在$D = 3 \times 10^{- 14}\ \mathrm{m^{2} / s}$的温度下的均匀化时间。
::: solution
$$
t \approx \frac{\left( 100 \times 10^{- 6} \right)^{2}}{4 \times 3 \times 10^{- 14}} = 8.3 \times 10^{4}\ \mathrm{s} = 23\ \mathrm{h} .
$$
**合理性检验。**通过更快冷却把枝晶臂间距减半，均匀化时间降到四分之一，这就是在意均匀性时熔模铸造、冷铁铸造和快凝胜过砂型铸造的全部理由。它也是为什么大铸锭要均匀化几天而薄带在同一温度只要几分钟。

::: exercise 铁碳 {level=2}
给出$0.30\ \%$和$0.90\ \%$碳钢在共析温度稍下方的珠光体分数。
::: solution
对亚共析钢，珠光体分数就是共析温度下的奥氏体分数，
$$
f_{\mathrm{pearlite}, 0.30} = \frac{0.30 - 0.022}{0.76 - 0.022} = 0.38 .
$$
对过共析钢，先共析相是渗碳体，所以
$$
f_{\mathrm{pearlite}, 0.90} = \frac{6.67 - 0.90}{6.67 - 0.022} = 0.88 .
$$
**合理性检验。**普通碳钢的强度随珠光体分数上升，到约$0.85\ \%$碳时达到最大，然后**下降**，因为先共析渗碳体网络变得连续，断裂变为沿晶。这就是共析钢是最强的普通碳钢、而$1.2\ \%$钢更弱的原因，也是轴承钢是过共析的但要做球化处理的原因——球化后碳化物是球状的，不存在网络。
:::

::: exercise 正规溶液 {level=2}
一个二元系的交互作用参数$\Omega = 12\ \mathrm{kJ / mol}$。给出临界固溶温度，并判断系统在$500\ {}^{\circ}\mathrm{C}$是否互溶。
::: solution
$$
T_{c} = \frac{\Omega}{2 R} = \frac{12{,}000}{2 \times 8.314} = 722\ \mathrm{K} = 449\ {}^{\circ}\mathrm{C} .
$$
在$500\ {}^{\circ}\mathrm{C}$系统**高于**$T_{c}$，完全互溶；在$400\ {}^{\circ}\mathrm{C}$低于$T_{c}$，发生分离。
**合理性检验。**这就是每一次调幅分解的算术，包括Cu-Ni-Fe"Coprecip"软磁家族的铜镍铁合金，以及铁铬的$\alpha^{\prime}$分解——后者发生在$500\ {}^{\circ}\mathrm{C}$以下，临界成分在$46\ \%$铬附近，使长期停在$475\ {}^{\circ}\mathrm{C}$的双相不锈钢脆化——即文献中的"475脆性"，它不过是铬铁相图上的一个混溶隙。

::: exercise 推导 {level=3}
由质量守恒推导杠杆定律，并由吉布斯-汤姆孙论证推导共格析出物平衡成分的条件。
::: solution
**杠杆定律。**一千克成分为$x_0$的合金含$x_0$千克溶质。它分成$f_{\alpha}$千克成分为$x_{\alpha}$的$\alpha$相和$f_{\beta}$千克成分为$x_{\beta}$的$\beta$相，所以
$$
f_{\alpha} + f_{\beta} = 1 , \qquad
f_{\alpha} x_{\alpha} + f_{\beta} x_{\beta} = x_0 .
$$
代入$f_{\beta} = 1 - f_{\alpha}$，
$$
f_{\alpha} x_{\alpha} + x_{\beta} - f_{\alpha} x_{\beta} = x_0
\quad\Longrightarrow\quad
f_{\alpha} = \frac{x_{\beta} - x_0}{x_{\beta} - x_{\alpha}} . \quad \checkmark
$$
对溶质做同样的守恒给出$f_{\beta} = \left( x_0 - x_{\alpha} \right) / \left( x_{\beta} - x_{\alpha} \right)$，两式恒等地相加为一。注意推导只用了质量守恒，这就是杠杆定律在热力学的一切改进中幸存、而只在相图单位混用时失效的原因。
**吉布斯-汤姆孙条件。**从过饱和基体中形成半径为$r$的球形析出物的自由能为
$$
\Delta G = \frac{4}{3} \pi r^{3} \Delta g_v + 4 \pi r^{2} \gamma ,
$$
界面两侧的压力差为$\Delta p = 2 \gamma / r$。对稀溶液，基体中溶质的化学势为$\mu = \mu^{\circ} + R T \ln c$，压力把析出物的势提高$V_m \Delta p = 2 \gamma V_{m} / r$。令两者相等，
$$
R T \ln \frac{c_{r}}{c_{\infty}} = \frac{2 \gamma V_{m}}{r}
\quad\Longrightarrow\quad
\boxed{ c_{r} = c_{\infty} \exp \left( \frac{2 \gamma V_{m}}{r R T} \right) } . \quad \checkmark
$$
**合理性检验。**有两个从公式看不显然的推论。第一，$c_{r}$随$r$增大而减小，所以小颗粒溶解而大颗粒以小颗粒为代价长大——奥斯特瓦尔德熟化——平均半径因此必按$t^{1 / 3}$长大，这就是**利夫希茨-斯柳佐夫-瓦格纳（Lifshitz-Slyozov-Wagner）**律，也是时效曲线有峰值的原因。第二，推导假设了界面是**非共格**的；对共格界面，应变能加上一项不按$1 / r$标度的项，这就是共格的GPB区可以过饱和到远超非共格颗粒预测值的原因，也是铝铜中析出的第一阶段根本不是平衡现象的原因。
:::

::: exercise 设计 {level=3}
为一个将在$- 40\ {}^{\circ}\mathrm{C}$与$125\ {}^{\circ}\mathrm{C}$之间循环的功率模块选择焊料合金，并对照相图论证。
::: solution
**旧答案及其消亡。**$\mathrm{Sn - 37\ Pb}$恰好在$183\ {}^{\circ}\mathrm{C}$共晶，润湿完美，蠕变可接受，而自2006年起在欧盟因RoHS指令而非法。
**替代者。**$\mathrm{Sn - 3.0\ Ag - 0.5\ Cu}$，近共晶，$217$到$220\ {}^{\circ}\mathrm{C}$，高了$34\ {}^{\circ}\mathrm{C}$，因而离$125\ {}^{\circ}\mathrm{C}$的服役温度远了$34\ {}^{\circ}\mathrm{C}$——**更高的**对比温度更糟，所以在同一应力下蠕变抗力按阿伦尼乌斯因子$\exp \left[ Q / R \left( 1 / 398 - 1 / 456 \right) \right] \approx 4$更好。
**相图的警告。**$\mathrm{Sn - Ag}$相图有一个$\mathrm{Ag_3 Sn}$金属间化合物和一个$2.5\ \%$银处的共晶，$0.5\ \%$的铜通过让熔体饱和铜来钉住焊料在铜镀层上的润湿行为。铜超过$0.7\ \%$，$\mathrm{Cu_6 Sn_5}$就作为粗大块体析出，使接头开裂。
**真实的失效。**$- 40$到$125\ {}^{\circ}\mathrm{C}$之间的热循环，因为硅芯片、铜焊盘和层压基板的热膨胀系数分别为$3$、$17$和$14\ \mu \varepsilon / \mathrm{K}$，而焊料为$23$，使直径$1\ \mathrm{mm}$的焊柱每个循环承受$1.2\ \%$的应变范围。寿命是一个**科芬-曼森（Coffin-Manson）**疲劳寿命，$N_f \propto \Delta \epsilon^{- 2.5}$，它由焊料的蠕变抗力决定，而不由液相线决定。
**设计。**在RoHS对服务器与电信硬件的豁免适用处，使用**高铅**或**无铅高银**合金；或者用烧结银或铜柱扩散焊把接头完全移出热路径，那里没有会疲劳的焊料。

**合理性检验。**电子工业2006年的RoHS转换是工程史上最大的一次无计划材料替代，它是凭毒性论证做出的，没有力学论证。结果是汽车与航空航天电子因焊点疲劳经历了十年现场失效，而最终的答案不是更好的合金，而是**更好的读相图习惯**：要紧的性质是服役对比温度下的蠕变速率，相图只告诉你液相线在哪里。
:::
