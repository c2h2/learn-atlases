相图是一张自由能极小值地图。图上每一条边界都是自由能曲线上的公切线作图改变其答案时所在的温度与成分的轨迹，每一个区域都是某一种相组合自由能最低的范围，而液相线、固相线、固溶线与共晶线这一整套精巧的装置，只是一个条件的二维投影：每一种组元在每个含有它的相中的化学势都相等。

这就是相图如此有用、也如此被误用的原因。它们是平衡地图，而几乎每一个工程过程——铸造、焊接、热处理、时效、烧结、高温服役——都是对平衡的偏离，偏离的程度才是有意思的部分。一个熔池在几秒内凝固，远快于相图所假定的扩散，它留下的偏析芯组织就是相图的答案减去本该发生的扩散。一个时效合金是故意在错误的温度上读相图。而一支室温下的工具钢里含有稳定的铁-石墨相图上没有的渗碳体，因为渗碳体是亚稳的，而它转变为石墨的速度在钢中慢到可以忽略。

::: warning 先读坐标轴，再读相区
四个错误造成了相图对设计师的大部分伤害。**在多数工程相图上成分以重量百分数计，而在多数物理相图上以原子百分数计**，在稀溶液极限下两者相差原子质量之比——对$\mathrm{Al - 12\ wt\ \%\ Si}$，硅的原子分数是$11.6$百分数，相差不大，因为铝和硅的原子质量相近；但对重溶剂中的轻溶质，例如铁中的碳，原子百分数是重量百分数的好几倍。**相图是一个大气压下的截面**，所以任何含挥发性组元的体系——锂、镁、锌、锰、氮、氧——在真空或反应性气氛中进行工艺时都会移动，而$\mathrm{TiAl}$合金的氮含量根本不在$\mathrm{Ti - Al}$相图上。**每一条线都是平衡线**，所以每秒一度的冷却速率就可能把固态转变过冷几十度，把边界放到相图没有放的地方；[[materials-science/phase-transformations]]的连续冷却转变图才是那个修正，也是热处理工作者实际使用的那张图。而且**相区不是组织**：相图告诉你相分数和成分，对相的形状、间距与连续性——性质真正所在之处——却一字不提。相分数相同的两种合金，韧性或蠕变强度可以相差好几倍，因为一种中的脆性相是连续的，另一种中是弥散的。
:::

## 平衡与相律

::: definition 平衡条件与相律 {#def-phase-rule}
对$C$个组元、$P$个相处于平衡的系统，温度、压力以及每种组元的化学势都是均匀的：
$$
T^{\alpha} = T^{\beta}, \quad p^{\alpha} = p^{\beta}, \quad
\mu_{i}^{\alpha} = \mu_{i}^{\beta} \quad \text{对每个 } i .
$$
每个相由$C - 1$个独立成分变量加上$T$和$p$描述，而每一个化学势相等条件消去一个自由度。这个计数就是**吉布斯相律**
$$
F = C - P + 2 ,
$$
在定压下——所有工程相图都是这样画的——$F = C - P + 1$。
**怎么读。**二元相图的单相区有$F = 2$：温度和成分都自由。两个共存相有$F = 1$：固定温度，结线就固定了两个成分。二元系中三个相有$F = 0$：共晶是一个**不变**反应，发生在一个温度上，三个相的成分都固定，这就是共晶成分的合金像纯金属一样在单一温度凝固的原因。在定压下，二元系中四个相不可能在平衡下共存。
:::

::: definition 公切线作图与杠杆定律 {#def-lever}
在温度$T$下，平衡相组合是自由能曲线$G^{\alpha} (x )$与$G^{\beta} (x )$的**公切线**：切线在各自的相成分处接触每条曲线，而两个切点之间的任何总成分都会通过沿$G$图上一条直线分裂成两相来降低自由能。公切线作图的结线端点就是相界成分，整个二元相图就是这些作图的一叠堆叠。
对总成分$x_0$、处于两相区且相成分为$x_{\alpha}$与$x_{\beta}$的合金，**质量守恒**给出相分数
$$
f_{\alpha} = \frac{x_{\beta} - x_0}{x_{\beta} - x_{\alpha}}, \qquad
f_{\beta} = \frac{x_0 - x_{\alpha}}{x_{\beta} - x_{\alpha}}, \qquad f_{\alpha} + f_{\beta} = 1 ,
$$
这就是**杠杆定律**：一个相的分数是支点*另一侧*结线长度除以整条结线。它就是质量守恒的陈述，别无其他，所以在重量百分数相图上它给出质量分数，在原子百分数相图上给出摩尔分数，而在两者混用时绝不成立。
:::

::: definition 同晶系、枝晶偏析与休姆-罗瑟里规则 {#def-isomorphous}
两种元素若晶体结构相同、原子半径相差在约百分之十五以内、电负性相近、价态相近，就可以形成**连续固溶体**——铜-镍、金-银、硅-锗、钼-钨——相图是液相线与固相线之间的一个透镜，任何地方都没有不变反应。
在平衡下冷却同晶合金得到均匀固体。以任何实际速率冷却都会产生**枝晶偏析**：最先凝固的固体比最后凝固的更富含高熔点元素，而固体中的扩散太慢，抹不平这个梯度。所以铜镍铸件的枝晶心部镍含量高于平均值，枝晶间区域低于平均值，而最后凝固的液体如此富含低熔点组元，以至于可能在平衡固相线以下才凝固，若之后把铸件重新加热到略低于平衡固相线，就会造成**初熔**。解药是在固相线以下进行**均匀化退火**，通常几小时到几十小时，然后再热加工。
:::

::: definition 共晶、包晶与偏晶 {#def-eutectic}
$$
\textbf{共晶:} \quad L \rightleftharpoons \alpha + \beta
\qquad
\textbf{包晶:} \quad L + \alpha \rightleftharpoons \beta
\qquad
\textbf{偏晶:} \quad L_1 \rightleftharpoons \alpha + L_2
$$
共晶是相图中该部分液相线的最低点，在单一温度凝固成**两相交织组织**，其间距$\lambda$由生长速度$V$按$\lambda^{2} V \approx \text{常数}$决定，因为溶质必须在片层之间横向扩散——生长越快，间距越细，从缓冷$\mathrm{Al - Si}$铸件中的几微米到快速凝固时的远小于一微米。包晶反应比看上去更慢，因为新相$\beta$在旧的$\alpha$**周围**形成一层，此后反应只能靠**穿过$\beta$**的扩散继续；所以铸态包晶合金通常保留着平衡相图说本应消失的未反应$\alpha$。
**同成分**熔化，$\text{化合物} \rightarrow L$成分不变，在液相线上给出一个极大（铝合金中的$\mathrm{Mg_2 Si}$，镍-铝系中的$\mathrm{NiAl}$）；**异成分**熔化在加热时把化合物分解为液体和另一个固相，在相图上表现为包晶反应。
:::

y: -0.4, 0.75
labels: G(x)
caption: 一条有两个极小值的示意自由能曲线，这种形式产生溶解度间隙。对公切线两个切点之间的任何总成分——这里是穿过两个极小值的水平线——自由能最低的是切点成分的两相混合物。在两个拐点之间，曲率为负，单相对任何微小的成分涨落都不稳定，无需形核势垒即可分解：那就是[[materials-science/phase-transformations]]的调幅分解。

::: definition 活度与液相线的形状 {#def-activity}
组元的化学势为$\mu_{i} = \mu_{i}^{\circ} + RT \ln a_i$，其中$a_i = \gamma_{i} x_{i}$是**活度**；平衡要求每种组元相对同一标准态的活度在两相中相等——而不是其浓度相等。**正规溶液**有
$$
\Delta G_{\mathrm{mix}} = \Omega\, x \left( 1 - x \right) + R T \left[ x \ln x + \left( 1 - x \right) \ln \left( 1 - x \right) \right] ,
$$
$\Omega$为相互作用参数，单是熵项就保证了在稀溶液极限下$\Delta G_{\mathrm{mix}} < 0$，这就是为什么**每一种**固体都至少溶解一点其他每一种元素。相分离要求$\Omega$为正且大到足以压过熵，在$x = 0.5$处的条件$\mathrm{d}^{2} G / \mathrm{d} x^{2} = 0$给出**临界溶解温度**
$$
T_{c} = \frac{\Omega}{2 R} ,
$$
所以$\Omega = 17\ \mathrm{kJ / mol}$给出$T_{c} = 1022\ \mathrm{K} = 749\ {}^{\circ}\mathrm{C}$，而铜-镍的$\Omega$为不大的正值，只在几百摄氏度才有溶解度间隙，那里扩散太慢，实际上无关紧要。
**凝固点降低。**若液体是理想溶液、固体是纯$A$，液相线自$A$的熔点下降为
$$
\ln \left( 1 - x_{B} \right) = - \frac{\Delta H_f}{R} \left( \frac{1}{T} - \frac{1}{T_{m}} \right) ,
$$
它只需要$A$的熔化焓，并能把铝硅液相线的铝侧重现到几度以内。
:::

::: example 读取二元相图 {#ex-cuni}
一种$50\ \%$铜-$50\ \%$镍（重量）合金缓慢冷却。把液体和固体都当作理想溶液，给出最初固体的成分、$1280\ {}^{\circ}\mathrm{C}$下液体的分数和最后液体的成分，并说明真实铸态组织包含什么。
::: solution
**最初固体。**由铜和镍的熔点与熔化焓算出的理想溶液透镜，把$50\ \%$Ni合金的液相线定在$1293\ {}^{\circ}\mathrm{C}$，与之平衡的固体含$57\ \%$Ni。所以第一批枝晶臂是**$57\ \%$的镍**，比熔体富七个点。
**在$1280\ {}^{\circ}\mathrm{C}$。**结线从$46.4\ \%$Ni的液体延伸到$53.5\ \%$Ni的固体，所以
$$
f_L = \frac{53.5 - 50}{53.5 - 46.4} = 0.49 ,
$$
约一半是液体，两相的镍含量相差七个点。
**最后液体。**平衡下合金在固相线$1267\ {}^{\circ}\mathrm{C}$全部凝固，最后的液体具有该温度下的液相线成分，$43\ \%$Ni。在任何实际冷却速率下固体无法重新达到平衡，剩余液体变得更贫镍，并在平衡固相线以下于枝晶臂之间最后凝固。
**真实组织。**一片带偏析芯的枝晶阵列，镍含量从枝晶轴处约$57\ \%$降到枝晶臂之间低于$43\ \%$。实测的铜镍相图与这个理想估算相差几十度，所以实际工作中数值要从实测相图上读；规律是相同的。

**校核。**均匀化时间按**枝晶臂间距的平方**变化：溶质要扩散约半个臂间距，所以$t \approx \lambda_{2}^{2} / \left( 4 D \right)$，对$\lambda_{2} = 50\ \mu\mathrm{m}$、假定$D = 10^{- 14}\ \mathrm{m^{2} / s}$，得$6.3 \times 10^{4}\ \mathrm{s}$，约十七小时。$\checkmark$

**合理性检验。**几小时以上的均匀化处理是铸造铜镍合金和镍合金的正常工业实践，而平方律说明了为什么更细的枝晶——来自更快的冷却，或来自真空电弧重熔和电渣重熔这类熔池更浅、凝固更快的重熔工艺——能如此有效地缩短处理时间。
:::

::: example 由一个参数求共晶温度 {#ex-alsi}
由铝的熔化焓和共晶成分估算铝硅系的共晶温度，并与实测的$577\ {}^{\circ}\mathrm{C}$比较。
::: solution
**成分。**按重量$12.6\ \%$的硅是
$$
x_{\mathrm{Si}} = \frac{12.6 / 28.09}{12.6 / 28.09 + 87.4 / 26.98} = 0.122 \text{ （原子分数）} .
$$
**凝固点降低。**取$\Delta H_f = 10.7\ \mathrm{kJ / mol}$、$T_{m} = 933\ \mathrm{K}$，
$$
\ln \left( 1 - 0.122 \right) = - 0.130 = - \frac{10{,}700}{8.314} \left( \frac{1}{T} - \frac{1}{933} \right)
\quad\Longrightarrow\quad
T = 853\ \mathrm{K} = 580\ {}^{\circ}\mathrm{C} .
$$
**比较。**实测共晶为$577\ {}^{\circ}\mathrm{C}$，只差三度，而模型只有**一个**材料参数、没有可调常数。
**为什么灵。**在铝侧液体近乎理想，而析出的固体几乎是纯铝（最多只溶解约$1.6\ \%$的硅），这恰好是公式的两个假设。

**校核。**这个方法需要实测的共晶成分。把同样的理想公式用于硅的液相线，取$\Delta H_f = 50.2\ \mathrm{kJ / mol}$、$T_m = 1687\ \mathrm{K}$，并与铝的液相线求交，得到的"共晶"在约$630\ {}^{\circ}\mathrm{C}$和$4.5$原子百分数硅——与事实相去甚远，因为富硅液体强烈偏离理想。液相线的一支可以是理想的，另一支却不是。$\checkmark$

**合理性检验。**较低的共晶温度和良好的流动性是$\mathrm{Al - Si}$合金主导铝铸造的原因。问题在**形貌**而不在相图——未变质的共晶硅长成粗大的脆性片——解药是少量钠或锶的添加，量级为百万分之一百左右，它改变硅的生长方式，把片状变成细小的纤维状网络。这是一张对性质一字不提的相图和一个决定性质的组织。
:::

::: example 仔细读取铁碳相图 {#ex-fe-c}
给出$0.40\ \%$碳钢在共析温度稍上方和稍下方、以及$1.0\ \%$碳工具钢在室温下的相及其分数。渗碳体为什么会出现在相图上？
::: solution
**在$727\ {}^{\circ}\mathrm{C}$稍上方。**$0.76\ \%$C的奥氏体加$0.022\ \%$C的先共析铁素体：
$$
f_{\alpha} = \frac{0.76 - 0.40}{0.76 - 0.022} = 0.49 , \qquad f_\gamma = 0.51 .
$$
**在$727\ {}^{\circ}\mathrm{C}$稍下方。**奥氏体已变成**珠光体**，一种层片状铁素体-渗碳体交织组织，所以相分数不变，但组织现在是两个组成物：$49\ \%$浅色的先共析铁素体和$51\ \%$暗色的珠光体，这正是缓冷后抛光并用硝酸酒精侵蚀的1040钢在显微镜下的样子。
**室温总渗碳体。**$\mathrm{Fe_3C}$含$6.67\ \%$C，忽略$727\ {}^{\circ}\mathrm{C}$以下碳溶解度的下降，铁素体含$0.022\ \%$，
$$
f_{\mathrm{Fe_3 C}} = \frac{0.40 - 0.022}{6.67 - 0.022} = 0.057 ,
$$
所以中碳钢按质量$94\ \%$是铁素体，渗碳体以很少的量起着很大的作用。
**$1.0\ \%$工具钢。**$f_{\mathrm{Fe_3 C}} = \left( 1.0 - 0.022 \right) / 6.648 = 0.147$。其中$\left( 1.0 - 0.76 \right) / \left( 6.67 - 0.76 \right) = 0.041$是沉积在原始奥氏体晶界上的**先共析渗碳体**，其余$0.106$是珠光体中的渗碳体。先共析渗碳体可以形成连续的脆性网络，这就是这类钢切削加工前要进行球化退火的原因，也是缓冷形成的网络必须通过在$A_{cm}$线以上奥氏体化、并以足够快的速度冷却使其不再形成来消除的原因。
**渗碳体为什么在图上。**铁碳平衡是$\mathrm{Fe} + \mathrm{C}$（石墨）；渗碳体是**亚稳**的。稳定相图与亚稳相图相距不远，但石墨的形成需要富碳相的形核和碳的长程扩散，慢到普通碳钢在室温下无限期地保持$\mathrm{Fe - Fe_3 C}$。灰铸铁中百分之一到三的硅促进石墨形成——这就是**铸铁**凝固时生成石墨、切削性好，而**钢**保留渗碳体的原因。

**校核。**共析成分$0.76\ \%$与共析温度$727\ {}^{\circ}\mathrm{C}$是现代数值；旧的$0.80\ \%$与$723\ {}^{\circ}\mathrm{C}$出现在较早的教科书里，它们把$0.40\ \%$钢的先共析铁素体分数从$0.49$移到$0.40 / 0.778 = 0.51$。$\checkmark$

**合理性检验。**退火态普通碳钢的含碳量从$0.40\ \%$升到$0.80\ \%$时，珠光体分数从约一半升到几乎整个组织，强度随之上升。但珠光体的强度主要由其**片层间距**决定，片层间距由穿过共析转变的冷却速率决定，而不由相图决定。相图给出分数；加工给出间距；性质取决于两者。
:::

::: example 纳米尺度溶解度与吉布斯-汤姆孙效应 {#ex-gibbs-thomson}
对界面能$0.5\ \mathrm{J / m^{2}}$、摩尔体积$10^{- 5}\ \mathrm{m^{3} / mol}$的析出物，在$473\ \mathrm{K}$下半径为$50$、$10$和$2\ \mathrm{nm}$时，平衡基体浓度提高多少倍？
::: solution
$$
\frac{c_{r}}{c_{\infty}} = \exp \left( \frac{2 \gamma V_{m}}{r R T} \right) ,
\qquad
\frac{2 \gamma V_{m}}{R T} = \frac{2 \times 0.5 \times 10^{- 5}}{8.314 \times 473} = 2.54 \times 10^{- 9}\ \mathrm{m} .
$$
$$
\begin{array}{c c}
r\ \left[ \mathrm{nm} \right] & c_{r} / c_{\infty} \\
50 & 1.05 \\
10 & 1.29 \\
2 & 3.6
\end{array}
$$
**后果。**$2\ \mathrm{nm}$析出物周围的基体与之平衡的溶质浓度是大颗粒值的**三点五倍**，所以长时间保温时小颗粒溶解而大颗粒长大——**奥斯特瓦尔德熟化**，也是峰值时效合金在时效温度下保温过久会软化的原因之一。
**另一个后果。**纳米尺度析出物的溶解度不是相图上的固溶线，所以相图无法描述时效处理的早期阶段，那时析出物只有几纳米大，而且常常是根本不出现在平衡相图上的亚稳相。

**校核。**吉布斯-汤姆孙长度$2 \gamma V_{m} / R T$在$473\ \mathrm{K}$为$2.5\ \mathrm{nm}$，在$950\ \mathrm{K}$为$1.3\ \mathrm{nm}$，所以对这组性质参数，这是一个纳米尺度现象，在半径$50\ \mathrm{nm}$时只有百分之几。$\checkmark$

**合理性检验。**同一个毛细项支配弥散相的粗化、枝晶尖端温度的曲率修正和粉末压坯烧结的驱动力，也是极小颗粒在低于块体熔点时就熔化的原因。相图是一份**大颗粒**文件，在析出物的尺度上需要这个修正。

::: example 设计 {#ex-design-weld}
一个Al-Mg-Si $6061$-T6支架用$4043$（Al-5Si）焊丝焊接。预测穿过焊缝的组织、强度分布和破坏位置。
::: solution
**母材。**6061靠$\mathrm{Mg_2 Si}$相的细小亚稳前驱体（$\beta^{\prime\prime}$）强化。它在约$530\ {}^{\circ}\mathrm{C}$固溶处理——高到足以溶解镁和硅，又低于合金开始熔化的温度——然后淬火，在约$160$到$177\ {}^{\circ}\mathrm{C}$时效。
**焊接热循环。**在TIG或MIG焊中，熔合区是熔化的金属，与其相邻的母材被短暂加热到从熔化区间到室温之间的每一个温度。把支架分成四个区：
1. **熔合区。**$4043$焊丝与熔化母材的混合物，亚共晶，在约$630$到$577\ {}^{\circ}\mathrm{C}$之间凝固成初生$\alpha$-Al枝晶和枝晶间的共晶硅。它是铸态组织，未经热处理，强度低。
2. **部分熔化区。**熔合边界处的一条窄带，母材晶界在这里曾短暂熔化；它容易产生**液化裂纹**，尤其是焊缝金属含硅低时，这是$6061$要用富硅焊丝的原因之一。
3. **热影响区，过时效。**峰值温度约$250$到$450\ {}^{\circ}\mathrm{C}$：$\beta^{\prime\prime}$析出相粗化为$\beta^{\prime}$和平衡的$\beta\ \mathrm{Mg_2 Si}$，合金不可逆地失去强度。这条带通常距焊缝几毫米到一两厘米，是整个构件中最弱的金属。
4. **热影响区，固溶化。**峰值温度接近固溶处理温度：析出相溶解，该区软如T4材料，冷却后在室温下**自然时效**，在几天到几周内恢复部分强度。
**破坏。**在**热影响区**，焊态抗拉强度约$165$到$185\ \mathrm{MPa}$，而T6母材为$310\ \mathrm{MPa}$——接头效率约$0.55$到$0.6$，这就是焊接规范给焊接6061-T6规定的设计强度远低于母材的原因。
**设计对策。**在可行时，先焊接，再对整个构件做固溶加时效——焊接的6061自行车架就是这样制造的；单靠再时效无法恢复过时效区。构件太大时，使用**不可热处理强化的5000系**合金，在退火（O）状态下它在热影响区几乎不损失强度，因为它本来就没有可失去的析出相或冷加工。

**设计评注。**这个例子教的一般规则是：**熔焊会毁掉其附近的热处理，任何焊丝都修不好这一点**。三个诚实的选项是：在软状态下焊接再对构件重新热处理；使用不可热处理强化合金；或者设计接头使热影响区不是危险截面。不诚实的是在焊接图上给构件指定母材的T6性能。
:::

::: history
热力学先行。**J. 威拉德·吉布斯（J. Willard Gibbs）**在1875至1878年发表于《康涅狄格科学院学报》的《论多相物质的平衡》（*On the Equilibrium of Heterogeneous Substances*）中给出了相间平衡的条件，包括相律；在**威廉·奥斯特瓦尔德（Wilhelm Ostwald）**1892年将其译成德文之前，化学家很少读它。**H. W. 巴库伊斯·鲁泽博姆（H. W. Bakhuis Roozeboom）**经**范德瓦耳斯（J. D. van der Waals）**介绍接触到吉布斯的工作，从1887年起展示了相律如何对真实的多相平衡进行分类，并于1900年按相律原理构建了一张铁碳相图。测量来自新仪器：**亨利·勒夏特列（Henry Le Chatelier）**在1880年代引入了铂/铂铑热电偶，**威廉·钱德勒·罗伯茨-奥斯汀（William Chandler Roberts-Austen）**在1890年代后期给合金研究委员会的报告中，用记录式高温计测定了铁碳合金的停顿点。[[#ex-alsi]]所用的理想溶液凝固点降低可追溯到**范托夫（J. H. van 't Hoff）**1886年的稀溶液理论，而**G. N. 路易斯（G. N. Lewis）**与**默尔·兰德尔（Merle Randall）**1923年的《热力学》使活度和化学势成为标准工具。**马克斯·汉森（Max Hansen）**1936年的二元相图汇编《二元合金的构成》（*Der Aufbau der Zweistofflegierungen*）成为工程合金的标准参考。**阿拉达尔·帕奇（Aladar Pacz）**约在1920年为铝硅合金的钠变质处理申请了专利。平衡对界面曲率的依赖可追溯到**威廉·汤姆孙（William Thomson，开尔文勋爵）**，他在1871年推导了弯曲表面上的蒸气压；**威廉·奥斯特瓦尔德**在1900年描述了小颗粒的熟化，**I. M. 栗弗席兹（I. M. Lifshitz）**与**V. V. 斯廖佐夫（V. V. Slyozov）**以及独立工作的**卡尔·瓦格纳（Carl Wagner）**在1961年给出了它的理论。
:::

## 后续内容

本讲的平衡相分数，在施加上冷却速率后就变成[[materials-science/phase-transformations]]的转变动力学；[[#ex-gibbs-thomson]]的析出物是[[materials-science/dislocations-strengthening]]的奥罗万障碍；[[#ex-fe-c]]的渗碳体网络是[[materials-science/failure]]的一条裂纹路径；而[[#ex-design-weld]]的焊缝热影响区也是焊接残余应力集中之处，那是[[mechanics-of-materials]]的问题。

::: summary
- 相图是自由能曲线叠上公切线作图的地图；相律$F = C - P + 1$数的是在一个相消失之前你可以改变什么。
- 杠杆定律只是质量守恒，且只在坐标轴所用的单位下成立。
- 同晶系冷却时产生枝晶偏析，均匀化所需时间的量级为枝晶臂间距的平方除以扩散系数。
- 共晶是不变的，在单一温度凝固，承载性质的是它的间距——而不仅是分数。
- 在已知共晶成分时，单参数理想凝固点降低把铝硅共晶温度重现到三度以内；富硅液相线远非理想。
- 在几纳米的析出物尺寸下，吉布斯-汤姆孙项使溶解度明显改变，这正是时效早期阶段的尺度。
:::

::: quiz
一个成分恰好为共晶的合金缓慢冷却。哪个说法正确？
- [x] 它在单一温度凝固，两个固相同时生成长成交织组织
- [ ] 它在液相线与固相线之间的整个区间内凝固
- [ ] 一个相先生成，另一个填满最后的液体
- [ ] 没有过冷它就无法凝固
::: solution
在共晶点，液体与两个固相共存，定压下$F = 0$，所以合金在单一温度同时转变为两个固相。这是近共晶合金成为好的铸造合金的部分原因——糊状区很小或没有，它们流动性好，也更容易补缩。
:::
:::

::: exercise 枝晶偏析 {level=2 check="23"}
一个铜镍枝晶的臂间距为$100\ \mu\mathrm{m}$。用$t \approx \lambda^{2} / \left( 4 D \right)$估算在$D = 3 \times 10^{- 14}\ \mathrm{m^{2} / s}$的温度下的均匀化时间，以小时计。
::: solution
$$
t \approx \frac{\left( 100 \times 10^{- 6} \right)^{2}}{4 \times 3 \times 10^{- 14}} = 8.3 \times 10^{4}\ \mathrm{s} = 23\ \mathrm{h} .
$$
**合理性检验。**通过更快冷却把枝晶臂间距减半，均匀化时间缩短为四分之一，这是在重视均匀性时采用冷却更快的铸造工艺的有力理由。这也是为什么在同一温度下大铸锭的均匀化时间比薄带铸坯长得多。

::: exercise 铁碳 {level=2}
给出$0.30\ \%$和$0.90\ \%$碳钢在共析温度稍下方的珠光体分数。
::: solution
对亚共析钢，珠光体分数就是共析温度下的奥氏体分数，
$$
f_{\mathrm{pearlite}, 0.30} = \frac{0.30 - 0.022}{0.76 - 0.022} = 0.38 .
$$
对过共析钢，先共析相是渗碳体，所以
$$
f_{\mathrm{pearlite}, 0.90} = \frac{6.67 - 0.90}{6.67 - 0.76} = 0.98 .
$$
**合理性检验。**在缓冷的过共析钢中，少量先共析渗碳体位于原始奥氏体晶界上，可以形成连续的脆性网络，所以即使硬度继续上升，塑性和韧性也会下降。这就是含碳约$1\ \%$的高碳轴承钢要先球化退火、再从部分碳化物仍保留为细小球状颗粒的温度淬火的原因，这样就不存在网络。
:::

::: exercise 正规溶液 {level=2 check="449"}
一个二元系的相互作用参数为$\Omega = 12\ \mathrm{kJ / mol}$。给出以摄氏度计的临界溶解温度，并说明该系在$500\ {}^{\circ}\mathrm{C}$是否互溶。
::: solution
$$
T_{c} = \frac{\Omega}{2 R} = \frac{12{,}000}{2 \times 8.314} = 722\ \mathrm{K} = 449\ {}^{\circ}\mathrm{C} .
$$
在$500\ {}^{\circ}\mathrm{C}$，该系**高于**$T_{c}$，完全互溶；在$400\ {}^{\circ}\mathrm{C}$，它低于$T_{c}$，成分范围中部的合金会分离成两相。
**合理性检验。**这类溶解度间隙是调幅分解的基础，Cu-Ni-Fe（"Cunife"）和Fe-Cr-Co永磁合金就利用了它。一个有害的例子是铁-铬溶解度间隙：高铬铁素体在约$300$到$500\ {}^{\circ}\mathrm{C}$保温时分解为富铁区和富铬区，使铁素体不锈钢和双相不锈钢变脆——即行业文献中的"$475\ {}^{\circ}\mathrm{C}$脆性"。
:::

::: exercise 推导 {level=3}
由质量守恒推导杠杆定律，并由吉布斯-汤姆孙论证推导析出物的平衡溶解度条件。
::: solution
**杠杆定律。**一千克成分为$x_0$的合金含$x_0$千克溶质。它分裂为成分$x_{\alpha}$的$f_{\alpha}$千克$\alpha$和成分$x_{\beta}$的$f_{\beta}$千克$\beta$，所以
$$
f_{\alpha} + f_{\beta} = 1 , \qquad
f_{\alpha} x_{\alpha} + f_{\beta} x_{\beta} = x_0 .
$$
代入$f_{\beta} = 1 - f_{\alpha}$，
$$
f_{\alpha} x_{\alpha} + x_{\beta} - f_{\alpha} x_{\beta} = x_0
\quad\Longrightarrow\quad
f_{\alpha} = \frac{x_{\beta} - x_0}{x_{\beta} - x_{\alpha}} . \quad \checkmark
$$
对溶质作同样的平衡给出$f_{\beta} = \left( x_0 - x_{\alpha} \right) / \left( x_{\beta} - x_{\alpha} \right)$，两者之和恒为一。注意推导只用到了质量守恒，这就是为什么杠杆定律经得起热力学的每一次精化，也只有在相图单位混用时才会失效。
**吉布斯-汤姆孙条件。**从过饱和基体中形成半径$r$的球形析出物的自由能为
$$
\Delta G = \frac{4}{3} \pi r^{3} \Delta g_v + 4 \pi r^{2} \gamma ,
$$
界面两侧的压力差为$\Delta p = 2 \gamma / r$。对稀溶液，基体中溶质的化学势为$\mu = \mu^{\circ} + R T \ln c$，而压力使析出物的化学势提高$V_m \Delta p = 2 \gamma V_{m} / r$。令两者相等，
$$
R T \ln \frac{c_{r}}{c_{\infty}} = \frac{2 \gamma V_{m}}{r}
\quad\Longrightarrow\quad
\boxed{ c_{r} = c_{\infty} \exp \left( \frac{2 \gamma V_{m}}{r R T} \right) } . \quad \checkmark
$$
**合理性检验。**由此得出两个从公式上看不出的推论。第一，$c_{r}$随$r$增大而减小，所以小颗粒溶解而大颗粒以小颗粒为代价长大——奥斯特瓦尔德熟化——在扩散控制的粗化中平均半径按$t^{1 / 3}$增长，这就是**栗弗席兹-斯廖佐夫-瓦格纳**定律，它决定了过时效合金软化的快慢。第二，推导忽略了弹性应变；对**共格**析出物，共格应变能提高其自由能，所以它的固溶线低于非共格平衡相的固溶线，这就是GP区这类亚稳共格相有其自己的、更低的固溶线的原因。
:::

::: exercise 设计 {level=3}
为一个在$- 40\ {}^{\circ}\mathrm{C}$与$125\ {}^{\circ}\mathrm{C}$之间循环的功率模块选择焊料合金，并对照相图说明理由。
::: solution
**旧答案及其为何不再可用。**$\mathrm{Sn - 37\ Pb}$接近$183\ {}^{\circ}\mathrm{C}$的锡铅共晶，润湿良好，服役记录很长，但自2006年7月起，欧盟RoHS指令限制了大多数电气电子设备中的铅。
**替代品。**$\mathrm{Sn - 3.0\ Ag - 0.5\ Cu}$（"SAC305"），近共晶，在$217$到$220\ {}^{\circ}\mathrm{C}$之间熔化。在$125\ {}^{\circ}\mathrm{C}$下它的同系温度为$398 / 490 = 0.81$，锡铅为$398 / 456 = 0.87$，较低的同系温度有助于它在循环高温端的抗蠕变性。
**相图的警告。**$\mathrm{Sn - Ag}$共晶位于$3.5\ \%$银和$221\ {}^{\circ}\mathrm{C}$，银形成金属间化合物$\mathrm{Ag_3 Sn}$；银含量达到或超过共晶值时，缓冷会长出削弱接头的大块初生$\mathrm{Ag_3 Sn}$片，这是采用低银合金的原因之一。铜的添加接近$\mathrm{Sn - Cu}$共晶含量$0.7\ \%$，略微降低熔点并减少铜焊盘的溶解；更高的铜含量会产生初生$\mathrm{Cu_6 Sn_5}$。
**真实的破坏。**在$- 40$与$125\ {}^{\circ}\mathrm{C}$之间的热循环给接头施加循环剪切应变，因为硅芯片、铜和基板的膨胀系数约为$3$、$17$和$15\ \mu \varepsilon / \mathrm{K}$，而焊料约为$22$。寿命是低周**科芬-曼森**疲劳寿命，大致$N_f \propto \Delta \epsilon^{- 2}$，由焊料的蠕变-疲劳行为和接头几何决定，而不由液相线决定。
**设计。**板级焊点用SAC305或低银SAC合金；功率模块中的芯片贴装，在RoHS对高熔点焊料的豁免仍适用之处用高铅焊料（铅含量超过$85\ \%$），或者干脆用烧结银连接把焊料移出热通路，它没有会蠕变的低熔点相。

**合理性检验。**无铅转换是由出于环保理由的法规推动的，由于锡银铜焊料的蠕变和疲劳行为与锡铅不同，它迫使业界进行了大量可靠性试验。教训是一种**读相图的习惯**：要紧的性质是服役同系温度下的蠕变-疲劳行为，而相图告诉你的是熔化区间和金属间化合物在哪里，不是接头能用多久。
:::
