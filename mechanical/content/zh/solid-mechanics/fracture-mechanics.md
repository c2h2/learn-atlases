1943年1月的一个夜晚，刚刚建成的油轮"斯克内克塔迪"号（SS *Schenectady*）停靠在俄勒冈州波特兰的舾装码头上，突然断成两截。她没有装载货物，海面也没有风浪；甲板上的名义应力远低于其钢材的屈服强度。在第二次世界大战期间建造的数千艘焊接的自由轮和T2油轮中，有数百艘发生了严重的脆性断裂，少数完全断裂。十年后的1954年，两架德哈维兰"彗星"客机——最早的喷气式运输机——在飞行中解体；调查人员在水槽中对一个完整机身做破坏性试验，把事故追溯到从增压客舱开口拐角处扩展的疲劳裂纹。

这些破坏都无法通过比较应力与强度来解释。每一起都始于一条**裂纹**——焊接缺陷、疲劳裂纹或缺口——而含裂纹物体的破坏，不是发生在某处应力达到强度之时，而是发生在裂纹能够扩展之时。**断裂力学**就是预测这一时刻的理论。它的核心结论是：在线弹性体中，任何裂纹尖端附近的应力场都具有相同的形状，其强度由一个数——**应力强度因子**$K$——来度量。当$K$达到一个材料性能——**断裂韧度**$K_{Ic}$——时发生断裂。这一个思想就使工程师能够计算结构能够容许多大的裂纹、疲劳裂纹以多快的速度扩展到这一尺寸，以及结构必须多久检查一次——这是飞机、压力容器、管道和桥梁**损伤容限设计**的基础。

本章从格里菲斯（Griffith）的能量论证和欧文（Irwin）的应力场论证出发建立线弹性断裂力学（LEFM），说明两者如何联系，阐明其适用限度（塑性区、平面应变和韧度试验），并把它应用于疲劳裂纹扩展。本章以[[solid-mechanics/linear-elasticity]]以及[[materials-science/failure]]中的材料学图景为基础。

## 为什么仅有应力是不够的

尖锐裂纹是一种极端的应力集中源。对远处受拉应力$\sigma$作用的宽板中半轴为$a$（垂直于载荷）和$b$的椭圆孔，英格利斯（Inglis）的弹性力学解给出长轴端点处的应力为
$$
\sigma_{\max} = \sigma\left(1 + \frac{2a}{b}\right) = \sigma\left(1 + 2\sqrt{\frac a\rho}\right),
$$ {#eq-inglis}
其中$\rho = b^2/a$为端部的曲率半径。圆孔（$a = b$）给出[[solid-mechanics/linear-elasticity]]中的系数3；裂纹的$\rho \to 0$，给出$\sigma_{\max} \to \infty$。如果破坏意味着"$\sigma_{\max}$达到强度"，那么每个含裂纹物体都会在零载荷下破坏。实际的含裂纹物体并非如此，所以需要另一个准则：一个不依赖于（无法知道的、在极限情况下为零的）尖端半径的准则。

## 格里菲斯能量平衡

格里菲斯的洞见在于不问应力而问能量。裂纹扩展时发生两件事：产生新的表面，这需要消耗能量；裂纹周围的物体变得更柔，这会释放储存的弹性能（或使载荷做功）。当释放的能量至少足以支付新表面所需时，裂纹就能扩展。

::: definition 能量释放率 {#def-G}
对厚度为$B$、裂纹长度为$a$的含裂纹物体，**能量释放率**$G$是裂纹每扩展单位面积时势能$\Pi$（应变能减去外加载荷的势）的减少量：
$$
G = -\frac{1}{B}\frac{d\Pi}{da} .
$$
其单位为$\mathrm{J/m^2} = \mathrm{N/m}$。当$G$达到临界值$G_c$——材料抵抗裂纹扩展的能力——时，裂纹扩展：对理想脆性固体，$G_c = 2\gamma_s$，即表面能的两倍（产生两个表面）；对金属和聚合物，它主要由尖端附近所做的塑性功决定。
:::

::: theorem 格里菲斯断裂准则 {#thm-griffith}
线弹性材料的无限大板中有一条长度为$2a$的穿透裂纹，垂直于远处均匀拉应力$\sigma$，其能量释放率（每个裂纹尖端）为
$$
G = \frac{\pi\sigma^2a}{E'}, \qquad E' = E\ \text{（平面应力）}, \quad E' = \frac{E}{1 - \nu^2}\ \text{（平面应变）},
$$
断裂发生在
$$
\sigma_f = \sqrt{\frac{E'G_c}{\pi a}} = \sqrt{\frac{2E'\gamma_s}{\pi a}}\quad\text{（理想脆性）}.
$$
:::

::: proof
英格利斯的解表明，在保持远处应力不变的条件下把裂纹引入板中，储存的应变能增加$\pi\sigma^2a^2B/E'$，而边界载荷做的功是它的两倍，因此势能（应变能减去载荷的功势）减少
$$
\Pi(a) - \Pi(0) = -\frac{\pi\sigma^2a^2B}{E'} .
$$
裂纹有两个尖端，每个尖端扩展$da$使裂纹面积增加$2B\,da$。因此
$$
G = -\frac{1}{2B}\frac{d\Pi}{da} = \frac{1}{2B}\cdot\frac{2\pi\sigma^2aB}{E'} = \frac{\pi\sigma^2a}{E'} .
$$
令$G = G_c$即得$\sigma_f$。这一平衡是不稳定的：$G$随$a$增大，而对理想脆性材料$G_c$为常数，所以裂纹一旦开始扩展，驱动力超过阻力的程度就越来越大。格里菲斯本人的表述针对总能量$U = -\pi\sigma^2a^2B/E' + 4a\gamma_sB$，它关于$a$的极大值给出同样的条件。
:::

::: example 为什么玻璃强度低 {#ex-glass}
窗玻璃的$E = 70\ \mathrm{GPa}$，表面能$\gamma_s \approx 1\ \mathrm{J/m^2}$。估计一块含有相当于半长$1\ \mu\mathrm{m}$裂纹的表面缺陷的玻璃板的断裂应力，并与原子键的理论强度（约为$E/10$）比较。
::: solution
$$
\sigma_f = \sqrt{\frac{2E\gamma_s}{\pi a}} = \sqrt{\frac{2\times70\times10^{9}\times1}{\pi\times1\times10^{-6}}} = 2.1\times10^{8}\ \mathrm{Pa} = 211\ \mathrm{MPa}.
$$
理论强度约为$E/10 = 7000\ \mathrm{MPa}$，高出三十多倍。普通玻璃的典型设计强度为几十MPa；表面完好的新拉制玻璃纤维可以达到几GPa。格里菲斯的解释——强度由最大的缺陷而非化学键控制——说明了为什么玻璃靠保护或压缩其表面（钢化、化学增强）而不是靠改变其化学成分来强化。合理性检查：缺陷尺寸减半只使$\sigma_f$提高$\sqrt2$倍，单位为$\sqrt{\mathrm{Pa\cdot J/m^2/m}} = \mathrm{Pa}$。
:::
:::

对金属而言，格里菲斯的表面能无关紧要：裂纹尖端塑性变形吸收的能量要大数千倍。欧文和奥罗万（Orowan）在1940年代末各自独立地提出，保留格里菲斯公式的形式，但把$2\gamma_s$换成$G_c$，即一个包含塑性功的实测韧度。这使能量方法可以用于工程金属——前提是塑性区很小。

### 柔度法

$G$可以根据含裂纹构件的载荷-位移行为测量或计算出来，而无需知道尖端附近的应力。

::: proposition 由柔度求能量释放率 {#prop-compliance}
对受力$P$作用、加载点位移为$\delta = C(a)P$的线弹性体，其中$C$为柔度，
$$
G = \frac{P^2}{2B}\frac{dC}{da},
$$
无论裂纹是在恒载荷还是在恒位移下扩展。
:::

::: proof
恒载荷时，应变能为$U = \tfrac12P\delta = \tfrac12CP^2$，载荷的势为$-P\delta = -CP^2$，所以$\Pi = -\tfrac12CP^2$，$G = -\frac1B\frac{d\Pi}{da} = \frac{P^2}{2B}\frac{dC}{da}$。恒位移时载荷不做功，$\Pi = U = \tfrac12\delta^2/C$，$G = -\frac1B\frac{dU}{da} = \frac{\delta^2}{2BC^2}\frac{dC}{da} = \frac{P^2}{2B}\frac{dC}{da}$，结果相同。供裂纹扩展的能量来源不同——一种情况来自加载系统，另一种来自储存的应变能——但数量相同。
:::

::: example 双悬臂梁试验 {#ex-dcb}
双悬臂梁（DCB）试样用于测量胶接接头和复合材料层合板的韧度：宽$B$、高$h$的两臂在长度为$a$的裂纹端部被力$P$拉开。把每臂视为悬臂梁，求$G$，并对铝制臂（$E = 70\ \mathrm{GPa}$，$B = 25\ \mathrm{mm}$，$h = 6\ \mathrm{mm}$，$a = 60\ \mathrm{mm}$）计算$G_c = 300\ \mathrm{J/m^2}$的胶黏剂发生脱粘时的载荷。
::: solution
每臂挠度为$Pa^3/3EI$，$I = Bh^3/12$，所以张开量为$\delta = 2Pa^3/3EI$，$C = 2a^3/3EI$。于是$dC/da = 2a^2/EI$，
$$
G = \frac{P^2}{2B}\cdot\frac{2a^2}{EI} = \frac{P^2a^2}{BEI} = \frac{12P^2a^2}{B^2Eh^3}.
$$
令$G = G_c$：
$$
P_c = \frac{Bh}{a}\sqrt{\frac{G_cEh}{12}} = \frac{0.025\times0.006}{0.060}\sqrt{\frac{300\times70\times10^{9}\times0.006}{12}} = 0.0025\times1.025\times10^{5} = 256\ \mathrm{N}.
$$
合理性检查：$P_c \propto 1/a$，所以扩展裂纹所需的载荷随裂纹增长而**下降**——但在恒位移下$G = 9EI\delta^2/(4Ba^4)$按$a^{-4}$下降，所以在位移控制的试验中裂纹稳定扩展，这正是DCB是一种好试验的原因。
:::
:::

## 应力强度因子

欧文的互补方法着眼于应力。在线弹性体中任何裂纹的尖端附近，应力都具有普适的形式：它们随离尖端的距离$r$按$1/\sqrt r$增长，角向分布只取决于加载模式。关于几何形状和载荷的全部信息都集中在一个比例因子中。

::: definition 裂纹模式与应力强度因子 {#def-K}
裂纹有三种加载方式：**I型**（张开型——垂直于裂纹面的拉伸）、**II型**（面内滑开型）和**III型**（面外撕开型）。对I型，在以尖端为中心、$\theta = 0$指向正前方的极坐标$(r, \theta)$中，
$$
\sigma_{ij} = \frac{K_I}{\sqrt{2\pi r}}\,f_{ij}(\theta) + \text{（当 } r \to 0 \text{ 时有界的项）}, \qquad \text{例如}\quad \sigma_{yy}(r, 0) = \frac{K_I}{\sqrt{2\pi r}},
$$
其中函数$f_{ij}$是普适的：$f_{yy}(\theta) = \cos\frac\theta2\left(1 + \sin\frac\theta2\sin\frac{3\theta}{2}\right)$，其他分量有类似的表达式。**应力强度因子**$K_I$的单位为$\mathrm{MPa\sqrt m}$，它取决于载荷、裂纹尺寸和几何形状，写成
$$
K_I = Y\sigma\sqrt{\pi a},
$$ {#eq-K}
其中$\sigma$为参考应力，$Y$为无量纲几何因子：无限大板中长$2a$的中心裂纹$Y = 1$，半无限大板中深$a$的短边裂纹$Y \approx 1.12$，其他情况的值可查表（应力强度因子手册）。
:::

::: theorem 欧文的$G$-$K$关系 {#thm-irwin}
在I型加载的线弹性体中，
$$
G = \frac{K_I^2}{E'},
$$
平面应力时$E' = E$，平面应变时$E' = E/(1 - \nu^2)$。因此能量准则$G = G_c$与应力准则$K_I = K_{Ic}$等价，$K_{Ic} = \sqrt{E'G_c}$。
:::

::: proof
欧文的裂纹闭合论证：裂纹扩展$\Delta a$时释放的能量，等于把它在这段长度上重新闭合所需的功。闭合之前，新尖端后方的裂纹面按长度为$a + \Delta a$的裂纹的近尖端位移张开；在原尖端前方距离$x$处（即新尖端后方$\Delta a - x$处），张开量为$2v = \frac{8K_I}{E'}\sqrt{\frac{\Delta a - x}{2\pi}}$（由近尖端位移场得出）。闭合它需要原尖端前方作用的应力$\sigma_{yy} = K_I/\sqrt{2\pi x}$。单位厚度上的功除以$\Delta a$为
$$
G = \lim_{\Delta a \to 0}\frac{1}{\Delta a}\int_0^{\Delta a}\frac12\sigma_{yy}(x)\,2v(x)\,dx = \lim\frac{1}{\Delta a}\int_0^{\Delta a}\frac{K_I}{\sqrt{2\pi x}}\cdot\frac{4K_I}{E'}\sqrt{\frac{\Delta a - x}{2\pi}}\,dx = \frac{2K_I^2}{\pi E'\Delta a}\int_0^{\Delta a}\sqrt{\frac{\Delta a - x}{x}}\,dx .
$$
该积分等于$\pi\Delta a/2$（代换$x = \Delta a\sin^2\phi$），得$G = K_I^2/E'$。与格里菲斯结果对照：$K_I = \sigma\sqrt{\pi a}$给出$K_I^2/E' = \pi\sigma^2a/E'$，即[[#thm-griffith]]。✓
:::

于是线弹性断裂力学的实用形式就是一个不等式，
$$
K_I = Y\sigma\sqrt{\pi a} < K_{Ic},
$$ {#eq-criterion}
它把设计者关心的三个量联系起来：**应力**$\sigma$、**裂纹尺寸**$a$（来自检测或假设）和**韧度**$K_{Ic}$（材料性能，由标准试验测定）。已知其中任意两个，就能得出第三个。材料手册中引用的典型室温值：高强度铝合金$20$–$35\ \mathrm{MPa\sqrt m}$；钛合金$40$–$100$；调质钢$50$–$150$；低碳结构钢在室温下约$100$以上，但在其韧脆转变温度以下低得多；玻璃和陶瓷$0.5$–$5$。设计采用针对实际材料、厚度和温度的认证试验数据，而不是手册中的范围值。

:::

::: example 高强度钢与高韧性钢 {#ex-steels}
某构件按屈服强度的一半作为工作应力进行设计。钢A的$\sigma_Y = 1000\ \mathrm{MPa}$，$K_{Ic} = 60\ \mathrm{MPa\sqrt m}$；钢B的$\sigma_Y = 250\ \mathrm{MPa}$，$K_{Ic} = 150\ \mathrm{MPa\sqrt m}$。对宽板中的中心裂纹（$Y = 1$），求每种钢在工作应力下的临界裂纹长度$2a_c$。
::: solution
由[[#eq-criterion]]，$a_c = \frac1\pi\left(\frac{K_{Ic}}{\sigma}\right)^2$。

钢A，$\sigma = 500\ \mathrm{MPa}$：$a_c = \frac1\pi(60/500)^2 = 4.58\times10^{-3}\ \mathrm{m}$，所以$2a_c = 9.2\ \mathrm{mm}$。

钢B，$\sigma = 125\ \mathrm{MPa}$：$a_c = \frac1\pi(150/125)^2 = 0.458\ \mathrm{m}$，所以$2a_c = 917\ \mathrm{mm}$。

高强度钢承受四倍的应力，但容许的裂纹却短一百倍——这样小的裂纹在常规检测中可能被漏检。钢B的临界裂纹如此之长，以至于板会先在净截面上屈服；线弹性断裂力学甚至不适用。比例关系的合理性检查：$a_c \propto (K_{Ic}/\sigma)^2$，而$(150/125)/(60/500) = 10$，平方为100。✓ 这就是超高强度钢只用于检测可靠、且断裂后果已被充分认识的场合的实际原因。
:::
:::

::: warning K的单位、裂纹长度的约定以及平面应力与平面应变
(1) $K$的单位为$\mathrm{MPa\sqrt m}$：$a$要用**米**而不是毫米，否则答案会差$\sqrt{1000} = 31.6$倍。(2) 对中心裂纹，公式用的是**半**长$a$；对边裂纹，用的是全深度$a$。两者混用会使$K$相差$\sqrt2$倍，使临界长度相差2倍。(3) $K_{Ic}$是**平面应变**韧度，是在厚试样中测得的下限值；薄板由于塑性区较大，表观韧度较高，但该值依赖于厚度，不是材料常数。把薄板的值用于厚焊缝是偏于不安全的。(4) 许多钢的韧度在韧脆转变温度以下急剧下降——自由轮是在冷水中断裂的——所以所用的值必须对应服役温度。
:::

## 塑性区与线弹性断裂力学的适用限度

$1/\sqrt r$奇异性预测尖端处应力为无穷大，但实际材料会屈服。只要该理论失效的区域——**塑性区**——与裂纹和物体相比很小，线弹性断裂力学仍然适用，因为此时弹性的$K$场包围并控制着它。

::: proposition 欧文的塑性区估计 {#prop-plastic-zone}
在平面应力下，理想弹塑性材料中I型裂纹尖端前方塑性区的长度约为
$$
r_p = \frac1\pi\left(\frac{K_I}{\sigma_Y}\right)^2,
$$
是弹性$\sigma_{yy}$等于$\sigma_Y$处的距离$r_y = \frac{1}{2\pi}(K_I/\sigma_Y)^2$的两倍。在平面应变下，三向约束提高了屈服所需的应力，塑性区大约只有三分之一大，$r_p \approx \frac{1}{3\pi}(K_I/\sigma_Y)^2$。
:::

::: proof
第一步估计：令$\sigma_{yy}(r, 0) = K_I/\sqrt{2\pi r} = \sigma_Y$，得$r_y = K_I^2/(2\pi\sigma_Y^2)$。但弹性解在$r_y$范围内高出$\sigma_Y$的那部分应力，即面积$\int_0^{r_y}K_I/\sqrt{2\pi r}\,dr - \sigma_Y r_y = 2\sigma_Y r_y - \sigma_Y r_y = \sigma_Yr_y$，不能简单地消失：它必须向更远处传递，而材料只能通过在额外一段长度上屈服来做到这一点。欧文的力平衡给出额外的$r_y$，所以$r_p = 2r_y = K_I^2/(\pi\sigma_Y^2)$。在平面应变下，沿$\theta = 0$尖端附近的应力为$\sigma_{xx} = \sigma_{yy}$和$\sigma_{zz} = \nu(\sigma_{xx} + \sigma_{yy})$，所以米泽斯应力为$(1 - 2\nu)\sigma_{yy}$，$\nu = 0.3$时约为$0.4\sigma_{yy}$：屈服需要大得多的$\sigma_{yy}$，塑性区缩小。约为3的系数是欧文常用的估计值。
:::

平面应变断裂韧度的标准试验（ASTM E399）要求试样厚度$B$、裂纹长度$a$和剩余韧带$W - a$满足
$$
B,\ a,\ (W - a) \ \ge\ 2.5\left(\frac{K_{Ic}}{\sigma_Y}\right)^2,
$$ {#eq-e399}
约为平面应变塑性区的25倍，从而使塑性区被弹性材料包围，且厚度方向的约束很高。对高韧性、低强度的钢，这需要几百毫米厚的试样；对它们采用弹塑性断裂力学。

### 超越线弹性断裂力学：CTOD与J积分

当塑性区不小时，有两个参量取代$K$。韦尔斯（Wells，1961）提出以**裂纹尖端张开位移**（CTOD）——尖端处裂纹面的间距——作为断裂参量；它广泛用于焊接钢结构。赖斯（Rice，1968）引入了**J积分**，
$$
J = \int_\Gamma\left(W\,dy - \mathbf{t}\cdot\frac{\partial\mathbf{u}}{\partial x}\,ds\right),
$$
其中$\Gamma$是从一个裂纹面绕裂纹尖端到另一个裂纹面的任意围道，$W$为应变能密度，$\mathbf{t}$为围道上的面力。对非线性弹性（或形变塑性）材料，$J$与路径无关，因此可以在远离尖端、应力已知的地方计算，且它等于能量释放率；对线弹性材料，$J = G = K^2/E'$。临界值$J_{Ic}$由标准试验测定，所用试样比E399要求的小得多。

::: example 线弹性断裂力学是否适用？ {#ex-validity}
一块$5\ \mathrm{mm}$厚的$7075$-T6铝合金板（$\sigma_Y = 500\ \mathrm{MPa}$，$K_{Ic} = 28\ \mathrm{MPa\sqrt m}$，手册典型值）。求断裂时平面应力和平面应变下的塑性区，以及有效的E399试验所需的厚度。$K_{Ic}$是否是这块板的合适韧度？
::: solution
$(K_{Ic}/\sigma_Y)^2 = (28/500)^2 = 3.14\times10^{-3}\ \mathrm{m}$。平面应力塑性区：$r_p = 3.14\times10^{-3}/\pi = 1.0\ \mathrm{mm}$；平面应变：$r_p \approx 3.14\times10^{-3}/(3\pi) = 0.33\ \mathrm{mm}$。E399厚度：$B \ge 2.5\times3.14\times10^{-3}\ \mathrm{m} = 7.8\ \mathrm{mm}$。

板厚小于$7.8\ \mathrm{mm}$，所以它并非完全处于平面应变状态：其塑性区（约$1\ \mathrm{mm}$）是厚度的五分之一，表观韧度会比$K_{Ic}$略高。用$K_{Ic}$是保守的；不那么保守的设计会采用在实际厚度上测得的平面应力韧度或$R$曲线韧度。合理性检查：与检测人员要寻找的任何裂纹（几毫米到几十毫米）相比，塑性区都很小，所以线弹性断裂力学是适用的。
:::
:::

## 疲劳裂纹扩展

在循环载荷下，远小于临界尺寸的裂纹每个循环扩展极小的一段。帕里斯（Paris）、戈麦斯（Gomez）和安德森（Anderson）（1961）以及帕里斯和埃尔多安（Erdogan）（1963）表明，每循环的扩展速率由循环中应力强度因子的变化范围$\Delta K = K_{\max} - K_{\min} = Y\Delta\sigma\sqrt{\pi a}$控制。

::: definition 帕里斯公式 {#def-paris}
在$\Delta K$的中间范围内，疲劳裂纹扩展速率服从
$$
\frac{da}{dN} = C(\Delta K)^m,
$$ {#eq-paris}
其中$C$和$m$为材料常数（钢通常$m \approx 3$，铝合金为$3$–$4$）。低于**门槛值**$\Delta K_{th}$（钢为几$\mathrm{MPa\sqrt m}$）时，裂纹没有可测量的扩展；当$K_{\max}$接近$K_{Ic}$时，扩展加速直至断裂。对铁素体-珠光体钢，巴索姆（Barsom）和罗尔夫（Rolfe）给出了保守的拟合$C = 6.9\times10^{-12}$、$m = 3.0$，其中$da/dN$的单位为$\mathrm{m/cycle}$（米/循环），$\Delta K$的单位为$\mathrm{MPa\sqrt m}$。该公式是经验关联式；常数取决于材料、环境和应力比$R = K_{\min}/K_{\max}$。
:::

::: proposition 由帕里斯公式求疲劳寿命 {#prop-life}
若$Y$为常数，裂纹从$a_i$扩展到$a_f$所需的循环数为
$$
N = \int_{a_i}^{a_f}\frac{da}{C(Y\Delta\sigma\sqrt{\pi a})^m} = \frac{a_i^{1 - m/2} - a_f^{1 - m/2}}{C\,(Y\Delta\sigma\sqrt\pi)^m\,(m/2 - 1)}, \qquad m \ne 2,
$$
$m = 2$时$N = \ln(a_f/a_i)/[C\pi(Y\Delta\sigma)^2]$。
:::

::: proof
对[[#eq-paris]]分离变量：$dN = da/[C(Y\Delta\sigma\sqrt\pi)^m a^{m/2}]$。对$a^{-m/2}$积分：$\int a^{-m/2}\,da = a^{1 - m/2}/(1 - m/2)$，从$a_i$到$a_f$取值，并把符号移入分母，即得所述结果。$m = 2$时积分为$\ln a$。若$Y$随$a$变化（有限尺寸物体就是如此），积分用数值方法计算。
:::

对$m > 2$，寿命由第一项主导：$N \approx a_i^{1 - m/2}/[\dots]$。**初始**裂纹尺寸控制寿命，最终尺寸几乎无关紧要。这有两个推论：检测必须能发现小裂纹；临界裂纹尺寸的适度误差对预测寿命影响很小。

::: example 含裂纹板的疲劳寿命 {#ex-fatigue}
一块带边裂纹的宽钢板（$Y = 1.12$，假定为常数）承受从$20$到$200\ \mathrm{MPa}$的循环应力。钢材的$K_{Ic} = 60\ \mathrm{MPa\sqrt m}$，帕里斯常数$C = 6.9\times10^{-12}$，$m = 3$（m/循环，$\mathrm{MPa\sqrt m}$）。检测能可靠地发现深$1\ \mathrm{mm}$的裂纹。求临界裂纹深度以及$1\ \mathrm{mm}$裂纹扩展到破坏所需的循环数。从$1$扩展到$2\ \mathrm{mm}$占寿命的多大比例？
::: solution
$\sigma_{\max} = 200\ \mathrm{MPa}$时的临界深度：
$$
a_c = \frac1\pi\left(\frac{K_{Ic}}{Y\sigma_{\max}}\right)^2 = \frac1\pi\left(\frac{60}{1.12\times200}\right)^2 = 0.0228\ \mathrm{m} = 22.8\ \mathrm{mm}.
$$
$\Delta\sigma = 180\ \mathrm{MPa}$，$C(Y\Delta\sigma\sqrt\pi)^3 = 6.9\times10^{-12}\times(1.12\times180\times1.7725)^3 = 3.148\times10^{-4}$，且$m/2 - 1 = 0.5$：
$$
N = \frac{a_i^{-1/2} - a_c^{-1/2}}{0.5\times3.148\times10^{-4}} = \frac{31.62 - 6.62}{1.574\times10^{-4}} = 1.59\times10^{5}\ \text{次循环}.
$$
从$1$到$2\ \mathrm{mm}$：$N_{1\to2} = (31.62 - 22.36)/1.574\times10^{-4} = 5.88\times10^{4}$次循环，占寿命的**37 %**；裂纹达到临界尺寸一半之前已经消耗了寿命的89 %。合理性检查：初始扩展速率为$da/dN = C(1.12\times180\sqrt{\pi\times0.001})^3 = 1.0\times10^{-8}\ \mathrm{m}$每循环——约10纳米，即几十个原子间距，这与疲劳断口上看到的疲劳条带相符。若该板每年经受10 000次循环，就可以根据这一计算、并对寿命取安全因数，确定几年一次的检测间隔。
:::
:::

## 损伤容限设计

断裂力学改变了飞机及其他关键结构的设计理念。较早的**安全寿命**方法按带分散系数的规定寿命设计零件，使其在该寿命内不产生裂纹。**破损安全**方法提供冗余的传力路径，使一个构件的破坏不会导致整体崩溃。**损伤容限**方法于1970年代成为运输类飞机结构的强制要求，它假定缺陷在制造时就已存在或在服役中产生，并通过分析和试验表明，检测可能漏掉的最大缺陷在下次检测之前不会扩展到临界尺寸。其要素正是本章的内容：该几何形状的应力强度因子解、材料的$K_{Ic}$（或剩余强度曲线）和裂纹扩展数据、载荷谱，以及经过验证的检测能力。

对压力设备有一个相关的思想——**未爆先漏**（leak-before-break）：如果一条长到足以产生可检测泄漏的穿透壁厚裂纹，在工作压强下仍短于临界长度，那么容器或管道会先以泄漏的方式暴露裂纹，而不会发生断裂。BS 7910和API 579-1/ASME FFS-1等评定规程规定了这些计算；它们由具备资质的工程师使用，本章只讲授其背后的原理。

::: history
英格利斯（C. E. Inglis）于1913年在《造船工程师学会会刊》（*Transactions of the Institution of Naval Architects*）上发表了椭圆孔周围应力的解。在皇家飞机研究院工作的格里菲斯（A. A. Griffith）在1921年的论文《固体中的断裂与流动现象》（"The phenomena of rupture and flow in solids"，*Philosophical Transactions of the Royal Society A*）中用它通过能量平衡解释了玻璃的强度。战时船舶断裂事故之后，美国海军研究实验室的欧文（G. R. Irwin）和奥罗万（E. Orowan）在1940年代末把格里菲斯的思想推广到金属，欧文1957年发表在《应用力学杂志》（*Journal of Applied Mechanics*）上的论文引入了应力强度因子。帕里斯（P. C. Paris）和埃尔多安（F. Erdogan）1963年的论文确立了疲劳裂纹扩展与$\Delta K$之间的幂律关联。韦尔斯（A. A. Wells）于1961年提出了裂纹尖端张开位移，赖斯（J. R. Rice）于1968年引入了J积分。1954年的"彗星"号事故及随后的调查——包括对机身进行全尺寸压力试验——使增压结构的疲劳与断裂成为飞机设计的核心问题。
:::

::: quiz
宽板中的中心裂纹长度加倍。断裂应力如何变化？
- [ ] 减半。
- [x] 降为原来的$1/\sqrt2$。
- [ ] 降为原来的1/4。
::: solution
$\sigma_f = K_{Ic}/\sqrt{\pi a} \propto a^{-1/2}$，所以$a$加倍使$\sigma_f$除以$\sqrt2 \approx 1.41$。
:::
:::

::: quiz
关于平面应变断裂韧度$K_{Ic}$，哪个说法是正确的？
- [ ] 它随试样厚度无限增大。
- [x] 它是试样厚到足以在裂纹尖端形成平面应变时达到的韧度下限值。
- [ ] 它等于屈服强度乘以$\sqrt{\text{厚度}}$。
::: solution
表观韧度随厚度增加而下降，一旦约束足够高便稳定在$K_{Ic}$；ASTM E399通过要求$B \ge 2.5(K_{Ic}/\sigma_Y)^2$来保证这一点。
:::
:::

::: summary
- 基于应力的准则对裂纹失效：尖端应力无界（英格利斯：$1 + 2\sqrt{a/\rho}$）。
- 格里菲斯：当能量释放率$G = -\frac1B\,d\Pi/da$达到$G_c$时裂纹扩展；中心裂纹$G = \pi\sigma^2a/E'$。柔度法：$G = \frac{P^2}{2B}\frac{dC}{da}$。
- 欧文：近尖端场为$K/\sqrt{2\pi r}$乘以普适的角向函数；$K = Y\sigma\sqrt{\pi a}$；$G = K^2/E'$。当$K = K_{Ic}$时断裂。
- 临界裂纹尺寸$a_c = \frac1\pi(K_{Ic}/Y\sigma)^2$：高强度材料容许的裂纹要小得多。
- 塑性区$\sim\frac1\pi(K/\sigma_Y)^2$很小时，线弹性断裂力学适用；E399要求$B, a, W - a \ge 2.5(K_{Ic}/\sigma_Y)^2$。否则采用CTOD或$J$。
- 疲劳裂纹按$da/dN = C(\Delta K)^m$扩展；寿命由初始裂纹尺寸控制。损伤容限设计据此确定检测间隔。
:::

## 习题

::: exercise 能量释放率 {level=1 check="2"}
一个处于平面应力状态的钢构件（$E = 200\ \mathrm{GPa}$）中有一条$K_I = 20\ \mathrm{MPa\sqrt m}$的裂纹。求能量释放率。（以kJ/m²为单位输入$G$。）
::: solution
$G = K^2/E = (20\times10^{6})^2/(200\times10^{9}) = 2000\ \mathrm{J/m^2} = 2\ \mathrm{kJ/m^2}$。
:::

::: exercise 椭圆孔 {level=1 check="21"}
宽板中一个椭圆孔的半轴为$a = 10\ \mathrm{mm}$（垂直于载荷）和$b = 1\ \mathrm{mm}$。求应力集中系数。（输入$K_t$。）
::: solution
$K_t = 1 + 2a/b = 1 + 20 = 21$。
:::

::: exercise 韧度试验的厚度 {level=1 check="25"}
某钢$K_{Ic} = 50\ \mathrm{MPa\sqrt m}$，$\sigma_Y = 500\ \mathrm{MPa}$。ASTM E399要求的最小试样厚度是多少？（以mm为单位输入。）
::: solution
$B \ge 2.5(K_{Ic}/\sigma_Y)^2 = 2.5\times(0.1)^2 = 0.025\ \mathrm{m} = 25\ \mathrm{mm}$。
:::
:::

::: exercise 临界裂纹的比例关系 {level=2 check="8"}
一块板含有半长$2\ \mathrm{mm}$的裂纹时在$400\ \mathrm{MPa}$下断裂。若$Y$不变，半长为多少时它会在$200\ \mathrm{MPa}$下断裂？（以mm为单位输入。）
::: solution
$\sigma_f\sqrt a$为常数，所以$a_2 = a_1(\sigma_1/\sigma_2)^2 = 2\times4 = 8\ \mathrm{mm}$。
:::
:::

::: exercise 应力幅对疲劳寿命的影响 {level=2 check="16"}
某铝合金服从$m = 4$的帕里斯公式。若应力幅减半（其他条件不变），裂纹扩展寿命增加多少倍？（输入倍数。）
::: solution
初始和最终裂纹尺寸固定时$N \propto (\Delta\sigma)^{-m}$（若$\sigma_{\max}$改变，最终尺寸也会改变，但寿命对它不敏感）。$\Delta\sigma$减半使寿命乘以$2^4 = 16$。
:::
:::

::: exercise 受压圆筒中的临界裂纹 {level=2}
一根平均半径$500\ \mathrm{mm}$、壁厚$20\ \mathrm{mm}$的薄壁钢管承受$8\ \mathrm{MPa}$的内压。钢材$K_{Ic} = 120\ \mathrm{MPa\sqrt m}$，$\sigma_Y = 450\ \mathrm{MPa}$。把一条长的轴向穿透壁厚裂纹看作平板中受环向应力作用的中心裂纹（$Y = 1$，忽略鼓胀修正），求临界裂纹长度$2a_c$。管道是否会未爆先漏？
::: solution
环向应力$\sigma = pr/t = 8\times500/20 = 200\ \mathrm{MPa}$。$a_c = \frac1\pi(120/200)^2 = 0.115\ \mathrm{m}$，所以$2a_c = 229\ \mathrm{mm}$。一条只有$20\ \mathrm{mm}$长（壁厚）的穿透裂纹就已经泄漏，它比临界长度短十倍；表面裂纹会在达到临界长度之前很久就穿透壁厚而泄漏——未爆先漏是可能的。实际评定要计入**鼓胀（Folias）系数**，它使曲壳中轴向裂纹的$K$增大（约为$\sqrt{1 + 1.61a^2/rt}$倍，这里在$a = 115\ \mathrm{mm}$时为$1.8$，所以真实的临界长度要短得多，必须迭代求解），并校核泄漏率是否可以检测到。
:::
:::

::: exercise 格里菲斯能量平衡 {level=3}
(a) 从含长$2a$裂纹的板的能量$U(a) = -\pi\sigma^2a^2B/E + 4a\gamma_sB$出发，证明裂纹在$\sigma = \sqrt{2E\gamma_s/\pi a}$时处于（不稳定）平衡。(b) 证明在有限尺寸板的固定夹持（恒位移）条件下，裂纹可以是稳定的，并从物理上解释原因。(c) 利用[[#ex-dcb]]的DCB结果，证明在恒定张开量$\delta$下$G$随$a$下降。
::: solution
(a) $dU/da = -2\pi\sigma^2aB/E + 4\gamma_sB = 0$给出$\sigma^2 = 2E\gamma_s/(\pi a)$。$d^2U/da^2 = -2\pi\sigma^2B/E < 0$：是极大值，所以不稳定——任何扩展都会使能量进一步降低。
(b) 在固定夹持下，裂纹扩展会降低载荷，因为位移保持不变而柔度增大。若$C$增长得足够快，$G = \frac{\delta^2}{2BC^2}\frac{dC}{da}$可以随$a$减小，此时$dG/da < 0 = dG_c/da$，扩展一小段后便停止：储存的能量是有限的，被扩展消耗掉了。而在恒载荷下，加载系统可以无限制地提供能量。
(c) 对DCB，$C = 2a^3/3EI$，$P = \delta/C$，所以$G = \frac{P^2a^2}{BEI} = \frac{\delta^2}{C^2}\frac{a^2}{BEI} = \frac{9EI\delta^2}{4Ba^4}$，按$a^{-4}$下降：在位移控制下稳定扩展，这就是DCB试验能够记录裂纹扩展阻力曲线的原因。
:::
:::

::: exercise 确定检测间隔 {level=3}
起重机上的一个焊接钢支架每年承受$2\times10^{5}$次载荷循环，应力幅$100\ \mathrm{MPa}$，最大应力$120\ \mathrm{MPa}$。磁粉检测能可靠地发现深$3\ \mathrm{mm}$的表面裂纹。取$Y = 1.12$，最低服役温度下$K_{Ic} = 80\ \mathrm{MPa\sqrt m}$，以及钢的巴索姆-罗尔夫常数。(a) 求临界裂纹深度以及从$3\ \mathrm{mm}$起的裂纹扩展寿命。(b) 提出检测间隔，并讨论在依赖它之前你希望核实哪些假设。

(a) $a_c = \frac1\pi\left(\frac{80}{1.12\times120}\right)^2 = 0.113\ \mathrm{m}$——比实际支架还大，所以实际上破坏会来自净截面屈服或$Y$随深度增大；取$a_f = 50\ \mathrm{mm}$作为实际极限。$C(Y\Delta\sigma\sqrt\pi)^3 = 6.9\times10^{-12}\times(1.12\times100\times1.7725)^3 = 5.40\times10^{-5}$；$N = (0.003^{-1/2} - 0.05^{-1/2})/(0.5\times5.40\times10^{-5}) = (18.26 - 4.47)/2.70\times10^{-5} = 5.1\times10^{5}$次循环，约**2.5年**。
(b) 常用的规则是检测间隔不超过扩展寿命的一半，使某次漏检的裂纹能在下一次检测中被发现：约每年一次，或更频繁。需要核实的假设：实际焊缝几何形状的$Y$（焊趾附加的应力集中会增大小裂纹的$\Delta K$）、焊接残余应力（拉伸残余应力使整个循环都有效，所以如此处这样采用全应力幅）、实际载荷谱（偶尔的超载、低温韧度）、检测方法在$3\ \mathrm{mm}$时的检出概率、环境影响（腐蚀疲劳会增大$C$），以及破坏的后果。评定应由具备资质的工程师按BS 7910等公认规程进行。
