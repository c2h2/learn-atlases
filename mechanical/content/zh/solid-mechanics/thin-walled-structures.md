飞机机翼是一个盒子：它由几毫米厚的金属板或复合材料蒙皮制成，用桁条加强，由翼梁封闭，跨度达许多米，承受升力、重力和扭矩。汽车的底盘纵梁、船体梁、冷弯型钢檩条和自行车车架管也都是这样构造的：材料被放在尽可能远离形心的地方，壁厚远小于截面宽度。这类**薄壁**构件的抗弯效率极高；而在扭转中，它们要么极其刚硬，要么极其柔软，这取决于一个细节——截面是否闭合。半径$50\ \mathrm{mm}$、壁厚$2\ \mathrm{mm}$的钢管，若沿长度方向切开一条缝，就会丧失99.9 %以上的抗扭刚度。

本章以飞机和车辆结构中使用的形式建立薄壁梁理论。它由三个思想支撑：**一般（非对称）弯曲公式**，它去掉了[[mechanics-of-materials/bending-stress]]中关于载荷位于对称平面内的假设；**剪流**，即单位壁长上的剪力，它把剪切和扭转问题变成沿壁的簿记；以及**弯曲中心**，即横向载荷必须通过的点，梁才能只弯曲而不扭转。

**坐标与符号规定。** 梁轴为$x$；横截面位于$y$–$z$平面内，原点在形心。$s$是沿壁中线量取的坐标，$t(s)$为壁厚。面积二次矩：$I_{yy} = \int z^2\,dA$，$I_{zz} = \int y^2\,dA$，惯性积$I_{yz} = \int yz\,dA$。弯矩$M_y$和$M_z$分别以在$z$为正和$y$为正的点处产生拉应力为正。正应力以拉为正。

::: definition 薄壁截面与剪流 {#def-shear-flow}
当壁厚$t$与截面其他尺寸相比很小时（实际中$t/b \lesssim 0.1$），称截面为**薄壁**截面。此时认为应力沿厚度均匀分布，切应力与中线相切。**剪流**为
$$
q(s) = \tau(s)\,t(s),
$$
即中线单位长度上的剪力，单位为$\mathrm{N/mm}$。若截面中线有自由端（槽形、工字形、角形、开缝管），称截面为**开口**截面；若中线构成一个或多个闭合回路（管、箱形、多闭室翼盒），称截面为**闭口**截面。
:::

$q$的意义在于它沿壁是守恒的，就像电流在导线中守恒一样。在没有轴向应力梯度的构件中取一小块壁元$dx \times ds$，其两条边$s$和$s + ds$上作用着剪力$q\,dx$；$x$方向的平衡使两者相等。因此在纯扭转中$q$沿闭室一周为常数，而在几块壁相交的节点处，流入的剪流必须等于流出的剪流。

## 非对称弯曲

若梁的截面没有对称轴——角钢、Z形截面、两侧翼梁高度不等的翼盒——绕一个轴的弯矩会使它绕两个轴弯曲。这时工程弯曲公式$\sigma = My/I$给出的应力是错误的，有时差到两倍。

::: theorem 一般弯曲公式 {#thm-unsym}
对平截面保持为平面的线弹性材料直梁，取形心轴$y$、$z$（不必是主轴），弯矩$M_y$和$M_z$引起的正应力为
$$
\sigma_x = \frac{(M_z I_{yy} - M_y I_{yz})\,y + (M_y I_{zz} - M_z I_{yz})\,z}{I_{yy}I_{zz} - I_{yz}^2} .
$$ {#eq-unsym}
中性轴（$\sigma_x = 0$）通过形心，与$y$轴的夹角为$\alpha$，$\tan\alpha = -\dfrac{M_zI_{yy} - M_yI_{yz}}{M_yI_{zz} - M_zI_{yz}}$。若$I_{yz} = 0$，公式化为$\sigma_x = M_y z/I_{yy} + M_z y/I_{zz}$。
:::

::: proof
平截面保持为平面意味着轴向应变在截面上是线性函数，$\varepsilon_x = \varepsilon_0 + \kappa_z y + \kappa_y z$，而无横向应力时的胡克定律给出$\sigma_x = E\varepsilon_x$。合力必须是零轴力和外加弯矩：
$$
N = \int\sigma_x\,dA = E(\varepsilon_0 A + \kappa_z\!\int y\,dA + \kappa_y\!\int z\,dA) = E\varepsilon_0 A = 0,
$$
因为对形心轴的静矩为零；所以$\varepsilon_0 = 0$。于是
$$
M_y = \int\sigma_x z\,dA = E(\kappa_z I_{yz} + \kappa_y I_{yy}), \qquad M_z = \int\sigma_x y\,dA = E(\kappa_z I_{zz} + \kappa_y I_{yz}).
$$
用克拉默法则解这个$2\times2$方程组，
$$
E\kappa_y = \frac{M_yI_{zz} - M_zI_{yz}}{I_{yy}I_{zz} - I_{yz}^2}, \qquad E\kappa_z = \frac{M_zI_{yy} - M_yI_{yz}}{I_{yy}I_{zz} - I_{yz}^2},
$$
而$\sigma_x = E(\kappa_zy + \kappa_yz)$就是[[#eq-unsym]]。中性轴是通过原点的直线$\kappa_z y + \kappa_y z = 0$，由此得所述斜率。假设：平截面（不计约束翘曲效应），线弹性，以及载荷不引起扭转——即载荷通过弯曲中心（见下文）。
:::

另一种做法是求截面的**主轴**（在主轴上$I_{yz} = 0$），把弯矩沿主轴分解，再把两个对称弯曲应力相加。两种途径结果相同；[[#eq-unsym]]免去了计算主轴角度。

::: example Z形檩条 {#ex-zsection}
一个Z形截面有高$h = 100\ \mathrm{mm}$的竖直腹板和两块宽$b = 50\ \mathrm{mm}$的水平翼缘，上翼缘指向$+y$，下翼缘指向$-y$；各壁厚均为$t = 4\ \mathrm{mm}$（尺寸量到中线；忽略$t^3$项）。它承受绕水平轴的$2.0\ \mathrm{kN\,m}$正弯矩（下部受拉）。求腹板与翼缘交接处和翼缘尖端处的正应力，以及中性轴的方向。
::: solution
截面是反对称的，所以形心在腹板中点。把腹板放在$y = 0$、$-50 \le z \le 50$处，上翼缘从$(0, 50)$到$(50, 50)$，下翼缘从$(0, -50)$到$(-50, -50)$。
$$
\begin{aligned}
I_{yy} &= \frac{t h^3}{12} + 2(bt)\left(\frac h2\right)^2 = 333\,333 + 1\,000\,000 = 1.333\times10^{6}\ \mathrm{mm^4},\\
I_{zz} &= 2\cdot\frac{t b^3}{3} = 3.333\times10^{5}\ \mathrm{mm^4},\\
I_{yz} &= \int_0^{50}(y)(50)\,t\,dy + \int_{-50}^0 (y)(-50)\,t\,dy = 250\,000 + 250\,000 = 5.000\times10^{5}\ \mathrm{mm^4}.
\end{aligned}
$$
下部（$z$为负）受拉意味着$M_y = -2.0\times10^{6}\ \mathrm{N\,mm}$；$M_z = 0$。分母为$I_{yy}I_{zz} - I_{yz}^2 = 4.444\times10^{11} - 2.500\times10^{11} = 1.944\times10^{11}\ \mathrm{mm^8}$，且
$$
\sigma_x = \frac{-M_yI_{yz}\,y + M_yI_{zz}\,z}{1.944\times10^{11}} = \frac{(1.0\times10^{12})\,y - (6.667\times10^{11})\,z}{1.944\times10^{11}} = 5.143\,y - 3.429\,z\ \ (\mathrm{MPa}).
$$
在上部腹板-翼缘交接处$(0, 50)$：$\sigma_x = -171.4\ \mathrm{MPa}$；在上翼缘尖端$(50, 50)$：$257.1 - 171.4 = +85.7\ \mathrm{MPa}$。由反对称性，下部交接处为$+171.4\ \mathrm{MPa}$，下翼缘尖端为$-85.7\ \mathrm{MPa}$。中性轴为$5.143y = 3.429z$，即$z = 1.5y$：与水平方向成$56.3^\circ$。

合理性检查：若把截面当作只绕水平轴弯曲，会得到翼缘上处处$\sigma = Mz/I_{yy} = 2\times10^{6}\times50/1.333\times10^{6} = 75\ \mathrm{MPa}$。真实的峰值大$2.3$倍，而且翼缘尖端的应力与交接处**符号相反**。梁除了向下挠曲还会侧向挠曲，这就是为什么坡屋面上的Z形檩条需要拉条或由屋面板提供约束。
:::
:::

## 开口截面中的剪流

横向剪力使弯矩沿梁变化，因而壁上某点的正应力随$x$变化。这种不平衡必须由剪流沿壁传递，与[[mechanics-of-materials/transverse-shear]]中推导$\tau = VQ/It$的方式相同——但现在适用于任意薄壁形状。

::: proposition 剪力引起的剪流 {#prop-shear-flow}
对承受通过弯曲中心（不扭转）的剪力$S_y = dM_z/dx$和$S_z = dM_y/dx$的薄壁梁，沿壁位置$s$处的剪流为
$$
q(s) = q_0 - \frac{S_yI_{yy} - S_zI_{yz}}{I_{yy}I_{zz} - I_{yz}^2}\int_0^s t\,y\,ds - \frac{S_zI_{zz} - S_yI_{yz}}{I_{yy}I_{zz} - I_{yz}^2}\int_0^s t\,z\,ds,
$$ {#eq-shear-flow}
其中$q_0$为$s = 0$处的剪流。在开口截面中，$s$从自由边量起，该处$q_0 = 0$。对关于$y$轴对称（$I_{yz} = 0$）且只有$S_z$的截面，上式为$q = -S_zQ_y(s)/I_{yy}$，其中$Q_y(s) = \int_0^s tz\,ds$是自由边与$s$之间那段壁的静矩。
:::

::: proof
取壁元$dx \times ds$。在其$x$和$x + dx$面上作用着轴向力$\sigma_x t\,ds$和$(\sigma_x + \partial\sigma_x/\partial x\,dx)\,t\,ds$；在其$s$和$s + ds$边上作用着$x$方向的剪力$q\,dx$和$(q + \partial q/\partial s\,ds)\,dx$（由切应力互等，沿壁的剪流等于横穿壁的截面上的纵向剪流）。$x$方向平衡：
$$
\frac{\partial q}{\partial s} + t\frac{\partial\sigma_x}{\partial x} = 0 .
$$
沿梁对[[#eq-unsym]]求导，利用$dM_y/dx = S_z$和$dM_z/dx = S_y$（以及截面性质不变）：
$$
\frac{\partial\sigma_x}{\partial x} = \frac{(S_yI_{yy} - S_zI_{yz})\,y + (S_zI_{zz} - S_yI_{yz})\,z}{I_{yy}I_{zz} - I_{yz}^2}.
$$
代入并从$0$积分到$s$即得[[#eq-shear-flow]]。在自由边处没有相邻材料来承受纵向剪力，所以$q_0 = 0$。之所以需要载荷通过弯曲中心的假设，是因为否则还必须叠加一个附加的扭转剪流。
:::

::: warning 剪流的符号：让物理来决定
公式[[#eq-shear-flow]]给出的$q$以$s$增大的方向为正，但这是"沿腹板向上"还是"沿腹板向下"，取决于$S_y$、$S_z$相对于载荷的符号规定，而各教材并不一致。稳妥的做法是：先用$|Q|$算出**大小**，再用两个物理检验确定每个方向——剪流的竖直分量之和必须等于外加的竖向剪力，且在每个节点处流入必须等于流出（如同节点处的电流）。不能通过其中任一检验的剪流图就有符号错误。另一个常见错误是在**非对称**截面中使用从中性轴量取$Q$的$VQ/It$：那时需要[[#eq-shear-flow]]中的两项。
:::

### 弯曲中心

对一个由通过腹板的竖向力加载的槽形截面，翼缘中的剪流产生一对大小相等、方向相反、相距$h$的水平力$F$：一个力偶。截面上没有其他东西能平衡它，所以槽钢会扭转。若把载荷从腹板移到远离翼缘的一侧，它对腹板的力矩就能抵消这个力偶；在某个特定位置，梁只弯曲而不扭转。这个位置就是**弯曲中心**。

::: definition 弯曲中心 {#def-shear-centre}
横截面的**弯曲中心**（剪切中心）是横向载荷的合力必须通过的点，梁才能只弯曲而不扭转。等价地，它是这样一个点：任何剪力所产生的剪流（按无扭转情形用[[#eq-shear-flow]]计算）对它的力矩等于该剪力对它的力矩。它位于截面的每一根对称轴上；对由交于一点的直壁组成的截面（角形、T形、十字形），它就在该交点处。
:::

::: proposition 槽形截面的弯曲中心 {#prop-channel}
腹板高$h$、翼缘宽$b$（均量到中线）、壁厚均匀为$t$的槽形截面，其弯曲中心位于对称轴上，在远离翼缘的一侧，距腹板中线
$$
e = \frac{3b^2}{h + 6b}
$$
处。
:::

::: proof
对对称轴的惯性矩（忽略$t^3$项）为$I = \tfrac{th^3}{12} + 2bt\left(\tfrac h2\right)^2 = \tfrac{th^2}{12}(h + 6b)$。施加竖向剪力$V$。在上翼缘中，$s$从自由尖端量起，截面以外那段壁的静矩为$Q = ts\,(h/2)$，所以剪流为$q = Vts h/(2I)$，线性增长到拐角处的$Vtbh/(2I)$。翼缘力为
$$
F = \int_0^b q\,ds = \frac{Vtb^2h}{4I}.
$$
下翼缘承受方向相反的同样大小的力，腹板承受竖向剪力$V$（检验：腹板剪流积分为$V$，因为翼缘不承受竖向力）。对腹板中点取矩：腹板剪流没有力臂；两个翼缘力构成力偶$Fh$。要不扭转，作用在距腹板$e$处的载荷$V$必须产生相同的力矩：$Ve = Fh$，所以
$$
e = \frac{tb^2h^2}{4I} = \frac{tb^2h^2}{4}\cdot\frac{12}{th^2(h + 6b)} = \frac{3b^2}{h + 6b}. 
$$
:::

:::

::: example 槽形截面的切应力与弯曲中心 {#ex-channel}
一个槽形截面$h = 200\ \mathrm{mm}$，$b = 80\ \mathrm{mm}$，$t = 5\ \mathrm{mm}$（中线尺寸），承受竖向剪力$V = 20\ \mathrm{kN}$。求翼缘-腹板拐角处和中性轴处的切应力，以及弯曲中心的位置。
::: solution
$I = \tfrac{th^2}{12}(h + 6b) = \tfrac{5\times200^2}{12}\times680 = 1.133\times10^{7}\ \mathrm{mm^4}$。

在拐角处，$Q = tb\,(h/2) = 5\times80\times100 = 40\,000\ \mathrm{mm^3}$：
$$
q = \frac{VQ}{I} = \frac{20\,000\times40\,000}{1.133\times10^{7}} = 70.6\ \mathrm{N/mm}, \qquad \tau = q/t = 14.1\ \mathrm{MPa}.
$$
在中性轴处再加上腹板的上半部分，$Q = 40\,000 + 5\times100\times50 = 65\,000\ \mathrm{mm^3}$：$q = 114.7\ \mathrm{N/mm}$，$\tau_{\max} = 22.9\ \mathrm{MPa}$。

弯曲中心：$e = 3\times80^2/(200 + 480) = 28.2\ \mathrm{mm}$，距腹板中线，位于槽钢之外。用翼缘力校核：$F = Vtb^2h/(4I) = 20\,000\times5\times6400\times200/(4\times1.133\times10^{7}) = 2824\ \mathrm{N}$，$Fh/V = 2824\times200/20\,000 = 28.2\ \mathrm{mm}$。✓

合理性检查：腹板平均切应力$V/(ht) = 20\ \mathrm{MPa}$介于拐角值和峰值之间，这正符合腹板上"常数加抛物线"的分布；翼缘不承受竖向合力，所以腹板承担全部$V$。
:::

## 闭口截面的扭转

扭转一根闭口薄壁管。没有轴向应力梯度时，上面的微元论证给出$\partial q/\partial s = 0$：无论厚度如何变化，单闭室**壁上每一点的剪流都相同**。壁薄的地方应力高；单位长度上的力是常数。

::: theorem 布雷特-巴索公式 {#thm-bredt}
受扭矩$T$作用（翘曲不受约束）的单闭室薄壁截面承受常剪流
$$
q = \frac{T}{2A},
$$ {#eq-bredt}
其中$A$为壁中线所围的面积，扭转率为
$$
\frac{d\theta}{dx} = \frac{T}{4A^2G}\oint\frac{ds}{t}, \qquad\text{从而}\qquad J = \frac{4A^2}{\oint ds/t}.
$$ {#eq-bredt-twist}
:::

::: proof
$q$为常数已在上面证明。剪流对截面平面内任一点$O$的力矩为$\oint q\,p\,ds$，其中$p$是$O$到中线切线的垂直距离。而$\tfrac12p\,ds$是以$O$为顶点、$ds$为底的细三角形的面积，所以$\oint p\,ds = 2A$，$T = q\cdot2A$。（结果与$O$无关，对纯力偶理应如此。）

扭转率用能量法求。切应力$\tau = q/t$在单位体积中储存应变能$\tau^2/(2G)$，所以梁单位长度上
$$
U' = \oint\frac{q^2}{2Gt^2}\,t\,ds = \frac{q^2}{2G}\oint\frac{ds}{t} = \frac{T^2}{8A^2G}\oint\frac{ds}{t}.
$$
它等于扭矩在单位长度上所做的功$\tfrac12T\,d\theta/dx$，由此得[[#eq-bredt-twist]]。假设：薄壁，线弹性，横截面保持形状（可以自由地发生面外翘曲），$\tau$沿$t$均匀。
:::

### 开口截面的扭转

开口截面不能靠绕截面环流的剪流承受扭矩——没有闭合路径。相反，每一块薄壁都像一条受扭的狭长矩形条，切应力沿厚度线性变化并在中线处变号："剪流"在厚度内环流，力臂只有$t$的量级。

::: proposition 薄壁开口截面的扭转 {#prop-open}
由长度为$b_i$、厚度为$t_i$的壁组成的薄壁开口截面，其扭转常数和最大切应力为
$$
J = \sum_i\frac{b_it_i^3}{3}, \qquad \frac{d\theta}{dx} = \frac{T}{GJ}, \qquad \tau_{\max} = \frac{T\,t_{\max}}{J}.
$$
:::

::: proof
对单根宽度$b \gg t$的狭条，在远离狭条端部处，普朗特（Prandtl）应力函数只依赖于厚度方向坐标$n$：$\phi = G\theta'(t^2/4 - n^2)$，它满足$\nabla^2\phi = -2G\theta'$，并在表面$n = \pm t/2$上为零。于是$\tau = -\partial\phi/\partial n = 2G\theta'n$，在表面上最大，为$G\theta't$；扭矩$T = 2\int\phi\,dA = 2G\theta' b\int_{-t/2}^{t/2}(t^2/4 - n^2)\,dn = G\theta'\,bt^3/3$。（$T = 2\int\phi\,dA$中的因子2包含了短边切应力的贡献，它们虽然作用面积极小，却承担了一半扭矩。）因此$J = bt^3/3$，$\tau_{\max} = G\theta't = Tt/J$。对以相同扭转率一起扭转的多壁截面，扭矩相加：$T = G\theta'\sum b_it_i^3/3$。这一近似忽略了拐角和端部，当每个$b_i/t_i$都很大时是可以接受的。
:::

::: example 开缝管与闭口管的比较 {#ex-slit}
一根钢管（$G = 80\ \mathrm{GPa}$）平均半径$R = 50\ \mathrm{mm}$，壁厚$t = 2\ \mathrm{mm}$，承受$500\ \mathrm{N\,m}$的扭矩。求(a)闭口管和(b)沿长度开缝后的切应力和每米扭转角。在相同切应力下，开缝管能承受多大扭矩？
::: solution
(a) 闭口：$A = \pi R^2 = 7854\ \mathrm{mm^2}$，$q = T/2A = 5\times10^{5}/15\,708 = 31.8\ \mathrm{N/mm}$，$\tau = 15.9\ \mathrm{MPa}$。$J = 4A^2/(2\pi R/t) = 2\pi R^3t = 1.571\times10^{6}\ \mathrm{mm^4}$，
$$
\frac{d\theta}{dx} = \frac{T}{GJ} = \frac{5\times10^{5}}{80\,000\times1.571\times10^{6}} = 3.98\times10^{-6}\ \mathrm{rad/mm} = 0.228^\circ/\mathrm{m}.
$$
(b) 开缝：一根宽$2\pi R = 314.2\ \mathrm{mm}$的狭条：$J = 314.2\times2^3/3 = 837.8\ \mathrm{mm^4}$。在相同扭矩下，$\tau = Tt/J = 5\times10^{5}\times2/837.8 = 1194\ \mathrm{MPa}$——管子早就屈服了——而扭转率会大$1875$倍。在相同的$15.9\ \mathrm{MPa}$应力下，开缝管只能承受$T = \tau J/t = 15.9\times837.8/2 = 6.67\ \mathrm{N\,m}$。

这些比值具有一般性：$J_\text{closed}/J_\text{open} = 3(R/t)^2 = 1875$，$\tau_\text{open}/\tau_\text{closed} = 3R/t = 75$。合理性检查：闭口管的结果与实心轴公式$J = \tfrac{\pi}{2}(R_o^4 - R_i^4)$在$R_o = 51$、$R_i = 49\ \mathrm{mm}$时的结果一致：$1.572\times10^{6}\ \mathrm{mm^4}$。
:::

## 闭口截面的剪切与扭转

作用在闭口截面上的剪力所产生的剪流不能仅由[[#eq-shear-flow]]求出，因为没有已知$q_0$的自由边。做法是在方便的位置**切开**壁，从切口算起计算开口截面剪流$q_b(s)$，再加上一个沿闭室的未知常剪流$q_{s,0}$。这个常数由一个附加条件确定：总剪流对任一点的力矩必须等于外加载荷对该点的力矩（若载荷不通过弯曲中心，扭转率则由[[#eq-bredt-twist]]类型的积分得到）。利用对称性，切口常常可以放在$q = 0$处。

::: example 薄壁圆管中的切应力 {#ex-tube-shear}
平均半径为$R$、厚度为$t$的薄壁管承受通过其中心的横向剪力$V$。证明最大切应力为$2V/A_\text{wall}$，即平均值的两倍，并对$V = 15\ \mathrm{kN}$、$R = 40\ \mathrm{mm}$、$t = 3\ \mathrm{mm}$计算其值。
::: solution
令$V$沿$z$方向作用，角度$\phi$从管顶量起。由关于$z$轴的对称性，顶部和底部剪流为零，所以在$\phi = 0$处"切开"有$q_0 = 0$。由$I = \pi R^3t$和$z = R\cos\phi$：
$$
q(\phi) = \frac{V}{I}\int_0^\phi t\,(R\cos\psi)\,R\,d\psi = \frac{VR^2t\sin\phi}{\pi R^3t} = \frac{V\sin\phi}{\pi R}.
$$
最大值在$\phi = 90^\circ$（中性轴）处：$q_{\max} = V/(\pi R)$，$\tau_{\max} = V/(\pi Rt) = 2V/(2\pi Rt) = 2V/A_\text{wall}$。检验：剪流的竖直分量$2\int_0^\pi q\sin\phi\,R\,d\phi = \tfrac{2V}{\pi}\cdot\tfrac{\pi}{2} = V$。✓

数值：$A_\text{wall} = 2\pi\times40\times3 = 754\ \mathrm{mm^2}$，$\tau_{\max} = 2\times15\,000/754 = 39.8\ \mathrm{MPa}$。
:::
:::

### 多闭室截面

翼盒通常有两三根翼梁，形成两个或更多闭室。受扭时，每个闭室$i$承受自己的常剪流$q_i$；闭室$i$与$j$共用的内腹板承受$q_i - q_j$。此时未知量比扭矩平衡所能确定的多，附加方程来自相容条件：所有闭室的扭转率相同，因为截面在其平面内作刚体转动。

::: algorithm $n$闭室截面的扭转 {#alg-multicell}
1. 给每个闭室指定一个未知常剪流$q_i$（逆时针为正）。闭室$i$与$j$之间的壁承受$q_i - q_j$（以闭室$i$的转向为正）。
2. 扭矩平衡：$T = \sum_i 2A_iq_i$。
3. 每个闭室的扭转率，由对单个闭室写出的布雷特第二公式：$\dfrac{d\theta}{dx} = \dfrac{1}{2A_iG}\oint_i\dfrac{q\,ds}{t}$，积分沿闭室$i$一周进行，各壁取其中实际存在的剪流。
4. 令$n$个扭转率相等；解$n + 1$个线性方程，求出$q_1, \dots, q_n$和$d\theta/dx$。然后$J = T/(G\,d\theta/dx)$，各壁中$\tau = q/t$。
:::

::: example 双闭室翼盒 {#ex-twocell}
一个铝合金双闭室盒（$G = 27\ \mathrm{GPa}$）宽$300\ \mathrm{mm}$、高$100\ \mathrm{mm}$（中线尺寸），由距左侧$200\ \mathrm{mm}$的内腹板分隔，使闭室1为$200\times100$，闭室2为$100\times100\ \mathrm{mm}$。所有壁厚均为$2\ \mathrm{mm}$。求$T = 10\ \mathrm{kN\,m}$作用下的剪流和扭转率，并与无内腹板的盒子比较。
::: solution
$A_1 = 20\,000\ \mathrm{mm^2}$，$A_2 = 10\,000\ \mathrm{mm^2}$。闭室1的外壁总长$500\ \mathrm{mm}$，闭室2为$300\ \mathrm{mm}$，共用腹板$100\ \mathrm{mm}$；各处$t = 2\ \mathrm{mm}$。
$$
\begin{aligned}
&T: && 40\,000\,q_1 + 20\,000\,q_2 = 10^{7}\ \mathrm{N\,mm},\\
&\text{闭室 1}: && \theta' = \frac{1}{2A_1G}\left[\frac{500}{2}q_1 + \frac{100}{2}(q_1 - q_2)\right] = \frac{300q_1 - 50q_2}{2A_1G},\\
&\text{闭室 2}: && \theta' = \frac{1}{2A_2G}\left[\frac{300}{2}q_2 + \frac{100}{2}(q_2 - q_1)\right] = \frac{200q_2 - 50q_1}{2A_2G}.
\end{aligned}
$$
令扭转率相等：$(300q_1 - 50q_2)/2 = 200q_2 - 50q_1$，所以$q_1 = 1.125\,q_2$。结合扭矩方程：$q_2 = 153.8\ \mathrm{N/mm}$，$q_1 = 173.1\ \mathrm{N/mm}$，内腹板承受$q_1 - q_2 = 19.2\ \mathrm{N/mm}$。切应力分别为$86.5$、$76.9$和$9.6\ \mathrm{MPa}$。扭转率为
$$
\theta' = \frac{300(173.1) - 50(153.8)}{2(20\,000)(27\,000)} = 4.10\times10^{-5}\ \mathrm{rad/mm} = 2.35^\circ/\mathrm{m}.
$$
无内腹板时（一个$300\times100$的闭室）：$q = T/2A = 166.7\ \mathrm{N/mm}$，$\tau = 83.3\ \mathrm{MPa}$，$\theta' = T\oint ds/t/(4A^2G) = 10^{7}\times400/(4\times30\,000^2\times27\,000) = 4.12\times10^{-5}\ \mathrm{rad/mm}$。

内腹板使抗扭刚度的变化不到1 %，承担的扭矩也很少：它的作用是抗剪（它是翼梁）和保证稳定，而不是抗扭。检验：$2A_1q_1 + 2A_2q_2 = 6.92 + 3.08 = 10.0\ \mathrm{kN\,m}$。✓
:::

::: application 飞机结构中的结构理想化
在加筋机翼或机身中，桁条和梁缘条承担大部分正应力，而它们之间的薄蒙皮主要承受剪切。因此飞机强度分析人员把截面**理想化**为集中面积，即**桁条面积**（booms），它们承担全部正应力，由只承受剪流的蒙皮板连接。于是两根桁条之间的剪流为常数，[[#eq-shear-flow]]变成求和：跨过位于$(y_r, z_r)$、面积为$B_r$的桁条时，$q$改变$-(S_y$项$)B_ry_r - (S_z$项$)B_rz_r$。这一方法由梅格森（Megson）详细阐述，是在有限元模型建立之前手算确定翼盒尺寸的方法，也是校核模型结果的方法。实际飞机结构由具备资质的工程师按适航规章进行审定；手算方法教人知道数字应当是什么样子。
:::

::: history
薄壁闭口管扭转的公式$q = T/2A$由德国工程师鲁道夫·布雷特（Rudolf Bredt）于1896年发表在德国工程师协会（Verein Deutscher Ingenieure）的会刊上，由于后来西里尔·巴索（Cyril Batho）的工作，常被称为布雷特-巴索公式。弯曲中心——槽钢上的载荷必须通过才能避免扭转的点——是在1920年代初被认识到的；瑞士工程师罗伯特·马亚尔（Robert Maillart）1921年发表在《瑞士建筑杂志》（*Schweizerische Bauzeitung*）上的论文把这一概念引入了工程实践。薄壁开口梁的一般理论，包括当这里假设的自由翘曲受到约束时产生的翘曲应力，由苏联工程师瓦西里·符拉索夫（Vasily Vlasov）建立，他关于薄壁弹性梁的著作出版于1940年。
:::

::: quiz
一个闭口薄壁截面的壁有两种厚度：$2\ \mathrm{mm}$和$4\ \mathrm{mm}$。在纯扭转下，哪种说法正确？
- [ ] 所有壁中的切应力相同。
- [x] 所有壁中的剪流相同；较薄壁中的切应力是较厚壁中的两倍。
- [ ] 较厚的壁承受两倍的剪流。
::: solution
在纯扭转的单闭室中，壁元的纵向平衡迫使$\partial q/\partial s = 0$，所以处处$q = T/2A$，而$\tau = q/t$在壁最薄处最大。
:::
:::

::: quiz
等边角钢截面的弯曲中心在哪里？
- [ ] 在其形心。
- [x] 在两肢相交的角点。
- [ ] 在截面之外、对称轴上、角点以外。
::: solution
两肢中的剪流都沿各肢中线作用，而两条中线都通过角点；因此它们的合力对角点没有力矩，所以通过角点的载荷不引起扭转（[[#def-shear-centre]]）。
:::
:::

::: summary
- 在薄壁截面中，用剪流$q = \tau t$进行分析；在没有轴向应力梯度的壁中它沿壁为常数，在节点处流入等于流出。
- 非对称弯曲：$\sigma_x = [(M_zI_{yy} - M_yI_{yz})y + (M_yI_{zz} - M_zI_{yz})z]/(I_{yy}I_{zz} - I_{yz}^2)$；中性轴一般不垂直于弯矩作用面。
- 开口截面中的剪流来自$\partial q/\partial s = -t\,\partial\sigma_x/\partial x$，从$q = 0$的自由边开始积分。
- 弯曲中心是载荷必须作用的位置，才能只引起弯曲而不扭转；对槽形截面，$e = 3b^2/(h + 6b)$，从腹板量起，在截面之外。
- 闭口截面：$q = T/2A$，$d\theta/dx = (T/4A^2G)\oint ds/t$。开口截面：$J = \sum bt^3/3$，$\tau_{\max} = Tt/J$。使截面闭合可使其抗扭刚度提高$(R/t)^2$量级的倍数。
- 受剪的闭口截面：切开，计算开口截面剪流，再加上由力矩平衡确定的常数。受扭的多闭室截面：每个闭室一个$q$，扭转率相等。
:::

::: exercise 矩形管的扭转 {level=2 check="0.01875"}

::: exercise 不等边角钢 {level=2}
一个角形截面有一条$100\ \mathrm{mm}$的竖肢和一条$60\ \mathrm{mm}$的水平肢（从角点量起的中线长度），厚度均为$5\ \mathrm{mm}$。它承受绕水平轴的$1.0\ \mathrm{kN\,m}$弯矩，竖肢顶部受拉。求形心、$I_{yy}$、$I_{zz}$、$I_{yz}$，以及竖肢顶部、水平肢尖端和角点处的正应力，并与$Mz/I_{yy}$比较。
::: solution
把角点放在原点，竖肢沿$+z$，水平肢沿$+y$。面积分别为$500$和$300\ \mathrm{mm^2}$；形心$\bar y = 300\times30/800 = 11.25\ \mathrm{mm}$，$\bar z = 500\times50/800 = 31.25\ \mathrm{mm}$。对形心（薄壁近似）：
$I_{yy} = 5\times100^3/12 + 500(50 - 31.25)^2 + 300(31.25)^2 = 416\,667 + 175\,781 + 292\,969 = 8.854\times10^{5}\ \mathrm{mm^4}$；
$I_{zz} = 5\times60^3/12 + 300(30 - 11.25)^2 + 500(11.25)^2 = 90\,000 + 105\,469 + 63\,281 = 2.588\times10^{5}\ \mathrm{mm^4}$；
$I_{yz} = 500(-11.25)(18.75) + 300(18.75)(-31.25) = -105\,469 - 175\,781 = -2.813\times10^{5}\ \mathrm{mm^4}$。
取$M_y = 10^{6}\ \mathrm{N\,mm}$，$M_z = 0$，分母$8.854\times10^{5}\times2.588\times10^{5} - (2.813\times10^{5})^2 = 1.500\times10^{11}$：$\sigma = (-M_yI_{yz}y + M_yI_{zz}z)/1.500\times10^{11} = 1.875y + 1.725z$（MPa，$y, z$从形心量起）。竖肢顶部$(-11.25, 68.75)$：$-21.1 + 118.6 = 97.5\ \mathrm{MPa}$。水平肢尖端$(48.75, -31.25)$：$91.4 - 53.9 = 37.5\ \mathrm{MPa}$。角点$(-11.25, -31.25)$：$-21.1 - 53.9 = -75.0\ \mathrm{MPa}$。简单套用$Mz/I_{yy}$会在顶部给出$77.6\ \mathrm{MPa}$，在角点和水平肢尖端给出$-35.3\ \mathrm{MPa}$——大小是错的，而在尖端处连符号也是错的。

::: exercise 开缝管的弯曲中心 {level=3}
平均半径为$R$、厚度为$t$的薄壁圆管沿一条母线开缝。证明其弯曲中心位于对称轴上、开缝的对侧，距管中心$2R$。解释为什么这意味着通过中心加载的开缝管会扭转。
::: solution
把缝放在$\phi = 0$处（角度从缝起沿管周量取），对称轴取通过缝和中心的直线，施加垂直于该轴的剪力$V$。沿$V$的方向取$z = R\sin\phi$（在缝处和$\phi = \pi$处为零）。$I = \pi R^3t$。从缝处的自由边开始，
$$
q(\phi) = \frac{V}{I}\int_0^\phi tR\sin\psi\,R\,d\psi = \frac{V(1 - \cos\phi)}{\pi R}.
$$
每一段剪流都在半径$R$处沿切向作用，所以它对中心的力矩为$qR\,R\,d\phi$，总力矩为
$$
\int_0^{2\pi}\frac{V(1 - \cos\phi)}{\pi R}R^2\,d\phi = \frac{VR}{\pi}\cdot2\pi = 2VR.
$$
要不扭转，载荷对中心必须产生相同的力矩：$Ve = 2VR$，所以$e = 2R$，在远离缝的一侧（那里剪流最大）。因此通过中心的载荷会留下不平衡的扭矩$2VR$，而由于$J_\text{open}$极小，扭转很大。把缝封闭后，闭室可以承受一个常剪流$q_{s,0}$来抵消这个扭矩，使弯曲中心移到管的中心。
:::
:::

::: exercise 底盘纵梁用开口还是闭口截面 {level=3}
一辆轻型挂车的底盘纵梁既要抵抗弯曲，又要抵抗不平路面引起的扭转。可以选用冷弯槽钢$150\times60\times4\ \mathrm{mm}$，也可以选用矩形空心型钢$150\times60\times4\ \mathrm{mm}$（均为外形尺寸，每米质量相近）。估算两者在相同扭矩下的抗扭刚度之比和最大切应力之比，并讨论实际后果：横梁的连接、腐蚀、成本，以及抗扭柔性的车架是否有时反而更可取。
::: solution
两者的中线尺寸都约为$146\times56\ \mathrm{mm}$。槽钢：$J = \sum bt^3/3 = (146 + 2\times56)\times64/3 = 5504\ \mathrm{mm^4}$。箱形：$A = 146\times56 = 8176\ \mathrm{mm^2}$，$\oint ds/t = 2(146 + 56)/4 = 101$，$J = 4A^2/101 = 2.647\times10^{6}\ \mathrm{mm^4}$：刚度约为**480倍**。扭矩$T$下的应力：槽钢$\tau = Tt/J = T\times4/5504 = 7.27\times10^{-4}T$；箱形$\tau = T/(2At) = T/65\,408 = 1.53\times10^{-5}T$：开口截面的应力约高48倍（$T$以N mm计，$\tau$以MPa计）。好的回答接着会权衡：槽钢的弯曲中心在腹板之外，所以通过腹板的竖向载荷也会使它扭转，除非有横梁约束；开口槽钢便于螺栓连接，内侧也便于检查和涂漆，而闭口截面需要排水孔和内部防腐；闭口截面使车架刚度大得多，但有意做成抗扭柔性的梯形车架（开口槽钢）能让所有车轮在崎岖路面上保持着地，并使载荷不进入连接处，这就是许多卡车和挂车车架采用槽钢的原因。连接设计（焊接横梁处的翘曲约束会引起局部应力，而本章的自由翘曲理论忽略了这一点）通常决定疲劳寿命；车架须按适用的车辆标准设计。
