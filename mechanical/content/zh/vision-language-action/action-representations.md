策略的输出是一个数或一列数，机器人把它们变成运动。这些数*意味着*什么——是关节角还是末端执行器位姿、是绝对目标还是小增量、是一步还是未来一整秒的运动、是实数还是离散词元——由**动作表示**决定，而它几乎影响学习策略的一切：能否用其他机器人的数据训练、有多精确多平滑、能否表达多峰行为、每秒需要多少次网络求值、对突发情况反应多快。

本章逐一梳理这些选择。先是**动作空间**：关节还是末端执行器、绝对还是增量、增量在哪个坐标系中表达、旋转的表示（以及为什么学习方法偏爱六数的表示），以及夹爪。然后是**归一化与离散化**：把每个维度分成256个箱并把箱当作语言模型的词元，正如 RT-2与 OpenVLA 所做；以及用离散余弦变换压缩整个动作块的频域词元化（FAST）。最后是**动作分块**：一次预测许多未来动作、开环执行它们，或用时间维集成混合重叠的预测，以及控制频率、块长与反应时间之间的权衡。关节空间与末端执行器空间背后的运动学见[[robotics/forward-kinematics]]、[[robotics/jacobians]]与[[robotics/rigid-motions]]。

## 动作空间 {#sec-spaces}

::: definition 动作空间 {#def-action-space}
**动作空间**规定策略的输出向量命令什么、用什么单位与坐标系、以及底层控制器如何执行它。机械臂的常见选择有
- **绝对关节位置**$\mathbf q^{\mathrm{cmd}}_t\in\R^n$（$n$个关节各自的期望角度）；
- **关节增量**$\Delta\mathbf q_t = \mathbf q^{\mathrm{cmd}}_t - \mathbf q_t$，或关节速度$\dot{\mathbf q}^{\mathrm{cmd}}_t$；
- **绝对末端执行器位姿**$T^{\mathrm{cmd}}_t\in SE(3)$，即工具在机器人基坐标系中的位置$\mathbf p\in\R^3$与姿态$R\in SO(3)$；
- **末端执行器增量**$(\Delta\mathbf p_t, \Delta R_t)$，即在基坐标系或当前工具坐标系中表达的一个小平移与小旋转；
加上一个或多个**夹爪**维度（开/合，或目标指宽）。
:::

每种选择各有一组不同的优缺点。

**关节空间**运行时不需要逆运动学，因而没有奇异位形或 IK 失败，而且策略直接控制冗余（7自由度臂的肘部）。主从式示范（[[vision-language-action/demonstration-data]]）天然产生关节指令。但关节动作专属于某一机械臂：在一个机器人上记录的数据不能直接说明连杆长度不同的另一个机器人。

**末端执行器空间**离任务更近——“把夹爪向杯子移动2 cm”在任何机械臂上含义相同——所以它是跨机器人汇集数据的自然选择，Open X-Embodiment 数据集大多使用末端执行器增量。其代价是回路中需要一个 IK 或笛卡尔控制器，连同它全部的奇异位形与关节限位问题（[[robotics/inverse-kinematics]]），以及冗余臂的多解歧义。

**绝对与增量。**增量$\Delta\mathbf p$很小，在工作空间各处统计特性相近，易学且便于在任务之间共享。但已执行增量的误差会累积——控制器每一步都稍微欠一点，机器人就会漂移——而且增量必须相对*某个东西*来解释：实测位姿，还是上一条指令。绝对目标不漂移，对控制器滞后也更稳健，但其分布取决于任务在工作空间中的位置。许多近年的分块策略预测绝对关节目标（ACT、π0在双臂上），而许多跨具身数据集使用增量；只要数据集同时记录了指令与实测状态，两者互换很容易。

::: example 工具坐标系中的增量 {#ex-tool-frame}
某夹爪的工具坐标系相对基坐标系绕基座$z$轴旋转了$+90^\circ$（其$x$轴沿基座的$y$轴）。策略在工具坐标系中输出平移增量$\Delta\mathbf p^{\mathrm{tool}} = (10, 0, -5)\,\mathrm{mm}$。求基坐标系中的增量。若控制器把输出当作基坐标系增量来解释，会发生什么？
::: solution
从工具坐标到基坐标的旋转为
$$
R = R_z(90^\circ) = \begin{pmatrix} 0 & -1 & 0\\ 1 & 0 & 0\\ 0 & 0 & 1\end{pmatrix},\qquad \Delta\mathbf p^{\mathrm{base}} = R\,\Delta\mathbf p^{\mathrm{tool}} = \begin{pmatrix} 0\\ 10\\ -5\end{pmatrix}\mathrm{mm}.
$$
夹爪沿基座$y$移动10 mm、下降5 mm。若按基坐标系指令解释，同样的数字会把它沿基座$x$移动10 mm——与预期方向成直角。检验：竖直分量不变，因为旋转是关于$z$的；这本身就是个提醒。数据集与控制器之间这类坐标系不一致，是将在某个数据集上训练的模型搬到另一个机器人上时最常见的静默 bug 之一；动作坐标系应当写进数据集的元数据。
:::
:::

旋转增量在两个坐标系中的合成方式不同：基坐标系增量对应$R_{t+1} = \Delta R\,R_t$，工具坐标系增量对应$R_{t+1} = R_t\,\Delta R$（[[robotics/rigid-motions]]）。

### 旋转的表示 {#sec-rotations}

姿态有三个自由度，但没有任何三个数的组合能在处处把它描述好。**欧拉角**在某个角度回绕时会跳变$2\pi$，并在万向节锁处丢失一个自由度。**轴角**向量$\boldsymbol\phi = \theta\,\mathbf u$对同一个旋转会在$\pi\mathbf u$与$-\pi\mathbf u$之间跳变。**单位四元数**光滑但是二重覆盖：$\mathbf q$与$-\mathbf q$是同一个旋转，因此被要求输出“那个”四元数的网络必须学一个会在某处不连续变号的任意选择。对神经网络——其输入的连续函数——而言，在几乎相同的输入之间跳变的目标极难拟合。

Zhou、Barnes、Lu、Yang 与 Li 在2019年证明了这在低维中不可避免——用$\R^d$中向量对3维旋转的任何表示，只要$d\le4$，必在某处不连续——并提出了六维中的连续表示。

::: proposition 6维旋转表示 {#prop-6d}
用$R = [\mathbf r_1\ \mathbf r_2\ \mathbf r_3]\in SO(3)$的前两列$(\mathbf r_1, \mathbf r_2)\in\R^6$来表示它。反过来，把任意一对线性无关的向量$(\mathbf a_1, \mathbf a_2)$映射为
$$
\mathbf b_1 = \frac{\mathbf a_1}{\norm{\mathbf a_1}},\qquad \mathbf b_2 = \frac{\mathbf a_2 - (\mathbf b_1\cdot\mathbf a_2)\,\mathbf b_1}{\norm{\mathbf a_2 - (\mathbf b_1\cdot\mathbf a_2)\,\mathbf b_1}},\qquad \mathbf b_3 = \mathbf b_1\times\mathbf b_2,\qquad R = [\mathbf b_1\ \mathbf b_2\ \mathbf b_3].
$$ {#eq-gram-schmidt}
则$R\in SO(3)$；对一个旋转的前两列施用该映射会返回该旋转；并且两个映射都连续（后者在线性无关对的集合上连续）。
:::

::: proof
$\mathbf b_1$是单位向量。$\mathbf b_2$是$\mathbf a_2$减去其沿$\mathbf b_1$的分量，故$\mathbf b_1\cdot\mathbf b_2 = 0$，再作归一化；分母恰在$\mathbf a_2$不平行于$\mathbf a_1$时非零。两个标准正交向量的叉积是单位向量，与两者正交且$\det[\mathbf b_1\ \mathbf b_2\ \mathbf b_3] = (\mathbf b_1\times\mathbf b_2)\cdot\mathbf b_3 = \norm{\mathbf b_3}^2 = 1$，所以$R$是行列式为$+1$的正交矩阵，即一个旋转。若$(\mathbf a_1, \mathbf a_2) = (\mathbf r_1, \mathbf r_2)$是一个旋转的两列，它们本来就标准正交，于是$\mathbf b_1 = \mathbf r_1$、$\mathbf b_2 = \mathbf r_2$，而对右手系$\mathbf b_3 = \mathbf r_1\times\mathbf r_2 = \mathbf r_3$。取列是线性的，故连续；格拉姆-施密特（Gram–Schmidt）映射由求和、乘积、叉积以及除以其在定义域内不为零的范数构成，故在其上连续。
:::

网络输出六个无约束的数，损失可以在重构出的矩阵上计算（或直接在这六个数上计算），没有任何东西会跳变。6维表示在学习策略中常用于*绝对*姿态。而对小*增量*，轴角与欧拉角的不连续性离得很远（发生在接近$\pi$的旋转处），所以三个数的增量被广泛使用且完全够用。

::: example 从带噪的6维输出恢复旋转 {#ex-6d}
真实姿态是$R_z(30^\circ)$，其前两列为$(0.866, 0.5, 0)$与$(-0.5, 0.866, 0)$。某网络输出$\mathbf a_1 = (0.90, 0.45, 0.05)$、$\mathbf a_2 = (-0.40, 0.90, 0.00)$。用[[#eq-gram-schmidt]]重构$R$并求其角度误差。
::: solution
$\norm{\mathbf a_1} = 1.0075$，故$\mathbf b_1 = (0.8933, 0.4467, 0.0496)$。$\mathbf b_1\cdot\mathbf a_2 = -0.3573 + 0.4020 + 0 = 0.0447$；$\mathbf a_2 - 0.0447\,\mathbf b_1 = (-0.4399, 0.8800, -0.0022)$，其范数为$0.9839$，故$\mathbf b_2 = (-0.4471, 0.8945, -0.0023)$。$\mathbf b_3 = \mathbf b_1\times\mathbf b_2 = (-0.0454, -0.0202, 0.9988)$。
误差旋转$R_{\mathrm{true}}\T R$的角度由$\tr(R_{\mathrm{true}}\T R) = 1 + 2\cos\theta_{\mathrm{err}}$给出；数值上$\theta_{\mathrm{err}} = 4.5^\circ$。
检验：$\mathbf b_1$在$xy$平面内指向$\arctan(0.4467/0.8933) = 26.6^\circ$，比$30^\circ$差$3.4^\circ$，并偏离该平面$2.8^\circ$；合计几度的误差与此相符。无论原始数错得多么离谱，输出永远是一个合法旋转——这正是该表示用起来安全的性质。
:::
:::

### 夹爪

平行夹爪常由单个数指挥：目标开度，或开/合二值。数据中的夹爪动作几乎是二值的——长时间完全张开或完全闭合，加上短暂的过渡——这使它易于分类却难以回归（MSE 头会在决定的瞬间预测出“半闭合”）。多数策略要么对连续输出取阈值（$> 0.5$则闭合），要么把夹爪当作独立的二值或类别输出。灵巧手每个驱动关节加一维，按额外的臂关节对待。

## 归一化与离散化 {#sec-discretisation}

不同动作维度的单位与范围各异——米、弧度、夹爪开度比——所以训练前先**归一化**。扩散策略与流策略通常把每个维度标准化为零均值单位方差，或映射到$[-1, 1]$。离散化的策略把范围$[a_{\min}, a_{\max}]$映到箱；对取范围的稳健做法是使用数据的分位数（OpenVLA，2024，用了第1与第99百分位数），以免罕见离群值浪费分辨率。

::: proposition 均匀箱的量化误差 {#prop-quant}
把$[a_{\min}, a_{\max}]$分成$B$个等宽箱，宽度$\Delta = (a_{\max} - a_{\min})/B$，每个箱解码到其中心。则范围内任何动作的解码误差不超过$\Delta/2$；若动作在其箱内均匀分布，则均方根误差为$\Delta/\sqrt{12}$。
:::

::: proof
箱$[c - \Delta/2, c + \Delta/2)$内的动作$a$被解码到中心$c$，故$\lvert a - c\rvert\le\Delta/2$。若$e = a - c$在$[-\Delta/2, \Delta/2]$上均匀，其均值为0，均方为$\frac{1}{\Delta}\int_{-\Delta/2}^{\Delta/2} e^2\,de = \frac{1}{\Delta}\cdot\frac{2}{3}\left(\frac{\Delta}{2}\right)^3 = \frac{\Delta^2}{12}$。
:::

### 动作即词元

语言模型从词表预测下一个词元。**RT-2**（Brohan 等，2023）把这台机器用于机器人控制：把每个动作维度表示为256个箱之一，并把箱索引写成词元——于是一个动作变成一句短的“句子”，含八个词元（一个终止标志、位置增量三个、旋转增量三个、夹爪一个）。**OpenVLA**（Kim 等，2024）沿用同一想法，每步七个词元，把其 Llama 2分词器中最少使用的256个词元重新指派给动作箱。模型用普通的下一词元交叉熵损失训练，这使它对每个维度获得一个类别分布——因而可以是多峰的——并以已生成的维度为条件。

::: definition 逐维动作词元化 {#def-binning}
在**逐维分箱**中，每个归一化动作维度$a^{(j)}\in[-1,1]$被映射到箱索引$k^{(j)} = \min\bigl(\lfloor (a^{(j)}+1)B/2\rfloor, B-1\bigr)\in\{0,\dots,B-1\}$，每个索引再映射到模型词表中保留的一个词元。一个$d$维动作变成$d$个词元，自回归生成；长度为$H$的动作块变成$Hd$个词元。
:::

::: widget plot

x: 0, 6.3
y: -1.1, 1.1
sliders: b=4:1:64

caption: 一条平滑的动作轨迹（归一化单位下的正弦曲线）及其均匀分箱成$b$个箱后的解码。箱数很少时阶梯一目了然；到64个箱已不易看出的，到256个箱（RT-2、OpenVLA）台阶只有归一化范围的$2/256 \approx 0.008$。注意误差处处以半个台阶为界，与动作变化多快无关。
:::

对控制而言，词元输出有两个性质要紧。

1. **开销。**每个词元需要语言模型一次前进一步。每动作$d = 7$个词元，则70亿参数的模型每个控制步要跑七个解码步。有了键值缓存，每个解码步比处理整个提示便宜，但大型自回归 VLA 在2024年于单张高端 GPU 上只能跑到几 Hz（[[vision-language-action/vla-deployment]]；另见 LLM Atlas 中的 [KV 缓存](/learn/llm/lesson.php?c=inference&l=kv-cache)）。
2. **高频动作块词元化得很糟。**在50 Hz 下，相邻动作几乎相等，于是在分箱动作的块里，每个词元都几乎是其前$d$个位置的词元的复制品。这样下一词元预测有一条轻松的捷径（复制），关于整体运动的信号则收获得很少。Pertsch 等（2025）表明，用朴素分箱在高频灵巧数据上训练的自回归 VLA 表现很差，并提出了一种压缩词元化。

### FAST：频率空间动作词元化 {#sec-fast}

**FAST**（Frequency-space Action Sequence Tokenization；Pertsch 等，Physical Intelligence，2025）的思想和 JPEG 图像压缩一样：平滑信号的能量大多集中在少数低频余弦分量上，所以先变换、再量化，只保留少数大系数。

::: algorithm 动作块的 FAST 词元化 {#alg-fast}
输入：一个$H$步、$d$维的动作块，已逐维归一化（例如使第1与第99百分位数映到$\mp1$）。
1. **变换。**对每个维度$j$，沿时间对$H$个值施加离散余弦变换（DCT-II），得到系数$C^{(j)}_0, \dots, C^{(j)}_{H-1}$；$C_0$与均值成正比，下标越高对应越快的振荡。
2. **量化。**乘以缩放因子$\gamma$并取整，$\hat C^{(j)}_k = \operatorname{round}(\gamma\,C^{(j)}_k)$。多数高频系数变为零。$\gamma$控制压缩率与保真度之间的权衡。
3. **展平。**把这些整数排成一个序列，低频在前、维度交错：$\hat C^{(1)}_0, \hat C^{(2)}_0, \dots, \hat C^{(d)}_0, \hat C^{(1)}_1, \dots$，使最重要的信息最先出现。
4. **压缩。**施加字节对编码（BPE）——在这种序列的语料上训练过——把频繁的图案（尤其是长长的零游程）合并成单个词元。所得词元就是模型动作输出的词表。
解码依次逆执行第4到第1步：BPE 解码、整形、除以$\gamma$、逆 DCT。
:::

词元化只在第2步有损，其余可逆。其输出长度随信号自适应：平滑运动只需几个词元，顿挫的运动则多些。作者还发布了一个在大量而多样的机器人动作数据上训练的“通用”分词器。据报道，用 FAST 词元训练的自回归 VLA 在灵巧任务上能与扩散/流式的打平，而且训练更快，代价是推理较慢——因为解码仍逐词元进行（截至2025年）。

::: theorem DCT 的正交性（Parseval） {#thm-dct}
采用标准正交 DCT-II
$$
C_k = \sqrt{\frac{2 - \delta_{k0}}{H}}\sum_{n=0}^{H-1} x_n\cos\frac{\pi (n+\frac12)k}{H},\qquad k = 0,\dots,H-1,
$$ {#eq-dct}
变换矩阵是正交的，于是$\sum_n x_n^2 = \sum_k C_k^2$，且逆就是转置。由此，改动系数之后的平方重构误差等于系数改动的平方和。
:::

::: proof
分量$c_{k,n} = \sqrt{(2-\delta_{k0})/H}\,\cos\bigl(\pi(n+\tfrac12)k/H\bigr)$的向量$\mathbf c_k$，是带反射（诺伊曼）边界的对称$H\times H$二阶差分矩阵的特征向量，特征值$2 - 2\cos(\pi k/H)$互不相同，所以它们两两正交；归一化常数使每个都是单位长（和$\sum_n\cos^2(\pi(n+\frac12)k/H)$在$k\ge1$时为$H/2$，在$k = 0$时为$H$）。行标准正交的矩阵是正交矩阵，因此保持欧氏范数，其逆就是转置。若系数改变$\delta\mathbf C$，信号改变$\mathbf M\T\delta\mathbf C$，二者范数相同。（连续情形见 [Maths Atlas 的傅里叶级数](/learn/maths/lesson.php?c=pde&l=fourier-series)。）
:::

于是每个系数上$1/\gamma$的量化步长像[[#prop-quant]]那样给出误差上界，但只对存活的系数成立——把一个系数舍入到零，至多从中去掉$1/(2\gamma)$。

::: example 压缩一个平滑运动 {#ex-fast}
一个动作维度归一化到$[-1, 1]$，在$H = 50$步的块内（50 Hz 下的一秒）沿五次多项型线从$-1$走到$+1$。标准正交 DCT 给出$C_0 = 0$、$C_1 = -5.357$、$C_2 = 0$、$C_3 = 0.296$、$C_5 = 0.042$、$C_7 = 0.011$，偶数下标系数由对称性为零，其余更小。用$\gamma = 10$量化，求非零整数、重构误差、以及相对50个逐步分箱的压缩率。若夹爪在第30步突然闭合会怎样？
::: solution
$\gamma C_1 = -53.57\to-54$，$\gamma C_3 = 2.96\to3$，$\gamma C_5 = 0.42\to0$，其余一切$\to0$。50个系数中只有两个非零整数；经 BPE 把零游程合并后，这个维度只花几个词元而不是50个。
能量：$C_1^2 + C_3^2 = 28.79$，而总能量为$28.79 + 0.002$，所以超过99.9%的信号在两个系数里。数值上，从$(-54, 3)/10$重构得最大误差$0.020$、均方根误差$0.0087$（归一化单位）——是半量程的1%。取$\gamma = 20$，三个系数存活（$-107, 6, 1$），最大误差降到$0.004$。
夹爪在第30步从$-1$跳到$+1$是一个间断，其余弦系数衰减很慢：取$\gamma = 10$时50个系数中41个非零，几乎没有压缩。台阶状维度压缩很差，这是分词器的 BPE 环节与其训练语料重要的原因之一。
检验：$C_1 = -5.36$接近振幅为1的半个余弦的理论值$-\sqrt{H/2} = -5$——对一个看起来像半个余弦的型线，本应如此。
:::
:::

## 动作分块 {#sec-chunking}

每个控制步只输出一个动作的策略必须每隔几毫秒做一次决定，而每个决定都是一次[[vision-language-action/imitation-learning#prop-t2]]中累积误差的机会。**动作分块**——由 ACT（Action Chunking with Transformers；Zhao、Kumar、Levine 与 Finn，2023）引入现代操作研究——一次预测一段未来动作。

::: definition 动作块与执行时域 {#def-chunk}
长度为$H$的**动作块**是策略在时刻$t$的观测下输出的序列$\mathbf A_t = (a_t, a_{t+1}, \dots, a_{t+H-1})$。策略每隔$h$个控制步查询一次（$1\le h\le H$），每块执行前$h$个动作；$h$是**执行时域**。$h = H$时各块首尾相接开环执行；$h < H$时余下部分被丢弃，或与下一个预测混合。
:::

分块从三方面起作用。它使有效决策时域缩短$h$倍。它让策略能表达运动的*时间*结构——一条平滑的弧、一次停顿——而不必逐步学起，这也减轻了示范中停顿与其他非马尔可夫行为的影响。它还把控制频率与推理频率解耦：只要一个块的执行时长超过一次推理，慢网络就能驱动快控制器。

代价是反应性：在块内的开环阶段，机器人无视新的观测。

::: example 控制频率、块长与反应时间 {#ex-rates}
某机械臂以$f = 50\,\mathrm{Hz}$控制。策略预测$H = 50$个动作的块，每次推理耗时$t_{\mathrm{inf}} = 80\,\mathrm{ms}$。比较 (a) 逐步查询、(b) $h = 25$、(c) $h = 50$：每秒各需多少次推理，时序上可行吗，机器人对一个事件（有人移动了目标物体）做出反应前的最坏延迟是多少？
::: solution
一个控制步$1/f = 20\,\mathrm{ms}$；一个块覆盖$50\times20 = 1.0\,\mathrm s$；一次推理占$80/20 = 4$个控制步。
(a) $h = 1$：每秒50次推理，每次80 ms——不用批处理之类的手段在一张 GPU 上不可能；策略最多只能以$1/0.080 = 12.5\,\mathrm{Hz}$跟上。
(b) $h = 25$：每秒2次推理，每秒用去$2\times80 = 160\,\mathrm{ms}$的算力。最坏情形下，事件恰在一次观测采集后发生；它要到下次查询即$25\times20 = 500\,\mathrm{ms}$后才被看到，再经一次推理，在事件后$500 + 80 = 580\,\mathrm{ms}$才被处理。
(c) $h = 50$：每秒1次推理；最坏反应$1000 + 80 = 1080\,\mathrm{ms}$。
若推理同步运行（机器人等待），每个块的边界还会插入一次80 ms 的停顿——表现为卡顿；在上一块执行的同时异步运行推理即可消除（[[vision-language-action/vla-deployment]]）。
检验：人的反应时间是几百毫秒，所以 (b) 与人相当；(c) 会整整一秒视被移动的物体而不见，肉眼可见。
:::
:::

### 时间维集成

ACT 提出了一个兼得平滑与反应性的办法：*每*步都查询策略，并对所有仍在覆盖范围内的块在时刻$t$做出的预测执行一个关于时刻$t$的加权平均。若块是在时刻$t - i$（$i = 0, 1, \dots, H-1$）预测的，每个都给出当前步的预测$\hat a^{(i)}_t$，执行的动作为
$$
a_t = \frac{\sum_i w_i\,\hat a^{(i)}_t}{\sum_i w_i},\qquad w_i = e^{-m\,i},
$$ {#eq-ensemble}
其中在 ACT 论文里$w_0$是*最旧*预测的权重，因此正的$m$偏向较旧的预测，小的$m$让新观测更快地进入。时间维集成平滑了块与块之间的衔接，代价是每个控制步一次推理——对小型 ACT 模型（数千万参数）负担得起，对数十亿参数的 VLA 通常负担不起，后者的部署改用执行时域$h > 1$并在块边界间做平滑。

::: warning 对动作块取平均会重新引入模式平均
时间维集成是对预测取平均。若相邻两块来自*不同*的模式——一块从障碍物左边绕，下一块从右边绕——平均就撞进障碍物，正是[[vision-language-action/imitation-learning#ex-obstacle]]中 MSE 回归的失效方式。对承诺于单一模式的确定性策略，集成是安全的；对随机（扩散或流）策略，要么执行时不取平均，要么让每个新块以前一块为条件，要么只在两块一致时混合。
:::

::: example 时间维集成的权重 {#ex-ensemble}
在当前步，四个块（分别于3、2、1、0步前预测）对某个夹爪高度（米）的预测由旧到新为$0.120, 0.118, 0.112, 0.105$。用$w_i = e^{-mi}$、$i = 0$对应最旧，求$m = 0.01$、$0.1$与$0.5$时的执行值。
::: solution
$m = 0.01$：权重$1, 0.990, 0.980, 0.970$；加权平均$0.1138\,\mathrm m$——几乎就是普通平均$0.1138$。
$m = 0.1$：权重$1, 0.905, 0.819, 0.741$；平均$0.1144\,\mathrm m$。
$m = 0.5$：权重$1, 0.607, 0.368, 0.223$；平均$0.1166\,\mathrm m$，接近最旧的预测。
最新的预测（0.105 m，基于最新的图像）说夹爪应当更低；$m$越大，执行的动作就越滞后于它。检验：每个加权平均都介于最小与最大预测之间——凸组合必然如此。
:::
:::

::: widget plot
f: exp(-m*x)
x: 0, 50
y: 0, 1.05
sliders: m=0.005:0.005:0.3
labels: w_i = e^{-m i}
caption: 时间维集成的权重随龄期下标$i$的变化（块长为50时，$i = 0$是仍在覆盖范围的最旧一块）。小的$m$给出近乎相等的权重——一个移动平均，对新观测响应很慢；大的$m$把权重集中到最旧的预测上。平均的时间常数约为$1/m$步。
:::

::: quiz
一个团队把逐步动作换成1 s 的块、以30 Hz 开环执行。名义任务上的成功率提高了，但只要有人在运动过程中碰一下目标物体，策略就失败。最直接的修复是什么？
- [ ] 加长块，让策略计划得更远。
- [x] 缩短执行时域（更频繁地查询，例如每0.25 s 一次），并异步运行推理。
- [ ] 把末端执行器增量换成关节位置。
::: solution
1 s 的块开环执行意味着机器人最多一秒不理会那一下碰动。更频繁地查询（缩短执行时域）在保留预测一块的好处的同时恢复反应性；异步推理避免边界处的停顿。加长块只会更糟，而动作空间不是病因。
:::
:::

::: history
早期学习的视觉运动策略（2016）直接输出关节力矩或速度，一步一步来。RT-1（2022）把11个动作维度（机械臂、底盘与模式）各离散成256个箱，RT-2（2023）又把这些箱写成视觉-语言模型的文本词元。Zhou 等作者对旋转表示的连续性分析（2019）使学习的位姿预测转向6维表示。ACT（2023）把动作分块与时间维集成带入低成本双臂操作，Diffusion Policy（2023）则连续地生成整块动作（[[vision-language-action/diffusion-flow-policies]]）。FAST（2025）把 JPEG 的离散余弦变换用于动作块，使自回归模型也能学到高频灵巧控制。
:::

::: summary
- 动作空间：关节（无需 IK、专属某一具身）或末端执行器（可迁移、需要 IK）；绝对（不漂移）或增量（统计均匀）；务必记录坐标系与单位。
- 旋转：欧拉角、轴角与四元数作为网络目标都必在某处不连续；带格拉姆-施密特的6维表示是连续的。小增量可以用三个数。
- 均匀分箱的误差$\le\Delta/2$，均方根$\Delta/\sqrt{12}$；RT-2与 OpenVLA 把每维256个箱写成词元。
- FAST 用 DCT、量化、低频先行的展平与 BPE 对块作词元化；平滑运动压缩到很少的词元，间断则不然。
- 长$H$、每次执行$h$步的动作块缩短决策时域，并把控制频率与推理频率解耦；最坏反应时间约为$h/f + t_{\mathrm{inf}}$。
- 时间维集成平滑动作块但会对模式取平均；只对确定性策略使用，或只混合一致的块。
:::

## 习题

::: exercise 箱宽 {#exr-binwidth level=1 check="0.469"}
绕单轴的旋转增量被截断到$\pm 0.06\,\mathrm{rad}$并分成256个箱。求箱宽。（以 mrad 填入，保留三位有效数字。）
::: solution
$\Delta = 0.12/256 = 4.69\times10^{-4}\,\mathrm{rad} = 0.469\,\mathrm{mrad}$。
:::
:::

::: exercise 每秒词元数 {#exr-tokens level=1 check="70"}
一个自回归 VLA 每个动作发出7个词元，机器人每秒需要10个动作且不分块。它每秒必须生成多少个动作词元？（填入数字。）
::: solution
$7\times10 = 70$个词元每秒，每个都需要整个模型一次解码。
:::
:::

::: exercise 反应时间 {#exr-react level=1 check="0.43"}
一个30 Hz 的控制器每块执行$h = 12$个动作，推理耗时$30\,\mathrm{ms}$。求对事件的最坏反应时间。（以 s 填入，保留两位有效数字。）
::: solution
$h/f + t_{\mathrm{inf}} = 12/30 + 0.030 = 0.400 + 0.030 = 0.43\,\mathrm s$。
:::
:::

::: exercise RMS 量化误差 {#exr-rms level=2 check="0.0451"}
0到80 mm 之间的夹爪开度指令被分箱成512级。求箱内开度均匀分布时的 RMS 量化误差。（以 mm 填入，保留三位有效数字。）
::: solution
$\Delta = 80/512 = 0.15625\,\mathrm{mm}$；RMS $= \Delta/\sqrt{12} = 0.0451\,\mathrm{mm}$。
:::
:::

::: exercise 基坐标系的旋转增量 {#exr-compose level=2}
当前工具姿态为$R_t = R_x(90^\circ)$。策略输出绕$z$轴$+10^\circ$的增量。若增量分别位于 (a) 基坐标系与 (b) 工具坐标系，写出$R_{t+1}$，并各用物理语言描述这个运动。
::: solution
(a) $R_{t+1} = R_z(10^\circ)R_x(90^\circ)$：工具绕*基座*铅垂轴旋转——它绕桌面的铅垂线扫过。(b) $R_{t+1} = R_x(90^\circ)R_z(10^\circ)$：工具绕自身$z$轴旋转，而该轴经$R_x(90^\circ)$后沿基座$-y$方向；它绕一根水平轴扭转。同样的数字，不同的运动：坐标系必须是指令的一部分。
:::
:::

::: exercise 带新鲜修正的集成 {#exr-ens level=2 check="0.1166"}
在[[#ex-ensemble]]的情形下取$m = 0.5$，验证执行值。（以 m 填入，保留四位有效数字。）
::: solution
权重$1, e^{-0.5} = 0.6065, e^{-1} = 0.3679, e^{-1.5} = 0.2231$；和为$2.1975$。加权和$0.120 + 0.118\times0.6065 + 0.112\times0.3679 + 0.105\times0.2231 = 0.1200 + 0.0716 + 0.0412 + 0.0234 = 0.2562$。平均$0.2562/2.1975 = 0.1166\,\mathrm m$。
:::
:::

::: exercise 为什么是六个数而不是九个？ {#exr-6d level=3}
完整旋转矩阵（九个数，经 SVD 投影使其正交）也是连续表示。讨论6维与9维表示作为网络输出的权衡，并说明6维映射[[#eq-gram-schmidt]]对两列的处理是不对称的。
::: solution
两者都连续。带 SVD 正交化（Frobenius 范数下的最近旋转）的9维表示对称地对待所有列，且有报告称其表现至少同样好；其投影代价更高，其梯度涉及 SVD。6维映射便宜而简单。它是不对称的：$\mathbf b_1$只依赖$\mathbf a_1$，而$\mathbf b_2$依赖两者，于是$\mathbf a_1$的误差传播到每一列，而$\mathbf a_2$沿$\mathbf a_1$方向的误差被丢弃。例如$(\mathbf a_1, \mathbf a_2)$与$(\mathbf a_1, \mathbf a_2 + 5\mathbf a_1)$给出同一旋转，$(\mathbf a_1 + 5\mathbf a_2, \mathbf a_2)$却不然。实践中两者都行；要紧的是对绝对姿态避开不连续的3维与4维表示。
:::
:::

::: exercise 选择动作表示 {#exr-choose level=3}
你公司的6自由度机械臂将运行一个从在 Open X-Embodiment（多为3–15 Hz 的末端执行器增量）上预训练的模型微调来的 VLA。产品任务是把瓶盖拧到瓶子上，由关节控制器以100 Hz 控制，示范来自主从式采集台。提出动作空间、归一化、块长与执行时域，并逐项论证。
::: solution
一个站得住脚的答案：同时记录关节指令（来自领航臂）*与*末端执行器位姿；微调时按预训练模型的约定用绝对关节目标或末端执行器目标——与预训练动作空间一致有助于迁移，但对单一产品机械臂，关节目标避开 IK 问题并精确捕捉腕部转动。用产品数据的分位数逐维归一化。以20–50 Hz 的策略频率预测动作块（由控制器插值到100 Hz），例如50 Hz 下$H = 50$步（1 s），恰好覆盖瓶盖的一整圈；执行时域$h$取10–25步（0.2–0.5 s），以便策略对乱扣螺纹做出反应；检查$h/f$是否超过推理延迟。夹爪作为独立的二值输出。用闭环试验而非离线损失来评估备选方案。
:::
