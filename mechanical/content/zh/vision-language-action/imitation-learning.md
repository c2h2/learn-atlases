传统的机器人程序是一份指令清单：移动到这一位姿、合上夹爪、移动到那一位姿。当零件以已知位置送入夹具时，它工作得十分漂亮；而世界一旦不再配合——箱子偏左2 cm、电缆每次垂法不同、一条必须叠起来的毛巾——它立刻失效。为这类任务写程序意味着预想每一种情形，而没有人做得到。**模仿学习**走另一条路：人向机器人示范该怎么做，许多次，在许多略有不同的情形下，一个神经网络学出一个从机器人*看到*的东西到它*应该做*的东西的函数。这个函数称为**策略**。

本章覆盖模仿学习中最早、也仍是应用最广的形式——**行为克隆**，它把问题当作普通的监督学习。我们精确定义观测、动作与策略，说明行为克隆是一个回归或分类问题，然后研究会出问题的两件事。第一件是**复合误差**（compounding error）：会犯小错的策略漂移到示范者从未到过的情形里，错误在那里越滚越大——$T$步一个回合的误差按$T^2$而非$T$增长。第二件是**多峰性**：当示范者用两种不同方式解决同一情形时，用均方误差训练的网络会把两者平均，而“从障碍物左边绕”与“从右边绕”的平均是“撞进去”。解药——DAgger、更丰富的动作分布、动作分块——为课程的后续章节定下议程。

本章假定[[robot-arm-design/software-stack]]的软件图景：一个以几百赫兹到几千赫兹运行的实时关节控制器，以及到达得更慢的高层指令。学得的策略正是那些高层指令源之一。关于神经网络及其训练，参考 LLM 图谱：[多层网络](/learn/llm/lesson.php?c=neural-networks&l=perceptrons-mlps)、[反向传播](/learn/llm/lesson.php?c=neural-networks&l=backpropagation)与[优化器](/learn/llm/lesson.php?c=neural-networks&l=optimisers)。

## 观测、动作与策略 {#sec-policies}

每个控制步$t$，机器人收到一个**观测**$o_t$，发出一个**动作**$a_t$。对做桌面操作的机械臂，典型的观测是

- 一到三幅相机图像：一台固定、看着工作空间的“场景”相机，加一台装在末端执行器上的“腕部”相机（尺寸调整后常为224 × 224或256 × 256像素，RGB）；
- **本体感知**：实测关节角（7自由度臂为七个数）、可能还有关节速度、夹爪开度，有时还有正运动学算出的末端执行器位姿；
- 对以语言为条件的策略，还有一条诸如“把红杯子放到盘子上”的指令。

典型的动作是一个7维向量：末端执行器位置的小变化（三个数）与姿态的小变化（三个数）加一个夹爪指令，或者一个关节角目标向量。这个选择关系极大，是[[vision-language-action/action-representations]]的主题。策略通常以5–50 Hz 运行；其动作经插值升到关节控制器的速率。

::: definition 策略、回合与示范 {#def-policy}
**策略**是从观测（或观测的历史）到动作的映射。它可以是**确定性的**，$a_t = \pi(o_t)$，也可以是**随机性的**——一个条件概率分布$\pi(a_t \mid o_t)$，动作从中采样。一个**回合**是从初始状态到成功、失败或时限的序列$\tau = (o_1, a_1, o_2, a_2, \dots, o_T, a_T)$；$T$是**时域**。**示范**是一条其中的动作由专家——通常是遥操作机械臂的人——选出的回合，而**示范数据集**是由$N$条示范构成的集合$\mathcal D = \{\tau^{(1)}, \dots, \tau^{(N)}\}$。
:::

观测不是世界的**状态**$s_t$。状态包括每个物体的精确位置与速度、摩擦系数、一只关着的抽屉里装了什么——这些都是任何相机看不到的。当观测对任务而言足以确定状态时，问题对观测是**马尔可夫的**，策略$\pi(a_t \mid o_t)$就够用。当它不够时（一个被夹爪挡住的物体、一个效果延迟的按钮），策略需要**历史**：$\pi(a_t \mid o_{t-k}, \dots, o_t)$。

::: example 数一数输入与输出 {#ex-dimensions}
一个7自由度平行夹爪臂的策略使用两路224 × 224像素 RGB 相机、七个关节角与夹爪开度，并以10 Hz 输出一个7维末端执行器增量加一条夹爪指令。数一数每步的输入与输出个数，以及200条每条25 s 的示范中的监督训练对数。
::: solution
图像：$2 \times 224 \times 224 \times 3 = 301\,056$个数。本体感知：$7 + 1 = 8$。每步输入总数$\approx 301\,064$个数——被像素以近$40\,000$倍的比例压倒。输出：$6 + 1 = 7$个数（三个平移、三个旋转、一个夹爪），若姿态用四数四元数则为8个。
在10 Hz 下一条25 s 的回合有$T = 250$步，所以200条示范给出$200 \times 250 = 50\,000$对观测-动作。
检验：50,000对听起来不少，但相邻的对几乎一模一样（场景在0.1 s 内变化很小），于是*独立*样本的有效数目更接近示范条数——200。这就是机器人学习贪数据的原因，也是图像编码器通常在别的数据上预训练、而不是仅从这50,000帧学起的原因。
:::
:::

## 行为克隆 {#sec-bc}

拿到示范数据集后最简单的做法，是把每一步当作一个带标签的样本——输入$o_t$，标签$a_t$——对它拟合一个网络。

::: definition 行为克隆 {#def-bc}
**行为克隆**（BC）通过在观测-动作对上做监督学习，把参数化策略$\pi_\theta$拟合到示范，最小化一个经验损失
$$
\mathcal L(\theta) = \frac{1}{\lvert\mathcal D\rvert}\sum_{(o_t, a_t)\in\mathcal D} \ell\bigl(\pi_\theta, o_t, a_t\bigr).
$$ {#eq-bc}
对确定性策略，损失是诸如$\ell = \norm{\pi_\theta(o_t) - a_t}^2$（均方误差，MSE）或$\norm{\pi_\theta(o_t) - a_t}_1$（L1）的回归损失。对随机策略，它是**负对数似然** $\ell = -\log \pi_\theta(a_t \mid o_t)$，于是训练就是专家动作分布的最大似然估计。
:::

行为克隆的吸引力在于它不过是监督学习：不需要奖励函数，训练期间不与世界交互，也不需要仿真器。数据采一次，训练像任何别的深度学习任务一样跑。它的弱点恰恰是同一件事：训练只见专家到过的那些状态，而训好的策略将在一个对*它自己的*——而非专家的——动作做出反应的世界里运行。

上面两个损失是相通的。若策略输出一个均值为$\mu_\theta(o)$、方差固定为$\sigma^2 I$的高斯分布，则
$$
-\log \pi_\theta(a\mid o) = \frac{1}{2\sigma^2}\norm{a - \mu_\theta(o)}^2 + \text{常数},
$$
于是 MSE 回归*就是*单一固定宽度高斯下的最大似然。同样，L1回归是拉普拉斯分布下的最大似然。选哪个损失，就是选假定动作分布是什么形状——这一点我们在[[#sec-multimodal]]中还会回来。

::: quiz
一个行为克隆策略在留出的示范画面上达到0.2 mm 的平均动作误差。关于它在机器人上成功的频率，这告诉你什么？
- [ ] 它几乎总会成功，因为0.2 mm 远低于任务容差。
- [x] 单它本身什么也说明不了：留出的画面来自专家的状态分布，而机器人到达的将是策略自己的动作产生的状态。
- [ ] 它会失败，因为任何非零误差都会无穷放大。
::: solution
离线动作误差是在*专家*到达的状态上度量的。运行策略会产生它自己的轨迹，漂移到数据中可能根本不存在的状态，那里的误差可能大得多。离线损失是有用的调试信号（能抓出 bug 和严重欠拟合），但与闭环成功只有松散的相关，闭环成功必须在机器人上或仿真中度量（[[vision-language-action/policy-evaluation]]）。
:::
:::

## 复合误差与协变量偏移 {#sec-compounding}

设想一个策略沿示范路径驱动夹爪，每一步都差一点点：每步结束时偏离专家路径0.5 mm。下一步的相机图像就与训练集里的任何东西都略有不同。若网络泛化得好，它会修正回路径。若不好——训练目标里没有任何东西要求它会修正，因为专家从不需要从0.5 mm 的偏差中恢复——那么下一个误差就再大一点，图像再陌生一点，轨迹就此脱落。这就是**复合误差**。

::: definition 协变量偏移 {#def-covariate-shift}
设$d_{\pi^*}$是专家策略$\pi^*$访问的观测分布，$d_{\pi_\theta}$是执行学得的策略$\pi_\theta$时访问的分布。行为克隆最小化$d_{\pi^*}$之下的损失，策略却在$d_{\pi_\theta}$之下被使用。训练与测试输入分布之间的这种差异称为**协变量偏移**（或分布偏移）；在序贯决策中，它是策略自己、通过自己的错误造成的。
:::

能坏到什么地步？Ross 与 Bagnell 在2010年通过数错误分析了这一问题。

::: proposition 行为克隆的二次复合误差 {#prop-t2}
考虑一条$T$步的回合，凡学习者的动作与专家不同的每一步记1的代价（更一般地，任何每步代价在$[0,1]$内、只要学习者跟着专家走就为零）。假设在从专家分布抽出的状态上，学得的策略每步犯错的概率至多为$\varepsilon$，并设最坏情形：学习者第一次犯错之后就落在陌生状态里，其余每一步代价都是1。则期望总代价满足
$$
J(\pi_\theta) \le \sum_{t=1}^{T}\bigl[1 - (1-\varepsilon)^t\bigr] \le \varepsilon\,\frac{T(T+1)}{2} = O(\varepsilon T^2),
$$ {#eq-t2}
并且存在达到这一量级的任务。若一个策略*在自己*的状态分布上每步错误率为$\varepsilon$，代价只有$J \le \varepsilon T$。
:::

::: proof
学习者尚未犯错时，它走在专家的轨迹上，所以每一步都是从专家分布中的一次抽样，其上犯错概率至多$\varepsilon$。因此前$t$步一次错也没犯的概率至少为$(1-\varepsilon)^t$，到第$t$步为止至少犯过一次错的概率至多为$1 - (1-\varepsilon)^t$。在最坏情形假设下，第$t$步代价为1恰当在$t$或更早就已至少犯过一次错，故第$t$步的期望代价至多为$1-(1-\varepsilon)^t$。对$t$求和得第一个不等式。伯努利不等式$(1-\varepsilon)^t \ge 1 - t\varepsilon$（对$0\le\varepsilon\le1$、$t\ge1$成立）给出$1-(1-\varepsilon)^t \le t\varepsilon$，而$\sum_{t=1}^T t = T(T+1)/2$给出第二个。
关于达到上界，取一个“窄台”：一次错误把系统送进专家数据中不含恢复之法的区域，此后每一步代价都是1。当$\varepsilon T$很小时，第$t$步的一次错误代价为$T - t + 1$，期望代价为$\sum_t \varepsilon(1-\varepsilon)^{t-1}(T-t+1) \approx \varepsilon T^2/2$。
至于最后一句，若在学习者自己的分布下每步犯错概率至多为$\varepsilon$，则每步期望代价至多为$\varepsilon$，$T$步之和至多为$\varepsilon T$。
:::

这一分析故意悲观——真实的策略常能从小错误中恢复，因为网络会泛化——但它抓住了问题的形状：*同样*的每步精度，在长任务里远比在短任务里值钱得少。更实际的读法用一条回合不带不可恢复错误走完全程的概率$(1-\varepsilon)^T$。

::: example 一个策略能做多长的任务？ {#ex-survival}
某策略每步以概率$\varepsilon = 0.005$犯一次不可恢复的错误。它以10 Hz 运行。估计一个30 s 任务的成功概率，以及要90%成功需要怎样的$\varepsilon$。把 BC 的代价上界与$\varepsilon T$上界比较一下。
::: solution
$T = 30\,\mathrm s \times 10\,\mathrm{Hz} = 300$步。成功概率$(1-0.005)^{300} = 0.222$——五次尝试勉强成一次。
要90%成功，$(1-\varepsilon)^{300} = 0.9$给出$\varepsilon = 1 - 0.9^{1/300} = 3.51\times10^{-4}$：每步失败率必须降低约14倍。
用$\varepsilon = 0.005$的[[#eq-t2]]上界，300步中有$0.005 \times 300 \times 301/2 = 226$步有代价；$\varepsilon T$上界是$1.5$。检验：二次上界离$T = 300$本身——可能的最坏代价——并不远，与只有22%的成功概率相符。
由此得出两条工程教训。更短的有效时域有帮助——这正是*动作分块*（[[vision-language-action/action-representations]]，每几个控制步才做一次决策）效果如此之好的一个原因。而恢复数据——从略有偏差的状态开始的示范——则直接进攻这个问题。
:::
:::

x: 0, 600

sliders: r=0.0005:0.0005:0.01

### DAgger：请教专家，到学习者去的地方 {#sec-dagger}

[[#prop-t2]]的证明指出了多出的那个因子$T$从何而来：学习者在一个分布上训练，却在另一个分布上测试。**DAgger**（Dataset Aggregation，数据集聚合；Ross、Gordon 与 Bagnell，2011）通过*在学习者访问的状态上*收集专家标签来消除这一失配。

::: algorithm DAgger {#alg-dagger}
1. 收集一个专家示范的初始数据集$\mathcal D_0$，用行为克隆在其上训练$\pi_1$。
2. 对迭代$i = 1, 2, \dots, K$：
   - 运行当前策略$\pi_i$（可与专家混合：以概率$\beta_i$执行专家的动作，此概率递减到0），记录它访问的观测。
   - 请专家为每个访问到的观测$o$标注它本会采取的动作$\pi^*(o)$。
   - 聚合：$\mathcal D_i = \mathcal D_{i-1}\cup\{(o, \pi^*(o))\}$。
   - 在$\mathcal D_i$上训练$\pi_{i+1}$。
3. 返回验证回合上最好的策略。
:::

由于训练分布现在包含了学习者自己的状态，学习者就在它被测试的地方接受训练；Ross、Gordon 与 Bagnell 利用无后悔在线学习理论证明，所得代价只随时域线性增长，$O(\varepsilon T)$。

在真实机械臂上的症结是第2步：事后请人为机器人轨迹的每一帧标注动作是反人性的——人看着视频，说不出自己当时会下什么关节速度指令。实用的变体改让人来干预。**人类门控 DAgger**（HG-DAgger，Kelly 等，2019）中，操作员手持遥操作设备看着策略运行，出错时便接管；接管片段——从策略自己造成的状态中的一次恢复——被加入数据。许多工业数据采集项目采用这一模式（“干预数据”），并配合有意扰动的示范：操作员从一个略有偏差的位姿出发并把它纠正回来。

::: warning 要恢复数据，不要错误
加入干预数据时，只把*专家*的纠正动作记为训练标签。若把策略正在漂移（人接管之前）的帧连同策略自己的动作一起留作标签，数据集就反过来在教那些错误。给日志里的每一帧标上当时由谁掌控，并在构造训练集时按该标志过滤。
:::

## 多峰示范 {#sec-multimodal}

协变量偏移是策略在*哪里*被评测的问题。朴素行为克隆的第二个失效是它在单一状态上学到*什么*的问题。人的示范很少一致：面对一只马克杯，一位操作员抓把手，另一位抓杯沿；面对一个障碍物，一半从左边绕，一半从右边绕。于是专家的动作分布$\pi^*(a\mid o)$有好几个分立的峰——它是**多峰的**。

::: proposition MSE 最优策略是条件均值 {#prop-mean}
在观测的所有函数$f$中，示范分布下的期望平方误差$\E\bigl[\norm{a - f(o)}^2\bigr]$在条件均值$f^*(o) = \E[a\mid o]$处最小。标量动作的 L1误差$\E\bigl[\lvert a - f(o)\rvert\bigr]$在条件中位数处最小。
:::

::: proof
固定$o$，记$m = \E[a\mid o]$。对任意候选值$c$，
$$
\E\bigl[\norm{a-c}^2\mid o\bigr] = \E\bigl[\norm{(a-m) + (m-c)}^2\mid o\bigr] = \E\bigl[\norm{a-m}^2\mid o\bigr] + \norm{m-c}^2,
$$
因为交叉项$2(m-c)\T\E[a-m\mid o] = 0$。右端在$c = m$时最小。对$o$取平均，函数$f^*(o) = \E[a\mid o]$即最优。对 L1，$g(c) = \E\lvert a - c\rvert$是凸函数，其（次）导数为$\Prob(a < c) - \Prob(a > c)$，它在中位数处变号。
:::

多峰分布的条件均值一般*在*各模式*之间*，而专家从不在那里动作。对一个策略来说，那个平均往往是唯一注定失败的动作。

::: example 绕障碍物的平均 {#ex-obstacle}
夹爪必须越过一根占据$-0.05\,\mathrm m < y < 0.05\,\mathrm m$的立柱。60%的示范中操作员从$y = -0.10\,\mathrm m$处绕左；40%中从$y = +0.10\,\mathrm m$处绕右。(a) MSE 训练的策略选哪个横向位置？(b) 把该选择的 MSE 与总是绕左的 MSE 比较。(c) 拟合一个两分量高斯混合头，权重$0.6/0.4$、均值$\mp0.10\,\mathrm m$、标准差$0.02\,\mathrm m$。它在$y = -0.10$、$+0.10$与$-0.02\,\mathrm m$处的负对数似然是多少？
::: solution
(a) 由[[#prop-mean]]，$y^* = 0.6(-0.10) + 0.4(0.10) = -0.02\,\mathrm m$——在立柱内部。策略会撞上。
(b) $y = -0.02$处的 MSE：$0.6(-0.10+0.02)^2 + 0.4(0.10+0.02)^2 = 0.6(0.0064) + 0.4(0.0144) = 0.0096\,\mathrm{m^2}$。总是绕左的 MSE：$0.6(0) + 0.4(0.20)^2 = 0.0160\,\mathrm{m^2}$。损失*大幅偏爱*这个会撞上的动作；再多的训练数据或网络容量也救不了，因为损失本身正是在那个平均上取到最小。
(c) 混合密度为$p(y) = 0.6\,\mathcal N(y; -0.1, 0.02^2) + 0.4\,\mathcal N(y; 0.1, 0.02^2)$，每个高斯的峰值高度$1/(0.02\sqrt{2\pi}) = 19.95\,\mathrm{m^{-1}}$。在$y = -0.10$处第二分量贡献$e^{-50}$，可忽略，故$p = 0.6 \times 19.95 = 11.97$，$-\log p = -2.48$。在$+0.10$：$p = 0.4\times19.95 = 7.98$，$-\log p = -2.08$。在$-0.02$：两个分量分别在4个与6个标准差之外，$p = 0.6\times19.95\,e^{-8} + 0.4\times19.95\,e^{-18} = 4.0\times10^{-3}$，$-\log p = 5.52$。似然损失把概率放在各模式上、几乎一点不放在它们之间；从中采样60%的时间得左、40%得右，两者都安全。
检验：本例中的 L1损失会选中位数$-0.10\,\mathrm m$，恰好安全——但只因为一个模式占了过半的数据。若是各占33%的三个模式，中位数就是中间那个模式；若是连续展布，它又可能落在模式之间。
:::
:::

### 更丰富的动作头

解法是给策略一个能表示多个峰的输出，并用似然（或等价目标）而非平方误差来训练。所用的有三族。

1. **混合密度头。**网络输出$K$个高斯分量的权重$w_k$、均值$\boldsymbol\mu_k$与（对角）方差，$\pi_\theta(a\mid o) = \sum_k w_k\,\mathcal N(a; \boldsymbol\mu_k, \Sigma_k)$，以负对数似然训练。$K = 5$到$10$时，它在2021年前后的机器人学习基准上是很强的基线。混合分布可能难训练（分量会塌到一起，或一个分量拿走全部权重），在高维中也会变得别扭。
2. **在离散化动作上作分类。**每个动作维度分成箱——RT-1与 RT-2用256个——网络输出箱上的类别分布，用交叉熵训练。类别分布每维能表示任意多个模式。它的局限是分辨率与维度之间的相互独立，而它也正是[[vision-language-action/action-representations]]中“动作即词元”的基础。
3. **整个动作的生成式模型。**扩散与流匹配模型（[[vision-language-action/diffusion-flow-policies]]）学会从整个动作块上的任意分布*采样*，是截至2026年连续控制的主导做法。隐式（基于能量）策略给候选动作打分并挑最好的，曾是中间的一步（Florence 等，2021）。

::: example 256箱分类头的分辨率 {#ex-bins}
末端执行器每步平移指令被限制在$\pm 5\,\mathrm{cm}$内，并每轴均匀离散为256个箱。求箱宽、最大量化误差与 RMS 量化误差，并与典型协作机械臂的重复定位精度（约$\pm 0.03$–$0.1\,\mathrm{mm}$）作比较。
::: solution
范围$0.10\,\mathrm m$；箱宽$\Delta = 0.10/256 = 3.91\times10^{-4}\,\mathrm m = 0.391\,\mathrm{mm}$。解码出的动作是箱中心，故最大误差为$\Delta/2 = 0.195\,\mathrm{mm}$；对箱内均匀分布的动作，RMS 误差为$\Delta/\sqrt{12} = 0.113\,\mathrm{mm}$。
这比机械臂的重复定位精度大，但与多数抓取几毫米的容差相比很小。注意这是*每步*误差：若策略在对增量做积分，量化误差就会累积，尽管来自相机的闭环反馈会把它们纠正掉。更紧的范围（$\pm 2\,\mathrm{cm}$）给出$0.156\,\mathrm{mm}$的箱，却会削去更快的动作——范围与箱数必须依数据的统计特性选取，这就是 VLA 训练流水线在离散化前先计算动作逐维分位数的原因。
:::
:::

## 历史、观测与因果混淆 {#sec-history}

策略该看一帧还是几帧？加历史看似无害——更多信息不可能害到一个完美的学习者——但实践中它常常使行为克隆*更糟*。这一原因被 de Haan、Jayaraman 与 Levine（2019）命名为**因果混淆**：有了历史，网络可能找到一条捷径，从机器人自己最近的运动而非从场景来预测专家的动作。在一条示范里，机械臂在第$t-1$步的下降是它在第$t$步继续下降的绝佳预报量。一个学会“接着做你在做的动作”的网络达到很低的训练损失，却在必须*开始*一个动作时彻底失败。相关的**复制问题**（copycat problem）出现在使用本体感知历史时：过去的动作几乎就是标签的复制品。

实用的推论，在被广泛使用的策略中有所体现：

- 多数成功的操作策略使用**短历史**——当前帧，或过去的一两帧——转而通过预测未来动作的*块*来提供时间上下文（[[vision-language-action/action-representations]]）。
- **本体感知**有助精度（网络确切知道夹爪在哪里），但会招致走捷径；一些流水线在训练期间对其加噪或随机丢弃。
- 对抓取来说，**腕部相机**是单项添加中最有效的之一：它以近距、在夹爪自身的坐标系中看物体，那里的小误差在像素上是大的。
- 观测应当包含专家做决定时用过的信息。若操作员看了显示屏，或听了一声咔哒，这些信息就必须出现在观测里，否则策略会看到专家“无缘无故”地行动——这看起来就像多峰性。

::: remark 模仿与强化学习
强化学习（RL）通过试错优化奖励，原则上没有协变量偏移问题，因为它从自己的经验中学习。在真实机械臂上，它受限于探索的代价与安全性，以及为“把衬衫叠整齐”这类任务写奖励的困难。模仿学习能从示范迅速得到不错的策略；随后 RL 可对它微调。截至2026年，多数部署的学习型操作策略主要以模仿方式训练，某些系统用 RL 做微调。Sutton 与 Barto（见课程参考文献）是标准入门。
:::

::: example 为抓取-放置工位选损失 {#ex-design}
一台机械臂从料箱里拣出螺栓并放入夹具。示范由四位操作员采集。检查发现：对放置动作，所有操作员几乎动作一致；而对抓取，操作员会选择料箱里不同的螺栓。推荐一个动作头，并说明你会如何检验数据是否多峰。
::: solution
抓取本质上是多峰的：给定同一幅料箱图像，“正确的”目标是若干螺栓中的任何一个，而 MSE 头会朝两个螺栓之间瞄。需要一个能表示分布的头——动作块上的扩散头或流头，或一个离散化头——以似然（或其扩散/流等价形式）训练。对放置动作，单峰回归即可满足，但一个头可以两用。
要检验多峰性，找出近似重复的观测（例如预训练编码器图像嵌入空间中的最近邻），并画出对应专家动作的散布。散布分裂成簇的即是多峰；只是宽的散布可能是不一致的操作，那最好在数据采集阶段解决（[[vision-language-action/demonstration-data]]）。第二种检验是行为上的：若一个回归策略在机器人上悬停、犹豫或在两个目标之间振荡，它就是在对模式取平均。
检验：所需容量不大——低维动作里的几个模式——所以即使每维256箱的分类头也能表示它；此时头之间的选择由平滑性与推理速度而非表达力决定。
:::
:::

::: history
行为克隆比深度学习更老。Dean Pomerleau 在卡内基梅隆的 ALVINN（1988–89）是一个三层网络，带30 × 32输入的“视网膜”，从人类司机的记录中学开面包车；Pomerleau 已经看到了协变量偏移——只在良好驾驶上训练的网络永远见不到汽车偏离中线——并用合成带相应纠正转向的道路平移视图加以外。Stéphane Ross 与 Drew Bagnell 在2010年给出$T^2$分析，并与 Geoffrey Gordon 在2011年提出 DAgger，在赛车游戏与《超级马里奥兄弟》上试验。约2016年出现了从像素端到端训练的深度视觉运动策略（Levine、Finn、Darrell 与 Abbeel）。2022年，Google 的 RT-1表明，用 Transformer 和约130,000条真实示范做行为克隆，能产生一个覆盖数百条指令的统一策略；2023年，Diffusion Policy（Chi 等）与 ACT（Zhao 等）把多峰性与精度问题解决得足够好，行为克隆从此成为学习型操作的默认配方。
:::

::: summary
- **策略**把观测（图像、本体感知、指令）映射为动作；**行为克隆**用示范对做监督学习来拟合它。
- MSE 回归是单峰高斯下的最大似然；损失编码了关于专家动作分布形状的一个假定。
- **协变量偏移**：策略在专家的状态上训练，却在自己造成的状态上运行。最坏情形下期望代价按$O(\varepsilon T^2)$增长，训练与测试分布一致时才是$O(\varepsilon T)$；一条回合干净走完的概率约为$(1-\varepsilon)^T$。
- **DAgger** 给学习者自己的状态标注标签；在真实机械臂上，人的干预与恢复示范起同样作用。只标注专家的纠正动作。
- **多峰**示范使 MSE 最优动作成为条件均值，它可能落在安全模式之间。以似然训练的混合、类别与生成式（扩散、流）头能表示多个模式。
- 长历史招致**因果混淆**；短历史加上动作块与腕部相机是通常的设计。
:::

::: exercise 数据集中的样本对 {#exr-pairs level=1 check="72000"}
一个数据集含120条每条40 s 的示范，以15 Hz 记录。它包含多少个观测-动作对？（填入对数。）
::: solution
每条示范$T = 40 \times 15 = 600$步；$120 \times 600 = 72\,000$对。
:::

::: exercise 三分之分的 MSE 最优值 {#exr-mean3 level=1 check="0.015"}
在某一状态，示范者们的横向偏置为$-0.06\,\mathrm m$（25%）、$0.02\,\mathrm m$（50%）与$0.08\,\mathrm m$（25%）。MSE 训练的确定性策略会输出哪个偏置？（以 m 填入该偏置。）
::: solution
条件均值：$0.25(-0.06) + 0.5(0.02) + 0.25(0.08) = -0.015 + 0.010 + 0.020 = 0.015\,\mathrm m$。它落在前两个模式之间，那里没有示范者动作过。（L1最优是中位数$0.02\,\mathrm m$。）
:::
:::

::: exercise 更长任务上的存活 {#exr-survive level=1 check="0.549"}
一个每步不可恢复错误概率为$\varepsilon = 0.001$的策略以20 Hz 运行一个30 s 的任务。估计成功概率。（以小数填入，保留三位小数。）
::: solution
$T = 600$；$(1-0.001)^{600} = e^{600\ln 0.999} = e^{-0.6003} = 0.549$。
:::
:::

::: exercise 达到目标所需的每步可靠性 {#exr-eps level=2 check="5.27e-4"}
在模型$(1-\varepsilon)^T$下，一个10 Hz 的20 s 任务必须有90%的时间成功。允许的最大每步失败概率$\varepsilon$是多少？（$\varepsilon$保留三位有效数字。）
::: solution
$T = 200$；$\varepsilon = 1 - 0.9^{1/200} = 1 - e^{\ln(0.9)/200} = 1 - e^{-5.268\times10^{-4}} = 5.27\times10^{-4}$。近似为$-\ln(0.9)/T = 0.1054/200$，在$\varepsilon$很小时它是准的。
:::
:::

::: exercise 动作分块与时域 {#exr-chunk level=2 check="0.740"}
把[[#ex-survival]]中的同一个策略改为预测10步动作块并对每块开环执行，于是每10个控制步才做一次决策。假设不可恢复错误的概率现在为*每次决策*$\varepsilon_c = 0.01$（比每步更高，因为每次决策承诺了整整一秒的运动）。求30 s 任务的成功概率。（保留三位小数。）
::: solution
决策数：$300/10 = 30$。成功$(1-0.01)^{30} = 0.99^{30} = 0.740$。与逐步决策的0.222相比，更短的有效时域抵过了更高的每次决策错误率。这个模型很粗糙（开环执行在块内无法反应），但说明了分块为何对行为克隆有如此大的助益。
:::
:::

::: exercise 高斯对混合的似然 {#exr-nll level=2}
对[[#ex-obstacle]]的示范分布（60%在$-0.10\,\mathrm m$，40%在$+0.10\,\mathrm m$），比较 (a) 最佳单高斯与 (b) 例中给出的$\sigma = 0.02\,\mathrm m$两分量混合的平均负对数似然。把示范视为恰好在$\pm0.10\,\mathrm m$。
::: solution
(a) 最大似然单高斯取数据均值$-0.02\,\mathrm m$与方差$0.0096\,\mathrm{m^2}$（例子中已算出），标准差$0.098\,\mathrm m$。其平均 NLL 为$\tfrac12\ln(2\pi\sigma^2) + \tfrac12 = \tfrac12\ln(0.0603) + 0.5 = -1.404 + 0.5 = -0.904$。(b) 混合的 NLL 在左模式为$-2.48$、在右模式为$-2.08$，平均$0.6(-2.48) + 0.4(-2.08) = -2.32$。混合对数据的拟合好得多（每样本 NLL 低$1.42$纳特），而且——更重要的是——几乎不把概率放在碰撞区域上，而单高斯的峰就在碰撞点。
:::
:::

::: exercise 窄台的二次上界 {#exr-ledge level=3}
在[[#prop-t2]]的窄台任务中，第$t$步的错误使步$t, t+1, \dots, T$各产生1的代价，而学习者在首次犯错之前每步都以概率$\varepsilon$犯错。证明期望代价为$J = \sum_{t=1}^{T} \varepsilon(1-\varepsilon)^{t-1}(T-t+1)$，对$\varepsilon = 0.01$、$T = 50$求其值，并与$\varepsilon T^2/2$和$\varepsilon T$比较。
::: hint
第一次错误发生在第$t$步的概率为$\varepsilon(1-\varepsilon)^{t-1}$。数值求和即可。
:::
::: solution
事件“第$t$步首次犯错”（$t = 1,\dots,T$）两两互斥，概率为$\varepsilon(1-\varepsilon)^{t-1}$；其时代价为$T - t + 1$。求和即得$J$；该和有封闭形式$J = T - (1-\varepsilon)\bigl(1 - (1-\varepsilon)^T\bigr)/\varepsilon$。取$\varepsilon = 0.01$、$T = 50$，$(1-\varepsilon)^T = 0.605$，故$J = 50 - 0.99\times0.395/0.01 = 10.9$。近似$\varepsilon T^2/2 = 12.5$略有高估，因为它略去了不犯错的可能；线性速率$\varepsilon T = 0.5$则小了二十倍。二次增长来自因子$(T - t + 1)$：一次早犯的错误赔上整个剩余回合。
:::
:::

::: exercise 规划一个干预数据项目 {#exr-intervention level=3}
你公司针对插入连接器的第一个行为克隆策略在55%的试次中成功。失败视频显示，策略接近的动作正确，但当连接器卡在壳体边缘时，它继续硬推，而不是退出、重新对准。设计一个数据采集方案（由谁、采什么、采多少、如何标注）来修复这一点，并说明你如何知道它起效了。
::: solution
这一失败是示范从未到过的一种状态（连接器卡在边缘上），所以这是协变量偏移，不是多峰性。方案：(1) 操作员手持遥操作设备运行当前策略；连接器卡住时，操作员接管、退出、重新对准并完成插入（HG-DAgger 风格）。给每一帧记录一个“谁在掌控”标志。(2) 同时采集刻意的恢复示范：操作员从错位的接触出发并恢复过来。(3) 采足够的量使其在混合中占分量——量级为50–100条干预回合，相对于几百条原始示范占可观的比例，因为恢复状态在原始数据中罕见。(4) 在原始数据加上仅由操作员掌控的帧上训练。(5) 用同一组初始条件、盲评且交错地评测新旧策略，报告带置信区间的成功率（[[vision-language-action/policy-evaluation]]）；同时统计卡在边缘上的状态出现的频率，以及如今它被恢复的频率。若出现新的失败模式就重复这一流程——DAgger 生来就是迭代的。
:::
:::

::: exercise 为什么完美的学习者仍会失败 {#exr-perfect level=3}
用一个机器人操作的例子解释：一个行为克隆策略为何能在专家的状态分布上达到*零*误差、却仍在机器人上失败。要不发生这一点，专家的示范需要什么性质？
::: solution
在$d_{\pi^*}$下误差为零，对其支撑之外的状态什么也没说。任何数据中不存在的扰动——一次传感器故障、一次打滑的接触、一个放在示范范围外3 cm 处的零件、一个以与遥操作时略为不同的动力学跟踪指令的执行器——都会把机器人移出专家的轨迹，而策略在那里的行为就是网络碰巧外推出的任何东西。例子：所有示范都一次完美抓起马克杯，于是数据集里没有任何抓取落空的图像；一次落空之后，策略可能提起一只空夹爪。要使 BC 稳健，示范必须以纠正动作覆盖专家轨迹的一个邻域：专家应当“带噪声但会恢复”（扰动的起点、遥操作期间注入噪声——Laskey 等的 DART 方法（2017）背后的思想——或干预数据），使$d_{\pi^*}$包含学习者将要到达的状态。
:::
:::
