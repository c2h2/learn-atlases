“我们的策略有85%的成功率。”这句话是多数机器人学习工作的最终成果，单看它几乎什么也说明不了。85%是对多少次试次而言——20次还是2,000次？从哪些位置出发，由谁挑选？与什么相比，在同一天、由知道正在运行哪个策略的评测者测出的？两个策略各做20次，10个百分点的差距完全落在单凭运气也能产生的范围之内；一个在训练所用物体上表现出色的策略，可能会在顾客放到它面前的第一个新杯子上失败。学得的策略不能像程序那样逐行验证，所以它们的评测*就是*它们的规格说明：你测到了什么、测得有多仔细，就是你对将要交付之物所能知道的全部。

本章把评测当作一场试验来对待。我们先定义指标，把成功建模为二项结果，并构造在试次数少时也表现正确的置信区间（Wilson 区间），再用能利用配平初始条件的检验来比较两个策略。接着介绍规程——设盲、交错进行、预先登记的试次——以及应当沿之检验泛化的各个泛化轴。最后一部分讲仿真：用于比较各方法的基准（LIBERO、SIMPLER、CALVIN 等）、它们能告诉你什么、不能告诉你什么，以及仿真到真机的差距（sim-to-real gap）。所用的统计就是 Maths Atlas 中的[置信区间](/learn/maths/lesson.php?c=statistics&l=confidence-intervals)与[假设检验](/learn/maths/lesson.php?c=statistics&l=hypothesis-testing)；语言模型上的同样问题在 LLM Atlas 的[评测中的统计](/learn/llm/lesson.php?c=evaluation&l=evaluation-statistics)中讨论。

## 要测什么 {#sec-metrics}

::: definition 试次与成功率 {#def-trial}
一次**评测试次**是从一个指定的**初始条件**（物体的位置与身份、机器人起始位姿、场景、指令）出发运行策略的一个回合，直到成功、失败或到达时限为止，其结果由事先固定的**成功判据**判定。策略在一个初始条件分布上的**成功率**是该分布下一次试次成功的概率$p$；它由$n$次独立试次中的$k$次成功估计为$\hat p = k/n$。
:::

一个二元的成败标志隐藏了许多东西，所以评测通常还会记录：

- 多阶段任务的**进度或部分得分**（已抓住、已抬起、已放置、已松开），它显示策略在*哪里*失败；
- 成功者中间的**完成用时**，以及一个单元能达到的吞吐（每小时抓取数）；
- **干预**：长时间运行时需要人手帮忙的频率（每小时干预次数或平均干预间隔时间）；
- **安全事件**：碰撞、触发力或速度上限、掉落物体、保护性停止（[[vision-language-action/vla-deployment]]）；
- **失败类别**：感知（认错物体）、抓取、碰撞、超时、卡死。

成功判据必须精确到两名评测者能达成一致：“杯子竖直放在盘子上、底部完全位于盘沿以内，且夹爪已松开”，而不是“杯子在盘子上”。在第一次试次之前就要把它写下来。

## 成功率的不确定度 {#sec-intervals}

若各试次独立且有共同的成功概率$p$，则$n$次试次中的成功次数$K$服从二项分布$K\sim\Bin(n, p)$，均值为$np$、方差为$np(1-p)$；$\hat p$的标准误差为$\sqrt{p(1-p)/n}$。教科书里那种（“Wald”）95%区间$\hat p\pm1.96\sqrt{\hat p(1-\hat p)/n}$在机器人评测的样本量下不可靠：20次中成功17次时它给出$[0.69, 1.01]$——已经越过100%——而成功0次或$n$次时它的宽度为零。Wilson 得分区间没有这些毛病。

::: proposition Wilson 得分区间 {#prop-wilson}
设$\hat p = k/n$，并设$z$为所选置信水平对应的标准正态分位数（95%时$z = 1.96$）。使$\lvert\hat p - p\rvert\le z\sqrt{p(1-p)/n}$成立的$p$的取值集合，就是一个中心与半宽如下的区间：
$$
\tilde p = \frac{\hat p + \dfrac{z^2}{2n}}{1 + \dfrac{z^2}{n}},\qquad w = \frac{z}{1 + \dfrac{z^2}{n}}\sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}} .
$$ {#eq-wilson}
它永远落在$[0, 1]$之内，并且对大的$n$有接近名义水平的覆盖率——$n$很小时也接近。
:::

::: proof
这个区间收集的是不被正态近似（“得分”）检验拒绝的$p$值，该检验在假设的$p$处而不是在$\hat p$处取标准误差。把条件平方：$(\hat p - p)^2\le z^2p(1-p)/n$。令$c = z^2/n$，它就是
$$
(1 + c)\,p^2 - (2\hat p + c)\,p + \hat p^2\le0,
$$
这是关于$p$、首项系数为正的二次不等式，所以解集是它的两个根之间的区间
$$
p_\pm = \frac{2\hat p + c\pm\sqrt{(2\hat p + c)^2 - 4(1+c)\hat p^2}}{2(1+c)} .
$$
判别式化简：$(2\hat p + c)^2 - 4(1+c)\hat p^2 = 4\hat p c + c^2 - 4c\hat p^2 = 4c\,\hat p(1-\hat p) + c^2$。于是中心为$(\hat p + c/2)/(1+c)$，半宽为$\sqrt{4c\hat p(1-\hat p) + c^2}/\bigl(2(1+c)\bigr) = \frac{\sqrt c}{1+c}\sqrt{\hat p(1-\hat p) + c/4}$；代入$c = z^2/n$即得 [[#eq-wilson]]。在$p = 0$与$p = 1$处，原条件的右端为零而左端为$\hat p^2\ge0$或$(1-\hat p)^2\ge0$，所以两个根都落在$[0,1]$之内——只有当$\hat p = 0$时才能取到0，只有当$\hat p = 1$时才能取到1。覆盖率：由中心极限定理，$(\hat p - p)/\sqrt{p(1-p)/n}$近似标准正态，所以$z = 1.96$时该条件约有95%的概率成立。
:::

::: example 小规模评测的 Wilson 区间 {#ex-wilson}
求下列情形下95%的 Wilson 区间：(a) 20次试次中成功17次，(b) 20次中0次，(c) 100次试次中成功85次。把 (a) 与 Wald 区间作比较。
::: solution
(a) $\hat p = 0.85$，$c = 1.96^2/20 = 0.1921$。中心 $(0.85 + 0.0960)/1.1921 = 0.794$。半宽 $\frac{1.96}{1.1921}\sqrt{0.85\times0.15/20 + 1.96^2/1600} = 1.644\sqrt{0.006375 + 0.002401} = 1.644\times0.09368 = 0.154$。区间 $[0.640, 0.948]$。Wald：$0.85\pm1.96\times0.0798 = [0.694, 1.006]$——整体偏上，且上端是不可能出现的值。
(b) $\hat p = 0$：中心 $0.0960/1.1921 = 0.0806$，半宽 $1.644\sqrt{0.002401} = 0.0806$；区间 $[0, 0.161]$。即使20次试次无一成功，也不能排除16%的真实成功率。（“三法则”给出零事件时精确单侧95%上界的一个快捷近似：$3/n = 0.15$。）
(c) $c = 0.03842$；中心 $(0.85 + 0.0192)/1.0384 = 0.837$；半宽 $\frac{1.96}{1.0384}\sqrt{0.001275 + 0.000096} = 1.8875\times0.03703 = 0.0699$；区间 $[0.767, 0.907]$。
检验：试次数增至五倍，宽度从0.31缩到0.14，比值约 $\sqrt5 = 2.2$，正合 $1/\sqrt n$ 律的预测。20次试次能区分“大约80%”与“大约50%”，但区分不了80%与90%。
:::
:::

### 独立性与$p$指的是什么

二项模型假设各试次独立且有共同的$p$。两者都不精确成立。来自*不同*初始条件的试次有不同的成功概率（靠近工作空间边缘的物体更难），此时$\hat p$估计的是对所选条件集合取的平均——只有当这个集合能代表使用条件时，这个平均才有意义。试次之间可能通过时间发生相关：机器人在预热，午后光线在变，评测者越来越会把物体摆得对自己有利。把要比较的策略交错运行，并固定初始条件清单，能使这些效应不至于给比较带来偏差。

## 比较两个策略 {#sec-compare}

多数评测都是比较：新检查点对比旧检查点，微调后的对比基座，带不带腕部相机。对两组独立的试次，标准的精确检验是对成功与失败构成的$2\times2$表做 **Fisher 精确检验**。机器人评测可以做得更好，因为两个策略可以用完全相同的初始条件。

::: definition 配对评测 {#def-paired}
在**配对**评测中，$m$个初始条件中的每一个都在策略 A 与策略 B 下各运行一次，顺序随机。每个条件于是落入四个格子之一：两者都成功（$n_{11}$）、只有 A 成功（$n_{10}$）、只有 B 成功（$n_{01}$）、两者都失败（$n_{00}$）。结果不同的那些对子（$n_{10}$与$n_{01}$）称为**不一致**对。
:::

::: proposition McNemar 精确检验 {#prop-mcnemar}
若 A 与 B 在每个初始条件上的成功概率相同（原假设），则在给定不一致对数$n_d = n_{10} + n_{01}$的条件下，计数$n_{10}$服从二项分布$\Bin(n_d, \tfrac12)$。观察到这种分裂的双侧$p$值为$2\Prob\bigl(X\le\min(n_{10}, n_{01})\bigr)$，其中$X\sim\Bin(n_d, \tfrac12)$（超过1时按1计）。
:::

::: proof
固定一个初始条件，设两个策略在其上的成功概率都是$q$，并设两次试次相互独立。只有 A 成功的概率是$q(1-q)$，只有 B 成功的概率是$(1-q)q$——相同。所以，在给定某对不一致的条件下，它是“只有 A”类型的概率是$\tfrac12$，无论$q$为何值。来自不同条件的对子相互独立，所以在给定$n_d$对不一致的条件下，$n_{10}$就是对概率$\tfrac12$做的$n_d$次独立试验中的成功次数。双侧$p$值把与所观察分裂至少同样悬殊情形的尾概率加倍（分布是对称的）。
:::

一致的对子不携带关于两个策略*差异*的信息，检验把它们忽略掉。容易的条件（两者都成功）与不可能的条件（两者都失败）不再增加噪声，这就是配对设计需要更少试次的原因。

::: example 同一批试次的配对与不配对分析 {#ex-paired}
30个初始条件各在策略 A 与 B 下运行一次。两者都成功的14个，只有 A 成功的10个，只有 B 成功的2个，两者都失败的4个。(a) 给出每个策略的成功率及其 Wilson 区间。(b) 忽略配对，用 Fisher 精确检验检验这一差异。(c) 用 McNemar 精确检验检验它。
::: solution
(a) A：$14 + 10 = 24$，共30，$\hat p = 0.80$，Wilson $[0.63, 0.91]$。B：$14 + 2 = 16$，共30，$0.53$，Wilson $[0.36, 0.70]$。两个区间稍有重叠。
(b) $2\times2$表为24/6对16/14；Fisher 精确双侧$p = 0.054$——在5%水平下不显著。
(c) 不一致对$n_d = 12$，分裂为10比2。对$X\sim\Bin(12, \tfrac12)$，$\Prob(X\le2) = (1 + 12 + 66)/2^{12} = 79/4096 = 0.0193$；双侧$p = 0.039$——在5%下显著。
同样60次试次按配对分析时给出更清楚的答案，因为18个一致的条件（14个容易、4个不可能）被从比较中剔除了。检验：在两个策略确有分歧的条件上出现10比2的分裂是一个很强的信号，而且 A 的成功率高出27个百分点；两种分析指向一致，而只有配对的那一种灵敏到足以确认它。
:::
:::

::: warning 区间重叠不是检验
即使两个策略之间的差异在统计上显著，两个95%置信区间也可能重叠（[[#ex-paired]]）；而不重叠又是比5%检验严格得多的判据。比较策略要用针对*差异*的检验（或区间），设计是配对的就要用配对的检验。
:::

### 需要多少次试次？

对两组独立的试次，要用显著性水平$\alpha$、功效$1-\beta$的双侧检验检出成功率$p_1$与$p_2$之间的差异，每个策略所需的试次数近似为
$$
n\approx\frac{\Bigl(z_{1-\alpha/2}\sqrt{2\bar p(1-\bar p)} + z_{1-\beta}\sqrt{p_1(1-p_1) + p_2(1-p_2)}\Bigr)^2}{(p_1 - p_2)^2},\qquad \bar p = \frac{p_1 + p_2}{2},
$$ {#eq-samplesize}
这是比较两个比例的标准正态近似公式。配对设计需要的试次更少，减少多少取决于两个策略的结果在各条件之间关联得有多强。

::: example 规划一次 A/B 试验 {#ex-samplesize}
一个新检查点预计把成功率从60%提到80%。要在不配对的试次下、在5%水平上达到80%的功效，每个策略需要多少次试次？如果每次试次（含复位）耗时2分钟，评测要做多久？
::: solution
$\bar p = 0.70$；$z_{0.975} = 1.960$，$z_{0.80} = 0.842$。分子：$1.960\sqrt{2\times0.7\times0.3} + 0.842\sqrt{0.24 + 0.16} = 1.960\times0.6481 + 0.842\times0.6325 = 1.2703 + 0.5323 = 1.8026$；平方得 $3.249$。分母 $0.04$。$n\approx81$ 次试次每个策略。
用时：$2\times81\times2\,\mathrm{min} = 324\,\mathrm{min} = 5.4\,\mathrm h$ 的机器人时间与人手时间。
检验：常见的“各20次”检出20个百分点提升的概率只有大约四分之一到三分之一；这样的评测会漏掉大部分这个量级的真实改进，而一旦“检出显著”，又往往把它夸大。在一组固定的条件上做配对设计，是做得更好的最省钱办法。
:::
:::

## 规程 {#sec-protocol}

统计救不了一个有偏的实验。以下做法借鉴临床试验，如今在严谨的机器人学习论文中已属常见，它们消除的是偏倚的主要来源。

::: algorithm 一套真实世界评测规程 {#alg-protocol}
1. **先定问题与判据**，再开始跑任何东西：策略、任务、成功判据、部分得分的阶段、时限与试次数。
2. **固定初始条件**：一份物体位置、身份与姿态的清单（从预期分布抽样，或取网格），用模板、标记，或在实时相机画面上叠加一幅参考图来摆放。
3. **配对并随机化**：每个条件在每个策略下都运行；每个条件之内各策略的顺序随机，使任何策略都不因时刻、电池或磨损效应而占便宜。
4. **对评测者设盲**：负责复位场景与判定成败的人不应知道正在运行哪个策略（由脚本选择并加载）。
5. **记录一切**：每次试次的视频、策略与检查点标识符、时间戳、判定的结果与失败类别。
6. **在另一组条件上选检查点**：超参数与检查点在一个条件验证集上选；最终结果在留出的条件上报告。
7. **完整报告**：试次数、每个成功率以及两者之差的区间、所用的检验、条件清单与失败分析——包括失败本身。
:::

::: example 检查点选择的胜者诅咒 {#ex-selection}
同一次训练的五个检查点，真实成功率都是60%。各用20次试次评测，报告其中最好的那个。平均报告出的成功率是多少？
::: solution
每个观察到的成功率是$\Bin(20, 0.6)/20$，标准差$\sqrt{0.24/20} = 0.110$。这样的五个抽样取最大值会向上偏；用模拟求得其期望为$0.725$，即72.5%，比真实值高约12个百分点。五个独立标准正态的期望最大值约为$1.16$，给出估计$0.60 + 1.16\times0.110 = 0.73$，与模拟一致。
补救办法是规程的第6步：在一组试次上选检查点，再在一组全新的试次上报告它的成功率。检验：每个检查点用100次试次时标准差会是$0.049$，偏倚约6个百分点——更小，但仍不为零。
:::
:::

## 泛化 {#sec-generalisation}

成功率总是相对于一个初始条件分布定义的（[[#def-trial]]）。一个策略只有当这个分布与它在使用中将要遇到的情形相符时才有用，所以评测要沿着一个个有名字的**泛化轴**来探，每个轴相对训练只改变一样东西：

| 轴 | 变化示例 |
|---|---|
| 位置 | 物体放在示范区域之外、被旋转过 |
| 物体个体 | 同一类别的另一只杯子；一个新 SKU |
| 干扰物 | 额外的物体、杂乱、外观相近的物体 |
| 视觉场景 | 光照、桌面、背景、相机位姿偏移几厘米 |
| 语言 | 换过说法的指令、已知物体与动词的新组合、新概念 |
| 任务 | 微调数据中没有的任务 |
| 具身形态 | 不同的夹爪、机械臂或控制频率 |
| 物理 | 更重、更滑或可变形的物体 |

沿每个轴分别报告成功率显示的是策略学到了*什么*；一个汇总的数字做不到这一点。VLA 论文常区分**视觉**、**物理**与**语义**泛化——最后者正是网络数据预训练的主要承诺（[[vision-language-action/vla-architectures]]）。

::: quiz
一个策略在训练所用的五个物体上95%的试次成功，在同类别的五个新物体上是45%。一位同事报告“70%的成功率”。这份报告错在哪里？
- [ ] 没有错；70%是正确的平均值。
- [x] 汇总的数字描述的两种情形都不是；两个成功率应分开报告，因为它们回答的是不同的问题（分布内表现与物体泛化）。
- [ ] 新物体的试次不在训练数据里，应当丢弃。
::: solution
这个平均值取决于评测中新旧物体50/50的任意配比。只用新物体的顾客看到的将是约45%。要按轴报告结果，并附上各自的区间。
:::
:::

## 仿真基准 {#sec-sim}

真实世界评测缓慢、昂贵，且难以在各实验室之间复现。仿真基准给出快速、可重复的比较：

- **Meta-World**（2019）：MuJoCo 里50个用仿真 Sawyer 臂的操作任务，主要用于多任务与元强化学习。
- **RLBench**（2020）：约100个仿真 Franka 臂的任务，示范由运动规划生成。
- **robomimic**（2021）：任务与质量参差的人类示范，为研究离线模仿学习而设计。
- **CALVIN**（2022）：桌面场景里以语言为条件的长时程任务，配 Franka 臂；按策略能连续完成一条指令链中的多少条指令来打分。
- **LIBERO**（2023）：130个以语言为条件的任务，分成分别隔离空间布局、物体、目标与长时程变化的套件，附人类示范；被广泛用于评测 VLA 微调。到2025年，其主要套件上报告的最高成功率已超过95%，因此它不再能很好地区分强方法。
- **SIMPLER**（2024）：两个被广泛使用的真实数据集背后的真实装置（Google 的移动操作机器人与 WidowX/Bridge 装置）的仿真复制品，为评测在*真实*数据上训练的策略而建，相机视角与视觉外观都相匹配；其作者测量了仿真结果相对于真实评测给策略排名的能力。
- **ManiSkill**（第2、3版，2023–24）及其他基准提供 GPU 并行的仿真，任务与机器人众多。

::: remark 基准是干什么用的
基准度量的是在*它自己的*任务上的进展。LIBERO 上的高分说明一个方法能在那个仿真器里从几十条示范中学好；并不能说明它会抓你的零件。把基准用来调试训练代码、在受控条件下比较各方法；要决定交付什么，用你自己的评测。
:::

### 仿真到真机的差距

在仿真里能用的策略常常在硬件上失败，仿真中的策略排名与真机上的排名也未必一致。差距有几个来源：

- **视觉**：渲染与相机图像在纹理、光照、反光、噪声与运动模糊上不同；
- **物理**：接触、摩擦以及可变形或铰接物体的行为都是近似，而且常常是为数值稳定而非为保真调过参的；
- **感知与时间**：真实相机有延迟与抖动，真实关节编码器有噪声，真实控制器有跟踪误差与滞后；
- **具身形态细节**：线缆、柔顺性、减速器回差、夹爪垫磨损。

补救办法包括**域随机化**（domain randomisation，在随机化的纹理、光照、质量与摩擦上训练，使现实看起来只是又一个样本）、精细的**系统辨识**、照片级渲染或真实场景的重建，以及——就评测而言——在信任仿真器之前，先在少数几个策略上验证它给出的排名与真实试次一致，正如 SIMPLER 的作者们所做的那样。

::: history
机器人学习长期缺少共同的标尺：每篇论文都在自己的机器人和任务上报告成功率，社区对此反复讨论。操作任务的仿真基准追随游戏强化学习的基准而来：Meta-World（2019）、RLBench（2020）、robomimic（2021）、CALVIN（2022）与 LIBERO（2023）。至于真实机器人评测，共享硬件的挑战赛（Amazon Picking Challenge，2015–17）以及后来的共享平台与规程（如2024年的 DROID 装置）使跨实验室比较成为可能，SIMPLER（2024）则试图让仿真评测对真实世界的结果有预测力。统计工具更老：Wilson 区间出自1927年，McNemar 检验出自1947年。
:::

::: summary
- 事先定义试次、初始条件与成功判据；除了成功，还要记录进度、用时、干预、安全事件与失败类别。
- 成功计数服从二项分布；用 Wilson 区间，它留在$[0,1]$之内、小$n$时表现良好。20次试次大约能分辨$\pm15$–$20$个百分点。
- 在配平的初始条件上比较策略；McNemar 检验只用不一致对，比不配对的检验更灵敏。区间重叠不是检验。
- 用 [[#eq-samplesize]] 规划试次数；检出60%对80%大约需要每个策略80次不配对的试次。
- 随机化顺序、对评测者设盲、录制视频、在另一组条件上选检查点（胜者诅咒），并按泛化轴分别报告。
- 仿真基准（LIBERO、SIMPLER、CALVIN……）用于受控比较与调试；仿真到真机的差距使你自己硬件上的评测具有决定意义。
:::

## 习题

::: exercise 一个成功率 {#exr-rate level=1 check="0.65"}
一个策略在40次试次中成功26次。估计的成功率是多少？（填入一个分数。）
::: solution
$26/40 = 0.65$。
:::
:::

::: exercise Wilson 区间的中心 {#exr-centre level=1 check="0.5"}
20次试次中成功10次的 Wilson 区间，其中心是什么？（填入数值。）
::: solution
$\hat p = 0.5$，且对任何$c$都有 $(0.5 + c/2)/(1+c) = 0.5$：区间关于二分之一对称。
:::
:::

::: exercise 三法则 {#exr-three level=1 check="0.03"}
一个抓取策略在100次试次中没有失败。用三法则给出其失败率的一个近似95%上界。（填入一个分数。）
::: solution
$3/100 = 0.03$：失败率高达约3%都与“100次试次零失败”相容。
:::
:::

::: exercise 45/50的 Wilson 区间 {#exr-wilson level=2 check="0.786"}
求50次试次中成功45次的95% Wilson 区间的下端。（保留三位小数。）
::: solution
$\hat p = 0.9$，$c = 3.8416/50 = 0.07683$。中心 $(0.9 + 0.03842)/1.07683 = 0.8715$。半宽 $\frac{1.96}{1.07683}\sqrt{0.09/50 + 3.8416/10\,000} = 1.8202\sqrt{0.0018 + 0.000384} = 1.8202\times0.04673 = 0.0851$。下端 $0.8715 - 0.0851 = 0.786$；上端 $0.957$。
:::
:::

::: exercise 手算 McNemar {#exr-mcnemar level=2 check="0.012"}
一次配对评测中，11个条件不一致：10个有利于新策略，1个有利于旧策略。求双侧精确 McNemar$p$值。（保留两位有效数字。）
::: solution
对$X\sim\Bin(11, \tfrac12)$，$\Prob(X\le1) = (1 + 11)/2^{11} = 12/2048 = 0.00586$；双侧$p$值为 $0.0117\approx0.012$。仅凭11个有信息量的条件，就能在5%水平下判定新策略更好。
:::
:::

::: exercise 更小改进所需的试次数 {#exr-n level=2 check="199"}
用 [[#eq-samplesize]]，取5%显著性与80%功效，要检出从80%到90%的改进，每个策略需要多少次不配对的试次？（填入数字，向上取整。）
::: solution
$\bar p = 0.85$。分子 $1.960\sqrt{2\times0.85\times0.15} + 0.842\sqrt{0.16 + 0.09} = 1.960\times0.5050 + 0.842\times0.5 = 0.9898 + 0.4210 = 1.4108$；平方 $1.9903$；除以 $0.01$ 得 $199.0$，即每个策略199次试次——比 [[#ex-samplesize]] 中60比80的比较多出一倍以上，因为这里的差异只有一半大（数量按 $1/\Delta^2$ 缩放），而85%附近的方差略小一些。
:::
:::

::: exercise 一套有偏的规程 {#exr-bias level=3}
一个团队上午评测新策略（20次试次）、下午评测旧策略（20次试次）；摆物体并判定成败的是同一个人，而他正是新策略的开发者。列出偏倚的来源，并重新设计评测。
::: solution
偏倚：时刻效应（透过窗户的光线、机器人温度、操作员疲劳）与策略混杂；评测者未设盲，可能在下意识里对新策略把物体摆得更有利、或把临界的结果判得更宽；初始条件不固定，于是两组的难度可能不同；各20次试次功效很低。重新设计：固定一份比如40–60个初始条件的清单，用模板摆放；每个条件在两个策略下按随机顺序运行，全天交错；由脚本选择策略并隐去其身份；由第二个人（或回看录像）对照书面判据判定成败；用 McNemar 检验配 Wilson 区间做分析；视频存档。
:::
:::

::: exercise 一份产品的评测计划 {#exr-plan level=3}
你公司将交付一个由 VLA 驱动的料箱拣选（bin-picking）单元，面向300个 SKU。设计决定能否交付的评测：指标、初始条件、泛化轴、试次数、仿真的角色，以及验收标准。
::: solution
指标：每次尝试的抓取成功率、每小时抓取数、长时间运行下的平均干预间隔时间、损坏率与掉落率、安全上限触发次数。初始条件：按成文随机流程装满的料箱，按 SKU 组分层（小的、反光的、可变形的、重的）。轴：训练见过的 SKU 与留出的 SKU；光照；料箱装满程度；干扰物；包装变化。试次：多到满足验收标准——例如，要证明抓取成功率高于95%且 Wilson 下界高于0.93，每个层需要数百次抓取（$\hat p = 0.97$、$n = 300$ 时 Wilson 下界为0.944）；长达数个班的长时间运行测试用来考察干预率。仿真：在硬件试跑之前对每个新检查点做回归测试，并在验证过仿真对少数几个策略的排名与真实单元一致之后，用它对罕见条件做压力测试。验收：按层的事先登记的置信下界门槛、没有未解决的安全事件，以及在配平的料箱上与现有（程序化）方案的比较。
:::
:::
