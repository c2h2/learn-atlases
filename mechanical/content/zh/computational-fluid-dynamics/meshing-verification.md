CFD 结果是由一连串选择产生的一个数：控制方程与模型、几何形状及其简化、网格、边界条件、离散格式、迭代收敛。每一环都可能引入误差，而链条末端那幅色彩缤纷的云图，无论误差是$1\,\%$还是$100\,\%$，看起来都同样令人信服。这最后一课讨论最直接地受分析者控制的环节——**网格**和**边界条件**——以及**验证与确认**（V&V）这门学问，它把 CFD 结果变成附有不确定度的工程陈述。

这里的工具并不是研究人员可有可无的附加品。设计规范和监管机构越来越多地要求提供有文档记录的网格收敛研究；ASME V&V 20 标准规定了如何比较模拟与实验；而工业中 CFD 结果出错的最常见原因是：在关键部位网格太粗、边界条件放置或选择不当，以及在模型经过确认的范围之外使用模型。这些思想建立在前面全部内容之上：[[computational-fluid-dynamics/finite-differences]]中的截断误差和精度阶、[[computational-fluid-dynamics/linear-solvers]]中的迭代收敛，以及[[computational-fluid-dynamics/turbulence-modelling]]中的近壁网格要求。

## 网格

网格是把流动区域划分为单元的一种分割。它的两大类各有所长。

- **结构网格**的单元按规则的$i, j, k$下标模式排列，因此通过算术运算就能找到相邻单元。在复杂几何周围不可能只用单个块，于是把区域划分为**多块**结构区域，在翼型、叶片和圆柱周围常采用 H 型、C 型或 O 型拓扑。结构网格每个单元的精度高，单元与流动方向对齐，求解器效率高；但对复杂形状生成起来很费力。
- **非结构网格**的单元具有任意的连接关系：四面体、六面体、三棱柱、四棱锥或一般多面体，相邻关系列表被显式存储。四面体网格生成基本上是自动的（Delaunay 三角剖分和阵面推进法），因此复杂几何的网格只需几小时而不是几周就能生成。在壁面附近，从表面拉伸出若干层**棱柱**（或六面体）单元来解析边界层；由四面体合并而成的**多面体**网格每个单元有更多的相邻单元，对单元畸变不那么敏感。**切割单元**网格和**重叠**（Chimera）网格是处理运动物体和极复杂形状的另外两种选择。

无论哪种类型，[[computational-fluid-dynamics/finite-differences#def-truncation]]中的局部截断误差不仅取决于单元尺寸，还取决于单元形状以及尺寸在相邻单元之间如何变化。

::: definition 网格质量指标 {#def-mesh-quality}
- **长宽比**：单元最长尺寸与最短尺寸之比。大的长宽比（$10^2$–$10^3$）在以壁面法向梯度为主的边界层中无害，但在流动没有优势方向的区域中有害。
- **增长率（膨胀比）**：相邻单元尺寸之比。尺寸的突变即使在名义上二阶的格式中也会引入一阶误差项；应使其保持在约$1.2$–$1.3$以下。
- **非正交性**：面法向$\mathbf{n}_f$与连接共享该面的两个单元中心的连线$\mathbf{d}_{PN}$之间的夹角。它会降低用于扩散通量的两点梯度的精度（[[computational-fluid-dynamics/finite-volume-diffusion]]）；超过约$10^\circ$–$20^\circ$就需要修正，超过约$70^\circ$时大多数程序都难以应付。
- **偏斜度**：衡量单元偏离理想（等边或正方形）形状的程度，或者面中心偏离$\mathbf{d}_{PN}$与该面交点的程度。它会降低面插值的精度；应避免高度偏斜的单元（等角偏斜度大于约$0.9$）。
:::

### 近壁层与拉伸

边界层需要在壁面法向上有细小的单元，但只在那里需要。标准的手段是**几何拉伸**：第一层单元高度为$h_1$（由[[computational-fluid-dynamics/turbulence-modelling#alg-wall-mesh]]中的$y^+$估计确定），其后每一层按常数比$q$增大。

::: proposition 几何拉伸层的厚度 {#prop-stretching}
若第一层单元高度为$h_1$，且每一层比其下一层厚$q > 1$倍，则$n$层的总厚度和最后一层的高度为
$$
T_n = h_1\frac{q^n - 1}{q - 1},\qquad h_n = h_1q^{n-1},
$$ {#eq-stretching}
达到厚度$T$所需的层数为$n = \left\lceil\ln\!\left(1 + T(q-1)/h_1\right)/\ln q\right\rceil$。
:::

::: proof
各层高度$h_1, h_1q, \dots, h_1q^{n-1}$构成等比数列，其和为$h_1(1 + q + \dots + q^{n-1}) = h_1(q^n - 1)/(q - 1)$。令$T_n \ge T$并求解，得$q^n \ge 1 + T(q - 1)/h_1$；取对数（$\ln q > 0$）即得所述界限，再向上取整为整数层数。
:::

::: example 壁面解析边界层的棱柱层 {#ex-prism-layers}
某壁面解析 SST 计算在一个边界层厚$5.0\ \mathrm{mm}$的表面上需要高度为$h_1 = 10\ \mu\mathrm{m}$的第一层单元。取增长率$q = 1.2$，需要多少层棱柱层才能覆盖边界层？最后一层有多大？
::: solution
$n \ge \ln(1 + 5.0\times10^{-3} \times 0.2/10^{-5})/\ln 1.2 = \ln 101/\ln 1.2 = 4.615/0.1823 = 25.3$，所以需要$26$层，总厚度为$10^{-5}(1.2^{26} - 1)/0.2 = 5.67\ \mathrm{mm}$。最后一层为$h_{26} = 10^{-5} \times 1.2^{25} = 0.95\ \mathrm{mm}$。合理性检验：最外层棱柱层应与相邻的核心网格单元尺寸相近（这里约为$1\ \mathrm{mm}$），使交界处的增长率保持在$q$附近；如果核心单元是$5\ \mathrm{mm}$，从$0.95$到$5\ \mathrm{mm}$的跳跃就是糟糕的过渡，需要更多的层或更大的$q$。
:::
:::

## 边界条件

CFD 计算域的边界有两类：物理表面（壁面）和穿过流体的人为截断面（进口、出口、远场、对称面）。它们的条件必须与方程的数学类型相容（[[computational-fluid-dynamics/governing-equations]]）：每个边界上给定数目恰当的量，并在信息进入的地方给定。

| 边界 | 典型的给定量 | 注意事项 |
|---|---|---|
| **速度入口** | 速度矢量（已知时给剖面）、温度、湍流量 | 均匀剖面需要一段发展长度；对可压缩流动它固定了质量流量，可能造成过定 |
| **质量流量入口或总压入口** | 质量流量，或总压和流动方向；总温 | 总压适用于来自稳压腔的亚声速可压缩进口 |
| **压强出口** | 静压（其他变量从内部外推） | 放在流动近乎均匀且正在流出的地方；经出口的回流会使问题不适定 |
| **壁面** | 无滑移（$\mathbf{u} = \mathbf{u}_{\text{wall}}$）；温度、热流密度或对流条件；粗糙度 | 近壁网格必须与壁面处理相匹配 |
| **对称面** | 法向速度为零，其他一切量的法向梯度为零 | 只有当流动（而不仅是几何）对称时才可用；有涡脱落的尾迹不对称 |
| **周期性** | 一个面上的值等于与之匹配的面上的值（必要时带旋转或压强跳跃） | 用于重复的几何：叶栅、换热器通道 |
| **远场** | 自由流条件，最好采用特征（无反射）处理 | 对椭圆型的亚声速流动必须放得很远（翼型为几十倍弦长） |

两条规则可以防止大多数问题。第一，把人为边界放在你**知道**流动行为的地方——障碍物的远上游，以及任何尾迹都已有空间发展的下游（常见的准则是钝体下游至少$5$–$10$个特征长度，要求尾迹准确时更远）——并通过移动边界来检查：如果移动出口后结果改变，说明出口太近了。第二，绝不给定多于物理所允许的信息：在不可压缩进口同时给定速度和压强，或在亚声速可压缩出口固定速度，都会使问题过定，产生反射或不收敛。

::: warning 终止于回流区的计算域
如果出口边界切过分离区，流体就会经由它重新进入计算域。程序于是必须在该边界上为温度、湍流量和组分编造入流值——通常是它的"回流"设置，而这些设置没有人仔细选过——收敛后的结果就依赖于它们。关于出口处反向流动的警告并非无关紧要：应延长计算域，直到出口处的流动处处流出，或者把出口移到流动已知的地方。
:::

## 验证与确认

在信任一个 CFD 预测之前，必须回答两个不同的问题。Roache 把它们概括为"把方程解对"和"解对的方程"。

::: definition 验证与确认 {#def-vv}
- **验证**询问所选模型的方程是否被正确而准确地求解。它包括两部分：**代码验证**，检查软件是否无误地实现了预定的离散并达到其理论精度阶；以及**解的验证**，估计某一具体计算的数值误差（离散误差、迭代误差和舍入误差）。
- **确认**询问模型——方程、湍流模型、边界条件、物性——对预定用途而言是否足够准确地代表了真实的物理系统。它通过与实验数据比较来进行，并在给定的不确定度范围内量化**模型误差**。

验证是数学活动；确认是物理活动。验证必须在先：拿一个未收敛或分辨率不足的解与实验比较，对模型说明不了任何问题。
:::

### 代码验证：人造解

最干净的代码验证测试是**人造解方法**（制造解方法，MMS）。不去寻找具有已知精确解的问题，而是**选定**一个光滑的解，把它代入控制方程，并加上使之成为精确解所需的任何源项。

::: algorithm 人造解方法 {#alg-mms}
1. 选择一个光滑的解析场$\phi_m(\mathbf{x}, t)$，使它能检验方程的每一项（所涉及的各阶导数均不为零，在所有方向上都非平凡）。
2. 对它施加连续算子：$S_m = \mathcal{L}(\phi_m)$，其中方程为$\mathcal{L}(\phi) = 0$。于是$\phi_m$精确地满足$\mathcal{L}(\phi) = S_m$。
3. 加上额外源项$S_m$、取$\phi_m$给出的边界条件，在一系列系统加密的网格上运行程序。
4. 在每套网格上计算误差范数$\lVert\phi_h - \phi_m\rVert$，并由相继的网格计算观测精度阶；它必须趋近格式的形式精度阶。
:::

::: example 对流–扩散方程的人造源项 {#ex-mms}
对于定常一维对流–扩散方程$\dfrac{\mathrm{d}(\rho u\phi)}{\mathrm{d}x} - \dfrac{\mathrm{d}}{\mathrm{d}x}\!\left(\Gamma\dfrac{\mathrm{d}\phi}{\mathrm{d}x}\right) = S$，其中$\rho u = 1.0\ \mathrm{kg\,m^{-2}\,s^{-1}}$和$\Gamma = 0.10\ \mathrm{kg\,m^{-1}\,s^{-1}}$为常数，区间为$0 \le x \le 1\ \mathrm{m}$，构造人造解$\phi_m = \sin(\pi x)$。求源项及其在$x = 0.25\ \mathrm{m}$处的值，并给出边界条件。
::: solution
$\mathrm{d}\phi_m/\mathrm{d}x = \pi\cos(\pi x)$，$\mathrm{d}^2\phi_m/\mathrm{d}x^2 = -\pi^2\sin(\pi x)$，所以
$$
S_m = \rho u\,\pi\cos(\pi x) + \Gamma\pi^2\sin(\pi x) = \pi\cos(\pi x) + 0.1\pi^2\sin(\pi x).
$$
在$x = 0.25$处：$S_m = \pi(0.7071) + 0.9870(0.7071) = 2.221 + 0.698 = 2.919$（单位为$\mathrm{kg\,m^{-3}\,s^{-1}}$乘以$\phi$的单位）。边界条件：$\phi(0) = \phi(1) = 0$。二阶程序在$20$、$40$和$80$个单元上运行时，误差每加密一次必须以趋近$4$的倍数下降。合理性检验：算子的两项都受到了检验（对流通过余弦，扩散通过正弦），所以其中任何一项有错都会表现为错误的精度阶。
:::
:::

### 解的验证：网格收敛

对于实际问题，精确解是未知的，但它在加密下的**行为**是已知的：对于$p$阶格式，在渐近范围内任何量$f$的离散误差近似为$Ch^p$，其中$h$是代表性单元尺寸。在系统加密的网格上得到的三个结果就足以估计$p$、外推值和误差。

::: proposition 观测精度阶与理查森外推 {#prop-richardson}
设$f_1$、$f_2$、$f_3$是某个量在细、中、粗网格上的值，单元尺寸为$h_1 < h_2 = rh_1 < h_3 = r^2h_1$（常数加密比$r > 1$），并假定$f_i = f_0 + Ch_i^p$严格成立。那么
$$
p = \frac{\ln\!\left[(f_3 - f_2)/(f_2 - f_1)\right]}{\ln r},\qquad
f_0 = f_1 + \frac{f_1 - f_2}{r^p - 1}.
$$ {#eq-richardson}
:::

::: proof
相减得$f_2 - f_1 = Ch_1^p(r^p - 1)$和$f_3 - f_2 = Ch_1^p r^p(r^p - 1)$。两者之比为$r^p$，由此得到$p$。由第一个差得$Ch_1^p = (f_2 - f_1)/(r^p - 1)$，而$f_0 = f_1 - Ch_1^p$给出外推值。假设$f_i = f_0 + Ch_i^p$只是近似成立，而且只在$h$小到首项误差占主导时成立——即**渐近范围**。该方法要求这些差同号（**单调收敛**）；振荡收敛使对数无定义，表明网格不在渐近范围内。
:::

理查森外推能估计误差，但外推值本身不如其推导所显示的那样可靠，因为由带噪声的数据估计出的$p$可能与形式精度阶相去甚远。Roache 的**网格收敛指数**（GCI）把这一估计转换为一个保守的不确定度区间。

::: definition 网格收敛指数 {#def-gci}
记两套最细网格之间的相对变化为$\varepsilon_{12} = (f_2 - f_1)/f_1$，细网格 GCI 为
$$
\mathrm{GCI}_{12} = \frac{F_s\,\lvert\varepsilon_{12}\rvert}{r^p - 1},
$$ {#eq-gci}
其中$F_s$是**安全因数**：当$p$由三套或更多网格观测得到时取$1.25$，当只有两套网格并假定形式精度阶时取$3$。GCI 是对$f_1$的相对离散不确定度的估计，置信度约为$95\,\%$。若$\mathrm{GCI}_{23}/(r^p\,\mathrm{GCI}_{12}) \approx 1$，则网格处于渐近范围内。
:::

对于无法严格地通过对分单元来加密的非结构网格，用代表性单元尺寸$h = (V/N)^{1/3}$（三维情形，总体积为$V$，单元数为$N$）定义有效加密比$r = (N_1/N_2)^{1/3}$。Roache 建议$r \ge 1.3$，使网格之间的差值超过迭代噪声和舍入噪声。

::: example 阻力系数的三网格研究 {#ex-gci}
在每个方向上以$r = 1.5$加密的三套网格（约$4.0\times10^{6}$、$1.19\times10^{6}$和$3.5\times10^{5}$个单元）上计算阻力系数：$C_{D,1} = 0.3120$（细），$C_{D,2} = 0.3165$，$C_{D,3} = 0.3266$（粗）。迭代误差可以忽略。求观测精度阶、外推值、细网格 GCI，并检查渐近范围。（这些数值仅作示例。）
::: solution
差值为$f_3 - f_2 = 0.0101$和$f_2 - f_1 = 0.0045$，都为正：单调收敛。
$$
p = \frac{\ln(0.0101/0.0045)}{\ln 1.5} = \frac{0.8085}{0.4055} = 1.99,\qquad r^p = 2.244,
$$
接近形式上的二阶。外推值：$C_{D,0} = 0.3120 + (0.3120 - 0.3165)/(2.244 - 1) = 0.3120 - 0.0036 = 0.3084$。由$\lvert\varepsilon_{12}\rvert = 0.0045/0.3120 = 0.0144$，
$$
\mathrm{GCI}_{12} = \frac{1.25 \times 0.0144}{1.244} = 0.0145 = 1.45\,\%,
$$
即离散带来的结果为$C_D = 0.3120 \pm 0.0045$。同理，$\lvert\varepsilon_{23}\rvert = 0.0101/0.3165 = 0.0319$，$\mathrm{GCI}_{23} = 3.21\,\%$；比值$\mathrm{GCI}_{23}/(r^p\,\mathrm{GCI}_{12}) = 0.0321/(2.244 \times 0.0145) = 0.99$，所以网格处于渐近范围内。合理性检验：细网格误差估计（$0.0036$）略小于 GCI 区间（$0.0045$），这正是安全因数的用意；并且细网格结果位于外推值与较粗网格结果之间。
:::
:::

### 迭代误差及其他数值误差

离散误差并不是唯一的数值误差。在网格研究有意义之前，必须使**迭代误差**远小于离散误差——要像[[computational-fluid-dynamics/linear-solvers#prop-error-estimate]]中那样监测所关心的量本身，而不只是残差。对于非定常问题，**时间步长误差**用与网格误差相同的方法、通过系统地减小$\Delta t$来估计；周期性或统计平稳的量必须在足够长的时间内平均，以使**采样误差**很小。在双精度下舍入误差通常可以忽略，但在单精度下或单元尺寸差别极大时可能有影响。

## 确认

确认把经过验证的模拟与实验数据进行比较，同时考虑两者的不确定度。ASME V&V 20 标准对标量的这种比较作了规范化。

::: proposition ASME V&V 20 的确认比较 {#prop-vv20}
设$S$为模拟结果，$D$为实验值，$T$为（未知的）真值。定义**比较误差**$E = S - D$。写出$S = T + \delta_{\text{model}} + \delta_{\text{num}} + \delta_{\text{input}}$和$D = T + \delta_D$，
$$
E = \delta_{\text{model}} + \delta_{\text{num}} + \delta_{\text{input}} - \delta_D ,
$$
所以模型误差满足$\delta_{\text{model}} = E - (\delta_{\text{num}} + \delta_{\text{input}} - \delta_D)$。若三个误差来源相互独立，标准不确定度分别为$u_{\text{num}}$、$u_{\text{input}}$和$u_D$，则**确认不确定度**为
$$
u_{\text{val}} = \sqrt{u_{\text{num}}^2 + u_{\text{input}}^2 + u_D^2},
$$ {#eq-uval}
而$\delta_{\text{model}}$位于区间$E \pm k\,u_{\text{val}}$内，包含因子$k$按所需的置信度选取。
:::

::: proof
$E$的表达式由相减得出：$T$被消去。相互独立的随机误差之和的不确定度，等于它们标准不确定度的方和根（系数为$\pm1$的线性组合的不确定度传播律），由此得到[[#eq-uval]]。$\delta_D$的符号对方差没有影响。独立性是一个假设：例如，如果同一个实测进口剖面既进入$S$又进入$D$，误差就是相关的，必须加上协方差项。
:::

解释是直接的。若$\lvert E\rvert \gg u_{\text{val}}$，则模型误差近似为$E$，对于这一用途模型需要改进（或加以修正）。若$\lvert E\rvert \lesssim u_{\text{val}}$，则模型误差处于确认工作的"噪声"之内——除非通过更好的实验、更确切已知的输入或更细的网格来减小$u_{\text{val}}$，否则无法做得更好。确认总是针对具体用途的：一个对附着管流压降经过确认的模型，并不因此就对分离扩压器中的传热也得到了确认。

::: example 确认一个压降预测 {#ex-validation}
某阀门的 CFD 模型预测压降$S = 1250\ \mathrm{Pa}$；试验给出$D = 1200\ \mathrm{Pa}$，标准不确定度$u_D = 30\ \mathrm{Pa}$。网格研究给出$u_{\text{num}} = 20\ \mathrm{Pa}$，进口流量和粗糙度的不确定度经模型传播给出$u_{\text{input}} = 25\ \mathrm{Pa}$。关于模型误差可以得出什么结论？
::: solution
$E = 1250 - 1200 = 50\ \mathrm{Pa}$，$u_{\text{val}} = \sqrt{20^2 + 25^2 + 30^2} = \sqrt{1925} = 43.9\ \mathrm{Pa}$。取$k = 2$（约$95\,\%$包含概率），$\delta_{\text{model}} \in 50 \pm 88\ \mathrm{Pa}$，即在$-38$与$+138\ \mathrm{Pa}$之间。比较误差约为一个确认不确定度：没有明确的模型误差证据，但模型可能偏差多达压降的约$11\,\%$。要使结论更严格，必须首先减小最大的贡献项（$u_D$，即实验）。合理性检验：相对不确定度（实验$2.5\,\%$，数值$1.6\,\%$）是细致工作的典型值；没有这样的不确定度预算而声称"吻合在$1\,\%$以内"是没有意义的。
:::
:::

::: algorithm 工程 CFD 研究的最低限度 V&V 流程 {#alg-vv-workflow}
1. **定义**所关心的量，以及它们所支持的决策所需的精度。
2. **代码验证：**对所用的模型，使用有文档记录的验证（MMS 或精确解测试）的程序；对自编程序，运行 MMS。
3. **迭代收敛：**一直迭代到所关心的量的变化远小于目标精度。
4. **网格（和时间步长）收敛：**三套系统加密的网格，观测精度阶，理查森估计，GCI；检查渐近范围；报告$u_{\text{num}}$。
5. **输入不确定度：**改变不确定的输入（进口条件、物性、粗糙度、几何公差）并加以传播。
6. **确认：**与相同或非常相似构型的实验比较；计算$E$和$u_{\text{val}}$。
7. **报告**结果及其不确定度，以及确认所适用的条件范围。
:::

::: quiz
在三套网格（$r = 2$）上，算得的表面传热系数依次为$152$、$148$和$151\ \mathrm{W\,m^{-2}\,K^{-1}}$（由细到粗）。你应当得出什么结论？
- [ ] 观测精度阶为$\ln(3/4)/\ln 2$，理查森外推给出精确值。
- [x] 收敛是振荡的：网格不在渐近范围内（或者迭代误差太大），所以不能应用理查森外推和 GCI；应进一步加密并检查迭代收敛。
- [ ] 细网格值已经收敛，因为三个值相差不到$3\,\%$。
- [ ] 模型已经得到确认。
::: solution
$f_3 - f_2 = 151 - 148 = +3$，而$f_2 - f_1 = 148 - 152 = -4$：差值变号，所以[[#eq-richardson]]中的比值为负，其对数无定义。网格之间的差值小，若是振荡的，并不能作为收敛的证据。确认是另一个问题，需要实验数据。
:::
:::

::: history
理查森（Lewis Fry Richardson）于 1911 年提出可以把两套网格上的结果组合起来以消去首项误差，并于 1927 年与冈特（J. Arthur Gaunt）把这一思想发展为"向极限的延迟逼近"（《皇家学会哲学汇刊 A 辑》（*Philosophical Transactions of the Royal Society A*））。用于贴体结构网格的椭圆型网格生成方法由汤普森（Joe F. Thompson）、泰姆斯（Frank C. Thames）和马斯廷（C. Wayne Mastin）于 1974 年提出（《计算物理杂志》（*Journal of Computational Physics*））。罗奇（Patrick Roache）于 1994 年提出了网格收敛指数（《观点：统一报告网格加密研究的一种方法》（"Perspective: a method for uniform reporting of grid refinement studies"），《流体工程杂志》（*Journal of Fluids Engineering*）），他 1998 年的著作阐述了这里所用的验证框架；人造解方法由罗奇和斯坦伯格（Stanly Steinberg）于 1984 年倡导。AIAA《计算流体动力学模拟的验证与确认指南》（*Guide for the Verification and Validation of Computational Fluid Dynamics Simulations*，G-077）于 1998 年问世，ASME《计算流体动力学与传热的验证与确认标准》（*Standard for Verification and Validation in Computational Fluid Dynamics and Heat Transfer*，V&V 20）于 2009 年问世；《流体工程杂志》于 2008 年发表了切利克（I. B. Celik）及其合作者提出的、被广泛采用的离散不确定度逐步估计程序。
:::

::: summary
- 结构网格每个单元的精度和效率高；非结构网格能为复杂几何自动生成；棱柱层用于解析壁面。
- 注意长宽比（在边界层中无妨）、增长率（$\lesssim 1.2$）、非正交性和偏斜度。
- $n$层单元的拉伸层厚度为$h_1(q^n - 1)/(q - 1)$；最外层应与核心网格相匹配。
- 边界条件必须与方程类型相匹配：只给定进入的信息，把人为边界放在流动已知的地方，避免出口回流。
- 验证（把方程解对）先于确认（解对的方程）；MMS 验证代码，网格研究验证解。
- 三套网格给出观测精度阶$p = \ln[(f_3 - f_2)/(f_2 - f_1)]/\ln r$、理查森估计和 GCI$= F_s\lvert\varepsilon_{12}\rvert/(r^p - 1)$；振荡收敛意味着尚未到达渐近范围。
- 确认把$E = S - D$与$u_{\text{val}} = \sqrt{u_{\text{num}}^2 + u_{\text{input}}^2 + u_D^2}$相比较；模型误差位于$E \pm k\,u_{\text{val}}$内，并且只针对经过确认的用途。
:::

## 习题

::: exercise 观测精度阶 {level=1 check="1.585"}
三套$r = 2$的网格给出$f_1 = 1.000$、$f_2 = 1.004$和$f_3 = 1.016$（由细到粗）。计算观测精度阶。（输入$p$，保留三位小数。）
::: solution
$p = \ln[(1.016 - 1.004)/(1.004 - 1.000)]/\ln 2 = \ln 3/\ln 2 = 1.585$。当名义上二阶的格式在局部切换为一阶时（限制器、壁面函数、网格不规则），观测精度阶常为介于$1$和$2$之间的非整数。
:::
:::

::: exercise 理查森外推 {level=1 check="0.9827"}
二阶格式（$p = 2$）在细网格上给出$f_1 = 0.9800$，在粗一倍的网格上给出$f_2 = 0.9720$。估计精确值。（输入该值，保留四位小数。）
::: solution
$f_0 = f_1 + (f_1 - f_2)/(r^p - 1) = 0.9800 + 0.0080/3 = 0.98267$，即$0.9827$。
:::
:::

::: exercise 两网格 GCI {level=1 check="0.34"}
对上一题的数据，取$p = 2$和$F_s = 1.25$计算细网格 GCI，再用两网格安全因数$F_s = 3$计算。（输入$F_s = 1.25$时的 GCI，以百分数表示，保留两位小数。）
::: solution
$\lvert\varepsilon_{12}\rvert = 0.0080/0.9800 = 0.00816$；$\mathrm{GCI} = 1.25 \times 0.00816/(4 - 1) = 0.00340 = 0.34\,\%$。用两网格安全因数$F_s = 3$时为$0.82\,\%$——这是不知道观测精度阶的代价。
:::
:::

::: exercise 棱柱层的层数 {level=2 check="31"}
第一层单元为$20\ \mu\mathrm{m}$、增长率为$1.15$，必须覆盖$10\ \mathrm{mm}$的边界层。需要多少层？（输入整数层数。）
::: solution
$n \ge \ln(1 + 0.010 \times 0.15/2\times10^{-5})/\ln 1.15 = \ln 76/\ln 1.15 = 4.331/0.1398 = 30.99$，所以需要$31$层。最后一层为$2\times10^{-5} \times 1.15^{30} = 1.3\ \mathrm{mm}$。
:::
:::

::: exercise 有效加密比 {level=2 check="1.494"}
同一区域的两套非结构三维网格分别有$1.0\times10^{6}$和$3.0\times10^{5}$个单元。计算有效加密比。（输入$r$，保留三位小数。）
::: solution
$r = (N_1/N_2)^{1/3} = (10/3)^{1/3} = 1.494$，高于 Roache 建议的最小值$1.3$。
:::
:::

::: exercise 非正交性 {level=2 check="11.31"}
在二维网格中，共享一个面的两个单元中心之间的矢量为$\mathbf{d} = (1.0, 0.20)$（以单元尺寸为单位），面法向为$\mathbf{n} = (1, 0)$。计算非正交角。（输入该角，单位为度，保留两位小数。）
::: solution
$\cos\alpha = \mathbf{d}\cdot\mathbf{n}/\lvert\mathbf{d}\rvert = 1.0/\sqrt{1.04} = 0.9806$，所以$\alpha = 11.31^\circ$（等价地为$\arctan 0.2$）。属于中等程度：建议对扩散通量作非正交修正。
:::
:::

::: exercise 确认不确定度 {level=2 check="43.87"}
对$u_{\text{num}} = 20\ \mathrm{Pa}$、$u_{\text{input}} = 25\ \mathrm{Pa}$和$u_D = 30\ \mathrm{Pa}$，计算$u_{\text{val}}$。（输入$u_{\text{val}}$，单位为 Pa，保留两位小数。）
::: solution
$u_{\text{val}} = \sqrt{400 + 625 + 900} = \sqrt{1925} = 43.87\ \mathrm{Pa}$。注意最大的分量占主导：仅把$u_{\text{num}}$减半，只能把$u_{\text{val}}$降到$40.31\ \mathrm{Pa}$。
:::

::: exercise 二维人造解 {level=3}
对于$\rho$和$\nu$为常数的定常二维不可压缩动量方程和连续性方程，提出一个严格满足连续性方程的人造速度场，并在人造压强为$p_m = \cos x\cos y$（取$\rho = 1$）时推导$x$方向动量方程所需的源项。解释为什么人造速度应严格满足连续性方程。
::: solution
取一个流函数，例如$\psi = \sin x\sin y$，得$u = \partial\psi/\partial y = \sin x\cos y$和$v = -\partial\psi/\partial x = -\cos x\sin y$，按构造即为无散的。$x$方向动量源项为$S_x = u\,\partial_xu + v\,\partial_yu + \partial_xp - \nu\nabla^2u$。这里$\partial_xu = \cos x\cos y$，$\partial_yu = -\sin x\sin y$，所以$u\partial_xu + v\partial_yu = \sin x\cos x\cos^2y + \cos x\sin x\sin^2y = \sin x\cos x$；$\partial_xp = -\sin x\cos y$；$\nabla^2u = -2\sin x\cos y$。因此$S_x = \sin x\cos x - \sin x\cos y + 2\nu\sin x\cos y$。如果人造速度不满足连续性方程，连续性方程就需要一个质量源项；许多基于压强的程序无法接受质量源项，而且压强–速度耦合算法将在实际中从不会遇到的条件下受到检验。
:::

::: exercise 为设计决策规划 V&V {level=3}
一项 CFD 研究必须判定：重新设计的换热器进口集管能否把$40$根管子之间的流量分配不均减小到足以满足"任何一根管子的流量都不超过平均流量的$110\,\%$"这一要求。规划验证与确认：监测哪些量、用多少套网格以及加密到什么程度、如何处理湍流模型的不确定度、你会寻求哪些实验数据，以及你将如何表述结论。
::: solution
一个好的方案：所关心的量是最大管流量比（以及完整的分布）。迭代收敛到它的变化小于$0.1\,\%$。至少使用三套$r \ge 1.3$的网格（一致地加密集管、管子入口和壁面层），对最大流量比和若干根单独的管子计算$p$、外推比值和 GCI；检查渐近范围。用第二种湍流模型（例如$k$–$\varepsilon$和 SST）以及改变进口剖面重复计算，以评估模型形式不确定度；传播进口流量和几何公差。为了确认，寻求现有集管（或缩比试验台）上逐根管子的流量测量数据，确认基准设计，并计算$E$和$u_{\text{val}}$。把结论表述为，例如，"最大管流量为$106\,\% \pm 2\,\%$（数值），由基准设计的确认得出的模型误差界为$\pm 3\,\%$；满足要求且留有余量"，并注明确认只适用于所试验的雷诺数范围。
:::
