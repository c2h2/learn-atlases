计算机无法存储一个函数，只能存储一串数。把微分方程变成计算机可以求解的问题，最简单的方法是只在网格点上保留未知量，并把每个导数替换为相邻网格值的某种组合——即**有限差分**。这是 CFD 中最古老的离散方法，即使形式上属于“有限体积”或“有限元”的程序，内部也在使用差分公式：用于面上的梯度、时间导数和边界通量。更重要的是，有限差分是最容易学习数值分析语言的地方：截断误差、精度阶、显式与隐式时间推进、修正波数。所有这些在以后每一课中都会用到。

本课由泰勒级数构造差分公式，度量其误差，并用它们离散[[computational-fluid-dynamics/governing-equations]]中引入的 CFD 两个模型方程——热（扩散）方程和线性对流方程。这些离散是否**稳定**，是下一课[[computational-fluid-dynamics/stability-accuracy]]的主题。其背后的数值分析见数学图谱（[数值积分与数值微分](/learn/maths/lesson.php?c=numerical-analysis&l=numerical-integration)和[常微分方程数值解](/learn/maths/lesson.php?c=numerical-analysis&l=numerical-odes)）。

## 网格与记号

在区间$0 \le x \le L$上布置均匀网格，**步长（网格间距）**为$h = \Delta x = L/N$，节点为$x_i = i\,\Delta x$，$i = 0, 1, \dots, N$；时间上采用步长$\Delta t$，时间层为$t^n = n\,\Delta t$。精确解在节点处的值为$\phi(x_i, t^n)$；数值格式在该处算出的值记为$\phi_i^n$。二者是不同的数，整个数值分析所关心的就是它们之差的大小。在二维情形中增加第二个下标：$(x_i, y_j)$处为$\phi_{i,j}$。

心中要有这样一幅图景：一条光滑曲线$\phi(x)$在等距点上采样，在相邻采样点之间搭一把直尺。直尺的斜率近似于曲线的斜率；近似得好坏取决于曲线在距离$h$上弯曲的程度。

## 由泰勒级数得到差分公式

在$x_i$处展开$\phi$，假设它具有所需阶数的连续导数：
$$
\phi_{i\pm1} = \phi_i \pm h\,\phi'_i + \frac{h^2}{2}\phi''_i \pm \frac{h^3}{6}\phi'''_i + \frac{h^4}{24}\phi^{(4)}_i \pm \cdots
$$ {#eq-taylor}
本课中的每个差分公式都来自这一展开式若干份的相加和相减。

::: definition 截断误差与精度阶 {#def-truncation}
设$D_h\phi$是某点处导数$D\phi$的差分近似，由间距为$h$的网格值构成。其**截断误差**为$\tau = D_h\phi - D\phi$，对**精确的**光滑函数$\phi$计算。若$\tau = C h^p + O(h^{p+1})$，其中$C \ne 0$与$h$无关，则该近似为**$p$阶**的；$C h^p$称为**误差主项**。
:::

阶数$p$告诉你加密网格时误差如何缩放：$h$减半，误差除以$2^p$（一阶为 2 倍，二阶为 4 倍，四阶为 16 倍）。它不说明$C$的大小，$C$取决于解的高阶导数；如果解不光滑，在粗网格上二阶公式可能不如一阶公式精确。

::: proposition 基本差分公式 {#prop-basic-fd}
对于足够光滑的$\phi$，
$$
\begin{aligned}
\text{向前差分：}\quad & \frac{\phi_{i+1} - \phi_i}{h} = \phi'_i + \frac{h}{2}\phi''_i + O(h^2),\\
\text{向后差分：}\quad & \frac{\phi_i - \phi_{i-1}}{h} = \phi'_i - \frac{h}{2}\phi''_i + O(h^2),\\
\text{中心差分：}\quad & \frac{\phi_{i+1} - \phi_{i-1}}{2h} = \phi'_i + \frac{h^2}{6}\phi'''_i + O(h^4),\\
\text{二阶导数的中心差分：}\quad & \frac{\phi_{i+1} - 2\phi_i + \phi_{i-1}}{h^2} = \phi''_i + \frac{h^2}{12}\phi^{(4)}_i + O(h^4).
\end{aligned}
$$ {#eq-basic-fd}
单侧公式是一阶的；两个中心公式是二阶的。
:::

::: proof
取[[#eq-taylor]]中的上方符号，减去$\phi_i$再除以$h$：$(\phi_{i+1} - \phi_i)/h = \phi'_i + \tfrac{h}{2}\phi''_i + \tfrac{h^2}{6}\phi'''_i + \cdots$。向后公式只需将$h \to -h$。把[[#eq-taylor]]的两个展开式相减，所有偶次幂相消：$\phi_{i+1} - \phi_{i-1} = 2h\phi'_i + \tfrac{h^3}{3}\phi'''_i + O(h^5)$；再除以$2h$。把它们相加，所有奇次幂相消：$\phi_{i+1} + \phi_{i-1} = 2\phi_i + h^2\phi''_i + \tfrac{h^4}{12}\phi^{(4)}_i + O(h^6)$；减去$2\phi_i$再除以$h^2$。每种情形中，误差都是若干项之和，其系数是$\phi$在$x_i$处的导数——当$\phi$光滑时它们有界——因此误差的阶如上所述。这些相消是对称性的结果：中心模板没有偏好方向，因此在一个偶的量中奇次误差项不可能保留下来，反之亦然。
:::

::: example 测量精度阶 {#ex-order}
对$\phi = \sin x$（精确值$\cos 1 = 0.540302$），分别取$h = 0.1$和$h = 0.05$，用向前公式和中心公式近似$\phi'(1)$。将误差与[[#eq-basic-fd]]中的主项比较，并计算观测精度阶。
::: solution
| $h$ | 向前差分 | 误差 | 中心差分 | 误差 |
|---|---|---|---|---|
| $0.1$ | $0.497364$ | $-4.294\times10^{-2}$ | $0.539402$ | $-9.001\times10^{-4}$ |
| $0.05$ | $0.519045$ | $-2.126\times10^{-2}$ | $0.540077$ | $-2.251\times10^{-4}$ |

$h = 0.1$时预测的误差主项为$\tfrac{h}{2}\phi'' = -0.05\sin 1 = -4.207\times10^{-2}$（向前）和$\tfrac{h^2}{6}\phi''' = -\tfrac{0.01}{6}\cos 1 = -9.005\times10^{-4}$（中心）：与实际误差非常接近。观测精度阶为
$$
p = \frac{\ln(e_{0.1}/e_{0.05})}{\ln 2}:\qquad
p_{\text{向前}} = \frac{\ln(4.294/2.126)}{\ln 2} = 1.01,\qquad
p_{\text{中心}} = \frac{\ln(9.001/2.251)}{\ln 2} = 2.00 .
$$
合理性检查：$h = 0.1$时中心公式的精度约为向前公式的五十倍，**而所用的函数值计算次数同为两次**。对称性带来的是免费的精度。
:::
:::

### 构造任意公式：待定系数法

泰勒级数方法可以推广到任意模板。要由一组点近似某个导数，先写出带未知权重的公式，代入泰勒展开式，再选择权重使尽可能多的低阶项匹配。

::: algorithm 待定系数法 {#alg-undetermined}
要在选定的一组偏移量$k$上求公式$\phi^{(m)}_i \approx h^{-m}\sum_{k} a_k\,\phi_{i+k}$：
1. 展开每个$\phi_{i+k} = \sum_{j\ge 0} (kh)^j\phi^{(j)}_i/j!$。
2. 按幂次合并：$\sum_k a_k\phi_{i+k} = \sum_j \left(\sum_k a_k k^j\right) h^j\phi^{(j)}_i/j!$。
3. 要求对$j = 0, 1, \dots$有$\sum_k a_k k^j = 0$，但$\sum_k a_k k^m = m!$。用$s$个点可以满足$s$个这样的条件（$j = 0, \dots, s-1$）。
4. 解关于$a_k$的线性方程组。第一个使$\sum_k a_k k^j \ne 0$（且$j > m$）的$j$给出误差主项，其阶为$h^{j-m}$。
:::

::: example 用于壁面热流密度的单侧梯度 {#ex-wall-flux}
在壁面（$y = 0$）处只有一侧的点可用。由$\phi_0$、$\phi_1$、$\phi_2$推导$\phi'_0$的二阶公式，并用它求进入水（$k = 0.60\ \mathrm{W\,m^{-1}\,K^{-1}}$）的热流密度：模拟给出壁面处$T_0 = 80.0\,^\circ\mathrm{C}$，$y = 1.0\ \mathrm{mm}$处$T_1 = 72.0\,^\circ\mathrm{C}$，$y = 2.0\ \mathrm{mm}$处$T_2 = 65.0\,^\circ\mathrm{C}$。与一阶公式进行比较。
::: solution
取偏移量$k = 0, 1, 2$，$m = 1$，算法第 3 步给出
$$
a_0 + a_1 + a_2 = 0,\qquad a_1 + 2a_2 = 1,\qquad a_1 + 4a_2 = 0,
$$
故$a_2 = -\tfrac{1}{2}$，$a_1 = 2$，$a_0 = -\tfrac{3}{2}$：
$$
\phi'_0 \approx \frac{-3\phi_0 + 4\phi_1 - \phi_2}{2h}.
$$
第一个不匹配的矩为$\sum_k a_k k^3 = 2 - 4 = -2$，因此误差为$\tfrac{1}{h}\cdot\tfrac{h^3}{6}(-2)\phi''' = -\tfrac{2}{6}h^2\phi''' = -\tfrac{h^2}{3}\phi'''$：二阶。取$h = 1.0\times10^{-3}\ \mathrm{m}$，
$$
\left.\frac{\mathrm{d}T}{\mathrm{d}y}\right|_0 \approx \frac{-3(80.0) + 4(72.0) - 65.0}{2\times10^{-3}} = \frac{-17.0}{2\times10^{-3}} = -8.50\times10^{3}\ \mathrm{K/m},
$$
由壁面进入水的热流密度为$q = -k\,\mathrm{d}T/\mathrm{d}y = 0.60 \times 8.50\times10^{3} = 5.1\times10^{3}\ \mathrm{W/m^2}$。一阶公式给出$(72.0 - 80.0)/10^{-3} = -8.0\times10^{3}\ \mathrm{K/m}$和$q = 4.8\times10^{3}\ \mathrm{W/m^2}$，约低$6\,\%$：它实际上测量的是到第一个节点一半处的斜率，那里的温度剖面已经较平缓。合理性检查：相继每毫米上的温差为$8.0$和$7.0\ \mathrm{K}$，说明剖面在离开壁面后逐渐变平，因此真实的壁面斜率必定比第一条弦更陡，正如二阶公式所示。
:::
:::

用偏移量$-2, \dots, 2$运用同样的方法，得到四阶中心公式
$$
\phi'_i \approx \frac{-\phi_{i+2} + 8\phi_{i+1} - 8\phi_{i-1} + \phi_{i-2}}{12h},\qquad \tau = -\frac{h^4}{30}\phi^{(5)}_i + \cdots
$$ {#eq-fourth-order}
——更宽的模板换来更高的阶，代价是更多的计算量、更复杂的边界处理，以及隐式格式中更大的矩阵带宽。

### 舍入误差：为什么$h$不能任意小

截断误差随$h$减小而减小，但每个网格值在双精度下都以约$\varepsilon_{\text{mach}} \approx 1.1\times10^{-16}$的相对舍入误差存储。在向前差分中，分子$\phi_{i+1} - \phi_i$是两个几乎相等的数之间的小差值，因此其绝对舍入误差$\approx 2\varepsilon_{\text{mach}}|\phi|$被$h$除。总误差的行为类似于
$$
E(h) \approx \frac{h}{2}|\phi''| + \frac{2\varepsilon_{\text{mach}}|\phi|}{h},
$$
当$\phi \sim \phi''$时，它在$h^\ast = 2\sqrt{\varepsilon_{\text{mach}}|\phi|/|\phi''|} \approx 10^{-8}$处取最小值。对于$x = 1$处的$\phi = \sin x$，向前差分的误差在$h = 10^{-4}$时为$4.2\times10^{-5}$，在$h = 10^{-8}$时为$3\times10^{-9}$，然后在$h = 10^{-10}$时**上升**到$6\times10^{-8}$，在$h = 10^{-12}$时达到$4\times10^{-5}$。在 CFD 中，网格间距从来不会接近这一极限，但在单精度程序中、在壁面附近高度拉伸的网格上，以及由很大的绝对压强计算微小压强差时（在不可压缩程序中应使用表压），舍入误差确实重要。

## 修正波数

泰勒级数告诉你误差如何随$h$缩放。另一种互补的观点对对流问题更有用，它考察一个公式对**波**求导的效果如何。任何网格函数都可分解为傅里叶模态，对单个模态$\phi = e^{\mathrm{i}kx}$，精确导数为$\mathrm{i}k\,\phi$。应用中心差分：
$$
\frac{\phi_{i+1} - \phi_{i-1}}{2h} = \frac{e^{\mathrm{i}kh} - e^{-\mathrm{i}kh}}{2h}\,\phi_i = \mathrm{i}\,\frac{\sin(kh)}{h}\,\phi_i .
$$

::: definition 修正波数 {#def-modified-wavenumber}
对于近似$\mathrm{d}/\mathrm{d}x$的差分公式$D_h$，**修正波数**$k'$由$D_h e^{\mathrm{i}kx} = \mathrm{i}k'\,e^{\mathrm{i}kx}$定义。用无量纲波数$\theta = kh \in [0, \pi]$表示（从很长的波$\theta \to 0$，到网格所能承载的最短波，即每个波长两个点，$\theta = \pi$），
$$
\text{二阶中心：} k'h = \sin\theta, \qquad
\text{四阶中心：} k'h = \frac{8\sin\theta - \sin 2\theta}{6}, \qquad
\text{向前：} k'h = -\mathrm{i}\left(e^{\mathrm{i}\theta} - 1\right) = \sin\theta - \mathrm{i}(\cos\theta - 1).
$$
:::

完美的公式应有$k'h = \theta$。中心公式给出的$k'$是**实数**但偏小：短波被当作较长的波来求导，因此在对流问题中它们传播得太慢——这就是**色散误差**。向前公式有虚部，在对流问题中它会改变波的振幅：即**耗散**（若符号相反，则为放大）。这两种效应在泰勒级数的阶数计数中都看不出来，却主导着对陡峭锋面的模拟结果的面貌。

::: example 每个波长的点数 {#ex-ppw}
要使正弦函数一阶导数的精度达到$1\,\%$，二阶中心差分需要每个波长多少个网格点？对四阶公式重复计算。

要求$k'/k = \sin\theta/\theta \ge 0.99$。由于$\sin\theta/\theta \approx 1 - \theta^2/6$，初步估计为$\theta \approx \sqrt{0.06} = 0.245$；数值求解$\sin\theta/\theta = 0.99$得$\theta = 0.2453$。每个波长的点数$= 2\pi/\theta = 25.6$。

对于四阶公式，$(8\sin\theta - \sin2\theta)/(6\theta) = 0.99$给出$\theta = 0.7527$（展开式：$1 - \theta^4/30 = 0.99$给出$\theta \approx 0.74$），因此每个波长需要$2\pi/\theta = 8.3$个点。合理性检查：四阶公式在每个维度上每个波长所需的点数约为三分之一。在三维中，对于波状解达到相同精度，网格点数约少$27$倍。
:::

## 模型方程 1：热方程

考虑一维非稳态导热$\partial T/\partial t = \alpha\,\partial^2T/\partial x^2$，$0 < x < L$，两端温度给定，并给定初始分布。空间用二阶导数的中心差分离散；问题在于时间如何离散。

::: definition 热方程的显式与隐式格式 {#def-heat-schemes}
记**扩散数**为$d = \alpha\Delta t/\Delta x^2$，
- **FTCS**（时间向前、空间中心；显式欧拉）：$T_i^{n+1} = T_i^n + d\left(T_{i+1}^n - 2T_i^n + T_{i-1}^n\right)$；
- **BTCS**（时间向后、空间中心；隐式欧拉）：$-d\,T_{i-1}^{n+1} + (1 + 2d)T_i^{n+1} - d\,T_{i+1}^{n+1} = T_i^n$；
- **克兰克-尼科尔森（Crank–Nicolson）格式**：取上述两种格式右端的平均，
$$
-\tfrac{d}{2}T_{i-1}^{n+1} + (1 + d)T_i^{n+1} - \tfrac{d}{2}T_{i+1}^{n+1} = \tfrac{d}{2}T_{i-1}^{n} + (1 - d)T_i^{n} + \tfrac{d}{2}T_{i+1}^{n}.
$$
:::

FTCS 直接由旧值给出每个新值：计算量小、简单，但——正如下一课将证明的——只有当$d \le \tfrac{1}{2}$时才稳定。BTCS 和克兰克-尼科尔森格式把相邻节点的新值耦合在一起，因此每一步都需要求解一个三对角线性方程组；作为回报，它们对任何$\Delta t$都稳定。

::: proposition 热方程各格式的局部截断误差 {#prop-heat-te}
对于$T_t = \alpha T_{xx}$的光滑解，FTCS 和 BTCS 的截断误差为$O(\Delta t) + O(\Delta x^2)$，克兰克-尼科尔森格式的截断误差为$O(\Delta t^2) + O(\Delta x^2)$。
:::

::: proof
把 FTCS 写成$\left(T_i^{n+1} - T_i^n\right)/\Delta t - \alpha\left(T_{i+1}^n - 2T_i^n + T_{i-1}^n\right)/\Delta x^2 = 0$，并代入精确解。由[[#eq-basic-fd]]，时间差分为$T_t + \tfrac{\Delta t}{2}T_{tt} + O(\Delta t^2)$，空间差分为$T_{xx} + \tfrac{\Delta x^2}{12}T_{xxxx} + O(\Delta x^4)$，二者都在$(x_i, t^n)$处取值。由于$T_t - \alpha T_{xx} = 0$，余量为$\tau = \tfrac{\Delta t}{2}T_{tt} - \tfrac{\alpha\Delta x^2}{12}T_{xxxx} + \cdots$。BTCS 是关于$t^{n+1}$的同样展开，对应项为$-\tfrac{\Delta t}{2}T_{tt}$。对于克兰克-尼科尔森格式，在中点$t^{n+1/2}$处展开：时间差分是中心差分，误差为$\tfrac{\Delta t^2}{24}T_{ttt}$；空间算子在$n$和$n+1$处的平均等于它在$n + \tfrac12$处的值加上$\tfrac{\Delta t^2}{8}\partial_t^2(\alpha T_{xx})$。二者都是$O(\Delta t^2)$。
:::

::: example 显式推进一步和两步 {#ex-ftcs}
一根长$60\ \mathrm{mm}$、$\alpha = 1.0\times10^{-5}\ \mathrm{m^2/s}$的细杆初始温度为$100\,^\circ\mathrm{C}$；$t = 0$时两端骤然降至$0\,^\circ\mathrm{C}$。用 FTCS，取$\Delta x = 10\ \mathrm{mm}$（节点$0$至$6$）和$\Delta t = 2.0\ \mathrm{s}$，计算两个时间步。
::: solution
$d = \alpha\Delta t/\Delta x^2 = 1.0\times10^{-5} \times 2.0/(0.010)^2 = 0.20$。初始时$T = (0, 100, 100, 100, 100, 100, 0)$（两端角点取边界值）。第 1 步：只有紧邻两端的节点感受到非零的二阶差分：$T_1^1 = 100 + 0.2(0 - 200 + 100) = 80$，同样$T_5^1 = 80$；节点$2$–$4$保持$100$。第 2 步：$T_1^2 = 80 + 0.2(0 - 160 + 100) = 68$，$T_2^2 = 100 + 0.2(80 - 200 + 100) = 96$，$T_3^2 = 100$，对称地$T_4^2 = 96$，$T_5^2 = 68$：
$$
T^{2} = (0,\ 68,\ 96,\ 100,\ 96,\ 68,\ 0)\ ^\circ\mathrm{C}\quad\text{在 } t = 4\ \mathrm{s}.
$$
合理性检查：冷却波每步恰好前进一个节点——显式模板无法把信息传得更远——而且每个新值都是旧值的加权平均，权重$d$、$1 - 2d$、$d$都为正，因此任何值都不会超出$[0, 100]$的范围。当$d > \tfrac12$时这种正性就丧失了，这正是稳定性限制的核心。
:::
:::

::: example 隐式推进一步与托马斯算法 {#ex-btcs}
一根长$40\ \mathrm{mm}$的杆（$\Delta x = 10\ \mathrm{mm}$，内部节点$1$–$3$）初始温度为$100\,^\circ\mathrm{C}$，两端保持$0\,^\circ\mathrm{C}$；$\alpha = 1.0\times10^{-5}\ \mathrm{m^2/s}$。取$\Delta t = 10\ \mathrm{s}$，用 BTCS 推进一步。
::: solution
$d = 10^{-5} \times 10/10^{-4} = 1.0$——是 FTCS 限制的两倍。将零端值移到右端后，BTCS 方程为
$$
\begin{pmatrix} 3 & -1 & 0 \\ -1 & 3 & -1 \\ 0 & -1 & 3 \end{pmatrix}
\begin{pmatrix} T_1 \\ T_2 \\ T_3 \end{pmatrix}
= \begin{pmatrix} 100 \\ 100 \\ 100 \end{pmatrix}.
$$
用向前消元和回代求解（即**托马斯算法**，详见[[computational-fluid-dynamics/linear-solvers]]）。第 1 行：$T_1 = 33.33 + T_2/3$。代入第 2 行：$(3 - \tfrac13)T_2 - T_3 = 100 + 33.33$，即$T_2 = 50 + \tfrac38T_3$。代入第 3 行：$(3 - \tfrac38)T_3 = 100 + 50$，故$T_3 = 150/2.625 = 57.14$。回代：$T_2 = 50 + 0.375 \times 57.14 = 71.43$，$T_1 = 33.33 + 71.43/3 = 57.14\,^\circ\mathrm{C}$。

合理性检查：解是对称的，处处低于$100\,^\circ\mathrm{C}$且为正。三个节点在一步之内都发生了变化：隐式格式在一步之内就把信息传遍整个计算域，正如抛物型方程所要求的。若在$d = 1$时用 FTCS，会得到$T_1 = 100 + 1(0 - 200 + 100) = 0$和$T_2 = 100$——已经是一个很差、容易振荡的结果。
:::
:::

## 模型方程 2：线性对流

另一个原型是标量以常速度$a > 0$的纯对流：$\partial\phi/\partial t + a\,\partial\phi/\partial x = 0$，其精确解$\phi(x, t) = \phi_0(x - at)$使初始剖面原样平移。它是最简单的双曲型方程，也是一个毫不留情的检验：任何会抹平、扭曲或错移运动锋面的格式都会立刻暴露。

::: definition 对流方程的两种显式格式 {#def-advection-schemes}
记**库朗数**为$C = a\Delta t/\Delta x$，
- **FTCS**：$\phi_i^{n+1} = \phi_i^n - \tfrac{C}{2}\left(\phi_{i+1}^n - \phi_{i-1}^n\right)$——空间中心差分；
- **FTBS**或**一阶迎风格式**（对$a > 0$）：$\phi_i^{n+1} = \phi_i^n - C\left(\phi_i^n - \phi_{i-1}^n\right)$——空间差分朝**上游**看，即信息所来的方向。
:::

迎风格式可改写为$\phi_i^{n+1} = (1 - C)\phi_i^n + C\phi_{i-1}^n$：当$0 \le C \le 1$时，新值是两个旧值的加权平均，因此不会产生新的极大值或极小值。当$C = 1$时它是精确的——$\phi_i^{n+1} = \phi_{i-1}^n$使剖面每步平移一个单元，与真解完全相同。对流方程的 FTCS 格式看起来更精确（空间二阶），但正如下一课所示，它对任何$\Delta t > 0$都不稳定。

::: example 用迎风格式推进阶跃 {#ex-upwind}
阶跃剖面$i \le 2$时$\phi = 1$、$i \ge 3$时$\phi = 0$，用迎风格式以$C = 0.5$进行对流。计算两步。
::: solution
$\phi_i^{n+1} = 0.5\phi_i^n + 0.5\phi_{i-1}^n$。从$i = 0, \dots, 5$的$(1, 1, 1, 0, 0, 0)$出发（入流值$\phi_0 = 1$保持不变）：
$$
\phi^1 = (1,\ 1,\ 1,\ 0.5,\ 0,\ 0),\qquad \phi^2 = (1,\ 1,\ 1,\ 0.75,\ 0.25,\ 0).
$$
两步后的精确解使阶跃移动了$2C\Delta x = 1$个单元，因此为$(1, 1, 1, 1, 0, 0)$。迎风解的平均位置正确（$\phi = 0.5$的穿越点位于节点 3 和 4 之间，$x \approx 3.5\Delta x$处，正是精确阶跃现在所在的位置），但锋面被抹平了，而且抹平程度随每一步增长。这就是**数值扩散**；下一课将表明，迎风格式的行为相当于精确方程加上一个人工扩散系数$\tfrac12 a\Delta x(1 - C)$。合理性检查：各值保持在$0$和$1$之间，总量$\sum\phi_i$每步恰好增加$C = 0.5$，即经左边界流入的量——该格式是守恒的。
:::
:::

::: warning 不要逆风差分
对于对流问题，单侧差分的方向不是个人偏好的问题。当$a > 0$时，向前差分$\phi_i^{n+1} = \phi_i^n - C(\phi_{i+1}^n - \phi_i^n)$（“顺风”）从流体**将要去**的地方获取信息。它是无条件不稳定的：把它写成$\phi_i^{n+1} = (1 + C)\phi_i^n - C\phi_{i+1}^n$，其中有一个负权重，误差每步最多增长$1 + 2C$倍。程序根据当地速度（或面上质量流量）的符号，逐个单元地选择迎风侧；把方向写死在代码中是一个经典错误，它只在流动反向时——在回流区中——才会暴露出来。
:::

### 显式时间推进与刚性

空间离散之后，偏微分方程变成关于时间的一个大型常微分方程组$\mathrm{d}\boldsymbol{\phi}/\mathrm{d}t = \mathbf{A}\boldsymbol{\phi} + \mathbf{b}$——这就是**直线法**。此后可以使用任何常微分方程积分方法。对于热方程，$\mathbf{A}$的特征值从约$-\alpha\pi^2/L^2$（缓慢、光滑的模态）到约$-4\alpha/\Delta x^2$（快速的锯齿模态）。显式欧拉法只有在对每个特征值都满足$|1 + \lambda\Delta t| \le 1$时才稳定，由此得$\Delta t \le 2/(4\alpha/\Delta x^2) = \Delta x^2/(2\alpha)$，又是 FTCS 的限制。最快速率与最慢速率之比按$(L/\Delta x)^2$增长：方程组是**刚性的**，显式方法几乎把所有步数都花在分辨一个早已衰减殆尽的锯齿模态上。

::: widget odesolver
f: -20*y
y0: 1
t: 0, 1
exact: exp(-20*t)
h: 0.12
methods: euler; heun; rk4
caption: 单个刚性模态$y' = \lambda y$，$\lambda = -20\ \mathrm{s^{-1}}$，类似于细密导热网格上的锯齿模态。取$h = 0.12$时，$|1 + \lambda h| = 1.4 > 1$，显式欧拉法以不断增大的振幅振荡，尽管精确解早已衰减为零。把$h$减小到$2/20 = 0.1$以下，欧拉法变得稳定；小于$0.05$时不再振荡。高阶显式方法的稳定区域稍大，但性质相同。隐式方法（如 BTCS）没有这样的限制。
:::

::: quiz
对热方程使用 FTCS 时，为提高精度把网格间距减半，同时使扩散数$d$保持在其稳定的最大值。在一维情形下，达到固定的终止时刻所需的计算时间增长为原来的多少倍？
- [ ] $2$
- [ ] $4$
- [x] $8$
- [ ] $16$
::: solution
$\Delta x$减半使节点数加倍。保持$d = \alpha\Delta t/\Delta x^2$不变，迫使$\Delta t$减小为原来的$1/4$，因此需要四倍的步数。工作量$\propto$节点数$\times$步数$= 2 \times 4 = 8$。在三维中这一倍数为$2^3 \times 4 = 32$——这是扩散占优的问题首选隐式方法的主要原因。
:::
:::

::: application 这些公式在实际程序中的位置
通用有限体积程序对每个扩散项使用（通量形式的）二阶中心差分，对对流项使用迎风偏置差分，在后处理中用[[#ex-wall-flux]]那样的单侧公式计算壁面热流密度和切应力，在时间上使用隐式欧拉法或二阶向后公式$\left(3\phi^{n+1} - 4\phi^n + \phi^{n-1}\right)/(2\Delta t)$。商用程序设置中的“二阶精度”标签，指的正是这些泰勒级数意义下的阶。
:::

::: history
刘易斯·弗赖伊·理查森（Lewis Fry Richardson）1911 年关于砌石坝应力的论文（《英国皇家学会哲学汇刊 A 辑》（*Philosophical Transactions of the Royal Society A*），第 210 卷）通常被视为系统地用有限差分求解偏微分方程的开端；该文还提出了组合两套网格上的结果以消去误差主项的想法，即今天所说的理查森外推（[[computational-fluid-dynamics/meshing-verification]]）。约翰·克兰克（John Crank）和菲莉丝·尼科尔森（Phyllis Nicolson）于 1947 年在研究有内热源的导热问题时发表了以他们命名的格式（《剑桥哲学学会会刊》（*Proceedings of the Cambridge Philosophical Society*）），并指出了显式方法在大时间步长下的不稳定性。[[#ex-btcs]]中的三对角消元法以卢埃林·H·托马斯（Llewellyn H. Thomas）命名，称为托马斯算法，他在 1949 年哥伦比亚大学沃森科学计算实验室的一份报告中描述了这一方法。
:::

::: summary
- 有限差分用网格值的加权和代替导数；权重来自泰勒级数[[#eq-taylor]]或待定系数法。
- 向前和向后差分是一阶的；一阶和二阶导数的中心差分是二阶的，见[[#eq-basic-fd]]；$h$减半使$p$阶误差除以$2^p$。
- $(-3\phi_0 + 4\phi_1 - \phi_2)/(2h)$之类的单侧公式在边界上保持二阶精度。
- 舍入误差设定了一个下限，低于它时减小$h$反而使导数更差。
- 修正波数显示了色散（中心格式：短波传播太慢）和耗散（单侧格式）；锯齿波$(-1)^i$对中心一阶差分是不可见的。
- 对于热方程，FTCS 是显式的，受限于$d \le \tfrac12$；BTCS 和克兰克-尼科尔森格式是隐式的，每步需要一次三对角求解，没有这一限制。
- 对于对流方程，迎风差分有界，在$C = 1$时精确，但有扩散性；FTCS 和顺风差分是不稳定的。
:::

## 习题

::: exercise 中心差分 {level=1 check="1.00167"}
取$h = 0.1$，用中心差分近似$e^x$在$x = 0$处的导数，并将误差与主项$\tfrac{h^2}{6}\phi'''$比较。（输入近似值，保留五位小数。）
::: solution
$(e^{0.1} - e^{-0.1})/0.2 = \sinh(0.1)/0.1 = 1.001668$。精确值为$1$，故误差为$1.668\times10^{-3}$；主项为$0.01/6 \times 1 = 1.667\times10^{-3}$。下一项$h^4/120$解释了剩余的$10^{-6}$。
:::
:::

::: exercise 三次函数的向前差分 {level=1 check="0.31"}
对$\phi = x^3$，取$h = 0.1$，计算向前差分求$\phi'(1)$的误差，并与主项$\tfrac{h}{2}\phi''$比较。（输入误差。）
::: solution
$(1.1^3 - 1)/0.1 = 0.331/0.1 = 3.31$；精确导数为$3$，故误差为$0.31$。主项为$0.05 \times 6 = 0.30$；余下的$\tfrac{h^2}{6}\phi''' = 0.01 \times 6/6 = 0.01$恰好补足总和，因为三次函数的泰勒级数在三阶导数之后终止。
:::
:::

::: exercise 四次函数的二阶导数 {level=1 check="12.02"}
取$h = 0.1$，在$x = 1$处对$\phi = x^4$应用二阶导数的中心差分。（输入近似值。）
::: solution
$(1.1^4 - 2 + 0.9^4)/0.01 = (1.4641 - 2 + 0.6561)/0.01 = 12.02$。精确值为$12$；误差$0.02$恰好等于$\tfrac{h^2}{12}\phi^{(4)} = \tfrac{0.01}{12} \times 24 = 0.02$，因为$x^4$的更高阶导数全为零。
:::
:::

::: exercise 由两套网格求观测精度阶 {level=2 check="3"}
某程序计算一个导数，在间距为$h$的网格上误差为$3.2\times10^{-3}$，在间距为$h/2$的网格上误差为$4.0\times10^{-4}$。观测精度阶是多少？推测它可能使用了哪类公式。（输入阶数$p$。）
::: solution
$p = \ln(3.2\times10^{-3}/4.0\times10^{-4})/\ln 2 = \ln 8/\ln 2 = 3$。奇数阶是四点模板上迎风偏置公式的典型特征，例如三阶迎风偏置公式$(2\phi_{i+1} + 3\phi_i - 6\phi_{i-1} + \phi_{i-2})/(6h)$：中心对称的四点模板会消去奇次误差项，给出偶数阶。
:::
:::

::: exercise 显式时间步长限制 {level=2 check="0.1667"}
用 FTCS 模拟一块钢板（$\alpha = 1.2\times10^{-5}\ \mathrm{m^2/s}$），取$\Delta x = 2.0\ \mathrm{mm}$。利用条件$d \le \tfrac12$，求允许的最大时间步长，以及模拟一分钟所需的步数。（以秒为单位输入$\Delta t$，保留四位小数。）
::: solution
$\Delta t \le \Delta x^2/(2\alpha) = (2.0\times10^{-3})^2/(2 \times 1.2\times10^{-5}) = 4.0\times10^{-6}/2.4\times10^{-5} = 0.1667\ \mathrm{s}$，因此一分钟需要$360$步。若$\Delta x$减半，则需要四倍的步数。
:::
:::

::: exercise 手算一个隐式步 {level=2 check="66.67"}
一根有两个内部节点的杆，两端为$0\,^\circ\mathrm{C}$，两个内部节点初始均为$100\,^\circ\mathrm{C}$，以$d = 0.5$用 BTCS 推进一步。求内部节点的新温度。（以$^\circ\mathrm{C}$为单位输入，保留两位小数。）
::: solution
方程为$2T_1 - 0.5T_2 = 100$和$-0.5T_1 + 2T_2 = 100$。由对称性$T_1 = T_2 = T$，$1.5T = 100$，故$T = 66.67\,^\circ\mathrm{C}$。以$d = 0.5$用 FTCS 会得到$100 + 0.5(0 - 200 + 100) = 50\,^\circ\mathrm{C}$。这两个一阶格式把半离散方程的精确解$100\,e^{-0.5} = 60.65\,^\circ\mathrm{C}$夹在中间（这个两节点系统的对称模态以速率$\alpha/\Delta x^2$衰减，而$d = 0.5$意味着$\alpha\Delta t/\Delta x^2 = 0.5$）。
:::
:::

::: exercise 波的分辨率 {level=2 check="25.6"}
某对流格式对$\partial\phi/\partial x$使用二阶中心差分。利用修正波数，求使正弦波相速度误差在精确值$1\,\%$以内所需的每个波长的点数。（输入每个波长的点数，保留一位小数。）
::: solution
在半离散对流中，数值相速度为$a\,k'/k = a\sin\theta/\theta$。令$\sin\theta/\theta = 0.99$得$\theta = 0.2453$，因此每个波长需要$2\pi/\theta = 25.6$个点，与[[#ex-ppw]]相同。
:::
:::

::: exercise 二阶导数的边界公式 {level=3}
用待定系数法求阶数尽可能高的四点单侧公式$\phi''_0 \approx (a_0\phi_0 + a_1\phi_1 + a_2\phi_2 + a_3\phi_3)/h^2$，并给出其误差主项。为什么程序在实践中可能更愿意采用较低阶的边界公式？
::: solution
条件为：$j = 0, 1, 3$时$\sum a_k k^j = 0$，且$\sum a_k k^2 = 2$：
$$
a_0 + a_1 + a_2 + a_3 = 0,\quad a_1 + 2a_2 + 3a_3 = 0,\quad a_1 + 4a_2 + 9a_3 = 2,\quad a_1 + 8a_2 + 27a_3 = 0 .
$$
解为$a_0 = 2$，$a_1 = -5$，$a_2 = 4$，$a_3 = -1$：$\phi''_0 \approx (2\phi_0 - 5\phi_1 + 4\phi_2 - \phi_3)/h^2$。于是$\sum a_k k^4 = -5 + 64 - 81 = -22$，误差为$\tfrac{-22}{24}h^2\phi^{(4)} = -\tfrac{11}{12}h^2\phi^{(4)}$：二阶，其常数是中心公式的十一倍。宽的单侧模板误差常数大，可能降低隐式格式的稳定性（它们在三对角带之外增加元素，并引入符号混杂的系数），还会放大噪声；较低阶但紧凑的边界处理往往是更好的工程选择，而且对扩散问题而言，它不会降低二阶格式的整体精度阶。
:::
:::

::: exercise 为设计研究选择格式 {level=3}
你需要计算一块厚$20\ \mathrm{mm}$、一面受热的铝壁（$\alpha = 9.7\times10^{-5}\ \mathrm{m^2/s}$）中$10$分钟内的瞬态温度，为分辨一个很薄的表面层取$\Delta x = 0.5\ \mathrm{mm}$。比较 FTCS 和$\Delta t = 0.5\ \mathrm{s}$的克兰克-尼科尔森格式的计算代价，讨论精度，并推荐一种格式。在什么情况下你仍会选择 FTCS？
::: solution
FTCS：$\Delta t \le \Delta x^2/(2\alpha) = (5\times10^{-4})^2/(1.94\times10^{-4}) = 1.29\times10^{-3}\ \mathrm{s}$，因此$600\ \mathrm{s}$在$41$个节点上需要约$4.7\times10^{5}$步——每步都很简单，总计约$2\times10^7$次节点更新。$\Delta t = 0.5\ \mathrm{s}$的克兰克-尼科尔森格式需要$1200$步，每步是一次三对角求解，每个节点约$8$次运算：大约$4\times10^{5}$次运算，便宜约五十倍。精度方面：$d = 9.7\times10^{-5} \times 0.5/(5\times10^{-4})^2 = 194$，克兰克-尼科尔森格式稳定，但它对最短波的放大因子接近$-1$，因此陡峭的初始特征（表面突然受热）会产生缓慢衰减的网格尺度振荡；先用几步 BTCS 启动，或采用较小的第一个时间步，即可消除这一问题。单用 BTCS 在时间上只有一阶精度，要达到相同精度需要更小的步长。在以下情况中 FTCS 仍有吸引力：物理过程本身就需要极小的时间步（快速瞬变、与其他显式求解器显式耦合），在线性求解代价高昂的大规模并行硬件上，或网格非常粗时。推荐：采用克兰克-尼科尔森格式（或二阶向后差分），并以短暂的隐式步启动。
:::
