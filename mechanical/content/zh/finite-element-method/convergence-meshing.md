有限元程序总会返回一个答案。答案是否可靠，取决于程序无法替你做出的决定：用什么单元、用多少、放在哪里。前几章展示了各种症状——[[finite-element-method/weak-forms]]中只在单元中点处精确的应力，[[finite-element-method/plane-elements]]中弯曲时刚了三倍的四边形单元，[[finite-element-method/isoparametric-elements]]中积分点太少引起的虚假模式。本章把它们整理为一套可用的精度理论。我们定义如何度量误差，叙述并证明随着网格加密误差下降有多快，说明如何由一系列网格**测量**收敛速度并外推到收敛的答案，指出通常的收敛速度失效的两种情形——闭锁与奇异性——最后介绍应力回收、误差估计与自适应网格划分等实用工具。目标是养成一种把分析与“涂色”区分开来的习惯：不给出任何证据说明一个有限元数值离数学模型的答案有多近，就绝不报告它。

## 误差从何而来

把误差分为四类是有益的，因为它们的补救方法不同。

1. **建模误差**：数学模型与物理对象不同——理想化的支承、钢材屈服处却用线性材料、用板模型代替厚零件、遗漏了接触。网格加密对它毫无作用。它通过与试验对比的**确认**来评估，将在[[finite-element-method/nonlinear-analysis]]中讨论。
2. **离散误差**：数学模型的精确解与有限元解之差，由用有限个形函数表示场所引起。本章讨论的就是它。
3. **积分误差与几何误差**：来自畸变单元的数值积分，以及用单元边近似曲边边界。如果单元表述是合理的，它们通常随离散误差一起收敛。
4. **舍入误差**：来自有限精度算术。在双精度下它可以忽略，除非刚度矩阵的条件数很差（刚度差异巨大、罚数、近奇异模型）。

::: definition 误差度量 {#def-error}
设$u$是数学模型的精确解，$u_h$是特征单元尺寸为$h$的网格上的有限元解。误差$e = u - u_h$用以下方式度量：
- **能量范数**$\|e\|_E = \left(\int_V \boldsymbol{\varepsilon}(e)^{\mathsf T}\mathbf{D}\,\boldsymbol{\varepsilon}(e)\,dV\right)^{1/2}$，即误差场应变能两倍的平方根——这是应力与应变的自然度量；
- **$L^2$范数**$\|e\|_{L^2} = \left(\int_V e^2\,dV\right)^{1/2}$，位移的一种平均度量；
- 关心的量的**逐点误差**，例如端部挠度或圆角处的峰值应力。

**相对**能量范数误差为$\eta = \|e\|_E/\|u\|_E$。若当$h \to 0$时误差趋于零，则称方法**收敛**；若在某一范数下误差的行为像$Ch^p$，则称它在该范数下以**速度**$p$收敛。
:::

## 收敛的条件

在问一个方法收敛多快之前，我们必须知道它是否收敛。对基于位移的单元，经典的充分条件是：

- **完备性**：单元能表示每一种刚体运动和每一种常应变状态（这样当单元缩小、每个单元上的应变趋于常数时，就能逼近真实的场）。对等参单元，这已在[[finite-element-method/isoparametric-elements]]中证明。
- **协调性（相容性）**：位移在单元之间连续（对梁和板，斜率也连续），使有限元场是弱形式的容许试探函数。
- **稳定性**：单元刚度没有虚假零能模式，且随着网格加密，组装矩阵保持良好的条件数。

协调性可以放宽——确实存在成功的非协调单元与非协调模式单元——但此时收敛不再是自动的，必须用艾恩斯（Bruce Irons）设计的一种数值实验来检验：分片试验。

::: algorithm 分片试验 {#alg-patch}
1. 建立一个小的单元**片**，其中至少有一个节点完全位于内部，并故意采用畸变的单元形状（不用矩形）。
2. 选取一个关于坐标为线性的位移场$u = a_0 + a_1x + a_2y$，$v = b_0 + b_1x + b_2y$，它对应一个常应变状态。
3. 在单元片的所有**边界**节点上给定这个场；不施加其他载荷。（在第二种版本中，只给定足以阻止刚体运动的约束，并把常应力状态的边界面力作为一致节点载荷施加。）
4. 求解内部节点。
5. 若内部位移等于该线性场，且每个单元在每个积分点上都显示精确的常应变和常应力（精确到舍入误差），则**通过**。任何偏差，无论多小，都是**不通过**。
:::

通过分片试验且稳定的单元，会随着网格加密而收敛。不通过的单元可能在规则网格上给出看似可信的结果，却在不规则网格上收敛到错误的答案。

::: example Q4单元的分片试验 {#ex-patch}
四个Q4单元填满正方形$0 \le x, y \le 20\,\mathrm{mm}$；内部节点从中心$(10, 10)$移到$(13, 8)\,\mathrm{mm}$，使四个单元都发生畸变。平面应力，$E = 200\,\mathrm{GPa}$，$\nu = 0.3$。八个边界节点被赋予场$u = 10^{-3}x + 0.5\times10^{-3}y$、$v = 0.5\times10^{-3}x + 0.2\times10^{-3}y$（单位mm）的位移。进行该试验。
::: solution
该场的应变为常数$\varepsilon_x = 1.0\times10^{-3}$，$\varepsilon_y = 0.2\times10^{-3}$，$\gamma_{xy} = 0.5\times10^{-3} + 0.5\times10^{-3} = 1.0\times10^{-3}$，用平面应力$\mathbf{D}$得精确应力为
$$
\sigma_x = 219\,780(1.0 + 0.3 \times 0.2)\times10^{-3} = 232.97\,\mathrm{MPa}, \quad \sigma_y = 219\,780(0.3 + 0.2)\times10^{-3} = 109.89\,\mathrm{MPa}, \quad \tau_{xy} = 76.92\,\mathrm{MPa}.
$$
组装四个用$2 \times 2$积分的单元矩阵并求解两个内部自由度，得$u = 0.01700\,\mathrm{mm}$，$v = 0.00810\,\mathrm{mm}$；在$(13, 8)$处计算该场得$u = 0.013 + 0.004 = 0.0170$与$v = 0.0065 + 0.0016 = 0.0081\,\mathrm{mm}$——完全相同。全部十六个高斯点上的应力在打印精度内都等于$(232.97, 109.89, 76.92)\,\mathrm{MPa}$。

**结论。**等参Q4单元通过了试验，正如[[finite-element-method/isoparametric-elements]]所保证的。该试验代价很小，是对任何新单元或新程序首先要做的事情：它能发现$\mathbf{B}$、雅可比矩阵、数值积分和组装中的错误。
:::
:::

## 收敛速度

伽辽金法给出能量范数下的最佳逼近（见[[finite-element-method/weak-forms]]），所以有限元解的误差不大于有限元空间中**任何**函数的误差——特别是精确解的插值函数的误差。因此估计插值误差就估计了有限元误差。在一维中，论证很简短。

::: theorem 一维线性单元的能量误差 {#thm-rate}
对于$EA$为常数的杆问题$-(EAu')' = b$，用最大长度为$h$的线性单元求解，若$u''$平方可积，则
$$
\|u - u_h\|_E \le \frac{h}{\pi}\sqrt{EA}\,\|u''\|_{L^2}.
$$
能量范数误差，从而应力误差，是$O(h)$的。
:::

::: proof
由最佳逼近定理，$\|u - u_h\|_E \le \|u - \mathcal{I}u\|_E$，其中$\mathcal{I}u$是$u$在节点处的分片线性插值。在长为$h_i$的一个单元$[x_i, x_{i+1}]$上，插值误差$e = u - \mathcal{I}u$在两端为零，所以其导数$e'$在单元上的平均值为零。维尔丁格（Wirtinger）不等式指出，在长为$h_i$的区间上平均值为零的函数$g$满足$\int g^2 \le (h_i/\pi)^2\int(g')^2$。把它应用于$g = e'$，并注意$e'' = u''$（因为$\mathcal{I}u$是线性的），
$$
\int_{x_i}^{x_{i+1}}(e')^2\,dx \le \frac{h_i^2}{\pi^2}\int_{x_i}^{x_{i+1}}(u'')^2\,dx.
$$
对各单元求和，乘以$EA$，并利用$h_i \le h$，得$\|e\|_E^2 \le (h/\pi)^2EA\,\|u''\|^2_{L^2}$。假设：精确积分，$EA$为常数，$u''$平方可积（解“足够光滑”）。
:::

用多项式插值理论代替维尔丁格不等式，同样的推理给出一般的先验估计（Strang与Fix，1973年）：对于包含$p$次完全多项式的单元以及足够光滑的解，
$$
\|u - u_h\|_E \le C\,h^{p}, \qquad \|u - u_h\|_{L^2} \le C'\,h^{p+1},
$$ {#eq-apriori}
其中常数依赖于解的导数和单元形状（对严重畸变的单元会增大），但不依赖于$h$。线性单元（$p = 1$：CST、Q4、4节点四面体）给出的应力按$h$收敛、位移按$h^2$收敛；二次单元（$p = 2$：T6、Q8、10节点四面体）给出$h^2$与$h^3$。特殊点处的逐点值常常收敛得更快（**超收敛**：我们看到，线性杆单元在节点处是精确的，而在均布载荷下其应力在单元中点处是精确的）。

::: example 一维中的实测收敛速度 {#ex-rates}
对[[finite-element-method/weak-forms]]中受线性增大载荷的杆，取无量纲形式（$EA = 1$，$L = 1$，$b = x$，精确解$u = (x - x^3/3)/2$），计算用$n = 2, 4, 8, 16$个单元时线性有限元解的能量范数误差与$L^2$误差，以及观测到的收敛速度。
::: solution
由于有限元解就是节点插值，误差可以通过逐个单元积分$u - \mathcal{I}u$来计算（此处8点高斯积分是精确的）：

| $n$ | $\|e\|_E$ | 速度 | $\|e\|_{L^2}$ | 速度 |
|---|---|---|---|---|
| 2 | 0.08122 | — | 0.012778 | — |
| 4 | 0.04141 | 0.97 | 0.003269 | 1.97 |
| 8 | 0.02080 | 0.99 | 0.000822 | 1.99 |
| 16 | 0.01041 | 1.00 | 0.000206 | 2.00 |

收敛速度是相继误差之比的$\log_2$。能量（应力）误差：速度为1；位移误差：速度为2，正如[[#eq-apriori]]对$p = 1$所预言的。

**与[[#thm-rate]]对照。**$u'' = -x$，$\|u''\|_{L^2} = 1/\sqrt3 = 0.5774$；$n = 2$时界为$(0.5/\pi)(0.5774) = 0.0919 \ge 0.0812$，$n = 4$时为$0.0459 \ge 0.0414$。精确的能量范数为$0.3651$，所以两个单元时相对误差为$22\,\%$，十六个单元时为$2.9\,\%$——这说明线性单元在应力上收敛得多么慢。
:::
:::

## 由一系列网格测量收敛性

实践中精确解是未知的。但如果误差的行为像$Ch^p$，那么在系统加密的网格上得到的三个解就能确定$C$、$p$和极限值。

::: proposition 观测阶次与理查森外推 {#prop-richardson}
设$f_1, f_2, f_3$是在尺寸为$h$、$h/r$与$h/r^2$（加密比$r > 1$）的网格上计算的某个量的值，并假设$f(h) = f_\infty + Ch^p$，高阶项可以忽略。则
$$
p = \frac{\ln\left[(f_2 - f_1)/(f_3 - f_2)\right]}{\ln r}, \qquad f_\infty \approx f_3 + \frac{f_3 - f_2}{r^p - 1}.
$$ {#eq-richardson}
最细网格解的**估计误差**为$\lvert f_\infty - f_3\rvert = \lvert f_3 - f_2\rvert/(r^p - 1)$。
:::

::: proof
$f_1 - f_2 = Ch^p(1 - r^{-p})$，$f_2 - f_3 = Ch^pr^{-p}(1 - r^{-p})$，所以$(f_2 - f_1)/(f_3 - f_2) = r^p$，由此得$p$。于是$f_3 - f_\infty = Ch^pr^{-2p}$，$f_2 - f_3 = Ch^pr^{-2p}(r^p - 1)$，所以$f_3 - f_\infty = (f_2 - f_3)/(r^p - 1)$，整理即得所述的$f_\infty$。该估计只在主导项占优的**渐近范围**内才有意义：观测到的$p$应接近理论值，三个结果应单调变化。振荡或不规则的结果意味着网格太粗，或者存在奇异性。
:::

::: example 外推悬臂梁的挠度 {#ex-richardson}
[[finite-element-method/plane-elements]]中的Q4悬臂板在$20 \times 2$、$40 \times 4$与$80 \times 8$个正方形单元的网格上给出端部挠度$17.9053$、$19.5041$与$19.9585\,\mathrm{mm}$。估计收敛阶次、收敛的挠度以及最细网格的误差。
::: solution
取$r = 2$：
$$
p = \frac{\ln(1.5988/0.4544)}{\ln 2} = \frac{\ln 3.518}{0.6931} = 1.81, \qquad f_\infty = 19.9585 + \frac{0.4544}{2^{1.81} - 1} = 19.9585 + \frac{0.4544}{2.518} = 20.139\,\mathrm{mm}.
$$
最细网格的估计误差：$0.180\,\mathrm{mm}$，即$0.9\,\%$。

**校核。**线性单元位移的理论阶次为2；观测到的1.81表明这些网格接近但尚未完全进入渐近范围——粗网格仍受剪切闭锁的影响。外推值与带剪切修正的梁理论估计（$20.16\,\mathrm{mm}$）相差在$0.1\,\%$以内，这一小差别与有限元模型中完全固定的根部边缘相符，而梁理论无法表示它。外推不花任何代价就把1 %的误差变成了约0.1 %。
:::
:::

## 收敛速度失效之时：奇异性与闭锁

### 奇异性

估计式[[#eq-apriori]]需要光滑的解。只要几何形状或载荷有尖锐特征，线弹性力学就有非光滑解：凹角、裂纹、集中载荷、点支承、异种材料粘接接头的边缘。在内角$\alpha > 180°$的凹角附近，应力按$r^{\lambda - 1}$变化，其中$r$是到角点的距离，$\lambda < 1$依赖于角度（M. L. Williams，1952年）。对$270°$的角（无圆角的L形支架），主导的对称模式有$\lambda = 0.5445$，所以应力按$r^{-0.4555}$增长；对裂纹（$360°$），$\lambda = 0.5$，应力按$r^{-1/2}$增长。

::: proposition 奇异点附近的收敛 {#prop-singular}
若精确解具有指数$\lambda < p$的奇异性，则无论单元阶次$p$如何，均匀加密给出的能量范数误差都是$O(h^{\lambda})$。奇异点处计算出的应力不收敛：随着网格加密，它按$h^{\lambda - 1}$增长。
:::

::: proof
（概要。）能量范数下的插值误差由与奇异点相接的单元主导。在角点处尺寸为$h$的单元上，行为如$r^\lambda$的场在能量范数下不能被多项式逼近得比$O(h^\lambda)$更好，因为该单元中误差的应变能按$\int_0^h (r^{\lambda - 1})^2\,r\,dr \sim h^{2\lambda}$标度；远离角点的单元贡献光滑速度$h^p$，它更小。至于角点处的应力，那里的单元看到的是$r^{\lambda - 1}$在尺寸为$h$的区域上的平均，其量级为$h^{\lambda - 1}$，当$h \to 0$时无限增大。
:::

因此，尖锐凹角处的峰值应力不是结构的性质，而是网格的性质。补救方法是：模拟真实的几何形状（每个制造出来的角都有圆角半径，有了圆角，应力是有限的并且收敛）；对真正的奇异点使用朝它渐变的网格（这能恢复能量范数下的最优速度）；或者对于裂纹，计算应力强度因子而不是应力。

::: widget interpolation
f: sqrt(x)
n: 7

x: 0, 1
caption: 对$\sqrt{x}$的分片线性插值，其导数$1/(2\sqrt{x})$在$x = 0$处为无穷大——这是应力奇异性的一维漫画。增加点数：远离原点处的误差很快消失，但第一个区间总是带有最大的误差，第一段的斜率（那里的“应力”）不断增大。均匀加密把点浪费在函数光滑的地方；渐变网格会把它们放在原点附近。
:::

### 闭锁

**闭锁**是相反的失效：解收敛，但收敛得如此之慢，以致实用的网格毫无用处，因为单元无法在满足物理所施加的某个约束的同时不抑制正当的变形。在固体力学中有两种闭锁很重要。

- 薄构件弯曲中的**剪切闭锁**：精确解的横向切应变（几乎）为零；线性单元不产生寄生剪切就无法弯曲，如[[finite-element-method/plane-elements]]中所计算的，因而刚得多。[[#eq-apriori]]中的常数随单元的细长程度增大。
- 近不可压缩材料（橡胶、金属的塑性流动、饱和土）的**体积闭锁**：当$\nu \to \tfrac12$时，体积模量$K = E/[3(1 - 2\nu)]$变得远大于切变模量$G$，材料抵抗任何体积变化。低阶单元在所有积分点上都保持体积不变的变形模式太少；在各处强制$\varepsilon_v \approx 0$会把它们冻结。位移结果太小，压力场出现棋盘格式振荡。

补救方法有减缩积分或选择性积分（在较少的点上计算受约束的项）、非协调模式单元与假设应变单元、位移-压力混合（u/p）表述，以及闭锁轻得多的二次单元。决定性的检验仍然是收敛研究：闭锁单元表现为从过刚一侧非常缓慢地收敛。

::: warning 加密的网格可能掩盖错误的模型
收敛研究只度量离散误差。一个收敛到$0.1\,\%$的模型可能错$50\,\%$，因为支承被理想化为刚性的、焊缝被模拟为尖角、载荷施加在单个节点上，或者材料发生了屈服。更糟的是，在奇异点周围加密网格会“收敛”到无穷大的应力。在进行任何加密研究之前，先问一问你要使其收敛的量在数学模型中是否存在——尖角处或集中载荷下的应力并不存在——并单独判断建模误差，办法是与试验、与更简单的模型以及与物理极限进行比较。
:::

## 应力回收与误差估计

有限元模型的位移是其首要的、收敛最好的输出；应力是导数，表现更差——在单元之间不连续，在节点处精度最低，而那正是设计者查看的地方。因此实用程序会**回收**改进的应力。

**在高斯点处采样。**对许多单元，减缩（低一阶）高斯点处的应力比其他地方更精确——这些就是**超收敛**点或最优采样点（Barlow，1976年）。对线性杆，它们是单元中点；对Q8单元，是$2 \times 2$高斯点。

**节点平均。**把应力从高斯点外推到节点，并对在节点处相交的所有单元的贡献取平均。这就产生了商用程序中光滑的云图；它很简单，但在边界和材料界面处可能很差，而跨越材料界面或厚度突变处取平均显然是错误的。

**超收敛分片恢复（SPR）。**监凯维奇与朱（1992年）对每个节点，用最小二乘法把一个与位移场同阶的多项式拟合到围绕该节点的单元片的高斯点应力上，并在节点处计算该多项式。回收的场$\boldsymbol{\sigma}^*$是连续的，并且常常比原始应力收敛快一阶。

::: proposition 监凯维奇-朱误差估计子 {#prop-zz}
若$\boldsymbol{\sigma}^*$是一个比有限元应力$\boldsymbol{\sigma}_h$精确得多的回收应力场，则能量范数误差可以逐个单元地估计为
$$
\|e\|_{E,\text{估计}}^2 = \sum_e \int_{V_e}(\boldsymbol{\sigma}^* - \boldsymbol{\sigma}_h)^{\mathsf T}\mathbf{D}^{-1}(\boldsymbol{\sigma}^* - \boldsymbol{\sigma}_h)\,dV,
$$
并且当$\boldsymbol{\sigma}^*$超收敛时，该估计在$h \to 0$时是渐近精确的。
:::

::: proof
（概要。）能量的精确误差为$\int(\boldsymbol{\sigma} - \boldsymbol{\sigma}_h)^{\mathsf T}\mathbf{D}^{-1}(\boldsymbol{\sigma} - \boldsymbol{\sigma}_h)\,dV$。写$\boldsymbol{\sigma} - \boldsymbol{\sigma}_h = (\boldsymbol{\sigma}^* - \boldsymbol{\sigma}_h) + (\boldsymbol{\sigma} - \boldsymbol{\sigma}^*)$。由能量范数下的三角不等式，真实误差与估计之差至多为$\|\boldsymbol{\sigma} - \boldsymbol{\sigma}^*\|$。若回收应力比有限元应力收敛得快，则$\|\boldsymbol{\sigma} - \boldsymbol{\sigma}^*\| = o(\|\boldsymbol{\sigma} - \boldsymbol{\sigma}_h\|)$，估计与真实误差之比（**有效性指数**）趋于1。
:::

估计子的单元贡献是**自适应网格划分**的基础：估计误差超过其目标份额的单元被细分（或者用由预测收敛速度导出的尺寸场重新生成网格），这一过程重复进行，直到整体估计满足目标。有三种加密策略：**h加密**（更小的单元，阶次不变）、**p加密**（在同一网格上提高多项式阶次）与**hp加密**（两者兼用，在奇异点附近用小单元，在解光滑处用高阶次），后者能实现指数收敛。

::: example 达到目标精度所需的网格尺寸 {#ex-target}
用线性单元对圆角进行应力分析，局部单元尺寸为$25\,\mathrm{mm}$时，由加密研究估计峰值应力的误差为$3.2\,\%$；该量观测到的收敛速度为$p = 2$。要达到$0.5\,\%$需要多大的单元尺寸？如果观测到的速度是1呢？
::: solution
由误差$\propto h^p$：$h_\text{新} = h\,(\eta_\text{目标}/\eta)^{1/p}$。对$p = 2$：$25 \times (0.5/3.2)^{1/2} = 25 \times 0.3953 = 9.9\,\mathrm{mm}$，即约$10\,\mathrm{mm}$。对$p = 1$：$25 \times 0.5/3.2 = 3.9\,\mathrm{mm}$。

**校核。**在二维中，加密区域内的单元数按$h^{-2}$标度：$p = 2$的情况在那里需要约$6.4$倍的单元，$p = 1$的情况约$41$倍。收敛速度比任何计算能力都更有价值；这就是为什么二次单元和布置得当的加密是应力集中分析的常规做法。
:::
:::

## 网格质量

单元形状进入[[#eq-apriori]]中的常数$C$。网格生成器报告的量有：
- **长宽比**（最长尺寸与最短尺寸之比）：在应力梯度区域中，至多约为3的值是无害的；只有在跨越其短边方向的梯度大而沿其长边方向的梯度小的地方（边界层、沿厚度方向的网格），细长单元才可接受；
- **扭斜与内角**：四边形的角远离$90°$（比如在$45°$–$135°$之外）以及三角形的角接近$0°$或$180°$都会降低精度；$180°$的角使$\det\mathbf{J}$为零；
- **雅可比比**（单元内最小与最大$\det\mathbf{J}$之比），以及二次单元的边中节点位置；
- **尺寸过渡**：相邻单元的尺寸之比不应超过约两倍。

这些限值是经验法则，而不是定理；它们因程序和单元类型而异。对网格唯一可靠的检验是对所关心的量进行收敛研究——网格质量指标只告诉你首先该看哪里。1991年斯莱普纳A平台的沉没（见课程历史）是标准的警示：整体模型中三格室壁的单元形状不良，那里的剪力被低估了约45 %，而没有人通过加密网格或独立的手算来校核这个数值。

::: quiz
一位设计者在L形板尖锐内角处把网格加密了三次。峰值应力读数为210、285和390 MPa。应当得出什么结论？
- [ ] 应力已收敛到约400 MPa；用理查森外推求出其值。
- [x] 应力在尖角处是奇异的，将无限增大；必须用真实的圆角半径来模拟该角，或者在远离角点处评估应力。
- [ ] 网格太粗；再加密一两次就会显示收敛。
- [ ] 该单元类型发生了闭锁。
::: solution
比值$285/210 = 1.36$与$390/285 = 1.37$几乎是常数——这是$h^{\lambda - 1}$增长的特征，对按二倍加密的$270°$角，此值接近$2^{0.4555} = 1.37$。理查森外推假设误差是**减小**的；在这里应用它毫无意义。物理应力取决于实际的圆角半径，必须把它纳入模型。
:::
:::

::: history
有限元法的收敛性最早由工程师们在20世纪60年代初从能量原理出发加以论证，艾恩斯（Bruce Irons）于60年代中期提出了分片试验（它与Bazeley、张佑启（Cheung）和监凯维奇在1965年一篇关于板单元的会议论文中被提出，并由艾恩斯与Razzaque于1972年加以分析）。随后数学家们接手了这一方法：斯特朗（Gilbert Strang）与菲克斯（George Fix）的《有限元法分析》（*An Analysis of the Finite Element Method*，1973年）证明了[[#eq-apriori]]的收敛速度，并解释了分片试验何时充分、何时不充分。实用的误差估计随后于1987年出现，监凯维奇（Olgierd Zienkiewicz）与朱（Jian Zhu）提出把有限元应力与光滑化的应力相比较，而他们1992年的超收敛分片恢复使该估计子足够可靠，可用于自动自适应网格划分，如今这在商用程序中已是标准功能。具有指数收敛性的hp版本由巴布什卡（Ivo Babuška）、萨博（Barna Szabó）及其合作者自20世纪80年代初开始发展。
:::

::: summary
- 区分建模误差、离散误差、积分误差与舍入误差；加密只减小离散误差。
- 收敛需要完备性（刚体运动与常应变）、协调性或通过分片试验，以及稳定性（无虚假模式）。
- 对光滑解和$p$次单元：能量（应力）误差为$O(h^p)$，位移误差为$O(h^{p+1})$。在一维中，线性单元满足$\|e\|_E \le (h/\pi)\sqrt{EA}\|u''\|$。
- 由三个系统加密的网格，$p = \ln[(f_2 - f_1)/(f_3 - f_2)]/\ln r$，$f_\infty \approx f_3 + (f_3 - f_2)/(r^p - 1)$，只在渐近范围内有效。
- 奇异性（尖锐凹角、裂纹、集中载荷）把收敛速度降低到$h^\lambda$，并使局部应力发散；闭锁（剪切、体积）使收敛从过刚一侧慢得不切实际。
- 回收应力（高斯点采样、SPR）优于原始应力，两者之差给出监凯维奇-朱误差估计，用以驱动自适应h加密、p加密与hp加密。
- 网格质量指标只是警告；对所关心的量进行收敛研究才是检验。
:::

## 习题

::: exercise 由两个误差求观测阶次 {level=1 check="2"}
在精确解已知的情况下，某位移的误差在尺寸为$h$的网格上为$0.080\,\mathrm{mm}$，在尺寸为$h/2$的网格上为$0.020\,\mathrm{mm}$。观测到的收敛阶次是多少？（输入$p$。）
::: solution
$p = \log_2(0.080/0.020) = \log_2 4 = 2$。
:::
:::

::: exercise 两网格外推 {level=1 check="10.8"}
某挠度在尺寸为$h$的网格上为$10.0\,\mathrm{mm}$，在尺寸为$h/2$的网格上为$10.6\,\mathrm{mm}$。假设理论阶次$p = 2$，估计收敛值。（以mm为单位输入。）
::: solution
$f_\infty = 10.6 + (10.6 - 10.0)/(2^2 - 1) = 10.6 + 0.2 = 10.8\,\mathrm{mm}$。只有两个网格时阶次必须假设；第三个网格可以检验它。
:::
:::

::: exercise 单元尺寸减半 {level=1 check="4"}
对用二次单元求解的光滑问题，单元尺寸减半时能量范数误差缩小为原来的几分之一？（输入该倍数。）
::: solution
能量范数下$p = 2$，所以倍数为$2^2 = 4$（$L^2$位移误差则为$2^3 = 8$）。
:::
:::

::: exercise 峰值应力的三网格研究 {level=2 check="202.45"}
某圆角处的峰值应力在每次加密2倍的网格上分别为$182$、$197$与$201\,\mathrm{MPa}$。求观测阶次与外推应力。（以MPa为单位输入外推应力。）
::: solution
$p = \ln(15/4)/\ln 2 = 1.907$；$f_\infty = 201 + 4/(2^{1.907} - 1) = 201 + 4/2.750 = 202.45\,\mathrm{MPa}$。最细网格约低$0.7\,\%$。单调的序列以及接近2的阶次（光滑圆角处的二次单元）表明已进入渐近范围。
:::
:::

::: exercise 达到目标应力误差的单元尺寸 {level=2 check="1.667"}
尺寸为$10\,\mathrm{mm}$的线性单元使某个以速度$p = 1$收敛的应力有$6\,\%$的误差。要达到$1\,\%$的误差需要多大的单元尺寸？（以mm为单位输入。）
::: solution
$h = 10 \times (1/6)^{1/1} = 1.667\,\mathrm{mm}$。改用二次单元（$p = 2$）只需约$10 \times (1/6)^{1/2} = 4.1\,\mathrm{mm}$，单元数少得多。
:::
:::

::: exercise 奇异应力的增长 {level=2 check="2^0.4555"}
在尖锐的$270°$凹角处，应力场按$r^{\lambda - 1}$变化，$\lambda = 0.5445$。该处网格每加密两倍，计算出的角点应力增大为原来的几倍？（输入该倍数。）
::: solution
角点应力按$h^{\lambda - 1}$标度，所以$h$减半使它乘以$2^{1 - \lambda} = 2^{0.4555} = 1.371$。这就是测验中看到的比值；恒定的增长比是奇异性显露自身的方式。
:::
:::

::: exercise 用数字看体积闭锁 {level=3 check="499.67"}
对$\nu = 0.499$的材料，计算体积模量与切变模量之比$K/G$。结合完全积分Q4单元网格可用的保体积变形模式的个数，解释为什么这种材料会闭锁。（输入$K/G$。）
::: solution
$K/G = \dfrac{E/[3(1 - 2\nu)]}{E/[2(1 + \nu)]} = \dfrac{2(1 + \nu)}{3(1 - 2\nu)} = \dfrac{2.998}{0.006} = 499.67$。任何体积变化所消耗的能量约为同样大小的剪切的500倍，所以解实际上在每个积分点上都被约束为$\varepsilon_v = 0$。由$n \times n$个完全积分Q4单元组成的网格约有$2n^2$个自由自由度，却有$4n^2$个体积约束（每个高斯点一个）：约束多于未知量，而满足所有约束的唯一位移场（几乎）为零。对体积项进行选择性减缩积分（每个单元一个约束，共$n^2$个）留下约$n^2$个自由模式，而混合u/p表述把压力作为一个单独的未知量来处理。
:::
:::

::: exercise 悬挂杆的先验估计 {level=3}
对在自重作用下悬挂的竖直杆（$b$为常数，$EA$为常数，顶端固定，底端自由），用[[#thm-rate]]给出由$n$个等长线性单元组成的网格的能量范数误差界，并与精确误差比较——由于有限元解就是节点插值，你可以计算出精确误差。证明界与实际误差之比趋于一个常数，并求出它。
::: solution
$u'' = -b/EA$，所以$\|u''\|_{L^2} = bL^{1/2}/EA$，界为$\frac{L}{n\pi}\sqrt{EA}\,\frac{b\sqrt L}{EA} = \frac{bL^{3/2}}{n\pi\sqrt{EA}}$。在每个单元上，二次函数的插值误差为$e = \frac{b}{2EA}(x - x_i)(x_{i+1} - x)$，$e' = \frac{b}{2EA}(x_i + x_{i+1} - 2x)$，所以每个单元上$\int(e')^2dx = \frac{b^2}{4EA^2}\cdot\frac{h^3}{3}$。对$n$个长为$h = L/n$的单元求和并乘以$EA$：$\|e\|_E^2 = \frac{b^2}{12EA}\,nh^3 = \frac{b^2L^3}{12EA\,n^2}$，所以$\|e\|_E = \frac{bL^{3/2}}{2\sqrt3\,n\sqrt{EA}}$。界与实际误差之比对每个$n$都是$2\sqrt3/\pi = 1.103$：该估计精确到10 %以内，两者都按$1/n$减小。
:::
:::

::: exercise 规划网格研究 {level=3}
你必须报告一个带$4\,\mathrm{mm}$圆角和一个螺栓孔的钢支架中的最大米泽斯应力，该支架在商用程序中用10节点四面体建模。写一个简短的计划：你将监测哪些量；用多少个网格、以什么加密比；你将如何处理螺栓孔接触和载荷施加以避免人为的奇异性；什么样的结果会使你不信任分析；以及你将报告什么。
::: solution
监测圆角处的峰值应力（所关心的量）、应变能（整体的、光滑收敛的量）和一个位移。至少使用三个网格，在圆角处的局部加密比约为1.5–2，并保持合理的单元质量；二次四面体对圆角应力应给出单调收敛，观测阶次接近2。把载荷作为分布压力施加，或通过在实际面积上的耦合施加，而不要施加在单个节点上；把螺栓模拟为接触或在孔表面上的分布约束，并忽略任何残留点约束周围约一个单元范围内的应力。不可信的迹象：峰值恰好位于约束、载荷点或尖锐边缘处；加密时应力按恒定比值增长；观测阶次远低于预期；峰值处平均与未平均应力差别很大；约束力与载荷不平衡。报告最细网格的值、外推值及估计的离散误差、观测阶次、网格尺寸和建模假设——并说明该结果可供参考，但不能代替按适用设计规范进行的校核。
:::
