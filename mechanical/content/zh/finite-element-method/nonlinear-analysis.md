到目前为止，本课程中的每一个分析都是线性的：刚度与位移无关，所以载荷加倍会使每个响应加倍，求解一次$\mathbf{K}\mathbf{d} = \mathbf{F}$就是全部工作。实际构件会以三种方式离开这个舒适的世界。它们的**材料**会屈服、蠕变或呈橡胶态（[[solid-mechanics/plasticity]]）；它们的**几何**变化大到必须在变形后的形状上写平衡方程——屈曲的细长柱、跳跃失稳的扁拱、随拉伸而变刚的缆索；它们的**边界条件**会随着零件进入或脱离接触而变化。这三者都使内力成为位移的非线性函数，方程必须迭代求解。本章在小到可以追踪每一个数字的问题上建立标准的方法——载荷增量步内的牛顿-拉弗森迭代——说明它如何在极值点处失效以及对此该怎么办，然后转向本章标题的另一半：建立、检查、验证与确认有限元模型（无论线性与否）的实践，使其结果值得信赖。

## 非线性平衡

::: definition 残差与切线刚度 {#def-residual}
对节点位移为$\mathbf{d}$的离散结构，设$\mathbf{F}_\text{int}(\mathbf{d})$为**内力**向量——即变形后受应力的单元所施加的节点力，由$\int\mathbf{B}^{\mathsf T}\boldsymbol\sigma\,dV$组装而成——$\mathbf{F}_\text{ext} = \lambda\mathbf{F}_0$为外载荷，按**载荷因子**$\lambda$缩放。平衡就是**残差**为零：
$$
\mathbf{r}(\mathbf{d}, \lambda) = \lambda\mathbf{F}_0 - \mathbf{F}_\text{int}(\mathbf{d}) = \mathbf{0}.
$$ {#eq-residual}
**切线刚度**是雅可比矩阵$\mathbf{K}_T(\mathbf{d}) = \partial\mathbf{F}_\text{int}/\partial\mathbf{d}$。在线性问题中$\mathbf{F}_\text{int} = \mathbf{K}\mathbf{d}$，$\mathbf{K}_T = \mathbf{K}$。
:::

把问题写成“内力与外力平衡”而不是“$\mathbf{K}\mathbf{d} = \mathbf{F}$”，是观点上的关键转变。对给定的位移，内力总是可以**计算**的——遍历各单元，由当前几何计算应变，由材料本构关系计算应力，然后组装——即使不存在线性意义上的刚度矩阵。问题在于如何找到使残差为零的位移。

## 牛顿-拉弗森迭代

把残差在当前估计值$\mathbf{d}_i$附近展开：$\mathbf{r}(\mathbf{d}_i + \Delta\mathbf{d}) \approx \mathbf{r}(\mathbf{d}_i) - \mathbf{K}_T(\mathbf{d}_i)\,\Delta\mathbf{d}$。令线性化结果为零即得修正量。

::: algorithm 增量牛顿-拉弗森法 {#alg-nr}
把载荷分为若干增量$\lambda_1 < \lambda_2 < \dots < \lambda_N = 1$。从上一增量步的收敛状态$\mathbf{d}$出发：
1. 令$\lambda = \lambda_{n+1}$，计算残差$\mathbf{r} = \lambda\mathbf{F}_0 - \mathbf{F}_\text{int}(\mathbf{d})$。
2. 组装切线刚度$\mathbf{K}_T(\mathbf{d})$并引入支承。
3. 求解$\mathbf{K}_T\,\Delta\mathbf{d} = \mathbf{r}$，并更新$\mathbf{d} \leftarrow \mathbf{d} + \Delta\mathbf{d}$。
4. 计算新的残差并检验收敛，例如$\lVert\mathbf{r}\rVert \le \epsilon_r\lVert\lambda\mathbf{F}_0\rVert$（力）、$\lVert\Delta\mathbf{d}\rVert \le \epsilon_d\lVert\mathbf{d}\rVert$（位移）或$\lvert\Delta\mathbf{d}^{\mathsf T}\mathbf{r}\rvert \le \epsilon_E$乘以其初值（能量），容差通常取$10^{-3}$到$10^{-6}$。
5. 若未收敛，返回第2步；若迭代次数超过限值或残差增大，则缩小增量（把$\lambda_{n+1} - \lambda_n$二分），并从上一个收敛状态重新开始。
6. 收敛后，储存状态（应力、塑性应变），进入下一个增量步。

**修正牛顿-拉弗森法**保留增量步开始时的切线（甚至初始弹性刚度），在以后的迭代中跳过第2步：每次迭代更便宜（无需重新分解），但收敛只是线性的。
:::

::: proposition 牛顿法的二次收敛 {#prop-quadratic}
设$\mathbf{r}$在解$\mathbf{d}^*$附近二阶连续可导，且$\mathbf{K}_T(\mathbf{d}^*)$非奇异。则当$\mathbf{d}_0$足够接近$\mathbf{d}^*$时，牛顿迭代收敛，且误差$\mathbf{e}_i = \mathbf{d}_i - \mathbf{d}^*$满足$\lVert\mathbf{e}_{i+1}\rVert \le C\lVert\mathbf{e}_i\rVert^2$。
:::

::: proof
（一维版本；多维证明把导数换成雅可比矩阵。）写$g(d) = F_\text{int}(d) - \lambda F_0$，于是$g' = K_T$，$g(d^*) = 0$。在$d_i$附近应用泰勒定理，对介于$d_i$与$d^*$之间的某个$\xi$有$0 = g(d^*) = g(d_i) - g'(d_i)e_i + \tfrac12 g''(\xi)e_i^2$。牛顿更新为$d_{i+1} = d_i - g(d_i)/g'(d_i)$，所以$e_{i+1} = e_i - g(d_i)/g'(d_i) = \frac{g''(\xi)}{2g'(d_i)}e_i^2$。在$d^*$附近，$g'$远离零，$g''$有界，所以$\lvert e_{i+1}\rvert \le C e_i^2$。若$\lvert e_0\rvert < 1/C$，误差递减，每次迭代正确的位数大约加倍。在**极值点**（$K_T$奇异）处这些假设不成立，收敛变慢或失败；对于非光滑的材料本构关系（屈服）也不成立，因为$g''$在折点处不存在。
:::

::: example 硬化弹簧 {#ex-spring}
一根弹簧的内力为$F_\text{int}(u) = k_0(u + a\,u^3)$，$k_0 = 1000\,\mathrm{N/mm}$，$a = 0.5\,\mathrm{mm^{-2}}$（一种变刚的支承，如橡胶减振垫或绷紧的缆索）。用牛顿-拉弗森法求$F = 3000\,\mathrm{N}$下的位移：(a) 从$u = 0$出发用一个增量步；(b) 用两个相等的增量步；并尝试 (c) 采用初始刚度$k_0$的修正牛顿-拉弗森法。
::: solution
切线刚度$K_T(u) = k_0(1 + 3au^2)$。$u + 0.5u^3 = 3$的精确根为$u^* = 1.45616\,\mathrm{mm}$。

(a) 一个增量步：

## 几何非线性与极值点

当位移大到足以改变几何形状时，必须在变形后的构形上写平衡方程。经典的例子是扁平双杆桁架——米泽斯（von Mises）桁架——它是扁拱或跳跃开关的模型。

::: proposition 扁平双杆桁架 {#prop-vonmises}
两根相同的杆（轴向刚度$EA$）从位于$(\pm a, 0)$的铰支座延伸到高度为$h \ll a$的顶点；向下的载荷$P$作用于顶点，顶点向下移动$w$。在小应变但有限转动的条件下，在变形后位置写出的平衡方程，精确到$h/a$的首阶，给出
$$
P(w) = \frac{EA}{L_0^3}\,w\,(2h - w)(h - w), \qquad L_0 = \sqrt{a^2 + h^2}.
$$ {#eq-vonmises}
载荷在$w = h(1 - 1/\sqrt3)$处达到最大值，即**极限载荷**$P_\text{max} = \dfrac{2}{3\sqrt3}\dfrac{EAh^3}{L_0^3}$；切线刚度$dP/dw$在该处为零，超过该点后为负。
:::

::: proof
变形后的杆长为$L = \sqrt{a^2 + (h - w)^2}$，所以对$h, w \ll a$，轴向应变为$\varepsilon = (L - L_0)/L_0 \approx \dfrac{(h - w)^2 - h^2}{2L_0^2} = -\dfrac{w(2h - w)}{2L_0^2}$（展开平方根）。杆的压力为$N = -EA\varepsilon$，其在**变形后**位置的竖直分量为$N(h - w)/L \approx N(h - w)/L_0$。两根杆作用下顶点的竖向平衡：$P = 2N(h - w)/L_0 = \dfrac{EA}{L_0^3}w(2h - w)(h - w)$。令$dP/dw = 0$：$\frac{d}{dw}[w(2h - w)(h - w)] = 2h^2 - 6hw + 3w^2 = 0$，所以$w = h(1 \pm 1/\sqrt3)$；较小的根给出最大值$P = \frac{EAh^3}{L_0^3}\cdot\frac{2}{3\sqrt3}$。线性分析会使用未变形的几何，并永远预测$P = (2EAh^2/L_0^3)\,w$。
:::

在$w = h(1 - 1/\sqrt3)$与$w = h(1 + 1/\sqrt3)$之间，结构的切线刚度为负：在恒载下它是不稳定的，一旦$P$达到$P_\text{max}$，顶点就会动态地**跳跃**到远端分支上的反转构形，在那里$P(w)$再次上升（$w$略大于$2h$）。这就是薄板“油罐”式屈曲以及扁球壳和扁拱跳跃失稳的机理。

::: example 扁桁架的极限载荷 {#ex-vonmises}
两根$EA = 2\times10^{7}\,\mathrm{N}$（例如$A = 100\,\mathrm{mm^2}$，$E = 200\,\mathrm{GPa}$）的钢杆从位于$(\pm 1.0, 0)\,\mathrm{m}$的支座延伸到高度$h = 0.1\,\mathrm{m}$的顶点。求极限载荷及其出现时的顶点挠度，并与精确的大转动解比较。跳跃之后顶点落在何处？
::: solution
$L_0 = \sqrt{1 + 0.01} = 1.00499\,\mathrm{m}$，$L_0^3 = 1.0151\,\mathrm{m^3}$。由[[#prop-vonmises]]：
$$
P_\text{max} = 0.3849 \times \frac{2\times10^7 \times 10^{-3}}{1.0151} = 7584\,\mathrm{N}, \qquad w = 0.1(1 - 0.5774) = 0.0423\,\mathrm{m}.
$$
用$L = \sqrt{a^2 + (h - w)^2}$、$N = EA(L_0 - L)/L_0$与$P = 2N(h - w)/L$精确求解平衡，数值结果为$w = 0.0424\,\mathrm{m}$处$P_\text{max} = 7622\,\mathrm{N}$：扁桁架公式的误差在$0.5\,\%$以内。跳跃之后，载荷$P_\text{max}$再次由$w = 2h$以外的上升分支承担；由[[#eq-vonmises]]，这发生在$w = 0.2155\,\mathrm{m}$处，此时顶点位于支座**下方**$0.115\,\mathrm{m}$。

**校核。**与杆的屈服承载力（对$250\,\mathrm{MPa}$的钢每根约$25\,\mathrm{kN}$）相比，极限载荷非常小——这是几何的失稳，而不是材料的失效，线性分析永远发现不了它。极值点处杆的压应变为$w(2h - w)/(2L_0^2) = 3.3\times10^{-3}$；实际上杆可能先发生屈曲，而本模型忽略了这一点。
:::
:::

### 越过极值点

在**载荷控制**下（给定$\lambda$的[[#alg-nr]]），随着接近极值点，牛顿法失效：$\mathbf{K}_T$变为奇异，修正量变得巨大，而对于超过极限的$\lambda$不存在平衡状态。有两种补救方法。

- **位移控制**：给定一个位移分量（顶点挠度），把$\lambda$作为未知量。当某个位移沿路径单调增加时（如上面的桁架）有效，但在被控制的位移本身发生反转的“回跳”点处失效。
- **弧长法**（Riks，1979年；Crisfield，1981年）：增加约束条件，使每个增量在位移-载荷联合空间中具有给定的长度，$\Delta\mathbf{d}^{\mathsf T}\Delta\mathbf{d} + \psi^2\Delta\lambda^2\,\mathbf{F}_0^{\mathsf T}\mathbf{F}_0 = \Delta s^2$，并同时求解$\Delta\mathbf{d}$与$\Delta\lambda$。此时载荷因子可以减小，迭代能沿平衡路径越过极值点和回跳点。弧长法是后屈曲与倒塌分析的标准工具。

切线刚度奇异也出现在**分岔**点处，在那里第二条平衡路径分叉出来（理想柱的欧拉屈曲）。分析者通常在此引入一个小的初始缺陷——其形状常取自线性特征值分析得到的第一阶屈曲模态——使分岔变为弧长法能够追踪的极值点。

## 材料非线性

在弹塑性材料中，应力依赖于应变历史，所以内力是通过在每个积分点上对每个载荷增量步积分本构关系来计算的。对线性各向同性硬化的一维情形，这足够简短，可以写出来。

::: algorithm 一维弹塑性杆的返回映射 {#alg-return}
材料：弹性模量$E$，初始屈服应力$\sigma_Y$，塑性模量$H$（硬化；理想塑性时$H = 0$）。在每个点上储存：应力$\sigma_n$，塑性应变$\varepsilon^p_n$，累积塑性应变$\alpha_n$。给定增量步结束时的总应变$\varepsilon_{n+1}$：
1. **弹性试探：**$\sigma^\text{tr} = E(\varepsilon_{n+1} - \varepsilon^p_n)$；试探屈服函数$f^\text{tr} = \lvert\sigma^\text{tr}\rvert - (\sigma_Y + H\alpha_n)$。
2. 若$f^\text{tr} \le 0$：该步为弹性；$\sigma_{n+1} = \sigma^\text{tr}$，历史变量不变，切线模量为$E$。
3. 否则**返回**屈服面：$\Delta\gamma = f^\text{tr}/(E + H)$，$\sigma_{n+1} = \sigma^\text{tr} - E\Delta\gamma\,\operatorname{sign}(\sigma^\text{tr})$，$\varepsilon^p_{n+1} = \varepsilon^p_n + \Delta\gamma\,\operatorname{sign}(\sigma^\text{tr})$，$\alpha_{n+1} = \alpha_n + \Delta\gamma$；**一致切线**模量为$EH/(E + H)$。
:::

材料子程序返回的切线模量就是进入$\mathbf{K}_T$的量。使用**一致**切线（算法给出的应力对应变的精确导数）能保持牛顿法的二次收敛；始终使用弹性模量则得到修正NR，收敛缓慢。在二维和三维中，同样的结构——弹性预测、塑性修正、一致切线——适用于采用径向返回算法的米泽斯塑性。

::: example 两根并联杆 {#ex-plastic}
一块刚性板由两根并联的钢杆支承，杆长$L_1 = 1.0\,\mathrm{m}$与$L_2 = 1.5\,\mathrm{m}$，均为$A = 100\,\mathrm{mm^2}$，$E = 200\,\mathrm{GPa}$，理想弹塑性，$\sigma_Y = 250\,\mathrm{MPa}$。两杆的伸长量都等于板的位移$\delta$。求初始屈服载荷、倒塌载荷、用牛顿-拉弗森法求$P = 45\,\mathrm{kN}$下的位移，以及卸载后的残余状态。
::: solution
刚度$k_1 = EA/L_1 = 20\,000\,\mathrm{N/mm}$，$k_2 = 13\,333\,\mathrm{N/mm}$；每根杆的屈服力$F_Y = 250 \times 100 = 25\,\mathrm{kN}$。

**初始屈服。**较短、较刚的杆先屈服，此时$\delta = 25\,000/20\,000 = 1.25\,\mathrm{mm}$；于是$P = 25 + 13.333 \times 1.25 = 41.67\,\mathrm{kN}$。**倒塌。**杆2在$\delta = 25\,000/13\,333 = 1.875\,\mathrm{mm}$时屈服；两杆都处于$F_Y$时载荷不能超过$50\,\mathrm{kN}$。

**$P = 45\,\mathrm{kN}$的牛顿-拉弗森求解**（一个增量步，$\delta_0 = 0$）：第1次迭代用$K_T = k_1 + k_2 = 33\,333\,\mathrm{N/mm}$，得$\delta = 1.35\,\mathrm{mm}$。返回映射把杆1限制在$25\,\mathrm{kN}$；杆2承受$18\,\mathrm{kN}$；残差$45 - 43 = 2\,\mathrm{kN}$。第2次迭代用切线$K_T = k_2 = 13\,333\,\mathrm{N/mm}$（杆1现在贡献为零）：$\Delta\delta = 0.15\,\mathrm{mm}$，$\delta = 1.50\,\mathrm{mm}$，残差为零。杆力为$25$与$20\,\mathrm{kN}$。

**卸载**在两根杆中都是弹性的（刚度$33\,333\,\mathrm{N/mm}$）：$\Delta\delta = -45\,000/33\,333 = -1.35\,\mathrm{mm}$，留下永久变形$\delta_\text{残余} = 0.15\,\mathrm{mm}$，杆1为$25 - 20 \times 1.35 = -2.0\,\mathrm{kN}$（压），杆2为$20 - 13.333 \times 1.35 = +2.0\,\mathrm{kN}$（拉）。

**校核。**残余力是自平衡的（无载荷时其和为零），理应如此。再次加载到$45\,\mathrm{kN}$时响应是弹性的——对该载荷结构已经**安定**。牛顿法两次迭代就收敛了，因为材料本构关系是分段线性的：一旦确定了正确的屈服杆集合，问题就是线性的。
:::

## 建模实践：建立值得信赖的模型

本课程的每一章都以校核结束。值得把它们汇集起来，因为工业中大多数有限元错误不是数值上的，而是人为的：单位错误、支承错误、载荷错误、材料错误，以及不加怀疑地读取结果。

**验证与确认。****验证**（verification）问的是方程是否被正确地求解：程序验证（软件在基准问题上给出已知答案——分片试验、构造解、NAFEMS基准题）与解的验证（用[[finite-element-method/convergence-meshing]]中的网格加密来估计**本**模型的离散误差）。**确认**（validation）问的是所求解的是否是正确的方程：把模型预测与专门设计的物理试验相比较，并对两者的不确定性加以量化。对固体力学，这一区分以及规划两者的框架见ASME V&V 10（2006年作为指南发布，2019年作为标准发布）。一个模型可以被完美地验证，却仍然是无效的。

::: algorithm 检查有限元模型 {#alg-checks}
在信任结果之前：
1. **单位。**写下单位制（例如N、mm、t、s、MPa），并对照它检查每一项输入——弹性模量、密度、载荷、压力。在N–mm模型中把钢的弹性模量输入为200（而不是200 000），会使一切都柔1000倍。
2. **自由-自由检查。**不加支承进行模态分析：必须恰好有六个（三维）或三个（二维）零频率刚体模态。多了表明存在机构或不相连的部件；少了表明存在虚假的接地。
3. **约束力。**约束力之和必须在每个方向上与外加载荷平衡，其数值必须与总载荷的手算值（压力 × 面积、重量）相符。
4. **变形形状。**以放大的比例动画显示它。它应当在物理上合理：支承在预期的位置，若问题对称则变形对称，没有孤立的节点飞出，没有锯齿（沙漏）图案。
5. **数量级。**把一个关键的位移和应力与手算估计（梁、板或压力容器公式）比较。相差几十个百分点以内算通过；相差1000倍是单位错误，相差2或3倍通常是支承或载荷错误。
6. **网格。**在需要结果的地方加密并检查收敛；检查峰值应力不位于集中载荷、点支承或尖锐凹角处。
7. **非线性计算。**检查载荷-位移曲线（光滑，没有无法解释的跳跃）、收敛历史（每个增量步的迭代次数、有无步长缩减）以及能量平衡。
8. **文档。**记录假设、输入、校核及其结果，使独立的审核者能够重复它们。
:::

::: example 通过手算校核发现的单位错误 {#ex-units}
一个长$300\,\mathrm{mm}$、矩形截面宽$20\,\mathrm{mm}$、高$40\,\mathrm{mm}$的钢制悬臂支架，端部承受$2\,\mathrm{kN}$。一个以N和mm建立的模型报告端部挠度为$844\,\mathrm{mm}$，根部弯曲应力为$112\,\mathrm{MPa}$。诊断问题。
::: solution
手算估计：$I = 20 \times 40^3/12 = 1.067\times10^{5}\,\mathrm{mm^4}$。端部挠度$PL^3/(3EI) = 2000 \times 2.7\times10^{7}/(3 \times 200\,000 \times 1.067\times10^{5}) = 0.844\,\mathrm{mm}$。根部应力$Mc/I = 2000 \times 300 \times 20/1.067\times10^{5} = 112.5\,\mathrm{MPa}$。

应力与手算值一致，所以载荷、几何与支承都是正确的：在静定构件中，应力与$E$无关。挠度恰好大了$1000$倍，而挠度按$1/E$标度。结论：在应力单位为MPa的模型中，弹性模量被输入为$200$（GPa，即数据表上的数字），而它应当是$200\,000$。改正后得$0.844\,\mathrm{mm}$。

**方法的校核。**先比较应力：那里的不一致指向载荷、几何或支承。再比较挠度与应力之比：那里的不一致指向刚度——弹性模量、截面性质或支承柔度。干净的1000倍几乎总是单位问题；2到4倍通常是支承或载荷施加错误。还要注意，$300\,\mathrm{mm}$的支架有$844\,\mathrm{mm}$的挠度，违反了分析本身的小位移假设——这一结果甚至都不是自洽的。
:::
:::

::: warning 模型不是结构
1991年8月斯莱普纳A重力式基座平台在挪威一处峡湾中的沉没是标准的警示故事。在一次受控的压载试验中，混凝土结构的一面格室壁破坏，整个基座沉没。调查发现，用线弹性通用程序进行的整体有限元分析把三格室壁中的剪力低估了约45 %，这主要是由于该区域的单元形状不利，同时那里的配筋构造也不充分。对剪力的手算校核或更细的局部模型本可以暴露这一错误。没有任何软件能代替一个会问“这些数字是否合理”的工程师——而且有限元结果为设计提供参考，并不能为设计作证明。安全攸关的结构要按适用的规范设计并进行独立校核。
:::

::: quiz
一个扁拱在递增载荷下的几何非线性分析在目标载荷的63 %处停止，并提示“求解未能收敛——二分次数过多”。最可能的解释与补救方法是什么？
- [ ] 网格太细；把它加粗。
- [x] 结构已到达极值点，在那里切线刚度变为奇异，在载荷控制下更高的载荷不存在平衡；改用弧长法（Riks法）或位移控制，并检查载荷-位移路径。
- [ ] 容差太严格；把它放宽到10 %。
- [ ] 牛顿-拉弗森法不能处理几何非线性；改用线性分析。
::: solution
在某个固定的载荷水平附近反复二分且修正量不断增大，是极值点的典型症状。结构的实际承载力可能就是目标的63 %——这是一个真实而重要的结果——而弧长法将显示路径是继续（跳跃到另一个构形）还是倒塌。放宽容差只会掩盖问题，而线性分析根本看不到极值点。
:::
:::

::: history
非线性结构方程的迭代求解紧随线性方法之后出现：到20世纪60年代中期，用于塑性与大挠度的增量“切线刚度”方法已在使用，70年代产生了通用非线性程序以及至今仍在使用的连续介质力学表述（完全拉格朗日与更新拉格朗日表述）。越过极值点是剩下的障碍。温普纳（G. A. Wempner，1971年）与里克斯（E. Riks，1979年）提出约束每个增量在载荷-位移空间中的长度，克里斯菲尔德（M. A. Crisfield，1981年）给出了圆柱弧长法，其形式如今已内置于大多数商用程序中；他的两卷本《固体与结构的非线性有限元分析》（*Non-Linear Finite Element Analysis of Solids and Structures*，1991年、1997年）仍是标准教材。验证与确认这门学科自20世纪90年代发展起来，其推动力来自核能、航空航天与国防机构，它们需要在无法进行试验的场合依靠仿真；2006年ASME为固体力学将其规范化。
:::

::: summary
- 非线性问题写成残差形式$\mathbf{r} = \lambda\mathbf{F}_0 - \mathbf{F}_\text{int}(\mathbf{d}) = \mathbf{0}$；内力由当前几何与材料状态逐个单元地计算。
- 牛顿-拉弗森法在载荷增量步内反复求解$\mathbf{K}_T\Delta\mathbf{d} = \mathbf{r}$，若切线精确，则在解附近二次收敛；修正NR每次迭代更便宜，但只是线性收敛，并且对变刚的响应可能发散。
- 几何非线性可产生极值点（切线刚度为零）与跳跃失稳，如扁桁架$P = \frac{EA}{L_0^3}w(2h - w)(h - w)$；载荷控制在该处失效，位移控制或弧长法可以继续。
- 材料非线性通过在每个积分点上对本构关系进行返回映射积分来处理；一致切线保持二次收敛。塑性变形留下永久变形和自平衡的残余应力。
- 验证（方程是否被正确求解？）与确认（它们是否是正确的方程？）是不同的；在信任任何结果之前，检查单位、刚体模态、约束力、变形形状、手算估计和网格收敛。
:::

## 习题

::: exercise 第一步牛顿迭代 {level=1 check="3"}
对[[#ex-spring]]中承受$3000\,\mathrm{N}$的硬化弹簧，从$u = 0$出发进行第一次牛顿-拉弗森迭代后的位移是多少？（以mm为单位输入。）
::: solution
$K_T(0) = k_0 = 1000\,\mathrm{N/mm}$，$r = 3000\,\mathrm{N}$，所以$u_1 = 3000/1000 = 3.0\,\mathrm{mm}$——即线性解。
:::
:::

::: exercise 残差 {level=1 check="-3000"}
对同样的弹簧与载荷，计算$u = 2\,\mathrm{mm}$处的残差$r = F - F_\text{int}(u)$。（以N为单位输入，带符号。）
::: solution
$F_\text{int}(2) = 1000(2 + 0.5 \times 8) = 6000\,\mathrm{N}$，所以$r = 3000 - 6000 = -3000\,\mathrm{N}$：弹簧在$u = 2\,\mathrm{mm}$处的回推力大于载荷，下一次修正为负。
:::
:::

::: exercise 更扁桁架的极限载荷 {level=1 check="958.65"}
把顶点高度减小到$h = 0.05\,\mathrm{m}$（其余不变），重做[[#ex-vonmises]]的极限载荷计算。（以N为单位输入$P_\text{max}$。）
::: solution
$L_0 = \sqrt{1.0025} = 1.00125\,\mathrm{m}$，$L_0^3 = 1.003756$。$P_\text{max} = 0.38490 \times 2\times10^7 \times 1.25\times10^{-4}/1.003756 = 958.65\,\mathrm{N}$。矢高减半使极限载荷约缩小为1/8（$h^3$）：扁拱对其矢高极为敏感，也对减小矢高的缺陷极为敏感。
:::
:::

::: exercise 并联系统中的初始屈服 {level=2 check="41.667"}
在[[#ex-plastic]]中，外加载荷为多大时第一根杆屈服？（以kN为单位输入$P$。）
::: solution
在弹性阶段载荷按刚度比例分配；杆1在$\delta = 1.25\,\mathrm{mm}$时达到$25\,\mathrm{kN}$，此时杆2承受$13.333 \times 1.25 = 16.667\,\mathrm{kN}$。总计$41.667\,\mathrm{kN}$。
:::
:::

::: exercise 永久变形 {level=2 check="0.15"}
在[[#ex-plastic]]中，载荷加到$45\,\mathrm{kN}$后卸除。板的永久位移是多少？（以mm为单位输入。）
::: solution
加载时：$\delta = 1.50\,\mathrm{mm}$。卸载是弹性的，刚度为$k_1 + k_2 = 33\,333\,\mathrm{N/mm}$：恢复$45\,000/33\,333 = 1.35\,\mathrm{mm}$。永久变形$0.15\,\mathrm{mm}$，两杆中的残余力为$\mp 2\,\mathrm{kN}$。
:::
:::

::: exercise 弹簧的收敛位移 {level=2 check="1.45616"}
从$u = 1.5$出发，用牛顿法求解$1000(u + 0.5u^3) = 3000$，精确到六位有效数字。（以mm为单位输入$u$。）
::: solution
$g(u) = u + 0.5u^3 - 3$，$g'(u) = 1 + 1.5u^2$。从$1.5$出发：$g = 0.1875$，$g' = 4.375$，$u = 1.457143$；$g = 0.004094$，$g' = 4.18490$，$u = 1.456165$；下一次修正$\sim 10^{-6}$。$u = 1.45616\,\mathrm{mm}$。
:::
:::

::: exercise 跳跃位移 {level=3}
对[[#prop-vonmises]]中的扁桁架，证明在$P_\text{max}$处跳跃之后，顶点（静力地）停在$w = h(1 + 2/\sqrt3)$处，并解释为什么载荷控制的牛顿-拉弗森分析不能从极值点继续而找到这一状态。新状态下的切线刚度是多少？
::: solution
写$x = w/h$，$p(x) = x(2 - x)(1 - x)$；在$x = 1 - 1/\sqrt3$处$p_\text{max} = 2/(3\sqrt3)$。代入$x = 1 + y$：$p = (1 + y)(1 - y)(-y) = y^3 - y$。方程$y^3 - y = 2/(3\sqrt3)$有二重根$y = -1/\sqrt3$（极值点），又因为各根之和为零，第三个根为$y = 2/\sqrt3$。所以$x = 1 + 2/\sqrt3 = 2.155$，即$w = 2.155h$。从极值点出发的载荷控制牛顿法面对的是奇异的$K_T$，并且在更高载荷下附近不存在平衡状态；跳到$x = 2.155$是一个动力事件，静力路径跟踪方法只有通过追踪不稳定分支（弧长法）才能到达。新状态下的切线刚度：$dp/dx = 3y^2 - 1 = 3(4/3) - 1 = 3$，即$K_T = 3EAh^2/L_0^3$——为正且稳定，是初始刚度$2EAh^2/L_0^3$的1.5倍。
:::
:::

::: exercise 牛顿法为何在屈服时失效 {level=3}
对承受$P > F_Y$的单根理想弹塑性杆（刚度$k$，屈服力$F_Y$），证明该静力问题无解，并描述当要求牛顿-拉弗森程序施加这一载荷时它会做什么。然后解释为什么对同一根杆进行位移控制分析会收敛，以及它报告什么。
::: solution
在理想塑性下，内力为$\min(k\delta, F_Y)$，从不大于$F_Y$；对每个$\delta$，残差$P - F_\text{int}$至少为$P - F_Y > 0$，所以平衡是不可能的。牛顿法：第一次迭代过冲进入塑性范围，那里的一致切线为零；求解器遇到奇异矩阵（或者在有小的数值刚度时遇到巨大的修正量），增量被反复二分，计算在低于$P$处停止——这个“未能收敛”正是杆已经倒塌这一正确的物理答案。在位移控制下，每个给定的$\delta$都有唯一的力$\min(k\delta, F_Y)$；分析收敛，并描绘出位于$F_Y$（即倒塌载荷）的平台。这就是极限（倒塌）载荷最好用位移控制或弧长控制来计算的原因。
:::
:::

::: exercise 验证与确认计划 {level=3}
你的公司将用一个非线性有限元模型来预测一个薄壁铝制吸能盒的倒塌载荷，该零件在落锤试验台上进行试验。起草一个验证与确认计划：列出程序验证问题、解的验证步骤、确认试验及所测量的量、你将如何把预测与试验比较（包括离散性），以及什么情况会使你否定该模型。
::: solution
**程序验证：**用相同的单元类型和选项重现解析解或基准解——薄板或圆柱壳的弹性屈曲（与经典公式比较）、弹塑性杆或受内压的厚壁圆筒，以及一个已发表的压溃基准题；对壳单元进行分片试验。**解的验证：**对吸能盒进行网格加密（至少三个网格，褶皱波长必须由若干个单元分辨），显式计算中时间步长与质量缩放的敏感性，沙漏能低于内能的百分之几，能量平衡闭合。**确认：**对若干个试件进行准静态压缩试验和落锤试验，测量力-位移曲线、峰值载荷、平均压溃力、褶皱模式，并对同一批材料进行材料试验（相关应变率下的拉伸曲线）。**比较：**报告带有离散不确定性的预测值，与带有离散性（例如±2倍标准差）的试验均值相比较；事先商定验收准则（例如峰值力与平均力在合成不确定性之内、褶皱模式一致）。**否定：**超出不确定性带的系统性偏差、不同的褶皱模式、对数值参数的敏感性大于试验离散性，或者只有通过调整没有物理依据的参数才能得到一致。经确认的模型只在所试验的条件下有效，而不能超出这些条件。
:::
