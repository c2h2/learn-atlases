静定结构可以用受力图求解：仅由平衡就能得到内力，变形随后求出。大多数实际结构并非如此。夹在两堵墙之间的杆、带一根多余斜杆的桁架、支承多于严格所需的机器机架——它们的未知力都多于平衡方程，在[[mechanics-of-materials/axial-loading]]中，你是通过针对每种情况专门写出变形协调条件来求解这类问题的。本章用一个对任何线性结构都适用的统一程序来代替这种逐例推理，无论结构有多少杆件和支承：这就是**直接刚度法**。它是第一个有限元方法，其中的每个思想——单元刚度、组装、支承、求解、内力回收——都原封不动地出现在以后的每一章中。我们针对两种最简单的单元来建立它，即线性弹簧与轴向受载的杆，此时每个矩阵都可以手工写出。

## 自由度与弹簧单元

直接刚度法的未知量是有限个点处的**位移**，而不是力。位移一旦已知，每根杆件中的力就由其自身的刚度得出，而平衡自动满足。这一颠倒——先求位移——正是使该方法具有一般性的原因：无论超静定次数是多少，每一个可能的运动总是恰好对应一个未知量。

::: definition 节点、自由度与弹簧单元 {#def-spring}
**节点**是单元相互连接、或载荷与支承作用的点。**自由度**（degree of freedom，DOF）是节点的一个独立位移分量；本章中每个节点只沿$x$轴运动，因此它有一个自由度，即位移$u_i$，以$+x$方向为正。**线性弹簧单元**$e$连接节点$i$与$j$，承受与其伸长量$u_j - u_i$成正比的轴力：
$$
N^{(e)} = k^{(e)}\,(u_j - u_i),
$$
其中**刚度**$k^{(e)} > 0$（单位N/m，或更方便地用N/mm），并约定**拉力**为正。**节点力**$f_i^{(e)}, f_j^{(e)}$是节点施加**于单元上**的力，以$+x$方向为正。
:::

单独画出弹簧的受力图。若它承受拉力$N$，则其右端的节点必须以$f_j^{(e)} = +N$向右拉它，左端的节点必须向左拉它，$f_i^{(e)} = -N$。代入$N = k(u_j - u_i)$得到两个方程，
$$
f_i^{(e)} = k\,u_i - k\,u_j, \qquad f_j^{(e)} = -k\,u_i + k\,u_j,
$$
写成矩阵形式即为**单元方程**
$$
\begin{bmatrix} f_i \\ f_j \end{bmatrix}^{(e)} = k^{(e)} \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix} \begin{bmatrix} u_i \\ u_j \end{bmatrix}, \qquad \mathbf{f}^{(e)} = \mathbf{k}^{(e)}\,\mathbf{d}^{(e)}.
$$ {#eq-spring-k}

矩阵$\mathbf{k}^{(e)}$称为**单元刚度矩阵**。它的每一列都有一个值得记住的物理意义，因为这是写出任何单元刚度矩阵的最快方法：**第$m$列列出了使单元保持在“第$m$个自由度等于1、其余自由度都等于0”这一构形所需的节点力。**固定节点$i$，把节点$j$向右推动一个单位：弹簧伸长1，需要在$j$处施加$+k$、在$i$处施加$-k$——这就是第二列。

$\mathbf{k}^{(e)}$的三个性质已经显而易见。它是**对称的**。每一列之和为零，因为作用在一个分离体上的两个节点力必须平衡。并且它是**奇异的**：刚体运动$u_i = u_j = 1$不产生任何力，$\mathbf{k}^{(e)}[1, 1]^{\mathsf T} = \mathbf{0}$，所以$\det\mathbf{k}^{(e)} = 0$。单独一根弹簧可以漂移；只有支承才能使问题可解。

## 杆单元

长为$L$、横截面积$A$为常数、弹性模量为$E$且只在两端受载的弹性杆就是一根弹簧。由[[mechanics-of-materials/axial-loading]]，它在轴力$N$作用下的伸长量为$\delta = NL/(EA)$，于是

::: definition 杆单元 {#def-bar}
位于$x$轴上节点$i$与$j$之间、长为$L$、面积为$A$、弹性模量为$E$的**杆单元**（轴向单元、拉压杆单元）的刚度为$k = EA/L$，单元刚度矩阵为
$$
\mathbf{k}^{(e)} = \frac{EA}{L}\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}.
$$
单元内位移线性变化，$u(x) = N_i(x)\,u_i + N_j(x)\,u_j$，其中**形函数**为$N_i = 1 - x/L$与$N_j = x/L$（$x$从节点$i$量起），因此应变与应力为常数：
$$
\varepsilon = \frac{u_j - u_i}{L}, \qquad \sigma = E\varepsilon = \frac{E}{L}\,(u_j - u_i), \qquad N = \sigma A.
$$
:::

对于两端受载的等截面杆，线性位移场并不是近似，而是精确解，因为沿这样的杆轴力为常数，因而应变也是常数。只有当杆是变截面的、或沿长度受载（自重、分布摩擦力）时才引入近似；此时一串短单元用常应变的阶梯代替光滑的变化，而这串单元必须多细的问题，就是我们与收敛性的第一次相遇。

在单位方面，最简单的做法是始终使用**牛顿与毫米**：这样$E$的单位是$\mathrm{N/mm^2} = \mathrm{MPa}$，面积用$\mathrm{mm^2}$，长度用mm，刚度用N/mm，位移用mm，应力用MPa，永远不会出现换算因子。一根$E = 200\,\mathrm{GPa} = 200\,000\,\mathrm{MPa}$、$A = 400\,\mathrm{mm^2}$、$L = 300\,\mathrm{mm}$的钢杆有$k = 200\,000 \times 400 / 300 = 266\,667\,\mathrm{N/mm}$，即约$267\,\mathrm{kN/mm}$——杆是很刚的。

## 组装

结构是一组共享节点的单元。在每个节点处，作用于该节点的外力必须等于该节点施加于与其相连的各单元上的力之和（牛顿第三定律加上节点的平衡）。若节点$I$承受外力$F_I$，则
$$
F_I = \sum_{e \ni I} f_I^{(e)},
$$ {#eq-node-eq}
求和遍及包含节点$I$的所有单元。每个$f_I^{(e)}$都通过$\mathbf{k}^{(e)}$成为节点位移的线性组合，所以全部节点方程构成关于整体位移向量$\mathbf{d} = [u_1, \dots, u_n]^{\mathsf T}$的线性方程组$\mathbf{K}\mathbf{d} = \mathbf{F}$。$\mathbf{K}$的元素是把每个单元的元素加到其整体自由度对应的行和列中得到的：

::: algorithm 直接刚度法 {#alg-dsm}
1. **编号**：对节点编号$1, \dots, n$并对整体自由度编号；写出**单元连接表**：对每个单元，列出其节点的整体编号（按$i$、$j$的顺序）。
2. **单元矩阵。**对每个单元计算$\mathbf{k}^{(e)}$（以及单元载荷向量，如有）。
3. **组装。**从$n \times n$零矩阵$\mathbf{K}$与零向量$\mathbf{F}$开始。对每个单元，把元素$k^{(e)}_{ab}$加到$K_{IJ}$上，其中$I$与$J$是单元局部自由度$a$与$b$对应的整体自由度。把所施加的节点载荷加到$\mathbf{F}$中。
4. **支承。**把自由度划分为自由（$f$）集与给定（$s$）集，并引入给定值（见[[#prop-partition]]）。
5. **求解**$\mathbf{K}_{ff}\mathbf{d}_f = \mathbf{F}_f - \mathbf{K}_{fs}\mathbf{d}_s$，得到未知位移。
6. **回收**约束力$\mathbf{R}_s = \mathbf{K}_{sf}\mathbf{d}_f + \mathbf{K}_{ss}\mathbf{d}_s - \mathbf{F}_s$，并逐个单元地由[[#def-bar]]回收应变、应力与杆件内力。
7. **校核**约束力与所施加的载荷平衡，且变形形状合理。
:::

“直接”一词指第3步：整体矩阵是把单元贡献直接加到相应位置而建立的，从不需要显式地写出节点平衡方程。对于一串弹簧，连接节点$e$与$e+1$的单元$e$在对角线上贡献一个$2\times2$块，这些块在共享节点处重叠，于是$\mathbf{K}$是**三对角**的。一般地，只有当节点$I$与$J$属于同一个单元时才有$K_{IJ} \neq 0$，所以大型模型的整体矩阵绝大部分元素为零——是**稀疏**的——而且若对节点编号使相连节点的编号相近，它还是**带状**的。实际的求解器同时利用这两个性质；一个有一百万个自由度的模型大约只有三千万个非零元素，而不是$10^{12}$个。

::: proposition 组装刚度矩阵的性质 {#prop-k-props}
对任何由正刚度的弹簧与杆组装成的系统，在引入支承之前：
1. $\mathbf{K}$是对称的；
2. 对每个$\mathbf{d}$都有$\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d} = \sum_e k^{(e)}\,(u_j - u_i)^2 \ge 0$（半正定），且$\tfrac12\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d}$是所储存的应变能；
3. $\mathbf{K}$是奇异的：刚体平移$\mathbf{d} = [1, 1, \dots, 1]^{\mathsf T}$满足$\mathbf{K}\mathbf{d} = \mathbf{0}$；
4. 若结构是连通的且至少有一个自由度被给定，则缩减矩阵$\mathbf{K}_{ff}$对称正定，因而可逆。
:::

::: proof
(1) 每个$\mathbf{k}^{(e)}$都是对称的，并且把$k^{(e)}_{ab}$加到$K_{IJ}$上时，总伴随着把$k^{(e)}_{ba} = k^{(e)}_{ab}$加到$K_{JI}$上。(2) 组装就是命题$\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d} = \sum_e \mathbf{d}^{(e)\mathsf T}\mathbf{k}^{(e)}\mathbf{d}^{(e)}$，其中$\mathbf{d}^{(e)}$取出该单元的节点值；对一根弹簧，$\mathbf{d}^{(e)\mathsf T}\mathbf{k}^{(e)}\mathbf{d}^{(e)} = k(u_i^2 - 2u_iu_j + u_j^2) = k(u_j - u_i)^2$。它的一半就是伸长$\delta$的弹簧的应变能$\tfrac12 k\delta^2$。(3) 在均匀平移下每个单元都有$u_j - u_i = 0$，所以每一项都为零，而满足$\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d} = 0$的半正定矩阵有$\mathbf{K}\mathbf{d} = \mathbf{0}$。(4) 设在给定自由度取零时$\mathbf{d}_f^{\mathsf T}\mathbf{K}_{ff}\mathbf{d}_f = 0$。则每个单元的伸长量为零，因此每个单元两端的位移相等；由于结构连通，所有位移都等于给定的位移，即为零。故对每个非零的$\mathbf{d}_f$，该二次型都为正。
:::

第(4)部分是一条实用规则的数学形式：**只有当支承抑制了每一种刚体运动时，模型才可解。**没有支承或支承不足的模型给出奇异矩阵，求解器会报告“零主元”“矩阵非正定”，或者——更糟的是，由于舍入误差——返回巨大而毫无意义的位移。

## 边界条件

支承给定位移；在给定的自由度上，力是未知的（约束力），而位移是已知的。因此每个自由度都恰好有一个已知量和一个未知量，方程可以重新排序，使未知量分离出来。

::: proposition 分块求解 {#prop-partition}
把自由度排序为自由自由度$f$（位移未知，力已知）与给定自由度$s$（位移已知，约束力未知）。把给定自由度上的力写成所施加的载荷加约束力，$\mathbf{F}_s + \mathbf{R}_s$，则方程组分块为
$$
\begin{bmatrix} \mathbf{K}_{ff} & \mathbf{K}_{fs} \\ \mathbf{K}_{sf} & \mathbf{K}_{ss} \end{bmatrix}\begin{bmatrix} \mathbf{d}_f \\ \mathbf{d}_s \end{bmatrix} = \begin{bmatrix} \mathbf{F}_f \\ \mathbf{F}_s + \mathbf{R}_s \end{bmatrix},
$$
因此自由位移与约束力为
$$
\mathbf{d}_f = \mathbf{K}_{ff}^{-1}\left(\mathbf{F}_f - \mathbf{K}_{fs}\mathbf{d}_s\right), \qquad \mathbf{R}_s = \mathbf{K}_{sf}\mathbf{d}_f + \mathbf{K}_{ss}\mathbf{d}_s - \mathbf{F}_s.
$$ {#eq-partition}
:::

::: proof
第一块行为$\mathbf{K}_{ff}\mathbf{d}_f + \mathbf{K}_{fs}\mathbf{d}_s = \mathbf{F}_f$；$\mathbf{d}_s$已知，把它移到右端便得到一个方阵方程组，由[[#prop-k-props]](4)，其矩阵可逆。第二块行随后显式地给出$\mathbf{R}_s$。不需要假设$\mathbf{d}_s = \mathbf{0}$：给定的非零位移（支座沉降、强制装配）只是把$\mathbf{K}_{fs}\mathbf{d}_s$项移到右端，在那里它起等效载荷的作用。
:::

当$\mathbf{d}_s = \mathbf{0}$时，这一做法就是熟悉的“划去受支承自由度所在的行与列”。程序很少真正对矩阵重新排序；它们要么就地求解缩减方程组，要么采用**罚函数法**：在每个给定自由度$m$上，把一个很大的数$C$加到$K_{mm}$上，并把$C\,\bar d_m$加到$F_m$上，这相当于用一根很刚的弹簧把节点拴在给定位置上。罚函数法保持矩阵的规模与稀疏结构不变，但给定值只是近似满足，相对误差的量级为$k/C$，而$C$太大又会破坏矩阵的条件数。常用的选择是$C$约为$\mathbf{K}$最大对角元的$10^4$到$10^6$倍。

::: warning 单位、符号与支承
大多数错误的手算都源于三种错误。**单位混用**：$E$用GPa而长度用mm、力用N，得到的位移会差$10^3$倍；选定N–mm–MPa（或N–m–Pa）并始终坚持使用，并记住$1\,\mathrm{kN/m} = 1\,\mathrm{N/mm}$。**约束力的符号**：由[[#eq-partition]]得到的约束力是支承施加**于结构上**的力，以$+x$方向为正；负值表示向左作用，并且约束力必须与所施加的载荷严格平衡（$\sum R + \sum F = 0$）。**支承缺失**：若划去的行太少，$\mathbf{K}_{ff}$就是奇异的；此时软件给出的“解”只是数值噪声，位移常常达到$10^{10}$ mm。务必校核约束力之和，并查看变形形状。
:::

## 算例

::: example 两根串联弹簧 {#ex-series}
两根弹簧$k_1 = 200\,\mathrm{kN/m}$（位于节点1与2之间）与$k_2 = 300\,\mathrm{kN/m}$（位于节点2与3之间）在节点1处从墙上沿一条直线悬挂。沿$+x$方向的力$F = 500\,\mathrm{N}$作用于节点3。求节点位移、弹簧力与墙的约束力。
::: solution
采用N与mm：$k_1 = 200\,\mathrm{N/mm}$，$k_2 = 300\,\mathrm{N/mm}$。整体受力图：节点3处向右的500 N载荷，以及墙处的未知约束力$R_1$。组装（单元连接：单元1 = 节点1–2，单元2 = 节点2–3）：
$$
\mathbf{K} = \begin{bmatrix} 200 & -200 & 0 \\ -200 & 200 + 300 & -300 \\ 0 & -300 & 300 \end{bmatrix}\ \mathrm{N/mm}.
$$
节点1固定，$u_1 = 0$，所以缩减方程组由第2、3行与第2、3列组成：
$$
\begin{bmatrix} 500 & -300 \\ -300 & 300 \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} 0 \\ 500 \end{bmatrix}.
$$
两个方程相加得$200\,u_2 = 500$，所以$u_2 = 2.50\,\mathrm{mm}$；然后$300\,u_3 = 500 + 300 \times 2.50 = 1250$，$u_3 = 4.167\,\mathrm{mm}$。

弹簧力：$N_1 = 200(2.50 - 0) = 500\,\mathrm{N}$，$N_2 = 300(4.167 - 2.50) = 500\,\mathrm{N}$，均为拉力。由完整方程组的第一行得约束力：$R_1 = 200 \cdot 0 - 200 \times 2.50 = -500\,\mathrm{N}$，即向左500 N。

**校核。**串联弹簧承受相同的力，且$1/k_\text{eq} = 1/200 + 1/300$，$k_\text{eq} = 120\,\mathrm{N/mm}$；$u_3 = 500/120 = 4.167\,\mathrm{mm}$。约束力与载荷平衡。注意数量级：$k$用N/mm时答案是毫米——如果刚度是$2000$与$3000\,\mathrm{N/m}$，同样的算术给出的是米，这样软的弹簧会伸长四分之一米。
:::
:::

::: example 两墙之间的阶梯杆 {#ex-stepped}
一段钢杆（$E_1 = 200\,\mathrm{GPa}$，$A_1 = 400\,\mathrm{mm^2}$，$L_1 = 300\,\mathrm{mm}$）与一段铝杆（$E_2 = 70\,\mathrm{GPa}$，$A_2 = 600\,\mathrm{mm^2}$，$L_2 = 200\,\mathrm{mm}$）首尾相接，固定在两堵刚性墙之间。轴向载荷$P = 60\,\mathrm{kN}$在连接处向右作用。求连接处的位移、两段中的应力以及墙的约束力。
::: solution
受力图：节点2处向右的载荷$P$，两墙处的未知约束力$R_1$与$R_3$——两个未知力，一个平衡方程，所以问题是一次超静定的。该方法对此并不在意。

单元刚度（N、mm、MPa）：
$$
k_1 = \frac{200\,000 \times 400}{300} = 266\,667\,\mathrm{N/mm}, \qquad k_2 = \frac{70\,000 \times 600}{200} = 210\,000\,\mathrm{N/mm}.
$$
节点1与3固定，所以只有$u_2$是自由的，它在$\mathbf{K}$中的行为$[-k_1,\ k_1 + k_2,\ -k_2]$：
$$
(k_1 + k_2)\,u_2 = P \quad\Rightarrow\quad u_2 = \frac{60\,000}{476\,667} = 0.1259\,\mathrm{mm}.
$$
由[[#def-bar]]得应力：
$$
\sigma_1 = \frac{E_1}{L_1}(u_2 - u_1) = \frac{200\,000}{300}(0.1259) = 83.9\,\mathrm{MPa}, \qquad \sigma_2 = \frac{E_2}{L_2}(u_3 - u_2) = \frac{70\,000}{200}(-0.1259) = -44.1\,\mathrm{MPa}.
$$
钢段受拉，铝段受压。由第1行与第3行得约束力：$R_1 = -k_1u_2 = -33.57\,\mathrm{kN}$，$R_3 = -k_2u_2 = -26.43\,\mathrm{kN}$。

**校核。**$R_1 + R_3 + P = -33.57 - 26.43 + 60 = 0$。载荷按两条传力路径的刚度成比例分配，钢段分得$k_1/(k_1 + k_2) = 56\,\%$——与[[mechanics-of-materials/axial-loading]]中用变形协调求得的解完全相同，但无需写出变形协调方程：协调性是内含的，因为两个单元共享唯一的未知量$u_2$。
:::
:::

::: example 给定的支座位移 {#ex-settlement}
三根弹簧$k_1 = 100$、$k_2 = 200$、$k_3 = 100\,\mathrm{N/mm}$沿一条直线分别连接节点1–2、2–3与3–4。节点1固定；节点4连接在一个向左移动了$5\,\mathrm{mm}$的支座上（$u_4 = -5\,\mathrm{mm}$）；沿$+x$方向的$1500\,\mathrm{N}$力作用于节点3。求$u_2$、$u_3$、约束力与弹簧力，并与罚函数法的解比较。
::: solution
组装矩阵（N/mm）：
$$
\mathbf{K} = \begin{bmatrix} 100 & -100 & 0 & 0 \\ -100 & 300 & -200 & 0 \\ 0 & -200 & 300 & -100 \\ 0 & 0 & -100 & 100 \end{bmatrix}.
$$
自由自由度$f = \{2, 3\}$，给定自由度$s = \{1, 4\}$，$\mathbf{d}_s = [0, -5]^{\mathsf T}\,\mathrm{mm}$。由[[#eq-partition]]，右端项为
$$
\mathbf{F}_f - \mathbf{K}_{fs}\mathbf{d}_s = \begin{bmatrix} 0 \\ 1500 \end{bmatrix} - \begin{bmatrix} -100 & 0 \\ 0 & -100 \end{bmatrix}\begin{bmatrix} 0 \\ -5 \end{bmatrix} = \begin{bmatrix} 0 \\ 1500 - 500 \end{bmatrix} = \begin{bmatrix} 0 \\ 1000 \end{bmatrix}\ \mathrm{N},
$$
从而
$$
\begin{bmatrix} 300 & -200 \\ -200 & 300 \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} 0 \\ 1000 \end{bmatrix} \quad\Rightarrow\quad u_2 = 4.00\,\mathrm{mm}, \quad u_3 = 6.00\,\mathrm{mm}.
$$
（行列式为$300^2 - 200^2 = 50\,000$；$u_2 = 200\,000/50\,000$，$u_3 = 300\,000/50\,000$。）由第1行与第4行（该处无外加载荷）得约束力：$R_1 = -100 \times 4 = -400\,\mathrm{N}$，$R_4 = -100 \times 6 + 100 \times (-5) = -1100\,\mathrm{N}$。弹簧力：$N_1 = 100(4 - 0) = 400\,\mathrm{N}$，$N_2 = 200(6 - 4) = 400\,\mathrm{N}$（拉），$N_3 = 100(-5 - 6) = -1100\,\mathrm{N}$（压）。

**校核。**$R_1 + 1500 + R_4 = -400 + 1500 - 1100 = 0$。链的左段承受400 N，右侧弹簧承受1100 N的压力：外加力被分担，而节点4的强制位移进一步压缩右侧弹簧。

**罚函数法求解。**把$C = 3 \times 10^6\,\mathrm{N/mm}$（最大对角元300的$10^4$倍）加到$K_{11}$与$K_{44}$上，并把$C \times (-5)$加到$F_4$上，完整的$4 \times 4$方程组给出$u_1 = 1.3 \times 10^{-4}\,\mathrm{mm}$，$u_2 = 4.0002$，$u_3 = 6.0003$，$u_4 = -4.9996\,\mathrm{mm}$：误差量级为$k/C \approx 10^{-4}$，与预测一致。
:::

## 能量：该方法为何成立

到目前为止，$\mathbf{K}\mathbf{d} = \mathbf{F}$来自节点平衡。同样的方程也可以由能量原理得出，而这第二种推导正是能推广到连续体的那一种，因为在连续体中没有离散的弹簧可画。

::: proposition 最小总势能原理 {#prop-mpe}
对受节点载荷$\mathbf{F}$作用的线弹性组装系统，定义**总势能**
$$
\Pi(\mathbf{d}) = U - W = \tfrac12\,\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d} - \mathbf{d}^{\mathsf T}\mathbf{F}.
$$ {#eq-pe}
在所有满足给定支承条件的位移向量中，平衡构形是使$\Pi$取驻值的那一个；它满足$\mathbf{K}_{ff}\mathbf{d}_f = \mathbf{F}_f - \mathbf{K}_{fs}\mathbf{d}_s$，并且当$\mathbf{K}_{ff}$正定时，驻点是唯一的极小点。
:::

::: proof
由[[#prop-k-props]]，应变能为$U = \sum_e \tfrac12 k^{(e)}(u_j - u_i)^2 = \tfrac12\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d}$，而载荷为常量（恒载），所以其势能为$-\mathbf{d}^{\mathsf T}\mathbf{F}$。只有自由自由度可以变化。由于$\mathbf{K}$对称，$\partial\Pi/\partial\mathbf{d}_f = \mathbf{K}_{ff}\mathbf{d}_f + \mathbf{K}_{fs}\mathbf{d}_s - \mathbf{F}_f$，令其为零即得[[#prop-partition]]的第一行。$\Pi$关于$\mathbf{d}_f$的黑塞矩阵是$\mathbf{K}_{ff}$；若它正定，$\Pi$就是严格凸的二次函数，驻点是其唯一的极小点。假设：线弹性，小位移（写出$\mathbf{k}^{(e)}$所用的几何形状不变），载荷不随变形而变化。
:::

对单根弹簧，$\Pi = \tfrac12 ku^2 - Fu$是一条抛物线，其最低点在$u = F/k$。对连续体，位移场有无穷多个自由度；有限元法把它限制为由有限个节点值描述的场，并在这个受限集合上使$\Pi$极小。所得的$\mathbf{K}$仍然逐个单元地组装，因为能量对单元是可加的。这一思想将在[[finite-element-method/weak-forms]]中正式展开。

## 单元上的载荷：热应变与分布载荷

作用在单元内部而非节点上的载荷必须转换为**等效节点载荷**。最简单也最常见的情况是温度变化。线膨胀系数为$\alpha$的杆升温$\Delta T$后，总应变为$\varepsilon = \sigma/E + \alpha\,\Delta T$，所以其轴力为$N = EA\left[(u_j - u_i)/L - \alpha\Delta T\right]$。像前面一样写出节点力，
$$
\mathbf{f}^{(e)} = \mathbf{k}^{(e)}\mathbf{d}^{(e)} - EA\alpha\,\Delta T\begin{bmatrix} -1 \\ 1 \end{bmatrix},
$$ {#eq-thermal}
把第二项移到载荷一侧可见，受热的单元以力$EA\alpha\Delta T$向外推其节点：**温度载荷向量**$\mathbf{f}_T^{(e)} = EA\alpha\Delta T\,[-1, 1]^{\mathsf T}$像任何其他载荷一样组装到$\mathbf{F}$中。求解之后，应力必须由**机械**应变回收，$\sigma = E\left[(u_j - u_i)/L - \alpha\Delta T\right]$；在这一步忘记$\alpha\Delta T$项是一个经典错误，它会把无应力的受约束杆报告为高应力，或者相反。

变截面杆或沿长度受载的杆用细分来处理。给每个单元一个常数面积——例如其中点处的面积——并把分布载荷集中到节点上（每个单元所分担的部分一半分给每一端；一致的规则在[[finite-element-method/weak-forms]]中推导）。此时答案不再精确，但随着单元缩小而收敛。

::: example 用一个、两个和四个单元计算变截面杆 {#ex-taper}
一根铝杆（$E = 70\,\mathrm{GPa}$），长$L = 1.2\,\mathrm{m}$，在$x = 0$处固定，该处面积为$A_0 = 600\,\mathrm{mm^2}$；面积线性减小到自由端的$A_0/2 = 300\,\mathrm{mm^2}$，自由端作用轴向载荷$P = 20\,\mathrm{kN}$。用$n = 1, 2, 4$个取中点面积的等长单元计算端部位移，并与精确值比较。
::: solution
**精确解。**各处的力都是$P$，且$A(x) = A_0(1 - x/2L)$，所以
$$
\delta = \int_0^L \frac{P\,dx}{EA_0(1 - x/2L)} = \frac{PL}{EA_0}\,2\ln 2 = \frac{20\,000 \times 1200}{70\,000 \times 600}(1.3863) = 0.5714 \times 1.3863 = 0.7922\,\mathrm{mm}.
$$
**有限元解。**$n$个单元串联、只有端部一个载荷时，每个单元都承受$P$，端部位移是各单元伸长量之和$\delta_n = \sum_e PL_e/(EA_e)$，这恰好就是组装后的三对角方程组给出的结果。
- $n = 1$：$A = 450\,\mathrm{mm^2}$，$\delta_1 = 20\,000 \times 1200/(70\,000 \times 450) = 0.7619\,\mathrm{mm}$（误差$3.82\,\%$）。
- $n = 2$：面积$525$与$375\,\mathrm{mm^2}$，$L_e = 600\,\mathrm{mm}$：$\delta_2 = \frac{20\,000 \times 600}{70\,000}\left(\frac{1}{525} + \frac{1}{375}\right) = 171.43 \times 0.0045714 = 0.7837\,\mathrm{mm}$（误差$1.07\,\%$）。
- $n = 4$：面积$562.5, 487.5, 412.5, 337.5\,\mathrm{mm^2}$：$\delta_4 = 0.7900\,\mathrm{mm}$（误差$0.28\,\%$）。

**校核。**单元长度每减半一次，误差约缩小为原来的1/3.6到1/3.9，趋近于1/4：误差的行为像$h^2$，这是隐含在“中点面积”选择中的中点公式的特征。有限元答案都**低于**精确值——阶梯模型比实际杆更刚——这一规律我们将在[[finite-element-method/weak-forms]]中再次遇到并加以证明。
:::

::: example 受约束双材料杆中的热应力 {#ex-thermal}
[[#ex-stepped]]中的钢–铝杆在无应力状态下装配在两墙之间，不受机械载荷，然后均匀升温$\Delta T = 40\,\mathrm{K}$。取$\alpha_\text{steel} = 12 \times 10^{-6}\,\mathrm{K^{-1}}$，$\alpha_\text{Al} = 23 \times 10^{-6}\,\mathrm{K^{-1}}$。求连接处的位移与应力。
::: solution
温度力$E A\alpha\Delta T$（N）：钢段$200\,000 \times 400 \times 12\times10^{-6} \times 40 = 38\,400\,\mathrm{N}$；铝段$70\,000 \times 600 \times 23\times10^{-6} \times 40 = 38\,640\,\mathrm{N}$。由[[#eq-thermal]]，单元1对节点2贡献$+38\,400$，单元2对节点2贡献$-38\,640$，所以
$$
(k_1 + k_2)\,u_2 = 38\,400 - 38\,640 = -240\,\mathrm{N} \quad\Rightarrow\quad u_2 = \frac{-240}{476\,667} = -5.03 \times 10^{-4}\,\mathrm{mm}.
$$
由机械应变求应力：
$$
\sigma_1 = 200\,000\left(\frac{-5.03\times10^{-4}}{300} - 12\times10^{-6} \times 40\right) = -96.3\,\mathrm{MPa}, \qquad \sigma_2 = 70\,000\left(\frac{0 + 5.03\times10^{-4}}{200} - 23\times10^{-6} \times 40\right) = -64.2\,\mathrm{MPa}.
$$
杆件内力：$\sigma_1A_1 = -38.53\,\mathrm{kN}$与$\sigma_2A_2 = -38.53\,\mathrm{kN}$——两者相等，在连接处无载荷的串联杆中必然如此。

**校核。**经典的变形协调解法：自由热伸长$(\alpha_1L_1 + \alpha_2L_2)\Delta T = 0.328\,\mathrm{mm}$必须由一个力$N$消除，其柔度为$L_1/(E_1A_1) + L_2/(E_2A_2) = 8.512 \times 10^{-6}\,\mathrm{mm/N}$，得$N = -38.53\,\mathrm{kN}$。连接处几乎不动，因为两个温度力几乎相互抵消。如果我们由总应变计算应力，会报告钢段中为$-0.34\,\mathrm{MPa}$——相差将近300倍。
:::

::: quiz
一个由五根杆沿直线组成的模型（六个节点，每个节点一个自由度）只在节点1处有支承。有人“为了保险”又删去了节点6对应的行和列，尽管节点6上作用着外加载荷。后果是什么？
- [ ] 没有影响：删去多余的行只会使方程组更小、求解更快。
- [x] 节点6现在被固定在$u_6 = 0$：模型多了一个实际不存在的支承，节点6上的载荷直接进入一个虚构的约束力，所有位移都是错的。
- [ ] 矩阵变为奇异，求解器停止运行。
- [ ] 答案不变，因为刚度矩阵是对称的。
::: solution
划去一行一列等同于给定该位移为零。缩减矩阵仍然正定（现在有两个支承），所以求解器顺利运行并返回错误的答案。约束力校核会揭露这一错误：程序报告了节点6处的一个约束力，而实际结构并没有它。
:::

::: history
结构矩阵方法产生于20世纪40年代末和50年代的飞机工程，当时后掠翼与三角翼已无法作为简单的梁来分析。帝国理工学院的阿吉里斯（John Argyris）在1954—1955年于《飞机工程》（*Aircraft Engineering*）上发表的系列文章“Energy theorems and structural analysis”中，提出了一般的结构矩阵理论。在波音公司，特纳（M. J. Turner）与克拉夫（Ray Clough，当时利用暑假离开伯克利）、马丁（H. C. Martin）和托普（L. J. Topp）合作，通过推导杆与三角形板的刚度矩阵并把它们加入整体矩阵来分析三角翼；他们1956年发表在《航空科学杂志》（*Journal of the Aeronautical Sciences*）上的论文“Stiffness and deflection analysis of complex structures”通常被视为有限元法的开端，其中的组装程序就是本章的直接刚度法。更早时候，1941年赫列尼科夫（Alexander Hrennikoff）把连续体模拟为杆件构成的框架，1943年柯朗（Richard Courant）在三角形上的分片线性函数中使扭转问题的能量极小；两者当时都未被采纳，因为所需的矩阵计算要用电子计算机。克拉夫于1960年为该方法命名。
:::

::: summary
- 直接刚度法的未知量是节点位移；杆件内力由单元刚度得出，所以变形协调自动满足，超静定性无关紧要。
- 弹簧或等截面杆有$\mathbf{k}^{(e)} = k[1, -1; -1, 1]$，其中$k = EA/L$；第$m$列是第$m$个自由度取单位值时的节点力。
- 组装把单元元素加到其自由度所对应的整体行和列中；$\mathbf{K}$是对称的、稀疏的，编号良好时是带状的，半正定，并且在支承消除每一种刚体运动之前是奇异的。
- 支承通过分块引入：$\mathbf{K}_{ff}\mathbf{d}_f = \mathbf{F}_f - \mathbf{K}_{fs}\mathbf{d}_s$，然后$\mathbf{R}_s = \mathbf{K}_{sf}\mathbf{d}_f + \mathbf{K}_{ss}\mathbf{d}_s - \mathbf{F}_s$；给定的非零位移变为等效载荷。罚函数法以$\sim k/C$的误差近似实现同样的事情。
- $\mathbf{K}\mathbf{d} = \mathbf{F}$是总势能$\tfrac12\mathbf{d}^{\mathsf T}\mathbf{K}\mathbf{d} - \mathbf{d}^{\mathsf T}\mathbf{F}$的驻值条件，这一形式可以推广到连续体。
- 热应变以载荷$EA\alpha\Delta T[-1, 1]^{\mathsf T}$的形式引入；应力只由机械应变回收。变截面杆或内部受载的杆需要若干个单元，此时误差像$h^2$一样下降。
- 始终校核约束力与载荷是否平衡，并使用一套一致的单位制（N、mm、MPa最简便）。
:::

::: exercise 钢杆的刚度 {level=1 check="41.888"}
一根直径$20\,\mathrm{mm}$、长$1.5\,\mathrm{m}$的实心钢杆，$E = 200\,\mathrm{GPa}$。它的轴向刚度$k = EA/L$是多少？（以kN/mm为单位输入$k$。）
::: solution
$A = \pi(10)^2 = 314.16\,\mathrm{mm^2}$，所以$k = 200\,000 \times 314.16/1500 = 41\,888\,\mathrm{N/mm} = 41.888\,\mathrm{kN/mm}$。

::: exercise 并联弹簧 {level=1 check="5"}
两根弹簧$k_a = 50\,\mathrm{N/mm}$与$k_b = 30\,\mathrm{N/mm}$都连接节点1（固定）与节点2。$400\,\mathrm{N}$的力作用于节点2。组装$2 \times 2$整体矩阵并求$u_2$。（以mm为单位输入$u_2$。）
::: solution
两个单元都加到相同的四个位置上：$\mathbf{K} = 80\,[1, -1; -1, 1]\ \mathrm{N/mm}$。由$u_1 = 0$，$80\,u_2 = 400$，$u_2 = 5\,\mathrm{mm}$。组装自动给出并联规则$k_\text{eq} = k_a + k_b$。
:::
:::

::: exercise 一个对角元 {level=1 check="50"}
一串弹簧在节点1与2之间为$k_1 = 10\,\mathrm{kN/m}$，在节点2与3之间为$k_2 = 20\,\mathrm{kN/m}$，在节点3与4之间为$k_3 = 30\,\mathrm{kN/m}$。组装后整体矩阵的元素$K_{33}$是多少？$K_{32}$与$K_{31}$又是多少？（以kN/m为单位输入$K_{33}$。）
::: solution
节点3属于单元2与单元3，所以$K_{33} = k_2 + k_3 = 50\,\mathrm{kN/m}$。$K_{32} = -k_2 = -20\,\mathrm{kN/m}$，而$K_{31} = 0$，因为节点1与3不共享任何单元。从物理上看，$K_{33}$是在其余所有节点固定时使节点3移动一个单位所需施加在节点3上的力。
:::
:::

::: exercise 阶梯杆的端部位移 {level=2 check="0.25"}
一根左端固定的钢杆（$E = 200\,\mathrm{GPa}$）由一段面积$500\,\mathrm{mm^2}$、长$400\,\mathrm{mm}$的杆段和随后一段面积$250\,\mathrm{mm^2}$、长$300\,\mathrm{mm}$的杆段组成。自由端作用$25\,\mathrm{kN}$的拉力。建立两单元模型，求解并求出端部位移。（以mm为单位输入。）
::: solution
$k_1 = 200\,000 \times 500/400 = 250\,000\,\mathrm{N/mm}$，$k_2 = 200\,000 \times 250/300 = 166\,667\,\mathrm{N/mm}$。缩减方程组：
$$
\begin{bmatrix} k_1 + k_2 & -k_2 \\ -k_2 & k_2 \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} 0 \\ 25\,000 \end{bmatrix}.
$$
两行相加：$k_1u_2 = 25\,000$，$u_2 = 0.100\,\mathrm{mm}$；然后$u_3 = u_2 + 25\,000/k_2 = 0.100 + 0.150 = 0.250\,\mathrm{mm}$。应力为$50$与$100\,\mathrm{MPa}$。该问题是静定的，所以结果与$\sum PL/(EA)$一致。
:::
:::

::: exercise 间隙闭合 {level=2 check="6.6"}
一根铝杆（$E = 70\,\mathrm{GPa}$，$A = 200\,\mathrm{mm^2}$，$L = 500\,\mathrm{mm}$）左端（节点1）固定。其右端（节点2）承受向右$50\,\mathrm{kN}$的载荷。一根刚度为$12\,\mathrm{kN/mm}$、远端固定的弹簧，其自由端位于节点2右侧$1.0\,\mathrm{mm}$处，因此只有在节点2移动$1.0\,\mathrm{mm}$之后才被接触。求弹簧中的力。（以kN为单位，输入正数。）
::: hint
先假设不接触，检查间隙是否闭合。若闭合，弹簧作用在节点2与一个实际上“给定”在$1\,\mathrm{mm}$外的点之间。
:::
::: solution
杆的刚度$k_1 = 70\,000 \times 200/500 = 28\,000\,\mathrm{N/mm}$。不接触时$u_2 = 50\,000/28\,000 = 1.786\,\mathrm{mm} > 1.0$，所以间隙闭合。接触时，弹簧力为向左的$k_2(u_2 - 1.0)$，节点平衡给出
$$
28\,000\,u_2 + 12\,000\,(u_2 - 1.0) = 50\,000 \quad\Rightarrow\quad u_2 = \frac{62\,000}{40\,000} = 1.55\,\mathrm{mm}.
$$
弹簧力$= 12\,000 \times 0.55 = 6600\,\mathrm{N} = 6.6\,\mathrm{kN}$（压）；杆承受$28\,000 \times 1.55 = 43.4\,\mathrm{kN}$。校核：$43.4 + 6.6 = 50\,\mathrm{kN}$。这是最简单的接触问题：只有在知道哪种状态（张开或闭合）正确之后，模型才是线性的，这就是为什么在[[finite-element-method/nonlinear-analysis]]中把接触作为一种非线性来处理。
:::
:::

::: exercise 更刚的钢段 {level=2 check="43.05"}
在[[#ex-stepped]]中把钢段面积加倍为$800\,\mathrm{mm^2}$，其余不变。求左侧（钢段一侧）墙处约束力的大小。（以kN为单位输入。）
::: solution
$k_1 = 200\,000 \times 800/300 = 533\,333\,\mathrm{N/mm}$，$k_2 = 210\,000\,\mathrm{N/mm}$。$u_2 = 60\,000/743\,333 = 0.08072\,\mathrm{mm}$，$R_1 = -k_1u_2 = -43\,049\,\mathrm{N}$，所以其大小为$43.05\,\mathrm{kN}$（且$R_3 = -16.95\,\mathrm{kN}$）。加强一条传力路径会把载荷吸引过去：钢段的分担比例从56 %升至72 %。
:::
:::

::: exercise 固定杆中的热应力 {level=2 check="-80.5"}
一根铝杆（$E = 70\,\mathrm{GPa}$，$\alpha = 23 \times 10^{-6}\,\mathrm{K^{-1}}$）固定在两堵刚性墙之间，升温$50\,\mathrm{K}$。用两个等长单元建模，并证明有限元解是精确的。应力是多少？（以MPa为单位输入$\sigma$，带符号。）
::: solution
每个单元的刚度为$k = 2EA/L$，温度载荷为$EA\alpha\Delta T[-1, 1]^{\mathsf T}$。在中间节点，贡献$+EA\alpha\Delta T$（单元1）与$-EA\alpha\Delta T$（单元2）相互抵消，所以$2k\,u_2 = 0$，$u_2 = 0$。于是应力为$\sigma = E(0 - \alpha\Delta T) = -70\,000 \times 23\times10^{-6} \times 50 = -80.5\,\mathrm{MPa}$，与$A$和$L$无关，这是经典结果。有限元解是精确的，因为精确位移（$u \equiv 0$）在每个单元内都是线性的。
:::

::: exercise 罚数取多大？ {level=3 check="999"}
一个节点通过刚度为$k$的弹簧与地面相连，必须用罚函数法给它施加给定位移$\bar d$，即把$C$加到它的对角元上、把$C\bar d$加到它的载荷上（没有其他载荷作用）。推导计算出的位移，以及使强制位移的相对误差不超过$0.1\,\%$的最小比值$C/k$。（输入$C/k$。）
::: solution
唯一的方程是$(k + C)\,u = C\bar d$，所以$u = \bar d\,C/(k + C)$，相对误差为$(\bar d - u)/\bar d = k/(k + C)$。要求$k/(k + C) \le 10^{-3}$，得$k + C \ge 1000k$，即$C/k \ge 999$。实践中$C$要取大几个数量级，但又不能大到使$k$在$k + C$的舍入中丢失：在双精度（约16位有效数字）下，比值$10^{8}$仍能保留$k$的8位有效数字。
:::

::: exercise 由能量求刚度矩阵 {level=3}
对位移为线性$u(x) = (1 - x/L)\,u_1 + (x/L)\,u_2$的等截面杆单元，把应变能$U = \int_0^L \tfrac12 EA\,(du/dx)^2\,dx$写成$u_1, u_2$的二次型，并以黑塞矩阵$\partial^2U/\partial u_a\partial u_b$的形式求出$\mathbf{k}^{(e)}$。然后对面积从$A_1$线性变化到$A_2$的杆重复这一过程，保持同样的线性位移，并证明结果是以平均面积$(A_1 + A_2)/2$计算的等截面杆矩阵。
::: solution
$du/dx = (u_2 - u_1)/L$为常数，所以$U = \tfrac12 EA\,L\,(u_2 - u_1)^2/L^2 = \tfrac12 (EA/L)(u_1^2 - 2u_1u_2 + u_2^2)$。黑塞矩阵为$(EA/L)[1, -1; -1, 1]$。对变化的面积，$U = \tfrac12 E\,(u_2 - u_1)^2L^{-2}\int_0^L A(x)\,dx = \tfrac12 E\,\bar A\,(u_2 - u_1)^2/L$，其中$\bar A = (A_1 + A_2)/2$，所以$\mathbf{k}^{(e)} = (E\bar A/L)[1, -1; -1, 1]$。由于假设的应变为常数，只有$A$的积分起作用。（变截面杆的精确刚度用的是面积的调和平均，即$\int dx/A$；线性位移单元更刚，这与最小能量性质一致——假设的位移场总是高估刚度。）
:::

::: exercise 需要多少个单元？ {level=3 check="3"}
对[[#ex-taper]]中用$n$个取中点面积的等长单元建模的变截面杆，求使端部位移与精确值之差在$0.5\,\%$以内的最小$n$。然后，作为一个设计问题，提出一种能用更少单元达到同样精度的非均匀划分，并解释原因。
::: solution
由$\rho_n = \delta_n/\delta = \frac{1}{2\ln 2}\sum_{k=1}^n \frac{1/n}{1 - (k - 1/2)/(2n)}$：$\rho_2 = 0.98928$（误差1.07 %），$\rho_3 = 0.99511$（误差0.489 %），所以$n = 3$是最小值。每个单元的误差在面积相对其自身数值变化最快的地方最大，即靠近细的端部（$1/A$在那里弯曲得最厉害）。对网格进行渐变——在自由端附近用更短的单元——可以在误差最大处减小每个单元的误差；这是[[finite-element-method/convergence-meshing]]中讨论的网格渐变的第一个例子。对于这种平缓的锥度，收益很小：把两单元网格的分界点从$0.5L$移到$0.6L$，误差只从1.07 %降到0.99 %，所以仍需要第三个单元。当变化高度集中时（截面突变、应力集中），网格渐变才有回报；对于平缓、光滑的变化，均匀加密几乎一样好。用一个五行的脚本来检验这样的论断，而不是依赖直觉，正是需要养成的习惯。
:::
