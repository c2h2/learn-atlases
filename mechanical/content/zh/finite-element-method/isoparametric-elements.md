[[finite-element-method/plane-elements]]中的四边形单元是与坐标轴对齐的矩形，因为只有这样它的形函数才是$x$和$y$的简单函数。实际的网格由畸变的四边形、沿圆角和孔边走向的曲边单元，以及三维中的六面体和四面体组成。一个思想就能处理所有这些单元：在自然坐标$(\xi, \eta, \zeta)$中把每个单元都定义在一个固定的**母单元**形状——正方形、三角形、立方体——上，并用**同一组**形函数把母单元映射为实际单元、同时插值位移。这样的单元称为**等参单元**。代价是$\mathbf{k}^{(e)}$的积分不再能以封闭形式完成，因为映射在分母中引入了雅可比行列式；它们用**高斯积分**计算，而高斯积分如此高效，以至于它对单元性能的决定作用不亚于形函数。本章建立映射、雅可比矩阵、高斯积分以及积分点选得太少的后果，并概述实践中使用的高阶单元与三维单元。

## 等参映射

::: definition 等参单元 {#def-iso}
设$N_i(\xi, \eta)$（$i = 1, \dots, n$）是母单元域（对四边形为正方形$-1 \le \xi, \eta \le 1$）上的形函数，在母单元节点$i$处$N_i = 1$，在其他节点处为$0$。若一个物理节点坐标为$(x_i, y_i)$的单元，其几何形状与位移场都用这些函数插值：
$$
x = \sum_{i=1}^n N_i(\xi, \eta)\,x_i, \quad y = \sum_{i=1}^n N_i(\xi, \eta)\,y_i, \qquad u = \sum_{i=1}^n N_i(\xi, \eta)\,u_i, \quad v = \sum_{i=1}^n N_i(\xi, \eta)\,v_i,
$$ {#eq-iso}
则称它为**等参单元**。若几何所用函数的阶次低于位移，则单元为**亚参单元**；若高于位移，则为**超参单元**。
:::

对四节点四边形单元（Q4），$N_i = \tfrac14(1 + \xi_i\xi)(1 + \eta_i\eta)$把母正方形映射为任意直边凸四边形；对八节点单元（Q8），映射是二次的，边可以是抛物线弧，能很好地逼近圆。由于母单元的每条边只通过该边上的节点映射到物理单元的一条边上，共享边节点的相邻等参单元就共享整条边以及沿该边的位移：协调性自动满足。

映射还保证了任何单元为了收敛所需的两个性质。

::: proposition 等参单元能表示刚体运动与常应变 {#prop-complete}
若形函数满足$\sum_i N_i \equiv 1$，则等参单元能精确重现每一个关于$x$和$y$为线性的位移场$u = a_0 + a_1x + a_2y$，$v = b_0 + b_1x + b_2y$。特别地，它能无应变地作刚体运动，并能表示任何常应变状态。
:::

::: proof
给节点赋以线性场的值：$u_i = a_0 + a_1x_i + a_2y_i$。利用$\sum N_i = 1$与几何映射[[#eq-iso]]，插值场为$u = \sum N_iu_i = a_0\sum N_i + a_1\sum N_ix_i + a_2\sum N_iy_i = a_0 + a_1x + a_2y$。所以无论单元如何畸变，单元的位移在每一点上**就是**该线性场。对亚参单元，除非几何函数是位移函数的子集，否则同样的论证不成立；对超参单元一般也不成立——这就是等参单元成为标准的原因。
:::

## 雅可比矩阵

应变需要对$x$和$y$的导数，而形函数是用$\xi$和$\eta$给出的。由链式法则，
$$
\begin{bmatrix} \partial N_i/\partial\xi \\ \partial N_i/\partial\eta \end{bmatrix} = \underbrace{\begin{bmatrix} \partial x/\partial\xi & \partial y/\partial\xi \\ \partial x/\partial\eta & \partial y/\partial\eta \end{bmatrix}}_{\mathbf{J}}\begin{bmatrix} \partial N_i/\partial x \\ \partial N_i/\partial y \end{bmatrix}, \qquad \mathbf{J} = \begin{bmatrix} \sum \dfrac{\partial N_i}{\partial\xi}x_i & \sum \dfrac{\partial N_i}{\partial\xi}y_i \\ \sum \dfrac{\partial N_i}{\partial\eta}x_i & \sum \dfrac{\partial N_i}{\partial\eta}y_i \end{bmatrix}.
$$ {#eq-jacobian}

::: proposition 等参单元中的导数与面积 {#prop-jacobian}
在$\det\mathbf{J} \neq 0$的任一点处，
$$
\begin{bmatrix} \partial N_i/\partial x \\ \partial N_i/\partial y \end{bmatrix} = \mathbf{J}^{-1}\begin{bmatrix} \partial N_i/\partial\xi \\ \partial N_i/\partial\eta \end{bmatrix}, \qquad dA = dx\,dy = \det\mathbf{J}\;d\xi\,d\eta,
$$
于是[[finite-element-method/plane-elements]]中的单元刚度变为母正方形上的积分：
$$
\mathbf{k}^{(e)} = \int_{-1}^{1}\int_{-1}^{1}\mathbf{B}^{\mathsf T}(\xi, \eta)\,\mathbf{D}\,\mathbf{B}(\xi, \eta)\;t\,\det\mathbf{J}(\xi, \eta)\;d\xi\,d\eta.
$$ {#eq-kiso}
:::

::: proof
$N_i$通过$(\xi, \eta)$依赖于$(x, y)$；把它看作$(\xi, \eta)$的函数，$\partial N_i/\partial\xi = (\partial N_i/\partial x)(\partial x/\partial\xi) + (\partial N_i/\partial y)(\partial y/\partial\xi)$，对$\eta$同样，这就是[[#eq-jacobian]]。求$2 \times 2$矩阵的逆要求$\det\mathbf{J} \neq 0$。面积微元是二重积分的标准变量替换（[多元微积分](/learn/maths/lesson.php?c=multivariable)）：母单元的矩形$d\xi \times d\eta$映射为由$(\partial x/\partial\xi, \partial y/\partial\xi)\,d\xi$与$(\partial x/\partial\eta, \partial y/\partial\eta)\,d\eta$张成的平行四边形，其面积为$\lvert\det\mathbf{J}\rvert\,d\xi\,d\eta$；节点按逆时针编号时$\det\mathbf{J} > 0$。
:::

$\mathbf{B}$的元素现在是比值——对$\xi, \eta$的导数乘以含有$1/\det\mathbf{J}$的雅可比逆矩阵——所以对一般四边形，[[#eq-kiso]]的被积函数是有理函数，而不是多项式。只有对平行四边形，$\mathbf{J}$才是常数，被积函数才是多项式。

::: example 畸变四边形的雅可比矩阵 {#ex-jacobian}
一个Q4单元的节点为1 $(0, 0)$、2 $(40, 0)$、3 $(50, 30)$、4 $(10, 20)\,\mathrm{mm}$。求中心与四个角点处的$\mathbf{J}$与$\det\mathbf{J}$、单元面积，以及母单元点$(\xi, \eta) = (0.5, 0.5)$的物理位置。
::: solution
形函数的导数为$\partial N_i/\partial\xi = \tfrac14\xi_i(1 + \eta_i\eta)$与$\partial N_i/\partial\eta = \tfrac14\eta_i(1 + \xi_i\xi)$。在中心处，$\partial N/\partial\xi = \tfrac14[-1, 1, 1, -1]$，$\partial N/\partial\eta = \tfrac14[-1, -1, 1, 1]$，所以
$$
\frac{\partial x}{\partial\xi} = \tfrac14(-0 + 40 + 50 - 10) = 20, \quad \frac{\partial y}{\partial\xi} = \tfrac14(0 + 0 + 30 - 20) = 2.5, \quad \frac{\partial x}{\partial\eta} = \tfrac14(-0 - 40 + 50 + 10) = 5, \quad \frac{\partial y}{\partial\eta} = \tfrac14(30 + 20) = 12.5,
$$
$\mathbf{J}(0, 0) = [20, 2.5; 5, 12.5]\,\mathrm{mm}$，$\det\mathbf{J} = 250 - 12.5 = 237.5\,\mathrm{mm^2}$。在角点处重复计算，得节点1、2、3、4处$\det\mathbf{J} = 200, 300, 275, 175\,\mathrm{mm^2}$。它们都为正，所以映射有效。

面积：$\int\!\!\int\det\mathbf{J}\,d\xi\,d\eta$。对Q4，$\det\mathbf{J}$关于$\xi$与$\eta$是线性的（$\xi\eta$项相互抵消），所以它在正方形上的积分为$4\det\mathbf{J}(0, 0) = 950\,\mathrm{mm^2}$。鞋带公式给出$\tfrac12\lvert 0 \cdot 0 - 40 \cdot 0 + 40 \cdot 30 - 50 \cdot 0 + 50 \cdot 20 - 10 \cdot 30 + 10 \cdot 0 - 0 \cdot 20\rvert = \tfrac12(1200 + 1000 - 300) = 950\,\mathrm{mm^2}$。

$(0.5, 0.5)$的映射：$N = [0.0625, 0.1875, 0.5625, 0.1875]$，所以$x = 0.1875 \times 40 + 0.5625 \times 50 + 0.1875 \times 10 = 37.5\,\mathrm{mm}$，$y = 0.5625 \times 30 + 0.1875 \times 20 = 20.625\,\mathrm{mm}$。

**校核。**$\det\mathbf{J}$的角点值是该角点处相交的两条边所构成平行四边形面积的四分之一：在节点2处，边$(−40, 0)$与$(10, 30)$给出$\lvert -40 \times 30\rvert/4 = 300$。✓。
:::
:::

### 畸变与$\det\mathbf{J}$的符号

只有当$\det\mathbf{J}$在单元内处处为正时，映射才有效。对Q4，这恰好在四边形为凸时成立：若某个内角趋于$180°$，则$\det\mathbf{J}$在该角点处趋于零，而凹（箭头形）四边形在该处的$\det\mathbf{J}$为负——映射自身发生折叠。程序把这样的单元报告为错误。有效但严重畸变的单元（内角远离$90°$、长宽比大、边中节点远离边的中点）会被接受，但精度下降，因为有理被积函数难以积分，也因为畸变单元不再能表示给出良好收敛性的二次及更高阶场。网格生成器报告**雅可比比**——单元上最小与最大$\det\mathbf{J}$之比——作为质量指标；对上面的单元它为$175/300 = 0.58$，可以接受。

## 高斯积分

母正方形上的积分按被积函数在选定点上的值的加权和计算：
$$
\int_{-1}^{1}\int_{-1}^{1}g(\xi, \eta)\,d\xi\,d\eta \approx \sum_{i=1}^{n}\sum_{j=1}^{n}w_iw_j\,g(\xi_i, \eta_j).
$$
一维规则的选择是使给定点数下的精度尽可能高。

::: theorem 高斯-勒让德积分 {#thm-gauss}
设$\xi_1, \dots, \xi_n$是$n$次勒让德多项式$P_n$的根，$w_i = \int_{-1}^{1}\ell_i(\xi)\,d\xi$是通过这些点的拉格朗日多项式$\ell_i$的积分。则
$$
\int_{-1}^{1}p(\xi)\,d\xi = \sum_{i=1}^n w_i\,p(\xi_i)
$$
对每个次数不超过$2n - 1$的多项式$p$成立。没有任何$n$点规则能对所有$2n$次多项式精确。
:::

::: proof
勒让德多项式在$[-1, 1]$上正交：对每个次数低于$n$的多项式$q$，$\int_{-1}^{1}P_nq\,d\xi = 0$。用$P_n$除$p$（次数$\le 2n - 1$）：$p = qP_n + r$，其中$q$与$r$的次数$\le n - 1$。于是$\int p = \int qP_n + \int r = \int r$。另一方面，由于$\xi_i$是$P_n$的根，$\sum w_ip(\xi_i) = \sum w_iq(\xi_i)P_n(\xi_i) + \sum w_ir(\xi_i) = \sum w_ir(\xi_i)$。最后，$r$的次数$\le n - 1$，所以它等于通过这$n$个点的拉格朗日插值多项式$r = \sum r(\xi_i)\ell_i$，积分得$\int r = \sum w_ir(\xi_i)$。因此该规则对$p$是精确的。对于否定的命题，取在任意$n$个点上构造的$2n$次多项式$p = \prod_i(\xi - \xi_i)^2$：$\int p > 0$，但规则给出$0$。
:::

$n = 1$时：$\xi_1 = 0$，$w_1 = 2$（中点公式，对线性函数精确）。$n = 2$时：$P_2 = \tfrac12(3\xi^2 - 1)$，所以$\xi = \pm1/\sqrt3 = \pm0.57735$，$w = 1$（对三次多项式精确）。$n = 3$时：$\xi = 0, \pm\sqrt{3/5} = \pm0.77460$，$w = 8/9, 5/9, 5/9$（对五次多项式精确）。同样的数值也可以直接通过要求对$1, \xi, \xi^2, \dots$精确而得到：对两点，对称性给出$\xi = \pm a$，由$\int 1 = 2$得$w_1 = w_2 = 1$，由$\int\xi^2 = 2/3 = 2a^2$得$a = 1/\sqrt3$。与梯形公式或辛普森公式相比，高斯积分在同样的多项式精度下大约把函数求值次数减半——而在有限元程序中，每次求值都意味着构造$\mathbf{B}$并计算$\mathbf{B}^{\mathsf T}\mathbf{D}\mathbf{B}$。

::: example 两个积分的高斯积分 {#ex-gauss}
用一点、两点与三点高斯规则计算$\int_{-1}^{1}(\xi^3 + \xi^2)\,d\xi$与$\int_{-1}^{1}e^\xi\,d\xi$。
::: solution
**多项式。**精确值$0 + 2/3 = 0.6667$。一点：$2(0 + 0) = 0$（该规则只对一次以下精确）。两点：$(\tfrac{1}{3\sqrt3} + \tfrac13) + (-\tfrac{1}{3\sqrt3} + \tfrac13) = 0.6667$，正如定理对三次多项式所保证的那样精确；奇次项由于对称而抵消，对每个对称规则都是如此。三点：精确。

**指数函数。**精确值$e - e^{-1} = 2.350402$。一点：$2e^0 = 2.000000$（误差$15\,\%$）。两点：$e^{0.57735} + e^{-0.57735} = 2.342696$（误差$0.33\,\%$）。三点：$\tfrac59(e^{0.77460} + e^{-0.77460}) + \tfrac89 = 2.350337$（误差$0.0028\,\%$）。

**校核。**对光滑被积函数，每增加一个点精度大约提高两个数量级，因为$n$点规则的误差正比于$2n$阶导数除以大约$(2n)!$。对畸变单元的有理被积函数，收敛情况类似，但在任何有限的$n$下都不精确。
:::
:::

::: algorithm 用数值积分计算单元刚度 {#alg-stiffness}
对采用$n_G \times n_G$高斯规则的等参平面单元：
1. 令$\mathbf{k}^{(e)} = \mathbf{0}$。
2. 对每个权为$w_iw_j$的高斯点$(\xi_i, \eta_j)$：
   1. 对所有节点$a$计算$\partial N_a/\partial\xi$、$\partial N_a/\partial\eta$；
   2. 由[[#eq-jacobian]]构造$\mathbf{J}$并计算$\det\mathbf{J}$；若$\det\mathbf{J} \le 0$则报错停止；
   3. 用$\mathbf{J}^{-1}$计算$\partial N_a/\partial x$、$\partial N_a/\partial y$并组成$\mathbf{B}$；
   4. 把$w_iw_j\,t\,\det\mathbf{J}\;\mathbf{B}^{\mathsf T}\mathbf{D}\mathbf{B}$加到$\mathbf{k}^{(e)}$上。
3. 载荷向量在同一循环中用$\mathbf{N}^{\mathsf T}\mathbf{b}$积分；应力随后在同样的高斯点上计算，通常在那里精度最高。
:::

## 需要多少个积分点？

点太多浪费时间；点太少则产生的单元要么不精确，要么更糟——奇异。被积函数给出两条指导规则。

**完全积分**是对未畸变单元精确积分$\mathbf{k}^{(e)}$的规则。对Q4矩形，$\mathbf{B}$含有关于一个坐标的线性项，所以$\mathbf{B}^{\mathsf T}\mathbf{D}\mathbf{B}$对$\xi$与$\eta$各自至多是二次的：$2\times2$规则就是完全积分。对八节点Q8为$3\times3$；对九节点Q9为$3\times3$。

**减缩积分**低一阶：Q4用$1 \times 1$，Q8用$2 \times 2$。它更便宜，而且值得注意的是，常常**更**精确，因为[[finite-element-method/plane-elements]]中寄生剪切引起的变刚来自于在减缩积分点处为零的项——在Q4的中心处，寄生切应变$\gamma = \alpha\xi/b$为零。危险在于秩亏。

::: proposition 虚假零能模式 {#prop-hourglass}
用$n_p$个积分点计算、应变向量有$n_s$个分量的单元刚度矩阵，其秩至多为$n_pn_s$。若单元有$n_d$个自由度与$n_r$个刚体模式，则只要$n_d - n_r - n_pn_s$为正，它至少有这么多个**虚假零能模式**。
:::

::: proof
$\mathbf{k}^{(e)} = \sum_p w_p t\det\mathbf{J}_p\,\mathbf{B}_p^{\mathsf T}\mathbf{D}\mathbf{B}_p$是$n_p$个矩阵之和，每个矩阵的秩至多为$n_s$（$\mathbf{B}_p$的行数）。和的秩至多为各秩之和，所以$\operatorname{rank}\mathbf{k}^{(e)} \le n_pn_s$，零空间的维数至少为$n_d - n_pn_s$。在这些零向量中，$n_r$个是正当的刚体模式；其余的是在任何积分点处都不产生应变、因而不消耗能量的变形模式。
:::

对一点积分的Q4：$n_d = 8$，$n_r = 3$，$n_pn_s = 3$，所以至少有$8 - 3 - 3 = 2$个虚假模式。它们就是两个**沙漏模式**$u = \xi\eta$、$v = 0$与$u = 0$、$v = \xi\eta$，也就是弯曲模式本身：每个单元都可以无阻力地变形为沙漏形状，而在网格中这些模式可以组合成锯齿形图案，淹没真正的解。对$2 \times 2$积分的Q8：$16 - 3 - 12 = 1$个虚假模式，与Q4的模式不同，它不能在由多个单元组成的网格中传播（它是“不可传递的”），所以减缩积分的Q8单元被广泛使用。使用一点积分Q4单元的程序——在显式动力学中为了速度而很常见——会加入一个小的人工**沙漏控制**刚度，分析者必须检查人工沙漏能是否保持为应变能的一小部分（百分之几）。

::: example 畸变单元的完全积分与减缩积分 {#ex-integration}
对[[#ex-jacobian]]中的单元（钢，$E = 200\,\mathrm{GPa}$，$\nu = 0.3$，平面应力，$t = 10\,\mathrm{mm}$），分别用$1 \times 1$、$2 \times 2$、$3 \times 3$与$10 \times 10$高斯规则计算元素$k_{11}$，并在每种情况下数出$\mathbf{k}^{(e)}$的零特征值个数。
::: solution
利用[[#alg-stiffness]]（一个小程序）：

| 规则 | $k_{11}$ (kN/mm) | 零特征值个数 |
|---|---|---|
| $1 \times 1$ | 413.5 | 5 |
| $2 \times 2$ | 741.5 | 3 |
| $3 \times 3$ | 743.60 | 3 |
| $10 \times 10$ | 743.63 | 3 |

$10 \times 10$的值已收敛到五位有效数字，取作精确值。尽管被积函数是有理函数，$2 \times 2$规则的误差仍在$0.28\,\%$以内；一点规则漏掉了$k_{11}$的近一半，并留下五个零特征值——三个刚体模式加上[[#prop-hourglass]]中的两个沙漏模式。

**校核。**对未畸变的矩形，$2\times2$将是精确的；这里的误差只来自畸变。零特征值的计数是检验虚假模式的实用方法，每个单元的程序实现都应当通过这一检验。
:::
:::

::: warning 积分阶次是单元的一部分
一个程序中的“Q4”与另一个程序中的“Q4”可能是不同的单元：完全积分、选择性减缩积分（剪切项用一点、正应变项用$2\times2$）、带沙漏控制的一点积分，或非协调模式表述。它们在粗网格上给出明显不同的答案，尤其是在弯曲问题和近不可压缩材料中。请阅读单元文档，了解你所使用的是哪种表述；绝不要为了“使它更柔”而把单元切换为减缩积分却不检查沙漏模式——变形形状中出现锯齿图案或沙漏能很大，意味着结果毫无意义。
:::

## 高阶单元与三维单元

线性单元在应力变化的地方需要很多单元。二次单元能在每个单元内表示应变的线性变化和曲边边界，在光滑问题中用少得多的自由度就能达到给定精度。

- **八节点偶然族（serendipity）四边形单元（Q8）：**角节点与边中节点；完全二次项加上$\xi^2\eta$、$\xi\eta^2$项。角点函数$N_i = \tfrac14(1 + \xi_i\xi)(1 + \eta_i\eta)(\xi_i\xi + \eta_i\eta - 1)$，边中点函数如$\tfrac12(1 - \xi^2)(1 + \eta_i\eta)$。弯曲性能极佳：单层矩形Q8单元能精确表示纯弯曲。
- **九节点拉格朗日四边形单元（Q9）：**增加一个中心节点，具有完全双二次场；畸变时更稳健。
- **六节点三角形单元（T6，线性应变三角形单元）：**完全二次，是Q8的三角形对应单元；与自动三角形网格生成器配合使用。
- **三维实体单元：**8节点六面体（三线性，砖形单元）及其20节点偶然族版本，4节点四面体（常应变，弯曲时很刚）与10节点四面体。自动网格生成器用四面体填充复杂实体，所以在实践中三维应力分析依赖于**10节点二次四面体**；4节点四面体只有在网格非常细时才应用于应力计算。

一维三节点杆单元展示了二次单元的本质新特点：边中节点控制着映射。节点位于$\xi = -1, 0, 1$时，形函数为$N_1 = \tfrac12\xi(\xi - 1)$、$N_3 = 1 - \xi^2$（边中节点）与$N_2 = \tfrac12\xi(\xi + 1)$。

::: example 四分之一点单元 {#ex-quarter}
一个三节点杆单元从$x = 0$（节点1）延伸到$x = L$（节点2），其边中节点3位于$x = sL$。求雅可比$dx/d\xi$，证明只有当$\tfrac14 < s < \tfrac34$时它在整个单元内为正，并证明当$s = \tfrac14$时应变在节点1附近按$1/\sqrt{x}$变化。
::: solution
$x(\xi) = N_2L + N_3sL = L\left[\tfrac12\xi(\xi + 1) + s(1 - \xi^2)\right]$，所以
$$
J = \frac{dx}{d\xi} = L\left[\xi + \tfrac12 - 2s\xi\right] = L\left[\tfrac12 + (1 - 2s)\xi\right].
$$
$J$关于$\xi$是线性的，所以只要它在两端为正，它在$[-1, 1]$上就为正：$J(-1) = L(2s - \tfrac12) > 0$要求$s > \tfrac14$，$J(1) = L(\tfrac32 - 2s) > 0$要求$s < \tfrac34$。当$s = \tfrac12$（边中节点在中点）时$J = L/2$为常数，映射是线性的。

当$s = \tfrac14$时：$x = \tfrac{L}{4}(1 + \xi)^2$，所以$1 + \xi = 2\sqrt{x/L}$，且$J = \tfrac{L}{2}(1 + \xi) = \sqrt{xL}$，它在节点1处为零。关于$\xi$为二次的位移场，用$x$表示时是$1$、$\sqrt{x}$与$x$的组合；其应变$du/dx = (du/d\xi)/J$含有正比于$1/\sqrt{x}$的项。

**解释。**边中节点位于边长四分之一处时，单元恰好包含线弹性断裂力学中裂纹尖端处$1/\sqrt{r}$的应变奇异性。**四分之一点单元**——在裂纹尖端退化为三角形、并把相邻边中节点移到四分之一点的八节点四边形单元——是用普通有限元程序计算应力强度因子的标准方法（见[[solid-mechanics/fracture-mechanics]]）。在远离裂纹的网格中意外发生的同样移动会造成虚假的奇异性：边中节点必须保持在边的中点附近。
:::

::: quiz
一个采用一点积分Q4单元的网格给出的变形形状中，在光滑变形上叠加了规则的锯齿形位移图案，而单元中心处的应力看起来合理。发生了什么？
- [ ] 网格太细，舍入误差占主导。
- [x] 沙漏模式：一点积分使双线性$\xi\eta$模式没有刚度，而它们被载荷或支承激发了。
- [ ] 单元发生剪切闭锁。
- [ ] 某些单元的雅可比为负。
::: solution
中心点应力对$\xi\eta$模式是“盲”的，因为这些模式在$\xi = \eta = 0$处不产生应变；这就是应力看起来正常而位移已被污染的原因。补救措施：沙漏控制、完全积分或选择性积分，或者采用更细的网格并把载荷分布到若干个节点上。闭锁会使模型过刚，而不是呈波浪状；负雅可比会被报告为错误。
:::
:::

::: history
从母单元形状映射单元的思想出现在20世纪60年代初泰格（I. C. Taig）在英国电气公司（English Electric）为飞机结构撰写的一份关于四边形单元的报告中。艾恩斯（Bruce Irons）推广了这一思想，并于1966年在《美国航空航天学会会刊》（*AIAA Journal*）上发表了一篇关于刚度法中数值积分的短文；1968年，埃尔加托迪斯、艾恩斯与监凯维奇（Zienkiewicz）在《国际固体与结构杂志》（*International Journal of Solids and Structures*）上描述了用高斯积分计算的曲边等参四边形单元，正是这篇论文为这类单元命名。积分方法本身可追溯到高斯（Carl Friedrich Gauss）1814年关于近似积分的论文。20世纪70年代人们发现减缩积分与选择性积分能消除闭锁，而它们引入的沙漏模式——弗拉纳根（Flanagan）与贝利奇科（Belytschko）等人于1981年对其进行了分析——使沙漏控制成为显式碰撞与冲击程序的标准功能。
:::

::: summary
- 等参单元在母单元域上用同一组形函数插值几何与位移；若$\sum N_i = 1$，无论如何畸变，它都能表示刚体运动与常应变。
- 雅可比矩阵$\mathbf{J}$把对$\xi, \eta$的导数转换为对$x, y$的导数，且$dA = \det\mathbf{J}\,d\xi\,d\eta$；$\det\mathbf{J}$必须处处为正（凸四边形，边中节点靠近边的中点）。
- $n$点高斯-勒让德积分对$2n - 1$次多项式精确；积分点是$P_n$的根（$n = 2$时为$\pm1/\sqrt3$）。
- 完全积分（Q4为$2\times2$，Q8为$3\times3$）对未畸变单元是精确的；减缩积分能消除闭锁，但可能留下虚假零能（沙漏）模式，其个数至少为$n_d - n_r - n_pn_s$。
- 二次单元（Q8、Q9、T6、10节点四面体）在弯曲问题和曲边边界上按每个自由度计算的精度高得多；四分之一点边中节点内含$1/\sqrt r$的裂纹尖端奇异性。
:::

## 习题

::: exercise 两点高斯积分计算四次多项式 {level=1 check="2/9"}
用两点高斯规则计算$\int_{-1}^{1}\xi^4\,d\xi$。（输入该规则给出的值。）精确值是多少？为什么该规则失效？
::: solution
$\xi^4$在$\pm1/\sqrt3$处等于$1/9$，所以该规则给出$2/9 = 0.2222$，而精确值为$2/5 = 0.4$。两点规则只对不超过$2n - 1 = 3$次的多项式精确。
:::
:::

::: exercise 矩形的雅可比 {level=1 check="600"}
一个Q4单元是宽$60\,\mathrm{mm}$、高$40\,\mathrm{mm}$、与坐标轴对齐的矩形。$\det\mathbf{J}$是多少？（以mm²为单位输入。）
::: solution
$\partial x/\partial\xi = a = 30\,\mathrm{mm}$，$\partial y/\partial\eta = b = 20\,\mathrm{mm}$，非对角项为零：$\det\mathbf{J} = ab = 600\,\mathrm{mm^2}$，即面积的四分之一，因为母正方形的面积为4。
:::
:::

::: exercise 选择积分点数 {level=1 check="3"}
在某个一维单元中，刚度矩阵的被积函数是5次多项式。精确积分它所需的最少高斯点数是多少？（输入点数。）
::: solution
需要$2n - 1 \ge 5$，所以$n = 3$。
:::
:::

::: exercise 映射一个点 {level=2 check="37.5"}
对[[#ex-jacobian]]中的单元，由形函数计算母单元点$(\xi, \eta) = (0.5, 0.5)$的$x$坐标。（以mm为单位输入$x$。）
::: solution
$N_1 = \tfrac14(0.5)(0.5) = 0.0625$，$N_2 = \tfrac14(1.5)(0.5) = 0.1875$，$N_3 = \tfrac14(1.5)(1.5) = 0.5625$，$N_4 = 0.1875$。$x = 0.0625 \times 0 + 0.1875 \times 40 + 0.5625 \times 50 + 0.1875 \times 10 = 37.5\,\mathrm{mm}$。
:::
:::

::: exercise 三点高斯积分计算指数函数 {level=2 check="2.350337"}
用三点高斯规则计算$\int_{-1}^{1}e^\xi\,d\xi$。（结果保留六位小数。）
::: solution
取$\sqrt{0.6} = 0.7745967$：$e^{0.7745967} = 2.1697168$，$e^{-0.7745967} = 0.4608896$，两者之和为$2.6306065$。该规则给出$\tfrac59 \times 2.6306065 + \tfrac89 = 1.4614480 + 0.8888889 = 2.350337$，而精确值为$e - e^{-1} = 2.350402$（相对误差$2.8\times10^{-5}$）。积分点与权至少要保留七位有效数字：把$\sqrt{0.6}$舍入为$0.775$就已经改变了第五位小数。
:::
:::

::: exercise 八节点单元的虚假模式 {level=2 check="1"}
利用[[#prop-hourglass]]，八节点平面四边形单元用$2 \times 2$规则积分时有多少个虚假零能模式？（输入个数。）
::: solution
$n_d = 16$，$n_r = 3$，$n_pn_s = 4 \times 3 = 12$，所以至少有$16 - 3 - 12 = 1$个。它是单个的模式，不能在由多个单元组成的网格中传播，这就是在使用多于一个单元时减缩积分Q8单元在实践中是安全的原因。
:::
:::

::: exercise 用高斯积分求面积 {level=2 check="950"}
证明对Q4单元，$\det\mathbf{J}$是$\xi$与$\eta$的线性函数（没有$\xi\eta$项），从而一点规则能精确给出面积。对[[#ex-jacobian]]中的单元加以验证。（以mm²为单位输入面积。）
::: solution
$\partial x/\partial\xi = A_1 + A_2\eta$，$\partial y/\partial\eta = B_1 + B_2\xi$，$\partial x/\partial\eta = C_1 + A_2\xi$，$\partial y/\partial\xi = D_1 + B_2\eta$，其中常数由节点确定（同样的$A_2$与$B_2$各出现两次，因为它们都来自映射的$\xi\eta$项）。于是$\det\mathbf{J} = (A_1 + A_2\eta)(B_1 + B_2\xi) - (C_1 + A_2\xi)(D_1 + B_2\eta)$，其中$\xi\eta$项$A_2B_2\xi\eta$相互抵消。线性函数能被一点规则精确积分：面积$= 4\det\mathbf{J}(0, 0) = 4 \times 237.5 = 950\,\mathrm{mm^2}$。
:::
:::

::: exercise 推导两点规则 {level=3}
不假设对称性，通过要求对$1, \xi, \xi^2, \xi^3$精确（四个非线性方程，未知积分点$\xi_1, \xi_2$与权$w_1, w_2$），从头推导两点高斯规则。然后证明，没有任何两个点与权的选择能在精确积分较低次幂的同时也精确积分$\xi^4$。
::: solution
方程：$w_1 + w_2 = 2$，$w_1\xi_1 + w_2\xi_2 = 0$，$w_1\xi_1^2 + w_2\xi_2^2 = 2/3$，$w_1\xi_1^3 + w_2\xi_2^3 = 0$。由第二与第四个方程，$w_1\xi_1(\xi_1^2 - \xi_2^2) = 0$。$w_1 = 0$或$\xi_1 = 0$都与其他方程矛盾（例如$\xi_1 = 0$迫使$w_2\xi_2 = 0$，进而$w_2\xi_2^2 = 0 \neq 2/3$），所以$\xi_1^2 = \xi_2^2$，而两点不同，故$\xi_2 = -\xi_1$。于是$w_1 = w_2 = 1$，$2\xi_1^2 = 2/3$，$\xi_1 = 1/\sqrt3$。第五个条件$\xi_1^4 + \xi_2^4 = 2/5$将要求$2/9 = 2/5$，这是不可能的——与[[#thm-gauss]]一致。
:::
:::

::: exercise 四分之一点单元的应变奇异性 {level=3}
对[[#ex-quarter]]中$s = \tfrac14$的三节点杆，设节点位移为$u_1 = 0$、$u_2 = U$与$u_3 = U_3$。把应变$du/dx$表示为$x$的函数，并求使应变在$x = 0$处有限的$U_3$值。解释这一结果：哪些节点位移使奇异项消失？
::: solution
$u = N_2U + N_3U_3 = \tfrac12\xi(\xi + 1)U + (1 - \xi^2)U_3$，其中$1 + \xi = 2\sqrt{x/L}$，即$\xi = 2\rho - 1$，$\rho = \sqrt{x/L}$。于是$\tfrac12\xi(\xi + 1) = \rho(2\rho - 1) = 2\rho^2 - \rho$，$1 - \xi^2 = (1 - \xi)(1 + \xi) = (2 - 2\rho)(2\rho) = 4\rho - 4\rho^2$。所以$u = U(2x/L - \rho) + U_3(4\rho - 4x/L) = (2U - 4U_3)x/L + (4U_3 - U)\sqrt{x/L}$。应变为$du/dx = (2U - 4U_3)/L + (4U_3 - U)/(2\sqrt{xL})$。只有当$U_3 = U/4$时它在$x = 0$处才有限，即四分之一点节点的位移与其位置成正比，如同在均匀应变场中那样；任何其他值都会引入$1/\sqrt{x}$的应变。因此该单元既能表示均匀应变，又能表示平方根奇异应变，而这正是裂纹尖端单元所需要的。
:::
