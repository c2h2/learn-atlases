前两章由物理推理建立单元矩阵：杆是弹簧，梁服从转角位移方程。一旦单元不再是经典结构构件的一段——从板上切下的三角形、一块土体、导热肋片中的一个单元格——这种推理就无以为继了。所需要的是一个处方，它从**任何**问题的控制微分方程出发，自动地产生单元矩阵。本章就提供这样的处方。我们把微分方程改写为积分形式的**弱形式**，证明对弹性体而言它就是虚功原理和势能驻值原理（见[[solid-mechanics/energy-methods]]），然后用简单形函数的组合来近似未知函数——这就是**伽辽金法**。采用分片线性形函数时，这一处方重现了[[finite-element-method/direct-stiffness]]中的杆单元，更重要的是，它告诉我们如何处理分布载荷、弹簧与变化的物性，以及解为什么收敛。所有内容都针对一维杆来进行，使每个积分都能手算；[[finite-element-method/plane-elements]]中的二维版本是同样的论证，只是下标更多。

## 强形式

从轴向刚度为$EA(x)$、承受单位长度轴向体力$b(x)$（竖直杆的自重、土对桩的摩擦力、旋转叶片上的离心载荷）的杆上切出一个微段$dx$。轴力为$N = EA\,du/dx$，微段的平衡$N(x + dx) - N(x) + b\,dx = 0$给出下面的微分方程。

::: definition 轴向受载杆的强形式 {#def-strong}
在$0 \le x \le L$上求位移$u(x)$，使得
$$
-\frac{d}{dx}\left(EA\,\frac{du}{dx}\right) = b(x) \quad\text{当 } 0 < x < L,
$$ {#eq-strong}
在支承处满足**本质**（位移，狄利克雷（Dirichlet））边界条件$u(0) = \bar u$，在受载端满足**自然**（力，诺伊曼（Neumann））边界条件$EA\,u'(L) = \bar P$。把端部与地面相连的刚度为$k_s$的弹簧给出混合（罗宾（Robin））条件$EA\,u'(L) = -k_s\,u(L)$。**强形式**要求$u$二阶可导，并在每一点上满足[[#eq-strong]]。
:::

强形式是一个苛刻的要求。若$EA$有跳跃——阶梯杆——则$u'$也有跳跃，$u''$在台阶处不存在；若中间作用一个集中载荷，$N$有跳跃，方程必须用界面条件来补充。分片线性的有限元函数就更糟了：它们的二阶导数在每个单元内为零，在节点处没有定义。需要一种对光滑性要求更低的表述。

## 弱形式

把[[#eq-strong]]乘以任意函数$w(x)$——**权函数**或**试验函数**——并在杆上积分：
$$
-\int_0^L w\,(EAu')'\,dx = \int_0^L w\,b\,dx.
$$
对左边分部积分：$-\int_0^L w(EAu')'\,dx = \int_0^L w'EAu'\,dx - \left[w\,EAu'\right]_0^L$。在$x = L$处，自然条件把$EAu'(L)$替换为$\bar P$；在$x = 0$处我们不知道$EAu'(0)$（它是约束力），所以要求$w(0) = 0$，即试验函数在位移给定处为零。结果就是弱形式。

::: proposition 杆问题的弱形式 {#prop-weak}
设$\mathcal{S} = \{u : u(0) = \bar u,\ \int_0^L (u')^2dx < \infty\}$为**试探函数**，$\mathcal{V} = \{w : w(0) = 0,\ \int_0^L (w')^2dx < \infty\}$为**试验函数**。弱形式为：求$u \in \mathcal{S}$，使得
$$
\int_0^L \frac{dw}{dx}\,EA\,\frac{du}{dx}\,dx = \int_0^L w\,b\,dx + w(L)\,\bar P \qquad \text{对每个 } w \in \mathcal{V}.
$$ {#eq-weak}
若$u$足够光滑（二阶可导），则它是弱形式的解当且仅当它是强形式的解。
:::

::: proof
**强形式 ⇒ 弱形式：**即上面的分部积分，利用$w(0) = 0$与$EAu'(L) = \bar P$。**弱形式 ⇒ 强形式：**若$u$二阶可导，把[[#eq-weak]]的左边再分部积分回去：
$$
\int_0^L w\left[-(EAu')' - b\right]dx + w(L)\left[EAu'(L) - \bar P\right] = 0 \quad\text{对所有 } w \in \mathcal{V}.
$$
先选取在$x = L$处也为零的试验函数；于是对所有这样的$w$，积分本身为零。若方括号$r(x) = -(EAu')' - b$在某点非零，由连续性它在一个小区间上保持同一符号，而一个在该区间上为正、在其他地方为零的试验函数会使积分非零——矛盾。所以$r \equiv 0$：微分方程成立。现在积分对每个$w$都为零，剩下$w(L)[EAu'(L) - \bar P] = 0$；选取$w(L) = 1$的$w$即得自然边界条件。本质条件成立，因为$u \in \mathcal{S}$。
:::

弱形式的三个特点决定了后面的一切。

1. **较低的光滑性。**只出现一阶导数，而且只出现在积分中。连续的、在节点处有折点的分片线性$u$是容许的试探函数。
2. **$u$与$w$之间的对称性。**左边$a(w, u) = \int_0^L w'EAu'\,dx$是对称的。这正是刚度矩阵对称的原因。
3. **两类边界条件。**本质条件内建于函数空间中，必须显式地施加。自然条件出现在方程本身之中——我们从不对试探函数施加$EAu'(L) = \bar P$；它从解中近似地自动得到满足。无载荷的自由端是$\bar P = 0$的自然条件，根本不需要任何处理。

::: intuition 弱形式就是虚功
把$w$理解为**虚位移**$\delta u$：一个与支承相容（在$u$给定处$\delta u = 0$）的任意微小位移场。于是$\int_0^L \delta u'\,EAu'\,dx = \int_0^L \delta\varepsilon\,\sigma A\,dx$是实际应力在虚应变上所做的**内力虚功**，右边则是体力与端部载荷的**外力虚功**。弱形式表明：变形体处于平衡，当且仅当对每一个容许虚位移，内力虚功与外力虚功相等。分部积分就是虚功原理的数学证明。
:::

::: proposition 最小总势能原理 {#prop-mpe}
定义杆的总势能
$$
\Pi(u) = \frac12\int_0^L EA\,(u')^2\,dx - \int_0^L b\,u\,dx - \bar P\,u(L).
$$
若$EA > 0$，则弱形式的解是$\mathcal{S}$中使$\Pi$极小的唯一函数。
:::

::: proof
设$u$是[[#eq-weak]]的解，$v = u + w$是任何其他试探函数，于是$w = v - u \in \mathcal{V}$。展开二次式，
$$
\Pi(u + w) = \Pi(u) + \left[\int_0^L w'EAu'\,dx - \int_0^L bw\,dx - \bar Pw(L)\right] + \frac12\int_0^L EA\,(w')^2\,dx.
$$
方括号由弱形式为零，最后一项为正，除非$w' \equiv 0$，而结合$w(0) = 0$这意味着$w \equiv 0$。所以对每个$v \neq u$都有$\Pi(v) > \Pi(u)$。反之，极小点对所有$w$都使$\frac{d}{d\epsilon}\Pi(u + \epsilon w)\big|_{\epsilon = 0} = 0$，这就是[[#eq-weak]]。假设：线弹性（$N = EAu'$），恒载，$EA > 0$。
:::

## 近似解：瑞利-里茨法与伽辽金法

弱形式有无穷多个试验函数，未知量是一个完整的函数。为了计算，我们用有限维子集代替$\mathcal{S}$与$\mathcal{V}$。令$u_h(x) = \sum_{j=1}^n N_j(x)\,d_j + (\text{满足本质边界条件的函数})$，其中$N_j$是选定的、在$u$给定处为零的**基函数**或**形函数**，并让试验函数取遍同样的函数$N_i$：

::: definition 伽辽金法 {#def-galerkin}
**伽辽金法**寻求$u_h = \sum_j N_jd_j$（加上本质边界条件部分），使弱形式对同一组基所张成的空间中的每个试验函数$w = N_i$（$i = 1, \dots, n$）都成立。这给出$n$个线性方程
$$
\sum_{j=1}^n K_{ij}\,d_j = F_i, \qquad K_{ij} = \int_0^L N_i'\,EA\,N_j'\,dx, \qquad F_i = \int_0^L N_i\,b\,dx + N_i(L)\,\bar P.
$$ {#eq-galerkin}
当弱形式来自一个能量泛函时，伽辽金法与**瑞利-里茨法**一致，后者对系数$d_j$使$\Pi(u_h)$极小：$\partial\Pi/\partial d_i = 0$恰好就是[[#eq-galerkin]]的第$i$行。
:::

矩阵$\mathbf{K}$是对称的，因为$a(\cdot,\cdot)$是对称的；它是正定的，因为$\Pi$是严格凸的。答案的质量完全取决于$N_j$的选择。里茨用的是定义在整个物体上的多项式；有限元法用的则是只在少数几个单元上非零的函数。

::: example 一项与两项里茨解 {#ex-ritz}
一根长$L = 2\,\mathrm{m}$、$EA = 1.0\times10^{8}\,\mathrm{N}$（钢，$A = 500\,\mathrm{mm^2}$）的杆在$x = 0$处固定，在$x = L$处自由。它承受从零线性增大的体力$b(x) = b_0\,x/L$，$b_0 = 30\,\mathrm{kN/m}$。求取$u_h = a_1x$和$u_h = a_1x + a_2x^2$时的里茨近似，并把端部位移与根部应力同精确解比较。
::: solution
**精确解。**在$u(0) = 0$与$EAu'(L) = 0$下积分$EAu'' = -b_0x/L$：
$$
u(x) = \frac{b_0}{2EA\,L}\left(L^2x - \frac{x^3}{3}\right), \qquad u(L) = \frac{b_0L^2}{3EA}, \qquad N(0) = EAu'(0) = \frac{b_0L}{2}.
$$
代入数值：$u(L) = 30\,000 \times 4/(3\times10^{8}) = 4.00\times10^{-4}\,\mathrm{m} = 0.400\,\mathrm{mm}$，$N(0) = 30\,\mathrm{kN}$，即$\sigma(0) = 60\,\mathrm{MPa}$。

**一项。**$u_h = a_1x$满足$u(0) = 0$。$\Pi = \tfrac12 EAa_1^2L - a_1\int_0^L (b_0x/L)\,x\,dx = \tfrac12EAa_1^2L - a_1b_0L^2/3$。令$d\Pi/da_1 = 0$：$a_1 = b_0L/(3EA)$。端部：$a_1L = b_0L^2/(3EA) = 0.400\,\mathrm{mm}$——精确。根部力：$EAa_1 = b_0L/3 = 20\,\mathrm{kN}$（$40\,\mathrm{MPa}$），低了三分之一。

**两项。**取$u_h = a_1x + a_2x^2$，两个方程$\partial\Pi/\partial a_1 = \partial\Pi/\partial a_2 = 0$为
$$
EA\begin{bmatrix} L & L^2 \\ L^2 & \tfrac43L^3 \end{bmatrix}\begin{bmatrix} a_1 \\ a_2 \end{bmatrix} = b_0\begin{bmatrix} L^2/3 \\ L^3/4 \end{bmatrix},
$$
其解为$a_1 = 7b_0L/(12EA)$，$a_2 = -b_0/(4EA)$。端部：$(7/12 - 1/4)\,b_0L^2/EA = b_0L^2/(3EA) = 0.400\,\mathrm{mm}$——又是精确的。根部力$EAa_1 = 7b_0L/12 = 35\,\mathrm{kN}$（$70\,\mathrm{MPa}$），现在高了17 %。

**校核与解释。**应变能与精确值之比为$5/6$（一项）与$95/96$（两项）：能量收敛得很快，而且从下方收敛，正如[[#prop-mpe]]所要求的（在更小的集合上求极小只能给出更大的$\Pi$，而对本问题，在解处$\Pi = -U$）。位移比应力收敛得快，应力误差在边界处最大——这一规律在每个有限元模型中都存在。
:::
:::

## 有限元形函数

把$[0, L]$划分为单元，节点为$x_1 < x_2 < \dots < x_{n+1}$。**帽函数**$N_i$在节点$i$处等于1，在其他每个节点处等于0，并在每个单元上是线性的。它只在与节点$i$相邻的两个单元上非零，所以除非节点$i$与$j$共享一个单元，否则$K_{ij} = 0$——直接刚度法的稀疏性，现在被推导出来了。任何连续的分片线性函数都是$u_h = \sum_i N_i\,u_i$，其中$u_i = u_h(x_i)$：系数就是**节点位移**。

在从$x_i$到$x_j$、长为$L_e$的一个单元上，只有$N_i = (x_j - x)/L_e$与$N_j = (x - x_i)/L_e$非零。由于[[#eq-galerkin]]中的积分可拆分为对各单元的求和，整体矩阵由单元矩阵组装而成：

::: proposition 由伽辽金法得到的线性杆单元 {#prop-element}
对$EA$为常数、采用上述线性形函数的两节点单元，
$$
\mathbf{k}^{(e)} = \int_{x_i}^{x_j}\begin{bmatrix} N_i' \\ N_j' \end{bmatrix}EA\begin{bmatrix} N_i' & N_j' \end{bmatrix}dx = \frac{EA}{L_e}\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}, \qquad \mathbf{f}^{(e)} = \int_{x_i}^{x_j}\begin{bmatrix} N_i \\ N_j \end{bmatrix}b\,dx.
$$ {#eq-element}
对均匀体力$b$，$\mathbf{f}^{(e)} = \tfrac12 bL_e\,[1, 1]^{\mathsf T}$；对从$b_i$线性变化到$b_j$的$b$，$\mathbf{f}^{(e)} = \tfrac{L_e}{6}\,[2b_i + b_j,\ b_i + 2b_j]^{\mathsf T}$。
:::

::: proof
$N_i' = -1/L_e$与$N_j' = 1/L_e$为常数，所以$\int N_a'EAN_b'\,dx = EA\,L_e\,(\pm 1/L_e^2)$，这给出杆矩阵。对载荷，$\int N_i\,dx = \int N_j\,dx = L_e/2$。对线性载荷写$b = b_iN_i + b_jN_j$；则$\int N_i^2\,dx = L_e/3$，$\int N_iN_j\,dx = L_e/6$，所以$f_i = b_iL_e/3 + b_jL_e/6$，$f_j$同理。总和$f_i + f_j = (b_i + b_j)L_e/2$是载荷的合力，其分配使载荷较大的节点分得更多。
:::

因此第一章的直接刚度法就是采用帽函数的伽辽金法。新的东西是载荷向量：分布载荷不是凭判断“集中”，而是由形函数分配，$\int\mathbf{N}^{\mathsf T}b\,dx$，这是真实载荷在节点虚位移上所做的虚功。这些就是**一致**节点载荷；[[finite-element-method/trusses-frames]]中的梁载荷$qL/2$与$qL^2/12$来自采用埃尔米特函数的同一公式。

::: example 均布载荷下的两个线性单元 {#ex-two-elements}
[[#ex-ritz]]中的杆改为承受均匀体力$b = 20\,\mathrm{kN/m}$。用两个等长线性单元求解，并把位移与轴力同精确解比较。
::: solution
$L_e = 1\,\mathrm{m}$，$EA/L_e = 1.0\times10^{8}\,\mathrm{N/m}$，一致载荷为每个单元端$bL_e/2 = 10\,\mathrm{kN}$。组装后的载荷：节点1（支承）10 kN，节点2 20 kN，节点3 10 kN。由$u_1 = 0$：
$$
10^{8}\begin{bmatrix} 2 & -1 \\ -1 & 1 \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} 20\,000 \\ 10\,000 \end{bmatrix}\ \mathrm{N} \quad\Rightarrow\quad u_2 = 3.0\times10^{-4}\,\mathrm{m}, \quad u_3 = 4.0\times10^{-4}\,\mathrm{m}.
$$
精确解：$u = \frac{b}{EA}\left(Lx - \frac{x^2}{2}\right)$给出$u(1) = 2\times10^{-4}(2 - 0.5) = 3.0\times10^{-4}\,\mathrm{m}$与$u(2) = 4.0\times10^{-4}\,\mathrm{m}$：节点值是精确的。

轴力：单元1，$N = EA(u_2 - u_1)/L_e = 30\,\mathrm{kN}$；单元2，$N = 10\,\mathrm{kN}$。精确的力$N(x) = b(L - x)$是线性的，从根部的40 kN到端部的0；单元给出的常数等于精确力**在单元中点处**的值（$x = 0.5$：30 kN；$x = 1.5$：10 kN），但在单元端部相差10 kN。由第1行得到的约束力$R_1 = -10^8 u_2 - 10\,000 = -40\,\mathrm{kN}$是精确的，因为它来自采用一致载荷的整体平衡。

**校核。**总载荷$bL = 40\,\mathrm{kN}$与约束力平衡。在单元中点而非节点处读取应力，是应力回收的最简单形式，将在[[finite-element-method/convergence-meshing]]中讨论。
:::
:::

节点值精确并非偶然。

::: theorem 伽辽金正交性与最佳逼近 {#thm-best}
设$u$是弱形式的解，$u_h$是有限维空间$\mathcal{V}_h \subset \mathcal{V}$中的伽辽金解（具有相同的本质边界条件部分）。记$a(v, w) = \int_0^L v'EAw'\,dx$，能量范数$\|v\|_E = \sqrt{a(v, v)}$。则
1. （**正交性**）对每个$w_h \in \mathcal{V}_h$，$a(w_h, u - u_h) = 0$；
2. （**最佳逼近**）对试探空间中每个容许的$v_h$，$\|u - u_h\|_E \le \|u - v_h\|_E$：以应变能度量，伽辽金解是该空间中最接近精确解的函数。
:::

::: proof
(1) 精确解对所有$w \in \mathcal{V}$满足[[#eq-weak]]，特别是对$w_h \in \mathcal{V}_h$；伽辽金解按构造对这些$w_h$满足同一方程。相减得$a(w_h, u - u_h) = 0$。(2) 设$v_h$是另一个试探函数；则$w_h = u_h - v_h \in \mathcal{V}_h$。利用对称性与正交性，
$$
\|u - v_h\|_E^2 = \|(u - u_h) + w_h\|_E^2 = \|u - u_h\|_E^2 + 2a(w_h, u - u_h) + \|w_h\|_E^2 = \|u - u_h\|_E^2 + \|w_h\|_E^2 \ge \|u - u_h\|_E^2.
$$
假设：$a$对称正定（$EA > 0$，支承充分），积分精确计算。
:::

该定理把“有限元解有多精确？”这个问题，转化为容易得多的问题“这个空间中的函数能多好地逼近精确解？”——这是一个插值问题，[[finite-element-method/convergence-meshing]]用单元尺寸的幂次来回答它。它也解释了[[finite-element-method/direct-stiffness]]中看到的变刚现象：由(1)取$w_h = u_h$，$a(u_h, u_h) = a(u, u_h)$，这在只施加力时导出$U(u_h) = U(u) - \tfrac12\|u - u_h\|_E^2 \le U(u)$——基于位移的模型储存的应变能太少，即它过刚。

::: proposition 一维中的节点精确性 {#prop-nodal}
对于$EA$在每个单元上为常数的杆问题，采用线性单元并精确积分一致载荷的伽辽金解在每个节点处都等于精确解，无论载荷$b(x)$是什么。
:::

::: proof
固定一个节点$x_k$（不是支承）。考虑函数$g_k(x)$，它是无体力、在$x = 0$处固定、在$x = L$处自由、在$x_k$处作用单位集中载荷的杆问题的解：它是单位载荷引起的位移，$g_k(x) = \int_0^{\min(x, x_k)}dx'/EA$。在$EA$于每个单元上为常数的情况下，$g_k$在每个单元上是线性的，且连续：它属于有限元空间。其弱形式为对每个试验函数$w$有$a(w, g_k) = w(x_k)$（单位载荷所做的功）。取在$x = 0$处为零的$w = u - u_h$：由伽辽金正交性，因为$g_k \in \mathcal{V}_h$，$(u - u_h)(x_k) = a(u - u_h, g_k) = a(g_k, u - u_h) = 0$。因此$u_h(x_k) = u(x_k)$。
:::

节点精确性是特殊的：一旦方程中含有另一项（下面的弹性地基上的杆）、在二维中、或积分是近似计算时，它就不再成立。一般情况下保留下来的是[[#thm-best]]的最佳逼近性质。

## 实践中的自然边界条件

::: example 端部弹簧 {#ex-spring-end}
[[#ex-two-elements]]中的杆（均匀$b = 20\,\mathrm{kN/m}$，两个单元）现在在$x = L$处通过弹簧$k_s = 5.0\times10^{7}\,\mathrm{N/m}$与地面相连。推导弹簧如何进入方程并求解。
::: solution
端部条件现在是$EAu'(L) = -k_su(L)$（弹簧向回推）。在弱形式中边界项$w(L)\,EAu'(L)$变为$-k_s\,w(L)\,u(L)$；把它移到左边，
$$
\int_0^L w'EAu'\,dx + k_s\,w(L)\,u(L) = \int_0^L w\,b\,dx.
$$
取$w = N_i$与$u_h = \sum N_ju_j$，新的一项只在端部节点的对角元上加上$k_s$——弹簧就像一个连接到固定节点的弹簧单元那样被组装。方程组变为
$$
\begin{bmatrix} 2\times10^{8} & -1\times10^{8} \\ -1\times10^{8} & 1\times10^{8} + 5\times10^{7} \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} 20\,000 \\ 10\,000 \end{bmatrix},
$$
其解为$u_2 = u_3 = 2.0\times10^{-4}\,\mathrm{m}$。弹簧力$k_su_3 = 10\,\mathrm{kN}$，墙的约束力30 kN。

**校核。**精确解：$u = -\frac{b}{2EA}x^2 + Cx$，$C$由$EAu'(L) = -k_su(L)$确定，得$C = 3.0\times10^{-4}$，$u(1) = u(2) = 2.0\times10^{-4}\,\mathrm{m}$：又是节点精确的。载荷平衡：$30 + 10 = 40\,\mathrm{kN}$。注意，端部的单元应变**并不**满足自然条件$EAu'(L) = -k_su(L)$（单元2有$u' = 0$）；它只在弱的、积分的意义上得到满足。
:::
:::

::: example 弹性地基上的杆 {#ex-foundation}
埋在土中的桩可以模拟为带分布弹簧支承的杆：$-(EAu')' + k_fu = b$。取无量纲形式$-u'' + u = 1$，$0 < x < 1$，$u(0) = 0$，$u'(1) = 0$。求线性单元的伽辽金方程以及用一个单元求得的端部位移；与精确值$u(1) = 1 - 1/\cosh 1$比较。
::: solution
弱形式增加一项$\int_0^1 w\,u\,dx$，所以每个单元除刚度$\frac{1}{L_e}[1, -1; -1, 1]$外，还得到一个**地基矩阵**$\int\mathbf{N}^{\mathsf T}\mathbf{N}\,dx = \frac{L_e}{6}[2, 1; 1, 2]$（与[[#prop-element]]中线性载荷的积分相同）。用一个单元（$L_e = 1$）且$u_1 = 0$时，只有$(2,2)$元素起作用：$(1 + \tfrac13)u_2 = \tfrac12$，所以$u_2 = 0.375$。精确解：$u = 1 - \cosh(1 - x)/\cosh 1$，$u(1) = 1 - 1/1.5431 = 0.3519$。误差$6.6\,\%$。用四个单元时计算得到的端部值为$0.3532$（误差$0.37\,\%$）。

**校核。**答案不再是节点精确的，因为地基上的杆的单位载荷响应由指数函数而非线性段组成，所以[[#prop-nodal]]的论证不再成立。它仍然收敛，而且从预期的一侧收敛：$L_e$每减半一次，误差约缩小为1/4。
:::
:::

::: warning 本质条件不可省略
伽辽金法自动施加自然条件，而从不施加本质条件。忘记施加$u(0) = 0$会留下奇异矩阵（刚体模式）；把**自然**条件当作本质条件来施加——例如用约束使自由端的应变为零，或在对称面上约束了错误的方向——会使模型过约束，所得答案收敛于另一个问题的解。对每一段边界都要判断哪个量是已知的：若是位移，就约束它；若是力（包括零力），就把它留给弱形式，并把任何非零值放入$\mathbf{F}$。
:::

::: quiz
对梁方程$EI\,v'''' = q$，弱形式通过两次分部积分得到。哪些边界量是本质的？
- [x] 挠度$v$与转角$v'$。
- [ ] 弯矩$EIv''$与剪力$EIv'''$。
- [ ] 只有挠度。
- [ ] 全部四个，因为方程是四阶的。
::: solution
两次分部积分之后，弱形式$\int w''EIv''\,dx = \int wq\,dx + [\dots]$的边界项中含有分别与剪力和弯矩相乘的$w$与$w'$。与试验函数及其一阶导数配对的量——$v$与$v'$——是本质的，必须内建于试探空间中；弯矩与剪力是自然的。这就是为什么梁单元以挠度和转角为自由度，以及为什么其形函数必须连续且斜率连续（埃尔米特三次函数）。
:::
:::

## 其他加权余量法

伽辽金的选择$w = N_i$只是一个方法族中的一员。把近似$u_h$代入强形式会留下**余量**$r = -(EAu_h')' - b$，而每种**加权余量法**都对$n$个选定的权要求$\int_0^L w_ir\,dx = 0$。**配点法**取$w_i$为狄拉克$\delta$函数，强迫$r$在$n$个点上为零；它需要二阶可导的试探函数，并给出非对称矩阵。**最小二乘法**取$w_i = \partial r/\partial d_i$，使$\int r^2\,dx$极小；它是对称的，但同样需要二阶导数，且矩阵条件数差。**子域法**强迫$r$在每个单元格上的积分为零，这正是计算流体力学中所用有限体积法的实质。伽辽金法对于对称问题能重现能量原理，给出对称正定矩阵，降低所需的光滑性，并具有最佳逼近性质；这就是它成为固体力学与热传导标准方法的原因。对于强对流流动，算子不对称，这时改用$w \neq N$的修正权（彼得罗夫-伽辽金（Petrov–Galerkin）法）。

::: history
这些要素比计算机更古老。瑞利勋爵（Lord Rayleigh）在《声学理论》（*The Theory of Sound*，1877年）中把假设的挠曲形状代入能量表达式来估算固有频率；里茨（Walther Ritz）在1908—1909年把它发展为采用若干试探函数并讨论收敛性的系统方法，伽辽金（Boris Galerkin）在1915年发表了用试探函数本身对方程加权的方法，它不需要能量泛函。他们的试探函数遍及整个物体，这使得它们对复杂形状不实用。柯朗（Richard Courant）1943年关于扭转的论文采用里茨法，所用函数在网格的每个三角形上是线性的——即二维的帽函数——因此常被引为有限元法在数学上的诞生；工程师们在20世纪50年代通过直接刚度法独立地得到了同样的矩阵，而大约在1960—1965年两者被认同，赋予了该方法理论基础与普遍性。
:::

::: summary
- 强形式要求微分方程在每一点成立；弱形式通过乘以试验函数$w$并分部积分得到，只需要一阶导数，对光滑解与强形式等价。
- 本质边界条件（位移）施加于试探函数，试验函数在该处为零；自然条件（力、弹簧）出现在弱形式本身之中。
- 对弹性力学，弱形式就是虚功原理，其解使总势能极小。
- 伽辽金法对试探与试验使用同样的函数，给出对称的$K_{ij} = \int N_i'EAN_j'\,dx$与一致载荷$F_i = \int N_ib\,dx$；采用帽函数时它重现杆单元。
- 伽辽金正交性使有限元解成为能量范数下的最佳逼近；因此位移模型过刚，低估应变能。
- 在一维中，当$EA$分片为常数时，线性单元在节点处是精确的；应力只在单元中点附近精确，并且比位移收敛慢一阶。
:::

## 习题

::: exercise 均匀体力的一致载荷 {level=1 check="0.5"}
一个长$0.5\,\mathrm{m}$的线性杆单元承受均匀轴向体力$b = 2\,\mathrm{kN/m}$。每个节点处的一致节点载荷是多少？（以kN为单位输入。）
::: solution
每个节点为$bL_e/2 = 2 \times 0.5/2 = 0.5\,\mathrm{kN}$。
:::
:::

::: exercise 用一个单元计算悬挂杆 {level=1 check="0.4813"}
一根长$50\,\mathrm{m}$的钢杆（$E = 200\,\mathrm{GPa}$，$\rho = 7850\,\mathrm{kg/m^3}$，$A = 400\,\mathrm{mm^2}$，$g = 9.81\,\mathrm{m/s^2}$）从顶端悬挂。用一个线性单元和一致自重载荷建模，求底端的伸长。（以mm为单位输入。）
::: solution
$b = \rho gA = 7850 \times 9.81 \times 4\times10^{-4} = 30.80\,\mathrm{N/m}$。自由节点处的一致载荷为$bL/2 = 770.0\,\mathrm{N}$，$k = EA/L = 200\times10^9 \times 4\times10^{-4}/50 = 1.6\times10^{6}\,\mathrm{N/m}$，所以$u = 770.0/1.6\times10^{6} = 4.813\times10^{-4}\,\mathrm{m} = 0.4813\,\mathrm{mm}$。这等于精确值$\rho gL^2/(2E)$，正如[[#prop-nodal]]所预言的；单元应力$3.85/2 = 1.93\,\mathrm{MPa}$是中点处的真实值，而顶端处的真实最大值为$\rho gL = 3.85\,\mathrm{MPa}$。
:::
:::

::: exercise 三角形载荷 {level=1 check="3"}
一个长$1.5\,\mathrm{m}$的线性单元承受从节点$i$处的0线性变化到节点$j$处的$6\,\mathrm{kN/m}$的轴向体力。求一致载荷。（以kN为单位输入$f_j$。）
::: solution
由[[#prop-element]]，取$b_i = 0$，$b_j = 6$：$f_i = L_e(b_j)/6 = 1.5\,\mathrm{kN}$，$f_j = L_e(2b_j)/6 = 3.0\,\mathrm{kN}$。总和为$4.5\,\mathrm{kN}$，即三角形载荷的合力，按1 : 2的比例分配，因为合力作用在长度的三分之二处。
:::
:::

::: exercise 两项里茨解的根部应力 {level=2 check="70"}
通过计算积分验证[[#ex-ritz]]的两项里茨方程，求解它们，并在$A = 500\,\mathrm{mm^2}$下计算根部应力$EAu_h'(0)/A$。（以MPa为单位输入。）
::: solution
取$u_h' = a_1 + 2a_2x$，$\int_0^L (u_h')^2dx$给出矩阵元素$L$、$L^2$与$\tfrac43L^3$；载荷项为$\int b\,x\,dx = b_0L^2/3$与$\int b\,x^2\,dx = b_0L^3/4$。求解得：$a_1 = 7b_0L/(12EA)$。根部力$EAa_1 = 7 \times 30 \times 2/12 = 35\,\mathrm{kN}$；应力$35\,000/500 = 70\,\mathrm{MPa}$（精确值60 MPa）。
:::
:::

::: exercise 一项解的能量 {level=2 check="5/6"}
对[[#ex-ritz]]，计算一项里茨解的应变能与精确应变能之比。（以数值输入该比值。）
::: solution
$U_h = \tfrac12EA\,a_1^2L = \tfrac12EA(b_0L/3EA)^2L = b_0^2L^3/(18EA)$。精确值：$u' = \frac{b_0}{2EAL}(L^2 - x^2)$，$U = \frac{EA}{2}\int_0^L(u')^2dx = \frac{b_0^2}{8EAL^2}\int_0^L(L^2 - x^2)^2dx = \frac{b_0^2}{8EAL^2}\cdot\frac{8L^5}{15} = \frac{b_0^2L^3}{15EA}$。比值$= 15/18 = 5/6$。它小于一，正如最佳逼近定理对受力载荷的位移模型所要求的。
:::
:::

::: exercise 更刚的端部弹簧 {level=2 check="13.333"}
取$k_s = 1.0\times10^{8}\,\mathrm{N/m}$重做[[#ex-spring-end]]。求弹簧力。（以kN为单位输入。）
::: solution
$10^{8}[2, -1; -1, 2][u_2, u_3]^{\mathsf T} = [20\,000, 10\,000]^{\mathsf T}$；行列式为$3\times10^{16}$，所以$u_3 = 10^{8}(20\,000 + 2 \times 10\,000)/(3\times10^{16}) = 1.333\times10^{-4}\,\mathrm{m}$，$u_2 = 1.667\times10^{-4}\,\mathrm{m}$。弹簧力$= 10^{8} \times 1.333\times10^{-4} = 13.33\,\mathrm{kN}$；墙的约束力$26.67\,\mathrm{kN}$。弹簧越刚，吸引的载荷越多，当$k_s \to \infty$时趋于20 kN（由对称性，为载荷的一半）。
:::

::: exercise 用两个单元求解地基问题 {level=3 check="0.35723"}
用两个等长线性单元手算求解[[#ex-foundation]]的问题，并给出端部值$u(1)$。（至少给出四位有效数字。）
::: solution
$L_e = \tfrac12$：每个单元贡献$2[1, -1; -1, 1] + \tfrac{1}{12}[2, 1; 1, 2]$，载荷为$\tfrac14[1, 1]$。由$u_1 = 0$：
$$
\begin{bmatrix} 4 + \tfrac13 & -2 + \tfrac1{12} \\ -2 + \tfrac1{12} & 2 + \tfrac16 \end{bmatrix}\begin{bmatrix} u_2 \\ u_3 \end{bmatrix} = \begin{bmatrix} \tfrac12 \\ \tfrac14 \end{bmatrix}.
$$
行列式$= \tfrac{13}{3}\cdot\tfrac{13}{6} - \left(\tfrac{23}{12}\right)^2 = 9.3889 - 3.6736 = 5.7153$。$u_3 = \left(\tfrac{13}{3}\cdot\tfrac14 + \tfrac{23}{12}\cdot\tfrac12\right)/5.7153 = (1.08333 + 0.95833)/5.7153 = 0.35723$。精确值0.35194：误差1.5 %，而一个单元时为6.6 %——单元尺寸减半，误差缩小为1/4.4。
:::

::: exercise 梁方程的弱形式 {level=3}
从$0 < x < L$上的$(EIv'')'' = q$出发，乘以试验函数$w$并分部积分两次。写出在$x = 0$处固定、在$x = L$处承受端部力$\bar F$与端部力矩$\bar M$的悬臂梁的弱形式，给出试验空间与试探空间，并证明采用埃尔米特函数的伽辽金法给出梁单元刚度$\int\mathbf{B}^{\mathsf T}EI\mathbf{B}\,dx$（$\mathbf{B} = \mathbf{N}''$）与一致载荷$\int\mathbf{N}^{\mathsf T}q\,dx$。
::: solution
$\int_0^Lw(EIv'')''dx = [w(EIv'')']_0^L - [w'EIv'']_0^L + \int_0^Lw''EIv''dx$。取剪力$V = -(EIv'')'$与弯矩$M = EIv''$（符号约定同[[finite-element-method/trusses-frames]]），对向上的力与逆时针的力矩，端部条件为$(EIv'')'(L) = -\bar F$与$EIv''(L) = \bar M$。要求$w(0) = w'(0) = 0$消去了固定端处的未知约束力。弱形式：求满足$v(0) = v'(0) = 0$且$v''$平方可积的$v$，使得
$$
\int_0^L w''EIv''\,dx = \int_0^L wq\,dx + w(L)\bar F + w'(L)\bar M \quad\text{对所有这样的 } w.
$$
试探函数与试验函数需要$v$与$v'$连续（$C^1$）。代入$v = \mathbf{N}\mathbf{d}$，$w = N_i$，得$\sum_j\left(\int N_i''EIN_j''dx\right)d_j = \int N_iq\,dx + N_i(L)\bar F + N_i'(L)\bar M$：即刚度$\int\mathbf{B}^{\mathsf T}EI\mathbf{B}\,dx$、一致载荷，以及进入端部节点$v$行与$\theta$行的端部力与力矩。
:::
:::

::: exercise 有限元解何时精确？ {level=3}
利用[[#prop-nodal]]与[[#thm-best]]解释：(a) 为什么线性杆单元对任意轴向载荷下的阶梯杆给出精确的节点位移；(b) 为什么对于用等面积单元模拟的连续变截面杆却不是这样；(c) 为什么[[finite-element-method/trusses-frames]]中的梁单元在均布载荷下给出精确的节点位移与转角。这些精确情形的“单位载荷响应”有什么共同性质？
::: solution
(a) 当$EA$在每个单元上为常数时，单位载荷响应$g_k(x) = \int_0^{\min(x, x_k)}dx/EA$是分片线性的，折点只在节点处（把台阶放在节点处），所以它属于有限元空间，正交性论证给出节点精确性。(b) 如果模型用单元常数代替变截面的$EA(x)$，它求解的是一个**不同的**问题（阶梯杆）；其节点值对阶梯杆是精确的，但对变截面杆不是。即使在单元矩阵中对精确的$EA(x)$积分，变截面杆的$g_k$也不是分片线性的，所以论证不成立。(c) 对等截面梁，节点处单位集中载荷或单位力矩引起的挠度是分段三次的，在节点之间为三次多项式，斜率连续：它属于埃尔米特函数张成的空间。共同的性质是：节点值的格林函数（影响函数）属于有限元空间；于是无论载荷如何，伽辽金正交性都迫使节点误差为零。
:::
:::
