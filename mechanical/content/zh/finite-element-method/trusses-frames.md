在[[finite-element-method/direct-stiffness]]中，每个节点都沿一条直线运动。实际结构可没有这么配合：桁架的杆件指向许多方向，刚架的杆件既伸长又弯曲。本章为任意形状的杆系结构补充所需的两个要素。第一个是**坐标变换**，它用杆两端的水平与竖直位移来表示倾斜杆的刚度，从而使不同方位的杆件能够在公共节点处组装。第二个是**梁单元**，其节点除横向位移外还有转角，其刚度由[[mechanics-of-materials/beam-deflection]]中的三次挠曲线得出。把杆与梁结合起来就得到**平面刚架单元**，用它可以分析房屋框架、机器底盘或起重机臂架。一切都与以前完全一样地组装和求解；只有单元矩阵改变了。

## 平面桁架单元

桁架杆件是两端铰接、只在节点处受载的杆，因此只承受轴力（见[[statics/trusses]]）。在其自身的**局部**坐标$\hat x$（由节点$i$指向节点$j$）中，它就是上一章刚度为$EA/L$的杆单元。然而节点在二维中运动，一个节点处的整体位移分量$(u, v)$由在该处相交的每根杆件所共享。

::: definition 方向余弦与平面桁架单元 {#def-truss}
设杆从位于$(x_i, y_i)$的节点$i$延伸到位于$(x_j, y_j)$的节点$j$，长度为$L = \sqrt{(x_j - x_i)^2 + (y_j - y_i)^2}$。其**方向余弦**为
$$
c = \cos\theta = \frac{x_j - x_i}{L}, \qquad s = \sin\theta = \frac{y_j - y_i}{L},
$$
其中$\theta$从整体$x$轴起按逆时针方向量取。每个节点有两个自由度，$u$（沿$x$）与$v$（沿$y$）；单元位移向量为$\mathbf{d}^{(e)} = [u_i, v_i, u_j, v_j]^{\mathsf T}$。精确到位移的一阶，杆的**伸长量**是相对位移在杆轴上的投影：
$$
\delta = (u_j - u_i)\,c + (v_j - v_i)\,s.
$$ {#eq-elongation}
:::

伸长量公式是一个小位移命题。把节点$j$沿侧向（垂直于杆）移动$w$，长度只改变$w^2/(2L)$，这是二阶量，被忽略了；这就是为什么单根杆对侧向运动不提供刚度，以及为什么杆的横向自由度只能由其他杆件承担。被忽略的这一项在[[finite-element-method/nonlinear-analysis]]中变得重要。

::: proposition 平面桁架单元的刚度 {#prop-truss-k}
在整体坐标中，平面桁架单元有
$$
\mathbf{k}^{(e)} = \frac{EA}{L}\begin{bmatrix} c^2 & cs & -c^2 & -cs \\ cs & s^2 & -cs & -s^2 \\ -c^2 & -cs & c^2 & cs \\ -cs & -s^2 & cs & s^2 \end{bmatrix} = \mathbf{T}^{\mathsf T}\,\hat{\mathbf{k}}\,\mathbf{T}, \qquad \mathbf{T} = \begin{bmatrix} c & s & 0 & 0 \\ 0 & 0 & c & s \end{bmatrix},
$$ {#eq-truss-k}
其中$\hat{\mathbf{k}} = (EA/L)[1, -1; -1, 1]$是局部杆刚度。轴力与应力由$N = (EA/L)\,\delta$和$\sigma = N/A$回收，其中$\delta$由[[#eq-elongation]]给出。
:::

::: proof
局部轴向位移是投影$\hat u_i = c\,u_i + s\,v_i$与$\hat u_j = c\,u_j + s\,v_j$，即$\hat{\mathbf{d}} = \mathbf{T}\mathbf{d}^{(e)}$。局部节点力$\hat{\mathbf{f}} = \hat{\mathbf{k}}\hat{\mathbf{d}}$沿杆轴作用，所以它们的整体分量为$\mathbf{f}^{(e)} = \mathbf{T}^{\mathsf T}\hat{\mathbf{f}}$（沿杆轴的力$\hat f_i$的分量为$\hat f_i c$与$\hat f_i s$）。合起来得$\mathbf{f}^{(e)} = \mathbf{T}^{\mathsf T}\hat{\mathbf{k}}\mathbf{T}\,\mathbf{d}^{(e)}$。乘开即得显式矩阵。同样的结果也可由能量得出：$U = \tfrac12 (EA/L)\delta^2$，其中$\delta = [-c, -s, c, s]\,\mathbf{d}^{(e)}$，所以$\mathbf{k}^{(e)} = (EA/L)\,\mathbf{b}\mathbf{b}^{\mathsf T}$，$\mathbf{b} = [-c, -s, c, s]^{\mathsf T}$，这又是那个显式矩阵。后一种形式立刻表明$\mathbf{k}^{(e)}$的秩为一：只有一种变形——拉伸——消耗能量。
:::

秩为一这一结构值得牢记。秩为一的$4 \times 4$矩阵有三个独立的零能运动：两个刚体平移和一个刚体转动（精确到一阶，转动使节点$j$垂直于杆移动）。对结构的每一部分，支承和其他杆件都必须抑制全部三种运动，否则整体矩阵是奇异的——这就是“桁架必须几何不变且支承恰当”这一命题的矩阵版本。

### 空间桁架与斜支承

在三维中每个节点有三个自由度$(u, v, w)$，杆的方向有三个余弦$c_x = \Delta x/L$、$c_y = \Delta y/L$、$c_z = \Delta z/L$。取$\mathbf{b} = [-c_x, -c_y, -c_z, c_x, c_y, c_z]^{\mathsf T}$，证明中的能量论证直接给出
$$
\mathbf{k}^{(e)} = \frac{EA}{L}\,\mathbf{b}\,\mathbf{b}^{\mathsf T} \quad (6 \times 6), \qquad \delta = \mathbf{b}^{\mathsf T}\mathbf{d}^{(e)}.
$$
滚动面倾斜角度为$\beta$的辊轴支座给定的是垂直于该表面的位移，而不是$u$或$v$。通常的处理方法是用一个$2\times2$转动（同样的$c, s$代数）把该节点的两个自由度转到斜向方向上，之后像任何其他支承一样划去法向分量。

::: example 三杆吊架 {#ex-three-bar}
位于原点的一个自由节点由三根钢杆（每根$E = 200\,\mathrm{GPa}$，$A = 500\,\mathrm{mm^2}$）悬挂于$(-2, 2)$、$(0, 2)$与$(2, 2)\,\mathrm{m}$处的三个支座上。分量为$F_x = 20\,\mathrm{kN}$与$F_y = -50\,\mathrm{kN}$的载荷作用于该自由节点。求其位移与三根杆中的力。
::: solution
节点的受力图：外加载荷，以及沿各杆作用的三个杆力，每个都假设为拉力（把节点拉向其支座）。两个平衡方程，三个未知杆力：一次超静定。

单位N、mm。每根杆都从自由节点（节点$i$，自由度$u, v$）指向其支座（节点$j$，固定）。只需要自由节点的$2 \times 2$块，由[[#eq-truss-k]]，它为$(EA/L)[c^2, cs; cs, s^2]$。

| 杆 | 指向 | $L$ (mm) | $c$ | $s$ | $EA/L$ (N/mm) |
|---|---|---|---|---|---|
| 1 | $(-2, 2)$ | 2828.4 | $-0.7071$ | $0.7071$ | 35 355 |
| 2 | $(0, 2)$ | 2000 | 0 | 1 | 50 000 |
| 3 | $(2, 2)$ | 2828.4 | $0.7071$ | $0.7071$ | 35 355 |

组装三个块：$K_{uu} = 35\,355(0.5) + 0 + 35\,355(0.5) = 35\,355$，$K_{vv} = 35\,355(0.5) + 50\,000 + 35\,355(0.5) = 85\,355$，$K_{uv} = 35\,355(-0.5) + 0 + 35\,355(0.5) = 0$（对称布置使$u$与$v$解耦）。于是
$$
u = \frac{20\,000}{35\,355} = 0.5657\,\mathrm{mm}, \qquad v = \frac{-50\,000}{85\,355} = -0.5858\,\mathrm{mm}.
$$
由$N = (EA/L)\,\delta$求杆力，其中$\delta = (0 - u)c + (0 - v)s$：
- 杆1：$\delta = -0.5657(-0.7071) + 0.5858(0.7071) = 0.8142\,\mathrm{mm}$，$N_1 = 28.79\,\mathrm{kN}$（应力$57.6\,\mathrm{MPa}$）；
- 杆2：$\delta = 0.5858\,\mathrm{mm}$，$N_2 = 29.29\,\mathrm{kN}$（$58.6\,\mathrm{MPa}$）；
- 杆3：$\delta = -0.5657(0.7071) + 0.5858(0.7071) = 0.0142\,\mathrm{mm}$，$N_3 = 0.50\,\mathrm{kN}$（$1.0\,\mathrm{MPa}$）。

**校核**节点的平衡，每根杆都沿其指向支座的单位向量拉节点：$x$方向：$28.79(-0.7071) + 0 + 0.50(0.7071) = -20.0\,\mathrm{kN}$，与$+20$平衡；$y$方向：$28.79(0.7071) + 29.29 + 0.50(0.7071) = 50.0\,\mathrm{kN}$，与$-50$平衡。水平载荷几乎完全由杆1承担，它使杆1伸长，同时几乎卸载了杆3。
:::

## 梁单元

梁单元靠弯曲承受横向载荷。在[[mechanics-of-materials/beam-deflection]]的欧拉-伯努利（Euler–Bernoulli）理论中，其挠度$v(x)$满足$EI\,v'''' = q(x)$，弯矩为$M = EI\,v''$，剪力为$V = -EI\,v'''$（采用该处所用的使梁下凸（下侧受拉）为正的弯矩符号约定；我们只需要$M = EIv''$）。连接两个梁段要求挠度**与转角**都连续，所以每个梁节点有两个自由度：横向位移$v$与转角$\theta = dv/dx$，以逆时针为正。

::: proposition 埃尔米特形函数 {#prop-hermite}
对长为$L$、节点自由度为$\mathbf{d}^{(e)} = [v_1, \theta_1, v_2, \theta_2]^{\mathsf T}$的梁单元，满足$v(0) = v_1$、$v'(0) = \theta_1$、$v(L) = v_2$、$v'(L) = \theta_2$的唯一三次多项式$v(x)$为$v = N_1v_1 + N_2\theta_1 + N_3v_2 + N_4\theta_2$，其中，记$\xi = x/L$，
$$
N_1 = 1 - 3\xi^2 + 2\xi^3, \quad N_2 = L(\xi - 2\xi^2 + \xi^3), \quad N_3 = 3\xi^2 - 2\xi^3, \quad N_4 = L(-\xi^2 + \xi^3).
$$ {#eq-hermite}
在节点之间无载荷时，这一三次多项式就是精确的欧拉-伯努利挠度。
:::

::: proof
写$v = a_0 + a_1x + a_2x^2 + a_3x^3$。四个条件关于各个$a$是线性的：$a_0 = v_1$，$a_1 = \theta_1$，$a_0 + a_1L + a_2L^2 + a_3L^3 = v_2$，$a_1 + 2a_2L + 3a_3L^2 = \theta_2$。由后两个解出$a_2, a_3$，得$a_2 = (3(v_2 - v_1) - L(2\theta_1 + \theta_2))/L^2$，$a_3 = (2(v_1 - v_2) + L(\theta_1 + \theta_2))/L^3$；按各节点值归并系数即得[[#eq-hermite]]。该方程组有唯一解，因为其行列式为$L^4 \neq 0$。当单元上$q = 0$时，$EIv'''' = 0$使精确解为三次多项式，而三次多项式由四个端部值确定，所以它与插值函数重合。
:::

::: widget plot

x: 0, 1
y: -0.2, 1.05
labels: N_1; N_2/L; N_3; N_4/L
caption: $0 \le \xi \le 1$上的四个埃尔米特三次函数。$N_1$与$N_3$是两端转角都保持为零时端部单位位移所对应的挠曲形状；$N_2/L$与$N_4/L$是两端位移都保持为零时端部单位转角所对应的形状。检查端部的斜率：每个函数在“自己的”一端斜率为一，在另一端为零。注意$N_1 + N_3 = 1$（刚体平移）且$N_2 + N_4 + L N_3 = x$（绕节点1的刚体转动）——单元可以无应变地作刚体运动。
:::

::: proposition 梁单元刚度矩阵 {#prop-beam-k}
对等截面欧拉-伯努利梁单元（$EI$为常数），
$$
\mathbf{k}^{(e)} = \frac{EI}{L^3}\begin{bmatrix} 12 & 6L & -12 & 6L \\ 6L & 4L^2 & -6L & 2L^2 \\ -12 & -6L & 12 & -6L \\ 6L & 2L^2 & -6L & 4L^2 \end{bmatrix},
$$ {#eq-beam-k}
它作用于$[v_1, \theta_1, v_2, \theta_2]^{\mathsf T}$，给出节点剪力与力矩$[F_1, M_1, F_2, M_2]^{\mathsf T}$（向上与逆时针为正）。
:::

::: proof
弯曲应变能为$U = \tfrac12\int_0^L EI\,(v'')^2\,dx$。由$v = \mathbf{N}\mathbf{d}^{(e)}$有$v'' = \mathbf{B}\mathbf{d}^{(e)}$，$\mathbf{B} = d^2\mathbf{N}/dx^2$，所以$U = \tfrac12\mathbf{d}^{(e)\mathsf T}\left(\int_0^L EI\,\mathbf{B}^{\mathsf T}\mathbf{B}\,dx\right)\mathbf{d}^{(e)}$，$\mathbf{k}^{(e)} = \int_0^L EI\,\mathbf{B}^{\mathsf T}\mathbf{B}\,dx$。把[[#eq-hermite]]求两次导数（$d/dx = L^{-1}d/d\xi$）：
$$
\mathbf{B} = \frac{1}{L^2}\left[\,-6 + 12\xi,\ \ L(-4 + 6\xi),\ \ 6 - 12\xi,\ \ L(-2 + 6\xi)\,\right].
$$
每个元素为$k_{ab} = (EI/L^3)\int_0^1 \hat B_a\hat B_b\,d\xi$，其中$\hat B$是方括号中的函数。例如$k_{11} = (EI/L^3)\int_0^1(12\xi - 6)^2d\xi = (EI/L^3)\cdot 12$，$k_{22} = (EI/L^3)L^2\int_0^1(6\xi - 4)^2d\xi = (EI/L^3)\cdot 4L^2$，$k_{24} = (EI/L^3)L^2\int_0^1(6\xi - 4)(6\xi - 2)d\xi = (EI/L^3)\cdot 2L^2$。其余元素同样得出。由于形函数对无载荷的梁是精确的，该矩阵就是等截面欧拉-伯努利梁的**精确**刚度，与经典结构分析中的转角位移方程完全相同。
:::

每一列同样有直接的意义。第2列表明：在其余三个自由度固定的情况下，要使端1转过单位角度，需要在端1施加力矩$4EI/L$，在端2施加力矩$2EI/L$（即一半的“传递”），同时需要剪力$\pm 6EI/L^2$使单元保持力矩平衡。假设：小挠度，平截面变形后仍为平面且垂直于轴线（无剪切变形——铁木辛柯（Timoshenko）单元为深梁加入了剪切变形），线弹性材料，绕主轴弯曲。

### 节点之间的载荷

分布载荷不能直接施加于梁模型；它被**一致节点载荷**代替，即在埃尔米特位移场上与真实载荷做相同虚功的节点力与节点力矩：$\mathbf{f}_q^{(e)} = \int_0^L \mathbf{N}^{\mathsf T}q(x)\,dx$。对均布载荷$q$（向上为正），它给出
$$
\mathbf{f}_q^{(e)} = \left[\ \frac{qL}{2},\ \ \frac{qL^2}{12},\ \ \frac{qL}{2},\ \ -\frac{qL^2}{12}\ \right]^{\mathsf T},
$$ {#eq-udl}
这就是两端固定梁的固端反力改变符号后的值。用这些载荷求得的节点位移是精确的。然而杆端力为$\mathbf{k}^{(e)}\mathbf{d}^{(e)} - \mathbf{f}_q^{(e)}$，而且埃尔米特三次多项式给出的节点**之间**的挠度缺少真实曲线的四次部分；要得到内部的挠度与弯矩，需要加上两端固定的特解，或者使用更多的单元。

::: warning 梁载荷的集中化不同于一致载荷
一个诱人的捷径是在受载梁单元的每一端施加$qL/2$而不施加力矩。对节点**力**来说这是正确的，但被省略的力矩$\pm qL^2/12$只在两个相同的受载单元相接处才相互抵消；在固定端、辊轴支座或载荷变化处它们不会抵消，结果就是错的。用一个单元和集中载荷模拟受均布载荷的一端固定一端简支梁，得到的辊轴处转角为零，而不是$qL^3/(48EI)$。应使用[[#eq-udl]]，并记住在回收杆端力时减去$\mathbf{f}_q^{(e)}$。
:::

::: example 用一个单元计算悬臂梁 {#ex-cantilever}
一根钢悬臂梁（$E = 200\,\mathrm{GPa}$，$I = 8.0 \times 10^{6}\,\mathrm{mm^4}$），长$L = 2\,\mathrm{m}$，端部承受向下的载荷$P = 10\,\mathrm{kN}$。用一个梁单元求端部挠度与转角。
::: solution
节点1为固定端（$v_1 = \theta_1 = 0$）；节点2承受$F_2 = -10\,000\,\mathrm{N}$，$M_2 = 0$。缩减方程组是[[#eq-beam-k]]的右下块：
$$
\frac{EI}{L^3}\begin{bmatrix} 12 & -6L \\ -6L & 4L^2 \end{bmatrix}\begin{bmatrix} v_2 \\ \theta_2 \end{bmatrix} = \begin{bmatrix} -P \\ 0 \end{bmatrix}.
$$
第二行给出$\theta_2 = 3v_2/(2L)$；第一行于是给出$(EI/L^3)(12 - 9)v_2 = -P$，所以
$$
v_2 = -\frac{PL^3}{3EI} = -\frac{10\,000 \times 2000^3}{3 \times 200\,000 \times 8.0\times10^6} = -16.67\,\mathrm{mm}, \qquad \theta_2 = -\frac{PL^2}{2EI} = -0.0125\,\mathrm{rad}.
$$
**校核。**这些恰好就是教科书公式，正如[[#prop-hermite]]对节点之间无载荷的单元所保证的；负转角是顺时针的，对下垂的端部来说正应如此。挠度为$L/120$，较大，但仍属小挠度问题。
:::
:::

::: example 受均布载荷的一端固定一端简支梁 {#ex-propped}
一根长$L = 5\,\mathrm{m}$、$EI = 1.0 \times 10^{13}\,\mathrm{N\,mm^2}$（$E = 200\,\mathrm{GPa}$，$I = 50 \times 10^6\,\mathrm{mm^4}$）的梁在$x = 0$处固定，在$x = L$处简支；它承受向下的均布载荷$w = 10\,\mathrm{kN/m}$。用一个单元分析它，求约束力，并把一个和两个单元求得的跨中挠度与精确值比较。
::: solution
**一个单元。**单位N、mm：$w = 10\,\mathrm{N/mm}$，所以$q = -10\,\mathrm{N/mm}$。由[[#eq-udl]]得一致载荷：$\mathbf{f}_q = [-25\,000,\ -2.083\times10^{7},\ -25\,000,\ +2.083\times10^{7}]^{\mathsf T}$（N，N mm）。支承：$v_1 = \theta_1 = v_2 = 0$，只剩下$\theta_2$：
$$
\frac{4EI}{L}\,\theta_2 = \frac{wL^2}{12} \quad\Rightarrow\quad \theta_2 = \frac{wL^3}{48EI} = \frac{10 \times 5000^3}{48 \times 10^{13}} = 2.604\times10^{-3}\,\mathrm{rad}.
$$
这就是一端固定一端简支梁的精确端部转角。杆端力$\mathbf{k}\mathbf{d} - \mathbf{f}_q$：用[[#eq-beam-k]]的第4列乘以$\theta_2$，即$(EI/L^3)[6L, 2L^2, -6L, 4L^2]\theta_2 = [6\,250,\ 1.042\times10^{7},\ -6\,250,\ 2.083\times10^{7}]$，减去$\mathbf{f}_q$：
$$
[F_1, M_1, F_2, M_2] = [31\,250\,\mathrm{N},\ 3.125\times10^{7}\,\mathrm{N\,mm},\ 18\,750\,\mathrm{N},\ 0].
$$
所以$R_A = 31.25\,\mathrm{kN} = 5wL/8$，$M_A = 31.25\,\mathrm{kN\,m} = wL^2/8$（作用于梁上为逆时针：墙处为使梁上凸的负弯矩），$R_B = 18.75\,\mathrm{kN} = 3wL/8$，辊轴处的弯矩为零，正应如此。四者都是精确的。

**跨中挠度。**精确曲线为$v = -\dfrac{w x^2(3L^2 - 5Lx + 2x^2)}{48EI}$，给出$v(L/2) = -wL^4/(192EI) = -3.255\,\mathrm{mm}$。一个单元的埃尔米特三次多项式给出$v(L/2) = N_4(\tfrac12)\theta_2 = -\tfrac{L}{8}\theta_2 = -1.628\,\mathrm{mm}$——只有一半。用两个单元时，跨中节点是一个自由度，解在那里恰好给出$v = -3.255\,\mathrm{mm}$，节点之间的最大挠度为$3.357\,\mathrm{mm}$，位于$x = 2.9\,\mathrm{m}$附近，而精确值为$x = 0.5785L = 2.89\,\mathrm{m}$处的$3.385\,\mathrm{mm}$。

**校核。**$R_A + R_B = 50\,\mathrm{kN} = wL$。教训是：由一致载荷得到的节点值是精确的，但节点之间的场只是插值；要在有节点的地方索取结果。
:::

## 平面刚架单元

刚架杆件既伸长又弯曲。在其局部坐标轴（$\hat x$沿杆件，$\hat y$与之垂直，由$\hat x$逆时针转得）中，对小位移这两种作用是不耦合的，所以局部刚度就是轴向自由度上的杆矩阵加上横向自由度上的梁矩阵：

::: proposition 平面刚架单元 {#prop-frame}
取局部自由度$\hat{\mathbf{d}} = [\hat u_1, \hat v_1, \theta_1, \hat u_2, \hat v_2, \theta_2]^{\mathsf T}$，并记$a = EA/L$，$b = EI/L^3$，
$$
\hat{\mathbf{k}} = \begin{bmatrix} a & 0 & 0 & -a & 0 & 0 \\ 0 & 12b & 6bL & 0 & -12b & 6bL \\ 0 & 6bL & 4bL^2 & 0 & -6bL & 2bL^2 \\ -a & 0 & 0 & a & 0 & 0 \\ 0 & -12b & -6bL & 0 & 12b & -6bL \\ 0 & 6bL & 2bL^2 & 0 & -6bL & 4bL^2 \end{bmatrix}.
$$
在整体坐标中$\mathbf{k}^{(e)} = \mathbf{T}^{\mathsf T}\hat{\mathbf{k}}\mathbf{T}$，其中$\mathbf{T}$是由两个
$$
\mathbf{r} = \begin{bmatrix} c & s & 0 \\ -s & c & 0 \\ 0 & 0 & 1 \end{bmatrix}
$$
组成的分块对角矩阵。
:::

::: proof
在每个节点处，局部平动是整体平动旋转$\theta$后的结果：$\hat u = cu + sv$，$\hat v = -su + cv$，而绕$z$轴的转动在两个坐标系中相同。因此$\hat{\mathbf{d}} = \mathbf{T}\mathbf{d}$。节点力以同样的方式变换，又因为$\mathbf{r}$是正交矩阵（$\mathbf{r}^{-1} = \mathbf{r}^{\mathsf T}$），$\mathbf{f} = \mathbf{T}^{\mathsf T}\hat{\mathbf{f}}$。于是$\mathbf{f} = \mathbf{T}^{\mathsf T}\hat{\mathbf{k}}\mathbf{T}\mathbf{d}$。等价地，应变能是不变的，$\tfrac12\hat{\mathbf{d}}^{\mathsf T}\hat{\mathbf{k}}\hat{\mathbf{d}} = \tfrac12\mathbf{d}^{\mathsf T}(\mathbf{T}^{\mathsf T}\hat{\mathbf{k}}\mathbf{T})\mathbf{d}$。$\hat{\mathbf{k}}$的分块结构（轴向自由度与弯曲自由度之间无耦合）对轴线通过截面形心的直杆在小位移下成立；轴力确实会改变弯曲刚度（$P$–$\Delta$效应），这是一种几何非线性。
:::

刚架杆件之间的刚性节点共享全部三个自由度，因此能传递弯矩。**铰**（销）只共享平动：杆件在该节点处各有独立的转角自由度，或者把释放端的弯矩从单元矩阵中凝聚掉。由于轴向刚度$EA/L$通常比弯曲刚度$12EI/L^3$大几个数量级，刚架杆件几乎不可伸长，整体矩阵中的元素相差很大的倍数——在双精度下无害，但这正是手算方法常常假设杆件不可伸长的原因。

::: example 受侧向载荷的门式刚架 {#ex-portal}
一个门式刚架有两根高$4\,\mathrm{m}$的柱，柱脚固定于$(0, 0)$与$(6, 0)\,\mathrm{m}$处，一根跨度$6\,\mathrm{m}$的横梁把两柱顶刚性连接。所有杆件均为钢，$E = 200\,\mathrm{GPa}$，$A = 6000\,\mathrm{mm^2}$，$I = 50 \times 10^6\,\mathrm{mm^4}$。水平风载$H = 10\,\mathrm{kN}$作用于左柱顶部。求侧移与柱脚约束力。
::: solution
**模型。**节点1 $(0, 0)$、2 $(0, 4000)$、3 $(6000, 4000)$、4 $(6000, 0)\,\mathrm{mm}$；单元1–2（柱，$\theta = 90°$，$c = 0$，$s = 1$），2–3（梁，$c = 1$，$s = 0$），4–3（柱）。节点1与4固定，剩下六个自由自由度$u_2, v_2, \theta_2, u_3, v_3, \theta_3$。对柱，$\mathbf{T}$使角色互换：局部轴向是整体$v$，局部横向是$-u$。单元常数：柱$EA/L = 300\,000\,\mathrm{N/mm}$，$12EI/L^3 = 1875\,\mathrm{N/mm}$；梁$EA/L = 200\,000\,\mathrm{N/mm}$，$12EI/L^3 = 555.6\,\mathrm{N/mm}$。把三个$6 \times 6$整体矩阵组装成$12 \times 12$方程组，并求解$6 \times 6$的自由块（由计算机完成；手算虽属常规但很冗长），得
$$
u_2 = 4.284\,\mathrm{mm}, \quad u_3 = 4.259\,\mathrm{mm}, \quad v_2 = -v_3 = 0.0089\,\mathrm{mm}, \quad \theta_2 = -8.06\times10^{-4}, \quad \theta_3 = -7.99\times10^{-4}\,\mathrm{rad}.
$$
横梁在约$5\,\mathrm{kN}$的轴力作用下缩短$0.025\,\mathrm{mm}$；竖向位移是倾覆引起的柱的缩短与伸长。

约束力（柱脚自由度处的$\mathbf{R} = \mathbf{K}\mathbf{d} - \mathbf{F}$）：水平方向$-5.01$与$-4.99\,\mathrm{kN}$，竖直方向$-2.66$与$+2.66\,\mathrm{kN}$，柱脚弯矩$12.04$与$11.98\,\mathrm{kN\,m}$。

**校核。**$\sum F_x$：$10 - 5.01 - 4.99 = 0$。对左柱脚取矩：载荷产生顺时针的$10 \times 4 = 40\,\mathrm{kN\,m}$，由柱脚弯矩$12.04 + 11.98 = 24.02$加上竖向约束力形成的力偶$2.66 \times 6 = 15.99$抵抗，合计$40.0\,\mathrm{kN\,m}$。界限：若横梁无限刚，每根柱就是一根两端固定的杆件，侧移刚度为$12EI/h^3$，$\Delta = Hh^3/(24EI) = 2.67\,\mathrm{mm}$；若没有横梁，每根柱都是自由悬臂，两柱平均分担时$\Delta = Hh^3/(6EI) = 10.67\,\mathrm{mm}$。计算得到的$4.28\,\mathrm{mm}$位于两者之间，更接近刚性梁的界限，因为横梁（$I/L = 8.3\times10^3\,\mathrm{mm^3}$）并不比柱（$12.5\times10^3\,\mathrm{mm^3}$）柔多少。
:::

::: quiz
一个平面桁架模型有6个节点、9根杆，在两个节点处有铰支座。组装并去掉受支承的自由度后，求解器报告刚度矩阵奇异。最可能的原因是什么？
- [ ] 杆太多：多余杆件使$\mathbf{K}$奇异。
- [x] 机构：某个节点或某组杆件可以在不使任何杆伸长的情况下运动，例如只有共线杆相交的节点。
- [ ] 杆的面积各不相同。
- [ ] 某些杆的方向余弦为负。
::: solution
当且仅当某个非零位移在任何杆中都不产生伸长——即机构——时，$\mathbf{K}_{ff}$是奇异的。计数给出$2 \times 6 = 12$个自由度，$9 + 4 = 13$个杆加约束力分量，所以桁架在数目上并不欠缺；问题必定出在布置上，例如由两根共线杆连接的节点，它可以垂直于这两根杆运动而没有一阶伸长。多余杆使结构更刚，绝不会使其奇异，而负的余弦只是方位而已。
:::
:::

::: history
桁架单元与刚架单元最先出现，因为飞机工程师与土木工程师已经掌握了结构分析的矩阵表述：梁单元的转角位移方程可追溯到20世纪初，而克罗斯（Hardy Cross）用手算迭代求解这些方程的力矩分配法则始于1930年。20世纪50年代发生变化的是计算机。特纳、克拉夫、马丁与托普1956年关于波音三角翼的论文把翼梁与翼肋作为杆和梁、把蒙皮作为三角形板，全部变换到整体坐标轴并加入一个矩阵；阿吉里斯1954—1955年发表在《飞机工程》（*Aircraft Engineering*）上的文章给出了变换与组装单元矩阵的一般理论。通用程序在20世纪60年代随之出现：美国国家航空航天局（NASA）的NASTRAN开发于60年代末，开发ANSYS的Swanson Analysis Systems公司成立于1970年。今天用于设计每一座高层建筑和海洋平台的空间刚架分析，正是这些矩阵被组装了数百万次。
:::

::: summary
- 平面桁架单元是一根杆，其轴向位移是节点位移的投影$c\,u + s\,v$；$\mathbf{k}^{(e)} = \mathbf{T}^{\mathsf T}\hat{\mathbf{k}}\mathbf{T} = (EA/L)\mathbf{b}\mathbf{b}^{\mathsf T}$，这是一个秩为一的矩阵，在二维中有三个刚体模式。
- 杆件内力由伸长量$\delta = (u_j - u_i)c + (v_j - v_i)s$回收；三维杆以同样方式使用三个方向余弦。
- 桁架矩阵奇异意味着机构或支承不足，而不是多余约束。
- 梁单元在每个节点处有自由度$v$与$\theta$；其埃尔米特三次形函数对无载荷的欧拉-伯努利梁是精确的，所以$\mathbf{k}^{(e)} = (EI/L^3)[12, 6L, \dots]$就是精确的转角位移刚度。
- 分布载荷变为一致节点载荷$\int\mathbf{N}^{\mathsf T}q\,dx$（对均布载荷为$qL/2$与$\pm qL^2/12$）；此时节点位移是精确的，但杆端力需要减去$\mathbf{f}_q$，节点之间的挠度只是插值。
- 平面刚架单元在局部坐标轴中叠加杆与梁的刚度，并用分块对角的$\mathbf{T}$加以转动；铰释放转角。
- 用约束力的平衡与简单的界限模型校核每一个解。
:::

## 习题

::: exercise 倾斜杆的一个元素 {level=1 check="30"}
一根钢杆（$E = 200\,\mathrm{GPa}$，$A = 400\,\mathrm{mm^2}$，$L = 2\,\mathrm{m}$）与$x$轴成$30°$倾斜。其整体刚度矩阵的元素$k_{11}$（$u_i$–$u_i$项）是多少？（以kN/mm为单位输入。）
::: solution
$EA/L = 200\,000 \times 400/2000 = 40\,000\,\mathrm{N/mm}$，$c^2 = \cos^2 30° = 0.75$，所以$k_{11} = 30\,000\,\mathrm{N/mm} = 30\,\mathrm{kN/mm}$。
:::

::: exercise 由节点位移求应力 {level=1 check="88"}
一根杆从位于$(0, 0)$的节点$i$延伸到位于$(3, 4)\,\mathrm{m}$的节点$j$；$E = 200\,\mathrm{GPa}$。某个解给出$u_i = v_i = 0$，$u_j = 1.0\,\mathrm{mm}$，$v_j = 2.0\,\mathrm{mm}$。杆中的应力是多少？（以MPa为单位输入；拉为正。）
::: solution
$L = 5000\,\mathrm{mm}$，$c = 0.6$，$s = 0.8$。伸长量$\delta = 1.0(0.6) + 2.0(0.8) = 2.2\,\mathrm{mm}$，应变$4.4\times10^{-4}$，应力$200\,000 \times 4.4\times10^{-4} = 88\,\mathrm{MPa}$（拉）。
:::
:::

::: exercise 悬臂梁的端部转角 {level=1 check="0.0125"}
对[[#ex-cantilever]]中的悬臂梁，由缩减的$2 \times 2$方程组验证端部转角的大小为$PL^2/(2EI)$，并求其值。（以rad为单位输入$|\theta_2|$。）
::: solution
由第二行，$\theta_2 = 3v_2/(2L)$，其中$v_2 = -PL^3/(3EI)$，所以$\theta_2 = -PL^2/(2EI) = -10\,000 \times 2000^2/(2 \times 1.6\times10^{12}) = -0.0125\,\mathrm{rad}$。
:::
:::

::: exercise 楼面梁的一致力矩 {level=2 check="9"}
一个长$3\,\mathrm{m}$的梁单元承受$12\,\mathrm{kN/m}$的均布载荷。每个一致节点力矩的大小是多少？解释为什么这些力矩在两个相同受载单元之间的内部节点处相互抵消，而在支座处不抵消。（以kN m为单位输入力矩。）
::: solution
$qL^2/12 = 12 \times 3^2/12 = 9\,\mathrm{kN\,m}$，对向上的载荷，左节点处为逆时针，右节点处为顺时针（向下的载荷则相反）。在内部节点处，一个单元的右端贡献$-9$，下一个单元的左端贡献$+9$：两者抵消。在支座处或受载区段的端部没有与之配对的单元，必须保留该力矩。
:::
:::

::: exercise 对称双杆吊架 {level=2 check="1.302"}
两根相同的钢杆（$E = 200\,\mathrm{GPa}$，$A = 300\,\mathrm{mm^2}$）从位于$(-1.5, 2)\,\mathrm{m}$与$(1.5, 2)\,\mathrm{m}$的支座延伸到位于原点的自由节点，该节点承受$40\,\mathrm{kN}$的向下载荷。由[[#eq-truss-k]]推导节点的竖向刚度并求挠度。（以mm为单位输入向下的挠度。）
::: solution
每根杆$L = 2.5\,\mathrm{m}$，$|c| = 0.6$，$s = 0.8$，$EA/L = 200\,000 \times 300/2500 = 24\,000\,\mathrm{N/mm}$。$vv$元素之和为$2 \times 24\,000 \times 0.64 = 30\,720\,\mathrm{N/mm}$，$uv$元素由于对称而抵消。挠度$= 40\,000/30\,720 = 1.302\,\mathrm{mm}$。写成公式为$\delta = PL/(2EA\sin^2\theta)$：越平的吊杆（$\sin\theta$小）柔度大得多。
:::

::: exercise 跨中受集中载荷的两端固定梁 {level=2 check="1.667"}
一根长$4\,\mathrm{m}$、两端固定的梁，$E = 200\,\mathrm{GPa}$，$I = 20\times10^6\,\mathrm{mm^4}$，跨中承受$20\,\mathrm{kN}$的向下集中载荷。用两个梁单元建模，利用对称性论证跨中$\theta = 0$，并求中点挠度。（以mm为单位输入其大小。）
::: solution
取$L_e = 2000\,\mathrm{mm}$，自由自由度是跨中的$v_2, \theta_2$。$\theta_2$行有贡献$-6EI/L_e^2\,v_2$（单元1）与$+6EI/L_e^2\,v_2$（单元2），两者抵消，所以$(8EI/L_e)\theta_2 = 0$，$\theta_2 = 0$。$v_2$行给出$2 \times 12EI/L_e^3\,v_2 = -P$，所以$v_2 = -PL_e^3/(24EI) = -PL^3/(192EI) = -20\,000 \times 4000^3/(192 \times 4\times10^{12}) = -1.667\,\mathrm{mm}$。这是精确结果，因为集中载荷作用在节点上。
:::

::: exercise 空间桁架杆件 {level=3 check="22.449"}
一根空间桁架杆件从位于$(0, 0, 0)$的节点$i$延伸到位于$(2, 3, 6)\,\mathrm{m}$的节点$j$；$E = 200\,\mathrm{GPa}$，$A = 500\,\mathrm{mm^2}$。节点$i$固定，节点$j$的位移为$(1, -1, 2)\,\mathrm{mm}$。求轴力。然后证明节点$j$的位移$(3, -2, 0)$不产生一阶的力，并解释原因。（以kN为单位输入第一种位移下的轴力。）
::: solution
$L = \sqrt{4 + 9 + 36} = 7\,\mathrm{m}$，方向余弦$(2/7, 3/7, 6/7)$。伸长量$\delta = (2 \cdot 1 + 3 \cdot (-1) + 6 \cdot 2)/7 = 11/7 = 1.571\,\mathrm{mm}$。$EA/L = 200\,000 \times 500/7000 = 14\,286\,\mathrm{N/mm}$，所以$N = 22\,449\,\mathrm{N} = 22.449\,\mathrm{kN}$（拉）。对$(3, -2, 0)$：$\delta = (6 - 6 + 0)/7 = 0$；该位移垂直于杆件，所以精确到一阶它只是使杆转动。因此空间桁架的节点至少需要三根不共面的杆件才能保持几何不变。
:::

::: exercise 由能量求梁的刚度元素 {level=3}
从$\mathbf{k}^{(e)} = \int_0^L EI\,\mathbf{B}^{\mathsf T}\mathbf{B}\,dx$与埃尔米特函数出发，推导$k_{12} = 6EI/L^2$与$k_{44} = 4EI/L$。然后证明[[#eq-beam-k]]第一行与第三行之和为零，第2行 + 第4行等于第3行的$-L$倍；把这两个事实都解释为单元的平衡。
::: solution
取$\hat B_1 = 12\xi - 6$，$\hat B_2 = L(6\xi - 4)$，$\hat B_4 = L(6\xi - 2)$，$dx = L\,d\xi$：$k_{12} = (EI/L^3)L\int_0^1(12\xi - 6)(6\xi - 4)d\xi$。积分为$\int_0^1(72\xi^2 - 84\xi + 24)d\xi = 24 - 42 + 24 = 6$，所以$k_{12} = 6EI/L^2$。$k_{44} = (EI/L^3)L^2\int_0^1(6\xi - 2)^2d\xi = (EI/L)(12 - 12 + 4) = 4EI/L$。第1行 + 第3行$= (EI/L^3)[0, 0, 0, 0]$：自由单元的两个端部剪力平衡（竖向平衡）。第2行 + 第4行$= (EI/L^3)[12L, 6L^2, -12L, 6L^2] = -L \times$第3行：端部弯矩加上端部剪力$F_2$对节点1之矩为零（力矩平衡）。因此该矩阵是奇异的，有两个刚体模式：平移与转动。
:::

::: exercise 桁架还是刚架？ {level=3}
要校核一个用焊接节点板连接的钢屋架。讨论它应当用桁架单元还是刚架单元建模。你的回答应涉及：两种模型对节点作了什么假设；各自给出哪些量；节点刚性引起的“次”弯曲应力何时显著（考虑杆件的长细比$L/r$）；以及你会如何同时使用两种模型来作出判断。提出一个可以用本章单元进行的定量校核。
::: solution
桁架模型假设节点为无摩擦的铰：杆件只承受轴力，对静定桁架，这些力由静力学得出。刚架模型使节点为刚性的，所以杆件还承受由变形协调所需的节点转动引起的杆端弯矩（“次弯矩”）。对细长杆件（$L/r$大于约50–100），弯曲刚度$EI/L$与轴向刚度$EA/L$相比很小（两者之比为$(r/L)^2$），所以次应力通常为轴向应力的百分之几到大约20 %；对短粗杆件，或在节点之间施加载荷时（上弦上的檩条），弯曲是主要的，必须使用刚架模型。一个实用的程序是：求解两种模型；比较轴力（若桁架理想化合理，两者应非常接近）；取刚架模型的杆端弯矩，计算$\sigma = N/A \pm Mc/I$；把节点之间受载的杆件作为梁来校核；并记住实际的节点板连接既不是完美的铰也不是完全刚性的，所以两种模型给出了行为的上下界。节点偏心与受压杆件的屈曲必须另外按适用的设计规范校核；本分析不能代替它。
:::
