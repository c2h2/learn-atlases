到目前为止的一切建立在叠加原理之上，而叠加只是一个近似。真实弹簧拉得远了会变硬，间隙会开开关关，摩擦会反向，阻力随速度的平方变化，结构的刚度随它所承受的载荷改变。方程一旦非线性，四件在线性系统中不可能发生的事就变得稀松平常：固有频率取决于**振幅**，响应**多值**并发生跳跃，振荡可以在完全没有外力的情况下**自我维持**，运动可以变得**混沌**——确定论的，却在几个周期之外不可预测。

这些都不稀奇：吉他弦用力拨时音高变尖，汽车的俯仰频率随乘客人数改变，桥梁在风中振荡而风里根本没有激励频率，传动链里有间隙的机床以主轴转速的一半轰鸣。不经仿真就能让这些变得可预测的工具，是能量积分、谐波平衡和平均法。

::: warning 线性直觉以四种特定方式失效
**（1）**固有频率随振幅改变，所以"共振"是幅频空间中的一条**曲线**而不是一个点。**（2）**一个激励频率可能对应**三个**稳态振幅，其中两个稳定，系统带滞回地在它们之间跳跃。**（3）**系统可以在完全没有激励的情况下振荡，振幅由非线性决定而不是由初始条件决定——**极限环**。**（4）**确定论系统可以对初始条件**敏感**依赖，以致两次相差百万分之一的运行指数式地分道扬镳。
:::

## 振幅相关的频率

::: definition 达芬（Duffing）振子 {#def-duffing}
典范的非线性振子是$m \ddot{x} + c \dot{x} + k x + \alpha x^{3} = F \cos \Omega t$，$\alpha > 0$对应**硬化**弹簧（张紧的弦、大挠度梁、受压支承），$\alpha < 0$对应**软化**弹簧（屈曲柱、磁悬浮、预载橡胶支承）。记$\omega_0^{2} = k / m$、$\beta = \alpha / m$，由谐波平衡得**骨干曲线**——振幅$A$下的自由振荡频率——为
$$
\omega^{2} (A) = \omega_0^{2} + \tfrac{3}{4} \beta A^{2},
\qquad
T (A) = T_0 \left( 1 + \tfrac{3}{8} \frac{\beta A^{2}}{\omega_0^{2}} \right)^{- 1} .
$$
三次项还产生一个小的**三次谐波**，在习题中计算。
:::

::: proof 保守非线性振子的周期 {#proof-nonlinear-period}
对$m \ddot{x} + \mathrm{d} V / \mathrm{d} x = 0$，能量积分给出$m \dot{x}^{2} / 2 + V (x ) = V (A )$（在转折点$x = A$处），所以
$$
T = 2 \sqrt{2 m} \int_0^{A} \frac{\mathrm{d} x}{\sqrt{V (A ) - V (x )}} .
$$
对$V = k x^{2} / 2 + \alpha x^{4} / 4$，代入$x = A \sin \theta$并积分，
$$
T = \frac{2 T_0}{\pi} \int_0^{\pi / 2} \frac{\mathrm{d} \theta}{\sqrt{1 + \frac{\alpha A^{2}}{2 k} \sin^{2} \theta}} ,
$$
是一个椭圆积分。对小$\alpha A^{2} / k$展开，
$$
T = T_0 \left( 1 - \frac{3 \alpha A^{2}}{8 k} + \cdots \right),
$$
所以硬化弹簧在较大振幅下**周期更短**，相对变化为$3 \alpha A^{2} / \left( 8 k \right)$——与谐波平衡给出的系数相同，这正是近似做对了事的检验。$\checkmark$

**注。**对单摆，同一积分给$T = \dfrac{2 T_0}{\pi} K \left( \sin^{2} \dfrac{\theta_0}{2} \right)$和$T = T_0 \left( 1 + \theta_0^{2} / 16 + \cdots \right)$：摆是**软化**的。
:::

::: widget plot
f: 1/(1+0.375*x*x)
x: 0, 2
y: 0.5, 1.1
labels: T / T_0
caption: $\beta / \omega_0^{2} = 1$的硬化达芬振子自由振荡周期随振幅的变化，取自展开式$T / T_0 = 1 - 3 \beta A^{2} / \left( 8 \omega_0^{2} \right)$。硬化系统的共振向右弯曲，在扫频试验中，弯曲早在跳跃本身发生之前就已可见。
:::

::: example 落地钟的摆 {#ex-pendulum-period}
一座落地钟的摆长$1.0\ \mathrm{m}$，以$6^{\circ}$的半幅摆动。求相对小角度值的周期误差；若一阵风使摆幅加倍，误差又是多少。
::: solution
由$\theta_0 = 6^{\circ} = 0.1047\ \mathrm{rad}$，
$$
\frac{\Delta T}{T} = \frac{\theta_0^{2}}{16} = \frac{0.01097}{16} = 6.9 \times 10^{- 4},
$$
即每天快$59\ \mathrm{s}$。摆幅加倍到$12^{\circ}$使误差变为四倍，即$2.8 \times 10^{- 3}$，每天$240\ \mathrm{s}$。

**校核。**$6^{\circ}$处椭圆积分的精确值为$T / T_0 = 1.000685$，展开式为$1.000686$。$\checkmark$

**合理性检验。**摆幅加倍，一天差出四分之一个白天——这就是**擒纵机构**的职责不只是补充损失的能量、还要使振幅几乎与驱动力矩无关的原因。死擒纵机构和大本钟的重力擒纵机构的存在就只为这件事，把冲量与振幅解耦，在驱动变化范围内把日差保持在百分之几秒。
:::
:::

## 多值响应与跳跃

::: theorem 跳跃现象 {#thm-jump}
频率为$\Omega$驱动的硬化达芬振子，稳态振幅满足
$$
\left[ \left( \omega_0^{2} - \Omega^{2} \right) A + \tfrac{3}{4} \beta A^{3} \right]^{2} + \left( 2 \zeta \omega_0 \Omega A \right)^{2} = \left( F / m \right)^{2} .
$$
这是关于$A^{2}$的三次方程，所以在一段驱动频率内**三个**振幅都可能，中间那个不稳定。**向上**扫频时响应沿低分支走，在上折叠处**向上**跳；**向下**扫频时沿高分支走，在较低频率处**向下**跳。两个折叠之间是**滞回**区，力越大、阻尼越轻，区域越宽。
:::

::: example 跳跃与滞回 {#ex-jump}
对$\ddot{x} + 0.1 \dot{x} + x + 0.3 x^{3} = 0.3 \cos \Omega t$，求跳上和跳下的频率，以及每次跳跃两侧的振幅。
::: solution
在整个扫频范围内解关于$A^{2}$的三次方程，$1.222 < \Omega < 1.418$内有三个实根：

- **向上扫频。**低分支在$\Omega = 1.418$处达到$A = 0.30$，跳到$A = 2.11$。
- **向下扫频。**高分支在$\Omega = 1.222$处达到$A = 1.67$，跳到$A = 0.88$。

线性系统的共振振幅本应为$F / \left( 2 \zeta \right) = 3.0$，所以硬化项把峰值推离了共振并削去了百分之三十。

**校核。**骨干曲线在$A = 1.67$处给$\Omega = \sqrt{1 + 0.225 A^{2}} = 1.275$，落在滞回带内——本应如此。$\checkmark$

**合理性检验。**从$A = 1.67$跳到$A = 0.88$是应力四倍的变化，发生在频率向下扫不到百分之二十时的不到一个周期之内。因此**向上**穿过非线性共振和**向下**滑过它是两种不同的经历：一台在共振之上运行、然后降速的机器，会一直待在高分支上、远低于其线性固有频率，然后突然安静下来——这是软化支承或松动螺栓的经典特征，而且通常被误诊。
:::
:::

## 自激振荡

::: definition 极限环与负阻尼 {#def-limit-cycle}
阻尼为负处振幅增长，为正处衰减；若阻尼随振幅**变号**，系统就稳定在一个**极限环**上，其振幅由系统决定而不是由初始条件决定。典范例子是范德波尔（van der Pol）方程
$$
\ddot{x} - \mu \left( 1 - x^{2} \right) \dot{x} + x = 0 ,
$$
用平均法求得其极限环振幅对一切$\mu > 0$都是$2$。物理上的自激表现为**颤振**、**制动尖啸**、**机床颤振**、桥梁或管道的**歌唱**、被弓拉的提琴弦，以及烟囱或输电线的风致振动。
:::

::: proof 用平均法求极限环振幅 {#proof-van-der-pol}
对$\ddot{x} + x = \mu \left( 1 - x^{2} \right) \dot{x}$寻求慢变$a$和$\phi$的解$x = a \cos \left( t + \phi \right)$。线性部分的能量为$E = \left( \dot{x}^{2} + x^{2} \right) / 2 = a^{2} / 2$，其变化率恰为非线性阻尼输入功率，
$$
\frac{\mathrm{d} E}{\mathrm{d} t} = \dot{x} \left( \ddot{x} + x \right) = \mu \left( 1 - x^{2} \right) \dot{x}^{2} .
$$
代入零阶解$x = a \cos \psi$、$\dot{x} = - a \sin \psi$，利用$\overline{\sin^{2} \psi} = 1 / 2$和$\overline{\sin^{2} \psi \cos^{2} \psi} = 1 / 8$对一个周期取平均，
$$
\overline{ \left( 1 - a^{2} \cos^{2} \psi \right) a^{2} \sin^{2} \psi }
= a^{2} \left( \frac{1}{2} - \frac{a^{2}}{8} \right),
\qquad
\dot{E} = \mu a^{2} \left( \frac{1}{2} - \frac{a^{2}}{8} \right) .
$$
由$\dot{E} = a \dot{a}$，
$$
\dot{a} = \frac{\mu a}{2} \left( 1 - \frac{a^{2}}{4} \right),
$$
它对一切$\mu > 0$在$a = 2$处有稳定不动点，其下$\dot{a} > 0$，其上$\dot{a} < 0$。$\checkmark$

**注。**振幅由**非线性**决定，而不是由初始条件决定。共振时振幅正比于激励，激励消失振幅就消失；自激时振幅是**系统自身的属性**，激励只需大到把阻尼压成负值即可。
:::

::: example 颤振起始速度 {#ex-flutter}
一架风洞模型机翼在静气中弯曲频率$12\ \mathrm{Hz}$、阻尼比$2\%$。气动阻尼为$\zeta_\text{aero} = - 0.004 \left( V / 30 \right)^{2}$。求颤振速度，以及高出它百分之十时振幅的倍增时间。
::: solution
总阻尼为零时颤振开始：
$$
0.02 - 0.004 \left( \frac{V}{30} \right)^{2} = 0
\quad\Longrightarrow\quad
V = 30 \sqrt{5} = 67\ \mathrm{m / s}.
$$
**高出百分之十。**$V = 73.8\ \mathrm{m / s}$时，
$$
\zeta = 0.02 - 0.004 \times 6.05 = - 0.0042,
\qquad
\text{增长率} = \left| \zeta \right| \omega_n = 0.0042 \times 2 \pi \times 12 = 0.317\ \mathrm{s^{- 1}},
$$
$$
\text{倍增时间} = \frac{\ln 2}{0.317} = 2.2\ \mathrm{s} = 26\ \text{个周期}.
$$
**合理性检验。**经典的颤振试验不能坐等振幅"发散"，因为速度高出百分之一时倍增时间是$260$秒，其间模型处于危险、风洞又热；标准做法改为在每个速度激发一次**自由衰减**、测量对数衰减率、把阻尼外推到零——与给出疲劳极限的同一条直线外推，而且只用完全**低于**颤振速度的数据就给出颤振速度。阻止真实机翼自毁的振幅限制来自气动失速或材料屈服，产生一个**极限环振荡**，其振幅随超出颤振点的速度平方根增长——这正是颤振工程师在风洞中寻找的特征。
:::
:::

## 参数激励与混沌

::: definition 参数激励 {#def-parametric}
当变化的不是外加力而是系统的**参数**时，方程成为$\ddot{x} + \omega_0^{2} \left( 1 + m \cos \Omega t \right) x = 0$，即马蒂厄（Mathieu）方程，其解在某些$\left( \Omega , m \right)$区域稳定、在另一些区域不稳定。失稳舌状区在$\Omega = 2 \omega_0 / n$处张开，**主**舌区最宽，位于$\Omega = 2 \omega_0$，半宽为$m \omega_0 / 2$。机理是参数每周期被改变两次，恰在位移最大时刻，于是每个半周期都对系统做正功。
:::

::: example 荡秋千的孩子 {#ex-swing}
一个孩子在$2.5\ \mathrm{m}$长的秋千上通过站起蹲下"给劲"。求给劲的频率、必须采用的相位，以及秋千仍能增大的给劲频率带宽。
::: solution
$$
\omega_0 = \sqrt{\frac{9.81}{2.5}} = 1.981\ \mathrm{rad / s}, \qquad
f_0 = 0.315\ \mathrm{Hz}, \qquad
f_{\text{pump}} = 2 f_0 = 0.63\ \mathrm{Hz}.
$$
**相位。**孩子必须在**最低点**附近**站起**——那里张力最大、功$\int T \, \mathrm{d} l$最大——在两端张力最小处蹲下。相位不对的站起，恰好抵消相位对的站起所加的能量。
**带宽。**取长度相对变化$m \approx 0.2$，主舌区在$\Omega / 2$上延伸$\pm m \omega_0 / 4$，所以
$$
\Delta f = \frac{m f_0}{2} = 0.032\ \mathrm{Hz},
$$
即$0.63\ \mathrm{Hz}$附近$\pm 5\%$的带宽。

**合理性检验。**秋千是一个捕获带宽$\pm 5\%$的参数振子，这就是孩子学会**在**秋千自身频率上给劲、而在其他频率上给不上劲的原因。同一机理使行走的人成为人行桥竖直振型在其**两倍**频率上的参数激励器——这就是"便步走"是一条频率指令而不是一条力指令的原因。
:::
:::

::: example 稳定倒立摆 {#ex-inverted-pendulum}
打算以固有频率十倍的频率竖直振动摆的支点，把摆倒立稳定住。求支点加速度振幅与$g$之比的要求值，以及对应的行程。
::: solution
高频判据为
$$
\frac{A \Omega^{2}}{g} > \sqrt{2} \, \frac{\Omega}{\omega_0} = \sqrt{2} \times 10 = 14.1 ,
$$
对单体矩阵的精确弗凯（Floquet）分析给出$14.3$。所以支点加速度振幅必须为$14.3\ g$，行程为
$$
A = \frac{14.3 g}{\Omega^{2}} = \frac{14.3 g}{100 \omega_0^{2}} = 0.143 \frac{g}{\omega_0^{2}} = 0.143 l_{\text{eq}} .
$$
对$0.3\ \mathrm{m}$的摆，$\omega_0 = 5.72\ \mathrm{rad / s}$，$\Omega = 57.2\ \mathrm{rad / s} = 9.1\ \mathrm{Hz}$，$A = 14.3 \times 9.81 / 57.2^{2} = 43\ \mathrm{mm}$。

**校核。**有效重力为$g_{\text{eff}} = g \left[ 1 - \tfrac{1}{2} \left( A \Omega^{2} / g \right)^{2} \left( \omega_0 / \Omega \right)^{2} \right]$，恰在$A \Omega^{2} / g = \sqrt{2} \Omega / \omega_0$处为零，证实了判据。$\checkmark$

**合理性检验。**$300\ \mathrm{mm}$的摆要在$9.1\ \mathrm{Hz}$下做$43\ \mathrm{mm}$行程的振动，是剧烈的摇晃——这就是卡皮察（Kapitza）摆是实验室奇观而不是控制策略的原因：所需加速度随驱动频率**线性**增长，行程却只按其平方下降，两者几乎抵消，任何频率下所需机器都很大。真实的倒立摆稳定——火箭、赛格威、土星五号——用的是**反馈**，它在振幅上分文不花。
:::
:::

::: example 混沌 {#ex-chaos}
受迫摆$\ddot{x} + 0.5 \dot{x} + \sin x = 0.667 \cos \left( 2 t / 3 \right)$是标准的混沌算例。分别从$x = 0$、$\dot{x} = 0$和$x = 10^{- 6}$、$\dot{x} = 0$出发，求两个解能保持接近多久。
::: solution
积分两个解，它们按$\left| \Delta x \right| \sim 10^{- 6} e^{\lambda t}$分离，最大**李雅普诺夫（Lyapunov）指数**为
$$
\lambda \approx 0.06 \ \text{每单位时间},
$$
所以分离达到量级一需要
$$
t = \frac{\ln \left( 10^{6} \right)}{0.06} = 230 \ \text{时间单位} = 55 \ \text{个驱动周期}.
$$
**合理性检验。**五十五个周期的可预测性，然后彻底不可预测——这不是数值伪影而是方程的性质，因为同样的李雅普诺夫指数在真实的磁铁摆装置上就能测到。其后果是：混沌系统无法在由初始条件精度和$1 / \lambda$设定的视界之外**预报**，控制必须闭环，而一个带间隙齿轮传动链的仿真每次运行可能给出**不同**的答案——这不是程序错误。实用法则是别再问"响应是多少"，改问"**吸引子**是什么"——系统访问的振幅范围，即使时间历程不可复现，它仍可复现。
:::
:::

::: example 设计 {#ex-design-absorber}
某机器机架在$40\ \mathrm{Hz}$处显示$\beta / \omega_0^{2} = 0.8\ \mathrm{m^{- 2}}$的硬化非线性，工作转速固定为$46\ \mathrm{Hz}$。振动须保持在$0.2\ \mathrm{mm}$以下。判断线性调谐吸振器是否安全。
::: solution
**骨干曲线。**振幅$A$处的共振频率为$f (A ) = 40 \sqrt{1 + 0.6 A^{2}}$，在$A = 0.2\ \mathrm{mm}$处为$40.0\ \mathrm{Hz}$，在$2\ \mathrm{mm}$处为$40.96\ \mathrm{Hz}$。工作转速$46\ \mathrm{Hz}$是小振幅共振的$1.15$倍、$2\ \mathrm{mm}$振幅共振的$1.12$倍。
**跳跃在哪里。**$\zeta = 0.02$、共振振幅$5\ \mathrm{mm}$时的跳下折叠位于$\Omega / \omega_0 = 0.85$附近，远低于工作点，所以机器坐在**低**分支上，响应为
$$
x \approx \frac{X_{\text{st}}}{\Omega^{2} / \omega_0^{2} - 1 - 0.6 A^{2}} \approx \frac{0.05}{1.32 - 1} = 0.16\ \mathrm{mm}.
$$
其中$X_{\text{st}} = 0.05\ \mathrm{mm}$是激力作用下的静变形。
**吸振器。**调谐到$46\ \mathrm{Hz}$的线性吸振器会添加第二个振型；一旦主振幅增长到其自身共振达到$46\ \mathrm{Hz}$，吸振器就调到了**错误**频率，反而可能使响应变坏。

**设计点评。**裕度是$0.16$对$0.2\ \mathrm{mm}$，而它之所以存在，只是因为工作点在共振之上且非线性轻微。线性吸振器在这里**不**安全，因为吸振器靠制造两个振型工作，而非线性会把主振型从它们中间推过去；对策是**非线性**吸振器、**振动中和器**，或者干脆加大阻尼——后者在一个频率范围内限制响应，而不是调一个凹口。吸振器设计假设线性，而共振移动超过吸振器带宽——通常为百分之二三——的机器无法用它处理。
:::

**振幅相关的周期**1673年就为惠更斯（Huygens）所知，他设计了摆线夹板来校正它；精确的椭圆积分表达式归功于勒让德（Legendre）和高斯（Gauss），后者用算术几何平均数在几次迭代内把它算到机器精度。**跳跃现象**由里德（Rieder）1789年和亥姆霍兹（Helmholtz）观测到，**达芬（Duffing）**1918年从音叉实验给出解释，直到1950年代才获得严格处理。**范德波尔（Van der Pol）**1926年的方程来自三极管振荡器，求解它所用的**平均法**可追溯到庞加莱（Poincaré）1892年的《新天体力学方法》（*Méthodes nouvelles*），并由**克雷洛夫（Krylov）**和**博柳波夫（Bogoliubov）**在1937年奠定严格基础。**马蒂厄（Mathieu）**1868年的方程和**弗凯（Floquet）**1883年的理论给出**斯特拉特（Strutt）**1931年绘制的稳定图，**卡皮察（Kapitza）摆**则出现在1951年《自然》杂志一封二十行的信里。**混沌**始于庞加莱1890年关于三体问题的备忘录，被遗忘，再由**洛伦兹（Lorenz）**1963年和**费根鲍姆（Feigenbaum）**1978年及其常数$4.015$重新发现；**戈卢布（Gollub）**和**斯威尼（Swinney）**1975年的摆实验是例 8 的直接祖先。
:::

::: quiz
一台结构先用振动台**向上**扫过共振、再**向下**扫过共振来测试，通常会显示：
- [ ] 两个方向相同的响应曲线，因为系统是确定论的
- [x] 每个方向不同的响应，带跳跃和滞回带
- [ ] 只有向上扫频时峰值更高，因为振动台在加速
- [ ] 除非阻尼恰好为零，否则没有差别
::: solution
**非线性**结构的响应曲线随振幅弯曲，所以在一段频率内三个振幅都可能，系统占据哪一个取决于它从哪里来。上扫与下扫的轨迹不同，而这个差别就是诊断依据：完全线性的结构给出完全相同的轨迹，振动试验中的任何滞回都是非线性的证据——裂纹、松动的接头、脱落的支承、屈曲的板件或一张一合的接触。这就是"上下扫频对比"是本应线性的结构的标准验收试验的原因，也是飞行件两条轨迹不一致就把它送回检查而不是重新分析的原因。
:::
:::

## 后续内容

这一切所偏离的线性频率响应见[[vibrations/harmonic-excitation]]，周期变得与振幅相关的自由振荡见[[vibrations/free-vibration]]，被非线性系统摧毁的多自由度模态图像见[[vibrations/modal-analysis]]，非线性系统以线性系统做不到的方式过滤的随机激励见[[vibrations/general-excitation]]。自激背后的稳定性思想在[[mechanics-of-materials/buckling]]中作为发散和颤振重现。

::: summary
- 非线性恢复力使固有频率依赖振幅：三次弹簧为$\omega^{2} = \omega_0^{2} + 3 \beta A^{2} / 4$，硬化抬高、软化压低。
- 非线性系统的受迫响应在一段频率内多值，振幅在折叠处**跳跃**，上扫与下扫之间存在滞回。
- 阻尼随振幅变号处系统稳定在**极限环**上，其振幅是系统的属性而非初始条件的属性；这就是颤振、切削颤振、尖啸与歌唱。
- 参数激励在$\Omega = 2 \omega_0 / n$处失稳，主舌区位于固有频率的两倍处，相对宽度只有直接共振峰的一半。
- 受迫有阻尼非线性振子可能混沌，其李雅普诺夫指数设定了硬预报视界；可复现的对象是吸引子，不是时间历程。
- 吸振器、调谐阻尼器和整套线性设计词汇都假设叠加原理，并在共振移动超过其带宽时悄然失效。
:::

## 习题

::: exercise 硬化 {level=1 check="0.03"}
某达芬振子$\beta / \omega_0^{2} = 0.5\ \mathrm{m^{- 2}}$。振幅为$0.4\ \mathrm{m}$时其周期下降多少比例？
::: solution
$\Delta T / T = 3 \beta A^{2} / \left( 8 \omega_0^{2} \right) = 3 \times 0.5 \times 0.16 / 8 = 0.03$。
:::

::: exercise 单摆 {level=1 check="0.017"}
半幅$30^{\circ}$时摆的周期增大多大比例？
::: solution
$\theta_0 = 0.5236\ \mathrm{rad}$，$\theta_0^{2} / 16 = 0.0171$，约$1.7\%$。
:::

::: exercise 极限环 {level=1 check="2"}
$\ddot{x} - \mu \left( 1 - x^{2} \right) \dot{x} + x = 0$的极限环振幅是多少？
::: solution
$2$，对$\mu$的一切取值。

::: exercise 参数 {level=1 check="2"}
摆要在其固有频率的多少倍处参数驱动才出现主失稳？
::: solution
$2$——固有频率的两倍。

::: exercise 骨干曲线 {level=2}
一端固支的钢梁小振幅下一阶固有频率为$25\ \mathrm{Hz}$，硬化系数使其频率在$2.5\ \mathrm{mm}$的端部位移振幅下上升$10\%$。求$30\ \mathrm{Hz}$驱动恰好落在共振上的振幅，并说明那里的响应是否稳定。
::: solution
$$
c = \frac{1.1^{2} - 1}{0.0025^{2}} = \frac{0.21}{6.25 \times 10^{- 6}} = 33\,600\ \mathrm{m^{- 2}},
\qquad
25 \sqrt{1 + c A^{2}} = 30 \;\Longrightarrow\; 1 + c A^{2} = 1.44 ,
$$
$$
A = \sqrt{0.44 / 33\,600} = 3.6\ \mathrm{mm}.
$$
**合理性检验。**$30\ \mathrm{Hz}$的驱动恰好在梁自身频率达到$30\ \mathrm{Hz}$的那个振幅上共振，而那里的响应只有当扫频从上方到达它时才**稳定**。从$25\ \mathrm{Hz}$向上扫，响应沿低分支走并在到达之前跳上；从$35\ \mathrm{Hz}$向下扫，它沿高分支穿过$30\ \mathrm{Hz}$，可以达到非常大的振幅。这就是**向下**扫频是寻找非线性结构最大响应的标准方法的原因，也是规定"以$1\ \mathrm{oct / min}$向上扫频"可能漏掉一个向下扫频以两倍振幅找到的共振的原因。
:::
:::

::: exercise 平均法 {level=2}
对$\dot{a} = \mu a \left( 1 - a^{2} / 4 \right)$的自激振子，求$\mu = 0.05\ \mathrm{s^{- 1}}$时振幅从$0.1$增长到$1.9$的时间，以及极限环附近的增长率。
::: solution
分离变量，
$$
t = \frac{1}{\mu} \int_{0.1}^{1.9} \frac{\mathrm{d} a}{a \left( 1 - a^{2} / 4 \right)}
= \frac{2}{\mu} \left[ \ln \frac{a}{\sqrt{4 - a^{2}}} \right]_{0.1}^{1.9}
= \frac{2}{0.05} \left( 1.113 + 2.995 \right) = 164\ \mathrm{s}.
$$
在$a = 2$附近，记$a = 2 + \epsilon$得$\dot{\epsilon} = - 2 \mu \epsilon$，所以趋近极限环的时间常数为$1 / \left( 2 \mu \right) = 10\ \mathrm{s}$，是早期指数增长时间的一半。
**合理性检验。**$\mu = 0.05$时，从小振幅到接近满极限环需两分钟：对颤振而言这是每秒十分之一的增长率，快到足以在风洞记录上被注意到，又慢到衰减率外推法有效。两个速率都由单一参数$\mu$设定，是超临界霍普夫（Hopf）分岔的普遍性质，也是颤振试验中**阻尼外推**法可靠的原因。
:::
:::

::: exercise 马蒂厄 {level=2}
对$m = 0.1$的$\ddot{x} + \omega_0^{2} \left( 1 + m \cos \Omega t \right) x = 0$，求$\omega_0 = 20\ \mathrm{rad / s}$时主参数共振失稳的$\Omega$带。
::: solution
把方程写成标准马蒂厄形式，取$z = \Omega t / 2$，得$a = 4 \omega_0^{2} / \Omega^{2}$、$q = - 2 m \omega_0^{2} / \Omega^{2}$，主边界为$a = 1 \pm q$。消去得
$$
\Omega = 2 \omega_0 \sqrt{1 \pm m / 2} ,
$$
所以
$$
\Omega = 40 \sqrt{1 \pm 0.05} = 40 \left( 1 \pm 0.025 \right) = 39.0 \text{ 到 } 41.0\ \mathrm{rad / s}.
$$
**合理性检验。**两侧各百分之二点五的带宽，对比同样调制深度下直接共振给出的百分之二的半宽——参数激励并非本质上更强，而是**有选择性**，因为它根本不激励相邻振型。这就是参数驱动的MEMS陀螺比力驱动灵敏得多的原因，也是同一机理使一串悬挂珠子——其张力在驱动频率上被调制——只传递窄带的原因。
:::
:::

::: exercise 跳跃 {level=3}
对例 3 的振子，把激励幅值减半并重新计算滞回带。结果对跳跃相对激励水平的敏感性说明了什么？
::: solution
$F$取$0.15$而不是$0.3$时，三根区域缩小到$1.136 < \Omega < 1.174$。**向上**扫频，低分支在$\Omega = 1.174$处达到$A = 0.42$并跳跃；**向下**扫频，高分支在$\Omega = 1.136$处达到$A = 1.22$并落到$A = 0.72$。
**合理性检验。**力减半把滞回带从$0.20$宽削到$0.038$宽——五倍——并把整个现象从$1.22$-$1.42$移到$1.14$-$1.17$，大大靠近线性共振。跳跃本身并不消失：它在每个激励水平都存在，只是位置和宽度在移动，所以对带自由间隙或松动接头的结构做低量级振动台试验仍会显示滞回，可以用来**定位**非线性。实际推论是：跳跃**不是**过度试验的伪影——它在每个激励水平都存在，只是位置在移动，所以对带自由间隙或松动接头的结构做低量级振动台试验会显示滞回，可以用来定位非线性。反过来，只在低量级测试的结构显示的带比飞行或使用工况**更窄**——这里力减半窄五倍——按低量级试验论证的设计在高量级可能是错的。这就是非线性结构要在整个振幅范围内而不是单一水平上表征的原因，也是扫频速率要紧的原因：快速扫频不给系统到达折叠的时间，跳跃出现在比应有值更高的频率上。
:::
:::

::: exercise 推导 {level=3}
用谐波平衡法推导骨干曲线$\omega^{2} = \omega_0^{2} + 3 \beta A^{2} / 4$，并求出近似忽略掉的三次谐波振幅。
::: solution
**一次谐波。**把$x = A \cos \omega t + x_3$代入$\ddot{x} + \omega_0^{2} x + \beta x^{3} = 0$，并用
$$
\cos^{3} \psi = \tfrac{3}{4} \cos \psi + \tfrac{1}{4} \cos 3 \psi .
$$
平衡基波，
$$
- \omega^{2} A + \omega_0^{2} A + \tfrac{3}{4} \beta A^{3} = 0
\quad\Longrightarrow\quad
\omega^{2} = \omega_0^{2} + \tfrac{3}{4} \beta A^{2} .
$$
**三次谐波。**平衡$\cos 3 \omega t$项，$x_3$很小，
$$
- 9 \omega^{2} x_3 + \omega_0^{2} x_3 + \tfrac{1}{4} \beta A^{3} = 0
\quad\Longrightarrow\quad
x_3 = \frac{\beta A^{3} / 4}{9 \omega^{2} - \omega_0^{2}} \approx \frac{\beta A^{3}}{32 \omega_0^{2}} .
$$
**校核。**比值$x_3 / A = \beta A^{2} / \left( 32 \omega_0^{2} \right)$，对上面图中$\beta / \omega_0^{2} = 1$、$A = 1$的情形为$0.031$——百分之三，证明忽略是合理的。$\checkmark$
**注。**三次谐波并非总可忽略：$3 \omega \approx \omega_0$时分母为零，系统在其固有频率三分之一处显示**超谐波共振**，其中三次谐波占主导、波形强烈偏离正弦。$\omega_0 / 2$和$\omega_0 / 3$处的超谐波是振动频谱中裂纹轴或松动接头的常见特征，也是频谱要读其**谐波**而不只读基波的原因。
:::
