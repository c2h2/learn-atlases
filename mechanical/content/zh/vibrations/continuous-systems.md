连续系统有无穷多个自由度，因而有无穷多个固有频率，而前面各课的整套机器完好地挺过了这个极限：仍然有模态、仍然有正交性、仍然有模态展开——但谱现在是**稠密**的，问题从"固有频率是多少"变成"这个频带里有多少个固有频率，它们如何与一个点力耦合"。

三个事实组织起整个主题。波会传播：每个连续系统都有一个波速，而固有频率是边界发完言之后行波剩下的东西。**频散关系**——频率与波数之间的关系——因系统而异——弦和流体管是非频散的，梁和壳是强频散的——而差别直接显现在谱的间距上。而在二维和三维中**模态密度**随频率增长，所以低频结构有模态、高频结构有混响场，其间的转变是工程师必须尊重的，因为有限元网格必须分辨它要表示的每一个模态。

::: warning 模态计数就是一条网格要求
连续系统的有限元模型是**硬**的，其频率从上方收敛：几个单元就能准确给出梁的第一模态，但每个更高的模态需要成比例更多的单元，常用的经验法则是**关注的最高模态每个波长至少六个单元**（低阶单元还要更多）。低于此，模型不是不准确而是悄悄地错，因为它报告的模态属于一个更硬的结构，且误差随模态阶数陡增。**试验**中对应的陷阱是空间混叠：点间距大于半波长的加速度计普查测到的是错误阶次的模态，却把它报成正确的那个——这正是模态普查自相矛盾的方式。
:::

## 弦、杆与轴

::: definition 波动方程及其波速 {#def-wave-eq}
张力$T$、线密度$\mu$的张紧弦，作纵向运动的模量$E$、密度$\rho$、截面积$A$的均匀杆，剪切模量$G$的受扭轴，以及刚性管中的流体，都服从同一个方程
$$
\frac{\partial^{2} u}{\partial x^{2}} = \frac{1}{c^{2}} \frac{\partial^{2} u}{\partial t^{2}},
\qquad
c^{2} = \begin{cases} T / \mu & \text{弦} \\ E / \rho & \text{纵向杆} \\ G / \rho & \text{受扭轴} \\ K / \rho & \text{体积模量为 } K \text{ 的流体中的声} \end{cases}
$$
以及同一个推论：波以$c$双向传播而形状不变，长为$L$的有限系统两端固定或两端自由时固有频率为$c / 2 L$的整数倍，一端固定一端自由时为$c / 4 L$的奇数倍。谱是**谐波**的——这就是弦发乐音而梁不发乐音的原因。
:::

::: proof 分离变量与正交性 {#proof-separation}
在$\mu u_{tt} = \left( T u_x \right)_x$中设$u = \phi (x ) q (t )$。代入并除以$T \phi q$，
$$
\frac{\phi''}{\phi} = \frac{\mu}{T} \frac{\ddot{q}}{q} = - k^{2},
$$
是一个常数，因为左边只依赖$x$而右边只依赖$t$。两个方程为
$$
\phi'' + k^{2} \phi = 0, \qquad \ddot{q} + \omega^{2} q = 0,
\qquad \omega = k c ,
$$
边界条件$\phi (0 ) = \phi (L ) = 0$选出$k_n = n \pi / L$，于是
$$
\phi_n = \sin \frac{n \pi x}{L}, \qquad
f_n = \frac{n c}{2 L} .
$$
为证正交性，取两个模态相减：
$$
\int_0^L \left( \phi_m T \phi_n'' - \phi_n T \phi_m'' \right) \mathrm{d}x
= \left( k_n^{2} - k_m^{2} \right) \int_0^L T \phi_m \phi_n \, \mathrm{d}x .
$$
左边分部积分后化为一个边界项，它在每端$\phi = 0$与$T \phi' = 0$的任意组合下消失，所以只要$k_m \ne k_n$积分就为零。$\checkmark$

**注。**这个论证就是**刘维尔（Sturm–Liouville）**论证，它原封不动地推广到杆、轴、梁、膜和板，推广到任何使边界项消失的边界条件——这正是"自伴"一词的数学内容，也正是为什么一个带**非保守**边界、随动力或行进速度边界条件的结构，其模态不再正交、并可能合并成所谓例外点的退化振形。弦的模态是正交的；旋转轴或制动盘的模态则未必。
:::

::: definition 欧拉–伯努利（Euler–Bernoulli）梁 {#def-beam}
弯曲打破了规律。抗弯刚度$EI$、线密度$\rho A$的梁服从四阶空间方程，
$$
EI \frac{\partial^{4} u}{\partial x^{4}} + \rho A \frac{\partial^{2} u}{\partial t^{2}} = 0,
\qquad
\omega = \left( \frac{EI}{\rho A} \right)^{1 / 2} k^{2},
$$
所以相速$\omega / k$正比于$k$，而**群**速是相速的两倍：一个弯曲脉冲在传播中扩散。固有频率按$\left( \beta_n L \right)^{2}$走，$\beta_n L$由超越频率方程决定、大致正比于$n$，所以谱大致按$n^{2}$张开，而不是像弦那样按$n$——悬臂梁的模态在第一阶的$1$、$6.27$、$17.5$和$34.4$倍处，而不是$1$、$4$、$9$和$16$倍。
:::

::: proof 悬臂梁频率方程 {#proof-cantilever}
对$\phi'''' - \beta^{4} \phi = 0$，通解为
$$
\phi = A \cosh \beta x + B \sinh \beta x + C \cos \beta x + D \sin \beta x .
$$
固支端$\phi = \phi' = 0$，自由端弯矩和剪力为零，$\phi'' = \phi''' = 0$。前两个给出$A = - C$、$B = - D$，后两个给出
$$
\begin{pmatrix} \cosh \beta L + \cos \beta L & \sinh \beta L + \sin \beta L \\ \sinh \beta L - \sin \beta L & \cosh \beta L - \cos \beta L \end{pmatrix}
\begin{pmatrix} A \\ B \end{pmatrix} = \mathbf{0} .
$$
令行列式为零，并用$\cosh^{2} - \sinh^{2} = 1$和$\cos^{2} + \sin^{2} = 1$，一切坍缩为
$$
\cosh \beta L \cos \beta L = - 1,
\qquad
\beta_1 L = 1.8751, \quad \beta_2 L = 4.6941, \quad \beta_3 L = 7.8548 ,
$$
频率为$f_n = \left( \beta_n L \right)^{2} / 2 \pi \sqrt{EI / \rho A L^{4}}$。$\checkmark$

**注。**$n$大于二时，根与$\left( 2 n - 1 \right) \pi / 2$相差不到$0.001$，所以梁的高频段谱按$\left( 2 n - 1 \right)^{2}$走，其模态密度按$\mathrm{d}N / \mathrm{d}f \propto 1 / \sqrt{f}$——弯曲模态每赫兹变得**更稀**；而弯曲板的模态密度是常数，膜的模态密度随频率增长。这一个事实就解释了为什么细长梁好建模而平板不好，也为什么"梁式"理想化在板自身模态的开始比梁模态来得更快的时刻被放弃。
:::

::: definition 二维系统与模态密度 {#def-2d}
单位长度张力$T$、面密度$\rho_s$的膜服从二维波动方程，所以其频率正比于$\sqrt{\left( n_x / a \right)^{2} + \left( n_y / b \right)^{2}}$，其谱**不**是谐波的——正方形除外，那里不同的指标对撞进同一频率。弯曲板像梁一样是频散的：其弯曲波速按$\sqrt{f}$上升，在**吻合**（临界）**频率**处等于相邻流体中的声速，高于此频率板高效辐射、最难隔声。
计数才是结构与房间的区别所在。一维非频散系统的模态密度$\mathrm{d}N / \mathrm{d}f$是常数，弯曲板也是如此；二维非频散系统按$f$增长；三维声腔按$f^{2}$增长。**模态重叠**$\varepsilon = \eta \omega\, \mathrm{d}N / \mathrm{d}f$——模态带宽与其间距之比——对车身在几百赫兹、对船舱在几十赫兹越过一，在其上单个共振无法分辨，正确的描述是功率平衡而不是频率响应。
:::

::: example 一根钢琴弦 {#ex-string}
一根直径$0.6\ \mathrm{mm}$、有效长度$650\ \mathrm{mm}$的钢钢琴弦要发出$440\ \mathrm{Hz}$的A音。求张力，以及第八分音的偏高程度。
::: solution
$$
\mu = \rho \frac{\pi d^{2}}{4} = 7850 \times 2.827 \times 10^{- 7} = 2.220 \times 10^{- 3}\ \mathrm{kg / m},
\qquad
c = 2 L f = 572\ \mathrm{m / s},
$$
$$
T = \mu c^{2} = 2.220 \times 10^{- 3} \times 572^{2} = 726\ \mathrm{N}.
$$
**非谐性。**抗弯刚度使$f_n = \frac{n c}{2 L} \sqrt{1 + \beta n^{2}}$，其中
$$
\beta = \frac{\pi^{2} EI}{T L^{2}} = \frac{9.87 \times 200 \times 10^{9} \times 6.36 \times 10^{- 15}}{726 \times 0.4225} = 4.09 \times 10^{- 5},
$$
所以第八分音偏高$\sqrt{1 + 64 \beta} = 1.0013$，即$2.3$音分。

**校核。**钢琴弦的工作张力为$700$到$1000\ \mathrm{N}$，三角钢琴的框架承受约$200\ \mathrm{kN}$的弦总张力——这就是框架用铸铁的原因。$\checkmark$

**合理性检验。**两音分低于约五音分的恰能分辨差别，这就是钢琴高音弦用光钢弦的原因。**低音**区同一公式迫使设计改变：要在$1.3\ \mathrm{m}$的弦上以合理张力发出$55\ \mathrm{Hz}$，线密度需要大十六倍，而那么重的光钢弦（直径$2.4\ \mathrm{mm}$）其$\beta$大到使第八分音偏高超过**一个半音**。补救是缠弦——细芯外缠铜，把质量加在几乎不增加抗弯刚度的外侧——剩余的非谐性就是钢琴要**拉伸**调律的原因：八度被调宽，使低音弦的非谐分音与高音弦的分音重合。
:::
:::

::: example 一片涡轮叶片 {#ex-blade}
一片涡轮叶片长$50\ \mathrm{mm}$、宽$20\ \mathrm{mm}$、弯曲方向厚$3\ \mathrm{mm}$，$E = 200\ \mathrm{GPa}$、$\rho = 7850\ \mathrm{kg / m^{3}}$。求其前三阶水平弯曲频率。
::: solution
$$
I = \frac{b h^{3}}{12} = 4.50 \times 10^{- 11}\ \mathrm{m^{4}}, \qquad
\rho A = 0.471\ \mathrm{kg / m}, \qquad
\sqrt{\frac{EI}{\rho A L^{4}}} = 1748\ \mathrm{s^{- 1}},
$$
$$
f_n = \frac{\left( \beta_n L \right)^{2}}{2 \pi} \times 1748,
\qquad
f_1 = 978\ \mathrm{Hz}, \quad
f_2 = 6130\ \mathrm{Hz}, \quad
f_3 = 17\,160\ \mathrm{Hz}.
$$
**校核。**比值为$6.27$和$17.55$，而$\left( 4.6941 / 1.8751 \right)^{2} = 6.267$ $\checkmark$

**合理性检验。**第二模态是第一模态的六倍多，这就是叶片的**第二**弯曲模态虽是第二柔的却很少成为设计工况的原因：涡轮机械的激励谱是转速整数倍的线谱，而如此急剧张开的谱意味着叶片可以调谐避开前几个发动机阶次并保持避开。同样的陡峭也是叶片在第二模态的**应力**远比第一模态恶劣的原因——第二模态在跨内有一个节点，因此同样端部位移下应变能大得多。
:::
:::

::: example 一根钻柱 {#ex-drillstring}
一根$100\ \mathrm{m}$长的钻柱自由悬挂在井眼中。求其前两阶**纵向**固有频率，并说明泥浆密度改变如何影响它们。
::: solution
$$
c_L = \sqrt{\frac{E}{\rho}} = \sqrt{\frac{200 \times 10^{9}}{7850}} = 5048\ \mathrm{m / s},
\qquad
f_n = \frac{n c_L}{2 L} = 25.2 , 50.5\ \mathrm{Hz}.
$$
**校核。**钢中的纵波速度是一个值得记住的标准数——钢$5048\ \mathrm{m / s}$、铝$5130$、钢中剪切$3178$——因为它能把实测回波延迟直接换算成长度，卡住的钻杆就是这样定位的。$\checkmark$

**合理性检验。**频率**只**依赖$E$和$\rho$，不依赖截面，所以同样长度的厚壁钻柱和薄壁钻柱有相同的纵向谱——而这正是该测量是材料测量而不是几何测量的原因。泥浆密度对纵向模态几乎没有影响，因为轴向运动几乎不推开流体。它对**横向**（弯曲）模态才要紧：随管运动的泥浆充当**附加质量**，降低频率——正是同一效应使结构在水池试验中的湿固有频率低于干态。
:::
:::

::: example 一根受扭轴 {#ex-torsion}
一台电动机经$400\ \mathrm{mm}$长、$30\ \mathrm{mm}$的钢轴驱动一个直径$300\ \mathrm{mm}$、质量$20\ \mathrm{kg}$的联轴节盘。求第一阶扭转固有频率。
::: solution
$$
J = \frac{\pi d^{4}}{32} = 7.95 \times 10^{- 8}\ \mathrm{m^{4}}, \qquad
k_t = \frac{G J}{L} = \frac{79.3 \times 10^{9} \times 7.95 \times 10^{- 8}}{0.400} = 15\,760\ \mathrm{N\, m / rad},
$$
$$
I_p = \frac{m R^{2}}{2} = 0.225\ \mathrm{kg\, m^{2}}, \qquad
f_1 = \frac{1}{2 \pi} \sqrt{\frac{15\,760}{0.225}} = 42.1\ \mathrm{Hz}.
$$
**校核。**分布模型给出轴**自身**第一扭转模态$f_1 = c_s / 4 L = 3178 / 1.6 = 1986\ \mathrm{Hz}$，高出四十七倍，所以集中参数模型极好。$\checkmark$

**合理性检验。**四十二赫兹正是四缸四冲程发动机在约$1260\ \mathrm{rev / min}$时的发火频率——这就是扭转振动是曲轴问题而不是轴问题的原因：激励在转速的**整数倍**上，一个调谐到怠速时避开一阶激励的系统，可能在运转转速被三阶或四阶精确地驱动在共振上。设计对策要么把轴做硬——$k_t \propto d^{4}$，直径多百分之二十刚度就翻倍——要么在皮带轮上装一个**离心摆吸振器**，其调谐与转速成正比，因而在每个转速都精确。
:::

::: example 一面鼓和一根管 {#ex-fluids}
求一面直径$400\ \mathrm{mm}$、张力$2\ \mathrm{kN / m}$、面密度$0.15\ \mathrm{kg / m^{2}}$的圆鼓膜的基本频率，以及一根等长、内径$40\ \mathrm{mm}$、两端开口的管风琴管的基本频率。
::: solution
**膜。**由$\nabla^{2} u = \left( \rho_s / T \right) u_{tt}$和固定边界，
$$
f_{01} = \frac{2.4048}{2 \pi R} \sqrt{\frac{T}{\rho_s}}
= \frac{2.4048}{2 \pi \times 0.200} \times 115.5 = 221\ \mathrm{Hz},
$$
其中$2.4048$是贝塞尔函数$J_0$的第一个零点。
**管。**取$c = 343\ \mathrm{m / s}$、管半径$a = 20\ \mathrm{mm}$、每个开口端$0.6 a$的端部修正，
$$
f_1 = \frac{c}{2 \left( L + 1.2 a \right)} = \frac{343}{2 \times 0.424} = 405\ \mathrm{Hz},
$$
对比理想$c / 2 L$的$429\ \mathrm{Hz}$。

**合理性检验。**膜的谱**不**是谐波的：接下来的根是第一阶的$1.593$和$2.136$倍，而不是$2$和$3$——这就是鼓有音高却没有乐音的原因，也是定音鼓做成半球形鼓身、使其自身共振加强一组近谐波膜模态的原因。管风琴管的端部修正使音高降低百分之六——约一个半音——这就是管风琴管的发音是在工作台上靠耳朵**整音**、而不是按公式下料的原因，也是风乐器公式只是起点、从来不是成品设计的原因。
:::

::: example 设计 {#ex-design-bracket}
一个传感器支架是长$200\ \mathrm{mm}$、厚$40\ \mathrm{mm}$的钢悬臂梁，端部带$2\ \mathrm{kg}$的探头。求把第一阶弯曲模态推到$400\ \mathrm{Hz}$以上所需的宽度。
::: solution
用静挠度曲线的瑞利法给出
$$
k_{\text{eq}} = \frac{3 EI}{L^{3}} = 4.00 \times 10^{8} b,
\qquad
m_{\text{eq}} = 0.2357 \rho A L + M = 14.8 b + 2 ,
$$
其中$b$以米计，所以$f^{2} = k_{\text{eq}} / m_{\text{eq}}$在$400\ \mathrm{Hz}$要求
$$
4.00 \times 10^{8} b = \left( 2 \pi \times 400 \right)^{2} \left( 14.8 b + 2 \right)
\quad\Longrightarrow\quad
b = 0.041\ \mathrm{m}.
$$
支架宽度至少$41\ \mathrm{mm}$——实际上取$40 \times 45\ \mathrm{mm}$的方钢。

**设计点评。**答案由**端部质量**主导：支架自身的等效质量是$0.61\ \mathrm{kg}$，对比探头的$2\ \mathrm{kg}$，所以频率主要由$\sqrt{3 EI / L^{3} M}$决定，支架自身质量使其降低约百分之十二。这有两个后果。其一是接头而不是板决定答案——焊在框架$10\ \mathrm{mm}$板上的$200\ \mathrm{mm}$悬臂梁是装在扭转弹簧上的悬臂梁，而[[vibrations/modal-analysis]]中标定试件的同一套算术表明，适度柔的根部就能拿走百分之二十的频率。其二是对策是**长度**，它以$L^{-3}$进入：把支架缩短到$150\ \mathrm{mm}$，同样宽度下频率提高近百分之六十，或者宽度可以减到三分之一——这就是有经验的设计师在加固问题上的第一招是移动安装点而不是添加材料的原因。
:::

振动弦是数学物理中最古老的问题：**毕达哥拉斯（Pythagoras）**及其学派据说凭经验发现了谐波比，**梅兰·梅森（Marin Mersenne）**在《普遍和谐》（*Harmonie universelle*，1636–1637）中发表了频率与张力、长度和质量的关系定律，**达朗贝尔（d'Alembert）**于1747年写出波动方程及其行波解。**丹尼尔·伯努利（Daniel Bernoulli）**1753年提出一般运动是正弦叠加——**欧拉（Euler）**和达朗贝尔怀疑非光滑初始形状能否如此表示——这一主张最终由**傅里叶（Fourier）**证实，其《热的解析理论》（*Théorie analytique de la chaleur*）出版于1822年。丹尼尔·伯努利和欧拉在1740年代得到了梁方程和悬臂梁频率方程；**克拉尼（Chladni）**从1787年起用沙粒显示板的振动图案；**基尔霍夫（Kirchhoff）**1850年给出薄板理论；**瑞利（Rayleigh）**的《声学理论》（1877–1878）在梁理论中加入了转动惯量并汇集了能量法，**铁木辛柯（Timoshenko）**于1921年加入剪切变形。**里茨（Ritz）**1909年的方法使近似频率的求法系统化。腔体中模态的计数可追溯到瑞利与金斯（Jeans）以及**外尔（Weyl）**1911年的定理，**莫尔斯（Morse）**的《振动与声》（*Vibration and Sound*，1936）把它带入声学。钢琴弦的**非谐性**由**舒克（Schuck）与扬（Young）**（1943）和**弗莱彻（Fletcher）**（1964）分析，解释了**雷尔斯巴克（Railsback）**1938年测得的八度拉伸。
:::

::: quiz
一根均匀梁的模态位于其第一频率的$1$、$6.27$、$17.5$和$34.4$倍处。间距**变宽**而不是保持均匀的原因是：
- [ ] 剪切变形，它使高阶模态变硬
- [x] 频散关系$\omega \propto k^{2}$，所以波数加倍频率变为四倍
- [ ] 转动惯量，它抬高高阶模态
- [ ] 边界条件，它是超越的
::: solution
对梁$\omega = \left( EI / \rho A \right)^{1 / 2} k^{2}$，而模态阶数大致线性地决定$k$，所以$f_n \propto n^{2}$，间距$f_{n+1} - f_n \propto 2 n + 1$变宽。剪切变形和转动惯量——蒂莫申科（Timoshenko）修正——确实把高阶模态抬到欧拉值之上，但它们是修正而不是原因；超越频率方程只是微扰那些整数，因为$n$大于二时$\beta_n L$与$\left( 2 n - 1 \right) \pi / 2$相差不到$0.001$。实际后果是梁的模态密度随频率**下降**，所以细长结构在远高于同样材料的平板的频率上仍可逐模态分辨，而一个设计停止逐模态分析的时刻，通常是板模态到来的时刻，而不是梁模型失效的时刻。
:::
:::

## 后续内容

单自由度系统是本课一切内容的第一项，见[[vibrations/free-vibration]]和[[vibrations/harmonic-excitation]]；有限系统的模态展开——它变成这里的展开——见[[vibrations/two-degrees-of-freedom]]；从离散测量提取连续模态见[[vibrations/modal-analysis]]；悬挂在连续结构上的吸振器见[[vibrations/vibration-absorbers]]；而这一切的有限元数值求解是[[vibrations/modal-analysis]]和任何有限元教材的主题。

::: summary
- 每个连续系统都有一个波速和无穷多个模态；固有频率是边界发过言之后的行波。
- 弦、杆、受扭轴和流体管是非频散的，有**谐波**谱；梁、板和壳是频散的，其谱向外张开。
- 振型正交是因为空间问题是自伴的，这在对非保守边界——旋转轴、随动力、运动介质——不成立。
- 梁的频率按$\left( \beta_n L \right)^{2}$走，$\beta_n L$来自超越方程：悬臂梁的模态在第一阶的$1$、$6.27$、$17.5$和$34.4$倍处。
- 抗弯刚度使真实弦**非谐**，这一效应决定了钢琴低音弦的设计和一切真实乐器的调律。
- 模态密度对梁随频率下降，对弯曲板为常数，对膜和声腔随频率上升，所以"有模态的结构"与"混响盒子"之间的边界，对网格、普查和分析同样是一条设计要求。
:::

::: exercise 弦张力 {level=2}
一根直径$0.9\ \mathrm{mm}$、有效弦长$650\ \mathrm{mm}$、密度$7850\ \mathrm{kg / m^{3}}$的吉他弦调至$82.4\ \mathrm{Hz}$的E音。求张力。
::: solution
$$
\mu = 7850 \times \frac{\pi \times 0.9^{2} \times 10^{- 6}}{4} = 4.995 \times 10^{- 3}\ \mathrm{kg / m},
\qquad
c = 2 \times 0.65 \times 82.4 = 107.1\ \mathrm{m / s},
$$
$$
T = \mu c^{2} = 4.995 \times 10^{- 3} \times 107.1^{2} = 57.3\ \mathrm{N}.
$$
**合理性检验。**吉他弦的工作张力为$50$到$90\ \mathrm{N}$，钢弦吉他总张力约$700\ \mathrm{N}$——这就是吉他面板要加音梁、钢琴框架用铸铁的原因。频率的平方律就是把音高升一个全音会拉断弦的原因——频率多百分之十二张力就多百分之二十六——也是"不要把吉他往高调"这条标准建议说的是$T \propto f^{2}$、而不是弦的老化的原因。
:::
:::

::: exercise 纵向杆 {level=2}
一根$1\ \mathrm{m}$长的铝杆在第一阶自由–自由纵向模态以$2560\ \mathrm{Hz}$鸣响。求比值$E / \rho$，并与表列值$2.63 \times 10^{7}\ \mathrm{m^{2} / s^{2}}$比较。
::: solution
$$
c_L = 2 L f = 5120\ \mathrm{m / s}, \qquad
\frac{E}{\rho} = c_L^{2} = 2.62 \times 10^{7}\ \mathrm{m^{2} / s^{2}},
$$
与可热处理铝合金的表列值$2.63 \times 10^{7}\ \mathrm{m^{2} / s^{2}}$相差百分之零点五以内。
**合理性检验。**该测量是一项**材料**测量，对杆的截面和质量不敏感，是一项标准的无损检测技术：冲击激振法（ASTM E1876）从小矩形杆的弯曲和扭转共振读出$E$和$G$，用于表征陶瓷、混凝土和增材制造试件而不破坏它们。其精度受基本假设——杆是细长且自由的——以及厚杆弯曲共振所需的剪切与转动惯量修正的限制。
:::
:::

::: exercise 管风琴管 {level=2}
一根闭管管风琴管要发出$261.6\ \mathrm{Hz}$的中音C。若口径$40\ \mathrm{mm}$、声速$343\ \mathrm{m / s}$，求其长度。
::: solution
$$
L + 0.6 R = \frac{c}{4 f} = 0.3278\ \mathrm{m}
\quad\Longrightarrow\quad
L = 0.3278 - 0.012 = 0.316\ \mathrm{m}.
$$
**合理性检验。**端部修正占长度的百分之四，对喇叭口或有唇的管比光管更大——这就是管风琴师逐管手工整音调音的原因。同一修正也是亥姆霍兹共振器公式带一个"有效长度"的原因，也是消声器第一个衰减谷从不落在图纸算术所说位置的原因。
:::

::: exercise 模态密度 {level=2}
求例 3 钻柱的模态密度（每赫兹模态数），以及$2\ \mathrm{m}$见方、$2\ \mathrm{mm}$厚钢板弯曲振动（$\nu = 0.3$）的模态密度。
::: solution
**弦。**$\mathrm{d}N / \mathrm{d}f = 2 L / c = 200 / 5048 = 0.0396$模每赫兹，每$25\ \mathrm{Hz}$一个模态。
**板。**面积为$A$的薄板弯曲时$\mathrm{d}N / \mathrm{d}f = \left( A / 2 \right) \sqrt{\rho h / D}$，与频率无关。取$D = E h^{3} / 12 \left( 1 - \nu^{2} \right) = 146.5\ \mathrm{N\, m}$、$\rho h = 15.7\ \mathrm{kg / m^{2}}$，
$$
\frac{\mathrm{d}N}{\mathrm{d}f} = 2 \times \sqrt{\frac{15.7}{146.5}} = 0.65\ \mathrm{Hz^{- 1}},
$$
每$1.5\ \mathrm{Hz}$一个模态。
**合理性检验。**模态密度决定谐波分析是**离散**问题还是**统计**问题。每二十五赫兹一个模态意味着十赫兹的激励带宽里一个都没有，响应是寥寥几个共振；像板那样每一赫兹半一个模态，意味着同样带宽里约有七个；频率更高、结构更大时数目以百计，响应就成了一个各个频率已不再要紧的功率流问题。这一转变就是统计能量分析的工作范围，而模态重叠因子——模态带宽与模态间距之比——是选方法之前要算的数。
:::
:::

::: exercise 梁与弦 {level=3}
一根长$300\ \mathrm{mm}$、宽$20\ \mathrm{mm}$、厚$2\ \mathrm{mm}$、两端铰支的钢带受轴向力$P$张紧。求使其第一弯曲频率加倍的$P$，以及该频率降为零时的压力载荷。
::: solution
对铰支梁，振形$\sin \left( \pi x / L \right)$不受轴向张力影响，频率严格按
$$
f^{2} = f_{\text{beam}}^{2} + f_{\text{string}}^{2},
\qquad
f_{\text{string}} = \frac{1}{2 L} \sqrt{\frac{P}{\rho A}}
$$
提高梁的频率。
这里$I = 1.333 \times 10^{- 11}\ \mathrm{m^{4}}$、$\rho A = 0.314\ \mathrm{kg / m}$，所以
$$
\sqrt{\frac{EI}{\rho A L^{4}}} = 32.4\ \mathrm{s^{- 1}},
\qquad
f_{\text{beam}} = \frac{\pi^{2} \times 32.4}{2 \pi} = 50.9\ \mathrm{Hz},
\qquad
f_{\text{string}} = 2.974 \sqrt{P} ,
$$
加倍要求$f_{\text{string}} = \sqrt{3} \times 50.9 = 88.1\ \mathrm{Hz}$，所以
$$
P = \left( \frac{88.1}{2.974} \right)^{2} = 877\ \mathrm{N}.
$$
欧拉屈曲载荷为$P_{\text{cr}} = \pi^{2} EI / L^{2} = 292\ \mathrm{N}$，而且确实$f^{2} = f_{\text{beam}}^{2} \left( 1 + P / P_{\text{cr}} \right)$，所以频率加倍恰好需要$P = 3 P_{\text{cr}}$，而在$292\ \mathrm{N}$的压力下频率降为零。
**合理性检验。**零频率情形就是**屈曲**载荷，公式说明了原因：轴力变为压力时$f$趋于零，到达$- P_{\text{cr}}$时"频率"变成虚数、模态变成分岔。测量张紧构件的频率随张力的变化并外推到零，是一种真实而精确的方法，用于寻找无法直接测量的载荷——用于斜拉索、桩的拉力和埋入钢筋的应力——它之所以有效，是因为频率是一台**张力计**，其标定只涉及长度和线密度。它的弱点恰是同一个平方律：低张力下频率由弯曲主导、对载荷几乎不敏感——这就是索张力计对松弛索不可靠的原因。
:::

::: exercise 推导 {level=3}
推导两端**简支**均匀梁的频率方程，并证明其谱是单一频率的$n^{2}$倍。为什么它关于$n^{2}$谐波而关于$n$不谐波？
::: solution
边界条件是两端$\phi = 0$且$\phi'' = 0$。代入通解，
$$
\phi (0 ) = 0 \Rightarrow A + C = 0, \qquad
\phi'' (0 ) = 0 \Rightarrow \beta^{2} \left( A - C \right) = 0
\quad\Longrightarrow\quad A = C = 0 ,
$$
剩下的$\phi = B \sinh \beta x + D \sin \beta x$在$x = L$给出
$$
B \sinh \beta L + D \sin \beta L = 0, \qquad
B \sinh \beta L - D \sin \beta L = 0 ,
$$
所以$B = 0$且$\sin \beta L = 0$，于是$\beta_n L = n \pi$且
$$
f_n = \frac{n^{2} \pi^{2}}{2 \pi L^{2}} \sqrt{\frac{EI}{\rho A}} . \quad \checkmark
$$
**注。**简支梁是唯一干净分离的情形：两端的条件$\phi = \phi'' = 0$仅由$\sin \beta x$就能满足，所以双曲项脱落、没有超越方程幸存。谱按$n^{2}$而不是$n$走，是因为弯曲的恢复力是转角的**二阶**导数——波数为$k$的模态曲率正比于$k^{2}$、因而应变能正比于$k^{4}$，而动能按质量走，所以$\omega^{2} \propto k^{4}$、$\omega \propto k^{2}$。弦的恢复力只正比于曲率，$\omega \propto k$。空间算子阶数的这一个差别，就是梁听起来像钟而弦听起来像弦的原因，也是必须发出乐音的乐器设计就是其边界条件设计的原因。
:::
