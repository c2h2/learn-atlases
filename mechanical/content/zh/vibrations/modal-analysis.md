有限元模型是一个假说，振动试验是证据。模态分析就是诚实地比较二者的学科：它从测量中提取一组带不确定度声明的频率、阻尼比和振型，并判定一个计算模态和一个实测模态是否是同一个物理实体。做好之后，它是工程师能够信任装配结构动力学模型的唯一理由，因为接头、螺栓、密封胶、电缆和灌浆垫块的刚度不在图纸里、也不在模型里，而它们能把答案改变两倍。

两个思想使整个学科运转起来。第一个是**频率响应函数**，它是上一课的机械导纳的实测版本而非计算版本，其极点就是模态。第二个是实测振型是一个**向量**，而比较两个向量需要一个对缩放、对分量单位、对测量点顺序都不变的数——**模态置信准则**。

::: warning 模态是估计算法说它是什么它就是什么
对同一批数据使用不同的提取算法会返回不同的频率，而差别不是错误而是**假设**。峰值拾取假设模态分隔良好、阻尼轻微且频率间隔超过分析分辨率；圆拟合假设每个频率由单一模态主导；多参考最小二乘拟合假设带内有固定数目的模态；随机子空间拟合假设激励是白的、结构是线性平稳的。用一个假设错了百分之十的算法报出四位有效数字的频率不是测量，诚实的报告给出多次拟合的**散布带**，而不是一个数。
:::

## 测量频率响应函数

::: definition 输入–输出估计器 {#def-estimators}
以力$f$和响应$x$，真实机械导纳为$\alpha = X / F$。对自谱和互谱取$N$次平均后测量，
$$
H_1 = \frac{G_{xf}}{G_{ff}}, \qquad
H_2 = \frac{G_{xx}}{G_{fx}}, \qquad
H_3 = \frac{G_{xf} - G_{nn}^{x} / c}{G_{ff} - G_{nn}^{f} / c} ,
$$
其中$G$表示平均谱密度，$G_{nn}$表示噪声底。若**力**测量被噪声污染，$H_1$偏低而$H_2$无偏；若**响应**被污染，则相反。因此在全频段上比较$H_1$和$H_2$不是走过场而是标准诊断：一致说明测量自洽，不一致则定位噪声。
:::

::: proof H1估计器的偏差 {#proof-h1bias}
设测得的力为$f_m = f + n_f$，噪声$n_f$与$f$和响应$x = \alpha f$都不相关，响应无噪声。则
$$
G_{x f_m} = \alpha G_{ff}, \qquad
G_{f_m f_m} = G_{ff} + G_{n_f n_f},
\qquad
H_1 = \frac{\alpha G_{ff}}{G_{ff} + G_{n_f n_f}}
= \frac{\alpha}{1 + G_{n_f n_f} / G_{ff}} .
$$
因此该估计器按力信噪比的倒数**偏低**，且误差在力谱最小处最严重——对冲击试验是频带两端，对振动台是反共振处。同时
$$
H_2 = \frac{G_{xx}}{G_{x f_m}} = \frac{\alpha^{2} G_{ff}}{\alpha G_{ff}} = \alpha ,
$$
是无偏的。$\checkmark$

**注。**同样的代数对带噪声的加速度计给出$H_2$偏低、$H_1$无偏，所以数对$\left( H_1 , H_2 \right)$把真值夹在中间，而**相干函数**$\gamma^{2} = G_{xf}^{2} / \left( G_{xx} G_{ff} \right)$报告二者应相差多少：$1 - \gamma^{2}$在一阶近似下就是噪声功率份额。相干$0.9$听起来极好，却对应该频率上百分之三十的幅值误差——这就是模态报告必须画出相干随频率的曲线、而不能仅仅断言它高于某个门限的原因。
:::

::: definition 模态置信准则 {#def-mac}
对两个振型向量$\left\{ A \right\}$和$\left\{ B \right\}$，
$$
\operatorname{MAC} = \frac{\left| \left\{ A \right\}^{\mathrm{H}} \left\{ B \right\} \right|^{2}}{\left( \left\{ A \right\}^{\mathrm{H}} \left\{ A \right\} \right) \left( \left\{ B \right\}^{\mathrm{H}} \left\{ B \right\} \right)}
= \cos^{2} \theta ,
$$
即复向量空间中二者夹角的余弦平方。比例向量$\operatorname{MAC} = 1$，正交向量为$0$。**非对角**形式使用质量矩阵，$\left\{ A \right\}^{\mathrm{H}} \mathbf{M} \left\{ B \right\}$，度量的是一个模态被另一个模态污染的程度而不是它们的相似度。
:::

::: definition 模态模型与部件综合 {#def-cms}
**模态模型**用模态矩阵取代物理矩阵，
$$
\mathbf{M} \approx \boldsymbol{\Phi}_n \boldsymbol{\Phi}_n^{\mathrm{T}} \mathbf{M} \boldsymbol{\Phi}_n \boldsymbol{\Phi}_n^{\mathrm{T}},
\qquad
\mathbf{K} \approx \boldsymbol{\Phi}_n \operatorname{diag} \left( \omega_r^{2} m_r \right) \boldsymbol{\Phi}_n^{\mathrm{T}} ,
$$
截断到要紧的$n$个模态，而这只有在关注频段之上才合法，因为截断的模态模型在低频是**硬**的：它不含被丢弃模态的静柔度。补救是加入**残余柔度**项，而同一论证正是**部件模态综合**的基础——子结构由其低阶模态加一组静约束模态表示：**盖恩（Guyan）**缩减只用界面自由度，**克雷格–班普顿（Craig–Bampton）**则同时使用固定界面固有模态和静约束模态。试验从另一个方向给出同一个对象：实测模态模型复现测量带内的频率响应函数，带外什么也不复现。
:::

::: proof MAC就是一个余弦平方，仅此而已 {#proof-mac}
插入正交归一基$\left\{ u_i \right\}$，写$\left\{ A \right\} = \sum_i a_i \left\{ u_i \right\}$、$\left\{ B \right\} = \sum_i b_i \left\{ u_i \right\}$。则
$$
\operatorname{MAC} = \frac{\left| \sum_i a_i^{*} b_i \right|^{2}}{\left( \sum_i \left| a_i \right|^{2} \right) \left( \sum_i \left| b_i \right|^{2} \right)} .
$$
由柯西–施瓦茨（Cauchy–Schwarz）不等式，它介于$0$与$1$之间，上界当且仅当$b_i = c a_i$（某个常数$c$）时取到，即当且仅当两向量**成比例**时取到。分子分母对每个向量都是二次齐次的，所以任一向量乘以任意常数都不改变MAC；二者又对幺正基变换不变，其中包括重排测量点、以及在一点处平动分量与转动分量之间旋转。$\checkmark$

**注。**这些不变性正是要点。试验给出的振型单位是微伏每g、按任意参考缩放，模型给出的振型以最大位移为一归一化，而二者是在不同的点、以不同的顺序测得的——MAC是唯一能扛住这三点的比较。它一个危险性质是对**幅值误差钝感**：形状对而幅值错的振型能得满分一。因此模态报告要同时给出MAC**和**广义相位互易（一种只比相位的比较）**和**频率差，三者一致才接受一个模态。
:::

::: example 标定试件 {#ex-cantilever}
一根钢悬臂梁长$150\ \mathrm{mm}$、宽$20\ \mathrm{mm}$、厚$3\ \mathrm{mm}$，$E = 200\ \mathrm{GPa}$、$\rho = 7850\ \mathrm{kg / m^{3}}$。在冲击试验之前预测前三阶固有频率。
::: solution
$$
I = \frac{b h^{3}}{12} = 4.50 \times 10^{- 11}\ \mathrm{m^{4}}, \quad
EI = 9.00\ \mathrm{N\, m^{2}}, \quad
\mu = \rho b h = 0.471\ \mathrm{kg / m},
$$
$$
f_n = \frac{\left( \beta_n L \right)^{2}}{2 \pi} \sqrt{\frac{EI}{\mu L^{4}}}, \qquad
\beta_n L = 1.875 , 4.694 , 7.855 ,
\qquad \sqrt{\frac{EI}{\mu L^{4}}} = 194.3\ \mathrm{s^{- 1}} ,
$$
$$
f_1 = 108.7\ \mathrm{Hz}, \qquad f_2 = 681\ \mathrm{Hz}, \qquad f_3 = 1908\ \mathrm{Hz}.
$$
**校核。**用静挠度曲线$\varphi = 1.5 u^{2} - 0.5 u^{3}$的瑞利法给出
$$
k_{\text{eq}} = EI \int_0^L \left( \varphi'' \right)^{2} \mathrm{d}x = \frac{3 EI}{L^{3}} = 8000\ \mathrm{N / m},
\qquad
m_{\text{eq}} = 0.2357 \mu L = 0.01665\ \mathrm{kg},
$$
$$
f = \frac{1}{2 \pi} \sqrt{\frac{8000}{0.01665}} = 110.3\ \mathrm{Hz},
$$
比精确值高百分之一二，符合瑞利上限定理的要求。$\checkmark$

**合理性检验。**这个尺寸的一个机加工、均质、夹持良好的试件，是模态实验室里最接近尺子的东西，一次好的试验能把$f_1$复现到百分之二三以内——前提是夹持真的刚性。台钳里的$150\ \mathrm{mm}$悬臂梁实际上是装在扭转弹簧上的悬臂梁，若台钳每牛·米转一微弧度，第一频率就下降约百分之十。这就是标定试件要软支撑**自由–自由**测试的原因，也是"模型与试验相差百分之八"多半说的是螺栓接头而不是有限元网格的原因。
:::
:::

::: example 用质量加载找节线 {#ex-mass-loading}
把$20\ \mathrm{g}$的一块质量粘在例 1 试件的端部，第一频率降到$74.4\ \mathrm{Hz}$。解释之；并预测同一质量放在**一阶转角为零**的点时的降幅。
::: solution
**端部。**用瑞利模型，
$$
f = \frac{1}{2 \pi} \sqrt{\frac{8000}{0.01665 + 0.020}} = 74.4\ \mathrm{Hz},
$$
降幅百分之三十二，与测量一致。
**在转角为零的点**，附加质量不动，所以什么都不贡献，频率不变。第一模态的转角只在根部为零，所以该试验的实用形式是把质量沿试件移动并画出频率：曲线是$\varphi^{2}$的按比例图像，其极小值定位模态的节点。

**校核。**实测比$74.4 / 108.7 = 0.684$，对比预测的$\sqrt{0.01665 / 0.03665} = 0.674$——差百分之一二，可归因于质量自身的转动惯量和瑞利振形的近似性。$\checkmark$

**合理性检验。**这种粗糙的"一块橡皮泥"普查是最古老的模态技术，也仍然最稳健，因为它不需要相位、不需要参考、不需要第二个传感器。它也是**每次试验都必须考虑质量加载**的原因：八克的加速度计装在$3\ \mathrm{mm}$钢梁上，就是在模态最大处加了$1.7\%$的质量，会把实测频率压低约百分之一——超过分析员想要分辨的不确定度。修正式为$f_{\text{true}} = f_{\text{meas}} \sqrt{1 + m_a \varphi^2 / m_{\text{eq}}}$，用不用它是模态普查与频率普查的区别。
:::
:::

::: example 模型与试验的比较 {#ex-mac}
某有限元模型和一次冲击试验给出梁上三点的如下三分量振型：
$$
\{ A \} = \left( 1.00 , 0.62 , - 0.31 \right), \qquad
\{ B \} = \left( 0.95 , 0.75 , - 0.20 \right) .
$$
计算MAC并判断配对。
::: solution
$$
\{ A \}^{\mathrm{T}} \{ B \} = 0.950 + 0.465 + 0.062 = 1.477 ,
$$
$$
\{ A \}^{\mathrm{T}} \{ A \} = 1.000 + 0.384 + 0.096 = 1.480 , \quad
\{ B \}^{\mathrm{T}} \{ B \} = 0.903 + 0.563 + 0.040 = 1.505 ,
$$
$$
\operatorname{MAC} = \frac{1.477^{2}}{1.480 \times 1.505} = 0.979 .
$$
**合理性检验。**MAC为$0.98$是一次好的配对，二者无疑是同一个模态，但形状差别并非微不足道：第二分量差百分之二十一，第三分量差三分之一，在相关图上这是看得见的扭曲。由**三个**点算出的MAC作为质量声明也近乎没有意义——三个分量三个未知数，几乎任何一对向量都得高分。"MAC高于$0.9$算同一个模态、低于$0.7$算不同模态"这条经验法则是在航空板件二十点普查上建立的，把它用到支架的三点普查上，就是一个坏模型被签字放行的方式。
:::
:::

::: example 诊断H1与H2 {#ex-h1h2}
一次经隔振器做的振动台试验，$H_1$和$H_2$在$200\ \mathrm{Hz}$以下一致到百分之二，到$600\ \mathrm{Hz}$逐渐发散，在$600\ \mathrm{Hz}$相差三倍且$H_1$较小。发生了什么？
::: solution
$H_1$偏低而$H_2$无偏意味着**力测量噪声**，而随频率增长的发散意味着噪声不是白的，而是谱随频率上升的那种。经典原因是**顶杆或太软的顶杆杆**自身共振就在附近，或者更常见的是惯性误差：力传感器自身的质量在加速，所以测得的力是$F - m_t a$，误差按$\omega^{2}$增长。
**诊断。**把$1 - \gamma^{2}$与发散程度对照。若相干高而发散大，两种误差是**相关的**——真实的结构非线性或夹具打滑，而不是噪声。若相干随发散一起下降，那是噪声，祸首是传感器系统。

**合理性检验。**惯性误差机理就是模态力传感器做得尽可能轻、并装在**被驱动**一侧的原因，也是几百赫兹以上经软顶杆做的试验只被当作定性结果的原因。这种记录里报出的$600\ \mathrm{Hz}$"共振"可能就是顶杆自身的弯曲模态，证明的办法是换顶杆看哪个峰移动：结构模态留在原地，夹具模态跟着夹具走。
:::
:::

::: example 运行模态分析 {#ex-oma}
一座桥梁装了十六个加速度计而没有力测量；激励它的只有车流和风。解释如何提取模态，以及答案包含什么、不包含什么。
::: solution
仅输出的**功率谱密度矩阵**为
$$
\left[ G_{xx} (\omega ) \right] = \left[ \Phi \right] \left[ G_{ff} (\omega ) \right] \left[ \Phi \right]^{\mathrm{T}*} ,
$$
对白、带限、不相关的激励，$\left[ G_{ff} \right]$是对角常数阵，所以在每个频率对$\left[ G_{xx} \right]$做**奇异值分解**，每个共振附近给出一个占主导的奇异值，其奇异向量就是振型。这就是**频域分解**。或者，输出的相关函数满足与自由振动相同的齐次方程——**自然激励技术**——再用随机子空间拟合从单段长记录返回频率、阻尼和模态。

**缺什么。**模态出来时**没有任何质量归一化**：运行模态振型没有尺度，因为没有力可以去除。频率和阻尼是绝对的，可与模型直接比较；形状只能比到一个常数——这正是MAC能容忍的，而**刚度**修正不能容忍的。

**合理性检验。**仅输出方法是为这样的土木结构开发的：没人能称一座桥的重量，也没人能给它装振动台；如今它是风力发电机的标准做法——激励是风，而结构在两百米高处够不着。它唯一的系统性弱点是**环境变异性**：桥梁的频率随温度移动百分之几，因此寻找频率下降的损伤探测算法，找的其实是一个天气比裂纹更可靠地制造出来的信号。严肃的结构健康监测跟踪**振型**或温度补偿后的频率，报告的是概率而不是报警。
:::
:::

::: example 设计 {#ex-design-test}
规划一台$12\ \mathrm{kg}$仪表支架的模态普查，它螺栓连接到振动台台面，计算的前五阶模态位于$180$到$900\ \mathrm{Hz}$之间。
::: solution
**频带。**至少测到最高关注模态的$1.2$倍，即$1.1\ \mathrm{kHz}$；频率分辨率不超过半功率带宽的一半：$\zeta = 0.01$、$900\ \mathrm{Hz}$时半功率带宽为$18\ \mathrm{Hz}$，所以$\Delta f \le 9\ \mathrm{Hz}$，取$1.6\ \mathrm{Hz}$很从容。
**激励。**对$12\ \mathrm{kg}$的支架，模态锤在$180\ \mathrm{Hz}$输入太小；改用小型激振器经**软**顶杆驱动，支架装在自己的隔振器上，使振动台接地的动圈臂不成为结构的一部分。
**测点。**在模态有应变的面上取二十四个点、三个正交方向，避开计算模态的节线——节点上的一个点测到的是模态的**负值**，可能把振形翻转。
**参考。**整个试验期间在支架上留一个三轴加速度计，再移到第二个位置做重复试验以检查MAC。
**质量加载。**$12\ \mathrm{kg}$支架上$2\ \mathrm{g}$的加速度计可以忽略；薄面上$20\ \mathrm{g}$的线缆夹不行。

**设计点评。**决定结果质量的唯一决策是**参考传感器位置**，标准错误是把它放在响应最大的点——那里夹具自身的局部模态主导参考通道，每个实测振型都继承它的相位。正确的选择是一个远离局部模态、三个方向耦合都好的点，从计算振型中选定而不是图省事。第二个决策是支架是否**按装配状态**试验——带电缆、带盖板、按规定力矩——若答案是否，试验测的就是一个服役中永远不会出现的结构，这是模态普查最普遍的失效方式。
:::

定量模态试验始于1950年代的**传递阻抗**测量装置：一个电动振动台、一个相位计和一个记录仪，一下午产出一条曲线上的一个点；**肯尼迪（Kennedy）与帕诺夫斯基（Panofsky）**1956年的教科书和同一十年的桑迪亚与国家航空咨询委员会报告确立了方法。**冲击**或**锤击**试验约1968年在通用动力公司由**坎宁安（Cunningham）**发明，**威廉斯（Williams）、牛顿（Newton）与凯撒（Kaiser）**以及**纽兰德（Newland）与沃拉斯（Wallace）**也各自独立报告，它使模态试验从实验室技术变成现场技术。1969–1974年的**俄勒冈协调试验计划**中，二十四个实验室测量同一个十格焊接空间框架并比较结果，至今仍是这门学科做过的最有教益的实验：报告频率的散布大于别处报告的多数分析–试验之差——这就是严肃模态报告要给出不确定度的原因。**快速傅里叶分析仪**在1960年代末商用，使$H_1$、$H_2$估计器对变得实用；**海伍德（Heywood）**、**苏瓦兹（Soize）**，尤其是**尤因斯（Ewins）**——其1984年的《模态试验》（*Modal Testing*）教育了两代人——把估计器带入现代形态。**模态置信准则**在1970年代末出现于**施图姆（Sturm）**以及**阿伯内西（Abernethy）与布伦南（Brennan）**的工作中。**盖恩（Guyan）**1965年的静力缩减和**克雷格（Craig）与钱奇–班普顿（Chang-Bampton）**1968年的工作使部件模态综合成为可能，模型修正跟随1980年代的灵敏度分析，而仅输出识别——1990年代的**自然激励技术**和**布林克尔（Brincker）**2000年的频域分解——通过彻底省去力测量把整个方法翻了个面。
:::

::: quiz
一个实测模态与对应的计算模态的模态置信准则为$0.62$。最可能的解释是：
- [ ] 缩放误差，因为两个振型单位不同
- [x] 形状确实不同，因为MAC对缩放不变，而$0.62$对应约$51^{\circ}$的夹角
- [ ] 频率误差，因为MAC依赖于频率
- [ ] 阻尼误差，因为MAC是在共振处测的
::: solution
MAC对缩放、单位和测量点顺序都不变，所以$0.62$不可能是缩放伪影；它是$\cos^2\theta$，所以两向量在形状空间中相差$\theta = \arccos\sqrt{0.62} = 51^{\circ}$。要么配对错了——该模态被配到了错误的计算模态，两个计算模态靠得近时这很常见——要么模型漏掉了什么结构性的东西。首先要检查的是**配对**，方法是看完整的MAC矩阵而不是对角线，因为模态对调给出的恰好就是这个数，而且比五十度的形状误差常见得多。
:::
:::

## 后续内容

模态试验所测量的机械导纳就是[[vibrations/two-degrees-of-freedom]]和[[vibrations/harmonic-excitation]]中的那些，估计器所平均的随机谱是[[vibrations/general-excitation]]中的那些，离散普查所逼近的连续模态见[[vibrations/continuous-systems]]，而会把普查搞混的反共振所在的吸振器与支承见[[vibrations/vibration-absorbers]]和[[vibrations/isolation-transmissibility]]。

::: summary
- 频率响应函数是测出来的而不是算出来的，估计器对$H_1$、$H_2$把真值夹在中间：二者的发散定位噪声，相干函数量化噪声。
- 模态是频率响应函数的极点；提取算法的差别在于它们对测量点之间的模态做了哪些假设。
- 振型用模态置信准则比较——一个对缩放和基不变的余弦平方——它必须与一个相位判据和一个频率差配套使用。
- 每次测量都在给结构加载：加速度计是附加质量，夹具是附加刚度，修正模型之前两者都必须计入。
- 仅输出方法从环境响应本身恢复频率、阻尼和无尺度形状，代价是失去了给力——从而给模态大小——的参考。
- 模态普查要按计算振型来规划：参考位置、测点和激励点的选择是为了避开节点和夹具局部模态，而不是图方便。
:::

::: exercise 相干 {level=1 check="0.9"}
某频率响应函数的测量相干为$0.90$。$1 - \gamma^{2}$是多少？
::: solution
$0.10$。

::: exercise MAC {level=1 check="1"}
一个振型与它自己乘以$3.7$的模态置信准则是多少？
::: solution
$1$，因为MAC对缩放不变。

::: exercise 估计器 {level=1 check="0.9"}
某试验力通道的信噪功率比为$9$。$H_1$偏低的因子是多少？
::: solution
$1 / \left( 1 + 1 / 9 \right) = 0.90$。
:::

::: exercise 节点 {level=1 check="0"}
恰好落在某模态一条节线上的点，该模态的留数是多少？
::: solution
零——模态在那里既不被激励也不被观测。

::: exercise 梁频率 {level=2}
对例 1 的试件，求同一根梁用作**简支**跨时的第一频率。
::: solution
$$
\beta_1 L = \pi, \qquad
f_1 = \frac{\pi^{2}}{2 \pi} \times 194.3 = \frac{\pi}{2} \times 194.3 = 305\ \mathrm{Hz}.
$$
**合理性检验。**简支频率是悬臂频率的$2.8$倍，因为悬臂模态在自由端达到满幅，而简支模态在两端被按住位移和转角都为零。比值$\left( \pi / 1.875 \right)^{2} = 2.80$是自由–自由或简支试验的有用校验，而这个巨大差别就是结构的**边界条件**——而不是网格密度——是模型与试验不符的主导原因的原因。
:::
:::

::: exercise 质量加载 {level=2}
一个$5\ \mathrm{g}$的加速度计放在例 1 试件的端部。估算实测的第一频率。
::: solution
$$
f = \frac{1}{2 \pi} \sqrt{\frac{8000}{0.01665 + 0.005}} = 96.7\ \mathrm{Hz},
$$
对比真实值$108.7\ \mathrm{Hz}$，误差百分之十一。
**合理性检验。**百分之十一远超一个好的有限元模型的不确定度，这意味着在轻结构上**测量定义了结构**，分析员必须要么修正传感器的影响，要么把传感器沿节线布置，要么使用什么都不添加的扫描激光测振仪。这就是小型柔性结构的模态普查如今通常用光学方法完成的原因，也是修正式$f_{\text{true}} = f_{\text{meas}} \sqrt{1 + m_a \varphi^{2} / m_{\text{eq}}}$应当印在轻结构试验规程首页的原因。
:::
:::

::: exercise 非对角MAC {level=2}
两个实测模态给出$\{ A \}^{\mathrm{T}} \mathbf{M} \{ B \} = 0.12\ \mathrm{kg}$，且$\{ A \}^{\mathrm{T}} \mathbf{M} \{ A \} = 2.0\ \mathrm{kg}$、$\{ B \}^{\mathrm{T}} \mathbf{M} \{ B \} = 2.4\ \mathrm{kg}$。求非对角MAC并评论。
::: solution
$$
\operatorname{MAC}_{\text{off}} = \frac{0.12^{2}}{2.0 \times 2.4} = 0.003 = 0.3\ \% .
$$
**合理性检验。**相互污染低于百分之一，意味着两个实测模态接近到测量所能显示的质量正交，这是提取已把它们正确分开的现有最强证据。大的非对角值是**混合**对的特征，发生在两个模态靠得近、算法把一对真实模态劈成它们自身的两个任意线性组合时。那种情形下单个振型根本不是物理的，只有它们张成的**子空间**是物理的，诚实的报告应当这么写，而不是报出两个振型和两个MAC。
:::
:::

::: exercise 频率分辨率 {level=2}
$500\ \mathrm{Hz}$的一个模态阻尼为百分之三。傅里叶分析需要多大的频率分辨率和多长的记录？分辨率太粗会出什么问题？
::: solution
$$
\Delta f_{1 / 2} = \zeta f_n = 15\ \mathrm{Hz}, \qquad
\Delta f \le \frac{1}{2} \Delta f_{1 / 2} = 7.5\ \mathrm{Hz},
\qquad
T = \frac{1}{\Delta f} \ge 0.13\ \mathrm{s}.
$$
**合理性检验。**要求不仅是峰可见，而是峰的每一侧要坐上**好几条**谱线，因为峰值拾取算法对最大值周围的点拟合曲线，而峰上只有两个点的模态，其频率不确定度达一整个谱线间隔。对轻阻尼结构，记录长度成为限制因素——$100\ \mathrm{Hz}$处百分之一的阻尼需要半秒的记录和一个不把峰抹宽的**矩形**窗——这就是轻阻尼结构的锤击试验必须用指数窗和长记录的原因，也是锤击试验报告的阻尼几乎总是偏高的原因。
:::
:::

::: exercise 模型修正 {level=3}
某模型预测$f_1 = 118\ \mathrm{Hz}$而试验给出$108.7\ \mathrm{Hz}$；振型由**根部转动**主导而不是梁弯曲。估算能解释这一差别的夹持转动刚度。
::: solution
把梁当作单自由度系统，根部带转动弹簧$K_{\theta}$。频率比给出
$$
\left( \frac{108.7}{118} \right)^{2} = 0.848
$$
作为有效刚度之比。把悬臂梁自身的端部转动柔度写为$\theta / M = L / EI$，加上夹持的$1 / K_{\theta}$，
$$
\frac{k_{\text{clamped}}}{k_{\text{rigid}}} = \frac{1}{1 + EI / \left( K_{\theta} L \right)} = 0.848
\quad\Longrightarrow\quad
K_{\theta} = \frac{EI}{L} \times \frac{0.848}{1 - 0.848} = 60 \times 5.6 = 340\ \mathrm{N\, m / rad} .
$$
**合理性检验。**$340\ \mathrm{N\, m / rad}$的夹持转动刚度是一个中等紧固程度的螺栓接头，不是刚性固支，对台钳里的试件来说完全典型。这一教训推广为**模型修正**的标准建议：修正你指得出的参数。单个频率不能告诉你哪个刚度错了；一个频率**加**一个形状能告诉你误差在哪种变形里，修正抵抗那种变形的接头是一个站得住的模型改动，而把所有单元的模量乘以同一个因子去凑频率则是曲线拟合，经不起设计的改变。
:::
:::

::: exercise 推导 {level=3}
证明比例阻尼系统在坐标$i$与$j$之间测得的频率响应函数可写成单自由度项之和，并指出模态试验测量什么、不能测量什么。
::: solution
由模态展开，
$$
\alpha_{ij} (\omega ) = \sum_{r = 1}^{n} \frac{\phi_r (i ) \phi_r (j )}{k_r - \omega^{2} m_r + \mathrm{i} \omega c_r}
= \sum_r \frac{\phi_r (i ) \phi_r (j ) / m_r}{\omega_r^{2} - \omega^{2} + 2 \mathrm{i} \zeta_r \omega_r \omega} .
$$
试验测量的是**留数**$\phi_r (i ) \phi_r (j ) / m_r$、**极点**$\omega_r$、$\zeta_r$，此外别无其他。所以模态尺度$\phi_r$只能作为两点分量的**乘积**恢复，绝对尺度需要一个已知量——一个已知质量、一个已知静刚度，或一个实测**有效模态质量**。
**合理性检验。**这正是没有力测量、因而根本没有留数的运行模态分析返回任意尺度振型的原因，也是必须为**载荷**分析提供输入的模态试验至少需要一个绝对测量的原因：带力传感器的振动台、已知偏心质量，或一次静态推载。这也是每份模态报告里都出现"振型已按最大值为1归一化"这句话的原因——归一化是强加给不含尺度信息的数据的约定，而针对这种振型修正的模型必须先按同样方式重新归一化，比较才有意义。
:::
:::
