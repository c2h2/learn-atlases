[[mechatronics/sensors]]中的传感器很少能给出控制器可以直接使用的信号。应变片电桥给出的是叠加在几伏共模电压上的几毫伏信号；热电偶每开尔文只给出几微伏；加速度计的信号与两根电缆之外的电机驱动器产生的电噪声混在一起。**信号调理**（signal conditioning）是把这类信号变成干净、比例正确的电压的电路链——放大、电桥补全、滤波、隔离——而**数据采集**（data acquisition）是它的最后一步，按选定的速率把电压转换为数值。这里的错误特别危险，因为调理不当的信号仍然会给出看似合理的数值：一个饱和的放大器、一个把信号本身滤掉的滤波器，或者一个把高频噪声折叠成缓慢而令人信服的漂移的采样频率。

本章讨论与传感器配用的运算放大器电路、惠斯通电桥、有源滤波器、噪声与干扰，以及模数转换与采样定理和混叠。运算放大器的电路理论在[电气工程图谱](/learn/ee/lesson.php?c=circuits-1&l=operational-amplifiers)中有更深入的讨论；这里我们集中于规定一条测量链的工程师必须计算的内容。

## 运算放大器电路 {#sec-opamps}

**运算放大器**（operational amplifier，op-amp）是一种高增益差分放大器：其输出为$v_o = A(v_+ - v_-)$，低频开环增益$A$为$10^5$–$10^6$，输入电阻很高，输出电阻很低。在测量电路中它从不开环使用；从输出到反相输入端的**负反馈**用电阻比来设定增益，与不确定的$A$值无关。

::: definition 理想运算放大器法则 {#def-ideal-opamp}
对于带负反馈、工作在其输出电压和频率限值以内的运算放大器，分析时使用两条法则：
1. **无输入电流**（虚断）：流入$+$和$-$输入端的电流为零。
2. **虚短**：反馈调节输出，使$v_+ = v_-$。

法则2源于：$v_o$有限时，当$A \to \infty$，$v_+ - v_- = v_o/A \to 0$。当输出饱和（达到电源轨）或信号频率接近运算放大器的增益带宽积时，两条法则都失效。
:::

::: proposition 反相、同相与差分放大器 {#prop-amps}
采用理想运算放大器时：

(a) **反相放大器**（输入经$R_{\text{in}}$接$-$输入端，反馈电阻$R_f$从输出接到$-$输入端，$+$输入端接地）：$v_o = -(R_f/R_{\text{in}})\,v_{\text{in}}$；输入电阻为$R_{\text{in}}$。

(b) **同相放大器**（输入接$+$；$R_g$从$-$接地，$R_f$从输出接到$-$）：$v_o = (1 + R_f/R_g)\,v_{\text{in}}$；输入电阻实际上为无穷大。令$R_f = 0$并去掉$R_g$，它就是**电压跟随器**（缓冲器），增益为$1$。

(c) **差分放大器**（$v_1$经$R_1$接$-$，$R_2$从输出接到$-$；$v_2$经$R_1$接$+$，$R_2$从$+$接地）：$v_o = (R_2/R_1)(v_2 - v_1)$。
:::

::: proof
(a) $+$输入端电位为$0$，由法则2，$-$输入端电位也为$0$（“虚地”）。电流$v_{\text{in}}/R_{\text{in}}$经$R_{\text{in}}$流入，由法则1，它全部继续流过$R_f$，所以$v_o = 0 - R_f\,v_{\text{in}}/R_{\text{in}}$。(b) $v_- = v_+ = v_{\text{in}}$。由于没有输入电流，$R_f$和$R_g$构成$v_o$的分压器：$v_- = v_oR_g/(R_g + R_f)$；令二者相等得$v_o = v_{\text{in}}(1 + R_f/R_g)$。(c) $+$输入端是$v_2$的分压器：$v_+ = v_2R_2/(R_1 + R_2)$。在$-$输入端应用KCL：$(v_1 - v_-)/R_1 = (v_- - v_o)/R_2$。利用$v_- = v_+$解出$v_o$：$v_o = v_-(1 + R_2/R_1) - v_1R_2/R_1 = v_2R_2/R_1 - v_1R_2/R_1$。
:::

差分放大器抑制两个输入端共有的任何电压——但其效果只取决于电阻比匹配得多好。如果一个比值相差一个比例$\delta$，共模电压$v_{cm}$就会产生$\delta\,v_{cm}R_2/(R_1 + R_2)$量级的输出误差。其品质因数是**共模抑制比**，$\mathrm{CMRR} = 20\log_{10}(G_{\text{diff}}/G_{cm})$，以分贝计。它的另一个弱点是其输入电阻（$R_1$和$R_1 + R_2$）会对信号源产生负载效应。这两个问题都由仪表放大器解决。

::: proposition 三运放仪表放大器 {#prop-inamp}
两个同相放大器共用一个接在它们反相输入端之间的增益电阻$R_G$，各自的反馈电阻为$R$，它们驱动一个单位增益差分放大器。输出为
$$
v_o = \left(1 + \frac{2R}{R_G}\right)(v_2 - v_1),
$$ {#eq-inamp}
两个输入端的输入电阻都是运算放大器同相输入端的输入电阻（很高），而共模电压以单位增益通过第一级，因而被差分级抑制。
:::

::: proof
由法则2，$R_G$两端的电位分别为$v_1$和$v_2$，所以流过它的电流为$i = (v_2 - v_1)/R_G$。由法则1，同一电流流过两个电阻$R$，所以第一级的输出为$v_{o2} = v_2 + iR$和$v_{o1} = v_1 - iR$，其差为$v_{o2} - v_{o1} = (v_2 - v_1)(1 + 2R/R_G)$。电阻相等的差分级给出$v_o = v_{o2} - v_{o1}$。共模输入$v_1 = v_2 = v_{cm}$使$i = 0$，所以第一级的两个输出都等于$v_{cm}$：第一级把差模放大$1 + 2R/R_G$倍，而共模只放大$1$倍，从而使总的CMRR乘以第一级增益。
:::

集成仪表放大器内含经激光修调的匹配电阻，只需一个外接电阻$R_G$设定增益，高增益时CMRR超过$100\ \mathrm{dB}$。它们是电桥、热电偶和生物医学电极的标准前端。

## 惠斯通电桥 {#sec-bridge}

应变片的电阻变化最多只有约$0.1\,\%$。用电流给单个应变片供电并测量其两端电压，意味着要在几伏的信号上检测毫伏级的变化，而电源的任何漂移都会把它淹没。**惠斯通电桥**把大的恒定部分减掉。

::: proposition 电桥输出 {#prop-bridge}
四个电阻在激励电压$V_s$两端构成两个分压器：左边为$R_1$（上）和$R_2$（下），右边为$R_4$（上）和$R_3$（下）。右、左两个中点之间的差分输出为
$$
V_o = V_s\left(\frac{R_3}{R_3 + R_4} - \frac{R_2}{R_1 + R_2}\right),
$$ {#eq-bridge}
当$R_1R_3 = R_2R_4$时输出为零（电桥**平衡**）。对于四臂都等于$R$、变化$\Delta R_i$很小的情形，
$$
V_o \approx \frac{V_s}{4}\left(\frac{\Delta R_3}{R} - \frac{\Delta R_4}{R} - \frac{\Delta R_2}{R} + \frac{\Delta R_1}{R}\right).
$$ {#eq-bridge-lin}
对于**四分之一桥**（单臂电桥，一片工作应变片，$\Delta R_3 = \Delta R$），精确输出为$V_o = V_s\,x/(4 + 2x)$，其中$x = \Delta R/R$，近似为$V_s\,GF\,\varepsilon/4$。
:::

::: proof
每个中点电压都是一个分压器的输出（[[mechatronics/mechatronic-systems#eq-divider]]），由于输出由仪表放大器读取，分压器不受负载；相减即得[[#eq-bridge]]。平衡条件：$R_3/(R_3 + R_4) = R_2/(R_1 + R_2)$交叉相乘得$R_3R_1 = R_2R_4$。线性化时，$R_3/(R_3 + R_4)$对$R_3$的偏导数在各臂相等时为$R_4/(R_3 + R_4)^2 = 1/(4R)$，对$R_4$的偏导数为$-1/(4R)$；同样，左边的分压器贡献$-\Delta R_2/(4R) + \Delta R_1/(4R)$。四分之一桥的精确值：$V_o = V_s[R(1 + x)/(R(2 + x)) - \tfrac12] = V_s\,x/(2(2 + x))$。
:::

式[[#eq-bridge-lin]]是电桥设计的关键。**相邻**桥臂（共用一个输出节点，如$R_3$和$R_4$）的变化相减；**相对**桥臂（$R_1$和$R_3$）的变化相加。因此：

- 桥臂3中一片受拉的应变片，与桥臂4中一片贴在同一材料上、处于同一温度、不受应变的相同“补偿”应变片，可抵消温度的影响；
- 在受弯梁上，桥臂3中一片贴在受拉面、桥臂4中一片贴在受压面，可使输出加倍（**半桥**）并抵消温度影响；
- 采用四片工作应变片，两片受拉、两片受压，接在合适的桥臂中（**全桥**），输出为$V_s\,GF\,\varepsilon$，是四分之一桥的四倍，严格线性，并有温度补偿。测力传感器都是全桥，用每伏激励电压的毫伏数表示其**额定输出**，典型值为$2\ \mathrm{mV/V}$。

电桥输出是**比率式**的：与$V_s$成正比。如果ADC的基准电压取自同一激励电压，电源的漂移就会在数字读数中抵消。

::: example 测力传感器的信号调理 {#ex-load-cell-chain}
一个额定输出为$2\ \mathrm{mV/V}$（$500\ \mathrm{N}$时）的全桥测力传感器用$5.0\ \mathrm{V}$激励。要用一个内部电阻为$R = 25\ \mathrm{k\Omega}$的仪表放大器把满量程映射到约$2.5\ \mathrm{V}$，供输入范围为$0$–$4.096\ \mathrm{V}$的ADC使用。选择$R_G$，求共模电压，以及CMRR为$100\ \mathrm{dB}$时引起的误差。
::: solution
电桥满量程输出$2\ \mathrm{mV/V} \times 5.0\ \mathrm{V} = 10\ \mathrm{mV}$。所需增益$2.5/0.010 = 250$；由[[#eq-inamp]]，$R_G = 2R/(G - 1)$。取$G = 251$，得$R_G = 50\,000/250 = 200\ \mathrm{\Omega}$（恰好），满量程变为$2.51\ \mathrm{V}$，为过载留有余量。

电桥的两个输出端都处于$V_s/2 = 2.5\ \mathrm{V}$附近：这就是共模电压。CMRR为$100\ \mathrm{dB}$（$10^5$）意味着共模输入等效于小$10^5$倍的差模输入：$2.5/10^5 = 25\ \mathrm{\mu V}$，即$10\ \mathrm{mV}$满量程的$0.25\,\%$。由于共模电压恒定，它表现为一个偏置，可通过去皮（调零）消除——但它随激励电压漂移，这是精密设计采用比率式转换的原因之一。

合理性检查：增益必须使放大器的输出保持在其摆幅以内——$5\ \mathrm{V}$轨到轨器件上的$2.51\ \mathrm{V}$没有问题——而且$2.5\ \mathrm{V}$的输入共模电压必须处于放大器允许的输入范围内，单电源器件很容易违反这一点。这两项都要在数据手册中核查。
:::
:::

::: example 四分之一桥的非线性 {#ex-quarter}
一片$350\ \mathrm{\Omega}$、$GF = 2.0$的应变片接在以$5.0\ \mathrm{V}$激励的四分之一桥中，应变为$500\ \mu\varepsilon$。比较精确输出与线性化输出。
::: solution
$x = GF\,\varepsilon = 1.0\times10^{-3}$。线性化：$V_sx/4 = 5.0 \times 10^{-3}/4 = 1.250\ \mathrm{mV}$。精确：$V_sx/(4 + 2x) = 5.0\times10^{-3}/4.002 = 1.2494\ \mathrm{mV}$。相对误差为$x/2 = 0.05\,\%$。

合理性检查：非线性随应变成比例增长，所以在$5000\ \mu\varepsilon$（钢的塑性应变）时它将为$0.5\,\%$；对于金属的弹性应变，四分之一桥对大多数用途已足够线性。全桥没有这种误差。
:::
:::

## 滤波器 {#sec-filters}

**滤波器**去除信号频谱中我们不需要的部分：高频噪声、工频干扰，或高于采样频率一半、否则会发生混叠的分量（见下文）。最简单的是[[mechatronics/mechatronic-systems#prop-rc]]中的RC低通滤波器，其传递函数为$1/(\tau s + 1)$，转折频率为$f_c = 1/(2\pi RC)$；在$f_c$以上它以每十倍频程$20\ \mathrm{dB}$衰减。需要更陡的滚降时，就把二阶有源节级联起来。

::: proposition 单位增益萨伦-基低通滤波器 {#prop-sallen-key}
串联的电阻$R_1$和$R_2$把输入接到电压跟随器的$+$输入端；电容$C_1$把两电阻的连接点接到输出端，$C_2$把$+$输入端接地。传递函数为
$$
\frac{V_o(s)}{V_i(s)} = \frac{1}{R_1R_2C_1C_2\,s^2 + C_2(R_1 + R_2)\,s + 1},
$$ {#eq-sallen-key}
这是一个二阶低通滤波器，$\omega_n = 1/\sqrt{R_1R_2C_1C_2}$，品质因数$Q = \sqrt{R_1R_2C_1C_2}/[C_2(R_1 + R_2)]$。取$R_1 = R_2 = R$时，$Q = \tfrac12\sqrt{C_1/C_2}$，选择$C_1 = 2C_2$得$Q = 1/\sqrt2$：即二阶**巴特沃斯**响应。
:::

::: proof
设$A$为两电阻的连接点。跟随器使$v_+ = v_o$。在$+$输入端应用KCL（无电流流入运算放大器）：$(V_A - V_o)/R_2 = sC_2V_o$，故$V_A = V_o(1 + sR_2C_2)$，$V_A - V_o = sR_2C_2V_o$。在$A$点应用KCL：$(V_i - V_A)/R_1 = (V_A - V_o)/R_2 + sC_1(V_A - V_o) = sC_2V_o + s^2R_2C_1C_2V_o$。因此$V_i = V_A + R_1V_o(sC_2 + s^2R_2C_1C_2) = V_o[1 + s(R_1 + R_2)C_2 + s^2R_1R_2C_1C_2]$，即[[#eq-sallen-key]]。与$1/(s^2/\omega_n^2 + s/(Q\omega_n) + 1)$比较，得$\omega_n$以及$1/(Q\omega_n) = C_2(R_1 + R_2)$，故$Q = \sqrt{R_1R_2C_1C_2}/[C_2(R_1 + R_2)]$。电阻相等时，它等于$\sqrt{C_1C_2}/(2C_2) = \tfrac12\sqrt{C_1/C_2}$。
:::

$n$阶**巴特沃斯**滤波器具有最大平坦的幅频响应
$$
\lvert H(f)\rvert = \frac{1}{\sqrt{1 + (f/f_c)^{2n}}},
$$ {#eq-butterworth}
对每个$n$，它在$f_c$处都下降$3\ \mathrm{dB}$，在$f_c$以上以每十倍频程$20n\ \mathrm{dB}$下降。它由具有特定$Q$值的二阶节级联构成（对$n = 4$：$0.541$和$1.307$）。其他设计以平坦度换取陡度（切比雪夫、椭圆滤波器），或换取超调很小的干净阶跃响应（贝塞尔滤波器，其群时延几乎恒定——当瞬态的**形状**很重要时，例如在控制回路中，优先采用它）。

## 噪声与干扰 {#sec-noise}

到达测量系统的无用信号有两类。**固有噪声**产生于元件内部：每个处于热力学温度$T$的电阻都产生**热噪声**（约翰逊噪声），其均方根电压为
$$
v_n = \sqrt{4k_BTRB},
$$ {#eq-johnson}
其中$k_B = 1.380649\times10^{-23}\ \mathrm{J/K}$，$B$为以赫兹计的带宽；$1\ \mathrm{k\Omega}$电阻在$300\ \mathrm{K}$、$10\ \mathrm{kHz}$带宽内的噪声为$0.41\ \mathrm{\mu V}$（均方根值）。放大器还会加入自身的电压噪声和电流噪声，在低频处$1/f$（“闪烁”）噪声上升。由于噪声功率随带宽增长，**低噪声测量的第一条法则是不使用超过信号所需的带宽。**

**干扰**从外部耦合进来，在机器中它通常占主导：

- 来自附近高压导体——在几十纳秒内切换几百伏电压的电机电缆——的**电容（电场）耦合**，用接地的**屏蔽层**减小，对低频信号屏蔽层单端接地；
- 来自附近导体中电流的**电感（磁场）耦合**，通过减小信号回路面积来减小：采用**双绞线**，信号电缆远离动力电缆布线，交叉时成直角；
- **接地环路**：当传感器和仪表在不同点接地时，二者之间接地导体上的电压降（由电机和电源电流引起）会叠加到信号上。差分输入（仪表放大器）、单点接地和电气隔离可以断开该环路（[[mechatronics/system-integration]]）。

在工厂中进行长距离传输时，模拟信号以**4–20 mA电流环**传送：变送器设定一个电流，无论导线电阻如何，该电流在整个串联回路中处处相同，在接收端通过一个精密电阻转换回电压。“活零点”（$4\ \mathrm{mA}$）把零读数与断线（$0\ \mathrm{mA}$）区分开来。

## 模数转换 {#sec-adc}

::: definition ADC的分辨力与量化 {#def-adc}
满量程范围为$V_{FS}$的$N$位**模数转换器**（ADC）把输入映射为$2^N$个整数码之一。码宽——即**最低有效位**（LSB）——为
$$
Q = \frac{V_{FS}}{2^N}.
$$ {#eq-lsb}
把输入舍入为一个码所产生的误差是**量化误差**，对理想转换器它处于$\pm Q/2$以内。常见的结构有：**逐次逼近型**（SAR；10–18位，最高每秒几百万次采样；通常的微控制器ADC）、**Σ-Δ型**（较低速率下16–24位，内置数字滤波；用于测力传感器和热电偶）以及用于极高速率的**闪速型/流水线型**转换器。
:::

::: proposition 量化噪声与理想信噪比 {#prop-quant-noise}
如果输入在许多个码之间变化，使量化误差在$[-Q/2, Q/2]$上均匀分布，则其均方根值为$Q/\sqrt{12}$。对满量程正弦波，理想$N$位转换器的信号功率与量化噪声功率之比为
$$
\mathrm{SNR} = 6.02N + 1.76\ \mathrm{dB}.
$$ {#eq-snr}
:::

::: proof
对在$[-Q/2, Q/2]$上均匀分布的$e$，均方值为$\frac1Q\int_{-Q/2}^{Q/2}e^2\,\mathrm{d}e = \frac{1}{Q}\cdot\frac{2}{3}\left(\frac Q2\right)^3 = \frac{Q^2}{12}$。充满量程的正弦波的幅值为$V_{FS}/2 = 2^NQ/2$，均方值为$(2^NQ/2)^2/2 = 2^{2N}Q^2/8$。功率比为$(2^{2N}Q^2/8)/(Q^2/12) = 1.5 \times 2^{2N}$，而$10\log_{10}(1.5 \times 2^{2N}) = 20N\log_{10}2 + 10\log_{10}1.5 = 6.02N + 1.76\ \mathrm{dB}$。
:::

实际转换器由于自身的噪声和非线性达不到[[#eq-snr]]；**有效位数**（ENOB）是由实测SNR反算出的$N$。12位微控制器ADC通常能达到10到11个有效位。而且只有当信号充满ADC的量程时，其分辨力才有用：把$10\ \mathrm{mV}$的电桥信号直接加到$3.3\ \mathrm{V}$的12位转换器上，只会用到$12$个码。

::: example 测力传感器信号链的分辨力 {#ex-resolution}
[[#ex-load-cell-chain]]中的测力传感器信号（$500\ \mathrm{N}$时为$2.51\ \mathrm{V}$）由基准电压为$4.096\ \mathrm{V}$的12位ADC读取。求LSB、每个LSB对应的力、以牛顿计的量化噪声均方根值以及理想SNR。
::: solution
$Q = 4.096/4096 = 1.000\ \mathrm{mV}$。ADC处的力灵敏度：$2.51\ \mathrm{V}/500\ \mathrm{N} = 5.02\ \mathrm{mV/N}$，所以一个LSB为$1.000/5.02 = 0.199\ \mathrm{N}$，量化噪声均方根值为$0.199/\sqrt{12} = 0.058\ \mathrm{N}$。折算到电桥，一个LSB为$1\ \mathrm{mV}/251 = 3.98\ \mathrm{\mu V}$。满量程正弦波的理想SNR：$6.02 \times 12 + 1.76 = 74.0\ \mathrm{dB}$。

合理性检查：$500\ \mathrm{N}/0.199\ \mathrm{N} \approx 2500$级，而不是$4096$级，因为信号只用了量程的$2.51/4.096 = 61\,\%$。折算到输入端的放大器噪声（通常为$10$–$20\ \mathrm{nV/\sqrt{Hz}}$，即在$100\ \mathrm{Hz}$带宽内远低于一微伏）小于一个LSB，所以这条信号链受转换器限制；采用商用称重电子装置所用的24位Σ-Δ转换器即可消除这一限制。
:::
:::

### 采样与混叠

::: theorem 采样定理 {#thm-sampling}
不含等于或高于$f_s/2$的频率分量的信号，完全由以速率$f_s$采得的样本确定。频率$f$高于$f_s/2$的正弦信号所产生的样本，与频率为**混叠频率**
$$
f_a = \lvert f - kf_s\rvert,\qquad k \text{ 为使下列条件成立的整数：} f_a \le f_s/2 .
$$ {#eq-alias}
的正弦信号的样本完全相同。
:::

::: proof
我们证明关于混叠的论断，这是实践中重要的部分；重建的一半（惠特克-香农插值）在信号处理教材中证明（[数学图谱](/learn/maths/)）。$\cos(2\pi ft + \phi)$在$t_n = n/f_s$处的样本为$\cos(2\pi fn/f_s + \phi)$。把$f$换成$f - kf_s$使辐角改变$2\pi kn$，即$2\pi$的整数倍，所以样本不变。把$f$换成$-f$、$\phi$换成$-\phi$也使余弦不变。因此，对每个整数$k$，频率$f$、$\lvert f - kf_s\rvert$和$kf_s - f$在采样后无法区分，而其中恰好有一个处于$[0, f_s/2]$内。$[0, f_s/2)$内两个频率不同的正弦信号给出不同的样本序列，这就是为什么这个频带、而且只有这个频带，能够被无歧义地表示。
:::

频率$f_s/2$称为**奈奎斯特频率**。混叠在采样之后无法消除：被混叠的分量位于信号频带内，与真实信号无法区分。必须在ADC**之前**用模拟**抗混叠滤波器**加以防止，该滤波器要把$f_s/2$以上的一切衰减到转换器的分辨力以下。

::: example 规定抗混叠滤波器 {#ex-antialias}
最高$100\ \mathrm{Hz}$的振动信号由12位ADC以$1\ \mathrm{kHz}$采样。奈奎斯特频率以上任何频率处的干扰都可能大到满量程。哪些分量会混叠进$0$–$100\ \mathrm{Hz}$频带？$f_c = 100\ \mathrm{Hz}$的巴特沃斯滤波器需要几阶才能使它们低于一个LSB？如果以$10\ \mathrm{kHz}$采样并进行数字滤波，情况有何变化？
::: solution
由[[#eq-alias]]，折叠到$0$–$100\ \mathrm{Hz}$的频率是与$f_s$的整数倍相距$100\ \mathrm{Hz}$以内的频率：$900$–$1100\ \mathrm{Hz}$、$1900$–$2100\ \mathrm{Hz}$，依此类推。最低的是$900\ \mathrm{Hz} = 9f_c$。12位的一个LSB是满量程的$1/4096$，即$-72.2\ \mathrm{dB}$。由[[#eq-butterworth]]，在$f/f_c = 9$处：一阶给出$-19.1\ \mathrm{dB}$，二阶$-38.2\ \mathrm{dB}$，四阶$-76.3\ \mathrm{dB}$。需要四阶滤波器。

以$10\ \mathrm{kHz}$采样时，第一个混叠频带从$9900\ \mathrm{Hz} = 99f_c$开始，在那里二阶滤波器已给出$-79.8\ \mathrm{dB}$。一个简单的模拟滤波器就够了，其余由处理器中的陡峭数字低通滤波器完成（若需要$1\ \mathrm{kHz}$的速率，再每十个样本保留一个）。这种**过采样**策略正是Σ-Δ转换器（其内部以极高速率采样）只需要极简单的模拟滤波器的原因。

合理性检查：$100\ \mathrm{Hz}$处的$-3\ \mathrm{dB}$点意味着滤波器也把信号频带的上端衰减了$29\,\%$；如果$100\ \mathrm{Hz}$附近的幅值很重要，就必须把$f_c$设得更高，滤波器阶数也要再提高——这是支持过采样的又一个理由。
:::
:::

::: warning PWM纹波与工频干扰的混叠
一个典型的机电系统故障：电机电流或位置信号带有驱动器PWM频率（比如$20\ \mathrm{kHz}$）的纹波，在没有抗混叠滤波器的情况下以$1\ \mathrm{kHz}$采样。由于$20\ \mathrm{kHz}$恰好是$f_s$的整数倍，纹波混叠到$0\ \mathrm{Hz}$——形成一个取决于PWM与采样之间相位的恒定偏置，当任一时钟漂移时它就变化，表现为缓慢的游移。如果PWM频率改为$20.05\ \mathrm{kHz}$，混叠就成为一个令人信服的$50\ \mathrm{Hz}$振荡。解决办法是采用模拟滤波器，或使采样与PWM同步，让每个样本都在PWM周期的同一点采得（电机驱动器正是这样做的）。同样，$50$或$60\ \mathrm{Hz}$的工频干扰应在采样前去除，或使采样窗口为工频周期的整数倍，这就是积分型转换器常采用$20\ \mathrm{ms}$或$100\ \mathrm{ms}$积分时间的原因。
:::

::: quiz
一个信号以$f_s = 1000\ \mathrm{Hz}$采样。$1300\ \mathrm{Hz}$的干扰分量在采样数据中出现在什么频率？
- [ ] $1300\ \mathrm{Hz}$
- [ ] $700\ \mathrm{Hz}$
- [x] $300\ \mathrm{Hz}$
- [ ] 它被采样消除了
::: solution
由[[#eq-alias]]取$k = 1$：$\lvert 1300 - 1000\rvert = 300\ \mathrm{Hz}$，低于$500\ \mathrm{Hz}$的奈奎斯特频率。$700\ \mathrm{Hz}$也是一个有效的混叠频率（$2000 - 1300$），但它高于$500\ \mathrm{Hz}$，所以在只表示$0$–$500\ \mathrm{Hz}$的采样数据中，它表现为$1000 - 700 = 300\ \mathrm{Hz}$。
:::
:::

::: history
电桥电路由塞缪尔·亨特·克里斯蒂（Samuel Hunter Christie）于1833年描述，并由查尔斯·惠斯通（Charles Wheatstone）在1843年的贝克讲座中推广，用于比较电阻。**运算放大器**一词出自约翰·R·拉加齐尼（John R. Ragazzini）、罗伯特·H·兰德尔（Robert H. Randall）和弗雷德里克·A·拉塞尔（Frederick A. Russell）1947年关于电子模拟计算机的论文，这些计算机的放大器通过反馈执行数学运算——加法、积分；集成运算放大器随后于20世纪60年代出现，即罗伯特·维德拉（Robert Widlar）在仙童公司的设计（μA709，1965年），而1968年的μA741成为标准的通用器件。斯蒂芬·巴特沃斯（Stephen Butterworth）于1930年发表了最大平坦滤波器，R. P. 萨伦（R. P. Sallen）和E. L. 基（E. L. Key）于1955年发表了他们的有源滤波电路。哈里·奈奎斯特（Harry Nyquist）1928年对电报信号传输的分析和克劳德·香农（Claude Shannon）1949年的论文《噪声中的通信》（*Communication in the presence of noise*）确立了工程师所使用的采样定理；E. T. 惠特克（E. T. Whittaker，1915年）和V. A. 科捷利尼科夫（V. A. Kotelnikov，1933年）曾独立得到等价的结果。
:::

::: summary
- 在负反馈下，理想运算放大器不取输入电流并保持$v_+ = v_-$。反相增益$-R_f/R_{\text{in}}$；同相增益$1 + R_f/R_g$；差分增益$R_2/R_1$。
- 仪表放大器的增益为$1 + 2R/R_G$，兼具高输入电阻、可调增益和高CMRR——是电桥的标准前端。
- 电桥输出$\approx (V_s/4)\sum \pm\Delta R_i/R$：相邻桥臂相减，相对桥臂相加。四分之一桥$V_sGF\varepsilon/4$，全桥$V_sGF\varepsilon$，有温度补偿且线性。
- 巴特沃斯滤波器在$f_c$以上每十倍频程下降$20n\ \mathrm{dB}$；$C_1 = 2C_2$的单位增益萨伦-基节是二阶巴特沃斯滤波器。
- 热噪声$\sqrt{4k_BTRB}$随带宽增长；对付干扰要用屏蔽、双绞线、差分输入、单点接地和电流环。
- ADC：$Q = V_{FS}/2^N$，量化噪声$Q/\sqrt{12}$，理想SNR $6.02N + 1.76\ \mathrm{dB}$；要缩放信号使其充满量程。
- 高于$f_s/2$的频率混叠到$\lvert f - kf_s\rvert$，事后无法去除：要在采样前滤波，或采用过采样。
:::

## 习题

::: exercise 同相增益 {level=1 check="100"}
一个同相放大器的$R_f = 99\ \mathrm{k\Omega}$，$R_g = 1.0\ \mathrm{k\Omega}$。求其增益。（填写增益。）
::: solution
$1 + R_f/R_g = 1 + 99 = 100$。
:::
:::

::: exercise 反相放大器的输出 {level=1 check="-0.825"}
一个反相放大器的$R_{\text{in}} = 10\ \mathrm{k\Omega}$，$R_f = 33\ \mathrm{k\Omega}$，输入为$0.25\ \mathrm{V}$。求输出。（填写$v_o$，单位V。）
::: solution
$v_o = -(33/10) \times 0.25 = -0.825\ \mathrm{V}$。信号源看到的输入电阻只有$10\ \mathrm{k\Omega}$，这对高阻抗传感器很重要。
:::
:::

::: exercise 选择增益电阻 {level=1 check="500"}
一个仪表放大器的内部电阻为$R = 25\ \mathrm{k\Omega}$。求增益为$101$时的$R_G$。（填写$R_G$，单位Ω。）
::: solution
$R_G = 2R/(G - 1) = 50\,000/100 = 500\ \mathrm{\Omega}$。
:::
:::

::: exercise 四分之一桥的输出 {level=1 check="5"}
一个采用$GF = 2.0$应变片的四分之一桥以$10\ \mathrm{V}$激励，应变片应变为$1000\ \mu\varepsilon$。用线性化公式求输出，并说明非线性误差的大小。（填写$V_o$，单位mV。）
::: solution
$V_o \approx V_sGF\varepsilon/4 = 10 \times 2.0 \times 10^{-3}/4 = 5.0\ \mathrm{mV}$。精确值为$V_sx/(4 + 2x)$，其中$x = 2\times10^{-3}$，即$4.995\ \mathrm{mV}$：相对误差为$x/2 = 0.1\,\%$。
:::
:::

::: exercise 双极性ADC {level=2 check="0.3125"}
一个16位ADC的输入范围为$\pm 10.24\ \mathrm{V}$。求其LSB。（填写$Q$，单位mV。）
::: solution
$V_{FS} = 20.48\ \mathrm{V}$；$Q = 20.48/65\,536 = 3.125\times10^{-4}\ \mathrm{V} = 0.3125\ \mathrm{mV}$。
:::
:::

::: exercise 混叠频率 {level=2 check="300"}
$2.3\ \mathrm{kHz}$的振动未经滤波进入以$1\ \mathrm{kHz}$采样的ADC。它出现在什么频率？（填写$f_a$，单位Hz。）
::: solution
$\lvert 2300 - 2 \times 1000\rvert = 300\ \mathrm{Hz}$，低于$500\ \mathrm{Hz}$的奈奎斯特频率。
:::
:::

::: exercise 巴特沃斯滤波器的衰减 {level=2 check="1/17"}
求二阶巴特沃斯低通滤波器在两倍转折频率处的功率比$\lvert H\rvert^2$。（填写精确比值。）
::: solution
$\lvert H\rvert^2 = 1/(1 + 2^4) = 1/17$，即$-12.3\ \mathrm{dB}$；幅值比为$1/\sqrt{17} = 0.243$。
:::
:::

::: exercise 理想信噪比 {level=2 check="98.08"}
用[[#eq-snr]]求16位转换器对满量程正弦波的理想SNR。（以dB为单位填写。）
::: solution
$6.02 \times 16 + 1.76 = 98.08\ \mathrm{dB}$。实际的16位SAR转换器约能达到$90$–$95\ \mathrm{dB}$。
:::
:::

::: exercise 萨伦-基滤波器设计 {level=2 check="2"}
用$R_1 = R_2 = 10\ \mathrm{k\Omega}$设计一个$f_c = 1\ \mathrm{kHz}$的单位增益萨伦-基巴特沃斯低通滤波器。求$C_2$和$C_1$，并说明$C_1/C_2$是所需的比值。（填写$C_1/C_2$。）
::: solution
对巴特沃斯响应，$C_1 = 2C_2$，故$\omega_n = 1/(R\sqrt{2}\,C_2)$。取$\omega_n = 2\pi \times 1000\ \mathrm{rad/s}$：$C_2 = 1/(\sqrt2 R\omega_n) = 1/(1.414 \times 10^4 \times 6283) = 11.3\ \mathrm{nF}$，$C_1 = 22.5\ \mathrm{nF}$。实际上会选$C_2 = 10\ \mathrm{nF}$、$C_1 = 22\ \mathrm{nF}$并调整电阻：$C_1/C_2 = 2.2$时，$Q = \tfrac12\sqrt{2.2} = 0.742$，略有峰值，对大多数用途可以接受。
:::
:::

::: exercise 扭矩传感器的测量链 {level=3}
一根旋转轴上装有测量扭矩（最大$200\ \mathrm{N\,m}$）的应变片全桥（额定输出$1.5\ \mathrm{mV/V}$）。在一个附近有$15\ \mathrm{kW}$变频器供电电机的试验台上，需要$1\ \mathrm{kHz}$带宽的信号。提出完整的测量链——激励、从旋转轴上引出信号的传输方式、放大、滤波、转换、接地与屏蔽——并估算达到$0.1\ \mathrm{N\,m}$所需的增益和ADC分辨力。
::: solution
好的回答包括：(i) 激励$5$–$10\ \mathrm{V}$（比如$5\ \mathrm{V}$：满量程$7.5\ \mathrm{mV}$）；比率式转换。(ii) 从轴上引出：滑环噪声大且会磨损；现代设计把放大器和ADC装在轴上，通过感应或无线遥测以数字方式传输，并采用感应供电。(iii) 用靠近电桥的仪表放大器提供约$300$的增益，得到约$2.25\ \mathrm{V}$的满量程。(iv) $200\ \mathrm{N\,m}$中的$0.1\ \mathrm{N\,m}$是两千分之一；考虑噪声和偏置的余量，采用14–16位转换器（ENOB $\ge 12$）是合适的。(v) 抗混叠：以$10$–$20\ \mathrm{kHz}$采样，用转折频率在$2$–$5\ \mathrm{kHz}$附近的二阶到四阶模拟滤波器，再数字滤波到$1\ \mathrm{kHz}$；与变频器的开关频率及其谐波同步，或在远离它们处充分滤波。(vi) 采用屏蔽双绞线电缆，与电机电缆分开，屏蔽层在仪表端接地，单一星形接地点，与PC之间采用隔离接口。(vii) 用杠杆和已知砝码标定，并用并联标定电阻检查整个信号链。
:::
