挖掘机挖沟、压力机冲压汽车车身覆盖件、飞机起落架放下、注塑机以几百吨的力锁紧模具：当需要在狭小空间内产生很大的力时，执行器通常是液压的。工作压力为$20\ \mathrm{MPa}$——大气压的两百倍——的液压缸，每$10\ \mathrm{cm^2}$活塞面积就能产生$20\ \mathrm{kN}$的力，而液压系统能够通过一根软管把几十千瓦的功率输送到需要力的任何地方。**气动**技术使用约$0.6\ \mathrm{MPa}$的压缩空气，以力换取清洁、快速和低成本，在工厂自动化的简单点到点运动中占主导地位：夹爪、夹具、推出器、分拣闸门。

对机电一体化工程师而言，流体传动是与电气驱动一样的一种执行技术，有它自己的元件（泵、阀、液压缸、液压马达）、自己的图形符号和自己的动态特性——后者主要由流体的可压缩性和流经阀口的强非线性流动决定。本章建立各元件的定量模型，把它们组合成回路，并推导限制液压伺服系统快速性的固有频率。其基础流体力学——压强、伯努利方程、管路损失——见[[fluid-mechanics]]。

## 压力、力与流量 {#sec-basics}

流体传动的基础是：静止流体中的压力在各个方向上相等，并且不衰减地传递到流体各处（帕斯卡原理），所以泵可以在一处产生压力，液压缸可以在另一处利用它。在工作回路中流体并不静止，压力会损失在管路、管接头，尤其是阀中；但这些损失另行计算，而执行器本身服从简单的定律。

::: proposition 液压缸的力、速度与功率 {#prop-cylinder}
双作用液压缸的活塞（无杆腔）面积为$A_1$，环形（有杆腔）面积为$A_2 = A_1 - A_r$，其中$A_r$为活塞杆面积。无杆腔和有杆腔中的压力分别为$p_1$和$p_2$时，活塞杆上的力（向外为正，忽略摩擦）和伸出速度为
$$
F = p_1A_1 - p_2A_2,\qquad v = \frac{Q_1}{A_1} = \frac{Q_2}{A_2},
$$ {#eq-cylinder}
其中$Q_1$为流入无杆腔的流量，$Q_2$为流出有杆腔的流量。传递给液流的液压功率为$P = \Delta p\,Q$。
:::

::: proof
活塞和活塞杆的受力图：无杆腔压力作用在整个活塞面积上，以力$p_1A_1$向外推；有杆腔压力作用在环形面积上，以力$p_2A_2$向内推（活塞杆本身的截面在缸外暴露于大气中，取大气压为表压零点）。合力为$F = p_1A_1 - p_2A_2$。若把油视为不可压缩，无杆腔容积以$A_1v$的速率增大，必须以该速率供油，$Q_1 = A_1v$；有杆腔容积以$A_2v$的速率减小，排出$Q_2 = A_2v$。功率：体积$\mathrm{d}V$经过压力升高$\Delta p$被推送时获得功$\Delta p\,\mathrm{d}V$，所以$P = \Delta p\,\mathrm{d}V/\mathrm{d}t = \Delta p\,Q$。对液压缸，$Fv = p_1A_1v - p_2A_2v = p_1Q_1 - p_2Q_2$，即所消耗的净液压功率。
:::

由于$A_2 < A_1$，在相同的泵流量和压力下，单杆液压缸伸出时比缩回时更慢、力更大，而缩回时排出的油比进入的油多。这些公式中的压力是表压；在液压中它与绝对压力的区别很少有影响，但在要用到气体定律的气动中总是有影响的。

::: example 压力机液压缸的选定 {#ex-cylinder}
一个缸径$80\ \mathrm{mm}$、杆径$40\ \mathrm{mm}$的液压缸以$20\ \mathrm{L/min}$供油，最高压力为$10\ \mathrm{MPa}$（溢流阀调定值），回油侧压力可忽略。求最大伸出力和缩回力、速度以及液压功率。
::: solution
$A_1 = \pi(0.040)^2 = 5.027\times10^{-3}\ \mathrm{m^2}$；$A_r = \pi(0.020)^2 = 1.257\times10^{-3}\ \mathrm{m^2}$；$A_2 = 3.770\times10^{-3}\ \mathrm{m^2}$。$Q = 20\times10^{-3}/60 = 3.333\times10^{-4}\ \mathrm{m^3/s}$。

力：伸出$10\times10^{6} \times 5.027\times10^{-3} = 50.3\ \mathrm{kN}$；缩回$10\times10^{6} \times 3.770\times10^{-3} = 37.7\ \mathrm{kN}$。

速度：伸出$3.333\times10^{-4}/5.027\times10^{-3} = 0.0663\ \mathrm{m/s}$；缩回$3.333\times10^{-4}/3.770\times10^{-3} = 0.0884\ \mathrm{m/s}$。

满压力时的功率：$10\times10^{6} \times 3.333\times10^{-4} = 3.33\ \mathrm{kW}$。

合理性检查：伸出时的$Fv$为$50.3\ \mathrm{kN} \times 0.0663\ \mathrm{m/s} = 3.33\ \mathrm{kW}$，与$pQ$相符，正如[[#prop-cylinder]]所要求的。注意电气方案的困难：用滚珠丝杠以$66\ \mathrm{mm/s}$产生$50\ \mathrm{kN}$是可能的，但丝杠和电机会比$80\ \mathrm{mm}$的液压缸笨重得多。
:::
:::

## 泵与马达 {#sec-pumps}

液压系统使用**容积式**泵——齿轮泵、叶片泵和柱塞泵（轴向或径向）——它们每转输出一个固定的体积，即**排量**$D$，几乎与压力无关。同样的机器反向运行就是**液压马达**。实际机器存在内泄漏（压力越高、黏度越低，泄漏越大），也有摩擦。

::: definition 泵的效率 {#def-pump-eff}
排量为$D$（每转）的泵以转速$n$（rev/s）克服压力升高$\Delta p$运行，输出流量
$$
Q = Dn\,\eta_v
$$
其中**容积效率**$\eta_v < 1$计及泄漏；所需轴转矩为
$$
T = \frac{D\,\Delta p}{2\pi\,\eta_m}
$$
其中**机械（液压机械）效率**$\eta_m < 1$计及摩擦。**总效率**是液压输出功率与轴功率之比，$\eta = \Delta p\,Q/(2\pi nT) = \eta_v\eta_m$。
:::

转矩公式由能量关系得出：理想泵转过一转时克服$\Delta p$排出$D$，吸收功$\Delta p\,D$，所以$2\pi T = \Delta p\,D$。典型值：齿轮泵$\eta \approx 0.80$–$0.90$（便宜，定量），轴向柱塞泵在最高$35$–$45\ \mathrm{MPa}$的压力下$\eta \approx 0.85$–$0.92$，并有**变量**型，使泵只输出所需的流量，而不必节流掉多余的流量。

::: example 泵及其驱动电机 {#ex-pump}
一台排量为$20\ \mathrm{cm^3/rev}$的轴向柱塞泵以$1500\ \mathrm{rev/min}$克服$20\ \mathrm{MPa}$运行，$\eta_v = 0.95$，$\eta_m = 0.90$。求流量、液压功率、轴转矩和轴功率，以及总效率。
::: solution
$n = 25\ \mathrm{rev/s}$。流量$Q = 20\times10^{-6} \times 25 \times 0.95 = 4.75\times10^{-4}\ \mathrm{m^3/s} = 28.5\ \mathrm{L/min}$。液压功率$20\times10^{6} \times 4.75\times10^{-4} = 9.50\ \mathrm{kW}$。转矩$T = 20\times10^{-6} \times 20\times10^{6}/(2\pi \times 0.90) = 70.7\ \mathrm{N\,m}$。轴功率$T\omega = 70.7 \times 157.1 = 11.1\ \mathrm{kW}$。效率$9.50/11.1 = 0.855 = \eta_v\eta_m$。

合理性检查：$1.6\ \mathrm{kW}$的损失变成油中的热量，必须由冷却器或油箱带走；液压系统的设计不仅要有力和流量的平衡，还要有热平衡。一台$11\ \mathrm{kW}$的四极感应电动机就能驱动这台泵——这是一套标准的工业液压动力单元。
:::
:::

## 阀 {#sec-valves}

阀控制流体的方向、压力和流量。其工作元件是一个可变的**节流口**：一个锐边节流结构，例如阀芯凸肩与油口边缘之间的缝隙。

::: proposition 节流口方程 {#prop-orifice}
密度为$\rho$的液体流过面积为$A$、压降为$\Delta p$的锐边节流口，其流量为
$$
Q = C_dA\sqrt{\frac{2\,\Delta p}{\rho}},
$$ {#eq-orifice}
其中**流量系数**$C_d$（对高雷诺数下的锐边节流口约为$0.6$–$0.7$；经典值为$0.61$）计及射流的收缩和摩擦。
:::

::: proof
在节流口上游，流体以压力$p_1$缓慢流动；它在流经节流口时加速，形成一股射流，在紧靠下游处收缩到最窄截面（**缩流断面**，vena contracta），其面积为$C_cA$，该处流线平行，压力等于下游压力$p_2$。沿一条流线应用伯努利方程，忽略上游速度和损失，得$p_1 = p_2 + \tfrac12\rho v_j^2$，所以射流速度为$v_j = \sqrt{2\Delta p/\rho}$。流量为$Q = C_cA\,v_j$。摩擦使射流速度略有降低，用速度系数$C_v \approx 0.97$–$0.99$表示，$C_d = C_cC_v$。对锐边圆形节流口，$C_c \approx 0.61$–$0.62$，由实验得出（对二维缝隙，由基尔霍夫（Kirchhoff）自由流线理论得$\pi/(\pi + 2) = 0.611$）。
:::

在缩流断面下游，射流的动能在湍流中耗散并变为热：全部压降$\Delta p$都损失掉了，功率$\Delta p\,Q$使油发热。这是阀控的核心事实——**节流本质上是有损耗的**——也是高效机器采用变量泵、负载敏感回路或电气驱动来只提供负载所需的压力和流量的原因。

::: example 节流口中的流量与发热 {#ex-orifice}
矿物油（$\rho = 870\ \mathrm{kg/m^3}$）流过直径为$2.0\ \mathrm{mm}$的锐边节流口，压降为$5.0\ \mathrm{MPa}$。取$C_d = 0.61$，求流量和转换为热的功率。
::: solution
$A = \pi(1.0\times10^{-3})^2 = 3.142\times10^{-6}\ \mathrm{m^2}$。射流速度$\sqrt{2 \times 5.0\times10^{6}/870} = 107.2\ \mathrm{m/s}$。$Q = 0.61 \times 3.142\times10^{-6} \times 107.2 = 2.05\times10^{-4}\ \mathrm{m^3/s} = 12.3\ \mathrm{L/min}$。发热：$5.0\times10^{6} \times 2.05\times10^{-4} = 1.03\ \mathrm{kW}$。

合理性检查：$100\ \mathrm{m/s}$的射流是大压降下控制阀的典型情况，它解释了控制阀的噪声、冲蚀和气穴；在一个指甲盖大小的零件中产生一千瓦的热量，这就是节流阀需要油流把热量带走、以及连续节流的回路会发热的原因。由于$Q \propto \sqrt{\Delta p}$，把压降增大到四倍，流量只增加一倍。
:::
:::

### 阀的类型

- **方向控制阀**为液流选择通路。它们按油口数和工作位置数命名：**四通三位阀**（4/3阀）有四个油口（压力油口P、回油口T和两个执行器油口A、B）和三个阀芯位置——伸出、缩回和一个中位，中位的连接方式（各油口全封闭，A和B通油箱，P通油箱使泵卸荷……）决定阀处于中位时液压缸的状态。开关阀由电磁铁、手柄或先导压力操纵。
- **压力控制阀**：**溢流阀**通过向油箱开启来限制系统的最高压力，保护泵和各元件；**减压阀**向回路的一部分提供较低的压力；**平衡阀**保持悬吊的负载，防止其在下降时失控。
- **流量控制阀**通过节流设定速度。简单的针阀给出的流量随负载压力变化（[[#eq-orifice]]）；**压力补偿型**流量阀用一个弹簧加载的压力补偿器保持其节流口两端的压降恒定，所以流量与负载无关。把它装在液压缸进口（**进口节流**）或出口（**出口节流**），即可控制速度；出口节流还能控制拖动液压缸的超越负载。
- **比例阀与伺服阀**的阀芯由比例电磁铁或由力矩马达和液压放大级连续定位，其流量与电指令近似成正比。伺服阀的阀芯间隙极小，带宽为几十到几百赫兹，用于闭环位置和力控制——飞行模拟器、材料试验机、轧钢厂的厚度控制、飞机飞行操纵系统。

在某一工作点附近，流经伺服阀通向负载压差为$p_L$的负载的流量线性化为$Q_L = K_qx_v - K_cp_L$，其中**流量增益**$K_q = \partial Q/\partial x_v$，**流量-压力系数**$K_c = -\partial Q/\partial p_L$——即把[[#eq-orifice]]应用于阀的节流边所得的斜率。压力系数对执行器起阻尼器的作用，而它在阀的中位附近最小——执行器阻尼最小——伺服系统的大部分时间恰恰处于这个位置。

## 可压缩性与液压固有频率 {#sec-stiffness}

液压油刚度很高，但并非刚性。其可压缩性用**体积弹性模量**描述
$$
\beta = -V\frac{\mathrm{d}p}{\mathrm{d}V},
$$
纯矿物油约为$1.4$–$1.8\ \mathrm{GPa}$。混入的空气和软管的膨胀会使**有效**体积弹性模量大大降低，在实际回路中常为$0.7$–$1\ \mathrm{GPa}$；设计时应采用这个值。因此，封闭在液压缸腔和管路中的油在阀与负载之间起着弹簧的作用，这个弹簧与负载质量一起构成一个轻阻尼振子——即限制每个阀控执行器带宽的**液压谐振**。

::: proposition 液压弹簧刚度 {#prop-hydraulic-stiffness}
面积为$A$的活塞封闭着体积为$V$、体积弹性模量为$\beta$的流体，其刚度为$k = \beta A^2/V$。对于两侧面积都为$A$的液压缸（双杆液压缸），封闭容积为$V_1$和$V_2$（包括通向阀的管路），两腔相当于并联的弹簧：
$$
k_h = \beta A^2\left(\frac{1}{V_1} + \frac{1}{V_2}\right),\qquad \omega_h = \sqrt{\frac{k_h}{m}},
$$ {#eq-hydraulic-stiffness}
其中$m$为运动质量。活塞处于行程中点时，$V_1 = V_2 = V_t/2$，$k_h = 4\beta A^2/V_t$，这是整个行程中的最小值。
:::

::: proof
在阀关闭时使活塞向腔1移动一个小位移$x$。该腔容积减小$\mathrm{d}V = -Ax$，由$\beta$的定义，压力升高$\mathrm{d}p_1 = \beta Ax/V_1$，它以力$A\,\mathrm{d}p_1 = (\beta A^2/V_1)x$推回活塞。与此同时，腔2容积扩大$Ax$，其压力降低$\beta Ax/V_2$，作用在活塞上的净力增加$(\beta A^2/V_2)x$。两个力都阻碍位移，所以刚度相加。质量在这个弹簧上的固有频率为$\sqrt{k_h/m}$。在$V_1 + V_2 = V_t$固定时，$1/V_1 + 1/V_2$在$V_1 = V_2$处最小（由对称性和$1/V$的凸性），得$4/V_t$。
:::

设计上的结论是直接的。液压固有频率随活塞面积和体积弹性模量增大而升高，随封闭容积和质量增大而降低，所以伺服阀直接安装在液压缸上（管路短而刚硬，不用软管），液压缸的行程也不宜过大。根据梅里特（Merritt）的经典分析，一条经验法则是：阀控位置伺服系统所能达到的闭环带宽最多只有$\omega_h$的三分之一左右，阻尼低时还更小。

::: example 定位轴的固有频率 {#ex-hydraulic-freq}
一个有效面积为$A = 2.0\times10^{-3}\ \mathrm{m^2}$的双杆液压缸推动$500\ \mathrm{kg}$的质量。在行程中点，每个腔连同其管路容纳$4.0\times10^{-4}\ \mathrm{m^3}$有效体积弹性模量为$1.4\ \mathrm{GPa}$的油。求液压刚度和固有频率，并估算可达到的位置环带宽。如果软管使有效体积弹性模量降至$0.7\ \mathrm{GPa}$，会怎样？
::: solution
$k_h = 1.4\times10^{9} \times (2.0\times10^{-3})^2 \times (2/4.0\times10^{-4}) = 1.4\times10^{9} \times 4.0\times10^{-6} \times 5000 = 2.8\times10^{7}\ \mathrm{N/m}$。$\omega_h = \sqrt{2.8\times10^{7}/500} = 237\ \mathrm{rad/s}$，即$37.7\ \mathrm{Hz}$。可达到的带宽约为其三分之一：大约$12\ \mathrm{Hz}$。

$\beta = 0.7\ \mathrm{GPa}$时，$k_h$减半，$\omega_h$降低为$1/\sqrt2$，即$26.6\ \mathrm{Hz}$，带宽降至约$9\ \mathrm{Hz}$。

合理性检查：$28\ \mathrm{N/\mu m}$的刚度远高于尺寸相近的气缸（其值约为它的千分之一量级，见下文），但与一个普通钢机架的刚度相当——所以在实际机器中，结构的柔度是串联作用的，必须计入。
:::
:::

## 气动 {#sec-pneumatics}

气动执行器以较轻的形式使用同样的元件，压缩空气通常为$0.6\ \mathrm{MPa}$（表压），来自中央空压机，在每台机器处经过过滤、干燥和调压。力同样是$pA$（表压），所以缸径$50\ \mathrm{mm}$的气缸在$0.6\ \mathrm{MPa}$下约推出$1.2\ \mathrm{kN}$。空气便宜、清洁、不可燃，泄漏也无害；气缸轻、快（速度可达$1\ \mathrm{m/s}$以上），过载时只是停住而不会损坏。其缺点全都源于**可压缩性**：

- 气体弹簧的刚度为$k = n\,pA^2/V$，其中$p$为**绝对**压力，$n$为多变指数（快速的绝热变化取$1.4$）——比油小几千倍，因为取代$\beta$（约$1\ \mathrm{GPa}$）的是$np$（约$1\ \mathrm{MPa}$）。因此在变化的负载下很难保持中间位置，大多数气缸在两端止挡之间运行，并用可调缓冲吸收冲击；
- 速度取决于负载、供气压力以及阀和管道的通流能力，用出口节流阀设定；
- 压缩空气是一种昂贵的能量载体：从空压机耗电到气缸所做的功，总效率常常只有$10\,\%$左右，而泄漏是工厂的一项主要成本。

耗气量按**自由空气**体积（大气压下的体积）计算：容积为$V$、充气到绝对压力$p$的腔内所含的质量，与$Vp/p_{\text{atm}}$的自由空气相同（等温条件下），而这些空气每一行程都会排掉。

::: example 气缸的耗气量 {#ex-air}
一个缸径$50\ \mathrm{mm}$、杆径$20\ \mathrm{mm}$、行程$200\ \mathrm{mm}$的双作用气缸在$0.6\ \mathrm{MPa}$（表压）下工作，每分钟完成$10$个循环（伸出并返回）。取$p_{\text{atm}} = 0.1013\ \mathrm{MPa}$并忽略死容积，求自由空气耗气量。把行程中点处气体的刚度与同一缸中$\beta = 1.4\ \mathrm{GPa}$的油的刚度作比较。
::: solution
无杆腔容积$\pi(0.025)^2 \times 0.200 = 3.927\times10^{-4}\ \mathrm{m^3}$；有杆腔容积$\pi(0.025^2 - 0.010^2) \times 0.200 = 3.299\times10^{-4}\ \mathrm{m^3}$。压力比$(0.6 + 0.1013)/0.1013 = 6.92$。每循环的自由空气$(3.927 + 3.299)\times10^{-4} \times 6.92 = 5.00\times10^{-3}\ \mathrm{m^3}$；每分钟$0.0500\ \mathrm{m^3} = 50\ \mathrm{L/min}$自由空气。

行程中点的刚度：把两腔都视为具有活塞面积$A = 1.963\times10^{-3}\ \mathrm{m^2}$、各占扫过容积的一半$V = 1.963\times10^{-4}\ \mathrm{m^3}$，绝对压力$0.701\ \mathrm{MPa}$，$n = 1.4$（对单杆气缸的一种近似）：$k \approx 1.4 \times 0.701\times10^{6} \times (1.963\times10^{-3})^2 \times 2/(1.963\times10^{-4}) = 3.9\times10^{4}\ \mathrm{N/m}$。用$\beta = 1.4\ \mathrm{GPa}$的油代替$np = 0.98\ \mathrm{MPa}$，得到的值约大$1400$倍，即$5.5\times10^{7}\ \mathrm{N/m}$。

合理性检查：按典型的比功率，$50\ \mathrm{L/min}$自由空气约需$0.3\ \mathrm{kW}$的空压机功率——对一个气缸不算多，但对一个有几百个气缸的工厂就很大了。$10\ \mathrm{kg}$的质量在$39\ \mathrm{kN/m}$的弹簧上约以$10\ \mathrm{Hz}$振荡：气动定位是“软”的。
:::
:::

::: warning 储存的能量与流体注射伤害
液压和气动系统储存着在泵或空压机关闭后仍然存在的能量：在蓄能器中（充气的容器，处于系统全压），在支撑负载的封闭油液中，在储气罐和管路中的压缩空气中。拧松带压管路上的接头，或者一个只靠单向阀支撑的负载，都可能使能量猛烈释放。流体传动系统上的工作只能由受过培训的人员进行，并须先以机械方式放下负载、进行隔离并**确认零压力**（蓄能器通过其泄放阀卸压），遵守现场的上锁挂牌程序。高压下的针孔泄漏可以把油注入皮肤；这种伤害看似轻微，却是外科急症。绝不要用手去摸查泄漏。不得用压缩空气清洁衣物或皮肤。
:::

::: quiz
一个液压缸在供油$12\ \mathrm{L/min}$时以$0.10\ \mathrm{m/s}$伸出。泵流量加倍而负载不变。忽略泄漏，会发生什么？
- [ ] 速度加倍，压力加倍
- [x] 速度加倍，压力不变（若溢流阀不开启）
- [ ] 速度不变，力加倍
- [ ] 速度增大到$\sqrt2$倍
::: solution
速度等于流量除以面积，所以加倍；压力等于负载力除以面积，所以不变（另加略高的管路损失）。液压执行器把二者解耦：流量决定速度，负载决定压力，正如在直流电机中电压决定转速、负载决定电流一样（[[mechatronics/electric-actuators#prop-torque-speed]]）。$\sqrt2$的答案适用于压降加倍时流经固定节流口的流量。
:::
:::

::: history
布莱兹·帕斯卡（Blaise Pascal）在其身后于1663年出版的《论液体平衡》（*Traité de l'équilibre des liqueurs*）中阐述了压力传递原理。约瑟夫·布拉默（Joseph Bramah）于1795年取得了以水为工作介质的水压机专利；19世纪，液压动力在城市中输送：威廉·阿姆斯特朗（William Armstrong）制造了液压起重机，并于1850年前后发明了为其储存压力的重锤式蓄能器，公共液压动力网络向伦敦和其他城市的升降机、起重机和桥梁供能，一直延续到20世纪。从20世纪初起油取代了水，带来了润滑和更高的压力。电液伺服阀于20世纪40年代末和50年代为飞机飞行操纵和其他伺服系统而研制，赫伯特·E·梅里特（Herbert E. Merritt）的《液压控制系统》（*Hydraulic Control Systems*，1967年）给出了阀控执行器的分析——流量增益、压力系数、液压固有频率——至今仍在使用。
:::

::: summary
- 液压缸：$F = p_1A_1 - p_2A_2$，$v = Q/A$；功率$\Delta p\,Q$。流量决定速度，负载决定压力。
- 泵：$Q = Dn\eta_v$，$T = D\Delta p/(2\pi\eta_m)$，$\eta = \eta_v\eta_m$；损失使油发热。
- 节流口：$Q = C_dA\sqrt{2\Delta p/\rho}$，$C_d \approx 0.61$；节流把$\Delta p\,Q$转化为热。
- 阀：方向阀（4/3阀及各种中位机能）、压力阀（溢流阀、减压阀、平衡阀）、流量阀（压力补偿型、进口/出口节流）、比例阀和伺服阀；线性化$Q_L = K_qx_v - K_cp_L$。
- 油是一个弹簧：$k_h = \beta A^2(1/V_1 + 1/V_2)$，$\omega_h = \sqrt{k_h/m}$，在行程中点最低；采用有效体积弹性模量，并使封闭容积尽量小。位置环带宽$\lesssim \omega_h/3$。
- 气动：力$pA$（表压），刚度$npA^2/V$（绝对压力$p$），便宜、快速、清洁，但“软”且能效低；每行程的自由空气耗量$V\,p_{\text{abs}}/p_{\text{atm}}$。
- 流体系统中储存的能量是严重的危险源：工作前要隔离、释放并确认。
:::

## 习题

::: exercise 缩回力 {level=1 check="36"}
一个液压缸的活塞面积为$5000\ \mathrm{mm^2}$，活塞杆面积为$2000\ \mathrm{mm^2}$。有杆腔压力为$12\ \mathrm{MPa}$、无杆腔通油箱时，求缩回力。（以kN为单位填写。）
::: solution
$A_2 = 5000 - 2000 = 3000\ \mathrm{mm^2} = 3.0\times10^{-3}\ \mathrm{m^2}$；$F = 12\times10^{6} \times 3.0\times10^{-3} = 36\ \mathrm{kN}$。
:::
:::

::: exercise 伸出速度 {level=1 check="0.25"}
一台泵向活塞面积为$2000\ \mathrm{mm^2}$的液压缸无杆腔供油$30\ \mathrm{L/min}$。求伸出速度。（以m/s为单位填写。）
::: solution
$Q = 30\times10^{-3}/60 = 5.0\times10^{-4}\ \mathrm{m^3/s}$；$v = 5.0\times10^{-4}/2.0\times10^{-3} = 0.25\ \mathrm{m/s}$。
:::
:::

::: exercise 泵的流量 {level=1 check="27.36"}
一台排量为$16\ \mathrm{cm^3/rev}$的齿轮泵以$1800\ \mathrm{rev/min}$运行，容积效率为$0.95$。求其输出流量。（以L/min为单位填写。）
::: solution
$Q = 16 \times 1800 \times 0.95 = 27\,360\ \mathrm{cm^3/min} = 27.36\ \mathrm{L/min}$。
:::
:::

::: exercise 液压功率 {level=1 check="10.5"}
求压力为$21\ \mathrm{MPa}$、流量为$30\ \mathrm{L/min}$的液流的液压功率。（以kW为单位填写。）
::: solution
$P = 21\times10^{6} \times 5.0\times10^{-4} = 10\,500\ \mathrm{W} = 10.5\ \mathrm{kW}$。
:::
:::

::: exercise 油弹簧的刚度 {level=2 check="3"}
一个有效体积弹性模量为$1.5\ \mathrm{GPa}$、体积为$5.0\times10^{-4}\ \mathrm{m^3}$的单腔油液被封闭在面积为$1.0\times10^{-3}\ \mathrm{m^2}$的活塞后面。求其刚度。（填写$k$，单位MN/m。）
::: solution
$k = \beta A^2/V = 1.5\times10^{9} \times 1.0\times10^{-6}/5.0\times10^{-4} = 3.0\times10^{6}\ \mathrm{N/m} = 3\ \mathrm{MN/m}$。
:::
:::

::: exercise 压降加倍时的节流口流量 {level=2 check="sqrt(2)"}
压降加倍时，流经固定节流口的流量增大到原来的几倍？（填写精确倍数，例如写作sqrt(2)。）
::: solution
$Q \propto \sqrt{\Delta p}$，所以倍数为$\sqrt2 \approx 1.414$，而耗散的功率$\Delta p\,Q$增大到$2\sqrt2 \approx 2.83$倍。
:::
:::

::: exercise 液压固有频率 {level=2 check="200"}
一个液压轴的最小液压刚度为$8.0\times10^{6}\ \mathrm{N/m}$，运动质量为$200\ \mathrm{kg}$。求其固有频率。（填写$\omega_h$，单位rad/s。）
::: solution
$\omega_h = \sqrt{8.0\times10^{6}/200} = \sqrt{4.0\times10^{4}} = 200\ \mathrm{rad/s}$（$31.8\ \mathrm{Hz}$）；可以预期大约$10\ \mathrm{Hz}$的闭环带宽。
:::
:::

::: exercise 每行程的自由空气 {level=2 check="3.5"}
一个活塞面积为$2000\ \mathrm{mm^2}$、行程为$0.25\ \mathrm{m}$的气缸，每个伸出行程都充气到$0.6\ \mathrm{MPa}$（表压）。取大气压为$0.1\ \mathrm{MPa}$，求每次伸出所用的自由空气。（以L为单位填写。）
::: solution
$V = 2.0\times10^{-3} \times 0.25 = 5.0\times10^{-4}\ \mathrm{m^3}$；绝对压力$0.7\ \mathrm{MPa}$，比值为$7$；自由空气$3.5\times10^{-3}\ \mathrm{m^3} = 3.5\ \mathrm{L}$。
:::
:::

::: exercise 液压还是电动？ {level=3}
一台机器必须把轴承压入轴承座，压装力最大$60\ \mathrm{kN}$，行程$150\ \mathrm{mm}$，以$100\ \mathrm{mm/s}$趋近，以$5\ \mathrm{mm/s}$压装，每小时$600$次，并记录压装力用于质量控制。比较液压方案（液压动力单元、阀、液压缸、压力传感器）与机电方案（伺服电机、行星滚柱丝杠或滚珠丝杠、测力传感器）：粗略选定各方案的主要元件，并讨论能耗、力的控制与监测、噪声、维护、成本和安全。
::: solution
好的回答：液压方案：在$20\ \mathrm{MPa}$下，$A = 60\,000/20\times10^{6} = 3.0\times10^{-3}\ \mathrm{m^2}$，缸径约$62\ \mathrm{mm}$（选$63\ \mathrm{mm}$）；趋近流量$3.0\times10^{-3} \times 0.10 = 3.0\times10^{-4}\ \mathrm{m^3/s} = 18\ \mathrm{L/min}$；压装功率只有$300\ \mathrm{W}$，但带溢流阀的定量泵会把其大部分功率作为热量浪费掉；变量泵或伺服电机驱动的泵可以减少这种浪费。力由压力（减去摩擦）或测力传感器得到；用比例阀实现速度和力的曲线。机电方案：丝杠在$5\ \mathrm{mm/s}$时出力$60\ \mathrm{kN}$（$300\ \mathrm{W}$），以$100\ \mathrm{mm/s}$小力趋近；采用导程$10\ \mathrm{mm}$的丝杠（$\eta \approx 0.9$），满载转矩为$60\,000 \times 0.010/(2\pi \times 0.9) = 106\ \mathrm{N\,m}$，所以需要一个减速器和峰值约$1$–$2\ \mathrm{kW}$的伺服电机；只在运动时耗能；借助伺服驱动器和测力传感器，精确的位置和力曲线以及监测都很自然；无油，较安静，但丝杠必须按工作循环和寿命选定（轴承和丝杠的额定值）。安全：两者都需要防护装置和双手操纵或光幕（[[mechatronics/system-integration]]）；液压系统还有储能和泄漏的危险。对这个力的范围，许多现代压装工位采用机电方案；在力大得多或要求工具处结构紧凑的场合，液压方案胜出。
:::
