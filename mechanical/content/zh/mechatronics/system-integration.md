前面各章逐一讨论了机电系统的各个部分：传感器、信号调理、微控制器、电机、流体传动、运动控制。一台机器不只是其各部分的总和。各自都满足技术要求的元件，组合在一起仍可能失效：电机驱动器的开关噪声污染了测力传感器的信号，回馈的制动能量使电源过电压，按平均功率选定的散热器让晶体管在峰值时被烧坏，乐观地把各部分准确度相加的误差预算使机器超差，用普通软件实现的防护联锁在程序第一次挂死时就失效了。**系统集成**是这样一门学问：设计各个部分，使整体能够工作——并在不能工作时安全地失效。

本章汇集系统层面的工具：设计过程与需求、误差预算、功率与热预算、电磁兼容与接地、可靠性以及功能安全。最后以把整个课程联系起来的工程案例作结：喷墨打印机小车、防抱死制动和3D打印机的一个轴。

## 从需求到架构 {#sec-process}

[[mechatronics/mechatronic-systems#sec-elements]]中的设计过程从**需求**开始：可测量的陈述，说明系统必须做什么、在什么条件下做以及如何验证。“又快又准”不是需求；“在$10$–$40\,^\circ\mathrm{C}$的环境温度下，以每分钟$60$个循环，在$0.35\ \mathrm{s}$内把$2\ \mathrm{kg}$的头在$400\ \mathrm{mm}$范围内定位到$\pm 50\ \mathrm{\mu m}$，寿命$20\,000$小时”才是需求。需求涵盖功能与性能、环境（温度、湿度、振动、粉尘、电磁环境）、接口（电源、通信、安装）、寿命与可靠性、安全及适用的标准、成本与产量。

**架构**把各项功能分配给物理要素，并确定它们之间的接口：哪些回路在哪里、以什么频率闭合，哪个控制器运行哪个任务，哪些信号以什么形式（模拟、数字、现场总线）跨越哪些边界，电能如何分配，安全功能设在哪里。然后，VDI 2206准则的V模型引导设计经过各领域的设计进入集成与验证，每一层都按分配给它的需求进行测试。有两个习惯使这一过程在实践中行之有效：**预算**——把每项系统需求在各要素之间分摊（误差、功率、热、时间、成本），并随设计的进展加以修订；以及粗糙原型的**早期集成**，因为各领域之间的相互作用——被控制回路激起的谐振、从驱动器耦合进传感器的噪声——发现起来要比预测容易得多。

## 误差预算 {#sec-error-budget}

一台机器的准确度是许多独立误差的综合：传感器分辨力与标定、丝杠导程误差、热膨胀、载荷下的结构变形、伺服误差、回差。**误差预算**把它们列出并加以合成。

::: proposition 独立误差的合成 {#prop-rss}
若总误差是独立随机分量$E_i$的加权和$E = \sum_i c_iE_i$，各分量的标准差为$u_i$（其**标准不确定度**），灵敏系数为$c_i$，则$E$的标准差为
$$
u_c = \sqrt{\sum_i c_i^2u_i^2} \qquad\text{（方和根，RSS）},
$$ {#eq-rss}
它绝不超过最坏情况之和$\sum_i \lvert c_i\rvert u_i$。对于只知道处于$\pm a$以内、且任何值都不比其他值更可能出现的分量（均匀分布），$u = a/\sqrt3$。
:::

::: proof
独立随机变量之和的方差等于其方差之和：$\operatorname{Var}(\sum c_iE_i) = \sum c_i^2\operatorname{Var}(E_i)$，因为对独立变量，交叉项$2c_ic_j\operatorname{Cov}(E_i, E_j)$为零。取平方根即得[[#eq-rss]]。不等式是向量$(\lvert c_1\rvert u_1, \dots)$的欧几里得范数与其$\ell^1$范数之间的三角不等式：对$x_i \ge 0$有$\sqrt{\sum x_i^2} \le \sum x_i$，因为把右边平方会加上非负的交叉项。对$[-a, a]$上的均匀分布，方差为$\frac{1}{2a}\int_{-a}^{a}x^2\,\mathrm{d}x = a^2/3$。
:::

这是《测量不确定度表示指南》（GUM，JCGM 100:2008）的规则。其有效性以独立性为前提：具有共同原因的误差——比如两个都随温度增大的分量——必须先线性相加，再与其余分量合成。可以测量的系统误差（丝杠的导程误差、系数已知的热漂移）应通过控制器中的标定表或温度模型加以**补偿**，而不是计入预算；预算中剩下的是补偿的不确定度。要以给定的置信度给出界限，就把合成标准不确定度乘以一个**包含因子**：当总和近似服从正态分布时，$k = 2$给出约$95\,\%$的包含概率。

::: example 定位误差预算 {#ex-error-budget}
一个直线轴在刀具处有以下独立误差分量（以标准不确定度给出）：伺服误差和编码器量化$3\ \mathrm{\mu m}$，补偿后的剩余丝杠导程误差$4\ \mathrm{\mu m}$，热膨胀$12\ \mathrm{\mu m}$。求合成标准不确定度、$k = 2$时的扩展不确定度以及线性和。设计者应首先解决哪一个分量？
::: solution
$u_c = \sqrt{3^2 + 4^2 + 12^2} = \sqrt{169} = 13\ \mathrm{\mu m}$。扩展不确定度：$U = 2 \times 13 = 26\ \mathrm{\mu m}$（包含概率约$95\,\%$）。线性和：$3 + 4 + 12 = 19\ \mathrm{\mu m}$（标准不确定度之和）。

热分量占主导：完全消除伺服误差和导程误差只能使$u_c$从$13$降到$12\ \mathrm{\mu m}$，而把热误差减半就能使其降到$\sqrt{9 + 16 + 36} = 7.8\ \mathrm{\mu m}$。热措施——温度控制、低膨胀材料、温度补偿的光栅尺，或控制器中的热模型——应放在首位。

合理性检查：在RSS预算中，最大项以平方关系占主导，所以花在小项上的力气是白费的。一根$300\ \mathrm{mm}$的钢丝杠每开尔文伸长$11.7 \times 10^{-6} \times 300\ \mathrm{mm} = 3.5\ \mathrm{\mu m}$；$12\ \mathrm{\mu m}$的热不确定度约相当于$3.4\ \mathrm{K}$——在没有空调的车间里，这是合理的日温度变化。
:::
:::

## 功率预算与热预算 {#sec-power}

**功率预算**列出每个用电者——控制器、传感器、驱动器和执行器——及其平均需求和峰值需求。电源按可能同时出现的峰值需求选定，其平均额定值按平均值选定，导线、熔断器和连接器按所涉及的电流选定。逻辑电路、模拟测量和功率级采用分开的电源（或至少是分别稳压和滤波的电源轨），在单一点汇接。

电机加速负载，然后又使其制动。电机减速时作为发电机运行，其驱动器把动能回馈到直流母线。蓄电池可以吸收这些能量；市电整流器则不能，所以这些能量给驱动器的母线电容充电，使其电压升高。由能量平衡$\tfrac12C(V_2^2 - V_1^2) = E$，母线电压升至
$$
V_2 = \sqrt{V_1^2 + \frac{2E}{C}} .
$$ {#eq-regen}
如果$V_2$会超过驱动器的额定值，就用斩波器接通的**制动电阻**（“再生”或“泄放”电路）把这些能量耗散掉。

::: example 24 V母线上的回馈能量 {#ex-regen}
一个$J = 2.0\times10^{-4}\ \mathrm{kg\,m^2}$的电机与负载从$300\ \mathrm{rad/s}$减速到静止。驱动器的母线由一个不能吸收电流的电源以$24\ \mathrm{V}$供电，母线电容为$4700\ \mathrm{\mu F}$。忽略损耗，求停止结束时的母线电压。
::: solution
$E = \tfrac12J\omega^2 = 0.5 \times 2.0\times10^{-4} \times 9.0\times10^{4} = 9.0\ \mathrm{J}$。$V_2 = \sqrt{24^2 + 2 \times 9.0/4.7\times10^{-3}} = \sqrt{576 + 3830} = 66\ \mathrm{V}$。

额定值为（比如）$60\ \mathrm{V}$的驱动器会因过电压而跳闸或损坏。补救办法：在约$30\ \mathrm{V}$以上由斩波器接入的制动电阻；更大的电容（要保持在$30\ \mathrm{V}$以下，需要$C = 2E/(30^2 - 24^2) = 0.056\ \mathrm{F}$，这是一个很大的电容器组）；或者能吸收能量的电源。

合理性检查：实际上绕组电阻和摩擦会耗散一部分能量，所以这是一个上限——但数量级是对的，而且同时停止所有轴（急停）的多轴机器会在同一时刻回馈所有轴的动能之和。
:::
:::

每一瓦损耗都变成热，必须经过一串**热阻**散发出去。对于耗散功率为$P$的半导体器件，稳态结温为
$$
T_j = T_a + P\left(R_{\theta jc} + R_{\theta cs} + R_{\theta sa}\right),
$$ {#eq-thermal}
其中各项分别为结到壳、壳到散热器（界面材料）和散热器到环境的热阻，单位K/W——这是欧姆定律的热学类比（[[heat-transfer/steady-conduction]]）。所选散热器应使$T_j$在最高环境温度下仍留有余量地低于数据手册的最大值（通常为$125$–$175\,^\circ\mathrm{C}$）；电解电容的寿命大约每升高$10\ \mathrm{K}$减半，它往往才是真正的限制。机箱也需要同样的预算：内部产生的热量必须通过箱壁或风扇散出，使内部温度高于室温。

## 电磁兼容与接地 {#sec-emc}

**电磁兼容**（EMC）是指系统不干扰其他设备（**发射**），也不受其环境的干扰（**抗扰度**）。机电系统是棘手的情形：它们包含强大的噪声源——在纳秒级内切换几百伏电压的PWM驱动器、继电器和电磁铁、开关电源——而旁边就是微伏级的传感器信号。在欧盟，EMC指令（2014/30/EU）要求符合性，通常按协调标准来证明，例如针对工业环境的IEC 61000-6-2（抗扰度）和IEC 61000-6-4（发射）。

耦合机理已在[[mechatronics/signal-conditioning#sec-noise]]中介绍过。在系统层面的做法是：

- 对设计进行**分区**：功率电子、电机电缆和开关电路在一个区域，敏感的模拟电路在另一个区域，每一根进出的电缆都要滤波。
- **接地：**电路板上采用完整的参考平面；用单一**星形点**把逻辑地、模拟地和功率地连接起来，使大的回流电流不流过信号地；或者在无法避免时，采用差分信号传输和电气隔离（光耦合器、隔离放大器、隔离电源）来断开**接地环路**。
- **布线：**屏蔽电机电缆，屏蔽层两端作360°搭接（针对高频发射），信号用双绞线，信号电缆与动力电缆分开，在入口处的电缆上加铁氧体磁环。
- **去耦：**在每个集成电路的电源引脚处、紧靠引脚放置一个陶瓷电容（典型值$100\ \mathrm{nF}$），在每块电路板的电源输入处放置大容量电容；使开关电流回路保持很小。

::: example 传感器输入中的接地环路 {#ex-ground-loop}
一个$0$–$10\ \mathrm{V}$位置传感器的地通过一根电阻为$20\ \mathrm{m\Omega}$的导体接到控制器的地，而该导体同时承载电机驱动器$10\ \mathrm{A}$的回流电流。求传感器读数的误差，并提出两种解决办法。
::: solution
驱动器电流在共用导体上产生$10 \times 0.020 = 0.20\ \mathrm{V}$的压降。控制器相对于它自己的地测量传感器电压，所以读数偏移最多可达$0.20\ \mathrm{V}$——满量程的$2\,\%$——而且偏移随电机电流变化，表现为与运动相关的噪声。

解决办法：(1) 给传感器一根单独的地回线接到控制器的星形点，使其中没有电机电流流过；(2) 用差分输入（仪表放大器）读取传感器，测量传感器输出与传感器自己的地线之间的电压，从而抑制共模偏移。采用$4$–$20\ \mathrm{mA}$电流环的传感器也不受影响。

合理性检查：$20\ \mathrm{m\Omega}$只相当于几米长的$1.5\ \mathrm{mm^2}$铜线。共用回线是电机一停就消失的“传感器噪声”最常见的根源。
:::
:::

## 可靠性 {#sec-reliability}

::: definition 可靠度、失效率与MTTF {#def-reliability}
元件的**可靠度**$R(t)$是它在时刻$t$仍在工作的概率。对于**失效率**$\lambda$（幸存者中单位时间的失效数）为常数的元件——这对处于早期失效与耗损之间的有用寿命期内的电子器件是一个很好的模型——
$$
R(t) = e^{-\lambda t},\qquad \text{MTTF} = \int_0^\infty R(t)\,\mathrm{d}t = \frac1\lambda .
$$
电子器件的失效率常以**FIT**（每$10^9$器件小时的失效数）表示。对于可修复系统，以同样的方式使用平均故障间隔时间（MTBF）。
:::

::: proposition 串联系统与并联系统 {#prop-series-parallel}
(a) $n$个独立元件中**任何一个**失效系统即失效（可靠性意义上的**串联**），则$R_s = \prod_i R_i$；失效率恒定时，$\lambda_s = \sum_i\lambda_i$。

(b) $n$个独立元件中**至少一个**工作系统即工作（**工作冗余**，并联），则$R_p = 1 - \prod_i(1 - R_i)$。对于两个失效率均为常数$\lambda$的相同元件，$\text{MTTF} = 3/(2\lambda)$。
:::

::: proof
(a) 只有每个元件都幸存，系统才幸存；对独立事件，概率为乘积。由$R_i = e^{-\lambda_it}$，$\prod_iR_i = e^{-(\sum_i\lambda_i)t}$，这是速率为$\sum_i\lambda_i$的指数分布。(b) 只有每个元件都失效，系统才失效，其概率为$\prod_i(1 - R_i)$；系统以互补的概率幸存。对两个相同元件，$R_p = 1 - (1 - e^{-\lambda t})^2 = 2e^{-\lambda t} - e^{-2\lambda t}$，$\text{MTTF} = \int_0^\infty R_p\,\mathrm{d}t = 2/\lambda - 1/(2\lambda) = 3/(2\lambda)$。
:::

串联系统是常态：一台有一百个元件的机器，只要其中任何一个失效它就失效，所以其失效率是各元件失效率之和，每个元件都很重要。冗余代价高昂，而且其作用比直觉所认为的要小：两个单元并联只使MTTF提高$50\,\%$，尽管它们大大提高了短任务期内的可靠度（当$\lambda t$很小时，$R \approx 1 - (\lambda t)^2$而不是$1 - \lambda t$）——这就是冗余用于任务期间不容许失效的场合（飞机飞行操纵、车辆制动）、并与监测和维修相结合的原因。冗余通道还必须防范**共因失效**——共用的电源、同一个软件缺陷、同样的过热——它们会使冗余通道同时失效。

::: example 控制器的可靠性 {#ex-reliability}
一块电机控制板上有一个微控制器（$100\ \mathrm{FIT}$）、一个栅极驱动器（$200\ \mathrm{FIT}$）、六个功率MOSFET（各$100\ \mathrm{FIT}$）、电解电容（共$600\ \mathrm{FIT}$）、连接器和焊点（$500\ \mathrm{FIT}$）——全部串联。求其失效率、MTTF以及连续运行一年的幸存概率。两块这样的板工作冗余时，一年可靠度是多少？
::: solution
$\lambda = 100 + 200 + 600 + 600 + 500 = 2000\ \mathrm{FIT} = 2.0\times10^{-6}\ \mathrm{h^{-1}}$。MTTF $= 5.0\times10^{5}\ \mathrm{h}$（约$57$年）。一年（$8760\ \mathrm{h}$）：$R = e^{-0.01752} = 0.9826$——失效概率为$1.7\,\%$。两块并联：$R_p = 1 - (1 - 0.9826)^2 = 1 - 3.0\times10^{-4} = 0.9997$。

合理性检查：几十年的MTTF并不意味着一块板能用几十年——它意味着在$1000$块板中，第一年约有$17$块失效。恒定失效率模型也忽略了耗损；电解电容和风扇会耗损，必须另行校核它们在工作温度下的寿命。
:::
:::

## 功能安全 {#sec-safety}

运动的机器可能伤人。**机械安全**从**风险评估**（ISO 12100）开始：识别危险（挤压、剪切、缠绕、储存的能量、热、电），根据严重程度和可能性估计每种危险的风险，并依次通过本质安全设计（限制力和速度，消除夹点）、安全防护（固定式防护装置、联锁的活动式防护装置、光幕、双手操纵装置）和使用信息（警告、培训）来降低风险。当安全防护依赖于控制系统时——例如一个必须使电机停止的防护门开关——该控制功能就是一个**安全功能**，其可靠性由**功能安全**标准规定和验证：ISO 13849-1把控制系统中与安全相关的部件按**性能等级**PL a到e分级；IEC 62061和通用标准IEC 61508采用**安全完整性等级**SIL 1到3（IEC 61508中到4），每个等级对应每小时危险失效概率的一个范围。

由此得出机电设计的几条原则：

- **安全功能与普通控制分开。**防护联锁不是运动控制软件中的一条`if`语句，那样的软件可能挂死或出错；它由具备安全等级的元件实现——安全继电器或安全控制器，以及驱动器中的**安全转矩关断**（STO，IEC 61800-5-2），它用硬件切断电机栅极驱动器的电源，使电机无法产生转矩。
- **停止类别**（IEC 60204-1）：0类立即切断电源（电机惯性滑行）；1类受控制动，然后切断电源；2类受控停止并保持供电。急停为0类或1类，并且必须优先于其他一切功能。
- **故障安全和受监控的设计**：常闭安全触点（断线即使机器停止），带交叉监控的冗余通道，使控制器复位到安全状态的看门狗定时器，断电时接合的制动器（用于垂直轴，电机被禁止时垂直轴会在重力作用下坠落）。
- **确认**：作为符合适用法规的一部分，要对安全功能进行测试，并把其性能等级的计算形成文件——在欧盟是机械指令2006/42/EC，它正被将于2027年1月起适用的机械法规（EU）2023/1230取代。

::: warning 软件不是防护装置
最危险的集成错误是依赖普通控制程序来保证安全：在软件中暂停运动的“门开”输入，由运行电机的同一个微控制器读取的急停按钮，只在轨迹发生器中执行的速度限制。每一种都恰恰在需要它的时候失效——程序挂死、变量被破坏、接线故障被读成“正常”。安全功能要采用按所要求的PL或SIL设计和确认的、具备安全等级并受监控的硬件（或经认证的安全控制器），由STO或接触器直接作用于电源。本讲讲授的是原则；机械安全是一个受法规管理的领域，实际的机器由合格的工程师按现行标准设计和确认。
:::

## 工程案例 {#sec-cases}

**喷墨打印机小车。**一台有刷直流电机通过同步带驱动打印头小车沿一根普通钢杆运动。一条每英寸约150到600线（每毫米6到24线）的透明码带由小车上的光学正交传感器读取，直接在打印头处给出位置——所以带的伸长和带轮误差都处于回路之内并被修正。控制器生成梯形曲线，采用速度和加速度前馈以及几千赫兹的PID回路，并由编码器边沿而不是由时间触发喷嘴，使得即使速度有变化，墨滴也能落在正确的位置。进纸采用另一台带旋转编码器的直流电机。一切——机构、电机、传感器——都很便宜；精度来自传感器的布置和软件。

**防抱死制动。**车轮抱死时，轮胎滑移，既失去制动附着力，也失去转向能力。防抱死制动系统（ABS）用齿圈和电感式或霍尔式传感器测量每个车轮的转速，由所有车轮估算车速$v$，并计算**滑移率**
$$
\lambda = \frac{v - \omega r}{v},
$$ {#eq-slip}
（$\omega$为车轮转速，$r$为其滚动半径）。在大多数路面上，轮胎的制动力在滑移率约为$0.1$–$0.2$时达到峰值，超过后下降。当车轮减速过快或滑移率越过峰值时，液压调节器中的电磁阀先保持、然后释放该车轮的制动压力，一台泵把释放出的制动液送回；然后重新加压，每秒循环数次，使车轮保持在摩擦曲线峰值附近。ABS是完整意义上的机电系统：传感器、液压执行器（[[mechatronics/fluid-power]]）、具有大量自监测功能的嵌入式控制器，以及一个失效时必须退回常规制动的安全关键功能。

::: example ABS中的滑移率 {#ex-slip}
一辆汽车以$20\ \mathrm{m/s}$行驶。制动时，一个滚动半径为$0.30\ \mathrm{m}$的车轮以$60\ \mathrm{rad/s}$转动。求滑移率。若控制器的目标区间为$0.10$–$0.20$，在此车速下应保持怎样的车轮转速范围？
::: solution
$\omega r = 60 \times 0.30 = 18\ \mathrm{m/s}$；$\lambda = (20 - 18)/20 = 0.10$，处于区间的下边缘。对于该区间：$\omega = v(1 - \lambda)/r$，即从$20 \times 0.90/0.30 = 60\ \mathrm{rad/s}$到$20 \times 0.80/0.30 = 53.3\ \mathrm{rad/s}$。

合理性检查：这个区间只有$7\ \mathrm{rad/s}$宽，而车速估计本身就不确定（所有车轮可能都在滑移），所以实用的ABS算法同时使用车轮减速度阈值和滑移率估计，而不是一个精确的滑移率设定值。
:::
:::

**3D打印机的一个轴。**典型的桌面打印机用两相混合式步进电机（[[mechatronics/electric-actuators#sec-stepper]]）驱动同步带来移动打印头，开环工作，采用$1/16$微步，用限位开关回零。固件通过一个前瞻缓冲区规划梯形或限制加加速度的曲线，使打印头不会在曲线的每一段都停下来。加热块和热床是各自独立的温度回路，采用热敏电阻和MOSFET开关（[[mechatronics/mechatronic-systems]]），固件中有热失控保护（较好的设计中还有独立的热熔断器）。这些设计选择出于经济考虑：步进电机省去了编码器和整定，代价是喷嘴撞上翘边的打印件时会丢步——这就是较贵的打印机增加编码器、闭环步进电机或基于加速度计的谐振补偿（输入整形）的原因，它们所用的恰恰是[[mechatronics/motion-control]]中的思想。

::: quiz
两个相同的控制器，一年可靠度各为$0.90$，以工作冗余方式使用，二者由同一个电源供电，该电源的一年可靠度为$0.95$。系统的一年可靠度是多少？
- [ ] $0.99$
- [x] 约$0.94$
- [ ] $0.90$
- [ ] $0.855$
::: solution
冗余对的$R = 1 - 0.1^2 = 0.99$；它与共用电源串联：$0.99 \times 0.95 = 0.9405$。共用电源是一个占主导的共因失效；在电源也加倍之前，冗余几乎没有收益。
:::
:::

::: history
机电产品的系统化设计方法被整理成德国准则VDI 2206《机电系统设计方法》（*Design methodology for mechatronic systems*），于2004年发布，2021年修订。功能安全以1998年至2000年间分部分发布的IEC 61508获得了其现代形式，由它衍生出各行业标准——机械领域的IEC 62061（2005年）、采用概率形式的ISO 13849-1（2006年）以及道路车辆的ISO 26262（2011年）。博世于1978年在梅赛德斯-奔驰S级轿车上把第一套电子四轮防抱死制动系统投入批量生产，并于1986年发布了控制器局域网（CAN），CAN于1991年在梅赛德斯-奔驰S级轿车上首次投入批量生产，成为汽车电子的骨干。
:::

::: summary
- 从可测量的需求出发；确定架构和接口；保持误差、功率、热、时序和成本预算；尽早集成。
- 独立误差按标准不确定度的方和根合成，$u_c = \sqrt{\sum c_i^2u_i^2}$；相关误差线性相加；最大项占主导；可测量的系统误差应予以补偿。
- 电源按同时出现的峰值选定；回馈能量使母线升至$\sqrt{V_1^2 + 2E/C}$——要使用制动电阻。$T_j = T_a + P\sum R_\theta$。
- EMC：分区、星形接地、隔离、屏蔽电缆和双绞线、去耦；共用的地回线会把电机电流变成传感器误差。
- 可靠性：$R = e^{-\lambda t}$，MTTF $1/\lambda$；串联时失效率相加；并联对大大提高短任务可靠度，但MTTF只提高$50\,\%$；要提防共因失效。
- 安全：风险评估（ISO 12100），安全功能由达到所要求的PL或SIL的安全等级硬件（STO、安全继电器）实现，IEC 60204-1的停止类别；绝不依赖普通软件。
:::

## 习题

::: exercise 方和根 {level=1 check="26"}
三个独立误差分量的标准不确定度为$6$、$8$和$24\ \mathrm{\mu m}$。求合成标准不确定度。（以μm为单位填写。）
::: solution
$\sqrt{36 + 64 + 576} = \sqrt{676} = 26\ \mathrm{\mu m}$，而线性和为$38\ \mathrm{\mu m}$。
:::
:::

::: exercise 串联失效率 {level=1 check="1000000"}
一个系统由失效率为$200$、$300$和$500\ \mathrm{FIT}$的三个元件串联组成。求其MTTF。（以小时为单位填写。）
::: solution
$\lambda = 1000\ \mathrm{FIT} = 10^{-6}\ \mathrm{h^{-1}}$；MTTF $= 10^{6}\ \mathrm{h}$。
:::
:::

::: exercise 并联冗余 {level=1 check="0.99"}
两个独立的传感器在一次任务期内的可靠度各为$0.90$，使用时任一个即可满足要求。求任务可靠度。（填写$R$。）
::: solution
$1 - (1 - 0.90)^2 = 1 - 0.01 = 0.99$。
:::
:::

::: exercise 冗余对的MTTF {level=2 check="15000"}
两个失效率恒为$\lambda = 1.0\times10^{-4}\ \mathrm{h^{-1}}$的相同单元以工作冗余方式运行。求该冗余对的MTTF。（以小时为单位填写。）
::: solution
$3/(2\lambda) = 3/(2\times10^{-4}) = 15\,000\ \mathrm{h}$，而单个单元为$10\,000\ \mathrm{h}$。
:::
:::

::: exercise 散热器选择 {level=2 check="14.5"}
一个MOSFET耗散$5.0\ \mathrm{W}$，$R_{\theta jc} = 1.0\ \mathrm{K/W}$，导热垫为$0.5\ \mathrm{K/W}$。在$45\,^\circ\mathrm{C}$环境温度下，结温必须低于$125\,^\circ\mathrm{C}$。求可接受的最大散热器到环境热阻。（以K/W为单位填写。）
::: solution
允许的总热阻$(125 - 45)/5.0 = 16\ \mathrm{K/W}$；$R_{\theta sa} \le 16 - 1.0 - 0.5 = 14.5\ \mathrm{K/W}$。设计者可能会为留出余量而选择约$10\ \mathrm{K/W}$的散热器。
:::
:::

::: exercise 电池续航时间 {level=2 check="4.8"}
一台移动机器人从一块$24\ \mathrm{V}$、$20\ \mathrm{Ah}$的电池中平均取用$80\ \mathrm{W}$，电池容量的$80\,\%$可以使用。求续航时间。（以小时为单位填写。）
::: solution
可用能量$24 \times 20 \times 0.80 = 384\ \mathrm{Wh}$；续航时间$384/80 = 4.8\ \mathrm{h}$。高于平均值的峰值不改变能量，但决定电池的电流额定值和电压跌落。
:::
:::

::: exercise 滑移率 {level=2 check="0.104"}
一辆汽车以$25\ \mathrm{m/s}$行驶，一个滚动半径为$0.32\ \mathrm{m}$的制动车轮以$70\ \mathrm{rad/s}$转动。求滑移率。（填写$\lambda$。）
::: solution
$\omega r = 22.4\ \mathrm{m/s}$；$\lambda = (25 - 22.4)/25 = 0.104$。
:::
:::

::: exercise 接地环路误差 {level=2 check="1.5"}
$15\ \mathrm{A}$的电机回流电流流过与一个$0$–$10\ \mathrm{V}$传感器的地共用的$10\ \mathrm{m\Omega}$导体。求由此产生的误差占满量程的百分数。（以%为单位填写。）
::: solution
$15 \times 0.010 = 0.15\ \mathrm{V}$，即$10\ \mathrm{V}$的$1.5\,\%$。
:::
:::

::: exercise 备用冗余 {level=3}
在**备用**冗余中，第二个单元只在第一个单元失效时才接通（假设切换完美且空闲时不失效）。对两个失效率恒为$\lambda$的相同单元，推导可靠度$R(t)$，并证明MTTF为$2/\lambda$。与工作冗余比较并解释其差别。
::: solution
系统存活到$t$的情形是：第一个单元存活（$e^{-\lambda t}$），或者它在某个$\tau < t$时失效（概率密度$\lambda e^{-\lambda\tau}$），而在$\tau$时启动的第二个单元在剩余的$t - \tau$内存活（$e^{-\lambda(t - \tau)}$）。所以$R(t) = e^{-\lambda t} + \int_0^t\lambda e^{-\lambda\tau}e^{-\lambda(t - \tau)}\,\mathrm{d}\tau = e^{-\lambda t}(1 + \lambda t)$。于是$\text{MTTF} = \int_0^\infty e^{-\lambda t}(1 + \lambda t)\,\mathrm{d}t = 1/\lambda + 1/\lambda = 2/\lambda$——寿命相加。工作冗余只给出$3/(2\lambda)$，因为两个单元一起老化，当第一个失效时第二个可能已经失效了。备用冗余在纸面上更好，但它依赖于切换的正常工作以及对工作单元失效的检测；空闲单元也可能发生未被发现的失效，所以要定期测试。
:::
:::

::: exercise 包裹分拣闸门的概念设计 {level=3}
一条输送机以$2\ \mathrm{m/s}$输送$0.2$–$10\ \mathrm{kg}$的包裹；一个闸门必须把选定的包裹分流到侧面滑槽，在触发后$150\ \mathrm{ms}$内完成其行程，每小时$3000$次，寿命$10$年。提出系统方案：需求清单、执行器选择（气缸、伺服电机、电磁铁）、传感（包裹检测、闸门位置）、控制器与通信、误差和时序预算、可靠性（循环次数），以及针对在输送机附近工作人员的安全措施。
::: solution
好的回答包括：(i) 量化的需求——行程和力（由包裹动量决定，需改变方向的动量最多为$10 \times 2 = 20\ \mathrm{N\,s}$），时序（$150\ \mathrm{ms}$，所以传感器、控制器以及阀或驱动器从触发到动作的延迟最多只能是几十毫秒），寿命（若连续运行为$3000 \times 8760 \times 10 \approx 2.6\times10^{8}$次循环——这是一个关键因素：电磁阀和气缸的额定寿命为几千万次循环，所以可能需要规定维护周期，或采用没有易磨损密封件的伺服驱动）。(ii) 执行器：气缸便宜而快速，但其时序随供气压力变化，密封件会磨损；带曲柄或同步带的伺服电机给出可重复、可编程的运动和诊断功能。(iii) 传感：上游设置光栅或摄像头，利用已知的距离和输送速度（输送机上的编码器）为闸门定时；闸门位置由终端开关或伺服编码器得到。(iv) 控制器：具有确定性时序的PLC或微控制器；通过现场总线与分拣系统通信；检测、决策和执行的时序预算。(v) 可靠性：识别易损件并安排更换；监测循环时间以预测失效。(vi) 安全：风险评估；在闸门扫过的空间周围设置防护装置；通过安全继电器作用于STO或气动泄放阀的联锁检修门，急停；停止时释放储存的气压能；在可能夹住手指的地方限制闸门的力。
:::
