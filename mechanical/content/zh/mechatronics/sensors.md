控制器的好坏取决于它得到的信息。位置回路不可能把小车保持得比编码器的分辨力更准；力控制器施加力的准确度不可能超过测力传感器的测量准确度；传感器迟缓的温度回路无论怎样整定都会超调。因此，选择并理解传感器是任何机电系统中的第一项设计决策，也是许多系统出问题的地方。

**传感器**（sensor，或称变换器，transducer）把一个物理量——**被测量**（measurand）——转换为一个信号，这个信号几乎总是电信号。大多数传感器利用某种把被测量与电学量耦合起来的物理效应：受拉导线的电阻变化、两种金属结点处的电压、受挤压晶体上的电荷、开槽圆盘对光线的遮断。本章首先定义比较传感器所用的性能指标——静态的和动态的——然后逐一讨论机械工程师最常遇到的传感器：位置与速度、加速度、应变、力与压强以及温度传感器。把它们微弱而含噪声的信号变成数值的电子电路是[[mechatronics/signal-conditioning]]的主题。

## 静态特性 {#sec-static}

::: definition 传感器的静态特性 {#def-static}
对于在输入（被测量）$x$为稳定值时测量其输出$y$的传感器：

- **量程**（range）是传感器设计工作的$x$区间；**跨度**或**满量程**（full scale，FS）是该区间的宽度。**输出跨度**是$y$的相应范围。
- **灵敏度**是标定曲线的斜率$S = \mathrm{d}y/\mathrm{d}x$（例如$\mathrm{mV/N}$或$\mathrm{counts/mm}$）。
- **分辨力**是能使$y$产生可检测变化的$x$的最小变化量。对数字传感器，它是一个计数；对模拟传感器，它由噪声和读取它的转换器决定。
- **误差**是示值与真值之差；**准确度**是误差的界限，通常表示为满量程的百分数（% FS）或读数的百分数。
- **非线性度**是标定曲线对参考直线的最大偏差，以% FS表示。**端点**直线连接量程两端的输出；**独立**（最佳拟合）直线使最大偏差最小，所得数值约为端点数值的一半。
- **迟滞**是从下方和从上方趋近同一输入时输出的最大差值。
- **重复性**是在相同条件下重复施加同一输入时输出的分散程度。
- **漂移**是输入不变时输出随时间或温度的变化：**零点漂移**（偏置）和**灵敏度漂移**（增益）。
:::

**分辨力**与**准确度**的区别时时都很重要。一个编码器可以分辨一微米，而它所安装的丝杠却有十微米的导程误差；一个16位转换器分辨读数的六万五千五百三十六分之一，而传感器的准确度只有五百分之一。反馈控制能修正传感器看得到的一切，而对它看不到的东西无能为力：传感器与关注点**之间**的误差（丝杠导程、热膨胀、机架变形）依然存在，这就是精密机床把编码器尽可能装得靠近刀具的原因。

::: example 由标定求非线性度 {#ex-linearity}
一个量程为$0$–$100\ \mathrm{N}$的测力传感器用砝码标定，得到如下输出

| $F$ / N | 0 | 25 | 50 | 75 | 100 |
|---|---|---|---|---|---|
| $y$ / mV | 0 | 2.52 | 5.03 | 7.52 | 10.00 |

求灵敏度和端点非线性度。
::: solution
端点直线连接$(0, 0)$和$(100, 10.00)$：灵敏度$S = 10.00/100 = 0.100\ \mathrm{mV/N}$，它在中间各载荷处预测的输出为$2.50$、$5.00$、$7.50\ \mathrm{mV}$。偏差为$0.02$、$0.03$、$0.02\ \mathrm{mV}$。最大偏差为$0.03\ \mathrm{mV}$，跨度为$10.00\ \mathrm{mV}$：非线性度为$0.3\,\%$ FS。

合理性检查：各偏差符号相同，且在量程中部最大——呈弓形，这是刚度略有非线性的弹性元件的典型表现。最佳拟合直线约上移$0.015\ \mathrm{mV}$，可使该数值减半，约为$0.15\,\%$ FS，这就是制造商通常给出最佳拟合值的原因；要弄清数据手册指的是哪一条直线。
:::
:::

## 动态特性 {#sec-dynamic}

一个稳态下完美的传感器，如果响应迟缓，放在回路中仍可能毫无用处。大多数传感器可以用一阶或二阶模型很好地描述。

### 一阶传感器

::: proposition 集总传感器的热时间常数 {#prop-thermal-tau}
质量为$m$、比热容为$c$、表面积为$A$的传感器浸没在温度为$T_f(t)$、表面传热系数为$h$的流体中，且尺寸足够小，使其自身温度均匀（毕渥数$\mathrm{Bi} = h(V/A)/k < 0.1$），则它满足
$$
\tau\,\frac{\mathrm{d}T_s}{\mathrm{d}t} + T_s = T_f(t),\qquad \tau = \frac{mc}{hA} = \frac{\rho c V}{hA}.
$$ {#eq-first-order-sensor}
$T_f$阶跃变化后，误差按$e^{-t/\tau}$衰减；当$T_f$以恒定速率$\dot T$上升时，瞬态消失后传感器读数滞后$\tau\dot T$。
:::

::: proof
对传感器作能量平衡：储能的增加率等于对流传入的热流量，$mc\,\mathrm{d}T_s/\mathrm{d}t = hA(T_f - T_s)$，其中整个物体用一个温度表示（由于毕渥数很小，这是合理的，与[[heat-transfer/transient-conduction]]中的集总参数法分析相同）。除以$hA$即得[[#eq-first-order-sensor]]。对斜坡输入$T_f = T_0 + \dot Tt$且$T_s(0) = T_0$，试取$T_s = T_0 + \dot T(t - \tau) + Be^{-t/\tau}$：则$\tau\,\mathrm{d}T_s/\mathrm{d}t = \tau\dot T - Be^{-t/\tau}$，加上$T_s$得$T_0 + \dot Tt = T_f$，故对任意$B$该试探函数都满足方程；初始条件$T_s(0) = T_0$给出$B = \dot T\tau$。当$t \to \infty$时指数项消失，$T_f - T_s \to \dot T\tau$。
:::

同一方程描述任何具有一个储能元件和一个耗散元件的传感器：通过细长管连接到小腔体的压力传感器、RC滤波器、低频下的热线风速计。时间常数并不只是传感器本身的属性：它取决于$h$，而流动的水中的$h$比静止空气中大几百倍。

::: example 热电偶测量端 {#ex-bead}
一个热电偶结点是直径为$1.0\ \mathrm{mm}$的小球，$\rho = 8500\ \mathrm{kg/m^3}$，$c = 400\ \mathrm{J\,kg^{-1}\,K^{-1}}$，$k = 20\ \mathrm{W\,m^{-1}\,K^{-1}}$，置于$h = 200\ \mathrm{W\,m^{-2}\,K^{-1}}$的气流中。求其时间常数，检验集总假设，并求气体温度以$2\ \mathrm{K/s}$上升时的滞后。
::: solution
对球体，$V/A = D/6 = 1.667\times10^{-4}\ \mathrm{m}$。于是$\tau = \rho cV/(hA) = 8500 \times 400 \times 1.667\times10^{-4}/200 = 2.83\ \mathrm{s}$。毕渥数$200 \times 1.667\times10^{-4}/20 = 1.7\times10^{-3} \ll 0.1$：集总分析成立。斜坡过程中的滞后：$\tau\dot T = 2.83 \times 2 = 5.7\ \mathrm{K}$。

合理性检查：$\tau \propto D$，所以$0.25\ \mathrm{mm}$的测量端约在$0.7\ \mathrm{s}$内响应（而且测量端越小，$h$也越大）。装在直径几毫米的保护套管中的热电偶，时间常数可达几十秒——比它所用于控制的许多过程还慢。
:::
:::

### 二阶传感器：加速度计

**加速度计**通过测量使一个小**检验质量**（proof mass）跟随其壳体运动所需的力来测量加速度。把它建模为壳体内一个质量$m$、弹簧$k$、阻尼$c$的系统，壳体以位移$x_b(t)$运动；令$z = x_m - x_b$为质量相对于壳体的位移，它由敏感元件（压电晶体、电容梳齿、应变片）测量。

::: proposition 惯性式加速度计 {#prop-accelerometer}
相对位移$z$对壳体加速度$a = \ddot x_b$的响应为
$$
\frac{Z(s)}{A(s)} = \frac{-1}{s^2 + 2\zeta\omega_n s + \omega_n^2},\qquad \omega_n = \sqrt{k/m},\quad \zeta = \frac{c}{2\sqrt{km}} .
$$ {#eq-accelerometer}
在远低于共振的频率下$z \approx -a/\omega_n^2$，所以灵敏度为$1/\omega_n^2$。对频率为$\omega$的正弦加速度，相对于低频值的幅值比为
$$
\frac{\lvert Z\rvert\,\omega_n^2}{\lvert A\rvert} = \frac{1}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}},\qquad r = \frac{\omega}{\omega_n}.
$$ {#eq-accel-ratio}
:::

::: proof
检验质量的受力图：弹簧力$-k(x_m - x_b)$和阻尼力$-c(\dot x_m - \dot x_b)$，二者都作用在质量上并由壳体传来；重力是一个常值偏置，略去。由牛顿第二定律$m\ddot x_m = -kz - c\dot z$，并利用$\ddot x_m = \ddot z + a$，得$m\ddot z + c\dot z + kz = -ma$。除以$m$并在零初始条件下取拉普拉斯变换，即得[[#eq-accelerometer]]。在$s = 0$处增益为$-1/\omega_n^2$；令$s = j\omega$并取相对于该值的模，即得[[#eq-accel-ratio]]。
:::

由此得出的设计结论是灵敏度与带宽之间的权衡：柔软的悬挂（低$\omega_n$）使单位加速度产生的位移大，但可用频率低。压电加速度计刚度很高（共振频率$20$–$50\ \mathrm{kHz}$），几乎无阻尼（$\zeta \approx 0.01$–$0.05$）；它们的使用频率上限约为共振频率的五分之一，此时幅值误差约为$4\,\%$。MEMS电容式加速度计（如手机和安全气囊控制器中的）共振频率为几千赫，气体阻尼接近$\zeta \approx 0.7$，这使响应在直到约$0.6\,\omega_n$的范围内保持在$5\,\%$以内（对$\zeta = 1/\sqrt2$，当$r \to 0$时完全平直，在$r = 1$附近为$-3\ \mathrm{dB}$）。

## 位置与速度 {#sec-position}

### 电位器与LVDT

**电位器**是带有滑动电刷的电阻轨道：在轨道两端加上电源$V_s$，只要读取时不产生负载效应（[[mechatronics/mechatronic-systems#ex-pot-loading]]），电刷电压就与位置成正比。它便宜、给出绝对位置且不需要电子电路，但电刷会磨损，分辨力受轨道限制（线绕轨道逐匝跳变）。它见于操纵杆、节气门位置传感器和模型用伺服电机。

**线性可变差动变压器**（LVDT）有一个由交流电压（通常为$1$–$10\ \mathrm{kHz}$）激励的初级线圈和两个反向串联的次级线圈，以及一个可移动的铁磁铁芯。铁芯处于中心时两个次级电压相互抵消；铁芯移动时一个增大、另一个减小，差值的幅值与位移成正比，其相位指示方向。相敏解调器把它转换为直流电压。由于铁芯与线圈之间没有接触，LVDT的分辨力实际上是无限的（受电子电路限制），没有磨损，并能在恶劣环境中工作，包括在液压缸内部。

### 编码器

::: definition 增量式编码器与绝对式编码器 {#def-encoder}
**增量式编码器**在运动时产生脉冲：一个圆盘（旋转式）或标尺（直线式）上每转或每单位长度刻有$N$条线，由两个相距四分之一线距的传感器（通道$A$和$B$）以光学或磁学方式读取，因此两个方波相差$90°$（**正交**，quadrature）。对两个通道的每一个上升沿和下降沿计数，每转得到$4N$个计数（**四倍频解码**）；边沿的先后次序（$A$超前$B$还是$B$超前$A$）给出方向。第三个**零位**（index）通道每转给出一个脉冲作为基准。位置只能相对于上电时的位置得知，所以机器在启动后要**回零**到一个开关或零位脉冲。

**绝对式编码器**对每个位置给出唯一的码字，它从若干码道读取（或从单芯片传感器串行读出），所以上电时立即就知道位置。其码道采用**格雷码**（Gray code），相邻位置之间恰好只有一位不同，因此在跳变过程中读取的值最多错一步。
:::

通过导程为$p$（每转行程）的丝杠驱动直线轴的旋转编码器，其分辨力为每个计数$p/(4N)$。采用普通二进制码时，从$0111$到$1000$的一步改变四位；如果读头稍有错位，在这一跳变过程中读到的值可能是十六个值中的任何一个。格雷码（$0100$到$1100$）消除了这个问题。

::: example 滚珠丝杠轴上的编码器分辨力 {#ex-encoder}
一台伺服电机带有2500线增量式编码器，通过导程为$10\ \mathrm{mm}$的滚珠丝杠驱动小车。求以每转计数和以微米表示的分辨力，以及小车速度为$0.5\ \mathrm{m/s}$时的计数频率。
::: solution
四倍频解码：每转$4 \times 2500 = 10\,000$个计数。直线分辨力为每个计数$10\ \mathrm{mm}/10\,000 = 1.0\ \mathrm{\mu m}$。在$0.5\ \mathrm{m/s}$时丝杠转速为$0.5/0.010 = 50\ \mathrm{rev/s}$（$3000\ \mathrm{rev/min}$），计数率为每秒$50 \times 10\,000 = 5.0\times10^{5}$个计数；每个通道的线频率为$50 \times 2500 = 125\ \mathrm{kHz}$。

合理性检查：微控制器的正交解码外设和驱动器输入能处理每秒数百万个计数，所以$0.5\ \mathrm{MHz}$绰绰有余——但电缆必须干净地传输$125\ \mathrm{kHz}$的方波，这就是工业编码器采用差分（RS-422）线驱动器的原因。$1\ \mathrm{\mu m}$的计数并不说明准确度：典型的精密滚珠丝杠的导程误差约为每$300\ \mathrm{mm}$ $10\ \mathrm{\mu m}$的量级。
:::
:::

### 速度测量

速度可以用**测速发电机**（一种小型直流发电机，其电压与转速成正比，$v = K\omega$）直接测量，但现在通常由编码器计算得到。有两种方法。

::: proposition 测速的计数法与周期法 {#prop-speed}
设编码器每转给出$n_e$个计数。

(a) **计数（频率）法**（M法）：在固定窗口$T$内对编码器边沿计数，得$m$。速度为$\omega = 2\pi m/(n_eT)$，其分辨力（一个计数对应的$\omega$的变化）为
$$
\Delta\omega = \frac{2\pi}{n_eT}\quad\text{（与速度无关）}.
$$ {#eq-count-method}
(b) **周期法**（T法）：在相邻两个编码器边沿之间对频率为$f_c$的高速时钟脉冲计数，得$q$。速度为$\omega = 2\pi f_c/(n_eq)$，其相对分辨力为
$$
\frac{\Delta\omega}{\omega} \approx \frac1q = \frac{n_e\,\omega}{2\pi f_c}\quad\text{（与速度成正比）}.
$$ {#eq-period-method}
:::

::: proof
(a) 在时间$T$内轴转过$m/n_e$转，即$2\pi m/n_e$弧度，故$\omega = 2\pi m/(n_eT)$；$m$是整数，它改变1使$\omega$改变$2\pi/(n_eT)$。(b) 相邻边沿之间的时间（一转的$1/n_e$）为$q/f_c$，故$\omega = (2\pi/n_e)/(q/f_c)$。$q$改变1使$\omega$改变的比例为$1/(q \mp 1) \approx 1/q$；代入$q = 2\pi f_c/(n_e\omega)$即得[[#eq-period-method]]的第二种形式。
:::

计数法在高速时好（每个窗口计数多），在低速时差；周期法正好相反，而且在极低速时必须等待很长时间才有下一个边沿。伺服驱动器把二者结合起来，例如在每个采样窗口内对最后一个边沿计时，并对结果滤波，因为对编码器信号作差分得到的信号噪声很大（[[mechatronics/motion-control]]）。

### 霍尔传感器

在半导体薄片中横穿磁场流动的电流，会在薄片两侧产生与磁场成正比的电压（霍尔效应）。霍尔传感器测量磁场，并借此测量磁铁的位置：它们在无刷电机中检测转子位置（[[mechatronics/electric-actuators]]），用作非接触开关和齿轮齿转速传感器，套在磁芯中的导体周围时还能非接触地测量电流。

## 应变、力与压强 {#sec-strain}

::: definition 灵敏系数 {#def-gauge-factor}
**应变片**是粘贴在零件表面、随零件一起伸长的细金属栅（箔式，通常厚几微米，带聚合物基底）。其电阻随沿栅方向的应变$\varepsilon$变化；**灵敏系数**（gauge factor）为
$$
GF = \frac{\Delta R/R}{\varepsilon}.
$$
金属箔式应变片（康铜，一种铜镍合金）的$GF \approx 2.0$–$2.1$，标称电阻为$120$、$350$或$1000\ \mathrm{\Omega}$；半导体（硅）应变片的灵敏系数约为$100$或更大，但受温度影响很大。
:::

::: proposition 灵敏系数的来源 {#prop-gauge-factor}
对电阻率为$\rho$、长度为$L$、横截面积为$A$的导体，在泊松比为$\nu$、单轴应变为$\varepsilon$时，
$$
GF = 1 + 2\nu + \frac{\Delta\rho/\rho}{\varepsilon} .
$$ {#eq-gauge-factor}
:::

::: proof
$R = \rho L/A$，故$\ln R = \ln\rho + \ln L - \ln A$，对微小变化有$\mathrm{d}R/R = \mathrm{d}\rho/\rho + \mathrm{d}L/L - \mathrm{d}A/A$。这里$\mathrm{d}L/L = \varepsilon$。每个横向的横向应变为$-\nu\varepsilon$，所以每个横向尺寸变为原来的$(1 - \nu\varepsilon)$倍，面积变为$(1 - \nu\varepsilon)^2 \approx 1 - 2\nu\varepsilon$倍：$\mathrm{d}A/A = -2\nu\varepsilon$。因此$\mathrm{d}R/R = \mathrm{d}\rho/\rho + \varepsilon(1 + 2\nu)$；除以$\varepsilon$即得[[#eq-gauge-factor]]。
:::

取$\nu = 0.3$，几何部分为$1.6$；金属应变片约为$2$的灵敏系数中其余部分来自电阻率随应变的变化（压阻效应），在半导体中压阻效应完全占主导。电阻变化极小：在$1000\ \mu\varepsilon$（应变$0.1\,\%$，对钢已是很大的工作应变）时，$350\ \mathrm{\Omega}$的应变片变化$0.7\ \mathrm{\Omega}$。它们用惠斯通电桥测量，电桥还能抵消温度的影响（[[mechatronics/signal-conditioning]]）。

**测力传感器**（load cell）是一个弹性元件——柱、梁、剪切腹板、圆环——其设计使力在贴片位置产生明确的应变，四个应变片接成全桥。它的设计是[[mechanics-of-materials]]的一个练习：贴片处应变大以获得灵敏度，其他地方应力低以保证疲劳寿命，并采用能抑制偏轴载荷的布置。

::: example 拉力测力传感器 {#ex-load-cell}
一根横截面积为$100\ \mathrm{mm^2}$的钢制拉杆（$E = 200\ \mathrm{GPa}$）沿轴线贴有一片$R = 350\ \mathrm{\Omega}$、$GF = 2.0$的应变片。求$10\ \mathrm{kN}$时应变片的电阻变化以及应力。
::: solution
$\sigma = F/A = 10\,000/(100\times10^{-6}) = 100\ \mathrm{MPa}$；$\varepsilon = \sigma/E = 100\times10^{6}/200\times10^{9} = 5.0\times10^{-4} = 500\ \mu\varepsilon$；$\Delta R = GF\,\varepsilon R = 2.0 \times 5.0\times10^{-4} \times 350 = 0.35\ \mathrm{\Omega}$。

合理性检查：$\Delta R/R = 0.1\,\%$。测力传感器通常按满量程$1000$–$1500\ \mu\varepsilon$设计，所以这根拉杆处于典型设计应变的约三分之一到一半；应力$100\ \mathrm{MPa}$只是优质钢疲劳强度的一个适度的分数，对一个要承受数百万次载荷的零件理应如此。
:::
:::

**压力传感器**采用薄膜片，用粘贴式或扩散式（硅）应变片、电容极板或谐振元件测量膜片的挠度或表面应变。传感器可测量**绝对**压强（相对于密封的真空基准）、**表压**（通过通气孔相对于大气）或两个接口之间的**差压**。

**压电式**传感器（石英或陶瓷）产生与力成正比的电荷，$q = dF$，石英的$d \approx 2.3\ \mathrm{pC/N}$。它们刚度极高、响应极快，非常适合冲击、切削力和燃烧压力的测量，但电荷会通过有限的绝缘电阻泄漏，所以不能测量静态力；其频率下限由读取它的电荷放大器的时间常数决定。

::: warning 表压、绝对压强——以及视应变
两种典型错误。(1) 混淆表压与绝对压强：表压读数为$0\ \mathrm{bar}$的传感器，其绝对压强约为$1.013\ \mathrm{bar}$，而气体定律的计算（[[mechatronics/fluid-power]]）需要绝对值。(2) 把温度读成应变：钢零件上的应变片在零件温度升高$10\ \mathrm{K}$时，由于应变片与零件热膨胀的失配以及合金的电阻温度系数，会出现电阻变化（**视应变**，apparent strain），对未与材料匹配的应变片可达几十微应变。应采用其合金已针对零件膨胀系数作了补偿的应变片（“温度自补偿”应变片），以及使相邻桥臂的相等变化相互抵消的电桥接法。
:::

## 温度 {#sec-temperature}

**热电偶。**两种不同金属的结点接在一个回路中，若回路另一结点处于不同温度，就会产生取决于温差的电压（塞贝克效应）。实际上，电压是沿导线在存在温度梯度的各处产生的，回路读出的是测量（“热”）端与热电偶导线接到仪表铜导线处（**参考端**或**冷端**）之间的差值。因此仪表必须测量冷端温度——用其接线端子处的热敏电阻或半导体传感器——并把它加回去：这就是**冷端补偿**。常用的K型（镍铬对镍铝）在室温附近约产生$41\ \mathrm{\mu V/K}$，可工作到约$1250\,^\circ\mathrm{C}$；完整的关系是非线性的，由标准分度表和多项式给出（IEC 60584-1、NIST ITS-90分度表）。热电偶便宜、坚固、小巧、量程宽；其信号小，准确度通常为$\pm 1$–$2\ \mathrm{K}$。

::: example 冷端补偿 {#ex-cjc}
一支K型热电偶在接线端子处于$20\,^\circ\mathrm{C}$的仪表上读数为$3.28\ \mathrm{mV}$。取恒定灵敏度$41\ \mathrm{\mu V/K}$，估算热端温度，并说明若不作补偿会怎样。
::: solution
该电压对应热端与冷端之间的温差$3.28\ \mathrm{mV}/(0.041\ \mathrm{mV/K}) = 80\ \mathrm{K}$，所以$T \approx 20 + 80 = 100\,^\circ\mathrm{C}$。若不作补偿，仪表会把读数当作相对于$0\,^\circ\mathrm{C}$的值，显示$80\,^\circ\mathrm{C}$，而且误差会随室温漂移。

用标准分度表作合理性检查：K型在$100\,^\circ\mathrm{C}$时为$4.096\ \mathrm{mV}$，在$20\,^\circ\mathrm{C}$时为$0.798\ \mathrm{mV}$（均相对于$0\,^\circ\mathrm{C}$）；二者之差$3.298\ \mathrm{mV}$按线性估算会读作$100.4\,^\circ\mathrm{C}$。用分度表的正确做法是把冷端**电压**（$0.798\ \mathrm{mV}$）加到读数上，再把和换算回温度——只有对线性特性，把温度相加才是精确的。
:::
:::

**热电阻（RTD）。**纯铂的电阻几乎随温度线性上升。标准工业元件Pt100在$0\,^\circ\mathrm{C}$时$R_0 = 100\ \mathrm{\Omega}$，在$0 \le T \le 850\,^\circ\mathrm{C}$范围内服从IEC 60751的卡伦德-范杜森（Callendar–Van Dusen）方程
$$
R(T) = R_0\left(1 + AT + BT^2\right),\qquad A = 3.9083\times10^{-3}\ ^\circ\mathrm{C}^{-1},\quad B = -5.775\times10^{-7}\ ^\circ\mathrm{C}^{-2},
$$ {#eq-cvd}
其中$T$以°C计（低于$0\,^\circ\mathrm{C}$时要再加一个三次项）。在$100\,^\circ\mathrm{C}$时Pt100的读数为$100(1 + 0.39083 - 0.005775) = 138.51\ \mathrm{\Omega}$，灵敏度约为$0.385\ \mathrm{\Omega/K}$。热电阻比热电偶更准确、更稳定（A级允差为$\pm(0.15 + 0.002\lvert T\rvert)\ \mathrm{K}$），但体积更大、响应更慢。有两种误差必须处理：引线电阻，这就是采用三线制和四线制接法的原因；以及测量电流引起的**自热**，$P = I^2R$，这就是把电流限制在约$1\ \mathrm{mA}$的原因。

**热敏电阻**是电阻随温度急剧下降的半导体陶瓷（NTC型），在室温下通常每开尔文下降约$4\,\%$。它们灵敏、便宜、小巧，但非线性很强；在有限范围内，“B值”模型$R = R_{25}\exp[B(1/T - 1/T_{25})]$（$T$以开尔文计）已足够，斯坦哈特-哈特（Steinhart–Hart）方程更准确。它们是消费品、电池组和3D打印机热端的常用选择。

| 传感器 | 典型量程 | 准确度（典型） | 优点 | 缺点 |
|---|---|---|---|---|
| 热电偶（K型） | $-200$至$1250\,^\circ\mathrm{C}$ | $\pm 1.5$–$2\ \mathrm{K}$ | 量程宽，坚固，细丝时响应快 | 信号小，需要冷端补偿 |
| Pt100热电阻 | $-200$至$850\,^\circ\mathrm{C}$ | $0\,^\circ\mathrm{C}$附近$\pm 0.15$–$0.3\ \mathrm{K}$ | 准确，稳定，近似线性 | 引线电阻，自热，较慢 |
| NTC热敏电阻 | $-50$至$150\,^\circ\mathrm{C}$ | $\pm 0.2$–$1\ \mathrm{K}$ | 灵敏度很高，便宜 | 非线性强，量程有限 |

::: quiz
电机上的1000线增量式编码器采用四倍频解码读取。控制器每转看到多少个计数？它如何知道方向？
- [ ] 1000个计数；由零位脉冲得知
- [ ] 2000个计数；由脉冲宽度得知
- [x] 4000个计数；由通道A和B中哪一个超前得知
- [ ] 4000个计数；由电压的符号得知
::: solution
每条线在两个通道上各产生一个上升沿和一个下降沿：每转$4 \times 1000 = 4000$个边沿。两个通道相差$90°$，所以在一个方向上$A$先于$B$变化，另一个方向上$B$先于$A$变化；解码器的状态机据此加计数或减计数。零位脉冲每转标记一次基准位置，不携带方向信息。
:::
:::

::: history
传感器所利用的许多效应早在用于控制之前很久就已被发现。托马斯·约翰·塞贝克（Thomas Johann Seebeck）于1821年报告了热电效应；皮埃尔·居里（Pierre Curie）和雅克·居里（Jacques Curie）于1880年发现了压电效应；埃德温·霍尔（Edwin Hall）于1879年发现了以他命名的效应；休·朗伯恩·卡伦德（Hugh Longbourne Callendar）关于铂电阻温度计的工作发表于1887年，奠定了精密电阻测温的基础。粘贴式电阻应变片于1938年被独立发明：麻省理工学院的阿瑟·C·鲁格（Arthur C. Ruge）在研究地震载荷时把细金属丝粘贴到模型结构上，而加州理工学院的爱德华·E·西蒙斯（Edward E. Simmons）已为冲击试验研制了类似的应变片；1942年专利授予西蒙斯，取代金属丝的腐蚀箔式应变片于20世纪50年代问世。贝尔实验室的弗兰克·格雷（Frank Gray）于1953年（1947年提交申请）取得了如今用于绝对式编码器的反射二进制码的专利，其用途是脉冲编码通信，而不是位置测量。
:::

::: summary
- 静态指标：量程、灵敏度、分辨力、准确度、非线性度（须说明参考直线）、迟滞、重复性和漂移。分辨力不等于准确度，反馈只能修正传感器看得到的误差。
- 集总热传感器是一阶的，$\tau = \rho cV/(hA)$；它对斜坡输入滞后$\tau\dot T$。其时间常数取决于周围的流动。
- 惯性式加速度计在共振以下测得$z \approx -a/\omega_n^2$；幅值比为$1/\sqrt{(1 - r^2)^2 + (2\zeta r)^2}$。轻阻尼把使用范围限制在约$r = 0.2$；$\zeta \approx 0.7$可将其扩展到约$0.6$。
- 增量式编码器每转给出$4N$个计数，由正交关系判别方向；绝对式编码器采用格雷码。测速可用计数法（高速时好）或计时法（低速时好）。
- 应变片：金属箔式的$GF = 1 + 2\nu + (\Delta\rho/\rho)/\varepsilon \approx 2$；$\Delta R/R$为$10^{-3}$量级，用电桥读取。
- 热电偶需要冷端补偿；Pt100热电阻服从$R_0(1 + AT + BT^2)$；热敏电阻灵敏但非线性。
:::

## 习题

::: exercise 编码器的角分辨力 {level=1 check="0.087890625"}
一个1024线增量式编码器采用四倍频解码读取。求其角分辨力。（以度为单位，填写精确值。）
::: solution
每转$4 \times 1024 = 4096$个计数；$360°/4096 = 0.087890625°$（$1.534\ \mathrm{mrad}$）。
:::
:::

::: exercise 应变片的电阻变化 {level=1 check="0.252"}
一片$120\ \mathrm{\Omega}$、$GF = 2.1$的应变片承受$1000\ \mu\varepsilon$的应变。求其电阻变化。（填写$\Delta R$，单位Ω。）
::: solution
$\Delta R = GF\,\varepsilon R = 2.1 \times 10^{-3} \times 120 = 0.252\ \mathrm{\Omega}$。
:::
:::

::: exercise 50 °C时的Pt100 {level=1 check="119.397125"}
用[[#eq-cvd]]求Pt100在$50\,^\circ\mathrm{C}$时的电阻。（填写$R$，单位Ω，至少保留四位小数。）
::: solution
$R = 100(1 + 3.9083\times10^{-3} \times 50 - 5.775\times10^{-7} \times 2500) = 100(1 + 0.195415 - 0.00144375) = 119.397125\ \mathrm{\Omega}$。采用平均系数$0.00385$的线性模型会得到$119.25\ \mathrm{\Omega}$，其误差约相当于$0.4\ \mathrm{K}$。
:::
:::

::: exercise 斜坡滞后 {level=1 check="10"}
一支时间常数为$2.5\ \mathrm{s}$的带套管温度探头测量温度以$4\ \mathrm{K/s}$稳定上升的油。启动瞬态过后，读数比油温滞后多少？（填写滞后量，单位K。）
::: solution
由[[#prop-thermal-tau]]，滞后为$\tau\dot T = 2.5 \times 4 = 10\ \mathrm{K}$。依据这个读数动作的控制器会认为油温比实际低$10\ \mathrm{K}$。
:::
:::

::: exercise 速度分辨力 {level=2 check="15"}
一个500线编码器采用四倍频解码读取，控制器在$2\ \mathrm{ms}$窗口内对边沿计数来计算速度。求速度分辨力。（以rev/min为单位填写。）
::: solution
每转计数$n_e = 2000$。$2\ \mathrm{ms}$内一个计数对应$1/(2000 \times 0.002) = 0.25\ \mathrm{rev/s} = 15\ \mathrm{rev/min}$。在$30\ \mathrm{rev/min}$时，读数会在$15$、$30$和$45\ \mathrm{rev/min}$之间跳变——若不采用周期法或更长的窗口，对低速控制毫无用处。
:::
:::

::: exercise 在过于接近共振处使用的加速度计 {level=2 check="4/3"}
一个共振频率为$10\ \mathrm{kHz}$的无阻尼加速度计（$\zeta \approx 0$）用于测量$5\ \mathrm{kHz}$的振动。它把加速度幅值夸大了多少倍？（填写倍数。）
::: solution
$r = 0.5$，由[[#eq-accel-ratio]]，比值为$1/(1 - 0.25) = 4/3$：读数偏高$33\,\%$。对无阻尼传感器，要使误差低于$5\,\%$，应使$r$保持在约$0.2$以下。
:::
:::

::: exercise 端点非线性度 {level=2 check="1"}
一个量程为$0$–$20\ \mathrm{mm}$的位移传感器在$0$、$5$、$10$、$15$和$20\ \mathrm{mm}$时分别输出$0$、$1.03$、$2.04$、$3.02$和$4.00\ \mathrm{V}$。求端点非线性度。（以满量程的百分数填写。）
::: solution
端点斜率$4.00/20 = 0.200\ \mathrm{V/mm}$，预测值为$1.00$、$2.00$、$3.00\ \mathrm{V}$。偏差为$0.03$、$0.04$、$0.02\ \mathrm{V}$；最大偏差$0.04\ \mathrm{V}$是$4.00\ \mathrm{V}$跨度的$1\,\%$。
:::
:::

::: exercise 硅中的压阻效应 {level=2 check="118.4"}
一片硅应变片的$GF = 120$，$\nu = 0.3$。用[[#eq-gauge-factor]]求电阻率变化的贡献$(\Delta\rho/\rho)/\varepsilon$。（填写数值。）
::: solution
$(\Delta\rho/\rho)/\varepsilon = GF - 1 - 2\nu = 120 - 1.6 = 118.4$。几何效应只贡献响应的约$1.3\,\%$；其余都是压阻效应。
:::
:::

::: exercise 测量液压缸的位置 {level=3}
一台林业机械上行程为$400\ \mathrm{mm}$的液压缸需要精度为$\pm 0.5\ \mathrm{mm}$的位置反馈，工作环境有振动、泥浆、喷水，温度为$-30$至$+80\,^\circ\mathrm{C}$。对照这些要求比较至少三种传感器方案（例如外置电位器、拉线编码器、LVDT、装在活塞杆内的磁致伸缩传感器、摄像头），并推荐一种。
::: solution
好的回答应考虑：分辨力和准确度（$400\ \mathrm{mm}$上的$0.5\ \mathrm{mm}$为$0.125\,\%$ FS——所有非接触方案都能达到）；绝对式还是增量式（优先选绝对式：断电后无需回零）；防护（装在缸内的传感器，如装在深孔钻削的活塞杆中的磁致伸缩位置传感器或LVDT，能免受撞击和污物；外置电位器或拉线编码器则暴露在外）；磨损（电位器会因振动引起的持续微小运动而磨损）；温度范围与密封；电气接口（模拟$4$–$20\ \mathrm{mA}$在长电缆上稳健，CAN或SSI数字接口在行走机械上很常见）；以及成本与可维修性。典型的推荐是带数字或电流环输出的缸内磁致伸缩传感器，代价是需要一个活塞杆带孔的专用液压缸；摄像头不适合泥浆和振动环境。
:::
