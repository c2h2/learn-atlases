几乎每一种机电产品中的控制器都是一片**微控制器**：一台完整的小型计算机——处理器、程序存储器、数据存储器以及一组用于定时、输入和输出的外设——集成在一块芯片上，价格从几毛钱到几欧元不等。它读取开关和转换器、对编码器脉冲计数、计算控制律，并用脉宽调制信号驱动晶体管，所有这些都在一个程序的控制之下完成，而这个程序不仅要算出正确的结果，还必须**按时**算出。一个运行滞后的控制回路，实际上就是一个附加了延迟的回路，而延迟正是使反馈系统失稳的因素。

本章是为需要选定控制器、并与编程人员合作——或自己编程——的工程师写的。内容包括微控制器的体系结构、数的表示方法、数字输入与输出、定时器与脉宽调制、中断、实时调度、数字PID控制器的实现以及串行通信。采样数据控制的理论见[[control-systems/digital-control]]；这里讨论的是芯片内部发生的事情。

## 体系结构 {#sec-architecture}

::: definition 微控制器 {#def-mcu}
**微控制器**（MCU，俗称单片机）在一块芯片上集成了：
1. 取指并执行指令的**中央处理器**（CPU），字长为8、16或32位，时钟频率从几兆赫到几百兆赫；
2. 非易失性**程序存储器**（闪存，通常为$16\ \mathrm{kB}$到几MB），断电后仍保存程序；
3. 易失性**数据存储器**（SRAM，通常为$2\ \mathrm{kB}$到$1\ \mathrm{MB}$），用于变量和堆栈；
4. **外设**：通用输入/输出引脚（GPIO），具有捕获、比较和PWM功能的定时器/计数器，模数（有时还有数模）转换器，编码器接口，串行接口（UART、SPI、I²C、CAN、USB、以太网），看门狗定时器，以及无需CPU参与即可在外设与存储器之间传送数据的直接存储器访问（DMA）控制器；
5. **中断控制器**，使外设事件能够暂停正在运行的程序并启动一个处理程序。
:::

与之相对，**微处理器**是一个需要外部存储器和外设的CPU；台式计算机或单板Linux计算机就是以微处理器为核心构建的。微控制器以原始速度换取集成度、低功耗、确定性的时序和坚固性，而这正是嵌入式控制所需要的。大多数微控制器内部是**哈佛**结构，指令和数据使用分开的总线，因此二者可以在一个周期内同时取出。当前的32位微控制器以基于ARM Cortex-M系列的内核为主；8位器件（AVR、PIC、8051衍生型号）在简单、对成本敏感的产品中仍很常见，RISC-V内核的使用也日益增多。有些内核带有硬件**浮点运算单元**（FPU），这对控制代码影响很大（见下文）。

外设通过**寄存器**控制：寄存器是一些存储单元，其各位用于配置硬件（把一个引脚设为输出、选择定时器的时钟）或反映硬件的状态（一次转换已完成、一个字节已到达）。程序像读写变量一样读写它们。厂商提供把寄存器访问封装成函数的库，但只有理解了寄存器，才能读懂数据手册并知道硬件能做什么。

## 微控制器中的数 {#sec-numbers}

整数存储在$n$位的二进制字中。**无符号**整数的范围是$0$到$2^n - 1$；**有符号**整数采用**二进制补码**，范围是$-2^{n-1}$到$2^{n-1} - 1$，$x$的相反数通过把所有位取反再加一得到。运算是模$2^n$的：最大值加$1$会回绕到最小值。这种**溢出**是无声的——不报任何错误——嵌入式控制中相当大一部分错误都源于此。

实数可以用**浮点数**（IEEE 754单精度：24位尾数，约七位有效数字）或**定点数**表示。

::: definition 定点（Q）格式 {#def-q-format}
在**Q$m$.$f$**格式中，有符号整数字$n$表示实数$x = n/2^f$，其中$f$位为小数位，$m$位（加上符号位）为整数位。广泛使用的**Q15**格式在16位字中存储$[-1, 1)$内的数：$x = n/32\,768$，分辨率为$2^{-15} \approx 3.05\times10^{-5}$。同一格式的两个数相加就是整数相加；两个Q15数的乘积是32位字中的Q30数，通过算术右移15位转换回Q15。
:::

定点运算在没有FPU的内核上速度很快，但程序员必须跟踪每个变量的比例因子并防止溢出，通常采用**饱和**运算，即把结果钳位在可表示范围内而不是回绕。在带FPU的内核上，单精度浮点数如今是控制律的常规选择；它消除了大多数比例因子错误，但也带来了它自己的问题：把一个小增量加到一个大累加器上（长时间运行后的积分器，或以秒计的上电后时间），一旦二者之比超过约$10^7$，这个增量就会丢失。

::: example 定点运算与溢出 {#ex-q15}
用Q15计算(a) $0.5 \times 0.25$和(b) $0.75 + 0.5$，写出所涉及的整数，并说明饱和在(b)中起什么作用。
::: solution
(a) $0.5 \to 16\,384$，$0.25 \to 8192$。整数乘积$16\,384 \times 8192 = 134\,217\,728$（一个Q30值，需要32位）。右移15位：$134\,217\,728/32\,768 = 4096$，它表示$4096/32\,768 = 0.125$。结果正确。

(b) $0.75 \to 24\,576$，$0.5 \to 16\,384$，和为$40\,960$，超过了16位有符号数的最大值$32\,767$。在二进制补码中它回绕为$40\,960 - 65\,536 = -24\,576$，表示$-0.75$：两个正数之和变成了负数。发生这种情况的控制输出会把执行器从接近正向满量程猛然打到很大的负值。饱和加法则返回$32\,767$（$\approx 0.99997$）——虽然不对，但方向正确且有界。

合理性检查：真实结果$1.25$超出了Q15的范围$[-1, 1)$，所以任何Q15答案都不可能正确；设计上的解决办法是为这个变量选择带整数位的格式（例如Q2.13），对信号范围作比例分析本应发现这一点。
:::
:::

回绕并不总是敌人。硬件计数器——编码器计数器、自由运行的定时器——连续回绕，只要两次读数之间发生的计数少于$2^n$个，用无符号模运算求得的两次读数之**差**就是正确的。如果一个16位编码器计数器先读到$65\,530$，然后读到$4$，运动量就是$(4 - 65\,530) \bmod 65\,536 = 10$个计数（正向）。把差值存入16位有符号变量还能给出方向，前提是两次读数之间经过的计数少于$32\,768$个。

## 数字输入与输出 {#sec-gpio}

配置为**输出**的GPIO引脚由一对晶体管驱动到电源电压（逻辑1，例如$3.3\ \mathrm{V}$）或地（逻辑0），能输出或吸入几毫安电流——足以驱动LED或晶体管的栅极，但绝不能驱动电机、继电器或电磁铁（[[mechatronics/mechatronic-systems#prop-flyback]]）。在**开漏**模式下只使用低边晶体管，使几个输出可以共用一根由电阻上拉的线（如I²C中那样）。配置为**输入**的引脚把高于某一阈值（通常为$0.7V_{DD}$）的电压读作1，把低于另一阈值（$0.3V_{DD}$）的电压读作0；介于二者之间时读数不确定，而悬空的输入会浮动并随机读数，所以来自开关的输入要使用**上拉**或**下拉**电阻（通常已内置）。

机械开关会**抖动**：触点在稳定之前，会在几毫秒内闭合又断开若干次。对边沿计数的程序会把每次抖动都计进去。消抖在硬件上用RC滤波器和施密特触发器输入完成，在软件上则是：每隔一毫秒左右读取一次，只有新状态在连续几次读数中保持稳定后才予以接受。

来自机器的输入（限位开关、工业实践中$24\ \mathrm{V}$的接近传感器）从不直接连接：它们要经过分压器、钳位电路，或者——最好是——**光耦合器**，光耦以光的形式跨越绝缘屏障传送信号，从而保护微控制器免受现场接线中噪声很大、偶尔具有破坏性的电压的影响。

## 定时器与脉宽调制 {#sec-timers}

**定时器**是一个由时钟递增的计数器。它的时钟是外设时钟$f_{\text{clk}}$除以**预分频**系数$P + 1$；计数器从$0$计到**自动重装载**寄存器中保存的值$A$，然后从$0$重新开始，并产生一个**更新事件**（它可以触发中断或ADC转换）。**比较**寄存器$C$使输出引脚在计数器经过$C$时改变状态；**捕获**寄存器在输入引脚变化时记录计数器的值，脉冲周期和宽度就是这样测量的。

::: proposition 定时器周期与PWM {#prop-timer}
时钟为$f_{\text{clk}}$、预分频设定为$P$、自动重装载值为$A$的定时器，产生更新事件的频率为
$$
f_{\text{upd}} = \frac{f_{\text{clk}}}{(P + 1)(A + 1)} .
$$ {#eq-timer}
在边沿对齐PWM模式下，计数器低于比较值$C$时输出为高电平，输出是频率为$f_{\text{upd}}$、占空比为$D = C/(A + 1)$的矩形波，占空比可按$A + 1$级调节。通过开关从电源$V_s$施加到负载上，它给出的平均电压为
$$
\bar v = DV_s .
$$ {#eq-pwm-average}
:::

::: proof
计数器每$(P + 1)$个时钟周期前进一次，在重新开始之前经历$A + 1$个值$0, 1, \dots, A$，所以一个周期持续$(P + 1)(A + 1)/f_{\text{clk}}$，这就是[[#eq-timer]]。在$A + 1$个计数值中，输出在$C$个值$0, \dots, C - 1$上为高电平，因此$D = C/(A + 1)$，$C$可以取$0$到$A + 1$的整数值。在时间$DT$内等于$V_s$、在$(1 - D)T$内等于$0$的波形，其平均值为$\frac1T\int_0^T v\,\mathrm{d}t = \frac1T V_sDT = DV_s$。
:::

**PWM**是数字控制器高效地产生“模拟”输出的方法。开关要么完全导通（其两端电压很小），要么完全关断（没有电流），所以它耗散的功率很小；负载——其电感使电流平滑的电机绕组，或其热容使温度平滑的加热器——响应的是平均值（[[mechatronics/electric-actuators]]）。设计上要在频率与分辨率之间权衡：对给定的时钟，提高$f_{\text{PWM}}$会减少级数$A + 1$。电机驱动器采用$15$–$30\ \mathrm{kHz}$，高于可听范围，且比绕组的电气时间常数快；加热器采用几赫兹。

::: example 配置控制回路定时器和PWM输出 {#ex-timer}
一个微控制器的定时器由$72\ \mathrm{MHz}$时钟驱动。(a) 配置一个定时器，使其为控制回路恰好以$1\ \mathrm{kHz}$产生中断。(b) 以尽可能高的分辨率配置一个$20\ \mathrm{kHz}$的PWM输出，并以级数和位数给出分辨率。(c) 由$24\ \mathrm{V}$电源得到$9.0\ \mathrm{V}$平均电压，占空比寄存器应取何值？
::: solution
(a) $(P + 1)(A + 1) = 72\times10^{6}/1000 = 72\,000$。对于16位自动重装载寄存器（$A \le 65\,535$），选$P = 71$（定时器时钟$1\ \mathrm{MHz}$），$A = 999$。

(b) 最高分辨率意味着$P = 0$：$A + 1 = 72\times10^{6}/20\,000 = 3600$，故$A = 3599$；占空比有$3600$级，$\log_2 3600 = 11.8$位，每级$1/3600 = 0.028\,\%$。

(c) $D = 9.0/24 = 0.375$，$C = 0.375 \times 3600 = 1350$。

合理性检查：$1\ \mathrm{ms}$的回路周期包含$20$个PWM周期，所以回路输出的变化相对于PWM是平滑的，理应如此。有些定时器提供中心对齐PWM（先加计数再减计数），在相同$A$下频率减半，但脉冲中心位于周期中的固定点，便于在脉冲中点对电机电流采样。
:::
:::

## 中断与实时运行 {#sec-realtime}

程序可以通过**轮询**（在循环中反复检查一个标志）或**中断**得知一个事件：外设向中断控制器发出信号，CPU执行完当前指令，保存其状态，运行**中断服务程序**（ISR），之后返回原处。从事件发生到ISR第一条指令之间的时间是**中断延迟**——在Cortex-M内核上，如果没有更高优先级的中断正在运行，只需十几个时钟周期，即远小于一微秒。中断有优先级，较高优先级的中断可以抢占较低优先级的中断。

因此，小型运动控制器的标准结构是：一个以控制频率运行的定时器中断（最高优先级的软件任务）读取传感器、计算控制律并写出输出；较低优先级的中断处理通信；主循环处理所有非时间关键的事务（用户界面、日志、诊断）。有两条规则保证它正常工作。ISR必须简短——算完就退出；在ISR与主循环之间共享的变量必须声明为`volatile`，并以不会被中途打断的方式访问（原子访问，或关闭中断的短暂临界区），否则主循环可能读到一半旧一半新的值。

::: definition 周期任务、利用率与抖动 {#def-utilisation}
**周期任务**$i$每隔$T_i$秒释放一次，最多需要$C_i$秒的处理器时间（其**最坏情况执行时间**）才能完成，截止期限为$T_i$。由$n$个任务组成的任务集的处理器**利用率**为
$$
U = \sum_{i=1}^{n}\frac{C_i}{T_i} .
$$ {#eq-utilisation}
**抖动**是任务的实际开始（或输出）时刻相对于其理想周期调度的偏差。
:::

::: proposition 可调度性的必要条件 {#prop-utilisation}
对于$U > 1$的周期任务集，单处理器上的任何调度策略都不能满足其全部截止期限。
:::

::: proof
考虑区间$[0, L]$，$L$为各周期的最小公倍数（假定周期为有理数）。任务$i$在其中释放$L/T_i$次，每次需要$C_i$，总需求为$\sum_i (L/T_i)C_i = LU$。在$[0, L]$内释放的每个作业，其截止期限都在$L$或$L$之前，所以所有这些工作必须在$[0, L]$内完成，而在此区间内处理器最多能提供$L$秒的执行时间。若$U > 1$，需求超过供给，必有某个截止期限被错过。
:::

对每一种策略来说，其逆命题并不成立。在**单调速率**调度下——固定优先级，周期最短的任务优先级最高，这正是把最快的中断设为最高优先级时自然得到的结果——刘炯朗（Liu）和莱兰（Layland）（1973年）证明：截止期限等于周期的$n$个独立周期任务组成的任务集，若满足
$$
U \le n\left(2^{1/n} - 1\right),
$$ {#eq-liu-layland}
则总能满足其截止期限。这个界对一个任务为$1$，两个任务为$0.828$，三个任务为$0.780$，任务很多时趋于$\ln 2 = 0.693$。超过该界的任务集仍可能是可调度的，这可以通过计算每个任务的最坏情况响应时间来检验。实践中，设计者使利用率远低于该界，为不可避免的执行时间低估留出余量。

::: example 检验一个任务集 {#ex-rms}
一个电机控制器有三个周期任务：电流控制每$0.1\ \mathrm{ms}$一次，最多耗时$25\ \mathrm{\mu s}$；位置和速度控制每$1\ \mathrm{ms}$一次，最多耗时$200\ \mathrm{\mu s}$；通信每$10\ \mathrm{ms}$一次，最多耗时$1\ \mathrm{ms}$。按刘-莱兰判据，该任务集在单调速率优先级下是否可调度？
::: solution
$U = 25/100 + 200/1000 + 1/10 = 0.25 + 0.20 + 0.10 = 0.55$。三个任务的界为$3(2^{1/3} - 1) = 0.780$。由于$0.55 \le 0.780$，所有截止期限都能满足。电流回路以最高优先级运行，位置回路其次，通信最后。

合理性检查：最慢任务的最坏情况可以直接估算。在$10\ \mathrm{ms}$内，两个较快的任务消耗$100 \times 25\ \mathrm{\mu s} + 10 \times 200\ \mathrm{\mu s} = 4.5\ \mathrm{ms}$，为$1\ \mathrm{ms}$的通信任务留下$5.5\ \mathrm{ms}$——绰绰有余。位置任务被电流任务抢占，其$200\ \mathrm{\mu s}$被拉长约四分之一，达到约$275\ \mathrm{\mu s}$，这在其周期内表现为输出抖动：这就是快速回路在固定时刻（例如在下一个定时器事件时）写出输出，而不是在计算恰好完成时写出的原因。
:::
:::

## 数字控制器的实现 {#sec-digital-pid}

连续PID控制器$u = K_pe + K_i\int e\,\mathrm{d}t + K_d\,\mathrm{d}e/\mathrm{d}t$（[[control-systems/pid-control]]）在采样时刻$t_k = kT$实现时，用累加和近似积分，用差分近似导数：
$$
I_k = I_{k-1} + K_iT\,e_k,\qquad u_k = K_pe_k + I_k - \frac{K_d}{T}\left(y_k - y_{k-1}\right).
$$ {#eq-discrete-pid}
有三个细节把能工作的实现与教科书公式区分开来。

1. **对测量值求微分。**微分项作用于$-y$而不是$e = r - y$，使参考输入的阶跃不会产生巨大的尖峰（“微分冲击”）；并且对它作低通滤波，因为对量化的、含噪声的信号作差分会把噪声放大约$1/T$倍。
2. **抗积分饱和。**当执行器饱和（PWM处于$100\,\%$）时，误差持续存在，积分器不断增大；当误差最终反向时，过大的积分值使执行器在本应退出饱和之后很久仍保持饱和，从而产生很大的超调。最简单的解决办法是：只要输出朝着会加剧饱和的方向饱和，就停止积分（或钳位$I_k$）。
3. **定时。**采样时刻和输出时刻必须规则。采样回路的表现近似于一个附加了延迟的连续回路：零阶保持器贡献约$T/2$，如果输出在下一个采样时刻写出，计算再贡献$T$。在穿越频率$\omega_c$处，延迟$\tau_d$会使相角裕度减少$\omega_c\tau_d$弧度。

::: example 数字PI控制器的两步计算 {#ex-pi-steps}
一个PI速度控制器的$K_p = 2.0\ \mathrm{V\,s/rad}$，$K_i = 10\ \mathrm{V/rad}$，$T = 10\ \mathrm{ms}$，$I_{-1} = 0$。前两个采样的速度误差为$e_0 = 1.0$和$e_1 = 0.8\ \mathrm{rad/s}$。计算$u_0$和$u_1$。然后估算在一个以$1\ \mathrm{kHz}$采样、输出在测量后一个采样周期写出的回路中，穿越频率$40\ \mathrm{Hz}$处损失的相角。
::: solution
$K_iT = 0.10\ \mathrm{V\,s/rad}$。第0步：$I_0 = 0 + 0.10 \times 1.0 = 0.10\ \mathrm{V}$，$u_0 = 2.0 \times 1.0 + 0.10 = 2.10\ \mathrm{V}$。第1步：$I_1 = 0.10 + 0.10 \times 0.8 = 0.18\ \mathrm{V}$，$u_1 = 2.0 \times 0.8 + 0.18 = 1.78\ \mathrm{V}$。

延迟：保持器$T/2$加上一个采样周期的计算，$1.5T = 1.5\ \mathrm{ms}$。损失的相角$= 360° \times f_c \times \tau_d = 360 \times 40 \times 0.0015 = 21.6°$，其中保持器占$7.2°$，计算延迟占$14.4°$。

合理性检查：典型的相角裕度为$45°$–$60°$；损失$22°$是很严重的，这就是快速回路要以穿越频率许多倍的频率采样、以及在采样后立即计算输出（而不是晚一个完整周期）值得花力气的原因。
:::
:::

::: warning 浮点时间、整数溢出与阻塞代码
嵌入式控制代码中反复出现三类错误。(1) 用单精度`float`以秒为单位记录时间：约$4.6$小时（$2^{14}\ \mathrm{s}$）之后，浮点数的分辨率超过$1\ \mathrm{ms}$，加到它上面的$1\ \mathrm{ms}$时间步长会被舍入——由时间差计算的微分项和积分项就会出错。应改为用无符号整数计时钟节拍数并取差值。(2) 中间结果的整数溢出：两个16位值的乘积需要32位，而32位微秒计数器约$71.6$分钟就会回绕；要使用足够宽的类型和模差值。(3) 在ISR或控制任务中使用阻塞调用——在循环中等待串行发送或调用延时函数；这样回路的时序就取决于程序所做的其他一切。要实测真实的执行时间和抖动（在任务开始和结束时翻转一个引脚，用示波器观察），而不是假定它们。
:::

## 通信 {#sec-comms}

微控制器通过串行链路与传感器、驱动器以及彼此通信：

- **UART**（异步串行）：起始位、$8$个数据位、停止位——每字节$10$个位时间；在$115\,200\ \mathrm{bit/s}$时一个字节需要$86.8\ \mathrm{\mu s}$。点对点；RS-232和RS-485规定了电压，RS-485还规定了工业中使用的差分多点总线（例如配合Modbus协议）。
- **SPI**：同步，一根时钟线、一根数据输入线、一根数据输出线，每个器件一根片选线；在电路板上短距离传输时速率达每秒几十兆位——是连接高速ADC、编码器和驱动器的常用链路。
- **I²C**：两根开漏线（时钟和数据），器件按地址寻址；$100\ \mathrm{kbit/s}$–$1\ \mathrm{Mbit/s}$；用于板上的低速传感器和存储器。
- **CAN**（控制器局域网）：差分双线总线，报文优先级逐位仲裁（标识符最小者胜出，且不破坏另一报文），具有内置的错误检测和自动重发；经典形式下最高$1\ \mathrm{Mbit/s}$（CAN FD中更高）。它是汽车和许多机器的标准网络。一个携带$8$个数据字节的经典帧约长$110$位，所以$1\ \mathrm{Mbit/s}$的总线每秒约能传输$9000$个这样的帧。
- **工业以太网**的各种变体（EtherCAT、PROFINET、Ethernet/IP）在控制器与驱动器之间提供同步的、确定性的通信，周期可短至几十微秒。

选择取决于距离、噪声、数据速率，以及——对控制而言——链路的**延迟和确定性**：通过网络闭合的反馈回路会继承网络的延迟及其抖动。

::: quiz
一个控制任务以$5\ \mathrm{kHz}$运行，其中断服务程序耗时$60\ \mathrm{\mu s}$。它占用处理器的多大比例？
- [ ] $6\,\%$
- [ ] $12\,\%$
- [x] $30\,\%$
- [ ] $60\,\%$
::: solution
周期为$200\ \mathrm{\mu s}$，所以$U = 60/200 = 0.30$。把回路频率加倍将占用$60\,\%$——控制频率与处理器能力直接此消彼长，除非让代码更快（FPU、定点运算、用DMA传送数据）。
:::

::: history
1971年的英特尔4004由费德里科·法金（Federico Faggin）、特德·霍夫（Ted Hoff）、斯坦利·梅泽尔（Stanley Mazor）和岛正利（Masatoshi Shima）为Busicom计算器设计，它把一个4位CPU集成在一块芯片上，但需要单独的存储器和I/O芯片。在德州仪器，加里·布恩（Gary Boone）和迈克尔·科克伦（Michael Cochran）于1971年设计了一种片上带有存储器和I/O的单片计算机，德州仪器于1974年以TMS1000系列将其商品化，用于计算器、玩具和家用电器——它通常被视为第一个微控制器。随后是英特尔的8048（1976年）和8051（1980年）；8051架构至今仍在生产。1973年，刘炯朗（C. L. Liu）和詹姆斯·莱兰（James Layland）发表了单调速率调度的分析，它是实时操作系统的基础。ARM于2004年推出的Cortex-M3内核，开启了嵌入式控制向具有快速、确定性中断处理能力的32位处理器的转变。
:::

::: summary
- 微控制器在一块芯片上集成了CPU、闪存、SRAM和外设（GPIO、定时器、ADC、串行接口、DMA、中断）；外设通过寄存器配置。
- 整数溢出时无声回绕；定点Q格式需要比例分析和饱和处理；浮点数会丢失加到大数上的小增量。用模运算求计数器差值是正确的。
- GPIO引脚只能驱动毫安级电流；输入需要上拉、消抖，来自现场接线的输入还需要隔离。
- 定时器频率$f_{\text{clk}}/[(P + 1)(A + 1)]$；PWM占空比$C/(A + 1)$，平均值$DV_s$；频率与分辨率相互制约。
- 利用率$U = \sum C_i/T_i \le 1$是必要条件；单调速率优先级在$U \le n(2^{1/n} - 1)$时保证满足截止期限。
- 数字PID：带抗积分饱和的累加和积分、对测量值求微分并滤波、规则的定时；采样和计算附加约$1.5T$的延迟，使相角裕度损失$\omega_c\tau_d$。
- 串行链路（UART、SPI、I²C、CAN、工业以太网）根据距离、噪声、速率、延迟和确定性来选择。
:::

## 习题

::: exercise 定时器重装载值 {level=1 check="1999"}
一个定时器的时钟为$48\ \mathrm{MHz}$，预分频设定$P = 47$。求使更新事件频率为$500\ \mathrm{Hz}$的自动重装载值$A$。（填写$A$。）
::: solution
$(A + 1) = 48\times10^{6}/(48 \times 500) = 2000$，故$A = 1999$。
:::
:::

::: exercise PWM级数 {level=1 check="4000"}
一个时钟为$100\ \mathrm{MHz}$、不分频的定时器产生$25\ \mathrm{kHz}$的PWM。占空比有多少级可用？（填写级数。）
::: solution
$A + 1 = 10^{8}/25\,000 = 4000$级，约$12$位，每级$0.025\,\%$。
:::
:::

::: exercise PWM平均电压 {level=1 check="8.4"}
$24\ \mathrm{V}$电源以占空比$0.35$开关供电给一台电机。求平均电压。（以V为单位填写。）
::: solution
$\bar v = DV_s = 0.35 \times 24 = 8.4\ \mathrm{V}$。
:::
:::

::: exercise 一个Q15常数 {level=1 check="-12288"}
求在Q15中表示$-0.375$的16位整数。（填写该整数。）
::: solution
$n = -0.375 \times 32\,768 = -12\,288$。用十六进制二进制补码表示为`0xD000`。
:::
:::

::: exercise 计数器回绕 {level=2 check="836"}
一个16位无符号编码器计数器在某次采样时读数为$65\,000$，下一次为$300$；已知该轴缓慢正向运动。它移动了多少个计数？（填写计数个数。）
::: solution
$(300 - 65\,000) \bmod 65\,536 = 300 + 65\,536 - 65\,000 = 836$个计数。16位无符号减法直接给出这一结果。
:::
:::

::: exercise 中断负荷 {level=2 check="24"}
一个耗时$12\ \mathrm{\mu s}$的ISR以$20\ \mathrm{kHz}$运行。求处理器负荷。（以%为单位填写。）
::: solution
周期$50\ \mathrm{\mu s}$；$U = 12/50 = 0.24 = 24\,\%$。
:::
:::

::: exercise 任务集的利用率 {level=2 check="17/30"}
三个任务的$(C_i, T_i)$分别为$(2, 10)$、$(3, 15)$和$(5, 30)$毫秒。求其利用率，并判断刘-莱兰判据能否保证单调速率可调度。（以精确分数填写$U$。）
::: solution
$U = 0.2 + 0.2 + 1/6 = 17/30 = 0.567 \le 0.780$：按此充分判据可调度。
:::

::: exercise 零阶保持器造成的相角损失 {level=2 check="9"}
一个每$0.5\ \mathrm{ms}$采样一次的回路，穿越频率为$100\ \mathrm{Hz}$。取零阶保持器的等效延迟为$T/2$，求它在穿越频率处附加的相位滞后。（以度为单位填写。）
::: solution
$360° \times 100 \times 0.25\times10^{-3} = 9°$。如果输出还要在测量后整整一个采样周期才写出，再加$18°$。
:::

::: exercise 直流电机速度控制器的固件 {level=3}
概述一个微控制器的固件，它根据增量式编码器控制有刷直流电机的速度，配有PWM H桥、用于保护的电流检测输入、接收速度指令的CAN接口和一个状态LED。说明各定时器和中断及其频率和优先级、它们之间共享的数据及其保护方法、测速方法、控制器及其抗积分饱和措施，以及故障处理（指令丢失、过电流、编码器故障）。
::: solution
好的回答：(i) 硬件PWM定时器工作在$20\ \mathrm{kHz}$，其更新事件通过DMA在脉冲中点触发电流ADC转换；过电流比较器接到定时器的硬件刹车输入，使电桥在没有软件参与的情况下被禁止。(ii) 一个$1\ \mathrm{kHz}$的控制定时器中断（最高软件优先级），读取编码器计数器，用模差值计算速度（低速时采用周期计时，[[mechatronics/sensors#prop-speed]]），运行带钳位抗积分饱和和输出限幅的PI控制器，并写入比较寄存器。(iii) 一个CAN接收中断（较低优先级），把速度指令复制到一个共享变量中，以原子方式写入（32位内核上的32位对齐字）并加时间戳。(iv) 主循环处理LED、诊断和指令超时：如果在比如$100\ \mathrm{ms}$内没有收到指令，就使速度斜坡降到零。(v) 编码器故障：如果PWM很高但在一段时间内没有计数，就报故障并禁止输出。(vi) 由控制任务刷新的看门狗定时器，使程序挂死时控制器复位到安全的禁止状态。(vii) 用一个空闲引脚和示波器实测利用率和最坏情况时序。
:::
