电动机是机电系统的肌肉。它们带动打印机小车、机器人关节、相机镜头、汽车车窗和机床主轴，而且在各处受青睐的理由都相同：电能易于分配和开关，电机高效而清洁，其转矩与一个功率电子装置能在微秒级内控制的电流成正比。设计问题也总是相同的：需要多大转矩、在什么转速下？电机在控制器看来是什么样子——它的传递函数是什么？它应该怎样通过传动与负载相连？选哪一类电机、哪一种驱动器？

本章针对机电系统中使用的三类电机回答这些问题：**有刷直流电机**，其简单模型是所有其他电机的参照；**步进电机**，通过计数步数进行开环定位；以及**无刷（永磁同步）电机**，它在伺服驱动、无人机和电动汽车中占主导地位。本章还讨论为它们供电的H桥驱动器、传动比与惯量匹配，以及按工作循环选定电机。电机在电气工程中有深入研究；这里把电机当作一个具有模型和数据手册的元件来处理。

## 有刷直流电机 {#sec-dc-motor}

有刷直流电机有一个静止的磁场——在机电系统的小型电机中由永磁体产生——和一个旋转的**电枢**绕组，电枢绕组通过机械**换向器**和碳质或贵金属**电刷**供电。当每个电枢线圈从一个磁极下方转到下一个磁极下方时，换向器使其中的电流反向，因此作用在导体上的力始终使转子朝同一方向转动。支配它的是两条物理定律：磁场中载有电流$i$的导体受到力的作用（每根导体$F = Bli$），在磁场中运动的导体中感应出电压（$e = Blv$）。对所有导体求和，就得到电机的两个方程。

::: definition 直流电机常数 {#def-motor-constants}
对于电枢电流为$i$、轴转速为$\omega$的永磁直流电机：
- 电磁转矩为$T = K_t\,i$，**转矩常数**$K_t$的单位为$\mathrm{N\,m/A}$；
- 电枢中感应的**反电动势**为$e = K_e\,\omega$，**反电动势（速度）常数**$K_e$的单位为$\mathrm{V\,s/rad}$。

电枢电路的电阻为$R$（绕组和电刷），电感为$L$。转子绕其轴线的转动惯量为$J_m$。
:::

::: proposition 转矩常数与反电动势常数相等 {#prop-kt-ke}
在一致的SI单位制中，$K_t = K_e$；共同的值记为$K$。数据手册常以每$1000\ \mathrm{rev/min}$的伏数给出反电动势常数，必须加以换算（$1\ \mathrm{V/krpm} = 9.549\times10^{-3}\ \mathrm{V\,s/rad}$）。
:::

::: proof
反电动势吸收的电功率$ei$就是由电能转换为机械能的功率；它必须等于电磁转矩所发出的机械功率$T\omega$，因为能量转换本身既不储存也不耗散能量（损耗发生在$R$中、摩擦中和铁心中，都另行计算）。因此对所有$i$和$\omega$都有$K_e\omega\,i = K_t i\,\omega$，故$K_e = K_t$。换算系数：$1000\ \mathrm{rev/min} = 1000 \times 2\pi/60 = 104.72\ \mathrm{rad/s}$，所以$1\ \mathrm{V/krpm} = 1/104.72\ \mathrm{V\,s/rad}$。
:::

### 稳态：转矩-转速直线

::: proposition 稳态特性 {#prop-torque-speed}
在恒定外加电压$V$下的稳态（电流恒定，故$L\,\mathrm{d}i/\mathrm{d}t = 0$）中，输出转矩为$T$的直流电机的转速为
$$
\omega = \frac{V}{K} - \frac{R}{K^2}\,T .
$$ {#eq-torque-speed}
**空载转速**为$\omega_0 = V/K$，**堵转转矩**为$T_s = KV/R$（堵转电流为$V/R$）。机械输出功率$P = T\omega$在$T = T_s/2$、$\omega = \omega_0/2$处最大，此时$P_{\max} = T_s\omega_0/4$；若忽略摩擦，效率为$\eta = \omega/\omega_0 = 1 - T/T_s$。
:::

::: proof
沿电枢回路应用KVL：$V = Ri + L\,\mathrm{d}i/\mathrm{d}t + K\omega$。稳态下$V = Ri + K\omega$，代入$i = T/K$得$\omega = (V - RT/K)/K$，即[[#eq-torque-speed]]。令$T = 0$得$\omega_0$；令$\omega = 0$得$T_s$。写成$\omega = \omega_0(1 - T/T_s)$，功率$P = T\omega_0(1 - T/T_s)$是$T$的抛物线，其最大值位于$\mathrm{d}P/\mathrm{d}T = \omega_0(1 - 2T/T_s) = 0$处，即$T = T_s/2$，得$P_{\max} = \omega_0T_s/4$。输入功率为$Vi = VT/K$，故$\eta = T\omega/(VT/K) = K\omega/V = \omega/\omega_0$。
:::

转矩-转速特性是一条直线，电压使其平行移动：电压决定转速，负载决定电流。**电机常数**$K_m = K/\sqrt R$（每单位铜损平方根的转矩，$T/\sqrt{i^2R}$）是比较尺寸相近的电机时最好的单一品质指标。注意效率的结果：在最大功率点电机效率只有$50\,\%$（一半输入功率损耗在绕组中），而且发热严重；连续运行是在低得多的转矩下进行的，那里效率很高。实际电机还有摩擦损耗和铁损，所以效率在空载和堵转时都降为零，峰值出现在堵转转矩的$10$–$20\,\%$附近。

::: example 小型直流电机的特性 {#ex-dc-motor}
一台永磁直流电机的$K = 0.050\ \mathrm{N\,m/A}$，$R = 2.0\ \mathrm{\Omega}$，供电电压为$24\ \mathrm{V}$。忽略摩擦，求(a) 空载转速、堵转电流和堵转转矩，(b) 最大输出功率，(c) 驱动$0.20\ \mathrm{N\,m}$负载时的转速、电流和效率。
::: solution
(a) $\omega_0 = V/K = 24/0.050 = 480\ \mathrm{rad/s}$（$4580\ \mathrm{rev/min}$）。堵转电流$V/R = 12\ \mathrm{A}$，堵转转矩$KV/R = 0.050 \times 12 = 0.60\ \mathrm{N\,m}$。

(b) $P_{\max} = T_s\omega_0/4 = 0.60 \times 480/4 = 72\ \mathrm{W}$，出现在$0.30\ \mathrm{N\,m}$和$240\ \mathrm{rad/s}$处。

(c) $\omega = 480 - (2.0/0.0025) \times 0.20 = 480 - 160 = 320\ \mathrm{rad/s}$；$i = 0.20/0.050 = 4.0\ \mathrm{A}$。输入$24 \times 4.0 = 96\ \mathrm{W}$，输出$0.20 \times 320 = 64\ \mathrm{W}$，效率$67\,\%$（$= 320/480$）；其余$32\ \mathrm{W} = i^2R$使绕组发热。

合理性检查：功率平衡$96 = 64 + 32$。$12\ \mathrm{A}$的堵转电流是一种瞬态工况——在一台$72\ \mathrm{W}$的电机中耗散$288\ \mathrm{W}$会在几秒钟内使其过热——所以驱动器要限制电流，而数据手册中的连续转矩额定值（由绕组温度决定）远低于堵转转矩。
:::
:::

### 动态特性

::: proposition 直流电机的传递函数 {#prop-motor-tf}
电枢电阻为$R$、电感为$L$的直流电机驱动总惯量$J$（转子加上折算的负载），黏性摩擦系数为$b$，则从电压到转速的传递函数为
$$
\frac{\Omega(s)}{V(s)} = \frac{K}{(Ls + R)(Js + b) + K^2} .
$$ {#eq-motor-tf}
当$L$和$b$可以忽略时，它为$\dfrac{1/K}{\tau_m s + 1}$，其中**机电时间常数**$\tau_m = JR/K^2$，到转角的传递函数为$\dfrac{1/K}{s(\tau_m s + 1)}$。**电气时间常数**为$\tau_e = L/R$；当$\tau_e \ll \tau_m$时一阶近似成立。
:::

::: proof
电气方程：$V = Ri + L\,\mathrm{d}i/\mathrm{d}t + K\omega$，变换后为$V = (Ls + R)I + K\Omega$。机械方程（转子的受力图：电机转矩$Ki$，摩擦转矩$-b\omega$，无负载转矩）：$J\,\mathrm{d}\omega/\mathrm{d}t = Ki - b\omega$，即$(Js + b)\Omega = KI$。消去$I = (Js + b)\Omega/K$：$V = [(Ls + R)(Js + b)/K + K]\Omega$，整理即得[[#eq-motor-tf]]。令$L = b = 0$：$\Omega/V = K/(RJs + K^2) = (1/K)/(\tau_ms + 1)$。转角是转速的积分，这增加了因子$1/s$。
:::

反电动势的作用类似于黏性阻尼：在机械方程中代入$i = (V - K\omega)/R$，转矩中就包含一项$-(K^2/R)\omega$。这种**电气阻尼**就是电压源驱动的直流电机具有阻尼良好的转速响应的原因，也是把旋转电机的端子短接就能使其制动的原因。它也是[[mechatronics/mechatronic-systems#prop-p-servo]]中所用被控对象$b/[s(s + a)]$（其中$a = 1/\tau_m$）的来源。

如果改用**电流控制型放大器**驱动电机——即伺服驱动器中标准配置的快速电流内环——反电动势对外环就不再有影响（放大器对它作了补偿），转矩几乎立即跟随指令，电机在位置控制器看来就是一个纯惯量，$\Theta(s)/I(s) = K/(Js^2)$。这就是[[mechatronics/motion-control]]中使用的模型。

## 传动比与惯量匹配 {#sec-gearing}

电机在高转速、低转矩下最高效、最紧凑；负载通常需要的恰恰相反。传动比为$N$（电机转速$= N \times$负载转速）的**减速器**、带传动或丝杠把转矩放大$N$倍（扣除损耗），把转速缩小$N$倍。它还改变电机所看到的惯量：以$\omega/N$运动的负载惯量$J_L$具有动能$\tfrac12J_L(\omega/N)^2$，所以它在电机轴上表现为**折算惯量**$J_L/N^2$。对于导程为$p$、推动质量$m$的丝杠，折算到丝杠上的等效惯量为$m(p/2\pi)^2$。

::: proposition 使加速度最大的最佳传动比 {#prop-inertia-match}
惯量为$J_m$、输出转矩为$T_m$的电机通过传动比为$N$的理想齿轮驱动纯惯量$J_L$。负载的角加速度
$$
\alpha_L = \frac{NT_m}{N^2J_m + J_L},
$$ {#eq-load-accel}
在$N = \sqrt{J_L/J_m}$时最大，即折算负载惯量等于电机惯量时；此时$\alpha_{L,\max} = T_m/(2\sqrt{J_mJ_L})$。
:::

::: proof
折算到电机轴上，总惯量为$J_m + J_L/N^2$，电机加速度为$\alpha_m = T_m/(J_m + J_L/N^2)$；负载的加速度为$\alpha_L = \alpha_m/N = T_m/(NJ_m + J_L/N) = NT_m/(N^2J_m + J_L)$。对$N$求导：$\mathrm{d}\alpha_L/\mathrm{d}N = T_m(J_L - N^2J_m)/(N^2J_m + J_L)^2$，它在$N^2 = J_L/J_m$处为零，并在该处由正变负，所以是最大值。代入得$\alpha_L = \sqrt{J_L/J_m}\,T_m/(2J_L) = T_m/(2\sqrt{J_mJ_L})$。
:::

惯量匹配是一条指导原则，而不是硬性规则。它使给定转矩下的加速度最大，但在最佳点电机一半的转矩用于加速它自己的转子。实践中，为获得良好的控制，伺服设计者接受（折算后的）负载与电机惯量比最高约为$5$–$10$——更大的惯量比会使回路对联轴器和传动带的柔度敏感——并且选择$N$时还要使电机保持在其最高转速以下，并使连续转矩需求符合电机的额定值。

::: example 选择传动比 {#ex-gear}
一台转子惯量为$J_m = 1.0\times10^{-5}\ \mathrm{kg\,m^2}$、峰值转矩为$0.40\ \mathrm{N\,m}$的电机要加速一个惯量为$J_L = 4.0\times10^{-3}\ \mathrm{kg\,m^2}$的转台。求使转台加速度最大的传动比及所得的加速度；并与$N = 10$和$N = 40$比较。
::: solution
$N_{\text{opt}} = \sqrt{4.0\times10^{-3}/1.0\times10^{-5}} = \sqrt{400} = 20$。于是$\alpha_L = 20 \times 0.40/(400 \times 10^{-5} + 4.0\times10^{-3}) = 8.0/8.0\times10^{-3} = 1000\ \mathrm{rad/s^2}$。$N = 10$时：$4.0/(1.0\times10^{-3} + 4.0\times10^{-3}) = 800\ \mathrm{rad/s^2}$；$N = 40$时：$16/(1.6\times10^{-2} + 4.0\times10^{-3}) = 800\ \mathrm{rad/s^2}$。

合理性检查：最佳点很平坦——两侧相差一倍只损失$20\,\%$——所以可以根据其他理由选择传动比（最高转速：若电机限速$500\ \mathrm{rad/s}$，$N = 20$时转台转速为$25\ \mathrm{rad/s}$；$N = 10$时为$50\ \mathrm{rad/s}$）。$N = 10$和$40$处的对称值由[[#eq-load-accel]]得出：把$N$换成$N_{\text{opt}}^2/N$时$\alpha_L$不变。
:::
:::

## 驱动器：H桥与PWM {#sec-hbridge}

直流电机需要一个控制器可以调节、可正可负（以便双向驱动）的电压。**H桥**——四个晶体管开关排成字母H形，电机跨接在中间——提供了这样的电压。闭合左上和右下开关，电机上加$+V_s$；闭合右上和左下开关，加$-V_s$；闭合两个下方（或两个上方）开关，则把电机短路以实现制动。同一侧的两个开关绝不能同时导通（那会使电源短路，即**直通**），所以栅极驱动器在每次切换时插入一段短暂的**死区时间**，在此期间电机电流流经跨接在开关上的二极管（对MOSFET而言是其固有的体二极管）。由于电流可以双向流过每个开关和二极管，电桥能够在两个方向上驱动和制动——即**四象限**运行——而制动时电机作为发电机运行，把能量回馈给电源，电源必须能够吸收这些能量。

开关由PWM控制（[[mechatronics/microcontrollers#prop-timer]]）。在**符号-幅值**（单极性）运行中，一侧按所选方向保持固定状态，另一侧以占空比$D$开关，电机平均电压为$DV_s$；在**锁定反相**（双极性）运行中，两条对角线交替导通，平均电压为$(2D - 1)V_s$，在$D = 0.5$时为零。由于电机的电气时间常数$L/R$比PWM周期长得多，电流几乎恒定，只有很小的三角形纹波。

::: proposition PWM驱动电机中的电流纹波 {#prop-ripple}
对于由电源$V_s$供电、频率为$f$、占空比为$D$的符号-幅值PWM，若PWM周期比$L/R$短且电机以稳定转速运行，则电流纹波的峰-峰值近似为
$$
\Delta I = \frac{V_s\,D(1 - D)}{Lf},
$$ {#eq-ripple}
在$D = 0.5$时最大，此时$\Delta I_{\max} = V_s/(4Lf)$。
:::

::: proof
在一个周期内，反电动势$E$和电阻压降几乎恒定。在导通时间$DT$内电机承受$V_s - E - Ri$，在关断时间内（电流经低边开关续流）承受$-E - Ri$。稳态下电流在每个周期都回到起始值，所以电感电压的平均值为零：$D(V_s - E - R\bar i) + (1 - D)(-E - R\bar i) = 0$，即$E + R\bar i = DV_s$。于是导通时间内的电流上升量为$\Delta I = (V_s - DV_s)DT/L = V_sD(1 - D)/(Lf)$，这里忽略了周期内$Ri$的微小变化。乘积$D(1 - D)$在$D = \tfrac12$时最大，为$\tfrac14$。
:::

纹波会增加铜损（$i_{\text{rms}}^2R$）和磁损耗，如果$f$处于可听范围内，还会产生转矩脉动和可闻噪声。提高$f$可以减小纹波——代价是晶体管的开关损耗——也可以增加串联电感。低电感电机（空心杯、“无铁心”直流电机，$L$只有几十微亨）因此需要很高的PWM频率。

::: example 选择PWM频率 {#ex-pwm-ripple}
一台$L = 1.0\ \mathrm{mH}$、$R = 2.0\ \mathrm{\Omega}$的直流电机由$24\ \mathrm{V}$电源以$20\ \mathrm{kHz}$符号-幅值PWM驱动。求最坏情况下的电流纹波，并与额定负载电流$4\ \mathrm{A}$比较。$2\ \mathrm{kHz}$是否可以接受？
::: solution
$\Delta I_{\max} = 24/(4 \times 1.0\times10^{-3} \times 20\,000) = 0.30\ \mathrm{A}$（峰-峰值），为$4\ \mathrm{A}$的$7.5\,\%$。近似成立：$T = 50\ \mathrm{\mu s} \ll L/R = 500\ \mathrm{\mu s}$。

在$2\ \mathrm{kHz}$时公式给出$3.0\ \mathrm{A}$，但此时$T = 500\ \mathrm{\mu s} = L/R$，线性斜坡近似不再成立（纹波会稍小一些）。无论如何，纹波与负载电流相当，转矩以$2\ \mathrm{kHz}$可闻地脉动，额外的有效值电流还会增加铜损。$20\ \mathrm{kHz}$是更好的选择。

合理性检查：三角波纹波使均方电流增加$\Delta I^2/12$：在$20\ \mathrm{kHz}$时为$0.0075\ \mathrm{A^2}$，与$16\ \mathrm{A^2}$相比可以忽略；在$2\ \mathrm{kHz}$时约为$0.75\ \mathrm{A^2}$，使铜损增加$5\,\%$。
:::
:::

## 步进电机 {#sec-stepper}

**步进电机**在其相绕组被依次通电时以固定的角度增量运动。常见的**混合式**步进电机有一个带齿的轴向磁化转子和一个有两相绕组的定子；其标准步距角为$1.8°$（每转$200$个整步）。依次给A相、B相、$-$A相、$-$B相通电，每次使转子前进一步，步进频率决定转速。由于位置可以通过计数步数得知，步进电机可以**开环**定位而无需编码器——这就是它被用于3D打印机、小型数控机床、阀门、仪器和打印机的原因。

现代驱动器通过**斩波**（电流模式PWM）调节相电流，并施加正弦-余弦电流对，把每个整步细分为若干**微步**（$1/16$或更细）。微步驱动使运动更平稳、更安静；但并不能使精度成比例地提高，因为保持在中间位置可用的转矩很小，转子位置会随负载而偏离。

由物理原理产生三方面的局限。(1) **转矩随转速下降**：每相都有电感，随着步进频率升高，驱动器克服绕组的反电动势和电感建立电流的时间越来越少，所以**牵出转矩**曲线在每分钟几百转以上急剧下降；提高电源电压可以扩展可用转速范围。(2) **丢步**：如果负载转矩超过可用转矩（卡住时，或加速过猛时），转子会滑过一步或几步——控制器并不知道，此后的每个位置都是错的，直到机器重新回零。(3) **共振**：处于磁定位状态的转子表现为轻阻尼的弹簧-质量系统，在某些步进频率下（通常为每秒$100$–$200$个整步）运动会变得粗糙或电机失步停转；微步驱动和机械阻尼可以减轻这一问题。步进电机在静止时也要通满电流，因而发热严重。在这些局限很重要的场合，就采用闭环步进电机（带编码器）或伺服电机。

::: example 步进轴的分辨率和步进频率 {#ex-stepper}
一台$1.8°$步进电机，驱动器设为$1/16$微步，驱动导程为$8\ \mathrm{mm}$的丝杠。求每微步的行程以及$50\ \mathrm{mm/s}$时的步进脉冲频率。
::: solution
每转微步数$200 \times 16 = 3200$；每微步行程$8\ \mathrm{mm}/3200 = 2.5\ \mathrm{\mu m}$。在$50\ \mathrm{mm/s}$时丝杠转速为$50/8 = 6.25\ \mathrm{rev/s}$（$375\ \mathrm{rev/min}$），需要每秒$6.25 \times 3200 = 20\,000$个步进脉冲。

合理性检查：$375\ \mathrm{rev/min}$处于典型小型混合式步进电机仍保有相当一部分保持转矩的范围内；在五倍于此的转速下，它可能已所剩无几。$2.5\ \mathrm{\mu m}$的分辨率只是名义值：负载下微步的定位精度可能不优于整步的百分之几（这里相当于$40\ \mathrm{\mu m}$的行程）。
:::
:::

## 无刷电机 {#sec-brushless}

换向器和电刷是直流电机的薄弱环节：它们会磨损、产生火花、限制转速，并且把发热的绕组放在转子上，难以冷却。**无刷**电机把电机里外翻转过来：永磁体在转子上，绕组（通常为三相）在定子上，换向则由**三相逆变器**（三个半桥）以电子方式完成，它根据转子位置切换各相电流。

按反电动势波形和驱动方式区分，有两种变体。**无刷直流电机**（BLDC）具有梯形反电动势，采用**六步**（方波）换向驱动：任一时刻有两相通电，导通模式根据三个霍尔传感器（[[mechatronics/sensors]]）每隔$60°$电角度切换一次。它简单而便宜（风扇、泵、无人机、电动工具），但在切换时刻有一定的转矩脉动。**永磁同步电机**（PMSM，常称交流伺服电机）具有正弦反电动势，由与编码器或旋转变压器同步的正弦电流驱动。其标准控制方法是**磁场定向控制**（FOC，矢量控制）：把测得的三相电流（通过克拉克变换和帕克变换）变换到随转子旋转的坐标系中，在那里它们表现为两个直流量——产生转矩的$i_q$和沿磁体磁通方向的$i_d$——各由一个PI控制器调节。当$i_d = 0$时，转矩为
$$
T = \tfrac32\,p\,\psi_m\,i_q,
$$ {#eq-pmsm-torque}
其中$p$为极对数，$\psi_m$为磁体磁链：转矩与一个电流成正比，与直流电机完全一样。正是FOC使无刷伺服电机在外环看来就像一台带快速电流环的理想直流电机，直到零速都有平稳的转矩。

| 类型 | 位置反馈 | 优点 | 缺点 | 典型用途 |
|---|---|---|---|---|
| 有刷直流 | 可选（伺服用途需编码器） | 驱动简单，便宜，模型线性 | 电刷磨损，火花，转速受限，转子发热 | 玩具，汽车辅助装置，低成本伺服 |
| 步进（混合式） | 无（开环）或编码器 | 开环定位，有保持转矩，控制简单 | 转矩随转速下降，丢步，共振，静止时发热 | 3D打印机，小型数控机床，仪器 |
| BLDC（六步） | 霍尔传感器或无传感器 | 高效，寿命长，转速高 | 转矩脉动，驱动较复杂 | 风扇，泵，无人机，工具 |
| 采用FOC的PMSM | 编码器或旋转变压器 | 转矩平稳，动态性能高，高效 | 驱动复杂，成本高 | 伺服轴，机器人，电动汽车 |

::: warning 峰值转矩、连续转矩与热极限
电机样本列出**峰值转矩**（受驱动器电流限值和磁体退磁的限制）和**连续转矩**（受绕组温度的限制）。只按运动中的峰值转矩选定电机是一个常见错误：绕组按整个循环中电流的**均方值**发热，所以要在实际环境温度和安装条件下，用均方根转矩（[[#exr-rms]]）与连续额定值比较。相反的错误——按均方根转矩选型，却忘了检查峰值需求及其出现时的转速是否位于电机加驱动器的转矩-转速曲线之下——会得到一个无法跟踪其轨迹的轴。两项校核都需要，另加余量，通常为$20$–$50\,\%$。
:::

::: quiz
直流电机的电源电压减半，而负载转矩保持不变。稳态下会发生什么？
- [x] 电流不变，转速下降超过一半
- [ ] 电流减半，转速减半
- [ ] 电流加倍，转速不变
- [ ] 转速恰好减半，电流不变
::: solution
电流由负载决定，$i = T/K$，所以不变。转速为$\omega = V/K - RT/K^2$：第一项减半，而第二项（负载引起的转速降）保持不变，所以转速下降超过一半。在[[#ex-dc-motor]]中，负载为$0.2\ \mathrm{N\,m}$时，把电压从$24$降到$12\ \mathrm{V}$，转速从$320$降到$80\ \mathrm{rad/s}$。
:::
:::

::: history
1821年，迈克尔·法拉第（Michael Faraday）演示了连续的电磁旋转——一根载流导线在一杯水银中绕磁铁转动。实用的直流电机出现于19世纪30年代，其中有佛蒙特州铁匠托马斯·达文波特（Thomas Davenport）的电机，他于1837年获得了一项电动机的美国专利；但在19世纪七八十年代发电机使电力变得便宜之前，它们很少得到应用。随着20世纪60年代功率晶体管的出现，电子换向变得实用；磁场定向控制于1970年前后由西门子公司和达姆施塔特工业大学的费利克斯·布拉施克（Felix Blaschke）和卡尔·哈塞（Karl Hasse）发展起来。1984年由住友特殊金属的佐川真人（Masato Sagawa）及其同事、并由通用汽车公司独立宣布的钕铁硼磁体，赋予了无刷电机无人机、机器人和电动汽车所依赖的高能量密度。
:::

::: summary
- 直流电机：$T = Ki$，$e = K\omega$，在SI单位制中$K$相同（功率平衡）。稳态$\omega = V/K - (R/K^2)T$；堵转转矩$KV/R$，空载转速$V/K$，最大功率$T_s\omega_0/4$，此时效率为$50\,\%$。
- 动态特性：$\Omega/V = K/[(Ls + R)(Js + b) + K^2] \approx (1/K)/(\tau_ms + 1)$，其中$\tau_m = JR/K^2$；反电动势起阻尼作用。在电流控制下电机是一个纯惯量，$K/(Js^2)$。
- 折算惯量$J_L/N^2$；加速度在$N = \sqrt{J_L/J_m}$时最大，这个最佳点很宽。
- H桥实现四象限运行；PWM设定平均电压；纹波$V_sD(1 - D)/(Lf)$，在$D = 0.5$时最大。
- 步进电机通过计数步数开环定位，但转矩随转速下降，可能丢步并发生共振。
- 无刷电机：电子换向；采用霍尔传感器的六步换向，或采用FOC，$T = \tfrac32p\psi_mi_q$。
- 选定电机时既要按均方根转矩（热）校核，也要按峰值转矩-转速需求校核。
:::

## 习题

::: exercise 换算反电动势常数 {level=1 check="0.1"}
数据手册给出的反电动势常数为每$1000\ \mathrm{rev/min}$ $10.472\ \mathrm{V}$。利用$1000\ \mathrm{rev/min} = 104.72\ \mathrm{rad/s}$，求SI单位的转矩常数。（填写$K$，单位N·m/A。）
::: solution
$K = 10.472/104.72 = 0.100\ \mathrm{V\,s/rad}$，由[[#prop-kt-ke]]，转矩常数是同一个数值，$0.100\ \mathrm{N\,m/A}$。若忘记换算而直接使用$10.472$，会把每安培的转矩夸大一百倍。
:::
:::

::: exercise 堵转转矩 {level=1 check="0.375"}
一台$K = 0.025\ \mathrm{N\,m/A}$、$R = 0.80\ \mathrm{\Omega}$的电机以$12\ \mathrm{V}$供电。求其堵转转矩。（以N·m为单位填写。）
::: solution
堵转电流$12/0.80 = 15\ \mathrm{A}$；$T_s = 0.025 \times 15 = 0.375\ \mathrm{N\,m}$。
:::
:::

::: exercise 机电时间常数 {level=1 check="16"}
一台$K = 0.050\ \mathrm{N\,m/A}$、$R = 2.0\ \mathrm{\Omega}$的电机驱动$2.0\times10^{-5}\ \mathrm{kg\,m^2}$的总惯量。求机电时间常数。（填写$\tau_m$，单位ms。）
::: solution
$\tau_m = JR/K^2 = 2.0\times10^{-5} \times 2.0/0.0025 = 0.016\ \mathrm{s} = 16\ \mathrm{ms}$。
:::
:::

::: exercise 步进电机每步的行程 {level=1 check="10"}
一台$1.8°$步进电机以整步方式驱动导程为$2\ \mathrm{mm}$的丝杠。求每步的行程。（以μm为单位填写。）
::: solution
$2\ \mathrm{mm}/200 = 0.010\ \mathrm{mm} = 10\ \mathrm{\mu m}$。
:::
:::

::: exercise 另一频率下的纹波 {level=2 check="0.3"}
一台$L = 0.50\ \mathrm{mH}$的电机由$48\ \mathrm{V}$电源以$80\ \mathrm{kHz}$符号-幅值PWM驱动。求最坏情况下电流纹波的峰-峰值。（以A为单位填写。）
::: solution
$\Delta I_{\max} = V_s/(4Lf) = 48/(4 \times 5.0\times10^{-4} \times 8.0\times10^{4}) = 48/160 = 0.30\ \mathrm{A}$。
:::
:::

::: exercise 工作点 {level=2 check="160"}
上面堵转转矩习题中的电机（$K = 0.025\ \mathrm{N\,m/A}$，$R = 0.80\ \mathrm{\Omega}$，$12\ \mathrm{V}$）驱动$0.25\ \mathrm{N\,m}$的负载。忽略摩擦，求其转速。（填写$\omega$，单位rad/s。）
::: solution
空载转速$12/0.025 = 480\ \mathrm{rad/s}$；斜率$R/K^2 = 0.80/6.25\times10^{-4} = 1280\ \mathrm{rad\,s^{-1}/(N\,m)}$。因此$\omega = 480 - 1280 \times 0.25 = 160\ \mathrm{rad/s}$。电流为$0.25/0.025 = 10\ \mathrm{A}$，效率为$160/480 = 33\,\%$：电机工作在其堵转转矩的三分之二，远远超出任何合理的连续额定值。
:::
:::

::: exercise 均方根转矩 {#exr-rms level=2 check="0.4"}
一个伺服轴重复如下循环：电机输出$0.60\ \mathrm{N\,m}$持续$1.0\ \mathrm{s}$（加速），$0.20\ \mathrm{N\,m}$持续$1.0\ \mathrm{s}$（克服摩擦匀速运动），$0$持续$0.5\ \mathrm{s}$（停歇）。求必须与连续额定值比较的均方根转矩。（以N·m为单位填写。）
::: solution
$T_{\text{rms}} = \sqrt{(0.36 \times 1.0 + 0.04 \times 1.0 + 0)/2.5} = \sqrt{0.16} = 0.40\ \mathrm{N\,m}$。铜损与$i^2 \propto T^2$成正比，所以均方根转矩给出与该循环相同的平均发热。平均转矩$0.32\ \mathrm{N\,m}$会低估发热。
:::
:::

::: exercise 通过减速器的负载加速度 {level=2 check="1250"}
一台$J_m = 2.0\times10^{-5}\ \mathrm{kg\,m^2}$、转矩为$0.50\ \mathrm{N\,m}$的电机通过传动比$N = 10$的理想减速器驱动$J_L = 2.0\times10^{-3}\ \mathrm{kg\,m^2}$的负载。求负载的角加速度。（填写$\alpha_L$，单位rad/s²。）
::: solution
$\alpha_L = NT_m/(N^2J_m + J_L) = 10 \times 0.50/(100 \times 2.0\times10^{-5} + 2.0\times10^{-3}) = 5.0/(4.0\times10^{-3}) = 1250\ \mathrm{rad/s^2}$。这里$N = \sqrt{J_L/J_m} = 10$正是最佳传动比，结果等于$T_m/(2\sqrt{J_mJ_L}) = 0.50/(2 \times 2.0\times10^{-4}) = 1250\ \mathrm{rad/s^2}$。
:::
:::

::: exercise 为机器人关节选择电机 {level=3}
一个机器人关节必须按三角形速度曲线在$0.5\ \mathrm{s}$内把一条手臂（绕关节的惯量为$0.50\ \mathrm{kg\,m^2}$，重力矩最大$20\ \mathrm{N\,m}$）转过$90°$，然后保持。在有刷直流电机、步进电机和采用FOC的PMSM之间作出选择；为所选方案选定传动比，估算电机的峰值转矩、均方根转矩和峰值转速，并说明你的假设。
::: solution
好的回答：在$t = 0.5\ \mathrm{s}$内转过$\theta = \pi/2$的三角形速度曲线给出关节峰值转速$2\theta/t = 6.28\ \mathrm{rad/s}$和加速度$4\theta/t^2 = 25.1\ \mathrm{rad/s^2}$。关节峰值转矩$0.50 \times 25.1 + 20 = 32.6\ \mathrm{N\,m}$（克服重力加速），连续保持$20\ \mathrm{N\,m}$。选用采用FOC的PMSM（转矩平稳，以适中的电流保持而不过热，有编码器反馈），通过传动比约为$100$的谐波或行星减速器：电机峰值转速$628\ \mathrm{rad/s}$（$6000\ \mathrm{rev/min}$），峰值转矩$0.33\ \mathrm{N\,m}$，再加上电机自身的惯性转矩和齿轮损耗（效率约为$70$–$80\,\%$，所以约为$0.45\ \mathrm{N\,m}$），若手臂在循环的大部分时间处于保持状态，连续转矩约为$0.25$–$0.3\ \mathrm{N\,m}$。校核折算惯量$0.5/100^2 = 5\times10^{-5}\ \mathrm{kg\,m^2}$与电机转子惯量之比（比值在$1$–$10$以内为好）。断电时需要制动器来保持手臂。步进电机只有在留有很大余量时才能开环完成这一任务，而且在重力载荷下丢步是一个安全问题；有刷电机可以工作，但会磨损。
:::
