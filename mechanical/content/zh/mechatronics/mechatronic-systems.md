机电系统是最复杂的系统：机电系统是机器人、数控机床、防抱死制动系统和自动驾驶汽车，而机电系统正是决定机器性能的那个系统。**设计机电系统而不理解系统集成的工程师并不是在设计系统；他们设计出的将是一个因失稳而失效、而非因元件失效而失效的系统。**机电系统设计是工程师能够预测系统性能的原因，而预测正是系统安全的原因。

机电系统设计的定量工具是**系统架构**（将系统分解为若干子系统）、**传感器选择**（为测量选择传感器）、**执行器选择**（为运动选择执行器）以及**控制系统设计**（为性能选择控制器）。这些工具是表达机电系统设计所使用的语言，而这种语言正是设计是一种计算而非猜测的原因。

::: warning 机电系统设计出错的九种方式
**没有检查系统架构。** 设计机电系统而不检查系统架构的工程师并不是在设计系统；他们设计出的将是一个因集成而失效的系统。**系统架构是系统为集成而非为单个元件而设计的原因，而集成正是系统是机器中最关键部件的原因。** **没有检查传感器带宽。** 选择传感器而不检查带宽的工程师并不是在选择传感器；他们是在猜测。**传感器带宽是传感器为频率而非幅值而设计的原因，而频率正是传感器是控制系统中最关键部件的原因。** **没有检查执行器带宽。** 选择执行器而不检查带宽的工程师并不是在选择执行器；他们是在猜测。**执行器带宽是执行器为频率而非力而设计的原因，而频率正是执行器是控制系统中最关键部件的原因。** **没有检查控制系统稳定性。** 设计控制系统而不检查稳定性的工程师并不是在设计控制系统；他们是在猜测。**控制系统稳定性是控制系统为稳定性而非性能而设计的原因，而稳定性正是控制系统是机器中最关键部件的原因。** **没有检查信号调理。** 设计信号调理而不检查噪声的工程师并不是在设计信号调理；他们是在猜测。**噪声是信号调理为信噪比而非增益而设计的原因，而信噪比正是信号调理是测量系统中最关键部件的原因。** **没有检查通信带宽。** 设计通信系统而不检查带宽的工程师并不是在设计通信系统；他们是在猜测。**通信带宽是通信系统为数据率而非距离而设计的原因，而数据率正是通信系统是分布式系统中最关键部件的原因。** **没有检查电源。** 设计电源而不检查纹波的工程师并不是在设计电源；他们是在猜测。**纹波是电源为纹波而非电压而设计的原因，而纹波正是电源是电子系统中最关键部件的原因。** **没有检查电磁兼容性。** 设计系统而不检查电磁兼容性的工程师并不是在设计系统；他们设计出的将是一个因电磁干扰而失效的系统。**电磁兼容性是系统为电磁兼容性而非性能而设计的原因，而电磁兼容性正是系统是车辆中最关键部件的原因。** **没有检查安全性。** 设计系统而不检查安全性的工程师并不是在设计系统；他们设计出的将是一个因危险而失效的系统。**安全性是系统为安全性而非性能而设计的原因，而安全性正是系统是机器中最关键部件的原因。**
:::

## 1. 机电系统架构

::: definition 机电系统架构 {#def-architecture}
**机电系统架构**是将系统分解为若干子系统，而机电系统架构是工程师能够使系统安全的原因。

**机电系统**由以下部分组成：
1. **传感器**：测量物理量（位置、速度、力、温度、压力）的装置
2. **信号调理**：对传感器信号进行放大、滤波和变换的装置
3. **控制器**：由传感器信号计算控制作用的装置
4. **执行器**：将控制信号转换为物理作用（力、运动、热）的装置
5. **电源**：为系统提供电能的装置
6. **通信**：在各子系统之间传输数据的装置

$$
\begin{array} { l c c c }
\textbf{子系统} & \textbf{功能} & \textbf{关键参数} & \textbf{适用场合} \\ \hline
\text{传感器} & \text{测量物理量} & \text{带宽、精度} & \text{位置、速度、力} \\
\text{信号调理} & \text{放大、滤波、变换} & \text{增益、噪声、带宽} & \text{应变片、热电偶} \\
\text{控制器} & \text{计算控制作用} & \text{采样率、计算能力} & \text{PID、状态空间、模糊} \\
\text{执行器} & \text{将信号转换为作用} & \text{力、速度、带宽} & \text{电机、液压、气动} \\
\text{电源} & \text{提供电能} & \text{电压、电流、纹波} & \text{电池、开关电源、线性电源} \\
\text{通信} & \text{传输数据} & \text{数据率、时延} & \text{CAN、以太网、SPI} \\
\end{array}
$$

**系统架构是系统为集成而非为单个元件而设计的原因，而集成正是系统是机器中最关键部件的原因。设计机电系统而不检查系统架构的工程师并不是在设计系统；他们设计出的将是一个因集成而失效的系统。**
:::

::: definition 传感器-执行器选择 {#def-sensor-actuator}
**传感器-执行器选择**是为具体应用选择传感器和执行器，而传感器-执行器选择是工程师能够使系统安全的原因。

**传感器选择准则：**
1. **被测量**：待测量的物理量
2. **量程**：被测量的最小值与最大值
3. **精度**：测量值与真值的接近程度
4. **分辨率**：能够检测到的被测量的最小变化
5. **带宽**：传感器能够响应的频率范围
6. **线性度**：传感器输出与直线的接近程度
7. **环境**：温度、湿度、振动与电磁干扰

**执行器选择准则：**
1. **力/转矩**：所需的力或转矩
2. **速度**：运动的速度
3. **精度**：定位精度
4. **带宽**：频率响应
5. **效率**：输出功率与输入功率之比
6. **环境**：温度、湿度、振动与电磁干扰

$$
\begin{array} { l c c c }
\textbf{传感器类型} & \textbf{被测量} & \textbf{量程} & \textbf{精度} \\ \hline
\text{电位器} & \text{位置} & 0 \text{--} 3 6 0 ^ { \circ } & 0 . 1 \ \% \\
\text{LVDT} & \text{位置} & \pm 5 0 0 \ \text{mm} & 0 . 2 5 \ \% \\
\text{编码器} & \text{位置} & \text{不限} & 0 . 0 1 \ \% \\
\text{应变片} & \text{力/应变} & \pm 1 0 \ 0 0 0 \ \mu \varepsilon & 0 . 1 \ \% \\
\text{加速度计} & \text{加速度} & \pm 1 0 0 \, g & 0 . 1 \ \% \\
\text{热电偶} & \text{温度} & - 2 0 0 \text{--} 1  7 0 0 \, ^ { \circ } \text{C} & 1 \ ^ { \circ } \text{C} \\
\text{RTD} & \text{温度} & - 2 0 0 \text{--} 8 5 0 \, ^ { \circ } \text{C} & 0 . 1 \ ^ { \circ } \text{C} \\
\text{压电式} & \text{力/压强} & 0 \text{--} 1 0 0 \ \text{MPa} & 1 \ \% \\
\end{array}
$$

**传感器带宽是传感器为频率而非幅值而设计的原因，而频率正是传感器是控制系统中最关键部件的原因。选择传感器而不检查带宽的工程师并不是在选择传感器；他们是在猜测。**
:::

::: example 数控机床的传感器选择 {#ex-sensor-selection level=3 check="2"}
某数控机床需要一个量程为 0-1000 mm、精度为 ±0.01 mm、带宽为 1 kHz 的位置传感器。选择适当的传感器。

**所需精度：**

$$
\text{精度} \; = \; { \frac { 0 . 0 1 } { 1 0 0 0 } } \times 1 0 0 \; = \; 0 . 0 0 1 \; \ \%
$$

**传感器比较：**

$$
\begin{array} { l c c c }
\textbf{传感器} & \textbf{精度} & \textbf{带宽} & \textbf{是否合适？} \\ \hline
\text{电位器} & 0 . 1 \ \% & 1 0 0 \ \text{Hz} & \text{否（精度、带宽）} \\
\text{LVDT} & 0 . 2 5 \ \% & 5 0 0 \ \text{Hz} & \text{否（精度）} \\
\text{直线编码器} & 0 . 0 0 1 \ \% & 1 0 \ \text{kHz} & \text{是} \\
\text{光栅尺} & 0 . 0 0 0 5 \ \% & 1 0 0 \ \text{kHz} & \text{是（超出要求）} \\
\end{array}
$$

**直线编码器是合适的传感器，因为直线编码器满足精度和带宽要求。工程师会为数控机床选择直线编码器，因为直线编码器正是数控机床为精度而非量程而设计的原因。**
:::

## 2. 控制系统设计

::: definition 控制系统设计 {#def-control-design}
**控制系统设计**是为性能选择控制器，而控制系统设计是工程师能够使系统安全的原因。

**PID 控制器**是应用最广泛的控制器：

$$
u ( t ) \; = \; K _ { p } \, e ( t ) + K _ { i } \, \int _ { 0 } ^ { t } \, e ( \tau ) \, d \tau + K _ { d } \, { \frac { d e ( t ) } { d t } }
$$

**闭环传递函数**为：

$$
G _ { c l } ( s ) \; = \; { \frac { G _ { c } ( s ) \, G _ { p } ( s ) } { 1 + G _ { c } ( s ) \, G _ { p } ( s ) \, H ( s ) } }
$$

**稳定裕度**为：
- **幅值裕度**：在失稳之前增益可以增大的倍数
- **相角裕度**：在失稳之前可以附加的相位滞后量

$$
\begin{array} { l c c c }
\textbf{控制器} & \textbf{传递函数} & \textbf{适用场合} & \textbf{整定方法} \\ \hline
\text{P} & K _ { p } & \text{简单系统} & \text{齐格勒-尼科尔斯法} \\
\text{PI} & K _ { p } + K _ { i } / s & \text{零稳态误差} & \text{齐格勒-尼科尔斯法} \\
\text{PID} & K _ { p } + K _ { i } / s + K _ { d } \, s & \text{通用} & \text{齐格勒-尼科尔斯法} \\
\text{超前-滞后} & ( 1 + a \, T \, s ) / ( 1 + T \, s ) & \text{相角裕度} & \text{频率响应} \\
\text{状态空间} & u = - K \, x & \text{多输入多输出系统} & \text{极点配置} \\
\end{array}
$$

**控制系统稳定性是控制系统为稳定性而非性能而设计的原因，而稳定性正是控制系统是机器中最关键部件的原因。设计控制系统而不检查稳定性的工程师并不是在设计控制系统；他们是在猜测。**
:::
