轴是大多数工程师设计时最不在意的结构构件，也是尺寸最经常被做小的构件。电机输出一个扭矩，联轴器在一端施加它，齿轮和带轮沿长度间隔地把它取走，而任一截面上轴内部剩下的，是该截面一侧所有外力偶的代数和。扭矩图画错，轴就在你从未查看的地方超载；直径算错，轴就扭得齿轮错位、轴承磨损失准。

扭转也是本课程中最干净的理论。对圆截面轴，弹性解是**精确**的，不是近似的：横截面保持平面，半径保持直线，切应力从轴心处的零线性变化到表面的最大值。正是这种精确性使圆轴无处不在，也使方形轴或带键槽轴的性态发生的是种类上的不同、而不仅仅是程度上的不同。一旦离开圆形——一条槽、一个平面、一堵薄壁、一条裂纹——你要么发生翘曲，要么不发生，而整个设计随之改变。

::: warning 只适用于圆截面轴
$\tau = T \rho / J$ 和 $\phi = T L / J G$ 对**圆**截面轴——实心或空心、棱柱形、线弹性——是精确的。对非圆**实心**截面，轴会翘曲出截面平面，凸角边界处的应力为零，而且扭转常数 $J$ 不再是极惯性矩：对矩形 $J = \beta_1 b t^{3}$，$\beta_1$ 介于 $0.141$ 与 $0.333$ 之间。对薄壁**开口**截面——开缝管、槽钢、角钢——$J = \tfrac{1}{3} \sum s t^{3}$，对开缝管，这比同厚度的闭口管小一个因子 $2 t^{2} / r^{2}$。直径 $80\ \mathrm{mm}$、壁厚 $3\ \mathrm{mm}$ 的开缝管，其扭转刚度比把缝焊死的同一根管低 $530$ 倍。绝不要把圆轴公式用在非圆形的形状上。
:::

## 圆截面轴

::: definition 圆截面轴的扭转 {#def-torsion}
对半径 $c$、极惯性矩 $J$、承受扭矩 $T$ 的轴，
$$
\tau = \frac{T \rho}{J}, \qquad
\tau_{\max} = \frac{T c}{J} = \frac{T}{J / c}, \qquad
J = \frac{\pi c^{4}}{2} = \frac{\pi D^{4}}{32},
$$
其中 $J / c = \pi D^{3} / 16$ 是**抗扭截面系数**。对空心轴，
$$
J = \frac{\pi \left( D_o^{4} - D_i^{4} \right)}{32}, \qquad
\frac{J}{c} = \frac{\pi \left( D_o^{4} - D_i^{4} \right)}{16 D_o} .
$$
长度 $L$ 上的**扭转角**为
$$
\phi = \frac{T L}{J G} \quad \text{（弧度）}, \qquad \gamma_{\max} = \frac{c \phi}{L} = \frac{\tau_{\max}}{G} .
$$
:::

::: proposition 功率、扭矩与转速 {#prop-power}
以每分钟 $n$ 转传递功率 $\mathcal{P}$ 的轴，其扭矩为
$$
T = \frac{\mathcal{P}}{\omega} = \frac{60 \, \mathcal{P}}{2 \pi n}, \qquad
\mathcal{P} = T \omega = T \frac{2 \pi n}{60} = 2 \pi n T \times 10^{-3} \ \mathrm{kW} \text{，} n \text{ 以 rev/s 计}.
$$
对功率以 $\mathrm{kW}$ 计、扭矩以 $\mathrm{N\,m}$ 计的常用情形，
$$
T = 9549 \, \frac{\mathcal{P} \text{ (kW)}}{n \text{ (rpm)}} .
$$
:::

::: proof
每转的功是扭矩乘以转角，$T \times 2 \pi$，而每秒有 $n / 60$ 转，所以
$$
\mathcal{P} = \frac{2 \pi n T}{60}
\quad\Longrightarrow\quad
T = \frac{60 \mathcal{P}}{2 \pi n} = 9.549 \frac{\mathcal{P} \text{ (W)}}{n} = 9549 \frac{\mathcal{P} \text{ (kW)}}{n} .
$$
其推论支配着传动设计：功率一定时，扭矩与转速成反比，所以高速轴细小、低速轴巨大。$1500\ \mathrm{rev / min}$ 的 $75\ \mathrm{kW}$ 传动需要 $477\ \mathrm{N\,m}$；同一功率经 $20:1$ 齿轮箱在 $75\ \mathrm{rev / min}$ 下需要 $9550\ \mathrm{N\,m}$，是二十倍——这就是为什么风力机的低速轴直径达一米、而高速轴只有手腕粗。
:::

::: example 带齿轮的轴 {#ex-shaft-gears}
一钢轴在 $A$、$E$ 两处的轴承中自由转动，顺序为 $A$-$B$-$C$-$D$-$E$。齿轮 $B$ 处施加扭矩 $2500\ \mathrm{N\,m}$；$C$ 处取走 $1500\ \mathrm{N\,m}$，$D$ 处取走 $1000\ \mathrm{N\,m}$。各段长度 $A B = 0.4\ \mathrm{m}$、$B C = 0.8\ \mathrm{m}$、$C D = 0.6\ \mathrm{m}$、$D E = 0.4\ \mathrm{m}$，直径 $60\ \mathrm{mm}$。取 $G = 80\ \mathrm{GPa}$，求最大切应力和 $D$ 相对 $A$ 的扭转角。
::: solution
**扭矩图**，从自由端 $A$ 出发，逐段加上经过的每个外力偶：
$$
T_{AB} = 0, \qquad
T_{BC} = + 2500\ \mathrm{N\,m}, \qquad
T_{CD} = 2500 - 1500 = + 1000\ \mathrm{N\,m}, \qquad
T_{DE} = 1000 - 1000 = 0 .
$$
**校核**：扭矩在最远端轴承处回到零，这是必然的，因为两个轴承都不传递扭矩。最大扭矩在 $B C$ 段，为 $2500\ \mathrm{N\,m}$。

**应力。** 由 $J = \pi \times 0.060^{4} / 32 = 1.2723 \times 10^{-6}\ \mathrm{m^{4}}$，
$$
\tau_{\max} = \frac{2500 \times 0.030}{1.2723 \times 10^{-6}} = 58.9\ \mathrm{MPa}.
$$
**$D$ 相对 $A$ 的扭转角。**
$$
\phi_{D / A} = \frac{1}{J G} \sum T_i L_i
= \frac{2500 \times 0.8 + 1000 \times 0.6}{1.2723 \times 10^{-6} \times 80 \times 10^{9}}
= \frac{2600}{101.8} = 0.02554\ \mathrm{rad} = 1.46^{\circ} .
$$
**合理性。** 机器轴通常限制每米扭转约 $1^{\circ}$ 或切应力约 $56\ \mathrm{MPa}$。此轴在最不利截面的扭转率为 $2500 / (J G) = 0.0246\ \mathrm{rad / m} = 1.41^{\circ} / \mathrm{m}$，应力达到 $58.9\ \mathrm{MPa}$，两项准则都略微不满足。它更多是**强度**问题而非刚度问题，解决办法是加大直径或改善齿轮轴肩处的圆角——决定寿命的是那里的应力集中，而不是名义的 $58.9\ \mathrm{MPa}$。另请注意最大扭矩位于**最长**的一段，这是最糟糕的布置：把输入齿轮放在跨中而非一端，可使最大扭矩和扭转角都减半。
:::
:::

::: example 空心与实心 {#ex-hollow}
一直径 $50\ \mathrm{mm}$ 的实心钢轴承受 $1200\ \mathrm{N\,m}$。拟用外径 $60\ \mathrm{mm}$ 的空心轴替换它，在相同最大应力下传递相同扭矩。求内径和减重比例。
::: solution
实心轴的应力为
$$
\tau = \frac{16 \times 1200}{\pi \times 0.050^{3}} = 48.9\ \mathrm{MPa}.
$$
令空心轴的 $T c / J$ 与之相等，
$$
J_{\text{req}} = \frac{T \left( D_o / 2 \right)}{\tau}
= \frac{1200 \times 0.030}{48.9 \times 10^{6}} = 7.362 \times 10^{-7}\ \mathrm{m^{4}},
$$
$$
D_i^{4} = D_o^{4} - \frac{32 J_{\text{req}}}{\pi}
= 1.296 \times 10^{-5} - 7.507 \times 10^{-6} = 5.453 \times 10^{-6}
\quad\Longrightarrow\quad
D_i = 48.3\ \mathrm{mm}, \quad \frac{D_i}{D_o} = 0.806 .
$$
面积比为
$$
\frac{A_{\text{空心}}}{A_{\text{实心}}} = \frac{60^{2} - 48.3^{2}}{50^{2}} = \frac{3600 - 2333}{2500} = 0.507 ,
$$
即在相同应力、相同扭矩下**减重 $49$ 个百分点**。

**合理性。** 空心轴还更刚：$J$ 从 $6.14 \times 10^{-7}$ 升到 $7.36 \times 10^{-7}\ \mathrm{m^{4}}$，重量减半而刚度多 $20$ 个百分点，因为从中间挖掉的材料几乎什么都没干——半径 $\rho$ 处的切应力正比于 $\rho$，所以半径的内半部分承受的应力不到表面的四分之一，对以 $\rho^{3}$ 加权的 $J$ 贡献更小。这就是所有值回票价的旋转轴都是空心的原因：传动轴、钻杆、自行车中轴轴心和涡轮转子都把中间钻空。限制在于要能穿过芯轴、开键槽装齿轮，或让流体或电缆从孔中通过。
:::
:::

::: proposition 扭转的应变能 {#prop-torsion-energy}
长 $L$、承受扭矩 $T$ 的轴储存
$$
U = \frac{T^{2} L}{2 G J} = \frac{\tau_{\max}^{2}}{4 G} \times (\text{体积}),
$$
所以**剪切回弹模量**（单位体积）为 $u = \tau_y^{2} / (4 G)$——在相同限制应力下，是轴向加载值的一半。
:::

::: proof
与轴向加载同样的论证，扭矩从零增长到 $T$、转过 $\phi = T L / J G$ 所做的功为
$$
U = \tfrac{1}{2} T \phi = \frac{T^{2} L}{2 G J} .
$$
代入 $T = \tau_{\max} J / c$，并把 $L$ 写成体积除以面积，得
$$
U = \frac{\tau_{\max}^{2} J L}{2 G c^{2} A} = \frac{\tau_{\max}^{2}}{4 G} (A L)
$$
其中用了实心或空心圆截面的 $J / (A c^{2}) = \tfrac{1}{2}$——正是这个因子使剪切回弹能为轴向的一半。这一结果是**扭杆弹簧**的设计基础：它在一根绕自身轴线扭转的直杆中储存剪切能，这就是军用车辆、赛车和坦克悬挂用受扭直杆而不用螺旋弹簧的原因——弹簧就是结构本身，不需要导向，还可以埋进车体。
:::

::: example 扭杆弹簧 {#ex-torsion-bar}
一直径 $25\ \mathrm{mm}$、长 $1.2\ \mathrm{m}$ 的扭杆用 $\tau_y = 500\ \mathrm{MPa}$、$G = 80\ \mathrm{GPa}$ 的弹簧钢制成。求屈服时的扭转角和储存的能量。
::: solution
$$
\phi_y = \frac{\tau_y L}{G c} = \frac{500 \times 10^{6} \times 1.2}{80 \times 10^{9} \times 0.0125}
= 0.600\ \mathrm{rad} = 34.4^{\circ},
$$
$$
u = \frac{\tau_y^{2}}{4 G} = \frac{(500 \times 10^{6})^{2}}{4 \times 80 \times 10^{9}} = 781\ \mathrm{kJ / m^{3}},
\qquad
V = \frac{\pi \times 0.025^{2}}{4} \times 1.2 = 5.89 \times 10^{-4}\ \mathrm{m^{3}},
$$
$$
U = 781 \times 10^{3} \times 5.89 \times 10^{-4} = 460\ \mathrm{J}.
$$
**合理性。** $34^{\circ}$ 的弹性扭转角是巨大的，而它之所以可得，只因为杆细长：应变为 $\tau / G = 0.00625$，在该应变下，长 $1.2\ \mathrm{m}$、直径 $25\ \mathrm{mm}$ 的杆可以转过半弧度多。$781\ \mathrm{kJ / m^{3}}$ 的能量密度相当可观——同钢种的螺旋弹簧每单位重量约能达到 $1.5$ 倍，因为螺旋弹簧同时利用扭转**和**剪切、几乎让整个丝杠都工作在最大应力附近，而扭杆浪费了它的核心。
:::
:::

## 超静定轴

::: algorithm 超静定轴的解法 {#alg-shaft-indet}
1. 在平衡允许的范围内画出**扭矩图**。若端部约束力偶（墙体扭矩）比平衡方程多出 $n$ 个，轴即为 $n$ 次超静定。
2. **解除** $n$ 个约束：切开轴，或用施加的扭矩 $T_0$ 代替一个固定端。
3. 计算每个解除处由外加扭矩和由单位多余力偶所产生的**扭转角**。
4. **施加协调条件**：固定端 $\phi = 0$；连到刚性法兰上的组合轴两段的扭转角相等；弹簧支承处 $\phi = T / k_\theta$。
5. 求解，然后求出扭矩图、应力和扭转角。
:::

::: example 两端固定的轴 {#ex-shaft-fixed}
一均质钢轴直径 $50\ \mathrm{mm}$、总长 $1.2\ \mathrm{m}$，两端嵌入刚性墙。距左墙 $0.4\ \mathrm{m}$ 处的套箍上施加扭矩 $800\ \mathrm{N\,m}$。求两端墙体扭矩和最大应力。
::: solution
**平衡。** $T_A + T_B = 800\ \mathrm{N\,m}$——一个方程，两个未知数。

**协调。** 两墙都不转动，所以左段的扭转角等于右段的（符号相反的）扭转角：
$$
\frac{T_A \times 0.4}{J G} = \frac{T_B \times 0.8}{J G}
\quad\Longrightarrow\quad
T_A = 2 T_B .
$$
于是 $3 T_B = 800$，
$$
T_B = 266.7\ \mathrm{N\,m}, \qquad T_A = 533.3\ \mathrm{N\,m}.
$$
最大应力在左段，
$$
\tau_{\max} = \frac{16 \times 533.3}{\pi \times 0.050^{3}} = 21.7\ \mathrm{MPa}.
$$
**校核。** $\phi_{\text{套箍}} = 533.3 \times 0.4 / (5.896 \times 10^{-7} \times 80 \times 10^{9}) = 4.51 \times 10^{-3}\ \mathrm{rad} = 0.258^{\circ}$，而右段反向扭转 $266.7 \times 0.8 / (J G) = 4.51 \times 10^{-3}\ \mathrm{rad}$，所以右墙没有转动。$\checkmark$

**合理性。** 与上一章的轴向杆一样，较短较刚的一段承担更多载荷——这里是两倍，等于长度反比之比。这就是为什么带中间轴承或墙体处联轴器的轴必须按长度精加工：比设计长度短 $1\ \mathrm{mm}$ 的一段会按更大比例承担扭矩，而且即使不施加任何外载，整个组件中也会出现残余预扭转。
:::
:::

::: example 圆形与方形 {#ex-round-square}
比较横截面**面积相同**的实心圆轴和正方形截面杆承受相同扭矩的情形。哪个更强，哪个更刚？
::: solution
对边长 $a$ 的正方形，精确弹性解给出
$$
J_{\square} = 0.1406\, a^{4}, \qquad \tau_{\square} = \frac{2.40\, T}{a^{3}} .
$$
按面积相等，$a^{2} = \pi d^{2} / 4$ 得 $d = 1.128\, a$，于是圆截面有
$$
J_{\bigcirc} = \frac{\pi d^{4}}{32} = 0.1589\, a^{4}, \qquad
\tau_{\bigcirc} = \frac{16 T}{\pi d^{3}} = \frac{3.55\, T}{a^{3}} .
$$
**刚度：** $J_{\bigcirc} / J_{\square} = 0.1589 / 0.1406 = 1.13$，圆轴刚 $13$ 个百分点。
**强度：** $\tau_{\square} / \tau_{\bigcirc} = 2.40 / 3.55 = 0.68$，方轴在相同峰值应力下多承担 $48$ 个百分点的扭矩。

**合理性。** 这个结果违反直觉，值得细想。方形的角是不受力的——棱柱杆扭转时，无凹角的凸角处切应力精确为零，这是弹性理论的一个定理——所以角是浪费的材料，但方形截面的材料比同面积的圆形平均离形心更远，这一点占了上风。教训狭窄而重要：圆是扭转中每单位重量**刚度**的最优解，不是强度的最优解，而当轴还必须通过平面或键槽传递扭矩时，方形或六边形截面是合理的选择。在弯曲中它则**绝不**最优：圆截面的材料平均离中性轴比方形的近，工字形截面在弯曲中完胜。
:::
:::

## 薄壁闭口截面

::: theorem 薄壁闭口管的 Bredt 公式 {#thm-bredt}
对任意闭口横截面、壁厚 $t$ 的薄壁管，**剪流** $q = \tau t$ 沿截面为常数，且等于
$$
q = \frac{T}{2 A}, \qquad \tau = \frac{T}{2 t A},
$$
其中 $A$ 是壁中线**所围**的面积。单位长度扭转角为
$$
\theta = \frac{T}{4 A^{2} G} \oint \frac{\mathrm{d} s}{t} .
$$
对平均半径 $r$、壁厚均匀的圆管，这些公式给出 $\tau = T / (2 \pi r^{2} t)$ 和 $J = 4 \pi r^{3} t$，正是 $\pi (D_o^{4} - D_i^{4}) / 32$ 的薄壁极限。
:::

::: proof
因为壁薄，可认为切应力沿壁厚均匀并沿中线方向。考虑在两个横向截面和 $s_1$、$s_2$ 处两条纵向切口之间切出的长度为 $\mathrm{d} z$ 的管段。该管段沿 $z$ 方向的平衡要求纵向合力为零；由于闭口截面不发生翘曲（单连通的闭口管要不撕裂壁面就无法翘曲），纵向应力为零，进出任一微元的剪流必须平衡：
$$
q(s_1) = q(s_2) \quad\Longrightarrow\quad q = \tau t = \text{常数}.
$$
这就是 **Bredt 第一公式**。扭矩是这常数剪流对任一内点的矩；沿微元 $\mathrm{d} s$ 作用的剪流 $q$ 贡献 $q \cdot r\, \mathrm{d} s$，而 $r\, \mathrm{d} s = 2\, \mathrm{d} A$，所以
$$
T = \oint q r\, \mathrm{d} s = 2 q \oint \mathrm{d} A = 2 q A
\quad\Longrightarrow\quad
q = \frac{T}{2 A},
$$
这就是 Bredt 的第二个结果。对扭转角，令单位长度的余能 $\oint q^{2} \mathrm{d} s / (2 G t)$ 等于 $T \theta / 2$，或沿中线积分切应变 $\gamma = q / (G t)$ 并要求总转角单值：
$$
\theta \oint \frac{\mathrm{d} s}{t} = \oint \frac{q}{G t}\, \mathrm{d} s \times \ldots
$$
得 $\theta = q / (2 A G) \oint \mathrm{d} s / t = T / (4 A^{2} G) \oint \mathrm{d} s / t$。
:::

::: example 闭口与开缝 {#ex-slit}
一飞机板件由平均直径 $80\ \mathrm{mm}$、壁厚 $3\ \mathrm{mm}$ 的管制成，承受 $1500\ \mathrm{N\,m}$。求切应力和扭转刚度，并与沿一条母线剖开的同一根管比较。
::: solution
**闭口。** 所围面积 $A = \pi \times 0.040^{2} = 5.027 \times 10^{-3}\ \mathrm{m^{2}}$，所以
$$
\tau = \frac{1500}{2 \times 0.003 \times 5.027 \times 10^{-3}} = 49.7\ \mathrm{MPa},
$$
$$
J_{\text{闭口}} = \frac{4 A^{2}}{\oint \mathrm{d} s / t}
= \frac{4 A^{2} t}{2 \pi r} = \frac{4 \times 2.527 \times 10^{-5} \times 0.003}{0.2513}
= 1.206 \times 10^{-6}\ \mathrm{m^{4}} .
$$
**开缝。** 对由长 $s = 2 \pi r$、厚 $t$ 的一条薄板条组成的薄开口截面，
$$
J_{\text{开口}} = \frac{1}{3} s t^{3} = \frac{1}{3} \times 0.2513 \times 27 \times 10^{-9}
= 2.262 \times 10^{-9}\ \mathrm{m^{4}},
$$
$$
\tau_{\text{开口}} = \frac{3 T t}{s t^{3}} = \frac{3 T}{s t^{2}}
= \frac{3 \times 1500}{0.2513 \times 9 \times 10^{-6}} = 1989\ \mathrm{MPa}.
$$
闭口管的刚度是开缝管的 **$533$ 倍**，应力只有其 **$1 / 40$**。

**合理性。** 对这一几何，刚度之比为 $3 (2 r / t)^{2} / \pi^{2} \approx 533$，且它随径厚比的平方增长——这就是为什么飞机机身框、传动轴、扭杆和防滚架环都是**闭口**截面，为什么钻孔或开槽的管是一场灾难，为什么不能承受剪流的长桁-蒙皮接头会把闭口机身变成开口机身、使扭转角增大数百倍。薄壁受扭构件中最要紧的一个几何决定，就是截面闭口还是不闭口。
:::

caption: 例 6 闭口管的切应力 $\tau = T / (2 t A)$ 随壁厚从 $2$ 到 $6\ \mathrm{mm}$ 的变化：$2\ \mathrm{mm}$ 时 $74.6\ \mathrm{MPa}$，$3\ \mathrm{mm}$ 时 $49.7\ \mathrm{MPa}$，$6\ \mathrm{mm}$ 时 $24.9\ \mathrm{MPa}$。应力与壁厚成反比，而对实心轴它与直径的立方成反比——所以薄壁设计在板厚上线性而宽容，但在比值 $r / t$ 上残酷，因为到那个比值时，壁会在斜向压力下远远早于剪切屈服而屈曲。

::: warning 键槽、轴肩与疲劳
键槽从切应力最大的表面挖去材料，并留下一个尖角，其扭转应力集中因数为 $1.6$ 到 $2.2$，弯曲下可达 $3$。因此轴的设计惯例是：先按弯扭组合并计入疲劳因数初选轴径，再为键槽加大 $5$ 到 $10\ \mathrm{mm}$，然后校核挠度和齿轮处的转角。横向销孔更糟，$K_t$ 接近 $2.5$，弹性挡圈槽还要糟。典型的失效是：轴在中段完全够用，却在一百万次循环后在圆角处断裂，断口上显示出从圆角根部放射的海滩状条纹。圆角半径至少应为 $0.04 d$，最好是 $0.1 d$；安装轴承处，轴肩要足够高以定位轴承、又要圆角足够大以免使轴开裂，这就是轴承样本给出最小圆角半径和最大轴肩高度的原因，也是忽视其中任何一项都是设计错误而非个人偏好的原因。
:::

::: history
圆截面轴的扭转是力学中最古老的已解问题之一，而它的解答先于为它提供依据的理论出现。夏尔-奥古斯丁·德·库仑（Charles-Augustin de Coulomb）在 1784 年向法国科学院宣读了关于金属丝扭转的论文——他此前已用扭秤测量了使他成名的静电力和磁力——并从拧丝试验中陈述了切应力沿截面线性变化和抗力与直径四次方成正比这两个 $J \propto D^{4}$ 背后的实验事实。第一个严格的弹性解归功于柯西（Cauchy），以及更明确地归功于泊松（Poisson）——他在 1812 年把扭转作为弹性力学的边值问题处理——还有纳维（Navier），他用他们共同发明的应力函数法求解了它。该方法给出圆截面的精确解，并立刻表明非圆截面为什么会翘曲；椭圆和等边三角形的扭转常数归功于圣维南（Saint-Venant），他 1855 年还陈述了那个解释"键槽附近的精确解为何在一个直径之外就无关紧要"的原理。薄壁闭口截面的 Bredt 公式归功于 Rudolf Bredt（1885 年），而它在第一次世界大战后被飞机设计采纳——当时受力蒙皮硬壳结构使闭口剪切腹板成为主承力结构——这就是它出现在每一本航空教材、却几乎不出现在任何土木教材中的原因。库仑使用的扭秤被约翰·米歇尔（John Michell）和卡文迪什（Cavendish）改进，于 1798 年称量了地球；一个世纪后查尔斯·弗农·博伊斯（Charles Vernon Boys）又用它测量了 $G$ 本身，这仍是有史以来解决过的最精密的扭转问题。
:::

::: quiz
两根同材料、每米重量相同的轴受扭：轴 1 是直径 $d$ 的实心轴；轴 2 是外径 $2 d$ 的管。在相同最大应力下哪个承受更大扭矩？
- [ ] 轴 1，因为它是实心的
- [ ] 两者相同，因为它们一样重
- [x] 轴 2，且多得多
- [ ] 不知道长度就无法判断
::: solution
轴 2。每米重量相同意味着面积相同，$\pi (D_o^{2} - D_i^{2}) / 4 = \pi d^{2} / 4$，由 $D_o = 2 d$ 得 $D_i = \sqrt{3} d$。扭矩容量正比于 $J / c = \pi (D_o^{4} - D_i^{4}) / (16 D_o) = \pi (16 - 9) d^{4} / (32 d) = 0.2188 \pi d^{3}$，而实心轴为 $\pi d^{3} / 16 = 0.0625 \pi d^{3}$——相差 $3.5$ 倍。原因在于 $J$ 以 $\rho^{3}$ 加权，而应力限制定在 $\rho = c$ 处：把材料往外移远比把它留在里面值钱。极限是壁的屈曲，这就是真实空心轴采用 $0.6$ 到 $0.85$ 而不是 $0.87$ 的直径比的原因。
:::
:::

## 后续内容

弯扭组合下的轴的设计在 [[machine-design/shafts]] 中展开，键槽的疲劳后果在 [[machine-design/fatigue]] 中，用于超静定轴的能量法在 [[solid-mechanics/energy-methods]] 中，一般棱柱截面的扭转（应力函数法）也在 [[solid-mechanics/energy-methods]] 中。薄壁剪流贯穿飞机与车辆车体结构，而 [[mechanics-of-materials/transverse-shear]] 中的类似剪流是同一个数学对象。

::: summary
- $\tau = T \rho / J$ 和 $\phi = T L / J G$ 只对圆截面轴精确；实心圆 $J = \pi D^{4} / 32$，圆管 $\pi (D_o^{4} - D_i^{4}) / 32$。
- 扭矩来自功率和转速，$T = 9549 \, \mathcal{P} / n$；功率一定时，扭矩从而轴的尺寸与转速成反比。
- 从自由端画扭矩图；最大应力在扭矩图的峰值处，扭转角是各 $T_i L_i / J G$ 之和。
- 空心轴远比实心轴高效，因为应力和 $J$ 的贡献都在轴心处为零；直径比 $0.8$ 的管在相同应力下省下一半重量。
- 超静定轴用扭转角协调求解；较短较刚的一段承担较大份额。
- 对薄壁，闭口截面远优于开口截面：Bredt 公式给出 $\tau = T / (2 t A)$，其刚度是同一截面开缝后的数百倍。
:::

## 习题

::: exercise 应力 {level=1 check="41.0"}
求承受 $516\ \mathrm{N\,m}$ 的直径 $40\ \mathrm{mm}$ 实心轴的最大切应力。
::: solution
$\tau = 16 T / (\pi D^{3}) = 16 \times 516 / (\pi \times 0.040^{3}) = 41.0\ \mathrm{MPa}$。
**用抗扭截面系数校核。** $J / c = \pi \times 0.040^{3} / 16 = 1.257 \times 10^{-5}\ \mathrm{m^{3}}$，所以 $\tau = 516 / 1.257 \times 10^{-5} = 41.0\ \mathrm{MPa}$。$\checkmark$
:::
:::

::: exercise 由功率求扭矩 {level=1 check="955"}
$15\ \mathrm{kW}$ 电机在 $150\ \mathrm{rev / min}$ 下输出多大扭矩？
::: solution
$T = 9549 \times 15 / 150 = 955\ \mathrm{N\,m}$。同一电机经 $10:1$ 减速器在 $15\ \mathrm{rev / min}$ 下输出 $9550\ \mathrm{N\,m}$，这就是卷扬机齿轮箱输出轴直径数倍于电机电枢轴的原因。
:::
:::

::: exercise 扭转角 {level=1 check="1.30"}
一钢轴直径 $30\ \mathrm{mm}$、长 $800\ \mathrm{mm}$（$G = 80\ \mathrm{GPa}$），承受 $180\ \mathrm{N\,m}$。求扭转角（度）。
::: solution
$J = \pi \times 0.030^{4} / 32 = 7.952 \times 10^{-8}\ \mathrm{m^{4}}$，
$$
\phi = \frac{180 \times 0.8}{7.952 \times 10^{-8} \times 80 \times 10^{9}} = 2.263 \times 10^{-2}\ \mathrm{rad} = 1.30^{\circ}.
$$
**注。** 这相当于每米 $1.63^{\circ}$，超过了常用的 $1^{\circ} / \mathrm{m}$ 使用限值，所以尽管其应力 $34.0\ \mathrm{MPa}$ 低得微不足道，这根轴对机床来说还是太小了。细长轴是刚度问题。
:::
:::

::: exercise 空心轴 {level=2}
一 $D_i / D_o = 0.6$ 的空心轴，在相同最大应力下传递与同材料实心轴相同的扭矩。它的重量是后者的几分之几？扭转刚度呢？
::: solution
应力相等意味着 $J / c$ 相等：
$$
\frac{\pi D_o^{4} (1 - k^{4})}{16 D_o} = \frac{\pi d^{3}}{16}
\quad\Longrightarrow\quad
D_o^{3} (1 - k^{4}) = d^{3}, \qquad k = 0.6,
$$
$$
D_o = d \left( 1 - 0.1296 \right)^{-1/3} = d \times 1.0466 .
$$
重量比：
$$
\frac{A_h}{A_s} = \frac{D_o^{2} (1 - k^{2})}{d^{2}} = 1.0466^{2} \times 0.64 = 0.701 .
$$
刚度比，由 $D_o^{4} / d^{4} = 1.0466^{4} = 1.200$：
$$
\frac{J_h}{J_s} = \frac{D_o^{4} (1 - k^{4})}{d^{4}} = 1.200 \times 0.8704 = 1.044 .
$$
所以空心轴**轻 $30$ 个百分点**，且在相同最大应力下**刚 $4$ 个百分点**。
:::
:::

::: exercise 超静定轴 {level=2}
对例 5 的轴，把外加扭矩移到距左墙 $0.8\ \mathrm{m}$ 处。求两端墙体扭矩。
::: solution
协调条件给出 $T_A \times 0.8 = T_B \times 0.4$，即 $T_B = 2 T_A$，结合 $T_A + T_B = 800$，
$$
T_A = 266.7\ \mathrm{N\,m}, \qquad T_B = 533.3\ \mathrm{N\,m}.
$$
两个扭矩互换，最大应力仍是 $21.7\ \mathrm{MPa}$，因为较大的扭矩总是属于较短的一段。
:::
:::

::: exercise 闭口截面 {level=2}
一矩形闭口管中线尺寸 $100 \times 60\ \mathrm{mm}$、壁厚 $4\ \mathrm{mm}$，承受 $2000\ \mathrm{N\,m}$。取 $G = 70\ \mathrm{GPa}$，求切应力和每米扭转角。
::: solution
$A = 0.100 \times 0.060 = 6.0 \times 10^{-3}\ \mathrm{m^{2}}$，所以
$$
\tau = \frac{2000}{2 \times 0.004 \times 6.0 \times 10^{-3}} = 41.7\ \mathrm{MPa},
$$
$$
\oint \frac{\mathrm{d} s}{t} = \frac{2 (0.100 + 0.060)}{0.004} = 80\ \mathrm{m^{-1}}, \qquad
\theta = \frac{2000}{4 \times 3.6 \times 10^{-5} \times 70 \times 10^{9}} \times 80 = 1.587 \times 10^{-4}\ \mathrm{rad / m} = 0.0091^{\circ} / \mathrm{m}.
$$
**合理性。** 因为壁厚均匀，应力沿壁处处相同；壁加厚处应力按比例下降，剪流保持不变。$q$ 的这个恒定性正是闭口截面如此高效的原因，也是加厚拐角对扭转强度毫无用处的原因——只有在屈曲或安装接头需要时才值得加厚。
:::
:::

::: exercise 设计 {level=3}
设计一根传递 $30\ \mathrm{kW}$、$960\ \mathrm{rev / min}$ 的实心钢轴的直径，许用切应力 $55\ \mathrm{MPa}$，扭转角限值每米 $1^{\circ}$。取 $G = 80\ \mathrm{GPa}$，为键槽预留 $8\ \mathrm{mm}$。
::: solution
$$
T = 9549 \times \frac{30}{960} = 298.4\ \mathrm{N\,m}.
$$
**强度准则。**
$$
D = \left( \frac{16 T}{\pi \tau_{\text{allow}}} \right)^{1/3}
= \left( \frac{16 \times 298.4}{\pi \times 55 \times 10^{6}} \right)^{1/3}
= 28.0\ \mathrm{mm}.
$$
**刚度准则。** 取 $\theta_{\text{allow}} = 0.01745\ \mathrm{rad / m}$，
$$
J_{\text{req}} = \frac{T}{G \theta} = \frac{298.4}{80 \times 10^{9} \times 0.01745} = 2.139 \times 10^{-7}\ \mathrm{m^{4}}
\quad\Longrightarrow\quad
D = \left( \frac{32 J}{\pi} \right)^{1/4} = 34.5\ \mathrm{mm}.
$$
刚度控制。为键槽加 $8\ \mathrm{mm}$ 得 $42.5\ \mathrm{mm}$；选取标准直径 $45\ \mathrm{mm}$ 的轴。

**设计点评。** 是刚度限值定了尺寸，而两项准则的接近程度值得注意：在 $34.5\ \mathrm{mm}$ 处应力只有 $36.5\ \mathrm{MPa}$，比许用值低三分之一。机器轴几乎总是由刚度或变形控制而非强度控制，因为齿轮和轴承只能容忍千分之几弧度的偏斜，否则载荷就会跑到齿端之外。只按应力选轴的设计师，得到的是一根能转的轴和一台嚎叫的齿轮箱。
:::
:::

::: exercise 推导 {level=3}
由变形几何、胡克定律和平衡推导扭转公式 $\tau = T \rho / J$，并陈述每一条假定。
::: solution
**假定：** 圆截面、均匀各向同性线弹性材料、棱柱轴、纯扭矩、小位移，以及（待验证的）横截面保持平面。

**几何。** 设长 $L$ 的轴扭转 $\phi$，每个横截面像刚性圆盘一样转动。半径 $\rho$ 处的点周向移动 $\rho \phi$，所以微元的角畸变为
$$
\gamma = \frac{\rho \phi}{L},
$$
它关于 $\rho$ 线性，在轴线上为零。

**物理。** 纯剪切下胡克定律给出 $\tau = G \gamma$，于是
$$
\tau = \frac{G \phi}{L} \rho,
$$
同样关于 $\rho$ 线性，表面处 $\tau_{\max} = G \phi c / L$。

**平衡。** 内力偶矩必须等于外加扭矩：
$$
T = \int_A \tau \rho\, \mathrm{d} A = \frac{G \phi}{L} \int_A \rho^{2}\, \mathrm{d} A = \frac{G \phi}{L} J .
$$
在应力表达式和扭矩表达式之间消去 $\phi / L$ 得 $\tau = T \rho / J$，把扭矩表达式改写即得 $\phi = T L / J G$。

**验证。** 剩下的问题是：所设定位移场是否满足边界条件——圆柱面上无面力。因为切应力处处周向，而表面是旋转面，$\tau$ 与表面相切、其法向没有面力：该场是精确的。对非圆截面，类似的位移会在边界上要求面力，这就是这类截面要翘曲的原因，也是圆是唯一能用这三行论证求解的情形。正是这一次验证，是轴做成圆形的原因，也是花键轴或铣扁轴必须作为 $J$ 折减的非圆截面处理的原因。
:::
