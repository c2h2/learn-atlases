轴就是机器的化身：电动机、泵、压缩机、齿轮箱、涡轮机和螺旋桨的中心都有一根轴，轴把功率从源头传送到负载。**一根轴失效不只是自身断裂；它还会毁掉轴承、齿轮、密封件和箱体，而这种破坏正是轴成为机器中最关键零件的原因。**轴的设计是一个多约束优化问题：轴必须足够强，以承受扭转和弯曲；足够刚，以限制挠度和轴承处的转角；并且动力稳定性足够好，以避开临界转速。**按强度定尺寸的轴往往刚度不足；按刚度定尺寸的轴往往强度不足；而按临界转速定尺寸的轴往往不是最便宜的。**

轴设计的定量工具是 **ASME 轴方程**（弯扭组合加上冲击与疲劳系数）、**挠度计算**（轴承转角与齿轮挠度的叠加）、**临界转速计算**（瑞利（Rayleigh）法与邓克莱（Dunkerley）法）以及**键槽应力集中**（键槽和轴肩圆角处的 $K _ { t }$）。这些工具就是表达轴设计决策的语言，而这套语言正是轴设计是计算而非猜测的原因。

::: warning 轴设计出错的九种方式
**不校核挠度。**按强度准则定尺寸却不校核挠度的工程师，设计的不是轴，而是一根强度试验试样。**按强度定尺寸的轴往往柔度过大 30–50 %，而这种柔性正是齿轮啮合噪声大、轴承寿命短、密封件泄漏的原因。** **不考虑键槽处的应力集中。**在键槽处计算名义应力却不乘应力集中系数的工程师，设计的不是键槽，而是名义截面。**键槽的 $K _ { t }$ 扭转时为 1.5–2.5，弯曲时为 2.0–3.5，而这个放大倍数正是轴在键槽处而不是在跨中失效的原因。** **不校核临界转速。**设计轴却不校核临界转速的工程师，设计的不是轴，而是一只会响的汽笛。**工作转速处于临界转速 80–120 % 的轴会发生共振，而共振正是这种轴几分钟内而不是几年内失效的原因。** **不考虑轴肩圆角。**设计轴肩却不给圆角半径的工程师，设计的不是轴肩，而是一个裂纹引发源。**轴肩圆角的 $K _ { t }$ 弯曲时为 1.5–3.0，而这个放大倍数正是轴在轴肩处而不是在跨中失效的原因。** **不校核轴承处转角。**设计轴却不校核轴承处转角的工程师，设计的不是轴，而是一次轴承失效。**球轴承处转角必须小于 0.5°（0.0087 rad），圆柱滚子轴承处必须小于 0.25°（0.0044 rad），而这个限值正是轴按刚度而不是强度定尺寸的原因。** **不考虑键的剪切与挤压。**把轴按疲劳准则设计却不校核键的剪切和挤压的工程师，设计的不是键，而是一次键失效。**键是轴的保险丝：键被设计成先于轴失效，而保险丝正是键按剪切和挤压而不是按疲劳定尺寸的原因。** **不考虑轴向力。**把轴按扭转和弯曲设计却不考虑轴向推力的工程师，设计的不是轴，而是一次轴承失效。**轴向推力由推力轴承或轴肩承受，而轴肩必须按推力而不只是按弯曲定尺寸。** **不校核齿轮处的挠度。**只校核跨中挠度而不校核齿轮处挠度的工程师，设计的不是轴，而是一次齿轮失效。**精密齿轮处的挠度必须小于 0.05 mm，普通齿轮处必须小于 0.1 mm，而这个限值正是轴按齿轮处挠度而不是跨中挠度定尺寸的原因。** **不记录轴的设计文件。**设计轴却不记录载荷图、弯矩图、挠度图和临界转速计算的工程师，不是在轴设计，而是在瞎猜。**这些文件正是轴的设计在设计评审和法庭上站得住脚的原因。**
:::

## 1. 轴的载荷与 ASME 轴方程

::: definition 轴的载荷图与弯矩图 {#def-shaft-loading}
轴承受**扭转**（功率传输）、**弯曲**（齿轮、带轮和链轮的力）和**轴向推力**（斜齿轮、锥齿轮和螺旋桨）。载荷图就是轴的受力图（分离体图），而载荷图是弯矩图的输入。

$$
\begin{array} { l l l l }
\textbf{载荷类型} & \textbf{来源} & \textbf{应力类型} & \textbf{图形} \\ \hline
\text{扭转 } ( T ) & \text{功率传输} & \text{切应力 } ( \tau = 1 6 T / \pi d ^ { 3 } ) & \text{带轮之间为常数} \\
\text{弯曲 } ( M ) & \text{齿轮、带轮、链轮} & \text{正应力 } ( \sigma = 3 2 M / \pi d ^ { 3 } ) & \text{支座之间为线性} \\
\text{轴向 } ( F ) & \text{斜齿轮、螺旋桨} & \text{正应力 } ( \sigma = 4 F / \pi d ^ { 2 } ) & \text{推力面之间为常数} \\
\end{array}
$$

**载荷图是轴的设计中最重要的文件，因为载荷图是弯矩图的输入，而弯矩图是轴径计算的输入。不画载荷图就设计轴的工程师不是在轴设计，而是在瞎猜。**
:::

::: definition ASME 轴方程 {#def-asme-shaft}
**ASME 轴方程**（ASME B106.1M）是轴承受弯扭组合作用的设计方程：

$$
d \; = \; \left( { \frac { 1 6 n } { \pi } } \right) ^ { 1 / 3 } \left[ { \frac { \sqrt { 4 ( K _ { b } M ) ^ { 2 } + 3 ( K _ { t } T ) ^ { 2 } } } { S _ { e } } } + { \frac { \sqrt { 3 ( K _ { t } T ) ^ { 2 } } } { S _ { y } } } \right] ^ { 1 / 3 }
$$

简化情形（稳定载荷，$K _ { b } = K _ { t } = 1$ ）：

$$
d \; = \; \left( { \frac { 1 6 n } { \pi \, S _ { \text{allow } } } } \right) ^ { 1 / 3 } \, { \sqrt { M ^ { 2 } + T ^ { 2 } } } ^ { 1 / 3 }
$$

其中 $n$ 是安全因数，$M$ 是弯矩，$T$ 是扭矩，$S _ { \text{allow } }$ 是许用应力。

$$
\begin{array} { l c c }
\textbf{载荷类型} & \textbf{ } K _ { b } \textbf{（弯曲）} & \textbf{ } K _ { t } \textbf{（扭转）} \\ \hline
\text{平稳、稳定} & 1 . 0 & 1 . 0 \\
\text{轻微冲击} & 1 . 5 & 1 . 5 \\
\text{较重冲击} & 2 . 0 & 1 . 5 \text{--} 2 . 0 \\
\text{强烈冲击} & 2 . 5 \text{--} 3 . 0 & 2 . 0 \text{--} 3 . 0 \\
\end{array}
$$

**ASME 轴方程正是轴按弯扭组合而不是按单独扭转或单独弯曲定尺寸的原因。只按扭转定尺寸轴的工程师不是在轴设计，而是在设计一根扭转试验试样。**
:::

::: definition 键槽应力集中 {#def-keyway-kt}
**键槽**是轴中最常见的应力集中源，因为键槽是把扭矩从轴传向齿轮、带轮和联轴器最常用的方式。

$$
\begin{array} { l c c c }
\textbf{键槽类型} & \textbf{ } K _ { t } \textbf{（弯曲）} & \textbf{ } K _ { t } \textbf{（扭转）} & \textbf{ } K _ { f } \textbf{（典型）} \\ \hline
\text{普通键槽（方头）} & 2 . 0 \text{--} 2 . 5 & 1 . 5 \text{--} 2 . 0 & 1 . 5 \text{--} 2 . 0 \\
\text{盘铣键槽（圆头）} & 1 . 5 \text{--} 2 . 0 & 1 . 3 \text{--} 1 . 6 & 1 . 3 \text{--} 1 . 6 \\
\text{指铣键槽} & 1 . 5 \text{--} 1 . 8 & 1 . 2 \text{--} 1 . 5 & 1 . 2 \text{--} 1 . 5 \\
\text{半圆键槽} & 1 . 8 \text{--} 2 . 2 & 1 . 4 \text{--} 1 . 7 & 1 . 4 \text{--} 1 . 7 \\
\end{array}
$$

**盘铣键槽的 $K _ { t }$ 低于普通键槽，因为盘铣键槽的圆头端部比普通键槽的方头端部有更大的圆角半径。把键槽由普通型改为盘铣型的工程师，把 $K _ { t }$ 降低 20–25 %，而这一降低正是盘铣键槽成为受疲劳载荷的轴的首选的原因。**
:::

:::

::: example 按 ASME 方程定轴径 {#ex-shaft-sizing level=3 check="4"}
某轴在 1 500 rpm 下传输 50 kW。轴承受弯矩 200 N·m 和扭矩 318 N·m。材料 $S _ { y } = 5 0 0$ MPa、$S _ { u t } = 8 0 0$ MPa。冲击系数 $K _ { b } = 1 . 5$、$K _ { t } = 1 . 5$。安全因数为 2.0。试计算轴径。

**当量弯矩：**

$$
M _ { e } \; = \; { \frac { 1 } { 2 } } \left[ K _ { b } M + \sqrt { ( K _ { b } M ) ^ { 2 } + ( K _ { t } T ) ^ { 2 } } \right]
$$

$$
M _ { e } \; = \; { \frac { 1 } { 2 } } \left[ 1 . 5 \times 2 0 0 + { \sqrt { ( 3 0 0 ) ^ { 2 } + ( 4 7 7 ) ^ { 2 } } } \right] \; = \; { \frac { 1 } { 2 } } [ 3 0 0 + 5 6 2 ] \; = \; 4 3 1 \ \text{N} { \cdot } \text{m}
$$

**许用应力：** $S _ { \text{allow } } = S _ { y } / n = 5 0 0 / 2 = 2 5 0$ MPa。

**轴径：**

$$
d \; = \; \left( { \frac { 3 2 \, M _ { e } } { \pi \, S _ { \text{allow } } } } \right) ^ { 1 / 3 } \; = \; \left( { \frac { 3 2 \times 4 3 1 \times 1 0 ^ { 3 } } { \pi \times 2 5 0 } } \right) ^ { 1 / 3 } \; = \; \left( { \frac { 1 . 3 8 \times 1 0 ^ { 7 } } { 7 8 5 . 4 } } \right) ^ { 1 / 3 } \; = \; ( 1 7 \ 5 6 8 ) ^ { 1 / 3 }
$$

$$
d \; = \; { \bf 2 6 } \ \text{mm}
$$

**轴径为 26 mm。工程师会选用 30 mm 的轴（下一个标准尺寸），而 30 mm 轴的安全因数为 2.4，超过 2.0 的设计因数。**
:::

## 2. 轴的挠度与刚度

::: definition 轴的挠度与轴承处转角 {#def-shaft-deflection}
**轴的挠度**是轴设计中最重要的刚度准则，因为挠度影响齿轮啮合、轴承寿命和密封性能。

$$
\begin{array} { l c l }
\textbf{准则} & \textbf{限值} & \textbf{原因} \\ \hline
\text{齿轮处挠度} & 0 . 0 2 5 \text{--} 0 . 0 5 \ \text{mm} & \text{齿轮啮合质量} \\
\text{齿轮端面处转角} & 0 . 0 0 1 \text{--} 0 . 0 0 2 \ \text{rad} & \text{齿轮啮合对位} \\
\text{球轴承处转角} & 0 . 0 0 8 7 \ \text{rad} \; ( 0 . 5 ^ { \circ } ) & \text{轴承寿命} \\
\text{滚子轴承处转角} & 0 . 0 0 4 4 \ \text{rad} \; ( 0 . 2 5 ^ { \circ } ) & \text{轴承寿命} \\
\text{密封处挠度} & 0 . 0 5 \ \text{mm} & \text{密封性能} \\
\end{array}
$$

**齿轮处的挠度**用叠加法计算：

$$
\delta _ { \text{gear } } \; = \; \sum _ { i } { \frac { P _ { i } \, a _ { i } ^ { 2 } \, b _ { i } ^ { 2 } } { 3 \, E \, I \, L } }
$$

其中 $P _ { i }$ 是载荷，$a _ { i }$ 和 $b _ { i }$ 是到两支座的距离，$E$ 是弹性模量，$I = \pi d ^ { 4 } / 6 4$ 是惯性矩，$L$ 是跨长。

**齿轮处的挠度正是轴按刚度而不是强度定尺寸的原因。按强度定尺寸的轴往往柔度过大 30–50 %，而这种柔性正是齿轮啮合噪声大、轴承寿命短的原因。**
:::

::: definition 临界转速与固有频率 {#def-critical-speed}
**临界转速**是轴的固有频率等于回转频率时的转速，而临界转速正是轴在几分钟内而不是几年内失效的原因。

$$
n _ { c } \; = \; { \frac { 1 } { 2 \pi } } \, { \sqrt { \frac { g } { \delta _ { \text{static } } } } } \quad \text{（单质量瑞利法）}
$$

其中 $\delta _ { \text{static } }$ 是质量所在处的静挠度。

**邓克莱法**（多质量情形）：

$$
{ \frac { 1 } { n _ { c } ^ { 2 } } } \; = \; { \frac { 1 } { n _ { 1 } ^ { 2 } } } + { \frac { 1 } { n _ { 2 } ^ { 2 } } } + \cdots + { \frac { 1 } { n _ { k } ^ { 2 } } }
$$

其中 $n _ { i }$ 是轴上只有质量 $i$ 时的临界转速。

$$
\begin{array} { l c l }
\textbf{工作转速} & \textbf{ } n / n _ { c } & \textbf{设计要求} \\ \hline
\text{亚临界} & < 0 . 7 & \text{安全，刚性轴} \\
\text{超临界} & > 1 . 4 & \text{安全，柔性轴} \\
\text{共振区} & 0 . 7 \text{--} 1 . 4 & \text{不安全，必须避开} \\
\end{array}
$$

**轴必须在其一阶临界转速的 70 % 以下或 140 % 以上工作。把工作转速设计在临界转速 80–120 % 的工程师不是在轴设计，而是在设计一只会响的汽笛。**
:::

labels: Steel (E=207 GPa); Aluminium (E=71 GPa)
caption: 受集中载荷的简支梁，轴的挠度随轴径的变化曲线。**挠度按 $1 / d ^ { 4 }$ 规律变化，而四次方规律正是轴径成为刚度设计中最重要参数的原因。把轴径增大 20 % 的工程师把挠度减小 60 %，而这 60 % 正是刚度设计由轴径主导的原因。** **铝轴的挠度是钢轴的 3 倍，而这 3 倍正是刚度关键场合很少使用铝轴的原因。**

::: example 轴的挠度校核 {#ex-shaft-deflection level=3 check="2"}
某钢轴（$E = 2 0 7$ GPa）直径 40 mm，跨长 500 mm，跨中受集中载荷 5 kN。试计算跨中挠度和轴承处转角。

**惯性矩：**

$$
I \; = \; { \frac { \pi d ^ { 4 } } { 6 4 } } \; = \; { \frac { \pi \times 4 0 ^ { 4 } } { 6 4 } } \; = \; 1 2 7 \ 1 0 0 \ \text{mm} ^ { 4 }
$$

**跨中挠度：**

$$
\delta \; = \; { \frac { P L ^ { 3 } } { 4 8 \, E \, I } } \; = \; { \frac { 5 \ 0 0 0 \times 5 0 0 ^ { 3 } } { 4 8 \times 2 0 7 \ 0 0 0 \times 1 2 7 \ 1 0 0 } } \; = \; { \frac { 6 . 2 5 \times 1 0 ^ { 1 1 } } { 1 . 2 6 \times 1 0 ^ { 1 1 } } } \; = \; { \bf 0 . 5 0 } \ \text{mm}
$$

**轴承处转角：**

$$
\theta \; = \; { \frac { P L ^ { 2 } } { 1 6 \, E \, I } } \; = \; { \frac { 5 \ 0 0 0 \times 5 0 0 ^ { 2 } } { 1 6 \times 2 0 7 \ 0 0 0 \times 1 2 7 \ 1 0 0 } } \; = \; { \frac { 1 . 2 5 \times 1 0 ^ { 9 } } { 4 . 2 1 \times 1 0 ^ { 1 1 } } } \; = \; { \bf 0 . 0 0 3 } \ \text{rad} \; = \; 0 . 1 7 ^ { \circ }
$$

**挠度（0.50 mm）超过了齿轮轴 0.05 mm 的典型限值，而转角（0.17°）低于球轴承 0.5° 的限值。工程师必须增大轴径或减小跨长以满足挠度限值。**
:::
## 3. 轴的结构尺寸与设计细节

::: definition 轴的结构尺寸与标准尺寸 {#def-shaft-proportions}
**轴的结构尺寸**是轴径与键槽尺寸、轴肩高度和圆角半径之间的比例：

$$
\begin{array} { l c c c }
\textbf{参数} & \textbf{公式} & \textbf{典型值} & \textbf{原因} \\ \hline
\text{键宽} & w = d / 4 & d = 3 0 \text{--} 5 0 \text{时} 8 \text{--} 1 2 \ \text{mm} & \text{标准比例} \\
\text{键高} & h = d / 6 & d = 3 0 \text{--} 5 0 \text{时} 5 \text{--} 8 \ \text{mm} & \text{标准比例} \\
\text{轴肩高度} & h _ { s } = 0 . 1 d & d = 3 0 \text{--} 5 0 \text{时} 3 \text{--} 5 \ \text{mm} & \text{轴承定位} \\
\text{圆角半径} & r = 0 . 0 5 d \text{--} 0 . 1 d & d = 3 0 \text{--} 5 0 \text{时} 1 . 5 \text{--} 5 \ \text{mm} & \text{应力集中} \\
\text{倒角} & 4 5 ^ { \circ } \times 0 . 5 d _ { \text{key } } & 2 \text{--} 4 \ \text{mm} & \text{装配} \\
\end{array}
$$

**圆角半径是最重要的轴的结构尺寸，因为圆角半径决定轴肩处的应力集中系数。把圆角半径从 1 mm 增大到 3 mm 的工程师，把 $K _ { t }$ 从 2.5 降到 1.7，峰值应力降低 32 %，而这一降低正是圆角半径成为轴设计中第一个被优化的参数的原因。**
:::

::: definition 键的设计：剪切与挤压 {#def-key-design}
**键**是轴的保险丝：键被设计成先于轴、齿轮和联轴器失效。键按**剪切**和**挤压**准则定尺寸：

**剪切：**

$$
\tau _ { \text{key } } \; = \; { \frac { 2 T } { w \, l \, d } } \; \le \; { \frac { S _ { y , \text{key } } } { n } }
$$

**挤压：**

$$
\sigma _ { b , \text{key } } \; = \; { \frac { 4 T } { h \, l \, d } } \; \le \; { \frac { S _ { y , \text{key } } } { n } }
$$

其中 $T$ 是扭矩，$w$ 是键宽，$h$ 是键高，$l$ 是键长，$d$ 是轴径，$n$ 是安全因数。

$$
\begin{array} { l c c c }
\textbf{键类型} & \textbf{抗剪能力} & \textbf{抗压能力} & \textbf{适用场合} \\ \hline
\text{方键} & \text{高} & \text{高} & \text{通用} \\
\text{平键} & \text{中} & \text{中} & \text{齿轮、带轮} \\
\text{半圆键} & \text{低} & \text{低} & \text{小轴、自动对位} \\
\text{楔键} & \text{很高} & \text{很高} & \text{重载、大轴} \\
\text{花键} & \text{很高} & \text{很高} & \text{滑移齿轮、大扭矩} \\
\end{array}
$$

**键是轴的保险丝：键被设计成先于轴失效，而保险丝正是键用比轴软的材料制造（AISI 1020 对 AISI 4140）的原因。把键设计得比轴还强的工程师不是在键设计，而是在设计一次轴的失效。**
:::

::: example 30 mm 轴的键设计 {#ex-key-design level=3 check="2"}
直径 30 mm 的轴通过方键（$w = h = 8$ mm，$l = 3 0$ mm）传输扭矩 300 N·m。键材料 $S _ { y } = 3 5 0$ MPa。试计算剪切和挤压的安全因数。

**剪切：**

$$
\tau _ { \text{key } } \; = \; { \frac { 2 T } { w \, l \, d } } \; = \; { \frac { 2 \times 3 0 0 \times 1 0 ^ { 3 } } { 8 \times 3 0 \times 3 0 } } \; = \; { \frac { 6 0 0 \ 0 0 0 } { 7 \ 2 0 0 } } \; = \; 8 3 . 3 \ \text{MPa}
$$

$$
n _ { \text{shear } } \; = \; { \frac { 3 5 0 } { 8 3 . 3 } } \; = \; { \bf 4 . 2 }
$$

**挤压：**

$$
\sigma _ { b , \text{key } } \; = \; { \frac { 4 T } { h \, l \, d } } \; = \; { \frac { 4 \times 3 0 0 \times 1 0 ^ { 3 } } { 8 \times 3 0 \times 3 0 } } \; = \; { \frac { 1 \ 2 0 0 \ 0 0 0 } { 7 \ 2 0 0 } } \; = \; 1 6 6 . 7 \ \text{MPa}
$$

$$
n _ { \text{bearing } } \; = \; { \frac { 3 5 0 } { 1 6 6 . 7 } } \; = \; { \bf 2 . 1 }
$$

**挤压安全因数（2.1）低于剪切安全因数（4.2），因为挤压面积（$h \times l / 2$）是剪切面积（$w \times l$）的一半。挤压是控制性准则，而控制性准则正是键按挤压而不是按剪切定尺寸的原因。**
:::

::: example 带键槽和轴肩圆角的轴 {#ex-shaft-combined level=3 check="2"}
某轴有一段直径 40 mm 的轴身，带盘铣键槽（$K _ { t , \text{bending} } = 1 . 8$、$K _ { t , \text{torsion} } = 1 . 4$），并有一个 $r = 2$ mm、$D = 5 0$ mm、$d = 4 0$ mm 的轴肩圆角（$K _ { t , \text{bending} } = 1 . 7$、$K _ { t , \text{torsion} } = 1 . 3$）。轴承受 $M = 1 5 0$ N·m 和 $T = 2 0 0$ N·m。材料 $S _ { y } = 6 0 0$ MPa。试计算危险截面处的安全因数。

**危险截面是轴肩圆角（弯曲 $K _ { t }$ 更高）。**

**名义应力：**

$$
\sigma _ { \text{nom } } \; = \; { \frac { 3 2 M } { \pi d ^ { 3 } } } \; = \; { \frac { 3 2 \times 1 5 0 \times 1 0 ^ { 3 } } { \pi \times 4 0 ^ { 3 } } } \; = \; 2 3 . 9 \ \text{MPa}
$$

$$
\tau _ { \text{nom } } \; = \; { \frac { 1 6 T } { \pi d ^ { 3 } } } \; = \; { \frac { 1 6 \times 2 0 0 \times 1 0 ^ { 3 } } { \pi \times 4 0 ^ { 3 } } } \; = \; 1 5 . 9 \ \text{MPa}
$$

**峰值应力（轴肩圆角）：**

$$
\sigma _ { \max } \; = \; 1 . 7 \times 2 3 . 9 \; = \; 4 0 . 6 \ \text{MPa}
$$

$$
\tau _ { \max } \; = \; 1 . 3 \times 1 5 . 9 \; = \; 2 0 . 7 \ \text{MPa}
$$

**米泽斯：**

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { 4 0 . 6 ^ { 2 } + 3 \times 2 0 . 7 ^ { 2 } } } \; = \; { \sqrt { 1 6 4 8 + 1 2 8 5 } } \; = \; { \sqrt { 2 9 3 3 } } \; = \; 5 4 . 2 \ \text{MPa}
$$

$$
n \; = \; { \frac { 6 0 0 } { 5 4 . 2 } } \; = \; { \bf 1 1 . 1 }
$$

**安全因数为 11.1。工程师还必须校核键槽截面：键槽的弯曲 $K _ { t }$ 更低（1.8 对 1.7）而扭转 $K _ { t }$ 更高（1.4 对 1.3），所以危险截面取决于 $M / T$ 比值。对本例载荷，危险截面是轴肩圆角。**
:::

## 习题

::: exercise 按 ASME 方程定轴径 {#ex-shaft-asme level=3 check="3"}
某轴在 900 rpm 下传输 30 kW。弯矩 150 N·m，扭矩 318 N·m。材料 $S _ { y } = 4 0 0$ MPa。冲击系数 $K _ { b } = 2 . 0$、$K _ { t } = 1 . 5$。安全因数为 2.0。试计算轴径。

::: solution
**当量弯矩：**

$$
M _ { e } \; = \; { \frac { 1 } { 2 } } \left[ K _ { b } M + { \sqrt { ( K _ { b } M ) ^ { 2 } + ( K _ { t } T ) ^ { 2 } } } \right] \; = \; { \frac { 1 } { 2 } } \left[ 3 0 0 + { \sqrt { 3 0 0 ^ { 2 } + 4 7 7 ^ { 2 } } } \right] \; = \; { \frac { 1 } { 2 } } [ 3 0 0 + 5 6 3 ] \; = \; 4 3 2 \ \text{N} { \cdot } \text{m}
$$

**许用应力：** $S _ { \text{allow } } = 4 0 0 / 2 = 2 0 0$ MPa。

$$
d \; = \; \left( { \frac { 3 2 \times 4 3 2 \times 1 0 ^ { 3 } } { \pi \times 2 0 0 } } \right) ^ { 1 / 3 } \; = \; ( 2 2 \ 0 2 0 ) ^ { 1 / 3 } \; = \; { \bf 2 8 } \ \text{mm}
$$

**轴径为 28 mm。工程师会选用 30 mm 的轴（下一个标准尺寸）。**
:::
:::

::: exercise 轴的挠度校核 {#ex-shaft-deflection-ex level=3 check="1"}
某钢轴（$E = 2 0 7$ GPa）直径 50 mm，跨长 600 mm，跨中受集中载荷 10 kN。试计算跨中挠度。它满足齿轮轴 0.05 mm 的限值吗？

::: solution
$$
I \; = \; { \frac { \pi \times 5 0 ^ { 4 } } { 6 4 } } \; = \; 3 0 6 \ 8 0 0 \ \text{mm} ^ { 4 }
$$

$$
\delta \; = \; { \frac { 1 0 \ 0 0 0 \times 6 0 0 ^ { 3 } } { 4 8 \times 2 0 7 \ 0 0 0 \times 3 0 6 \ 8 0 0 } } \; = \; { \frac { 2 . 1 6 \times 1 0 ^ { 1 2 } } { 3 . 0 5 \times 1 0 ^ { 1 2 } } } \; = \; { \bf 0 . 7 1 } \ \text{mm}
$$

**挠度（0.71 mm）超过 0.05 mm 限值 14 倍。工程师必须把轴径增大到约 100 mm（或把跨长减小到 200 mm）才能满足挠度限值。轴是按刚度而不是强度定尺寸的。**
:::
:::

::: exercise 临界转速计算 {#ex-critical-speed level=3 check="2"}
某轴跨中装有 20 kg 的质量，质量所在处的静挠度为 2 mm。试计算一阶临界转速。若轴在 3 000 rpm 下工作，它是亚临界、超临界还是处于共振区？

::: solution
$$
n _ { c } \; = \; { \frac { 1 } { 2 \pi } } \, { \sqrt { \frac { g } { \delta _ { \text{static } } } } } \; = \; { \frac { 1 } { 2 \pi } } \, { \sqrt { \frac { 9 . 8 1 } { 0 . 0 0 2 } } } \; = \; { \frac { 1 } { 2 \pi } } \times 7 0 \; = \; 1 1 . 1 \ \text{Hz} \; = \; { \bf 6 6 9 } \ \text{rpm}
$$

**工作转速比：**

$$
{ \frac { n } { n _ { c } } } \; = \; { \frac { 3 \ 0 0 0 } { 6 6 9 } } \; = \; 4 . 4 9
$$

**轴在临界转速的 4.49 倍下工作，属于超临界（$n / n _ { c } > 1 . 4$ ）。轴是安全的，但起动过程中必须穿过共振区，而这一穿越正是起动时间必须很短（几秒钟而不是几分钟）的原因。**
:::
:::

::: exercise 键的设计 {#ex-key-design-ex level=3 check="2"}
直径 40 mm 的轴通过平键（$w = 1 2$ mm、$h = 8$ mm、$l = 5 0$ mm）传输扭矩 500 N·m。键材料 $S _ { y } = 3 0 0$ MPa。试计算剪切和挤压的安全因数。

::: solution
**剪切：**

$$
\tau _ { \text{key } } \; = \; { \frac { 2 \times 5 0 0 \times 1 0 ^ { 3 } } { 1 2 \times 5 0 \times 4 0 } } \; = \; { \frac { 1 \ 0 0 0 \ 0 0 0 } { 2 4 \ 0 0 0 } } \; = \; 4 1 . 7 \ \text{MPa}
$$

$$
n _ { \text{shear } } \; = \; { \frac { 3 0 0 } { 4 1 . 7 } } \; = \; { \bf 7 . 2 }
$$

**挤压：**

$$
\sigma _ { b , \text{key } } \; = \; { \frac { 4 \times 5 0 0 \times 1 0 ^ { 3 } } { 8 \times 5 0 \times 4 0 } } \; = \; { \frac { 2 \ 0 0 0 \ 0 0 0 } { 1 6 \ 0 0 0 } } \; = \; 1 2 5 \ \text{MPa}
$$

$$
n _ { \text{bearing } } \; = \; { \frac { 3 0 0 } { 1 2 5 } } \; = \; { \bf 2 . 4 }
$$

**挤压安全因数（2.4）是控制性准则。键满足 2.0 的设计因数。**
:::
:::

::: exercise 轴肩圆角处的应力集中 {#ex-shoulder-fillet level=3 check="2"}
一阶梯轴 $D = 6 0$ mm、$d = 5 0$ mm、$r = 3$ mm。轴承受弯矩 300 N·m。材料 $S _ { y } = 6 0 0$ MPa。试用计入应力集中的米泽斯理论计算安全因数。

::: solution
**名义弯曲应力：**

$$
\sigma _ { \text{nom } } \; = \; { \frac { 3 2 M } { \pi d ^ { 3 } } } \; = \; { \frac { 3 2 \times 3 0 0 \times 1 0 ^ { 3 } } { \pi \times 5 0 ^ { 3 } } } \; = \; { \frac { 9 . 6 \times 1 0 ^ { 6 } } { 3 9 2 \ 7 0 0 } } \; = \; 2 4 . 4 \ \text{MPa}
$$

**应力集中系数：** $r / d = 3 / 5 0 = 0 . 0 6$，$D / d = 6 0 / 5 0 = 1 . 2$。查表得 $K _ { t } \approx 1 . 6$（弯曲）。

**峰值应力：** $\sigma _ { \max } = 1 . 6 \times 2 4 . 4 = 3 9 . 1$ MPa。

$$
n \; = \; { \frac { 6 0 0 } { 3 9 . 1 } } \; = \; { \bf 1 5 . 3 }
$$

**安全因数为 15.3。不计应力集中时 $n = 6 0 0 / 2 4 . 4 = 2 4 . 6$。应力集中使安全因数降低 38 %。**
:::
:::

::: exercise 邓克莱法 {#ex-dunkerley level=3 check="1"}
某轴装有两个质量，各自的临界转速为 $n _ { 1 } = 2 0 0 0$ rpm 和 $n _ { 2 } = 3 0 0 0$ rpm。试用邓克莱法计算合成临界转速。

::: solution
$$
{ \frac { 1 } { n _ { c } ^ { 2 } } } \; = \; { \frac { 1 } { n _ { 1 } ^ { 2 } } } + { \frac { 1 } { n _ { 2 } ^ { 2 } } } \; = \; { \frac { 1 } { 2 0 0 0 ^ { 2 } } } + { \frac { 1 } { 3 0 0 0 ^ { 2 } } } \; = \; { \frac { 1 } { 4 \times 1 0 ^ { 6 } } } + { \frac { 1 } { 9 \times 1 0 ^ { 6 } } }
$$

$$
{ \frac { 1 } { n _ { c } ^ { 2 } } } \; = \; 2 . 5 \times 1 0 ^ { - 7 } + 1 . 1 1 \times 1 0 ^ { - 7 } \; = \; 3 . 6 1 \times 1 0 ^ { - 7 }
$$

$$
n _ { c } \; = \; { \frac { 1 } { \sqrt { 3 . 6 1 \times 1 0 ^ { - 7 } } } } \; = \; { \bf 1 \ 6 6 7 } \ \text{rpm}
$$

**合成临界转速（1 667 rpm）低于最低的单个临界转速（2 000 rpm），因为邓克莱法是偏保守的。这种保守性正是邓克莱法用于初步设计、而瑞利法用于最终设计的原因。**
:::
:::

::: exercise 推导：ASME 轴方程 {#ex-derive-asme level=4 check="3"}
证明：ASME 轴方程 $d = ( 1 6 n / \pi ) ^ { 1 / 3 } [ ( M _ { e } ) / S _ { \text{allow } } ] ^ { 1 / 3 }$ 可由弯扭组合作用的米泽斯准则导出，其中 $M _ { e } = { \frac { 1 } { 2 } } [ K _ { b } M + \sqrt { ( K _ { b } M ) ^ { 2 } + ( K _ { t } T ) ^ { 2 } } ]$。并对 $M = 2 0 0$ N·m、$T = 3 0 0$ N·m、$K _ { b } = K _ { t } = 1 . 5$、$S _ { \text{allow } } = 2 0 0$ MPa、$n = 2 . 0$ 计算轴径。

::: solution
弯曲（$\sigma = 3 2 M / \pi d ^ { 3 }$）与扭转（$\tau = 1 6 T / \pi d ^ { 3 }$）组合作用的米泽斯准则为：

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { \sigma ^ { 2 } + 3 \tau ^ { 2 } } } \; = \; { \frac { 1 6 } { \pi d ^ { 3 } } } \, { \sqrt { 4 M ^ { 2 } + 3 T ^ { 2 } } } \; \le \; { \frac { S _ { y } } { n } }
$$

ASME 方程使用当量弯矩：

$$
M _ { e } \; = \; { \frac { 1 } { 2 } } \left[ K _ { b } M + { \sqrt { ( K _ { b } M ) ^ { 2 } + ( K _ { t } T ) ^ { 2 } } } \right]
$$

$$
M _ { e } \; = \; { \frac { 1 } { 2 } } \left[ 3 0 0 + { \sqrt { 3 0 0 ^ { 2 } + 4 5 0 ^ { 2 } } } \right] \; = \; { \frac { 1 } { 2 } } [ 3 0 0 + 5 4 1 ] \; = \; 4 2 0 \ \text{N} { \cdot } \text{m}
$$

$$
d \; = \; \left( { \frac { 3 2 \times 4 2 0 \times 1 0 ^ { 3 } } { \pi \times 2 0 0 } } \right) ^ { 1 / 3 } \; = \; ( 2 1 \ 3 9 5 ) ^ { 1 / 3 } \; = \; { \bf 2 8 } \ \text{mm}
$$

**ASME 轴方程就是带冲击系数的米泽斯准则，而冲击系数正是 ASME 方程比纯粹的米泽斯准则更保守的原因。** $\blacksquare$
:::
:::

::: exercise 推导：临界转速 {#ex-derive-critical-speed level=4 check="1"}
证明：临界转速 $n _ { c } = ( 1 / 2 \pi ) { \sqrt { g / \delta _ { \text{static } } } }$ 可由单质量系统的固有频率 $\omega _ { n } = { \sqrt { k / m } }$ 代入 $k = m g / \delta _ { \text{static } }$ 导出。并对 $\delta _ { \text{static } } = 5$ mm 计算临界转速。

::: solution
单质量系统的固有频率为：

$$
\omega _ { n } \; = \; { \sqrt { \frac { k } { m } } }
$$

静挠度为 $\delta _ { \text{static } } = m g / k$，所以 $k = m g / \delta _ { \text{static } }$。代入：

$$
\omega _ { n } \; = \; { \sqrt { \frac { m g / \delta _ { \text{static } } } { m } } } \; = \; { \sqrt { \frac { g } { \delta _ { \text{static } } } } }
$$

临界转速为：

$$
n _ { c } \; = \; { \frac { \omega _ { n } } { 2 \pi } } \; = \; { \frac { 1 } { 2 \pi } } \, { \sqrt { \frac { g } { \delta _ { \text{static } } } } }
$$

对 $\delta _ { \text{static } } = 5$ mm = 0.005 m：

$$
n _ { c } \; = \; { \frac { 1 } { 2 \pi } } \, { \sqrt { \frac { 9 . 8 1 } { 0 . 0 0 5 } } } \; = \; { \frac { 1 } { 2 \pi } } \times 4 4 . 3 \; = \; 7 . 0 5 \ \text{Hz} \; = \; { \bf 4 2 3 } \ \text{rpm}
$$

**临界转速为 423 rpm。静挠度是决定临界转速的唯一参数，而这种简单性正是瑞利法成为临界转速初步计算中应用最广方法的原因。** $\blacksquare$
:::
:::

## 本讲的去向

- **[[machine-design/static-failure]]** —— 米泽斯准则是 ASME 轴方程的基础。
- **[[machine-design/fatigue]]** —— 轴按疲劳准则（Goodman 或 ASME）定尺寸，并计入键槽和轴肩圆角处的应力集中。
- **[[machine-design/bearings]]** —— 轴承处转角必须小于 0.5°（球轴承）或 0.25°（滚子轴承）。
- **[[machine-design/gear-design]]** —— 精密齿轮处的挠度必须小于 0.05 mm。
- **[[machine-design/fasteners-joints]]** —— 键是轴的保险丝，键被设计成先于轴失效。
- **[[machine-design/clutches-brakes-belts]]** —— 带轮和链轮的力是轴的弯矩图的输入。
- **[[vibrations/continuous-systems|临界转速]]** —— 临界转速计算是转子动力学分析的基础。
- **[[mechanics-of-materials/beam-deflection]]** —— 轴的挠度用梁的挠度公式计算。

::: history 轴的设计：从朗肯方程到 ASME 规范 {#history-shafts}
**1858** —— **朗肯（W.J.M. Rankine）**提出第一个轴的设计方程，用最大切应力理论把扭转与弯曲组合起来。**朗肯方程是 ASME 轴方程的基础，而这一基础正是 ASME 方程成为应用最广的轴设计方程的原因。**

**1890** —— 德国工程师**巴赫（C. Bach）**首次测量了**键槽应力集中**，测出了键槽处的疲劳强度降低。**巴赫的测量正是每本机械设计教材都列出键槽 $K _ { t }$ 表格的原因。**

**1910** —— **ASME 轴设计委员会**成立，该委员会于 1919 年发布了第一部 ASME 轴设计规范。**ASME 规范正是轴的设计成为标准化计算而不是猜测的原因。**

**20 世纪 20 年代** —— **费伦纽斯（W. Fellenius）与斯托多拉（A. Stodola）**发展了**临界转速理论**，计算旋转轴的固有频率。**临界转速理论正是轴被设计成避开共振的原因，而避开共振正是涡轮机轴安全的原因。**

**20 世纪 40 年代** —— Goodman 和 Soderberg 准则把**疲劳方法**引入轴的设计，考虑了平均应力的影响。**疲劳方法正是轴按疲劳准则而不是静力准则定尺寸的原因。**

**1960** —— **彼得森（R.E. Peterson）**出版《Stress Concentration Design Factors》，列出了键槽、轴肩圆角和弹性挡圈槽的 $K _ { t }$ 表格。**彼得森的著作正是工程师无需有限元分析就能计算轴上不连续处峰值应力的原因。**

**1980** —— **有限元法**被用于轴的设计，取代挠度和应力集中的手算。**有限元分析正是轴的设计按重量和刚度而不是只按强度进行优化的原因。**
:::

::: summary 轴 {#summary-shafts}
- **轴是机器中最关键的零件，轴失效会毁掉轴承、齿轮、密封件和箱体。**轴的设计是一个多约束优化问题：强度、刚度和动力稳定性。
- **ASME 轴方程按带冲击系数 $K _ { b }$ 和 $K _ { t }$ 的弯扭组合给轴定尺寸。**当量弯矩为 $M _ { e } = { \frac { 1 } { 2 } } [ K _ { b } M + \sqrt { ( K _ { b } M ) ^ { 2 } + ( K _ { t } T ) ^ { 2 } } ]$。
- **轴的挠度是最重要的刚度准则：齿轮处挠度必须小于 0.05 mm，轴承处转角必须小于 0.5°。**按强度定尺寸的轴往往柔度过大 30–50 %。
- **临界转速是轴的固有频率等于回转频率时的转速。**轴必须在其一阶临界转速的 70 % 以下或 140 % 以上工作。
- **键槽是轴中最常见的应力集中源：扭转 $K _ { t }$ 为 1.5–2.5，弯曲 $K _ { t }$ 为 2.0–3.5。**盘铣键槽的 $K _ { t }$ 低于普通键槽。
- **键是轴的保险丝：键被设计成先于轴、齿轮和联轴器失效。**键按剪切和挤压准则定尺寸，挤压是控制性准则。
- **圆角半径是最重要的轴的结构尺寸：把圆角半径从 1 mm 增大到 3 mm，$K _ { t }$ 从 2.5 降到 1.7，峰值应力降低 32 %。**圆角半径是轴设计中第一个被优化的参数。
- **邓克莱法是偏保守的：合成临界转速低于最低的单个临界转速。**瑞利法更精确，用于最终设计。
- **轴的结构尺寸（键宽 $= d / 4$、键高 $= d / 6$、轴肩高度 $= 0 . 1 d$、圆角半径 $= 0 . 0 5 d \text{--} 0 . 1 d$）是保证轴可制造、可装配的标准比例。**这些比例正是轴按标准而不是按计算设计的原因。
- **轴的设计必须附上载荷图、弯矩图、挠度图和临界转速计算书。**这些文件正是轴的设计在设计评审和法庭上站得住脚的原因。
:::
