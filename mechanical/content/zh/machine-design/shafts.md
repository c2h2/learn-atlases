轴是几乎所有靠转动传递功率的机器的骨架。它承载着把转矩输入或输出的齿轮、带轮、链轮、叶轮和转子，并由轴承定位，轴承承受这些零件产生的力。齿轮箱轴、泵轴、机床主轴和汽车传动轴做的是同一件事：在所传递的扭矩作用下扭转，在所承载零件的横向力作用下弯曲，并且在转动，因此表面上的每一点每转一圈都要经过一次受拉和一次受压。

可能出问题的地方有三处，轴的设计必须逐一校核。轴可能断裂，几乎总是由疲劳引起，起源于弯曲应力集中的轴肩圆角、键槽或沟槽处。它可能变形过大，使齿轮啮合不良、轴承在偏斜状态下运转、密封泄漏，而此时离断裂还远得很。它还可能发生涡动：在某些转速，即临界转速下，微小的不平衡力会使旋转的轴产生很大的弯曲。本章先讨论决定应力集中源和载荷位置的布局问题，然后依次讨论这三个问题，最后讨论把轴与其所驱动零件连接起来的键、联轴器和过盈配合。

这里使用的疲劳方法就是[[machine-design/fatigue]]中的方法：用 Marin 系数修正疲劳极限，用$K_f$和$K_{fs}$考虑缺口，用 von Mises 方法合成应力幅和平均应力，以及 Goodman、Gerber 和 ASME 椭圆准则。挠度计算采用[[mechanics-of-materials/beam-deflection]]中的梁理论，临界转速则与[[vibrations/vibration-fundamentals]]和[[vibrations/continuous-systems]]相联系。符号沿用 Budynas 与 Nisbett《Shigley 机械工程设计》（*Shigley's Mechanical Engineering Design*，第 11 版），其第 7 章是本章方法的基础。

## 轴的布局

::: definition 轴、心轴与主轴 {#def-shaft}
**轴**（传动轴）是通常为圆截面的转动构件，用于传递功率，因而传递转矩。**心轴**承载车轮等转动零件但不传递转矩；它可以转动（铁路轮对车轴），也可以固定不动（挂车车轮的轴）。**主轴**是一种短轴，典型的是机床主轴，对它而言刚度和回转精度比强度更重要。
:::

关于轴的大多数重要决定，在计算任何应力之前、在绘制布局图时就已作出。典型的齿轮箱轴是一个阶梯圆柱体。每个零件装在各自直径的轴段上，轴段之间的台阶形成**轴肩**，齿轮和轴承靠在轴肩上作轴向定位。直径通常从两端向中间逐渐增大，这样每个零件都能从一端越过较小的轴段套入，并压靠在自己的轴肩上。零件靠套筒、装在沟槽中的挡圈（弹性挡圈）、轴端螺纹上的锁紧螺母或相邻零件的轮毂压紧在轴肩上。

布局通过有经验的设计者所遵循的几条规则决定了载荷和应力：

- **轴要短，悬臂要小。**弯矩、挠度和转角都随跨距迅速增长：中央集中载荷下的挠度按$l^3$增长。齿轮和带轮应靠近轴承，悬臂的带轮或叶轮应尽可能靠近轴承。
- **尽可能用两个轴承。**两支点的轴是静定的；第三个轴承使支反力取决于对中情况和箱体刚度，而这些都是不确定的。
- **只在一个轴承处作轴向定位。**一个轴承为**固定**（定位）轴承，在轴上和箱体中都轴向夹紧，承受两个方向的轴向载荷。另一个为**游动**轴承，可以轴向滑动——在箱体中滑动，或者（对圆柱滚子轴承）在轴承内部滑动——这样轴相对箱体的热膨胀就不会使轴承受到轴向载荷。一根长$300\ \mathrm{mm}$、比箱体高$40\ \mathrm{K}$的钢轴伸长约$12\times10^{-6}\times300\times40 = 0.14\ \mathrm{mm}$——足以使两端都被夹紧的一对轴承过载。温差小的短轴有时改用两端单向固定的方式，每个轴承承受一个方向的轴向力。
- **把应力集中源放在弯矩小的地方。**挡圈槽、螺纹和键槽端部造成很强的应力集中；在简支轴的两端附近，弯矩降为零，它们的代价很小。
- **遵守轴承制造商给出的安装尺寸。**轴肩必须足够高以支承轴承套圈，圆角半径必须小于轴承的倒角尺寸，轴承才能端正地贴靠。若因此只能用小而尖的圆角，可以采用退刀槽或单独的轴肩环。

轴通常由中碳钢制造，小尺寸用冷拔材料，大尺寸由热轧棒料车削而成：一般用途用 AISI 1040–1050 或 EN C45，需要更高强度时用 4140（42CrMo4）等合金钢，当轴本身构成轴承或齿轮表面时用渗碳钢。有一个事实影响着选材：所有这些钢的弹性模量都约为$207\ \mathrm{GPa}$。合金钢换来的是强度而不是刚度，因此尺寸由挠度决定的轴从合金钢中得不到任何好处。

### 轴上的载荷

::: definition 传递的转矩 {#def-torque}
以角速度$\omega$传递功率$P$的轴承受的转矩为
$$
T = \frac{P}{\omega}, \qquad \omega = \frac{2\pi n}{60}\ \ (n\ \text{以 rpm 计}),
$$ {#eq-torque}
即$T\,[\mathrm{N\,m}] = 9549\,P\,[\mathrm{kW}]/n\,[\mathrm{rpm}]$。扭矩只作用在输入功率的零件与输出功率的零件之间的那一段轴上。
:::

轴上的零件把转矩转化为横向力。分度圆直径为$d_p$、压力角为$\phi$的直齿轮承受圆周力$W_t = 2T/d_p$和径向（分离）力$W_r = W_t\tan\phi$；斜齿轮和锥齿轮还附加轴向力，须由固定轴承承受（这些力在[[machine-design/gear-design]]中推导）。带轮被两边带拉力之和$F_1 + F_2$拉向另一个带轮，这个和可以是有效圆周力$F_1 - F_2$的数倍（[[machine-design/clutches-brakes-belts]]）。把每个力分解到包含轴线的两个互相垂直的平面内，在每个平面内画剪力图和弯矩图，再把两个弯矩按矢量合成：
$$
M = \sqrt{M_{xy}^2 + M_{xz}^2}.
$$ {#eq-resultant}
对圆轴这样做是合理的：表面的弯曲应力只取决于弯矩矢量的大小而与其方向无关，况且轴本身就会转过所有方向。注意，合成弯矩一般并不在任一分量最大的地方最大，因此要在每个候选截面上计算。

::: example 齿轮轴上的载荷 {#ex-loads}
一根中间轴以$600\ \mathrm{rpm}$传递$11\ \mathrm{kW}$。功率经由轴承$A$左侧悬伸端上的弹性联轴器输入，经由距$A$为$120\ \mathrm{mm}$的直齿轮（分度圆直径$200\ \mathrm{mm}$，模数$4\ \mathrm{mm}$，压力角$20°$）输出。轴承$B$距$A$为$300\ \mathrm{mm}$。齿轮轴段上有键槽，齿轮的轴肩在距$A$为$100\ \mathrm{mm}$处。求扭矩、齿轮力、轴承支反力，以及齿轮处和轴肩处的弯矩。
::: solution
**扭矩。**$\omega = 2\pi\times600/60 = 62.83\ \mathrm{rad/s}$，$T = 11\,000/62.83 = 175.1\ \mathrm{N\,m}$。它作用在联轴器与齿轮之间。

**齿轮力。**$W_t = 2T/d_p = 2\times175.1/0.200 = 1751\ \mathrm{N}$；$W_r = 1751\tan20° = 637\ \mathrm{N}$。二者位于互相垂直的平面内并作用在同一截面上，因此它们的合力$F = \sqrt{1751^2 + 637^2} = 1863\ \mathrm{N}$可以当作一个横向力处理（$F$所在平面取任何方位，弯矩大小都相同）。

**受力图。**轴是跨距$l = 300\ \mathrm{mm}$的简支梁：力$F$作用在距$A$为$a = 120\ \mathrm{mm}$处（距$B$为$b = 180\ \mathrm{mm}$），轴承处的支反力$R_A$和$R_B$与之反向。联轴器只传递扭矩。分别对$B$和$A$取矩：
$$
R_A = \frac{Fb}{l} = \frac{1863\times180}{300} = 1118\ \mathrm{N}, \qquad R_B = \frac{Fa}{l} = \frac{1863\times120}{300} = 745\ \mathrm{N}.
$$

**弯矩。**齿轮处$M = R_Aa = 1118\times0.120 = 134.1\ \mathrm{N\,m}$；轴肩处$M = R_A\times0.100 = 111.8\ \mathrm{N\,m}$。

**合理性检查。**$R_A + R_B = 1863\ \mathrm{N} = F$。离齿轮较近的轴承分担较大的份额，理应如此。两个危险截面——齿轮处的键槽和轴肩圆角——都承受全部扭矩和接近最大值的弯矩。
:::
:::

## 危险截面上的应力

在空间固定的齿轮力或带拉力作用下转动的轴，承受方向固定的弯矩，而材料在其中转过。因此表面上的一点每转一圈从受拉侧转到受压侧再转回来：弯曲应力是**对称循环**的，其应力幅等于静弯曲应力，尽管弯矩本身是恒定的。稳定功率流产生的扭矩是稳定的。因此通常的情况是旋转弯曲加稳定扭转，但下面的方法允许二者都有应力幅分量和平均分量（例如往复式发动机产生强烈波动的转矩）。

::: definition 轴的交变载荷与平均载荷 {#def-components}
在转轴的某一截面上，设$M_a$和$M_m$为表面一点所经历的交变弯矩和平均弯矩，$T_a$和$T_m$为交变扭矩和平均扭矩。$K_f$和$K_{fs}$为该截面弯曲和扭转的疲劳缺口系数，则直径为$d$的实心圆轴的表面应力为
$$
\sigma_a = K_f\frac{32M_a}{\pi d^3}, \quad \sigma_m = K_f\frac{32M_m}{\pi d^3}, \quad \tau_a = K_{fs}\frac{16T_a}{\pi d^3}, \quad \tau_m = K_{fs}\frac{16T_m}{\pi d^3}.
$$ {#eq-stresses}
对转轴上的稳定横向载荷，$M_a = M$，$M_m = 0$；对稳定扭矩，$T_m = T$，$T_a = 0$。
:::

斜齿轮轴向力或立轴自重产生的轴向应力通常远小于弯曲应力，像[[#eq-stresses]]那样略去；不能略去时，把它们加到$\sigma_m$中（转轴上的稳定轴向载荷是平均应力）。横向剪切应力在弯曲应力最大的表面处为零，也被忽略，只有短而重载的轴例外。

::: proposition DE-Goodman 轴设计公式 {#prop-de-goodman}
在证明中列出的假设下，直径为$d$的实心圆轴的无限寿命安全因数为
$$
\frac1n = \frac{16}{\pi d^3}\left\{\frac{1}{S_e}\left[4(K_fM_a)^2 + 3(K_{fs}T_a)^2\right]^{1/2} + \frac{1}{S_{ut}}\left[4(K_fM_m)^2 + 3(K_{fs}T_m)^2\right]^{1/2}\right\},
$$ {#eq-de-goodman}
而设计安全因数为$n$时所需的直径为
$$
d = \left(\frac{16n}{\pi}\left\{\frac{1}{S_e}\left[4(K_fM_a)^2 + 3(K_{fs}T_a)^2\right]^{1/2} + \frac{1}{S_{ut}}\left[4(K_fM_m)^2 + 3(K_{fs}T_m)^2\right]^{1/2}\right\}\right)^{1/3}.
$$ {#eq-de-goodman-d}
它们就是 Budynas 与 Nisbett 书中的式 7-7 和式 7-8。
:::

::: proof
**假设。**(i) 危险点位于实心圆截面的表面，只承受弯曲应力$\sigma$和扭转切应力$\tau$（略去轴向应力和横向剪切应力）。(ii) 弯曲分量与扭转分量同相位，因此可以像[[machine-design/fatigue]]中的复合载荷算法那样，把应力幅部分和平均部分分别合成为 von Mises 当量应力。(iii) 无限寿命的失效由通过$S_e$和$S_{ut}$的修正 Goodman 直线控制，$S_e$按弯曲计算（$k_c = 1$）。(iv) 载荷增大到$n$倍时所有应力按比例增长（径向载荷线）。(v) 材料是延性、各向同性的，$K_f$、$K_{fs}$作用在应力上。

**当量应力。**对只有一个正应力$\sigma$和一个切应力$\tau$的平面应力状态，von Mises 应力为$\sigma' = (\sigma^2 + 3\tau^2)^{1/2}$。分别用于[[#eq-stresses]]的应力幅部分和平均部分：
$$
\sigma_a' = \left[\left(\frac{32K_fM_a}{\pi d^3}\right)^2 + 3\left(\frac{16K_{fs}T_a}{\pi d^3}\right)^2\right]^{1/2} = \frac{16}{\pi d^3}\left[4(K_fM_a)^2 + 3(K_{fs}T_a)^2\right]^{1/2},
$$
因为$32 = 2\times16$在括号内产生因数$4$；同理$\sigma_m' = \dfrac{16}{\pi d^3}\left[4(K_fM_m)^2 + 3(K_{fs}T_m)^2\right]^{1/2}$。

**Goodman。**对径向载荷线，Goodman 安全因数为$1/n = \sigma_a'/S_e + \sigma_m'/S_{ut}$。代入两个当量应力并提出公因子$16/(\pi d^3)$，即得[[#eq-de-goodman]]。对$d^3$求解并开立方，即得[[#eq-de-goodman-d]]。
:::

"DE-Goodman"这个名称记录了两个组成部分：用于合成弯曲与扭转的畸变能（von Mises）理论，以及用于平均应力的 Goodman 直线。把 Goodman 直线换成[[machine-design/fatigue]]中的其他准则，就得到相应的公式（Budynas 与 Nisbett，§7-4）。记
$$
A = \left[4(K_fM_a)^2 + 3(K_{fs}T_a)^2\right]^{1/2}, \qquad B = \left[4(K_fM_m)^2 + 3(K_{fs}T_m)^2\right]^{1/2}.
$$
则

$$
\text{DE-Gerber：}\quad \frac1n = \frac{8A}{\pi d^3S_e}\left\{1 + \left[1 + \left(\frac{2BS_e}{AS_{ut}}\right)^2\right]^{1/2}\right\},
$$ {#eq-de-gerber}
$$
\text{DE-ASME 椭圆：}\quad \frac1n = \frac{16}{\pi d^3}\left[4\left(\frac{K_fM_a}{S_e}\right)^2 + 3\left(\frac{K_{fs}T_a}{S_e}\right)^2 + 4\left(\frac{K_fM_m}{S_y}\right)^2 + 3\left(\frac{K_{fs}T_m}{S_y}\right)^2\right]^{1/2}.
$$ {#eq-de-elliptic}

DE-Goodman 公式是三者中最保守的，求解$d$也最简单；DE-Gerber 和 DE-ASME 椭圆公式更接近延性钢的试验数据，通常给出的直径小几个百分点。三者都是无限寿命准则；对有限寿命，用该寿命下的疲劳强度$S_f$代替$S_e$。

疲劳准则不校核首次循环时的屈服，因此接着要用最大 von Mises 应力作 Langer 型校核，它由峰值弯矩和峰值扭矩算出：
$$
\sigma'_{\max} = \left[\left(\frac{32K_f(M_m + M_a)}{\pi d^3}\right)^2 + 3\left(\frac{16K_{fs}(T_m + T_a)}{\pi d^3}\right)^2\right]^{1/2}, \qquad n_y = \frac{S_y}{\sigma'_{\max}}.
$$ {#eq-yield}
这里使用$K_f$是保守的：延性材料缺口根部局部屈服并不会使轴失效。有些设计者在屈服校核中不计$K_f$；Budynas 与 Nisbett 保留了它。

### "ASME 公式"指的是什么

较早的教材和许多设计手册以"ASME 公式"之名给出另一个公式：
$$
d^3 = \frac{16}{\pi\tau_\text{all}}\sqrt{(K_bM)^2 + (K_tT)^2},
$$ {#eq-old-asme}
其中$K_b$和$K_t$（不是应力集中系数）是弯曲和扭转的经验性冲击–疲劳综合系数。它来自 ASME 于 1927 年发布的《传动轴设计规范》（*Code for the Design of Transmission Shafting*，后编号为 ASA B17c），是一个静强度公式：$\sqrt{M^2 + T^2}$是最大切应力（Tresca）理论的当量扭矩，疲劳只是通过这些系数和一个较低的许用切应力间接计入——许用切应力取$0.30S_y$但不超过$0.18S_{ut}$，有键槽时再降低四分之一。它不区分交变应力和平均应力，也不使用$K_f$或疲劳极限。该规范后来被 ANSI/ASME B106.1M-1985《传动轴设计》（*Design of Transmission Shafting*）取代，后者采用疲劳方法：对旋转弯矩$M$和稳定扭矩$T$，其直径公式为
$$
d = \left\{\frac{32n}{\pi}\left[\left(\frac{K_fM}{S_e}\right)^2 + \frac34\left(\frac{T}{S_y}\right)^2\right]^{1/2}\right\}^{1/3},
$$ {#eq-b106}
这恰好就是$M_m = T_a = 0$、$K_{fs} = 1$时的[[#eq-de-elliptic]]（把$4$作为$2$提到根号外，$16\times2 = 32$）。B106.1M 后来已被撤销（据美国输送设备制造商协会 CEMA 称，撤销于 1994 年），没有直接的后继标准，但其方法仍在工业界使用，并作为参考收录在 ANSI/AGMA 6001-D97 中。受监管行业中的实际轴按这些行业的标准设计，例如铁路车轴按 EN 13103 和 EN 13104；本章讲授的是原理，不能代替这些标准。

## 直径的设计

DE 公式需要$K_f$、$K_{fs}$和$S_e$，而三者都取决于正要求的直径：$K_t$取决于圆角半径比$r/d$和台阶比$D/d$，缺口敏感度$q$取决于半径$r$，尺寸系数$k_b$取决于$d$。解决办法是从典型值出发进行迭代。Budynas 与 Nisbett（表 7-1）给出了下列$K_t$的首轮估计值，它们对典型比例取偏安全的值：

| 结构 | $K_t$（弯曲） | $K_{ts}$（扭转） | $K_t$（轴向） |
|---|---|---|---|
| 轴肩圆角，尖锐（$r/d = 0.02$） | $2.7$ | $2.2$ | $3.0$ |
| 轴肩圆角，充分倒圆（$r/d = 0.1$） | $1.7$ | $1.5$ | $1.9$ |
| 端铣键槽（$r/d = 0.02$） | $2.14$ | $3.0$ | — |
| 盘铣（滑橇形）键槽 | $1.7$ | — | — |
| 挡圈槽 | $5.0$ | $3.0$ | $5.0$ |

尖锐圆角通常是轴承轴肩所迫；在孔口有倒角的齿轮下面则可以采用充分倒圆的圆角。端铣键槽以一个凹窝突然终止；用盘铣刀加工的滑橇形键槽逐渐收尾，弯曲应力集中较小。首轮计算取$q = 1$（$K_f = K_t$）是安全的假设。

::: algorithm 按强度设计轴 {#alg-shaft}
1. 布置轴：零件和轴承的位置、轴肩、键槽和沟槽；固定轴承和游动轴承。
2. 由功率和转速求扭矩[[#eq-torque]]及其作用范围；求每个零件的作用力，画两个平面内的弯矩图并按[[#eq-resultant]]合成。
3. 选出候选危险截面：弯矩最大处，以及弯矩和扭矩较大区域中的每一个应力集中源。求出各处的$M_a$、$M_m$、$T_a$、$T_m$。
4. 首轮迭代：由上表估计$K_f = K_t$和$K_{fs} = K_{ts}$；取$k_c = 1$并假设$k_b \approx 0.9$求$S_e$；按选定的设计安全因数，用[[#eq-de-goodman-d]]（或 Gerber、椭圆形式）求各截面的$d$。
5. 选择标准直径、台阶比（通常$D/d \approx 1.1$–$1.5$）以及与轴承和零件相容的圆角半径。
6. 第二轮迭代：按实际几何由图表求$K_t$、$K_{ts}$，再求$q$、$K_f$、$K_{fs}$和$k_b$；用[[#eq-de-goodman]]重算每个危险截面的$n$，用[[#eq-yield]]求$n_y$。
7. 校核挠度和转角（[[#eq-scaling]]及下文的限值）以及一阶临界转速；必要时加大轴径并重新校核。

**键槽处的载荷。**旋转弯曲$M_a = 134.1\ \mathrm{N\,m}$，$M_m = 0$；稳定扭矩$T_m = 175.1\ \mathrm{N\,m}$，$T_a = 0$。端铣键槽：$K_f = 2.14$，$K_{fs} = 3.0$。

**疲劳极限初估。**$S_e' = 0.5\times690 = 345\ \mathrm{MPa}$；切削加工，$k_a = 4.51\times690^{-0.265} = 0.798$；假设$k_b = 0.9$；$k_c = k_d = k_e = k_f = 1$。$S_e = 0.798\times0.9\times345 = 247.7\ \mathrm{MPa}$。

**初定直径。**以 N 和 mm 为单位，[[#eq-de-goodman-d]]的两项为
$$
\frac{2K_fM_a}{S_e} = \frac{2\times2.14\times134\,100}{247.7} = 2318\ \mathrm{mm^3}, \qquad \frac{\sqrt3\,K_{fs}T_m}{S_{ut}} = \frac{1.732\times3.0\times175\,100}{690} = 1318\ \mathrm{mm^3},
$$

**迭代$k_b$。**在$d = 30.3\ \mathrm{mm}$时，$k_b = 1.24\times30.3^{-0.107} = 0.861$，$S_e = 236.9\ \mathrm{MPa}$，同样的计算给出$d = 30.6\ \mathrm{mm}$；再迭代一次不再变化。齿轮轴段取$d = 32\ \mathrm{mm}$，轴肩取$38\ \mathrm{mm}$。

$$

$$
因此$\sigma_a' = 89.2\ \mathrm{MPa}$，$\sigma_m' = \sqrt3\times81.6 = 141.4\ \mathrm{MPa}$，

\frac1n = \frac{89.2}{235.5} + \frac{141.4}{690} = 0.379 + 0.205 = 0.584, \qquad n = 1.71.

::: warning 使轴计算前功尽弃的错误
- **把旋转弯曲当作稳定弯曲。**转轴上的恒定弯矩产生对称循环应力：$M_a = M$，$M_m = 0$。只有随轴一起转动的载荷（例如不平衡力）才产生稳定的弯曲应力。
- **只校核弯矩最大的截面。**轴在轴肩、键槽和沟槽处失效，这些地方往往离弯矩最大处有一段距离。受载区域内的每一个应力集中源都是候选危险截面。
- **在 von Mises 公式中对扭转使用$k_c = 0.59$**，这把切变强度的折减计算了两次。DE 公式使用弯曲的$S_e$。
- **把弯矩分量代数相加**，而不是按[[#eq-resultant]]作矢量合成。
- **只算到强度为止。**大多数齿轮箱轴比强度要求的更粗，因为尺寸是由挠度、轴承处转角或临界转速决定的。
- **把[[#eq-old-asme]]称为疲劳准则。**它是带经验系数的静强度公式；它并不知道应力是否交变。
:::

## 挠度与转角

一根轴可能强度足够却仍然不能用。轴一弯曲，啮合的一对齿轮就会分离并倾斜，载荷集中在齿宽的一端；轴承在套圈偏斜的状态下运转；密封不均匀磨损。限值由零件而不是由轴决定。Budynas 与 Nisbett（表 7-2）汇集了典型的最大值：

| 零件 | 典型最大值 |
|---|---|
| 圆锥滚子轴承处的转角 | $0.0005$–$0.0012\ \mathrm{rad}$ |
| 圆柱滚子轴承处的转角 | $0.0008$–$0.0012\ \mathrm{rad}$ |
| 深沟球轴承处的转角 | $0.001$–$0.003\ \mathrm{rad}$ |
| 球面或调心球轴承处的转角 | $0.026$–$0.052\ \mathrm{rad}$ |
| 不修鼓的直齿轮处的转角 | 小于$0.0005\ \mathrm{rad}$ |
| 直齿轮处的挠度，粗齿（模数约$2.5\ \mathrm{mm}$以上） | $0.25\ \mathrm{mm}$（$0.010\ \mathrm{in}$） |
| 直齿轮处的挠度，中等齿（模数约$1.3$–$2.3\ \mathrm{mm}$） | $0.13\ \mathrm{mm}$（$0.005\ \mathrm{in}$） |
| 直齿轮处的挠度，细齿（模数约$0.5$–$1.3\ \mathrm{mm}$） | $0.08\ \mathrm{mm}$（$0.003\ \mathrm{in}$） |

齿轮的限值原本以径节（每英寸齿数）给出；模数范围是换算值。有条件时应使用轴承制造商样本中各类轴承的允许偏斜量。

轴的挠度就是梁的挠度（[[mechanics-of-materials/beam-deflection]]），但有两点复杂之处。载荷位于两个平面内，因此要分别求出每个平面内的挠度，再像弯矩那样按矢量合成。阶梯轴每一段的$I$不同，因此曲率$M/(EI)$是不连续的。初步校核时常把轴当作具有代表性直径的等截面轴；最终校核则沿各轴段对$M/(EI)$作数值积分，或使用梁单元有限元程序。轴承附近的小台阶对该处转角的影响比其长度所显示的要大，因为支座处的转角是整个跨距上曲率的积分。

::: proposition 按刚度缩放直径 {#prop-scaling}
若轴的所有直径都乘以同一个因数，而载荷和长度不变，则所有挠度和转角都按$d^{-4}$变化。因此，若计算出的挠度或转角$y_\text{old}$须在设计安全因数$n_d$下降到允许值$y_\text{all}$，所有直径须乘以
$$
\frac{d_\text{new}}{d_\text{old}} = \left|\frac{n_d\,y_\text{old}}{y_\text{all}}\right|^{1/4}.
$$ {#eq-scaling}
:::

::: proof
**假设。**线弹性小挠度，由$EIv'' = M$控制；弯矩由静力学确定（两支点轴是静定的），因此不随直径改变；剪切变形可以忽略。

所有直径乘以$\lambda$，则每个$I = \pi d^4/64$乘以$\lambda^4$，而$M(x)$不变，因此曲率$v'' = M/(EI)$处处除以$\lambda^4$。转角和挠度由曲率积分得到，积分常数由轴承处$v = 0$的支承条件确定，这些条件是线性的；因此$v'$和$v$也都除以$\lambda^4$。令$n_dy_\text{old}/\lambda^4 = y_\text{all}$，即得[[#eq-scaling]]。
:::

对于等截面轴，若单个横向力$F$作用在距轴承$A$为$a$、距轴承$B$为$b$处，跨距$l = a + b$，标准结果为
$$
\theta_A = \frac{Fb(l^2 - b^2)}{6EIl}, \qquad \theta_B = \frac{Fa(l^2 - a^2)}{6EIl}, \qquad y_F = \frac{Fa^2b^2}{3EIl},
$$ {#eq-point-load}
其中$y_F$为载荷作用点的挠度；多个载荷用叠加法相加。

::: example 中间轴的刚度 {#ex-deflection}
把[[#ex-size]]中的轴当作$d = 32\ \mathrm{mm}$的等截面轴（$E = 207\ \mathrm{GPa}$）。求轴承处的转角、齿轮处的挠度和转角，并与深沟球轴承和模数为$4$的直齿轮的限值比较。若采用限值为$0.0005\ \mathrm{rad}$的圆锥滚子轴承，需要多大的直径？
::: solution
**截面。**$I = \pi\times32^4/64 = 51\,470\ \mathrm{mm^4}$，$EI = 207\,000\times51\,470 = 1.065\times10^{10}\ \mathrm{N\,mm^2}$。力取合力$F = 1863\ \mathrm{N}$（等截面轴在各个平面内刚度相同，因此挠度位于$F$所在平面内），$a = 120$，$b = 180$，$l = 300\ \mathrm{mm}$。

**轴承处的转角。**由[[#eq-point-load]]，
$$
\theta_A = \frac{1863\times180\times(300^2 - 180^2)}{6\times1.065\times10^{10}\times300} = \frac{1.932\times10^{10}}{1.918\times10^{13}} = 0.00101\ \mathrm{rad}, \qquad \theta_B = 0.00088\ \mathrm{rad}.
$$

**齿轮处。**$y_F = 1863\times120^2\times180^2/(3\times1.065\times10^{10}\times300) = 0.091\ \mathrm{mm}$。对$v = Fbx(l^2 - b^2 - x^2)/(6EIl)$求导得$x = a$处的转角：$\theta_F = Fb(l^2 - b^2 - 3a^2)/(6EIl) = 0.00025\ \mathrm{rad}$。

**比较。**深沟球轴承，$0.001$–$0.003\ \mathrm{rad}$：$\theta_A$处于范围的下限，可以接受但没有余量。齿轮挠度$0.091\ \mathrm{mm}$对$0.25\ \mathrm{mm}$，齿轮转角$0.00025$对$0.0005\ \mathrm{rad}$：都可以接受。

**圆锥滚子轴承。**由[[#eq-scaling]]，取$n_d = 1$，$d = 32\times(0.00101/0.0005)^{1/4} = 32\times1.192 = 38.1\ \mathrm{mm}$，即约$40\ \mathrm{mm}$——比强度所需大四分之一。

**合理性检查。**实际的轴承轴段（比如$30\ \mathrm{mm}$）比$32\ \mathrm{mm}$细，因此真实转角比这些等截面轴的值稍大；这正是最终校核要沿实际台阶积分的原因。十分之一毫米和一毫弧度的量级，是比例恰当的齿轮箱轴的典型值。
:::

## 临界转速

让一根带圆盘的细长轴越转越快。到某一转速，它会剧烈地弯出，而且弯曲形状随轴一起转动；超过这一转速，轴又会变直。这个转速就是**临界转速**，这种运动称为**涡动**。它是一种共振：圆盘的不平衡力以轴的转速旋转，当转速等于轴在轴承上的横向振动固有频率时，响应只受阻尼限制。

::: definition 临界转速 {#def-critical}
转轴的**临界转速**是对不平衡的同步响应达到极大值的转速。对陀螺效应可以忽略、轴承刚性的轴，临界转速等于带有附加质量的不转动轴的横向（弯曲）振动固有频率$\omega_1 < \omega_2 < \dots$；$\omega_1$为**一阶临界转速**。
:::

::: proposition 不平衡圆盘的涡动（Jeffcott 转子） {#prop-jeffcott}
质量为$m$的圆盘，其质心偏离轴线距离$e$，装在一根在圆盘处横向刚度为$k$的轴上；令$\omega_n = \sqrt{k/m}$。在无阻尼的稳态同步涡动中，转速为$\omega$时圆盘处轴心的径向挠度为
$$
r = \frac{e\,(\omega/\omega_n)^2}{1 - (\omega/\omega_n)^2},
$$ {#eq-jeffcott}
以偏心方向为正。当$\omega \to \omega_n$时挠度无限增大；在$\omega_n$以上挠度为负，且当$\omega \to \infty$时$r \to -e$：圆盘绕自身质心旋转。
:::

::: proof
**假设。**轴无质量；轴承刚性；圆盘位于跨中，因此不倾斜，也没有陀螺耦合；无阻尼；忽略重力（或扣除其静挠度）；轴刚度为线性；稳态涡动，即弯曲的轴和圆盘作为一个刚性构形一起以$\omega$转动。

在稳态涡动中，圆盘的几何中心（轴穿过的点）沿半径为$r$的圆运动，而沿同一径向刚性偏移$e$的质心沿半径为$r + e$的圆运动。圆盘所受的唯一横向力是轴的弹性恢复力$kr$，指向轴线。质心作匀速圆周运动，由牛顿第二定律，需要向心力$m\omega^2(r + e)$，所以
$$
kr = m\omega^2(r + e) \quad\Longrightarrow\quad r = \frac{m\omega^2e}{k - m\omega^2} = \frac{e\,(\omega/\omega_n)^2}{1 - (\omega/\omega_n)^2}.
$$
$\omega < \omega_n$时$r > 0$：轴向重的一侧弯曲。$\omega > \omega_n$时$r < 0$：几何中心位于轴线上与重点相对的一侧，并且$\omega \to \infty$时$r \to -e$，因此质心$r + e \to 0$落在轴承连线上。
:::

这是[[vibrations/vibration-fundamentals]]中受迫响应的另一种形式：[[#eq-jeffcott]]就是以轴转速为激励频率的旋转不平衡响应。有两个推论值得指出。第一，在同步涡动中弯曲形状随轴一起转动，因此纤维承受的是稳定的而不是交变的弯曲应力；临界转速的危险在于挠度的大小——它可能毁坏密封、轴承和转子间隙——以及很大的轴承力。第二，轴可以在一阶临界转速以上稳定运转（称为"超临界"），只要它快速通过临界转速并有足够的阻尼。汽轮机和燃气轮机、离心机以及许多高速主轴都是这样运转的。普通工业轴则保持在一阶临界转速以下并留有余量；Budynas 与 Nisbett 建议一阶临界转速至少为工作转速的两倍。

对单位长度质量为$m'$、两端简支的等截面轴，[[vibrations/continuous-systems]]中的连续梁分析给出一阶固有频率
$$
\omega_1 = \left(\frac{\pi}{l}\right)^2\sqrt{\frac{EI}{m'}}.
$$ {#eq-uniform}
实际的轴是阶梯形的并带有圆盘，对它们使用两种经典的估计方法。

::: proposition Rayleigh 估计 {#prop-rayleigh}
设无质量轴上带有集中质量$m_i$，$y_i$为每个质量受自身重力$m_ig$沿同一横向作用时各质量处的静挠度。则
$$
\omega_1 \approx \sqrt{\frac{g\sum m_iy_i}{\sum m_iy_i^2}},
$$ {#eq-rayleigh}
并且这一估计值从不低于真实的一阶临界转速。
:::

::: proof
**假设。**轴线弹性，支承在刚性轴承上；集中质量无转动惯量，无陀螺效应；无阻尼自由振动。

**能量平衡。**设轴以一阶振型作简谐振动，$y_i(t) = Y_i\cos\omega t$。最大动能出现在挠度为零的瞬间，为$\tfrac12\omega^2\sum m_iY_i^2$。最大应变能出现在极端位置，等于缓慢施加产生挠度$Y_i$的力$F_i$所做的功，即$\tfrac12\sum F_iY_i$。没有阻尼时两个最大值相等。

**假设振型。**真实振型是未知的。Rayleigh 方法使用它的一个近似，这里取在力$F_i = m_ig$作用下的静挠度曲线，对它而言挠度$y_i$与力之间的关系是精确的。于是$\tfrac12\omega^2\sum m_iy_i^2 = \tfrac12\sum m_igy_i$，即[[#eq-rayleigh]]。

**上界。**对任何容许形状$\mathbf{y}$，比值$\omega_R^2 = U_{\max}/(\tfrac12\sum m_iy_i^2)$——即 Rayleigh 商——是各阶固有频率平方的加权平均，权重等于各阶振型在$\mathbf{y}$中参与量的平方；因此它不可能小于其中最小的$\omega_1^2$，只有当$\mathbf{y}$就是一阶振型时才等于它。静挠度曲线接近一阶振型，所以估计值很接近且略偏高。
:::

实际计算中，无论轴的真实方位如何，挠度$y_i$都按轴水平放置时重力作用下的挠度计算；只有形状才有意义。对质量位于不同平面内的轴，设想所有的力都在同一平面内。

::: proposition Dunkerley 估计 {#prop-dunkerley}
设$a_{ij}$为轴的影响系数（单位力作用于$j$处时$i$处的挠度），$\omega_{ii} = 1/\sqrt{a_{ii}m_i}$为轴上只有质量$m_i$时的固有频率。则
$$
\frac{1}{\omega_1^2} \approx \sum_i\frac{1}{\omega_{ii}^2} = \sum_i a_{ii}m_i,
$$ {#eq-dunkerley}
并且这一估计值从不高于真实的一阶临界转速。
:::

::: proof
**假设。**与 Rayleigh 估计相同。

**特征值问题。**用轴的柔度矩阵$\mathbf{A} = [a_{ij}]$，惯性力$-m_j\ddot y_j$引起的挠度为$y_i = -\sum_j a_{ij}m_j\ddot y_j$。对频率为$\omega$的简谐运动，$\ddot y_j = -\omega^2y_j$，因此$\mathbf{A}\mathbf{M}\mathbf{y} = \omega^{-2}\mathbf{y}$，其中$\mathbf{M}$为对角质量矩阵。$\mathbf{A}\mathbf{M}$的特征值为$\lambda_k = 1/\omega_k^2$。

**迹。**矩阵特征值之和等于其迹：$\sum_k 1/\omega_k^2 = \sum_i a_{ii}m_i$。矩阵$\mathbf{A}$对称（Maxwell 互等定理）且正定，$\mathbf{M}$为对角元素为正的对角矩阵，因此$\mathbf{A}\mathbf{M}$与正定矩阵$\mathbf{M}^{1/2}\mathbf{A}\mathbf{M}^{1/2}$相似；它的所有特征值都为正。

**界。**只保留第一项而略去其余各项，得$1/\omega_1^2 < \sum_k 1/\omega_k^2 = \sum_i a_{ii}m_i$，这就给出[[#eq-dunkerley]]作为$\omega_1$的下界。误差是被略去的$\sum_{k \ge 2}1/\omega_k^2$，当高阶临界转速远高于一阶时，它很小。
:::

Dunkerley 估计更便于手算，因为每个$\omega_{ii}$只需要一个挠度公式，各项直接相加；轴自身的质量可以通过加上光轴的一项$1/\omega_s^2$（由[[#eq-uniform]]求得）近似计入。Rayleigh 估计需要完整的静挠度曲线，但要接近得多。二者把一阶临界转速夹在中间。

::: example 双圆盘轴的临界转速 {#ex-critical}
一根直径$40\ \mathrm{mm}$的钢轴（$E = 207\ \mathrm{GPa}$，$\rho = 7850\ \mathrm{kg/m^3}$）简支在相距$800\ \mathrm{mm}$的两个轴承上，在距左轴承$250\ \mathrm{mm}$处装一个$25\ \mathrm{kg}$的圆盘，在$500\ \mathrm{mm}$处装一个$40\ \mathrm{kg}$的圆盘。忽略轴的质量，用 Rayleigh 法和 Dunkerley 法估计一阶临界转速，与精确值比较，然后计入轴的质量。该轴要在$1500\ \mathrm{rpm}$下运转；是否可以接受？
::: solution
**刚度。**$I = \pi\times0.04^4/64 = 1.257\times10^{-7}\ \mathrm{m^4}$，$EI = 26\,010\ \mathrm{N\,m^2}$。单位载荷作用在距右轴承$b$处时，（载荷左侧）$x$处的挠度为$a(x) = bx(l^2 - b^2 - x^2)/(6EIl)$。取站点$x_1 = 0.25\ \mathrm{m}$，$x_2 = 0.5\ \mathrm{m}$：
$$
a_{11} = 3.028\times10^{-7}, \quad a_{22} = 3.604\times10^{-7}, \quad a_{12} = a_{21} = 2.928\times10^{-7}\ \mathrm{m/N}.
$$

**Rayleigh。**重力作用下的静挠度：$y_1 = g(a_{11}m_1 + a_{12}m_2) = 9.81\times(7.57 + 11.71)\times10^{-6} = 0.189\ \mathrm{mm}$；$y_2 = g(a_{21}m_1 + a_{22}m_2) = 0.213\ \mathrm{mm}$。于是
$$
\omega_1 \approx \sqrt{\frac{9.81\times(25\times0.189 + 40\times0.213)\times10^{-3}}{(25\times0.189^2 + 40\times0.213^2)\times10^{-6}}} = 218.9\ \mathrm{rad/s} = 2091\ \mathrm{rpm}.
$$

**Dunkerley。**$\omega_{11} = 1/\sqrt{a_{11}m_1} = 363.4\ \mathrm{rad/s}$，$\omega_{22} = 1/\sqrt{a_{22}m_2} = 263.4\ \mathrm{rad/s}$，因此$1/\omega_1^2 = 1/363.4^2 + 1/263.4^2$，$\omega_1 \approx 213.3\ \mathrm{rad/s} = 2037\ \mathrm{rpm}$。

**精确值。**$\mathbf{AM}$的较大特征值给出$\omega_1 = 218.9\ \mathrm{rad/s}$（以及$\omega_2 = 944\ \mathrm{rad/s}$）。Rayleigh 偏高$0.01$%，Dunkerley 偏低$2.6$%。

**轴的质量。**$m' = 7850\times\pi\times0.02^2 = 9.86\ \mathrm{kg/m}$（总计$7.9\ \mathrm{kg}$）。由[[#eq-uniform]]，光轴的$\omega_s = (\pi/0.8)^2\sqrt{26\,010/9.86} = 792\ \mathrm{rad/s}$。把这一项加入 Dunkerley 求和：$\omega_1 \approx 205.9\ \mathrm{rad/s} = 1966\ \mathrm{rpm}$。

**能否接受。**约$1970$–$2090\ \mathrm{rpm}$只是运转转速的$1.3$–$1.4$倍，达不到两倍。不计轴的质量时，每个临界转速都按$\sqrt{k/m} \propto d^2$变化；要达到$3000\ \mathrm{rpm}$，直径须增大到约$40\sqrt{3000/2091} = 48\ \mathrm{mm}$，因此取$50\ \mathrm{mm}$。

**合理性检查。**两个界的表现与证明一致：Dunkerley 偏低，Rayleigh 偏高，由于$\omega_2$是$\omega_1$的四倍多，二者都很接近。约$0.2\ \mathrm{mm}$的静挠度也给出一个快速估计，$\sqrt{g/\delta} = \sqrt{9.81/0.0002} = 221\ \mathrm{rad/s}$——这就是熟知的规律：静挠度$\delta$对应的固有频率接近$\sqrt{g/\delta}$。
:::
:::

上述方法假设轴承刚性并忽略陀螺效应。弹性轴承和箱体会降低临界转速，有时降低得很多；悬臂圆盘和大型转子通过陀螺力矩使临界转速随运转转速变化；油膜轴承增加随转速变化的刚度和阻尼，并可能引起不稳定涡动。这些是转子动力学的内容，高速机械用专门的转子动力学软件分析，在某些行业中还要按诸如透平机械的 API 标准进行。

## 键、联轴器与过盈配合

### 键

::: definition 平键 {#def-key}
**平键**是矩形或正方形截面的键条，宽$b$、高$h$、长$l$，一半嵌在轴上铣出的键槽中，一半嵌在轮毂的键槽中，靠侧面承压在二者之间传递转矩。直径为$d$的轴传递转矩$T$时，键在轴表面处承受圆周力
$$
F = \frac{2T}{d}
$$ {#eq-key-force}
:::

键可能以两种方式失效。它可能沿轴与轮毂之间的平面被剪断，剪切面积为$bl$；它的侧面，或轴槽、毂槽的侧面，可能在该平面两侧的接触高度$h_c$上被压溃（挤压屈服）：
$$
\tau = \frac{F}{bl} \le \frac{S_{sy}}{n}, \qquad \sigma_c = \frac{F}{h_cl} \le \frac{S_y}{n},
$$ {#eq-key}
其中按畸变能理论$S_{sy} \approx 0.577S_y$，$S_y$取键、轴和轮毂中最弱者的值。对装在对称键槽中的方键，$h_c = h/2$；对 DIN 6885-1 的矩形键，轮毂中的接触高度$h - t_1$（$t_1$为轴槽深度）较小，通常起控制作用。这些都是名义应力；载荷沿键长并不均匀，这是长键收效甚微的原因之一（常用的经验规则是键长不超过约$1.5d$；轮毂更长时用两个键或花键）。

键的尺寸按轴径标准化：公制采用 ISO 773 和 DIN 6885-1，英制采用 ANSI B17.1（使用方键，例如轴径大于$1\tfrac14$至$1\tfrac38\ \mathrm{in}$时用$\tfrac{5}{16}\ \mathrm{in}$方键）。设计者选择键长，必要时选择键的材料。键通常用比轴稍弱的钢制造，这样过载时剪断的是廉价的键，而不会损坏轴或轮毂；键槽的应力集中（见上表）属于轴设计的一部分。

::: example 齿轮的键 {#ex-key}
[[#ex-loads]]中的齿轮（$T = 175.1\ \mathrm{N\,m}$）装在[[#ex-size]]的$32\ \mathrm{mm}$轴段上。DIN 6885-1 对大于$30$至$38\ \mathrm{mm}$的轴规定键$b\times h = 10\times8\ \mathrm{mm}$，轴槽深$t_1 = 5.0\ \mathrm{mm}$。键用冷拔 AISI 1020 钢（$S_y = 390\ \mathrm{MPa}$），比轴和齿轮轮毂弱。求安全因数为$2$时所需的键长。
::: solution
**力。**$F = 2T/d = 2\times175\,100/32 = 10\,940\ \mathrm{N}$。

**剪切。**$S_{sy} = 0.577\times390 = 225\ \mathrm{MPa}$。$l \ge nF/(bS_{sy}) = 2\times10\,940/(10\times225) = 9.7\ \mathrm{mm}$。

**挤压。**轮毂一侧接触高度$h_c = h - t_1 = 8 - 5 = 3\ \mathrm{mm}$（轴一侧为$5\ \mathrm{mm}$）。$l \ge nF/(h_cS_y) = 2\times10\,940/(3\times390) = 18.7\ \mathrm{mm}$。

**选择。**挤压起控制作用。标准键长$25\ \mathrm{mm}$或更长即可；实际上键做得接近轮毂长度（这里为$40\ \mathrm{mm}$，因此用$32$或$36\ \mathrm{mm}$的键），挤压应力进一步降低。若键为圆头，只有直线段长度$l - b$计作承压长度。

**合理性检查。**轴本身在键槽处的名义扭转应力为$16T/(\pi d^3) = 27\ \mathrm{MPa}$；长$25\ \mathrm{mm}$的键$\tau = 44\ \mathrm{MPa}$，$\sigma_c = 146\ \mathrm{MPa}$，与轴的应力同一量级，匹配良好的连接正应如此。
:::
:::

当键不能传递所需转矩或轮毂须滑动时，采用**花键**：沿轴周布置许多与轴一体的键，通常为渐开线齿形（公制按 ISO 4156），它们分担载荷并使轮毂对中。轻载可以用紧定螺钉、销或锥形胀紧元件传递。

### 过盈配合

轮毂也可以压装或热装到稍大的轴上。过盈量在配合面上产生接触压力$p$，由[[solid-mechanics/thick-cylinders-discs]]中的厚壁圆筒理论计算，配合面上的摩擦传递转矩和轴向力。若在直径$d$、长度$l$的配合面上压力均匀，摩擦系数为$\mu$，则可用的摩擦力为$\mu p\,\pi dl$，作用在半径$d/2$处，因此
$$
T_\text{max} = \frac{\pi}{2}\mu p\,d^2l, \qquad F_{a,\max} = \pi\mu p\,dl.
$$ {#eq-press-fit}
干燥钢–钢压装配合的摩擦系数通常取$0.1$–$0.2$，热装时更高；该值不确定，设计必须考虑到这一点。配合按 ISO 286 极限与配合制度规定（例如 H7/p6 或 H7/s6 为轻至中等压入配合），压力必须按公差所允许的极限过盈量计算。过盈配合避免了键槽的应力集中，却产生了它自己的应力集中：压力在轮毂边缘处达到峰值，那里的微动滑移产生微动磨损，这是轮座和齿轮座处许多疲劳失效的原因。在轮毂边缘下面设一个小轴肩或卸载槽，并使轮毂比所需稍长，会有帮助。

### 联轴器

联轴器连接两根轴。**刚性联轴器**——套筒、一对用螺栓连接的凸缘或剖分夹紧式——使两根轴如同一根轴，要求二者精确对中；任何不对中都只能靠轴的弯曲来消除，并使轴承受载。**挠性联轴器**能容许小的不对中：带弹性体星形件的爪式联轴器、用薄钢片叠层的膜片和膜盘联轴器、带鼓形齿的齿式联轴器、波纹管联轴器，以及用于平行偏移的十字滑块（Oldham）联轴器。每种类型在样本中都有转矩、转速以及允许的角向、径向和轴向偏差的额定值，有的还提供有益的扭转阻尼。单个万向节（Hooke 或 Cardan 万向节）能在大的夹角下传递转矩，但使输出转速每转波动两次；两个正确布置的万向节可以抵消这种波动，如汽车的传动轴。

::: history
涡动理论始于朗肯（W. J. M. Rankine）发表在《工程师》（*The Engineer*）上的论文《论转轴的离心力》（"On the centrifugal force of rotating shafts"，1869 年）。朗肯的模型没有计入耦合两个运动方向的惯性力，它预言超过涡动转速后挠度将无限增大，他的结论在很长时间里使人们不敢让轴在该转速以上运转。1894 年，Stanley Dunkerley 在《皇家学会哲学汇刊》（*Philosophical Transactions of the Royal Society*，A 辑，第 185 卷）上发表《论轴的涡动与振动》（"On the whirling and vibration of shafts"），这是一项篇幅很长的理论与试验研究，其中针对带带轮的轴提出的经验求和规则，就是至今仍称为 Dunkerley 法的估计方法。证明朗肯错了的工程实例来自 Gustaf de Laval 的高速汽轮机，其细长的轴在临界转速以上运转；1895 年，August Föppl 从理论上解释了柔性轴上的圆盘为什么在高速下会自动定心，并在模型上作了验证。H. H. Jeffcott 1919 年发表在《哲学杂志》（*Philosophical Magazine*，第 6 辑，第 37 卷）上的论文研究了涡动转速附近不平衡的影响，给出了[[#prop-jeffcott]]的简单模型，今称 Jeffcott 转子。Rayleigh 的能量法见于他的《声学理论》（*Theory of Sound*，1877 年）。在强度方面，ASME 1927 年的传动轴规范及其当量扭矩公式曾作为标准沿用了几十年；ANSI/ASME B106.1M-1985 以疲劳方法取代了它，而现在讲授的 DE-Goodman 系列公式沿用的是 Shigley 教材中的处理。
:::

::: summary
- 先定布局：跨距短，零件靠近轴承，一个固定轴承和一个游动轴承，应力集中源放在弯矩小的地方；所有钢的弹性模量相同，因而刚度相同。
- 扭矩$T = P/\omega$；齿轮力和带拉力分解到两个平面，合成为合成弯矩$M = \sqrt{M_{xy}^2 + M_{xz}^2}$。
- 转轴上的稳定载荷产生对称循环弯曲；稳定扭矩产生平均切应力。计入$K_f$和$K_{fs}$，按 von Mises 合成并应用 Goodman：DE-Goodman 公式[[#eq-de-goodman]]和[[#eq-de-goodman-d]]；DE-Gerber 和 DE-ASME 椭圆公式较不保守；用$\sigma'_{\max}$校核屈服。
- 迭代：从典型的$K_t$值（Shigley 表 7-1）和$k_b \approx 0.9$出发，选定标准尺寸，再按实际几何重新校核。
- 旧的"ASME 公式"是带经验系数的静强度 Tresca 公式；ANSI/ASME B106.1M-1985（已撤销）采用 DE-ASME 椭圆形式。
- 挠度和转角受齿轮和轴承限制（典型限值：球轴承$0.001$–$0.003\ \mathrm{rad}$，直齿轮处小于$0.0005\ \mathrm{rad}$）；它们按$d^{-4}$缩放。
- 临界转速就是横向固有频率：等截面简支轴$\omega_1 = (\pi/l)^2\sqrt{EI/m'}$；Rayleigh 估计是上界，Dunkerley 估计是下界。使$\omega_1$高于约两倍的运转转速，或按超临界运转设计。
- 键：$F = 2T/d$，校核$bl$上的剪切和$h_cl$上的挤压；过盈配合可传递$T = \tfrac{\pi}{2}\mu pd^2l$，但会在轮毂边缘引起微动磨损。
:::

## 习题

::: exercise 由功率求扭矩 {level=1 check="80"}
一根轴以$150\ \mathrm{rad/s}$传递$12\ \mathrm{kW}$。求扭矩。（以 N·m 为单位输入$T$。）
::: solution
$T = P/\omega = 12\,000/150 = 80\ \mathrm{N\,m}$。换成转速，$150\ \mathrm{rad/s}$为$1432\ \mathrm{rpm}$，$9549\times12/1432 = 80\ \mathrm{N\,m}$，结果相同。
:::
:::

::: exercise 临界转速的缩放 {level=1 check="6"}
一根等截面简支轴重新设计，直径增大到$1.5$倍，轴承跨距缩短一半。它的一阶临界转速变为原来的多少倍？（输入倍数。）
::: solution
由[[#eq-uniform]]，$\omega_1 \propto l^{-2}\sqrt{I/m'} \propto l^{-2}\sqrt{d^4/d^2} = d/l^2$。倍数为$1.5/0.5^2 = 6$。
:::
:::

::: exercise 键的切应力 {level=1 check="20"}
一根$40\ \mathrm{mm}$的轴通过宽$10\ \mathrm{mm}$、长$50\ \mathrm{mm}$的键传递$200\ \mathrm{N\,m}$。求键中的切应力。（以 MPa 为单位输入$\tau$。）
::: solution
$F = 2T/d = 2\times200\,000/40 = 10\,000\ \mathrm{N}$；$\tau = F/(bl) = 10\,000/(10\times50) = 20\ \mathrm{MPa}$。
:::
:::

::: exercise 两个质量的 Dunkerley 估计 {level=2 check="240"}
一根轴带有两个圆盘。若轴上只有其中一个圆盘，固有频率分别为$300\ \mathrm{rad/s}$和$400\ \mathrm{rad/s}$。忽略轴的质量，用 Dunkerley 法估计两个圆盘同时存在时的一阶临界转速。（以 rad/s 为单位输入$\omega_1$。）
::: solution
$1/\omega_1^2 = 1/300^2 + 1/400^2 = (16 + 9)/(1.44\times10^6)$，所以$\omega_1 = 1200/5 = 240\ \mathrm{rad/s}$。这是一个下界：真实值稍高一些。
:::
:::

::: exercise 为满足轴承转角而加粗轴 {level=2 check="45"}
一根$30\ \mathrm{mm}$的等截面轴，计算得到它在圆柱滚子轴承处的转角为$0.00405\ \mathrm{rad}$，而该轴承的允许转角为$0.0008\ \mathrm{rad}$。取设计安全因数为$1$，需要多大的直径？（以 mm 为单位输入$d$。）
::: solution
由[[#eq-scaling]]，$d = 30\times(0.00405/0.0008)^{1/4} = 30\times5.0625^{1/4} = 30\times1.5 = 45\ \mathrm{mm}$。转角按$d^{-4}$变化，所以直径增大 50% 使转角降为约五分之一。
:::
:::

::: exercise 轴肩处的安全因数 {level=2}
一根直径$40\ \mathrm{mm}$的转轴，在某轴肩圆角处承受$300\ \mathrm{N\,m}$的旋转弯矩和$400\ \mathrm{N\,m}$的稳定扭矩，$K_f = 1.7$，$K_{fs} = 1.5$。完全修正后的疲劳极限$S_e = 220\ \mathrm{MPa}$，$S_{ut} = 700\ \mathrm{MPa}$，$S_y = 500\ \mathrm{MPa}$。求 DE-Goodman 和 DE-ASME 椭圆安全因数以及屈服安全因数。
::: solution
**应力。**$\sigma_a = 1.7\times32\times300\,000/(\pi\times40^3) = 81.2\ \mathrm{MPa}$；$\tau_m = 1.5\times16\times400\,000/(\pi\times40^3) = 47.7\ \mathrm{MPa}$；$\sigma_m' = \sqrt3\times47.7 = 82.7\ \mathrm{MPa}$。

**DE-Goodman。**$1/n = 81.2/220 + 82.7/700 = 0.369 + 0.118 = 0.487$，$n = 2.05$。

**DE-ASME 椭圆。**$1/n = \sqrt{(81.2/220)^2 + (82.7/500)^2} = \sqrt{0.1361 + 0.0274} = 0.404$，$n = 2.47$。

**屈服。**$\sigma'_{\max} = \sqrt{81.2^2 + 3\times47.7^2} = 115.9\ \mathrm{MPa}$，$n_y = 500/115.9 = 4.31$。
:::
:::

::: exercise 压装配合的转矩能力 {level=2}
一个齿轮轮毂压装在$40\ \mathrm{mm}$的轴上，配合长度$50\ \mathrm{mm}$；接触压力（按最小过盈量由厚壁圆筒分析求得）为$30\ \mathrm{MPa}$，$\mu = 0.12$。求该配合能传递的转矩和轴向力，并把转矩与一个$12\times8\ \mathrm{mm}$、长$40\ \mathrm{mm}$、轮毂接触高度$3\ \mathrm{mm}$、材料$S_y = 390\ \mathrm{MPa}$的键（按挤压，安全因数取$1$）比较。
::: solution
**压装配合。**$T = \tfrac{\pi}{2}\times0.12\times30\times40^2\times50 = 452\,400\ \mathrm{N\,mm} = 452\ \mathrm{N\,m}$；$F_a = \pi\times0.12\times30\times40\times50 = 22\,600\ \mathrm{N}$。

**键。**挤压力$F = h_clS_y = 3\times40\times390 = 46\,800\ \mathrm{N}$，$T = Fd/2 = 46\,800\times0.020 = 936\ \mathrm{N\,m}$。

**评述。**键的能力约为两倍，但压装配合没有键槽，能使轮毂精确对中，还能承受轴向载荷。它的能力直接取决于$\mu$和最小过盈量，而二者都不确定，因此靠压装配合传递转矩时要留有很大的余量，或与键联合使用。
:::
:::

::: exercise DE-Gerber 公式 {level=3}
由 Gerber 准则$n\sigma_a'/S_e + (n\sigma_m'/S_{ut})^2 = 1$和[[#prop-de-goodman]]中的 von Mises 当量应力推导[[#eq-de-gerber]]。证明平均应力为零时它退化为 DE-Goodman 的结果。
::: solution
**当量应力。**由[[#prop-de-goodman]]的证明，$\sigma_a' = 16A/(\pi d^3)$，$\sigma_m' = 16B/(\pi d^3)$。

**关于$n$的二次方程。**Gerber 条件$\dfrac{n\sigma_a'}{S_e} + \dfrac{n^2\sigma_m'^2}{S_{ut}^2} = 1$是二次方程$\alpha n^2 + \beta n - 1 = 0$，其中$\alpha = \sigma_m'^2/S_{ut}^2$，$\beta = \sigma_a'/S_e$。把它的正根写成$1/n$：
$$
\frac1n = \frac{2\alpha}{-\beta + \sqrt{\beta^2 + 4\alpha}} = \frac{2\alpha(\beta + \sqrt{\beta^2 + 4\alpha})}{4\alpha} = \frac{\beta}{2}\left[1 + \sqrt{1 + \frac{4\alpha}{\beta^2}}\right],
$$
这里分子分母同乘了$\beta + \sqrt{\beta^2 + 4\alpha}$。

**代入。**$\beta/2 = 8A/(\pi d^3S_e)$，$4\alpha/\beta^2 = 4\sigma_m'^2S_e^2/(S_{ut}^2\sigma_a'^2) = (2BS_e/(AS_{ut}))^2$，即得[[#eq-de-gerber]]。

**平均应力为零。**$B = 0$时方括号为$2$，$1/n = 16A/(\pi d^3S_e)$，即$B = 0$时的 DE-Goodman 结果：两个准则只通过平均应力产生差别。
:::
:::

::: exercise Rayleigh 法有多准？ {level=3}
单位长度质量为$m'$的等截面轴简支在跨距$l$上。它在自重$w = m'g$（单位长度）作用下的静挠度为$y(x) = \dfrac{w}{24EI}\,x\,(l^3 - 2lx^2 + x^3)$。用 Rayleigh 估计的连续形式$\omega^2 = g\int_0^l y\,dx\big/\int_0^l y^2\,dx$求$\omega_1$，并与精确的[[#eq-uniform]]比较。
::: solution
**积分。**令$\xi = x/l$，$y = \dfrac{wl^4}{24EI}\,\xi(1 - 2\xi^2 + \xi^3)$。则$\int_0^1\xi(1 - 2\xi^2 + \xi^3)\,d\xi = \tfrac12 - \tfrac12 + \tfrac15 = \tfrac15$，且
$$
\int_0^1\xi^2(1 - 2\xi^2 + \xi^3)^2d\xi = \int_0^1(\xi^2 - 4\xi^4 + 2\xi^5 + 4\xi^6 - 4\xi^7 + \xi^8)\,d\xi = \tfrac13 - \tfrac45 + \tfrac13 + \tfrac47 - \tfrac12 + \tfrac19 = \tfrac{31}{630}.
$$

**估计。**$\omega^2 = \dfrac{g\,(wl^4/24EI)\,l\,(1/5)}{(wl^4/24EI)^2\,l\,(31/630)} = \dfrac{24EI}{m'l^4}\cdot\dfrac{630}{5\times31} = \dfrac{3024}{31}\,\dfrac{EI}{m'l^4}$，所以$\omega_1 \approx \dfrac{9.877}{l^2}\sqrt{\dfrac{EI}{m'}}$。

**比较。**精确系数为$\pi^2 = 9.870$。Rayleigh 估计偏高——这是必然的——但只高$0.07$%：均布载荷下的静挠度曲线与半正弦振型非常接近。
:::
:::

::: exercise 设计一根双齿轮中间轴 {level=3}
一根中间轴以$500\ \mathrm{rpm}$传递$7.5\ \mathrm{kW}$。轴承$A$与$B$相距$400\ \mathrm{mm}$。从动直齿轮$C$（分度圆直径$240\ \mathrm{mm}$）距$A$为$100\ \mathrm{mm}$，主动直齿小齿轮$D$（分度圆直径$80\ \mathrm{mm}$）距$A$为$300\ \mathrm{mm}$；压力角均为$20°$。取$x$沿轴线，啮合齿轮的布置使轴所受的力为：在$C$处，$W_t$沿$-y$，$W_r$沿$-z$；在$D$处，$W_r$沿$+y$，$W_t$沿$-z$。提出一个布局方案（轴承配置、轴肩、齿轮的定位方式），找出危险截面，并用冷拔 AISI 1050 钢（$S_{ut} = 690$，$S_y = 580\ \mathrm{MPa}$）按 DE-Goodman 设计安全因数$1.5$选择直径，两个齿轮都用键连接。说明下一步你要校核什么。
::: solution
**扭矩和力。**$T = 7500/(2\pi\times500/60) = 143.2\ \mathrm{N\,m}$，只作用在$C$与$D$之间。在$C$处：$W_t = 2\times143.2/0.240 = 1194\ \mathrm{N}$，$W_r = 434\ \mathrm{N}$。在$D$处：$W_t = 2\times143.2/0.080 = 3581\ \mathrm{N}$，$W_r = 1303\ \mathrm{N}$。

**支反力和弯矩。**在$xy$平面内（$C$处$-1194\ \mathrm{N}$，$D$处$+1303\ \mathrm{N}$）：$R_{By} = -(-1194\times0.1 + 1303\times0.3)/0.4 = -679\ \mathrm{N}$，$R_{Ay} = 569\ \mathrm{N}$；$M_{Cy} = 56.9$，$M_{Dy} = -67.9\ \mathrm{N\,m}$。在$xz$平面内（$C$处$-434$，$D$处$-3581\ \mathrm{N}$）：$R_{Az} = 1221\ \mathrm{N}$，$R_{Bz} = 2794\ \mathrm{N}$；$M_{Cz} = 122.1$，$M_{Dz} = 279.4\ \mathrm{N\,m}$。合成：$M_C = 134.7\ \mathrm{N\,m}$，$M_D = 287.6\ \mathrm{N\,m}$；轴承载荷在$A$处为$1347\ \mathrm{N}$，在$B$处为$2876\ \mathrm{N}$。

**布局（一种合理的选择）。**固定轴承设在$B$（载荷较大的一个，靠近小齿轮），用锁紧螺母夹紧；游动轴承设在$A$。两齿轮之间的中间轴环约$48\ \mathrm{mm}$，作为两个齿轮的轴肩；套筒从轴承内圈一侧把齿轮压靠在轴环上。键槽在轴肩圆角之前终止。

**直径。**在小齿轮键槽处（$M_a = 287.6\ \mathrm{N\,m}$，$T_m = 143.2\ \mathrm{N\,m}$，$K_f = 2.14$，$K_{fs} = 3.0$），连同$k_b$迭代[[#eq-de-goodman-d]]得$d = 36.5\ \mathrm{mm}$（$S_e \approx 232\ \mathrm{MPa}$）：取$40\ \mathrm{mm}$（DIN 键$12\times8$）。在齿轮键槽处（$M_a = 134.7\ \mathrm{N\,m}$）$d = 29.9\ \mathrm{mm}$：取$35\ \mathrm{mm}$，使齿轮能越过轴承轴段装入；两端弯矩趋于零处的轴承轴段取$30\ \mathrm{mm}$（用当地的$M$和$T$校核那里的圆角；$B$处没有扭矩）。小齿轮很小：孔径$40\ \mathrm{mm}$再加上键槽，轮齿下的轮缘很薄，做成齿轮轴可能更好。

**下一步校核。**用实际的$K_t$、$q$和$k_b$重新校核每个圆角和键槽；$D$处（靠近$B$的大的小齿轮载荷）的挠度和转角以及轴承处的转角，与所选轴承的限值比较；一阶临界转速（对$500\ \mathrm{rpm}$几乎肯定远高于运转转速）；用支反力计算轴承寿命（[[machine-design/bearings]]）；键长。不同但同样合理的布局——齿轮轴、不同的轴承配置——会得到不同的数值；重要的是每一个选择都有依据。
:::
