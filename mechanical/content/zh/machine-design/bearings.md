轴承是旋转轴与静止箱体之间的界面，而轴承是决定机器寿命、精度和效率的零件。**轴承失效不只是让机器停转；它还会毁掉轴、齿轮、密封件和箱体，而这种破坏正是轴承成为机器失效最常见原因的原因。**轴承设计是一个多准则选型问题：轴承必须承受径向载荷和轴向载荷、保持轴的位置、把摩擦降到最低、并坚持完设计寿命。**只按载荷额定值选轴承的工程师不是在选轴承，而是在选一个会因疲劳、磨损或过热而失效的轴承。**

轴承设计的定量工具是 **L10 寿命**（90 % 可靠度下的轴承寿命）、**SKF 通用寿命方程**（寿命修正系数）、**雷诺（Reynolds）方程**（滑动轴承的压力分布）、**彼得罗夫（Petroff）方程**（摩擦因数）和**索默菲尔德（Sommerfeld）数**（轴承性能参数）。这些工具就是表达轴承设计决策的语言，而这套语言正是轴承设计是计算而非猜测的原因。

::: warning 轴承设计出错的九种方式
**不计算 L10 寿命。**只按静载荷额定值选轴承而不计算 L10 寿命的工程师，不是在选轴承，而是在选一个会因疲劳而失效的轴承。**L10 寿命是 10 % 的轴承失效时的转数（或小时数），而这 10 % 正是 L10 寿命成为轴承设计依据的原因。** **不考虑当量动载荷。**轴承承受径向与轴向联合载荷却只用径向载荷的工程师，不是在计算 L10 寿命，而是在瞎猜。**当量动载荷 $P = X F _ { r } + Y F _ { a }$ 考虑了联合载荷，而这种联合正是轴承寿命被削减 50–90 % 的原因。** **不考虑可靠度系数。**在应用要求 99 % 可靠度时却使用 L10 寿命（90 % 可靠度）的工程师，不是在按可靠度设计，而是在为失效的那 10 % 设计。**可靠度系数 $a _ { 1 }$ 在 99 % 可靠度下把寿命降低 20–50 %，而这一降低正是高可靠度应用必须放大轴承尺寸的原因。** **不校核静载荷额定值。**计算 L10 寿命却不校核静载荷额定值的工程师，不是在轴承设计，而是在设计一个会因压痕失效的轴承。**静载荷额定值 $C _ { 0 }$ 必须大于当量静载荷 $P _ { 0 }$ 并取 1.5–3 的安全因数，而安全因数正是轴承不会被冲击载荷压出凹痕的原因。** **不考虑转速极限。**只按载荷额定值选轴承却不校核转速极限的工程师，不是在选轴承，而是在选一个会因过热而失效的轴承。**转速极限 $n _ { \max }$ 由轴承类型、润滑和间隙决定，而这一极限正是轴承必须按转速而不只是按载荷选型的原因。** **不考虑润滑。**选轴承却不规定润滑剂、黏度和供油方式的工程师，不是在轴承设计，而是在选一个会因磨损而失效的轴承。**润滑正确时轴承寿命是润滑错误时的 10 倍，而这 10 倍正是润滑成为轴承设计中最重要因素的原因。** **不考虑配合。**选轴承却不规定轴和外壳配合的工程师，不是在轴承设计，而是在选一个会因蠕动或咬死而失效的轴承。**配合正确时轴承寿命是配合错误时的 5 倍，而这 5 倍正是配合成为轴承安装中最重要因素的原因。** **不考虑调心能力。**选轴承却不检查允许不对中量的工程师，不是在选轴承，而是在选一个会因边缘受载而失效的轴承。**球面轴承的允许不对中量为 2–4°，圆柱形轴承为 0.5°，而这一容限正是轴承必须按不对中量而不只是按载荷选型的原因。** **不考虑温度。**对工作在 200 °C 的轴承使用室温载荷额定值的工程师，设计的不是耐高温轴承，而是“室温”轴承。**200 °C 下的载荷额定值只有室温额定值的 70–80 %，而这一降低正是轴承必须按温度降额使用的原因。**
:::

## 1. 滚动轴承

::: definition 轴承类型及其承载能力 {#def-bearing-types}
**滚动轴承**是机械设计中最常见的轴承类型，因为滚动轴承的摩擦因数低（0.001–0.005）、承载能力高、寿命长。

$$
\begin{array} { l c c c l }
\textbf{轴承类型} & \textbf{径向载荷} & \textbf{轴向载荷} & \textbf{转速极限} & \textbf{不对中容许} \\ \hline
\text{深沟球轴承} & \text{高} & \text{中} & \text{很高} & 2\text{--}4^\circ \\
\text{角接触球轴承} & \text{中} & \text{高} & \text{很高} & 2\text{--}4^\circ \\
\text{调心球轴承} & \text{中} & \text{低} & \text{高} & 2\text{--}4^\circ \\
\text{圆柱滚子轴承} & \text{很高} & \text{无} & \text{高} & 0.5^\circ \\
\text{圆锥滚子轴承} & \text{高} & \text{高} & \text{中} & 0.5^\circ \\
\text{调心滚子轴承} & \text{很高} & \text{中} & \text{中} & 2\text{--}4^\circ \\
\text{推力球轴承} & \text{无} & \text{很高} & \text{中} & 2\text{--}4^\circ \\
\text{滚针轴承} & \text{高} & \text{低} & \text{中} & 0.5^\circ \\
\end{array}
$$

**轴承类型按载荷方向、转速、不对中容许量和空间限制选定。只按载荷额定值选轴承的工程师不是在选轴承，而是在选一个会因磨损、过热或不对中而失效的轴承。**
:::

::: definition L10 寿命与基本额定动载荷 {#def-l10-life}
**L10 寿命**是 90 % 的轴承存活、10 % 因疲劳失效时的转数（恒定转速下为小时数）。L10 寿命为：

$$
L _ { 1 0 } \; = \; \left( { \frac { C } { P } } \right) ^ { p }
$$

其中 $C$ 是基本额定动载荷，$P$ 是当量动载荷，$p$ 是寿命指数：

$$
p \; = \; { \left\{ \begin{array} { l l } { 3 } & { \text{球轴承} } \\ { 1 0 / 3 } & { \text{滚子轴承} } \end{array} \right. }
$$

**以小时计的 L10 寿命**为：

$$
L _ { 1 0 , h } \; = \; { \frac { 1 0 ^ { 6 } } { 6 0 \, n } } \, \left( { \frac { C } { P } } \right) ^ { p }
$$

其中 $n$ 是转速，单位 rpm。

$$
\begin{array} { l c l }
\textbf{应用} & \textbf{典型 } L _ { 1 0 , h } \textbf{（小时）} & \textbf{原因} \\ \hline
\text{电动机} & 1 0 0 \ 0 0 0 & \text{连续运转，维护少} \\
\text{齿轮箱} & 5 0 \ 0 0 0 \text{--} 1 0 0 \ 0 0 0 & \text{连续运转} \\
\text{机床} & 1 0 \ 0 0 0 \text{--} 5 0 \ 0 0 0 & \text{间歇运转，精度高} \\
\text{汽车轮毂} & 5 0 \ 0 0 0 \text{--} 1 0 0 \ 0 0 0 & \text{密封，终身润滑} \\
\text{航空发动机} & 5 \ 0 0 0 \text{--} 1 0 \ 0 0 0 & \text{定期大修} \\
\text{矿山设备} & 2 0 \ 0 0 0 \text{--} 5 0 \ 0 0 0 & \text{重载，冲击载荷} \\
\end{array}
$$

**L10 寿命是轴承的设计依据，而设计依据正是轴承按 L10 寿命而不是静载荷额定值选型的原因。按静载荷额定值选轴承的工程师不是在选轴承，而是在选一个会因疲劳而失效的轴承。**
:::

::: definition 当量动载荷 {#def-equivalent-load}
**当量动载荷**是这样一种恒定径向载荷：它产生的 L10 寿命与实际径向-轴向联合载荷产生的 L10 寿命相同：

$$
P \; = \; X \, F _ { r } \; + \; Y \, F _ { a }
$$

其中 $F _ { r }$ 是径向载荷，$F _ { a }$ 是轴向载荷，$X$ 和 $Y$ 是载荷系数。

$$
\begin{array} { l c c c }
\textbf{轴承类型} & \textbf{ } X & \textbf{ } Y & \textbf{条件} \\ \hline
\text{深沟球轴承} & 1 & 0 & F _ { a } / F _ { r } \le e \\
\text{深沟球轴承} & 0 . 5 6 & 1 . 5 \text{--} 2 . 5 & F _ { a } / F _ { r } > e \\
\text{角接触球轴承} & 1 & 0 & F _ { a } / F _ { r } \le e \\
\text{角接触球轴承} & 0 . 4 4 & 1 . 5 \text{--} 2 . 0 & F _ { a } / F _ { r } > e \\
\text{圆锥滚子轴承} & 0 . 4 & 0 . 4 / { \tan \alpha } & \text{总是} \\
\text{圆柱滚子轴承} & 1 & 0 & \text{仅径向} \\
\end{array}
$$

其中 $e$ 是轴向载荷系数（通常 0.2–0.4）。

**当量动载荷正是存在轴向载荷时轴承寿命被削减 50–90 % 的原因。轴承承受径向-轴向联合载荷却只用径向载荷的工程师，不是在计算 L10 寿命，而是在瞎猜。**
:::

::: example L10 寿命计算 {#ex-l10-life level=3 check="2"}
某深沟球轴承的基本额定动载荷 $C = 5 0$ kN，承受径向载荷 $F _ { r } = 1 0$ kN 和轴向载荷 $F _ { a } = 5$ kN。转速 1 500 rpm。轴向载荷系数 $e = 0 . 3$，当 $F _ { a } / F _ { r } > e$ 时 $X = 0 . 5 6$、$Y = 1 . 8$。试计算以小时计的 L10 寿命。

**载荷比：**

$$
{ \frac { F _ { a } } { F _ { r } } } \; = \; { \frac { 5 } { 1 0 } } \; = \; 0 . 5 \; > \; e \; = \; 0 . 3
$$

**当量动载荷：**

$$
P \; = \; 0 . 5 6 \times 1 0 + 1 . 8 \times 5 \; = \; 5 . 6 + 9 . 0 \; = \; 1 4 . 6 \ \text{kN}
$$

**以转计的 L10 寿命：**

$$
L _ { 1 0 } \; = \; \left( { \frac { 5 0 } { 1 4 . 6 } } \right) ^ { 3 } \; = \; 3 . 4 2 ^ { 3 } \; = \; 4 0 . 0 \times 1 0 ^ { 6 } \ \text{转}
$$

**以小时计的 L10 寿命：**

$$
L _ { 1 0 , h } \; = \; { \frac { 1 0 ^ { 6 } } { 6 0 \times 1 \ 5 0 0 } } \times 4 0 . 0 \; = \; { \bf 4 4 5 } \ \text{小时}
$$

**L10 寿命为 445 小时，远低于电动机典型的 100 000 小时要求。工程师必须选用更大的轴承或减小载荷。**
:::

::: definition SKF 通用寿命方程 {#def-skf-life}
**SKF 通用寿命方程**（寿命修正法）把 L10 寿命推广到考虑可靠度、润滑、污染和疲劳载荷极限：

$$
L _ { n m } \; = \; a _ { 1 } \, a _ { \text{SKF } } \, L _ { 1 0 }
$$

其中 $a _ { 1 }$ 是可靠度系数，$a _ { \text{SKF } }$ 是寿命修正系数。

$$
\begin{array} { l c c }
\textbf{可靠度} & \textbf{ } a _ { 1 } & \textbf{ } L _ { n m } / L _ { 1 0 } \\ \hline
90 \ \% \; ( L _ { 1 0 } ) & 1 . 0 0 & 1 . 0 0 \\
95 \ \% \; ( L _ { 5 } ) & 0 . 6 4 & 0 . 6 4 \\
96 \ \% \; ( L _ { 4 } ) & 0 . 5 5 & 0 . 5 5 \\
99 \ \% \; ( L _ { 1 } ) & 0 . 2 1 & 0 . 2 1 \\
\end{array}
$$

**可靠度系数 $a _ { 1 }$ 在 99 % 可靠度下把寿命降低 79 %，而这一降低正是高可靠度应用必须放大轴承尺寸的原因。在应用要求 99 % 可靠度时却使用 L10 寿命（90 % 可靠度）的工程师，不是在按可靠度设计，而是在为失效的那 10 % 设计。**
:::

## 2. 滑动轴承

::: definition 雷诺方程与滑动轴承 {#def-reynolds}
**滑动轴承**是轴颈（轴本身）在静止轴瓦内旋转的滑动轴承，载荷由动压润滑膜承受。润滑膜中的压力分布由**雷诺方程**控制：

$$
{ \frac { \partial } { \partial x } } \! \left( { \frac { h ^ { 3 } } { \mu } } { \frac { \partial p } { \partial x } } \right) + { \frac { \partial } { \partial z } } \! \left( { \frac { h ^ { 3 } } { \mu } } \! \, { \frac { \partial p } { \partial z } } \right) \; = \; 6 U { \frac { \partial h } { \partial x } }
$$

其中 $h$ 是膜厚，$\mu$ 是动力黏度，$p$ 是压强，$U$ 是表面速度。

**膜厚比**（偏心率）为：

$$
\varepsilon \; = \; { \frac { e } { c } } \; = \; 1 - { \frac { h _ { \min } } { c } }
$$

其中 $e$ 是偏心距，$c$ 是径向间隙，$h _ { \min }$ 是最小膜厚。

**偏心率 $\varepsilon$ 的取值范围是 0（同心，无载荷）到 1（金属接触，失效）。设计偏心率取 0.6–0.8，而这一范围正是滑动轴承按最小膜厚 $h _ { \min } = ( 0 . 2 \text{--} 0 . 4 ) \, c$ 设计的原因。**
:::

::: definition 彼得罗夫方程与摩擦因数 {#def-petroff}
**彼得罗夫方程**在轻载假设下估算滑动轴承的摩擦因数：

$$
f \; = \; { \frac { 2 \pi ^ { 2 } } { S } } \; + \; 0 . 6 \, { \frac { c } { r } }
$$

其中 $S$ 是**索默菲尔德数**：

$$
S \; = \; \left( { \frac { r } { c } } \right) ^ { 2 } { \frac { \mu \, n } { P }}
$$

其中 $r$ 是轴颈半径，$c$ 是径向间隙，$\mu$ 是动力黏度，$n$ 是转速（转/秒），$P = W / ( r L )$ 是轴承压强。

$$
\begin{array} { l c c }
\textbf{轴承状态} & \textbf{ } f \textbf{（摩擦因数）} & \textbf{ } S \textbf{（索默菲尔德数）} \\ \hline
\text{轻载} & 0 . 0 0 1 \text{--} 0 . 0 0 5 & > 5 \\
\text{中载} & 0 . 0 0 5 \text{--} 0 . 0 1 & 1 \text{--} 5 \\
\text{重载} & 0 . 0 1 \text{--} 0 . 0 3 & 0 . 1 \text{--} 1 \\
\text{边界润滑} & 0 . 0 5 \text{--} 0 . 2 & < 0 . 1 \\
\end{array}
$$

**索默菲尔德数是滑动轴承设计中最重要的参数，因为索默菲尔德数决定偏心率、摩擦数和最小膜厚。不计算索默菲尔德数就设计滑动轴承的工程师不是在轴承设计，而是在瞎猜。**
:::

::: example 滑动轴承设计 {#ex-journal-bearing level=3 check="2"}
某滑动轴承直径 50 mm，长度 50 mm，径向间隙 0.05 mm，转速 3 000 rpm，载荷 5 kN。润滑剂黏度 0.03 Pa·s。试计算索默菲尔德数、最小膜厚和摩擦因数。

**轴承压强：**

$$
P \; = \; { \frac { W } { r \, L } } \; = \; { \frac { 5 \ 0 0 0 } { 2 5 \times 5 0 } } \; = \; 4 \ \text{MPa}
$$

**索默菲尔德数：**

$$
S \; = \; \left( { \frac { r } { c } } \right) ^ { 2 } { \frac { \mu \, n } { P } } \; = \; \left( { \frac { 2 5 } { 0 . 0 5 } } \right) ^ { 2 } \times { \frac { 0 . 0 3 \times 5 0 } { 4 \times 1 0 ^ { 6 } } } \; = \; 2 5 0 \ 0 0 0 \times { \frac { 1 . 5 } { 4 \times 1 0 ^ { 6 } } } \; = \; { \bf 0 . 0 9 4 }
$$

**偏心率（查赖蒙迪-博伊德（Raimondi-Boyd）曲线）：** $\varepsilon \approx 0 . 9$（重载）。

**最小膜厚：**

$$
h _ { \min } \; = \; c \, ( 1 - \varepsilon ) \; = \; 0 . 0 5 \times ( 1 - 0 . 9 ) \; = \; { \bf 0 . 0 0 5 } \ \text{mm} \; = \; 5 \ \mu \text{m}
$$

**摩擦因数（彼得罗夫）：**

$$
f \; = \; { \frac { 2 \pi ^ { 2 } } { S } } \times { \frac { c } { r } } \; = \; { \frac { 2 \pi ^ { 2 } } { 0 . 0 9 4 } } \times { \frac { 0 . 0 5 } { 2 5 } } \; = \; 2 1 0 \times 0 . 0 0 2 \; = \; { \bf 0 . 0 4 2 }
$$

**最小膜厚（5 μm）低于推荐的最低值 10–20 μm，而摩擦因数（0.042）处于边界润滑区。工程师必须提高转速、减小载荷或增大黏度，才能达到动压润滑区。**
:::
## 3. 轴承选型与设计

::: definition 轴承选型准则 {#def-bearing-selection}
**轴承选型**是一个多准则决策，要考虑载荷、转速、寿命、精度、刚度、噪声和成本：

$$
\begin{array} { l c c c }
\textbf{准则} & \textbf{球轴承} & \textbf{滚子轴承} & \textbf{滑动轴承} \\ \hline
\text{径向承载能力} & \text{中} & \text{很高} & \text{很高} \\
\text{轴向承载能力} & \text{中} & \text{高} & \text{低} \\
\text{转速极限} & \text{很高} & \text{中} & \text{很高} \\
\text{刚度} & \text{中} & \text{高} & \text{低} \\
\text{精度} & \text{高} & \text{中} & \text{低} \\
\text{噪声} & \text{低} & \text{中} & \text{很低} \\
\text{成本} & \text{低} & \text{中} & \text{高} \\
\text{维护} & \text{低} & \text{中} & \text{高} \\
\end{array}
$$

**轴承选型正是轴承成为机器中最重要零件的原因：轴承决定机器的寿命、精度、效率和噪声。只按载荷额定值选轴承的工程师不是在选轴承，而是在选一个会因磨损、过热或不对中而失效的轴承。**
:::

::: definition 静载荷额定值与安全因数 {#def-static-load}
**静载荷额定值**（$C _ { 0 }$，即基本额定静载荷）是在最大受载接触点产生 $0 . 0 0 0 1 \, D$（$D$ 为滚动体直径）永久变形时的载荷。**当量静载荷**为：

$$
P _ { 0 } \; = \; X _ { 0 } \, F _ { r } \; + \; Y _ { 0 } \, F _ { a }
$$

**静力安全因数**为：

$$
s _ { 0 } \; = \; { \frac { C _ { 0 } } { P _ { 0 } } }
$$

$$
\begin{array} { l c l }
\textbf{应用} & \textbf{ } s _ { 0 } & \textbf{原因} \\ \hline
\text{精密主轴} & 2 \text{--} 4 & \text{振动、冲击} \\
\text{一般机械} & 1 . 5 \text{--} 2 . 5 & \text{正常运转} \\
\text{低冲击、平稳} & 1 \text{--} 1 . 5 & \text{平稳运转} \\
\text{重冲击、撞击} & 2 . 5 \text{--} 4 & \text{冲击载荷} \\
\text{静止、偶尔受载} & 0 . 5 \text{--} 1 & \text{极少受载} \\
\end{array}
$$

**静力安全因数正是轴承不会被冲击载荷压出压痕的原因。计算 L10 寿命却不校核静载荷额定值的工程师，不是在轴承设计，而是在设计一个会因压痕失效的轴承。**
:::

::: example 电动机轴承选型 {#ex-bearing-selection level=3 check="3"}
某电动机轴的径向载荷为 2 kN，轴向载荷为 0.5 kN，转速 3 000 rpm，要求的 L10 寿命为 100 000 小时。试选择轴承。

**所需动载荷额定值：**

$$
L _ { 1 0 } \; = \; { \frac { 1 0 ^ { 6 } } { 6 0 \times 3 \ 0 0 0 } } \times \left( { \frac { C } { P } } \right) ^ { 3 } \; = \; 1 0 0 \ 0 0 0 \ \text{小时}
$$

$$
\left( { \frac { C } { P } } \right) ^ { 3 } \; = \; { \frac { 1 0 0 \ 0 0 0 \times 6 0 \times 3 \ 0 0 0 } { 1 0 ^ { 6 } } } \; = \; 1 8 \ 0 0 0
$$

$$
{ \frac { C } { P } } \; = \; 1 8 \ 0 0 0 ^ { 1 / 3 } \; = \; 2 6 . 2
$$

**当量动载荷：** $P = F _ { r } = 2$ kN（假设 $F _ { a } / F _ { r } < e$）。

**所需基本额定动载荷：**

$$
C \; = \; 2 6 . 2 \times 2 \; = \; { \bf 5 2 } \ \text{kN}
$$

**工程师会选用 6210 深沟球轴承（$C = 5 5 . 3$ kN，$d = 5 0$ mm），其基本额定动载荷为 55.3 kN，超过所需的 52 kN。**
:::

::: example 齿轮箱轴承选型 {#ex-bearing-gearbox level=3 check="2"}
某齿轮箱输入轴的径向载荷为 3 kN，轴向载荷为 1 kN，转速 1 450 rpm，要求的 L10 寿命为 40 000 小时。轴向载荷系数 $e = 0 . 3$，当 $F _ { a } / F _ { r } > e$ 时 $X = 0 . 5 6$、$Y = 1 . 6$。试选择轴承。

**载荷比：**

$$
{ \frac { F _ { a } } { F _ { r } } } \; = \; { \frac { 1 } { 3 } } \; = \; 0 . 3 3 \; > \; e \; = \; 0 . 3
$$

**当量动载荷：**

$$
P \; = \; 0 . 5 6 \times 3 + 1 . 6 \times 1 \; = \; 1 . 6 8 + 1 . 6 \; = \; 3 . 2 8 \ \text{kN}
$$

**所需基本额定动载荷：**

$$
\left( { \frac { C } { P } } \right) ^ { 3 } \; = \; { \frac { 4 0 \ 0 0 0 \times 6 0 \times 1 \ 4 5 0 } { 1 0 ^ { 6 } } } \; = \; 3 \ 4 8 0
$$

$$
{ \frac { C } { P } } \; = \; 3 \ 4 8 0 ^ { 1 / 3 } \; = \; 1 5 . 1
$$

$$
C \; = \; 1 5 . 1 \times 3 . 2 8 \; = \; { \bf 4 9 } \ \text{kN}
$$

**工程师会选用 6209 深沟球轴承（$C = 5 2 . 8$ kN，$d = 4 5$ mm），其基本额定动载荷为 52.8 kN，超过所需的 49 kN。6209 轴承的 L10 寿命为 46 000 小时，超过所需的 40 000 小时。**
:::

## 习题

::: exercise 滚子轴承的 L10 寿命 {#ex-l10-roller level=3 check="2"}
某圆柱滚子轴承 $C = 8 0$ kN，承受径向载荷 20 kN。转速 1 000 rpm。试计算以小时计的 L10 寿命。

::: solution
$$
L _ { 1 0 } \; = \; \left( { \frac { 8 0 } { 2 0 } } \right) ^ { 1 0 / 3 } \; = \; 4 ^ { 3 . 3 3 } \; = \; 9 0 . 5 \times 1 0 ^ { 6 } \ \text{转}
$$

$$
L _ { 1 0 , h } \; = \; { \frac { 1 0 ^ { 6 } } { 6 0 \times 1 \ 0 0 0 } } \times 9 0 . 5 \; = \; { \bf 1 \ 5 0 8 } \ \text{小时}
$$

**L10 寿命为 1 508 小时。滚子轴承的寿命-载荷曲线比球轴承更陡，而这陡峭正是滚子轴承对过载更敏感的原因。**
:::
:::

::: exercise 当量动载荷 {#ex-equivalent-load level=3 check="2"}
某深沟球轴承 $F _ { r } = 8$ kN，$F _ { a } = 4$ kN。轴向载荷系数 $e = 0 . 3$，当 $F _ { a } / F _ { r } > e$ 时 $X = 0 . 5 6$、$Y = 2 . 0$。试计算当量动载荷。

::: solution
$$
{ \frac { F _ { a } } { F _ { r } } } \; = \; { \frac { 4 } { 8 } } \; = \; 0 . 5 \; > \; e \; = \; 0 . 3
$$

$$
P \; = \; 0 . 5 6 \times 8 + 2 . 0 \times 4 \; = \; 4 . 4 8 + 8 . 0 \; = \; { \bf 1 2 . 5 } \ \text{kN}
$$

**当量动载荷（12.5 kN）比径向载荷（8 kN）高 56 %，因为轴向载荷不可忽略。使用径向载荷的工程师不是在计算 L10 寿命，而是在瞎猜。**
:::
:::

::: exercise 索默菲尔德数 {#ex-sommerfeld level=3 check="1"}
某滑动轴承 $r = 3 0$ mm，$c = 0 . 0 6$ mm，$\mu = 0 . 0 2$ Pa·s，$n = 2 \ 5 0 0$ rpm，$P = 3$ MPa。试计算索默菲尔德数。

::: solution
$$
S \; = \; \left( { \frac { r } { c } } \right) ^ { 2 } { \frac { \mu \, n } { P } } \; = \; \left( { \frac { 3 0 } { 0 . 0 6 } } \right) ^ { 2 } \times { \frac { 0 . 0 2 \times 4 1 . 6 7 } { 3 \times 1 0 ^ { 6 } } }
$$

$$
S \; = \; 2 5 0 \ 0 0 0 \times { \frac { 0 . 8 3 3 } { 3 \times 1 0 ^ { 6 } } } \; = \; 2 5 0 \ 0 0 0 \times 2 . 7 8 \times 1 0 ^ { - 7 } \; = \; { \bf 0 . 0 7 }
$$

**索默菲尔德数（0.07）处于重载区（$S < 0 . 1$），这意味着轴承工作在边界润滑区。工程师必须提高转速、减小载荷或增大黏度，才能达到流体动压润滑区。**
:::
:::

::: exercise 静力安全因数 {#ex-static-safety level=3 check="2"}
某轴承 $C _ { 0 } = 4 5$ kN，承受静径向载荷 15 kN 和静轴向载荷 5 kN。静载荷系数 $X _ { 0 } = 0 . 6$、$Y _ { 0 } = 0 . 5$。试计算静力安全因数。

::: solution
$$
P _ { 0 } \; = \; 0 . 6 \times 1 5 + 0 . 5 \times 5 \; = \; 9 + 2 . 5 \; = \; 1 1 . 5 \ \text{kN}
$$

$$
s _ { 0 } \; = \; { \frac { 4 5 } { 1 1 . 5 } } \; = \; { \bf 3 . 9 1 }
$$

**静力安全因数（3.91）超过一般机械的典型要求 1.5–2.5。轴承不会发生压痕，是安全的。**
:::
:::

::: exercise 可靠度系数 {#ex-reliability-factor level=3 check="1"}
某轴承的 L10 寿命为 50 000 小时。试计算 L1 寿命（99 % 可靠度）和 L5 寿命（95 % 可靠度）。

::: solution
$$
L _ { 1 } \; = \; a _ { 1 } \times L _ { 1 0 } \; = \; 0 . 2 1 \times 5 0 \ 0 0 0 \; = \; { \bf 1 0 \ 5 0 0 } \ \text{小时}
$$

$$
L _ { 5 } \; = \; 0 . 6 4 \times 5 0 \ 0 0 0 \; = \; { \bf 3 2 \ 0 0 0 } \ \text{小时}
$$

**L1 寿命（10 500 小时）是 L10 寿命（50 000 小时）的 21 %，而这降低正是高可靠度应用必须放大轴承尺寸的原因。在应用要求 99 % 可靠度时却使用 L10 寿命的工程师，不是在按可靠度设计，而是在为失效的那 10 % 设计。**
:::
:::

::: exercise 最小油膜厚度 {#ex-min-film level=3 check="2"}
某滑动轴承的径向间隙为 0.08 mm，偏心率为 0.75。试计算最小油膜厚度。它对流体动压润滑足够吗？

::: solution
$$
h _ { \min } \; = \; c \, ( 1 - \varepsilon ) \; = \; 0 . 0 8 \times ( 1 - 0 . 7 5 ) \; = \; 0 . 0 8 \times 0 . 2 5 \; = \; { \bf 0 . 0 2 } \ \text{mm} \; = \; 2 0 \ \mu \text{m}
$$

**最小油膜厚度（20 μm）处于推荐范围（流体动压润滑为 10–20 μm）的下限。轴承工作在动压区的边界上，工程师应提高转速或减小载荷以增大油膜厚度。**
:::
:::

::: exercise 推导：L10 寿命方程 {#ex-derive-l10 level=4 check="3"}
试证明 L10 寿命方程 $L _ { 1 0 } = ( C / P ) ^ { p }$ 由疲劳寿命模型 $N \propto P ^ { - p }$ 导出，其中球轴承 $p = 3$，滚子轴承 $p = 1 0 / 3$。并对球轴承计算载荷加倍时的寿命比 $L _ { 2 } / L _ { 1 }$。

::: solution
疲劳寿命模型指出，失效前的循环数与载荷的 $p$ 次幂成反比：

$$
N \; \propto \; P ^ { - p } \quad \Longrightarrow \quad N \; = \; k \, P ^ { - p }
$$

在基本额定动载荷 $C$ 下，寿命为 $1 0 ^ { 6 }$ 转：

$$
1 0 ^ { 6 } \; = \; k \, C ^ { - p } \quad \Longrightarrow \quad k \; = \; 1 0 ^ { 6 } \, C ^ { p }
$$

代入：

$$
L _ { 1 0 } \; = \; { \frac { k \, P ^ { - p } } { 1 0 ^ { 6 } } } \; = \; \left( { \frac { C } { P } } \right) ^ { p }
$$

载荷加倍时的寿命比：

$$
{ \frac { L _ { 2 } } { L _ { 1 } } } \; = \; \left( { \frac { P _ { 1 } } { P _ { 2 } } } \right) ^ { p } \; = \; \left( { \frac { 1 } { 2 } } \right) ^ { 3 } \; = \; { \bf 0 . 1 2 5 } \; \; ( 1 2 . 5 \ \% )
$$

**载荷加倍时寿命降到 12.5 %，而这降低正是轴承不应过载的原因。把载荷加倍的工程师把寿命削减了 87.5 %，而这 87.5 % 正是轴承按 L10 寿命而不是静载荷额定值选型的原因。** $\blacksquare$
:::
:::

::: exercise 推导：索默菲尔德数 {#ex-derive-sommerfeld level=4 check="1"}
试通过验证各项的量纲，证明索默菲尔德数 $S = ( r / c ) ^ { 2 } \mu n / P$ 是无量纲参数。并对 $r = 2 5$ mm、$c = 0 . 0 5$ mm、$\mu = 0 . 0 4$ Pa·s、$n = 3 \ 6 0 0$ rpm、$P = 2$ MPa 计算索默菲尔德数。

::: solution
**量纲分析：**

$$
[ ( r / c ) ^ { 2 } ] \; = \; [ \text{无量纲} ] ^ { 2 } \; = \; \text{无量纲}
$$

$$
[ \mu \, n / P ] \; = \; { \frac { [ \text{Pa} { \cdot } \text{s} ] \times [ \text{s} ^ { - 1 } ] } { [ \text{Pa} ] } } \; = \; { \frac { [ \text{Pa} ] } { [ \text{Pa} ] } } \; = \; \text{无量纲}
$$

**索默菲尔德数是无量纲的，而这无量纲正是索默菲尔德数成为滑动轴承设计中最重要参数的原因。**

$$
S \; = \; \left( { \frac { 2 5 } { 0 . 0 5 } } \right) ^ { 2 } \times { \frac { 0 . 0 4 \times 6 0 } { 2 \times 1 0 ^ { 6 } } } \; = \; 2 5 0 \ 0 0 0 \times { \frac { 2 . 4 } { 2 \times 1 0 ^ { 6 } } } \; = \; 2 5 0 \ 0 0 0 \times 1 . 2 \times 1 0 ^ { - 6 } \; = \; { \bf 0 . 3 }
$$

**索默菲尔德数（0.3）处于中载区（$0 . 1 < S < 1$），这意味着轴承工作在混合润滑区。工程师应提高转速或减小载荷，才能达到流体动压润滑区。** $\blacksquare$
:::
:::

## 本讲的去向

- **[[machine-design/shafts]]** — 轴承处的转角对球轴承必须小于 0.5°，对滚子轴承必须小于 0.25°。
- **[[machine-design/fatigue]]** — 轴承寿命是疲劳寿命，而疲劳寿命正是轴承按 L10 寿命选型的原因。
- **[[machine-design/gear-design]]** — 轴承按齿轮的径向载荷和轴向载荷选型。
- **[[machine-design/clutches-brakes-belts]]** — 轴承按带和链的拉力选型。
- **[[machine-design/fasteners-joints]]** — 轴承配合正是配合正确时轴承寿命比配合错误时长 5 倍的原因。
- **[[vibrations/vibration-fundamentals]]** — 轴承刚度是转子动力学分析的输入。
- **[[materials-science/mechanical-properties]]** — 轴承材料的硬度和疲劳强度决定载荷额定值。
- **[[fluid-mechanics/fluid-properties|润滑理论]]** — 雷诺方程是滑动轴承分析的基础。

::: history 轴承：从原木滚轴到 SKF 通用寿命方程 {#history-bearings}
**公元前 3000 年** — **最早的滚动轴承**出土于一辆埃及战车：车轴与车轮之间的一根木质滚轴。**埃及滚轴轴承正是轴承成为最古老机器元件的原因，而这古老正是轴承成为最精熟机器元件的原因。**

**1794 年** — **菲利普·沃恩（Philip Vaughan）** 在英国为第一个球轴承申请了专利。**沃恩的专利正是球轴承成为应用最广的轴承类型的原因，而这专利正是球轴承成为最精熟轴承类型的原因。**

**1839 年** — **亨利·贝塞麦（Henry Bessemer）** 提出自润滑轴承，用多孔材料供给润滑剂。**贝塞麦的自润滑轴承正是含油粉末冶金轴承成为小家电中应用最广的轴承的原因。**

**1907 年** — **斯文·温奎斯特（Sven Wingquist）** 在瑞典哥德堡创立 **SKF**，并发明了调心球轴承。**温奎斯特的调心球轴承正是轴承能容忍不对中的原因，而这容忍正是轴承成为最宽容机器元件的原因。**

**1942 年** — **伦德贝里（Lundberg）与帕姆格伦（Palmgren）** 发表**轴承寿命理论**，把 L10 寿命与载荷额定值联系起来：$L _ { 1 0 } = ( C / P ) ^ { p }$。**伦德贝里-帕姆格伦理论正是轴承按 L10 寿命而不是静载荷额定值选型的原因，而这选型正是轴承成为最可预测机器元件的原因。**

**1953 年** — **ISO 281 标准**发布，把轴承寿命计算固定为规范。**ISO 281 标准正是轴承寿命成为标准化计算而不是猜测的原因。**

**1995 年** — **SKF 通用寿命方程**发布，把 L10 寿命推广到考虑可靠度、润滑、污染和疲劳载荷极限。**SKF 通用寿命方程正是轴承寿命成为更准确预测的原因，而这准确正是轴承成为最可靠机器元件的原因。**

**2000 年** — 轴承的**状态监测**（振动分析、油液分析、红外热像）成为工业维护的标准做法。**状态监测正是轴承在失效之前被更换的原因，而这更换正是轴承成为最受监测机器元件的原因。**
:::

::: summary 轴承 {#summary-bearings}
- **轴承是旋转轴与静止箱体之间的界面，轴承决定机器的寿命、精度和效率。** 轴承是机器失效最常见的原因。
- **L10 寿命是 90 % 的轴承存活、10 % 因疲劳失效时的转数（或小时数）。** L10 寿命是轴承的设计依据。
- **当量动载荷 $P = X F _ { r } + Y F _ { a }$ 考虑了径向与轴向联合载荷。** 轴承承受联合载荷却只用径向载荷的工程师，不是在计算 L10 寿命，而是在瞎猜。
- **SKF 通用寿命方程把 L10 寿命推广到考虑可靠度、润滑、污染和疲劳载荷极限。** 可靠度系数 $a _ { 1 }$ 在 99 % 可靠度下把寿命降低 79 %。
- **静载荷额定值 $C _ { 0 }$ 必须大于当量静载荷 $P _ { 0 }$ 并取 1.5–3 的安全因数。** 静力安全因数正是轴承不会被冲击载荷压出压痕的原因。
- **滑动轴承由雷诺方程支配，而雷诺方程由索默菲尔德数求解。** 索默菲尔德数决定偏心率、摩擦因数和最小油膜厚度。
- **彼得罗夫方程在轻载假设下估算滑动轴承的摩擦因数。** 流体动压润滑时摩擦因数为 0.001–0.005，边界润滑时为 0.05–0.2。
- **轴承选型是多准则决策：载荷、转速、寿命、精度、刚度、噪声和成本。** 只按载荷额定值选轴承的工程师不是在选轴承，而是在选一个会因磨损、过热或不对中而失效的轴承。
- **流体动压润滑要求最小油膜厚度为 10–20 μm。** 不计算最小油膜厚度就设计滑动轴承的工程师不是在轴承设计，而是在瞎猜。
- **轴承配合正是配合正确时轴承寿命比配合错误时长 5 倍的原因。** 配合是轴承安装中最重要的因素。
:::

- **Joseph E. Shigley、Charles R. Mischke 与 Richard G. Budynas（2015）** — 《机械设计》（*Mechanical Engineering Design*）第 11 版。McGraw-Hill。轴承寿命计算、当量动载荷与滑动轴承。
- **SKF（2023）** — 《SKF 滚动轴承目录》（*SKF Rolling Bearings Catalogue*）。SKF。轴承尺寸、载荷额定值与选型表。
- **ISO 281:2007** — 《滚动轴承 — 动载荷额定值与额定寿命》（*Rolling Bearings — Dynamic Load Ratings and Rating Life*）。ISO。轴承寿命计算标准。
- **B.J. Hamrock、S.R. Schmid 与 B.O. Jacobson（2004）** — 《流体膜润滑基础》（*Fundamentals of Fluid Film Lubrication*）第 2 版。Marcel Dekker。雷诺方程、滑动轴承与索默菲尔德数。
- **A. Raimondi 与 J. Boyd（1958）** — "A general theory for the finite width journal bearing."（有限宽滑动轴承的一般理论）*Journal of Basic Engineering*, 80(3), 599–610。滑动轴承的赖蒙迪-博伊德图表。
- **Palmgren A.（1964）** — 《球轴承与滚子轴承工程》（*Ball and Roller Bearing Engineering*）第 3 版。Burstrom。轴承寿命理论与轴承选型。
- **John M. Vance（1988）** — 《转子动力学及其在透平机械中的应用》（*Rotordynamics with Turbomachinery Applications*）。Oxford University Press。轴承刚度、转子动力学与临界转速。
