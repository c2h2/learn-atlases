每一根旋转的轴都必须由某种既能固定它、又能让它转动的东西来支承。这种东西就是轴承，而构成轴承的方式有两种本质上不同的途径。在**滚动轴承**中，轴与轴承座之间隔着在淬硬套圈之间滚动的球或滚子；表面之间是滚动而不是滑动，因此即使从静止起动，摩擦也很小。在**滑动轴承**（径向滑动轴承）中，轴——即轴颈——在一个间隙很小的孔内转动，间隙中充满润滑油；当轴转得足够快时，它把油带入间隙逐渐收窄的部分，建立起压力，把轴从孔壁上托起，使两表面根本不接触。

这两类轴承的失效方式不同，设计方法也不同。润滑良好且保持清洁的滚动轴承最终因**接触疲劳**（滚动接触疲劳）而失效：在球或滚子下经受数以百万计的应力循环之后，滚道表面下方萌生裂纹，一片金属剥落下来。其设计是统计性的：名义上相同的轴承，寿命分散在十比一甚至更大的范围内，人们按规定可靠度下的规定寿命从样本中选用轴承。具有完整油膜的滑动轴承在原则上既不磨损，也没有疲劳寿命；当油膜太薄、油温太高或载荷超过油膜的承载能力时，它就失效。其设计属于流体力学：雷诺（Osborne Reynolds）的润滑理论。

本章前半部分讨论滚动轴承，后半部分讨论流体动压滑动轴承。提供轴承载荷的轴的分析见[[machine-design/shafts]]；寿命方程背后的疲劳概念见[[machine-design/fatigue]]；干摩擦见[[statics/friction]]，黏度见[[fluid-mechanics/fluid-properties]]。

实际的轴承选用遵循轴承制造商的样本和现行标准——ISO 281:2007（额定动载荷与额定寿命）、ISO 76:2006（额定静载荷），对滑动轴承则有 ISO 7902 系列及类似的指南。本章讲授这些标准背后的原理，不能代替标准本身。符号采用 Budynas 与 Nisbett《Shigley 机械工程设计》（*Shigley's Mechanical Engineering Design*）第 11、12 章的记法，样本中使用 ISO 符号之处也采用 ISO 符号。

## 滚动轴承：组成与类型

滚动轴承由四部分组成：**内圈**，通常以过盈配合装在轴上；**外圈**，装在轴承座孔中；**滚动体**（球，或圆柱、圆锥、球面、滚针等滚子），在称为**滚道**的沟槽或轨道中滚动；以及使滚动体均匀分布的**保持架**。许多轴承还带有密封圈或防尘盖，并终身润滑脂润滑。

接触的几何形状决定轴承能承受哪些载荷。球与滚道在一点接触，受载后扩展为一个小椭圆；滚子则沿一条线接触。线接触在相同空间内能承受更大的载荷，但对不对中更为敏感。接触的方向——即通过接触点的连线与径向平面之间的**接触角**——决定轴承能承受多大的轴向载荷：接触角为零的是纯径向轴承，接触角大的是为承受推力而设计的轴承。

| 类型 | 径向载荷 | 轴向载荷 | 说明 |
|---|---|---|---|
| 深沟球轴承 | 中等 | 中等，双向 | 最常用的类型；运转平静，适合高速，几乎不能容许不对中 |
| 角接触球轴承 | 中等 | 大，单向 | 接触角通常为$15°$–$40°$；成对使用，常加预紧，用于主轴和泵 |
| 调心球轴承 | 中等 | 小 | 外圈滚道为球面，内圈可以倾斜；能容许轴的挠曲和不对中 |
| 圆柱滚子轴承 | 大 | 无（带挡边时可承受小的轴向载荷） | 线接触；允许轴的轴向移动，因而用作"游动"轴承 |
| 圆锥滚子轴承 | 大 | 大，单向 | 滚子与滚道均为圆锥，锥顶交于轴线上一点；成对用于轮毂和齿轮箱 |
| 调心滚子轴承 | 很大 | 中等 | 能自动调心；用于重型机械、冲击载荷、挠曲较大的轴 |
| 滚针轴承 | 就其尺寸而言很大 | 无 | 径向截面很小；常直接在淬硬的轴上运转 |
| 推力球轴承或推力滚子轴承 | 无 | 大 | 用于中等转速下的纯轴向载荷 |

此表是定性的：实际承载能力和极限转速见各制造商的样本。一根轴通常由两个轴承支承，一个为**定位**轴承（轴向固定，承受两个方向的轴向载荷），另一个为**非定位**（游动）轴承（可在轴向滑动，或采用内部允许轴向移动的圆柱滚子轴承），这样轴的热膨胀不会使两个轴承互相顶紧。

## 接触疲劳与额定寿命

球每滚过滚道上的一点，该点就受到一次尖锐的赫兹接触应力脉冲，工作中通常为$1$–$3\ \mathrm{GPa}$。最大切应力位于表面下方不远处，其深度与接触区半宽同一量级；疲劳裂纹正是在那里、在钢中的夹杂物或其他薄弱点处萌生。裂纹向表面扩展，一个凹坑或一片金属剥落下来——**剥落**——此后轴承变得有噪声、运转粗糙，即认为已经失效。

这一过程的两个特点决定了设计方法：寿命随载荷增大而急剧下降；寿命又高度随机，取决于受应力的钢材中最薄弱的缺陷恰好位于何处。同一批相同的轴承在相同载荷下，最长寿命可以超过最短寿命的十倍，因此只能预测寿命的分布。

::: definition 额定寿命与额定动载荷 {#def-rating-life}
一组看来相同、在相同条件下运转的滚动轴承的**额定寿命**$L_{10}$，是其中$90\,\%$的轴承在出现接触疲劳的最初迹象之前能够达到或超过的转数（或在给定恒定转速下的小时数）。它是可靠度为$90\,\%$时的寿命；预计有$10\,\%$的轴承会更早失效。

**基本额定动载荷**$C$（ISO 281:2007；Budynas 与 Nisbett 记为$C_{10}$）是使额定寿命为一百万转的恒定静止载荷——对向心轴承为径向载荷，对推力轴承为中心轴向载荷。每一份样本都列出它。它是计算寿命用的参考值，而不是轴承可以安全承受的载荷：一个在$P = C$下连续运转的轴承，额定寿命只有$10^6$转。
:::

载荷与寿命的关系来自耐久试验：在双对数坐标中，寿命对载荷是一条直线，与疲劳中高周 S–N 直线是同一类幂律。ISO 281 的形式为
$$
L_{10} = \left(\frac{C}{P}\right)^{p}\quad\left[10^6\ \text{转}\right], \qquad p = 3 \ \text{（球轴承）}, \quad p = \frac{10}{3}\ \text{（滚子轴承）},
$$ {#eq-l10}
式中$P$为当量动载荷（定义见下文），单位与$C$相同。这些指数的依据是 G. Lundberg 与 A. Palmgren 的理论（球轴承 1947 年，滚子轴承 1952 年），该理论把赫兹接触应力与受应力体积中含有致命缺陷的概率的威布尔模型结合起来，并用 SKF 的耐久试验加以拟合。对点接触，他们的理论给出指数 3；对理想线接触给出 4；ISO 281 对滚子轴承取$10/3$，因为实际滚子带有凸度，部分处于点接触、部分处于线接触。该方程是经验公式，只在疲劳起控制作用时适用：它假定润滑充分、清洁、安装正确，并且载荷既不至于小到使滚动体打滑，也不至于大到使塑性变形和其他失效形式介入；样本中给出了各类轴承的限值。

在以 r/min 计的恒定转速$n$下，以小时计的额定寿命为
$$
L_{10h} = \frac{10^6}{60\,n}\left(\frac{C}{P}\right)^{p}.
$$ {#eq-l10h}

由于寿命随载荷按幂次变化，起作用的是载荷比$C/P$。载荷加倍时，球轴承的寿命除以$2^3 = 8$，滚子轴承的寿命除以$2^{10/3} = 10.1$。反过来，适度增大轴承尺寸——从而增大$C$——就能换来寿命的大幅增加。

::: example 球轴承和滚子轴承的额定寿命 {#ex-life}
一个$C = 25.5\ \mathrm{kN}$的深沟球轴承（Budynas 与 Nisbett 表 11-2 中 02 系列、内径$35\ \mathrm{mm}$的轴承）在$1500\ \mathrm{rev/min}$下承受$3.0\ \mathrm{kN}$的稳定径向载荷。求其以转数和小时计的额定寿命。并与具有相同$C$的滚子轴承比较，以及载荷加倍对两者的影响。
::: solution
**球轴承。** 纯径向载荷时$P = F_r = 3.0\ \mathrm{kN}$，故$C/P = 25.5/3.0 = 8.5$。由[[#eq-l10]]，取$p = 3$，
$$
L_{10} = 8.5^3 = 614.1\times10^6\ \text{rev}, \qquad L_{10h} = \frac{614.1\times10^6}{60\times1500\ \mathrm{rev/h}} = 6824\ \mathrm{h}.
$$
**具有相同额定值的滚子轴承。** 取$p = 10/3$：$L_{10} = 8.5^{10/3} = 1253\times10^6\ \text{rev}$，$L_{10h} = 13\,930\ \mathrm{h}$，约为两倍。

**载荷加倍。** 在$P = 6.0\ \mathrm{kN}$下，球轴承的寿命除以$8$，降到$76.8\times10^6$转（$853\ \mathrm{h}$）；滚子轴承的寿命除以$10.1$，降到$124\times10^6$转（$1381\ \mathrm{h}$）。

**合理性检查。** $6824\ \mathrm{h}$约相当于单班工作$3\tfrac12$年——对轻载机器是合理的，对昼夜运转的机器则偏短（与[[#alg-select]]中推荐的寿命比较）。单位：$C/P$无量纲，寿命以$10^6$转为单位，正如[[#eq-l10]]所要求的。
:::
:::

::: warning 额定载荷的定义基准并不都相同
- 核对样本中的额定值对应什么寿命。ISO 281 的额定值对应$10^6$转；有些圆锥滚子轴承制造商曾按$90\times10^6$转列出额定值，同一轴承的数值因而小得多。不经换算就把这样的额定值代入[[#eq-l10]]，预测的寿命只有实际的九十分之一（相差系数$90$）。
- $C$不是安全工作载荷。$P = C$时额定寿命只有一百万转；要获得长寿命，$P$必须只是$C$的一小部分（对球轴承，十分之一给出$10^9$转）。
- 用对指数。对滚子轴承用$p = 3$，或对球轴承用$10/3$，预测寿命会相差$C/P$的$1/3$次方——在$C/P = 8$时约为 2 倍。
- 以 r/min 计的转速与[[#eq-l10h]]中的系数$60$相配；以 r/s 或 rad/s 计的转速需要不同的系数。
:::

## 寿命的分散与可靠度

::: definition 轴承寿命的威布尔分布 {#def-weibull}
令$x = L/L_{10}$为以额定寿命为单位度量的寿命。轴承寿命可以用**三参数威布尔分布**很好地描述，其中可靠度——轴承寿命超过$x$的概率——为
$$
R(x) = \exp\left[-\left(\frac{x - x_0}{\theta - x_0}\right)^{b}\right], \qquad x \ge x_0,
$$ {#eq-weibull}
当$x < x_0$时$R = 1$。这里$x_0$为**保证寿命**（最小寿命），$\theta$为**特征寿命**（此时$R = e^{-1} = 0.368$），$b$为**形状参数**（威布尔斜率），描述分散程度：$b$越大，分散越小。
:::

Budynas 与 Nisbett（第 11 章）针对某一制造商的样本数据给出参数
$$
x_0 = 0.02, \qquad \theta - x_0 = 4.439, \qquad b = 1.483,
$$ {#eq-weibull-params}
由此得$R(1) = 0.899$，即在额定寿命处有$90\,\%$存活，理应如此。这些是针对该数据集的经验值：其他制造商和轴承类型给出的参数有所不同。

ISO 281:2007 通过**可靠度寿命修正系数**$a_1$处理可靠度：$(100 - n)\,\%$的轴承能达到的寿命$L_{nm}$等于额定寿命的$a_1$倍。2007 版标准（以及与之一致的 JIS B 1518:2013）列出

| 可靠度$R$ | $90\,\%$ | $95\,\%$ | $96\,\%$ | $97\,\%$ | $98\,\%$ | $99\,\%$ | $99.9\,\%$ | $99.95\,\%$ |
|---|---|---|---|---|---|---|---|---|
| $a_1$ | $1$ | $0.64$ | $0.55$ | $0.47$ | $0.37$ | $0.25$ | $0.093$ | $0.077$ |

这些值来自斜率为$1.5$、保证寿命为$0.05\,L_{10}$的威布尔分布：
$$
a_1 = 0.95\left(\frac{\ln(1/R)}{\ln(1/0.9)}\right)^{2/3} + 0.05.
$$ {#eq-a1}
（例如$R = 0.99$：$\ln(1/0.99)/\ln(1/0.9) = 0.0954$，其$2/3$次方为$0.209$，故$a_1 = 0.95\times0.209 + 0.05 = 0.248$，表中取为$0.25$。）ISO 281 的早期版本采用不含$0.05$的两参数形式，在$99\,\%$时给出$0.21$；这个旧值至今仍出现在一些书籍和软件中。

威布尔模型与载荷–寿命方程结合后，就成为一个选用公式。

::: proposition 给定寿命和可靠度所需的额定载荷 {#prop-c10}
一个轴承必须在设计载荷$F_D$下以可靠度$R_D$运转$x_D$百万转。若其寿命服从参数与载荷无关的[[#eq-weibull]]，且其额定寿命服从[[#eq-l10]]，则样本额定值必须满足
$$
C_{10} \ge a_f\,F_D\left[\frac{x_D}{x_0 + (\theta - x_0)\left[\ln(1/R_D)\right]^{1/b}}\right]^{1/p},
$$ {#eq-c10}
式中$a_f \ge 1$为作用于载荷的使用系数（载荷系数）。若改用 ISO 系数，则$C \ge a_f F_D\,(x_D/a_1)^{1/p}$。
:::

::: proof
**假设。** 额定值$C_{10}$对应$10^6$转的额定寿命；[[#eq-l10]]在所关心的载荷范围内成立；以$L_{10}$为单位表示的寿命分布在任何载荷下具有相同的威布尔参数（分散程度与额定寿命成比例）；实际载荷为设计载荷乘以$a_f$。

在载荷$a_fF_D$下，额定寿命为$L_{10} = (C_{10}/a_fF_D)^p$百万转。以此额定寿命为单位，所需寿命为$x = x_D/L_{10}$。由[[#eq-weibull]]，该寿命处的可靠度不小于$R_D$的条件是
$$
\left(\frac{x - x_0}{\theta - x_0}\right)^b \le \ln\frac{1}{R_D} \iff x \le x_0 + (\theta - x_0)\left[\ln(1/R_D)\right]^{1/b}.
$$
代入$x = x_D(a_fF_D/C_{10})^p$并对$C_{10}$求解，即得[[#eq-c10]]。ISO 形式可同样得到，只需以$x \le a_1$代替方括号中的条件。
:::

对$R_D = 0.99$，[[#eq-c10]]中的分母为$0.02 + 4.439\times0.01005^{0.6743} = 0.220$，因此对相同寿命，球轴承所需的额定值是$90\,\%$可靠度时的$(1/0.220)^{1/3} = 1.66$倍。由于一台机器通常依赖多个轴承，还需要另一条规则。

::: proposition 一组轴承的可靠度 {#prop-system}
若机器的$k$个轴承中任何一个失效都会导致机器失效，且各轴承在设计寿命处以可靠度$R_1, \dots, R_k$相互独立地失效，则这组轴承的可靠度为
$$
R = R_1R_2\cdots R_k.
$$ {#eq-system}
对于$k$个可靠度相同的轴承，若要求整组达到$R$，每个轴承需要$R_i = R^{1/k}$。
:::

::: proof
**假设。** 各失效在统计上相互独立（一个轴承失效不改变其他轴承的失效概率），且任一失效都会使机器停机（串联系统）。只有每个轴承都存活，机器才存活；对独立事件，全部发生的概率等于各自概率之积。
:::

一个有四个轴承、要求整组可靠度为$96\,\%$的齿轮箱，每个轴承需要达到$0.96^{1/4} = 0.9898$，即约$99\,\%$。而一台四个轴承都按$L_{10}$选用的机器，在该寿命处的可靠度只有$0.9^4 = 0.66$——每三台机器中就有一台已经发生过轴承失效。

## 复合载荷：当量动载荷

多数轴承同时承受径向力$F_r$和轴向力$F_a$。由于额定载荷是针对纯径向（或纯轴向）载荷定义的，需要用一个**当量动载荷**$P$来代替这种组合：它是与实际复合载荷产生相同寿命的恒定径向载荷。

::: definition 当量动载荷 {#def-equivalent}
$$
P = X F_r + Y F_a,
$$ {#eq-p}
式中$X$为**径向载荷系数**，$Y$为**轴向载荷系数**。对向心轴承存在一个判断系数$e$：若$F_a/F_r \le e$，轴向载荷的影响可以忽略，$X = 1$，$Y = 0$，即$P = F_r$；若$F_a/F_r > e$，则取另外的值。这些系数取决于轴承类型和内部几何，在 ISO 281 和各样本中给出。
:::

对深沟球轴承，轴向载荷会改变接触角，因此$e$和$Y$取决于轴向载荷相对于轴承尺寸的大小——用$F_a/C_0$度量，$C_0$为下文定义的额定静载荷。以下摘自 Budynas 与 Nisbett 表 11-1（深沟球轴承，依据 ISO 281），适用于$F_a/F_r > e$，此时$X = 0.56$：

| $F_a/C_0$ | $0.014$ | $0.028$ | $0.056$ | $0.084$ | $0.110$ | $0.17$ | $0.28$ | $0.42$ | $0.56$ |
|---|---|---|---|---|---|---|---|---|---|
| $e$ | $0.19$ | $0.22$ | $0.26$ | $0.28$ | $0.30$ | $0.34$ | $0.38$ | $0.42$ | $0.44$ |
| $Y$ | $2.30$ | $1.99$ | $1.71$ | $1.55$ | $1.45$ | $1.31$ | $1.15$ | $1.04$ | $1.00$ |

中间值用线性插值求得。各样本给出等效的表格，有时还带有轴承内部游隙的附加系数；应使用与所选轴承配套的表格。

角接触球轴承和圆锥滚子轴承还有一个特点：由于接触是倾斜的，径向载荷会在轴承内部产生**派生轴向力**。因此这类轴承成对反向安装，每个轴承上的轴向载荷由两者的派生轴向力和外加推力共同求出。Budynas 与 Nisbett（§11-9）介绍了某圆锥滚子轴承制造商采用的方法，其中派生轴向力为$0.47F_r/K$，$K$是与轴承锥角有关的系数（对径向型轴承约为$1.5$）；应采用所选轴承的样本中给出的方法。

::: example 复合载荷下的当量载荷与寿命 {#ex-equivalent}
一个 02 系列、内径$65\ \mathrm{mm}$的深沟球轴承，$C = 55.9\ \mathrm{kN}$，$C_0 = 34.0\ \mathrm{kN}$（Budynas 与 Nisbett 表 11-2）。它在$500\ \mathrm{rev/min}$下承受$F_r = 7.0\ \mathrm{kN}$和$F_a = 3.0\ \mathrm{kN}$。求当量载荷和以小时计的额定寿命。
::: solution
**轴向载荷的大小。** $F_a/C_0 = 3.0/34.0 = 0.0882$，介于表中$0.084$与$0.110$两项之间。插值得
$$
e = 0.28 + 0.02\times\frac{0.0882 - 0.084}{0.110 - 0.084} = 0.283, \qquad Y = 1.55 - 0.10\times\frac{0.0882 - 0.084}{0.026} = 1.534.
$$
**取哪一组系数？** $F_a/F_r = 3.0/7.0 = 0.429 > e = 0.283$，故$X = 0.56$，$Y = 1.534$。

**当量载荷。** 由[[#eq-p]]，
$$
P = 0.56\times7.0 + 1.534\times3.0 = 3.92 + 4.60 = 8.52\ \mathrm{kN}.
$$
**寿命。** $C/P = 55.9/8.52 = 6.56$；$L_{10} = 6.56^3 = 282\times10^6$转，$L_{10h} = 282\times10^6/(60\times500) = 9410\ \mathrm{h}$。

**合理性检查。** $P$大于$F_r$，但小于算术和$F_r + F_a = 10\ \mathrm{kN}$：这里轴向载荷按其自身大小的约一倍半计入，径向载荷约按一半计入。若忽略轴向载荷，则$C/P = 7.99$，预测寿命为$17\,000\ \mathrm{h}$——几乎是真实值的两倍。
:::
:::

当载荷或转速在一个工作循环中变化时，与迈因纳（Miner）法则（[[machine-design/fatigue]]）相同的疲劳推理给出一个单一的当量载荷。

::: proposition 工作循环的当量载荷 {#prop-duty}
若轴承在恒定当量载荷$P_1, P_2, \dots$下分别运转其总转数的$\alpha_1, \alpha_2, \dots$（$\sum\alpha_i = 1$），则其额定寿命等于在恒定载荷
$$
P_\text{eq} = \left(\sum_i \alpha_i P_i^{\,p}\right)^{1/p}
$$ {#eq-peq}
下的额定寿命。
:::

::: proof
**假设。** 损伤线性累积（Palmgren–Miner 法则，Palmgren 正是针对这一问题于 1924 年提出的）：在载荷$P_i$下转一转消耗寿命的$1/L_i$，其中$L_i = (C/P_i)^p$是该载荷下的额定寿命；载荷的先后次序无关紧要。

在总共$L$转中，有$\alpha_iL$转是在$P_i$下完成的；当损伤之和达到 1 时发生失效（在$90\,\%$可靠度下）：
$$
\sum_i \frac{\alpha_iL}{L_i} = L\sum_i\frac{\alpha_iP_i^{\,p}}{C^p} = 1 \quad\Longrightarrow\quad L = \frac{C^p}{\sum_i\alpha_iP_i^{\,p}} = \left(\frac{C}{P_\text{eq}}\right)^p,
$$
其中$P_\text{eq}$如[[#eq-peq]]所示。注意权重是**转数**的分数，而不是时间的分数：高速运转的时段权重更大。
:::

## 额定静载荷

缓慢转动、小角度摆动或在载荷下静止的轴承（起重吊钩、回转支承、运输中的机器）不是因疲劳而失效，而是因**压痕**（布氏压痕）失效：滚道上的永久凹痕，以后会使轴承运转粗糙并产生噪声。旋转轴承受到严重冲击载荷时也会如此。

::: definition 额定静载荷与静载安全因数 {#def-static}
**基本额定静载荷**$C_0$（ISO 76:2006）是在受载最大的接触中心处产生如下计算接触应力的静载荷：调心球轴承为$4600\ \mathrm{MPa}$，其他球轴承为$4200\ \mathrm{MPa}$，滚子轴承为$4000\ \mathrm{MPa}$。在这些应力下，滚动体与滚道的总永久变形约为滚动体直径的$0.0001$，经验表明这不会妨碍正常运转。

**当量静载荷**为$P_0 = X_0F_r + Y_0F_a$，静载系数取自样本（对深沟球轴承，$X_0 = 0.6$，$Y_0 = 0.5$，若后者更大则取$P_0 = F_r$）。**静载安全因数**为
$$
s_0 = \frac{C_0}{P_0},
$$ {#eq-s0}
用可能出现的最大载荷（包括冲击）计算。
:::

所需的$s_0$取决于轴承类型、载荷的平稳程度以及对运转平静性的要求。样本中的指导值对一般机械通常约为$1$–$2$，对冲击载荷或要求低噪声的场合更高，对可以容许一定永久变形的缓慢转动轴承则低于 1。应采用所选轴承制造商的指导值。

## 修正额定寿命：洁净钢材疲劳之外的因素

额定寿命描述的是标准轴承钢在良好条件下的疲劳。由于润滑油膜、污染以及应力水平相对于钢材疲劳极限的高低，现场寿命往往与之相差很大的倍数。ISO 281:2007 将**修正额定寿命**标准化为
$$
L_{nm} = a_1\,a_\text{ISO}\,L_{10},
$$ {#eq-lnm}
其中$a_1$是上述可靠度系数，$a_\text{ISO}$是**寿命修正系数**，它取决于三方面：

- **黏度比**$\kappa = \nu/\nu_1$，即润滑剂在工作温度下的实际运动黏度除以在该转速和尺寸下使表面分开所需的黏度：较厚的弹性流体动压油膜保护表面；
- **污染系数**$e_C$，在非常清洁的条件下为 1，润滑剂中的颗粒在滚道上压出凹痕并引发裂纹时随之减小；
- **疲劳载荷极限**$C_u$（低于此载荷钢材不会疲劳，依据 E. Ioannides 与 T. A. Harris 1985 年的模型）与当量载荷$P$之比。

该系数由标准和样本中的图表查得；对清洁、润滑良好、轻载的轴承可以远大于 1，对脏污或润滑不良的轴承则远小于 1。因此许多设计者先按$L_{10}$并结合经验推荐寿命选用轴承，再用制造商的工具校核$L_{nm}$。磨损、腐蚀、伪压痕、电蚀和密封失效都可能终结轴承的寿命，而这些是任何疲劳方程都预测不了的。

## 滚动轴承的选用

选用是一个从载荷出发、得到样本型号、再校核结果的过程。

::: algorithm 滚动轴承的选用 {#alg-select}
1. **载荷与转速。** 由轴的分析求出每种工况下各轴承处的径向和轴向支反力、转速以及每种工况所占的转数分数；若载荷变化，用[[#eq-peq]]加以合成。
2. **类型与布置。** 根据载荷方向、转速、不对中和空间选择类型（见类型表），并确定由哪个轴承对轴作轴向定位。
3. **设计寿命与可靠度。** 根据工作情况（下表或样本指南）选定以小时计的所需寿命$L_D$，并换算为转数$x_D = 60\,n\,L_D/10^6$。用[[#eq-system]]确定每个轴承的可靠度。
4. **使用系数。** 将载荷乘以使用系数$a_f$，以计入分析未能反映的冲击和载荷（见下表）。
5. **所需额定值。** 由[[#eq-c10]]（或用$a_1$）计算$C_{10}$；对复合载荷，先假定$X$和$Y$（例如$X = 0.56$，$Y = 1.5$），选出轴承，再用所选轴承的$C_0$重新计算$P$并迭代。
6. **选定**所选系列中额定值不低于所需值、且内径与轴相配的最小轴承。
7. **校核**峰值载荷下的静载安全因数[[#eq-s0]]、转速与样本极限转速的比较、润滑剂黏度与清洁度（$a_\text{ISO}$）、配合以及轴肩高度。
:::

推荐的设计寿命来自经验，而不是理论。Budynas 与 Nisbett（表 11-4）给出如下范围：

| 应用类型 | 寿命（$10^3\ \mathrm{h}$） |
|---|---|
| 不经常使用的仪器和装置 | 至多$0.5$ |
| 航空发动机 | $0.5$–$2$ |
| 短时或间歇运转、停机影响不大的机器 | $4$–$8$ |
| 间歇工作、可靠运转非常重要的机器 | $8$–$14$ |
| 每天工作 8 小时、但并非总是满负荷使用的机器 | $14$–$20$ |
| 每天工作 8 小时、满负荷使用的机器 | $20$–$30$ |
| 每天 24 小时连续工作的机器 | $50$–$60$ |
| 每天 24 小时连续工作、可靠性极为重要的机器 | $100$–$200$ |

轴承制造商也发布类似的指导表。工业用电动机和齿轮传动通常属于单班或连续工作这几行——几万小时；$100\,000\ \mathrm{h}$这一档用于停机代价非常高的连续工作机器（电站辅机、造纸机）。Budynas 与 Nisbett（表 11-5）给出如下使用系数：

| 应用类型 | $a_f$ |
|---|---|
| 精密齿轮传动 | $1.0$–$1.1$ |
| 普通齿轮传动 | $1.1$–$1.3$ |
| 轴承密封不良的场合 | $1.2$ |
| 无冲击的机械 | $1.0$–$1.2$ |
| 轻微冲击的机械 | $1.2$–$1.5$ |
| 中等冲击的机械 | $1.5$–$3.0$ |

::: example 为齿轮轴选用轴承 {#ex-select}
一台普通齿轮传动装置的轴以$960\ \mathrm{rev/min}$运转，单班、满负荷使用，某一轴承处的径向支反力为$2.5\ \mathrm{kN}$，无明显轴向载荷。按$99\,\%$可靠度，从 Budynas 与 Nisbett 表 11-2 中选一个 02 系列深沟球轴承（内径$60\ \mathrm{mm}$：$C_{10} = 47.5\ \mathrm{kN}$，$C_0 = 28.0\ \mathrm{kN}$；$65\ \mathrm{mm}$：$55.9\ \mathrm{kN}$，$34.0\ \mathrm{kN}$）。
::: solution
**寿命。** 单班、满负荷：取$L_D = 20\,000\ \mathrm{h}$，即$20$–$30\times10^3\ \mathrm{h}$范围的下限。于是$x_D = 60\times960\times20\,000/10^6 = 1152$百万转。

**使用系数。** 普通齿轮传动：$a_f = 1.2$，故设计载荷为$1.2\times2.5 = 3.0\ \mathrm{kN}$。

**所需额定值，威布尔模型。** 由[[#eq-c10]]，取$p = 3$及参数[[#eq-weibull-params]]，分母为$0.02 + 4.439\times(\ln(1/0.99))^{1/1.483} = 0.2196$：
$$
C_{10} \ge 3.0\left(\frac{1152}{0.2196}\right)^{1/3} = 3.0\times17.38 = 52.1\ \mathrm{kN}.
$$
**所需额定值，ISO 系数。** 取$a_1 = 0.25$：$C \ge 3.0\times(1152/0.25)^{1/3} = 3.0\times16.64 = 49.9\ \mathrm{kN}$。

**选定。** 按任一模型，$60\ \mathrm{mm}$的轴承（$47.5\ \mathrm{kN}$）都太小；$65\ \mathrm{mm}$的轴承（$55.9\ \mathrm{kN}$）两者都满足。它在$3.0\ \mathrm{kN}$下的额定寿命为$(55.9/3.0)^3 = 6470$百万转，故$x = 1152/6470 = 0.178$，由[[#eq-weibull]]得$R = 0.993$。

**静载校核。** $P_0 = F_r = 2.5\ \mathrm{kN}$（无轴向载荷），$s_0 = 34.0/2.5 = 13.6$——静载荷不成问题。

**合理性检查。** 在$90\,\%$可靠度下，所需额定值本为$3.0\times1152^{1/3} = 31.4\ \mathrm{kN}$；要求$99\,\%$使额定值增大到$1.66$倍，与[[#prop-c10]]之后的说明一致。实际上内径还必须与[[machine-design/shafts]]中确定的轴径相配；若轴径较小，可改用内径较小而额定值相同的重系列（03 系列）轴承。
:::
:::

## 滑动轴承与流体动压润滑

滑动轴承就是孔中的一根轴，间隙里充满油——曲轴主轴承、汽轮机轴承都是如此。轴静止时，它坐在孔的底部，金属与金属接触。开始转动时，它沿孔壁稍稍爬升并发生摩擦（**边界润滑**：表面上吸附的润滑剂和添加剂薄膜承受载荷，摩擦因数为$0.05$–$0.15$量级）。随着转速升高，旋转的轴颈把油带入最小间隙前方的收敛间隙中。油来不及流走，压力升高；转速足够高时，压力承受全部载荷：轴颈漂浮在厚几微米到几十微米的油膜上。这就是**流体动压**（全膜）润滑。此时摩擦纯粹是油的黏性剪切，摩擦因数为$0.001$–$0.01$量级，原则上没有磨损。两者之间是**混合润滑**，油膜承受一部分载荷，微凸体承受其余部分。

施特里贝克（R. Stribeck）对滑动轴承和滚动轴承所做的实验（1901 年报告，1902 年发表）表明，随着转速升高，摩擦因数从边界润滑时的值急剧下降，经过一个最小值后再缓慢上升。后来的工作，特别是 M. D. Hersey 的工作（1914），表明以无量纲组合$\mu N/P$——黏度乘以转速再除以单位投影面积上的载荷——为横坐标作图时，不同载荷、转速和润滑油的数据都落在同一条曲线上。这条曲线称为**施特里贝克曲线**。在最小值右侧（全膜区），摩擦随$\mu N/P$增大而增大；这一区域在热学上是稳定的，因为轴承变热后油变稀，摩擦减小。在最小值左侧，油膜破裂。轴承应设计在远离最小值的右侧运转。

::: definition 黏度 {#def-viscosity}
在间距为$h$的两平行平板之间受剪切的牛顿流体中，若一板相对另一板以速度$U$运动，切应力为
$$
\tau = \mu\frac{du}{dy} = \mu\frac{U}{h},
$$ {#eq-newton}
式中$\mu$为**动力黏度**，单位为$\mathrm{Pa\,s}$（$1\ \mathrm{mPa\,s} = 1\ \mathrm{cP}$）。**运动黏度**为$\nu = \mu/\rho$，单位为$\mathrm{m^2/s}$（样本中用$\mathrm{mm^2/s} = \mathrm{cSt}$）。工业用油按 **ISO 黏度等级**（ISO 3448）出售：例如 ISO VG 32 在$40\ \mathrm{°C}$时的运动黏度为$32\ \mathrm{mm^2/s}$（$\pm10\,\%$）。
:::

黏度随温度急剧下降——在通常的工作范围内，典型矿物油的温度每升高$20\ \mathrm{°C}$，黏度约降低一半——因此每一项轴承计算中的黏度都必须取油膜中油的工作温度下的值，而不是$40\ \mathrm{°C}$时的值。确定这一温度本身就是设计的一部分（见下文）。

### 彼得罗夫方程

最简单的轴承是完全不受载的轴承：轴颈与孔同心，油受到均匀剪切。N. P. Petrov（彼得罗夫）于 1883 年分析了这种情况，他的结果至今仍能对轻载轴承的摩擦给出有用的估计。

::: proposition 彼得罗夫方程 {#prop-petroff}
半径为$r$、长度为$l$的轴颈以$N$ r/s 的转速转动，与半径间隙为$c$的轴承同心，间隙中充满黏度为$\mu$的油。摩擦力矩为
$$
T = \frac{4\pi^2r^3l\mu N}{c},
$$ {#eq-petroff-torque}
若对载荷$W$用$T = fWr$定义摩擦因数，并取投影面积上的单位载荷$P = W/(2rl)$，则
$$
f = 2\pi^2\,\frac{\mu N}{P}\,\frac{r}{c}.
$$ {#eq-petroff}
:::

::: proof
**假设。** 轴颈与孔同心（无偏心，相当于载荷趋于零），因此各处油膜厚度都等于半径间隙$c$；$c \ll r$，油膜可视为平的；流动为层流，速度沿膜厚线性变化；油为黏度恒定的牛顿流体并充满整个间隙；无轴向流动，忽略端部效应。

轴颈的表面速度为$U = 2\pi rN$。由[[#eq-newton]]，轴颈表面上的切应力为$\tau = \mu U/c = 2\pi r\mu N/c$。它作用在面积$2\pi rl$上，产生摩擦力$F = \tau\cdot2\pi rl = 4\pi^2r^2l\mu N/c$，其对轴线的力矩为
$$
T = Fr = \frac{4\pi^2r^3l\mu N}{c}.
$$
现在令一个小载荷$W$作用，$P = W/(2rl)$，即$W = 2rlP$。于是$f = T/(Wr) = 4\pi^2r^3l\mu N/(c\cdot2r^2lP) = 2\pi^2(\mu N/P)(r/c)$。
:::

彼得罗夫方程包含了本质的组合量。摩擦因数取决于施特里贝克曲线中的 Hersey 组合$\mu N/P$，以及间隙比$r/c$（通常为$500$–$1000$；即$c/r$约为$0.001$–$0.002$）。它不能告诉我们轴承能承受多大载荷——同心的轴颈不产生压力——但它是实际轴承在轻载时趋近的极限。

::: example 用彼得罗夫方程计算摩擦与功率损失 {#ex-petroff}
一个轻载轴承，$d = 50\ \mathrm{mm}$（$r = 25\ \mathrm{mm}$），$l = 40\ \mathrm{mm}$，半径间隙$c = 0.030\ \mathrm{mm}$，在$1500\ \mathrm{rev/min}$下承受$W = 400\ \mathrm{N}$。油膜温度下油的黏度为$\mu = 10\ \mathrm{mPa\,s}$。估算摩擦因数、摩擦力矩和功率损失。
::: solution
**组合量。** $N = 1500/60 = 25\ \mathrm{rev/s}$；$P = W/(2rl) = 400/(0.050\times0.040) = 200\ \mathrm{kPa}$；$r/c = 25/0.030 = 833.3$；
$$
\frac{\mu N}{P} = \frac{0.010\ \mathrm{Pa\,s}\times25\ \mathrm{s^{-1}}}{200\,000\ \mathrm{Pa}} = 1.25\times10^{-6}.
$$
**摩擦因数。** 由[[#eq-petroff]]，$f = 2\pi^2\times1.25\times10^{-6}\times833.3 = 0.0206$。

**力矩与功率。** $T = fWr = 0.0206\times400\times0.025 = 0.206\ \mathrm{N\,m}$（理应与[[#eq-petroff-torque]]相等：$4\pi^2\times0.025^3\times0.040\times0.010\times25/(3.0\times10^{-5}) = 0.206\ \mathrm{N\,m}$）。耗散功率为$T\omega = 0.206\times2\pi\times25 = 32\ \mathrm{W}$，全部用来加热油。

**合理性检查。** 下文定义的索末菲数为$S = (r/c)^2\mu N/P = 0.868$，数值较大，所以载荷确实很轻。对该轴承（$l/d = 0.8$）求雷诺方程的数值解，得偏心率约为$0.2$，$(r/c)f \approx 18$，即$f \approx 0.022$——彼得罗夫的估计约低$6\,\%$，这是忽略偏心的代价。注意$f = 0.02$并不小：轻载时摩擦力由油的剪切决定，而与载荷无关，因此尽管摩擦*力*很小，摩擦*因数*却很大。
:::

### 雷诺方程

承受载荷的是油膜中的压力。受载时轴颈偏离中心，偏移量为**偏心距**$e$；于是油膜在某一点最薄，被轴颈带动的油被挤过轴颈前方逐渐收窄的间隙。

::: definition 偏心率与油膜厚度 {#def-eccentricity}
设半径间隙为$c$，轴颈中心与轴承中心之间的偏心距为$e$，则**偏心率**为$\varepsilon = e/c$（$0 \le \varepsilon < 1$）。从油膜最厚的位置起沿转动方向量取角度$\theta$，在$c/r$的一阶近似下，油膜厚度为
$$
h(\theta) = c\,(1 + \varepsilon\cos\theta),
$$ {#eq-film}
**最小油膜厚度**为$h_0 = c(1 - \varepsilon)$，位于$\theta = \pi$处。**偏位角**$\phi$是载荷作用线与中心连线之间的夹角。
:::

::: proposition 径向滑动轴承的雷诺方程 {#prop-reynolds}
对于稳定载荷下的轴承，轴颈表面沿周向$x$以速度$U$运动、轴承静止，油膜中的压力$p(x, z)$满足
$$
\frac{\partial}{\partial x}\left(h^3\frac{\partial p}{\partial x}\right) + \frac{\partial}{\partial z}\left(h^3\frac{\partial p}{\partial z}\right) = 6\mu U\frac{\partial h}{\partial x},
$$ {#eq-reynolds}
式中$z$为轴向坐标，$h(x)$由[[#eq-film]]给出，$x = r\theta$。
:::

::: proof
**假设（润滑近似）。** 油膜很薄，$h \ll r$且$h \ll l$，因此可以忽略其曲率，把$x$、$y$（沿膜厚方向）、$z$当作直角坐标；流动为层流，惯性力和体积力与黏性力相比可以忽略（修正雷诺数$\rho Uh^2/(\mu l)$很小）；润滑剂为牛顿流体、不可压缩、黏度恒定；压力沿膜厚不变，$\partial p/\partial y = 0$；表面无滑移；运动是定常的。

**速度。** 在这些假设下，纳维–斯托克斯方程（[[fluid-mechanics/navier-stokes]]）简化为$\partial p/\partial x = \mu\,\partial^2u/\partial y^2$和$\partial p/\partial z = \mu\,\partial^2w/\partial y^2$。在轴颈上（$y = 0$）取$u = U$、$w = 0$，在轴承上（$y = h$）取$u = w = 0$，沿膜厚积分两次得
$$
u = U\left(1 - \frac{y}{h}\right) + \frac{1}{2\mu}\frac{\partial p}{\partial x}\left(y^2 - hy\right), \qquad w = \frac{1}{2\mu}\frac{\partial p}{\partial z}\left(y^2 - hy\right).
$$
**流量。** 沿膜厚积分，得单位宽度的流量：
$$
q_x = \int_0^h u\,dy = \frac{Uh}{2} - \frac{h^3}{12\mu}\frac{\partial p}{\partial x}, \qquad q_z = -\frac{h^3}{12\mu}\frac{\partial p}{\partial z}.
$$
$q_x$的第一项是**剪切**（库埃特）流，第二项是**压力**（泊肃叶）流。

**连续性。** 对定常油膜中的不可压缩流体，穿过整个膜厚的小柱体$dx\,dz$的净流出量必须为零：$\partial q_x/\partial x + \partial q_z/\partial z = 0$。代入得
$$
\frac{U}{2}\frac{\partial h}{\partial x} - \frac{\partial}{\partial x}\left(\frac{h^3}{12\mu}\frac{\partial p}{\partial x}\right) - \frac{\partial}{\partial z}\left(\frac{h^3}{12\mu}\frac{\partial p}{\partial z}\right) = 0,
$$
乘以$12\mu$即得[[#eq-reynolds]]。
:::

右端是压力的来源：在沿运动方向收敛的油膜中（$\partial h/\partial x < 0$），剪切流量沿$x$本应减小，因此必须建立压力梯度把差额推过去。在发散的油膜中，方程预测出低于环境的压力，而实际油膜无法维持这样的压力：它发生**空化**（析出溶解的空气和蒸气），压力保持在环境压力附近。因此求解时要施加边界条件：轴承两端$p = 0$（表压）；并采用**半索末菲**条件（直接把负压置为零）或更符合实际的**雷诺**（Swift–Stieber）条件，即油膜在$p$与$\partial p/\partial\theta$同时为零处终止。

解析解只在极限情况下存在。对无限长轴承（$\partial/\partial z = 0$），索末菲（A. Sommerfeld）于 1904 年求得了闭合形式的解。对短轴承，轴向项占主导，可以略去周向项而直接积分（短轴承理论，见[[#ex-short]]）。对实际比例（$l/d$约为$0.25$到$1$），方程需要数值求解。

### 索末菲数

雷诺方程含有许多参数——$r$、$c$、$l$、$\mu$、$N$、$W$——但它们只组合成很少几个组合量。

::: proposition 轴承的无量纲特性 {#prop-sommerfeld}
对给定$l/d$和给定边界条件的轴承，偏心率$\varepsilon$、偏位角$\phi$、摩擦变量$(r/c)f$以及无量纲流量只取决于**索末菲数**
$$
S = \left(\frac{r}{c}\right)^2\frac{\mu N}{P}, \qquad P = \frac{W}{2rl},\quad N\ \text{以 r/s 计}.
$$ {#eq-sommerfeld}
:::

::: proof
**假设。** 与[[#prop-reynolds]]相同，并且压力边界条件固定（两端为环境压力，发散区采用半索末菲条件或雷诺条件）。

引入$\theta = x/r$、$\zeta = z/r$、$H = h/c = 1 + \varepsilon\cos\theta$以及无量纲压力$\bar p = p\,c^2/(6\mu Ur)$。由于$\partial/\partial x = (1/r)\,\partial/\partial\theta$，$\partial/\partial z = (1/r)\,\partial/\partial\zeta$，[[#eq-reynolds]]的左端变为$(c^3/r^2)(6\mu Ur/c^2)\left[\partial_\theta(H^3\partial_\theta\bar p) + \partial_\zeta(H^3\partial_\zeta\bar p)\right]$，右端变为$6\mu U(c/r)\,dH/d\theta$。因子$6\mu Uc/r$相消：
$$
\frac{\partial}{\partial\theta}\left(H^3\frac{\partial\bar p}{\partial\theta}\right) + \frac{\partial}{\partial\zeta}\left(H^3\frac{\partial\bar p}{\partial\zeta}\right) = \frac{dH}{d\theta}, \qquad |\zeta| \le \frac{l}{2r} = \frac{l}{d}.
$$
这个问题只含$\varepsilon$和$l/d$，所以它的解$\bar p(\theta, \zeta)$及其任何积分都只取决于$\varepsilon$和$l/d$。载荷为$W = (6\mu Ur^3/c^2)\,\bar W(\varepsilon, l/d)$，其中$\bar W$是$\iint\bar p\,(\cos\theta, \sin\theta)\,d\theta\,d\zeta$的模。利用$U = 2\pi rN$和$W = 2rlP$，
$$
\frac{1}{\bar W} = \frac{6\mu Ur^3}{c^2W} = \frac{6\cdot2\pi rN\mu r^3}{c^2\cdot2rlP} = 6\pi\,\frac{r}{l}\left(\frac{r}{c}\right)^2\frac{\mu N}{P} = 6\pi\frac{r}{l}\,S,
$$
所以$S = l/(6\pi r\bar W)$只是$\varepsilon$和$l/d$的函数；反过来，$\varepsilon$是$S$和$l/d$的函数。摩擦力由切应力$\tau = \mu U/h + (h/2r)\,\partial p/\partial\theta$在轴颈上积分得到，它等于$\mu Ur^2/c$乘以$\varepsilon$和$l/d$的某个函数，所以$f = F/W$乘以$r/c$同样只是$S$和$l/d$的函数。同样的论证也适用于以$rcNl$为尺度的流量。
:::

除常数外，索末菲数是无量纲载荷的倒数。$S$大（轻载、高速、油黏）意味着轴颈几乎同心；$S$小意味着重载轴承、油膜很薄。用[[#eq-sommerfeld]]改写后，彼得罗夫方程就是
$$
\frac{r}{c}f = 2\pi^2 S,
$$ {#eq-petroff-s}
即精确关系在大$S$时的极限。

### 设计图表及其使用

1958 年，A. A. Raimondi 与 J. Boyd 发表了有限长径向滑动轴承雷诺方程的数值解，采用雷诺边界条件，覆盖$l/d = \tfrac14$、$\tfrac12$、$1$和无限长轴承。他们的图表（Budynas 与 Nisbett 第 12 章中有转载）以$S$和$l/d$为自变量给出：最小油膜厚度变量$h_0/c$（从而得到$\varepsilon$）、偏位角$\phi$、摩擦变量$(r/c)f$、流量变量$Q/(rcNl)$、从两端流出的流量所占比例$Q_s/Q$、平均压力与最大油膜压力之比$P/p_\text{max}$，以及最大压力位置和油膜终止位置。图表必须从印刷的原始资料中读取；绝不能凭猜测读数。

为说明这类解给出什么，下列$l/d = 1$的数值是为本章用有限差分法在雷诺边界条件下求解[[#eq-reynolds]]得到的；它们与 Raimondi 和 Boyd 发表的表格相差约$1$–$2\,\%$以内：

| $\varepsilon$ | $0.2$ | $0.4$ | $0.6$ | $0.8$ | $0.9$ |
|---|---|---|---|---|---|
| $S$ | $0.632$ | $0.261$ | $0.121$ | $0.0446$ | $0.0188$ |
| $\phi$ | $74°$ | $63°$ | $51°$ | $36°$ | $26°$ |
| $(r/c)f$ | $12.8$ | $5.79$ | $3.22$ | $1.70$ | $1.05$ |
| $2\pi^2S$（彼得罗夫） | $12.5$ | $5.15$ | $2.39$ | $0.88$ | $0.37$ |

最后一行表明，随着载荷增大、轴颈偏心增加，彼得罗夫的估计越来越低于真实摩擦。

分析一个已有轴承时，要把这些数据与热平衡结合使用。损失的功率$fWr\cdot2\pi N$使油变热；油的温升取决于通过轴承的流量；而黏度又取决于温度。由于求$S$需要黏度，求流量和摩擦又需要$S$，计算要迭代进行：假定一个平均油膜温度，查出$\mu$，计算$S$，求出$(r/c)f$和流量，计算温升，重复直至假定温度与计算温度一致。Budynas 与 Nisbett（第 12 章）完整地给出了这一步骤。

稳定载荷轴承的设计准则来自经验。Budynas 与 Nisbett 引用的 P. R. Trumpler（1966）准则包括：最小油膜厚度$h_0 \ge 0.005\ \mathrm{mm} + 0.00004\,d$（由他的英寸公式$0.0002 + 0.00004\,d$换算而来，以英寸计）、起动时最大单位载荷约$2\ \mathrm{MPa}$、最高油膜温度约$120\ \mathrm{°C}$，以及对运转载荷取设计系数 2。典型的设计比例为$l/d$约$0.5$到$1$，$c/r$约$0.001$。

::: example 流体动压轴承的分析 {#ex-journal}
一个轴承，$d = 50\ \mathrm{mm}$，$l = 50\ \mathrm{mm}$，半径间隙$c = 0.025\ \mathrm{mm}$，在$1800\ \mathrm{rev/min}$下承受$W = 5.0\ \mathrm{kN}$。平均油膜温度下$\mu = 8.0\ \mathrm{mPa\,s}$。求索末菲数、最小油膜厚度和摩擦功率，并评价该设计。使用上表中$l/d = 1$的数据。
::: solution
**组合量。** $r/c = 25/0.025 = 1000$；$N = 30\ \mathrm{rev/s}$；$P = W/(2rl) = 5000/(0.050\times0.050) = 2.0\ \mathrm{MPa}$：
$$
S = (1000)^2\times\frac{0.0080\times30}{2.0\times10^6} = 10^6\times1.2\times10^{-7} = 0.120.
$$
**偏心率与油膜。** 由表，$l/d = 1$时$S = 0.120$对应$\varepsilon \approx 0.60$（$\varepsilon = 0.6$时$S = 0.121$）。故$h_0 = c(1 - \varepsilon) = 0.025\times0.40 = 0.010\ \mathrm{mm} = 10\ \mu\mathrm{m}$，偏位角约为$51°$。

**摩擦。** $(r/c)f \approx 3.22$，故$f = 0.00322$；力矩$fWr = 0.00322\times5000\times0.025 = 0.40\ \mathrm{N\,m}$；功率$0.40\times2\pi\times30 = 76\ \mathrm{W}$。（彼得罗夫方程给出$f = 2\pi^2\times0.120/1000 = 0.00237$，低$26\,\%$。）

**评价。** Trumpler 的油膜准则要求$h_0 \ge 0.005 + 0.00004\times50 = 0.0070\ \mathrm{mm}$：$10\ \mu\mathrm{m}$的油膜满足要求，但达不到同一套准则所要求的载荷设计系数 2，因为在两倍载荷下（$S = 0.060$），由表得$\varepsilon$介于$0.6$与$0.8$之间，约为$0.75$，$h_0 \approx 6\ \mu\mathrm{m}$。$2\ \mathrm{MPa}$的单位载荷正好处于起动限值。表面加工必须足够精细，使两表面的综合粗糙度只占$10\ \mu\mathrm{m}$的一小部分。这一设计处于临界状态；采用黏度更高的油或更长的轴承会有所改善。

**合理性检查。** $\varepsilon = 0.6$处于受载轴承通常的工作范围内，$f \approx 0.003$是全膜润滑的典型值——比边界摩擦低一个数量级。
:::

::: warning 毁掉滑动轴承计算的常见失误
- **转速以 r/s 计。** [[#eq-sommerfeld]]和[[#eq-petroff]]中的$N$以每秒转数计。用 r/min 会使$S$大 60 倍；用 rad/s 会使它大$2\pi$倍。
- **半径间隙与直径间隙。** $c$是半径间隙，即孔径与轴颈直径之差的一半。用直径间隙会使$S$小为四分之一。
- **投影面积。** $P = W/(2rl) = W/(ld)$，是单位投影面积上的载荷，而不是单位表面积上的载荷。
- **黏度单位与温度。** $\mu$以$\mathrm{Pa\,s}$计（不是厘泊，也不是$\mathrm{mm^2/s}$），取油膜工作温度下的值。对一个在$70\ \mathrm{°C}$下运转的轴承使用$40\ \mathrm{°C}$时的黏度，可能把$S$高估 3 倍。
- **起动与停机。** 流体动压理论对起动过程无能为力，此时轴承处于边界润滑；轴承材料（巴氏合金、青铜、铝合金）是根据其耐摩擦和嵌藏污物的能力来选择的。
:::

::: history
对轴承摩擦的系统研究始于 19 世纪 80 年代。在为英国机械工程师学会（Institution of Mechanical Engineers）进行、自 1883 年起陆续报告的实验中，托尔（Beauchamp Tower）发现润滑良好的滑动轴承运转时摩擦极小，而且间隙中的油承受着相当大的压力——据说压力大到足以把塞在承载区油孔中的塞子顶出来。同年，俄国的彼得罗夫（N. P. Petrov）发表了他对同心轴承黏性摩擦的分析。雷诺（Osborne Reynolds）在 1886 年发表于《皇家学会哲学汇刊》（*Philosophical Transactions of the Royal Society*）的论文中解释了托尔的结果，推导出以他的名字命名的薄膜流动方程；索末菲（A. Sommerfeld）于 1904 年对长径向轴承求解了这一方程，引入了今天称为索末菲数的参数。施特里贝克（R. Stribeck）的摩擦测量（1901–1902）给出了以他命名的曲线。A. A. Raimondi 与 J. Boyd 对有限长轴承的数值解（1958）是至今仍印在教科书中的设计图表的基础。

在滚动轴承方面，哥德堡一家纺织厂的工程师温奎斯特（Sven Wingquist）于 1907 年获得调心球轴承的专利；同年为制造这种轴承成立了 SKF 公司。SKF 的帕姆格伦（A. Palmgren）于 1924 年提出了轴承的线性损伤法则，伦德伯格（G. Lundberg）与帕姆格伦于 1947 年（球轴承）和 1952 年（滚子轴承）发表了接触疲劳的统计理论。这一理论成为额定动载荷国际标准的基础，即现在的 ISO 281:2007；该标准的修正寿命方法还借鉴了 E. Ioannides 与 T. A. Harris（1985）的疲劳极限模型。
:::

::: quiz
圆柱滚子轴承的径向载荷增大$25\,\%$。其额定寿命大约变为原来的多少倍？
- [ ] $0.80$
- [ ] $0.64$
- [x] $0.48$
- [ ] $0.51$
::: solution
$L_{10} \propto P^{-10/3}$，所以寿命乘以$1.25^{-10/3} = 0.475$。对球轴承，该倍数为$1.25^{-3} = 0.512$——即第四个选项，这是用错指数的陷阱。
:::

::: quiz
一个流体动压滑动轴承的转速加倍，而载荷、油温和尺寸保持不变。下列哪种说法正确？
- [ ] 索末菲数减半，油膜变薄。
- [x] 索末菲数加倍，偏心率减小，最小油膜变厚。
- [ ] 索末菲数不变，因为它只取决于几何尺寸。
- [ ] 摩擦因数减半，正如彼得罗夫方程所预测的。
::: solution
$S = (r/c)^2\mu N/P$与$N$成正比，所以加倍；$S$越大，轴颈偏心越小，油膜越厚。按彼得罗夫方程，摩擦因数会加倍而不是减半——不过实际上额外的发热会降低黏度，$S$的增益会损失一部分，这正是需要进行温度迭代的原因。
:::
:::

::: summary
- 滚动轴承因接触疲劳而失效；寿命分散很大，按统计方法规定。额定寿命$L_{10}$是$90\,\%$的轴承能达到的寿命。
- 载荷–寿命关系（ISO 281）：$L_{10} = (C/P)^p$百万转，球轴承$p = 3$，滚子轴承为$10/3$；以小时计，$L_{10h} = 10^6(C/P)^p/(60n)$。
- 可靠度：威布尔分布，例如$x_0 = 0.02$，$\theta - x_0 = 4.439$，$b = 1.483$（Budynas 与 Nisbett），或 ISO 281 的$a_1$（$95\,\%$时$0.64$，$99\,\%$时$0.25$）。所需额定值见[[#eq-c10]]。$k$个轴承组成的一组的可靠度为$\prod R_i$。
- 复合载荷：$P = XF_r + YF_a$，$X$、$Y$、$e$取自样本；工作循环：$P_\text{eq} = (\sum\alpha_iP_i^p)^{1/p}$，按转数加权。
- 静载能力：$C_0$（ISO 76），对峰值载荷计算$s_0 = C_0/P_0$。修正寿命$L_{nm} = a_1a_\text{ISO}L_{10}$计入润滑、污染和疲劳载荷极限。
- 选用：载荷 → 类型 → 寿命（来自经验，例如满负荷单班机器$20$–$30\times10^3\ \mathrm{h}$，连续工作$50$–$60\times10^3\ \mathrm{h}$）→ 使用系数 → 所需$C$ → 样本 → 校核。
- 滑动轴承：沿$f$对$\mu N/P$的施特里贝克曲线依次为边界、混合和全膜润滑区。彼得罗夫：$f = 2\pi^2(\mu N/P)(r/c)$，为轻载极限。
- 雷诺方程$\partial_x(h^3\partial_xp) + \partial_z(h^3\partial_zp) = 6\mu U\,\partial_xh$支配油膜；对给定$l/d$，所有性能变量只取决于$S = (r/c)^2\mu N/P$，Raimondi–Boyd 图表正是按此组织的。黏度必须取油膜温度下的值，而油膜温度通过迭代求得。
:::

## 习题

::: exercise 载荷加倍的影响 {level=1 check="0.125"}
深沟球轴承上的载荷加倍。其额定寿命乘以什么倍数？（填入倍数。）
::: solution
$L_{10} \propto P^{-3}$，所以倍数为$2^{-3} = 0.125$。对滚子轴承则为$2^{-10/3} = 0.099$。
:::

::: exercise 以小时计的额定寿命 {level=1 check="6000"}
一个$C = 30\ \mathrm{kN}$的球轴承在$600\ \mathrm{rev/min}$下承受$5\ \mathrm{kN}$的径向载荷。求其额定寿命。（填入以小时计的寿命。）
::: solution
$C/P = 6$，$L_{10} = 6^3 = 216\times10^6$转。每小时$600\times60 = 36\,000$转，$L_{10h} = 216\times10^6/36\,000 = 6000\ \mathrm{h}$。
:::
:::

::: exercise 索末菲数 {level=1 check="0.5"}
一个滑动轴承，$r/c = 1000$，油膜温度下油的黏度$\mu = 0.020\ \mathrm{Pa\,s}$，转速$1500\ \mathrm{rev/min}$，单位载荷$P = 1.0\ \mathrm{MPa}$。求索末菲数。（填入$S$。）
::: solution
$N = 25\ \mathrm{rev/s}$。$S = 10^6\times0.020\times25/10^6 = 0.5$。常见的失误是用$1500$ r/min，那样会得到$30$。
:::
:::

::: exercise 所需额定载荷 {level=2 check="30"}
一个球轴承在$1200\ \mathrm{rev/min}$、当量载荷$2.5\ \mathrm{kN}$下必须达到$24\,000\ \mathrm{h}$的额定寿命（$a_f = 1$，可靠度$90\,\%$）。求所需的基本额定动载荷。（填入以 kN 计的$C$。）
::: solution
$x_D = 24\,000\times60\times1200/10^6 = 1728$百万转。$C = P\,x_D^{1/3} = 2.5\times1728^{1/3} = 2.5\times12 = 30\ \mathrm{kN}$。
:::
:::

::: exercise 当量载荷 {level=2 check="5.44"}
一个球轴承承受$F_r = 4.0\ \mathrm{kN}$和$F_a = 2.0\ \mathrm{kN}$。样本给出该轴承在此轴向载荷下$e = 0.30$，当$F_a/F_r > e$时$X = 0.56$，$Y = 1.6$。求当量动载荷。（填入以 kN 计的$P$。）
::: solution
$F_a/F_r = 0.5 > 0.30$，故$P = 0.56\times4.0 + 1.6\times2.0 = 2.24 + 3.20 = 5.44\ \mathrm{kN}$。若$F_a/F_r$小于$e$，则$P$就等于$F_r$。
:::

::: exercise 更高可靠度下的寿命 {level=2 check="18500"}
一个轴承的额定寿命为$50\,000\ \mathrm{h}$。用 ISO 281 的系数$a_1$并取$a_\text{ISO} = 1$，求这类轴承中$98\,\%$能达到的寿命。（填入以小时计的寿命。）
::: solution
$98\,\%$时$a_1 = 0.37$，故$L_{2m} = 0.37\times50\,000 = 18\,500\ \mathrm{h}$。用[[#eq-a1]]校核：$\ln(1/0.98)/\ln(1/0.9) = 0.1917$，其$2/3$次方为$0.3326$，$0.95\times0.3326 + 0.05 = 0.366$。
:::

::: exercise 工作循环 {level=2}
一个$C = 20\ \mathrm{kN}$的球轴承，其转数的$90\,\%$在$P = 2\ \mathrm{kN}$下运转，$10\,\%$在$P = 4\ \mathrm{kN}$下运转。求当量载荷和以转数计的额定寿命。在较高载荷下运转的那$10\,\%$造成了多大比例的损伤？
::: solution
由[[#eq-peq]]：$P_\text{eq} = (0.9\times2^3 + 0.1\times4^3)^{1/3} = (7.2 + 6.4)^{1/3} = 13.6^{1/3} = 2.387\ \mathrm{kN}$。$L_{10} = (20/2.387)^3 = 588\times10^6$转。损伤份额与$\alpha_iP_i^3$成正比：$6.4/13.6 = 47\,\%$的损伤是在$10\,\%$的转数中造成的。短时间的高载荷远比其持续时间所显示的更重要。
:::

::: exercise 一组轴承的可靠度 {level=2}
一台输送机驱动装置有六个轴承，都按相同寿命、每个$R = 0.99$选用。(a) 在该寿命处这组轴承的可靠度是多少？(b) 要使整组达到$95\,\%$，每个轴承的可靠度必须是多少？(c) 为达到 (b)，每个球轴承的额定值必须比按$L_{10}$选用时增大多少倍？使用威布尔参数[[#eq-weibull-params]]。
::: solution
(a) $0.99^6 = 0.941$。(b) $R_i = 0.95^{1/6} = 0.99149$。(c) $\ln(1/0.99149) = 0.008549$；$0.008549^{1/1.483} = 0.0403$；[[#eq-c10]]中的方括号为$0.02 + 4.439\times0.0403 = 0.199$，额定值倍数为$(1/0.199)^{1/3} = 1.71$。
:::

::: exercise 彼得罗夫功率损失 {level=2}
一个汽轮机轴承，$d = 200\ \mathrm{mm}$，$l = 150\ \mathrm{mm}$，$c/r = 0.0015$，以$3000\ \mathrm{rev/min}$运转，油的黏度$\mu = 15\ \mathrm{mPa\,s}$，承受$W = 20\ \mathrm{kN}$。用彼得罗夫方程估算摩擦因数和摩擦功率，并求索末菲数。彼得罗夫的估计在这里是否可能准确？
::: solution
$r = 0.1\ \mathrm{m}$，$c = 0.15\ \mathrm{mm}$，$r/c = 666.7$，$N = 50\ \mathrm{rev/s}$，$P = 20\,000/(0.2\times0.15) = 0.667\ \mathrm{MPa}$。$\mu N/P = 0.015\times50/666\,700 = 1.125\times10^{-6}$。$f = 2\pi^2\times1.125\times10^{-6}\times666.7 = 0.0148$。力矩$fWr = 0.0148\times20\,000\times0.1 = 29.6\ \mathrm{N\,m}$，功率$29.6\times2\pi\times50 = 9.3\ \mathrm{kW}$。$S = 666.7^2\times1.125\times10^{-6} = 0.50$：中等载荷。对$l/d = 0.75$、$S = 0.5$求雷诺方程的数值解，得$\varepsilon \approx 0.35$，$(r/c)f \approx 10.7$，比彼得罗夫的$2\pi^2S = 9.9$约高$8\,\%$，因此作为初步估计是合理的。这$9\ \mathrm{kW}$必须由强制供油带走。
:::

::: exercise 短轴承理论 {#ex-short level=3}
对短轴承（$l/d$小），[[#eq-reynolds]]中周向压力流项与轴向项相比可以忽略。(a) 在$z = \pm l/2$处$p = 0$的条件下积分简化方程$\partial_z(h^3\partial_zp) = 6\mu U\,dh/dx$，求$p(\theta, z)$。(b) 采用半索末菲条件（$\pi < \theta < 2\pi$时$p = 0$），证明载荷为
$$
W = \frac{\mu Ul^3}{4c^2}\,\frac{\varepsilon}{(1 - \varepsilon^2)^2}\sqrt{\pi^2(1 - \varepsilon^2) + 16\varepsilon^2}
$$
并由此得$S\,(l/d)^2 = (1 - \varepsilon^2)^2/\big(\pi\varepsilon\sqrt{\pi^2(1 - \varepsilon^2) + 16\varepsilon^2}\big)$。(c) 计算$l/d = 0.25$、$\varepsilon = 0.6$时的$S$，并与完整数值解给出的$S \approx 1.08$比较，加以评论。
::: solution
(a) $h$与$z$无关，所以$h^3\,\partial p/\partial z = 6\mu U(dh/dx)\,z + A$；关于$z = 0$的对称性给出$A = 0$。在$p(\pm l/2) = 0$的条件下再积分一次：
$$
p = \frac{3\mu U}{h^3}\frac{dh}{dx}\left(z^2 - \frac{l^2}{4}\right) = \frac{3\mu U\varepsilon\sin\theta}{rc^2(1 + \varepsilon\cos\theta)^3}\left(\frac{l^2}{4} - z^2\right),
$$
其中用到$dh/dx = -(c\varepsilon/r)\sin\theta$。在$0 < \theta < \pi$（收敛油膜）内压力为正。

(b) $\int_{-l/2}^{l/2}(l^2/4 - z^2)\,dz = l^3/6$，因此对$z$积分（并为弧长$r\,d\theta$乘以$r$）后，公共因子为$K_0 = \dfrac{3\mu U\varepsilon}{rc^2}\cdot\dfrac{l^3}{6}\cdot r = \dfrac{\mu U\varepsilon l^3}{2c^2}$。沿中心连线及垂直于中心连线的载荷分量为$W_\parallel = -K_0\int_0^\pi\dfrac{\sin\theta\cos\theta}{(1 + \varepsilon\cos\theta)^3}d\theta$和$W_\perp = K_0\int_0^\pi\dfrac{\sin^2\theta}{(1 + \varepsilon\cos\theta)^3}d\theta$。利用标准积分$\int_0^\pi\sin\theta\cos\theta\,(1 + \varepsilon\cos\theta)^{-3}d\theta = -2\varepsilon/(1 - \varepsilon^2)^2$和$\int_0^\pi\sin^2\theta\,(1 + \varepsilon\cos\theta)^{-3}d\theta = \pi/[2(1 - \varepsilon^2)^{3/2}]$：
$$
W_\parallel = \frac{\mu Ul^3\varepsilon^2}{c^2(1 - \varepsilon^2)^2}, \qquad W_\perp = \frac{\pi\mu Ul^3\varepsilon}{4c^2(1 - \varepsilon^2)^{3/2}}.
$$
于是$W = \sqrt{W_\parallel^2 + W_\perp^2} = \dfrac{\mu Ul^3\varepsilon}{4c^2(1 - \varepsilon^2)^2}\sqrt{16\varepsilon^2 + \pi^2(1 - \varepsilon^2)}$。利用$U = 2\pi rN$和$W = 2rlP$，$S = (r/c)^2\mu N/P = (r/c)^2\mu N\cdot2rl/W$；代入$W$得$S = \dfrac{4r^2}{l^2}\dfrac{(1 - \varepsilon^2)^2}{\pi\varepsilon\sqrt{\pi^2(1 - \varepsilon^2) + 16\varepsilon^2}}$，而$4r^2/l^2 = (d/l)^2$。偏位角满足$\tan\phi = W_\perp/W_\parallel = \pi\sqrt{1 - \varepsilon^2}/(4\varepsilon)$。

(c) $\varepsilon = 0.6$：$\sqrt{\pi^2\times0.64 + 16\times0.36} = 3.475$；$S(l/d)^2 = 0.4096/(\pi\times0.6\times3.475) = 0.0625$；由$(l/d)^2 = 1/16$得$S = 1.00$。完整解给出$S \approx 1.08$：此处短轴承理论把承载能力高估约$8\,\%$，因为它忽略的周向压力流会让一部分油流走。误差随$l/d$增大而增大；在$l/d = 1$时该理论已不适用。
:::

::: exercise 选择并论证轴承布置 {level=3}
一台离心泵的轴以$2900\ \mathrm{rev/min}$连续运转。叶轮端轴承承受$3.0\ \mathrm{kN}$的径向载荷；另一个轴承承受$1.5\ \mathrm{kN}$的径向载荷和全部$1.2\ \mathrm{kN}$的水力推力。非计划停机代价高昂。提出一个轴承布置方案（类型、哪个轴承定位）、设计寿命和可靠度以及所需的额定载荷。然后讨论还需要校核什么，以及流体动压轴承是否会是更好的选择。
::: solution
这是开放性问题；下面给出一个合理的答案。

**布置。** 推力端为定位轴承：一个深沟球轴承（若推力更大或方向会反转，则用一对角接触轴承）；叶轮端为非定位轴承：一个可在轴承座内滑动的深沟球轴承，或一个圆柱滚子轴承，以允许热膨胀。

**寿命与可靠度。** 每天 24 小时连续工作：由表取$50$–$60\times10^3\ \mathrm{h}$；由于停机代价高，取$60\,000\ \mathrm{h}$，每个轴承$R = 0.99$（两个合计约$0.98$）。使用系数：几乎无冲击的旋转机械，$a_f = 1.2$。寿命：$x_D = 60\times2900\times60\,000/10^6 = 10\,440$百万转。

**叶轮端轴承（球轴承，纯径向载荷）。** 由[[#eq-c10]]，$C \ge 1.2\times3.0\times(10\,440/0.2196)^{1/3} = 3.6\times36.2 = 130\ \mathrm{kN}$——这是一个大轴承；若用圆柱滚子轴承（$p = 10/3$），$C \ge 3.6\times(47\,540)^{0.3} = 3.6\times25.3 = 91\ \mathrm{kN}$。

**推力端轴承。** 假定$X = 0.56$，$Y = 1.5$：$P = 0.56\times1.5 + 1.5\times1.2 = 2.64\ \mathrm{kN}$；乘以$a_f$得$3.17\ \mathrm{kN}$，$C \ge 3.17\times36.2 = 115\ \mathrm{kN}$。从样本中选出轴承，再用该轴承的$C_0$重新计算$Y$并迭代。

**进一步校核。** 额定值之所以大，是因为高速下要求的寿命很长：校核极限转速；看在清洁的油润滑下（$a_\text{ISO} > 1$）$L_{nm}$是否允许采用更小的轴承；针对推力冲击校核静载安全因数；规定配合和润滑方式。

**流体动压方案。** 滑动轴承没有疲劳极限，并能阻尼振动，但需要可靠的供油、一个推力轴承以及对起动过程的照顾。小型泵用滚动轴承；大型锅炉给水泵通常采用流体动压径向轴承和可倾瓦推力轴承。
:::
