紧固件是最常见的机器元件：螺栓、螺钉、铆钉和焊缝是把机器连成一体的接头，而接头是决定机器强度、刚度和疲劳寿命的零件。**失效的接头不只是让零件分开；它还会释放储存的能量，而释放正是接头失效成为机械设计中最危险失效形式的原因。**紧固件设计是一个多准则计算：螺栓必须承受预紧力、外载荷和疲劳载荷；焊缝必须承受剪切、拉伸和疲劳载荷；胶接接头必须承受剪切、剥离和环境载荷。**只按静拉伸强度设计螺栓的工程师不是在螺栓设计，而是在设计一个会因疲劳而不是拉伸失效的螺栓。**

紧固件设计的定量工具是**螺栓预紧力与扭矩**（摩擦模型）、**螺栓疲劳**（考虑预紧效应的古德曼（Goodman）图）、**焊缝强度**（剪切与拉伸准则）、**焊缝疲劳**（考虑应力集中的 S-N 曲线）和**胶接强度**（剪切与剥离准则）。这些工具就是表达紧固件设计决策的语言，而这套语言正是紧固件设计是计算而非猜测的原因。

::: warning 紧固件设计出错的九种方式
**不计算预紧力。**不计算预紧力就设计螺栓的工程师，不是在螺栓设计，而是在设计一个会松动的螺栓。**预紧力正是螺栓在振动下不松动的原因，而预紧力也正是有预紧时螺栓疲劳寿命比无预紧时长 5 倍的原因。** **不考虑扭矩-预紧力分散。**由扭矩计算预紧力却不考虑分散系数的工程师，不是在计算预紧力，而是在瞎猜。**扭矩-预紧力分散为 ±25–30 %，而分散正是预紧力必须用转角法或超声波法校核的原因。** **不校核螺栓疲劳。**按静拉伸强度设计螺栓却不校核疲劳的工程师，不是在螺栓设计，而是在设计一个会因疲劳失效的螺栓。**螺栓疲劳是最常见的螺栓失效形式（占螺栓失效的 80–90 %），而疲劳正是螺栓按古德曼图而不是按静拉伸强度设计的原因。** **不考虑连接刚度。**不计算连接刚度就设计螺栓的工程师，不是在螺栓设计，而是在设计一个会因疲劳失效的螺栓。**连接刚度决定螺栓与连接之间的载荷分配，而载荷分配正是刚性连接下螺栓疲劳寿命比柔性连接下长 5 倍的原因。** **不校核焊缝疲劳。**按静抗剪强度设计焊缝却不校核疲劳的工程师，不是在焊缝设计，而是在设计一个会因疲劳失效的焊缝。**焊缝疲劳是最常见的焊缝失效形式（占焊缝失效的 70–80 %），而疲劳正是焊缝按 S-N 曲线而不是按静抗剪强度设计的原因。** **不规定焊缝质量等级。**设计焊缝却不规定焊缝质量等级（ISO 5817）的工程师，不是在焊缝设计，而是在选一条会因缺陷失效的焊缝。**焊缝质量等级决定缺陷尺寸，而缺陷尺寸正是 B 级焊缝疲劳寿命比 D 级长 5 倍的原因。** **不考虑胶接表面处理。**设计胶接接头却不规定表面处理的工程师，不是在胶接设计，而是在选一个会因粘附失效的接头。**表面处理正确时胶接强度比表面处理错误时高 3 倍，而这 3 倍正是表面处理成为胶接中最重要因素的影响。** **不校核螺栓剪切。**按拉伸强度设计螺栓却不校核剪切的工程师，不是在螺栓设计，而是在设计一个会因剪切失效的螺栓。**螺栓剪切是法兰螺栓连接中最常见的失效形式，而剪切正是螺栓按抗剪强度而不是抗拉强度设计的原因。** **不考虑热膨胀。**设计螺栓连接却不校核热膨胀的工程师，不是在接头设计，而是在设计一个会泄漏的接头。**热膨胀正是螺栓预紧力随温度变化 20–50 % 的原因，而变化正是螺栓连接必须按热载荷而不只是机械载荷设计的原因。**
:::

## 1. 螺栓连接

::: definition 螺栓预紧力与扭矩-预紧力关系 {#def-bolt-preload}
**螺栓预紧力**是由拧紧扭矩在螺栓中引起的拉力，而预紧力正是螺栓在振动下不松动的原因。

$$
T \; = \; K \, d \, F _ { i }
$$

其中 $T$ 是拧紧扭矩，$K$ 是扭矩系数（典型 0.15–0.20），$d$ 是螺栓直径，$F _ { i }$ 是预紧力。

**预紧力**通常取螺栓保证载荷的 70–90 %：

$$
F _ { i } \; = \; ( 0 . 7 \text{--} 0 . 9 ) \, A _ { t } \, S _ { p }
$$

其中 $A _ { t }$ 是应力截面积，$S _ { p }$ 是保证应力。

$$
\begin{array} { l c c c c }
\textbf{性能等级} & \textbf{ } S _ { y } \textbf{（MPa）} & \textbf{ } S _ { u t } \textbf{（MPa）} & \textbf{ } S _ { p } \textbf{（MPa）} & \textbf{使用场合} \\ \hline
8 . 8 & 6 4 0 & 8 0 0 & 6 0 0 & \text{通用} \\
1 0 . 9 & 9 0 0 & 1 \ 0 0 0 & 8 3 0 & \text{高强度} \\
1 2 . 9 & 1 \ 1 0 0 & 1 \ 2 0 0 & 9 7 0 & \text{超高强度} \\
A 2 \text{-} 7 0 \text{（不锈钢）} & 4 5 0 & 7 0 0 & 4 5 0 & \text{耐腐蚀} \\
\end{array}
$$

**预紧力正是螺栓在振动下不松动的原因，而预紧力也正是有预紧时螺栓疲劳寿命比无预紧时长 5 倍的原因。不计算预紧力就设计螺栓的工程师，不是在螺栓设计，而是在设计一个会松动的螺栓。**
:::

::: definition 连接刚度与载荷分配 {#def-joint-stiffness}
**连接刚度比**是被连接件刚度与螺栓刚度之比，连接刚度决定螺栓与连接之间的载荷分配。

$$
C \; = \; { \frac { k _ { b } } { k _ { b } + k _ { m } } }
$$

其中 $k _ { b }$ 是螺栓刚度，$k _ { m }$ 是连接（被连接件）刚度。

外载荷 $P$ 作用下的**螺栓载荷**为：

$$
F _ { b } \; = \; F _ { i } + C \, P
$$

外载荷 $P$ 作用下的**连接载荷**为：

$$
F _ { m } \; = \; F _ { i } - ( 1 - C ) \, P
$$

$$
\begin{array} { l c c }
\textbf{连接刚度比 } C & \textbf{螺栓载荷增量} & \textbf{疲劳寿命} \\ \hline
0 . 1 \text{（刚性连接）} & P \text{ 的 } 1 0 \ \% & \text{很长} \\
0 . 2 \text{（典型）} & P \text{ 的 } 2 0 \ \% & \text{长} \\
0 . 3 \text{（柔性连接）} & P \text{ 的 } 3 0 \ \% & \text{中等} \\
0 . 5 \text{（很柔）} & P \text{ 的 } 5 0 \ \% & \text{短} \\
\end{array}
$$

**连接刚度正是刚性连接下螺栓疲劳寿命比柔性连接下长 5 倍的原因。不计算连接刚度就设计螺栓的工程师，不是在螺栓设计，而是在设计一个会因疲劳失效的螺栓。**
:::

::: definition 螺栓疲劳与古德曼图 {#def-bolt-fatigue}
**螺栓疲劳**是最常见的螺栓失效形式（占螺栓失效的 80–90 %），而螺栓疲劳正是螺栓按古德曼图而不是按静拉伸强度设计的原因。

**螺栓连接的古德曼图**为：

$$
{ \frac { \sigma _ { a } } { S _ { e } } } + { \frac { \sigma _ { m } } { S _ { u t } } } \; = \; { \frac { 1 } { n } }
$$

其中 $\sigma _ { a }$ 是应力幅，$\sigma _ { m }$ 是平均应力。

对有预紧力的螺栓：

$$
\sigma _ { a } \; = \; { \frac { C \, P _ { \max } - P _ { \min } } { 2 \, A _ { t } } } \qquad \sigma _ { m } \; = \; { \frac { C \, P _ { \max } + P _ { \min } } { 2 \, A _ { t } } } + { \frac { F _ { i } } { A _ { t } } }
$$

**预紧力把应力幅降低 80–90 %，而这降低正是有预紧时螺栓疲劳寿命比无预紧时长 5 倍的原因。不施加预紧力就设计螺栓的工程师，不是在螺栓设计，而是在设计一个会因疲劳失效的螺栓。**
:::

::: example 螺栓预紧力与扭矩 {#ex-bolt-preload level=3 check="2"}
某 M12 螺栓（性能等级 8.8，$A _ { t } = 8 4 . 3$ mm²，$S _ { p } = 6 0 0$ MPa）拧紧到保证载荷的 75 %。扭矩系数 $K = 0 . 1 5$。试计算预紧力和拧紧扭矩。

**预紧力：**

$$
F _ { i } \; = \; 0 . 7 5 \times A _ { t } \times S _ { p } \; = \; 0 . 7 5 \times 8 4 . 3 \times 6 0 0 \; = \; { \bf 3 7 \ 9 3 5 } \ \text{N} \; = \; 3 7 . 9 \ \text{kN}
$$

**拧紧扭矩：**

$$
T \; = \; K \, d \, F _ { i } \; = \; 0 . 1 5 \times 1 2 \times 3 7 \ 9 3 5 \; = \; { \bf 6 8 . 3 } \ \text{N} { \cdot } \text{m}
$$

**预紧力为 37.9 kN，拧紧扭矩为 68.3 N·m。工程师会规定扭矩 68 N·m ± 10 %，而这 ± 10 % 正是扭矩-预紧力分散为 ± 25–30 % 的原因。**
:::
## 2. 焊接接头

::: definition 焊缝类型及其强度 {#def-weld-types}
**焊缝类型**按接头形式、载荷方向和可达性选定：

$$
\begin{array} { l c c c l }
\textbf{焊缝类型} & \textbf{载荷方向} & \textbf{应力类型} & \textbf{强度} & \textbf{使用场合} \\ \hline
\text{对接（直边坡口）} & \text{拉伸} & \text{拉伸} & \text{等强于母材} & \text{板对板} \\
\text{角焊缝（平行）} & \text{剪切} & \text{剪切} & 0 . 7 \times \text{母材} & \text{T 形接头、搭接} \\
\text{角焊缝（垂直）} & \text{拉伸} & \text{拉伸 + 剪切} & 0 . 8 5 \times \text{母材} & \text{T 形接头、搭接} \\
\text{塞焊/槽焊} & \text{剪切} & \text{剪切} & \text{低} & \text{薄板} \\
\text{点焊（电阻焊）} & \text{剪切} & \text{剪切} & \text{中} & \text{薄板、汽车} \\
\text{缝焊（电阻焊）} & \text{剪切} & \text{剪切} & \text{中} & \text{管材、罐体} \\
\end{array}
$$

**角焊缝是最常见的焊缝类型，因为角焊缝最易施焊，且对装配误差的容忍度最高。按焊脚尺寸设计角焊缝却不计算焊喉厚度的工程师，不是在焊缝设计，而是在设计一条会因剪切失效的焊缝。**
:::

::: definition 角焊缝强度 {#def-fillet-weld}
**角焊缝**按**焊喉厚度** $t = 0 . 7 0 7 \, h$（$h$ 为焊脚尺寸）和**焊缝长度** $L$ 定尺寸：

**剪切（平行角焊缝）：**

$$
\tau \; = \; { \frac { F } { t \, L } } \; = \; { \frac { F } { 0 . 7 0 7 \, h \, L } } \; \le \; { \frac { S _ { u t , \text{weld } } } { n } }
$$

**拉伸（垂直角焊缝）：**

$$
\sigma \; = \; { \frac { F } { t \, L } } \; \le \; { \frac { S _ { u t , \text{weld } } } { n } }
$$

**组合（弯曲 + 剪切）：**

$$
\sigma _ { \text{eq } } \; = \; { \sqrt { \sigma ^ { 2 } + 3 \, \tau ^ { 2 } } } \; \le \; { \frac { S _ { u t , \text{weld } } } { n } }
$$

$$
\begin{array} { l c c }
\textbf{焊缝质量等级（ISO 5817）} & \textbf{缺陷尺寸} & \textbf{疲劳强度} \\ \hline
\text{B（严格）} & \text{小} & \text{高} \\
\text{C（中等）} & \text{中} & \text{中} \\
\text{D（较低）} & \text{大} & \text{低} \\
\end{array}
$$

**焊缝质量等级正是 B 级焊缝疲劳寿命比 D 级长 5 倍的原因。设计焊缝却不规定焊缝质量等级的工程师，不是在焊缝设计，而是在选一条会因缺陷失效的焊缝。**
:::

::: example 角焊缝设计 {#ex-fillet-weld-design level=3 check="2"}
某 T 形接头用两条平行角焊缝焊接，每条长 100 mm。接头承受剪切载荷 80 kN。焊缝材料 $S _ { u t } = 4 5 0$ MPa，安全因数取 2.5。试计算所需焊脚尺寸。

**所需焊喉面积：**

$$
A _ { \text{required } } \; = \; { \frac { F \times n } { S _ { u t } } } \; = \; { \frac { 8 0 \ 0 0 0 \times 2 . 5 } { 4 5 0 } } \; = \; 4 4 4 . 4 \ \text{mm} ^ { 2 }
$$

**焊缝总长（两条焊缝）：**

$$
L _ { \text{total } } \; = \; 2 \times 1 0 0 \; = \; 2 0 0 \ \text{mm}
$$

**所需焊喉厚度：**

$$
t \; = \; { \frac { A _ { \text{required } } } { L _ { \text{total } } } } \; = \; { \frac { 4 4 4 . 4 } { 2 0 0 } } \; = \; 2 . 2 2 \ \text{mm}
$$

**所需焊脚尺寸：**

$$
h \; = \; { \frac { t } { 0 . 7 0 7 } } \; = \; { \frac { 2 . 2 2 } { 0 . 7 0 7 } } \; = \; { \bf 3 . 1 4 } \ \text{mm}
$$

**工程师会规定 4 mm 角焊缝（下一个标准尺寸），此时安全因数为 3.2。**
:::

## 3. 胶接接头与其他接头

::: definition 胶接强度 {#def-adhesive-bond}
**胶接接头**是用聚合物胶粘剂连接零件的接头，而胶接接头正是接头成为连续而不是间断连接的原因。

$$
\begin{array} { l c c c }
\textbf{胶粘剂类型} & \textbf{抗剪强度（MPa）} & \textbf{剥离强度（MPa）} & \textbf{温度上限（°C）} \\ \hline
\text{环氧} & 2 0 \text{--} 3 5 & 5 \text{--} 1 0 & 1 2 0 \text{--} 1 8 0 \\
\text{丙烯酸（MMA）} & 1 5 \text{--} 2 5 & 8 \text{--} 1 5 & 8 0 \text{--} 1 2 0 \\
\text{聚氨酯} & 1 0 \text{--} 2 0 & 1 0 \text{--} 2 0 & 8 0 \text{--} 1 0 0 \\
\text{氰基酸酯（瞬间接着剂）} & 1 5 \text{--} 2 5 & 2 \text{--} 5 & 8 0 \text{--} 1 0 0 \\
\text{有机硅} & 2 \text{--} 5 & 5 \text{--} 1 0 & 2 0 0 \text{--} 2 5 0 \\
\end{array}
$$

**胶接正是接头成为连续连接的原因，而连续正是胶接接头比铆接接头更强的原因。设计胶接接头却不规定表面处理的工程师，不是在胶接设计，而是在选一个会因粘附失效的接头。**
:::

::: definition 铆接接头 {#def-riveted-joint}
**铆接接头**是用铆钉连接零件的接头，而铆接接头正是接头成为永久而不是可拆连接的原因。

$$
\begin{array} { l c c }
\textbf{接头形式} & \textbf{失效形式} & \textbf{强度公式} \\ \hline
\text{单剪} & \text{铆钉剪切} & \tau = F / ( \pi d ^ { 2 } / 4 ) \\
\text{双剪} & \text{铆钉剪切} & \tau = F / ( 2 \times \pi d ^ { 2 } / 4 ) \\
\text{挤压} & \text{板件压溃} & \sigma _ { b } = F / ( d \, t ) \\
\text{拉伸} & \text{板件净截面} & \sigma = F / ( ( w - n d ) \, t ) \\
\end{array}
$$

**铆接正是接头成为永久连接的原因，而永久正是铆接接头用于飞机、桥梁和压力容器的原因。只按铆钉剪切设计铆接接头却不校核板件挤压的工程师，不是在接头设计，而是在设计一个会因挤压失效的接头。**
:::

::: example 螺栓连接疲劳 {#ex-bolt-fatigue level=3 check="2"}
某 M16 螺栓（性能等级 10.9，$A _ { t } = 1 5 7$ mm²，$S _ { u t } = 1 0 0 0$ MPa，$S _ { e } = 2 0 0$ MPa）预紧到保证载荷的 70 %（$S _ { p } = 8 3 0$ MPa）。连接刚度比 $C = 0 . 2$。外载荷在 0 到 40 kN 之间变化。试用古德曼准则计算安全因数。

**预紧力：**

$$
F _ { i } \; = \; 0 . 7 \times 1 5 7 \times 8 3 0 \; = \; 9 1 \ 1 4 7 \ \text{N} \; = \; 9 1 . 1 \ \text{kN}
$$

**应力幅：**

$$
\sigma _ { a } \; = \; { \frac { C \, ( P _ { \max } - P _ { \min } ) } { 2 \, A _ { t } } } \; = \; { \frac { 0 . 2 \times 4 0 \ 0 0 0 } { 2 \times 1 5 7 } } \; = \; { \frac { 8 \ 0 0 0 } { 3 1 4 } } \; = \; 2 5 . 5 \ \text{MPa}
$$

**平均应力：**

$$
\sigma _ { m } \; = \; { \frac { F _ { i } } { A _ { t } } } + { \frac { C \, ( P _ { \max } + P _ { \min } ) } { 2 \, A _ { t } } } \; = \; { \frac { 9 1 \ 1 4 7 } { 1 5 7 } } + { \frac { 0 . 2 \times 4 0 \ 0 0 0 } { 2 \times 1 5 7 } } \; = \; 5 8 0 . 6 + 2 5 . 5 \; = \; 6 0 6 . 1 \ \text{MPa}
$$

**古德曼准则：**

$$
{ \frac { 2 5 . 5 } { 2 0 0 } } + { \frac { 6 0 6 . 1 } { 1 \ 0 0 0 } } \; = \; 0 . 1 2 8 + 0 . 6 0 6 \; = \; 0 . 7 3 4 \; = \; { \frac { 1 } { n } }
$$

$$
n \; = \; { \frac { 1 } { 0 . 7 3 4 } } \; = \; { \bf 1 . 3 6 }
$$

**安全因数（1.36）低于典型要求 1.5。工程师必须增大预紧力、减小外载荷或改用更高强度的螺栓。**
:::

::: example 螺栓法兰连接 {#ex-bolted-flange level=3 check="2"}
某螺栓法兰连接有 8 个螺栓（M16，性能等级 8.8，$A _ { t } = 1 5 7$ mm²，$S _ { p } = 6 0 0$ MPa）。法兰承受作用在 12 000 mm² 垫片面积上的 5 MPa 内压。连接刚度比 $C = 0 . 2 5$。试计算每个螺栓的预紧力和压力载荷下的螺栓应力。

**外载荷总量：**

$$
P _ { \\text{total } } \\; = \\; p \\times A _ { \\text{gasket } } \\; = \\; 5 \\times 1 2 \\ 0 0 0 \\; = \\; 6 0 \\ 0 0 0 \\ \\text{N} \\; = \\; 6 0 \\ \\text{kN}
$$

**每个螺栓的外载荷：**

$$
P _ { \\text{bolt } } \\; = \\; { \\frac { 6 0 } { 8 } } \\; = \\; 7 . 5 \\ \\text{kN}
$$

**每个螺栓的预紧力（保证载荷的 75 %）：**

$$
F _ { i } \\; = \\; 0 . 7 5 \\times 1 5 7 \\times 6 0 0 \\; = \\; { \\bf 7 0 \\ 6 5 0 } \\ \\text{N} \\; = \\; 7 0 . 7 \\ \\text{kN}
$$

**压力下的螺栓载荷：**

$$
F _ { b } \\; = \\; F _ { i } + C \\times P _ { \\text{bolt } } \\; = \\; 7 0 . 7 + 0 . 2 5 \\times 7 . 5 \\; = \\; { \\bf 7 2 . 6 } \\ \\text{kN}
$$

**螺栓应力：**

$$
\\sigma _ { b } \\; = \\; { \\frac { F _ { b } } { A _ { t } } } \\; = \\; { \\frac { 7 2 \\ 6 0 0 } { 1 5 7 } } \\; = \\; { \\bf 4 6 2 } \\ \\text{MPa}
$$

**螺栓应力（462 MPa）低于保证应力（600 MPa），连接是安全的。每个螺栓的预紧力为 70.7 kN，而预紧力正是接头在压力下不泄漏的原因。**
:::
## 习题

::: exercise 螺栓扭矩计算 {#ex-bolt-torque level=3 check="2"}
某 M10 螺栓（性能等级 8.8，$A _ { t } = 5 8$ mm²，$S _ { p } = 6 0 0$ MPa）拧紧到保证载荷的 80 %。扭矩系数 $K = 0 . 1 8$。试计算预紧力和拧紧扭矩。

::: solution
$$
F _ { i } \; = \; 0 . 8 \times 5 8 \times 6 0 0 \; = \; { \bf 2 7 \ 8 4 0 } \ \text{N} \; = \; 2 7 . 8 \ \text{kN}
$$

$$
T \; = \; 0 . 1 8 \times 1 0 \times 2 7 \ 8 4 0 \; = \; { \bf 5 0 . 1 } \ \text{N} { \cdot } \text{m}
$$

**预紧力为 27.8 kN，拧紧扭矩为 50.1 N·m。**
:::
:::

::: exercise 连接刚度与载荷分配 {#ex-joint-stiffness level=3 check="2"}
某螺栓连接的螺栓刚度 $k _ { b } = 2 0 0$ MN/m，连接刚度 $k _ { m } = 8 0 0$ MN/m。外载荷 20 kN，预紧力 30 kN。试计算螺栓载荷和连接载荷。

::: solution
$$
C \; = \; { \frac { 2 0 0 } { 2 0 0 + 8 0 0 } } \; = \; 0 . 2
$$

$$
F _ { b } \; = \; 3 0 + 0 . 2 \times 2 0 \; = \; { \bf 3 4 } \ \text{kN}
$$

$$
F _ { m } \; = \; 3 0 - 0 . 8 \times 2 0 \; = \; { \bf 1 4 } \ \text{kN}
$$

**螺栓载荷增加 4 kN（外载荷的 20 %），连接载荷减少 16 kN（外载荷的 80 %）。刚性连接正是螺栓疲劳寿命长的原因。**
:::
:::

::: exercise 角焊缝设计 {#ex-fillet-weld-ex level=3 check="2"}
某搭接接头用两条垂直角焊缝焊接，每条长 80 mm。接头承受拉伸载荷 60 kN。焊缝材料 $S _ { u t } = 4 0 0$ MPa，安全因数取 3.0。试计算所需焊脚尺寸。

::: solution
$$
A _ { \text{required } } \; = \; { \frac { 6 0 \ 0 0 0 \times 3 . 0 } { 4 0 0 } } \; = \; 4 5 0 \ \text{mm} ^ { 2 }
$$

$$
L _ { \text{total } } \; = \; 2 \times 8 0 \; = \; 1 6 0 \ \text{mm}
$$

$$
t \; = \; { \frac { 4 5 0 } { 1 6 0 } } \; = \; 2 . 8 1 \ \text{mm}
$$

$$
h \; = \; { \frac { 2 . 8 1 } { 0 . 7 0 7 } } \; = \; { \bf 3 . 9 8 } \ \text{mm}
$$

**工程师会规定 5 mm 角焊缝（下一个标准尺寸），此时安全因数为 3.7。**
:::
:::

::: exercise 铆接接头 {#ex-riveted-joint level=3 check="2"}
某单排铆钉搭接接头的铆钉直径 16 mm，板厚 8 mm，板宽 80 mm。铆钉材料 $S _ { u t } = 4 0 0$ MPa，板材料 $S _ { u t } = 3 5 0$ MPa。试计算接头效率。

::: solution
**铆钉剪切面积（单剪）：**

$$
A _ { \text{shear } } \; = \; { \frac { \pi \times 1 6 ^ { 2 } } { 4 } } \; = \; 2 0 1 \ \text{mm} ^ { 2 }
$$

**铆钉抗剪强度：**

$$
F _ { \text{shear } } \; = \; 2 0 1 \times 4 0 0 \; = \; 8 0 . 4 \ \text{kN}
$$

**板件净截面面积：**

$$
A _ { \text{net } } \; = \; ( 8 0 - 1 6 ) \times 8 \; = \; 5 1 2 \ \text{mm} ^ { 2 }
$$

**板件抗拉强度：**

$$
F _ { \text{tension } } \; = \; 5 1 2 \times 3 5 0 \; = \; 1 7 9 . 2 \ \text{kN}
$$

**接头效率：**

$$
\eta \; = \; { \frac { \min ( 8 0 . 4 , \; 1 7 9 . 2 ) } { 8 0 \times 8 \times 3 5 0 / 1 0 0 0 } } \; = \; { \frac { 8 0 . 4 } { 2 2 4 } } \; = \; { \bf 3 5 . 9 } \ \ \%
$$

**接头效率为 35.9 %，这是单排铆钉搭接接头的典型值。效率正是铆接接头不用于高强度场合的原因。**
:::
:::

::: exercise 胶接接头 {#ex-adhesive-bond level=3 check="2"}
某环氧胶接接头的搭接长度 25 mm，宽度 20 mm，抗剪强度 25 MPa。被粘物厚度 3 mm，被粘物抗剪强度 60 MPa。试计算最大载荷和失效形式。

::: solution
**胶粘剂剪切面积：**

$$
A _ { \text{adhesive } } \; = \; 2 5 \times 2 0 \; = \; 5 0 0 \ \text{mm} ^ { 2 }
$$

**胶粘剂抗剪强度：**

$$
F _ { \text{adhesive } } \; = \; 5 0 0 \times 2 5 \; = \; 1 2 . 5 \ \text{kN}
$$

**被粘物剪切面积：**

$$
A _ { \text{adherend } } \; = \; 2 5 \times 3 \; = \; 7 5 \ \text{mm} ^ { 2 }
$$

**被粘物抗剪强度：**

$$
F _ { \text{adherend } } \; = \; 7 5 \times 6 0 \; = \; 4 . 5 \ \text{kN}
$$

**最大载荷为 4.5 kN，失效形式是被粘物剪切（而不是胶粘剂剪切）。被粘物是较弱元件，而较弱正是胶接接头要按被粘物强度而不是胶粘剂强度设计的原因。**
:::
:::

::: exercise 螺栓疲劳 {#ex-bolt-fatigue-ex level=3 check="2"}
某 M12 螺栓（性能等级 8.8，$A _ { t } = 8 4 . 3$ mm²，$S _ { u t } = 8 0 0$ MPa，$S _ { e } = 1 5 0$ MPa）预紧到保证载荷的 75 %（$S _ { p } = 6 0 0$ MPa）。连接刚度比 $C = 0 . 2 5$。外载荷在 0 到 20 kN 之间变化。试用古德曼准则计算安全因数。

::: solution
**预紧力：**

$$
F _ { i } \; = \; 0 . 7 5 \times 8 4 . 3 \times 6 0 0 \; = \; 3 7 \ 9 3 5 \ \text{N}
$$

**应力幅：**

$$
\sigma _ { a } \; = \; { \frac { 0 . 2 5 \times 2 0 \ 0 0 0 } { 2 \times 8 4 . 3 } } \; = \; { \frac { 5 \ 0 0 0 } { 1 6 8 . 6 } } \; = \; 2 9 . 7 \ \text{MPa}
$$

**平均应力：**

$$
\sigma _ { m } \; = \; { \frac { 3 7 \ 9 3 5 } { 8 4 . 3 } } + 2 9 . 7 \; = \; 4 5 0 + 2 9 . 7 \; = \; 4 7 9 . 7 \ \text{MPa}
$$

**古德曼准则：**

$$
{ \frac { 2 9 . 7 } { 1 5 0 } } + { \frac { 4 7 9 . 7 } { 8 0 0 } } \; = \; 0 . 1 9 8 + 0 . 6 0 0 \; = \; 0 . 7 9 8 \; = \; { \frac { 1 } { n } }
$$

$$
n \; = \; { \frac { 1 } { 0 . 7 9 8 } } \; = \; { \bf 1 . 2 5 }
$$

**安全因数（1.25）低于典型要求 1.5。工程师必须增大预紧力或减小外载荷。**
:::
:::

::: exercise 推导：螺栓预紧力与扭矩 {#ex-derive-bolt-torque level=4 check="2"}
试证明拧紧扭矩 $T = K d F _ { i }$ 由扭矩平衡导出：施加的扭矩是螺纹摩擦扭矩、支承面摩擦扭矩和螺纹升距扭矩之和。并对螺纹摩擦系数 $\mu _ { t } = 0 . 1 5$、支承面摩擦系数 $\mu _ { b } = 0 . 1 5$、螺距 $p = 1 . 7 5$ mm、支承面半径 $r _ { b } = 7 . 2$ mm 计算扭矩系数 $K$。

::: solution
扭矩平衡为：

$$
T \; = \; T _ { \text{thread } } + T _ { \text{bearing } } + T _ { \text{pitch } }
$$

$$
T \; = \; \mu _ { t } \, F _ { i } \, { \frac { d _ { 2 } } { 2 } } + \mu _ { b } \, F _ { i } \, r _ { b } + F _ { i } \, { \frac { p } { 2 \pi } }
$$

对 M12：$d _ { 2 } \approx 1 0 . 9$ mm，$p = 1 . 7 5$ mm，$r _ { b } = 7 . 2$ mm。

$$
T \; = \; F _ { i } \left( 0 . 1 5 \times { \frac { 1 0 . 9 } { 2 } } + 0 . 1 5 \times 7 . 2 + { \frac { 1 . 7 5 } { 2 \pi } } \right) \; = \; F _ { i } \, ( 0 . 8 1 8 + 1 . 0 8 + 0 . 2 7 9 )
$$

$$
T \; = \; F _ { i } \times 2 . 1 7 7 \; = \; F _ { i } \times 0 . 1 8 1 \times 1 2
$$

$$
K \; = \; { \frac { 2 . 1 7 7 } { 1 2 } } \; = \; { \bf 0 . 1 8 1 }
$$

**扭矩系数 $K = 0 . 1 8 1$ 处于典型范围（0.15–0.20）之内，而这一范围正是扭矩-预紧力分散为 ± 25–30 % 的原因。** $\blacksquare$
:::
:::

::: exercise 推导：连接刚度 {#ex-derive-joint-stiffness level=4 check="2"}
试证明连接刚度比 $C = k _ { b } / ( k _ { b } + k _ { m } )$ 由变形协调条件导出：外载荷作用下螺栓伸长增量等于连接压缩减量。并对 $k _ { b } = 3 0 0$ MN/m、$k _ { m } = 1 2 0 0$ MN/m 计算 $C$。

::: solution
变形协调条件指出，螺栓伸长增量等于连接压缩减量：

$$
\Delta \delta _ { b } \; = \; \Delta \delta _ { m }
$$

螺栓载荷增量为 $\Delta F _ { b } = k _ { b } \, \Delta \delta$，连接载荷减量为 $\Delta F _ { m } = k _ { m } \, \Delta \delta$。

外载荷是螺栓载荷增量与连接载荷减量之和：

$$
P \; = \; \Delta F _ { b } + \Delta F _ { m } \; = \; ( k _ { b } + k _ { m } ) \, \Delta \delta
$$

螺栓载荷增量为：

$$
\Delta F _ { b } \; = \; k _ { b } \, \Delta \delta \; = \; k _ { b } \, { \frac { P } { k _ { b } + k _ { m } } } \; = \; C \, P
$$

其中 $C = k _ { b } / ( k _ { b } + k _ { m } )$。

$$
C \; = \; { \frac { 3 0 0 } { 3 0 0 + 1 \ 2 0 0 } } \; = \; { \frac { 3 0 0 } { 1 \ 5 0 0 } } \; = \; { \bf 0 . 2 }
$$

**连接刚度比 $C = 0 . 2$ 意味着外载荷的 20 % 由螺栓承受，80 % 由连接承受。刚性连接正是螺栓疲劳寿命长的原因。** $\blacksquare$
:::
:::

## 本讲的去向

- **[[machine-design/static-failure]]** — 螺栓和焊缝按失效理论（米泽斯、特雷斯卡）定尺寸。
- **[[machine-design/fatigue]]** — 螺栓和焊缝按疲劳准则（古德曼图、S-N 曲线）定尺寸。
- **[[machine-design/shafts]]** — 键是轴的保险丝，键被设计成先于轴失效。
- **[[machine-design/bearings]]** — 轴承配合正是配合正确时轴承寿命比配合错误时长 5 倍的原因。
- **[[machine-design/springs]]** — 弹簧是储存能量的弹性元件，而能量正是弹簧按疲劳准则设计的原因。
- **[[machine-design/clutches-brakes-belts]]** — 离合器和制动器是传递转矩的摩擦副接头，而摩擦正是离合器按摩擦因数设计的原因。
- **[[manufacturing/joining]]** — 焊缝质量等级（ISO 5817）正是 B 级焊缝疲劳寿命比 D 级长 5 倍的原因。
- **[[design-process/reliability-risk]]** — 螺栓连接和焊接接头是 FMEA 中的关键元件，而 FMEA 正是接头要按失效后果设计的原因。

::: history 紧固件与接头：从铆钉到高强度螺栓 {#history-fasteners}
**公元前 3000 年** — **最早的铆接接头**出土于埃及金器：金片用金铆钉连接。**埃及铆接接头正是铆钉成为最古老紧固件的原因，而这古老正是铆钉成为最精熟紧固件的原因。**

**1797 年** — **亨利·莫兹利（Henry Maudslay）** 发明了**标准化螺纹**，使螺栓具有互换性。**莫兹利的标准化螺纹正是螺栓成为应用最广紧固件的原因，而互换性正是螺栓成为最易加工紧固件的原因。**

**1841 年** — **惠氏螺纹（Whitworth）** 在英国实现标准化，**塞勒斯螺纹（Sellers）** 在美国实现标准化。**螺纹标准化正是螺栓成为最国际化紧固件的原因，而国际标准正是螺栓成为应用最广紧固件的原因。**

**1912 年** — **高强度螺栓**在美国问世，并被用于钢结构桥梁建设。**高强度螺栓正是螺栓连接用于桥梁的原因，而桥梁正是螺栓成为最关键紧固件的原因。**

**20 世纪 30 年代** — **电弧焊**工艺得到发展，电弧焊在造船和桥梁建设中取代了铆接。**电弧焊正是焊接接头成为钢结构中最常见接头的原因，而焊接接头正是钢结构成为最高效结构的原因。**

**20 世纪 50 年代** — **胶接**为航空应用而发展，胶接在飞机结构中取代了铆接。**胶接正是胶接接头成为最连续接头的原因，而连续正是胶接接头成为最抗疲劳接头的原因。**

**20 世纪 70 年代** — **螺栓疲劳**经 VDI 2230 标准得到系统研究，该标准提供了螺栓连接的计算方法。**VDI 2230 标准正是螺栓连接按计算而不是按经验设计的原因，而计算正是螺栓连接成为最可预测接头的原因。**

**20 世纪 90 年代** — **摩擦型（预紧）高强度螺栓**成为钢结构桥梁的标准，取代了承压型螺栓连接。**摩擦型螺栓正是螺栓连接抗疲劳的原因，而抗疲劳正是螺栓连接成为桥梁中最可靠接头的原因。**
:::

::: summary 紧固件与接头 {#summary-fasteners}
- **紧固件是最常见的机器元件，接头是决定机器强度、刚度和疲劳寿命的零件。** 接头失效是机械设计中最危险的失效形式。
- **螺栓预紧力是由拧紧扭矩引起的拉力：$T = K d F _ { i }$。** 预紧力正是螺栓在振动下不松动的原因，而预紧力也正是有预紧时螺栓疲劳寿命比无预紧时长 5 倍的原因。
- **连接刚度比 $C = k _ { b } / ( k _ { b } + k _ { m } )$ 决定螺栓与连接之间的载荷分配。** 刚性连接正是刚性连接下螺栓疲劳寿命比柔性连接下长 5 倍的原因。
- **螺栓疲劳是最常见的螺栓失效形式（占螺栓失效的 80–90 %），螺栓疲劳按古德曼图设计。** 预紧力把应力幅降低 80–90 %，而这降低正是有预紧时螺栓疲劳寿命比无预紧时长 5 倍的原因。
- **角焊缝按焊喉厚度 $t = 0 . 7 0 7 \, h$ 而不是焊脚尺寸定尺寸。** 按焊脚尺寸设计角焊缝却不计算焊喉厚度的工程师，不是在焊缝设计，而是在设计一条会因剪切失效的焊缝。
- **焊缝疲劳是最常见的焊缝失效形式（占焊缝失效的 70–80 %），焊缝疲劳按 S-N 曲线设计。** 焊缝质量等级（ISO 5817）正是 B 级焊缝疲劳寿命比 D 级长 5 倍的原因。
- **胶接正是接头成为连续连接的原因，而连续正是胶接接头比铆接接头更强的原因。** 表面处理正确时胶接强度比表面处理错误时高 3 倍。
- **铆接正是接头成为永久连接的原因，而永久正是铆接接头用于飞机、桥梁和压力容器的原因。** 接头效率正是铆接接头不用于高强度场合的原因。
- **扭矩-预紧力分散为 ±25–30 %，而分散正是预紧力必须用转角法或超声波法校核的原因。** 润滑螺纹的扭矩系数 $K$ 为 0.15–0.20，干式螺纹为 0.20–0.30。
- **热膨胀正是螺栓预紧力随温度变化 20–50 % 的原因，而变化正是螺栓连接必须按热载荷而不只是机械载荷设计的原因。** 设计螺栓连接却不校核热膨胀的工程师，不是在接头设计，而是在设计一个会泄漏的接头。
:::
