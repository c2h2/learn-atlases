按一下圆珠笔、关上车门、打开发动机气门或掀起钢琴盖，都有一个螺旋弹簧在工作：它的变形与载荷成正比，把对它所做的功储存为应变能，再把能量释放出来。弹簧把气门压在阀座上、使离合器摩擦片保持夹紧、让踏板和手柄复位、给轴承施加预紧、在缓冲器中吸收冲击，在弹簧秤中称量载荷。它们是机器中应力最高的零件之一——一个好的气门弹簧在超过$500\ \mathrm{MPa}$的切应力下工作数亿次循环——而设计它们所用的是一小套经过充分检验的公式，本章将推导这些公式。

关键的观察很简单。沿轴线拉或压一个螺旋弹簧，簧丝几乎根本没有被拉伸：簧丝的每一个横截面都承受一个**扭矩**$FD/2$，即轴向力乘以弹簧圈的半径。螺旋弹簧就是绕成螺旋线的扭杆。它的刚度来自这根杆的扭转角（[[mechanics-of-materials/torsion]]），它的应力来自扭转切应力公式，再对直接剪切和簧丝曲率加以修正。疲劳（[[machine-design/fatigue]]）决定承受重复载荷的弹簧的寿命，而细长、轻质线圈所特有的两种现象——失稳和颤振（surge）——又规定了另外的限制。

符号：$d$为簧丝直径，$D$为弹簧中径（到簧丝中心线），$C = D/d$为旋绕比（弹簧指数），$N_a$为有效圈数，$G$为切变模量，$F$为轴向力，$y$（或$\delta$）为轴向变形。压缩弹簧中的力以受压为正。

## 螺旋压缩弹簧的几何

::: definition 旋绕比、有效圈数与各种长度 {#def-geometry}
对用直径$d$的圆截面簧丝、以中径$D$绕制的螺旋弹簧：
- **旋绕比**为$C = D/d$；外径为$D + d$，内径为$D - d$；
- **节距**$p$是相邻两圈间的轴向距离，**螺旋升角**$\lambda$满足$\tan\lambda = p/(\pi D)$；
- **总圈数**$N_t$包括端部的圈；**有效圈数**$N_a$是能够自由变形的圈数，$N_t = N_a + N_e$，其中$N_e$为不起作用的端圈数；
- **自由长度**$L_0$是不受载时的长度，**并紧长度**$L_s$是各圈全部接触时的长度；
- **弹簧刚度**为$k = dF/dy$，理想螺旋弹簧的刚度为常数。
:::

端部的形式决定有多少圈不起作用以及长度如何计算。下表列出四种标准端部形式，取自 Budynas 与 Nisbett《Shigley 机械工程设计》（*Shigley's Mechanical Engineering Design*）表 10-1。"并紧"端是把最后一圈以零节距绕制，使其平坦地贴合；"磨平"端还要磨平，去掉端圈的一部分，使弹簧能端正地立在平板上。

| 端部形式 | 端圈数 $N_e$ | 总圈数 $N_t$ | 自由长度 $L_0$ | 并紧长度 $L_s$ |
|---|---|---|---|---|
| 不并紧 | $0$ | $N_a$ | $pN_a + d$ | $d(N_t + 1)$ |
| 不并紧磨平 | $1$ | $N_a + 1$ | $p(N_a + 1)$ | $dN_t$ |
| 并紧 | $2$ | $N_a + 2$ | $pN_a + 3d$ | $d(N_t + 1)$ |
| 并紧磨平 | $2$ | $N_a + 2$ | $pN_a + 2d$ | $dN_t$ |

并紧磨平端是压缩弹簧施加对中良好的力时的常用选择；不并紧端较便宜，但力偏离中心作用，弹簧容易弯曲。这些圈数是理想化的：实际的有效圈数取决于端圈如何贴合，往往要通过测量样件的刚度来确定。

## 变形与弹簧刚度

::: proposition 密圈螺旋弹簧的变形 {#prop-deflection}
螺旋升角很小、簧丝直径$d$、中径$D$、有效圈数$N_a$、用切变模量为$G$的线弹性材料制成的螺旋弹簧，在轴向力$F$作用下的变形为
$$
y = \frac{8FD^3N_a}{Gd^4},
$$ {#eq-deflection}
因此其刚度为
$$
k = \frac{F}{y} = \frac{d^4G}{8D^3N_a}.
$$ {#eq-rate}
若计入簧丝中直接剪力的微小贡献，变形为$y = \dfrac{8FD^3N_a}{Gd^4}\left(1 + \dfrac{1}{2C^2}\right)$。
:::

::: proof
**假设。** 螺旋升角很小（小于约$10°$），因此每一圈几乎位于与弹簧轴线垂直的平面内，簧丝可以看作长度为$L = \pi DN_a$、处于纯扭转的直杆；载荷沿弹簧轴线作用；材料为线弹性；簧丝的平截面保持平面；簧丝的曲率（它会使应力重新分布，见下一节）对整体扭转的影响可以忽略。

**内力。** 在簧丝的任一点处把弹簧截开，保留一端。端部这一段的受力图显示：沿弹簧轴线作用的外力$F$，以及截面上与之平衡的内力——一个剪力$F$（平行于轴线，作用在簧丝中心，距轴线$D/2$）和一个力偶。对簧丝中心取矩得到该力偶：一个绕簧丝自身轴线的扭矩
$$
T = F\frac{D}{2}.
$$
各截面上的扭矩相同，所以簧丝处于均匀扭转。

**扭转角。** 由扭转公式，簧丝的微段$ds$扭转$d\varphi = T\,ds/(GJ)$，其中$J = \pi d^4/32$。沿全部有效簧丝的总扭转角为
$$
\theta = \frac{TL}{GJ} = \frac{(FD/2)(\pi DN_a)}{G\,\pi d^4/32} = \frac{16FD^2N_a}{Gd^4}.
$$

**由扭转角到轴向变形。** 当微段$ds$扭转$d\varphi$时，它以外的整个弹簧绕该微段处簧丝的切线刚性地转过$d\varphi$。螺旋升角很小时，这条切线垂直于弹簧轴线，而载荷作用线到它的距离为$D/2$，因此加载点沿轴线移动$dy = (D/2)\,d\varphi$。把所有微段的贡献相加，
$$
y = \frac{D}{2}\,\theta = \frac{D}{2}\cdot\frac{16FD^2N_a}{Gd^4} = \frac{8FD^3N_a}{Gd^4},
$$
即[[#eq-deflection]]；用$F$除以$y$即得[[#eq-rate]]。

**直接剪切（卡氏定理）。** 用应变能可以得到同样的结果。扭转储存的应变能为$U_T = T^2L/(2GJ)$，横向剪力$F$储存的应变能近似为$U_V = F^2L/(2AG)$，$A = \pi d^2/4$。由卡斯蒂利亚诺（Castigliano）定理（[[solid-mechanics/energy-methods]]），
$$
y = \frac{\partial (U_T + U_V)}{\partial F} = \frac{FD^2L}{4GJ} + \frac{FL}{AG} = \frac{8FD^3N_a}{Gd^4} + \frac{4FDN_a}{Gd^2} = \frac{8FD^3N_a}{Gd^4}\left(1 + \frac{1}{2C^2}\right).
$$
$C = 6$时括号内为$1.014$，所以直接剪切项通常略去。
:::

[[#eq-rate]]的三个特点指导着每一次设计。刚度随$d^4$增大，因此簧丝尺寸的微小变化会使刚度大幅改变；刚度随$D^3$减小；刚度与有效圈数成反比，把一个弹簧截去一半，刚度就加倍。其中的模量是切变模量：弹簧钢约为$79$–$82\ \mathrm{GPa}$（Budynas 与 Nisbett，表 10-5），302 不锈钢为$69\ \mathrm{GPa}$，磷青铜和铍青铜约为$40$–$45\ \mathrm{GPa}$。

弹簧的组合与其他弹性元件相同。**并联**的弹簧（并排，或一个套在另一个里面，如许多发动机的气门弹簧）变形相同，刚度相加：$k = k_1 + k_2$。**串联**的弹簧（首尾相接）受力相同，柔度相加：$1/k = 1/k_1 + 1/k_2$。

::: example 小弹簧的刚度、变形与应力 {#ex-rate}
一个压缩弹簧用$d = 2.5\ \mathrm{mm}$的钢丝以中径$D = 20\ \mathrm{mm}$绕制，有效圈数$N_a = 10$；取$G = 80\ \mathrm{GPa}$。求其刚度以及在$F = 60\ \mathrm{N}$作用下的变形。
::: solution
**刚度。** 以 N 和 mm 为单位（$G = 80\,000\ \mathrm{N/mm^2}$）：
$$
k = \frac{d^4G}{8D^3N_a} = \frac{2.5^4\times80\,000}{8\times20^3\times10} = \frac{39.0625\times80\,000}{640\,000} = 4.883\ \mathrm{N/mm}.
$$
**变形。** $y = F/k = 60/4.883 = 12.29\ \mathrm{mm}$。

**直接剪切修正。** $C = 20/2.5 = 8$，括号内为$1 + 1/128 = 1.008$，$y = 12.38\ \mathrm{mm}$——增加不到 1%，远在$G$和有效圈数的分散范围之内。

**合理性检查。** 若把$d$加倍到$5\ \mathrm{mm}$，刚度将乘以$16$；单位$\mathrm{mm^4\cdot (N/mm^2)/mm^3} = \mathrm{N/mm}$正是刚度的单位。该弹簧的应力在[[#ex-stress]]中计算。
:::
:::

## 簧丝中的应力

扭矩$T = FD/2$在簧丝表面产生熟悉的扭转切应力$16T/(\pi d^3) = 8FD/(\pi d^3)$。有两个效应会改变它。直接剪力$F$附加一个切应力，它在弹簧圈的内侧最大，且在那里与扭转切应力方向相同。而且簧丝是弯曲的：弹簧圈内侧的纤维比外侧的短，因此在相同的扭转角下应变更大。两个效应都使弹簧圈**内侧**表面的应力升高，螺旋弹簧正是在那里开裂的。

::: proposition 计入直接剪切系数的切应力 {#prop-ks}
不计曲率时，承受轴向力$F$的螺旋弹簧簧丝中的最大切应力为
$$
\tau = K_s\frac{8FD}{\pi d^3}, \qquad K_s = 1 + \frac{0.5}{C}.
$$ {#eq-ks}
:::

::: proof
**假设。** 扭矩用直杆扭转理论计算，直接剪力按在横截面上均匀分布处理（这是一种近似；圆截面的精确切应力分布峰值为平均值的$4/3$，这是下面的曲率系数所考虑的部分内容）。

在弹簧圈的内侧表面，扭转切应力$Tr/J$与直接切应力$F/A$方向相同，所以二者相加：
$$
\tau = \frac{T(d/2)}{\pi d^4/32} + \frac{F}{\pi d^2/4} = \frac{8FD}{\pi d^3} + \frac{4F}{\pi d^2} = \frac{8FD}{\pi d^3}\left(1 + \frac{d}{2D}\right) = \frac{8FD}{\pi d^3}\left(1 + \frac{0.5}{C}\right).
$$
:::

曲率修正无法由直杆理论得出。A. M. Wahl 把弯曲的簧丝当作受扭圆环的一部分进行分析，得到一个同时包括直接剪切和曲率的系数；M. Bergsträsser 提出了一个更简单的表达式，在实用范围内与之相差约 1%。二者都是对精确弹性力学解的近似：
$$
K_W = \frac{4C - 1}{4C - 4} + \frac{0.615}{C} \quad \text{（Wahl）}, \qquad K_B = \frac{4C + 2}{4C - 3} \quad \text{（Bergsträsser）},
$$ {#eq-wahl}
弹簧圈内侧表面的最大切应力为
$$
\tau = K_B\frac{8FD}{\pi d^3} \quad (\text{或以 } K_W \text{ 代替 } K_B).
$$ {#eq-tau}
Budynas 与 Nisbett 采用$K_B$；许多弹簧手册以及 EN 13906-1（螺旋压缩弹簧，欧洲标准）采用 Wahl 型或 Bergsträsser 型的系数。比值$K_B/K_s$是纯粹的曲率效应，有时记作$K_c$。

x: 3, 16
y: 1, 1.6

caption: 应力修正系数随旋绕比$C = D/d$的变化。竖线标出常用设计范围$4 \le C \le 12$。$C = 4$时，曲率在直接剪切系数之上再增加约 23%（$K_B = 1.385$，而$K_s = 1.125$）；$C = 12$时只增加约 7%。Wahl 曲线与 Bergsträsser 曲线几乎无法区分——沿曲线向下看到$C = 3$，可以看到它们分开。绕得很紧的弹簧（$C$小）难以制造，且弹簧圈内侧应力很高；绕得很松的弹簧（$C$大）容易缠结和失稳。
:::

::: example 第一个例题中弹簧的应力 {#ex-stress}
对[[#ex-rate]]中的弹簧（$d = 2.5\ \mathrm{mm}$，$D = 20\ \mathrm{mm}$，$C = 8$），在$F = 60\ \mathrm{N}$作用下，比较不加修正、用$K_s$、用$K_W$和用$K_B$所得的应力。
::: solution
未修正的扭转切应力为
$$
\frac{8FD}{\pi d^3} = \frac{8\times60\times20}{\pi\times2.5^3} = \frac{9600}{49.09} = 195.6\ \mathrm{MPa}.
$$
$C = 8$时：$K_s = 1.0625$，$K_W = \tfrac{31}{28} + \tfrac{0.615}{8} = 1.1840$，$K_B = \tfrac{34}{29} = 1.1724$。修正后的应力分别为$207.8$、$231.6$和$229.3\ \mathrm{MPa}$。

**评注。** 忽略曲率会使内侧纤维的应力低估约 10%；两个曲率系数相差 1%。对经过立定处理的静载弹簧，有些设计者只用$K_s$，理由是内侧纤维的局部屈服会使应力重新分布；对疲劳则总是采用完整的系数。
:::
:::

::: warning 弹簧计算中的常见失误
- 把**外径**当作$D$。公式用的是中径$D = OD - d$；$C = 6$时，用外径计算会使变形高估$(7/6)^3 = 1.59$倍。
- 在刚度公式中用**总**圈数。只有有效圈才变形；并紧弹簧的端圈不起作用。
- 两次计入$K_B$：一次在应力中，又一次作为疲劳应力集中系数。曲率系数本身*就是*弹簧的应力集中。
- 忘记$d$在刚度中以四次方、在应力中以三次方出现：簧丝直径$\pm1\%$的公差会使刚度产生约$\pm4\%$的变化。
- 单位混用：力以 N、长度以 mm 计时，应力的单位是$\mathrm{N/mm^2} = \mathrm{MPa}$，$G$必须以 MPa 计。
:::

## 弹簧材料

大多数弹簧用冷拉钢丝制造。钢丝通过一系列逐渐缩小的模具拉拔，产生冷作硬化并使显微组织定向；结果是抗拉强度随钢丝变细而急剧升高。Budynas 与 Nisbett（表 10-4，取自弹簧行业数据）用下式拟合最低抗拉强度：
$$
S_{ut} = \frac{A}{d^m},
$$ {#eq-sut}
其中$d$以 mm 计，$S_{ut}$以 MPa 计。部分常数如下：

| 材料 | 典型用途 | $m$ | $A$（$\mathrm{MPa\cdot mm^m}$） |
|---|---|---|---|
| 琴钢丝（ASTM A228） | 小弹簧用的最好的高碳钢丝 | $0.145$ | $2211$ |
| 油淬回火钢丝（A229） | 通用，较大尺寸 | $0.187$ | $1855$ |
| 硬拉钢丝（A227） | 最便宜，低负荷 | $0.190$ | $1783$ |
| 铬钒钢丝（A232） | 冲击和疲劳载荷 | $0.168$ | $2005$ |
| 铬硅钢丝（A401） | 高应力，气门弹簧 | $0.108$ | $1974$ |

每个拟合式只在规定的直径范围内有效（琴钢丝约为$0.1$–$6.5\ \mathrm{mm}$）；超出范围时应采用供应商的数据。按欧洲标准（EN 10270）规定的弹簧钢丝有类似的强度等级。

弹簧以剪切方式失效，所以设计需要扭转强度。Budynas 与 Nisbett（表 10-6）把压缩弹簧的扭转屈服强度表示为$S_{ut}$的一个分数：
$$
S_{sy} \ge 0.45\,S_{ut} \quad \text{（琴钢丝和冷拉碳钢，未经立定处理）},
$$ {#eq-ssy}
淬火回火碳钢和低合金钢为$0.50\,S_{ut}$，弹簧经过**立定处理**（预压：制成后压缩到超过屈服，留下有利的残余应力并使弹簧略微变短）时为$0.60$–$0.75\,S_{ut}$。疲劳计算中所用的扭转极限强度估计为$S_{su} = 0.67\,S_{ut}$。

## 静载设计

在静载或缓慢变化的载荷下，压缩弹簧必须做到三件事：在工作长度时给出所需的力；即使被压并也不屈服（因为迟早会有人把它压并）；不失稳。

**防碰余量。** 工作变形应在并紧之前停止。Budynas 与 Nisbett 建议**并紧前的相对余量**$\xi \ge 0.15$：从自由状态到并紧的变形至少是最大工作变形的$1.15$倍，使弹簧圈在工作中不相碰。

**并紧时的安全因数。** 并紧长度时的应力$\tau_s = K_B\,8F_sD/(\pi d^3)$，其中$F_s = k(L_0 - L_s)$，应满足$n_s = S_{sy}/\tau_s \ge 1.2$。

**比例。** 同一来源建议$4 \le C \le 12$及$3 \le N_a \le 15$。$C$小于 4 时簧丝难以卷绕，曲率应力高；大于 12 时弹簧在成批搬运中会缠结。圈数太少则端部效应占主导；太多则弹簧容易失稳和颤振。

**失稳。** 在两平板间受压的长压缩弹簧会像压杆一样侧向弯曲。自由长度为$L_0$的弹簧若满足
$$
L_0 < \frac{\pi D}{\alpha}\left[\frac{2(E - G)}{2G + E}\right]^{1/2},
$$ {#eq-buckle}
则为绝对稳定（在任何变形下都不会失稳）；对钢（$E = 207\ \mathrm{GPa}$，$G = 79.3\ \mathrm{GPa}$）即$L_0 < 2.63\,D/\alpha$。端部条件常数$\alpha$：弹簧位于两平行平板之间（固定端）时为$0.5$，一端固定一端铰支时为$0.707$，两端铰支时为$1$，一端夹紧一端自由时为$2$（Budynas 与 Nisbett，§10-7）。这一判据在此引用而不推导：它是把螺旋弹簧当作具有弯曲、剪切和轴向柔度的压杆时的稳定性极限（Haringx 与 Wahl 的理论），常数$2.63$是把钢的数值代入括号得到的：$2(207 - 79.3)/(2\times79.3 + 207) = 0.699$，其平方根为$0.836$，$\pi\times0.836 = 2.63$。结果的形式是压杆的结果：越长越细的弹簧以及越自由的端部（$\alpha$越大，正如[[mechanics-of-materials/buckling]]中欧拉压杆的长度因数）越不稳定。超出极限的弹簧若用内部的导杆或外部的导管导向，仍可使用，代价是摩擦和磨损。

通常的设计步骤是尽可能多地由功能确定各量（力、变形、空间），然后在剩下的自由选择——通常是簧丝直径——上进行搜索。

::: algorithm 螺旋压缩弹簧的静载设计 {#alg-static}
1. 由功能确定最大工作力$F_{\max}$、所需刚度$k$（或两组力–长度数据）和空间：最大外径、最小内径（套在导杆上时）、可用长度。
2. 选择材料和端部形式。选择一个适合空间的试算中径$D$。
3. 对一个试选的标准簧丝直径$d$：计算$C = D/d$、$K_B$，由[[#eq-sut]]求$S_{ut}$，由[[#eq-ssy]]求$S_{sy}$。
4. 由余量确定并紧力$F_s = (1 + \xi)F_{\max}$，由[[#eq-tau]]计算$\tau_s$，并求$n_s = S_{sy}/\tau_s$。
5. 由[[#eq-rate]]计算$N_a = d^4G/(8D^3k)$；圆整到实用值（常圆整到半圈），并重新计算$k$。
6. 计算$N_t$、并紧长度$L_s$、自由长度$L_0 = L_s + (1 + \xi)F_{\max}/k$，并用[[#eq-buckle]]校核失稳。
7. 若$4 \le C \le 12$、$3 \le N_a \le 15$、$n_s \ge 1.2$、弹簧装得下且稳定，则接受设计；否则改变$d$（或$D$）重复。在可接受的设计中按成本、质量或尺寸选择。
:::

::: example 设计一个复位弹簧 {#ex-design}
一个并紧磨平的琴钢丝弹簧在工作变形时必须施加$F_{\max} = 250\ \mathrm{N}$的力，刚度接近$5\ \mathrm{N/mm}$。它在直径$32\ \mathrm{mm}$的孔内、两平行平板之间工作。取$D = 25\ \mathrm{mm}$，$G = 80\ \mathrm{GPa}$，$\xi = 0.15$，并采用[[#alg-static]]的准则。
::: solution
**试算簧丝直径。** $F_s = 1.15\times250 = 287.5\ \mathrm{N}$，对每种簧丝直径：

| $d$（mm） | $C$ | $S_{ut}$（MPa） | $S_{sy}$（MPa） | $\tau_s$（MPa） | $n_s$ | $k = 5$所需$N_a$ |
|---|---|---|---|---|---|---|
| $3.0$ | $8.33$ | $1885$ | $848$ | $790$ | $1.07$ | $10.4$ |
| $3.2$ | $7.81$ | $1868$ | $840$ | $657$ | $1.28$ | $13.4$ |
| $3.5$ | $7.14$ | $1844$ | $830$ | $510$ | $1.63$ | $19.2$ |

$3.0\ \mathrm{mm}$不满足并紧校核；$3.5\ \mathrm{mm}$所需圈数太多。取$d = 3.2\ \mathrm{mm}$。详细计算：$S_{ut} = 2211/3.2^{0.145} = 1868\ \mathrm{MPa}$，$S_{sy} = 0.45\times1868 = 840.5\ \mathrm{MPa}$；$K_B = (4\times7.8125 + 2)/(4\times7.8125 - 3) = 1.177$；
$$
\tau_s = 1.177\times\frac{8\times287.5\times25}{\pi\times3.2^3} = 657\ \mathrm{MPa}, \qquad n_s = \frac{840.5}{657} = 1.28.
$$
**圈数。** $N_a = 3.2^4\times80\,000/(8\times25^3\times5) = 13.4$；取$N_a = 13.5$，得$k = 4.97\ \mathrm{N/mm}$。

**长度。** $N_t = 15.5$，$L_s = dN_t = 3.2\times15.5 = 49.6\ \mathrm{mm}$。工作变形$y_{\max} = 250/4.97 = 50.3\ \mathrm{mm}$，到并紧的变形$1.15\times50.3 = 57.8\ \mathrm{mm}$，因此$L_0 = 49.6 + 57.8 = 107.4\ \mathrm{mm}$。

**失稳。** 两平行平板之间$\alpha = 0.5$：极限$2.63\times25/0.5 = 131.5\ \mathrm{mm} > 107.4\ \mathrm{mm}$，稳定。

**装配。** 外径$25 + 3.2 = 28.2\ \mathrm{mm}$；压缩弹簧受压时直径略有增大，在$32\ \mathrm{mm}$孔中$3.8\ \mathrm{mm}$的直径间隙足够。

**检查。** 所有准则都满足：$C = 7.8$，$N_a = 13.5$，$n_s = 1.28$。弹簧质量约为$67\ \mathrm{g}$（[[#ex-fatigue]]）。较便宜的硬拉钢丝的$A$低 19%，需要更大的直径。

## 弹簧的疲劳

发动机、泵、开关和悬架中的弹簧承受重复载荷，几乎总是在两个压缩力$F_{\min}$与$F_{\max}$之间变化——弹簧从不反向受载。应力幅和平均应力对应的力为
$$
F_a = \frac{F_{\max} - F_{\min}}{2}, \qquad F_m = \frac{F_{\max} + F_{\min}}{2},
$$
由于应力与力成正比，$\tau_a = K_B\,8F_aD/(\pi d^3)$，$\tau_m = K_B\,8F_mD/(\pi d^3)$，二者采用同一系数$K_B$（Budynas 与 Nisbett 的约定）。

弹簧钢丝以成品状态进行试验，因此[[machine-design/fatigue]]中一般的 Marin 修正系数方法被直接的试验数据所取代。Associated Spring 公司的 F. P. Zimmerli 报告（1957 年）：对直径小于约$10\ \mathrm{mm}$的弹簧钢丝，无限寿命的扭转强度基本上与材料和抗拉强度无关。按 Budynas 与 Nisbett 的引用，疲劳强度分量为
$$
\text{未喷丸：} S_{sa} = 241\ \mathrm{MPa},\ S_{sm} = 379\ \mathrm{MPa}; \qquad \text{喷丸：} S_{sa} = 398\ \mathrm{MPa},\ S_{sm} = 534\ \mathrm{MPa}.
$$ {#eq-zimmerli}
每一组数据是$\tau_m$–$\tau_a$疲劳图上的一个点：对未喷丸钢丝，是弹簧能无限次承受的、在$379 - 241 = 138\ \mathrm{MPa}$与$379 + 241 = 620\ \mathrm{MPa}$之间变化的应力循环。修正后的曲率系数已经包含在所测应力中，因此不再施加别的应力集中系数。

为了把这个点用于其他应力比，过该点和平均应力轴上的扭转极限强度$S_{su} = 0.67S_{ut}$画一条失效线。把这条线延长到$\tau_m = 0$，得到对称循环的扭转疲劳强度
$$
S_{se} = \frac{S_{sa}}{1 - S_{sm}/S_{su}} \quad\text{（Goodman）}, \qquad S_{se} = \frac{S_{sa}}{1 - (S_{sm}/S_{su})^2} \quad\text{（Gerber）},
$$ {#eq-sse}
沿过原点的载荷线（两个力都按$n_f$放大）的疲劳安全因数为
$$
\frac{1}{n_f} = \frac{\tau_a}{S_{se}} + \frac{\tau_m}{S_{su}} \quad\text{（Goodman）}, \qquad n_f = \frac12\left(\frac{S_{su}}{\tau_m}\right)^2\frac{\tau_a}{S_{se}}\left[-1 + \sqrt{1 + \left(\frac{2\tau_mS_{se}}{S_{su}\tau_a}\right)^2}\right] \quad\text{（Gerber）}.
$$ {#eq-nf}
Gerber 抛物线与弹簧疲劳数据吻合得更好；Goodman 直线更保守。再对峰值应力作屈服校核$n_y = S_{sy}/(\tau_a + \tau_m)$，分析才算完整。

::: example 复位弹簧的疲劳校核与颤振 {#ex-fatigue}
[[#ex-design]]中设计的弹簧（$d = 3.2\ \mathrm{mm}$，$D = 25\ \mathrm{mm}$，$N_a = 13.5$，$k = 4.97\ \mathrm{N/mm}$，琴钢丝，未喷丸）在$F_{\min} = 100\ \mathrm{N}$与$F_{\max} = 250\ \mathrm{N}$之间工作。分别用 Goodman 和 Gerber 准则求疲劳安全因数，校核$F_{\max}$时的屈服，并求第一阶颤振频率（$\rho = 7850\ \mathrm{kg/m^3}$）。
::: solution
**应力。** $F_a = 75\ \mathrm{N}$，$F_m = 175\ \mathrm{N}$；$K_B = 1.177$，$8D/(\pi d^3) = 8\times25/(\pi\times32.77) = 1.943\ \mathrm{mm^{-2}}$：
$$
\tau_a = 1.177\times1.943\times75 = 171.5\ \mathrm{MPa}, \qquad \tau_m = 1.177\times1.943\times175 = 400.2\ \mathrm{MPa}.
$$
**强度。** $S_{ut} = 1868\ \mathrm{MPa}$，$S_{su} = 0.67\times1868 = 1251\ \mathrm{MPa}$。由[[#eq-sse]]：Goodman $S_{se} = 241/(1 - 379/1251) = 345.7\ \mathrm{MPa}$；Gerber $S_{se} = 241/(1 - 0.3029^2) = 265.3\ \mathrm{MPa}$。

**安全因数。** Goodman：$1/n_f = 171.5/345.7 + 400.2/1251 = 0.496 + 0.320 = 0.816$，$n_f = 1.23$。Gerber：由[[#eq-nf]]，$2\tau_mS_{se}/(S_{su}\tau_a) = 0.990$，$n_f = 1.29$。

**屈服。** $\tau_{\max} = 171.5 + 400.2 = 571.7\ \mathrm{MPa}$，$n_y = 840.5/571.7 = 1.47$。

**颤振。** 有效簧丝质量$m = \rho\,(\pi d^2/4)(\pi DN_a) = 7850\times\tfrac{\pi^2}{4}\times(3.2\times10^{-3})^2\times0.025\times13.5 = 0.0669\ \mathrm{kg}$。两端都抵在平板上，由[[#prop-surge]]得$f_1 = \tfrac12\sqrt{k/m} = \tfrac12\sqrt{4970/0.0669} = 136\ \mathrm{Hz}$。

**判断。** 弹簧将有一定余量地无限期工作（按 Goodman 为$1.23$）。喷丸可把$n_f$提高到约$1.9$。按第一阶颤振频率至少应为工作频率 15–20 倍的规则，弹簧的循环频率可达约$7\ \mathrm{Hz}$（每分钟$400$次）而不发生颤振。
:::

## 颤振

弹簧并不是无质量的刚度：它的各圈有质量，一端的突然运动会以压缩波的形式沿弹簧传播。如果端部运动是周期性的，且其某个谐波与弹簧的某阶固有频率重合，弹簧圈就在两端之间剧烈振动——**颤振**（surge）——端部力发生波动，弹簧圈可能相碰，应力远超静态值。由凸轮以凸轮轴频率的许多谐波驱动的发动机气门弹簧是典型的例子。

::: proposition 螺旋弹簧的固有频率 {#prop-surge}
刚度为$k$、有效质量为$m$且沿长度均匀分布的螺旋弹簧，其固有频率为
$$
f_n = \frac{n}{2}\sqrt{\frac{k}{m}} \quad (n = 1, 2, \dots) \quad\text{两端固定（位于两平板之间）},
$$ {#eq-surge}
一端固定、另一端自由时为$f_n = \dfrac{2n - 1}{4}\sqrt{\dfrac{k}{m}}$。当$k$以 N/m、$m$以 kg 计时，频率单位为赫兹。
:::

::: proof
**假设。** 把弹簧模化为作轴向运动的均匀弹性杆：长度$l$，单位长度质量$m/l$，轴向刚度$EA_\text{eq}$的取法使长度$l$的刚度为$k$，即$EA_\text{eq} = kl$。忽略弹簧圈相碰、阻尼以及有效圈数随变形的变化。

设$u(x, t)$为位置$x$处弹簧圈的轴向位移。短段$dx$的质量为$(m/l)\,dx$，$x$处弹簧中的力为$kl\,\partial u/\partial x$。对该段应用牛顿第二定律得到波动方程
$$
\frac{m}{l}\frac{\partial^2u}{\partial t^2} = kl\frac{\partial^2u}{\partial x^2} \quad\Longrightarrow\quad \frac{\partial^2u}{\partial t^2} = c^2\frac{\partial^2u}{\partial x^2}, \qquad c = l\sqrt{\frac{k}{m}}.
$$
两端固定，$u(0, t) = u(l, t) = 0$，分离变量解为$u = \sin(n\pi x/l)\cos\omega_nt$，$\omega_n = n\pi c/l = n\pi\sqrt{k/m}$，因此$f_n = \omega_n/2\pi = (n/2)\sqrt{k/m}$。一端自由（$x = l$处$\partial u/\partial x = 0$）时，振型为$\sin[(2n - 1)\pi x/2l]$，$f_n = \tfrac{2n - 1}{4}\sqrt{k/m}$。（同样的波动方程和振型也出现在[[vibrations/continuous-systems]]的杆中。）
:::

圆截面簧丝弹簧的有效质量为$m = \rho\,\dfrac{\pi^2d^2DN_a}{4}$。Budynas 与 Nisbett 建议基频至少为外力频率的 15–20 倍，使外力的主要谐波不能激起它。在做不到这一点时（如高速发动机），设计者采用固有频率不同的套装弹簧、各圈逐渐并紧从而在行程中改变频率的变节距（渐进）弹簧，或摩擦阻尼器。

## 拉伸弹簧与扭转弹簧

**拉伸弹簧**是密绕的，相邻各圈互相压紧：弹簧在开始伸长之前已承受一个**初拉力**$F_i$，力–变形关系为$F = F_i + ky$。弹簧体的分析与压缩弹簧完全相同；端部的钩环是薄弱处，那里簧丝既受扭又受弯。设钩环的弯曲半径为$r_1$，$C_1 = 2r_1/d$，钩环内侧的弯曲应力为$\sigma_A = F\left[(K)_A\dfrac{16D}{\pi d^3} + \dfrac{4}{\pi d^2}\right]$，$(K)_A = \dfrac{4C_1^2 - C_1 - 1}{4C_1(C_1 - 1)}$；侧面弯曲处（半径$r_2$，$C_2 = 2r_2/d$）的扭转切应力为$\tau_B = (K)_B\,8FD/(\pi d^3)$，$(K)_B = (4C_2 - 1)/(4C_2 - 4)$（Budynas 与 Nisbett，§10-11）。能够绕制进去的初拉力取决于旋绕比；该书给出的初始扭转切应力的推荐范围为
$$
\tau_i = \frac{231}{e^{0.105C}} \pm 6.9\left(4 - \frac{C - 3}{6.5}\right)\ \mathrm{MPa},
$$
$C = 8$时约为$77$–$122\ \mathrm{MPa}$。拉伸弹簧没有并紧长度来阻止过载，因此在安全功能中（门、制动器）使用的拉伸弹簧一旦断裂，必须有备用装置。

**螺旋扭转弹簧**（如晾衣夹、铰链和拉绳起动器复位中所用）承受绕弹簧轴线的力矩$M$。此时簧丝处于**弯曲**而不是扭转：簧丝各截面上的弯矩相同，因此簧丝是长度为$L = \pi DN_a$、处于纯弯曲的梁。其转角为$\theta = ML/(EI)$，$I = \pi d^4/64$：
$$
\theta = \frac{64MDN_a}{Ed^4}\ \text{rad}, \qquad k' = \frac{M}{\theta} = \frac{d^4E}{64DN_a}.
$$ {#eq-torsion-spring}
Budynas 与 Nisbett 用$10.8\times2\pi = 67.8$代替$64$（每弧度的刚度），以考虑弹簧圈之间以及弹簧与芯轴之间的摩擦，这是测量所显示的。弹簧圈内侧的弯曲应力为$\sigma = K_i\,32M/(\pi d^3)$，$K_i = (4C^2 - C - 1)/[4C(C - 1)]$。扭转弹簧应始终沿使其卷紧（弹簧圈直径减小）的方向加载，因为此时卷绕产生的残余应力在内侧纤维处与工作应力相反。

::: application 气门弹簧与悬架弹簧
汽车发动机的气门弹簧是短而高应力的铬硅钢弹簧，经过喷丸，常做成椭圆截面或"蜂窝"（锥形）形状，以减小运动质量、提高颤振频率；它必须在最高发动机转速下使气门跟随凸轮。汽车的螺旋悬架弹簧则是相反的情形：尺寸大（$d$为$10$–$15\ \mathrm{mm}$），用硅铬钢或类似钢材热卷，经过喷丸和立定处理，常做成变节距或鼓形，以适应空间并得到渐增的刚度。两者都用本章的公式设计，再以实际弹簧的疲劳试验加以验证，因为卷绕、立定和喷丸产生的残余应力控制着它们的寿命。
:::

::: history
胡克（Robert Hooke）在《关于恢复力或弹簧的讲演》（*Lectures de Potentia Restitutiva, or of Spring*，1678 年）中发表了他的弹簧定律 *ut tensio, sic vis*（"伸长如何，力亦如何"），所举的例子中就有卷绕的钢丝弹簧。螺旋弹簧的现代设计方法主要出自西屋公司的 A. M. Wahl，他的曲率修正系数和著作《机械弹簧》（*Mechanical Springs*，1944 年；第二版 1963 年）为设计者提供了本章所用的应力公式。F. P. Zimmerli 于 1957 年报告的弹簧钢丝疲劳试验表明，小直径弹簧钢丝的疲劳强度几乎与其抗拉强度无关，并提供了至今仍被教科书引用的数据。如今螺旋弹簧按 EN 13906（欧洲）等标准以及弹簧行业的设计手册进行设计；本章讲授的是这些标准背后的原理，不能代替它们。
:::

- [x] 在弹簧圈内侧，那里扭转切应力与直接切应力相加，且曲率使应变增大。
- [ ] 在弹簧高度的中部，那里弯曲最大。
- [ ] 在端圈，因为它们不起作用。
::: solution
在内侧纤维处，直接切应力与扭转切应力相加；又因为曲杆内侧的纤维较短，在相同扭转下应变更大。系数$K_B$同时考虑了这两点；裂纹沿与簧丝轴线约成$45°$的方向、即沿最大拉应力平面扩展。
:::
:::

::: summary
- 螺旋弹簧是扭杆：簧丝在长度$\pi DN_a$上承受扭矩$FD/2$；由扭转角得$y = 8FD^3N_a/(Gd^4)$，$k = d^4G/(8D^3N_a)$（[[#prop-deflection]]）。
- 最大切应力在弹簧圈内侧表面：$\tau = K_B\,8FD/(\pi d^3)$，$K_B = (4C + 2)/(4C - 3)$，或采用包括直接剪切和曲率的 Wahl 系数；$K_s = 1 + 0.5/C$只包括直接剪切。
- 钢丝强度与尺寸有关，$S_{ut} = A/d^m$；扭转屈服强度约为$0.45S_{ut}$（未经立定处理），扭转极限强度为$0.67S_{ut}$。
- 静载设计：并紧前余量$\xi \ge 0.15$，并紧时$n_s \ge 1.2$，$4 \le C \le 12$，$3 \le N_a \le 15$，钢弹簧绝对稳定条件$L_0 < 2.63D/\alpha$。
- 疲劳：Zimmerli 疲劳数据（未喷丸$241/379\ \mathrm{MPa}$，喷丸$398/534\ \mathrm{MPa}$），配合通向$S_{su}$的 Goodman 直线或 Gerber 抛物线。
- 颤振：两平板之间$f_1 = \tfrac12\sqrt{k/m}$；使其比外力频率高 15–20 倍。
- 拉伸弹簧：初拉力和钩环应力；扭转弹簧：簧丝处于弯曲，理想刚度$k' = d^4E/(64DN_a)$。
:::

## 习题

::: exercise 弹簧刚度 {level=1 check="7.8125"}
一个压缩弹簧$d = 4\ \mathrm{mm}$，$D = 32\ \mathrm{mm}$，$N_a = 10$，$G = 80\ \mathrm{GPa}$。求其刚度。（以 N/mm 为单位输入刚度。）
::: solution
$k = d^4G/(8D^3N_a) = 256\times80\,000/(8\times32\,768\times10) = 20\,480\,000/2\,621\,440 = 7.8125\ \mathrm{N/mm}$。注意$C = 8$，与[[#ex-rate]]相同：把$d$和$D$同时放大$s$倍，刚度放大$s$倍（此处$1.6\times4.883 = 7.81$）。
:::
:::

::: exercise 曲率系数 {level=1 check="1.2"}
一个弹簧用$3\ \mathrm{mm}$钢丝以$21\ \mathrm{mm}$的中径绕制。求 Bergsträsser 系数$K_B$，再求$F = 100\ \mathrm{N}$时的最大切应力。（输入$K_B$。）
::: solution
$C = 7$，$K_B = (4\times7 + 2)/(4\times7 - 3) = 30/25 = 1.2$。于是$\tau = 1.2\times8\times100\times21/(\pi\times27) = 1.2\times198.1 = 237.7\ \mathrm{MPa}$。Wahl 系数给出$K_W = 27/24 + 0.615/7 = 1.2129$，约高 1%。
:::
:::

::: exercise 串联弹簧 {level=1 check="2"}
刚度分别为$6\ \mathrm{N/mm}$和$3\ \mathrm{N/mm}$的两个压缩弹簧首尾叠放，中间有导向件。求组合后的刚度。（以 N/mm 为单位输入刚度。）
::: solution
串联时力相同、变形相加：$1/k = 1/6 + 1/3 = 1/2$，因此$k = 2\ \mathrm{N/mm}$。若改为套装并排受载，刚度相加为$9\ \mathrm{N/mm}$。
:::
:::

::: exercise 自由长度与并紧长度 {level=2 check="86"}
一个并紧磨平的压缩弹簧$d = 3\ \mathrm{mm}$，$N_a = 10$，节距$8\ \mathrm{mm}$。求自由长度和并紧长度。（以 mm 为单位输入自由长度。）
::: solution
由端部形式表：$L_0 = pN_a + 2d = 80 + 6 = 86\ \mathrm{mm}$；$N_t = N_a + 2 = 12$，$L_s = dN_t = 36\ \mathrm{mm}$。从自由到并紧的变形为$50\ \mathrm{mm}$；取$\xi = 0.15$，最大工作变形为$50/1.15 = 43.5\ \mathrm{mm}$。
:::
:::

::: exercise 失稳极限 {level=2 check="131.5"}
一个中径$25\ \mathrm{mm}$的钢压缩弹簧在两平行平板之间工作。求绝对稳定所允许的最大自由长度。（以 mm 为单位输入长度。）
::: solution
$\alpha = 0.5$，由[[#eq-buckle]]得$L_0 < 2.63\times25/0.5 = 131.5\ \mathrm{mm}$。若一端可以转动（$\alpha = 0.707$），极限降至$93\ \mathrm{mm}$。
:::
:::

::: exercise 颤振频率 {level=2 check="250"}
一个气门弹簧刚度为$10\ \mathrm{N/mm}$，有效质量为$40\ \mathrm{g}$，在气缸盖与气门弹簧座之间工作。求其基本颤振频率。（以 Hz 为单位输入频率。）
::: solution
$k = 10\,000\ \mathrm{N/m}$，$m = 0.040\ \mathrm{kg}$：$f_1 = \tfrac12\sqrt{10\,000/0.04} = \tfrac12\times500 = 250\ \mathrm{Hz}$。按 15–20 倍的规则，外力的基频（凸轮轴每转一次）不应超过约$12.5$–$17\ \mathrm{Hz}$，即凸轮轴转速$750$–$1000\ \mathrm{rpm}$——远低于现代发动机的转速，这就是为什么气门弹簧要按高频设计并加阻尼，以及为什么要控制凸轮型线的谐波。
:::
:::

::: exercise 小弹簧的疲劳 {level=2}
一个琴钢丝弹簧$d = 2.0\ \mathrm{mm}$，$D = 16\ \mathrm{mm}$（未喷丸，并紧磨平），在$20\ \mathrm{N}$与$60\ \mathrm{N}$之间循环。按 Goodman 和 Gerber 准则求疲劳安全因数，并求峰值力下的屈服安全因数。
::: solution
$C = 8$，$K_B = 1.1724$。$F_a = 20\ \mathrm{N}$，$F_m = 40\ \mathrm{N}$；$8D/(\pi d^3) = 128/(8\pi) = 5.093\ \mathrm{mm^{-2}}$，因此$\tau_a = 1.1724\times5.093\times20 = 119.4\ \mathrm{MPa}$，$\tau_m = 238.8\ \mathrm{MPa}$。$S_{ut} = 2211/2^{0.145} = 2000\ \mathrm{MPa}$，$S_{su} = 1340\ \mathrm{MPa}$，$S_{sy} = 900\ \mathrm{MPa}$。

Goodman：$S_{se} = 241/(1 - 379/1340) = 336.1\ \mathrm{MPa}$；$1/n_f = 119.4/336.1 + 238.8/1340 = 0.355 + 0.178 = 0.534$，$n_f = 1.87$。

Gerber：$S_{se} = 241/(1 - 0.2829^2) = 262.0\ \mathrm{MPa}$；$2\tau_mS_{se}/(S_{su}\tau_a) = 0.782$；$n_f = \tfrac12(1340/238.8)^2(119.4/262.0)[-1 + \sqrt{1 + 0.782^2}] = 1.93$。

屈服：$\tau_{\max} = 358.3\ \mathrm{MPa}$，$n_y = 900/358.3 = 2.51$。疲劳起控制作用。
:::
:::

::: exercise 扭转弹簧的转角 {level=2 check="1.5"}
一个螺旋扭转弹簧$d = 2\ \mathrm{mm}$，$D = 20\ \mathrm{mm}$，有效圈数$N_a = 5$，$E = 200\ \mathrm{GPa}$。用理想公式[[#eq-torsion-spring]]（不计摩擦修正），求$750\ \mathrm{N\,mm}$的力矩使它卷紧的角度。（以弧度为单位输入角度。）
::: solution
$\theta = 64MDN_a/(Ed^4) = 64\times750\times20\times5/(200\,000\times16) = 4\,800\,000/3\,200\,000 = 1.5\ \mathrm{rad}$（$86°$）。若用考虑摩擦的常数$67.8$代替$64$，转角为$1.59\ \mathrm{rad}$。弯曲应力：$C = 10$，$K_i = 389/360 = 1.081$，为$1.081\times32\times750/(8\pi) = 1032\ \mathrm{MPa}$，约为$S_{ut} = 2000\ \mathrm{MPa}$的 52%。静载扭转弹簧的弯曲许用应力占$S_{ut}$的比例高于压缩弹簧的扭转许用应力，因为钢丝在弯曲中屈服的应力高于在剪切中屈服的应力。
:::
:::

::: exercise 计入直接剪切的变形 {level=3}
(a) 重复[[#prop-deflection]]中用卡氏定理的推导，但对圆截面横向剪切的应变能采用形状系数$10/9$，$U_V = \tfrac{10}{9}\,F^2L/(2AG)$。(b) 旋绕比为多少时，直接剪切项使变形增加 1%？增加 5% 呢？(c) 说明为什么实践中几乎从不作这项修正，而对*应力*的相应修正（$K_s$）却要作。
::: solution
(a) $y = \partial U/\partial F = 8FD^3N_a/(Gd^4) + \tfrac{10}{9}\cdot 4FDN_a/(Gd^2) = \tfrac{8FD^3N_a}{Gd^4}\left(1 + \tfrac{5}{9C^2}\right)$。
(b) $5/(9C^2) = 0.01$得$C = 7.45$；$= 0.05$得$C = 3.33$——低于实用范围。
(c) 变形是整根簧丝上的平均量，剪切贡献平均下来是$1/C^2$量级的项；应力是局部峰值，直接剪切恰好在扭转切应力最大处附加一个$1/C$量级的项。有效圈数的不确定性（大约$\pm\tfrac14$圈，对 12 圈的弹簧为 2%）和$G$的不确定性已经超过了变形修正。
:::
:::

::: exercise 为安全阀设计弹簧 {level=3}
一个小型泄压阀需要一个弹簧：在$40\ \mathrm{mm}$的安装长度下以$120\ \mathrm{N}$的力使阀芯保持关闭，在阀门全开、再压缩$6\ \mathrm{mm}$时给出$150\ \mathrm{N}$。弹簧套在$14\ \mathrm{mm}$的导杆上，位于$26\ \mathrm{mm}$的孔内；只偶尔循环。选择材料、$d$、$D$、$N_a$、端部形式和自由长度，并校核并紧应力和失稳。讨论对泄压装置还必须考虑什么。
::: solution
**刚度。** $k = (150 - 120)/6 = 5\ \mathrm{N/mm}$；最大工作力$150\ \mathrm{N}$；取$\xi = 0.15$，$F_s = 172.5\ \mathrm{N}$。

**空间。** $D - d > 14$且$D + d < 26$，并留间隙：取$D = 20\ \mathrm{mm}$。

**钢丝。** 琴钢丝，并紧磨平。试$d = 2.5\ \mathrm{mm}$：$C = 8$，$K_B = 1.172$，$\tau_s = 1.172\times8\times172.5\times20/(\pi\times15.625) = 659\ \mathrm{MPa}$；$S_{ut} = 1936$，$S_{sy} = 871\ \mathrm{MPa}$，$n_s = 1.32$——可以接受。$N_a = 2.5^4\times80\,000/(8\times8000\times5) = 9.77$；取$9.75$，$k = 5.01\ \mathrm{N/mm}$。

**长度。** 安装变形$120/5.01 = 24.0\ \mathrm{mm}$，因此$L_0 = 40 + 24.0 = 64.0\ \mathrm{mm}$。$N_t = 11.75$，$L_s = 29.4\ \mathrm{mm}$；全开长度$34\ \mathrm{mm}$，距并紧还有$4.6\ \mathrm{mm}$——余量$\xi = 4.6/30.0 = 0.15$，恰好满足推荐值（良好）。

**失稳。** $2.63\times20/0.5 = 105\ \mathrm{mm} > 64\ \mathrm{mm}$，且导杆增加了安全性。

**其他考虑。** 泄压阀是按压力设备规范（如 ISO 4126 或 ASME 第 VIII 卷的要求）制造和认证的安全装置，其整定压力要经试验验证；弹簧的公差（簧丝直径、圈数、立定）会改变开启压力，所以需要调节手段；腐蚀或温度可能要求采用不锈钢（$G$和$S_{ut}$较低，需重新设计）；还必须限制松弛（在应力下力随时间的损失），这有利于采用经立定处理、工作应力较低的弹簧。
:::
