机械设计者的第一个问题不是“它会断裂吗？”，而是“它何时断裂、如何断裂？”设计过余的零件昂贵、笨重、上市迟缓；设计不足的零件危险、遭召回、吃官司。失效理论就是用单个数字回答“何时”与“如何”的工具：这个数就是**安全因数**，而安全因数是材料强度与所受应力之比。**安全因数不是无知的余地，而是已知的余地：工程师知道载荷、几何和材料，安全因数考虑的是工程师不知道的东西：载荷的波动、材料的分散性、制造缺陷以及失效的后果。**

失效理论分为两大家族：**塑性材料失效理论**（最大切应力理论/特雷斯卡（Tresca）、最大畸变能理论/米泽斯（von Mises）、最大正应力理论）和**脆性材料失效理论**（最大正应力理论、莫尔-库仑（Mohr-Coulomb）理论）。塑性理论预测屈服，即使零件报废的永久变形；脆性理论预测断裂，即把零件变成抛射物的突然分离。**理论的选择不是偏好问题，而是材料塑性的问题：伸长率超过 5 % 的材料是塑性的，伸长率小于 5 % 的材料是脆性的。**

::: warning 静力失效分析出错的九种方式
**用错失效理论。**对灰铸铁（脆性材料）套用米泽斯理论，或对低碳钢（塑性材料）套用最大正应力理论的工程师，并不是保守，而是错误。**塑性材料靠剪切屈服（滑移面滑动），所以失效理论必须是剪切理论（特雷斯卡或米泽斯）。脆性材料靠拉伸断裂（原子键被拉开），所以失效理论必须是正应力理论（最大正应力或莫尔-库仑）。** **忽略应力集中。**在圆角处计算名义应力并直接套用屈服强度的工程师，设计的不是圆角，而是名义截面。**应力集中系数 $K _ { t }$ 把名义应力放大 2–5 倍，而这个放大倍数正是圆角成为机器零件中最常见失效部位的原因。** **对塑性材料用抗拉强度代替屈服强度。**按抗拉强度（而不是屈服强度）设计轴的工程师，设计出的轴会先屈服后断裂，而屈服是使轴报废的永久变形。**对塑性材料，设计准则用的是屈服强度而不是抗拉强度。对脆性材料，设计准则用抗拉强度，因为脆性材料不屈服。** **不考虑多轴应力状态。**把单轴屈服强度与单轴工作应力相比较的工程师，不是在分析零件，而是在瞎猜。**受扭转与弯曲联合作用的轴处于多轴应力状态，多轴应力状态需要米泽斯或特雷斯卡准则，而不是单轴比较。** **不校核挤压应力。**把销钉按剪切强度设计却不校核板上挤压应力的工程师，设计出的销钉会冲穿板。**挤压应力是销钉与板之间的接触压强，挤压应力必须小于材料的压缩屈服强度（脆性材料则用抗压强度）。** **不考虑载荷类型。**把静载屈服强度用于冲击载荷零件的工程师，设计的不是抗冲击结构，而是静力等效结构。**冲击载荷需要动载因数（通常 1.5–3），而动载因数正是冲击载荷零件比静载零件大 50–200 % 的原因。** **不校核挠度。**按强度准则设计零件却不校核挠度的工程师，设计出的零件强而不刚。**刚度准则（最大挠度、最大转角、固有频率）往往是控制性准则，而控制性准则正是零件按刚度而非强度定尺寸的原因。** **不考虑温度。**对工作在 500 °C 的零件使用室温屈服强度的工程师，设计的不是耐高温结构，而是“室温”结构。**500 °C 下的屈服强度只有室温屈服强度的 50–70 %，而这一折减正是高温零件比室温零件大 50–100 % 的原因。** **不记录安全因数的依据。**选定安全因数却不记录理由的工程师，不是在决策，而是在猜测。**安全因数必须连同依据一起记录：载荷的不确定性、材料的分散性、失效的后果以及规范要求，而这些记录正是安全因数在设计评审和法庭上站得住脚的原因。**
:::

## 1. 塑性材料的失效理论

::: definition 安全因数与设计准则 {#def-factor-safety}
**安全因数**（FoS，$n$）是材料强度与所受应力之比：

$$
n \; = \; { \frac { \text{强度} } { \text{应力} } } \; = \; { \frac { S } { \sigma } }
$$

**设计准则**是安全因数必须满足的条件：

$$
n \; \ge \; n _ { \text{设计} }
$$

其中 $n _ { \text{设计} }$ 是设计安全因数，由规范、客户要求或工程师的判断选定。

$$
\begin{array} { l c l }
\textbf{应用场景} & \textbf{典型 } n & \textbf{依据} \\ \hline
\text{飞机结构} & 1 . 2 \text{--} 1 . 5 & \text{重量关键，载荷已知，检验频繁} \\
\text{机器零件} & 1 . 5 \text{--} 2 . 5 & \text{载荷已知，材料稳定} \\
\text{压力容器} & 3 . 5 \text{--} 4 & \text{失效后果严重，ASME 规范} \\
\text{桥梁、建筑} & 2 \text{--} 3 & \text{失效后果严重，载荷不确定} \\
\text{起重机、起重设备} & 4 \text{--} 5 & \text{失效后果致命，动载荷} \\
\text{生物医学植入物} & 2 \text{--} 4 & \text{失效后果致命，材料分散性} \\
\end{array}
$$

**安全因数不是无知的余地，而是已知的余地。选定 $n = 2$ 却不记录依据的工程师并不是保守，而是任意。依据必须回答：载荷的不确定性、材料的分散性、制造缺陷、失效的后果以及规范要求。**
:::

::: definition 最大切应力理论（特雷斯卡） {#def-tresca}
**最大切应力理论**（特雷斯卡、格斯特（Guest），1864 年）认为：当零件中的最大切应力达到单轴拉伸试验中屈服点处的最大切应力时，塑性材料发生屈服：

$$
\tau _ { \max } \; = \; { \frac { \sigma _ { 1 } - \sigma _ { 3 } } { 2 } } \; \ge \; { \frac { S _ { y } } { 2 } } \quad \Longrightarrow \quad \sigma _ { 1 } - \sigma _ { 3 } \; \ge \; S _ { y }
$$

其中 $\sigma _ { 1 }$ 和 $\sigma _ { 3 }$ 是最大和最小主应力。

**特雷斯卡等效应力**为：

$$
\sigma _ { \text{Tresca } } \; = \; \sigma _ { 1 } - \sigma _ { 3 }
$$

**安全因数**为：

$$
n \; = \; { \frac { S _ { y } } { \sigma _ { \text{Tresca } } } } \; = \; { \frac { S _ { y } } { \sigma _ { 1 } - \sigma _ { 3 } } }
$$

**特雷斯卡理论偏于保守：它预测屈服发生的载荷低于米泽斯理论，而这种保守性正是压力容器规范（ASME 规范第八卷）和飞机起落架设计偏爱特雷斯卡理论的原因。**
:::

::: definition 最大畸变能理论（米泽斯） {#def-von-mises}
**最大畸变能理论**（米泽斯、汉基（Hencky）、胡伯（Huber），1913 年）认为：当零件中单位体积的畸变能达到单轴拉伸试验中屈服点处单位体积的畸变能时，塑性材料发生屈服：

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } } } \; \ge \; S _ { y }
$$

对一般三维应力状态：

$$
\sigma _ { \text{vM } } \; = \; { \frac { 1 } { \sqrt { 2 } } } \, { \sqrt { ( \sigma _ { 1 } - \sigma _ { 2 } ) ^ { 2 } + ( \sigma _ { 2 } - \sigma _ { 3 } ) ^ { 2 } + ( \sigma _ { 3 } - \sigma _ { 1 } ) ^ { 2 } } }
$$

**安全因数**为：

$$
n \; = \; { \frac { S _ { y } } { \sigma _ { \text{vM } } } }
$$

**米泽斯理论比特雷斯卡理论更精确：对大多数塑性金属，米泽斯理论预测的屈服与实验数据的偏差在 3 % 以内，而特雷斯卡理论最多偏保守 15 %。米泽斯理论是机械设计中塑性材料的默认失效理论。**
:::

::: definition 特雷斯卡与米泽斯的对比 {#def-tresca-vs-von-mises}
特雷斯卡理论与米泽斯理论在多轴应力下对屈服的预测不同：

$$
\begin{array} { l c c c }
\textbf{应力状态} & \textbf{特雷斯卡 } \sigma _ { \text{eq } } & \textbf{米泽斯 } \sigma _ { \text{eq } } & \textbf{差异} \\ \hline
\text{单轴拉伸 } ( \sigma , 0 , 0 ) & \sigma & \sigma & 0 \ \% \\
\text{纯剪切 } ( 0 , 0 , \tau ) & 2 \tau & { \sqrt { 3 } } \tau = 1 . 7 3 \tau & 1 5 . 5 \ \% \\
\text{等值双轴 } ( \sigma , \sigma , 0 ) & \sigma & \sigma & 0 \ \% \\
\text{纯扭转 } ( 0 , \tau , - \tau ) & 2 \tau & { \sqrt { 3 } } \tau & 1 5 . 5 \ \% \\
\text{弯曲 + 扭转} & \text{变化} & \text{变化} & 0 \text{--} 1 5 . 5 \ \% \\
\end{array}
$$

**特雷斯卡理论与米泽斯理论的最大差异为 15.5 %，出现在纯剪切状态下。这 15.5 % 正是改用特雷斯卡理论代替米泽斯理论的工程师保守 15.5 % 的原因，而这种保守性正是失效后果严重时偏爱特雷斯卡理论的原因。**
:::

::: example 受弯曲与扭转的轴 {#ex-shaft-bending-torsion level=3 check="2"}
某轴承受弯曲应力 $\sigma _ { x } = 8 0$ MPa 和扭转切应力 $\tau _ { x y } = 5 0$ MPa。材料的屈服强度 $S _ { y } = 4 0 0$ MPa。试用特雷斯卡理论和米泽斯理论计算安全因数。

**主应力：**

$$
\sigma _ { 1 , 3 } \; = \; { \frac { \sigma _ { x } } { 2 } } \pm { \sqrt { \left( { \frac { \sigma _ { x } } { 2 } } \right) ^ { 2 } + \tau _ { x y } ^ { 2 } } } \; = \; 4 0 \pm { \sqrt { 1 6 0 0 + 2 5 0 0 } } \; = \; 4 0 \pm 6 4 . 0
$$

$$
\sigma _ { 1 } = 1 0 4 . 0 \ \text{MPa } , \quad \sigma _ { 3 } = - 2 4 . 0 \ \text{MPa}
$$

**特雷斯卡：**

$$
\sigma _ { \text{Tresca } } \; = \; \sigma _ { 1 } - \sigma _ { 3 } \; = \; 1 0 4 . 0 - ( - 2 4 . 0 ) \; = \; 1 2 8 . 0 \ \text{MPa}
$$

$$
n _ { \text{Tresca } } \; = \; { \frac { 4 0 0 } { 1 2 8 . 0 } } \; = \; { \bf 3 . 1 3 }
$$

**米泽斯：**

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { 8 0 ^ { 2 } + 3 \times 5 0 ^ { 2 } } } \; = \; { \sqrt { 6 4 0 0 + 7 5 0 0 } } \; = \; { \sqrt { 1 3 9 0 0 } } \; = \; 1 1 7 . 9 \ \text{MPa}
$$

$$
n _ { \text{vM } } \; = \; { \frac { 4 0 0 } { 1 1 7 . 9 } } \; = \; { \bf 3 . 3 9 }
$$

**米泽斯安全因数（3.39）比特雷斯卡安全因数（3.13）高 8 %，因为米泽斯理论不如特雷斯卡理论保守。这 8 % 正是改用米泽斯理论代替特雷斯卡理论的工程师能节省 8 % 材料的原因，而这一节省正是米泽斯理论成为机械设计默认选择的原因。**
:::

::: example 压力容器 {#ex-pressure-vessel level=3 check="3"}
一薄壁圆柱形压力容器，内半径 $r = 2 0 0$ mm，壁厚 $t = 1 0$ mm，内压 $p = 5$ MPa。材料的屈服强度 $S _ { y } = 3 5 0$ MPa。试计算安全因数。

**环向应力与轴向应力：**

$$
\sigma _ { \theta } \; = \; { \frac { p r } { t } } \; = \; { \frac { 5 \times 2 0 0 } { 1 0 } } \; = \; 1 0 0 \ \text{MPa}
$$

$$
\sigma _ { z } \; = \; { \frac { p r } { 2 t } } \; = \; { \frac { 5 \times 2 0 0 } { 2 \times 1 0 } } \; = \; 5 0 \ \text{MPa}
$$

**主应力：** $\sigma _ { 1 } = 1 0 0$ MPa，$\sigma _ { 2 } = 5 0$ MPa，$\sigma _ { 3 } \approx 0$（内表面处 $\sigma _ { r } \approx - p$，但 $p \ll \sigma _ { \theta }$）。

**特雷斯卡：**

$$
\sigma _ { \text{Tresca } } \; = \; \sigma _ { 1 } - \sigma _ { 3 } \; = \; 1 0 0 - 0 \; = \; 1 0 0 \ \text{MPa}
$$

$$
n _ { \text{Tresca } } \; = \; { \frac { 3 5 0 } { 1 0 0 } } \; = \; { \bf 3 . 5 }
$$

**米泽斯：**

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { 1 0 0 ^ { 2 } - 1 0 0 \times 5 0 + 5 0 ^ { 2 } } } \; = \; { \sqrt { 1 0 0 0 0 - 5 0 0 0 + 2 5 0 0 } } \; = \; { \sqrt { 7 5 0 0 } } \; = \; 8 6 . 6 \ \text{MPa}
$$

$$
n _ { \text{vM } } \; = \; { \frac { 3 5 0 } { 8 6 . 6 } } \; = \; { \bf 4 . 0 4 }
$$

**ASME 压力容器规范要求 $n \ge 3 . 5$（基于抗拉强度而非屈服强度）。特雷斯卡安全因数（3.5）恰好满足 ASME 要求，米泽斯安全因数（4.04）则超过它。ASME 规范采用特雷斯卡理论，因为特雷斯卡理论更保守，而这种保守性正是压力容器安全的原因。**
:::
## 2. 脆性材料的失效理论

::: definition 最大正应力理论 {#def-max-normal-stress}
**最大正应力理论**认为：当零件中的最大正应力达到抗拉强度时，脆性材料发生断裂：

$$
\sigma _ { 1 } \; \ge \; S _ { u t } \quad \text{（拉伸）} \qquad \sigma _ { 3 } \; \le \; - S _ { u c } \quad \text{（压缩）}
$$

其中 $S _ { u t }$ 是抗拉强度，$S _ { u c }$ 是抗压强度。

**最大正应力理论是最简单的失效理论，而这种简单性正是该理论用于断裂由最大拉应力控制的脆性材料（铸铁、混凝土、玻璃、陶瓷）的原因。**
:::

::: definition 莫尔-库仑理论 {#def-mohr-coulomb}
**莫尔-库仑理论**（内摩擦理论）把最大正应力理论推广到抗拉与抗压强度不相等（$S _ { u t } \ne S _ { u c }$）的情形，这正是脆性材料的典型特征：

$$
{ \frac { \sigma _ { 1 } } { S _ { u t } } } - { \frac { \sigma _ { 3 } } { S _ { u c } } } \; \ge \; 1 \quad \text{（当 } \sigma _ { 1 } > 0 \text{，} \sigma _ { 3 } < 0 \text{）}
$$

**安全因数**为：

$$
n \; = \; { \frac { 1 } { { \dfrac { \sigma _ { 1 } } { S _ { u t } } } - { \dfrac { \sigma _ { 3 } } { S _ { u c } } } } }
$$

$$
\begin{array} { l c c }
\textbf{材料} & \textbf{ } S _ { u t } \textbf{（MPa）} & \textbf{ } S _ { u c } \textbf{（MPa）} \\ \hline
\text{铸铁（灰铸铁）} & 2 0 0 & 6 0 0 \\
\text{混凝土（C30）} & 3 & 3 0 \\
\text{花岗岩} & 1 5 & 2 0 0 \\
\text{玻璃} & 4 0 & 1 0 0 0 \\
\text{铝合金（7075-T6）} & 5 0 3 & 5 0 3 \text{（} S _ { u t } \approx S _ { u c } \text{）} \\
\end{array}
$$

**莫尔-库仑理论是 $S _ { u c } \gg S _ { u t }$ 的脆性材料（铸铁、混凝土、岩石）的正确理论。当 $S _ { u t } = S _ { u c }$ 时（塑性材料），该理论退化为最大正应力理论。**
:::

:::

::: example 组合载荷下的脆性材料 {#ex-brittle-combined level=3 check="2"}
某铸铁零件的主应力为 $\sigma _ { 1 } = 6 0$ MPa、$\sigma _ { 3 } = - 2 0$ MPa。材料 $S _ { u t } = 2 0 0$ MPa、$S _ { u c } = 6 0 0$ MPa。试用莫尔-库仑理论计算安全因数。

$$
n \; = \; { \frac { 1 } { { \dfrac { \sigma _ { 1 } } { S _ { u t } } } - { \dfrac { \sigma _ { 3 } } { S _ { u c } } } } } \; = \; { \frac { 1 } { { \dfrac { 6 0 } { 2 0 0 } } - { \dfrac { - 2 0 } { 6 0 0 } } } } \; = \; { \frac { 1 } { 0 . 3 0 + 0 . 0 3 3 } } \; = \; { \frac { 1 } { 0 . 3 3 3 } } \; = \; { \bf 3 . 0 }
$$

**安全因数为 3.0。若工程师采用最大正应力理论（忽略压应力），安全因数将是 $n = 2 0 0 / 6 0 = 3 . 3 3$，高出 11 %。这 11 % 正是对拉压组合载荷下的脆性材料，莫尔-库仑理论比最大正应力理论更精确的原因。**
:::

## 3. 应力集中

::: definition 应力集中系数 {#def-stress-concentration}
**应力集中系数**（$K _ { t }$）是几何不连续处最大局部应力与不存在该不连续时的名义应力之比：

$$
K _ { t } \; = \; { \frac { \sigma _ { \max } } { \sigma _ { \text{nom } } } }
$$

应力集中系数取决于不连续的几何形状（圆角半径、孔径、缺口深度）和载荷类型（轴向、弯曲、扭转）：

$$
\begin{array} { l c c c }
\textbf{不连续形式} & \textbf{载荷} & \textbf{典型 } K _ { t } & \textbf{公式} \\ \hline
\text{板上横向圆孔} & \text{拉伸} & 2 . 5 \text{--} 3 . 0 & K _ { t } \approx 3 - 3 . 1 4 ( d / W ) + \ldots \\
\text{圆角（轴肩）} & \text{弯曲} & 1 . 5 \text{--} 3 . 0 & K _ { t } = f ( r / D , d / D ) \\
\text{圆角（轴肩）} & \text{扭转} & 1 . 2 \text{--} 2 . 0 & K _ { t } = f ( r / D , d / D ) \\
\text{U 形缺口} & \text{拉伸} & 2 . 0 \text{--} 6 . 0 & K _ { t } \approx 1 + 2 ( a / \rho ) ^ { 1 / 2 } \\
\text{螺纹牙底} & \text{拉伸} & 2 . 5 \text{--} 4 . 0 & K _ { t } \approx 3 \text{（尖牙螺纹）} \\
\text{键槽} & \text{扭转} & 1 . 5 \text{--} 2 . 5 & K _ { t } \approx 2 \text{（盘形铣刀加工键槽）} \\
\text{弹性挡圈槽} & \text{弯曲} & 2 . 0 \text{--} 3 . 5 & K _ { t } \approx 2 . 5 \\
\end{array}
$$

**应力集中系数是机械设计中最重要的系数，因为应力集中正是零件在圆角、圆孔、螺纹和键槽处而不是在名义截面处失效的原因。只把名义截面按屈服强度设计却忽略应力集中的工程师，设计出的零件会在不连续处失效。**
:::

::: definition 圆角的应力集中系数 {#def-fillet-kt}
**圆角应力集中系数**是机械设计中最常见的应力集中，因为轴肩、齿根和支架圆角是最常见的几何不连续。

圆角 $K _ { t }$ 是几何比值 $r / d$（圆角半径与小直径之比）和 $D / d$（大直径与小直径之比）的函数：

$$
K _ { t } \; = \; f \! \left( { \frac { r } { d } } , \; { \frac { D } { d } } \right)
$$

$$
\begin{array} { l c c c c }
\textbf{载荷} & \textbf{ } r / d = 0 . 0 2 & \textbf{ } r / d = 0 . 0 5 & \textbf{ } r / d = 0 . 1 & \textbf{ } r / d = 0 . 2 \\ \hline
\text{轴向} & 2 . 5 & 2 . 0 & 1 . 7 & 1 . 5 \\
\text{弯曲} & 2 . 1 & 1 . 7 & 1 . 5 & 1 . 3 \\
\text{扭转} & 1 . 6 & 1 . 4 & 1 . 3 & 1 . 2 \\
\end{array}
$$

**圆角 $K _ { t }$ 随圆角半径增大而减小，而这一减小正是圆角半径成为轴设计中最重要设计参数的原因。把圆角半径从 1 mm 增大到 3 mm 的工程师，把 $K _ { t }$ 从 2.5 降到 1.7，峰值应力降低 32 %，而这一降低正是圆角半径成为轴设计中第一个被优化的参数的原因。**
:::

::: example 轴肩处的应力集中 {#ex-shaft-shoulder level=3 check="3"}
一阶梯轴 $D = 5 0$ mm、$d = 4 0$ mm、$r = 2$ mm。轴承受弯矩 $M = 2 0 0$ N·m。材料 $S _ { y } = 6 0 0$ MPa。试用米泽斯理论计算不计与计入应力集中时的安全因数。

**名义弯曲应力：**

$$
\sigma _ { \text{nom } } \; = \; { \frac { 3 2 M } { \pi d ^ { 3 } } } \; = \; { \frac { 3 2 \times 2 0 0 \times 1 0 ^ { 3 } } { \pi \times 4 0 ^ { 3 } } } \; = \; { \frac { 6 . 4 \times 1 0 ^ { 6 } } { 2 0 1 \ 0 6 2 } } \; = \; 3 1 . 8 \ \text{MPa}
$$

**应力集中系数：** $r / d = 2 / 4 0 = 0 . 0 5$，$D / d = 5 0 / 4 0 = 1 . 2 5$。查表得 $K _ { t } \approx 1 . 7$（弯曲）。

**峰值应力：**

$$
\sigma _ { \max } \; = \; K _ { t } \times \sigma _ { \text{nom } } \; = \; 1 . 7 \times 3 1 . 8 \; = \; 5 4 . 1 \ \text{MPa}
$$

**不计应力集中的安全因数：**

$$
n _ { \text{no } K _ { t } } \; = \; { \frac { 6 0 0 } { 3 1 . 8 } } \; = \; { \bf 1 8 . 9 }
$$

**计入应力集中的安全因数：**

$$
n _ { \text{with } K _ { t } } \; = \; { \frac { 6 0 0 } { 5 4 . 1 } } \; = \; { \bf 1 1 . 1 }
$$

**应力集中把安全因数从 18.9 降到 11.1，降低了 41 %。这 41 % 正是应力集中成为机械设计中最重要因素的原因，而这种重要性正是忽略应力集中的工程师设计出的零件会在圆角处失效的原因。**
:::

## 4. 设计决策与安全因数

::: definition 设计决策：强度还是刚度 {#def-strength-vs-stiffness}
零件按**强度准则**（应力必须小于许用应力）或**刚度准则**（挠度必须小于许用挠度）定尺寸，而哪个准则控制设计取决于应用场景：

$$
\begin{array} { l l l l }
\textbf{应用场景} & \textbf{控制性准则} & \textbf{原因} & \textbf{示例} \\ \hline
\text{轴} & \text{刚度} & \text{挠度影响齿轮啮合、轴承寿命} & \text{挠度} < 0 . 0 5 \ \text{mm} \\
\text{螺栓} & \text{强度} & \text{螺栓以断裂而非变形失效} & \text{应力} < S _ { y } / n \\
\text{弹簧} & \text{刚度} & \text{弹簧就是为变形而设计的} & \text{刚度} = 5 0 0 \ \text{N/mm} \\
\text{支架} & \text{强度} & \text{支架以屈服失效} & \text{应力} < S _ { y } / n \\
\text{机床} & \text{刚度} & \text{挠度影响加工精度} & \text{挠度} < 1 0 \ \mu \text{m} \\
\text{吊钩} & \text{强度} & \text{吊钩以断裂失效} & \text{应力} < S _ { y } / n \\
\end{array}
$$

**当挠度影响功能（齿轮啮合、轴承寿命、加工精度）时，刚度准则控制设计，而功能正是刚度而非强度成为控制性准则的原因。**
:::

::: definition 载荷类型与动载因数 {#def-load-types}
**载荷类型**决定把名义载荷放大的动载因数 $K _ { d }$：

$$
\begin{array} { l c l }
\textbf{载荷类型} & \textbf{ } K _ { d } & \textbf{示例} \\ \hline
\text{静载（缓慢施加）} & 1 . 0 & \text{自重、螺栓预紧力} \\
\text{逐渐施加} & 1 . 0 \text{--} 1 . 5 & \text{机器起动、平稳接合} \\
\text{冲击（突然）} & 1 . 5 \text{--} 3 . 0 & \text{撞击、锤击、碰撞} \\
\text{循环（疲劳）} & \text{疲劳分析} & \text{对称循环弯曲、旋转轴} \\
\text{振动} & \text{动力分析} & \text{共振、不平衡、颤振} \\
\end{array}
$$

**动载因数正是冲击载荷零件比静载零件大 50–200 % 的原因。把静载屈服强度用于冲击载荷零件的工程师，设计的不是抗冲击结构，而是静力等效结构，而静力等效正是零件在第一次冲击下就失效的原因。**
:::

::: example 销接中的挤压应力 {#ex-bearing-stress level=3 check="2"}
一销接的销钉直径 $d = 2 0$ mm，板厚 $t = 1 0$ mm，载荷 $P = 3 0$ kN。销钉材料 $S _ { y } = 4 0 0$ MPa，板材料 $S _ { y } = 2 5 0$ MPa。试计算挤压应力和安全因数。

**挤压面积：**

$$
A _ { b } \; = \; d \times t \; = \; 2 0 \times 1 0 \; = \; 2 0 0 \ \text{mm} ^ { 2 }
$$

**挤压应力：**

$$
\sigma _ { b } \; = \; { \frac { P } { A _ { b } } } \; = \; { \frac { 3 0 \ 0 0 0 } { 2 0 0 } } \; = \; 1 5 0 \ \text{MPa}
$$

**安全因数（板，较弱的材料）：**

$$
n \; = \; { \frac { S _ { y , \text{plate } } } { \sigma _ { b } } } \; = \; { \frac { 2 5 0 } { 1 5 0 } } \; = \; { \bf 1 . 6 7 }
$$

**挤压应力（150 MPa）达到板屈服强度（250 MPa）的 60 %，而安全因数（1.67）低于典型设计因数 2.0。工程师必须增大板厚或销钉直径以满足设计因数。挤压应力正是销接以板被冲穿而非销钉剪断失效的原因。**
:::

## 习题

::: exercise 轴的特雷斯卡与米泽斯对比 {#ex-tresca-von-mises level=3 check="2"}
某轴 $\sigma _ { x } = 1 0 0$ MPa、$\tau _ { x y } = 6 0$ MPa。材料 $S _ { y } = 5 0 0$ MPa。试用特雷斯卡理论和米泽斯理论计算安全因数。

::: solution
**主应力：**

$$
\sigma _ { 1 , 3 } = { \frac { 1 0 0 } { 2 } } \pm { \sqrt { 5 0 ^ { 2 } + 6 0 ^ { 2 } } } = 5 0 \pm { \sqrt { 2 5 0 0 + 3 6 0 0 } } = 5 0 \pm 7 8 . 1
$$

$\sigma _ { 1 } = 1 2 8 . 1$ MPa，$\sigma _ { 3 } = - 2 8 . 1$ MPa。

**特雷斯卡：** $\sigma _ { \text{Tresca } } = 1 2 8 . 1 - ( - 2 8 . 1 ) = 1 5 6 . 2$ MPa。$n = 5 0 0 / 1 5 6 . 2 = { \bf 3 . 2 }$

**米泽斯：** $\sigma _ { \text{vM } } = { \sqrt { 1 0 0 ^ { 2 } + 3 \times 6 0 ^ { 2 } } } = { \sqrt { 1 0 0 0 0 + 1 0 8 0 0 } } = { \sqrt { 2 0 8 0 0 } } = 1 4 4 . 2$ MPa。$n = 5 0 0 / 1 4 4 . 2 = { \bf 3 . 4 7 }$

**米泽斯安全因数（3.47）比特雷斯卡安全因数（3.2）高 8.4 %，因为米泽斯理论不如特雷斯卡理论保守。**
:::
:::

::: exercise 铸铁的莫尔-库仑计算 {#ex-mohr-coulomb level=3 check="2"}
某铸铁零件 $\sigma _ { 1 } = 8 0$ MPa、$\sigma _ { 3 } = - 4 0$ MPa。材料 $S _ { u t } = 2 5 0$ MPa、$S _ { u c } = 7 5 0$ MPa。试用莫尔-库仑理论计算安全因数。

::: solution
$$
n \; = \; { \frac { 1 } { { \dfrac { 8 0 } { 2 5 0 } } - { \dfrac { - 4 0 } { 7 5 0 } } } } \; = \; { \frac { 1 } { 0 . 3 2 + 0 . 0 5 3 3 } } \; = \; { \frac { 1 } { 0 . 3 7 3 3 } } \; = \; { \bf 2 . 6 8 }
$$

**安全因数为 2.68。莫尔-库仑理论比最大正应力理论（$n = 2 5 0 / 8 0 = 3 . 1 3$）保守 11 %，因为莫尔-库仑理论考虑了压应力。**
:::
:::

::: exercise 圆角处的应力集中 {#ex-fillet-kt level=3 check="3"}
一阶梯轴 $D = 6 0$ mm、$d = 4 0$ mm、$r = 3$ mm。轴承受扭矩 $T = 5 0 0$ N·m。材料 $S _ { y } = 5 0 0$ MPa。试用计入应力集中的米泽斯理论计算安全因数。

::: solution
**名义扭转切应力：**

$$
\tau _ { \text{nom } } \; = \; { \frac { 1 6 T } { \pi d ^ { 3 } } } \; = \; { \frac { 1 6 \times 5 0 0 \times 1 0 ^ { 3 } } { \pi \times 4 0 ^ { 3 } } } \; = \; { \frac { 8 \times 1 0 ^ { 6 } } { 2 0 1 \ 0 6 2 } } \; = \; 3 9 . 8 \ \text{MPa}
$$

**应力集中系数：** $r / d = 3 / 4 0 = 0 . 0 7 5$，$D / d = 6 0 / 4 0 = 1 . 5$。查表得 $K _ { t } \approx 1 . 3$（扭转）。

**峰值切应力：** $\tau _ { \max } = 1 . 3 \times 3 9 . 8 = 5 1 . 7$ MPa。

**米泽斯（纯剪切）：** $\sigma _ { \text{vM } } = { \sqrt { 3 } } \times \tau _ { \max } = 1 . 7 3 2 \times 5 1 . 7 = 8 9 . 6$ MPa。

$$
n \; = \; { \frac { 5 0 0 } { 8 9 . 6 } } \; = \; { \bf 5 . 6 }
$$

**安全因数为 5.6。不计应力集中时 $n = 5 0 0 / ( { \sqrt { 3 } } \times 3 9 . 8 ) = 7 . 2 5$。应力集中使安全因数降低 23 %。**
:::
:::

::: exercise 螺栓连接的挤压应力 {#ex-bearing-bolt level=3 check="2"}
一螺栓连接的螺栓直径 $d = 1 6$ mm，板厚 $t = 1 2$ mm，预紧力 $F = 4 0$ kN。板材料 $S _ { y } = 3 0 0$ MPa。试计算挤压应力和安全因数。

::: solution
$$
A _ { b } \; = \; d \times t \; = \; 1 6 \times 1 2 \; = \; 1 9 2 \ \text{mm} ^ { 2 }
$$

$$
\sigma _ { b } \; = \; { \frac { F } { A _ { b } } } \; = \; { \frac { 4 0 \ 0 0 0 } { 1 9 2 } } \; = \; 2 0 8 . 3 \ \text{MPa}
$$

$$
n \; = \; { \frac { 3 0 0 } { 2 0 8 . 3 } } \; = \; { \bf 1 . 4 4 }
$$

**安全因数（1.44）低于典型设计因数 2.0。工程师必须增大板厚或螺栓直径以满足设计因数。**
:::
:::

::: exercise 带孔的压力容器 {#ex-vessel-hole level=3 check="2"}
一薄壁压力容器 $r = 3 0 0$ mm、$t = 1 2$ mm、$p = 4$ MPa，壁上有一个横向圆孔，$d / W = 0 . 1$。材料 $S _ { y } = 4 0 0$ MPa。试用计入应力集中（$K _ { t } = 2 . 5$）的米泽斯理论计算安全因数。

::: solution
**环向应力：** $\sigma _ { \theta } = p r / t = 4 \times 3 0 0 / 1 2 = 1 0 0$ MPa。

**孔边峰值环向应力：** $\sigma _ { \max } = K _ { t } \times \sigma _ { \theta } = 2 . 5 \times 1 0 0 = 2 5 0$ MPa。

**米泽斯（双轴，$\sigma _ { 1 } = 2 5 0$，$\sigma _ { 2 } = 5 0$）：**

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { 2 5 0 ^ { 2 } - 2 5 0 \times 5 0 + 5 0 ^ { 2 } } } \; = \; { \sqrt { 6 2 5 0 0 - 1 2 5 0 0 + 2 5 0 0 } } \; = \; { \sqrt { 5 2 5 0 0 } } \; = \; 2 2 9 . 1 \ \text{MPa}
$$

$$
n \; = \; { \frac { 4 0 0 } { 2 2 9 . 1 } } \; = \; { \bf 1 . 7 5 }
$$

**安全因数（1.75）低于 ASME 要求的 3.5。圆孔正是压力容器在接管处而非壳体处失效的原因。**
:::
:::
::: exercise 动载因数 {#ex-dynamic-load level=3 check="3"}
一支架承受静载荷 10 kN 和冲击载荷 25 kN。支架按静载荷设计，取 $n = 2$。若动载因数 $K _ { d } = 2 . 5$，冲击载荷下的安全因数是多少？

::: solution
**静载设计：** $\sigma _ { \text{allow } } = S _ { y } / 2$。

**冲击应力：** $\sigma _ { \text{shock } } = K _ { d } \times \sigma _ { \text{static } } = 2 . 5 \times \sigma _ { \text{static } }$。

**冲击下的安全因数：**

$$
n _ { \text{shock } } \; = \; { \frac { S _ { y } } { \sigma _ { \text{shock } } } } \; = \; { \frac { S _ { y } } { 2 . 5 \times \sigma _ { \text{static } } } } \; = \; { \frac { n _ { \text{static } } } { 2 . 5 } } \; = \; { \frac { 2 } { 2 . 5 } } \; = \; { \bf 0 . 8 }
$$

**冲击载荷下的安全因数为 0.8，低于 1.0。支架在冲击载荷下屈服。工程师必须把支架截面增大 125 %（或用减振器降低动载因数），才能满足 2.0 的设计因数。**
:::
:::

::: exercise 推导：由畸变能导出米泽斯准则 {#ex-derive-von-mises level=4 check="3"}
证明：米泽斯等效应力 $\sigma _ { \text{vM } } = { \sqrt { \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } } }$ 可由畸变能 $U _ { d } = ( 1 + \nu ) / ( 3 E ) \times ( \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } )$ 令 $U _ { d }$ 等于单轴拉伸屈服点处的畸变能导出。

::: solution
单位体积的总应变能为：

$$
U \; = \; { \frac { 1 } { 2 E } } \left[ \sigma _ { x } ^ { 2 } + \sigma _ { y } ^ { 2 } - 2 \nu \sigma _ { x } \sigma _ { y } + 2 ( 1 + \nu ) \tau _ { x y } ^ { 2 } \right]
$$

体积改变（体变）应变能为：

$$
U _ { v } \; = \; { \frac { ( 1 - 2 \nu ) } { 6 E } } ( \sigma _ { x } + \sigma _ { y } ) ^ { 2 }
$$

畸变能为 $U _ { d } = U - U _ { v }$：

$$
U _ { d } \; = \; { \frac { 1 + \nu } { 3 E } } \left( \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } \right)
$$

单轴拉伸屈服点处（$\sigma _ { x } = S _ { y }$，$\sigma _ { y } = 0$，$\tau _ { x y } = 0$）：

$$
U _ { d , \text{yield } } \; = \; { \frac { 1 + \nu } { 3 E } } S _ { y } ^ { 2 }
$$

令 $U _ { d } = U _ { d , \text{yield } }$：

$$
{ \frac { 1 + \nu } { 3 E } } \left( \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } \right) \; = \; { \frac { 1 + \nu } { 3 E } } S _ { y } ^ { 2 }
$$

$$
\sigma _ { \text{vM } } \; = \; { \sqrt { \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } } } \; = \; S _ { y } \qquad \blacksquare
$$

**米泽斯准则就是畸变能准则，而畸变能正是对塑性材料米泽斯准则比特雷斯卡准则更精确的原因。**
:::
:::

::: exercise 推导：由最大切应力导出特雷斯卡准则 {#ex-derive-tresca level=4 check="2"}
证明：特雷斯卡准则 $\sigma _ { 1 } - \sigma _ { 3 } = S _ { y }$ 可由最大切应力 $\tau _ { \max } = ( \sigma _ { 1 } - \sigma _ { 3 } ) / 2$ 令 $\tau _ { \max }$ 等于单轴拉伸屈服点处的最大切应力导出。并对 $\sigma _ { 1 } = 1 2 0$ MPa、$\sigma _ { 3 } = - 3 0$ MPa、$S _ { y } = 4 5 0$ MPa 计算特雷斯卡安全因数。

::: solution
单轴拉伸试验在屈服点处 $\sigma _ { 1 } = S _ { y }$、$\sigma _ { 3 } = 0$，所以：

$$
\tau _ { \max , \text{yield } } \; = \; { \frac { S _ { y } - 0 } { 2 } } \; = \; { \frac { S _ { y } } { 2 } }
$$

特雷斯卡准则认为材料在下列条件下屈服：

$$
\tau _ { \max } \; = \; { \frac { \sigma _ { 1 } - \sigma _ { 3 } } { 2 } } \; \ge \; { \frac { S _ { y } } { 2 } } \quad \Longrightarrow \quad \sigma _ { 1 } - \sigma _ { 3 } \; \ge \; S _ { y }
$$

对 $\sigma _ { 1 } = 1 2 0$ MPa、$\sigma _ { 3 } = - 3 0$ MPa、$S _ { y } = 4 5 0$ MPa：

$$
n \; = \; { \frac { S _ { y } } { \sigma _ { 1 } - \sigma _ { 3 } } } \; = \; { \frac { 4 5 0 } { 1 2 0 - ( - 3 0 ) } } \; = \; { \frac { 450}{150} } \; = \; { \bf 3 . 0 }
$$

**特雷斯卡安全因数为 3.0。特雷斯卡准则就是最大切应力准则，而最大切应力正是特雷斯卡准则比米泽斯准则更保守的原因。** $\blacksquare$
:::

- [x] 最大畸变能理论（米泽斯）

## 本讲的去向

- **[[mechanics-of-materials/stress-transformation]]** —— 主应力和最大切应力是各失效理论的输入。
- **[[mechanics-of-materials/stress-transformation|屈服准则]]** —— 屈服准则是塑性材料失效理论的基础。
- **[[machine-design/fatigue]]** —— 应力集中系数是疲劳设计中最主要的因素，因为疲劳裂纹在应力集中处萌生。
- **[[machine-design/shafts]]** —— 轴按米泽斯准则定尺寸，并计入键槽和轴肩圆角处的应力集中。
- **[[machine-design/fasteners-joints]]** —— 螺栓按最大正应力理论定尺寸（螺栓是塑性的，但螺纹牙底是应力集中源）。
- **[[machine-design/bearings]]** —— 轴承按接触应力（赫兹压强）而非米泽斯应力定尺寸。
- **[[solid-mechanics/fracture-mechanics]]** —— 当裂纹存在时，断裂力学评估取代失效理论。
- **[[finite-element-method/direct-stiffness]]** —— 有限元计算不连续处的应力，取代 $K _ { t }$ 的手算。

::: history 静力失效理论：从库仑到米泽斯 {#history-static-failure}
**1773** —— **库仑（Charles-Augustin de Coulomb）**提出失效的内摩擦理论，把剪切强度与正应力联系起来：$\tau = c + \sigma \tan \phi$。**库仑理论是莫尔-库仑失效准则的基础，而这一基础正是莫尔-库仑理论用于土、岩石和混凝土的原因。**

**1864** —— **特雷斯卡（Henri Tresca）**基于他对金属板冲孔的实验提出最大切应力屈服理论。特雷斯卡观察到材料在最大切应力达到临界值时屈服。**特雷斯卡理论是第一个定量屈服准则，而这一准则正是压力容器规范（ASME 规范第八卷）采用特雷斯卡理论的原因。**

**1882** —— **莫尔（Christian Otto Mohr）**建立了应力状态的图形表示（莫尔圆）和失效包络线，把库仑理论推广到一般二维应力状态。**莫尔圆是机械设计中最重要的图形工具，而这一工具正是工程师能在一张纸上把多轴应力状态可视化出来的原因。**

**1913** —— **米泽斯（Richard von Mises）**基于材料在单位体积畸变能达到临界值时屈服的思想提出最大畸变能屈服理论。**米泽斯理论对塑性金属是最精确的屈服准则，而这种精确性正是米泽斯理论成为机械设计默认选择的原因。**

**1920** —— **格里菲斯（A.A. Griffith）**提出脆性断裂的能量平衡理论，解释了玻璃的断裂强度为何比理论强度低 100 倍。**格里菲斯理论是断裂力学的基础，而这一基础正是工程师必须考虑裂纹而不仅是应力的原因。**

**1950** —— **ASME 锅炉及压力容器规范**采用最大切应力理论（特雷斯卡）作为压力容器的设计准则，因为特雷斯卡理论比米泽斯理论更保守。**ASME 规范正是特雷斯卡理论成为压力容器法定要求的原因，而这一法定要求正是工程师必须同时掌握两种理论的原因。**

**1960** —— **R.E. 彼得森（R.E. Peterson）**在《Stress Concentration Design Factors》（Wiley）中给出了应力集中系数的表格，这是第一部机器零件 $K _ { t }$ 数据的系统汇编。**彼得森的著作正是工程师无需有限元分析就能计算圆角、圆孔和螺纹处峰值应力的原因。**
:::

::: summary 静力失效 {#summary-static-failure}
- **安全因数是材料强度与所受应力之比，安全因数是已知的余地而非无知的余地。**依据必须回答载荷的不确定性、材料的分散性、制造缺陷、失效的后果以及规范要求。
- **特雷斯卡（最大切应力）理论偏保守，用于压力容器规范。**特雷斯卡准则为 $\sigma _ { 1 } - \sigma _ { 3 } \ge S _ { y }$。
- **米泽斯（最大畸变能）理论更精确，是塑性材料的默认选择。**米泽斯准则为 $\sigma _ { \text{vM } } = { \sqrt { \sigma _ { x } ^ { 2 } - \sigma _ { x } \sigma _ { y } + \sigma _ { y } ^ { 2 } + 3 \tau _ { x y } ^ { 2 } } } \ge S _ { y }$。
- **特雷斯卡理论与米泽斯理论的最大差异为 15.5 %，出现在纯剪切状态下。**特雷斯卡理论更保守，而这种保守性正是失效后果严重时偏爱特雷斯卡理论的原因。
- **最大正应力理论用于 $S _ { u t } \approx S _ { u c }$ 的脆性材料。**莫尔-库仑理论用于 $S _ { u c } \gg S _ { u t }$ 的脆性材料（铸铁、混凝土、岩石）。
- **在圆角、圆孔、螺纹和键槽处，应力集中系数 $K _ { t }$ 把名义应力放大 2–5 倍。**应力集中正是零件在不连续处而非名义截面处失效的原因。
- **圆角半径是轴设计中最重要的设计参数。**把圆角半径从 1 mm 增大到 3 mm，$K _ { t }$ 从 2.5 降到 1.7，峰值应力降低 32 %。
- **当挠度影响功能（齿轮啮合、轴承寿命、加工精度）时，刚度准则控制设计。**当零件以断裂失效（螺栓、吊钩）时，强度准则控制设计。
- **冲击载荷下动载因数 $K _ { d }$ 把名义载荷放大 1.5–3 倍。**冲击载荷零件比静载零件大 50–200 %。
- **挤压应力是销钉与板之间的接触压强，挤压应力必须小于材料的压缩屈服强度。**销接以板被冲穿而非销钉剪断失效。
:::
