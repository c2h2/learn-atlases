大多数在使用中断裂的机器零件，并不是因为某一次载荷超过了它们的强度而断裂的。它们断裂，是因为一个远低于屈服强度的适中载荷被施加了数百万次。车轴、曲轴、连杆、螺栓、弹簧、齿轮轮齿、涡轮叶片和焊接支架都以这种方式失效，几乎没有可见的变形，而且往往没有预兆。这种现象就是**疲劳**，防止疲劳是机械设计的核心任务：[[machine-design/static-failure]]中的静强度失效理论决定零件能否承受第一次加载，疲劳则决定它能否活过整个寿命。

疲劳失效分为三个阶段。裂纹在局部应力很高的点——圆角根部、键槽、加工刀痕、夹杂物、腐蚀坑——由少数晶粒中的循环滑移而**萌生**。然后它每一循环**扩展**一点，方向垂直于最大拉应力，并在断口上留下记录载荷停顿和变化的"海滩纹"。最后剩余截面太小，承受不了峰值载荷而突然**断裂**。这些阶段的冶金学见[[materials-science/failure]]，裂纹扩展的力学见[[solid-mechanics/fracture-mechanics]]。本章讲授用来确定大多数机器零件尺寸的工程方法：**应力–寿命**法，它由应力幅预测失效前的循环次数，并对实际零件和平均应力加以修正。

符号沿用 Budynas 与 Nisbett《Shigley 机械工程设计》（*Shigley's Mechanical Engineering Design*，第 11 版）：$S$表示强度，$\sigma$和$\tau$表示应力，$n$表示安全因数，$N$表示失效前的循环次数。

## 应力循环的描述

::: definition 变应力 {#def-cycle}
在$\sigma_{\max}$与$\sigma_{\min}$之间周期变化的应力，用以下各量描述：
$$
\text{应力幅}\ \ \sigma_a = \frac{\sigma_{\max} - \sigma_{\min}}{2}, \qquad \text{平均应力}\ \ \sigma_m = \frac{\sigma_{\max} + \sigma_{\min}}{2},
$$ {#eq-cycle}
**应力范围**$\Delta\sigma = 2\sigma_a$，**应力比**$R = \sigma_{\min}/\sigma_{\max}$。**对称循环**$\sigma_m = 0$，$R = -1$；**脉动循环**（从零到最大）$\sigma_{\min} = 0$，$R = 0$，$\sigma_a = \sigma_m$。
:::

一阶近似下，疲劳寿命取决于循环的应力幅和平均应力，而与波形形状无关，（对室温下、通常频率下的金属）也与频率无关。应力幅驱动裂纹扩展；拉伸平均应力使裂纹张开、缩短寿命，压缩平均应力则延长寿命。

在恒定弯矩下转动的轴是典型的对称循环：表面上的每一点每转一圈交替经过受拉侧和受压侧各一次。这正是 R. R. Moore **旋转弯曲试验**的加载方式：把直径约$7.6\ \mathrm{mm}$的抛光试样在恒定弯矩下转动，直到断裂或达到$10^7$次以上循环。大多数公开的疲劳数据来自这种试验。

## 应力–寿命（S–N）曲线

以试样失效时的应力幅对循环次数$N$作图，取对数坐标，得到**S–N 曲线**（Wöhler 曲线）。钢的曲线可以看到三个区域。约$10^3$次循环以下，强度从抗拉强度缓慢下降（低周疲劳，塑性应变起主导作用，用应变–寿命法更好）。$10^3$到约$10^6$次循环之间，数据在双对数坐标上接近一条直线（高周疲劳）。约$10^6$–$10^7$次循环以后，大多数钢和钛合金的曲线变平，出现一个**拐点**：低于某个应力幅——**疲劳极限**——试样似乎可以无限期地工作。铝、铜和镁合金没有这样的拐点，它们的强度按规定寿命给出，常为$5\times10^8$次循环。

::: definition 疲劳极限与疲劳强度 {#def-endurance}
**疲劳极限**$S_e'$是这样一个对称循环应力幅：抛光的实验室试样在此应力幅以下无论经受多少次循环都不失效。$N$次循环时的**疲劳强度**$S_f'$是在$N$次循环时引起失效的对称循环应力幅。带撇号的量表示标准试样的性能；不带撇号的$S_e$和$S_f$是经过下文修正后的实际零件的值。
:::

对钢而言，旋转弯曲数据对抗拉强度作图虽然分散很大，但遵循一个趋势，Budynas 与 Nisbett（式 6-8）将其概括为
$$
S_e' = \begin{cases} 0.5\,S_{ut}, & S_{ut} \le 1400\ \mathrm{MPa}, \\ 700\ \mathrm{MPa}, & S_{ut} > 1400\ \mathrm{MPa}. \end{cases}
$$ {#eq-se-prime}
数据中这个比值在约$0.4$与$0.6$之间变化；这个估计用于没有试验数据的场合。强度很高的钢的疲劳极限不按比例增加，因为它们的失效从夹杂物处开始，而且对表面缺陷更敏感。

::: proposition 高周 S–N 直线 {#prop-basquin}
若 S–N 曲线在双对数坐标上是一条通过点$(10^3,\ fS_{ut})$和$(10^6,\ S_e)$的直线，则当$10^3 \le N \le 10^6$时
$$
S_f = a\,N^b, \qquad a = \frac{(fS_{ut})^2}{S_e}, \qquad b = -\frac13\log_{10}\frac{fS_{ut}}{S_e},
$$ {#eq-basquin}
在此范围内，对称循环应力幅$\sigma_\text{rev}$下的寿命为$N = (\sigma_\text{rev}/a)^{1/b}$。
:::

::: proof
**假设。** 幂律$S_f = aN^b$（Basquin 关系）在$10^3$与$10^6$次循环之间成立；$10^3$次循环时的强度为$S_{ut}$的分数$f$；拐点在$10^6$次循环处。

取对数，$\log S_f = \log a + b\log N$，是一条直线。通过两点：$\log(fS_{ut}) = \log a + 3b$，$\log S_e = \log a + 6b$。相减得$3b = \log S_e - \log(fS_{ut})$，故$b = -\tfrac13\log(fS_{ut}/S_e)$。于是$\log a = \log(fS_{ut}) - 3b = \log(fS_{ut}) + \log(fS_{ut}/S_e) = \log[(fS_{ut})^2/S_e]$。把$\sigma_\text{rev} = aN^b$反解即得寿命。
:::

**疲劳强度分数**$f$是$10^3$次循环时的强度与$S_{ut}$之比。Budynas 与 Nisbett 以图的形式给出它（其图 6-18）：$S_{ut}$约在$490\ \mathrm{MPa}$以下时$f = 0.9$，在$1400\ \mathrm{MPa}$附近降到约$0.75$。本章除另有说明外取$f = 0.9$。注意[[#eq-basquin]]中的$S_e$是**零件**的疲劳极限，因此应用下文的修正后，整条直线都会下移。

::: example 抛光试样的寿命 {#ex-sn}
某钢$S_{ut} = 700\ \mathrm{MPa}$。估计抛光旋转弯曲试样的 S–N 直线、$10^5$次循环时的疲劳强度，以及对称循环应力幅$450\ \mathrm{MPa}$下的寿命。
::: solution
**疲劳极限。** $S_e' = 0.5\times700 = 350\ \mathrm{MPa}$。取$f = 0.9$，$fS_{ut} = 630\ \mathrm{MPa}$。

**常数。** $a = 630^2/350 = 1134\ \mathrm{MPa}$，$b = -\tfrac13\log_{10}(630/350) = -\tfrac13\times0.2553 = -0.0851$。

**$10^5$次循环时的强度。** $S_f = 1134\times(10^5)^{-0.0851} = 1134\times0.3755 = 426\ \mathrm{MPa}$。

**$450\ \mathrm{MPa}$下的寿命。** $N = (450/1134)^{1/(-0.0851)} = (0.3968)^{-11.75} = 5.2\times10^4$次循环。

**合理性检查。** $426\ \mathrm{MPa}$位于$630$与$350$之间、在对数刻度上约下降了三分之二，正如$10^5$在对数上位于$10^3$到$10^6$之间三分之二处。应力只比$426\ \mathrm{MPa}$高 6%，寿命就减半：寿命对应力非常敏感，这就是疲劳寿命只给出一位有效数字的原因。
:::
:::

## 从试样到零件：Marin 系数

实际零件与$7.6\ \mathrm{mm}$的抛光试样在表面、尺寸、载荷类型、温度和所要求的可靠度上都不同。按照 J. Marin（1962 年）的做法，这些差别以乘数的形式作用在试样疲劳极限上：
$$
S_e = k_a\,k_b\,k_c\,k_d\,k_e\,k_f\,S_e'.
$$ {#eq-marin}
下面各系数是 Budynas 与 Nisbett（§6-9）给出的经验拟合式；每一个都是分散数据的统计平均，只在没有实际零件试验时使用。

**表面系数**$k_a = a\,S_{ut}^{\,b}$（$S_{ut}$以 MPa 计）。粗糙表面布满小缺口，而且由于高强度钢对缺口更敏感，这一影响随强度增加：

| 表面加工 | $a$（MPa） | $b$ |
|---|---|---|
| 磨削 | $1.58$ | $-0.085$ |
| 切削加工或冷拉 | $4.51$ | $-0.265$ |
| 热轧 | $57.7$ | $-0.718$ |
| 锻后未加工 | $272$ | $-0.995$ |

**尺寸系数**$k_b$。在弯曲和扭转中，截面越大，高应力材料的体积越大，因而越可能存在薄弱点。对旋转弯曲或扭转下的圆棒，
$$
k_b = 1.24\,d^{-0.107}\ \ (2.79 \le d \le 51\ \mathrm{mm}), \qquad k_b = 1.51\,d^{-0.157}\ \ (51 < d \le 254\ \mathrm{mm}),
$$ {#eq-kb}
$d$以 mm 计；不旋转的截面和非圆截面采用当量直径。轴向加载没有应力梯度，$k_b = 1$。

**载荷系数**$k_c$：弯曲为$1$，轴向加载为$0.85$，扭转为$0.59$。如本章后面那样，扭转与其他应力通过米泽斯（von Mises）应力合成时取$k_c = 1$，因为米泽斯换算已经考虑了剪切强度与正应力强度的差别。

**温度系数**$k_d$：室温附近为$1$；高温下疲劳极限随抗拉强度下降，在约一半绝对熔点温度以上必须考虑蠕变。

**可靠度系数**$k_e$。疲劳极限的分散，其标准差约为平均值的 8%。[[#eq-se-prime]]给出的是平均值；要求更高可靠度时：

| 可靠度 | 50% | 90% | 95% | 99% | 99.9% |
|---|---|---|---|---|---|
| $k_e$ | $1.000$ | $0.897$ | $0.868$ | $0.814$ | $0.753$ |

**其他系数**$k_f$：腐蚀、镀层、微动磨损、残余应力——计算中通常取$1$，但它提醒我们这些影响可能起支配作用。喷丸和滚压在表面留下残余压应力，可显著提高疲劳强度；腐蚀和镀铬则可能使其急剧下降。

::: example 切削加工轴的疲劳极限 {#ex-marin}
一根直径$40\ \mathrm{mm}$的切削加工钢轴（$S_{ut} = 700\ \mathrm{MPa}$）在室温下承受恒定弯矩旋转。估计其 99% 可靠度下的疲劳极限，以及（远离任何缺口处）对称循环应力幅$300\ \mathrm{MPa}$下的寿命。
::: solution
**系数。** $k_a = 4.51\times700^{-0.265} = 0.795$；$k_b = 1.24\times40^{-0.107} = 0.836$；$k_c = 1$（弯曲）；$k_d = 1$；$k_e = 0.814$；$k_f = 1$。

**疲劳极限。** $S_e = 0.795\times0.836\times0.814\times350 = 189\ \mathrm{MPa}$——为试样值的 54%。

**S–N 直线。** $a = 630^2/189.2 = 2098\ \mathrm{MPa}$，$b = -\tfrac13\log_{10}(630/189.2) = -0.1741$。在$300\ \mathrm{MPa}$下：$N = (300/2098)^{-1/0.1741} = 7.1\times10^4$次循环。

**评注。** 抛光试样在$300\ \mathrm{MPa}$下可以无限期工作，因为它低于$S_e' = 350\ \mathrm{MPa}$。而切削加工的、更粗的轴在 99% 可靠度下只能转约$70\,000$转——在$1800\ \mathrm{rpm}$下约 40 分钟。表面和尺寸修正不是细枝末节，它们决定了设计。
:::
:::

## 应力集中与缺口敏感性

疲劳裂纹从缺口处萌生。在静载下，延性材料会局部屈服，[[machine-design/static-failure]]中的弹性应力集中系数$K_t$几乎不起作用；在循环载荷下它则影响很大。但实际观察到的也不是完整的$K_t$：小而尖的缺口对零件的削弱小于$K_t$的预测，因为应力从缺口根部起急剧衰减，而裂纹萌生需要一定体积的高应力材料。**疲劳缺口系数**$K_f$（无缺口与有缺口疲劳强度之比）通过**缺口敏感系数**$q$与$K_t$相联系：
$$
K_f = 1 + q\,(K_t - 1), \qquad 0 \le q \le 1,
$$ {#eq-kf}
剪切时类似地有$K_{fs} = 1 + q_s(K_{ts} - 1)$。$q = 0$表示缺口没有影响；$q = 1$表示完全敏感，$K_f = K_t$。Neuber 给出的对缺口半径$r$的依赖关系为
$$
q = \frac{1}{1 + \sqrt{a_N}/\sqrt{r}},
$$ {#eq-neuber}
其中$\sqrt{a_N}$（Neuber 常数，单位为$\sqrt{\mathrm{mm}}$）是随抗拉强度增大而减小的材料性能：强度越高的钢对缺口越敏感。Budynas 与 Nisbett 以曲线图给出不同强度的钢和铝合金的$q$对$r$的关系；缺口半径为几毫米的钢，$q$通常为$0.7$–$0.95$。拿不准时取$q = 1$。

$K_f$乘的是名义应力，而不是强度。Budynas 与 Nisbett 把它同时作用于应力幅和平均应力，$\sigma_a = K_f\sigma_{a,\text{nom}}$，$\sigma_m = K_f\sigma_{m,\text{nom}}$；当缺口根部在第一次循环就屈服时，这样做是保守的。

::: warning 使疲劳预测失去价值的错误
- **把试样的疲劳极限用于零件。** 仅仅忘记$k_a$和$k_b$就可能使$S_e$高估一倍、寿命高估几个数量级。
- **两次计入$K_f$**：一次作用于应力，又一次作用于强度；或者把它作用于本来就是在带缺口零件上测得的强度（例如螺纹紧固件或弹簧的疲劳强度）。
- **扭转取$k_c = 0.59$，同时又采用米泽斯应力**，这把剪切强度的降低算了两次。
- **忽略平均应力**，或者在没有试验依据的情况下在设计计算中把压缩平均应力当作有利因素。
- **期望精确。** 用应力–寿命法估计的寿命，最好也只能准确到 2–3 倍以内；应对应力取足够的安全因数，在失效后果严重时对实际零件进行试验。
:::

## 变应力：平均应力的影响

在不同平均应力下进行的试验，对每一个寿命给出一组引起失效的组合$(\sigma_m, \sigma_a)$。在$\sigma_a$对$\sigma_m$的图——**疲劳极限图**——上，无限寿命的点从应力幅轴上的$(0, S_e)$向平均应力轴上的抗拉强度方向下降。常用几条曲线来表示它们（Budynas 与 Nisbett，§6-12）：
$$
\begin{aligned}
&\text{修正 Goodman：} && \frac{\sigma_a}{S_e} + \frac{\sigma_m}{S_{ut}} = \frac1n, \\
&\text{Gerber：} && \frac{n\sigma_a}{S_e} + \left(\frac{n\sigma_m}{S_{ut}}\right)^2 = 1, \\
&\text{ASME 椭圆：} && \left(\frac{n\sigma_a}{S_e}\right)^2 + \left(\frac{n\sigma_m}{S_y}\right)^2 = 1, \\
&\text{Soderberg：} && \frac{\sigma_a}{S_e} + \frac{\sigma_m}{S_y} = \frac1n, \\
&\text{Langer（首次循环屈服）：} && \sigma_a + \sigma_m = \frac{S_y}{n}.
\end{aligned}
$$ {#eq-mean}
这些是经验的失效轨迹，而不是定律。Gerber 抛物线穿过延性钢数据的中部；Goodman 直线位于大多数数据之下，简单而保守；ASME 椭圆曲线拟合良好，用于 ASME 轴设计标准；通过$S_y$的 Soderberg 直线非常保守。每一个准则都是针对**过原点的载荷线**写出的：$\sigma_a$和$\sigma_m$都按因数$n$增大，正如形状固定的载荷增大时那样。Langer 直线校核首次循环时的屈服；需要它，是因为在平均应力轴附近 Goodman 和 Gerber 曲线会延伸到$S_y$以外。

::: proposition 径向载荷线上的 Goodman 安全因数 {#prop-goodman-n}
若某点的应力按比例增大，$(\sigma_m, \sigma_a) \to (n\sigma_m, n\sigma_a)$，则按修正 Goodman 准则，防止无限寿命疲劳失效的安全因数为
$$
n_f = \left(\frac{\sigma_a}{S_e} + \frac{\sigma_m}{S_{ut}}\right)^{-1},
$$ {#eq-goodman-n}
Gerber 安全因数为
$$
n_f = \frac12\left(\frac{S_{ut}}{\sigma_m}\right)^2\frac{\sigma_a}{S_e}\left[-1 + \sqrt{1 + \left(\frac{2\sigma_mS_e}{S_{ut}\sigma_a}\right)^2}\right] \quad (\sigma_m > 0).
$$ {#eq-gerber-n}
:::

::: proof
**假设。** 平均应力为拉应力（$\sigma_m > 0$）；失效轨迹是通过$(0, S_e)$和$(S_{ut}, 0)$的 Goodman 直线或 Gerber 抛物线；载荷线通过原点。

**Goodman。** 当$n(\sigma_a/S_e + \sigma_m/S_{ut}) = 1$时，点$(n\sigma_m, n\sigma_a)$位于直线$S_a/S_e + S_m/S_{ut} = 1$上，这就是[[#eq-goodman-n]]。

**Gerber。** 当$n\sigma_a/S_e + n^2\sigma_m^2/S_{ut}^2 = 1$时，该点位于$S_a/S_e + (S_m/S_{ut})^2 = 1$上，这是二次方程$An^2 + Bn - 1 = 0$，$A = \sigma_m^2/S_{ut}^2$，$B = \sigma_a/S_e$。其正根为$n = \dfrac{-B + \sqrt{B^2 + 4A}}{2A} = \dfrac{B}{2A}\left[-1 + \sqrt{1 + 4A/B^2}\right]$。代入$B/(2A) = \tfrac12(S_{ut}/\sigma_m)^2\sigma_a/S_e$和$4A/B^2 = (2\sigma_mS_e/(S_{ut}\sigma_a))^2$，即得[[#eq-gerber-n]]。
:::

::: example 承受变化拉力的带缺口杆 {#ex-mean}
一根切削加工的钢杆（$S_{ut} = 700\ \mathrm{MPa}$，$S_y = 550\ \mathrm{MPa}$）在一个$K_t = 2.0$、缺口敏感系数$q = 0.8$的沟槽处净截面积为$300\ \mathrm{mm^2}$。它承受在$10\ \mathrm{kN}$与$40\ \mathrm{kN}$之间循环的轴向载荷。求按 Goodman、Gerber、ASME 椭圆和 Soderberg 准则的无限寿命安全因数，以及防止首次循环屈服的安全因数。取 50% 可靠度。
::: solution
**疲劳极限。** $k_a = 0.795$（同[[#ex-marin]]），轴向载荷$k_b = 1$，$k_c = 0.85$：$S_e = 0.795\times0.85\times350 = 236\ \mathrm{MPa}$。

**应力。** $K_f = 1 + 0.8(2.0 - 1) = 1.8$。$F_a = 15\ \mathrm{kN}$，$F_m = 25\ \mathrm{kN}$，因此$\sigma_a = 1.8\times15\,000/300 = 90\ \mathrm{MPa}$，$\sigma_m = 1.8\times25\,000/300 = 150\ \mathrm{MPa}$。

**安全因数。**
- Goodman：$1/n = 90/236 + 150/700 = 0.381 + 0.214 = 0.595$，$n = 1.68$。
- Gerber，[[#eq-gerber-n]]：$2\sigma_mS_e/(S_{ut}\sigma_a) = 1.126$，$n = 2.10$。
- ASME 椭圆：$n = [(90/236)^2 + (150/550)^2]^{-1/2} = 2.14$。
- Soderberg：$1/n = 90/236 + 150/550 = 0.654$，$n = 1.53$。
- Langer：$n_y = 550/(90 + 150) = 2.29$。

**解释。** 各种情况下都是疲劳起控制作用。从$1.5$到$2.1$的分散就是准则本身的不确定性；用 Goodman 准则并取$n \ge 1.5$的设计者可以免受其影响。屈服校核采用了完整的$K_f$，是保守的：延性缺口根部在首次循环时局部屈服，实际上会使平均应力松弛。
:::
:::

## 组合载荷

轴、曲柄和支架同时承受弯曲、轴向和扭转应力，每一种都有各自的应力幅和平均应力分量。常用的工程方法（Budynas 与 Nisbett，§6-14）是通过米泽斯应力，分别把应力幅部分和平均应力部分合成，然后应用单轴疲劳准则。

::: algorithm 同相组合载荷下的疲劳 {#alg-combined}
1. 在危险点求各应力的名义应力幅和平均应力分量：$\sigma_{a}$、$\sigma_{m}$（弯曲加轴向）和$\tau_a$、$\tau_m$（扭转）。
2. 把每个分量乘以相应的疲劳缺口系数：弯曲用$K_f$（轴向用$K_{f,\text{axial}}$；若疲劳极限按弯曲取值，则轴向应力幅除以$0.85$），扭转用$K_{fs}$。
3. 合成：$\sigma_a' = \sqrt{\sigma_a^2 + 3\tau_a^2}$，$\sigma_m' = \sqrt{\sigma_m^2 + 3\tau_m^2}$（用已乘以集中系数的值）。
4. 取$k_c = 1$（弯曲）计算$S_e$。
5. 用$\sigma_a'$、$\sigma_m'$应用[[#eq-mean]]中的某个平均应力准则；用$\sigma'_{\max} = \sqrt{(\sigma_a + \sigma_m)^2 + 3(\tau_a + \tau_m)^2}$校核首次循环屈服。
:::

该方法是近似的。它假定各分量同相（同时达到峰值）；对于非同相的多轴载荷，如某些曲轴和转子轴，则改用临界平面法。

::: example 承受变化弯曲和稳定扭转的杠杆 {#ex-combined}
在一个杠杆臂的圆角处，名义弯曲应力在$0$到$120\ \mathrm{MPa}$之间循环，同时作用着$40\ \mathrm{MPa}$的稳定扭转切应力。$K_f = 1.6$，$K_{fs} = 1.3$。完全修正后的疲劳极限（$k_c = 1$）为$S_e = 200\ \mathrm{MPa}$；$S_{ut} = 700\ \mathrm{MPa}$，$S_y = 550\ \mathrm{MPa}$。求 Goodman 安全因数和屈服安全因数。
::: solution
**分量。** $\sigma_a = \sigma_m = 60\ \mathrm{MPa}$；$\tau_a = 0$，$\tau_m = 40\ \mathrm{MPa}$。

**米泽斯应力。** $\sigma_a' = 1.6\times60 = 96.0\ \mathrm{MPa}$；$\sigma_m' = \sqrt{(1.6\times60)^2 + 3(1.3\times40)^2} = \sqrt{9216 + 8112} = 131.6\ \mathrm{MPa}$。

**Goodman。** $1/n_f = 96.0/200 + 131.6/700 = 0.480 + 0.188 = 0.668$，$n_f = 1.50$。

**屈服。** $\sigma'_{\max} = \sqrt{(1.6\times120)^2 + 3(1.3\times40)^2} = \sqrt{36\,864 + 8112} = 212.1\ \mathrm{MPa}$，$n_y = 550/212.1 = 2.59$。

**评注。** 稳定扭矩对应力幅毫无贡献，但提高了平均应力，使安全因数从$1/(0.48 + 96/700) = 1.62$（仅弯曲）降到$1.50$。
:::
:::

## 变幅载荷与累积损伤

实际零件很少承受等幅循环。起重机吊钩、车辆悬架臂或风力机主轴承受的是一个应力幅谱。对实测应力历程中的循环进行计数，采用**雨流计数法**（ASTM E1049 中有标准规定），它把峰和谷配对成封闭的滞回环，每个环有一个应力幅和一个平均应力。然后把计数所得各循环的损伤相加。

::: proposition Palmgren–Miner 线性损伤法则 {#prop-miner}
设零件在应力幅$\sigma_i$下承受$n_i$次循环（$i = 1, \dots, k$），$\sigma_i$下的等幅寿命为$N_i$。若在$\sigma_i$下每一次循环无论何时施加都消耗寿命的$1/N_i$，则当
$$
D = \sum_{i=1}^{k}\frac{n_i}{N_i} = 1
$$ {#eq-miner}
时发生失效。
:::

::: proof
**假设（即该法则的假说）。** 损伤是一个标量$D$，它在每一应力幅下随循环次数线性累积，从$D = 0$（新件）到$D = 1$（失效），累积速率只取决于当前应力幅：$dD/dn = 1/N(\sigma)$。在等幅下这再现了 S–N 曲线，因为$D = n/N$在$n = N$时达到 1。在一系列应力幅下，各增量相加，$D = \sum n_i/N_i$，而且由于速率与$D$无关，施加顺序无关紧要。以$D = 1$为失效即得[[#eq-miner]]。这一推导恰恰表明了该法则忽略了什么：损伤速率对已有损伤的依赖，因而也忽略了一切加载顺序效应。
:::

该法则由 A. Palmgren（1924 年）针对滚珠轴承、由 M. A. Miner（1945 年）针对飞机结构提出。试验得到的失效时的$D$在约$0.3$到$3$之间：先高后低的加载顺序往往提前失效（$D < 1$），因为高载荷萌生的裂纹会在本来不足以萌生裂纹的载荷下扩展；先低后高的顺序往往寿命更长。在简单法则中，低于疲劳极限的循环被视为无害，一旦裂纹已经存在，这就是不保守的；正因为如此，焊接结构的规范（如 EN 1993-1-9）以较小的斜率把 S–N 直线延伸到拐点以下。有些设计规范要求$D \le 0.5$或更小。

::: example 载荷谱下的寿命 {#ex-miner}
[[#ex-marin]]中的切削加工轴（$S_e = 189\ \mathrm{MPa}$，$a = 2098\ \mathrm{MPa}$，$b = -0.1741$）在每一个运行程序块中承受：$350\ \mathrm{MPa}$下$2000$次循环，$280\ \mathrm{MPa}$下$10\,000$次，$220\ \mathrm{MPa}$下$50\,000$次，$150\ \mathrm{MPa}$下$10^6$次，均为对称循环。估计失效前的程序块数。
::: solution
**寿命。** $N = (\sigma/a)^{1/b}$：$350\ \mathrm{MPa}$下$N_1 = 2.92\times10^4$；$280$下$N_2 = 1.05\times10^5$；$220$下$N_3 = 4.21\times10^5$；$150\ \mathrm{MPa}$低于$S_e$，$N_4 = \infty$。

**每个程序块的损伤。** $D = 2000/29\,230 + 10\,000/105\,300 + 50\,000/420\,600 + 0 = 0.068 + 0.095 + 0.119 = 0.282$。

**程序块数。** $1/0.282 = 3.5$个程序块。

**评注。** 每个有损伤的应力水平贡献的份额相近；按此法则，一百万次低应力循环毫无贡献。如果忽略拐点而把 S–N 直线延伸下去，$150\ \mathrm{MPa}$下的寿命将是$N_4 = (150/2098)^{1/b} = 3.8\times10^6$次循环，每个程序块增加$10^6/3.8\times10^6 = 0.26$，使寿命几乎减半，降到$1.8$个程序块。哪种假设正确，取决于裂纹是否已经在扩展——而这恰恰是线性法则无法告诉我们的。
:::
:::

## 应力–寿命法之外

应力–寿命法适用于长寿命和设计上保持弹性的零件。工业中还使用另外两种方法。**应变–寿命**法（Coffin–Manson 与 Basquin 关系，并用 Neuber 法则求缺口根部应变）显式地处理缺口处的循环塑性应变；它是低周疲劳的方法，如涡轮零件的热循环和以过载为主的载荷谱。**线弹性断裂力学**处理裂纹本身：借助 Paris 公式$da/dN = C(\Delta K)^m$，它预测已知尺寸的裂纹扩展到临界尺寸需要多久，这是飞机结构损伤容限设计和检查间隔的基础。见[[solid-mechanics/fracture-mechanics]]。

::: application 铁路车轴与飞机结构
铁路车轴是最早按疲劳设计的工程零件，至今仍是一个要求很高的例子：轮对车轴每行驶一百万公里约转 5 亿转，每转一圈就是一次旋转弯曲循环，而在压装引起微动磨损的轮座处存在应力集中。现代车轴按标准（欧洲为 EN 13103 和 EN 13104）设计，标准规定了各截面的许用应力，车轴在使用中还要进行超声波探伤。在航空领域，1954 年两架德哈维兰"彗星"客机的失事被追查到增压机身开口拐角处的疲劳裂纹；调查中包括在水槽中对整段机身进行的全尺寸压力试验，它改变了增压结构的设计、试验和检查方式。
:::

::: history
最早有记录的疲劳试验是由克劳斯塔尔的矿务官员 Wilhelm Albert 进行的，他在 1837 年发表了反复加载的铁制输送链的试验结果。19 世纪 40 年代铁路车轴频繁断裂，著名的有 1842 年的凡尔赛（默东）事故，W. J. M. 朗肯（Rankine）于 1843 年撰文讨论车轴在尖锐轴肩处的断裂。August Wöhler 作为德国的铁路工程师，制造了在旋转弯曲下试验车轴的机器，并在 1858 年至 1870 年间发表了结果，证明了铁和钢存在疲劳极限以及应力范围的重要性；S–N 曲线常被称为 Wöhler 曲线。Heinrich Gerber 于 1874 年提出了他的抛物线平均应力关系，John Goodman 的《应用于工程的力学》（*Mechanics Applied to Engineering*，1899 年）引入了直线图，后来被修改为"修正 Goodman"直线。O. H. Basquin 于 1910 年描述了 S–N 曲线的双对数直线关系。Arvid Palmgren 于 1924 年把线性损伤累加用于滚珠轴承，M. A. Miner 于 1945 年针对飞机结构发表了这一法则。
:::

::: quiz
对一个切削加工的钢零件，下列哪种改变使其疲劳极限提高得最多？
- [ ] 改用抗拉强度高 20% 的钢，仍为切削加工。
- [x] 对危险表面进行磨削和喷丸。
- [ ] 把直径增大 20%，同时保持应力不变。
- [ ] 在更高的循环频率下试验。
::: solution
强度更高的切削加工钢，其增益不到 20%，因为$k_a$随$S_{ut}$下降；直径增大使$k_b$降低；频率影响很小。磨削提高$k_a$（在$S_{ut} = 700\ \mathrm{MPa}$时从约$0.79$提高到$0.91$），喷丸在裂纹萌生的表面加入残余压应力，常使疲劳强度提高百分之几十。
:::
:::

::: quiz
一个支架承受稳定的拉伸平均应力和交变应力。应力幅加倍而平均应力不变。按 Goodman 准则，比例载荷线上的安全因数
- [ ] 恰好减半。
- [x] 下降，但下降不到一半。
- [ ] 不变，因为平均应力不变。
::: solution
$1/n = \sigma_a/S_e + \sigma_m/S_{ut}$；$\sigma_a$加倍只使第一项加倍，所以$1/n$增大不到一倍，$n$的下降不到一半（除非$\sigma_m = 0$）。
:::
:::

::: summary
- 用$\sigma_a = (\sigma_{\max} - \sigma_{\min})/2$和$\sigma_m = (\sigma_{\max} + \sigma_{\min})/2$描述一个循环。
- 钢：$S_e' \approx 0.5S_{ut}$（最高$700\ \mathrm{MPa}$）；在$10^3$与$10^6$次循环之间，$S_f = aN^b$通过$fS_{ut}$和$S_e$。
- 实际零件：$S_e = k_ak_bk_ck_dk_ek_fS_e'$——表面、尺寸、载荷类型、温度、可靠度和其他影响；表面和尺寸通常影响最大。
- 缺口：$K_f = 1 + q(K_t - 1)$，作用于应力。
- 平均应力：Goodman $\sigma_a/S_e + \sigma_m/S_{ut} = 1/n$（保守），Gerber（数据的中部），ASME 椭圆，Soderberg；用 Langer 校核首次循环屈服。
- 同相组合应力：分别对应力幅部分和平均应力部分取米泽斯应力，$k_c = 1$。
- 变幅载荷：雨流计数和 Miner 法则$\sum n_i/N_i = 1$——有用但粗略，忽略了顺序效应。
- 应力–寿命法预测的寿命有 2–3 倍的不确定性；安全关键零件按规范设计并经试验验证。
:::

::: exercise 高强度钢的疲劳极限 {level=1 check="700"}
估计$S_{ut} = 1600\ \mathrm{MPa}$的钢的旋转弯曲疲劳极限。（以 MPa 为单位输入$S_e'$。）
::: solution
$S_{ut} > 1400\ \mathrm{MPa}$，因此由[[#eq-se-prime]]，$S_e' = 700\ \mathrm{MPa}$，而不是$800\ \mathrm{MPa}$。这种钢对缺口和表面高度敏感：切削加工时$k_a = 4.51\times1600^{-0.265} = 0.63$。

::: exercise 疲劳缺口系数 {level=1 check="2.2"}
一个轴肩圆角$K_t = 2.5$，材料在该处的缺口敏感系数为$q = 0.8$。求$K_f$。
::: solution
$K_f = 1 + 0.8\times(2.5 - 1) = 1 + 1.2 = 2.2$。
:::

::: exercise 应力循环 {level=1 check="125"}
应力在$+200\ \mathrm{MPa}$与$-50\ \mathrm{MPa}$之间变化。求应力幅、平均应力和应力比。（以 MPa 为单位输入$\sigma_a$。）
::: solution
$\sigma_a = (200 - (-50))/2 = 125\ \mathrm{MPa}$，$\sigma_m = (200 - 50)/2 = 75\ \mathrm{MPa}$，$R = -50/200 = -0.25$。
:::

::: exercise Marin 系数 {level=2 check="202.3"}
某零件的试样疲劳极限$S_e' = 350\ \mathrm{MPa}$，表面系数$k_a = 0.80$，尺寸系数$k_b = 0.85$，在室温下承受轴向载荷；可靠度 50%。求其疲劳极限。（以 MPa 为单位输入$S_e$。）
::: solution
轴向载荷：$k_c = 0.85$；$k_d = k_e = k_f = 1$。$S_e = 0.80\times0.85\times0.85\times350 = 202.3\ \mathrm{MPa}$。（严格地说，轴向载荷没有应力梯度，$k_b$应取$1$，得$238\ \mathrm{MPa}$；有时出于统计上的理由对轴向受载零件仍保留尺寸效应——体积越大，所含缺陷越多。）
:::
:::

::: exercise 由 Basquin 直线求寿命 {level=2 check="1024"}
某材料的 S–N 直线为$S_f = 1000\,N^{-0.1}$（MPa）。求对称循环应力幅$500\ \mathrm{MPa}$下的寿命。（输入循环次数。）
::: solution
$N = (500/1000)^{-1/0.1} = 0.5^{-10} = 2^{10} = 1024$次循环。答案靠近直线的$10^3$次循环一端，那里应力–寿命法最不可靠。
:::
:::

::: exercise Goodman 与 Gerber {level=2 check="1.25"}
在某危险点$\sigma_a = 100\ \mathrm{MPa}$，$\sigma_m = 400\ \mathrm{MPa}$（均已计入$K_f$）；$S_e = 250\ \mathrm{MPa}$，$S_{ut} = 1000\ \mathrm{MPa}$，$S_y = 850\ \mathrm{MPa}$。求 Goodman 安全因数，再求 Gerber 和 Langer 安全因数。（输入 Goodman 值。）
::: solution
Goodman：$1/n = 100/250 + 400/1000 = 0.4 + 0.4 = 0.8$，$n = 1.25$。Gerber：$2\sigma_mS_e/(S_{ut}\sigma_a) = 2$，$n = \tfrac12(2.5)^2(0.4)(-1 + \sqrt5) = 1.545$。Langer：$850/500 = 1.70$。疲劳起控制作用。
:::
:::

::: exercise 剩余寿命 {level=2 check="140000"}
某零件已在一个寿命为$100\,000$次循环的应力幅下累积了$30\,000$次循环。按 Miner 法则，它随后在一个寿命为$2\times10^5$次循环的较低应力幅下还能承受多少次循环？（输入循环次数。）
::: solution
已有损伤$D_1 = 0.3$；剩余$0.7$，因此$n_2 = 0.7\times200\,000 = 140\,000$次循环。由于这是先高后低的顺序，试验往往给出比 Miner 法则预测更少的循环次数。
:::
:::

::: exercise 平均应力不变 {level=3}
一个弹簧卡子以固定的预紧力装配，因此在使用中其平均应力保持为$\sigma_m$，而应力幅$\sigma_a$可能因过载而增大。(a) 证明采用 Goodman 直线时，对应力幅的安全因数为$n = \dfrac{S_e}{\sigma_a}\left(1 - \dfrac{\sigma_m}{S_{ut}}\right)$。(b) 对$\sigma_a = 100$、$\sigma_m = 300$、$S_e = 250$、$S_{ut} = 1000\ \mathrm{MPa}$，将其与[[#eq-goodman-n]]比较。(c) 说明为什么载荷线的选择是对加载物理本质的陈述，而不是数学上的方便。
::: solution
(a) $\sigma_m$固定时，当应力幅达到该平均应力下 Goodman 直线上的$S_a$时失效：$S_a = S_e(1 - \sigma_m/S_{ut})$。安全因数为$S_a/\sigma_a$。
(b) 平均应力不变：$n = 2.5\times0.7 = 1.75$。径向线：$1/n = 0.4 + 0.3 = 0.7$，$n = 1.43$。
(c) 安全因数回答的是"载荷能增大多少才失效？"。如果整个载荷按比例增大（轴的转矩增大），两个分量都按比例增大，适用径向线；如果平均应力由装配（预紧力、自重）决定而只有变化部分可能增大，则适用竖直线。用错了就会错估裕度——此处相差 20%。
:::

::: exercise 确定拉杆尺寸 {level=3}
压力机机架中的一根圆截面钢拉杆承受在$20\ \mathrm{kN}$与$100\ \mathrm{kN}$之间循环的轴向载荷。它用$S_{ut} = 700\ \mathrm{MPa}$、$S_y = 550\ \mathrm{MPa}$的钢切削加工而成，有一个$K_t = 2.2$、$q = 0.85$的螺纹退刀槽。在 99% 可靠度下，按 Goodman 安全因数$2$选择无限寿命的直径，校核屈服，并说明为减轻重量你会采取什么不同的做法。
::: solution
**强度。** $k_a = 0.795$，$k_b = 1$（轴向），$k_c = 0.85$，$k_e = 0.814$：$S_e = 0.795\times0.85\times0.814\times350 = 192.5\ \mathrm{MPa}$。$K_f = 1 + 0.85\times1.2 = 2.02$。

**净面积$A$上的应力。** $F_a = 40\ \mathrm{kN}$，$F_m = 60\ \mathrm{kN}$；$\sigma_a = 2.02\times40\,000/A$，$\sigma_m = 2.02\times60\,000/A$。

**取$n = 2$的 Goodman 准则。** $1/2 = (80\,800/A)/192.5 + (121\,200/A)/700$，故$A = 2(419.7 + 173.1) = 1186\ \mathrm{mm^2}$，槽底直径$d = \sqrt{4A/\pi} = 38.9\ \mathrm{mm}$；取$40\ \mathrm{mm}$（$A = 1257\ \mathrm{mm^2}$，$n = 2.12$）。

**屈服。** $\sigma_{\max} = 2.02\times100\,000/1257 = 161\ \mathrm{MPa}$，$n_y = 3.4$。

**减轻重量。** 沟槽和切削加工表面损失了一半以上的强度。加大沟槽半径（降低$K_t$）、滚压螺纹和滚压沟槽（残余压应力，更好的$k_a$），或采用细腰杆身使螺纹不再是危险截面，都能使拉杆显著变细；对机架施加拉杆预紧也可以，它降低了拉杆所承受的应力幅（[[machine-design/fasteners-joints]]中的螺栓连接原理）。任何改变都应通过实际细节的疲劳试验加以验证。
:::
