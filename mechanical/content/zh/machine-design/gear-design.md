打开任何一个齿轮箱——汽车变速器、风力发电机组的传动链、车床主轴箱、工业减速器——都会看到一对对带齿的轮子以固定的传动比把转矩从一根轴传到另一根轴。齿轮副是一种效率极高、结构紧凑的机械零件：润滑良好的直齿轮啮合只损失它所传递功率的百分之一二，一个拳头大小的小齿轮就能传递几十千瓦。这种紧凑是有代价的。每个轮齿都是一根短而粗的悬臂梁，在一个移动的点上承受很大的力，每转一次加载一次，要承受数百万乃至数十亿次；而力在齿与齿之间通过一条宽度不到一毫米的接触带传递，那里的表面压力可达一吉帕。

因此轮齿有两种典型的失效方式。轮齿可能因弯曲疲劳在齿根**折断**——这通常是更危险的失效，因为齿轮立即停止传动，折断的碎块还会毁坏齿轮箱的其余部分。齿面也可能发生**点蚀**：由于接触（滚动）疲劳，工作表面上剥落出一个个小坑，齿廓逐渐被破坏，齿轮噪声增大，最终轮齿从受损的表面开裂。齿轮的强度计算就是要同时校核这两者：齿根的弯曲应力与弯曲疲劳强度比较，齿面的接触应力与接触疲劳强度比较。本章推导两个经典的应力公式——路易斯（Wilfred Lewis）的弯曲公式和赫兹（Heinrich Hertz）的接触应力——然后说明现代齿轮强度计算标准如何在它们的基础上建立起来。

齿轮的运动学——齿廓啮合基本定律、渐开线齿廓、干涉与根切——在[[mechanisms/gears]]中讲述，轮系在[[mechanisms/gear-trains]]中讲述。这里只回顾应力分析所需要的几何关系。下面的受力分析求出啮合对轴和轴承施加的载荷，它们是[[machine-design/shafts]]和[[machine-design/bearings]]的输入；全章所用的疲劳概念来自[[machine-design/fatigue]]。

符号沿用 Budynas 与 Nisbett《Shigley 机械工程设计》（*Shigley's Mechanical Engineering Design*，第 11 版）的国际单位制形式：模数$m$，小齿轮齿数$z_P$和大齿轮齿数$z_G$，分度圆直径$d$，压力角$\phi$，齿宽$F$，传递的（圆周）载荷$W_t$，安全因数$n$，以及后文引入的 AGMA 系数$K_o$、$K_v$、$K_s$、$K_H$、$K_B$、$Y_J$、$Z_I$、$Y_N$、$Z_N$、$S_F$、$S_H$。一对齿轮中较小的称为**小齿轮**；传动比为$m_G = z_G/z_P \ge 1$。

## 直齿圆柱齿轮几何简述

直齿圆柱齿轮的轮齿是平行于轴线的直齿。两个啮合齿轮在运动学上相当于两个做纯滚动的圆柱——**分度圆柱**（节圆柱），其横截面为**分度圆**——轮齿的形状使这种滚动被精确地复现，无论轮齿处于什么位置，角速度比都保持恒定。

::: definition 米制直齿圆柱齿轮的术语 {#def-nomenclature}
对齿数为$z$的直齿圆柱齿轮：
- **模数**为$m = d/z$，即每个齿所对应的分度圆直径，单位为毫米；相啮合的齿轮必须具有相同的模数；
- **分度圆直径**为$d = mz$，**齿距**（分度圆上相邻两齿对应点之间的弧长）为$p = \pi d/z = \pi m$；
- **压力角**$\phi$是啮合线（接触点处两齿廓的公法线）与两分度圆公切线之间的夹角；标准值为$\phi = 20°$；
- 渐开线齿廓由之展开的**基圆**半径为$r_b = (d/2)\cos\phi$，**基圆齿距**（基节）为$p_b = p\cos\phi = \pi m\cos\phi$；
- 对标准全齿高齿（ISO 53 基本齿条），**齿顶高**（分度圆到齿顶）为$h_a = m$，**齿根高**（分度圆到齿根）为$h_f = 1.25m$，因此齿顶圆直径为$d_a = d + 2m$，齿根圆直径为$d_f = d - 2.5m$，全齿高为$2.25m$，顶隙为$0.25m$；
- 两个标准齿轮在**中心距**$C = (d_P + d_G)/2 = m(z_P + z_G)/2$处啮合。
:::

模数起着尺寸比例的作用：齿数不变时模数加倍，轮齿的每一个线尺寸都加倍。优先采用的模数值由 ISO 54 规定——第一系列为$1$、$1.25$、$1.5$、$2$、$2.5$、$3$、$4$、$5$、$6$、$8$、$10\ \mathrm{mm}$等，第二系列（$1.75$、$2.25$、$2.75$、$3.5$、$4.5$、……）仅在必要时使用。在美国，齿轮还用**径节**$P = z/d$（每英寸齿数）来规定，这是与模数互为倒数的概念：$m = 25.4/P$毫米。

渐开线齿廓有两个性质是本章其余部分所依赖的（两者都在[[mechanisms/gears]]中证明）。第一，接触点始终位于一条直线——**啮合线**——上，它与两个基圆相切，与节线切线成$\phi$角，因此无摩擦齿面之间的作用力始终沿这条直线、以恒定的角度$\phi$作用。第二，渐开线上任一点的曲率半径等于该点到基圆的切线长度；在节点处它等于$(d/2)\sin\phi$。小齿轮受到**根切**的限制：用齿条型刀具展成的标准 20° 全齿高小齿轮至少需要$2/\sin^2\phi = 17.1$个齿，即 18 个齿，才能避免根切。

### 重合度

为了平稳运转，前一对轮齿脱离啮合之前，新的一对轮齿必须已经进入啮合。**重合度**$m_c$是同时处于啮合的轮齿对数的平均值。

::: proposition 外啮合直齿圆柱齿轮的重合度 {#prop-contact-ratio}
对于两个外啮合直齿圆柱齿轮，齿顶圆半径为$r_{aP}$、$r_{aG}$，基圆半径为$r_{bP}$、$r_{bG}$，啮合角为$\phi$，中心距为$C$，实际啮合线长度为
$$
Z = \sqrt{r_{aP}^2 - r_{bP}^2} + \sqrt{r_{aG}^2 - r_{bG}^2} - C\sin\phi,
$$ {#eq-path}
重合度为
$$
m_c = \frac{Z}{p_b} = \frac{Z}{\pi m\cos\phi}.
$$ {#eq-contact-ratio}
:::

::: proof
**假设。** 渐开线轮齿，刚性且齿距精确；啮合在啮合线与两个齿顶圆的交点处开始和结束（无齿顶修缘，无干涉）。

啮合线是两个基圆的内公切线；设$T_P$和$T_G$为其切点。距离$T_PT_G$是中心线在啮合线上的投影。中心线长为$C$，与啮合线成$90° - \phi$角，所以$T_PT_G = C\sin\phi$。

啮合从大齿轮齿顶圆与啮合线的交点$A$开始，到小齿轮齿顶圆与啮合线的交点$B$结束。由于$O_GT_G$垂直于啮合线，直角三角形$O_G T_G A$给出$T_GA = \sqrt{r_{aG}^2 - r_{bG}^2}$；同理$T_PB = \sqrt{r_{aP}^2 - r_{bP}^2}$。这两段重叠部分为$AB$，于是
$$
AB = T_GA + T_PB - T_PT_G = \sqrt{r_{aP}^2 - r_{bP}^2} + \sqrt{r_{aG}^2 - r_{bG}^2} - C\sin\phi,
$$
即[[#eq-path]]。

同一齿轮上相继的渐开线齿廓是一族平行曲线，它们与啮合线相交处都垂直于啮合线，并且沿任一公法线的间距都等于它们在基圆上所夹的弧长，即基节$p_b = 2\pi r_b/z = \pi m\cos\phi$。所以一对轮齿在接触点走过长度$Z$的期间保持接触，而每隔$p_b$就有一对新齿开始啮合；平均同时啮合的齿对数为$Z/p_b$，即[[#eq-contact-ratio]]。
:::

重合度为$1.6$意味着在 60% 的时间内两对齿分担载荷，40% 的时间内一对齿单独承载。齿轮设计的重合度不应低于约$1.2$；常用齿数范围内的标准 20° 齿轮，$m_c$约在$1.4$到$1.8$之间。重合度大于 1 也是下文路易斯所假设的“齿顶加载”偏于保守的原因：当一个轮齿在齿顶受载时，通常还有另一对齿也在啮合。

::: example 一对齿轮的几何尺寸与重合度 {#ex-geometry}
齿数$z_P = 20$的小齿轮驱动齿数$z_G = 40$的大齿轮；模数$m = 4\ \mathrm{mm}$，$\phi = 20°$，标准全齿高齿，标准中心距。求分度圆、齿顶圆、齿根圆和基圆直径，中心距及重合度。
::: solution
**直径。** $d_P = mz_P = 80\ \mathrm{mm}$，$d_G = 160\ \mathrm{mm}$。齿顶圆直径$d_a = d + 2m$：$88$和$168\ \mathrm{mm}$，故$r_{aP} = 44\ \mathrm{mm}$，$r_{aG} = 84\ \mathrm{mm}$。齿根圆直径$d - 2.5m$：$70$和$150\ \mathrm{mm}$。基圆半径$r_b = (d/2)\cos 20°$：$r_{bP} = 40\times0.93969 = 37.588\ \mathrm{mm}$，$r_{bG} = 75.175\ \mathrm{mm}$。

**中心距。** $C = (80 + 160)/2 = 120\ \mathrm{mm}$，$C\sin\phi = 120\times0.34202 = 41.042\ \mathrm{mm}$。

**实际啮合线长度。** 由[[#eq-path]]，
$$
Z = \sqrt{44^2 - 37.588^2} + \sqrt{84^2 - 75.175^2} - 41.042 = 22.873 + 37.479 - 41.042 = 19.309\ \mathrm{mm}.
$$
**重合度。** $p_b = \pi\times4\times\cos20° = 11.809\ \mathrm{mm}$，所以$m_c = 19.309/11.809 = 1.64$。

**合理性检查。** 该值位于通常范围$1.4$–$1.8$内，高于约$1.2$的最小值。齿数不变而模数增大时，$Z$和$p_b$同比例放大，$m_c$不变；（模数不变时）齿数增多会使它增大。
:::
:::

## 啮合的受力分析

直齿小齿轮的受力图包括：来自其轴的驱动转矩$T$；大齿轮轮齿作用在小齿轮轮齿上的力$W$，作用于节点、沿啮合线方向；以及轴在齿轮中心处的约束力，与$W$大小相等、方向相反。齿面间的摩擦力很小（润滑啮合中摩擦因数约为$0.05$量级，且在节点处换向），受力分析中略去不计。把$W$分解为垂直于中心线的**圆周**分力$W_t$（它传递转矩）和沿中心线的**径向**分力$W_r$（它只把两齿轮推开）较为方便。

::: proposition 直齿圆柱齿轮啮合中的力 {#prop-forces}
分度圆直径为$d$的直齿圆柱齿轮传递转矩$T$（或在节线速度$V$下传递功率$H$），轮齿为压力角$\phi$的无摩擦渐开线齿，则
$$
W_t = \frac{2T}{d} = \frac{H}{V}, \qquad W_r = W_t\tan\phi, \qquad W = \frac{W_t}{\cos\phi},
$$ {#eq-spur-forces}
其中$V = \omega d/2 = \pi d n/60$，$n$以 r/min 计。一对齿轮的两个齿轮上作用着相同的$W_t$；转矩之比等于分度圆直径之比，$T_G/T_P = d_G/d_P = m_G$。
:::

::: proof
**假设。** 齿面无摩擦，齿轮为刚体，载荷作用于节点（此处$W_t$的力臂正好是$d/2$；在其他接触点，渐开线几何给出相同的转矩，因为$W$对齿轮中心的力臂始终等于基圆半径），稳定转动，齿轮角加速度为零。

齿面力沿啮合线作用，与节线切线成$\phi$角，所以其分力为$W_t = W\cos\phi$和$W_r = W\sin\phi$，由此得$W_r = W_t\tan\phi$和$W = W_t/\cos\phi$。对齿轮中心取矩：$W_r$通过中心，$W_t$的力臂为$d/2$，所以稳定转动的齿轮平衡要求$T = W_t d/2$。功率为$H = T\omega = W_t(d/2)\omega = W_tV$。由牛顿第三定律，大齿轮轮齿承受大小相同、方向相反的力；其转矩为$W_t d_G/2$，所以$T_G/T_P = d_G/d_P$。
:::

$H$以瓦、$V$以 m/s 计时，$W_t$的单位为牛。力的**方向**由受力图确定：在主动小齿轮上，$W_t$与转动方向相反；在从动大齿轮上，它与转动方向相同；两者的$W_r$都指向各自齿轮的中心。

::: example 减速器中的轮齿力 {#ex-forces}
[[#ex-geometry]]中的小齿轮（$d_P = 80\ \mathrm{mm}$）由一台电动机驱动，输出功率$H = 15\ \mathrm{kW}$，转速$n = 1440\ \mathrm{rev/min}$。求圆周力、径向力、总齿面力、节线速度和输出转矩。
::: solution
**转矩。** $\omega = 2\pi\times1440/60 = 150.80\ \mathrm{rad/s}$，所以$T_P = H/\omega = 15\,000/150.80 = 99.47\ \mathrm{N\,m}$。

**圆周力。** $W_t = 2T_P/d_P = 2\times99.47/0.080 = 2487\ \mathrm{N}$。用功率校核：$V = \omega d_P/2 = 150.80\times0.040 = 6.032\ \mathrm{m/s}$，$H/V = 15\,000/6.032 = 2487\ \mathrm{N}$。

**径向力与总力。** $W_r = 2487\tan 20° = 905\ \mathrm{N}$；$W = 2487/\cos20° = 2646\ \mathrm{N}$。

**输出。** $T_G = W_t d_G/2 = 2487\times0.080 = 198.9\ \mathrm{N\,m}$，转速$1440/2 = 720\ \mathrm{rev/min}$——略去摩擦时，转矩加倍、转速减半，理应如此。

**合理性检查。** 小齿轮轴除转矩外还必须承受合力$2.65\ \mathrm{kN}$作为弯曲载荷（由其两个轴承分担）；径向分力是圆周分力的$36$%（$\tan20° = 0.364$）。
:::
:::

### 斜齿轮、锥齿轮与蜗杆传动

**斜齿圆柱齿轮**的轮齿沿螺旋线切制，螺旋角为$\psi$（在分度圆柱上从轴线量起）。接触从轮齿的一端开始，逐渐扩展到整个齿宽，因此斜齿轮比同样尺寸的直齿轮运转更安静、承载能力更大。这时有两个压力角要区分：在垂直于轮齿的平面内的**法面**压力角$\phi_n$，即刀具的压力角（通常为$20°$），以及在旋转平面内的**端面**压力角$\phi_t$。同样有法面模数$m_n$（刀具的模数）和端面模数$m_t = m_n/\cos\psi$，且$d = m_t z$。

::: proposition 斜齿轮上的力 {#prop-helical}
对螺旋角为$\psi$、法面压力角为$\phi_n$的斜齿轮，端面压力角满足
$$
\tan\phi_n = \tan\phi_t\cos\psi,
$$ {#eq-helical-angle}
齿面力的各分力为
$$
W_t = \frac{2T}{d}, \qquad W_r = W_t\tan\phi_t, \qquad W_a = W_t\tan\psi, \qquad W = \frac{W_t}{\cos\phi_n\cos\psi}.
$$ {#eq-helical-forces}
:::

::: proof
**假设。** 齿面无摩擦；合力在分度圆柱上垂直于齿面作用。

力$W$垂直于齿面。在法面内它与分度圆柱切平面成$\phi_n$角，所以其径向分力为$W_r = W\sin\phi_n$，在切平面内的分力为$W\cos\phi_n$。在切平面内，这个分力垂直于螺旋线，而螺旋线与轴线成$\psi$角，所以它分解为$W_t = W\cos\phi_n\cos\psi$（圆周方向）和$W_a = W\cos\phi_n\sin\psi$（轴向）。因此$W = W_t/(\cos\phi_n\cos\psi)$，$W_a = W_t\tan\psi$。在端面内，力的分量为$W_t$和$W_r$，所以$\tan\phi_t = W_r/W_t = \sin\phi_n/(\cos\phi_n\cos\psi) = \tan\phi_n/\cos\psi$，即[[#eq-helical-angle]]；并且$W_r = W_t\tan\phi_t$。与直齿轮一样，转矩为$W_t d/2$，因为$W_r$和$W_a$对轴线无矩。
:::

轴向力$W_a$是斜齿的代价：它必须由能承受轴向力的轴承承担（[[machine-design/bearings]]），或用两半旋向相反的人字齿轮将其抵消。螺旋角通常取$15$–$30°$。

::: example 减速器的斜齿轮方案 {#ex-helical}
把[[#ex-forces]]中的小齿轮换成$\phi_n = 20°$、$\psi = 25°$的斜齿小齿轮，传递相同的$W_t = 2487\ \mathrm{N}$。求$\phi_t$和各分力。若法面模数为$4\ \mathrm{mm}$，$z_P = 20$，分度圆直径是多少？
::: solution
**端面压力角。** $\tan\phi_t = \tan20°/\cos25° = 0.36397/0.90631 = 0.40160$，所以$\phi_t = 21.88°$。

**各力。** $W_r = 2487\times0.40160 = 999\ \mathrm{N}$；$W_a = 2487\tan25° = 2487\times0.46631 = 1160\ \mathrm{N}$；$W = 2487/(\cos20°\cos25°) = 2487/0.85165 = 2920\ \mathrm{N}$。校核：$\sqrt{2487^2 + 999^2 + 1160^2} = 2920\ \mathrm{N}$。

**直径。** $m_t = 4/\cos25° = 4.414\ \mathrm{mm}$，$d_P = 4.414\times20 = 88.3\ \mathrm{mm}$——法面模数和齿数相同时，斜齿轮比直齿轮大，所以同样的转矩下$W_t$实际上会略小；这里保持$W_t$不变，是为了比较各分力。

**合理性检查。** 轴向力接近圆周力的一半；轴的轴承布置必须对它进行轴向定位。
:::
:::

**直齿锥齿轮**连接相交的两轴；其节面是圆锥。力通常在齿宽中点处计算，该处节圆半径为$r_{av}$：$W_t = T/r_{av}$，对所考虑齿轮的节锥角$\gamma$，$W_r = W_t\tan\phi\cos\gamma$，$W_a = W_t\tan\phi\sin\gamma$（Budynas 与 Nisbett，§13-15）。**蜗杆传动**以一级实现交错轴间的大传动比；由于蜗杆螺纹沿蜗轮轮齿滑动，摩擦不再可以忽略。设导程角为$\lambda$，法面压力角为$\phi_n$，摩擦因数为$f$，在同样的力分解中加入摩擦力，得到蜗杆驱动蜗轮时的效率
$$
e = \frac{\cos\phi_n - f\tan\lambda}{\cos\phi_n + f\cot\lambda},
$$ {#eq-worm-efficiency}
（Budynas 与 Nisbett，§13-17），导程角小时效率急剧下降；小导程角的蜗杆传动可能自锁。相比之下，N. E. Anderson 和 S. H. Loewenthal 在 NASA 进行的直齿轮试验（约 1980 年）表明，除载荷很轻时外，啮合效率一般高于 98%，而空载（搅油和风阻）损失在总损失中占相当比例。锥齿轮和蜗杆传动按各自的 AGMA 和 ISO 标准计算，这里不再讨论。

## 弯曲应力：路易斯公式

从侧面看一个轮齿。它是一根固定在轮缘上的短悬臂梁，齿根宽、齿顶窄，齿面上沿啮合线作用着力$W$。路易斯考虑的最不利情况是全部载荷作用在一个轮齿的齿顶。径向分力$W_r$使轮齿略受压缩，圆周分力$W_t$使其弯曲；弯曲起主导作用。危险截面在哪里？路易斯的洞见是：截面高度变化使各截面弯曲应力都相同的悬臂梁——等强度梁——具有抛物线形轮廓。在轮齿内作一条内切抛物线，其顶点位于载荷作用线与轮齿中心线的交点，两侧与齿根过渡圆角相切：轮齿除两个切点外处处比这条抛物线强，所以通过这两个切点的截面最弱。

::: proposition 路易斯弯曲公式 {#prop-lewis}
设齿宽为$F$、模数为$m$的直齿轮轮齿在齿顶承受圆周载荷$W_t$，内切抛物线在厚度为$t$、位于载荷作用点以下高度$l$处的截面与齿根圆角相切。该截面上的弯曲应力为
$$
\sigma = \frac{W_t}{F\,m\,Y}, \qquad Y = \frac{2x}{3m}, \quad x = \frac{t^2}{4l},
$$ {#eq-lewis}
其中**路易斯齿形系数**$Y$只取决于轮齿的形状——即齿数和齿制——而与其尺寸无关。
:::

::: proof
**假设。** (1) 全部载荷由一个轮齿承担并作用于齿顶（无载荷分担）。(2) 只考虑圆周分力$W_t$；忽略$W_r$引起的压缩。(3) 载荷沿齿宽$F$均匀分布。(4) 轮齿为悬臂梁，适用初等梁理论$\sigma = Mc/I$，忽略齿根圆角处的应力集中。(5) 齿轮为刚体且制造精确，因此没有动载荷。

在危险截面上弯矩为$M = W_t l$，截面为$F \times t$的矩形，$I/c = Ft^2/6$。所以
$$
\sigma = \frac{6W_tl}{Ft^2}.
$$
距载荷$\lambda$处应力为$6W_t\lambda/(F t(\lambda)^2)$的矩形截面悬臂梁，当$t(\lambda)^2 \propto \lambda$时为等强度梁，即其半厚度随距离的平方根增长：一条顶点在载荷作用点的抛物线。内切于轮齿的抛物线在危险截面处与轮齿相切，该处半厚度为$t/2$，位于顶点以下距离$l$处。

现在从顶点向切点作直线，再从切点作该直线的垂线，与轮齿中心线交于危险截面以下距离$x$处。与中心线构成的两个直角三角形相似：一个的直角边为$l$（沿中心线）和$t/2$，另一个为$t/2$和$x$。因此
$$
\frac{t/2}{x} = \frac{l}{t/2}, \qquad x = \frac{t^2}{4l},
$$
所以$t^2/l = 4x$，且
$$
\sigma = \frac{6W_t}{F}\cdot\frac{l}{t^2} = \frac{6W_t}{4Fx} = \frac{3W_t}{2Fx}.
$$
分子分母同乘模数，$\sigma = W_t/\big(F m \cdot \tfrac{2x}{3m}\big) = W_t/(FmY)$，其中$Y = 2x/(3m)$。由于给定齿数和齿形的轮齿的每个尺寸都与$m$成比例，$x/m$——从而$Y$——与模数无关。
:::

有两项修正把路易斯公式变成了实用的设计公式。第一项针对**速度**。齿距或齿廓不完全精确的轮齿在啮合时会发生微小冲击，动态齿面载荷随节线速度增大。Budynas 与 Nisbett 认为出自 19 世纪 Carl G. Barth 的一个经验**速度系数**乘在路易斯应力上：
$$
\sigma = \frac{K_vW_t}{FmY}, \qquad K_v = \frac{3.05 + V}{3.05}\ \ \text{（铸铁，铸造齿形）}, \qquad K_v = \frac{6.1 + V}{6.1}\ \ \text{（切制或铣制齿形）},
$$ {#eq-barth}
$V$以 m/s 计。对于制造更精确的齿轮，同一文献给出后来的 AGMA 形式：滚齿或插齿齿形$K_v = (3.56 + \sqrt V)/3.56$，剃齿或磨齿齿形$K_v = (5.56 + \sqrt V)/5.56$。这些系数很粗糙——其中不包含齿轮的质量和轮齿的刚度——但抓住了基本趋势。（较早的书中速度系数写成倒数$K_v < 1$，用来除许用应力，而不是乘作用应力。）

第二项针对**疲劳**。路易斯应力是名义应力；齿根圆角使它集中，而且轮齿每转加载一次（单向驱动的齿轮为从零到最大的脉动循环；惰轮则先向一边、再向另一边弯曲，为对称循环）。今天这些修正由强度计算标准中的几何系数和强度数据来完成，见下文。带$K_v$的路易斯公式仍可用于快速初估齿轮尺寸——而且$W_t/(FmY)$的结构在标准中保留了下来。

直齿轮齿宽的一个实用比例是 3 到 5 个齿距，$3\pi m \le F \le 5\pi m$（Budynas 与 Nisbett，§14-1）：齿宽太窄浪费了轴和轴承布置，太宽则难以对中，使载荷不能沿齿宽均匀分布。

::: example 减速器中的路易斯弯曲应力 {#ex-lewis}
[[#ex-forces]]中的减速器（$m = 4\ \mathrm{mm}$，$z_P = 20$，$z_G = 40$，$W_t = 2487\ \mathrm{N}$，$V = 6.032\ \mathrm{m/s}$）采用滚齿加工的齿轮，齿宽$F = 40\ \mathrm{mm}$。求小齿轮和大齿轮的路易斯弯曲应力；若两者都用冷拔 AISI 1040 钢（$S_y = 490\ \mathrm{MPa}$，Budynas 与 Nisbett 表 A-20），求对屈服的安全因数。
::: solution
**速度系数。** 滚齿齿形：$K_v = (3.56 + \sqrt{6.032})/3.56 = (3.56 + 2.456)/3.56 = 1.690$。

**齿宽。** $F/(\pi m) = 40/12.57 = 3.2$个齿距——在$3$–$5$的范围内。

**小齿轮。** $z = 20$时$Y = 0.322$：
$$
\sigma_P = \frac{K_vW_t}{FmY} = \frac{1.690\times2487}{40\times4\times0.322} = \frac{4203}{51.52} = 81.6\ \mathrm{MPa}.
$$
**大齿轮。** $z = 40$时$Y = 0.389$（插值）：$\sigma_G = 81.6\times0.322/0.389 = 67.5\ \mathrm{MPa}$。

**对屈服的安全因数。** 小齿轮$n = 490/81.6 = 6.0$。

**合理性检查。** 不计$K_v$时小齿轮应力为$48.3\ \mathrm{MPa}$：速度使应力增加 69%。小齿轮的弯曲应力较高，因为其齿根较薄（$Y$较小），而且载荷循环次数是大齿轮的两倍。对屈服的安全因数 6 看似宽裕，但在长寿命中轮齿要加载$10^9$次以上，齿根圆角又使应力集中；下面的强度计算方法将说明这是否足够。
:::
:::

## 接触应力：赫兹理论

两个相啮合轮齿的齿面沿一条横贯齿宽的线接触。在节点附近，每个齿面局部上都是一个圆柱，其半径为该处渐开线的曲率半径；因此两个轮齿的接触在很好的近似下就是两个平行圆柱在法向力$W$作用下的接触。受载后两个圆柱压扁成一条窄的矩形接触带，接触带上的压力远高于轮齿中的任何弯曲应力。

::: proposition 两平行圆柱的赫兹接触 {#prop-hertz}
两个半径为$r_1$、$r_2$，长度为$l$，弹性模量为$E_1$、$E_2$，泊松比为$\nu_1$、$\nu_2$的长平行圆柱，在力$F$作用下相互压紧。它们在半宽为
$$
b = \sqrt{\frac{4F}{\pi l}\cdot\frac{\dfrac{1 - \nu_1^2}{E_1} + \dfrac{1 - \nu_2^2}{E_2}}{\dfrac{1}{r_1} + \dfrac{1}{r_2}}}
$$ {#eq-hertz-b}
的接触带上接触，接触带上的压力呈椭圆分布，$p(x) = p_{\max}\sqrt{1 - x^2/b^2}$，其最大值为
$$
p_{\max} = \frac{2F}{\pi bl}, \qquad p_{\max}^2 = \frac{F}{\pi l}\cdot\frac{\dfrac{1}{r_1} + \dfrac{1}{r_2}}{\dfrac{1 - \nu_1^2}{E_1} + \dfrac{1 - \nu_2^2}{E_2}}.
$$ {#eq-hertz-p}
:::

::: proof
**假设。** (1) 材料均匀、各向同性、线弹性。(2) 接触半宽远小于半径，因此计算变形时每个物体都可看作弹性半空间（此处为半平面，因为圆柱很长、处于平面应变）。(3) 表面光滑无摩擦，只传递法向压力。(4) 两轴线平行，载荷沿长度均匀分布。

**几何。** 取$x$横贯接触带，以最初接触点为原点。加载前两表面之间的间隙近似为$h(x) = x^2/(2r_1) + x^2/(2r_2) = x^2/(2R)$，其中$1/R = 1/r_1 + 1/r_2$（每个圆用其密切抛物线近似）。加载后，两物体以刚体位移$\delta$相互趋近，表面被弹性位移$u_1(x)$和$u_2(x)$压入（以指向各自物体内部为正）。在接触带内两表面重合：
$$
u_1(x) + u_2(x) = \delta - \frac{x^2}{2R}, \qquad\text{所以}\qquad \frac{d(u_1 + u_2)}{dx} = -\frac{x}{R} \quad (|x| < b).
$$

**半平面的位移。** 对于平面应变的半平面，表面受压力$p(s)$作用时，表面法向位移的斜率为（Johnson，*Contact Mechanics*，1985，§2.7）
$$
\frac{du}{dx} = -\frac{2(1 - \nu^2)}{\pi E}\,\mathrm{PV}\!\!\int_{-b}^{b}\frac{p(s)}{x - s}\,ds,
$$
其中 PV 表示柯西主值。试取椭圆压力$p(s) = p_{\max}\sqrt{1 - s^2/b^2}$。令$s = b\tau$，并利用标准的主值积分$\mathrm{PV}\!\int_{-1}^{1}\sqrt{1 - \tau^2}/(\xi - \tau)\,d\tau = \pi\xi$（$|\xi| < 1$），
$$
\mathrm{PV}\!\!\int_{-b}^{b}\frac{p(s)}{x - s}\,ds = p_{\max}\,\pi\frac{x}{b}, \qquad \frac{du_i}{dx} = -\frac{2(1 - \nu_i^2)}{E_i}\cdot\frac{p_{\max}x}{b}.
$$
斜率是$x$的线性函数，正如几何条件所要求的——这正是椭圆分布为解的原因。

**匹配。** 把两个物体的结果相加并令其等于$-x/R$：
$$
\frac{2p_{\max}}{b}\left(\frac{1 - \nu_1^2}{E_1} + \frac{1 - \nu_2^2}{E_2}\right) = \frac{1}{R}, \qquad\text{所以}\qquad p_{\max} = \frac{b}{2R\Sigma}, \quad \Sigma = \frac{1 - \nu_1^2}{E_1} + \frac{1 - \nu_2^2}{E_2}.
$$
**平衡。** 压力必须与载荷平衡：$F = l\int_{-b}^{b}p\,dx = l\,p_{\max}\,\pi b/2$（半椭圆的面积），所以$p_{\max} = 2F/(\pi bl)$。

**求解。** 令$p_{\max}$的两个表达式相等：$b^2 = 4FR\Sigma/(\pi l)$，即[[#eq-hertz-b]]，其中$R = 1/(1/r_1 + 1/r_2)$。于是$p_{\max}^2 = b^2/(4R^2\Sigma^2) = F/(\pi lR\Sigma)$，即[[#eq-hertz-p]]。压力在$x = \pm b$处降为零，与光滑表面相切分离的情况一致。
:::

这一结果的两个特点决定了齿轮设计。第一，$p_{\max} \propto \sqrt F$：接触应力只随载荷的平方根增长。第二，应力最大的点不在表面上。接触区下方材料处于三向受压状态，最大切应力约为$0.30\,p_{\max}$，出现在约$0.78\,b$的深度处（Johnson，§4.2）。接触疲劳裂纹在该深度附近或从表面缺陷处萌生、扩展，剥落出小片，留下一个**点蚀坑**。由于这种应力是压力，齿轮强度计算中的“接触应力”要与由齿轮试验得到的经验**接触疲劳强度**比较，而不是与抗拉强度或屈服强度比较。

每种材料的两个弹性常数只以组合$\Sigma$的形式出现，因此 AGMA 定义了**弹性系数**
$$
Z_E = \sqrt{\frac{1}{\pi\left(\dfrac{1 - \nu_P^2}{E_P} + \dfrac{1 - \nu_G^2}{E_G}\right)}},
$$ {#eq-ze}
$E$以 MPa 计时其单位为$\sqrt{\mathrm{MPa}}$（在美国惯用单位中写作$C_p$）。对$E = 207\ \mathrm{GPa}$、$\nu = 0.30$的钢对钢：
$$
Z_E = \sqrt{\frac{1}{\pi\times2\times0.91/207\,000}} = \sqrt{36\,200\ \mathrm{MPa}} = 190.3\ \sqrt{\mathrm{MPa}},
$$
Budynas 与 Nisbett（表 14-8）列出的值为$191\ \sqrt{\mathrm{MPa}}$（由$2300\ \sqrt{\mathrm{psi}}$换算）。铸铁或青铜齿轮弹性模量较低，$Z_E$较小，同样载荷下接触应力较低——但其接触强度也低得多。

### 赫兹理论用于轮齿

::: proposition 节点处的接触应力 {#prop-gear-contact}
对于外啮合直齿圆柱齿轮副，小齿轮分度圆直径为$d_P$，传动比$m_G = d_G/d_P$，压力角$\phi$，齿宽$F$，圆周载荷$W_t$，节点处的赫兹接触应力为
$$
\sigma_C = Z_E\sqrt{\frac{W_t}{F\cos\phi}\left(\frac{1}{r_1} + \frac{1}{r_2}\right)} = Z_E\sqrt{\frac{W_t}{d_PF\,Z_I}}, \qquad r_1 = \frac{d_P\sin\phi}{2},\quad r_2 = \frac{d_G\sin\phi}{2},
$$ {#eq-gear-contact}
其中**接触几何系数**为
$$
Z_I = \frac{\cos\phi\sin\phi}{2}\cdot\frac{m_G}{m_G + 1}.
$$ {#eq-zi}
:::

::: proof
**假设。** 与[[#prop-hertz]]相同；一对轮齿承担载荷（对通常的重合度，节点一般位于单齿啮合区内）；载荷沿齿宽均匀；齿面无摩擦。

轮齿间的法向力为$W = W_t/\cos\phi$（[[#eq-spur-forces]]），作用在长度$F$上。渐开线上一点的曲率半径等于该点到基圆的切线长；在节点处为$\sqrt{(d/2)^2 - r_b^2} = (d/2)\sin\phi$，由此得$r_1$和$r_2$。在[[#eq-hertz-p]]中代入$F \to W_t/\cos\phi$、$l \to F$并利用[[#eq-ze]]，得到第一种形式。对于第二种形式，
$$
\frac{1}{r_1} + \frac{1}{r_2} = \frac{2}{\sin\phi}\left(\frac{1}{d_P} + \frac{1}{m_Gd_P}\right) = \frac{2}{d_P\sin\phi}\cdot\frac{m_G + 1}{m_G},
$$
所以
$$
\frac{W_t}{F\cos\phi}\left(\frac{1}{r_1} + \frac{1}{r_2}\right) = \frac{W_t}{d_PF}\cdot\frac{2(m_G + 1)}{m_G\cos\phi\sin\phi} = \frac{W_t}{d_PF\,Z_I}.
$$
:::

对于内齿轮（齿圈），两个齿面弯曲方向相同，$1/r_1 + 1/r_2$变为$1/r_1 - 1/r_2$，$m_G/(m_G + 1)$变为$m_G/(m_G - 1)$——这是一种贴合较好的接触，应力较低（见[[#ex-internal]]）。对 20° 齿，$\cos\phi\sin\phi/2 = 0.1607$；$m_G = 2$时$Z_I = 0.1071$。在 AGMA 的美国惯用单位符号中$Z_I$写作$I$。

形式$\sigma_C = Z_E\sqrt{W_t/(d_PFZ_I)}$揭示了主要的设计手段。由于$W_t = 2T/d_P$，$\sigma_C \propto \sqrt{T/(d_P^2F)}$：齿面接触强度取决于小齿轮直径和齿宽——即齿轮的尺寸——而**不**取决于模数。弯曲应力则强烈依赖于模数。这一差别就是下图的主题。

$$

::: warning 齿轮应力计算中的常见错误
- **直接比较两个安全因数。** 弯曲应力与载荷成正比，接触应力与载荷的平方根成正比。接触安全因数$S_H = 1.2$（以应力计）对载荷而言只有$1.2^2 = 1.44$。要比较$S_F$与$S_H^2$才能看出哪种失效起控制作用（对点接触的鼓形齿，$\sigma_C \propto W^{1/3}$，要与$S_H^3$比较）。
- **混淆两种齿形系数。** 路易斯$Y$（不计应力集中、齿顶加载）和 AGMA 几何系数$Y_J$（计入圆角应力集中和载荷分担）是不同的数，用于不同的公式。同样，相对于模数定义的$Y$是相对于齿距定义的$y$的$\pi$倍。
- **用错速度系数的约定。** 现行教材中$K_v \ge 1$乘在载荷上；较早的教材中它$\le 1$，用来除载荷。
- **在斜齿轮的法面中使用端面数值**（或反之）：$d = m_tz$，而不是$m_nz$，刀具的压力角是$\phi_n$。
- **忘记校核大齿轮。** 弯曲通常由小齿轮控制，但大齿轮循环次数较少、材料常常较软，可能控制点蚀；两个齿轮都必须用各自的强度和寿命系数校核。
- **单位。** $W_t$以 N、长度以 mm 计时，应力单位为$\mathrm{N/mm^2} = \mathrm{MPa}$，$Z_E$必须以$\sqrt{\mathrm{MPa}}$计。
:::

## 齿轮强度计算：AGMA 方法与 ISO 方法

路易斯公式和赫兹公式是一切现代强度计算方法所用的两个应力公式的核心。在美国，齿轮按 ANSI/AGMA 2001-D04《渐开线直齿和斜齿圆柱齿轮轮齿的基本强度系数与计算方法》（*Fundamental Rating Factors and Calculation Methods for Involute Spur and Helical Gear Teeth*，米制版为 ANSI/AGMA 2101-D04）计算；在国际上以及欧洲和中国，按 ISO 6336 计算（第 1 至第 3 部分，2019 年版，分别为基本原理、齿面接触强度和齿根弯曲强度；第 5 部分为材料强度）。两种方法的具体系数不同，但结构相同：在实际工况下对实际齿轮计算弯曲应力和接触应力，方法是把名义应力乘以一系列**载荷系数**，以计入简单理论所忽略的一切因素；由在齿轮上测得的材料强度，经寿命、温度和可靠度修正，算出许用应力；然后求它们的比值。下面的概述按 Budynas 与 Nisbett（§14-3 至 §14-5）所介绍的 AGMA 国际单位制形式进行。它讲的是各系数的含义；实际齿轮必须按完整的标准及其表格、图线和适用条件进行计算。

AGMA 把**弯曲应力**和**接触应力**写成
$$
\sigma = W_tK_oK_vK_s\,\frac{1}{F\,m_t}\,\frac{K_HK_B}{Y_J},
$$ {#eq-agma-bending}
$$
\sigma_C = Z_E\sqrt{W_tK_oK_vK_s\,\frac{K_H}{d_PF}\,\frac{Z_R}{Z_I}},
$$ {#eq-agma-contact}
其中$m_t$为端面模数，各系数为：

- $K_o$，**过载系数**（ISO 中称使用系数）：考虑原动机和工作机引起的高于名义$W_t$的载荷（例如来自往复式发动机或破碎机的冲击）。原动机和负载都均匀时$K_o = 1$；更高的值取自标准中的表格或实测载荷谱。
- $K_v$，**动载系数**：Barth 系数的 AGMA 继承者，取决于节线速度和传动精度等级$Q_v$（$Q_v$越高，齿轮越精确）。Budynas 与 Nisbett（式 14-27）给出
$$
K_v = \left(\frac{A + \sqrt{200V}}{A}\right)^B, \qquad A = 50 + 56(1 - B), \qquad B = 0.25(12 - Q_v)^{2/3},
$$ {#eq-agma-kv}
$V$以 m/s 计，适用于$V_{\max} = [A + (Q_v - 3)]^2/200$ m/s 以下。
- $K_s$，**尺寸系数**：考虑大尺寸轮齿强度较低（受应力体积较大、热处理效果较差）。AGMA 建议除非有理由，否则取$K_s = 1$；Budynas 与 Nisbett 给出了一个基于路易斯$Y$的估算式。
- $K_H$（美国惯用单位中写作$K_m$），**载荷分布系数**（齿向载荷分布系数）：单位齿宽上的峰值载荷与平均值之比，由轴和箱体的变形、不对中和螺旋线误差引起。它通常在约$1.1$到$2$之间，随齿宽增大而增大，常常是计算中最大的不确定因素。
- $K_B$，**轮缘厚度系数**：实体齿轮或厚轮缘为$1$；薄轮缘随轮齿一起弯曲时更大。
- $Y_J$（美国惯用$J$），**弯曲几何系数**：它取代路易斯的$Y$，计入齿根圆角的应力集中以及轮齿间的载荷分担，危险载荷作用在单齿啮合区的最高点。它从图线（AGMA 908）中查取或计算得到；对 20–40 齿的 20° 全齿高直齿小齿轮，它约在$0.3$–$0.4$量级。
- $Z_I$（美国惯用$I$），**接触几何系数**，对直齿轮即[[#eq-zi]]（$m_N = 1$；对斜齿轮还要除以载荷分担比$m_N$）；$Z_R$（美国惯用$C_f$），**表面状况系数**，一般表面取$1$。

许用应力为
$$
\sigma_{\text{all}} = \frac{S_t}{S_F}\,\frac{Y_N}{Y_\theta Y_Z}, \qquad \sigma_{C,\text{all}} = \frac{S_c}{S_H}\,\frac{Z_NZ_W}{Y_\theta Y_Z},
$$ {#eq-agma-allow}
其中$S_t$和$S_c$为 AGMA 弯曲和接触**强度**（许用应力值），在单向加载、$10^7$次循环、99% 可靠度条件下在齿轮上测得；$Y_N$和$Z_N$为把它们换算到其他寿命的**应力循环系数**（寿命系数）；$Y_\theta$（美国惯用$K_T$）为温度系数，约$120\ °\mathrm{C}$以下取$1$；$Y_Z$（美国惯用$K_R$）为可靠度系数，99% 时取$1$；$Z_W$（美国惯用$C_H$）为硬度比系数，对与较硬小齿轮配对的较软大齿轮给予少许提高。**安全因数**定义为应力之比，
$$
S_F = \frac{S_tY_N/(Y_\theta Y_Z)}{\sigma}, \qquad S_H = \frac{S_cZ_NZ_W/(Y_\theta Y_Z)}{\sigma_C}.
$$ {#eq-sf-sh}
作为初步估算，Budynas 与 Nisbett（图 14-2 和图 14-5）把 AGMA 1 级调质钢的强度拟合为
$$
S_t = 0.533H_B + 88.3\ \mathrm{MPa}, \qquad S_c = 2.22H_B + 200\ \mathrm{MPa},
$$ {#eq-strengths}
$H_B$为布氏硬度；并把钢在约$3\times10^6$次循环以上的应力循环系数（其图 14-14 和图 14-15 的上方曲线）拟合为
$$
Y_N = 1.3558\,N^{-0.0178}, \qquad Z_N = 1.4488\,N^{-0.023}.
$$ {#eq-life-factors}
渗碳淬火钢（表面 58–64 HRC）的表面强度高得多：同一文献给出 1 级的$S_c$约为$1240\ \mathrm{MPa}$。

::: algorithm 直齿圆柱齿轮副的强度计算（AGMA 结构） {#alg-rating}
1. 由工况确定功率、转速、每个齿轮的寿命循环次数、可靠度和工作温度。计算$W_t$和$V$（[[#prop-forces]]）。
2. 确定几何参数：$m$、$z_P$、$z_G$、$F$、$\phi$；校核根切和重合度（[[#prop-contact-ratio]]）以及比例$3\pi m \le F \le 5\pi m$。
3. 选取载荷系数：由原动机和负载确定$K_o$，按精度等级由[[#eq-agma-kv]]确定$K_v$，确定$K_s$，由安装情况确定$K_H$，由轮缘确定$K_B$。
4. 对每个齿轮查取$Y_J$，由[[#eq-agma-bending]]计算$\sigma$；求$Z_I$、$Z_E$，由[[#eq-agma-contact]]计算$\sigma_C$（一对齿轮一个值）。
5. 对每个齿轮，按材料和热处理确定$S_t$、$S_c$，按其自身的循环次数确定寿命系数$Y_N$、$Z_N$，以及$Y_\theta$、$Y_Z$、$Z_W$；由[[#eq-sf-sh]]计算$S_F$和$S_H$。
6. 比较$S_F$与$S_H^2$，找出起控制作用的失效形式。若其中之一过低，则增大齿宽或直径（接触）或模数（弯曲），或选用更硬的材料或表面处理，然后重复。
:::

::: example 减速器小齿轮的强度计算 {#ex-agma}
对[[#ex-lewis]]中减速器的小齿轮（$m = 4\ \mathrm{mm}$，$z_P = 20$，$z_G = 40$，$F = 40\ \mathrm{mm}$，$W_t = 2487\ \mathrm{N}$，$V = 6.032\ \mathrm{m/s}$）进行强度计算，寿命为在$1440\ \mathrm{rev/min}$下工作$20\,000$小时。取$K_o = 1.25$（电动机驱动，工作机有中等冲击），精度等级$Q_v = 7$，$K_s = 1$，$K_H = 1.3$，$K_B = 1$，$Z_R = 1$，$Z_W = 1$，该齿形给定的几何系数$Y_J = 0.33$。小齿轮为$300\ \mathrm{HB}$的 1 级调质钢，可靠度 99%，温度低于$120\ °\mathrm{C}$（$Y_\theta = Y_Z = 1$）。
::: solution
**动载系数。** $B = 0.25\times5^{2/3} = 0.7310$，$A = 50 + 56\times0.2690 = 65.06$，
$$
K_v = \left(\frac{65.06 + \sqrt{200\times6.032}}{65.06}\right)^{0.7310} = \left(\frac{65.06 + 34.73}{65.06}\right)^{0.7310} = 1.367.
$$
（$V_{\max} = (65.06 + 4)^2/200 = 23.8\ \mathrm{m/s}$，所以公式适用。）

**弯曲应力。** $W_tK_oK_vK_s = 2487\times1.25\times1.367 = 4250\ \mathrm{N}$；
$$
\sigma = \frac{4250}{40\times4}\times\frac{1.3\times1}{0.33} = 26.56\times3.939 = 104.6\ \mathrm{MPa}.
$$
**接触应力。** $Z_I = 0.10713$（取自[[#ex-contact]]），$Z_E = 190.3\ \sqrt{\mathrm{MPa}}$：
$$
\sigma_C = 190.3\sqrt{\frac{4250\times1.3}{80\times40\times0.10713}} = 190.3\sqrt{16.12} = 764\ \mathrm{MPa}.
$$
**强度。** 由[[#eq-strengths]]：$S_t = 0.533\times300 + 88.3 = 248.2\ \mathrm{MPa}$，$S_c = 2.22\times300 + 200 = 866\ \mathrm{MPa}$。小齿轮循环次数：$N = 1440\times60\times20\,000 = 1.728\times10^9$，所以$Y_N = 1.3558\times(1.728\times10^9)^{-0.0178} = 0.928$，$Z_N = 1.4488\times(1.728\times10^9)^{-0.023} = 0.888$。

**安全因数。**
$$
S_F = \frac{248.2\times0.928}{104.6} = 2.20, \qquad S_H = \frac{866\times0.888}{764} = 1.01.
$$
**哪一个起控制作用？** $S_H^2 = 1.01$，而$S_F = 2.20$：以载荷计，小齿轮防止轮齿折断的裕量是防止点蚀裕量的两倍多。点蚀起控制作用，而且裕量基本为零。

**改进措施。** 弯曲承载能力很充裕，所以模数无需改变。增大齿宽只按$\sqrt F$起作用，且受$K_H$限制。有效的办法是表面硬化：$S_c \approx 1240\ \mathrm{MPa}$的渗碳小齿轮给出$S_H = 1240\times0.888/764 = 1.44$，$S_H^2 = 2.08$——这时两种失效形式达到平衡。大齿轮（循环次数为一半，有其自身的$Y_J$）必须以同样方法计算。

**合理性检查。** [[#ex-lewis]]中的路易斯估算对同一轮齿给出$81.6\ \mathrm{MPa}$；AGMA 应力因过载系数和载荷分布系数（$1.25\times1.3 = 1.63$）以及由$Y$改为$Y_J$（应力集中，部分被载荷分担抵消；此处变化很小）而更高，又因精确齿轮的动载系数较小（$1.367$对$1.690$）而更低。
:::

::: quiz
一对直齿圆柱齿轮传递的转矩加倍，其他条件不变。节点处的接触应力变为原来的多少倍？
- [ ] 加倍。
- [x] 增大为$\sqrt2 \approx 1.41$倍。
- [ ] 增大为$2^{1/3} \approx 1.26$倍。

由[[#eq-gear-contact]]，$\sigma_C \propto \sqrt{W_t}$，而$W_t \propto T$。接触带宽度按$\sqrt{W_t}$增大，所以峰值压力的增长慢于载荷。（$2^{1/3}$规律适用于点接触，例如两个球之间。）弯曲应力则加倍。
:::

::: quiz
某小齿轮的 AGMA 计算给出弯曲安全因数$S_F = 1.5$，点蚀安全因数$S_H = 1.1$。哪一种失效形式更接近？
- [ ] 弯曲，因为$1.1 < 1.5$对弯曲没有意义。
- [x] 点蚀，因为防止点蚀的载荷裕量为$S_H^2 = 1.21$，低于$1.5$。
- [ ] 弯曲，因为$S_H^2 = 1.21$是应力裕量，必须与$\sqrt{S_F}$比较。

## 材料与表面处理

齿轮材料要同时满足两种强度：齿根的弯曲疲劳强度，需要韧性好的心部和良好的圆角表面；齿面的接触疲劳强度，需要硬的表面。主要的选择按承载能力和成本递增排列如下：

- **铸铁**（灰铸铁或球墨铸铁）和**青铜**：安静、便宜，在润滑不良时表现良好；青铜是与淬硬钢蜗杆配对的蜗轮的常用材料。强度低。
- **聚合物**（聚甲醛、尼龙，常加玻璃纤维）：轻、安静、自润滑，用于小载荷、中等温度；由于其强度强烈依赖于温度，按专门的方法计算。
- **调质钢**（碳钢和合金钢淬火回火到约$200$–$400\ \mathrm{HB}$）：轮齿可在热处理后切制，齿轮精度得以保持，但硬度——从而$S_c$——受到限制。小齿轮常比大齿轮硬$30$–$50\ \mathrm{HB}$，以均衡磨损，并使大齿轮获得硬度比系数$Z_W$的提高。
- **表面硬化钢**：**渗碳**（低碳合金钢表面渗入碳，淬火后表面约$58$–$64\ \mathrm{HRC}$，心部保持韧性）、**渗氮**（硬化层较薄、硬度很高、变形很小）以及中碳钢的**感应淬火或火焰淬火**。硬化层深度超过最大次表层切应力的深度——前面求得的深度$0.78b$再乘以充分的裕量——可使接触强度大约翻倍，并通过齿根处的残余压应力提高弯曲强度。渗碳齿轮淬火时会变形，通常随后要磨齿，这同时也提高了精度等级。

齿根圆角的**喷丸**增加残余压应力，提高弯曲疲劳强度，与弹簧的情形一样。润滑与材料同样重要：油膜把齿面隔开并带走热量；如果在高速重载下油膜破裂，齿面会局部焊合并撕裂——这就是**胶合**，一种不同于点蚀的失效形式，标准用闪温或积分温度判据来校核（ISO/TS 6336-20 和 -21）。

::: application 风力发电机组齿轮箱
兆瓦级风力发电机组通过齿轮箱驱动发电机，把风轮转速（约$10$–$15$ r/min）提高约 100 倍，通常第一级为行星级（[[mechanisms/gear-trains]]），其后为平行轴斜齿轮级。齿轮经渗碳和磨齿，按 ISO 6336 并结合风电行业设计标准 IEC 61400-4 计算，并且校核的是由湍流风仿真得出的载荷谱，而不是单一的设计载荷：多个载荷水平造成的累积损伤用寿命系数$Y_N$和$Z_N$及迈因纳法则（[[machine-design/fatigue]]）评估。现场经验表明，许多齿轮箱故障并非始于轮齿而是始于轴承，而载荷分布系数——结构变形时载荷沿齿宽分布的均匀程度——对轮齿寿命有决定性影响。
:::

::: history
渐开线齿廓在 18 世纪中叶由欧拉（Leonhard Euler）进行了分析，但直到齿轮能够用机床精确展成之后，它才取代了摆线齿廓（见[[mechanisms/gears]]）。第一个定量的轮齿强度计算出自路易斯（Wilfred Lewis）：1892 年 10 月 15 日他在费城工程师俱乐部（Engineers' Club of Philadelphia）作报告，1893 年以《齿轮轮齿强度的研究》（"Investigation of the Strength of Gear Teeth"）为题发表于该俱乐部的 *Proceedings*，他把轮齿看作悬臂梁，用内切抛物线确定其最弱截面，并列出了齿形系数表。赫兹（Heinrich Hertz）的论文《论弹性固体的接触》（"Über die Berührung fester elastischer Körper"，*Journal für die reine und angewandte Mathematik*，第 92 卷，1882 年）求解了弹性体的接触问题；这个问题起源于他对相互压紧的玻璃透镜之间干涉条纹的研究。美国齿轮制造商协会（AGMA）成立于 1916 年。20 世纪 20 年代，白金汉（Earle Buckingham）领导的 ASME 研究委员会用路易斯制造的试验机测量了轮齿上的动载荷，并于 1931 年发表了报告《轮齿上的动载荷》（*Dynamic Loads on Gear Teeth*）；白金汉的《齿轮分析力学》（*Analytical Mechanics of Gears*，McGraw-Hill，1949 年）成为齿轮几何与载荷方面的标准参考书。今天使用的强度计算方法 ANSI/AGMA 2001-D04 和 ISO 6336 是路易斯和赫兹分析的后继者，经过了数十年齿轮试验的完善；本章讲授的是它们背后的原理，而不是它们的替代品。
:::

::: summary
- 米制直齿圆柱齿轮：$d = mz$，$p = \pi m$，齿顶高$m$，齿根高$1.25m$，基圆半径$(d/2)\cos\phi$，$C = m(z_P + z_G)/2$；重合度$m_c = Z/(\pi m\cos\phi)$，至少约为$1.2$（[[#prop-contact-ratio]]）。
- 力：$W_t = 2T/d = H/V$，$W_r = W_t\tan\phi$；斜齿轮还有$W_a = W_t\tan\psi$，且$\tan\phi_n = \tan\phi_t\cos\psi$。
- 弯曲（路易斯）：$\sigma = K_vW_t/(FmY)$，来自内切等强度抛物线的悬臂梁；$Y$查表，20 齿时为$0.322$，齿条为$0.485$。
- 接触（赫兹）：$p_{\max}^2 = \dfrac{F}{\pi l}\dfrac{1/r_1 + 1/r_2}{\Sigma(1 - \nu^2)/E}$；对齿轮$\sigma_C = Z_E\sqrt{W_t/(d_PFZ_I)}$，钢对钢$Z_E \approx 190\ \sqrt{\mathrm{MPa}}$，$Z_I = \tfrac12\cos\phi\sin\phi\,m_G/(m_G + 1)$。
- 弯曲应力与载荷成正比并取决于模数；接触应力与载荷的平方根成正比，取决于小齿轮直径和齿宽。
- 强度计算（ANSI/AGMA 2001-D04，ISO 6336）：应力乘以$K_o$、$K_v$、$K_s$、$K_H$、$K_B$，几何系数为$Y_J$、$Z_I$；强度用$Y_N$、$Z_N$、$Y_\theta$、$Y_Z$、$Z_W$修正；比较$S_F$与$S_H^2$。
- 表面硬化（渗碳、渗氮、感应淬火）是提高抗点蚀能力的主要手段。
:::

## 习题

::: exercise 齿轮尺寸 {level=1 check="96"}
一个标准 20° 全齿高直齿圆柱齿轮，$m = 3\ \mathrm{mm}$，$z = 30$。求其分度圆、齿顶圆、齿根圆和基圆直径以及齿距。（输入齿顶圆直径，单位 mm。）
::: solution
$d = mz = 90\ \mathrm{mm}$；$d_a = d + 2m = 96\ \mathrm{mm}$；$d_f = d - 2.5m = 82.5\ \mathrm{mm}$；$d_b = d\cos20° = 84.57\ \mathrm{mm}$；$p = \pi m = 9.425\ \mathrm{mm}$。这里基圆位于齿根圆之上，凡齿数少于约 42 的标准齿轮都是如此（$z(1 - \cos20°) < 2.5$）；齿面在基圆以下的部分不可能是渐开线，其形状由过渡圆角决定。
:::
:::

::: exercise 圆周力 {level=1 check="2000"}
一个齿轮以$5\ \mathrm{m/s}$的节线速度传递$10\ \mathrm{kW}$；$\phi = 20°$。求圆周力和径向力。（输入圆周力，单位 N。）
::: solution
$W_t = H/V = 10\,000/5 = 2000\ \mathrm{N}$；$W_r = 2000\tan20° = 728\ \mathrm{N}$；合力为$2000/\cos20° = 2128\ \mathrm{N}$。
:::
:::

::: exercise 路易斯应力 {level=1 check="50"}
一个 50 齿直齿圆柱齿轮，$m = 4\ \mathrm{mm}$，$F = 30\ \mathrm{mm}$，低速下承受$W_t = 2454\ \mathrm{N}$。不计速度系数，求路易斯弯曲应力。（输入应力，单位 MPa。）
::: solution
查表，$z = 50$时$Y = 0.409$：$\sigma = W_t/(FmY) = 2454/(30\times4\times0.409) = 2454/49.08 = 50.0\ \mathrm{MPa}$。
:::
:::

::: exercise 相同齿轮的重合度 {level=2}
两个相同的标准 20° 全齿高齿轮，$z = 30$，$m = 5\ \mathrm{mm}$，在标准中心距啮合。求重合度。
::: solution
$r = 75\ \mathrm{mm}$，$r_a = 80\ \mathrm{mm}$，$r_b = 75\cos20° = 70.477\ \mathrm{mm}$，$C = 150\ \mathrm{mm}$。$Z = 2\sqrt{80^2 - 70.477^2} - 150\sin20° = 2\times37.854 - 51.303 = 24.41\ \mathrm{mm}$；$p_b = 5\pi\cos20° = 14.761\ \mathrm{mm}$；$m_c = 1.65$。与[[#ex-geometry]]（20/40 齿，$1.64$）比较：重合度取决于齿数，而与模数无关。
:::
:::

::: exercise 斜齿轮的力 {level=2}
一个$\phi_n = 20°$、$\psi = 30°$的斜齿轮传递$W_t = 3000\ \mathrm{N}$。求端面压力角以及径向力、轴向力和总力。
::: solution
$\tan\phi_t = \tan20°/\cos30° = 0.36397/0.86603 = 0.42028$，$\phi_t = 22.80°$。$W_r = 3000\times0.42028 = 1261\ \mathrm{N}$；$W_a = 3000\tan30° = 1732\ \mathrm{N}$；$W = 3000/(\cos20°\cos30°) = 3686\ \mathrm{N}$。校核：$\sqrt{3000^2 + 1261^2 + 1732^2} = 3686\ \mathrm{N}$。
:::
:::

::: exercise 为降低接触应力而加宽齿面 {level=2 check="1.5625"}
要通过加宽齿面使小齿轮的接触应力降低 20%，载荷、直径和载荷系数不变。齿宽必须增大为原来的多少倍？（输入倍数。）
::: solution
$\sigma_C \propto 1/\sqrt F$，所以$\sqrt{F_1/F_2} = 0.8$，$F_2/F_1 = 1/0.64 = 1.5625$。实际上$K_H$随齿宽增大，所以真正需要的增量更大——而且齿宽增大$56$% 可能超出 3–5 个齿距的指导范围。增大小齿轮直径通常是更好的手段，因为转矩一定时$\sigma_C \propto 1/d_P$。
:::
:::

::: exercise 用 Barth 系数求许用载荷 {level=2 check="1738.8"}
一个 20 齿切制钢小齿轮，$m = 3\ \mathrm{mm}$，$F = 36\ \mathrm{mm}$，节线速度为$6.1\ \mathrm{m/s}$。许用弯曲应力为$100\ \mathrm{MPa}$。用路易斯公式和切制齿形的 Barth 系数，求许用圆周载荷。（输入载荷，单位 N。）
::: solution
$K_v = (6.1 + 6.1)/6.1 = 2$；$Y = 0.322$。$W_t = \sigma_{\text{all}}FmY/K_v = 100\times36\times3\times0.322/2 = 1738.8\ \mathrm{N}$。相应的功率为$1738.8\times6.1 = 10.6\ \mathrm{kW}$。同样尺寸的磨齿小齿轮（$K_v = (5.56 + \sqrt{6.1})/5.56 = 1.444$）可多承载 38%。
:::
:::

::: exercise 钢对铸铁的弹性系数 {level=2}
求钢制小齿轮（$E = 207\ \mathrm{GPa}$，$\nu = 0.30$）与灰铸铁大齿轮（$E = 100\ \mathrm{GPa}$，$\nu = 0.26$）配对时的$Z_E$，以及同样载荷下其接触应力与钢对钢齿轮副之比。
::: solution
$\Sigma = 0.91/207\,000 + 0.9324/100\,000 = 4.396\times10^{-6} + 9.324\times10^{-6} = 1.372\times10^{-5}\ \mathrm{MPa^{-1}}$；$Z_E = 1/\sqrt{\pi\times1.372\times10^{-5}} = 152.3\ \sqrt{\mathrm{MPa}}$。接触应力是钢对钢值的$152.3/190.3 = 0.80$：较软的齿轮压扁得更多，使载荷分布在更宽的接触带上。这对齿轮副是好是坏，取决于铸铁的接触强度，而它比淬硬钢低得多。
:::
:::

::: exercise 内齿轮 {#ex-internal level=3}
(a) 对与内齿轮（齿圈）啮合的小齿轮重复[[#prop-gear-contact]]的证明，此时齿圈的齿面是凹的，证明$Z_I = \tfrac12\cos\phi\sin\phi\,m_G/(m_G - 1)$。(b) 对$m_G = 3$，与同样传动比、同样小齿轮和载荷的外啮合齿轮相比，接触应力降低为多少倍？(c) 为什么这使行星齿轮箱适合传递大转矩？
::: solution
(a) 在节点处，齿圈齿面的曲率半径为$r_2 = (d_G/2)\sin\phi$，但其弯曲方向与小齿轮齿面相同，所以在赫兹间隙函数中$1/R = 1/r_1 - 1/r_2$。于是$1/r_1 - 1/r_2 = \dfrac{2}{d_P\sin\phi}\left(1 - \dfrac{1}{m_G}\right) = \dfrac{2(m_G - 1)}{d_P m_G\sin\phi}$，与前面相同的代数运算给出$Z_I = \dfrac{\cos\phi\sin\phi}{2}\cdot\dfrac{m_G}{m_G - 1}$。
(b) $\sigma_C \propto 1/\sqrt{Z_I}$，所以比值为$\sqrt{(m_G - 1)/(m_G + 1)} = \sqrt{2/4} = 0.707$：约低 29%。
(c) 在行星级中，行星轮与太阳轮啮合（外啮合，凸对凸），也与齿圈啮合（内啮合，凸对凹）；齿圈啮合是应力较低的一方。更重要的是载荷由几个行星轮分担，所以行星级能在小得多的体积内传递给定的转矩（[[mechanisms/gear-trains]]）；通常是太阳轮与行星轮的外啮合起控制作用。
:::
:::

::: exercise 设计一对齿轮 {level=3}
一个$z_P = 20$的小齿轮由电动机以$960\ \mathrm{rev/min}$驱动，向$z_G = 60$的大齿轮传递$5\ \mathrm{kW}$。要求寿命为小齿轮$10^9$转；$K_o = 1.25$，$Q_v = 7$，$K_H = 1.3$，$K_s = K_B = Z_R = Z_W = Y_\theta = Y_Z = 1$，小齿轮$Y_J = 0.33$；钢对钢。选择模数（ISO 54 值）和齿宽（$3\pi m \le F \le 5\pi m$），使小齿轮$S_F \ge 1.5$且$S_H \ge 1.2$：(a) 采用$300\ \mathrm{HB}$调质钢；(b) 采用渗碳小齿轮（$S_t \approx 380\ \mathrm{MPa}$，$S_c \approx 1240\ \mathrm{MPa}$）。比较尺寸，并列出设计完成前还必须校核的内容。
::: solution
**共同数据。** $Z_I = 0.1607\times3/4 = 0.1205$；$Y_N = 1.3558\times(10^9)^{-0.0178} = 0.938$，$Z_N = 1.4488\times(10^9)^{-0.023} = 0.900$；$Q_v = 7$时$A = 65.06$，$B = 0.7310$。

**(a) 调质钢，$S_t = 248.2$，$S_c = 866\ \mathrm{MPa}$。** 试取$m = 3$，$F = 36\ \mathrm{mm}$：$d_P = 60\ \mathrm{mm}$，$V = 3.016\ \mathrm{m/s}$，$W_t = 1658\ \mathrm{N}$，$K_v = 1.264$。$\sigma = 1658\times1.25\times1.264/(36\times3)\times1.3/0.33 = 95.5\ \mathrm{MPa}$，$S_F = 2.44$；$\sigma_C = 190.3\sqrt{1658\times1.25\times1.264\times1.3/(60\times36\times0.1205)} = 688\ \mathrm{MPa}$，$S_H = 866\times0.900/688 = 1.13$——太低。把齿宽加到上限$5\pi m = 47\ \mathrm{mm}$，在纸面上可得$S_H \approx 1.13\sqrt{47/36} = 1.29$，但$K_H$随齿宽增大；增大直径是更可靠的手段。改用$m = 3.5$（第二系列），$F = 35\ \mathrm{mm}$：$d_P = 70\ \mathrm{mm}$，$W_t = 1421\ \mathrm{N}$，$K_v = 1.284$，$\sigma = 73.3\ \mathrm{MPa}$，$S_F = 3.17$；$\sigma_C = 603\ \mathrm{MPa}$，$S_H = 1.29$。或用第一系列$m = 4$，$F = 40\ \mathrm{mm}$（$d_P = 80\ \mathrm{mm}$）：$S_F = 4.67$，$S_H = 1.57$。各方案中都是点蚀起控制作用；弯曲远非临界。

**(b) 渗碳小齿轮。** $m = 2.5$，$F = 30\ \mathrm{mm}$：$d_P = 50\ \mathrm{mm}$，$V = 2.513\ \mathrm{m/s}$，$W_t = 1989\ \mathrm{N}$，$K_v = 1.242$，$\sigma = 162.2\ \mathrm{MPa}$，$S_F = 380\times0.938/162.2 = 2.20$；$\sigma_C = 897\ \mathrm{MPa}$，$S_H = 1240\times0.900/897 = 1.24$。小齿轮直径从$70$降到$50\ \mathrm{mm}$，中心距从$140$降到$100\ \mathrm{mm}$——齿轮箱体积大约减半，代价是渗碳和磨齿。

**尚需校核。** 大齿轮（其自身的$Y_J$、材料和$Z_W$，$3.3\times10^8$次循环）；根切（20 齿高于最少齿数 18）和重合度；用力$W_t$、$W_r$校核轴和轴承（[[machine-design/shafts]]，[[machine-design/bearings]]）；润滑与胶合；由轴的变形求得的实际$K_H$；公差与精度等级；对实际产品，还要按 ISO 6336 或 ANSI/AGMA 2001-D04 进行完整的强度计算，而不是这些估算。
