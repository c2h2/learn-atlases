汽车从静止起步、电梯在楼层停住、带载起动的输送机、由电动机通过带传动驱动的车床，都有赖于被有意利用的摩擦。**离合器**把以不同转速转动的两根轴连接起来，使它们达到共同的转速；**制动器**做同样的事，只不过其中一根"轴"是静止的机架；绕在带轮上的**带**或**制动带**依靠分布在接触弧上的摩擦传递转矩。**链**以啮合而非摩擦完成与带相同的工作。这些元件外形各异，但其分析建立在三个共同的概念之上，本章即围绕它们组织：

1. **转矩容量**由摩擦力在接触面上的积分得到，这需要对压强如何分布作出假设（[[statics/friction]]提供了库仑摩擦定律$f = \mu N$）。
2. 只要表面打滑就会耗散**能量**，由此引起的温升——而不是转矩——通常是离合器或制动器的限制因素。
3. 把柔性件**包绕**在鼓轮上，会使摩擦随包角按指数倍增。

符号约定：转矩和角速度以驱动方向为正；带和制动带中的张力以受拉为正。除非另有说明，摩擦因数$\mu$均为动（滑动）摩擦因数。

## 圆盘离合器与制动器

圆盘（片式）离合器用轴向力$F$把外径$D$、内径$d$的环形摩擦衬片压在配对的盘上。汽车离合器有一片从动盘，两面都有衬片，因此有两个摩擦面；自动变速器或摩托车中的多片离合器则有许多个。每个摩擦面能传递的转矩取决于压强$p(r)$在环面上如何分布，有两个模型界定了实际情况。

::: definition 均匀压强与均匀磨损 {#def-models}
- **均匀压强：** $p$在各半径处相同。这适用于新的、精确平整、支承良好的盘。
- **均匀磨损：** 各半径处的磨损率相同。磨损被认为与单位面积的摩擦功成正比，即与$p$乘以滑动速度$\omega r$成正比，因此均匀磨损要求$pr = \text{常数}$。磨合后的离合器趋于这种状态，最大压强$p_{\max}$出现在内半径处。
:::

::: proposition 圆盘离合器的转矩容量 {#prop-disc}
对一个摩擦因数为$\mu$、外径$D$、内径$d$、轴向力$F$的摩擦面：
$$
\text{均匀磨损：}\quad F = \frac{\pi p_{\max}d}{2}(D - d), \qquad T = \frac{\mu F}{4}(D + d) = \frac{\pi\mu p_{\max}d}{8}(D^2 - d^2);
$$ {#eq-wear}
$$
\text{均匀压强：}\quad F = \frac{\pi p}{4}(D^2 - d^2), \qquad T = \frac{\mu F}{3}\,\frac{D^3 - d^3}{D^2 - d^2}.
$$ {#eq-pressure}
有$N$个并联的摩擦面（同一轴向力通过所有摩擦面）时，转矩为$N$倍。
:::

::: proof
**假设。** 整个表面上为$\mu$恒定的库仑摩擦；压强只与半径有关；每个微元上的摩擦力沿切向作用，与相对滑动方向相反。

取半径$r$、宽度$dr$的圆环，面积为$2\pi r\,dr$。它承受法向力$dF = p\,2\pi r\,dr$，在半径$r$处的摩擦力为$\mu\,dF$，因此贡献转矩$dT = \mu p\,2\pi r^2\,dr$。

**均匀磨损。** 由$pr = C$且最大压强在内半径处，$C = p_{\max}d/2$。于是
$$
F = \int_{d/2}^{D/2} 2\pi C\,dr = \pi C(D - d) = \frac{\pi p_{\max}d}{2}(D - d), \qquad T = \int_{d/2}^{D/2} 2\pi\mu Cr\,dr = \pi\mu C\,\frac{D^2 - d^2}{4}.
$$
二者相除，$T/F = \mu(D^2 - d^2)/[4(D - d)] = \mu(D + d)/4$：摩擦力实际上作用在平均半径$(D + d)/4$处。

**均匀压强。** $F = p\,\pi(D^2 - d^2)/4$，$T = 2\pi\mu p\int_{d/2}^{D/2}r^2\,dr = \tfrac{2\pi\mu p}{3}\cdot\tfrac{D^3 - d^3}{8}$。二者相除即得[[#eq-pressure]]。
:::

两个模型相差不大：$d/D = 0.6$时，相同轴向力下均匀压强模型的转矩只高 2%。由于磨损后的离合器容量比新的略*小*，设计者采用偏于保守的均匀磨损公式。

均匀磨损的结果还回答了一个设计问题。如果衬片材料把压强限制在$p_{\max}$，而外径$D$由空间确定，内径取多大时转矩最大？令$x = d/D$，由[[#eq-wear]]得$T = \tfrac{\pi}{8}\mu p_{\max}D^3\,x(1 - x^2)$；令$d/dx[x(1 - x^2)] = 1 - 3x^2 = 0$得
$$
\frac{d}{D} = \frac{1}{\sqrt3} = 0.577.
$$ {#eq-optimum}
这个最优点很平坦：约$0.42$到$0.72$之间的任何值都在最大值的 10% 以内，所以实际离合器采用$0.5$–$0.7$的比值，同时也兼顾热容量和衬片寿命。

**锥形离合器**把半锥角为$\alpha$的锥形摩擦面压入配对的锥孔中。在锥面上重复积分，每个圆环上的法向力等于轴向力除以$\sin\alpha$，因此对均匀磨损
$$
T = \frac{\mu F}{4\sin\alpha}(D + d).
$$ {#eq-cone}
$\alpha$为$10$–$15°$时，锥面使给定轴向力下的转矩增大到$4$–$6$倍；小于约$8°$时锥面容易卡死，难以分离。

::: example 汽车离合器的转矩容量 {#ex-car}
一个单片干式离合器从动盘两面的衬片外径$250\ \mathrm{mm}$、内径$150\ \mathrm{mm}$；$\mu = 0.35$，衬片最大压强为$0.25\ \mathrm{MPa}$。按均匀磨损模型求压紧力和转矩容量。
::: solution
**受力图。** 压盘以力$F$把从动盘压向飞轮；从动盘两面的摩擦都传给变速器轴，因此$N = 2$个摩擦面承受同一个$F$。

**压紧力。** $F = \tfrac{\pi}{2}p_{\max}d(D - d) = \tfrac{\pi}{2}\times0.25\times10^6\times0.150\times0.100 = 5890\ \mathrm{N}$。

**转矩。** $T = N\,\mu F(D + d)/4 = 2\times0.35\times5890\times0.400/4 = 412\ \mathrm{N\,m}$。

**检查。** 转矩$250$–$300\ \mathrm{N\,m}$的汽车发动机需要约$1.3$–$1.5$的防滑裕度，以考虑衬片磨损、发热和扭转振动，所以这个尺寸是合适的。相同压紧力下按均匀压强计算为$1.021\times412 = 421\ \mathrm{N\,m}$。
:::
:::

## 能量、打滑时间与温升

离合器接合时，两侧打滑，直到达到共同转速。打滑期间离合器传递其全部摩擦转矩，转矩与滑差角速度之积在摩擦面上转化为热。能量只取决于转动惯量和转速，而与离合器无关。

::: proposition 离合器接合时耗散的能量 {#prop-energy}
转动惯量分别为$I_1$和$I_2$、以$\omega_1$和$\omega_2$转动的两根轴，通过一个传递恒定转矩$T$的离合器连接，且没有其他转矩作用。它们在打滑时间$t_s = \dfrac{I_1I_2(\omega_1 - \omega_2)}{T(I_1 + I_2)}$之后达到共同转速
$$
\omega_f = \frac{I_1\omega_1 + I_2\omega_2}{I_1 + I_2},
$$
转化为热的能量为
$$
E = \frac{I_1I_2}{2(I_1 + I_2)}(\omega_1 - \omega_2)^2.
$$ {#eq-engage}
:::

::: proof
**受力图。** 轴 1 受离合器转矩$-T$作用（减速）；轴 2 受$+T$作用（加速）；这对轴不受外转矩。

**最终转速。** 没有外转矩，对公共轴线的动量矩守恒：$I_1\omega_1 + I_2\omega_2 = (I_1 + I_2)\omega_f$。

**打滑时间。** $I_1\dot\omega_1 = -T$，$I_2\dot\omega_2 = T$，因此滑差角速度$\omega_1 - \omega_2$以恒定速率$T(1/I_1 + 1/I_2) = T(I_1 + I_2)/(I_1I_2)$下降，在$t_s$时降为零。

**能量。** 损失的能量是动能之差：
$$
E = \tfrac12I_1\omega_1^2 + \tfrac12I_2\omega_2^2 - \tfrac12(I_1 + I_2)\omega_f^2 = \frac{I_1I_2}{2(I_1 + I_2)}(\omega_1 - \omega_2)^2,
$$
展开$\omega_f^2$即可看出。等价地，$E = \int_0^{t_s}T(\omega_1 - \omega_2)\,dt$，即转矩乘以平均滑差角速度$(\omega_1 - \omega_2)/2$再乘以$t_s$，结果相同。能量与$T$无关：更强的离合器接合得更快，但耗散的热量相同。
:::

如果主动侧由电动机保持恒速（而不是惯性滑行），电动机在打滑期间提供额外的能量，离合器耗散的热量与从动侧获得的动能一样多——总共从电动机取得两倍的能量。

**温升。** 如果热量$E$在散失之前全部进入质量为$m$、比热容为$c$的物体，
$$
\Delta T = \frac{E}{mc}.
$$ {#eq-temp}
这是一次接合后整体温度的上界，因为打滑期间有一部分热量被传导和对流带走；它忽略了摩擦表面上高得多的**闪温**，而正是闪温使衬片劣化。对于反复接合，平均热输入必须与向周围环境的散热平衡，$\bar P = h A(T_s - T_\infty)$，其中$h$是表面传热系数，$A$是外露面积；这决定了允许的接合频率。衬片制造商给出温度极限以及压强与摩擦速度之积$p v$的极限。

::: example 通过离合器起动机器 {#ex-engage}
一个由电动机驱动的输入端，转动惯量$0.5\ \mathrm{kg\,m^2}$，以$2000\ \mathrm{rpm}$惯性滑行，通过离合器与一台静止的机器接合，该机器折算到离合器轴上的转动惯量为$2.0\ \mathrm{kg\,m^2}$。离合器转矩为$300\ \mathrm{N\,m}$。求共同转速、打滑时间、产生的热量，以及若全部热量由一个$5\ \mathrm{kg}$的钢制压盘（$c = 500\ \mathrm{J/(kg\,K)}$）吸收时的温升。
::: solution
$\omega_1 = 2000\times2\pi/60 = 209.4\ \mathrm{rad/s}$，$\omega_2 = 0$。

**共同转速。** $\omega_f = 0.5\times209.4/2.5 = 41.9\ \mathrm{rad/s} = 400\ \mathrm{rpm}$。

**打滑时间。** $t_s = 0.5\times2.0\times209.4/(300\times2.5) = 0.279\ \mathrm{s}$。

**能量。** $E = \tfrac{0.5\times2.0}{2\times2.5}\times209.4^2 = 8770\ \mathrm{J}$——为输入端动能$10\,960\ \mathrm{J}$的 80%。

**温度。** $\Delta T = 8770/(5\times500) = 3.5\ \mathrm{K}$。

**检查。** 一次接合无害；若每小时接合 100 次而无冷却，将增加$350\ \mathrm{K}$——因此决定工作制度的是冷却，而不是转矩。还要注意机器只达到$400\ \mathrm{rpm}$：实际上电动机持续驱动，打滑时间更长，热量更大。
:::
:::

## 制动器

制动器把机器或车辆的动能（有时还有势能）转化为热。质量为$M$的车辆以恒定减速度$a$从速度$v$制动到静止，能量为$\tfrac12Mv^2$，停车时间为$v/a$，制动功率在开始时为$Mav$，线性下降到零，平均为其一半。在长下坡时还必须以稳定的速率吸收势能，这就是持续制动（载货汽车、电梯、起重机）依赖缓速器或再生制动、以及制动器要按热负荷确定尺寸的原因。

::: example 汽车从 100 km/h 制动 {#ex-car-brake}
一辆$1500\ \mathrm{kg}$的汽车以$0.8g$从$100\ \mathrm{km/h}$制动到静止。前制动器吸收 70% 的能量，由两个各重$6\ \mathrm{kg}$的铸铁制动盘（$c = 460\ \mathrm{J/(kg\,K)}$）平均分担。求能量、停车时间、峰值制动功率和前制动盘的温升。
::: solution
$v = 27.78\ \mathrm{m/s}$，$a = 7.85\ \mathrm{m/s^2}$。

**能量。** $\tfrac12\times1500\times27.78^2 = 578.7\ \mathrm{kJ}$。

**时间。** $t = 27.78/7.85 = 3.54\ \mathrm{s}$。

**功率。** 开始时峰值$Mav = 1500\times7.85\times27.78 = 327\ \mathrm{kW}$，平均$164\ \mathrm{kW}$——超过大多数汽车发动机的输出功率。

**制动盘温度。** 每个前制动盘吸收$0.35\times578.7 = 202.5\ \mathrm{kJ}$；$\Delta T = 202\,500/(6\times460) = 73\ \mathrm{K}$。

**检查。** 制动过程中实际的盘表面温度高于这个整体值；反复紧急制动而无冷却时间，会使盘温升到几百摄氏度，衬片在那里开始热衰退，这就是制动盘要做成通风式的原因。
:::
:::

**盘式制动器**（制动钳夹住制动盘）采用圆盘离合器的公式：两块摩擦片，往往是扇形而不是整个环面，转矩$T = 2\mu F r_e$，其中$r_e$是接近摩擦片形心的有效半径。**鼓式制动器**把制动蹄压在制动鼓的内表面或外表面上，此时制动蹄及其支点的几何关系会以一种重要的方式改变结果。

::: proposition 短蹄制动器：自增力与自锁 {#prop-shoe}
铰接于$O$点的杠杆上的短制动蹄压在半径为$r$的制动鼓上。操纵力$F$作用在距$O$为$a$处，制动鼓对蹄的法向力$N$作用在距$O$为$b$处，与鼓相切的摩擦力$\mu N$的作用线到$O$的垂直距离为$c$。则
$$
N = \frac{Fa}{b \mp \mu c}, \qquad T = \mu Nr,
$$ {#eq-shoe}
当制动鼓的转向使摩擦力对$O$的力矩助长$F$时（**自增力**蹄）取上面的符号，当它与$F$相反时取下面的符号。若$\mu c \ge b$，自增力蹄是**自锁**的——无需操纵力就能保持制动。
:::

::: proof
**假设。** 蹄很短，因此压强均匀，法向力和摩擦力可视为集中作用在蹄的中心；$\mu$恒定的库仑摩擦；杠杆为刚体且处于平衡；$O$处的销轴无摩擦。

**杠杆与蹄的受力图。** 力有：$F$（对$O$的力臂为$a$，使蹄压向制动鼓）；制动鼓对蹄的法向反力$N$（力臂$b$，与$F$相反）；制动鼓对蹄的摩擦力$\mu N$，沿接触处制动鼓的运动方向（力臂$c$）；以及$O$处的销轴反力，它对$O$没有力矩。

**对$O$取矩。** 若摩擦力矩与$F$的力矩同向：$Fa + \mu Nc - Nb = 0$，故$N = Fa/(b - \mu c)$。若反向：$Fa - \mu Nc - Nb = 0$，故$N = Fa/(b + \mu c)$。作用在制动鼓上的制动转矩为摩擦力乘以半径，$T = \mu Nr$。在自增力的情况下，当$\mu c \to b$时$N$无限增大；当$\mu c \ge b$时平衡要求$F \le 0$——蹄自己就会抱死。
:::

自增力是有用的：汽车鼓式制动器的领蹄在相同踏板力下给出更大的转矩。自锁只在逆止器中有用（它阻止反转），在行车制动器中则是危险的，因为此时转矩取决于$\mu$，而$\mu$随温度和潮湿程度变化。长蹄的压强随角度变化，要通过对压强分布积分进行分析（Budynas 与 Nisbett，§16-3）；结论相同。

**带式制动器**把内衬摩擦材料的柔性钢带包绕在制动鼓上。其分析就是下一节带传动摩擦的结果：两端的张力满足$P_1/P_2 = e^{\mu\phi}$，$\phi$为包角，直径为$D$的制动鼓上的制动转矩为$T = (P_1 - P_2)D/2$。

::: warning 摩擦元件中的错误
- **对打滑的离合器或制动器使用静摩擦因数。** 衬片按其动摩擦因数$\mu$标定，干式有机和烧结衬片通常为$0.25$–$0.45$，油中约为$0.1$，而且$\mu$随温度、速度和压强变化——计算容量时用供应商给出范围的下限，计算零件强度时用上限。
- **摩擦面数算错。** 一片从动盘有两个摩擦面；夹在主动盘之间的$n$片从动盘组成的多片组有$2n$个。
- **只按转矩确定尺寸。** 通常起控制作用的是发热和磨损；要校核每次接合的能量、接合频率和温度。
- **设计出自锁的行车制动器。** $\mu c$接近$b$的蹄会随着$\mu$的变化而抱死和颤动。
- **忘记高速带中的离心张力**，它减小有效张力而不增加抓附力。
- 电梯、起重机、卷扬机和车辆的制动器是安全关键件：它们按相应的标准（例如电梯的 EN 81、车辆的 UN ECE R13 和 R13-H）设计并进行型式试验。本章讲授原理，不能代替这些规范。
:::

## 带传动

绕在带轮上的平带或绳之所以能传递转矩，是因为摩擦允许张力沿接触弧变化。张力从松边的$F_2$增加到紧边的$F_1$；二者之差乘以带轮半径就是转矩。带打滑之前比值$F_1/F_2$能有多大，由一个简单而出色的定律决定。

::: theorem 计入离心张力的带传动摩擦（欧拉–艾特尔魏因公式） {#thm-belt}
单位长度质量为$m'$的平带以速度$v$绕过带轮，接触角为$\phi$，库仑摩擦因数为$\mu$。当它在整个接触弧上处于即将打滑的状态时，
$$
\frac{F_1 - F_c}{F_2 - F_c} = e^{\mu\phi}, \qquad F_c = m'v^2,
$$ {#eq-belt}
其中$F_1$和$F_2$为紧边和松边张力，$F_c$为离心张力。对静止的带、制动带或绳（$v = 0$），这就是绞盘公式$F_1/F_2 = e^{\mu\phi}$。
:::

::: proof
**假设。** 带很薄、柔软（没有弯曲刚度），在微元范围内不可伸长；以恒定速度运动；摩擦为库仑摩擦，在接触弧上各处$\mu$相同且充分发挥（处处即将打滑）；带的重量可以忽略。

**带微元的受力图**：微元对带轮中心所张的角为$d\theta$，半径为$r$；一端张力为$F$，另一端为$F + dF$，各与微元中心处的切线成$d\theta/2$角；带轮对带的法向力$dN$，指向外，背离带轮中心；以及沿切线、阻止打滑趋势的摩擦力$\mu\,dN$。

**径向。** 质量为$m'r\,d\theta$的微元以速度$v$作圆周运动，需要指向中心的向心力$m'r\,d\theta\,v^2/r = m'v^2\,d\theta$。张力向内的分量为$2F\sin(d\theta/2) \approx F\,d\theta$；法向力向外推。因此$F\,d\theta - dN = m'v^2\,d\theta$，即$dN = (F - m'v^2)\,d\theta$。

**切向。** 速度恒定，没有切向加速度：$dF = \mu\,dN = \mu(F - F_c)\,d\theta$。

**积分。** $\dfrac{dF}{F - F_c} = \mu\,d\theta$，从$\theta = 0$处$F = F_2$积分到$\theta = \phi$处$F = F_1$：$\ln\dfrac{F_1 - F_c}{F_2 - F_c} = \mu\phi$。令$v = 0$即得绞盘公式。
:::

正是这个指数关系，使水手绕缆桩缠几圈绳就能拉住很重的载荷：$\mu = 0.3$时，每绕一整圈，拉力放大$e^{0.6\pi} = 6.6$倍，三圈放大近 300 倍。

**功率。** 传递的功率为$P = (F_1 - F_2)v$。离心张力在两边相等，对转矩毫无贡献，只是占用了张力容量。若带的许用张力（由带的强度或接头决定）为$F_a = F_1$，则由[[#eq-belt]]
$$
P = (F_a - m'v^2)\left(1 - e^{-\mu\phi}\right)v.
$$ {#eq-power}
低速时功率随$v$增大；高速时离心张力吞噬了有效张力。令$dP/dv = (F_a - 3m'v^2)(1 - e^{-\mu\phi}) = 0$，功率在
$$
v_\text{opt} = \sqrt{\frac{F_a}{3m'}}
$$ {#eq-vopt}
时最大，此时离心张力为许用张力的三分之一。

**开口带的几何关系。** 直径为$D > d$、中心距为$C$的两带轮，小带轮上的包角为$\phi_d = \pi - 2\arcsin\dfrac{D - d}{2C}$，大带轮上为$\phi_D = \pi + 2\arcsin\dfrac{D - d}{2C}$，带长为
$$
L = \sqrt{4C^2 - (D - d)^2} + \tfrac12(D\phi_D + d\phi_d).
$$ {#eq-length}
包角较小的小带轮是带首先打滑的地方，所以[[#eq-belt]]中用的是它。

**V 带。** V 带在楔角为$\beta$的轮槽中运行并楔入其中。每个侧面上的法向力比径向力大$1/[2\sin(\beta/2)]$倍，且有两个侧面，因此摩擦如同摩擦因数变为
$$
\mu' = \frac{\mu}{\sin(\beta/2)}.
$$ {#eq-vbelt}
轮槽角为$38°$时，$\mu'$为$3.07\mu$。这就是 V 带能以适中的张力和较短的中心距传递大功率的原因。带按制造商的额定值和标准（例如普通 V 带和窄 V 带的 ISO 4184）选用，其中包括了带绕过小带轮时弯曲引起的疲劳寿命——这是带失效的常见原因。

::: example V 带的功率容量 {#ex-vbelt}
一根 V 带$m' = 0.20\ \mathrm{kg/m}$，许用张力$600\ \mathrm{N}$，以$20\ \mathrm{m/s}$在$38°$的轮槽中运行，$\mu = 0.3$；小带轮上的包角为$160°$。求松边张力、即将打滑时的功率和功率最大时的带速。
::: solution
**当量摩擦因数。** $\mu' = 0.3/\sin19° = 0.921$；$\mu'\phi = 0.921\times2.793 = 2.573$；$e^{2.573} = 13.1$。

**张力。** $F_c = 0.20\times20^2 = 80\ \mathrm{N}$；$F_1 = 600\ \mathrm{N}$；$F_2 = 80 + (600 - 80)/13.1 = 119.7\ \mathrm{N}$。

**功率。** $P = (600 - 119.7)\times20 = 9.61\ \mathrm{kW}$。

**最佳速度。** $v_\text{opt} = \sqrt{600/(3\times0.20)} = 31.6\ \mathrm{m/s}$，此时$P_{\max} = (600 - 200)(1 - 1/13.1)\times31.6 = 11.7\ \mathrm{kW}$。

**检查。** 相同$\mu$和张力的平带只能达到$(F_1 - F_c)/(F_2 - F_c) = 2.31$，$F_2 = 305\ \mathrm{N}$，约$5.9\ \mathrm{kW}$。设计功率低于$9.6\ \mathrm{kW}$，因为带不能在即将打滑的状态下工作：安装时施加初拉力，使工作中的张力比低于极限，并按疲劳寿命确定额定值。
:::

## 链传动

滚子链靠滚子与链轮轮齿的啮合传递功率，因此不打滑，无需靠初拉力获得抓附力，能在低速下承受很大的力。它在运动学上的弱点是链条以多边形而不是圆包绕链轮。齿数为$N$、链节距为$p$的链轮，其分度圆直径为
$$
D = \frac{p}{\sin(180°/N)},
$$ {#eq-pitch}
即通过各滚子中心的圆，因为每个链节都是所张圆心角为$360°/N$的弦。

::: proposition 多边形效应引起的速度波动 {#prop-chordal}
由以恒定角速度$\omega$转动的链轮驱动的链条，其速度每转过一齿变化一次，在
$$
v_{\max} = \frac{\omega D}{2}, \qquad v_{\min} = \frac{\omega D}{2}\cos\frac{180°}{N}
$$
之间变化，相对波动量为$\dfrac{v_{\max} - v_{\min}}{v_{\max}} = 1 - \cos\dfrac{180°}{N}$。
:::

::: proof
**假设。** 进入链轮的链条是直的，并与链轮的节距多边形相切；正在啮合的链节随链轮刚性转动；忽略链节的弹性。

即将入座的滚子位于半径$D/2$处，以速度$\omega D/2$垂直于其半径运动。链条的速度是该速度沿直线链段方向的分量。链轮转过一个齿时，入座链节与链段方向的夹角从$-180°/N$变到$+180°/N$。当链节与链段平行（夹角为 0）时，链段以全速$\omega D/2$运动；在周期的两端，速度为$(\omega D/2)\cos(180°/N)$。这种"多边形效应"还使链段每转过一齿升降一次。
:::

8 齿时波动为$7.6\ \%$，17 齿时为$1.7\ \%$，25 齿时为$0.8\ \%$。它在每个滚子入座时引起振动、噪声和冲击，这就是链条制造商建议中等速度下小链轮至少约 17 齿、高速时更多的原因。链条在销轴处磨损，节距增大，链条在轮齿上爬高，常用的更换判据约为 1–3% 的伸长。滚子链和链轮已经标准化（ISO 606），其额定功率在低速时由链板疲劳决定，在高速时由滚子–套筒的冲击和胶合决定，由制造商的表格给出。

::: example 滚子链传动 {#ex-chain}
一个 17 齿的链轮以$600\ \mathrm{rpm}$驱动节距$19.05\ \mathrm{mm}$的链条。求分度圆直径、平均链速和速度波动。
::: solution
**分度圆直径。** $D = 19.05/\sin(180°/17) = 19.05/0.1837 = 103.7\ \mathrm{mm}$。

**速度。** $\omega = 62.83\ \mathrm{rad/s}$；$v_{\max} = 62.83\times0.05184 = 3.26\ \mathrm{m/s}$；$v_{\min} = 3.26\times\cos10.59° = 3.20\ \mathrm{m/s}$；波动为$1 - \cos10.59° = 1.7\ \%$。由节距乘以每秒通过的齿数得平均速度$Np\,n/60 = 17\times0.01905\times10 = 3.24\ \mathrm{m/s}$。

**检查。** 速度每秒波动$17\times10 = 170$次；如果这个频率接近链段或从动机器的某阶固有频率，就会发生共振——这是增加齿数的又一个理由。
:::
:::

::: application 汽车离合器、双离合变速器与同步带
手动挡汽车的干式单片离合器就是[[#ex-car]]中的圆盘离合器；它由膜片弹簧压紧，必须承受坡道起步产生的热量。双离合变速器有两个离合器，一个对应奇数挡，一个对应偶数挡，换挡时一个分离、另一个接合，因此每个离合器都在载荷下短暂打滑——热管理再次成为设计的限制，大转矩时采用油冷的湿式多片离合器。有齿的（同步）带兼有带的轻巧安静和链的确定性传动，用于发动机凸轮轴和定位驱动；它们按齿的剪切和抗拉芯线的疲劳而不是摩擦来标定额定值。
:::

::: history
阿蒙通（Guillaume Amontons，1699 年）和库仑（Charles-Augustin Coulomb）建立了干摩擦定律，每一个离合器和制动器的计算都以此为基础；库仑的《简单机械理论》（*Théorie des machines simples*）获得巴黎科学院 1781 年的奖项，于 1785 年发表。欧拉（Leonhard Euler）在柏林科学院院刊的一篇论文（1769 年印行）中分析了绕在柱上的绳的摩擦，艾特尔魏因（Johann Albert Eytelwein）在他的《固体静力学手册》（*Handbuch der Statik fester Körper*，1808 年）中给出了这一指数定律，因此它被称为欧拉–艾特尔魏因公式。Hans Renold 于 1880 年获得套筒滚子链的专利，这是今天标准链条的基础。Frederick Lanchester 于 1902 年获得汽车盘式制动器的专利，但在 20 世纪 50 年代盘式制动器普及之前，汽车上一直以鼓式制动器为主。John Gates 的公司于 1917 年推出了橡胶 V 带。
:::

::: quiz
某带传动在小带轮上开始打滑。下列哪种改变*不*会有帮助？
- [ ] 增大中心距。
- [ ] 增大初拉力。
- [x] 在功率和许用张力不变、带速已经高于$v_\text{opt}$的情况下，使带运行得更快。
- [ ] 把平带换成 V 带。
::: solution
中心距增大使小带轮包角增大；初拉力增大使可用张力提高；V 带使当量$\mu$成倍增大。高于$v_\text{opt}$时，速度越高离心张力越大，有效张力越小，因此容量下降。
:::
:::

::: quiz
把一个离合器换成转矩容量为其两倍的离合器，其他不变。每次接合产生的热量
- [ ] 加倍。
- [ ] 减半。
- [x] 不变，但在一半的时间内产生。
::: solution
$E = I_1I_2(\omega_1 - \omega_2)^2/[2(I_1 + I_2)]$中不含$T$；打滑时间$t_s \propto 1/T$减半，因此热流密度加倍，闪温升高。
:::
:::

::: summary
- 圆盘离合器，每个摩擦面：均匀磨损$T = \mu F(D + d)/4$（用于设计），均匀压强$T = \mu F(D^3 - d^3)/[3(D^2 - d^2)]$；$D$和$p_{\max}$固定时最佳$d/D = 1/\sqrt3$；锥形离合器再除以$\sin\alpha$。
- 两个转动惯量接合时耗散$E = I_1I_2(\omega_1 - \omega_2)^2/[2(I_1 + I_2)]$，与离合器无关；$\Delta T \le E/(mc)$；离合器和制动器通常受发热限制。
- 车辆制动器吸收$\tfrac12Mv^2$，峰值功率为$Mav$。
- 短蹄鼓式制动器：$N = Fa/(b \mp \mu c)$；取减号时为自增力，$\mu c \ge b$时自锁。
- 带和制动带：$(F_1 - F_c)/(F_2 - F_c) = e^{\mu\phi}$，$F_c = m'v^2$；功率$(F_1 - F_2)v$；在$v = \sqrt{F_a/3m'}$时最大；V 带用$\mu/\sin(\beta/2)$。
- 链：分度圆直径$p/\sin(180°/N)$，多边形效应速度波动$1 - \cos(180°/N)$；至少用约 17 齿。
:::

::: exercise 圆盘离合器的转矩 {level=1 check="90"}
一个单摩擦面的圆盘离合器$D = 200\ \mathrm{mm}$，$d = 100\ \mathrm{mm}$，$\mu = 0.3$，轴向力$4\ \mathrm{kN}$。按均匀磨损模型求其转矩容量。（以 N m 为单位输入转矩。）

$T = \mu F(D + d)/4 = 0.3\times4000\times0.300/4 = 90\ \mathrm{N\,m}$。最大压强在内半径处，$p_{\max} = 2F/[\pi d(D - d)] = 8000/(\pi\times0.1\times0.1) = 0.255\ \mathrm{MPa}$。

直径$300\ \mathrm{mm}$的制动鼓上的带式制动器，两端张力分别为$1000\ \mathrm{N}$和$500\ \mathrm{N}$。求制动转矩。（以 N m 为单位输入转矩。）

::: exercise 自锁的制动蹄 {level=2 check="0.375"}
在一个短蹄制动器中，法向力作用在距杠杆支点$150\ \mathrm{mm}$处，摩擦力作用线到支点的距离为$400\ \mathrm{mm}$。摩擦因数大于多少时，自增力蹄会自锁？

::: exercise 锥形离合器 {level=3}
(a) 从锥面上的一个微元出发，推导半锥角为$\alpha$的锥形离合器在均匀磨损下的[[#eq-cone]]。(b) 证明均匀压强下$T = \dfrac{\mu F}{3\sin\alpha}\dfrac{D^3 - d^3}{D^2 - d^2}$。(c) 一个锥形离合器$D = 300\ \mathrm{mm}$，$d = 250\ \mathrm{mm}$，$\alpha = 12°$，$\mu = 0.3$，必须传递$200\ \mathrm{N\,m}$。按均匀磨损求轴向力，并与相同直径的单摩擦面圆盘离合器比较。
::: solution
(a) 锥面上半径$r$与$r + dr$之间的圆环，斜宽为$dr/\sin\alpha$，面积为$2\pi r\,dr/\sin\alpha$。法向力为$p\,2\pi r\,dr/\sin\alpha$，其轴向分量为$p\,2\pi r\,dr$（因子$\sin\alpha$消去）。摩擦转矩为$\mu p\,2\pi r^2\,dr/\sin\alpha$。由$pr = C$：$F = \pi C(D - d)$，与圆盘相同；$T = \pi\mu C(D^2 - d^2)/(4\sin\alpha)$，故$T = \mu F(D + d)/(4\sin\alpha)$。
(b) $p$为常数：$F = p\pi(D^2 - d^2)/4$，$T = 2\pi\mu p(D^3 - d^3)/(24\sin\alpha)$；二者相除即得结果。
(c) $F = 4T\sin\alpha/[\mu(D + d)] = 4\times200\times0.2079/(0.3\times0.55) = 1008\ \mathrm{N}$。圆盘离合器需要$F = 4T/[\mu(D + d)] = 4848\ \mathrm{N}$，为其$1/\sin12° = 4.8$倍。
:::

::: exercise 设计输送机离合器 {level=3}
一台输送机折算到离合器轴上的转动惯量为$15\ \mathrm{kg\,m^2}$，要由以恒定$300\ \mathrm{rpm}$运转的电动机在不超过$1.5\ \mathrm{s}$内起动到$300\ \mathrm{rpm}$，每小时 20 次；起动过程中作用着$40\ \mathrm{N\,m}$的稳定负载转矩。选择离合器转矩，估算每次起动的热量和平均热流，并按$\mu = 0.3$、$p_{\max} = 0.3\ \mathrm{MPa}$确定一个干式单片离合器（两个摩擦面）的尺寸。讨论还必须校核什么。
::: solution
**转矩。** 在$1.5\ \mathrm{s}$内把$15\ \mathrm{kg\,m^2}$加速到$\omega = 31.4\ \mathrm{rad/s}$需要$15\times31.4/1.5 = 314\ \mathrm{N\,m}$，加上$40\ \mathrm{N\,m}$的负载：$354\ \mathrm{N\,m}$。取$T = 400\ \mathrm{N\,m}$；则净加速转矩为$360\ \mathrm{N\,m}$，打滑时间为$15\times31.4/360 = 1.31\ \mathrm{s}$。

**热量。** 电动机侧以恒速运转，因此离合器耗散的是转矩乘以滑差角速度的积分：滑差角速度从$31.4\ \mathrm{rad/s}$线性降到$0$，故每次起动$E = T\times\tfrac12\times31.4\times1.31 = 400\times20.6 = 8.2\ \mathrm{kJ}$——比输送机获得的动能（$7.4\ \mathrm{kJ}$）多，因为离合器在克服负载转矩时也在打滑。每小时 20 次：平均$8.2\times20/3600 = 46\ \mathrm{W}$，很容易散掉；值得关注的是每次$1.3\ \mathrm{s}$打滑期间的表面温度（平均$6.3\ \mathrm{kW}$）。

**尺寸。** 两个摩擦面，$T = 2\times\tfrac{\pi}{8}\mu p_{\max}d(D^2 - d^2)$。取$d = 0.6D$：$400 = \tfrac{\pi}{4}\times0.3\times0.3\times10^6\times0.6D\times0.64D^2$，故$D^3 = 400/27\,143 = 0.01474\ \mathrm{m^3}$，$D = 245\ \mathrm{mm}$；取$D = 250$、$d = 150\ \mathrm{mm}$（容量$T = 2\times\tfrac{\pi}{8}\times0.3\times0.3\times10^6\times0.15\times0.04 = 424\ \mathrm{N\,m}$）。

**进一步校核。** 供应商给出的衬片$pv$值和温度极限；压紧弹簧力（$F = \tfrac{\pi}{2}p_{\max}d(D - d) = 7.1\ \mathrm{kN}$）和磨损余量；盘的热容量和冷却；转矩峰值期间轴、键和轴承的载荷；以及软起动电动机驱动或液力偶合器是否更合适。
