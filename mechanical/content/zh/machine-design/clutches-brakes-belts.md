摩擦传动是最多面手的功率传输元件：离合器接合与分离功率，制动器停止运动，带隔着距离传输功率，链无滑差地传输功率。**失效的摩擦传动不只是失去功能；它还会释放储存的能量，而释放正是摩擦传动失效成为起重机、电梯和汽车中最危险失效形式的原因。**摩擦传动设计是一个多准则计算：离合器必须不打滑地传递转矩，制动器必须在所需距离内停住运动，带必须不打滑地传递功率，链必须不疲劳地传递功率。**只按转矩容量设计离合器的工程师不是在离合器设计，而是在设计一个会因磨损而不是因转矩失效的离合器。**

摩擦传动设计的定量工具是**离合器转矩容量**（均匀压力理论与均匀磨损理论）、**制动器转矩**（鼓式与盘式制动器方程）、**带摩擦**（欧拉-艾特尔瓦因（Euler-Eytelwein）方程）、**链疲劳**（滚子链寿命方程）和**摩擦热**（能量耗散）。这些工具就是表达摩擦传动设计决策的语言，而这套语言正是摩擦传动设计是计算而非猜测的原因。

::: warning 摩擦传动设计出错的九种方式
**不考虑热量。**不计算发热量就设计离合器的工程师，不是在离合器设计，而是在设计一个会衰退的离合器。**离合器热量正是离合器衰退的原因，而衰退正是离合器必须按热容量而不只是转矩容量设计的原因。** **不考虑磨损。**不计算磨损率就设计离合器的工程师，不是在离合器设计，而是在设计一个会因磨损失效的离合器。**离合器磨损正是材料错误时离合器寿命比材料正确时短 5 倍的原因，而这 5 倍正是材料成为离合器设计中最重要因素的影响。** **不考虑带打滑。**设计带却不校核打滑的工程师，不是在带设计，而是在设计一条会打滑的带。**带打滑正是张紧错误时带寿命比张紧正确时短 5 倍的原因，而这 5 倍正是带张力成为带设计中最重要因素的影响。** **不考虑链疲劳。**设计链却不校核疲劳的工程师，不是在链设计，而是在设计一条会因疲劳失效的链。**链疲劳是最常见的链失效形式（占链失效的 70–80 %），而疲劳正是链按疲劳寿命而不是静强度设计的原因。** **不考虑制动器衰退。**设计制动器却不校核衰退的工程师，不是在制动器设计，而是在设计一个会因衰退失效的制动器。**制动器衰退正是制动器必须按热容量而不只是转矩容量设计的原因，而热容量正是制动器必须通风或水冷的原因。** **不规定摩擦材料。**设计离合器或制动器却不规定摩擦材料的工程师，不是在离合器设计，而是在选一个会因磨损或衰退失效的离合器。**摩擦材料正是材料正确时离合器寿命比材料错误时长 5 倍的原因，而这 5 倍正是材料成为离合器和制动器设计中最重要因素的影响。** **不考虑带张力。**不计算张力就设计带的工程师，不是在带设计，而是在设计一条会打滑或疲劳失效的带。**带张力正是张力正确时带寿命比张力错误时长 5 倍的原因，而这 5 倍正是带张力成为带设计中最重要因素的影响。** **不考虑链伸长。**设计链却不校核伸长的工程师，不是在链设计，而是在设计一条会跳齿的链。**链伸长正是链的伸长超过 2–3 % 时必须更换的原因，而这 2–3 % 正是链成为维护量最大的功率传输元件的原因。** **不考虑动载。**设计带或链却不校核动载的工程师，不是在带设计，而是在设计一条会因动载过载失效的带。**动载正是带和链必须按动载而不是静载荷设计的原因，而动载也正是带和链按疲劳寿命而不是静强度设计的原因。**
:::

## 1. 离合器

::: definition 离合器转矩容量 {#def-clutch-torque}
**离合器转矩容量**是离合器不打滑所能传递的最大转矩，而离合器转矩容量是最重要的离合器设计参数。

**均匀压力理论**（新离合器）：

$$
T \; = \; { \frac { 2 } { 3 } } \, \mu \, F \, { \frac { r _ { o } ^ { 3 } - r _ { i } ^ { 3 } } { r _ { o } ^ { 2 } - r _ { i } ^ { 2 } } }
$$

**均匀磨损理论**（已磨损离合器）：

$$
T \; = \; \mu \, F \, r _ { m } \; = \; \mu \, F \, { \frac { r _ { o } + r _ { i } } { 2 } }
$$

其中 $\mu$ 是摩擦因数，$F$ 是压紧力，$r _ { o }$ 是外半径，$r _ { i }$ 是内半径。

$$
\begin{array} { l c c c }
\textbf{离合器类型} & \textbf{转矩容量} & \textbf{热容量} & \textbf{使用场合} \\ \hline
\text{单盘} & \mu \, F \, r _ { m } & \text{低} & \text{汽车} \\
\text{多盘} & n \, \mu \, F \, r _ { m } & \text{中} & \text{摩托车、飞机} \\
\text{锥形} & \mu \, F \, r _ { m } / \sin \alpha & \text{低} & \text{机床} \\
\text{离心} & \text{随转速而定} & \text{中} & \text{割草机、链锯} \\
\text{电磁} & \mu \, F \, r _ { m } & \text{低} & \text{打印机、伺服} \\
\end{array}
$$

**多盘离合器的转矩容量最高，而高转矩容量正是多盘离合器用于摩托车和飞机的原因。只按转矩容量设计离合器却不校核热量的工程师，不是在离合器设计，而是在设计一个会衰退的离合器。**
:::

::: definition 离合器热量与衰退 {#def-clutch-heat}
**离合器热量**是每次接合耗散的能量，而离合器热量正是离合器衰退的原因。

$$
E \; = \; { \frac { 1 } { 2 } } \, I \, \omega ^ { 2 } \; = \; { \frac { 1 } { 2 } } \, I \, ( 2 \pi \, n / 6 0 ) ^ { 2 }
$$

其中 $I$ 是转动惯量，$\omega$ 是角速度。

每次接合的**温升**为：

$$
\Delta T \; = \; { \frac { E } { m \, c _ { p } } }
$$

其中 $m$ 是摩擦片质量，$c _ { p }$ 是比热容。

$$
\begin{array} { l c c }
\textbf{摩擦材料} & \textbf{ } \mu & \textbf{温度上限（°C）} \\ \hline
\text{有机材料（无石棉）} & 0 . 3 \text{--} 0 . 5 & 1 5 0 \text{--} 2 0 0 \\
\text{烧结金属} & 0 . 4 \text{--} 0 . 6 & 5 0 0 \text{--} 6 0 0 \\
\text{碳/碳复合材料} & 0 . 2 \text{--} 0 . 4 & 1 \ 0 0 0 \text{--} 1 \ 5 0 0 \\
\text{陶瓷} & 0 . 4 \text{--} 0 . 7 & 6 0 0 \text{--} 8 0 0 \\
\text{纸基（湿式）} & 0 . 0 8 \text{--} 0 . 1 2 & 1 0 0 \text{--} 1 5 0 \\
\end{array}
$$

**离合器衰退正是离合器必须按热容量而不只是转矩容量设计的原因。不计算热量就设计离合器的工程师，不是在离合器设计，而是在设计一个会衰退的离合器。**
:::

::: example 单盘离合器设计 {#ex-clutch-design level=3 check="2"}
某单盘离合器外半径 150 mm，内半径 100 mm，摩擦因数 0.35。压紧力 5 kN。试用均匀磨损理论计算转矩容量。

**平均半径：**

$$
r _ { m } \; = \; { \frac { r _ { o } + r _ { i } } { 2 } } \; = \; { \frac { 1 5 0 + 1 0 0 } { 2 } } \; = \; 1 2 5 \ \text{mm}
$$

**转矩容量（均匀磨损，一个摩擦面）：**

$$
T \; = \; \mu \, F \, r _ { m } \; = \; 0 . 3 5 \times 5 \ 0 0 0 \times 0 . 1 2 5 \; = \; { \bf 2 1 9 } \ \text{N} { \cdot } \text{m}
$$

**对于有两个摩擦面（盘两侧）的单盘离合器：**

$$
T _ { \text{total } } \; = \; 2 \times 2 1 9 \; = \; { \bf 4 3 8 } \ \text{N} { \cdot } \text{m}
$$

**转矩容量为 438 N·m。工程师会规定 1.5–2.0 的安全因数，对应设计转矩 219–292 N·m。**
:::
## 2. 制动器

::: definition 鼓式制动器 {#def-drum-brake}
**鼓式制动器**是摩擦在蹄片与制动鼓之间产生的制动器，而鼓式制动器正是制动器紧凑且具有自增力作用的原因。

$$
T \; = \; \mu \, F \, r \, { \frac { b } { a } } \; \times \; { \frac { 1 } { 1 - \mu \, b / a } }
$$

其中 $F$ 是促动力，$r$ 是制动鼓半径，$a$ 是支点到促动点的距离，$b$ 是支点到蹄片的距离。

**自增力系数**为：

$$
\text{自增力系数} \; = \; { \frac { 1 } { 1 - \mu \, b / a } }
$$

$$
\begin{array} { l c c c }
\textbf{制动器类型} & \textbf{转矩} & \textbf{热容量} & \textbf{使用场合} \\ \hline
\text{鼓式（领蹄）} & \text{高（自增力）} & \text{中} & \text{汽车后轮} \\
\text{鼓式（从蹄）} & \text{低} & \text{中} & \text{汽车后轮} \\
\text{盘式（单活塞）} & \text{中} & \text{高} & \text{汽车前轮} \\
\text{盘式（多活塞）} & \text{高} & \text{很高} & \text{赛车、飞机} \\
\text{带式} & \text{高} & \text{低} & \text{卷扬机、起重机} \\
\end{array}
$$

**盘式制动器的热容量最高，而高热容量正是盘式制动器用于汽车前轮和赛车的原因。只按转矩容量设计制动器却不校核热量的工程师，不是在制动器设计，而是在设计一个会衰退的制动器。**
:::

::: definition 制动器热量与衰退 {#def-brake-heat}
**制动器热量**是每次制动停车耗散的动能，而制动器热量正是制动器衰退的原因。

$$
E \; = \; { \frac { 1 } { 2 } } \, m \, v ^ { 2 }
$$

其中 $m$ 是整车质量，$v$ 是速度。

每次停车的**温升**为：

$$
\Delta T \; = \; { \frac { E \, ( 1 - \eta _ { \text{regen } } ) } { m _ { \text{disc } } \, c _ { p } } }
$$

其中 $\eta _ { \text{regen } }$ 是能量回收效率（摩擦制动为 0）。

**制动器衰退正是制动器必须按热容量而不只是转矩容量设计的原因。设计制动器却不校核衰退的工程师，不是在制动器设计，而是在设计一个会因衰退失效的制动器。**
:::

::: example 鼓式制动器设计 {#ex-drum-brake level=3 check="2"}
某鼓式制动器制动鼓半径 150 mm，蹄片宽 40 mm，摩擦因数 0.4，促动力 2 kN。支点到促动点的距离 300 mm，支点到蹄片的距离 200 mm。试计算制动转矩和自增力系数。

**自增力系数：**

$$
\text{自增力系数} \; = \; { \frac { 1 } { 1 - \mu \, b / a } } \; = \; { \frac { 1 } { 1 - 0 . 4 \times 2 0 0 / 3 0 0 } } \; = \; { \frac { 1 } { 1 - 0 . 2 6 7 } } \; = \; { \frac { 1 } { 0 . 7 3 3 } } \; = \; { \bf 1 . 3 6 }
$$

**制动转矩：**

$$
T \; = \; \mu \, F \, r \, { \frac { b } { a } } \; \times \; \text{自增力系数} \; = \; 0 . 4 \times 2 \ 0 0 0 \times 0 . 1 5 \times { \frac { 2 0 0 } { 3 0 0 } } \times 1 . 3 6
$$

$$
T \; = \; 0 . 4 \times 2 \ 0 0 0 \times 0 . 1 5 \times 0 . 6 6 7 \times 1 . 3 6 \; = \; { \bf 1 0 9 } \ \text{N} { \cdot } \text{m}
$$

**制动转矩为 109 N·m，自增力系数为 1.36。自增力系数正是鼓式制动器比盘式制动器所需促动力更小的原因，而促动力更小正是鼓式制动器用于汽车后轮的原因。**
:::

## 3. 带传动

::: definition 带摩擦与欧拉-艾特尔瓦因方程 {#def-belt-friction}
**带摩擦**是带与带轮之间的摩擦，而带摩擦正是带不打滑地传递功率的原因。

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { \mu \, \theta }
$$

其中 $T _ { 1 }$ 是紧边拉力，$T _ { 2 }$ 是松边拉力，$\mu$ 是摩擦因数，$\theta$ 是包角（弧度）。

**功率容量**为：

$$
P \; = \; ( T _ { 1 } - T _ { 2 } ) \, v \; = \; T _ { 2 } \, ( e ^ { \mu \, \theta } - 1 ) \, v
$$

其中 $v$ 是带速。

$$
\begin{array} { l c c c }
\textbf{带类型} & \textbf{ } \mu _ { \text{eff } } & \textbf{速度上限（m/s）} & \textbf{效率} \\ \hline
\text{平带} & 0 . 2 5 \text{--} 0 . 3 5 & 2 5 \text{--} 3 5 & 9 5 \text{--} 9 8 \ \% \\
\text{V 带（普通）} & 0 . 5 0 \text{--} 0 . 7 0 & 2 0 \text{--} 2 5 & 9 0 \text{--} 9 6 \ \% \\
\text{V 带（窄）} & 0 . 5 0 \text{--} 0 . 7 0 & 2 5 \text{--} 3 0 & 9 3 \text{--} 9 7 \ \% \\
\text{同步带（齿形）} & \text{啮合传动} & 3 0 \text{--} 5 0 & 9 8 \text{--} 9 9 \ \% \\
\text{圆带} & 0 . 2 5 \text{--} 0 . 3 5 & 1 0 \text{--} 1 5 & 8 5 \text{--} 9 0 \ \% \\
\end{array}
$$

**V 带的有效摩擦因数最高，而高摩擦因数正是 V 带成为应用最广的带类型的原因。设计带却不校核打滑的工程师，不是在带设计，而是在设计一条会打滑的带。**
:::

::: definition 链传动 {#def-chain-drive}
**链传动**是链条与链轮齿啮合的功率传输元件，而链传动正是传动成为啮合传动（无滑差）的原因。

$$
P \; = \; { \frac { T \, n } { 9 \ 5 5 0 } } \qquad T \; = \; F _ { t } \, { \frac { d } { 2 } }
$$

其中 $F _ { t }$ 是圆周力，$d$ 是链轮节圆直径。

$$
\begin{array} { l c c c }
\textbf{链类型} & \textbf{节距（mm）} & \textbf{速度上限（m/s）} & \textbf{使用场合} \\ \hline
\text{滚子链（单排）} & 9 . 5 \text{--} 5 0 . 8 & 1 5 \text{--} 2 5 & \text{通用} \\
\text{滚子链（双排）} & 9 . 5 \text{--} 5 0 . 8 & 1 5 \text{--} 2 5 & \text{大功率} \\
\text{齿形链（无声链）} & 9 . 5 \text{--} 2 5 . 4 & 2 0 \text{--} 3 5 & \text{高速、低噪声} \\
\text{板式链} & 1 2 . 7 \text{--} 3 8 . 1 & 5 \text{--} 1 0 & \text{起重、吊装} \\
\end{array}
$$

**链传动正是传动成为啮合传动（无滑差）的原因，而啮合传动正是链用于自行车、摩托车和输送机的原因。设计链却不校核疲劳的工程师，不是在链设计，而是在设计一条会因疲劳失效的链。**
:::

::: example V 带设计 {#ex-v-belt level=3 check="2"}
某 V 带传动在 1 200 rpm 下传递 10 kW。小带轮直径 150 mm，包角 160°，有效摩擦因数 0.55。试计算紧边拉力、松边拉力和带速。

**带速：**

$$
v \; = \; { \frac { \pi \, d \, n } { 6 0 } } \; = \; { \frac { \pi \times 0 . 1 5 \times 1 \ 2 0 0 } { 6 0 } } \; = \; { \bf 9 . 4 2 } \ \text{m/s}
$$

**包角（弧度）：**

$$
\theta \; = \; 1 6 0 \times { \frac { \pi } { 1 8 0 } } \; = \; 2 . 7 9 \ \text{rad}
$$

**拉力比：**

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { \mu \, \theta } \; = \; e ^ { 0 . 5 5 \times 2 . 7 9 } \; = \; e ^ { 1 . 5 3 5 } \; = \; { \bf 4 . 6 4 }
$$

**功率方程：**

$$
P \; = \; ( T _ { 1 } - T _ { 2 } ) \, v \; \Longrightarrow \; 1 0 \ 0 0 0 \; = \; ( T _ { 1 } - T _ { 2 } ) \times 9 . 4 2
$$

$$
T _ { 1 } - T _ { 2 } \; = \; { \frac { 1 0 \ 0 0 0 } { 9 . 4 2 } } \; = \; 1 \ 0 6 2 \ \text{N}
$$

**求解：**

$$
T _ { 2 } \; = \; { \frac { 1 \ 0 6 2 } { 4 . 6 4 - 1 } } \; = \; { \bf 3 0 6 } \ \text{N}
$$

$$
T _ { 1 } \; = \; 4 . 6 4 \times 3 0 6 \; = \; { \bf 1 \ 4 2 0 } \ \text{N}
$$

**紧边拉力为 1 420 N，松边拉力为 306 N。工程师会规定张力容量至少 1 420 N 的带，而张力容量正是带按紧边拉力而不是松边拉力设计的原因。**
:::

::: example 链传动设计 {#ex-chain-design level=3 check="2"}
某滚子链传动在 900 rpm 下传递 7.5 kW。小链轮 19 齿，大链轮 57 齿，链节距 15.875 mm。试计算传动比、链速和圆周力。

**传动比：**

$$
i \\; = \\; { \\frac { N _ { 2 } } { N _ { 1 } } } \\; = \\; { \\frac { 5 7 } { 1 9 } } \\; = \\; { \\bf 3 . 0 }
$$

**链轮节圆直径（小链轮）：**

$$
d _ { 1 } \\; = \\; { \\frac { p } { \\sin ( \\pi / N _ { 1 } ) } } \\; = \\; { \\frac { 1 5 . 8 7 5 } { \\sin ( \\pi / 1 9 ) } } \\; = \\; { \\frac { 1 5 . 8 7 5 } { 0 . 1 6 4 6 } } \\; = \\; 9 6 . 4 \\ \\text{mm}
$$

**链速：**

$$
v \\; = \\; { \\frac { \\pi \\, d _ { 1 } \\, n _ { 1 } } { 6 0 } } \\; = \\; { \\frac { \\pi \\times 0 . 0 9 6 4 \\times 9 0 0 } { 6 0 } } \\; = \\; { \\bf 4 . 5 4 } \\ \\text{m/s}
$$

**圆周力：**

$$
F _ { t } \\; = \\; { \\frac { P } { v } } \\; = \\; { \\frac { 7 \\ 5 0 0 } { 4 . 5 4 } } \\; = \\; { \\bf 1 \\ 6 5 2 } \\ \\text{N}
$$

**传动比为 3.0，链速为 4.54 m/s，圆周力为 1 652 N。工程师会规定拉伸容量至少为圆周力 3 倍（5 kN）的链，而这 3 倍正是链按疲劳寿命而不是静强度设计的原因。**
:::
## 习题

::: exercise 离合器转矩容量 {#ex-clutch-torque level=3 check="2"}
某多盘离合器有 6 个盘，外半径 120 mm，内半径 80 mm，摩擦因数 0.3。压紧力 3 kN。试用均匀磨损理论计算转矩容量。

::: solution
**平均半径：**

$$
r _ { m } \; = \; { \frac { 1 2 0 + 8 0 } { 2 } } \; = \; 1 0 0 \ \text{mm} \; = \; 0 . 1 \ \text{m}
$$

**摩擦面数：** $n = 6 - 1 = 5$（6 个盘有 5 个摩擦界面）。

**转矩容量：**

$$
T \; = \; n \, \mu \, F \, r _ { m } \; = \; 5 \times 0 . 3 \times 3 \ 0 0 0 \times 0 . 1 \; = \; { \bf 4 5 0 } \ \text{N} { \cdot } \text{m}
$$

**转矩容量为 450 N·m。**
:::
:::

::: exercise 制动器热量 {#ex-brake-heat level=3 check="2"}
某 1 200 kg 的汽车以 80 km/h 行驶，4 秒内停车。制动盘质量 8 kg，比热容 500 J/(kg·K)。试计算每次停车的温升。

::: solution
**动能：**

$$
E \; = \; { \frac { 1 } { 2 } } \times 1 \ 2 0 0 \times ( 8 0 / 3 . 6 ) ^ { 2 } \; = \; { \frac { 1 } { 2 } } \times 1 \ 2 0 0 \times 4 9 3 . 8 \; = \; 2 9 6 \ 3 0 0 \ \text{J}
$$

**温升：**

$$
\Delta T \; = \; { \frac { 2 9 6 \ 3 0 0 } { 8 \times 5 0 0 } } \; = \; { \frac { 2 9 6 \ 3 0 0 } { 4 \ 0 0 0 } } \; = \; { \bf 7 4 . 1 } \ \text{K}
$$

**每次停车温升 74.1 K。若温升超过 100 K，工程师会规定通风盘，而这 100 K 正是通风盘用于高性能场合的原因。**
:::
:::

::: exercise 带摩擦 {#ex-belt-friction level=3 check="2"}
某平带包角 180°，摩擦因数 0.3。紧边拉力 800 N。试计算松边拉力以及在 15 m/s 带速下的功率容量。

::: solution
**包角（弧度）：** $\theta = \pi = 3 . 1 4$ rad。

**拉力比：**

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { 0 . 3 \times 3 . 1 4 } \; = \; e ^ { 0 . 9 4 2 } \; = \; 2 . 5 7
$$

**松边拉力：**

$$
T _ { 2 } \; = \; { \frac { 8 0 0 } { 2 . 5 7 } } \; = \; { \bf 3 1 1 } \ \text{N}
$$

**功率容量：**

$$
P \; = \; ( 8 0 0 - 3 1 1 ) \times 1 5 \; = \; 4 8 9 \times 1 5 \; = \; { \bf 7 . 3 4 } \ \text{kW}
$$

**松边拉力为 311 N，功率容量为 7.34 kW。**
:::
:::

::: exercise 链传动 {#ex-chain-drive level=3 check="2"}
某滚子链传动在 600 rpm 下传递 5 kW。小链轮 17 齿，节距 12.7 mm。试计算圆周力和链速。

::: solution
**链轮节圆直径：**

$$
d \; = \; { \frac { p } { \sin ( \pi / N ) } } \; = \; { \frac { 1 2 . 7 } { \sin ( \pi / 1 7 ) } } \; = \; { \frac { 1 2 . 7 } { 0 . 1 8 4 } } \; = \; 6 9 . 0 \ \text{mm}
$$

**链速：**

$$
v \; = \; { \frac { \pi \, d \, n } { 6 0 } } \; = \; { \frac { \pi \times 0 . 0 6 9 \times 6 0 0 } { 6 0 } } \; = \; { \bf 2 . 1 7 } \ \text{m/s}
$$

**圆周力：**

$$
F _ { t } \; = \; { \frac { P } { v } } \; = \; { \frac { 5 \ 0 0 0 } { 2 . 1 7 } } \; = \; { \bf 2 \ 3 0 4 } \ \text{N}
$$

**圆周力为 2 304 N，链速为 2.17 m/s。**
:::
:::

::: exercise 锥形离合器 {#ex-cone-clutch level=3 check="2"}
某锥形离合器锥角 12°，平均半径 100 mm，摩擦因数 0.3，压紧力 2 kN。试计算转矩容量。

::: solution
$$
T \; = \; { \frac { \mu \, F \, r _ { m } } { \sin \alpha } } \; = \; { \frac { 0 . 3 \times 2 \ 0 0 0 \times 0 . 1 } { \sin 1 2 ^ { \circ } } } \; = \; { \frac { 6 0 } { 0 . 2 0 8 } } \; = \; { \bf 2 8 9 } \ \text{N} { \cdot } \text{m}
$$

**转矩容量为 289 N·m，比平摩擦面离合器（60 N·m）高 4.8 倍。锥形离合器正是机床离合器紧凑的原因，而紧凑正是锥形离合器用于机床的原因。**
:::
:::

::: exercise 带拉力比 {#ex-belt-tension-ratio level=3 check="2"}
某 V 带有效摩擦因数 0.6，包角 150°。试计算拉力比，以及松边拉力占紧边拉力的百分比。

::: solution
**包角（弧度）：** $\theta = 1 5 0 \times \pi / 1 8 0 = 2 . 6 2$ rad。

**拉力比：**

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { 0 . 6 \times 2 . 6 2 } \; = \; e ^ { 1 . 5 7 2 } \; = \; { \bf 4 . 8 2 }
$$

**松边拉力占紧边拉力的百分比：**

$$
{ \frac { T _ { 2 } } { T _ { 1 } } } \; = \; { \frac { 1 } { 4 . 8 2 } } \; = \; { \bf 2 0 . 7 } \ \ \%
$$

**松边拉力占紧边拉力的 20.7 %。工程师会规定张力容量至少等于紧边拉力的带，而张力容量正是带按紧边拉力而不是松边拉力设计的原因。**
:::
:::

::: exercise 推导：欧拉-艾特尔瓦因方程 {#ex-derive-euler level=4 check="2"}
试证明欧拉-艾特尔瓦因方程 $T _ { 1 } / T _ { 2 } = e ^ { \mu \theta }$ 由微元带的受力平衡导出。并对 $\mu = 0 . 3$、$\theta = \pi$ 计算 $T _ { 1 } / T _ { 2 }$。

::: solution
考察对应圆心角为 $d \theta$ 的微元带。切向受力平衡为：

$$
d T \; = \; \mu \, d N
$$

径向受力平衡为：

$$
d N \; = \; T \, d \theta
$$

代入：

$$
{ \frac { d T } { T } } \; = \; \mu \, d \theta
$$

从 $T _ { 2 }$（$\theta = 0$ 处）积分到 $T _ { 1 }$（$\theta = \theta$ 处）：

$$
\int _ { T _ { 2 } } ^ { T _ { 1 } } { \frac { d T } { T } } \; = \; \int _ { 0 } ^ { \theta } \mu \, d \theta \quad \Longrightarrow \quad \ln { \frac { T _ { 1 } } { T _ { 2 } } } \; = \; \mu \, \theta
$$

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { \mu \, \theta }
$$

对 $\mu = 0 . 3$、$\theta = \pi$：

$$
{ \frac { T _ { 1 } } { T _ { 2 } } } \; = \; e ^ { 0 . 3 \times \pi } \; = \; e ^ { 0 . 9 4 2 } \; = \; { \bf 2 . 5 7 }
$$

**拉力比为 2.57，即紧边拉力是松边拉力的 2.57 倍。** $\blacksquare$
:::
:::

::: exercise 推导：离合器转矩容量 {#ex-derive-clutch level=4 check="2"}
试证明均匀磨损理论的离合器转矩容量 $T = \mu F r _ { m }$ 由转矩积分 $T = \int r \, d F _ { \text{friction } }$ 导出，其中磨损率与压强和速度的乘积成正比。并对 $\mu = 0 . 3$、$F = 5$ kN、$r _ { o } = 1 5 0$ mm、$r _ { i } = 1 0 0$ mm 计算 $T$。

::: solution
均匀磨损理论假设磨损率在摩擦面上均匀，即：

$$
p \, r \; = \; \text{常数} \quad \Longrightarrow \quad p \; = \; { \frac { p _ { i } \, r _ { i } } { r } }
$$

压紧力为：

$$
F \; = \; \int _ { r _ { i } } ^ { r _ { o } } p \, 2 \pi \, r \, d r \; = \; 2 \pi \, p _ { i } \, r _ { i } \, ( r _ { o } - r _ { i } )
$$

转矩容量为：

$$
T \; = \; \int _ { r _ { i } } ^ { r _ { o } } r \, \mu \, p \, 2 \pi \, r \, d r \; = \; 2 \pi \, \mu \, p _ { i } \, r _ { i } \, { \frac { r _ { o } ^ { 2 } - r _ { i } ^ { 2 } } { 2 } }
$$

代入 $p _ { i } \, r _ { i } = F / [ 2 \pi \, ( r _ { o } - r _ { i } ) ]$：

$$
T \; = \; \mu \, F \, { \frac { r _ { o } + r _ { i } } { 2 } } \; = \; \mu \, F \, r _ { m }
$$

对 $\mu = 0 . 3$、$F = 5$ kN、$r _ { o } = 1 5 0$ mm、$r _ { i } = 1 0 0$ mm：

$$
T \; = \; 0 . 3 \times 5 \ 0 0 0 \times { \frac { 1 5 0 + 1 0 0 } { 2 } } \times 1 0 ^ { - 3 } \; = \; 0 . 3 \times 5 \ 0 0 0 \times 0 . 1 2 5 \; = \; { \bf 1 8 8 } \ \text{N} { \cdot } \text{m}
$$

**每个摩擦面的转矩容量为 188 N·m。** $\blacksquare$
:::
:::

::: quiz 离合器 {#quiz-clutch}
多盘离合器的转矩容量比单盘离合器高，是因为：

- [ ] 摩擦因数更高
- [x] 摩擦面数更多
- [ ] 压紧力更大
- [ ] 半径更大

::: solution
**摩擦面数更多。** 多盘离合器有 $n - 1$ 个摩擦面（$n$ 为盘数），转矩容量与摩擦面数成正比。高转矩容量正是多盘离合器用于摩托车和飞机的原因。
:::

::: quiz 带传动 {#quiz-belt}
V 带的有效摩擦因数比平带高，是因为：

- [ ] V 带材料更黏
- [x] 楔形效应放大了法向力
- [ ] V 带更厚
- [ ] V 带包角更大

::: solution
**楔形效应放大了法向力。** V 带嵌入带轮轮槽，楔形效应把法向力放大 $1 / \sin ( \beta / 2 )$ 倍，其中 $\beta$ 是轮槽角。有效摩擦因数为 $\mu _ { \text{eff } } = \mu / \sin ( \beta / 2 )$，比平带摩擦因数高 2–3 倍。
:::

## 本讲的去向

- **[[machine-design/shafts]]** — 离合器和制动器装在轴上，轴按离合器转矩定尺寸。
- **[[machine-design/gear-design]]** — 齿轮是最高效的功率传输元件，而效率正是齿轮被最广泛使用的原因。
- **[[machine-design/bearings]]** — 轴承按离合器和制动器的载荷选型，而载荷正是轴承寿命如此的原因。
- **[[machine-design/springs]]** — 弹簧用于离合器和制动器，而弹簧力正是离合器接合的原因。
- **[[machine-design/fasteners-joints]]** — 离合器和制动器用螺栓安装，而螺栓按离合器转矩定尺寸。
- **[[machine-design/fatigue]]** — 链按疲劳寿命定尺寸，而疲劳寿命正是链成为维护量最大的功率传输元件的原因。
- **[[thermodynamics/first-law-closed|热力学第一定律]]** — 离合器和制动器把动能转化为热，而热正是离合器和制动器必须按热容量设计的原因。
- **[[vibrations/vibration-fundamentals]]** — 带和链是振动系统中的弹性元件，而弹性正是带和链按动载荷设计的原因。

::: history 离合器、制动器、带与链：从带式制动器到双离合变速器 {#history-friction-drives}
**1725 年** — **带式制动器**由法国工程师尼古拉·莱昂纳尔·萨迪·卡诺（Nicolas Léonard Sadi Carnot）发明，而带式制动器正是制动器成为最早的摩擦传动的原因。**带式制动器正是制动器成为最古老摩擦传动的原因，而这古老正是制动器成为最精熟摩擦传动的原因。**

**1895 年** — **摩擦离合器**被引入汽车，而摩擦离合器正是汽车能够换挡的原因。**摩擦离合器正是汽车能够驾驶的原因，而可驾驶性正是离合器成为汽车传动系统中最关键零件的原因。**

**1902 年** — **弗雷德里克·兰彻斯特（Frederick Lanchester）** 在汽车上引入了**盘式制动器**，而盘式制动器正是制动器比鼓式制动器更可靠的原因。**盘式制动器正是制动器更可靠的原因，而可靠正是盘式制动器成为汽车前轮上应用最广的制动器的原因。**

**1905 年** — **V 带**由美国工程师约翰·W·盖茨（John W. Gates）发明，而 V 带正是带传动成为应用最广的功率传输元件的原因。**V 带正是带传动应用最广的原因，而楔形效应正是 V 带成为最高效带类型的原因。**

**20 世纪 20 年代** — **滚子链**经美国链条协会实现标准化，而滚子链正是链传动成为应用最广的啮合传动的原因。**滚子链正是链传动成为应用最广的啮合传动的原因，而啮合传动正是链用于自行车和摩托车的原因。**

**20 世纪 50 年代** — **自动变速器**（液力变矩器）被引入汽车，而液力变矩器正是离合器变为液压式的原因。**液力变矩器正是离合器变为液压式的原因，而液压化正是自动变速器成为汽车中应用最广的变速器的原因。**

**20 世纪 80 年代** — **防抱死制动系统（ABS）**被引入汽车，而 ABS 正是制动器安全的原因。**ABS 正是制动器安全的原因，而安全正是 ABS 成为汽车中最重要安全配置的原因。**

**2003 年** — **双离合变速器（DCT）**被引入大众高尔夫，而 DCT 正是换挡瞬时完成的原因。**DCT 正是换挡瞬时完成的原因，而瞬时换挡正是 DCT 成为最高效自动变速器的原因。**
:::

::: summary 离合器、制动器、带与链 {#summary-friction-drives}
- **摩擦传动是最多面手的功率传输元件，摩擦传动负责接合、分离、停止和传输功率。** 摩擦传动失效是起重机、电梯和汽车中最危险的失效形式。
- **离合器转矩容量为 $T = \mu F r _ { m }$（均匀磨损）或 $T = ( 2 / 3 ) \mu F ( r _ { o } ^ { 3 } - r _ { i } ^ { 3 } ) / ( r _ { o } ^ { 2 } - r _ { i } ^ { 2 } )$（均匀压力）。** 多盘离合器的转矩容量最高，而高转矩容量正是多盘离合器用于摩托车和飞机的原因。
- **离合器热量是每次接合耗散的能量，而离合器热量正是离合器衰退的原因。** 不计算热量就设计离合器的工程师，不是在离合器设计，而是在设计一个会衰退的离合器。
- **鼓式制动器具有自增力作用，自增力系数为 $1 / ( 1 - \mu \, b / a )$。** 自增力系数正是鼓式制动器比盘式制动器所需促动力更小的原因。
- **盘式制动器的热容量最高，而高热容量正是盘式制动器用于汽车前轮和赛车的原因。** 只按转矩容量设计制动器却不校核热量的工程师，不是在制动器设计，而是在设计一个会衰退的制动器。
- **带摩擦由欧拉-艾特尔瓦因方程描述：$T _ { 1 } / T _ { 2 } = e ^ { \mu \theta }$。** V 带的有效摩擦因数最高，而高摩擦因数正是 V 带成为应用最广的带类型的原因。
- **链传动正是传动成为啮合传动（无滑差）的原因，而啮合传动正是链用于自行车、摩托车和输送机的原因。** 链疲劳是最常见的链失效形式（占链失效的 70–80 %）。
- **制动器热量是每次停车耗散的动能，而制动器热量与速度的平方成正比。** 制动器热量正是制动器必须按热容量而不只是转矩容量设计的原因。
- **摩擦材料正是材料正确时离合器寿命比材料错误时长 5 倍的原因。** 碳/碳摩擦材料的温度上限最高（1 000–1 500 °C）。
- **链伸长正是链的伸长超过 2–3 % 时必须更换的原因，而这 2–3 % 正是链成为维护量最大的功率传输元件的原因。** 设计链却不校核伸长的工程师，不是在链设计，而是在设计一条会跳齿的链。
:::
