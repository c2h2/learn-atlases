传递函数用一个分式装下了整个经典控制：一个线性对象将来会做的一切，都写在它的极点和零点的位置里，而每一个设计决策——多快、多阻尼、甩掉多少扰动、放进多少噪声——都是关于这个分式的一句话。它同时也是控制从微分方程变成附带几何的代数的地方，这就是这门学科早于可计算半个世纪就已可设计的原因。

撑起这一讲的有三个思想。传递函数的**极点**是系统不用你请就要表演的模态，而**零点**是系统拒绝传输的频率——右半平面的零点则是一个承诺：响应必须先朝反方向走。**方框图代数**把线性方框的任何互联都化为一个分式，而它的系统化版本——梅森增益公式——正是复杂回路可以在一分钟内在图上读出来的原因。而**闭环**改变极点，这就是反馈的全部机制：对象的极点是它的命运，回路的极点是一个设计选择，而这个选择所受的限制是接下来三讲的主题。

::: warning 零初始条件，以及它的代价
传递函数定义为输出与输入变换之比，且**所有初始条件为零**，这个限定不是迂腐。初始状态非零的系统会产生带有额外项——“自由”部分——的响应，而传递函数不包含这些项，所以用传递函数搭起来的方框图默默假定了对象从静止开始。由此引出两种失败。第一种是实践上的：积分器已绕满的伺服，或者已经烧热的炉子，不会按图上的方式响应，这正是PID一讲中抗积分饱和与无扰切换机制的由来。第二种是概念上的：一个不处于静止的系统，关于那个静止点也不是线性的，唯一诚实的处理是状态方程，在那里初始条件不过是众多输入中的一个。传递函数是为其所解决的问题而生的辉煌工具，而那个问题不是“这台机器会干什么”，而是“这台机器被激励时会干什么”。
:::

## 传递函数及其代数

::: definition 传递函数、极点与零点 {#def-tf}
对零初始条件下的$a_n y^{(n)} + \cdots + a_1 \dot{y} + a_0 y = b_m u^{(m)} + \cdots + b_1 \dot{u} + b_0 u$，
$$
G (s ) = \frac{Y (s )}{U (s )} = \frac{b_m s^{m} + \cdots + b_1 s + b_0}{a_n s^{n} + \cdots + a_1 s + a_0}
= K \frac{\prod_{i} \left( s - z_i \right)}{\prod_{j} \left( s - p_j \right)} .
$$
$p_j$是**极点**，它们是系统自己的模态，不依赖于输入；$z_i$是**零点**，即系统阻断的复频率：输入$e^{z_i t}$在该指数上不产生输出，而位于虚轴$\pm \mathrm{j} \omega_0$处的零点在稳态下阻断频率为$\omega_0$的正弦。对任何输入的响应都在$p_j$处**以及**输入的极点处有极点，所以阶跃给输出加上一个常数，正弦给输出加上一个正弦。系统稳定当且仅当每个极点的实部为负；而只有当$m \le n$时才是**真**的——即物理上可实现的。
:::

::: proof 部分分式与响应的解剖 {#proof-partial}
写$Y (s ) = G (s ) U (s )$，围绕单极点$p_k$展开，
$$
Y (s ) = \sum_k \frac{r_k}{s - p_k}, \qquad
r_k = \lim_{s \to p_k} \left( s - p_k \right) G (s ) U (s ) .
$$
逐项反变换，
$$
y (t ) = \sum_k r_k e^{p_k t},
$$
所以响应是一串指数之和，**乘积**$G U$的每个极点对应一项：来自$G$的$p_j$那些是自由响应，系统稳定时它们衰减；来自$U$的那些是强迫响应，它们会持续。$\checkmark$

**注。**有两个推论值得变成条件反射。第一，$G U$中的**零极点对消**把模态从输出中除去，但没有从系统中除去：如果控制器零点把不稳定对象极点对消掉，这个对消只在精确算术中成立，而在真实回路里，模态会在方框图没有画出的那个状态变量里重新长出来。这是经典设计中单个最危险的想法，也是每一个现代教材都坚持检查**内部**稳定性的原因——内部稳定性指回路中每一对信号之间的每一个传递函数，而不只是到输出的那一个。第二，重数为$m$的重极点$p$会贡献$t^{j} e^{p t}$，$j$最大到$m - 1$，所以在原点有二重极点的系统对脉冲的响应是一条斜坡、对阶跃的响应是一条抛物线：重极点的临界稳定在实际中就是失稳，这就是劳斯判据要用严格不等式陈述的原因。
:::

::: definition 方框图代数与梅森公式 {#def-mason}
三条局部规则可化简任何图：**串联**的方框相乘，**并联**的方框相加，前向增益为$G$、反馈通路为$H$的一个**回路**化为$G / \left( 1 \pm G H \right)$。引出点可以向外移过方框（乘以它），相加点可以向外移过方框（除以它），两个相加点可以互换。系统化形式是**梅森增益公式**，
$$
T = \frac{1}{\Delta} \sum_k P_k \Delta_k,
\qquad
\Delta = 1 - \sum_i L_i + \sum_{i < j} L_i L_j - \cdots,
$$
其中$P_k$是从输入到输出的前向通路，$L_i$是各个回路增益，第二个和号遍历**互不接触**回路的二元组，$\Delta_k$是从$\Delta$中删去与通路$k$接触的回路后剩下的部分。
:::

::: proof 单回路的梅森公式 {#proof-mason}
只有一个前向通路$P$和一个回路$L$的图就是方程
$$
x = P u + L x \quad\Longrightarrow\quad x = \frac{P}{1 - L} u ,
$$
这正是$\Delta = 1 - L$、$\Delta_1 = 1$的梅森公式。对两个互不接触的回路，方程解耦为
$$
x_1 = P_1 u + L_1 x_1, \qquad x_2 = L_2 x_2 + \cdots
$$
各自贡献自己的$1 / \left( 1 - L_i \right)$，其乘积展开为$1 - L_1 - L_2 + L_1 L_2$，这恰好是包含了互不接触二元组的$\Delta$。加上一个**接触**两个回路的回路会去掉它的$L_1 L_2$项，因为这两个回路此时共享一个节点，不能被独立地反复代入——这就是“互不接触”规则的全部内容，也是公式在有限多项后终止的原因。$\checkmark$

**注。**梅森公式就是把克拉默法则用在图的节点方程上，这个恒等式值得知道，有两个原因。第一，使$\Delta (s ) = 0$的那些$s$值就是图中每一个传递函数的极点，所以$\Delta (s ) = 0$**就是**特征方程，整个稳定性理论都住在一个分母里。第二，它告诉你图大到无法手工列举回路时该怎么办：写出节点方程并作为线性方程组求解，这就是每种仿真软件所做的事。
:::

::: definition 非最小相位与滞后 {#def-nmp}
所有零点都在左半平面的传递函数是**最小相位**的：在所有具有相同幅值响应的系统中，它的相位滞后最小，且它的相位可由幅值经伯特关系恢复。位于$s = z$（$z > 0$）的右半平面零点贡献的幅值与左半平面的一个相同，但多出$2 \arctan \left( \omega / z \right)$的**额外**相位滞后，并且迫使阶跃响应先朝错误方向运动。纯滞后$e^{- T s}$根本没有零点，幅值平坦而相位滞后无界；它是$n$个全通因子级联$\left[ \left( 1 - T s / 2 n \right) / \left( 1 + T s / 2 n \right) \right]^{n}$在$n \to \infty$时的极限，因此其行为就像无穷多个右半平面零点。
:::

::: example RLC 电路 {#ex-rlc}
$R = 100\ \Omega$、$L = 0.1\ \mathrm{H}$、$C = 10\ \mu\mathrm{F}$的串联电路由电压源驱动，测量其电流。求传递函数、它的极点与零点，以及对$10\ \mathrm{V}$阶跃的响应。
::: solution
$$
\frac{I}{V} = \frac{1}{L s + R + 1 / C s} = \frac{s / L}{s^{2} + \left( R / L \right) s + 1 / L C}
= \frac{10\, s}{s^{2} + 1000\, s + 10^{6}} ,
$$
$$
\omega_n = \frac{1}{\sqrt{L C}} = 1000\ \mathrm{rad / s}, \qquad
\zeta = \frac{R}{2} \sqrt{\frac{C}{L}} = 0.50, \qquad
p = - 500 \pm 866\ \mathrm{j} .
$$
这里有一个**原点处的零点**：在$\omega = 0$处电容隔断，所以直流电压下的稳态电流为零。阶跃响应由$I (s ) = 10 \times 10 s /\left[ s \left( s^{2} + 1000 s + 10^{6} \right) \right]$得出，
$$
i (t ) = \frac{V}{L \omega_d} e^{- \zeta \omega_n t} \sin \omega_d t
= 0.115\, e^{- 500 t} \sin 866 t\ \mathrm{A} .
$$
**校核。**终值为零，正如原点零点所要求的；初始斜率为$\left. \dot{i} \right|_0 = 0.1155 \times 866 = 100\ \mathrm{A / s}$，等于预期的$V / L = 100\ \mathrm{A / s}$相符——电感在接通瞬间表现为开路。$\checkmark$

**合理性检验。**电流输出的串联RLC是一个**带通**：直流处为零是因为电容，无穷远处为零是因为电感，在$\omega_n$处有一个高度为$1 / R = 10\ \mathrm{mS}$的谐振峰。同样的零极点模式——原点处一个零点加一对复极点——就是弹簧–质量–阻尼器的迁移率（单位力产生的速度）$s / \left( m s^{2} + c s + k \right)$，两者的解读都一样：两个异类储能元件串联给出带通，而电阻单独决定它有多尖锐。
:::
:::

::: example 化简一个伺服方框图 {#ex-reduce}
一个位置伺服带有增益为$K_p = 2$的放大器、一台电机$\Theta / V = K_m / s \left( \tau s + 1 \right)$（$K_m = 5\ \mathrm{rad / s / V}$，$\tau = 0.1\ \mathrm{s}$）、单位位置反馈，以及增益为$K_t$的测速发电机，其电压从电机电压中减去，构成围绕电机的内环。求闭环传递函数，以及给出$\zeta = 0.7$的$K_t$。
::: solution
测速环在位置环内部，所以先化简它：
$$
\frac{\Theta}{V_e} = \frac{K_m}{s \left( \tau s + 1 \right) + K_m K_t s}
\quad\Longrightarrow\quad
\frac{\Theta}{\Theta_r} = \frac{K_p K_m}{\tau s^{2} + \left( 1 + K_m K_t \right) s + K_p K_m} .
$$
代入$K_p = 2$、$K_m = 5$、$\tau = 0.1$，
$$
\omega_n^{2} = 100 \Rightarrow \omega_n = 10\ \mathrm{rad / s},
\qquad
2 \zeta \omega_n = 10 \left( 1 + 5 K_t \right) = 14
\quad\Longrightarrow\quad
K_t = 0.080\ \mathrm{V\, s / rad}.
$$
**校核。**不加测速时分母为$s^{2} + 10 s + 100$（已除以$\tau$），所以$\zeta = 10 / \left( 2 \times 10 \right) = 0.50$；测速发电机把阻尼从$0.50$提到了$0.70$，而没有改变$\omega_n$。$\checkmark$

**合理性检验。**测速环是**微分**反馈，是对轻阻尼对象的标准疗法，因为它只乘$s$的系数而不碰常数项——它改变阻尼而保留固有频率。注意它的代价：测速发电机带来自己的噪声，而它的增益容差现在决定了阻尼容差，所以弱百分之五的测速机给出$\zeta = 0.69$而不是$0.70$，无伤大雅；而若改用对位置信号求微分来代替它，就需要低通滤波器来抑制噪声，这会在穿越频率处带来测速发电机所没有的相位滞后。这个结论可以推广：任何用于阻尼的测量都必须在高频处安静，因为阻尼是高频性质。
:::
:::

::: example 非最小相位对象 {#ex-nmp}
某对象有$G (s ) = \dfrac{2 - s}{\left( 1 + s \right)\left( 1 + 2 s \right)}$。求它的阶跃响应，以及它的右半平面零点在$\omega = 1\ \mathrm{rad / s}$处让它付出的相位。
::: solution
$$
\frac{G}{s} = \frac{2}{s} + \frac{3}{1 + s} - \frac{10}{1 + 2 s}
\quad\Longrightarrow\quad
y (t ) = 2 + 3 e^{- t} - 5 e^{- t / 2} ,
$$
$$
y \left( 0.365 \right) = - 0.083 \quad \text{（下冲百分之四）},
\qquad
y (\infty ) = 2 .
$$
初始斜率为$y' (0 ) = - 3 + 2.5 = - 0.5$，对正阶跃而言为负。该零点贡献
$$
- 2 \arctan \frac{\omega}{2} = - 53.1^{\circ}
$$
在$\omega = 1$处，叠加在两个极点的$- 45^{\circ} - 63.4^{\circ}$之上，而具有相同幅值的最小相位对象是$0^{\circ}$。

**合理性检验。**下冲不是设计的缺陷而是对象的属性，而且在每一个真实案例中它都有物理根源：飞机受命爬升时先**损失**一点高度，因为升降舵产生的额外尾翼下压力立即起作用，而机翼升力要等机头转起来才增加；船舶在操舵指令后横向位置先朝错误方向移动，因为舵力在船体偏航之前先把船艉推向一侧；锅炉汽包水位在蒸汽负荷增加时先**上升**，因为汽包压力下降，上升管中的气泡膨胀把水顶了上去，尽管水的存量正在减少——这就是水位控制器必须绕着它来设计的“虚假水位”（收缩与膨胀）现象，通常采用同时测量蒸汽流量和给水流量的三冲量方案。在每一个案例中，右半平面零点都把可达的闭环带宽限制在零点自身频率的一个分数（大约三分之一到二分之一）以内，而这个上限就是一项设计要求。
:::

::: example 级联回路上的梅森公式 {#ex-mason}
一台传动的放大器为$G_1 = 2$，电机$G_2 = 5 / s$外面套着电流反馈元件$H_1 = 0.5$的电流环，负载$G_3 = 1 / \left( s + 1 \right)$在单位位置环之内。用梅森公式求闭环传递函数，并用直接化简校核。
::: solution
只有一条前向通路和两个回路，且两个回路相互接触：
$$
P = G_1 G_2 G_3 = \frac{10}{s \left( s + 1 \right)},
\qquad
L_1 = - G_2 H_1 = - \frac{2.5}{s},
\qquad
L_2 = - G_1 G_2 G_3 = - \frac{10}{s \left( s + 1 \right)} ,
$$
$$
T = \frac{P}{1 - L_1 - L_2}
= \frac{10}{s \left( s + 1 \right) + 2.5 \left( s + 1 \right) + 10}
= \frac{10}{s^{2} + 3.5\, s + 12.5} .
$$
**用化简校核。**仅内环为$G_2 / \left( 1 + G_2 H_1 \right) = 5 / \left( s + 2.5 \right)$，所以前向通路为$10 / \left[ \left( s + 2.5 \right)\left( s + 1 \right) \right]$，闭合外环得$10 / \left[ \left( s + 2.5 \right)\left( s + 1 \right) + 10 \right]$，分母相同。$\checkmark$
$$
\omega_n = 3.54\ \mathrm{rad / s}, \qquad \zeta = 0.495, \qquad M_p = 16.7\ \%.
$$
**合理性检验。**内电流环把对象的极点从原点移到了$- 2.5\ \mathrm{s^{- 1}}$——它把一个积分器（临界稳定、只用比例增益无法控制）变成了一个增益为二的惯性环节。这就是传动中电流环的全部目的，也是每台伺服驱动器都必有它的原因：电机从转矩到速度、从速度到位置都是积分器，两个串联的积分器无法被任何单回路比例网络镇定，而内环消掉了其中一个。剩下的$0.50$阻尼则说明了设计师还要做什么——加测速或微分反馈，或者接受每次动作百分之十七的超调。
:::

::: example 设计 {#ex-design-ff}
一座炉子用PID控制其温度。一个扰动以可测量的进料流量变化形式进入。设计前馈通路，并说明它修不了什么。
::: solution
设对象为$G_p$、执行器为$G_a$、扰动通路为$G_d$，完全补偿要求前馈$G_{ff}$使输出对扰动的依赖消失：
$$
G_{ff} G_a G_p + G_d = 0
\qquad\Longrightarrow\qquad
G_{ff} = - \frac{G_d}{G_a G_p} .
$$
对一阶炉子$G_p = K / \left( \tau s + 1 \right)$，$G_a = 1$，扰动经同一个一阶环节进入，$G_d = K_d / \left( \tau s + 1 \right)$。取加热器增益$K = 2.0\ \mathrm{K / kW}$，并设进料每增加$1\ \mathrm{kg / min}$炉子稳态降温$0.6\ \mathrm{K}$，即$K_d = - 0.6\ \mathrm{K\, min / kg}$；则
$$
G_{ff} = - \frac{K_d}{K} = + 0.30\ \mathrm{kW\, min / kg} ,
$$
是一个**纯增益**——进料每增加$1\ \mathrm{kg / min}$就多加$0.3\ \mathrm{kW}$的热量——因为扰动与控制经过相同的动力学。

**设计点评。**实践中有两件事会破坏它，而且两者都是结构性的而非数值性的。第一，所需的$G_{ff}$是**对象的逆**，而任何带滞后、右半平面零点或极点多于零点的对象，其逆都是不可实现的——所以可达到的最好前馈是增益加超前，残余部分留给反馈回路。第二，扰动通路的增益会漂移：这里$K_d$随负荷变化，在一个工作点设好的前馈在另一个工作点就是错的，这就是工业前馈方案包含一个由反馈控制器自身输出驱动的在线**校正**项的原因。经历这一切之后仍然成立的准则是那条有价值的：前馈负责**可测量的**且**大的**扰动，让反馈回路只需处理未测量的残余；对小的或未测量的扰动，前馈一无是处。炉子的进料流量可测量且大，所以前馈值得配；它的环境温度可测量但小，为它配一条前馈通路是维护上的累赘。
:::

**拉普拉斯变换**可追溯到拉普拉斯（Laplace）1780年代的论文以及他1812年的《概率的解析理论》（*Théorie analytique des probabilités*），在那里变换是积分学的工具，还不是工程工具。它的工程用法是**奥利弗·赫维赛（Oliver Heaviside）**在缺乏严格论证的情况下发明的，他在《电磁理论》（*Electromagnetic Theory*，1893–1912）中阐述的算子演算把$p = \mathrm{d} / \mathrm{d}t$当作一个数来演算，并算出了经典方法碰不到的电报线问题的正确答案。论证来自**托马斯·布罗姆维奇（Thomas Bromwich）**1916年的围道积分处理、**约翰·卡森（John Carson）**1926年的《电路理论与算子演算》（*Electric Circuit Theory and the Operational Calculus*）以及**古斯塔夫·德奇（Gustav Doetsch）**1937年的《拉普拉斯变换的理论与应用》（*Theorie und Anwendung der Laplace-Transformation*），它们把算子演算改写成了今天工程师使用的拉普拉斯变换。**哈罗德·布莱克（Harold Black）**于1927年在去贝尔实验室上班的拉克瓦纳渡轮上，在一张报纸上构想出负反馈放大器，并于1934年发表；**奈奎斯特（Nyquist）**1932年的论文把回路的几何变成了设计对象。**塞缪尔·梅森（Samuel Mason）**1953年和1956年关于信号流图的论文给出了增益公式，使大型方框图的化简成为常规。**亨德里克·伯德（Hendrik Bode）**1945年的《网络分析与反馈放大器设计》（*Network Analysis and Feedback Amplifier Design*）阐述了最小相位的增益–相位关系和灵敏度积分——使本讲的权衡定量化的那个定理——教会了一代人反馈要付什么代价。
:::

::: quiz
某对象的阶跃响应起初**背离**其终值运动。下列说法哪个正确？
- [ ] 控制器中的微分项可以消除下冲
- [x] 对象有右半平面零点（奇数个），任何线性控制器都无法消除初始的反向运动
- [ ] 增大回路增益会消除它
- [ ] 它是执行器中的测量误差
::: solution
一开始朝错误方向运动的阶跃响应，是奇数个右半平面零点的标志（纯滞后只会推迟响应，不会使它反向）。这些零点原封不动地出现在回路的**互补**传递函数中，不借助回路中别处的不稳定对消就无法消除。微分项改变闭环零点但不改变对象的零点，而提高增益只会让下冲来得更快、不会更小。设计上的后果是带宽上限约为零点频率的三分之一，而这个上限之所以真实，是因为造成下冲的同一批零点也在吃掉更快回路本需要的相角裕度。
:::
:::

## 后续内容

贯穿使用的二阶闭环，不过是[[vibrations/vibration-fundamentals]]中弹簧–质量–阻尼器的另一副面孔，它的时域行为在[[vibrations/free-vibration]]和[[vibrations/harmonic-excitation]]中展开，极点和零点的频域解读在[[vibrations/isolation-transmissibility]]中继续，而限制真实伺服增益的柔性模态在[[vibrations/two-degrees-of-freedom]]和[[vibrations/continuous-systems]]中。

::: summary
- 传递函数在零初始条件下定义；它的极点是系统的模态，它的零点是它拒绝传输的东西。
- 对任何输入的响应都是在**乘积**$G U$的极点处的一串指数之和，所以对消是藏起模态而不是除去模态。
- 串联、并联、回路化简加上引出点与相加点的移动可化简任何图；梅森公式一行搞定，而它的分母就是特征方程。
- 右半平面零点迫使响应初始朝错误方向运动，并把可达带宽限制在其自身频率的约三分之一处；滞后是同样的病，却连一个零点都没有。
- 嵌套回路的带宽必须按五到十倍分开，内环更快，否则各回路会为争夺同一段相位而打架。
- 前馈必须求对象的逆，这就是它永远不可能完美、且总是与反馈并用而非替代反馈的原因。
:::

::: exercise 极点与零点 {level=2}
求$G (s ) = \dfrac{10 \left( s + 2 \right)}{s \left( s^{2} + 6 s + 25 \right)}$的极点与零点，以及它对阶跃的稳态响应。
::: solution
零点在$s = - 2$；极点在$s = 0$和$s = - 3 \pm 4\ \mathrm{j}$。原点处的极点使阶跃响应无界增长，所以不存在稳态。
**合理性检验。**原点处的极点是**积分器**，而前向通路中单个积分器正是阶跃跟踪误差为零的原因——所以同一个极点，使开环响应无界的同时，使闭环响应完美。这就是系统的“型”，也是纯比例控制器对阶跃总留下残余误差的原因：误差必须非零，才能产生维持输出所需控制量的控制作用，而只有积分器能以零误差维持输出。
:::
:::

::: exercise 方框图化简 {level=2}
化简串联的$G_1 = 1 /(s + 1 )$、$G_2 = 2 / \left( s + 3 \right)$，两者外面套单位负反馈。
::: solution
$$
\frac{G_1 G_2}{1 + G_1 G_2} = \frac{2}{\left( s + 1 \right)\left( s + 3 \right) + 2}
= \frac{2}{s^{2} + 4 s + 5},
$$
极点在$- 2 \pm \mathrm{j}$，$\omega_n = \sqrt{5}$，$\zeta = 2 / \sqrt{5} = 0.894$。
**合理性检验。**开环极点在$- 1$和$- 3$；闭环把它们移到$- 2 \pm \mathrm{j}$，所以反馈把这一对变成了**均衡且振荡的**——实部的平均值不变，而分离变成了虚的。这就是反馈对一对实极点所作所为的标准图像：先把它们在实轴上拉到一起，再把它们推出实轴，而它们离开实轴的分离点就是该结构可达到的最大阻尼。超过那一点再增大增益对阻尼毫无帮助，只帮助速度，这就是为什么不断拧大增益的设计师最终得到的是更快也更振荡的回路，而不是更好的回路。
:::
:::

::: exercise 梅森公式 {level=2}
某图有一条前向通路$P = 10$和两个相互接触的回路$L_1 = - 2$、$L_2 = - 3$。求增益；再求若两回路互不接触时的增益。
::: solution
$$
T = \frac{P}{1 - L_1 - L_2} = \frac{10}{1 + 2 + 3} = 1.67 .
$$
**合理性检验。**若两个回路互不接触，分母将是$1 - L_1 - L_2 + L_1 L_2 = 12$，得$0.833$。差别在乘积项，它只对互不接触的回路出现：相互接触的两个回路不能都被独立地反复代入，所以它们的乘积不进入分母，而接触的情形有**更大**的增益，也就是不那么有效的反馈。
:::
:::

::: exercise 非最小相位 {level=3}
证明$s = z$处的右半平面零点贡献与左半平面零点相同的幅值、却多$2 \arctan \left( \omega / z \right)$的相位滞后，并求$z = 2$时在$\omega = z$处的相位滞后。
::: solution
$$
\left| \frac{\mathrm{i} \omega + z}{\mathrm{i} \omega - z} \right| = 1, \qquad
\arg \left( \mathrm{i} \omega + z \right) - \arg \left( \mathrm{i} \omega - z \right)
= \arctan \frac{\omega}{z} - \left( \pi - \arctan \frac{\omega}{z} \right) ,
$$
所以全通因子$\left( z - s \right) / \left( z + s \right)$的模为1、相位为$- 2 \arctan \left( \omega / z \right)$，在$\omega = z$处为$- 90^{\circ}$。
**合理性检验。**幅值分文不花地丢九十度相位——这就是非最小相位零点的全部经济学，也是为什么零点在$2\ \mathrm{rad / s}$处的对象，设计师还没动手相角裕度就已经没了。由此得出的经验法则，是每个传动与过程工程师都在用的那条：把闭环带宽保持在右半平面零点频率的大约三分之一以下，此处全通因子花掉$2 \arctan \left( 1 / 3 \right) = 37^{\circ}$的相位——账单不小，但撑得住。
:::
:::

::: exercise 滞后 {level=3}
用$\left[ 1 / 1 \right]$帕德近似$\left( 1 - s / 2 \right) / \left( 1 + s / 2 \right)$近似$T = 1$的$e^{- T s}$，并在$\omega = 1$处比较两者。
::: solution
帕德形式是一个**全通**环节，在$2 / T$处有一个右半平面零点、在$2 / T$处有一个左半平面极点。在$\omega = 1$处，精确滞后的相位是$- 57.3^{\circ}$，而近似为
$$
- 2 \arctan \frac{\omega}{2} = - 53.1^{\circ},
$$
低了百分之七，而两者在每一个频率处的模都恰好为1。
**合理性检验。**帕德近似是把滞后放进根轨迹或状态空间设计的标准做法，而它的右半平面零点不是伪影而是公正的警告：滞后确实是越来越多个全通因子（每个带一个右半平面零点）级联的极限，而近似以引入一对对象身上没有的零极点为代价，把这个结构带进了设计。实际的告诫是：近似在$\omega = 2 / T$以上会退化，所以在滞后转折频率之上穿越的设计，是在对着一个已经不再像对象的模型做设计。
:::
:::

::: exercise 推导 {level=3}
对$G (s ) = \omega_n^{2} / \left( s^{2} + 2 \zeta \omega_n s + \omega_n^{2} \right)$推导阶跃响应，并证明超调量百分数只取决于阻尼比。
::: solution
$$
Y (s ) = \frac{\omega_n^{2}}{s \left( s^{2} + 2 \zeta \omega_n s + \omega_n^{2} \right)}
= \frac{1}{s} - \frac{s + \zeta \omega_n}{\left( s + \zeta \omega_n \right)^{2} + \omega_d^{2}},
\qquad \omega_d = \omega_n \sqrt{1 - \zeta^{2}} ,
$$
$$
y (t ) = 1 - \frac{e^{- \zeta \omega_n t}}{\sqrt{1 - \zeta^{2}}}
\sin \left( \omega_d t + \arccos \zeta \right) .
$$
第一个峰值出现在$\omega_d t = \pi$，所以
$$
M_p = e^{- \pi \zeta / \sqrt{1 - \zeta^{2}}} . \quad \checkmark
$$
**合理性检验。**这个结果了不起，值得记到本能在里面：二阶系统的超调量告诉你它的阻尼比而不告诉你别的任何东西，所以在干净的二阶对象上做一次阶跃试验，就能从一个数直接测出$\zeta$。反演式是$\zeta = \left[ 1 + \left( \pi / \ln M_p \right)^{2} \right]^{- 1 / 2}$，所以$10$%的超调意味着$\zeta = 0.59$，$5$%的超调意味着$0.69$。这个公式还解释了为什么$\zeta \approx 0.7$是常用的默认目标：它给出$4.6$%的超调，以及按$2$%准则估计的调节时间$4 / \left( 0.7 \omega_n \right) = 5.7 / \omega_n$，是速度与超调之间合理的折中。
:::
