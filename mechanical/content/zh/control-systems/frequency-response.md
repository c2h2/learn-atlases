根轨迹回答的是"极点往哪里去？"这个问题；伯德图回答的则是现场工程师真正能问出口的问题——"我还能再加多少增益，这个回路能容忍多少滞后？"两者是同一份信息的重新包装，而正是这种重新包装使频率响应成为控制领域的工作语言。一条实测的频率响应曲线，把对象、执行器、传感器、布线电容与采样滞后全部装进一条曲线里，而且不必写任何微分方程就能取得——这就是为什么每个行业的每一位置入调试工程师都握有一种理论家的状态空间模型无法企及的权威。

这个方法建立在关于**最小相位**系统的一个非凡事实之上：幅值曲线决定相角曲线。增益一旦画好，相角就不是额外的信息，而是它的变换，于是整个设计空间坍缩为一条曲线的形状。例外——积分器、滞后、右半平面零点、渐近线分辨不出的窄共振——恰恰是实践中出问题的东西，把它们当作**对规则的偏离**来记住，是现场最快的诊断法：相角下降得比斜率预测的更快，那是滞后或未被建模的共振；相角在下降而幅值却是平的，那是一阶全通。

::: warning 直线图只是草图，而草图在三处具体地方说谎
渐近线伯德作图法逐因子相加分贝与角度，而这只在极限意义下才精确。三种失效是系统性的，且各有大小。**谐振峰是看不见的：**阻尼比$0.2$的复极点对在其固有频率处高出渐近线$1.2$个数量级，而把伺服机构机械共振的渐近线与电气滞后的渐近线相加的设计师，会把穿越频率画低一倍、把相角裕度画高二十度。**共振的相角是被压缩的：**一对极点在$\omega_n$两侧各一个数量级之内贡献其全部的$- 180^{\circ}$，所以一个设计师"远远保持在穿越频率之上"的共振，仍可能在穿越频率本身处送出$- 60^{\circ}$。**而且这张图画的是回路断开时的回路增益**，而恰恰在这个条件下，具有不稳定模态、饱和执行器或条件稳定区域的对象，其表现与闭环现实毫无相似之处。职业习惯是先画渐近线，用三十秒找到穿越频率，然后在那一个频率上算出精确的幅值与相角，之后才相信其中任何数字。
:::

## 读图

::: definition 三个模板因子与分贝的算术 {#def-bode}
每张伯德图都由三个因子拼成，以分贝相加：

| 因子 | 幅值 | 相角 | 斜率 |
|---|---|---|---|
| 增益$K$ | $20 \log_{10} K$ dB，平坦 | $0^{\circ}$ | $0$ dB/dec |
| 积分器$1 / \left( \mathrm{j} \omega \right)$ | $- 20 \log_{10} \omega$ | $- 90^{\circ}$ 平坦 | $- 20$ dB/dec |
| 极点$1 / \left( 1 + \mathrm{j} \omega / \omega_b \right)$ | 先$0$后$- 20$ dB/dec | $0 \rightarrow - 90^{\circ}$ | $\omega_b$之后$- 20$ dB/dec |
| 零点$1 + \mathrm{j} \omega / \omega_b$ | 先$0$后$+ 20$ dB/dec | $0 \rightarrow + 90^{\circ}$ | $\omega_b$之后$+ 20$ dB/dec |
| 极点对$\omega_n^{2} / \left( s^{2} + 2 \zeta \omega_n s + \omega_n^{2} \right)$ | 先$0$后$- 40$ dB/dec | $0 \rightarrow - 180^{\circ}$ | $- 40$ dB/dec，峰值$1 / \left( 2 \zeta \right)$ |

有用的算术：$20\ \mathrm{dB}$是十倍，$6\ \mathrm{dB}$是两倍，$3\ \mathrm{dB}$是$\sqrt{2}$，$1\ \mathrm{dB}$是$1.12$。极点在其转折频率处贡献其总相角的一半，在转折频率的四倍与四十倍处各按每数量级$90^{\circ}$贡献；而极点对的相角恰在$\omega_n$处坍缩到$- 90^{\circ}$，与阻尼无关。
:::

::: proof 斜率预测相角 {#proof-slope-phase}
对最小相位传递函数，某频率处的相角是邻近频率处幅值的**对数斜率**的加权平均。当斜率在几个数量级内保持常数时，平均坍缩为局部值，于是
$$
\varphi \approx \frac{\pi}{2} \frac{\mathrm{d} \ln \left| G \right|}{\mathrm{d} \ln \omega} \ \text{弧度}
\qquad\Longleftrightarrow\qquad
\varphi \left[ ^{\circ} \right] \approx 4.5 \times \left( \text{每数量级的 dB 斜率} \right) .
$$
**校核（对模板）。**单个极点在高频率处斜率为$- 20$、相角为$- 90^{\circ}$：$4.5 \times \left( - 20 \right) = - 90$ $\checkmark$。极点对：$- 180$ $\checkmark$。纯积分器，斜率$- 20$、相角$- 90^{\circ}$平坦 $\checkmark$。在单个极点自己的转折频率处，局部斜率为$- 10$，公式给出$- 45^{\circ}$，而这正是精确值——关系在那里不只是渐近的。$\checkmark$
**宽带幂律的推导。**若$\left| G \right| = A \omega^{n}$在一个频带内成立，则由解析延拓，在该带内$G \approx A \left( \mathrm{j} \omega \right)^{n}$，于是$\varphi = n \pi / 2$精确成立。一般情形之所以成立，是因为精确关系——伯德增益-相角积分——把$\omega^{\prime} = \omega u$处的斜率以$\left( 2 / \pi \right) \ln \coth \left| \ln u \right| / 2$加权，这是一个单位面积、集中于$\omega$七倍以内的核——这就是局部斜率为何有效、以及幅值突变时它为何失效的原因。$\checkmark$

**注。**这个关系既是伯德幅值图可以**读**而无需计算的原因，也是"每 dB/dec 斜率对应四点五度"值得背下来的原因。它同时也是三个例外为何如此重要的原因。纯滞后幅值平坦、相角为$- \omega \theta$，所以它表现为远低于斜率预测的相角，而相角缺口（以度计）除以频率（以 rad/s 计）**就是**滞后本身——这是本书现场测量中最有用的一招。右半平面零点的幅值与左半平面的相同，却多出$- 2 \arctan \left( \omega / z \right)$的相角，所以它也表现为相角缺口，但这个缺口在$- 180^{\circ}$处**饱和**而非无界增长，由此把它与滞后区分开。而积分器贡献斜率却不贡献任何相角变化，所以一张在三个数量级内斜率为$- 20$ dB/dec、相角平坦于$- 90^{\circ}$的图，是纯积分器而不是一个极慢的极点。
:::

::: definition 最小相位与增益-相角积分 {#def-minphase}
当传递函数除原点处的极点外，在闭合右半平面内既无零点也无极点时，称为**最小相位**。对此类函数，记$M = \ln \left| G \left( \mathrm{j} \omega \right) \right|$，
$$
\varphi \left( \omega \right) = - \frac{2 \omega}{\pi} \int_0^{\infty} \frac{M \left( \omega^{\prime} \right) - M \left( \omega \right)}{\omega^{\prime 2} - \omega^{2}} \mathrm{d} \omega^{\prime} .
$$
两条设计推论。第一，**幅值图就是相角图**：一个固定了幅值穿越频率与斜率的设计师就固定了相角裕度，二者不可得而离其一。第二，在所有具有给定幅值的传递函数中，最小相位者的**相角滞后最小**——名字即由此而来——所以每一个非最小相位元件都损失掉任何重新设计都找不回的相角。
:::

## 穿越量

::: definition 描述一个回路的四个数 {#def-crossover}
从回路增益的伯德图上读出：
$$
\begin{array}{ll}
\textbf{增益穿越} & \omega_{gc} : \left| L \right| = 0\ \mathrm{dB}, \quad
\textbf{相角裕度} \quad \varphi_m = 180^{\circ} + \angle L \left( \mathrm{j} \omega_{gc} \right), \\[4pt]
\textbf{相角穿越} & \omega_{pc} : \angle L = - 180^{\circ}, \quad
\textbf{增益裕度} \quad g_m = - \left. \left| L \right| \right|_{\omega_{pc}} \mathrm{dB}, \\[4pt]
\textbf{幅值裕度} & b = \min_\omega \left| 1 + L \left( \mathrm{j} \omega \right) \right| = 1 / M_s, \quad
\textbf{滞后裕度} \quad \theta_m = \varphi_m / \omega_{gc} .
\end{array}
$$
幅值裕度是从临界点$\left( - 1 , 0 \right)$到奈奎斯特曲线的距离，是**四个数中唯一在表示变换下不变的**一个；相角裕度与增益裕度都可以被$L$在其各自频率之外的形状打扮得好看或难看，而一个有两个穿越点的回路各有好几个这样的裕度。只要回路里含有计算机、网络或传输滞后，设计师就必须报出滞后裕度，因为它是说明软件的采样与对象的传输能否相容的那个数。
:::

::: example 速度伺服 {#ex-servo}
画出$L = 7.8 / \left[ s \left( 0.1 s + 1 \right)\left( 0.02 s + 1 \right) \right]$的伯德图，读出四个穿越量。
::: solution
**渐近线。**积分器的$- 20$ dB/dec直线在$\omega = 1$处经过$20 \log_{10} 7.8 = 17.8$ dB。$10\ \mathrm{rad / s}$处的极点把斜率折到$- 40$，$50$处的极点再折到$- 60$。
**穿越。**从$\omega = 10$出发的$- 40$ dB/dec直线在$\omega \approx 6.5$处到达$0$ dB；该处的精确幅值为$7.8 / \left( 6.49 \times 1.193 \times 1.008 \right) = 1.00$。
**相角裕度。**
$$
\angle L = - 90^{\circ} - \arctan \left( 0.649 \right) - \arctan \left( 0.130 \right)
= - 90^{\circ} - 33.0^{\circ} - 7.4^{\circ} = - 130.4^{\circ},
\qquad \varphi_m = 49.6^{\circ} .
$$
**相角穿越。**两个滞后在$0.1 \omega \times 0.02 \omega = 1$时合计达到$- 90^{\circ}$，即$\omega_{pc} = 22.4\ \mathrm{rad / s}$，此处$\left| L \right| = 0.130$，所以$g_m = 17.7\ \mathrm{dB}$。
**幅值裕度与滞后裕度。**$M_s = 1.60$，$b = 0.63$，且
$$
\theta_m = \frac{0.866\ \mathrm{rad}}{6.49\ \mathrm{rad / s}} = 133\ \mathrm{ms} .
$$
**阻尼。**$\zeta \approx 0.01 \varphi_m = 0.50$，$M_p \approx 16\ \%$，调节时间$4 / \left( 0.5 \times 7.6 \right) = 1.05\ \mathrm{s}$。

**校核。**$17.7\ \mathrm{dB}$的增益裕度是$7.7$倍，而在相角裕度跌破$30^{\circ}$之前增益只能提高约$2.4$倍——增益裕度是两个约束中**更松**的那个，这在一个相角于穿越频率附近陡降的回路中是通常情形。$\checkmark$

**合理性检验。**速度常数为$K_v = 7.8\ \mathrm{s^{- 1}}$，所以$100\ \mathrm{mm / s}$的斜坡指令会以$12.8\ \mathrm{mm}$的误差跟随，而改善跟踪意味着提高增益——$133\ \mathrm{ms}$的滞后裕度只有在整个回路——编码器滤波器、电流环、PWM更新——都待在该预算之内时才付得起这笔账。一个$1\ \mathrm{kHz}$的电流环配上$500\ \mu\mathrm{s}$的更新与$2\ \mathrm{ms}$的编码器滤波器，用掉$2.5\ \mathrm{ms}$，绰绰有余；噪声环境中一个$100\ \mathrm{Hz}$的滤波器用掉$10\ \mathrm{ms}$，仍然宽裕；一台慢速PLC上一个$20\ \mathrm{Hz}$的软件滤波器用掉$40\ \mathrm{ms}$，设计就只剩四分之一的裕度了——这就是为什么滤波器的转折频率是一个控制决策而不是信号调理决策。

::: proof 超前网络的最大相位 {#proof-lead}
超前网络为$C = \left( 1 + \mathrm{j} \omega T \right) / \left( 1 + \mathrm{j} \omega \alpha T \right)$，其中$\alpha < 1$。其相角为
$$
\varphi = \arctan \left( \omega T \right) - \arctan \left( \omega \alpha T \right) .
$$
求导并令$\mathrm{d} \varphi / \mathrm{d} \omega = 0$，
$$
\frac{T}{1 + \omega^{2} T^{2}} = \frac{\alpha T}{1 + \omega^{2} \alpha^{2} T^{2}}
\quad\Longrightarrow\quad
\omega_{\max} = \frac{1}{T \sqrt{\alpha}} ,
$$
即两个转折频率的**几何平均**。代入并用正切差公式，
$$
\tan \varphi_{\max} = \frac{{\left( 1 - \alpha \right) \omega T}}{1 + \alpha \omega^{2} T^{2}}
= \frac{\left( 1 - \alpha \right) / \sqrt{\alpha}}{2} \cdot \frac{2}{1 + 1} \cdot 2
= \frac{1 - \alpha}{2 \sqrt{\alpha}},
$$
再由$\tan \varphi = 2 t / \left( 1 - t^{2} \right)$与$t = \sqrt{ \left( 1 - \alpha \right) / \left( 1 + \alpha \right) }$，化简为标准形式
$$
\sin \varphi_{\max} = \frac{1 - \alpha}{1 + \alpha},
\qquad
\left| C \left( \mathrm{j} \omega_{\max} \right) \right| = \frac{1}{\sqrt{\alpha}} .
$$
$\checkmark$
**一句话的交换。**超前所能买到的相位与它必须随之附加的增益被$\alpha$绑在一起：$45^{\circ}$要付出$5.8$倍的高频增益，$60^{\circ}$要付出$13.9$倍。由于噪声随该增益增长，而穿越频率会移到对象滞后更多的更高频率处，单个超前超过大约$60^{\circ}$是绝不使用的；设计法则是取$\varphi_{\max}$等于所需提升加上为穿越频率移动预留的十度余量。$\checkmark$
:::

::: example 在图上做超前设计 {#ex-lead-bode}
一个速度回路有$G = 20 / \left[ s \left( s + 1 \right) \right]$，其中$K_v = 20\ \mathrm{s^{- 1}}$的值由跟踪规格固定。相角裕度不足；用超前网络把它恢复到$55^{\circ}$。
::: solution
**未校正。**由$\omega \sqrt{1 + \omega^{2}} = 20$得$\omega_{gc} = 4.4\ \mathrm{rad / s}$，且
$$
\varphi_m = 180^{\circ} - 90^{\circ} - \arctan \left( 4.4 \right) = 12.8^{\circ},
$$
这对应阻尼比$0.11$、超调量百分之七十。
**所需提升。**$55 - 12.8 = 42^{\circ}$，加上超前将导致的穿越频率移动的$10^{\circ}$余量，所以$\varphi_{\max} = 47^{\circ}$，
$$
\alpha = \frac{1 - \sin 47^{\circ}}{1 + \sin 47^{\circ}} = \frac{0.269}{1.731} = 0.155,
\qquad
\frac{1}{\sqrt{\alpha}} = 2.54 .
$$
**把$\omega_{\max}$放在新穿越频率处。**新穿越频率是未校正幅值等于$\sqrt{\alpha} = 0.394$之处：
$$
\omega \sqrt{1 + \omega^{2}} = 20 / 0.394 = 50.8
\quad\Longrightarrow\quad
\omega_{\max} = 7.07\ \mathrm{rad / s} .
$$
**转折频率。**
$$
T = \frac{1}{\omega_{\max} \sqrt{\alpha}} = \frac{1}{7.07 \times 0.394} = 0.359\ \mathrm{s},
\qquad
\frac{1}{T} = 2.79, \quad \frac{1}{\alpha T} = 17.97 ,
$$
所以$C = \left( s + 2.79 \right) / \left( s + 17.97 \right)$。
**校核。**在$\omega = 7.07$处对象贡献$- 90^{\circ} - 81.9^{\circ}$，超前贡献$+ 68.5^{\circ} - 21.4^{\circ} = + 47.0^{\circ}$，回路增益为$0.396 \times 2.535 = 1.00$。
$$
\varphi_m = 180^{\circ} - 171.9^{\circ} + 47.0^{\circ} = 55.1^{\circ},
\qquad
\zeta \approx 0.55, \quad M_p \approx 13\ \%, \quad K_v = 20\ \mathrm{s^{- 1}} \text{不变}.
$$
**合理性检验。**穿越频率从$4.4$移到了$7.1\ \mathrm{rad / s}$，所以回路快了$60\ \%$；而穿越频率处的噪声随超前的$8.1\ \mathrm{dB}$高频增益上升，同时对象自身在这些频率处的噪声底比之前高$2.5$倍。测量噪声灵敏度$\left| C G \right|$——每单位传感器噪声注入的转矩噪声——通常才是决定超前是否付得起的因素；对这个回路，它正是一台真实驱动器会把同一个零点实现为**测速发电机反馈**（内环周围的速率反馈）的原因——后者把根轨迹和伯德图朝同一方向移动而不附带高频增益的代价，代价是加载求和点、并需要第二个增益来恢复低频响应。
:::

## 滞后与非最小相位

::: definition 滞后与右半平面零点对图做了什么 {#def-delay-nmp}
滞后$\mathrm{e}^{- \mathrm{j} \omega \theta}$在**每个频率处幅值为一**，相角为$- \omega \theta$弧度，所以它在幅值图上不可见，表现为一个线性无界增长的相角缺口。位于$z$的右半平面零点幅值与左半平面零点相同，却贡献
$$
\Delta \varphi = - 2 \arctan \left( \omega / z \right),
$$
它在$- 180^{\circ}$处饱和。两者都是对最小相位的违背，两者都给穿越频率封顶：对滞后，上限是$\varphi_{\text{need}} / \theta$；对非最小相位零点，经验上限是
$$
\omega_{gc} \lesssim z / 3 .
$$
区分二者的诊断法是缺口的**形状**：在两个相距很远的频率上测量相角相对于斜率预测值的缺口。若缺口随频率加倍，那是滞后；其度数除以$57.3$再除以频率就是以秒计的滞后。若缺口增长不到成正比、且正朝$180^{\circ}$走去，那是非最小相位零点；其位置由缺口达到$90^{\circ}$的频率得出，该频率即$\omega = z$。
:::

::: example 滞后吞噬相位 {#ex-delay}
例4的超前设计在一台驱动器上实现，其电流环、PWM更新与编码器滤波器合计贡献$100\ \mathrm{ms}$的滞后。还剩什么？
::: solution
滞后贡献
$$
\Delta \varphi = \omega_{gc} \theta = 7.07 \times 0.100 = 0.707\ \mathrm{rad} = 40.5^{\circ},
$$
剩下$\varphi_m = 55.1 - 40.5 = 14.6^{\circ}$，对应阻尼比$0.13$、超调量百分之六十二。
**设计师能做什么。**校正后回路的滞后裕度是$55.1^{\circ} = 0.961\ \mathrm{rad}$除以$7.07$，即$136\ \mathrm{ms}$，所以回路比现有滞后还能多容忍$36\ \mathrm{ms}$——但它无法在保住穿越频率的同时容忍被塞给它的$100\ \mathrm{ms}$。选项按驱动器工程师会尝试的顺序是：提高电流环带宽与PWM频率来缩短滞后，这是免费的；把编码器滤波器的转折上移，这要付出噪声；或者把穿越频率降到$3.6\ \mathrm{rad / s}$，在那里滞后只花$18^{\circ}$、超前可以重新调回$55^{\circ}$，代价是带宽减半、调节时间加倍。

**校核。**在$\omega = 3.6$处滞后花$3.6 \times 0.1 = 0.36\ \mathrm{rad} = 20.6^{\circ}$，而对象自身的滞后是$90 + 74.5 = 164.5^{\circ}$，所以超前必须供给$55 - \left( 180 - 164.5 - 20.6 \right) = 60^{\circ}$——这需要$\alpha = 0.095$与$1 / \sqrt{\alpha} = 3.24$，即再多$10\ \mathrm{dB}$的噪声增益。$\checkmark$

**合理性检验。**这就是那条标准建议背后的算术：**控制回路周期应小于对象主导时间常数的十分之一**。这里对象在穿越频率处的滞后是$74.5^{\circ}$，对应时间常数$1 / \tan 74.5^{\circ} = 0.28\ \mathrm{s}$，而$0.1\ \mathrm{s}$的滞后是它的三分之一——超了三倍。能绕开整个权衡的替代方案是移除滞后的**根源**：一台模拟测速发电机或一台短孔径的旋转变压器-数字转换器可以完全取代编码器的滤波器；一个$20\ \mathrm{kHz}$的磁场定向电流环贡献的是三分之一个采样周期，而不是滤波器的十毫秒。当滞后无法移除时——输送机、带材线、远程操作机——诚实的答案是史密斯预估器或基于模型的控制器，而不是超前网络。
:::
:::

::: example 两个系统，一张幅值图 {#ex-allpass}
比较$G_1 = \left( 1 - \mathrm{j} \omega \right) / \left( 1 + \mathrm{j} \omega \right)^{2}$与$G_2 = 1 / \left( 1 + \mathrm{j} \omega \right)$，并解释为什么只有一个能被快速闭环。
::: solution
幅值为
$$
\left| G_1 \right| = \frac{\sqrt{1 + \omega^{2}}}{1 + \omega^{2}} = \frac{1}{\sqrt{1 + \omega^{2}}} = \left| G_2 \right| ,
$$
在每个频率处都相同：同样的$- 20$ dB/dec图线，$\omega = 0$处同样的$0\ \mathrm{dB}$，$\omega = 1$处同样的$- 3\ \mathrm{dB}$。相角为
$$
\angle G_1 = - \arctan \omega - 2 \arctan \omega = - 3 \arctan \omega,
\qquad
\angle G_2 = - \arctan \omega,
$$
所以$G_1$带着三倍的滞后，而多出的$- 2 \arctan \omega$正是右半平面零点的签名。
**单位增益下的穿越。**$G_2$在$\omega = 1$处穿越，$\varphi_m = 180 - 45 = 135^{\circ}$；$G_1$在$\omega = 1$处穿越，$\varphi_m = 180 - 135 = 45^{\circ}$。
**带增益$K$。**$G_2$对每个$K$都保持稳定；$G_1$在$3 \arctan \omega = 180^{\circ}$时达到$\varphi_m = 0$，即在$\omega = \tan 60^{\circ} = 1.73$处，此处$\left| G_1 \right| = 0.46$，所以它在$K = 2.00$处失稳。

**合理性检验。**只看幅值图会把这两个对象判成同一台机器，而一个可以被推到任意带宽的回路与一个在增益超过二之上就振荡的回路，差别全在相角里。右半平面零点的物理起源永远是一条**迟到且符号错误的通路**——在降压变换器里，输出电容的等效串联电阻把开关纹波直通输出，而电感的滞后拖慢了控制通路；在蒸馏塔里，加大回流量会**先**增加塔顶的轻组分、后增加塔底的；在飞机里，机身弯曲模态把节点前方的加速度计与其后方的操纵面耦合在一起。每种情形下响应起初都朝错误的方向走，而设计师的工作是接受低于零点频率三分之一的穿越频率，并停止假装另有办法。
:::
:::

::: example 在运行中的对象上测量裕度 {#ex-plant-test}
一个回路正在运行且不能停下来。用扰动试验估计它的相角裕度。
::: solution
向设定点注入一个小阶跃或一个扫频正弦，记录闭环响应。有三种读法：
**1. 闭环峰值。**回路对参考噪声的灵敏度是$\left| T \right| = \left| L / \left( 1 + L \right) \right|$。若闭环幅值在$M_r$处出现尖峰，就把回路当作二阶处理，从
$$
M_r = \frac{1}{2 \zeta \sqrt{1 - \zeta^{2}}} ,
$$
读出阻尼比，再用$\varphi_m \approx 100 \zeta$换算。峰值$M_r = 1.4$给出$\zeta = 0.39$、$\varphi_m \approx 39^{\circ}$；峰值$1.2$给出$\zeta = 0.60$、$60^{\circ}$。
**2. 振铃频率。**阶跃之后的衰减振荡以$\omega_d \approx \omega_{gc}$振铃，所以数一数振铃周期就得到穿越频率，而振铃的**衰减**通过阻尼比给出相角裕度：相邻两峰值之比为$r$时，$\zeta = - \ln r / \sqrt{4 \pi^{2} + \ln^{2} r}$，$\varphi_m \approx 100 \zeta$度。
**3. 换增益试验。**在允许断开回路的地方断开它，注入扫频正弦并直接记录$L$——这是唯一给出真实裕度而非其闭环投影的方法。

**校核。**一个阶跃响应以$1.2\ \mathrm{s}$周期振铃、相邻峰值比为$0.4$的回路，$\ln 0.4 = - 0.916$，
$$
\zeta = \frac{0.916}{\sqrt{4 \pi^{2} + 0.916^{2}}} = \frac{0.916}{6.35} = 0.145,
\qquad \varphi_m \approx 14.5^{\circ} .
$$
$\checkmark$

**合理性检验。**双峰法很粗糙——它读出的是**主导**极点对的阻尼，对第二对更靠近虚轴却激励很弱的极点、以及一个增加超调却不增加振铃的非最小相位零点都是盲的。但它仍是运行中的对象上唯一可用的方法，而两个峰值之比比峰值与终值之比抗噪得多，因为噪声在一个周期之隔的比值中被平均掉了。职业做法是记录三四个周期的比值、取对数包络的斜率而不是单个比值——这与自由振动课程里用对数衰减率时是同一个技巧，理由也相同。
:::
:::

::: example 设计 {#ex-design-oven}
一个回流焊炉温区由阶跃试验辨识为$G = 0.8 \, \mathrm{e}^{- 12 s} / \left( 45 s + 1 \right)$，即前面FOPDT参数下的模型。规格是：设定点变化的超调不超过百分之五，扰动抑制在四分钟内恢复，并容忍输送速度变化带来的额外$20\ \mathrm{s}$传输滞后。设计控制器。
::: solution
**结构。**带滞后的一阶对象无法靠微分作用改善——滞后已经主宰了相角——所以PI是正确的结构，积分时间取对象自身的时间常数。
**从相位预算选穿越频率。**相角为
$$
\angle L = - \arctan \frac{1}{\omega T_i} - \arctan \left( 45 \omega \right) - 12 \omega \times 57.3^{\circ} .
$$
在$T_i = 45\ \mathrm{s}$下解出$70^{\circ}$裕度，得$\omega_{gc} = 0.030\ \mathrm{rad / s}$，此时三项贡献为$- 5.3^{\circ}$、$- 53.1^{\circ}$与$- 20.6^{\circ}$。
**由幅值得增益。**
$$
\left| G \right|_{0.030} = \frac{0.8}{\sqrt{1 + 1.35^{2}}} = 0.476,
\qquad
\left| C \right| = K_c \sqrt{1 + \left( \frac{1}{\omega T_i} \right)^{2}} = 1.244 K_c ,
$$
所以$K_c = 1 / \left( 0.476 \times 1.244 \right) = 1.69$。
**校核。**
$$
\varphi_m = 69.4^{\circ}, \quad M_s = 1.38, \quad
\theta_m = \frac{1.211}{0.030} = 40.4\ \mathrm{s}, \quad
K_v = \frac{K_c K}{T_i} = 0.030\ \mathrm{s^{- 1}} .
$$
**对照规格。**百分之五的超调需要$\varphi_m \ge 55^{\circ}$——$69^{\circ}$满足。调节时间为$4 / \left( 0.030 \right) \approx 130\ \mathrm{s}$，而扰动恢复由积分作用的零点$0.022\ \mathrm{rad / s}$决定，约为$180\ \mathrm{s}$——在四分钟之内。$40\ \mathrm{s}$的滞后裕度减去对象自身的$12\ \mathrm{s}$，剩下$28\ \mathrm{s}$的传输滞后余量，而要求是$20\ \mathrm{s}$。$1\ {}^{\circ}\mathrm{C} / \mathrm{min}$曲线的斜坡误差是$\left( 1 / 60 \right) / 0.030 = 0.56\ {}^{\circ}\mathrm{C}$。

**设计点评。**整个设计就是与十二秒滞后的一场谈判，而数字说出了论据掩盖的东西。$0.030\ \mathrm{rad / s}$的穿越频率对应$210\ \mathrm{s}$的周期，是对象时间常数的四点五倍：这个回路**比它所控制的进程还慢**，只要滞后还在，再多的巧妙也改变不了这一点。如果曲线的斜坡误差$0.56\ {}^{\circ}\mathrm{C}$太大，补救之道不是加大增益——滞后裕度才是约束——而是对设定点斜坡做**前馈**，因为它在回路之外，对稳定性分毫不损，而这正是曲线控温进程的标准答案。算术没有显示的第二件事是：炉子的$K$与$\tau$随负载变化——一个满载产品的温区增益大约翻倍、时间常数变成三倍，这会移动穿越频率却几乎不动相角裕度，因为对象的相角由滞后主宰，而滞后是唯一不随被加热物而变的对象参数。这就是为什么以滞后为主的热工回路是流程工业中最鲁棒、同时也最慢的回路之一。
:::
:::

::: history
网络的频率响应是**贝尔系统**的母语，而伯德图是这家机构的文献而非数学的文献：**亨德里克·伯特（Hendrik Bode）**1940年的论文*"Relation between phase and amplitude of minimum-phase transfer functions"*以工程师能够图解积分的形式证明了第二个定义中的积分关系，他1945年的书又把设计法则——斜率-相角关系、四数量级法则、灵敏度积分——汇成手册，培养了一代从未学会解微分方程的控制工程师。**奈奎斯特（Nyquist）**1932年的论文提供了那张以他命名的图，而**哈里·布莱克（Harry Black）**1927年的负反馈放大器提供了整个学科存在的原因：一个增益由无源反馈对决定的放大器，只要没人考虑过相位就不稳定，而最早的反馈放大器都在振荡。**伯特（Bode）**本人对那段时期的记述，是数学结果与工程结果之差的样本——相角-幅值关系早在1926年就由**比日别特科维奇（Biezbetkowitsch）**证明过，此外就只有拉迪斯拉夫·博特凯维奇（Ladislaus Bortkiewicz）的那位无名表亲证明过它了——而把积分变成设计工具的，是伯特对它的图解求值。**超前-滞后**的命名法出自同年美国的实践；**幅值裕度**及其不变性归功于**泽姆斯（Zames）**1966年关于稳定裕度的论文——那篇文章第一次把"哪个裕度才是对的？"这个问题说精确了——而以灵敏度峰值为设计目标，则归功于**多伊尔（Doyle）**与**斯坦（Stein）**1981年的鲁棒控制工作。
:::

::: quiz
两个回路有完全相同的幅值伯德图。回路A是最小相位的，回路B含有一个纯滞后。哪个相角裕度更大？
- [x] 总是回路A，且任意频率处的缺口恰为$\omega \theta$
- [ ] 回路B，因为滞后不碰幅值
- [ ] 两者相等，因为幅值决定裕度
- [ ] 没有闭环响应就无法比较
::: solution
幅值图只对最小相位系统决定相角，而滞后是违背的最小相位典型：它在任何地方不增加幅值、在每个地方增加$- \omega \theta$的相角。因此回路A在每个穿越频率处都有更大的相角裕度，其差为$\omega_{gc} \theta$弧度——这就是为什么当一台计算机或一段传输滞后即将被插入现有回路时，应当报出的数是滞后裕度$\theta_m = \varphi_m / \omega_{gc}$。
:::
:::

## 后续内容

这里读出的穿越量，就是[[control-systems/feedback-stability]]中抽象定义的那些量；滞后裕度决定[[control-systems/digital-control]]的采样周期；例7的比例-积分整定在[[control-systems/pid-control]]中从结构上推导；而降压变换器与蒸馏塔的非最小相位零点是最后一课设计法则的主题。

::: summary
- 伯德图由四个模板因子以分贝相加拼成，局部斜率按每 dB/dec 四点五度预测相角。
- 对最小相位系统，幅值决定相角，所以穿越频率与斜率固定了相角裕度；滞后与右半平面零点破坏这条规则，付出找不回的相角。
- 四个穿越数是增益穿越与相角穿越、它们各自定义的裕度、以及幅值裕度，其中只有最后一个与表示无关。
- 超前至多买到正弦值为$(1-\alpha)/(1+\alpha)$的那个相位，并以同一频率处的高频增益为代价；滞后买到低频增益，以一条慢拖尾为代价。
- 滞后在幅值图上不可见，花费$\omega \theta$的相角，直接换算成滞后裕度$\varphi_m / \omega_{gc}$——决定计算机能否闭环的那个数。
- 在运行中的对象上，相角裕度可以从阶跃后振铃的衰减读出，代价是假设振铃就是主导模态。
:::

一个最小相位对象在某频率处的幅值斜率为每数量级$- 30\ \mathrm{dB}$。斜率关系在那里预测的相角是多少度？
::: solution
$4.5 \times \left( - 30 \right) = - 135^{\circ}$。

::: exercise 分贝 {level=1 check="20"}
回路增益$0.1$用分贝表示是$- 20\ \mathrm{dB}$。$- 6\ \mathrm{dB}$处的幅值是多少？
::: solution
$10^{- 6 / 20} = 0.501$，约二分之一。
:::

::: exercise 滞后相角 {level=1 check="57.3"}
$1\ \mathrm{ms}$的滞后在$100\ \mathrm{rad / s}$处贡献多少度相角？
::: solution
$\omega \theta = 0.1\ \mathrm{rad} = 57.3^{\circ}$。
:::

::: exercise 积分器 {level=1 check="-90"}
纯积分器在任意频率处贡献什么相角？
::: solution
$- 90^{\circ}$，平坦。
:::

::: exercise 渐近线 {level=2}
草绘$200 \left( s + 2 \right) / \left[ s^{2} \left( s + 20 \right) \right]$的幅值渐近线，并求穿越频率。
::: solution
二重积分器$- 40$ dB/dec，$2$处的零点把它带到$- 20$，$20$处的极点再带回$- 40$。在$\omega = 1$处二重积分器给出$20 \log 200 / 1 = 46$ dB；在$\omega = 2$处是$46 - 40 \log 2 = 34$ dB；从此出发的$- 20$直线要过$34 / 20 = 1.7$个数量级才到$0$ dB……这超过了$20$处的极点，所以穿越落在最后那条$- 40$直线上。精确求值，$\left| L \right| = 200 \sqrt{1 + \omega^{2} / 4} / \left[ \omega^{2} \sqrt{1 + \omega^{2} / 400} \right] = 1$在$\omega = 19.4\ \mathrm{rad / s}$处成立。
**合理性检验。**渐近线估计"二之后一个半数量级"是$63\ \mathrm{rad / s}$，而精确值是$19.4$，差了三倍——这是穿越恰好落在**转折频率处**而非远远越过它时的通常误差，也是必须在答案处求值精确幅值的原因。
:::
:::

::: exercise 相角裕度 {level=2}
对$L = 4 / \left[ s \left( s + 1 \right) \right]$，求穿越频率与相角裕度。
::: solution
$\omega \sqrt{1 + \omega^{2}} = 4$给出$\omega = 1.88$；于是$\varphi_m = 180 - 90 - \arctan 1.88 = 28.0^{\circ}$。
**合理性检验。**低于$30^{\circ}$的相角裕度意味着阻尼比接近$0.25$、超调量百分之四十五，这是一个只为速度调参的回路的经典签名。速度常数为$K_v = 4$，而在不失去它的前提下改善瞬态的唯一办法是超前、速率反馈或串级电流环——三者都是在穿越频率处增加相位，而不只是削减增益。
:::
:::

::: exercise 超前 {level=2}
超前网络为$60^{\circ}$的相位要付出多大的高频增益倍数？$\alpha$是多少？
::: solution
$\sin 60^{\circ} = 0.866 = \left( 1 - \alpha \right) / \left( 1 + \alpha \right)$给出$\alpha = 0.0718$、$1 / \sqrt{\alpha} = 3.73$，即$11.4\ \mathrm{dB}$。
**合理性检验。**在噪声栖身的频率处增加十一分贝的噪声增益，再把穿越频率推到滞后更多的更高频率，这就是$60^{\circ}$是单个超前网络的实际上限、超过它就要用两个超前级联（其实是伪装的超前-滞后）的原因。
:::
:::

::: exercise 滞后裕度 {level=2}
一个回路在穿越频率$5\ \mathrm{rad / s}$处有$50^{\circ}$的相角裕度。它能吸收多少额外滞后？若滞后为一点五个采样周期，可容忍的采样周期是多少？
::: solution
$\theta_m = \left( 50 \pi / 180 \right) / 5 = 0.175\ \mathrm{s}$。滞后为$1.5 T_s$时，得$T_s \le 0.117\ \mathrm{s}$，所以$100\ \mathrm{ms}$的采样可以——而想要五倍裕度余量的设计师需要$23\ \mathrm{ms}$。
**合理性检验。**五倍法则是工业习惯，它的存在是因为滞后从来不只是采样：抗混叠滤波器、通信协议栈、执行器自身的响应各贡献自己的一份，而一个恰好卡在算术极限上的回路，会在某次固件更新把其中一项拉长的当天失效。
:::
:::

::: exercise 推导 {level=3}
对$\alpha = 0.1$的超前网络，在两个转折频率处与几何平均处分别求相角，并确认最大相位证明所要求的对称性。
::: solution
在$\omega = 1 / T$处相角为$45^{\circ} - \arctan \alpha = 45^{\circ} - 5.7^{\circ} = 39.3^{\circ}$，在$\omega = 1 / \left( \alpha T \right)$处为$\arctan \left( 1 / \alpha \right) - 45^{\circ} = 84.3^{\circ} - 45^{\circ} = 39.3^{\circ}$——相等，正如关于几何平均的对称性所要求的，因为两个转折位于$\omega_{\max} \sqrt{\alpha}$与$\omega_{\max} / \sqrt{\alpha}$，而相角是$\ln \left( \omega / \omega_{\max} \right)$的奇函数。最大值为
$$
\arcsin \frac{1 - 0.1}{1 + 0.1} = 54.9^{\circ}
\quad \text{在} \quad
\omega = \frac{1}{T \sqrt{0.1}} = \frac{3.16}{T} .
$$
**合理性检验。**最大值比两个转折频率处的值高出十五度半，所以把零点放在穿越频率处、把极点"放在上面某处"的设计师，只能得到网络所能提供相位的三分之二——更糟的是，他把穿越频率放在了两个转折中**较小**的那个处，而网络在那里只有$1 / \sqrt{1 + \alpha^{2}} \ldots $的最终值。超前设计的全部就是摆放，而摆放法则只有一行：把两个转折的**几何平均**放在穿越频率处。
:::

::: exercise 设计 {level=3}
一个液位回路有$G = 2 / \left[ \left( 120 s + 1 \right)\left( 20 s + 1 \right) \right]$和一个每单位控制器输出$0.5\ \mathrm{m^{3} / s}$的阀门。规格是相角裕度$65^{\circ}$，以及对$0.2\ \mathrm{m^{3} / s}$负载变化的稳态偏差不超过量程的$2\ \%$，量程跨度为$5\ \mathrm{m}$。设计一个PI并校核滞后裕度。
::: solution
**由相位预算定穿越频率。**取$T_i = 120\ \mathrm{s}$，
$$
- \arctan \frac{1}{\omega T_i} - \arctan \left( 120 \omega \right) - \arctan \left( 20 \omega \right) = - 115^{\circ}
$$
给出$\omega_{gc} = 0.0233\ \mathrm{rad / s}$，其三项贡献为$- 19.7^{\circ}$、$- 70.2^{\circ}$与$- 25.1^{\circ}$。
**增益。**$\left| G \right| = 2 / \left( 2.95 \times 1.10 \right) = 0.610$，且$\left| C \right| = K_c \sqrt{1 + 0.362^{2}} = 1.064 K_c$，所以
$$
K_c = \frac{1}{0.610 \times 1.064} = 1.54 .
$$
**偏差。**$K_p = K_c K = 3.1$；纯比例回路会留下$0.2 \times 2 / \left( 1 + 3.1 \right) = 0.098\ \mathrm{m}$，即$5\ \mathrm{m}$跨度的$1.96\ \%$——在积分作用起作用之前就已勉强满足规格。积分作用把偏差完全消除，瞬态在$81\ \mathrm{s}$后峰值达$0.44\ \mathrm{m}$，在$550\ \mathrm{s}$后回到百分之二以内。
**滞后裕度。**$\theta_m = \left( 65 \pi / 180 \right) / 0.0233 = 49\ \mathrm{s}$，且$M_s = 1.28$。

**合理性检验。**四十九秒的滞后裕度很宽裕，这正是液位回路最容易整定的原因——但裕度会花在规格没有提到的东西上：泵沿长集管输送的传输滞后、阀门定位器的死区时间、或数字控制器自身的扫描。一台以$2\ \mathrm{s}$扫描与$5\ \mathrm{s}$定位器闭环的液位回路用掉了不到百分之十五的预算，而同一个回路闭环在一台带四十米降液管的蒸馏塔上，就用掉了大半——这就是为什么塔的控制是一门慢艺术而罐的不是。$0.44\ \mathrm{m}$的峰值是要回给工艺工程师的那个数，因为决定罐子是否溢出的正是峰值，而它是规格所写的那个稳态偏差的四倍。
