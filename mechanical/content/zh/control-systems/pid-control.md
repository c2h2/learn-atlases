三个数，十分钟整定，驱动着地球上也许百分之九十的控制回路。这就是比例-积分-微分控制器令人不安的头衔：它是本书中最不精巧的控制器，使用量却以压倒性优势位居第一，而原因不是它最优，而是它对单输入单输出工业回路真正需要什么**在结构上诚实**。比例项在对象没有增益的地方供给增益。积分项消除比例反馈在结构上无法消除的偏差，而且不需要设计师知道扰动是什么。微分项在对象的滞后耗尽相位的地方把相位买回来。没有别的东西像它那样常常恰如所需地够用，也没有别的东西像它那样以如此有趣的方式如此罕见地失效。

教科书少教的是三个常数周围的一切：操作员改变设定点时会踢一脚的微分，阀门顶在限位上时悄悄灌满、一小时后又把存货倾泻出来的积分器，产生灵敏度峰值$2.4$的回路却被叫作"激进"而不是"阻尼不良"的整定法则，以及真实工厂里包围着PID的串级、前馈、分程与特性化函数结构——PID在其中只是一个细小简单的部件。这一课讲算法、整定法则及其真实裕度，以及让PID不惹麻烦的结构。

::: warning 整定法则只是起点，而激进的那些就在悬崖边上
每条经典整定法则都在优化某个东西，而它优化的大多数东西都不是设计师想要的。**齐格勒（Ziegler）-尼科尔斯（Nichols）**法则以四分之一衰减比为靶子——相邻峰值之比为$1 : 4$，阻尼比约$0.2$——而在[[#ex-tunings]]的炉子上，它给出的整定值坐在灵敏度峰值$2.4$上：一个每次扰动之后都会振铃、而对象增益或滞后一旦增大就可能活不下来的回路。**科恩（Cohen）-库恩（Coon）**以同样的四分之一衰减比为靶子，并对滞后作了基于模型的修正，在滞后与惯性之比较小时还要更激进。**λ**与**钱（Chien）-赫罗恩斯（Hrones）-雷斯威克（Reswick）**整定以指定的闭环时间常数或指定的超调量为靶子，是回路要紧时该用的。职业习惯是从λ整定出发，取闭环时间常数等于对象的主导滞后，校核灵敏度峰值不超过约$1.6$，然后才决定回路是否付得起更快——并记下用的是哪条法则，因为一个用齐格勒-尼科尔斯整定、对象此后已被改动的回路，是一个根本没有记录在案裕度的回路。
:::

## 算法及其形式

::: definition 位置式算法的三种形式 {#def-pid-forms}
**理想**（非交互）形式是
$$
u (t ) = K_c \left[ e (t ) + \frac{1}{T_i} \int_0^{t} e \, \mathrm{d} t^{\prime} + T_d \frac{\mathrm{d} e}{\mathrm{d} t} \right],
\qquad
e = y_{sp} - y .
$$
**串联**（交互，气动遗留）形式把滞后与超前相乘，
$$
u = K_c \left( 1 + \frac{1}{T_i s} \right)\left( 1 + T_d s \right) e
  = K_c \left[ 1 + \frac{1}{T_i s} + T_d s + \frac{T_d}{T_i s} \right] e ,
$$
多出一个常数项$T_d / T_i$，所以同样的名义$K_c , T_i , T_d$给出不同的回路：串联控制器等于一个$K_c^{\prime} = K_c \left( 1 + T_d / T_i \right)$、$T_i^{\prime} = T_i + T_d$、$T_d^{\prime} = T_i T_d / \left( T_i + T_d \right)$的理想形式控制器。**并联**形式是$K_p + K_i / s + K_d s$，其中$K_p = K_c$，$K_i = K_c / T_i$，$K_d = K_c T_d$。换算是一一对应的，而控制器文件上写明的形式与录入常数者假定的形式不一致，是一种真实且常见的故障：当$T_d / T_i = 0.25$时，用同样的数，串联形式的比例作用比理想形式的强百分之二十五。
两种实用改法是普遍存在的。微分作用于**测量值**而非误差，
$$
u = K_c \left[ e + \frac{1}{T_i} \int e \, \mathrm{d} t - T_d \frac{\mathrm{d} y}{\mathrm{d} t} \right],
$$
这样设定点的阶跃就不会产生阀门行程的冲击。而微分是**带滤波的**，$T_d s \rightarrow T_d s / \left( \tau_f s + 1 \right)$，其中$\tau_f = T_d / N$、$N$在五到二十之间，因为理想微分器在无穷频率处有无穷增益，而每一个真实传感器都有噪声。
:::

::: proof PID对回路做了什么 {#proof-pid-zeros}
理想PID的传递函数是
$$
C (s ) = K_c \left( 1 + \frac{1}{T_i s} + T_d s \right)
      = \frac{K_c}{T_i s} \left( T_d T_i s^{2} + T_i s + 1 \right)
      = \frac{K_c}{T_i s} \left( 1 + \frac{s}{\omega_1} \right) \left( 1 + \frac{s}{\omega_2} \right) .
$$
**原点一个极点，两个零点，没有高频极点。**伯德签名是精确的：低频处由积分器给出$- 20$ dB/dec，两个零点之间平坦于$20 \log K_c$，其上方$+ 20$ dB/dec，终止于所配的任何滤波器。零点为
$$
\omega_{1,2} = \frac{1 \mp \sqrt{1 - 4 T_d / T_i}}{2 T_d},
\qquad
\omega_z = \frac{1}{\sqrt{T_d T_i}},
\qquad
\zeta_z = \frac{1}{2} \sqrt{ \frac{T_i}{T_d} } ,
$$
所以零点在$T_i \ge 4 T_d$时为**实**，低于该值则是复数对。$\checkmark$
**比值为何要紧。**复数零点对在控制器幅值上贡献一个谐振**峰**，更糟的是贡献一个设计师没有要求、也无法摆放的快速相位**超前**。更直接地说，闭环传递函数把控制器的零点继承为自己的零点，而$\zeta_z = 0.3$的复数零点对会在极点贡献之外再加上自己的超调。这就是实用法则$T_d \le T_i / 4$被引用的原因，也是为什么一个$T_d$与$T_i$被独立整定——由一位一次只动一个旋钮的调试工程师——的控制器，其阶跃响应常有一个谁也无法从回路稳定裕度（它们明明很好）解释的大超调。$\checkmark$
**天花板。**带滤波微分时控制器的高频增益趋于$K_c \left( 1 + N \right)$而非无界增长，所以微分的噪声放大由滤波比$N$而非$T_d$决定。比例加滤波微分部分为$1 + T_d s / \left( \tau_f s + 1 \right) = \left[ 1 + \left( T_d + \tau_f \right) s \right] / \left( 1 + \tau_f s \right)$，是一个超前网络，它在穿越频率处提供的相位为
$$
\Delta \varphi = \arctan \left[ \omega_{gc} \left( T_d + \tau_f \right) \right] - \arctan \left( \omega_{gc} \tau_f \right),
$$
当$\tau_f \ll 1 / \omega_{gc}$时它化简为理想的$\arctan \left( \omega_{gc} T_d \right)$，而且永远不超过$\arcsin \left[ N / \left( N + 2 \right) \right]$——$N = 10$时为$56^{\circ}$——而不是逼近$90^{\circ}$。由此得出的设计法则是$T_d$取$1 / \omega_{gc}$的量级，这已买到$45^{\circ}$：超过它，微分几乎不再供给更多相位，只供给更多噪声和一对必须盯住的零点。$\checkmark$
:::

::: definition 积分饱和及其解法 {#def-windup}
执行器饱和时，回路是**断开**的，而控制器并不知道。积分器继续对着一个不再响应的过程累积，控制器的内部状态——积分器的值——发散到远超让输出停在限位上的那个值。多余的部分必须先倒回去，回路才能重新掌握权力，而倒回的时间是
$$
t_{\text{recovery}} \approx \frac{T_i}{K_c} \cdot \frac{u_{\text{excess}}}{\left| e \right|} ,
$$
对大的多余量这是几分钟而不是几秒。三种解法，按优劣排序：
**反算。**把要求的输出与实际交付的输出之差经增益$1 / T_t$反馈给积分器，
$$
\frac{\mathrm{d} x_i}{\mathrm{d} t} = \frac{K_c}{T_i} e + \frac{1}{T_t} \left( u_{\text{actual}} - u_{\text{demanded}} \right),
$$
它把积分器钉在与饱和相容的值上，并让它从那里继续。$T_t = T_i$是安全的；对PID而言，$T_t = \sqrt{T_i T_d}$是常见的更快选择。
**条件积分。**只要输出饱和**且**误差的符号会把它推得更远，就冻结积分器。便宜，但误差带噪声时会出错。
**外部复位（抗积分饱和反馈）。**用实测的执行器位置作为积分器的限位参考——当真实限位是阀门的行程而不是控制器的钳位时，这是正确答案。
:::

## 整定法则及其实际交付物

::: definition 整定法则家族 {#def-tuning}
给定辨识为带滞后一阶的对象$K \mathrm{e}^{- \theta s} / \left( \tau s + 1 \right)$，记$\rho = \theta / \tau$：

| 法则 | $K_c$ | $T_i$ | $T_d$ | 目标 |
|---|---|---|---|---|
| 齐格勒-尼科尔斯（开环，PID） | $1.2 \tau / \left( K \theta \right)$ | $2 \theta$ | $\theta / 2$ | 四分之一衰减比 |
| 齐格勒-尼科尔斯（闭环，PI） | $0.45 K_u$ | $P_u / 1.2$ | — | 四分之一衰减比 |
| 齐格勒-尼科尔斯（闭环，PID） | $0.6 K_u$ | $P_u / 2$ | $P_u / 8$ | 四分之一衰减比 |
| 科恩-库恩（PI） | $\dfrac{\tau}{K \theta} \left( 0.9 + \dfrac{\rho}{12} \right)$ | $\theta \dfrac{30 + 3 \rho}{9 + 20 \rho}$ | — | 四分之一衰减比 |
| 钱-赫罗恩斯-雷斯威克（PID，设定点，0%超调） | $0.6 \tau / \left( K \theta \right)$ | $\tau$ | $\theta / 2$ | 设定点跟踪，无超调 |
| λ / SIMC（PI） | $\dfrac{\tau}{K \left( \lambda + \theta \right)}$ | $\min \left( \tau , 4 \left( \lambda + \theta \right) \right)$ | — | 闭环时间常数$\lambda$ |

闭环齐格勒-尼科尔斯法则只需要把回路推到持续振荡测得的临界增益$K_u$与临界周期$P_u$，这就是它八十年里一直是现场法则、而每当回路可以被更仔细地整定时它仍然是错误答案的原因。**λ**法则（表中所给的是舍戈斯塔（Skogestad）的SIMC形式，其中的$\min$防止惯性主导对象上的积分时间过长）含有一个连续的设计参数$\lambda$——期望的闭环时间常数——是表中唯一让设计师选择买多少裕度的法则。$\lambda = \theta$是通常的起点，在惯性主导的对象上给出约$1.6$的灵敏度峰值；更大的$\lambda$买到更多裕度，而$\lambda = 0.5 \theta$已把峰值推向$2$。
:::

::: example 同一个炉子的四种整定 {#ex-tunings}
上一课的回流焊炉温区，$K = 0.8\ {}^{\circ}\mathrm{C}$每百分之一，$\tau = 45\ \mathrm{s}$，$\theta = 12\ \mathrm{s}$，用四种方法整定。比较之。
::: solution
**临界增益与临界周期。**相位条件$\omega \theta + \arctan \left( \omega \tau \right) = 180^{\circ}$给出$\omega_u = 0.1437\ \mathrm{rad / s}$，所以
$$
P_u = 43.7\ \mathrm{s}, \qquad
K_u = \frac{\sqrt{1 + \left( \omega_u \tau \right)^{2}}}{K} = \frac{6.54}{0.8} = 8.18 .
$$
**四种整定值**（ZN-PID取$0.6 K_u$、$P_u / 2$、$P_u / 8$；ZN-PI取$0.45 K_u$、$P_u / 1.2$；λ取自表中；最后一行是[[control-systems/frequency-response#ex-design-oven]]的频率响应设计）：

| 整定 | $K_c$ | $T_i$ | $T_d$ | $\omega_{gc}$ | $\varphi_m$ | $M_s$ |
|---|---|---|---|---|---|---|
| ZN-PID | $4.91$ | $21.9$ | $5.47$ | $0.085$ | $42^{\circ}$ | $2.38$ |
| ZN-PI | $3.68$ | $36.4$ | — | $0.067$ | $40^{\circ}$ | $2.36$ |
| λ，$\lambda = \theta$ | $2.34$ | $45$ | — | $0.042$ | $61^{\circ}$ | $1.59$ |
| 频率设计 | $1.64$ | $45$ | — | $0.029$ | $70^{\circ}$ | $1.37$ |

**读表。**齐格勒-尼科尔斯的整定给出的穿越频率比频率设计高近三倍——灵敏度峰值$2.4$对$1.4$。那个峰是其频率处负载扰动的$7.5\ \mathrm{dB}$放大，而一个能稳定的回路与一个会振铃的回路的差别全部在它。
**为什么相角裕度不是全部故事。**ZN-PID在$0.085\ \mathrm{rad / s}$处的$\varphi_m = 42^{\circ}$与其在$0.19\ \mathrm{rad / s}$处的$M_s = 2.38$都是真的，而后一个数才是最终在产品上显现的那个。微分的零点在高频把回路增益又推**了回去**，所以幅值曲线在宽频带内接近$0\ \mathrm{dB}$而不是穿越一次，到临界点的距离比相角裕度暗示的小得多。这就是引用$M_s$而不是两个裕度的标准理由。

**校核。**对ZN-PI整定由$S = 1 / \left( 1 + L \right)$在频率扫描上重新计算$M_s$，得$2.36$于$0.104\ \mathrm{rad / s}$。仿真的设定点阶跃：ZN-PI整定超调$37\ \%$，ZN-PID（微分作用于测量值，$N = 10$）超调$52\ \%$，而λ整定为$4\ \%$，频率设计则没有超调。$\checkmark$

**合理性检验。**齐格勒-尼科尔斯之所以长存，是因为它**可测量**：不需要模型、不需要分析仪，只要操作面板和一块秒表，而一个振荡的回路是一个观察起来毫不含糊的东西。它通常应当被取代的原因是，它的目标——四分之一衰减比——是1942年为手工整定的气动控制器选的，它以鲁棒性换速度，而这种交换是如今很少有应用想要的。在回路必须快的地方，按所需扰动抑制选$\lambda$的λ法则是诚实的方法；而在对象的$\rho = \theta / \tau$很大的地方——本例只有$0.27$——任何PID都无法在大约$1 / \left( 2 \theta \right)$的穿越频率之上给出阻尼良好的响应，滞后占主导时的答案是史密斯预估器或基于模型的控制器。
:::

::: example 开门期间的积分饱和 {#ex-windup}
[[#ex-tunings]]的炉子在$25\ {}^{\circ}\mathrm{C}$的房间里用ZN-PI整定保持$95\ {}^{\circ}\mathrm{C}$，$K_c = 3.68$、$T_i = 36.4\ \mathrm{s}$，加热器限位为$0$–$100\ \%$。一扇门打开两分钟，其冷风被建模为加热器输入处的负载，稳态时相当于$- 30\ {}^{\circ}\mathrm{C}$。比较有无反算时的恢复。
::: solution
**稳态。**所需输出为$\left( 95 - 25 \right) / 0.8 = 87.5\ \%$，只剩$12.5\ \%$的余量。
**门打开。**温度下降，输出几秒内冲到$100\ \%$；回路现在断开了，对象趋向$25 + 0.8 \times 100 - 30 = 75\ {}^{\circ}\mathrm{C}$，误差$20\ {}^{\circ}\mathrm{C}$。到门关上时它已降到$76.1\ {}^{\circ}\mathrm{C}$。
**积分器的速率。**误差接近$20\ {}^{\circ}\mathrm{C}$时，
$$
\frac{\mathrm{d} u_i}{\mathrm{d} t} = \frac{K_c}{T_i} e = \frac{3.68}{36.4} \times 20 = 2.02\ \% \ \text{每秒},
$$
所以两分钟里积分项累积了约两百个百分点的多余量。仿真该回路，控制器的内部要求达到$328\ \%$，而它稍后真正需要的只是$87.5\ \%$。
**门关上。**在多余量被倒回去的过程中，输出又在$100\ \%$停留了四分钟，而温度几乎爬到对象饱和时的稳态值，
$$
y_{\text{sat}} = 25 + 0.8 \times 100 = 105\ {}^{\circ}\mathrm{C},
$$
峰值为$104.9\ {}^{\circ}\mathrm{C}$——对$95\ {}^{\circ}\mathrm{C}$的保温设定点超调$10\ {}^{\circ}\mathrm{C}$。
**带反算**（$T_t = T_i$）时积分器被保持在与饱和相容的值附近，门关上约$50\ \mathrm{s}$后输出就离开限位，峰值为$98.2\ {}^{\circ}\mathrm{C}$——超调只有三分之一。门开着的那段时间里的下冲完全相同，都是$76.1\ {}^{\circ}\mathrm{C}$，因为两种情况下执行器都饱和；抗积分饱和在扰动持续期间一无所获，在扰动之后赢得一切。

**校核。**带反算时，门关上约$100\ \mathrm{s}$后温度回到设定点$0.5\ {}^{\circ}\mathrm{C}$以内；不带时约需$360\ \mathrm{s}$。两条路径也不同：没有抗积分饱和时回路冲过设定点直到$105\ {}^{\circ}\mathrm{C}$再回落；有它时超调小而短暂。$\checkmark$

**合理性检验。**$10\ {}^{\circ}\mathrm{C}$的超调不是控制理论的奇谈；在回流焊炉里它是一块好板子与一块分层板子的区别，在挤出机里是报废的树脂。三条法则可以防止它。控制器里配置输出限位必须是**真实**限位，让控制器知道自己何时失去了权力。高钳位应留出余量——一个静止时需要$87.5\ \%$的回路，全部扰动抑制只有$12.5\ \%$可用，这是加热器设计错误而不是整定错误。而"控制器输出顶在限位超过五分钟"的报警，是唯一能告诉操作员发生了什么的东西，因为在超调到来之前，温度曲线看上去只是迟钝。
:::

::: proof 反算与恢复时间 {#proof-backcalc}
带反算时积分器状态服从
$$
T_t \frac{\mathrm{d} x_i}{\mathrm{d} t} = \frac{T_t K_c}{T_i} e + \left( u_{\text{act}} - u_{\text{dem}} \right) .
$$
饱和期间$u_{\text{act}}$停在限位上为常数，而$u_{\text{dem}} = u_p + x_i$，所以记$x_i^{*}$为使$u_{\text{dem}} = u_{\text{act}}$的值，
$$
T_t \frac{\mathrm{d} x_i}{\mathrm{d} t} = T_t \frac{K_c}{T_i} e - \left( x_i - x_i^{*} \right)
\quad\Longrightarrow\quad
x_i \rightarrow x_i^{*} + \frac{T_t K_c}{T_i} e
$$
时间常数为$T_t$。因此积分器把自身跟踪到饱和值的一个有界偏差$T_t K_c e / T_i$之内而不会发散，退饱和时回路从那里继续，而不必先倒回累积的多余量。$\checkmark$
**选择$T_t$。**小的$T_t$跟踪得紧，但会让积分器跟随每一次短暂进入饱和（包括噪声造成的）；大的$T_t$则让积分器在被拉回之前漂得更远。$T_t = T_i$是安全的默认值；控制器带微分时，阿斯特罗姆（Åström）与黑格伦德（Hägglund）建议$T_t$取在$T_d$与$T_i$之间，例如$\sqrt{T_i T_d}$。这些是经验法则，而非最优解。$\checkmark$
:::

::: definition 串级控制 {#def-cascade}
两个回路，两个测量，两个控制器：**外**（主）环控制器的输出是内（从）环控制器的**设定点**，内环包住过程中更快、测量更好的那部分。
$$
\text{error} \rightarrow \boxed{C_{\text{outer}}} \rightarrow y_{sp,\text{inner}} \rightarrow \boxed{C_{\text{inner}}} \rightarrow u \rightarrow \left[ G_{\text{inner}} \right] \rightarrow y_{\text{inner}} \rightarrow \cdots \rightarrow y_{\text{outer}}
$$
三条法则支配设计。内环必须比外环**快五到十倍**，使它的闭环在外环带宽内近似单位增益、两个回路互不作用。内环必须包住**主导扰动**——这就是整个结构的全部意义。而内环控制器必须**先**整定，外环断开，因为一个未整定的内环会给外环呈现一个谐振负载。
这个结构的代价是一个额外的变送器和一次额外的整定，而它的失效模式是一个其实并不更快的内环，此时两个回路相互作用，即使各自单独整定得很仔细，外环也可能振荡。
:::

::: example 夹套反应器 {#ex-cascade}
一个搅拌反应器由夹套蒸汽加热，以反应器温度受控。蒸汽供压的波动在几秒内扰动夹套温度、在几分钟内扰动反应器温度。夹套对蒸汽阀的响应为增益每百分之一$0.4\ {}^{\circ}\mathrm{C}$、时间常数$40\ \mathrm{s}$、滞后$5\ \mathrm{s}$；反应器对夹套温度的响应为增益每${}^{\circ}\mathrm{C}$为$1.2\ {}^{\circ}\mathrm{C}$（反应热将其放大）、时间常数$900\ \mathrm{s}$、滞后$60\ \mathrm{s}$。设计结构并用λ法则整定。
::: solution
**结构。**内环控**夹套温度**（或控蒸汽流量，那还更快），外环控反应器温度。内环的设定点就是外环控制器的输出。
**时间尺度分离。**两个主导时间常数之比为$900 / 40 = 22$，稳稳高于法则要求的五。
**内环整定。**λ法则取$\lambda = \theta = 5\ \mathrm{s}$：
$$
K_{c,i} = \frac{40}{0.4 \times 10} = 10.0, \qquad T_{i,i} = 40\ \mathrm{s} .
$$
**外环整定。**内环闭合后夹套以单位增益跟随其设定点，大致表现为自身$5\ \mathrm{s}$滞后之后的一个$\lambda = 5\ \mathrm{s}$的一阶惯性。把这$10\ \mathrm{s}$当作额外等效滞后，外环对象为$\theta^{\prime} = 60 + 10 = 70\ \mathrm{s}$、$\tau = 900\ \mathrm{s}$，取$\lambda = \theta^{\prime}$：
$$
K_{c,o} = \frac{900}{1.2 \times \left( 70 + 70 \right)} = 5.4, \qquad T_{i,o} = \min \left( 900 , 4 \times 140 \right) = 560\ \mathrm{s} .
$$
**扰动抑制。**稳态时相当于$10\ {}^{\circ}\mathrm{C}$夹套温度的蒸汽集管压降被内环截住：仿真显示夹套偏差仅在约$20\ \mathrm{s}$后达到峰值$2.0\ {}^{\circ}\mathrm{C}$，$50\ \mathrm{s}$内降到$1\ {}^{\circ}\mathrm{C}$以下。反应器只经由其$900\ \mathrm{s}$的惯性看到这段短暂偏差的积分（约$100\ {}^{\circ}\mathrm{C\, s}$），即使外环尚未动作，偏差也只有约$0.1\ {}^{\circ}\mathrm{C}$。没有串级时，夹套的整整$10\ {}^{\circ}\mathrm{C}$变化会一直持续到慢速外环将其纠正，反应器会在许多分钟的时间尺度上朝$12\ {}^{\circ}\mathrm{C}$的误差漂移。

**校核。**$\lambda = \theta$时内环的灵敏度峰值为$M_s = 1.59$——可接受但谈不上宽裕，这也是当外环很慢时夹套回路常被失配到$\lambda = 1.5 \theta$的原因，此时$M_s = 1.44$。$\checkmark$

**合理性检验。**另一个可选的内环变量是**蒸汽流量**，它更快，还能在供压变化到达夹套之前就将其抑制。它的缺点是流量环看不见直接作用在夹套上的扰动——结垢、冷凝液排出的变化、反应器自身热需求的变化——而且流量信号噪声大、依赖蒸汽密度。经验法则是：内环应包住最要紧的扰动，并使用快速可靠的测量；许多工厂两者兼用，即反应器温度环内套夹套温度环、再内套蒸汽流量环。
:::
:::

::: example 前馈加反馈 {#ex-feedforward}
一个管壳式换热器把产品流从$60$加热到$85\ {}^{\circ}\mathrm{C}$。可测扰动是产品流量$q$与入口温度$T_{in}$；操纵变量是蒸汽阀。设计前馈并校核它给反馈控制器留下了什么。
::: solution
**静态前馈。**稳态下所需热量为$Q = q \rho c_p \left( 85 - T_{in} \right)$，若蒸汽阀到热量的增益为$K_h$，
$$
u_{ff} = \frac{q \rho c_p}{K_h} \left( 85 - T_{in} \right) .
$$
**动态匹配。**产品通路（流量到出口温度）与蒸汽通路（阀门到出口温度）动力学不同。两者都建模为带滞后一阶，$G_d = K_d \mathrm{e}^{- \theta_d s} / \left( \tau_d s + 1 \right)$、$G = K \mathrm{e}^{- \theta s} / \left( \tau s + 1 \right)$，理想前馈为$- G_d / G$，其中
$$
\frac{G_d (s )}{G (s )} = \frac{K_d}{K} \cdot \frac{1 + \tau s}{1 + \tau_d s} \cdot \mathrm{e}^{- \left( \theta_d - \theta \right) s} .
$$
流量通路$\tau_d = 90\ \mathrm{s}$、$\theta_d = 20\ \mathrm{s}$，蒸汽通路$\tau = 40\ \mathrm{s}$、$\theta = 8\ \mathrm{s}$，补偿器是超前-滞后加滞后，
$$
\frac{G_d}{G} = \frac{K_d}{K} \cdot \frac{1 + 40 s}{1 + 90 s} \mathrm{e}^{- 12 s},
$$
它是可实现的，因为扰动通路的滞后**更长**，校正可以等待$12\ \mathrm{s}$仍准时到达。若蒸汽通路的滞后更长，理想补偿器就需要负的滞后——即预测——标准折中是去掉滞后项，把失配留给反馈回路。
**留下的东西。**理想的前馈会什么都不留。实践中增益会有百分之十的错误——$K_h$随冷凝液负荷变化，换热器会结垢——所以反馈控制器的任务是纠正**残差**，那是一个量级为$0.1 \times Q$的阶跃而不是整个扰动。流量增加$20\ \%$而完全不加纠正时，出口温度会降低$0.2 \times 25 = 5\ {}^{\circ}\mathrm{C}$；前馈留下约$0.1 \times 5 = 0.5\ {}^{\circ}\mathrm{C}$的残差给反馈控制器去消除。
**对整定的影响。**因为反馈回路现在处理的是残差而不是完整的阶跃，它可以整定得更保守——更低的穿越频率与更低的灵敏度峰值——这也减少阀门的行程与磨损。

**校核。**在$\omega = 0.02\ \mathrm{rad / s}$处，蒸汽通路的相角为$- \arctan 0.8 - 0.16\ \mathrm{rad} = - 38.7^{\circ} - 9.2^{\circ} = - 47.8^{\circ}$，流量通路为$- \arctan 1.8 - 0.40\ \mathrm{rad} = - 60.9^{\circ} - 22.9^{\circ} = - 83.9^{\circ}$。补偿器贡献$\arctan 0.8 - \arctan 1.8 - 0.24\ \mathrm{rad} = - 22.2^{\circ} - 13.8^{\circ} = - 36.0^{\circ}$，而$- 47.8^{\circ} - 36.0^{\circ} = - 83.8^{\circ}$与流量通路一致，理应如此。$\checkmark$

**合理性检验。**前馈的算术简单，而它的经济性全在**测量**上：一台需要购置、安装和校准的流量计，对比单靠反馈回路会放过去的不合格产品。决定这笔账的法则是：当扰动**大而可测且快**——流量或入口温度——前馈付得起；对一个缓慢不可测的漂移则不划算。而要提防的失效模式是变送器故障：一条由已归零的流量计驱动的前馈通路会把蒸汽阀推到限位，这就是为什么前馈设计都带一个变送器健康检查，在测量失效时退回纯反馈。
:::
:::

::: example 设计 {#ex-design-moulder}
注塑机喷嘴温区是一个$2.4\ \mathrm{kW}$带状加热器装在约$1.6\ \mathrm{kg}$的钢上（热容约$0.8\ \mathrm{kJ / K}$）。在$180\ {}^{\circ}\mathrm{C}$时把加热器输出提高$10\ \%$的阶跃试验，在$15\ \mathrm{s}$滞后之后给出初始斜率$0.30\ {}^{\circ}\mathrm{C / s}$、时间常数$190\ \mathrm{s}$。规格是：保温温度保持到$\pm 1\ {}^{\circ}\mathrm{C}$（对抗螺杆转速$20\ \%$的变化），设定点无明显超调，加热器由$50\ \mathrm{Hz}$电网上群周波周期$2\ \mathrm{s}$的固态继电器开关。设计回路。
::: solution
**模型。**$K = 0.30 \times 190 / 10 = 5.7\ {}^{\circ}\mathrm{C}$每百分之一，$\tau = 190\ \mathrm{s}$，$\theta = 15\ \mathrm{s}$，所以$\rho = 0.079$——就滞后而言是个容易的对象，就执行器而言是个困难的对象。（一致性：$2.4\ \mathrm{kW}$的$10\ \%$是$240\ \mathrm{W}$，而$240 / 800 = 0.30\ {}^{\circ}\mathrm{C / s}$。）
**结构。**温区温度控制，加螺杆转速的**前馈**——它可测、大而快。不用微分：滞后短而传感器慢。
**反馈整定。**λ法则取$\lambda = 2 \theta = 30\ \mathrm{s}$，得到失配的、无超调的响应：
$$
K_c = \frac{190}{5.7 \times 45} = 0.74, \qquad
T_i = \min \left( 190 , 4 \times 45 \right) = 180\ \mathrm{s} .
$$
**执行器约束。**$50\ \mathrm{Hz}$电网上周期$2\ \mathrm{s}$的群周波继电器按整周波开关，每周期$100$个，所以把输出量化成$1\ \%$的台阶。$0.2\ {}^{\circ}\mathrm{C}$传感器噪声经控制器输出为$K_c \times 0.2 = 0.15\ \%$，远低于量化步长，所以不需要死区——但$N = 10$的**微分**会把它放大约十一倍，到约$1.6\ \%$，超过一整个台阶，会让继电器抖动。
**扰动。**螺杆转速增加$20\ \%$，多带走的热量约相当于加热器输出的$2.7\ \%$（$65\ \mathrm{W}$）。PI回路的仿真显示，每百分之一这样的负载产生$0.98\ {}^{\circ}\mathrm{C}$的峰值偏差，出现在负载到来约一分钟后，所以是$2.7\ {}^{\circ}\mathrm{C}$——超出$\pm 1\ {}^{\circ}\mathrm{C}$的规格，而不放弃执行器所需的裕度，重新整定也修不好它。螺杆转速前馈，用机器自身的比能耗曲线拟合静态增益，消除其中约百分之八十五，留下$0.4\ {}^{\circ}\mathrm{C}$。
**无超调。**$\lambda = 2 \theta = 30\ \mathrm{s}$的λ整定给出$\omega_{gc} = 0.022\ \mathrm{rad / s}$、$\varphi_m = 70^{\circ}$、$M_s = 1.35$；仿真的设定点阶跃超调不到百分之一。

**设计点评。**这里有趣的约束不是回路而是**继电器**。$1\ \%$的输出台阶就是$5.7\ {}^{\circ}\mathrm{C}$的稳态温度变化，所以加热器自身的量化已占$\pm 1\ {}^{\circ}\mathrm{C}$带宽的很大一部分，而任何因传感器噪声让输出跳动超过一两个台阶的控制作用，都是在毫无益处地使劲循环加热器。因此这个设计用带宽换执行器寿命，规格中的$\pm 1\ {}^{\circ}\mathrm{C}$靠前馈而非反馈满足。第二件值得说清的事是**区与区之间的耦合**——温度不同的相邻温区会沿料筒导热——这是一个多变量控制器能处理、而一组单回路只能靠各区部分地为对方纠正来处理的扰动；通常的实际答案是在温区之间隔热，并保守地整定每个回路。
:::

::: history
三项控制器早于解释它的许多理论。**尼古拉斯·米诺尔斯基（Nicolas Minorsky）**1922年的论文*"Directional stability of automatically steered bodies"*，源自对舵手操船的观察，首次对船舶自动操舵中的比例、积分与微分作用作了理论分析。具有比例与复位（积分）作用的气动过程控制器在1930年代普及于工业，到1940年前后，三种作用齐备的控制器已是商品。泰勒仪器公司的**约翰·齐格勒（John Ziegler）与纳撒尼尔·尼科尔斯（Nathaniel Nichols）**1942年发表*"Optimum settings for automatic controllers"*——闭环临界灵敏度试验与开环反应曲线法，各附一张整定表——它成为过程控制中被引用最多的论文之一。**科恩（Cohen）与库恩（Coon）**1953年的论文*"Theoretical consideration of retarded control"*针对带滞后的对象改进了反应曲线法则，**钱（Chien）、赫罗恩斯（Hrones）与雷斯威克（Reswick）**1952年的论文给出了按设定点与负载变化下超调量索引的整定值。**奥托·史密斯（Otto J. M. Smith）**1957年的预估器使滞后补偿成为可能。λ法则所源自的内模控制PID整定路线，是**里维拉（Rivera）、莫拉里（Morari）与舍戈斯塔（Skogestad）**1986年的论文，而整定表中给出的是**舍戈斯塔**2003年的SIMC法则。**阿斯特罗姆（Åström）与黑格伦德（Hägglund）**1984年的继电反馈自整定器用一个继电器取代手工试验，复活了齐格勒-尼科尔斯的思想，并进入了许多商用控制器；他们后来的工作帮助使灵敏度峰值成为标准设计目标。
:::

::: quiz
PID的微分项带滤波器实现，$T_d s \rightarrow T_d s / \left( \tau_f s + 1 \right)$。什么决定控制器的高频增益？
- [x] $K_c \left( 1 + N \right)$，其中$N = T_d / \tau_f$——滤波比，不是微分时间
- [ ] $K_c T_d$，仅微分时间
- [ ] $K_c / T_i$，仅积分时间
- [ ] 无论怎么做高频增益都无界
::: solution
滤波微分的增益趋于$T_d / \tau_f = N$，所以连同比例项，控制器的增益趋于$K_c \left( 1 + N \right)$并停在那里。这就是为什么$N$——典型为五到二十——是决定多少传感器噪声到达阀门的参数，也是为什么在$N$固定时改变$T_d$，会改变穿越频率处所供的相位而不改变高频噪声增益。
:::
:::

## 后续内容

这一课的整定法则是[[control-systems/frequency-response]]的频率域设计压缩成的一张表，它们与之交换的灵敏度峰值是[[control-systems/feedback-stability]]的水床，群周波继电器强加的采样周期是[[control-systems/digital-control]]的主题，而串级结构的内环就是[[control-systems/modelling-dynamic-systems]]的一阶模型。

::: summary
- PID是一个积分极点加两个零点；只有当 Ti 至少是 Td 的四倍时零点才是实的，而复数对添上稳定裕度不会揭示的超调。
- 微分必须作用于测量值且必须带滤波；其噪声增益由滤波比 N 决定而不是由 Td 决定。
- 齐格勒-尼科尔斯以四分之一衰减比为靶，在典型的惯性主导对象上交付接近 2.4 的灵敏度峰值；选定闭环时间常数的 λ 整定是家族中让设计师有意买裕度的法则。
- 饱和的执行器断开回路、积分器饱和累积；Tt 量级为 Ti 的反算给多余量设界，把恢复缩短数倍。
- 串级把一个快而测量良好的内环放到主导扰动周围，要求五到十倍的时间尺度分离；前馈把可测扰动从反馈回路的工作量里拿走，让反馈回路得以失配。
- 实践中起约束作用的通常是执行器——阀门的死区、继电器的群周波周期、加热器的供电限位——整定由它决定，而不是由对象决定。
:::

## 习题

::: exercise 串联形式 {level=1 check="0.25"}
一台串联形式PID的$T_i = 20\ \mathrm{s}$、$T_d = 5\ \mathrm{s}$。与使用同样三个数的理想形式PID相比，它的比例增益大出多大比例？（以小数输入。）
::: solution
额外的常数项是$T_d / T_i = 5 / 20 = 0.25$，所以等效比例增益为$K_c \left( 1 + 0.25 \right)$，大出百分之二十五。
:::
:::

::: exercise 微分滤波 {level=1 check="0.4"}
一台PID的$T_d = 4\ \mathrm{s}$，微分滤波器$N = 10$。滤波器的时间常数是多少秒？
::: solution
$\tau_f = T_d / N = 0.4\ \mathrm{s}$。
:::
:::

::: exercise 齐格勒-尼科尔斯 {level=1 check="36.4"}
一个被推到持续振荡的回路以临界周期$43.7\ \mathrm{s}$振荡。PI控制器的齐格勒-尼科尔斯积分时间是多少秒？
::: solution
$T_i = P_u / 1.2 = 36.4\ \mathrm{s}$。
:::
:::

::: exercise λ {level=1 check="96"}
λ整定中$\lambda = \theta = 12\ \mathrm{s}$、对象时间常数$\tau = 190\ \mathrm{s}$，积分时间为$T_i = \min \left( \tau , 4 \left( \lambda + \theta \right) \right)$。哪一支起作用，$T_i$是多少秒？
::: solution
$4 \left( 12 + 12 \right) = 96 < 190$，所以第二支起作用，$T_i = 96\ \mathrm{s}$——而[[#ex-design-moulder]]中$\lambda = 30\ \mathrm{s}$、$\theta = 15\ \mathrm{s}$的注塑机是$4 \times 45 = 180\ \mathrm{s}$。
:::
:::

::: exercise 零点 {level=2}
一台PID的$T_i = 12\ \mathrm{s}$、$T_d = 4\ \mathrm{s}$。它的零点是实的还是复的？阻尼比是多少？
::: solution
$T_i / T_d = 3 < 4$，所以零点是一个复数对，$\zeta_z = 0.5 \sqrt{3} = 0.87$——复的但阻尼良好。
**合理性检验。**要紧的是阻尼比而不是"是不是复的"这个事实本身：$\zeta_z = 0.87$的零点对表现得几乎像两个实零点，对响应的影响很小，而$\zeta_z = 0.3$可能添上很大的超调。因此法则$T_d \le T_i / 4$是保守的，它至今仍在教授的原因是它是一条不等式、背下来就行，而精确零点的算术不是。
:::
:::

::: exercise 临界增益 {level=2 check="4.25"}
对象$2 \mathrm{e}^{- 8 s} / \left( 40 s + 1 \right)$用比例控制闭环。求临界增益与临界周期。（输入临界增益。）
::: solution
解$8 \omega + \arctan \left( 40 \omega \right) = \pi$：$\omega_u = 0.211\ \mathrm{rad / s}$，$P_u = 29.8\ \mathrm{s}$，且
$$
K_u = \frac{\sqrt{1 + \left( 40 \times 0.211 \right)^{2}}}{2} = \frac{8.51}{2} = 4.25 .
$$
**合理性检验。**$29.8\ \mathrm{s}$的临界周期是滞后的$3.7$倍。对任何带滞后一阶对象，这个比值介于二（滞后主导）与四（惯性主导）之间，因为惯性在$180^{\circ}$中贡献$0^{\circ}$到$90^{\circ}$：因此一个以实测周期振荡的回路，在做任何其他试验之前就把滞后告诉你到两倍以内。
:::

::: exercise 积分饱和 {level=2 check="300"}
一台$K_c = 2.5$、$T_i = 60\ \mathrm{s}$的PI控制器在$100\ \%$处饱和，误差恒为$8$个单位。它的积分器累积多快？累积$100\ \%$的多余量要多久？（以秒为单位输入时间。）
::: solution
$\mathrm{d} u_i / \mathrm{d} t = K_c e / T_i = 2.5 \times 8 / 60 = 0.33\ \%$每秒，所以$100\ \%$的多余量需$300\ \mathrm{s}$。
**合理性检验。**五分钟无人察觉的累积，在误差反号后以同样速率倒回去，这就是一个在启动期间饱和过的回路之后十分钟行为反常的原因，也是为什么诊断结论永远是"有人把设定点改得太快"。
:::
:::

::: exercise 串级 {level=2 check="120"}
一个外环的主导时间常数为$600\ \mathrm{s}$。满足五倍分离法则的最慢内环闭环时间常数是多少？内环的闭环响应对外环的滞后做了什么？（以秒为单位输入时间常数。）
::: solution
$600 / 5 = 120\ \mathrm{s}$是允许的最慢内环闭环时间常数，而实践中内环被做到快十倍、即$60\ \mathrm{s}$。它的闭环随后大致表现为自身滞后之后一个时间常数为$\lambda$的一阶惯性，这段惯性加滞后作为额外等效滞后加到外环对象上，外环整定必须计入。
**合理性检验。**这个附加滞后是串级容易被忘记的代价，也是为什么整定得太慢的内环可能让外环比完全没有串级还**糟**：内环的$\lambda + \theta$很容易超过外环对象自身的滞后，此时外环控制器的相角裕度已经花出去、什么都没买到。
:::
:::

::: exercise 推导 {level=3}
对带滞后一阶对象上的PI控制器，通过要求与对象**无滞后**模型构成的闭环为$1 / \left( \lambda s + 1 \right)$，推导λ整定法则，并求放回滞后后的相角裕度。
::: solution
要求闭环$C G / \left( 1 + C G \right)$等于$1 / \left( \lambda s + 1 \right)$，等同于要求开环为$1 / \left( \lambda s \right)$：
$$
C (s ) G_{\text{model}} (s ) = K_c \frac{T_i s + 1}{T_i s} \cdot \frac{K}{\tau s + 1} = \frac{1}{\lambda s} ,
$$
恰好在控制器的零点对消对象极点、剩余积分器被定标时成立：
$$
T_i = \tau , \qquad \frac{K K_c}{T_i s} = \frac{1}{\lambda s}
\quad\Longrightarrow\quad
\boxed{ K_c = \frac{\tau}{K \lambda}, \quad T_i = \tau } .
$$
真实回路增益是上式乘以模型未含的滞后，$L = \mathrm{e}^{- \theta s} / \left( \lambda s \right)$，其穿越频率为$\omega_{gc} = 1 / \lambda$，且
$$
\varphi_m = 90^{\circ} - \omega_{gc} \theta = 90^{\circ} - \frac{\theta}{\lambda}\ \text{rad},
$$
在$\lambda = \theta$时只有$33^{\circ}$。若在模型中用$\mathrm{e}^{- \theta s} \approx 1 - \theta s$近似滞后再推导一遍，得$K_c = \tau / \left[ K \left( \lambda + \theta \right) \right]$，即整定表中的形式，此时$\omega_{gc} = 1 / \left( \lambda + \theta \right)$，$\varphi_m = 90^{\circ} - \theta / \left( \lambda + \theta \right)\ \text{rad}$，在$\lambda = \theta$时为$61.4^{\circ}$。对这一形式要求$\varphi_m \ge 60^{\circ}$，给出$\lambda \gtrsim \theta$。
**合理性检验。**推导使法则的两个弱点显式化。它**对消对象极点**，所以时间常数变化百分之三十的对象不再被对消，回路以一种特定而可预测的方式失谐；它**假定滞后已知且恒定**，所以滞后随吞吐量变化的对象——管道、干燥机、带材线——在其量程的一端是失谐的。两个弱点都是模型匹配整定在实践中被失配到$\lambda \ge \theta$、而不在理论极限上运行的原因。
:::

::: exercise 设计 {level=3 check="4.7"}
一个蒸馏塔再沸器热负荷回路的$K = 0.4\ {}^{\circ}\mathrm{C}$每MW，$\tau = 900\ \mathrm{s}$，$\theta = 120\ \mathrm{s}$。塔板上的成分控制器时间常数为$2400\ \mathrm{s}$，不能容忍周期短于$3000\ \mathrm{s}$的再沸器振荡。用λ法则设计内环并校核约束。（以每${}^{\circ}\mathrm{C}$的MW为单位输入最终控制器增益。）
::: solution
**内环。**λ法则取$\lambda = \theta = 120\ \mathrm{s}$：
$$
K_c = \frac{900}{0.4 \times 240} = 9.4, \qquad T_i = 900\ \mathrm{s} .
$$
**带宽。**穿越落在$\omega_{gc} = 0.00417\ \mathrm{rad / s}$，周期$1508\ \mathrm{s}$——短于成分回路$3000\ \mathrm{s}$的容忍度，所以内环必须失配。
**失配。**要求周期$3000\ \mathrm{s}$意味着$\omega_{gc} \le 0.0021\ \mathrm{rad / s}$，需要$\lambda \approx 360\ \mathrm{s}$：
$$
K_c = \frac{900}{0.4 \times 480} = 4.7, \qquad T_i = 900\ \mathrm{s} ,
$$
给出穿越周期$3016\ \mathrm{s}$、$\varphi_m = 76^{\circ}$、$M_s = 1.25$。
**校核。**$\rho = 120 / 900 = 0.13$，所以对象对滞后友好，失配在鲁棒性上损失很小；但内环的闭环响应——$120\ \mathrm{s}$滞后之后一个$\lambda = 360\ \mathrm{s}$的惯性——与成分对象自身的$2400\ \mathrm{s}$相比已不算快，外环整定必须计入它。

**合理性检验。**塔的控制是串级结构被物理强加、又被经济限制的经典情形：再沸器回路必须快到足以抑制蒸汽压力变化、又慢到不与成分回路自身极慢的动力学打架，而这两个要求在带宽上差着两倍。工业界的答案是从蒸汽压力到再沸器设定点的比值前馈，它根本不必闭合一个快的温度回路就抑制了压力扰动——一个比快串级便宜、且不花成分回路裕度的解。
:::
