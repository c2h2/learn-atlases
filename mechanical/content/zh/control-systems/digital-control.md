大约1985年以来建造的每一个控制回路都跑在计算机上，而它与前八课理论之间的差别，比学生预期的要小、比工程师计划的要大。说它小，是因为一台快计算机的采样-保持非常接近设计中的连续执行器，频率方法几乎原样平移过来；说它大，是因为计算机会引入连续系统绝对没有的三样东西——**一个采样周期的滞后**、**半采样率以上一切东西的混叠**、以及控制器里每个积分器和微分器的**一种离散化选择**——而对一个在设计极限附近运行的回路，每一样都是一阶效应。

整个学科归结为一个映射和三个推论。映射是$z = \mathrm{e}^{sT}$，它把$s$平面的左半折进单位圆，让稳定性从符号问题变成模的问题。三个推论是：半采样滞后的相位拖后，在穿越频率处花费$\omega T / 2$弧度，也是数字回路带宽被采样率封顶的原因；混叠，它把无法测量的噪声放进回路自己的带宽之内；以及离散化，它决定控制器的积分器在其真正要紧的频率上是否还有设计时给它的增益。无视这三样的数字控制设计大多数时候照样工作——这就是为什么那么多这样的设计被交付——然后在某个回路穿越频率恰好在上一版修订中被调高的机器上失效。

::: warning 数字回路会失效、而连续回路不会的三种方式
**混叠不是麻烦，是一个控制输入。**一台$1\ \mathrm{kHz}$采样的传感器上的$950\ \mathrm{Hz}$振动，在数据里表现为一个$50\ \mathrm{Hz}$信号，而$50\ \mathrm{Hz}$在回路带宽之内，所以控制器对它的响应与对真实运动的响应完全一样。回路自身的频率响应里没有任何东西警告这一点，因为混叠分量到达时已经带着它的假频率和满幅值。抗混叠滤波器不是可选项，而它的相位拖后必须计入回路的相位预算——一个把裕度花在带宽上、然后再加上一个$4\ \mathrm{kHz}$双极点滤波器的设计，已经悄悄在穿越频率处又花掉了$20^{\circ}$。
**计算滞后是第二个未被建模的滞后。**采样在$t = 0$发生，控制在$t = T$算出并写出，对象在$t = T$看到它——在保持器已计入的半周期之上，再加整整一个周期的滞后。设计师建模了那个"半"、忘了那个"整"，而一个在$\omega T = 0.5$处有$20^{\circ}$裕度的回路，会把它没有建模的滞后吃掉的$28^{\circ}$输掉。
**微分的离散化是一个设计决策，不是细节。**后向差分$\left( e_k - e_{k - 1} \right) / T$与塔斯廷形式在奈奎斯特频率处的相位差两倍，在穿越频率处的差别也足以让一个重度微分的回路仅仅改变采样代码、别的什么都不动，就能变稳定或变不稳定。如果一个回路的稳定性会因为积分器从前向改成梯形而改变，这个回路就从未被鲁棒地设计过。
:::

## 采样与z变换

::: definition 采样、保持器与半采样滞后 {#def-sampling}
理想采样器把连续信号乘以一串脉冲；真实的采样器每$T$秒取一个值，并用**零阶保持器**把它保持到下一次。保持器的传递函数是
$$
H (s ) = \frac{1 - \mathrm{e}^{- sT}}{s},
$$
其频率响应的幅值为$T \operatorname{sinc} \left( \omega T / \left( 2 \pi \right) \right)$，相角为
$$
\angle H = - \frac{\omega T}{2},
$$
恰好是一个**半采样滞后**。奈奎斯特频率为$\omega_N = \pi / T$，采样信号中任何高于$\omega_N$的分量，在采样之后都会以其混叠$\left| \omega - 2 \pi k / T \right|$出现在$\left[ 0 , \omega_N \right]$之内，幅值不变、相位共轭。
:::

::: definition z变换与保持器等效离散对象 {#def-z}
采样序列的$z$变换是$\mathcal{Z} \left\{ x_k \right\} = X (z ) = \sum_{k = 0}^{\infty} x_k z^{- k}$，而映射$z = \mathrm{e}^{sT}$把虚轴搬到单位圆上、把左半平面搬进其内部、把带域$\left| \operatorname{Im} s \right| < \pi / T$一一映射。稳定性是$\left| z \right| < 1$。
连续对象$G (s )$的**保持器等效**离散传递函数是
$$
G (z ) = \left( 1 - z^{- 1} \right) \mathcal{Z} \left\{ \frac{G (s )}{s} \right\},
$$
对一阶对象给出闭式
$$
G (s ) = \frac{1}{\tau s + 1}
\quad\Longrightarrow\quad
G (z ) = \frac{1 - \mathrm{e}^{- T / \tau}}{z - \mathrm{e}^{- T / \tau}} .
$$
积分器$1 / s$的三种标准离散化是：**前向**的$T / \left( 2 z^{- 1} \right)$族选择$T z / \left( z - 1 \right)$、**后向**的$T / \left( 1 - z^{- 1} \right)$，以及**梯形或塔斯廷（Tustin）**的$\left( T / 2 \right) \left( 1 + z^{- 1} \right) / \left( 1 - z^{- 1} \right)$，分别对应代换$s \rightarrow \left( z - 1 \right) / T$、$s \rightarrow \left( 1 - z^{- 1} \right) / T$与$s \rightarrow \left( 2 / T \right) \left( z - 1 \right) / \left( z + 1 \right)$。
:::

caption: 离散积分器的增益相对于理想 $1 / \left( \mathrm{j} \omega \right)$ 之比，横轴为 $\omega T$。两者在低频都趋于 1。后向差分读数偏高，且在 $\omega T$ 趋于 $\pi$ 时发散；塔斯廷形式读数偏低，并在奈奎斯特频率处降到 **零**，其分子 $1 + z^{- 1}$ 在那里为零。因此用塔斯廷积分器的倒数实现的微分器，在奈奎斯特频率处有一个零点——这是一个真实且常常不受欢迎的特征，属于那个在连续时间中设计、从未被注意到的控制器。
:::

::: example 一阶对象的保持器等效 {#ex-zoh}
一个温度回路$G = 0.8 / \left( 45 s + 1 \right)$，每$T = 1\ \mathrm{s}$采样一次。求离散对象，并求离散化在$0.03\ \mathrm{rad / s}$穿越频率处引入的相位误差。
::: solution
**离散对象。**由$\mathrm{e}^{- T / \tau} = \mathrm{e}^{- 1 / 45} = 0.9782$，
$$
G (z ) = 0.8 \times \frac{1 - 0.9782}{z - 0.9782} = \frac{0.01744}{z - 0.9782} .
$$
**直流增益。**$G (1 ) = 0.01744 / 0.0218 = 0.800$ $\checkmark$——保持器等效精确保持直流增益，这正是让设计得以平移的性质。
**极点位置。**连续极点$- 1 / 45 = - 0.0222\ \mathrm{s^{- 1}}$映射到$\mathrm{e}^{- 0.0222} = 0.9782$，到单位圆的距离为$0.0218$，而连续距离为$0.0222$——$2\ \%$的误差，因为$T \ll \tau$所以很小。
**相位误差。**保持器在$0.03\ \mathrm{rad / s}$处的拖后为
$$
\frac{\omega T}{2} = \frac{0.03 \times 1}{2} = 0.015\ \mathrm{rad} = 0.86^{\circ},
$$
相对回路的$69^{\circ}$相角裕度可以忽略。

**校核。**$G \left( \mathrm{e}^{\mathrm{j} \omega T} \right)$在$\omega = 0.03$处的精确离散相位是$- 54.33^{\circ}$，连续对象为$- 53.47^{\circ}$——差$0.86^{\circ}$，与半采样估计吻合到百分之一度，这就是保持器相位确实是精确的$\omega T / 2$而非近似的算术证明。$\checkmark$

**合理性检验。**从这套算术里掉出来的法则是每家驱动器厂商都印的那条：**采样至少比回路穿越频率快二十倍**，而在那个比值下保持器的代价是$\omega_{gc} T / 2 = 0.025\ \mathrm{rad} = 1.4^{\circ}$，只是一个舍入误差。这条法则说的不是对象的极点——它在任何合理速率下都良性地离散化——而是保持器的相位，它随穿越频率线性增长，根本不在乎对象有多慢。
:::
:::

::: example 混叠算例 {#ex-alias}
一个位置传感器以$1\ \mathrm{kHz}$采样。机器把一次$1.499\ \mathrm{kHz}$的结构振动以$2\ \mathrm{mm}$幅值传进传感器，控制回路的灵敏度峰值为$1.5$、位于$10\ \mathrm{Hz}$。回路看到什么、做了什么？
::: solution
**良性情形。**以$f_s = 1000\ \mathrm{Hz}$采样，$f = 1499\ \mathrm{Hz}$处的分量出现在$\left| 1499 - 1000 \right| = 499\ \mathrm{Hz}$——在第一奈奎斯特区之内、但远高于回路的$10\ \mathrm{Hz}$带宽，那里灵敏度为$0.02$，所以回路把它抑制掉，什么都没发生。
**危险情形。**把振动改成$1049\ \mathrm{Hz}$，混叠就是$\left| 1049 - 1000 \right| = 49\ \mathrm{Hz}$：回路看到一个货真价实的$49\ \mathrm{Hz}$、幅值$2\ \mathrm{mm}$的信号。
**响应。**$49\ \mathrm{Hz}$处灵敏度接近峰值，$\left| S \right| \approx 1.4$，所以回路**跟随**这个假信号而不是抑制它，指令移动了$2.8\ \mathrm{mm}$当量，而操作员看到轴在一个机器上没有任何部件在振动的频率上振荡。
**破绽。**混叠扰动在回路重新整定时不变，在机器放慢时不变，而在采样率改变时**表观频率反转**——最后一条就是诊断法。把$f_s$从$1\ \mathrm{kHz}$提到$1.2\ \mathrm{kHz}$，$1049\ \mathrm{Hz}$分量的混叠就从$49\ \mathrm{Hz}$移到$151\ \mathrm{Hz}$，而一个随采样率改变而频率跳变的振荡就是混叠。

**校核。**实信号以$f_s$采样的一般混叠公式是$f_{\text{alias}} = \left|\, \operatorname{round} \left( f / f_s \right) f_s - f \,\right|$，对$f = 1049$、$f_s = 1000$给出$\left| 1000 - 1049 \right| = 49$ $\checkmark$

**合理性检验。**这是控制问题而不是信号处理问题的原因，在于控制器会对混叠**动作**。数据采集工程师混叠了一个测量，得到的是一张坏图；控制工程师得到的是一个极限环，而回路自身的增益被加到了假信号上。补救是转换器之前的模拟抗混叠滤波器——一个取五分之一奈奎斯特频率的二阶巴特沃斯，在$50\ \mathrm{Hz}$穿越频率处花费$2 \arctan \left( 2 \times 50 / 500 \right) \approx 23^{\circ}$，必须从一开始就写进相位预算。
:::

## 离散设计

::: definition 稳定性检验与离散根轨迹 {#def-zstab}
离散回路稳定当且仅当所有闭环极点都在单位圆内。**朱里（Jury）判据**对多项式$P (z ) = a_n z^n + \cdots + a_0$扮演劳斯的角色，要求$P (1 ) > 0$、$\left( - 1 \right)^n P \left( - 1 \right) > 0$以及一张行列式条件表；**双线性或默比乌斯（Möbius）变换**$z = \left( 1 + w \right) / \left( 1 - w \right)$把单位圆盘映到$w$平面的左半平面，让劳斯阵列可以原样使用。
**离散根轨迹**对$1 + K G (z ) = 0$画在$z$平面上，可接受的二阶行为区域是$z = 1$附近一个小圆的内部：等阻尼比$\zeta$线是**螺线**$\left| z \right| = \mathrm{e}^{- \zeta \omega_n T / \sqrt{1 - \zeta^{2}}}$，等固有频率线是对数螺线，所以熟悉的$s$平面设计楔形变成一个随$T$增大而收缩的弯曲区域。
:::

::: proof 半采样滞后与带宽天花板 {#proof-halfsample}
**保持器的相位。**由$H (s ) = \left( 1 - \mathrm{e}^{- sT} \right) / s$，写
$$
1 - \mathrm{e}^{- \mathrm{j} \omega T} = \mathrm{e}^{- \mathrm{j} \omega T / 2} \left( \mathrm{e}^{\mathrm{j} \omega T / 2} - \mathrm{e}^{- \mathrm{j} \omega T / 2} \right)
= 2 \mathrm{j} \sin \frac{\omega T}{2} \ \mathrm{e}^{- \mathrm{j} \omega T / 2},
$$
所以$\angle H = 90^{\circ} - 90^{\circ} - \omega T / 2 = - \omega T / 2$精确成立，且$\left| H \right| = T \sin \left( \omega T / 2 \right) / \left( \omega T / 2 \right)$。因此保持器就是一个纯半采样滞后乘以一个实的sinc——滞后是精确的，幅值下坠是对理想滞后的唯一偏离。$\checkmark$
**天花板。**一个穿越频率为$\omega_{gc}$、带一个周期计算滞后加保持器半滞后的回路，滞后引起的相位损失为
$$
\Delta \varphi = \frac{3}{2} \omega_{gc} T .
$$
要求$\Delta \varphi$不超过典型的$60^{\circ}$裕度的三分之一——二十度，$0.35\ \mathrm{rad}$——得
$$
\omega_{gc} T \le \frac{2 \times 0.35}{3} = 0.23
\qquad\Longleftrightarrow\qquad
f_s \ge \frac{2 \pi}{0.23} f_{gc} \approx 27 f_{gc} .
$$
这就是每家运动控制器厂商引用的"二十到三十倍"法则的来历：它不是关于采样的定理，而是关于设计师愿意在计算机身上花掉多少相位预算的算术陈述。$\checkmark$
**法则管不到的地方。**一个**本来就有**传输滞后$\theta$的对象，总滞后为$\theta + 1.5 T$，天花板变成
$$
\omega_{gc} \le \frac{0.35}{\theta + 1.5 T},
$$
所以一个$\rho = \theta / \tau$已达$0.3$的对象，约束它的是自己的物理而不是采样率，把$T$减半几乎买不到什么。反过来，一个$\theta = 0$的刚性机械轴几乎完全受$T$限制，采样率翻倍买到可实现带宽的按比例增长——这就是为什么伺服驱动器行业的采样率随它们驱动的机器的带宽一起上升、又在机械成为极限时停止上升。
:::

::: example 双积分器的无差拍控制 {#ex-deadbeat}
一个质点$\ddot{x} = u$，经周期$T$的零阶保持器驱动，要从静止到静止、在尽可能短的时间内移动距离$x_0$。求控制序列。
::: solution
**离散模型。**以状态$\left[ x , v \right]^{T}$，
$$
\begin{bmatrix} x \\ v \end{bmatrix}_{k + 1}
= \begin{bmatrix} 1 & T \\ 0 & 1 \end{bmatrix}
\begin{bmatrix} x \\ v \end{bmatrix}_k
+ \begin{bmatrix} T^{2} / 2 \\ T \end{bmatrix} u_k .
$$
**两步是最少的**，因为一步只有一个自由度、却有两个条件要满足。要求从$\left[ x_0 , 0 \right]$出发$x_2 = v_2 = 0$，得
$$
\begin{bmatrix} 1.5 T^{2} & 0.5 T^{2} \\ T & T \end{bmatrix}
\begin{bmatrix} u_0 \\ u_1 \end{bmatrix}
= - \begin{bmatrix} x_0 \\ 0 \end{bmatrix}
\quad\Longrightarrow\quad
u_0 = - \frac{x_0}{T^{2}}, \qquad u_1 = + \frac{x_0}{T^{2}} .
$$
**轨迹。**$x \left( T \right) = x_0 + \tfrac{1}{2} T^{2} u_0 = 0.5 x_0$，$v \left( T \right) = - x_0 / T$；质点在$t = 2 T$以零速度到达原点，**从不过冲**。
**代价。**所需加速度是$x_0 / T^{2}$：采样周期减半把它**变成四倍**。对$T = 1\ \mathrm{ms}$的平台上$0.1\ \mathrm{m}$的移动，$u_0 = 10^{5}\ \mathrm{m / s^{2}}$，而无论质量还是力，都不存在给得出这个数的执行器。

**校核。**代入：$x_1 = x_0 - 0.5 x_0 = 0.5 x_0$，$v_1 = - x_0 / T$，$x_2 = 0.5 x_0 - x_0 + 0.5 x_0 = 0$，$v_2 = - x_0 / T + x_0 / T = 0$ $\checkmark$

**合理性检验。**无差拍就是所有极点都在原点的极点配置设计——最快的离散响应、这个框架产出的最激进控制器，也是它几乎从不裸用的原因。它的两个标准缺陷是这里展示的惊人控制功和**零鲁棒性**：假定质量有百分之十的误差，就留下一个永不衰减的残余振荡，因为两步之后无差拍不再有任何反馈作用。实用形式是把极点向$\left| z \right| \approx 0.7$内移的类无差拍极点配置——那是主导极点近似的离散版本——再加上[[control-systems/pid-control]]的执行器限位。
:::
:::

::: example 从模拟设计到数字PID {#ex-dpid}
把例1的炉子PI——$K_c = 3.68$、$T_i = 36.4\ \mathrm{s}$——转换成$T = 1\ \mathrm{s}$的数字控制器，给出差分方程。
::: solution
**塔斯廷积分。**$1 / s \rightarrow \left( T / 2 \right) \left( 1 + z^{- 1} \right) / \left( 1 - z^{- 1} \right)$，所以对$u = K_c e + K_c \int e / T_i$，
$$
u_k = K_c e_k + u_{i, k},
\qquad
u_{i, k} = u_{i, k - 1} + \frac{K_c T}{2 T_i} \left( e_k + e_{k - 1} \right),
$$
代入数字$K_c T / \left( 2 T_i \right) = 3.68 / 72.8 = 0.0506$：
$$
\boxed{ u_k = 3.68\, e_k + u_{i, k - 1} + 0.0506 \left( e_k + e_{k - 1} \right) }
$$
**抗积分饱和。**积分器用反算钳位，$u_{i,k} \leftarrow u_{i,k} + \left( u_{\text{sat}} - u_k \right)$，跟踪时间常数按连续设计取$T_i$。
**穿越频率处的积分作用。**在$\omega_{gc} = 0.104\ \mathrm{rad / s}$处，塔斯廷积分器的增益误差是$0.09\ \%$，因为$\omega T / 2 = 0.052$——在回路真正工作的地方，离散化基本上是精确的。
**不精确的地方。**在奈奎斯特频率$\omega_N = \pi = 3.14\ \mathrm{rad / s}$处，塔斯廷积分器的增益是**零**（见上图），所以控制器的高频增益只有$K_c$，奈奎斯特处的回路增益是$3.68 \times 0.8 / \sqrt{1 + \left( 45 \times 3.14 \right)^{2}} = 0.021$——比一小三十四分贝，所以离散化不可能让这个回路失稳。

**校核。**用保持器等效对象，由$1 + C (z ) G (z ) = 0$得到的离散回路特征多项式的根是$z = 0.9675$与$z = 0.9486$，都是实的，经$s = \ln z / T$映回为$- 0.0330$与$- 0.0528\ \mathrm{s^{- 1}}$。连续设计的极点是$- 0.0327$与$- 0.0549\ \mathrm{s^{- 1}}$，所以离散化把它们移动了百分之一和四——并注意连续回路在这里本身就是两个实极点，而不是$Z_i = 36.4\ \mathrm{s}$的积分时间本想避开的那对振荡极点。$\checkmark$

**合理性检验。**这个例子是故意选得良性的：$T = 1\ \mathrm{s}$下的慢热回路$\omega_{gc} T = 0.10$，离散化不可见。对$40\ \mathrm{rad / s}$的位置伺服在$T = 1\ \mathrm{ms}$下重复同样的转换，$\omega_{gc} T = 0.04$，同样良性。麻烦出现在设计师把$1\ \mathrm{ms}$的电流环代码拿去复用于$200\ \mathrm{Hz}$的张力回路时，那里$\omega_{gc} T = 1.26$、塔斯廷积分器的增益误差是$36\ \%$——回路的积分作用比设计少了三分之一、稳态误差是规格的三倍，却没有失稳可以指认。
:::

::: example 设计 {#ex-design-servo}
为PWM载波$8\ \mathrm{kHz}$的例7双质量伺服设计数字位置回路，穿越频率$32\ \mathrm{rad / s}$。
::: solution
**采样周期。**电流控制的驱动器在调制中心对齐时以载波的半周期更新，得$T = 62.5\ \mu\mathrm{s}$；加上一个计算周期的额外滞后，总计$1.5 T = 94\ \mu\mathrm{s}$。
**滞后代价。**在穿越频率处，
$$
\Delta \varphi = 1.5 \omega_{gc} T = 1.5 \times 32 \times 62.5 \times 10^{- 6} = 0.003\ \mathrm{rad} = 0.17^{\circ},
$$
完全可忽略。比值$f_s / f_{gc} = 16{,}000 / 5.1 = 3100$，比二十倍法则高出三个数量级。
**真正的极限。**联轴器的反共振在$200\ \mathrm{rad / s}$、共振在$283\ \mathrm{rad / s}$，而采样率与此毫无关系。
**采样率真正咬人的地方。**驱动器内部的电流环，其穿越频率通常是调制频率的五分之一，即$1.6\ \mathrm{kHz}$或$10{,}000\ \mathrm{rad / s}$，那里$\omega_{gc} T = 0.63$、滞后损失$1.5 \times 0.63 = 0.95\ \mathrm{rad} = 54^{\circ}$——其相位预算的大半花在了计算机上。这就是电流环是驱动器里最难的数字控制问题的原因，也是高性能驱动器采用一步无差拍电流控制、用基于模型的预测提前一步算出电流的原因。
**预测。**由当前电流预测下一个电流，$\hat{i}_{k + 1} = \Phi i_k + \Gamma u_k$，并对$\hat{i}_{k + 1}$而不是$i_k$施加算出的控制，就把整整一个采样周期的滞后找了回来，代价是一次乘加——这是数字电机控制中最有价值的一个技巧，也是一台$16\ \mathrm{kHz}$驱动器能守住$6\ \mathrm{kHz}$电流环带宽的原因。

**设计点评。**这个例子的算术就是"我需要多快的采样率？"这个问题的诚实回答，即：**采样率在位置回路上从来不是极限，在电流回路上几乎总是极限。**$32\ \mathrm{rad / s}$的位置回路能容忍$T = 1\ \mathrm{ms}$；$10{,}000\ \mathrm{rad / s}$的电流环没有预测就容忍不了超过约$100\ \mu\mathrm{s}$的$T$。用一条采样率法则设计这两个回路，会浪费位置回路的裕度、饿死电流环，而标准架构——载波速率下的快电流环、其两倍速率下的速度环、四倍速率下的位置环——就是这个权衡的实用解。第二个结论是：采样率问题不由回路的带宽回答，而由回路自身对象的**滞后-时间常数比**回答，与连续情形完全一样：电流环的对象是一个时间常数为毫秒级的$L / R$，所以$62.5\ \mu\mathrm{s}$的采样是它的十分之一；而位置回路的是一个根本没有时间常数的刚体，所以采样率是免费的。
:::

::: history
采样数据控制始于战时由离散轴与气动逻辑运行的火控与鱼雷制导机构，始于**德索尔（C. A. Desoer）与陶（J. B. Tou）**1955年的论文*"The discrete (z) transform and its application to sampled-data control systems"*——它把这个学科放上了数学地基。这个变换的名字来自**扎德（Lotfi A. Zadeh）**1952年的论文，而**拉加齐尼（John R. Ragazzini）**在哥伦比亚大学的课题组——**伍德（Wood）、雷斯尼克（Resnick）、斯库尼克（Skurnik）、德索莱（De Sole）与内特堡（Netburg）**——1958年出版了首个教科书处理；**郭（Benjamin Kuo）**1958年的《采样数据控制系统》（*Sampled-Data Control Systems*）与**富兰克林（Franklin）与达文波特（Davenport）**1959年的著作把符号标准化了一代人。**卡尔曼（Kalman）与伯特伦（Bertram）**1960年的论文把李雅普诺夫方法带进离散域。
**双线性变换**是**塔斯廷（Arnold Tustin）**1947年用差分方程逼近微分方程的电气工程近似，做法是令梯形法则等于精确积分；让它在一个频率上精确的预畸变精化在1960年代成为标准。**时间最优**或无差拍控制是**费尔德鲍姆（A. A. Feldbaum）**1953至1956年的理论，以俄文发表在《苏联科学院院报》（*Doklady Akademii Nauk*）上、直到1965年才有译本，比西方教科书通过庞特里亚金（Pontryagin）1956年的极大值原理重新发现的开关结果早了十年。
**阿斯特罗姆（Karl Johan Åström）**1965年的论文*"A new design method for digital control systems"*与其1970年的《随机控制理论导论》（*Introduction to Stochastic Control Theory*）把离散处理与最小方差调节器带入主流；**阿斯特罗姆（Åström）与维滕马克（Wittenmark）**1984年的《计算机控制系统》（*Computer-Controlled Systems*，2011年第三版）至今仍是标准教科书，也是大多数从业工程师的采样启蒙书。**抗混叠**与量化的文献来自**奈奎斯特（Harry Nyquist）**1928年的电报传输论文、**哈特利（Ralph V. L. Hartley）**1928年的信息率结果、**奥利弗（Warren Oliver）、皮尔斯（John Pierce）与香农（Claude Shannon）**1928年的脉冲编码调制专利，以及**贝内特（W. R. Bennett）**1925与1933年的量化噪声分析——全部出自同一个十年的贝尔实验室，全部不是为控制工程师写的，这就是为什么控制文献至今把混叠当作事后补充。

## 后续内容

半采样滞后是[[control-systems/feedback-stability]]的传输滞后换了个由设计师时钟设定的数值重新出现；离散根轨迹是[[control-systems/root-locus]]的根轨迹画在一张设计楔形会弯曲的曲面上；例5的抗积分饱和在软件里原样照那课实现；而例6的电流环是[[control-systems/modelling-dynamic-systems]]的电气模型，处在其自身时间常数不再可忽略的那个采样率上。

::: summary
- 采样给出映射 $z = \mathrm{e}^{sT}$，把左半平面折进单位圆，让稳定性成为模的问题。
- 零阶保持器恰是一个半采样滞后加一个 sinc 下坠；加上一个计算周期共 $1.5 T$，在穿越频率处花费 $1.5 \omega_{gc} T$ 弧度。
- "二十倍带宽"法则是那句相位预算陈述，不是定理；自带传输滞后的对象受限于两者之和。
- 混叠把无法测量的高频噪声以满幅值放进回路带宽、再施以回路的全部增益；抗混叠滤波器的相位属于预算之内。
- 离散化选择——前向、后向、塔斯廷——在 $\omega_{gc} T$ 超过约 $0.3$ 时于穿越频率处相差几十个百分点，而塔斯廷积分器在奈奎斯特频率处有一个零点。
- 无差拍是所有极点在原点的离散极点配置：最快、最激进、对一切都不鲁棒；实用设计把极点内移并提前一步预测。
:::

::: quiz
一个数字回路同时提高穿越频率并把采样周期减半。采样-保持与计算滞后花掉的相位会怎样？
- [x] 不变，因为损失是 $1.5 \omega_{gc} T$，而乘积固定
- [ ] 减半
- [ ] 加倍
- [ ] 仅当对象没有传输滞后时才不变
::: solution
滞后损失是$1.5 \omega_{gc} T$弧度，穿越频率加倍、周期减半，乘积原地不动。带宽与采样率必须互相交换而不是同时提高，有用的动作是让采样率远快于穿越频率地提高，让这一项彻底退出相位预算。
:::
:::

## 习题

::: exercise 奈奎斯特 {level=1 check="500"}
一个信号以 $1\ \mathrm{kHz}$ 采样。不发生混叠所能表示的最高频率是多少赫兹？
::: solution
$500\ \mathrm{Hz}$，即奈奎斯特频率 $f_s / 2$。

::: exercise 保持器 {level=1 check="0.5"}
零阶保持器贡献多少个采样周期的滞后？
::: solution
半个采样，$T / 2$。
:::

::: exercise 映射 {level=1 check="1"}
连续时间中虚轴上的极点映射到 $\left| z \right|$ 的什么值？
::: solution
一——虚轴就是单位圆，所以临界稳定的连续系统在离散意义下也临界稳定。
:::

::: exercise 塔斯廷 {level=1 check="2"}
双线性代换是 $s \rightarrow (c) \left( z - 1 \right) / \left( z + 1 \right)$。用采样周期 $T$ 表示 $c$。
::: solution
$c = 2 / T$。
:::

::: exercise 混叠 {level=2}
一个 $1049\ \mathrm{Hz}$ 分量先以 $1\ \mathrm{kHz}$ 采样、再以 $1.2\ \mathrm{kHz}$ 采样。给出两个混叠频率。
::: solution
$\left| 1000 - 1049 \right| = 49\ \mathrm{Hz}$ 与 $\left| 1200 - 1049 \right| = 151\ \mathrm{Hz}$。
**合理性检验。**表观频率随采样率改变而移动，是区分混叠分量与真实分量的诊断法，而且免费：把采样率改一分钟，看着频谱仪就行。
:::
:::

::: exercise 保持器等效 {level=2}
求 $G = 2 / \left( 2 s + 1 \right)$ 在 $T = 0.5\ \mathrm{s}$ 下的保持器等效离散传递函数，并校核其直流增益。
::: solution
由 $\mathrm{e}^{- T / \tau} = \mathrm{e}^{- 0.25} = 0.7788$，
$$
G (z ) = \frac{2 \times 0.2212}{z - 0.7788} = \frac{0.4424}{z - 0.7788},
\qquad G (1 ) = \frac{0.4424}{0.2212} = 2.000 .
$$
**合理性检验。**直流增益按构造被精确保持，而极点到单位圆的距离 $\left| 1 - z \right| = 0.2212$，与无量纲的连续极点 $\left| s \right| T = 0.5 \times 0.5 = 0.25$ 相比——$12\ \%$ 的误差，良性，因为 $T$ 是时间常数的四分之一，而那正是一条一阶对象可以被任何标准方法离散化而设计察觉不到的边界。
:::
:::

::: exercise 滞后预算 {level=2}
一个回路穿越频率 $20\ \mathrm{Hz}$、采样周期 $2\ \mathrm{ms}$。给出保持器与一个计算周期各花掉多少度的相位。
::: solution
$\omega_{gc} = 157\ \mathrm{rad / s}$，所以保持器花 $\omega_{gc} T / 2 = 0.079\ \mathrm{rad} = 4.5^{\circ}$，计算周期再花 $8.9^{\circ}$，共 $13.4^{\circ}$。
**合理性检验。**十三度是正常相角裕度的四分之一，而这里的采样率只是穿越频率的二十倍——厂商法则的下限。把 $T$ 减半找回七度，这在数字回路上常常是最便宜、且不需要任何机械改动的稳定性改善。
:::
:::

::: exercise 无差拍 {level=2}
对例4的双积分器，$T = 2\ \mathrm{ms}$、移动 $2\ \mathrm{mm}$，给出两个控制值与以 $g$ 计的峰值加速度。
::: solution
$u_0 = - x_0 / T^{2} = - 2 \times 10^{- 3} / 4 \times 10^{- 6} = - 500\ \mathrm{m / s^{2}}$、$u_1 = + 500\ \mathrm{m / s^{2}}$，峰值 $51\ g$。
**合理性检验。**五十个 $g$ 在一台小音圈平台上拿得出、在皮带驱动的轴上拿不出，而标度 $u_0 \propto x_0 / T^{2}$ 说明减少它的唯一办法是更长的行程、与采样率无关的更慢曲线，或把无差拍约束从两步放宽到三步——这就是为什么工业运动曲线是梯形或S曲线，而无差拍被关在磁盘磁头与键合机的范围里。
:::
:::

::: exercise 推导 {level=3}
从零阶保持器的定义推导保持器等效离散传递函数 $G (z ) = \left( 1 - z^{- 1} \right) \mathcal{Z} \left\{ G (s ) / s \right\}$。
::: solution
保持器的输出是一串阶跃：$u (t ) = \sum_k u_k \left[ 1 \left( t - kT \right) - 1 \left( t - \left( k + 1 \right) T \right) \right]$，所以其拉普拉斯变换为$U (s ) = \left( 1 - \mathrm{e}^{- sT} \right) \sum_k u_k \mathrm{e}^{- k s T} / s = \left( 1 - \mathrm{e}^{- sT} \right) U (z ) / s$。对象的采样输出因而是
$$
Y (z ) = \mathcal{Z} \left\{ G (s ) \frac{1 - \mathrm{e}^{- sT}}{s} U (z ) \right\}
= \left( 1 - z^{- 1} \right) \mathcal{Z} \left\{ \frac{G (s )}{s} \right\} U (z ),
$$
因为$\mathrm{e}^{- sT}$在采样域中是一个采样滞后、可以从$z$变换中提出。$\checkmark$
**合理性检验。**这个构造解释了要紧的两个性质：因子$\left( 1 - z^{- 1} \right)$对消$1 / s$引入的$z = 1$处那个额外极点，所以相对阶为一的严格真连续对象，给出一个**极点数比零点数多一**且带一个采样滞后的离散传递函数；而直流增益被保持，因为$\left( 1 - z^{- 1} \right) \rightarrow 0$与$\mathcal{Z} \left\{ G / s \right\} \rightarrow \infty$恰好以互补的方式发生。每个保持器等效里的那个采样滞后，就是证明3里那个半采样从另一侧的样子，而把它数两次——一次在保持器等效里、一次当滞后——的设计师，是在一个一阶滞后的地方建模了一点五个采样的滞后。
:::
:::

::: exercise 设计 {level=3}
一个张力回路穿越频率 $25\ \mathrm{Hz}$、在采样周期 $1\ \mathrm{ms}$ 下相角裕度 $55^{\circ}$，抗混叠滤波器为 $250\ \mathrm{Hz}$ 的两个极点。采样周期减到 $0.5\ \mathrm{ms}$、穿越频率提到 $50\ \mathrm{Hz}$。估计新的相角裕度。
::: solution
**新穿越频率处的得与失。**
- 采样：滞后代价从 $1.5 \times 157 \times 0.001 = 0.236\ \mathrm{rad} = 13.5^{\circ}$ 变为 $1.5 \times 314 \times 0.0005 = 0.236\ \mathrm{rad} = 13.5^{\circ}$——**没有变化**，因为采样率与穿越频率一起翻倍了。
- 抗混叠滤波器：$2 \arctan \left( 50 / 250 \right) = 22.6^{\circ}$ 对 $2 \arctan \left( 25 / 250 \right) = 11.4^{\circ}$，再损失 $11.2^{\circ}$。
- 对象：回路自身的相位在 $25$ 到 $50\ \mathrm{Hz}$ 之间随对象贡献多少就降多少；对一个在该处增益斜率为 $- 40\ \mathrm{dB / decade}$ 的对象，相位已接近 $- 180^{\circ}$，额外损失通常是 $10$ 到 $15^{\circ}$。
**结果。**$55 - 11 - 12 \approx 32^{\circ}$，设计处于临界。
**补救。**把抗混叠滤波器移到 $800\ \mathrm{Hz}$ 并进一步减小采样周期，或者接受 $35\ \mathrm{Hz}$。

**合理性检验。**有教益的是第一条：**采样率与穿越频率一起翻倍什么也买不到**，因为滞后代价是$1.5 \omega_{gc} T$而乘积不变。采样率与带宽必须互相交换，有用的设计动作是让采样率的提高远超带宽的提高——带宽翻倍、速率翻五十倍——让滞后那一项彻底不再出现在预算里。
:::
