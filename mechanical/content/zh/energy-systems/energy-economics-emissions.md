本课程前面各章按效率比较能源系统。效率很重要，但没有人因为电站效率高才建它：人们建电站，是因为它能以可接受的成本供应能量，并且——越来越多地——以可接受的温室气体排放供应能量。风电场以低于50 %的气动效率转换"免费"的燃料，而燃气–蒸汽联合循环电站以60 %的效率转换昂贵的燃料；哪个更便宜，取决于各自需要多少资本、每年运行多少小时、天然气价格多少、为建设而借的钱成本多少，以及社会对其排放的二氧化碳收取多少费用。

本章提供进行这种比较的工具。它从货币的时间价值和资本回收系数讲起，从定义出发建立平准化度电成本（LCOE），并说明为什么资本密集型技术对折现率和容量因数敏感，而燃料密集型技术对燃料价格和碳价敏感。然后从燃料化学和效率推导化石燃料发电的排放强度，求出天然气取代煤炭的碳价，并介绍生命周期评价、能量回收期和碳的社会成本。始终要记住贯穿整个能源经济学的告诫：数字的好坏取决于假设，而假设——折现率、燃料价格、寿命、碳价——必须始终说明。

下面所有成本数字均以美元计。除非注明来源和日期，这些成本都是为说明方法而选取的**示意性整数**，而不是当前的市场数据。

## 货币的时间价值 {#sec-discounting}

今天的一美元比十年后的一美元更值钱：它可以在此期间用于投资并获得回报，而把钱借给项目的人期望为等待和不能收回的风险得到补偿。能源项目受这一效应的支配，因为它们在一开始（建设电站）花掉大部分资金，然后在二十到四十年内赚回来。

::: definition 折现率与现值 {#def-present-value}
以每年的**折现率**$i$计，$t$年后发生的现金流$C_t$的**现值**为
$$
\mathrm{PV} = \frac{C_t}{(1+i)^t} = C_t\,v^t, \qquad v = \frac{1}{1+i},
$$ {#eq-pv}
其中$v$是一年的**折现因子**。项目的**净现值**是其全部现金流现值之和，成本为负，收入为正。电力公司使用的折现率通常是其**加权平均资本成本**（WACC）：其贷款人和股东所要求的平均回报。**实际**折现率$i_r$不含通货膨胀；**名义**折现率$i_n$包含通货膨胀，$1 + i_n = (1 + i_r)(1 + \text{通胀率})$。
:::

在$i = 7\,\%$时，10年后收到的一美元今天值$1/1.07^{10} = \$0.51$，30年后收到的只值$\$0.13$。电站寿命后期的收入几乎不算数；这就是廉价融资有利于长寿命、资本密集型资产的原因。

::: proposition 资本回收系数 {#prop-crf}
现在投入的资本$P$，在折现率$i > 0$下，恰好由$n$笔相等的年末支付偿还：
$$
A = P\cdot\mathrm{CRF}(i, n), \qquad \mathrm{CRF}(i, n) = \frac{i(1+i)^n}{(1+i)^n - 1}.
$$ {#eq-crf}
当$i \to 0$时$\mathrm{CRF} \to 1/n$（简单还款），当$n \to \infty$时$\mathrm{CRF} \to i$（支付的只是利息）。
:::

::: proof
第$1, \dots, n$年年末的支付$A$的现值必须等于$P$：
$$
P = A\sum_{t=1}^{n} v^t = A\,v\,\frac{1 - v^n}{1 - v},
$$
这里对几何级数求和。由$v = 1/(1+i)$，$1 - v = i/(1+i)$，所以$v/(1-v) = 1/i$，
$$
P = A\,\frac{1 - (1+i)^{-n}}{i} \quad\Longrightarrow\quad A = P\,\frac{i}{1 - (1+i)^{-n}} = P\,\frac{i(1+i)^n}{(1+i)^n - 1}.
$$
极限：当$n \to \infty$时，$(1+i)^{-n} \to 0$，$\mathrm{CRF} \to i$。当$i \to 0$时，$1 - (1+i)^{-n} \approx ni$，所以$\mathrm{CRF} \to i/(ni) = 1/n$。假设条件是折现率恒定、在年末支付、不计税；在这些条件下，$1/\mathrm{CRF}$是**年金系数**，即$n$年内每年一美元的现值。
:::

::: example 电站成本的年化 {#ex-crf}
一座电站每千瓦容量造价$\$1000$，瞬间建成（即"隔夜"成本），寿命25年。求实际折现率为$7\,\%$和$3\,\%$时每千瓦的年资本费用，并与直线还款比较。
::: solution
在$7\,\%$时：$(1.07)^{25} = 5.427$，所以
$$
\mathrm{CRF} = \frac{0.07 \times 5.427}{5.427 - 1} = \frac{0.3799}{4.427} = 0.0858,
$$
年费用为每千瓦年$\$85.8$。在$3\,\%$时，$\mathrm{CRF} = 0.0574$，为每千瓦年$\$57.4$。不计利息的直线还款为每千瓦年$1000/25 = \$40$。

合理性检查：CRF必须同时大于$i$和$1/n$——在$7\,\%$时，$0.0858 > 0.07$且$> 0.04$。从$3\,\%$变到$7\,\%$使资本费用增加一半，对任何成本以资本为主的技术来说这都是很大的影响。
:::
:::

## 平准化度电成本 {#sec-lcoe}

不同电站的成本随时间的分布不同：光伏电站几乎全是前期资本；燃气轮机建造便宜而燃料昂贵。为了比较它们，我们需要一个数字，即每兆瓦时的价格，若每生产一兆瓦时都得到这一价格，就恰好能支付包括资本回报在内的全部成本。

::: definition 平准化度电成本 {#def-lcoe}
对于第$t = 0, 1, \dots, n$年的成本为$C_t$（资本、运行维护、燃料、碳）、能量产出为$E_t$的电站，折现率为$i$时的**平准化度电成本**为
$$
\mathrm{LCOE} = \frac{\displaystyle\sum_{t=0}^{n} \frac{C_t}{(1+i)^t}}{\displaystyle\sum_{t=0}^{n} \frac{E_t}{(1+i)^t}} .
$$ {#eq-lcoe}
它是使收入现值$\sum pE_t v^t$等于成本现值的恒定价格$p$——即盈亏平衡电价。在分母中对*能量*折现并不是花招：这正是该盈亏平衡条件所要求的，因为收入随能量一起到来。
:::

实践中通常假设年成本和年产出恒定，这把[[#eq-lcoe]]简化为可以手算的公式。

::: proposition 年金形式的LCOE {#prop-lcoe-annuity}
假设电站在$t = 0$时以每千瓦隔夜资本成本$I$建成，然后运行$n$年，容量因数$\mathrm{CF}$恒定，固定运维成本为每千瓦年$F$，可变运维成本为每兆瓦时$V$，燃料价格为每GJ $p_f$，热耗率$\mathrm{HR}$以GJ/MWh计，碳价为每吨CO₂ $p_c$，排放强度$\mathrm{EI}$以t/MWh计，均以实际值计且恒定。则以$\$/\mathrm{MWh}$计的LCOE为
$$
\mathrm{LCOE} = \frac{\mathrm{CRF}(i,n)\,I + F}{8.76\,\mathrm{CF}} + V + p_f\,\mathrm{HR} + p_c\,\mathrm{EI},
$$ {#eq-lcoe-annuity}
其中$I$以$\$/\mathrm{kW}$计，$F$以$\$/(\mathrm{kW\,yr})$计；系数$8.76$把千瓦年换算为兆瓦时（$1\,\mathrm{kW} \times 8760\,\mathrm{h} = 8.76\,\mathrm{MWh}$）。
:::

::: proof
按每千瓦容量计，第$t = 1, \dots, n$年每年的能量为$E = 8.76\,\mathrm{CF}$ MWh，年运行成本为$R = F + (V + p_f\mathrm{HR} + p_c\mathrm{EI})E$。利用[[#prop-crf]]证明中的年金求和，[[#eq-lcoe]]的分子为$I + R\sum_{t=1}^n v^t = I + R/\mathrm{CRF}$，分母为$E\sum_{t=1}^n v^t = E/\mathrm{CRF}$。相除，
$$
\mathrm{LCOE} = \frac{I + R/\mathrm{CRF}}{E/\mathrm{CRF}} = \frac{\mathrm{CRF}\cdot I + R}{E} = \frac{\mathrm{CRF}\cdot I + F}{8.76\,\mathrm{CF}} + V + p_f\mathrm{HR} + p_c\mathrm{EI}.
$$
在所述假设下结果是精确的。当假设不成立时它是近似的：建设分散在若干年（把建设期利息加到$I$中），产出衰减或成本以实际值上涨（见[[#exr-escalation]]），税收和折旧，以及寿命末期的退役费用。
:::

该公式清楚地分为按$1/\mathrm{CF}$下降的**资本项**和与电站运行多少无关的**运行项**。这一个事实组织起了电力系统经济学的大部分内容。

::: algorithm 估算LCOE {#alg-lcoe}
1. 确定基准：注明年份的实际美元或名义美元，折现率（WACC），经济寿命，以及热耗率的热值基准。
2. 收集隔夜资本$I$（建设期长时加上建设期利息）、固定运维$F$、可变运维$V$、热耗率、燃料价格、排放强度和碳价。
3. 按电站的角色选择现实的容量因数——而不是其技术上的最大值（[[energy-systems/energy-overview]]）。
4. 由[[#eq-crf]]计算$\mathrm{CRF}(i, n)$，并逐项计算[[#eq-lcoe-annuity]]。
5. 分别报告各项（资本、运维、燃料、碳），并检验对两三个最不确定的输入的敏感性。
:::

::: example 陆上风电场的LCOE {#ex-lcoe-wind}
示意数据：隔夜成本$\$1400/\mathrm{kW}$，固定运维$\$40/(\mathrm{kW\,yr})$，无燃料，可变运维可忽略，容量因数$0.35$，寿命25年，实际折现率$7\,\%$。求LCOE及其对折现率的敏感性。
::: solution
$\mathrm{CRF}(0.07, 25) = 0.0858$（由[[#ex-crf]]）。每千瓦年发电量：$8.76 \times 0.35 = 3.066\,\mathrm{MWh}$。由[[#eq-lcoe-annuity]]：
$$
\mathrm{LCOE} = \frac{0.0858 \times 1400 + 40}{3.066} = \frac{120.1 + 40}{3.066} = 39.2 + 13.0 = 52.2\,\$/\mathrm{MWh}.
$$
成本的四分之三是资本。在其他折现率下重算：$3\,\%$得$39.3$，$5\,\%$得$45.4$，$10\,\%$得$63.4\,\$/\mathrm{MWh}$——仅融资一项就造成60 %的差距。

合理性检查：IRENA的《2024年可再生能源发电成本》（*Renewable Power Generation Costs in 2024*，2025年7月发布）给出新建陆上风电的全球加权平均LCOE为$\$0.034/\mathrm{kWh}$，平均装机成本为$\$1041/\mathrm{kW}$；示意算例更贵，因为其资本成本和折现率高于全球平均值，而全球平均值偏重于低成本的中国项目。数量级是正确的。
:::
:::

::: example 燃气–蒸汽联合循环电站的LCOE {#ex-lcoe-ccgt}
示意数据：隔夜成本$\$1000/\mathrm{kW}$，固定运维$\$25/(\mathrm{kW\,yr})$，可变运维$\$3/\mathrm{MWh}$，效率$55\,\%$（低位热值），天然气价格$\$8/\mathrm{GJ}$（低位热值），容量因数$0.55$，寿命30年，折现率$7\,\%$。取排放强度为$0.367\,\mathrm{t/MWh}$（在[[#ex-emissions]]中推导），求无碳价和碳价为每吨CO₂ $\$80$时的LCOE。
::: solution
热耗率：$\mathrm{HR} = 3.6\,\mathrm{GJ/MWh}/0.55 = 6.545\,\mathrm{GJ/MWh}$。$\mathrm{CRF}(0.07, 30) = 0.0806$。各项：
$$
\text{资本与固定运维} = \frac{0.0806 \times 1000 + 25}{8.76 \times 0.55} = \frac{105.6}{4.818} = 21.9\,\$/\mathrm{MWh},
$$
燃料$= 8 \times 6.545 = 52.4\,\$/\mathrm{MWh}$，可变运维$3.0\,\$/\mathrm{MWh}$。合计$\mathrm{LCOE} = 77.3\,\$/\mathrm{MWh}$。碳价为$\$80/\mathrm{t}$时：$+80 \times 0.367 = 29.4$，得$106.7\,\$/\mathrm{MWh}$。

这里燃料占成本的三分之二。折现率影响很小：$3\,\%$得$71.1$，$10\,\%$得$82.6\,\$/\mathrm{MWh}$，差距为16 %，而风电场为60 %。

合理性检查：燃料项就是价格乘以热耗率——在$\$8/\mathrm{GJ}$时，效率每提高一个百分点约值$\$1/\mathrm{MWh}$，这就是[[energy-systems/gas-turbines-combined-cycles]]中所述的效率提升如此重要的原因。
:::
:::

### LCOE没有告诉你的

LCOE是在电站寿命期内平均的单位能量成本。它完全不涉及能量*何时*到来，而电的价值随时间变化很大。在晚高峰由燃气轮机提供的一兆瓦时，比在已经被光伏饱和的系统中正午的一兆瓦时光伏电更值钱。还有三类成本不在电站自身的LCOE之内：**容量支撑**（风和阳光缺席时必须可用的容量）、**平衡**（应对预测误差的备用）和**电网**成本（向偏远场址的输电）。当波动性可再生能源在系统中占比较小时，这些并网成本很小，随着其占比上升而增长。完整的比较要用逐小时调度整个机组群的系统模型，类似于[[energy-systems/energy-overview]]中用负荷持续曲线所勾勒的那种，并在需要时加入储能（[[energy-systems/energy-storage]]）。

::: warning 成本比较中的常见错误
**混用实际利率和名义利率。** 通胀率$2\,\%$时，$7\,\%$的名义利率对应的实际利率为$1.07/1.02 - 1 = 4.9\,\%$；对以不变美元报价的成本使用名义利率，会高估资本密集型电站的LCOE。**使用技术容量因数**而不是预期容量因数：将以$0.35$作为腰荷运行的燃气电站，其LCOE不是它在$0.85$时的LCOE。**混用热值基准：** 按高位热值的热耗率配上按低位热值的燃料价格，对天然气约有$10\,\%$的误差。**把不同角色电站的LCOE相比较**，仿佛一兆瓦时无论何时生产都是一兆瓦时。**忘记单位：** 以$\$/\mathrm{kW}$计的资本除以以$\mathrm{MWh}$计的能量，需要隐含在$8.76$中的1000倍系数。
:::

## 化石燃料发电的排放 {#sec-emissions}

燃料燃烧基本上把其全部碳变成CO₂：每千克碳变成$44/12 = 3.67\,\mathrm{kg}$ CO₂。单位*燃料能量*的排放取决于燃料的碳与能量之比——煤主要是碳，比值高；天然气的甲烷分子带有四个氢原子，它们释放能量而不产生CO₂，比值低。单位*电量*的排放则还取决于电站效率。

::: proposition 火力发电的排放强度 {#prop-emission-intensity}
燃烧CO₂排放因子为$\mathrm{EF}$（以每GJ燃料热值的$\mathrm{kg}$计）的燃料、在同一热值基准下净效率为$\eta$的电站排放
$$
\mathrm{EI} = \frac{\mathrm{EF}}{\eta} \times 0.0036\,\mathrm{GJ/kWh} \quad [\mathrm{kg\,CO_2/kWh}],
$$ {#eq-ei}
即$\mathrm{EI} = \mathrm{EF} \times \mathrm{HR}$。对碳质量分数为$w_C$、热值为$\mathrm{HV}$（MJ/kg）的燃料，完全燃烧给出（按每千克燃料计）$\mathrm{EF} = (44/12)\,w_C/\mathrm{HV} \times 1000\,\mathrm{kg/GJ}$。
:::

::: proof
每发一千瓦时电，电站燃烧$3.6\,\mathrm{MJ}/\eta = 0.0036/\eta\,\mathrm{GJ}$的燃料能量（热耗率，[[energy-systems/energy-overview]]）；每GJ释放$\mathrm{EF}$ kg CO₂，由此得[[#eq-ei]]。对排放因子，一千克燃料含$w_C$ kg碳，生成$w_C \times 44/12$ kg CO₂（CO₂与C的摩尔质量），同时释放$\mathrm{HV}$ MJ $= \mathrm{HV}/1000$ GJ。相除即得公式。假设条件：全部碳都氧化为CO₂（在大型锅炉中未燃碳和CO很少），不捕集CO₂，$\eta$和$\mathrm{EF}$采用同一热值基准。
:::

对纯甲烷（$w_C = 12/16 = 0.75$，$\mathrm{LHV} = 50.0\,\mathrm{MJ/kg}$），公式给出$3.667 \times 0.75/0.050 = 55.0\,\mathrm{kg/GJ}$。《2006年IPCC国家温室气体清单指南》（第2卷，表1.4）采用按净热值（低位热值）计的缺省因子：天然气（含一些乙烷、丙烷和CO₂）为$56.1\,\mathrm{kg/GJ}$，其他烟煤为$94.6\,\mathrm{kg/GJ}$。单位热量下煤排放的CO₂约为天然气的$1.7$倍。

::: example 燃煤和燃气电站的排放强度 {#ex-emissions}
用IPCC缺省因子，求 (a) 燃烧天然气、效率$55\,\%$（低位热值）的联合循环电站，以及 (b) 燃烧烟煤、效率$40\,\%$（低位热值）的亚临界燃煤电站的排放强度。(c) 一家电力公司每年用燃气发电替代$1\,\mathrm{TWh}$燃煤发电。它避免了多少CO₂？
::: solution
(a) $\mathrm{EI} = 56.1 \times 0.0036/0.55 = 0.367\,\mathrm{kg/kWh}$。

(b) $\mathrm{EI} = 94.6 \times 0.0036/0.40 = 0.851\,\mathrm{kg/kWh}$。

(c) 每千瓦时节省$= 0.851 - 0.367 = 0.484\,\mathrm{kg}$；对$10^9\,\mathrm{kWh}$，每年$4.84\times10^{8}\,\mathrm{kg} = 0.48\,\mathrm{Mt}$ CO₂。

合理性检查：燃气电站通常被引述为约$0.35$–$0.40\,\mathrm{kg/kWh}$，燃煤电站为$0.8$–$1.0$；这一替换使每千瓦时的排放减少一半以上，因为排放因子和效率都有利于天然气。天然气生产上游泄漏的甲烷未计入这里；这是生命周期数字更高的原因之一（见下一节）。
:::
:::

### 碳价与燃料替代

碳价——来自碳税或排放交易体系——给每兆瓦时的成本加上$p_c\,\mathrm{EI}$。在短期内，已建成的电站按其**短期边际成本**（燃料加可变运维加碳）的顺序调度，因为其资本已经花掉。燃料便宜但排放高的煤电和燃料较贵但排放低的气电，在某一确定的碳价下在这一调度次序中互换位置。

::: proposition 煤改气的转换碳价 {#prop-switching}
设燃煤电站和燃气电站不含碳的短期成本分别为$m_c$和$m_g$（以$\$/\mathrm{MWh}$计），$m_g > m_c$，排放强度$\mathrm{EI}_c > \mathrm{EI}_g$（以$\mathrm{t/MWh}$计）。当碳价超过
$$
p_c^{*} = \frac{m_g - m_c}{\mathrm{EI}_c - \mathrm{EI}_g}
$$ {#eq-switch}
时，燃气电站的运行成本变得更低。
:::

::: proof
含碳的短期成本为$m_c + p_c\mathrm{EI}_c$和$m_g + p_c\mathrm{EI}_g$，两者都是$p_c$的线性函数。当$p_c(\mathrm{EI}_c - \mathrm{EI}_g) = m_g - m_c$时两者相等，得到$p_c^{*}$；由于$\mathrm{EI}_c > \mathrm{EI}_g$，煤电直线更陡，对所有$p_c > p_c^{*}$都位于气电直线之上。该结果假设两座电站都可用、其热耗率不随调度变化，而且只比较短期成本；是否*新建*电站要由完整的LCOE决定。
:::

::: example 转换碳价 {#ex-switch}
煤价$\$3/\mathrm{GJ}$，燃煤电站热耗率$9.0\,\mathrm{GJ/MWh}$（$40\,\%$），可变运维$\$5/\mathrm{MWh}$；天然气价格$\$8/\mathrm{GJ}$，用于$55\,\%$的联合循环机组（$6.545\,\mathrm{GJ/MWh}$），可变运维$\$3/\mathrm{MWh}$。使用[[#ex-emissions]]的排放强度。求转换碳价。
::: solution
$m_c = 3 \times 9.0 + 5 = 32.0\,\$/\mathrm{MWh}$；$m_g = 8 \times 6.545 + 3 = 55.4\,\$/\mathrm{MWh}$。由[[#eq-switch]]：
$$
p_c^{*} = \frac{55.4 - 32.0}{0.851 - 0.367} = \frac{23.4}{0.484} = 48.3\,\$/\mathrm{t\,CO_2}.
$$
合理性检查：气煤燃料成本差约为$\$23/\mathrm{MWh}$，每替换一兆瓦时约节省半吨，所以碳价必须约为每吨$\$46$–$50$。若天然气价格降到$\$5/\mathrm{GJ}$，转换将在约$\$8/\mathrm{t}$时发生——这就是为什么在一些市场中，推动煤电大幅下降的主要是廉价天然气，而不仅仅是碳政策。
:::
:::

x: 0, 150
y: 0, 250
sliders: fc=3:1:8:0.25; pg=8:2:20:0.5
labels: \text{煤电（40\%）}; \text{联合循环（55\%）}
caption: 燃煤电站和燃气–蒸汽联合循环电站的短期边际成本（\$/MWh）随碳价（\$/t CO₂）的变化，煤价$f_c$和天然气价格$p_g$（均为\$/GJ）由滑块设定。两条直线在[[#prop-switching]]的转换碳价处相交；交点右侧燃气电站优先运行。煤电直线的斜率是气电的两倍多，因为煤电排放$0.85$而气电为$0.37\,\mathrm{t/MWh}$。把$p_g$推高到$\$15/\mathrm{GJ}$，观察交点移到$\$100/\mathrm{t}$以外；把它降到$\$4/\mathrm{GJ}$，即使没有碳价，天然气也更便宜。
:::

## 生命周期评价 {#sec-lca}

风力机和光伏组件在运行时不排放任何东西，但钢、混凝土、玻璃、硅和铜必须开采、精炼、制成部件、运输、安装并最终拆除，这一切都消耗能量并排放温室气体。化石燃料电站在烟囱之外也有排放——采矿、天然气处理和管道泄漏。公平地比较各种技术，意味着要统计从摇篮到坟墓的一切。

::: definition 生命周期评价 {#def-lca}
按ISO 14040:2006（原则与框架）和ISO 14044:2006（要求与指南）标准化的**生命周期评价**（LCA），评价产品系统在其整个生命周期内的环境影响，分为四个阶段：
1. **目的与范围的确定**——目的、系统边界（包括哪些过程），以及**功能单位**，即所有流都折算到的量化服务；对发电而言，通常是提供（或生产）的$1\,\mathrm{kWh}$。
2. **生命周期清单分析**（LCI）——边界内每个过程的输入（能量、材料）和输出（排放、废物），按功能单位折算。
3. **生命周期影响评价**（LCIA）——把清单中的流归入各影响类别（气候变化、酸化、毒性、土地利用……），并特征化为共同的单位，例如以$\mathrm{kg\,CO_2\text{-}eq}$计的全球变暖潜势。
4. **解释**——结论、敏感性和不确定性，以及研究的局限，并检验与目的的一致性。
:::

甲烷和氧化亚氮乘以其在规定时间范围（通常为100年）内的全球变暖潜势，换算为**CO₂当量**。对甲烷，时间范围的选择很重要，因为它的效力远强于CO₂，但寿命短。

引用最广的比较是IPCC第五次评估报告第三工作组（2014）附录III对已发表LCA的综述。其生命周期排放中位数（以$\mathrm{g\,CO_2\text{-}eq/kWh}$计）为：

| 技术 | 中位数（g CO₂-eq/kWh） |
|---|---|
| 煤电，煤粉炉 | 820 |
| 天然气，联合循环 | 490 |
| 光伏，公用事业规模 | 48 |
| 水电 | 24 |
| 核电 | 12 |
| 风电，陆上 | 11 |

这些中位数背后的范围很宽（水电的范围跨越三个数量级，取决于淹没植被产生的甲烷），而且由于组件效率提高、制造能耗下降，光伏的数字自那些基础研究以来已经下降。这一格局是稳健的：化石燃料发电以燃烧排放为主（把$820$与[[#ex-emissions]]中针对效率较高机组的直接燃烧数字$851$相比），而可再生能源和核电的排放低一到两个数量级，几乎全部发生在制造和建设期间。

::: definition 能量回收期与能源投资回报率 {#def-epbt}
发电系统的**能量回收期**（EPBT）是其产出等于制造、安装和退役所用一次能源所需的运行时间：
$$
\mathrm{EPBT} = \frac{E_\text{embodied}}{E_\text{annual,primary-eq}},
$$
其中$E_\text{annual,primary-eq}$是把年发电量换算为它所替代的一次能源（除以被替代电网的效率）。寿命$L$内的**能源投资回报率**为$\mathrm{EROI} = L\,E_\text{annual}/E_\text{embodied}$；必须说明产出是按电计还是按一次能源当量计，因为两者相差2.5–3倍。
:::

::: example 屋顶光伏系统的回收期 {#ex-epbt}
示意数据：一套光伏系统每kWp制造、运输和安装需要$7.0\,\mathrm{GJ}$一次能源，每kWp每年发电$1200\,\mathrm{kWh}$，所替代的电网电力的一次能源系数为$2.5$（即平均转换效率$40\,\%$）。其隐含排放为每kWp $1000\,\mathrm{kg\,CO_2\text{-}eq}$。忽略衰减，求EPBT、25年内按一次能源当量计的EROI，以及生命周期排放强度。
::: solution
每年替代的一次能源：$1200 \times 3.6\,\mathrm{MJ} \times 2.5 = 10\,800\,\mathrm{MJ} = 10.8\,\mathrm{GJ}$。因此
$$
\mathrm{EPBT} = \frac{7.0}{10.8} = 0.65\,\mathrm{yr} \approx 8\ \text{个月}.
$$
EROI（一次能源当量）$= 25 \times 10.8/7.0 = 38.6$；按电计为$38.6/2.5 = 15$。

生命周期强度：寿命期发电量$25 \times 1200 = 30\,000\,\mathrm{kWh}$，所以$1\,000\,000\,\mathrm{g}/30\,000\,\mathrm{kWh} = 33\,\mathrm{g\,CO_2\text{-}eq/kWh}$。

合理性检查：$33\,\mathrm{g/kWh}$低于IPCC 2014年公用事业光伏的中位数$48$，这与更新、更高效的组件相符；在每kWp只发$900\,\mathrm{kWh}$的多云气候中，它将为$44\,\mathrm{g/kWh}$。排放强度与太阳能资源成反比，与LCOE的情形相同（[[energy-systems/solar-energy]]）。
:::
:::

## 碳的社会成本 {#sec-scc}

LCOE中的碳价引出另一个问题：它*应该*是多少？一种答案是**碳的社会成本**（SCC），即今天多排放一吨CO₂所造成的未来损害的现值。估算它要把排放–浓度模型、气候模型、把变暖转化为经济损失（农业、健康、海平面上升、劳动生产率）的损害函数串联起来，最后用一个折现率把几个世纪中发生的损害折回今天。按[[#eq-pv]]的算术，最后一步主导了答案：100年后发生的$\$1000$损害，在$2\,\%$时今天值$\$138$，在$3\,\%$时值$\$52$，在$5\,\%$时值$\$7.6$。

2023年12月，美国环境保护署发布了更新的估计值，中心值约为每吨CO₂ $\$190$（针对2020年的排放，以2020年美元计，近期折现率$2\,\%$），是此前使用的联邦临时值每吨$\$51$的数倍。2025年，联邦政府撤回了对这些估计值的使用：第14154号行政令解散了负责这些估计的跨部门工作组，2025年5月的一份白宫备忘录指示各机构除法律要求外停止对气候损害进行货币化。这一事件表明，SCC既是计算，也是价值判断——折现率的选择是关于给予后代多大权重的伦理选择——而且引用已发表的数字时必须注明其日期、来源和折现率。

::: widget plot
f: 1/(1+r/100)^x; 1/1.02^x
x: 0, 200
y: 0, 1
sliders: r=5:0.5:8:0.5
labels: (1+r)^{-t}; (1.02)^{-t}
caption: $t$年后发生的$\$1$损害的现值，折现率$r$（%）由滑块设定，并以固定的$2\,\%$作对比。在$5\,\%$时，100年后的损害今天每美元值不到一美分；在$2\,\%$时还保留14美分。把$r$滑到$2\,\%$使两条曲线重合，注意曲线下的面积——大致相当于一串未来损害在今天的价值——增长了好几倍。这一个参数解释了已发表的碳的社会成本之间的大部分分歧。
:::

::: quiz
在$5\,\%$折现率下，一座风电场和一座燃气电站的LCOE同为$\$60/\mathrm{MWh}$。资本成本升到$9\,\%$。会发生什么？
- [ ] 两者的LCOE上升同样多，因为两座电站都借钱。
- [x] 风电场的LCOE上升得多得多，因为其成本大部分是资本，所以它成为更贵的选项。
- [ ] 燃气电站的LCOE上升更多，因为其燃料是在电站寿命期内购买的。
- [ ] 两者都不变，因为LCOE是在固定折现率下定义的。
::: solution
在[[#eq-lcoe-annuity]]中，折现率只通过$\mathrm{CRF}\cdot I$进入。对风电场，该项约占LCOE的四分之三；对联合循环机组，它只占四分之一或更少，其余是燃料，燃料随用随付，不会被折现掉。因此较高的资本成本惩罚资本密集型技术——这是利率和项目风险对能源转型至关重要的核心原因。
:::
:::

::: history
1958年，查尔斯·戴维·**基林**（Charles David Keeling）开始在夏威夷莫纳罗亚观测站连续测量大气CO₂；不断上升并随季节振荡的"基林曲线"使化石碳的积累变得清晰可见。世界气象组织和联合国环境规划署于1988年成立了**政府间气候变化专门委员会**。1997年12月通过、2005年2月生效的**《京都议定书》**为工业化国家设定了具有约束力的排放目标；**欧盟排放交易体系**于2005年1月1日开始交易配额，这是第一个大型CO₂总量控制与交易市场，也是欧洲电站运营商如今计入其调度决策的碳价的来源。在核算方面，关于生命周期评价的ISO 14040于1997年首次发布，并于2006年与新的ISO 14044一起修订。威廉·**诺德豪斯**（William Nordhaus）的综合评估模型为气候损害定价，是大多数碳的社会成本估计的基础，他与保罗·**罗默**（Paul Romer）分享了2018年诺贝尔经济学纪念奖。
:::

::: summary
- 货币有时间价值：第$t$年的现金流$C_t$今天值$C_t/(1+i)^t$。资本回收系数$i(1+i)^n/((1+i)^n-1)$把一笔投资转化为相等的年费用。
- LCOE是折现后的寿命期成本除以折现后的寿命期能量——即盈亏平衡价格。在年值恒定时它简化为$(\mathrm{CRF}\,I + F)/(8.76\,\mathrm{CF}) + V + p_f\mathrm{HR} + p_c\mathrm{EI}$。
- 资本密集型电站（风电、光伏、核电）对折现率和容量因数敏感；燃料密集型电站（燃气）对燃料价格和碳价敏感。
- LCOE忽略能量何时提供；容量支撑、平衡和电网成本必须在系统层面加上。
- 排放强度$= \mathrm{EF}/\eta$：采用IPCC缺省因子时，联合循环机组约为$0.37\,\mathrm{kg/kWh}$，$40\,\%$的燃煤电站约为$0.85$。
- 碳价高于$(m_g - m_c)/(\mathrm{EI}_c - \mathrm{EI}_g)$时，燃气在调度中取代燃煤。
- 生命周期评价（ISO 14040/14044）按功能单位统计从摇篮到坟墓的排放；IPCC（2014）的中位数为：煤电约820 g/kWh，气电490，风电、核电、水电和光伏为11–48。
- 碳的社会成本首先取决于折现率和政策；引用时要注明日期、来源和折现率。
:::

## 习题 {#sec-exercises}

::: exercise 现值 {#exr-pv level=1 check="377"}
折现率为$5\,\%$时，20年后收到的$\$1000$的现值是多少？（以美元为单位输入，取整数。）
::: solution
$\mathrm{PV} = 1000/1.05^{20} = 1000/2.6533 = \$376.89$，即$\$377$。
:::
:::

::: exercise 资本回收系数 {#exr-crf level=1 check="0.1019"}
计算$i = 8\,\%$、$n = 20$年时的$\mathrm{CRF}(i, n)$。（输入CRF，保留四位小数。）
::: solution
$(1.08)^{20} = 4.6610$，所以$\mathrm{CRF} = 0.08 \times 4.6610/3.6610 = 0.37288/3.6610 = 0.10185$，即$0.1019$。一笔$\$1000$的贷款由20年中每年$\$101.85$偿还。
:::
:::

::: exercise 燃气内燃机的排放强度 {#exr-engine level=1 check="0.481"}
一座燃气内燃机电站的净效率为$42\,\%$（低位热值）。用天然气的IPCC缺省排放因子$56.1\,\mathrm{kg/GJ}$，求其排放强度。（以每kWh的kg CO₂为单位输入，保留三位小数。）
::: solution
由[[#eq-ei]]，$\mathrm{EI} = 56.1 \times 0.0036/0.42 = 0.2020/0.42 = 0.481\,\mathrm{kg/kWh}$——比燃烧同样天然气的联合循环约多30 %。
:::
:::

::: exercise 光伏电站的LCOE {#exr-solar-lcoe level=2 check="44.3"}
一座公用事业规模光伏电站的造价为$\$800/\mathrm{kW}$（隔夜），固定运维$\$15/(\mathrm{kW\,yr})$，容量因数$0.20$，寿命25年。用[[#eq-lcoe-annuity]]，在实际折现率$6\,\%$下求其LCOE。（以\$/MWh为单位输入LCOE，保留三位有效数字。）
::: solution
$\mathrm{CRF}(0.06, 25) = 0.06 \times 4.2919/3.2919 = 0.07823$。每千瓦年发电量$= 8.76 \times 0.20 = 1.752\,\mathrm{MWh}$。
$$
\mathrm{LCOE} = \frac{0.07823 \times 800 + 15}{1.752} = \frac{62.58 + 15}{1.752} = 44.3\,\$/\mathrm{MWh}.
$$
对比IRENA给出的2024年新建光伏全球加权平均值$\$43/\mathrm{MWh}$，平均装机成本为$\$691/\mathrm{kW}$。
:::
:::

::: exercise 燃料更便宜时的转换碳价 {#exr-switch level=2 check="34.6"}
煤价$\$2.5/\mathrm{GJ}$，燃煤电站热耗率$9.0\,\mathrm{GJ/MWh}$；天然气价格$\$6/\mathrm{GJ}$，用于$55\,\%$的联合循环机组。忽略可变运维。取排放强度为$0.8514$和$0.3672\,\mathrm{t/MWh}$，求燃气运行成本变得更低时的碳价。（以\$/t CO₂为单位输入，保留三位有效数字。）
::: solution
$m_c = 2.5 \times 9.0 = 22.5\,\$/\mathrm{MWh}$；$m_g = 6 \times 3.6/0.55 = 39.27\,\$/\mathrm{MWh}$。由[[#eq-switch]]，
$$
p_c^{*} = \frac{39.27 - 22.5}{0.8514 - 0.3672} = \frac{16.77}{0.4842} = 34.6\,\$/\mathrm{t}.
$$
:::
:::

::: exercise 风力机的生命周期排放强度 {#exr-wind-lca level=2 check="11.4"}
一台$3.0\,\mathrm{MW}$风力机的隐含排放（材料、制造、运输、安装和退役）为$2400\,\mathrm{t\,CO_2\text{-}eq}$。它以$0.32$的容量因数运行25年。求其生命周期排放强度。（以每kWh的g CO₂-eq为单位输入，保留三位有效数字。）
::: solution
寿命期发电量：$3000\,\mathrm{kW} \times 8760\,\mathrm{h} \times 0.32 \times 25 = 2.102\times10^{8}\,\mathrm{kWh}$。强度：$2.4\times10^{9}\,\mathrm{g}/2.102\times10^{8}\,\mathrm{kWh} = 11.4\,\mathrm{g/kWh}$，接近IPCC陆上风电的中位数11，约为燃煤电站的$1/75$。
:::
:::

::: exercise 风电的资本成本 {#exr-wind-rate level=2 check="63.4"}
在实际折现率$10\,\%$下重算[[#ex-lcoe-wind]]中风电场的LCOE。与$7\,\%$的情形相比上升了百分之几？（以\$/MWh为单位输入10 %时的LCOE，保留三位有效数字。）
::: solution
$(1.10)^{25} = 10.835$，$\mathrm{CRF} = 0.10 \times 10.835/9.835 = 0.11017$。$\mathrm{LCOE} = (0.11017 \times 1400 + 40)/3.066 = (154.2 + 40)/3.066 = 63.4\,\$/\mathrm{MWh}$，比$52.2$上升$21\,\%$——而风力机、风和场址都没有改变。
:::

::: exercise 推导：上涨燃料价格的平准化 {#exr-escalation level=3 check="9.83"}
(a) 燃料价格在第1年为$p_0$，每年以实际增长率$g$上涨，所以$p_t = p_0(1+g)^{t-1}$。证明**平准化燃料价格**——在折现率$i$下、$n$年内具有相同现值的恒定价格——为
$$
\bar p = p_0\,\mathrm{CRF}(i,n)\,\frac{1}{1+i}\,\frac{1 - k^n}{1 - k}, \qquad k = \frac{1+g}{1+i}.
$$
(b) 对$p_0 = \$8/\mathrm{GJ}$、$g = 2\,\%$、$i = 7\,\%$、$n = 30$计算它。(c) 这一上涨使[[#ex-lcoe-ccgt]]中联合循环机组的LCOE增加多少？（以\$/GJ为单位输入$\bar p$，保留三位有效数字。）
::: solution
(a) 按每年所用的单位燃料计，燃料支付的现值为
$$
\sum_{t=1}^{n} \frac{p_0(1+g)^{t-1}}{(1+i)^t} = \frac{p_0}{1+i}\sum_{t=1}^{n} k^{t-1} = \frac{p_0}{1+i}\,\frac{1-k^n}{1-k}.
$$
恒定价格$\bar p$的现值为$\bar p/\mathrm{CRF}$（年金系数）。两者相等即得公式。校核：$g = 0$时$k = v$，$\frac{1}{1+i}\frac{1-v^n}{1-v} = 1/\mathrm{CRF}$，所以$\bar p = p_0$。

(b) $k = 1.02/1.07 = 0.95327$，$k^{30} = 0.2378$，$(1 - k^{30})/(1 - k) = 0.7622/0.04673 = 16.31$。取$\mathrm{CRF}(0.07, 30) = 0.08059$：$\bar p = 8 \times 0.08059 \times 16.31/1.07 = 9.83\,\$/\mathrm{GJ}$，平准化系数为$1.23$。

(c) 燃料项从$8 \times 6.545 = 52.4$升到$9.83 \times 6.545 = 64.3\,\$/\mathrm{MWh}$，增加$\$11.9/\mathrm{MWh}$；LCOE变为约$89\,\$/\mathrm{MWh}$。每年仅$2\,\%$的实际上涨之所以重要，是因为电站寿命很长。
:::

::: exercise 远期损害的折现 {#exr-scc level=3 check="138"}
假设今天排放的一吨CO₂造成$\$1000$的损害，集中在100年后的某一年。(a) 求折现率为$2\,\%$、$3\,\%$和$5\,\%$时的现值。(b) 若损害改为在第1到100年均匀分布，每年$\$10$，在$3\,\%$时现值是多少？(c) 评述这对SCC争论意味着什么。（输入(a)中$2\,\%$时的现值，以美元为单位，取整数。）
::: solution
(a) $1000/1.02^{100} = \$138$；$1000/1.03^{100} = \$52.0$；$1000/1.05^{100} = \$7.6$。从2 %变到5 %，价值除以18。

(b) $10/\mathrm{CRF}(0.03, 100)$：$(1.03)^{100} = 19.22$，$\mathrm{CRF} = 0.03 \times 19.22/18.22 = 0.03165$，所以$\mathrm{PV} = 10/0.03165 = \$316$。很快就开始的损害被折现得少得多。

(c) 由于气候损害延续几个世纪，SCC主要由折现率和所假设的损害时间分布决定；关于SCC的分歧很大程度上就是关于这些的分歧，这就是已发表的数值跨越一个数量级、而且必须始终注明其折现率的原因。应输入的答案是$138$。
:::

::: exercise 设计：工业场址的新电源 {#exr-design level=3}
一座化工厂需要连续的$50\,\mathrm{MW}$电力，正在以下方案中选择：(i) 电网供电，电价$\$90/\mathrm{MWh}$，电网平均排放强度$0.30\,\mathrm{kg/kWh}$；(ii) 厂内燃气内燃机或联合循环机组；(iii) 与远方风电场和光伏电站签订购电合同，不足部分由电网补充。用[[#eq-lcoe-annuity]]和明确说明的示意性假设，估算碳价为$\$0$、$\$50$和$\$150/\mathrm{t}$时各方案的年成本和年CO₂排放，决定你会推荐哪个方案，并指出最可能改变你决定的两个假设。答案不唯一；请给出你的数字。
::: solution
一种答案的概要。年用电量$= 50 \times 8760 = 438\,\mathrm{GWh}$。(i) 电网：$438\,\mathrm{GWh} \times \$90 = \$39.4\,\mathrm{M}$；CO₂ $= 438\times10^{6} \times 0.30 = 131\,\mathrm{kt}$（假设碳成本已包含在电价中）。(ii) 以$\mathrm{CF} = 0.90$运行的联合循环机组约需$56\,\mathrm{MW}$；取$\$1100/\mathrm{kW}$、$\$25/(\mathrm{kW\,yr})$、$\$8/\mathrm{GJ}$和$52\,\%$（较小的电站效率较低），未计碳时LCOE约为$(0.0806 \times 1100 + 25)/7.884 + 3 + 8 \times 6.92 = 14.4 + 3 + 55.4 = 72.8\,\$/\mathrm{MWh}$；排放$0.388\,\mathrm{t/MWh}$，即每年$170\,\mathrm{kt}$；碳价为$\$50$和$\$150$时分别增加$\$19$和$\$58/\mathrm{MWh}$。若回收热量供工艺蒸汽（热电联产，[[energy-systems/gas-turbines-combined-cycles]]），有效成本会大幅下降。(iii) $\$50$–$60/\mathrm{MWh}$的风光购电合同大约覆盖$60$–$70\,\%$的小时数；其余从电网购买，所以综合成本接近$\$65$–$70/\mathrm{MWh}$，排放降到约$40$–$50\,\mathrm{kt}$。推荐取决于天然气价格和碳价——好的答案会检验这两个输入——以及场址是否需要蒸汽：碳价低时这强烈有利于热电联产，碳价高时则有利于可再生能源合同。
:::
