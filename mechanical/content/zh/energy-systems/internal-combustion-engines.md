往复式内燃机在工质内部燃烧燃料。火焰与活塞之间既没有锅炉，也没有换热器：一份空气（汽油机中还有燃料）被吸入气缸，经过压缩、点燃，高温产物推动活塞下行，然后被排掉。由于最热的燃气在每个循环中只与金属接触几毫秒，峰值燃气温度可以超过$2500\ \mathrm{K}$，而气缸壁仍保持在约$500\ \mathrm{K}$以下——这远远超过了任何蒸汽电站或燃气轮机能够持续承受的温度，也是一台小发动机的有效效率能达到$40\ \%$以上的原因。代价是循环是非稳态的，燃烧是与活塞运动的一场赛跑，排气以$700$–$1200\ \mathrm{K}$的温度离开，带走燃料能量的很大一部分。

本章分四个层次建立工程师对这类发动机的描述。首先是几何关系，它决定了工作容积和压缩比。然后是空气标准循环（奥托循环、狄塞尔循环和混合加热循环），它们表明压缩比和加热方式如何为效率设定上限。接着是每个试验台上都要用到的性能参数——指示功和有效功、平均有效压力、充气效率、有效燃料消耗率——它们由一个发动机功率方程联系在一起。最后是实际限制：爆震、节流、增压，以及如今与效率同样深刻地影响发动机设计的污染物。理想循环的热力学已在[[thermodynamics/power-cycles]]中介绍，燃料–空气混合物的化学在[[thermodynamics/mixtures-combustion]]中介绍；这里把两者用于实际机器。

## 几何关系与四冲程循环 {#sec-geometry}

设想一个气缸。活塞在**上止点**（TDC，其上方容积最小）和**下止点**（BDC，容积最大）之间运动。在**四冲程**发动机中，一个工作循环需要曲轴转两圈：*进气*冲程中进气门打开、活塞下行，吸入新鲜充量；*压缩*冲程中两个气门都关闭，充量被压缩；在上止点附近充量被点燃——点燃式（SI）发动机用火花点火，压燃式（CI）发动机即柴油机则把燃料喷入经压缩已热到足以着火的空气中——随后是*膨胀*（做功）冲程；*排气*冲程把产物推出去。**二冲程**发动机通过下止点附近的气口换气，在一圈内完成循环，代价是扫气较差；大型船用柴油机是二冲程的，几乎所有轿车和卡车发动机都是四冲程的。

::: definition 发动机几何参数 {#def-geometry}
对于**缸径**为$B$、**行程**为$L$（活塞从上止点到下止点的位移，等于曲柄半径的两倍）的气缸：

- 每缸的**工作容积**（排量）为$V_d = \dfrac{\pi B^2}{4} L$，$n_c$个气缸的发动机排量为$n_c V_d$；
- **燃烧室容积**（余隙容积）$V_c$是活塞在上止点时其上方的容积；下止点时的气缸容积为$V_c + V_d$；
- **压缩比**为$r = \dfrac{V_c + V_d}{V_c} = \dfrac{V_\text{下止点}}{V_\text{上止点}}$——是容积之比，而不是压力之比；
- 曲轴转速为$N$（每秒转数）时的**活塞平均速度**为$\bar U_p = 2 L N$；
- $n_R$是每个气缸每个做功冲程所对应的曲轴转数：四冲程$n_R = 2$，二冲程$n_R = 1$。
:::

活塞平均速度是发动机天然的速度尺度。摩擦、惯性载荷和气门处的压降都随之增大，而尺寸差别很大的发动机，其活塞平均速度都保持在一个窄范围内：额定转速下大型柴油机约为$8$–$15\ \mathrm{m/s}$，高转速轿车发动机可达约$20\ \mathrm{m/s}$。因此在相同的$\bar U_p$下，大发动机转得慢，小发动机转得快。

::: example 一台2升发动机的几何参数 {#ex-geometry}
一台四缸四冲程汽油机，缸径$84\ \mathrm{mm}$，行程$90\ \mathrm{mm}$，压缩比$12$。求排量、每缸燃烧室容积以及$6000\ \mathrm{rev/min}$时的活塞平均速度。
::: solution
每缸工作容积：
$$
V_d = \frac{\pi (0.084\ \mathrm{m})^2}{4} \times 0.090\ \mathrm{m} = 4.988\times10^{-4}\ \mathrm{m^3} = 498.8\ \mathrm{cm^3},
$$
所以发动机排量为$4 \times 498.8 = 1995\ \mathrm{cm^3}$，即一台"2.0升"发动机。由$r = (V_c + V_d)/V_c$，
$$
V_c = \frac{V_d}{r - 1} = \frac{498.8\ \mathrm{cm^3}}{11} = 45.3\ \mathrm{cm^3}.
$$
在$N = 6000/60 = 100\ \mathrm{rev/s}$时，活塞平均速度为$\bar U_p = 2 \times 0.090\ \mathrm{m} \times 100\ \mathrm{s^{-1}} = 18.0\ \mathrm{m/s}$。

**校核：** 燃烧室容积略小于工作容积的十分之一，对$r = 12$理应如此（$V_\text{下止点}/V_\text{上止点} = 544.1/45.3 = 12.0$）；$18\ \mathrm{m/s}$处于量产轿车发动机额定转速下正常范围的上限。
:::
:::

## 空气标准循环 {#sec-cycles}

实际发动机循环涉及有化学反应、有泄漏的非稳态流动。为了看清是什么在控制其效率，我们把它简化为**空气标准循环**：一定质量的空气，比热容为常数的理想气体（*冷空气标准*，$c_p = 1.005\ \mathrm{kJ/(kg\,K)}$，$c_v = 0.718\ \mathrm{kJ/(kg\,K)}$，$k = 1.4$，$R = 0.287\ \mathrm{kJ/(kg\,K)}$），燃烧用从外部加热代替，排气和进气用定容放热代替，所有过程都内部可逆。三种经典循环的区别仅在于加热方式。

::: proposition 奥托循环的效率 {#prop-otto}
奥托循环由等熵压缩$1 \to 2$、定容加热$2 \to 3$、等熵膨胀$3 \to 4$和定容放热$4 \to 1$组成。在冷空气标准的假设下，其热效率为
$$
\eta_\text{Otto} = 1 - \frac{1}{r^{\,k-1}},
$$ {#eq-otto}
它只取决于压缩比$r$和比热容比$k$。
:::

::: proof
对单位质量，$c_v$恒定时，加入和放出的热量为$q_\text{入} = c_v (T_3 - T_2)$和$q_\text{出} = c_v (T_4 - T_1)$，所以$\eta = 1 - q_\text{出}/q_\text{入} = 1 - (T_4 - T_1)/(T_3 - T_2)$。对于$k$恒定的理想气体等熵过程，$T v^{k-1}$为常数。压缩和膨胀在同样两个容积之间进行，$v_1/v_2 = v_4/v_3 = r$，因此
$$
\frac{T_2}{T_1} = r^{\,k-1} = \frac{T_3}{T_4}
\quad\Longrightarrow\quad
T_2 = r^{\,k-1} T_1, \qquad T_3 = r^{\,k-1} T_4 .
$$
代入得$T_3 - T_2 = r^{\,k-1}(T_4 - T_1)$，放热与加热之比为$1/r^{\,k-1}$，即得[[#eq-otto]]。所用的假设是：理想气体，比热容恒定，可逆绝热的压缩和膨胀，严格定容的换热（在上止点瞬时燃烧）。
:::

柴油机的构想是更缓慢地加热——燃料在活塞已经开始下行时于一段曲轴转角内喷入——其极限理想化是定压加热。两类实际发动机都介于定容加热和定压加热之间，所以最有用的单一模型是**混合加热循环**（或限压循环），它把两者都作为极限情形包括在内。

::: definition 混合加热循环 {#def-dual}
**混合加热循环**为：按压缩比$r = v_1/v_2$的等熵压缩$1 \to 2$；定容加热$2 \to 3$，使压力提高**压力升高比**$\alpha = p_3/p_2$倍；接着定压加热$3 \to 4$，**预胀比**为$\beta = v_4/v_3$；等熵膨胀$4 \to 5$到$v_5 = v_1$；以及定容放热$5 \to 1$。奥托循环是$\beta = 1$的情形，狄塞尔循环是$\alpha = 1$的情形。
:::

::: proposition 混合加热循环和狄塞尔循环的效率 {#prop-dual}
在冷空气标准的假设下，混合加热循环的热效率为
$$
\eta_\text{dual} = 1 - \frac{1}{r^{\,k-1}} \, \frac{\alpha \beta^{k} - 1}{(\alpha - 1) + k\alpha(\beta - 1)},
$$ {#eq-dual}
令$\alpha = 1$得到狄塞尔循环的效率
$$
\eta_\text{Diesel} = 1 - \frac{1}{r^{\,k-1}} \, \frac{\beta^{k} - 1}{k(\beta - 1)}.
$$ {#eq-diesel}
:::

::: proof
把每个温度都用$T_1$表示。等熵压缩：$T_2 = T_1 r^{\,k-1}$。定容：$T_3 = T_2\, p_3/p_2 = \alpha T_1 r^{\,k-1}$。定压：$T_4 = T_3\, v_4/v_3 = \alpha\beta T_1 r^{\,k-1}$。对膨胀，$v_5/v_4 = (v_1/v_2)(v_3/v_4) = r/\beta$（利用$v_3 = v_2$），所以
$$
T_5 = T_4 \left(\frac{\beta}{r}\right)^{k-1} = \alpha\beta T_1 r^{\,k-1}\,\frac{\beta^{k-1}}{r^{\,k-1}} = \alpha \beta^{k} T_1 .
$$
加入的热量为$q_\text{入} = c_v(T_3 - T_2) + c_p(T_4 - T_3)$，放出的热量为$q_\text{出} = c_v(T_5 - T_1)$。除以$c_v$并利用$c_p/c_v = k$，
$$
\frac{q_\text{出}}{q_\text{入}} = \frac{T_1(\alpha\beta^{k} - 1)}{T_1 r^{\,k-1}\left[(\alpha - 1) + k\alpha(\beta - 1)\right]},
$$
而$\eta = 1 - q_\text{出}/q_\text{入}$即[[#eq-dual]]。取$\alpha = 1$，分母变为$k(\beta - 1)$，得[[#eq-diesel]]；取$\beta \to 1$，分式趋于$(\alpha - 1)/(\alpha - 1) = 1$，恢复奥托循环的结果[[#eq-otto]]。假设与[[#prop-otto]]相同。
:::

[[#eq-diesel]]中乘在$1/r^{\,k-1}$上的因子对每个$\beta > 1$都大于$1$（把$\beta^k$在$\beta = 1$处展开，可知它为$1 + \tfrac{1}{2}(k-1)(\beta - 1) + \dots$）。所以**在相同压缩比下奥托循环效率更高**：定压加入的热量有一部分是在膨胀过程中加入的，因而膨胀所经历的容积比较小。柴油机之所以在实际中胜出，是因为它不受同样压缩比的限制：它只压缩空气，不会爆震，可以在$r = 15$–$22$下运行，而汽油机被限制在约$10$–$13$。

::: example 空气标准奥托循环 {#ex-otto}
一个$r = 10$的奥托循环从$p_1 = 100\ \mathrm{kPa}$、$T_1 = 300\ \mathrm{K}$开始，加入热量$q_\text{入} = 1800\ \mathrm{kJ/kg}$。用冷空气标准求最高温度和最高压力、净功、热效率和平均有效压力。
::: solution
压缩，$r^{\,k-1} = 10^{0.4} = 2.512$：
$$
T_2 = 300 \times 2.512 = 753.6\ \mathrm{K}, \qquad p_2 = 100 \times 10^{1.4} = 2512\ \mathrm{kPa}.
$$
加热：$T_3 = T_2 + q_\text{入}/c_v = 753.6 + 1800/0.718 = 3261\ \mathrm{K}$，$p_3 = p_2 T_3/T_2 = 10\,870\ \mathrm{kPa}$（$10.9\ \mathrm{MPa}$）。
膨胀：$T_4 = T_3/2.512 = 1298\ \mathrm{K}$。放热$q_\text{出} = 0.718\,(1298 - 300) = 716.6\ \mathrm{kJ/kg}$，净功$w = 1800 - 716.6 = 1083\ \mathrm{kJ/kg}$，且
$$
\eta = \frac{1083}{1800} = 0.602 = 1 - 10^{-0.4} .
$$
**平均有效压力**是在整个行程中作用、能做出净功的恒定压力：$v_1 = R T_1/p_1 = 0.287 \times 300/100 = 0.861\ \mathrm{m^3/kg}$，$v_2 = v_1/10$，
$$
\text{mep} = \frac{w}{v_1 - v_2} = \frac{1083\ \mathrm{kJ/kg}}{0.775\ \mathrm{m^3/kg}} = 1398\ \mathrm{kPa} \approx 1.40\ \mathrm{MPa}.
$$
**校核：** 由各状态温度算出的效率与[[#eq-otto]]一致。$3260\ \mathrm{K}$的最高温度太高了——真实气体物性和离解会使它保持在$2700$–$2800\ \mathrm{K}$附近——这是冷空气标准高估效率的第一个迹象。
:::
:::

::: example 柴油机的混合加热循环 {#ex-dual}
一台柴油机用混合加热循环建模，$r = 16$，压力升高比$\alpha = 1.5$，预胀比$\beta = 1.6$，从$T_1 = 300\ \mathrm{K}$开始。求各状态温度、每千克空气的加热量和效率。与相同压缩比的奥托循环和狄塞尔循环比较。
::: solution
$T_2 = 300 \times 16^{0.4} = 909.4\ \mathrm{K}$；$T_3 = 1.5 \times 909.4 = 1364\ \mathrm{K}$；$T_4 = 1.6 \times 1364 = 2183\ \mathrm{K}$；$T_5 = \alpha\beta^{k} T_1 = 1.5 \times 1.6^{1.4} \times 300 = 868.9\ \mathrm{K}$。
加热量：$q_\text{入} = 0.718\,(1364 - 909.4) + 1.005\,(2183 - 1364) = 326.4 + 822.7 = 1149\ \mathrm{kJ/kg}$。放热量：$q_\text{出} = 0.718\,(868.9 - 300) = 408.5\ \mathrm{kJ/kg}$。因此
$$
\eta = 1 - \frac{408.5}{1149} = 0.645 ,
$$
与[[#eq-dual]]一致：$1 - 16^{-0.4} \times (1.5 \times 1.6^{1.4} - 1)/(0.5 + 1.4 \times 1.5 \times 0.6) = 0.645$。
在$r = 16$时，奥托循环给出$1 - 16^{-0.4} = 0.670$，而$\beta = 2$的纯狄塞尔循环给出$0.614$。

**校核：** 混合加热循环的结果介于奥托和狄塞尔的值之间，理应如此；定容加入的热量越多，它就越接近奥托的值。
:::
:::

## 实际发动机为何达不到空气标准循环 {#sec-real}

一台$r = 12$的优秀现代汽油机，峰值有效效率约为$40\ \%$，而空气标准循环为$63\ \%$。这一差距有五个主要原因，值得分别列出，因为每个原因都有不同的对策。

1. **真实工质物性。** 燃烧产物的比热容随温度升高，而在化学计量火焰的峰值温度下，部分$\mathrm{CO_2}$和$\mathrm{H_2O}$会离解，吸收的能量在膨胀过程中只能部分返还。有效$k$约为$1.3$而不是$1.4$，使$r = 10$时的奥托效率从$60.2\ \%$降到$49.9\ \%$。用实际混合气的平衡物性计算的*燃料–空气循环*，是衡量发动机的更好的理想基准。
2. **传热。** $2500\ \mathrm{K}$的燃气与$400$–$500\ \mathrm{K}$的壁面接触，在整个燃烧和膨胀初期都在散热。粗略地说，经冷却液和经排气离开的燃料能量数量相当，通常各占四分之一到三分之一。
3. **有限的燃烧时间。** 火焰穿过燃烧室需要$40$–$60°$曲轴转角；在上止点前燃烧浪费压缩功，在上止点后燃烧则膨胀所经历的容积比较小。点火正时设定为获得最大有效转矩（MBT），作为一种折中。
4. **换气（泵气）。** 推出排气和吸入充量都要耗功。点燃式发动机在部分负荷时，节气门使进气歧管压力远低于大气压，泵气损失变得很大（见[[#sec-load]]）。
5. **机械摩擦和附件。** 活塞环和活塞裙部、轴承、配气机构、机油泵和冷却液泵消耗指示功的一部分，这部分随转速增大，在小负荷时占主导。

前三项减少由气缸压力测得的*指示*功；第四和第五项把指示功与在曲轴处测得的*有效*功区分开来。发动机试验的术语把它们分得很清楚。

## 发动机性能参数 {#sec-performance}

::: definition 功、平均有效压力和效率 {#def-performance}
对一个气缸的一个循环：

- **指示功**$W_i = \oint p\,\mathrm{d}V$是燃气对活塞所做的功，由测得的气缸压力求出。*总*指示功只计压缩和膨胀；*净*指示功包括泵气回线。
- **有效功率**$P_b = 2\pi N T$是曲轴处的功率，由测功机在转速$N$（rev/s）下测得的转矩$T$求出。**摩擦功率**为$P_f = P_i - P_b$，**机械效率**为$\eta_m = P_b/P_i$。
- **平均有效压力**是每循环的功除以工作容积：$\text{mep} = W/V_d$。每循环$n_R$转时，对整台发动机（用总排量）$P = \text{mep}\, V_d\, N/n_R$。指示、有效和摩擦的值分别记为imep、bmep和fmep，$\text{bmep} = \text{imep} - \text{fmep}$。
- **有效燃料消耗率**是单位有效功率的燃料质量流量，$\text{bsfc} = \dot m_f/P_b$，通常以$\mathrm{g/kWh}$给出。
- **有效热效率**（燃料转换效率）为$\eta_b = P_b/(\dot m_f Q_\text{LHV})$，以燃料的低位热值$Q_\text{LHV}$为基准。
- 四冲程发动机的**充气效率**为$\eta_v = \dfrac{2\dot m_a}{\rho_{a,i} V_d N}$：实际吸入的空气，除以在进气密度$\rho_{a,i}$下充满工作容积的空气。
:::

平均有效压力是比较不同尺寸发动机最有用的数字：它衡量每升排量被利用的强度，与尺寸和转速无关。自然吸气汽油机的最大bmep约为$1.0$–$1.3\ \mathrm{MPa}$；涡轮增压轿车发动机为$2$–$2.5\ \mathrm{MPa}$；重型卡车柴油机超过$2\ \mathrm{MPa}$。转矩与bmep成正比：由$P_b = 2\pi N T = \text{bmep}\,V_d N/n_R$，
$$
\text{bmep} = \frac{2\pi n_R\, T}{V_d}, \qquad\text{对四冲程}\quad \text{bmep} = \frac{4\pi T}{V_d}.
$$ {#eq-bmep}

燃料消耗率和效率包含同样的信息。由定义，$\text{bsfc} = \dot m_f/P_b = 1/(\eta_b Q_\text{LHV})$。$Q_\text{LHV}$以$\mathrm{MJ/kg}$计，$1\ \mathrm{kWh} = 3.6\ \mathrm{MJ}$，
$$
\text{bsfc}\ [\mathrm{g/kWh}] = \frac{3600}{\eta_b\, Q_\text{LHV}\ [\mathrm{MJ/kg}]}.
$$ {#eq-bsfc}
对柴油（$Q_\text{LHV} \approx 42.8\ \mathrm{MJ/kg}$），$200\ \mathrm{g/kWh}$的bsfc意味着$\eta_b = 0.42$；对汽油（$\approx 43$–$44\ \mathrm{MJ/kg}$），最好的轿车发动机约达$210$–$230\ \mathrm{g/kWh}$。

::: warning 毁掉发动机计算的四个疏忽
**忘记$n_R$。** 四冲程气缸每*两*转才点火一次。对四冲程写$P = \text{bmep}\,V_d N$会使功率加倍。**混淆imep和bmep。** 效率和mep值必须在同一基准上：指示量配指示效率，有效量配有效效率；两者之差就是摩擦。**热值。** 发动机效率和bsfc按惯例以*低位*热值为基准；对液态烃，用高位热值会使$\eta_b$降低其自身的约$6$–$7\ \%$。**$\eta_v$的参考密度用错。** 充气效率用*发动机进口*处的密度定义——涡轮增压发动机中是压气机和中冷器之后的密度——而不是环境密度；若用环境密度，涡轮增压发动机会显示"$\eta_v > 2$"，这就根本不是效率了。
:::

### 功率方程 {#sec-power-equation}

所有这些量组合成一个关系式，它解释了设计者如何从发动机中获得功率。

::: proposition 发动机功率方程 {#prop-power}
对于总排量为$V_d$、以$N$ rev/s运行、每循环$n_R$转的发动机，有效功率为
$$
P_b = \frac{\eta_b\, \eta_v\, \rho_{a,i}\, V_d\, N\, (F/A)\, Q_\text{LHV}}{n_R},
$$ {#eq-power}
其中$F/A$是燃料–空气质量比。等价地，$\text{bmep} = \eta_b\, \eta_v\, \rho_{a,i}\, (F/A)\, Q_\text{LHV}$。
:::

::: proof
按充气效率的定义（推广到每循环$n_R$转），每循环吸入的空气质量为$\eta_v \rho_{a,i} V_d$，每秒循环数为$N/n_R$，所以$\dot m_a = \eta_v \rho_{a,i} V_d N/n_R$。燃料流量为$\dot m_f = (F/A)\,\dot m_a$，燃料能量流率为$\dot m_f Q_\text{LHV}$。乘以有效效率即得[[#eq-power]]。除以$V_d N/n_R$并利用$P_b = \text{bmep}\, V_d N/n_R$，得到bmep形式。这里没有作任何热力学假设：这只是核算，其价值在于把各因素分离开来。
:::

这个方程列出了设计者可以调节的各个杠杆。**$V_d$和$N$**：更大或更快的发动机——受质量、摩擦和活塞平均速度的限制。**$\eta_b$**：更好的燃烧，更少的散热和摩擦。**$\eta_v$**：良好的气道和气门设计、调谐的进排气系统、可变气门正时——自然吸气发动机全负荷时通常为$0.80$–$0.95$。**$\rho_{a,i}$**：压缩并冷却进气（带中冷的涡轮增压）。**$F/A$**：汽油机在接近化学计量比下运行，因为其催化器需要如此；柴油机必须保持稀燃（全负荷时约$20$–$50\ \%$的过量空气）才能无烟地燃烧燃料，这就是它需要涡轮增压器才能在功率上竞争的原因。

::: algorithm 根据技术规格估算发动机性能 {#alg-performance}
1. 由缸径、行程和缸数计算$V_d$（整台发动机），并检查额定转速下的$\bar U_p = 2LN$。
2. 由进气歧管（或增压）压力和温度求进气密度$\rho_{a,i} = p_i/(R T_i)$，用开尔文和绝对压力。
3. 选定或测量$\eta_v$，并由化学计量比和当量比确定$F/A$：$F/A = \phi\,(F/A)_s = 1/(\lambda\,(A/F)_s)$。
4. 计算$\dot m_a = \eta_v \rho_{a,i} V_d N/n_R$和$\dot m_f = (F/A)\,\dot m_a$。
5. 用估计的有效效率求$P_b = \eta_b \dot m_f Q_\text{LHV}$；然后求转矩$T = P_b/(2\pi N)$，由[[#eq-bmep]]求$\text{bmep}$，由[[#eq-bsfc]]求bsfc。
6. 合理性检查：bmep在该类发动机的范围内，$\bar U_p$低于约$20\ \mathrm{m/s}$，排气中的$\mathrm{CO_2}$与燃料中的碳一致。
:::

::: example 自然吸气汽油机的额定功率 {#ex-power-si}
[[#ex-geometry]]的2.0升发动机（$V_d = 1.995\times10^{-3}\ \mathrm{m^3}$）在节气门全开、$5500\ \mathrm{rev/min}$下运行，以$101.3\ \mathrm{kPa}$、$25\ °\mathrm{C}$的环境空气为基准的$\eta_v = 0.90$。混合气$A/F = 14.6$，燃料$Q_\text{LHV} = 43.0\ \mathrm{MJ/kg}$，该工况点的有效效率为$0.30$。求有效功率、转矩、bmep和bsfc。
::: solution
进气密度：$\rho_a = 101.3/(0.287 \times 298.15) = 1.184\ \mathrm{kg/m^3}$。$N = 91.67\ \mathrm{rev/s}$，$n_R = 2$，
$$
\dot m_a = 0.90 \times 1.184 \times 1.995\times10^{-3} \times \frac{91.67}{2} = 0.0974\ \mathrm{kg/s}, \qquad \dot m_f = \frac{0.0974}{14.6} = 6.67\ \mathrm{g/s}.
$$
有效功率：$P_b = 0.30 \times 6.67\times10^{-3}\ \mathrm{kg/s} \times 43.0\times10^{6}\ \mathrm{J/kg} = 86.1\ \mathrm{kW}$。
转矩：$T = 86\,100/(2\pi \times 91.67) = 149\ \mathrm{N\,m}$。由[[#eq-bmep]]得bmep：$4\pi \times 149.5/1.995\times10^{-3} = 942\ \mathrm{kPa}$。bsfc：$3600/(0.30 \times 43.0) = 279\ \mathrm{g/kWh}$。

**校核：** 每升$43\ \mathrm{kW}$、高转速下bmep低于$1\ \mathrm{MPa}$，是自然吸气发动机的典型值；全功率时$30\ \%$的效率低于该发动机的最佳值（中等转速、高负荷时$\approx 35$–$40\ \%$），因为高转速下每循环的摩擦和散热增加，而且为了保护零部件可能会加浓混合气。
:::
:::

## 混合气浓度、爆震与负荷调节 {#sec-load}

::: definition 当量比与过量空气系数 {#def-phi}
**当量比**为$\phi = \dfrac{(F/A)}{(F/A)_s}$，即实际燃料–空气比除以化学计量比；**相对空燃比**（过量空气系数）为$\lambda = 1/\phi$。$\phi < 1$（$\lambda > 1$）的混合气为*稀*混合气，$\phi > 1$为*浓*混合气。
:::

对异辛烷，$\mathrm{C_8H_{18}} + 12.5\,(\mathrm{O_2} + 3.76\,\mathrm{N_2}) \to 8\,\mathrm{CO_2} + 9\,\mathrm{H_2O} + 47\,\mathrm{N_2}$，所以化学计量空燃比为$12.5 \times 4.76 \times 28.97/114.23 = 15.1$。含芳烃和含氧化合物的商品汽油更接近$14.6$–$14.7$，柴油约为$14.5$。

**爆震。** 在点燃式发动机中，火焰从火花塞开始，在预混充量中传播。火焰前方未燃的*末端混合气*受到膨胀的已燃气体压缩和加热；如果其温度和压力保持足够长的时间，它就会在火焰到达之前自燃。由此产生的几乎瞬时的能量释放使压力波在燃烧室中回荡——即可听见的"爆震"——持续发生会侵蚀活塞、冲坏缸垫。由于压缩后末端混合气的温度大致按$r^{\,k-1}$升高，爆震限制了点燃式发动机的压缩比，从而限制了其空气标准效率。燃料的抗自燃能力用**辛烷值**表示；发动机设计手段（紧凑的燃烧室、冷却的废气再循环、利用燃油蒸发冷却充量的缸内直喷、推迟点火的爆震传感器）能换来稍高一些的压缩比。

柴油机不会发生这种意义上的爆震，因为在喷油之前气缸中只有空气；它依靠自燃，其燃料选的是*容易*着火的（高**十六烷值**）。这就是柴油机能以$r = 15$–$22$运行的原因。

**负荷调节。** 带三效催化器的汽油机必须保持$\lambda \approx 1$，所以只能通过减少混合气的*数量*来降低功率：节气门降低进气歧管压力。于是活塞在每个进气冲程都要对抗部分真空做功。进气歧管压力为$p_i$、排气背压为$p_e$时，泵气平均有效压力约为$\text{pmep} \approx p_e - p_i$——在小负荷、$p_i = 40\ \mathrm{kPa}$、$p_e = 105\ \mathrm{kPa}$时约为$65\ \mathrm{kPa}$，在本身可能只有$200\ \mathrm{kPa}$的bmep中占很大比例。柴油机不节流：它通过向满充量的空气中喷入较少的燃料来调节负荷（质调节而不是量调节），其部分负荷效率相应地更好。可变气门正时（早关或晚关进气门）、停缸以及使发动机保持在高负荷运行的混合动力系统，是汽油机的应对之策。

::: quiz
一台汽油机和一台柴油机的峰值有效效率相同。下列哪种说法最能解释为什么柴油机在城市行驶中通常更省油？
- [ ] 在相同压缩比下，狄塞尔循环比奥托循环效率更高。
- [x] 柴油机不节流，所以在小负荷时避免了大部分泵气损失，而其短促的喷油（小预胀比）提高了循环效率。
- [ ] 柴油的单位质量热值比汽油高得多。
- [ ] 柴油机的催化器回收了部分排气能量。
::: solution
在相同压缩比下奥托循环效率更高（[[#prop-dual]]），所以选项1是错的；柴油（$\approx 42.8\ \mathrm{MJ/kg}$）和汽油（$\approx 43$–$44\ \mathrm{MJ/kg}$）的单位质量低位热值几乎相等（柴油密度较大，所以每升携带更多能量，但这并不改变效率）；后处理装置也不回收任何功。柴油机在小负荷时的优势在于它只靠燃料量调节功率：没有节气门，泵气功很小，而接近$1$的预胀比使它的循环在其高压缩比下趋向奥托极限。
:::
:::

## 涡轮增压与中冷 {#sec-turbo}

功率方程表明，功率密度与进气密度成正比。**涡轮增压器**利用排气中的涡轮——回收一部分本来要被丢弃的能量——驱动进气侧的离心式压气机。压缩会使空气升温，这与目的背道而驰：按压气机等熵效率$\eta_c$的定义，对于压比$\pi_c = p_2/p_1$，出口温度为
$$
T_2 = T_1\left[1 + \frac{\pi_c^{(k-1)/k} - 1}{\eta_c}\right],
$$ {#eq-compressor}
用温度为$T_1$的环境空气冷却、效能为$\varepsilon$的**中冷器**（增压空气冷却器）把温度降到$T_3 = T_2 - \varepsilon(T_2 - T_1)$。于是相对于环境的密度比为$\rho_3/\rho_1 = \pi_c\,T_1/T_3$（忽略中冷器压降）。较冷的充量还会降低末端混合气温度和火焰温度，减少点燃式发动机的爆震和柴油机的$\mathrm{NO}_x$。

::: example 有无中冷时的充量密度 {#ex-turbo}
一台$\eta_c = 0.75$的涡轮增压器压气机把$100\ \mathrm{kPa}$、$25\ °\mathrm{C}$的环境空气增压到$250\ \mathrm{kPa}$。求压气机出口温度，以及无中冷器和装有效能$0.80$的中冷器时的密度比$\rho/\rho_\text{amb}$。
::: solution
$\pi_c^{(k-1)/k} = 2.5^{0.2857} = 1.2992$。由[[#eq-compressor]]，
$$
T_2 = 298.15\left[1 + \frac{0.2992}{0.75}\right] = 417.1\ \mathrm{K}\ (144\ °\mathrm{C}).
$$
无中冷：$\rho_2/\rho_1 = 2.5 \times 298.15/417.1 = 1.79$。有中冷：$T_3 = 417.1 - 0.80\,(417.1 - 298.15) = 321.9\ \mathrm{K}$（$49\ °\mathrm{C}$），$\rho_3/\rho_1 = 2.5 \times 298.15/321.9 = 2.32$。

**校核：** 中冷器使送入的空气质量——从而在固定$\phi$下的潜在功率——提高到$2.32/1.79 = 1.30$倍——不增加增压压力就获得$30\ \%$的增益。充量仍比环境热，所以密度比仍低于压比，理应如此。
:::
:::

功率方程现在可以解释现代重型柴油机了。

::: example 涡轮增压卡车柴油机 {#ex-truck}
一台$13.0\ \mathrm{L}$六缸四冲程卡车柴油机以$1500\ \mathrm{rev/min}$运行，中冷器后的进气歧管状态为$250\ \mathrm{kPa}$和$320\ \mathrm{K}$。充气效率为$0.95$，过量空气系数$\lambda = 1.5$，$(A/F)_s = 14.5$，燃料$Q_\text{LHV} = 42.8\ \mathrm{MJ/kg}$，碳质量分数$0.862$，有效效率为$0.45$。求有效功率、转矩、bmep、bsfc以及每kWh排放的$\mathrm{CO_2}$。
::: solution
$\rho_{a,i} = 250/(0.287 \times 320) = 2.722\ \mathrm{kg/m^3}$；$N = 25\ \mathrm{rev/s}$。
$$
\dot m_a = 0.95 \times 2.722 \times 0.0130 \times \frac{25}{2} = 0.420\ \mathrm{kg/s}, \qquad
\dot m_f = \frac{0.420}{1.5 \times 14.5} = 19.3\ \mathrm{g/s}.
$$
$P_b = 0.45 \times 0.01932 \times 42.8\times10^{6} = 372\ \mathrm{kW}$。转矩$T = 372\,100/(2\pi \times 25) = 2370\ \mathrm{N\,m}$；$\text{bmep} = 4\pi \times 2369/0.0130 = 2.29\ \mathrm{MPa}$。由[[#eq-bsfc]]，$\text{bsfc} = 3600/(0.45 \times 42.8) = 187\ \mathrm{g/kWh}$。
每千克燃料含$0.862\ \mathrm{kg}$碳，生成$0.862 \times 44.01/12.011 = 3.16\ \mathrm{kg}$ $\mathrm{CO_2}$。每kWh：$0.187\ \mathrm{kg} \times 3.16 = 0.590\ \mathrm{kg\ CO_2/kWh}$。

**校核：** $372\ \mathrm{kW}$（$\approx 500\ \mathrm{hp}$）和$2.3\ \mathrm{MPa}$的bmep是当前长途卡车发动机的典型值。没有涡轮增压器（$\rho \approx 1.18$）时，同一台发动机只能输出约$160\ \mathrm{kW}$。其$\mathrm{CO_2}$强度低于燃煤电站，高于燃气联合循环电站（比较[[energy-systems/energy-economics-emissions]]）。
:::
:::

截至2025年，往复式发动机公布的最佳数字在百分之五十出头：潍柴动力于2024年4月报告了一台有效热效率为$53.09\ \%$的重型柴油机，经TÜV南德和中汽中心（CATARC）认证，在台架上测得，不含余热回收。对汽油机，丰田的2.0升"Dynamic Force"发动机于2018年发布，最高热效率为$40\ \%$（常规版）和$41\ \%$（混合动力版）。大型二冲程船用柴油机以极低转速和极长行程运行，达到相近或更高的效率。这些是最佳工况点的峰值；在整个行驶工况上平均，轿车发动机的效率要低得多。

## 排放 {#sec-emissions}

在过量空气中完全燃烧烃类的发动机只会排放$\mathrm{CO_2}$、$\mathrm{H_2O}$、$\mathrm{N_2}$和$\mathrm{O_2}$。对化石燃料而言$\mathrm{CO_2}$是不可避免的——它由含碳量决定，如[[#ex-truck]]——只能通过少烧燃料或使用低碳燃料来减少。受管制的污染物来自对理想燃烧的偏离：

- **氮氧化物（$\mathrm{NO}_x$）**由大气中的氮和氧在最热的已燃气体中生成（热力型机理，或称泽尔多维奇（Zel'dovich）机理）。其生成量随温度急剧增大，并且需要游离氧，所以峰值出现在略稀于化学计量比处。对策：降低火焰温度（废气再循环、推迟正时、充量冷却）和后处理。
- **一氧化碳（CO）**源于缺氧：浓混合气中多，稀混合气中少。
- **未燃碳氢化合物（HC）**来自逃脱火焰的燃料：活塞环周围的缝隙中、冷壁附近的淬熄层中、被油膜吸附的，以及冷起动期间的。
- **颗粒物（PM）**主要是碳烟，生成于柴油喷雾的富油核心区，在缸内直喷汽油机中也有较少生成。

汽油机的**三效催化器**同时氧化CO和HC并还原$\mathrm{NO}_x$，但只在$\lambda = 1$附近的一个窄窗口内有效：稀时氧太多，无法还原$\mathrm{NO}_x$；浓时氧太少，无法氧化CO和HC。排气中的氧传感器和闭环燃油控制把混合气保持在这个窗口内，这就是为什么点燃式发动机的负荷调节是节流而不是稀燃。柴油机稀燃运行，所以不能使用三效催化器。取而代之的是：柴油机氧化催化器去除CO和HC，柴油机颗粒过滤器捕集碳烟并定期将其烧掉，**选择性催化还原**（SCR）用喷入的尿素溶液（32.5 %的尿素水溶液，以AdBlue或DEF之名出售）所产生的氨还原$\mathrm{NO}_x$，总反应为$4\,\mathrm{NO} + 4\,\mathrm{NH_3} + \mathrm{O_2} \to 4\,\mathrm{N_2} + 6\,\mathrm{H_2O}$。柴油机标定中贯穿着一种权衡：高温、早燃效率高、碳烟少，但$\mathrm{NO}_x$多；低温、晚燃$\mathrm{NO}_x$少，但碳烟多、油耗高。SCR使现代发动机得以按效率标定，然后再把$\mathrm{NO}_x$清理掉。

::: example 由燃料消耗求每公里$\mathrm{CO_2}$ {#ex-co2-km}
一辆汽油车每$100\ \mathrm{km}$消耗$6.0\ \mathrm{L}$燃料。燃料密度为$745\ \mathrm{kg/m^3}$，碳质量分数为$0.866$。求尾气$\mathrm{CO_2}$排放（克每公里）。
::: solution
每公里燃料质量：$0.060\ \mathrm{L/km} \times 0.745\ \mathrm{kg/L} = 0.0447\ \mathrm{kg/km}$。碳：$0.0447 \times 0.866 = 0.0387\ \mathrm{kg/km}$。每$12.011\ \mathrm{kg}$碳生成$44.01\ \mathrm{kg}$ $\mathrm{CO_2}$：
$$
m_{\mathrm{CO_2}} = 0.0387 \times \frac{44.01}{12.011} = 0.142\ \mathrm{kg/km} = 142\ \mathrm{g/km}.
$$
**校核：** 这相当于每升汽油$2.36\ \mathrm{kg}$ $\mathrm{CO_2}$——人们熟悉的换算系数；逃逸的CO和HC只占碳的零点几个百分点，对这一平衡的影响小到可以忽略。
:::
:::

::: history
艾蒂安·**勒努瓦**（Étienne Lenoir）1860年在法国取得一种煤气机的专利，并售出了几百台；它在行程的一部分中吸入煤气和空气，然后*不经压缩*就点燃，效率只有百分之几。1862年，阿方斯·**博·德·罗沙**（Alphonse Beau de Rochas）在一项法国专利中描述了四冲程原理——进气、压缩、点火和膨胀、排气——但没有制造发动机。尼古拉斯·奥古斯特·**奥托**（Nicolaus August Otto）与欧根·兰根（Eugen Langen）在科隆附近的道依茨工厂于1876年制成了第一台成功的带压缩的四冲程发动机；其专利后来在德国（1886年）因博·德·罗沙更早的描述而被宣告无效，但这一循环仍以奥托命名。鲁道夫·**狄塞尔**（Rudolf Diesel）于1892年为其压燃式发动机申请专利（德国专利67207号，1893年授权），在奥格斯堡机器制造厂经过多年研制后，他的发动机于1897年2月通过了莫里茨·**施勒特尔**（Moritz Schröter）教授主持的验收试验，总效率约为$26\ \%$，远高于同等规模的蒸汽机和煤气机。
:::

## 小结

::: summary
- 几何关系：每缸$V_d = \pi B^2 L/4$，压缩比$r = (V_c + V_d)/V_c$，活塞平均速度$\bar U_p = 2LN$；四冲程每循环$n_R = 2$转。
- 空气标准效率：奥托循环$1 - r^{1-k}$；在相同$r$下狄塞尔循环和混合加热循环较低（[[#eq-dual]]）。柴油机胜出是因为它能用$r = 15$–$22$；汽油机受爆震限制在约$10$–$13$。
- 实际发动机由于比热容变化和离解、传热、有限燃烧时间、泵气和摩擦而达不到空气标准循环；峰值有效效率约为$40\ \%$（汽油机）和$45$–$50\ \%$或更高（大型柴油机）。
- 平均有效压力（四冲程$\text{bmep} = 4\pi T/V_d$）可以不受尺寸影响地比较发动机；$\text{bsfc}\,[\mathrm{g/kWh}] = 3600/(\eta_b Q_\text{LHV}[\mathrm{MJ/kg}])$。
- 功率方程：$P_b = \eta_b \eta_v \rho_{a,i} V_d N (F/A) Q_\text{LHV}/n_R$——功率来自效率、换气、充量密度、尺寸、转速和混合气浓度。
- 带中冷的涡轮增压提高充量密度；节流使点燃式发动机在部分负荷时效率低下。
- $\mathrm{CO_2}$由燃料中的碳决定；$\mathrm{NO}_x$、CO、HC和PM来自不完善的燃烧。汽油机在$\lambda \approx 1$下使用三效催化器；柴油机需要氧化催化器、颗粒过滤器和尿素SCR。
:::

## 习题

::: exercise 由尺寸求压缩比 {#exr-cr level=1 check="18.1"}
一台柴油机气缸的缸径为$100\ \mathrm{mm}$，行程$120\ \mathrm{mm}$，燃烧室容积$55\ \mathrm{cm^3}$。求压缩比。（输入$r$，保留一位小数。）
::: solution
$V_d = \pi (0.100)^2/4 \times 0.120 = 9.425\times10^{-4}\ \mathrm{m^3} = 942.5\ \mathrm{cm^3}$。于是
$$
r = \frac{942.5 + 55}{55} = 18.14 \approx 18.1 .
$$
这是直喷柴油机的典型值。
:::
:::

::: exercise 奥托循环效率 {#exr-otto level=1 check="61.7"}
求压缩比为$11$的奥托循环的冷空气标准（$k = 1.4$）效率。（以百分数输入效率，保留一位小数。）
::: solution
$\eta = 1 - 11^{-0.4} = 1 - 0.3832 = 0.6168$，即$61.7\ \%$。具有这一压缩比的实际发动机在其最佳工况点能达到这一数值的约三分之二。
:::
:::

::: exercise 燃料消耗率 {#exr-bsfc level=1 check="200"}
一台柴油机燃用$Q_\text{LHV} = 42.8\ \mathrm{MJ/kg}$的燃料，有效热效率为$42\ \%$。求其bsfc。（以g/kWh为单位输入bsfc，取整数。）
::: solution
由[[#eq-bsfc]]，$\text{bsfc} = 3600/(0.42 \times 42.8) = 200.3\ \mathrm{g/kWh}$，即$200\ \mathrm{g/kWh}$。"200 g/kWh"柴油机是优秀现代卡车发动机的常用基准。
:::
:::

::: exercise 由转矩曲线求bmep {#exr-bmep level=2 check="2011"}
一台涡轮增压2.0升四冲程汽油机（$V_d = 2.000\times10^{-3}\ \mathrm{m^3}$）的最大转矩为$320\ \mathrm{N\,m}$。求该点的bmep并评论其数值。（以kPa为单位输入bmep，取整数。）
::: solution
由[[#eq-bmep]]，
$$
\text{bmep} = \frac{4\pi T}{V_d} = \frac{4\pi \times 320}{2.000\times10^{-3}} = 2.0106\times10^{6}\ \mathrm{Pa} = 2011\ \mathrm{kPa}.
$$
约为自然吸气发动机所能达到的$1.0$–$1.3\ \mathrm{MPa}$的两倍：这台发动机依靠约为二的增压压比（带中冷），以及缸内直喷和爆震控制，才能利用更高的气缸压力。
:::
:::

::: exercise 狄塞尔循环效率 {#exr-diesel level=2 check="62.2"}
求压缩比为$18$、预胀比为$2.2$的狄塞尔循环的冷空气标准效率，并与$r = 10$的奥托循环比较。（以百分数输入狄塞尔循环效率，保留一位小数。）
::: solution
由[[#eq-diesel]]，$k = 1.4$：$18^{-0.4} = 0.3147$，$2.2^{1.4} = 3.016$，所以
$$
\eta = 1 - 0.3147 \times \frac{3.016 - 1}{1.4 \times 1.2} = 1 - 0.3147 \times 1.2001 = 0.6224 ,
$$
即$62.2\ \%$。$r = 10$的奥托循环给出$60.2\ \%$：柴油机较高的压缩比足以弥补其不太有利的加热方式。
:::
:::

::: exercise 小型发动机的功率 {#exr-power level=2 check="81.3"}
一台$1.6\ \mathrm{L}$四冲程汽油机在$6000\ \mathrm{rev/min}$、节气门全开下运行，以进气密度$1.18\ \mathrm{kg/m^3}$为基准的$\eta_v = 0.92$，$A/F = 14.7$，$Q_\text{LHV} = 43\ \mathrm{MJ/kg}$，有效效率$0.32$。求有效功率。（以kW为单位输入功率，保留三位有效数字。）
::: solution
$\dot m_a = 0.92 \times 1.18 \times 1.6\times10^{-3} \times 100/2 = 0.08685\ \mathrm{kg/s}$；$\dot m_f = 0.08685/14.7 = 5.908\ \mathrm{g/s}$；
$$
P_b = 0.32 \times 5.908\times10^{-3} \times 43\times10^{6} = 81.29\ \mathrm{kW} \approx 81.3\ \mathrm{kW}.
$$
即每升$51\ \mathrm{kW}$，对自然吸气发动机偏高，但对为高转速调校的发动机是现实的。
:::
:::

::: exercise 化学计量空燃比 {#exr-afr level=2 check="15.09"}
取空气摩尔质量为$28.97\ \mathrm{kg/kmol}$，空气组成为$\mathrm{O_2} + 3.76\,\mathrm{N_2}$，求异辛烷$\mathrm{C_8H_{18}}$（$M = 114.23\ \mathrm{kg/kmol}$）的化学计量空燃质量比。（输入$(A/F)_s$，保留两位小数。）
::: solution
配平$\mathrm{C_8H_{18}} + a\,(\mathrm{O_2} + 3.76\,\mathrm{N_2}) \to 8\,\mathrm{CO_2} + 9\,\mathrm{H_2O} + 3.76a\,\mathrm{N_2}$：氧原子给出$2a = 16 + 9$，所以$a = 12.5$。每kmol燃料需空气$12.5 \times 4.76 = 59.5\ \mathrm{kmol}$，
$$
(A/F)_s = \frac{59.5 \times 28.97}{114.23} = 15.09 .
$$
商品汽油略低（$\approx 14.6$–$14.7$），因为其中芳烃的氢碳比较低，而乙醇调和汽油本身已含氧。
:::
:::

::: exercise 最大功时的奥托循环 {#exr-maxwork level=3 check="13.5"}
一个奥托循环（冷空气标准）在固定的进口温度$T_1$和由材料及$\mathrm{NO}_x$决定的固定最高温度$T_3$之间工作。(a) 证明当$r^{\,k-1} = \sqrt{T_3/T_1}$时单位质量净功最大，此时效率为$1 - \sqrt{T_1/T_3}$。(b) 对$T_1 = 300\ \mathrm{K}$和$T_3 = 2400\ \mathrm{K}$，求这一压缩比和效率。（输入压缩比，保留一位小数。）
::: hint
令$x = r^{\,k-1}$，把$w = q_\text{入} - q_\text{出}$用$x$、$T_1$和$T_3$表示。
:::
::: solution
(a) 令$x = r^{\,k-1}$：$T_2 = x T_1$，$T_4 = T_3/x$。于是
$$
\frac{w}{c_v} = (T_3 - x T_1) - \left(\frac{T_3}{x} - T_1\right) = T_3 + T_1 - x T_1 - \frac{T_3}{x}.
$$
令$\mathrm{d}w/\mathrm{d}x = c_v(-T_1 + T_3/x^2) = 0$，得$x = \sqrt{T_3/T_1}$；二阶导数$-2c_v T_3/x^3$为负，所以这是极大值。效率为$1 - 1/x = 1 - \sqrt{T_1/T_3}$，最大功为$c_v(\sqrt{T_3} - \sqrt{T_1})^2$。物理意义：$r$小时每循环提取的功少；$r$大时仅压缩就使$T_2$接近$T_3$，几乎没有余地加热。
(b) $T_3/T_1 = 8$，所以$x = \sqrt 8 = 2.828$，$r = 8^{1/(2 \times 0.4)} = 8^{1.25} = 13.45 \approx 13.5$；效率为$1 - 1/\sqrt 8 = 0.646$，即$64.6\ \%$。
:::
:::

::: exercise SCR的尿素消耗 {#exr-scr level=3 check="9.5"}
一台卡车柴油机的原排$\mathrm{NO}_x$为$5.0\ \mathrm{g/kWh}$，按法规的做法以$\mathrm{NO_2}$计，$M = 46.01\ \mathrm{kg/kmol}$。SCR系统转化其中的$95\ \%$，每转化一摩尔$\mathrm{NO}_x$消耗一摩尔$\mathrm{NH_3}$；每摩尔尿素$\mathrm{CO(NH_2)_2}$（$M = 60.06\ \mathrm{kg/kmol}$）产生两摩尔$\mathrm{NH_3}$。还原剂是质量分数$32.5\ \%$的尿素溶液。求每kWh的溶液消耗量，并与$190\ \mathrm{g/kWh}$的bsfc比较。（以g/kWh为单位输入溶液消耗量，保留一位小数。）
::: solution
$\mathrm{NO}_x$的摩尔数：$5.0/46.01 = 0.1087\ \mathrm{mol/kWh}$；转化量：$0.95 \times 0.1087 = 0.1032\ \mathrm{mol/kWh}$，需要等量的$\mathrm{NH_3}$。尿素：$0.1032/2 = 0.0516\ \mathrm{mol}$，即$0.0516 \times 60.06 = 3.10\ \mathrm{g/kWh}$。溶液：$3.10/0.325 = 9.54 \approx 9.5\ \mathrm{g/kWh}$。
相对于燃料，$9.54/190 = 5.0\ \%$——与经验法则一致：装有SCR的现代卡车的AdBlue用量为其柴油消耗的百分之几。降低原排$\mathrm{NO}_x$（低温燃烧）会节省尿素，但要多耗燃料：这就是[[#sec-emissions]]中所述的标定权衡。
:::

::: exercise 设计：增程器发动机 {#exr-design level=3}
一辆串联式混合动力厢式货车需要一台车载发电用发动机，持续输出$40\ \mathrm{kW}$轴功率，以你选定的单一转速运行。在自然吸气汽油机和小型涡轮增压柴油机之间作出选择；选定转速并估算排量（说明你假定的bmep及理由）、按你所选缸数的缸径和行程、活塞平均速度，以及以kg/h计的燃料消耗和$\mathrm{CO_2}$排放。讨论排放后处理、噪声和质量。
::: solution
一种合理的答案。发电用发动机可以一直在最佳工况点运行，所以应选择接近峰值效率而不是峰值功率的转速，并避免节流。**汽油机方案：** 自然吸气发动机在$3000\ \mathrm{rev/min}$（$N = 50\ \mathrm{rev/s}$）、$\text{bmep} = 0.95\ \mathrm{MPa}$（接近全负荷，效率最佳处）下需要$V_d = 2 P/(\text{bmep}\,N) = 2 \times 40\,000/(0.95\times10^{6} \times 50) = 1.68\times10^{-3}\ \mathrm{m^3}$——一台1.7升三缸机，例如$B = 85\ \mathrm{mm}$，$L = 99\ \mathrm{mm}$（$3 \times 0.562 = 1.69\ \mathrm{L}$），$\bar U_p = 2 \times 0.099 \times 50 = 9.9\ \mathrm{m/s}$。在$\eta_b \approx 0.36$、$Q_\text{LHV} = 43\ \mathrm{MJ/kg}$时，bsfc $= 3600/(0.36 \times 43) = 233\ \mathrm{g/kWh}$，所以燃料$9.3\ \mathrm{kg/h}$，按每千克燃料$3.17\ \mathrm{kg\ CO_2}$（$0.866 \times 44.01/12.011$）计，$\mathrm{CO_2}$约$30\ \mathrm{kg/h}$。$\lambda = 1$下的三效催化器能低成本地处理污染物。**柴油机方案：** 在$\text{bmep} = 1.6\ \mathrm{MPa}$、$3000\ \mathrm{rev/min}$下，$V_d = 1.0\ \mathrm{L}$；$\eta_b \approx 0.40$给出$210\ \mathrm{g/kWh}$、$8.4\ \mathrm{kg/h}$、$\approx 26.6\ \mathrm{kg\ CO_2/h}$——燃料约少$10\ \%$，但要有颗粒过滤器、SCR和尿素箱，质量更大、噪声更大、成本更高。对于只在部分时间运行发动机的轻型厢式货车，通常优选汽油机；对于持续运行发动机的重型车辆，柴油机节省的燃料可能足以抵偿其后处理的费用。可信的答案应说明所假定的bmep和效率，并检查$\bar U_p$。
:::
