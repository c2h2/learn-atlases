本课程的每一章都只讲一种转换：燃料中的化学能变成热，再变成轴功；热变成冷；阳光变成电流；风变成旋转。在分析任何机器之前，我们需要一套把它们联系起来的核算方法——计量能量的单位，离开地面的能量与到达暖气片或车轮的能量之间的差别，热力学对每一步施加的限制，以及需求在一天和一年中的变化方式。这些都不难，但能源工程中几乎每一个错误、公众能源讨论中的大部分混乱，都来自把这些量混为一谈：把千瓦与千瓦时相比，把低位热值与高位热值相比，或者把燃料输入与电力输出相比。

本章就来建立这套核算方法。先讲单位和热值，然后沿着一条转换链追踪能量从一次能源到有用服务的过程，定量计算热能转换的损失（卡诺极限以及更接近实际的最大功率下的 Curzon–Ahlborn 效率），引入电力工程师用来代替效率的热耗率，最后讲需求如何描述——负荷曲线、负荷持续曲线和容量因数——以及给定的功率需要多少土地。本章假定读者已掌握[[thermodynamics/first-law-open]]和[[thermodynamics/second-law]]中的第一定律和第二定律，以及[[thermodynamics/exergy]]中㶲（exergy）的概念。

## 能量、功率及其单位 {#sec-units}

能量是一个量；功率是一个速率。电池储存的是能量；发动机输出的是功率。一户人家一年的用能是能量，它在寒冷傍晚的峰值需求是功率。国际单位制的单位是焦耳和瓦特，$1\,\mathrm{W} = 1\,\mathrm{J/s}$，但能源统计中使用的其他单位五花八门，因为每个行业都形成了自己的一套。

::: definition 能量和功率的单位 {#def-units}
能量的国际单位是**焦耳**（J）；功率的国际单位是**瓦特**（$1\,\mathrm{W} = 1\,\mathrm{J\,s^{-1}}$）。能源工程中常用的单位：

| 单位 | 折合焦耳 | 使用场合 |
|---|---|---|
| 瓦时，$\mathrm{Wh}$ | $3600\,\mathrm{J}$ | 电池（$\mathrm{Wh}$、$\mathrm{kWh}$） |
| 千瓦时，$\mathrm{kWh}$ | $3.6\times10^{6}\,\mathrm{J} = 3.6\,\mathrm{MJ}$ | 电费和燃气费账单 |
| 太瓦时，$\mathrm{TWh}$ | $3.6\times10^{15}\,\mathrm{J} = 3.6\,\mathrm{PJ}$ | 国家电力统计 |
| 吨油当量，$\mathrm{toe}$ | $41.868\times10^{9}\,\mathrm{J}$（按定义） | 国际能源署（IEA）和各国能源平衡表 |
| 艾焦，$\mathrm{EJ}$ | $10^{18}\,\mathrm{J}$ | 世界能源统计 |
| 英热单位，$\mathrm{Btu}$ | $1055.06\,\mathrm{J}$（国际蒸汽表值） | 美国的燃料和热耗率数据 |

**功率**乘以时间是能量：一台$2\,\mathrm{kW}$的电暖器运行$3\,\mathrm{h}$，消耗$6\,\mathrm{kWh} = 21.6\,\mathrm{MJ}$。能量除以时间是**平均功率**：一年（$8760\,\mathrm{h}$）消耗$8760\,\mathrm{kWh}$，平均为$1\,\mathrm{kW}$。
:::

千瓦时是一个与国际单位制完全兼容的能量单位（它等于$3.6\,\mathrm{MJ}$），而且往往最方便。麻烦出在看起来像能量、实际上是功率的单位上（"每年千瓦时"是功率：$1\,\mathrm{kWh/yr} = 0.114\,\mathrm{W}$），或者在该写"kWh"的地方写成了"kW"。解决办法是每一行都带着单位计算。

一个有用的数量感：一个人每天吃$2000\,\mathrm{kcal}$（$8.4\,\mathrm{MJ}$）的食物，平均代谢功率约为$97\,\mathrm{W}$。2025年世界人均一次能源供应约为每年$73\,\mathrm{GJ}$——$600\,\mathrm{EJ}$（能源研究所（Energy Institute），《世界能源统计年鉴》（*Statistical Review of World Energy*）2026年版）由约$82$亿人分摊——平均为$2.3\,\mathrm{kW}$，约为我们所吃食物的二十四倍。

### 热值

燃料按其完全燃烧、且产物冷却回参考温度（通常为$25\,^\circ\mathrm{C}$）时放出的热量来标定（见[[thermodynamics/mixtures-combustion]]）。含氢燃料会生成水，这些水最终是液态还是蒸气，会造成5–10 %的差别。

::: definition 高位热值与低位热值 {#def-heating-value}
燃料的**高位热值**（HHV，总发热量）是单位质量（或体积）燃料完全燃烧、且产物中的水**冷凝为液体**时放出的热量。**低位热值**（LHV，净发热量）是产物中的水保持为**蒸气**时的相应值。若$m_w$是单位质量燃料生成的水的质量，$h_{fg}$是水在参考温度下的汽化焓，则
$$
\mathrm{HHV} - \mathrm{LHV} = m_w\, h_{fg}.
$$ {#eq-hhv-lhv}
对甲烷，$\mathrm{HHV} \approx 55.5\,\mathrm{MJ/kg}$，$\mathrm{LHV} \approx 50.0\,\mathrm{MJ/kg}$；对煤，两者之差较小，因为煤含氢较少。
:::

效率是有用输出除以燃料能量输入，它随所用的热值而变。欧洲的惯例和大多数燃气轮机数据给出的是低位热值效率；美国电力公司和美国能源信息署（EIA）用的是高位热值。一座按低位热值效率为$60\,\%$的联合循环电站，按高位热值效率为$60 \times 50.0/55.5 = 54\,\%$——同一座电站，同一张燃料账单。冷凝式锅炉有时被宣传为"效率超过100 %"（以低位热值为基准），正是因为它回收了低位热值所未计入的一部分潜热。

::: example 用一致的单位表示一户人家的用能 {#ex-household}
一户人家一年用电$3500\,\mathrm{kWh}$，用天然气$12\,000\,\mathrm{kWh}$（按燃气表和账单所用的高位热值基准）。把两者都换算为吉焦，求平均用电功率；若天然气在计量状态下的高位热值为$39\,\mathrm{MJ/m^3}$，估算燃烧的天然气体积。
::: solution
能量：电力$3500\,\mathrm{kWh} \times 3.6\,\mathrm{MJ/kWh} = 12\,600\,\mathrm{MJ} = 12.6\,\mathrm{GJ}$，天然气$12\,000 \times 3.6 = 43\,200\,\mathrm{MJ} = 43.2\,\mathrm{GJ}$。

平均用电功率：
$$
\bar P = \frac{3500\,\mathrm{kWh}}{8760\,\mathrm{h}} = 0.400\,\mathrm{kW} = 400\,\mathrm{W}.
$$
天然气体积：每年$V = 43\,200\,\mathrm{MJ} / 39\,\mathrm{MJ/m^3} = 1.11\times10^{3}\,\mathrm{m^3}$。

合理性检查：$400\,\mathrm{W}$相当于一台冰箱、一些照明、电子设备和偶尔做饭——合理。按能量计，天然气是电力的三倍半，这是温带气候下用燃气锅炉采暖的住宅的典型情况；这户人家的大部分能量是热，而不是电。两者合计$55.8\,\mathrm{GJ}$，平均约$1.8\,\mathrm{kW}$。
:::
:::

## 一次能源、终端能源与有用能 {#sec-chain}

能源统计在每条供应链上区分三个环节。地下的煤、井口的原油、空气中的风和照到电池板上的阳光是**一次**能源。插座上的电、加油站的汽油和燃气表处的天然气是**终端**（或交付）能源。房间里的热、车辆的运动和灯发出的光是**有用**能（有时称为能源服务）。它们之间是各个转换环节——炼油厂、电站、输电线路、锅炉、发动机——每个环节都有自己的效率。

::: definition 一次能源、终端能源与有用能；转换效率 {#def-primary-final}
**一次能源**是从自然界最初开采时的形态的能量，尚未经过任何人为转换。**终端能源**是交付给最终用户的能量。**有用能**是实际以所需服务（热、功、光）的形式提供的能量。转换环节$i$的**效率**为
$$
\eta_i = \frac{E_{\text{出},i}}{E_{\text{入},i}},
$$
其中$E_{\text{出},i}$是所需形式的能量，其余部分$E_{\text{入},i} - E_{\text{出},i}$是该环节的**损失**（排出的热、摩擦、电阻发热）。对于搬运热量而非转换热量的装置——热泵——有用热量与输入功之比大于1，称为**性能系数**，而不称为效率。
:::

::: proposition 转换链的效率 {#prop-chain}
若能量依次串联通过效率为$\eta_1, \dots, \eta_n$的$n$个转换环节，且每个环节的全部有用输出都是下一个环节的输入，则总效率为各效率之积
$$
\eta_{\text{总}} = \prod_{i=1}^{n} \eta_i ,
$$ {#eq-chain}
第$k$个环节的损失占一次能源输入的份额为$(1-\eta_k)\prod_{i<k}\eta_i$。各环节的损失份额与总效率之和为1。
:::

::: proof
设$E_0$为一次能源输入，$E_k$为第$k$个环节的输出，也就是第$k+1$个环节的输入。按定义$E_k = \eta_k E_{k-1}$，由归纳法得$E_k = E_0 \prod_{i=1}^{k}\eta_i$，取$k=n$即得[[#eq-chain]]。第$k$个环节的损失为$E_{k-1} - E_k = (1-\eta_k)E_{k-1} = (1-\eta_k)E_0\prod_{i<k}\eta_i$。各损失之和逐项相消：$\sum_k (E_{k-1} - E_k) = E_0 - E_n$，所以损失加输出等于$E_0$——这就是第一定律。假设条件是：没有旁路输入或输出（中途不添加燃料，也没有有用的副产品，例如热电联产电站的热），并且所有效率都在同一能量基准上定义（全部按低位热值或全部按高位热值）。
:::

乘积法则带来一个发人深省的推论：五个效率各为$90\,\%$的环节组成的链，总效率只有$0.9^5 = 59\,\%$；而一个效率很低的环节（效率为$35\,\%$的热机）会压倒其余一切。这就是为什么大多数能源系统中最大的单项损失是火电厂和发动机排出的热，也是为什么[[energy-systems/steam-power-plants]]、[[energy-systems/gas-turbines-combined-cycles]]和[[energy-systems/internal-combustion-engines]]各章都围绕着提高同一个数字展开。

**桑基图**（Sankey diagram）把转换链画成宽度与能流成正比的箭头：一支宽大的一次能源箭头从左侧进入，分成若干转换路径，在每一步向下分出损失，最后在右侧以有用能的形式输出。国家层面的桑基图（例如劳伦斯·利弗莫尔国家实验室为美国发布的桑基图）通常表明，只有约三分之一的一次能源最终成为能源服务；其余是"弃能"，其中大部分是电站和车辆发动机排出的低温热。

::: example 从油井到车轮：电动汽车与汽油车 {#ex-ev-chain}
一辆汽车在综合工况下每公里需要车轮处$0.45\,\mathrm{MJ}$的功。比较以下两种情况每公里的一次能源消耗：
(a) 由燃气联合循环电站充电的纯电动汽车：电站$\eta = 0.55$（低位热值），输配电$0.93$，充电器$0.90$，电池-逆变器-电机-变速器$0.85$；
(b) 汽油车：从原油到油箱中的燃料$0.85$（开采、炼制和配送），从油箱到车轮$0.22$（发动机和传动系统在整个工况下的效率）。
并求汽油消耗量（单位：升每$100\,\mathrm{km}$），汽油低位热值取$32\,\mathrm{MJ/L}$。
::: solution
(a) 由[[#prop-chain]]，
$$
\eta_{\text{EV}} = 0.55 \times 0.93 \times 0.90 \times 0.85 = 0.391,
$$
所以每公里的一次能源为天然气$0.45/0.391 = 1.15\,\mathrm{MJ/km}$。

(b) $\eta_{\text{汽油}} = 0.85 \times 0.22 = 0.187$，所以为原油$0.45/0.187 = 2.41\,\mathrm{MJ/km}$。

即使电力来自化石天然气，电动汽车的一次能源消耗也只有汽油车的一半左右。汽油车每公里消耗油箱中的燃料$0.45/0.22 = 2.05\,\mathrm{MJ}$，即$2.05/32 = 0.0639\,\mathrm{L/km}$，或$6.4\,\mathrm{L/100\,km}$。

合理性检查：$6.4\,\mathrm{L/100\,km}$是中型汽油车的典型数值；电动汽车每公里消耗的电池能量$0.45/0.85 = 0.53\,\mathrm{MJ} = 0.147\,\mathrm{kWh}$，即约$15\,\mathrm{kWh/100\,km}$，也是中型电动汽车的典型数值。比较结果随发电结构而变：若用效率为$35\,\%$的燃煤电站代替联合循环电站，链效率降至$0.249$，仍高于汽油车，但单位一次能源的碳排放约为两倍（见[[energy-systems/energy-economics-emissions]]）。
:::
:::

### 一千瓦时风电算多少一次能源？

对燃料而言，一次能源就是其热值。对于不用燃料发出的电——风电、太阳能发电、水电——不存在热值，统计人员必须选择一种约定。目前使用三种方法：

- **直接当量法**把$1\,\mathrm{kWh}$风电或太阳能发电计为$1\,\mathrm{kWh}$（$3.6\,\mathrm{MJ}$）的一次能源；
- **物理能量含量法**（国际能源署，以及能源研究所自2025年版起的能源总供应）对风电、太阳能发电和水电做法相同，但对核电和地热发电按反应堆中产生的热或从地下取出的热计算，对核电约为发电量的三倍（假定效率为$33\,\%$）；
- **替代法**按典型火电厂发出同样电量所需燃烧的燃料来计算非化石电力，约为发电量的$2.5$倍。

::: warning 一次能源占比取决于核算方法
"太阳能提供了世界能源的X %"这句话，在说明核算方法之前毫无意义。在直接当量法或物理含量法下，火电厂的一千瓦时电所计的一次能源约为风力机一千瓦时电的$2.5$–$3$倍，原因仅仅是火电厂排出的热也被计入了。因此，即使服务不变，用可再生能源实现电气化也会*减少*统计上的一次能源，而一次能源占比会低估风电和太阳能对电力的贡献。始终要同类相比：电与电比，或者在同一种明确说明的方法下一次能源与一次能源比。高位热值和低位热值也需要同样的小心：在同一计算中燃料输入用高位热值、效率用低位热值，会得出偏差5–10 %的错误结果。
:::

::: example 解读世界能源统计 {#ex-statistics}
《世界能源统计年鉴》2026年版（能源研究所，2025年数据，物理含量法）报告的能源总供应为$600\,\mathrm{EJ}$，其中太阳能为$10.12\,\mathrm{EJ}$，核能占$5.2\,\%$；太阳能发电占世界发电量的$8.7\,\%$，核电占$8.8\,\%$。(a) 推算世界发电量（单位$\mathrm{TWh}$）。(b) 求以$\mathrm{EJ}$计的核电量，并与核能的一次能源数值比较。(c) 在替代法下，若假定火电效率为$40\,\%$，太阳能的一次能源数值是多少？
::: solution
(a) 在物理含量法下，太阳能一次能源等于太阳能发电量：$10.12\,\mathrm{EJ} / (3.6\times10^{15}\,\mathrm{J/TWh}) = 2811\,\mathrm{TWh}$。这占发电量的$8.7\,\%$，所以
$$
E_{\text{电}} = \frac{2811\,\mathrm{TWh}}{0.087} = 3.23\times10^{4}\,\mathrm{TWh}.
$$
（用风电得到同样的总量：$9.77\,\mathrm{EJ} = 2714\,\mathrm{TWh}$，占$8.4\,\%$，即$3.23\times10^{4}\,\mathrm{TWh}$——公布的占比是自洽的。）

(b) 核电量为$0.088 \times 3.23\times10^{4} = 2843\,\mathrm{TWh} = 10.2\,\mathrm{EJ}$。其一次能源数值为$0.052 \times 600 = 31.2\,\mathrm{EJ}$。比值$10.2/31.2 = 0.33$就是该方法所假定的反应堆热到电的效率。

(c) 替代法会把太阳能计为$10.12/0.40 = 25.3\,\mathrm{EJ}$，占相应增大的总量的$4.2\,\%$，而不是$1.7\,\%$。

合理性检查：2025年核电与太阳能发电的发电量几乎相同，但在一次能源中分别计为$31.2$和$10.1\,\mathrm{EJ}$——正是上面警示中所说的三倍。
:::
:::

## 热能转换及其极限 {#sec-limits}

世界一次能源中大约五分之四仍是燃料，其中大部分被燃烧产生热——一部分直接使用，很多在电站和发动机中转换为功。第二定律为这种转换设定了上限。一台在热力学温度$T_H$下吸热、在$T_C$下放热的热机，其效率至多为卡诺效率
$$
\eta_{\text{C}} = 1 - \frac{T_C}{T_H}
$$ {#eq-carnot}
（[[thermodynamics/second-law]]）。对于蒸汽温度$600\,^\circ\mathrm{C}$、凝汽器温度$35\,^\circ\mathrm{C}$的蒸汽电站，$\eta_\text{C} = 1 - 308/873 = 0.65$；这类实际电站能达到$0.40$–$0.47$。这一差距主要不是工程水平差造成的。热量是在一个温度范围内加入的，而不是全在最高温度下加入；炉膛烟气温度在$1500\,^\circ\mathrm{C}$以上，热量跨越很大的温差不可逆地流入蒸汽；而且可逆热机不输出功率，因为可逆传热要求温差为零，从而需要无穷大的面积或无穷长的时间。

### 最大功率下的效率

最后一点可以定量化。实际发动机既要考虑效率也要考虑功率，所以其换热器都在有限温差下工作。能抓住这一点的最简单模型是**内可逆热机**：一台可逆热机，其唯一的不可逆性在于与热源之间的传热。

::: proposition 最大功率下的 Curzon–Ahlborn 效率 {#prop-curzon-ahlborn}
一台热机通过热导$K_H$和$K_C$（单位$\mathrm{W/K}$）分别与温度为$T_H$的高温热源和温度为$T_C$的低温热源换热，使得$\dot Q_H = K_H (T_H - T_1)$，$\dot Q_C = K_C (T_2 - T_C)$，其中$T_1$和$T_2$为工质温度。若热机内部可逆，则当
$$
\eta = 1 - \sqrt{\frac{T_C}{T_H}}
$$ {#eq-ca}
时其输出功率最大，这与$K_H$和$K_C$无关，最大功率为
$$
\dot W_{\max} = \frac{K_H K_C}{K_H + K_C}\left(\sqrt{T_H} - \sqrt{T_C}\right)^{2}.
$$ {#eq-ca-power}
:::

::: proof
假设稳定运行，传热为线性（牛顿冷却）且热导恒定，热机在$T_1$和$T_2$之间内部可逆，于是工质的熵平衡给出$\dot Q_H/T_1 = \dot Q_C/T_2$。记$x = T_2/T_1$；则$\dot Q_C = x\,\dot Q_H$，效率为$\eta = 1 - x$。

把$T_2 = xT_1$代入两个传热关系式，并令$\dot Q_C = x\dot Q_H$：
$$
K_C (x T_1 - T_C) = x K_H (T_H - T_1)
\quad\Longrightarrow\quad
T_1 = \frac{x K_H T_H + K_C T_C}{x (K_H + K_C)} .
$$
于是
$$
\dot Q_H = K_H (T_H - T_1) = \frac{K_H K_C}{K_H + K_C}\,\frac{x T_H - T_C}{x},
$$
记$K = K_H K_C/(K_H + K_C)$，功率为
$$
\dot W = (1-x)\dot Q_H = K\,(1 - x)\left(T_H - \frac{T_C}{x}\right) = K\left(T_H + T_C - x T_H - \frac{T_C}{x}\right).
$$
令$d\dot W/dx = K\,(-T_H + T_C/x^2) = 0$，得$x = \sqrt{T_C/T_H}$，而$d^2\dot W/dx^2 = -2KT_C/x^3 < 0$证实这是极大值。因此$\eta = 1 - \sqrt{T_C/T_H}$，回代得$\dot W_{\max} = K(T_H + T_C - 2\sqrt{T_H T_C}) = K(\sqrt{T_H} - \sqrt{T_C})^2$。

极限情形：$x \to T_C/T_H$（卡诺值）时$\dot W \to 0$，因为$T_1 \to T_H$、$T_2 \to T_C$，没有热量流动；$x \to 1$时$\dot W \to 0$，因为热机什么也没转换。最优值介于两者之间，而由于$\sqrt{T_C/T_H} > T_C/T_H$，最大功率下的效率总是低于卡诺效率。
:::

这一结果由 F. L. Curzon 和 B. Ahlborn 于1975年发表（此前在1957年已由 I. I. Novikov 和 P. Chambadal 在核电站的背景下得到）。它是一个模型，而不是定律：实际电站并非内可逆，也不在最大功率下运行，但[[#eq-ca]]与许多实际热力电站的效率惊人地接近，这提示了它们为什么远低于卡诺效率。

::: example 燃煤电站能多接近卡诺效率？ {#ex-curzon}
一座燃煤蒸汽电站产生$565\,^\circ\mathrm{C}$的蒸汽，在$25\,^\circ\mathrm{C}$下放热。计算卡诺效率和 Curzon–Ahlborn 效率，并与这一蒸汽温度的亚临界机组典型净效率$36$–$38\,\%$相比较。
::: solution
用开尔文表示，$T_H = 838.15\,\mathrm{K}$，$T_C = 298.15\,\mathrm{K}$，所以$T_C/T_H = 0.3557$。
$$
\eta_\text{C} = 1 - 0.3557 = 0.644, \qquad \eta_\text{CA} = 1 - \sqrt{0.3557} = 1 - 0.5964 = 0.404.
$$
Curzon–Ahlborn 值$40\,\%$与实测的$36$–$38\,\%$只差几个百分点，而卡诺效率高估了25个百分点以上。剩下的差距来自锅炉损失（烟气带走燃料能量的8–12 %）、汽轮机的不完善以及电站的厂用电。

合理性检查：若在[[#eq-carnot]]中使用摄氏温度，会得到$1 - 25/565 = 0.96$——这是一个荒谬的答案，也是常见错误；热力学公式中的温度必须是热力学温度。
:::

### 热耗率

电力工程师很少报效率。他们报的是**热耗率**：每单位电量所需的燃料能量，因为它可以直接乘出燃料成本和排放。

::: proposition 热耗率、燃料流量和年燃料消耗 {#prop-heat-rate}
对于净电功率为$\dot W$、效率（燃料热值到净电力）为$\eta$的电站，**热耗率**为
$$
\mathrm{HR} = \frac{\dot Q_\text{fuel}}{\dot W} = \frac{1}{\eta}
\quad\Longrightarrow\quad
\mathrm{HR}\ [\mathrm{kJ/kWh}] = \frac{3600}{\eta},
$$ {#eq-heat-rate}
对热值为$\mathrm{HV}$的燃料，燃料质量流量为$\dot m_f = \dot W\,\mathrm{HR}/\mathrm{HV}$。在容量因数为$\mathrm{CF}$时，一年的燃料用量为$m_f = \dot m_f \times 8760\,\mathrm{h} \times \mathrm{CF}$。
:::

::: proof
按定义$\eta = \dot W/\dot Q_\text{fuel}$，所以$\dot Q_\text{fuel}/\dot W = 1/\eta$，这是一个量纲一的比值。电量用kWh、热量用kJ表示时，该比值乘以$3600\,\mathrm{kJ/kWh}$。燃料能量流率为$\dot Q_\text{fuel} = \dot m_f\,\mathrm{HV}$，由此得$\dot m_f = \dot W\,\mathrm{HR}/\mathrm{HV}$。年发电量为$\dot W \times 8760\,\mathrm{h} \times \mathrm{CF}$（容量因数的定义，[[#def-capacity-factor]]），由于假定热耗率不变，燃料也按同样比例变化。实际上热耗率在部分负荷时会升高，所以对于经常调峰的电站，用满负荷热耗率算出的年燃料量是偏低的。
:::

美国惯例中热耗率的单位是$\mathrm{Btu/kWh}$：$\mathrm{HR} = 3412.14/\eta$，所以效率为$33\,\%$的电站热耗率约为$10\,300\,\mathrm{Btu/kWh}$。

::: example 燃煤机组的燃料供应 {#ex-heat-rate}
一台$400\,\mathrm{MW}$（净）燃煤机组按低位热值计的净效率为$40\,\%$，燃用$\mathrm{LHV} = 25\,\mathrm{MJ/kg}$的煤。求热耗率、满负荷时的燃煤流量，以及容量因数为$0.60$时的年耗煤量。
::: solution
由[[#eq-heat-rate]]得热耗率：$\mathrm{HR} = 3600/0.40 = 9000\,\mathrm{kJ/kWh}$。

燃料能量流率：$\dot Q = 400\,\mathrm{MW}/0.40 = 1000\,\mathrm{MW}$。燃煤流量：
$$
\dot m_f = \frac{1000\times10^{3}\,\mathrm{kJ/s}}{25\times10^{3}\,\mathrm{kJ/kg}} = 40\,\mathrm{kg/s} = 144\,\mathrm{t/h}.
$$
年耗煤量：$40\,\mathrm{kg/s} \times 3600\,\mathrm{s/h} \times 8760\,\mathrm{h} \times 0.60 = 7.57\times10^{8}\,\mathrm{kg} = 0.76\,\mathrm{Mt}$。

合理性检查：每节铁路货车约装$100\,\mathrm{t}$，$144\,\mathrm{t/h}$相当于昼夜不停地每40分钟一节车皮——这就是燃煤电站要建在铁路旁、河边或矿口的原因。排出的热$1000 - 400 = 600\,\mathrm{MW}$，就是[[energy-systems/steam-power-plants]]中所讨论的冷却问题的规模。
:::
:::

## 需求：负荷曲线与容量因数 {#sec-demand}

电力无法廉价地大量储存（这是[[energy-systems/energy-storage]]的主题），所以供给必须逐秒跟随需求。需求随一天（夜间低，早晚出现高峰）、一周和一年（冬季采暖、夏季空调）而变化。把它对时间作图，就是**负荷曲线**。把同样的8760个小时值按大小降序重新排列——最高的一小时排在最前——就构成**负荷持续曲线**，它表明一年中负荷超过任一给定水平的小时数。

::: definition 容量因数、负荷率与负荷持续曲线 {#def-capacity-factor}
额定功率为$P_r$、在时段$T$内发电量为$E$的发电机组，其**容量因数**为
$$
\mathrm{CF} = \frac{E}{P_r T}.
$$
系统的**负荷率**是其平均负荷除以峰值负荷。**负荷持续曲线**$L(t)$（$0 \le t \le T$）是按降序排列的负荷，使得$L(t)$是在该时段内累计被超过时间$t$的负荷水平。典型容量因数（随地点和市场变化很大）：核电0.8–0.9，陆上风电0.25–0.40，光伏0.10–0.25，调峰燃气轮机低于0.1。
:::

::: proposition 负荷持续曲线上一个负荷带所供应的能量 {#prop-ldc}
设负荷持续曲线$L(t)$由按负荷带叠放的电站供电，负责负荷水平$a$与$b$（$a < b$）之间负荷带的电站在负荷超过$a$时发电。它在该时段内供应的能量是曲线下该负荷带的面积，
$$
E_{ab} = \int_0^T \min\bigl(b - a,\ \max(0,\ L(t) - a)\bigr)\,dt ,
$$
其容量因数为$\mathrm{CF}_{ab} = E_{ab}/[(b-a)T]$。曲线底部的负荷带（基荷）容量因数接近1；接近峰值的负荷带容量因数接近0。
:::

::: proof
在任一时刻，负荷$L$的分配方式是：负荷带$[a, b]$中的电站在$L \le a$时不发电，在$a < L < b$时承担全部$L - a$，在$L \ge b$时满发$b - a$；即$\min(b-a, \max(0, L-a))$。能量是功率对时间的积分，而由于被积函数仅通过$L$的值依赖于时间，把各小时重新排序不改变积分值，所以可以在负荷持续曲线上而不是在按时间顺序的负荷曲线上积分。容量因数由[[#def-capacity-factor]]取$P_r = b - a$得到。由于$L(t)$不增，负荷带在$t < t_b$（$L = b$处）时满载，到$t_a$（$L = a$处）为止部分带载，所以$\mathrm{CF}_{ab}$介于$t_b/T$和$t_a/T$之间：低负荷带的高，高负荷带的低。
:::

这就是发电机组组合的经济逻辑：资本成本高、运行成本低的电站（核电、大型燃煤电站，实际上还有风电和太阳能，它们只要资源允许就发电）应放在曲线底部，使其资本在最多的小时数里得到利用；资本成本低、燃料成本高的电站（开式循环燃气轮机、内燃机）应放在顶部，每年只运行几百小时。[[energy-systems/energy-economics-emissions]]一章将对这一权衡给出具体数字。

::: example 模型负荷持续曲线上的基荷电站和调峰电站 {#ex-ldc}
某系统的负荷持续曲线模型为$L(t)/L_\text{peak} = 0.4 + 0.6(1 - t/T)^2$，$L_\text{peak} = 10\,\mathrm{GW}$。求 (a) 系统负荷率和年用电量；(b) 负责$0$到$5\,\mathrm{GW}$负荷带的电站的容量因数；(c) 负责$8$到$10\,\mathrm{GW}$的调峰电站的容量因数。
::: solution
记$s = t/T$，$\ell(s) = 0.4 + 0.6(1-s)^2$。

(a) 负荷率$= \int_0^1 \ell\,ds = 0.4 + 0.6/3 = 0.600$。年用电量$= 0.600 \times 10\,\mathrm{GW} \times 8760\,\mathrm{h} = 52.6\,\mathrm{TWh}$。

(b) 负荷带$[0, 0.5]$（标幺值）。当$0.6(1-s)^2 > 0.1$，即$s < s_b = 1 - \sqrt{1/6} = 0.592$时，负荷超过$0.5$。此后该负荷带承担全部$\ell$。所以
$$
\int_0^1 \min(0.5, \ell)\,ds = 0.5\,s_b + \int_{s_b}^{1}\left[0.4 + 0.6(1-s)^2\right] ds = 0.5(0.592) + 0.4(0.408) + 0.2(0.408)^3 = 0.473,
$$
$\mathrm{CF} = 0.473/0.5 = 0.946$。

(c) 负荷带$[0.8, 1]$：当$(1-s)^2 > 2/3$，即$s < 1 - \sqrt{2/3} = 0.1835$时，负荷超过$0.8$。能量为$\int_0^{0.1835}[0.6(1-s)^2 - 0.4]\,ds = 0.2[1 - (0.8165)^3] - 0.4(0.1835) = 0.0177$，所以$\mathrm{CF} = 0.0177/0.2 = 0.089$。

合理性检查：底部一半的容量供应了$0.473/0.600 = 79\,\%$的能量，而顶部五分之一的容量只供应了$3\,\%$，折合满发运行每年仅约$780$小时——这是实际系统的典型情况。
:::

## 功率密度与可再生能源供应的规模 {#sec-density}

燃料使能量集中：一座$1\,\mathrm{GW}$的燃煤电站连同其储煤场占地一两平方公里。可再生能流是分散的，有用的度量是全年平均的**单位土地面积功率**。地面的太阳辐射平均约为$100$–$250\,\mathrm{W/m^2}$，取决于纬度和气候（[[energy-systems/solar-energy]]）；扣除转换效率和组件行间距之后，太阳能电站每平方米土地提供的平均电功率约为$5$–$15\,\mathrm{W}$量级。MacKay（2009）针对英国的条件估计：风电场约为$2\,\mathrm{W/m^2}$，太阳能电站$5\,\mathrm{W/m^2}$，能源作物$0.5\,\mathrm{W/m^2}$。风电场稀疏，是因为风力机之间必须相隔几倍风轮直径以避开彼此的尾流，但它们之间的土地仍可利用。

::: example 太阳能供电城市所需的土地 {#ex-land}
一座百万人口的城市人均平均用电功率为$0.5\,\mathrm{kW}$。如果平均由每平方米土地提供$10\,\mathrm{W}$平均电功率的太阳能电站供电（日照充足的场址），需要多少土地？取人口密度为每平方公里$4000$人，与城市本身的面积相比较。
::: solution
平均需求$\bar P = 10^6 \times 0.5\,\mathrm{kW} = 500\,\mathrm{MW}$。土地：
$$
A = \frac{500\times10^{6}\,\mathrm{W}}{10\,\mathrm{W/m^2}} = 5.0\times10^{7}\,\mathrm{m^2} = 50\,\mathrm{km^2}.
$$
城市面积：$10^6/4000 = 250\,\mathrm{km^2}$。太阳能电站所需的土地相当于城市自身面积的五分之一。

合理性检查和说明：这只满足了*平均值*；太阳能出力在夜间为零、在冬季较低，所以系统还需要储能或其他电源（[[energy-systems/energy-storage]]）。若按$2\,\mathrm{W/m^2}$（英国的风电）计算，面积将是$250\,\mathrm{km^2}$，与城市一样大。
:::
:::

::: quiz
一座$1.0\,\mathrm{GW}$的核电站以$0.90$的容量因数运行，热效率为$33\,\%$。下列说法哪一个正确？
- [ ] 它每年发出$0.90\,\mathrm{GW}$的能量。
- [x] 它每年发电约$7.9\,\mathrm{TWh}$，按物理含量法计，一次能源约为$24\,\mathrm{TWh}$。
- [ ] 它的热耗率为$3600 \times 0.33 = 1188\,\mathrm{kJ/kWh}$。
- [ ] 无论采用哪种核算方法，它的一次能源都是$7.9\,\mathrm{TWh}$。
::: solution
能量$= 1.0\,\mathrm{GW} \times 8760\,\mathrm{h} \times 0.90 = 7884\,\mathrm{GWh} \approx 7.9\,\mathrm{TWh}$；一次能源（反应堆热）为$7.9/0.33 \approx 24\,\mathrm{TWh}$。"每年GW"把功率和时间混在一起，不是能量。热耗率是$3600/\eta = 10\,900\,\mathrm{kJ/kWh}$，而不是$3600\eta$。直接当量法会计为$7.9\,\mathrm{TWh}$，物理含量法约为$24\,\mathrm{TWh}$——方法不同，结果不同。
:::

::: history
本章的单位比它们所计量的机器还年轻。詹姆斯·瓦特（James Watt）用马力来标定他的蒸汽机；**瓦特**作为功率单位是威廉·西门子（William Siemens）在1882年8月英国科学促进会的会长演说中提出的，**焦耳**则由1889年在巴黎召开的第二届国际电学大会与之一并采用。1865年，经济学家威廉·斯坦利·**杰文斯**（William Stanley Jevons）出版了《煤炭问题》（*The Coal Question*），论证英国的煤炭不会长久，并指出——这一观察如今称为杰文斯悖论——更高效的蒸汽机由于使煤炭驱动的功变得更便宜，反而*增加*了煤炭消耗。最大功率下的效率由 I. I. **Novikov** 和 P. **Chambadal** 于1957年针对核电站作过分析，后来又由 F. L. **Curzon** 和 B. **Ahlborn** 在1975年发表于《美国物理学杂志》（*American Journal of Physics*）的论文《最大输出功率下卡诺热机的效率》（"Efficiency of a Carnot engine at maximum power output"）中重新发现，由此开创了如今称为有限时间热力学的领域。
:::

::: summary
- 能量（J、kWh、toe、EJ）是一个量；功率（W）是一个速率。$1\,\mathrm{kWh} = 3.6\,\mathrm{MJ}$，$1\,\mathrm{toe} = 41.868\,\mathrm{GJ}$；平均功率是能量除以时间。
- 高位热值包含产物中水的潜热，低位热值不包含；每个效率都要说明用的是哪一个（甲烷$55.5$对$50.0\,\mathrm{MJ/kg}$）。
- 一次能源 → 终端能源 → 有用能：转换链的总效率是各环节效率之积，所以最差的环节——通常是热机——起支配作用。
- 非燃料电力的一次能源核算是一种约定（直接当量法、物理含量法、替代法）；占比取决于所用方法。
- 卡诺效率$1 - T_C/T_H$是热能转换的上限；最大功率下的 Curzon–Ahlborn 效率$1 - \sqrt{T_C/T_H}$更接近实际电站。
- 热耗率$= 3600/\eta$ kJ/kWh把效率转换为单位电量的燃料；燃料流量为$\dot W\,\mathrm{HR}/\mathrm{HV}$。
- 容量因数$= E/(P_r T)$；负荷持续曲线说明了为什么基荷带几乎全年运行，而峰荷带只运行几百小时。
- 可再生能流的功率密度低（每平方米土地几瓦），所以制约它们的是土地面积和波动性，而不是资源总量。
:::

## 习题 {#sec-exercises}

::: exercise 吨油当量 {#exr-toe level=1 check="11630"}
把$1\,\mathrm{toe}$换算为千瓦时。（以kWh为单位输入整数。）
::: solution
$1\,\mathrm{toe} = 41.868\times10^{9}\,\mathrm{J}$，$1\,\mathrm{kWh} = 3.6\times10^{6}\,\mathrm{J}$，所以
$$
1\,\mathrm{toe} = \frac{41.868\times10^{9}}{3.6\times10^{6}}\,\mathrm{kWh} = 11\,630\,\mathrm{kWh}.
$$
若在效率为$40\,\%$的电站中燃烧，一吨油当量只能发出约$4650\,\mathrm{kWh}$的电。
:::
:::

::: exercise 联合循环的热耗率 {#exr-heat-rate level=1 check="6207"}
一座联合循环电站的净效率为$58\,\%$（低位热值）。它的热耗率是多少？（以kJ/kWh为单位输入，四舍五入到整数。）
::: solution
由[[#eq-heat-rate]]，$\mathrm{HR} = 3600/0.58 = 6206.9\,\mathrm{kJ/kWh}$，四舍五入为$6207\,\mathrm{kJ/kWh}$。用美国单位，在同样的低位热值基准下为$3412.14/0.58 = 5883\,\mathrm{Btu/kWh}$（美国的数据通常按高位热值，因而约高$11\,\%$）。
:::
:::

::: exercise 风力机的容量因数 {#exr-cf level=1 check="30"}
一台$2.0\,\mathrm{MW}$的风力机在一个（非闰）年中发电$5256\,\mathrm{MWh}$。它的容量因数是多少？（以百分数输入容量因数。）
::: solution
$$
\mathrm{CF} = \frac{5256\,\mathrm{MWh}}{2.0\,\mathrm{MW} \times 8760\,\mathrm{h}} = \frac{5256}{17\,520} = 0.300 = 30\,\%.
$$
这并不意味着风力机只在30 %的时间里运行；它大部分时间都在部分出力下运行（见[[energy-systems/wind-hydro]]）。
:::
:::

::: exercise 热泵还是燃气锅炉？ {#exr-heat-pump level=2 check="1.64"}
一栋住宅可以用效率为$0.90$的燃气锅炉采暖，也可以用季节性能系数为$3.2$的电动热泵采暖，热泵由效率为$0.55$的联合循环电站通过损失为$7\,\%$的电网供电。利用[[#prop-chain]]，热泵路线中每单位燃烧的燃气能量有多少热量到达住宅？（输入送达热量与燃气能量之比，保留两位小数。）
::: solution
转换链为燃气 → 电（$0.55$） → 送达的电（$0.93$） → 热（$\mathrm{COP} = 3.2$）：
$$
\frac{Q_\text{住宅}}{E_\text{燃气}} = 0.55 \times 0.93 \times 3.2 = 1.6368 \approx 1.64.
$$
锅炉提供$0.90$，所以热泵路线由同样的燃气得到的热量是锅炉的$1.64/0.90 = 1.82$倍。性能系数不是效率——它大于1，因为热泵搬运了环境中的热——所以[[#prop-chain]]仍然适用，但链的"效率"大于1（[[energy-systems/refrigeration-hvac]]）。
:::
:::

::: exercise 甲烷的高位热值与低位热值之差 {#exr-hhv level=2 check="5.5"}
甲烷的燃烧反应为$\mathrm{CH_4 + 2\,O_2 \rightarrow CO_2 + 2\,H_2O}$。取$M_{\mathrm{CH_4}} = 16.04\,\mathrm{kg/kmol}$，$M_{\mathrm{H_2O}} = 18.02\,\mathrm{kg/kmol}$，$25\,^\circ\mathrm{C}$时水的$h_{fg} = 2442\,\mathrm{kJ/kg}$，求高位热值与低位热值之差。（以MJ/kg为单位输入$\mathrm{HHV} - \mathrm{LHV}$，保留一位小数。）
::: solution
每千克甲烷生成的水：$m_w = 2 \times 18.02/16.04 = 2.247\,\mathrm{kg/kg}$。由[[#eq-hhv-lhv]]，
$$
\mathrm{HHV} - \mathrm{LHV} = 2.247 \times 2442\,\mathrm{kJ/kg} = 5487\,\mathrm{kJ/kg} \approx 5.5\,\mathrm{MJ/kg}.
$$
校核：$55.5 - 50.0 = 5.5\,\mathrm{MJ/kg}$，与热值表一致。对甲烷这种含氢量最高的烃，这一差值约为高位热值的$10\,\%$。
:::
:::

::: exercise 负荷持续曲线上的基荷带 {#exr-ldc level=2 check="95"}
对于[[#ex-ldc]]的负荷持续曲线$\ell(s) = 0.4 + 0.6(1-s)^2$，利用[[#prop-ldc]]求负责峰值$0$到$0.5$负荷带的电站的容量因数。然后不经计算说明为什么$0$到$0.4$负荷带的容量因数恰好为1。（以百分数输入$0$–$0.5$负荷带的容量因数，四舍五入到整数。）
::: solution
由[[#ex-ldc]](b)，负荷带能量为$0.5 s_b + 0.4(1 - s_b) + 0.2(1 - s_b)^3$，其中$s_b = 1 - \sqrt{1/6} = 0.5918$：$0.2959 + 0.1633 + 0.0136 = 0.4728$。容量因数为$0.4728/0.5 = 0.946$，即$95\,\%$。

$0$到$0.4$负荷带完全位于最小负荷$\ell(1) = 0.4$之下，所以在每一时刻都满载，$\mathrm{CF} = 1$（实际上，检修停运会使之降到$0.85$–$0.95$）。
:::
:::

::: exercise 地热电站最大功率下的效率 {#exr-geo level=2 check="18.2"}
一座地热电站从$180\,^\circ\mathrm{C}$的热卤水中吸热，在$30\,^\circ\mathrm{C}$下放热。求其最大功率下的 Curzon–Ahlborn 效率。（以百分数输入效率，保留一位小数。）
::: solution
$T_H = 453.15\,\mathrm{K}$，$T_C = 303.15\,\mathrm{K}$，$T_C/T_H = 0.6690$。由[[#eq-ca]]，
$$
\eta_\text{CA} = 1 - \sqrt{0.6690} = 1 - 0.8179 = 0.182 = 18.2\,\%.
$$
卡诺效率为$33.1\,\%$。这一温度的双工质地热电站通常只能达到约10–15 %的净效率——低温热是低品质的能量，这从它的㶲可以看出（[[thermodynamics/exergy]]）。
:::
:::

::: exercise 世界化石能源的碳强度 {#exr-world-co2 level=3 check="69.4"}
2025年与能源相关的CO₂排放为$35\,806\,\mathrm{Mt}$，能源总供应为$600\,\mathrm{EJ}$，其中化石燃料占$86\,\%$（能源研究所，2026）。(a) 求每吉焦化石能源供应的平均排放。(b) 典型的燃烧排放因子约为：天然气$56\,\mathrm{kg/GJ}$，油品$73\,\mathrm{kg/GJ}$，煤$95\,\mathrm{kg/GJ}$（IPCC 2006年缺省值，低位热值基准）。你的结果说明了化石能源结构的什么情况？（以kg CO₂每GJ为单位输入(a)的结果，保留三位有效数字。）
::: solution
(a) 化石能源供应$= 0.86 \times 600\,\mathrm{EJ} = 516\,\mathrm{EJ} = 5.16\times10^{11}\,\mathrm{GJ}$。排放$= 35\,806\times10^{9}\,\mathrm{kg}$。平均值：
$$
\frac{3.5806\times10^{13}\,\mathrm{kg}}{5.16\times10^{11}\,\mathrm{GJ}} = 69.4\,\mathrm{kg/GJ}.
$$
(b) $69.4\,\mathrm{kg/GJ}$介于天然气和石油之间，远低于煤；考虑到用作化工原料的化石燃料（计入供应但并未全部排放）以及统计基准的影响，这与石油、煤和天然气比例相当的能源结构是一致的。若改为除以全部供应，则得到$59.7\,\mathrm{kg/GJ}$——无碳部分拉低了平均值。
:::
:::

::: exercise 推导：内可逆热机的最大功率 {#exr-ca-derive level=3}
(a) 从[[#prop-curzon-ahlborn]]的模型出发，证明最大功率时的工质温度为$T_1 = \sqrt{T_H}\,\bigl(\sqrt{T_H}K_H + \sqrt{T_C}K_C\bigr)/(K_H + K_C)$和$T_2 = \sqrt{T_C/T_H}\,T_1$。
(b) 在总热导$K_H + K_C = K_\text{tot}$固定（换热面积预算固定）的条件下，证明当$K_H = K_C$时最大功率最大，并求$T_H = 900\,\mathrm{K}$、$T_C = 300\,\mathrm{K}$、$K_\text{tot} = 20\,\mathrm{MW/K}$时的该功率。
::: solution
(a) 由证明过程，$T_1 = (xK_HT_H + K_CT_C)/[x(K_H+K_C)]$，其中$x = \sqrt{T_C/T_H}$。而$K_CT_C/x = K_C\sqrt{T_CT_H}$，所以
$$
T_1 = \frac{K_H T_H + K_C\sqrt{T_C T_H}}{K_H + K_C} = \sqrt{T_H}\,\frac{K_H\sqrt{T_H} + K_C\sqrt{T_C}}{K_H + K_C},
$$
由$x$的定义，$T_2 = xT_1$。

(b) $\dot W_{\max} = K(\sqrt{T_H} - \sqrt{T_C})^2$，其中$K = K_HK_C/(K_H+K_C)$。在$K_H + K_C = K_\text{tot}$固定时，$K_HK_C = K_H(K_\text{tot} - K_H)$在$K_H = K_\text{tot}/2$处最大，此时$K = K_\text{tot}/4$。代入数值：$\sqrt{900} - \sqrt{300} = 30 - 17.32 = 12.68\,\mathrm{K^{1/2}}$，平方为$160.8\,\mathrm{K}$，所以
$$
\dot W_{\max} = \frac{20\,\mathrm{MW/K}}{4} \times 160.8\,\mathrm{K} = 804\,\mathrm{MW},
$$
效率为$1 - \sqrt{1/3} = 42.3\,\%$。平均分配是这一对称模型的性质；实际电站会把更多面积用在表面传热系数低的地方。
:::
:::

::: exercise 设计：海岛的能源供应 {#exr-island level=3}
一个有$20\,000$人的海岛目前全部电力都靠柴油发电机组：平均需求$8\,\mathrm{MW}$，峰值$14\,\mathrm{MW}$，发电机组效率$40\,\%$，柴油低位热值$43\,\mathrm{MJ/kg}$。估算目前每年的柴油消耗量。然后构思一个使柴油用量减半的供电系统，可在风电（容量因数约$0.35$）、光伏（约$0.18$）和电池中选择，给出各自的容量、陆地或海域面积（利用[[#sec-density]]中的功率密度）以及主要风险。答案不唯一；用数字论证你的选择。
::: solution
目前的燃料：年发电量$8\,\mathrm{MW} \times 8760\,\mathrm{h} = 70.1\,\mathrm{GWh}$；燃料能量$70.1/0.40 = 175\,\mathrm{GWh} = 631\,\mathrm{TJ}$；柴油$631\times10^{12}/43\times10^{6} = 1.47\times10^{7}\,\mathrm{kg} \approx 14.7\,\mathrm{kt}$每年，约$17\,\mathrm{ML}$。

要使之减半，可再生能源每年必须提供约$35\,\mathrm{GWh}$*有用*的电。一种可能的设计：$8\,\mathrm{MW}$风电（$8 \times 8760 \times 0.35 = 24.5\,\mathrm{GWh}$）加$8\,\mathrm{MW}$光伏（$12.6\,\mathrm{GWh}$），弃电前合计$37\,\mathrm{GWh}$。由于风和太阳有时会超过需求，除非加以储存，否则一部分电要被弃掉；一组约$10\,\mathrm{MW}$ / $20$–$40\,\mathrm{MWh}$的电池可以把中午的太阳能移到傍晚高峰，并给柴油机组留出启动时间（[[energy-systems/energy-storage]]）。土地：按平均$2\,\mathrm{W/m^2}$计，风电场$2.8\,\mathrm{MW}$的平均出力需要约$1.4\,\mathrm{km^2}$分散布置的风力机（大部分土地仍可耕种）；光伏按平均约$7\,\mathrm{W/m^2}$计，需要约$0.2\,\mathrm{km^2}$。

需要讨论的风险：无风多云的几周（柴油机组仍须承担全部$14\,\mathrm{MW}$峰值，所以柴油*容量*并不减少，减少的只是其发电量）；低惯量下的电网稳定性；盐雾腐蚀和台风载荷；柴油机更多地在部分负荷下运行，热耗率较高，会侵蚀节省的燃料。好的答案应逐月而不是按全年核对能量平衡。
:::
