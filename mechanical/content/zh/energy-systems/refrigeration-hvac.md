制冷机做的是任何热流都不会自发去做的事：它把热量从冷空间取出，倒进较暖的空间。第二定律说这要耗功，而制冷的技艺就在于每搬运一千焦热量付出尽可能少的功。同一台机器，从其高温侧看，就是热泵——一种用比所耗电能多两到四倍的热量来给建筑供暖的方法。而一旦把这种机器的冷盘管放进一股空气流中，它不仅冷却空气，还会使其中的水分凝结出来，这就是为什么空气调节一半是制冷剂的热力学，一半是湿空气的热力学。

本章讨论这两半。先讲为性能系数设定上限的逆卡诺循环，然后建立几乎所有冰箱、空调和热泵都采用的蒸气压缩循环——先是理想循环，再加上过热、过冷和实际压缩机——并讨论在臭氧消耗和全球变暖约束下如何选择制冷剂。有一小节介绍以热而不是功驱动的吸收式制冷机。后一半建立湿空气热力学——含湿量、相对湿度、露点、湿球温度和湿空气的焓——并把质量平衡和能量平衡应用于空调系统的各个过程，最后对一间办公室作冷负荷估算。本章假定读者已掌握[[thermodynamics/entropy]]和[[thermodynamics/power-cycles]]中的熵与循环分析，以及[[thermodynamics/mixtures-combustion]]中的理想气体混合物。

**物性数据。** 本章的制冷剂物性由 CoolProp 中实现的参考状态方程计算（对R-134a为 Tillner-Roth–Baehr 方程），采用**IIR焓基准**：$0\,^\circ\mathrm{C}$饱和液体的$h = 200\,\mathrm{kJ/kg}$，$s = 1\,\mathrm{kJ/(kg\,K)}$。Çengel & Boles 的R-134a表采用ASHRAE基准（$-40\,^\circ\mathrm{C}$饱和液体的$h = s = 0$），所以其绝对值与我们的相差一个常数，但每一个焓*差*——这是循环分析唯一用到的——都一致。切勿在一次计算中混用两种基准。水蒸气压力取自 IAPWS-95。

## 逆卡诺循环与性能系数 {#sec-carnot}

制冷机和热泵是用于不同目的的同一种装置。两者都从温度为$T_L$的低温区吸热$Q_L$，接受功$W$，并向温度为$T_H$的高温区放热$Q_H = Q_L + W$。对制冷机，有用输出是$Q_L$；对热泵，是$Q_H$。

::: definition 性能系数 {#def-cop}
对于在低温下吸热$Q_L$、在高温下放热$Q_H$、消耗净功$W_\text{入} = Q_H - Q_L$的循环装置，
$$
\mathrm{COP}_R = \frac{Q_L}{W_\text{入}}, \qquad \mathrm{COP}_{HP} = \frac{Q_H}{W_\text{入}} .
$$
同样的比值也适用于速率（$\dot Q_L$、$\dot Q_H$、$\dot W_\text{入}$）。制冷量以千瓦表示；北美惯例中也用**冷吨**，$1\,\text{冷吨} = 12\,000\,\mathrm{Btu/h} = 3.517\,\mathrm{kW}$（一天内融化一短吨冰的吸热速率）。性能系数不是效率：它通常大于1，因为装置是在搬运热量而不是转换热量。
:::

::: proposition 性能系数的卡诺极限 {#prop-carnot-cop}
对于在热力学温度为$T_L < T_H$的两个热源之间工作的任何制冷机或热泵，
$$
\mathrm{COP}_R \le \frac{T_L}{T_H - T_L}, \qquad \mathrm{COP}_{HP} \le \frac{T_H}{T_H - T_L},
$$ {#eq-carnot-cop}
可逆装置取等号；且对每一种装置（可逆或不可逆）都有$\mathrm{COP}_{HP} = \mathrm{COP}_R + 1$。
:::

::: proof
一个循环的第一定律给出$W_\text{入} = Q_H - Q_L$，所以对任何装置$\mathrm{COP}_{HP} = Q_H/W_\text{入} = (Q_L + W_\text{入})/W_\text{入} = \mathrm{COP}_R + 1$。第二定律，写成只与两个热源换热的一个循环的熵平衡，为
$$
S_\text{gen} = \frac{Q_H}{T_H} - \frac{Q_L}{T_L} \ge 0 ,
$$
因为工质回到初态（净熵变为零），而高温热源获得$Q_H/T_H$，低温热源失去$Q_L/T_L$。因此$Q_H/Q_L \ge T_H/T_L$，
$$
\mathrm{COP}_R = \frac{Q_L}{Q_H - Q_L} = \frac{1}{Q_H/Q_L - 1} \le \frac{1}{T_H/T_L - 1} = \frac{T_L}{T_H - T_L},
$$
当$S_\text{gen} = 0$时取等号。加1即得热泵的上限。假设条件：稳定的循环运行，只在两个热源温度下换热（所以对实际机器，$T_L$和$T_H$应取空间的温度，而不是制冷剂的温度），温度用开尔文。
:::

两个推论决定了后面的一切。第一，性能系数取决于**温升**$T_H - T_L$，而不是温度本身：跨越$45\,\mathrm{K}$工作的冷冻柜本质上就比跨越$20\,\mathrm{K}$工作的空调差。第二，每多一开尔文的温升都要损失百分之几的性能系数——所以制冷剂为了以有限速率换热而在蒸发器和冷凝器中所需的每一开尔文温差，都要用压缩机功率来支付。

::: example 家用冷冻柜和热泵的卡诺极限 {#ex-carnot}
(a) 一台冷冻柜在$25\,^\circ\mathrm{C}$的厨房中保持$-18\,^\circ\mathrm{C}$。可能的最高性能系数是多少？(b) 一台热泵从$-18\,^\circ\mathrm{C}$的室外空气向$25\,^\circ\mathrm{C}$的住宅供热。其可能的最高性能系数是多少？
::: solution
(a) $T_L = 255.15\,\mathrm{K}$，$T_H = 298.15\,\mathrm{K}$，温升$43\,\mathrm{K}$。由[[#eq-carnot-cop]]，
$$
\mathrm{COP}_{R,\max} = \frac{255.15}{43} = 5.93 .
$$
(b) 温度相同，所以$\mathrm{COP}_{HP,\max} = 298.15/43 = 6.93 = 5.93 + 1$。

合理性检查：实际冷冻柜在这些条件下的性能系数约为1.5–2，"卡诺比"约为0.3；制冷剂必须比冷冻柜冷几开、比厨房热几开，仅此一项就把温升提高到$60\,\mathrm{K}$或更多。若用摄氏温度，$-18/43$，会得到负的性能系数——公式需要开尔文。
:::
:::

## 蒸气压缩循环 {#sec-vcr}

在两相区内使用蒸气的卡诺制冷机，需要一台处理湿蒸气的压缩机和一台从液体中产出一点点功的膨胀机。实际机器作了两点改变。压缩机吸入**干蒸气**，所以压缩终止于过热区；膨胀用**节流阀**（或毛细管）完成，它浪费了那一点膨胀功，但便宜且易于控制。结果就是蒸气压缩循环：

1. → 2：压缩机把饱和（或略微过热）蒸气从蒸发压力提高到冷凝压力；
2. → 3：冷凝器向环境放热；蒸气被冷却到饱和、冷凝，以饱和（或过冷）液体离开；
3. → 4：膨胀阀把液体等焓节流到蒸发压力，产生低温的气液混合物；
4. → 1：液体沸腾时，蒸发器从冷空间吸热。

在制冷工程师常用的$p$–$h$图（而不是$T$–$s$图）上，循环近似为一个矩形：两条水平线（定压蒸发和冷凝）、一条竖直线（定$h$节流）和一条陡峭的压缩线。

::: proposition 蒸气压缩循环的能量平衡 {#prop-vcr}
对于质量流量为$\dot m$的制冷剂稳定流动，动能和势能变化可忽略，压缩机无散热，膨胀阀绝热，
$$
\dot Q_L = \dot m\,(h_1 - h_4), \quad \dot W_\text{入} = \dot m\,(h_2 - h_1), \quad \dot Q_H = \dot m\,(h_2 - h_3), \quad h_4 = h_3,
$$
于是
$$
\mathrm{COP}_R = \frac{h_1 - h_3}{h_2 - h_1}, \qquad \mathrm{COP}_{HP} = \frac{h_2 - h_3}{h_2 - h_1}.
$$ {#eq-vcr-cop}
若压缩机等熵效率为$\eta_c = (h_{2s} - h_1)/(h_2 - h_1)$，则实际出口焓为$h_2 = h_1 + (h_{2s} - h_1)/\eta_c$，其中$h_{2s}$在冷凝压力和$s_{2s} = s_1$下求取。
:::

::: proof
对每个单进单出的部件应用稳定流动能量方程$\dot Q - \dot W = \dot m\,(h_\text{出} - h_\text{入})$（[[thermodynamics/first-law-open]]）。蒸发器：无功，$\dot Q_L = \dot m(h_1 - h_4)$。压缩机：按假设绝热，$-\dot W = \dot m(h_2 - h_1)$，所以$\dot W_\text{入} = \dot m(h_2 - h_1)$。冷凝器：无功，热量离开，$\dot Q_H = \dot m(h_2 - h_3)$。阀门：无热无功，所以$h_4 = h_3$——节流过程等焓但不可逆（熵增加）。在比值$\dot Q_L/\dot W_\text{入}$中代入$h_4 = h_3$即得[[#eq-vcr-cop]]，而总平衡$\dot Q_H = \dot Q_L + \dot W_\text{入}$恒成立。等熵效率关系式就是$\eta_c$的定义对$h_2$求解。
:::

::: algorithm 蒸气压缩循环的分析 {#alg-vcr}
1. 确定蒸发温度（比冷空间温度低几开）和冷凝温度（比热汇温度高几开）；查出饱和压力$p_L$、$p_H$。
2. 状态1（压缩机进口）：在$p_L$下，为饱和蒸气或具有给定的过热度；求$h_1$、$s_1$。
3. 状态$2s$：在$p_H$下，$s = s_1$；求$h_{2s}$。然后$h_2 = h_1 + (h_{2s} - h_1)/\eta_c$，由$(p_H, h_2)$求排气温度。
4. 状态3（冷凝器出口）：在$p_H$下，为饱和液体或具有给定的过冷度；求$h_3$。状态4：$h_4 = h_3$。
5. 单位制冷量$q_L = h_1 - h_4$；质量流量$\dot m = \dot Q_L/q_L$；功率$\dot W = \dot m(h_2 - h_1)$；性能系数由[[#eq-vcr-cop]]求得。
6. 合理性检查：$\mathrm{COP} <$制冷剂温度下的卡诺值；排气温度对压缩机润滑油是可接受的（通常低于约$100$–$120\,^\circ\mathrm{C}$）；$\dot Q_H = \dot Q_L + \dot W$。
:::

::: example 使用R-134a的理想循环 {#ex-ideal-vcr}
一台使用R-134a的理想蒸气压缩制冷机，蒸发温度为$-10\,^\circ\mathrm{C}$，冷凝温度为$40\,^\circ\mathrm{C}$。制冷剂以饱和蒸气离开蒸发器，以饱和液体离开冷凝器；压缩为等熵过程。对于$10\,\mathrm{kW}$的制冷量，求性能系数、质量流量、压缩机功率和放热量。
::: solution
按[[#alg-vcr]]，用R-134a物性（IIR基准）：

- $p_L = p_\text{sat}(-10\,^\circ\mathrm{C}) = 200.6\,\mathrm{kPa}$；$p_H = p_\text{sat}(40\,^\circ\mathrm{C}) = 1016.6\,\mathrm{kPa}$。
- 状态1，$-10\,^\circ\mathrm{C}$的饱和蒸气：$h_1 = 392.66\,\mathrm{kJ/kg}$，$s_1 = 1.7334\,\mathrm{kJ/(kg\,K)}$。
- 状态2s，$1016.6\,\mathrm{kPa}$，$s = 1.7334$：$h_2 = 426.48\,\mathrm{kJ/kg}$，$T_2 = 46.3\,^\circ\mathrm{C}$。
- 状态3，$40\,^\circ\mathrm{C}$的饱和液体：$h_3 = 256.41\,\mathrm{kJ/kg} = h_4$。

单位制冷量$q_L = 392.66 - 256.41 = 136.26\,\mathrm{kJ/kg}$；压缩机功$w = 426.48 - 392.66 = 33.81\,\mathrm{kJ/kg}$。
$$
\mathrm{COP}_R = \frac{136.26}{33.81} = 4.03, \qquad \dot m = \frac{10\,\mathrm{kW}}{136.26\,\mathrm{kJ/kg}} = 0.0734\,\mathrm{kg/s},
$$
$\dot W_\text{入} = 0.0734 \times 33.81 = 2.48\,\mathrm{kW}$，$\dot Q_H = 10 + 2.48 = 12.48\,\mathrm{kW}$。

合理性检查：制冷剂温度之间的卡诺性能系数为$263.15/50 = 5.26$；理想蒸气压缩循环达到其$77\,\%$，不足部分来自节流损失以及压缩过程中高于冷凝温度的过热"尖角"。若用 Çengel & Boles 的ASHRAE基准表，各焓值都约低$148\,\mathrm{kJ/kg}$，但$q_L$、$w$和性能系数相同。
:::
:::

### 过热、过冷与实际压缩机

实际循环与理想循环有三方面有意或不可避免的差别。蒸发器出口几开的**过热**保护压缩机免受液滴冲击（热力膨胀阀所控制的正是这一过热度）。冷凝器出口几开的**过冷**确保阀门得到纯液体，并且由于$h_3$降低而增大单位制冷量。而压缩机不是等熵的：小型全封闭压缩机的等熵效率约为0.6–0.75，大型螺杆式和离心式机组为0.75–0.85。换热器和管道中的压降带来更多损失。

::: example 实际R-134a循环 {#ex-real-vcr}
重做[[#ex-ideal-vcr]]，压缩机进口过热$5\,\mathrm{K}$（于是在$200.6\,\mathrm{kPa}$下$T_1 = -5\,^\circ\mathrm{C}$），冷凝器出口过冷$5\,\mathrm{K}$（在$1016.6\,\mathrm{kPa}$下$T_3 = 35\,^\circ\mathrm{C}$），压缩机等熵效率为$0.75$。忽略压降。
::: solution
- 状态1：$200.6\,\mathrm{kPa}$，$-5\,^\circ\mathrm{C}$：$h_1 = 396.93\,\mathrm{kJ/kg}$，$s_1 = 1.7494\,\mathrm{kJ/(kg\,K)}$。
- 状态2s：$1016.6\,\mathrm{kPa}$，$s = 1.7494$：$h_{2s} = 431.64\,\mathrm{kJ/kg}$。
- 实际：$h_2 = 396.93 + (431.64 - 396.93)/0.75 = 443.21\,\mathrm{kJ/kg}$，排气温度为$61.9\,^\circ\mathrm{C}$。
- 状态3：$35\,^\circ\mathrm{C}$的过冷液体（取为$35\,^\circ\mathrm{C}$的饱和液体）：$h_3 = 248.99\,\mathrm{kJ/kg} = h_4$。

$q_L = 396.93 - 248.99 = 147.93\,\mathrm{kJ/kg}$，$w = 443.21 - 396.93 = 46.29\,\mathrm{kJ/kg}$，
$$
\mathrm{COP}_R = \frac{147.93}{46.29} = 3.20 .
$$
对$10\,\mathrm{kW}$：$\dot m = 10/147.93 = 0.0676\,\mathrm{kg/s}$，$\dot W_\text{入} = 0.0676 \times 46.29 = 3.13\,\mathrm{kW}$。

合理性检查：过冷和过热使单位制冷量提高了$8.6\,\%$（这里假定过热是在蒸发器内完成的有效制冷），但压缩机的不完善使功增加了$37\,\%$，所以性能系数从$4.03$降到$3.20$——卡诺比为$3.20/5.26 = 0.61$，是优良商用机组的典型值。
:::
:::

## 制冷剂 {#sec-refrigerants}

制冷剂必须在蒸发温度下以方便的压力蒸发（最好高于大气压，使泄漏向外而空气不会漏入），单位体积吸气的潜热要大（使压缩机小），化学性质稳定，与润滑油和材料相容，并且安全。自20世纪80年代以来，两项环境指标占据了主导地位。

- **臭氧消耗潜值（ODP）**：每千克排放所破坏的臭氧，相对于CFC-11。含氯的CFC（R-12，ODP 1）和HCFC（R-22，ODP 0.055）根据**《蒙特利尔议定书》**正在或已经被淘汰。
- **全球变暖潜值（GWP）**：每千克排放在100年内的时间积分辐射强迫，相对于每千克CO₂。氢氟碳化物（HFC）的ODP为零但GWP高，正在根据**基加利修正案**（2016年）逐步削减，其时间表采用IPCC第四次评估报告（AR4）的100年GWP值。

| 制冷剂 | 类型 | GWP（100年） | 安全分类 | 典型用途 |
|---|---|---|---|---|
| R-134a | HFC | 1430（AR4） | A1 | 汽车空调（旧款）、冷水机组、家用（旧款） |
| R-410A | HFC混合物 | 2088（AR4） | A1 | 分体空调（正被取代） |
| R-32 | HFC | 675（AR4） | A2L | 分体空调、热泵 |
| R-1234yf | HFO | 低于1（IPCC AR5） | A2L | 汽车空调 |
| R-290（丙烷） | 碳氢化合物 | 3 | A3 | 家用和商用机组、热泵 |
| R-717（氨） | 天然工质 | 0 | B2L | 工业制冷、冷库 |
| R-744（CO₂） | 天然工质 | 1 | A1 | 超市、热泵热水器 |

安全分类（ISO 817 / ASHRAE 34）把毒性（A较低，B较高）与可燃性（1不燃，2L微燃，2，3高度可燃）结合起来。趋势是从合成的高GWP工质转向氨、CO₂、碳氢化合物和HFO，每一种都带来工程问题：氨的毒性，CO₂的高压（其临界温度为$31\,^\circ\mathrm{C}$，所以放热过程常常是跨临界的），丙烷的可燃性（限制了充注量）以及HFO的成本。

::: warning 泄漏与制冷系统的"直接"排放
制冷剂的气候影响是其GWP乘以逸出的质量，而实际系统会泄漏：商用系统的充注量每年损失百分之几，报废时若不回收，全部充注量都会逸出。一家充注$200\,\mathrm{kg}$ R-404A（AR4 GWP 3922）、每年损失$15\,\%$的超市，每年排放$200 \times 0.15 \times 3922 = 118\,\mathrm{t}$ CO₂当量——与该装置用电所产生的排放相当。比较制冷剂时，不要只比较性能系数。而且制冷剂作业受到管制：操作、回收和检漏需要经过培训和认证的技术人员，氨和碳氢化合物还需要专门的安全措施。
:::

## 热泵 {#sec-heat-pumps}

热泵是一台蒸气压缩机器，其冷凝器为建筑或生活热水供热，其蒸发器从室外空气、土壤或水源中取热。品质因数是$\mathrm{COP}_{HP}$，以及在室外温度不断变化的整个采暖季中的**季节性能系数**（SCOP），即整个季节供热量与用电量之比。由于温升影响很大，热泵最适合配低温散热末端（$35$–$45\,^\circ\mathrm{C}$的地板采暖或大型散热器），以及温暖的热源（深层土壤温度保持在年平均气温附近）。

::: example 使用丙烷的空气–水热泵 {#ex-heat-pump}
一台使用R-290的空气–水热泵，蒸发温度为$-5\,^\circ\mathrm{C}$（室外空气约$+2\,^\circ\mathrm{C}$），冷凝温度为$45\,^\circ\mathrm{C}$（送往散热器的水约$40\,^\circ\mathrm{C}$）。制冷剂以饱和蒸气离开蒸发器，以饱和液体离开冷凝器；$\eta_c = 0.70$。求$\mathrm{COP}_{HP}$、其卡诺比和压缩机排气温度。与相同条件下的R-32比较，后者的性能系数为$3.76$，排气温度为$103\,^\circ\mathrm{C}$。
::: solution
R-290物性：$p_L = 406.0\,\mathrm{kPa}$，$p_H = 1534\,\mathrm{kPa}$；$h_1 = 569.30\,\mathrm{kJ/kg}$，$s_1 = 2.3781\,\mathrm{kJ/(kg\,K)}$；$h_{2s} = 631.64\,\mathrm{kJ/kg}$；$h_3 = 321.79\,\mathrm{kJ/kg}$。

$h_2 = 569.30 + (631.64 - 569.30)/0.70 = 658.35\,\mathrm{kJ/kg}$，所以
$$
\mathrm{COP}_{HP} = \frac{h_2 - h_3}{h_2 - h_1} = \frac{658.35 - 321.79}{658.35 - 569.30} = \frac{336.56}{89.05} = 3.78 .
$$
制冷剂温度之间的卡诺值：$318.15/50 = 6.36$；卡诺比$3.78/6.36 = 0.59$。由$p_H$和$h_2$得排气温度：$62.6\,^\circ\mathrm{C}$。

比较：R-32给出几乎相同的性能系数，但排气温度约为$103\,^\circ\mathrm{C}$，因为其蒸气的比热容比较高；这限制了R-32在高温升场合（寒冷气候、生活热水）的使用，而丙烷的限制在于其可燃性。合理性检查：$3.78$是空气–水热泵在$+2/35$–$45\,^\circ\mathrm{C}$工况下的典型额定性能系数；每单位电能提供$3.78$单位的热，其中$2.78$单位取自室外空气。
:::
:::

## 吸收式制冷 {#sec-absorption}

吸收式制冷机用"热压缩机"代替压缩机。来自蒸发器的低压制冷剂蒸气被**吸收**到液态溶液中（水蒸气吸收到溴化锂溶液中，或氨吸收到水中），溶液被**泵送**到高压——泵送液体耗功极少——在**发生器**中，热量把制冷剂从溶液中重新驱出，成为高压蒸气，然后像蒸气压缩循环中一样冷凝、节流和蒸发。因此这种机器在三个温度下换热：在高温$T_G$下接受驱动热$Q_G$（蒸汽、热水、废热、太阳能热），在$T_L$下吸热$Q_L$，并在环境温度$T_0$下（在吸收器和冷凝器中）放出$Q_G + Q_L$。

::: proposition 热驱动制冷机的最大性能系数 {#prop-absorption}
一个在$T_G$下接受热量$Q_G$、在$T_L$下提取$Q_L$、只在$T_0$下放热（$T_L < T_0 < T_G$）且耗功可忽略的装置，有
$$
\mathrm{COP}_\text{abs} = \frac{Q_L}{Q_G} \le \left(1 - \frac{T_0}{T_G}\right)\frac{T_L}{T_0 - T_L} .
$$ {#eq-abs-cop}
:::

::: proof
一个循环的第一定律：放热量$Q_0 = Q_G + Q_L$。与三个热源换热的一个循环的熵平衡：
$$
S_\text{gen} = \frac{Q_0}{T_0} - \frac{Q_G}{T_G} - \frac{Q_L}{T_L} \ge 0 .
$$
代入$Q_0 = Q_G + Q_L$：
$$
Q_G\left(\frac{1}{T_0} - \frac{1}{T_G}\right) \ge Q_L\left(\frac{1}{T_L} - \frac{1}{T_0}\right)
\quad\Longrightarrow\quad
\frac{Q_L}{Q_G} \le \frac{(T_G - T_0)/(T_0 T_G)}{(T_0 - T_L)/(T_0 T_L)} = \frac{T_G - T_0}{T_G}\cdot\frac{T_L}{T_0 - T_L}.
$$
该上限是$T_G$与$T_0$之间卡诺热机效率与$T_L$与$T_0$之间卡诺制冷机性能系数之积——恰好等于用一台可逆热机驱动一台可逆制冷机所得的结果，这表明该上限原则上是可以达到的。假设条件：稳定的循环运行，忽略泵功，在三个热源温度下换热。
:::

驱动热为$120\,^\circ\mathrm{C}$、放热温度为$30\,^\circ\mathrm{C}$、冷冻水为$5\,^\circ\mathrm{C}$时，上限为$(1 - 303.15/393.15)(278.15/25) = 2.55$。实际的单效溴化锂冷水机组约达$0.7$，以$150$–$180\,^\circ\mathrm{C}$驱动的双效机组约达$1.2$。性能系数低于1并不是失败：输入的是热，往往是本来要被丢弃的废热，由燃气发动机或燃气轮机排气驱动的吸收式冷水机组是冷热电三联供电站的标准部件（见[[energy-systems/gas-turbines-combined-cycles]]）。

## 湿空气：湿空气热力学 {#sec-psychro}

空气调节同时控制空气的温度和湿度。大气中的空气是干空气与水蒸气的混合物，在所涉及的低分压（几千帕）下两者都表现为理想气体。水蒸气含量很小——按质量约百分之一——但其潜热使它在空调过程的能量中占很大份额。

::: definition 湿空气的状态参数 {#def-psychro}
对于总压为$p$、干球温度为$T$、水蒸气分压为$p_v$、干空气分压为$p_a = p - p_v$的湿空气：

- **含湿量**（比湿度）$\omega = m_v/m_a$，即单位质量*干空气*所含的水蒸气质量；
- **相对湿度**$\phi = p_v/p_g(T)$，其中$p_g(T)$是水在$T$下的饱和压力；
- **露点温度**$T_{dp}$：$p_v$下的饱和温度，即空气在定压、定$\omega$下冷却时达到饱和的温度；
- **绝热饱和温度**，（对常规条件下的空气–水体系）近似等于在流动空气中用包着湿纱布的温度计读得的**湿球温度**$T_{wb}$：空气通过绝热地蒸发水分而达到饱和时所达到的温度。

空气调节中的所有比参数——焓、比体积——都以每千克干空气计，因为干空气质量流量在每个过程中守恒，而水蒸气质量不守恒。
:::

::: proposition 湿空气的含湿量与焓 {#prop-moist-air}
把干空气和水蒸气当作理想气体，
$$
\omega = 0.622\,\frac{p_v}{p - p_v} = 0.622\,\frac{\phi\,p_g}{p - \phi\,p_g},
$$ {#eq-omega}
以$0\,^\circ\mathrm{C}$的干空气和$0\,^\circ\mathrm{C}$的饱和液态水为参考状态，每千克干空气的焓为
$$
h = c_{pa}\,T + \omega\,(h_{g0} + c_{pv}\,T) \approx 1.005\,T + \omega\,(2501 + 1.82\,T)\quad \mathrm{kJ/kg\ dry\ air},
$$ {#eq-moist-h}
其中$T$以$^\circ\mathrm{C}$计。
:::

::: proof
每种组分以其自身的分压占据整个容积$V$（道尔顿定律），所以$p_v V = m_v R_v T$，$p_a V = m_a R_a T$，$T$为热力学温度。相除，
$$
\omega = \frac{m_v}{m_a} = \frac{R_a}{R_v}\,\frac{p_v}{p_a} = \frac{0.2870}{0.4615}\,\frac{p_v}{p - p_v} = 0.622\,\frac{p_v}{p - p_v},
$$
比值$R_a/R_v = M_v/M_a = 18.015/28.97 = 0.622$。代入$p_v = \phi p_g$即得第二种形式。

理想气体混合物的焓是各组分焓之和，每个组分的焓只取决于温度：$H = m_a h_a + m_v h_v$，按单位质量干空气计$h = h_a + \omega h_v$。对于$c_{pa} = 1.005\,\mathrm{kJ/(kg\,K)}$恒定、$0\,^\circ\mathrm{C}$时焓为零的干空气，$h_a = 1.005\,T$。低分压下水蒸气的焓几乎与压力无关；从$0\,^\circ\mathrm{C}$的饱和蒸气出发，$h_{g0} = 2501\,\mathrm{kJ/kg}$（相对于$0\,^\circ\mathrm{C}$的液体），再以$c_{pv} = 1.82\,\mathrm{kJ/(kg\,K)}$作为理想气体加热，得$h_v = 2501 + 1.82\,T$。与真实气体湿空气模型相比，在大气压下$0$到$50\,^\circ\mathrm{C}$之间，这一近似的误差低于约$0.5\,\%$。
:::

**焓湿图**在固定总压（通常为$101.325\,\mathrm{kPa}$）下以$\omega$对$T$作图，图上有等$\phi$曲线（最上面的$\phi = 1$是饱和曲线）、等湿球温度线和等焓线（两者几乎平行，向右下倾斜），以及等比体积线。每个空调过程都是图上的一条线或一个点。

::: solution
$p_v = 0.60 \times 4.247 = 2.548\,\mathrm{kPa}$。由[[#eq-omega]]，
$$
\omega = 0.622 \times \frac{2.548}{101.325 - 2.548} = 0.01605\,\mathrm{kg/kg\ dry\ air} = 16.0\,\mathrm{g/kg}.
$$
露点：$2.548\,\mathrm{kPa}$下的饱和温度为$T_{dp} = 21.4\,^\circ\mathrm{C}$；任何比它冷的表面（冷却盘管、冷水管）都会结露。由[[#eq-moist-h]]求焓：
$$
h = 1.005(30) + 0.01605\,(2501 + 1.82 \times 30) = 30.15 + 41.01 = 71.2\,\mathrm{kJ/kg\ dry\ air}.
$$
比体积（干空气在其分压下）：$v = R_a T/p_a = 0.2870 \times 303.15/(101.325 - 2.548) = 0.881\,\mathrm{m^3/kg\ dry\ air}$。

合理性检查：焓的一半以上（$71\,\mathrm{kJ/kg}$中的$41$）由只占质量1.6 %的水蒸气携带——这就是潜热部分。CoolProp 的真实气体湿空气模型给出$\omega = 16.1\,\mathrm{g/kg}$和$h = 71.4\,\mathrm{kJ/kg}$，所以理想气体公式的精度远优于1 %；同一模型给出的湿球温度为$23.8\,^\circ\mathrm{C}$。

## 空气调节过程 {#sec-processes}

每一个空调过程——加热、冷却、加湿、除湿、混合——都用稳定流动装置的三个平衡来分析：干空气质量、水的质量和能量。水平衡包括加入（加湿器）或除去（凝结水）的任何液态水，能量平衡包括其焓$h_w$（液态水的焓，$\approx 4.18\,T$ kJ/kg）。

- **显热加热或冷却**（不加入也不除去水分）：$\omega$不变，$\dot Q = \dot m_a(h_2 - h_1)$；加热时相对湿度下降，冷却时上升。
- **冷却除湿**：空气在冷盘管上被冷却到露点以下；水分凝结并排出。$\dot m_w = \dot m_a(\omega_1 - \omega_2)$，$\dot Q_\text{出} = \dot m_a(h_1 - h_2) - \dot m_w h_w$。空气离开时接近饱和，往往太冷，相对湿度也太高，因此可能需要再热。
- **蒸发冷却**：热而干燥的空气通过湿填料；水利用空气自身的显热蒸发。过程是绝热的，所以$h$（以及湿球温度）几乎不变，而$\omega$升高、$T$下降——在炎热干燥的气候中很有效。
- 两股气流的**绝热混合**：$\dot m_{a3} = \dot m_{a1} + \dot m_{a2}$，$\omega_3$和$h_3$是按干空气质量加权的平均值，所以在图上混合状态位于连接两个进口状态的直线上。

::: example 带再热的冷却除湿盘管 {#ex-coil}
$1.2\,\mathrm{kg/s}$干空气（连同其水分），状态为$30\,^\circ\mathrm{C}$、$\phi = 60\,\%$——即[[#ex-psychro]]的状态——流过冷却盘管，以$12\,^\circ\mathrm{C}$的饱和状态离开；然后再热到$20\,^\circ\mathrm{C}$。取$p_g(12\,^\circ\mathrm{C}) = 1.403\,\mathrm{kPa}$，$p_g(20\,^\circ\mathrm{C}) = 2.339\,\mathrm{kPa}$，凝结水以$12\,^\circ\mathrm{C}$离开（$h_w = 50.4\,\mathrm{kJ/kg}$），求盘管负荷、凝结水流量、再热量和最终相对湿度。
::: solution
状态1：$\omega_1 = 0.01605$，$h_1 = 71.16\,\mathrm{kJ/kg}$（由[[#ex-psychro]]）。

状态2，$12\,^\circ\mathrm{C}$饱和：
$$
\omega_2 = 0.622\times\frac{1.403}{101.325 - 1.403} = 0.008733, \qquad h_2 = 1.005(12) + 0.008733\,(2501 + 21.8) = 34.09\,\mathrm{kJ/kg}.
$$
水平衡：$\dot m_w = 1.2\,(0.01605 - 0.008733) = 0.00878\,\mathrm{kg/s}$，即每小时$31.6\,\mathrm{kg}$凝结水。

盘管能量平衡：
$$
\dot Q_\text{盘管} = \dot m_a(h_1 - h_2) - \dot m_w h_w = 1.2\,(71.16 - 34.09) - 0.00878 \times 50.4 = 44.48 - 0.44 = 44.0\,\mathrm{kW}.
$$
其中显热部分约为$1.2 \times 1.005 \times 18 = 21.7\,\mathrm{kW}$；其余约一半是潜热——凝结水分。

在$\omega_3 = \omega_2$不变下再热：$h_3 = 1.005(20) + 0.008733\,(2501 + 36.4) = 42.26\,\mathrm{kJ/kg}$，$\dot Q_\text{再热} = 1.2\,(42.26 - 34.09) = 9.80\,\mathrm{kW}$。最终相对湿度：
$$
\phi_3 = \frac{\omega_3\,p}{(0.622 + \omega_3)\,p_g(20\,^\circ\mathrm{C})} = \frac{0.008733 \times 101.325}{0.6307 \times 2.339} = 0.600 = 60\,\%.
$$
合理性检查：对$1.06\,\mathrm{m^3/s}$的空气（$v_1 = 0.881\,\mathrm{m^3/kg}$），$44\,\mathrm{kW}$相当于$12.5$冷吨，这是常用的经验比值。把刚冷却的空气再加热是浪费的；现代系统通过热回收或以其他方式控制湿度来避免这样做。
:::
:::

## 冷负荷 {#sec-loads}

为确定设备容量，必须估算设计条件下热量和水分进入空调空间的速率——即**冷负荷**。它有**显热**部分（通过墙、屋顶和玻璃的导热；透过窗户的太阳辐射；人员、照明和设备的散热；通风用的室外空气）和**潜热**部分（人员和工艺散湿，以及室外空气比室内潮湿时通风空气带入的水分）。显热负荷与总负荷之比，即**显热比**，决定了盘管必须在露点以下多少度工作。专业计算（ASHRAE热平衡法和辐射时间序列法）考虑了建筑的热质量，它会推迟并削平峰值；下面的稳态估算是第一步。

::: example 小型办公室的冷负荷 {#ex-load}
一间$100\,\mathrm{m^2}$的办公室，室内$24\,^\circ\mathrm{C}$、$50\,\%$（含湿量$0.0093$），设计日室外空气为$32\,^\circ\mathrm{C}$，含湿量$0.0160$。由以下各项估算总冷负荷：围护结构导热，$UA = 150\,\mathrm{W/K}$；$12\,\mathrm{m^2}$玻璃接受$250\,\mathrm{W/m^2}$的太阳辐射，太阳得热系数为$0.4$；十名从事办公室工作的人员（每人显热$75\,\mathrm{W}$、潜热$55\,\mathrm{W}$，典型的表列值）；照明$10\,\mathrm{W/m^2}$；十台电脑，每台$100\,\mathrm{W}$；通风量为每人$10\,\mathrm{L/s}$室外空气（$\rho = 1.16\,\mathrm{kg/m^3}$，$h_{fg} \approx 2450\,\mathrm{kJ/kg}$）。
::: solution
显热得热：

| 来源 | 计算 | W |
|---|---|---|
| 导热 | $150 \times (32 - 24)$ | 1200 |
| 透过玻璃的太阳辐射 | $12 \times 250 \times 0.4$ | 1200 |
| 人员显热 | $10 \times 75$ | 750 |
| 照明 | $100 \times 10$ | 1000 |
| 设备 | $10 \times 100$ | 1000 |
| 通风显热 | $0.116 \times 1.005 \times 8 \times 1000$ | 933 |

通风质量流量为$0.1\,\mathrm{m^3/s} \times 1.16 = 0.116\,\mathrm{kg/s}$。显热合计：$6083\,\mathrm{W}$。

潜热得热：人员$10 \times 55 = 550\,\mathrm{W}$；通风$0.116 \times (0.0160 - 0.0093) \times 2450 \times 1000 = 1904\,\mathrm{W}$。潜热合计$2454\,\mathrm{W}$。

总负荷$= 6083 + 2454 = 8537\,\mathrm{W} \approx 8.5\,\mathrm{kW}$（$2.4$冷吨），显热比$6083/8537 = 0.71$。

合理性检查：每平方米地板面积$85\,\mathrm{W}$，在温暖气候下办公室的常见范围内。通风空气贡献了三分之一的负荷——这就是大型建筑要从排风中回收能量的原因。若用性能系数为3.5的热泵，电力需求约为$2.4\,\mathrm{kW}$。
:::

一台房间空调器的蒸发器盘管在$8\,^\circ\mathrm{C}$下运行。室内空气为$26\,^\circ\mathrm{C}$，露点$16\,^\circ\mathrm{C}$。下列哪种说法正确？
- [ ] 盘管只对空气进行显热冷却，因为盘管温度高于室内空气的湿球温度。
- [x] 盘管对空气除湿，因为其表面低于空气的露点，所以盘管负荷的一部分是潜热。
- [ ] 离开盘管的空气相对湿度低于室内空气，因为空气已被干燥。
- [ ] 把蒸发温度降到$2\,^\circ\mathrm{C}$会提高性能系数。
::: solution
凡是表面低于露点（$16\,^\circ\mathrm{C}$）的地方，水分都会凝结；因此$8\,^\circ\mathrm{C}$的盘管会除去水分，其部分能力用于潜热。离开的空气接近饱和——尽管其含湿量较低，其*相对*湿度却更高。降低蒸发温度会增大温升、降低性能系数（[[#prop-carnot-cop]]），尽管它会增强除湿。
:::
:::

::: history
在伦敦工作的美国人雅各布·**珀金斯**（Jacob Perkins）于1834年获得英国第6662号专利，内容是一台以乙醚为工质的蒸气压缩机器，具有压缩机、冷凝器、膨胀阀和蒸发器——现代循环的每一个要素——但它在商业上并不成功。费迪南·**卡雷**（Ferdinand Carré）于1859年在法国取得氨–水吸收式机器的专利，这是第一台进入工业应用的吸收式机器。1902年，威利斯·**开利**（Willis Carrier）为布鲁克林的 Sackett-Wilhelms 印刷厂设计了一套控制湿度的系统，那里的湿度变化会使纸张在两次套色之间变形；他的美国专利808,897号"空气处理装置"（"Apparatus for Treating Air"）于1906年授权，他1911年的论文《合理的湿空气公式》（"Rational psychrometric formulae"）为湿空气热力学奠定了现代基础。1930年，小托马斯·**米奇利**（Thomas Midgley Jr.）推出了二氯二氟甲烷（R-12），一种无毒、不燃的制冷剂，使家用制冷变得安全。1974年，马里奥·**莫利纳**（Mario Molina）和 F. 舍伍德·**罗兰**（F. Sherwood Rowland）在《自然》（*Nature*）上证明氯氟烃会在平流层中释放氯并破坏臭氧；1987年的**《蒙特利尔议定书》**淘汰了CFC，莫利纳、罗兰和保罗·克鲁岑（Paul Crutzen）分享了1995年诺贝尔化学奖。《蒙特利尔议定书》的**基加利修正案**于2016年10月达成，2019年1月1日生效，把该条约扩展到逐步削减HFC，以采用IPCC AR4 GWP值的CO₂当量计量。
:::

::: summary
- $\mathrm{COP}_R = Q_L/W$，$\mathrm{COP}_{HP} = Q_H/W = \mathrm{COP}_R + 1$；卡诺极限$T_L/(T_H - T_L)$和$T_H/(T_H - T_L)$取决于以开尔文计的温升。
- 蒸气压缩循环（压缩、冷凝、节流、蒸发）给出$\mathrm{COP}_R = (h_1 - h_3)/(h_2 - h_1)$，$h_4 = h_3$；计及$\eta_c$时，$h_2 = h_1 + (h_{2s} - h_1)/\eta_c$。
- 实际机组达到制冷剂温度下卡诺性能系数的约0.5–0.65；每多一开尔文温升约损失性能系数的$1/(T_H - T_L)$。
- 制冷剂的选择要在热力学性能与ODP、GWP（基加利修正案，AR4值）、毒性和可燃性之间权衡；泄漏可能主导其气候影响。
- 吸收式冷水机组用热驱动：$\mathrm{COP} \le (1 - T_0/T_G)\,T_L/(T_0 - T_L)$；实际值为0.7（单效）到1.2（双效）。
- 湿空气：每千克干空气$\omega = 0.622\,p_v/(p - p_v)$，$\phi = p_v/p_g$，$h = 1.005T + \omega(2501 + 1.82T)$。
- 空调过程由干空气、水和能量平衡得出；冷却到露点以下会除湿，凝结水带走潜热负荷。
- 冷负荷是显热加潜热；通风空气往往占总负荷的三分之一。
:::

## 习题 {#sec-exercises}

::: exercise 空调器的卡诺性能系数 {#exr-carnot-ac level=1 check="8.09"}
一台空调器的制冷剂在$10\,^\circ\mathrm{C}$下蒸发、在$45\,^\circ\mathrm{C}$下冷凝。这两个温度之间的卡诺性能系数是多少？（输入性能系数，保留两位小数。）
::: solution
$T_L = 283.15\,\mathrm{K}$，$T_H - T_L = 35\,\mathrm{K}$：
$$
\mathrm{COP}_{R,\max} = \frac{283.15}{35} = 8.09 .
$$
在这些条件下实际机组的性能系数约为4–5，卡诺比接近0.55。
:::
:::

::: exercise 由冷吨求冷水机组的性能系数 {#exr-tons level=1 check="5.60"}
一台额定制冷量为$350$冷吨的冷水机组，在该制冷量下耗电$220\,\mathrm{kW}$。它的性能系数是多少？（取$1\,\text{冷吨} = 3.517\,\mathrm{kW}$；输入性能系数，保留两位小数。）
::: solution
制冷量$= 350 \times 3.517 = 1231\,\mathrm{kW}$。$\mathrm{COP} = 1231/220 = 5.595 \approx 5.60$。美国的样本常给出其倒数，以每冷吨千瓦计：$220/350 = 0.63\,\mathrm{kW/ton}$。
:::

::: exercise 含湿量 {#exr-omega level=1 check="9.9"}
室内空气在$101.325\,\mathrm{kPa}$下为$25\,^\circ\mathrm{C}$、相对湿度$50\,\%$；$p_g(25\,^\circ\mathrm{C}) = 3.170\,\mathrm{kPa}$。求含湿量。（以克每千克干空气为单位输入$\omega$，保留一位小数。）
::: solution
$p_v = 0.5 \times 3.170 = 1.585\,\mathrm{kPa}$；由[[#eq-omega]]，
$$
\omega = 0.622\times\frac{1.585}{101.325 - 1.585} = 0.00988\,\mathrm{kg/kg} = 9.9\,\mathrm{g/kg}.
$$
:::
:::

::: exercise 实际循环的性能系数 {#exr-real-cop level=2 check="3.41"}
在一台R-134a制冷机中（IIR基准），压缩机进口焓$h_1 = 396.93\,\mathrm{kJ/kg}$，等熵出口焓$h_{2s} = 431.64\,\mathrm{kJ/kg}$，冷凝器出口焓$h_3 = 248.99\,\mathrm{kJ/kg}$。压缩机等熵效率为$0.80$。求性能系数。（输入性能系数，保留两位小数。）
::: solution
$h_2 = 396.93 + (431.64 - 396.93)/0.80 = 440.32\,\mathrm{kJ/kg}$。由[[#eq-vcr-cop]]，
$$
\mathrm{COP}_R = \frac{396.93 - 248.99}{440.32 - 396.93} = \frac{147.94}{43.39} = 3.41 .
$$
与[[#ex-real-vcr]]（$\eta_c = 0.75$，性能系数$3.20$）相比，压缩机效率提高五个百分点，性能系数提高$6.6\,\%$。
:::
:::

::: exercise 热泵的用电量 {#exr-scop level=2 check="4000"}
一栋住宅每年需要$12\,000\,\mathrm{kWh}$的热量。一台季节性能系数为$3.0$的热泵供应全部热量。它用电多少？与季节效率为$0.90$的燃气锅炉比较。（以kWh为单位输入电量。）
::: solution
$E = 12\,000/3.0 = 4000\,\mathrm{kWh}$。锅炉将燃烧$12\,000/0.90 = 13\,333\,\mathrm{kWh}$的燃气。热泵能否节约一次能源和碳排放，取决于电力的生产方式（[[energy-systems/energy-overview]]）；若电网电力来自效率为$50\,\%$的燃气电站，则需要$8000\,\mathrm{kWh}$燃气——仍然少$40\,\%$。
:::

::: exercise 蒸发冷却器 {#exr-evap level=2 check="74"}
$35\,^\circ\mathrm{C}$、$\phi = 20\,\%$、$101.325\,\mathrm{kPa}$的空气通过蒸发冷却器，以$22\,^\circ\mathrm{C}$离开。把过程视为绝热、每千克干空气的焓不变（忽略加入的水的焓）。取$p_g(35\,^\circ\mathrm{C}) = 5.629\,\mathrm{kPa}$，$p_g(22\,^\circ\mathrm{C}) = 2.645\,\mathrm{kPa}$。求出口相对湿度。（以百分数输入$\phi$，取整数。）
::: solution
进口：$p_v = 0.2 \times 5.629 = 1.126\,\mathrm{kPa}$，$\omega_1 = 0.622 \times 1.126/100.199 = 0.006989$，$h_1 = 1.005(35) + 0.006989\,(2501 + 63.7) = 53.10\,\mathrm{kJ/kg}$。

出口为$22\,^\circ\mathrm{C}$，$h_2 = h_1$：
$$
\omega_2 = \frac{53.10 - 1.005 \times 22}{2501 + 1.82 \times 22} = \frac{30.99}{2541.0} = 0.012195 .
$$
于是$p_v = \omega_2 p/(0.622 + \omega_2) = 0.012195 \times 101.325/0.634195 = 1.948\,\mathrm{kPa}$，$\phi_2 = 1.948/2.645 = 0.737$，即$74\,\%$。空气不用压缩机就冷却了$13\,\mathrm{K}$，代价是每千克空气蒸发$5.2\,\mathrm{g}$水。
:::
:::

::: exercise 室外空气与回风的混合 {#exr-mixing level=2 check="12.00"}
在一台空气处理机组中，$2.0\,\mathrm{kg/s}$（按干空气计）的室外空气（$30\,^\circ\mathrm{C}$，$\omega = 0.016046$）与$3.0\,\mathrm{kg/s}$的回风（$24\,^\circ\mathrm{C}$，$\omega = 0.009299$）绝热混合。求混合空气的含湿量，并由混合焓求其温度。（以g/kg干空气为单位输入混合含湿量，保留两位小数。）
::: solution
水平衡：$\omega_3 = (2.0 \times 0.016046 + 3.0 \times 0.009299)/5.0 = 0.011998 = 12.00\,\mathrm{g/kg}$。
由[[#eq-moist-h]]求焓：$h_1 = 71.16$，$h_2 = 1.005(24) + 0.009299\,(2544.7) = 47.78\,\mathrm{kJ/kg}$；$h_3 = (2 \times 71.16 + 3 \times 47.78)/5 = 57.13\,\mathrm{kJ/kg}$。温度：$T_3 = (h_3 - 2501\,\omega_3)/(1.005 + 1.82\,\omega_3) = (57.13 - 30.01)/1.0268 = 26.4\,^\circ\mathrm{C}$，接近质量加权平均值$26.4\,^\circ\mathrm{C}$，对于几乎线性的$h(T, \omega)$理应如此。
:::

::: exercise 推导：吸收式冷水机组的极限 {#exr-abs level=3 check="1.52"}
(a) 证明上限[[#eq-abs-cop]]等于这样一个系统的性能系数：一台在$T_G$与$T_0$之间运行的可逆热机驱动一台在$T_L$与$T_0$之间运行的可逆制冷机。(b) 对驱动热为$90\,^\circ\mathrm{C}$、放热温度为$35\,^\circ\mathrm{C}$、冷冻水为$7\,^\circ\mathrm{C}$的太阳能驱动冷水机组计算它。（输入最大性能系数，保留两位小数。）
::: solution
(a) 热机把$Q_G$转换为$W = (1 - T_0/T_G)Q_G$，其余在$T_0$下放出；制冷机用$W$提取$Q_L = W\,T_L/(T_0 - T_L)$，在$T_0$下放热。于是$Q_L/Q_G = (1 - T_0/T_G)\,T_L/(T_0 - T_L)$，即该上限。由于这一组合是可逆的（$S_\text{gen} = 0$），并具有相同的三项换热，任何装置都不可能做得更好：若有，则可以把它与反向运行的这一对组合起来违反第二定律。

(b) $T_G = 363.15\,\mathrm{K}$，$T_0 = 308.15\,\mathrm{K}$，$T_L = 280.15\,\mathrm{K}$：
$$
\mathrm{COP}_{\max} = \left(1 - \frac{308.15}{363.15}\right)\frac{280.15}{28} = 0.15145 \times 10.005 = 1.52 .
$$
在这些条件下实际的单效溴化锂冷水机组约达$0.6$–$0.7$。
:::
:::

::: exercise 推导：一开尔文温升的代价 {#exr-lift level=3 check="2"}
对于性能系数为$T_L$与$T_H$之间卡诺性能系数的恒定比例$q$的制冷机，证明冷凝温度升高$\Delta T_H$（小量）使性能系数变化的比例为$-\Delta T_H/(T_H - T_L)$，而$T_L$降低$\Delta T$使之变化$-\Delta T\,T_H/[T_L(T_H - T_L)]$。对$T_L = -5\,^\circ\mathrm{C}$、$T_H = 45\,^\circ\mathrm{C}$计算前者。（输入冷凝温度每升高一开尔文性能系数下降的百分数。）
::: solution
$\mathrm{COP} = q\,T_L/(T_H - T_L)$，所以$\ln \mathrm{COP} = \ln q + \ln T_L - \ln(T_H - T_L)$。求微分，
$$
\frac{d\,\mathrm{COP}}{\mathrm{COP}} = \frac{dT_L}{T_L} - \frac{dT_H - dT_L}{T_H - T_L}.
$$
取$dT_L = 0$：$d\mathrm{COP}/\mathrm{COP} = -dT_H/(T_H - T_L)$。取$dT_H = 0$、$dT_L = -\Delta T$：$d\mathrm{COP}/\mathrm{COP} = -\Delta T\,[1/T_L + 1/(T_H - T_L)] = -\Delta T\,T_H/[T_L(T_H - T_L)]$。

数值：$T_H - T_L = 50\,\mathrm{K}$，所以冷凝温度每升高一开尔文损失性能系数的$1/50 = 2\,\%$；蒸发温度每降低一开尔文损失$318.15/(268.15 \times 50) = 2.4\,\%$。这就是为什么换热面积——它能缩小温差——通常是提高性能系数最便宜的途径。
:::

::: exercise 设计：为老房子配热泵 {#exr-design level=3}
一栋老房子在室外$-5\,^\circ\mathrm{C}$、室内$20\,^\circ\mathrm{C}$时的设计热损失为$10\,\mathrm{kW}$，其散热器是按燃气锅炉$70\,^\circ\mathrm{C}$供水设计的。提出一个热泵方案。需要决定：空气源还是地源；是更换散热器还是改善保温，使$45$–$50\,^\circ\mathrm{C}$的供水温度即可满足；制冷剂；设计条件下的容量；并用约$0.5$的卡诺比和$15\,000\,\mathrm{kWh}$的季节热需求估算设计工况下的性能系数和全年用电量。答案不唯一。
::: solution
一种有理有据的答案。**先看供水温度：** 在$70\,^\circ\mathrm{C}$供水、室外$-5\,^\circ\mathrm{C}$时，空气源机组的冷凝温度约为$75\,^\circ\mathrm{C}$，蒸发温度约为$-12\,^\circ\mathrm{C}$：卡诺性能系数$348/87 = 4.0$，实际约$2.0$。散热器的散热量大致按$(\Delta T_\text{平均})^{1.3}$变化；散热器与室内的温差减半，散热量降到原来的约$0.5^{1.3} = 0.41$，所以加大部分散热器，并通过保温和堵漏风降低热损失（比如降到$8\,\mathrm{kW}$），就可以采用$50\,^\circ\mathrm{C}$供水。

**再看性能系数：** 冷凝$55\,^\circ\mathrm{C}$、蒸发$-12\,^\circ\mathrm{C}$：卡诺值$328/67 = 4.9$，设计工况下实际约$2.4$。在整个采暖季中室外平均温度接近$5\,^\circ\mathrm{C}$，供水温度可以按气候补偿降到$35$–$40\,^\circ\mathrm{C}$，所以接近$3$的季节性能系数是现实的；地源热泵（整个冬季蒸发温度接近$-3\,^\circ\mathrm{C}$）约可达$3.5$–$4$，但安装费用更高。

**用电量：** 每年$15\,000/3 = 5000\,\mathrm{kWh}$（空气源）或约$4000\,\mathrm{kWh}$（地源）。**制冷剂：** R-290适合较高的供水温度（排气温度适中，GWP 3），采用放在室外的整体式机组，可把可燃充注量留在室外；R-32是常见的替代方案。**容量：** $-5\,^\circ\mathrm{C}$时约$8\,\mathrm{kW}$，要核对制造商在该温度下的容量（空气源机组在寒冷时容量下降），并配一个小的电辅热或保留旧锅炉以应对少见的极端天气。讨论噪声、热水罐的安装空间，以及结合当地电价与气价之比的运行费用。
:::
