电网必须每一秒都保持供需平衡，然而最便宜的新电源——风和阳光——何时到来由天气决定，而需求的高峰出现在人们傍晚回家的时候。储能把两者解耦。它还承担与可再生能源无关的工作：让汽车携带自己的能量，在发电机启动前的几秒钟内维持数据中心运行，并让光热电站在日落后继续发电。每一种储能技术都做同样的三件事——吸收能量、保存能量、释放能量——每一步都会损失一些。

本章以能源系统工程师必须采用的方式讨论储能：先介绍表征任何储能装置的数字（能量、功率、持续时间、往返效率、寿命），然后讨论每一类的物理原理——重力（抽水蓄能）、压力（压缩空气）、动能（飞轮）、热、电化学（电池）和化学（氢）。对每一类我们都从基本原理推导其能量含量，因为推导揭示了限制它的因素：水库的水头、压缩空气的温升、转子的强度、电池电压和反应物的质量。最后的比较是关于把储能与工况相匹配，而不是评出胜者。

## 描述储能装置 {#sec-metrics}

::: definition 储能指标 {#def-metrics}
对于一个储能系统：
- **能量容量**$E$（kWh, MWh）——在额定条件下从满到空所能提供的能量；
- **功率容量**$P$（kW, MW）——最大放电速率（以及另行规定的充电速率）；
- **持续时间**$t_d = E/P$——能以额定功率输出多长时间；
- **往返效率**$\eta_{rt} = E_\text{出}/E_\text{入}$——在一个完整循环中，每吸收单位能量所提供的能量，在并网点测量；
- **放电深度**（DoD）——一个循环中所用的标称容量份额；**荷电状态**（SoC）——剩余的份额；
- **循环寿命**——在规定的放电深度下达到规定寿命终点（常为初始容量的$80\,\%$）的循环次数；
- **比能量**（Wh/kg）和**能量密度**（Wh/L），对车辆和便携设备很重要，对电网储能则不那么重要；
- **自放电**——闲置时单位时间的相对损失。
:::

对大多数技术而言，功率和能量是相互独立的设计选择。抽水蓄能电站的功率由其水轮机决定，能量由其水库决定；电池的功率由逆变器和电池化学体系决定，能量由电芯数量决定。"一个100 MW的电池"并没有说明它能持续十分钟还是十小时：总要同时给出两者，例如$100\,\mathrm{MW}/400\,\mathrm{MWh}$。

::: proposition 有内阻的储能装置的往返效率 {#prop-rte}
若充电和放电效率分别为$\eta_c$和$\eta_d$，且储能装置闲置时不损失能量，则$\eta_{rt} = \eta_c\eta_d$。对于模拟为开路电压$V_0$的理想电源串联电阻$R$的电化学电池，以相同电流$I$充入和放出相同电荷量，
$$
\eta_{rt} = \frac{V_0 - IR}{V_0 + IR},
$$ {#eq-rte-r}
它随电流增大而下降。相对速率为$1/\tau$的自放电在闲置时间$t$内使储存能量乘以$e^{-t/\tau}$。
:::

::: proof
进入储能装置的能量为$E_\text{入}$；其中份额$\eta_c$被储存；其中份额$\eta_d$被释放，所以$E_\text{出} = \eta_d\eta_c E_\text{入}$。对电池：充电时端电压必须比开路电压高出电阻压降，$V_\text{ch} = V_0 + IR$；放电时为$V_\text{dis} = V_0 - IR$。充入和放出相同的电荷$q = It$，$E_\text{入} = (V_0 + IR)q$，$E_\text{出} = (V_0 - IR)q$，得[[#eq-rte-r]]。（假设$V_0$在循环中恒定，且放出的电荷与充入相同，即库仑效率为一。）对自放电，$dE/dt = -E/\tau$积分得$E(t) = E(0)e^{-t/\tau}$。极限情形：$I \to 0$给出$\eta_{rt} \to 1$——缓慢的循环不在电阻中浪费任何能量，这是准静态过程的电化学类比。
:::

## 抽水蓄能 {#sec-pumped-hydro}

抽水蓄能电站在电力便宜或充裕时把水从下水库抽到上水库，在需要时让水流回经水轮机发电。通常由同一台可逆式水泵水轮机完成这两项工作。它技术成熟，可使用几十年，历来提供了世界电网储能容量的绝大部分。

::: proposition 上水库中储存的能量 {#prop-pumped}
体积为$V$、密度为$\rho$的水被提升到上水库，其质心位于水轮机以上平均净水头$\bar H$处，以发电效率$\eta_d$（水轮机、发电机和引水系统损失）放电时释放
$$
E = \eta_d\,\rho g V \bar H .
$$ {#eq-pumped}
充电需要$\rho gV\bar H/\eta_c$，所以$\eta_{rt} = \eta_c\eta_d$。每立方米水、每米水头储存的能量为$\rho g = 9.81\,\mathrm{kJ/(m^3\,m)} = 2.73\,\mathrm{Wh/(m^3\,m)}$。
:::

::: proof
质量为$dm$、位于水轮机以上高度$z$处的流体微元的势能为$g z\,dm$；对所储存的水积分得$gM z_G = \rho g V z_G$，其中$z_G$是其质心高度。水并不都从同一高度落下——最上层落得最远——所以正确的乘数是*平均*水头$\bar H = z_G$（减去平均尾水位和引水系统损失，这些已计入净水头）。通过水轮机的稳定流动能量守恒（[[energy-systems/wind-hydro]]）给出轴功，各效率则实现水能与电能之间的换算。取$\rho = 1000\,\mathrm{kg/m^3}$，$\rho g = 9810\,\mathrm{J/(m^3\,m)}$，即$2.725\,\mathrm{Wh}$。
:::

能量密度低——$300\,\mathrm{m}$水头下每立方米$0.82\,\mathrm{kWh}$——这就是抽水蓄能需要山地的原因：高水头使水库变小。

::: example 抽水蓄能方案的规模确定 {#ex-pumped}
一座抽水蓄能电站要提供$1.0\,\mathrm{GWh}$（例如$250\,\mathrm{MW}$持续$4\,\mathrm{h}$），平均净水头为$300\,\mathrm{m}$。发电效率为$0.90$，抽水效率为$0.88$。求 (a) 循环的水量；(b) 消落深度为$20\,\mathrm{m}$时上水库的面积；(c) 再充电所需的能量和往返效率；(d) 发电工况$250\,\mathrm{MW}$时的流量。
::: solution
(a) 由[[#eq-pumped]]，
$$
V = \frac{E}{\eta_d\rho g\bar H} = \frac{1.0\times10^{9}\times3600\,\mathrm{J}}{0.90 \times 1000 \times 9.81 \times 300} = 1.36\times10^{6}\,\mathrm{m^3}.
$$
(b) 面积$= 1.36\times10^{6}/20 = 6.8\times10^{4}\,\mathrm{m^2} = 6.8\,\mathrm{ha}$——大约边长$260\,\mathrm{m}$的方形水库。

(c) 提升这些水需要$\rho gV\bar H/\eta_c = (1.0/0.90)/0.88 = 1.26\,\mathrm{GWh}$。往返：$\eta_{rt} = 0.90 \times 0.88 = 0.79$。

(d) $Q = P/(\eta_d\rho g\bar H) = 250\times10^{6}/(0.90 \times 9810 \times 300) = 94\,\mathrm{m^3/s}$。

合理性检查：$94\,\mathrm{m^3/s}$持续$4\,\mathrm{h}$（$14\,400\,\mathrm{s}$）的水量为$1.36\times10^{6}\,\mathrm{m^3}$，与(a)相同。在$30\,\mathrm{m}$水头下，同样的方案需要十倍的水和十倍的水库面积，这就是低水头抽水蓄能很少经济可行的原因。
:::
:::

## 压缩空气 {#sec-caes}

压缩空气储能（CAES）把空气压入地下洞穴——通常是在盐丘中溶浸出的盐穴——之后再通过透平膨胀做功。核心难题是热。压缩使空气升温，若空气在储存前被冷却，这部分热就损失了；膨胀使空气降温，而冷空气做功很少。压缩过程的热力学决定了效率。

::: proposition 等温压缩功与绝热压缩功 {#prop-compression}
在稳定流动压气机中，把单位质量、气体常数为$R$的理想气体从$p_1, T_1$压缩到压力$p_2$所需的最小（可逆）功为
$$
w_\text{iso} = RT_1\ln\frac{p_2}{p_1} \quad \text{（等温）}, \qquad
w_\text{ad} = c_pT_1\left[\left(\frac{p_2}{p_1}\right)^{(k-1)/k} - 1\right] \quad \text{（可逆绝热）},
$$ {#eq-compression}
绝热情形下出口温度为$T_2 = T_1(p_2/p_1)^{(k-1)/k}$。对任何大于一的压比，$w_\text{ad} > w_\text{iso}$；其差值以热空气中的显热形式离开压气机。
:::

::: proof
对动能和势能变化可忽略的可逆稳定流动，单位质量输入功为$w = \int_1^2 v\,dp$（由第一定律$dh = \delta q + v\,dp$，以及对可逆过程$\delta q = T\,ds$和$dh = T\,ds + v\,dp$）。等温理想气体：$v = RT_1/p$，所以$w = RT_1\int dp/p = RT_1\ln(p_2/p_1)$；热量$RT_1\ln(p_2/p_1)$被排向环境，出口空气的焓等于进口空气的焓。可逆绝热：$pv^k$为常数，功等于焓升$c_p(T_2 - T_1)$，且$T_2/T_1 = (p_2/p_1)^{(k-1)/k}$，得到第二种形式。为证明$w_\text{ad} > w_\text{iso}$，令$x = \ln(p_2/p_1) > 0$，$c_p = Rk/(k-1)$：则$w_\text{ad}/(RT_1) = \tfrac{k}{k-1}\bigl(e^{x(k-1)/k} - 1\bigr) > \tfrac{k}{k-1}\cdot x\tfrac{k-1}{k} = x$，这里用了$y > 0$时$e^y - 1 > y$。
:::

x: 1, 100
y: 0, 900

:::

::: example 压缩到洞穴压力 {#ex-caes}
$1.0\,\mathrm{bar}$、$20\,^\circ\mathrm{C}$的空气被压缩到$70\,\mathrm{bar}$。取$R = 0.287\,\mathrm{kJ/(kg\,K)}$，$c_p = 1.005\,\mathrm{kJ/(kg\,K)}$，$k = 1.4$，计算 (a) 等温功；(b) 单级可逆绝热功和出口温度。(c) 解释这一差别对压缩空气储能电站的意义。
::: solution
(a) $w_\text{iso} = 0.287 \times 293.15 \times \ln 70 = 84.13 \times 4.248 = 357\,\mathrm{kJ/kg}$。

(b) $(70)^{0.2857} = 3.366$，所以$T_2 = 293.15 \times 3.366 = 987\,\mathrm{K}$（$714\,^\circ\mathrm{C}$），$w_\text{ad} = 1.005 \times 293.15 \times 2.366 = 697\,\mathrm{kJ/kg}$。

(c) 没有哪台实际压气机会输出$714\,^\circ\mathrm{C}$的空气；这类机器分级制造并带级间冷却器，以接近等温压缩。在**补燃式**电站中，级间冷却的热被排掉，空气在接近环境温度下储存，放电时燃烧天然气把它重新加热后再进入膨胀透平；这种电站一半是储能装置，一半是一台压气机已提前运行过的燃气轮机。两座商业电站——德国的亨托夫（Huntorf，1978）和阿拉巴马州的麦金托什（McIntosh，1991，增设了排气热回热器）——都按这种方式工作。**绝热式**压缩空气储能电站则把压缩热储存在储热装置中，在膨胀前还给空气，从而无需燃料；其往返效率受储热装置和机器损失的限制。

合理性检查：在绝热情形下全部功都以焓的形式留在空气中，$c_p(T_2 - T_1) = 1.005 \times 694 = 697\,\mathrm{kJ/kg}$；在等温情形下出口焓等于进口焓，全部$357\,\mathrm{kJ/kg}$都以环境温度下的热离开。把空气以热态储存，可以把多出的$340\,\mathrm{kJ/kg}$保留下来用于膨胀——如果洞穴能容纳它的话。
:::
:::

## 飞轮 {#sec-flywheels}

飞轮把动能$E = \tfrac12 I\omega^2$储存在旋转的转子中。它能在几秒钟内充放电，可承受数百万次循环，用于电能质量、不间断电源和调频——在这些工况下功率和循环寿命比持续时间更重要。限制其能量的是转子强度：离心应力随轮缘速度的平方增长。

::: proposition 飞轮的比能量 {#prop-flywheel}
密度为$\rho$、以轮缘速度$v$旋转的薄轮缘（径向厚度远小于半径的圆环）承受环向应力$\sigma = \rho v^2$。因此其单位质量动能为
$$
e = \frac{E}{m} = \tfrac12 v^2 = \frac{\sigma}{2\rho},
$$ {#eq-flywheel}
所以最大比能量由许用应力与密度之比决定。对其他转子形状，$e = K\sigma/\rho$，形状系数$K$（薄轮缘$K = 1/2$，等厚平圆盘约为$0.6$，理想等应力圆盘为$1$）。
:::

::: proof
取半径为$r$、截面积为$A$、以$\omega$旋转的薄圆环，于是$v = \omega r$。沿直径把它切开，考虑其中一半。每个长度为$r\,d\theta$的微元质量为$\rho Ar\,d\theta$，需要指向圆心的向心力$\rho Ar\,d\theta\,\omega^2 r$；其沿半圆环对称轴的分量从$0$到$\pi$积分为$\rho A\omega^2r^2\int_0^\pi \sin\theta\,d\theta = 2\rho A v^2$。这必须由两个切面上的张力$\sigma A$提供，即$2\sigma A$。因此$\sigma = \rho v^2$。全部质量以速度$v$运动，所以$E = \tfrac12 mv^2$，$e = \tfrac12 v^2 = \sigma/(2\rho)$。质量和半径都消去了：在强度极限下，飞轮的比能量只取决于材料，而与其尺寸无关。
:::

这一结果解释了高性能飞轮为什么采用碳纤维复合材料。高强度钢（$\sigma \approx 1\,\mathrm{GPa}$，$\rho = 7850\,\mathrm{kg/m^3}$）做成薄轮缘至多给出$\sigma/2\rho = 64\,\mathrm{kJ/kg}$（$18\,\mathrm{Wh/kg}$）；碳纤维轮缘（纤维方向$\sigma \approx 1.5\,\mathrm{GPa}$，$\rho \approx 1600\,\mathrm{kg/m^3}$）在不计安全系数时给出$470\,\mathrm{kJ/kg}$（$130\,\mathrm{Wh/kg}$）。计入安全系数、轮毂、轴承、真空外壳和防护后，实际系统远低于这些数值。转子爆裂时几乎瞬间释放其能量，所以防护是首要的安全要求；对旋转机械的作业只能在有适当防护和经过培训的条件下进行。

::: example 用于UPS的钢制飞轮 {#ex-flywheel}
一个质量$500\,\mathrm{kg}$、平均半径$0.50\,\mathrm{m}$的薄钢轮缘，设计工作环向应力为$600\,\mathrm{MPa}$（$\rho = 7850\,\mathrm{kg/m^3}$）。求最大轮缘速度、以rpm计的转速和储存的能量。若允许减速到一半转速，它能提供$200\,\mathrm{kW}$多长时间？
::: solution
轮缘速度：$v = \sqrt{\sigma/\rho} = \sqrt{600\times10^{6}/7850} = 276\,\mathrm{m/s}$。转速：$\omega = v/r = 553\,\mathrm{rad/s}$，即$553 \times 60/2\pi = 5280\,\mathrm{rpm}$。

全速时的能量：$E = \tfrac12 mv^2 = 0.5 \times 500 \times 276.5^2 = 1.91\times10^{7}\,\mathrm{J} = 5.3\,\mathrm{kWh}$。

减速到一半转速释放其中的$1 - (1/2)^2 = 3/4$：$1.43\times10^{7}\,\mathrm{J}$，足以在$200\,\mathrm{kW}$下维持$1.43\times10^{7}/2\times10^{5} = 72\,\mathrm{s}$（未计转换损失）。

合理性检查：在几百千瓦下维持约一分钟，正是飞轮UPS装置的作用——在备用柴油机启动之前提供过渡。比能量$5.3\,\mathrm{kWh}/500\,\mathrm{kg} = 10.6\,\mathrm{Wh/kg}$远低于电池，但飞轮可以这样工作几十万次。
:::
:::

## 储热 {#sec-thermal}

当需要的就是热，或者热将用来驱动动力循环时，储热很便宜。**显热**储热提高材料的温度：水（无压时最高$100\,^\circ\mathrm{C}$）、岩石、混凝土或熔盐；储存的能量为$Q = mc\Delta T$。**潜热**储热熔化相变材料——用于建筑供冷的冰（$334\,\mathrm{kJ/kg}$，每吨约$93\,\mathrm{kWh}$冷量），以及用于较高温度的盐和石蜡——在很窄的温度范围内提供大的容量。

聚光太阳能热发电站使用按质量约$60\,\%$硝酸钠和$40\,\%$硝酸钾的混合物（"太阳盐"），保持在冷罐约$290\,^\circ\mathrm{C}$和热罐$565\,^\circ\mathrm{C}$之间，比热容接近$1.5\,\mathrm{kJ/(kg\,K)}$。下限由盐的凝固点（约$220$–$240\,^\circ\mathrm{C}$，留有裕度）决定，上限由硝酸盐的热分解决定。

::: example 太阳能塔的熔盐储热 {#ex-salt}
一座$100\,\mathrm{MW_e}$的太阳能塔电站要在日落后靠储热运行$8\,\mathrm{h}$。其蒸汽循环效率为$40\,\%$。取$c_p = 1.5\,\mathrm{kJ/(kg\,K)}$，储罐温度为$290$和$565\,^\circ\mathrm{C}$，求所需熔盐质量。
::: solution
电能：$100\,\mathrm{MW} \times 8\,\mathrm{h} = 800\,\mathrm{MWh_e}$；所需热量$= 800/0.40 = 2000\,\mathrm{MWh_{th}} = 7.2\times10^{12}\,\mathrm{J}$。

每千克储热量：$c_p\Delta T = 1.5 \times 275 = 412.5\,\mathrm{kJ/kg}$。质量：
$$
m = \frac{7.2\times10^{12}\,\mathrm{J}}{412.5\times10^{3}\,\mathrm{J/kg}} = 1.75\times10^{7}\,\mathrm{kg} \approx 17\,500\,\mathrm{t}.
$$
合理性检查：密度接近$1800\,\mathrm{kg/m^3}$时，这约为$9700\,\mathrm{m^3}$——一个直径约$35\,\mathrm{m}$、深$10\,\mathrm{m}$的储罐，正是实际光热电站熔盐罐的规模。储热作为热的往返效率很高（通过保温层每天损失百分之几），但储存的是热而不是电：$40\,\%$的循环效率同样适用于储存的热，就像适用于来自接收器的热一样。
:::
:::

## 电池 {#sec-batteries}

电池以化学势的形式储存能量：电池反应的吉布斯自由能表现为两个电极之间的电压，电解质允许离子——但不允许电子——在电极之间通过，所以电子必须经外电路流动。

::: proposition 电池电压与理论比能量 {#prop-cell}
对于每摩尔反应转移$n$摩尔电子、吉布斯自由能变化为$\Delta G$的电池反应，可逆电池电压为
$$
E = -\frac{\Delta G}{nF},
$$ {#eq-cell}
$F = 96\,485\,\mathrm{C/mol}$。只计反应物质量$\sum M_i$（每摩尔反应）时，该电对的**理论比能量**为
$$
e_\text{th} = \frac{nFE}{\sum M_i}.
$$
电池以安时计的电荷容量乘以其平均电压就是其能量：$E_\text{电池}\,[\mathrm{Wh}] = C\,[\mathrm{Ah}] \times \bar V\,[\mathrm{V}]$。
:::

::: proof
对于定温定压下的可逆过程，从反应中可获得的最大非膨胀功等于$-\Delta G$。在电池中这一功是电功：使电荷$nF$（每摩尔反应的库仑数）通过电势差$E$所做的功为$nFE$。两者相等即得[[#eq-cell]]。用每摩尔反应消耗的反应物质量除$nFE$，得到单位反应物质量的能量，这是一个上限，因为实际电池还包含电解质、隔膜、集流体、外壳和过量的活性物质。最后，能量为$\int V\,dq$；$q$以安时（$3600\,\mathrm{C}$）计，$V$取平均值，则$E = C\bar V$，单位为瓦时。
:::

::: example 铅酸电池的理论极限 {#ex-lead-acid}
铅酸电池反应为$\mathrm{Pb + PbO_2 + 2\,H_2SO_4 \rightarrow 2\,PbSO_4 + 2\,H_2O}$，$n = 2$，$E = 2.04\,\mathrm{V}$。利用摩尔质量$207.2$（Pb）、$239.2$（$\mathrm{PbO_2}$）和$98.08\,\mathrm{g/mol}$（$\mathrm{H_2SO_4}$），求理论比能量，并与实际铅酸电池的$30$–$40\,\mathrm{Wh/kg}$比较。
::: solution
每摩尔反应的反应物质量：$207.2 + 239.2 + 2 \times 98.08 = 642.6\,\mathrm{g}$。每摩尔能量：$nFE = 2 \times 96\,485 \times 2.04 = 3.937\times10^{5}\,\mathrm{J}$。所以
$$
e_\text{th} = \frac{3.937\times10^{5}\,\mathrm{J}}{0.6426\,\mathrm{kg}} = 6.13\times10^{5}\,\mathrm{J/kg} = 170\,\mathrm{Wh/kg}.
$$
实际电池约达到其五分之一：硫酸是稀的（电解质质量大部分是水），不损伤极板就无法利用全部活性物质，而铅栅、外壳和端子增加了质量却不增加能量。

合理性检查：锂离子化学体系的电压更高（约$3.2$–$3.7\,\mathrm{V}$），反应物更轻，理论值为几百Wh/kg，实际电芯为$150$–$300\,\mathrm{Wh/kg}$——实际值与理论值之比相同。
:::
:::

**C倍率**表示相对于容量的电流：$100\,\mathrm{Ah}$的电池以$1C$放电，以$100\,\mathrm{A}$输出约一小时；以$0.25C$放电，以$25\,\mathrm{A}$输出约四小时。电网电池大多按$0.25$–$1C$设计（持续一到四小时），电动工具和赛车电池为$10C$或更高。下表给出主要化学体系电芯层面的参考数据；它们随技术进步变化很快，应以最新的规格书为准。

| 化学体系 | 电芯电压（V） | 电芯比能量（Wh/kg） | 循环寿命（至80 %） | 备注 |
|---|---|---|---|---|
| 铅酸 | 2.0 | 30–40 | 几百到约1500，取决于放电深度 | 便宜、可回收、重；备用和启动电池 |
| 锂离子NMC（镍锰钴氧化物正极） | 约3.6–3.7 | 约200–300 | 约1000–3000 | 能量最高；大多数电动汽车 |
| 锂离子LFP（磷酸铁锂正极） | 约3.2–3.3 | 约150–200 | 几千次 | 更安全、更便宜、不含钴镍；大多数新建电网储能 |

成本的下降速度超过能源领域的任何其他东西：彭博新能源财经（BloombergNEF）的年度调查报告，2025年锂离子电池包平均价格为每kWh $\$108$，比2024年低$8\,\%$。由于逆变器、箱体、消防和并网设施，电网系统每kWh的成本高于电池包。

::: warning 能量、功率与用错的效率
储能计算中反复出现三类错误。(1) 混淆功率和能量：一个$50\,\mathrm{MW}$、持续时间$1\,\mathrm{h}$的电池，若*标称*为$50\,\mathrm{MWh}$但只有$90\,\%$可用、往返效率$88\,\%$，就不能为$10\,\mathrm{MW}$的负荷供电五小时——实际提供的可用能量少于铭牌值。(2) 把往返效率用了两次，或把它用于提供的能量而不是吸收的能量：$E_\text{出} = \eta_{rt}E_\text{入}$。(3) 把止于直流端子的"往返效率"与在并网点测量的往返效率相比较，或把按低位热值计的氢效率与按高位热值计的相比较。要说明边界和基准。
:::

## 氢及其他化学储能 {#sec-hydrogen}

电可以以燃料的形式储存：电解把水分解为氢和氧，氢被压缩或液化后储存，之后由燃料电池或透平把它转换回电。其能量含量很大——$39.4\,\mathrm{kWh/kg}$（高位热值）或$33.3\,\mathrm{kWh/kg}$（低位热值）——而且氢可以在盐穴中储存数月，所以它是电池无法经济地提供的*季节性*储能的候选者。代价是往返效率低，因为每一次转换都损失能量。

::: example 经氢的往返 {#ex-hydrogen}
电解槽每生产一千克氢耗电$52\,\mathrm{kWh}$；压缩到储存压力另需$3\,\mathrm{kWh/kg}$；燃料电池以氢低位热值的$55\,\%$转换。求按高位热值计的电解槽效率和往返效率。
::: solution
电解槽：$39.4/52 = 0.758$，即按高位热值计$76\,\%$（按低位热值计$64\,\%$）。每千克输出电能：$0.55 \times 33.3 = 18.3\,\mathrm{kWh}$。输入电能：$52 + 3 = 55\,\mathrm{kWh}$。往返：
$$
\eta_{rt} = \frac{18.3}{55} = 0.333.
$$
合理性检查：三分之一是电–氢–电链条的典型值，而电池和抽水蓄能为$0.8$–$0.9$。三分之二的输入变成了热；若这些热能被利用（电解槽附近的区域供热，或燃烧氢的联合循环电站），系统效率会提高。只有在廉价的长时储存比其损失更重要的场合，用氢储能才有意义。
:::
:::

## 选择储能方式 {#sec-choosing}

各种技术最清楚地按持续时间区分，即按各自最便宜时的能量与功率之比：

| 持续时间 | 工况 | 技术 |
|---|---|---|
| 几秒到几分钟 | 调频、电能质量、穿越 | 飞轮、超级电容器、电池 |
| 约1–4小时 | 把太阳能日内转移到傍晚、峰荷容量 | 锂离子电池、抽水蓄能 |
| 约4–24小时 | 高能量的日循环、夜间风电 | 抽水蓄能、压缩空气储能、配光热电站的储热、液流电池 |
| 几天到季节 | 无风的数周、冬季供暖 | 氢及其他燃料、大型储热、水电水库 |

每kWh容量的成本主导长时储能（一年只循环几次的储能装置必须有非常便宜的能量容量）；每kW的成本和效率主导短时、频繁的循环。循环频繁时效率最重要；循环深且每天进行时循环寿命最重要。经济比较——平准化储能成本、套利价值和容量价值——采用[[energy-systems/energy-economics-emissions]]中的工具。

::: quiz
一个额定$100\,\mathrm{MW}/400\,\mathrm{MWh}$的电网电池，在并网点测得的往返效率为$88\,\%$。它从空充到满。下列哪种说法正确？
- [ ] 它能提供$400\,\mathrm{MWh}$，再充电需要$400\,\mathrm{MWh}$。
- [ ] 它能以$100\,\mathrm{MW}$输出$4.4\,\mathrm{h}$。
- [x] 它提供$400\,\mathrm{MWh}$（若额定值是可用能量），再充电时从电网取用约$455\,\mathrm{MWh}$。
- [ ] 它提供$352\,\mathrm{MWh}$，再充电需要$400\,\mathrm{MWh}$，因为效率作用于输出。
::: solution
若额定值定义为可提供的能量，则$E_\text{入} = E_\text{出}/\eta_{rt} = 400/0.88 = 455\,\mathrm{MWh}$。额定功率下的持续时间为$400/100 = 4\,\mathrm{h}$。最后一个选项把效率用在了错误的量上，除非额定值定义为充电能量——这就是必须说明额定基准的原因。
:::
:::

::: history
亚历山德罗·**伏打**（Alessandro Volta）在1800年致英国皇家学会的一封信中，描述了他用浸过盐水的布隔开的锌片和铜片堆成的电堆——第一个电化学电池。加斯东·**普朗特**（Gaston Planté）于1859–60年展示了可充电的铅酸电池，其后代至今仍在启动大多数汽车。抽水蓄能在二十世纪之交前后于瑞士和意大利投入使用，在1930年代出现可逆式水泵水轮机后得到广泛推广。第一座压缩空气储能电站——德国的亨托夫电站——于1978年投运，容量约$290\,\mathrm{MW}$，有两个盐穴；1991年阿拉巴马州$110\,\mathrm{MW}$的麦金托什电站随之投运，可连续发电约26小时。索尼于1991年将第一款商用锂离子电池推向市场，其基础是M. 斯坦利·**惠廷厄姆**（M. Stanley Whittingham）、约翰·B. **古迪纳夫**（John B. Goodenough）和**吉野彰**（Akira Yoshino）开发的嵌入式正极和碳负极，三人因锂离子电池分享了2019年诺贝尔化学奖。
:::

::: summary
- 用能量（MWh）、功率（MW）、持续时间$E/P$、往返效率、放电深度、循环寿命以及（对移动用途）比能量来表征储能装置。
- $\eta_{rt} = \eta_c\eta_d$；对电阻为$R$的电池，$\eta_{rt} = (V_0 - IR)/(V_0 + IR)$，所以快速循环要付出效率代价。
- 抽水蓄能储存$\rho gV\bar H$（每立方米、每米水头$2.73\,\mathrm{Wh}$），$\eta_{rt}$约为$0.75$–$0.8$；高水头使水库小。
- 压缩使空气升温：在洞穴压力下，等温功$RT\ln(p_2/p_1)$约为绝热功的一半；补燃式压缩空气储能燃烧燃料来补偿损失的热，绝热式则把热储存起来。
- 飞轮的比能量为$K\sigma/\rho$，与尺寸无关——强度与密度之比决定一切。
- 显热$mc\Delta T$和潜热储热对于供热和光热电站很便宜。
- 电池能量来自$\Delta G = -nFE$；实际电池只达到理论比能量的一部分。2025年锂离子电池包平均价格为每kWh $\$108$（BNEF）。
- 氢提供廉价的长时能量容量，往返效率约为三分之一。
- 按持续时间匹配技术：秒级（飞轮）、小时级（电池、抽水蓄能）、天到季节级（氢、储热、水库）。
:::

## 习题 {#sec-exercises}

::: exercise 电网电池的持续时间 {#exr-duration level=1 check="4"}
一个电池的额定值为$100\,\mathrm{MW}$和$400\,\mathrm{MWh}$。它能以额定功率输出多长时间？（以小时为单位输入持续时间。）
::: solution
$t_d = E/P = 400\,\mathrm{MWh}/100\,\mathrm{MW} = 4\,\mathrm{h}$。
:::
:::

::: exercise 电动汽车电池包的安时数 {#exr-ah level=1 check="187.5"}
一辆电动汽车的电池包为$75\,\mathrm{kWh}$，标称电压$400\,\mathrm{V}$。它的电荷容量是多少？（以Ah为单位输入容量。）
::: solution
由[[#prop-cell]]，$C = E/\bar V = 75\,000\,\mathrm{Wh}/400\,\mathrm{V} = 187.5\,\mathrm{Ah}$。以$150\,\mathrm{kW}$充电意味着约$375\,\mathrm{A}$，即$2C$倍率。
:::
:::

::: exercise 上水库中的能量 {#exr-reservoir level=1 check="1960"}
一个上水库在平均净水头$400\,\mathrm{m}$处蓄有$2.0\times10^{6}\,\mathrm{m^3}$可用水。发电效率为$0.90$。取$\rho = 1000\,\mathrm{kg/m^3}$，$g = 9.81\,\mathrm{m/s^2}$。它能提供多少电能？（以MWh为单位输入能量，保留三位有效数字。）
::: solution
由[[#eq-pumped]]，$E = 0.90 \times 1000 \times 9.81 \times 2.0\times10^{6} \times 400 = 7.063\times10^{12}\,\mathrm{J}$。除以$3.6\times10^{9}\,\mathrm{J/MWh}$得$1962\,\mathrm{MWh}$，保留三位有效数字为$1960\,\mathrm{MWh}$——约$2\,\mathrm{GWh}$。
:::
:::

::: exercise 电池中的电阻损失 {#exr-resistance level=2 check="94.1"}
一块磷酸铁锂电池的开路电压为$3.3\,\mathrm{V}$，内阻为$1.0\,\mathrm{m\Omega}$。用[[#eq-rte-r]]求它以$100\,\mathrm{A}$循环时的往返效率。（以百分数输入效率，保留一位小数。）
::: solution
$IR = 100 \times 0.001 = 0.10\,\mathrm{V}$。$\eta_{rt} = (3.3 - 0.1)/(3.3 + 0.1) = 3.2/3.4 = 0.9412$，即$94.1\,\%$。在$50\,\mathrm{A}$时为$97.0\,\%$：电流减半，电阻损失大致减半。
:::
:::

::: exercise 钢制飞轮的比能量 {#exr-flywheel level=2 check="10.6"}
一个薄钢轮缘（$\rho = 7850\,\mathrm{kg/m^3}$）的设计工作环向应力为$600\,\mathrm{MPa}$。用[[#eq-flywheel]]求其比能量。（以Wh/kg为单位输入比能量，保留三位有效数字。）
::: solution
$e = \sigma/(2\rho) = 600\times10^{6}/(2 \times 7850) = 3.822\times10^{4}\,\mathrm{J/kg}$；除以$3600\,\mathrm{J/Wh}$得$10.6\,\mathrm{Wh/kg}$——与[[#ex-flywheel]]一致。
:::
:::

::: exercise 较小太阳能塔的熔盐量 {#exr-salt level=2 check="6550"}
一座$50\,\mathrm{MW_e}$的太阳能塔需要$6\,\mathrm{h}$的储热。动力循环效率为$40\,\%$；熔盐$c_p = 1.5\,\mathrm{kJ/(kg\,K)}$，在$290$与$565\,^\circ\mathrm{C}$之间循环。需要多少熔盐？（以吨为单位输入质量，保留三位有效数字。）
::: solution
热量：$50 \times 6/0.40 = 750\,\mathrm{MWh_{th}} = 2.70\times10^{12}\,\mathrm{J}$。每千克：$1.5 \times 275 = 412.5\,\mathrm{kJ}$。质量：$2.70\times10^{12}/4.125\times10^{5} = 6.545\times10^{6}\,\mathrm{kg}$，即$6550\,\mathrm{t}$。
:::
:::

::: exercise 等温压缩功 {#exr-iso level=2 check="329"}
$1.0\,\mathrm{bar}$、$20\,^\circ\mathrm{C}$的空气（$R = 0.287\,\mathrm{kJ/(kg\,K)}$）被等温可逆地压缩到$50\,\mathrm{bar}$。求每千克的功。（以kJ/kg为单位输入功，保留三位有效数字。）
::: solution
$w = RT\ln(p_2/p_1) = 0.287 \times 293.15 \times \ln 50 = 84.13 \times 3.912 = 329\,\mathrm{kJ/kg}$。同样的压缩若以单级绝热方式完成，需要$1.005 \times 293.15 \times (50^{0.2857} - 1) = 606\,\mathrm{kJ/kg}$。
:::
:::

::: exercise 推导：压缩空气洞穴的㶲 {#exr-exergy level=3 check="1.90"}
(a) 一个容积为$V$的刚性洞穴中装有压力为$p$、处于环境温度$T_0$的空气（理想气体）；环境为$p_0, T_0$。证明让空气与环境达到平衡所能获得的最大功（其㶲（exergy），[[thermodynamics/exergy]]）为
$$
X = pV\left[\ln\frac{p}{p_0} - 1 + \frac{p_0}{p}\right].
$$
(b) 对$V = 3.0\times10^{5}\,\mathrm{m^3}$、$p = 70\,\mathrm{bar}$、$p_0 = 1.0\,\mathrm{bar}$计算它。（以GWh为单位输入$X$，保留三位有效数字。）
::: solution
(a) 闭口系统的㶲为$X = (U - U_0) + p_0(V_\text{gas} - V_0) - T_0(S - S_0)$，下标0表示同样质量$m$处于$p_0, T_0$时的状态。对同温的理想气体，$U = U_0$；$S - S_0 = -mR\ln(p/p_0)$；气体在环境条件下所占的体积为$V_0 = Vp/p_0$。所以
$$
X = p_0\left(V - \frac{pV}{p_0}\right) + T_0 mR\ln\frac{p}{p_0} = pV\ln\frac{p}{p_0} - (p - p_0)V,
$$
这里用了$mRT_0 = pV$。提出$pV$即得结果。它是等温膨胀功$pV\ln(p/p_0)$减去膨胀的气体推开大气所必须付出的功$p_0(V_0 - V) = (p - p_0)V$。

(b) $pV = 7.0\times10^{6} \times 3.0\times10^{5} = 2.1\times10^{12}\,\mathrm{J}$；括号$= \ln 70 - 1 + 1/70 = 4.2485 - 1 + 0.0143 = 3.2628$。$X = 6.852\times10^{12}\,\mathrm{J} = 1.90\,\mathrm{GWh}$。实际电站在两个压力之间循环洞穴（以保持洞穴稳定，并使透平进口压力可行），只利用其中一部分。
:::
:::

::: exercise 用透平完成的氢往返 {#exr-h2 level=3 check="27.2"}
重做[[#ex-hydrogen]]，但用按低位热值计效率为$45\,\%$的燃气–蒸汽联合循环机组把氢转换回电，并假设电解槽需要$55\,\mathrm{kWh/kg}$（含压缩）。求往返效率。（以百分数输入，保留一位小数。）
::: solution
每千克输出电能：$0.45 \times 33.3 = 14.985\,\mathrm{kWh}$。往返：$14.985/55 = 0.2725$，即$27.2\,\%$。大型氢透平通常用于少见的、长时间的低风期，那时效率不如在洞穴中把氢储存数月的极低成本重要。
:::

::: exercise 设计：为光伏电站提供稳定出力 {#exr-design level=3}
一座$50\,\mathrm{MW}$光伏电站在晴朗的夏日从06:00到20:00的出力大致为半个正弦波，峰值$45\,\mathrm{MW}$。电网调度希望每天18:00到23:00有稳定的$20\,\mathrm{MW}$。确定一个储能系统：技术、功率、能量、放电深度和预期循环寿命；估算必须转用于充电的太阳能电量；并说明阴沉的冬日会怎样。全程使用数字。答案不唯一。
::: solution
一种有理有据的答案。需从储能提供的能量：18:00到20:00光伏出力本身在下降（14 h的半正弦在18:00给出$45\sin(\pi \times 12/14) = 19.5\,\mathrm{MW}$，20:00为$0$），所以储能必须在18–20时补充，并在20到23时提供全部$20\,\mathrm{MW}$。仔细估算：20:00之后约$20 \times 3 = 60\,\mathrm{MWh}$，加上18–20时约$20$，共提供约$80\,\mathrm{MWh}$。按$90\,\%$可用放电深度，规定约$90\,\mathrm{MWh}$标称容量和$20$–$25\,\mathrm{MW}$逆变器功率：四小时的LFP电池合适（并网点$20\,\mathrm{MW}/90\,\mathrm{MWh}$）。按$88\,\%$往返效率的充电能量：$80/0.88 = 91\,\mathrm{MWh}$光伏电量，约为当天出力$\int 45\sin(\pi t/14)\,dt = 45 \times 28/\pi = 401\,\mathrm{MWh}$的五分之一。每天一个循环、持续15年约为$5500$次循环——在这一放电深度下处于LFP的范围内，但应为10–15年后更换或扩容电芯编列预算。阴沉的冬日电站可能只发$100\,\mathrm{MWh}$或更少；给电池充电后白天可送出的电量所剩无几，若不从电网充电或没有备用电站，傍晚的稳定出力可能无法兑现。只有附近存在有水头的场址时才适合抽水蓄能；对于日循环，氢的效率太低了。
