一台大型燃气轮机就是一台中间生着火的空气泵。前端的压气机每秒吸入约$600\ \mathrm{kg}$空气，把它压缩到约二十个大气压；天然气在这些空气中定压燃烧，直到燃气温度高于它即将遇到的叶片的熔点；后面的涡轮从膨胀中提取足够的功，既驱动压气机，*又*驱动一台几百兆瓦的发电机。从尾部排出的仍是一股$550$–$650\ \mathrm{^\circ C}$的狂风般的燃气，携带着燃料一半以上的能量。简单循环燃气轮机把它丢掉；**联合循环**让它通过余热锅炉和汽轮机，从而把燃料热值的约$60\ \%$转换为电——这是所有大型热力电站中最好的数字。如果把排气余热作为工艺蒸汽或区域供热出售，同一台机器就成为**热电联产**电站，能利用其燃料的$80\ \%$或更多。

本章把[[thermodynamics/power-cycles]]中的理想布雷顿循环变成对实际机器的分析。首先加入部件效率，发现压比此时有*两个*不同的最优值，一个对应比功，一个对应效率。然后看为什么燃气轮机在炎热的日子里会损失功率、进气冷却如何把它找回来，为什么涡轮进口温度受叶片冷却而不是燃料的限制，以及如何由节点温差来确定余热锅炉的尺寸。最后推导联合循环效率公式和评价热电联产的指标。同一循环的航空发动机版本见[[propulsion/gas-turbine-cycles]]；蒸汽侧在[[energy-systems/steam-power-plants]]中有完整讨论。

全章的第一定律采用 Çengel & Boles 的进/出约定：$\dot W_\mathrm{net} = \dot W_t - \dot W_c$是输出的净轴功率，每个热和功的符号都是正的大小。公式中的温度单位为开尔文。

## 作为电站的燃气轮机 {#sec-gt-plant}

市场上有两类机器。**重型（工业）燃气轮机**是为电站制造的：单轴，以电网频率运行（50 Hz为3000 rpm，60 Hz为3600 rpm），与发电机直接相连，机壳厚重，出力从几十兆瓦到最大机组的$500\ \mathrm{MW}$以上。**航改型燃气轮机**由飞机发动机改型而来：重量轻、启动快、压比较高，出力从几兆瓦到约$100\ \mathrm{MW}$，用于调峰、海上平台和管道增压。两者都以**ISO参考条件**——$15\ \mathrm{^\circ C}$、$101.325\ \mathrm{kPa}$和$60\ \%$相对湿度——标定额定值，而且在空气炎热或稀薄时都会损失出力——这一点我们将予以定量化。

::: definition 热效率、热耗率和比功 {#def-heat-rate}
对于以质量流量$\dot m_f$燃烧低位热值为$\mathrm{LHV}$的燃料、输出净电功率$\dot W_e$的电站：

- **热效率**为$\eta = \dot W_e / (\dot m_f\,\mathrm{LHV})$；
- **热耗率**是单位电量所需的燃料能量，
$$
\mathrm{HR} = \frac{\dot m_f\,\mathrm{LHV}}{\dot W_e} = \frac{3600\ \mathrm{kJ/kWh}}{\eta},
$$ {#eq-heat-rate}
  因为$1\ \mathrm{kWh} = 3600\ \mathrm{kJ}$；热耗率越低，电站越好；
- **比功**是每单位质量吸入空气的净功，$w_\mathrm{net} = \dot W_\mathrm{net}/\dot m_a$，单位$\mathrm{kJ/kg}$。它决定了机器的*尺寸*：对于给定功率，$w_\mathrm{net}$越高，空气流量越小，涡轮也越小、越便宜。
:::

燃气轮机的效率和热耗率按惯例以**低位**热值给出，因为排气中的水蒸气从不冷凝。美国电力公司的统计常以$\mathrm{Btu/kWh}$给出基于**高位**热值的热耗率（$3412\ \mathrm{Btu/kWh}$对应$\eta = 1$）。对天然气，高位热值比低位热值约大$11\ \%$，所以同一座电站按高位热值计的效率看上去要低大约四到六个百分点。始终要问清一个数字用的是哪种基准。

## 实际布雷顿循环 {#sec-real-brayton}

在理想循环中，效率$1 - r_p^{-(k-1)/k}$只取决于压比$r_p$，并随之不断提高。实际的压气机和涡轮打破了这幅简单的图景，因为压气机功很大——约为涡轮功的一半——而压气机中的每一点不完善都要付出两次代价：一次是额外的输入功，另一次是压气机出口温度更高，留给燃料的余地更小。

推导中采用**冷空气标准**：空气为理想气体，$c_p = 1.005\ \mathrm{kJ/(kg\,K)}$和$k = 1.4$为常数，忽略燃料质量，忽略燃烧室和管道中的压力损失。引入温比和压缩的等熵温比，
$$
\tau = \frac{T_3}{T_1}, \qquad x = r_p^{(k-1)/k},
$$
其中$T_1$是压气机进口温度，$T_3$是涡轮进口温度。压气机的等熵效率为$\eta_c$，涡轮为$\eta_t$。

::: proposition 实际简单循环的比功和效率 {#prop-real-brayton}
在冷空气标准下，部件等熵效率为$\eta_c$和$\eta_t$时，
$$
w_\mathrm{net} = c_p T_1 \left[ \tau\,\eta_t \left(1 - \frac{1}{x}\right) - \frac{x - 1}{\eta_c} \right],
$$ {#eq-wnet-real}
$$
\eta = \frac{\tau\,\eta_t \left(1 - 1/x\right) - (x - 1)/\eta_c}{\tau - 1 - (x - 1)/\eta_c}.
$$ {#eq-eta-real}
当$\eta_c = \eta_t = 1$时，效率退化为理想值$1 - 1/x$。
:::

::: proof
各部件中均为稳定流动，动能和势能变化可忽略。从$T_1$出发按压比$r_p$等熵压缩，终点为$T_{2s} = T_1 x$。由定义$\eta_c = (h_{2s} - h_1)/(h_2 - h_1)$及$c_p$恒定得
$$
T_2 = T_1 + \frac{T_1 (x - 1)}{\eta_c}, \qquad w_c = c_p (T_2 - T_1) = c_p T_1 \frac{x - 1}{\eta_c}.
$$
无压力损失时涡轮按同一压比膨胀，所以$T_{4s} = T_3/x$，由$\eta_t = (h_3 - h_4)/(h_3 - h_{4s})$得
$$
w_t = c_p (T_3 - T_4) = \eta_t c_p T_3 \left(1 - \frac{1}{x}\right) = c_p T_1\,\tau\,\eta_t \left(1 - \frac{1}{x}\right).
$$
两者相减即得[[#eq-wnet-real]]。燃烧室中加入的热量为$q_\mathrm{in} = c_p (T_3 - T_2) = c_p T_1 \left[\tau - 1 - (x - 1)/\eta_c\right]$，而$\eta = w_\mathrm{net}/q_\mathrm{in}$即[[#eq-eta-real]]。令$\eta_c = \eta_t = 1$，分子变为$\tau(1 - 1/x) - (x - 1) = (x - 1)(\tau/x - 1)$，分母变为$\tau - x = x(\tau/x - 1)$，其比为$(x - 1)/x = 1 - 1/x$。
:::

随着$x$增大，[[#eq-wnet-real]]的两部分向相反方向变化：涡轮项向$\tau\eta_t$增长并趋于饱和，而压气机项线性地无限增长。因此净功有一个最大值，而超过某一压比后，涡轮甚至无法驱动它自己的压气机。

::: proposition 两个最优压比 {#prop-optimum-ratio}
在[[#prop-real-brayton]]的假设下：

1. 比功在
$$
x_w = \sqrt{\eta_c\,\eta_t\,\tau}, \qquad r_{p,w} = \left(\eta_c \eta_t \tau\right)^{k/[2(k-1)]}
$$ {#eq-xopt-work}
时最大。
2. 效率在方程
$$
b(a - c)\,x^2 - 2ab\,x + a(b + c) = 0, \qquad a = \tau\eta_t,\ \ b = \frac{1}{\eta_c},\ \ c = \tau - 1
$$ {#eq-xopt-eta}
的根$x_\eta > 1$处最大，即$x_\eta = \dfrac{ab - \sqrt{a^2b^2 - ab(a - c)(b + c)}}{b(a - c)}$；对实际的部件效率，它总是大于$x_w$。
:::

::: proof
(1) 将[[#eq-wnet-real]]对$x$求导：$\mathrm{d}w_\mathrm{net}/\mathrm{d}x = c_p T_1 \left[\tau\eta_t / x^2 - 1/\eta_c\right]$，它在$x^2 = \eta_c\eta_t\tau$处为零；二阶导数$-2c_pT_1\tau\eta_t/x^3$为负，所以这是极大值。用$r_p = x^{k/(k-1)}$换算即得[[#eq-xopt-work]]。对理想循环，这就是熟知的$r_{p,w} = \tau^{k/[2(k-1)]}$，此时$T_2 = T_4$。

(2) 写$\eta = N/D$，其中$N = a(1 - 1/x) - b(x - 1)$，$D = c - b(x - 1)$，于是$N' = a/x^2 - b$，$D' = -b$。条件$\eta' = 0$即$N'D = ND'$：
$$
\left(\frac{a}{x^2} - b\right)\bigl(c - b(x - 1)\bigr) + b\left(a - \frac{a}{x} - b(x - 1)\right) = 0.
$$
$\pm b^2(x - 1)$项相消；其余各项乘以$x^2$并按$x$的幂次整理，得$(ab - bc)x^2 - 2ab\,x + (ac + ab) = 0$，即[[#eq-xopt-eta]]。两个根中，较大的一个位于$D = 0$之点（压气机出口已比$T_3$还热）之外，没有物理意义；较小的一个是极大值点。$x_\eta > x_w$的理由是：在$x_w$处功取驻值，$\mathrm{d}w/\mathrm{d}x = 0$，而$q_\mathrm{in}$仍随$x$减小，所以那里$\mathrm{d}\eta/\mathrm{d}x = -w\,\mathrm{d}q_\mathrm{in}/\mathrm{d}x / q_\mathrm{in}^2 > 0$：功达到峰值时效率仍在上升。
:::

工程上的后果是设计者必须作出选择。压比接近$r_{p,w}$时，每千克空气的功率最大——机器小；压比接近$r_{p,\eta}$时，每千瓦时的燃料最少。在两者之间效率曲线非常平坦，所以用于联合循环的重型机组靠近功的最优值（排气更热也适合蒸汽循环），而必须单独高效运行的航改型机组则采用更高的压比。

::: example $T_3 = 1600\ \mathrm{K}$的实际简单循环 {#ex-real-cycle}
一台燃气轮机吸入$T_1 = 288\ \mathrm{K}$的空气，涡轮进口温度$T_3 = 1600\ \mathrm{K}$，压比$20$，$\eta_c = 0.88$，$\eta_t = 0.90$。用冷空气标准求比功、效率和反功比，与理想循环比较，并求两个最优压比。
::: solution
**比值。** $\tau = 1600/288 = 5.556$，$x = 20^{0.4/1.4} = 20^{0.2857} = 2.3535$。

**温度。**
$$
T_2 = 288 + \frac{288 \times 1.3535}{0.88} = 731.0\ \mathrm{K}, \qquad T_4 = 1600\left[1 - 0.90\left(1 - \frac{1}{2.3535}\right)\right] = 771.8\ \mathrm{K}.
$$
**功和热。**
$$
w_c = 1.005 \times (731.0 - 288) = 445.2\ \mathrm{kJ/kg}, \qquad w_t = 1.005 \times (1600 - 771.8) = 832.3\ \mathrm{kJ/kg},
$$
$$
w_\mathrm{net} = 387.1\ \mathrm{kJ/kg}, \qquad q_\mathrm{in} = 1.005 \times (1600 - 731.0) = 873.4\ \mathrm{kJ/kg}, \qquad \eta = \frac{387.1}{873.4} = 0.443.
$$
反功比为$w_c/w_t = 445.2/832.3 = 0.535$：涡轮功的一半以上又回到了压气机中。

**与理想循环比较。** 同一$r_p$下的理想循环$\eta = 1 - 1/2.3535 = 0.575$，$w_\mathrm{net} = 533.0\ \mathrm{kJ/kg}$。$10$–$12\ \%$的部件损失使效率损失了$13$个百分点、功损失了$27\ \%$，因为它们作用在很大的总功上，而不是作用在很小的净功上。

**最优值。** 由[[#eq-xopt-work]]，$x_w = \sqrt{0.88 \times 0.90 \times 5.556} = 2.098$，所以$r_{p,w} = 2.098^{3.5} = 13.4$，此时$w_\mathrm{max} = 396.3\ \mathrm{kJ/kg}$，$\eta = 0.414$。对于[[#eq-xopt-eta]]，$a = 5.000$，$b = 1.1364$，$c = 4.556$，二次方程$0.5051x^2 - 11.364x + 28.46 = 0$的物理根为$x_\eta = 2.871$，即$r_{p,\eta} = 40.1$，此时$\eta = 0.466$，$w_\mathrm{net} = 327.8\ \mathrm{kJ/kg}$。

**合理性检查。** 从$r_p = 20$到$40$，效率只提高$2.3$个百分点，比功却损失$15\ \%$——这正是效率曲线平坦的体现。所有效率都低于卡诺值$1 - 288/1600 = 0.82$。
:::

::: example ISO条件下的重型燃气轮机 {#ex-heavy-duty}
一台重型燃气轮机吸入$\dot m_a = 600\ \mathrm{kg/s}$、$T_1 = 288.15\ \mathrm{K}$、$p_1 = 101.325\ \mathrm{kPa}$的空气。压比$20$；$\eta_c = 0.88$，$\eta_t = 0.90$；涡轮进口温度$1600\ \mathrm{K}$；燃烧室损失其进口压力的$4\ \%$；发电机效率$0.985$。空气取$c_{pa} = 1.005\ \mathrm{kJ/(kg\,K)}$，$k_a = 1.4$，燃气取$c_{pg} = 1.15\ \mathrm{kJ/(kg\,K)}$，$k_g = 1.333$；燃料为天然气，$\mathrm{LHV} = 50\ \mathrm{MJ/kg}$。求燃料流量、电功率、效率、热耗率和排气状态。
::: solution
**压气机。** $T_{2s} = 288.15 \times 20^{0.2857} = 678.2\ \mathrm{K}$，$T_2 = 288.15 + 390.0/0.88 = 731.4\ \mathrm{K}$，所以
$$
\dot W_c = 600 \times 1.005 \times (731.4 - 288.15) = 267.3\ \mathrm{MW}.
$$
**燃烧室。** 焓的基准取在$T_1$（低位热值的定义温度在$25\ \mathrm{^\circ C}$附近；这里的差别可以忽略）。能量平衡$\dot m_f\,\mathrm{LHV} + \dot m_a c_{pa}(T_2 - T_1) = (\dot m_a + \dot m_f) c_{pg} (T_3 - T_1)$给出
$$
\dot m_f = \frac{\dot m_a\left[c_{pg}(T_3 - T_1) - c_{pa}(T_2 - T_1)\right]}{\mathrm{LHV} - c_{pg}(T_3 - T_1)} = \frac{600\,(1.15 \times 1311.85 - 445.5)}{50\,000 - 1508.6} = 13.16\ \mathrm{kg/s},
$$
燃料空气比为$0.0219$——约为甲烷化学计量比的$37\ \%$，其余空气用来把$T_3$压低。

**涡轮。** 压比$20 \times 0.96 = 19.2$；$T_{4s} = 1600/19.2^{0.333/1.333} = 764.8\ \mathrm{K}$；$T_4 = 1600 - 0.90 \times 835.2 = 848.3\ \mathrm{K}$（$575.2\ \mathrm{^\circ C}$）。
$$
\dot W_t = 613.16 \times 1.15 \times (1600 - 848.3) = 530.1\ \mathrm{MW}.
$$
**出力和效率。** 轴功率$530.1 - 267.3 = 262.8\ \mathrm{MW}$；电功率$\dot W_e = 0.985 \times 262.8 = 258.9\ \mathrm{MW}$。燃料功率$13.16 \times 50 = 657.8\ \mathrm{MW}$，所以
$$
\eta = \frac{258.9}{657.8} = 0.394, \qquad \mathrm{HR} = \frac{3600}{0.3935} = 9148\ \mathrm{kJ/kWh}.
$$
**排气。** $613.2\ \mathrm{kg/s}$，$575\ \mathrm{^\circ C}$，相对于环境携带$613.16 \times 1.15 \times (848.3 - 288.15) = 395.0\ \mathrm{MW}$——恰好等于燃料功率减去轴功率，正如第一定律所要求的。

**合理性检查。** 结果——约$260\ \mathrm{MW}$、$39\ \%$、排气$575\ \mathrm{^\circ C}$——对现代重型机组来说量级是对的（大型F级和H级机组公布的ISO额定效率大致在$38$–$44\ \%$范围内）。该模型对效率略为悲观，因为它只有一个涡轮进口温度，也没有显式的冷却气流；它是下面联合循环各例题的输入。

## 环境温度与进气冷却 {#sec-ambient}

燃气轮机的压气机在一阶近似下是一台*容积*流量恒定的机器：在固定转速下，它的叶片每秒输送固定体积的空气。在炎热的日子里这些空气的质量较小，于是涡轮——其功率与流过的质量成正比——出力下降，而压气机的功却丝毫不减。这就是为什么燃气轮机电站恰恰在空调需求最高的时候损失出力。

::: proposition 出力随环境温度的变化 {#prop-ambient}
设压气机在进口处输送固定的容积流量$\dot V_1$，压比、涡轮进口温度和部件效率固定，忽略燃料质量。则压气机功率与进口温度$T_1$无关，涡轮功率与$T_1$成反比，且
$$
\dot W_\mathrm{net}(T_1) = \frac{A}{T_1} - B, \qquad \frac{1}{\dot W_\mathrm{net}}\frac{\mathrm{d}\dot W_\mathrm{net}}{\mathrm{d}T_1} = -\frac{1}{T_1\,(1 - \mathrm{bwr})},
$$ {#eq-ambient}
其中$\mathrm{bwr} = \dot W_c/\dot W_t$是反功比。
:::

::: proof
理想气体的质量流量为$\dot m = p_1 \dot V_1/(R T_1)$。压气机功率为$\dot W_c = \dot m\,c_p T_1 (x - 1)/\eta_c = p_1 \dot V_1 c_p (x - 1)/(R\,\eta_c)$，其中$T_1$已约去：炎热的日子里空气少了，但每千克空气需要的功按比例增加了。涡轮功率为$\dot W_t = \dot m\,c_p T_3 \eta_t (1 - 1/x) = A/T_1$，其中$A = p_1\dot V_1 c_p T_3\eta_t(1 - 1/x)/R$与$T_1$无关，因为$T_3$是固定的。因此$\dot W_\mathrm{net} = A/T_1 - B$，$B = \dot W_c$。求导得$\mathrm{d}\dot W_\mathrm{net}/\mathrm{d}T_1 = -A/T_1^2 = -\dot W_t/T_1$，再除以$\dot W_\mathrm{net} = \dot W_t(1 - \mathrm{bwr})$即得[[#eq-ambient]]。
:::

取$\mathrm{bwr} \approx 0.5$、$T_1 = 288\ \mathrm{K}$，[[#eq-ambient]]预测每开尔文损失出力$1/(288 \times 0.5) \approx 0.7\ \%$——这正是制造商修正曲线所给的数字，视机组及其控制方式不同，约为每开尔文$0.5$到$0.9\ \%$。高反功比是放大器：$\mathrm{bwr} = 0.5$的机器对环境温度的敏感程度是压气机不耗功的机器的两倍。

补救办法是冷却进气。**蒸发冷却器**（湿膜式）或**喷雾**系统向进气中喷水，水蒸发使空气冷却，趋向其湿球温度；冷却器的**效能**为$\varepsilon_\mathrm{evap} = (T_\mathrm{db} - T_\mathrm{out})/(T_\mathrm{db} - T_\mathrm{wb})$，湿膜式冷却器通常为$0.85$–$0.95$。它便宜，在炎热干燥的气候中效果最好。用制冷装置进行**进气冷冻**（[[energy-systems/refrigeration-hvac]]）可以冷却到湿球温度以下，代价是冷水机组的功率和投资。

::: example 炎热的一天，以及蒸发冷却器 {#ex-hot-day}
[[#ex-heavy-duty]]的机组在海平面、$35\ \mathrm{^\circ C}$、$30\ \%$相对湿度下运行。(a) 假设进口容积流量相同，求其出力。(b) 安装了效能为$0.90$的蒸发冷却器；环境空气的湿球温度为$21.5\ \mathrm{^\circ C}$（由焓湿图或 CoolProp 的湿空气模型查得）。求冷却器运行时的出力。
::: solution
**(a)** 质量流量按$1/T_1$变化：$\dot m_a = 600 \times 288.15/308.15 = 561.1\ \mathrm{kg/s}$。以$T_1 = 308.15\ \mathrm{K}$重复[[#ex-heavy-duty]]：$T_2 = 782.1\ \mathrm{K}$，压气机功率仍为$267.3\ \mathrm{MW}$（正如[[#prop-ambient]]所说）。燃料流量降至$11.67\ \mathrm{kg/s}$，涡轮（$T_3$相同，出口温度同为$848.3\ \mathrm{K}$）给出$572.7 \times 1.15 \times 751.7 = 495.1\ \mathrm{MW}$，于是
$$
\dot W_e = 0.985 \times (495.1 - 267.3) = 224.4\ \mathrm{MW},
$$
比ISO额定值低$13.3\ \%$，即每开尔文$0.66\ \%$。效率只从$39.4\ \%$降到$38.5\ \%$：炎热的日子主要是容量问题。

**(b)** 冷却器出口$T_\mathrm{out} = 35 - 0.90 \times (35 - 21.5) = 22.85\ \mathrm{^\circ C}$，即$296.0\ \mathrm{K}$。于是$\dot m_a = 600 \times 288.15/296.0 = 584.1\ \mathrm{kg/s}$，涡轮给出$515.8\ \mathrm{MW}$，
$$
\dot W_e = 0.985 \times (515.8 - 267.3) = 244.8\ \mathrm{MW},
$$
比不冷却时增加$20.4\ \mathrm{MW}$（$9.1\ \%$）。含湿量从$0.0106$提高到$0.0157$，需要蒸发约$3.0\ \mathrm{kg/s}$的水，约每小时$11\ \mathrm{m^3}$。

**合理性检查。** 在ISO点用[[#eq-ambient]]线性化（$\mathrm{bwr} = 267.3/530.1 = 0.504$）：每开尔文$1/(288.15 \times 0.496) = 0.70\ \%$，而精确模型在$20\ \mathrm{K}$范围内给出每开尔文$0.66\ \%$——两者一致，因为曲线$A/T_1$随$T_1$升高而变平。

::: warning 环境修正需要用开尔文和正确的流量假设
常见的错误有两个。第一，用$288/35$而不是$288.15/308.15$来缩放质量流量：理想气体的密度与*热力学*温度成反比，用摄氏温度会得出荒谬的结果。第二，假设压气机功率像涡轮功率一样随质量流量变化。在容积流量固定时，压气机每千克的功与$T_1$成比例增加，恰好抵消质量流量的减少，所以压气机功率保持不变——全部损失都落在净出力上。实际机组还有可调进口导叶和控制规律，会改变细节，所以现场性能总是取自制造商的修正曲线；这个模型解释了这些曲线的形状。
:::

## 涡轮进口温度与叶片冷却 {#sec-cooling}

[[#ex-real-cycle]]表明，功和效率都随$\tau = T_3/T_1$提高。因此涡轮进口温度是燃气轮机设计中最有价值的数字，而这个行业的历史在很大程度上就是提高这一温度的历史。限制不在于燃料——甲烷的化学计量火焰温度会超过$2200\ \mathrm{K}$——而在于第一级导叶和动叶。镍基单晶高温合金在约$1000$–$1100\ \mathrm{^\circ C}$以上就失去强度，远低于现代机组的燃气温度。叶片之所以能存活，全靠**冷却**：从压气机引出的空气流过内部的蛇形通道，冲击前缘内壁，再从成排的小孔中流出，在外表面上形成一层保护**气膜**；同时，零点几毫米厚的陶瓷**热障涂层**（通常是氧化钇稳定的氧化锆）再提供一段温降。

"涡轮进口温度"这个术语用得很随意，而不同说法之间可相差$100\ \mathrm{K}$或更多：**燃烧室出口温度**；燃气被第一级导叶冷却空气稀释之后的**转子进口温度**或**燃烧温度**；以及**ISO 2314参考温度**，这是一个假想的混合温度，按所有冷却空气都在涡轮之前混入来计算。要同类相比。作为有日期的技术水平实例，三菱重工在其《技术评论》（*Technical Review*）中报告，其M501J机组自2011年起在高砂进行示范运行，首次达到$1600\ \mathrm{^\circ C}$的涡轮进口温度；截至2025年，各主要制造商的H级和J级机组都运行在这一水平附近或更高。

::: definition 冷却效率 {#def-cooling-eff}
对于燃气温度（相对于叶片）为$T_g$、冷却剂供给温度为$T_c$、金属温度为$T_m$的冷却叶片，**综合冷却效率**为
$$
\phi = \frac{T_g - T_m}{T_g - T_c}, \qquad 0 \le \phi < 1.
$$
$\phi = 0$表示未冷却、处于燃气温度的叶片；$\phi \to 1$将使金属温度降到冷却剂温度。仅靠对流冷却可达$\phi \approx 0.5$；气膜冷却与热障涂层结合可达$0.6$–$0.7$。
:::

冷却不是免费的。冷却剂是绕过燃烧室的压缩空气，它吸收了压气机功，却没有被燃料加热；随后它混入高温燃气，降低其温度和压力，而气膜冷却还会破坏叶片的气动性能。在最先进的机组中，五分之一或更多的压气机流量用于冷却和密封。提高燃烧温度的收益，是较大的$\tau$与较大的冷却代价相抵后的净值，超过某一温度后，额外的冷却空气会吃掉全部收益——这就是人们不断寻求更好的合金、涂层，以及在某些设计中采用闭式蒸汽冷却（把热量返回蒸汽循环）的原因。

::: example 第一级叶片需要冷却到什么程度？ {#ex-blade-cooling}
在[[#ex-heavy-duty]]的机组中，相对于第一级动叶的燃气温度为$1600\ \mathrm{^\circ C}$，冷却剂是压气机出口空气，$T_2 = 731.4\ \mathrm{K}$（$458.3\ \mathrm{^\circ C}$）。叶片合金的金属温度限值为$900\ \mathrm{^\circ C}$。(a) 需要多大的冷却效率？(b) 若冷却空气先在外部冷却器中冷却到$250\ \mathrm{^\circ C}$，需要多大的冷却效率？
::: solution
**(a)** 以开尔文计的温差等于以摄氏度计的温差：
$$
\phi = \frac{1600 - 900}{1600 - 458.3} = \frac{700}{1141.7} = 0.613.
$$
**(b)** 取$T_c = 250\ \mathrm{^\circ C}$：
$$
\phi = \frac{700}{1600 - 250} = \frac{700}{1350} = 0.519.
$$
**解释。** 要求(a)需要气膜冷却和热障涂层；(b)用良好的对流冷却加少量气膜冷却即可达到，所以需要的空气较少。代价是从冷却空气中取走的热量，如果不想损失掉，就必须把它返回循环（例如在余热锅炉中）。**合理性检查：** 冷却剂越冷，$\phi$越低，理应如此；两个值都在现代第一级叶片所给的$0.5$–$0.7$范围内。
:::
:::

## 余热锅炉 {#sec-hrsg}

[[#ex-heavy-duty]]的排气在$575\ \mathrm{^\circ C}$下携带$395\ \mathrm{MW}$——足以产生品质良好的蒸汽。**余热锅炉**（HRSG）是一台逆流换热器，通常不补燃，排气在其中流过成排的翅片管：先是**过热器**，然后是**蒸发器**（与汽包相连，或为直流式），再是**省煤器**，它把给水预热到接近饱和。设计的难点在于温度–传热量（T–Q）图上两条温度曲线的形状。燃气沿直线冷却（$\dot m_g c_{pg}$恒定）。水沿省煤器线上升，蒸发时停留在饱和温度不变，然后在过热器中再次上升。平直的蒸发段意味着两条线恰好在燃气离开蒸发器处最为接近：这就是**节点**（pinch point）。

::: definition 节点温差与接近点温差 {#def-pinch}
在产生饱和温度为$T_\mathrm{sat}$的蒸汽的余热锅炉段中：

- **节点温差**$\Delta T_\mathrm{pp} = T_{g,\mathrm{pp}} - T_\mathrm{sat}$是离开蒸发器的燃气温度与饱和温度之差，是换热器中的最小温差；
- **接近点温差**$\Delta T_\mathrm{ap} = T_\mathrm{sat} - T_{w,\mathrm{eco}}$是离开省煤器的水低于饱和温度的裕量，用以防止部分负荷时省煤器中产生汽化。

典型设计值为$\Delta T_\mathrm{pp} = 5$–$15\ \mathrm{K}$，$\Delta T_\mathrm{ap} = 3$–$10\ \mathrm{K}$。节点温差越小，回收的热量越多，但需要的面积大得多，因为在节点附近面积大致按$1/\Delta T$增长（[[heat-transfer/heat-exchangers]]）。
:::

::: algorithm 由节点温差确定单压余热锅炉的尺寸 {#alg-hrsg}
已知排气流量$\dot m_g$、平均比热容$c_{pg}$和进口温度$T_{g1}$；蒸汽压力$p$和过热温度$T_\mathrm{sh}$；给水焓$h_\mathrm{fw}$；以及$\Delta T_\mathrm{pp}$和$\Delta T_\mathrm{ap}$：

1. 由水蒸气表查得$T_\mathrm{sat}(p)$，以及焓$h_\mathrm{sh} = h(p, T_\mathrm{sh})$和离开省煤器的水的焓$h_w = h(p, T_\mathrm{sat} - \Delta T_\mathrm{ap})$。
2. 节点处的燃气温度：$T_{g,\mathrm{pp}} = T_\mathrm{sat} + \Delta T_\mathrm{pp}$。
3. 由过热器加蒸发器（余热锅炉中比节点热的部分）的能量平衡求蒸汽流量：
$$
\dot m_s = \frac{\dot m_g c_{pg} (T_{g1} - T_{g,\mathrm{pp}})}{h_\mathrm{sh} - h_w}.
$$
4. 由省煤器平衡求排烟温度：$T_\mathrm{stack} = T_{g,\mathrm{pp}} - \dot m_s (h_w - h_\mathrm{fw})/(\dot m_g c_{pg})$。
5. 校核：过热器不得与燃气线交叉（$T_{g1} - T_\mathrm{sh}$至少$20$–$30\ \mathrm{K}$）；排烟温度必须高于燃气的酸露点（天然气较低，含硫燃油则高得多）；$\dot Q = \dot m_s (h_\mathrm{sh} - h_\mathrm{fw})$是回收的热量。
:::

该算法从节点向外推算，因为设计者所控制的是节点而不是排烟：确定了蒸汽压力就确定了$T_\mathrm{sat}$，也就确定了节点处的燃气温度，其余一切都由两个能量平衡得出。

::: example 重型机组后的单压余热锅炉 {#ex-hrsg}
[[#ex-heavy-duty]]的排气（$\dot m_g = 613.2\ \mathrm{kg/s}$，$c_{pg} = 1.15\ \mathrm{kJ/(kg\,K)}$，$T_{g1} = 575.2\ \mathrm{^\circ C}$）送入一台单压余热锅炉，产生$8\ \mathrm{MPa}$、$545\ \mathrm{^\circ C}$的蒸汽。给水直接来自给水泵，温度$33.6\ \mathrm{^\circ C}$，$h_\mathrm{fw} = 147.8\ \mathrm{kJ/kg}$（凝汽器压力$5\ \mathrm{kPa}$）。取$\Delta T_\mathrm{pp} = 10\ \mathrm{K}$，$\Delta T_\mathrm{ap} = 5\ \mathrm{K}$。求蒸汽流量、排烟温度、回收热量和各段的热负荷。蒸汽物性取自 IAPWS-95（CoolProp）；印刷的水蒸气表在所示位数内与之一致。
::: solution
**第1步。** 在$8\ \mathrm{MPa}$下：$T_\mathrm{sat} = 295.0\ \mathrm{^\circ C}$，$h_f = 1317.3$，$h_g = 2758.7\ \mathrm{kJ/kg}$；$h_\mathrm{sh} = h(8\ \mathrm{MPa}, 545\ \mathrm{^\circ C}) = 3509.7\ \mathrm{kJ/kg}$；以$290.0\ \mathrm{^\circ C}$离开省煤器的水的焓$h_w = 1289.6\ \mathrm{kJ/kg}$。

**第2步。** $T_{g,\mathrm{pp}} = 295.0 + 10 = 305.0\ \mathrm{^\circ C}$。

**第3步。** $\dot m_g c_{pg} = 613.2 \times 1.15 = 705.1\ \mathrm{kW/K}$，
$$
\dot m_s = \frac{705.1 \times (575.2 - 305.0)}{3509.7 - 1289.6} = \frac{190.5\ \mathrm{MW}}{2220.1\ \mathrm{kJ/kg}} = 85.8\ \mathrm{kg/s}.
$$
**第4步。**
$$
T_\mathrm{stack} = 305.0 - \frac{85.8 \times (1289.6 - 147.8)}{705.1} = 305.0 - 138.9 = 166.1\ \mathrm{^\circ C}.
$$
**第5步。** 回收热量$\dot Q = 85.8 \times (3509.7 - 147.8) = 288.5\ \mathrm{MW}$，其中过热器$85.8 \times (3509.7 - 2758.7) = 64.4\ \mathrm{MW}$，蒸发器$85.8 \times (2758.7 - 1289.6) = 126.0\ \mathrm{MW}$，省煤器$98.0\ \mathrm{MW}$。燃气以$575.2 - 64.4/0.7051 = 483.8\ \mathrm{^\circ C}$离开过热器。过热器热端温差为$575.2 - 545 = 30\ \mathrm{K}$，可以接受。

**合理性检查。** 排气中相对于环境的$395.0\ \mathrm{MW}$中，回收了$288.5\ \mathrm{MW}$（$73\ \%$）；其余在$166\ \mathrm{^\circ C}$下排出。这一排烟温度比良好的燃天然气余热锅炉的$80$–$90\ \mathrm{^\circ C}$高得多：在节点以下给水只能吸收$98\ \mathrm{MW}$，而燃气在那里有$705.1 \times (305 - 15) = 204\ \mathrm{MW}$。单压余热锅炉缺少冷端的吸热面——这就引出了下面的多压设计。
:::
:::

| $2\ \mathrm{MPa}$ | $212.4\ \mathrm{^\circ C}$ | $92.7\ \mathrm{kg/s}$ | $124.3\ \mathrm{^\circ C}$ | $317.9\ \mathrm{MW}$ | $0.323$ | $102.8\ \mathrm{MW}$ |

蒸汽侧功率几乎不变：单一压力在数量上的所得，在品质上又失去了。出路是在一台余热锅炉中采用*几个*压力等级——高压段位于高温燃气中，中压和低压蒸发器位于更下游，各有自己的节点——使水–蒸汽线更贴近笔直的燃气线，平均温差（以及随之而来的传热中的㶲（exergy）损失）减小，排烟温度降到$80$–$90\ \mathrm{^\circ C}$。大型现代联合循环采用**三压再热**，高压蒸汽为$16$–$18\ \mathrm{MPa}$，再热温度接近$600\ \mathrm{^\circ C}$；有些采用超临界压力的直流高压段。

## 联合循环效率 {#sec-cc}

把两个循环连接起来，就能用各部分的效率表示电站的效率。推导就是两个第一定律平衡。

::: proposition 联合循环的效率 {#prop-cc}
设效率为$\eta_\mathrm{GT} = \dot W_\mathrm{GT}/\dot Q_f$的燃气轮机把所有未转换为功的能量都随排气排出；余热锅炉回收其中的份额$\varepsilon_\mathrm{HR}$，蒸汽循环以效率$\eta_\mathrm{ST}$把所得的热转换为功。则联合循环的效率为
$$
\eta_\mathrm{CC} = \eta_\mathrm{GT} + \varepsilon_\mathrm{HR}\,\eta_\mathrm{ST}\,(1 - \eta_\mathrm{GT}).
$$ {#eq-eta-cc}
在完全回收热量（$\varepsilon_\mathrm{HR} = 1$）时，这成为$1 - \eta_\mathrm{CC} = (1 - \eta_\mathrm{GT})(1 - \eta_\mathrm{ST})$：两个循环的*损失*相乘。
:::

::: proof
稳态，无补燃，所有未转换为燃气轮机功的能量都随排气离开（机壳散热损失和发电机损失约百分之一，计入"排气"份额或忽略）。于是排气能量为$\dot Q_\mathrm{ex} = \dot Q_f - \dot W_\mathrm{GT} = (1 - \eta_\mathrm{GT})\dot Q_f$。按回收系数的定义，蒸汽循环得到$\dot Q_\mathrm{HRSG} = \varepsilon_\mathrm{HR}\dot Q_\mathrm{ex}$，并输出$\dot W_\mathrm{ST} = \eta_\mathrm{ST}\dot Q_\mathrm{HRSG}$。两部分输出相加并除以$\dot Q_f$：
$$
\eta_\mathrm{CC} = \frac{\dot W_\mathrm{GT} + \dot W_\mathrm{ST}}{\dot Q_f} = \eta_\mathrm{GT} + \eta_\mathrm{ST}\,\varepsilon_\mathrm{HR}\,(1 - \eta_\mathrm{GT}).
$$
令$\varepsilon_\mathrm{HR} = 1$，$1 - \eta_\mathrm{CC} = (1 - \eta_\mathrm{GT}) - \eta_\mathrm{ST}(1 - \eta_\mathrm{GT}) = (1 - \eta_\mathrm{GT})(1 - \eta_\mathrm{ST})$。
:::

这个公式解释了联合循环为何如此有效。两个平平的循环，$\eta_\mathrm{GT} = 0.40$和$\eta_\mathrm{ST}\varepsilon_\mathrm{HR} = 0.30$，组合起来得到$0.40 + 0.30 \times 0.60 = 0.58$。从热力学上看，燃气轮机在很高的平均温度下吸热（蒸汽循环做不到：其锅炉管被限制在约$600$–$650\ \mathrm{^\circ C}$），而蒸汽循环在接近环境的温度下放热（燃气轮机做不到：其排气温度为$575\ \mathrm{^\circ C}$）。两者合在一起，几乎跨越了从火焰到河水的整个温度范围。

它还揭示了设计上的矛盾。提高燃气轮机的压比会提高$\eta_\mathrm{GT}$，但使排气变冷，从而降低$\eta_\mathrm{ST}$和$\varepsilon_\mathrm{HR}$。对[[#eq-eta-cc]]求微分可知，在底循环性能固定时，增益$\delta\eta_\mathrm{GT}$对联合循环只值$(1 - \varepsilon_\mathrm{HR}\eta_\mathrm{ST})\,\delta\eta_\mathrm{GT} \approx 0.7\,\delta\eta_\mathrm{GT}$，若底循环受损则更少。这就是为什么为联合循环设计的燃气轮机偏爱高涡轮进口温度和适中的压比。

::: example 完整的联合循环 {#ex-cc}
把[[#ex-heavy-duty]]的燃气轮机与[[#ex-hrsg]]的$8\ \mathrm{MPa}$、$545\ \mathrm{^\circ C}$余热锅炉以及一台等熵效率为$0.88$、排往$5\ \mathrm{kPa}$凝汽器的无再热汽轮机组合起来；给水泵的等熵效率为$0.80$。求汽轮机功率、电站效率和热耗率，并用[[#eq-eta-cc]]校核。忽略汽轮发电机的电气损失。
::: solution
**汽轮机。** 在$8\ \mathrm{MPa}$、$545\ \mathrm{^\circ C}$下：$h_1 = 3509.7\ \mathrm{kJ/kg}$，$s_1 = 6.865\ \mathrm{kJ/(kg\,K)}$。等熵膨胀到$5\ \mathrm{kPa}$得$h_{2s} = 2092.9\ \mathrm{kJ/kg}$（干度$0.807$），
$$
h_2 = 3509.7 - 0.88 \times (3509.7 - 2092.9) = 2262.9\ \mathrm{kJ/kg}, \qquad x_2 = 0.877.
$$
**泵。** $5\ \mathrm{kPa}$下的饱和液体：$h_3 = 137.7\ \mathrm{kJ/kg}$，$v_3 = 0.001005\ \mathrm{m^3/kg}$；$w_p = v_3 \Delta p/\eta_p = 0.001005 \times 7995/0.80 = 10.0\ \mathrm{kJ/kg}$，所以$h_\mathrm{fw} = 147.8\ \mathrm{kJ/kg}$（即[[#ex-hrsg]]中所用的值）。

**蒸汽循环。** $w_\mathrm{net} = (3509.7 - 2262.9) - 10.0 = 1236.7\ \mathrm{kJ/kg}$，$\eta_\mathrm{ST} = 1236.7/(3509.7 - 147.8) = 0.368$，
$$
\dot W_\mathrm{ST} = 85.8 \times 1236.7 = 106.1\ \mathrm{MW}.
$$
**电站。** 由$657.8\ \mathrm{MW}$的燃料得到$\dot W = 258.9 + 106.1 = 365.0\ \mathrm{MW}$：
$$
\eta_\mathrm{CC} = \frac{365.0}{657.8} = 0.555, \qquad \mathrm{HR} = \frac{3600}{0.5548} = 6488\ \mathrm{kJ/kWh}.
$$
**用[[#eq-eta-cc]]校核。** $\varepsilon_\mathrm{HR} = 288.5/(657.8 - 258.9) = 0.723$，所以$\eta_\mathrm{CC} = 0.3935 + 0.723 \times 0.368 \times 0.6065 = 0.555$，理应如此。

**合理性检查。** 燃气轮机提供$71\ \%$的出力，汽轮机提供$29\ \%$——接近通常的二比一。$55.5\ \%$远低于最好的现代电站的$60$–$64\ \%$，因为这里只有一个压力等级、没有再热、排气只有$575\ \mathrm{^\circ C}$、排烟温度高达$166\ \mathrm{^\circ C}$；出口干度$0.877$对于末级汽轮机是可以接受的。
:::
:::

**补燃。** 在燃气轮机与余热锅炉之间的烟道中设置燃烧器，可以提高排气温度（排气中氧气充足——[[#ex-heavy-duty]]的排气中仍含有大部分空气），按需产生更多蒸汽和更多功率。但在那里燃烧的燃料只能通过蒸汽循环发电，效率约为$\eta_\mathrm{ST}$，所以电站的平均效率会下降；烟道补燃是购买尖峰容量的廉价手段，而不是提高效率的手段。

作为有日期的基准：吉尼斯世界纪录在2016年认证了法国电力公司（EDF）位于法国的 Bouchain 电站（GE 9HA.01 燃气轮机）的净效率为$62.22\ \%$，又认证了SSE公司位于英格兰的 Keadby 2 电站（Siemens Energy SGT5-9000HL）的净效率为$64.18\ \%$，于2024年5月21日核实；截至2025年，Keadby 2 仍保持着联合循环的纪录。这些都是试验条件下按低位热值计的数字。

## 热电联产 {#sec-chp}

只发电的电站必须把低温热排给河流或大气。而许多用户——炼油厂、造纸厂、医院、区域供热管网——需要的恰恰是这种热。**热电联产**（CHP）电站把排气余热以工艺蒸汽或热水的形式送给它们，而不是送给凝汽器。带余热锅炉、产生工艺蒸汽的燃气轮机是典型的前置循环热电联产电站。

::: definition 热电联产电站的指标 {#def-chp}
对于由燃料功率$\dot Q_f$输出电功率$\dot W$和有用热$\dot Q_u$的电站：

- **燃料利用系数**（燃料利用率、总效率）：$\varepsilon_u = (\dot W + \dot Q_u)/\dot Q_f$；
- **热电比**（电热比）：$\sigma = \dot W/\dot Q_u$——带余热锅炉的燃气轮机较高，背压式汽轮机较低；
- **一次能源节约率**，相对于在电效率为$\eta_{e,\mathrm{ref}}$、热效率为$\eta_{h,\mathrm{ref}}$的参考电站中分别生产同样的电和热：
$$
\mathrm{PES} = 1 - \frac{1}{\dfrac{\eta_h}{\eta_{h,\mathrm{ref}}} + \dfrac{\eta_e}{\eta_{e,\mathrm{ref}}}}, \qquad \eta_e = \frac{\dot W}{\dot Q_f},\ \ \eta_h = \frac{\dot Q_u}{\dot Q_f}.
$$ {#eq-pes}
:::

一次能源节约率公式不过是燃料之比：分产的电站将燃烧$\dot W/\eta_{e,\mathrm{ref}} + \dot Q_u/\eta_{h,\mathrm{ref}}$；用它去除$\dot Q_f$再从1中减去，即得[[#eq-pes]]。单看燃料利用系数会产生误导，因为它把电的千瓦与热的千瓦相加，仿佛两者价值相同：一台锅炉的燃料利用系数为$0.9$，却根本不产生功。一次能源节约率则是同类相比。它是欧洲法律所用的指标：第2012/27/EU号指令（《能源效率指令》）把**高效热电联产**定义为相对于欧盟委员会规定的统一参考效率，一次能源节约率至少达到$10\ \%$。在美国，1978年的《公用事业管制政策法》（PURPA）创设了"合格设施"；联邦能源管理委员会（FERC）对燃气或燃油前置循环设施的效率标准（18 CFR 292.205）要求有用电力输出加有用热输出的**一半**至少为燃料输入的$42.5\ \%$（若热输出不到总输出的$15\ \%$，则为$45\ \%$），且热输出至少为总输出的$5\ \%$。二分之一这个因子是同一思想的粗略版本：热的价值低于功。

::: example 造纸厂的燃气轮机热电联产电站 {#ex-chp}
一台燃气轮机以$\eta_e = 0.40$输出$45\ \mathrm{MW}$电力；其排气为$135\ \mathrm{kg/s}$、$461\ \mathrm{^\circ C}$，$c_{pg} = 1.12\ \mathrm{kJ/(kg\,K)}$，通过一台不补燃的余热锅炉，为造纸厂产生$1.0\ \mathrm{MPa}$的饱和蒸汽。凝结水以$90\ \mathrm{^\circ C}$返回；节点温差$10\ \mathrm{K}$，接近点温差为零。求蒸汽流量、排烟温度和有用热，燃料利用系数和热电比，电站是否满足PURPA标准，以及相对于参考效率$0.525$（电）和$0.90$（热）的一次能源节约率（这里的参考效率取为示意值）。
::: solution
**燃料。** $\dot Q_f = 45/0.40 = 112.5\ \mathrm{MW}$。

**余热锅炉（[[#alg-hrsg]]，无过热器）。** 在$1.0\ \mathrm{MPa}$下：$T_\mathrm{sat} = 179.9\ \mathrm{^\circ C}$，$h_f = 762.5$，$h_g = 2777.1\ \mathrm{kJ/kg}$；$90\ \mathrm{^\circ C}$的回水$h = 377.8\ \mathrm{kJ/kg}$。节点处燃气温度$189.9\ \mathrm{^\circ C}$；$\dot m_g c_{pg} = 151.2\ \mathrm{kW/K}$。
$$
\dot m_s = \frac{151.2 \times (461 - 189.9)}{2777.1 - 762.5} = 20.35\ \mathrm{kg/s}, \qquad T_\mathrm{stack} = 189.9 - \frac{20.35 \times (762.5 - 377.8)}{151.2} = 138.1\ \mathrm{^\circ C}.
$$
有用热$\dot Q_u = 20.35 \times (2777.1 - 377.8) = 48.8\ \mathrm{MW}$。

**指标。**
$$
\varepsilon_u = \frac{45 + 48.8}{112.5} = 0.834, \qquad \sigma = \frac{45}{48.8} = 0.92.
$$
PURPA：$(45 + 48.8/2)/112.5 = 0.617 \ge 0.425$，热输出占总输出的$52\ \%$——电站轻松合格。一次能源节约率，取$\eta_e = 0.400$，$\eta_h = 0.434$：
$$
\mathrm{PES} = 1 - \frac{1}{0.434/0.90 + 0.400/0.525} = 1 - \frac{1}{1.2440} = 0.196.
$$
**解释。** 分产将燃烧$45/0.525 + 48.8/0.90 = 140.0\ \mathrm{MW}$的燃料，而不是$112.5\ \mathrm{MW}$：节约$27.5\ \mathrm{MW}$，即$19.6\ \%$。**合理性检查：** $\varepsilon_u < 1$；排烟温度高于节点温度减去省煤器温降之值，且远高于回水温度；一次能源节约率远低于$\varepsilon_u$，当热和电都按其参考值计算时理应如此。
:::
:::

::: warning 燃料利用系数不是效率
燃料利用系数为$0.85$，并不意味着热电联产电站在发电厂的意义上"效率为85 %"。电和热不能互换：热泵可以把$1\ \mathrm{kW}$电变成$3\ \mathrm{kW}$低温热，但没有任何装置能以高于卡诺效率的效率把热变回功。比较热电联产电站，要用一次能源节约率、㶲效率（[[thermodynamics/exergy]]），或者相对于实际替代方案的成本和排放（[[energy-systems/energy-economics-emissions]]），并说明所用的参考效率。
:::

::: quiz
某联合循环电站的燃气轮机经过升级，效率从$38\ \%$提高到$40\ \%$，余热锅炉和蒸汽循环不变，其乘积$\varepsilon_\mathrm{HR}\eta_\mathrm{ST}$保持为$0.30$。联合循环效率会怎样变化？
- [ ] 提高$2$个百分点，与燃气轮机相同。
- [x] 提高$1.4$个百分点。
- [ ] 提高$0.6$个百分点。
- [ ] 下降，因为到达蒸汽循环的热量减少了。
::: solution
由[[#eq-eta-cc]]，$\eta_\mathrm{CC} = \eta_\mathrm{GT} + 0.30(1 - \eta_\mathrm{GT}) = 0.30 + 0.70\,\eta_\mathrm{GT}$。升级前：$0.30 + 0.70 \times 0.38 = 0.566$；升级后：$0.30 + 0.70 \times 0.40 = 0.580$，提高$1.4$个百分点。蒸汽循环确实损失了一些热量，即$0.30 \times 0.02 = 0.6$个百分点的出力，但燃气轮机提高了$2$个百分点，所以净效果为正。实际上效率更高的燃气轮机排气往往更冷，这也会降低$\eta_\mathrm{ST}$，所以实际增益可能还要小。
:::
:::

::: history
燃气轮机在能够工作之前很久就已取得专利。**约翰·巴伯**（John Barber）**1791**年的英国第1833号专利描述了压气机、燃烧室和涡轮；但没有已知的可工作的发动机。障碍在于压气机：以当时的部件效率，涡轮无法驱动它（见[[#prop-real-brayton]]）。**1903**年，挪威工程师**埃吉迪乌斯·埃林**（Ægidius Elling）在克里斯蒂安尼亚（奥斯陆）运行了一般公认的第一台输出净功率的燃气轮机，约$11\ \mathrm{hp}$，以压缩空气的形式输出。第一台商业发电的燃气轮机由**布朗-博韦里公司**（Brown Boveri）制造，**1939**年安装在瑞士**纳沙泰尔**市立电站：一台$4\ \mathrm{MW}$的备用机组，由**奥雷尔·斯托多拉**（Aurel Stodola）监督的验收试验测得效率为$17.4\ \%$。它一直服役到2002年，是ASME历史地标（1988年）。在美国，一台$3.5\ \mathrm{MW}$的通用电气机组于**1949**年在俄克拉何马燃气与电力公司的**贝尔岛**（Belle Isle）电站投入运行；其排气用于加热电站蒸汽装置的给水，成为两种循环相结合的早期实例。**1978**年的**《公用事业管制政策法》**向独立的热电联产商开放了美国电网，帮助形成了燃气轮机热电联产的市场，并在廉价天然气和更好的涡轮的推动下，形成了联合循环的市场。经吉尼斯世界纪录认证的联合循环效率纪录，**2016**年在 Bouchain（法国）提高到$62.22\ \%$，**2024**年在 Keadby 2（英格兰）提高到$64.18\ \%$。
:::

::: summary
- 实际部件效率使简单循环效率成为压比和涡轮进口温度两者的函数，并有两个最优值：比功在$x = \sqrt{\eta_c\eta_t\tau}$处最大，效率在由一个二次方程给出的更高压比处最大（[[#prop-optimum-ratio]]）。两者之间效率曲线平坦。
- 约$0.5$的反功比放大了压气机的每一项损失，并使容积流量固定时环境温度每升高一开尔文出力下降约$0.7\ \%$（[[#prop-ambient]]）；蒸发式或制冷式进气冷却可以找回其中的大部分。
- 涡轮进口温度是最有价值的设计参数，受叶片金属温度的限制；$0.6$–$0.7$的冷却效率$\phi = (T_g - T_m)/(T_g - T_c)$使$1600\ \mathrm{^\circ C}$的燃气能与$900\ \mathrm{^\circ C}$的叶片相遇，代价是冷却空气。
- 余热锅炉由节点温差确定尺寸（[[#alg-hrsg]]）：节点决定蒸汽流量，省煤器平衡决定排烟温度。多个压力等级和再热能以更高的品质回收更多热量。
- 联合循环效率为$\eta_\mathrm{CC} = \eta_\mathrm{GT} + \varepsilon_\mathrm{HR}\eta_\mathrm{ST}(1 - \eta_\mathrm{GT})$；最好的电站约达$64\ \%$（低位热值，2024年）。补燃增加的是容量，而不是效率。
- 热电联产要用相对于分产的一次能源节约率来评价，而不是用燃料利用系数；监管规定体现了这一点（欧盟的高效热电联产，PURPA对热量的二分之一计入）。
- 热耗率$= 3600/\eta$，单位$\mathrm{kJ/kWh}$；务必注明低位热值或高位热值。
:::

## 习题

::: exercise 热耗率 {#exr-heat-rate level=1 check="8780"}
一台航改型燃气轮机的简单循环效率为$41\ \%$（低位热值）。它的热耗率是多少？（以kJ/kWh为单位输入热耗率，四舍五入到$10\ \mathrm{kJ/kWh}$。）
::: solution
$\mathrm{HR} = 3600/0.41 = 8780.5\ \mathrm{kJ/kWh}$，四舍五入到$10$为$8780\ \mathrm{kJ/kWh}$。用美国单位，在同样的低位热值基准下为$3412/0.41 = 8322\ \mathrm{Btu/kWh}$。
:::

::: exercise 理想联合循环 {#exr-ideal-cc level=1 check="61"}
一台效率为$40\ \%$的燃气轮机与效率为$35\ \%$的蒸汽循环组合，燃气轮机的排气余热全部回收。联合循环效率是多少？（以百分数输入效率。）
::: solution
取$\varepsilon_\mathrm{HR} = 1$，[[#eq-eta-cc]]给出$1 - \eta_\mathrm{CC} = (1 - 0.40)(1 - 0.35) = 0.60 \times 0.65 = 0.39$，所以$\eta_\mathrm{CC} = 0.61 = 61\ \%$。实际的余热锅炉回收排气余热的$70$–$90\ \%$，所以具有这些部件效率的实际电站将达到$55$–$59\ \%$。
:::

::: exercise 所需的冷却效率 {#exr-cooling level=1 check="0.574"}
一个第一级导叶处于$1500\ \mathrm{^\circ C}$的燃气中，用$420\ \mathrm{^\circ C}$的空气冷却，其温度不得超过$880\ \mathrm{^\circ C}$。需要多大的综合冷却效率？（输入$\phi$，保留三位有效数字。）
::: solution
$\phi = (1500 - 880)/(1500 - 420) = 620/1080 = 0.5741$，即$0.574$。温差可以用摄氏度计，因为偏移量相互抵消。
:::

::: exercise 最大功的压比 {#exr-ropt level=2 check="10.5"}
一台小型工业燃气轮机$T_1 = 300\ \mathrm{K}$，$T_3 = 1500\ \mathrm{K}$，$\eta_c = 0.86$，$\eta_t = 0.89$。用冷空气标准（$k = 1.4$）求使比功最大的压比，以及该压比下的比功和效率。（输入压比，保留三位有效数字。）
::: solution
$\tau = 5$，所以$x_w = \sqrt{0.86 \times 0.89 \times 5} = 1.9563$，$r_{p,w} = 1.9563^{3.5} = 10.47$，即$10.5$。再由[[#eq-wnet-real]]
$$
w_\mathrm{net} = 1.005 \times 300 \left[5 \times 0.89 \left(1 - \frac{1}{1.9563}\right) - \frac{0.9563}{0.86}\right] = 320.6\ \mathrm{kJ/kg},
$$
$q_\mathrm{in} = 1.005 \times 300 \times (4 - 0.9563/0.86) = 870.8\ \mathrm{kJ/kg}$，所以$\eta = 0.368$。理想循环的功最优压比在$5^{1.75} = 16.7$：部件损失把最优值拉向较低的压比。
:::

::: exercise 炎热天气下的出力 {#exr-hot-day level=2 check="84.0"}
一台燃气轮机在ISO条件（$15\ \mathrm{^\circ C}$）下涡轮功率为$200\ \mathrm{MW}$，压气机功率为$100\ \mathrm{MW}$。利用[[#prop-ambient]]（容积流量、压比和涡轮进口温度固定），估算其在$40\ \mathrm{^\circ C}$时的净轴功率。（以MW为单位输入功率，保留一位小数。）
::: solution
压气机功率保持$100\ \mathrm{MW}$；涡轮功率按$1/T_1$变化：
$$
\dot W_t = 200 \times \frac{288.15}{313.15} = 184.03\ \mathrm{MW}, \qquad \dot W_\mathrm{net} = 84.03 \approx 84.0\ \mathrm{MW}.
$$
温度升高$25\ \mathrm{K}$使出力损失了$16\ \%$，约每开尔文$0.64\ \%$；[[#eq-ambient]]在$15\ \mathrm{^\circ C}$处给出的初始值为每开尔文$1/(288.15 \times 0.5) = 0.69\ \%$。
:::
:::

::: exercise 一次能源节约率 {#exr-pes level=2 check="14.3"}
一座热电联产电站燃烧$100\ \mathrm{MW}$燃料，输出$35\ \mathrm{MW}$电力和$45\ \mathrm{MW}$有用热。求其燃料利用系数、热电比，判断是否满足PURPA前置循环标准，并求相对于参考效率$0.525$（电）和$0.90$（热）的一次能源节约率。（以百分数输入一次能源节约率，保留一位小数。）
::: solution
$\varepsilon_u = (35 + 45)/100 = 0.80$；$\sigma = 35/45 = 0.78$。PURPA：$(35 + 22.5)/100 = 0.575 \ge 0.425$，且热量超过输出的$15\ \%$，所以合格。取$\eta_e = 0.35$，$\eta_h = 0.45$：
$$
\mathrm{PES} = 1 - \frac{1}{0.45/0.90 + 0.35/0.525} = 1 - \frac{1}{1.1667} = 0.1429 = 14.3\ \%.
$$
它超过了欧盟意义上"高效热电联产"所需的$10\ \%$（在这些参考值下）。
:::

::: exercise 单压余热锅炉 {#exr-hrsg level=2}
排气（$500\ \mathrm{kg/s}$，$c_{pg} = 1.10\ \mathrm{kJ/(kg\,K)}$，$600\ \mathrm{^\circ C}$）把$40\ \mathrm{^\circ C}$的给水加热成$6\ \mathrm{MPa}$、$560\ \mathrm{^\circ C}$的蒸汽。节点温差为$8\ \mathrm{K}$，接近点温差为零，利用水蒸气表求蒸汽流量、排烟温度和回收热量。画出T–Q图。
::: solution
在$6\ \mathrm{MPa}$下：$T_\mathrm{sat} = 275.6\ \mathrm{^\circ C}$，$h_f = 1213.9\ \mathrm{kJ/kg}$；$h(6\ \mathrm{MPa}, 560\ \mathrm{^\circ C}) = 3564.8\ \mathrm{kJ/kg}$；$40\ \mathrm{^\circ C}$的压缩水$h_\mathrm{fw} = 172.8\ \mathrm{kJ/kg}$（IAPWS-95；饱和液体表给出$167.5$，这里的差别可以忽略）。节点处燃气温度为$283.6\ \mathrm{^\circ C}$，$\dot m_g c_{pg} = 550\ \mathrm{kW/K}$：
$$
\dot m_s = \frac{550 \times (600 - 283.6)}{3564.8 - 1213.9} = 74.0\ \mathrm{kg/s},
\qquad
T_\mathrm{stack} = 283.6 - \frac{74.0 \times (1213.9 - 172.8)}{550} = 143.5\ \mathrm{^\circ C},
$$
$\dot Q = 74.0 \times (3564.8 - 172.8) = 251\ \mathrm{MW}$。在T–Q图上，燃气线从$143.5$到$600\ \mathrm{^\circ C}$是一条直线；水线在最初的$77\ \mathrm{MW}$内从$40$升到$275.6\ \mathrm{^\circ C}$，在蒸发器中保持水平，然后在过热器中升到$560\ \mathrm{^\circ C}$，在蒸发器冷端与燃气线相距$8\ \mathrm{K}$。
:::

::: exercise 补燃 {#exr-duct-firing level=3 check="53.9"}
[[#ex-cc]]的联合循环（燃气轮机$258.85\ \mathrm{MW}$，汽轮机$106.1\ \mathrm{MW}$，燃料$657.8\ \mathrm{MW}$）加装了烟道燃烧器，增加$60\ \mathrm{MW}$燃料。假设它全部以额外蒸汽的形式回收，并以蒸汽循环的效率$0.368$转换。求新的出力和电站效率，并用[[#eq-eta-cc]]解释结果。（以百分数输入新的电站效率，保留一位小数。）
::: solution
额外功率$0.368 \times 60 = 22.08\ \mathrm{MW}$，所以由$717.8\ \mathrm{MW}$燃料得到$\dot W = 258.85 + 106.1 + 22.08 = 387.0\ \mathrm{MW}$：
$$
\eta = \frac{387.0}{717.8} = 0.539 = 53.9\ \%,
$$
从$55.5\ \%$下降。烟道燃料的边际效率只是蒸汽循环本身的效率$36.8\ \%$，低于电站平均值，所以加入它会降低平均值。（实际上汽轮机和余热锅炉必须按额外蒸汽确定尺寸，而余热锅炉燃气温度升高可能使$\eta_\mathrm{ST}$略有提高。）烟道补燃在容量稀缺而燃料便宜时很有价值，但不是一项提高效率的措施。
:::

::: exercise 理想循环的效率最优值 {#exr-ideal-optimum level=3}
(a) 证明当$\eta_c = \eta_t = 1$时，二次方程[[#eq-xopt-eta]]在$x = \tau$处有二重根，并解释它：那里的$T_2$、$w_\mathrm{net}$和$\eta$各是多少？(b) 更一般地，证明[[#eq-wnet-real]]中的$w_\mathrm{net}$在$x = 1$和$x = \eta_c\eta_t\tau$处为零，且$x_w$是它们的几何平均。
::: solution
(a) 取$a = \tau$，$b = 1$，$c = \tau - 1$：$b(a - c) = 1$，$2ab = 2\tau$，$a(b + c) = \tau^2$，所以二次方程为$x^2 - 2\tau x + \tau^2 = (x - \tau)^2 = 0$。在$x = \tau$处，$T_2 = T_1 x = T_3$：仅靠压气机就把空气加热到涡轮进口温度，不加燃料，$w_\mathrm{net} = 0$；效率$1 - 1/x = 1 - T_1/T_3$等于$T_1$与$T_3$之间的卡诺效率。理想循环的效率单调地趋向这一极限，而只有在输出为零时才能达到——这就是理想循环中效率与比功不能同时取最大值的表述。

(b) $w_\mathrm{net} = (c_pT_1/x)\left[\tau\eta_t(x - 1) - x(x - 1)/\eta_c\right] = (c_pT_1/\eta_c)(x - 1)(\eta_c\eta_t\tau - x)/x$，在$x = 1$和$x = \eta_c\eta_t\tau$处为零。它们的几何平均是$\sqrt{\eta_c\eta_t\tau}$，即[[#eq-xopt-work]]中的$x_w$。$\eta_c\eta_t\tau < 1$的机器在任何压比下都不能产生净功——这就是部件效率接近$0.6$、进口温度又低的早期燃气轮机失败的原因。
:::

::: exercise 设计：为炎热干燥的场址供电 {#exr-design level=3}
沙漠中一个炎热的矿业小镇（夏季午后干球温度$45\ \mathrm{^\circ C}$，湿球温度$22\ \mathrm{^\circ C}$；冬季夜间接近$5\ \mathrm{^\circ C}$）需要$120\ \mathrm{MW}$的可靠电力，高峰在夏季午后；其加工厂全年需要约$40\ \mathrm{MW}$、$1\ \mathrm{MPa}$的蒸汽。水资源稀缺，天然气可通过管道供应。提出并比较至少两种电站配置——例如，带进气冷冻和产生工艺蒸汽的余热锅炉的航改型机组；或者带空冷凝汽器和补燃的重型联合循环——对每种方案估算ISO出力和夏季出力、效率或一次能源节约率、耗水量和主要风险。说明你的假设，以及你会向制造商索要哪些数据。
::: solution
答案不唯一；好的答案会量化各种权衡。**降额：** 由[[#eq-ambient]]取$\mathrm{bwr} \approx 0.5$，$45\ \mathrm{^\circ C}$时的出力约为ISO额定值的$1 - (318.15 - 288.15) \times 0.007 \approx 79\ \%$（精确的$A/T_1 - B$模型给出$1 - 2 \times (1 - 288.15/318.15) = 81\ \%$），所以不采用进气冷却时需要$150$–$155\ \mathrm{MW}$的ISO容量，再加上保证可靠供电的冗余（$N + 1$台机组）。**进气冷却：** 效能为$0.9$的蒸发冷却器可把$45\ \mathrm{^\circ C}$降到约$24\ \mathrm{^\circ C}$，找回大部分降额，但要耗水（在这些条件下每$100\ \mathrm{kg/s}$空气约$1\ \mathrm{kg/s}$量级）；机械制冷机组可以避免耗水，代价是百分之几的出力。**热电联产：** 燃气轮机后的余热锅炉可以提供$40\ \mathrm{MW}$工艺蒸汽，燃料利用系数接近$0.8$，一次能源节约率约$15$–$25\ \%$（如[[#ex-chp]]）；联合循环在沙漠中需要空冷凝汽器，炎热天气下凝结压力升高（可能是$15$–$20\ \mathrm{kPa}$而不是$5$），恰恰在最需要电的时候降低了$\eta_\mathrm{ST}$。**比较：** 几台带余热锅炉的航改型机组为小型孤立电网提供了模块化、快速启动和良好的部分负荷效率；联合循环满负荷效率最好，但存在单台大机组的风险。向制造商索要随环境温度变化的现场额定出力和热耗率、部分负荷曲线、耗水量、启动时间和检修间隔；核查排放限值和供气的可靠性。
:::
