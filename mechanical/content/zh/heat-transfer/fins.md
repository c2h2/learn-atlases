肋片就是被赋予了更多面积的壁面，而全部肋片理论就是核算这些面积究竟值多少。这个想法显而易见，算术也很简单；不那么显而易见的是，**增加的面积从来不会完全发挥作用**，因为热量必须沿肋片传导才能到达那里，而肋端的温度低于肋基的温度，所以远端比近端出力要少。衡量这一点的单一数字是**肋效率**，即肋片实际散出的热量与整个肋片都处于肋基温度时所能散出的热量之比，它是热工程中最常被误读的量。

肋片之所以起作用，归根结底是两个热阻的比较。沿长度为$L$、截面积为$A_c$、周长为$P$的肋片的导热提供热阻$L / ( k A _ { c } )$；其表面的对流提供热阻$1 / ( h P L )$。两者之比就是支配一切的参数：
$$
m ^ { 2 } L ^ { 2 } = \frac { L / ( k A _ { c } ) } { 1 / ( h P L ) } = \frac { h P L ^ { 2 } } { k A _ { c } } \qquad \Longleftrightarrow \qquad m = \sqrt { \frac { h P } { k A _ { c } } }
$$
**当$mL \ll 1$时，肋片又短又粗，整个表面都接近肋基温度，它所做的不过是稍厚一点的壁面也能做到的事。当$mL \gg 1$时，肋片又细又长，温度在离肋基不远处就降了下去，其大部分表面处于环境温度，根本不起作用。**有用的范围是$mL$约在$0.3$到$1.5$之间，肋片设计的全部技艺就是把一块金属放进这个窗口。

有两个推论决定着大多数实际设计。**肋效能**——肋片传递的热量与同一肋基面积在没有肋片时所传递的热量之比——对长肋而言为$\sqrt { P k / ( h A _ { c } ) }$，它**在$h$小的时候就大**：肋片是弥补流体之不足的办法，这就是为什么每一样风冷的东西都布满了金属，而水冷的东西几乎都没有。而**肋片阵列的最优间距**根本不是由肋片本身决定的，而是由肋片之间的边界层决定的：**可行的节距约为当量膜层厚度$k / h$的两倍，这就是为什么自然对流散热器的肋片间距为$8$到$12\ \mathrm{mm}$，而强制风冷散热器为$2$到$3\ \mathrm{mm}$——同一条规则，用于相差约四倍的两个$h$值。**

::: warning 各行各业都会犯的五个肋片错误
**混淆肋效率与肋效能。**一片肋效率为$58\ \%$、肋效能为$20$的肋片是**好肋片**：它散出的热量是同形状等温肋片的$58\ \%$，是它下方裸壁的二十倍。**肋效率衡量的是金属；肋效能衡量的是决策。****以为肋片越多越好。**对于长肋，散热量为$\sqrt { h P k A _ { c } } \, \Delta T$，**其中根本不含长度**：把一片$mL > 2$的肋片加长一倍只多换来百分之几，质量却翻了一番。在阵列中，以固定节距增加肋片会先增加面积，然后就停止起作用，因为边界层合并，$h$随之崩塌。**自然对流散热器的最优间距宽而平坦——从最优间距的约三分之二到一倍半，性能变化不到$10\ \%$——所以买一个装得下的散热器，然后停止优化。****忽视肋基。**肋片是装上去的，而连接处有接触热阻，对压入或环氧黏接的接头，典型值为$3000$到$8000\ \mathrm { W / m ^ { 2 } K }$。分布在宽阔的底板上时，它通常可以忽略；集中在每一片压装肋片狭窄的根部接触面上时，它可能吃掉阵列一半以上的性能——见[[#ex-contact]]。**对不薄的肋片使用一维肋片方程。**肋片方程假定温度沿厚度方向均匀，这要求以半厚度计的毕渥数$h t / 2 k$很小。对于空气中$1\ \mathrm{mm}$厚的铝肋片，它约为$10^{-5}$，这个假定极好。**对于沸腾水中的薄不锈钢或钛肋片，它不成立；对于聚合物肋片，它从来就不成立**——而补救办法不是把肋片方程解得更好，而是不再使用它。**以为肋端无关紧要。**对于厚度为$t$的肋片，肋端大约承担总量的$t / ( 2 L )$，这对平板肋可以忽略，对与其长度一样粗的针肋则**不**可忽略。标准的补救办法是**修正长度**$L _ { c } = L + t / 2$，只需一行修正，总是值得采用。
:::

## 肋片方程

::: definition 等截面直肋 {#def-fineq}
对周长为$P$、截面积为$A_c$、以表面传热系数$h$向温度为$T_\infty$的流体散热的肋片，在厚度为$dx$的薄片上作能量平衡。令$\theta = T - T_\infty$，
$$
\boxed { \; { \frac { d ^ { 2 } \theta } { d x ^ { 2 } } } - m ^ { 2 } \theta = 0 , \qquad m = \sqrt { \frac { h P } { k A _ { c } } } \; } \qquad \theta ( x ) = C _ { 1 } e ^ { m x } + C _ { 2 } e ^ { - m x }
$$
**这个方程说的是温度分布曲线的曲率与温度分布本身成正比**，这就是为什么解是指数函数：温度降得越多，单位长度的散热就越少，于是温度继续下降得也就越平缓。**通解加上四种边界条件，就给出了设计者所需的一切：**
$$
\begin{array}{l l l}
\text{无限长肋} & \theta ( L ) \to 0 & \theta = \theta _ { b } e ^ { - m x } , \quad q _ { f } = \sqrt { h P k A _ { c } } \, \theta _ { b } \\[4pt]
\text{肋端绝热} & d \theta / d x | _ { L } = 0 & \theta = \theta _ { b } \dfrac { \cosh m ( L - x ) } { \cosh m L } , \quad q _ { f } = \sqrt { h P k A _ { c } } \, \theta _ { b } \tanh m L \\[10pt]
\text{给定肋端温度} & \theta ( L ) = \theta _ { L } & \theta = \dfrac { \theta _ { b } \sinh m ( L - x ) + \theta _ { L } \sinh m x } { \sinh m L } \\[10pt]
\text{肋端对流} & - k \, d \theta / d x | _ { L } = h _ { t } \theta _ { L } & \text{用 } L _ { c } \text{ 和肋端绝热的结果}
\end{array}
$$
**长度$1 / m$是肋片自身的长度尺度**——过余温度在这段距离上降为$1 / e$——值得在做其他任何事之前先算出来，因为它告诉你肋片有多少部分在干活。对于静止空气中$h = 8$的$1\ \mathrm{mm}$厚铝制平板肋，$1 / m = 1 0 6\ \mathrm { m m }$；对于同样尺寸、处于$h = 4 5$的强制气流中的不锈钢肋片，$1 / m = 1 3\ \mathrm { m m }$；对于水中$h = 3 0 0 0$、直径$1\ \mathrm{mm}$的铜针肋，$1 / m = 6\ \mathrm { m m }$。**比$1 / m$长好几倍的肋片，多半只是装饰。**
:::

::: exercise 推导：由薄片导出肋片方程 {level=3}
::: solution
在$x$处导入的热量为$- k A _ { c } \, d T / d x$，在$x + d x$处导出的热量为在该处取值的$- k A _ { c } \, d T / d x$；薄片表面的对流散热为$h \left( T - T _ { \infty } \right) P \, d x$。稳态平衡，令$\theta = T - T _ { \infty }$且$d T _ { \infty } / d x = 0$：
$$
- k A _ { c } { \frac { d \theta } { d x } } \bigg | _ { x } + k A _ { c } { \frac { d \theta } { d x } } \bigg | _ { x + d x } = h \theta P \, d x \qquad \Longrightarrow \qquad k A _ { c } { \frac { d ^ { 2 } \theta } { d x ^ { 2 } } } = h P \theta
$$
**推导揭示了方框中的方程所隐藏的三件事。**
**(i) 并没有假定$h$为常数**，只假定它是已知的。如果$h$沿肋片变化——在自然对流阵列中，它从肋根到肋端变化达两倍——方程在$m ( x )$中含$h ( x )$时仍然成立，失去的只是封闭形式解。
**(ii) 横向温度梯度被假定不存在。**推导只用了跨越$d x$的一维导热项。由此引入的误差与以半厚度计的毕渥数$h t / 2 k$同量级：对于$1\ \mathrm{mm}$的肋片，**空气中的铝（$h = 8$）为$2 \times 10^{-5}$；$h = 5 0 0 0$的沸腾水中的铝为$0 . 0 1 4$；空气中的聚四氟乙烯（$k \approx 0.25$）为$0 . 0 1 6$；$h = 3000$的水中的聚四氟乙烯为$6$，这个理论就彻底失效了。**
**(iii) 周长$P$完全没有计入肋端的贡献**，这就是为什么表中第四种边界条件是靠加长肋片而不是重新求解来处理的。增加$A_c / P$的额外长度——对薄矩形肋即修正长度$L_c = L + t/2$，对针肋为$L + d/4$——对一般的肋片比例，能把肋端对流的答案复现到百分之几以内，所以采用$L_c$的肋端绝热公式几乎涵盖了所有实际情形。
:::
:::

::: definition 肋效率 {#def-fin-eff}
$$
\eta _ { f } \equiv { \frac { q _ { \text{实际} } } { q _ { \text{若整个肋片均处于 } T _ { b } } } } = { \frac { \int h \theta \, d A } { h A _ { f } \theta _ { b } } } \qquad \Longrightarrow \qquad \boxed { \eta _ { f } = { \frac { \tanh m L _ { c } } { m L _ { c } } } } \quad \text{等截面直肋}
$$
$$
\begin{array} { c c c c c c c c c c }
m L _ { c } & 0 . 1 & 0 . 2 & 0 . 3 & 0 . 5 & 0 . 7 5 & 1 . 0 & 1 . 5 & 2 . 0 & 3 . 0 & 5 . 0 \\
\eta _ { f } & 0 . 9 9 7 & 0 . 9 8 7 & 0 . 9 7 1 & 0 . 9 2 4 & 0 . 8 4 7 & 0 . 7 6 2 & 0 . 6 0 3 & 0 . 4 8 2 & 0 . 3 3 2 & 0 . 2 0 0
\end{array}
$$
**常用的设计窗口是$m L _ { c } \approx 0 . 5$到$1 . 0$，即$\eta _ { f } \approx 0 . 9 2$到$0 . 7 6$。**远低于此，肋片几乎等温，这些金属本可以做得更高，或用来再做一片肋；远高于此，肋片外段接近流体温度，几乎是白花钱。
**对于矩形截面的环肋**，精确解是修正贝塞尔函数$I _ { 1 }$与$K _ { 1 }$的组合，没有人会在办公桌前去计算它。一个广泛使用的近似是施密特（Schmidt）的近似（1949），在通常范围内精确到百分之几：
$$
\eta _ { f } \approx { \frac { \tanh \left( m L _ { c } \psi \right) } { m L _ { c } \psi } } , \qquad \psi = 1 . 0 + 0 . 3 5 \ln \left( { \frac { r _ { 2 c } } { r _ { 1 } } } \right) , \qquad L _ { c } = L + { \frac { t } { 2 } } , \quad r _ { 2 c } = r _ { 2 } + { \frac { t } { 2 } }
$$
**因子$\psi > 1$是环肋因其为环形而付出的代价**：面积随半径增大，所以肋片更多的面积位于远离肋根、肋片最冷的地方，肋片的表现就好像它比实际更长。$r_{2c} / r_1 = 2$时，$\psi = 1 . 2 4$；$r_{2c} / r_1 = 5$时，$\psi = 1 . 5 6$。
:::

::: definition 肋效能 {#def-fin-effec}
$$
\varepsilon _ { f } \equiv { \frac { q _ { \text{肋片}} } { q _ { \text{同面积的裸肋基} } } } = { \frac { \sqrt { h P k A _ { c } } \, \theta _ { b } \tanh m L _ { c } } { h A _ { b } \theta _ { b } } } \qquad \Longrightarrow \qquad \varepsilon _ { f } \approx \sqrt { \frac { P k } { h A _ { c } } } \quad \text{当 } m L \gg 1
$$
**肋效能的分母中含有$h$，这一个事实就是肋片选用问题的全部。**对于厚度为$t$、单位深度的矩形肋，$P = 2$，$A _ { c } = t$，因此$\varepsilon _ { f } = \sqrt { 2 k / ( h t ) }$：
$$
\begin{array}{l c c c}
\text{肋片} & k \left( \mathrm { W / m \, K } \right) & h \left( \mathrm { W / m ^ { 2 } K } \right) & \varepsilon _ { f } \text{，当 } t = 1 \mathrm { m m } \\
\text{静止空气中的铝} & 1 8 0 & 6 & 2 4 5 \\
\text{强制风冷中的铝} & 1 8 0 & 5 0 & 8 5 \\
\text{水中的铝} & 1 8 0 & 3 0 0 0 & 1 1 \\
\text{沸腾水中的铝} & 1 8 0 & 1 0 { , } 0 0 0 & 6 \\
\text{静止空气中的不锈钢} & 1 6 & 6 & 7 3 \\
\text{静止空气中的铜} & 4 0 1 & 6 & 3 6 6
\end{array}
$$
**把最后两行与第一行对照着读。**空气中的铜肋片比铝肋片的肋效能高$50\ \%$，但铜的密度是铝的三倍多，每千克的价格也贵好几倍——**这就是为什么大多数散热器是铝制的，而铜用于体积固定、导热路径又长的场合。****再读水的那几行：在$h = 3 0 0 0$时肋效能为$1 1$且还在下降，沸腾时为$6$。水中的肋片仍然有帮助，但小得多；在沸腾水中，长肋片增益甚微，沸腾表面通常改用能促进核化的精细结构来强化。**
:::

## 肋片阵列

::: definition 肋壁总效率与阵列热阻 {#def-array}
实际的表面既有肋片，**也有**肋片之间裸露的肋基。设$A _ { f }$为肋片总面积，$A _ { b }$为外露的肋基面积，$A _ { t } = A _ { f } + A _ { b }$，
$$
\boxed { \; \eta _ { o } = 1 - { \frac { A _ { f } } { A _ { t } } } \left( 1 - \eta _ { f } \right ) \; } \qquad \Longrightarrow \qquad R _ { \text{conv} } = { \frac { 1 } { \eta _ { o } \, h \, A _ { t } } }
$$
**这个修正的结构值得细看：损失等于肋片面积份额乘以肋片的低效部分。**由于密集阵列的$A _ { f } / A _ { t } = 0 . 9 0$到$0 . 9 7$，**肋基几乎无关紧要，整个阵列就是肋片**——所以密集阵列中$0 . 7 0$的肋效率给出$\eta _ { o } = 0 . 7 2$，对裸露肋基再怎么用心也无济于事。
**于是，安装好的散热器的完整热阻是一个串联链**，把它写出来，是任何电子设备热设计中最有用的五分钟：
$$
R _ { j \to \infty } = R _ { j c } + { \frac { t _ { \text{界面} } } { k _ { \text{界面} } A _ { \text{管壳} } } } + { \frac { 1 } { h _ { b } A _ { \text{底板} } } } + { \frac { 1 } { \eta _ { o } h A _ { t } } }
$$
其中$h _ { b }$是路径中另一个接头（例如用螺栓固定在散热器底板上的均热块）的**接触**热导，$A_{\text{底板}}$是其面积；对于涂了导热脂、按规定力矩拧紧的接头，典型值为$3 0 0 0$到$8 0 0 0\ \mathrm { W / m ^ { 2 } K }$，对于干燥、平整但未经机加工的接头为$2 0 0$到$8 0 0$。**注意加肋片时这条链发生了什么：它缩小了最后一项，而中间两项原封不动。**这就是热工程中最令人泄气的那句话背后的算术——**"你选的散热器只是问题的三分之一。"**
:::

::: example 肋片下面的接头 {#ex-contact}
径向高度$2 0 \ \mathrm { m m }$、厚$1 \ \mathrm { m m }$的铝制环肋以$3 \ \mathrm { m m }$的节距压装在外径$2 5 \ \mathrm { m m }$的管子上，由$h = 4 5 \ \mathrm { W / m ^ { 2 } K }$的强制气流冷却。肋片取$k = 1 8 0 \ \mathrm { W / m \, K }$，压装接头的接触热导取$2 0 0 0 \ \mathrm { W / m ^ { 2 } K }$（即热阻$0 . 0 0 0 5 \ \mathrm { m ^ { 2 } K / W }$）。有和没有这个接头时，每米管长的热阻各是多少？

::: solution
**先求肋效率。**$m = { \sqrt { 2 h / k t } } = { \sqrt { 2 \times 4 5 / ( 1 8 0 \times 0 . 0 0 1 ) } } = 2 2 . 4 \ \mathrm { m ^ { - 1 } }$，又$r _ { 1 } = 1 2 . 5 \ \mathrm { m m }$，$r _ { 2 c } = 3 3 \ \mathrm { m m }$：
$$
\psi = 1 + 0 . 3 5 \ln \left( { \frac { 3 3 } { 1 2 . 5 } } \right) = 1 . 3 4 \qquad m L _ { c } \psi = 2 2 . 4 \times 0 . 0 2 0 5 \times 1 . 3 4 = 0 . 6 1 4 \qquad \eta _ { f } = { \frac { \tanh 0 . 6 1 4 } { 0 . 6 1 4 } } = 0 . 8 9 1
$$
**每米管长的面积**（每米$3 3 3$片肋）：
$$
A _ { f } = 3 3 3 \times 2 \pi \left( 0 . 0 3 3 ^ { 2 } - 0 . 0 1 2 5 ^ { 2 } \right) = 1 . 9 5 4 \ \mathrm { m ^ { 2 } } \qquad A _ { b } = \pi \times 0 . 0 2 5 \times ( 1 - 3 3 3 \times 0 . 0 0 1 ) = 0 . 0 5 2 4 \ \mathrm { m ^ { 2 } }
$$
$$
\eta _ { o } = 1 - { \frac { 1 . 9 5 4 } { 2 . 0 0 6 } } ( 1 - 0 . 8 9 1 ) = 0 . 8 9 4 \qquad R _ { \text{阵列} } = { \frac { 1 } { 0 . 8 9 4 \times 4 5 \times 2 . 0 0 6 } } = \mathbf { 0 . 0 1 2 4 \ \mathrm { K / W } } \ \text{每米}
$$
**现在考虑接头。**一片肋的接触面积是圆环面$2 \pi r _ { 1 } t = 7 . 8 5 \times 1 0 ^ { - 5 } \ \mathrm { m ^ { 2 } }$，所以一片肋带有$0 . 0 0 0 5 / 7 . 8 5 \times 1 0 ^ { - 5 } = 6 . 4 \ \mathrm { K / W }$的接触热阻，$3 3 3$片肋并联后，每米管长降为$0 . 0 1 9 1 \ \mathrm { K / W }$：
$$
R _ { \text{肋片+接触} } = { \frac { 1 } { \eta _ { f } h A _ { f } } } + R _ { \text{接触} } = 0 . 0 1 2 8 + 0 . 0 1 9 1 = 0 . 0 3 1 9 \qquad { \frac { 1 } { R } } = { \frac { 1 } { 0 . 0 3 1 9 } } + { \frac { 1 } { 1 / ( 4 5 \times 0 . 0 5 2 4 ) } } = 3 1 . 4 + 2 . 4 = 3 3 . 7
$$
$$
R _ { \text{有接头} } = \mathbf { 0 . 0 2 9 6 \ \mathrm { K / W } } \ \text{每米} \qquad \text{性能变差 } \mathbf { 2 . 4 } \text{ 倍，肋片工作的 } \mathbf { 6 0 \ \% } \text{ 化为乌有}
$$
**肋效率从未改变；阵列效率从未改变；每一个尺寸都与表格的规定分毫不差。****夺走肋片$6 0 \ \%$贡献的，是一个相当于约$1 3 \ \mu\mathrm { m }$厚空气膜（$0.0005 \times 0.026$）的接头——这就是为什么凡是看重性能的场合，带肋管都采用整体式、挤压式、焊接式或带肩缠绕式肋片。****由此得出设计规则：每片肋的根部接触面只有该肋自身表面积的$1.3\ \%$，而肋片的全部热量都必须穿过它，所以接触热导必须达到$h$的约$75$倍，才仅仅与它所供给的对流相匹配。凡是热量要汇聚穿过一个小接触面时，先检查接触。**

::: example 等质量铝材的两种散热器，选哪一个 {#ex-sink}
一个$6 0\ \mathrm{W}$的器件装在$1 2 0 \times 1 2 0 \times 6\ \mathrm { m m }$的铝底板（$k = 1 8 0$）上，底板带有$1 2 0\ \mathrm{mm}$长的直肋，$3\ \mathrm { m / s }$的强制气流根据阵列疏密给出$h \approx 3 8$到$4 2\ \mathrm { W / m ^ { 2 } K }$。环境温度为$4 5\ {} ^ { \circ } \mathrm { C }$；$R _ { j c } = 0 . 3 5$，界面再增加$0 . 2 5\ \mathrm { K / W }$。比较(a) $1 2$片$1 . 5\ \mathrm{mm}$厚的肋片和(b) $1 8$片$1 . 0\ \mathrm{mm}$厚的肋片，两者都高$6 0\ \mathrm{mm}$。**两种阵列所含铝的体积完全相同。**

::: solution

::: definition 肋片阵列的最优间距 {#def-spacing}
肋片方程中没有任何东西确定节距。确定节距的是**$h$并不独立于节距**：肋片靠拢时，它们的边界层合并，肋间流体不再被冲刷，表面传热系数随之下降。一个在两个极限下都正确、可以使用的模型是
$$
h ( S ) \approx h _ { \infty } \, \frac { S ^ { 2 } } { S ^ { 2 } + S _ { m } ^ { 2 } } , \qquad S _ { m } \sim \frac { 2 k _ { f } } { h _ { \infty } }
$$
其中$S$是相邻肋片之间的间隙，$h _ { \infty }$是孤立肋片的表面传热系数，$S _ { m }$是相邻膜层恰好相接时的间隙。于是高度为$L$、厚度为$t$的平板肋阵列单位**投影**面积的散热量为
$$
q ^ { \prime \prime } = h ( S ) \, \eta _ { f } \, { \frac { 2 L } { S + t } } \, \Delta T \qquad \Longrightarrow \qquad { \frac { d q ^ { \prime \prime } } { d S } } = 0 \quad \Longrightarrow \quad S _ { \text{opt} } ^ { 3 } - S _ { \text{opt} } S _ { m } ^ { 2 } - 2 S _ { m } ^ { 2 } t = 0
$$
$$
\boxed { \; S _ { \text{opt} } \approx ( 1 . 0 \text{ 到 } 1 . 2 ) \, S _ { m } \approx { \frac { 2 k _ { f } } { h _ { \infty } } } \; } \qquad \text{且 } q ^ { \prime \prime } \text{ 的变化小于 } 1 0 \ \% \text{，只要 } 0 . 7 S _ { \text{opt} } < S < 1 . 6 S _ { \text{opt} }
$$
**这条规则只有一行，却比推导更有价值：最优肋片节距约为流体当量导热膜层厚度$k _ { f } / h$的两倍。**对于$k _ { f } = 0 . 0 2 6$的空气：
$$
\begin{array}{l c c l}
h \left( \mathrm { W / m ^ { 2 } K } \right) & S _ { \text{opt} } & \text{典型应用} \\
5 \text{ 到 } 8 \text{（自然对流）} & 7 \text{ 到 } 1 0 \ \mathrm { m m } & \text{挤压型材自然对流散热器、功率电阻} \\
2 0 \text{（轻柔的风扇）} & 2 . 6 \ \mathrm { m m } & \text{低矮型强制风冷散热器} \\
4 0 \text{（3 m/s 轴流风扇）} & 1 . 3 \ \mathrm { m m } & \text{CPU 与逆变器散热器、铲齿肋片} \\
5 0 0 0 \text{（水，} k _ { f } = 0 . 6 \text{）} & 0 . 2 4 \ \mathrm { m m } & \text{微通道冷板，} 0 . 2 \text{ 到 } 0 . 5 \ \mathrm { m m }
\end{array}
$$
**最后一行需要用水自身的导热系数$k_f = 0.6$，而不是空气的。**用了它，规则要求的通道宽约四分之一毫米——这恰恰是**微通道**冷板的尺度，其代价是实实在在的压降和实实在在的污垢问题。**一般的说法是，扩展表面的回报大致与$1/\sqrt{h}$（即肋效能）成正比，所以在液体中，肋片必须短、相对其高度要厚，而且排列紧密。**
:::

::: example 一片效率只有六成却完全正确的肋片 {#ex-60}
一片不锈钢（$k = 1 6 \ \mathrm { W / m \, K }$）肋片厚$1 . 5\ \mathrm{mm}$、高$2 5\ \mathrm{mm}$，位于$h = 4 5 \ \mathrm { W / m ^ { 2 } K }$的风道中。它的肋效率是$0 . 5 8$。应该更换它吗？

::: solution
回答之前先算出另一个数。矩形肋的肋效能，取自[[#ex-ss]]的$m L_c = 1.58$：
$$
\varepsilon _ { f } = { \sqrt { \frac { 2 k } { h t } } } \tanh m L _ { c } = { \sqrt { \frac { 3 2 } { 4 5 \times 0 . 0 0 1 5 } } } \times 0 . 9 1 8 = 2 1 . 8 \times 0 . 9 1 8 = 2 0 . 0
$$
**什么也不用换。**这片肋散出的热量是同形状等温肋片的$5 8\ \%$，是它所占据的那条$1 . 5\ \mathrm{mm}$宽壁面的二十倍。**肋效率低是因为金属导热差，而不是因为肋片比例不当**——而改进低效率肋片的办法，按性价比排序依次是：**做短**（高度减半使$m L _ { c }$从$1 . 5 8$降到$0 . 8 1$，$\eta _ { f }$升到$0 . 8 3$，代价是面积减半），**做厚**（$t$增到$8\ \mathrm{mm}$：$\eta _ { f } = 0 . 8 4$，代价是五倍的质量，每米的肋片数也少五倍），或**换金属**（$k = 4 0 1$的铜给出$\eta _ { f } = 0 . 9 7$，前提是使用条件允许用铜）。
**肋片之所以一开始就用不锈钢，几乎总是出于腐蚀、温度或强度的原因——在这三种情况下材料都没有商量余地，所以唯一的杠杆是几何形状。****正确的设计举措是肋效率指向、肋效能允许的那一个：保留不锈钢，把肋片截短，直到$m L _ { c } \approx 1$。**
:::

## 二维导热

::: definition 热流图（流网） {#def-fluxplot}
对于无内热源的二维稳态导热，$T$满足拉普拉斯方程，其解可以**画出来**。等温线与绝热线（热流线）以直角相交，若选择间距使每个单元都是曲边**正方形**，整个问题就归结为计数：
$$
\boxed { \; q = { \frac { M } { N } } \, k \, \Delta T \, w \; }
$$
其中$M$是热流通道数，$N$是温度间隔数，$w$是垂直于图面的厚度。**与$q = S k \Delta T w$比较可知$M / N$就是单位厚度的形状因子**——所以热流图就是用铅笔进行的形状因子测量，在熟练者手中精确到$2$到$5\ \%$。
**作图规则有四条，第四条是最容易让人出错的。**
**(i) 在对称性要求的地方先画绝热线**，而不是在方便的地方画：几何和温度上的对称线是绝热线，等温边界是等温线。
**(ii) 让正方形真正是正方形。**曲边正方形的两条对角线长度近似相等；挑一些单元画出两条对角线来检查。
**(iii) 在正方形变小的地方加密**，因为那里热流密度最高，答案也在那里决定。
**(iv) 在整个求解域上数$M$和$N$，而不是在四分之一上数**——或者在四分之一上数，然后把$M$乘以对称重复的次数而$N$保持不变。**把两者都乘以四是经典错误，而且在图上看不出来。**
:::

::: definition 扩散热阻 {#def-spreading}
当在一个小区域内产生的热量必须进入一个大物体时，热流线发散，热阻远大于一维估计$L / ( k A )$所暗示的值。对于导热系数为$k$的**半无限大物体**表面上面积为$A _ { s }$的小等温热源，
$$
\boxed { \; R _ { \text{扩散} } = { \frac { 1 } { 4 k { \sqrt { A _ { s } / \pi } } } } \; } \qquad \text{（半无限大物体，热源位于表面）}
$$
**只要热源形状大致是圆的，这个结果就与热源形状无关（误差在百分之几以内），它有两个性质支配着电子设备的热设计。**
**(i) 它不含物体的厚度。**一旦盖板的厚度和宽度都是热源尺寸的好几倍，它的表现就如同半无限大物体，再加厚几乎不改变扩散热阻——**这就是为什么"把盖板加厚"往往是对热点的无用回应。**（比热源尺寸薄得多的盖板则是另一回事：那里扩散热阻随盖板变薄而增大。）
**(ii) 它按$1 / \sqrt { A _ { s } }$变化，而不是$1 / A _ { s }$。****把正方形热源的边长加倍，扩散热阻减半；把它的面积加倍，只使扩散热阻减小$29\ \%$。**由此得到的推论正是人们实际去做的：**代价最低的大幅改善，是一开始就让热量在更大的面积上进入**，这正是均热板、铜盖板或石墨均热片所做的：它们都在热量进入主路径之前把等温线向外推移。
:::

::: example 芯片下面的热点 {#ex-spread}
一块$3 \times 3 \ \mathrm{mm}$的硅芯片均匀地耗散$1 8 \ \mathrm{W}$，焊接在一块厚$5\ \mathrm{mm}$、$4 0 \times 4 0 \ \mathrm{mm}$的铜盖板（$k = 4 0 1 \ \mathrm { W / m \, K }$）上，盖板外表面由$4 0 \ {} ^ { \circ } \mathrm { C }$的冷板以$h = 9 0 0 0 \ \mathrm { W / m ^ { 2 } K }$冷却。估算芯片与冷板之间的温差。

::: solution
**三个热阻串联。**从芯片扩散到盖板，以半无限大物体的值为上界：
$$
a = { \sqrt { \frac { 9 \times 1 0 ^ { - 6 } } { \pi } } } = 1 . 6 9 3 \times 1 0 ^ { - 3 } \ \mathrm { m } , \qquad R _ { \text{扩散} } \le { \frac { 1 } { 4 \times 4 0 1 \times 1 . 6 9 3 \times 1 0 ^ { - 3 } } } = 0 . 3 6 8 \ \mathrm { K / W }
$$
穿过盖板的一维导热，$R = t / ( k A ) = 0 . 0 0 5 / ( 4 0 1 \times 0 . 0 0 1 6 ) = 0 . 0 0 7 8 \ \mathrm { K / W }$。冷板膜层，$R = 1 / ( 9 0 0 0 \times 0 . 0 0 1 6 ) = 0 . 0 6 9 4 \ \mathrm { K / W }$。
$$
\Delta T = 1 8 \times ( 0 . 3 6 8 + 0 . 0 0 7 8 + 0 . 0 6 9 4 ) = 1 8 \times 0 . 4 4 5 = \mathbf { 8 . 0 \ K } , \qquad T _ { \text{芯片} } \approx 4 8 \ {} ^ { \circ } \mathrm { C }
$$
**扩散项占总量的$8 3\ \%$，$5\ \mathrm{mm}$的铜盖板贡献$1 . 8\ \%$，而非常昂贵的冷板贡献$1 6\ \%$。****这就是业内每一块盖板、均热片和均热板背后的算术：解决热点的办法不是缩短导热路径或让冷却剂更冷，而是让热源在热学上变大——也就是说，在热量必须穿透之前先把它扩散开。**一块有效面内导热系数为$5 0 0 0 \ \mathrm { W / m \, K }$量级的均热板盖板，按同样的半无限大物体估计，会把扩散项降到约$0 . 0 3 \ \mathrm { K / W }$，并把整个$8\ \mathrm{K}$的问题转移到界面和冷板上，在那里可以用导热脂和流量来对付它。
:::

## 自己动手

::: exercise 静止空气中的铝肋片 {#ex-al level=1 check="0.995"}
一片平直的铝肋片（$k = 1 8 0 \ \mathrm { W / m \, K }$）厚$1 . 0 \ \mathrm{mm}$、高$1 2 \ \mathrm{mm}$，周围空气给出$h = 8 \ \mathrm { W / m ^ { 2 } K }$。它的肋效率是多少？

::: solution
对于单位深度的平板肋，$P = 2$，$A _ { c } = t$：
$$
m = { \sqrt { \frac { 2 h } { k t } } } = { \sqrt { \frac { 1 6 } { 1 8 0 \times 0 . 0 0 1 } } } = 9 . 4 3 \ \mathrm { m ^ { - 1 } } , \qquad L _ { c } = 0 . 0 1 2 5 \ \mathrm { m } , \qquad m L _ { c } = 0 . 1 1 8
$$
$$
\eta _ { f } = { \frac { \tanh 0 . 1 1 8 } { 0 . 1 1 8 } } = \mathbf { 0 . 9 9 5 }
$$
**实际上是完美的，而这正是空气中铝肋片的正常答案。**肋片自身的长度尺度$1/m = 106\ \mathrm{mm}$接近其高度的九倍，所以温度沿肋片几乎不降。**推论是：在空气中，铝肋片受限于你能买到多少面积，而不是这些面积发挥得多好——这恰恰是最优间距规则所针对的情形。**
:::

::: exercise 换成不锈钢的同类肋片 {#ex-ss level=1 check="0.58"}
一片不锈钢肋片（$k = 1 6 \ \mathrm { W / m \, K }$）厚$1 . 5 \ \mathrm{mm}$、高$2 5 \ \mathrm{mm}$，位于$h = 4 5 \ \mathrm { W / m ^ { 2 } K }$的风道中。它的肋效率是多少？

::: solution
$$
m = { \sqrt { \frac { 2 \times 4 5 } { 1 6 \times 0 . 0 0 1 5 } } } = { \sqrt { 3 7 5 0 } } = 6 1 . 2 \ \mathrm { m ^ { - 1 } } , \qquad m L _ { c } = 6 1 . 2 \times 0 . 0 2 5 7 5 = 1 . 5 8
$$
$$
\eta _ { f } = { \frac { \tanh 1 . 5 8 } { 1 . 5 8 } } = { \frac { 0 . 9 1 8 } { 1 . 5 8 } } = \mathbf { 0 . 5 8 }
$$
**九分之一的导热系数、$5.6$倍的表面传热系数，再加上更厚更高的肋片，共同把参数从[[#ex-al]]中的$m L _ { c } = 0 . 1 2$推到$1 . 5 8$——增大了十三倍，肋效率下降了$4 1$个百分点。****经验法则：肋片的好坏取决于$k / ( h t )$所允许的程度，而由于$1/m \propto \sqrt{k}$，在相同的$h$和厚度下从铝换成不锈钢，可用的肋片高度约减为三分之一。**
:::

::: exercise 那片不锈钢肋片值多少？ {#ex-effec level=1 check="20.0"}
对于[[#ex-ss|不锈钢肋片习题]]中的不锈钢肋片，它相对于所立足的裸壁的肋效能是多少（用修正长度的肋端绝热结果）？

::: solution
对于单位深度的矩形肋，$P = 2$，$A _ { c } = t$，且$m L_c = 1.58$：
$$
\varepsilon _ { f } = { \sqrt { \frac { P k } { h A _ { c } } } } \tanh m L _ { c } = { \sqrt { \frac { 2 \times 1 6 } { 4 5 \times 0 . 0 0 1 5 } } } \times 0 . 9 1 8 = 2 1 . 8 \times 0 . 9 1 8 = \mathbf { 2 0 . 0 }
$$
**是裸壁的二十倍，而肋效率为$5 8\ \%$**（仅用长肋极限会给出$21.8$）。**这两个数并不矛盾：肋效率问的是肋片自身的面积被利用得多好，肋效能问的是这片肋片该不该存在，而第二个问题必须先回答。****这个公式也说明了为什么肋效能随$h$的减小而提高：$\varepsilon _ { f } \propto 1 / { \sqrt { h } }$，所以在长肋极限下，同一片肋片在$h = 6$的静止空气中可达约$6 0$，而不是$2 2$——扩展表面是这样一剂药：病根越重的地方，药效越强。**
:::
:::

::: exercise 管子上的环肋 {#ex-ann level=2 check="0.92"}
一片钢制（$k = 1 6 \ \mathrm { W / m \, K }$）环肋厚$1 . 5 \ \mathrm{mm}$，从$r _ { 1 } = 1 5 \ \mathrm { m m }$延伸到$r _ { 2 } = 2 5 \ \mathrm { m m }$，$h = 2 0 \ \mathrm { W / m ^ { 2 } K }$。估算它的肋效率。

::: solution
用施密特近似，采用修正半径和修正长度：
$$
L _ { c } = 0 . 0 1 0 + 0 . 0 0 0 7 5 = 0 . 0 1 0 7 5 \ \mathrm { m } , \qquad m = { \sqrt { \frac { 2 \times 2 0 } { 1 6 \times 0 . 0 0 1 5 } } } = 4 0 . 8 \ \mathrm { m ^ { - 1 } } , \qquad m L _ { c } = 0 . 4 3 9
$$
$$
\psi = 1 + 0 . 3 5 \ln \left( { \frac { 0 . 0 2 5 7 5 } { 0 . 0 1 5 } } \right) = 1 + 0 . 3 5 \times 0 . 5 4 0 = 1 . 1 8 9 , \qquad m L _ { c } \psi = 0 . 5 2 2
$$
$$
\eta _ { f } = { \frac { \tanh 0 . 5 2 2 } { 0 . 5 2 2 } } = \mathbf { 0 . 9 2 }
$$
**与[[#ex-ss|不锈钢肋片习题]]比较：同样金属和厚度的直肋，在更高的表面传热系数（$h = 4 5$）下，高$2 5 \ \mathrm{mm}$时只达到$0 . 5 8$，而这片环肋在$h = 2 0$下、高$1 0 \ \mathrm{mm}$时达到$0 . 9 2$。**这是肋片更短和$h$更低的结果；环形几何本身的作用方向相反，$\psi = 1.19$使肋片表现得好像长了$19\ \%$。不计$\psi$，$m L_c = 0.439$的直肋效率为$0.94$。

::: exercise 是阵列，而不是肋片 {#ex-array level=1 check="0.83"}
某散热器的肋片占其总表面积的$9 2\ \%$，肋效率为$0 . 8 2$。肋壁总效率是多少？

::: solution
$$
\eta _ { o } = 1 - { \frac { A _ { f } } { A _ { t } } } \left( 1 - \eta _ { f } \right ) = 1 - 0 . 9 2 \times 0 . 1 8 = \mathbf { 0 . 8 3 }
$$
**裸露的肋基只稍微改变答案：如果肋片占面积的$80\ \%$而不是$92\ \%$，$\eta _ { o }$将为$0 . 8 6$。****这个公式提醒你该往哪里看。**在密集阵列中，整个表面就是肋片，所以任何改进都必须来自$\eta _ { f }$——更厚的金属、更短的肋片或更高的导热系数——而**最省钱的推论是：如果你在密集阵列中要在更好的肋片材料和更好的肋基接头之间做选择，你是在影响$92\ \%$表面的东西和影响$8\ \%$表面的东西之间做选择。**
:::
:::

::: exercise 托架的热流图 {#ex-net level=2 check="12"}
一个混凝土托架，垂直于图面的厚度为$2 0 0 \ \mathrm{mm}$，导热系数为$1 . 2 \ \mathrm { W / m \, K }$，用流网求解：在温差为$1 0 0 \ \mathrm{K}$的两个表面之间有$8$个热流通道和$1 6$个温度间隔。热流量是多少瓦？

::: solution
$$
q = { \frac { M } { N } } \, k \, \Delta T \, w = { \frac { 8 } { 1 6 } } \times 1 . 2 \times 1 0 0 \times 0 . 2 0 0 = \mathbf { 1 2 \ W }
$$
**单位厚度的形状因子为$M / N = 0 . 5$，即对这个托架$S = 0 . 1 0 \ \mathrm { m }$。****任何手绘流网都值得做两项检查。**第一，**在整个求解域上计数**：如果流网是利用对称性画在四分之一上的，则$M$为$4 \times 8 = 3 2$而$N$仍为$1 6$，给出$q = 4 8 \ \mathrm{W}$，而把两者都乘以四的错误会造成四倍的误差。第二，**流网必须处处是正方形**：如果热角附近的单元明显被拉长，局部热流就被少计了，总量会偏低。**一张热流图要花二十分钟，精确到百分之几；同一个托架的粗糙有限元模型也要花同样的二十分钟，如果网格经过斟酌，精确到百分之十，而流网的优点是你能看出它哪里错了。**
:::
:::

::: exercise 扩散一个较小的热源 {#ex-spread2 level=2 check="0.37"}
一个$3 . 0 \times 3 . 0 \ \mathrm{mm}$的正方形热源位于一块大铜块（$k = 4 0 1 \ \mathrm { W / m \, K }$）的表面上。估算扩散热阻，单位为K/W。

::: solution
$$
a = { \sqrt { \frac { A _ { s } } { \pi } } } = { \sqrt { \frac { 9 . 0 \times 1 0 ^ { - 6 } } { \pi } } } = 1 . 6 9 3 \times 1 0 ^ { - 3 } \ \mathrm { m } , \qquad R _ { \text {扩散 } } = { \frac { 1 } { 4 k a } } = { \frac { 1 } { 4 \times 4 0 1 \times 1 . 6 9 3 \times 1 0 ^ { - 3 } } } = \mathbf { 0 . 3 7 \ K / W }
$$
**在$1 8 \ \mathrm{W}$下，这就是$6 . 6 \ \mathrm{K}$——比典型冷板的全部温降还大。****现在把热源减小到$1 . 5 \times 1 . 5 \ \mathrm{mm}$，面积变为四分之一：**$a$减半，$R$加倍到$0 . 7 4 \ \mathrm { K / W }$。**标度关系$R \propto 1 / \sqrt { A _ { s } }$意味着把同样的功率集中到更小的热源上会提高它的扩散温升：面积变为四分之一，温升加倍。**均热盖板和均热板的作用，就是在热量进入主导热路径之前扩大有效热源面积。
:::

::: exercise 把肋片高度加倍 {#ex-double level=2 check="1.26"}
[[#ex-sink|两种散热器例题]]中$1 . 5 \ \mathrm{mm}$的铝肋片高$6 0 \ \mathrm{mm}$，处于$h = 3 8 \ \mathrm { W / m ^ { 2 } K }$的空气中。如果高度加倍到$1 2 0 \ \mathrm{mm}$，一片肋片的散热量增大为原来的多少倍？

::: solution
两种情况下都是$m = 1 6 . 7 8 \ \mathrm { m ^ { - 1 } }$，且$q \propto \tanh m L _ { c }$：
$$
m L _ { c 1 } = 1 6 . 7 8 \times 0 . 0 6 0 7 5 = 1 . 0 1 9 \quad \Longrightarrow \quad \operatorname { t a n h } = 0 . 7 6 9
$$
$$
m L _ { c 2 } = 1 6 . 7 8 \times 0 . 1 2 0 7 5 = 2 . 0 2 6 \quad \Longrightarrow \quad \operatorname { t a n h } = 0 . 9 6 6 \qquad \Longrightarrow \qquad \mathbf { 1 . 2 6 }
$$
**用两倍的金属和两倍的机箱高度，只换来多百分之二十六的热量。****再加倍到$2 4 0 \ \mathrm{mm}$，答案是$1 . 3 0$——肋片已趋于渐近值，因为长肋的热流量为$\sqrt { h P k A _ { c } } \, \Delta T$，其中根本不含长度。****反方向的同一算术才是更好的设计举措：截短到$3 0 \ \mathrm{mm}$保留了一片肋片$6 1\ \%$的散热量，金属却减半，于是同样的底板上能放下两倍的肋片——阵列在铝的质量完全相同的情况下多散出$2 3\ \%$的热量。****这里假定$h$不变：在$h \approx 38$的强制风冷中，间距规则给出$2 k_f / h \approx 1.4\ \mathrm{mm}$，所以把节距从$10$减半到$5\ \mathrm{mm}$（间隙$3.5\ \mathrm{mm}$）仍能使边界层保持分开——不过风扇的压降会增大，这一点必须核查。**按挤压机的能力而不是按$1 / m$确定尺寸的肋片，是一种常见的浪费。
:::

::: quiz 好肋片 {#quiz-good}
一片肋片的肋效率为$0 . 5 8$，肋效能为$2 4$。另一片肋片的肋效率为$0 . 9 7$，肋效能为$1 . 6$。两者占据相同的肋基面积。应该安装哪一片？

- [ ] 第二片，因为效率$9 7\ \%$的金属显然比效率$5 8\ \%$的金属好
- [x] 第一片，因为肋效能——相对于它所覆盖的裸肋基所传递的热量——才决定一片肋片是否值得安装
- [ ] 都可以：这两个数是衡量同一件事的两种方式
- [ ] 都不行：任何肋效率低于$60\ \%$的肋片都应当先重新设计

::: solution
**第一片，理由是肋效能。**第一片肋散出的热量是裸肋基的$2 4$倍；第二片是$1 . 6$倍。**第二片肋的高效率恰恰诊断出了它自身的失败：$\eta _ { f } \to 1$意味着$m L \ll 1$，一片又短又粗、几乎等温、却几乎没有给它所覆盖的肋基增加面积的肋片——$1.6$的肋效能说的正是这一点。**
**这两个数并不是对同一件事的两种度量：$\eta _ { f }$是肋片形状的性质，$\varepsilon _ { f }$是决策的性质。****这道题设下的陷阱是"效率"这个词：在日常语言中，效率$5 8\ \%$的任何东西都是糟糕的东西，而在肋片工作中，效率$5 8\ \%$的肋片往往是更好的肋片。**
:::

::: quiz 密集的散热器 {#quiz-dense}
一个自然对流散热器的肋片高$5 0 \ \mathrm{mm}$、厚$1 \ \mathrm{mm}$、间距$3 \ \mathrm{mm}$。一位同事提议做一个底板和肋高都相同、但间距为$1 0 \ \mathrm{mm}$的版本，肋片数大约只有三分之一。会怎样？

- [ ] 变差，因为损失了三分之二的表面积
- [x] 变好，而且好很多倍，因为在$3 \ \mathrm{mm}$节距下边界层已经合并，大部分面积没有被利用
- [ ] 不变，因为面积与表面传热系数的乘积是固定的
- [ ] 取决于环境温度

::: solution
**会好得多。**对于空气中的自然对流，最优间隙为$S _ { \text{opt} } \approx 2 k _ { f } / h _ { \infty } \approx 2 \times 0 . 0 2 8 / 5 . 5 \approx 1 0 \ \mathrm { m m }$，而用上面那幅图的模型（它恰好就是这些肋片），$3 \ \mathrm{mm}$间隙下的阵列单位投影面积散出约$1 1 \ \mathrm { W / m ^ { 2 } K }$，而$1 0 \ \mathrm{mm}$时为$2 4$——**不到同一底板所能做到的一半**。**把肋片数减到约三分之一，去掉了三分之二的面积，却使表面传热系数成倍增大，乘积提高到约$2 . 2$倍。**肋效率略有下降，因为$m \propto \sqrt{h}$，但在这样的表面传热系数下，$50\ \mathrm{mm}$的铝肋片效率仍保持在$90\ \%$以上。
**错误答案之所以诱人，是因为它用了正确的公式和错误的$h$：**$R = 1 / ( \eta _ { o } h A _ { t } )$说"面积越小，热阻越大"，**只有当$h$是常数时才成立，而在阵列中$h$不是常数。****普遍的教训正是本讲存在的意义：肋片阵列不是一群独立肋片的集合，任何把它当作这样一群肋片的计算，都会叫你没完没了地增加肋片。**
:::

## 后续内容

到目前为止，本课程的一切都假定换热表面处于同一个温度，且表面传热系数$h$是一个交到你手上的数。**肋片打破了第一个假定——表面温度现在是位置的函数，由它本身被用来计算的那个热流决定——而接下来的四讲就是为了打破第二个假定。**表面传热系数$h$是对流传热的主题，而对流传热是动量方程与能量方程的联立解，肋片自身的温度分布则作为流体的边界条件出现。这种耦合就是为什么对流关联式要注明是针对**恒壁温**还是**恒热流**，也是为什么实际阵列中的肋片介于两者之间：自然对流肋片的肋基接近等温，肋端接近绝热，你所用的关联式应当是其假定与你的情况最接近的那一个。

本讲有两条线索延续下去。**最优间距的结果是本课程中第一个来自物理而不是来自成本函数的设计最优值**——边界层合并，单位投影面积的散热量存在一个真实的极大值，而不是两种预算之间的折中。同样的结构会再次出现在管内对流一讲的微通道设计中、换热器一讲的管翅式几何中，并以一般形式出现在贝冉（Bejan）的体点问题中：**给定一个发热的体积和一个排热的位置，导热材料的最优分布是一棵树。**第二条线索是扩散热阻，它是整个现代电子冷却成为一个关于横向而不是穿透地输送热量的故事的原因。

还有一个警告值得重复，因为它是这一领域最常见的错误。**肋片阵列不是肋片。**上面的效率公式针对的是处于未受扰动来流中的孤立肋片，而在密集阵列中，来流受到扰动，表面传热系数更低，肋基更热，整个计算必须对照实测的阵列数据来做。**散热器的产品目录曲线是阵列的测量结果，而不是肋片的计算结果；一旦你发现自己在计算肋效率来核对目录上的数字，你就应该问一问：目录中的$h$是否是在你的流量下、你的安装方位下、并且有你的电缆挡在那里时测得的。**

::: summary
- **肋片方程是$\theta ^ { \prime \prime } = m ^ { 2 } \theta$，其中$m = \sqrt { h P / k A _ { c } }$**，$1 / m$是肋片过余温度衰减的距离。**比$1 / m$长好几倍的肋片只是装饰。**
- **肋效率$\eta _ { f } = \tanh m L _ { c } / m L _ { c }$衡量的是金属；肋效能$\varepsilon _ { f } = \sqrt { P k / h A _ { c } } \tanh m L_c$衡量的是决策。**先回答第二个问题，也永远不要因为一片肋片的效率只有$6 0 \ \%$就否定它。
- **常用的设计窗口是$m L _ { c } \approx 0 . 5$到$1 . 0$，$\eta _ { f } \approx 0 . 9 2$到$0 . 7 6$。**远低于此，肋片几乎等温，可以做得更高或更薄；远高于此，肋端几乎不起作用。
- **肋效能按$1 / \sqrt { h }$变化。**肋片是弥补流体之不足的办法：对于$1\ \mathrm{mm}$的铝肋片，在静止空气中可达$2 4 5$倍，在水中为$1 1$倍，在沸腾水中为$6$倍。
- **阵列满足$\eta _ { o } = 1 - ( A _ { f } / A _ { t } ) ( 1 - \eta _ { f } )$，在密集阵列中肋基无关紧要。**一切都在肋片上，而肋基下面的接头是一个单独的热阻，任何肋片都帮不上忙。
- **最优节距为$S \approx 2 k _ { f } / h _ { \infty }$**——空气自然对流约为$1 0 \ \mathrm{mm}$，$h = 40$时为$1 . 3 \ \mathrm{mm}$，在水中约为$0 . 2 5 \ \mathrm{mm}$——即微通道冷板的尺度。
- **最优值是平坦的。**从最佳间隙的约三分之二到一倍半，性能变化不到$10\ \%$，所以选择装得下、易清洁、成本最低的散热器。
- **把肋片高度加倍，得到的是增量的$\tanh$，而不是增量本身**：对$m L _ { c } = 1 . 0$的肋片为$+ 2 6\ \%$，对$m L _ { c } = 2$的肋片为$+ 3 . 7 \ \%$。
- **热流图通过数曲边正方形给出$q = ( M / N ) k \Delta T w$**，精确到百分之几，并表明$M / N$就是单位厚度的形状因子。
- **进入半无限大物体的扩散热阻为$1 / ( 4 k \sqrt { A _ { s } / \pi } )$**，一旦物体厚度达到热源尺寸的好几倍，它就与物体厚度无关。更厚的盖板对热点帮助不大；更大的有效热源面积则帮助很大。
:::

- **W. Elenbaas**，《平行平板的自然对流散热》（*Heat dissipation of parallel plates by free convection*），*Physica* 9（1942）——经验法则背后的测量。
- **D. Q. Kern**，*Process Heat Transfer*（McGraw-Hill，1950；有重印本）——换热器工况下的肋效率，包括带肋套管式换热器。
- **A. Bejan & S. Lorente**，*Design with Constructal Theory*（Wiley，2008）——把树形导热路径和肋片组合作为一种设计方法来处理。
- **JEDEC JESD51 系列**——集成电路封装的热测试标准：结-壳热阻和结-环境热阻如何测量，以及为什么不同测试条件下的数字不可比较。
