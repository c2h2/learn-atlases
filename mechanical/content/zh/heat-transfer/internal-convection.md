管子是人类发明过的最常见的换热元件，它有一个任何平板都没有的性质：**流出管子的流体记得发生在它身上的一切。** 在平板上方，来流是无限的、不变的、健忘的；而在管道内部，从进口进入的同一批分子仍然留在管道里，吸收热量，增厚边界层，并拖着整个温度场一起向前。**因此，管内强制对流是一个记账问题——对流体本身的能量平衡、壁面影响所能达到的长度，以及一个说明流动混合得有多好的关联式。** 把这三件事理清楚，本课程中每一项管内侧计算都化为算术。

记账从一个无法用温度计测量的温度开始。**平均温度（混合平均温度）$T _ { m } ( x )$的定义使得$\dot { m } c _ { p } T _ { m }$等于穿过某一截面的热能通量，它就是在该截面处放置一个杯子所收集到的流体的温度——而不是温度分布的面积平均值，因为轴线附近的快速流体每秒携带的能量比壁面处的慢速流体更多。** **每一个管内流动关联式都在$T _ { m }$下取值，每一个壁面与流体之间的温差都是$T _ { s } - T _ { m }$，而整个学科的控制方程只有一行：$\mathrm { d } T _ { m } / \mathrm { d } x = q _ { s } ^ { \prime } / ( \dot { m } c _ { p } )$——平均温度以壁面供热的速率升高，再除以流体的热容量流率。** 本课其余的一切都是对这一行的注释：当你试图使用$h$时它是什么，以及壁面条件对答案有什么影响。

这些注释分为两种流态，而两者的差别之大几乎令人尴尬。**层流是一个带记忆的扩散问题：答案取决于管道形状、壁面条件和长度，而充分发展的答案$\mathrm { N u } = 3 . 6 6$如此之小，以至于一米长的层流水管几乎算不上换热器——入口段处的$\mathrm { N u }$可达其两倍，它不是一项修正，而是设计的全部。** **湍流是一个混合问题：涡旋把温度分布压平，充分发展时的表面传热系数非常大，入口段只有十倍管径长且很快被遗忘，而答案是一个附带$\pm 2 5 \ \ \%$分散带的关联式——求快用迪图斯-贝尔特（Dittus–Boelter），求准用格尼林斯基（Gnielinski）。** 两者之间是$\mathrm { R e } \approx 2 3 0 0$到$1 0 { , } 0 0 0$的过渡区，在那里，老实的回答是没有人能告诉你你的管子会怎样表现，而且在那里默默地达不到设计性能的换热器比在其他任何流态下都多。

::: warning 管内强制对流的五种错误，按代价大小排序
**在过渡区使用湍流关联式。** 一台在$\mathrm { R e } = 4 5 0 0$下用格尼林斯基关联式设计的管式换热器得到$\mathrm { N u } \approx 3 4$；而一根真实的、光滑的、平静的、无振动的管子在这个雷诺数下可以保持层流，并根据长度给出介于$4$与$1 4$之间的$\mathrm { N u }$——**缺少三倍或更多的面积，这也是水侧设计流速几乎总是取在$\mathrm { R e } = 1 0 { , } 0 0 0$以上、流动毫无疑问是湍流的原因。** **反过来的错误同样常见，后果却轻一些：把一根在$\mathrm { R e } = 4 0 0 0$下工作、有污垢、粗糙且振动的管子当作层流来设计，而它实际上处于过渡和湍流状态，结果为你并不需要的金属付钱。** **使用错误的参考温度。** 迪图斯-贝尔特关联式的全部物性都在**主流平均温度**下取值；西德-塔特（Sieder–Tate）关联式增加了一个壁面黏度因子$( \mu / \mu _ { s } ) ^ { 0 . 1 4 }$；外部流动的膜温度在任何管内关联式中都没有位置。**对油来说，这并非吹毛求疵：在$6 0 \ \mathrm { K }$的壁面冷却温差下，机油的黏度在主流与壁面之间相差五倍，而$0 . 1 4$次方把它变成$2 5 \ \ \%$的修正，比关联式本身的误差还大。** **混淆两种壁面条件。** 在恒热流密度下$\mathrm { N u } = 4 . 3 6$，壁面与流体之间的温差**沿管长不变**；在恒壁温下$\mathrm { N u } = 3 . 6 6$，这个温差**按指数衰减**。**对相同的总热负荷，恒热流密度的管子在末端的壁温更高——在长管中温差相差两倍——而如果热负荷关系到沸腾、裂解或燃料液膜结焦的限值，那么壁温就是设计约束，壁面条件就是设计本身。** **不加思考地把圆管答案用于非圆形管道。** 当量直径（水力直径）$D _ { h } = 4 A _ { c } / P$能把湍流挽救到$1 0 \ \ \%$以内，却**毁掉层流**：大宽高比的平行平板通道有$\mathrm { N u } _ { D _ { h } } = 7 . 5 4$，而圆管为$3 . 6 6$——**通过$D _ { h }$套用圆管数值，会把板式换热器的层流性能低估一半。** **忘记管子还需要用泵输送流体。** 在湍流中，质量流量固定时表面传热系数按$D ^ { - 1 . 8 }$变化，压降按$D ^ { - 4 . 8 }$变化——**把管径减半换来$3 . 5$倍的表面传热系数（每米管长的热导为$1 . 7 4$倍，因为每米的面积减半），代价是$2 8$倍的泵送压力，而每一块钻过孔的管板都位于这条权衡曲线上的某处。** **在流量方向上也是同样的交易：流量加倍换来多$7 4 \ \ \%$的传热量，代价是$7$倍的泵功率。**
:::

## 平均温度：运动流体的记账

::: definition 平均温度（主流温度、混合平均温度） {#def-mean}
穿过管道截面的能量通量为$\rho c _ { p } \int u ( r ) T ( r ) \, d A$；**平均温度**$T _ { m }$的定义使这一通量等于$\dot { m } c _ { p } T _ { m }$：
$$
\boxed { \; T _ { m } ( x ) = { \frac { \int _ { A } u ( r , x ) \, T ( r , x ) \, d A } { \int _ { A } u ( r , x ) \, d A } } \; } \qquad \dot { m } = \rho U _ { m } A _ { c }
$$
**三种解读。** **(i) 它是按通量加权的平均值，而不是面积平均值：** 快速的核心区权重更大，因为它每秒携带更多的能量。对于充分发展的湍流速度分布，除紧贴壁面的一薄层外，速度都接近$U _ { m }$，两种平均值相差在百分之几以内；对于层流的抛物线分布，两者可以相差百分之几十，因为壁面附近停滞的、在热上已经达到平衡的流体几乎不携带什么。
**(ii) 它就是杯子测得的温度。** 用热电偶探测管道，读到的是介于当地温度与平均温度之间的某个值；把该截面处的流体收集到杯子里，让它混合，你得到的恰好就是$T _ { m }$——“混合杯温度”的名称由此而来。**这就是为什么每一个管内流动关联式都注明物性在$T _ { m }$下取值：关联式是对$q = \dot { m } c _ { p } ( T _ { m , \text{out} } - T _ { m , \text{in} } )$的测量值拟合出来的，而实验室里没有其他任何东西是可以直接测量的。**
**(iii) 它是能量方程所知道的唯一温度。** 对一个壁面热流密度为$q _ { s } ^ { \prime \prime }$、周长为$P$的微元段$d x$作总体平衡，对于轴向导热可忽略、无轴功的不可压缩流动，得到
$$
\boxed { \; { \frac { \mathrm { d } T _ { m } } { \mathrm { d } x } } = { \frac { P q _ { s } ^ { \prime \prime } } { \dot { m } c _ { p } } } = { \frac { q _ { s } ^ { \prime } } { \dot { m } c _ { p } } } \; } \qquad q _ { s } = \dot { m } c _ { p } \left( T _ { m } ( L ) - T _ { m } ( 0 ) \right )
$$
**平均温度以壁面供热的速率升高，再除以流体的热容量流率$\dot { m } c _ { p }$——这一行在层流、湍流、发展中的流动、有壁面吹气、物性随温度变化的情况下都成立，无论你是否写下过努塞尔数。** 它是应用于一根流管的热力学第一定律，也是每一项管子设计的起点：不是问“$h$是多少？”，而是问“流体的温度必须怎样变化，这需要多少壁面？”
:::

::: definition 两种壁面条件，以及为什么这一选择不是表面文章 {#def-wallcond}
当地牛顿冷却公式为$q _ { s } ^ { \prime \prime } ( x ) = h ( x ) \left[ T _ { s } ( x ) - T _ { m } ( x ) \right ]$，把它与能量平衡联立，得到两个有不同答案的典型问题：
$$
\begin{array} { l l l }
\textbf{恒热流密度} \; q _ { s } ^ { \prime \prime } = \text{const} & { T _ { m } } \text{ 线性升高；} & { T _ { s } - T _ { m } = q _ { s } ^ { \prime \prime } / h = \text{在充分发展流动中为常数} } \\
\textbf{恒壁温} \; T _ { s } = \text{const} & { T _ { m } } \text{ 按指数趋近 } T _ { s } \text{；} & q _ { s } ^ { \prime \prime } \text{ 沿管长衰减}
\end{array}
$$
对于恒壁温情形，在$h$为常数时，从两个加框方程中消去$q _ { s } ^ { \prime \prime }$，得到一个关于$T _ { s } - T _ { m }$的常微分方程：
$$
\boxed { \; { \frac { T _ { s } - T _ { m } ( x ) } { T _ { s } - T _ { m } ( 0 ) } } = \exp \! \left( - { \frac { P h x } { \dot { m } c _ { p } } } \right ) \qquad { \frac { T _ { s } - T _ { m } ( L ) } { T _ { s } - T _ { m } ( 0 ) } } = \exp \! \left( - { \frac { h A _ { s } } { \dot { m } c _ { p } } } \right ) \; }
$$
**这个指数正是换热器一课使用对数平均温差的全部原因：一根由恒温壁面加热的管子永远不会“达到”壁温，它以由无量纲组合$h A _ { s } / ( \dot { m } c _ { p } )$决定的速率趋近壁温——这恰好就是两章之后 NTU 的含义。**
**哪一种壁面条件是真实的。** 电加热管、核燃料棒、太阳能吸热管以及冷板上的芯片都接近于**恒热流密度**——热量由电流、裂变率或硅片决定，壁温则是算出来是多少就是多少。管外有蒸汽凝结的管子，或浸没在相变流体中的管子，接近于**恒壁温**——壁面被钉在饱和温度上，热流密度则是算出来是多少就是多少。**两种条件在充分发展层流的$\mathrm { N u }$上只相差$1 9 \ \ \%$（$4 . 3 6$对$3 . 6 6$），在湍流中只相差百分之几——但它们在长管末端的壁温上可以相差任意大的量，而在设计中，你要保护的正是壁面。**
:::

::: exercise 推导：平均温度方程 {#der-tm level=3}
::: solution
**控制体。** 取管道在$x$与$x + d x$之间的一段，周长为$P$，截面积为$A _ { c }$，壁面热流密度为$q _ { s } ^ { \prime \prime }$（以流入为正），无轴功，不可压缩流动，轴向导热可忽略，动能和位能的变化可忽略。稳定流动控制体的热力学第一定律表明：流入的能量$=$流出的能量，所以
$$
\underbrace { \rho c _ { p } \int _ { A } u T \, d A } _ { \text{在 } x \text{ 处流入} } + \underbrace { q _ { s } ^ { \prime \prime } P \, d x } _ { \text{穿过壁面} } = \underbrace { \rho c _ { p } \int _ { A } u T \, d A + { \frac { \partial } { \partial x } } \! \left( \rho c _ { p } \int _ { A } u T \, d A \right ) \! d x } _ { \text{在 } x + d x \text{ 处流出} }
$$
**认出积分中$T _ { m }$的定义**（$\rho \int u T \, d A = \rho U _ { m } A _ { c } T _ { m } = \dot { m } T _ { m }$，由连续性方程$\dot { m }$为常数），上式就化为
$$
q _ { s } ^ { \prime \prime } P \, d x = { \frac { \partial } { \partial x } } \left( \dot { m } c _ { p } T _ { m } \right ) d x \qquad \Longrightarrow \qquad \boxed { \; { \frac { \mathrm { d } T _ { m } } { \mathrm { d } x } } = { \frac { P q _ { s } ^ { \prime \prime } } { \dot { m } c _ { p } } } \; }
$$
**做了哪些假设，什么会破坏它们。** **$\dot { m }$为常数**——在壁面吹气、发汗冷却或质量加入时不成立（火箭冷却通道把燃料向内泄出，方程会多出一个源项）。**$c _ { p }$为常数**——对液体在大温度跨度下只是轻微地不成立（水的$c _ { p }$在$0$–$1 0 0 \ \ {} ^ { \circ } \mathrm { C }$范围内变化$1 \ \ \%$），而在临界点附近严重不成立，那里$c _ { p }$发散，超临界传热关联式也不再与本式相像。**无轴向导热**——佩克莱数$\mathrm { R e } \, \mathrm { P r }$必须很大；对于液态金属（$\mathrm { P r } \sim 0 . 0 1$），在通常的$\mathrm { R e }$下轴向导热项并不小，整个方程必须连同它一起重新推导。**无相变**——有沸腾时，流体携带的是$\dot { m } \left( i _ { f } + x \, h _ { f g } \right)$，被输运的量是焓（以及蒸气干度$x$），而不是温度；这一推广就是两相流一课中记账的全部内容。
**一般形式。** 去掉$c _ { p }$为常数的简化，老实的表述是一个**焓**平衡：$\mathrm { d } ( \dot { m } \bar { i } ) / \mathrm { d } x = P q _ { s } ^ { \prime \prime }$，其中$\bar { i }$是混合平均焓。**每一个对流传热关联式都是使这个方程封闭的一种方法；没有一个能取代它。**
:::

## 入口段长度：一根管子要多长才能成为它自己

::: definition 流动入口段与热入口段长度 {#def-entry}
一根半径为$R$、以均匀速度分布供入流体的管子，会形成一层壁面边界层，它不断增长，直到在轴线处汇合。到达充分发展流动的距离就是**入口段长度**，它由与平板边界层相同的物理决定——在边界层汇合之前，管子**就是**一块卷成管状的平板：
$$
\boxed { \; { \frac { x _ { f , d } } { D } } \approx { \begin{cases} 0 . 0 5 \, \mathrm { R e } _ { D } & \text{层流} \\[4pt] 1 0 \text{ 到 } 6 0 \; ( \text{常取} \approx 1 0 ) & \text{湍流} \end{cases} } \; } \qquad { \frac { x _ { t , d } } { D } } \approx { \begin{cases} 0 . 0 5 \, \mathrm { R e } _ { D } \, \mathrm { P r } & \text{层流，} \mathrm { P r } \gtrsim 1 \\ 1 0 \text{ 到 } 6 0 & \text{湍流} \end{cases} }
$$
**层流的标度关系就是代入$\delta \sim D$后的平板标度关系：令$\delta / x \sim 5 / { \sqrt { \mathrm { R e } _ { x } } }$等于$D / 2$，得到$x \propto \mathrm { R e } _ { D } \, D$；粗略的平板估算把系数放在$0 . 0 1$附近，而完整的发展流动解（随着边界层增长，核心区加速）把它提高到这里所用的$0 . 0 5$。** **热入口段长度多出一个普朗特数，是因为在层流中热量必须以自身的速率扩散过与动量“相同”的距离：高普朗特数的油速度发展得快，温度发展得慢——$\mathrm { R e } = 1 0 0$的机油需要$x _ { t , d } / D \approx 0 . 0 5 \times 1 0 0 \times 5 0 0 = 2 5 0 0$倍管径才能达到热充分发展，这就是油冷却器很长的原因。**
**湍流入口段短，而且出了名地不精确**——边界层按$\delta \propto x ^ { 4 / 5 }$增长，在十到六十倍管径之内吞没核心区，而文献中的分散本身就有六倍。**工程规则是：湍流，$L / D > 6 0$：使用充分发展关联式；$L / D < 1 0$：这是射流或孔口，不是管子；介于两者之间，施加量级为$( D / L ) ^ { 1 / 3 }$的入口修正，或者去测量。**
**为什么有人在乎。** 在入口段中，边界层薄，梯度陡，**当地努塞尔数从进口处的无穷大一路下降到其充分发展值**——短管上的平均值可以是充分发展值的好几倍。在层流中这不是一项修正：对于$L / D$与$0 . 0 5 \, \mathrm { R e } \, \mathrm { P r }$相当的管子，入口段**就是**整根管子，正确的答案是下一节的格雷茨-西德-塔特答案。
:::

::: definition 充分发展层流：格雷茨数值 {#def-graetz}
对于圆管，速度充分发展，温度充分发展，物性为常数，带抛物线速度分布$u = 2 U _ { m } \left[ 1 - ( r / R ) ^ { 2 } \right ]$的能量方程是线性的、可分离变量的——这就是**格雷茨（Graetz）问题**（1883）——它的第一个特征值给出
$$
\boxed { \; \mathrm { N u } _ { D } = 3 . 6 6 \quad ( T _ { s } = \text{const} ) \qquad \mathrm { N u } _ { D } = 4 . 3 6 \quad \left( q _ { s } ^ { \prime \prime } = \text{const} \right ) \; } \qquad ( \mathrm { R e } _ { D } \, \mathrm { Pr } \, D / L \lesssim 2 0 )
$$
**两个数都是常数——与雷诺数、普朗特数和流量无关。** **这不是近似；它是关于解的形状的一个定理（见推导习题），也是管内强制对流中最具诊断意义的一个事实：在充分发展层流中，$h \propto U _ { m } ^ { 0 }$——把泵开大，除了泵功之外什么也换不来。** **原因在于抛物线速度分布与温度分布被流动锁定在一起：把$U$加倍会使停留时间减半，同时使壁面处的梯度加倍，两者恰好相互抵消，比值$h D / k$纹丝不动。**
**平行平板通道**（间隙为$2 B$，宽度很大）在恒壁温下给出$\mathrm { N u } _ { D _ { h } } = 7 . 5 4$，在恒热流密度下给出$8 . 2 3$——**在相同当量直径下是圆管的两倍多，因为平面通道的速度分布更均匀地快——$u _ { \max } / U _ { m } = 1 . 5$，而圆管为$2 . 0$——这使得单位流量中靠近壁面的慢速流体更少。** **任何把平板几何通过$D _ { h }$配上$3 . 6 6$来计算的层流计算都错了一倍；格雷茨数值属于形状，而且只属于形状。**
**格雷茨数**是衡量层流热发展还要走多远的无量纲数：
$$
\mathrm { G z } _ { D } = { \frac { \dot { m } c _ { p } } { k L } } = { \frac { \pi } { 4 } } \, { \frac { D } { L } } \, \mathrm { R e } _ { D } \, \mathrm { P r } \qquad \mathrm { G z } _ { D } \lesssim 1 6 \ \left( \mathrm { R e } \, \mathrm { Pr } \, D / L \lesssim 2 0 \right) \text{ 意味着大部分已充分发展}
$$
:::

::: exercise 推导：$\mathrm { N u } = 3 . 6 6$是一个特征值 {#der-graetz level=5}
::: solution
**问题的建立。** 圆管内的充分发展层流：$u ( r ) = 2 U _ { m } \left( 1 - r ^ { 2 } / R ^ { 2 } \right )$，$v = 0$，物性为常数，轴向导热和内热源可忽略。能量方程为
$$
u ( r ) \, { \frac { \partial T } { \partial x } } = \alpha \, { \frac { 1 } { r } } { \frac { \partial } { \partial r } } \! \left( r { \frac { \partial T } { \partial r } } \right )
$$
**关键的一步不是分离变量——而是认清“温度充分发展”意味着什么。** 对于恒壁温，径向温度分布的形状变得固定，所以写成$T ( r , x ) = T _ { s } + \left( T _ { m } ( x ) - T _ { s } \right ) \Theta ( r ^ { + } )$，其中$r ^ { + } = r / R$；代入并以常数$\lambda ^ { 2 }$分离变量，把半径无量纲化之后得到
$$
{ \frac { 1 } { r ^ { + } } } { \frac { \mathrm { d } } { \mathrm { d } r ^ { + } } } \! \left( r ^ { + } { \frac { \mathrm { d } \Theta } { \mathrm { d } r ^ { + } } } \right ) + \lambda ^ { 2 } \left( 1 - r ^ { + 2 } \right ) \Theta = 0 \qquad \Theta ^ { \prime } ( 0 ) = 0 , \quad \Theta ( 1 ) = 0
$$
**这是一个奇异的施图姆-刘维尔（Sturm–Liouville）问题**（权函数$1 - r ^ { + 2 }$在壁面处为零），特征值为$\lambda _ { n } ^ { 2 }$；每一项的轴向衰减率等于它的特征值，又因为壁面处于$T _ { s }$，全部驱动温差都体现在流体平均温度中，所以努塞尔数单由第一个特征函数决定：
$$
\mathrm { N u } _ { D } = { \frac { h D } { k } } = { \frac { - \, \Theta ^ { \prime } ( 1 ) } { \Theta _ { m } } } \qquad \Theta _ { m } = { \frac { \int _ { 0 } ^ { 1 } \Theta \left( 1 - r ^ { + 2 } \right ) r ^ { + } \, d r ^ { + } } { \int _ { 0 } ^ { 1 } \left( 1 - r ^ { + 2 } \right ) r ^ { + } \, d r ^ { + } } }
$$
**求解第一个特征值**（幂级数解，由格雷茨在1880年代、努塞尔（Nusselt）在1910年给出）得到$\lambda _ { 1 } = 2 . 7 0 4$，$\lambda _ { 1 } ^ { 2 } = 7 . 3 1 4$，以及
$$
\mathrm { N u } _ { D } = { \frac { \lambda _ { 1 } ^ { 2 } } { 2 } } = 3 . 6 5 7 \qquad \text{轴向衰减为 } { \frac { T _ { m } - T _ { s } } { T _ { m , 0 } - T _ { s } } } \propto e ^ { - 2 \lambda _ { 1 } ^ { 2 } x ^ { + } } = e ^ { - 1 4 . 6 3 \, x ^ { + } } , \quad x ^ { + } = { \frac { x / D } { \mathrm { R e } _ { D } \, \mathrm { P r } } }
$$
**下一个特征值（$\lambda _ { 2 } ^ { 2 } = 4 4 . 6 1$）衰减得快约六倍，所以在$x ^ { + } \approx 0 . 0 5$（即$\mathrm { R e } \, \mathrm { Pr } \, D / L \lesssim 2 0$）之后，单项答案给出的当地$\mathrm { N u }$精确到百分之一二。**（衰减率可以用能量平衡来校核：取$h = 3 . 6 6 k / D$的$\mathrm { d } T _ { m } / \mathrm { d } x$给出指数$4 \, \mathrm { N u } \, x ^ { + } = 1 4 . 6 3 \, x ^ { + }$。）**对于恒热流密度，用$\partial T / \partial x = \text{const}$代替$T _ { s } = \text{const }$，按同样的步骤得到$\mathrm { N u } = 4 . 3 6 4$——$1 9 \ \ \%$的差别完全来自两种边界条件对近壁区的不同加权。**
**这个定理带来了什么。** **因为$\lambda _ { 1 } ^ { 2 }$是一个纯数，$\mathrm { N u }$也是一个纯数：没有$\mathrm { R e }$，没有$\mathrm { P r }$，与你泵送得多快无关。** **检查其适用限度：这个结果要求充分发展的抛物线速度分布——它在入口段不成立，那里平坦的核心区使梯度保持陡峭（$\mathrm { N u }$大得多）；它对剪切变稀的非牛顿流体不成立，其更平坦的速度分布把$\mathrm { N u }$推向柱塞流极限$5 . 7 8$；当轴向导热重要时（$\mathrm { R e } \, \mathrm { P r } \lesssim 1 0 0$）它也不成立，这就是液态金属需要自己的理论的原因。**
:::

## 层流：入口段就是设计

::: definition 层流复合入口段：西德-塔特关联式 {#def-siedertate}
对于圆管内的层流，流动入口段和热入口段**同时**存在，恒壁温，在全长$L$上取平均，
$$
\boxed { \; { \overline { { \mathrm { N u } } } } _ { D } = 1 . 8 6 \left( { \frac { \mathrm { R e } _ { D } \, \mathrm { P r } \, D } { L } } \right ) ^ { 1 / 3 } \left( { \frac { \mu } { \mu _ { s } } } \right ) ^ { 0 . 1 4 } \; } \qquad \left[ \; { \overline { { \mathrm { N u } } } } _ { D } \to 3 . 6 6 \; \text{ 当 } { \frac { L / D } { \mathrm { R e } \, \mathrm { P r } } } \gtrsim 0 . 0 5 \; \right]
$$
**物性在主流平均温度$T _ { m }$下取值；黏度比使用壁温$T _ { s }$，且只对液体重要**（加热液体时：壁面更热，$\mu _ { s } < \mu$，比值大于一，$h$因薄而热的壁面层而提高；冷却时：情况相反，这个因子对油的影响最大）。**组合$\mathrm { R e } \, \mathrm { Pr } \, D / L = 4 \, \mathrm { G z } / \pi$是改头换面的格雷茨数：关联式表明$\overline { { \mathrm { N u } } } \propto \mathrm { G z } ^ { 1 / 3 }$——长管和强烈的热扩散（小$\mathrm { G z }$）都会把表面传热系数压平。** **Incropera 等人给出的适用范围：$0 . 6 \lesssim \mathrm { P r } \lesssim 5$，$0 . 0 0 4 4 \lesssim \mu / \mu _ { s } \lesssim 9 . 7 5$，以及$\overline { \mathrm { N u } } \gtrsim 3 . 7$；尽管如此，它仍常规地用于黏性油——黏度因子本来就是为它们引入的——不确定度量级为$\pm 2 5 \ \ \%$。方括号中的条件标出了管子在热上算作长管、答案回到$3 . 6 6$的地方。**
**把这个关联式当作标度律来读，因为它本来就是。** $\overline { { \mathrm { N u } } } \propto ( \dot { m } c _ { p } ) ^ { 1 / 3 } k ^ { - 1 / 3 }$——**在入口段中，层流的$h$确实依赖于流量（按$\dot { m } ^ { 1 / 3 }$），而这是你唯一的杠杆：要使层流油冷却器的表面传热系数加倍，就得把每根管的流量乘以八——或者把管子缩短，因为$\overline { { \mathrm { N u } } } \propto L ^ { - 1 / 3 }$，管长减半换来$2 6 \ \ \%$。**
:::

::: example 短管中的层流水：入口段承担全部工作 {#ex-lam-water}
$2 7 \ \ {} ^ { \circ } \mathrm { C }$的水以$\dot { m } = 0 . 0 1 0 \ \mathrm { k g / s }$流过一根$D = 8 \ \mathrm { m m }$、$L = 1 . 5 \ \mathrm { m }$的管子，被加热到不高的壁温。估算平均表面传热系数。$3 0 0 \ \mathrm { K }$下的物性：$\rho = 9 9 7 \ \mathrm { k g / m ^ { 3 } }$，$c _ { p } = 4 1 7 9 \ \mathrm { J / k g \, K }$，$\mu = 8 5 5 \times 1 0 ^ { - 6 } \ \mathrm { N \, s / m ^ { 2 } }$，$k = 0 . 6 1 3 \ \mathrm { W / m \, K }$，$\mathrm { P r } = 5 . 8 3$。

::: solution
$$
U _ { m } = { \frac { \dot { m } }{ \rho \pi D ^ { 2 } / 4 } } = { \frac { 0 . 0 1 0 } { 9 9 7 \times 5 . 0 2 7 \times 1 0 ^ { - 5 } } } = 0 . 1 9 9 \ \mathrm { m / s } \qquad \mathrm { R e } _ { D } = { \frac { \rho U _ { m } D } { \mu } } = { \frac { 9 9 7 \times 0 . 1 9 9 \times 0 . 0 0 8 } { 8 5 5 \times 1 0 ^ { - 6 } } } = 1 8 6 0
$$
**层流，稳稳低于$2 3 0 0$。** 入口段长度：$x _ { f , d } = 0 . 0 5 \times 1 8 6 0 \times 0 . 0 0 8 = 0 . 7 4 \ \mathrm { m }$——**管子有一半在流动上仍处于发展之中**——以及格雷茨组合

$$
$$
\mathrm { G z } ^ { - 1 } \text{形式：} \quad { \frac { \mathrm { R e } \, \mathrm { P r } \, D } { L } } = { \frac { 1 8 6 0 \times 5 . 8 3 \times 0 . 0 0 8 } { 1 . 5 } } = 5 7 . 7 \qquad { \overline { { \mathrm { N u } } } } = 1 . 8 6 \times 5 7 . 7 ^ { 1 / 3 } = 1 . 8 6 \times 3 . 8 6 5 = 7 . 1 9
$$
$$
\boxed { \; { \overline { { h } } } = { \frac { 7 . 1 9 \times 0 . 6 1 3 } { 0 . 0 0 8 } } = 5 5 1 \ \mathrm { W / m ^ { 2 } K } \; } \qquad \text{对比充分发展值：} \ { \frac { 3 . 6 6 \times 0 . 6 1 3 } { 0 . 0 0 8 } } = 2 8 0 \ \mathrm { W / m ^ { 2 } K }

**入口段使答案翻了一倍。** **如果你随手用了$\mathrm { N u } = 3 . 6 6$，你会把管子面积选成所需的两倍。** **合理性检查：热容量流率为$\dot { m } c _ { p } = 4 1 . 8 \ \mathrm { W / K }$，所以$2 5 \ \mathrm { W / m }$的壁面热流只使水升温$0 . 9 \ \mathrm { K }$——这根管子在热上微不足道，而这正是“充分发展”式思维失灵的流态，因为流体根本没有机会忘记进口。** **如果你转而随手用了湍流关联式——在这个雷诺数下误用迪图斯-贝尔特关联式——你会得到$h \approx 1 4 7 0 \ \mathrm { W / m ^ { 2 } K } $，高了将近三倍。**

::: definition 液态金属：以导热为主的流动 {#def-liquidmetal}
对于$\mathrm { P r } \lesssim 0 . 0 3$（液态钠、铅铋合金、锂），热量传导得如此容易，以致即使在湍流中温度场也遍及整个截面，上面的湍流关联式失效，努塞尔数只微弱地依赖于佩克莱数$\mathrm { Pe } = \mathrm { Re } \, \mathrm { Pr }$：
$$
\boxed { \; \mathrm { N u } _ { D } = 5 . 0 + 0 . 0 2 5 \, \mathrm { Pe } ^ { 0 . 8 } \; ( T _ { s } = \text{const，Seban–Shimazaki} ) \qquad \mathrm { N u } _ { D } = 4 . 8 2 + 0 . 0 1 8 5 \, \mathrm { Pe } ^ { 0 . 8 2 7 } \; ( q _ { s } ^ { \prime \prime } = \text{const，Skupinski} ) \; }
$$
（两者都是在$\mathrm { Pe } \gtrsim 1 0 0$下拟合的，在此以下使用时要小心。）**在低佩克莱数下$\mathrm { Nu} \approx 5$——分子导热完成了在水中由涡旋完成的大部分工作。** **由此得到的工程结论很有用：即使在不大的流量下也有$h \approx 5 k / D$，液态钠在反应堆温度下$k \approx 7 0 \ \mathrm { W / m \, K }$，使一条$1 0 \ \mathrm { m m }$的通道获得$h \approx 3 5 { , } 0 0 0$–$4 0 { , } 0 0 0 \ \mathrm { W / m ^ { 2 } K } $，流量变化一百倍时它只变化约两倍。** **因此液态金属传热与流量的关系很弱——这有利于承受流量扰动，但也意味着把泵开大对$h$帮助不大；流量换来的是冷却剂的载热能力$\dot { m } c _ { p }$。**

## 湍流：两个关联式，以及两者都不适用的范围

::: definition 迪图斯-贝尔特关联式：主力 {#def-db}
对于光滑圆管内的湍流，热充分发展，截面上物性差别不大：
$$
\boxed { \; { \overline { \mathrm { N u } } } _ { D } = 0 . 0 2 3 \, \mathrm { R e } _ { D } ^ { 0 . 8 } \, \mathrm { Pr } ^ { n } \; } \qquad n = { \begin{cases} 0 . 4 & \text{流体被加热} \left( T _ { s } > T _ { m } \right) \\ 0 . 3 & \text{流体被冷却} \end{cases} }
$$
**适用范围：$\mathrm { R e } _ { D } \gtrsim 1 0 ^ { 4 }$，$0 . 6 \lesssim \mathrm { Pr } \lesssim 1 6 0$，$L / D \gtrsim 1 0$；全部物性在主流平均温度$T _ { m }$下取值；分散$\pm 2 5 \ \ \%$，在普朗特数的两端更差。** **它源自迪图斯和贝尔特1930年的汽车散热器数据（他们原来的常数是$0 . 0 2 4 3$和$0 . 0 2 6 5$；圆整后的$0 . 0 2 3$形式由麦克亚当斯（McAdams）推广开来），至今仍是热工工程中使用最多的方程——用于估算，而不是用于采购订单。**
**为什么指数是$0 . 8$，又为什么不对称。** $4 / 5$来自湍流层的七分之一次方速度分布（$\delta / D \sim \mathrm { R e } ^ { - 1 / 4 }$，所以壁面梯度以及$\mathrm { N u }$按$\mathrm { R e } ^ { 4 / 5 }$变化）——与湍流平板的指数相同，因为管内核心区是平板的一个无人照管的孪生兄弟。**普朗特数上的$0 . 4$对$0 . 3$是一项粗略的黏度修正：加热液体使壁面层变薄而有助于传热（因而指数较大），冷却使它变厚而不利于传热。** **当液体黏度在截面上变化剧烈时，改用西德-塔特湍流形式——$\mathrm { N u } = 0 . 0 2 7 \, \mathrm { R e } ^ { 0 . 8 } \, \mathrm { Pr } ^ { 1 / 3 } ( \mu / \mu _ { s } ) ^ { 0 . 1 4 }$——它把物性的影响放在物理所放的地方，即壁面上。** **对于温差大的气体，类似的修正是一个因子$( T _ { m } / T _ { s } ) ^ { n }$，加热时$n \approx 0 . 5 5$，冷却时$n \approx 0$（Hall–Prieder），因为在气体中重新安排近壁层的是密度，而不是黏度。**
**同一信息的柯尔本（Colburn）$j$因子形式，值得记住，因为它可以推广到传质和粗糙表面：**
$$
j _ { H } \equiv \mathrm { St } \, \mathrm { Pr } ^ { 2 / 3 } = { \frac { f } { 8 } } \qquad \Longleftrightarrow \qquad \mathrm { N u } = { \frac { f } { 8 } } \, \mathrm { R e } \, \mathrm { Pr } ^ { 1 / 3 }
$$
**其中$f$是达西摩擦因子——对这些雷诺数下的光滑管，$f = 0 . 1 8 4 \, \mathrm { R e } ^ { - 0 . 2 }$，它在百分之几以内重现$0 . 0 2 3 \, \mathrm { R e } ^ { 0 . 8 }$。这个比拟表明，管子以相同的兑换率交换热量和动量，与平板上完全一样：任何为了绊发边界层而提高$f$的装置——绕丝、扰流器、粗糙度——都会按比例提高$\mathrm { N u }$，而强化表面的全部诀窍就是以低于这个比拟所定价格的摩擦代价做到这一点。**
:::

::: definition 格尼林斯基关联式：精确的那一个 {#def-gnielinski}
对于$3 0 0 0 < \mathrm { R e } _ { D } < 5 \times 1 0 ^ { 6 }$和$0 . 5 < \mathrm { Pr } < 2 0 0 0$，光滑管，充分发展：
$$
\boxed { \; { \overline { { \mathrm { N u } } } } _ { D } = { \frac { ( f / 8 ) \left( \mathrm { R e } _ { D } - 1 0 0 0 \right ) \mathrm { Pr } } { 1 + 1 2 . 7 \, ( f / 8 ) ^ { 1 / 2 } \left( \mathrm { Pr } ^ { 2 / 3 } - 1 \right ) } } \; } \qquad f = \left( 0 . 7 9 \, \ln \mathrm { R e } _ { D } - 1 . 6 4 \right ) ^ { - 2 }
$$
**分子中的摩擦因子是彼图霍夫（Petukhov）的光滑管拟合式；分子中的$- 1 0 0 0$和含普朗特数的分母是双层修正——前者考虑层流底层吃掉了一部分动量传递，后者考虑底层的热阻。两者都是从数据中得来的，而且两者都重要：把它们关掉，你就回到了一个分散大好几倍的柯尔本型方程。**
**精度：在$\mathrm { R e } > 1 0 ^ { 4 }$和$0 . 6 < \mathrm { Pr } < 2 0 0$时约为$\pm 1 0 \ \ \%$——这是现有最好的通用关联式，只要数字要写进采购订单，就用它。** **在$\mathrm { R e } = 3 0 0 0$时它注明的误差已经是$\pm 2 5 \ \ \%$，而在$3 0 0 0$以下，它对你的管子会怎样表现一言不发。** **注意$- 1 0 0 0$：在$\mathrm { Re } = 3 0 0 0$时，关联式自己就把三分之一的雷诺数当作不做湍流功而一笔勾销了。**

::: example 用恒壁温表面加热水 {#ex-turb-water}
$2 0 \ \ {} ^ { \circ } \mathrm { C }$的水以$\dot { m } = 0 . 4 0 \ \mathrm { k g / s }$流过$L = 1 0 \ \mathrm { m }$长、$D = 1 6 \ \mathrm { m m }$的管子，管外凝结的蒸汽使管壁保持在$8 0 \ \ {} ^ { \circ } \mathrm { C }$。求出口温度、传热速率和泵功率。

::: solution
**物性按假定的$4 0 \ \ {} ^ { \circ } \mathrm { C }$平均温度取值**（如果答案使平均温度变化较大，就进行迭代）：$\rho = 9 9 2 \ \mathrm { k g / m ^ { 3 } }$，$c _ { p } = 4 1 7 9 \ \mathrm { J / k g \, K }$，$\mu = 6 5 3 \times 1 0 ^ { - 6 } \ \mathrm { N \, s / m ^ { 2 } }$，$k = 0 . 6 3 1 \ \mathrm { W / m \, K }$，$\mathrm { P r } = 4 . 3 2$。
$$
U _ { m } = { \frac { 0 . 4 0 } { 9 9 2 \times 2 . 0 1 1 \times 1 0 ^ { - 4 } } } = 2 . 0 0 \ \mathrm { m / s } \qquad \mathrm { R e } _ { D } = { \frac { 9 9 2 \times 2 . 0 0 \times 0 . 0 1 6 } { 6 5 3 \times 1 0 ^ { - 6 } } } = 4 8 { , } 7 0 0
$$
**湍流，且在热上是长管（$L / D = 6 2 5 \gg 6 0$），所以适用充分发展关联式。** 格尼林斯基关联式，取$f = \left( 0 . 7 9 \ln 4 8 \, 7 0 0 - 1 . 6 4 \right ) ^ { - 2 } = 0 . 0 2 1 1$：
$$
\mathrm { N u } = { \frac { ( 0 . 0 2 1 1 / 8 ) \times 4 7 { , } 7 0 0 \times 4 . 3 2 } { 1 + 1 2 . 7 \times ( 0 . 0 2 1 1 / 8 ) ^ { 1 / 2 } \times \left( 4 . 3 2 ^ { 2 / 3 } - 1 \right ) } } = { \frac { 5 4 4 } { 2 . 0 8 } } = 2 6 2 \qquad h = { \frac { 2 6 2 \times 0 . 6 3 1 } { 0 . 0 1 6 } } = 1 0 { , } 3 0 0 \ \mathrm { W / m ^ { 2 } K }
$$
**（迪图斯-贝尔特关联式会给出$2 3 2$和$9 1 7 0$——低$1 1 \ \ \%$，在两个关联式的误差带之内，这一句话就概括了两者之间的全部争论。）** 恒壁温意味着指数趋近：
$$
\mathrm { N T U } = { \frac { h \pi D L } { { \dot { m } } c _ { p } } } = { \frac { 1 0 \, 3 0 0 \times \pi \times 0 . 0 1 6 \times 1 0 } { 0 . 4 0 \times 4 1 7 9 } } = 3 . 1 0 \qquad T _ { m } ( L ) = 8 0 - 6 0 \, e ^ { - 3 . 1 0 } = \mathbf { 7 7 . 3 \ \mathrm { ^ \circ C } }
$$
$$
q = { \dot { m } } c _ { p } \Delta T _ { m } = 1 6 7 2 \times 5 7 . 3 = \mathbf { 9 5 . 8 \ \mathrm { k W } } \qquad \Delta p = f { \frac { L } { D } } { \frac { \rho U ^ { 2 } } { 2 } } = 0 . 0 2 1 1 \times 6 2 5 \times 1 9 9 0 = 2 6 . 3 \ \mathrm { k P a } \qquad P = { \frac { \Delta p \, { \dot { m } } } { \rho } } = \mathbf { 1 0 . 6 \ \mathrm { W } }
$$
**三种解读。管子出口比蒸汽温度低$3 \ \mathrm { K }$，传递了将近$1 0 0 \ \mathrm { k W }$——而把剩下的$2 . 7 \ \mathrm { K }$温差每再缩小$e$倍，都要再花$1 0 / 3 . 1 0 = 3 . 2 \ \mathrm { m }$，因为$e ^ { - 3 }$正是指数函数的栖身之处。** **泵功率十瓦，而传热量九十六千瓦：$0 . 0 1 \ \ \%$——湍流的水输送起来很便宜，这就是为什么下面关于过渡区的担忧比任何关于泵功的担忧都更值得。** **再说物性的选取：假定的$4 0 \ \ {} ^ { \circ } \mathrm { C }$偏低——真实的主流平均温度是$( 2 0 + 7 7 ) / 2 \approx 4 9 \ \ {} ^ { \circ } \mathrm { C }$，在此温度下$\mu \approx 5 5 0 \times 1 0 ^ { - 6 }$，$\mathrm { P r } \approx 3 . 6$。重复计算得到$\mathrm { R e } \approx 5 8 \, 0 0 0$，$h \approx 1 1 \, 2 0 0 \ \mathrm { W / m ^ { 2 } K }$，出口温度$7 7 . 9 \ \ {} ^ { \circ } \mathrm { C }$——$h$变化了$9 \ \ \%$，出口温度却只变化$0 . 6 \ \mathrm { K }$，因为指数已经饱和了。对水，在平均温度下取物性并迭代一次；这只花一分钟。**

:::

**过渡区值得单独写一段，因为没有任何关联式覆盖它。** 在$\mathrm { R e } \approx 2 3 0 0$与$1 0 ^ { 4 }$之间，流动两者都不是：湍流斑出现又消失，它们能否占上风取决于进口历史、表面粗糙度、振动和来流湍流度，而这种依赖关系从来没有被关联到优于两倍的精度。**测量表明，这一范围内的当地努塞尔数可以低于层流值——流动破碎得无法像湍流那样混合，又混合得无法像层流那样导热——而谨慎的设计指导（自雷诺1883年的染色实验以来，这个流态就已为人所知）是：如果你必须在这里运行，就按层流答案设计，并对结果进行测量监控。** **实际的出路有三条：把流量提高到$\mathrm { R e } = 1 0 ^ { 4 }$以上（通常的答案，也是管壳式换热器在$1 6$–$2 0 \ \mathrm { m m }$管子中把水侧流速选在$1 . 5$–$2 \ \mathrm { m / s }$附近的原因）；用粗糙的进口或插入的金属丝有意绊发流动；或者把整个设备设计成层流，接受格雷茨答案。**

## 压降、泵功率与管径交易

::: definition 压降及其代价 {#def-pumping}
长度为$L$的光滑管的达西-魏斯巴赫（Darcy–Weisbach）公式，加上为之付账的泵功率：
$$
\Delta p = f \, { \frac { L } { D } } \, { \frac { \rho U _ { m } ^ { 2 } } { 2 } } \qquad P _ { \text{pump} } = { \frac { \Delta p \, { \dot { m } } } { \rho } } \qquad f = { \begin{cases} 6 4 / \mathrm { R e } & \text{层流} \\ \left( 0 . 7 9 \ln \mathrm { R e } - 1 . 6 4 \right ) ^ { - 2 } & \text{湍流，光滑管} \end{cases} }
$$
**两种流态的标度关系完全不同，而每一项换热器设计都是沿着这些标度关系的一次行走。** 在固定流量下：
$$
\begin{array} { l c c c }
& \text{层流} & \text{湍流（光滑管）} & \text{解读} \\
h \text{ 在固定 } \dot { m } , D \text{ 下} & \propto \ \dot { m } ^ { 0 } \text{（充分发展）或 } \dot { m } ^ { 1 / 3 } \text{（入口段）} & \propto \ \dot { m } ^ { 0 . 8 } & \text{流量加倍：湍流 } + 7 4 \ \ \% \\
\Delta p \text{ 在固定 } \dot { m } , D \text{ 下} & \propto \ \dot { m } ^ { 1 } & \propto \ \dot { m } ^ { 1 . 8 } & \text{流量加倍：泵功率 } \times 7 \\
h \text{ 在固定 } \dot { m } , L \text{ 下} & \propto \ D ^ { - 1 } \text{（充分发展和入口段）} & \propto \ D ^ { - 1 . 8 } & \text{管径减半：} \times 3 . 5 \\
\Delta p \text{ 在固定 } \dot { m } , L \text{ 下} & \propto \ D ^ { - 4 } & \propto \ D ^ { - 4 . 8 } & \text{管径减半：} \times 1 6 \text{ 到 } 2 8
\end{array}
$$
**湍流这一行是每个设计者都要签下的交易：表面传热系数以$D ^ { - 1 . 8 }$的比率从管径那里买来（每米管长的热导$h \pi D$只按$D ^ { - 0 . 8 }$），而以$D ^ { - 4 . 8 }$的比率付账——从指数上看，压力账单的增长比它所买到的热导快六倍。** **这就是为什么对泵送液体，紧凑式换热器把$D$压到几毫米就不再往下压；为什么燃气轮机用小孔冷却叶片，却不用泵把空气压过通道；以及为什么自然循环——其驱动压头是几厘米的密度差，而不是泵——根本不能使用小管子。**
:::

::: example 两根杠杆，标上价格 {#ex-levers}
一根水管在$\mathrm { R e } = 4 \times 1 0 ^ { 4 }$下以湍流工作。比较以下两种做法的代价与收益：(a) 把流量加倍；(b) 在总流量和总长度不变的情况下，把这段管子换成管径减半的管子。

::: solution
**(a) 流量加倍。** $h \propto { \dot { m } } ^ { 0 . 8 }$：表面传热系数$\times 2 ^ { 0 . 8 } = 1 . 7 4$。面积不变，所以单位壁面温差下的传热量$\times 1 . 7 4$。泵送：$\Delta p \propto { \dot { m } } ^ { 1 . 8 }$，且$P = \Delta p \, \dot { m } / \rho \propto { \dot { m } } ^ { 2 . 8 }$：**泵功率$\times 2 ^ { 2 . 8 } = 7 . 0$。** **兑换率是$7$倍的泵功换$1 . 7 4$倍的热量——当另一种选择是更大的换热器时可以接受，当泵已经在其特性曲线的极限上时就很痛苦。**
**(b) 管径减半。** 取单管替换：同样的$\dot { m }$流过管径减半的管子，所以$U \times 4$，$\mathrm { Re } \times 2$；由$\mathrm { Nu } \propto \mathrm { Re } ^ { 0 . 8 }$和$h = \mathrm { Nu } \, k / D$，得$h \propto D ^ { - 1 . 8 }$：
$$
h \times 2 ^ { 1 . 8 } = 3 . 4 8 \qquad \Delta p \propto D ^ { - 4 . 8 } : \ \times 2 ^ { 4 . 8 } = 2 8 \qquad \text{每米面积} \times { \frac { 1 } { 2 } } \quad \Longrightarrow \quad { \frac { h A } { \text{每米} } } \times 1 . 7 4 , \quad P \times 2 8
$$
**与流量加倍所买到的同样是每米管长$1 . 7 4$倍的热导——但代价是二十八倍而不是七倍的泵功率：管径这根杠杆在泵上要贵四倍。** **在$2 8$倍的压降下，一段$1 0 \ \mathrm { m }$长、由$1 6 \rightarrow 8 \ \mathrm { m m }$的管子从$2 6 \ \mathrm { k P a }$（[[#ex-turb-water|蒸汽加热管的例题]]）变为四分之三兆帕，管束的管箱、垫片和泵都变得比你省下的那些额外金属更贵。** **这笔算术所指向的最优点——按你的能源价格，在面积的投资成本与泵送的运行成本之间权衡——就是为什么实际设计中$1 6 \ \mathrm { m m } $管内的水流速集中在$1 . 5$–$2 \ \mathrm { m / s }$，而且自克恩（Kern）1950年的表格以来一直如此。**
:::
:::

::: definition 小通道、微通道与非圆形管道 {#def-dh}
**当量直径（水力直径）。** 对于任何管道，$D _ { h } = 4 A _ { c } / P _ { w }$（流通面积除以润湿周长）。**对于湍流这是行得通的：使用$D _ { h }$时，每一种非圆形管道与圆管关联式的符合程度都在$1 0$–$1 5 \ \ \%$以内，因为湍流混合抹去截面形状的程度，几乎与它抹去流动历史的程度一样。** **对于层流它以一种特定的、可预见的方式失效：$\mathrm { N u }$和$f \, \mathrm { R e }$都是形状常数，而它们的比值与圆管不同：**
$$
\begin{array} { l c c c c }
\text{截面} & \text{圆形} & \text{平行平板} \left( \text{宽} \right) & \text{正方形} & \text{等边三角形} \\
\mathrm { N u } _ { D _ { h } } \; ( T _ { s } = \text{const} ) & 3 . 6 6 & 7 . 5 4 & 2 . 9 8 & 2 . 4 7 \\
f \, \mathrm { R e } _ { D _ { h } } & 6 4 & 9 6 & 5 6 . 9 & 5 3 . 3
\end{array}
$$
**这张表应这样读：单凭当量直径会对全部四种形状预测出$3 . 6 6$；真实值的跨度达三倍。** **实用的修正办法（Shah 和 London 已详尽列表）：用$D _ { h }$算出圆管答案，再乘以列表给出的比值$\left( \mathrm { N u } / \mathrm { N u } _ { \text{circle} } \right ) _ { \text{shape} }$——平行平板为$2 . 0 6$，正方形为$0 . 8 1$——摩擦常数也同样处理。**
**小通道与微通道**（当量直径小于约$1 \ \mathrm { m m }$，严格意义上小于$2 0 0 \ \mu\mathrm { m }$）**所打破的不只是形状表。** 经典的连续介质假设一起受到侵蚀：细通道中的黏性耗散不管你愿不愿意都会加热流体（它作为单位长度上的源项$\tau _ { w } P U _ { m }$进入平均温度方程）；早期实验报告的转捩雷诺数远低于$2 3 0 0$，但后来用光滑通道和特性明确的进口所做的仔细工作发现了约$2 0 0 0$–$2 3 0 0$的常规值——早期的分散大多来自入口效应、粗糙度和测量误差；而在亚微米尺度上，无滑移假设和连续介质假设本身就需要克努森数修正。**老实的工程立场是：在$1 0 0 \ \mu\mathrm { m }$以下，已发表的关联式彼此相差两倍，你应该根据自己的测量或制造商的曲线来设计。**
:::

::: example 硅微通道冷板 {#ex-micro}
$2 7 \ \ {} ^ { \circ } \mathrm { C }$的水以$1 \ \mathrm { m / s }$的平均流速被驱动流过刻蚀在硅中的$2 0 0 \ \mu\mathrm { m } \times 6 0 0 \ \mu\mathrm { m }$矩形通道。估算表面传热系数、芯片热流密度为$1 0 0 \ \mathrm { W / c m ^ { 2 } }$时的壁面温升，以及压力梯度。

::: solution
$$
D _ { h } = { \frac { 4 \times 2 0 0 \times 6 0 0 } { 2 ( 2 0 0 + 6 0 0 ) } } = 3 0 0 \ \mu\mathrm { m } \qquad \mathrm { R e } _ { D _ { h } } = { \frac { 9 9 7 \times 1 . 0 \times 3 0 0 \times 1 0 ^ { - 6 } } { 8 5 5 \times 1 0 ^ { - 6 } } } = 3 5 0
$$
**层流；对于$1 0 \ \mathrm { m m }$长的通道，格雷茨组合$\mathrm { R e } \, \mathrm { Pr } \, D _ { h } / L$为$3 5 0 \times 5 . 8 3 \times 0 . 0 3 = 6 1 > 2 0$——处于热发展之中，但取$3 : 1$矩形的充分发展恒热流密度值（$\mathrm { Nu } = 4 . 7 9$，$f \, \mathrm { Re } = 6 9$，Shah & London）作为下限，忽略硅肋中的导热扩展：**
$$
h \gtrsim { \frac { 4 . 7 9 \times 0 . 6 1 3 } { 3 0 0 \times 1 0 ^ { - 6 } } } = 9 8 0 0 \ \mathrm { W / m ^ { 2 } K } \qquad \text{（入口段使其提高；典型值为 } \mathrm { N u } \approx 1 2 \text{，} h \approx 2 5 { , } 0 0 0 \text{）}
$$
$$
\Delta T _ { w } = { \frac { q ^ { \prime \prime } } { h } } = { \frac { 1 0 ^ { 6 } } { 9 8 0 0 } } = 1 0 2 \ \mathrm { K } \ \text{（最坏）} \qquad \text{或} \qquad { \frac { 1 0 ^ { 6 } } { 2 5 \, 0 0 0 } } = 4 0 \ \mathrm { K } \ \text{（计入入口段）}
$$
$$
f = { \frac { 6 9 } { 3 5 0 } } = 0 . 1 9 7 \qquad { \frac { \Delta p } { L } } = f { \frac { \rho U ^ { 2 } } { 2 D _ { h } } } = 0 . 1 9 7 \times { \frac { 9 9 7 \times 1 ^ { 2 } } { 2 \times 3 0 0 \times 1 0 ^ { - 6 } } } = \mathbf { 0 . 3 3 \ \mathrm { M P a / m } }
$$
**每米三分之一兆帕——每米超过三巴，芯片每厘米$3 . 3 \ \mathrm { k P a }$——只为了以步行速度把水推过几根头发丝宽的通道。** **这一个数就讲完了微通道冷却的全部故事：传热一侧蔚为壮观（是任何风冷散热器的十倍，而$1 0 0 \ \mathrm { W / c m ^ { 2 } }$下的$4 0 \ \mathrm { K }$是一个真实的芯片冷却答案），流体一侧则在压力、密封和一台根本不该出现在电子设备机箱里的泵上把预算吃光。** **与本课中一贯的做法一样，设计上的对策就是那个记账方程：在层流中，以十分之一的流速获得同样的充分发展$h$，只需十分之一的压力梯度和百分之一的泵功率（但流量也只有十分之一，所以冷却剂温升为十倍）——微通道设计的成败取决于分配流量的歧管设计，而不是关联式。**

## 习题

::: exercise 水不再是层流时的流量 {#ex-re2300 level=1 check="0.019"}
$4 0 \ \ {} ^ { \circ } \mathrm { C }$的水$\left( \mu = 6 5 3 \times 1 0 ^ { - 6 } \ \mathrm { N \, s / m ^ { 2 } } \right)$在$D = 1 6 \ \mathrm { m m }$的管子中，多大的质量流量对应于经典的转捩下限$\mathrm { R e } _ { D } = 2 3 0 0$？（以$\mathrm { k g / s }$为单位输入质量流量。）

::: solution
$$
{ \dot { m } } = { \frac { \pi } { 4 } } D \, \mu \, \mathrm { R e } = { \frac { \pi } { 4 } } \times 0 . 0 1 6 \times 6 5 3 \times 1 0 ^ { - 6 } \times 2 3 0 0 = 0 . 0 1 8 9 \ \mathrm { k g / s } \approx \mathbf { 0 . 0 1 9 \ \mathrm { k g / s } }
$$
**每秒十九克——约为厨房水龙头流量的十分之一——就是一根$1 6 \ \mathrm { m m }$水管的整个层流范围。** **这是管内强制对流中最鲜为人知的事实：对于常规管径中的水，“层流”是一个实验室流态，你将来做的几乎每一个层流计算，要么是微尺度的，要么是油，要么就是一个错误。**

- [x] A 的壁面更热：在均匀热流密度下，壁温始终比流体高一个恒定的$q ^ { \prime \prime } / h$，而流体一路升到了$7 0 \ \ {} ^ { \circ } \mathrm { C }$；B 的壁面则趋近其流体，最终只比流体高几开尔文

::: summary
- **一个方程就是全部的记账：** $d T _ { m } / d x = P q _ { s } ^ { \prime \prime } / ( \dot { m } c _ { p } )$——平均温度以壁面供热的速率升高。恒热流密度给出线性的$T _ { m }$和恒定的壁面温差；恒壁温给出指数趋近，其中$\mathrm { N T U } = h A _ { s } / ( \dot { m } c _ { p } )$。
- **$T _ { m }$是按通量加权的混合平均温度，每一个管内关联式都在它下面取值**（对液体再加一个壁面黏度因子）。膜温度属于外部流动；把它们留在那里。
- **充分发展层流是一个定理，而不是一个关联式：** $\mathrm { N u } = 3 . 6 6$（恒$T _ { s }$）或$4 . 3 6$（恒$q ^ { \prime \prime }$），取决于形状，与流量无关。**如果你的层流设计显示$h$随流量提高，那你就处在入口段中——而你多半正是如此。**
- **层流入口段就是设计：** $\overline { { \mathrm { N u } } } = 1 . 8 6 ( \mathrm { R e } \, \mathrm { Pr } \, D / L ) ^ { 1 / 3 } ( \mu / \mu _ { s } ) ^ { 0 . 1 4 }$，在$\mathrm { R e } \, \mathrm { Pr } \, D / L \gtrsim 2 0$时适用；入口段长度为$0 . 0 5 \, \mathrm { Re } \, D$（层流）和约十倍管径（湍流）。
- **湍流：用迪图斯-贝尔特关联式估算，用格尼林斯基关联式定案。** $0 . 0 2 3 \, \mathrm { Re } ^ { 0 . 8 } \mathrm { Pr } ^ { n }$带有$\pm 2 5 \ \ \%$的误差；格尼林斯基关联式在$\mathrm { Re } = 1 0 ^ { 4 }$以上约为$\pm 1 0 \ \ \%$——而两者对过渡范围$2 3 0 0$–$1 0 ^ { 4 }$都一言不发，在那里老实的答案是移动工作点。
- **摩擦比拟为每一种强化定价：** $\mathrm { St } \, \mathrm { Pr } ^ { 2 / 3 } = f / 8$——扰流器、粗糙度和扭带以摩擦因子的兑换率购买热量，而好的强化手段能打败这个兑换率。
- **管径交易：** 在固定流量下，湍流$h \propto D ^ { - 1 . 8 }$，而$\Delta p \propto D ^ { - 4 . 8 }$；在固定管径下，流量加倍以$7$倍的泵功率换来$1 . 7 4$倍的热量。**微通道在传热上取胜，在压力上付账：$1 \ \mathrm { m / s }$下每米三分之一兆帕不是细节，它就是设计。**
- **当量直径：对湍流没问题，对层流很危险**——格雷茨数值在不同形状之间相差三倍；使用该形状自己的数值，或 Shah 的修正。
- **液态金属：$\mathrm { N u } \approx 5 + 0 . 0 2 5 \, \mathrm { Pe } ^ { 0 . 8 }$，与流量关系很弱**——巨大的表面传热系数，泵几乎无法使它提高，泵跳闸也几乎不会使它降低。
:::

## 延伸阅读

- **F. P. Incropera, D. P. DeWitt, T. L. Bergman & A. S. Lavine**，*Fundamentals of Heat and Mass Transfer*，第8版（Wiley，2017）——第8章就是本课的内容，包含每一个关联式、每一个修正因子以及完整的物性变化讨论。
- **R. K. Shah & A. L. London**，*Laminar Flow Forced Convection in Ducts*（Academic Press，1978）——完整的层流目录：每一种截面、每一种壁面条件、每一种入口段修正，都列在表中，当你的管道不是圆形的那一天，你会需要它们。
- **A. Bejan**，*Convection Heat Transfer*，第4版（Wiley，2013）——标度律的观点：为什么关联式具有它们所具有的指数，以及如何思考管内流动而不把任何单个关联式信任到超出其误差限的程度。
- **W. M. Kays & A. L. London**，*Compact Heat Exchangers*，第3版（McGraw-Hill，1984）——管内流动与真实硬件相遇之处：错位肋片、百叶窗和波纹表面的$j$因子和$f$因子数据，每一家换热器厂商都据此确定尺寸。
- **F. M. White**，*Viscous Fluid Flow*，第3版（McGraw-Hill，2006）——第6章讲述比拟中的摩擦因子一侧，包括传热关联式默默继承的粗糙壁面数据。
