稳态导热是一切都不随时间变化的情形：进入物体的热量全部离开，温度场是一个纯几何问题的解。这一个简化的价值极大：它把一个带初始条件的偏微分方程变成带边界条件的拉普拉斯方程，使复合墙中的温度场像电阻网络中的电流一样可算；并且意味着**对于一大类真实的工程问题——每一面墙、每一根包保温层的管道、每一个散热器底座、每一个冬季的建筑围护结构——答案就是一组倒数之和。**

热阻类比既不是比喻，也不是近似。在一维、导热系数为常数且无内热源的情况下，通过平壁、圆筒壳和球壳的热流量都取"驱动温差除以热阻"的形式，热阻像电路中那样严格地串联相加，并联路径则以热导相加。**这个类比恰好在两种情况下失效，两者都值得叫出名字：当导热系数强烈依赖于温度时（碳质炉衬或铝制低温衬里，$k$在壁厚内可变化一个数量级），以及当热流路径不是一维时（穿过保温层的螺栓、穿过冷墙的支架），此时二维和三维的扩散必须用形状因子或数值解来处理。**

本讲中有两个结果，其分量与其难度不成比例，而且两者都是通过对热阻关于半径求导得到的。**临界热绝缘半径**指出，在小直径物体上增加保温层，直到半径$k / h$为止都会**增加**散热量——这就是为什么电线包绝缘层是让它更凉而不是更热，也是为什么给一根$6\ \mathrm{mm}$的蒸汽管包上厚度不当的保温层反而会使问题更糟。**均匀内热源物体中的抛物线温度分布**指出，发热平板中心与表面之间的温差为$\dot{q} L^2 / 2k$——这就是为什么核燃料芯块的中心比表面高$700\ \mathrm{K}$，为什么芯片的结温随其厚度的**平方**变化，也是为什么内热源问题的答案总是"做得更薄"，而从不是"做得更大"。

::: warning 四个看起来算术正确的稳态导热错误
**把并联路径的热阻相加。**夹芯板有芯材和两根加强筋；冷库屋顶有保温层和钢螺栓；墙体有砖和空腔。如果各路径是并排的，**热导相加**：$U = \Sigma (A_j / A_{\text{tot}})(1 / R_j)$。如果把它们当作串联，你会得到一个偏小的答案；对于用螺栓固定的保温板，**每平方米四根$16\ \mathrm{mm}$螺栓就造成两倍的误差**。**在三维热流处用一维热阻。**进入埋在大介质中的小物体的热量并不沿圆柱面或球面传播；它是汇聚的。一根埋深$1.2\ \mathrm{m}$的$100\ \mathrm{mm}$管道散热$122\ \mathrm{W / m}$，而"把直到地表的土壤看作圆筒壳"的朴素模型预测$148\ \mathrm{W / m}$——**偏高$22\ \%$，而且偏向于不会给你省钱的方向。****忘记热阻在效果上可能是负的。**给半径小于$k / h$的圆柱加一层保温层会**增加**传热量，因为第二项即表面热阻$1 / ( 2 \pi r h )$下降得比第一项$\ln ( r _ { 2 } / r _ { 1 } ) / ( 2 \pi k )$上升得更快。**这不是奇谈：它是每一根小直径保温管线和每一根绝缘电缆的设计规则。****把只是$\pm 2 0\ \%$估计值的表面传热系数当作精确数。**在下面的保温管道例题中，保温层占热阻的$92\ \%$，外表面膜占$7.8\ \%$，所以$h$的$20\ \%$误差只使答案变化$1.6\ \%$——无关紧要。**在不保温的管道中，表面膜就是一切**；而在保温良好的建筑中，两层表面膜合计占墙体热阻的$12\ \%$，却是剩余改进空间的$100\ \%$。**在给出三位有效数字之前，先弄清你处在哪种情况。**
:::

## 方程与边界条件

::: definition 导热微分方程 {#def-heateq}
对一个固定的体积元$d V$作能量平衡，内热源强度为$\dot{q}$（单位$\mathrm{W / m^3}$）：积存量等于导入的净热量加上内热源，
$$
\rho c _ { p } { \frac { \partial T } { \partial t } } d V = - \nabla \cdot \boldsymbol{q} \, d V + { \dot { q } } \, d V \qquad \Longrightarrow \qquad \boxed { \; \rho c _ { p } { \frac { \partial T } { \partial t } } = \nabla \cdot \left( k \nabla T \right) + { \dot { q } } \; }
$$
当$k$为常数时即为$\partial T / \partial t = \alpha \nabla ^ { 2 } T + { \dot { q } } / \rho c _ { p }$。本课程的大部分工作由四种简化形式完成：
$$
\begin{array}{l l l}
\text{稳态，无内热源} & \nabla ^ { 2 } T = 0 & \text{拉普拉斯方程：墙体、保温层、形状因子} \\
\text{稳态，有内热源} & \nabla ^ { 2 } T = - { \dot { q } } / k & \text{泊松方程：芯片、燃料、汇流排} \\
\text{非稳态，无内热源} & \partial T / \partial t = \alpha \nabla ^ { 2 } T & \text{加热、淬火、昼夜温度波动} \\
\text{一维稳态} & \dfrac { d } { d x } \! \left( k { \dfrac { d T } { d x } } \right) = 0 & \text{你将来要报价的每一面墙}
\end{array}
$$
**从不写出却总在使用的那一个。**若$k = k ( T )$，一维稳态方程积分一次即得**基尔霍夫变换**（Kirchhoff transform），
$$
q ^ { \prime \prime } = \frac { 1 } { L } \int _ { T _ { 2 } } ^ { T _ { 1 } } k ( T ) \, d T
$$
因此导热系数线性变化的墙体，应使用**实际温度范围内的平均导热系数**，而不是数据表上$300\ \mathrm{K}$的值。**对于一种耐火材料，其$k$从$1200\ {}^{\circ}\mathrm{C}$热面的$28\ \mathrm{W / m\,K}$线性变化到$400\ {}^{\circ}\mathrm{C}$冷面的$12$，平均值为$20$；用冷面值会把散热量低估$40\ \%$（用热面值则高估同样的幅度）。**
:::

::: definition 三类边界条件 {#def-bcs}
每个方向上的二阶方程在每个边界上需要一个条件，值得一提的只有三类，外加一个"白送"的：
$$
\begin{array}{l l l}
\text{第一类（狄利克雷）} & T ( 0 ) = T _ { s } & \text{与大热源接触的表面} \\
\text{第二类（诺伊曼）} & - k \, d T / d x | _ { 0 } = q _ { 0 } ^ { \prime \prime } & \text{给定热流密度：加热器、制动盘面、绝热} \\
\text{第三类（罗宾）} & - k \, d T / d x | _ { 0 } = h \left[ T ( 0 ) - T _ { \infty } \right] & \text{对流：迄今最常见} \\
\text{对称 / 绝热} & d T / d x | _ { \text{中面 } } = 0 & \text{不是条件，而是结果：使求解域减半}
\end{array}
$$
**第三类边界条件是热阻网络之所以成立的原因**，因为它使边界条件对未知的表面温度是线性的，从而等价于一个接到电压源上的电阻。**一旦边界是辐射边界，$- k d T / d x = \epsilon \sigma ( T _ { s } ^ { 4 } - T _ { \mathrm { sur } } ^ { 4 })$，网络就不再是线性的**，类比就从算术变成了迭代——这就是为什么炉子的计算要做两遍，而管道保温的计算只做一遍。
:::

::: exercise 推导：由球壳导出导热微分方程 {level=3}
::: solution
在导热系数为$k$、单位体积内热源为$\dot{q}$的介质中，取$r$与$r + d r$之间的球壳。导热面积为$4 \pi r ^ { 2 }$，故导热进入的净速率为
$$
\left[ - k \, 4 \pi r ^ { 2 } { \frac { \partial T } { \partial r } } \right] _ { r } - \left[ - k \, 4 \pi r ^ { 2 } { \frac { \partial T } { \partial r } } \right] _ { r + d r } = { \frac { 1 } { r ^ { 2 } } } { \frac { \partial } { \partial r } } \! \left( k r ^ { 2 } { \frac { \partial T } { \partial r } } \right) 4 \pi r ^ { 2 } d r
$$
内热源项与积存项分别为${ \dot { q } } \, 4 \pi r ^ { 2 } d r$和$\rho c _ { p } ( \partial T / \partial t ) 4 \pi r ^ { 2 } d r$。令其相等并消去体积，
$$
\rho c _ { p } { \frac { \partial T } { \partial t } } = { \frac { k } { r ^ { 2 } } } { \frac { \partial } { \partial r } } \! \left( r ^ { 2 } { \frac { \partial T } { \partial r } } \right) + { \dot { q } }
$$
**两点解读，比推导本身更有价值。**导数内的因子$r ^ { 2 }$是**面积的增长**，它就是平壁与球之间的全部差别：平壁中面积不变，温度分布是直线；圆柱中面积随$r$增长，温度分布是对数曲线；球中面积随$r ^ { 2 }$增长，温度分布是双曲线$1 / r$。**第二点，也是能挽救设计的一点：由于面积向外增长，球壳或圆筒壳的热阻会饱和。**同心球壳的热阻为$( r _ { 2 } - r _ { 1 } ) / ( 4 \pi k r _ { 1 } r _ { 2 } )$，当$r _ { 2 } \to \infty$时趋于**有限**极限$1 / ( 4 \pi k r _ { 1 } )$。**在球上把保温层越做越厚，收益越来越小，过了某一点几乎毫无收益。**
:::
:::

::: example 从六个实际问题中读出边界条件 {#ex-bcs}
$$
\begin{array}{l l l}
\text{问题} & \text{边界条件} & \text{简化形式} \\
\text{冬季的房屋墙体} & \text{两面均为第三类} & \text{一维，拉普拉斯，两个热阻相加} \\
\text{向盖板导热的芯片} & \text{芯片处第二类，盖板处第三类} & \text{一维，拉普拉斯，} q ^ { \prime \prime } \text{ 已知} \\
\text{核燃料芯块} & r = 0 \text{ 处对称，} r _ { 1 } \text{ 处第三类} & \text{一维径向，泊松} \\
\text{外侧绝热的反应堆压力容器} & \text{内侧第三类，外侧第二类（零）} & \text{一维径向，拉普拉斯} \\
\text{热线风速仪探头} & \text{热线处第一类，} \infty \text{ 处 } T \to T _ { \infty } & \text{径向，拉普拉斯，} S = 2 \pi L / \ln ( 2 L / r ) \\
\text{受太阳加热的屋面板} & \text{外侧第二类（太阳辐射）+ 第三类，内侧第三类} & \text{一维，拉普拉斯，两个热流叠加}
\end{array}
$$
**最后一行承载着本例的要点。**受阳光照射的屋顶有**两个**第二类边界条件和两个第三类边界条件，而由于问题是线性的，答案就是两个解之和：一个由室内外温差驱动，另一个由吸收的太阳热流驱动。**建筑设备中的每一个"室外综合温度"（sol-air temperature）都是把这种叠加包装成单一的等效室外温度，它的精确程度恰好等于使之成立的线性程度——也就是说完全精确，直到有人在问题中加入相变材料或随温度变化的发射率为止。**
:::

## 一维墙体与热阻网络

::: definition 平壁与热阻网络 {#def-planewall}
对于厚度为$L$、面积为$A$、$k$为常数且两面均有对流的平壁，
$$
q = \frac { T _ { \infty , i } - T _ { \infty , o } } { R _ { i } + R _ { w } + R _ { o } } , \qquad R _ { i } = \frac { 1 } { h _ { i } A } , \quad R _ { w } = \frac { L } { k A } , \quad R _ { o } = \frac { 1 } { h _ { o } A }
$$
于是电路分析的整套工具都可以搬过来：**串联热阻相加，并联路径以热导相加，任一交界面上的温度由分压关系给出，且热流量在串联的每一个元件中都相同。**建筑行业对同一表述的形式是除以面积再取倒数：
$$
U = \frac { 1 } { \dfrac { 1 } { h _ { i } } + \displaystyle \sum _ { j } \dfrac { L _ { j } } { k _ { j } } + \dfrac { 1 } { h _ { o } } } \qquad \left[ U \right] = \mathrm { W / m ^ { 2 } K }
$$
称为**传热系数**（thermal transmittance）。其倒数$1 / U$是**$R$值**（单位面积热阻）；美国习惯给出$R$值，单位常为$\mathrm{ft^2\,{}^{\circ}F\,h/Btu}$，欧洲习惯以国际单位给出$U$值，**把两者弄混是一种常见且代价高昂的单位错误。**
**由分压关系得出的三条规则。**(i) **交界面温度是两侧环境温度的加权和**，权重等于另一侧的热阻，因此紧邻冷流体的一层薄的高导热层，其温度几乎就是该流体的温度。(ii) **凝结发生在温度分布穿过露点之处**，而这个交点只能由分压关系求得——这使得隔汽层的布置完全是一个热阻网络计算。(iii) **占主导的热阻起主导作用**：若某一层占总热阻的$90\ \%$，把其余所有层减半也只能使总热阻减小$5\ \%$，正是这笔算术阻止人们去重新设计错误的那一层。
:::

::: example 冷库墙体，以及水在哪里结冰 {#ex-coldstore}
一座$- 20\ {}^{\circ}\mathrm{C}$的冷库位于$30\ {}^{\circ}\mathrm{C}$、相对湿度$70\ \%$的空气中。其墙板为**两层$1\ \mathrm{mm}$钢板**（$k = 50$）之间夹**$150\ \mathrm{mm}$聚氨酯**（$k = 0.026\ \mathrm{W / m\,K}$）。取$h_i = 8$，$h_o = 25\ \mathrm{W / m^2 K}$，均已包括辐射项。
**每平方米的各项热阻。**
$$
{ \frac { 1 } { U } } = \underbrace { \frac { 1 } { 8 } } _ { 0 . 1 2 5 0 } + \underbrace { \frac { 2 \times 0 . 0 0 1 } { 5 0 } } _ { 0 . 0 0 0 0 4 } + \underbrace { \frac { 0 . 1 5 0 } { 0 . 0 2 6 } } _ { 5 . 7 6 9 2 } + \underbrace { \frac { 1 } { 2 5 } } _ { 0 . 0 4 0 0 } = 5 . 9 3 4 3 \ \mathrm { m ^ { 2 } K / W }
$$
$$
U = \mathbf { 0 . 1 6 8 5 \ W / m ^ { 2 } K } , \qquad q ^ { \prime \prime } = 0 . 1 6 8 5 \times 5 0 = \mathbf { 8 . 4 3 \ W / m ^ { 2 } }
$$
**两层钢皮只占热阻的$0.0007\ \%$**，它们是为结构强度和气密性而存在的，而不是出于热的考虑。**保温层占$97.2\ \%$，内表面膜占$2.1\ \%$，外表面膜占$0.7\ \%$。**
**露点在哪里？**$30\ {}^{\circ}\mathrm{C}$、$70\ \%$的室外空气露点为$23.9\ {}^{\circ}\mathrm{C}$。从外表面向内量取$x$，
$$
T ( x ) = 3 0 - q ^ { \prime \prime } \left( { \frac { 1 } { h _ { o } } } + { \frac { x } { k } } \right) = 3 0 - 8 . 4 3 \left( 0 . 0 4 + { \frac { x } { 0 . 0 2 6 } } \right) = 2 9 . 6 6 - 3 2 4 . 1 x
$$
$$
T ( x ) = 2 3 . 9 \quad \Longrightarrow \quad x = { \frac { 5 . 7 6 } { 3 2 4 . 1 } } = \mathbf { 1 7 . 8 \ m m \ i n s i d e \ t h e \ f o a m }
$$
**因此从暖侧向内扩散的水蒸气，从保温层内约$18\ \mathrm{mm}$处开始凝结，再往深处就结冰**，因为温度在$x = 9 1\ \mathrm{mm}$处降到$0\ {}^{\circ}\mathrm{C}$。水和冰的导热比泡沫孔中的气体好二十到八十倍，冻融又会破坏孔结构，所以受潮墙板的$U$值在其余生中会不断攀升。
**由此得出一条构造规则：隔汽层设在暖侧，而且必须连续，因为从一条小缝隙漏过的空气所携带的水分，远多于穿过整个完好隔汽层扩散的水分。**告诉你暖侧露点位于何处的，正是热阻网络。
:::

::: example 带接缝的炉墙 {#ex-furnace}
一面炉墙由**$230\ \mathrm{mm}$耐火砖**（$k = 1.1\ \mathrm{W / m\,K}$）和背衬的**$100\ \mathrm{mm}$陶瓷纤维**（$k = 0.10$）构成。热烟气为$1200\ {}^{\circ}\mathrm{C}$，$h_i = 120\ \mathrm{W / m^2 K}$；室内空气为$25\ {}^{\circ}\mathrm{C}$，$h_o = 25$。
**热阻网络。**
$$
{ \frac { 1 } { U } } = { \frac { 1 } { 1 2 0 } } + { \frac { 0 . 2 3 0 } { 1 . 1 } } + { \frac { 0 . 1 0 0 } { 0 . 1 0 } } + { \frac { 1 } { 2 5 } } = 0 . 0 0 8 3 3 + 0 . 2 0 9 0 9 + 1 . 0 0 0 0 0 + 0 . 0 4 0 0 0 = 1 . 2 5 7 4 2\ \mathrm { m ^ { 2 } K / W }
$$
$$
q ^ { \prime \prime } = { \frac { 1 2 0 0 - 2 5 } { 1 . 2 5 7 4 2 } } = \mathbf { 9 3 4\ W / m ^ { 2 } }
$$
**纤维层以$30\ \%$的厚度占了$79.5\ \%$的热阻。**再用分压关系求交界面温度：
$$
T _ { \text{交界面} } = 1 2 0 0 - 9 3 4 \times ( 0 . 0 0 8 3 3 + 0 . 2 0 9 0 9 ) = 1 2 0 0 - 2 0 3 = \mathbf { 9 9 7 ^ { \circ } C }
$$
**而这个数就是设计本身。**耐火砖的使用温度约为$1300\ {}^{\circ}\mathrm{C}$，在$997$下没有问题；如果两层颠倒，纤维的热面将处于约$1190\ {}^{\circ}\mathrm{C}$——接近普通陶瓷纤维等级的分级温度上限，而且直接暴露在火焰中，没有砖那样的机械强度和抗冲刷能力——而砖只处于约$260\ {}^{\circ}\mathrm{C}$。**规则：把耐用的耐火材料放在必须经受考验的热侧，把好的保温材料放在它后面、只需承担保温的地方**，并用分压关系逐层核对交界面温度是否超过其额定值。
**现在在交界面上加$2 \times 10 ^ { - 3 }\ \mathrm { m^2 K / W }$的接触热阻**（接缝砌筑不良）：
$$
q ^ { \prime \prime } = { \frac { 1 1 7 5 } { 1 . 2 5 7 4 2 + 0 . 0 0 2 } } = 9 3 3 . 0\ \mathrm { W / m ^ { 2 } }
$$
**变化$0.2\ \%$，察觉不到。**同样的接触热阻放在[[#ex-coldstore|冷库例题]]的冷库墙中只占$0.002 / 5.93 = 0.03\ \%$——而在自身热阻只有$0.2\ \mathrm{m^2 K / W}$的墙体中，比如铝框玻璃单元，它占$1\ \%$。**接触热阻是一个固定的绝对量，所以它的重要性取决于其他一切有多小：在炉子里可以忽略，在散热器里则起主导作用。**
:::

## 径向系统

::: definition 圆柱与球的导热 {#def-radial}
在长度为$L$、内外半径为$r_1$和$r_2$的长圆筒中，稳态无内热源方程$\frac{d}{dr}\left(r \frac{dT}{dr}\right) = 0$积分得对数函数，热阻随之得出：
$$
T ( r ) = T _ { 1 } - \left( T _ { 1 } - T _ { 2 } \right) { \frac { \ln \left( r / r _ { 1 } \right) } { \ln \left( r _ { 2 } / r _ { 1 } \right) } } , \qquad q = { \frac { T _ { 1 } - T _ { 2 } } { R _ { \mathrm { cyl } } } } , \qquad R _ { \mathrm { cyl } } = { \frac { \ln \left( r _ { 2 } / r _ { 1 } \right) } { 2 \pi k L } }
$$
对于球壳，温度分布是双曲线，热阻为
$$
T ( r ) = T _ { 1 } - \left( T _ { 1 } - T _ { 2 } \right) { \frac { 1 - r _ { 1 } / r } { 1 - r _ { 1 } / r _ { 2 } } } , \qquad R _ { \mathrm { sph } } = { \frac { r _ { 2 } - r _ { 1 } } { 4 \pi k r _ { 1 } r _ { 2 } } } \ { \xrightarrow [ r _ { 2 } \to \infty ] { } }\ { \frac { 1 } { 4 \pi k r _ { 1 } } }
$$
**三个在平壁中没有对应物的推论。**
**(i) 对数意味着最初一厘米的保温层做了大部分工作。**对于管道，$R_{\mathrm{cyl}}$随$\ln(r_2/r_1)$增长，所以**把保温层外半径加倍，无论管径多大，增加的热阻都是同样的$\ln 2 / 2 \pi k$**——而且每再加倍一次也只增加同样的量，因此每增加单位热阻所需的保温材料体积呈几何级数增长。
**(ii) 面积向外增长，所以热流密度不均匀。**在下面[[#ex-pipe|保温管道例题]]中的$50\ \mathrm{mm}$保温层上，内表面的热流密度是外表面的$160.3 / 60.3 = 2.66$倍。**任何关于"保温管道的热流密度"的说法都必须说明是指哪个半径处。**
**(iii) 球的热阻会饱和。**由于面积随$r^2$增长，比厚度增长得快，当外半径趋于无穷时，球壳的热阻有一个**有限极限**。**一个球与远处介质之间存在一个最大可能热阻，它就是$1 / ( 4 \pi k r _ { 1 } )$——一个只取决于球自身半径和介质、而与介质延伸多远无关的数。**每一个埋地物体、每一个接地电极以及每一个由球体散热的计算都继承了这一上限。
:::

::: definition 临界热绝缘半径 {#def-critical}
在外半径为$r_1$的圆柱上包一层导热系数为$k_i$的保温层，外侧表面传热系数为$h$。单位长度的总热阻为
$$
R ^ { \prime } ( r ) = { \frac { \ln \left( r / r _ { 1 } \right) } { 2 \pi k _ { i } } } + { \frac { 1 } { 2 \pi r h } }
$$
第一项上升而第二项下降，求导得
$$
\frac { d R ^ { \prime } } { d r } = 0 \quad \Longleftrightarrow \quad \boxed { r _ { \mathrm { cr } } = \frac { k _ { i } } { h } } \qquad \text{（热阻最小，散热量最大）}
$$
**在$r_{\mathrm{cr}}$以下，增加保温层反而使物体冷却得更好；在其以上，它才起保温作用。**对于球，同样的推导给出$r _ { \mathrm { cr } } = 2 k _ { i } / h$，宽松一倍。
$$
\begin{array}{l c c c}
\text{空气中小物体上的保温材料} & k _ { i } & h & r _ { \mathrm { cr } } \\
\text{聚氯乙烯} & 0 . 2 3 & 1 0 & 2 3 \mathrm { m m } \\
\text{橡胶} & 0 . 1 3 & 1 0 & 1 3 \mathrm { m m } \\
\text{玻璃棉} & 0 . 0 4 & 1 0 & 4 \mathrm { m m } \\
\text{聚氨酯} & 0 . 0 2 6 & 1 0 & 2 . 6 \mathrm { m m } \\
\text{硅酸钙} & 0 . 0 8 & 1 2 & 6 . 7 \mathrm { m m }
\end{array}
$$
**对照物体来读这张表。**半径$50\ \mathrm{mm}$的蒸汽管远大于表中每一个$r_{\mathrm{cr}}$，所以保温总是有益的。**半径$3\ \mathrm{mm}$的毛细管、电线、热电偶测温球或光纤则小于其中大多数**，对这些物体而言，在$r_{\mathrm{cr}}$以内保温层就是散热器。**这个工程推论并非纸上谈兵：细导线加上塑料护套后，其载流量可能提高，因为护套降低了导线到环境的总热阻。**
:::

::: example 保温蒸汽管：热阻究竟在哪里 {#ex-pipe}
一根**外径$60.3\ \mathrm{mm}$、壁厚$3.91\ \mathrm{mm}$**的碳钢管（$k = 45\ \mathrm{W / m\,K}$）输送$250\ {}^{\circ}\mathrm{C}$的蒸汽，内表面传热系数$h_i = 2000\ \mathrm{W / m^2 K}$。管外包**$50\ \mathrm{mm}$硅酸钙**（$k = 0.08$），位于$25\ {}^{\circ}\mathrm{C}$的设备间内，$h_o = 12\ \mathrm{W / m^2 K}$。求每米散热量和表面温度。
**每米管长的四项热阻。**
$$
\begin{array}{l c l}
R _ { i } ^ { \prime } = \dfrac { 1 } { h _ { i } \pi d _ { i } } = \dfrac { 1 } { 2 0 0 0 \times \pi \times 0 . 0 5 2 5 } & = 3 . 0 3 \times 1 0 ^ { - 3 } & 0 . 1 4 \ \% \\[4pt]
R _ { \mathrm { steel } } ^ { \prime } = \dfrac { \ln ( 6 0 . 3 / 5 2 . 5 ) } { 2 \pi \times 4 5 } & = 4 . 9 1 \times 1 0 ^ { - 4 } & 0 . 0 2 \ \% \\[4pt]
R _ { \mathrm { lag} } ^ { \prime } = \dfrac { \ln ( 1 6 0 . 3 / 6 0 . 3 ) } { 2 \pi \times 0 . 0 8 } & = 1 . 9 4 5 0 & \mathbf { 9 2 . 0 \ \% } \\[4pt]
R _ { o } ^ { \prime } = \dfrac { 1 } { h _ { o } \pi d _ { o } } = \dfrac { 1 } { 1 2 \times \pi \times 0 . 1 6 0 3 } & = 0 . 1 6 5 5 & 7 . 8 \ \%
\end{array}
$$
$$
\sum R ^ { \prime } = 2 . 1 1 4\ \mathrm { m \, K / W } , \qquad q ^ { \prime } = { \frac { 2 5 0 - 2 5 } { 2 . 1 1 4 } } = \mathbf { 1 0 6 . 4 \ W / m }
$$
**钢管只占热阻的$0.02\ \%$，管壁上的全部温降只有$0.05\ \mathrm{K}$。**钢管是用来盛装蒸汽的，而不是用来导热的，**任何保温管道计算都不应该在金属上花一行字。**
**用分压关系求温度分布。**
$$
T _ { \text{内壁} } = 2 5 0 - 1 0 6 . 4 \times 0 . 0 0 3 0 3 = 2 4 9 . 7 ^ { \circ } \mathrm { C } , \qquad T _ { \text{保温层外表面} } = 2 4 9 . 6 - 1 0 6 . 4 \times 1 . 9 4 5 = \mathbf { 4 2 . 6 ^ { \circ } C }
$$
**而$4 2 . 6 - 1 0 6 . 4 \times 0 . 1 6 5 5 = 2 5 . 0\ {}^{\circ}\mathrm{C}$，平衡闭合。**保温层外表面为$42.6\ {}^{\circ}\mathrm{C}$，低于$60\ {}^{\circ}\mathrm{C}$的接触限值，因此保温层也在履行它的另一项职责：保护人员。
**三点设计解读。**(i) **$92\ \%$的热阻来自硅酸钙**，所以唯一要紧的杠杆是它的厚度和状况——而**受潮的保温层是典型的失效形式，因为$k = 0.6$的水是硅酸钙的七倍半，会使这一散热量增大约五倍。**(ii) **外表面膜占$7.8\ \%$**，所以一旦保温层足够厚，再加厚收益就会减少，剩下唯一的改进是让保温层外表面更大或更好：**低发射率的铝制外护层会使$h_o$变差而不是变好，这就是为什么保温外护层是为机械保护和防水而规定的，从不计入节热效果。**(iii) **保温层外表面温度是操作人员评判这项工作的数字**，它等于散热量乘以外表面膜热阻：比室温高$106.4 \times 0.1655 = 17.6\ \mathrm{K}$。
:::

::: example 给导线保温与给管道保温：相反的答案 {#ex-critical}
**情形A：直径$1.5\ \mathrm{mm}$的导体**，包$k = 0.13\ \mathrm{W / m\,K}$的橡胶，处于$h = 12\ \mathrm{W / m^2 K}$的静止空气中。
$$
r _ { \mathrm { cr } } = { \frac { 0 . 1 3 } { 1 2 } } = 1 0 . 8 3 \ \mathrm { m m } \gg r _ { 1 } = 0 . 7 5 \ \mathrm { m m }
$$
$$
R _ { \text{裸线} } ^ { \prime } = { \frac { 1 } { 2 \pi \times 0 . 0 0 0 7 5 \times 1 2 } } = 1 7 . 6 8 \ \mathrm { m \, K / W } , \qquad R _ { \text{在 } r _ { \mathrm { cr } } \text{ 处} } ^ { \prime } = { \frac { \ln ( 1 0 . 8 3 / 0 . 7 5 ) } { 2 \pi \times 0 . 1 3 } } + { \frac { 1 } { 2 \pi \times 0 . 0 1 0 8 3 \times 1 2 } } = 3 . 2 6 9 + 1 . 2 2 4 = 4 . 4 9 4
$$
**保温层使散热量增大到$1 7 . 6 8 / 4 . 4 9 4 = 3 . 9 4$倍。**原本比环境高$53\ \mathrm{K}$运行的导体，现在只高$13\ \mathrm{K}$，保温层在充当散热器。
**情形B：外径$60.3\ \mathrm{mm}$的管道**，包$k = 0.08$的硅酸钙，$h = 12$。
$$
r _ { \mathrm { cr } } = { \frac { 0 . 0 8 } { 1 2 } } = 6 . 7 \ \mathrm { m m } \ll r _ { 1 } = 3 0 . 2 \ \mathrm { m m }
$$
**管道在包保温层之前就已是临界半径的四倍半**，所以每一毫米保温层都起保温作用，散热量最大的那一点已永远落在身后。
**判定你处于哪种情形的规则。**计算$r _ { \mathrm { cr } } = k _ { i } / h$，并与裸露半径比较。**对于静止空气中的橡胶或塑料绝缘（$r_{\mathrm{cr}} \approx 10$–$25\ \mathrm{mm}$），导线和小管属于情形A，最初几毫米的绝缘层是降温而不是保温；对于现代泡沫材料（$r_{\mathrm{cr}} \approx 3$–$4\ \mathrm{mm}$），只有最小的物体才属于情形A。**对于任何管道、风管或容器，你都处于情形B，"保温减少散热"的直觉是可靠的。
:::

## 内热源：为什么中间最热

::: definition 均匀内热源给出抛物线或对数修正的温度分布 {#def-generation}
在均匀体积内热源$\dot{q}$和常数$k$下，方程为泊松方程，温度分布为：
$$
\begin{array}{l l l l}
\text{平板，厚 } 2 L \text{，两面温度 } T _ { s } & T ( x ) - T _ { s } = \dfrac { { \dot { q } } } { 2 k } \left( L ^ { 2 } - x ^ { 2 } \right) & T _ { \max } - T _ { s } = \dfrac { { \dot { q } } L ^ { 2 } } { 2 k } & q ^ { \prime \prime } = { \dot { q } } L \\[8pt]
\text{圆柱，半径 } r _ { 1 } \text{，表面温度 } T _ { s } & T ( r ) - T _ { s } = \dfrac { { \dot { q } } } { 4 k } \left( r _ { 1 } ^ { 2 } - r ^ { 2 } \right) & T _ { \max } - T _ { s } = \dfrac { { \dot { q } } r _ { 1 } ^ { 2 } } { 4 k } = \dfrac { q ^ { \prime } } { 4 \pi k } & q ^ { \prime } = { \dot { q } } \pi r _ { 1 } ^ { 2 } \\[8pt]
\text{球，半径 } r _ { 1 } \text{，表面温度 } T _ { s } & T ( r ) - T _ { s } = \dfrac { { \dot { q } } } { 6 k } \left( r _ { 1 } ^ { 2 } - r ^ { 2 } \right) & T _ { \max } - T _ { s } = \dfrac { { \dot { q } } r _ { 1 } ^ { 2 } } { 6 k } & q = { \dot { q } } \frac { 4 } { 3 } \pi r _ { 1 } ^ { 3 }
\end{array}
$$
**三个结构性事实。**(i) **中心与表面的温差正比于总功率、反比于导热系数，在平板中取决于半厚的平方，在圆柱或球中取决于半径的平方。****把发热体做薄是平方律的收益，做大则是平方律的损失**，这无法绕过，因为热量必须走过与尺寸成正比的距离，而它所穿过的面积只随平方增长。(ii) **表面热流密度只由内热源和尺寸决定**——$q'' = \dot{q}L$，$q' = \dot{q}\pi r_1^2$——**因此冷却负荷无可商量，可以商量的只有物体内部的温降。**(iii) **温度分布是抛物线，所以表面处的温度梯度是平均梯度的两倍**，任何表面损伤、热应力或沸腾临界热流密度的计算都必须使用表面梯度，而不是平均值。
:::

::: example 核燃料芯块与硅芯片 {#ex-generation}
**芯块。**二氧化铀燃料棒的芯块直径为$8.2\ \mathrm{mm}$，工作温度下的导热系数为$k = 2.8\ \mathrm{W / m\,K}$，线功率为$q' = 25\ \mathrm{kW / m}$。
$$
T _ { \text{中心} } - T _ { \text{表面} } = { \frac { q ^ { \prime } } { 4 \pi k } } = { \frac { 2 5 { , } 0 0 0 } { 4 \pi \times 2 . 8 } } = \mathbf { 7 1 1 \ K }
$$
**四毫米之内七百开尔文。**体积释热率为$\dot{q} = 2 5 { , } 0 0 0 / ( \pi \times 0 . 0 0 4 1 ^ { 2 } ) = 4 . 7 3 \times 1 0 ^ { 8 }\ \mathrm { W / m^3 }$；再加上燃料与包壳间隙、包壳和冷却剂膜层上的温降，这就是为什么在冷却剂约为$300\ {}^{\circ}\mathrm{C}$的反应堆中，芯块中心线温度远高于$1000\ {}^{\circ}\mathrm{C}$。
**三个推论。**(i) **二氧化铀的熔点约为$2850\ {}^{\circ}\mathrm{C}$，而到熔化的裕度被芯块自身的$711\ \mathrm{K}$加上间隙、包壳和冷却剂膜层的温降所蚕食**——这就是为什么燃料设计者限制的是线功率，而不是总功率。(ii) **由于$\Delta T \propto q'$，功率提升$10\ \%$就意味着中心线温度上升$71\ \mathrm{K}$**，这就是围绕机组"提升功率"之争的全部内容。(iii) **由于在线功率固定时$\Delta T$与半径无关**，在相同kW/m下把芯块做粗并无帮助；在相同**体积**释热率下做粗，则$\Delta T$按半径的平方增大。**降低芯块内部温降的唯一途径是采用导热系数更高的燃料（硅化铀和氮化铀就是部分出于这一原因而被研究的候选材料之一），或者降低线功率——用更多、更细的燃料棒分担同样的堆芯功率。**
**芯片。**一块$12 \times 12\ \mathrm{mm}$、厚$0.5\ \mathrm{mm}$的硅芯片均匀发热$45\ \mathrm{W}$，通过一个面冷却。
$$
\dot { q } = { \frac { 4 5 } { 1 . 4 4 \times 1 0 ^ { - 4 } \times 5 \times 1 0 ^ { - 4 } } } = 6 . 2 5 \times 1 0 ^ { 8 } \ \mathrm { W / m ^ { 3 } } , \qquad T _ { \max } - T _ { \text{冷却面} } = { \frac { { \dot { q } } L ^ { 2 } } { 2 k } } = { \frac { 6 . 2 5 \times 1 0 ^ { 8 } \times 2 . 5 \times 1 0 ^ { - 7 } } { 2 \times 1 4 8 } } = \mathbf { 0 . 5 3 \ K }
$$
这里$L = 0.5\ \mathrm{mm}$是全厚度，因为未冷却的那一面是绝热的。（对照[[heat-transfer/heat-transfer-modes#ex-die]]，那里同样的$45\ \mathrm{W}$穿过整个厚度，温降是此值的两倍。）**体积释热率与燃料芯块大致相同，温降却小了一千多倍——因为热流路径短了八倍，而这要按平方计；同时硅的导热比二氧化铀好五十倍。****这是微电子热设计中最可迁移的一个数：薄不是制造上的便利，而是热策略本身。**这就是为什么芯片在堆叠前要从$700\ \mu\mathrm{m}$减薄到$50\ \mu\mathrm{m}$，为什么会有硅通孔，也是为什么功率模块中的介质层是其中最难的热问题。
:::

## 三维导热：形状因子

::: definition 导热形状因子 {#def-shape}
只要导热系数为$k$的物体连接两个温差为$\Delta T$的等温面，热流量就可以写成
$$
q = S k \, \Delta T
$$
其中$S$称为**形状因子**，具有长度的量纲，只取决于几何形状。**它是$A / L$在三维中的推广，并且恰好对这样的情形有定义：两个表面等温，其余一切要么绝热，要么在很远处。**由于拉普拉斯方程是线性的，而$S$是一个纯数乘以一个长度，一张$S$值表就是一张已解问题的表：
$$
\begin{array}{l l}
\text{平壁，面积 } A \text{，厚度 } L & S = A / L \\
\text{长圆筒，} r _ { 2 } > r _ { 1 } & S = 2 \pi L / \ln \left( r _ { 2 } / r _ { 1 } \right) \\
\text{同心球} & S = 4 \pi r _ { 1 } r _ { 2 } / \left( r _ { 2 } - r _ { 1 } \right) \\
\text{无限大介质中半径为 } r \text{ 的等温球} & S = 4 \pi r \\
\text{无限大介质中直径为 } D \text{ 的等温圆盘} & S = 2 D \\
\text{埋深 } z \text{ 的直径 } D \text{ 水平管（} z > 1 . 5 D , \ L \gg D \text{）} & S = 2 \pi L / \ln \left( 4 z / D \right) \\
\text{竖直圆柱，长 } L \text{，半径 } r \text{，顶端与地表齐平} & S = 2 \pi L / \ln \left( 2 L / r \right) \\
\text{半径 } r \text{、球心埋深 } z \text{ 的球} & S = 4 \pi r / ( 1 - 0 . 5 \, r / z ) \\
\text{无限大介质中边长为 } a \text{ 的等温立方体} & S = 8 . 2 4 \, a \\
\text{间距 } s \gg D \text{ 的 } N \text{ 根等距埋地管} & S \approx 2 \pi N L / \ln \left( 4 z / D \right) \ \text{（忽略相互影响）}
\end{array}
$$
**两点注意。**形状因子假定**两个**表面都等温；实际管道还有串联的管壁热阻和流体热阻，必须作为普通热阻相加，于是$1 / ( S k )$成为总和中的又一项。**而且埋地管公式在接近地表时迅速变差**：它是在$z > 1 . 5 D$条件下导出的，在$z > 2 D$时精度在百分之几以内；在此以下，地表不再近似等温，答案必须由共形映射或网格计算给出。
:::

::: example 埋地区域供热管道 {#ex-buried}
一根**外径$100\ \mathrm{mm}$**的区域供热干管在$80\ {}^{\circ}\mathrm{C}$下运行，管中心线埋深**$1.2\ \mathrm{m}$**，土壤$k = 1.0\ \mathrm{W / m\,K}$，地表温度为$5\ {}^{\circ}\mathrm{C}$。
**用形状因子。**
$$
S ^ { \prime } = { \frac { 2 \pi } { \ln \left( 4 \times 1 . 2 / 0 . 1 \right) } } = { \frac { 6 . 2 8 3 2 }{ \ln 4 8 } } = { \frac { 6 . 2 8 3 2 } { 3 . 8 7 1 2 } } = 1 . 6 2 3 \ \mathrm { m } \ \text{每米管长}
$$
$$
q ^ { \prime } = 1 . 6 2 3 \times 1 . 0 \times ( 8 0 - 5 ) = \mathbf { 1 2 2 \ W / m }
$$
**用朴素的一维模型**——"把直到$1.2\ \mathrm{m}$深的土壤看作圆筒壳"：
$$
R ^ { \prime } = { \frac { \ln \left( 1 . 2 / 0 . 0 5 \right) } { 2 \pi \times 1 . 0 } } = 0 . 5 0 5 8 \quad \Longrightarrow \quad q ^ { \prime } = { \frac { 7 5 } { 0 . 5 0 5 8 } } = 1 4 8 \ \mathrm { W / m } \qquad \left( \text{偏高 } 2 2 \ \% \right)
$$
**朴素模型之所以错，是因为热量并不沿圆柱面传播；它是从比$50\ \mathrm{mm}$到$1.2\ \mathrm{m}$之间的圆筒壳大得多的土壤体积向管道汇聚的，而多出来的面积正是形状因子所计入的。**
**现在给它包上$50\ \mathrm{mm}$聚氨酯**（$k = 0.026$），把泡沫作为普通串联热阻加入：
$$
R _ { \mathrm { foam } } ^ { \prime } = { \frac { \ln \left( 0 . 1 0 / 0 . 0 5 \right) } { 2 \pi \times 0 . 0 2 6 } } = 4 . 2 4 3 , \qquad R _ { \mathrm { soil} } ^ { \prime } = { \frac { 1 } { S ^ { \prime } k } } = { \frac { 1 } { 1 . 6 2 3 } } = 0 . 6 1 6
$$
$$
q ^ { \prime } = { \frac { 7 5 } { 4 . 8 5 9 } } = \mathbf { 1 5 . 4 \ W / m } \qquad \left( { \frac { 1 2 2 } { 1 5 . 4 } } = 7 . 9 \ \text{倍的降低} \right)
$$
**土壤热阻现在只占总热阻的$12.7\ \%$，而且无法通过加厚泡沫来减小。****这是冷库上限的埋地管版本：大地是一个品质有限的热汇，它的热导由管道自身的尺寸和埋深决定，而不由你包在管上的任何东西决定。**相比之下，埋深是一根弱杠杆：把这根管道再埋深$0.4\ \mathrm{m}$，裸管散热量减少约$7\ \%$，保温管则不到$1\ \%$——这就是为什么热设计是在泡沫上做的，而不是在管沟上。
:::

::: exercise 铜汇流排自身的温降 {#ex-bus level=1 check="0.37"}
热量以$5\ \mathrm{W / cm^2}$的热流密度穿过一根铜汇流排$3\ \mathrm{mm}$的厚度。取$k = 401\ \mathrm{W / m\,K}$。厚度方向上的温差是多少K？

::: solution
$$
\Delta T = { \frac { q ^ { \prime \prime } L } { k } } = { \frac { 5 \times 1 0 ^ { 4 } \times 3 \times 1 0 ^ { - 3 } } { 4 0 1 } } = \mathbf { 0 . 3 7 \ K }
$$
**不到半开尔文。**这就是金属被当作等温体而非金属不被如此对待的原因：同样的热流密度穿过$3\ \mathrm{mm}$不锈钢（$k \approx 16$）为$9.4\ \mathrm{K}$，穿过$3\ \mathrm{mm}$致密氧化铝（$k \approx 30$）为$5\ \mathrm{K}$，穿过$3\ \mathrm{mm}$环氧树脂（$k \approx 0.2$）则为$750\ \mathrm{K}$。**由此得出的经验法则应在打开计算器之前使用：金属通常不是热阻所在，而塑料总是。**
:::

::: exercise 保温凝结水回水管 {#ex-cond level=2 check="106.4"}
一根外径$60.3\ \mathrm{mm}$、壁厚$3.91\ \mathrm{mm}$的碳钢管（$k = 45\ \mathrm{W / m\,K}$）输送$250\ {}^{\circ}\mathrm{C}$的凝结水，$h_i = 2000\ \mathrm{W / m^2 K}$。管外包$50\ \mathrm{mm}$硅酸钙（$k = 0.08$），位于$25\ {}^{\circ}\mathrm{C}$的房间内，$h_o = 12\ \mathrm{W / m^2 K}$。每米散热量是多少W/m？

$$
\begin{aligned}
R _ { i } ^ { \prime } & = 1 / ( 2 0 0 0 \times \pi \times 0 . 0 5 2 5 ) = 0 . 0 0 3 0 3 \\
R _ { \mathrm { steel} } ^ { \prime } & = \ln ( 6 0 . 3 / 5 2 . 5 ) / ( 2 \pi \times 4 5 ) = 0 . 0 0 0 4 9 \\

R _ { o } ^ { \prime } & = 1 / ( 1 2 \times \pi \times 0 . 1 6 0 3 ) = 0 . 1 6 5 4 5
\end{aligned}

$$
q ^ { \prime } = { \frac { 2 2 5 } { 2 . 1 1 3 9 8 } } = \mathbf { 1 0 6 . 4 \ W / m }
$$
**保温层占$92.0\ \%$，外表面膜占$7.8\ \%$，钢管与内表面膜合计占$0.17\ \%$。**按每年$6000$等效满负荷小时计，这根管道每公里散失$638\ \mathrm{MWh}$——对一根$60\ \mathrm{mm}$的管线来说是很大的损失，也提醒我们保温层厚度是一个经济决策。

::: exercise 给细导线包绝缘 {#ex-wire level=2 check="3.94"}
一根直径$1.5\ \mathrm{mm}$的导体包以$k = 0.13\ \mathrm{W / m\,K}$的橡胶，向$h = 12\ \mathrm{W / m^2 K}$的空气散热。当橡胶加厚到临界半径时，每米散热量增大到几倍？

::: solution
$$
r _ { \mathrm { cr } } = { \frac { 0 . 1 3 } { 1 2 } } = 1 0 . 8 3 \ \mathrm { m m }
$$
$$
R _ { \text{裸线} } ^ { \prime } = { \frac { 1 } { 2 \pi \times 0 . 0 0 0 7 5 \times 1 2 } } = 1 7 . 6 8 4 \ \mathrm { m \, K / W } , \qquad R _ { \mathrm { cr} } ^ { \prime } = { \frac { \ln ( 1 0 . 8 3 / 0 . 7 5 ) } { 2 \pi \times 0 . 1 3 } } + { \frac { 1 } { 2 \pi \times 0 . 0 1 0 8 3 \times 1 2 } } = 3 . 2 6 9 + 1 . 2 2 4 = 4 . 4 9 4

::: exercise 球形储罐保温层的上限 {#ex-sphlevel level=2 check="1.77"}
一个外半径$0.5\ \mathrm{m}$的球形低温容器包有$100\ \mathrm{mm}$二氧化硅气凝胶毡（$k = 0.015\ \mathrm{W / m\,K}$）。该毡层的导热热阻是多少？任意厚度的毡层所能给出的最大热阻又是多少？输入毡层的热阻，单位K/W。

::: solution
$$
R = { \frac { r _ { 2 } - r _ { 1 } } { 4 \pi k r _ { 1 } r _ { 2 } } } = { \frac { 0 . 1 } { 4 \pi \times 0 . 0 1 5 \times 0 . 5 \times 0 . 6 } } = { \frac { 0 . 1 } { 0 . 0 5 6 5 5 } } = \mathbf { 1 . 7 7 \ K / W }
$$
$$
R _ { \max } = { \frac { 1 } { 4 \pi k r _ { 1 } } } = { \frac { 1 } { 4 \pi \times 0 . 0 1 5 \times 0 . 5 } } = \mathbf { 1 0 . 6 \ K / W }
$$
**$100\ \mathrm{mm}$的毡层只达到理论最大值的$17\ \%$；要达到最大值的一半，需要$R / R _ { \max } = 1 - r _ { 1 } / r _ { 2 } = 0 . 5$，即$r _ { 2 } = 1.0\ \mathrm{m}$——在半径半米的储罐上包半米厚的气凝胶。****这就是球导热的饱和性质作为一个设计事实：在球上，保温层厚度有一个任何预算都达不到的硬上限，把钱花在同样厚度下导热系数更低的材料上，远比花在更厚上划算。**同样的算术也说明了为什么小型低温球罐按比例比大型的更难保温：最小可能的漏热$\Delta T / R_{\max}$正比于$r_1$，而容积按$r_1^3$变化，所以半径减半会使相对蒸发率变为四倍。
:::

::: exercise 燃料芯块自身的极限 {#ex-pellet level=2 check="710.5"}
一个二氧化铀燃料芯块直径$8.2\ \mathrm{mm}$，工作温度下的导热系数为$2.8\ \mathrm{W / m\,K}$，线功率为$25\ \mathrm{kW / m}$。芯块中心线与表面之间的温差是多少K？

::: solution
$$
T _ { 0 } - T _ { s } = { \frac { q ^ { \prime } } { 4 \pi k } } = { \frac { 2 5 { , } 0 0 0 } { 4 \pi \times 2 . 8 } } = { \frac { 2 5 { , } 0 0 0 } { 3 5 . 1 9 } } = \mathbf { 7 1 0 . 5 \ K }
$$
**注意答案中不含直径**，因为在线功率固定时，直径在$\dot q \propto 1 / r^2$与$\Delta T \propto r^2$之间相消。**直径真正控制的是给定功率的堆芯需要多少根燃料棒，从而控制每根棒承担的线功率**：在相同堆芯功率下采用更多、更细的燃料棒栅格可以降低$q'$，这才是真正降低这一温降的杠杆。
:::

::: exercise 导热系数随温度变化的耐火材料 {#ex-meank level=2 check="1078"}
一面$230\ \mathrm{mm}$的硅藻土隔热砖墙，两面温度为$900$和$100\ {}^{\circ}\mathrm{C}$。砖的导热系数在$100\ {}^{\circ}\mathrm{C}$时为$0.36\ \mathrm{W / m\,K}$，$500\ {}^{\circ}\mathrm{C}$时为$0.31$，$900\ {}^{\circ}\mathrm{C}$时为$0.28$。估算热流密度，单位$\mathrm{W/m^2}$。

::: solution
对于$k ( T )$随$T$线性变化的一维稳态导热，基尔霍夫变换表明应使用**两表面平均温度**下的导热系数——这里为$500\ {}^{\circ}\mathrm{C}$，故$k = 0.31$：
$$
q ^ { \prime \prime } = { \frac { { \bar { k } } \, \Delta T } { L } } = { \frac { 0 . 3 1 \times 8 0 0 } { 0 . 2 3 0 } } = \mathbf { 1 0 7 8 \ W / m ^ { 2 } }
$$
**用冷面值$0.36$会得到$1252\ \mathrm{W / m^2}$，高估$16\ \%$；用热面值$0.28$会得到$974$，低估$10\ \%$。****当$k ( T )$随$T$线性变化时平均值法则是精确的，否则精度也在百分之几以内**：对这里的分段线性数据精确积分得$\int k\,dT / L = 1096\ \mathrm{W/m^2}$，比估计值高$1.6\ \%$。**误差的方向值得记住：当$k$随温度下降时（如这种砖），用室温下的数据表值会高估散热量；当$k$随温度上升时（许多隔热耐火材料都是如此），同样的值会低估散热量。**
:::

::: exercise 穿过保温层的钢螺栓 {#ex-bolts level=3 check="1.60"}
一个冷库屋顶为$50\ \mathrm{mm}$玻璃棉（$k = 0.04\ \mathrm{W / m\,K}$），**每平方米有四根直径$16\ \mathrm{mm}$的钢螺栓**（$k = 50\ \mathrm{W / m\,K}$）贯穿全厚。忽略表面膜，保温层的有效$U$值是多少？

::: solution
螺栓与玻璃棉是**并联**的，因此在一平方米平面面积上热导相加。每根螺栓杆的截面积$= \pi \times 0 . 0 1 6 ^ { 2 } / 4 = 2 . 0 1 \times 1 0 ^ { - 4 }\ \mathrm { m^2 }$，四根为$A_b = 8 . 0 4 \times 1 0 ^ { - 4 }\ \mathrm { m^2 }$：
$$
U _ { \text{玻璃棉} } = { \frac { 0 . 0 4 \times ( 1 - 8 . 0 4 \times 1 0 ^ { - 4 } ) } { 0 . 0 5 } } = 0 . 7 9 9 4 \ \mathrm { W / m ^ { 2 } K } , \qquad U _ { \text{螺栓} } = { \frac { 5 0 \times 8 . 0 4 \times 1 0 ^ { - 4 } } { 0 . 0 5 } } = 0 . 8 0 4 0 \ \mathrm { W / m ^ { 2 } K }
$$
$$
U = 0 . 7 9 9 4 + 0 . 8 0 4 0 = \mathbf { 1 . 6 0 \ W / m ^ { 2 } K }
$$
**每平方米四根钢螺栓——只占面积的$0.08\ \%$——恰好使漏热翻倍。**比值为$k_b / k_w \times A_b / A = 50 / 0.04 \times 8 . 0 4 \times 1 0 ^ { - 4 } = 1 . 0 0 5$，即**每根螺栓所抵消的保温面积等于其自身面积乘以导热系数之比，对于玻璃棉中的钢而言这个比为$1250$。****这是低温构造中设计最不足的单一细部：**同样的问题还以穿过空腔墙的钢托架角钢、穿墙构件、中空玻璃中的铝间隔条以及夹芯板中的紧固件等形式出现——而标准的补救措施永远是同样两步：**使用导热系数更低的紧固件（玻璃钢、不锈钢或断热支架），并减少数量**，因为面积分数是你唯一能廉价控制的项。
:::

::: exercise 给埋地干管保温 {#ex-buried2 level=2 check="15.4"}
对于[[#ex-buried|埋地管道例题]]中的管道，如果在敷设于同样土壤之前先包上$50\ \mathrm{mm}$聚氨酯（$k = 0.026\ \mathrm{W / m\,K}$），每米散热量是多少？

::: solution
泡沫与土壤是**串联**的，所以热阻相加；土壤热阻是形状因子与其导热系数乘积的倒数。
$$
R _ { \mathrm { foam} } ^ { \prime } = { \frac { \ln ( 0 . 1 0 / 0 . 0 5 ) } { 2 \pi \times 0 . 0 2 6 } } = 4 . 2 4 3 \ \mathrm { m \, K / W } , \qquad R _ { \mathrm { soil} } ^ { \prime } = { \frac { 1 } { S ^ { \prime } k _ { \mathrm { soil} } } } = { \frac { 1 } { 1 . 6 2 3 \times 1 . 0 } } = 0 . 6 1 6
$$
$$
q ^ { \prime } = { \frac { 8 0 - 5 } { 4 . 2 4 3 + 0 . 6 1 6 } } = { \frac { 7 5 } { 4 . 8 5 9 } } = \mathbf { 1 5 . 4 \ W / m }
$$
**降低$7.9$倍，而现在由土壤限制一切：$12.7\ \%$的热阻在大地中，再多的泡沫也改变不了它。****这道习题所确立的一般规则，正是使形状因子值得学习的那条规则：每当一个小物体与一个大物体换热时，大物体贡献一个固定热导$S k$；一旦小物体本身保温良好，它就成为约束条件——剩下的杠杆只有物体的尺寸、位置以及大介质的导热系数。**
:::

::: quiz 保温层起哪个方向的作用？ {#quiz-crit}
在静止空气（$h \approx 10\ \mathrm{W / m^2 K}$）中，要给四个物体包上$1\ \mathrm{mm}$聚氨酯泡沫（$k = 0.026\ \mathrm{W / m\,K}$）。**在哪种情况下泡沫会增加而不是减少散热量？**

- [ ] 直径$100\ \mathrm{mm}$的蒸汽管
- [ ] 直径$30\ \mathrm{mm}$的冷冻水管
- [x] 直径$4\ \mathrm{mm}$的毛细管
- [ ] 直径$500\ \mathrm{mm}$的储罐

::: solution
**直径$4\ \mathrm{mm}$的毛细管。**临界半径为$r _ { \mathrm { cr } } = k / h = 0 . 0 2 6 / 1 0 = 2 . 6 \ \mathrm { mm}$，而毛细管的半径为$2.0\ \mathrm{mm}$——低于它。包$1\ \mathrm{mm}$泡沫后，$R' = \ln(3/2)/(2\pi \times 0.026) + 1/(2\pi \times 0.003 \times 10) = 2.48 + 5.31 = 7.79\ \mathrm{m\,K/W}$，而裸管为$1/(2\pi \times 0.002 \times 10) = 7.96$，所以泡沫使传热量**增加**约$2\ \%$。（$2\ \mathrm{mm}$厚的泡沫会把表面推到$4\ \mathrm{mm}$，超过热阻回到裸管值时的半径$3.5\ \mathrm{mm}$，已经会使散热量略有减少：起始时低于$r_{\mathrm{cr}}$是必要条件而非充分条件。）$30\ \mathrm{mm}$管的半径为$15\ \mathrm{mm}$，接近$r_{\mathrm{cr}}$的六倍，另外两个就更大了。
现代泡沫材料在静止空气中的$r_{\mathrm{cr}}$只有几毫米，所以这一效应仅限于小直径物品——毛细管、导线、热电偶测温球和传感器引线。**对它们来说，包覆层可能起扩展表面的作用而不是保温作用，在给小传感器或引线包保温之前值得核查一下。**

::: quiz 改进了错误的那一层 {#quiz-layer}
[[#ex-coldstore|冷库例题]]中的冷库墙板$1 / U = 5 . 9 3 4\ \mathrm { m^2 K / W}$，由内表面膜$0.125$、钢板$0.00004$、泡沫$5.769$和外表面膜$0.040$组成。一位顾问建议加装风扇，把内表面传热系数从$8$提高到$12\ \mathrm{W / m^2 K}$。漏热减少多少？

- [ ] 约$12\ \%$，因为内表面膜占热阻的$12\ \%$
- [x] 约$0.7\ \%$，因为表面膜只占总热阻的$2.1\ \%$，把它减少三分之一只去掉$0.7\ \%$
- [ ] 约$4\ \%$，因为表面膜热阻下降三分之一，其中一半体现在热侧
- [ ] 没有减少，因为风扇无法改变表面传热系数

::: solution
**约$0.7\ \%$。**内表面膜热阻从$1 / 8 = 0.1250$降到$1 / 1 2 = 0.0833$，所以
$$
{ \frac { 1 } { U } } \colon 5 . 9 3 4 \rightarrow 5 . 8 9 2 \qquad \Longrightarrow \qquad U \colon 0 . 1 6 8 5 \rightarrow 0 . 1 6 9 7 \quad ( + 0 . 7 \ \% )
$$
**第一个选项是陷阱，它之所以是陷阱，是因为算术是对的而结论是错的：表面膜占热阻的$2.1\ \%$，而不是$12\ \%$，把$2.1\ \%$减少三分之一就是$0.7\ \%$。****一般规则正是整讲一直在铺垫的那条：在串联网络中，任何元件所能提供的改进量就是该元件所占总热阻的份额，再多的努力也买不到更多。**推论就是设计指令——**找到占$90\ \%$的那一项，其余的别去管它**；对于冷库墙板，这意味着更多泡沫、更好的隔汽层和更少的螺栓，而绝不是风扇。
:::
:::

## 后续内容

稳态导热是传热学中唯一能在一讲之内讲完的部分，因为只有它的控制方程是线性的、与时间无关的，而且——在一维情况下——一眼就能积分出来。本讲之后的一切，都是关于本讲当作已知的那两项。**下一讲把平壁弯成肋片**，使表面温度沿肋片成为未知量，并引出决定额外金属是否值得购买的肋效率和肋效能。**再下一讲把时间放回方程中**，而毕渥数——你刚学会计算的内部热阻与你刚学会叠加的表面热阻之比——将被证明是判定一个物体只有一个温度还是有一个温度分布的唯一判据。

然后是难点。**本讲热阻网络中的每一个$h$都是直接给出的，而接下来的五讲就是为了计算它而存在的。**导热解与对流解在壁面相遇，两者必须在热流密度上一致，正是这种相遇使整门学科成为一门学科而不是两门。本讲有两个结果会被反复引用：**临界半径$k / h$**，它是小型保温物体表现反常的原因；以及**形状因子上限$S k$**，它是埋在大介质中的良好保温物体受限于介质而不是保温层的原因。

::: history
| 年份 | 事件 |
|---|---|
| 1822 | **傅里叶（Joseph Fourier）**在《热的解析理论》（*Théorie analytique de la chaleur*）中给出导热方程，并用三角级数求解了平板、圆环、球、圆柱和棱柱中的导热。本讲中的一维稳态解是其中最简单的情形。 |
| 1822 | 傅里叶还以至今仍在使用的形式给出了第三类边界条件$-k \partial T / \partial n = h(T - T_\infty)$——并承认$h$必须由实验提供。**两百年的对流研究都是对这一承认所作的脚注。** |
| 1813, 1835 | **泊松（Siméon Denis Poisson）**针对引力势提出方程$\nabla^2 \phi = -(\text{源})$，如今它以他的名字命名并支配有均匀内热源的导热；1835年他出版了自己的《热的数学理论》（*Théorie mathématique de la chaleur*）。 |
| 1842 | 年仅十七岁的**威廉·汤姆孙（William Thomson，后来的开尔文勋爵）**在《剑桥数学杂志》（*Cambridge Mathematical Journal*）上发表《论热在均匀固体中的均匀运动及其与电学数学理论的联系》，证明稳态热流与静电学服从同样的数学——这是热阻类比与形状因子类比的根源。 |
| 1913 | **朗缪尔（Irving Langmuir）、亚当斯（E. Q. Adams）与米克尔（G. S. Meikle）**在《美国电化学学会会刊》（*Transactions of the American Electrochemical Society*）上发表《通过炉墙的热流：形状因子》，引入形状因子来处理炉墙的棱边和角隅——这是$q = S k \Delta T$的起源。 |
| 1950 | **克恩（D. Q. Kern）**的《过程传热》（*Process Heat Transfer*）把工厂工程师关于保温、换热器和污垢热阻的方法整理成过程工程师沿用数十年的形式——其中包括本讲略去的污垢热阻，而在脏污的换热器中它往往是网络中最大的一项。 |

::: summary
- **稳态、一维、无内热源就是拉普拉斯方程，其在平壁、圆柱和球中的解分别是直线、对数曲线和双曲线。**本讲的其余内容都是这三者加上一个边界条件。
- **热阻网络是精确的而不是近似的**——对$k$为常数的一维路径而言。当$k(T)$变化剧烈时它失效（用实际温度范围内的平均值），当热流是多维的时它也失效（用形状因子）。
- **串联热阻相加；并联路径以热导相加。**四根穿过玻璃棉屋顶的钢螺栓使漏热翻倍，同样的算术也适用于空腔墙托架、中空玻璃间隔条和夹芯板紧固件。
- **任何元件所能提供的改进量就是它所占总热阻的份额。**在保温管道中，保温层占$92\ \%$，钢管占$0.02\ \%$；在冷库墙板中，表面膜占$2.8\ \%$，任何风扇都帮不上忙。
- **径向热阻会饱和。**圆柱热阻随$\ln(r_2/r_1)$增长，球热阻则趋于硬上限$1 / (4 \pi k r_1)$，所以厚度的收益递减，在球上还有一个极限。
- **在$r_{\mathrm{cr}} = k/h$以下保温层起降温作用。**对于静止空气中的常见保温材料，$r_{\mathrm{cr}}$约为$2.5$–$25\ \mathrm{mm}$，这使导线、毛细管、测温球和传感器引线落在保温层充当散热器的那一侧。
- **内热源在平板中给出$\Delta T = \dot{q} L^2 / 2k$，在圆柱中给出$q' / 4 \pi k$。**厚度是平方律杠杆：相近的体积释热率在半径$4.1\ \mathrm{mm}$的陶瓷燃料中产生$711\ \mathrm{K}$的温降，在$0.5\ \mathrm{mm}$的硅中只产生$0.53\ \mathrm{K}$。
- **表面热流密度无可商量；可以商量的只有内部温降。**$q'' = \dot{q} L$由内热源和几何决定，所以冷却系统是按一个你无法改变的负荷和一个你可以改变的温度来设计的。
- **形状因子$S$把三维难题变成$q = S k \Delta T$。**埋地管道按形状因子散热$122\ \mathrm{W/m}$，按朴素圆筒模型则为$148$；一旦管道保温良好，大地的$S k$就成为约束条件。
- **界面热阻和表面膜热阻是绝对量，而不是相对量。**同样$2 \times 10^{-3}\ \mathrm{m^2 K/W}$的接缝在炉墙中占$0.2\ \%$，在冷库墙板中占$0.03\ \%$，而在自身只有$0.2\ \mathrm{m^2 K/W}$的墙体中占$1\ \%$；问题从来不是"接缝是否糟糕"，而是"其他一切有多小"。
:::

## 延伸阅读

- **H. S. Carslaw & J. C. Jaeger**，*Conduction of Heat in Solids*，第2版（Oxford University Press，1959；有重印本）——本讲每一个封闭形式解的来源，还有若干在后来任何书中都找不到的解。把它当作目录而不是教材来读，每当遇到不寻常的几何形状时都放在手边。
- **F. P. Incropera, D. P. DeWitt, T. L. Bergman & A. S. Lavine**，*Fundamentals of Heat and Mass Transfer*，第8版（Wiley，2017）——第2至4章，尤其是第4章的形状因子表，以及上述习题所依循的管道保温例题。
- **J. P. Holman**，*Heat Transfer*，第10版（McGraw-Hill，2010）——学习热阻网络最平易的途径，也是这一层次上最好的一组复合墙习题。
- **D. Q. Kern**，*Process Heat Transfer*（McGraw-Hill，1950；Krieger重印）——管道保温、污垢热阻以及保温层厚度的经济性，作者是一位默认读者有一座工厂要建的工程师。

- **EN ISO 6946**，*Building components and building elements — Thermal resistance and thermal transmittance — Calculation methods*——多维修正以及[[#ex-bolts|螺栓穿透保温层习题]]所揭示的接点与紧固件修正的标准方法，也很好地说明了一个计算无法完全解决、而一张节点详图却能解决的传热问题。
