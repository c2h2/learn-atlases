一台管壳式换热器用海水冷却船舶的淡水回路；一组板式（垫片式）换热器以数倍的传热系数、只占几分之一的体积完成同样的液–液换热任务；小型燃气轮机的回热器则在两种气体之间工作，其传热系数低到需要每立方米数百平方米的面积密度，而它的压降要在机器的整个寿命期内用轴功来偿付。本课程到目前为止的大部分内容都是关于如何求出一个表面传热系数。本讲讨论的是：当壁面两侧各有一个系数、两种流体不得相混、而唯一的温差又沿流程逐渐耗尽时，你该怎么办。

三个问题统领整门学科。**传热面积需要多大？**——这就是传热系数$U$ 、对数平均温差，以及会让你后悔的污垢热阻。**出口温度是多少？**——这就是效能-传热单元数法，而它正是你在部分负荷下校核一台现有设备时实际面对的问题。**两种流体中哪一种决定一切？**——这就是热容量比$C _ { r } = C _ { \min } / C _ { \max }$ ，它解释了为什么水量比气量大一百倍的气体冷却器表现得就像一面处于水温的壁面，也解释了为什么肋片总是加在气体侧。

::: warning 五个换热器错误，按代价大小排列
1. **使用算术平均温差。**它总是偏大，有时偏大一倍，而且误差恰恰在换热器的设计区间——靠近温度夹点或温度交叉处——最大。应使用对数平均温差；如果两端温差相差在$2 0 \ \ \%$ 以内，算术平均值与之相差不到百分之零点五，此时你应当说明你用了算术平均。
2. **忘记污垢热阻。**一台清洁时$U = 8 5 0 \ \mathrm { W / m ^ { 2 } K }$ 的水–水换热器，在污垢热阻合计$0 . 0 0 0 6 \ \mathrm { m ^ { 2 } K / W }$ 时变为$5 6 0$ ，差了$3 4 \ \ \%$ ，而工厂要到八月才发现这一点。$1 / U$ 是各热阻之和，而污垢项通常正是你漏掉的那两项。
3. **对$U$ 取平均却没有注意哪一侧起主导作用。**如果气体侧占热阻的$9 6 \ \ \%$ ，那么水侧表面传热系数、管壁金属和凝结液膜都无关紧要——反过来，气体侧表面传热系数提高$2 0 \ \ \%$ 会使$U$ 提高$1 9 \ \ \%$ 。在优化任何东西之前，先算出热阻分布。
4. **接受低于$0 . 8$ 的修正系数。**存在较大温度交叉的单壳程管壳式换热器，其$F$ 会急剧下降；按$F = 0 . 6$ 设计意味着比逆流多$6 7 \ \ \%$ 的面积，而且结果对出口温度极其敏感。低于$0 . 8$ 时应改变布置形式，而不是增加面积。
5. **混淆设计计算与校核计算。**出口温度已知时，用对数平均温差法。出口温度未知时——这是通常的校核问题，而部分负荷问题总是如此——对数平均温差法需要循环迭代，而$\varepsilon$–NTU 法是直接的。两种方法依据相同的物理；它们的区别仅在于哪些量是已知的。
:::

## 1. 设备，以及每种类型的用途

::: definition 流动布置及相关术语 {#def-arrangements}
被壁面隔开的两种流体可以**顺流**（两者同向）、**逆流**（方向相反）、**叉流（交叉流）**（相互垂直，每股流体或者是**混合的**——自由射流、流体可以绕流的肋片管束——或者是**非混合的**——在通道内受约束的流动），或者采用某种**多流程**组合。**间壁式**换热器（回热器）通过壁面把两种流体隔开；**蓄热式换热器**（转轮、斯特林发动机的回热器填料、高炉热风炉的格子砖）让两种流体交替流过同一表面，并在两次流过之间把热量储存在填料中。**热管**或**回路热虹吸管**在密封回路中依靠蒸发和凝结输送热量，因此两股流体不必处于同一高度，也不必在物理上相邻可达。

描述任何换热器的三个数是：**热容量（热容率）**$C = \dot { m } c _ { p }$ ，单位为$\mathrm { W / K }$ （它不是物性——而是流量乘以物性），它的最小值和最大值$C _ { \min }$ 和$C _ { \max }$ ，以及**热容量比**$C _ { r } = C _ { \min } / C _ { \max }$ 。冷凝器或蒸发器有一侧处于恒定温度，这对应于极限$C \rightarrow \infty$ ，因而$C _ { r } = 0$ ；**平衡**换热器的$C _ { r } = 1$ 。

## 2. 传热系数：一个串联回路，以及唯一要紧的那个热阻

::: definition 传热系数与污垢热阻 {#def-overall}
对于长度为$L$ 、内外径为$D _ { i }$ 和$D _ { o }$ 、导热系数为$k _ { w }$ 、内外表面传热系数为$h _ { i }$ 和$h _ { o }$ 的管子，传热量写为

$$q = U _ { o } A _ { o } \, \Delta T _ { \text{总 } } \ , \qquad { \frac { 1 } { U _ { o } A _ { o } } } = { \frac { 1 } { h _ { i } A _ { i } } } + { \frac { \ln ( D _ { o } / D _ { i } ) } { 2 \pi k _ { w } L } } + { \frac { 1 } { h _ { o } A _ { o } } } + \underbrace { { \frac { R _ { f , i } } { A _ { i } } } + { \frac { R _ { f , o } } { A _ { o } } } } _ { \text{污垢} }$$

每一项都是**串联的热阻**，并且——这是学生常出错的地方——面积不能约掉：折算到外表面积的内侧热阻$1 / h _ { i }$ 必须乘以$D _ { o } / D _ { i }$ 。污垢热阻$R _ { f }$ 是针对水垢、腐蚀产物、生物沉积和灰分的经验裕量；代表性数值（Incropera 等人依据 TEMA 所列）如下：

| 工况 | $R _ { f }$ （$\mathrm { m ^ { 2 } K / W }$） | 工况 | $R _ { f }$ （$\mathrm { m ^ { 2 } K / W }$） |
|:--|--:|:--|--:|
| 海水和经处理的锅炉给水，低于$5 0 \ \ {} ^ { \circ } \mathrm { C }$ | $0 . 0 0 0 1$ | 海水和经处理的锅炉给水，高于$5 0 \ \ {} ^ { \circ } \mathrm { C }$ | $0 . 0 0 0 2$ |
| 河水，低于$5 0 \ \ {} ^ { \circ } \mathrm { C }$ | $0 . 0 0 0 2$–$0 . 0 0 1$ | 燃料油 | $0 . 0 0 0 9$ |
| 蒸汽，无油 | $0 . 0 0 0 1$ | 制冷液体 | $0 . 0 0 0 2$ |
| 空气，含尘/压缩机排气 | $0 . 0 0 0 6$ | | |

**热阻要按热阻相加，绝不能按系数相加：$h = 5 0 0 0$ 和$h = 5 0$ 的两种流体给出$U \approx 4 9 . 5$ ，而不是$2 5 0 0$ ，也不是$5 0 2 5$ 。**
:::

::: example 热阻在哪里，以及肋片能换来什么 {#ex-fin-why level=2 check="602"}
$2 5 0 0 \ \mathrm { W / m ^ { 2 } K }$ 的水在$2 0 / 2 5 \ \mathrm { mm }$ 碳钢管（$k _ { w } = 1 8 \ \mathrm { W / m \, K }$）内流动；燃气以$6 5 \ \mathrm { W / m ^ { 2 } K }$ 横掠管外。求折算到光管外表面积的传热系数，先求光管的，再求气体侧加肋片后的。（输入肋片管的$U _ { o }$ ，单位$\mathrm { W / m ^ { 2 } K }$ 。）对于光管：

$${ \frac { 1 } { U _ { o } } } = \underbrace { { \frac { D _ { o } } { D _ { i } h _ { i } } } } _ { \textstyle 1 . 2 5 / 2 5 0 0 = 0 . 0 0 0 5 0 } + \underbrace { { \frac { D _ { o } \ln ( D _ { o } / D _ { i } ) } { 2 k _ { w } } } } _ { \textstyle 0 . 0 0 0 1 5 } + \underbrace { { \frac { 1 } { h _ { o } } } } _ { \textstyle 1 / 6 5 = 0 . 0 1 5 3 8 } = 0 . 0 1 6 0 4 \ \mathrm { m ^ { 2 } K / W } \qquad U _ { o } = 6 2 . 3 \ \mathrm { W / m ^ { 2 } K }$$

**气体侧占热阻的$9 6 \ \ \%$ 。**现在在管外加装环形肋片，使面积变为光管的$1 8$ 倍，总表面效率$\eta _ { o } = 0 . 8 5$ ，于是折算到光管面积的气体侧热阻变为$1 / ( \eta _ { o } A _ { \text{比} } h _ { o } )$ ：

$${ \frac { 1 } { U _ { o } } } = 0 . 0 0 0 5 0 + 0 . 0 0 0 1 5 + { \frac { 1 } { 0 . 8 5 \times 1 8 \times 6 5 } } = 0 . 0 0 0 5 0 + 0 . 0 0 0 1 5 + 0 . 0 0 1 0 1 = 0 . 0 0 1 6 6 \qquad U _ { o } = \mathbf { 6 0 2 \ W / m ^ { 2 } K }$$

**以肋片的代价换来传热系数近十倍的提高，因为肋片针对的正是唯一要紧的那个热阻。****注意水侧发生了什么。在光管上，把$h _ { i }$ 从$2 5 0 0$ 提高到$1 0 \, 0 0 0 \ \mathrm { W / m ^ { 2 } K }$ 只使$U$ 从$6 2 . 3$ 变为$6 3 . 8$ ，增益$2 \ \ \%$ ；而在肋片管上，水侧现在占热阻的$3 0 \ \ \%$ ，同样的改变使$U$ 从$6 0 2$ 提高到$7 7 8$ ，即$2 9 \ \ \%$ 。****消除了主导热阻，就改变了哪个热阻起主导作用——所以每次改进之后都必须重新计算热阻分布。**
:::

::: example 污垢：三月买来的换热器，八月就不够用了 {#ex-fouling level=2 check="563"}
一台水–水换热器按清洁状态$U _ { \text{清洁 } } = 8 5 0 \ \mathrm { W / m ^ { 2 } K }$ 选型。设计允许管程污垢热阻$0 . 0 0 0 2$ 、壳程$0 . 0 0 0 4 \ \mathrm { m ^ { 2 } K / W }$ ，两者折算到同一面积。求结垢后的传热系数。（输入$U _ { \text{结垢} }$ ，单位$\mathrm { W / m ^ { 2 } K }$ 。）

$$U _ { \text{结垢 } } = \left[ { \frac { 1 } { 8 5 0 } } + 0 . 0 0 0 2 + 0 . 0 0 0 4 \right] ^ { - 1 } = \left[ 0 . 0 0 1 1 7 6 + 0 . 0 0 0 6 \right] ^ { - 1 } = \mathbf { 5 6 3 \ W / m ^ { 2 } K }$$

**传热系数损失$3 4 \ \ \%$ ，在面积固定时，这会使一台$C _ { r } = 0 . 7 5$ 的逆流换热器的效能从$0 . 7 2$ 降到$0 . 6 1$ ——而在换热量固定时，所需面积比按清洁状态计算的多$5 1 \ \ \%$ 。****由此得出两条设计结论，都是标准做法：面积是按结垢状态购买的，所以新换热器的性能超过其规格，在污垢形成之前要用旁通或节流流量来运行；而清洗周期则由损失热量的代价与停机的代价之间的权衡来确定。****而且污垢裕量本身是不确定的：如果壳程是取表中范围上限$0 . 0 0 1$ 的河水，$U$ 将为$4 2 1$ ，又低了$2 5 \ \ \%$ ——污垢热阻表只是指导，同一工况的不同表值相差数倍。**
:::

## 3. 对数平均温差

::: proof 对数平均温差，以及平均值为什么是对数形式的 {#proof-lmtd}
取一台面积为$A$ 的逆流换热器，热流体以热容量$C _ { h }$ 在$T _ { h , i }$ 下进入，冷流体以$C _ { c }$ 在$T _ { c , i }$ 下进入。在热流体已放出热量$q ( x )$ 的截面处，其温度为$T _ { h } = T _ { h , i } - q / C _ { h }$ ，而反向流动的冷流体温度为$T _ { c } = T _ { c , i } + ( Q - q ) / C _ { c }$ 。因此局部温差**是$q$ 的线性函数**：

$$\Delta T ( q ) = T _ { h } - T _ { c } = \underbrace { \left( T _ { h , i } - T _ { c , i } - { \frac { Q } { C _ { c } } } \right) } _ { \Delta T _ { 2 } \text{，取值于 } q = 0 } + q \left( { \frac { 1 } { C _ { c } } } - { \frac { 1 } { C _ { h } } } \right)$$

而局部传热为$d q = U \, \Delta T \, d A$ 。在$d q = U \Delta T \, d A$ 与$d ( \Delta T ) = ( 1 / C _ { c } - 1 / C _ { h } ) \, d q$ 之间消去$q$ ，得到$d ( \Delta T ) / \Delta T = U ( 1 / C _ { c } - 1 / C _ { h } ) \, d A$ ，积分后为一个对数。利用$1 / C _ { c } - 1 / C _ { h } = ( \Delta T _ { 1 } - \Delta T _ { 2 } ) / Q$ ，其中$\Delta T _ { 1 }$ 是$q = Q$ 处（热流体出口端）的温差，

$$\boxed { \ Q = U A \, \Delta T _ { \mathrm { lm } } \ , \qquad \Delta T _ { \mathrm { lm } } = { \frac { \Delta T _ { 1 } - \Delta T _ { 2 } } { \ln ( \Delta T _ { 1 } / \Delta T _ { 2 } ) } } \ } \qquad \Delta T _ { 1 } , \Delta T _ { 2 } = \text{两端温差}$$

**推导告诉你的三件事，都不在公式里。****对于顺流（两端温差定义为各端的$T _ { h } - T _ { c }$ ）和逆流，结果完全相同——两种布置的区别完全在于两端温差最终是多少。****它要求$U$ 和$c _ { p }$ 沿换热器保持不变，当一侧凝结或沸腾时这一条件严重失效，这也是带过热区和过冷区的冷凝器必须分区计算的原因。****而且$\Delta T _ { \mathrm { lm } }$ 总是低于算术平均值，并且随$\Delta T _ { 1 } / \Delta T _ { 2 }$ 增大而低得更多——两端温差之比为$3$ 时，算术平均值偏高$1 0 \ \ \%$ ，为$1 0$ 时偏高$4 1 \ \ \%$ ，为$1 0 0$ 时偏高$1 3 5 \ \ \%$ （此时对数平均值比它低$5 7 \ \ \%$ ）。**
:::

::: example 逆流、顺流，以及你原本没有的那百分之十 {#ex-lmtd level=2 check="4.2"}
$2 . 0 \ \mathrm { k g / s }$ 的热水从$9 0$ 冷却到$7 0 \ \ {} ^ { \circ } \mathrm { C }$ ，冷却介质为$1 . 5 \ \mathrm { k g / s }$ 、进口$2 0 \ \ {} ^ { \circ } \mathrm { C }$ 的水。取$c _ { p } = 4 1 8 0 \ \mathrm { J / k g \, K }$ 和$U = 8 5 0 \ \mathrm { W / m ^ { 2 } K }$ ，求逆流时的面积。（输入$A$ ，单位$\mathrm { m ^ { 2 } }$ 。）

$$C _ { h } = 8 3 6 0 \ \mathrm { W / K } \qquad C _ { c } = 6 2 7 0 \ \mathrm { W / K } \qquad Q = 8 3 6 0 \times 2 0 = 1 6 7 . 2 \ \mathrm { k W } \qquad T _ { c , o } = 2 0 + { \frac { 1 6 7 \, 2 0 0 } { 6 2 7 0 } } = 4 6 . 7 \ \mathrm { {} ^ { \circ } C }$$

**逆流：**$\Delta T _ { 1 } = 9 0 - 4 6 . 7 = 4 3 . 3 \ \mathrm { K }$ ，$\Delta T _ { 2 } = 7 0 - 2 0 = 5 0 \ \mathrm { K }$ ，

$$\Delta T _ { \text{lm } } = { \frac { 5 0 - 4 3 . 3 } { \ln ( 5 0 / 4 3 . 3 ) } } = 4 6 . 6 \ \mathrm { K } \qquad A = { \frac { 1 6 7 \, 2 0 0 } { 8 5 0 \times 4 6 . 6 } } = \mathbf { 4 . 2 \ m ^ { 2 } } \ ( 4 . 2 2 )$$

**顺流：**同样的换热量和出口温度给出$\Delta T _ { 1 } = 9 0 - 2 0 = 7 0 \ \mathrm { K }$ 和$\Delta T _ { 2 } = 7 0 - 4 6 . 7 = 2 3 . 3 \ \mathrm { K }$ ，$\Delta T _ { \text{lm } } = 4 2 . 5 \ \mathrm { K }$ ，$A = 4 . 6 3 \ \mathrm { m ^ { 2 } }$ ，**同样换热量需要多$1 0 \ \ \%$ 的面积**——更重要的是，无论面积多大，顺流都不可能把冷流体加热到共同温度$( C _ { h } T _ { h , i } + C _ { c } T _ { c , i } ) / ( C _ { h } + C _ { c } ) = 6 0 \ \ {} ^ { \circ } \mathrm { C }$ 以上，因为两个出口温度只能渐近地相互接近；逆流则没有这一限制。

**逆流两端温差的算术平均值为$4 6 . 7 \ \mathrm { K }$ ，与对数平均值相差不到$0 . 2 \ \ \%$ ，因为两端温差恰好几乎相等——这就是为什么"两端温差相差在$2 0 \ \ \%$ 以内时可用算术平均"是一条安全的规则。****还要注意$C _ { h } > C _ { c }$ ：冷流体的温度变化较大，热流体$2 0 \ \mathrm { K }$ 的温降换来冷流体$2 6 . 7 \ \mathrm { K }$ 的温升。热容量较小的流体温度变化总是较大；它就是$C _ { \min }$ 。**
:::

::: definition 修正系数$F$ ：实际换热器并非逆流 {#def-ffactor}
对于纯逆流或冷凝器以外的任何布置，传热速率方程写为$Q = U A F \Delta T _ { \text{lm,cf } }$ ，其中$\Delta T _ { \text{lm,cf } }$ 是按四个进出口温度计算的逆流对数平均温差，$F \leq 1$ 取决于两个无量纲温度比，

$$P = { \frac { t _ { 2 } - t _ { 1 } } { T _ { 1 } - t _ { 1 } } } \quad \text{（冷流体的温度效率）} \qquad R = { \frac { T _ { 1 } - T _ { 2 } } { t _ { 2 } - t _ { 1 } } } = { \frac { C _ { c } } { C _ { h } } } \quad \text{（热容量比）}$$

对于**1–2 型换热器**（单壳程、双管程），其解析式为

$$F = { \frac { \sqrt { R ^ { 2 } + 1 } } { R - 1 } } \, { \frac { \ln \left[ ( 1 - P ) / ( 1 - P R ) \right] } { \ln \left[ \dfrac { 2 / P - 1 - R + \sqrt { R ^ { 2 } + 1 } } { 2 / P - 1 - R - \sqrt { R ^ { 2 } + 1 } } \right] } }$$

**$F$ 在图的大部分区域都接近于一，然后在$P R \rightarrow 1$ 时断崖式下跌，因为此时要求换热器产生的温度变化是这种流动布置在物理上无法实现的。****规则是$F \geq 0 . 8 5$ （绝不低于$0 . 8$）：低于此值时，面积对出口温度极其敏感，解决办法是增加壳程数或采用逆流，而不是增加面积。****对于叉流，$F$ 从线图中查取，在正常设计范围内一般为$0 . 8$ 到$0 . 9 5$ 。**
:::

## 4. 效能-传热单元数法：用于你实际面对的问题

::: definition 效能、传热单元数与热容量比 {#def-epsilon}
换热器的两个进口温度已知，你想知道的是出口是什么。定义**最大可能传热量**为：使热容量*较小*的那股流体一直变化到另一股流体进口温度时的传热量，

$$Q _ { \max } = C _ { \min } \left( T _ { h , i } - T _ { c , i } \right) \ , \qquad \varepsilon = { \frac { Q } { Q _ { \max } } } \ , \qquad \boxed { \ \varepsilon = f ( \mathrm { N T U } , \, C _ { r } , \, \text{布置形式} ) \ } \qquad \mathrm { N T U } = { \frac { U A } { C _ { \min } } }$$

其中**NTU，即传热单元数，是换热器的热导$U A$ 与流体带走热量的能力$C _ { \min }$ 之比**——一个无量纲的"相对于流过的流体量，我有多少传热面"。于是出口温度无需任何迭代即可得出：

$$T _ { h , o } = T _ { h , i } - \varepsilon { \frac { C _ { \min } } { C _ { h } } } ( T _ { h , i } - T _ { c , i } ) \ , \qquad T _ { c , o } = T _ { c , i } + \varepsilon { \frac { C _ { \min } } { C _ { c } } } ( T _ { h , i } - T _ { c , i } )$$

常见布置的封闭形式：

| 布置形式 | $\varepsilon ( \mathrm { N T U } , C _ { r } )$ |
|:--|:--|
| 冷凝器或蒸发器，$C _ { r } = 0$ | $1 - e ^ { - \mathrm { N T U } }$ |
| 逆流，$C _ { r } < 1$ | $\dfrac { 1 - \exp [ - \mathrm { N T U } ( 1 - C _ { r } ) ] } { 1 - C _ { r } \exp [ - \mathrm { N T U } ( 1 - C _ { r } ) ] }$ |
| 逆流，平衡，$C _ { r } = 1$ | $\dfrac { \mathrm { N T U } } { 1 + \mathrm { N T U } }$ |
| 顺流 | $\dfrac { 1 - \exp [ - \mathrm { N T U } ( 1 + C _ { r } ) ] } { 1 + C _ { r } }$ |
| 叉流，两侧均非混合（近似式） | $1 - \exp \! \left[ { \frac { 1 } { C _ { r } } } \mathrm { N T U } ^ { 0 . 2 2 } \left( e ^ { - C _ { r } \mathrm { N T U } ^ { 0 . 7 8 } } - 1 \right) \right]$ |
| 叉流，$C _ { \max }$ 混合，$C _ { \min }$ 非混合 | ${ \frac { 1 } { C _ { r } } } \left\{ 1 - \exp \! \left[ - C _ { r } \left( 1 - e ^ { - \mathrm { N T U } } \right) \right] \right\}$ |
| 平衡逆流蓄热器，快速旋转 | $\dfrac { \mathrm { N T U } } { 1 + \mathrm { N T U } }$ （平衡逆流的极限） |

**当四个温度已知而要求面积时——即设计计算——用对数平均温差法。当面积已知而要求温度时——即校核计算，以及你将遇到的每一个部分负荷、非设计工况、"如果流量减半会怎样"的问题——用$\varepsilon$–NTU 法。**
:::

::: proof 逆流换热器的效能 {#proof-epsilon-cf}
从热流体进口量起位置。在微元$d A$ 中，热流体温度降低$d T _ { h }$ ，而由于冷流体反向流动，同一截面处的冷流体温度沿此方向也降低：$d q = - C _ { h } \, d T _ { h } = - C _ { c } \, d T _ { c } = U \Delta T \, d A$ ，其中$\Delta T = T _ { h } - T _ { c }$ 。于是

$$d ( \Delta T ) = d T _ { h } - d T _ { c } = - \left( { \frac { 1 } { C _ { h } } } - { \frac { 1 } { C _ { c } } } \right) d q = - U \Delta T \left( { \frac { 1 } { C _ { h } } } - { \frac { 1 } { C _ { c } } } \right) d A$$

从热流体进口端（$\Delta T = T _ { h , i } - T _ { c , o }$ ）积分到热流体出口端（$\Delta T = T _ { h , o } - T _ { c , i }$ ）。设热流体为$C _ { \min }$ ，即$C _ { h } = C _ { \min }$ ，$C _ { c } = C _ { \min } / C _ { r }$ ：

$$\frac { T _ { h , o } - T _ { c , i } } { T _ { h , i } - T _ { c , o } } = \exp \left[ - \mathrm { N T U } ( 1 - C _ { r } ) \right]$$

**现在代入$T _ { h , o } = T _ { h , i } - \varepsilon \Delta T _ { i }$ 和$T _ { c , o } = T _ { c , i } + \varepsilon C _ { r } \Delta T _ { i }$ ，其中$\Delta T _ { i } = T _ { h , i } - T _ { c , i }$ ：左边变为$( 1 - \varepsilon ) / ( 1 - \varepsilon C _ { r } )$ ，解出$\varepsilon$ 即得表中的逆流结果。**（取冷流体为$C _ { \min }$ 得到同一公式。）**两个极限顺带可得。****当$C _ { r } \rightarrow 0$ （一侧凝结）时，它变为$1 - e ^ { - \mathrm { N T U } }$ ，与[[heat-transfer/transient-conduction]]中集总参数法的答案是同一个指数，只是时间被比值$U A / C$ 所替代。****而当$C _ { r } \rightarrow 1$ 时，表达式成为$0 / 0$ ，其极限为$\mathrm { N T U } / ( 1 + \mathrm { N T U } )$ ，这就是平衡情形要单独列出的原因；对于给定的效能，当热容量相等时逆流所需的 NTU 最多。**
:::

::: example 校核一台你已拥有的空气加热器 {#ex-airheater level=3 check="42.3"}
一台两侧均非混合的叉流换热器，$A = 1 2 \ \mathrm { m ^ { 2 } }$ ，$U = 4 5 \ \mathrm { W / m ^ { 2 } K }$ （一如既往由气体侧主导）。$1 . 0 \ \mathrm { k g / s }$ 、$2 0 \ \ {} ^ { \circ } \mathrm { C }$ 的空气被$0 . 5 \ \mathrm { k g / s }$ 、$8 0 \ \ {} ^ { \circ } \mathrm { C }$ 的水加热。取$c _ { p , a } = 1 0 0 7$ ，$c _ { p , w } = 4 1 8 0 \ \mathrm { J / k g \, K }$ ，求空气出口温度。（输入，单位$^ { \circ } \mathrm { C }$ 。）

$$C _ { a } = 1 0 0 7 \ \mathrm { W / K } \qquad C _ { w } = 2 0 9 0 \ \mathrm { W / K } \qquad C _ { \min } = C _ { a } \ , \quad C _ { r } = { \frac { 1 0 0 7 } { 2 0 9 0 } } = 0 . 4 8 2$$

$$\mathrm { N T U } = { \frac { U A } { C _ { \min } } } = { \frac { 4 5 \times 1 2 } { 1 0 0 7 } } = 0 . 5 3 6 \qquad \varepsilon = 1 - \exp \! \left[ { \frac { 0 . 5 3 6 ^ { 0 . 2 2 } } { 0 . 4 8 2 } } \left( e ^ { - 0 . 4 8 2 \times 0 . 5 3 6 ^ { 0 . 7 8 } } - 1 \right) \right] = 0 . 3 7 1$$

$$Q = \varepsilon C _ { \min } \Delta T _ { i } = 0 . 3 7 1 \times 1 0 0 7 \times 6 0 = 2 2 . 4 \ \mathrm { k W } \qquad T _ { a , o } = 2 0 + { \frac { 2 2 \, 4 0 0 } { 1 0 0 7 } } = \mathbf { 4 2 . 3 \ {} ^ { \circ } C } \qquad T _ { w , o } = 8 0 - { \frac { 2 2 \, 4 0 0 } { 2 0 9 0 } } = 6 9 . 3 \ \mathrm { {} ^ { \circ } C }$$

**空气以$4 2 \ \ {} ^ { \circ } \mathrm { C }$ 离开，远未接近$8 0 \ \ {} ^ { \circ } \mathrm { C }$ 的水温，而水几乎察觉不到这次换热——它降低$1 1 \ \mathrm { K }$ ，空气则升高$2 2 \ \mathrm { K }$ ，因为水的热容量是空气的两倍。****热容量较小的流体承担了大部分温度变化并决定$Q _ { \max }$ ；这台换热器的 NTU 只有$0 . 5 4$ ，只回收了其中略多于三分之一。****还要注意这个答案*不*需要什么：不需要迭代，不需要假设出口温度，也不需要对尚不知道的量取对数平均。**
:::

::: example 部分负荷：同一台换热器在一半流量下 {#ex-partload level=3 check="125"}
对数平均温差例题中那台$4 . 2 2 \ \mathrm { m ^ { 2 } }$ 的水–水换热器投入运行时，**两股流量都减半**，进口温度不变。为简单起见保持$U = 8 5 0 \ \mathrm { W / m ^ { 2 } K }$ （实际上它随流量下降——见本讲末尾的测验）。求换热量。（输入$Q$ ，单位 kW。）$C _ { h } = 4 1 8 0$ ，$C _ { c } = 3 1 3 5 \ \mathrm { W / K }$ ，所以$C _ { \min } = 3 1 3 5$ ，$C _ { r } = 0 . 7 5$ ，且

$$\mathrm { N T U } = { \frac { 8 5 0 \times 4 . 2 2 } { 3 1 3 5 } } = 1 . 1 4 \qquad \varepsilon = { \frac { 1 - \exp [ - 1 . 1 4 \times 0 . 2 5 ] } { 1 - 0 . 7 5 \exp [ - 1 . 1 4 \times 0 . 2 5 ] } } = { \frac { 0 . 2 4 9 } { 0 . 4 3 7 } } = 0 . 5 7 0$$

$$Q = 0 . 5 7 0 \times 3 1 3 5 \times 7 0 = \mathbf { 1 2 5 \ k W } \qquad T _ { h , o } = 9 0 - { \frac { 1 2 5 \, 0 0 0 } { 4 1 8 0 } } = 6 0 . 1 \ \mathrm { {} ^ { \circ } C } \qquad T _ { c , o } = 2 0 + { \frac { 1 2 5 \, 0 0 0 } { 3 1 3 5 } } = 5 9 . 9 \ \mathrm { {} ^ { \circ } C }$$

**两股流量减半使效能从$0 . 3 8$ 提高到$0 . 5 7$ ——同样的传热面与流体接触的时间加倍——但换热量从$1 6 7$ 降到$1 2 5 \ \mathrm { k W }$ ，因为$Q _ { \max } = C _ { \min } \Delta T _ { i }$ 随流量减半了。****两个出口温度现在相差不到$0 . 2 \ \mathrm { K }$ ——这是这组数字的巧合，但也表明这台换热器相对于它所通过的流量而言，现在有大量的传热面。****一般结论：在进口温度固定时，换热量的下降小于流量下降的比例，因为效能随流量减小而升高，而只有$\varepsilon$–NTU 法能不经迭代给出这一答案。**
:::

## 5. 叉流、多流程与蓄热式设备

::: definition 混合、非混合，以及这一区分为何重要 {#def-mixed}
当流体被限制在管道或通道中、无法在换热器宽度方向上重新分配温度时，该流体是**非混合的**；能够重新分配时则是**混合的**——横掠管束的叉流是混合的，因为流体绕过管子滑行并重新平均，而管内流体是非混合的。**混合会破坏温差**：混合的流体离开一排管子时处于它刚刚获得热量的平均温度，因此它不能像非混合流体那样被推得那么远。这一损失随 NTU 和$C _ { r }$ 增大——从$\mathrm { N T U } \approx 1$ 时可以忽略，到平衡换热器在$\mathrm { N T U } = 5$ 时约为效能的$1 5 \ \ \%$ （两侧非混合为$0 . 7 5$ ，一侧混合为$0 . 6 3$ ）。**一个相关的陷阱：旁路或泄漏通道使部分流体绕过传热面，换热器会悄无声息地损失任何关联式都预测不到的性能。**
:::

::: example 板式对管壳式：同样的换热量，几分之一的体积 {#ex-plate level=3 check="0.60"}
对数平均温差例题中$1 6 7 \ \mathrm { k W }$ 的水–水换热量，改用$U = 6 0 0 0 \ \mathrm { W / m ^ { 2 } K }$ 的垫片式板框换热器（典型值：波纹板使流动在雷诺数为几百、通道流速为每秒零点几米时即成为湍流），按逆流处理。求面积。（输入$A$ ，单位$\mathrm { m ^ { 2 } }$ 。）

$$A = { \frac { 1 6 7 \, 2 0 0 } { 6 0 0 0 \times 4 6 . 6 } } = \mathbf { 0 . 6 0 \ m ^ { 2 } } \qquad \text{而管壳式为 } 4 . 2 \ \mathrm { m ^ { 2 } } \text{，其 } U = 8 5 0$$

**传热面少到七分之一，而且——因为板片组的面积密度为$3 0 0$ 到$5 0 0 \ \mathrm { m ^ { 2 } / m ^ { 3 } }$ ，而管壳式管束为$2 0 0$ ——体积大约只有十分之一。****代价是：弹性体垫片把温度限制在大约$1 5 0 \ \ {} ^ { \circ } \mathrm { C }$ 、压力限制在大约$2 . 5 \ \mathrm { M P a }$ ，而且只有几毫米宽的窄通道会被杂物堵塞（不过板片组可以打开，板片可以用手工清洗）。****这一权衡——传热系数和紧凑性对污垢容忍度和压力–温度限制——就是这两种设备之间的全部选型决策，这也是区域供热换热站使用板式换热器、而高压电站给水加热器不用的原因。**
:::

::: definition 蓄热器，以及热填料的代价 {#def-regenerator}
**蓄热器**把热量储存在一个热质中，片刻之后再交给另一股流体：由波纹金属箔构成的旋转转轮（容克式（Ljungström）空气预热器、通风热回收转轮），在热气与冷气之间切换的固定格子砖床（高炉热风炉、玻璃窑炉），或斯特林发动机的金属丝网填料。对于平衡、理想、切换无限快的转轮，其效能恰好等于平衡逆流的结果$\varepsilon = \mathrm { N T U } / ( 1 + \mathrm { N T U } )$ ，其中$\mathrm { N T U } = h A _ { s } / C _ { \min }$ 以填料表面计——而由于填料的面积密度可达$2 0 0 0$ 到$4 0 0 0 \ \mathrm { m ^ { 2 } / m ^ { 3 } }$ ，转轮能在间壁式换热器体积的几分之一内达到$\varepsilon = 0 . 7 5$ 到$0 . 8 5$ 。**随之而来的有三项代价：携带泄漏**（截留在填料中的气体被带入另一股流体——对空气–空气换热可以接受，对许多工艺气体则不可接受，这也是转轮装有吹扫扇区的原因），**填料温度控制**（冷端温度低于烟气酸露点的锅炉空气预热器会发生腐蚀和积灰），以及转轮的**寄生驱动功率**。**斯特林发动机的回热器是极端情形：面积密度量级为$1 0 ^ { 4 } \ \mathrm { m ^ { 2 } / m ^ { 3 } }$ 的细丝填料，其效能必须接近$0 . 9 9$ ，因为回热器每差百分之一的效能，都是发动机必须重新供给的热量。**
:::

## 6. 夹点，以及最后一开尔文的代价

::: definition 温差就是货币 {#def-pinch}
在$T$–$Q$ 图（温度对累计传热量）上，每股流体都是一条斜率为$1 / C$ 的直线，两线之间的竖直间距就是局部驱动温差。**夹点是图上的最小间距**，也是换热器每瓦热量所需面积最多的地方。对于平衡逆流换热器，间距是均匀的，等于$( 1 - \varepsilon ) \Delta T _ { i }$ ，因此面积遵循如下规律

$$A = { \frac { Q } { U \Delta T _ { \text{间距 } } } } = { \frac { C _ { \min } \, \varepsilon \, \Delta T _ { i } } { U ( 1 - \varepsilon ) \Delta T _ { i } } } = { \frac { C _ { \min } } { U } } \, { \frac { \varepsilon } { 1 - \varepsilon } } \qquad \Longrightarrow \qquad \boxed { A = { \frac { C _ { \min } } { U } } \, { \frac { \Delta T _ { i } - \Delta T _ { \text{夹点 } } } { \Delta T _ { \text{夹点 } } } } \approx { \frac { C _ { \min } } { U } } { \frac { \Delta T _ { i } } { \Delta T _ { \text{夹点 } } } } }$$

**一旦逼近温差比进口温差小得多，把它减半就大致使面积加倍。****因此经济最优并不是"越接近越好"：液–液和制冷工况的典型设计逼近温差为几开尔文到$1 5 \ \mathrm { K }$ ，在传热面昂贵的气–液换热器中更大，而在低温和空气分离装置中只有一到几开尔文，因为在那里较大的逼近温差所浪费的冷量更加昂贵。****同一张图也是整个工厂夹点分析的工具：换热网络的设计使任何一台换热器的间距都不小于所选的最小值，并通过在各股流体之间转移热量、而不是一上来就动用冷却水，使全厂的总面积最小。**
:::

::: example 最后七开尔文的代价 {#ex-approach level=3 check="66.4"}
一台平衡的水–水换热器，$C _ { \min } = 6 2 7 0 \ \mathrm { W / K }$ ，$U = 8 5 0 \ \mathrm { W / m ^ { 2 } K }$ ，进口温度为$9 0$ 和$2 0 \ \ {} ^ { \circ } \mathrm { C }$ 。每种逼近温差各需要多少传热面？（输入$7 \ \mathrm { K }$ 逼近温差对应的面积，单位$\mathrm { m ^ { 2 } }$ 。）

| 逼近温差（两端） | $\varepsilon$ | NTU $= \varepsilon / ( 1 - \varepsilon )$ | 面积$= \mathrm { NTU } \, C _ { \min } / U$ |
|:--|--:|--:|--:|
| $1 4 \ \mathrm { K }$ | $0 . 8 0$ | $4 . 0$ | $2 9 . 5 \ \mathrm { m ^ { 2 } }$ |
| $7 \ \mathrm { K }$ | $0 . 9 0$ | $9 . 0$ | $\mathbf { 6 6 . 4 \ m ^ { 2 } }$ |
| $5 \ \mathrm { K }$ | $0 . 9 2 9$ | $1 3 . 0$ | $9 5 . 9 \ \mathrm { m ^ { 2 } }$ |
| $3 . 5 \ \mathrm { K }$ | $0 . 9 5$ | $1 9 . 0$ | $1 4 0 \ \mathrm { m ^ { 2 } }$ |

**把逼近温差从$1 4$ 减半到$7 \ \mathrm { K }$ 需要$2 . 2 5$ 倍的面积；再减半到$3 . 5 \ \mathrm { K }$ 需要原来的$4 . 7 5$ 倍。****第一行的换热量为$0 . 8 0 \times 6 2 7 0 \times 7 0 = 3 5 1 \ \mathrm { k W }$ ，最后一行为$4 1 7 \ \mathrm { k W }$ ——用$4 . 7 5$ 倍的金属换来$1 9 \ \ \%$ 的热量增益。****这是否值得购买，取决于额外热量的价值与传热面成本的比较——而这正是在每一个热回收设计中决定逼近温差的那个权衡。**
:::

::: warning 另外两个，来自热力学第二定律
**换热器通过有限温差传热而产生熵。**损失的功为$T _ { 0 } \dot { S } _ { \text{产 } }$ ，当温差小且沿换热器均匀时它最小——这需要热容量近乎相等的逆流布置；一股$1 0 0 \ \mathrm { k W / K }$ 的流体加热一股$1 0 \ \mathrm { k W / K }$ 的流体，不可能在两端都保持小的间距。**权衡的另一半是泵功：换热量只随流量亚线性地增加，因为 NTU 随$C$ 增大而减小；而在湍流中，压降大致随流量的平方增加，泵或风机的功率大致随其立方增加。****这就是为什么对于给定的换热量，一台较大的、低流速的换热器往往胜过一台较小的、高强度运行的换热器。**
:::

::: proof 顺流效能及其上限 {#proof-parallel}
直接从微元能量平衡推导顺流换热器的$\varepsilon = \left\{ 1 - \exp [ - \mathrm { N T U } ( 1 + C _ { r } ) ] \right\} / ( 1 + C _ { r } )$ ，并由此求出$A \rightarrow \infty$ 时的出口温度。解释为什么平衡顺流换热器无论多大都不能超过$\varepsilon = 0 . 5$ ，以及为什么逆流换热器没有这样的上限。
::: solution
**在顺流中两种流体沿同一方向流动，因此$d q = - C _ { h } d T _ { h } = C _ { c } d T _ { c }$ ，且**
$$d ( \Delta T ) = d T _ { h } - d T _ { c } = - \left( { \frac { 1 } { C _ { h } } } + { \frac { 1 } { C _ { c } } } \right) d q = - U \Delta T \left( { \frac { 1 } { C _ { h } } } + { \frac { 1 } { C _ { c } } } \right) d A$$
**积分得$\Delta T _ { o } / \Delta T _ { i } = \exp [ - U A ( 1 / C _ { h } + 1 / C _ { c } ) ]$ 。写出$Q = C _ { h } ( T _ { h , i } - T _ { h , o } ) = C _ { c } ( T _ { c , o } - T _ { c , i } )$ 和$\Delta T _ { i } - \Delta T _ { o } = Q ( 1 / C _ { h } + 1 / C _ { c } )$ ，再除以$C _ { \min } \Delta T _ { i }$ ，**
$$\varepsilon = { \frac { 1 - \Delta T _ { o } / \Delta T _ { i } } { C _ { \min } ( 1 / C _ { h } + 1 / C _ { c } ) } } = { \frac { 1 - \exp [ - \mathrm { N T U } ( 1 + C _ { r } ) ] } { 1 + C _ { r } } }$$
**因为$C _ { \min } ( 1 / C _ { h } + 1 / C _ { c } ) = C _ { \min } / C _ { \min } + C _ { \min } / C _ { \max } = 1 + C _ { r }$ 。当$A \rightarrow \infty$ 时指数项消失，$\varepsilon _ { \max } = 1 / ( 1 + C _ { r } )$ ，当$C _ { r } = 1$ 时为$0 . 5$ ：两股流体在共同温度$T _ { \infty }$ 处相遇，换热器在其出口处耗尽了驱动力，无论增加多少传热面都是如此。****逆流没有上限，因为两端是解耦的——热流体出口面对冷流体进口——所以$\Delta T$ 可以处处均匀且为正，并且对每一个$C _ { r }$ 都有当$\mathrm { N T U } \rightarrow \infty$ 时$\varepsilon \rightarrow 1$。**
:::

::: proof 最佳清洗周期 {#proof-fouling-optimum}
一台热回收换热器在清洁时回收热量$Q _ { 0 }$ ，清洁传热系数为$U _ { c }$ 。其污垢热阻随时间线性增长，$R _ { f } = a t$ ，在$U _ { c } R _ { f } \ll 1$ 时取回收热量与$U$ 成比例下降（低 NTU 的保守情形），于是损失热量的速率为$Q _ { 0 } U _ { c } a t$ 。每次清洗的固定费用为$K _ { c }$ ，损失热量的价值为每焦耳$p$ 。证明使平均费用最小的清洗周期为$t _ { c } ^ { * } = \sqrt { 2 K _ { c } / ( p Q _ { 0 } U _ { c } a ) }$ ，并在$Q _ { 0 } = 5 \ \mathrm { M W }$ 、$U _ { c } = 6 0 0 \ \mathrm { W / m ^ { 2 } K }$ 、污垢热阻在$1 0 0$ 天内增长$0 . 0 0 0 4 \ \mathrm { m ^ { 2 } K / W }$ 、一次清洗的费用等于整整一天回收热量的价值时求其数值。
::: solution
**在长度为$t _ { c }$ 的一个周期内，损失的热量为$\int _ { 0 } ^ { t _ { c } } Q _ { 0 } U _ { c } a t \, \mathrm { d } t = \tfrac { 1 } { 2 } Q _ { 0 } U _ { c } a t _ { c } ^ { 2 }$ ，因此单位时间的平均费用为**
$$\bar { K } ( t _ { c } ) = { \frac { K _ { c } } { t _ { c } } } + \tfrac { 1 } { 2 } p Q _ { 0 } U _ { c } a \, t _ { c } \qquad { \frac { \mathrm { d } \bar { K } } { \mathrm { d } t _ { c } } } = - { \frac { K _ { c } } { t _ { c } ^ { 2 } } } + \tfrac { 1 } { 2 } p Q _ { 0 } U _ { c } a = 0 \ \Longrightarrow \ t _ { c } ^ { * } = \sqrt { \frac { 2 K _ { c } } { p Q _ { 0 } U _ { c } a } }$$
**在最优点两项相等：每天的清洗费用等于每天损失热量的平均价值。****取$K _ { c } = p Q _ { 0 } \times ( 1 \ \text{天} )$ ，价格相互抵消，并且$a = 4 \times 1 0 ^ { - 6 } \ \mathrm { m ^ { 2 } K / W }$ 每天，**
$$t _ { c } ^ { * } = \sqrt { \frac { 2 \times 1 \ \text{天} } { 6 0 0 \times 4 \times 1 0 ^ { - 6 } \ \text{天} ^ { - 1 } } } = \sqrt { 8 3 3 } \ \text{天} \approx 2 9 \ \text{天}$$
**到那时$U _ { c } R _ { f } = 0 . 0 7$ ，所以小污垢假设成立，换热器损失了约$7 \ \ \%$ 的换热量，即$0 . 3 5 \ \mathrm { M W }$ 。****清洗周期与清洗费用对污垢增长速率之比的平方根成正比：清洗费用贵四倍，周期只加倍。实践中污垢增长速率是测出来的，而不是假设的——它来自根据工厂自身的温度和流量算出的$U$ 的变化趋势。**
:::
:::

::: quiz 哪类问题，用哪种方法 {#quiz-method}
一台你已拥有的换热器必须在其设计流量的一半下重新校核，出口温度未知。正确的方法是
- [ ] 用设计温差的对数平均温差法，因为$U$ 不变
- [x] $\varepsilon$–NTU 法，并按新的流量重新计算$U$
- [ ] 两者皆可，它们完全相同
- [ ] 算术平均温差，因为换热器是平衡的

::: solution
**$\varepsilon$–NTU 法是校核方法：面积已知，流量已知，出口温度未知，而对未知温度取对数平均是循环的。****这个答案中的陷阱在后半句：$U$ *并非*不变，因为两侧的表面传热系数都随流量变化（在湍流单相侧大致与$G ^ { 0 . 8 }$ 成正比，在气体侧为$G ^ { 0 . 5 }$ 或更差），所以两侧流量都减半可能使$U$ 降低三分之一或更多，而"$U$ 不变、NTU 加倍"的天真答案会高估换热量。**
:::
:::

::: quiz 肋片加在哪里 {#quiz-fins}
一台气–水换热器的$h _ { \text{气 } } = 6 0$ ，$h _ { \text{水 } } = 4 0 0 0 \ \mathrm { W / m ^ { 2 } K }$。对于固定的光管面积，哪一项改变获得的热量最多？
- [ ] 使水流速加倍，从而使$h _ { \text{水 } }$ 加倍
- [x] 在气体侧加装总表面效率为$0 . 8 5$ 、面积比为$1 5$ 的肋片
- [ ] 采用导热系数更高的管子
- [ ] 改为纯逆流

::: solution
**气体侧占热阻的$9 8 . 5 \ \ \%$ ，所以只有气体侧要紧：$\eta _ { o } A _ { r } = 1 2 . 7 5$ 的肋片使气体侧热阻减小到原来的这么多分之一，使$U$ 从$5 9$ 提高到约$6 4 0 \ \mathrm { W / m ^ { 2 } K }$ 。****使水侧表面传热系数加倍只使$U$ 变化不到$1 \ \ \%$ ；更好的管材只使它变化百分之零点几；而逆流与设计良好的多流程壳体相比可带来$5$ 到$1 5 \ \ \%$ 的差别——确实存在，但比解决主导热阻小一个数量级。****本讲的一般规则：先算出热阻分布，然后才去讨论改进。**
:::

## 后续内容

- **[[heat-transfer/boiling-condensation|沸腾与凝结]]**提供了主导蒸发器和冷凝器设计的两个表面传热系数，并提醒：在进口为过热蒸汽的冷凝器中$U$ 沿程不是常数——这类换热器要分区计算。
- **[[heat-transfer/internal-convection|管内强制对流]]**给出管程表面传热系数，并通过$h \propto G ^ { 0 . 8 }$ 给出换热器在部分流量下的全部非设计工况特性。
- **[[heat-transfer/external-convection|外部强制对流]]**是肋片管、管束和叉流的那一侧：气体表面传热系数、管排修正以及紧凑式传热面的压降。
- **[[heat-transfer/fins|扩展表面]]**是肋效率的计算，它决定你加装的肋片是否值得那些金属。
- **[[thermodynamics/second-law|热力学第二定律]]**和**[[thermodynamics/exergy|㶲（exergy）]]**是本讲的熵产观点成为全厂方法的地方：夹点分析、热集成，以及温差就是一次被耗费掉的机会这一事实。
- **[[energy-systems/gas-turbines-combined-cycles|燃气轮机与联合循环]]**、**[[energy-systems/refrigeration-hvac|制冷与暖通空调]]**和**[[propulsion/gas-turbine-cycles|燃气涡轮循环]]**是回热器、蓄热器、中间冷却器和冷凝器不再是习题、而开始决定循环效率的地方。
- **[[fluid-mechanics/pipe-flow|管内流动]]**为每一个换热器决策的另一半定价：气侧和水侧的压降，它们在工厂的整个寿命期内变成风机和泵的功率。

::: summary
- **$1 / U A$ 是折算到所选同一面积的串联热阻回路。**在光管气–液换热器中，气体侧通常占$9 5 \ \ \%$ 或更多，这就是肋片加在气体侧的原因——加肋之后液体侧又变得重要。污垢热阻按热阻相加，在$U = 8 5 0$ 的换热器上加$0 . 0 0 0 6 \ \mathrm { m ^ { 2 } K / W }$ 就是传热系数损失$3 4 \ \ \%$ 。
- **$Q = U A F \Delta T _ { \text{lm } }$ ，其中$\Delta T _ { \text{lm } } = ( \Delta T _ { 1 } - \Delta T _ { 2 } ) / \ln ( \Delta T _ { 1 } / \Delta T _ { 2 } )$**——总是低于算术平均值，两端温差之比为$2 . 3$ 时低$6 \ \ \%$ ，为$1 0 0$ 时低$5 7 \ \ \%$ 。在四个温度已知时使用它。
- **$F$ 是不采用逆流的代价。**保持$F \geq 0 . 8 5$ ；低于$0 . 8$ 时改变布置形式（增加壳程、改用板式或套管式），绝不改变面积。$F$ 在$P R \rightarrow 1$ 时崩落，因为这种布置耗尽的是温差，而不是传热面。
- **$\varepsilon = Q / ( C _ { \min } \Delta T _ { i } )$ ，$\mathrm { N T U } = U A / C _ { \min }$ ，$C _ { r } = C _ { \min } / C _ { \max }$**——校核方法，也是回答部分负荷问题唯一合理的途径。$C _ { \min }$ 那股流体的温度变化最大，并决定上限。
- **应该记在脑子里的公式：**冷凝器$\varepsilon = 1 - e ^ { - \mathrm { N T U } }$ ；平衡逆流$\varepsilon = \mathrm { N T U } / ( 1 + \mathrm { N T U } )$ ；顺流$\varepsilon = \{ 1 - \exp [ - \mathrm { N T U } ( 1 + C _ { r } ) ] \} / ( 1 + C _ { r } )$ ，上限为$1 / ( 1 + C _ { r } )$ 。逆流没有上限；顺流总有。
- **NTU 的收益递减，夹点是有价格的。**平衡换热器要达到$8 0 \ \ \%$ 需要 4 个传热单元，要达到$9 5 \ \ \%$ 需要 19 个；一旦逼近温差较小，把它减半大致使面积加倍。根据热量的价格与金属的价格来选择逼近温差，而不是凭乐观。
- **在高 NTU 时混合会损失效能（平衡换热器在$\mathrm { N T U } = 5$ 时约$1 5 \ \ \%$ ），而用新鲜冷却介质分级不能替代使用同样冷却介质的逆流。**蓄热器以携带泄漏和一台驱动电机为代价，换取单位体积的效能。
- **换热器是一个第二定律装置：**通过有限温差传热会损失功$T _ { 0 } \dot { S } _ { \text{产 } }$ ，设计中的权衡是面积和泵功的成本与较大温差所浪费的价值之间的比较。
:::
