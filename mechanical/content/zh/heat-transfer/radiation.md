站在离一块炽热锻件一米远的地方，你的脸立刻就能感到热，尽管你们之间的空气仍是凉的。没有任何物质在传递这份热量；它到达的速率由锻件热力学温度的**四次方**决定——这条定律在本课程的其他任何地方都找不到类比。热辐射不是对导热和对流传热的修正；它是一种遵循不同规则的不同机理，正是这一机理把太阳的能量送过一亿五千万千米的虚空，决定着每一个航天器的温度，主导着火焰和炉膛中的传热，并在房间里任何热表面的散热中占很大份额。

工程上的难点在于热辐射具有**选择性**和**方向性**。一个表面并没有唯一的发射率；它对每一个波长、每一个方向都有不同的发射率，而两个表面之间的换热又取决于连接它们的几何关系。使这一切变得可以处理的那套工具——黑体、灰体、角系数和网络类比——是这门学科中最优美的应用物理之一，而它全部建立在普朗克（Max Planck）于1900年为黑体光谱找到的公式之上；正是在这一过程中，他引入了量子。

::: warning 这门学科会强行灌输给你的四个习惯
**其一——永远不要用温差，要用四次方之差。**$q = \varepsilon \sigma A ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } )$在你有意将其线性化之前并不等于$h _ { r } A \Delta T$，而且这种线性化只在很小的范围内才站得住。在$3 0 0 \ \mathrm { K }$与$3 1 0 \ \mathrm { K }$之间两种形式一致；在$3 0 0 \ \mathrm { K }$与$1 5 0 0 \ \mathrm { K }$之间它们毫无相似之处。

**其二——环境是一个表面，而不是一个温度。**管道中的热电偶读出的是来自气体的对流与向**它所能看到的壁面**的辐射之间的平衡；如果壁面比气体冷$4 0 0 \ \mathrm { K }$，测点的读数可能偏低几十开尔文（在第9节的例题中偏低九十开尔文）。“环境温度”不是辐射边界条件；周围表面的温度才是，而它通常是另一个数。

**其三——发射率不是材料常数。**它取决于波长、方向、温度，尤其取决于表面最后几微米的经历：$\varepsilon \approx 0 . 0 4$的抛光铝一旦经过风化、氧化或变脏，发射率就会高出好几倍，而阳极氧化铝接近$0 . 8$。本讲每一张表中的每一个发射率都是一种**表面状况**，而不是其下金属的物性。

**其四——热辐射沿直线传播。**导热和对流传热是扩散的，热辐射则是射流式的；两个彼此看不见的表面无论多热、离得多近，都不能通过辐射换热。本讲的大部分算术都是几何。
:::

## 1. 发射、投入辐射、有效辐射：记账

::: definition 各个量，以及每个量计的是什么 {#def-quantities}
热辐射是波长约在$0 . 1$到$1 0 0 \ \mu \mathrm { m }$范围内的电磁辐射——跨越近紫外、整个可见光区和热红外区。记账要用到五个量，把它们混为一谈是这门学科中最常见的错误：

| 量 | 符号 | 它计的是什么 | 单位 |
|:--|:--|:--|:--|
| 光谱辐射力 | $E _ { \lambda }$ | 实际表面单位面积、单位波长**发射**的能量 | $\mathrm { W / m ^ { 2 } \, \mu m }$ |
| 黑体光谱辐射力 | $E _ { b \lambda }$ | 理想发射体的同一个量 | $\mathrm { W / m ^ { 2 } \, \mu m }$ |
| 投入辐射 | $G$ | 从其他一切**到达**表面的能量 | $\mathrm { W / m ^ { 2 } }$ |
| 有效辐射 | $J$ | **离开**表面的能量：发射加反射 | $\mathrm { W / m ^ { 2 } }$ |
| 定向辐射强度 | $I$ | 沿某一方向、单位投影面积、单位立体角的能量 | $\mathrm { W / m ^ { 2 } \, sr }$ |

实际表面的总（对全部波长积分的）辐射力为$E = \varepsilon \sigma T _ { s } ^ { 4 }$，而离开不透明表面的净辐射热流密度等于离开的减去到达的：

$$q _ { \text{net,rad } } = J - G = \varepsilon \sigma T _ { s } ^ { 4 } - \alpha G \qquad \text{以及} \qquad J = \underbrace { \varepsilon \sigma T _ { s } ^ { 4 } } _ { \text{发射} } + \underbrace { ( 1 - \varepsilon ) G } _ { \text{反射} } \quad \text{（不透明表面）}$$

**有效辐射方程一行就包含了网络法的全部**：表面发射其温度和发射率所规定的能量，并反射到达能量中的其余部分；而由于$\varepsilon$同时也决定了投入辐射中有多少**不**被反射，一个数就把账结清了。对于能透射的表面（一块玻璃板），还必须加上一个透射项。
:::

::: definition 黑体，以及它为什么是恰当的基准 {#def-blackbody}
**黑体**吸收投射到它上面的全部辐射$( \alpha = 1 )$，并且作为可能的最佳吸收体，按基尔霍夫定律它在每一个波长上都是可能的最佳发射体。**没有任何实际表面能胜过它，所以它是标尺。**有两个事实使它不只是一种约定。**第一，一个开有小孔的小等温空腔是近乎完美的黑体，不论空腔由什么材料制成、内壁多么光亮**——射入小孔的辐射被反射许多次，每次反射都被吸收掉一部分，因此逃逸的概率很小；开口足够小时，即使壁面发射率并不高，小孔的有效发射率也超过$0 . 9 9$。这就是每一台高温计和每一台红外热像仪中的标准辐射源和标准基准。**第二，黑体光谱只取决于温度**——与材料无关，与形状无关，与经历无关——这就是为什么它是唯一能从第一性原理求解的辐射问题，也是为什么它是其他一切的基准。
:::

::: example 寒冷机房中的热管道 {#ex-hot-pipe-room level=2 check="775"}
一根直径$1 0 0 \ \mathrm { m m }$、长$1 \ \mathrm { m }$的蒸汽管道，温度为$5 0 0 \ \mathrm { K }$ $( 2 2 7 \ \mathrm { {} ^ { \circ } C } )$，处在一个墙壁、地板和天花板均为$3 0 0 \ \mathrm { K }$的房间中。管道涂有$\varepsilon = 0 . 8$的油漆。求辐射散热量，并与$h \approx 5 \ \mathrm { W / m ^ { 2 } K }$的自然对流相比较。（输入辐射散热量，单位W。）

$$A = \pi D L = \pi \times 0 . 1 \times 1 = 0 . 3 1 4 \ \mathrm { m ^ { 2 } } \qquad q _ { \text{rad } } = \varepsilon \sigma A ( T _ { s } ^ { 4 } - T _ { \text{sur } } ^ { 4 } ) = 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } \times 0 . 3 1 4 \times ( 6 . 2 5 - 0 . 8 1 ) \times 1 0 ^ { 1 0 }$$

$$q _ { \text{rad } } = \mathbf { 7 7 5 \ W } \qquad q _ { \text{conv } } = h A \Delta T \approx 5 \times 0 . 3 1 4 \times 2 0 0 = 3 1 4 \ \mathrm { W }$$

**辐射是自然对流的两倍半，它并不是任何人所以为的那个小项。****一个数里有三条教训。****四次方很陡：$5 0 0 ^ { 4 } / 3 0 0 ^ { 4 } = 7 . 7$，而温度只高了$1 . 6 7$倍。****周围环境起决定性作用——把$3 0 0 \ \mathrm { K }$的墙壁换成$4 5 0 \ \mathrm { K }$的表面，无论空气如何，净辐射都会骤降到$3 0 6 \ \mathrm { W }$。****而发射率是一个你可以转动的调节旋钮：用$\varepsilon = 0 . 0 5$的铝箔包住管道，辐射项就降到$4 8 \ \mathrm { W }$，这就是为什么保温管道的外层用光亮的金属护板而不是黑漆。**

## 2. 普朗克、维恩、斯特藩-玻尔兹曼，以及要紧的波段

::: definition 三条黑体定律 {#def-planck}
**普朗克定律**给出热力学温度为$T$的黑体单位波长的光谱辐射力：

$$E _ { b \lambda } ( \lambda , T ) = { \frac { C _ { 1 } } { \lambda ^ { 5 } \left[ \exp \! \left( C _ { 2 } / \lambda T \right) - 1 \right] } } \qquad C _ { 1 } = 3 . 7 4 2 \times 1 0 ^ { 8 } \ { \frac { \mathrm { W \, \mu m ^ { 4 } } } { \mathrm { m ^ { 2 } } } } \ , \quad C _ { 2 } = 1 . 4 3 8 8 \times 1 0 ^ { 4 } \ \mu \mathrm { m \, K }$$

**维恩位移定律**——对$\lambda$求导并令结果为零——确定峰值的位置：

$$\lambda _ { \max } T = 2 8 9 8 \ \mu \mathrm { m \, K }$$

**斯特藩-玻尔兹曼定律**——对普朗克定律在全部波长上积分——给出总量：

$$\boxed { \ E _ { b } ( T ) = \sigma T ^ { 4 } \ } \qquad \sigma = 5 . 6 7 0 \times 1 0 ^ { - 8 } \ \mathrm { W / m ^ { 2 } K ^ { 4 } }$$

**两条定律说的是互补的事。****维恩定律说能量在哪里：随着$T$升高，整个光谱移向短波，所以$3 0 0 \ \mathrm { K }$的表面在$1 0 \ \mu \mathrm { m }$附近辐射，$5 8 0 0 \ \mathrm { K }$的表面在$0 . 5 \ \mu \mathrm { m }$附近辐射。****斯特藩-玻尔兹曼定律说有多少：总量按$T ^ { 4 }$变化，所以热力学温度加倍，发射就增至十六倍。****对工程而言，有用的导出量是线性化系数**

$$h _ { r } = { \frac { \varepsilon \sigma ( T _ { s } ^ { 4 } - T _ { \text{sur } } ^ { 4 } ) } { T _ { s } - T _ { \text{sur } } } } \approx 4 \varepsilon \sigma T _ { m } ^ { 3 } \qquad \Longrightarrow \qquad h _ { r } = 4 . 9 \ , \ 2 3 \ , \ 9 3 \ , \ 1 8 1 \ , \ 6 1 2 \ \mathrm { W / m ^ { 2 } K } \ \text{对应 } T _ { m } = 3 0 0 , 5 0 0 , 8 0 0 , 1 0 0 0 , 1 5 0 0 \ \mathrm { K } \ ( \varepsilon = 0 . 8 )$$

**这个阶梯是本讲中最有用的一个数。****在室温下，辐射充其量与自然对流相当；在$8 0 0 \ \mathrm { K }$时，它胜过几乎任何不靠耗费功率就能造出的强制对流系数；在$1 5 0 0 \ \mathrm { K }$时，它是唯一要紧的项。**
:::

::: proof 对普朗克定律积分，以及$\sigma$从何而来 {#proof-sigma}
令$x = C _ { 2 } / \lambda T$，于是$\lambda = C _ { 2 } / ( x T )$，$d \lambda = - C _ { 2 } \, d x / ( x ^ { 2 } T )$。则

$$E _ { b } = \int _ { 0 } ^ { \infty } { \frac { C _ { 1 } } { \lambda ^ { 5 } ( e ^ { C _ { 2 } / \lambda T } - 1 ) } } \, d \lambda = { \frac { C _ { 1 } T ^ { 4 } } { C _ { 2 } ^ { 4 } } } \int _ { 0 } ^ { \infty } { \frac { x ^ { 3 } } { e ^ { x } - 1 } } \, d x = { \frac { C _ { 1 } T ^ { 4 } } { C _ { 2 } ^ { 4 } } } \cdot { \frac { \pi ^ { 4 } } { 1 5 } }$$

**所以$E _ { b } \propto T ^ { 4 }$——四次方仅由变量替换就得出，而积分是纯数$\pi ^ { 4 } / 1 5 = 6 . 4 9 4$。****代入常数：$\sigma = 3 . 7 4 2 \times 1 0 ^ { 8 } \times 6 . 4 9 4 / ( 1 . 4 3 8 8 \times 1 0 ^ { 4 } ) ^ { 4 } = 5 . 6 7 \times 1 0 ^ { - 8 } \ \mathrm { W / m ^ { 2 } K ^ { 4 } }$，这就是斯特藩（Josef Stefan）于1879年主要依据廷德尔（John Tyndall）的测量凭经验推断、玻尔兹曼（Ludwig Boltzmann）于1884年由热力学导出的那条定律的常数。****求峰值时，对普朗克定律求导并令$d E _ { b \lambda } / d \lambda = 0$，得到超越方程$5 ( 1 - e ^ { - x } ) = x$，其根为$x = 4 . 9 6 5$，因此$\lambda _ { \max } = C _ { 2 } / ( 4 . 9 6 5 \, T )$，$\lambda _ { \max } T = 1 4 \, 3 8 8 / 4 . 9 6 5 = 2 8 9 8 \ \mu \mathrm { m \, K }$。****注意按波长的峰值并不是按频率的峰值——$E _ { \nu }$与$E _ { \lambda }$的峰值位置不同，因为$d \nu \neq d \lambda$——（频率峰值在$x = 2 . 8 2 1$处），这就是为什么太阳按单位波长计的峰值被说成在$0 . 5 0 \ \mu \mathrm { m }$，而按单位频率计的峰值则在约$0 . 8 8 \ \mu \mathrm { m }$所对应的频率处。两者都对；请用波长形式，因为每一张工程表格都用它。**
:::

## 3. 实际表面：发射率、吸收比与基尔霍夫定律

::: definition 发射率、吸收比，以及联系二者的那一条定律 {#def-emissivity}
对于温度为$T _ { s }$的不透明表面，**全波长半球发射率**是它实际产生的发射占黑体发射的份额，

$$\varepsilon ( T _ { s } ) = { \frac { \int _ { 0 } ^ { \infty } \varepsilon _ { \lambda } ( \lambda ) \, E _ { b \lambda } ( \lambda , T _ { s } ) \, d \lambda } { \sigma T _ { s } ^ { 4 } } } \qquad \text{以及} \qquad \alpha ( T _ { \text{源} } ) = { \frac { \int _ { 0 } ^ { \infty } \alpha _ { \lambda } ( \lambda ) \, G _ { \lambda } ( \lambda ) \, d \lambda } { G } }$$

**看一看权函数：$\varepsilon$以表面在其自身温度下的自身发射为权，而$\alpha$则以恰好照射在它上面的任何辐射源的入射辐射为权。****因此，只要辐射源与表面处于不同温度，它们就是不同的数。****基尔霍夫定律**说明的是它们何时相等：

$$\boxed { \ \varepsilon _ { \lambda } ( \lambda , \theta , T ) = \alpha _ { \lambda } ( \lambda , \theta , T ) \ } \quad \text{热平衡时，逐方向、逐波长成立}$$

**在给定波长和方向上的良好吸收体，在同一波长和方向上也是良好发射体——这是热力学第二定律的要求，因为一个在某一模式中吸收多于发射的表面，会自发地从与它自身同温的物体获得热量而升温。****注意基尔霍夫定律所不允许的东西：对于全波长的宽带性质，$\alpha = \varepsilon$仅当入射辐射与表面自身发射具有相同的光谱分布时才成立，也就是说，仅当表面所见的环境与其自身同温时才成立。****灰表面定义为在所有波长上$\varepsilon _ { \lambda } = \alpha _ { \lambda } = \text{常数}$，正是这一假设使第6节的全部内容变得可以处理；对于非金属、油漆、氧化物、皮肤、木材、纸张和炭黑，它是很好的近似，对于抛光金属则是很差的近似。**
:::

::: definition 值得记住的发射率，以及它们的真实含义 {#def-emissivity-table}
| 表面 | $\varepsilon$ | 表面 | $\varepsilon$ |
|:--|--:|:--|--:|
| 黑体空腔 | 0.99–0.999 | 氧化的铜 | 0.6–0.8 |
| 黑铬（选择性吸收涂层，红外） | 0.1 | 碳钢，氧化 | 0.7–0.9 |

| 白漆 | 0.90–0.95 | 砖，耐火黏土 | 0.85–0.95 |
| 人体皮肤 | 0.98 | 混凝土 | 0.85–0.95 |
| 水、冰 | 0.95–0.97 | 玻璃 | 0.85–0.94 |
| 雪 | 0.95–0.99 | 阳极氧化铝 | 0.8 |
| 铝，抛光 | 0.03–0.06 | 铝，氧化 | 0.1–0.3 |
| 银，抛光 | 0.02 | 干空气，常规厚度 | 0.0（透明） |
| 钨，抛光 | 0.03–0.35（随$T$急剧升高） | 木材、纸张 | 0.8–0.95 |

**要带走的三条规律。****抛光金属是差的发射体，而且温度越低越差**——自由电子使它们在红外区成为良好的反射体，并且$\varepsilon$随$T$升高，这就是为什么$2 8 0 0 \ \mathrm { K }$的钨丝有$\varepsilon \approx 0 . 3$，而同一根钨丝在室温下约为$0 . 0 3$。**非金属恰恰相反：发射率高，随温度变化相当平缓，在热红外区的吸收比也高**——这就是为什么在可见光下呈白色的白漆，在$1 0 \ \mu \mathrm { m }$处却是黑的：**漆成白色的散热器和漆成黑色的同一散热器散热速率相同，“黑色散热器散热多”的说法是一个神话，而“白色汽车在阳光下更凉快”的说法却是真的，因为那里辐射源是太阳。****而且同一种金属的数值会因表面状况不同而跨越一个数量级，这就是为什么诚实的设计者取一个范围而不是一个值。**
:::

::: example 选择性表面：两种性质，一个表面 {#ex-selective level=3 check="585"}
一台平板太阳能集热器在环境温度$2 7 \ \mathrm { {} ^ { \circ } C }$下受到$7 0 0 \ \mathrm { W / m ^ { 2 } }$的日照。比较一块平黑板$( \alpha = 0 . 9 5$，$\varepsilon = 0 . 9 5 )$与一块**选择性吸收板**——黑铬或金属陶瓷涂层，在太阳光波段$\alpha = 0 . 9 5$，而在热红外区$\varepsilon = 0 . 1 0$。忽略对流和来自天空的长波辐射，滞止温度由$\alpha G = \varepsilon \sigma T ^ { 4 }$求得。（输入选择性吸收板的温度，单位K。）

$$T = \left( { \frac { \alpha G } { \varepsilon \sigma } } \right) ^ { 1 / 4 } = \left( { \frac { 0 . 9 5 \times 7 0 0 } { 0 . 1 0 \times 5 . 6 7 \times 1 0 ^ { - 8 } } } \right) ^ { 1 / 4 } = \mathbf { 5 8 5 \ K } \ ( 3 1 2 \ \mathrm { {} ^ { \circ } C } ) \qquad \text{对比} \qquad \left( { \frac { 0 . 9 5 \times 7 0 0 } { 0 . 9 5 \times 5 . 6 7 \times 1 0 ^ { - 8 } } } \right) ^ { 1 / 4 } = 3 3 3 \ \mathrm { K } \ ( 6 0 \ \mathrm { {} ^ { \circ } C } )$$

**两百五十开尔文，来自一层涂层。****这个把戏是合法的，因为两种性质对应不同的波段，因而对应不同的物理：涂层是金属基底上的一层薄吸收层（金属陶瓷或黑铬）：它的厚度足以吸收$0 . 3$–$2 . 5 \ \mu \mathrm { m }$的太阳光谱，但在$4 0 0$–$6 0 0 \ \mathrm { K }$的表面发射所在的$5$–$2 5 \ \mu \mathrm { m }$波长上几乎透明，在这些波长上，其下光亮的金属起反射作用。****基尔霍夫定律并未被违反：在$2 \ \mu \mathrm { m }$处，它以$0 . 9 5$吸收、以$0 . 9 5$发射；在$1 0 \ \mu \mathrm { m }$处，它以$0 . 1 0$吸收、以$0 . 1 0$发射。****节能玻璃上的低辐射涂层也是同一想法：在中空玻璃单元的一个内表面上，薄膜叠层中几纳米厚的银对可见光透明而在红外区反射，把该表面的发射率从$0 . 8 4$降到约$0 . 0 5$。两块玻璃分别为$2 0$和$- 1 0 \ \ {} ^ { \circ } \mathrm { C }$时，空腔中的辐射换热降为原来的几分之一，倍数为**

$$\frac { 1 / 0 . 0 5 + 1 / 0 . 8 4 - 1 } { 2 / 0 . 8 4 - 1 } = \frac { 2 0 . 2 } { 1 . 3 8 } = \mathbf { 1 4 . 6 } \qquad 1 0 6 \ \mathrm { W / m ^ { 2 } } \ \longrightarrow \ 7 . 3 \ \mathrm { W / m ^ { 2 } }$$

**而由于在普通充空气的空腔中辐射携带了将近四分之三的热量，一层看不见的涂层就把空腔的热导降到约三分之一（见第9节的窗户空气层例题）。**
:::

## 4. 角系数：可见之物的几何

::: definition 角系数，以及让你免于积分的四条规则 {#def-viewfactor}
辐射以锥形离开表面微元并沿直线传播。**角系数**$F _ { i j }$是离开表面$i$的全部辐射中直接落到表面$j$上的份额；对于漫射表面，它是一个只取决于几何的纯数：

$$F _ { i j } = { \frac { 1 } { A _ { i } } } \int _ { A _ { i } } \int _ { A _ { j } } { \frac { \cos \theta _ { i } \cos \theta _ { j } } { \pi S ^ { 2 } } } \, d A _ { j } \, d A _ { i } \qquad \left[ \sum _ { j } F _ { i j } = 1 \right]$$

这个二重积分实际上是四维的，很少直接计算。四条规则几乎承担了全部工作：

| 规则 | 表述 | 用途 |
|:--|:--|:--|
| **相对性** | $A _ { i } F _ { i j } = A _ { j } F _ { j i }$ | 由容易的方向求出困难的方向 |
| **完整性** | 对封闭空间，$\sum _ { j } F _ { i j } = 1$ | 由已知求未知 |
| **对称性** | 积分之前先利用对称面 | 使问题减半或减为四分之一 |
| **交叉线法**（霍特尔） | 对于长的二维几何体，$F _ { 1 2 } = \dfrac { \sum \text{交叉线} - \sum \text{非交叉线} } { 2 L _ { 1 } }$，其中线绷紧地拉在表面1与表面2的端点之间，$L _ { 1 }$为表面1的宽度 | 无须微积分即可处理任何长管道、槽道或沟槽 |

**关于这个数本身的两个事实。****$F _ { i j }$不是对称的：大而冷的房间中一个小的热零件有$F _ { 1 2 } = 1$，而房间看零件的角系数为$F _ { 2 1 } = A _ { 1 } / A _ { 2 }$，是个很小的数。****对于平面或凸表面$F _ { i i } = 0$，而对于凹表面它可以很大——半球的内表面能看到自身，而一个深空腔向自身辐射，正是这一点使其有效发射率趋近于1。**
:::

::: example 四个你应当能直接写出的角系数 {#ex-four-vf level=2 check="0.38"}
**(a) 两块无限大平行平板：**$F _ { 1 2 } = 1$。**离开一块板的一切都落到另一块上。**
**(b) 同心圆柱或同心球，内表面为1：**$F _ { 1 2 } = 1$，由相对性$F _ { 2 1 } = A _ { 1 } / A _ { 2 } = ( D _ { 1 } / D _ { 2 } ) ^ { 2 }$。**对于套在$0 . 5 \ \mathrm { m }$球内的$0 . 2 \ \mathrm { m }$球，$F _ { 2 1 } = 0 . 1 6$——外球看到的大部分是它自己。**
**(c) 同轴平行等圆盘，半径$r$，间距$L$，$r = L$（输入这个$F _ { 1 2 }$）：**$X = 1 + ( 1 + ( r / L ) ^ { 2 } ) / ( r / L ) ^ { 2 } = 3$，所以

$$F _ { 1 2 } = { \frac { 1 } { 2 } } \left[ X - { \sqrt { X ^ { 2 } - 4 } } \right] = { \frac { 1 } { 2 } } ( 3 - 2 . 2 3 6 ) = \mathbf { 0 . 3 8 }$$

**即使在这样宽松的几何中，离开一个圆盘的辐射也只有$3 8 \ \%$到达另一个——等于半径的间距就已经丢掉了五分之三以上的换热。**
**(d) 正对同轴圆盘的微元面**，圆盘半径$r$，距离$L$，微元面与圆盘平行：$F = r ^ { 2 } / ( r ^ { 2 } + L ^ { 2 } )$，所以当$r = 0 . 5 \ \mathrm { m }$、$L = 1 \ \mathrm { m }$时，$F = 0 . 2 5 / 1 . 2 5 = 0 . 2 0$。**把微元面倾斜$6 0 ^ { \circ }$，对于小圆盘，这个数大约减半（因子$\cos 6 0 ^ { \circ }$）——这就是为什么太阳能集热器要对准太阳。**
:::

::: warning 角系数会咬人的三个地方
**其一——“辐射面积”不是表面积。**一个看不见它本应冷却的冷表面的肋片毫无贡献，这就是为什么航天器辐射器是看向深空的平板，而不是大部分时间互相对看的密集肋片阵列。

**其二——遮热板、挡板或相邻部件是角系数问题，而不是导热问题。**在热元件与冷传感器之间放一块小的抛光板，只要大到足以挡住视线，即使它可以自由导热，也会大幅削减直接换热。**这就是辐射挡板起作用的原因，也是为什么设计挡板的第一步是画视线。**

**其三——如果空间不封闭，完整性规则可能会骗人。**写出$\sum F _ { i j } = 1$要求离开$i$的每一条射线都落到列表中的某个表面上。一个“敞口”的箱子、一个孔，或者一个透过窗户看到天空的表面，都需要把开口当作一个具有天空有效温度的真实表面来处理——在晴朗干燥的夜晚，这个温度比气温**低**$2 0$到$3 0 \ \mathrm { K }$，这就是为什么在晴朗的夜晚，即使气温比冰点高几度也会结霜，也是为什么朝向开阔天空的汽车挡风玻璃最先结冰。
:::

## 5. 黑表面间的辐射换热：空间辐射热阻

::: definition 黑体间的换热与网络思想 {#def-space-resistance}
如果封闭空间中的每个表面都是黑的，那么到达的每条射线都被吸收，其中任意两个表面之间的换热可以直接写出：

$$q _ { i \rightarrow j } = A _ { i } F _ { i j } \, \sigma T _ { i } ^ { 4 } \qquad \Longrightarrow \qquad q _ { 1 2 , \text{net } } = A _ { 1 } F _ { 1 2 } \, \sigma ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) = { \frac { \sigma T _ { 1 } ^ { 4 } - \sigma T _ { 2 } ^ { 4 } } { 1 / ( A _ { 1 } F _ { 1 2 } ) } }$$

**驱动势是黑体辐射力之差$\sigma T ^ { 4 }$，而不是温差**；热阻$1 / ( A _ { 1 } F _ { 1 2 } )$称为**空间辐射热阻**——它是几何的代价，是两个表面不正对彼此的代价，即使两个表面都是完美的黑体，它也依然存在。**两块正对的平行黑色正方形板，边长$1 \ \mathrm { m }$×$1 \ \mathrm { m }$，相距$1 \ \mathrm { m }$（$F _ { 1 2 } = 0 . 2 0$），温度分别为$1 0 0 0$和$5 0 0 \ \mathrm { K }$，其换热量为**

$$q = \sigma ( 1 0 0 0 ^ { 4 } - 5 0 0 ^ { 4 } ) \times 1 \times 0 . 2 0 = 1 0 . 6 \ \mathrm { k W } \qquad \text{而当 } F = 1 \text{（两板非常靠近）时 } q = 5 3 . 2 \ \mathrm { k W }$$

**单是几何就造成五倍之差。****网络法——在节点上取势$\sigma T _ { i } ^ { 4 }$（或有效辐射），在支路上取热阻，在每个节点上应用基尔霍夫电流定律——恰恰就是有效辐射平衡的代数，所以由漫射灰表面组成的封闭空间可以用与电路相同的规则来求解。**
:::

## 6. 灰体封闭空间：两表面公式及其三种极限

::: definition 两个灰表面之间的换热 {#def-grey-two}
对于两个彼此构成封闭空间的不透明灰表面（离开其中一个的每条射线最终都会落到另一个上，可能经过若干次反射），表面辐射热阻$( 1 - \varepsilon ) / ( \varepsilon A )$——即**把辐射送出表面**的代价——与空间辐射热阻串联相加：

$$\boxed { \ q = { \frac { \sigma ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) } { \dfrac { 1 - \varepsilon _ { 1 } } { \varepsilon _ { 1 } A _ { 1 } } + \dfrac { 1 } { A _ { 1 } F _ { 1 2 } } + \dfrac { 1 - \varepsilon _ { 2 } } { \varepsilon _ { 2 } A _ { 2 } } } } \ } \qquad \text{（三个热阻串联）}$$

**三种值得记住的极限：**

| 几何 | $F _ { 1 2 }$ | 结果 |
|:--|:--|:--|
| 两块大平行平板 | 1 | $q = \sigma A ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) / ( 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 )$ |
| 同心圆柱或同心球，内表面为1 | 1 | $q = \sigma A _ { 1 } ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) / [ 1 / \varepsilon _ { 1 } + ( 1 - \varepsilon _ { 2 } ) ( A _ { 1 } / A _ { 2 } ) / \varepsilon _ { 2 } ]$，其中$A _ { 1 } / A _ { 2 } = D _ { 1 } / D _ { 2 }$（圆柱）或$( D _ { 1 } / D _ { 2 } ) ^ { 2 }$（球） |
| 大封闭空间中面积为$A _ { 1 }$的小物体 | 1，且$A _ { 1 } / A _ { 2 } \to 0$ | $q = \varepsilon _ { 1 } \sigma A _ { 1 } ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } )$——**封闭空间的发射率消失了** |

**第三行是你最常用的：房间里的热部件，管道中的热电偶测点，离开炉子的锻件，寒冷大厅中的人。****注意答案中只含$\varepsilon _ { 1 }$——墙壁是抛光金属还是炭黑都毫无区别，因为一个大的封闭空间，不论其表面如何，对其中的小物体而言都表现得像一个黑体空腔。****再注意平行平板分母的形式：两个表面都为$\varepsilon = 0 . 0 5$时它等于$3 9$，所以两个相对的抛光表面之间的换热只有两个黑表面的四十分之一，热阻由表面主导，而不是由间隙主导。**
:::

::: example 双层壁容器：热阻实际在哪里 {#ex-double-wall level=3 check="541"}
一个热的内圆柱，$D _ { 1 } = 0 . 1 \ \mathrm { m }$，$\varepsilon _ { 1 } = 0 . 6$，温度$5 0 0 \ \mathrm { K }$，与外圆柱$D _ { 2 } = 0 . 2 \ \mathrm { m }$，$\varepsilon _ { 2 } = 0 . 8$，温度$3 0 0 \ \mathrm { K }$同心。每米长度上，$A _ { 1 } = \pi D _ { 1 } = 0 . 3 1 4 \ \mathrm { m ^ { 2 } }$，$A _ { 2 } = 0 . 6 2 8 \ \mathrm { m ^ { 2 } }$，$F _ { 1 2 } = 1$。求每米长度的净换热量。（输入W/m。）

$$R _ { 1 } = { \frac { 1 - 0 . 6 } { 0 . 6 \times 0 . 3 1 4 } } = 2 . 1 2 \qquad R _ { \text{空间} } = { \frac { 1 } { 0 . 3 1 4 } } = 3 . 1 8 \qquad R _ { 2 } = { \frac { 1 - 0 . 8 } { 0 . 8 \times 0 . 6 2 8 } } = 0 . 4 0 \qquad \left[ \sum R = 5 . 7 0 \right]$$

$$q = { \frac { 5 . 6 7 \times 1 0 ^ { - 8 } \times ( 6 . 2 5 - 0 . 8 1 ) \times 1 0 ^ { 1 0 } } { 5 . 7 0 } } = \mathbf { 5 4 1 \ W / m }$$

**热阻的分解才是有用的输出：$3 7 \ \%$是内表面自身的表面辐射热阻，$5 6 \ \%$是空间辐射热阻，只有$7 \ \ \%$属于外表面。****所以降低内圆柱的发射率大有帮助，而在这里改变外圆柱的发射率几乎无关紧要。****如果把外圆柱做得大得多，$R _ { 2 }$就缩向零，答案趋于小物体极限$q \rightarrow \varepsilon _ { 1 } \sigma A _ { 1 } ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) = 5 8 1 \ \mathrm { W / m }$——只比目前的答案高$7 \ \ \%$。**
:::

## 7. 遮热板：最便宜的热阻

::: definition 为什么一块薄的、光亮的、不加冷却的薄板作用如此之大 {#def-shield}
在两个表面之间插入一块薄的低发射率遮热板，它会达到一个浮动温度，在该温度下它吸收的等于它发射的——所以它必定**比冷表面热、比热表面冷**，于是每个表面现在都与一个温度已经朝自身温度靠近了一段的邻居换热。**对于两块大平行平板之间一块两面发射率分别为$\varepsilon _ { s , 1 }$和$\varepsilon _ { s , 2 }$的遮热板，**

$$q = { \frac { \sigma ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) } { ( 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 ) + ( 1 / \varepsilon _ { s , 1 } + 1 / \varepsilon _ { s , 2 } - 1 ) } } \qquad \Longrightarrow \qquad q _ { N } = { \frac { q _ { 0 } } { 1 + N ( 2 / \varepsilon _ { s } - 1 ) / ( 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 ) } }$$

**遮热板不花任何代价：它不需要冷却，不需要功率，不需要维护，每平方米只重几克，因为它不是热沉，而是反射体。****问题在于，只有当遮热板与它所隔开的表面热绝缘时，它才起作用——一块与热表面和冷表面接触的遮热板，恰好在你刚买下的那个热阻上提供了一条导热通路。****这就是为什么保温瓶的内胆只在其窄颈处支撑，也是为什么多层隔热材料的各层要用网或纤维纸之类稀疏的低导热间隔物隔开。**
:::

::: example 七层镀铝聚酯薄膜 {#ex-mli level=3 check="0.98"}
一个液氦杜瓦瓶：内容器为$4 . 2 \ \mathrm { K }$，外壳为$3 0 0 \ \mathrm { K }$，两个表面都是$\varepsilon = 0 . 2$。多层隔热材料由$N$层$\varepsilon = 0 . 0 3$的镀铝聚合物薄膜组成，用纤维隔层隔开，处于良好真空中，使气体导热可以忽略。把各层当作大平行平板，求$N = 7$时的辐射热流密度。（输入$\mathrm { W / m ^ { 2 } }$。）

$$q / A = { \frac { \sigma ( 3 0 0 ^ { 4 } - 4 . 2 ^ { 4 } ) } { ( 2 / 0 . 2 - 1 ) + N ( 2 / 0 . 0 3 - 1 ) } } = { \frac { 4 5 9 } { 9 + 6 5 . 7 \, N } } \qquad \Longrightarrow \qquad { \frac { 5 1 . 0 \ \mathrm { W / m ^ { 2 } } } { N = 0 } } \ , \quad { \frac { 6 . 2 } { N = 1 } } \ , \quad \mathbf { 0 . 9 8 } \ \mathbf { W / m ^ { 2 } } \ ( N = 7 ) \ , \quad 0 . 3 5 \ ( N = 2 0 )$$

**从每平方米五十一瓦降到一瓦。****第一层遮热板带来八倍的改善；接下来六层合起来再带来六倍；此后每一层的贡献越来越小，而在实际中，通过间隔物的固体导热和层间接触限制了更多层所能起的作用，这就是为什么实际的多层隔热毯用几十层而不是几百层。****包裹卫星的多层隔热毯，以及装在外墙上散热器背后的反射箔，用的都是同样的算术。**
:::

## 8. 参与性介质：火焰、炉气与大气的作用

::: definition 为什么有些气体辐射而大多数气体不辐射 {#def-gas-radiation}
氮和氧——占干空气的$9 9 \ \%$，也是任何烟气的主体——在任何实际的射线行程下对热辐射都**基本透明**。**原因是量子力学的，没有商量余地：只有当振动改变分子的电偶极矩时，分子才能吸收或发射红外辐射，而同核双原子分子没有可改变的偶极矩。****二氧化碳（其$4 . 3 \ \mu \mathrm { m }$处的不对称伸缩振动和$1 5 \ \mu \mathrm { m }$处的弯曲振动）、水蒸气（$2 . 7$、$6 . 3$以及$1 2 \ \mu \mathrm { m }$以上的振转谱带）、一氧化碳、甲烷、二氧化硫和一氧化二氮都有很强的辐射；炭黑也是如此，它根本不是气体，而是一团发射连续光谱的固体颗粒。****由此得出三个推论，它们决定了一台锅炉是好用还是不好用：**

**其一——气体不像表面那样辐射。**发射和吸收沿射线行程累积，所以相关的量是**光学厚度**；对于平均吸收系数为$\kappa _ { \lambda }$的谱带，

$$I _ { \lambda } ( s ) = I _ { \lambda } ( 0 ) \, e ^ { - \kappa _ { \lambda } \rho s } + I _ { b \lambda } ( T _ { g } ) \left( 1 - e ^ { - \kappa _ { \lambda } \rho s } \right) \qquad \Longrightarrow \qquad \varepsilon _ { g } \approx 1 - e ^ { - \kappa \, p \, L }$$

**分压与射线行程的乘积$p L$是设计变量，这就是为什么在相同温度下大炉子的辐射远强于小炉子，也是为什么火焰的热流密度不仅取决于其温度，还取决于炉膛的尺寸。**

**其二——光谱是线状结构的，所以气体绝对不是灰体**，其发射率必须在气体温度下从线图（霍特尔（Hottel）线图，或莱克纳（Leckner）关联式之类）中读取，然后对总压以及气体在**吸收**来自不同温度壁面的辐射这一事实进行修正：

$$q = \varepsilon _ { w } A _ { w } \, \sigma \left[ \varepsilon _ { g } \, T _ { g } ^ { 4 } - \alpha _ { g } \, T _ { w } ^ { 4 } \right] \ , \qquad \alpha _ { g } = C \left( { \frac { T _ { g } } { T _ { w } } } \right) ^ { n } \varepsilon _ { g } \! \left( T _ { w } , \ p L { \frac { T _ { w } } { T _ { g } } } \right)$$

**其中对$\mathrm { C O } _ { 2 }$取$n \approx 0 . 6 5$，对$\mathrm { H } _ { 2 } \mathrm { O }$取$n \approx 0 . 4 5$，在大气压下$C = 1$（因子$\varepsilon _ { w }$是对灰壁面的简单近似；对黑壁面它等于$1$）。由于$\alpha _ { g }$是针对来自较冷壁面的辐射计算的，当$T _ { g } > T _ { w }$时它通常大于$\varepsilon _ { g }$——基尔霍夫定律是逐谱带满足的，而不是在这些总量上满足的。**

**其三——平均射线程长**$L _ { e }$**取代不规则容积中的真实行程：对于由其边界所包围的气体容积，$L _ { e } = 3 . 6 \, V / A$；对于大平行表面之间的气体，取相关尺寸的$0 . 9$倍。****它是一种近似（霍特尔的系数$3 . 6$常被减小到约$3 . 5$以符合典型的气体发射率），而它正是炉子设计者既关心炉膛温度、也关心炉膛尺寸的原因。**
:::

::: example 炉壁：气体辐射与气体对流的较量 {#ex-furnace level=3 check="68"}
一台$3 \times 3 \times 6 \ \mathrm { m }$的炉子燃烧时含$12 \ \ \% \ \mathrm { C O } _ { 2 }$和$12 \ \ \% \ \mathrm { H } _ { 2 } \mathrm { O }$，温度$1 5 0 0 \ \mathrm { K }$，压强$1 \ \mathrm { atm }$；水冷壁管温度为$8 0 0 \ \mathrm { K }$，$\varepsilon _ { w } = 0 . 8$。估算到壁面的辐射热流密度。（输入$\mathrm { k W / m ^ { 2 } }$。）

$$V = 5 4 \ \mathrm { m ^ { 3 } } \ , \ A = 9 0 \ \mathrm { m ^ { 2 } } \ , \qquad L _ { e } = 3 . 6 \times { \frac { 5 4 } { 9 0 } } = 2 . 1 6 \ \mathrm { m } \qquad p _ { c } L _ { e } = p _ { w } L _ { e } = 0 . 1 2 \times 2 . 1 6 = 0 . 2 6 \ \mathrm { atm \, m }$$

**作为近似的线图读数，取$1 5 0 0 \ \mathrm { K }$下气体发射率$\varepsilon _ { g } \approx 0 . 3 3$（二氧化碳与水蒸气合计，减去重叠修正），以及经过$( T _ { g } / T _ { w } ) ^ { n }$修正后对壁面辐射的吸收比$\alpha _ { g } \approx 0 . 4 2$。于是**

$$q = 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } \left[ 0 . 3 3 \times 1 5 0 0 ^ { 4 } - 0 . 4 2 \times 8 0 0 ^ { 4 } \right] = 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } \times \left[ 1 . 6 7 \times 1 0 ^ { 1 2 } - 1 . 7 2 \times 1 0 ^ { 1 1 } \right] = \mathbf { 6 8 \ k W / m ^ { 2 } }$$

**相比之下，辐射室中缓慢流动的气体的对流贡献只有约$h \Delta T \approx 2 0 \times 7 0 0 = 1 4 \ \mathrm { k W / m ^ { 2 } }$。****辐射是较大的一项，大五倍，而这完全归功于各占百分之十二的二氧化碳和水蒸气——构成气体主体的氮和氧基本上毫无贡献。****现在让火焰因炭黑而发光：充满这样大小炉膛的浓烟火焰，其发射率可接近约$0 . 8$，把它当作灰体（$\varepsilon _ { g } = \alpha _ { g } = 0 . 8$），同一台炉子的辐射为**

$$q = 0 . 8 \times 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } \times ( 1 5 0 0 ^ { 4 } - 8 0 0 ^ { 4 } ) \approx \mathbf { 1 7 0 \ k W / m ^ { 2 } }$$

**是前者的两倍半。****这就是为什么发光的油火焰和煤火焰的辐射传热远强于近乎透明的天然气火焰，也是为什么“火焰看起来一样”不能算是传热学的回答。**
:::

::: warning 大气是一种参与性介质，这不是比喻
**干空气在$8$到$1 3 \ \mu \mathrm { m }$波段几乎透明，而$3 0 0 \ \mathrm { K }$的表面有$3 2 \ \ \%$的发射落在这个窗口中——这就是为什么向夜空的辐射冷却行之有效，为什么在晴朗干燥的夜晚，充分暴露的轻质表面可以比气温低好几开尔文，为什么露和霜首先在这样的表面上形成，也是为什么每一项航天器热设计都是太阳、地球红外辐射与$2 . 7 \ \mathrm { K }$的深空之间的一场较量。****水蒸气和二氧化碳封住了光谱的其余部分：水平表面向晴朗冬季天空辐射时的“天空有效温度”通常比环境空气低$2 0$到$3 0 \ \mathrm { K }$，而在潮湿的阴天只低几开尔文——这恰恰就是大气的温室效应，与上面的炉气是同样的逐谱带物理，只是运行在$2 5 5 \ \mathrm { K }$而不是$1 5 0 0 \ \mathrm { K }$。****对这一机理的诚实表述很简短：大气对太阳$0 . 5 \ \mu \mathrm { m }$的辐射部分透明，对地球$1 1 \ \mu \mathrm { m }$的辐射部分不透明，所以加入一种红外活性气体会抬高行星向太空辐射的高度，而由于温度随高度降低，地表必须升温，直到逸出的热流恢复为止。****这句话中的每一项，都与决定太阳能集热器性能的那套光谱记账相同。**
:::

## 9. 辐射与对流并存：你图纸上真正存在的两个问题

::: example 读数偏低九十开尔文的热电偶 {#ex-tc-duct level=4 check="410"}
一支裸露的、无遮热罩的热电偶，$\varepsilon = 0 . 8$，测量管道中$5 0 0 \ \mathrm { {} ^ { \circ } C }$ $( 7 7 3 \ \mathrm { K } )$的气体，管壁温度为$1 0 0 \ \mathrm { {} ^ { \circ } C }$ $( 3 7 3 \ \mathrm { K } )$。测点很小，所以它看壁面的角系数为$F = 1$，气体以$h = 1 0 0 \ \mathrm { W / m ^ { 2 } K }$对流。忽略沿导线的导热，在稳态下，以对流到达的热量以辐射离开。求指示温度。（输入$^ { \circ } \mathrm { C }$。）

$$h ( T _ { g } - T _ { j } ) = \varepsilon \sigma ( T _ { j } ^ { 4 } - T _ { w } ^ { 4 } ) \qquad 1 0 0 ( 7 7 3 - T _ { j } ) = 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } ( T _ { j } ^ { 4 } - 3 7 3 ^ { 4 } )$$

**解得**$T _ { j } = 6 8 3 \ \mathrm { K } = \mathbf { 4 1 0 \ {} ^ { \circ } C }$，**误差为$9 0 \ \mathrm { K }$，其方向会让你以为过程运行得偏冷。****这一误差的变化规律与所有辐射误差相同：**

| $h \ ( \mathrm { W / m ^ { 2 } K } )$ | 5 | 20 | 50 | 100 | 300 |
|:--|--:|--:|--:|--:|--:|
| 指示温度 | $2 0 4 \ \mathrm { {} ^ { \circ } C }$ | $3 0 0 \ \mathrm { {} ^ { \circ } C }$ | $3 6 6 \ \mathrm { {} ^ { \circ } C }$ | $4 1 0 \ \mathrm { {} ^ { \circ } C }$ | $4 5 9 \ \mathrm { {} ^ { \circ } C }$ |
| 误差 | $2 9 6 \ \mathrm { K }$ | $2 0 0 \ \mathrm { K }$ | $1 3 4 \ \mathrm { K }$ | $9 0 \ \mathrm { K }$ | $4 1 \ \mathrm { K }$ |

**恰好有两种对策，它们就是方程中的两根杠杆。****提高$h$：抽气式高温计以高速把气体抽过测点，表中显示了误差随$h$下降得有多快。****或者减少与冷壁面的辐射换热：在每块遮热罩只是把测点的有效发射率除以$N + 1$的粗略模型中，一块遮热罩把误差从$9 0$降到$5 6 \ \mathrm { K }$，三块降到$3 2 \ \mathrm { K }$，五块降到$2 3 \ \mathrm { K }$。****在这个模型中，一块遮热罩的作用恰好等于把$h$加倍，三块遮热罩等于把它增至四倍——这就是为什么两者兼施的抽气式高温计（带遮热罩的测点，气体从遮热罩中抽过）是测量炉气温度的标准仪器。**
:::

::: example 窗户中的空气层，以及窗后的散热器 {#ex-window-gap level=3 check="6.2"}
一个$1 5 \ \mathrm { mm }$的静止空气腔，两侧表面温度分别为$2 9 3$和$2 8 3 \ \mathrm { K }$，均为$\varepsilon = 0 . 9$。求空腔的总热导，即导热加上在$T _ { m } = 2 8 8 \ \mathrm { K }$下线性化的辐射。（以$\mathrm { W / m ^ { 2 } K }$为单位输入。）**穿过空气层的导热（在这一温差下，空气层太窄，不发生对流）：**

$$h _ { \text{cond } } = { \frac { k } { L } } = { \frac { 0 . 0 2 6 } { 0 . 0 1 5 } } = 1 . 7 3 \ \mathrm { W / m ^ { 2 } K } \qquad h _ { r } = 4 \varepsilon _ { \text{eff } } \sigma T _ { m } ^ { 3 } = { \frac { 4 \sigma T _ { m } ^ { 3 } } { 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 } } = { \frac { 5 . 4 2 } { 1 . 2 2 } } = 4 . 4 \ \mathrm { W / m ^ { 2 } K }$$

**在设计者心目中其职责是导热的空气层里，辐射携带了将近四分之三的热量；空腔的总热导为$1 . 7 3 + 4 . 4 3 = \mathbf { 6 . 2 \ W / m ^ { 2 } K }$，热阻为$0 . 1 6 \ \mathrm { m ^ { 2 } K / W }$，与建筑标准中对$1 5 \ \mathrm { mm }$无通风空气层列出的$0 . 1 7$相近。****现在给一个表面镀上低辐射膜，$\varepsilon = 0 . 0 5$：分母变为$1 / 0 . 9 + 1 / 0 . 0 5 - 1 = 2 0 . 1$，$h _ { r }$降到$0 . 2 7$，空腔热导降到$2 . 0 \ \mathrm { W / m ^ { 2 } K }$——降为三分之一，而涂层并不增加任何厚度。****再把空气层抽成真空，就只剩固体支撑物导热——这就是真空玻璃和真空绝热板的原理，其芯材导热系数只有千分之几$\mathrm { W / m \, K }$：阻断气体，并使表面光亮。****家用散热器也是同样的算术：板式散热器有相当大一部分输出靠辐射，用任何普通油漆重新涂刷它都改变不大，因为它已经是$\varepsilon \approx 0 . 9$；而装在外墙上、位于散热器背后的反射箔，是靠降低散热器背面所对墙面的发射率起作用的——与低辐射窗是同一个把戏。**
:::

一根直径$8 0 \ \mathrm { m m }$、长$3 \ \mathrm { m }$、温度$4 5 0 \ \mathrm { K }$的蒸汽管道，$\varepsilon = 0 . 9$，穿过一个墙壁温度为$2 9 3 \ \mathrm { K }$的车间。求辐射散热量。（输入W。）

$$q = 0 . 9 \times 5 . 6 7 \times 1 0 ^ { - 8 } \times 0 . 7 5 4 \times ( 4 . 1 0 \times 1 0 ^ { 1 0 } - 7 . 3 7 \times 1 0 ^ { 9 } ) = \mathbf { 1 2 9 4 \ W }$$
**用$\varepsilon = 0 . 0 5$的抛光铝包住它，辐射散热量就降到$7 2 \ \mathrm { W }$——降为十八分之一（铝箔表面的温度也会略低一些，但对流在性质上不变）。****这一好处只在铝箔保持光亮时才能维持：脏污、氧化的铝会升向$\varepsilon \approx 0 . 3$，大部分收益就丧失了。**

::: exercise 是谁在使人变冷？ {#ex-human level=2 check="81"}
一个站立的人，着装后的表面积为$1 . 8 \ \mathrm { m ^ { 2 } }$，温度为$2 8 \ \mathrm { {} ^ { \circ } C }$，发射率为$0 . 9 5$。求其向一个所有表面都为$2 0 \ \mathrm { {} ^ { \circ } C }$的房间的辐射散热量。（输入W。）
::: solution
$$q = 0 . 9 5 \times 5 . 6 7 \times 1 0 ^ { - 8 } \times 1 . 8 \times ( 3 0 1 ^ { 4 } - 2 9 3 ^ { 4 } ) = \mathbf { 8 1 \ W }$$
**静息的成年人大约产生$1 0 0 \ \mathrm { W }$的代谢热，所以辐射在干性散热中占很大一部分——而且它取决的不是空气温度，而是周围表面的温度。****把平均表面温度降到$1 5 \ \ {} ^ { \circ } \mathrm { C }$，就像寒冷夜晚靠近单层玻璃窗时那样，辐射散热量就升到$1 2 9 \ \mathrm { W }$，身体必须额外补充$4 8 \ \mathrm { W }$。****这就是为什么即使空气温暖，墙壁冰冷的房间也让人觉得冷，也是为什么舒适性标准采用对空气温度和周围表面温度取平均的操作温度。**

::: exercise 立方体的各个面 {#ex-viewfactor level=2 check="0.2"}
一个边长为$L$的封闭立方体箱子。求从一个面到其对面的角系数，以及从同一个面到四个相邻面之一的角系数。（输入$F _ { \text{对面} }$。）
::: solution
**由于绕通过底面的轴线的四重对称性，四个侧面是等价的，所以对底面应用完整性得到**
$$F _ { \text{对面} } + 4 F _ { \text{邻面} } = 1$$
**一个查表或计算得到的值就确定了另一个。标准的平行等正方形结果给出**
$$F _ { \text{对面} } = \mathbf { 0 . 2 0 } \qquad \Longrightarrow \qquad F _ { \text{邻面} } = ( 1 - 0 . 2 0 ) / 4 = 0 . 2 0$$
**而共用一条边的两个垂直正方形的表列值为$0 . 2 0 0 0$，二者一致；对面的值$0 . 1 9 9 8$与它只在小数点后第四位上不同——这对立方体而言是数值上的巧合，而不是定理。****两个交叉校核：半径为$L / 2$、间距为$L$的同轴圆盘公式给出$F = 0 . 1 7 2$——更小，这是必然的，因为内切圆盘比正方形小；底面中心处的微元面看顶面的角系数为$0 . 2 3 9$，大于面平均值$0 . 2 0$，因为中心是底面上位置最好的点，而靠近棱边和角隅的微元看到的更少。****这就是实际要点：装在炉底某一点上的探测器看到的并不是面平均角系数，而用面平均值代替局部值的投入辐射计算在棱边和角隅附近可能偏差很大。**
:::

::: exercise 遮热板放在哪里 {#ex-shield level=3 check="676"}
两块大平行平板，温度分别为$8 0 0$和$3 0 0 \ \mathrm { K }$，$\varepsilon _ { 1 } = \varepsilon _ { 2 } = 0 . 5$。在它们之间放一块两面均为$\varepsilon _ { s } = 0 . 0 5$的抛光遮热板。求遮热板的平衡温度。（输入K。）
::: solution
**遮热板是一个浮动节点：它在一面吸收的，就从另一面发射出去，而由于电路两半的热阻相同，**
$$\sigma T _ { s } ^ { 4 } = { \frac { \sigma T _ { 1 } ^ { 4 } + \sigma T _ { 2 } ^ { 4 } } { 2 } } \qquad \Longrightarrow \qquad T _ { s } = \left( { \frac { 8 0 0 ^ { 4 } + 3 0 0 ^ { 4 } } { 2 } } \right) ^ { 1 / 4 } = \mathbf { 6 7 6 \ K } \ ( 4 0 3 \ \mathrm { {} ^ { \circ } C } )$$
**注意遮热板的温度离热板比离冷板近得多——四次方意味着$\sigma T ^ { 4 }$的中点不是$T$的中点。****热流密度为$q = \sigma ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) / [ ( 2 + 2 - 1 ) + ( 2 0 + 2 0 - 1 ) ] = 2 2 \, 7 6 5 / 4 2 = 5 4 2 \ \mathrm { W / m ^ { 2 } }$，而无遮热板时为$7 5 8 8 \ \mathrm { W / m ^ { 2 } }$，降为十四分之一。****如果把遮热板从中间平面移向热板，热流密度完全不变——对于大平行平板，遮热板的位置无关紧要；要紧的只有它的发射率和遮热板的块数。**
:::

::: exercise 炉子中的热电偶 {#ex-thermocouple level=3 check="451"}
一支裸露的热电偶，$\varepsilon = 0 . 8$，位于一个气体温度为$6 0 0 \ \mathrm { {} ^ { \circ } C }$、壁温为$5 0 \ \mathrm { {} ^ { \circ } C }$的管道中。当$h = 8 0 \ \mathrm { W / m ^ { 2 } K }$时，它的读数是多少？（输入$^ { \circ } \mathrm { C }$。）
::: solution
$$8 0 ( 8 7 3 - T _ { j } ) = 0 . 8 \times 5 . 6 7 \times 1 0 ^ { - 8 } ( T _ { j } ^ { 4 } - 3 2 3 ^ { 4 } ) \qquad \Longrightarrow \qquad T _ { j } = 7 2 4 \ \mathrm { K } = \mathbf { 4 5 1 \ {} ^ { \circ } C }$$
**误差为$1 4 9 \ \mathrm { K }$，而且这是一个任何校准都消除不了的系统误差，因为它取决于设备的壁温和气体流速，而不取决于仪表。****把气体流速加倍（$h$大致按$G ^ { 0 . 6 }$增大，所以约为$\times 1 . 5$）只能把误差降到$1 1 8 \ \mathrm { K }$；按例题中的粗略模型，三块遮热罩把它降到约$6 0 \ \mathrm { K }$；两者兼施的抽气式高温计效果更好。****这一教训适用于高温设备中的每一次温度测量：显示屏上的数字是一个你没有看到的能量平衡的解，首先要问的是传感器能看到什么。**

::: exercise 失去了炭黑的炉子 {#ex-gas level=4 check="0.32"}
$1 4 0 0 \ \mathrm { K }$、$1 \ \mathrm { atm }$的炉气含$1 1 \ \ \% \ \mathrm { C O } _ { 2 }$和$1 1 \ \ \% \ \mathrm { H } _ { 2 } \mathrm { O }$，充满一个容积为$4 0 \ \mathrm { m ^ { 3 } }$、表面积为$8 0 \ \mathrm { m ^ { 2 } }$的炉膛。已知在相应的$p L$下近似的线图读数为$\varepsilon _ { c } \approx 0 . 1 4$和$\varepsilon _ { w } \approx 0 . 1 9$，重叠修正为$\Delta \varepsilon \approx 0 . 0 1$，估算壁面所见的气体发射率。（输入$\varepsilon _ { g }$。）
::: solution
$$L _ { e } = 3 . 6 \times { \frac { 4 0 } { 8 0 } } = 1 . 8 \ \mathrm { m } \qquad p _ { c } L _ { e } = p _ { w } L _ { e } = 0 . 1 1 \times 1 . 8 = 0 . 2 0 \ \mathrm { atm \, m }$$
**由$T _ { g } = 1 4 0 0 \ \mathrm { K }$下的线图：$\varepsilon _ { c } \approx 0 . 1 4$，$\varepsilon _ { w } \approx 0 . 1 9$，$\Delta \approx 0 . 0 1$，所以$\varepsilon _ { g } = 0 . 1 4 + 0 . 1 9 - 0 . 0 1 = \mathbf { 0 . 3 2 }$。****现在在相同温度下把炉膛的每一个线性尺寸减半：$V / A$、$L _ { e }$和$p L$都减半，线图给出的发射率明显较低——气体发射率随$p L$增长得很慢，在这一范围内大致呈对数关系，所以损失只是其中一部分，而不是一半。****这一点具有普遍性：在相同的气体温度和成分下，小燃烧室的辐射效能不如大燃烧室，这就是小型试验台不能复现全尺寸炉子辐射传热的原因之一。**

::: exercise 两块玻璃，一层涂层 {#ex-window level=2 check="2.7"}
两块大的平行玻璃板，温度分别为$2 8 3$和$2 9 3 \ \mathrm { K }$，彼此相对。求两者都为$\varepsilon = 0 . 8 4$时以及其中一块镀膜至$\varepsilon = 0 . 0 5$时的辐射热流密度。（以$\mathrm { W / m ^ { 2 } }$为单位输入镀膜时的值。）
::: solution
$$q _ { \text{未镀膜} } = { \frac { 5 . 6 7 \times 1 0 ^ { - 8 } ( 2 9 3 ^ { 4 } - 2 8 3 ^ { 4 } ) } { 1 / 0 . 8 4 + 1 / 0 . 8 4 - 1 } } = { \frac { 5 4 . 2 } { 1 . 3 8 } } = 3 9 \ \mathrm { W / m ^ { 2 } } \qquad q _ { \text{镀膜} } = { \frac { 5 4 . 2 } { 1 / 0 . 8 4 + 1 / 0 . 0 5 - 1 } } = { \frac { 5 4 . 2 } { 2 0 . 2 } } = \mathbf { 2 . 7 \ W / m ^ { 2 } }$$
**降为十四分之一，来自一层远薄于一微米的透明涂层。****注意镀膜情形并不是$q _ { \text{未镀膜} } / 1 7$，尽管发射率下降为十七分之一：分母是$1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1$，一旦有一个表面是光亮的，它就占主导——镀膜面贡献$1 / 0 . 0 5 = 2 0$，未镀膜面只贡献$1 / 0 . 8 4 - 1 = 0 . 1 9$。****这就是“一个好表面就够了”的规则：再给第二个面镀膜，也只能把分母从$2 0 . 2$提高到$3 9$，这就是为什么低辐射中空玻璃单元通常只有一个镀膜面。**

::: exercise 带两种涂层的航天器面板 {#ex-spacecraft level=4 check="331"}
卫星上一块水平放置的$1 \ \mathrm { m ^ { 2 } }$面板，在$1 \ \mathrm { AU }$处的阳光下正对太阳，并从两面向深空辐射。忽略地球反照和红外辐射。若朝向太阳的涂层$\alpha _ { s } = 0 . 9 0$，$\varepsilon = 0 . 9 0$，背面$\varepsilon = 0 . 9 0$，并忽略内部耗散，求平衡温度。（输入K。）

$$0 . 9 0 \times 1 3 6 1 = 2 \times 0 . 9 0 \times 5 . 6 7 \times 1 0 ^ { - 8 } \, T ^ { 4 } \qquad \Longrightarrow \qquad T = \left( { \frac { 1 2 2 5 } { 1 . 0 2 \times 1 0 ^ { - 7 } } } \right) ^ { 1 / 4 } = \mathbf { 3 3 1 \ K } \ ( 5 8 \ \mathrm { {} ^ { \circ } C } )$$
**把正面涂层换成光学太阳反射镜$( \alpha _ { s } = 0 . 2 0$，$\varepsilon = 0 . 8 5 )$，同一块面板就运行在$2 3 1 \ \mathrm { K }$，冷了一百开尔文，无须功率，没有运动部件，也无须维护。****注意答案与什么无关：面板的质量、导热系数、厚度，以及它后面有什么——这些决定的是瞬态过程和温度的均匀性，而不是平衡温度。****再注意设计中的陷阱：在实验室里是白色的涂层对太阳而言不一定是白的，因为$\alpha _ { s }$以太阳光谱为权，而$\varepsilon$以面板自身$2 8 0 \ \mathrm { K }$的发射为权；而且轨道上的紫外辐射和粒子辐射会在任务期间使$\alpha _ { s }$升高（对许多白漆而言升高百分之几或更多），这就是为什么航天器热设计要同时按寿命初期和寿命末期的性质进行校核。**

::: proof 由网络导出两表面灰体公式 {#proof-network}
对于只看到彼此的两个漫射灰表面，导出$q = \sigma ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } ) / [ ( 1 - \varepsilon _ { 1 } ) / ( \varepsilon _ { 1 } A _ { 1 } ) + 1 / ( A _ { 1 } F _ { 1 2 } ) + ( 1 - \varepsilon _ { 2 } ) / ( \varepsilon _ { 2 } A _ { 2 } ) ]$，并证明它可以化为本讲所引的平行平板、同心圆柱和小物体极限。
::: solution
**在每个表面上，有效辐射平衡$J = \varepsilon \sigma T ^ { 4 } + ( 1 - \varepsilon ) G$可以利用$q _ { i } = A _ { i } ( J _ { i } - G _ { i } )$改写成黑体势与有效辐射节点之间的欧姆定律形式：**
$$q _ { i } = { \frac { \sigma T _ { i } ^ { 4 } - J _ { i } } { ( 1 - \varepsilon _ { i } ) / ( \varepsilon _ { i } A _ { i } ) } }$$
**而离开表面1并到达表面2的辐射减去离开表面2并到达表面1的辐射，给出**
$$q = A _ { 1 } F _ { 1 2 } J _ { 1 } - A _ { 2 } F _ { 2 1 } J _ { 2 } = { \frac { J _ { 1 } - J _ { 2 } } { 1 / ( A _ { 1 } F _ { 1 2 } ) } } \ , \qquad \text{利用相对性 } A _ { 1 } F _ { 1 2 } = A _ { 2 } F _ { 2 1 }$$
**把三个“电压降”相加，并令总和等于$\sigma T _ { 1 } ^ { 4 } - \sigma T _ { 2 } ^ { 4 }$，就得到该公式。三种极限随后只是算术：平行平板有$A _ { 1 } = A _ { 2 }$，所以分母变为$( 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 ) / A$；同心圆柱和同心球分别有$A _ { 1 } F _ { 1 2 } = A _ { 1 }$以及$A _ { 2 } = A _ { 1 } ( D _ { 2 } / D _ { 1 } )$或$A _ { 1 } ( D _ { 2 } / D _ { 1 } ) ^ { 2 }$，从而在外表面项上出现因子$A _ { 1 } / A _ { 2 }$；而$A _ { 1 } / A _ { 2 } \rightarrow 0$使最后一项完全消失，剩下$q = \varepsilon _ { 1 } \sigma A _ { 1 } ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } )$。****推导使一个注意事项变得显而易见，而公式本身却不会显示它：结果假定每个表面都是均匀等温的，并且发射率均匀。两块温度均匀但不同、由导热壁相连的板，或者一个部分镀膜的表面，需要多节点网络——同样的三个热阻在面积上复制若干份，再作为电路求解，这正是辐射换热计算程序所做的。**
:::

::: proof 基尔霍夫定律，以及为什么$\alpha$不必等于$\varepsilon$ {#proof-kirchhoff}
由热力学第二定律证明在给定波长和方向上$\varepsilon _ { \lambda } = \alpha _ { \lambda }$，然后构造使选择性表面成为可能的反例。
::: solution

**把一个面积为$A$、光谱定向吸收比为$\alpha _ { \lambda }$、发射率为$\varepsilon _ { \lambda }$的物体放进一个同样处于温度$T$的等温空腔中。空腔以黑体辐射$E _ { b \lambda } ( T )$照射它，在波长$\lambda$处的净换热为**
$$q _ { \lambda } = A \, \alpha _ { \lambda } \, E _ { b \lambda } ( T ) \, d \lambda - A \, \varepsilon _ { \lambda } \, E _ { b \lambda } ( T ) \, d \lambda$$
**如果$\alpha _ { \lambda } > \varepsilon _ { \lambda }$，物体在这一个波段中吸收多于发射，而其他一切都处于同一温度，它就会自发升温——这是第二类永动机，因为多出的部分可以由一台运行在该物体与其所在空腔之间的可逆热机作为功提取出来。****反方向的不等式同样被禁止，所以$\alpha _ { \lambda } = \varepsilon _ { \lambda }$；而由于这一论证分别适用于每一个波长和每一个方向，这个等式是光谱的、定向的等式。****反例现在是现成的：全波长吸收比为$\alpha = \int \alpha _ { \lambda } G _ { \lambda } d \lambda / G$，全波长发射率为$\varepsilon = \int \varepsilon _ { \lambda } E _ { b \lambda } ( T _ { s } ) d \lambda / \sigma T _ { s } ^ { 4 }$，而这两个积分以不同的函数为权。****取$\lambda < 3 \ \mu \mathrm { m }$时$\alpha _ { \lambda } = \varepsilon _ { \lambda } = 0 . 9 5$，超出此范围为$0 . 1 0$，这个表面在每一个波长上都完全遵守基尔霍夫定律。在$5 8 0 0 \ \mathrm { K }$的光源照射下（其能量约有$9 8 \ \ \%$位于$3 \ \mu \mathrm { m }$以下），它有$\alpha \approx 0 . 9 3$；在$3 5 0 \ \mathrm { K }$下发射时（此时其发射基本上全部位于$3 \ \mu \mathrm { m }$以上），它有$\varepsilon \approx 0 . 1 0$。****两个数相差九倍，却没有违反任何定律——这就是选择性太阳能吸收表面和低辐射玻璃的物理。**
:::

::: quiz 散热器的神话 {#quiz-myth}
两个相同房间中的两台相同散热器涂着同一种耐高温瓷漆，一台黑色，一台白色。哪一台向房间散热更多？
- [ ] 黑色的，因为它是更好的发射体
- [x] 两者相同，因为两者在热红外区都有$\varepsilon \approx 0 . 9$
- [ ] 白色的，因为它反射
- [ ] 两者都不——油漆对传热毫无影响

::: solution
**两者相同。****油漆是分散在黏结剂中的介电颜料膜，在$6 0 \ \mathrm { {} ^ { \circ } C }$的散热器发射所在的$1 0 \ \mu \mathrm { m }$波长上，两者基本上都是黑的：白漆$\varepsilon \approx 0 . 9 2$，黑漆$0 . 9 6$，发射率相差百分之几，你感觉不到任何区别。****这个神话之所以流传，是因为它混淆了可见光和红外：在太阳光谱中，白色和黑色的吸收比相差五倍，这就是为什么黑色车顶比白色车顶热——但散热器并没有被太阳照射，它是在自身温度下发射。****真正成立的推论是：给裸露的抛光金属散热器涂上任何油漆，都会大幅提高其散热量，因为你把$\varepsilon$从约$0 . 0 5$变成了$0 . 9$，而颜色无关紧要。**
:::

::: quiz 误差在哪里 {#quiz-error}
管道中的一支热电偶读数比真实气体温度低$8 0 \ \mathrm { K }$。把以下哪一项加倍最能减小误差？
- [ ] 热电偶丝的直径
- [x] 流过测点的气体流速
- [ ] 管道壁厚
- [ ] 热电偶套管的长度

::: solution
**把流速加倍会提高$h$（大致按$G ^ { 0 . 6 }$，所以约为$1 . 5 \times$），而由于误差近似为$h _ { r } ( T _ { j } - T _ { w } ) / h$，它会下降约四分之一到三分之一——在管道例题中从$9 0$降到$6 9 \ \mathrm { K }$。****导线直径和套管长度改变的是响应时间以及沿套管的导热误差，而不是辐射误差——混淆这两种误差机理是典型的错误。****在实践中最好的答案是抽气式高温计，它同时提高流速并遮蔽测点。**

| 1900 | **普朗克（Max Planck）**于10月提出他的辐射公式，并于12月14日给出由能量限于$h \nu$整数倍的振子所作的推导——这是量子理论的开端。$\sigma$、$C _ { 1 }$和$C _ { 2 }$成为$h$、$c$和$k$的组合。 |

::: summary
- **热辐射是电磁辐射，不需要介质，沿直线传播，并按$T ^ { 4 }$变化。**$q = \varepsilon \sigma A ( T _ { s } ^ { 4 } - T _ { \text{sur } } ^ { 4 } )$；周围环境是一个有自身温度的**表面**，而不是空气温度。
- **三条黑体定律：**普朗克定律给出光谱，维恩定律$\lambda _ { \max } T = 2 8 9 8 \ \mu \mathrm { m \, K }$给出它在哪里，斯特藩-玻尔兹曼定律$E _ { b } = \sigma T ^ { 4 }$给出有多少。**由$\lambda T$表查出的波段份额决定什么是要紧的：**太阳的辐射有$4 3 \ \%$是可见光，$9 9 \ \%$位于$4 \ \mu \mathrm { m }$以下；$3 0 0 \ \mathrm { K }$的表面基本上$1 0 0 \ \%$位于$4 \ \mu \mathrm { m }$以上。
- **基尔霍夫定律是光谱的、定向的：$\alpha _ { \lambda } = \varepsilon _ { \lambda }$。**只要辐射源与表面处于不同温度，全波长$\alpha$与全波长$\varepsilon$就不同——正是这一点使选择性表面、低辐射玻璃、太阳能热发电和温室效应成为可能。
- **抛光金属：$\varepsilon \sim 0 . 0 2$到$0 . 1$，随温度升高。非金属、氧化物、油漆、皮肤、水：$0 . 8$到$0 . 9 8$，白漆在红外区是黑的。**发射率是一种表面**状况**，而不是材料常数。
- **角系数由相对性、完整性、对称性和交叉线法求得。**$A _ { i } F _ { i j } = A _ { j } F _ { j i }$；在封闭空间上$\sum _ { j } F _ { i j } = 1$；凸表面看不到自身的任何部分。
- **网络法：势$\sigma T ^ { 4 }$，表面辐射热阻$( 1 - \varepsilon ) / ( \varepsilon A )$，空间辐射热阻$1 / ( A _ { 1 } F _ { 1 2 } )$。**三种极限：平行平板、同心圆柱，以及——你最常用的——大封闭空间中的小物体，$q = \varepsilon _ { 1 } \sigma A _ { 1 } ( T _ { 1 } ^ { 4 } - T _ { 2 } ^ { 4 } )$，其中封闭空间的发射率完全消失。
- **遮热板成倍增加热阻，而且不花任何代价。**$N$块低$\varepsilon$遮热板使热流密度大致降为原来的$1 / ( 1 + N ( 2 / \varepsilon _ { s } - 1 ) / ( 1 / \varepsilon _ { 1 } + 1 / \varepsilon _ { 2 } - 1 ) )$；它们必须热绝缘并保持清洁，而它们在两个灰表面之间的位置无关紧要。
- **只有当分子具有可振动的偶极矩时气体才辐射：**$\mathrm { C O } _ { 2 }$、$\mathrm { H } _ { 2 } \mathrm { O }$、$\mathrm { C H } _ { 4 }$、CO、$\mathrm { S O } _ { 2 }$和炭黑辐射；$\mathrm { N } _ { 2 }$和$\mathrm { O } _ { 2 }$不辐射。发射率取决于$p L$和平均射线程长$L _ { e } \approx 3 . 6 V / A$，当气体比壁面热时，通常$\alpha _ { g } > \varepsilon _ { g }$。
- **线性化只用于思考，绝不用于设计计算：**在$3 0 0$、$5 0 0$、$8 0 0$、$1 0 0 0$、$1 5 0 0 \ \mathrm { K }$时，$h _ { r } = 4 \varepsilon \sigma T _ { m } ^ { 3 } = 4 . 9$、$2 3$、$9 3$、$1 8 1$、$6 1 2 \ \mathrm { W / m ^ { 2 } K }$。**在室温附近辐射与自然对流相当，在约$8 0 0 \ \mathrm { K }$以上通常是主导项。**
- **本讲要解决的两个问题：**一个热物体散失多少热量（辐射加对流，辐射由周围表面决定），以及如何阻止它（抽走气体，使表面光亮，插入浮动的遮热板）——在保温瓶、航天器隔热毯和中空玻璃单元中，用的是同样的杠杆。

## 延伸阅读

- **M. F. Modest & S. Mazumder**，*Radiative Heat Transfer*，第4版（Academic Press，2021）——参与性介质和辐射传递方程的参考书；当网络法不再适用时，你需要的就是这本书。
- **J. R. Howell, M. P. Mengüç & R. Siegel**，*Thermal Radiation Heat Transfer*，第6版（CRC Press，2016）——角系数、封闭空间分析，以及灰体与非灰体的处理方法。
- **H. C. Hottel & A. F. Sarofim**，*Radiative Transfer*（McGraw-Hill，1967）——由气体发射率线图和交叉线法的创始人撰写的炉内辐射与气体辐射。
- **J. R. Howell**，*A Catalog of Radiation Heat Transfer Configuration Factors*（在线，University of Texas at Austin）——数百种几何形状的封闭形式角系数。
- **F. P. Incropera, D. P. DeWitt, T. L. Bergman & A. S. Lavine**，*Fundamentals of Heat and Mass Transfer*，第12–13章——本讲所依循的网络法、角系数和气体辐射的教科书式讲解。
- **E. R. G. Eckert & R. M. Drake**，*Analysis of Heat and Mass Transfer*（McGraw-Hill，1972）——关于发射率数据及其离散性的经典论述，其中那些警示性的表格会让你不再引用到小数点后第三位。
- **D. G. Gilmore (ed.)**，*Spacecraft Thermal Control Handbook*，Vol. I：*Fundamental Technologies*，第2版（The Aerospace Press / AIAA，2002）——辐射器、涂层、多层隔热材料，以及航天器表面涂层的$\alpha _ { s }$和$\varepsilon$数据表。
