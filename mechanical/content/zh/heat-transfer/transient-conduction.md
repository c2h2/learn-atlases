稳态导热问的是热量流向何处；非稳态导热问的是**热量要多久才能到达那里**，而答案取决于另一个材料物性，而不是稳态问题所用的那个。稳态温度场只关心$k$。变化中的温度场既关心$k$，也关心材料在途中必须吸收多少热量，即$\rho c$：比值
$$
\alpha = { \frac { k } { \rho c } } \qquad \left[ \mathrm { m ^ { 2 } / s } \right]
$$
称为**热扩散率**（导温系数），它是决定每一个非稳态导热解的时间尺度的物性。**水的导热能力约为空气的二十三倍，然而静止空气的热扩散率（$2.25 \times 10^{-5}\ \mathrm{m^2/s}$）却约为水（$1.47 \times 10^{-7}$）的$150$倍，因为每立方米的水每开尔文所储存的热量约为空气的$3500$倍。**因此，仅凭导热系数来判断一种材料响应的快慢，是一种范畴错误。

这门学问有一个重大的简化和一个重大的划分。**简化在于热方程是线性的**，因此一个非稳态问题可以由若干稳态问题与指数衰减叠加而成，复杂的热历程也可以借叠加原理由简单的历程拼装出来。**划分则是毕渥数**，即内部导热热阻与外部对流热阻之比，
$$
\mathrm { B i } = { \frac { h L _ { c } } { k } } = { \frac { L _ { c } / ( k A ) } { 1 / ( h A ) } } , \qquad L _ { c } = { \frac { V } { A } }
$$
它决定了物体处于两个截然不同的世界中的哪一个。**若$\mathrm { B i } \ll 1$，物体只有一个温度**：一个常微分方程、一个指数函数，整个非稳态导热问题退化为一个时间常数。**若$\mathrm { B i } \gg 1$，物体内有温度分布**：表面立即达到流体温度，而内部还丝毫没有察觉发生了什么，答案是一个误差函数。**介于两者之间的一切，都是一张特征值表。**

因此，本章在实用上的架构是三件工具加上一条在它们之间进行选择的规则。**集总参数法**适用于$\mathrm { B i } \lesssim 0 . 1$：一个指数函数、一个时间常数，用信封背面就能完成的算术。**一项近似（级数取首项）**适用于有限的毕渥数：中心温度在短暂的初始阶段之后按指数衰减，两个系数从表中查出。**半无限大物体**适用于短时间和大尺寸物体：一个误差函数，以及按时间平方根增长的穿透深度$\sqrt { \alpha t }$，它是整章中最有用的一个估算。**在它们之间进行选择的规则是傅里叶数$\mathrm { F o } = \alpha t / L ^ { 2 }$**：低于约$0 . 0 5$时，物体还没有察觉到自己的远端边界，半无限大解是对的；高于约$0 . 2$时，一项近似是对的；介于两者之间时，两者都不对，应当查表。

::: warning 五种非稳态导热错误，按代价大小排列
**在$\mathrm { B i } = 1$时使用集总参数法，并说误差很小。**在$\mathrm { B i } = 3$时，平板中心在傅里叶数为$1 . 7 5$时降到其初始过余温度的$10\ \%$；集总模型给出的是$0 . 7 7$。**集总模型并非“近似正确”，它在时间上错了$2 . 3$倍**——而且这种失效在任何方向上都不保守，因为集总模型还认为表面与中心温度相等，而实际上表面处于$1 5\ \%$、中心处于$4 1\ \%$。**$0 . 1$这一判据并不是吹毛求疵：它是内、外热阻相差十倍的那一点，这等于说内部热阻可以忽略。****根据导热系数给出冷却时间。**集总物体的时间常数是$\rho c V / ( h A )$，**其中根本不含导热系数**；大物体受导热控制的冷却时间是$L ^ { 2 } / \alpha$，一旦用$\alpha$来写，其中同样不含导热系数。**银和铝在同一流体中、尺寸相同时，冷却速率大致相同，因为它们的热扩散率相差不到两倍，单位体积热容也相差不到两倍。****在物体已经察觉其远端之后仍使用半无限大解。**半无限大解适用于$\mathrm { F o } = \alpha t / L ^ { 2 } \lesssim 0 . 0 5$；超过这一范围，背面已经升温，表面温度不再是公式所给出的值。对于一块从一侧表面加热的$2 5 \ \mathrm{mm}$厚合金钢板（$\alpha = 5 . 6 \times 1 0 ^ { - 6 } \mathrm { m ^ { 2 } / s }$），这相当于$t \lesssim 6 \ \mathrm { s }$；对于一块$5 0 0 \ \mathrm{mm}$厚的块体，则是$t \lesssim 3 7 \ \mathrm { m i n }$。**半无限大区域是大物体或短时间的区域，在一块板上用它算更长的时间就是错误。**过了这一点，假定内部是处于$T_i$的取之不尽的热库的半无限大模型，在表面温度固定时会高估换热量，在热流密度固定时会低估表面温度的变化。**假定流体保持其标称温度。**这里的每一个公式都是针对一个恒定的$T _ { \infty }$写出的。一个$2 0 0$升的淬火槽接收一件$8 5 0 \ {} ^ { \circ } \mathrm { C }$、$2 0 \ \mathrm{kg}$的钢锻件，锻件高出槽液温度的热量约为$8\ \mathrm{MJ}$，足以使整个$200$升槽液升温约$10\ \mathrm{K}$——如果槽液不搅拌，零件附近的水升温还要多得多——于是指数中的驱动力$\left( T - T _ { \infty } \right )$就不再是你所写的那个值了。**在写下冷却时间之前，先把槽液的热容量与零件的热容量作比较；两者之比常常小于十，这时集总参数法必须既用于零件，也用于槽液。****信赖一个无法测量的表面传热系数。**在集总区域，冷却时间与$h$**成反比**，因此$h$差两倍，时间就差两倍。**在导热控制区域，时间由$L ^ { 2 } / \alpha$决定，$h$几乎完全无关紧要**——这在一种情形下是一种安慰，在另一种情形下则是一个警告；知道自己处于哪个区域，比拥有一个更好的关联式更有价值。
:::

## 集总参数法

::: definition 毕渥数与集总参数法 {#def-lumped}
如果内部的导热热阻与外部的对流热阻相比可以忽略，那么整个物体处于同一温度$T ( t )$，对其作能量平衡得到
$$
\rho c V { \frac { d T } { d t } } = - h A \left( T - T _ { \infty } \right ) \qquad \Longrightarrow \qquad \boxed { \; { \frac { \theta } { \theta _ { i } } } = { \frac { T - T _ { \infty } } { T _ { i } - T _ { \infty } } } = e ^ { - t / \tau } , \qquad \tau = { \frac { \rho c V } { h A } } = { \frac { \rho c L _ { c } } { h } } \; }
$$
**时间常数是热容除以热导，与 RC 电路中完全一样，而且这一类比是精确的**：$T \leftrightarrow$电压，$\rho c V \leftrightarrow$电容，$1 / ( h A ) \leftrightarrow$电阻，$h A ( T _ { \infty } - T ) \leftrightarrow$一个驱动电容趋向戴维南等效电压的电流源。**因此，只要把元件一一对应过去，SPICE 之类的电路仿真程序以及每一本控制教材中的阶跃响应，都能精确求解集总热问题。**
**特征长度是$L _ { c } = V / A$，即体积除以参与换热的面积**——而把$A$取对就是全部的技巧所在。对于半径为$r$、周围全部冷却的长圆柱，$L _ { c } = r / 2$；对于球，$L _ { c } = r / 3$；对于两侧面冷却、半厚为$L$的平板，$L _ { c } = L$；**对于只有一侧面冷却的平板，$L _ { c } = 2 L$，而忘记哪些面在换热，是这一方法中最常见的单一错误。**
**判据是$\mathrm { B i } = h L _ { c } / k \lesssim 0 . 1$**，值得推导一次而不是死记（见[[#der-lumped|推导]]）：它说的是物体**内部**的温降至多为物体到流体温降的$10\ \%$。
$$
\begin{array}{l c c c}
\text{物体} & h \left( \mathrm { W / m ^ { 2 } K } \right) & k \left( \mathrm { W / m \, K } \right) & \mathrm { B i } \text{（当 } L _ { c } = 1 0 \ \mathrm { m m } \text{）} \\
\text{静止空气中的铜} & 8 & 4 0 1 & 0 . 0 0 0 2 \\
\text{静止空气中的铝} & 8 & 1 8 0 & 0 . 0 0 0 4 \\
\text{静止空气中的钢} & 8 & 4 5 & 0 . 0 0 1 8 \\
\text{静止空气中的混凝土} & 8 & 1 . 0 & 0 . 0 8 0 \\
\text{水中的铝} & 2 0 0 0 & 1 8 0 & 0 . 1 1 \\
\text{油中的钢} & 3 0 0 & 4 5 & 0 . 0 6 7 \\
\text{沸水中的钢} & 1 0 { , } 0 0 0 & 4 5 & 2 . 2 \\
\text{空气中的氧化镁保温材料} & 8 & 0 . 1 2 & 0 . 6 7
\end{array}
$$
**把这张表当作一张地图来读，看简便方法何时有效：气体中的金属，总是有效；液体中的金属，通常有效；沸水或凝结蒸汽中的任何物体，从不有效；保温材料几乎从不有效，因为失效的恰恰是它们自身的导热系数。**
:::

::: exercise 推导：集总参数法与$B i = 0 . 1$判据 {#der-lumped level=3}
::: solution
**第 1 部分：方法。**对体积为$V$、表面积为$A$、密度为$\rho$、比热容为$c$、向温度为$T _ { \infty }$的流体散热的等温物体写出能量平衡：
$$
\rho c V { \frac { d T } { d t } } = - h A \left( T - T _ { \infty } \right )
$$
分离变量，并从$t = 0$时的$T _ { i }$开始积分：
$$
\int _ { \theta _ { i } } ^ { \theta } { \frac { d \theta } { \theta } } = - { \frac { h A } { \rho c V } } \int _ { 0 } ^ { t } d t \qquad \Longrightarrow \qquad \theta = \theta _ { i } e ^ { - h A t / ( \rho c V ) }
$$
**第 2 部分：判据。**现在来问等温假设有多糟。在物体处于$T$、流体处于$T _ { \infty }$的那一瞬间，离开表面的热量必须从内部传到表面，因此内部温度梯度满足$k \, \Delta T _ { \text{int} } / L _ { c } \approx h \left( T - T _ { \infty } \right )$，即
$$
\Delta T _ { \text{int} } \approx { \frac { h L _ { c } } { k } } \left( T - T _ { \infty } \right ) = \mathrm { B i } \times \left( T - T _ { \infty } \right )
$$
**因此，内部的不均匀程度约为驱动温差的$\mathrm { B i }$倍，相差一个与形状有关的量级为一的因子。**在$\mathrm { B i } = 0 . 1$时，以剩余过余温度计，物体远端与表面相差$10\ \%$，这等于说时间常数偏差$10\ \%$。**这就是$0 . 1$规则的全部内容，也正因为如此，这条规则是一个你有权更改的容差：如果冷却时间可以接受$2 5\ \%$的误差，$\mathrm { B i } = 0 . 2 5$就是一个完全正当的选择；而如果你在计算热应力，即便$\mathrm { B i } = 0 . 0 1$也可能过于粗糙，因为应力关心的是梯度而不是平均值。**
:::

::: definition 傅里叶数 {#def-fourier}
$$
\boxed { \; \mathrm { F o } = { \frac { \alpha t } { L ^ { 2 } } } \; } \qquad \text{（无量纲时间）} \qquad \Longleftrightarrow \qquad { \frac { t } { \tau } } = { \frac { h A } { \rho c V } } t = { \frac { h L _ { c } } { k } } { \frac { k t } { \rho c L _ { c } ^ { 2 } } } = \mathrm { B i } \times \mathrm { F o }
$$
**集总解就是$\theta / \theta _ { i } = e ^ { - \mathrm { B i } \, \mathrm { F o } }$，而这一恒等式正是两个无量纲数就足以描述每一个线性非稳态导热问题的原因**：答案总是$\mathrm { F o }$的函数、以$\mathrm { B i }$为参数，因此只要$\mathrm { B i }$和$\mathrm { F o }$都相匹配，在小模型上测得的冷却曲线就能精确预测大零件。
**这两个数各有简单的物理含义，比公式更有价值。**
**$\mathrm { F o }$是已扩散穿过物体的热量与物体中储存的热量之比**——或者更有用的说法是，**以导热穿过物体所需时间$L ^ { 2 } / \alpha$为单位来度量的已经过的时间。**$\mathrm { F o } = 1$意味着“热波已有时间穿过物体”；$\mathrm { F o } = 0 . 0 1$意味着“热波才走了十分之一的路程”。
**$\mathrm { B i }$是物体内部温降与外部温降之比。**$\mathrm { B i } \ll 1$：流体是瓶颈，物体是等温的。$\mathrm { B i } \gg 1$：物体是瓶颈，其表面处于流体温度。
$$
\begin{array}{l c c}
\text{区域} & \text{条件} & \text{控制性答案} \\
\text{集总} & { \mathrm { B i } < 0 . 1 } & { \theta / \theta _ { i } = e ^ { - { \mathrm { B i } } \, { \mathrm { F o } } } } \\
\text{半无限大} & { \mathrm { F o } < 0 . 0 5 , \text{ 任意 } { \mathrm { B i } } } & { { \text{误差函数，穿透深度 } } { \sqrt { \alpha t } } } \\
\text{一项近似} & { \mathrm { F o } > 0 . 2 , \text{ 任意 } { \mathrm { B i } } } & { C _ { 1 } e ^ { - \zeta _ { 1 } ^ { 2 } { \mathrm { F o } } } \times \text{形状函数} } \\
\text{稳态} & { \zeta _ { 1 } ^ { 2 } \mathrm { F o } \gtrsim 5 } & { \theta < 1 \ \% \text{ 的 } \theta _ { i } , \text{ 采用稳态解} }
\end{array}
$$

::: definition 一项近似 {#def-oneterm}

## 半无限大物体

::: definition 半无限大物体与穿透深度 {#def-semiinf}
尚未感受到其远端边界的物体，其行为如同一个半空间，而半空间中的热方程有一个**相似解**：自变量组合成单一的组合量
$$
\eta = { \frac { x } { 2 { \sqrt { \alpha t } } } } \qquad \Longrightarrow \qquad { \frac { T - T _ { i } } { T _ { s } - T _ { i } } } = \operatorname { erfc } ( \eta ) , \qquad q _ { s } ^ { \prime \prime } = { \frac { k \left( T _ { s } - T _ { i } \right ) } { \sqrt { \pi \alpha t } } }
$$
**三种标准情形，全都只是$\eta$的函数：**
$$
\begin{array}{l l l}
\text{给定表面温度} & { T ( 0 , t ) = T _ { s } } & { \dfrac { T - T _ { i } } { T _ { s } - T _ { i } } = \operatorname { erfc } \eta , \quad q _ { s } ^ { \prime \prime } = \dfrac { k \Delta T } { \sqrt { \pi \alpha t } } } \\[10pt]
\text{给定表面热流密度} & { q _ { s } ^ { \prime \prime } = \text{常数} } & { T _ { s } - T _ { i } = \dfrac { 2 q _ { s } ^ { \prime \prime } } { k } \sqrt { \dfrac { \alpha t } { \pi } } , \quad T - T _ { i } = \dfrac { 2 q _ { s } ^ { \prime \prime } \sqrt { \alpha t } } { k } \left[ { \frac { e ^ { - \eta ^ { 2 } } } { \sqrt { \pi } } } - \eta \operatorname { erfc } \eta \right] } \\[10pt]
\text{表面对流} & { - k \partial T / \partial x = h ( T _ { \infty } - T _ { s } ) } & { \dfrac { T - T _ { i } } { T _ { \infty } - T _ { i } } = \operatorname { erfc } \eta - e ^ { h x / k + \xi ^ { 2 } } \operatorname { erfc } ( \eta + \xi ) , \ \xi = \dfrac { h \sqrt { \alpha t } } { k } }
\end{array}
$$
**穿透深度用一个符号就道尽了全部内容：**
$$
\boxed { \; \delta \sim { \sqrt { \alpha t } } \; } \qquad \text{且} \qquad t \sim { \frac { \delta ^ { 2 } } { \alpha } }
$$
**距离随时间的平方根增长，所以时间随距离的平方增长——这是热处理、铸造、防火安全和烹饪中影响最为深远的一条标度律。****想改变温度的深度加倍，时间就变为四倍；需要冷却的截面减半，时间就缩短为四分之一。****在导热控制区域，一根$2 5 \ \mathrm{mm}$的棒料冷透所需的时间约为同种钢$5 0 \ \mathrm{mm}$棒料的四分之一，而$5 0 \ \mathrm{mm}$棒料又约为$1 0 0 \ \mathrm{mm}$棒料的四分之一**——这就是热处理工艺规程按截面尺寸编写的原因。
**该模型在$\mathrm { F o } = \alpha t / L ^ { 2 } \lesssim 0 . 0 5$时成立**，即在$\sqrt{\alpha t} \lesssim 0.22\,L$时成立。
:::

::: definition 接触温度 {#def-contactT}
使两个分别处于$T _ { 1 }$和$T _ { 2 }$的半无限大物体实现理想热接触。界面温度不随时间变化，由**吸热系数**（蓄热系数）$e = \sqrt { k \rho c }$决定：
$$
\boxed { \; T _ { c } = { \frac { e _ { 1 } T _ { 1 } + e _ { 2 } T _ { 2 } } { e _ { 1 } + e _ { 2 } } } \; } \qquad q ^ { \prime \prime } ( t ) = { \frac { e _ { 1 } e _ { 2 } } { e _ { 1 } + e _ { 2 } } } { \frac { T _ { 1 } - T _ { 2 } } { \sqrt { \pi t } } }
$$
**界面温度是以吸热系数为权的加权平均，每种材料的权重就是它供给热量的能力；热流密度按$1 / { \sqrt { t } }$衰减——接触在触碰的那一瞬间最为剧烈。**
$$
\begin{array}{l c c}
\text{材料} & e = { \sqrt { k \rho c } } \ \left( \mathrm { J / m ^ { 2 } K \, s ^ { 1 / 2 } } \right) & \text{在 } 2 0 \ \mathrm { ^ \circ C } \text{ 时的触感} \\
\text{铜} & 3 7 { , } 3 0 0 & \text{很冷} \\
\text{铝} & 2 0 { , } 9 0 0 & \text{冷} \\
\text{碳钢} & 1 3 { , } 6 0 0 & \text{冷} \\
\text{混凝土} & 1 7 0 0 & \text{凉} \\
\text{玻璃} & 1 6 0 0 & \text{凉} \\
\text{橡木} & 4 7 0 & \text{不冷不热} \\
\text{泡沫塑料} & \sim 4 0 & \text{温暖} \\
\text{静止空气} & 5 . 5 & \text{温暖（除非流动）}
\end{array}
$$
**这张表解释了为什么同温度的金属表面和木质表面摸起来感觉不同，也解释了为什么热金属板会烫伤人，而同温度的热空气却不会。**
:::

## 热冲击

::: definition 两个热冲击严重程度参数 {#def-shock}
一个表面相对于内部突然改变$\Delta T$的物体不能自由变形，由此产生的应力对平板而言为
$$
\sigma _ { \text{表面} } \approx { \frac { E \alpha _ { e } \, \Delta T } { 1 - \nu } } \times \begin{cases} 1 & { \mathrm { B i } \gtrsim 3 \ \text{（表面处于流体温度，完全约束）}} \\ { \mathrm { B i } / 3 } & { \mathrm { B i } \lesssim 3 \ \text{（内部为抛物线形温度分布）}} \end{cases}
$$
**令其等于断裂强度$\sigma _ { f }$，得到两个经典的抗热冲击参数：**
$$
\boxed { \; R = { \frac { \sigma _ { f } \left( 1 - \nu \right ) } { E \alpha _ { e } } } \quad \text{（强烈淬冷）} \qquad \qquad \Delta T _ { \text{crit} } = { \frac { 3 R k } { h L } } \quad \text{（温和淬冷）} \; }
$$
$$
\begin{array}{l c c c c c c}
\text{材料} & \sigma _ { f } \left( \mathrm { M P a } \right) & E \left( \mathrm { G P a } \right) & \nu & \alpha _ { e } \left( 1 0 ^ { - 6 } / \mathrm { K } \right) & k \left( \mathrm { W / m \, K } \right) & R \left( \mathrm { K } \right) \\
\text{熔融石英} & 6 0 & 7 2 & 0 . 1 7 & 0 . 5 5 & 1 . 4 & 1 2 5 8 \\
\text{硼硅酸盐玻璃} & 7 0 & 6 4 & 0 . 2 0 & 3 . 3 & 1 . 2 & 2 6 5 \\
\text{碳化硅} & 3 5 0 & 4 1 0 & 0 . 1 7 & 4 . 5 & 1 2 0 & 1 5 7 \\
\text{瓷} & 5 5 & 7 0 & 0 . 2 2 & 6 . 5 & 1 . 5 & 9 4 \\
\text{氧化铝} & 2 5 0 & 3 7 0 & 0 . 2 6 & 8 . 0 & 2 5 & 6 3 \\
\text{钠钙玻璃} & 4 0 & 7 0 & 0 . 2 2 & 9 . 0 & 1 . 0 & 5 0
\end{array}
$$
**这张表包含了陶瓷力学中最违反直觉的事实：氧化铝的强度是硼硅酸盐玻璃的$3 . 6$倍，导热系数是它的$2 1$倍，但在强烈淬冷中却对热冲击敏感得多，因为它的弹性模量高$5 . 8$倍，膨胀系数大$2 . 4$倍，而产生应力的正是弹性模量和膨胀。****熔融石英能经受$1 2 5 0 \ \mathrm{K}$的淬冷，不是因为它强——它是表中最弱的材料之一——而是因为它几乎不膨胀。**
**第二种读法才是会改变设计的读法：在温和淬冷区域，$\Delta T _ { \text{crit} } \propto k / ( h L )$，所以补救办法是更温和的介质、更薄的截面和导热性更好的材料——而其中第一项是不花钱的。**
:::

::: example 管子会开裂吗？ {#ex-shock}

::: solution
半厚$L = 0 . 0 0 3 \ \mathrm { m }$，$k = 2 5 \ \mathrm { W / m \, K }$，$R = 6 3 \ \mathrm { K }$。
**(a) 静止空气，$h \approx 1 0 \ \mathrm { W / m ^ { 2 } K }$。**$\mathrm { B i } = 1 0 \times 0 . 0 0 3 / 2 5 = 0 . 0 0 1 2 \ll 3$，所以
$$
\Delta T _ { \text{crit} } = { \frac { 3 \times 6 3 \times 2 5 } { 1 0 \times 0 . 0 0 3 } } = 1 5 7 { , } 5 0 0 \ \mathrm { K }
$$
**它可以安然放在工作台上。**管子在冷却过程中几乎保持均匀，应力远低于强度的百分之一。
**(b) 水。**$\mathrm { B i } = 5 0 0 0 \times 0 . 0 0 3 / 2 5 = 0 . 6 0 < 3$，所以
$$
\Delta T _ { \text{crit} } = { \frac { 3 \times 6 3 \times 2 5 } { 5 0 0 0 \times 0 . 0 0 3 } } = \mathbf { 3 1 5 \ \mathrm { K } } \qquad \text{而实际的 } \Delta T = 7 7 5 \ \mathrm { K }
$$
**它会开裂，驱动温差超出两倍半。****现在是有用的部分：公式表明，失效的原因不在于水，而在于$h L$。**先在静止空气中把管子冷却到$4 0 0 \ {} ^ { \circ } \mathrm { C }$再插入水中，得到$\Delta T = 3 7 5 \ \mathrm { K }$——仍高于$315\ \mathrm{K}$的极限。**可靠的解决办法是在零件热的时候让$h$小：插入温水中，或先放在静止空气中、待管子降到$3 0 0 \ {} ^ { \circ } \mathrm { C }$以下再用强制风冷，或者采用更薄的管子，因为$\Delta T _ { \text{crit} } \propto 1 / L$，壁厚减半可使热冲击裕度加倍，而不牺牲任何其他性能。**
:::

## 周期性加热：温度波

::: definition 温度波的衰减深度 {#def-cyclic}
当表面温度以周期$P$、角频率$\omega = 2 \pi / P$作正弦振荡时，物体以一个**衰减的行波**作出响应：
$$
\boxed { \; { \frac { T ( x , t ) - T _ { m } } { \Delta T _ { s } } } = e ^ { - x / \delta } \cos \left( \omega t - { \frac { x } { \delta } } \right ) , \qquad \delta = { \sqrt { \frac { 2 \alpha } { \omega } } } = { \sqrt { \frac { \alpha P } { \pi } } } \; }
$$
**每经过深度$\delta$，振幅衰减为原来的$1 / e$，相位滞后一个弧度——因此波以速度$\omega \delta = \sqrt { 2 \alpha \omega }$传播，正比于$\sqrt { \alpha }$和频率的平方根。****与声波不同，温度波没有固定的波速：高频热量比低频热量传得快，速度之比等于两者频率的平方根之比。**
$$
\begin{array}{l c c c}
\text{材料} & \alpha \left( \mathrm { m ^ { 2 } / s } \right) & \delta _ { \text{日} } \left( P = 2 4 \ \mathrm { h } \right) & \delta _ { \text{年} } \left( P = 1 \ \mathrm { y r } \right) \\
\text{铜} & 1 . 1 1 \times 1 0 ^ { - 4 } & 1 . 7 5 \ \mathrm { m } & 3 3 . 4 \ \mathrm { m } \\
\text{铝} & 9 . 7 \times 1 0 ^ { - 5 } & 1 . 6 3 \ \mathrm { m } & 3 1 . 2 \ \mathrm { m } \\
\text{碳钢} & 1 . 2 5 \times 1 0 ^ { - 5 } & 5 8 6 \ \mathrm { m m } & 1 1 . 2 \ \mathrm { m } \\
\text{混凝土} & 7 . 0 \times 1 0 ^ { - 7 } & 1 3 9 \ \mathrm { m m } & 2 . 6 5 \ \mathrm { m } \\
\text{砖} & 5 . 3 \times 1 0 ^ { - 7 } & 1 2 1 \ \mathrm { m m } & 2 . 3 1 \ \mathrm { m } \\
\text{保温板} & 3 . 7 \times 1 0 ^ { - 7 } & 1 0 1 \ \mathrm { m m } & 1 . 9 3 \ \mathrm { m }
\end{array}
$$
**首先注意，对金属而言，日衰减深度比大多数建筑物还大：一块铜坯在以日为尺度的时间上在热方面是等温的，对任何用金属工作的人来说，热质量根本不是一种可用的设计手段。****这张表是每一部建筑规范中“热质量”条款的物理基础，而它所说的比条款更为尖锐：一堵$2 0 0 \ \mathrm{mm}$厚的混凝土墙能让日温度波动的$2 4 \ \%$通过，而年波动则通过$9 3 \ \%$。****热质量是一个低通滤波器，其转折点由你所关心的周期决定，它的全部价值在于这个转折点落在日与年之间。****相位滞后是这一益处的另一半，也是计算中通常被遗漏的那一半：一堵$2 0 0 \ \mathrm{mm}$厚的混凝土墙使日峰值延迟$2 0 0 / 1 3 9 = 1 . 4 4$弧度，即$1 . 4 4 / 2 \pi \times 2 4 = 5 . 5$小时——午后的阳光到晚上九点左右才在室内形成峰值，那时空调系统已经关闭，夜间通风已经开始。**
:::

## 用乘积解求多维非稳态问题

::: definition 乘积解 {#def-product}
如果一个物体是两个或三个一维物体的交集——短圆柱是长圆柱与平板的交集，矩形块是三块平板的交集——且所有表面都暴露于同一$T _ { \infty }$、具有相同的$h$，并且没有内热源，那么
$$
\boxed { \; \left( { \frac { T - T _ { \infty } } { T _ { i } - T _ { \infty } } } \right ) _ { \text{组合} } = \left( \theta ^ { * } \right ) _ { 1 } \times \left( \theta ^ { * } \right ) _ { 2 } \times \left( \theta ^ { * } \right ) _ { 3 } \; }
$$
在同一点、同一时刻取值，每个因子取自该物体对应的一维解。**这一结果是精确的而非近似的，它直接源于热方程是线性且可分离的：$\partial \theta / \partial t = \alpha \nabla ^ { 2 } \theta$在各个坐标中的解的乘积，就是它在所有坐标中的解。**
**这条规则恰好在三种情形下失效，而这三种情形都很常见：各表面的$h$或$T _ { \infty }$不同（一端较热的坯料）、有内热源，以及两个物性不同的物体相互接触。前两种情形的答案是有限差分模型；第三种是接触热阻模型，并在两侧分别求解非稳态问题。**
:::

::: example 炉中的短圆柱 {#ex-short}
一根直径$6 0 \ \mathrm{mm}$、长$1 2 0 \ \mathrm{mm}$的不锈钢坯料（$k = 1 6 \ \mathrm { W / m \, K }$，$\rho = 7 9 0 0 \ \mathrm { k g / m ^ { 3 } }$，$c = 5 0 0 \ \mathrm { J / k g \, K }$，$\alpha = 4 . 0 5 \times 1 0 ^ { - 6 } \ \mathrm { m ^ { 2 } / s }$）从$2 0 \ {} ^ { \circ } \mathrm { C }$的料架送入$8 0 0 \ {} ^ { \circ } \mathrm { C }$的炉中，各表面$h = 1 2 0 \ \mathrm { W / m ^ { 2 } K }$。$1 0$分钟后中截面中心的温度是多少？最冷点需要多长时间达到$7 0 0 \ {} ^ { \circ } \mathrm { C }$？

::: solution
**坯料是半径$0 . 0 3 0 \ \mathrm { m }$的长圆柱与半厚$0 . 0 6 0 \ \mathrm { m }$的平板的交集。中截面的中心既是圆柱的轴线，又是平板的中面，因此两个因子都在各自的中心处取值。**
$$
\begin{array} { l l l l }
\text{平板} & { L = 0 . 0 6 0 \ \mathrm { m } , \ \mathrm { B i } = 1 2 0 \times 0 . 0 6 0 / 1 6 = 0 . 4 5 0 \ \Rightarrow \ \zeta _ { 1 } = 0 . 6 2 4 4 , \ C _ { 1 } = 1 . 0 6 4 2 } \\[2pt]
\text{圆柱} & { r _ { o } = 0 . 0 3 0 \ \mathrm { m } , \ \mathrm { B i } = 1 2 0 \times 0 . 0 3 0 / 1 6 = 0 . 2 2 5 \ \Rightarrow \ \zeta _ { 1 } = 0 . 6 5 2 4 , \ C _ { 1 } = 1 . 0 5 4 1 }
\end{array}
$$
在$t = 6 0 0 \ \mathrm { s }$时：$\mathrm { F o } _ { \text{平板} } = 4 . 0 5 \times 1 0 ^ { - 6 } \times 6 0 0 / 0 . 0 6 0 ^ { 2 } = 0 . 6 7 5$，$\mathrm { F o } _ { \text{圆柱} } = 4 . 0 5 \times 1 0 ^ { - 6 } \times 6 0 0 / 0 . 0 3 0 ^ { 2 } = 2 . 7 0 0$，
$$
\theta _ { \text{平板} } ^ { * } = 1 . 0 6 4 2 e ^ { - 0 . 6 2 4 4 ^ { 2 } \times 0 . 6 7 5 } = 0 . 8 1 8 , \qquad \theta _ { \text{圆柱} } ^ { * } = 1 . 0 5 4 1 e ^ { - 0 . 6 5 2 4 ^ { 2 } \times 2 . 7 0 0 } = 0 . 3 3 4
$$
$$
\theta ^ { * } = 0 . 8 1 8 \times 0 . 3 3 4 = 0 . 2 7 3 \qquad \Longrightarrow \qquad T = 8 0 0 - 0 . 2 7 3 \times 7 8 0 = \mathbf { 5 8 7 \ {} ^ { \circ } C }
$$
**中心是最冷点，对于从各个方向加热的物体，这是必然的。**同一时刻，长度中点处的柱面处于$6 0 9 \ {} ^ { \circ } \mathrm { C }$（那里的圆柱因子多乘一个$J _ { 0 } ( 0 . 6 5 2 4 ) = 0 . 8 9 6$），圆形端面的中心处于$6 2 7 \ {} ^ { \circ } \mathrm { C }$，而棱角——坯料上最尖锐的部位——处于$6 4 5 \ {} ^ { \circ } \mathrm { C }$，比中心高$5 8 \ \mathrm{K}$。
**求中心达到$7 0 0 \ {} ^ { \circ } \mathrm { C }$的时间**（$\theta ^ { * } = 1 0 0 / 7 8 0 = 0 . 1 2 8 2$），得$t = 9 2 1 \ \mathrm { s } = \mathbf { 1 5 . 4 \ min }$。**棱角在$7 8 6 \ \mathrm{ s }$时已越过$7 0 0 \ {} ^ { \circ } \mathrm { C }$，约早两分十五秒，当中心到达时它处于$7 2 7 \ {} ^ { \circ } \mathrm { C }$。**
**从这些算术中得到两点教训。****圆柱因子承担了全部工作：在同一时刻，它已降到$0 . 3 3 4$，而平板因子才到$0 . 8 1 8$，因为$\mathrm { F o } \propto 1 / L ^ { 2 }$，而半径只有半长的一半——$\mathrm { F o }$相差四倍，$\theta ^ { * }$相差得还要更多。****而且“在炉中加热多久”是按中心来回答的，冶金质量却是按棱角来判断的。****在中心达到$7 0 0 \ {} ^ { \circ } \mathrm { C }$的时刻，棱角要高$2 7 \ \mathrm{K}$；保温时间由最慢的点决定，表面状态由最热的点决定，这就是加热炉工艺既规定最高表面温度、又规定最低中心温度的原因。**
:::

\theta _ { 0 } ^ { * } = 1 . 2 1 0 2 \, e ^ { - 1 . 1 9 2 5 ^ { 2 } \times 0 . 7 6 8 } = 1 . 2 1 0 2 \times 0 . 3 3 5 7 = 0 . 4 0 6 \qquad T _ { 0 } = 6 0 + 0 . 4 0 6 \times 7 4 0 = 3 6 1 \ \mathrm { ^ \circ C }
$$
**同一时刻表面处于$0 . 4 0 6 \times \cos ( 1 . 1 9 2 5 ) = 0 . 1 5 0$，即$1 7 1 \ {} ^ { \circ } \mathrm { C }$——所以设计者的$134\ {}^{\circ}\mathrm{C}$连表面温度都不是，而中心比报告值高$227\ \mathrm{K}$。**误用的方法错的不是一点点；它报告的是一个均匀的物体，而真实物体的表面与中心相差$190\ \mathrm{K}$。
:::
:::

::: quiz 加快淬火 {#quiz-quench}
一个$\mathrm { B i } = 4 0$的大钢锻件正在淬火。工厂把喷淋量加倍，使$h$加倍。中心的冷却速率：

- [ ] 加倍，因为时间常数是$1 / h$
- [x] 只提高百分之几，因为$\zeta _ { 1 } ^ { 2 }$已接近饱和
- [ ] 不变，因为毕渥数很大
- [ ] 减半，因为$h$越大，蒸汽膜越厚

::: solution
**只提高百分之几。**在$\mathrm { B i } = 4 0$时，平板特征值为$\zeta _ { 1 } = 1 . 5 3 3$；在$\mathrm { B i } = 8 0$时为$1 . 5 5 1$。**冷却指数$\zeta _ { 1 } ^ { 2 }$从$2 . 3 4 9$升到$2 . 4 0 7$——用双倍的水只换来$2 . 5 \ \%$的改进。****渐近值为$\zeta _ { 1 } \to \pi / 2$，$\zeta _ { 1 } ^ { 2 } \to 2 . 4 6 7$，所以即使无限大的喷淋量，也只比原来的喷淋多出$5 \ \%$。****选项 (d) 也不算糟糕的猜测——喷淋量加倍可能把淬火从核态沸腾区推入膜态沸腾区，使之变慢——但那是关联式的失效，而不是毕渥数的失效，而毕渥数告诉你的是，这样做本来就不会有多大帮助。****在$\mathrm { B i } \gg 1$时唯一有效的杠杆是$L$：截面减半，时间缩短为四分之一。**
:::
:::

## 后续内容

- **外部对流传热**接手本章视为给定的$h$，并表明在集总区域——冷却时间与$1 / h$成正比——整个答案都取决于一个你可能只知道到两倍精度的关联式。
- **内部对流传热**和**自然对流**为淬火槽和锻造加热炉实际运行的两种区域提供关联式，包括在不搅拌的槽中起主导作用的自由表面运动。
- **沸腾与凝结**是“$h$为常数”这一假设最终失效的地方：在核态沸腾和膜态沸腾中，传热系数取决于零件自身的温度，冷却曲线不再是指数曲线。
- **稳态导热**是这里一切内容在$t \to \infty$时的极限，两者在此相遇：一项近似朝稳态解衰减，而首项的时间常数就是稳态问题建立所需的时间。
- 本课程的开篇一章引入了决定[[#def-contactT|接触温度]]的吸热系数；在这里它作为相似解的系数出现，而不是作为一条经验法则。
- [[vibrations]]以不同的名称使用相同的数学：集总物体是具有时间常数的一阶系统，一项近似是模态展开，温度波是有阻尼振子的扩散类比。
- [[control-systems]]把集总物体看作一阶对象$K / ( \tau s + 1 )$；温度控制回路之所以缓慢且依赖积分作用，原因正是$\tau = \rho c V / ( h A )$。

::: history 非稳态导热简史
**1701 年——牛顿（Newton）冷却定律。**匿名发表于《哲学汇刊》（*Philosophical Transactions*）**22**卷第 824–829 页的《热度标尺》（“Scala graduum Caloris”），通过记录一块加热的铁块冷却的时间，把温标延伸到温度计量程以上，其前提假设是冷却速率正比于其高出环境的过余温度。**这一假设只对处于恒定$h$中的集总物体才精确成立——这一事实此后一百年都无人能够认识到。**
**1822 年——傅里叶（Fourier）。**《热的解析理论》（*Théorie analytique de la chaleur*）用衰减模态级数求解平板、球和圆柱中的非稳态导热——这些特征函数展开正是本章一项近似背后的东西——并用以他命名的积分处理无限大物体。
**1833 年——杜阿梅尔（Duhamel）学会在时间上叠加。**杜阿梅尔（J.-M. Duhamel）关于周围介质温度随时间变化的固体中热传导的论文（《巴黎综合理工学院学报》，*Journal de l'École Polytechnique*，1833）提供了一种手段，把每一个恒定条件下的解变为任意条件下的解：把历程构造为一系列阶跃。**每一个用解析法计算的炉温升温曲线和焊接热循环，都是某种形式的杜阿梅尔积分。**
**1848 年——威廉·汤姆森（William Thomson）与镜像法。**镜像法由二十四岁的汤姆森为静电学提出并移用于传热，它通过把热源对平面边界作镜像，给出靠近该边界的热源的解。
**1860–1862 年——开尔文（Kelvin）研究地下温度。**汤姆森用本章的周期解分析了福布斯（James David Forbes）在爱丁堡记录的地下温度，从年温度波的衰减和滞后中求出岩石的热扩散率；1862 年，他用冷却半空间的误差函数解，根据地温梯度估算地球的年龄。
**1936 年——纽曼（Newman）作乘法。**纽曼（A. B. Newman）的《矩形与圆柱形固体的加热与冷却》（“Heating and cooling rectangular and cylindrical solids”，*Industrial and Engineering Chemistry* **28**，545–548）表明，砖形体或短圆柱的解是一维解的乘积。**它把一个三维问题变成若干一维问题加上一次乘法。**
**1947 年——海斯勒（Heisler）把特征值画成线算图。**海斯勒（M. P. Heisler）的《感应加热和恒温加热的温度图》（“Temperature charts for induction and constant-temperature heating”，*Transactions of the ASME* **69**，227–236）把平板、圆柱和球的级数解转化为线算图，几十年来，热处理车间就是靠这些图来回答非稳态问题的。
**1991 年——作为测量仪器的半无限大解。**古斯塔夫松（S. E. Gustafsson）的《用于测量固体材料导热系数和热扩散率的瞬态平面热源技术》（*Review of Scientific Instruments* **62**，797–804）介绍了一种夹在试样两半之间的薄加热传感器，在试样仍表现为无界时记录其温升，由一次短时测试同时得到$k$和$\alpha$——这是把本章的非稳态解反过来使用。
:::

## 本章要点

::: summary
- **两个数主宰一切：$\mathrm { B i } = h L _ { c } / k$决定物体只有一个温度还是存在温度分布，$\mathrm { F o } = \alpha t / L ^ { 2 }$决定过程进行到了哪一步。**两者之积是集总解的指数，因此整个学科就是以$\mathrm { B i }$为参数的$\mathrm { F o }$的函数。
- **集总参数法的时间常数是$\tau = \rho c V / ( h A )$，其中不含导热系数。**它精确地就是一个 RC 电路。把$A$取对——$L _ { c } = V / A$只计入参与换热的表面。
- **$0 . 1$判据是一个容差，而不是一条定律**：它说内部温度梯度是驱动温差的$10\ \%$。对于冷却时间，你可以放宽它；对于热应力，则不可以。
- **一项近似仅在$\mathrm { F o } > 0 . 2$时成立，别处一概不成立**，因为$C _ { 1 } > 1$，在$\mathrm { F o }$较小时公式会预测出高于初始温度的温度。
- **当$\mathrm { B i } \to \infty$时$\zeta _ { 1 }$趋于饱和**（平板为$\pi / 2$，球为$\pi$）：超过$\mathrm { B i } \approx 1 0$后，更好的流体收效甚微；更小的截面收效巨大。
- **半无限大解是$\mathrm { F o } < 0 . 0 5$时的答案**，其内容可以用一句话概括：**穿透深度按$\sqrt { \alpha t }$增长，所以时间按深度的平方增长。**
- **接触温度是以吸热系数为权的加权平均，与厚度无关**；初始热流密度为无穷大，有用的数字是对时间积分后的值。
- **温度波每经过$\delta = \sqrt { \alpha P / \pi }$衰减为原来的$1 / e$，并滞后一个弧度**——这就是厚重的墙能把夏日午后延迟数小时，却对冬天毫无作用的原因。
- **对于边界条件均匀的一维物体的交集，乘积解是精确的**；而“在炉中加热多久”由中心决定，表面质量则在棱角处判断。
- **这里的每一个公式都假定$T _ { \infty }$和$h$为常数。**会升温的淬火槽、改变沸腾区域的喷淋、自身释放相变热的零件，都会破坏指数规律——首先要检查的是槽液的热容量是否大于零件。
:::
