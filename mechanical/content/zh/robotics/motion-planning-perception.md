前面各章假定已有人替机器人决定了它该去哪里，并且机器人知道自己在哪里。本章用最后两个问题使这一回路闭合。**运动规划**问的是：给定机器人和障碍物的模型，求一条从起点到终点的无碰撞运动。**感知**问的是：根据相机、测距传感器和里程计，世界的几何形状是什么，机器人在其中的什么位置？规划的统一思想是**位形空间**：任意形状的机器人都变成一个点，障碍物变成关节值空间或位姿空间中的禁区，于是规划就是为一个点寻找路径。我们将建立位形空间障碍的构造方法，介绍在离散化空间上使用的图搜索算法（Dijkstra 算法、A* 算法）并证明 A* 的最优性，讨论人工势场及其局部极小值，以及能够处理机械臂高维空间的基于采样的规划器（PRM、RRT）。在感知方面，我们推导针孔相机模型、立体视觉测深及其按平方增长的误差，以及卡尔曼滤波——它以统计意义上最优的方式把预测与含噪声的测量融合起来，是大多数机器人状态估计的基础。运动学来自[[robotics/forward-kinematics]]，车辆模型和贝叶斯滤波来自[[robotics/mobile-robots]]。

## 位形空间 {#sec-cspace}

::: definition 位形空间与位形空间障碍 {#def-cspace}
机器人的**位形空间**$\mathcal C$是其全部位形的集合——对机械臂是关节矢量$\mathbf q$，对平面车辆是位姿$(x, y, \phi)$；其维数等于自由度数。设$\mathcal A(\mathbf q)\subset\mathbb R^2$或$\mathbb R^3$为机器人在位形$\mathbf q$时所占据的点集，$\mathcal O$为障碍物所占据的点集。**位形空间障碍**（C 障碍）为
$$
\mathcal C_{\text{obs}} = \{\mathbf q\in\mathcal C : \mathcal A(\mathbf q)\cap\mathcal O\ne\varnothing\},
$$
**自由空间**为$\mathcal C_{\text{free}} = \mathcal C\setminus\mathcal C_{\text{obs}}$。**无碰撞路径**是一个连续映射$\boldsymbol\sigma:[0,1]\to\mathcal C_{\text{free}}$，满足$\boldsymbol\sigma(0) = \mathbf q_{\text{start}}$和$\boldsymbol\sigma(1) = \mathbf q_{\text{goal}}$。
:::

对于只做平移的机器人，C 障碍有简洁的几何描述。

::: proposition 平移机器人的 C 障碍 {#prop-minkowski}
设机器人是刚体$\mathcal A_0$（以其参考点位于原点来描述），只平移不转动，因此$\mathcal A(\mathbf q) = \mathcal A_0 + \mathbf q = \{\mathbf a + \mathbf q : \mathbf a\in\mathcal A_0\}$。则
$$
\mathcal C_{\text{obs}} = \mathcal O\oplus(-\mathcal A_0) = \{\mathbf o - \mathbf a : \mathbf o\in\mathcal O,\ \mathbf a\in\mathcal A_0\},
$$
即障碍物与反射后的机器人的**闵可夫斯基和**（Minkowski sum）。对于半径为$\rho$的圆盘机器人，$\mathcal C_{\text{obs}}$就是把障碍物**膨胀**$\rho$：即与$\mathcal O$的距离不超过$\rho$的所有点。
:::

::: proof
$\mathbf q\in\mathcal C_{\text{obs}}$当且仅当机器人与障碍物有公共点，即对某个$\mathbf a\in\mathcal A_0$、$\mathbf o\in\mathcal O$有$\mathbf a + \mathbf q = \mathbf o$，即对某一这样的点对有$\mathbf q = \mathbf o - \mathbf a$——这正是所述集合。对于以参考点为圆心的圆盘，$-\mathcal A_0 = \mathcal A_0$是以原点为圆心、半径为$\rho$的圆盘，而$\mathbf q = \mathbf o - \mathbf a$且$\lVert\mathbf a\rVert\le\rho$意味着对某个$\mathbf o\in\mathcal O$有$\lVert\mathbf q - \mathbf o\rVert\le\rho$。
:::

按机器人半径膨胀障碍物，正是大多数移动机器人规划器的做法：把[[robotics/mobile-robots]]中的占据栅格按机器人半径加上安全裕量进行膨胀，然后为一个点进行规划。对于凸多边形，闵可夫斯基和仍是凸多边形，其边就是两个多边形的边按方向排序后的组合，可以在线性时间内算出。当机器人还会转动时，每个方向角$\phi$给出一个不同的膨胀障碍物，$\mathcal C_{\text{obs}}$是一个三维的"扭曲"实体。

对于机械臂，$\mathcal C_{\text{obs}}$没有简单的公式：即使是 2R 机械臂附近的一个点障碍物，也会在$(\theta_1,\theta_2)$环面上产生一个弯曲的区域，因为每根连杆在一整族关节值下都会扫过该障碍物。因此机械臂的规划器从不显式构造$\mathcal C_{\text{obs}}$；它们只是询问**碰撞检测器**某个给定的$\mathbf q$是否自由，方法是用正运动学算出连杆的几何形状，并与障碍物的几何形状进行检测。

::: example 2R 机械臂的 C 障碍 {#ex-cspace-arm}
一台$L_1 = L_2 = 1\,\mathrm m$（连杆视为线段）的平面 2R 机械臂与位于$(1.2, 0.6)\,\mathrm m$的一个点障碍物处于同一平面内。$\theta_1 = 0$时哪些位形会发生碰撞？哪些$\theta_1$值有可能发生碰撞？
::: solution
$\theta_1 = 0$时，连杆 1 沿$x$轴位于$[0, 1]$，碰不到障碍物。连杆 2 从$(1, 0)$开始；障碍物的相对位置为$(0.2, 0.6)$，距离$\sqrt{0.04 + 0.36} = 0.632\,\mathrm m < L_2$，方向角为$\operatorname{atan2}(0.6, 0.2) = 71.6^\circ$。所以连杆 2 恰在$\theta_1 + \theta_2 = 71.6^\circ$，即$\theta_2 = 71.6^\circ$时碰到它：在位形空间的直线$\theta_1 = 0$上，障碍物只是一个点。障碍物到基座的距离为$\sqrt{1.44 + 0.36} = 1.342\,\mathrm m$，大于$L_1$，所以连杆 1 永远碰不到它；只有当肘部与障碍物的距离在$1\,\mathrm m$以内，即肘部$(\cos\theta_1, \sin\theta_1)$位于以$(1.2, 0.6)$为圆心、半径为$1$的圆内时，连杆 2 才可能碰到它。障碍物到肘部的距离：$\sqrt{(1.2 - \cos\theta_1)^2 + (0.6 - \sin\theta_1)^2}\le1$给出$2.8 - 2.4\cos\theta_1 - 1.2\sin\theta_1\le1$，即$\cos(\theta_1 - 26.6^\circ)\ge0.6708$，故$\theta_1\in[-21.3^\circ, 74.4^\circ]$。对每个这样的$\theta_1$，恰有一个$\theta_2$发生碰撞：点障碍物在位形空间中变成一条**曲线**。有一定尺寸的真实障碍物则变成环绕这条曲线的一条带，其形状与障碍物在工作空间中的形状毫无关系。
:::
:::

## 图搜索 {#sec-graph-search}

把$\mathcal C_{\text{free}}$离散化——划分成单元格栅格，或构成由采样位形组成的图——规划就变成边代价非负的图上的最短路径问题。**Dijkstra 算法**按从起点出发的已付代价$g(n)$的顺序扩展节点。**A\***按$f(n) = g(n) + h(n)$的顺序扩展节点，其中**启发函数**$h(n)$估计到终点的剩余代价，从而把搜索引向终点。

::: algorithm A* 搜索 {#alg-astar}
输入：边代价$c(n, n')\ge0$的图，起点$s$，终点$t$，启发函数$h$。
1. 令$g(s) = 0$，其余$g(n) = \infty$；把$s$放入优先队列 OPEN，键值为$f(s) = h(s)$；CLOSED 为空。
2. 从 OPEN 中取出$f(n)$最小的节点$n$。若$n = t$，停止，并从$t$沿父指针回溯返回路径。
3. 把$n$移入 CLOSED。对每个不在 CLOSED 中的邻居$n'$：若$g(n) + c(n, n') < g(n')$，则令$g(n') = g(n) + c(n, n')$，parent$(n') = n$，并以键值$f(n') = g(n') + h(n')$将$n'$插入 OPEN 或更新其在 OPEN 中的键值。
4. 若 OPEN 为空，报告不存在路径；否则转到 2。
当$h\equiv0$时，这就是 Dijkstra 算法。
:::

::: definition 可采纳启发函数与一致启发函数 {#def-heuristic}
如果启发函数从不高估，即$h(n)\le h^*(n)$（从$n$到终点的最廉价路径的真实代价），则称它是**可采纳的**（admissible）。如果$h(t) = 0$，且对每条边都有$h(n)\le c(n, n') + h(n')$——一种三角不等式——则称它是**一致的**（consistent）。一致性蕴含可采纳性（沿从$n$到$t$的最优路径把不等式相加即得）。在任何边代价不小于边的欧几里得长度的图上，直线（欧几里得）距离是一致的；在单位步长的 4 连通栅格上，曼哈顿距离是一致的。
:::

::: theorem A* 返回最优路径 {#thm-astar}
若$h$是一致的，则每当 A* 把节点$n$移入 CLOSED 时，$g(n)$都等于最优已付代价$g^*(n)$。特别地，当终点从 OPEN 中取出时返回的路径是最短路径，并且没有节点被扩展两次。
:::

::: proof
**第 1 步：$f$沿任何路径不减。** 对路径上满足$g(n') = g(n) + c(n, n')$的边$n\to n'$，一致性给出$f(n') = g(n) + c(n, n') + h(n')\ge g(n) + h(n) = f(n)$。
**第 2 步：已关闭的节点是最优的。** 用反证法，假设某节点$n$从 OPEN 中取出时$g(n) > g^*(n)$。取一条最优路径$s = n_0, n_1, \dots, n_k = n$。它不可能全部已关闭——否则其最后一条边会从已关闭且$g$最优的$n_{k-1}$被松弛，得到$g(n) = g^*(n)$。设$n_j$是其上第一个未关闭的节点；它的前驱已关闭（或$n_j = s$），按归纳假设已关闭节点的$g$是最优的，则进入$n_j$的边已被松弛，所以$n_j$在 OPEN 中且$g(n_j) = g^*(n_j)$。于是，沿最优路径应用第 1 步，
$$
f(n_j) = g^*(n_j) + h(n_j)\le g^*(n) + h(n) < g(n) + h(n) = f(n),
$$
所以 A* 会在$n$之前取出$n_j$——矛盾。因此当$n$关闭时$g(n) = g^*(n)$。应用于终点，返回的代价是最优的。由于已关闭节点的$g$不可能再减小，它永远不会被重新打开。
:::

该定理对速度只字未提；启发函数的质量决定 A* 扩展多少节点。$h$越接近$h^*$，扩展的节点越少；当$h = h^*$时，只扩展最优路径上的节点。把可采纳启发函数乘以因子$w > 1$（**加权 A\***）会扩展更少的节点，代价是返回的路径可能长达最优路径的$w$倍。

::: example 栅格上 Dijkstra 与 A* 的比较 {#ex-astar}
一个$12\times16$的栅格（4 连通，单位步长代价）中，第 8 列的第 2–9 行是一堵墙；起点在第 6 行第 2 列，终点在第 6 行第 13 列（184 个自由单元格）。比较 Dijkstra 算法、采用曼哈顿启发函数的 A*，以及$w = 2$的加权 A*。
::: solution
直线路线被挡住了；最短路径绕过墙较近的一端：从第 6 行向下到第 10 行（4 步），横穿 11 列，再向上 4 步：代价$4 + 11 + 4 = 19$。三种搜索都返回代价 19（加权 A* 并不保证这一点，但在这里做到了）。它们的区别在于工作量：Dijkstra 扩展了 184 个自由单元格中的 173 个——它向所有方向生长出一个等已付代价的"圆"；采用曼哈顿距离的 A* 扩展了 62 个，因为起点后方的单元格$f$值大于 19，永远不会被触及；加权 A* 扩展了 52 个。（计数来自一种在$f$相同时优先选择$g$较大者的实现。）曼哈顿启发函数在这里是一致的：单位步长使曼哈顿距离恰好改变 1。
:::
:::

::: warning 离散化分辨率决定能找到什么
栅格规划器只是**分辨率完备的**：如果在栅格分辨率下存在路径，它就能找到。比膨胀后栅格的两个单元格还窄的门口可能会完全消失，而在粗栅格上找到的路径可能在栅格点之间擦碰障碍物。栅格规模随维数指数增长——每个关节取 100 个值的 6 自由度机械臂有$10^{12}$个单元格——这就是为什么栅格用于二维和三维的移动机器人规划，而采样方法用于机械臂。栅格路径还呈锯齿状（运动限于 4 个或 8 个方向），在交给轨迹生成器（[[robotics/trajectory-planning]]）之前必须先加以平滑。
:::

## 人工势场 {#sec-potential}

势场规划器把机器人看作处于一个场中的质点，该场把它吸引向终点、使它远离障碍物，并沿负梯度运动。设终点为$\mathbf q_g$，$\rho(\mathbf q)$为到最近障碍物的距离，
$$
U(\mathbf q) = \tfrac12k\lVert\mathbf q - \mathbf q_g\rVert^2 + \begin{cases}\tfrac12\eta\Big(\dfrac1{\rho(\mathbf q)} - \dfrac1{\rho_0}\Big)^2, & \rho(\mathbf q)\le\rho_0,\\ 0, & \rho(\mathbf q) > \rho_0,\end{cases}
\qquad \dot{\mathbf q} = -\nabla U(\mathbf q),
$$ {#eq-potential}
其中$\rho_0$是障碍物的影响范围。当$\rho\to0$时斥力项无界增长，所以机器人永远不会碰到障碍物。该方法速度快、反应灵敏——随着传感器更新，梯度的计算代价很小——但它不是完备的：梯度下降会停在任何$\nabla U = \mathbf 0$的点，而除终点以外的此类**局部极小值**很常见。

::: example 障碍物前方的局部极小值 {#ex-local-minimum}
$x$轴上的一个点机器人被$x = 4$处的终点吸引，$k = 1$；$x = 2$处的一个点障碍物排斥它，$\eta = 1$，$\rho_0 = 1$。从$x = 0$出发，梯度下降停在哪里？
::: solution
当$1\le x < 2$时，距离为$\rho = 2 - x$，沿$+x$方向的力（负梯度）为
$$
F(x) = k(4 - x) - \eta\Big(\frac1\rho - \frac1{\rho_0}\Big)\frac1{\rho^2}.
$$
（斥力势对$\rho$的导数为$-\eta(1/\rho - 1/\rho_0)/\rho^2$，而$d\rho/dx = -1$。）当$x < 1$时只有引力作用，机器人前进。在$x = 1$处$F = 3 > 0$；当$x\to2$时斥力发散。数值求解$F(x) = 0$得$x = 1.443$，即机器人停在障碍物前方$0.557\,\mathrm m$处，而障碍物恰好位于它与终点之间——这是$U$的一个局部极小值（在一维中无路可绕；在平面中它是一个鞍点，一个扰动就能使机器人逃离，但 U 形障碍物会产生真正的极小值）。要逃离它，需要随机游走、设计成只有单一极小值的导航函数，或全局规划器。
:::
:::

::: widget contour

x: -1, 5
y: -2.5, 2.5

caption: 一个光滑化的势场：以终点$(4, 0)$为中心的二次碗形势，加上障碍物$(2, 0)$处的斥力峰$\eta/\rho$（一种简化的、处处起作用的斥力）。拖动该点并沿$-\nabla U$的箭头走：从稍偏离轴线处出发，下降过程绕过障碍物滑向终点；恰好从轴线上出发，则停在障碍物前方的一个鞍点处。增大$\eta$，可以看到驻点从障碍物向后退。
:::

## 基于采样的规划 {#sec-sampling}

对于有六个或更多关节的机械臂，栅格和显式 C 障碍都不实用，但碰撞检测器可以在几微秒内检测单个位形。基于采样的规划器通过随机采样建立由自由位形构成的图，并用简单的局部路径（通常是位形空间中的直线段，以精细的分辨率检测）把它们连接起来。

::: algorithm 概率路线图（PRM） {#alg-prm}
**构建**（每个环境一次）：
1. 在$\mathcal C$中均匀采样$N$个位形；保留其中无碰撞的作为路线图节点。
2. 对每个节点，尝试用直线段把它与其$k$个最近邻（或半径$r$内的所有节点）相连；对每条无碰撞的线段添加一条边。
**查询**：用同样的方法把$\mathbf q_{\text{start}}$和$\mathbf q_{\text{goal}}$连接到附近的节点，然后用 A* 搜索路线图。
:::

::: algorithm 快速扩展随机树（RRT） {#alg-rrt}
1. 以根节点$\mathbf q_{\text{start}}$初始化一棵树。
2. 重复：采样$\mathbf q_{\text{rand}}$（以一个小概率改取$\mathbf q_{\text{goal}}$——"目标偏置"）；找到最近的树节点$\mathbf q_{\text{near}}$；从它朝$\mathbf q_{\text{rand}}$前进距离$\varepsilon$得到$\mathbf q_{\text{new}}$；若从$\mathbf q_{\text{near}}$到$\mathbf q_{\text{new}}$的线段无碰撞，则以$\mathbf q_{\text{near}}$为父节点加入$\mathbf q_{\text{new}}$。
3. 当某节点距终点在$\varepsilon$以内且最后一段无碰撞时停止；返回树上的路径。
:::

RRT 是单次查询的，并且优先向未探索区域生长：距一个均匀随机样本最近的节点，最可能是树前沿上拥有很大沃罗诺伊（Voronoi）区域的节点。两种方法都是**概率完备的**：如果存在一条有一定间隙的路径，则随着样本数增加，找不到它的概率趋于零（对 PRM，按$N$指数衰减）。两者都不是最优的；尤其是 RRT 路径呈锯齿状，事后要加以缩短，而渐近最优的变体 PRM\* 和 RRT\*（Karaman 与 Frazzoli，2011）通过重新连线使图收敛到最短路径。狭窄通道仍然困难：在通道内采样的概率与其体积成正比，而在高维中这个体积可能极小。

::: remark 运动动力学规划
上述直线局部路径假定机器人能跟踪位形空间中的任意路径，这对机械臂成立（任何关节路径都可以按[[robotics/trajectory-planning]]的方法确定时间规律），但对非完整车辆不成立。对于类车机器人，局部规划器用可行曲线（Dubins 路径或 Reeds–Shepp 路径，[[robotics/mobile-robots]]）连接位姿，或者 RRT 通过用采样的控制量对车辆进行短时仿真来扩展节点。
:::

## 相机与立体视觉测深 {#sec-camera}

::: definition 针孔相机 {#def-pinhole}
在相机坐标系中坐标为$(X, Y, Z)$的点（$Z$沿光轴，相机前方$Z > 0$）投影到像素坐标
$$
u = f_x\frac XZ + c_x,\qquad v = f_y\frac YZ + c_y ,
$$ {#eq-pinhole}
其中$f_x$、$f_y$是以像素计的焦距（焦距除以像素尺寸），$(c_x, c_y)$是主点。用齐次坐标表示为$\lambda(u, v, 1)^{\mathsf T} = K(X, Y, Z)^{\mathsf T}$，其中**内参矩阵**$K = \begin{bmatrix} f_x & 0 & c_x\\ 0 & f_y & c_y\\ 0 & 0 & 1\end{bmatrix}$，$\lambda = Z$。在世界坐标系中给出的点，先用相机的位姿进行变换，$\mathbf p_c = T_{cw}\mathbf p_w$（[[robotics/rigid-motions]]）。
:::

单幅图像会丢失深度：穿过某一像素的射线上的每个点都投影到同一像素。两台相机可以恢复深度。

::: proposition 校正后立体像对的深度 {#prop-stereo}
两台焦距为$f$（像素）的相同针孔相机光轴平行，沿其共同的$x$轴相距**基线**$B$。深度为$Z$的点在两幅图像中出现的**视差**为$d = u_L - u_R$，并且
$$
Z = \frac{fB}{d},\qquad \delta Z \approx \frac{Z^2}{fB}\,\delta d ,
$$
因此固定的视差误差$\delta d$（通常为几分之一像素）所造成的深度误差随深度的平方增长。
:::

::: proof
在左相机中该点的坐标为$(X, Y, Z)$；在沿$x$方向平移了$B$的右相机中，其坐标为$(X - B, Y, Z)$。由[[#eq-pinhole]]，$u_L = fX/Z + c_x$，$u_R = f(X - B)/Z + c_x$，故$d = u_L - u_R = fB/Z$，$Z = fB/d$。求导得$dZ/dd = -fB/d^2 = -Z^2/(fB)$，所以在一阶近似下$\lvert\delta Z\rvert = Z^2\lvert\delta d\rvert/(fB)$。
:::

::: example 移动机器人上的立体相机 {#ex-stereo}
一台立体相机的$f = 700$像素，基线$B = 0.12\,\mathrm m$。某特征出现在$u_L = 361$和$u_R = 340$处。求其深度以及视差误差为$\pm0.5$像素时的深度不确定度；再对位于$12\,\mathrm m$处的特征重复计算。
::: solution
$d = 21$像素，$Z = 700\times0.12/21 = 4.0\,\mathrm m$，$\delta Z = 4.0^2\times0.5/84 = 0.095\,\mathrm m$（2.4%）。在$12\,\mathrm m$处：$d = 84/12 = 7$像素，$\delta Z = 144\times0.5/84 = 0.86\,\mathrm m$（7%）。距离变为三倍，误差变为九倍。更长的基线和焦距按比例改善精度，这就是为什么户外车辆的立体相机头很宽，而紧凑的室内传感器只在几米之内准确。
:::
:::

## 卡尔曼滤波 {#sec-kalman}

机器人通过把运动模型给出的**预测**与**测量**结合起来估计自身状态，而两者都有不确定性。当模型是线性的、噪声是高斯的时，[[robotics/mobile-robots]]中的贝叶斯滤波使置信度保持为高斯分布，其递推归结为更新均值和方差（或协方差矩阵）：这就是**卡尔曼滤波**。其核心是两个独立估计的融合。

::: proposition 两个估计的最优融合 {#prop-fusion}
设$\hat x^-$是标量$x$的无偏估计，方差为$P^-$；$z = x + w$是一个测量，其噪声与之独立、均值为零、方差为$R$。在所有形如$\hat x = \hat x^- + K(z - \hat x^-)$的估计中，使方差最小的是**卡尔曼增益**
$$
K = \frac{P^-}{P^- + R},\qquad\text{由此}\qquad P = (1 - K)P^- = \frac{P^-R}{P^- + R},\quad \frac1P = \frac1{P^-} + \frac1R .
$$
若两个误差都是高斯的，则$\hat x$和$P$就是后验分布$p(x\mid z)$的均值和方差。
:::

::: proof
融合估计的误差为$\hat x - x = (1 - K)(\hat x^- - x) + Kw$，是两个独立的零均值误差的组合，因此它是无偏的，方差为$P(K) = (1 - K)^2P^- + K^2R$。这是$K$的一个凸二次函数；令$dP/dK = -2(1 - K)P^- + 2KR = 0$得$K = P^-/(P^- + R)$。代入得$1 - K = R/(P^- + R)$，$P = \frac{R^2P^- + (P^-)^2R}{(P^- + R)^2} = \frac{P^-R}{P^- + R}$，等价于$1/P = 1/P^- + 1/R$。关于高斯情形的结论：由贝叶斯公式$p(x\mid z)\propto\exp\!\big(-\frac{(x - \hat x^-)^2}{2P^-} - \frac{(z - x)^2}{2R}\big)$；指数是$x$的二次式，$-x^2/2$的系数为$1/P^- + 1/R = 1/P$，配方后得均值$P(\hat x^-/P^- + z/R) = \hat x^- + K(z - \hat x^-)$。
:::

融合后的方差比任何一个都小：信息（方差的倒数）相加。增益按测量相对于预测的可信程度对测量加权——对完美的传感器$K\to1$，对毫无用处的传感器$K\to0$。完整的滤波器使这一**更新**与**预测**交替进行：对状态模型$x_k = x_{k-1} + u_k + n_k$（运动$u_k$，过程噪声方差为$Q$），预测为$\hat x_k^- = \hat x_{k-1} + u_k$，$P_k^- = P_{k-1} + Q$。在矢量情形下，同样的步骤写为$\hat{\mathbf x}^- = F\hat{\mathbf x} + G\mathbf u$，$P^- = FPF^{\mathsf T} + Q$，$K = P^-H^{\mathsf T}(HP^-H^{\mathsf T} + R)^{-1}$，$\hat{\mathbf x} = \hat{\mathbf x}^- + K(\mathbf z - H\hat{\mathbf x}^-)$，$P = (I - KH)P^-$。对于机器人的非线性模型（运动中的独轮车、观测路标的距离-方位传感器），**扩展卡尔曼滤波**在当前估计处对模型线性化，用它们的雅可比矩阵代替$F$和$H$。

::: example 融合里程计与测距 {#ex-kalman}
走廊中的一台机器人根据里程计认为自己距尽头墙壁$\hat x^- = 2.00\,\mathrm m$，标准差为$0.20\,\mathrm m$。一个超声波传感器测得$z = 2.30\,\mathrm m$，标准差为$0.10\,\mathrm m$。将它们融合。然后机器人又行驶$1.0\,\mathrm m$，里程计噪声的标准差为$0.10\,\mathrm m$：预测的置信度是什么？
::: solution
$P^- = 0.04\,\mathrm{m^2}$，$R = 0.01\,\mathrm{m^2}$，$K = 0.04/0.05 = 0.8$。$\hat x = 2.00 + 0.8\times0.30 = 2.24\,\mathrm m$，$P = 0.2\times0.04 = 0.008\,\mathrm{m^2}$，标准差$0.089\,\mathrm m$——优于单独使用传感器（$0.10$）。估计值位于向更精确的测量靠拢五分之四处。
预测：$\hat x^- = 3.24\,\mathrm m$，$P^- = 0.008 + 0.010 = 0.018\,\mathrm{m^2}$，标准差$0.134\,\mathrm m$。不确定性在运动中增大，在每次测量时减小；如果没有测量，它就会像里程计那样无界增长。
:::
:::

::: quiz
一台机器人的位置估计方差为$0.09\,\mathrm{m^2}$，一个独立测量的方差也为$0.09\,\mathrm{m^2}$。融合后的方差是多少？
- [ ] $0.09\,\mathrm{m^2}$：同等的信息不能改善估计
- [x] $0.045\,\mathrm{m^2}$
- [ ] $0.18\,\mathrm{m^2}$
- [ ] $0.03\,\mathrm{m^2}$
::: solution
$1/P = 1/0.09 + 1/0.09$，故$P = 0.045\,\mathrm{m^2}$，$K = 0.5$：融合估计是两者的平均值，方差减半（标准差减小为原来的$1/\sqrt2$）。
:::

::: history
哈特（Peter Hart）、尼尔森（Nils Nilsson）和拉斐尔（Bertram Raphael）于 1968 年为 SRI 的 Shakey 机器人项目发表了 A* 算法，用启发函数扩展了迪杰斯特拉（Edsger Dijkstra）1959 年的最短路径算法。洛萨诺-佩雷斯（Tomás Lozano-Pérez）1983 年的论文《空间规划：一种位形空间方法》（"Spatial planning: a configuration space approach"，发表于 IEEE Transactions on Computers）使位形空间成为运动规划的标准框架。哈提卜（Oussama Khatib）1986 年发表在《国际机器人研究杂志》（*International Journal of Robotics Research*）上的论文引入了用于实时避障的人工势场。卡夫拉基（Lydia Kavraki）、Švestka、拉托姆（Jean-Claude Latombe）和奥弗马斯（Mark Overmars）于 1996 年发表了概率路线图，拉瓦勒（Steven LaValle）于 1998 年在一份技术报告中提出了快速扩展随机树。卡尔曼（Rudolf Kálmán）1960 年的论文《线性滤波与预测问题的新方法》（"A new approach to linear filtering and prediction problems"）给出了以他的名字命名的递推滤波器；它很快被用于阿波罗计划的导航，至今仍是机器人状态估计的核心。
:::

::: summary
- 规划在位形空间中进行；平移机器人的 C 障碍是闵可夫斯基和$\mathcal O\oplus(-\mathcal A_0)$（按圆盘机器人的半径膨胀障碍物）；对于机械臂，用正运动学逐点检测碰撞。
- A* 按$f = g + h$扩展节点；采用一致（因而可采纳）的启发函数时，它返回最优路径，并且每个节点只关闭一次；更好的启发函数扩展更少的节点。栅格是分辨率完备的，其规模随维数指数增长。
- 势场$U = \frac12k\lVert\mathbf q - \mathbf q_g\rVert^2 + U_{\text{rep}}$速度快、反应灵敏，但会困在局部极小值中。
- PRM（多次查询路线图）和 RRT（单次查询树）是概率完备的，能处理高维位形空间；RRT\*/PRM\* 是渐近最优的；狭窄通道是难点。
- 针孔相机$u = f_xX/Z + c_x$；立体视觉深度$Z = fB/d$，误差$\delta Z = Z^2\delta d/(fB)$，随深度的平方增长。
- 卡尔曼滤波：先预测（$P^- = P + Q$），再以增益$K = P^-/(P^- + R)$更新；信息相加，$1/P = 1/P^- + 1/R$。EKF 对非线性的机器人模型和传感器模型进行线性化。
:::

::: exercise 膨胀障碍物 {#exr-grown level=1 check="2.4827"}
一个半径为$0.3\,\mathrm m$的圆盘机器人在障碍物之间运动；其中一个障碍物是$1\,\mathrm m\times1\,\mathrm m$的正方形。相应 C 障碍的面积是多少？（以$\mathrm{m^2}$为单位输入，保留四位小数。）
::: solution
膨胀后的正方形由正方形本身（$1$）、沿四条边的四个$1\times0.3$矩形（$1.2$）以及四个角上合成一个半径$0.3$整圆的四个四分之一圆（$0.09\pi = 0.2827$）组成：共$2.4827\,\mathrm{m^2}$，是障碍物面积的两倍半。一般地，对面积为$A$、周长为$P$的凸障碍物，膨胀后的面积为$A + P\rho + \pi\rho^2$。

一套立体装置的$f = 700$像素，$B = 0.12\,\mathrm m$；某特征的视差为 21 像素。它的深度是多少？（以 m 为单位输入$Z$。）
::: solution
$Z = fB/d = 84/21 = 4.0\,\mathrm m$。
:::

::: exercise 立体视觉深度误差 {#exr-stereo-error level=2 check="0.0952"}
对上一题的装置，在$Z = 4\,\mathrm m$处$0.5$像素的视差误差会造成多大的深度误差？（以 m 为单位输入$\delta Z$，保留四位小数。）
::: solution
$\delta Z = Z^2\delta d/(fB) = 16\times0.5/84 = 0.0952\,\mathrm m$。精确地说，视差范围$21\pm0.5$给出深度$84/21.5 = 3.907$和$84/20.5 = 4.098\,\mathrm m$，即误差为$-0.093$和$+0.098\,\mathrm m$——线性化值以很好的精度等于两者的平均值，而真实误差略不对称。
:::

::: exercise 栅格上的对角路径 {#exr-octile level=2 check="3*sqrt(2) + 2"}
在一个空的 8 连通栅格上，直行一步代价为 1，斜行一步代价为$\sqrt2$。从单元格$(0, 0)$到单元格$(5, 3)$的最短路径代价是多少？证明"八方向"（octile）距离$\max(\lvert\Delta x\rvert, \lvert\Delta y\rvert) + (\sqrt2 - 1)\min(\lvert\Delta x\rvert, \lvert\Delta y\rvert)$就是这一代价。（精确输入代价——可以输入诸如 3*sqrt(2) + 2 的表达式。）
::: solution
用 3 步斜行（在每个方向上各走 3）和 2 步直行：$3\sqrt2 + 2 = 6.243$。任何路径至少需要$\max = 5$步，并且在次要方向上至少移动$\min = 3$个单位；次要方向上每移动一个单位，需要一步斜行（代价$\sqrt2$）或单独一步直行（代价 1，外加主要方向上仍需的那一步直行），所以斜行最便宜，得到$3\sqrt2 + (5 - 3) = 5 + (\sqrt2 - 1)\times3$ ✓。由于它是无障碍时的精确代价，八方向距离是此类栅格上 A* 的一致启发函数，比欧几里得距离更紧。
:::
:::

::: exercise 卡尔曼融合 {#exr-fusion level=2 check="0.008"}
在[[#ex-kalman]]中，用$1/P = 1/P^- + 1/R$验证融合后的方差。（以$\mathrm{m^2}$为单位输入$P$。）
::: solution
$1/P = 1/0.04 + 1/0.01 = 25 + 100 = 125\,\mathrm{m^{-2}}$，$P = 0.008\,\mathrm{m^2}$ ✓。传感器贡献的信息是先验的四倍，所以它获得权重$100/125 = 0.8 = K$。
:::
:::

::: exercise 稳态卡尔曼增益 {#exr-steady level=3 check="0.3904"}
一台机器人的位置服从$x_k = x_{k-1} + u_k + n_k$，每步过程噪声方差$Q = 0.01\,\mathrm{m^2}$，并且每步测量一次位置，噪声方差$R = 0.04\,\mathrm{m^2}$。证明预测方差收敛到$(P^-)^2 - QP^- - QR = 0$的正根，并求稳态增益。（输入$K$，保留四位小数。）
::: solution
一个周期把$P^-_k$映射为$P_k = P^-_kR/(P^-_k + R)$，然后$P^-_{k+1} = P_k + Q$。不动点满足$P^- = \frac{P^-R}{P^- + R} + Q$；乘以$P^- + R$：$(P^-)^2 + P^-R = P^-R + QP^- + QR$，即$(P^-)^2 - QP^- - QR = 0$，其正根为$P^- = \frac{Q + \sqrt{Q^2 + 4QR}}{2} = \frac{0.01 + \sqrt{0.0001 + 0.0016}}{2} = 0.025616\,\mathrm{m^2}$。（该映射关于$P^-$是递增且上凸的，所以从任何正初值出发，迭代都收敛到这个不动点。）于是$K = P^-/(P^- + R) = 0.025616/0.065616 = 0.3904$，稳态后验方差为$(1 - K)P^- = 0.01562\,\mathrm{m^2}$（标准差$0.125\,\mathrm m$，优于传感器的$0.2\,\mathrm m$）。
:::
:::

::: exercise 一致性蕴含可采纳性 {#exr-consistent level=3}
证明一致启发函数是可采纳的，并用一个小例子说明可采纳启发函数不一定是一致的。
::: solution
设$n = n_0, n_1, \dots, n_k = t$是从$n$到终点的一条最优路径。一致性给出$h(n_i)\le c(n_i, n_{i+1}) + h(n_{i+1})$；对$i = 0, \dots, k-1$求和并逐项相消，得$h(n)\le\sum c(n_i, n_{i+1}) + h(t) = h^*(n) + 0$。反例：一条边代价均为 1 的路径$s\to a\to t$，取$h(s) = 2$，$h(a) = 0$，$h(t) = 0$。它是可采纳的（$h^*(s) = 2$，$h^*(a) = 1$），但$h(s) = 2 > c(s, a) + h(a) = 1$，所以它不是一致的：沿路径$f$从$f(s) = 2$降到$f(a) = 1$。采用不一致但可采纳的启发函数时，如果允许重新打开已关闭的节点，A* 仍返回最优路径，但可能会多次扩展同一节点。
:::
:::

::: exercise 选择规划器 {#exr-design level=3}
对下列每种场景选择一种规划方法并说明理由：(a) 一台仓库机器人（差速驱动，半径$0.4\,\mathrm m$）在已绘制成$5\,\mathrm{cm}$占据栅格的货架通道中导航；(b) 一台 7 自由度机械臂伸入杂乱的货架，每次都是新场景；(c) 一个固定的装配单元，其中一台 6 自由度机械臂在许多已知工位之间重复运动长达数月；(d) 一架无人机躲避突然出现的行人。
::: solution
(a) 按机器人半径加上裕量膨胀栅格（[[#prop-minkowski]]），在二维栅格上采用欧几里得或八方向启发函数运行 A*（或用于重规划的 D\*-Lite）；平滑路径，并用纯追踪进行跟踪；差速驱动能原地转向，所以二维点路径是可执行的。(b) 单次查询、高维、未知场景：采用 RRT 的一种变体（双向 RRT-Connect），以货架的点云或网格进行碰撞检测，随后进行路径捷径化和时间标度。(c) 固定环境中的多次查询：一次性构建 PRM（或预先计算并验证特定路径），之后每次查询用图搜索在几毫秒内作答。(d) 对移动障碍物的快速反应：以传感器频率运行的反应式局部方法（势场或速度障碍法避障），与提供航路点的全局规划器相结合——局部方法的局部极小值由全局规划来摆脱。在每种情况下，规划器的输出在执行前都必须对照机器人的动力学进行检查并确定时间规律。
:::

## 延伸阅读

Lynch 与 Park 的教材以及 LaValle 的《规划算法》（*Planning Algorithms*，可免费在线获取）深入论述位形空间、图搜索、势场和基于采样的规划；Thrun、Burgard 与 Fox 的教材发展了用于定位与建图的卡尔曼滤波和粒子滤波；Siegwart、Nourbakhsh 与 Scaramuzza 的教材讲述移动机器人的相机、立体视觉和测距传感器。
