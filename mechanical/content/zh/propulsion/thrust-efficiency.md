飞机发动机、船用螺旋桨、直升机旋翼和火箭的工作方式都相同：它们把一股流体向后推，反作用力把飞行器向前推。它们的区别在于推动**多少**流体、推得**多猛**。火箭把少量自身携带的推进剂以每秒数千米的速度向后抛出；涡轮风扇发动机把每秒数百千克的空气加速几百米每秒；螺旋桨或旋翼则以更小的速度增量加速更多的空气。本章把这幅图景变成数字。我们由控制体动量平衡导出推进装置的推力，定义全行业通用的燃油经济性指标——单位推力、推力耗油率和比冲——并把燃料能量转换为推力功率的过程分解为热效率和推进效率。本章最重要的结果——推进效率$\eta_p = 2/(1 + V_e/V_0)$——解释了为什么客机发动机长出了巨大的风扇、为什么战斗机发动机没有，以及为什么火箭只有在高速飞行时才有效率。最后我们讨论布雷盖（Breguet）航程方程，它把发动机效率与飞机能飞多远联系起来。

先修知识是控制体的动量方程和能量方程（[[fluid-mechanics/control-volume-analysis]]），以及稳定流动能量方程和循环效率（[[thermodynamics/first-law-open]]、[[thermodynamics/power-cycles]]）。

## 物理图景

从地面观察一架客机。在发动机前方很远处，空气是静止的；在发动机后方，射流相对发动机向后冲出的速度比飞机的飞行速度更快。在发动机坐标系中（分析时采用这个坐标系，因为此时流动是定常的），空气以飞行速度$V_0$到达，以射流速度$V_e > V_0$离开。因此发动机每秒给流经它的空气增加向后的动量$\dot m\,(V_e - V_0)$，根据牛顿（Newton）第三定律，空气以大小相同的力把发动机向前推。这就是推力。

有两个因素使这幅简单的图景复杂化。第一，发动机加入了燃料，所以离开的质量略多于进入的质量。第二，射流离开时的压强未必等于环境压强：不能使燃气完全膨胀的喷管，其出口截面上的压强高于环境压强，这个压强差作用在出口面积上，会产生附加的力。仔细的控制体分析可以把这两者都包括进来。

第三点是记账问题，而不是物理问题。进入发动机的空气在发动机坐标系中具有动量$\dot m_0 V_0$；把它吸入需要付出力$\dot m_0 V_0$，这就是**冲压阻力**（ram drag）或**动量阻力**。试车台上静止的发动机没有冲压阻力；同一台发动机在巡航时，其静推力的很大一部分被冲压阻力抵消。这就是为什么即使射流速度增大，发动机推力仍随飞行速度下降。

## 由控制体动量平衡求推力

::: definition 截面编号与质量流量 {#def-stations}
我们在发动机自身的坐标系中跟踪发动机：上游远处的自由流为**截面 0**（速度$V_0$，静压$p_0$，进入发动机的空气质量流量$\dot m_0$），喷管出口为**截面 e**（在[[propulsion/gas-turbine-cycles]]的发动机截面编号中称为截面 9），射流在那里的平均轴向速度为$V_e$、静压为$p_e$、面积为$A_e$。燃料以质量流量$\dot m_f$加入，所以**油气比**为$f = \dot m_f/\dot m_0$，出口质量流量为$\dot m_e = \dot m_0 + \dot m_f = (1+f)\,\dot m_0$。对燃烧煤油的燃气涡轮发动机，$f$通常为$0.015$–$0.03$。
:::

::: proposition 推力方程 {#prop-thrust}
对定常流动中的推进装置，若出口截面上的参数均匀，且除射流出口外控制体每一边界上的周围流动都处于自由流压强$p_0$，则**非安装推力**（发动机作用在其安装结构上的净轴向力）为
$$
F = \dot m_e V_e - \dot m_0 V_0 + (p_e - p_0)\,A_e .
$$ {#eq-thrust}
其中$\dot m_e V_e$项为**动量推力**，$(p_e - p_0)A_e$为**压力推力**，两者之和为**总推力**$F_G$，$\dot m_0 V_0$为**冲压阻力**：$F = F_G - \dot m_0 V_0$。
:::

::: proof
取流动为定常的发动机坐标系，在发动机周围画一个横截面积为$A$的大圆柱形控制体（即 Hill 和 Peterson 的“流管”控制体）。其前端面在上游远处，那里各处的速度为$V_0$、压强为$p_0$。其后端面穿过喷管出口截面：在射流面积$A_e$上，参数为$V_e$、$p_e$；在其余面积$A - A_e$上，外流未受扰动，为$V_0$和$p_0$。圆柱侧面离发动机足够远，其上的压强为$p_0$，但空气可以以流量$\dot m_s$穿过侧面，并携带轴向速度$V_0$。控制体还切过发动机的安装吊挂，结构通过吊挂向发动机传递轴向力$F$（向前、即逆着流动方向为正）。燃料通过吊挂进入，在此坐标系中不带轴向动量。

**质量守恒。** 通过前端面的流入量$\rho_0 V_0 A$加上燃料$\dot m_f$，等于通过射流的流出量$\dot m_e$、通过后端面其余部分的流出量$\rho_0 V_0 (A - A_e)$与通过侧面的流出量$\dot m_s$之和：
$$
\rho_0 V_0 A + \dot m_f = \dot m_e + \rho_0 V_0 (A - A_e) + \dot m_s
\quad\Longrightarrow\quad
\dot m_s = \rho_0 V_0 A_e - \dot m_0 ,
$$
其中用到了$\dot m_e - \dot m_f = \dot m_0$。

**轴向动量**（以下游、即流动方向为正）。设$R$为吊挂作用在发动机上的轴向力，以指向下游为正。作用在控制体内物质上的其他轴向力是前端面上的压力$+p_0 A$和后端面上的压力$-p_e A_e - p_0(A - A_e)$；圆柱侧面上的压力没有轴向分量。这些力之和等于轴向动量的净流出率（燃料不带入动量）：
$$
R + p_0 A - p_e A_e - p_0 (A - A_e)
= \dot m_e V_e + \rho_0 V_0^2 (A - A_e) + \dot m_s V_0 - \rho_0 V_0^2 A .
$$
左边的压力项化简为$-(p_e - p_0)A_e$。在右边，代入$\dot m_s = \rho_0 V_0 A_e - \dot m_0$后，所有含$\rho_0 V_0^2$的项都相消，剩下$\dot m_e V_e - \dot m_0 V_0$。因此
$$
R = \dot m_e V_e - \dot m_0 V_0 + (p_e - p_0)A_e .
$$
当发动机使流动加速时，$R > 0$：吊挂必须把发动机**向下游**推，才能使它保持不动。根据牛顿第三定律，发动机以大小相同的力把吊挂、并连同吊挂把飞机**向前**推，这就是推力：$F = R$。

大面积$A$和侧向流动都相消了，这正是这种构造的全部意义：只有进口远场和出口截面的参数才起作用。

所用**假设**：在发动机坐标系中流动定常；射流出口上的速度和压强均匀；射流以外的整个控制面上压强为$p_0$；侧向流出的轴向速度为$V_0$；控制面上的黏性应力可忽略；燃料不带入轴向动量。短舱和吊挂的外部阻力被有意排除在外而计入飞机——这就是**非安装**的含义。
:::

对[[#eq-thrust]]有两点说明。第一，压力推力是真实存在的，但并非白得：使$p_e > p_0$的喷管没有把全部可用的焓转换为射流速度；在[[propulsion/inlets-nozzles]]中我们将证明，对给定的喷管流动，当$p_e = p_0$（喷管**完全膨胀**）时总推力最大。第二，冲压阻力不是通常意义上的气动阻力；它是发动机必须给予以飞行速度吸入的空气的动量。

::: definition 有效排气速度，单位推力 {#def-specific-thrust}
**有效排气速度**$c$把动量推力和压力推力合并为一个速度：
$$
c = V_e + \frac{(p_e - p_0)A_e}{\dot m_e},
\qquad
F_G = \dot m_e\, c ,
$$
对完全膨胀的喷管，$c = V_e$。吸气式发动机的**单位推力**是单位空气质量流量的推力$F/\dot m_0$，单位为$\mathrm{N\,s/kg}$（量纲上是速度，$\mathrm{m/s}$）。对完全膨胀的喷管，
$$
\frac{F}{\dot m_0} = (1+f)\,V_e - V_0 \approx V_e - V_0 .
$$
单位推力高意味着对给定推力发动机小而轻；这正是战斗机或超声速发动机所需要的。
:::

::: example 涡轮喷气发动机巡航时的推力与效率 {#ex-turbojet-cruise}
一台涡轮喷气发动机以$V_0 = 250\ \mathrm{m/s}$飞行，空气质量流量$\dot m_0 = 50\ \mathrm{kg/s}$，油气比$f = 0.020$；其喷管完全膨胀，射流以$V_e = 600\ \mathrm{m/s}$离开。燃料的低热值$h_{PR} = 43\ \mathrm{MJ/kg}$。求推力、推力耗油率以及热效率、推进效率和总效率（定义见下一节）。
::: solution
**推力。** 由于$p_e = p_0$，[[#eq-thrust]]给出
$$
F = \dot m_0\left[(1+f)V_e - V_0\right] = 50\left[1.020 \times 600 - 250\right] = 50 \times 362 = 18\,100\ \mathrm{N} = 18.1\ \mathrm{kN}.
$$
冲压阻力$\dot m_0 V_0 = 12.5\ \mathrm{kN}$是总推力$30.6\ \mathrm{kN}$的五分之二：巡航时射流的大部分“功”用于克服来流空气的动量。

**燃油消耗。** $\dot m_f = f\dot m_0 = 1.00\ \mathrm{kg/s}$，所以
$$
\mathrm{TSFC} = \frac{\dot m_f}{F} = \frac{1.00}{18\,100} = 5.52\times10^{-5}\ \mathrm{kg/(N\,s)} = 55.2\ \mathrm{g/(kN\,s)}.
$$

**效率。** 发动机提高气流动能的速率为
$$
\Delta\dot K = \tfrac12\left[\dot m_e V_e^2 - \dot m_0 V_0^2\right] = \tfrac12\left[51.0 \times 600^2 - 50 \times 250^2\right] = 7.62\ \mathrm{MW}.
$$
推力功率为$F V_0 = 18\,100 \times 250 = 4.53\ \mathrm{MW}$，燃料功率为$\dot m_f h_{PR} = 43.0\ \mathrm{MW}$。因此
$$
\eta_{th} = \frac{7.62}{43.0} = 0.177,\qquad
\eta_p = \frac{4.53}{7.62} = 0.594,\qquad
\eta_o = \frac{4.53}{43.0} = 0.105 = \eta_{th}\,\eta_p .
$$
**校核。** 简单公式$\eta_p = 2/(1 + V_e/V_0) = 2/3.4 = 0.588$（忽略燃料质量）与之相差不到 1 %。约 10 % 的总效率和高于$50\ \mathrm{g/(kN\,s)}$的 TSFC 是早期低增压比涡轮喷气发动机的典型值；正如我们将看到的，现代涡轮风扇发动机要好三到四倍。
:::
:::

## 耗油率与比冲

::: definition 推力耗油率与比冲 {#def-tsfc}
**推力耗油率**是单位推力的燃油质量流量：
$$
\mathrm{TSFC} = \frac{\dot m_f}{F}\quad[\mathrm{kg/(N\,s)}],
$$
通常以$\mathrm{g/(kN\,s)}$给出，它与$\mathrm{mg/(N\,s)}$相同。（较早的数据和美国数据使用$\mathrm{lb/(lbf\,h)}$；$1\ \mathrm{lb/(lbf\,h)} = 28.33\ \mathrm{g/(kN\,s)}$。）**比冲**是消耗单位**重量**推进剂所提供的冲量：
$$
I_{sp} = \frac{F}{\dot m_p\, g_0}\quad[\mathrm{s}],\qquad g_0 = 9.80665\ \mathrm{m/s^2},
$$
其中$\dot m_p$是飞行器自身携带的推进剂的质量流量：对吸气式发动机只是燃料（空气是免费的），所以$I_{sp} = 1/(g_0\,\mathrm{TSFC})$；对火箭是燃料加氧化剂，所以$I_{sp} = c/g_0$。
:::

这两个指标从相反的方向描述同一件事：TSFC 低为好，$I_{sp}$高为好。吸气式发动机通常用 TSFC 表示，火箭则用$I_{sp}$表示。作为参考（公开数据，仅表示数量级）：现代大涵道比涡轮风扇发动机巡航时的 TSFC 约为$14$–$16\ \mathrm{g/(kN\,s)}$，相当于$I_{sp} \approx 6500$–$7300\ \mathrm{s}$；开加力的超声速涡轮喷气发动机的耗油要多好几倍；液氢-液氧火箭在真空中达到$I_{sp} \approx 450\ \mathrm{s}$，这个数字看起来很差，但别忘了火箭还要携带自己的氧化剂。

::: warning 静推力不是巡航推力，而且 TSFC 取决于速度
发动机宣传资料给出的是海平面静推力（$V_0 = 0$，无冲压阻力）。巡航时，冲压阻力$\dot m_0 V_0$和低空气密度使大涵道比涡轮风扇发动机的可用推力降到起飞额定推力的约五分之一，而且巡航时的 TSFC 比试车台上**更高**，尽管发动机在巡航时效率更高。TSFC 是单位**力**的燃油消耗，而效率关乎功率$F V_0$：在$V_0 = 0$时，发动机提供推力但不提供推力功率，无论其 TSFC 是多少，总效率都为零。切勿把在不同飞行速度下得到的 TSFC 值当作效率的度量来比较——应比较$\eta_o = V_0/(\mathrm{TSFC}\,h_{PR})$（见[[#prop-overall]]）。
:::

## 热效率、推进效率与总效率

发动机分两个阶段把燃料中的化学能转换为推力功率：首先，循环把热转换为气流动能的增加（热机）；然后，这部分动能被转换为对飞行器所做的有用功（推进器）。每个阶段的效率分别定义。

::: definition 热效率、推进效率与总效率 {#def-efficiencies}
设$\Delta\dot K = \tfrac12\left(\dot m_e V_e^2 - \dot m_0 V_0^2\right)$为流经发动机的气流动能的增加率（在发动机坐标系中），$h_{PR}$为燃料的低热值，则
$$
\eta_{th} = \frac{\Delta\dot K}{\dot m_f\, h_{PR}},\qquad
\eta_p = \frac{F\,V_0}{\Delta\dot K},\qquad
\eta_o = \frac{F\,V_0}{\dot m_f\, h_{PR}} = \eta_{th}\,\eta_p .
$$
**热效率**把发动机作为热机来衡量；**推进效率**衡量所产生的动能中有多少变成有用的推力功率；**总效率**是两者的乘积。对涡轮螺旋桨或涡轮轴发动机，$\Delta\dot K$用输出的轴功率加上射流动能的增加量代替。
:::

::: proposition 射流的推进效率 {#prop-propulsive}
对完全膨胀的射流（$p_e = p_0$），若燃料质量可忽略（$f \ll 1$，于是$\dot m_e = \dot m_0 = \dot m$），则
$$
\eta_p = \frac{2V_0}{V_e + V_0} = \frac{2}{1 + V_e/V_0},
$$ {#eq-etap}
未转换为推力功率的那部分功率，恰好是静止观察者看到的留在尾流中的动能，即单位时间$\tfrac12\dot m\,(V_e - V_0)^2$。
:::

::: proof
当$f \to 0$且$p_e = p_0$时，[[#eq-thrust]]化为$F = \dot m (V_e - V_0)$。动能增加率为
$$
\Delta\dot K = \tfrac12 \dot m\,(V_e^2 - V_0^2) = \tfrac12 \dot m\,(V_e - V_0)(V_e + V_0) = \tfrac12 F\,(V_e + V_0),
$$
所以$\eta_p = F V_0/\Delta\dot K = 2V_0/(V_e + V_0)$。差值
$$
\Delta\dot K - F V_0 = \tfrac12\dot m\left(V_e^2 - V_0^2\right) - \dot m (V_e - V_0)V_0 = \tfrac12\dot m\,(V_e - V_0)^2
$$
是动能沉积到大气中的速率：在地面坐标系中，空气原来静止，之后以$V_e - V_0$向后运动。假设：[[#prop-thrust]]的假设，再加上$p_e = p_0$和$f \ll 1$；计入$f$只使$\eta_p$改变约百分之一（[[#ex-turbojet-cruise]]）。
:::

[[#eq-etap]]包含了推进的核心矛盾。单位质量流量的推力为$V_e - V_0$，所以**紧凑**的发动机需要大的速度增量；而推进效率只有当$V_e \to V_0$时才趋于 1，这需要小的速度增量，因而对给定推力需要巨大的质量流量。起飞时的火箭（$V_0 = 0$）$\eta_p = 0$；$V_e/V_0 \approx 2.5$的战斗机发动机$\eta_p \approx 0.57$；巡航时外涵气流$V_e/V_0 \approx 1.3$–$1.4$的大涵道比涡轮风扇发动机达到$\eta_p \approx 0.85$；把一个非常大的流管加速百分之几的螺旋桨，在低速时还要更好。[[propulsion/gas-turbine-cycles]]和[[propulsion/propellers]]中的每一种发动机，都是沿这条曲线所作的不同折中。

::: quiz
两台发动机在相同飞行速度下产生相同的推力。发动机 A 的质量流量是发动机 B 的两倍。下列哪种说法正确？
- [ ] A 的射流速度更高，推进效率也更高。
- [x] A 的射流速度更低，推进效率更高。
- [ ] 两者推进效率相同，因为推力相同。
- [ ] A 的推进效率更低，因为它必须加速更多的空气。
::: solution
推力相等时，$\dot m (V_e - V_0)$固定，所以$\dot m$加倍使速度增量$V_e - V_0$减半。更小的$V_e/V_0$给出更大的$\eta_p = 2/(1 + V_e/V_0)$。浪费在尾流中的动能$\tfrac12 \dot m (V_e - V_0)^2 = \tfrac12 F (V_e - V_0)$减半。
:::
:::

::: example 为什么客机有大风扇 {#ex-big-fan}
一架客机在$V_0 = 240\ \mathrm{m/s}$时每台发动机需要$F = 100\ \mathrm{kN}$的推力。比较 (a) 用$\dot m = 200\ \mathrm{kg/s}$实现这一推力的发动机和 (b) 用$\dot m = 1000\ \mathrm{kg/s}$的发动机，两者都完全膨胀，燃料质量可忽略。若两台发动机以相同的热效率产生动能，(b) 使燃油流量减少多少比例？
::: solution
(a) $V_e - V_0 = F/\dot m = 500\ \mathrm{m/s}$，所以$V_e = 740\ \mathrm{m/s}$，$\eta_p = 2/(1 + 740/240) = 0.490$。
(b) $V_e - V_0 = 100\ \mathrm{m/s}$，$V_e = 340\ \mathrm{m/s}$，$\eta_p = 2/(1 + 340/240) = 0.828$。

发动机核心机必须向气流提供的功率为$\Delta\dot K = \tfrac12 F (V_e + V_0)$：
$$
\Delta\dot K_a = \tfrac12 \times 10^5 \times 980 = 49.0\ \mathrm{MW},\qquad
\Delta\dot K_b = \tfrac12 \times 10^5 \times 580 = 29.0\ \mathrm{MW}.
$$
两者提供相同的推力功率$F V_0 = 24.0\ \mathrm{MW}$。在热效率相同时，燃油流量正比于$\Delta\dot K$，所以 (b) 少烧$1 - 29.0/49.0 = 41\,\%$的燃油。

**校核。** 浪费的功率$\tfrac12 F (V_e - V_0)$在 (a) 中为$25\ \mathrm{MW}$，在 (b) 中为$5\ \mathrm{MW}$；$24 + 25 = 49$，$24 + 5 = 29$，理应如此。(b) 的代价是五倍的质量流量：在相同进口马赫数下，风扇直径约为$\sqrt5 \approx 2.2$倍，并随之带来重量和短舱阻力。选择涵道比就是权衡这些因素的艺术。
:::
:::

::: proposition 由 TSFC 求总效率 {#prop-overall}
吸气式发动机的总效率仅由其耗油率和飞行速度决定：
$$
\eta_o = \frac{V_0}{\mathrm{TSFC}\; h_{PR}} .
$$ {#eq-eta-overall}
:::

::: proof
按定义，$\eta_o = F V_0/(\dot m_f h_{PR})$。分子分母同除以$F$，并利用$\mathrm{TSFC} = \dot m_f/F$即可。除定义外不需要任何假设——特别是，这一结果对安装状态的发动机和实际喷管都成立，这就是为什么它是比较在不同条件下试验的发动机的公平方法。
:::

[[#eq-eta-overall]]立即表明，为什么效率固定的发动机的 TSFC 必然随飞行速度增大：当$\eta_o = 0.35$、$h_{PR} = 43\ \mathrm{MJ/kg}$时，在$V_0 = 240\ \mathrm{m/s}$下$\mathrm{TSFC} = 15.9\ \mathrm{g/(kN\,s)}$，而在$600\ \mathrm{m/s}$下为$39.9\ \mathrm{g/(kN\,s)}$，发动机的品质并没有任何变化。

::: example 起飞时的收敛喷管：压力推力 {#ex-pressure-thrust}
一台小型涡轮喷气发动机在海平面试车台上运转（$V_0 = 0$，$p_0 = 101.3\ \mathrm{kPa}$）。到达其收敛喷管的燃气的总温为$T_t = 950\ \mathrm{K}$，总压为$p_t = 220\ \mathrm{kPa}$，质量流量$\dot m_e = 80\ \mathrm{kg/s}$，$\gamma = 1.33$，$R = 287\ \mathrm{J/(kg\,K)}$。喷管处于壅塞状态（出口马赫数为 1）。求出口参数、出口面积、动量推力和压力推力、有效排气速度，并与完全膨胀到$p_0$的理想喷管比较。
::: solution
对壅塞的等熵喷管，出口处于声速状态（[[fluid-mechanics/compressible-flow]]）：
$$
T_e = \frac{2T_t}{\gamma + 1} = \frac{2 \times 950}{2.33} = 815\ \mathrm{K},\qquad
V_e = \sqrt{\gamma R T_e} = \sqrt{1.33 \times 287 \times 815} = 558\ \mathrm{m/s},
$$
$$
p_e = p_t\left(\frac{2}{\gamma+1}\right)^{\gamma/(\gamma-1)} = 220 \times 0.5404 = 118.9\ \mathrm{kPa}.
$$
出口密度为$\rho_e = p_e/(R T_e) = 0.508\ \mathrm{kg/m^3}$，所以$A_e = \dot m_e/(\rho_e V_e) = 0.282\ \mathrm{m^2}$。于是
$$
F = \underbrace{80 \times 558}_{44.6\ \mathrm{kN}} + \underbrace{(118.9 - 101.3)\times10^3 \times 0.282}_{5.0\ \mathrm{kN}} = 49.6\ \mathrm{kN},
\qquad c = \frac{F}{\dot m_e} = 620\ \mathrm{m/s}.
$$
膨胀到$p_0$的理想喷管给出$T_e = T_t (p_0/p_t)^{(\gamma-1)/\gamma} = 785\ \mathrm{K}$和$V_e = \sqrt{2c_p (T_t - T_e)}$，其中$c_p = \gamma R/(\gamma - 1) = 1157\ \mathrm{J/(kg\,K)}$：$V_e = 620.2\ \mathrm{m/s}$，$F = 49.6\ \mathrm{kN}$。

**校核。** 这里收敛喷管只损失约$0.05\,\%$的推力，因为喷管落压比$p_t/p_0 = 2.17$仅略高于临界值$1.85$；压力推力几乎恰好弥补了未达到的那部分速度。在超声速飞行高得多的落压比下，损失增大到百分之几，这就是超声速飞机采用缩放喷管的原因（[[propulsion/inlets-nozzles]]）。
:::
:::

## 航程：布雷盖方程

航空公司关心每千米烧掉的燃油，它既取决于发动机，**也**取决于机体。在定常平飞巡航中，升力等于重力，推力等于阻力，所以$F = D = W/(L/D)$，其中$L/D$为升阻比。

::: proposition 布雷盖航程方程 {#prop-breguet}
飞机以恒定飞行速度$V_0$、恒定升阻比$L/D$和恒定 TSFC 巡航，质量从初始值$m_i$变为最终值$m_f$，所飞过的航程为
$$
R = \frac{V_0}{g\,\mathrm{TSFC}}\,\frac{L}{D}\,\ln\frac{m_i}{m_f}
  = \eta_o\,\frac{h_{PR}}{g}\,\frac{L}{D}\,\ln\frac{m_i}{m_f}.
$$ {#eq-breguet}
:::

::: proof
飞机的质量以燃油消耗的速率减小：$\mathrm{d}m/\mathrm{d}t = -\dot m_f = -\mathrm{TSFC}\,F$。在定常平飞中$F = D$、$L = mg$，所以$F = mg/(L/D)$，且
$$
\frac{\mathrm{d}m}{m} = -\frac{g\,\mathrm{TSFC}}{L/D}\,\mathrm{d}t = -\frac{g\,\mathrm{TSFC}}{V_0\,(L/D)}\,\mathrm{d}s,
$$
其中飞过的距离用了$\mathrm{d}s = V_0\,\mathrm{d}t$。在$V_0$、$L/D$和 TSFC 为常数时，从$s = 0$处的$m_i$积分到$s = R$处的$m_f$：
$$
\ln\frac{m_i}{m_f} = \frac{g\,\mathrm{TSFC}}{V_0\,(L/D)}\,R .
$$
解出$R$即得第一种形式；[[#eq-eta-overall]]给出第二种形式。假设：定常、水平、无加速飞行；$V_0$、$L/D$、TSFC 为常数（实际上飞机随着变轻而缓慢爬升——即“巡航爬升”——使$L/D$保持在最佳值附近）；$g$为常数；不计爬升、下降和备份油。
:::

第二种形式很优美：航程是一个**发动机**指标（$\eta_o$）、一个**燃料**指标（$h_{PR}/g$，对煤油约为$4400\ \mathrm{km}$）、一个**气动**指标（$L/D$）和一个**结构**指标（质量比）的乘积。每一项都是一门独立的工程学科。

::: example 远程巡航航程 {#ex-breguet}
一架双发客机以$V_0 = 250\ \mathrm{m/s}$（在$11\ \mathrm{km}$高度为马赫数 0.85）巡航，$L/D = 18$，$\mathrm{TSFC} = 15\ \mathrm{g/(kN\,s)}$。巡航开始时$m_i = 1.35\, m_f$。估算巡航航程和发动机的总效率（$h_{PR} = 43\ \mathrm{MJ/kg}$）。
::: solution
取$\mathrm{TSFC} = 1.5\times10^{-5}\ \mathrm{kg/(N\,s)}$，$g = 9.81\ \mathrm{m/s^2}$：
$$
\frac{V_0}{g\,\mathrm{TSFC}} = \frac{250}{9.81 \times 1.5\times10^{-5}} = 1.70\times10^{6}\ \mathrm{m},
\qquad
R = 1.70\times10^{6} \times 18 \times \ln 1.35 = 9.18\times10^{6}\ \mathrm{m} \approx 9200\ \mathrm{km}.
$$
总效率为$\eta_o = V_0/(\mathrm{TSFC}\, h_{PR}) = 250/(1.5\times10^{-5} \times 4.3\times10^{7}) = 0.39$。

**校核。** 用第二种形式：$0.39 \times (4.3\times10^{7}/9.81) \times 18 \times 0.300 = 9.2\times10^{6}\ \mathrm{m}$。约$9000\ \mathrm{km}$航程所需的燃油占巡航开始时质量的$1 - 1/1.35 = 26\,\%$，这与远程双发喷气客机相符。TSFC 每降低百分之一，航程增加百分之一——或者在航程固定时燃油约减少百分之一，这就是发动机制造商为零点几个百分点而竞争的原因。
:::

## 作为极限情形的火箭

火箭携带全部推进剂，所以没有任何东西从自由流进入：$\dot m_0 = 0$，[[#eq-thrust]]变为$F = \dot m\,c$，与飞行速度无关。效率的记账也必须改变，因为推进剂在燃烧之前本身就具有动能$\tfrac12 \dot m V_0^2$（在地面坐标系中）。有用功率为$F V_0$；损失的功率是排气相对地面的动能$\tfrac12 \dot m (c - V_0)^2$。因此
$$
\eta_{p,\text{火箭}} = \frac{\dot m c V_0}{\dot m c V_0 + \tfrac12\dot m (c - V_0)^2} = \frac{2\,(V_0/c)}{1 + (V_0/c)^2},
$$ {#eq-etap-rocket}
它在起飞时为零，当飞行器恰好以排气速度飞行时升到 1（此时排气在地面坐标系中**静止**），超过之后又下降。火箭方程、多级和喷管性能在[[propulsion/rocket-fundamentals]]中展开。

::: example 爬升中的火箭级的推进效率 {#ex-rocket-etap}
某运载火箭的一级的有效排气速度为$c = 3.0\ \mathrm{km/s}$。求它在$V_0 = 0$、$0.9$、$3.0$和$6.0\ \mathrm{km/s}$时的推进效率。
::: solution
取$x = V_0/c$ = $0$、$0.3$、$1$、$2$：
$$
\eta_p = \frac{2x}{1+x^2} = 0,\quad \frac{0.6}{1.09} = 0.55,\quad 1,\quad \frac{4}{5} = 0.80 .
$$
**校核。** 该函数在$x \to 1/x$下对称（$\eta_p(2) = \eta_p(0.5) = 0.8$），在$x = 1$时排气在地面坐标系中静止，所以没有动能被浪费。飞行初期$\eta_p$低是不可避免的；这是运载火箭有效载荷比如此之小的原因之一。
:::
:::

::: history
推进器的动量理论可追溯到朗肯（W. J. M. Rankine，1865年）和弗劳德（R. E. Froude，1889年），他们把船用螺旋桨当作加速一个流管的圆盘来分析（[[propulsion/propellers]]）；因此，推进效率随射流速度接近飞行速度而提高这一结果，在喷气发动机出现前几十年就已为人所知。航程方程冠以路易·布雷盖（Louis Breguet）之名，源于他在 20 世纪 20 年代对远程飞机的研究。最早的喷气发动机——英国弗兰克·惠特尔（Frank Whittle）的发动机（1937年首次运转）和德国汉斯·冯·奥海因（Hans von Ohain）的发动机（1939年8月装在亨克尔 He 178 上首飞）——都是纯涡轮喷气发动机，射流速度高，推进效率低。约在1960年投入航线运营的罗尔斯-罗伊斯康维（Conway）是第一种投入使用的涵道式发动机，涵道比只有约 0.3。向大涵道比的跨越来自为洛克希德 C-5 研制的通用电气 TF39（涵道比约 8）和普惠 JT9D，后者于1970年1月随波音747投入航线运营，大幅降低了每座燃油消耗——这是把[[#eq-etap]]变成了硬件。
:::

::: summary
- 推力由控制体动量平衡得到：$F = \dot m_e V_e - \dot m_0 V_0 + (p_e - p_0)A_e$，即总推力减去冲压阻力；它是非安装推力，短舱和吊挂阻力计入机体。
- 有效排气速度$c = F_G/\dot m_e$吸收了压力推力；单位推力$F/\dot m_0 \approx V_e - V_0$衡量发动机的紧凑程度。
- $\mathrm{TSFC} = \dot m_f/F$（单位$\mathrm{g/(kN\,s)}$）和$I_{sp} = F/(\dot m_p g_0)$衡量燃油经济性；对吸气式发动机$I_{sp} = 1/(g_0\,\mathrm{TSFC})$。
- $\eta_o = \eta_{th}\eta_p = V_0/(\mathrm{TSFC}\,h_{PR})$；用$\eta_o$比较发动机，而不是用不同速度下的 TSFC。
- 推进效率$\eta_p = 2/(1 + V_e/V_0)$：高效率需要小的速度增量，从而需要大的质量流量——这就是采用涡轮风扇和螺旋桨的原因。
- 布雷盖航程$R = \eta_o (h_{PR}/g)(L/D)\ln(m_i/m_f)$把发动机、燃料、气动和结构分离开来。
- 对火箭，$\eta_p = 2(V_0/c)/[1 + (V_0/c)^2]$，当飞行器以排气速度飞行时最大。
:::

::: exercise {#exr-underexpanded level=2 check="32"}
一个为高空设计的火箭喷管在海平面（$p_0 = 101.3\ \mathrm{kPa}$）点火。其流量为$\dot m = 20\ \mathrm{kg/s}$，出口速度$V_e = 2600\ \mathrm{m/s}$，出口压强$p_e = 51.3\ \mathrm{kPa}$，出口面积$A_e = 0.40\ \mathrm{m^2}$。该喷管是过度膨胀还是欠膨胀？假设流动保持附着在喷管壁面上，求推力和有效排气速度。（以 kN 为单位输入推力。）
::: solution
$p_e < p_0$，所以喷管处于**过度膨胀**状态，压力推力为负：
$$
(p_e - p_0)A_e = (51.3 - 101.3)\times10^{3} \times 0.40 = -20.0\ \mathrm{kN}.
$$
动量推力为$\dot m V_e = 20 \times 2600 = 52.0\ \mathrm{kN}$，所以$F = 52.0 - 20.0 = 32.0\ \mathrm{kN}$，$c = F/\dot m = 1600\ \mathrm{m/s}$。损失很大，因为出口压强只有环境压强的一半；实际上如此过度膨胀的喷管会发生气流从壁面分离，这会改变这些数字（往往减小损失），并使喷管受载不均匀。在真空中同一喷管将给出$52.0 + 51.3\times10^{3}\times0.40/10^3 = 72.5\ \mathrm{kN}$。
:::
::: answer
过度膨胀；$F = 32\ \mathrm{kN}$，$c = 1600\ \mathrm{m/s}$。
:::

:::
::: answer
$400\ \mathrm{kg/s}$

::: exercise {#exr-jet-power level=3}
证明：对完全膨胀且燃料质量可忽略的射流，发动机核心机为了在飞行速度$V_0$下以质量流量$\dot m$产生推力$F$而必须加给气流的功率为
$$
\Delta\dot K = F V_0 + \frac{F^2}{2\dot m}.
$$
解释这两项，并用这一结果说明为什么在$F$和$V_0$固定时，增大质量流量总能减小所需功率，但收益递减。
::: solution
由$F = \dot m (V_e - V_0)$，$V_e = V_0 + F/\dot m$，于是
$$
\Delta\dot K = \tfrac12\dot m (V_e^2 - V_0^2) = \tfrac12 \dot m\left(2V_0\frac{F}{\dot m} + \frac{F^2}{\dot m^2}\right) = F V_0 + \frac{F^2}{2\dot m}.
$$
第一项是有用的推力功率，它与推力如何产生无关。第二项是留在尾流中的动能$\tfrac12\dot m (V_e - V_0)^2$。它按$1/\dot m$下降：质量流量加倍使损失减半，但每再加倍一次所节省的只有前一次的一半，而短舱阻力和发动机重量大致与$\dot m$成正比地增长。最佳涵道比位于尾流损失的边际节省等于边际安装代价之处。
:::

::: exercise {#exr-rocket-etap level=3 check="0.55"}
对火箭推进效率[[#eq-etap-rocket]]，(a) 证明它在$V_0 = c$时最大；(b) 求它在$V_0/c = 0.3$时的值。（输入$V_0/c = 0.3$时的值，保留两位有效数字。）
::: solution
(a) 取$x = V_0/c$，$\eta_p = 2x/(1+x^2)$，$\mathrm{d}\eta_p/\mathrm{d}x = 2(1 - x^2)/(1+x^2)^2$，它在$x = 1$处为零，此时$\eta_p = 1$；当$x < 1$时为正，$x > 1$时为负，所以这是最大值。(b) $\eta_p = 0.6/1.09 = 0.55$。
:::
::: answer
(b) $0.55$
