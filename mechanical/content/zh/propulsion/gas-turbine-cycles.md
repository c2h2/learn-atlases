上一章[[propulsion/thrust-efficiency]]把发动机当作一个黑箱：它以$V_0$吸入空气，以$V_e$把空气抛出。本章打开这个黑箱。每一种燃气涡轮发动机——涡轮喷气、涡轮风扇、涡轮螺旋桨——以及它没有压气机的近亲冲压发动机，都是**布雷顿循环**（Brayton cycle）的开口流动实现：压缩空气，在近似定压下加热，使高温燃气膨胀。航空发动机与电站燃气轮机的区别在于如何利用膨胀。动力涡轮把膨胀功全部作为轴功提取出来；涡轮喷气发动机只提取足以驱动压气机的那部分，其余留作高速射流；涡轮风扇发动机用其中一部分驱动风扇，加速一股大得多、慢得多的气流；涡轮螺旋桨发动机则通过减速器驱动螺旋桨。

我们将自底向上地建立分析：每个发动机公司都使用的滞止参数和截面编号；理想布雷顿循环及其效率；理想涡轮喷气发动机的**参数化循环分析**，它把单位推力和耗油率表示为飞行马赫数、压气机增压比和涡轮进口温度的显式函数；实际部件损失的影响；然后是涡轮风扇、冲压和涡轮螺旋桨发动机。热力学部分见[[thermodynamics/power-cycles]]，气体动力学部分见[[fluid-mechanics/compressible-flow]]。

## 截面与滞止参数

::: definition 发动机截面编号 {#def-stations}
按照 SAE 约定（ARP 755），涡轮喷气发动机或涡轮风扇发动机核心机的截面为：**0** 上游远处的自由流；**1** 进气道唇口；**2** 压气机（或风扇）进口；**3** 压气机出口；**4** 燃烧室出口 = 涡轮进口；**5** 涡轮出口；**7** 喷管进口；**9** 喷管出口。在涡轮风扇发动机中，外涵气流有自己的十几号编号：**13** 风扇出口，**19** 风扇喷管出口。加力燃烧室位于 5 与 7 之间。
:::

在发动机内部，燃气速度从几乎为零（在燃烧室中）变到每秒一千米以上（在喷管中），所以静温和静压是不方便的变量：即使在没有功或热交换的地方，它们也会变化。**滞止**（总）参数则不会。

::: definition 滞止温度与滞止压力；部件参数比 {#def-stagnation}
对$c_p$和$\gamma$为常数的完全气体，处于静态$(T, p)$、速度$V$、马赫数$M$的气流的**滞止温度**（总温）和**滞止压力**（总压）为
$$
T_t = T + \frac{V^2}{2c_p} = T\left(1 + \frac{\gamma-1}{2}M^2\right),
\qquad
p_t = p\left(\frac{T_t}{T}\right)^{\gamma/(\gamma-1)} .
$$
我们用每个部件的总温比$\tau$和总压比$\pi$（出口与进口之比）来描述它：压气机为$\tau_c = T_{t3}/T_{t2}$、$\pi_c = p_{t3}/p_{t2}$，涡轮为$\tau_t = T_{t5}/T_{t4}$、$\pi_t$，进气道（扩压器）为$\pi_d = p_{t2}/p_{t0}$，燃烧室为$\pi_b = p_{t4}/p_{t3}$，喷管为$\pi_n = p_{t9}/p_{t7}$。自由流本身对应**冲压比**
$$
\tau_r = \frac{T_{t0}}{T_0} = 1 + \frac{\gamma-1}{2}M_0^2,\qquad \pi_r = \frac{p_{t0}}{p_0} = \tau_r^{\gamma/(\gamma-1)},
$$
循环温度上限表示为$\tau_\lambda = c_{p}T_{t4}/(c_p T_0)$，对常数$c_p$它就是$T_{t4}/T_0$。
:::

有两个事实使滞止参数如此有用。第一，根据稳定流动能量方程（[[thermodynamics/first-law-open]]），压气机对单位质量燃气所做的功为$c_p(T_{t3} - T_{t2})$，其中已包括动能；在无功的绝热管道中，无论速度如何变化，$T_t$都保持不变。第二，对等熵过程，滞止参数比服从与静参数相同的等熵关系$\tau = \pi^{(\gamma-1)/\gamma}$；任何损失都表现为$p_t$下降而$T_t$不变，这就是为什么进气道、燃烧室和喷管用一个总压比$\pi < 1$来评定。

::: warning 滞止参数与静参数，以及始终使用开尔文
大多数错误的循环计算源于两个错误。(1) 混用静参数和滞止参数：在马赫数 0.8、$11\ \mathrm{km}$高度，自由流静温为$216.7\ \mathrm{K}$，但进入压气机的总温为$244.4\ \mathrm{K}$，总压比静压高$52\,\%$。部件计算使用$T_t$、$p_t$，只在需要射流速度的喷管出口才换算为静参数。(2) 使用摄氏度：每个比值$\tau$和每个等熵关系都需要绝对温度。“涡轮进口温度$1500\,^\circ\mathrm{C}$”即$1773\ \mathrm{K}$。
:::

## 理想布雷顿循环

::: proposition 理想布雷顿循环的热效率 {#prop-brayton}
对$c_p$和$\gamma$为常数的完全气体，经过总增压比为$\pi$、从$T_a$到$T_b$的等熵压缩，定压加热，等熵膨胀回到初始压力，再定压放热，其热效率为
$$
\eta_{th} = 1 - \frac{T_a}{T_b} = 1 - \frac{1}{\pi^{(\gamma-1)/\gamma}} .
$$ {#eq-brayton}
对航空发动机，压缩由冲压和压气机共同完成，$\pi = \pi_r \pi_c$，所以$\eta_{th} = 1 - 1/(\tau_r \tau_c)$。
:::

::: proof
把循环各点记为$a$（压缩开始）、$b$（压缩结束）、$c$（加热结束）、$d$（膨胀结束）。吸热量$q_{in} = c_p(T_c - T_b)$，放热量$q_{out} = c_p(T_d - T_a)$，$\eta_{th} = 1 - q_{out}/q_{in}$。过程$a\to b$和$c \to d$都是在相同两个压力之间的等熵过程，所以
$$
\frac{T_b}{T_a} = \frac{T_c}{T_d} = \pi^{(\gamma-1)/\gamma}
\quad\Longrightarrow\quad
\frac{T_d - T_a}{T_c - T_b} = \frac{T_a}{T_b},
$$
因为由$T_d = T_c T_a/T_b$得$T_d - T_a = (T_a/T_b)(T_c - T_b)$。因此$\eta_{th} = 1 - T_a/T_b$。飞行中，空气先由冲压效应从$T_0$压缩到$T_{t0} = \tau_r T_0$，再由压气机压缩$\tau_c$倍，在理想情形下两者都是等熵的，所以$T_b/T_a = \tau_r\tau_c$。开式循环发动机通过把高温燃气排入大气来“放热”，燃气随后在环境压力下冷却——这就是定压的封闭过程。假设：完全气体，$c_p$和$\gamma$为常数，燃料质量可忽略，除热交换本身之外所有过程均可逆。
:::

注意[[#eq-brayton]]中**不**包含的量：涡轮进口温度。理想循环效率只取决于总增压比。提高$T_{t4}$增大每千克空气的功——从而增大单位质量流量的推力，从而使发动机更小——但不提高理想效率。在实际发动机中，更高的$T_{t4}$确实会提高效率，因为它使固定的部件损失在更大的输出功中所占比例更小，并允许采用更高的有用增压比。

## 理想涡轮喷气发动机的参数化分析

在涡轮喷气发动机中，涡轮产生的功恰好等于压气机吸收的功；剩余部分通过喷管膨胀。**参数化（设计点）循环分析**由 Kerrebrock 和 Mattingly 发展而成，它在单一设计条件下计算一族发动机的性能，设计变量的选择保持开放，使设计者在任何硬件存在之前就能看清趋势。

::: proposition 理想涡轮喷气发动机的性能 {#prop-ideal-turbojet}
对理想涡轮喷气发动机（所有部件等熵，全程为$c_p$和$\gamma$为常数的完全气体，燃料质量可忽略，喷管完全膨胀到$p_9 = p_0$），取$a_0 = \sqrt{\gamma R T_0}$：
$$
\tau_t = 1 - \frac{\tau_r}{\tau_\lambda}(\tau_c - 1),
\qquad
\frac{V_9}{a_0} = \sqrt{\frac{2}{\gamma-1}\,\frac{\tau_\lambda}{\tau_r\tau_c}\,\left(\tau_r\tau_c\tau_t - 1\right)},
$$ {#eq-v9}
$$
\frac{F}{\dot m_0} = a_0\left(\frac{V_9}{a_0} - M_0\right),
\qquad
f = \frac{c_p T_0}{h_{PR}}\left(\tau_\lambda - \tau_r\tau_c\right),
\qquad
\mathrm{TSFC} = \frac{f}{F/\dot m_0}.
$$ {#eq-turbojet}
:::

::: proof
**涡轮。** 涡轮驱动压气机，所以对单位质量空气有$c_p(T_{t4} - T_{t5}) = c_p(T_{t3} - T_{t2})$。两边除以$c_p T_{t4}$，并利用$T_{t2} = T_{t0} = \tau_r T_0$（绝热进气道）和$T_{t4} = \tau_\lambda T_0$：
$$
1 - \tau_t = \frac{\tau_r T_0 (\tau_c - 1)}{\tau_\lambda T_0}
\quad\Longrightarrow\quad
\tau_t = 1 - \frac{\tau_r}{\tau_\lambda}(\tau_c - 1).
$$
**喷管出口。** 所有部件都是等熵的，所以喷管出口总压为$p_{t9} = p_0\,\pi_r\pi_c\pi_t$（$\pi_d = \pi_b = \pi_n = 1$）；由于每个$\pi = \tau^{\gamma/(\gamma-1)}$，在$p_9 = p_0$时$p_{t9}/p_9 = (\tau_r\tau_c\tau_t)^{\gamma/(\gamma-1)}$。等熵关系于是给出$T_{t9}/T_9 = \tau_r\tau_c\tau_t$。喷管是绝热的，所以$T_{t9} = T_{t5} = \tau_\lambda \tau_t T_0$，射流动能为
$$
V_9^2 = 2c_p(T_{t9} - T_9) = 2c_p T_{t9}\left(1 - \frac{1}{\tau_r\tau_c\tau_t}\right)
= 2 c_p T_0\, \frac{\tau_\lambda}{\tau_r\tau_c}\left(\tau_r\tau_c\tau_t - 1\right).
$$
除以$a_0^2 = \gamma R T_0 = (\gamma-1)c_p T_0$即得[[#eq-v9]]。
**推力与燃油。** 在$f \ll 1$且$p_9 = p_0$时，[[propulsion/thrust-efficiency]]的推力方程化为$F/\dot m_0 = V_9 - V_0$，其中$V_0 = a_0 M_0$。燃烧室能量平衡（在流量中忽略燃料质量，但在放热中不忽略）为$\dot m_f h_{PR} = \dot m_0 c_p(T_{t4} - T_{t3})$；由$T_{t3} = \tau_r\tau_c T_0$得$f = c_p T_0(\tau_\lambda - \tau_r\tau_c)/h_{PR}$。
:::

这些方程揭示了一个约束：压气机不能把空气加热到超过涡轮进口温度（$\tau_r\tau_c < \tau_\lambda$），也不能要求涡轮提供超过可用值的功。它们还揭示了一个最优值。

::: proposition 单位推力最大的压气机增压比 {#prop-opt-pic}
在$M_0$、$T_0$和$T_{t4}$固定时，理想涡轮喷气发动机的单位推力在
$$
\tau_c = \frac{\sqrt{\tau_\lambda}}{\tau_r},
\qquad\text{即}\qquad
T_{t3} = \sqrt{T_0\,T_{t4}}
$$ {#eq-opt-pic}
时最大。
:::

::: proof
$F/\dot m_0$随$V_9$增大，所以只需使$(V_9/a_0)^2 \propto \frac{\tau_\lambda}{\tau_r\tau_c}(\tau_r\tau_c\tau_t - 1)$最大。代入$\tau_t$：
$$
\frac{\tau_\lambda}{\tau_r\tau_c}\left[\tau_r\tau_c - \frac{\tau_r^2\tau_c}{\tau_\lambda}(\tau_c - 1) - 1\right]
= \tau_\lambda - \tau_r(\tau_c - 1) - \frac{\tau_\lambda}{\tau_r\tau_c}.
$$
对$\tau_c$求导得$-\tau_r + \tau_\lambda/(\tau_r\tau_c^2)$，它在$\tau_c^2 = \tau_\lambda/\tau_r^2$时为零；二阶导数$-2\tau_\lambda/(\tau_r\tau_c^3) < 0$确认这是最大值。于是$T_{t3} = \tau_r\tau_c T_0 = \sqrt{\tau_\lambda}\,T_0 = \sqrt{T_0 T_{t4}}$：压气机出口温度是循环最低温度与最高温度的几何平均值。
:::

超过这一最优值后效率继续提高（由[[#eq-brayton]]），而单位推力下降。因此追求燃油经济性的设计者会选择远高于单位推力最优值的增压比，而限制则来自压气机的尺寸、重量、稳定性及其出口温度。

::: example 亚声速巡航的理想涡轮喷气发动机 {#ex-ideal-turbojet}
一台理想涡轮喷气发动机在$11\ \mathrm{km}$高度（国际标准大气，$T_0 = 216.65\ \mathrm{K}$，$p_0 = 22.63\ \mathrm{kPa}$）以$M_0 = 0.80$飞行，$\pi_c = 20$，$T_{t4} = 1500\ \mathrm{K}$。取$\gamma = 1.4$，$c_p = 1004.5\ \mathrm{J/(kg\,K)}$，$h_{PR} = 43\ \mathrm{MJ/kg}$。求单位推力、油气比、TSFC 以及热效率、推进效率和总效率。
::: solution
$a_0 = \sqrt{1.4 \times 287 \times 216.65} = 295.0\ \mathrm{m/s}$，$V_0 = 236.0\ \mathrm{m/s}$。
$$
\tau_r = 1 + 0.2\times0.8^2 = 1.128,\quad
\tau_c = 20^{0.2857} = 2.3535,\quad
\tau_\lambda = \frac{1500}{216.65} = 6.9236 .
$$
涡轮：$\tau_t = 1 - (1.128/6.9236)(1.3535) = 0.7795$，所以$T_{t5} = 1169\ \mathrm{K}$，涡轮压比为$\pi_t = 0.7795^{3.5} = 0.418$。
射流：$\tau_r\tau_c\tau_t = 2.0694$，且
$$
\frac{V_9}{a_0} = \sqrt{5 \times \frac{6.9236}{2.6548} \times 1.0694} = 3.734,\qquad V_9 = 1102\ \mathrm{m/s}.
$$
于是
$$
\frac{F}{\dot m_0} = 1102 - 236 = 866\ \mathrm{N\,s/kg},\qquad
f = \frac{1004.5 \times 216.65}{43\times10^{6}}\left(6.9236 - 2.6548\right) = 0.0216,
$$
$$
\mathrm{TSFC} = \frac{0.0216}{866} = 2.50\times10^{-5}\ \mathrm{kg/(N\,s)} = 25.0\ \mathrm{g/(kN\,s)}.
$$
效率：$\eta_{th} = 1 - 1/(1.128 \times 2.3535) = 0.623$；$\eta_p = 2V_0/(V_9 + V_0) = 0.353$；$\eta_o = 0.623 \times 0.353 = 0.220$。

**校核。** [[#eq-opt-pic]]的最优值为$\tau_c = \sqrt{6.9236}/1.128 = 2.333$，$\pi_c = 19.4$：这个设计几乎恰好位于单位推力最优点。热效率很高，但推进效率很差——射流速度几乎是飞机速度的五倍。这是涡轮喷气发动机在亚声速下的根本弱点。
:::

## 实际部件

实际的压气机和涡轮产生熵；实际的进气道、燃烧室和喷管损失总压；燃烧并不完全；高温燃气的$c_p$比冷空气高、$\gamma$比冷空气低；涡轮还必须提供轴承摩擦和附件所需的功率。每种效应都用一个品质指标来表示。

::: definition 部件品质指标 {#def-component-eff}
- **进气道**总压恢复系数$\pi_d = p_{t2}/p_{t0}$（亚声速为 0.97–0.99；超声速时更低，见[[propulsion/inlets-nozzles]]）。
- **压气机等熵效率**$\eta_c = \dfrac{T_{t3s} - T_{t2}}{T_{t3} - T_{t2}} = \dfrac{\pi_c^{(\gamma-1)/\gamma} - 1}{\tau_c - 1}$，即相同增压比下理想功与实际功之比。
- **燃烧室**总压比$\pi_b = p_{t4}/p_{t3}$（0.94–0.97）和**燃烧效率**$\eta_b$，即燃料热值中实际释放的比例（设计点高于 0.99）。
- **涡轮等熵效率**$\eta_t = \dfrac{T_{t4} - T_{t5}}{T_{t4} - T_{t5s}} = \dfrac{1 - \tau_t}{1 - \pi_t^{(\gamma_t-1)/\gamma_t}}$，即相同压比下实际功与理想功之比。
- 转子的**机械效率**$\eta_m$（高于 0.99）和**喷管**总压比$\pi_n = p_{t9}/p_{t7}$。
:::

压气机效率和涡轮效率的定义方向相反——压气机需要的功**多于**理想值，涡轮**给出的**功少于理想值——所以两者都小于 1。多变（小级）效率能更公平地比较不同增压比的机器，它将在[[propulsion/compressors]]和[[propulsion/turbines]]中介绍。

::: algorithm 实际涡轮喷气发动机循环分析 {#alg-real-cycle}
已知飞行条件（$M_0$、$T_0$、$p_0$）、设计选择（$\pi_c$、$T_{t4}$）、部件品质指标、燃烧室上游的冷气物性$c_{pc}, \gamma_c$和下游的燃气物性$c_{ph}, \gamma_h$：
1. 自由流：$T_{t0} = \tau_r T_0$，$p_{t0} = \pi_r p_0$，$V_0 = M_0 a_0$。
2. 进气道：$T_{t2} = T_{t0}$，$p_{t2} = \pi_d p_{t0}$。
3. 压气机：$T_{t3s} = T_{t2}\pi_c^{(\gamma_c-1)/\gamma_c}$，$T_{t3} = T_{t2} + (T_{t3s} - T_{t2})/\eta_c$，$p_{t3} = \pi_c p_{t2}$。
4. 每千克空气的燃烧室能量平衡：$c_{pc}T_{t3} + f\,\eta_b h_{PR} = (1+f)\,c_{ph} T_{t4}$，所以$f = \dfrac{c_{ph}T_{t4} - c_{pc}T_{t3}}{\eta_b h_{PR} - c_{ph}T_{t4}}$；$p_{t4} = \pi_b p_{t3}$。
5. 涡轮功平衡：由$\eta_m (1+f) c_{ph}(T_{t4} - T_{t5}) = c_{pc}(T_{t3} - T_{t2})$得$T_{t5}$；然后$T_{t5s} = T_{t4} - (T_{t4} - T_{t5})/\eta_t$，$p_{t5} = p_{t4}(T_{t5s}/T_{t4})^{\gamma_h/(\gamma_h-1)}$。
6. 喷管：$p_{t9} = \pi_n p_{t5}$，$T_{t9} = T_{t5}$；完全膨胀时$T_9 = T_{t9}(p_0/p_{t9})^{(\gamma_h-1)/\gamma_h}$，$V_9 = \sqrt{2c_{ph}(T_{t9} - T_9)}$。（若$p_{t9}/p_0$超过临界比而喷管为收敛型，则取壅塞出口并加上压力推力。）
7. 性能：$F/\dot m_0 = (1+f)V_9 - V_0 + (p_9 - p_0)A_9/\dot m_0$，$\mathrm{TSFC} = f/(F/\dot m_0)$。
:::

::: example 采用实际部件的同一台涡轮喷气发动机 {#ex-real-turbojet}
取$\pi_d = 0.98$，$\eta_c = 0.86$，$\pi_b = 0.96$，$\eta_b = 0.99$，$\eta_t = 0.90$，$\eta_m = 1$，$\pi_n = 0.98$，喷管完全膨胀，燃气$c_{ph} = 1150\ \mathrm{J/(kg\,K)}$，$\gamma_h = 1.33$，重做[[#ex-ideal-turbojet]]。
::: solution
1–2. $T_{t2} = 244.4\ \mathrm{K}$；$p_{t0} = 22.63 \times 1.128^{3.5} = 34.50\ \mathrm{kPa}$，$p_{t2} = 33.81\ \mathrm{kPa}$。
3. $T_{t3s} = 244.4 \times 2.3535 = 575.2\ \mathrm{K}$；$T_{t3} = 244.4 + 330.8/0.86 = 629.0\ \mathrm{K}$；$p_{t3} = 676.2\ \mathrm{kPa}$。
4. $f = \dfrac{1150 \times 1500 - 1004.5 \times 629.0}{0.99 \times 43\times10^{6} - 1150 \times 1500} = \dfrac{1.0932\times10^{6}}{4.0845\times10^{7}} = 0.0268$；$p_{t4} = 649.1\ \mathrm{kPa}$。
5. 压气机功$c_{pc}(T_{t3} - T_{t2}) = 386.3\ \mathrm{kJ/kg}$，所以$T_{t5} = 1500 - 386.3\times10^{3}/(1.0268 \times 1150) = 1172.8\ \mathrm{K}$；$T_{t5s} = 1500 - 327.2/0.90 = 1136.4\ \mathrm{K}$；$p_{t5} = 649.1 \times (1136.4/1500)^{4.03} = 212.1\ \mathrm{kPa}$。
6. $p_{t9} = 207.8\ \mathrm{kPa}$；$T_9 = 1172.8 \times (22.63/207.8)^{0.2481} = 676.5\ \mathrm{K}$；$V_9 = \sqrt{2 \times 1150 \times 496.3} = 1068\ \mathrm{m/s}$。
7. $F/\dot m_0 = 1.0268 \times 1068 - 236.0 = 861\ \mathrm{N\,s/kg}$；$\mathrm{TSFC} = 0.0268/861 = 31.1\ \mathrm{g/(kN\,s)}$。

## 涡轮风扇发动机

涡轮风扇发动机把进入的空气分成两股。**内涵**（核心）气流（$\dot m_c$）像在涡轮喷气发动机中一样流经压气机、燃烧室和涡轮；**外涵**气流（$\dot m_F$）只经风扇压缩，并在自己的喷管中膨胀。比值$\alpha = \dot m_F/\dot m_c$就是**涵道比**。此时涡轮除驱动压气机外还要驱动风扇，所以它从核心气流中提取更多能量，核心射流变慢；这些能量以一股大而慢的风扇气流的形式重新出现。这正是[[propulsion/thrust-efficiency]]中推进效率所推荐的交换。

对风扇总温比为$\tau_f$的理想分开排气涡轮风扇发动机（风扇也压缩核心空气，这里$\tau_c$表示核心的**总**压缩），涡轮功平衡变为
$$
\tau_t = 1 - \frac{\tau_r}{\tau_\lambda}\left[(\tau_c - 1) + \alpha(\tau_f - 1)\right],
$$ {#eq-tf-turbine}
核心射流由取此$\tau_t$的[[#eq-v9]]给出，风扇射流由
$$
\frac{V_{19}}{a_0} = \sqrt{\frac{2}{\gamma - 1}\left(\tau_r\tau_f - 1\right)}
$$
给出，单位**总**空气流量的推力和 TSFC 为
$$
\frac{F}{\dot m_0} = \frac{a_0}{1+\alpha}\left[\left(\frac{V_9}{a_0} - M_0\right) + \alpha\left(\frac{V_{19}}{a_0} - M_0\right)\right],
\qquad
\mathrm{TSFC} = \frac{f}{(1+\alpha)\,F/\dot m_0},
$$ {#eq-tf-thrust}
其中$f$为核心油气比，与[[#eq-turbojet]]中的相同。（推导与涡轮喷气发动机逐行相同。）

::: proposition 最优风扇压比 {#prop-opt-fan}
对在固定$M_0$、$\tau_\lambda$、$\tau_c$和$\alpha$下的理想分开排气涡轮风扇发动机，使单位推力最大——由于此时燃油流量固定，也就是使 TSFC 最小——的风扇压比，是使两股射流速度相等即$V_9 = V_{19}$的那个压比。
:::

::: proof
燃油流量只取决于$\tau_c$和$\tau_\lambda$，所以在核心条件固定时，我们对$\tau_f$求$V_9 + \alpha V_{19}$的最大值。由[[#eq-v9]]，$V_9^2/a_0^2 = \frac{2}{\gamma-1}\left[\tau_\lambda\tau_t - \tau_\lambda/(\tau_r\tau_c)\right]$，而由[[#eq-tf-turbine]]，$\partial\tau_t/\partial\tau_f = -\alpha\tau_r/\tau_\lambda$，所以
$$
\frac{\partial}{\partial\tau_f}\left(\frac{V_9}{a_0}\right) = \frac{1}{2V_9/a_0}\cdot\frac{2}{\gamma-1}\tau_\lambda\cdot\left(-\frac{\alpha\tau_r}{\tau_\lambda}\right) = -\frac{\alpha\tau_r}{(\gamma-1)V_9/a_0},
\qquad
\frac{\partial}{\partial\tau_f}\left(\frac{V_{19}}{a_0}\right) = \frac{\tau_r}{(\gamma-1)V_{19}/a_0}.
$$
令$\partial(V_9 + \alpha V_{19})/\partial\tau_f = 0$，得$\alpha\tau_r/V_9 = \alpha\tau_r/V_{19}$，即$V_9 = V_{19}$。物理上：只要风扇射流是两者中较慢的一股，把一焦耳的功从核心射流转移到风扇射流就会提高推力，因为给定能量在更慢、质量更大的气流中产生更多动量。假设：理想部件，两股气流的$\gamma$和$c_p$相同，$f \ll 1$，喷管完全膨胀。
:::

采用实际部件时，最优值会移动，使风扇射流比核心射流略慢（两者之比大致等于风扇效率与低压涡轮效率的乘积），但原理相同。

::: example 理想涡轮风扇发动机与理想涡轮喷气发动机的比较 {#ex-turbofan}
在$M_0 = 0.80$、$11\ \mathrm{km}$高度，比较一台理想涡轮喷气发动机与一台涵道比$\alpha = 8$、风扇压比$\pi_f = 1.6$的理想分开排气涡轮风扇发动机。两者的总增压比均为$\pi_c = 36$，$T_{t4} = 1600\ \mathrm{K}$；常数同[[#ex-ideal-turbojet]]。然后求最优风扇压比。
::: solution
公共项：$\tau_r = 1.128$，$\tau_c = 36^{0.2857} = 2.7839$，$\tau_\lambda = 7.3852$，两者的$f = (1004.5 \times 216.65/43\times10^6)(7.3852 - 3.1403) = 0.0215$。
**涡轮喷气：** $\tau_t = 0.7275$，$V_9 = 1147\ \mathrm{m/s}$，$F/\dot m_0 = 911\ \mathrm{N\,s/kg}$，$\mathrm{TSFC} = 23.6\ \mathrm{g/(kN\,s)}$。
**涡轮风扇：** $\tau_f = 1.6^{0.2857} = 1.1437$，所以[[#eq-tf-turbine]]给出$\tau_t = 1 - (1.128/7.3852)(1.7839 + 8 \times 0.1437) = 0.5519$。核心射流：$V_9/a_0 = \sqrt{5 \times (7.3852/3.1403)\times(3.1403\times0.5519 - 1)} = 2.936$，$V_9 = 866\ \mathrm{m/s}$。风扇射流：$V_{19}/a_0 = \sqrt{5(1.128 \times 1.1437 - 1)} = 1.204$，$V_{19} = 355\ \mathrm{m/s}$。于是
$$
\frac{F}{\dot m_0} = \frac{295.0}{9}\left[(2.936 - 0.8) + 8(1.204 - 0.8)\right] = 176\ \mathrm{N\,s/kg},
\qquad
\mathrm{TSFC} = \frac{0.0215}{9 \times 176} = 13.6\ \mathrm{g/(kN\,s)}.
$$
**最优风扇。** 数值求解$V_9 = V_{19}$得$\pi_f = 2.41$，两股射流都为$442\ \mathrm{m/s}$，$F/\dot m_0 = 206\ \mathrm{N\,s/kg}$，$\mathrm{TSFC} = 11.6\ \mathrm{g/(kN\,s)}$。

**校核。** 两台发动机的热效率相同，$1 - 1/(\tau_r\tau_c) = 0.68$；涡轮风扇发动机的全部优势都在推进方面。在$\pi_f = 1.6$时，核心射流仍比风扇射流快得多，说明转移给风扇的功太少，最优值更好。涡轮风扇发动机的代价是单位推力低到五分之一：为获得相同推力，它必须吸入五倍的空气，这就是它的风扇如此之大的原因。

::: quiz
在飞行条件和压气机增压比都固定的理想涡轮喷气发动机中，提高涡轮进口温度$T_{t4}$。下列哪些情况会发生？（可能有多个正确选项。）
- [x] 单位推力增大。
- [ ] 热效率提高。
- [x] 射流速度增大，推进效率下降。
- [ ] TSFC 降低。
::: solution
在相同增压比下每千克加入更多的热，产生更多的功、更快的射流和每千克空气更大的推力。理想热效率$1 - 1/(\tau_r\tau_c)$不变，而更快的射流使$\eta_p$降低，所以总效率下降、TSFC 升高。高$T_{t4}$只有与更高的增压比或更高的涵道比（它把额外的功转化为风扇推力）结合时才有回报。

## 冲压发动机

在高飞行马赫数下，仅冲压压缩就能提供很大的增压比——在$M_0 = 3$时$\pi_r = 36.7$——于是可以去掉压气机，连同涡轮一起。剩下的就是**冲压发动机**：一个把空气减速到低亚声速的超声速进气道、一个燃烧室和一个喷管。取$\tau_c = \tau_t = 1$，[[#eq-v9]]简化为
$$
\frac{V_9}{a_0} = M_0\sqrt{\frac{\tau_\lambda}{\tau_r}},
\qquad
\frac{F}{\dot m_0} = a_0 M_0\left(\sqrt{\frac{\tau_\lambda}{\tau_r}} - 1\right),
\qquad
\eta_{th} = 1 - \frac{1}{\tau_r}.
$$ {#eq-ramjet}
冲压发动机不产生静推力（在$M_0 = 0$时根本没有压缩），在低马赫数下效率很差；它需要另一台发动机或火箭把它加速。它的上限来自进气道后空气的温度：在$M_0 = 6$时，$11\ \mathrm{km}$高度的$T_{t0}$已约为$1800\ \mathrm{K}$，所以在达到材料和离解极限之前只能加入很少的热，而且进气道激波损失变得很严重。使燃烧室内气流保持超声速——即**超燃冲压发动机**——是为更高速度而探索的答案。

::: example 马赫数 3 的理想冲压发动机 {#ex-ramjet}
一台理想冲压发动机在$11\ \mathrm{km}$高度以$M_0 = 3.0$飞行，燃烧室出口温度$T_{t4} = 2000\ \mathrm{K}$。求单位推力、TSFC 以及热效率和推进效率。在$M_0 = 0.8$时重复计算。
::: solution
在$M_0 = 3$时：$\tau_r = 1 + 0.2 \times 9 = 2.8$（$T_{t0} = 606.6\ \mathrm{K}$），$\tau_\lambda = 2000/216.65 = 9.231$，$\sqrt{\tau_\lambda/\tau_r} = 1.816$：
$$
V_9 = 3 \times 295.0 \times 1.816 = 1607\ \mathrm{m/s},\qquad
\frac{F}{\dot m_0} = 1607 - 885 = 722\ \mathrm{N\,s/kg},
$$
$f = (1004.5\times216.65/43\times10^6)(9.231 - 2.8) = 0.0326$，$\mathrm{TSFC} = 0.0326/722 = 45.1\ \mathrm{g/(kN\,s)}$。$\eta_{th} = 1 - 1/2.8 = 0.643$，$\eta_p = 2/(1 + 1.816) = 0.710$，所以$\eta_o = 0.456$。
在$M_0 = 0.8$时：$\tau_r = 1.128$，$\sqrt{\tau_\lambda/\tau_r} = 2.861$，$F/\dot m_0 = 236.0 \times 1.861 = 439\ \mathrm{N\,s/kg}$，$f = 0.0410$，$\mathrm{TSFC} = 93.4\ \mathrm{g/(kN\,s)}$，$\eta_{th} = 0.113$。

**校核。** 与涡轮风扇发动机的$13.6$相比，马赫数 3 时的 TSFC 看起来很高，但总效率$\eta_o = V_0/(\mathrm{TSFC}\,h_{PR}) = 885/(4.51\times10^{-5} \times 4.3\times10^{7}) = 0.456$是本章所有发动机中最高的——冲压压缩是“免费”的。在马赫数 0.8 时，同一台冲压发动机毫无用处。
:::
:::

## 涡轮螺旋桨、涡轮轴与加力燃烧室

**涡轮螺旋桨发动机**在涡轮中使核心燃气几乎膨胀到环境压力，把几乎全部可用功作为驱动螺旋桨的轴功率取出（通过减速器，因为螺旋桨桨尖速度必须保持亚声速，见[[propulsion/propellers]]）。通常在射流中保留少量能量。其循环分析与涡轮喷气发动机相同，只多一个变量：涡轮所取的可用焓降的比例。最优分配是使再多一焦耳的功在螺旋桨中和在射流中同样有价值——与[[#prop-opt-fan]]相同的边际论证，只是要用螺旋桨和减速器效率加权。功率用**当量轴功率**表示，燃油经济性用功率耗油率表示，单位为$\mathrm{kg/(kW\,h)}$或$\mathrm{mg/(W\,s)}$。**涡轮轴发动机**（直升机、辅助动力装置、船舶和电站）把全部功作为轴功率取出，不留有用的射流。

**加力燃烧室**（复燃室）在涡轮排气中燃烧额外的燃油；涡轮排气仍含有大部分氧气，因为$T_{t4}$的限制使主燃烧室只能使用贫油混合气。把喷管进口温度从比如$1100\ \mathrm{K}$提高到$2000\ \mathrm{K}$，射流速度大致按$\sqrt{T_{t7}}$增大——约$35\,\%$——单位推力增大得更多，但热量是在低压下加入的，TSFC 大约翻倍。因此加力燃烧室只在军用发动机和少数超声速民用发动机上短时间使用（起飞、跨声速加速），并且需要可调面积喷管，以便通过更热、密度更低的气流而不扰动上游的发动机。

::: history
乔治·布雷顿（George Brayton）于1872年在美国为他的定压“Ready Motor”申请了专利；以他的名字命名的循环后来被确认为燃气轮机的理想模型。法国工程师勒内·洛兰（René Lorin）在1913年描述了冲压发动机原理，比任何能飞得足够快以使用它的飞行器早了几十年。弗兰克·惠特尔（Frank Whittle）于1930年1月提交了他的涡轮喷气发动机英国专利，并于1937年4月运转了他的第一台实验发动机；汉斯·冯·奥海因（Hans von Ohain）的发动机于1939年8月驱动亨克尔 He 178 完成了首次喷气推进飞行。第一种飞行的涡轮螺旋桨发动机是罗尔斯-罗伊斯“特伦特”（Trent）——一台通过减速器驱动螺旋桨的“德温特”（Derwent）涡轮喷气发动机——于1945年9月装在一架改装的格罗斯特“流星”（Gloster Meteor）上飞行。本章所用形式的参数化循环分析，在 Kerrebrock 和 Mattingly 的教材中被系统化用于教学。
:::

::: summary
- 发动机用 SAE 截面编号（0、2、3、4、5、9；风扇为 13、19）和各部件的滞止参数比$\tau$、$\pi$描述；$\tau_r = 1 + \tfrac{\gamma-1}{2}M_0^2$表示冲压压缩。
- 理想布雷顿循环的$\eta_{th} = 1 - 1/(\tau_r\tau_c)$：它取决于总增压比，而不取决于涡轮进口温度。
- 理想涡轮喷气发动机：$\tau_t = 1 - (\tau_r/\tau_\lambda)(\tau_c - 1)$，射流速度由[[#eq-v9]]给出，$F/\dot m_0 = V_9 - V_0$；单位推力在$T_{t3} = \sqrt{T_0 T_{t4}}$时达到峰值，而效率随增压比继续提高。
- 实际部件（进气道总压恢复、$\eta_c$、$\pi_b$、$\eta_b$、$\eta_t$、$\pi_n$、燃气物性）损失的推力很少，但损失的燃油经济性很多。
- 涡轮风扇发动机把功从核心射流转移给一股大而慢的外涵气流；理想情况下最佳风扇压比使两股射流速度相等。
- 冲压发动机不需要压气机，在马赫数 3 左右效率很高，但没有静推力；涡轮螺旋桨发动机以轴功率形式取出功；加力燃烧室以燃油为代价换取推力。
:::

::: exercise {#exr-fan-split level=3}
利用[[#eq-tf-turbine]]和[[#eq-tf-thrust]]证明：对核心（$\tau_c$、$\tau_\lambda$）固定、风扇压比固定的理想涡轮风扇发动机，增大涵道比$\alpha$最终会**减小**单位核心流量的推力；并求核心射流速度降到飞行速度时的涵道比。解释为什么实际发动机远在达到这一点之前就止步了。
::: solution
单位核心流量的推力为$a_0[(V_9/a_0 - M_0) + \alpha(V_{19}/a_0 - M_0)]$。增大$\alpha$会增加风扇推力$\alpha(V_{19} - V_0)$，但通过[[#eq-tf-turbine]]降低$\tau_t$，从而降低$V_9$。当$V_9 = V_0$时核心推力为零，即
$$
\frac{2}{\gamma-1}\,\frac{\tau_\lambda}{\tau_r\tau_c}(\tau_r\tau_c\tau_t - 1) = M_0^2 .
$$
两边乘以$\frac{\gamma-1}{2}\frac{\tau_r\tau_c}{\tau_\lambda}$，并利用$\frac{\gamma-1}{2}M_0^2 = \tau_r - 1$，整理得
$$
\tau_t = \frac{1}{\tau_r\tau_c} + \frac{\tau_r - 1}{\tau_\lambda},
$$
再由[[#eq-tf-turbine]]得到涵道比：
$$
\alpha_{\max} = \frac{\tau_\lambda(1 - \tau_t)/\tau_r - (\tau_c - 1)}{\tau_f - 1}.
$$
对[[#ex-turbofan]]的数据（$\tau_r = 1.128$，$\tau_c = 2.7839$，$\tau_\lambda = 7.3852$，$\tau_f = 1.1437$）：$\tau_t = 1/3.1403 + 0.128/7.3852 = 0.3358$，$\alpha_{\max} = (7.3852 \times 0.6642/1.128 - 1.7839)/0.1437 = 17.9$。远在此之前，核心射流就已比风扇射流慢，[[#prop-opt-fan]]的最优点早已越过；实际上，风扇直径、重量、短舱阻力、离地间隙和低压涡轮的转速（齿轮传动可以缓解这一点）把当前发动机的涵道比限制在约 10–12（截至2026年）。
:::

::: exercise {#exr-design-tf level=3}
**设计研究。** 要求你为一台在$M_0 = 0.85$、$11\ \mathrm{km}$巡航的远程涡轮风扇发动机的核心机选择$\pi_c$和$T_{t4}$。利用本章的理想关系式（以及涡轮喷气核心的 TSFC 交互图），论证每个选择会把热效率、核心比功率和 TSFC 推向哪个方向，并指出阻止你无限提高每个参数的实际限制。然后解释为什么涡轮风扇发动机的最优$T_{t4}$高于具有相同核心机的涡轮喷气发动机。
::: solution
**增压比。** $\eta_{th} = 1 - 1/(\tau_r\tau_c)$随$\pi_c$提高；每千克核心功先增后减（最优点在$T_{t3} = \sqrt{T_0T_{t4}}$）。限制：压气机出口温度$T_{t3}$（轮盘和叶片材料，对当前镍基合金起飞时约为$900$–$1000\ \mathrm{K}$，以及随燃烧室进口温度急剧增加的 NO$_x$生成——见[[propulsion/combustors]]）；压气机后部叶片高度很小，叶尖间隙在通道中所占比例变大，效率下降；以及稳定性（喘振裕度，[[propulsion/compressors]]）。
**涡轮进口温度。** 在理想循环中$T_{t4}$不改变$\eta_{th}$，但提高比功。在涡轮喷气发动机中，额外的功变成更快的射流，推进效率下降，所以 TSFC 变差（第二个交互图）。在涡轮风扇发动机中，额外的核心功可以通过更大的涵道比或风扇压比交给风扇，使射流保持低速；因此涡轮风扇发动机把更高的$T_{t4}$转化为相同推力下更小的核心机，并在有实际损失时转化为更好的效率。限制：涡轮叶片材料与冷却（[[propulsion/turbines]]），绕过燃烧室并降低循环效率的冷却空气，以及 NO$_x$。
这就是为什么大涵道比、高增压比和高涡轮温度一直是共同发展的。
:::
:::
