燃气轮机是一种必须先压缩工质才能对其加热的热机，而压气机是决定发动机能否工作的部件。在现代涡轮风扇发动机中，核心压气机把空气压力提高 40 倍或更多，吸收涡轮所产生功率的大约一半；压气机效率损失几个百分点要付出两次代价，一次是额外的涡轮功，一次是更低的循环增压比。压气机也是最常限制发动机工作范围的部件，因为被推着**逆**压力梯度流动的空气容易从叶片上分离，而压气机中的分离流动可能在几毫秒内演变为失速或喘振。

本章从一个方程出发建立压气机气动力学。**欧拉叶轮机械方程**指出，对每千克气体所做的功等于叶片速度与周向（旋流）速度乘积的变化；其余一切——速度三角形、级负荷、反力度、扩散限制——都是在不使气流分离的前提下选择这一周向速度变化的方法。然后我们把级层面的图景变成整机层面的量：等熵效率与多变效率的区别，带滑移因子的离心压气机，带喘振边界和换算参数的压气机特性图，以及使高增压比压气机在整个转速范围内保持稳定的装置（可调静子、放气活门、多转子）。

全章中，滞止（总）参数带下标$t$——$T_t$、$p_t$、$h_t$——截面编号遵循 SAE ARP 755：截面 2 为压气机进口，截面 3 为压气机出口。压气机总增压比为$\pi_c = p_{t3}/p_{t2}$，其等熵效率为$\eta_c$。除非另有说明，空气为完全气体，$c_p = 1005\ \mathrm{J\,kg^{-1}\,K^{-1}}$，$\gamma = 1.4$，$R = 287\ \mathrm{J\,kg^{-1}\,K^{-1}}$。循环背景见[[propulsion/gas-turbine-cycles]]，滞止状态的热力学见[[thermodynamics/power-cycles]]。

## 物理图景：为什么压气机有很多级

涡轮叶栅使气流加速，而加速的气流容易引导：叶片上的边界层因压力下降而变薄。压气机叶栅则恰恰相反。为了提高压力，每排叶片都必须使气流**扩压**——使其相对叶片减速——而被要求流入升压区的边界层会增厚并最终分离。这就是轴流压气机的级数远多于驱动它们的涡轮的全部原因：典型的大涵道比涡轮风扇发动机的核心机有 10 到 14 级压气机（另加风扇和增压级），由大约 2 级高压涡轮和 4 到 7 级低压涡轮驱动。在叶片边界层分离之前，每一级压气机只能承担不大的增压，核心机的一级约为 1.2 到 1.6。

一个轴流级由**转子**和其后的**静子**组成：转子是装在以叶片速度$U = \omega r$旋转的轮盘上的一圈叶片，静子是一圈固定的导叶。转子给气流增加周向速度，从而对气流做功；其通道还使相对于叶片的气流扩压，提高静压。静子消除周向速度，使绝对气流扩压并进一步提高静压，并把气流以设计角度交给下一个转子。**离心**（径向）压气机以不同的方式完成同样的工作：气流在轴附近轴向进入，在叶轮中转向外，在轮缘处以很大的切向速度离开，因此大部分功是通过半径的增大而不是通过气流转折加入的；随后径向扩压器把动能恢复为压力。一个离心级可以提供 4 到 8 的增压比，这就是小型发动机、直升机涡轮轴发动机以及许多涡轮螺旋桨发动机压气机的末级采用离心式的原因。

## 速度三角形与欧拉方程

转子叶片所看到的气流不同于机匣上的观察者所看到的气流。两个参考系之间的联系就是速度三角形的全部内容。

::: definition 速度三角形 {#def-velocity-triangles}
在给定半径$r$处，叶片以速度$U = \omega r$沿切向运动。**绝对速度**$\mathbf{c}$在静止参考系中测量，**相对速度**$\mathbf{w}$在随叶片旋转的参考系中测量；两者的关系为
$$
\mathbf{c} = \mathbf{w} + \mathbf{U}.
$$
每个速度分解为**轴向**分量（下标$x$）、**切向**或**周向**分量（下标$\theta$），在径向机械中还有**径向**分量（下标$r$）。对轴流压气机，绝对气流角$\alpha$从轴向量起，以旋转方向为正；相对气流角$\beta$从轴向量起，以**逆**旋转方向为正，于是
$$
c_\theta = c_x\tan\alpha, \qquad U - c_\theta = c_x\tan\beta, \qquad \tan\alpha + \tan\beta = \frac{U}{c_x}.
$$
截面 1 为转子进口，截面 2 为转子出口（静子进口），截面 3 为静子出口。**重复级**（标准级）满足$c_3 = c_1$和$\alpha_3 = \alpha_1$，因此相同的级可以串联叠加。
:::

转子把相对气流从大角度$\beta_1$转到较小的角度$\beta_2$——朝向轴向——从而把绝对周向速度从$c_{\theta 1}$增大到$c_{\theta 2}$。这代表多少功，由角动量平衡得出。

::: proposition 欧拉叶轮机械方程 {#prop-euler}
对以角速度$\omega$旋转的转子中的定常绝热流动，质量流量$\dot m$在半径$r_1$处以周向速度$c_{\theta 1}$进入，在半径$r_2$处以周向速度$c_{\theta 2}$离开，则吸收的轴功率为
$$
\dot W = \dot m\,(U_2 c_{\theta 2} - U_1 c_{\theta 1}),
$$
比功等于总焓的增加：
$$
\Delta h_t = h_{t2} - h_{t1} = U_2 c_{\theta 2} - U_1 c_{\theta 1}.
$$ {#eq-euler}
对半径不变、轴向速度不变的轴流级（$U_1 = U_2 = U$，$c_{x1} = c_{x2} = c_x$），
$$
\Delta h_t = U\,(c_{\theta 2} - c_{\theta 1}) = U c_x(\tan\alpha_2 - \tan\alpha_1) = U c_x(\tan\beta_1 - \tan\beta_2).
$$ {#eq-euler-axial}
:::

::: proof
取一个包围转子通道、固定在空间中的控制体。假设流动定常（在一个叶片通过周期内平均），进出口截面上参数均匀，壁面绝热，静止机匣上剪切力产生的力矩可忽略。对轴线的角动量平衡指出，转子作用于流体的力矩$\tau$等于角动量的净流出率：
$$
\tau = \dot m\,(r_2 c_{\theta 2} - r_1 c_{\theta 1}).
$$
只有切向速度分量对轴线携带角动量；轴向和径向分量在该方向上没有力臂。轴传递的功率为$\dot W = \tau\omega$，由$U = \omega r$得$\dot W = \dot m(U_2 c_{\theta 2} - U_1 c_{\theta 1})$。有轴功输入$\dot W$的绝热控制体的稳定流动能量方程为$\dot W = \dot m\,(h_{t2} - h_{t1})$，其中$h_t = h + c^2/2$（气体的势能可忽略）。令两式相等即得[[#eq-euler]]。对轴流级，令$U_1 = U_2$，并利用[[#def-velocity-triangles]]中的$c_\theta = c_x\tan\alpha$和$U - c_\theta = c_x\tan\beta$；差值$c_{\theta 2} - c_{\theta 1}$等于$c_x(\tan\alpha_2 - \tan\alpha_1)$，也等于$(U - c_x\tan\beta_2) - (U - c_x\tan\beta_1) = c_x(\tan\beta_1 - \tan\beta_2)$。

注意证明中**不**需要什么：不需要关于通道内摩擦或损失的任何假设。欧拉方程对总焓增是精确的；损失只体现在总焓增中有多少变成了有用的压力升高。
:::

有两个推论值得立即指出。第一，每级的功按$U^2$变化：在气流角固定时叶片速度加倍，功变为四倍。叶片速度受轮盘和叶片应力以及叶尖相对马赫数的限制，所以核心压气机级的平均叶片速度通常为$300$到$400\ \mathrm{m/s}$。第二，功只取决于周向速度的**变化**，所以在下一个转子进口留下剩余周向速度$c_{\theta 1}$（正的$\alpha_1$，即**预旋**）的静子，会在给定转子出口周向速度时减小功——但它也降低了转子叶尖的相对速度，这就是预旋用于相对马赫数最高的前几级的原因。

在转子中，量$h + w^2/2$——相对参考系中的总焓——沿等半径流线守恒，因为在旋转参考系中叶片静止，不做功。把$h_t = h + c^2/2$与[[#eq-euler-axial]]结合即可证实这一点：$h_2 - h_1 = \tfrac{1}{2}(w_1^2 - w_2^2)$。因此转子中的静焓升由**相对**减速决定，而这正是叶片边界层必须承受的量。

## 级设计参数

三个无量纲数描述速度三角形的形状，从而描述一个级的特性。

::: definition 流量系数、级负荷系数与反力度 {#def-stage-parameters}
对平均叶片速度为$U$的轴流级：

- **流量系数**$\phi = c_x/U$衡量相对于叶片速度的轴向通流；
- **级负荷系数**$\psi = \Delta h_t / U^2$衡量相对于叶片动能的单位质量功；
- **反力度**$R$是级的静焓升中发生在转子中的比例，
$$
R = \frac{h_2 - h_1}{h_3 - h_1}.
$$
:::

::: proposition 由速度三角形求负荷与反力度 {#prop-reaction}
对轴向速度不变的重复轴流压气机级，
$$
\psi = \phi(\tan\beta_1 - \tan\beta_2) = 1 - \phi(\tan\alpha_1 + \tan\beta_2),
\qquad
R = \frac{\phi}{2}(\tan\beta_1 + \tan\beta_2).
$$ {#eq-reaction}
$R = \tfrac{1}{2}$的级具有对称的速度三角形：$\beta_1 = \alpha_2$，$\beta_2 = \alpha_1$。
:::

::: proof
负荷系数由[[#eq-euler-axial]]除以$U^2$得到：$\psi = (c_x/U)(\tan\beta_1 - \tan\beta_2)$。利用[[#def-velocity-triangles]]中的恒等式消去$\tan\beta_1 = 1/\phi - \tan\alpha_1$，即得第二种形式。对反力度，转子静焓升为$h_2 - h_1 = \tfrac{1}{2}(w_1^2 - w_2^2)$（等半径下相对总焓守恒）$= \tfrac{1}{2}c_x^2(\tan^2\beta_1 - \tan^2\beta_2)$，因为轴向分量不变。对重复级$c_3 = c_1$，所以整个级的静焓升等于总焓升：$h_3 - h_1 = h_{t3} - h_{t1} = U c_x(\tan\beta_1 - \tan\beta_2)$（静子不做功）。两者相除，并对平方差因式分解：
$$
R = \frac{\tfrac12 c_x^2(\tan\beta_1 - \tan\beta_2)(\tan\beta_1 + \tan\beta_2)}{U c_x(\tan\beta_1 - \tan\beta_2)} = \frac{\phi}{2}(\tan\beta_1 + \tan\beta_2).
$$
当$R = \tfrac12$时，利用$\tan\alpha_2 = 1/\phi - \tan\beta_2$，有$\phi(\tan\beta_1 + \tan\beta_2) = 1 = \phi(\tan\alpha_2 + \tan\beta_2)$。因此$\tan\beta_1 = \tan\alpha_2$；在进口作同样论证得$\beta_2 = \alpha_1$。假设为轴向速度不变、半径不变和重复级；若半径或轴向速度变化，公式中会出现附加项。
:::

[[#eq-reaction]]中$\psi$的第二种形式是级的理想**特性线**：在叶片出口角固定时（$\alpha_1$由上游静子决定，$\beta_2$由转子叶片决定），负荷系数随流量系数增大而**下降**。这一负斜率对稳定性很重要。如果流经机器的流量稍有下降，级做更多的功，产生更大的增压，从而把流量推回去。在接近失速时，实际特性线变平然后翻转，这一稳定机制就丧失了——这就是下面讨论的喘振的起源。

核心压气机的典型值为$\phi \approx 0.4$–$0.7$，$\psi \approx 0.3$–$0.45$，$R \approx 0.5$–$0.7$。接近二分之一的反力度使转子和静子平均分担扩压，因此对于各排叶片同样受扩压限制的级，这是一个自然的选择。

## 一排叶片能承受多大的扩压

级的功随转折量$\tan\beta_1 - \tan\beta_2$增大，而转折量受叶片边界层所能承受的减速程度的限制。日常使用的有两个经验准则；两者都是叶栅实验的总结，都不是定律。

最早的是**德哈勒准则**（de Haller，1953年）：叶栅前后的速度比不应低于约$0.72$，
$$
\frac{w_2}{w_1} \ge 0.72 \ \ \text{（转子）}, \qquad \frac{c_3}{c_2} \ge 0.72 \ \ \text{（静子）}.
$$ {#eq-dehaller}
这是一个粗糙的规则，因为它忽略了叶片间距：叶片排列紧密的叶栅把转折分摊给更多的叶片，可以扩压得更多。

更精细的准则是 Lieblein、Schwenk 和 Broderick 的**扩散因子**（NACA RM E53D01，1953年），它估计吸力面上的峰值速度并将其与出口速度比较：
$$
D = 1 - \frac{w_2}{w_1} + \frac{\lvert w_{\theta 1} - w_{\theta 2}\rvert}{2\sigma w_1},
\qquad \sigma = \frac{\text{弦长}}{\text{栅距}},
$$ {#eq-diffusion-factor}
这里写的是转子的形式（对静子使用绝对速度）。NACA 叶栅和转子数据的关联表明，在转子叶尖$D$不超过约$0.45$、在叶根和平均半径处不超过约$0.55$–$0.6$时，叶型损失保持在低水平，超过之后急剧上升。**稠度**$\sigma$之所以出现，是因为单位周长上叶片越多，每个叶片的负荷越低。

::: example 由速度三角形求一个轴流级 {#ex-axial-stage}
核心压气机的一个重复级以平均叶片速度$U = 350\ \mathrm{m/s}$工作，轴向速度$c_x = 175\ \mathrm{m/s}$。上游静子以$\alpha_1 = 20^\circ$输出气流，转子叶片把相对气流转到$\beta_2 = 45^\circ$。求转子进口相对气流角、总温升、负荷系数和反力度，并校核德哈勒数和扩散因子（稠度$\sigma = 1.2$）。若级等熵效率为$0.90$，进口总温为$288\ \mathrm{K}$，级增压比是多少？
::: solution
**速度三角形。** $\phi = 175/350 = 0.500$，所以$\tan\beta_1 = 1/\phi - \tan\alpha_1 = 2 - 0.3640 = 1.6360$，$\beta_1 = 58.57^\circ$。在转子出口，$\tan\alpha_2 = 1/\phi - \tan\beta_2 = 2 - 1 = 1$，所以$\alpha_2 = 45.00^\circ$。

**功。** 由[[#eq-euler-axial]]，
$$
\Delta h_t = U c_x(\tan\beta_1 - \tan\beta_2) = 350 \times 175 \times (1.6360 - 1.0000) = 38.96\ \mathrm{kJ/kg},
\qquad
\Delta T_t = \frac{38\,960}{1005} = 38.8\ \mathrm{K}.
$$

**系数。** $\psi = 38\,960/350^2 = 0.318$，$R = \tfrac{1}{2}(0.5)(1.6360 + 1.0000) = 0.659$。

**扩压。** $w_1 = c_x/\cos\beta_1 = 175/0.5216 = 335.6\ \mathrm{m/s}$，$w_2 = 175/\cos 45^\circ = 247.5\ \mathrm{m/s}$，所以$w_2/w_1 = 0.738$——刚好在德哈勒极限之内。静子的$c_3/c_2 = \cos\alpha_2/\cos\alpha_1 = 0.7071/0.9397 = 0.752$，也可以接受。扩散因子为
$$
D = 1 - 0.738 + \frac{175 \times 0.636}{2 \times 1.2 \times 335.6} = 0.262 + 0.138 = 0.401,
$$
充分低于$0.45$。

**增压比。** 取$T_{t1} = 288\ \mathrm{K}$，
$$
\frac{p_{t3}}{p_{t1}} = \left(1 + \eta_s\frac{\Delta T_t}{T_{t1}}\right)^{\gamma/(\gamma-1)} = \left(1 + 0.90 \times \frac{38.76}{288}\right)^{3.5} = 1.49.
$$

**合理性校核。** $0.32$的负荷系数和$1.5$的级增压比是核心机前面级的典型值。温升相同的后面级的增压比会更小，因为相同的$\Delta T_t$在更高的$T_t$中所占比例更小。实际的级所做的功也比中径速度三角形预测的略少，因为端壁边界层增厚使轴向速度分布在半叶高处出现峰值；设计者对前几级乘以约$0.98$的**做功因子**，在长压气机中逐渐降到$0.85$（Howell 的经验修正）。
:::
:::

::: warning 混淆角度约定
各教材对$\beta$是从轴向还是从切向量起、以及它的正负号说法不一。按[[#def-velocity-triangles]]的约定，每个截面上都有$\tan\alpha + \tan\beta = U/c_x$，而在压气机转子中$\beta_1 > \beta_2$（相对气流**朝向**轴线转折）。如果算出的功为负，或反力度大于 1，几乎可以肯定是把切向角公式和轴向角数据混在了一起，或者丢了$w_\theta$的符号。在写任何方程之前先画出速度三角形——叶片速度水平，轴向速度竖直——并检查$w_\theta + c_\theta = U$。
:::

## 等熵效率与多变效率

40 的总增压比是通过叠加许多级达到的，而整叠的效率并不等于一级的效率。原因是热力学的而不是气动的：前面级的损失加热了气体，而更热的气体通过下一个增压比需要更多的功——这就是**预热效应**。**多变**效率消除了这一效应，描述叶片本身的品质。

::: definition 压气机的等熵效率与多变效率 {#def-polytropic}
压气机的**等熵效率**是相同总压之间理想（等熵）功与实际功之比：
$$
\eta_c = \frac{h_{t3s} - h_{t2}}{h_{t3} - h_{t2}} = \frac{T_{t3s} - T_{t2}}{T_{t3} - T_{t2}} \quad\text{（完全气体）}.
$$
**多变**（小级）效率$\eta_p$是无穷小压缩步的等熵效率$\eta_p = \mathrm{d}h_{ts}/\mathrm{d}h_t$，假设它在整台机器中为常数。
:::

::: proposition 由多变效率求等熵效率 {#prop-polytropic}
对$c_p$为常数、$\eta_p$为常数的完全气体，
$$
\frac{T_{t3}}{T_{t2}} = \pi_c^{(\gamma-1)/(\gamma\eta_p)},
\qquad
\eta_c = \frac{\pi_c^{(\gamma-1)/\gamma} - 1}{\pi_c^{(\gamma-1)/(\gamma\eta_p)} - 1}.
$$ {#eq-polytropic}
当$\pi_c > 1$且$\eta_p < 1$时，$\eta_c < \eta_p$，且$\eta_c$随$\pi_c$增大而下降。
:::

::: proof
对等熵步，把吉布斯关系$T\,\mathrm{d}s = \mathrm{d}h - v\,\mathrm{d}p$用于滞止状态，得$\mathrm{d}h_{ts} = v_t\,\mathrm{d}p_t = (R T_t/p_t)\,\mathrm{d}p_t$。该步中的实际焓变为$\mathrm{d}h_t = \mathrm{d}h_{ts}/\eta_p = c_p\,\mathrm{d}T_t$。因此
$$
c_p\,\mathrm{d}T_t = \frac{R T_t}{\eta_p}\frac{\mathrm{d}p_t}{p_t}
\quad\Longrightarrow\quad
\frac{\mathrm{d}T_t}{T_t} = \frac{\gamma-1}{\gamma\eta_p}\frac{\mathrm{d}p_t}{p_t},
$$
其中用到了$R/c_p = (\gamma-1)/\gamma$。在$\eta_p$为常数时从截面 2 积分到截面 3，得$T_{t3}/T_{t2} = \pi_c^{(\gamma-1)/(\gamma\eta_p)}$。等熵温比为$\pi_c^{(\gamma-1)/\gamma}$，把两者代入$\eta_c$的定义即得[[#eq-polytropic]]。

为证明$\eta_c < \eta_p$，记$a = (\gamma-1)/\gamma\cdot\ln\pi_c > 0$，于是$\eta_c = (e^{a} - 1)/(e^{a/\eta_p} - 1)$。函数$g(x) = (e^{x}-1)/x$在$x > 0$时递增，且$a/\eta_p > a$，所以$(e^{a/\eta_p}-1)/(a/\eta_p) > (e^{a}-1)/a$，整理即得$\eta_c < \eta_p$。当$\pi_c \to 1$时$a \to 0$，$\eta_c \to \eta_p$：单个小级的等熵效率等于其多变效率。
:::

::: example 高增压比压气机的总效率 {#ex-polytropic}
某涡轮风扇发动机的核心压气机（增压级加高压压气机）总增压比$\pi_c = 40$，多变效率$\eta_p = 0.90$，$T_{t2} = 288\ \mathrm{K}$。求等熵效率、出口温度和比功。若每一级都产生[[#ex-axial-stage]]的温升，大约需要多少级？
::: solution
指数为$(\gamma - 1)/\gamma = 0.2857$和$0.2857/0.90 = 0.3175$。于是
$$
\frac{T_{t3}}{T_{t2}} = 40^{0.3175} = 3.225, \qquad T_{t3} = 928.9\ \mathrm{K},
$$
而等熵温比为$40^{0.2857} = 2.868$。因此
$$
\eta_c = \frac{2.868 - 1}{3.225 - 1} = 0.840,
\qquad
\Delta h_t = c_p(T_{t3} - T_{t2}) = 1005 \times 640.9 = 644\ \mathrm{kJ/kg}.
$$
每级$\Delta T_t = 38.8\ \mathrm{K}$，$640.9/38.8 = 9.9$，所以约需十级——实际上更多，因为做功因子减小了实际温升，而叶片短、端壁边界层厚的后面级负荷更轻。

**合理性校核。** 起飞时约$930\ \mathrm{K}$的出口温度是现代发动机的典型值，也是进一步提高增压比的约束之一：末级轮盘和燃烧室进口都承受这一温度。$\eta_p$与$\eta_c$之间六个百分点的效率差，正是长压气机的预热代价。
:::
:::

## 离心压气机

在离心压气机中，气流在叶尖半径$r_2$处径向离开叶轮，那里的叶片速度为$U_2$。若无进口预旋（$c_{\theta 1} = 0$），欧拉方程化为$\Delta h_t = U_2 c_{\theta 2}$。如果流体恰好沿径向叶片的方向离开叶轮，$c_{\theta 2}$将等于$U_2$，功将为$U_2^2$。但实际并非如此：每个叶片两面之间的压差（正是它传递力矩）也在每个通道中建立起相对环流，气流离开时的周向速度小于叶片所要施加的值。这就是**滑移**。

::: definition 滑移因子与功率输入系数 {#def-slip}
**滑移因子**是实际出口周向速度与理想导向所给出的周向速度之比。对径向叶片，
$$
\sigma_s = \frac{c_{\theta 2}}{U_2},
$$
对从径向后弯角度$\beta_{2b}$的叶片，它相对于与叶片一致的周向速度定义。**功率输入系数**$\psi_p \ge 1$计入轮盘摩擦和鼓风损失所吸收的额外功，这部分功加热气体而不增加周向速度。径向叶片、无进口预旋的叶轮的总温升为
$$
\Delta T_t = \frac{\psi_p\,\sigma_s U_2^2}{c_p}.
$$ {#eq-centrifugal}
:::

实践中滑移因子不是从第一性原理导出的，而是取自关联式。对径向叶片，Stanitz（1952年）的公式
$$
\sigma_s \approx 1 - \frac{0.63\pi}{Z},
$$ {#eq-stanitz}
（$Z$为叶片数）与数据吻合良好；对后弯叶轮，通常选用 Wiesner（1967年）的关联式
$$
\sigma_s \approx 1 - \frac{\sqrt{\cos\beta_{2b}}}{Z^{0.7}}, \qquad c_{\theta 2} = U_2\left(\sigma_s - \phi_2\tan\beta_{2b}\right),\quad \phi_2 = \frac{c_{r2}}{U_2}.
$$ {#eq-wiesner}
对常规叶片数（约 15 到 30），两者的精度都在百分之几以内，而对叶片很少的情形不可靠。

x: 6, 40
y: 0.6, 1
sliders: b=30:0:50:1

:::

尽管后弯叶片单位$U_2^2$的功较低，几乎所有现代离心压气机都采用它：它降低绝对出口速度（从而减轻扩压器的任务），由于特性线向下倾斜而拓宽稳定流量范围，并降低叶轮出口马赫数。代价是相同增压比需要更高的叶尖速度，以$U_2 = 500$–$600\ \mathrm{m/s}$运转的钛合金叶轮很常见。

::: example 径向叶片离心压气机 {#ex-centrifugal}
一个叶尖直径$0.50\ \mathrm{m}$的叶轮以$20\,000\ \mathrm{rpm}$旋转，有$19$片径向叶片，功率输入系数$1.04$，无进口预旋。进口总温为$288.15\ \mathrm{K}$，压气机等熵效率为$0.80$。求叶尖速度、总温升和增压比，以及流量为$5.0\ \mathrm{kg/s}$时的轴功率。
::: solution
**叶尖速度。** $U_2 = \pi D_2 N/60 = \pi \times 0.50 \times 20\,000/60 = 523.6\ \mathrm{m/s}$。

**滑移。** 由[[#eq-stanitz]]，$\sigma_s = 1 - 0.63\pi/19 = 0.896$。

**温升。** 由[[#eq-centrifugal]]，
$$
\Delta T_t = \frac{1.04 \times 0.896 \times 523.6^2}{1005} = 254.2\ \mathrm{K}.
$$

**增压比。**
$$
\pi_c = \left(1 + 0.80\times\frac{254.2}{288.15}\right)^{3.5} = 6.48.
$$

**功率。** $\dot W = \dot m c_p\Delta T_t = 5.0 \times 1005 \times 254.2 = 1.28\ \mathrm{MW}$。

**合理性校核。** 单级 6.5 处于已实现水平的上端，意味着离开叶轮的绝对速度是超声速的（$c_{\theta 2} = 0.896 \times 523.6 = 469\ \mathrm{m/s}$，而出口静温至多为$542 - 469^2/2010 \approx 433\ \mathrm{K}$，该温度下声速为$\sqrt{1.4 \times 287 \times 433} \approx 417\ \mathrm{m/s}$），这需要精心设计的叶片式扩压器。在这一叶尖速度下的径向叶片叶轮对小型涡轮轴发动机是合理的；后弯设计要达到相同增压比需要更高的转速。
:::
:::

## 压气机特性图、失速与喘振

压气机的性能画在**特性图**上：增压比对质量流量，带有等转速线和效率等值线。为了使一张特性图适用于所有进口条件，变量被无量纲化——或者像工业界那样，**换算**到标准海平面条件。

::: definition 换算质量流量与换算转速 {#def-corrected}
取$\theta = T_{t2}/T_{\mathrm{ref}}$和$\delta = p_{t2}/p_{\mathrm{ref}}$，其中$T_{\mathrm{ref}} = 288.15\ \mathrm{K}$，$p_{\mathrm{ref}} = 101.325\ \mathrm{kPa}$（国际标准大气海平面），**换算质量流量**和**换算转速**为
$$
\dot m_c = \frac{\dot m\sqrt{\theta}}{\delta}, \qquad N_c = \frac{N}{\sqrt{\theta}}.
$$
对给定的机器和气体，$\pi_c$和$\eta_c$只是$\dot m_c$和$N_c$的函数（忽略雷诺数效应）。
:::

其依据是量纲分析：支配压气机的无量纲组合是$\dot m\sqrt{RT_t}/(D^2 p_t)$、$ND/\sqrt{RT_t}$、增压比和效率，$\gamma$和雷诺数是附加参数。固定机器（其直径$D$）和气体（$R$、$\gamma$）并忽略雷诺数，两个独立组合就简化为换算量。单位面积的换算质量流量与轴向马赫数直接相关，换算转速与叶片马赫数直接相关——所以换算值相等意味着速度三角形相同。

在每条等转速线上，增压比随节流而升高，直到该线终止于**喘振边界**。在右侧，等转速线在气流**壅塞**处变为竖直——某排叶片在其喉部达到声速，不能再通过更多流量。发动机沿由涡轮和喷管确定的**共同工作线**运行（见[[propulsion/turbines]]），**喘振裕度**是工作线与喘振边界之间的距离，通常在等换算流量下定义为
$$
\mathrm{SM} = \frac{\pi_{c,\text{喘振}} - \pi_{c,\text{工作}}}{\pi_{c,\text{工作}}}
$$
（各公司定义不同；务必说明你使用的是哪一种）。民用发动机设计的喘振裕度约为 15–25 %，以应对过渡态、进口畸变和性能衰退。

喘振边界之外有两种不稳定性。**旋转失速**是一种局部现象：一个或多个由失速、低流量通道组成的失速团以转子转速的一部分（通常为 30–70 %）沿环形通道传播，因为绕过失速团的气流增大了其前方叶片的攻角，并卸载了其后方的叶片。平均流量几乎是定常的，但叶片振动可能具有破坏性。**喘振**是一种系统不稳定性：压气机不再能维持下游容腔（燃烧室和管道）中的压力，整台机器的流量崩溃甚至倒流，容腔排空，然后以几赫兹的频率循环往复，伴有巨响，在发动机中还会有火焰从进气道喷出。其原因是[[#prop-reaction]]之后描述的特性线翻转：一旦$\mathrm{d}\pi_c/\mathrm{d}\dot m$变为正值，流量的微小减少就会降低增压，而流量减少随之加剧。

高增压比压气机难以在偏离设计转速时运行，原因很简单。在设计点，40:1 的压气机中密度增大约 12 倍，环形通道面积相应缩小。在低转速下，增压小得多，密度增大不足，而按稠密空气确定尺寸的后面级必须通过更大的体积流量：它们在高$\phi$下工作并壅塞，而前面级在低$\phi$下工作并失速。常用三种对策，经常同时使用：

- **可调静子叶片。** 随转速下降转动进口导叶和前几排静子，关小以增加预旋并降低前面级的攻角。
- **放气活门。** 在低转速时从压气机中部放出空气，提高前面级的流量系数并卸载后面级。
- **多转子。** 把压气机分成装在不同轴上的低压和高压部分，各由自己的涡轮驱动，使每部分都能找到自己的转速。三转子发动机把这一思想更进一步。

::: example 巡航时的换算流量 {#ex-corrected}
一台压气机在国际标准大气海平面静止条件下以$10\,000\ \mathrm{rpm}$通过$100\ \mathrm{kg/s}$。巡航时，在国际标准大气$11\ \mathrm{km}$高度（$T = 216.65\ \mathrm{K}$，$p = 22.63\ \mathrm{kPa}$）、马赫数 0.80 下，发动机以相同的换算转速和换算流量（特性图上的同一点）运行。假设进气道理想，实际质量流量和物理转速是多少？
::: solution
理想进气道：滞止参数等于自由流滞止参数，
$$
T_{t2} = 216.65\,(1 + 0.2 \times 0.8^2) = 244.4\ \mathrm{K},
\qquad
p_{t2} = 22.63\,(1.128)^{3.5} = 34.50\ \mathrm{kPa}.
$$
于是$\theta = 244.4/288.15 = 0.848$，$\delta = 34.50/101.325 = 0.340$。换算流量相同：
$$
\dot m = \frac{\dot m_c\,\delta}{\sqrt{\theta}} = \frac{100 \times 0.3405}{\sqrt{0.848}} = 37.0\ \mathrm{kg/s},
\qquad
N = N_c\sqrt{\theta} = 10\,000\sqrt{0.848} = 9\,210\ \mathrm{rpm}.
$$
**合理性校核。** 巡航时发动机只吸入其海平面质量流量的约三分之一，因为空气密度只有三分之一，然而压气机在气动上做的事完全相同——相同的速度三角形、相同的增压比——只是在冷空气中转速约低 8 %。这就是为什么即使在相近的换算状态下，巡航推力也只是起飞推力的一小部分。
:::
:::

::: quiz
对一个压气机级节流，使其流量系数下降而叶片角保持不变。按照理想级特性线，会发生什么？
- [ ] 负荷系数下降，德哈勒数上升。
- [x] 负荷系数上升，转子德哈勒数下降，使级趋向失速。
- [ ] 两者都不变，因为叶片角固定。
- [ ] 反力度必须保持为二分之一。
::: solution
在$\alpha_1$和$\beta_2$固定时，$\psi = 1 - \phi(\tan\alpha_1 + \tan\beta_2)$随$\phi$下降而上升。进口相对气流角$\beta_1$增大（攻角增大），$w_1$相对$w_2$增大，比值$w_2/w_1$向德哈勒极限下降——级趋近失速。反力度也会改变，因为$\tan\beta_1$改变了。
:::
:::

::: history
查尔斯·**帕森斯**（Charles Parsons）于1884年制造了第一台实用的反动式汽轮机，他在 20 世纪最初几年还通过反向运转涡轮式叶片制造了轴流压气机；由于叶片不是按翼型设计的，效率很低，早期燃气轮机工作以离心压气机为主。1926年7月，皇家飞机研究院（RAE）的 A. A. **格里菲斯**（A. A. Griffith）写出了《涡轮设计的气动理论》（*An Aerodynamic Theory of Turbine Design*，RAE 报告 H1111），指出现有叶片实际上处于失速状态工作，压气机叶片应按翼型设计；此后几年 RAE 的试验台试验证实了轴流级可以做得很高效。弗兰克·**惠特尔**（Frank Whittle）于1937年4月12日运转的第一台发动机采用单级双面离心压气机，1941年5月在格罗斯特 E.28/39 上飞行的 W.1 也是如此。20 世纪 50 年代，NACA 系统的叶栅研究计划以及 Lieblein、Schwenk 和 Broderick 的扩散因子（1953年）为设计者提供了经验负荷极限，其改进形式一直沿用至今。
:::

::: summary
- **欧拉方程**$\Delta h_t = U_2 c_{\theta 2} - U_1 c_{\theta 1}$是一个精确的角动量结果：功等于叶片速度与周向速度乘积的变化。
- **速度三角形**通过$\mathbf{c} = \mathbf{w} + \mathbf{U}$联系绝对和相对参考系；在轴流级中$\Delta h_t = U c_x(\tan\beta_1 - \tan\beta_2)$。
- **流量系数**$\phi$、**负荷系数**$\psi$和**反力度**$R = \tfrac{\phi}{2}(\tan\beta_1 + \tan\beta_2)$确定级的形状；核心机典型值为$\phi \approx 0.5$，$\psi \approx 0.35$，$R \approx 0.5$–$0.7$。
- 压气机叶栅使气流**扩压**；德哈勒数（$\ge 0.72$）和 Lieblein **扩散因子**（$D \lesssim 0.45$–$0.6$）是经验极限，它们确定每级的功，从而确定级数。
- **多变效率**衡量叶片品质；由于预热，总等熵效率随增压比提高而低于多变效率。
- **离心**级的大部分功来自$U_2^2$，因**滑移**而减小（Stanitz、Wiesner 关联式），因轮盘摩擦而增大。
- 以换算流量和换算转速表示的**特性图**用**喘振**和**壅塞**界定工作范围；可调静子、放气和多转子使高增压比压气机在部分转速下保持稳定。
:::

## 习题

::: exercise {level=1 check="182.25"}
某离心叶轮叶尖速度$U_2 = 450\ \mathrm{m/s}$，气流离开时的周向速度$c_{\theta 2} = 0.90\,U_2$；无进口预旋。比功输入是多少？（以 kJ/kg 为单位输入功。）
::: solution
由于$c_{\theta 1} = 0$，[[#eq-euler]]给出$\Delta h_t = U_2 c_{\theta 2} = 450 \times 405 = 182\,250\ \mathrm{J/kg} = 182.25\ \mathrm{kJ/kg}$。相应的温升为$182\,250/1005 = 181\ \mathrm{K}$。
:::
:::

::: exercise {level=1 check="0.864"}
某压气机的多变效率为$0.90$，增压比为$10$。其等熵效率是多少？（以小数输入效率，保留三位有效数字。）
::: solution
$10^{0.2857} = 1.931$，$10^{0.2857/0.9} = 10^{0.3175} = 2.077$。所以$\eta_c = 0.931/1.077 = 0.864$。比较[[#ex-polytropic]]中$\pi_c = 40$时的$0.840$。
:::
:::

::: exercise {level=1 check="75.5"}
一台发动机在高空模拟试车台上吸入$40\ \mathrm{kg/s}$，压气机进口滞止参数为$T_{t2} = 250\ \mathrm{K}$、$p_{t2} = 50\ \mathrm{kPa}$。换算质量流量是多少？（以 kg/s 为单位输入，保留三位有效数字。）
::: solution
$\theta = 250/288.15 = 0.8676$，$\delta = 50/101.325 = 0.4935$。$\dot m_c = 40\sqrt{0.8676}/0.4935 = 75.5\ \mathrm{kg/s}$。换算流量大于实际流量，因为空气密度比参考状态低。
:::

一台增压比为$20$、多变效率为$0.90$的压气机吸入$T_{t2} = 288\ \mathrm{K}$的空气。每一级最多能提供$40\ \mathrm{K}$的总温升。最少需要多少级（整数）？（输入级数。）

::: exercise {level=2 check="0.678"}
设计者提出一个反力度为 50 % 的级，$\phi = 0.50$，$\psi = 0.40$。求相对气流角$\beta_1$和$\beta_2$以及转子德哈勒数。这个级可以接受吗？（输入$w_2/w_1$，保留三位有效数字。）
::: hint
联立求解$R = \tfrac{\phi}{2}(\tan\beta_1 + \tan\beta_2)$和$\psi = \phi(\tan\beta_1 - \tan\beta_2)$。
:::
::: solution
两式相加和相减：$\tan\beta_1 = (R + \psi/2)/\phi = 0.70/0.50 = 1.40$，$\tan\beta_2 = (R - \psi/2)/\phi = 0.30/0.50 = 0.60$。所以$\beta_1 = 54.46^\circ$，$\beta_2 = 30.96^\circ$。在$c_x$不变时，$w_2/w_1 = \cos\beta_1/\cos\beta_2 = 0.5812/0.8575 = 0.678$。这低于$0.72$：转子过度扩压。可以降低负荷系数、提高流量系数，或者（由于德哈勒准则忽略稠度）在否定它之前用高稠度校核扩散因子。

::: exercise {level=2 check="4.18"}
一个后弯离心叶轮有$Z = 20$片叶片，后弯角$\beta_{2b} = 30^\circ$，叶尖速度$U_2 = 500\ \mathrm{m/s}$，出口流量系数$\phi_2 = c_{r2}/U_2 = 0.30$，无进口预旋。利用 Wiesner 关联式，求$T_{t1} = 288.15\ \mathrm{K}$、$\eta_c = 0.82$（功率输入系数取$1$）时的出口周向速度、比功和增压比。（输入增压比，保留三位有效数字。）
::: solution
$\sigma_s = 1 - \sqrt{\cos 30^\circ}/20^{0.7} = 1 - 0.9306/8.141 = 0.886$。于是$c_{\theta 2} = 500(0.886 - 0.30\tan 30^\circ) = 500(0.886 - 0.173) = 356.2\ \mathrm{m/s}$。功$= U_2 c_{\theta 2} = 178.1\ \mathrm{kJ/kg}$，$\Delta T_t = 177.2\ \mathrm{K}$，$\pi_c = (1 + 0.82 \times 177.2/288.15)^{3.5} = 4.18$。相同转速下的径向叶片叶轮约给出$\sigma_s U_2^2 = 0.90 \times 500^2 = 225\ \mathrm{kJ/kg}$：后弯损失了功，但换来了稳定性和更低的出口马赫数。
:::

::: exercise {level=3}
从[[#eq-polytropic]]出发，证明对增压比很小的压气机$\pi_c = 1 + \varepsilon$（$\varepsilon \ll 1$），等熵效率为
$$
\eta_c \approx \eta_p\left[1 - \frac{\gamma-1}{2\gamma}\left(\frac{1}{\eta_p} - 1\right)\varepsilon\right],
$$
并从物理上解释为什么修正项为负。
::: solution
记$k = (\gamma-1)/\gamma$，$a = k\ln(1+\varepsilon) \approx k\varepsilon$。展开$e^{x} - 1 = x(1 + x/2 + \dots)$。于是
$$
\eta_c = \frac{a(1 + a/2)}{(a/\eta_p)(1 + a/(2\eta_p))} = \eta_p\frac{1 + a/2}{1 + a/(2\eta_p)} \approx \eta_p\left[1 + \frac{a}{2}\left(1 - \frac{1}{\eta_p}\right)\right],
$$
把$a$换成$k\varepsilon$即得结果（$\ln(1+\varepsilon)$的$O(\varepsilon^2)$部分只影响更高阶）。由于$\eta_p < 1$，方括号小于 1。物理上，压缩前一部分中的损失提高了进入后一部分的气体温度，而通过给定增压比所需的功与进口温度成正比；没有这种预热的理想过程是$\eta_c$的参考，所以整叠看起来比其各部分的效率都低。
:::

::: exercise {level=3}
**设计。** 为一台 10 级重复级压气机勾画初步中径设计，要求达到$\pi_c = 8$，$\eta_p = 0.91$，$T_{t2} = 288\ \mathrm{K}$，平均叶片速度不超过$350\ \mathrm{m/s}$。选择$\phi$、$\psi$和$R$，求叶片角和气流角，并用德哈勒准则和稠度$1.3$下$0.45$的扩散因子极限校核每排叶片。说明如果校核不通过你会改变什么。
::: solution
**所需的功。** $T_{t3}/T_{t2} = 8^{0.2857/0.91} = 8^{0.3140} = 1.921$，所以总的$\Delta T_t = 265\ \mathrm{K}$，每级$26.5\ \mathrm{K}$，即每级$26.7\ \mathrm{kJ/kg}$。考虑$0.90$的平均做功因子，每级按$\Delta h_t = 29.6\ \mathrm{kJ/kg}$设计。

**负荷。** 取$U = 350\ \mathrm{m/s}$，$\psi = 29\,600/350^2 = 0.242$——负荷较轻，留有余地。选择$\phi = 0.50$（$c_x = 175\ \mathrm{m/s}$）和$R = 0.5$。于是$\tan\beta_1 = (R + \psi/2)/\phi = 1.242$，$\tan\beta_2 = (R - \psi/2)/\phi = 0.758$，得$\beta_1 = \alpha_2 = 51.2^\circ$，$\beta_2 = \alpha_1 = 37.2^\circ$。

**校核。** $w_2/w_1 = \cos 51.2^\circ/\cos 37.2^\circ = 0.627/0.797 = 0.787 > 0.72$（由对称性，静子的比值相同）。扩散因子：$w_1 = 175/0.627 = 279\ \mathrm{m/s}$，$\Delta w_\theta = 175 \times 0.483 = 84.6\ \mathrm{m/s}$，$D = 1 - 0.787 + 84.6/(2 \times 1.3 \times 279) = 0.213 + 0.117 = 0.33$，远在极限之内。

**判断。** 该级负荷较轻；可以降低叶片速度（降低应力），采用更少但负荷更高的级，或者为叶根截面保留裕度，那里叶片速度较低而当地$\psi$较高。前面级还需要校核叶尖相对马赫数$w_{1,\text{叶尖}}$，在较大的叶尖半径处它可能接近或超过 1。如果校核不通过，可用的手段依次为：增大稠度（减小$D$，但不改变德哈勒数）、增大$\phi$（在给定功时减小转折）、增加一级，或在应力允许时提高$U$。答案会因所作选择而异；重要的是每一个选择都要用两个准则校核。
:::
