燃烧室是燃气涡轮发动机获得能量的地方。在压气机出口与涡轮进口之间，煤油被喷入空气并燃烧，在几十厘米长的空间里把温度从约$800\ \mathrm{K}$提高到$1600\ \mathrm{K}$或更高，燃气在几毫秒内流过这一空间。燃烧室不做功，也没有活动部件，却是最难设计的部件之一，因为它必须满足一系列相互矛盾的要求：从地面慢车到起飞的每个功率状态都完全燃烧；高空熄火后能重新点火；压力损失小；出口温度分布是涡轮能够承受的；火焰筒在辐射火焰中能工作数万小时；以及——越来越成为主导约束的——氮氧化物、一氧化碳、未燃碳氢化合物和碳烟的排放低。

本章像工程师在初步设计阶段那样处理燃烧室。我们首先求出给定温升所需的燃油量，并看到为什么总体混合气太贫，无法自行燃烧。这引出了分区燃烧室：只有一部分空气在接近化学恰当比的主燃区中与燃油相遇，其余的在下游加入。然后讨论火焰稳定与停留时间、压力损失和流经火焰筒孔的流动、预测燃烧效率的关联式，最后是污染物生成的化学以及由此推动的贫油燃烧设计。滞止参数带下标$t$；截面 3 为燃烧室进口（压气机出口），截面 4 为燃烧室出口（涡轮进口）。空气为完全气体，$R = 287\ \mathrm{J\,kg^{-1}\,K^{-1}}$；对高温混合物取平均$c_p = 1150\ \mathrm{J\,kg^{-1}\,K^{-1}}$。Jet A 煤油的低热值为$43\ \mathrm{MJ/kg}$。热化学内容见[[thermodynamics/mixtures-combustion]]。

## 要求与基本布局

现代航空发动机燃烧室几乎总是**环形**的：一个环状的火焰筒（**内衬**）位于压气机与涡轮之间的环形机匣内。早期发动机使用围绕轴布置的独立**单管**燃烧室，中间形式的**环管**燃烧室把独立的火焰筒置于共同的环形机匣内；环形设计胜出，因为它最短、最轻，需要冷却的湿面积最小。每种布局中都有相同的元件：

- **扩压器**，以尽可能小的压力损失把压气机出口空气从约$150\ \mathrm{m/s}$减速到每秒几十米；
- 火焰筒上游端带有燃油喷嘴和旋流器的**头部**；
- 火焰筒本身，上面开有成排的孔，空气分段由此进入；
- 火焰筒外侧的环形通道，输送尚未进入的空气。

燃油喷嘴把液态煤油雾化成几十微米量级的液滴，液滴在燃烧之前先蒸发并与空气混合。较早的发动机使用**压力旋流**雾化喷嘴，由燃油压力本身驱动旋转的液膜破碎；几乎所有现代发动机都使用**空气雾化**喷嘴，利用流经旋流器的高速空气撕碎薄燃油膜，得到随燃油流量变化很小的细雾。

## 油气比与当量比

::: definition 油气比与当量比 {#def-equivalence-ratio}
**油气比**是燃油质量流量与空气质量流量之比，$f = \dot m_f/\dot m_a$。**化学恰当**油气比$f_{st}$是空气中的氧恰好足以把全部碳氧化为$\mathrm{CO_2}$、全部氢氧化为$\mathrm{H_2O}$时的值。**当量比**为
$$
\Phi = \frac{f}{f_{st}},
$$
$\Phi < 1$为**贫油**混合气（空气过量），$\Phi > 1$为**富油**混合气（燃油过量）。（我们记作$\Phi$，以便把$\phi$留给[[propulsion/compressors]]中的流量系数。）
:::

煤油是数百种碳氢化合物的混合物；就化学计量而言，它可以很好地用替代分子式$\mathrm{C_{12}H_{23}}$（摩尔质量$167.3\ \mathrm{kg/kmol}$）表示。完全燃烧每摩尔燃料需要$12 + 23/4 = 17.75$摩尔$\mathrm{O_2}$，每摩尔$\mathrm{O_2}$伴随$1/0.2095 = 4.77$摩尔空气（摩尔质量$28.97\ \mathrm{kg/kmol}$），所以
$$
f_{st} = \frac{167.3}{17.75 \times 4.77 \times 28.97} = 0.068,
$$ {#eq-fst}
即空燃比约为$14.7$。这个数值值得记住：对氢碳比接近 2 的所有碳氢燃料，它几乎相同。

::: proposition 由能量平衡求油气比 {#prop-far}
对绝热燃烧室，进口空气温度为$T_{t3}$，燃油约以参考温度$T_{\mathrm{ref}} = 298\ \mathrm{K}$供入，燃烧效率为$\eta_b$，产物以$T_{t4}$离开，并且在该温度范围内对空气和产物取单一平均比热容$\bar c_p$，则
$$
f = \frac{\bar c_p\,(T_{t4} - T_{t3})}{\eta_b Q_R - \bar c_p\,(T_{t4} - T_{\mathrm{ref}})},
$$ {#eq-far}
其中$Q_R$为燃料的低热值。
:::

::: proof
对包围燃烧室的控制体应用稳定流动能量方程：无轴功，通过机匣的散热可忽略，动能变化包含在总焓中。焓从定义热值的$T_{\mathrm{ref}}$起算。空气带入$\dot m_a\bar c_p(T_{t3} - T_{\mathrm{ref}})$；燃油在$T_{\mathrm{ref}}$下不带入显焓，但释放化学能$\eta_b\dot m_f Q_R$，其中$\eta_b < 1$计入因燃烧不完全而未释放的部分。产物带出$(\dot m_a + \dot m_f)\bar c_p(T_{t4} - T_{\mathrm{ref}})$。因此
$$
\dot m_a\bar c_p(T_{t3} - T_{\mathrm{ref}}) + \eta_b\dot m_f Q_R = (\dot m_a + \dot m_f)\,\bar c_p(T_{t4} - T_{\mathrm{ref}}).
$$
除以$\dot m_a$，记$f = \dot m_f/\dot m_a$，合并含$f$的项：
$$
f\left[\eta_b Q_R - \bar c_p(T_{t4} - T_{\mathrm{ref}})\right] = \bar c_p(T_{t4} - T_{t3}),
$$
这就是[[#eq-far]]。近似之处在于单一平均比热容（产物的实际$c_p$随温度和含水量升高）以及忽略离解；精确计算时，用空气和燃烧产物的焓表，或温升对油气比的图线来代替$\bar c_p$。
:::

::: example 给定涡轮进口温度所需的燃油流量 {#ex-far}
某燃烧室接收$T_{t3} = 800\ \mathrm{K}$的空气$50\ \mathrm{kg/s}$，必须以燃烧效率$0.99$提供$T_{t4} = 1600\ \mathrm{K}$。求油气比、燃油流量和总当量比。
::: solution
由[[#eq-far]]，
$$
f = \frac{1150 \times 800}{0.99 \times 43\times10^{6} - 1150 \times 1302} = \frac{9.20\times10^{5}}{4.257\times10^{7} - 1.497\times10^{6}} = 0.0224.
$$
燃油流量$\dot m_f = 0.0224 \times 50 = 1.12\ \mathrm{kg/s}$，约每小时$4.0$吨。当量比为$\Phi = 0.0224/0.068 = 0.33$。

**合理性校核。** 忽略分母中的修正项，$f \approx 1150 \times 800/43\times10^6 = 0.0214$——相差在 5 % 以内，这是应当的，因为$T_{t4}$远低于火焰温度。核心流量$50\ \mathrm{kg/s}$时起飞燃油流量约每秒一千克，与大型现代涡轮风扇发动机相符。
:::
:::

[[#ex-far]]中$0.33$的当量比是燃烧室设计的核心事实。碳氢化合物-空气混合气在比约$\Phi \approx 0.5$贫得多时无法维持火焰，$\Phi = 0.33$的火焰根本无法稳定；即使能稳定，接近贫油极限的燃烧也缓慢而不完全。另一方面，涡轮无法承受接近化学恰当比火焰温度的任何温度。燃烧室通过**分段供气**同时解决了这两个问题。

::: widget plot
f: 1150*(x - T3)/(0.99*43e6 - 1150*(x - 298)); 0.068 + 0*x
x: 900, 3200
y: 0, 0.08
sliders: T3=800:500:950:10
labels: f\ \text{（达到}\ T_{t4}\ \text{所需）}; f_{st} = 0.068
caption: 对滑块上的压气机出口温度，能量平衡[[#eq-far]]所要求的油气比对出口温度$T_{t4}$（横轴，开尔文）的曲线。当今的涡轮进口温度（约$1600$–$2000\ \mathrm{K}$）只需化学恰当燃油量的三分之一到二分之一。取常数$\bar c_p$时，曲线在$3100\ \mathrm{K}$附近达到$f_{st}$；真实的化学恰当火焰温度要低几百开尔文，因为$c_p$随温度升高且产物发生离解——见下面的警告。
:::

::: warning 定$c_p$火焰温度高得离谱
单一$\bar c_p$的能量平衡对整个燃烧室不大的温升是准确的，但把它外推到化学恰当火焰就毫无意义了。从$800\ \mathrm{K}$出发，取$\bar c_p = 1150\ \mathrm{J\,kg^{-1}\,K^{-1}}$的[[#eq-far]]预测化学恰当温度超过$3100\ \mathrm{K}$；平衡计算给出的则是约$2600$–$2700\ \mathrm{K}$量级。缺少了两个效应。$\mathrm{CO_2}$和$\mathrm{H_2O}$的比热容在高温下急剧增大，所以每升高一开尔文都需要更多能量；而在约$2000\ \mathrm{K}$以上，产物**离解**——$\mathrm{CO_2} \rightleftharpoons \mathrm{CO} + \tfrac12\mathrm{O_2}$，$\mathrm{H_2O} \rightleftharpoons \mathrm{OH} + \tfrac12\mathrm{H_2}$——吸收能量。对任何主燃区温度或火焰温度，都应使用正规的平衡热化学（例如 NASA 的 CEA 程序或燃烧图表），并预期定$c_p$估算会高出几百开尔文。
:::

## 常规燃烧室的分区

常规（富油或接近化学恰当比主燃区）燃烧室沿长度把火焰筒分为三个区域。

1. **主燃区。** 在头部之后，来自喷嘴旋流器和第一排火焰筒孔的旋转空气与燃油以接近 1 的当量比混合。火焰在这里稳定，温度最高（超过$2000\ \mathrm{K}$）。强烈的回流（见下文）把高温已燃燃气送回喷嘴处，点燃进入的混合气。
2. **中间（补燃）区。** 通过第二排孔加入更多空气，在温度仍足以使反应进行时完成$\mathrm{CO}$和氢向$\mathrm{CO_2}$和水的氧化，并回收部分离解损失。
3. **掺混区。** 剩余空气以射流形式通过大孔进入，穿透到火焰筒中心，把燃气混合降温到涡轮进口温度，并塑造径向温度分布，使最热的燃气对着叶片的半叶高处，而不是对着应力很高的根部或叶尖。

一部分空气根本不通过孔进入，而是作为**冷却气膜**沿火焰筒内壁流动，或者通过数千个小发散孔，使金属保持在可接受的温度。火焰筒壁通常为带热障涂层的镍基或钴基合金板，某些现代发动机采用陶瓷基复合材料。

::: example 分区燃烧室的空气分配 {#ex-air-split}
对[[#ex-far]]的燃烧室（总$f = 0.0224$），如果全部燃油都在主燃区以$\Phi = 0.90$燃烧，应有多大比例的空气进入主燃区？其余空气去哪里？
::: solution
主燃区的油气比为$0.90 \times 0.068 = 0.0612$。全部燃油，即每千克总空气$0.0224$千克，必须与每千克总空气中的$0.0224/0.0612 = 0.366$千克空气相遇。所以约$37\ \%$的空气进入主燃区（包括旋流器空气）；其余$63\ \%$分配给中间区、掺混射流和火焰筒冷却。例如，若$20\ \%$用于壁面冷却、$15\ \%$用于中间区，则掺混孔取剩余的$28\ \%$。

**合理性校核。** 主燃区比例等于$\Phi_{\text{总}}/\Phi_{\text{主}} = 0.33/0.90$，这一结果与温度无关。公开的常规设计让约四分之一到二分之一的空气进入主燃区，与此一致。
:::
:::

## 火焰稳定与停留时间

预混气体中的火焰以**湍流火焰速度**向未燃混合气传播，最多每秒几米——但即使是减速后的燃烧室空气也以每秒几十米的速度运动。放在这样一股气流中的火焰会直接被吹出发动机。燃烧室通过制造一个当地流速低、热产物不断点燃新鲜混合气的区域来保持火焰：这就是**回流区**。

在航空发动机燃烧室中，回流主要由**旋流**产生。流经每个喷嘴周围旋流器叶片的空气获得很强的切向速度；旋转射流向外扩张，其中心压力降低，在旋流数超过临界值时中心线上的轴向流动反向——即**涡破碎**——在喷嘴下游紧邻处形成环形回流泡。来自第一排主燃孔的对冲射流加强了回流泡，并在下游端将其封闭。被困在回流泡中的热燃气的停留时间远长于平均值，起着连续点火源的作用，而回流泡的边缘——一个速度较低的剪切层——就是火焰稳定的地方。

燃烧能否完成，取决于燃气在火焰筒中停留的时间与蒸发、混合和化学反应所需时间的比较。平均**停留时间**大致为火焰筒长度除以平均燃气速度：
$$
\tau_{\text{停留}} \approx \frac{L}{\bar V}, \qquad \bar V = \frac{\dot m}{\bar\rho A},
$$ {#eq-residence}
在航空发动机中它约为几毫秒量级。在高功率下，压力和温度都高，化学反应快，几毫秒绰绰有余；在慢车和高空，压力低，化学反应速率下降，燃烧效率随之降低。

::: definition 参考速度与压力损失系数 {#def-plf}
燃烧室的**参考面积**$A_{\mathrm{ref}}$是机匣的最大横截面积。**参考速度**$V_{\mathrm{ref}} = \dot m_3/(\rho_3 A_{\mathrm{ref}})$和**参考动压**$q_{\mathrm{ref}} = \rho_3 V_{\mathrm{ref}}^2/2$用进口密度$\rho_3 = p_3/(RT_3)$构成。**压力损失系数**为
$$
\mathrm{PLF} = \frac{\Delta p_{t,3-4}}{q_{\mathrm{ref}}},
$$
它是几何形状的属性，随流量变化时几乎保持不变。进入循环计算的是相对损失$\Delta p_{t,3-4}/p_{t3}$，在航空发动机中通常为$3$–$6\ \%$。
:::

火焰筒壁两侧的压降不仅仅是损失：它驱动空气射流穿过火焰筒孔，而这些射流必须穿透并混合。射流速度由伯努利方程得到。

::: proposition 通过火焰筒孔的速度与流量 {#prop-liner-jet}
密度为$\rho_3$的空气从火焰筒外的环形通道（静压$p_{\mathrm{an}}$，速度可忽略）通过孔流入静压为$p_{\mathrm{L}}$的火焰筒，形成的射流速度和质量流量为
$$
V_j = \sqrt{\frac{2\Delta p_L}{\rho_3}}, \qquad \dot m_h = C_d A_h\sqrt{2\rho_3\Delta p_L}, \qquad \Delta p_L = p_{\mathrm{an}} - p_{\mathrm{L}},
$$
其中$A_h$为孔的几何面积，$C_d$（通常为$0.6$–$0.8$）为计入射流收缩的流量系数。
:::

::: proof
沿一条从环形通道到射流缩颈处的流线应用伯努利方程，假设流动定常、无黏、不可压（这是合理的，因为$\Delta p_L/p_3$只有百分之几，密度变化至多百分之几），环形通道速度可忽略：$p_{\mathrm{an}} = p_{\mathrm{L}} + \tfrac12\rho_3V_j^2$，由此得$V_j$。射流离开孔后收缩，所以其有效面积为$C_dA_h$，$\dot m_h = \rho_3 C_d A_h V_j = C_dA_h\sqrt{2\rho_3\Delta p_L}$。若环形通道速度不可忽略，则用环形通道**总**压代替$p_{\mathrm{an}}$，此时$C_d$取决于环形通道速度与射流速度之比。
:::

::: example 参考速度、停留时间与射流速度 {#ex-residence}
一个环形燃烧室以$p_3 = 3.0\ \mathrm{MPa}$、$T_3 = 800\ \mathrm{K}$通过参考面积$A_{\mathrm{ref}} = 0.25\ \mathrm{m^2}$的机匣输送$\dot m_3 = 50\ \mathrm{kg/s}$。火焰筒压降为$p_3$的$3\ \%$，火焰筒长约$0.25\ \mathrm{m}$，横截面积与机匣相同（一个粗略的上限）。求$V_{\mathrm{ref}}$、$q_{\mathrm{ref}}$、若全部$3\ \%$都是总压损失时的 PLF、燃气平均温度为$1600\ \mathrm{K}$时的停留时间估计值，以及通过火焰筒孔的射流速度。
::: solution
**参考值。** $\rho_3 = 3.0\times10^{6}/(287 \times 800) = 13.07\ \mathrm{kg/m^3}$，所以
$$
V_{\mathrm{ref}} = \frac{50}{13.07 \times 0.25} = 15.3\ \mathrm{m/s},
\qquad
q_{\mathrm{ref}} = \tfrac12 \times 13.07 \times 15.3^2 = 1531\ \mathrm{Pa}.
$$
**PLF。** $\Delta p_t = 0.03 \times 3.0\ \mathrm{MPa} = 90\ \mathrm{kPa}$，所以$\mathrm{PLF} = 90\,000/1531 = 59$。

**停留时间。** 在$1600\ \mathrm{K}$下密度减半，$\bar\rho = 6.53\ \mathrm{kg/m^3}$；流量为$51\ \mathrm{kg/s}$（空气加燃油），$\bar V = 51/(6.53 \times 0.25) = 31\ \mathrm{m/s}$，$\tau_{\text{停留}} \approx 0.25/31 = 8\ \mathrm{ms}$。火焰筒比机匣小，所以真实停留时间更短——几毫秒。

**射流速度。** 由[[#prop-liner-jet]]，$V_j = \sqrt{2 \times 90\,000/13.07} = 117\ \mathrm{m/s}$。

**合理性校核。** 射流进入速度约为参考速度的八倍；这一速度比及其所对应的射流与横流动量比，使掺混射流能够到达火焰筒中心线。代价是$3\ \%$的压力损失，它降低了涡轮膨胀比，对典型循环而言，每一个百分点的损失使耗油率增加约三分之一个百分点。
:::
:::

## 燃烧效率与负荷参数

**燃烧效率**$\eta_b$是燃料热值中实际释放的比例。起飞时它超过$99.9\ \%$；在地面慢车时，压力低、进口温度低、总体混合气贫，它可能降到$99\ \%$或更低，未释放的能量以一氧化碳和未燃碳氢化合物的形式离开。测得的排气成分可直接给出$\eta_b$：若$\mathrm{CO}$和未燃碳氢化合物的**排放指数**——每燃烧一千克燃油产生的污染物克数——为$\mathrm{EI_{CO}}$和$\mathrm{EI_{HC}}$，则
$$
1 - \eta_b \approx \frac{10.1\,\mathrm{EI_{CO}} + Q_R\,\mathrm{EI_{HC}}}{1000\,Q_R}
$$ {#eq-comb-ineff}
其中热值以$\mathrm{MJ/kg}$计：$10.1\ \mathrm{MJ/kg}$是$\mathrm{CO}$的热值，未燃碳氢化合物取燃料本身的热值。这是 SAE ARP 1533 的方法。

在设计中，给定工作点的燃烧效率与一个**负荷参数**相关联。在 Lefebvre 发展的方法中（见 Lefebvre 和 Ballal，*Gas Turbine Combustion*，第3版，2010年），假设燃烧速率受主燃区化学反应速率限制，由此得到参数
$$
\theta = \frac{p_3^{1.75}A_{\mathrm{ref}}D_{\mathrm{ref}}^{0.75}\,\exp(T_3/300)}{\dot m_3},
$$ {#eq-theta}
其中$p_3$以$\mathrm{Pa}$计，$A_{\mathrm{ref}}$以$\mathrm{m^2}$计，参考高度$D_{\mathrm{ref}}$以$\mathrm{m}$计，$T_3$以$\mathrm{K}$计，$\dot m_3$以$\mathrm{kg/s}$计。给定燃烧室的实验燃烧效率对$\theta$落在同一条曲线上，随$\theta$增大趋于$100\ \%$。指数是经验的；压力的$1.75$次方反映有效反应级数，指数函数反映反应速率对温度的依赖。该参数在求**比值**时最有用：缩放燃烧室，或比较同一燃烧室的不同工作点。

::: example 高度如何侵蚀燃烧效率 {#ex-theta}
[[#ex-residence]]的燃烧室起飞时$p_3 = 3.0\ \mathrm{MPa}$，$T_3 = 800\ \mathrm{K}$，$\dot m_3 = 50\ \mathrm{kg/s}$。巡航时这些值为$1.2\ \mathrm{MPa}$、$650\ \mathrm{K}$和$20\ \mathrm{kg/s}$；熄火后高空再点火时，风车状态的发动机提供$40\ \mathrm{kPa}$、$250\ \mathrm{K}$和$3\ \mathrm{kg/s}$。比较三种状态下的$\theta$。
::: solution
几何尺寸在比值中相消：
$$
\frac{\theta_{\text{巡航}}}{\theta_{\text{起飞}}} = \left(\frac{1.2}{3.0}\right)^{1.75}\exp\!\left(\frac{650 - 800}{300}\right)\frac{50}{20} = 0.2014 \times 0.6065 \times 2.5 = 0.305.
$$
$$
\frac{\theta_{\text{再点火}}}{\theta_{\text{起飞}}} = \left(\frac{0.040}{3.0}\right)^{1.75}\exp\!\left(\frac{250 - 800}{300}\right)\frac{50}{3} = 5.23\times10^{-4} \times 0.160 \times 16.7 = 1.4\times10^{-3}.
$$
**合理性校核。** 巡航时负荷参数下降到三分之一，对设计良好的燃烧室仍处于曲线平坦的高效率部分。高空再点火时它下降了近三个数量级，正是这一状态——而不是起飞——决定了主燃区容积，并确定了发动机取证的再点火高度。压力项起主导作用：低压火焰就是慢火焰。
:::
:::

## 污染物生成

每一种碳氢火焰都按所燃烧的燃油量成比例地产生$\mathrm{CO_2}$和水——每千克煤油约$3.16\ \mathrm{kg}$ $\mathrm{CO_2}$——只有少烧燃油才能减少它们。受管制的污染物则不同：它们是**不完全**反应或**副**反应的产物，由燃烧室设计控制。

- **一氧化碳和未燃碳氢化合物**来自不完全燃烧，主要在低功率时：主燃区温度低、雾化差、冷却气膜使反应淬熄。它们随功率增大而急剧下降。
- **烟和碳烟**（非挥发性颗粒物）在主燃区的富油区域中生成，在那里碳氢碎片长大成碳颗粒；大部分碳烟在下游重新被氧化，残存的部分被排出。
- **氮氧化物**（$\mathrm{NO}$和$\mathrm{NO_2}$，合称$\mathrm{NO_x}$）由空气中的氮和氧在高温下生成。它们随功率和增压比增大而增加——这是现代高增压比发动机燃烧室的主要排放问题。

燃气涡轮火焰中生成$\mathrm{NO}$的主要途径是**热力型**或**泽尔多维奇**（Zeldovich）机理（Zeldovich，1946年）：
$$
\mathrm{O + N_2 \rightarrow NO + N}, \qquad \mathrm{N + O_2 \rightarrow NO + O}, \qquad \mathrm{N + OH \rightarrow NO + H}.
$$
第一步必须打断很强的$\mathrm{N\equiv N}$键，是速率控制步骤。其速率常数的活化温度约为$38\,000\ \mathrm{K}$——常用值为$k = 1.8\times10^{14}\exp(-38\,370/T)\ \mathrm{cm^3\,mol^{-1}\,s^{-1}}$——而与之相乘的氧原子浓度也随温度急剧上升。因此热力型$\mathrm{NO_x}$在约$1800\ \mathrm{K}$以下可以忽略，在此以上大致按指数规律上升，并随燃气在高温下停留的时间增长。

::: widget plot
f: exp(-38370/x)/exp(-38370/Tr)
x: 1600, 2600
y: 0, 12
sliders: Tr=2000:1800:2400:10
hlines: 1
caption: 泽尔多维奇速率控制步骤的速率常数$k \propto \exp(-38\,370/T)$相对于其在滑块参考温度$T_r$下的值，对温度（开尔文）的曲线。从$2000\ \mathrm{K}$升高$200\ \mathrm{K}$使它增大近六倍——这还没有计入氧原子浓度的增加。正是这种陡峭性，使每一种低$\mathrm{NO_x}$策略首先都是一种避免接近化学恰当比的热点的策略。
:::

温度依赖性给出了两种现代策略。

**富油-淬熄-贫油（RQL）。** 主燃区富油工作（$\Phi \approx 1.5$–$1.8$），温度适中且几乎没有游离氧，所以生成的$\mathrm{NO}$很少；然后由强空气射流进行非常迅速的**淬熄**，使混合气尽快越过化学恰当比，贫油区在温度过低、不足以生成大量$\mathrm{NO}$的条件下完成$\mathrm{CO}$和碳烟的燃尽。淬熄混合的质量决定了结果。目前大多数民用发动机使用改进的 RQL 燃烧室。

**贫油燃烧（贫油预混或贫油直接喷射）。** 燃油在燃烧之前与燃烧室空气的很大一部分——百分之六十或更多——混合，在$\Phi \approx 0.5$–$0.7$下燃烧，使火焰在任何地方都达不到化学恰当比温度。这给出最低的$\mathrm{NO_x}$，但带来了自身的问题：贫油火焰接近吹熄极限，特别是在低功率时，所以贫油燃烧喷嘴是**分级**的，用较富的值班火焰应付慢车，随功率提高接通贫油主级；贫油预混火焰还容易发生**燃烧不稳定**，即放热与燃烧室声学耦合的自激压力振荡，可能损坏硬件。GE 的 TAPS（双环预混旋流器）贫油燃烧室于 21 世纪 10 年代初在 GEnx 上投入航线运营，并用于 CFM LEAP。

::: definition ICAO 附件 16 下的排放审定 {#def-icao-lto}
用于国际民用航空的发动机按 ICAO 附件 16 第 II 卷（第1版1981年；第5版2023年）审定，采用由四个推力状态及各自工作时间组成的**着陆起飞（LTO）循环**：起飞，$100\ \%$额定推力$F_{00}$，$0.7\ \mathrm{min}$；爬升，$85\ \%$，$2.2\ \mathrm{min}$；进近，$30\ \%$，$4.0\ \mathrm{min}$；滑行/地面慢车，$7\ \%$，$26.0\ \mathrm{min}$。对$\mathrm{NO_x}$、$\mathrm{CO}$和$\mathrm{HC}$中的每一种，受管制的量是整个循环的总排放质量$D_p$除以额定推力：$D_p/F_{00}$，单位$\mathrm{g/kN}$。限值由 ICAO 航空环境保护委员会（CAEP）制定，取决于增压比和审定日期；烟和非挥发性颗粒物有各自的标准。
:::

::: example LTO 循环的$\mathrm{NO_x}$指标 {#ex-lto}
一台假想的发动机额定推力$F_{00} = 120\ \mathrm{kN}$，在四个 LTO 状态（起飞、爬升、进近、慢车）下燃油流量分别为$1.10$、$0.90$、$0.30$和$0.10\ \mathrm{kg/s}$，$\mathrm{NO_x}$排放指数分别为$40.0$、$30.0$、$11.0$和$4.5\ \mathrm{g/kg}$。求$\mathrm{NO_x}$的$D_p/F_{00}$。
::: solution
各状态燃烧的燃油为燃油流量 × 时间：起飞$1.10 \times 42 = 46.2\ \mathrm{kg}$，爬升$0.90 \times 132 = 118.8\ \mathrm{kg}$，进近$0.30 \times 240 = 72.0\ \mathrm{kg}$，慢车$0.10 \times 1560 = 156.0\ \mathrm{kg}$。乘以排放指数：
$$
D_p = 46.2(40.0) + 118.8(30.0) + 72.0(11.0) + 156.0(4.5) = 1848 + 3564 + 792 + 702 = 6906\ \mathrm{g},
$$
所以$D_p/F_{00} = 6906/120 = 57.6\ \mathrm{g/kN}$。

**合理性校核。** 贡献最大的是爬升而不是起飞，因为爬升的工作时间更长；慢车烧的燃油最多，但排放指数低。每千牛几十克是现代大型发动机的典型值。注意这一规章如何偏向于高功率下$\mathrm{NO_x}$低的燃烧室——那里恰是热力型$\mathrm{NO_x}$的峰值所在——而慢车性能主要按$\mathrm{CO}$和$\mathrm{HC}$评判，它们是火焰**过冷**的产物。一个燃烧室必须同时满足两端的要求。
:::
:::

::: quiz
某发动机制造商为改善耗油率而提高新发动机的总增压比，同时保留常规燃烧室。哪一种排放最可能变得更难达标？
- [ ] 慢车时的一氧化碳
- [x] 高功率时的氮氧化物
- [ ] 慢车时的未燃碳氢化合物
- [ ] 每千克燃油的$\mathrm{CO_2}$
::: solution
更高的增压比提高了压气机出口温度$T_3$，从而提高了接近化学恰当比主燃区中的火焰温度，而热力型$\mathrm{NO_x}$大致随火焰温度（以及压力）按指数规律上升。慢车时的$\mathrm{CO}$和$\mathrm{HC}$在进口空气更热时往往会**改善**。每千克燃油的$\mathrm{CO_2}$由燃料的含碳量决定。循环效率与$\mathrm{NO_x}$之间的这种矛盾推动了贫油燃烧室的发展。
:::
:::

::: history
燃烧是第一批喷气发动机最难解决的问题之一。弗兰克·**惠特尔**（Frank Whittle）1937年的实验发动机运转时燃烧难以稳定和控制，一长串燃烧试验拖延了它的研制。1940年，艾萨克·**卢伯克**（Isaac Lubbock）及其在富勒姆壳牌实验室的团队与惠特尔的 Power Jets 公司合作，研制出带雾化燃烧器的燃烧室，提供了所需的稳定而强烈的燃烧；惠特尔认为壳牌的系统是燃烧不再成为障碍的转折点，W.1 发动机于1941年5月15日装在格罗斯特 E.28/39 上飞行。一氧化氮生成的热力机理由雅科夫·**泽尔多维奇**（Yakov Zeldovich）于1946年描述。航空发动机的国际排放审定始于1981年 ICAO 附件 16 第 II 卷第1版，此后历次 CAEP 标准不断收紧$\mathrm{NO_x}$限值。
:::

::: summary
- 燃烧室的总体混合气非常贫（$\Phi \approx 0.3$–$0.5$），因为涡轮无法承受化学恰当比温度；油气比由能量平衡[[#eq-far]]得出。
- 煤油的化学恰当油气比约为$0.068$；由于离解和$c_p$的增大，定$c_p$的火焰温度估计值高得离谱。
- 常规燃烧室**分段供气**：由旋流诱导的**回流**稳定的接近化学恰当比的主燃区、用于燃尽的中间区，以及决定出口温度分布的掺混区。
- 停留时间为几毫秒；压力损失（$3$–$6\ \%$）驱动火焰筒射流，$V_j = \sqrt{2\Delta p_L/\rho_3}$。
- 燃烧效率在高功率时接近$100\ \%$，在低压时下降；Lefebvre 负荷参数$\theta \propto p_3^{1.75}\exp(T_3/300)/\dot m_3$说明了为什么高空再点火决定主燃区尺寸。
- 热力型$\mathrm{NO_x}$（泽尔多维奇）对温度呈指数敏感；**RQL** 和**贫油燃烧**燃烧室避免接近化学恰当比的高温区。排放按 ICAO **LTO 循环**以$D_p/F_{00}$审定。
:::

$\Phi = 0.020/0.068 = 0.294$——空气约为燃烧燃油所需量的三倍。

::: exercise {level=2 check="0.988"}
地面慢车时某发动机排气中$\mathrm{EI_{CO}} = 30\ \mathrm{g/kg}$，$\mathrm{EI_{HC}} = 5\ \mathrm{g/kg}$。取$Q_R = 43\ \mathrm{MJ/kg}$，用[[#eq-comb-ineff]]估算燃烧效率。（输入$\eta_b$，保留三位有效数字。）

::: exercise {level=2 check="5.72"}
当火焰温度从$2000\ \mathrm{K}$升到$2200\ \mathrm{K}$时，反应$\mathrm{O + N_2 \rightarrow NO + N}$的速率常数$k = A\exp(-38\,370/T)$增大多少倍？（输入保留三位有效数字的倍数。）

$p_3 = 2.5\ \mathrm{MPa}$、$T_3 = 750\ \mathrm{K}$的空气在$100\ \mathrm{kPa}$的火焰筒压降下流过掺混孔。忽略环形通道速度，求射流速度。（以 m/s 为单位输入速度，保留三位有效数字。）
::: solution
$\rho_3 = 2.5\times10^{6}/(287 \times 750) = 11.61\ \mathrm{kg/m^3}$；$V_j = \sqrt{2 \times 100\,000/11.61} = 131\ \mathrm{m/s}$。

::: exercise {level=2 check="0.48"}
某贫油燃烧室在总油气比$0.0196$（值班级关闭）下，把燃烧室空气的$60\ \%$与全部燃油在主级中预混。主级火焰在什么当量比下燃烧？（取$f_{st} = 0.068$；输入$\Phi$，保留两位有效数字。）
::: solution
主级的油气比为$0.0196/0.60 = 0.0327$，所以$\Phi = 0.0327/0.068 = 0.48$。这接近贫油吹熄极限，这就是为什么贫油燃烧室保持值班级燃烧，并随功率在各级之间切换燃油。

::: exercise {level=3}
从稳定流动能量方程出发推导[[#eq-far]]。然后证明当$\bar c_p(T_{t4} - T_{\mathrm{ref}}) \ll \eta_bQ_R$时它化为$f \approx \bar c_p(T_{t4} - T_{t3})/(\eta_b Q_R)$，估计这一近似在[[#ex-far]]条件下的误差，并从物理上解释被忽略的项代表什么。
::: solution
推导即[[#prop-far]]的推导。展开得$f = \dfrac{\bar c_p\Delta T}{\eta_bQ_R}\left[1 - \dfrac{\bar c_p(T_{t4} - T_{\mathrm{ref}})}{\eta_bQ_R}\right]^{-1} \approx \dfrac{\bar c_p\Delta T}{\eta_bQ_R}\left[1 + \dfrac{\bar c_p(T_{t4} - T_{\mathrm{ref}})}{\eta_bQ_R}\right]$。对[[#ex-far]]，$\bar c_p(T_{t4} - T_{\mathrm{ref}})/(\eta_bQ_R) = 1.497\times10^{6}/4.257\times10^{7} = 0.035$，所以简单公式把$f$低估约$3.5\ \%$（$0.0216$对$0.0224$）。被忽略的项是把燃料**自身的质量**在燃烧后从参考温度加热到$T_{t4}$所需的能量：燃料不仅给气流增加了能量，也增加了质量，而这部分额外质量也必须被加热。
:::

::: exercise {level=3}
**设计。** 为一台发动机初步确定环形燃烧室的尺寸：$\dot m_3 = 40\ \mathrm{kg/s}$，$p_3 = 2.8\ \mathrm{MPa}$，$T_3 = 820\ \mathrm{K}$，$T_{t4} = 1700\ \mathrm{K}$，平均直径$0.60\ \mathrm{m}$，允许的总压损失为$4\ \%$，压力损失系数为$40$。求燃油流量、参考面积和环形通道高度、参考速度，以及$\Phi_{\text{主}} = 1.0$时的主燃区空气比例。讨论在设计可信之前还需要校核什么。
::: solution
**燃油。** $f = 1150 \times 880/(0.99 \times 43\times10^{6} - 1150 \times 1402) = 1.012\times10^{6}/4.096\times10^{7} = 0.0247$，所以$\dot m_f = 0.99\ \mathrm{kg/s}$。

**参考面积。** $\Delta p_t = 0.04 \times 2.8 = 0.112\ \mathrm{MPa}$，所以$q_{\mathrm{ref}} = 112\,000/40 = 2800\ \mathrm{Pa}$。$\rho_3 = 2.8\times10^{6}/(287 \times 820) = 11.90\ \mathrm{kg/m^3}$，$V_{\mathrm{ref}} = \sqrt{2q_{\mathrm{ref}}/\rho_3} = 21.7\ \mathrm{m/s}$，$A_{\mathrm{ref}} = \dot m_3/(\rho_3V_{\mathrm{ref}}) = 40/(11.90 \times 21.7) = 0.155\ \mathrm{m^2}$。平均直径$0.60\ \mathrm{m}$时，机匣高度为$0.155/(\pi \times 0.60) = 0.082\ \mathrm{m}$。

**主燃区。** $\Phi_{\text{总}} = 0.0247/0.068 = 0.36$，所以约$36\ \%$的空气必须在$\Phi = 1$下进入主燃区。

**其他事项。** 高空再点火和贫油吹熄（在最不利的风车状态下的$\theta$与已知燃烧室比较）；慢车时的停留时间和燃烧效率；火焰筒冷却空气需求和壁温；掺混射流穿透深度以及涡轮要求的径向出口温度分布（温度分布系数）；喷嘴数目和间距（热条纹）；在这一增压比下对照 CAEP 限值的$\mathrm{NO_x}$，这可能要求改用贫油燃烧设计；以及燃烧动力学。每一项都需要进一步的计算或试验，这就是燃烧室设计至今仍高度依赖经验的原因。
