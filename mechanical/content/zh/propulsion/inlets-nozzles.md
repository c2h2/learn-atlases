压气机和涡轮得到了大部分关注，但发动机的进气道和喷管决定了叶轮机械能否完成其工作。无论飞机处于什么状态——全功率静止、以马赫数 0.85 巡航，或者对超声速飞机而言以马赫数 2 飞行——进气道都必须向压气机提供马赫数约 0.5 的稳定、均匀的气流，而且总压损失要尽可能小，因为前端损失的每一个百分点的压力，都是压气机必须补回的一个百分点的增压比。后部的喷管把涡轮之后剩余的总压和总温转换为射流速度，其形状决定了这种转换完成得有多彻底。两者都属于**可压缩管道流动**，本章把[[fluid-mechanics/compressible-flow]]中的一维气体动力学（等熵流动、正激波和斜激波；另见[[aerodynamics/oblique-shocks]]）应用于它们的设计。

我们首先建立流量函数和面积-马赫数关系，它们支配着发动机中的每一段管道。然后讨论亚声速进气道和捕获流管的概念，超声速进气道及其中占主导地位的激波损失，最后是收敛喷管和缩放喷管、它们的设计与非设计工况，以及喷管在把燃气恰好膨胀到环境压力时推力最大的证明。

## 质量流量、面积与马赫数

::: proposition 流量函数 {#prop-mfp}
对$\gamma$和气体常数$R$为常数的完全气体的定常一维等熵流动，通过面积为$A$、马赫数为$M$、总压为$p_t$、总温为$T_t$的截面的质量流量为
$$
\frac{\dot m\sqrt{T_t}}{A\,p_t} = \mathrm{MFP}(M) = \sqrt{\frac{\gamma}{R}}\; M\left(1 + \frac{\gamma-1}{2}M^2\right)^{-\frac{\gamma+1}{2(\gamma-1)}} .
$$ {#eq-mfp}
$\mathrm{MFP}$在$M = 1$处取最大值；对空气（$\gamma = 1.4$，$R = 287\ \mathrm{J/(kg\,K)}$），最大值为$0.04042\ \mathrm{kg\,K^{1/2}/(N\,s)}$。
:::

::: proof
写出$\dot m = \rho A V$，其中$\rho = p/(RT)$，$V = M\sqrt{\gamma R T}$：
$$
\dot m = \frac{p}{RT}\,A\,M\sqrt{\gamma R T} = A\,M\,p\sqrt{\frac{\gamma}{RT}} .
$$
用滞止参数表示静参数，$T = T_t\,\theta^{-1}$，$p = p_t\,\theta^{-\gamma/(\gamma-1)}$，其中$\theta = 1 + \frac{\gamma-1}{2}M^2$：
$$
\dot m = A\,M\,p_t\sqrt{\frac{\gamma}{R T_t}}\;\theta^{-\frac{\gamma}{\gamma-1} + \frac12} ,
$$
而$-\frac{\gamma}{\gamma-1} + \frac12 = -\frac{\gamma+1}{2(\gamma-1)}$。对$\ln\mathrm{MFP} = \ln M - \frac{\gamma+1}{2(\gamma-1)}\ln\theta$求导得$1/M - \frac{\gamma+1}{2}\,M/\theta$，它在$2\theta = (\gamma+1)M^2$即$M = 1$时为零。假设：定常流动，截面上流动均匀，$\gamma$为常数的完全气体，从滞止状态起的流动绝热且可逆（式中只出现**当地**的$p_t$、$T_t$，所以只要使用当地$p_t$，该公式在有损失的下游也成立）。
:::

::: definition 临界面积与面积-马赫数关系 {#def-area-mach}
**临界面积**$A^*$是同一股流动（相同的$\dot m$、$p_t$、$T_t$）恰好达到声速时的面积。用$\mathrm{MFP}(1)$除以$\mathrm{MFP}(M)$得到**面积-马赫数关系**
$$
\frac{A}{A^*} = \frac{1}{M}\left[\frac{2}{\gamma+1}\left(1 + \frac{\gamma-1}{2}M^2\right)\right]^{\frac{\gamma+1}{2(\gamma-1)}} ,
$$ {#eq-area-mach}
它至少为 1，对每个$A/A^* > 1$有两个解：一个亚声速解，一个超声速解。亚声速流动在面积**增大**时减速（扩压器），在面积减小时加速；超声速流动则相反。因此，一股必须从亚声速过渡到超声速的气流需要一个收缩-扩张通道，且在喉部$M = 1$。
:::

流量函数解释了**壅塞**。当喷管（或涡轮导向器）的喉部达到声速时，通过它的流量为$\dot m = \mathrm{MFP}(1)\,A^*p_t/\sqrt{T_t}$，下游的任何变化都不能使它增大：进一步降低反压只改变喉部下游的流动，而不改变质量流量。在压气机进口计算的同一参数，就是发动机的**换算流量**$\dot m\sqrt{\theta}/\delta$（其中$\theta = T_{t2}/288.15\ \mathrm{K}$，$\delta = p_{t2}/101.325\ \mathrm{kPa}$），它是每一张压气机特性图横轴上的量（[[propulsion/compressors]]）。

## 亚声速进气道

亚声速进气道是一个短的、唇口圆钝的扩压器。它的设计难题在于：发动机对空气的需求由压气机决定，而不是由飞行速度决定。在进气道前方远处，将要进入发动机的空气占据一个面积为$A_0$的流管，由连续方程确定：
$$
A_0 = \frac{\dot m}{\rho_0 V_0} .
$$
将$A_0$与进气道唇口（前缘）面积$A_1$比较。在**巡航**时，发动机吸入的空气少于唇口投影面积所能收集的量，$A_0 < A_1$：流管在进气道前方扩张，空气部分地在进气道**外部**减速（外部扩压），其余部分在内部扩压，到风扇进口时约为$M_2 \approx 0.5$–$0.6$。在**起飞**和爬升时情况相反：$A_0 > A_1$，空气从侧面和唇口周围被吸入，并**加速**进入进气道。尖锐的唇口会使气流在那里分离，所以亚声速进气道采用厚而圆钝的唇口：这是起飞（厚唇口）与巡航阻力（薄唇口）之间的折中。

::: definition 进气道总压恢复系数与畸变 {#def-recovery}
进气道的**总压恢复系数**为$\pi_d = p_{t2}/p_{t0}$，即压气机进口面积平均总压与自由流总压之比。亚声速进气道可达$\pi_d \approx 0.97$–$0.995$，损失来自表面摩擦和可能出现的分离。**畸变**是压气机进口上$p_t$（及$T_t$）的不均匀性，通常用诸如$DC_{60}$的指数表示：进口面平均$p_t$与任一$60°$扇区上最低平均值之差，除以进口面平均动压。即使平均总压恢复很好，畸变也会降低压气机的喘振裕度。
:::

::: example 巡航时涡轮风扇发动机进气道的捕获面积 {#ex-capture}
一台涡轮风扇发动机在$11\ \mathrm{km}$高度（$T_0 = 216.65\ \mathrm{K}$，$p_0 = 22.63\ \mathrm{kPa}$）以$M_0 = 0.80$飞行，吸入$\dot m = 200\ \mathrm{kg/s}$。进气道总压恢复系数$\pi_d = 0.99$，在风扇进口提供$M_2 = 0.60$。求自由流捕获面积$A_0$、风扇进口流通面积$A_2$以及比值$A_0/A_2$。该比值说明了进气道前方流动的什么情况？
::: solution
**自由流。** $\rho_0 = p_0/(RT_0) = 22\,630/(287 \times 216.65) = 0.364\ \mathrm{kg/m^3}$，$V_0 = 0.8\sqrt{1.4 \times 287 \times 216.65} = 236.0\ \mathrm{m/s}$，所以
$$
A_0 = \frac{200}{0.364 \times 236.0} = 2.33\ \mathrm{m^2}.
$$
**风扇进口。** $T_{t2} = T_{t0} = 216.65 \times 1.128 = 244.4\ \mathrm{K}$；$p_{t0} = 22.63 \times 1.128^{3.5} = 34.50\ \mathrm{kPa}$；$p_{t2} = 0.99 \times 34.50 = 34.15\ \mathrm{kPa}$。由[[#eq-mfp]]，$\mathrm{MFP}(0.6) = 0.03402\ \mathrm{kg\,K^{1/2}/(N\,s)}$，所以
$$
A_2 = \frac{\dot m\sqrt{T_{t2}}}{p_{t2}\,\mathrm{MFP}(0.6)} = \frac{200 \times 15.63}{34\,150 \times 0.03402} = 2.69\ \mathrm{m^2},
$$
这一流通面积相当于直径$1.85\ \mathrm{m}$的圆（带轮毂的实际风扇更大）。

$A_0/A_2 = 0.865$：捕获流管比风扇进口窄，比尺寸相当的唇口窄得多，所以流管在进气道前方**扩张**，空气在到达唇口之前就已部分地从$M = 0.8$减速。**校核。** 由于$M_0 > M_2$，气流必须在某处减速，而亚声速减速需要面积增大：$A_0 < A_2$是一致的。起飞时（$M_0 \approx 0.25$）同样的计算给出$A_0 > A_2$，气流加速进入进气道。
:::
:::

## 超声速进气道

在超声速飞行速度下，空气必须通过至少一道激波才能降到$M \approx 0.5$，而激波产生熵：穿过激波总压下降，总温不变。损失随激波法向马赫数急剧增大，所以超声速进气道设计的全部艺术，就是用几道弱激波而不是一道强激波来完成减速。

::: proposition 正激波前后的总压比 {#prop-normal-shock}
对$\gamma$为常数的完全气体，上游马赫数为$M_1 > 1$的正激波产生的下游马赫数和总压比为
$$
M_2^2 = \frac{(\gamma-1)M_1^2 + 2}{2\gamma M_1^2 - (\gamma-1)},
\qquad
\frac{p_{t2}}{p_{t1}} = \left[\frac{(\gamma+1)M_1^2}{(\gamma-1)M_1^2 + 2}\right]^{\frac{\gamma}{\gamma-1}}\left[\frac{\gamma+1}{2\gamma M_1^2 - (\gamma-1)}\right]^{\frac{1}{\gamma-1}} .
$$ {#eq-normal-shock}
对激波角为$\beta$的斜激波，把$M_1$换成法向分量$M_{1n} = M_1\sin\beta$后同样的公式适用。
:::

::: proof
正激波前后的静压比和密度比由质量、动量和能量守恒得到（推导见[[fluid-mechanics/compressible-flow]]）：
$$
\frac{p_2}{p_1} = \frac{2\gamma M_1^2 - (\gamma-1)}{\gamma+1},\qquad
\frac{\rho_2}{\rho_1} = \frac{(\gamma+1)M_1^2}{(\gamma-1)M_1^2 + 2}.
$$
激波是绝热的，所以$T_{t2} = T_{t1}$。完全气体的熵变为$s_2 - s_1 = c_p\ln(T_2/T_1) - R\ln(p_2/p_1)$，在两个**滞止**状态之间计算它（滞止状态的熵与静态相同），并利用$T_{t2} = T_{t1}$，得$s_2 - s_1 = -R\ln(p_{t2}/p_{t1})$。在两个静态之间，利用$T_2/T_1 = (p_2/p_1)(\rho_1/\rho_2)$，
$$
\frac{s_2 - s_1}{R} = \frac{\gamma}{\gamma-1}\ln\frac{T_2}{T_1} - \ln\frac{p_2}{p_1}
= \frac{1}{\gamma-1}\ln\frac{p_2}{p_1} - \frac{\gamma}{\gamma-1}\ln\frac{\rho_2}{\rho_1},
$$
所以$p_{t2}/p_{t1} = (\rho_2/\rho_1)^{\gamma/(\gamma-1)}(p_2/p_1)^{-1/(\gamma-1)}$，这就是[[#eq-normal-shock]]。斜激波只改变垂直于它的速度分量（切向动量方程中没有压力项），所以斜激波就是在沿波面滑动的坐标系中的正激波。下游马赫数公式由同样的三个守恒定律得到。
:::

最简单的超声速进气道是**皮托式**（正激波）进气道——一个唇口尖锐的亚声速进气道，其前方立着一道正激波。它在马赫数约 1.5 以下够用（仅激波一项$\pi_d = 0.93$），超过之后就很差。更好的进气道先在斜板（二元进气道）或锥体（轴对称中心锥进气道）上通过一道或多道**斜激波**使气流转折，从而使结尾正激波发生在较低的马赫数下。克劳斯·奥斯瓦蒂奇（Klaus Oswatitsch）在 20 世纪 40 年代证明，对给定的激波数目，当各道斜激波的法向马赫数都相同时总压恢复最高；实际进气道在可能时还会加上最后的等熵（渐进）压缩。

::: example 马赫数 2 时用一道激波还是两道 {#ex-two-shock}
一架飞机以$M_0 = 2.0$飞行（$\gamma = 1.4$）。比较以下两者的激波损失总压恢复：(a) 带单道正激波的皮托式进气道；(b) 外压式进气道，带一块$10°$斜板，产生一道弱斜激波，随后在唇口处有一道正激波。
::: solution
(a) [[#eq-normal-shock]]在$M_1 = 2$时：$p_{t2}/p_{t1} = 0.721$，$M_2 = 0.577$。
(b) 对$M_1 = 2$和气流折转角$\theta = 10°$，$\theta$–$\beta$–$M$关系（[[aerodynamics/oblique-shocks]]）给出弱激波角$\beta = 39.3°$。法向马赫数为$M_{1n} = 2\sin 39.3° = 1.267$，给出$p_t$比$0.985$；下游法向分量为$0.803$，下游马赫数为$M_2 = 0.803/\sin(39.3° - 10°) = 1.64$。$M = 1.64$的正激波的$p_t$比为$0.880$。总计
$$
\pi_{\text{激波}} = 0.985 \times 0.880 = 0.866 .
$$
**校核。** 斜板把 28 % 的损失变成了 13 % 的损失，其中只有 1.5 % 来自斜激波本身：对弱激波，激波损失大致按$(M_n - 1)^3$增长，所以把压缩分开有极大的好处。第二块$10°$斜板（[[#exr-three-shock]]）使总压恢复达到$0.955$。每增加一道激波都要付出斜板长度、重量和边界层问题的代价，而且激波位置必须随飞行马赫数调节，这就是马赫数 2 进气道采用可调几何的原因。
:::
:::

在初步设计中，发动机研究使用标准的总压恢复规律而不是激波计算。最常用的是前美国军用发动机规范 MIL-E-5007D 中的规律（Mattingly，*Elements of Propulsion*）：
$$
\pi_{d,\text{激波}} = 1 - 0.075\,(M_0 - 1)^{1.35},\qquad 1 < M_0 < 5,
$$ {#eq-mil-spec}
这是一条代表良好多波系进气道的经验曲线；它还要乘以约 0.97–0.99 的亚声速扩压段摩擦总压恢复系数。

### 起动、嗡鸣与不起动

**混压式**或**内压式**进气道把部分激波置于收缩通道内，这允许采用更短、阻力更低的外罩，但带来了**起动问题**。为了从亚声速流动过渡到超声速流动，内部喉道必须足够大，以便在飞行器加速时把立在进气道前方的正激波吞入；其判据由 Kantrowitz 和 Donaldson 于1945年在 NACA 给出。起动之后，任何把激波推出进气道的扰动——发动机流量减小、阵风、迎角变化——都会使进气道**不起动**，导致总压恢复突然损失和阻力剧烈变化；可调喉道和放气系统用于防止不起动并从中恢复。外压式进气道在发动机流量过小时工作会发生**嗡鸣**（buzz），即外罩前方激波系的振荡。

::: warning 总压恢复系数是总压之比，并且它们相乘
进气道总压恢复系数是把$p_{t2}$与自由流**总压**$p_{t0} = \pi_r p_0$相比，而不是与静压$p_0$相比。在马赫数 2 时冲压比为$\pi_r = 7.82$；$\pi_d = 0.90$的进气道提供$p_{t2} = 7.04\,p_0$，仍然是很大的压缩。第二个错误是把损失相加：相继各元件（激波、亚声速扩压段、支板）的总压恢复系数是**相乘**的。还要记住，总压恢复系数不是唯一的品质指标——平均总压恢复极好而畸变严重的进气道仍可能使压气机喘振。
:::

## 喷管

排气喷管把燃气的总焓转换为射流速度。对把燃气从$p_{t9}$、$T_{t9}$膨胀到出口压力$p_9$的等熵喷管，
$$
V_9 = \sqrt{2c_p T_{t9}\left[1 - \left(\frac{p_9}{p_{t9}}\right)^{(\gamma-1)/\gamma}\right]},
$$ {#eq-nozzle-velocity}
这就是用等熵关系给出$T_9/T_{t9}$的稳定流动能量方程。喷管的工作状态用**喷管落压比**$\mathrm{NPR} = p_{t9}/p_0$描述。

### 收敛喷管与壅塞

纯收敛喷管最多只能在出口把燃气加速到$M = 1$。当 NPR 达到临界值
$$
\mathrm{NPR}_{\text{临界}} = \left(\frac{\gamma+1}{2}\right)^{\gamma/(\gamma-1)}
$$
时出口达到声速，对$\gamma = 1.4$它为$1.893$，对$\gamma = 1.33$为$1.851$。低于此值时出口压力等于环境压力，射流为亚声速。高于此值时喷管**壅塞**：出口保持声速，$p_9 = p_{t9}/\mathrm{NPR}_{\text{临界}} > p_0$，剩余的膨胀在喷管外以膨胀波和压缩波的形式进行（高温射流中可见的“激波钻石”）。额外的压力产生压力推力，但正如我们现在要证明的，它比完全膨胀所能给出的要少。

::: proposition 完全膨胀时总推力最大 {#prop-perfect-expansion}
对质量流量和进口滞止参数固定的等熵喷管，把总推力$F_G = \dot m V_9 + (p_9 - p_0)A_9$看作出口面积$A_9$的函数，它满足
$$
\frac{\mathrm{d}F_G}{\mathrm{d}A_9} = p_9 - p_0 ,
$$
因此当出口压力等于环境压力时它取驻值——而且是最大值。
:::

::: proof
在定常、准一维、无摩擦流动中，喷管一个薄片的动量方程为$\rho V\,\mathrm{d}V = -\mathrm{d}p$；乘以$A$并利用$\dot m = \rho V A$得$\dot m\,\mathrm{d}V = -A\,\mathrm{d}p$。把喷管延长$\mathrm{d}A_9$，使出口速度和压力改变$\mathrm{d}V_9$、$\mathrm{d}p_9$，它们按此方式相关联。于是
$$
\mathrm{d}F_G = \dot m\,\mathrm{d}V_9 + A_9\,\mathrm{d}p_9 + (p_9 - p_0)\,\mathrm{d}A_9 = (p_9 - p_0)\,\mathrm{d}A_9 ,
$$
因为前两项相消。在超声速流动中，更大的出口面积使$p_9$降低；所以当$p_9 > p_0$时扩大喷管增大推力，当$p_9 < p_0$时减小推力，最大值在$p_9 = p_0$处。物理上，延长扩张段壁面就增加了一个表面，燃气压力$p_9$在其上向前推，而环境压力$p_0$向后推：只有当$p_9 > p_0$时才值得这样做。假设：等熵、准一维、无分离流动；$\dot m$、$p_{t9}$、$T_{t9}$固定；外流压力为$p_0$（忽略喷管后体阻力）。
:::

::: example 超声速巡航时用收敛喷管还是缩放喷管 {#ex-cd-nozzle}
超声速巡航时，某发动机的喷管接收$T_{t9} = 1000\ \mathrm{K}$的燃气（$\gamma = 1.33$，$R = 287\ \mathrm{J/(kg\,K)}$，所以$c_p = 1157\ \mathrm{J/(kg\,K)}$），$\mathrm{NPR} = 8$。求完全膨胀的缩放喷管的出口马赫数、面积比$A_9/A^*$和射流速度，并将其单位质量流量的总推力与收敛喷管比较。
::: solution
**缩放喷管。** $p_9 = p_0$，所以$T_{t9}/T_9 = 8^{0.2481} = 1.675$，$T_9 = 597\ \mathrm{K}$：
$$
M_9 = \sqrt{\frac{2}{\gamma-1}\left(1.675 - 1\right)} = 2.02,\qquad
V_9 = \sqrt{2 \times 1157 \times (1000 - 597)} = 966\ \mathrm{m/s},
$$
取$\gamma = 1.33$，[[#eq-area-mach]]给出$A_9/A^* = 1.78$。
**收敛喷管。** 出口为声速：$T^* = 2T_{t9}/(\gamma+1) = 858\ \mathrm{K}$，$V^* = \sqrt{\gamma R T^*} = 572\ \mathrm{m/s}$，$p^* = 0.5404\,p_{t9}$。单位质量流量的压力推力为$(p^* - p_0)A^*/\dot m$，其中$\dot m/A^* = \mathrm{MFP}(1)\,p_{t9}/\sqrt{T_{t9}}$，对$\gamma = 1.33$有$\mathrm{MFP}(1) = 0.03970$：
$$
\frac{(p^* - p_0)A^*}{\dot m} = \frac{(0.5404 - 0.125)\sqrt{1000}}{0.03970} = 331\ \mathrm{m/s},
\qquad
\frac{F_G}{\dot m} = 572 + 331 = 903\ \mathrm{m/s}.
$$
收敛喷管提供理想总推力的$903/966 = 0.935$，损失 6.5 %。

**校核。** **净**推力的损失远大于 6.5 %：在马赫数 2 时，冲压阻力占总推力的很大比例，所以总推力减少 6.5 % 可能使净推力减少四分之一。这就是为什么每一种超声速巡航发动机都采用可调缩放喷管，而亚声速客机（巡航时 NPR 低于约 3）使用简单的收敛喷管，只损失零点几个百分点。
:::

### 缩放喷管的非设计工况

固定的缩放喷管只在一个 NPR 下完全膨胀。对面积比$A_9/A^*$，按 NPR 递减的顺序，流动状态为：

1. **欠膨胀**（NPR 高于设计值）：喷管内为设计流动，$p_9 > p_0$，在唇口处形成膨胀扇。
2. **带外部激波的过度膨胀**：内部流动仍是等熵的超声速设计流动，但$p_9 < p_0$，唇口处的斜激波提高射流压力。这种状态一直持续到使一道**正**激波恰好立于出口截面的 NPR。
3. **扩张段内有正激波**：随 NPR 下降激波向上游移动；激波后为亚声速流动，并扩压到$p_0$。（在实际喷管中，过度膨胀的边界层会先分离，流动图案更复杂。）
4. **全程亚声速**：低于喉部刚好达到$M = 1$、两侧均为亚声速流动时的 NPR。

这些边界由[[#eq-area-mach]]和[[#eq-normal-shock]]得出；[[#exr-off-design]]对[[#ex-cd-nozzle]]的喷管求出了它们。飞机喷管通过随飞行条件改变喉部和出口面积（鱼鳞片式或调节片式喷管）避免了大部分这些问题；火箭喷管做不到这一点，其高度特性在[[propulsion/rocket-fundamentals]]中讨论。

::: definition 喷管性能系数 {#def-nozzle-coeffs}
实际喷管用两个系数与理想喷管比较。**流量系数**$C_D = \dot m_{\text{实际}}/\dot m_{\text{理想}}$把质量流量与通过几何喉部的等熵流量比较（0.95–0.99；边界层和声速线的弯曲减小了有效喉部）。**总推力系数**$C_{fg} = F_{G,\text{实际}}/F_{G,\text{理想}}$把总推力与通过实际质量流量的完全膨胀等熵喷管的总推力比较（0.97–0.995），它综合了摩擦、出口气流的扩散（半锥角为$\alpha$的锥形喷管损失其动量推力的因子$(1 + \cos\alpha)/2$）和不完全膨胀。
:::

::: example 气流的混合：巡航时壅塞的风扇喷管 {#ex-fan-nozzle}
巡航时（$M_0 = 0.80$，$11\ \mathrm{km}$，$p_0 = 22.63\ \mathrm{kPa}$，$T_0 = 216.65\ \mathrm{K}$），大涵道比涡轮风扇发动机的风扇喷管接收风扇压比为$1.6$、进气道总压恢复系数为$0.99$的空气（风扇等熵，$\gamma = 1.4$）。收敛风扇喷管是否壅塞？若是，它比完全膨胀射流速度差多少？
::: solution
$p_{t13} = 1.6 \times 0.99 \times 34.50 = 54.65\ \mathrm{kPa}$，所以$\mathrm{NPR} = 54.65/22.63 = 2.415 > 1.893$：喷管壅塞。$T_{t13} = 244.4 \times 1.6^{0.2857} = 279.5\ \mathrm{K}$。
**壅塞的收敛喷管。** $T^* = 279.5/1.2 = 232.9\ \mathrm{K}$，$V^* = \sqrt{1.4 \times 287 \times 232.9} = 305.9\ \mathrm{m/s}$；$p^* = 54.65 \times 0.5283 = 28.87\ \mathrm{kPa}$；单位质量流量的$(p^* - p_0)A^*/\dot m = (28.87 - 22.63)\times10^3\sqrt{279.5}/(0.04042 \times 54\,650) = 47.2\ \mathrm{m/s}$，所以$F_G/\dot m = 353.1\ \mathrm{m/s}$。
**完全膨胀。** $V_{19} = \sqrt{2 \times 1004.5 \times 279.5\,[1 - 2.415^{-0.2857}]} = 353.6\ \mathrm{m/s}$。
收敛喷管达到理想总推力的$353.1/353.6 = 0.999$。

**校核。** 相对于风扇气流的单位推力$V_{19} - V_0 \approx 118\ \mathrm{m/s}$，$0.5\ \mathrm{m/s}$的差额约为风扇**净**推力的 0.4 %——很小，但对客机来说并非为零，不过仍比在直径两米的喷管上加一段扩张段所带来的重量和阻力代价小，这就是风扇喷管采用收敛型的原因。
:::

::: quiz
一个收敛喷管处于壅塞状态。环境压力降低（例如因爬升），而喷管进口的滞止参数保持不变。会发生什么？
- [ ] 质量流量增大，因为喷管两端的压差增大了。
- [x] 质量流量和出口速度保持不变，压力推力增大。
- [ ] 出口马赫数升到 1 以上。
- [ ] 出口压力降到新的环境压力。
::: solution
一旦出口达到声速，关于下游压力的信息就不能向上游传入喷管：质量流量$\mathrm{MFP}(1)A^*p_t/\sqrt{T_t}$、出口速度和出口压力都由上游滞止状态确定。只有压力推力$(p^* - p_0)A^*$随$p_0$下降而增大。收敛通道永远不能产生超声速流动。
:::

::: history
缩放喷管以古斯塔夫·德·拉瓦尔（Gustaf de Laval）命名，他在 19 世纪 80 年代用它产生超声速蒸汽射流来驱动他的小型高速汽轮机。奥莱尔·斯托多拉（Aurel Stodola）关于蒸汽喷管的实验发表于 20 世纪头十年，显示了立于过度膨胀喷管中的激波；超声速进气道理论是在第二次世界大战期间及战后不久发展起来的——德国的克劳斯·奥斯瓦蒂奇（Klaus Oswatitsch）研究多波系扩压器，NACA 的阿瑟·坎特罗维茨（Arthur Kantrowitz）和科尔曼·杜邦·唐纳森（Coleman duP. Donaldson）研究内压式扩压器的起动（1945年）。20 世纪 50 年代以后的超声速飞机使这些思想成为常规：1976年投入航线运营的协和号的可调斜板进气道，以及洛克希德 SR-71 的可移动中心锥进气道，是最著名的例子。
:::

::: summary
- 流量函数$\dot m\sqrt{T_t}/(Ap_t) = \mathrm{MFP}(M)$在$M = 1$时最大，它支配着壅塞和发动机部件的换算流量；面积-马赫数关系由它导出。
- 亚声速进气道扩压到$M_2 \approx 0.5$–$0.6$；捕获流管在巡航时小于唇口、在起飞时大于唇口，因此采用圆钝唇口。总压恢复系数$\pi_d = p_{t2}/p_{t0} \approx 0.97$–$0.995$；畸变与平均总压恢复同样重要。
- 超声速进气道在激波中损失总压；单道正激波在马赫数约 1.5 以下可以接受。把压缩分成几道弱斜激波加一道弱正激波，可以显著提高总压恢复；MIL-E-5007D 的$1 - 0.075(M_0 - 1)^{1.35}$是标准的设计研究规律。
- 内压式进气道必须起动，并可能不起动；外压式进气道可能发生嗡鸣。
- 收敛喷管在$\mathrm{NPR}_{\text{临界}} \approx 1.85$–$1.89$以上壅塞；由于$\mathrm{d}F_G/\mathrm{d}A_9 = p_9 - p_0$，喷管膨胀到$p_0$时总推力最大。
- 缩放喷管在高 NPR 下（超声速飞行、火箭）才有回报；在非设计工况下它欠膨胀或过度膨胀，激波位于喷管外或喷管内。
:::

::: exercise {#exr-off-design level=3 check="1.77"}
[[#ex-cd-nozzle]]的缩放喷管$A_9/A^* = 1.78$（$\gamma = 1.33$，设计$\mathrm{NPR} = 8$，设计$M_9 = 2.02$）。(a) 在什么 NPR 下正激波恰好立于出口截面？(b) NPR 低于多少时流动处处为亚声速？(c) 描述$\mathrm{NPR} = 3$时的流动。（输入 (a) 部分的 NPR，保留三位有效数字。）
::: solution
(a) 超声速设计流动到达出口时$p_9 = p_{t9}/8$，$M_9 = 2.02$。$M = 2.02$的正激波使静压乘以$[2\gamma M^2 - (\gamma-1)]/(\gamma+1) = 4.53$，所以当$p_0 = 4.53\,p_{t9}/8 = 0.566\,p_{t9}$即$\mathrm{NPR} = 1.77$时激波位于出口。
(b) [[#eq-area-mach]]对$A/A^* = 1.78$的亚声速解为$M = 0.351$，此时$p/p_t = 0.922$；所以在$\mathrm{NPR} = 1.085$时流动全程亚声速（喉部刚好声速），低于此值则完全为亚声速。
(c) $\mathrm{NPR} = 3$介于 1.77 和 8 之间：内部流动是等熵设计流动，$p_9 = p_{t9}/8$，低于环境压力（$p_{t9}/3$）。喷管过度膨胀，唇口处立有斜激波，压力推力$(p_9 - p_0)A_9$为负。（过度膨胀到这种程度的实际喷管很可能在扩张段内发生分离。）

::: exercise {#exr-inlet-design level=3}
**设计讨论。** 一架公务机要以马赫数 1.6 巡航。从总压恢复（用[[#eq-normal-shock]]和[[#eq-mil-spec]]）、重量、阻力、复杂性和起飞时的特性方面比较皮托式进气道与单斜板外压式进气道。估算总压恢复的差别对压气机进口总压的影响，并说明你会选择哪一种以及为什么。
::: solution
在$M_0 = 1.6$时，仅正激波给出$p_t$比$0.895$；对良好的多波系进气道，[[#eq-mil-spec]]给出$1 - 0.075 \times 0.6^{1.35} = 0.962$。由$\pi_r = (1 + 0.2 \times 2.56)^{3.5} = 4.25$，压气机进口压力为$3.80\,p_0$对$4.09\,p_0$（未计摩擦）——约低 7 %，压气机必须补回，代价是耗油率和推力上几个百分点。皮托式进气道轻、短，没有活动部件，没有起动问题，起飞特性好（采用圆钝唇口或辅助进气门）。斜板进气道需要可调几何以随马赫数调节激波，需要边界层放气，结构也更多。对马赫数不高的公务机，超声速飞行时间和重量代价都很重要，设计良好的皮托式或固定单斜板进气道是合理的选择；在马赫数 2 及以上，可调多波系进气道就变得必不可少。任何诚实的回答都应指出所有这些数字的不确定性，以及进行详细分析和试验的必要性。
:::
