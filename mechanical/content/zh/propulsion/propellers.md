螺旋桨是[[propulsion/thrust-efficiency]]这一课的极端情形：给**非常大**质量的空气一个**很小**的速度增量来产生推力，推进效率就趋近于 1。轻型飞机的螺旋桨扫过约$3\ \mathrm{m^2}$的桨盘，在$60\ \mathrm{m/s}$的巡航速度下只给流经它的空气增加每秒几米的速度；其推进效率原则上超过 90 %，实际上也高于 80 %。代价是桨叶必须运动得很快才能做到这一点——螺旋桨是一个旋转的机翼，其桨尖的运动速度是飞机速度的好几倍——随着飞行速度提高，桨尖接近声速，效率随之崩溃。这就是为什么在马赫数约 0.6 以下螺旋桨占主导，而在此之上则是涡轮风扇发动机。

本章建立螺旋桨的两种经典理论。**动量（作用盘）理论**把螺旋桨当作一个给气流增加压力的圆盘；它给出理想效率和给定推力所需的最小功率，但对桨叶一无所述。**叶素理论**把每个桨叶剖面当作翼型（[[aerodynamics/thin-airfoil-theory]]），对其升力和阻力积分；与动量理论结合，就成为实践中使用的**叶素动量（BEM）**方法。在此过程中我们引入螺旋桨性能总是用来表示的无量纲系数，最后讨论变距、压缩性以及螺旋桨与风扇之间的选择。

## 作用盘的动量理论

::: definition 作用盘 {#def-actuator-disc}
**作用盘**是理想化的螺旋桨：一个面积为$A$、无限薄的圆盘，气流无旋地穿过它，静压在盘上均匀地跃升$\Delta p$，而速度是连续的。在上游远处气流以$V_0$、压强$p_0$接近；在下游远处的**滑流**中，速度为$V_0 + w$，压强已回到$p_0$。盘处的速度记为$V_0 + v$，其中$v$为**诱导速度**。在动量平衡中，穿过圆盘的流管之外的流动不受扰动。
:::

::: proposition 弗劳德定理与理想效率 {#prop-froude}
对密度为$\rho$的定常、不可压、无黏流动中的作用盘：
1. 盘处的速度增量是远尾流中速度增量的一半，$v = w/2$；
2. 推力为$T = \rho A (V_0 + v)\,w = 2\rho A (V_0 + v)\,v$；
3. 吸收的功率为$P = T (V_0 + v)$，**理想推进效率**为
$$
\eta_i = \frac{T V_0}{P} = \frac{V_0}{V_0 + v} = \frac{2}{1 + \sqrt{1 + C_{T_s}}},
\qquad
C_{T_s} = \frac{T}{\tfrac12\rho V_0^2 A} .
$$ {#eq-ideal-eta}
:::

::: proof
**动量。** 取穿过圆盘的流管为控制体，其上游远处和下游远处的端面压强为$p_0$。质量流量为$\dot m = \rho A (V_0 + v)$。弯曲的流管边界上的压力确有轴向分量，所以改用经典论证：考虑一个包围圆盘的大控制体，其所有远边界上压强为$p_0$；与[[propulsion/thrust-efficiency]]中的推力方程一样，净力等于穿过圆盘的流动的动量变化，$T = \dot m\,w = \rho A (V_0 + v) w$。
**压强跃升。** 伯努利方程在圆盘上游和下游分别成立（除在圆盘处外没有能量加入）。上游：$p_0 + \tfrac12\rho V_0^2 = p_u + \tfrac12\rho(V_0 + v)^2$。下游：$p_d + \tfrac12\rho(V_0 + v)^2 = p_0 + \tfrac12\rho (V_0 + w)^2$。相减得
$$
\Delta p = p_d - p_u = \tfrac12\rho\left[(V_0 + w)^2 - V_0^2\right] = \rho w\left(V_0 + \tfrac12 w\right).
$$
作用在圆盘上的力也是$T = A\,\Delta p = \rho A w (V_0 + \tfrac12 w)$。与动量结果相等，得$V_0 + v = V_0 + \tfrac12 w$，即$v = w/2$。
**功率。** 传给气流的功率是动能通量的增加，$P = \tfrac12\dot m\left[(V_0 + w)^2 - V_0^2\right] = \dot m w (V_0 + \tfrac12 w) = T (V_0 + v)$。等价地，它是压强跃升乘以体积流量$\Delta p\,A(V_0 + v)$。效率为$\eta_i = TV_0/P = V_0/(V_0 + v)$。
**用推力载荷表示。** 由$T = 2\rho A (V_0 + v)v$解出$v$：$v = \tfrac12\left[-V_0 + \sqrt{V_0^2 + 2T/(\rho A)}\right]$，所以$(V_0 + v)/V_0 = \tfrac12\left[1 + \sqrt{1 + C_{T_s}}\right]$，由此得[[#eq-ideal-eta]]。假设：不可压、无黏、定常流动；载荷均匀；滑流中无旋转；无叶尖损失。实际螺旋桨还要因叶型阻力、旋转和载荷不均匀再损失 5–15 %。
:::

注意$\eta_i = 2/(1 + (V_0 + w)/V_0)$恰好是出口速度为$V_0 + w$的射流的推进效率：作用盘**就是**一台质量流量非常大的喷气发动机。效率只取决于一个数，即相对于动压的**推力载荷**$T/A$。轻载螺旋桨（桨盘大、推力小、速度高）效率高；重载螺旋桨则不然。

::: example 巡航轻型飞机的动量理论 {#ex-disc-cruise}
一架轻型飞机直径$1.9\ \mathrm{m}$的螺旋桨在海平面（$\rho = 1.225\ \mathrm{kg/m^3}$）以$V_0 = 60\ \mathrm{m/s}$飞行时产生$1500\ \mathrm{N}$推力。求滑流速度增量、理想效率和理想功率。
::: solution
$A = \pi \times 1.9^2/4 = 2.835\ \mathrm{m^2}$，$C_{T_s} = 1500/(\tfrac12 \times 1.225 \times 60^2 \times 2.835) = 0.240$。于是
$$
\eta_i = \frac{2}{1 + \sqrt{1.240}} = 0.946 .
$$
盘处速度为$V_0/\eta_i = 63.41\ \mathrm{m/s}$，所以$v = 3.41\ \mathrm{m/s}$，$w = 6.81\ \mathrm{m/s}$。功率$P = T(V_0 + v) = 1500 \times 63.41 = 95.1\ \mathrm{kW}$，其中$TV_0 = 90.0\ \mathrm{kW}$是有用的。

**校核。** 滑流只比自由流快 11 %，与$\eta_i$接近 1 相符。$\eta \approx 0.82$的实际螺旋桨大约需要$110\ \mathrm{kW}$轴功率——这正是四座飞机所装发动机的量级。多出的 15 kW 用于动量理论所忽略的桨叶叶型阻力、旋转和叶尖损失。
:::
:::

### 静推力与品质因数

在$V_0 = 0$时，上面定义的效率为零，而单位功率的推力恰恰是起飞、悬停旋翼和多旋翼无人机所关心的。在[[#prop-froude]]中令$V_0 = 0$：
$$
T = 2\rho A v^2,\qquad P_{\text{理想}} = T v = \frac{T^{3/2}}{\sqrt{2\rho A}} .
$$ {#eq-static}
在给定功率下，静推力按$(\rho A)^{1/3}P^{2/3}$增长：相同功率下桨盘越大升力越大，这就是直升机旋翼很大的原因。

::: definition 品质因数 {#def-figure-of-merit}
螺旋桨或旋翼在静态工作时的**品质因数**，是相同推力下理想（动量理论）功率与实际轴功率之比：
$$
\mathrm{FM} = \frac{T^{3/2}/\sqrt{2\rho A}}{P} .
$$
良好的直升机旋翼可达$\mathrm{FM} \approx 0.75$–$0.8$；小型无人机螺旋桨通常为$0.5$–$0.65$（雷诺数低，桨叶形状简单）。
:::

::: example 地面静推力 {#ex-static}
[[#ex-disc-cruise]]的螺旋桨在地面以$120\ \mathrm{kW}$驱动，品质因数为$0.75$。估算其静推力。
::: solution
实际推力对应的理想功率为$\mathrm{FM}\times P = 90\ \mathrm{kW}$，所以由[[#eq-static]]
$$
T = \left(2\rho A\,(\mathrm{FM}\,P)^2\right)^{1/3} = \left(2 \times 1.225 \times 2.835 \times (9.0\times10^{4})^2\right)^{1/3} = 3.83\ \mathrm{kN}.
$$
诱导速度为$v = \sqrt{T/(2\rho A)} = 23.5\ \mathrm{m/s}$。

**校核。** $3.8\ \mathrm{kN}$的静推力是$1.5\ \mathrm{kN}$巡航推力的两倍半——螺旋桨是大推力、低速度的装置，与涡轮喷气发动机相反，后者的推力在起飞滑跑过程中变化相对较小。实际上，定距巡航螺旋桨在$V_0 = 0$时会部分失速，达不到这个值；变距螺旋桨会更接近。
:::
:::

## 螺旋桨系数

对形状和桨距设置固定的螺旋桨应用量纲分析（[[fluid-mechanics/dimensional-analysis]]）表明，推力$T$、转矩$Q$和功率$P = 2\pi n Q$取决于$\rho$、$V_0$、转速$n$（每秒转数）、直径$D$，并通过雷诺数和桨尖马赫数取决于黏度和声速。当后两种效应是次要的时，三个组合就足够了。

::: definition 进距比与螺旋桨系数 {#def-coefficients}
$$
J = \frac{V_0}{nD},\qquad
C_T = \frac{T}{\rho n^2 D^4},\qquad
C_Q = \frac{Q}{\rho n^2 D^5},\qquad
C_P = \frac{P}{\rho n^3 D^5} = 2\pi C_Q ,
$$
螺旋桨效率为
$$
\eta = \frac{T V_0}{P} = J\,\frac{C_T}{C_P} .
$$ {#eq-prop-eta}
**进距比**$J$是飞机每转前进的距离，以直径为单位；$\pi/J$是桨尖速度与飞行速度之比。每个桨距设置下的$C_T(J)$、$C_P(J)$和$\eta(J)$构成螺旋桨的**性能图**。
:::

效率直接得出：$TV_0/P = (C_T\rho n^2D^4)(J nD)/(C_P\rho n^3 D^5) = JC_T/C_P$。对定距螺旋桨，$C_T$随$J$增大而下降（桨叶剖面以更小的迎角与空气相遇），并在**零推力进距比**处降到零；因此$\eta$从$J = 0$时的零上升到 0.8–0.88 的峰值，然后在该点之前急剧降回零。每个桨叶角有自己的曲线，各峰值的包络线就是变距螺旋桨所能追随的。

::: example 读螺旋桨性能图 {#ex-map}
一副两米的螺旋桨在海平面以$V_0 = 70\ \mathrm{m/s}$飞行时以$2400\ \mathrm{rpm}$旋转。在这一进距比下，其性能图给出$C_T = 0.080$，$C_P = 0.090$。求$J$、效率、推力和轴功率。
::: solution
$n = 2400/60 = 40\ \mathrm{rev/s}$，所以$J = 70/(40 \times 2.0) = 0.875$，$\eta = 0.875 \times 0.080/0.090 = 0.778$。
$$
T = C_T\rho n^2D^4 = 0.080 \times 1.225 \times 1600 \times 16 = 2.51\ \mathrm{kN},\qquad
P = C_P\rho n^3D^5 = 0.090 \times 1.225 \times 64\,000 \times 32 = 226\ \mathrm{kW}.
$$
**校核。** $TV_0/P = 2509 \times 70/225\,800 = 0.778$，理应如此。对相同推力和桨盘，动量理论给出$C_{T_s} = 2509/(\tfrac12 \times 1.225 \times 70^2 \times 3.142) = 0.266$，$\eta_i = 0.941$：实际螺旋桨达到理想值的约 83 %，这是典型的。
:::
:::

## 叶素理论

动量理论把螺旋桨当作一个黑色圆盘。要设计桨叶，我们需要知道每一段桨叶在做什么。

::: definition 叶素、入流角与迎角 {#def-blade-element}
考虑一副有$B$片桨叶的螺旋桨在半径$r$处、宽度为$\mathrm{d}r$的圆环，桨叶在该处弦长为$c$，从旋转平面量起的**桨叶角**（桨距角）为$\beta$。该剖面以轴向速度$V_a = V_0(1 + a)$和切向速度$V_\theta = \Omega r(1 - a')$与空气相遇，其中$\Omega = 2\pi n$，$a$、$a'$为轴向和周向**诱导因子**（在最简单的理论中两者都为零）。合速度为$W = \sqrt{V_a^2 + V_\theta^2}$，**入流角**为$\phi = \arctan(V_a/V_\theta)$，剖面迎角为$\alpha = \beta - \phi$。剖面的升力系数和阻力系数为$C_l(\alpha)$、$C_d(\alpha)$，其**阻力角**为$\gamma = \arctan(C_d/C_l)$。
:::

升力垂直于$W$，阻力沿$W$。分解到轴向（推力）和切向（转矩）：
$$
\mathrm{d}T = \tfrac12\rho W^2 B c\,(C_l\cos\phi - C_d\sin\phi)\,\mathrm{d}r,
\qquad
\mathrm{d}Q = \tfrac12\rho W^2 B c\,(C_l\sin\phi + C_d\cos\phi)\,r\,\mathrm{d}r .
$$ {#eq-blade-element}
若入流（即$a$和$a'$）已知，从桨毂积分到桨尖即得$T$和$Q$。

::: proposition 叶素效率 {#prop-element-eta}
忽略诱导速度（$a = a' = 0$），叶素效率为
$$
\eta_e = \frac{V_0\,\mathrm{d}T}{\Omega\,\mathrm{d}Q} = \frac{\tan\phi}{\tan(\phi + \gamma)},
$$ {#eq-element-eta}
对给定阻力角$\gamma$，它在$\phi = 45° - \gamma/2$时最大，此时$\eta_{e,\max} = \tan(45° - \gamma/2)/\tan(45° + \gamma/2)$。
:::

::: proof
取$C_d = C_l\tan\gamma$，[[#eq-blade-element]]给出
$$
\frac{\mathrm{d}T}{\mathrm{d}Q} = \frac{\cos\phi - \tan\gamma\sin\phi}{r(\sin\phi + \tan\gamma\cos\phi)} = \frac{\cos(\phi + \gamma)}{r\sin(\phi + \gamma)} = \frac{1}{r\tan(\phi+\gamma)},
$$
这里分子分母同乘了$\cos\gamma$。在$a = a' = 0$时，$\tan\phi = V_0/(\Omega r)$，所以
$$
\eta_e = \frac{V_0}{\Omega r\tan(\phi+\gamma)} = \frac{\tan\phi}{\tan(\phi+\gamma)} .
$$
求最大值时，令$\ln\eta_e = \ln\tan\phi - \ln\tan(\phi + \gamma)$的导数为零：$1/(\sin\phi\cos\phi) = 1/(\sin(\phi+\gamma)\cos(\phi+\gamma))$，即$\sin 2\phi = \sin(2\phi + 2\gamma)$，其相关解为$2\phi = 180° - 2\phi - 2\gamma$，所以$\phi = 45° - \gamma/2$。假设：二维剖面特性适用于每个半径；无诱导速度；各叶素之间无相互作用。
:::

[[#eq-element-eta]]给出两点启示。第一，即使没有诱导损失，叶型阻力也使效率在$\phi \to 0$（低进距比——桨叶在搅动空气）和$\phi + \gamma \to 90°$时都降到零。第二，最佳入流角约为$45°$，而实际螺旋桨不可能沿整个桨叶都具有这一角度，因为$\tan\phi = V_0/(\Omega r)$随半径变化：靠近桨毂的剖面$\phi$大，靠近桨尖的$\phi$小。这就是桨叶要**扭转**的原因——$\beta$向外减小——以使每个剖面都接近其最佳迎角，这也是桨叶内侧部分贡献很小的原因。

::: example 四分之三半径处的叶素 {#ex-element}
一副半径$1.0\ \mathrm{m}$的双叶螺旋桨在海平面以$60\ \mathrm{m/s}$飞行时以$2400\ \mathrm{rpm}$旋转。在$r = 0.75\ \mathrm{m}$处，桨叶弦长为$0.12\ \mathrm{m}$，桨叶角$\beta = 24°$；剖面迎角每度$C_l = 0.1$，$C_d = 0.010$。忽略诱导，求该半径处的入流角、迎角、两片桨叶单位展长的推力和转矩，以及叶素效率。
::: solution
$\Omega = 2\pi \times 40 = 251.3\ \mathrm{rad/s}$，$\Omega r = 188.5\ \mathrm{m/s}$；$\phi = \arctan(60/188.5) = 17.66°$，所以$\alpha = 24° - 17.66° = 6.34°$，$C_l = 0.634$。$W = \sqrt{60^2 + 188.5^2} = 197.8\ \mathrm{m/s}$，$\tfrac12\rho W^2 = 23.97\ \mathrm{kPa}$。
$$
\frac{\mathrm{d}T}{\mathrm{d}r} = 23\,970 \times 2 \times 0.12\,(0.634\cos 17.66° - 0.010\sin 17.66°) = 3.46\ \mathrm{kN/m},
$$
$$
\frac{\mathrm{d}Q}{\mathrm{d}r} = 23\,970 \times 2 \times 0.12\,(0.634\sin 17.66° + 0.010\cos 17.66°) \times 0.75 = 871\ \mathrm{N\,m/m}.
$$
叶素效率：$\eta_e = 60 \times 3459/(251.3 \times 871.1) = 0.948$；由[[#eq-element-eta]]，取$\gamma = \arctan(0.010/0.634) = 0.90°$，$\tan 17.66°/\tan 18.56° = 0.948$。

**校核。** 这一圆环的动量平衡$\mathrm{d}T = 4\pi r\rho V_0^2(1 + a)a\,\mathrm{d}r$要承担$3.46\ \mathrm{kN/m}$需要$a = 0.077$：桨叶处的轴向速度实际约为$64.6\ \mathrm{m/s}$，这使$\phi$增大、$\alpha$减小一度以上。忽略诱导会高估推力——这正是 BEM 方法所弥补的差距。
:::
:::

### 叶素动量理论

两种理论的缺口是互补的：叶素理论需要诱导速度，动量理论需要桨叶力。对每个圆环分别应用动量理论（假设各圆环互不影响）并令两者相等，就得到 BEM 方程。

::: algorithm 叶素动量（BEM）分析 {#alg-bem}
对半径$r$、宽度$\mathrm{d}r$的每个圆环：
1. 假设诱导因子$a$、$a'$（从零开始）。
2. 计算$V_a = V_0(1+a)$、$V_\theta = \Omega r(1 - a')$、$\phi$、$\alpha = \beta - \phi$、$W$，并按当地雷诺数和马赫数从剖面数据求$C_l$、$C_d$。
3. 由[[#eq-blade-element]]计算$\mathrm{d}T$和$\mathrm{d}Q$。
4. 令它们等于圆环动量关系——轴向动量$\mathrm{d}T = 4\pi r\rho V_0^2(1+a)a\,\mathrm{d}r$和角动量$\mathrm{d}Q = 4\pi r^3\rho V_0(1+a)\Omega a'\,\mathrm{d}r$——解出新的$a$、$a'$。
5. 欠松弛并重复 2–4，直到$a$、$a'$收敛。用**叶尖损失因子**（普朗特对 Goldstein 解的近似）乘以桨尖附近的载荷，以计入有限的桨叶数。
6. 沿桨叶对$\mathrm{d}T$、$\mathrm{d}Q$积分；$\eta = TV_0/(\Omega Q)$。
:::

BEM 速度快，在有良好翼型数据和叶尖损失修正时，对常规螺旋桨性能的预测误差在百分之几以内；它也是风力机风轮设计的基础（在那里气流被减速，在本符号约定下$a < 0$）。在其假设失效的地方它也就失效了：重载或大后掠桨叶、强烈的三维和压缩性效应，以及滑流中有短舱或机翼等安装效应，对这些情况要使用涡格法和 CFD 方法。

::: warning 进距比使用每秒转数，各种系数不能互换
$J = V_0/(nD)$以及系数$C_T = T/(\rho n^2D^4)$、$C_P = P/(\rho n^3 D^5)$中的$n$以**每秒转数**计，而不是 rpm，也不是 rad/s。使用以 rad/s 计的$\Omega$会使$C_T$改变$4\pi^2 \approx 39.5$倍。直升机领域还使用另一套系数，即以桨尖速度和桨盘面积为基准的$C_T = T/(\rho A(\Omega R)^2)$。从数据表读取数字之前，务必检查它使用的是哪种约定，并用$\eta = JC_T/C_P$作一致性校核。
:::

## 变距控制、压缩性与螺旋桨的极限

**定距。** 定距螺旋桨只在一个进距比下效率最高；按巡航设计时，它在起飞时效率低且部分失速，发动机达不到全转速；按爬升设计时，它在巡航时使发动机超转。

**变距与恒速螺旋桨。** 变距桨毂改变整片桨叶的$\beta$。在**恒速**螺旋桨中，调速器调节桨距，使发动机无论飞行速度和功率设置如何都以选定的转速运行，从而使螺旋桨保持在其效率峰值包络线附近。桨距还可以设为**顺桨**（桨叶以边缘对着气流，以在发动机失效后使阻力最小），在许多涡轮螺旋桨飞机上还可设为**反桨**，用于在跑道上刹车。

**桨尖马赫数。** 桨尖沿螺旋线运动，速度为$\sqrt{V_0^2 + (\pi n D)^2}$。当**螺旋桨尖螺旋马赫数**接近并超过约$0.85$–$0.9$时，外侧剖面上形成激波，阻力急剧上升，效率下降，噪声增大。这给桨尖速度设定了上限，进而在给定转速下限制了直径（因此涡轮螺旋桨发动机要用减速器，其涡轮以每分钟数千转运转，而螺旋桨约为$1000$–$2000$ rpm）。薄而后掠的桨尖和更多的桨叶可以提高可用马赫数。

::: example 涡轮螺旋桨飞机的桨尖马赫数 {#ex-tip-mach}
一架支线涡轮螺旋桨飞机的螺旋桨直径$3.9\ \mathrm{m}$，巡航时在温度为$242.7\ \mathrm{K}$的高度（标准大气$7\ \mathrm{km}$）以$V_0 = 140\ \mathrm{m/s}$飞行，转速$1020\ \mathrm{rpm}$。求螺旋桨尖螺旋马赫数。
::: solution
$a = \sqrt{1.4 \times 287 \times 242.7} = 312.3\ \mathrm{m/s}$。桨尖旋转速度$\pi n D = \pi \times 17.0 \times 3.9 = 208.3\ \mathrm{m/s}$。螺旋桨尖速度$\sqrt{208.3^2 + 140^2} = 251.0\ \mathrm{m/s}$，所以$M_{\text{桨尖}} = 0.80$。

**校核。** 飞行马赫数为$0.45$，进距比$J = 140/(17.0 \times 3.9) = 2.11$。如果飞机以相同转速在马赫数 0.7 下飞行，桨尖马赫数将为$\sqrt{(208.3/312.3)^2 + 0.7^2} = 0.97$——超出了宽松的极限。要飞得更快，螺旋桨必须转得更慢（每片桨叶的推力减少），或者使用薄而后掠的桨叶。
:::
:::

**螺旋桨还是风扇？** 在低速下，螺旋桨巨大的桨盘赋予它无可匹敌的推进效率和静推力。随着飞行马赫数提高，有三件事侵蚀了它的优势：螺旋桨尖螺旋马赫数的极限；旋转损失（螺旋桨留下旋转的滑流，而风扇的静子叶片消除了旋转）；以及螺旋桨无法在来流到达桨叶之前使其减速，而涵道风扇的进气道使气流扩压，使风扇叶片在任何巡航速度下看到的都是约马赫数 0.5–0.6。涡轮螺旋桨飞机通常以马赫数 0.5–0.65 巡航；在马赫数约 0.7 以上，大涵道比涡轮风扇发动机胜出。**开式转子**或**桨扇**——薄、大后掠、多桨叶的螺旋桨，常为对转的一对以回收旋转——以接近螺旋桨的效率瞄准马赫数 0.75–0.8，代价是噪声和安装困难；它们在 20 世纪 80 年代进行过飞行试验，至今仍在发展中。

::: quiz
一副按巡航设计的定距螺旋桨在地面以全油门试车。与巡航相比，下列哪种说法正确？
- [ ] 桨叶剖面以更小的迎角工作，所以螺旋桨载荷较轻。
- [x] 入流角$\phi$小得多，所以剖面以大迎角工作，可能失速。
- [ ] 推进效率更高，因为诱导速度更高。
- [ ] 进距比不变，因为转速不变。
::: solution
在$V_0 = 0$时（除诱导入流外），$\tan\phi = V_a/(\Omega r)$很小，$\alpha = \beta - \phi$接近完整的桨叶角，对于巡航桨距的桨叶，这在外侧剖面上远超失速。进距比为零，效率（定义为$TV_0/P$）为零，而且发动机通常无法克服大转矩达到全转速——这是采用变距螺旋桨的原因之一。
:::
:::

::: history
螺旋桨的动量理论由朗肯（W. J. M. Rankine，1865年）开创，他把船用螺旋桨当作加速一柱水的装置；由弗劳德（R. E. Froude，1889年）完成，他引入作用盘，并证明速度增量的一半发生在圆盘之前。威廉·弗劳德（William Froude）在1878年提出逐个叶素分析桨叶，斯特凡·杰维茨基（Stefan Drzewiecki）从 19 世纪 90 年代起发展了空气螺旋桨的叶素理论。莱特兄弟把桨叶当作旋转机翼，用自己的风洞试验数据设计了1903年飞行者号的螺旋桨。阿尔伯特·贝茨（Albert Betz，1919年）求出了使诱导损失最小的沿桨叶最优载荷分布，悉尼·戈德斯坦（Sydney Goldstein，1929年）求解了有限桨叶数的情形，这是 BEM 中所用叶尖损失修正的基础。变距和恒速螺旋桨在 20 世纪 30 年代得到广泛使用。
:::

::: summary
- 作用盘理论：速度增量的一半发生在圆盘之前；$T = 2\rho A(V_0 + v)v$，$P = T(V_0 + v)$，理想效率$\eta_i = V_0/(V_0 + v) = 2/(1 + \sqrt{1 + C_{T_s}})$。桨盘载荷低意味着效率高。
- 静态工作：$P_{\text{理想}} = T^{3/2}/\sqrt{2\rho A}$；品质因数比较理想功率与实际功率。
- 性能用$J = V_0/(nD)$、$C_T$、$C_P$和$\eta = JC_T/C_P$表示，$n$以每秒转数计。
- 叶素理论把剖面升力和阻力分解为推力和转矩；叶素效率$\tan\phi/\tan(\phi+\gamma)$在$\phi = 45°$附近最大；桨叶扭转以使各剖面接近最佳迎角。
- BEM 逐个圆环结合两种理论，并带叶尖损失修正。
- 变距使螺旋桨在各种速度下保持高效；螺旋桨尖螺旋马赫数限制速度和直径；在马赫数约 0.65–0.7 以上，涵道风扇取而代之。
:::

一副直径$1.8\ \mathrm{m}$的螺旋桨在飞行速度$54\ \mathrm{m/s}$下以$40\ \mathrm{rev/s}$旋转，此时其性能图给出$C_T = 0.10$，$C_P = 0.10$。求进距比和效率。（以小数输入效率。）

::: exercise {#exr-ideal-eta level=1 check="0.909"}
作用盘后方远处滑流中的速度比飞行速度高$20\,\%$。理想效率是多少？（以保留三位有效数字的小数输入。）
::: solution
$w = 0.2V_0$，$v = w/2 = 0.1V_0$，$\eta_i = V_0/(V_0 + v) = 1/1.1 = 0.909$。

::: exercise {#exr-tip-static level=1 check="0.832"}
一副直径$2.0\ \mathrm{m}$的螺旋桨在地面以$2700\ \mathrm{rpm}$旋转，该处声速为$340\ \mathrm{m/s}$。求桨尖马赫数。（保留三位有效数字输入。）
::: solution
桨尖速度$\pi n D = \pi \times 45 \times 2.0 = 282.7\ \mathrm{m/s}$；由于$V_0 = 0$，$M_{\text{桨尖}} = 282.7/340 = 0.832$。

$A = 0.1257\ \mathrm{m^2}$，$P_{\text{理想}} = 10^{1.5}/\sqrt{2 \times 1.225 \times 0.1257} = 31.62/0.5549 = 57.0\ \mathrm{W}$。轴功率$= 57.0/0.6 = 95\ \mathrm{W}$。

一副直径$2.2\ \mathrm{m}$的螺旋桨在$\rho = 1.00\ \mathrm{kg/m^3}$的高度以$35\ \mathrm{rev/s}$旋转，$C_T = 0.090$。求推力。（以 kN 为单位输入推力，保留三位有效数字。）

某桨叶剖面的升阻比为 50。忽略诱导损失，该剖面的任何叶素所能达到的最高效率是多少？（保留三位有效数字输入。）
::: solution
$\gamma = \arctan(0.02) = 1.146°$；在$\phi = 45° - 0.573° = 44.43°$处，$\eta_e = \tan 44.43°/\tan 45.57° = 0.961$。

::: exercise {#exr-disc-size level=3 check="1.47"}
选择最小的螺旋桨直径，使其在海平面（$\rho = 1.225\ \mathrm{kg/m^3}$）以$70\ \mathrm{m/s}$产生$2500\ \mathrm{N}$推力时，**理想**效率至少为$0.90$。（以 m 为单位输入直径，保留三位有效数字。）
::: solution
$\eta_i = V_0/(V_0 + v) = 0.90$给出$v = V_0/9 = 7.78\ \mathrm{m/s}$，$w = 15.56\ \mathrm{m/s}$。由$T = \rho A(V_0 + v)w$：$A = 2500/(1.225 \times 77.78 \times 15.56) = 1.687\ \mathrm{m^2}$，所以$D = \sqrt{4A/\pi} = 1.47\ \mathrm{m}$。这一尺寸的实际螺旋桨约能达到$0.8$；更大的直径会进一步提高效率，但会涉及桨尖马赫数极限和离地间隙问题。
:::

::: exercise {#exr-bem-derive level=3}
推导[[#alg-bem]]第 4 步所用的圆环动量关系：(a) $\mathrm{d}T = 4\pi r\rho V_0^2(1+a)a\,\mathrm{d}r$和 (b) $\mathrm{d}Q = 4\pi r^3\rho V_0(1+a)\Omega a'\,\mathrm{d}r$，其中盘处的诱导周向速度为$a'\Omega r$，远尾流中的为其两倍。说明所作的假设。
::: solution
(a) 圆环通过的流量为$\mathrm{d}\dot m = \rho\,2\pi r\,\mathrm{d}r\,V_0(1+a)$。对圆环应用[[#prop-froude]]，远尾流增量是盘处增量$aV_0$的两倍，所以$\mathrm{d}T = \mathrm{d}\dot m \times 2aV_0 = 4\pi r\rho V_0^2(1+a)a\,\mathrm{d}r$。
(b) 转矩等于气流角动量的增加率。空气无旋地进入，在圆盘紧后方具有切向速度$2a'\Omega r$（圆盘前方旋转为零，后方为$2a'\Omega r$，$a'\Omega r$是盘处的平均值）。其单位质量角动量为$r \times 2a'\Omega r$，所以$\mathrm{d}Q = \mathrm{d}\dot m\,2a'\Omega r^2 = 4\pi r^3\rho V_0(1+a)\Omega a'\,\mathrm{d}r$。
假设：各圆环相互独立（无径向相互作用），桨叶外为定常、不可压、无黏流动，轴对称（无限多桨叶——事后用叶尖损失因子修正），尾流中压强等于$p_0$（忽略与旋转相关的小压强亏损）。
:::
:::

::: exercise {#exr-prop-vs-fan level=3}
**设计讨论。** 一家飞机制造商必须为一架典型航段长度为$500\ \mathrm{km}$的 70 座支线飞机在涡轮螺旋桨发动机和齿轮传动涡轮风扇发动机之间作出选择。利用本章和[[propulsion/thrust-efficiency]]的思想，列出双方的论据（推进效率、巡航马赫数与轮挡时间、桨尖马赫数、客舱噪声、安装、维修），说明你会推荐哪一种，以及需要什么数据才能确定。
::: solution
**涡轮螺旋桨：** 大桨盘和低桨盘载荷带来高推进效率，在马赫数 0.5–0.6 下燃油消耗最低，起飞和短跑道性能优异；桨尖马赫数把巡航限制在约马赫数 0.65；客舱中的螺旋桨噪声和振动需要处理；减速器和螺旋桨增加维修工作。**涡轮风扇：** 以马赫数 0.75–0.8 巡航缩短轮挡时间——但在$500\ \mathrm{km}$的航段上，其中很大一部分是爬升和下降，节省的时间只有几分钟；短航段上每座燃油消耗更高；客舱更安静，翼下安装更简单，巡航高度更高、在天气之上。在短航段上，燃油成本通常有利于涡轮螺旋桨；在较长航段上，或在旅客偏好和速度占主导时，有利于涡轮风扇。合理的推荐需要根据实际航段剖面由发动机数据算出的任务燃油消耗、维修成本、机场噪声限制和机队通用性——物理学为选择提供框架，但不能单独作出决定。
:::
