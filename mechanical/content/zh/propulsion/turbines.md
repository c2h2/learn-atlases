涡轮是燃气涡轮发动机中为其他一切买单的部件。它从离开燃烧室的高温高压燃气中提取功，并通过轴把功送回压气机；在涡轮风扇或涡轮螺旋桨发动机中，它还驱动产生大部分推力的风扇或螺旋桨。它是在常用工程机械中最恶劣的环境里完成这一切的：第一排转子叶片处在比制造它的镍基合金熔点还热的燃气中，转得如此之快，以至于每片叶片以约十吨量级的力拉着它的榫根。

在气动上，涡轮是叶轮机械中容易的那一半。它的叶栅使气流**加速**，压力沿叶片表面下降，即使每排叶片使气流转折 100° 或更多，边界层也保持附着。因此一级涡轮能提取的功是一级压气机的好几倍，几级涡轮就能驱动十级或更多级的压气机。困难在别处——在冷却、在应力、在**匹配**：涡轮必须在每个工作点都恰好提供压气机所吸收的功率，而它的第一排导向叶片通常处于壅塞状态，决定了整台发动机的流通能力。

本章把[[propulsion/compressors]]中的欧拉方程应用于膨胀级，引入用于涡轮级分类的负荷和反力度参数，导出膨胀过程的多变效率关系，然后讨论使涡轮与众不同的三个主题：壅塞的导向器与流量函数、叶片冷却，以及限制叶片速度和环形通道面积的离心应力。滞止参数带下标$t$；截面 4 为涡轮进口（高压涡轮导向器进口），45 为高压涡轮出口，5 为末级涡轮出口。燃气视为完全气体，$c_p = 1150\ \mathrm{J\,kg^{-1}\,K^{-1}}$，$\gamma = 1.33$，$R = 287\ \mathrm{J\,kg^{-1}\,K^{-1}}$；空气取$c_p = 1005\ \mathrm{J\,kg^{-1}\,K^{-1}}$，$\gamma = 1.4$。

## 物理图景：膨胀级

涡轮级的排列顺序与压气机相反：先是一排静止的**导向叶片**（NGV，即静子，统称导向器），然后是**转子**。导向叶片使燃气加速，并使其沿旋转方向强烈转折，把压力转换为高速旋转射流。转子叶片接收这股射流，把它向另一侧转回，燃气对叶片的反作用力驱动叶片旋转。如果转子通道也使相对气流加速——**反力级**——压降的一部分发生在转子中；如果相对速度不变——**冲击级**——压降全部发生在导向叶片中。

顺压梯度解释了每级的高功量，但并不使涡轮没有损失。大转折角产生强烈的**二次流**——作用于低速端壁边界层的横向通道压力梯度所驱动的通道涡——而转子叶尖与机匣之间的间隙造成**叶尖泄漏**，即越过叶片而不做功的燃气。加上尾缘损失、叶型损失和冷却空气的掺混，这些因素使涡轮级效率约为 88–93 %。

## 速度三角形与功

我们使用与[[propulsion/compressors#def-velocity-triangles]]相同的参考系，但采用适合涡轮的符号约定：**所有**角度，绝对角$\alpha$和相对角$\beta$，都从轴向量起，以旋转方向为正，于是
$$
c_\theta = c_x\tan\alpha, \qquad w_\theta = c_\theta - U = c_x\tan\beta.
$$
截面 1 为导向叶片进口，2 为导向叶片出口（转子进口），3 为转子出口。在典型的级中，$\alpha_2$是很大的正值（导向叶片射流），$\beta_3$是很大的负值（转子把相对气流逆旋转方向转回），而$\alpha_3$接近零。

::: proposition 轴流涡轮级的功 {#prop-turbine-work}
对平均半径不变、轴向速度$c_x$不变的轴流涡轮级，传给转子的比功为
$$
w_t = h_{t1} - h_{t3} = U(c_{\theta 2} - c_{\theta 3}) = U c_x(\tan\alpha_2 - \tan\alpha_3) = U c_x(\tan\beta_2 - \tan\beta_3).
$$ {#eq-turbine-work}
用流量系数$\phi = c_x/U$和级负荷系数$\psi = w_t/U^2$表示，$c_3 = c_1$的级的反力度（静焓降中转子所占份额）为
$$
\psi = \phi(\tan\beta_2 - \tan\beta_3), \qquad R = \frac{h_2 - h_3}{h_1 - h_3} = -\frac{\phi}{2}(\tan\beta_2 + \tan\beta_3),
$$ {#eq-turbine-reaction}
若该级出口无周向速度（$\alpha_3 = 0$），则
$$
\psi = 2(1 - R).
$$ {#eq-zero-swirl}
:::

::: proof
欧拉方程[[propulsion/compressors#eq-euler]]给出对燃气**所做**的功为$h_{t3} - h_{t1} = U(c_{\theta 3} - c_{\theta 2})$，因为静子（1→2）不做功，而转子（2→3）半径不变。燃气输出的功为其负值，这就是[[#eq-turbine-work]]的第一种形式。代入$c_\theta = c_x\tan\alpha$得第二种形式；代入$c_\theta = U + c_x\tan\beta$得第三种形式，因为含$U$的项相消。

对反力度，相对总焓$h + w^2/2$在等半径下通过转子守恒（在旋转参考系中不做功），所以$h_2 - h_3 = \tfrac{1}{2}(w_3^2 - w_2^2) = \tfrac{1}{2}c_x^2(\tan^2\beta_3 - \tan^2\beta_2)$。由于$c_3 = c_1$，级的静焓降等于总焓降，$h_1 - h_3 = w_t = U c_x(\tan\beta_2 - \tan\beta_3)$。两者相除并因式分解：
$$
R = \frac{c_x^2(\tan\beta_3 - \tan\beta_2)(\tan\beta_3 + \tan\beta_2)}{2U c_x(\tan\beta_2 - \tan\beta_3)} = -\frac{\phi}{2}(\tan\beta_2 + \tan\beta_3).
$$
出口无周向速度时$c_{\theta 3} = 0$，所以$w_{\theta 3} = -U$，$\tan\beta_3 = -1/\phi$。于是$R = \tfrac12 - \tfrac{\phi}{2}\tan\beta_2$，即$\phi\tan\beta_2 = 1 - 2R$，而$\psi = \phi\tan\beta_2 + 1 = 2 - 2R$。假设：定常绝热流动，半径和轴向速度不变，各截面参数均匀（中径模型），反力度公式还要求重复级。
:::

[[#eq-zero-swirl]]是涡轮设计者的基本权衡。出口无周向速度的**50 % 反力度**级$\psi = 1$：功不大，速度三角形对称，两排叶片中都有加速，使损失保持较低。**冲击**级（$R = 0$）$\psi = 2$：相同叶片速度下功加倍，但转子不再使相对气流加速，所以其边界层表现较差，而且导向叶片出口速度很高。现代高压涡轮介于两者之间，通常在平均半径处$\psi \approx 1.5$–$2$，反力度约$0.25$–$0.45$；低压涡轮的叶片速度受慢速旋转的风扇轴限制，负荷系数为$2$–$3$。出口周向速度不为零时，通常选择略为**逆**旋转方向，这样以下一排叶片为代价增加了功。

给定$\phi$和$\psi$的级效率有多高？经典的总结是**史密斯图**（S. F. ::: example 一个高压涡轮级 {#ex-hp-stage}
某高压涡轮级平均叶片速度$U = 380\ \mathrm{m/s}$，轴向速度$c_x = 228\ \mathrm{m/s}$，负荷系数$\psi = 1.5$，出口无周向速度。进口总温$T_{t4} = 1600\ \mathrm{K}$。求反力度、气流角、总温降和导向叶片出口马赫数。
::: solution
**系数。** $\phi = 228/380 = 0.600$；由[[#eq-zero-swirl]]，$R = 1 - \psi/2 = 0.25$。

**角度。** 由于$c_{\theta 3} = 0$，功为$U c_{\theta 2}$，所以$\tan\alpha_2 = \psi/\phi = 2.5$，$\alpha_2 = 68.2^\circ$。转子进口：$\tan\beta_2 = \tan\alpha_2 - 1/\phi = 2.5 - 1.667 = 0.833$，$\beta_2 = 39.8^\circ$。转子出口：$\tan\beta_3 = -1/\phi$，$\beta_3 = -59.0^\circ$。转子使相对气流转折$98.8^\circ$。

**功。** $w_t = \psi U^2 = 1.5 \times 380^2 = 216.6\ \mathrm{kJ/kg}$，所以$\Delta T_t = 216\,600/1150 = 188.3\ \mathrm{K}$。

**导向叶片出口马赫数。** $c_2 = c_x/\cos\alpha_2 = 228/0.3714 = 613.9\ \mathrm{m/s}$。总温通过静止的导向叶片不变，所以$T_2 = 1600 - 613.9^2/(2 \times 1150) = 1436\ \mathrm{K}$，且
$$
M_2 = \frac{613.9}{\sqrt{1.33 \times 287 \times 1436}} = 0.83.
$$
**合理性校核。** 由角度求反力度的公式给出$R = -\tfrac{0.6}{2}(0.833 - 1.667) = 0.25$，与[[#eq-zero-swirl]]一致。一级提取$188\ \mathrm{K}$是典型值：两个这样的级使燃气温度降低约$380\ \mathrm{K}$，接近 20:1 压气机所需的值（下一例）。相对速度从$w_2 = 297\ \mathrm{m/s}$**升高**到$w_3 = 443\ \mathrm{m/s}$——转子使气流加速，正如反力级应有的那样。
:::
:::

## 膨胀效率

[[propulsion/compressors#prop-polytropic]]的预热效应在涡轮中有一个镜像。前面涡轮级的损失使燃气比等熵膨胀时更热，后面的级可以把这部分能量中的一部分作为额外的功回收——这就是**重热**效应。

::: proposition 膨胀过程的等熵效率 {#prop-turbine-polytropic}
对$c_p$为常数的完全气体，以恒定多变效率$\eta_{p}$（对膨胀定义为$\mathrm{d}h_t/\mathrm{d}h_{ts}$）通过总压比$\pi_t = p_{t4}/p_{t5} > 1$膨胀，
$$
\frac{T_{t5}}{T_{t4}} = \pi_t^{-\eta_p(\gamma-1)/\gamma},
\qquad
\eta_t = \frac{T_{t4} - T_{t5}}{T_{t4} - T_{t5s}} = \frac{1 - \pi_t^{-\eta_p(\gamma-1)/\gamma}}{1 - \pi_t^{-(\gamma-1)/\gamma}},
$$ {#eq-turbine-polytropic}
且当$\pi_t > 1$、$\eta_p < 1$时$\eta_t > \eta_p$。
:::

::: proof
在无穷小膨胀步中，等熵焓变为$\mathrm{d}h_{ts} = v_t\,\mathrm{d}p_t = (R T_t/p_t)\,\mathrm{d}p_t$（膨胀时为负），实际焓变是它的$\eta_p$倍：$c_p\,\mathrm{d}T_t = \eta_p R T_t\,\mathrm{d}p_t/p_t$。除以$c_p T_t$并利用$R/c_p = (\gamma-1)/\gamma$，
$$
\frac{\mathrm{d}T_t}{T_t} = \eta_p\frac{\gamma-1}{\gamma}\frac{\mathrm{d}p_t}{p_t},
$$
积分得$T_{t5}/T_{t4} = (p_{t5}/p_{t4})^{\eta_p(\gamma-1)/\gamma} = \pi_t^{-\eta_p(\gamma-1)/\gamma}$。等熵出口温度为$T_{t4}\pi_t^{-(\gamma-1)/\gamma}$；把两者代入定义即得[[#eq-turbine-polytropic]]。记$b = \tfrac{\gamma-1}{\gamma}\ln\pi_t > 0$，则$\eta_t = (1 - e^{-\eta_p b})/(1 - e^{-b})$。函数$g(x) = (1 - e^{-x})/x$在$x > 0$时递减，且$\eta_p b < b$，所以$g(\eta_p b) > g(b)$，即$(1 - e^{-\eta_p b})/(\eta_p b) > (1 - e^{-b})/b$，整理得$\eta_t > \eta_p$。
:::

## 涡轮与压气机的匹配

在以稳定转速运行的单轴上，涡轮功率必须等于压气机功率加上很小的机械损失和附件负载。把涡轮质量流量写成$\dot m(1 + f)$，其中$f$为油气比（这一简单模型中忽略绕过第一级的冷却空气），机械效率记为$\eta_m$：
$$
\eta_m\,\dot m(1 + f)\,c_{p,g}(T_{t4} - T_{t45}) = \dot m\,c_{p,a}(T_{t3} - T_{t2}).
$$ {#eq-work-balance}
一旦选定压气机，**功平衡**就确定了涡轮的温降；涡轮效率随后确定其压比，剩下的压力供下一级涡轮或喷管使用。

::: example 核心转子的功平衡 {#ex-work-balance}
一台增压比为$20$、多变效率为$0.90$的核心压气机吸入$T_{t2} = 288\ \mathrm{K}$的空气。驱动它的涡轮接收$T_{t4} = 1600\ \mathrm{K}$的燃气，$f = 0.025$；$\eta_m = 0.99$，涡轮多变效率为$0.90$。求涡轮出口温度、压比和等熵效率。
::: solution
**压气机。** $T_{t3} - T_{t2} = 288(20^{0.2857/0.90} - 1) = 457.4\ \mathrm{K}$。

**涡轮温降。** 由[[#eq-work-balance]]，
$$
T_{t4} - T_{t45} = \frac{1005 \times 457.4}{0.99 \times 1.025 \times 1150} = 394.0\ \mathrm{K},
\qquad T_{t45} = 1206\ \mathrm{K}.
$$
**压比。** 取$(\gamma-1)/\gamma = 0.2481$反解[[#eq-turbine-polytropic]]：
$$
\pi_t = \left(\frac{1600}{1206}\right)^{1/(0.90 \times 0.2481)} = 3.55,
\qquad
\eta_t = \frac{1 - 3.55^{-0.2233}}{1 - 3.55^{-0.2481}} = 0.914.
$$
**合理性校核。** 涡轮的温降小于压气机的温升（$394$对$457\ \mathrm{K}$），因为燃气的$c_p$更高，量也略多。它只需$3.5$的压比就能驱动$20:1$的压气机，因为它在高五倍的温度下工作——这与布雷顿循环之所以能产生净功是同一个原因。两个像[[#ex-hp-stage]]那样的级就能提供这一温降。
:::
:::

## 壅塞的导向器

在大多数发动机的大多数功率状态下，第一级导向叶片之间的喉道处于壅塞状态：燃气在那里达到马赫数 1。这使导向器喉道面积成为发动机性能中最重要的单个数字，因为壅塞喉道通过的质量流量仅由上游滞止参数决定。

::: definition 流量函数 {#def-flow-function}
在面积为$A$、马赫数为$M$、滞止参数为$p_t$、$T_t$的截面上，**流量函数**（质量流量参数）为
$$
\frac{\dot m\sqrt{T_t}}{A\,p_t} = \sqrt{\frac{\gamma}{R}}\;M\left(1 + \frac{\gamma-1}{2}M^2\right)^{-\frac{\gamma+1}{2(\gamma-1)}}.
$$ {#eq-flow-function}
:::

::: proposition 壅塞质量流量 {#prop-choked}
对完全气体的定常等熵流动，流量函数[[#eq-flow-function]]在$M = 1$处取最大值。因此面积为$A^*$的壅塞喉道通过的流量为
$$
\dot m = \frac{A^* p_t}{\sqrt{T_t}}\sqrt{\frac{\gamma}{R}}\left(\frac{2}{\gamma+1}\right)^{\frac{\gamma+1}{2(\gamma-1)}},
$$
与下游压力无关。对$\gamma = 1.33$、$R = 287\ \mathrm{J\,kg^{-1}\,K^{-1}}$，该常数为$0.0397\ \mathrm{kg\,K^{1/2}\,s^{-1}\,N^{-1}}$（对空气，$\gamma = 1.4$：$0.0404$）。
:::

::: proof
写出$\dot m = \rho A c$，其中$c = M\sqrt{\gamma R T}$，$\rho = p/(RT)$，所以$\dot m = A p M\sqrt{\gamma/(R T)}$。等熵滞止关系$T_t/T = 1 + \tfrac{\gamma-1}{2}M^2 \equiv X$和$p_t/p = X^{\gamma/(\gamma-1)}$给出
$$
\frac{\dot m\sqrt{T_t}}{A p_t} = \sqrt{\frac{\gamma}{R}}\,M\,X^{1/2}X^{-\gamma/(\gamma-1)} = \sqrt{\frac{\gamma}{R}}\,M\,X^{-\frac{\gamma+1}{2(\gamma-1)}},
$$
这就是[[#eq-flow-function]]。对右边取对数后对$M$求导：
$$
\frac{1}{M} - \frac{\gamma+1}{2(\gamma-1)}\cdot\frac{(\gamma-1)M}{X} = \frac{1}{M} - \frac{(\gamma+1)M}{2X} = \frac{2X - (\gamma+1)M^2}{2MX} = \frac{2(1 - M^2)}{2MX},
$$
它只在$M = 1$处为零，在此之下为正、之上为负：是最大值。在$M = 1$时$X = (\gamma+1)/2$，即得所述公式。一旦喉道达到声速，来自下游的压力扰动就不能通过它向上游传播，所以进一步降低下游压力不能增大流量。数值常数代入即得。假设：从滞止状态到喉道为等熵流动，$\gamma$为常数的完全气体，喉道上流动均匀（实际喉道使用约$0.95$–$0.98$的流量系数）。
:::

这对发动机匹配有深远的影响。导向器壅塞时，涡轮进口的换算流量$\dot m\sqrt{T_{t4}}/p_{t4}$固定。经过燃烧室（其相对压力损失很小且近乎恒定）往回推，再除以压气机进口参数，得
$$
\frac{\dot m\sqrt{T_{t2}}}{p_{t2}} \propto \frac{\pi_c}{\sqrt{T_{t4}/T_{t2}}},
$$
因此在压气机特性图上，涡轮施加了换算流量与增压比之间的一个关系，它取决于温比$T_{t4}/T_{t2}$——这就是[[propulsion/compressors]]中的**共同工作线**。在给定换算流量下提高涡轮进口温度，会把工作点推向更高的增压比，即趋向喘振。这也解释了为什么发动机的导向器面积被用来“微调”新设计：喉道面积改变几个百分点就会移动整条工作线。

::: example 确定导向器喉道尺寸 {#ex-ngv}
某核心机以$T_{t4} = 1600\ \mathrm{K}$、$p_{t4} = 3.0\ \mathrm{MPa}$向其高压涡轮输送$50\ \mathrm{kg/s}$燃气。若喉道壅塞，需要多大的导向器喉道总面积？（忽略流量系数。）
::: solution
由[[#prop-choked]]，取$\gamma = 1.33$，
$$
A^* = \frac{\dot m\sqrt{T_{t4}}}{0.0397\,p_{t4}} = \frac{50 \times 40.0}{0.0397 \times 3.0\times10^{6}} = 0.0168\ \mathrm{m^2} = 168\ \mathrm{cm^2}.
$$
**合理性校核。** 若有比如 40 片叶片，每个喉道约为$4.2\ \mathrm{cm^2}$——例如宽$10\ \mathrm{mm}$、高$42\ \mathrm{mm}$，对中等尺寸发动机的高压涡轮是合理的尺寸。面积小是因为燃气密度高：在$3\ \mathrm{MPa}$、$1600\ \mathrm{K}$下滞止密度约为$6.5\ \mathrm{kg/m^3}$。该面积$1\ \%$的误差就是在给定$p_{t4}$、$T_{t4}$下发动机流量$1\ \%$的误差。
:::
:::

## 叶片冷却与材料

更高的涡轮进口温度带来更高的单位推力，配合相应的增压比还带来更高的热效率（见[[propulsion/gas-turbine-cycles]]）。截至2026年，最先进的大型民用涡轮风扇发动机起飞时的涡轮进口温度约为$1900$–$2000\ \mathrm{K}$量级，而用于高压叶片的单晶镍基高温合金为达到所需的蠕变寿命，金属温度限制在大约$1300$–$1400\ \mathrm{K}$——几百开尔文的差距由冷却和几十分之一毫米厚的陶瓷**热障涂层**来弥补。

冷却空气从压气机出口引出——通常为$800$–$950\ \mathrm{K}$——经叶片榫根送入内部通道。热量通过带肋蛇形通道中的**对流**、射流对前缘内侧的**冲击**以及**气膜冷却**带走：从成排小孔喷出的空气在外表面形成一层冷气膜，使叶片与高温燃气隔开。

::: definition 冷却效能 {#def-cooling-effectiveness}
叶片的综合**冷却效能**为
$$
\varepsilon = \frac{T_g - T_m}{T_g - T_c},
$$
其中$T_g$为高温燃气的相对总温，$T_m$为叶片金属平均温度，$T_c$为冷却剂供给温度。$\varepsilon = 0$是处于燃气温度的无冷却叶片，$\varepsilon = 1$是保持在冷却剂温度的叶片。
:::

现代高压叶片的$\varepsilon \approx 0.6$–$0.7$。冷却剂不是免费的：绕过第一级转子的压缩空气以及掺入主流的气膜空气，都会降低涡轮功和效率，高压涡轮的冷却可能要用掉约五分之一量级的核心流量。因此，涡轮进口温度每进一步提高，都是材料、涂层、冷却孔设计与循环收益之间的一次权衡。

::: example 所需的冷却效能 {#ex-cooling}
第一级转子处燃气的相对总温为$1900\ \mathrm{K}$，冷却剂以$900\ \mathrm{K}$到达。(a) 冷却效能为$0.60$时金属平均温度是多少？(b) 要使金属温度为$1250\ \mathrm{K}$，需要多大的效能？
::: solution
(a) $T_m = T_g - \varepsilon(T_g - T_c) = 1900 - 0.60 \times 1000 = 1300\ \mathrm{K}$。

(b) $\varepsilon = (1900 - 1250)/(1900 - 900) = 0.65$。

**合理性校核。** 这里五十开尔文的金属温度要付出五个百分点的效能。在这个范围内，金属温度每升高$10$–$15\ \mathrm{K}$，镍基合金的蠕变寿命大约减半，所以 (a) 与 (b) 之间的差别对叶片寿命而言是一个很大的倍数——这就是为什么发动机在炎热天气起飞时要降额使用，以及为什么即使冷却效能的小损失（冷却孔堵塞、涂层脱落）也很重要。
:::
:::

::: warning 对转子叶片使用绝对燃气温度
转子叶片在其自身参考系中看待燃气，所以驱动热量传入叶片的温度是**相对**总温$T_{t,\mathrm{rel}} = T + w^2/(2c_p)$，而不是绝对总温$T_t = T + c^2/(2c_p)$。在导向叶片之后，绝对速度远大于相对速度（[[#ex-hp-stage]]中为$614$对$297\ \mathrm{m/s}$），所以转子看到的燃气比导向叶片出口总温低约$125\ \mathrm{K}$。反之，导向叶片承受燃烧室出口的全部温度**以及**其热斑——由离散的燃油喷嘴造成的周向不均匀性——它们是发动机中最热的部件。混淆两个参考系会使冷却设计偏差一百开尔文。
:::

## 离心应力与 AN² 极限

转子叶片被其自身的旋转向外拉。在给定半径处，叶片截面承受其外侧全部材料的离心载荷，应力在榫根处最大。

::: proposition 旋转叶片的根部应力 {#prop-an2}
截面均匀、密度为$\rho$、从轮毂半径$r_h$延伸到叶尖半径$r_t$、装在以角速度$\omega$旋转的轮盘上的叶片，其根部拉应力为
$$
\sigma_{\text{根部}} = \rho\,\omega^2\,\frac{r_t^2 - r_h^2}{2} = \frac{\rho\,\omega^2 A}{2\pi},
\qquad A = \pi(r_t^2 - r_h^2),
$$ {#eq-an2}
其中$A$为叶片扫过的环形通道面积。叶尖面积小于根部面积的变截面叶片，根部应力较低，减小的锥度因子通常为$0.5$–$0.7$。
:::

::: proof
考虑半径$r$与$r + \mathrm{d}r$之间的叶片微元，截面积为$a$时其质量为$\rho a\,\mathrm{d}r$。其向心加速度为$\omega^2 r$，必须由其内侧的叶片材料提供：该微元对根部拉力的贡献为$\rho a\omega^2 r\,\mathrm{d}r$。从根部到叶尖求和，
$$
F_{\text{根部}} = \int_{r_h}^{r_t}\rho a\,\omega^2 r\,\mathrm{d}r = \rho a\omega^2\,\frac{r_t^2 - r_h^2}{2}
$$
（$a$为常数），除以$a$即得应力。由于$A = \pi(r_t^2 - r_h^2)$，$\sigma = \rho\omega^2 A/(2\pi)$。若$a$向外减小，外侧材料更轻，积分更小。气动载荷产生的弯曲应力和榫头处的应力集中是附加的；这里只是直接的离心分量。
:::

由于$\omega \propto N$，根部应力正比于$A N^2$——即 **AN² 参数**，以$\mathrm{m^2\,rpm^2}$或$\mathrm{in^2\,rpm^2}$表示。这是涡轮设计者首先校核的数字。它把气动与结构耦合在一起：出口环形通道面积由质量流量和涡轮出口所需的轴向马赫数决定，转速由做功所需的叶片速度决定。必须通过大体积流量（大$A$）的涡轮必须转得慢——直接驱动涡轮风扇发动机的低压涡轮受风扇转速限制，因而需要很多级，这就是齿轮传动涡轮风扇发动机的动机。

::: example 高压叶片的根部应力 {#ex-an2}
某高压涡轮转子以$12\,000\ \mathrm{rpm}$运转，轮毂半径$0.30\ \mathrm{m}$，叶尖半径$0.38\ \mathrm{m}$。镍基合金密度为$8000\ \mathrm{kg/m^3}$。估算等截面叶片和锥度因子为$0.6$时的根部应力。
::: solution
$\omega = 12\,000 \times 2\pi/60 = 1257\ \mathrm{rad/s}$，$A = \pi(0.38^2 - 0.30^2) = 0.1709\ \mathrm{m^2}$。于是
$$
\sigma_{\text{根部}} = \frac{8000 \times 1257^2 \times 0.1709}{2\pi} = 344\ \mathrm{MPa},
$$
有锥度时为$0.6 \times 344 = 206\ \mathrm{MPa}$。AN² 值为$0.1709 \times 12\,000^2 = 2.46\times10^{7}\ \mathrm{m^2\,rpm^2}$。

**合理性校核。** 叶尖速度为$1257 \times 0.38 = 478\ \mathrm{m/s}$，是高压涡轮的典型值。在接近$1300\ \mathrm{K}$的金属温度下持续数千小时的$200$–$350\ \mathrm{MPa}$根部应力，正是单晶合金所针对的蠕变工况；承载叶片的轮缘承受的载荷更大。
:::
:::

::: quiz
某涡轮的导向器处于壅塞状态。发动机控制系统把涡轮进口温度提高 10 %，而涡轮进口总压保持不变。通过导向器的质量流量会怎样？
- [ ] 增大约 10 %，因为加入了更多能量。
- [ ] 不变，因为喉道壅塞。
- [x] 下降约 5 %，因为壅塞流量正比于$p_t/\sqrt{T_t}$。
- [ ] 下降约 10 %。
::: solution
壅塞流量为$\dot m \propto A^* p_t/\sqrt{T_t}$。在$p_t$不变时，$\dot m \propto T_t^{-1/2}$，所以$1.10^{-1/2} = 0.953$：下降约 4.7 %。“壅塞”意味着在给定**上游**滞止参数下流量固定，而不是绝对固定。在发动机中，$p_{t4}$实际上也会变化，工作点正是这样沿工作线移动的。
:::
:::

::: history
两种经典涡轮类型以其先驱者命名。查尔斯·**帕森斯**（Charles Parsons）于1884年获得多级反动式汽轮机专利，在固定和运动叶片排之间分配压降，并于1897年用涡轮驱动的“透平尼亚”号（*Turbinia*）作了引人注目的演示。古斯塔夫·**德·拉瓦尔**（Gustaf de Laval）在 19 世纪 80 年代发展了单级冲击式汽轮机，全部膨胀在喷管中完成——为此他引入了缩放喷管——叶轮以极高转速旋转。奥莱尔·**斯托多拉**（Aurel Stodola）的《汽轮机》（*Die Dampfturbinen*，1903年，后来扩充到燃气轮机）首次对涡轮设计进行了系统的工程论述。20 世纪 30 年代末的第一批航空燃气涡轮发动机采用无冷却涡轮，其进口温度被限制在约$1000$–$1100\ \mathrm{K}$；S. F. Smith 1965年的效率关联图（至今仍称史密斯图）总结了此后几十年的气动经验。
:::

::: summary
- 涡轮级是**先导向器后转子**；导向叶片产生高速旋转射流，转子把它转回。加速流动允许高负荷：一级涡轮对应几级压气机。
- 功：$w_t = U(c_{\theta 2} - c_{\theta 3}) = U c_x(\tan\beta_2 - \tan\beta_3)$；出口无周向速度时$\psi = 2(1 - R)$——50 % 反力度给出$\psi = 1$，冲击级给出$\psi = 2$。
- **史密斯图**把级效率与$\phi$和$\psi$关联起来；高压涡轮在$\psi \approx 1.5$–$2$下工作，低压涡轮更高。
- 在膨胀中等熵效率**超过**多变效率（重热），这是压气机预热代价的镜像。
- **功平衡**$\eta_m\dot m(1+f)c_{p,g}\Delta T_{t,\text{涡轮}} = \dot m c_{p,a}\Delta T_{t,\text{压气机}}$确定涡轮温降。
- **壅塞的导向器**固定了换算流量$\dot m\sqrt{T_{t4}}/p_{t4}$，从而确定压气机工作线。
- **冷却**（对流、冲击、气膜）和热障涂层使叶片能在比其金属极限高几百开尔文的燃气中工作；代价是冷却空气。
- 根部离心应力$\sigma = \rho\omega^2 A/(2\pi)$：**AN²** 极限把环形通道面积与轴转速联系起来。
:::

一个出口无周向速度的冲击式涡轮级以平均叶片速度$300\ \mathrm{m/s}$运转。其比功是多少？（以 kJ/kg 为单位输入功。）
::: solution
对出口无周向速度的$R = 0$，[[#eq-zero-swirl]]给出$\psi = 2$，所以$w_t = 2U^2 = 2 \times 300^2 = 180\,000\ \mathrm{J/kg} = 180\ \mathrm{kJ/kg}$。
:::

::: exercise {level=1 check="0.632"}
一片有冷却的导向叶片处于$1850\ \mathrm{K}$的燃气中；冷却剂以$900\ \mathrm{K}$进入，测得金属平均温度为$1250\ \mathrm{K}$。冷却效能是多少？（以小数输入，保留三位有效数字。）
::: solution
$\varepsilon = (1850 - 1250)/(1850 - 900) = 600/950 = 0.632$。
:::

::: exercise {level=1 check="0.915"}
某涡轮使燃气（$\gamma = 1.33$）通过总压比$4.0$膨胀，多变效率为$0.90$。其等熵效率是多少？（以小数输入，保留三位有效数字。）
::: solution
取$(\gamma-1)/\gamma = 0.2481$：$4^{-0.2481} = 0.7091$，$4^{-0.90 \times 0.2481} = 4^{-0.2233} = 0.7339$。所以$\eta_t = (1 - 0.7339)/(1 - 0.7091) = 0.2661/0.2909 = 0.915$，如[[#prop-turbine-polytropic]]所预言，高于多变效率。
:::
:::

::: exercise {level=2 check="55.0"}
一个 50 % 反力度的涡轮级出口无周向速度，流量系数为$0.70$。导向叶片出口角$\alpha_2$是多少？画出速度三角形，并给出转子进出口相对气流角。（以度为单位输入$\alpha_2$，保留一位小数。）
::: solution
$\psi = 2(1 - 0.5) = 1$，所以出口无周向速度时$\tan\alpha_2 = \psi/\phi = 1/0.7 = 1.4286$，$\alpha_2 = 55.0^\circ$。于是$\tan\beta_2 = \tan\alpha_2 - 1/\phi = 0$：相对气流轴向进入转子。在出口$\tan\beta_3 = -1/\phi$，$\beta_3 = -55.0^\circ$。速度三角形互为镜像——这是 50 % 反力度的标志（$\alpha_2 = -\beta_3$，$\beta_2 = \alpha_3$）。
:::
:::

::: exercise {level=2 check="6.07"}
某发动机的导向器处于壅塞状态。在炎热天气，涡轮进口温度在涡轮进口总压不变的情况下从$1500\ \mathrm{K}$提高到$1700\ \mathrm{K}$。通过导向器的质量流量下降百分之多少？（输入百分数，保留三位有效数字。）
::: solution
$\dot m \propto p_t/\sqrt{T_t}$，所以新流量是原流量的$\sqrt{1500/1700} = 0.9393$：下降$6.07\ \%$。
:::
:::

::: exercise {level=2 check="227"}
某直接驱动涡轮风扇发动机的一个低压涡轮级以$3600\ \mathrm{rpm}$旋转，轮毂半径$0.50\ \mathrm{m}$，叶尖半径$0.80\ \mathrm{m}$；叶片合金密度为$8200\ \mathrm{kg/m^3}$。估算等截面叶片的根部应力。这一结果对叶片设计有什么启示？（以 MPa 为单位输入应力，保留三位有效数字。）
::: solution
$\omega = 3600 \times 2\pi/60 = 377.0\ \mathrm{rad/s}$，$A = \pi(0.80^2 - 0.50^2) = 1.225\ \mathrm{m^2}$。于是$\sigma = 8200 \times 377.0^2 \times 1.225/(2\pi) = 227\ \mathrm{MPa}$。尽管转速不到[[#ex-an2]]中的三分之一，巨大的环形通道仍使应力与那里的变截面高压叶片相当，温度虽低，但叶片长得多、柔得多；长的低压叶片采用强烈的变截面并做成空心，或采用更轻的合金（某些低压涡轮使用钛铝合金）来降低应力。
:::
:::

::: exercise {level=3}
推导[[#eq-turbine-polytropic]]，并证明对压比很小的膨胀$\pi_t = 1 + \varepsilon$，$\eta_t \approx \eta_p\left[1 + \tfrac{\gamma-1}{2\gamma}(1 - \eta_p)\varepsilon\right]$。从物理上解释重热效应，并说明为什么它并不意味着前面级的损失无害。
::: solution
推导即[[#prop-turbine-polytropic]]的推导。对膨胀，令$b = \tfrac{\gamma-1}{\gamma}\ln\pi_t \approx k\varepsilon$，其中$k = (\gamma-1)/\gamma$。利用$1 - e^{-x} = x(1 - x/2 + \dots)$，
$$
\eta_t = \frac{\eta_p b(1 - \eta_p b/2)}{b(1 - b/2)} \approx \eta_p\left[1 + \frac{b}{2}(1 - \eta_p)\right] = \eta_p\left[1 + \frac{k}{2}(1 - \eta_p)\varepsilon\right].
$$
修正项为正。物理上，前面级中产生的熵使燃气在给定压力下比等熵膨胀时更热，而在给定压比上可提取的功与进口温度成正比，所以后面级提取的功比从等熵状态出发时略多。这是对前面损失的部分回收，而不是将其抵消：出口总温仍高于等熵值，总功仍小于等熵值，“损失”的能量仍随排气离开。只是相对于单一等熵参考的**记账**方式，使整叠看起来比其各级更好。
:::
:::

::: exercise {level=3}
**设计。** 一台高压涡轮必须用$T_{t4} = 1750\ \mathrm{K}$的燃气驱动一台每千克空气吸收$560\ \mathrm{kJ/kg}$的压气机（$f = 0.025$，$\eta_m = 0.99$）。叶尖速度受应力限制不超过$520\ \mathrm{m/s}$，可假设中径与叶尖半径之比为$0.88$。决定采用一级还是两级，为每级选择$\phi$、$\psi$和反力度，并估算第一级的导向叶片出口马赫数和转子相对进口温度。讨论其中的权衡。
::: solution
**每千克燃气的功。** $560/(0.99 \times 1.025) = 551.9\ \mathrm{kJ/kg}$，温降$480\ \mathrm{K}$。

**叶片速度。** 中径$U = 0.88 \times 520 = 458\ \mathrm{m/s}$，$U^2 = 2.09\times10^{5}\ \mathrm{m^2/s^2}$。一级需要$\psi = 552\,000/209\,000 = 2.64$——超出通常的高压范围，出口马赫数很高，由[[#eq-zero-swirl]]反力度接近零或为负；效率会很低。两级各取$\psi \approx 1.32$则很宽松，出口无周向速度时$R \approx 0.34$。

**第一级**，$\phi = 0.55$（$c_x = 252\ \mathrm{m/s}$），$\psi = 1.32$：$\tan\alpha_2 = 1.318/0.55 = 2.396$，$\alpha_2 = 67.3^\circ$，$c_2 = 252/0.3852 = 653\ \mathrm{m/s}$。$T_2 = 1750 - 653^2/2300 = 1564\ \mathrm{K}$，$M_2 = 653/\sqrt{1.33 \times 287 \times 1564} = 0.85$。相对：$\tan\beta_2 = 2.396 - 1.818 = 0.578$，$\beta_2 = 30.0^\circ$，$w_2 = 252/\cos 30.0^\circ = 291\ \mathrm{m/s}$，所以$T_{t,\text{相对}} = 1564 + 291^2/2300 = 1601\ \mathrm{K}$——比$T_{t4}$低 150 K，这减轻了转子冷却的负担。

**权衡。** 单个高负荷级（某些现代发动机采用很高的叶尖速度和跨声速导向器）节省了一排叶片的长度、重量和冷却空气，但可能损失两三个百分点的效率；两级效率更好，进入低压涡轮的出口周向速度更低，代价是多一排有冷却的叶片。选择取决于发动机是重量关键还是燃油关键。任何论证充分、数字一致的选择都可以接受。
