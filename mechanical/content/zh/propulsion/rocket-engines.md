[[propulsion/rocket-fundamentals]]把火箭发动机当作有效速度为$c = C_F c^*$的排气源。本章考察产生这些排气的机器，并提出工程师在选择发动机时必须回答的系统层面的问题：推进剂如何以高压送入燃烧室，燃烧室如何免于熔化，固体火箭发动机如何自行调节压力，以及为什么比冲是化学火箭十倍的电推力器只能产生毫牛级的推力？答案来自少数几条守恒定律——泵的能量、压力容器和燃烧表面的平衡、电推力器的功率——它们解释了这一领域的大格局：大推力化学发动机用于发射和着陆，小推力电推进用于空间中的长期任务。

本章的论述有意停留在标准教材（Sutton 和 Biblarz，*Rocket Propulsion Elements*；Goebel 和 Katz，*Fundamentals of Electric Propulsion*）中的性能和系统设计层次。它不包含任何推进剂配方或制造信息；火箭发动机的设计、制造和试验是由在严格安全规章下运作的有资质机构从事的工作。

## 火箭推进概览

::: definition 火箭推进的类别 {#def-classes}
- **液体双组元**发动机把燃料和氧化剂分别以液态贮存，并把它们喷入燃烧室。**单组元**推力器在催化剂上分解单一液体。
- **固体火箭发动机**把推进剂作为固体装药（**药柱**）装在燃烧室本身内；一旦点燃，就一直燃烧到烧完。
- **混合**火箭把一种组元（通常是氧化剂）以液态或气态贮存，另一种作为固体药柱装在燃烧室内。
- **电**推力器利用来自太阳电池阵或核能源的电能加速推进剂：通过加热（**电热式**：电阻加热推力器、电弧加热推力器），通过在静电场中加速离子（**静电式**：栅极离子推力器和霍尔效应推力器），或通过作用于等离子体的电磁力（**电磁式**：磁等离子体动力推力器和脉冲等离子体推力器）。
:::

化学类是**能量受限**的：每千克的能量由化学反应决定，所以排气速度有上限（最好的实用组合约为$4.5\ \mathrm{km/s}$），但功率——从而推力——可以极大，因为能量在推进剂内部以其供给的任意速率释放。电推力器是**功率受限**的：排气速度可以很高，但推力受航天器所能提供的电功率限制。

## 液体推进剂发动机

液体发动机由推进剂贮箱、把推进剂增压到高于燃烧室压力的供应系统、使推进剂雾化和混合的喷注器、燃烧室和喷管组成；阀门、点火器和控制系统安排其工作顺序。基本的设计问题是**如何把推进剂送进燃烧室**：$5$–$30\ \mathrm{MPa}$的燃烧室压力是理想的，因为高压使发动机相对其推力更紧凑（$F = C_F p_c A_t$），并允许在较短长度内获得大的喷管面积比。

### 挤压式与泵压式系统

最简单的供应系统用惰性气体给贮箱增压，让贮箱压力把推进剂推入燃烧室。它的弱点在于贮箱。

::: proposition 增压球形贮箱的质量 {#prop-tank-mass}
由密度为$\rho_m$、许用应力为$\sigma$的材料制成、容积为$V$、承受压力$p$的薄壁球形贮箱，其壁质量为
$$
m_{\text{贮箱}} = \frac{3}{2}\,\frac{p\,V\,\rho_m}{\sigma},
$$ {#eq-tank-mass}
对给定的$pV$它与贮箱尺寸无关：贮箱质量正比于所贮存的压力与容积之积。
:::

::: proof
对半径为$r$、壁厚$t \ll r$的薄球，半球的平衡给出薄膜应力$\sigma = pr/(2t)$（[[mechanics-of-materials]]薄壁压力容器），所以所需壁厚为$t = pr/(2\sigma)$。壁质量为$m = 4\pi r^2 t\rho_m = 2\pi r^3 p\rho_m/\sigma$，而由$V = \tfrac43\pi r^3$，$2\pi r^3 = \tfrac32 V$，由此得[[#eq-tank-mass]]。假设：薄壁，薄膜应力均匀，不考虑气垫空间、接头、屈曲，除$\sigma$中已包含的以外不另加安全因数。带半球形封头的圆柱形贮箱需要更多材料：圆柱中的环向应力是球的两倍。
:::

由于燃烧室压力必须低于贮箱压力（相差喷注器和管路损失），$p_c = 2\ \mathrm{MPa}$的挤压式发动机需要约$3\ \mathrm{MPa}$的贮箱，而[[#eq-tank-mass]]使大量推进剂的贮箱重得无法接受。因此挤压式供应用于简单性和可靠性比贮箱质量更重要的场合：航天器推力器和小型上面级，燃烧室压力约为$0.5$–$2\ \mathrm{MPa}$。

::: example 挤压式还是泵压式贮箱 {#ex-tankage}
某级在球形铝合金贮箱（$\rho_m = 2800\ \mathrm{kg/m^3}$，许用应力$250\ \mathrm{MPa}$）中携带$10\ \mathrm{m^3}$推进剂。比较贮箱压力为$0.3\ \mathrm{MPa}$的泵压式设计与贮箱需要$3.0\ \mathrm{MPa}$的挤压式设计的贮箱壁质量。
::: solution
由[[#eq-tank-mass]]，$m = 1.5\,pV\rho_m/\sigma$：
$$
m_{0.3} = \frac{1.5 \times 0.3\times10^{6} \times 10 \times 2800}{2.5\times10^{8}} = 50.4\ \mathrm{kg},\qquad
m_{3.0} = 504\ \mathrm{kg}.
$$
若推进剂平均密度约为$1000\ \mathrm{kg/m^3}$，挤压式贮箱的质量为推进剂的$5\,\%$，这还没有加上高压气体及其自身（更重的）贮气瓶；泵压式贮箱为$0.5\,\%$。

**校核。** 十倍的比值就是压力比，正如[[#eq-tank-mass]]所预言。实际上低压贮箱的尺寸由其他载荷决定——飞行弯曲、轴向压缩、操作搬运——所以其真实质量高于按压力的估计，但结论成立：对大型级而言，涡轮泵是产生压力的更轻的方式。
:::
:::

**泵压式**发动机使贮箱保持低压（几巴，足以防止泵汽蚀并加强结构刚度），用**涡轮泵**提高推进剂压力：由同轴涡轮驱动的离心泵（有时为轴流泵）。泵功率由不可压液体的稳定流动能量方程得到。

::: proposition 泵功率 {#prop-pump-power}
以质量流量$\dot m$把密度为$\rho$的液体的压力提高$\Delta p$、总效率为$\eta_p$的泵，吸收的轴功率为
$$
P = \frac{\dot m\,\Delta p}{\rho\,\eta_p} .
$$ {#eq-pump-power}
:::

::: proof
对动能和势能变化可忽略的不可压液体的定常绝热流动，单位质量的可逆功为$\int v\,\mathrm{d}p = \Delta p/\rho$（[[thermodynamics/first-law-open]]）。乘以$\dot m$得理想功率；实际功率大$1/\eta_p$倍，计入水力、泄漏和机械损失。假设：不可压液体（对远离临界点的低温推进剂足够准确），绝热泵，泵进出口之间速度和高度的变化可忽略。
:::

::: example 大型助推发动机的涡轮泵功率 {#ex-turbopump}
某助推发动机以$1800\ \mathrm{kg/s}$燃烧液氧（$\rho = 1140\ \mathrm{kg/m^3}$），以$700\ \mathrm{kg/s}$燃烧煤油（$\rho = 810\ \mathrm{kg/m^3}$）。泵分别把压力提高$15\ \mathrm{MPa}$和$18\ \mathrm{MPa}$（燃料还要流经冷却套，所以其升压更高），效率均为$0.70$。求泵功率。与贮箱增压作比较。
::: solution
由[[#eq-pump-power]]：
$$
P_{\text{氧}} = \frac{1800 \times 15\times10^{6}}{1140 \times 0.70} = 33.8\ \mathrm{MW},\qquad
P_{\text{燃}} = \frac{700 \times 18\times10^{6}}{810 \times 0.70} = 22.2\ \mathrm{MW},
$$
共$56\ \mathrm{MW}$——与大型船用燃气轮机的轴功率相当，却由一台装得进一两米范围的机器提供。
**校核。** 作为比较，[[#eq-tank-mass]]表明，把同样的推进剂贮存在比如$17\ \mathrm{MPa}$下，每立方米需要质量为$\tfrac32 \times 17\times10^{6} \times \rho_m/\sigma$的贮箱——对铝合金（$\rho_m = 2800\ \mathrm{kg/m^3}$，$\sigma = 250\ \mathrm{MPa}$）约为每$\mathrm{m^3}$ $286\ \mathrm{kg}$，是贮箱所装煤油质量的三分之一。几吨的涡轮泵取代了数百吨的贮箱壁。然而泵功率必须有来源——这就是发动机循环。
:::
:::

### 发动机循环

驱动泵的涡轮需要高温高压燃气，**发动机循环**描述这股燃气从哪里来、到哪里去。

- **燃气发生器（开式）循环。** 一小部分推进剂（百分之几）在单独的燃气发生器中燃烧，所选混合比使燃气足够凉以保护涡轮叶片；燃气驱动涡轮后通过单独的低性能排气管排出箭外。简单且久经验证；排掉的流量使发动机总比冲降低百分之几，并限制了实用的燃烧室压力。
- **补燃（闭式）循环。** 预燃室燃烧全部一种推进剂和少量另一种推进剂；仍处于高压的涡轮排气随后喷入主燃烧室，因此没有推进剂被浪费。这允许高燃烧室压力和最高的比冲，代价是极高的泵出口压力、要求苛刻的高温燃气管道和更大的复杂性。**全流量**补燃循环使用两个预燃室，一个富燃、一个富氧，使两种推进剂都流经涡轮。
- **膨胀循环。** 燃料（氢或甲烷）在燃烧室和喷管的冷却套中被加热，经涡轮膨胀后喷入燃烧室。燃烧室上游没有燃烧，使该循环温和且可多次起动，但冷却套吸收的热量限制了涡轮功率，从而限制了燃烧室压力和发动机尺寸；它适合上面级。
- **电动泵**发动机用电池供电的电动机驱动泵；对电池质量可以接受的小型运载火箭是实用的。

### 混合比、冷却与燃烧稳定性

比冲达到峰值时的**混合比**$O/F = \dot m_{\text{ox}}/\dot m_{\text{fuel}}$通常位于化学恰当比的**富燃**一侧。原因可从$c^* = \sqrt{R_uT_c/\mathcal{M}}\big/\Gamma$看出：偏向富燃使火焰温度略有降低，但使产物平均摩尔质量降低得更多——对氢尤其显著，其未燃烧的过量部分是非常轻的工质。氢氧发动机通常在$O/F \approx 5$–$6$下工作，而化学恰当值为 8。

$3000$–$3600\ \mathrm{K}$的燃烧室燃气温度超过任何实用壁面材料的熔点，热流密度在喉部附近最大，那里燃气密度和速度最高。大型发动机采用**再生冷却**：一种推进剂在喷入之前流经燃烧室和喷管壁中的通道，把热量带回循环。辅助的**液膜冷却**沿壁面喷入一层燃料；**烧蚀**内衬炭化和侵蚀，把热量带走（简单，用于固体火箭发动机和一些小型发动机）；难熔金属或陶瓷复合材料的**辐射冷却**喷管延伸段发光并向太空辐射热量。传热系数由适用于火箭条件的 Dittus–Boelter 型经验关联式估算（Bartz 关联式是经典的一个），然后由试验确认。

另一个设计问题是**燃烧不稳定**：燃烧与燃烧室声学模态之间的耦合可能产生足以在几分之一秒内摧毁发动机的压力振荡。喷注器设计、隔板和声腔用于抑制它；历史上大型发动机的研制在这一问题上花费了大量精力。

## 固体火箭发动机

固体火箭发动机是最简单的火箭：一个壳体（压力容器）、粘结在壳体上的推进剂药柱、一个点火器和一个喷管。其推力历程在制造时就由药柱形状决定，因为推进剂在其暴露的表面上燃烧，燃烧面积$A_b$随表面退移而变化。

::: definition 燃速与燃烧表面 {#def-burn-rate}
推进剂表面以**燃速**$r$（m/s）沿其法向退移。在适中的压力范围内，测得的燃速遵循经验的**燃速定律**（圣罗贝尔定律或维埃耶定律）
$$
r = a\,p_c^{\,n},
$$ {#eq-burn-rate}
其中$a$取决于推进剂及其初温，**压力指数**$n$对实用推进剂通常为$0.2$–$0.6$（Sutton 和 Biblarz）。燃气生成率为$\dot m_g = \rho_p A_b r$，$\rho_p$为推进剂密度。$A_b$随时间增大的药柱给出**增面**推力曲线，$A_b$减小的给出**减面**曲线，$A_b$几乎恒定的给出**恒面**曲线。
:::

::: proposition 平衡燃烧室压力及其稳定性 {#prop-solid-pc}
在固体火箭发动机中，燃烧室压力稳定在燃烧生成的燃气等于通过壅塞喉部排出的燃气之处：
$$
\rho_p A_b\,a\,p_c^{\,n} = \frac{p_c A_t}{c^*}
\qquad\Longrightarrow\qquad
p_c = \left(a\,\rho_p\,c^*\,\frac{A_b}{A_t}\right)^{1/(1-n)} .
$$ {#eq-solid-pc}
这一平衡只有在$n < 1$时才稳定，而面积比$K = A_b/A_t$的相对变化会产生$(1/(1-n))$倍的压力相对变化：
$$
\frac{\mathrm{d}p_c}{p_c} = \frac{1}{1-n}\,\frac{\mathrm{d}K}{K} .
$$
:::

::: proof
**平衡。** 燃气生成$\dot m_g = \rho_pA_b\,a p_c^n$；喷管排出$\dot m_n = p_cA_t/c^*$（$c^*$的定义，[[propulsion/rocket-fundamentals]]）。在准定常状态下两者相等（忽略在增大的燃烧室容积中贮存的燃气质量的小变化率）；除以$A_t$并求解即得[[#eq-solid-pc]]。
**稳定性。** 设压力受扰动略高于平衡值。生成量按$p_c^n$增长，排出量按$p_c^1$增长。若$n < 1$，排出量比生成量增长得快，离开的燃气多于产生的，压力回落：平衡是稳定的。若$n > 1$，生成量超过排出量，压力持续上升直到壳体破坏（或者，若扰动向下，压力下降直到发动机熄火）。形式上，燃烧室燃气质量$M$服从$\mathrm{d}M/\mathrm{d}t = \dot m_g - \dot m_n$，在平衡点$\partial(\dot m_g - \dot m_n)/\partial p_c = (n - 1)\dot m_n/p_c$，恰好在$n < 1$时为负。
**敏感性。** 对[[#eq-solid-pc]]取对数，$\ln p_c = \frac{1}{1-n}(\ln K + \text{常数})$，求微分即得结果。假设：准定常工作，燃速由[[#eq-burn-rate]]给出（无沿表面高速燃气造成的侵蚀燃烧），$c^*$恒定，喷管壅塞。
:::

::: example 固体火箭发动机的燃烧室压力 {#ex-solid}
某发动机燃烧面积$A_b = 5.0\ \mathrm{m^2}$，喉部面积$A_t = 0.025\ \mathrm{m^2}$。其推进剂密度为$1750\ \mathrm{kg/m^3}$，$c^* = 1550\ \mathrm{m/s}$，在$1\ \mathrm{MPa}$下燃速为$5.0\ \mathrm{mm/s}$，$n = 0.35$（于是$r = 5.0\ \mathrm{mm/s}\times(p_c/1\ \mathrm{MPa})^{0.35}$）。求平衡燃烧室压力、燃速、质量流量，以及燃烧面积增加$10\,\%$所引起的压力升高。
::: solution
$K = A_b/A_t = 200$。把$a\,p_c^n$写成$5.0\times10^{-3}\,(p_c/10^{6})^{0.35}$（$p_c$以帕计），[[#eq-solid-pc]]给出
$$
p_c^{\,0.65} = 1750 \times 1550 \times 200 \times 5.0\times10^{-3} \times (10^{6})^{-0.35}
\quad\Longrightarrow\quad
p_c = 4.64\ \mathrm{MPa}.
$$
于是$r = 5.0 \times 4.64^{0.35} = 8.56\ \mathrm{mm/s}$，$\dot m = \rho_pA_br = 1750 \times 5.0 \times 8.56\times10^{-3} = 74.9\ \mathrm{kg/s}$。
$A_b$增大$10\,\%$使压力乘以因子$1.1^{1/0.65} = 1.158$，即升高$15.8\,\%$。

**校核。** 喉部排出量$p_cA_t/c^* = 4.64\times10^{6} \times 0.025/1550 = 74.9\ \mathrm{kg/s}$一致。放大因子$1/(1-n) = 1.54$说明了为什么药柱裂纹或脱粘——它们暴露出额外的燃烧面积——是危险的，以及为什么优先选用压力指数低的推进剂；若$n = 0.7$，同样的 10 % 会使压力升高 37 %。
:::
:::

固体火箭发动机具有高密度、长期贮存、随时可用以及由简单装置产生大推力的优点，这就是它们被用作运载火箭的捆绑助推器和航天器的末级（踢级）的原因。它们的缺点由上述命题得出：点燃后推力不能调节，（一般）也不能关机；性能通过$a$随药柱温度变化；比冲低于最好的液体组合。

**混合火箭**把液态或气态氧化剂通过固体燃料药柱中的通道喷入。燃料退移速率主要取决于通过通道的氧化剂质量通量，而不是压力，所以混合火箭没有固体那种压力失控机制，可以通过氧化剂阀门调节推力和关机。其弱点是退移速率低（需要长药柱或多通道药柱）、混合比随通道扩大而漂移，以及混合不完全；它们在探空火箭和亚轨道飞行器中找到了用武之地。

::: warning 比冲不是比较的全部
仅凭$I_{sp}$比较发动机是一个经典错误。氢发动机约$450\ \mathrm{s}$的$I_{sp}$胜过煤油的$\sim 340\ \mathrm{s}$，但液氢的密度约为$71\ \mathrm{kg/m^3}$，而煤油为$810$：氢级需要大得多、带绝热的贮箱，这提高了其结构系数和阻力。对推力和贮箱容积最为重要的第一级，密度大的推进剂往往给出更轻、更便宜的飞行器；对每千克$\Delta v$就是一切的上面级，氢胜出。公平的比较是用火箭方程、采用各方案的$I_{sp}$、$\varepsilon$和推重比算出的整个飞行器的**有效载荷**。
:::

## 电推进

在电推力器中，赋予排气的能量来自电源，而不是来自推进剂。这完全改变了权衡。

::: proposition 功率受限的推力 {#prop-power-thrust}
以效率$\eta$（**推力效率**）把电功率$P$转换为射流动能功率的推力器，在排气速度$c$下产生
$$
F = \frac{2\eta P}{c} = \frac{2\eta P}{g_0 I_{sp}},\qquad \dot m = \frac{2\eta P}{c^2} .
$$ {#eq-power-thrust}
在功率固定时，推力与比冲成反比。
:::

::: proof
射流携带动能功率$\tfrac12\dot m c^2 = \eta P$，推力为$F = \dot m c$。消去$\dot m$：$F = 2\eta P/c$。假设：排气以速度$c$均匀（束流发散和离子速度的分散计入$\eta$），无压力推力（对这些装置在真空中成立）。
:::

当$\eta P$为几千瓦、$c$为每秒几十千米时，[[#eq-power-thrust]]给出的推力至多为零点几牛：电推力器需要几周或几个月才能提供化学发动机几分钟就能给出的$\Delta v$。它的回报来自火箭方程：在$c = 30\ \mathrm{km/s}$时，$5\ \mathrm{km/s}$的$\Delta v$只消耗初始质量的$15\,\%$作为推进剂。

::: proposition 静电推力器的排气速度 {#prop-ion-velocity}
质量为$m_i$、电荷为$q$的离子从静止开始经过电势差$V_b$加速，离开时的速度为
$$
v = \sqrt{\frac{2qV_b}{m_i}} .
$$ {#eq-ion-velocity}
:::

::: proof
能量守恒：电场所做的功$qV_b$变为动能$\tfrac12 m_iv^2$。假设：加速区内无碰撞，非相对论速度（成立：$v/c_{\text{光}} \sim 10^{-4}$），离子在完整束电势处由静止产生。
:::

**栅极离子推力器**在放电室中电离推进剂（通常为氙，因其原子质量大、电离能低、易于贮存），并通过一对间距很小的栅极加速离子；单独的**中和器**阴极向束流发射电子，使航天器不致带电。其比冲高（$3000$–$4000\ \mathrm{s}$或更高），效率好（$0.6$–$0.7$），但推力密度受栅极间电流的空间电荷极限限制。**霍尔效应推力器**在径向磁场两侧建立的电场中加速离子，该磁场把电子束缚在方位角漂移中；没有栅极，推力密度更高，典型比冲为$1500$–$2500\ \mathrm{s}$，效率约$0.5$–$0.6$。霍尔推力器目前在商业通信卫星的轨道提升和位置保持中占主导地位，并推进着大型近地轨道星座（截至2026年）。**电热式**装置（电阻加热推力器、电弧加热推力器）加热气体并在喷管中膨胀；它们较简单，但受材料温度和气体摩尔质量限制，$I_{sp}$只有几百到约$1000\ \mathrm{s}$。

::: example 深空中的离子推力器 {#ex-ion}
一台栅极氙离子推力器以$2.3\ \mathrm{kW}$输入功率工作，$I_{sp} = 3100\ \mathrm{s}$，推力效率$0.60$。（这些数值接近深空1号上飞行的 NASA NSTAR 推力器公开的全功率数据。）求推力和氙流量。将排气速度与束电压$1100\ \mathrm{V}$时[[#eq-ion-velocity]]给出的值比较（$m_{\mathrm{Xe}} = 131.29\ \mathrm{u}$）。该推力器要给一个$1000\ \mathrm{kg}$的航天器提供$\Delta v = 2\ \mathrm{km/s}$需要多长时间？
::: solution
$c = 3100 \times 9.80665 = 30.4\ \mathrm{km/s}$，所以由[[#eq-power-thrust]]
$$
F = \frac{2 \times 0.60 \times 2300}{30\,400} = 0.0908\ \mathrm{N} = 91\ \mathrm{mN},\qquad
\dot m = \frac{F}{c} = 2.99\ \mathrm{mg/s}.
$$
束流速度：$v = \sqrt{2 \times 1.602\times10^{-19} \times 1100/(131.29 \times 1.6605\times10^{-27})} = 40.2\ \mathrm{km/s}$，相当于$4100\ \mathrm{s}$。与有效的$3100\ \mathrm{s}$之间的差别，来自未电离就逸出的中性推进剂（工质利用率小于 1）、二价离子和束流发散。
$2\ \mathrm{km/s}$所需推进剂：$m_p = 1000(1 - e^{-2000/30\,400}) = 63.7\ \mathrm{kg}$；以$2.99\ \mathrm{mg/s}$计，需要连续推进$2.13\times10^{7}\ \mathrm{s} = 247$天。

**校核。** 化学双组元系统（$I_{sp} = 320\ \mathrm{s}$）为同样的$\Delta v$需要$1000(1 - e^{-2000/3138}) = 471\ \mathrm{kg}$推进剂——多七倍——但只需几分钟就能完成。$91\ \mathrm{mN}$的推力大约相当于地球上几张纸的重量。
:::
:::

排气速度应该多高？更高的$c$节省推进剂，但由[[#eq-power-thrust]]，相同推力需要更多功率，而电源（太阳电池阵、功率处理单元）有质量。若电源的比质量为$\alpha$（每瓦输入功率的千克数），任务要求在时间$t$内提供推力$F$，则推进剂质量为$Ft/c$，电源质量为$\alpha P = \alpha Fc/(2\eta)$。两者之和
$$
m_p + m_{pp} = \frac{Ft}{c} + \frac{\alpha F c}{2\eta}
$$
在
$$
c_{\text{opt}} = \sqrt{\frac{2\eta t}{\alpha}} ,
$$ {#eq-c-opt}
处最小（令对$c$的导数为零），此时两种质量相等。对$\alpha = 20\ \mathrm{kg/kW}$、$\eta = 0.6$、$t = 200$天，$c_{\text{opt}} = 32\ \mathrm{km/s}$（$I_{sp} \approx 3300\ \mathrm{s}$）——离子推力器的工作范围。较短的任务，例如在几周内完成轨道提升，偏好较低的$c$和霍尔推力器更大的推力。这一简单论证由恩斯特·斯图林格（Ernst Stuhlinger）在 20 世纪 60 年代加以完善，是选择电推进工作点的基础。

::: quiz
两台推力器以相同的效率使用相同的$5\ \mathrm{kW}$功率。推力器 A 的$I_{sp} = 1500\ \mathrm{s}$，推力器 B 为$3000\ \mathrm{s}$。下列哪些说法正确？（可能有多个正确选项。）
- [x] A 的推力是 B 的两倍。
- [x] B 的推进剂质量流量是 A 的四分之一。
- [ ] B 给航天器提供给定$\Delta v$所需的时间是 A 的一半。
- [x] 对$\Delta v$比两者的排气速度都小的任务，B 所需推进剂约为 A 的一半。
::: solution
$c$加倍时$F = 2\eta P/c$减半；$\dot m = 2\eta P/c^2$变为四分之一。提供$\Delta v$大约需要时间$m\Delta v/F$，所以 B 所需时间约为**两倍**。小$\Delta v$时推进剂质量约为$m\Delta v/c$，所以 B 需要一半。
:::
:::

## 发动机类型比较

| 类别 | 典型$I_{sp}$（s） | 推力范围 | 典型用途 |
|---|---|---|---|
| 液体双组元（低温，氢） | 360（海平面）– 465（真空） | kN 至 MN | 上面级、芯级 |
| 液体双组元（煤油、甲烷） | 280–310（海平面），310–380（真空） | kN 至 MN | 第一级、可重复使用助推器 |
| 可贮存双组元 | 290–330（真空） | N 至数百 kN | 航天器、轨道机动 |
| 单组元（肼） | 220–235 | 0.1 N 至 kN | 姿态控制、小型航天器 |
| 固体火箭发动机 | 240–300 | kN 至 MN | 捆绑助推器、末级（踢级） |
| 混合火箭 | 250–320 | N 至数百 kN | 探空和亚轨道飞行器 |
| 霍尔效应推力器 | 1500–2500 | mN 至 N | 轨道提升、位置保持、星座 |
| 栅极离子推力器 | 2500–4500 | mN | 深空任务 |

*代表性范围取自公开的发动机数据和 Sutton 与 Biblarz，截至2026年；具体发动机各有不同。*

这张表显示了根本的分野。离开地面需要大于 1 的推重比——$g$量级的加速度——只有化学发动机能提供。一旦进入太空，如果任务时间长，$10^{-5}g$的加速度也可以接受，电推进节省推进剂的优势就是决定性的。

::: history
今天使用的发动机循环是在 20 世纪 60 和 70 年代的航天计划中确立的：燃气发生器循环用于大型发动机，如推动土星五号第一级的 F-1（1967年首飞）；膨胀循环用于氢氧发动机 RL10，1963年首次在半人马座上面级上飞行；补燃循环用于 20 世纪 60 年代的苏联发动机和1981年首飞的航天飞机主发动机。大型分段式固体助推器在大力神 III 和航天飞机上飞行。电推进在 20 世纪初由罗伯特·戈达德（Robert Goddard）和康斯坦丁·齐奥尔科夫斯基（Konstantin Tsiolkovsky）提出；NASA 的 SERT 1 于1964年在太空中试验了离子推力器，苏联卫星从1971年起携带霍尔效应推力器，NASA 的深空1号（1998年发射）是第一个以离子发动机作为主推进的任务，随后是黎明号（2007年发射），它先后环绕灶神星和谷神星运行。
:::

::: summary
- 化学火箭是能量受限的（推力大，排气速度最高约$4.5\ \mathrm{km/s}$）；电推力器是功率受限的（排气速度$15$–$45\ \mathrm{km/s}$，推力为毫牛到牛）。
- 挤压式液体系统简单，但贮箱质量$\tfrac32 pV\rho_m/\sigma$把它们限制在低燃烧室压力；泵压式发动机需要涡轮泵功率$\dot m\Delta p/(\rho\eta)$，由燃气发生器、补燃或膨胀循环提供。
- 由于摩尔质量较低，最佳$I_{sp}$通常在富燃一侧；再生冷却、液膜冷却、烧蚀冷却和辐射冷却保护壁面。
- 固体火箭发动机燃烧室压力$p_c = (a\rho_pc^*A_b/A_t)^{1/(1-n)}$只在$n < 1$时稳定，并把燃烧面积的变化放大$1/(1-n)$倍；混合火箭避免了压力失控机制，并可调节推力。
- 电推力$F = 2\eta P/c$；离子排气速度$\sqrt{2qV_b/m_i}$；任务最优排气速度使推进剂与电源质量平衡，$c_{\text{opt}} = \sqrt{2\eta t/\alpha}$。
- 用飞行器有效载荷比较推进方案，而不是只看$I_{sp}$。
:::

用[[#eq-tank-mass]]求一个$1.0\ \mathrm{m^3}$、$2.0\ \mathrm{MPa}$的球形贮箱的壁质量，材料为$\rho_m = 2800\ \mathrm{kg/m^3}$、许用应力$250\ \mathrm{MPa}$的铝合金。（以 kg 为单位输入质量，保留三位有效数字。）

$m = 1.5 \times 2.0\times10^{6} \times 1.0 \times 2800/2.5\times10^{8} = 33.6\ \mathrm{kg}$。

::: exercise {#exr-ion-speed level=1 check="47.0"}
求经$1500\ \mathrm{V}$加速的一价氙离子（$131.29\ \mathrm{u}$，$1\ \mathrm{u} = 1.6605\times10^{-27}\ \mathrm{kg}$）的排气速度。（以 km/s 为单位输入速度，保留三位有效数字。）
::: solution
$v = \sqrt{2 \times 1.602\times10^{-19} \times 1500/(2.180\times10^{-25})} = 4.70\times10^{4}\ \mathrm{m/s} = 47.0\ \mathrm{km/s}$。
:::

::: exercise {#exr-hall level=1 check="312"}
某霍尔推力器以$I_{sp} = 1800\ \mathrm{s}$、推力效率$0.55$使用$5.0\ \mathrm{kW}$。求其推力。（以 mN 为单位输入推力，保留三位有效数字。）
::: solution
$F = 2 \times 0.55 \times 5000/(1800 \times 9.80665) = 0.312\ \mathrm{N} = 312\ \mathrm{mN}$。
:::
:::

::: exercise {#exr-pump level=2 check="28.6"}
一台氢泵以$0.70$的效率输送$40\ \mathrm{kg/s}$液氢（$\rho = 70\ \mathrm{kg/m^3}$），升压$35\ \mathrm{MPa}$。把氢视为不可压，求轴功率，并与以相同质量流量、相同升压泵送液氧（$\rho = 1140\ \mathrm{kg/m^3}$）所需的功率比较。（以 MW 为单位输入氢泵功率，保留三位有效数字。）
::: solution
$P = \dot m\Delta p/(\rho\eta) = 40 \times 35\times10^{6}/(70 \times 0.70) = 28.6\ \mathrm{MW}$。对氧，$P = 40 \times 35\times10^{6}/(1140 \times 0.70) = 1.75\ \mathrm{MW}$——小十六倍，即密度之比。氢泵必须处理巨大的体积流量，需要多个高速级，这就是为什么氢涡轮泵是火箭技术中要求最苛刻的机器。（在这样的压力下氢的可压缩性不可忽略；不可压估算只是一阶近似。）
:::
::: answer
$28.6\ \mathrm{MW}$
:::
:::

::: exercise {#exr-solid-sens level=2 check="1.37"}
某固体推进剂的压力指数$n = 0.70$。如果裂纹使燃烧面积增加$10\,\%$，燃烧室压力升高到原来的多少倍？（输入保留三位有效数字的倍数。）
::: solution
由[[#prop-solid-pc]]，$p_c \propto K^{1/(1-n)} = K^{3.33}$，所以倍数为$1.1^{3.33} = 1.37$。若$n = 0.35$则为$1.16$。
:::
:::

::: exercise {#exr-copt level=2 check="32.2"}
对比质量为$20\ \mathrm{kg/kW}$的电源、推力效率$0.60$、推进时间$200$天，求最优排气速度[[#eq-c-opt]]。（以 km/s 为单位输入，保留三位有效数字。）
::: solution
$t = 1.728\times10^{7}\ \mathrm{s}$，$\alpha = 0.020\ \mathrm{kg/W}$：$c_{\text{opt}} = \sqrt{2 \times 0.60 \times 1.728\times10^{7}/0.020} = 3.22\times10^{4}\ \mathrm{m/s} = 32.2\ \mathrm{km/s}$。
:::
:::

::: exercise {#exr-ion-time level=3 check="247"}
证明：对推力$F$和排气速度$c$恒定的推力器，给初始质量为$m_0$的航天器提供$\Delta v$所需的时间为$t = (m_0c/F)\left(1 - e^{-\Delta v/c}\right)$，并核对[[#ex-ion]]中$247$天的结果。（以天为单位输入时间，取整数。）
::: solution
所用推进剂为$m_p = m_0(1 - e^{-\Delta v/c})$（火箭方程），以恒定速率$\dot m = F/c$消耗，所以$t = m_p c/F = (m_0c/F)(1 - e^{-\Delta v/c})$。取$m_0 = 1000\ \mathrm{kg}$，$c = 30\,400\ \mathrm{m/s}$，$F = 0.0908\ \mathrm{N}$，$\Delta v = 2000\ \mathrm{m/s}$：$t = 3.348\times10^{8} \times 0.0637 = 2.13\times10^{7}\ \mathrm{s} = 247$天。对小的$\Delta v/c$，公式化为$t \approx m_0\Delta v/F$，即等加速度飞行。
:::
:::

::: exercise {#exr-cycle-choice level=3}
**设计讨论。** 为以下情形选择发动机循环（燃气发生器、补燃、膨胀、电动泵）和供应系统：(a) 可重复使用中型运载火箭的第一级；(b) 必须多次起动的氢氧上面级；(c) 运送 300 kg 有效载荷的小型运载火箭的主发动机；(d) 地球静止轨道卫星的远地点发动机。从燃烧室压力、比冲、复杂性、再起动能力和可重复使用性方面论证每一个选择。
::: solution
(a) 采用密度大的推进剂（煤油或甲烷）的燃气发生器或补燃循环：燃气发生器较简单且久经验证，补燃给出更高的$I_{sp}$和燃烧室压力；甲烷燃烧干净，便于重复使用。(b) 膨胀循环：氢优异的冷却能力在上游没有燃烧装置的情况下驱动涡轮，给出可靠的再起动和高$I_{sp}$；有限的涡轮功率对上面级不大的推力是可以接受的。(c) 电动泵或燃气发生器循环：在小尺寸下电池是可以接受的，循环简单、便宜；只有采用轻质高压贮箱才可能挤压式供应。(d) 挤压式可贮存双组元：没有叶轮机械，可长期贮存，可多次起动，$I_{sp}$约$320\ \mathrm{s}$——或者，如果运营商接受数月的转移时间，越来越多地采用霍尔推力器全电推进轨道提升。很少有唯一正确的答案；重要的是推理过程。
:::
