设计要求表一经同意（[[design-process/requirements]]），团队就知道了产品必须实现*什么*，但还不知道*如何*实现。**概念**是对产品的工作原理、布置和形态的近似描述——一张附有几句话和几个数字的草图，足以说明它如何工作以及大致要花多少钱。概念生成是这样一个阶段：在[[design-process/concept-selection]]中再次收窄之前，把可能解的空间尽可能有益地打开。它的重要性与其所占的工作量不成比例：概念决定了产品的大部分性能极限和相当一部分成本，而一个糟糕的概念是无法靠出色的详细设计挽救的。

有两种倾向妨碍得到好的结果。第一种是**思维定势**（fixation）：见过某一种解决方案的设计者——竞争对手的产品、去年的型号、会上提出的第一个想法——很难再想出别的方案，他们后来的想法也与之相似。第二种是过早评价：想法在得到发展之前就受到批评，不合常规的想法早早夭折。本讲的方法同时应对这两种倾向。功能分解把问题拆成先入之见较少的小问题；外部检索（专利、文献、其他行业、自然界）引入团队原本不知道的解决方案；结构化的创造性方法把生成与评判分开；形态学矩阵系统地组合部分解；TRIZ 则利用从专利中抽象出来的规律，提示如何化解要求之间的矛盾。

## 按功能分解问题 {#sec-function}

第一步是抽象地陈述问题。“设计一台更好的易拉罐压扁机”会引出现有压扁机的种种变体；“为回收而减小空饮料罐的体积”则允许粉碎、滚压、折叠以及其他原理。帕尔（Pahl）与拜茨（Beitz）建议把问题抽象到其本质功能清晰可见为止，然后再分解这一功能。

::: definition 功能、流与功能结构 {#def-function}
**功能**是对系统输入与输出之间预期关系的、与解决方案无关的描述，写成一个动词加一个名词：*储存能量*、*把电能转换为转动*、*定位罐子*、*检测卡滞*。输入和输出是三类**流**：**物料**流（物体、流体、用户的手）、**能量**流（机械能、电能、热能、化学能、人力）和**信号**流（信息、指令、测量值）。**总功能**把产品当作一个黑箱，这些流穿过其边界。**功能结构**把总功能分解为由流连接起来的**分功能**，使每个分功能都简单到可以单独求解。
:::

分解不是唯一的；它是一种建模选择。有两条启发式规则有所帮助。第一，沿着每一种流穿过产品：罐子从进入到离开的那一刻发生了什么？来自电池或用户手臂的能量在对罐子做功之前经历了什么？第二，使分功能保持与解决方案无关：写*放大力*而不是*杠杆*，写*夹持罐子*而不是*夹爪*。功能结构并不说明功能由一个零件还是几个零件实现；那是在具体化设计阶段（[[design-process/embodiment-design]]）决定的。

::: example 易拉罐压扁机的功能结构 {#ex-function}
为一种在回收前把空铝制饮料罐压扁的家用装置画出黑箱和功能结构。
::: solution
*黑箱。* 输入：空罐（物料）、压扁所需的能量（人的肌肉力或电能——暂不确定）、用户的指令（信号）。输出：压扁的罐（物料）、以热和噪声形式耗散的能量、向用户提供的状态（信号：“就绪”“卡滞”“收集箱已满”）。
*功能结构*，沿物料流：**接收罐子** → **定位罐子**（在确定的位置和方向上） → **压扁罐子** → **释放罐子** → **收集压扁的罐子**。沿能量流：**输入能量** → **储存能量**（可选：弹簧或飞轮可以允许较小的输入功率） → **放大力** → **把力传递给罐子**，它向*压扁罐子*功能供能。沿信号流：**接收指令** → **检测罐子存在**和**检测卡滞** → **显示状态**；指令和检测信号控制*传递力*。
这样写出功能，就揭示了“易拉罐压扁机”这一说法所掩盖的选项：*压扁罐子*可以通过轴向挤压、在辊子之间把罐子滚平或剪切来实现；*储存能量*可以省去（直接驱动），也可以由用户分几次行程完成；*定位罐子*对安全至关重要，因为位置不对的罐子可能被猛烈弹出。检查：每一种输入流都作为输出出现（物料输入 = 物料输出；能量输入 = 对罐子做的功 + 损失），因此分解中没有遗漏任何东西。
:::
:::

## 寻找部分解 {#sec-search}

现在团队为每个分功能收集**工作原理**——能够实现它的物理效应和布置。来源分为两类。

**外部检索**找出已经存在的东西。它包括对竞争对手的产品进行对标（把它们拆开往往是最快的学习方式）、访谈已经自己凑合出解决方案的领先用户、查阅手册和供应商样本、检索具有相同功能的其他行业（易拉罐压扁机和废金属打包机共有*压缩物料*这一功能），以及检索专利文献。

::: definition 专利、权利要求与现有技术 {#def-patent}
**专利**是国家授予的一种在有限期限内的权利，用以排除他人制造、使用或销售一项发明——一种新颖的、非显而易见的（具有创造性的）、能在产业上应用的技术方案——作为公开该发明的交换。根据 TRIPS 协定，最短保护期为自申请日起 20 年。**权利要求**界定保护的法律范围；说明书和附图对发明进行解释。**现有技术**是申请日之前在世界任何地方已为公众所知的一切。
:::

专利之所以是异常丰富的概念来源，有三个原因：它们按技术功能分类（国际专利分类和联合专利分类），因此比如压扁罐子的所有方法都能集中找到；它们必须说明发明如何工作；而且大多数专利已经过期，或者在所关心的国家从未生效，因此其思想可以自由使用。在项目早期进行检索，还能发现约束设计的有效专利——其法律方面在[[design-process/ethics-standards]]中讨论。阅读权利要求而不是标题是至关重要的：标题描述的是主题，但只有落入权利要求范围的东西才受保护。

**内部检索**利用团队自身的知识，并用[[#sec-creativity]]中的方法有意识地加以激发。两类检索都得益于**类比**——追问其他系统，无论天然的还是人造的，如何实现同一功能。生物学是常见的来源：乔治·德·梅斯特拉尔（Georges de Mestral）的钩毛搭扣在20世纪50年代以 Velcro（维可牢）的名义获得专利，它源于他在1941年一次打猎之后对粘在他衣服和狗身上的牛蒡带钩刺果的观察；20世纪90年代后期 500 系新干线列车那细长渐缩的车头受到翠鸟喙的启发——翠鸟入水时几乎不溅起水花——采用它是为了减小列车高速进入隧道时的压力波和“隧道微气压波”（tunnel boom）。在这两个例子中，类比提供的是原理；把它变成产品则花了多年的工程工作。

## 创造性方法 {#sec-creativity}

生成想法的群体方法有一条共同规则：*先生成，后评判*。在生成过程中进行批评会压制不寻常的想法，并让自信的发言者占据主导。

**头脑风暴法**由广告公司经理亚历克斯·奥斯本（Alex Osborn）在《你的创造力》（*Your Creative Power*，1948年）和《应用想象力》（*Applied Imagination*，1953年）中推广，它要求一个小组尽可能多地提出想法，推迟评判，欢迎不寻常的想法，并对他人的想法加以组合和改进。它在群体中的效果是有争议的：自20世纪50年代后期以来的实验室研究一再发现，同样数量的人各自独立工作再汇总想法（“名义小组”），比相互交流的小组产生的想法更多，因为在小组中同一时间只能有一个人发言，而且人们会保留担心受到评判的想法。

**书面头脑风暴法**（brainwriting）通过在纸上工作来消除这些问题。在伯恩德·罗尔巴赫（Bernd Rohrbach）于1969年发表的 **6-3-5 法**中，六名参与者每人在五分钟内在一张纸上写下三个想法，然后把纸传下去；每人再对收到的想法加以扩展或变化，直到每张纸都经过了每一个人。六轮共产生多达$6\times3\times6 = 108$个想法，用时三十分钟，并且全部记录在案。**画廊法**则让个人画草图，把草图钉在墙上，讨论之后再画。

其他有助于个人打破思维定势的提示包括：变换检查表（替代、组合、改造、修改、移作他用、去除、颠倒），有意考虑与显而易见的解决方案相反的做法，以及改变尺度或介质。

::: example 多少个想法才够？ {#ex-coverage}
作为一个粗略的模型，设每个独立生成的想法有一个小概率$p$成为值得发展的“好”概念。若$p = 0.02$，需要多少个想法$N$才有$90\,\%$的可能至少得到一个好想法？30 个想法又有多大可能？
::: solution
$N$个独立想法中没有一个好想法的概率为$(1 - p)^N$，因此
$$
P(\text{至少一个好想法}) = 1 - (1 - p)^N .
$$ {#eq-coverage}
令其等于$0.90$：$N \ge \ln 0.10/\ln 0.98 = -2.3026/(-0.020203) = 113.97$，所以需要$N = 114$个想法。$N = 30$时：$1 - 0.98^{30} = 1 - 0.5455 = 0.455$，即不到一半的可能。
这个模型过于简单——想法并不独立（思维定势使后来的想法与先前的相似），“好”也不是一种固定的属性——但它说明了为什么设计方法要求大量想法，以及为什么一次在半小时内产生约 100 个想法的结构化会议，比一次对第一个看似合理的想法达成一致的会议更有价值。合理性检查：$p$很小时，$(1 - p)^N \approx e^{-pN}$，且$e^{-0.02\times114} = e^{-2.28} = 0.10$ ✓。
:::
:::

::: widget plot
f: 1 - (1 - p)^x
x: 0, 200
y: 0, 1
sliders: p=0.02:0.005:0.1:0.005
labels: P(\text{至少一个好概念})
hlines: 0.9

caption: [[#ex-coverage]]中的粗略覆盖模型：当每个想法是好想法的概率为$p$（滑块）时，$N$个独立想法（横轴）中至少有一个好想法的概率。标出的点是$p = 0.02$时的$N = 114$。把$p$减半，达到$90\,\%$覆盖所需的想法数大致加倍；把$p$提高到$0.1$——一个已被充分理解的问题，或一个有相关经验的团队——约 22 个想法就够了。一旦曲线变平，收益就开始递减，这是停止生成、开始选择的一个理由。
:::

::: warning 只数想法而不探索空间
一份由某一原理的细微变体构成的 100 个想法的清单，对解空间的探索还不如基于十种不同原理的十个想法。数量只有在带来多样性时才有帮助。检查一份想法清单的办法是按工作原理对它们分组（对易拉罐压扁机：轴向挤压、滚压、折叠、粉碎、熔化）：如果几乎全部落在一组中，说明这次会议受到了思维定势的影响，应当从另一个分功能、另一个类比或一次专利检索出发，开始新的一轮。
:::

## 形态学矩阵 {#sec-morphology}

功能结构把问题分开；检索为每个分功能填入备选的部分解。**形态学矩阵**（morphological chart，或称形态学箱）由天体物理学家弗里茨·兹威基（Fritz Zwicky）于20世纪40年代在加州理工学院提出，并在他的著作《形态学世界观中的发现、发明与研究》（*Entdecken, Erfinden, Forschen im morphologischen Weltbild*，1966年；英文版1969年）中加以阐述，它把这些部分解列成表格。

::: definition 形态学矩阵 {#def-morph}
**形态学矩阵**为每个分功能（或设计参数）$k = 1,\dots,K$设一行，该行列出为它找到的$n_k$个备选部分解。从每一行中选取一项就构成一个**概念变型**。不同行中的两项如果在物理上或几何上不能协同工作，就称为**不相容的**。
:::

::: proposition 形态学空间的大小 {#prop-morph}
(a) 第$k$行有$n_k$个选项的矩阵定义了
$$
N = \prod_{k=1}^{K} n_k
$$ {#eq-morph}
个概念变型。
(b) 若$F_1,\dots,F_q$是分别包含禁止组合对$1,\dots,q$的变型集合，则相容变型的个数为
$$
N_{\text{ok}} = N - \sum_i \lvert F_i\rvert + \sum_{i<j}\lvert F_i\cap F_j\rvert - \sum_{i<j<l}\lvert F_i\cap F_j\cap F_l\rvert + \cdots
$$ {#eq-incl-excl}
其中，固定了第$a$行和第$b$行中选项的禁止组合对给出$\lvert F_i\rvert = N/(n_a n_b)$；若一个交集要求同一行中有两个不同的选项，则它为空，否则它等于它所留下的自由各行的$n_k$之积。
:::

::: proof
(a) 在每一行中独立地选取一项，是一个由$K$次选择构成的序列，每次分别有$n_1, n_2,\dots$种可能；由计数的乘法原理，共有$n_1n_2\cdots n_K$个序列。(b) 不相容的变型是并集$F_1\cup\cdots\cup F_q$，其大小由容斥原理给出；从$N$中减去它即得[[#eq-incl-excl]]。$F_i$中的变型在组合对$i$所涉及的两行中选项固定，其他各行自由，因此有$\prod_{k\ne a,b} n_k = N/(n_an_b)$个。交集中的变型必须包含所涉及各集合的全部固定选项；如果其中两个在同一行中规定了不同的选项，这就不可能，否则该变型在其余各行中是自由的。
:::

乘积增长得极快。七行、每行四个选项就已经给出$4^7 = 16\,384$个变型——即使其中大多数是荒谬的，也多到无法逐一评价。因此矩阵有以下三种用法：(i) 凭判断挑出少数几个有前途且相互相容的组合，通常每个“主题”一个（一个低成本的手动概念、一个高产量的电动概念……）；(ii) 先用[[design-process/concept-selection]]中的筛选方法逐行剔除弱的选项，从而减小每个$n_k$；(iii) 对定义明确的问题，用计算机按相容性规则枚举。它的主要价值不在于计数，而在于纪律：每一行都得到考虑，不寻常的组合也变得清晰可见。

::: example 易拉罐压扁机变型的计数 {#ex-morph}
一个团队为易拉罐压扁机建立的形态学矩阵有以下各行：
- A 能源：手动杠杆、脚踏板、电动机、气缸（$n_A = 4$）；
- B 力的放大：杠杆、肘杆机构、螺旋传动、液压缸（$n_B = 4$）；
- C 压扁动作：直线压板、一对辊子、回转凸轮（$n_C = 3$）；
- D 送料：手工逐个送入、重力料仓（$n_D = 2$）；
- E 卸料：重力落下、弹簧推出器、由压板推出（$n_E = 3$）。
辊子需要连续转动，因此与肘杆机构和螺旋传动（两者都只给出有限行程）不相容。由压板推出要求采用直线压板。共有多少个变型，其中多少个是相容的？如果粗略评价一个变型需要 15 分钟，评价全部相容变型需要多长时间？
::: solution
由[[#eq-morph]]，$N = 4\times4\times3\times2\times3 = 288$。
禁止集合：$F_1$ = {肘杆，辊子}：A、D、E 行自由，$\lvert F_1\rvert = 4\times2\times3 = 24$。$F_2$ = {螺旋，辊子}：$24$。“推出需要压板”禁止了 {辊子，推出}（$F_3$）和 {凸轮，推出}（$F_4$）：A、B、D 行自由，$\lvert F_3\rvert = \lvert F_4\rvert = 4\times4\times2 = 32$。
交集：$F_1\cap F_2$需要 B 行有两个选项——为空。$F_3\cap F_4$需要 C 行有两个选项——为空；$F_1\cap F_4$和$F_2\cap F_4$同样为空。$F_1\cap F_3$ = {肘杆，辊子，推出}：A、D 行自由，$4\times2 = 8$；$F_2\cap F_3$：$8$。没有非空的三重交集。
$N_{\text{ok}} = 288 - (24 + 24 + 32 + 32) + (8 + 8) = 288 - 112 + 16 = 192$。
以每个 15 min 评价 192 个变型需要$48\,\mathrm h$——超过一个工作周。用一个小程序枚举全部 288 种组合加以核对：有 192 种同时满足两条规则。结论是通常的那个：先在每一行内筛选选项（在厨房里用气缸说得过去吗？），然后组装大约五到十个协调一致的变型进行评价。
:::
:::

## TRIZ：化解矛盾 {#sec-triz}

许多设计问题之所以困难，是因为两项要求朝相反的方向拉扯：自行车车架应当更刚硬*而且*更轻；压力容器的壁为了强度应当更厚，*而*为了传热又应当更薄。常规做法是折中。TRIZ（俄文“发明问题解决理论”的缩写）由根里奇·阿奇舒勒（Genrich Altshuller）自20世纪40年代起发展，并于1956年与拉斐尔·夏皮罗（Rafael Shapiro）首次发表；它建立在研究大量专利所得出的一项观察之上：发明性的解决方案通常是*消除*这样的矛盾而不是折中，而且同样的少数几种策略在互不相关的领域中反复出现。

::: definition 技术矛盾与物理矛盾 {#def-contradiction}
当改善系统的一个参数会使另一个参数恶化时（提高强度会增加重量），就存在**技术矛盾**。当一个元素必须同时具有相反的性质时（起落架在着陆时必须放下，而在巡航时又必须不在那里），就存在**物理矛盾**。TRIZ 用 39 个通用工程参数（例如*运动物体的重量*、*强度*、*温度*、*可制造性*）来表达技术矛盾，并提供 40 条**发明原理**（例如*分割*、*局部质量*、*反向作用*、*动态化*、*参数变化*、*复合材料*）作为通用策略；阿奇舒勒的**矛盾矩阵**针对每一对改善参数和恶化参数，给出在他所研究的专利中最常用的原理。物理矛盾通过**分离**来解决：时间分离、空间分离、整体与部分分离，或条件分离。
:::

最好把 TRIZ 看作一份有条理的提示清单。它能可靠地促使团队准确地陈述矛盾——这往往是最有价值的一步——并指向团队可能没有考虑过的解的类型。它并不保证得到解，抽象的原理仍然必须转化为可行的具体结构。

::: example 运用 TRIZ 提示 {#ex-triz}
(a) 一辆可供轮椅进出的小型客车需要一块坡道板，它既要长（为轮椅提供平缓的坡度），又要短（以便收纳在车内而不阻挡人行道）。陈述这一矛盾，并用分离原理提出概念。(b) 一个管状自行车车架必须更刚硬而又不变重。用 TRIZ 参数把它表述为技术矛盾，并以*局部质量*、*复合材料*和*分割*原理作为提示。
::: solution
(a) 这是关于一个元素（坡道板长度）的物理矛盾。*时间分离*：展开时长，收纳时短——折叠式或伸缩式坡道板，或从地板下抽出的坡道板。*空间分离*：一部分高度差靠降低车身（下蹲式悬架）来消化，从而坡道板本身可以短一些。*条件分离*：用升降平台完全取代坡道板。这三种方案在实际车辆上都存在。
(b) 改善*强度*（刚度在 39 个参数中最接近的是它）会使*运动物体的重量*恶化。*局部质量*提示只在需要的地方布置材料：变壁厚管（butted tube），在弯矩最大的接头附近较厚，中部较薄；在主载荷平面内更刚硬的椭圆形或锥形截面。*复合材料*提示采用碳纤维增强聚合物，其纤维可以沿载荷路径铺设。*分割*提示由许多短杆件组成的车架（空间桁架），或用接头套管连接标准管材。对照实践检查：所有这些都用于商品车架，这证实了这些提示确实通向真实的选项——而团队接下来还必须通过分析和成本对它们进行比较（[[design-process/concept-selection]]）。
:::
:::

::: quiz
一个形态学矩阵有五行，分别有 3、4、2、5 和 3 个选项，没有不相容的组合。从有 5 个选项的那一行中删去一个选项。变型数下降了多大比例？
- [ ] $1/360$
- [ ] $5\,\%$
- [x] $20\,\%$
- [ ] $25\,\%$
::: solution
$N = 3\times4\times2\times5\times3 = 360$；那一行有 4 个选项时$N = 288$，因此减少了$72$个变型，即$72/360 = 20\,\%$。一般地，从第$k$行的$n_k$个选项中删去一个，就去掉了空间的$1/n_k$，与其他各行的内容无关——这就是逐行筛选弱选项如此有效的原因。
:::
:::

::: remark 记录概念
每个被保留下来的概念都记录在一张**概念表**上：一张草图、对工作原理的简短描述、在矩阵每一行中所作的选择、粗略的关键数字（尺寸、质量、功率、成本）以及尚未解决的问题。统一格式的概念表使[[design-process/concept-selection]]中的比较公平：一个精心渲染的心仪方案摆在潦草的备选方案旁边，会使任何评审产生偏向。
:::

::: history
生成机械解决方案的系统化方法是由德国工程设计研究者在20世纪60年代和70年代发展起来的，并由格哈德·帕尔（Gerhard Pahl）与沃尔夫冈·拜茨（Wolfgang Beitz）在《设计学》（*Konstruktionslehre*，1977年）中加以综合，功能结构和设计目录的使用即源于此。以天体物理学研究著称的弗里茨·兹威基（Fritz Zwicky）在20世纪40年代从事喷气推进工作时发展了形态学分析，并于1966年完整发表。亚历克斯·奥斯本（Alex Osborn）在《你的创造力》（*Your Creative Power*，1948年）中提出头脑风暴法，并在《应用想象力》（*Applied Imagination*，1953年）中加以阐发；书面头脑风暴的 6-3-5 法由伯恩德·罗尔巴赫（Bernd Rohrbach）于1969年发表。根里奇·阿奇舒勒（Genrich Altshuller）从20世纪40年代开始研究专利，并于1956年与拉斐尔·夏皮罗（Rafael Shapiro）发表了第一篇关于 TRIZ 的论文；他的工作曾因自1950年起被关押在劳改营而中断，直到斯大林于1953年去世后才获释；TRIZ 主要从20世纪90年代起才在西方广为人知。
:::

::: summary
- 概念是对工作原理、布置和形态的近似描述；它决定了产品的大部分极限和成本。
- 先把问题抽象化，再把总功能分解为由物料流、能量流和信号流连接的分功能；使分功能保持与解决方案无关。
- 进行外部检索（竞争对手、领先用户、其他行业、样本、专利、自然界）和内部检索（创造性方法）。专利按功能分类，而且大多数可以自由使用；要阅读权利要求。
- 把生成与评判分开。6-3-5 之类的书面头脑风暴法（30 min 内$6\times3\times6 = 108$个想法）避免了口头头脑风暴的发言阻塞。大量想法只有在多样时才有帮助。
- 每行有$n_k$个选项的形态学矩阵张成$\prod n_k$个变型；不相容的组合用容斥原理剔除；在行内进行筛选可使空间保持可控。
- TRIZ：准确陈述技术矛盾或物理矛盾；以 40 条发明原理和分离原理为提示，去消除而不是折中矛盾。
:::

::: exercise 一次书面头脑风暴 {#exr-brainwriting level=1 check="75"}
书面头脑风暴的一种 5-3-5 变体有五名参与者，每人每轮写三个想法，每名参与者对应一轮（纸张传递到每张都经过了每一个人为止）。最多能产生多少个想法？（输入该数。）
::: solution
五轮，每轮$5\times3 = 15$个想法：共$75$个想法。

::: exercise 电热水壶的功能结构 {#exr-kettle level=1}
给出电热水壶的黑箱输入和输出（按物料、能量和信号分类），以及一个至少包含六个分功能的功能结构。
::: solution
输入：冷水（物料）、电能、用户的指令（开关）和水温（信号）。输出：热水（物料）、热损失和蒸汽（能量、物料）、状态（指示灯、咔嗒声）。分功能：*接收水* → *容纳水* → *把电能转换为热* → *把热传给水* → *检测温度（或沸腾）* → *切断能量* → *显示状态*；以及*倒出水*、*使用户与热表面隔离*、*防止干烧*（检测无水状态）。注意*检测沸腾*是与解决方案无关的：被蒸汽加热的双金属片是一种解，电子热敏电阻是另一种解。
:::
:::

::: exercise 含不相容组合的变型 {#exr-morph-pairs level=2 check="30"}
一个矩阵有 A 行（$a_1, a_2, a_3$）、B 行（$b_1, b_2, b_3$）和 C 行（$c_1,\dots,c_4$）。组合对$\{a_1, b_2\}$和$\{b_2, c_3\}$不相容。共有多少个相容变型？（输入该数。）
::: solution
$N = 3\times3\times4 = 36$。$\lvert F_1\rvert$（$a_1, b_2$固定，C 自由）$= 4$；$\lvert F_2\rvert$（$b_2, c_3$固定，A 自由）$= 3$；$F_1\cap F_2 = \{(a_1, b_2, c_3)\}$，大小为 1。$N_{\text{ok}} = 36 - 4 - 3 + 1 = 30$。直接核对：含$b_2$的变型只有在$a\ne a_1$且$c\ne c_3$时才相容，在 12 个含$b_2$的变型中有$2\times3 = 6$个；24 个不含$b_2$的变型全部相容；$24 + 6 = 30$ ✓。
:::
:::

::: exercise 达到 95 % 覆盖所需的想法数 {#exr-coverage level=2 check="59"}
用[[#ex-coverage]]中的粗略模型，取$p = 0.05$，多少个想法才能至少有$95\,\%$的可能得到至少一个好概念？（输入想法数的整数。）
::: solution
$N \ge \ln 0.05/\ln 0.95 = -2.9957/(-0.051293) = 58.40$，所以$N = 59$。
:::
:::

::: exercise 陈述矛盾 {#exr-triz level=2}
对下列每种情况，说明矛盾是技术矛盾还是物理矛盾，并提出一种可能化解它的分离方法或发明原理：(a) 雨伞应当大，以使用户不被淋湿，又应当小，以便携带；(b) 切削刀片应当硬以抗磨损，又应当韧以抗崩刃；(c) 汽车为了操控性应当有硬的悬架，为了舒适性又应当有软的悬架。
::: solution
(a) 物理矛盾（一个元素的尺寸）。时间分离：折叠伞或伸缩伞。(b) 技术矛盾（提高耐磨性会使韧性恶化），或者，若针对一个元素来表述，则为物理矛盾。*局部质量*/空间分离：韧性好的基体加上一层薄的硬涂层（涂层硬质合金刀片）。(c) 物理矛盾（一个元素的刚度）。条件分离或时间分离：阻尼随路面输入或驾驶模式而变化的自适应减振器；*动态化*（使某一特性可调）。在每种情况下，团队仍然必须对这一想法进行尺寸计算和成本估算。
:::
:::

::: exercise 含禁止行组合的计数 {#exr-derive-morph level=3 check="64"}
(a) 证明：若第$a$行的一个选项$x$与第$b$行中由$s$个选项组成的集合$S$里的*每一个*选项都不相容，则$N_{\text{ok}} = N\,(1 - s/(n_an_b))$。(b) 一个矩阵各行分别有 3、4 和 8 个选项；第一行的选项 1 与第二行中的 3 个选项不相容，第一行的选项 2 与第二行中的 1 个选项不相容。共有多少个相容变型？（输入该数。）
::: solution
(a) 对$y\in S$的禁止集合$F_{x,y}$要求第$b$行中的选项各不相同，因此它们两两不相交；每个集合的大小为$N/(n_an_b)$。容斥公式简化为$N_{\text{ok}} = N - sN/(n_an_b)$。
(b) $N = 3\times4\times8 = 96$，$N/(n_an_b) = 8$。禁止集合是组合对（1，三个选项）和（2，一个选项）：共四对，两两不相交（要么第 2 行的选项不同，要么第 1 行的选项不同）。$N_{\text{ok}} = 96 - 4\times8 = 64$。
:::
:::

::: exercise 爬楼手推车的概念 {#exr-design level=3}
针对需要与要求一讲（[[design-process/requirements]]）中的爬楼手推车——一名志愿者必须把$40\,\mathrm{kg}$的包裹搬上住宅楼梯——(a) 画出功能结构；(b) 建立一个至少五行、每行至少三个选项的形态学矩阵，并至少使用一个外部来源（对爬楼手推车的专利检索，或来自自然界或其他行业的类比）；(c) 组装三个各不相同且相容的概念，并为每个概念写一张概念表。
::: solution
一种可能的答案。(a) 流：包裹（物料），志愿者的肌肉力以及可能有的电池能量，志愿者的指令。分功能：*承载载荷*、*保持载荷水平*、*把载荷送上一级台阶*、*在台阶边缘支承载荷*、*防止下滑*（必备的安全功能）、*输入能量*、*放大力*、*在楼梯平台上转向*、*折叠以便运输*。
(b) 行的例子：*送上一级台阶*——旋转的三星轮组、履带、步行腿、动力升降柱；*能量*——把手处的肌肉力、经脚踏板的肌肉力、电池加电动机；*放大力*——杠杆比、齿轮系、滚珠丝杠；*防止下滑*——轮轴上的棘轮、履带摩擦加自锁蜗杆传动、除非握住手柄否则即接合的制动器（失能保护原则）；*保持水平*——固定几何、摆锤调平平台、由操作者调节的把手；*折叠*——铰接把手、伸缩把手、可拆卸平台。对爬楼手推车的专利检索会返回许多三星轮和履带设计；履带车辆和步行机器人的腿部机构是来自其他领域的类比。
(c) 例如，*概念 1*：手动三星轮 + 杠杆 + 棘轮 + 固定几何 + 铰接把手（便宜，但每一级都要用力）。*概念 2*：电池驱动履带 + 自锁蜗杆传动 + 摆锤调平 + 可拆卸平台（省力，但重）。*概念 3*：电池驱动的升降柱，借助可收回的支脚一次爬一级 + 滚珠丝杠 + 失能保护制动器（不寻常——值得制作样机以便学习）。每张概念表记录草图、工作原理、在矩阵中的选择、估计的质量、成本和手推力，以及尚未解决的问题；被排除的组合（例如以肌肉力驱动的步行腿）应连同理由一起注明。
:::
