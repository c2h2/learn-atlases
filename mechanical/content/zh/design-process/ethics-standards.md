工程师的设计离开设计室之后，由从未见过那些计算的人去建造、销售和使用。社会通过三种相互重叠的方式保护这些人。**标准**记录公认的良好做法——尺寸、试验方法、安全距离、设计准则——使每个设计者不必重新发现它们。**法律**规定其中一部分做法在产品销售之前是强制性的，使生产者为缺陷产品造成的伤害承担赔偿责任，并以公开其成果为交换，给予发明者和设计者有限的垄断权。**职业伦理**涵盖标准和法律都无法触及的领域：当计算不确定、进度紧迫、而某个更有权势的人想要另一个答案时，工程师个人的判断。本讲依次讨论这三者——标准，以及欧洲的基本要求、协调标准和 CE 标志体系；产品责任；知识产权——然后讨论职业守则、伦理推理和举报，并以四个事实有充分记载的案例加以说明：凯悦酒店空中走廊、平托车油箱、花旗集团中心和挑战者号。本讲阐述的是原则；它不是法律意见，而且所引用的法规会变化，因此必须查阅其现行文本。风险分析本身在[[design-process/reliability-risk]]中讲授。

## 标准 {#sec-standards}

::: definition 标准 {#def-standard}
**标准**是经协商一致制定并经公认机构批准的文件，它为产品、过程或服务提供共同和重复使用的规则、指南或特性（ISO/IEC 指南 2 中的定义）。标准由制造商、用户、检测机构、监管者和研究者组成的委员会编制，定期复审（ISO 标准至少每五年一次），并以编号和年份标识——ISO 12100:2010、EN ISO 13849-1:2023——因为各版本之间的要求会有变化。
:::

工程师会遇到几类标准：**尺寸与互换性**标准（螺纹、ISO 286 极限与配合、轴承尺寸）、**试验方法**标准（按 ISO 6892-1 进行的拉伸试验、硬度、疲劳）、**设计与产品**标准（压力容器、起重机、机械防护装置、齿轮），以及**管理体系**标准（质量方面的 ISO 9001，环境管理方面的 ISO 14001）。国际机构是 ISO（成立于1947年）和电工技术方面的 IEC（1906年）；在欧洲，CEN 和 CENELEC 发布欧洲标准（EN），每个成员国的国家标准机构（BSI、DIN、AFNOR……）都必须原样采用，并撤销与之冲突的国家标准；在美国，标准来自许多经认可的制定机构，如 ASME、ASTM 和 SAE，由 ANSI 协调。

标准本身是**自愿性的**：没有人有义务遵循它。它通过三种途径实际上或法律上成为强制性的：当法律引用它时（美国许多州把 ASME《锅炉及压力容器规范》规定为其辖区内锅炉的强制性规范），当合同规定它时，或者——下面介绍的欧洲做法——当遵循它是证明满足法律要求的最简便途径时。而在法庭上，已发布的标准是一位称职的工程师当时本应知道和做到什么的有力证据。

### 机械安全标准的层次结构

如 ISO 12100 所述，机械安全标准分为三种类型：

- **A 类**（基础安全）标准给出适用于所有机械的概念和原则——主要是 ISO 12100:2010《机械安全 设计通则 风险评估与风险减小》（*Safety of machinery — General principles for design — Risk assessment and risk reduction*）。
- **B 类**（通用）标准涉及适用于多种机械的某一安全方面或某一类安全防护装置——安全距离（ISO 13857）、控制系统有关安全部件（ISO 13849-1）、急停（ISO 13850）、联锁装置（ISO 14119）、防护装置（ISO 14120）。
- **C 类**（产品安全）标准给出针对某一特定种类机械的详细要求——压力机、机器人、电梯、机床。若存在 C 类标准且其涵盖某一危险，则对该机械而言，其要求优先于 A 类和 B 类标准。

::: algorithm 风险评估与三步法（ISO 12100） {#alg-iso12100}
1. **确定机械的限制**：预定使用和*可合理预见的误用*，寿命的所有阶段（运输、安装、运行、清洁、维护、退役），暴露的人员，空间和时间限制。
2. **识别危险**（机械、电气、热、噪声、振动、辐射、材料、人类工效学……）以及每个阶段中的危险状态。
3. **估计**每种危险的**风险**：可能伤害的严重程度与其概率的组合——后者取决于暴露情况、危险事件的发生以及避免或限制伤害的可能性。
4. **评价风险**：是否需要进一步减小？
5. **减小风险**，按以下优先顺序：
   (a) **本质安全设计**——通过设计本身消除危险或减小危险（更低的力和速度、没有夹挤间隙、倒圆的棱边、低电压、稳定的几何形状）；
   (b) **安全防护和附加保护措施**——固定式和联锁式防护装置、光幕、双手操纵装置、急停装置；
   (c) **使用信息**——警告、标志、说明书、培训要求、个人防护装备。
   每采取一项措施后都要返回第 2 步：一项措施可能引入新的危险。
:::

顺序很重要：警告标签减小风险的作用不如消除危险，设计者也不得仅仅因为下一步更便宜就转到下一步。

::: example 对带式输送机应用三步法 {#ex-conveyor}
包装线上的一台带式输送机在输送带包绕驱动滚筒处有一个外露的卷入夹点，配有一台$0.75\,\mathrm{kW}$的齿轮电动机，操作人员每天在滚筒附近把产品残渣从输送带上刷掉进行清洁。对该夹点应用三步法。
::: solution
*限制与危险：*预定使用包括每天清洁；可合理预见的误用包括在输送带运行时进行清洁。危险：手和手臂在夹点处被卷入和挤压，可能导致截肢（严重度高）；每天暴露。

*第 1 步，本质安全设计：*能否消除危险？把驱动装置移到清洁人员永远无需触及的位置，采用不形成夹点的滚筒设计（例如间隙小到手指无法伸入——允许值见有关的 B 类标准），降低输送带张力和驱动转矩，使被夹住的手能够抽出，以及重新设计残渣的路径，使在滚筒附近清洁成为不必要。

*第 2 步，安全防护：*在夹点仍然存在之处，用一个只能借助工具拆下的固定式防护装置将其封闭；如果需要经常接近，则采用联锁式防护装置，在能够触及夹点之前使驱动停止（停止时间和 ISO 13857 的安全距离决定其几何尺寸）；在滚筒处安装刮板，使刷子成为不必要。

*第 3 步，信息：*要求在清洁前隔离能源的说明、上锁程序、防护装置上的警告标志。

*检查：*每一步之后都要重新评价剩余风险；防护装置不得产生新的危险（沉重的防护装置砸在手上），也不得诱使人规避（一个使清洁变慢的防护装置会被拆掉——因此清洁作业的设计也是安全设计的一部分）。
:::
:::

## 法规：基本要求与 CE 标志 {#sec-regulation}

在欧盟销售的产品受**新立法框架**（法规（EC）765/2008 和决定 768/2008/EC）以及在其基础上建立的产品立法管辖。法律规定**基本要求**——必须达到什么，例如运动部件的设计必须防止接触风险——而把技术手段留给标准。

::: definition 协调标准与符合性推定 {#def-harmonised}
**协调标准**是 CEN、CENELEC 或 ETSI 应欧盟委员会的请求、为支持某项产品立法而制定的欧洲标准（EN），其编号已在欧盟官方公报上公布。按照协调标准设计的产品，在该标准所涵盖的基本要求方面享有**符合性推定**。制造商可以采用其他手段，但那样就必须直接证明符合性。
:::

对于机械，制造商必须进行风险评估，按照满足基本健康与安全要求进行设计，编制**技术文件**（图样、计算书、风险评估、试验报告、所采用的标准、说明书），遵循适用的**符合性评定程序**——大多数机械为自我评定，列入清单的高风险类别则需要第三方*公告机构*参与——起草并签署 **EU 符合性声明**，并加贴 **CE 标志**。CE 标志是制造商关于产品满足所有适用的欧盟立法的声明；它不是质量标志，而且对大多数机械而言也不是第三方认证。

机械方面的规定见**机械指令 2006/42/EC**，它将被自2027年1月20日起适用的**机械法规（EU）2023/1230**取代。该法规在每个成员国直接适用，把基本要求扩展到（除其他外）安全功能涉及软件和自演化行为的机械，并允许以数字形式提供说明书。在英国（大不列颠），UKCA 标志和《2008年机械供应（安全）条例》起着平行的作用（对 CE 标志的认可已延长；请查核当前情况）。在美国，机械没有一般性的上市前审批；工作场所安全由 OSHA 监管，消费品由 CPSC 监管，许多规范通过州法律或合同获得效力——不安全设计的法律后果主要通过产品责任诉讼体现出来。

::: warning “它符合标准，所以是安全的”
符合协调标准产生的是符合性的*推定*，而不是安全的保证。标准落后于技术，只涵盖它们所列出的危险，并以其起草者所预见的预定使用为前提。设计者仍然必须针对实际的机械进行风险评估，包括可预见的误用；对于标准未涵盖的危险（新材料、不寻常的运行模式、软件行为），标准保持沉默，而减小风险的义务依然存在。反过来，偏离标准并不自动就是错的——但必须把理由和替代的证据记录在案。
:::

## 产品责任 {#sec-liability}

当一件产品使人受伤时，受害人可以向生产者索赔。有两种法律依据是重要的。在**过失责任**中，索赔人必须证明生产者负有注意义务，因低于一个合理称职的生产者的标准而违反了这一义务，并由此造成了损害。在**严格责任**中，则无需证明过错。

::: definition 缺陷产品（欧盟严格责任） {#def-defect}
根据欧盟产品责任指令 85/374/EEC，生产者对其产品缺陷造成的损害承担无过错责任。当一件产品在考虑全部情况——包括其外观说明、可合理预期的用途以及投入流通的时间——之后，不能提供人们有权期待的安全性时，该产品即为**有缺陷的**。抗辩理由包括：产品投入流通时缺陷并不存在，以及*开发风险抗辩*：当时的科学技术知识水平尚不能发现该缺陷。索赔必须在索赔人知悉损害、缺陷和生产者之日起三年内提出，且不得晚于产品投入流通后十年。
:::

该指令已被修订后的**产品责任指令（EU）2024/2853**取代，成员国必须在2026年12月9日之前将其转化为国内法，它适用于此日期之后投放市场的产品。它明确把软件（包括作为服务或更新提供的软件）纳入产品的定义，并减轻了索赔人在技术复杂案件中的举证负担。

缺陷通常分为**制造缺陷**（这一件与设计不符——漏焊）、**设计缺陷**（由于设计原因，每一件都是危险的）以及**警示或说明缺陷**。设计缺陷是工程师的直接责任，许多司法辖区的法院采用风险—效用检验来衡量它：当时是否存在技术上和经济上可行、能够降低风险的合理替代设计？因此，设计文件——风险评估、所考虑的备选方案以及否定它们的理由——也就是生产者的证据。在美国，*Grimshaw v. Ford Motor Co.*案（加利福尼亚州，1978年2月陪审团裁决）涉及一辆被追尾、油箱破裂的平托车：陪审团在补偿性赔偿之外裁定了 1.25 亿美元的惩罚性赔偿，后被法官减至 350 万美元。

## 知识产权 {#sec-ip}

一项设计代表着竞争对手可能抄袭的知识。知识产权法授予有限的排他性权利，作为交换——就专利而言——要求公开。

::: definition 可专利性 {#def-patent}
根据《欧洲专利公约》（第52—57条），**专利**授予任何技术领域中的发明，该发明必须是**新颖的**（不属于现有技术——即在申请日或优先权日之前在任何地方、以任何方式为公众所知的任何东西，包括发明人自己的发表）、具有**创造性**（对本领域技术人员而言不是显而易见的），并且**能在产业上应用**。发现、科学理论、数学方法、美学创作以及信息的呈现本身被排除在外。专利赋予在其获授权的地域内阻止他人制造、使用、销售或进口所要求保护的发明的权利，期限最长为**自申请日起 20 年**，须缴纳年费维持。申请在优先权日起 18 个月后公布。
:::

**权利要求**界定保护范围；说明书必须足够清楚地公开发明，使本领域技术人员能够实施。根据《巴黎公约》，在一个国家首先提出申请的申请人享有 12 个月的**优先权**期，可在其他地方提出申请并保留首次申请日。欧洲基本上没有宽限期：一位在提出申请之前就在会议上展示了一种新机构的工程师，已经破坏了它的新颖性。美国对发明人自己的公开给予一年的宽限期，但依赖这一宽限期会丧失在欧洲的权利。

其他权利：

- **注册外观设计**保护产品的外观（形状、轮廓、表面）；在英国和欧盟，以五年为一期，最长可达 25 年。**未注册外观设计权**提供较短的、自动产生的防抄袭保护。
- **商标**保护用以区分企业商品的标志；注册有效期为十年，可无限续展。
- **著作权**自动保护图样、文件和软件代码，在欧盟和英国保护期为作者死后 70 年；它保护的是表达，而不是思想。
- **商业秘密**——工艺参数、配方、供应商诀窍——只要采取合理措施保密就受到保护（在欧盟依据指令（EU）2016/943）；它们可以无限期存续，但不能对抗独立发现或反向工程。

工程师从两个方向使用专利。检索专利数据库（Espacenet、Google Patents）是概念的来源（[[design-process/concept-generation]]），并能显示现有技术水平。在推出产品之前，**自由实施**（FTO）分析检查它是否会侵犯在制造国和销售国有效的专利的权利要求；已过期的专利和未在某国生效的专利可以在该国自由使用。

::: example 专利的日期 {#ex-patent-dates}
一位工程师于2020年3月15日为一种新的夹紧机构提出英国专利申请，然后于2021年3月15日提出一件要求该优先权的欧洲申请。欧洲申请何时公布？如果缴纳了全部年费，欧洲专利何时期满？在两次申请之间，公司应当避免做什么？
::: solution
公布是在*优先权*日起 18 个月后：2021年9月。保护期是自欧洲申请的*申请日*起 20 年：专利于2041年3月15日期满。因此，要求优先权使保护的终止时间延长到首次申请后 21 年，而欧洲申请的新颖性按优先权日判断。在两次申请之间，公司可以按优先权申请中所描述的那样公开该发明而不损害新颖性；但以后增加的任何*新*特征，若在其自身提出申请之前公开，就不会受到保护，因此改进应当在展示之前提出申请。

*检查：*保护期和公布从不同的日期起算——这是常见的出错原因。
:::
:::

## 职业责任 {#sec-professional}

职业工程师之所以受到信任，是因为公众无法检查他们的工作。行为守则把这种信任的条件明确下来。美国全国职业工程师协会（NSPE）的伦理守则的基本准则以**“把公众的安全、健康和福祉放在首位”**的义务开头，接下来是只在自己能胜任的领域提供服务，只以客观和真实的方式发表公开声明，作为每个雇主或客户的忠实代理人或受托人行事，避免欺骗行为，以及以正直和守法的方式行事。其规则还补充道：如果工程师的判断在危及生命或财产的情况下被否决，他们应当通知其雇主或客户以及其他适当的主管机构。在英国，工程委员会和皇家工程院的《伦理原则声明》是各专业学会守则的基础，它于2026年2月更新，现列出五项原则：诚实与正直；对社会的责任；准确与严谨；领导与沟通；以及对技术、社会和环境未来的责任。注册为特许工程师或持证职业工程师，就使工程师受到某一守则的约束，违反守则可能导致丧失头衔或执照。

### 推理伦理困境的方法

守则无法解决每一个案例，因此了解主要的伦理学理论是有帮助的；它们通常结论一致，而在不一致的地方最有用。

- **后果主义**（功利主义）按结果评判行为：选择对所有受影响者而言利大于弊最多的方案。它是成本—效益分析和定量风险评估的基础。它的弱点在于，它可能为了许多人的小收益而认可把严重伤害强加给少数人，而且它依赖于对那些难以估价的东西——伤害、生命——进行估价。
- **义务论**伦理学与康德相联系，按行为是否尊重义务和权利来评判它：不欺骗，信守承诺，不把人仅仅当作手段。它解释了知情同意为什么重要——人们可以接受他们所知道的风险，但不能接受向他们隐瞒的风险。
- **美德伦理学**追问一个品格良好的人——诚实、称职、勇敢、尽责——会怎么做，它与工程师描述职业操守的方式很接近。

::: algorithm 处理工程伦理困境的实用方法 {#alg-dilemma}
1. **确定事实**：已知什么，不确定什么，哪些试验或计算能减小不确定性，需要多久。
2. **识别利益相关者**以及每一方可能的得失，包括不在场的人（用户、公众、未来的所有者）。
3. **识别义务**：法律、标准、雇主的程序、职业守则——在它们相互冲突时，要记住守则把公众安全放在首位。
4. **生成选项**——很少只有“服从”或“拒绝”两种：进一步试验、缩小运行范围、临时限制、在组织内部逐级上报、独立评审。
5. **检验选项**：对每个利益相关者的后果；受影响的人在充分知情的情况下是否会同意；如果这一决策及其理由被公开报道，你是否会感到坦然。
6. **行动并记录**：记录事实、所给出的建议和所作的决定。
:::

**举报**（whistle-blowing）——在正常的权力链之外披露危险或不当行为——是第 4 步中的最后手段。哲学家理查德·德乔治（Richard De George）提出的一套被广泛采用的条件认为：当伤害严重且重大、关切已向直接上级报告、且直到最高层的内部渠道都已用尽时，工程师*可以*公开举报；当此外还有足以说服一位合理而公正的观察者的书面证据，并有充分理由相信披露能防止伤害时，工程师*有义务*这样做。许多司法辖区保护通过规定渠道善意作出此类披露的雇员——英国有《1998年公共利益披露法》，欧盟有举报人保护指令（EU）2019/1937。

## 四个案例 {#sec-cases}

### 凯悦酒店空中走廊，1981年

1981年7月17日，在密苏里州堪萨斯城凯悦酒店（Hyatt Regency）中庭举行的一场茶舞会上，两条悬吊空中走廊坍塌：四楼走廊连同直接悬吊在其下方的二楼走廊，一起坠落到挤满人群的大堂上。114人死亡，200多人受伤。原设计用连续的吊杆悬吊两条走廊，吊杆从中庭屋顶向下穿过四楼的箱形梁直到二楼的箱形梁，每根梁由吊杆上的一个螺母和垫圈支承。在制作过程中，钢结构制作商提议把每根连续吊杆换成两根吊杆——一根从屋顶到四楼梁，另一根从四楼梁向下到二楼梁——而结构工程师接受了这一更改，却没有重新计算该连接。

::: proposition 四楼连接处的载荷 {#prop-hyatt}
设每个吊杆连接承受来自四楼走廊的载荷$P_4$和来自二楼走廊的载荷$P_2$。采用连续吊杆时，四楼箱形梁下方的螺母传递$P_4$。采用双吊杆构造时，它传递$P_4 + P_2$——在两条走廊载荷相等时为两倍。
:::

::: proof
*连续吊杆。* 取一个吊杆处的四楼箱形梁为分离体：向下为走廊载荷$P_4$；向上为螺母反力$N_4$。吊杆穿过梁，除该螺母外与梁没有连接，因此$N_4 = P_4$。二楼载荷$P_2$沿吊杆向上传递，越过四楼，直到屋顶；四楼以上的吊杆承受$P_4 + P_2$的拉力，但梁并不承受。

*双吊杆。* 取四楼箱形梁为分离体：向下为$P_4$以及下吊杆的拉力——下吊杆悬挂在这根梁上并承载二楼的梁，$T_{\mathrm{lower}} = P_2$（由二楼梁的分离体得出）；向上为上吊杆的螺母力$N_4$。由平衡得$N_4 = P_4 + P_2$。当$P_4 = P_2 = P$时，$N_4 = 2P$。这个力通过螺母、垫圈和箱形梁的焊缝传递——两种设计中的薄弱点都在这里。（忽略吊杆与梁之间的摩擦以及吊杆的自重。）
:::

美国国家标准局的调查发现，即使是原设计的构造，其承载能力也只有堪萨斯城建筑规范要求的约 60 %；而实际建成的构造又使作用在其上的需求加倍。密苏里州执照委员会认定负责结构设计的工程师在工程执业中犯有重大过失、不当行为和违反职业操守的行为，经1984年启动的纪律听证程序，吊销了他们在密苏里州的执照以及其公司的执业许可证。记录在案的工程师（engineer of record）后来承认对这次失事负有责任。美国土木工程师学会随后采取的立场是：记录在案的结构工程师负责审查加工详图和连接构造。给设计者的教训：**为便于施工而作的更改就是设计更改**，而设计更改必须经过与原设计同样的计算和审查。

### 平托车燃油系统与1973年的成本—效益备忘录

1971年推出的福特平托（Ford Pinto）的油箱位于后桥与后保险杠之间，在追尾碰撞中可能被刺破。在1977年的一篇杂志文章以及美国国家公路交通安全管理局的调查（该局于1978年5月认定燃油系统有缺陷）之后，福特于1978年6月召回了约 150 万辆平托和水星山猫（Mercury Bobcat）——这是当时汽车史上规模最大的召回。1980年，印第安纳州的一个陪审团就三名少女在一辆1973年款平托车中死亡一事，裁定福特不构成鲁莽杀人罪，这是美国首次因产品设计而对公司提起的刑事诉讼。人们记住这个案例，首先是因为福特1973年的一份备忘录《与碰撞引起的燃油泄漏和火灾有关的死亡》（“Fatalities Associated with Crash-Induced Fuel Leakage and Fires”，作者 E. S. 格拉什（E. S. Grush）和 C. S. 桑比（C. S. Saunby）），它被提交给监管机构，以反对一项拟议的燃油系统标准。与许多转述相反，它不是对平托追尾问题的分析，而是对一项适用于在美国销售的所有轿车和轻型卡车的翻车燃油泄漏要求所作的成本—效益分析。

::: example 1973年备忘录中的算术 {#ex-pinto}
备忘录估计，该要求每年可防止 180 人烧死、180 人严重烧伤和 2100 辆车被烧毁，按（监管机构1972年的数字）每例死亡 \$200 000、每例受伤 \$67 000、每辆车 \$700 估价，而成本为 1250 万辆车（1100 万辆轿车和 150 万辆轻型卡车）每辆 \$11。重现这些总数，并指出这一算术遗漏了什么。
::: solution
效益：$180\times200\,000 + 180\times67\,000 + 2100\times700 = 36.0 + 12.06 + 1.47 = \$49.53$百万。成本：$12.5\times10^6\times11 = \$137.5$百万（报告为 \$1.37 亿）。按这些数字，成本约为效益的 2.8 倍。

算术是正确的；使这份备忘录臭名昭著的是它所体现的东西。它以处于风险中的人们从未接受过的方式为死亡和伤害标价；它只计算了部分伤害（除监管机构的数字外，没有计入痛苦和折磨，也没有计入信任的丧失）；它把分摊到每个人身上的 \$11 成本与集中在少数人身上的死亡视为可以通约；而且它没有追问是否存在更便宜的修正办法。监管机构确实使用统计生命价值来确定安全措施之间的优先次序——这种方法本身并非不道德——但它是比较各种挽救生命方式的工具，而不是保留一个已知的、可以廉价避免的危险的许可证。*合理性检查：*$\$137.5\mathrm{M}/12.5\mathrm{M} = \$11$每辆车，$\$49.53\mathrm{M}/12.5\mathrm{M} \approx \$3.96$每辆车——这就是消费者被间接告知的这项修正所值的“每辆车效益”。
:::
:::

### 花旗集团中心，1978年

纽约 59 层的花旗集团中心（Citicorp Center，1977年竣工）由威廉·勒梅热里耶（William LeMessurier）进行结构设计，它立在四根布置于各边中点而非四角的柱子上，每个立面上叠置的人字形支撑把风载荷向下传给这些柱子，顶部还有一个调谐质量阻尼器以减小摆动。1978年，在普林斯顿大学学生黛安·哈特利（Diane Hartley）就以 45° 吹向大楼的风（“斜向风”）提出问题之后，并且在得知制作商已把支撑的焊接连接替换为螺栓连接之后，勒梅热里耶重新计算了结构。他发现斜向风使某些支撑中的力增大 40 %，使螺栓连接中的力增大 160 %，并估计足以使关键节点破坏的风暴，在阻尼器断电时平均每 16 年发生一次，在阻尼器正常工作时每 55 年发生一次。他通知了业主和市政当局；1978年8月至10月间，在为阻尼器安装了备用发电机并准备了疏散计划的情况下，人们在夜间把钢板焊接到螺栓连接节点上。一场飓风（埃拉，Ella）在9月初逼近，随后转向海上。这件事直到1995年才因乔·摩根斯特恩（Joe Morgenstern）在《纽约客》（*The New Yorker*）上的一篇文章而为公众所知。（NIST 后来的一项重新评估表明，斜向风载荷并不像勒梅热里耶计算的那样严重；但这个案例仍然是工程师报告自身错误的经典范例。）

::: proposition 至少超越一次的概率 {#prop-exceedance}
若某一事件（例如风速超过给定值）在任何一年中发生的概率为$p$，且各年相互独立，则它在$n$年中至少发生一次的概率为
$$
P_n = 1 - (1-p)^n \approx np \quad (np \ll 1).
$$ {#eq-exceedance}
两次发生之间的平均间隔——**重现期**——为$T = 1/p$。
:::

::: proof
一年中不发生的概率为$1-p$；由独立性，$n$年中都不发生的概率为$(1-p)^n$；其补事件为至少发生一次。$np$很小时，$(1-p)^n = e^{n\ln(1-p)} \approx e^{-np} \approx 1 - np$。到首次发生为止的年数服从几何分布，均值为$1/p$。
:::

::: example “每 16 年一次”是什么意思 {#ex-citicorp}
用勒梅热里耶的估计，求关键风暴 (a) 在阻尼器断电时一年内发生的概率，(b) 在阻尼器正常工作时 50 年设计寿命内发生的概率。
::: solution
(a) $p = 1/16 = 0.0625$：每年 6.25 %。(b) $p = 1/55$：$P_{50} = 1 - (54/55)^{50} = 1 - 0.400 = 0.600$——在寿命期内有 60 % 的可能发生一种可能使一座有人使用的高楼倒塌的破坏。相比之下，设计规范所追求的结构倒塌年概率要低许多个数量级。*合理性检查：*这里近似$np = 50/55 = 0.91$很差，因为$np$并不小；必须使用精确公式，而它永远不会超过 1。
:::
:::

x: 0, 100
y: 0, 1
sliders: T=55:5:500:5
labels: P_n,\ \text{重现期 }T; P_n,\ \text{重现期 }4T
caption: 重现期为$T$年的事件在$n$年（横轴）内至少发生一次的概率。设$T = 50$：在 50 年寿命内，“50 年一遇的事件”发生的可能性大于不发生（63.6 %）。再设$T = 16$，看勒梅热里耶阻尼器断电的情况，并对照第二条曲线，看重现期增加到四倍能换来多少。注意重现期等于设计寿命时，离“安全”有多远。
:::

### 挑战者号，1986年

1986年1月28日，*挑战者号*航天飞机在发射后 73 秒解体，七名机组人员全部遇难。由威廉·P. 罗杰斯（William P. Rogers）担任主席的总统调查委员会认定，事故原因是右侧固体火箭助推器后部现场接头的 O 形密封圈失效，使高温燃气逸出，烧穿了外贮箱连接件和贮箱。O 形圈的烧蚀和窜气在以前的飞行中已经出现过，而且人们知道，在低温下橡胶回弹性变差时这种情况会加剧。发射前夜，预报的早晨气温远低于以往任何一次发射（最冷的一次约为 12 °C，即 53 °F；发射时的气温约为 2 °C，即 36 °F），助推器承包商莫顿·聚硫橡胶公司（Morton Thiokol）的工程师，其中包括罗杰·博伊斯乔利（Roger Boisjoly）和阿诺德·汤普森（Arnold Thompson），建议不要在 12 °C 以下发射。NASA 的管理人员对这一建议提出质疑；在一次线下的内部讨论中，聚硫橡胶公司的高层管理人员推翻了这一建议——一位经理被要求“摘下工程师的帽子，戴上管理者的帽子”——随后聚硫橡胶公司签署了同意发射的建议。委员会（1986年6月的报告）批评了这样一种决策过程：举证责任转移到了工程师身上，要由他们来证明飞行不安全；而且这些担忧没有被传达给最高层的发射决策者。理查德·费曼（Richard Feynman）在其为报告撰写的附录中写道：“一项技术要取得成功，现实必须优先于公关，因为大自然是骗不了的。”

::: quiz
在挑战者号的电话会议中，罗杰斯委员会认为决策过程的核心失误是哪种推理上的转变？
- [ ] 工程师使用了错误的 O 形圈材料数据
- [x] 举证责任从证明发射安全转变为证明发射不安全
- [ ] 发射推迟得太频繁，增加了进度压力
- [ ] 工程师在发射前没有提出任何担忧
::: solution
工程师确实提出了他们的担忧，并建议不要发射。失误在于，在数据不完整的情况下，默认做法变成了“除非证明不安全，否则就发射”，颠倒了安全关键工程中在继续进行之前必须证明安全这一正常要求。对安全关键项的不确定性是停下来的理由，而不是继续前进的理由。
:::
:::

::: history
规范和标准一再在灾难之后跟进。1905年3月20日马萨诸塞州布罗克顿的格罗弗制鞋厂（Grover Shoe Factory）锅炉爆炸，造成58人死亡，促使马萨诸塞州通过了锅炉规程；ASME 于1911年成立了锅炉规范委员会，其第一部规范的日期为1914年，于1915年出版；它后来成为 ASME《锅炉及压力容器规范》。英国工程标准委员会——BSI 的前身——成立于1901年；IEC 成立于1906年，ISO 成立于1947年。产品责任法在20世纪60年代的美国法院中发展起来，在欧洲则随着1985年的指令 85/374/EEC 而发展。在凯悦酒店坍塌（1981年）和挑战者号事故（1986年）等案例之后，NSPE 的守则之类的职业守则变得愈加重要，这些案例也成为工程伦理教学的核心材料。
:::

::: summary
- 标准是协商一致的文件，本身是自愿性的，通过法律、合同或——在欧盟——通过给予与法定基本要求相符的推定而成为强制性的。引用标准时要注明年份。
- ISO 12100：确定限制，识别危险，估计和评价风险，然后首先通过本质安全设计、其次通过安全防护、最后通过信息来减小风险。A 类、B 类和 C 类标准构成机械安全标准的层次结构。
- CE 标志是制造商的符合性声明，以技术文件为支撑；机械将于2027年1月20日从指令 2006/42/EC 转到法规（EU）2023/1230。
- 欧盟产品责任是严格责任：如果产品缺乏人们有权期待的安全性，它就是有缺陷的；指令（EU）2024/2853 自2026年12月起把它扩展到软件。设计文件是生产者的证据。
- 专利要求新颖性、创造性和产业实用性，最长保护期为自申请日起 20 年；要先申请再公开。用专利检索获取创意，在推出产品前进行 FTO 分析。
- 守则把公众安全放在首位；后果主义、义务论和美德伦理的推理有助于看清困境；举报是用尽内部渠道之后的最后手段，在许多国家受法律保护。
- 凯悦酒店：一项为便于施工的更改使连接载荷加倍——每一项更改都是设计更改。平托车：成本—效益是工具，不是许可证。花旗集团中心：报告你自己的错误。挑战者号：在不确定的情况下，举证责任在于证明安全。
:::

::: exercise 50 年一遇的风 {#exr-fifty level=1 check="0.64"}
一座结构按重现期为 50 年的风速进行设计。在 50 年设计寿命内，这一风速至少被超过一次的概率是多少？（输入概率，保留两位小数。）
::: solution
$1 - (1 - 0.02)^{50} = 1 - 0.364 = 0.636 \approx 0.64$。这就是规范对特征风荷载施加荷载分项系数的原因：在结构的寿命期内，50 年一遇的值并不是罕见事件。
:::
:::

::: exercise 凯悦酒店连接力 {#exr-hyatt level=1 check="180"}
在一个类似[[#prop-hyatt]]的双吊杆构造中，每个吊杆连接承受来自四楼走廊的$90\,\mathrm{kN}$和来自二楼走廊的$90\,\mathrm{kN}$。四楼箱形梁下方的螺母传递多大的力？（以 kN 输入。）采用连续吊杆时又是多少？
::: solution
双吊杆：$N_4 = P_4 + P_2 = 90 + 90 = 180\,\mathrm{kN}$。连续吊杆：$N_4 = P_4 = 90\,\mathrm{kN}$。两种情况下四楼以上的吊杆都承受$180\,\mathrm{kN}$；改变的只是通过箱形梁的传力路径。
:::
:::

::: exercise 重新计算备忘录 {#exr-pinto level=2 check="49.53"}
用[[#ex-pinto]]中的数字，计算备忘录中的年度总效益。（以百万美元输入。）然后在其他数字不变的情况下，求使效益等于成本的每例死亡价值，并加以评论。
::: solution
效益$= 36.0 + 12.06 + 1.47 = 49.53$百万美元。令两者相等，$180V + 12.06 + 1.47 = 137.5$，故$V = (137.5 - 13.53)/180 = 0.689$百万美元每例死亡——约为所用数字的 3.4 倍。决策在这类估价（以及成本和伤亡估计）的合理范围之内就会翻转，这表明当一个成本—效益“证明”取决于一个有争议的估价时，它是多么脆弱，也说明了为什么应当说明每项输入的不确定性。
:::

::: exercise 阻尼器断电的十年 {#exr-citicorp level=2 check="0.476"}
用勒梅热里耶关于阻尼器断电时关键风暴 16 年一遇的估计，10 年内至少发生一次这种风暴的概率是多少？（保留三位小数输入。）阻尼器正常工作时（55 年一遇），多少年会有 50 % 的可能？
::: solution
$1 - (15/16)^{10} = 1 - 0.5245 = 0.476$。$p = 1/55$时达到 50 %：$n = \ln 0.5/\ln(54/55) = 37.8$，约 38 年。对于一座有人使用的建筑的倒塌，这两个数字都是不可接受的，这证明了紧急加固的必要性。
:::

::: exercise 标准的分类 {#exr-classify level=2}
把下列各项分类为 A 类、B 类或 C 类机械标准，并说明对于液压折弯机上的某一危险，若它们相互冲突，以哪个为准：(a) ISO 12100；(b) ISO 13857，防止触及危险区的安全距离；(c) EN 12622，液压折弯机的安全；(d) ISO 13850，急停。
::: solution
(a) A 类；(b) B 类；(c) C 类；(d) B 类。对于 C 类标准所涵盖的危险，对该机械而言以其要求为准；在 C 类标准未作规定之处适用 A 类和 B 类标准，它们提供一般方法（风险评估）和通用的安全防护装置。
:::

::: exercise 申请前公开 {#exr-disclosure level=2}
一个学生团队设计了一种新颖的自行车车轮快拆机构，5月在一次公开的设计展上展示了它，7月提出了英国专利申请。一家赞助商想在德国和美国为它申请专利。给他们提出建议。
::: solution
按照欧洲的规则（英国遵循《欧洲专利公约》），5月的公开展示对于7月提出的申请而言属于现有技术，因此英国申请和任何欧洲申请对于展会上展示过的内容都缺乏新颖性；只有展会上未公开的特征才能受到保护。在美国，发明人自己的公开在一年宽限期之内，因此在次年5月之前提出的美国申请仍可能有效，但这救不了欧洲。教训：先申请再公开（或者在保密协议下公开）；考虑用注册外观设计保护外观（英国和欧盟对外观设计允许 12 个月的宽限期）；并保留注明日期的开发记录。
:::

::: exercise 压力之下的签字 {#exr-dilemma level=3}
你是负责一条新生产线起吊梁设计计算的工程师。投产调试前两天，一位同事发现疲劳校核所用的载荷谱是按每天一班计算的，而工厂将三班运行。你的快速估算表明疲劳寿命从 25 年降到约 8 年。该梁在静力上是安全的。你的经理指出生产线必须按期投产，并说“八年比这个产品的生产期还长”。用[[#alg-dilemma]]分析这一情况，并说明你会怎么做。
::: solution
*事实：*静力安全不受影响，但疲劳寿命现在依赖于一个不受工程控制的假设（产品的生产期），而起吊梁的疲劳失效是突然的，并且可能致命。一次正确的重新计算（采用正确的载荷谱、构造细节类别和检查可能性）大概几个小时就能完成。*利益相关者：*梁下方的操作人员、维修人员、公司、设备的未来所有者。*义务：*职业守则（安全第一；准确与严谨）、起重设备法规和标准（它们要求设计适合实际工况）、雇主避免承担责任的利益。*选项：*现在就重新计算；如果确认寿命短，就在有书面限制的条件下投产（降低载荷或工作级别），在关键构造细节处规定检测裂纹的检查间隔，并定出更换或加固的日期；在投产前或投产后不久加固这些细节；书面通知客户。原样签署原来的计算书不是一个选项：现在已经知道该计算是错的，而且其结论依赖于一个被当作工程假设提出的商业假设。*行动并记录：*以书面形式把结果和各选项告诉经理；大多数此类冲突通过短暂的推迟或书面限制就能解决，无需上报。只有在危及生命的问题上被否决时，你才会按照守则的要求进一步上报。
:::

::: exercise 对一项便于施工的更改进行设计评审 {#exr-change level=3}
为简化安装，一家制作商提议把夹层楼板中一根两端铰接的拉杆换成两根较短的拉杆，在中点用螺栓连接到一块节点板上，并通过电子邮件要求“今天”批准。用类似[[#prop-hyatt]]的分离体论证，说明在批准之前你必须检查什么，并为你的公司起草处理所有此类请求应遵循的流程。
::: solution
新节点板的分离体：它现在要通过两组螺栓和板，在两根拉杆之间传递全部拉杆力，这是一条以前并不存在的传力路径；必须校核板的净截面、块状剪切、螺栓的抗剪和承压，以及任何偏心（如果两根拉杆不在同一直线上，板和拉杆就要承受弯曲）；而且拉杆的刚度会改变（螺栓滑移），这可能使超静定楼板中的力重新分配。流程：每一项拟议的更改都作为正式的更改申请连同图样记录下来；记录在案的工程师（或具备相应能力的受托人）用计算而不是目测来校核更改后的传力路径；校核要由第二位工程师按失效后果的严重程度相应地进行复核；批准以书面形式在加工详图上给出；更改在设计文件中可以追溯。凯悦酒店案例表明，一项“只涉及构造细节”的更改可能使一个力加倍，而没有计算的电话或电子邮件批准正是薄弱环节。
:::

## 延伸阅读

哈里斯（Harris）、普里查德（Pritchard）、拉宾斯（Rabins）、詹姆斯（James）与恩格尔哈特（Englehardt）的《工程伦理：概念与案例》（*Engineering Ethics: Concepts and Cases*，Cengage），以及马丁（Martin）与辛津格（Schinzinger）的《工程伦理》（*Ethics in Engineering*，第4版，McGraw-Hill，2005年），讨论了各种理论、守则和许多案例，包括上述案例。《总统挑战者号航天飞机事故调查委员会报告》（*Report of the Presidential Commission on the Space Shuttle Challenger Accident*，1986年）和美国国家标准局对堪萨斯城凯悦酒店空中走廊的调查报告（1982年）是其中两个案例的第一手记述；摩根斯特恩的《五十九层的危机》（“The fifty-nine-story crisis”，*The New Yorker*，1995年5月29日）讲述了花旗集团中心的故事。关于机械安全，ISO 12100:2010 是出发点；欧盟委员会关于机械指令和机械法规的指南解释了符合性程序。
