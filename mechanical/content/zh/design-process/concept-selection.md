概念生成（[[design-process/concept-generation]]）有意产生比能够开发的更多的想法。概念选择把它们收窄到一个——或者更常见的是两三个，一直保留到试验或分析能够把它们区分开为止。这一决策是在信息不完全的情况下作出的：概念只是草图，其性能是估计的，而要求本身（[[design-process/requirements]]）也可能还在变动。本讲各种方法的目的，不是从部分靠猜测得来的数字中算出“正确”答案，而是使比较明确、一致并且可以受到质疑，表明决策依赖于哪些判断，并把力量引向那些会改变决策的信息。

本讲由粗到细展开。普氏（Pugh）筛选矩阵用加号、减号和相同把许多概念与一个基准进行比较；加权评分矩阵细化对少数候选方案的比较；敏感性分析追问权重要改变多少才会改变排序；帕累托支配关系识别出无论权重如何都值得考虑的概念；期望值推理引入风险和试验的价值；简单的物理模型则在最重要的属性上区分各个概念。最后一节解释为什么评分方法在使用不当时会误导人。

## 筛选：普氏矩阵 {#sec-pugh}

::: definition 概念筛选矩阵 {#def-pugh}
**筛选矩阵**（普氏矩阵）以选择准则为行、以概念为列。选择一个概念——通常是现有产品或团队当前最看好的方案——作为**基准**。其他每个概念在每项准则上都与基准比较，并标记为 **+**（较好）、**−**（较差）或 **S**（大致相同）。加号和减号的个数及其差（**净得分**）概括了每个概念，但矩阵既要逐列阅读，也要逐行阅读。
:::

::: algorithm 普氏受控收敛法 {#alg-pugh}
1. 根据设计要求商定准则；准则要少（5–10 条）、相互独立，并且与区分各概念有关。
2. 选择一个基准；把所有概念画到相近的详细程度。
3. 用 +、S、− 对照基准评定每个概念；对分歧进行讨论，而不是取平均。
4. 统计加号、减号和净得分。剔除明显较差的概念；对于有前途的概念，审视其减号，并追问另一个概念的某个特征能否消除它们，从而生成**混合**概念。
5. 把基准换成最强的概念并重复，直到剩下一个或几个无法再通过组合加以改进的概念。
:::

斯图尔特·普（Stuart Pugh）称之为*受控收敛*：概念的数目交替地减少（剔除）和增加（混合），而其质量不断提高。这种方法有意做得很粗。它的长处在于迫使团队在每项准则上把每个概念与一个具体的参照物比较，并讨论原因；它的弱点在于每项准则同等重要，差异的大小也丢失了。

::: example 筛选易拉罐压扁机概念 {#ex-pugh}
基准是团队现有的产品，一种简单的壁挂式杠杆压扁机。比较来自[[design-process/concept-generation#ex-morph]]形态学矩阵的四个概念：C1 脚踏板加肘杆机构和重力料仓；C2 电动机驱动螺旋传动和压板；C3 电动机加一对辊子和料仓；C4 手动杠杆加肘杆机构（其余与基准相同）。团队的评定如下：

| 准则 | C1 | C2 | C3 | C4 |
|---|---|---|---|---|
| 装料方便性 | + | S | + | S |
| 用户用力 | + | + | + | + |
| 防夹手安全 | S | + | − | S |
| 处理量（每分钟罐数） | + | S | + | S |
| 制造成本 | − | − | − | S |
| 台面占用面积 | − | − | S | S |
| 清洁方便性 | S | − | − | S |

计算得分并提出下一步建议。
::: solution
C1：3 个加号，2 个减号，净得分$+1$。C2：2 个加号，3 个减号，净得分$-1$。C3：3 个加号，3 个减号，净得分$0$。C4：1 个加号，0 个减号，净得分$+1$。
C2 在较多准则上比基准差而不是好，而且没有提供 C1 或 C3 所不能提供的东西；可以将其剔除。C4 是一种稳妥的小改进。C1 和 C3 以一定代价带来了真正的收益（装料和处理量）。逐行阅读：C1 的减号（成本、占用面积）来自单独的踏板和机架；C3 的减号来自电动机和辊子。一个混合概念“C5”——C4 的肘杆机构加上 C1 的重力料仓，仍为手动操作——可能保留 C1 的大部分收益而无需机架。下一轮以 C1 为基准，把 C3、C4 和 C5 与之比较。
合理性检查：各净得分很接近（$-1$到$+1$），当基准是一个合理的产品时，这是典型情况。第一轮中净得分为$+5$的概念，通常意味着基准选得不好，或者准则偏向某一个概念。
:::
:::

## 加权评分 {#sec-scoring}

一旦候选清单变短，就通过给准则赋予**权重**、并用更细的标度评定每个概念来细化比较。

::: definition 加权和得分 {#def-weighted}
设准则$i = 1,\dots,m$的权重为$w_i \ge 0$，$\sum_i w_i = 1$，概念$j$在准则$i$上的评分$r_{ij}$采用同一标度（例如 1 到 5，或 0 到 1），则概念$j$的**加权得分**为
$$
S_j = \sum_{i=1}^{m} w_i\,r_{ij}.
$$ {#eq-weighted}
:::

评分可以来自对照参照物的判断（“3 = 与基准相同，5 = 好得多”），或者更好的做法是，通过把指标映射到评分标度上的**价值函数**，由估计的指标值$x_{ij}$得出。最简单的价值函数在设计要求的临界值与理想值之间是线性的：
$$
v_i(x) = \frac{x - x_{i,\text{marg}}}{x_{i,\text{ideal}} - x_{i,\text{marg}}},\qquad \text{截断到 } [0, 1],
$$ {#eq-value}
因而刚好达到临界值的概念得 0 分，达到理想值的概念得 1 分。同一公式也适用于“越小越好”的指标，因为此时$x_{i,\text{ideal}} < x_{i,\text{marg}}$。

::: proposition 加权和对什么敏感 {#prop-scale}
(a) 用同一个$a > 0$和$b$，对每项准则把*全部*评分换成$a\,r_{ij} + b$，不会改变按[[#eq-weighted]]得出的概念排序。
(b) 对*一项*准则的评分进行重新标定，$r_{kj} \to a_k r_{kj} + b_k$，$a_k \ne 1$，等价于把其权重从$w_k$改为$a_k w_k$（并在每个得分上加一个常数），并且可能改变排序。
:::

::: proof
(a) $S'_j = \sum_i w_i(a r_{ij} + b) = a S_j + b\sum_i w_i = aS_j + b$；递增的仿射映射保持顺序。(b) $S'_j = S_j + w_k(a_k - 1)r_{kj} + w_kb_k = \sum_{i\ne k} w_ir_{ij} + (a_kw_k)r_{kj} + w_kb_k$。常数$w_kb_k$对所有概念都相同；因子$a_kw_k$起着准则$k$上的新权重的作用。由于不同的权重可能给出不同的排序（见[[#prop-breakeven]]），对一项准则重新标定也可能如此。
:::

其实际结论是：权重本身没有意义；它是从*该准则标度*的底端移到顶端的重要程度。如果成本的评分范围是从 £20 到 £25，而安全性的评分范围是从“危险”到“本质安全”，那么相等的权重并不意味着两者同等重要。设定权重时应当把范围放在眼前——“把成本从 £25 降到 £20，与把质量从 12 kg 降到 8 kg 相比，我们看重多少？”——这种做法在决策分析中称为**摆幅加权**（swing weighting）。

::: example 加权评分矩阵 {#ex-weighted}
筛选之后剩下三个易拉罐压扁机概念：C1（脚踏板加肘杆）、C3（电动机加辊子）和 C4（手动杠杆加肘杆）。权重为安全性$0.30$、用户用力$0.25$、成本$0.25$、尺寸$0.20$，在 1–5 标度上的评分为

| 准则（权重） | C1 | C3 | C4 |
|---|---|---|---|
| 安全性（0.30） | 4 | 3 | 4 |
| 用户用力（0.25） | 4 | 5 | 2 |
| 成本（0.25） | 3 | 2 | 5 |
| 尺寸（0.20） | 3 | 2 | 4 |

计算加权得分。
::: solution
由[[#eq-weighted]]：
$S_{C1} = 0.30\cdot4 + 0.25\cdot4 + 0.25\cdot3 + 0.20\cdot3 = 1.20 + 1.00 + 0.75 + 0.60 = 3.55$。
$S_{C3} = 0.90 + 1.25 + 0.50 + 0.40 = 3.05$。
$S_{C4} = 1.20 + 0.50 + 1.25 + 0.80 = 3.75$。
C4 排第一，C1 第二，C3 第三。C4 与 C1 之间的差距为$0.20$，而标度的步长为$1$——小于单个评分的不确定度乘以其权重（$0.25\times1 = 0.25$），因此前两名的排序是脆弱的，需要进行下一节的敏感性检查。合理性检查：所有得分都在最低评分和最高评分之间，加权平均必然如此。
:::
:::

## 对权重的敏感性 {#sec-sensitivity}

权重是评分矩阵中最不确定的输入：不同的人，或者同一些人在不同的日子，会给出不同的权重。只有当排序在合理的变化下保持不变时，决策才是稳健的。

::: proposition 盈亏平衡权重 {#prop-breakeven}
让一项准则$k$的权重$u$从 0 变到 1，其他权重按比例缩放，使它们之和为$1 - u$。则每个得分都是$u$的线性函数，
$$
S_j(u) = u\,r_{kj} + (1 - u)\,\bar R_j,\qquad \bar R_j = \frac{\sum_{i\ne k} w_i r_{ij}}{\sum_{i\ne k} w_i},
$$
且概念$A$和$B$在**盈亏平衡权重**
$$
u^{*} = \frac{\bar R_A - \bar R_B}{(\bar R_A - \bar R_B) - (r_{kA} - r_{kB})},
$$ {#eq-breakeven}
处得分相等，前提是$0 \le u^* \le 1$；否则对$u$的每一个值，总是同一个概念较好。
:::

::: proof
把其他权重缩放为$w_i(1 - u)/\sum_{i\ne k}w_i$，得分为$u\,r_{kj} + (1 - u)\bar R_j$，它是$u$的线性函数。令$S_A(u) = S_B(u)$：$u(r_{kA} - r_{kB}) + (1 - u)(\bar R_A - \bar R_B) = 0$，即$u[(r_{kA} - r_{kB}) - (\bar R_A - \bar R_B)] = -(\bar R_A - \bar R_B)$，整理即得[[#eq-breakeven]]。两条直线至多相交一次，因此在交点以外，始终是同一个概念领先；若$u^*$位于$[0,1]$之外，它们在允许范围内不相交。
:::

::: example 用户用力要有多重要？ {#ex-sensitivity}
在[[#ex-weighted]]中，改变用户用力的权重$u$。求 C1 和 C3 超过 C4 时的权重。
::: solution
其他权重$(0.30, 0.25, 0.20)$之和为$0.75$。在安全性、成本和尺寸上的平均值：
$\bar R_{C1} = (0.30\cdot4 + 0.25\cdot3 + 0.20\cdot3)/0.75 = 2.55/0.75 = 3.400$；
$\bar R_{C3} = (0.90 + 0.50 + 0.40)/0.75 = 2.400$；
$\bar R_{C4} = (1.20 + 1.25 + 0.80)/0.75 = 4.333$。
C1 对 C4：$u^* = (3.400 - 4.333)/[(3.400 - 4.333) - (4 - 2)] = (-0.933)/(-2.933) = 0.318$。
C3 对 C4：$u^* = (2.400 - 4.333)/[(2.400 - 4.333) - (5 - 2)] = (-1.933)/(-4.933) = 0.392$。
因此，当用户用力的权重低于$0.318$时，C4 保持第一；在$0.318$与$0.5$之间 C1 领先（C1 与 C3 在$u = 0.5$处持平）；高于$0.5$时 C3 领先。当前权重为$0.25$，只比第一个转折点低$0.07$。在作出承诺之前，团队应当向用户核实用力到底有多重要——例如让几位用户用 C1 和 C4 的实物模型压扁一袋罐子。在$u = 0.25$处检查：$S_{C4} = 0.25\cdot2 + 0.75\cdot4.333 = 3.75$ ✓（与[[#ex-weighted]]相同）。
:::
:::

## 支配与帕累托前沿 {#sec-pareto}

有些比较根本不需要权重。如果概念 A 在每项准则上都至少与概念 B 一样好，并在某一项上严格更好，那么任何希望每种好东西都越多越好的人都不应选择 B。

::: definition 支配与帕累托最优 {#def-pareto}
设待最小化的准则为$f_1,\dots,f_m$（待最大化的准则改变符号），若对所有$i$有$f_i(A) \le f_i(B)$，且至少对一个$i$有$f_i(A) < f_i(B)$，则称概念$A$**支配**概念$B$。不被任何其他概念支配的概念称为**帕累托最优的**（非支配的）；它们的准则向量的集合称为**帕累托前沿**。
:::

::: proposition 加权和选出帕累托最优概念 {#prop-pareto}
若所有权重都严格为正，则在候选集合上使$\sum_i w_i f_i$最小的每一个概念都是帕累托最优的。
:::

::: proof
设$A$使加权和最小，却被某个$B$支配：对所有$i$有$f_i(B) \le f_i(A)$，且至少对一个$i = k$严格不等式成立。乘以$w_i > 0$并相加，得$\sum_i w_if_i(B) < \sum_i w_if_i(A)$，因为第$k$项严格更小，而没有一项更大。这与$A$的最小性矛盾。
:::

逆命题不成立：位于前沿“凹陷”处（前沿非凸之处）的帕累托最优概念，无论权重如何选择，都不会使任何加权和最小。因此加权评分永远不会推荐这样的概念，尽管有些决策者可能更喜欢它。把候选方案画在两个最重要准则构成的平面上，是看出这一点的最简单的方法。

::: example 支架的质量与成本 {#ex-pareto}
一个车辆支架的六个概念的估计质量和单件成本为
A $(1.2\,\mathrm{kg}, £18)$、B $(0.8\,\mathrm{kg}, £30)$、C $(1.5\,\mathrm{kg}, £15)$、D $(1.3\,\mathrm{kg}, £25)$、E $(0.9\,\mathrm{kg}, £26)$、F $(2.0\,\mathrm{kg}, £14)$。
(a) 哪些概念被支配？(b) 若每减轻一千克对客户来说值$\lambda$英镑（在车辆寿命期内节省的燃油），则总值为$\text{成本} + \lambda\,m$。在$\lambda = £20/\mathrm{kg}$和$\lambda = £50/\mathrm{kg}$时哪个概念最好？每个概念在$\lambda$的什么范围内最好？
::: solution
(a) D 被 A 支配（更轻，$1.2 < 1.3\,\mathrm{kg}$，且更便宜，£18 < £25）。没有其他概念被支配：从 F 到 C 到 A 到 E 到 B，质量递减而成本递增。帕累托前沿为 {F, C, A, E, B}。
(b) 对于$\lambda = 20$：总值 A $18 + 24 = 42$，B $46$，C $45$，D $51$，E $44$，F $54$；A 最好。对于$\lambda = 50$：A $78$，B $70$，C $90$，D $90$，E $71$，F $114$；B 最好。
前沿上相邻的概念在$\lambda = \Delta\text{成本}/\Delta m$处交换位置：F→C 在$1/0.5 = 2$，C→A 在$3/0.3 = 10$，A→E 在$8/0.3 = 26.7$，E→B 在$4/0.1 = 40\,£/\mathrm{kg}$。因此低于 £2/kg 时 F 最好，2 到 10 之间 C 最好，10 到 26.7 之间 A 最好，26.7 到 40 之间 E 最好，高于 £40/kg 时 B 最好。正如[[#prop-pareto]]所要求的，D 对任何$\lambda$都不是最好的。合理性检查：交换值沿前沿递增，这意味着前沿是凸的，每个非支配概念都会在某个$\lambda$下被选中；在非凸前沿上，某个概念会被跳过。
:::
:::

## 风险与信息的价值 {#sec-uncertainty}

不成熟概念的评分和指标估计是不确定的，而且各个概念的不确定程度不同：经过验证的机构是可预测的，一种新的工作原理则可能彻底失败。按最可能的性能给一个有风险的概念评分，就把这一点掩盖了。决策分析提供了两种简单的工具。

::: definition 期望值与信息价值 {#def-evpi}
若一项决策以概率$p_k$导致价值为$V_k$（利润、成本、得分）的结果$k$，则其**期望值**为$\mathrm{EV} = \sum_k p_kV_k$。关于某个不确定量的**完全信息期望值**（EVPI）是*在*得知该量*之后*再作决策的期望值，减去*之前*作决策的最佳期望值；它永远不为负，并且是揭示该量的试验或样机所值的上限。
:::

::: example 承诺之前先做样机？ {#ex-evpi}
一个团队必须在概念 X 和概念 Y 之间作出选择。X 是经过验证的设计，项目期望价值为 £2.0 M；Y 采用一种新的密封原理。如果密封有效（概率$0.6$），Y 价值 £3.5 M；如果它在开发后期失效，团队必须在延误之后退回到 X，项目只值 £0.5 M。一台能揭示密封是否有效的样机花费 £0.2 M，并且能排进进度。团队应当怎么做？
::: solution
不做试验：$\mathrm{EV}(X) = 2.0$；$\mathrm{EV}(Y) = 0.6\times3.5 + 0.4\times0.5 = 2.1 + 0.2 = 2.3\,$M。Y 的期望值较高，但有$40\,\%$的可能最终只得到 £0.5 M，而不是确定的 £2.0 M。
先获得完全信息：如果密封有效，选 Y（3.5）；如果无效，在作出承诺之前选 X（2.0）。$\mathrm{EV} = 0.6\times3.5 + 0.4\times2.0 = 2.9\,$M。EVPI $= 2.9 - 2.3 = 0.6\,$M。
样机花费 £0.2 M，少于它可能价值的 £0.6 M；先试验的净期望值为$2.9 - 0.2 = 2.7\,$M $> 2.3$。应当先制作样机，再作决定。这就是“先试验概念中风险最大的特征”这一一般建议的定量形式。合理性检查：EVPI（$0.6$）等于失效概率（$0.4$）乘以它所避免的损失（$2.0 - 0.5 = 1.5$），当信息只在失效情况下改变决策时，理应如此。
:::
:::

::: warning 精确不等于准确
一个报告$S = 3.547$对$3.512$的评分矩阵看起来是决定性的，其实不然。1–5 标度上的评分是判断，其不确定度至少为$\pm 1$；权重的不确定度为百分之几。在相信一个排序之前，(i) 检查胜出者是否被支配或接近被支配，(ii) 把每个重要权重变到其盈亏平衡值（[[#prop-breakeven]]），(iii) 把最不确定的评分改变一档，(iv) 追问什么*信息*会改变决策。如果排序是脆弱的，选择会议的正确产出就不是一个胜出者，而是一份试验计划。
:::

## 用早期建模区分概念 {#sec-modelling}

最不确定的评分，往往正是一个简单的物理模型就能解决的那些：这个概念会足够轻、足够刚硬、足够快吗？在概念阶段写几行力学计算，比一个精细的评分矩阵更有价值。目的是建立一个能抓住尺度规律的模型——属性如何依赖于概念的自由选择——而不是一个详细设计。

::: proposition 刚度受限梁的质量 {#prop-index}
给定长度$L$的悬臂梁必须承受端部载荷$F$，端部挠度不超过$\delta$。(a) 若其横截面为边长$b$可自由选择的实心正方形，则最小质量正比于$\rho/E^{1/2}$。(b) 若其为平均直径固定、壁厚$t$可自由选择的薄壁管，则最小质量正比于$\rho/E$。这里$\rho$为材料的密度，$E$为其弹性模量。
:::

::: proof
悬臂梁的端部挠度为$\delta = FL^3/(3EI)$（[[mechanics-of-materials]]），因此刚度要求为$I \ge FL^3/(3E\delta)$。(a) 对于实心正方形，$I = b^4/12$，质量为$m = \rho L b^2 = \rho L\sqrt{12 I}$。在最小的$I$处，$m = \rho L\sqrt{12FL^3/(3E\delta)} = 2L^{5/2}\sqrt{F/\delta}\,\rho/E^{1/2}$。(b) 对于平均半径为$r$的薄壁管，$I \approx \pi r^3t$，$m \approx 2\pi r t L\rho = 2LI\rho/r^2$；在最小的$I$处，$m = 2FL^4\rho/(3E\delta r^2)$，正比于$\rho/E$。比例常数只取决于载荷和几何，而它们对所有材料都相同。所作的假设是：线弹性、细长梁理论、受刚度而非强度限制，以及（对管而言）壁足够薄（可用薄壁近似）而又不发生局部屈曲。
:::

::: example 钢还是铝？取决于概念 {#ex-index}
对于一个刚度受限的臂，就[[#prop-index]]的两个概念比较钢（$E = 210\,\mathrm{GPa}$，$\rho = 7850\,\mathrm{kg/m^3}$）和铝合金（$E = 70\,\mathrm{GPa}$，$\rho = 2700\,\mathrm{kg/m^3}$；典型手册值）。
::: solution
(a) 尺寸自由的实心正方形：$m_{\text{Al}}/m_{\text{钢}} = (2700/\sqrt{70})/(7850/\sqrt{210}) = 322.7/541.7 = 0.596$。铝节省约$40\,\%$的质量。
(b) 直径固定的管：$m_{\text{Al}}/m_{\text{钢}} = (2700/70)/(7850/210) = 38.57/37.38 = 1.03$。两种材料给出的质量实际上相同。
是概念决定了比较的结果。当截面可以增大时，轻而刚度较低的材料胜出，因为弯曲刚度随尺寸增长（$I \propto b^4$）比质量（$\propto b^2$）快；当外形由安装空间固定时，只有壁厚可以改变，$I$和$m$都随$t$线性增长，于是只有比模量$E/\rho$起作用——而钢和铝的比模量几乎相同。阿什比（Ashby）的材料指数推广了这一推理（[[materials-science]]）。合理性检查：比值是无量纲的，而 (b) 的结果反映了大多数结构金属的$E/\rho$几乎相等这一众所周知的事实（两者都约为$\approx 26\,\mathrm{MJ/kg}$）。
:::
:::

## 综合的陷阱 {#sec-pitfalls}

评分方法把许多判断合成一个数字，而有些合成方法是不可靠的。有三个问题值得了解。

**投票循环。** 如果团队通过两两之间的多数投票对概念排序，即使每个成员的偏好都是一致的，群体的偏好也可能是循环的。三名工程师对三个概念的排序分别为$A \succ B \succ C$、$B \succ C \succ A$和$C \succ A \succ B$。多数人（第一名和第三名）偏好 A 甚于 B，多数人（第一名和第二名）偏好 B 甚于 C，而多数人（第二名和第三名）偏好 C 甚于 A。结果取决于各对方案付诸表决的顺序。肯尼斯·阿罗（Kenneth Arrow）的不可能性定理（1951年）表明，对三个或更多备选方案，没有任何综合个人排序的方法能在所有情况下满足一小组合理的条件。乔治·黑兹尔里格（George Hazelrigg）在1996年认为，这动摇了工程设计中的多准则评分方法；另一些人则回应说，为单个决策者综合各项准则与综合投票者并不是一回事。实际的教训是没有争议的：不要通过反复的两两投票来作决定，并使决策的依据（权重、评分及其来源）保持明确。

**重复计算。** 衡量同一事物的准则——“质量小”和“便于携带”，或者“零件少”和“装配成本低”——使该属性获得了两份权重。在加权之前要检查准则是否有重叠。

**没有锚点的得分。** 除非标度有锚点（“3 = 与基准相同”，或通过[[#eq-value]]对应到某个指标值），否则“4”分毫无意义。没有锚点的评分会向中间漂移，并向评分者本来就偏爱的方案漂移。

::: quiz
概念 P 在成本和安全性上胜过概念 Q，在其他每项准则上都持平。一位同事提议调整权重，看看 Q 是否仍有可能胜出。正确的回应是什么？
- [ ] 做敏感性研究；在合适的权重下 Q 可能胜出。
- [x] 没有必要：P 支配 Q，因此对任何正的权重 Q 都不可能胜出。
- [ ] 改用普氏矩阵，它能更好地处理持平。
- [ ] 把持平的准则权重设为零并重新计算。
::: solution
P 在每项准则上都至少与 Q 一样好，并在两项上严格更好，因此它支配 Q。由[[#prop-pareto]]的论证，对任何严格为正的权重，P 的得分都高于 Q（对非负权重则至少一样高）。可以把 Q 从比较中去掉——除非遗漏了某项准则，这一点值得问一问。
:::
:::

::: history
斯图尔特·普（Stuart Pugh）是一位后来成为斯特拉斯克莱德大学工程设计教授的工程师，他在论文《概念选择：一种行之有效的方法》（“Concept selection: a method that works”，1981年）和著作《全面设计》（*Total Design*，1991年）中介绍了他的概念选择方法。肯尼斯·阿罗（Kenneth Arrow）在《社会选择与个人价值》（*Social Choice and Individual Values*，1951年）中证明了不可能性定理；乔治·黑兹尔里格（George Hazelrigg）1996年在 ASME《机械设计杂志》（*Journal of Mechanical Design*）上发表的论文讨论了它对工程设计的含义，他1998年的“基于决策的工程设计框架”引发了一场关于设计中评分方法之基础的长期争论。帕累托最优的思想来自经济学家维尔弗雷多·帕累托（Vilfredo Pareto）1900年前后的工作；用性能指数分析材料选择的方法则由迈克尔·阿什比（Michael Ashby）在《机械设计中的材料选择》（*Materials Selection in Mechanical Design*，第1版1992年）中加以系统化。
:::

::: summary
- 用普氏矩阵（相对基准的 +、S、−）筛选大量概念；剔除，混合以消除弱点，更换基准，重复。
- 用$S_j = \sum_i w_i r_{ij}$对少数候选方案评分；为评分设置锚点，最好通过从临界指标值到理想指标值的价值函数。
- 权重是其准则标度全范围的重要程度：对一项准则重新标定，等同于改变其权重。
- 得分是任意一个权重的线性函数；盈亏平衡权重$u^*$表明一个权重在排序改变之前能移动多远。
- 被支配的概念无需任何权重即可剔除；正权重的加权和总是选出帕累托最优概念，但并非每个帕累托最优概念都能以这种方式被选出。
- 对有风险的概念，使用期望值和信息价值；费用低于 EVPI 的试验通常值得先做。
- 简单的物理模型（例如刚度受限梁的$m \propto \rho/E^{1/2}$或$\rho/E$）往往比精细的得分更能区分概念，而结果取决于概念的自由变量。
- 避免两两投票、重复计算和没有锚点的标度；报告排序时一并报告其敏感性。
:::

## 习题

::: exercise 普氏净得分 {#exr-pugh level=1 check="2"}
相对于基准，某概念在八项准则上的评定为$+, +, -, S, -, +, S, +$。它的净得分是多少？（输入该数。）
::: solution
四个加号，两个减号：净得分$4 - 2 = +2$。
:::
:::

::: exercise 一个加权得分 {#exr-weighted level=1 check="3.45"}
某概念在权重为$0.40$、$0.35$和$0.25$的三项准则上的评分分别为 3、5 和 2。它的加权得分是多少？（输入$S$。）
::: solution
$0.40\times3 + 0.35\times5 + 0.25\times2 = 1.20 + 1.75 + 0.50 = 3.45$。
:::
:::

::: exercise 统计帕累托前沿 {#exr-pareto level=1 check="4"}
六个概念的（质量 kg，成本 £）为：P $(3, 40)$、Q $(2.5, 55)$、R $(4, 35)$、S $(3.5, 45)$、T $(2, 70)$、U $(3, 50)$；两者都要最小化。有多少个概念是非支配的？（输入该数。）
::: solution
S 被 P 支配（$3 < 3.5$，$40 < 45$）；U 被 P 支配（质量相等，$40 < 50$）。P、Q、R 和 T 不被支配：按质量排序为 T $(2, 70)$、Q $(2.5, 55)$、P $(3, 40)$、R $(4, 35)$，质量增加时成本下降。共四个概念。
:::
:::

::: exercise 一个盈亏平衡权重 {#exr-breakeven level=2 check="0.4"}
概念 A 在准则$k$上得 5 分，在其他准则上的平均值为$\bar R_A = 2$；概念 B 在$k$上得 2 分，$\bar R_B = 4$。准则$k$的权重$u$高于多少时 A 的得分较高？（输入$u$。）
::: solution
由[[#eq-breakeven]]，$u^* = (2 - 4)/[(2 - 4) - (5 - 2)] = (-2)/(-5) = 0.4$。检查：$u = 0.4$时，$S_A = 0.4\times5 + 0.6\times2 = 3.2$，$S_B = 0.4\times2 + 0.6\times4 = 3.2$ ✓；$u > 0.4$时，在$k$上评分较高的 A 领先。
:::
:::

::: exercise 一个价值函数 {#exr-value level=2 check="0.625"}
设计要求给出的临界质量为$12\,\mathrm{kg}$，理想质量为$8\,\mathrm{kg}$。某概念的估计质量为$9.5\,\mathrm{kg}$。它在线性价值函数[[#eq-value]]上的评分是多少？（输入 0 到 1 之间的$v$。）
::: solution
$v = (9.5 - 12)/(8 - 12) = (-2.5)/(-4) = 0.625$。
:::
:::

::: exercise 这个试验值得做吗？ {#exr-evpi level=2 check="0.4"}
概念 X 确定价值 £1.0 M。如果一种新机构有效（概率$0.5$），概念 Y 价值 £2.4 M；如果它在后期失效，则价值 £0.2 M。关于该机构的完全信息期望值是多少？一项 £0.3 M 的试验值得做吗？（以 £M 输入 EVPI。）
::: solution
无信息时：$\mathrm{EV}(Y) = 0.5\times2.4 + 0.5\times0.2 = 1.3 > 1.0$，因此选 Y，$\mathrm{EV} = 1.3$。有完全信息时：$0.5\times2.4 + 0.5\times1.0 = 1.7$。EVPI $= 1.7 - 1.3 = 0.4\,$M。如果试验接近于决定性的，那么一项花费 £0.3 M 的试验是值得做的：净值$1.7 - 0.3 = 1.4 > 1.3$。检查：EVPI $= 0.5\times(1.0 - 0.2) = 0.4$ ✓。
:::
:::

::: exercise 管还是实心截面？ {#exr-index level=3 check="0.41"}
一个刚度受限的悬臂臂可以用钢制造，也可以用沿臂方向$E = 100\,\mathrm{GPa}$、$\rho = 1550\,\mathrm{kg/m^3}$的碳纤维增强聚合物制造（两者都按各向同性梁处理）。(a) 对于直径固定的薄壁管，质量比$m_{\text{CFRP}}/m_{\text{钢}}$是多少（保留两位小数）？(b) 如果截面是尺寸自由的实心正方形，CFRP 的优势是更大还是更小？(c) 为第三个概念导出指数：宽度$b$固定、高度$h$自由的矩形截面。（输入 (a) 的比值。）
::: solution
(a) $\rho/E$：钢$7850/210 = 37.38$；CFRP $1550/100 = 15.50$（单位为$\mathrm{kg\,m^{-3}\,GPa^{-1}}$）。比值$15.50/37.38 = 0.4147$，即$0.41$。
(b) $\rho/E^{1/2}$：钢$7850/\sqrt{210} = 541.7$；CFRP $1550/\sqrt{100} = 155.0$；比值$0.286$。优势更大（节省$71\,\%$而不是$59\,\%$），因为刚度较低的材料还可以采用更大的截面。
(c) 由$I = bh^3/12 \ge FL^3/(3E\delta)$得$h \propto E^{-1/3}$，而$m = \rho Lbh \propto \rho/E^{1/3}$。概念增大截面的自由度越大，$E$上的指数就越小，低密度材料就越受青睐。
:::
:::

::: exercise 为爬楼手推车选择概念 {#exr-design level=3}
取[[design-process/concept-generation]]最后一道习题中的三个概念（或者为你选定的某种产品自拟三个概念）。(a) 用普氏矩阵对照一个基准（传统的麻袋手推车）对它们进行筛选。(b) 建立一个至少有五项准则的加权评分矩阵，评分要有锚点，权重要有依据。(c) 求出你最没有把握的那项准则的盈亏平衡权重。(d) 指出最不确定的那一个评分，提出能解决它的模型或试验，并说明其费用是否合理。
::: solution
答案会各不相同；好的答案具有以下特点。(a) 基准是具体的，并画到相同的详细程度；每个 + 或 − 都用一句话说明理由；在某概念的减号可以通过借用另一特征消除的地方，提出混合概念。(b) 准则来自设计要求且互不重叠（例如爬楼时的手推力、质量、防溜车安全性、成本、折叠尺寸）；防溜车要求作为通过/不通过的约束处理，而不是加权准则；评分通过价值函数锚定到指标估计值（例如手推力：临界值$150\,\mathrm N$，理想值$80\,\mathrm N$）。(c) 盈亏平衡计算使用[[#eq-breakeven]]，并说明决策是否稳健。(d) 通常最不确定的评分是手动三星轮概念的手推力；先作一个快速估算（载荷对台阶边缘的力矩除以把手的力臂），再在真实楼梯上用木制实物模型试一试，只需几个小时，却可能改变决策，因此其信息价值很高。
:::
:::

## 延伸阅读

乌尔里希（Ulrich）、埃平格（Eppinger）与杨（Yang）的《产品设计与开发》（*Product Design and Development*，第7版，2020年）把概念筛选和概念评分作为一个两阶段过程来介绍，并给出实用建议。普的《全面设计》（*Total Design*，1991年）用他自己的话解释了受控收敛。克罗斯（Cross）的《工程设计方法》（*Engineering Design Methods*，第5版，2021年）讨论了加权目标法及其陷阱；阿什比的《机械设计中的材料选择》（*Materials Selection in Mechanical Design*）把[[#prop-index]]中的性能指数发展成为在概念阶段选择材料的完整方法。
