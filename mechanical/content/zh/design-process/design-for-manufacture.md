一件制成品的大部分成本，在工厂里任何人见到它之前就已经决定了。一旦设计者选定了零件的数目、材料、形状和公差，以及它们的连接方式，能够制造它们的工艺和装配它们所需的时间也就随之而定；此后制造工程师可以优化进给量、夹具和生产线布置，但只能在设计所设定的范围之内。**面向制造的设计**（design for manufacture，DFM）是选择材料、工艺、形状和公差，使每个零件都能以低成本、稳定一致地制造出来的做法；**面向装配的设计**（design for assembly，DFA）是减少零件数目、并使保留下来的零件易于抓取和插装的做法。两者合称**面向制造与装配的设计**（DFMA），是设计团队降低成本最有效的工具之一，而且它们往往还能提高质量，因为零件越少、操作越简单，出错的机会就越少。

本讲建立一个简单的**单件成本模型**，并用它按生产批量在工艺之间作出选择；介绍布斯罗伊德—杜赫斯特（Boothroyd–Dewhurst）DFA 方法及其最少零件判据和设计效率；汇集常用工艺——切削加工、注塑成形、铸造和钣金——的设计准则，并附两个小的定量模型（注塑冷却时间和悬臂卡扣）；最后讨论 DFMA 如何融入设计过程。本讲承接[[design-process/embodiment-design]]；工艺本身在[[manufacturing]]中介绍，材料选择在[[materials-science]]中介绍。

## 零件的成本从何而来 {#sec-cost}

::: definition 单件成本及其组成 {#def-unit-cost}
以一批或一次生产$N$个零件时，零件的**单件成本**模型为
$$
C = C_m + C_p + \frac{C_t}{N},
$$ {#eq-unit-cost}
其中$C_m$是每个零件的**材料成本**（包括废料），$C_p$是每个零件的**加工成本**（机床和人工时间乘以小时费率，包括分摊的间接费用），$C_t$是**专用工装与调整准备成本**——模具、冲模、夹具、编程——它对这一批生产只发生一次，并分摊到全部$N$个零件上。$C_m + C_p$是每个零件的**变动成本**；$C_t$是**固定**（非经常性）成本。
:::

这个模型是一种简化：工装会磨损，在一定数量的零件之后必须更换；加工费率取决于批量（大批量生产线是自动化的）；间接费用按会计规则分摊，可能并不反映真实成本。但它抓住了工艺之间的基本权衡。专用工装昂贵的工艺——压铸、注塑成形、锻造、冲压——变动成本低；几乎不需要专用工装的工艺——用棒料切削加工、砂型铸造、焊接构件制造、增材制造——变动成本高。哪一种更便宜取决于$N$。

::: proposition 两种工艺之间的交叉批量 {#prop-crossover}
设工艺 1 的变动成本为$v_1 = C_{m1} + C_{p1}$，工装成本为$C_{t1}$；工艺 2 的变动成本$v_2 < v_1$，工装成本$C_{t2} > C_{t1}$。则工艺 2 的单件成本较低，当且仅当
$$
N > N^* = \frac{C_{t2} - C_{t1}}{v_1 - v_2}.
$$ {#eq-crossover}
:::

::: proof
由[[#eq-unit-cost]]，$C_2 < C_1 \iff v_2 + C_{t2}/N < v_1 + C_{t1}/N \iff (C_{t2} - C_{t1})/N < v_1 - v_2$。由假设两边都为正，因此乘以$N/(v_1 - v_2) > 0$得$N > (C_{t2} - C_{t1})/(v_1 - v_2)$。在$N = N^*$处单件成本相等。若改为$v_2 < v_1$且$C_{t2} \le C_{t1}$，则工艺 2 在任何批量下都更便宜，不存在交叉点。
:::

::: example 切削加工还是压铸壳体？ {#ex-crossover}
一个小型铝制齿轮箱壳体可以在数控加工中心上用棒料切削加工，也可以压铸后再对轴承孔进行精加工。估计成本为：

| | 材料 $C_m$ | 加工 $C_p$ | 工装 $C_t$ |
|---|---|---|---|
| 用棒料数控加工 | 4.00 | 18.00 | 1 500 |
| 压铸 + 精加工 | 2.50 | 3.50 | 60 000 |

（单位为每个零件的货币单位；数控加工的工装是夹具和程序，铸造的工装是压铸模和夹具。）求交叉批量，以及$1\,000$件和$10\,000$件时的单件成本。
::: solution
变动成本：$v_1 = 22.00$，$v_2 = 6.00$。由[[#eq-crossover]]，
$$
N^* = \frac{60\,000 - 1\,500}{22.00 - 6.00} = \frac{58\,500}{16.00} = 3\,656.25,
$$
因此从$3\,657$件起压铸更便宜。

$N = 1\,000$时：数控加工$22.00 + 1.50 = 23.50$；压铸$6.00 + 60.00 = 66.00$。$N = 10\,000$时：数控加工$22.00 + 0.15 = 22.15$；压铸$6.00 + 6.00 = 12.00$。

**合理性检查。** 在$N^*$处两者都约为$22.41$ ✓。数控加工成本几乎不随$N$变化（工装所占份额很小），而铸造成本急剧下降，直到工装成本变得可以忽略。决策还取决于模型以外的因素：压铸模需要数周才能制成，压铸模一旦制成，设计就更难更改，而且压铸会带来机加工件所没有的气孔和拔模斜度。一种常见的做法是在制造压铸模期间，先用切削加工生产最初的几百个零件。
:::

### 选择工艺

候选工艺的初选清单由零件的几项属性决定：**材料**类别（并非每种工艺都能加工每种材料——压铸用于铝、锌、镁等低熔点合金；注塑成形用于热塑性塑料）、**形状**（棱柱形、回转体、薄壁、中空）、**尺寸**和质量、所要求的**公差**和**表面粗糙度**，以及**生产批量**。阿什比（Ashby）的工艺选择图把各类工艺的这些属性绘在图上，使初选清单可以系统地得出；然后再用单件成本模型对留下的工艺排序。粗略的指导如下：

- **切削加工**（车削、铣削、钻削、磨削）能达到最高的精度和最低的表面粗糙度，几乎不需要专用工装，但速度慢且浪费材料。它适用于小批量、样机，以及用其他工艺制造的零件上的精密特征。
- **铸造**一步就能得到复杂的形状。砂型铸造工装便宜，适用于小批量的大型零件；熔模铸造能得到精细的细节；压力铸造需要昂贵的压铸模，适用于大批量的有色金属零件。
- **成形**——锻造、挤压、板料冲压和折弯——能快速生产出强度高的零件，但需要模具，其成本必须分摊到大批量上（简单的折弯机折弯是例外）。
- 聚合物的**注塑成形**工装成本极高而变动成本极低；在大批量下，它往往是制造复杂零件最便宜的方法，并且能把许多特征（卡扣、铰链、凸台、加强筋）集成到一个零件中。
- **增材制造**不需要零件专用的工装，能制造其他任何工艺都做不出的形状，但每个零件的变动成本高；它适用于样机、小批量以及几何形状能带来功能优势的零件。

## 面向装配的设计 {#sec-dfa}

装配往往占产品成本的很大一部分，而每个零件都会两次增加成本：一次是它自身的制造，一次是被抓取、定向、插装和紧固。它还会增加库存、文件、采购、检验以及可能出错的环节数。因此，DFA 最有力的问题不是“这个零件怎样才能更容易地装配？”，而是“这个零件需要存在吗？”

::: definition 理论最少零件数 {#def-min-parts}
在布斯罗伊德—杜赫斯特方法中，按装配顺序用三个问题检验每个零件。除非至少有一个回答为“是”，否则该零件就是**可去除的候选**（通过与另一零件合并或干脆取消）：
1. 在产品工作过程中，该零件是否相对于所有已装配的其他零件**运动**？（只算大的运动；能由一个整体式弹性元件提供的微小弹性运动不算。）
2. 该零件是否必须采用与所有已装配的其他零件**不同的材料**，或者必须与它们**隔离**？（只限于根本性的原因：电绝缘或隔热、耐磨性、其他材料无法提供的某种性能。）
3. 该零件是否必须与所有已装配的其他零件**分开**，因为否则其他零件必要的**装配或拆卸**就不可能进行？

至少通过一项检验的零件数就是**理论最少零件数**$N_\text{min}$。第一个装配的零件（基础件）总是计入。紧固件、连接件和隔套几乎总是三项检验都通不过。
:::

这些判据有意定得很严。它们确定的是理论最小值；一个零件是否真的应该去除，取决于成本、实际约束（必须维修的零件、供应商的分工边界、外购的标准部件）以及可用的工艺。它们的价值在于迫使设计者为每个零件说明存在的理由。

::: definition 设计效率 {#def-design-efficiency}
手工装配的布斯罗伊德—杜赫斯特**设计效率**（DFA 指数）为
$$
E_\text{ma} = \frac{N_\text{min}\, t_a}{t_\text{ma}},
$$ {#eq-dfa-index}
其中$t_\text{ma}$是估计的手工装配总时间，$t_a = 3\,\mathrm s$是在他们的数据中抓取并插装一个理想零件所需的时间——这种零件小、对称、易于抓取、无需定向，插装时没有阻力也无需紧固。只含$N_\text{min}$个理想零件的产品将得到$E_\text{ma} = 1$。
:::

每个零件的装配时间是**抓取**时间（抓住、定向、移到工作点）与**插装**时间（放置和紧固）之和。在完整的方法中，两者都从按零件特征分类代码编排的表格中查得：零件绕插入轴线和垂直于插入轴线的对称性、尺寸和厚度、是否会套叠或缠结、是否需要工具或双手、可达性是否受阻、放置下一个零件时是否必须按住它，以及是通过拧螺纹、铆接还是弯折来紧固。螺纹紧固件特别费时，因为在抓取和插装之外，拧紧还要花好几秒钟。

::: algorithm 手工装配的 DFA 分析 {#alg-dfa}
1. 取得图样或样机，并把产品拆开（实际拆开或在头脑中拆开），按装配顺序记录零件和部件。
2. 对每个零件，记录相同零件的数目，估计抓取和插装时间（完整方法中从表格查得），并应用三个最少零件问题。
3. 把时间相加得到$t_\text{ma}$，统计$N_\text{min}$，并由[[#eq-dfa-index]]计算$E_\text{ma}$。
4. 重新设计：首先去除或合并三项问题都通不过的零件——特别是紧固件——然后改善保留零件的抓取和插装（对称性、倒角和导向结构、自定位特征、无需翻转的自上而下装配、用卡扣代替螺钉）。
5. 重新分析新设计，并估算零件的制造成本：合并后的零件更复杂，而总成本仍必须更低。
:::

::: example 风扇电动机安装座的 DFA {#ex-dfa}
一个小型风扇电动机安装座由以下零件组成：钢板底板；电动机；两个电动机螺钉；一个固定电动机后端的支架；两个支架螺钉；一个为便于维修而必须可拆卸的盖子；四个盖子螺钉；一个电缆夹；以及一个在电缆穿过底板处保护电缆的橡胶护圈。估计每项的抓取加插装时间（秒）为：底板 3.5，电动机 8.0，每个螺钉 8.0，支架 4.5，盖子 5.5，电缆夹 4.0，护圈 6.0。求$N_\text{min}$、装配时间和设计效率。然后评价一种重新设计：采用模塑底板，上面带有固定电动机的一体式卡扣和一体式电缆导槽，盖子则卡装上去。
::: solution
**最少零件。** 底板：第一个零件，计入。电动机：带运动件、材料不同的外购部件；计入。电动机螺钉、支架螺钉、盖子螺钉：紧固件——三项都通不过。支架：没有相对运动，可以与底板材料相同，也不需要分开；通不过。盖子：为了能维修电动机必须分开（问题 3）；计入。电缆夹：通不过（可以作为底板或盖子上的一个特征）。护圈：橡胶，出于根本性原因（保护电缆绝缘）而采用不同材料；计入。因此在$1 + 1 + 2 + 1 + 2 + 1 + 4 + 1 + 1 = 14$个零件中$N_\text{min} = 4$。

**时间。** $t_\text{ma} = 3.5 + 8.0 + 2(8.0) + 4.5 + 2(8.0) + 5.5 + 4(8.0) + 4.0 + 6.0 = 95.5\,\mathrm s$，其中$64\,\mathrm s$花在八个螺钉上。

**效率。** $E_\text{ma} = 4\times3/95.5 = 0.126$，约$13\,\%$。

**重新设计。** 模塑底板（3.5 s），电动机卡入一体式卡扣（估计 7.0 s），护圈（6.0 s），卡装式盖子（6.5 s，比以前略多，因为卡扣必须对准并压入）。四个零件，$t_\text{ma} = 23.0\,\mathrm s$，$E_\text{ma} = 12/23.0 = 0.52$。

**合理性检查。** 重新设计恰好有$N_\text{min}$个零件，因此其效率只受这些零件的时间限制；$E_\text{ma} \le 1$ ✓。装配时间的节省（每台$72.5\,\mathrm s$）必须按[[#prop-crossover]]的交叉点推理，与新底板注塑模的成本进行权衡；而且卡装式盖子仍必须能在不损坏卡扣的情况下拆下以便维修——这是对卡扣设计的一项要求。
:::

:::

::: warning 减少零件数并非没有代价
合并零件会使保留下来的零件更复杂。带一体式卡扣的模塑底板需要更昂贵的模具，可能还要侧抽芯；合并后的铸件可能需要更多切削加工；把易磨损特征与结构特征合在一起的零件，会在该特征磨损时迫使整个零件被更换。在宣布一项重新设计更好之前，一定要估算新零件的制造成本，以及对维修和回收的影响（[[design-process/sustainability]]）。DFA 减少的是零件数；必须降下来的是总成本——零件、工装、装配、质量、维修。
:::

## 常用工艺的设计准则 {#sec-rules}

设计准则概括了什么使零件易于或难以用某种工艺制造。它们是指导性原则，其数值取决于材料、机床和供应商；在冻结设计之前要与供应商核实。准则背后的原因比数字更重要。

**切削加工。**
- 规定功能所允许的最宽公差和最粗糙的表面粗糙度；更严的公差需要额外的走刀、磨削或检验。
- 优先采用标准刀具在少数几次装夹中就能加工到的特征：垂直于平面钻的孔，圆角半径不小于标准铣刀半径的内角（型腔中尖锐的内角是铣不出来的），除非必要不设倒扣（内凹槽）。
- 避免深而小的孔（钻头会偏斜和折断）和薄壁（会颤振和变形）。
- 从装夹零件所用的基准标注特征尺寸，并使重新装夹的次数尽量少。

**注塑成形。**
- 保持壁厚均匀。厚截面冷却慢，会延长周期并造成缩痕和空洞；壁厚突变会造成翘曲。把厚的部位挖空，用加强筋提供刚度。
- 给平行于开模方向的面设置**拔模斜度**，使零件能从模具中脱出。
- 避免需要侧抽芯或可折叠型芯的倒扣，除非它们能取代其他零件（一个省去两个螺钉的卡扣可以证明侧抽芯是合理的）。
- 内角倒圆，以减小应力集中并有助于熔体流动。

**铸造。** 道理类似：截面均匀、圆角充分，使金属顺序凝固而不出现热节（热节会造成缩松）；为取出模样或压铸模设置拔模斜度；只在需要的地方使用型芯；在功能面上留出加工余量。

**钣金。** 采用材料的标准厚度；使孔和切口与折弯处保持足够的距离，以免它们变形；折弯的内半径至少取该材料和厚度的推荐最小值；在折弯终止于边缘处加工止裂槽；设计能在板料上高效排样的展开图。折弯件的展开长度由**折弯补偿量**（bend allowance）即折弯处中性层的长度求得：
$$
BA = \theta\,(R + K t),
$$ {#eq-bend-allowance}
其中折弯角$\theta$以弧度计，$R$为内半径，$t$为厚度，$K$为经验的 **K 因子**（中性层到内侧的距离与厚度之比；视材料和$R/t$而定，通常约在 0.3 到 0.5 之间，最好采用折弯机供应商的数据）。

### 注塑成形的冷却时间

“壁要薄而均匀”这条准则有其定量依据。注塑成形周期的大部分时间都花在等待零件冷却到可以顶出上，而冷却是通过壁的非稳态导热。

::: proposition 注塑壁的冷却时间 {#prop-cooling}
一块厚度为$h$的塑料壁，初始温度为熔体温度$T_m$，两个表面都保持在模具温度$T_w$。只保留平壁级数解的第一项，中面冷却到顶出温度$T_e$所需的时间为
$$
t_c = \frac{h^2}{\pi^2\alpha}\,\ln\!\left(\frac{4}{\pi}\,\frac{T_m - T_w}{T_e - T_w}\right),
$$ {#eq-cooling}
其中$\alpha$为聚合物的热扩散率。冷却时间随壁厚的**平方**增长。
:::

::: proof
对于厚度为$h$（半厚度为$h/2$）、两个表面突然保持在$T_w$的平板，分离变量法的解在中面处给出
$$
\frac{T_c - T_w}{T_m - T_w} = \frac{4}{\pi}\sum_{k=0}^{\infty}\frac{(-1)^k}{2k+1}\exp\!\left(-\frac{(2k+1)^2\pi^2\alpha t}{h^2}\right).
$$
在所关心的时间范围内，第一项占主导（第二项衰减快九倍）。在第一项中令$T_c = T_e$并解出$t$，即得[[#eq-cooling]]。假设：物性为常数，通过壁的一维导热，与恒温模具表面完全接触，且没有结晶放热。非稳态导热的方法见[[heat-transfer]]。
:::

::: example 壁厚减半 {#ex-cooling}
一个零件用$\alpha = 1.0\times10^{-7}\,\mathrm{m^2/s}$的聚合物注塑成形，$T_m = 230\,^\circ\mathrm C$，$T_w = 50\,^\circ\mathrm C$，在中面温度为$90\,^\circ\mathrm C$时顶出。比较壁厚为$4\,\mathrm{mm}$和$2\,\mathrm{mm}$时的冷却时间。
::: solution
对数项为$\ln\!\left(\frac4\pi\times\frac{180}{40}\right) = \ln(5.73) = 1.746$。

对于$h = 4\,\mathrm{mm}$：$t_c = \dfrac{(4\times10^{-3})^2}{\pi^2\times1.0\times10^{-7}}\times1.746 = 16.2\times1.746 = 28.3\,\mathrm s$。

对于$h = 2\,\mathrm{mm}$：四分之一，$7.1\,\mathrm s$。

**合理性检查。** 温差只通过对数进入，因此结果对温差不敏感；厚度则以平方进入。几秒到几十秒的冷却时间是注塑成形的典型值，所以数量级是对的。壁厚减半使每个周期缩短约$21\,\mathrm s$——对于生产一百万个零件的模具，这约为 5 900 机时——这就是为什么要用加强筋而不是厚壁来获得刚度。
:::

### 卡扣

卡扣用一个弹性钩代替螺钉，该弹性钩在装配时发生挠曲，然后弹回到止挡后面。它们是在塑料零件中实现 DFA 所要求的取消紧固件的最常见方法。最简单的是等矩形截面的悬臂钩。

塑料供应商发布的设计指南给出：对于长度为$L$、厚度为$t$、端部挠度为$y$的悬臂，根部的最大表面应变为（简单梁理论，$\varepsilon = \sigma/E$，其中$\sigma = M/S$，$y = PL^3/(3EI)$）
$$
\varepsilon = \frac{3\,t\,y}{2\,L^2},
$$ {#eq-snap-strain}
它不得超过供应商为该牌号给出的**许用应变**（只装配一次的卡扣比反复装配的卡扣许用应变大）。设$b$为钩的宽度，$E_s$为该应变下的割线模量，则使钩挠曲所需的力为$P = b\,t^2E_s\varepsilon/(6L)$；把它推过角度为$\alpha$、摩擦因数为$\mu$的导入斜面所需的力为
$$
W = P\,\frac{\mu + \tan\alpha}{1 - \mu\tan\alpha}.
$$ {#eq-snap-force}

:::

::: example 确定悬臂卡扣的尺寸 {#ex-snap}
一个盖子由长$L = 15\,\mathrm{mm}$、厚$t = 1.8\,\mathrm{mm}$、宽$b = 8\,\mathrm{mm}$的悬臂卡扣固定，卡扣必须挠曲$y = 1.2\,\mathrm{mm}$才能越过止挡。供应商给出反复装配时的许用应变为$2\,\%$，该应变下的割线模量为$2.0\,\mathrm{GPa}$；斜面角为$30^\circ$，$\mu = 0.3$。校核应变并求每个卡扣的装配力。
::: solution
由[[#eq-snap-strain]]：$\varepsilon = 1.5\times1.8\times1.2/15^2 = 0.0144 = 1.44\,\%$，低于$2\,\%$ ✓。

挠曲力（mm 和 N/mm²）：$P = 8\times1.8^2\times2000\times0.0144/(6\times15) = 8.29\,\mathrm N$。

装配力：$(\mu + \tan\alpha)/(1 - \mu\tan\alpha) = (0.3 + 0.577)/(1 - 0.173) = 1.061$，故每个卡扣$W = 8.8\,\mathrm N$。有四个卡扣时，把盖子推到位约需$35\,\mathrm N$，用手很轻松。

**合理性检查。** 应变按$t/L^2$变化：长度减半的钩将承受四倍的应变，即$5.8\,\%$，太大了——这就是为什么卡扣钩做得又长又薄。对于可拆卸的盖子，止挡面还必须做成斜面，以便卡扣能在不损坏的情况下脱开（或者提供一种拆卸工具）。
:::

## 设计过程中的 DFMA {#sec-dfma-process}

DFM 和 DFA 在具体化设计中最为有效，此时架构和主要零件正在确定之中；而作为对完成图样的审查，它们的效果最差。一种实用的方法是：

1. 在概念设计和具体化设计期间，保持较少的零件数，并利用成本模型和工艺选择工具选择工艺。
2. 对第一版总体布局进行 DFA 分析，并请一位制造工程师参加；设定设计效率或零件数的目标。
3. 在形态设计和详细设计期间，使用针对具体工艺的准则，并征询供应商意见（**供应商早期介入**）。
4. 逐个零件估算成本（应有成本模型），并与报价进行比较。
5. 在订购工装之前再次评审，因为在那之后每一项更改都代价高昂。

DFMA 与其他面向 X 的设计目标相互影响。零件越少通常越有利于可靠性（可能失效的连接和接头更少，[[design-process/reliability-risk]]）；卡扣和一体式零件有利于装配，但除非设计成可脱开的，否则会妨碍拆卸和回收；由单一材料构成的合并零件有利于回收；紧固件越少可能使维修越复杂。设计团队必须有意识地平衡这些因素。

::: history
杰弗里·布斯罗伊德（Geoffrey Boothroyd）及其同事于20世纪70年代初在马萨诸塞大学阿默斯特分校开始研究装配的经济性；布斯罗伊德的《面向装配的设计——设计者手册》（*Design for Assembly — A Designer's Handbook*）于1980年在那里问世。他与彼得·杜赫斯特（Peter Dewhurst）自1981年起开发了该方法的计算机版本，并自1985年起在罗得岛大学继续这项工作。1991年，布斯罗伊德和杜赫斯特因开发面向制造与装配的设计并将其商品化而获得美国国家技术奖章。他们与温斯顿·奈特（Winston Knight）合著的《面向制造与装配的产品设计》（*Product Design for Manufacture and Assembly*）已出到第3版（2011年）。
:::

::: summary
- 单件成本$C = C_m + C_p + C_t/N$：工装成本高、变动成本低的工艺在交叉批量$N^* = (C_{t2} - C_{t1})/(v_1 - v_2)$以上胜出。
- 按材料、形状、尺寸、公差和批量初选工艺；用成本模型对它们排序。
- 布斯罗伊德—杜赫斯特 DFA：只有当一个零件相对于其他零件运动、出于根本性原因必须采用不同材料，或为了装配或拆卸必须分开时，才需要它。$E_\text{ma} = N_\text{min}\times3\,\mathrm s/t_\text{ma}$。
- 首先取消紧固件；然后使保留的零件易于抓取和插装。检查合并后的零件总体上是否仍然更便宜。
- 工艺准则：能用的最宽公差、标准刀具和少量装夹（切削加工）；均匀的薄壁、拔模斜度、加强筋（注塑和铸造）；折弯半径、孔距和止裂槽（钣金）。
- 注塑冷却时间$\propto h^2$；悬臂卡扣的根部应变为$\varepsilon = 1.5\,t\,y/L^2$，应保持在供应商的许用应变以下。
:::

## 习题

::: exercise 交叉批量 {#exr-crossover level=1 check="4000"}
工艺 A 的工装成本为 2 000，每个零件的变动成本为 12.00；工艺 B 的工装成本为 30 000，每个零件的变动成本为 5.00。生产批量高于多少时工艺 B 更便宜？（输入$N^*$。）
::: solution
$N^* = (30\,000 - 2\,000)/(12.00 - 5.00) = 28\,000/7.00 = 4\,000$件。恰好 4 000 件时两者的成本都是$12.00 + 0.50 = 12.50 = 5.00 + 7.50$ ✓。
:::
:::

::: exercise 注塑件的单件成本 {#exr-unit-cost level=1 check="1.55"}
一副注塑模花费 40 000。每个零件需要 0.30 的材料和 0.45 的机时费用。生产 50 000 件时的单件成本是多少？（以每件的货币单位输入$C$。）
::: solution
$C = 0.30 + 0.45 + 40\,000/50\,000 = 0.75 + 0.80 = 1.55$。在这一批量下，一半以上的成本是工装；若生产 500 000 件，则为$0.83$。
:::
:::

::: exercise 设计效率 {#exr-efficiency level=1 check="25"}
一个装配体的理论最少零件数为 5，估计手工装配时间为 60 s。它的布斯罗伊德—杜赫斯特设计效率是多少？（以百分数输入$E_\text{ma}$。）
::: solution
$E_\text{ma} = 5\times3/60 = 0.25 = 25\,\%$。
:::
:::

::: exercise 泵盖的最少零件数 {#exr-min-parts level=2 check="3"}
一个泵盖部件由以下零件组成：铸造泵盖、垫片、六个螺栓、六个垫圈、用两个铆钉固定的铭牌，以及压入泵盖、用于支承转轴的青铜轴承衬套。铭牌上的信息可以铸出或用激光标刻在泵盖上。应用三个最少零件问题，求$N_\text{min}$。（输入零件数。）
::: solution
泵盖：基础件，计入。垫片：出于根本性原因采用与铸造金属不同的柔性密封材料；计入。螺栓、垫圈、铆钉：紧固件；通不过。铭牌：其功能可以集成到泵盖中；通不过。衬套：必须采用不同的材料（与轴配合的青铜轴承表面，铸造泵盖无法提供）；计入。18 个零件中$N_\text{min} = 3$。实际上泵盖仍必须用螺栓连接到泵体上（它必须可拆卸），但分析指出了减少螺栓数、采用防脱螺栓或取消垫圈的方向。
:::
:::

::: exercise 卡扣的挠度 {#exr-snap level=2 check="1.28"}
一个等矩形截面的悬臂卡扣钩长$12\,\mathrm{mm}$、厚$1.5\,\mathrm{mm}$，材料为许用应变$2\,\%$的聚合物。它能设计成的最大端部挠度（倒扣深度）是多少？（以 mm 输入$y$。）
::: solution
由[[#eq-snap-strain]]，$y = \dfrac{2\varepsilon L^2}{3t} = \dfrac{2\times0.02\times144}{3\times1.5} = 1.28\,\mathrm{mm}$。
:::
:::

::: exercise 冷却时间与壁厚 {#exr-cooling level=2 check="2.25"}
一个注塑件的壁厚要从$3\,\mathrm{mm}$减小到$2\,\mathrm{mm}$，材料和温度不变。冷却时间缩短到原来的几分之一？（输入比值$t_{3\,\mathrm{mm}}/t_{2\,\mathrm{mm}}$。）
::: solution
由[[#eq-cooling]]，$t_c \propto h^2$：$(3/2)^2 = 2.25$。
:::
:::

::: exercise 折弯支架的展开长度 {#exr-bend level=2 check="54.08"}
一个 L 形支架用$1.5\,\mathrm{mm}$的板料折弯$90^\circ$，内半径为$2.0\,\mathrm{mm}$，K 因子为$0.40$。两段直边量到折弯起点处，分别长$30\,\mathrm{mm}$和$20\,\mathrm{mm}$。展开毛坯长度是多少？（以 mm 输入，保留两位小数。）
::: solution
$BA = \frac{\pi}{2}(2.0 + 0.40\times1.5) = 1.5708\times2.6 = 4.084\,\mathrm{mm}$。展开长度$= 30 + 20 + 4.084 = 54.084 \approx 54.08\,\mathrm{mm}$。检查：它介于两直边分别加上内弧长（$\frac\pi2\times2.0 = 3.14$）和外弧长（$\frac\pi2\times3.5 = 5.50$）所得的值之间 ✓。
:::
:::

::: exercise 成本模型中的工装更换 {#exr-tool-life level=3}
一副模具花费$C_t$，在生产$N_T$个零件后磨损报废，之后必须以同样的成本更换。(a) 写出生产$N$个零件时的单件成本。(b) 证明当$N \gg N_T$时单件成本趋于$v + C_t/N_T$，并解释这对在极大批量下比较工艺意味着什么。(c) 一副冲模花费 25 000，寿命为 400 000 件；变动成本为 0.12。求生产 1 000 000 件时的单件成本。
::: solution
(a) 所需模具数为$\lceil N/N_T\rceil$，故$C = v + C_t\lceil N/N_T\rceil/N$。

(b) $\lceil N/N_T\rceil/N$介于$1/N_T$与$1/N_T + 1/N$之间，因此当$N \to \infty$时它趋于$1/N_T$。这时工装表现为每个零件$C_t/N_T$的变动成本；[[#prop-crossover]]的交叉点分析必须把它计入，而且在极大批量下，耐用的工装（淬硬模或硬质合金模）尽管价格较高，却可能更便宜。

(c) $\lceil 10^6/4\times10^5\rceil = 3$副模具：$C = 0.12 + 3\times25\,000/10^6 = 0.12 + 0.075 = 0.195$。
:::
:::

::: exercise 一项 DFMA 重新设计 {#exr-redesign level=3}
一支手电筒包括：铝管筒身，带弹簧的螺纹铝尾盖，反光杯，透镜，固定透镜的螺纹灯头圈，每个螺纹连接处一个 O 形圈，装在小电路板上的 LED 模块，两个固定电路板的螺钉，一个按钮开关，以及一个电池架。应用三个最少零件问题，提出一种零件更少的重新设计，并讨论这一重新设计在制造、密封、维修（换电池）和回收方面可能付出的代价。
::: solution
一种站得住脚的分析：筒身（基础件）计入；尾盖为了换电池必须分开（问题 3）；弹簧相对于其他零件运动，且必须是弹簧材料（问题 1 和 2），但可以集成到电池架中；反光杯必须能反光，但可以是模塑件上的一个镀膜特征；透镜必须透明（材料不同）——计入；灯头圈只用于固定透镜，而透镜可以包覆成形或卡装；O 形圈是不同的材料（弹性体密封件）——计入，除非用包覆成形的密封实现密封；LED 模块计入（材料不同，电子元件）；螺钉通不过；开关运动（计入）；电池架可以与弹簧和触点合并。

重新设计可以把筒身用聚合物模塑成形并带有一体式反光杯，用卡环或包覆成形固定透镜，把 LED 电路板卡入加强筋之间，并把弹簧、触点和开关合并成一个尾盖模块。代价：需要一副模具，可能还要双色注塑；聚合物筒身对 LED 的散热较差；不可拆卸的透镜无法维修；把卡扣连接密封到某一防护等级，比用 O 形圈密封螺纹更难；换电池必须仍然无需工具。就回收而言，金属和聚合物零件可以分离、电池可以取出是可取的，这就不赞成把异种材料包覆成形在一起。好的答案会给出改前和改后的零件数，并说明每个保留下来的零件通过了哪些问题。
:::
