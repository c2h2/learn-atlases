一个选定的概念是一条原理：“由直齿圆柱齿轮减速器驱动的丝杠”“装在回转支承上的悬臂”“由偏心轮驱动的隔膜泵”。谁也无法制造一条原理。**具体化设计**（embodiment design）是概念获得形态的阶段——零件在空间中的布置、每个零件的材料和大致尺寸、零件之间的接口，以及足以表明这种布置能承受其载荷、能放入其外廓空间并能以目标成本制造的计算。随后，**详细设计**确定其余的每一个尺寸、公差、表面粗糙度和材料规格，并把它们记录在制造部门据以工作的图样和零件明细表中。这两个阶段大量重叠，一件机械产品的大部分工程工时都花在其中。

本讲沿用帕尔（Pahl）与拜茨（Beitz）对这项工作的划分。它从**产品架构**开始——功能如何映射到实体块上，以及这些块如何相互作用。接着给出具体化设计的基本规则和原理（明确、简单、安全；直接的载荷路径；任务分配；自助），根据载荷确定零件尺寸的步骤，用极值法和统计法进行的**公差累积**（尺寸链）分析，以及**样机与试验**的规划。输入是用[[design-process/concept-selection]]中的方法选定的概念；输出则是[[design-process/design-for-manufacture]]和[[design-process/reliability-risk]]的出发点。应力分析本身在[[mechanics-of-materials]]中讲授，标准机械零件的尺寸计算在[[machine-design]]中讲授；这里只是使用它们，而不加推导。

## 从概念到总体布局 {#sec-concept-to-layout}

具体化设计由粗到细进行。典型的顺序是：

1. 识别决定形态和尺寸的要求：载荷、速度、温度、外廓尺寸、质量、与外界的接口、生产批量、成本目标。它们来自[[design-process/requirements]]中的设计要求表。
2. 按比例画出主要功能载体（电动机、齿轮箱、结构、壳体）的粗略布局，看概念究竟能否放入外廓空间。
3. 确定架构：哪些功能共用一个零件，模块边界在哪里，哪些接口实行标准化。
4. 通过计算确定主要功能载体的尺寸，然后确定辅助功能载体（轴承、密封件、紧固件、盖板）的尺寸。
5. 对照[[#sec-rules]]中的规则，以及制造、装配、维护和回收方面的要求检查总体布局；在画了不止一种布局的地方对各备选方案进行评价。
6. 对不确定的部分制作样机并进行试验；迭代。

这些步骤并不是严格按顺序进行的。确定轴的尺寸可能表明轴承不再能装进壳体，这就要移动齿轮箱，进而改变架构。有纪律的步骤的目的不是避免迭代，而是使每一轮迭代都短，并首先解决影响最广的决策。

::: definition 总体布局、形态设计与详细设计 {#def-layout}
**总体布局**（总布置）是一张按比例绘制的图样或一个 CAD 装配体，它确定每个主要部件的位置、方向和大致尺寸，以及它们之间载荷、能量、物料和信号的传递路线。**形态设计**赋予每个部件以形状、材料和主要尺寸。**详细设计**完成全部定义：每个尺寸及其公差、几何公差、表面粗糙度、热处理、紧固件、标准件、图样、零件明细表和装配说明。详细设计的产出是一套完整的**技术产品文件**，第三方可以据此制造和检验产品。
:::

## 产品架构 {#sec-architecture}

::: definition 产品架构、块与接口 {#def-architecture}
**产品架构**是这样一种方案：产品的功能要素按它被安排到实体构件（**块**、模块或部件）中，块之间按它相互作用（Ulrich，1995）。它有三个部分：功能要素的安排，从功能要素到实体部件的映射，以及相互作用的部件之间**接口**——机械、能量、物料和信号连接——的规定。
:::

两个极端界定了各种可能性。

- 在**模块化架构**中，每个块完整地实现一个或少数几个功能要素，块之间的相互作用少而明确。台式计算机是经典的例子：电源、存储器、内存和显卡是带有标准接口的独立模块。围绕同一种电池包构建的无绳工具系列是另一个例子。
- 在**整体式架构**中，功能要素分散在几个块上，或者一个块实现许多功能，接口复杂且专属于该产品。一个同时充当结构、冷却液通道、润滑油道、轴承座和安装座的铸铝发动机缸体是整体式的；带有一体式铰链和卡扣的注塑塑料件也是如此。

乌尔里希（Ulrich）按接口模式区分了三种模块化架构：**插槽式**（slot，每个模块有不同的接口，如汽车收音机）、**总线式**（bus，所有模块都插入一个公共接口，如轨道照明或计算机背板）和**组合式**（sectional，模块之间通过相同的接口相互连接，如办公室隔断或管道）。

一般来说，两个极端都没有绝对的优劣。模块化使产品多样化变得便宜（更换一个模块，其余保留），使各模块可以并行地设计、试验、制造和采购，简化维修和升级，并限制设计更改的扩散范围。整体式通常在质量、尺寸、零件数和单件成本上占优，因为一个零件完成几项工作，连接也更少；当性能被推向极限（飞机结构、移动电话）或批量大到足以支付复杂工装的费用时，人们会优先选择它。这一决策既与工程有关，也同样与企业的战略——多样化、更改、标准化、外包——有关。

::: algorithm 定义模块化架构 {#alg-architecture}
1. 画出选定概念的功能结构（来自[[design-process/concept-generation]]）。
2. 画一个粗略的几何布局，看哪些要素必须彼此靠近。
3. 把功能要素聚合成块。把具有精确几何关系、将由同一供应商或同一种技术制造、可能一起更改，或者为几种产品变型所需要的要素归为一组。把相互作用弱的要素分开。
4. 画出**相互作用图**：块作为节点，每个接口作为一条边，并标出穿过它的东西（力、转矩、热、流体、电功率、数据）。
5. 识别**基本的**相互作用（功能所需要的）和**附带的**相互作用（块之间的热、振动、电磁噪声、热膨胀）。正是附带的相互作用使“独立的”模块在实践中相互干扰。
6. 为每条边编写接口规范，并在开始各块的详细工作之前冻结接口。
:::

接口规范通常汇集在一份由系统工程师负责的**接口控制文件**（ICD）中。对于机械接口，它规定配合几何及其公差、基准要素、传递的力和力矩、紧固件及其拧紧力矩、为热膨胀和装配预留的间隙，以及每一侧由谁负责。对已冻结接口一侧的更改需要另一侧负责人的同意；ICD 正是让两个团队能够并行工作而不至于设计出互不相容零件的机制。

## 具体化设计的基本规则与原理 {#sec-rules}

帕尔与拜茨把良好的具体化设计经验归纳为适用于每一项设计的三条**基本规则**，以及在适用场合使用的一组**原理**。

::: definition 基本规则：明确、简单、安全 {#def-basic-rules}
- **明确**：每项功能都有一个明确的功能载体，每个载荷都有一条可识别的路径，每个输入都有一个明确的输出。一个被两组螺栓夹紧、同时又用定位销定位的零件是超静定的，其载荷取决于制造误差；这就是不明确。
- **简单**：用能完成工作的最少零件和最简单的形状，使设计易于分析、制造、装配、检验和维护。
- **安全**：可靠地实现功能，并保护人员和环境，按以下顺序实现：*直接安全*（设计本身是安全的——没有危险，或危险不能造成伤害）、*间接安全*（防护装置和保护装置）和*警告*（说明和标志）。这与[[design-process/reliability-risk]]中讨论的 ISO 12100 三步法是同一个层次结构。
:::

最常用的原理如下。

- **力的传递。** 以最短、最直接的路径传递力，最好以轴向拉伸或压缩而不是弯曲或扭转的形式传递；力求等强度（每个截面承受相近的应力）；使配合零件的变形相协调，以便载荷按预期分担（一个螺栓比法兰刚硬得多的螺栓连接法兰，会使最近的螺栓承受最大的载荷）；尽可能在内部平衡力（成对使用旋向相反的斜齿轮、对置活塞），使轴承和壳体不必承受这些力。
- **任务分配。** 当一个零件同时承担几项功能会使每项功能都打折扣时，就给每项功能以各自的载体——例如采用单独的推力轴承和径向轴承，而不是用一个对两者都是糟糕折中的轴承。这是与集成相反的一股压力；设计者必须逐个情况作出决定。
- **自助。** 安排设计，使载荷本身有助于功能的实现：自增力鼓式制动器，向内开启、使内压将其压紧密封的压力容器门，唇口随压力升高而压得更紧的密封件。自保护的设计在过载时改变其载荷路径，使一个更强的元件在损坏发生之前接管载荷。
- **稳定性**：扰动所产生的效应应当相互抵消而不是相互放大（随温度升高而关闭的恒温阀）。
- **无差错设计**：安排设计，使制造、装配或使用中的差错不会造成故障——使错误装配不可能发生的不对称结构、只能以一种方式插入的连接器。

::: example 直接的载荷路径：悬臂支架与三角形支架 {#ex-load-path}
一个竖直载荷$F = 5\,\mathrm{kN}$必须从墙上传到距墙$L = 300\,\mathrm{mm}$的一点。比较 (a) 一根实心方形截面钢悬臂梁和 (b) 一个由水平圆截面拉杆和$45^\circ$圆截面压杆组成的三角形支架，两者在墙上都是铰接的。取许用应力$100\,\mathrm{MPa}$，$E = 200\,\mathrm{GPa}$，压杆的欧拉临界载荷取 3 倍的安全因数。比较两者的用钢体积。
::: solution
**受力图。** (a) 悬臂梁：端部受向下的载荷$F$；在墙上受向上的竖直约束力$F$和约束力偶矩$M = FL$。(b) 载荷点处的节点：向下的$F$，沿拉杆指向墙的拉杆力$T$，沿压杆的压杆力$C$。压杆从节点以$45^\circ$斜向下伸到墙上；由竖直方向的平衡，其竖直分量必须等于$F$。

(a) 墙处的弯矩为$M = FL = 5000 \times 0.3 = 1500\,\mathrm{N\,m}$。对于边长为$b$的正方形，$\sigma = M/S$，其中$S = b^3/6$，故
$$
b = \left(\frac{6M}{\sigma_\text{allow}}\right)^{1/3} = \left(\frac{6\times1500}{100\times10^6}\right)^{1/3} = 0.0448\,\mathrm m.
$$
截面为$44.8\,\mathrm{mm}$见方（$2008\,\mathrm{mm^2}$），等截面梁的体积为$2008\times300 = 6.02\times10^5\,\mathrm{mm^3} = 602\,\mathrm{cm^3}$。（变截面梁可以节省其中一部分，因为弯矩在端部降为零。）

(b) 节点平衡：由$C\sin45^\circ = F$得$C = 7071\,\mathrm N$（压缩）；水平方向$T = C\cos45^\circ = 5000\,\mathrm N$（拉伸）。拉杆面积：$5000/100 = 50\,\mathrm{mm^2}$（$d = 8.0\,\mathrm{mm}$）。压杆长$L_s = 0.3/\cos45^\circ = 0.424\,\mathrm m$；按$100\,\mathrm{MPa}$的应力只需要$71\,\mathrm{mm^2}$，但屈曲起控制作用。两端铰支时，由$3C = \pi^2EI/L_s^2$得
$$
I = \frac{3\times7071\times0.424^2}{\pi^2\times200\times10^9} = 1.93\times10^{-9}\,\mathrm{m^4},\qquad d = \left(\frac{64I}{\pi}\right)^{1/4} = 14.1\,\mathrm{mm},
$$
面积$156\,\mathrm{mm^2}$，应力$45\,\mathrm{MPa}$。体积：$50\times300 + 156\times424 = 8.1\times10^4\,\mathrm{mm^3} = 81\,\mathrm{cm^3}$。

三角形支架的用钢量约为悬臂梁的七分之一，因为它以轴力的形式承载，截面上的每一根纤维都在同一应力下工作，而在弯曲中只有外层纤维承受高应力。

**合理性检查。** 节点平衡：$T - C\cos45^\circ = 0$且$C\sin45^\circ - F = 0$ ✓。这一结果并不意味着悬臂梁是错误的：它在载荷下方占用的空间较少，不需要第二个墙上固定点，而且可能制造成本更低。原理告诉你哪个方案能很好地利用材料；由设计要求作出决定。
:::

:::

::: warning 超静定的布局会在你意想不到的地方承载
支承在三个轴承上的轴、由六个螺栓和两个定位销固定的板、在四个角上用螺栓固定在刚硬底座上的机架——每一种的支承都多于平衡所需，因此每个支承分担的载荷取决于刚度和制造误差。中间轴承$0.05\,\mathrm{mm}$的不对中，可能使它承受的载荷远大于轴本身重量所产生的载荷。要么使布局静定（一端固定、一端游动的轴承配置，三点安装），要么提供柔性，并在计入公差的情况下计算载荷分配。“它更刚硬，所以一定更结实”是一种常见而代价高昂的错误。
:::

## 从载荷到尺寸的尺寸计算 {#sec-sizing}

具体化设计中的计算与力学课程中的分析方向相反。分析给定几何形状求应力；尺寸计算则给定载荷和许用应力（或许用挠度、温度、寿命）求几何形状。

::: algorithm 确定零件尺寸 {#alg-sizing}
1. **载荷。** 根据设计要求和总体布局，确定作用在零件上的每一个载荷，包括它随时间的变化方式（静载、变载、冲击）及其极值。画出受力图。
2. **失效模式。** 列出零件可能无法履行功能的每一种方式：屈服、断裂、疲劳、屈曲、挠度过大、磨损、振动、过热、腐蚀。
3. **准则。** 对每种模式，把准则写成带有安全因数$n$或设计裕度的不等式：例如$\tau_\text{max} \le \tau_y/n$、$\theta \le \theta_\text{allow}$、$L_{10} \ge L_\text{required}$。
4. 针对起控制作用的尺寸**求解**每一条准则。所需尺寸最大者起控制作用。
5. **圆整**到标准尺寸或优先尺寸，然后用选定的尺寸重新校核全部准则。
6. **记录**载荷、假设、材料数据及其来源，以及所达到的裕度，以便计算能够受到评审，并在情况变化时重新进行。
:::

**安全因数**涵盖载荷、材料性能、模型和制造中的不确定性。对于载荷和性能都已知的塑性金属，典型值为$1.5$–$2.5$；压力容器、起重机或飞机的规范则规定各自的数值。在有规范适用的地方，以规范为准；这里的方法讲授的是推理过程，不能代替规范。

::: example 按强度和刚度确定电动机轴的尺寸 {#ex-shaft}
一根实心钢轴传递来自转速为$1450\,\mathrm{rev/min}$的电动机的功率$P = 7.5\,\mathrm{kW}$。联轴器与带轮之间的长度为$400\,\mathrm{mm}$。材料的拉伸屈服强度为$350\,\mathrm{MPa}$；取剪切屈服强度为其一半（特雷斯卡准则），安全因数为$2.5$。设计要求还把联轴器与带轮之间的扭转角限制在$1^\circ$以内（$G = 80\,\mathrm{GPa}$）。只考虑扭转，求轴径。
::: solution
转矩：$\omega = 1450\times2\pi/60 = 151.8\,\mathrm{rad/s}$，$T = P/\omega = 7500/151.8 = 49.4\,\mathrm{N\,m}$。

**强度。** $\tau_\text{allow} = 175/2.5 = 70\,\mathrm{MPa}$。对于实心轴，$\tau_\text{max} = 16T/(\pi d^3)$，故
$$
d \ge \left(\frac{16T}{\pi\,\tau_\text{allow}}\right)^{1/3} = \left(\frac{16\times49.4}{\pi\times70\times10^6}\right)^{1/3} = 15.3\,\mathrm{mm}.
$$

**刚度。** $\theta = TL/(GJ)$，其中$J = \pi d^4/32$。试算标准直径：

| $d$（mm） | $\tau_\text{max}$（MPa） | $\theta$（度） |
|---|---|---|
| 16 | 61.4 | 2.20 |
| 18 | 43.1 | 1.37 |
| 20 | 31.4 | 0.90 |

刚度准则起控制作用：$d = 20\,\mathrm{mm}$，在安全因数之外还有$70/31.4 = 2.2$的应力裕度。

**合理性检查。** $\tau \propto d^{-3}$，$\theta \propto d^{-4}$：从 16 mm 到 20 mm，应力乘以$(16/20)^3 = 0.51$ ✓，扭转角乘以$(16/20)^4 = 0.41$ ✓。对于实际的轴，还必须加上带拉力引起的弯曲、键槽和轴肩处的应力集中以及疲劳——方法见[[machine-design]]。这一初步估算确定了总体布局；详细校核随后进行。
:::

这个例子表明了一种反复出现的模式：对于许多机械零件，决定尺寸的是刚度或挠度要求，而不是强度。机床床身、齿轮箱壳体、机器人连杆和精密滑台的尺寸几乎完全由刚度和振动决定，其应力很低。

:::
## 公差累积 {#sec-tolerances}

每一个被制造出来的尺寸都有变动。当几个带公差的尺寸相加构成一个功能尺寸时——轴在壳体中的轴向游隙、门与门框之间的间隙、一对轴承中的预紧量——它们的变动就会累积。**公差累积**分析（尺寸链计算）根据各组成环的公差预测功能尺寸的变动。极限与配合以及几何公差本身在[[engineering-graphics/tolerances-fits]]中讨论；这里的问题是如何分配它们。

::: definition 公差累积、装配间隙与组成环 {#def-stack}
在一维**公差累积**中，功能尺寸（**装配间隙**，即封闭环）为
$$
G = \sum_{i=1}^{m} a_i X_i,
$$ {#eq-stack}
其中$X_i$是各组成尺寸（组成环），系数$a_i = +1$或$-1$，取决于增大$X_i$是使间隙增大还是减小（更一般地，$a_i = \partial G/\partial X_i$，即敏感系数）。每个组成环有公称值$\mu_i$和对称公差$\pm t_i$。从间隙的一侧绕回路到另一侧的尺寸链称为**尺寸回路**。
:::

::: proposition 极值法与平方和根法公差 {#prop-wc-rss}
(a) **极值法**（worst case）。若每个$X_i$都位于$\mu_i \pm t_i$之内，则$G$位于$G_0 \pm t_\text{WC}$之内，其中$G_0 = \sum a_i\mu_i$，且
$$
t_\text{WC} = \sum_{i=1}^{m} \lvert a_i\rvert\, t_i,
$$ {#eq-wc}
并且这个界是可以达到的。

(b) **平方和根法**（root sum square，RSS）。若$X_i$是均值为$\mu_i$、标准差为$\sigma_i$的独立随机变量，则$G$的均值为$G_0$，标准差为$\sigma_G = \sqrt{\sum a_i^2\sigma_i^2}$。若再设每个公差对应于$t_i = 3\sigma_i$，且$G$服从正态分布，则间隙的$\pm3\sigma$公差为
$$
t_\text{RSS} = \sqrt{\sum_{i=1}^{m} a_i^2\, t_i^2},
$$ {#eq-rss}
且约有$0.27\,\%$的装配体落在$G_0 \pm t_\text{RSS}$之外。
:::

::: proof
(a) $G - G_0 = \sum a_i(X_i - \mu_i)$，且$\lvert X_i - \mu_i\rvert \le t_i$，故由三角不等式，$\lvert G - G_0\rvert \le \sum\lvert a_i\rvert t_i$。把每个$X_i$都取在极限$\mu_i + t_i\,\mathrm{sgn}(a_i)$处即得等号，因此这个界是可以达到的。

(b) 数学期望是线性的，故$\E[G] = \sum a_i\mu_i = G_0$。对于独立变量，协方差为零，$\Var(G) = \sum a_i^2\Var(X_i) = \sum a_i^2\sigma_i^2$。代入$\sigma_i = t_i/3$得$\sigma_G = \frac13\sqrt{\sum a_i^2t_i^2}$，且$3\sigma_G = t_\text{RSS}$。若每个$X_i$都服从正态分布，则$G$恰好服从正态分布；否则，当有几个大小相近的组成环时，由中心极限定理，$G$近似服从正态分布。正态分布落在$\pm3\sigma$之外的比例为$2(1 - \Phi(3)) = 0.0027$。

假设：各组成环相互独立（没有共同原因，例如一把磨损的刀具使所有零件都偏大），工艺以公称值为中心，且$t_i = 3\sigma_i$（工序能力指数$C_p = 1$）。若这些假设不成立，RSS 的结果就是偏于乐观的。
:::

对于$m$个相等的公差$t$，$t_\text{WC} = mt$，而$t_\text{RSS} = \sqrt m\,t$。两者之差随组成环数目的增加而增大：对一条长尺寸链按极值法设计，会迫使每个零件都采用严格而昂贵的公差，以防范一种几乎从不发生的组合——每个零件都处于同一极限。统计公差法接受一个小而可预测的废品率或返工率，以换取较宽的零件公差。

::: example 轴系部件的轴向游隙 {#ex-stack}
一根轴上装有两个由隔套隔开的轴承，位于壳体之内；一个挡圈封闭壳体。轴向游隙等于壳体内宽减去轴承—隔套—轴承的累积长度。尺寸（mm）：壳体宽度$H = 50.50 \pm 0.10$，轴承$B_1 = B_2 = 15.00 \pm 0.05$，隔套$S = 20.00 \pm 0.08$。设计要求规定游隙在$0.20$与$0.80\,\mathrm{mm}$之间。分别用极值法和 RSS 法求游隙范围。
::: solution
尺寸回路：$G = H - B_1 - S - B_2$，故$a_H = +1$，其余为$-1$。公称游隙$G_0 = 50.50 - 15.00 - 20.00 - 15.00 = 0.50\,\mathrm{mm}$。

极值法：$t_\text{WC} = 0.10 + 0.05 + 0.08 + 0.05 = 0.28\,\mathrm{mm}$，游隙$0.22$至$0.78\,\mathrm{mm}$——在要求范围之内。

RSS 法：$t_\text{RSS} = \sqrt{0.10^2 + 0.05^2 + 0.08^2 + 0.05^2} = \sqrt{0.0214} = 0.146\,\mathrm{mm}$，在$\pm3\sigma$下游隙为$0.354$至$0.646\,\mathrm{mm}$。

由于极值法已经满足要求，每一个装配体都是合格的。RSS 的结果说明了更多的东西：$\sigma_G = 0.0488\,\mathrm{mm}$时，要求的极限距公称值$0.30/0.0488 = 6.2$个标准差，因此公差比需要的更严。这就引出了[[#ex-stack-loosen]]中的问题。

**合理性检查。** $t_\text{RSS} < t_\text{WC}$，且$t_\text{RSS} \ge$最大的单个公差（$0.10$） ✓——两者总是成立。
:::

:::

::: example 放宽公差 {#ex-stack-loosen}
为降低加工成本，把[[#ex-stack]]中的四个公差全部放宽 50 %（为$\pm0.15$、$\pm0.075$、$\pm0.12$、$\pm0.075$ mm）。设计是否仍然可以接受？假设工艺为以中心为准的正态分布且$t_i = 3\sigma_i$，估计落在$0.20$–$0.80\,\mathrm{mm}$要求之外的装配体比例。
::: solution
极值法：$t_\text{WC} = 1.5\times0.28 = 0.42\,\mathrm{mm}$，游隙$0.08$至$0.92\,\mathrm{mm}$——极值法分析否定了这一更改。

统计法：$t_\text{RSS} = 1.5\times0.146 = 0.219\,\mathrm{mm}$，故$\sigma_G = 0.0731\,\mathrm{mm}$。极限距公称值$\pm0.30\,\mathrm{mm}$，$z = 0.30/0.0731 = 4.10$个标准差。落在外面的比例为$2(1 - \Phi(4.10)) = 4.1\times10^{-5}$，约为每百万个装配体 41 个。

每百万个 41 个是否可以接受，是一项商业和安全决策。对于家用电器，超差的装配体会在下线试验中被发现并重新加垫片调整，几乎肯定可以接受；对于飞机作动器则可能不行，而且还需要通过测量工序能力来核对分析所依据的假设（独立性、对中）。

**合理性检查。** 采用原公差时，$z = 0.30/0.0488 = 6.15$，废品比例约为$8\times10^{-10}$；放宽 50 % 使$\sigma$乘以$1.5$，废品率约上升五个数量级，这与正态分布陡峭的尾部所预期的一致。
:::

## 样机与试验 {#sec-prototyping}

总体布局及其计算是一种预测。样机和试验在模型最薄弱的地方检验这种预测。

::: definition 样机的种类 {#def-prototype}
按照乌尔里希与埃平格（Eppinger）的说法，样机沿两个维度分类。**物理**样机是有形的制品；**分析**样机是数学模型或计算机模型（有限元模型、多体仿真、公差电子表格）。**专注型**样机实现一个或少数几个属性（用于人机工程的泡沫模型、针对某一轴承的试验台）；**综合型**样机实现大多数属性。在产品开发中，主要的物理样机阶段为：
- **原理验证**样机——专注型，通常很粗糙，用以表明某一工作原理是可行的；
- **alpha** 样机——零件具有预定的几何形状和材料，但通常不是用生产工艺制造的，用来检查设计是否按预期工作；
- **beta** 样机——零件用预定的生产工艺（或接近的工艺）制造，由企业并常常由选定的客户进行装配和试验，用来检查可靠性、现场性能和尚未解决的问题；
- **试生产**样件——在生产线上制造，用来检查工艺本身。
:::

样机有四种用途：学习（它能工作吗？工作得多好？）、沟通（与管理层、客户、供应商）、集成（各零件能否配合并协同工作？）以及里程碑（设计是否已达到足以证明下一笔投资合理的阶段？）。一份好的样机计划，每做一台样机都是为了以所花的钱降低最大的不确定性，这通常意味着早期制作风险最大要素的专注型样机，后期再制作综合型样机。

试验分为两大类。**验证**试验检查设计是否满足其设计要求（“我们把它造对了吗？”）：按设计载荷乘以验证系数进行的载荷试验、疲劳试验、环境试验（温度、湿度、振动、防护等级）、电磁兼容。**确认**试验检查产品是否满足用户的需要（“我们造的是对的东西吗？”）：现场试用、用户研究。试验计划为每项要求规定试验方法、样本量、合格判据和条件。

必须试验多少台？证明产品满足可靠性目标的试验是一项统计实验，而最简单的这类试验有一个简洁的答案。

::: proposition 零失效（成功运行）试验 {#prop-success-run}
若$n$台独立的产品各自按规定时长进行试验且无一失效，则只要
$$
n \ge \frac{\ln(1 - C)}{\ln R_0},
$$ {#eq-success-run}
就以置信度$C$证明了在该时长内的可靠度$R$至少为$R_0$。
:::

::: proof
设真实可靠度恰为$R_0$。每台产品独立地以概率$R_0$存活，因此全部$n$台存活的概率为$R_0^n$（零失效的二项概率）。如果真实可靠度更低，全部通过就更不可能。因此，若$R_0^n \le 1 - C$，则对任何$R \le R_0$的产品，全部通过的结果出现的概率至多为$1 - C$；观察到这一结果，就可以在置信度$C$下拒绝“$R \le R_0$”。对$R_0^n \le 1 - C$取对数并除以$\ln R_0 < 0$（这使不等号反向）即得结果。假设：试验时长和条件代表规定的使用，产品相互独立并能代表批量生产，且试验结束时无失效。
:::

::: example 规划一项疲劳鉴定试验 {#ex-success-run}
一个自行车曲柄必须通过规定的疲劳试验（在规定载荷下的若干次载荷循环）。设计团队希望通过零失效试验以$90\,\%$的置信度证明$R = 0.90$。必须试验多少个曲柄？如果置信度提高到$95\,\%$又如何？
::: solution
由[[#eq-success-run]]：$n \ge \ln(0.10)/\ln(0.90) = (-2.303)/(-0.1054) = 21.85$，所以需要$n = 22$个曲柄，并且全部必须通过。

置信度为$95\,\%$时：$n \ge \ln(0.05)/\ln(0.90) = 28.4$，所以$n = 29$。

**合理性检查。** $0.9^{22} = 0.098 < 0.10$ ✓，$0.9^{21} = 0.109 > 0.10$ ✓，因此 22 是满足要求的最小数目。用这种方法证明高可靠度是昂贵的——在 90 % 置信度下证明$R = 0.99$需要 230 台——这就是为什么试验工程师要进行超出规定寿命或更高载荷的试验，并使用寿命模型（例如[[design-process/reliability-risk]]中的威布尔模型）换算回来。
:::

:::

::: quiz
一个尺寸链有 16 个组成环，每个的公差为$\pm0.02\,\mathrm{mm}$，相互独立且对中，$t_i = 3\sigma_i$。间隙的极值法公差和 RSS 公差各是多少？
- [ ] $\pm0.32$和$\pm0.16\,\mathrm{mm}$
- [x] $\pm0.32$和$\pm0.08\,\mathrm{mm}$
- [ ] $\pm0.08$和$\pm0.02\,\mathrm{mm}$
- [ ] $\pm0.32$和$\pm0.32\,\mathrm{mm}$
::: solution
极值法：$16\times0.02 = 0.32\,\mathrm{mm}$。RSS：$\sqrt{16}\times0.02 = 4\times0.02 = 0.08\,\mathrm{mm}$。组成环很多时，RSS 公差要小得多——前提是[[#prop-wc-rss]]的假设成立。
:::
:::

## 详细设计与设计评审 {#sec-detail}

在详细设计中，决策变得数量众多、单个影响很小，但它们合在一起决定了大部分制造成本。其任务是：最终尺寸和公差（由公差累积分析分配）、几何公差和基准体系、表面粗糙度、材料规格和热处理、标准件（轴承、密封件、紧固件，选自产品样本）、带有产品制造信息的图样和三维模型、零件明细表（物料清单），以及装配、检验和维护说明。[[design-process/design-for-manufacture]]中的检查清单要逐个零件地应用。

设计评审在具体化设计和详细设计结束时举行。当与会者包括将要制造、装配、试验、销售和维修产品的人，材料提前分发，并且会议以一份记录在案的行动项及负责人清单结束时，评审才是有效的。评审对照设计要求审查功能和性能、计算及其假设、安全和风险分析、制造和装配、成本，以及与标准和法规的符合性（[[design-process/ethics-standards]]）。

::: history
对具体化设计的系统化论述源于德国的工程设计学派。格哈德·帕尔（Gerhard Pahl）与沃尔夫冈·拜茨（Wolfgang Beitz）于1977年出版了《设计学》（*Konstruktionslehre*）；其英译本《工程设计：系统化方法》（*Engineering Design: A Systematic Approach*）由肯·华莱士（Ken Wallace）编辑，于1984年问世；书中明确、简单、安全的基本规则，以及力的传递、任务分配和自助等原理，成为这一领域的标准术语。产品架构的概念及其模块化和整体式两种类型，由卡尔·乌尔里希（Karl Ulrich）在《产品架构在制造企业中的作用》（“The role of product architecture in the manufacturing firm”，*Research Policy*，1995年）中提出，并成为乌尔里希与埃平格的《产品设计与开发》（*Product Design and Development*，1995年首版）中的一章。
:::

::: summary
- 具体化设计赋予选定的概念以布置、形态、材料和主要尺寸；详细设计把定义完善为技术文件。
- 产品架构把功能要素映射到块上，并定义它们的接口。模块化架构（插槽式、总线式、组合式）有利于多样化、更改和并行工作；整体式架构有利于质量、尺寸和单件成本。接口要尽早冻结并受到控制。
- 基本规则：明确、简单、安全（先直接安全，再间接安全，最后警告）。原理：直接的轴向载荷路径、等强度、变形协调、力的平衡；任务分配；自助；无差错设计。
- 尺寸计算是分析的逆过程：载荷 → 失效模式 → 带安全因数的准则 → 起控制作用的尺寸 → 标准尺寸 → 重新校核。刚度往往起控制作用。
- 公差累积：$t_\text{WC} = \sum\lvert a_i\rvert t_i$保证每个装配体合格；$t_\text{RSS} = \sqrt{\sum a_i^2t_i^2}$假设组成环独立、对中、服从正态分布且$t = 3\sigma$，允许以可预测的废品率换取较宽的公差。
- 样机分为物理样机或分析样机、专注型或综合型；alpha 样机检验设计，beta 样机检验生产设计。对$n \ge \ln(1-C)/\ln R_0$台产品进行零失效试验，可以以置信度$C$证明可靠度$R_0$。
:::

## 习题

::: exercise 统计接口数 {#exr-interfaces level=1 check="15"}
一件产品被分成 6 个块。在最坏的（完全整体式的）情况下，每个块都与其他每个块直接相互作用。必须规定多少个两两之间的接口？（输入该数。）
::: solution
每对块有一个接口：$\binom62 = 6\times5/2 = 15$。在总线式架构中，6 个块都只与公共的第七个元件连接，只需要同一种标准类型的 6 个接口实例——这是总线式模块化能简化设计的原因之一。
:::
:::

::: exercise 极值法尺寸链 {#exr-wc level=1 check="0.2"}
一个间隙由公差分别为$\pm0.05$、$\pm0.10$和$\pm0.05\,\mathrm{mm}$的三个尺寸构成。间隙的极值法公差是多少？（以 mm 输入$t_\text{WC}$。）
::: solution
$t_\text{WC} = 0.05 + 0.10 + 0.05 = 0.20\,\mathrm{mm}$，与符号$a_i = \pm1$无关。
:::
:::

::: exercise RSS 尺寸链 {#exr-rss level=1 check="0.122"}
对同样的三个尺寸，假设工艺独立、对中、服从正态分布且$t_i = 3\sigma_i$，求间隙的 RSS 公差。（以 mm 输入$t_\text{RSS}$，保留三位小数。）
::: solution
$t_\text{RSS} = \sqrt{0.05^2 + 0.10^2 + 0.05^2} = \sqrt{0.0150} = 0.1225\,\mathrm{mm}$，舍入为$0.122\,\mathrm{mm}$（精确值为$0.12247$）。它由最大的组成环支配：减小$\pm0.10$的公差最有帮助。
:::
:::

::: exercise 由功率求转矩 {#exr-torque level=1 check="19.10"}
一台齿轮电动机在$1500\,\mathrm{rev/min}$下输出$3.0\,\mathrm{kW}$。其输出轴承受多大的转矩？（以 N·m 输入$T$，保留两位小数。）
::: solution
$\omega = 1500\times2\pi/60 = 157.08\,\mathrm{rad/s}$；$T = P/\omega = 3000/157.08 = 19.099\,\mathrm{N\,m} \approx 19.10\,\mathrm{N\,m}$。
:::
:::

::: exercise 按强度确定轴径 {#exr-shaft level=2 check="21"}
一根实心轴承受$100\,\mathrm{N\,m}$的恒定转矩。许用切应力（剪切屈服强度除以安全因数）为$60\,\mathrm{MPa}$。求最小直径，并向上圆整到下一个整毫米。（以 mm 输入$d$。）
::: solution
$d \ge (16T/(\pi\tau_\text{allow}))^{1/3} = (16\times100/(\pi\times60\times10^6))^{1/3} = 0.02040\,\mathrm m = 20.4\,\mathrm{mm}$，故$d = 21\,\mathrm{mm}$。检查：$\tau = 16\times100/(\pi\times0.021^3) = 55.0\,\mathrm{MPa} \le 60\,\mathrm{MPa}$ ✓。设计者很可能会进而选用 22 或 25 mm 之类的优先尺寸以适配标准轴承和密封件，然后校核刚度。
:::
:::

::: exercise 选择公称尺寸 {#exr-nominal level=2 check="49.38"}
一个内宽为$H \pm 0.08\,\mathrm{mm}$的壳体中依次装有长度为$12.00\pm0.05$、$25.00\pm0.10$和$12.00\pm0.05\,\mathrm{mm}$的三个零件。间隙绝不能小于$0.10\,\mathrm{mm}$（极值法）。壳体的最小公称宽度$H$是多少？（以 mm 输入$H$。）
::: solution
公称间隙$G = H - (12 + 25 + 12) = H - 49.00$，$t_\text{WC} = 0.08 + 0.05 + 0.10 + 0.05 = 0.28\,\mathrm{mm}$。最小间隙为$H - 49.00 - 0.28 \ge 0.10$，故$H \ge 49.38\,\mathrm{mm}$。这时最大间隙为$49.38 - 49.00 + 0.28 = 0.66\,\mathrm{mm}$，也必须对照功能进行检查。
:::
:::

::: exercise 可靠性证明试验 {#exr-success level=2 check="45"}
要以$90\,\%$的置信度证明可靠度为$0.95$，必须有多少台产品通过零失效试验？（输入台数。）
::: solution
$n \ge \ln(0.10)/\ln(0.95) = 2.303/0.0513 = 44.9$，所以需要$45$台。检查：$0.95^{45} = 0.099 < 0.10$ ✓，$0.95^{44} = 0.105$ ✗。
:::

::: exercise 壁挂搁板的载荷路径 {#exr-shelf level=2}
一个搁板支架在距墙$250\,\mathrm{mm}$处承受$1.2\,\mathrm{kN}$。画出两种布局的草图，一种受弯，一种为三角形，并对每种画出受力图，求出每根杆件中的力或墙处的弯矩。在每种情况下，哪些载荷最终作用在墙上的固定件上？这对膨胀螺栓（墙塞）的选择意味着什么？
::: solution
**悬臂式。** 在墙处：竖直剪力$1.2\,\mathrm{kN}$和弯矩$M = 1.2\times0.25 = 0.30\,\mathrm{kN\,m}$。弯矩由固定件之间的力偶来抵抗：若上、下固定件相距$h = 100\,\mathrm{mm}$，且支架绕其下边缘转动，则上固定件被以约$M/h = 3.0\,\mathrm{kN}$的力从墙中拔出，是搁板载荷的二倍半。

**三角形，压杆在下方呈$45^\circ$。** 载荷处的节点：压杆压力$1.2/\sin45^\circ = 1.70\,\mathrm{kN}$，拉杆拉力$1.2\,\mathrm{kN}$。在墙处，拉杆以$1.2\,\mathrm{kN}$把上固定件向外拉，压杆以水平$1.2\,\mathrm{kN}$和竖直$1.2\,\mathrm{kN}$的力把下端压向墙面。

直接的载荷路径把上固定件所受的拔出力从约$3\,\mathrm{kN}$降到$1.2\,\mathrm{kN}$；墙塞被拔出通常是关键的失效模式，因此对同样的墙塞而言，三角形布局更安全。把悬臂支架的背板做得更高（增大$h$）也有同样的作用。
:::
:::

::: exercise 均匀分布下的统计公差 {#exr-uniform level=3 check="0.346"}
有些工艺产生的尺寸大致均匀地分布在公差带内（例如在两次调整之间稳定磨损的刀具）。(a) 证明$[\mu - t, \mu + t]$上的均匀分布有$\sigma = t/\sqrt3$。(b) 证明对于$m$个独立的、公差均为$t$的均匀分布组成环，间隙的$3\sigma$公差为$\sqrt{3m}\,t$，并与极值法和正态 RSS 的值进行比较。(c) 计算$m = 4$、$t = 0.1\,\mathrm{mm}$时的$3\sigma$公差。（以 mm 输入，保留三位小数。）
::: solution
(a) 宽度为$2t$的均匀分布的方差为$(2t)^2/12 = t^2/3$，故$\sigma = t/\sqrt3$。

(b) $\sigma_G^2 = m\,t^2/3$，故$3\sigma_G = 3t\sqrt{m/3} = \sqrt{3m}\,t$。它是正态 RSS 值$\sqrt m\,t$的$\sqrt3 = 1.73$倍，且当$m > 3$时小于极值$mt$。当$m \le 3$时它给出$\ge$极值的结果，这表明在那里$3\sigma$的说法没有意义：组成环少且均匀分布时，间隙并不接近正态分布，极值才是正确的界。一种常见的实用折中是把 RSS 公差乘以约$1.5$的放大系数。

(c) $\sqrt{12}\times0.1 = 0.3464\,\mathrm{mm} \approx 0.346\,\mathrm{mm}$，而极值法为$0.4\,\mathrm{mm}$，正态 RSS 为$0.2\,\mathrm{mm}$。
:::
:::

::: exercise 无绳工具系列的架构 {#exr-architecture level=3}
一家公司计划推出 12 V 和 18 V 的无绳工具系列：电钻、冲击起子、曲线锯、圆锯和工作灯。提出一种架构。识别各个块，说明哪些在整个系列中共用、哪些是专用的，为电池接口选择模块化类型，列出该接口处的基本相互作用和附带相互作用，并说明接口控制文件必须规定哪些内容。模块化选择的代价是什么？
::: solution
一个合理的答案：各块为电池包、电动机及其电子控制器、传动装置（齿轮箱、离合器、钻夹头或锯片驱动）、带握把和扳机的壳体，以及工具专用附件（钻夹头、锯片护罩、灯头）。整个系列共用：电池包和充电器（每种电压一种），可能还有电动机系列和扳机开关；专用：传动装置和壳体。

电池接口是**总线式**（或者是同一电压的所有工具共用的插槽）：每件工具都提供完全相同的电池座。基本相互作用：在工具的振动和跌落载荷下的机械锁定、电功率（电压、峰值电流）以及数据（电芯温度、荷电状态、过流保护信号）。附带相互作用：来自电动机和电池包的热、触点的振动疲劳、水和灰尘的侵入，以及跌落时电池包质量产生的力矩。

ICD 规定导轨几何及其公差、锁扣力和跌落试验的锁定要求、触点布置、额定电流和电压范围、通信协议、温度限值、防护等级，以及防止装入错误电压电池包的防错结构（无差错设计）。模块化的代价：每件工具都要带一个按最大电池包和最大电流设计的电池座，接口无法针对某一件工具优化，而冻结接口又限制了以后的改进；兼容性必须保持多年，因为客户的投资在电池包上。
:::

## 延伸阅读
