一项在试验台上满足全部性能要求的设计，如果在使用中失效得太频繁，或者失效时会伤人，它仍然可能是一项糟糕的设计。**可靠性工程**研究产品在规定条件下、在规定时间内完成其功能的可能性有多大，以及如何预测、测量和提高这种可能性。**风险与安全工程**研究产品可能造成什么伤害，这种伤害的可能性和严重程度如何，以及设计如何消除或减小它。两者都处理不确定性，都在具体化设计期间而不是在首批现场失效之后应用时最为有效，并且都使用一小套成熟的工具。

本讲建立寿命的概率描述——可靠度函数、失效率（危险率）和浴盆曲线——以及机械设计中最常用的两种寿命分布，即指数分布和威布尔分布，并以滚动轴承寿命作为标准应用。然后用可靠性框图把元件组合成系统，包括冗余和共因失效，并介绍可用度。后半部分介绍风险的定性和半定量工具：**失效模式与影响分析**（FMEA）、**故障树分析**（FTA）、风险矩阵，以及 ISO 12100 中风险减小措施的先后次序。概率论本身见数学图谱（[probability](/learn/maths/course.php?c=probability)）；预测单个零件何时失效的应力分析和疲劳分析见[[mechanics-of-materials]]和[[machine-design]]。

## 描述寿命：可靠度与失效率 {#sec-reliability}

设$T$为一个单元的失效时间——它是一个随机变量，因为名义上相同的单元会在不同的时间失效。“时间”可以是小时、循环次数、转数或公里数。

::: definition 可靠度、失效分布与失效率 {#def-reliability}
**可靠度函数**（生存函数）为$R(t) = \Prob(T > t)$，即单元存活到$t$以后的概率。**累积失效分布函数**为$F(t) = 1 - R(t)$，**失效概率密度**为$f(t) = F'(t) = -R'(t)$。**失效率**（危险率，瞬时失效率）为
$$
h(t) = \frac{f(t)}{R(t)},
$$ {#eq-hazard}
因此$h(t)\,\Delta t$近似等于一个已存活到$t$的单元在下一个时间间隔$\Delta t$内失效的概率。**平均失效前时间**为$\mathrm{MTTF} = \E[T]$。
:::

$f$与$h$的区别很重要。$f(t)\,\Delta t$是*原有*总体中在$(t, t + \Delta t)$内失效的比例；$h(t)\,\Delta t$是*存活者*中失效的比例。一批到了寿命后期的灯泡$f$低（剩下的不多了），但$h$高（每个存活者都接近寿终）。

::: proposition 由失效率求可靠度；由可靠度求 MTTF {#prop-hazard}
对于在$t = 0$时为新品的单元，
$$
R(t) = \exp\!\left(-\int_0^t h(u)\,du\right) \qquad\text{且}\qquad \mathrm{MTTF} = \int_0^\infty R(t)\,dt.
$$ {#eq-r-from-h}
:::

::: proof
由定义，$h = f/R = -R'/R = -\frac{d}{dt}\ln R$。在$R(0) = 1$下从$0$积分到$t$，得$\ln R(t) = -\int_0^t h\,du$，即第一个结果。

对于第二个结果，$\mathrm{MTTF} = \int_0^\infty t f(t)\,dt = -\int_0^\infty t R'(t)\,dt$。分部积分，$= [-tR(t)]_0^\infty + \int_0^\infty R\,dt$。边界项在$0$处显然为零，在无穷远处只要均值有限（这时$tR(t) \to 0$）也为零。故$\mathrm{MTTF} = \int_0^\infty R\,dt$。
:::

### 浴盆曲线

把许多产品总体的失效率对使用时间作图，其形状像一个浴盆。失效率递减的**早期失效**（婴儿死亡）区由制造缺陷——不良焊点、受污染的轴承、夹杂物——造成，这些缺陷使一部分单元变得薄弱；它们很早就失效，剩下的总体就更强了。失效率大致恒定的**偶然失效**（有用寿命）区以随机过载和与使用时间无关的原因为主。失效率递增的**耗损失效**区由疲劳、磨损、腐蚀和老化造成。并非每种产品都表现出全部三个区——许多纯机械元件主要表现为耗损失效，而许多电子设备主要表现为早期失效和平坦区——但这幅图解释了标准的对策：用老练和筛选应对早期失效，用裕度应对随机过载，在耗损之前进行预防性更换。

## 指数分布与威布尔分布 {#sec-weibull}

::: definition 指数寿命分布与威布尔寿命分布 {#def-weibull}
由[[#eq-r-from-h]]，**恒定失效率**$h(t) = \lambda$给出**指数**分布
$$
R(t) = e^{-\lambda t},\qquad \mathrm{MTTF} = 1/\lambda.
$$ {#eq-exponential}
两参数**威布尔**分布为
$$
R(t) = \exp\!\left[-\left(\frac{t}{\eta}\right)^{\beta}\right],\qquad h(t) = \frac{\beta}{\eta}\left(\frac{t}{\eta}\right)^{\beta - 1},
$$ {#eq-weibull}
其中**形状参数**（威布尔斜率）$\beta > 0$，**特征寿命**（尺度参数）$\eta > 0$。无论$\beta$为何值，在$t = \eta$处都有$R = e^{-1} = 0.368$：到特征寿命时已有$63.2\,\%$的单元失效。$\beta < 1$给出递减的失效率（早期失效），$\beta = 1$为指数分布，$\beta > 1$给出递增的失效率（耗损失效）；$\beta$约在 3 与 4 之间时，概率密度近乎对称，与正态分布相似。
:::

指数分布是*无记忆的*：无论$t$为何值，$\Prob(T > t + s \mid T > t) = e^{-\lambda s}$，所以用过的单元与新的一样好。对于偶然失效区内的随机失效，这是一个合理的模型，也是大多数电子产品可靠性预计的基础；但对于会磨损的零件它是错误的，而只有当$\beta > 1$时，按计划更换这类零件才有帮助。

::: proposition 威布尔总体的百分位寿命 {#prop-bp-life}
威布尔总体中比例为$p$的单元已经失效时的使用时间$t_p$（$B_p$寿命，$p = 0.10$时记作$B_{10}$或$L_{10}$）为
$$
t_p = \eta\,\bigl[-\ln(1 - p)\bigr]^{1/\beta},
$$ {#eq-bp}
其均值为$\mathrm{MTTF} = \eta\,\Gamma(1 + 1/\beta)$。
:::

::: proof
令$F(t_p) = 1 - \exp[-(t_p/\eta)^\beta] = p$；则$(t_p/\eta)^\beta = -\ln(1 - p)$，整理即得[[#eq-bp]]。对于均值，在$\int_0^\infty \exp[-(t/\eta)^\beta]\,dt$中令$u = (t/\eta)^\beta$，$dt = (\eta/\beta)u^{1/\beta - 1}du$，得$(\eta/\beta)\Gamma(1/\beta) = \eta\,\Gamma(1 + 1/\beta)$。
:::

f: b*x^(b-1); exp(-x^b)
x: 0.02, 2.5
y: 0, 3
sliders: b=1.5:0.5:4:0.1

caption: 威布尔失效率（以特征寿命$\eta$标定）和可靠度与$t/\eta$的关系。设$\beta = 1$：失效率是平的（指数分布，随机失效）。小于 1 时它下降（早期失效）；大于 1 时它上升，$\beta = 2$时线性上升，再大则越来越陡。每条可靠度曲线都在$t/\eta = 1$处通过$R = 0.368$；$\beta$大意味着失效集中在$\eta$附近，这正是定期更换之所以有效的原因。
:::

### 滚动轴承寿命

滚动轴承是最早按概率寿命进行设计的机械零件。依据伦德贝里（Lundberg）与帕姆格伦（Palmgren）1947年的理论，ISO 281 把**基本额定寿命**$L_{10}$定义为：一大批在相同条件下运转的相同轴承中，90 % 在出现滚动接触疲劳的最初迹象之前所能达到或超过的寿命（以百万转计）：
$$
L_{10} = \left(\frac{C}{P}\right)^{p},\qquad p = 3 \text{ 用于球轴承},\ p = \tfrac{10}{3} \text{ 用于滚子轴承},
$$ {#eq-l10}
其中$C$是制造商样本中的基本额定动载荷，$P$是当量动载荷。该标准还对 90 % 以外的可靠度、润滑、污染和疲劳极限加入了修正系数；这些超出了本讲的范围，实际的轴承选择应遵循该标准和制造商的方法。

::: example 轴承寿命与可靠度 {#ex-bearing}
一个$C = 25\,\mathrm{kN}$的球轴承在$1500\,\mathrm{rev/min}$下承受当量载荷$P = 3\,\mathrm{kN}$。(a) 求以小时计的$L_{10}$。(b) 把寿命模拟为$\beta = 1.5$的两参数威布尔分布，求 99 % 可靠度下的寿命，以及在$L_{10}$寿命的两倍时的可靠度。
::: solution
(a) $L_{10} = (25/3)^3 = 578.7$百万转。按每小时$1500\times60 = 90\,000$转，$L_{10} = 578.7\times10^6/90\,000 = 6\,430\,\mathrm h$。

(b) 由[[#eq-bp]]，$t_p \propto [-\ln(1 - p)]^{1/\beta}$，故
$$
\frac{t_{0.01}}{t_{0.10}} = \left(\frac{-\ln 0.99}{-\ln 0.90}\right)^{1/1.5} = \left(\frac{0.01005}{0.1054}\right)^{0.667} = 0.209,
$$
且$L_1 = 0.209\times6\,430 = 1\,342\,\mathrm h$。特征寿命为$\eta = 6\,430/(0.1054)^{1/1.5} = 28\,800\,\mathrm h$，且$R(12\,860\,\mathrm h) = \exp[-(12\,860/28\,800)^{1.5}] = 0.742$。

**合理性检查。** $R(L_{10}) = \exp[-(6430/28\,800)^{1.5}] = 0.90$ ✓。要求 99 % 而不是 90 % 的存活率，寿命降为约五分之一；时间加倍并不使失效加倍——而是使失效从 10 % 升到约 26 %，因为$\beta > 1$。载荷加倍会使$L_{10}$降为$1/2^3 = 1/8$。
:::

### 由试验数据估计威布尔参数

给定试验得到的失效时间，可以用作图法估计参数。把$n$个失效时间排序为$t_1 \le t_2 \le \dots \le t_n$，用**中位秩**估计$F(t_i)$，其伯纳德（Bernard）近似为
$$
F_i \approx \frac{i - 0.3}{n + 0.4}.
$$ {#eq-median-rank}
对$1 - F = \exp[-(t/\eta)^\beta]$取两次对数得$\ln[-\ln(1 - F)] = \beta\ln t - \beta\ln\eta$：在以$\ln t$和$\ln[-\ln(1 - F)]$为坐标的图上（威布尔概率纸），数据点落在一条斜率为$\beta$、在$t = \eta$处过零的直线附近。用最小二乘法拟合这条直线即得估计值。（样本较大时首选最大似然估计；当有些单元尚未失效——截尾数据——时则必须用它；但作图仍然是看出模型是否拟合的最好方法。）

:::

::: example 疲劳试验的威布尔分析 {#ex-weibull-fit}
八个泵隔膜样件一直运行到失效。失效时间（小时）为 410、620、760、890、1020、1180、1390 和 1730。估计$\beta$、$\eta$、$B_{10}$寿命和 MTTF。
::: solution
$n = 8$时由[[#eq-median-rank]]得到的中位秩，以及作图坐标：

| $i$ | $t_i$（h） | $F_i$ | $x = \ln t_i$ | $y = \ln[-\ln(1-F_i)]$ |
|---|---|---|---|---|
| 1 | 410 | 0.0833 | 6.016 | −2.442 |
| 2 | 620 | 0.2024 | 6.430 | −1.487 |
| 3 | 760 | 0.3214 | 6.633 | −0.947 |
| 4 | 890 | 0.4405 | 6.791 | −0.544 |
| 5 | 1020 | 0.5595 | 6.928 | −0.199 |
| 6 | 1180 | 0.6786 | 7.073 | 0.127 |
| 7 | 1390 | 0.7976 | 7.237 | 0.469 |
| 8 | 1730 | 0.9167 | 7.456 | 0.910 |

最小二乘直线$y = \beta x + a$给出$\beta = 2.37$和$a = -16.66$，故$\eta = e^{-a/\beta} = 1\,139\,\mathrm h$。

$B_{10} = 1139\times(0.1054)^{1/2.37} = 440\,\mathrm h$。$\mathrm{MTTF} = 1139\times\Gamma(1 + 1/2.37) = 1139\times0.886 = 1\,009\,\mathrm h$。

**合理性检查。** MTTF 与样本均值$1\,000\,\mathrm h$很接近 ✓，而且$\eta$理应位于数据的第 63 百分位附近（在第 5 个和第 6 个失效之间）。$\beta \approx 2.4$表明是耗损失效，与挠曲隔膜的疲劳相符。只有八个点，估计值是不确定的——由八个点得出的$\beta$的置信区间很宽——因此基于$B_{10}$的设计决策应当使用置信下限，而不是点估计值。
:::

## 系统：框图、冗余与可用度 {#sec-systems}

**可靠性框图**（RBD）表示哪些正常工作的元件组合能使系统保持工作。**串联**的方框必须全部工作；**并联**（工作冗余）的方框只要有一个工作就能提供功能。

::: proposition 串联、并联与 n 中取 k 系统 {#prop-rbd}
对于在同一任务时间内可靠度为$R_i$、独立失效的元件：
$$
R_\text{串联} = \prod_{i=1}^{n} R_i,\qquad R_\text{并联} = 1 - \prod_{i=1}^{n}(1 - R_i),
$$ {#eq-series-parallel}
而对于$n$个可靠度为$R$、其中至少$k$个必须工作的相同单元，
$$
R_{k/n} = \sum_{j=k}^{n}\binom{n}{j}R^j(1 - R)^{n-j}.
$$ {#eq-k-of-n}
:::

::: proof
串联：只有每个元件都工作，系统才工作；由独立性，交事件的概率为乘积。并联：只有每个元件都失效，系统才失效；该交事件的概率为$\prod(1 - R_i)$，$R$为其补。$n$中取$k$：由独立性，正常工作的单元数服从参数为$n$和$R$的二项分布，该数至少为$k$时系统工作。
:::

对于串联的指数分布元件，$\prod e^{-\lambda_it} = e^{-(\sum\lambda_i)t}$：失效率相加。串联系统的好坏只等于其各部分的乘积，因此由 50 个$R = 0.99$的零件组成的系统有$R = 0.99^{50} = 0.61$；这是支持[[design-process/design-for-manufacture]]中减少零件数的有力论据。

只有当冗余单元真正独立失效时，冗余才是强有力的。**共因失效**通过一个共同的原因同时使几个单元失效：同一种受污染的流体、同一个电源、同一个设计错误、同一个维修失误、共用房间中的一场火灾。最简单的模型——**β 因子模型**——假设每个单元的失效概率中有比例为$\beta$的部分源于使所有冗余单元一起失效的原因（这里的符号$\beta$与威布尔斜率无关）。工业安全评估中使用的典型值约为 1 % 到 10 %，视各单元的隔离和多样化程度而定；这时 β 因子通常主宰冗余对的可靠度。

::: example 冷却水泵系统 {#ex-pumps}
一个冷却系统需要一台泵运行；其控制器（一年内$R = 0.98$）和一个隔离阀（$R = 0.95$）与泵串联。每台泵一年内的$R = 0.90$。比较 (a) 一台泵，(b) 两台独立失效的泵工作并联，以及 (c) 两台泵，共因因子$\beta = 0.1$。
::: solution
(a) $R = 0.90\times0.98\times0.95 = 0.838$。

(b) 泵对：$1 - 0.10^2 = 0.990$。系统：$0.990\times0.98\times0.95 = 0.922$。

(c) 每台泵的失效概率$0.10$分为独立部分$(1 - \beta)\times0.10 = 0.09$和共因部分$\beta\times0.10 = 0.01$。若共因不发生、且两台泵不同时独立失效，则泵对工作：$R_\text{泵对} = (1 - 0.01)(1 - 0.09^2) = 0.99\times0.9919 = 0.982$。系统：$0.982\times0.98\times0.95 = 0.914$。

**合理性检查。** 冗余使泵对不可靠度的贡献从$0.10$降到$0.010$，但有共因时为$0.018$，其中一半以上是共因项$0.01$。加了第二台泵之后，阀（不可靠度$0.05$）成了最薄弱的方框：下一步改进应该放在那里，而不是加第三台泵。
:::

### 可修系统与可用度

对于可修产品，**平均故障间隔时间**（MTBF）是相邻两次故障之间的平均工作时间，**平均修复时间**（MTTR）是每次故障的平均停机时间。产品能够工作的时间比例，即其稳态（固有）**可用度**，为
$$
A = \frac{\mathrm{MTBF}}{\mathrm{MTBF} + \mathrm{MTTR}}.
$$ {#eq-availability}
可以通过使故障更少或修复更快来提高可用度。面向维修性的设计——可达性、模块化更换单元、诊断功能、标准工具——能减小 MTTR，而且往往比同等程度地提高 MTBF 更便宜。

:::

::: warning MTBF 不是寿命
$100\,000\,\mathrm h$的 MTBF 并不意味着单元能用大约十一年。对于指数分布，只有$e^{-1} = 37\,\%$的单元能存活到 MTBF，而且 MTBF 数值只描述偶然失效区：它对可能在五年后开始的耗损失效只字未提。同样，对一个实际会磨损的机械零件给出恒定失效率，会得出误导性的更换间隔。要问清楚任何可靠性数字所指的是哪种分布、寿命的哪个区段以及哪种工作条件。
:::

::: quiz
三个元件在任务期内的可靠度均为 0.95，其布置方式是至少有两个工作时系统就工作。系统可靠度是多少？
- [ ] 0.857
- [ ] 0.9025
- [x] 0.99275
- [ ] 0.999875
::: solution
由[[#eq-k-of-n]]，取$k = 2$，$n = 3$：$3R^2(1 - R) + R^3 = 3(0.9025)(0.05) + 0.857375 = 0.135375 + 0.857375 = 0.99275$。第一个选项是三个串联（$0.95^3$），最后一个是三个并联。
:::
:::

## 失效模式与影响分析 {#sec-fmea}

概率模型需要失效数据。在获得这些数据之前，为了确保不遗漏任何重要的东西，设计者要系统地分析设计可能怎样失效。

::: definition 失效模式与影响分析（FMEA） {#def-fmea}
**FMEA** 是一种结构化的、自下而上的团队分析：对设计的每个元件或功能（设计 FMEA），或制造过程的每个步骤（过程 FMEA），检查其可能的**失效模式**（失效的方式：开裂、卡死、泄漏、松动、无输出）、它们对系统和用户的**影响**、它们的**原因**（机理：疲劳、腐蚀、材料用错、公差累积），以及防止原因发生或在失效到达客户之前将其探测出来的**现行控制措施**。传统上每一行按三个 1 到 10 的等级打分：影响的**严重度**$S$、**频度**$O$（原因发生的可能性）和**探测度**$D$（10 = 到客户之前无法探测）。**风险优先数**为$\mathrm{RPN} = S\times O\times D$。然后规划措施以消除原因、降低频度或改善探测，并重新打分。
:::

FMEA 的价值主要在于结构化的讨论及其产生的措施；数字只是排序的手段。RPN 有众所周知的弱点。$S$、$O$和$D$是序数评分——其间隔没有物理意义的等级数——因此它们的乘积不是风险的度量。截然不同的情况可以给出相同的乘积：$S = 10$、$O = 2$、$D = 2$（罕见、可探测但灾难性的失效）与$S = 2$、$O = 5$、$D = 4$（频繁的小麻烦）都得 40。一个团队可以仅靠改善探测，就把一个安全关键项的 RPN 降到措施阈值以下。由于这些原因，2019年为汽车行业出版的 AIAG–VDA 联合 FMEA 手册用**措施优先级**（高、中、低）取代了 RPN 排序，它从表格中查得，首先考虑严重度，其次是频度，最后是探测度。无论采用哪种方案，任何严重度评分很高的失效模式，不论其他评分如何，都需要予以关注。

::: example 起重葫芦制动器的设计 FMEA 片段 {#ex-fmea}
一台小型电动葫芦的弹簧加载、电磁释放式制动器的设计 FMEA 中有以下部分：

| 项目 | 失效模式 | 影响 | 原因 | S | O | D |
|---|---|---|---|---|---|---|
| 制动弹簧 | 断裂 | 制动器无法制动；载荷可能坠落 | 疲劳 | 10 | 2 | 6 |
| 摩擦衬片 | 磨薄 | 制动距离变长 | 正常磨损 | 7 | 6 | 3 |
| 释放线圈 | 断路 | 制动器保持制动；葫芦无法运行 | 接线端处导线疲劳 | 4 | 4 | 2 |

计算各 RPN，按 RPN 对各行排序，并说明这一排序遗漏了什么，以及你会采取什么措施。
::: solution
RPN：弹簧$10\times2\times6 = 120$；衬片$7\times6\times3 = 126$；线圈$4\times4\times2 = 32$。按 RPN，衬片排第一，弹簧排第二，两者几乎相等。

这一排序遗漏了：弹簧失效可能使载荷坠落——严重度为 10，而探测度评分表明这种失效在发生之前不易被发现。无论其 RPN 如何，都应首先处理它。措施：采用几根并联的弹簧，使一根断裂后仍有足够的制动转矩，从而使设计具有失效安全性（针对该失效模式的冗余）；按带裕度的无限疲劳寿命确定弹簧尺寸；并在定期检查中加入制动转矩检查。对于衬片，磨损指示器或磨损检测开关可以降低$D$。对于线圈，在接线端处加应力消除装置可以消除原因；其影响是安全的（制动器失效时处于*制动*状态），这是[[design-process/embodiment-design]]中自保护、失效安全设计原理的一个例子。

**合理性检查。** 采取措施之后，对弹簧一行合理的重新打分可能是$S = 10$（严重度是影响的属性，除非设计改变了影响，否则不会改变）、$O = 1$（多根弹簧）、$D = 4$（检查）：RPN 为 40。注意严重度仍为 10：只有重新设计才能改变它。
:::

## 故障树分析 {#sec-fta}

FMEA 从元件向上分析。**故障树分析**则从单一的不希望发生的**顶事件**——“载荷坠落”“冷却丧失”“压力容器超压”——向下分析，用逻辑门找出导致它的基本事件组合。**或门**在任一输入发生时把故障向上传递；**与门**只在所有输入都发生时才向上传递。

::: definition 最小割集 {#def-cut-set}
**割集**是这样一组基本事件：它们同时发生会导致顶事件。**最小割集**是去掉其中任何一个事件后就不再是割集的割集。顶事件发生，当且仅当至少一个最小割集中的全部事件都发生。只含一个事件的最小割集称为**单点故障**。
:::

对于概率$q_i$很小的独立基本事件，最小割集的概率等于其中各事件概率之积，而顶事件的概率近似等于对各最小割集求和（**稀有事件近似**，为一个上界）：
$$
Q_\text{top} \approx \sum_{\text{割集 } C}\ \prod_{i\in C} q_i.
$$ {#eq-fta}

::: example 冷却丧失的故障树 {#ex-fta}
若两台冗余泵 A 和 B 都失效，或者泵控制器 C 失效，或者供电 D 失效，则机器的冷却丧失（顶事件）。一年内$q_A = q_B = 0.05$，$q_C = 0.002$，$q_D = 0.001$，相互独立。画出故障树，求最小割集和顶事件的概率。
::: solution
故障树：顶事件是一个有三个输入的或门：一个与门（A，B）、基本事件 C、基本事件 D。最小割集：$\{A, B\}$、$\{C\}$、$\{D\}$。C 和 D 是单点故障。

稀有事件近似：$Q \approx 0.05\times0.05 + 0.002 + 0.001 = 0.0025 + 0.002 + 0.001 = 0.0055$。

精确值，由于三个割集没有共同的事件：$Q = 1 - (1 - 0.0025)(1 - 0.002)(1 - 0.001) = 0.00549$。

**合理性检查。** 近似值略微偏高，理应如此 ✓。冗余泵对贡献了 45 % 的风险，两个单点故障贡献 55 %；第二套独立的供电或控制器会比更好的泵更有用。而且必须对独立性假设提出质疑：如果两台泵共用供电 D，故障树中就已经可以看到一个共因事件——揭示这类共同依赖关系，正是故障树的主要作用之一。
:::

:::
## 风险与安全设计 {#sec-risk}

::: definition 风险、危险与风险评估 {#def-risk}
**危险**是潜在的伤害源。**风险**是伤害发生的概率与伤害严重程度的组合。**风险评估**包括识别危险、估计每种危险的风险，以及评价其是否可以接受；在不可接受之处，接着进行**风险减小**。ISO 12100（《机械安全 设计通则 风险评估与风险减小》，*Safety of machinery — General principles for design — Risk assessment and risk reduction*，2010）为机械规定了这一过程。
:::

**风险矩阵**给出一种快速、一致的排序：一个轴是严重度类别（例如可忽略、轻微、严重、重大、灾难性），另一个轴是可能性类别（极不可能到频繁），每个单元格被指定一个风险等级，如低、中或高，并规定每个等级需要采取什么措施。与 RPN 一样，风险矩阵是对序数类别进行相乘或组合，因此应当用于排序和筛选，并在类别边界处小心对待；在后果严重的情况下，要使用定量分析（故障树、事件树）。

ISO 12100 规定了风险减小的**三步法**，必须按顺序应用：
1. **本质安全设计措施**——通过设计本身消除危险或减小风险：通过几何形状消除挤压点，限制力、速度和能量，采用低电压，选用不会燃烧或碎裂的材料，把操纵装置布置在危险区之外。
2. **安全防护和附加保护措施**——防护装置、联锁装置、光幕、双手操纵装置、急停装置，用于无法合理地通过设计消除的风险。
3. **使用信息**——针对剩余风险的警告、标志、说明书和培训要求。

这一顺序是至关重要的：防护装置可能被拆掉，警告可能被忽视，但一个不存在的危险伤害不了任何人。职业安全中通用的控制层级（消除、替代、工程控制、管理控制、个人防护装备）以及[[design-process/embodiment-design]]中的安全基本规则，都体现了同样的优先次序。在欧盟，投放市场的机械必须满足机械法规中的基本健康与安全要求，通常通过 ISO 12100 等协调标准来证明符合性；法律框架见[[design-process/ethics-standards]]。本讲讲授的是原理；安全关键设计由合格的工程师按照现行标准进行评估。

::: history
正式的 FMEA 始于美国军用规程 MIL-P-1629《失效模式、影响及危害性分析实施程序》（*Procedures for Performing a Failure Mode, Effects and Criticality Analysis*），日期为1949年11月；20世纪60年代，美国国家航空航天局（NASA）及其承包商在阿波罗计划中使用了该方法，后来它成为汽车行业的标准做法。斯德哥尔摩皇家理工学院的瓦洛迪·威布尔（Waloddi Weibull）于1951年在《应用力学杂志》（*Journal of Applied Mechanics*）上发表了《一种适用范围广泛的统计分布函数》（“A statistical distribution function of wide applicability”），所举的例子从钢的强度到疲劳寿命；这一分布如今以他的名字命名。古斯塔夫·伦德贝里（Gustaf Lundberg）与阿尔维德·帕姆格伦（Arvid Palmgren）1947年的滚动轴承疲劳寿命理论是 ISO 281 中$L_{10}$额定寿命的基础。故障树分析由贝尔电话实验室的 H. A. 沃森（H. A. Watson）于1961—1962年为美国空军的一项发射控制安全研究而提出，并在波音公司得到进一步发展，再从那里推广到航空和核电安全领域。
:::

::: summary
- $R(t) = \Prob(T > t)$，$h = f/R$，$R(t) = \exp(-\int_0^t h\,du)$，$\mathrm{MTTF} = \int_0^\infty R\,dt$。浴盆曲线：早期失效（$h$下降）、偶然失效（$h$恒定）、耗损失效（$h$上升）。
- 指数分布：$R = e^{-\lambda t}$，无记忆，MTTF $= 1/\lambda$。威布尔分布：$R = \exp[-(t/\eta)^\beta]$；$\beta$决定失效模式；$t_p = \eta[-\ln(1-p)]^{1/\beta}$；由$\ln[-\ln(1-F_i)]$对$\ln t_i$的图估计$\beta$、$\eta$，其中$F_i \approx (i - 0.3)/(n + 0.4)$。
- 球轴承：$L_{10} = (C/P)^3$百万转（ISO 281）。
- 串联$\prod R_i$；并联$1 - \prod(1 - R_i)$；$n$中取$k$为二项分布。共因失效（β 因子）常常主宰冗余系统。$A = \mathrm{MTBF}/(\mathrm{MTBF} + \mathrm{MTTR})$。
- FMEA：模式、影响、原因、控制措施；$\mathrm{RPN} = S\times O\times D$可用于排序，但不是风险的度量——首先处理高严重度项（AIAG–VDA 措施优先级）。
- FTA：顶事件、与门/或门、最小割集，$Q \approx \sum\prod q_i$；单事件割集是单点故障。
- 按顺序进行风险减小（ISO 12100）：本质安全设计，然后安全防护，然后使用信息。
:::

## 习题

::: exercise 恒定失效率 {#exr-exp level=1 check="0.9802"}
一个元件的恒定失效率为每小时$2\times10^{-5}$。它在$1\,000\,\mathrm h$内的可靠度是多少？（输入$R$，保留四位小数。）
::: solution
$R = e^{-2\times10^{-5}\times1000} = e^{-0.02} = 0.98020 \approx 0.9802$。
:::
:::

::: exercise 可用度 {#exr-availability level=1 check="99.60"}
一台机床的 MTBF 为$2\,000\,\mathrm h$，MTTR 为$8\,\mathrm h$。它的固有可用度是多少？（以百分数输入$A$，保留两位小数。）若 MTTR 为$2\,\mathrm h$，又是多少？
::: solution
$A = 2000/2008 = 0.99602 = 99.60\,\%$。$\mathrm{MTTR} = 2\,\mathrm h$时：$2000/2002 = 99.90\,\%$。在每年 4 000 个工作小时中，停机时间约为 16 h 对 4 h。
:::
:::

::: exercise 轴承额定寿命 {#exr-l10 level=1 check="2980"}
一个基本额定动载荷为$19.5\,\mathrm{kN}$的球轴承在$3000\,\mathrm{rev/min}$下承受$2.4\,\mathrm{kN}$的当量载荷。它以小时计的基本额定寿命$L_{10}$是多少？（四舍五入到整数小时。）
::: solution
$L_{10} = (19.5/2.4)^3 = 8.125^3 = 536.4$百万转。按每小时$3000\times60 = 180\,000$转：$536.4\times10^6/180\,000 = 2\,979.9 \approx 2\,980\,\mathrm h$。
:::
:::

::: exercise 威布尔 B10 寿命 {#exr-b10 level=2 check="1623"}
一个元件的寿命服从$\eta = 5\,000\,\mathrm h$、$\beta = 2$的威布尔分布。求其$B_{10}$寿命。（以小时输入，四舍五入到整数小时。）
::: solution
$t_{0.10} = 5000\times(-\ln0.9)^{1/2} = 5000\times\sqrt{0.10536} = 5000\times0.32459 = 1\,623\,\mathrm h$。检查：$R(1623) = \exp[-(1623/5000)^2] = \exp(-0.1054) = 0.900$ ✓。
:::
:::

::: exercise 复制一个元件 {#exr-duplicate level=2 check="0.9401"}
一个系统由三个串联元件组成，每个$R = 0.97$。其中一个以工作并联方式加以复制（独立失效）。新的系统可靠度是多少？（保留四位小数输入。）
::: solution
之前：$0.97^3 = 0.9127$。复制后的元件对：$1 - 0.03^2 = 0.9991$。之后：$0.97^2\times0.9991 = 0.9409\times0.9991 = 0.94005 \approx 0.9401$。收益有限，因为另外两个未复制的元件仍贡献约$0.06$的不可靠度。
:::
:::

::: exercise 三取二 {#exr-2oo3 level=2 check="0.972"}
一个安全系统使用三个相同的传感器进行三取二表决；在验证试验间隔内每个传感器的$R = 0.9$。传感器组的可靠度是多少？（输入精确值。）
::: solution
$R_{2/3} = 3R^2(1 - R) + R^3 = 3R^2 - 2R^3 = 3(0.81) - 2(0.729) = 2.43 - 1.458 = 0.972$。单个传感器为$0.9$，二取一的传感器对为$0.99$；之所以选择三取二，是因为它还能容忍一个传感器在“跳闸”方向上失效而不引起误停车。
:::
:::

::: exercise 措施前后的 RPN {#exr-rpn level=2 check="54"}
一个失效模式的评分为$S = 9$、$O = 5$、$D = 4$。一项设计更改把频度降到$3$，增加的一项试验把探测度改善到$2$。新的 RPN 是多少？什么没有改变？（输入新的 RPN。）
::: solution
之前：$9\times5\times4 = 180$；之后：$9\times3\times2 = 54$。严重度仍为 9：这种失效一旦发生，其后果与以前一样严重。只有改变影响的设计更改（例如失效安全布置）才能降低$S$。
:::
:::

::: exercise 威布尔总体的平均寿命 {#exr-weibull-mean level=3 check="886"}
(a) 由[[#eq-r-from-h]]导出威布尔分布的$\mathrm{MTTF} = \eta\,\Gamma(1 + 1/\beta)$。(b) 证明$\beta = 1$时它化为指数分布的结果。(c) 计算$\eta = 1\,000\,\mathrm h$、$\beta = 2$时的 MTTF。（以小时输入，四舍五入到整数小时。）
::: solution
(a) $\mathrm{MTTF} = \int_0^\infty\exp[-(t/\eta)^\beta]\,dt$。令$u = (t/\eta)^\beta$，则$t = \eta u^{1/\beta}$，$dt = (\eta/\beta)u^{1/\beta - 1}\,du$：利用$\Gamma(1 + x) = x\Gamma(x)$，$\mathrm{MTTF} = (\eta/\beta)\int_0^\infty u^{1/\beta - 1}e^{-u}\,du = (\eta/\beta)\Gamma(1/\beta) = \eta\,\Gamma(1 + 1/\beta)$。

(b) $\beta = 1$：$\eta\,\Gamma(2) = \eta = 1/\lambda$ ✓。

(c) $1000\times\Gamma(1.5) = 1000\times\frac{\sqrt\pi}{2} = 886.2\,\mathrm h \approx 886\,\mathrm h$。均值小于$\eta$，因为到$\eta$时已有 63 % 失效。
:::
:::

::: exercise 台钻的风险评估 {#exr-drill level=3}
一台小型车间用立式（台式）钻床正在重新设计。识别至少四种危险，并对每种危险按顺序依照 ISO 12100 的三步法提出措施。为顶事件“操作者的手接触到旋转的钻夹头”画出故障树草图，并找出你所提设计中的单点故障。你的措施中哪些在 FMEA 中会列为探测控制，哪些会列为预防控制？
::: solution
危险（举例）：头发、袖子或手套被旋转的主轴和钻夹头卷入；工件被钻头卡住并随之旋转（“直升机效应”）；飞出的切屑和折断的钻头；触电；断电后意外启动；噪声。

本质安全设计：限制外露的旋转部分长度；光滑、不挂扯的钻夹头；一体式台虎钳或夹紧工作台，使工件无需手持；双重绝缘；失压保护，使电源恢复时机器不会重新启动；大钻头采用较低的最高转速。

安全防护：可调节的钻夹头防护罩，并与主轴联锁，使防护罩打开时主轴不能运转；在伸手可及处设急停装置；主轴制动器，使停机后惯性运转迅速停止。

使用信息：要求夹紧工件、扎起头发、在主轴附近不戴手套、佩戴护目镜的说明；警告标签。

故障树：顶事件 = 与（手在危险区内，主轴在旋转）。“手在危险区内” = 或（防护罩打开或被拆除，防护罩被规避，从防护罩下方伸手）；“主轴在旋转” = 或（正常运行，停机后惯性运转，意外启动）。如果联锁装置是单个开关，它的失效就是一个双事件割集 {联锁失效，运转时手在危险区内} 的一部分——设计应使联锁装置受到监控或具有冗余，使单个故障能被探测出来。单点故障是任何单独就能导致接触的事件，例如在没有防护罩的设计中。

用 FMEA 的术语来说，联锁装置、防护罩和夹紧台虎钳是预防控制（它们阻止失效原因造成伤害）；联锁自检或对制动器的定期检查是探测控制。好的答案会保持三个步骤的顺序，并说明为什么把每一项剩余风险留给下一步处理。
:::

## 延伸阅读

奥康纳（O'Connor）与克莱纳（Kleyner）的《实用可靠性工程》（*Practical Reliability Engineering*，第5版，Wiley，2012年）从实用工程的角度讨论寿命分布、威布尔分析、系统可靠性、FMEA、故障树和可靠性试验。阿伯内西（Abernethy）的《新威布尔手册》（*The New Weibull Handbook*）是对现场数据和试验数据进行威布尔分析的详细指南。关于机械安全，ISO 12100:2010 本身阐述了风险评估过程和三步法。伦德贝里与帕姆格伦的理论及其现代扩展，在各轴承制造商的技术手册中有所解释。
