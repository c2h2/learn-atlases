::: warning 转矩不是功率除以转速
本课之前的每一课都是从给定的运动算加速度。这一课算给定转矩产生的运动——而你发现的头一件事，是答案并不写在铭牌上。

一台 $10\ \mathrm{kW}$、$3000\ \mathrm{rev / min}$ 的电机并不输出 $31.8\ \mathrm{N \cdot m}$。它输出的是*平均* $31.8\ \mathrm{N \cdot m}$，而它驱动的机构所要求的却是一个振荡转矩，在 [[#sec-eqsys]] 的算例里高达约 $3400\ \mathrm{N \cdot m}$——**超过平均值的一百倍**——哪怕输出轴转得完全匀速。一台 $0.06\ \mathrm{s}$ 内冲 $6000\ \mathrm{J}$ 的压力机不需要 $100\ \mathrm{kW}$ 电机；它需要约 $20$–$25\ \mathrm{kW}$ 的电机加 $73\ \mathrm{kg \cdot m^2}$ 飞轮。而一台 $6000\ \mathrm{rev / min}$ 的四缸汽车发动机，以 $200\ \mathrm{Hz}$ 用 $44.6\ \mathrm{kN}$ 的自由力——相当于四吨半物体的重量——摇动它的悬置，而它内部没有任何不平衡的旋转质量。

三个事实出自同样两个思想：**惯量要在它实际所在之处被计算，而不是在轴所在之处；一个消不掉的力，往往可以被安排去指向别处。**
:::

## 你已经知道的内容

- **相对加速度与加速度影像**——来自 [[mechanisms/acceleration-analysis]]，靠它你求出每个构件质心的速度与加速度随曲柄转角的函数。这些速度除以曲柄角速度，就成为只依赖位置的**速度比**，本课正是建立在它们之上。
- **振动力**——$F_{\mathrm{shake}} = - \sum m_i a_{Gi}$，在 [[mechanisms/acceleration-analysis]] 中作为总质心加速度的负值导出。在这里它从副产品变成设计目标。
- **刚体的功与能**——[[dynamics/work-energy]] 的 $T = \frac{1}{2} J \omega^{2}$ 与动能定理，它是单自由度机器唯一需要的工具。
- **扭转振动与两自由度系统**——来自 [[vibrations/two-degrees-of-freedom]]，因为飞轮和电机电枢就是两根惯量由一根轴相连，而飞轮的转动惯量恰恰是决定它们耦合固有频率落在哪里的参数。
- **强度与疲劳**——来自 [[materials-science/mechanical-properties]]，因为飞轮轮缘像压力容器一样承受环向应力，也因为残余不平衡是一种循环轴承载荷，因而是疲劳寿命问题。

## 等效系统：一个惯量，一个转矩 {#sec-eqsys}

::: definition 等效转动惯量与等效力矩 {#def-eqsys}
一台单自由度机器——压力机、发动机、缝纫机、包装台——只有一个坐标 $\theta$，其中每个速度都正比于 $\dot\theta = \omega$。记构件 $i$ 质心速度比 $v_{Gi} / \omega$ 与角速度比 $\omega_i / \omega$。则该机器在该瞬间动力学上精确等价于

$$
\boxed{ \; J_{\mathrm{eq}} ( \theta ) = \sum_i \left[ m_i \left( \frac{ v_{Gi} }{ \omega } \right)^{ 2 } + I_{Gi} \left( \frac{ \omega_i }{ \omega } \right)^{ 2 } \right] \; } \qquad \text{（对输入轴）}
$$

$$
\boxed{ \; T_{\mathrm{eq}} ( \theta ) = \sum_i F_i \cdot \frac{ v_i }{ \omega } + \sum_i T_i \, \frac{ \omega_i }{ \omega } \; } \qquad \text{（作用在输入轴上，功率等效）}
$$

而运动方程是**能量积分**，不是 $J \alpha = T$：

$$
\frac{ \mathrm{d} }{ \mathrm{d} \theta } \left[ \frac{ 1 }{ 2 } J_{\mathrm{eq}} ( \theta ) \, \omega^{ 2 } \right] = T_{\mathrm{drive}} ( \theta ) - T_{\mathrm{load}} ( \theta )
$$

**$J_{\mathrm{eq}}$ 是位形的函数，不是常数。**对 [[#ex-ieq]] 的曲柄滑块机构，它一转之内变化近四倍，而这个变化本身就是一笔转矩。
:::

::: exercise 推导：$\tfrac{1}{2} \omega^{2} \, \mathrm{d} J_{ \mathrm{eq} } / \mathrm{d} \theta$ 项 {#deriv-dJ level=3}
::: solution
对动能 $K = \frac{1}{2} J_{\mathrm{eq}} ( \theta ) \omega^{2}$ 求时间导数，令其等于瞬时功率：

$$
\frac{ \mathrm{d} K }{ \mathrm{d} t } = \frac{ 1 }{ 2 } J_{\mathrm{eq}} \, 2 \omega \dot\omega + \frac{ 1 }{ 2 } \omega^{ 2 } \frac{ \mathrm{d} J_{\mathrm{eq}} }{ \mathrm{d} \theta } \omega = T_{\mathrm{eq} }
$$

除以 $\omega$，把 $\omega$ 写回 $\dot\theta$：

$$
\boxed{ \; T_{\mathrm{eq}} = J_{\mathrm{eq}} \, \alpha + \frac{ 1 }{ 2 } \frac{ \mathrm{d} J_{\mathrm{eq}} }{ \mathrm{d} \theta } \omega^{ 2 } \; }
$$

**第二项在匀速时也存在。**它是机构改变形状时，驱动为使机构自身各质量加速和减速而必须供给的转矩，它正比于 $\omega^{2}$。

两条决定真实设计的推论：

1. **匀速时 $T_{\mathrm{eq}}$ 中的惯性部分全部就是 $J$ 梯度项**，这是一个均值为零的振荡转矩；曲柄滑块机构的 $J_{\mathrm{eq}}$ 每半转重复一次，因此其基频是曲柄频率的两倍。只按平均转矩定额的电机会发热，因为铜耗取决于 *rms* 电流，而在 [[#ex-ieq]] 中梯度转矩的 rms 约为 $2100\ \mathrm{N \cdot m}$，有效平均转矩却只有 $32\ \mathrm{N \cdot m}$。
2. **该项按 $\omega^{2}$ 增长，而多数工艺的有效转矩大致恒定。**一台在 $500\ \mathrm{rev / min}$ 下工作良好的机构，到 $3000$ 时惯性转矩是原来的 36 倍；在高速连杆机械中，往往是这一项而不是工艺载荷决定了驱动的额定值和转速上限。
:::
:::

::: example 曲柄滑块机构的等效转动惯量 {#ex-ieq}
一曲柄滑块机构：曲柄 $r = 100\ \mathrm{mm}$，连杆 $l = 400\ \mathrm{mm}$（$\lambda = 0.25$），曲柄质量 $2.0\ \mathrm{kg}$、质心距曲柄销轴 $50\ \mathrm{mm}$、$I_{G2} = 2.5 \times 10^{- 3}\ \mathrm{kg \cdot m^2}$，连杆质量 $4.0\ \mathrm{kg}$ 按均质建模，滑块 $3.0\ \mathrm{kg}$。求对曲轴的 $J_{\mathrm{eq}} ( \theta )$，以及让它以恒定 $3000\ \mathrm{rev / min}$ 转动所需的转矩。

**答。**$J_{\mathrm{eq}}$ 在 $20.8$ 与 $80.3\ \mathrm{g \cdot m^2}$ 之间摆动——比值 $3.85$——而匀速转矩的幅值为 $3420\ \mathrm{N \cdot m}$。

::: solution
$\theta$ 从上止点量起，记 $D = \sqrt{ 1 - \lambda^{ 2 } \sin^{ 2 } \theta }$，速度比为

$$
\frac{ v_{\mathrm{slide}} }{ r \omega } = \sin \theta + \frac{ \lambda^{ 2 } \sin \theta \cos \theta }{ D } \equiv u \ , \qquad \frac{ \omega_{\mathrm{rod}} }{ \omega } = \frac{ \lambda \cos \theta }{ D }
$$

取连杆质心在中点，它的速度是曲柄销速度与滑块速度的平均，$\dfrac{ v_{G,\mathrm{rod}} }{ \omega } = \frac{r}{2} \sqrt{ ( u + \sin \theta )^{ 2 } + \cos^{ 2 } \theta }$。曲柄对轴贡献常数 $I_{G2} + m_2 ( 0.05 )^{2} = 7.5\ \mathrm{g \cdot m^2}$，连杆贡献 $m_{\mathrm{rod}} ( v_{G,\mathrm{rod}} / \omega )^{2} + ( m_{\mathrm{rod}} l^{2} / 12 ) ( \omega_{\mathrm{rod}} / \omega )^{2}$，滑块贡献 $m_{\mathrm{slide}} r^{2} u^{2}$。汇总各项：

| $\theta$ | $0^{\circ}$ | $30^{\circ}$ | $60^{\circ}$ | $90^{\circ}$ | $120^{\circ}$ | $150^{\circ}$ | $180^{\circ}$ | $270^{\circ}$ |
|---|---|---|---|---|---|---|---|---|
| $J_{\mathrm{eq}}$，$\mathrm{g \cdot m^2}$ | 20.83 | 40.97 | 73.47 | 77.50 | 54.26 | 30.06 | 20.83 | 77.50 |

最大值 $80.3\ \mathrm{g \cdot m^2}$ 出现在 $\theta = 78^{\circ}$。**惯量在止点最小，在行程中部附近最大**，完全合理：止点处滑块瞬时静止、连杆绕活塞销摆动，而在行程中部附近滑块满速、连杆几乎随它一起平动。（在 $90^{\circ}$ 处校核：$u = 1$，连杆以 $r \omega$ 平动而不转动，故 $J_{\mathrm{eq}} = 7.5 + ( 4.0 + 3.0 ) \times 0.1^{2} \times 10^{3} = 77.5\ \mathrm{g \cdot m^2}$。）

**匀速转矩。**$\omega = 314.16\ \mathrm{rad / s}$ 时，$\frac{1}{2} ( \mathrm{d} J_{\mathrm{eq}} / \mathrm{d} \theta ) \omega^{ 2 }$ 项的峰值为

$$
T = \frac{ 1 }{ 2 } \times 69.4 \times 10^{- 3 } \times 314.16^{ 2 } = 3420\ \mathrm{N \cdot m}
$$

（$J_{\mathrm{eq}}$ 的最大斜率 $69.4\ \mathrm{g \cdot m^2 / rad}$ 出现在 $\theta = 37^{\circ}$），而若机器做 $10\ \mathrm{kW}$ 有效功，平均转矩只有 $31.8\ \mathrm{N \cdot m}$。**为了输出稳定的 $32$，驱动看到的转矩在约 $- 3390$ 与 $+ 3460\ \mathrm{N \cdot m}$ 之间甩动**，rms 约 $2100\ \mathrm{N \cdot m}$。在同一根轴上装两套相同机构，若相位差 $180^{\circ}$ 并无帮助——$J_{\mathrm{eq}}$ 每半转重复，两者的梯度会相加——但相位差 $90^{\circ}$ 时可以抵消占主导的二次谐波。这类伺服驱动轴应按 rms 转矩与峰值转矩而非按功率选型。

**合理性检查。**$3420\ \mathrm{N \cdot m}$ 是合理的：滑块（$3\ \mathrm{kg}$）与连杆（$4\ \mathrm{kg}$）的峰值加速度量级为 $r \omega^{2} ( 1 + \lambda ) = 0.1 \times 314^{2} \times 1.25 \approx 12\,300\ \mathrm{m/s^2}$，即数十千牛的惯性力作用在 $0.1\ \mathrm{m}$ 的曲柄上。
:::

::: exercise 经传动比折算的等效转动惯量 {#ex-geareq level=2 check="3.0"}
上面的机构经一根 $1 : 1$ 的轴驱动载荷，但一位设计师提议把飞轮装在经 $10 : 1$ 增速（飞轮转速十倍于曲柄）的轴上。若飞轮对自身轴有 $J = 0.03\ \mathrm{kg \cdot m^2}$，它在曲柄处对 $J_{\mathrm{eq}}$ 贡献多少（第一问以 $\mathrm{kg \cdot m^2}$ 计）？此时总 $J_{\mathrm{eq}}$ 的峰谷比是多少？

::: solution
惯量经轮系按传动比的**平方**折算：

$$
J_{\mathrm{eq, \, flywheel}} = J \times \left( \frac{ \omega_f }{ \omega_c } \right)^{ 2 } = 0.03 \times 100 = \boxed{ 3.0\ \mathrm{kg \cdot m^2} }
$$

$J_{\mathrm{eq}}$ 的摆动绝对值不变——仍是 $59.5\ \mathrm{g \cdot m^2}$——但作为*分数*，它从 $3.85 : 1$ 的峰谷比塌缩到

$$
\frac{ 3000 + 80.3 }{ 3000 + 20.8 } = 1.020 \ , \qquad \text{即 } 2.0 \ \% \text{ 的波动，而不是 } 285 \ \%
$$

**这就是把飞轮放在高速轴上的理由。**同样 $0.03\ \mathrm{kg \cdot m^2}$ 若直接装在曲柄上，只贡献 $30\ \mathrm{g \cdot m^2}$，比机构本身还小。**一个快速旋转的小惯量，其价值是速比的平方，而速比便宜、质量不便宜。**其代价——见 [[#warn-flywheel]]——是轮缘应力按 $v^{2}$ 增长，储能和任何残余不平衡产生的力也随转速增大，所以快速飞轮需要更仔细的平衡和防护。
:::
:::

## 驱动力矩图

::: definition 驱动力矩图与速度波动系数 {#def-turning}
在机器的一个周期内，把驱动力矩 $T ( \theta )$ 对曲柄转角作图，再画上能做同样功的平均转矩 $T_m$。这张图就叫**驱动力矩图**；**能量波动**是二者之差的逐段积分，

$$
\Delta E ( \theta ) = \int_{ \theta_0 }^{ \theta } \left[ T ( \phi ) - T_m \right] \mathrm{d} \phi
$$

而 $\Delta U = \Delta E_{ \max } - \Delta E_{ \min }$ 是**最大能量波动**——机器在一个周期内必须吞下再吐出的最大能量数。**速度波动系数**为

$$
C_s = \frac{ \omega_{ \max } - \omega_{ \min } }{ \omega_{\mathrm{mean}} } \ , \qquad \omega_{\mathrm{mean}} = \frac{ \omega_{ \max } + \omega_{ \min } }{ 2 }
$$

典型的许用值——它们是规格而不是计算结果，取决于机器的用途：

| 机器 | $C_s$ | 原因 |
|---|---|---|
| 发电机组 | $0.002$–$0.005$ | 频率与电压的稳定 |
| 机床、纺纱与织造机械 | $0.01$–$0.03$ | 表面质量、纱线与套准质量 |
| 泵、压缩机 | $0.03$–$0.05$ | 对速度脉动不敏感 |
| 冲床、剪床、铆接机 | $0.1$–$0.2$ | 工作就是一击；接受冲击期间的降速 |
| 破碎机、锻锤 | 约 $0.2$ | 同上，而且飞轮本身就是工具的一部分 |

这些数值是机械设计教材中常列的参考范围；各行业有各自的数据。
:::

::: exercise 推导：$I_f = \Delta U / ( \omega^{2} C_s )$ {#deriv-fly level=3}
::: solution
在 $\omega_{ \min }$ 与 $\omega_{ \max }$ 之间，机器的动能恰好改变最大能量波动那么多，并且若飞轮主导总惯量（这是假设，也是事后要校核的假设）：

$$
\Delta U = \frac{ 1 }{ 2 } I_f \left( \omega_{ \max }^{ 2 } - \omega_{ \min }^{ 2 } \right) = \frac{ 1 }{ 2 } I_f \left( \omega_{ \max } + \omega_{ \min } \right) \left( \omega_{ \max } - \omega_{ \min } \right) = \frac{ 1 }{ 2 } I_f \times 2 \omega_{\mathrm{mean}} \times C_s \omega_{\mathrm{mean}}
$$

$$
\boxed{ \; I_f = \frac{ \Delta U }{ \omega_{\mathrm{mean}}^{ 2 } \, C_s } \; } \qquad \text{等价地} \qquad \Delta U = I_f \omega_{\mathrm{mean}}^{ 2 } C_s = 2 K \, C_s
$$

**最后这个形式——$\Delta U = 2 K C_s$，其中 $K$ 是储存的动能——才是该拿来思考的那个：速度的相对变化是能量相对变化的一半。**要在 $C_s = 0.05$ 下吸收能量波动 $\Delta U$，飞轮必须储存 $K = \Delta U / ( 2 \times 0.05 ) = 10 \, \Delta U$——这就是为什么压力机飞轮常常是整台机器最重的部件，也是为什么把飞轮做小的有效办法是提高 $\omega$，因为在固定 $C_s$ 下 $I_f \propto 1 / \omega^{ 2 }$。

**两点提醒。**第一，$I_f$ 是折算到测量 $\omega$ 那根轴上的*附加*惯量；若机器自身运动件已经贡献了可观的 $J_{\mathrm{eq}}$，要把它减去——并且记住 [[#ex-ieq]] 里 $J_{\mathrm{eq}}$ 不是常数。第二，公式假设飞轮的惯量是常数，所以**装在曲柄滑块机构曲轴上的飞轮，是在跟一个与它自己同量级的 $\Delta J_{\mathrm{eq}}$ 打架**；装在增速轴上则不是，这正是 [[#ex-geareq]] 的实际含义。
:::
:::

::: example 单缸发电机组的飞轮 {#ex-1cyl}
一台单缸四冲程发动机，排量 $500\ \mathrm{cm^3}$，制动平均有效压力 $8\ \mathrm{bar}$，以 $3000\ \mathrm{rev / min}$ 拖动发电机。把膨胀冲程建模为持续 $180^{\circ}$ 曲柄角的半正弦波，忽略泵气与压缩回线。求 $C_s = 0.005$ 所需的飞轮转动惯量。

**答。**$\Delta U = 305\ \mathrm{J}$，$I_f = 0.62\ \mathrm{kg \cdot m^2}$——约合平均直径 $400\ \mathrm{mm}$ 的铸铁轮缘 $15\ \mathrm{kg}$。

::: solution
每循环功 $=$ 制动平均有效压力 $\times$ 排量 $= 8 \times 10^{ 5 } \times 5 \times 10^{- 4 } = 400\ \mathrm{J}$，每 $720^{\circ} = 4 \pi$ 弧度曲柄角输出一次，于是

$$
T_m = \frac{ 400 }{ 4 \pi } = 31.83\ \mathrm{N \cdot m} \ , \qquad P = T_m \omega = 31.83 \times 314.16 = 10.0\ \mathrm{kW}
$$

半正弦波 $T_p \sin \theta$（$0 \le \theta \le \pi$）的面积为 $2 T_p$，故 $T_p = 400 / 2 = 200\ \mathrm{N \cdot m}$。它在 $200 \sin \theta = 31.83$ 处穿过平均线，即 $\theta = 9.16^{\circ}$ 与 $170.84^{\circ}$（$0.1598$ 与 $2.9818\ \mathrm{rad}$）。累积能量 $\Delta E$ 在第一个交点处最小、在第二个交点处最大（冲程之后，在其余 $540^{\circ}$ 内线性回落到零），所以最大能量波动就是平均线上方的面积：

$$
\Delta U = \int_{ 0.1598 }^{ 2.9818 } \! \left( 200 \sin \theta - 31.83 \right) \mathrm{d} \theta = 2 \times 200 \cos 9.16^{\circ} - 31.83 \times 2.8220 = 394.9 - 89.8 = 305.1\ \mathrm{J}
$$

$$
I_f = \frac{ 305.1 }{ 314.16^{ 2 } \times 0.005 } = \frac{ 305.1 }{ 493.5 } = 0.618\ \mathrm{kg \cdot m^2}
$$

平均半径 $0.20\ \mathrm{m}$ 的薄轮缘有 $I = m r^{ 2 }$，故 $m = 0.618 / 0.04 = 15.5\ \mathrm{kg}$。轮缘速度 $v = \omega r = 62.8\ \mathrm{m / s}$，环向应力 $\sigma = \rho v^{ 2 } = 7200 \times 62.8^{ 2 } = 28.4\ \mathrm{MPa}$——在合理安全系数下灰铸铁可以承受，这就是小型发动机飞轮至今仍用铸造的原因。

**合理性检查。**$\Delta U = 305\ \mathrm{J}$ 是 $400\ \mathrm{J}$ 循环功的 $76\ \%$，当几乎全部功都集中在四个冲程中的一个时，理应如此。

caption: 同一冲程的 $\Delta E ( \theta ) = \int_0^ \theta ( T - T_m ) \, d \theta$。**飞轮的任务量由这条曲线的纵向范围决定，而不是由峰值转矩决定**——$\Delta U = 305\ \mathrm{J}$ 是从低谷（$9.2^{\circ}$ 处 $- 2.5\ \mathrm{J}$）到峰值（$170.8^{\circ}$ 处 $302.5\ \mathrm{J}$）的高度。在 $180^{\circ}$ 处曲线为 $300\ \mathrm{J}$；在随后没有气体转矩的 $540^{\circ}$ 内，飞轮把这些能量还回去，$\Delta E$ 在 $720^{\circ}$ 处线性回落到零。

**被忽略的回线会做什么。**压缩冲程恰在膨胀冲程之前从飞轮取走能量，而真实的气体转矩不是半正弦波，而是上止点后不久的一个尖峰接一条下降的尾巴。两者都会加深低谷、使 $\Delta U$ 高于半正弦估算，所以实际设计要用实测或仿真的缸压图来计算。**方法不变，变的只是输入。**
:::

::: example 冲床：飞轮就是机器本身 {#ex-punch}
一冲头在 $20\ \mathrm{mm}$ 行程上施加 $300\ \mathrm{kN}$。曲轴以 $200\ \mathrm{rev / min}$ 转动，每转冲一次，冲压过程占 $0.06\ \mathrm{s}$——曲柄 $72^{\circ}$。许用 $C_s = 0.15$。确定飞轮与电动机。

**答。**$I_f = 73\ \mathrm{kg \cdot m^2}$，平均直径 $1.0\ \mathrm{m}$ 的轮缘 $292\ \mathrm{kg}$；电动机平均输出 $20\ \mathrm{kW}$（选 $25\ \mathrm{kW}$ 留有余量），否则需要 $100\ \mathrm{kW}$。

::: solution
每次冲压功 $= 300 \times 10^{ 3 } \times 0.020 = 6000\ \mathrm{J}$，在 $0.30\ \mathrm{s}$ 周期中的 $0.06\ \mathrm{s}$ 内交付。**若由电动机直接供给，峰值功率为：$6000 / 0.06 = 100\ \mathrm{kW}$。**平均功率：$6000 / 0.30 = 20\ \mathrm{kW}$。

稳定运行时电动机必须供给平均转矩 $T_m = 6000 / 2 \pi = 955\ \mathrm{N \cdot m}$（$\omega = 20.94\ \mathrm{rad / s}$，即 $20\ \mathrm{kW}$）；为留余量选 $25\ \mathrm{kW}$ 电动机，但稳态下它仍只输出平均值。冲压期间载荷转矩为 $6000 / 1.2566 = 4775\ \mathrm{N \cdot m}$，所以飞轮必须供给

$$
\Delta U = ( 4775 - 955 ) \times 1.2566 = 4800\ \mathrm{J}
$$

这恰好是冲压能量减去电动机在 $72^{\circ}$ 冲压期间输出的能量，$6000 \times ( 1 - 72 / 360 )$。于是

$$
I_f = \frac{ 4800 }{ 20.94^{ 2 } \times 0.15 } = \frac{ 4800 }{ 65.8 } = 73.0\ \mathrm{kg \cdot m^2}
$$

平均直径 $1.0\ \mathrm{m}$ 的薄轮缘需要 $m = 73.0 / 0.5^{ 2 } = 292\ \mathrm{kg}$。轮缘速度只有 $10.5\ \mathrm{m / s}$，所以环向应力为 $0.79\ \mathrm{MPa}$——**飞轮离它的应力极限远得很，这意味着它是一台便宜、笨重、铸造、慢速的机器，而这正是一台压力机飞轮应有的样子。**

caption: $\Delta U = 4800\ \mathrm{J}$、$200\ \mathrm{rev / min}$ 下的 $C_s = \Delta U / ( \omega^{ 2 } I_f )$。**曲线是等轴双曲线：波动减半，惯量翻倍。**在 $73\ \mathrm{kg \cdot m^2}$ 处设计落在 $C_s = 0.15$；收紧到 $C_s = 0.05$ 需要 $219\ \mathrm{kg \cdot m^2}$，同样直径下是 $875\ \mathrm{kg}$ 的轮缘。更便宜的办法是把飞轮装在更快的轴上，因为 $I_f \propto 1 / \omega^{ 2 }$——这就是压力机通常把飞轮装在减速传动电机侧轴上的原因（见 [[#sec-design]]）。

::: warning 飞轮做不到的四件事 {#warn-flywheel}
飞轮是一个增益固定的能量缓冲器，由此推出四条常被想当然地忽略的结论。

1. **它不降低峰值转矩。**冲头在曲柄处仍然看到 $4775\ \mathrm{N \cdot m}$、在滑块处仍然看到 $300\ \mathrm{kN}$。曲轴、齿轮、机架、轴承全由这个数定尺寸，再多的飞轮也改变不了它们。**飞轮降低的是从电网取用的峰值*功率*，永远不是机器内的峰值*力*。**
2. **它不调节转速；它限制转速变化的速率。**平均转速由电动机（或调速器）决定；飞轮只平滑一个周期内的波动。驱动脱开后，带飞轮的压力机带着全部储能继续滑行，这就是为什么压力机的离合器与制动器必须能在飞轮仍在全速时停住滑块。
3. **它无法平滑它没有储存的东西。**$C_s$ 由 $\Delta U$ 对*总*储存能量决定，$C_s = \Delta U / ( 2 K )$，$K = \frac{1}{2} I \omega^{ 2 }$。一个 $\mathrm{kg \cdot m^2}$ 很大但转得慢的惯量储能很少，所以只报 $I$ 而不说明对应的 $\omega$——即装在哪根轴上——是常见的选型错误。
4. **它储存的能量必须被包容。**以 $v = 100\ \mathrm{m / s}$ 运转的轮缘，每千克储存 $v^{2} / 2 = 5\ \mathrm{kJ}$；$292\ \mathrm{kg}$ 的压力机轮缘以 $10.5\ \mathrm{m / s}$ 运转储存 $16\ \mathrm{kJ}$。飞轮破裂时碎片大致以轮缘速度飞出，所以飞轮按破裂转速留有充裕余量设计、加防护罩，高速飞轮还要做超速旋转试验。
:::

::: exercise 发电机组的速度波动 {level=1 check="0.005"}
[[#ex-1cyl]] 的单缸机组在 $3000\ \mathrm{rev / min}$ 下 $\Delta U = 305\ \mathrm{J}$，飞轮 $I_f = 0.618\ \mathrm{kg \cdot m^2}$。$C_s$ 是多少（以小数表示）？对应多少转每分的速度摆动？

::: solution
$$
C_s = \frac{ \Delta U }{ I_f \omega^{ 2 } } = \frac{ 305.1 }{ 0.618 \times 314.16^{ 2 } } = \frac{ 305.1 }{ 61{,}000 } = \boxed{ 0.005 } \quad \Rightarrow \quad 0.005 \times 3000 = 15\ \mathrm{rev / min}
$$

**在 $3000\ \mathrm{rev / min}$ 的轴上有十五转每分的脉动——相对平均值 $\pm 0.25\ \%$——每个发动机循环即每两转重复一次（$25\ \mathrm{Hz}$）。**对 $50\ \mathrm{Hz}$ 交流发电机，这就是 $\pm 0.125\ \mathrm{Hz}$ 的周期性频率与电压脉动，这就是单缸发电机组要带较大飞轮的原因，而转矩平稳的同功率电动机则不需要飞轮。
:::
:::

::: exercise 转速翻倍 {#ex-doubling level=2 check="0.005"}
一台机床的飞轮在 $1500\ \mathrm{rev / min}$ 下给出 $C_s = 0.02$。工厂工程师把主轴转速翻倍到 $3000\ \mathrm{rev / min}$，飞轮不变、每循环 $\Delta U$ 不变。新的 $C_s$ 是多少？

::: solution
$I_f \omega^{ 2 } C_s = \Delta U$，$I_f$ 与 $\Delta U$ 不变，故 $C_s \propto 1 / \omega^{ 2 }$：

$$
C_s = 0.02 \times \left( \frac{ 1500 }{ 3000 } \right)^{ 2 } = \boxed{ 0.005 }
$$

**四倍的改善——转速是飞轮设计中威力最大的杠杆。**但要注意 $\Delta U$ 并不总是不变。若工艺每循环需要固定的能量——压力机的一次冲程、排量和压力固定的泵——转速翻倍只是把*速率*翻倍，每循环能量不变，结论成立。但若周期性转矩是惯性的或随转速增长——例如连杆机构的梯度转矩按 $\omega^{2}$ 增长——则每循环 $\Delta U$ 也按 $\omega^{2}$ 增长，$C_s$ 根本不会改善。**庆祝之前先弄清你面对的是哪一种。**
:::
:::

## 平衡（一）：转子，以及为什么两个平面是最少的

::: definition 静平衡与动平衡 {#def-balance}
为转子的每个圆盘 $i$ 附加一个**不平衡矢量** $U_i = m_i r_i$：它是一个平面极矢量，大小为（质量 $\times$ 半径）、方位在质量中心的角位置上；再记其轴向位置为 $z_i$。则

$$
\textbf{静平衡：} \quad \boxed{ \; \sum_i U_i = 0 \; } \qquad \text{（无合成离心力）}
$$

$$
\textbf{动平衡：} \quad \boxed{ \; \sum_i U_i = 0 \quad \text{且} \quad \sum_i z_i U_i = 0 \; } \qquad \text{（既无合力也无合力偶）}
$$

两者都是**矢量**方程，所以各含两个标量条件，动平衡一共是四个条件。**一根静平衡的细长转子并不是动平衡的：同一平面内两个相等的质量互相抵消，但同样两个质量若在不同平面，就构成一个每转反向两次的力偶，在轴承上感受到的是力矩而不是力。**这就是为什么平衡机有两个拾振传感器而不是一个，也是为什么校正永远要在两个平面上做。
:::

::: exercise 推导：两平面校正 {#deriv-2plane level=3}
::: solution
在平面 $a$、$b$ 内添加校正不平衡 $C_a$ 与 $C_b$。两个条件化为

$$
C_a + C_b = - \sum_i U_i \equiv - S \ , \qquad a \, C_a + b \, C_b = - \sum_i z_i U_i \equiv - M
$$

两个关于两个未知矢量的矢量方程：四个标量方程、四个未知量，故解唯一，为

$$
\boxed{ \; C_b = \frac{ - M + a S }{ b - a } \ , \qquad C_a = - S - C_b \; }
$$

**读一读分母。**所需校正与**校正平面的间距** $b - a$ 成反比。把两个平面挪近，配重大致按间距的反比增大，而校正后的剩余不平衡两种情况下都为零——**平衡机会报告一个靠大量配重换来的完美平衡，只有配重的大小才表明平面选得不好。**

第二件要读的事是 $C_a$ 与 $C_b$ 是复数：它们有相位，而这些相位通常与原始不平衡的相位不同。大小正确但相位误差为 $\delta$ 的校正，会留下原不平衡 $2 \sin ( \delta / 2 )$ 倍的残余：$30^{\circ}$ 时约为一半，$60^{\circ}$ 时与校正前一样大。**相位精度与大小同样重要，这就是平衡需要标定良好的相位基准的原因。**
:::
:::

::: example 双盘转子的两平面校正 {#ex-2plane}
一转子在平面 $z = 0$ 内带有 $0^{\circ}$ 方向的 $U_1 = 0.100\ \mathrm{kg \cdot m}$，在平面 $z = 0.5\ \mathrm{m}$ 内带有 $90^{\circ}$ 方向的 $U_2 = 0.080\ \mathrm{kg \cdot m}$。求半径 $150\ \mathrm{mm}$ 处、在（a）$z = 0.1$ 与 $0.4\ \mathrm{m}$、（b）$z = 0.2$ 与 $0.3\ \mathrm{m}$ 的校正质量。

**答。**（a）$168.7^{\circ}$ 方向 $0.906\ \mathrm{kg}$、$- 72.6^{\circ}$ 方向 $0.745\ \mathrm{kg}$。（b）$151.9^{\circ}$ 方向 $2.267\ \mathrm{kg}$ 与 $- 50.2^{\circ}$ 方向 $2.083\ \mathrm{kg}$——**$2.6$ 倍的质量，换来一模一样的剩余平衡。**

::: solution
用复数计算。$S = U_1 + U_2 = 0.100 + \mathrm{j} 0.080$；对 $z = 0$ 取矩，$M = 0 \times U_1 + 0.5 \times U_2 = \mathrm{j} 0.040$。

**（a）平面在 $a = 0.1$、$b = 0.4$：**

$$
C_b = \frac{ - \mathrm{j} 0.040 + 0.1 ( 0.100 + \mathrm{j} 0.080 ) }{ 0.3 } = \frac{ 0.0100 - \mathrm{j} 0.0320 }{ 0.3 } = 0.03333 - \mathrm{j} 0.10667
$$

$$
\left| C_b \right| = 0.1118\ \mathrm{kg \cdot m} \ \text{在} \ - 72.6^{ \circ } \ , \qquad
C_a = - S - C_b = - 0.1333 + \mathrm{j} 0.0267 \ \Rightarrow \ \left| C_a \right| = 0.1360 \ \text{在} \ 168.7^{ \circ }
$$

除以 $r = 0.15\ \mathrm{m}$：**$m_a = 0.906\ \mathrm{kg}$，$m_b = 0.745\ \mathrm{kg}$。**

**（b）平面在 $a = 0.2$、$b = 0.3$：**分母减半，

$$
C_b = \frac{ 0.0200 - \mathrm{j} 0.0240 }{ 0.1 } = 0.200 - \mathrm{j} 0.240 \ \Rightarrow \ \left| C_b \right| = 0.3124 \ , \qquad C_a = - 0.300 + \mathrm{j} 0.160 \ \Rightarrow \ \left| C_a \right| = 0.3400
$$

**$m_a = 2.267\ \mathrm{kg}$，$m_b = 2.083\ \mathrm{kg}$——同样的零剩余不平衡，总质量却是情形（a）的 $2.6$ 倍。**

**（c）作为对比，平面取 $a = 0$、$b = 0.6$，即跨过两个质量平面：**$C_a = 0.1009$ 在 $- 172.4^{ \circ }$，$C_b = 0.0667$ 在 $- 90^{ \circ }$，得 $0.673$ 与 $0.444\ \mathrm{kg}$，合计 $1.117\ \mathrm{kg}$。**三种布置中最好的一个，所需质量只有最坏者的 $1 / 3.9$。**

::: warning 校正平面放在哪里是设计决策，不是平衡决策
这条规则出自 [[#deriv-2plane]] 里的 $1 / ( b - a )$，值得背下来，因为它在图纸上只做一次，却要在产品的整个寿命里、在每一台平衡机上付账：

- **把校正平面放到轴承跨距允许的尽可能远的位置**，若设计允许，放到被校正质量所在平面之外。
- **避免在质量平面之间采用间距很小的校正平面**——那种几何让 $b - a$ 变小、让配重变大。
- **把转子设计成可校正的。**在靠近两端、大半径处设可加工的校正面，图纸上注明平衡工艺与最大钻孔深度——成本很低，却能使校正质量保持很小。
- **通常宁可去重，不要加重。**加上的配重必须抵抗自身的离心力——$0.9\ \mathrm{kg}$ 的配重在 $0.15\ \mathrm{m}$ 半径、$3000\ \mathrm{rev / min}$ 下的拉力为 $0.9 \times 0.15 \times 314.16^{ 2 } = 13.3\ \mathrm{kN}$——而钻出的孔不会松脱。
:::
:::
:::

::: definition 平衡品质等级，ISO 1940-1 {#def-ggrade}
标准规定的不是力；它规定的是**比不平衡量**——许用剩余量 $e_{\mathrm{per}} = U_{\mathrm{per}} / m$，以微米计的偏心距——并按工作转速列成**等级** $G$：

$$
\boxed{ \; e_{\mathrm{per}} \left[ \mu \mathrm{m} \right] = \frac{ 1000 \, G }{ \omega } = \frac{ 9549 \, G }{ n \left[ \mathrm{rev / min} \right] } \; } \qquad U_{\mathrm{per}} = m \, e_{\mathrm{per}}
$$

**等级号是一个速度。** $e_{\mathrm{per}} \omega = G\ \mathrm{mm / s}$ 是转子质心沿半径为 $e_{\mathrm{per}}$ 的轨道运行的速度——所以 $G 2.5$ 与 $G 63$ 相差二十五倍的是摆动的速度，不是金属的多少。

| 等级 $G$ | 典型转子 | $3000\ \mathrm{rev / min}$ 下的 $e_{\mathrm{per}}$ |
|---|---|---|
| $G \ 0.4$ | 陀螺仪、精密磨床主轴 | $1.3\ \mu \mathrm{m}$ |
| $G \ 1$ | 磨床传动、有特殊要求的小型电枢 | $3.2\ \mu \mathrm{m}$ |
| $G \ 2.5$ | 燃气轮机与汽轮机、透平压缩机、机床传动 | $7.96\ \mu \mathrm{m}$ |
| $G \ 6.3$ | 风机、泵、飞轮、一般电机电枢、机床零件 | $20.1\ \mu \mathrm{m}$ |
| $G \ 16$ | 万向轴与传动轴、农业机械与破碎机零件 | $51\ \mu \mathrm{m}$ |
| $G \ 40$ | 汽车车轮与轮辋 | $127\ \mu \mathrm{m}$ |
| $G \ 630$ | 刚性安装的大型发动机曲轴传动 | $2005\ \mu \mathrm{m}$ |

示例取自 ISO 1940-1（现为 ISO 21940-11）的经典表格；具体转子应查阅标准。
:::

::: example 一个等级要花多少金属 {#ex-grade}
一台 $15\ \mathrm{kg}$ 的机床电枢按 $G \ 6.3$ 平衡，用于 $3000\ \mathrm{rev / min}$。允许多大的剩余不平衡？它在轴承上产生多大的力？

**答。**$U_{\mathrm{per}} = 301\ \mathrm{g \cdot mm}$，支承上的旋转力至多 $29.7\ \mathrm{N}$。

::: solution
$$
e_{\mathrm{per}} = \frac{ 9549 \times 6.3 }{ 3000 } = 20.1\ \mu \mathrm{m} \ , \qquad
U_{\mathrm{per}} = 15 \times 20.1 \times 10^{- 6 } = 3.01 \times 10^{- 4 }\ \mathrm{kg \cdot m} = 301\ \mathrm{g \cdot mm}
$$

$\omega = 314.16\ \mathrm{rad / s}$ 时支承上的交变力为

$$
F = U_{\mathrm{per}} \, \omega^{ 2 } = 3.01 \times 10^{- 4 } \times 98{,}696 = 29.7\ \mathrm{N}
$$

由两个轴承分担（许用剩余量通常分配到两个校正平面）。**而 $301\ \mathrm{g \cdot mm}$ 是个惊人的小数字：它相当于 $10\ \mathrm{mm}$ 半径上 $30\ \mathrm{g}$，或 $15\ \mathrm{mm}$ 半径上 $20\ \mathrm{g}$——两颗小螺钉。**这就是平衡的难处：公差与装到转子上的零件同一量级，所以转子应**在它将要运行的状态下**平衡——带着键、风扇和附件——或者逐一计入每个附加零件的影响。

**也注意等级没有说什么。**它对*共振*只字未提。一台按等级平衡好的转子，在 $3000\ \mathrm{rev / min}$ 下运行于固有频率接近 $2800\ \mathrm{rev / min}$ 的支承上，照样会强烈振动，因为等级限制的是激振力，而支承的动态刚度决定响应。**平衡品质与振动水平相关，但不是一回事。**
:::
:::

::: exercise 校正平面的间距 {level=2 check="2.63"}
对 [[#ex-2plane]] 的转子，计算校正平面在 $z = 0.2$ 与 $0.3\ \mathrm{m}$ 时 $r = 150\ \mathrm{mm}$ 处的校正质量总和，再除以平面在 $z = 0.1$ 与 $0.4\ \mathrm{m}$ 时的总和（比值保留两位小数）。

::: solution
由 [[#ex-2plane]]，两种情形给出 $2.267 + 2.083 = 4.350\ \mathrm{kg}$ 与 $0.906 + 0.745 = 1.651\ \mathrm{kg}$，故比值为

$$
\frac{ 4.350 }{ 1.651 } = \boxed{ 2.63 }
$$

**接近但不等于平面间距之比 $0.30 / 0.10 = 3.0$**：$1 / ( b - a )$ 因子起主导作用，但分子 $- M + a S$ 也随平面位置而变。两台转子离开平衡机时都是完美平衡的。间距小的那台多带了 $2.7\ \mathrm{kg}$ 校正质量在 $150\ \mathrm{mm}$ 半径上——金属更多，相互对抗的大校正量使转子内部受弯，可能松脱的东西也更多。**这就是为什么校正平面的位置应画在制造图纸上。**
:::
:::

## 平衡（二）：往复质量，与二阶问题

::: definition 一阶与二阶惯性力 {#def-primary}
往复质量 $m_R$ 的滑块由半径 $r$、连杆长 $l$（记 $n = l / r$）的曲柄驱动，其加速度为

$$
a = r \omega^{ 2 } \left( \cos \theta + \frac{ \cos 2 \theta }{ n } + \cdots \right)
$$

（级数截取到二次谐波，当 $n \ge 3$ 时这是极好的近似），于是机架必须反承的惯性力是两个谐波之和：

$$
\boxed{ \; F = \underbrace{ m_R r \omega^{ 2 } \cos \theta }_{ \textbf{一阶} \; \equiv P } + \underbrace{ \frac{ m_R r \omega^{ 2 } }{ n } \cos 2 \theta }_{ \textbf{二阶} \; = P / n } \; }
$$

**一阶力就是假设连杆无限长时往复质量所经历的力；它恰好是把往复质量想象成集中在曲柄销上时，其离心力沿往复方向的分量。**下面的大部分结论都由这幅图像推出。

**二阶力只因连杆有限长而存在**，比一阶小一个连杆比 $n$，并以**两倍**于曲柄的频率运转。短连杆（$n = 3$）的二阶力是一阶的三分之一；长连杆（$n = 6$）是六分之一。较长的连杆减小二阶力，代价是发动机更高、更重——这是每一次选择连杆比时的折中之一。
:::

::: example 单缸机，以及部分平衡意味着什么 {#ex-single}
$m_R = 2.4\ \mathrm{kg}$，$r = 45\ \mathrm{mm}$，$l = 180\ \mathrm{mm}$（$n = 4$），$3000\ \mathrm{rev / min}$，曲柄销处旋转质量 $1.6\ \mathrm{kg}$。求不平衡力，并求使其中最坏者最小的平衡分数。

**答。**一阶力 $10.66\ \mathrm{kN}$，二阶力 $2.67\ \mathrm{kN}$，旋转力 $7.11\ \mathrm{kN}$；最优平衡分数为 $c = 0.5$，留下 $5.33\ \mathrm{kN}$ 的旋转残余力。

::: solution
$$
P = m_R r \omega^{ 2 } = 2.4 \times 0.045 \times 314.16^{ 2 } = 10{,}660\ \mathrm{N} \ , \qquad S = \frac{ P }{ n } = 2665\ \mathrm{N}
$$
$$
F_{\mathrm{rot}} = m_C r \omega^{ 2 } = 1.6 \times 0.045 \times 98{,}696 = 7106\ \mathrm{N}
$$

旋转力好办：在曲柄臂上对着销的位置放 $m_{\mathrm{cw}} = m_C r / r_{\mathrm{cw}}$，它就消失了。**往复力无法被任何旋转质量抵消，因为它是沿一条直线振荡而不是旋转的。**分数为 $c$ 的旋转平衡块做的是这件事：它加上一个大小 $c P$ 的旋转矢量，其沿往复方向的分量是 $c P \cos \theta$——抵消掉一阶力的 $c$——而其横向分量是 $c P \sin \theta$，这是原来没有的：

$$
F_{ \parallel } = ( 1 - c ) P \cos \theta \ , \qquad F_{ \perp } = c P \sin \theta
$$

**你把沿缸方向的抖动换成了横向抖动，而最坏情形永远不低于 $0.5 P$。**合力大小 $\sqrt{ ( 1 - c ) ^{ 2 } P^{ 2 } \cos^{ 2 } \theta + c^{ 2 } P^{ 2 } \sin^{ 2 } \theta }$ 在 $c P$ 与 $( 1 - c ) P$ 之间摆动；最坏情形在 $c = 0.5$ 处最小，此时合力变成一个大小恒为 $P / 2 = 5330\ \mathrm{N}$ 的**旋转**力。

**这就是蒸汽机车的折中。**气缸水平布置的机车只能把平衡块放在动轮里，因此只平衡一部分往复质量——通常约 $40$–$50\ \%$——并用**锤击力**付账：即车轮平衡块的竖直分量 $c P \sin \theta$，它交替地加载与卸载车轮对钢轨的压力，并随速度平方增长。（对本例的小发动机，$c = 0.6$ 时横向分量幅值为 $0.6 \times 10.66 = 6.4\ \mathrm{kN}$。）

**彻底的解法只用旋转质量：两个以曲柄转速反向旋转的配重，各带不平衡量 $m_R r / 2$，相位安排得使它们沿往复方向的分量相加以抵消一阶力，而横向分量相互抵消。**不产生侧向力，一阶力就此消失。这种一阶平衡轴用于某些单缸发动机；以两倍曲柄转速运转的同一原理可以抵消二阶力，如 [[#ex-ic4]]。
:::
:::

::: theorem 直列发动机里哪些阶次活了下来 {#thm-inline}
对曲柄角为 $\theta_i$、气缸中心线位于 $z_i$ 的直列发动机，四个条件是

$$
\sum_i \cos \theta_i = \sum_i \sin \theta_i = 0 \quad \text{（一阶力）} \qquad \sum_i z_i \cos \theta_i = \sum_i z_i \sin \theta_i = 0 \quad \text{（一阶力偶）}
$$

二阶则是同样的四个式子、把 $\theta_i$ 换成 $2 \theta_i$。**因为二阶角被翻倍，相隔 $180^{\circ}$ 的曲柄——经典的一阶抵消对——其二阶却相隔 $360^{\circ}$，即同相。**因此每一个靠把曲柄摆成对置来抵消一阶力的布置，都会把它的二阶力*加倍*而不是抵消。

**直列四缸**（$\theta = 0 , 180 , 180 , 0$；$z = - 3 d , - d , + d , + 3 d$）：

| 条件 | 求和 | 结果 |
|---|---|---|
| 一阶力 | $2 \cos \theta - 2 \cos \theta$ | $0$ ✓ |
| 一阶力偶 | $- 3 d \cos \theta + d \cos \theta - d \cos \theta + 3 d \cos \theta$ | $0$ ✓ |
| 二阶力 | $4 \cos 2 \theta$ | **$4 P / n$——不平衡** |
| 二阶力偶 | $4 \cos 2 \theta ( - 3 d - d + d + 3 d )$ | $0$ ✓ |

**所以直列四缸除了一个沿气缸线、以两倍曲柄频率振荡的 $4 P / n$ 自由力之外是完全平衡的。**它没有不平衡力偶、没有不平衡旋转质量、没有任何一阶抖动——可它仍然在抖，这就是许多排量较大的直列四缸带有一对平衡轴的原因。
:::

::: example 直列四缸的二阶力与其平衡轴 {#ex-ic4}
每缸 $m_R = 2.2\ \mathrm{kg}$，$r = 43\ \mathrm{mm}$，$l = 144\ \mathrm{mm}$（$n = 3.35$），$6000\ \mathrm{rev / min}$。求二阶力，以及抵消它所需的平衡轴不平衡量。

**答。**$200\ \mathrm{Hz}$ 下 $44.6\ \mathrm{kN}$，需要两根反向旋转轴各带 $14.1\ \mathrm{g \cdot m}$ 的不平衡量。

::: solution
$$
P = 2.2 \times 0.043 \times 628.3^{ 2 } = 37{,}347\ \mathrm{N \ per \ cylinder} \ , \qquad \frac{ P }{ n } = 11{,}152\ \mathrm{N}
$$

$$
F_{\mathrm{secondary}} = 4 \times 11{,}152 = 44{,}608\ \mathrm{N} \quad \text{在} \ 2 \times 6000 / 60 = 200\ \mathrm{Hz}
$$

**相当于四吨半物体重量的振荡力，出自一台没有任何不平衡旋转质量的发动机。**若作用在刚性安装的 $1200\ \mathrm{kg}$ 汽车上，将产生 $44\,608 / 1200 = 37\ \mathrm{m / s^2} = 3.8 \, g$；实际的发动机悬置隔离了其中大部分，但传出的部分仍足以被感觉到、听到，表现为二阶振动——$6000\ \mathrm{rev / min}$ 时 $200\ \mathrm{Hz}$，$2000$ 时 $67\ \mathrm{Hz}$——这类问题要按阶次而不是按绝对频率来诊断。

两根以 $2 \omega$ 驱动、各带不平衡量 $m_b r_b$ 的反向旋转轴，在一条固定直线上产生大小 $2 m_b r_b ( 2 \omega )^{ 2 } = 8 m_b r_b \omega^{ 2 }$ 的合力。令其对抗 $4 P / n$：

$$
m_b r_b = \frac{ P }{ 2 n \omega^{ 2 } } = \frac{ 37{,}347 }{ 2 \times 3.35 \times 394{,}784 } = 1.41 \times 10^{- 2 }\ \mathrm{kg \cdot m} = \boxed{ 14.1 \ \mathrm{g \cdot m} \ \text{（每根轴）} }
$$

——例如 $40\ \mathrm{mm}$ 半径上 $0.35\ \mathrm{kg}$。**不平衡量很小；代价在于轴本身、它的传动、轴承、相位公差和摩擦**，全都为了抵消一个只有（已被抵消的）一阶力 $1 / n$ 的力。

**其他布置怎么做。**二阶问题并非四缸特有；它是用对置曲柄抵消一阶力的必然结果，每种布置都是一笔不同的交易：

| 布置 | 一阶力 | 一阶力偶 | 二阶力 | 二阶力偶 |
|---|---|---|---|---|
| 直列 1 | ✗ $P$ | — | ✗ $P / n$ | — |
| 直列 2，曲柄 $180^{\circ}$ | ✓ | ✗ 摇摆 | ✗ $2 P / n$ | ✓ |
| 直列 3，曲柄 $120^{\circ}$ | ✓ | ✗ | ✓ | ✗ |
| **直列 4** | **✓** | **✓** | **✗ $4 P / n$** | **✓** |
| 直列 6 | ✓ | ✓ | ✓ | ✓ |

（V 型发动机可对两列气缸应用同样的求和得到；例如 $90^{\circ}$ 十字平面曲轴 V8 的一阶力偶随曲柄旋转，因而可以完全由曲轴平衡块抵消，且没有二阶力或二阶力偶。）

**直列六缸满足 [[#thm-inline]] 的全部一阶与二阶条件**，再加上均匀的发火间隔，这就是直六以平顺著称的原因。**直列三缸满足两个力的条件，但两个力偶条件都不满足：**它随曲柄旋转的一阶摇摆力偶通常用曲轴平衡块减小，必要时再加一根以曲柄转速旋转的平衡轴。

::: exercise 压力机滑块的平衡轴不平衡量 {level=3 check="33.8"}
一台往复质量 $450\ \mathrm{kg}$ 的压力机滑块，在 $150\ \mathrm{mm}$ 曲柄销距、$240\ \mathrm{rev / min}$ 下工作。（取曲柄半径 $r = 150\ \mathrm{mm}$。）两根以曲柄转速反向旋转的一阶平衡轴，各须携带多大的不平衡量（以 $\mathrm{kg \cdot m}$ 计）才能抵消滑块的一阶力？

::: solution
两根以曲柄转速反向旋转、各带不平衡量 $m_b r_b$ 的轴，沿往复方向产生 $2 m_b r_b \omega^{ 2 }$ 的合力，故

$$
2 m_b r_b \omega^{ 2 } = m_R r \omega^{ 2 } \quad \Longrightarrow \quad m_b r_b = \frac{ m_R r }{ 2 } = \frac{ 450 \times 0.150 }{ 2 } = \boxed{ 33.8 \ \mathrm{kg \cdot m} \ \text{（每根轴）} }
$$

**注意 $\omega$ 消掉了：所需不平衡量是一个纯几何量 $m_R r / 2$，与转速无关。**对比汽车发动机的 $14.1\ \mathrm{g \cdot m}$（四缸二阶平衡器每根轴需要 $m_R r / ( 2 n )$）：这里 $m_R r$ 是 $67.5\ \mathrm{kg \cdot m}$ 而不是 $0.095$。**每根轴三十四千克米，是一个与曲轴本身相当的配重。**在 $240\ \mathrm{rev / min}$ 下它要抵消的力为 $450 \times 0.150 \times 25.13^{2} = 42.6\ \mathrm{kN}$，若机架不受约束，作用在 $6000\ \mathrm{kg}$ 机架上得 $7.1\ \mathrm{m / s^2}$；在这种转速下通常的做法是用沉重的机架并锚固在大块基础上，而高速压力机则因为该力按 $\omega^{2}$ 增长而采用动平衡装置（反向运动的平衡质量）。

**设计教训：当 $m_R r$ 小或转速高时，平衡轴或平衡装置是自然的答案；当 $m_R r$ 大而转速低时，用沉重的机架和基础。**
:::
:::

## 作为储能器的飞轮：它的用途，以及它在哪儿胜过电池

::: definition 旋转储能器的比能量 {#def-store}
飞轮轮缘是一台旋转压力容器。记 $v$ 为轮缘速度；密度 $\rho$ 的薄轮缘中的环向应力为 $\sigma = \rho v^{ 2 }$，质量 $m$ 的薄轮缘的动能为 $K = \frac{ 1 }{ 2 } m v^{ 2 }$。消去 $v$：

$$
\boxed{ \; \frac{ K }{ m } = \frac{ \sigma }{ 2 \rho } \quad \text{（等强度轮缘，} \sigma = \text{轮缘许用应力）} \; }
$$

**对按许用应力运行的轮缘，储存给定能量所需的质量只取决于材料的比强度——与转速、直径或转动惯量分别为多少无关。**转速与直径只是你*达到*该应力的手段；应力才是你真正花钱买的东西。（实心圆盘和实际形状每千克储能比薄轮缘少，相差一个小于一的形状系数。）

| 材料 | 设计应力 $\sigma$（示意） | $\rho$，$\mathrm{kg/m^3}$ | $K / m$ |
|---|---|---|---|
| 灰铸铁 | $150\ \mathrm{MPa}$ | $7200$ | $10.4\ \mathrm{kJ / kg}$ |
| 球墨铸铁 | $300\ \mathrm{MPa}$ | $7100$ | $21.1\ \mathrm{kJ / kg}$ |
| 锻碳钢 | $400\ \mathrm{MPa}$ | $7800$ | $25.6\ \mathrm{kJ / kg}$ |
| $300\ \mathrm{M}$ 钢 | $1200\ \mathrm{MPa}$ | $7800$ | $76.9\ \mathrm{kJ / kg}$ |
| Ti-6Al-4V | $600\ \mathrm{MPa}$ | $4500$ | $66.7\ \mathrm{kJ / kg}$ |
| CFRP（环氧） | $1500\ \mathrm{MPa}$ | $1800$ | $417\ \mathrm{kJ / kg}$ |
| **锂离子电池**（约 $250\ \mathrm{Wh / kg}$） | — | — | $\approx 900\ \mathrm{kJ / kg}$ |
| **超级电容**（约 $5$–$10\ \mathrm{Wh / kg}$） | — | — | $\approx 20$–$35\ \mathrm{kJ / kg}$ |

**金属飞轮在能量密度上输给锂电池一个数量级以上，却能在功率上以相近的幅度赢回来。**储存 $25.6\ \mathrm{kJ / kg}$ 的钢轮缘可以在一秒内全部放出，即每千克轮缘 $25.6\ \mathrm{kW}$；$900\ \mathrm{kJ / kg}$ 的锂电池以 $1 \, C$（一小时）放电，只输出 $0.25\ \mathrm{kW / kg}$。**而且飞轮能承受极多次的满深度充放循环，因为没有任何化学物质被消耗。**
:::

::: example 一个放错位置的飞轮离最优有多远 {#ex-store}
[[#ex-punch]] 的冲床飞轮是 $292\ \mathrm{kg}$ 铸铁，储存 $K = \Delta U / ( 2 C_s ) = 4800 / 0.30 = 16{,}000\ \mathrm{J}$。一个应力取到 $150\ \mathrm{MPa}$ 的薄轮缘需要多少铸铁？

**答。**$1.5\ \mathrm{kg}$——该设计**比材料强度所要求的重约 $190$ 倍。**

::: solution
把轮缘速度取到许用应力，$\sigma = \rho v^{ 2 }$：

$$
v = \sqrt{ \frac{ 150 \times 10^{ 6 } }{ 7200 } } = 144\ \mathrm{m / s } \ , \qquad
m = \frac{ 2 K }{ v^{ 2 } } = \frac{ 2 \times 16{,}000 }{ 20{,}833 } = 1.54\ \mathrm{kg}
$$

该设计的轮缘跑在 $10.5\ \mathrm{m / s }$、$0.79\ \mathrm{MPa}$——**一个只用掉材料能力 $0.5\ \%$ 的飞轮。**这不是错误，而是经济选择，值得把多出来的 $290\ \mathrm{kg}$ 铁到底买到了什么说清楚：

- **成本。**$10.5\ \mathrm{m / s }$ 的砂型铸造灰铁轮缘只需一副模样、一次浇注。$144\ \mathrm{m / s }$ 的轮缘需要高完整性的锻件或复合材料、精密平衡和包容壳。
- **风阻。**气动损失随轮缘速度急剧上升（大致按 $v^{3}$），所以高速储能飞轮在真空中运行；$10.5\ \mathrm{m / s }$ 时风阻可以忽略，罩壳只是一块钢板护罩。
- **轴承。**轮缘的离心载荷以环向应力在内部自我平衡；轴承只承受重力和剩余不平衡力 $U \omega^{ 2 }$，低速下两者都不大。
- **失效。**$144\ \mathrm{m / s }$ 时爆裂的轮缘以大约这个速度抛出碎片。$10.5\ \mathrm{m / s }$ 时危险要小得多。**飞轮的转速首先是一条安全规格，然后才是一条效率规格。**

**总结：机器飞轮由成本、空间和安全性定尺寸，$\sigma / 2 \rho$ 只起很松的约束作用。**储能飞轮——电网调频、车辆动能回收——处在另一端：真空中的高速复合材料或高强度钢转子，用于必须以大功率反复吸收和释放能量的场合。
:::

::: quiz
一台机器的工作冲程比电动机供给多需 $800\ \mathrm{J}$，事后又交还回来。两个设计让同一台机器分别在 $1500$ 与 $3000\ \mathrm{rev / min}$ 下运转、$C_s$ 相同。$1500\ \mathrm{rev / min}$ 设计的飞轮转动惯量是：

- [ ] 相同，因为 $\Delta U$ 相同
- [x] 大四倍，因为 $I_f \propto 1 / \omega^{ 2 }$
- [ ] 大两倍，因为 $I_f \propto 1 / \omega$
- [ ] 更小，因为周期更短

::: solution
**大四倍。**$\Delta U$ 与 $C_s$ 固定时 $I_f = \Delta U / ( \omega^{ 2 } C_s )$ 给出 $I_f \propto 1 / \omega^{ 2 }$，转速减半、惯量翻四倍。两个设计所需的储能 $K = \Delta U / ( 2 C_s )$ 相同；但在较低转速下，实用直径的轮缘远低于许用应力运行，所以多出来的惯量要用质量和直径来买。**推论就是那条设计准则：飞轮属于快速轴**，如 [[#ex-geareq]] 与 [[#sec-design]]。

::: quiz
一个转子离开平衡车间时静平衡合格、动平衡不合格。于是支承感受到的是：

- [ ] 一个旋转力，无力偶
- [x] 一个旋转力偶，无合力
- [ ] 一个两倍工作转速的力
- [ ] 什么也没有，因为低速下只有静平衡要紧

## 设计：落料压力机的驱动 {#sec-design}

::: example 设计题：250 kN 落料压力机，90 次冲程 / 分 {#ex-design level=4}
**规格。**一台落料压力机在 $15\ \mathrm{mm}$ 工作行程上切出 $250\ \mathrm{kN}$，每分钟 $90$ 冲，每冲曲柄转一转。剪切占曲柄转角 $100^{\circ}$。滑块与上模往复质量合计 $380\ \mathrm{kg}$，行程 $250\ \mathrm{mm}$（曲柄半径 $125\ \mathrm{mm}$），连杆 $500\ \mathrm{mm}$。电动机转速 $1500\ \mathrm{rev / min}$。机架质量 $3500\ \mathrm{kg}$。确定电动机、飞轮及其安装位置，并校核振动力。

**解答：能量。**每冲功 $= 250 \times 10^{ 3 } \times 0.015 = 3750\ \mathrm{J}$。周期 $60 / 90 = 0.667\ \mathrm{s}$，故**平均**功率为 $5.63\ \mathrm{kW}$；若必须由电动机独自承担剪切，**峰值**功率为 $3750 / ( 0.667 \times 100 / 360 ) = 20.3\ \mathrm{kW}$。选一台 $7.5\ \mathrm{kW}$ 电动机，让飞轮承担差额——花一块铁盘的钱把电动机功率降 $2.7$ 倍。

**解答：飞轮，以及装在哪里。**在 $90\ \mathrm{rev / min}$ 的曲柄（$\omega_c = 9.425\ \mathrm{rad / s}$）上平均转矩为 $5625 / 9.425 = 597\ \mathrm{N \cdot m}$；剪切转矩在 $1.745\ \mathrm{rad}$ 上为 $3750 / 1.745 = 2149\ \mathrm{N \cdot m}$，故

$$
\Delta U = ( 2149 - 597 ) \times 1.745 = 2709\ \mathrm{J} \ , \qquad
I_{\mathrm{reflected \ at \ crank}} = \frac{ 2709 }{ 9.425^{ 2 } \times 0.08 } = 381\ \mathrm{kg \cdot m^2 }
$$

对压力机而言 $C_s = 0.08$ 已属宽松，而此处合适，因为剪切很短、机器很刚。**折算到曲柄，$381\ \mathrm{kg \cdot m^2 }$ 相当于直径 $1.0\ \mathrm{m}$ 的轮缘 $1524\ \mathrm{kg}$。**换个位置：

| 飞轮位置 | 转速 | 所需 $I$ | 半径 $R$ 的轮缘 | 质量 | 轮缘应力 |
|---|---|---|---|---|---|
| 装在曲柄上 | $90\ \mathrm{rev / min}$ | $381\ \mathrm{kg \cdot m^2 }$ | $0.50\ \mathrm{m}$ | $1524\ \mathrm{kg}$ | $0.16\ \mathrm{MPa}$ |
| 装在 $4 : 1$ 中间轴上 | $360\ \mathrm{rev / min}$ | $23.8\ \mathrm{kg \cdot m^2 }$ | $0.30\ \mathrm{m}$ | $264\ \mathrm{kg}$ | $0.92\ \mathrm{MPa}$ |
| **装在电动机轴上** | $1500\ \mathrm{rev / min}$ | $1.37\ \mathrm{kg \cdot m^2 }$ | $0.15\ \mathrm{m}$ | $\mathbf{61\ \mathrm{kg}}$ | $4.0\ \mathrm{MPa}$ |

**选电动机转速的轴。**飞轮是一个平均半径 $0.15\ \mathrm{m}$ 的球墨铸铁轮缘，$61\ \mathrm{kg}$，轮缘应力约为 $300\ \mathrm{MPa}$ 设计应力的 $1 / 75$，而从 $1524\ \mathrm{kg}$ 降到 $61\ \mathrm{kg}$ 只花了一个速比——**$I \propto 1 / \omega^{ 2 }$，所以 $16.7 : 1$ 的速比把所需惯量除以 $278$。**（质量下降得少一些，为 $25 : 1$，因为更快的轮缘也更小。）轮缘应力从 $0.16$ 升到 $4.0\ \mathrm{MPa}$，仍然可以忽略；实际上飞轮通常装在自己的轴和轴承上（常常就是带传动的大带轮），而不是悬臂挂在电动机上。

**解答：振动力。**一阶力 $= m_R r \omega^{ 2 } = 380 \times 0.125 \times 9.425^{ 2 } = 4219\ \mathrm{N}$，频率 $1.5\ \mathrm{Hz}$；二阶力 $= 4219 / 4 = 1055\ \mathrm{N}$，频率 $3\ \mathrm{Hz}$。作用在自由的 $3500\ \mathrm{kg}$ 机架上，一阶力将给出 $1.2\ \mathrm{m / s^2 } = 0.12 \, g$；螺栓固定在基础上时，它是地脚螺栓上 $4.2\ \mathrm{kN}$ 的交变载荷。

**不配平衡轴。**所需平衡轴不平衡量为 $m_R r / 2 = 23.8\ \mathrm{kg \cdot m}$ 每根——与曲柄配重一样大——只为抵消一个 $1.5\ \mathrm{Hz}$、$4.2\ \mathrm{kN}$ 的力，而这个频率远低于机架的任何结构共振，机架对它是准静态响应。**振动力不是这台机器的问题；$250\ \mathrm{kN}$ 的工艺载荷、机架在其下的变形、以及剪切期间的降速才是。**在买任何东西之前先弄清哪一项占主导。

**解答：接下来校核什么。**
1. **电动机的 rms 转矩，而不只是平均值。**电动机平均转矩为 $5625 / 157.08 = 35.8\ \mathrm{N \cdot m}$，是 $7.5\ \mathrm{kW}$ 电动机额定 $47.7\ \mathrm{N \cdot m}$ 的 $75\ \%$。若飞轮理想，电动机转矩保持在平均值；若没有飞轮，它须在每个周期的 $100^{\circ}$ 内供给剪切转矩 $2149 / 16.67 = 129\ \mathrm{N \cdot m}$，rms 为 $129 \sqrt{ 100 / 360 } = 68\ \mathrm{N \cdot m}$。真实的感应电动机转速降低时转矩上升，介于两者之间，所以**用 rms 转矩对照额定值，用峰值对照电动机的最大（颠覆）转矩。**
2. **滑块自身的 $J_{\mathrm{eq}}$。**折算到曲柄，滑块贡献 $m_R r^{2} u^{2} = 5.94\, u^{2}\ \mathrm{kg \cdot m^2}$，其最大斜率为 $7.5\ \mathrm{kg \cdot m^2 / rad}$；因此在 $90\ \mathrm{rev / min }$ 下 [[#deriv-dJ]] 的梯度转矩在曲柄处峰值为 $\frac{ 1 }{ 2 } \times 7.5 \times 9.425^{ 2 } = 333\ \mathrm{N \cdot m}$——约为剪切转矩的 $15\ \%$，值得计入驱动力矩图，但不改变设计。它按 $\omega^{2}$ 增长，所以更快的压力机必须认真对待它。
3. **离合器与制动器。**飞轮在离合器的电动机一侧，所以离合器必须传递剪切转矩（折算到曲柄为 $2149\ \mathrm{N \cdot m}$），而制动器必须在飞轮仍以 $1500\ \mathrm{rev / min }$ 旋转时停住滑块——见 [[#warn-flywheel]]。
4. **飞轮护罩。**$61\ \mathrm{kg}$、$23.6\ \mathrm{m / s }$ 储存 $\frac{1}{2} \times 61 \times 23.6^{2} = 17\ \mathrm{kJ}$。
:::

::: summary
- **惯量要在它实际所在之处计算，而不是在轴所在之处。**$J_{\mathrm{eq}} ( \theta ) = \sum [ m_i ( v_{Gi} / \omega )^{ 2 } + I_{Gi} ( \omega_i / \omega )^{ 2 } ]$，经轮系折算时取传动比的**平方**——这就是飞轮属于快速轴的原因。
- **连杆机构的运动方程是 $T = J_{\mathrm{eq}} \alpha + \frac{ 1 }{ 2 } ( \mathrm{d} J_{\mathrm{eq} } / \mathrm{d} \theta ) \omega^{ 2 }$，而第二项在匀速时也存在。**对算例中的曲柄滑块机构，它在 $3000\ \mathrm{rev / min}$ 下的峰值超过平均有效转矩的一百倍。
- **飞轮由 $\Delta U$ 定尺寸，而不是由峰值转矩：**$I_f = \Delta U / ( \omega^{ 2 } C_s )$，其中 $C_s$ 是规格（发电机组 $0.005$，压力机 $0.15$），而 $\Delta U$ 从驱动力矩图上读出，即累积能量曲线的纵向范围。
- **飞轮降低峰值功率，永远不降低峰值力。**曲轴、齿轮与机架由峰值转矩定尺寸，而制动器必须在飞轮仍在全速时停住机器。
- **按许用应力运行时，储存给定能量所需的薄轮缘质量是 $2 K \rho / \sigma$，与转速无关。**机器飞轮远比这重，因为它们便宜、慢速、安全——而这笔交易通常是对的。
- **动平衡需要两个平面，因为它是四个标量条件：**$\sum U_i = 0$ 与 $\sum z_i U_i = 0$。一根静平衡的细长转子仍可能带有不平衡力偶。
- **校正质量大致按 $1 / ( b - a )$ 缩放，即校正平面的间距。**在算例中选错平面要多花 $3.9$ 倍的金属，而剩余平衡却毫无差别——所以平面位置必须上图纸。
- **平衡等级是一个速度：**$e_{\mathrm{per}} \omega = G\ \mathrm{mm / s}$，故 $e_{\mathrm{per}} = 9549 G / n$ 微米。$3000\ \mathrm{rev / min }$ 下的 $G 6.3$ 是 $20\ \mu \mathrm{m}$，对 $15\ \mathrm{kg}$ 的转子即 $301\ \mathrm{g \cdot mm}$。
- **一阶惯性力 $m_R r \omega^{ 2 } \cos \theta$ 是假想的曲柄销处旋转质量沿行程方向的分量；二阶力是它的 $1 / n$、以两倍曲柄转速变化，只因连杆有限长而存在。**用对置曲柄抵消一阶力，会使二阶力同相。
- **直列四缸在一阶力、一阶力偶与二阶力偶上都平衡，却带着 $4 P / n$ 的自由二阶力**——$6000\ \mathrm{rev / min }$ 下为 $44.6\ \mathrm{kN}$——两根各带 $14.1\ \mathrm{g \cdot m}$ 的轴就能消掉它。**要不要消它是成本决策，而在 $90\ \mathrm{rev / min }$ 的压力机上，答案是不消。**
:::

## 延伸阅读

- **R. L. Norton, *Design of Machinery*, 5th ed.（McGraw-Hill, 2012）**——动态力分析、飞轮、振动力，以及连杆机构与多缸发动机的平衡，附大量算例。
- **J. J. Uicker、G. R. Pennock 与 J. E. Shigley, *Theory of Machines and Mechanisms*, 5th ed.（Oxford University Press, 2017）**——等效系统、驱动力矩图与飞轮选型，以及转子与发动机平衡。
- **B. Paul, *Kinematics and Dynamics of Planar Machinery*（Prentice-Hall, 1979）**——对单自由度机器动力学的严格论述，包括随位形变化的等效惯量。
- **S. H. Crandall、D. C. Karnopp、E. F. Kurtz 与 D. C. Pridmore-Brown, *Dynamics of Mechanical and Electromechanical Systems*（McGraw-Hill, 1968）**——一本经典教材，其中的能量方法与等效惯量表述，$\frac{ 1 }{ 2 } \omega^{ 2 } \, \mathrm{d} J / \mathrm{d} \theta$ 项由此自然得出。
- **I. I. Artobolevsky, *Mechanisms in Modern Engineering Design*（Mir）**——多卷本机构图册，包括平衡装置与飞轮布置。
- **ISO 21940-11, *Mechanical vibration — Rotor balancing — Part 11: Procedures and tolerances for rotors with rigid behaviour***——ISO 1940-1 平衡品质等级的现行形式；其中关于如何选择等级的说明性附录值得一读。
