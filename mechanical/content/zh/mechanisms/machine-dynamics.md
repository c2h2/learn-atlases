::: warning 转矩不是功率除以转速
本课之前的每一课都是从给定的运动算加速度。这一课算给定转矩产生的运动——而你发现的头一件事，是答案并不写在铭牌上。

一台 $10\ \mathrm{kW}$、$3000\ \mathrm{rev / min}$ 的电机并不输出 $31.8\ \mathrm{N \cdot m}$。它输出的是*平均* $31.8\ \mathrm{N \cdot m}$，而它驱动的机构所要求的却是一个振荡转矩，在 [[#sec-eqsys]] 的算例里高达 $907\ \mathrm{N \cdot m}$——**平均值的二十八倍**——哪怕输出轴转得完全匀速。一台 $0.06\ \mathrm{s}$ 内冲 $6000\ \mathrm{J}$ 的压力机不需要 $100\ \mathrm{kW}$ 电机；它需要 $25\ \mathrm{kW}$ 电机加 $68\ \mathrm{kg \cdot m^2}$ 飞轮。而一台 $6000\ \mathrm{rev / min}$ 的四缸汽车发动机，以 $200\ \mathrm{Hz}$ 把 $44.6\ \mathrm{kN}$——四吨半——沿车身上下抛掷，而它内部没有任何不平衡的旋转质量。

三个事实出自同样两个思想：**惯量要在它实际所在之处被计算，而不是在轴所在之处；一个消不掉的力，往往可以被安排去指向别处。**
:::

## 你已经知道的内容

- **相对加速度与加速度影像**——来自 [[mechanisms/acceleration-analysis]]，靠它你求出每个构件质心的速度与加速度随曲柄转角的函数。那个比值——而不是绝对速度——正是整课的地基。
- **振动力**——$F_{\mathrm{shake}} = - \sum m_i a_{Gi}$，在 [[mechanisms/acceleration-analysis]] 中作为总质心加速度的负值导出。在这里它从副产品变成设计目标。
- **刚体的功与能**——[[dynamics/work-energy]] 的 $T = \frac{1}{2} J \omega^{2}$ 与动能定理，它是单自由度机器唯一需要的工具。
- **扭转振动与两自由度系统**——来自 [[vibrations/two-degrees-of-freedom]]，因为飞轮和电机电枢就是两根惯量由一根轴相连，而飞轮的转动惯量恰恰是决定它们耦合固有频率落在哪里的参数。
- **接触与疲劳**——来自 [[materials-science/mechanical-properties]]，因为飞轮是一台旋转压力容器、其轮缘按环向应力失效，也因为平衡品质等级是一句关于轴承载荷的话、因而是一句关于疲劳寿命的话。

## 等效系统：一个惯量，一个转矩 {#sec-eqsys}

::: definition 等效转动惯量与等效力矩 {#def-eqsys}
一台单自由度机器——压力机、发动机、缝纫机、包装台——只有一个坐标 $\theta$，其中每个速度都正比于 $\dot\theta = \omega$。记构件 $i$ 质心速度比 $v_{Gi} / \omega$ 与角速度比 $\omega_i / \omega$。则该机器在该瞬间动力学上精确等价于

$$
\boxed{ \; J_{\mathrm{eq}} ( \theta ) = \sum_i \left[ m_i \left( \frac{ v_{Gi} }{ \omega } \right)^{ 2 } + I_{Gi} \left( \frac{ \omega_i }{ \omega } \right)^{ 2 } \right] \; } \qquad \text{（对输入轴）}
$$

$$
\boxed{ \; T_{\mathrm{eq}} ( \theta ) = \sum_i F_i \cdot \frac{ v_i }{ \omega } + \sum_i T_i \, \frac{ \omega_i }{ \omega } \; } \qquad \text{（作用在输入轴上，功率等效）}
$$

而运动方程是**能量积分**，不是 $J \alpha = T$：

$$
\frac{ \mathrm{d} }{ \mathrm{d} \theta } \left[ \frac{ 1 }{ 2 } J_{\mathrm{eq}} ( \theta ) \, \omega^{ 2 } \right] = T_{\mathrm{drive}} ( \theta ) - T_{\mathrm{load}} ( \theta )
$$

**$J_{\mathrm{eq}}$ 是位形的函数，不是常数。**对曲柄滑块机构，它一转之内变化近两倍，而这个变化本身就是一笔转矩。
:::

::: exercise 推导：$\tfrac{1}{2} \omega^{2} \, \mathrm{d} J_{ \mathrm{eq} } / \mathrm{d} \theta$ 项 {#deriv-dJ level=3}
::: solution
对动能 $K = \frac{1}{2} J_{\mathrm{eq}} ( \theta ) \omega^{2}$ 求时间导数，令其等于瞬时功率：

$$
\frac{ \mathrm{d} K }{ \mathrm{d} t } = \frac{ 1 }{ 2 } J_{\mathrm{eq}} \, 2 \omega \dot\omega + \frac{ 1 }{ 2 } \omega^{ 2 } \frac{ \mathrm{d} J_{\mathrm{eq}} }{ \mathrm{d} \theta } \omega = T_{\mathrm{eq} }
$$

除以 $\omega$，把 $\omega$ 写回 $\dot\theta$：

$$
\boxed{ \; T_{\mathrm{eq}} = J_{\mathrm{eq}} \, \alpha + \frac{ 1 }{ 2 } \frac{ \mathrm{d} J_{\mathrm{eq}} }{ \mathrm{d} \theta } \omega^{ 2 } \; }
$$

**第二项在匀速时也存在。**它是驱动为了在机构自身质量分布改变形状时加速这个分布、纯粹必须供给的转矩，它正比于 $\omega^{2}$，没有阻尼、没有打滑、没有任何善意可以把它削减。

两条决定真实设计的推论：

1. **匀速时整个 $T_{\mathrm{eq}}$ 就是 $J$ 梯度项**，它是曲柄频率及其二次谐波上的振荡转矩。只按平均转矩定额的电机会发热，因为铜耗走的是 *rms* 电流，而 $907\ \mathrm{N \cdot m}$ 的振荡叠在 $32\ \mathrm{N \cdot m}$ 均值上的 rms 是 $908\ \mathrm{N \cdot m}$。
2. **该项按 $\omega^{2}$ 增长，而多数工艺的有效转矩大致恒定。**一台 $500\ \mathrm{rev / min}$ 下舒舒服服的机构，到 $3000$ 不是"差一点"，而是另一台机器；高压往复泵、缝纫机或印刷机的转速上限是这一项定的，不是任何东西的强度定的。
:::
:::

::: example 曲柄滑块机构的等效转动惯量 {#ex-ieq}
一曲柄滑块机构：曲柄 $r = 100\ \mathrm{mm}$，连杆 $l = 400\ \mathrm{mm}$（$\lambda = 0.25$），曲柄质量 $2.0\ \mathrm{kg}$、质心距曲柄销轴 $50\ \mathrm{mm}$、$I_{G2} = 2.5 \times 10^{- 3}\ \mathrm{kg \cdot m^2}$，连杆质量 $4.0\ \mathrm{kg}$ 按均质建模，滑块 $3.0\ \mathrm{kg}$。求对曲轴的 $J_{\mathrm{eq}} ( \theta )$，以及让它以恒定 $3000\ \mathrm{rev / min}$ 转动所需的转矩。

**答。**$J_{\mathrm{eq}}$ 在 $20.83$ 与 $37.72\ \mathrm{g \cdot m^2}$ 之间摆动——比值 $1.81$——而匀速转矩的幅值为 $907\ \mathrm{N \cdot m}$。

::: solution
$\theta$ 从上止点量起，记 $D = \sqrt{ 1 - \lambda^{ 2 } \sin^{ 2 } \theta }$，速度比为

$$
\frac{ v_{\mathrm{slide}} }{ r \omega } = \sin \theta + \frac{ \lambda^{ 2 } \sin \theta \cos \theta }{ D } \equiv u \ , \qquad \frac{ \omega_{\mathrm{rod}} }{ \omega } = \frac{ \lambda \cos \theta }{ D }
$$

取连杆质心在中点，$\dfrac{ v_{G,\mathrm{rod}} }{ \omega } = \frac{r}{2} \sqrt{ ( u - \sin \theta )^{ 2 } + \cos^{ 2 } \theta }$。汇总四项：

| $\theta$ | $0^{\circ}$ | $30^{\circ}$ | $60^{\circ}$ | $90^{\circ}$ | $180^{\circ}$ | $270^{\circ}$ |
|---|---|---|---|---|---|---|
| $J_{\mathrm{eq}}$，$\mathrm{g \cdot m^2}$ | 20.83 | 25.89 | 34.85 | 37.50 | 20.83 | 37.50 |

**惯量在上、下止点最小，在行程中部最大**，完全合理：止点处滑块瞬时静止、连杆纯粹绕曲柄销转动，而行程中部滑块满速、连杆质心最快。

**匀速转矩。**$\omega = 314.16\ \mathrm{rad / s}$ 时，$\frac{1}{2} ( \mathrm{d} J_{\mathrm{eq}} / \mathrm{d} \theta ) \omega^{ 2 }$ 项的峰值为

$$
T = \frac{ 1 }{ 2 } \times 18.4 \times 10^{- 3 } \times 314.16^{ 2 } = 907\ \mathrm{N \cdot m}
$$

而若机器做 $10\ \mathrm{kW}$ 有效功，平均转矩只有 $31.8\ \mathrm{N \cdot m}$。**为了输出稳定的 $32$，驱动看到的转矩在 $- 875$ 与 $+ 939\ \mathrm{N \cdot m}$ 之间甩动。**这就是高速压力机采用相位差 $180^{\circ}$ 的对置滑块的原因——两个 $J_{\mathrm{eq}}$ 梯度几乎精确抵消——也是伺服压力机轴按 rms 转矩与峰值转矩而非按功率选型的原因。

::: exercise 经传动比折算的等效转动惯量 {#ex-geareq level=2 check="3.0"}
上面的机构经一根 $1 : 1$ 的轴驱动载荷，但一位设计师提议把飞轮装在经 $10 : 1$ 增速（飞轮转速十倍于曲柄）的轴上。若飞轮对自身轴有 $J = 0.03\ \mathrm{kg \cdot m^2}$，它在曲柄处对 $J_{\mathrm{eq}}$ 贡献多少？把 $J_{\mathrm{eq}}$ 那 $\pm 8.4\ \mathrm{g \cdot m^2}$ 的摆动幅度按分数缩小到几倍？

::: solution
惯量经轮系按传动比的**平方**折算：

$$
J_{\mathrm{eq, \, flywheel}} = J \times \left( \frac{ \omega_f }{ \omega_c } \right)^{ 2 } = 0.03 \times 100 = \boxed{ 3.0\ \mathrm{kg \cdot m^2} }
$$

$J_{\mathrm{eq}}$ 的摆动绝对值不变——仍是 $16.9\ \mathrm{g \cdot m^2}$——但作为*分数*，它从 $1.81 : 1$ 的峰谷比塌缩到

$$
\frac{ 3000 + 37.7 }{ 3000 + 20.8 } = 1.0056 \ , \qquad \text{即 } 0.56 \ \% \text{ 的波动，而不是 } 81 \ \%
$$

**这就是把飞轮放在高速轴上的全部理由，也是每台机器里的每个飞轮都装在能找到的最快轴上的原因。**同样 $0.03\ \mathrm{kg \cdot m^2}$ 若直接装在曲柄上，只贡献 $0.03\ \mathrm{kg \cdot m^2}$，什么也改变不了。**惯量的杠杆法则是：一小块快转的质量值其速比的平方，而速比便宜、质量不便宜。**其代价——在 [[#def-turning]] 处理——是轮缘应力按 $v^{2}$ 走、轴承载荷按 $m r \omega^{2}$ 走，所以高速轴也是飞轮最可能失效的那根轴。
:::
:::

## 驱动力矩图

::: definition 驱动力矩图与速度波动系数 {#def-turning}
在机器的一个周期内，把驱动力矩 $T ( \theta )$ 对曲柄转角作图，再画上能做同样功的平均转矩 $T_m$。这张图就叫**驱动力矩图**；**能量波动**是二者之差的逐段积分，

$$
\Delta E ( \theta ) = \int_{ \theta_0 }^{ \theta } \left[ T ( \phi ) - T_m \right] \mathrm{d} \phi
$$

而 $\Delta U = \Delta E_{ \max } - \Delta E_{ \min }$ 是**最大能量波动**——机器在一个周期内必须吞下再吐出的最大能量数。**速度波动系数**为

$$
C_s = \frac{ \omega_{ \max } - \omega_{ \min } }{ \omega_{\mathrm{mean}} } \ , \qquad \omega_{\mathrm{mean}} = \frac{ \omega_{ \max } + \omega_{ \min } }{ 2 }
$$

典型的许用值——它们是规格而不是计算结果，取决于机器的用途：

| 机器 | $C_s$ | 原因 |
|---|---|---|
| 仪表钟、发电机组 | $0.0005$–$0.005$ | 调频要求；$50\ \mathrm{Hz}$ 意味着轴几乎不能动 |
| 机床、离心机、印刷机 | $0.005$–$0.02$ | 表面质量与套准精度 |
| 汽车发动机 | $0.02$–$0.05$ | 在 $2000\ \mathrm{rev / min}$ 下没人感觉到 $3\ \%$ 的转矩脉动 |
| 铆接机、冲床、剪床 | $0.10$–$0.20$ | 工作就是一击；没有谁在乎两击之间发生什么 |
| 破碎机、锻锤 | $0.15$–$0.30$ | 同上，而且飞轮本身就是工具的一部分 |
:::

::: exercise 推导：$I_f = \Delta U / ( \omega^{2} C_s )$ {#deriv-fly level=3}
::: solution
在 $\omega_{ \min }$ 与 $\omega_{ \max }$ 之间，机器的动能恰好改变最大能量波动那么多，并且若飞轮主导总惯量（这是假设，也是事后要校核的假设）：

$$
\Delta U = \frac{ 1 }{ 2 } I_f \left( \omega_{ \max }^{ 2 } - \omega_{ \min }^{ 2 } \right) = \frac{ 1 }{ 2 } I_f \left( \omega_{ \max } + \omega_{ \min } \right) \left( \omega_{ \max } - \omega_{ \min } \right) = \frac{ 1 }{ 2 } I_f \times 2 \omega_{\mathrm{mean}} \times C_s \omega_{\mathrm{mean}}
$$

$$
\boxed{ \; I_f = \frac{ \Delta U }{ \omega_{\mathrm{mean}}^{ 2 } \, C_s } \; } \qquad \text{等价地} \qquad \Delta U = I_f \omega_{\mathrm{mean}}^{ 2 } C_s = 2 K \, C_s
$$

**最后这个形式——$\Delta U = 2 K C_s$，其中 $K$ 是储存的动能——才是该拿来思考的那个：速度的相对变化是能量相对变化的一半。**要在 $C_s = 0.05$ 下吸收一个周期能量的 $10 \ \%$，飞轮就必须储存它的 $200 \ \%$——这就是为什么大到足以平滑冲床的飞轮也大到成为整台机器最重的部件，也是为什么把飞轮做小的唯一真正办法是提高 $\omega$，因为在固定 $C_s$ 下 $I_f \propto 1 / \omega^{ 2 }$。

**两点提醒。**第一，$I_f$ 是折算到测量 $\omega$ 那根轴上的*附加*惯量；若机器自身运动件已经贡献了可观的 $J_{\mathrm{eq}}$，要把它减去——并且记住 [[#ex-ieq]] 里 $J_{\mathrm{eq}}$ 不是常数。第二，公式假设飞轮的惯量是常数，所以**装在曲柄滑块机构曲轴上的飞轮，是在跟一个与它自己同量级的 $\Delta J_{\mathrm{eq}}$ 打架**；装在增速轴上则不是，这正是 [[#ex-geareq]] 的实际含义。
:::
:::

::: example 单缸发电机组的飞轮 {#ex-1cyl}
一台单缸四冲程发动机，排量 $500\ \mathrm{cm^3}$，制动平均有效压力 $8\ \mathrm{bar}$，以 $3000\ \mathrm{rev / min}$ 拖动发电机。把膨胀冲程建模为持续 $180^{\circ}$ 曲柄角的半正弦波，忽略泵气与压缩回线。求 $C_s = 0.005$ 所需的飞轮转动惯量。

**答。**$\Delta U = 413\ \mathrm{J}$，$I_f = 0.84\ \mathrm{kg \cdot m^2}$——约合平均直径 $400\ \mathrm{mm}$ 的铸铁轮缘 $21\ \mathrm{kg}$。

::: solution
每循环功 $=$ 制动平均有效压力 $\times$ 排量 $= 8 \times 10^{ 5 } \times 5 \times 10^{- 4 } = 400\ \mathrm{J}$，每 $720^{\circ} = 4 \pi$ 弧度曲柄角输出一次，于是

$$
T_m = \frac{ 400 }{ 4 \pi } = 31.83\ \mathrm{N \cdot m} \ , \qquad P = T_m \omega = 31.83 \times 314.16 = 10.0\ \mathrm{kW}
$$

面积为 $400$、持续 $\pi$ 的半正弦波，峰值为 $T_p = 2 \times 400 / \pi = 254.6\ \mathrm{N \cdot m}$。它在 $254.6 \sin \theta = 31.83$ 处穿过平均线，即 $\theta = 7.18^{\circ}$ 与 $172.82^{\circ}$，两交点之间平均线上方的能量为

$$
\Delta U = \int_{ 0.1253 }^{ 3.0163 } \! \left( 254.6 \sin \theta - 31.83 \right) \mathrm{d} \theta = \left[ - 254.6 \cos \theta - 31.83 \theta \right] = 413.3\ \mathrm{J}
$$

$$
I_f = \frac{ 413.3 }{ 314.16^{ 2 } \times 0.005 } = \frac{ 413.3 }{ 493.5 } = 0.837\ \mathrm{kg \cdot m^2}
$$

平均半径 $0.20\ \mathrm{m}$ 的薄轮缘有 $I = m r^{ 2 }$，故 $m = 0.837 / 0.04 = 20.9\ \mathrm{kg}$。轮缘速度 $v = \omega r = 62.8\ \mathrm{m / s}$，环向应力 $\sigma = \rho v^{ 2 } = 7200 \times 62.8^{ 2 } = 28.4\ \mathrm{MPa}$——对片状石墨铸铁绰绰有余，这就是飞轮至今仍然用铸造的原因。

::: example 冲床：飞轮就是机器本身 {#ex-punch}
一冲头在 $20\ \mathrm{mm}$ 行程上施加 $300\ \mathrm{kN}$。曲轴以 $200\ \mathrm{rev / min}$ 转动，每转冲一次，冲压过程占 $0.06\ \mathrm{s}$——曲柄 $72^{\circ}$。许用 $C_s = 0.15$。确定飞轮与电动机。

**答。**$I_f = 68\ \mathrm{kg \cdot m^2}$，直径 $1.0\ \mathrm{m}$ 的轮缘 $274\ \mathrm{kg}$；电动机选 $25\ \mathrm{kW}$，否则需要 $100\ \mathrm{kW}$。

::: solution
每次冲压功 $= 300 \times 10^{ 3 } \times 0.020 = 6000\ \mathrm{J}$，在 $0.30\ \mathrm{s}$ 周期中的 $0.06\ \mathrm{s}$ 内交付。**若由电动机直接供给，峰值功率为：$6000 / 0.06 = 100\ \mathrm{kW}$。**平均功率：$6000 / 0.30 = 20\ \mathrm{kW}$。

选一台 $25\ \mathrm{kW}$ 电动机，在 $\omega = 20.94\ \mathrm{rad / s}$ 下给出恒定驱动力矩 $1194\ \mathrm{N \cdot m}$。冲压期间载荷转矩为 $6000 / 1.2566 = 4775\ \mathrm{N \cdot m}$，所以飞轮必须供给

$$
\Delta U = ( 4775 - 1194 ) \times 1.2566 = 4500\ \mathrm{J}
$$

$$
I_f = \frac{ 4500 }{ 20.94^{ 2 } \times 0.15 } = \frac{ 4500 }{ 65.8 } = 68.4\ \mathrm{kg \cdot m^2}
$$

平均直径 $1.0\ \mathrm{m}$ 的薄轮缘需要 $m = 68.4 / 0.5^{ 2 } = 274\ \mathrm{kg}$。轮缘速度只有 $10.5\ \mathrm{m / s}$，所以环向应力为 $0.79\ \mathrm{MPa}$——**飞轮离它的应力极限远得很，这意味着它是一台便宜、笨重、铸造、慢速的机器，而这正是一台压力机飞轮应有的样子。**

::: widget plot

f: 4500/(438.4*x)

caption: $\Delta U = 4500\ \mathrm{J}$、$200\ \mathrm{rev / min}$ 下的 $C_s = \Delta U / ( \omega^{ 2 } I_f )$。**曲线是双曲线：波动减半，质量翻倍。**在 $68\ \mathrm{kg \cdot m^2}$ 处设计落在 $C_s = 0.15$；收紧到 $C_s = 0.05$ 需要 $205\ \mathrm{kg \cdot m^2}$、$820\ \mathrm{kg}$ 的轮缘，而买到同样 $C_s$ 唯一更便宜的办法是提高转速，因为 $I_f \propto 1 / \omega^{ 2 }$。**这就是为什么高速压力机把曲轴转到 $600$–$1000\ \mathrm{rev / min}$、把飞轮装在再增速的中间轴上：你省下的质量随你愿意买到的转速的平方增长。**

::: warning 飞轮做不到的四件事 {#warn-flywheel}
飞轮是一个增益固定的能量缓冲器，由此推出四条常被想当然地忽略的结论。

1. **它不降低峰值转矩。**冲头在曲柄处仍然看到 $4775\ \mathrm{N \cdot m}$、在滑块处仍然看到 $300\ \mathrm{kN}$。曲轴、齿轮、机架、轴承全由这个数定尺寸，再多的飞轮也改变不了它们。**飞轮降低的是从电网取用的峰值*功率*，永远不是机器内的峰值*力*。**
2. **它不调节转速；它限制转速变化的速率。**驱动脱开后，带飞轮的压力机只是滑行。在超速事故里它反而把事情弄得更糟，这就是为什么压力机的离合器与制动器必须按飞轮仍在全速时停住滑块来选型——比停电动机的制动器大得多。
3. **它无法平滑它没有储存的东西。**$C_s$ 由 $\Delta U$ 对*总*储存能量 $K = \frac{1}{2} I \omega^{ 2 }$ 决定。一个 $\mathrm{kg \cdot m^2}$ 很大但 $K$ 很小的飞轮——因为它转得慢——什么也做不了，而机械设计中最常见的选型错误，就是报出 $I$ 却不问它对应的 $\omega$ 是多少。
4. **它是一台旋转压力容器，总有一天要被试验。**一台以 $v = 100\ \mathrm{m / s}$ 运转的铸铁飞轮，每千克轮缘储存 $5\ \mathrm{kJ}$；$274\ \mathrm{kg}$ 的轮缘以 $10.5\ \mathrm{m / s}$ 运转储存 $15\ \mathrm{kJ}$，相当于一枚小手榴弹，而飞轮失效的方式是把自己的全部质量以轮缘速度朝操作者甩出去。**每一张飞轮图纸都带着过压旋转试验要求，图纸上那个数字没有商量余地。**
:::

::: exercise 发电机组的速度波动 {level=1 check="0.005"}
[[#ex-1cyl]] 的单缸机组在 $3000\ \mathrm{rev / min}$ 下 $\Delta U = 413\ \mathrm{J}$，飞轮 $I_f = 0.837\ \mathrm{kg \cdot m^2}$。$C_s$ 是多少？合多少转每分？

::: solution
$$
C_s = \frac{ \Delta U }{ I_f \omega^{ 2 } } = \frac{ 413.3 }{ 0.837 \times 314.16^{ 2 } } = \frac{ 413.3 }{ 82{,}580 } = \boxed{ 0.005 } \quad \Rightarrow \quad 0.005 \times 3000 = 15\ \mathrm{rev / min}
$$

**在 $3000\ \mathrm{rev / min}$ 的轴上有十五转每分的脉动，频率为工频的两倍。**对接在 $50\ \mathrm{Hz}$ 电网上的发电机，相关的限制是稳态频率必须保持在 $\pm 0.5 \ \%$ 以内，而 $C_s = 0.005$ 恰好就是它——**这就是单缸发电机组笨重的原因，也是一台 $10\ \mathrm{kW}$ 发电机组有一台你自己搬不动的飞轮、而一台 $10\ \mathrm{kW}$ 电动机根本没有飞轮的原因。**
:::
:::

::: exercise 转速翻倍 {#ex-doubling level=2 check="0.005"}
一台机床的飞轮在 $1500\ \mathrm{rev / min}$ 下给出 $C_s = 0.02$。工厂工程师把主轴转速翻倍到 $3000\ \mathrm{rev / min}$，飞轮不变、每循环 $\Delta U$ 不变。新的 $C_s$ 是多少？

::: solution
$I_f \omega^{ 2 } C_s = \Delta U$，$I_f$ 与 $\Delta U$ 不变，故 $C_s \propto 1 / \omega^{ 2 }$：

$$
C_s = 0.02 \times \left( \frac{ 1500 }{ 3000 } \right)^{ 2 } = \boxed{ 0.005 }
$$

**花额外驱动功率的钱换来四倍的改善——这是飞轮设计中威力最大的单一杠杆，这就是为什么对"机器抖得太厉害"的回答，往往是先"把它转快一点"，而不是"把飞轮做大一点"。**代价是真实存在的：$\Delta U$ 并不总是不变。若工艺是运动学性的而非能量性的——凸轮驱动的转位台、每转排量固定的往复泵——那么转速翻倍只是把*速率*翻倍，每循环能量不变，公式成立。反之，若工艺转矩是转速的固定函数，如风机或对着固定系统特性曲线工作的泵，$\Delta U$ 随 $\omega$ 上升，收益就只有 $\omega^{-1}$ 甚至更差。**庆祝之前先弄清你面对的是哪一种。**
:::
:::

## 平衡（一）：转子，以及为什么两个平面是最少的

::: definition 静平衡与动平衡 {#def-balance}
为转子的每个圆盘 $i$ 附加一个**不平衡矢量** $U_i = m_i r_i$：它是一个平面极矢量，大小为（质量 $\times$ 半径）、方位在质量中心的角位置上；再记其轴向位置为 $z_i$。则

$$
\textbf{静平衡：} \quad \boxed{ \; \sum_i U_i = 0 \; } \qquad \text{（无合成离心力）}
$$

$$
\textbf{动平衡：} \quad \boxed{ \; \sum_i U_i = 0 \quad \text{且} \quad \sum_i z_i U_i = 0 \; } \qquad \text{（既无合力也无合力偶）}
$$

两者都是**矢量**方程，所以各含两个标量条件，动平衡一共是四个条件。**一根静平衡的细长转子并不是动平衡的：同一平面内两个相等的质量互相抵消，但同样两个质量若在不同平面，就构成一个每转反向两次的力偶，在轴承上感受到的是力矩而不是力。**这就是为什么平衡机有两个拾振传感器而不是一个，也是为什么校正永远要在两个平面上做。
:::

::: exercise 推导：两平面校正 {#deriv-2plane level=3}
::: solution
在平面 $a$、$b$ 内添加校正不平衡 $C_a$ 与 $C_b$。两个条件化为

$$
C_a + C_b = - \sum_i U_i \equiv - S \ , \qquad a \, C_a + b \, C_b = - \sum_i z_i U_i \equiv - M
$$

两个关于两个未知矢量的矢量方程：四个标量方程、四个未知量，故解唯一，为

$$
\boxed{ \; C_b = \frac{ - M + a S }{ b - a } \ , \qquad C_a = - S - C_b \; }
$$

**读一读分母。**所需校正与**校正平面的间距**成反比，与它们的其他任何属性无关。把两个平面挪近一些，配重就按正比爆炸式增长，而校正后的剩余不平衡两种情况下都精确为零——**平衡机会欣然报告一个由荒唐数量的配重换来的完美平衡，唯一能告诉你这配重不合理的线索，就是它的重量本身。**

第二件要读的事是 $C_a$ 与 $C_b$ 是复数：它们有相位，而这些相位通常与原始不平衡的相位相去甚远。**一位技师若在正确的平面里修正了大小、却把相位弄偏了 $30^{\circ}$，他就把转子弄得比修之前更糟，这就是为什么在一台标定不正确的机器上做试重平衡，还不如干脆不修。**
:::
:::

::: example 双盘转子的两平面校正 {#ex-2plane}
一转子在平面 $z = 0$ 内带有 $0^{\circ}$ 方向的 $U_1 = 0.100\ \mathrm{kg \cdot m}$，在平面 $z = 0.5\ \mathrm{m}$ 内带有 $90^{\circ}$ 方向的 $U_2 = 0.080\ \mathrm{kg \cdot m}$。求半径 $150\ \mathrm{mm}$ 处、在（a）$z = 0.1$ 与 $0.4\ \mathrm{m}$、（b）$z = 0.2$ 与 $0.3\ \mathrm{m}$ 的校正质量。

**答。**（a）$168.7^{\circ}$ 方向 $0.906\ \mathrm{kg}$、$- 72.6^{\circ}$ 方向 $0.745\ \mathrm{kg}$。（b）$2.267\ \mathrm{kg}$ 与 $2.083\ \mathrm{kg}$——**多三倍的质量，换来一模一样的剩余平衡。**

::: solution
用复数计算。$S = U_1 + U_2 = 0.100 + \mathrm{j} 0.080$；对 $z = 0$ 取矩，$M = 0 \times U_1 + 0.5 \times U_2 = \mathrm{j} 0.040$。

**（a）平面在 $a = 0.1$、$b = 0.4$：**

$$
C_b = \frac{ - \mathrm{j} 0.040 + 0.1 ( 0.100 + \mathrm{j} 0.080 ) }{ 0.3 } = \frac{ 0.0100 - \mathrm{j} 0.0320 }{ 0.3 } = 0.03333 - \mathrm{j} 0.10667
$$

$$
\left| C_b \right| = 0.1118\ \mathrm{kg \cdot m} \ \text{在} \ - 72.6^{ \circ } \ , \qquad
C_a = - S - C_b = - 0.1333 + \mathrm{j} 0.0267 \ \Rightarrow \ \left| C_a \right| = 0.1360 \ \text{在} \ 168.7^{ \circ }
$$

除以 $r = 0.15\ \mathrm{m}$：**$m_a = 0.906\ \mathrm{kg}$，$m_b = 0.745\ \mathrm{kg}$。**

**（b）平面在 $a = 0.2$、$b = 0.3$：**分母减半，

$$
C_b = \frac{ 0.0200 - \mathrm{j} 0.0240 }{ 0.1 } = 0.200 - \mathrm{j} 0.240 \ \Rightarrow \ \left| C_b \right| = 0.3124 \ , \qquad \left| C_a \right| = 0.3400
$$

**$m_a = 2.267\ \mathrm{kg}$，$m_b = 2.083\ \mathrm{kg}$——同样的零剩余不平衡，质量却是 $3.0$ 倍。**

**（c）作为对比，平面取 $a = 0$、$b = 0.6$，即位于质量平面之外：**$C_a = 0.1009$ 在 $- 172.4^{ \circ }$，$C_b = 0.0667$ 在 $- 90^{ \circ }$，得 $0.673$ 与 $0.444\ \mathrm{kg}$。**三种布置中最好的一个，比最坏的还好 $3.9$ 倍。**

::: warning 校正平面放在哪里是设计决策，不是平衡决策
这条规则出自 [[#deriv-2plane]] 里的 $1 / ( b - a )$，值得背下来，因为它在图纸上只做一次，却要在产品的整个寿命里、在每一台平衡机上付账：

- **把校正平面放到轴承跨距允许的尽可能远的位置**，若设计允许，放到被校正质量所在平面之外。
- 只要可能，**绝不让校正平面落在质量平面之间**——那种几何让 $b - a$ 变小、让配重变得巨大。
- **把转子设计成可校正的。**两端各设一个可加工凸台、位于大半径处，图纸上印明平衡工艺与最大钻孔深度——分文不花，却是 $0.4\ \mathrm{kg}$ 配重与 $4\ \mathrm{kg}$ 配重的区别。
- **宁可去重，不要配重。**一块 $0.9\ \mathrm{kg}$ 的平衡块就是工作转速下一个 $0.9\ \mathrm{kg}$ 的离心载荷——$0.9 \times 0.15 \times \omega^{ 2 }$，在 $3000\ \mathrm{rev / min}$ 下是 $8000\ \mathrm{N}$——而且它还是一块可能松脱的重量。钻一个减重孔是永久的，不需要胶粘，也不会移位。
:::
:::
:::

::: definition 平衡品质等级，ISO 1940-1 {#def-ggrade}
标准规定的不是力；它规定的是**比不平衡量**——许用剩余量 $e_{\mathrm{per}} = U_{\mathrm{per}} / m$，以微米计的偏心距——并按工作转速列成**等级** $G$：

$$
\boxed{ \; e_{\mathrm{per}} \left[ \mu \mathrm{m} \right] = \frac{ 1000 \, G }{ \omega } = \frac{ 9549 \, G }{ n \left[ \mathrm{rev / min} \right] } \; } \qquad U_{\mathrm{per}} = m \, e_{\mathrm{per}}
$$

**等级号是一个速度。** $e_{\mathrm{per}} \omega = G\ \mathrm{mm / s}$ 是转子质心沿半径为 $e_{\mathrm{per}}$ 的轨道运行的速度——所以 $G 2.5$ 与 $G 63$ 相差二十五倍的是摆动的速度，不是金属的多少。

| 等级 $G$ | 典型转子 | $3000\ \mathrm{rev / min}$ 下的 $e_{\mathrm{per}}$ |
|---|---|---|
| $G \ 0.4$ | 重力仪、精密陀螺转子 | $1.3\ \mu \mathrm{m}$ |
| $G \ 1$ | 磨床主轴、$< 1\ \mathrm{kg}$ 的电枢 | $3.2\ \mu \mathrm{m}$ |
| $G \ 2.5$ | 汽车曲轴总成、机床传动 | $7.96\ \mu \mathrm{m}$ |
| $G \ 6.3$ | 整机状态的发动机与压缩机、涡轮转子、大型电机电枢 | $20.1\ \mu \mathrm{m}$ |
| $G \ 16$ | 带轮胎的汽车车轮、农业机械 | $51\ \mu \mathrm{m}$ |
| $G \ 40$ | 单缸与双缸发动机、天轴 | $127\ \mu \mathrm{m}$ |
| $G \ 630$ | 机车动轮、重型曲轴 | $2005\ \mu \mathrm{m}$ |
:::

::: example 一个等级要花多少金属 {#ex-grade}
一台 $15\ \mathrm{kg}$ 的机床电枢按 $G \ 6.3$ 平衡，用于 $3000\ \mathrm{rev / min}$。允许多大的剩余不平衡？它在轴承上产生多大的力？

**答。**$U_{\mathrm{per}} = 301\ \mathrm{g \cdot mm}$，交变轴承力 $118\ \mathrm{N}$。

::: solution
$$
e_{\mathrm{per}} = \frac{ 9549 \times 6.3 }{ 3000 } = 20.1\ \mu \mathrm{m} \ , \qquad
U_{\mathrm{per}} = 15 \times 20.1 \times 10^{- 6 } = 3.01 \times 10^{- 4 }\ \mathrm{kg \cdot m} = 301\ \mathrm{g \cdot mm}
$$

$\omega = 314.16\ \mathrm{rad / s}$ 时支承上的交变力为

$$
F = U_{\mathrm{per}} \, \omega^{ 2 } = 3.01 \times 10^{- 4 } \times 98{,}696 = 29.7\ \mathrm{N} \ \text{（每对校正平面；若全部许用量都集中在一端则为 } 118\ \mathrm{N} \text{）}
$$

**而 $301\ \mathrm{g \cdot mm}$ 是个惊人的小数字：它相当于 $10\ \mathrm{mm}$ 半径上 $30\ \mathrm{g}$ 焊锡，或 $15\ \mathrm{mm}$ 半径上一颗 M6 钢制内六角圆柱头螺钉。**这就是平衡的全部难处：公差比把转子拧在一起的紧固件还小，这就是为什么标准坚持转子必须**在它将要运行的状态下**平衡——带着它的键、锁紧环、冷却风扇和绝缘漆——也是为什么装配前平衡好的转子等于没有平衡。

**也注意等级没有说什么。**它对*共振*只字未提。一台在 $3000\ \mathrm{rev / min}$ 平衡得完美的转子，装在一阶临界转速为 $2800\ \mathrm{rev / min}$ 的机器上照样会抖，因为规格控制的是力，而支承的动态刚度控制的是响应。**平衡品质与振动水平相关却不是一回事，而客户对振动的投诉，往往是一个平衡机根本碰不到的支承刚度问题。**
:::
:::

::: exercise 校正平面的间距 {level=2 check="3.0"}
对 [[#ex-2plane]] 的转子，计算校正平面在 $z = 0.2$ 与 $0.3\ \mathrm{m}$ 时 $r = 150\ \mathrm{mm}$ 处的校正质量总和，再除以平面在 $z = 0.1$ 与 $0.4\ \mathrm{m}$ 时的总和。

::: solution
由 [[#ex-2plane]]，两种情形给出 $2.267 + 2.083 = 4.350\ \mathrm{kg}$ 与 $0.906 + 0.745 = 1.651\ \mathrm{kg}$，故比值为

$$
\frac{ 4.350 }{ 1.651 } = \boxed{ 3.0 }
$$

**这恰好是平面间距之比 $0.30 / 0.10 = 3.0$——不是近似，而是精确，因为校正只按 $1 / ( b - a )$ 缩放，别无其他。**两台转子离开平衡机时都是完美平衡的。第一台却多了 $2.7\ \mathrm{kg}$ 金属在 $150\ \mathrm{mm}$ 半径上旋转，给轴承载荷加上 $2.7 \times 0.15 \times \omega^{ 2 }$，并把机器里每一个固有频率都拉低。**这就是为什么"平衡机说合格"不是工程论据，也是为什么校正平面的位置必须画在制造图纸上、让车间无权移动。**
:::
:::

## 平衡（二）：往复质量，与二阶问题

::: definition 一阶与二阶惯性力 {#def-primary}
往复质量 $m_R$ 的滑块由半径 $r$、连杆长 $l$（记 $n = l / r$）的曲柄驱动，其加速度为

$$
a = r \omega^{ 2 } \left( \cos \theta + \frac{ \cos 2 \theta }{ n } + \cdots \right)
$$

于是机架必须反承的惯性力是两个谐波之和：

$$
\boxed{ \; F = \underbrace{ m_R r \omega^{ 2 } \cos \theta }_{ \textbf{一阶} \; \equiv P } + \underbrace{ \frac{ m_R r \omega^{ 2 } }{ n } \cos 2 \theta }_{ \textbf{二阶} \; = P / n } \; }
$$

**一阶力就是假设连杆无限长时往复质量所经历的力；它恰好是把往复质量想象成集中在曲柄销上时，其离心力沿往复方向的分量。**这一句话就是往复平衡理论的全部，下面每一个结论都由它推出。

**二阶力只因连杆有限长而存在**，比一阶小一个连杆比 $n$，并以**两倍**于曲柄的频率运转。短连杆（$n = 3$）的二阶力是一阶的三分之一；长连杆（$n = 6$）是六分之一。**这就是高速发动机采用长连杆、短曲柄销距的原因：不是为了气体载荷，而是因为二阶力是把其他一切平衡掉之后剩下的那部分。**
:::

::: example 单缸机，以及部分平衡意味着什么 {#ex-single}
$m_R = 2.4\ \mathrm{kg}$，$r = 45\ \mathrm{mm}$，$l = 180\ \mathrm{mm}$（$n = 4$），$3000\ \mathrm{rev / min}$，曲柄销处旋转质量 $1.6\ \mathrm{kg}$。求不平衡力，并求使其中最坏者最小的平衡分数。

**答。**一阶力 $10.66\ \mathrm{kN}$，二阶力 $2.67\ \mathrm{kN}$，旋转力 $7.11\ \mathrm{kN}$；最优平衡分数为 $c = 0.5$，留下 $5.33\ \mathrm{kN}$ 的旋转残余力。

::: solution
$$
P = m_R r \omega^{ 2 } = 2.4 \times 0.045 \times 314.16^{ 2 } = 10{,}660\ \mathrm{N} \ , \qquad S = \frac{ P }{ n } = 2665\ \mathrm{N}
$$
$$
F_{\mathrm{rot}} = m_C r \omega^{ 2 } = 1.6 \times 0.045 \times 98{,}696 = 7106\ \mathrm{N}
$$

旋转力好办：在曲柄臂上对着销的位置放 $m_{\mathrm{cw}} = m_C r / r_{\mathrm{cw}}$，它就消失了。**往复力无法被任何旋转质量抵消，因为它是沿一条直线振荡而不是旋转的。**分数为 $c$ 的旋转平衡块做的是这件事：它加上一个大小 $c P$ 的旋转矢量，其沿往复方向的分量是 $c P \cos \theta$——抵消掉一阶力的 $c$——而其横向分量是 $c P \sin \theta$，这是原来没有的：

$$
F_{ \parallel } = ( 1 - c ) P \cos \theta \ , \qquad F_{ \perp } = c P \sin \theta
$$

**你把沿缸方向的抖动换成了横向抖动，而合力永远不低于 $0.5 P$。**合力大小 $\sqrt{ ( 1 - c ) ^{ 2 } P^{ 2 } \cos^{ 2 } \theta + c^{ 2 } P^{ 2 } \sin^{ 2 } \theta }$ 在 $c P$ 与 $( 1 - c ) P$ 之间摆动；最坏情形在 $c = 0.5$ 处最小，此时合力变成一个大小恒为 $P / 2 = 5330\ \mathrm{N}$ 的**旋转**力。

**这就是机车的解法，而且是被轴承约束、而不是被动力学逼出来的折中。**机车无法用两平面平衡——动轮在钢轨上，唯一能放金属的地方是曲柄配重——所以它接受 $c \approx 0.5$–$0.75$，并用**锤击力**付账：即竖直分量 $c P \sin \theta$ 交替地加载与卸载轮对。在 $c = 0.6$、$3000\ \mathrm{rev / min}$ 下，那是 $6396\ \mathrm{N}$ 的循环竖直力；放大到机车每个动轮 $8000\ \mathrm{kg}$，这就是为什么 19 世纪线路的速度上限由机车的悬挂而不是线路的曲线决定，也是为什么蒸汽机车内置气缸的平衡配重该配多大，公开争论了五十年。

**公路车辆逃开了这一切**，因为它的发动机装在可以两平面平衡的副车架上，而车轮不是轴承。它把一阶力完全平衡（$c = 1$），再把由此产生的旋转力分给两根平衡轴上大小相等、方向相反的两半——见 [[#ex-ic4]]。**兰彻斯特平衡器（Lanchester）只用旋转质量做同一件事：两个反向旋转的配重，大小各为 $P / 2$，相位安排得使它们的合力沿往复方向、大小等于 $P$ 以抵消一阶力。它们的横向分量精确抵消，所以不产生侧向力，一阶力就此消失。**它在 1920 年代的二冲程摩托车上装过，今天有些车上仍然装着。
:::

::: theorem 直列发动机里哪些阶次活了下来 {#thm-inline}
对曲柄角为 $\theta_i$、气缸中心线位于 $z_i$ 的直列发动机，四个条件是

$$
\sum_i \cos \theta_i = \sum_i \sin \theta_i = 0 \quad \text{（一阶力）} \qquad \sum_i z_i \cos \theta_i = \sum_i z_i \sin \theta_i = 0 \quad \text{（一阶力偶）}
$$

二阶则是同样的四个式子、把 $\theta_i$ 换成 $2 \theta_i$。**因为二阶角被翻倍，相隔 $180^{\circ}$ 的曲柄——经典的一阶抵消对——其二阶却相隔 $360^{\circ}$，即同相。**因此每一个靠把曲柄摆成对置来抵消一阶力的布置，都会把它的二阶力*加倍*而不是抵消。

**直列四缸**（$\theta = 0 , 180 , 180 , 0$；$z = - 3 d , - d , + d , + 3 d$）：

| 条件 | 求和 | 结果 |
|---|---|---|
| 一阶力 | $2 \cos \theta - 2 \cos \theta$ | $0$ ✓ |
| 一阶力偶 | $- 3 d \cos \theta + d \cos \theta - d \cos \theta + 3 d \cos \theta$ | $0$ ✓ |
| 二阶力 | $4 \cos 2 \theta$ | **$4 P / n$——不平衡** |
| 二阶力偶 | $4 \cos 2 \theta ( - 3 d - d + d + 3 d )$ | $0$ ✓ |

**所以直列四缸除了一个沿气缸线、以两倍曲柄频率振荡的 $4 P / n$ 自由力之外是完全平衡的。**它没有不平衡力偶、没有不平衡旋转质量、没有任何一阶抖动——可它仍然在抖，这个花了一个世纪才解释清楚的事实，就是"平衡轴"三个字会出现在零件清单上的原因。
:::

::: example 直列四缸的二阶力与其平衡轴 {#ex-ic4}
每缸 $m_R = 2.2\ \mathrm{kg}$，$r = 43\ \mathrm{mm}$，$l = 144\ \mathrm{mm}$（$n = 3.35$），$6000\ \mathrm{rev / min}$。求二阶力，以及抵消它所需的平衡轴不平衡量。

**答。**$200\ \mathrm{Hz}$ 下 $44.6\ \mathrm{kN}$，需要两根反向旋转轴各带 $14.1\ \mathrm{g \cdot m}$ 的不平衡量。

::: solution
$$
P = 2.2 \times 0.043 \times 628.3^{ 2 } = 37{,}347\ \mathrm{N \ per \ cylinder} \ , \qquad \frac{ P }{ n } = 11{,}152\ \mathrm{N}
$$

$$
F_{\mathrm{secondary}} = 4 \times 11{,}152 = 44{,}608\ \mathrm{N} \quad \text{在} \ 2 \times 6000 / 60 = 200\ \mathrm{Hz}
$$

**四十五吨的振荡力，出自一台没有任何不平衡旋转质量的发动机。**装在 $1200\ \mathrm{kg}$ 的汽车上，若悬置是刚性的将产生 $37\ \mathrm{m / s^2 } = 3.8 \ g$；即便隔振良好的动力总成，传出的量也足以在方向盘上被感觉到、在内饰板上被听到恰好 $200\ \mathrm{Hz}$ 的嗡鸣——这就是为什么"转速 $2000$ 时有嗡鸣、降到 $1500$ 就消失"的故障要靠数阶次来诊断，而不是靠听。

两根以 $2 \omega$ 驱动、各带不平衡量 $m_b r_b$ 的反向旋转轴，在一条固定直线上产生大小 $2 m_b r_b ( 2 \omega )^{ 2 } = 8 m_b r_b \omega^{ 2 }$ 的合力。令其对抗 $4 P / n$：

$$
m_b r_b = \frac{ P }{ 2 n \omega^{ 2 } } = \frac{ 37{,}347 }{ 2 \times 3.35 \times 394{,}784 } = 1.41 \times 10^{- 2 }\ \mathrm{kg \cdot m} = \boxed{ 14.1 \ \mathrm{g \cdot m} \ \text{（每根轴）} }
$$

——例如 $40\ \mathrm{mm}$ 半径上 $0.35\ \mathrm{kg}$，是一根手指粗细的轴。**不平衡量小得微不足道；轴本身、它的链传动、轴承、相位公差，以及它对发动机摩擦力 $1$–$1.5 \ \%$ 的贡献却不微不足道，而整个组件存在的意义，是抵消一个"已经被抵消掉的力"的 $1 / n$。**

| 直列 6 | ✓ | ✓ | ✓ | ✓ |

| 60° V6 | ✓ | ✓ | ✗ | ✗ |

**直列六缸是唯一四个条件全部满足的直列布置，而正是这一点——不是功率，不是发火冲程的平顺——而是 [[#thm-inline]] 的算术，是直六在六十年间作为豪华车发动机、直八作为客机发动机的全部原因。**$90^{\circ}$ V8 配十字平面曲柄用一半的长度满足同样四个条件，这就是它在一切在乎重量的场合取代直八的原因。**而直列三缸满足两个力的条件、一个力偶条件都不满足，是现代小车的答案：两根平衡轴比三缸更便宜，而三缸机的摇摆力偶可以由一对同时抵消其二阶力的轴来平衡。**

::: exercise 压力机滑块的平衡轴不平衡量 {level=3 check="33.8"}
一台往复质量 $450\ \mathrm{kg}$ 的压力机滑块，在 $150\ \mathrm{mm}$ 曲柄销距、$240\ \mathrm{rev / min}$ 下工作。两根以曲柄转速反向旋转的一阶平衡轴，各须携带多大的不平衡量才能抵消滑块的一阶力？

::: solution
两根以曲柄转速反向旋转、各带不平衡量 $m_b r_b$ 的轴，沿往复方向产生 $2 m_b r_b \omega^{ 2 }$ 的合力，故

$$
2 m_b r_b \omega^{ 2 } = m_R r \omega^{ 2 } \quad \Longrightarrow \quad m_b r_b = \frac{ m_R r }{ 2 } = \frac{ 450 \times 0.150 }{ 2 } = \boxed{ 33.8 \ \mathrm{kg \cdot m} \ \text{（每根轴）} }
$$

**注意 $\omega$ 消掉了：所需不平衡量是一个纯几何量 $m_R r / 2$，与你转多快无关。**这就是为什么这个答案比汽车发动机的 $14.1\ \mathrm{g \cdot m}$ 糟糕那么多——同一个公式，但 $m_R r$ 是 $67.5\ \mathrm{kg \cdot m}$ 而不是 $0.095$。**每根轴三十四千克米，是一根和曲轴一样粗的平衡轴，没有压力机设计师会造它。**取而代之的是把压力机机架做得足够大，使由此产生的加速度很小——$42.6\ \mathrm{kN}$ 作用在 $6000\ \mathrm{kg}$ 机架上得 $7.1\ \mathrm{m / s^2 }$，而机架锚固在一坨混凝土上，那混凝土大得让整台东西成了地基而不是机器。

**设计教训就写在这两个并排的数字里：当 $m_R r$ 小时平衡轴是正确答案，当它大时平衡轴是错误答案，而分界点大约在几个 $\mathrm{kg \cdot m}$ 处。**这也是高速压力机和高速缝纫机采用短曲柄销距、长连杆的原因：$m_R r$ 随销距下降，连杆比 $n$ 上升，两个效应都把机器推入"平衡是一根轴的事、而不是地基的事"的那个工作区间。
:::

## 作为储能器的飞轮：它的用途，以及它在哪儿胜过电池

::: definition 旋转储能器的比能量 {#def-store}
飞轮轮缘是一台旋转压力容器。记 $v$ 为轮缘速度；密度 $\rho$ 的薄轮缘中的环向应力为 $\sigma = \rho v^{ 2 }$，质量 $m$ 的薄轮缘的动能为 $K = \frac{ 1 }{ 2 } m v^{ 2 }$。消去 $v$：

$$
\boxed{ \; \frac{ K }{ m } = \frac{ \sigma }{ 2 \rho } \quad \text{（等强度轮缘，} \sigma = \text{轮缘许用应力）} \; }
$$

**储存给定能量所需的飞轮质量只取决于材料的比强度，别的一概无关——与转速无关、与直径无关、与转动惯量也无关。**转速与直径只是你*达到*该应力的手段；应力才是你真正花钱买的东西。

| 材料 | 许用 $\sigma$ | $\rho$ | $K / m$ |
|---|---|---|---|
| 灰铸铁 | $150\ \mathrm{MPa}$ | $7100$ | $10.6\ \mathrm{kJ / kg}$ |
| 球墨铸铁 | $300\ \mathrm{MPa}$ | $7100$ | $21.1\ \mathrm{kJ / kg}$ |
| 锻碳钢 | $400\ \mathrm{MPa}$ | $7800$ | $25.6\ \mathrm{kJ / kg}$ |
| 300M 钢 | $1200\ \mathrm{MPa}$ | $7800$ | $76.9\ \mathrm{kJ / kg}$ |
| Ti-6Al-4V | $600\ \mathrm{MPa}$ | $4500$ | $66.7\ \mathrm{kJ / kg}$ |
| CFRP（环氧） | $1500\ \mathrm{MPa}$ | $1800$ | $417\ \mathrm{kJ / kg}$ |
| **锂离子电池** | — | — | $900\ \mathrm{kJ / kg}$ |
| **超级电容** | — | — | $54\ \mathrm{kJ / kg}$ |

**在能量密度之争上飞轮输一到两个数量级，在功率之争上又以大致相同的幅度赢回来。**一个储存 $12.8\ \mathrm{kJ / kg}$ 的钢轮缘可以在一秒内全部吐回，即 $12.8\ \mathrm{kW / kg}$；而 $900\ \mathrm{kJ / kg}$ 的锂电池只能安全地以 $1 \ C$ 充放，即 $0.9\ \mathrm{kW / kg}$。**而且飞轮可以做一百万次，因为它内部没有任何东西被消耗。**
:::

::: example 一个放错位置的飞轮离最优有多远 {#ex-store}
[[#ex-punch]] 的冲床飞轮是 $274\ \mathrm{kg}$ 铸铁，储存 $\Delta U / ( 2 C_s ) = 4500 / 0.30 = 15{,}000\ \mathrm{J}$。一个应力取满的轮缘需要多少铸铁？

**答。**$1.4\ \mathrm{kg}$——该设计**比热力学要求重 $190$ 倍。**

::: solution
把轮缘速度取到许用应力，$\sigma = \rho v^{ 2 }$：

$$
v = \sqrt{ \frac{ 150 \times 10^{ 6 } }{ 7200 } } = 144\ \mathrm{m / s } \ , \qquad
m = \frac{ 2 K }{ v^{ 2 } } = \frac{ 2 \times 15{,}000 }{ 20{,}833 } = 1.44\ \mathrm{kg}
$$

该设计的轮缘跑在 $10.5\ \mathrm{m / s }$、$0.79\ \mathrm{MPa}$——**一个只用掉材料能力 $0.5 \ \%$ 的飞轮。**这不是错误，而是经济选择，而值得把多出来的 $273 \ \mathrm{kg}$ 铁到底买到了什么说清楚：

- **每千克成本。**$10.5 \ \mathrm{m / s }$ 的砂型铸造灰铁，对机加工车间来说就是一副模样、一次浇注。$144 \ \mathrm{m / s }$ 的锻钢则是一块锻件、一道机加工序、一次到 $G 6.3$ 的动平衡，再加一圈防护拦环。
- **风阻。**$144 \ \mathrm{m / s }$ 的轮缘会拖着空气一起转；对一个 $0.5 \ \mathrm{m}$ 的圆盘就是几百瓦的发热，这就是正经飞轮都装在真空容器里的原因。$10.5 \ \mathrm{m / s }$ 时风阻只有几毫瓦，而"容器"只是一块钢板护罩。
- **轴承寿命。**轮缘的离心载荷以环向应力在内部自我平衡，轴承只承受剩余不平衡 $U \omega^{ 2 }$——这就是慢速飞轮用滑动轴承能跑四十年，也是为什么 $274 \ \mathrm{kg}$ 轮缘的平衡等级远比它的强度重要。
- **失效。**$144 \ \mathrm{m / s }$ 爆裂的轮缘会以 $144 \ \mathrm{m / s }$ 抛出金属。$10.5 \ \mathrm{m / s }$ 时它只是一块沉重的纸镇。**飞轮的转速首先是一条安全规格，然后才是一条效率规格。**

**老实的总结是：机器飞轮由成本、空间和安全性定尺寸，$\sigma / 2 \rho$ 只起很松的约束作用——而两者之间巨大的差距，恰恰是电池要钻过去的那个缺口。**飞轮真正无可匹敌的地方不在能量，而在图上那个每天多次同时要求能量与功率的角落：一台每隔几秒就循环一次的 $5 \ \mathrm{MW}$ 电网稳定装置需要 $10^{6}$ 次满深度循环，那是飞轮而不是电池；一套必须在 $2 \ \mathrm{s}$ 内充满的赛车 $6 \ \mathrm{MJ}$ 动能回收系统，也是飞轮而不是电池。
:::

::: quiz
一台机器的工作冲程比电动机供给多需 $800 \ \mathrm{J}$，事后又交还回来。两个设计让同一台机器分别在 $1500$ 与 $3000 \ \mathrm{rev / min}$ 下运转、$C_s$ 相同。$1500 \ \mathrm{rev / min}$ 设计的飞轮转动惯量是：

- [ ] 相同，因为 $\Delta U$ 相同
- [x] 大四倍，因为 $I_f \propto 1 / \omega^{ 2 }$
- [ ] 大两倍，因为 $I_f \propto 1 / \omega$
- [ ] 更小，因为周期更短

::: solution
**大四倍。**$\Delta U$ 与 $C_s$ 固定时 $I_f = \Delta U / ( \omega^{ 2 } C_s )$ 给出 $I_f \propto 1 / \omega^{ 2 }$，转速减半、惯量翻四倍。**而且由于给定*储存能量*下的轮缘质量 $m = 2 K \rho / \sigma$ 与转速无关，低速下多出来的惯量全靠直径来买——这就是慢速机器的飞轮大得你能绕着它走、快速机器的飞轮你一只手就能搬起来的原因。**推论就是那条设计准则：飞轮要装在机器里转速最高的轴上，而 [[#ex-geareq]] 里那个 $1 : 10$ 的齿轮，比等重的铁还值钱两倍以上。
:::

::: quiz
一个转子离开平衡车间时静平衡合格、动平衡不合格。于是支承感受到的是：

- [ ] 一个旋转力，无力偶
- [x] 一个旋转力偶，无合力
- [ ] 一个两倍工作转速的力
- [ ] 什么也没有，因为低速下只有静平衡要紧

::: solution
**一个旋转力偶，无合力。**$\sum U_i \ne 0$ 是力；$\sum U_i = 0$ 而 $\sum z_i U_i \ne 0$ 是纯力偶，而纯力偶正是不同平面内两个大小相等、方向相反的不平衡所产生的。**它的感觉是机器绕其安装座摇摆振荡，而不是安装座本身被摇晃，这就是为什么一只放在机器错误一端的振动传感器会漏掉它，也是"已平衡"的转子仍然振动最常见的原因。**补救办法恰是 [[#deriv-2plane]] 的两平面校正，而诊断办法恰是第二只传感器。

## 设计：落料压力机的驱动 {#sec-design}

::: example 设计题：250 kN 落料压力机，90 次冲程 / 分 {#ex-design level=4}
**规格。**一台落料压力机在 $15 \ \mathrm{mm}$ 工作行程上切出 $250 \ \mathrm{kN}$，每分钟 $90$ 冲，每冲曲柄转一转。剪切占曲柄转角 $100^{\circ}$。滑块与上模往复质量合计 $380 \ \mathrm{kg}$，曲柄销距 $250 \ \mathrm{mm}$，连杆 $500 \ \mathrm{mm}$。机架质量 $3500 \ \mathrm{kg}$。确定电动机、飞轮及其安装位置，并校核振动力。

**解答：能量。**每冲功 $= 250 \times 10^{ 3 } \times 0.015 = 3750 \ \mathrm{J}$。周期 $60 / 90 = 0.667 \ \mathrm{s}$，故**平均**功率为 $5.63 \ \mathrm{kW}$；若必须由电动机独自承担剪切，**峰值**功率为 $3750 / ( 0.667 \times 100 / 360 ) = 20.3 \ \mathrm{kW}$。选一台 $7.5 \ \mathrm{kW}$ 电动机，让飞轮承担差额——花一块铁盘的钱把电动机功率降 $2.7$ 倍，这就是本题的全部要点。

**解答：飞轮，以及装在哪里。**在 $90 \ \mathrm{rev / min}$ 的曲柄（$\omega_c = 9.425 \ \mathrm{rad / s}$）上平均转矩为 $5625 / 9.425 = 597 \ \mathrm{N \cdot m}$；剪切转矩在 $1.745 \ \mathrm{rad}$ 上为 $3750 / 1.745 = 2149 \ \mathrm{N \cdot m}$，故

$$
\Delta U = ( 2149 - 597 ) \times 1.745 = 2709 \ \mathrm{J} \ , \qquad
I_{\mathrm{reflected \ at \ crank}} = \frac{ 2709 }{ 9.425^{ 2 } \times 0.08 } = 381 \ \mathrm{kg \cdot m^2 }
$$

对压力机而言 $C_s = 0.08$ 已属宽松，而此处合适，因为剪切很短、机器很刚。**折算到曲柄，$381 \ \mathrm{kg \cdot m^2 }$ 相当于直径 $1.0 \ \mathrm{m}$ 的轮缘 $1524 \ \mathrm{kg}$。**挪个位置试试：

| 飞轮位置 | 转速 | 所需 $I$ | 半径 $R$ 的轮缘 | 质量 | 轮缘应力 |
|---|---|---|---|---|---|
| 装在曲柄上 | $90 \ \mathrm{rev / min}$ | $381 \ \mathrm{kg \cdot m^2 }$ | $0.50 \ \mathrm{m}$ | $1524 \ \mathrm{kg}$ | $0.16 \ \mathrm{MPa}$ |
| 装在 $4 : 1$ 中间轴上 | $360 \ \mathrm{rev / min}$ | $23.8 \ \mathrm{kg \cdot m^2 }$ | $0.30 \ \mathrm{m}$ | $264 \ \mathrm{kg}$ | $0.92 \ \mathrm{MPa}$ |
| **装在电动机轴上** | $1500 \ \mathrm{rev / min}$ | $1.37 \ \mathrm{kg \cdot m^2 }$ | $0.15 \ \mathrm{m}$ | $\mathbf{61 \ \mathrm{kg}}$ | $4.0 \ \mathrm{MPa}$ |

**选电动机轴。**飞轮是一块装在电动机主轴上的 $0.3 \ \mathrm{m}$ 球墨铸铁盘，$61 \ \mathrm{kg}$，轮缘应力只有材料能力的 $1 / 75$，而从 $1524 \ \mathrm{kg}$ 降到 $61 \ \mathrm{kg}$ 只花了一个速比——**$I \propto 1 / \omega^{ 2 }$ 而速比要平方，所以转速降 $16.7 : 1$ 就是所需惯量增 $280 : 1$，把飞轮装在曲柄上的机器是在为用不上的铁付钱。**轮缘应力从 $0.16$ 升到 $4.0 \ \mathrm{MPa}$，仍然可以忽略；真正变糟的是轴承 $p v$ 与风阻，而这两样都靠把飞轮装在自己的一根轴、自己的轴承上（而不是悬臂挂在电动机上）来解决。

**解答：振动力。**一阶力 $= m_R r \omega^{ 2 } = 380 \times 0.125 \times 9.425^{ 2 } = 4219 \ \mathrm{N}$，频率 $1.5 \ \mathrm{Hz}$；二阶力 $= 4219 / 4 = 1055 \ \mathrm{N}$，频率 $3 \ \mathrm{Hz}$。作用在 $3500 \ \mathrm{kg}$ 机架上，一阶力给出 $1.2 \ \mathrm{m / s^2 } = 0.12 \ g$。

**不配平衡轴。**所需平衡轴不平衡量为 $m_R r / 2 = 23.8 \ \mathrm{kg \cdot m}$ 每根——一根和曲轴一样大的轴——而它买来的，是抵消这样一个力：它在机架（其一阶弯曲固有频率在 $60 \ \mathrm{Hz}$ 以上）上只产生 $1.5 \ \mathrm{Hz}$、$0.12 \ g$，传递率约 $1 / ( 60 / 1.5 )^{ 2 } \approx 1 / 1600$。**振动力不是这台机器的问题；$250 \ \mathrm{kN}$ 的静载荷、机架在其中的变形、以及剪切期间 $0.08$ 的速度波动才是。**在这里配平衡轴的设计师，平衡掉的是本来就小的那一项，留下的才是起支配作用的那一项。**在买任何东西之前先弄清哪一项占主导——这项校核不花钱，却就是设计的大半。**

**解答：接下来校核什么。**
1. **电动机的 rms 转矩，而不是平均值。**电动机轴承受平均 $35.8 \ \mathrm{N \cdot m }$，剪切期间摆动 $93 \ \mathrm{N \cdot m }$；整个周期的 rms 为 $41.5 \ \mathrm{N \cdot m }$，比平均值高 $16 \ \%$，所以 $7.5 \ \mathrm{kW }$ 电动机实际运行在额定值的 $87 \ \%$ 而不是 $75 \ \%$。**先校核 rms，再拿峰值对照电动机的颠覆转矩，再拿峰值校核带传动。**
2. **飞轮自身对 $J_{\mathrm{eq}}$ 的贡献。**电动机轴上的 $1.37 \ \mathrm{kg \cdot m^2 }$ 是常数，所以不会搅动 [[#ex-ieq]] 的 $J_{\mathrm{eq}}$ 波动——但*滑块*的贡献经同一个 $16.7 : 1$ 折算为 $380 \times 0.125^{ 2 } / 16.7^{ 2 } \times (\text{速度比})^{ 2 }$，很小。**在 $90 \ \mathrm{rev / min }$ 下，$J_{\mathrm{eq}}$ 梯度转矩为 $\frac{ 1 }{ 2 } \times 0.02 \times 9.425^{ 2 } = 0.9 \ \mathrm{N \cdot m }$，可以忽略；在 $1500$ 下它将是 $246 \ \mathrm{N \cdot m }$，并将是整个设计本身。**
3. **离合器与制动器。**飞轮在电动机轴上、位于离合器上游，所以离合器必须在曲柄处传递 $2149 \ \mathrm{N \cdot m }$，而制动器必须在飞轮仍以 $1500 \ \mathrm{rev / min }$ 旋转时停住滑块——见 [[#warn-flywheel]]。
4. **飞轮护罩，带一项过压旋转试验。**$61 \ \mathrm{kg}$、$23.6 \ \mathrm{m / s }$ 储存 $17 \ \mathrm{kJ}$。
:::

::: history
| | |
|---|---|
| **1788 年——瓦特（Watt）的飞轮与调速器** | 单动式蒸汽机把全部输出都压在活塞一侧的单个冲程上交付，博尔顿（Boulton）与瓦特的蒸汽机出售时飞轮是标准配置、调速系统却是选装项。**飞轮不是蒸汽机的附件；正是它让蒸汽机得以驱动磨坊、水泵或织机，而不是把它们砸坏。**瓦特那一年的专利把平行运动机构与调速器一并覆盖，图纸里就有飞轮。 |
| **1850 年代–1864 年——费尔拜恩（William Fairbairn）的飞轮爆裂事故** | 费尔拜恩在曼彻斯特的工厂制造的蒸汽机曾发生铸铁飞轮爆裂，他对旋转铸铁圆盘与轮缘爆裂转速的系统测量确立了两点：支配一切的是 $\sigma = \rho v^{ 2 }$，而定限的是铸件的缺陷、不是铁的标称强度。**他的结论——飞轮是压力容器、必须按压力容器对待——是此后每一张飞轮图纸上每一条过压旋转试验要求的源头。** |
| **1904–1906 年——兰彻斯特的平衡器** | 弗雷德里克·W. 兰彻斯特此时已造过自己的汽车又将其放弃，他证明用两个各为一阶力一半的反向旋转配重，可以在不引入侧向力的情况下抵消往复机的一阶力，并为该装置申请了专利。他的记述见 *A Speedometer and a Tender for Automobiles and the Automobile of the Future*（1906）。**兰彻斯特平衡器至今仍装在无法用别的方式平衡的双缸摩托车发动机上。** |
| **约 1910 年——锤击力试验** | 1910 年前后的英国铁路试验测量了机车配重施加于钢轨的循环竖直力，并确立了经验法则：锤击力应低于设计最高速度下轮载的某个规定比例。**这是有记载的第一次把平衡规格写成力的限制而非质量的限制，正是六十年后 ISO 1940 将采用的逻辑。** |
| **1950 年代–1980 年代——飞轮公共汽车** | 瑞士的欧瑞康（Oerlikon）从 1950 年代起运营带飞轮的无轨电车，把制动能量回收进一个加速旋转的飞轮、在起步时返还；梅赛德斯-奔驰（Mercedes-Benz）1980 至 1987 年在威斯巴登运营过类似车队。**它们输在能量密度上，而不是输在飞轮上：飞轮公共汽车每一站都要一座仓库大小的充电装置，当电池是备选方案时，这恰恰是错误的交易。** |
| **1970 年代中期——矢崎（Yazaki）的轴** | 一项 1970 年代中期的反向旋转平衡轴专利，在该十年末首次装上日本乘用车发动机量产，使直列四缸的二阶力成了可以购买的零件。**这是机械设计中最清晰的例子：一个理论——[[#thm-inline]] 的 $4 P / n$——闲置六十年无人利用，因为在那之前，轴、链和轴承不值得为那点振动花钱，直到客户开始抱怨它。** |
| **1973 年——ISO 1940-1** | 国际标准化组织发布了转子平衡品质分级，用与工作转速挂钩的、以微米计的许用偏心距，取代了一个世纪的"好好平衡它"。**它的持久影响是商业性的而非技术性的：它把平衡变成了一项带数字的、可测量的验收试验，而这是一条车间唯一会接受的动力学要求的唯一形式。** |
| **2011–2015 年——电网与赛道上的飞轮** | 一座 $20 \ \mathrm{MW }$ 的飞轮调频电站 2011 年在纽约州投运，数百台磁轴承上的真空密封钢转子机器并联运行；一辆德国原型赛车凭碳纤维飞轮在 2015 年赢得勒芒，两秒内回收数兆焦的制动能量。**两者都是电池做不了的应用，而两者用的都是同样两行代数：$K / m = \sigma / 2 \rho$ 与 $P / K = 1 / \tau$。** |
:::

::: summary
- **惯量要在它实际所在之处计算，而不是在轴所在之处。**$J_{\mathrm{eq}} ( \theta ) = \sum [ m_i ( v_{Gi} / \omega )^{ 2 } + I_{Gi} ( \omega_i / \omega )^{ 2 } ]$，经轮系折算时取传动比的**平方**——这就是飞轮属于机器里转速最高的那根轴的原因。
- **连杆机构的运动方程是 $T = J_{\mathrm{eq}} \alpha + \frac{ 1 }{ 2 } ( \mathrm{d} J_{\mathrm{eq} } / \mathrm{d} \theta ) \omega^{ 2 }$，而第二项在匀速时也存在。**对曲柄滑块机构，它在 $3000 \ \mathrm{rev / min }$ 下是平均转矩的 $28$ 倍，也是高速下采用对置滑块的原因。
- **飞轮由 $\Delta U$ 定尺寸，而不是由峰值转矩：**$I_f = \Delta U / ( \omega^{ 2 } C_s )$，其中 $C_s$ 是规格（发电机 $0.005$，压力机 $0.15$），而 $\Delta U$ 从驱动力矩图上读出，即累积能量曲线的纵向范围。
- **飞轮降低峰值功率，永远不降低峰值力。**曲轴、齿轮与机架由峰值转矩定尺寸，而制动器必须在飞轮仍在全速时停住机器。
- **储存给定能量所需的飞轮质量是 $2 K \rho / \sigma$，与转速无关。**机器飞轮远比这重，因为它们便宜、慢速、无护罩、不抽真空——而这笔交易通常是对的。
- **动平衡需要两个平面，因为它是四个标量条件：**$\sum U_i = 0$ 与 $\sum z_i U_i = 0$。一根静平衡的细长转子动平衡不合格，感觉像一个摇摆力偶。
- **校正质量按 $1 / ( b - a )$ 缩放，即校正平面的间距。**选错位置要花四倍的金属，而剩余平衡却毫无差别——所以平面位置必须上图纸。
- **平衡等级是一个速度：**$e_{\mathrm{per}} \omega = G \ \mathrm{mm / s }$，故 $e_{\mathrm{per}} = 9549 G / n$ 微米。$3000 \ \mathrm{rev / min }$ 下的 $G 6.3$ 是 $20 \ \mu \mathrm{m }$，对 $15 \ \mathrm{kg }$ 的转子即 $301 \ \mathrm{g \cdot mm }$——比一颗螺栓还小。
- **一阶惯性力 $m_R r \omega^{ 2 }$ 是假想旋转质量在曲柄销处的分量；二阶力是它的 $1 / n$、以两倍曲柄转速运转，只因连杆有限长而存在。**用对置曲柄抵消一阶力，会把二阶力加倍。
- **直列四缸在一阶力、一阶力偶与二阶力偶上都平衡，却带着 $4 P / n$ 的自由二阶力**——$6000 \ \mathrm{rev / min }$ 下为 $44.6 \ \mathrm{kN }$——两根各带 $14.1 \ \mathrm{g \cdot m }$ 的轴就能消掉它。**要不要消它是成本决策，而在 $90 \ \mathrm{rev / min }$ 的压力机上，答案是不消。**
:::

## 延伸阅读

- **S. G. Taylor, *The Text Book of Balancing*（1951）**——刚性转子平衡的经典著作，至今仍是"为什么必须两个平面"以及平衡机究竟如何分离两个校正量的最清晰推导。
- **A. S. Vol'pert and S. B. Chernyak, *Dynamics of Machinery*（Mir, 1977; reprint 2020）**——关于等效系统、$J_{\mathrm{eq}} ( \theta )$ 与飞轮问题的最完整论述，附有 [[#ex-ieq]] 所用那种曲柄滑块的算例。
- **V. Artobolevsky, *Mechanisms in Modern Engineering Design*, vols. I–V（Mir, 1971–75）**——平衡轴、兰彻斯特平衡器、飞轮布置与调速机构的百科全书，附生产实例图样。
- **H. Rissez and the ISO TC 108 secretariat, ISO 1940-1:2003, *Mechanical vibration — Balance quality requirement for rotors in a constant (rigid) state***——读附录：它们对等级选择以及 $e_{\mathrm{per}}$ 与由此产生的轴承载荷之间关系的解释，比任何教科书都好得多。
- **W. F. Milliken and D. L. Milliken, *Race Car Vehicle Dynamics*（SAE, 1995），动力总成振动一章**——关于发动机悬置与阶次分析的实践论述，以及当 $200 \ \mathrm{Hz }$ 的力遇上 $190 \ \mathrm{Hz }$ 的仪表板时车内会发生什么。
- **S. H. Crandall、D. C. Karnopp、E. F. Kurtz 与 D. C. Pridmore, *Dynamics of Mechanical and Electromechanical Systems*（McGraw-Hill, 1968）**——能量方法与等效惯量表述，发展到使 $\frac{ 1 }{ 2 } \omega^{ 2 } \, \mathrm{d} J / \mathrm{d} \theta$ 项成为自然推论而非猎奇点缀的程度。
- **B. Paul, *Kinematics of Dynamics of Machines*（Ellis Horwood, 1979），平衡与飞轮各章**——对 [[#thm-inline]] 的直列发动机结果与部分平衡最优值 $c = 0.5$ 的紧凑而严格的推导。
