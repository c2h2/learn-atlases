::: warning 齿轮可以双向驱动
凸轮能推不能拉，而[[mechanisms/cams]]里的一切都是在讨论把这一不对称推到极限时会发生什么。齿轮没有这个问题：**它的轮齿可以在两个方向上驱动**，所以一对齿轮传递转矩时，能经历换向、堵转和振荡，不需要弹簧、重力或第二套机构来维持接触。正是这一点，加上精确恒定的传动比，使齿轮成为应用最广的机械零件之一；也正因如此，齿轮失效——齿面剥落或齿根开裂——会让整台机器完全停机。

代价是一串凸轮不必遵守的约束。**两个齿轮的模数和压力角必须相同**，实际上就是说它们由同一种基本齿条展成。它们的中心距必须严格控制：中心距加大并不改变渐开线齿轮副的传动比，但会增加侧隙并缩短实际啮合线。它们的齿数还受干涉的下限约束，这就是为什么几乎每个齿轮箱里最小的那个齿轮决定了模数。
:::

## 你已经知道的内容

- **纯滚动**——齿轮副的节圆就是相互滚动的两个圆，与[[mechanisms/mechanisms-mobility]]摩擦传动讨论中的摩擦轮完全一样，区别在于轮齿使滚动成为精确的，而不依赖摩擦。
- **传动角与压力角**——[[mechanisms/cams]]里凸轮的$\tan \psi = s' / \left( r_p + s \right)$是齿轮压力角的一个特例，而齿轮的压力角是*恒定*的，凸轮的压力角却在整个升程中变化。
- **赫兹接触应力**——[[mechanisms/cams]]里的$p_0 = \sqrt{ F E^{*} / ( \pi b R ) }$支配齿轮点蚀，正如它支配凸轮磨损，只有一个关键区别：齿轮接触处的综合曲率半径$R$在啮合过程中*连续变化*，在啮合起始处、小齿轮齿根附近最小。
- **速度瞬心**——齿轮副的节点就是两个构件的相对瞬心，[[mechanisms/velocity-analysis]]中的三心定理（Kennedy定理）正是使它保持不动的原因。
- **等效惯量与转矩**——[[mechanisms/acceleration-analysis]]中的$T_{\mathrm{eq}} = T / \left( \eta i \right)$与$J_{\mathrm{eq}} = J / i^{2}$，这就是为什么选择齿轮箱既看它给出的转速，也看它“隐藏”的惯量。

## 齿廓啮合基本定律：什么样的齿廓才能工作

::: definition 齿廓啮合基本定律 {#def-law}
两条齿廓是**共轭的**——它们传递恒定的角速度比——当且仅当**两齿廓在每一接触点处的公法线都通过连心线上的一个定点**。这个定点就是**节点**$P$，过$P$、分别以两轴心为圆心的两个圆就是节圆。

等价地，记$O_1 P = r_1$、$O_2 P = r_2$，$N_1$、$N_2$为两轴心到公法线的垂足，

$$
\boxed{ \; \frac{\omega_1}{\omega_2} = \frac{O_2 P}{O_1 P} = \frac{r_2}{r_1} = \frac{O_2 N_2}{O_1 N_1} \; }
$$

（最后一个等号来自相似三角形$O_1 N_1 P$与$O_2 N_2 P$）。只有$P$不动，传动比才恒定；保证这一点的最简单办法，是让$N_1$与$N_2$成为*定点*——也就是说，让公法线成为**一条与两个固定圆相切的固定直线**。这两个圆就是基圆，做到这一点的齿廓就是渐开线。
:::

::: exercise 推导：渐开线是啮合线为直线的齿廓 {#deriv-involute level=3}
::: solution
取一条固定直线$\ell$作为公法线，它与以$O_1$为圆心、半径$r_{b1}$的圆以及以$O_2$为圆心、半径$r_{b2}$的圆都相切。接触点可以在$\ell$上任意位置，因此比值$O_1 N_1 / O_2 N_2 = r_{b1} / r_{b2}$按构造就是常数（直线$\ell$与连心线交于把$O_1 O_2$按$r_{b1} : r_{b2}$分割的定点），沿$\ell$的每一接触点都满足齿廓啮合基本定律。

现在问：构件1上什么样的齿廓，能使它在接触点处的法线始终是$\ell$？从构件1上看，直线$\ell$在基圆上作无滑动的纯滚动，而接触点是这条滚动直线上的一个固定点；该点相对构件1的轨迹就是齿廓。**把一根拉紧的线从半径为$r_b$的圆上展开：线的自由端描出的就是渐开线**，参数方程直接从这一构造得出，$t$为展开角，

$$
x = r_b \left( \cos t + t \sin t \right) , \qquad y = r_b \left( \sin t - t \cos t \right)
$$

于是参数$t$处的向径与局部压力角为

$$
r = r_b \sqrt{ 1 + t^{2} } , \qquad \cos \phi = \frac{r_b}{r} = \frac{1}{\sqrt{ 1 + t^{2} } } , \qquad t = \tan \phi
$$

而**渐开线函数**——渐开线上一点相对于渐开线在基圆上起点的极角——为

$$
\operatorname{inv} \phi = \tan \phi - \phi
$$

由此得出的两个事实在实践中都很重要。**圆的渐开线只依赖一个参数$r_b$**——当$r_b \to \infty$时它变成直线，所以给定模数和压力角的所有渐开线齿轮，其共轭齿廓都是同一条直边齿条。这正是一把齿条型刀具能展成任意齿数齿轮的原因。**渐开线只存在于基圆之外**，这是本课所有限制的几何根源：最少齿数、根切，以及齿数过少的齿轮不仅是弱，而且被根切。
:::
:::

## 渐开线为何胜出

曾大量使用过的共轭齿廓有两族，了解其中一族为何取代另一族是值得的，因为两者至今都还在制造。

**摆线齿**在节圆以上是外摆线（一个圆在节圆*外侧*滚动时其上一点的轨迹），在节圆以下是内摆线（圆在*内侧*滚动）。由同一个滚圆生成齿廓的齿轮彼此共轭，因此一组齿轮可以做到互换；而且凸的齿顶总是与凹的齿根相啮合，接触应力较低。直到十九世纪相当晚的时候，它都是磨坊和机械中的主流齿形，至今仍是钟表轮系的常用齿形。它的弱点在工艺上：齿廓是组合曲线，每种齿数需要不同的齿形；压力角在啮合过程中变化；而且**只有在理论中心距上传动比才是精确的**。

**渐开线**没有这些弱点。它的啮合线是一条固定直线，所以压力角恒定；又因为传动比只由两个基圆决定（$\omega_1 / \omega_2 = r_{b2} / r_{b1}$），**中心距改变时渐开线齿轮副仍保持精确恒定的传动比**——改变的只是侧隙和重合度。对制造而言最重要的是，渐开线齿条的齿是**直边**，所以齿条刀、滚刀（缠绕在圆柱上成螺旋的齿条）或直边砂轮可以展成给定模数和压力角的任意齿数。正是这种展成特性，而不是强度上的什么优势，使渐开线到十九世纪末成为动力齿轮的标准齿形。

要付出的代价是：渐开线在啮合起始处的综合曲率半径小；小齿轮的齿根窄；配对齿轮的齿顶可能越过基圆处渐开线的终点——这就是后面几节的干涉问题。

## 直齿轮的几何

::: definition 标准齿制 {#def-proportions}
直齿轮由**模数**$m = d / N$（每齿的毫米数，是英制径节$P = 25.4 / m$的SI替代量）、齿数$N$和压力角$\phi$定义。按标准基本齿条（ISO 53及其对应的AGMA标准），标准全齿高的尺寸比例为

| 特征 | 符号 | 数值 | 说明 |
|---|---|---|---|
| 分度圆直径 | $d$ | $m N$ | 节圆纯滚动处 |
| 基圆直径 | $d_b$ | $m N \cos \phi$ | 渐开线的发生圆 |
| 齿顶高 | $a$ | $1.0 \, m$ | 分度圆到齿顶 |
| 齿根高 | $b_d$ | $1.25 \, m$ | 分度圆到齿根；$0.25 m$为顶隙 |
| 齿顶圆直径 | $d_a$ | $m ( N + 2 )$ | |
| 齿根圆直径 | $d_f$ | $m ( N - 2.5 )$ | |
| 齿距 | $p$ | $\pi m$ | 分度圆上相邻两齿的弧长 |
| 基圆齿距 | $p_b$ | $\pi m \cos \phi$ | **真正起作用的齿距** |
| 齿厚 | $s$ | $\pi m / 2$ | 分度圆上，无侧隙时 |
| 中心距 | $C$ | $m ( N_1 + N_2 ) / 2$ | 标准、未变位 |

**决定两齿轮能否啮合的是基圆齿距，而不是分度圆齿距。**两个渐开线齿轮只有在基圆齿距相等时才能正确啮合；由于$p_b = \pi m \cos \phi$，对标准齿轮而言这就意味着模数*和*压力角都相等。（$m$和$\phi$不同但$m \cos \phi$相同的齿轮原则上也能啮合，只是啮合角不标准，而且它们不能用同一把标准刀具加工。）$14.5^{\circ}$齿轮与同模数的$20^{\circ}$齿轮不能正确啮合；直齿轮也不能与法向模数、法向压力角相同的斜齿轮啮合，因为斜齿轮的端面齿距更大。
:::

::: example 齿数24、模数4小齿轮的几何 {#ex-geometry}
对$N = 24$、$m = 4\ \mathrm{mm}$、$\phi = 20^{\circ}$，计算各直径、各齿距和基圆上的齿厚。

**答案。**$d = 96$、$d_a = 104$、$d_f = 86\ \mathrm{mm}$；$p = 12.566$、$p_b = 11.808\ \mathrm{mm}$；基圆齿厚$s_b = 7.25\ \mathrm{mm}$。与$72$齿大齿轮配对时$C = 192\ \mathrm{mm}$。

::: solution
$$
d_b = 96 \cos 20^{\circ} = 90.21\ \mathrm{mm} , \qquad p = \pi \times 4 = 12.566\ \mathrm{mm} , \qquad p_b = 12.566 \times 0.93969 = 11.808\ \mathrm{mm}
$$

任意半径$r_x$处的齿厚可由渐开线函数求得：轮齿对中心所张的半角在基圆处为$s / d + \operatorname{inv} \phi$，向外到半径$r_x$处减小$\operatorname{inv} \phi_x$，于是

$$
s_x = 2 r_x \left[ \frac{s}{d} + \operatorname{inv} \phi - \operatorname{inv} \phi_x \right] , \qquad \cos \phi_x = \frac{d_b}{d_x}
$$

在基圆处$\phi_x = 0$、$\operatorname{inv} 0 = 0$，且$s = \pi m / 2 = 6.283\ \mathrm{mm}$、$\operatorname{inv} 20^{\circ} = 0.36397 - 0.34907 = 0.014904$，

$$
s_b = 2 \times 45.105 \times \left[ \frac{6.283}{96} + 0.014904 \right] = 90.21 \times 0.080354 = 7.249\ \mathrm{mm} = 1.812 \, m
$$

**与分度圆上的$1.571 \, m$相比：渐开线齿在基圆处比在分度圆处厚15%。**反过来，在齿顶圆$r_a = 52\ \mathrm{mm}$处，局部压力角为$\phi_a = \arccos ( 45.105 / 52 ) = 29.84^{\circ}$，$\operatorname{inv} \phi_a = 0.05284$，于是

$$
s_a = 2 \times 52 \times \left[ 0.06545 + 0.014904 - 0.05284 \right] = 2.86\ \mathrm{mm} = 0.72 \, m
$$

所以轮齿从基圆处的$1.81 \, m$逐渐变窄到齿顶处的$0.72 \, m$。齿数减少或齿顶高增大时齿顶厚会缩小，常用的设计准则要求它至少为$0.25$–$0.4 \, m$——这也是变位量不能无限加大的限制之一。
:::
:::

## 干涉：齿数低于此值，轮齿就会被根切

渐开线只存在于基圆之外。基圆以内的齿廓根本不是渐开线——它是刀具留下的形状，而齿条型刀具的刀尖相对轮坯走出的是一条延伸渐开线（摆线类曲线）。如果*另一个*齿轮的齿顶伸进小齿轮基圆以内——越过啮合线与基圆的切点——它就必须穿过小齿轮的轮齿。这就是**干涉**。对展成加工的齿轮来说，刀具本身就相当于这样一个配对齿条，它在切削时会把妨碍的材料切掉：齿根被**根切**，轮齿在受力最大的截面处被削弱，部分有效渐开线也随之丢失。与本课的其他限制不同，它不是程度问题，而是几何问题。

::: proposition 避免干涉的最少齿数 {#thm-minteeth}
设$N_1$齿的小齿轮驱动$N_2 = G N_1$齿的外齿轮，标准中心距安装，压力角$\phi$，齿顶高$a = 1.0 \, m$。当任一齿顶圆越过啮合线与*另一*基圆的切点时，干涉开始。记$r = m N / 2$、$r_a = r + m$、$r_b = r \cos \phi$及$C = r_1 + r_2$，大齿轮齿顶保持在啮合线有效段内的条件为

$$
\sqrt{ r_{a2}^{2} - r_{b2}^{2} } \; \le \; C \sin \phi
$$

平方并消项后化为

$$
\boxed{ \; N_1 \left( N_1 + 2 N_2 \right) \ \ge \ \frac{4 \left( N_2 + 1 \right)}{\sin^{2} \phi} \; } \qquad \text{及对称地} \qquad N_2 \left( N_2 + 2 N_1 \right) \ \ge \ \frac{4 \left( N_1 + 1 \right)}{\sin^{2} \phi}
$$

对于与**齿条**啮合的小齿轮（$G \to \infty$），它退化为著名的

$$
\boxed{ \; N_{\min} = \frac{2}{\sin^{2} \phi} \; } \qquad \Rightarrow \qquad
\begin{cases} N_{\min} = 31.9 & \phi = 14.5^{\circ} \\[4pt] N_{\min} = 17.1 & \phi = 20^{\circ} \\[4pt] N_{\min} = 11.2 & \phi = 25^{\circ} \end{cases}
$$
:::

::: proof
啮合线在干涉点$N_1$处与小齿轮基圆相切，$N_1$距节点$P$为$r_1 \sin \phi$；在$N_2$处与大齿轮基圆相切，$N_2$距$P$为$r_2 \sin \phi$；所以$N_1 N_2 = C \sin \phi$。大齿轮齿顶圆与啮合线的交点距$N_2$为$\sqrt{ r_{a2}^{2} - r_{b2}^{2} }$，只有当该点位于$N_2$与$N_1$之间时，接触才保持在小齿轮的渐开线上，这就是第一个不等式。代入$r_{a2} = m ( N_2 + 2 ) / 2$、$r_{b2} = m N_2 \cos \phi / 2$和$C = m ( N_1 + N_2 ) / 2$，乘以$4 / m^{2}$并平方，

$$
( N_2 + 2 )^{2} - N_2^{2} \cos^{2} \phi \le ( N_1 + N_2 )^{2} \sin^{2} \phi \quad \Longleftrightarrow \quad 4 ( N_2 + 1 ) \le N_1 ( N_1 + 2 N_2 ) \sin^{2} \phi
$$

其中用到$\cos^{2} \phi = 1 - \sin^{2} \phi$。交换两齿轮的角色即得第二个条件。对齿条，两边除以$N_2$并令$N_2 \to \infty$：$4 \le 2 N_1 \sin^{2} \phi$。假设：未变位齿轮、标准中心距、全齿高齿顶高$1.0 \, m$，并以尖锐的齿顶角作为接触点（齿顶倒圆会使限制略为放宽）。
:::

::: widget plot
title: 小齿轮最少齿数与压力角的关系
f: 2/pow(sin(x*pi/180),2)
x: 14, 30
y: 8, 40
caption: 齿条情形，$N_{\min} = 2 / \sin^{2} \phi$。**曲线在低压力角一端极其陡峭**：从$14.5^{\circ}$到$20^{\circ}$，最少齿数减少约十五齿，这在很大程度上解释了为什么较早的$14.5^{\circ}$齿制在二十世纪让位于$20^{\circ}$成为通用标准。$20^{\circ}$时的17.1就是“未变位小齿轮不少于约17齿”这一经验规则的来源（恰为17齿时的轻微根切通常是可以接受的），而变位存在的主要理由就是突破这一限制。

::: example 读干涉表 {#ex-interference}
求传动比$G = 1$、$G = 3$和$G = \infty$时未变位$20^{\circ}$小齿轮的最少齿数，并检查$19 / 57$齿轮副是否安全。

**答案。**对$N$求解$G N + 1 \le N^{2} ( 1 + 2 G ) \sin^{2} \phi / 4$（这是[[#thm-minteeth]]的第一个条件，取$N_2 = G N$；当$G \ge 1$时它是起控制作用的条件）：

| 传动比$G$ | 最少$N_1$ | 起控制作用的约束 |
|---|---|---|
| 1 | 12.32 → **13** | 两者相同（对称） |
| 3 | 14.98 → **15** | 大齿轮齿顶切入小齿轮齿根 |
| $\infty$（齿条） | 17.10 → **18** | 齿条齿顶切入小齿轮齿根 |

::: solution
$19 / 57$齿轮副的$G = 3$，$N_1 = 19 > 15$，所以安全，还有四齿余量。取模数$3$直接校核几何（$r_1 = 28.5$、$r_2 = 85.5$、$r_{a2} = 88.5$、$r_{b2} = 80.344\ \mathrm{mm}$、$C = 114\ \mathrm{mm}$），大齿轮齿顶必须停在小齿轮干涉点之前：

$$
\sqrt{ r_{a2}^{2} - r_{b2}^{2} } = \sqrt{ 88.5^{2} - 80.344^{2} } = 37.11\ \mathrm{mm} \; < \; C \sin \phi = 114 \times 0.34202 = 38.99\ \mathrm{mm}
$$

**表中有两点值得细想。**第一，小齿轮最少齿数随传动比*增大*，从1:1时的13齿增加到与齿条啮合时的18齿——小齿轮与大齿轮啮合比两个相同齿轮啮合更不利，因为配对齿轮越大，它的齿顶沿啮合线伸向小齿轮干涉点的距离就越远。第二，**这一限制是几何限制，而不是强度限制**：低于它，轮齿在齿根被根切，随之也损失弯曲强度和一部分实际啮合线。
:::
:::

::: warning 变位不是锦上添花，而是标准解法
上一节的所有限制都假定**标准齿条**：齿顶高恰为$1.0 \, m$，齿轮的分度圆与齿条的分度线相切。把齿条从齿轮中心移开$x m$——变位系数为$x$的**变位**（**齿顶高修正**）——展成的轮齿齿根更厚、齿顶更窄，干涉条件变为

$$
N_{\min} ( x ) = \frac{ 2 \left( 1.0 - x \right)}{\sin^{2} \phi} \qquad \Rightarrow \qquad x = + 0.3 \ \text{使} \ N_{\min} \ \text{从} \ 17.1 \ \text{降到} \ 12.0
$$

变位在很大程度上就是为了换来这五个齿：在模数3时，它们就是$51\ \mathrm{mm}$与$36\ \mathrm{mm}$小齿轮之间的差别，可能决定齿轮箱装不装得下。变位齿轮仍用标准刀具加工，只是调整刀具位置，但**它们不再能与目录上的标准齿轮互换，小齿轮的齿顶变窄，配对齿轮也必须一起设计。**常见做法是小齿轮取$x_1 = +x$、大齿轮取$x_2 = -x$，两者之和为零，从而保持标准中心距；变位系数之和不为零时会改变中心距和啮合角，常被有意用来凑出给定的中心距，或平衡两齿轮的强度。
:::

## 重合度：有几对齿在承载

::: definition 重合度 {#def-crr}
**实际啮合线**是接触点在啮合线上扫过的长度，从小齿轮齿顶圆与啮合线的交点到大齿轮齿顶圆与啮合线的交点，

$$
L = \sqrt{ r_{a1}^{2} - r_{b1}^{2} } + \sqrt{ r_{a2}^{2} - r_{b2}^{2} } - C \sin \phi
$$

**端面重合度**就是以基圆齿距度量的这段长度，

$$
\boxed{ \; m_p = \frac{L}{p_b} = \frac{ \sqrt{ r_{a1}^{2} - r_{b1}^{2} } + \sqrt{ r_{a2}^{2} - r_{b2}^{2} } - C \sin \phi }{ \pi m \cos \phi } \; }
$$

它是同时处于接触的平均齿对数。**重合度小于1.0意味着一对齿在下一对齿进入啮合之前就已退出**：每个周期中有一段时间不存在渐开线接触，从动轮瞬时减速或加速，下一对齿带冲击进入啮合。实际直齿轮按$m_p \ge 1.2$设计，通常为$1.4$–$1.8$。
:::

对$N_1 = 20$、$N_2 = 40$、$m = 3\ \mathrm{mm}$、$\phi = 20^{\circ}$，标准齿制、标准中心距，计算实际啮合线长度和重合度。

$$

## 中心距：比看上去更严的公差

未变位齿轮副按$C = m ( N_1 + N_2 ) / 2$设计。把它装在稍大的中心距上，它照样转动，而且传动比完全不变——这正是渐开线的最大优点——但同时会发生三件事。

1. **出现侧隙。**齿槽比轮齿宽约$j \approx 2 \Delta C \tan \phi$，沿分度圆度量。
2. **啮合角增大。**基圆不变，所以过新中心距$C' = C + \Delta C$的内公切线更陡：

$$
C' \cos \phi_{\mathrm{op}} = C \cos \phi
$$

3. **重合度下降**，因为实际啮合线中被减去的项$C' \sin \phi_{\mathrm{op}}$增大，而两个齿顶圆项不变。

::: example 中心距敏感性，20/40模数3 {#ex-centre}
对[[#ex-crr]]中的$20 / 40$模数3齿轮副，列表给出中心距加大时的啮合角、侧隙和重合度。

::: solution
对每个$\Delta C$，$\phi_{\mathrm{op}} = \arccos [ 90 \cos 20^{\circ} / ( 90 + \Delta C ) ]$；圆周侧隙等于啮合节圆上的齿距减去两齿轮在啮合节圆上的齿厚（用[[#ex-geometry]]的齿厚公式）；而$m_p = [ 17.155 + 28.109 - C' \sin \phi_{\mathrm{op}} ] / 8.856$。

| $\Delta C$ (mm) | $\phi_{\mathrm{op}}$ | 侧隙$j$ (mm) | $m_p$ |
|---|---|---|---|
| 0 | $20.00^{\circ}$ | 0 | 1.635 |
| +0.05 | $20.09^{\circ}$ | 0.037 | 1.619 |
| +0.10 | $20.17^{\circ}$ | 0.073 | 1.602 |
| +0.20 | $20.35^{\circ}$ | 0.147 | 1.570 |
| +0.45 | $20.77^{\circ}$ | 0.335 | 1.489 |
| +0.90 | $21.50^{\circ}$ | 0.686 | 1.348 |
| +1.80 | $22.89^{\circ}$ | 1.431 | 1.079 |

$\Delta C$较小时，侧隙一栏与$2 \Delta C \tan \phi$相差不过百分之几；中心距每加大一毫米，重合度约下降$0.33$。**箱体孔距大了$0.1\ \mathrm{mm}$只损失$0.03$的重合度，但$0.9\ \mathrm{mm}$（$0.3$个模数）损失$0.29$，$1.8\ \mathrm{mm}$时只剩$m_p = 1.08$**——仅略高于“下一对齿在上一对齿退出前进入啮合”的极限，此时啮合角比名义值高三度，侧隙达$1.4\ \mathrm{mm}$。

**合理性检查。**$\Delta C$较小时变化是线性的，这是必然的：在$C' \cos \phi_{\mathrm{op}}$不变时，$d ( C' \sin \phi_{\mathrm{op}} ) / dC' = 1 / \sin \phi_{\mathrm{op}}$，所以$\Delta m_p \approx - \Delta C / ( p_b \sin \phi ) = - 1 / ( 8.856 \times 0.342 ) = - 0.33$每毫米。危险之处在于**看起来一切正常**——轴转动灵活，侧隙显得很充裕——但齿轮副在每个周期中单齿啮合的时间变长了，轮齿载荷更大，噪声也更大。

## 轮齿弯曲：机械工程中最古老的强度公式

::: definition 刘易斯公式 {#def-lewis}
把轮齿看作一根悬臂梁，载荷沿啮合线作用在齿顶外角。在内切等强度抛物线（其顶点位于载荷作用线与轮齿中线的交点）与齿根过渡曲线相切的截面——最薄弱截面——处截开，并对厚度为$t$、单位宽度的矩形截面写出弯曲应力$\sigma = M c / I$：

$$
\sigma_F = \frac{6 W_t a}{b \, t^{2}}
$$

其中$W_t$为传递的圆周力，$a$为载荷到危险截面的力臂，$b$为齿宽。令$t = Y' m$、$a = k' m$，即得**刘易斯公式**，

$$
\boxed{ \; \sigma_F = \frac{ W_t }{ b \, m \, Y } \; } \qquad Y = \frac{ t^{2} }{ 6 a m }
$$

其中$Y$为**刘易斯齿形系数**，是只取决于齿数和压力角的纯数。然后像校核轴的疲劳极限那样，用弯曲疲劳极限$\sigma_{F,\lim}$和安全系数校核轮齿——因为它本来就是这样：**齿根是一个每转加载一次的弯曲疲劳试件**，普通齿轮为脉动（零到最大）循环，惰轮两侧齿面都参与啮合，为对称循环，因此要降额使用。
:::

刘易斯公式提出于1892年，它的悬臂梁模型至今仍是AGMA和ISO弯曲强度计算的核心。它忽略了哪些因素值得列出，因为每一项后来都成了现代计算方法中的一个修正系数：

| 忽略的因素 | 后果 | 规范中的系数 | 典型值 |
|---|---|---|---|
| 齿根过渡圆角的应力集中 | 实际齿根应力高30-50% | 计入$J$（AGMA）或$Y_S$（ISO） | 1.2-1.5 |
| 截面上的剪切和压缩 | 百分之几 | 计入几何系数 | — |
| 两对齿分担载荷 | $m_p > 1$时载荷降低 | 计入$J$ / $Y_\varepsilon$ | — |
| 齿形误差与动态超调 | 载荷随速度增大 | $K_v$ | 1.05-1.6 |
| 不对中与轴的变形 | 载荷集中到齿宽一端 | $K_m$（AGMA），$K_{H\beta}$（ISO） | 1.05-1.4 |
| 齿对之间的齿距与齿廓误差 | 各齿对载荷分配不均 | $K_{H\alpha}$（ISO） | 1.0-1.25 |
| 工况与起动峰值 | 真实峰值，而非平均值 | $K_o$（AGMA），$K_A$（ISO） | 1.0-2.0 |

::: example 55 kW工业小齿轮的弯曲应力 {#ex-bend}
一台$55\ \mathrm{kW}$、$730\ \mathrm{rev / min}$的鼓风机减速器，用模数$6$、压力角$20^{\circ}$、未变位的$18 / 94$齿轮副，传动比$i = 94 / 18 = 5.22$，材料为调质42CrMo4，硬度$300\ \mathrm{HB}$，滚齿达到AGMA 8级精度。大齿轮齿宽$b = 70\ \mathrm{mm}$起控制作用（小齿轮为$75\ \mathrm{mm}$）。取使用系数$K_A = 1.25$，动载系数$K_v$按下一节所列AGMA公式取值，齿根过渡圆角系数$K_F = 1.4$，标准力臂$a = 1.2 \, m$，把轮齿看作厚度为$s_b$（基圆齿厚）的悬臂梁，全部载荷由一对齿承担，许用齿根应力$430\ \mathrm{MPa}$。

**答案。**小齿轮齿根处$\sigma_F = 166\ \mathrm{MPa}$：$S_F = 2.6$。

::: solution
$$
T_1 = \frac{ 55\,000 }{ 730 \times 2 \pi / 60 } = 719.5\ \mathrm{N \cdot m} , \qquad d_1 = 6 \times 18 = 108\ \mathrm{mm} , \qquad W_t = \frac{ 2 \times 719.5 }{ 0.108 } = 13\,323\ \mathrm{N}
$$

节线速度为$V = \pi \times 0.108 \times 730 / 60 = 4.13\ \mathrm{m/s}$，按AGMA公式，8级精度时$K_v = 1.24$。危险截面厚度用[[#ex-geometry]]的基圆齿厚公式计算，其中$r_b = 54 \cos 20^{\circ} = 50.74\ \mathrm{mm}$：

$$
s_b = 2 r_b \! \left[ \frac{ \pi m }{ 2 d} + \operatorname{inv} \phi \right] = 2 \times 50.74 \times \left[ \frac{ \pi }{ 36 } + 0.014904 \right] = 10.37\ \mathrm{mm} = 1.728 \, m
$$

取$a = 1.2 \, m = 7.2\ \mathrm{mm}$，

$$
\sigma_F = K_A K_v K_F \frac{ 6 W_t a }{ b \, s_b^{2} } = 1.25 \times 1.24 \times 1.4 \times \frac{ 6 \times 13\,323 \times 7.2 }{ 70 \times 10.37^{2} } = 2.170 \times 76.5 = \boxed{ 166\ \mathrm{MPa} }
$$

所以$S_F = 430 / 166 = 2.6$。**这个数字平淡无奇，而这正是要点。**由于$\sigma_F \propto 1 / b$，**仅按弯曲达到许用应力所需的齿宽为$70 \times 166 / 430 = 27\ \mathrm{mm}$。**齿轮之所以有$70\ \mathrm{mm}$的齿宽，是因为别的原因，那就是下一节的内容。

**合理性检查。**名义弯曲应力$W_t / ( b m ) = 13\,323 / ( 70 \times 6 ) = 31.7\ \mathrm{MPa}$，而$76.5 / 31.7 = 2.4$对应于基圆截面上的等效齿形系数$Y = 0.41$——与18齿的刘易斯齿形系数表值（约$0.31$）同一量级；它偏大，是因为基圆截面比齿根过渡曲线上更高处的真实危险截面更厚。
:::
:::

## 齿面耐久性：为什么齿宽真正要70 mm

::: definition 点蚀与接触安全系数 {#def-pitting}
两个齿面是线接触的两个曲面体，节点处的赫兹接触压力同样服从结束[[mechanisms/cams]]的那个公式$p_0 = \sqrt{ F E^{*} / ( \pi b R ) }$。两条渐开线在节点处的曲率半径就是节点到各自基圆切点的距离，即$r_1 \sin \phi$和$r_2 \sin \phi$，所以

$$
\frac{1}{R} = \frac{1}{r_1 \sin \phi} + \frac{1}{r_2 \sin \phi} \qquad \Rightarrow \qquad p_0 = \sqrt{ \frac{ W_n E^{*} }{ \pi b R } } \ , \qquad E^{*} = \frac{ E }{ 2 \left( 1 - \nu^{2} \right) } = 113.7\ \mathrm{GPa}\ \text{（钢对钢）}
$$

其中$W_n = W_t / \cos \phi$为法向齿面载荷。（许多教材用$W_t$写出结果，并把$\cos \phi$并入几何系数；本课为便于与额定值表比较而使用$W_t$，结果约偏低3%——见下文的合理性检查。）

**与凸轮不同，$R$不是常数。**它等于$\rho_1 \rho_2 / ( \rho_1 + \rho_2 )$，$\rho_i$为各*齿面*在接触点处的曲率半径；接触点沿小齿轮齿面向下、向基圆移动时，$\rho_1$减小。最不利的位置通常是小齿轮上的单齿啮合区下界点，那里的接触应力比节点处高10-20%。
:::

::: example 同一个小齿轮的点蚀校核 {#ex-pit}
对[[#ex-bend]]中的齿轮副，用相同的$K_A$和$K_v$求节点处的赫兹接触压力，并与调质钢的AGMA 1级许用接触应力$\sigma_{H,\lim} = 2.22\,\mathrm{HB} + 200 = 866\ \mathrm{MPa}$（$300\ \mathrm{HB}$时）比较。

**答案。**$p_0 = 830\ \mathrm{MPa}$，$S_H = 1.04$。

::: solution
$$
r_1 = 54 , \quad r_2 = 282\ \mathrm{mm} \qquad \Rightarrow \qquad \frac{1}{R} = \frac{1}{ 54 \times 0.34202 } + \frac{1}{ 282 \times 0.34202 } = 0.05414 + 0.01037 = 0.06451\ \mathrm{mm^{-1}}
$$

$$
R = 15.50\ \mathrm{mm} \qquad p_0 = \sqrt{ \frac{ 1.25 \times 1.24 \times 13\,323 \times 113\,700 }{ \pi \times 70 \times 15.50 } } = \boxed{ 830\ \mathrm{MPa} }
$$

与$866\ \mathrm{MPa}$相比——**接触安全系数为$1.04$，若计入单齿啮合区下界点处10-20%的应力升高，则低于1。**这个设计受点蚀控制：$70\ \mathrm{mm}$接近*最小*齿宽，而不是宽裕的齿宽。

**把两个数字放在一起看。**由于$p_0 \propto 1 / \sqrt{b}$，点蚀恰好达到许用值的齿宽为$70 \times ( 830 / 866 )^{2} = 64\ \mathrm{mm}$，而弯曲只需$27\ \mathrm{mm}$。**这个齿轮比单按弯曲所需宽约2.4倍，纯粹是为了让齿面活下来。**由此得到一条值得记住的经验规则：**调质钢齿轮通常由点蚀控制；渗碳淬火并磨齿的齿轮许用接触应力高得多，齿轮缩小到弯曲重新成为与之竞争的限制。**

**合理性检查。**用法向载荷$W_n = W_t / \cos 20^{\circ}$代替$W_t$，$p_0$增大$\sqrt{ 1 / 0.9397 } = 1.032$倍，为$856\ \mathrm{MPa}$——结论相同，余量更小。
:::
:::

::: exercise 由点蚀确定齿宽 {level=1 check="21"}
同一$18 / 94$模数6齿轮副改用渗碳淬火并磨齿的$20\mathrm{MnCr5}$制造，$\sigma_{H,\lim} = 1\,500\ \mathrm{MPa}$，许用齿根应力$850\ \mathrm{MPa}$，其他系数不变。按$S_H = 1$，**点蚀**校核要求多大齿宽（单位毫米，取整到毫米）？再按该齿宽校核弯曲。

::: solution
$p_0 \propto 1 / \sqrt{b}$，且$b = 70\ \mathrm{mm}$时$p_0 = 830\ \mathrm{MPa}$，所以

$$
b = 70 \times \left( \frac{ 830 }{ 1\,500 } \right)^{2} = 70 \times 0.3062 = 21.4\ \mathrm{mm} \ \Rightarrow \ \boxed{ 21\ \mathrm{mm} }
$$

**齿宽减少70%**，但要与渗碳和磨齿高得多的成本相权衡。在$b = 21.4$时校核弯曲：$\sigma_F = 166 \times 70 / 21.4 = 542\ \mathrm{MPa}$，对比$850$，$S_F = 1.57$——**在调质方案中余量为2.6的弯曲，一旦点蚀取合理余量，就成了两个限制中更接近的那个。**这是渗碳淬火齿轮的典型特征：齿面许用应力的提高远大于齿根许用应力的提高，于是齿轮缩小，直到弯曲重新与之竞争。（实际上，齿宽相对直径这么小时，还会促使设计者改用更小的模数和更多的齿。）
:::
:::

::: warning 点蚀到底是什么
点蚀不是“表面磨损掉了”。在无摩擦的赫兹线接触中，最大**切应力**不在表面，而在表面以下约$0.78 \, b_h$处（$b_h$为接触半宽），滚动接触疲劳裂纹可以从那里萌生。在齿轮上，情况因滑动而更复杂：滑动在节线处为零，并在节线两侧反向。在主动小齿轮的齿根部分（节线以下），摩擦力倾向于使表面裂纹张开，随后到来的接触把润滑油封闭在裂纹中并使之增压——这是Way在1930年代首先提出的油压楔入机理。观察到的结果是，**点蚀通常始于小齿轮齿面节线稍下方**；当裂纹在约$1\ \mathrm{GPa}$量级（约一万个大气压）的接触应力驱动下折回表面并使一片材料脱落时，就形成了一个蚀坑。

三条实用推论。**润滑油黏度有帮助：**更厚的弹流油膜能更好地隔开表面微凸体，这就是为什么开始点蚀的齿轮往往在需要加大尺寸之前，先靠提高黏度等级就能改善。**更硬的表面有帮助**，规范中的许用接触应力大致随表面硬度线性增加。**新跑合齿轮上少量的初期点蚀可能是非扩展性的**：一旦高点被去除、齿面相互贴合，它就停止发展。规范中的许用接触应力对应于规定的寿命和可靠度，而不是“无损伤”的门槛。
:::

## 动力学：啮合是一根刚度不断变化的弹簧

两对啮合齿是两根并联的弹簧，接触点沿啮合线移动时，同时接触的齿对数在$\lfloor m_p \rfloor$与$\lceil m_p \rceil$之间交替。**因此啮合刚度以啮合频率波动。**钢制直齿轮的平均啮合刚度约为每毫米齿宽$20\ \mathrm{N / ( mm \cdot \mu m )}$，所以上面$70\ \mathrm{mm}$齿宽的齿轮啮合刚度约为$1.4 \times 10^{9}\ \mathrm{N / m}$，在名义载荷下变形约$13\,323 / 1.4 \times 10^{9} = 9.5\ \mu\mathrm{m}$。

这个数字之所以重要，是因为**它与制造误差同一量级。**AGMA 8级齿轮的齿距和齿廓误差在$10\ \mu\mathrm{m}$量级；高精度磨齿齿轮只有几微米。当误差与弹性变形相当时，进入啮合的齿对必须先被压变形到位才能分担载荷，啮合周期内的载荷历程主要由误差而非几何决定。这就是动载系数$K_v$的物理内容。AGMA 2001的公式（SI单位，$V$以m/s计，精度等级$Q_v$为6到11）为

$$
K_v = \left( \frac{ A + \sqrt{ 200 V } }{ A } \right)^{B} , \qquad B = 0.25 \left( 12 - Q_v \right)^{2/3} , \qquad A = 50 + 56 \left( 1 - B \right)
$$

适用于$V_{\max} = [ A + ( Q_v - 3 ) ]^{2} / 200$以下。计算结果：

| AGMA精度等级$Q_v$ | $V = 4\ \mathrm{m/s}$ | $V = 10$ | $V = 20$ | $V = 30$ |
|---|---|---|---|---|
| 6 | 1.38 | 1.59 | — | — |
| 8 | 1.24 | 1.36 | 1.50 | — |
| 10 | 1.12 | 1.19 | 1.25 | 1.30 |
| 11 | 1.07 | 1.10 | 1.14 | 1.16 |

短横线表示速度超出该精度等级的$V_{\max}$（$Q_v = 6$时为$19.7\ \mathrm{m/s}$，$Q_v = 8$时为$28.7\ \mathrm{m/s}$）。表的形状就是要传达的信息：**精度换来的是速度。**在$4\ \mathrm{m/s}$时，6级与11级精度的轮齿载荷相差约29%；在$30\ \mathrm{m/s}$时，公式根本不允许使用较低的精度等级。

::: exercise 啮合频率与共振 {level=1 check="219"}
对上面$18$齿、$730\ \mathrm{rev / min}$的小齿轮，啮合频率是多少赫兹？若测得电动机—小齿轮系统的一阶扭转模态为$110\ \mathrm{Hz}$，设计是否可以接受？

::: solution
$$
f_{\text{mesh}} = \frac{ N_1 n }{ 60 } = \frac{ 18 \times 730 }{ 60 } = \boxed{ 219\ \mathrm{Hz} }
$$

啮合频率与固有频率之比为$219 / 110 = 2.0$，远在通常$\pm 20$–$30\%$的避让带之外，所以**在工作转速下，该模态不会被啮合基频激起**：系统在共振之上运行，对啮合激励的响应是减小的。还有两点需要检查。第一，起动过程中啮合频率会经过$110\ \mathrm{Hz}$，对应$n = 110 \times 60 / 18 = 367\ \mathrm{rev / min}$；电动机一两秒内加速通过时无害，但变速驱动不得在此转速附近停留。第二，其他激励阶次——轴频$730 / 60 = 12.2\ \mathrm{Hz}$及由跳动和偏心引起的谐波——也应避开$110\ \mathrm{Hz}$（第9阶轴频$109.5\ \mathrm{Hz}$很接近，但高阶轴频通常很弱）。设计可以接受。
:::

$55\ \mathrm{kW}$减速器在$\eta = 0.985$时的损耗为

$$

$$

**再与蜗杆比较。**同样的$55\ \mathrm{kW}$通过导程角$5^{\circ}$、$\eta = 0.63$的蜗杆传动，损耗为$55 \times 0.37 = 20\ \mathrm{kW}$——**超过输入功率的三分之一，约为斜齿轮箱损耗的25倍。**这就是为什么蜗杆传动用于低负载率或小功率场合，为什么连续工作时要大幅降额，为什么它先需要冷却器而后才需要更强的齿轮，以及为什么蜗杆减速器的设计问题从来不是“会不会断”而是“会不会烧”。

## 斜齿轮：同一条渐开线，沿齿宽扭转

::: definition 斜齿轮几何 {#def-helical}
斜齿轮是齿线在圆柱面上为螺旋线（**螺旋角**$\psi$）的直齿轮。它与直齿轮用同一把齿条刀具加工，但刀具在垂直于轮齿的**法面**内工作，所以标准模数和压力角是法面参数，而齿轮的渐开线位于**端面**内，基圆直径为$d \cos \phi_t$。用下标$n$表示法面（垂直于轮齿），$t$表示端面，

$$
m_n = m_t \cos \psi \qquad \tan \phi_t = \frac{ \tan \phi_n }{ \cos \psi } \qquad d = \frac{ m_n N }{ \cos \psi }
$$

在几何和强度两方面，该齿轮都相当于一个齿数为

$$
\boxed{ \; N_v = \frac{ N }{ \cos^{3} \psi } \; }
$$

的**当量**直齿轮。三次方来自椭圆：垂直于轮齿的平面截分度圆柱得到一个椭圆，它在轮齿处的曲率半径为$d / ( 2 \cos^{2} \psi )$，所以当量分度圆直径为$d / \cos^{2} \psi$，再除以$m_n$并代入$d = m_n N / \cos \psi$，就得到第三个余弦。
:::

三个推论，按它们改变设计的程度排列。

**1. 重合度增加了第二个独立的项。**由于轮齿沿一条斜线逐渐进入接触，而不是沿整个齿宽突然进入，**轴向重合度**叠加到端面重合度上，

$$
m_F = \frac{ b \sin \psi }{ \pi m_n } \qquad m_{\text{total}} = m_p + m_F
$$

而且与$m_p$不同，它**没有上限**——齿宽和螺旋角允许多少就能得到多少。标准齿制的直齿轮达不到2（$20^{\circ}$时齿条与齿条的极限为1.98，实际齿轮副为1.4–1.8）；把$18 / 94$模数6齿轮副做成斜齿轮，$\psi = 20^{\circ}$、$b = 70\ \mathrm{mm}$时，$m_F = 70 \sin 20^{\circ} / ( 6 \pi ) = 1.27$，端面重合度1.55，总重合度2.82。**这就是斜齿轮在几乎所有要求低噪声的场合取代直齿轮的主要原因。**

**2. 根切限制放宽。**由于齿轮相当于$N_v$个齿，最少齿数近似变为$N_{\min} = 17.1 \cos^{3} \psi$；端面内精确的齿条条件为$N_{\min} = 2 \cos \psi / \sin^{2} \phi_t$。$\psi = 20^{\circ}$时两者都给出15齿（14.2和14.4），$25^{\circ}$时为13到14齿（12.7和13.1）。**斜齿小齿轮在发生根切之前可以比直齿轮少几个齿**，而在由小齿轮直径决定中心距的齿轮箱里，几个齿很重要。

**3. 产生了轴向力。**齿线是倾斜的，所以法向力有一个沿轴线的分量：

$$
F_a = W_t \tan \psi
$$

对55 kW小齿轮，$\psi = 20^{\circ}$时为$13\,323 \times 0.364 = 4\,850\ \mathrm{N}$的轴向载荷，作用在原本不承受轴向力的轴上——需要推力轴承、轴肩、隔套和一组调整垫片。**这是要交的“税”，避免它只有两种办法：把螺旋角取为零，那就是直齿轮；或者在同一轮坯上加工两个旋向相反的半边，那就是双斜齿轮（人字齿轮）**，它在内部抵消轴向力。双斜齿轮通常在中间留有退刀槽，以便滚刀退出；没有退刀槽的真正人字齿轮需要专用插齿机。双斜齿轮是大型汽轮机和船用减速齿轮的标准形式，在那里单斜齿的轴向力需要非常大的推力轴承。

## 锥齿轮、蜗杆、内齿轮与行星齿轮，各一段

**直齿锥齿轮**是圆锥上的渐开线齿，全部设计都在**大端背锥**上进行，因为轮齿在锥顶处缩小为零。当量齿数为$N_v = N / \cos \delta$，$\delta$为分锥角（Tredgold背锥近似），所以一对1:1的20齿锥齿轮相当于一对$28 / 28$的直齿轮。它的弱点是任何安装距误差都会使接触斑点移动，这就是为什么锥齿轮副要用调整垫片装到规定的安装距并用接触斑点试验检查，也是为什么不检查接触斑点就重新调整垫片的差速器会啸叫。

**弧齿锥齿轮**增加了螺旋角，使总重合度超过2，安静和强度足以用于汽车车桥和直升机传动。后桥的**准双曲面齿轮**更进一步：小齿轮轴线偏置在大齿轮轴线下方，可以采用更大、更强的小齿轮并降低传动轴位置，代价是沿齿长方向的滑动，需要极压（EP）齿轮油，并损失百分之几的功率。

**蜗杆传动**是一个螺杆驱动蜗轮的一段弧，它的全部特性都来自两者之间的滑动速度，接触处的相对运动全部是滑动；正因如此，蜗轮通常用青铜，与淬硬的钢蜗杆配对，蜗杆传动受效率和发热的限制。它真正的优点是单级传动比可达约60:1甚至更高、运转安静、直角布置紧凑。它的代价是：在大传动比、小导程角时，损失三分之一到一半以上的功率。

**内齿轮**——在齿圈内啮合的齿轮——其内接触赫兹公式中两个曲率是*相减*而不是相加，综合曲率半径大得多，因此同样尺寸下接触应力更低。它有自己的附加干涉限制（小齿轮与内齿圈的齿数不能太接近，否则齿顶会相碰），而且不能滚齿，只能插齿、拉削或强力刮齿，因而价格较高。凡是外廓尺寸受限的地方都用它：行星齿轮箱（包括自动变速器中的行星排）以及轮毂驱动。

**行星齿轮**把转矩分配到$n$个行星轮啮合上，这是做出体积小、重量轻而能传递大转矩的齿轮箱的经典方法。代价是一个行星架、$n$个行星轮轴承，以及要求$n$个行星轮分担载荷——由于制造误差，它们并不能精确均载，除非让某个构件（通常是太阳轮）径向浮动，或者结构有足够的柔性来均衡载荷。设计规范用均载系数（啮合载荷系数）来考虑这一点：带浮动构件的三行星轮系几乎均匀分载，行星轮更多时则需要在名义行星轮载荷上乘以约1.2–1.4的系数，所以一个五行星轮的级相当于近四个均匀受载的行星轮，而不是五个。细节见[[mechanisms/gear-trains]]。

## 制造、精度等级与侧隙

较早的AGMA 2000体系中，AGMA精度等级大约从3到15（数字越大越精确；较新的AGMA 2015和ISO 1328等级方向相反），它规定的是齿距、齿廓和螺旋线的公差，而不是含糊的“优良程度”。参考值如下：

| 精度等级 | 典型工艺 | 齿距误差（量级） | 典型用途 |
|---|---|---|---|
| 4-6 | 铸造、铣齿 | 数十$\mu$m | 开式齿轮、矿山大齿圈 |
| 7-8 | 滚齿、插齿 | 10-30 $\mu$m | 工业减速器、农机 |
| 9-10 | 滚齿后剃齿 | 5-15 $\mu$m | 汽车变速器 |
| 11-12 | 磨齿 | 3-8 $\mu$m | 航空、机床、风电 |
| 13-14 | 精密磨齿 | 1-3 $\mu$m | 精密仪器与主轴 |

**工艺路线就是设计。**渗碳齿轮热处理变形超过其公差，所以高精度的渗碳淬火齿轮必须在淬火后磨齿（或珩齿）；而剃齿则在淬火之前进行。滚齿的调质齿轮可以直接装进齿轮箱。

**侧隙**是两齿面之间的间隙：固定大齿轮时小齿轮能转过的弧长，或分度圆上的齿厚减薄量。它不是误差，而是规定的量，用于补偿热膨胀、容纳油膜和吸收中心距公差的累积。工业齿轮的典型最小侧隙约为$0.03$–$0.1 \, m$，仪表齿轮更小；它通常由**齿厚**——把轮齿加工得比名义值稍薄——来保证，而不是靠加大中心距，原因已在[[#ex-centre]]中列表说明。

::: example 侧隙靠齿厚，不靠中心距 {#ex-backlash}
[[#ex-centre]]中的$20 / 40$模数3齿轮副需要分度圆上$0.20\ \mathrm{mm}$的圆周侧隙。比较用减薄轮齿和用加大中心距两种办法得到它。

**答案。**靠齿厚：每个轮齿减薄$0.10\ \mathrm{mm}$，中心距不变，重合度保持$1.635$。靠中心距：$m_p$降到$1.545$。

::: solution
靠中心距时，$\Delta C \approx j / ( 2 \tan \phi ) = 0.20 / 0.728 = 0.275\ \mathrm{mm}$，在$C' = 90.275\ \mathrm{mm}$处重复[[#ex-centre]]的计算，得

$$
\phi_{\mathrm{op}} = \arccos \frac{ 90 \cos 20^{\circ} }{ 90.275 } = 20.47^{\circ}, \qquad m_p = 1.545 \quad \text{对比} \ 1.635
$$

**重合度损失5.5%，换来的侧隙若用齿厚来获得几乎不花代价。**只有当中心距由其他因素决定时——例如为给定中心距设计的变位齿轮副——用中心距获得侧隙才可以接受，即便如此，也是通过选择变位系数和齿厚公差，使该中心距下得到所需的侧隙。
:::
:::

## 选用齿轮：一棵没人印出来的决策树

::: example 选定传动级 {#ex-select}
为下列各项指定齿轮类型并说明理由。

**(a)** 水泥厂中一台$7.5\ \mathrm{kW}$、$1450\ \mathrm{rev / min}$降到$48\ \mathrm{rev / min}$的输送机传动，连续工作，预算有限。
**(b)** 一个$250\ \mathrm{W}$的机器人腕关节，要求$180 : 1$，空程小于$0.05^{\circ}$。
**(c)** 一台$2\ \mathrm{MW}$风力机主传动，从$14$升到$1500\ \mathrm{rev / min}$，设计为20年不开箱。
**(d)** 一台$0.75\ \mathrm{kW}$的输送机，断电时必须停住并保持在$15^{\circ}$的斜坡上。

**答案。**

::: solution
**(a)** $i = 1450 / 48 = 30.2$，两级各约$5.5$。取整数齿数，$( 90 / 17 ) \times ( 97 / 17 ) = 5.29 \times 5.71 = 30.21$，输出$1450 / 30.21 = 48.0\ \mathrm{rev / min}$。对平行轴输送机：**两级斜齿轮，调质，滚齿约8级精度，飞溅润滑，$\eta \approx 0.985^{2} = 0.97$**（若输出必须成直角，则用一级斜齿轮加一级锥齿轮）。7.5 kW不值得采用渗碳淬火；这个齿轮箱受箱体限制，而不受齿轮限制。

**(b)** $0.05^{\circ}$即输出端$3$角分（$0.87\ \mathrm{mrad}$）。$180 : 1$的渐开线轮系需要三级，每一级的侧隙折算到输出端后相加；用这种方式达到3角分，需要消隙（剖分、弹簧加载）齿轮或非常严格而昂贵的公差。**通常的答案是谐波（波动）传动或摆线针轮（RV型）减速器**，它们用一到两级紧凑的传动获得大传动比，同时啮合的齿数多，侧隙小或为零。摆线减速器提醒我们：在传动比固定、多齿同时接触比用直边刀具展成更重要的场合，非渐开线齿廓仍然是正确的选择。

**(c)** $i = 107$。单级做不到。**这个尺寸的常见布置是一级$i \approx 5$的行星级加两级各$i \approx 4.6$的斜齿轮级**（$5 \times 4.6 \times 4.6 = 106$），由行星级承担巨大的低速转矩，在那里把转矩分配到几个行星轮上最能节省尺寸。20年不开箱意味着：渗碳淬火并磨齿的齿轮（18CrNiMo7-6是典型钢种）、充裕的接触和弯曲安全系数、精细的油过滤，以及——常被忽视的一点——每对啮合都采用**没有公因数的“追齿”齿数**，使每个小齿轮齿依次与每个大齿轮齿相遇（$N_1 N_2$次轮齿啮合后同一对齿才重复），局部缺陷不会总是碰到同一个对手。

**(d)** $0.75\ \mathrm{kW}$，在斜坡上保持。**导程角接近或小于摩擦角的蜗杆传动**是传统选择：在这个功率下效率低的代价不大；载荷静止时没有滑动，保持不消耗功率，而静摩擦角（高于运转时的摩擦角）对它有利。**但自锁不能代替制动器**，因为蜗杆的摩擦取决于温度、润滑和振动，试验中能保持的传动在使用中可能蠕动。答案是蜗杆减速器*加上*弹簧加载的电动机制动器，自锁只当作额外的保障。
:::
:::

::: exercise 变位后的最少齿数 {level=1 check="11"}
一个$20^{\circ}$小齿轮用标准齿条刀具展成。变位系数$x = + 0.4$时，不发生根切的最少齿数是多少？

::: solution
起切削作用的是齿条的齿顶，把齿条从齿轮中心移开$x m$，展成的齿根也同样向外移动，于是干涉条件变为

$$
N_{\min} = \frac{ 2 \left( 1 - x \right)}{\sin^{2} \phi} = \frac{ 2 \times 0.6 }{ 0.11698 } = 10.26 \ \Rightarrow \ \boxed{ 11 }
$$

**比未变位的17齿少六个齿，代价有三方面。**齿顶变窄——$x = + 0.4$、齿顶高为$( 1 + x ) m$的12齿小齿轮，齿顶厚只有$0.36 \, m$，接近通常的最小值；配对齿轮必须变位$- 0.4$，否则中心距要改变；这对齿轮也不再能用目录上的标准齿轮替换。**这就是为什么变位齿轮的图纸要标注变位系数，以及公法线长度（跨$k$齿测量）或量柱距等齿厚检验尺寸，而不只是分度圆直径。**
:::
:::

::: exercise 干涉极限处的重合度 {level=2 check="1.44"}
计算标准齿制、未变位的$13 / 13$齿$20^{\circ}$齿轮副的端面重合度，保留两位小数。这个结果是否宽裕？

::: solution
取单位模数，$r_1 = r_2 = 6.5$、$r_a = 7.5$、$r_b = 6.108$、$C = 13$：

$$
L = 2 \sqrt{ 7.5^{2} - 6.108^{2} } - 13 \times 0.34202 = 2 \times 4.352 - 4.446 = 4.258\ \mathrm{mm}
$$

$$
p_b = \pi \cos 20^{\circ} = 2.952\ \mathrm{mm} \qquad \Rightarrow \qquad m_p = \frac{ 4.258 }{ 2.952 } = \boxed{ 1.44 }
$$

**对比[[#ex-crr]]中$20 / 40$齿轮副的1.635。**它可以接受（高于通常的最小值1.2），但并不宽裕：该齿轮副在每个啮合周期中有56%的时间处于单齿啮合，而不是36%，所以轮齿承受全部载荷的时间更长，啮合刚度变化更大，噪声也更大。正变位是小齿轮防根切的常用办法，但它往往使实际啮合线进一步缩短。只要外廓尺寸允许，用更小的模数、更多的齿，往往比用极少的齿数与几何较劲更划算。
:::
:::

::: exercise 斜齿小齿轮的当量齿数 {level=1 check="15"}
要求一个斜齿小齿轮在螺旋角$20^{\circ}$下与$\phi_n = 20^{\circ}$的齿条啮合且不变位。不发生根切的最少齿数是多少？

::: solution
斜齿轮相当于齿数为$N_v = N / \cos^{3} \psi$的直齿轮，所以当$N_v \ge 17.1$时不发生根切：

$$
N \ \ge \ 17.1 \cos^{3} 20^{\circ} = 17.1 \times 0.8298 = 14.19 \ \Rightarrow \ \boxed{ 15 }
$$

端面内的精确条件$N \ge 2 \cos \psi / \sin^{2} \phi_t$，其中$\phi_t = \arctan ( \tan 20^{\circ} / \cos 20^{\circ} ) = 21.17^{\circ}$，给出$14.4$，答案相同。**比直齿轮的18齿少三个齿。**原因是斜齿轮在端面内的压力角更大，分度圆离渐开线终止的基圆更远。更大的螺旋角和$25^{\circ}$的法向压力角会使限制进一步放宽：$\psi = 30^{\circ}$、$\phi_n = 25^{\circ}$时精确极限为$7.7$，即8齿——但轴向力随之按$\tan 30^{\circ}$增大。
:::
:::

::: exercise 蜗杆效率与自锁界限 {level=1 check="0.77"}
一个蜗杆传动的导程角为$12^{\circ}$，工作温度下摩擦系数为$0.06$。它的正向效率是多少（用小数表示）？冷态$\mu = 0.12$时它是否自锁？

::: solution
$$
\phi = \arctan 0.06 = 3.43^{\circ} \qquad \eta = \frac{ \tan 12^{\circ} }{ \tan \left( 12 + 3.43 \right)^{\circ} } = \frac{ 0.2126 }{ 0.2762 } = \boxed{ 0.77 }
$$

冷态时$\phi = \arctan 0.12 = 6.84^{\circ}$，$\eta = \tan 12^{\circ} / \tan 18.84^{\circ} = 0.62$。当$\lambda < \phi$时蜗杆传动自锁（不能反向驱动）；这里$12^{\circ}$既大于$3.43^{\circ}$也大于$6.84^{\circ}$，所以**无论热态还是冷态都不自锁。**注意这种权衡的方向：设计成热态自锁的蜗杆（$\lambda < 3.4^{\circ}$）运转效率低于50%；而$\lambda$刚好高于冷态摩擦角（$\approx 6.9^{\circ}$）的蜗杆，热态效率也只有$\eta \approx 0.66$。无论导程角多大，都不应把蜗杆当作保持载荷的唯一手段。
:::
:::

::: exercise 锥齿轮的当量齿数 {level=1 check="28"}
一对1:1直齿锥齿轮各有20齿，压力角$20^{\circ}$。背锥上的当量直齿轮有多少齿（取整到整齿）？这对选择成形铣刀意味着什么？

::: solution
对1:1齿轮副，分锥角$\delta = 45^{\circ}$，当量齿数为

$$
N_v = \frac{ N }{ \cos \delta } = \frac{ 20 }{ 0.7071 } = 28.3 \ \Rightarrow \ \boxed{ 28 }
$$

**远高于17齿的干涉极限**——背锥半径是分度圆半径的$\sqrt{2}$倍，所以轮齿的表现如同在一个更大的齿轮上。当量齿数也决定了用盘形铣刀粗切锥齿轮时选哪把成形铣刀：在标准的八把一套渐开线成形铣刀中（1号用于135齿至齿条，直到8号用于12–13齿），28齿的当量齿轮落在**4号铣刀（26–34齿）**的范围内。之所以需要成套铣刀，是因为成形铣刀只能精确复制一种齿槽，而渐开线的形状随齿数变化；展成法让齿轮相对直边刀具滚动，从根本上避免了这个问题。
:::
:::

::: quiz
两个齿轮模数、齿宽、材料和热处理都相同，承受相同载荷。A齿轮有17齿，B齿轮有60齿，各自与一个相同的60齿大齿轮啮合。下列哪个说法正确？

- [ ] A齿轮弯曲强度较低，因为它的轮齿曲率更大
- [x] A齿轮接触应力更高、重合度更低，并且更接近干涉极限——为同样的直径节省付出三重代价
- [ ] B齿轮更安静仅仅因为它更大
- [ ] 两者应力相同，因为模数相同

::: solution
三重代价都落在A上。接触应力与$1 / \sqrt{ R }$成正比，而$1 / R = 1 / ( r_1 \sin \phi ) + 1 / ( r_2 \sin \phi )$，所以小齿轮的$R$更小、$p_0$更高——在相同圆周力下，$17 / 60$与$60 / 60$相比高$\sqrt{ ( 1/17 + 1/60 ) / ( 2/60 ) } = 1.50$倍。重合度为1.65对1.78。而且17齿与该传动比的干涉极限（15.3，即16齿）只差两齿以内，60齿则远离它。**尽管如此小齿轮仍被采用，是因为机器中其他一切都随中心距缩放：箱体、轴、轴承和质量。齿轮设计在很大程度上就是在这一取舍中权衡。**
:::
:::

::: quiz
一台齿轮箱装配后中心距比名义值大$0.15\ \mathrm{mm}$，测得的侧隙在规定范围内。这台齿轮箱应该验收吗？

- [ ] 应该——侧隙是规定的验收指标，且已满足
- [x] 不应该，至少在检查接触斑点之前不应该，因为侧隙可能是用中心距换来的，代价是重合度
- [ ] 应该，只要油位正确
- [ ] 不应该——任何正的中心距误差都要判废，无论侧隙如何

::: solution
对[[#ex-centre]]中的$20 / 40$模数3齿轮副，$\Delta C = + 0.15\ \mathrm{mm}$产生约$j \approx 0.11\ \mathrm{mm}$的侧隙，$m_p = 1.586$（对比1.635）——**侧隙合格，但它可能部分来自中心距而不是齿厚，伴随着3%的重合度损失和$0.26^{\circ}$的啮合角增大。**更好的验收依据是**接触斑点**（涂色检验显示接触印痕在齿面上位置合适，没有挤向一端或齿顶）以及对零件直接测量齿厚（公法线长度或量柱距）。**侧隙是症状，而不是性能：同样的测量侧隙，可能意味着正确加工的齿轮装在正确的中心距上，也可能意味着齿厚偏薄的齿轮装在错误的中心距上，只有接触斑点试验或直接测量齿厚才能区分。**

## 后续内容

齿轮是本课程两半内容交汇之处。[[mechanisms/position-analysis]]和[[mechanisms/velocity-analysis]]的**运动学**关心的是构件在哪里、动得多快；齿轮用一个整数——齿数比——取代三角函数求解，从构造上一劳永逸地回答了这个问题。[[mechanisms/acceleration-analysis]]和[[mechanisms/machine-dynamics]]的**动力学**关心的是运动学所隐含的力；齿轮在其设计寿命中最关心的正是其中一种力：赫兹接触压力。

认真对待这一点会引出三件事。**弹性流体动压润滑**解释了为什么[[#ex-pit]]中的$830\ \mathrm{MPa}$不会立即毁坏齿面：约一微米厚、在高压下几乎变成固体的油膜把两个齿面隔开；其背后的流体性质在[[fluid-mechanics/fluid-properties]]中介绍。**接触疲劳**解释了为什么同一表面在$10^{8}$–$10^{9}$次循环后才失效而不是立即失效，属于[[materials-science/failure]]的内容。**传动误差动力学**解释了齿轮噪声，在轿车车厢里它是与强度同样严格的设计约束，属于[[vibrations/harmonic-excitation]]的内容。

你最常被要求解释的失效，是计算认为足够的齿轮箱出现了齿面点蚀或剥落。很多时候是接触斑点移动了：轴、轴承和箱体在载荷下的变形超出设计假定，齿面修形（鼓形、螺旋线修正）不再与变形相匹配，接触挤向齿宽一端，局部压力远高于额定计算所用的平均值。**齿轮很少因为平均应力太高而失效。它们失效，是因为应力并不平均。**

::: summary
- **齿廓啮合基本定律**要求接触点的公法线通过一个固定的节点；渐开线让公法线成为与两基圆相切的固定直线来实现这一点。中心距改变时它仍保持恒定传动比，其直边齿条使展成刀具简单——这就是它成为标准的原因。
- 齿轮由模数$m$、齿数$N$和压力角$\phi$定义。**两个齿轮只有基圆齿距$\pi m \cos \phi$相等时才能正确啮合**——模数和压力角都必须相同。
- **与齿条啮合时最少齿数为$N_{\min} = 2 / \sin^{2} \phi$**：$14.5^{\circ}$时31.9，$20^{\circ}$时17.1，$25^{\circ}$时11.2。低于此值轮齿被根切。变位系数$x$把限制降到$2 ( 1 - x ) / \sin^{2} \phi$，代价是失去互换性和齿顶变窄。
- **重合度$m_p = L / p_b$**是同时接触的平均齿对数；实际直齿轮约为1.4-1.8，设计中不低于约1.2。低于1.0时，下一对齿要等上一对齿退出后才进入啮合。
- **加大中心距保持传动比不变，但损失重合度**：模数3的例子中每毫米约$0.33$，同时增加侧隙$\approx 2 \Delta C \tan \phi$。侧隙应靠齿厚而不是中心距获得。
- **弯曲为$\sigma_F = W_t / ( b m Y )$（再乘以各额定系数），点蚀为$p_0 = \sqrt{ W E^{*} / ( \pi b R ) }$**，钢对钢时$E^{*} = E / [ 2 ( 1 - \nu^{2} ) ]$。调质工业齿轮的点蚀所需齿宽通常是弯曲所需的两到三倍；渗碳淬火齿轮的弯曲重新成为竞争限制。
- **动载系数$K_v$既与速度有关，也同样与制造精度有关。**在$4\ \mathrm{m/s}$时AGMA公式给出6级精度1.38、11级精度1.07，而在高速时根本不允许使用低精度等级。
- **斜齿轮增加了随齿宽增长的轴向重合度$m_F = b \sin \psi / ( \pi m_n )$，使根切限制大致按$\cos^{3} \psi$放宽，并产生轴向力$W_t \tan \psi$**，这个力必须由轴承承受，或用双斜齿轮抵消。
:::

## 延伸阅读

- R. C. Juvinall and K. M. Marshek, *Fundamentals of Machine Component Design*, 6th ed., Wiley, 2017——清晰的刘易斯公式和AGMA弯曲与齿面耐久性算例
- R. G. Budynas and J. K. Nisbett, *Shigley's Mechanical Engineering Design*, 11th ed., McGraw-Hill, 2020——齿轮几何、干涉和AGMA额定公式（包括本课所用的$K_v$公式）的标准入门
- ANSI/AGMA 2001-D04 及其公制版 2101-D04, *Fundamental Rating Factors and Calculation Methods for Involute Spur and Helical Gear Teeth*——美国的齿轮承载能力标准；ISO 6336是相应的国际标准
- F. L. Litvin and A. Fuentes, *Gear Geometry and Applied Theory*, 2nd ed., Cambridge University Press, 2004——用微分几何处理啮合线和根切理论，包括锥齿轮和准双曲面齿轮几何
- W. Lewis, "Investigation of the strength of gear teeth", address to the Engineers' Club of Philadelphia, 15 October 1892——篇幅不长，至今仍值得一读，因为它的模型比规范透明
- B. J. Hamrock, S. R. Schmid and B. O. Jacobson, *Fundamentals of Fluid Film Lubrication*, 2nd ed., Marcel Dekker, 2004——齿轮和滚动接触中的弹流油膜厚度
- K. L. Johnson, *Contact Mechanics*, Cambridge University Press, 1985——赫兹理论、表层下应力场与滚动接触行为
