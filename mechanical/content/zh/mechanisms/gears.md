::: warning 齿轮是唯一双向强制封闭的传动
凸轮能推不能拉，而 [[mechanisms/cams]] 里的一切都是在争论把这一不对称逼到极限时会发生什么。齿轮没有这个问题：**它的齿在两个方向上都是形封闭的**，所以一对齿轮传递转矩时，穿过换向、穿过堵转、穿过振荡，不需要弹簧、不需要重力、不需要第二个机构把接触压住。这就是齿轮成为世界上使用最广的机器元件的全部理由，也是它的失效——不是凸轮断裂，而是一次点蚀剥落的齿面或一次剪断的齿根——同样能让一台机器完全停用的理由。

形封闭的代价是一串凸轮不必遵守的约束。**两个齿轮必须模数相同。**它们必须由同一把标准齿条刀切制。它们的中心距被"使它们纯滚动"的几何锁定在百分之几毫米之内，而搞错中心距不只是引入侧隙，它会摧毁重合度。而它们的齿数被干涉从下方封死，这就是为什么几乎每一台齿轮箱里最小的那个齿轮决定了模数。
:::

## 你已经知道的内容

- **纯滚动**——齿轮副的节圆就是相互滚动的两个圆，与 [[mechanisms/mechanisms-mobility]] 摩擦驱动讨论中的摩擦轮完全一样，区别在于轮齿使滚动成为精确的，而不依赖摩擦。
- **传动角与压力角**——[[mechanisms/cams]] 里凸轮的 $\tan \psi = s' / \left( r_p + s \right)$ 是齿轮压力角的一个特例，而齿轮的压力角是*恒定*的，凸轮的那个却在整个升程里游荡。
- **赫兹接触应力**——[[mechanisms/cams]] 里的 $p_0 = \sqrt{ F E^{*} / ( \pi b R ) }$ 支配齿轮点蚀，正如它支配凸轮磨损，只有一个关键区别：齿轮接触处的当量曲率半径 $R$ 在整个啮合过程中*连续变化*，并在啮合线的两端趋于零。
- **速度瞬心**——齿轮副的节点就是两个构件的瞬心，而 [[mechanisms/velocity-analysis]] 中的肯尼迪定理正是迫使它待在原地的东西。
- **等效惯量与转矩**——[[mechanisms/acceleration-analysis]] 中的 $T_{\mathrm{eq}} = T / \left( \eta i \right)$ 与 $J_{\mathrm{eq}} = J / i^{2}$，这就是为什么选齿轮箱既为它藏起来的惯量，也为它给出的转速。

## 齿廓啮合基本定律：为什么可行的曲线只有一族

::: definition 齿廓啮合基本定律 {#def-law}
两条齿廓是**共轭的**——它们传递恒定的角速度比——当且仅当**两齿面在每一接触点处的公法线都通过连心线上的一个定点**。这个定点就是**节点** $P$，过 $P$ 以两轴心为圆心的两个圆就是节圆。

等价地，记 $O_1 P = r_1$、$O_2 P = r_2$，$N_1$、$N_2$ 为两轴心到公法线的垂足，

$$
\frac{\omega_1}{\omega_2} = \frac{r_2}{r_1} = \frac{O_2 N_2}{O_1 N_1} \cos^{2} \theta_{\mathrm{press}} \quad \Rightarrow \quad \boxed{ \; O_1 N_1 \ \text{与} \ O_2 N_2 \ \text{被公法线截出，其比必须为常数} \; }
$$

而保证这一点的最简单办法，是让 $N_1$ 与 $N_2$ 成为*定点*——也就是说，让公法线成为**一条与两个固定圆相切的固定直线**。那两个圆就是基圆，而做到这一点的齿廓是渐开线。
:::

::: exercise 推导：为什么基圆必须相切 {#deriv-involute level=3}
::: solution
取一条公法线为固定直线 $\ell$，它与绕 $O_1$、半径 $r_{b1}$ 的圆相切，也与绕 $O_2$、半径 $r_{b2}$ 的圆相切。接触点可以是 $\ell$ 上任意一点，所以比值 $O_1 N_1 / O_2 N_2 = r_{b1} / r_{b2}$ 由构造保证为常数，齿廓啮合基本定律*在每一个接触点上同时*成立——这是任何曲线-法线族都做不到的。

现在问：构件2上取任意齿廓，构件1上与之相容的齿廓是什么。构件1在构件2上纯滚动时，接触点在构件1上描出一条沿基圆纯滚动的直线的切点轨迹。**把一根拉紧的细线从一个半径 $r_b$ 的圆上展开：线端描出渐开线**，而参数形式直接从作图法掉出来，其中 $t$ 为展开角，

$$
x = r_b \left( \cos t + t \sin t \right) , \qquad y = r_b \left( \sin t - t \cos t \right)
$$

于是参数 $t$ 处的半径与当地压力角为

$$
r = r_b \sqrt{ 1 + t^{2} } , \qquad \cos \phi = \frac{r_b}{r} = \frac{1}{\sqrt{ 1 + t^{2} } } , \qquad t = \tan \phi
$$

而**渐开线函数**——齿廓的角半宽作为压力角的函数——是

$$
\operatorname{inv} \phi = \tan \phi - \phi
$$

由此推出两个事实，二者在实践中都要紧。**圆的渐开线只依赖一个参数 $r_b$**——所以齿数为20的齿轮与基圆相同的齿数200的齿轮承载同一条曲线，这正是同一把刀能切一整段齿数范围的原因。**而渐开线只存在于它的基圆之外**，这是本课每一条极限的几何根源：最少齿数、根切，以及一个齿数太少的齿轮不只是弱、而是*几何上就是错的*。
:::
:::

f: 1/cos(x*pi/180); 1/cos(14.5*pi/180)
x: 0, 30
y: 1, 1.15

caption: 每一条渐开线都是同一条曲线按其基圆半径缩放。从基圆向外读，半径按 $1 / \cos \phi$ 增长，齿厚按每单位半径 $2 \operatorname{inv} \phi$ 变薄——正是这两个效应合力造出根切。直线是 $r / r_b$ 对工作压力角；水平线标出 $14.5^{\circ}$ 历史标准，它的渐开线在齿厚磨到零之前勉强到达 $r / r_b = 1.055$。

## 渐开线为何胜出，尽管有更漂亮的曲线

在渐开线于十九世纪中叶被标准化之前，人们试过三个曲线族，而它们各自落败的原因值得知道，因为每一个至今仍在某个地方使用。

**外摆线**——一个圆在另一个圆*外侧*滚动时圆上一点的轨迹——直到约1900年都是钟表与纺织机械的标准，至今仍在钟表轮系中使用。它的生成圆直径之比等于传动比，这意味着**一个外摆线小齿轮只能配一个齿轮**。它在弯曲上也更强，因为整个接触段上齿廓是凸对凹、油膜更厚。它输在第一条性质上：一套标准化的互换齿轮系统，不可能由与传动比绑定的曲线建成。

**内摆线**——一个圆*内侧*滚动——是外摆线的内啮合伙伴，同样与传动比绑定。它存活在**转子发动机与罗茨鼓风机的型线**里，那里的传动比由定义固定，而共轭运动必须在极大接触范围上精确。

**渐开线**由一条直线在一个圆上纯滚动生成，所以**它的生成元素是一条直线——这意味着刀具的切削刃是一条直线——意味着它能被制造、刃磨、检测、复制到一个任何凸轮都达不到的公差。**同一一直齿廓的齿条用的就是*同一把*刀。滚刀不过是一条绕在圆柱上的齿条。渐开线赢得世界，不是因为它是最优曲线，而是因为**它是唯一一把刀是直线的曲线**，而齿轮制造史就是这个事实的历史。

你为此付出的后果是：渐开线在啮合线两端的接触曲率很差，齿根处齿形薄，且对中心距敏感。这些代价每一项都是成就它标准化的制造优势的直接结果。

## 直齿轮的几何

::: definition 标准齿制 {#def-proportions}
一个直齿轮由它的**模数** $m = d / N$（每齿毫米数，是英制径节 $P = 25.4 / m$ 的SI替代，径节在英制实践中仍在使用）、齿数 $N$ 与压力角 $\phi$ 定义。来自ISO 53或AGMA 291.02标准齿条的标准全齿高齿制为

| 项目 | 符号 | 数值 | 注记 |
|---|---|---|---|
| 分度圆直径 | $d$ | $m N$ | 节圆在此滚动 |
| 基圆直径 | $d_b$ | $m N \cos \phi$ | 渐开线的生成圆 |
| 齿顶高 | $a$ | $1.0 \, m$ | 分度圆到齿顶 |
| 齿根高 | $b_d$ | $1.25 \, m$ | 分度圆到齿根；$0.25 m$ 是顶隙 |
| 齿顶圆直径 | $d_a$ | $m ( N + 2 )$ | |
| 齿根圆直径 | $d_f$ | $m ( N - 2.5 )$ | |
| 周节 | $p$ | $\pi m$ | 弧长，分度圆到分度圆 |
| 基圆齿距 | $p_b$ | $\pi m \cos \phi$ | **真正要紧的那个齿距** |
| 齿厚 | $s$ | $\pi m / 2$ | 分度圆上，侧隙为零时 |
| 中心距 | $C$ | $m ( N_1 + N_2 ) / 2$ | 标准，未变位 |

**决定两个齿轮能否啮合的量是基圆齿距，不是周节。**两个齿轮啮合当且仅当它们的基圆齿距相等，而既然 $p_b = \pi m \cos \phi$，这就意味着模数*与*压力角都要相等。一个 $14.5^{\circ}$ 齿轮与一个同模数的 $20^{\circ}$ 齿轮根本不能啮合；而一个 $20^{\circ}$ 齿轮，除非计入螺旋角，也不能与斜齿轮的端面当量啮合。
:::

::: example 齿数24、模数4小齿轮的几何 {#ex-geometry}
计算 $N = 24$、$m = 4\ \mathrm{mm}$、$\phi = 20^{\circ}$ 的各直径、齿距与基圆上的齿厚。

**答。**$d = 96$，$d_a = 104$，$d_f = 86$，与72齿齿轮配对时 $C = 192\ \mathrm{mm}$。

::: solution
$$
d_b = 96 \cos 20^{\circ} = 90.21\ \mathrm{mm} , \qquad p = \pi \times 4 = 12.566\ \mathrm{mm} , \qquad p_b = 12.566 \times 0.93969 = 11.808\ \mathrm{mm}
$$

任意半径 $r_x$ 处的齿厚来自基圆"齿槽"的不变性：在基圆上度量的、从齿中线到齿廓的弧长是不变量，

$$
s_x = 2 r_x \left[ \frac{s}{d} + \operatorname{inv} \phi - \operatorname{inv} \phi_x \right] , \qquad \cos \phi_x = \frac{d_b}{d_x}
$$

在基圆上 $\phi_x = 0$、$\operatorname{inv} 0 = 0$，且 $s = \pi m / 2 = 6.283\ \mathrm{mm}$、$\operatorname{inv} 20^{\circ} = 0.36397 - 0.34907 = 0.014904$，

$$
s_b = 2 \times 45.106 \times \left[ \frac{6.283}{96} + 0.014904 \right] = 90.21 \times 0.080402 = 7.253\ \mathrm{mm} = 1.813 \, m
$$

**与分度圆上的 $1.571 \, m$ 对比：齿在分度圆与基圆之间失去了四分之一的厚度，而且还在继续失去。**这就是胚胎状态的根切，也是决定一个齿轮到底能不能制造的是齿数——不是模数、不是齿宽——的原因。
:::
:::

## 根切干涉：齿数低于此值，齿轮就是错的

渐开线只存在于基圆之外。基圆以下齿廓根本不是渐开线——那是切齿刀留下什么就是什么，而切齿刀是一把齿条形的滚刀，它的刀顶扫出一条摆线。如果*另一个*齿轮的齿顶伸进那个区域，它就会在齿根附近从齿廓上挖走一瓢。这就是**根切干涉**，而与本课其他所有失效不同，它不是程度问题：一个发生干涉的齿轮不是稍差一点的齿轮，而是一个齿在需要齿的地方被挖掉的齿轮。

::: theorem 避免根切的最少齿数 {#thm-minteeth}
齿数 $N_1$ 的小齿轮在标准中心距下驱动齿数 $N_2 = G N_1$ 的外齿轮，压力角 $\phi$、齿顶高 $a = 1.0 \, m$，则当任一齿顶圆越过啮合线与*对方*基圆的切点时干涉开始。记 $r = m N / 2$、$r_a = r + m$、$r_b = r \cos \phi$、$C = r_1 + r_2$，齿轮齿顶保持在啮合线内的条件是

$$
\sqrt{ r_{a2}^{2} - r_{b2}^{2} } \; \le \; C \sin \phi
$$

平方、化简后化为

$$
\boxed{ \; N_1 \left( N_1 + 2 N_2 \right) \ \ge \ \frac{4 \left( N_2 + 1 \right)}{\sin^{2} \phi} \; } \qquad \text{对称地} \qquad N_2 \left( N_2 + 2 N_1 \right) \ \ge \ \frac{4 \left( N_1 + 1 \right)}{\sin^{2} \phi}
$$

对小齿轮对**齿条**（$G \to \infty$），它坍缩为那个著名的

$$
\boxed{ \; N_{\min} = \frac{2}{\sin^{2} \phi} \; } \qquad \Rightarrow \qquad
\begin{cases} N_{\min} = 31.9 & \phi = 14.5^{\circ} \\[4pt] N_{\min} = 17.1 & \phi = 20^{\circ} \\[4pt] N_{\min} = 11.2 & \phi = 25^{\circ} \end{cases}
$$
:::

caption: 齿条情形，$N_{\min} = 2 / \sin^{2} \phi$。**曲线在低压力角一端陡得粗暴**：从 $14.5^{\circ}$ 移到 $20^{\circ}$，最少齿数一下扔掉十五个，这正是十九世纪的 $14.5^{\circ}$ 标准在切齿机械让改换变得便宜之后立刻被抛弃的原因。$20^{\circ}$ 处的17.1是工业界"小齿轮绝不低于17齿"这一习惯的源头，也是变位制度存在的全部理由——它让你能用12齿。

::: example 读根切干涉表 {#ex-interference}
求传动比 $G = 1$、$G = 3$、$G = \infty$ 时最小的未变位 $20^{\circ}$ 小齿轮，并校核一对 $19 / 57$ 是否安全。

**答。**对 $N$ 解 $G N + 1 \le N^{2} ( 1 + 2 G ) \sin^{2} \phi / 4$：

| 传动比 $G$ | 最小 $N_1$ | 起约束作用的一方 |
|---|---|---|
| 1 | 12.32 → **13** | 由对称性，双方皆可 |
| 3 | 14.98 → **15** | 大齿轮齿顶挖小齿轮齿廓 |
| $\infty$（齿条） | 17.10 → **18** | 齿条刀顶挖小齿轮齿廓 |

::: solution
$19 / 57$ 副的 $G = 3$、$N_1 = 19 > 15$，所以安全，还富余四个齿。对小齿轮直接校核几何，

$$
\sqrt{ r_{a1}^{2} - r_{b1}^{2} } = \sqrt{ 28.5^{2} - 26.69^{2} } = 10.29\ \mathrm{mm} \; < \; C \sin \phi = 114 \times 0.34202 = 38.99\ \mathrm{mm}
$$

**表里有两点值得细品。**第一，小齿轮最少齿数随传动比*增加*，从1:1的13齿到对齿条的18齿——小齿轮配大齿轮比两个一样大的更吃亏，因为大齿轮的齿顶圆近乎一条直线，而直边齿条的齿顶是最糟糕的挖掘形状。第二，**数字17不是强度极限，也不是制造极限。**同模数的18齿小齿轮与12齿小齿轮承受的弯曲载荷几乎相同；12齿那个只是被挖掉了。
:::
:::

::: warning 变位不是精雕细琢，而是标准解法
上一节的每条极限都假定**标准齿条**：齿顶高恰好 $1.0 \, m$，齿轮的分度圆与齿条的节线相切。把齿条沿径向离齿轮中心滑开 $x m$——一个 $x$ 的**变位**（**径向变位**，又称移距修正）——你生成的齿在齿根处更厚、齿顶更窄，干涉条件变为

$$
N_{\min} ( x ) = \frac{ 2 \left( 1.0 - x \right)}{\sin^{2} \phi} \qquad \Rightarrow \qquad x = + 0.3 \ \text{把} \ N_{\min} \ \text{从} \ 17.1 \ \text{降到} \ 12.0
$$

整个ISO 53移距修正制度存在的意义就是买那五个齿，因为五个齿是 $57\ \mathrm{mm}$ 小齿轮与 $38\ \mathrm{mm}$ 小齿轮的差别，是装得下的齿轮箱与装不下的齿轮箱的差别。**代价是齿轮不再可互换、不再能用标准刀不经调整切制、也不再容忍中心距误差**——变位齿轮副必须运行在其设计中心距上，公差比未变位副更严，其原因下一节将定量说明。实践中：一对齿轮取 $x_1 = +0.4$、$x_2 = -0.4$、变位系数之和为零从而标准中心距仍然可用，是齿轮参数设计中最高频、也最少被写上图样的那一个决定。
:::

## 重合度：有几对齿在承载

::: definition 重合度 {#def-crr}
**啮合线长度**是接触点沿啮合线扫过的长度，从小齿轮齿顶圆与它的交点到齿轮齿顶圆与它的交点，

$$
L = \sqrt{ r_{a1}^{2} - r_{b1}^{2} } + \sqrt{ r_{a2}^{2} - r_{b2}^{2} } - C \sin \phi
$$

**端面重合度**是以基圆齿距度量的这段长度，

$$
\boxed{ \; m_p = \frac{L}{p_b} = \frac{ \sqrt{ r_{a1}^{2} - r_{b1}^{2} } + \sqrt{ r_{a2}^{2} - r_{b2}^{2} } - C \sin \phi }{ \pi m \cos \phi } \; }
$$

它就是同时啮合齿对数的平均值。**重合度低于1.0不只是低效——那是一对凸轮-从动件**，啮合线不再保证通过节点，速比不再恒定。
:::

$$

$$
L = \sqrt{ 63^{2} - 56.382^{2} } + \sqrt{ 33^{2} - 28.190^{2} } - 90 \times 0.34202 = 28.109 + 17.155 - 30.782 = 14.48\ \mathrm{mm}
$$

$$
p_b = \pi \times 3 \times 0.93969 = 8.857\ \mathrm{mm} \qquad \Rightarrow \qquad m_p = \frac{ 14.48 }{ 8.857 } = \boxed{ 1.635 }
$$

**读出那个0.635的含义。**啮合循环的63.5%由两对齿分担载荷，36.5%只有一对齿承载——而两者之间的过渡并不平滑。第二对齿进入啮合时，它自己的齿厚误差与它自己的受载变形意味着载荷不会从一对齿瞬间跳到两对；载荷是爬升的，而这个爬升是**啮合频率上的传递误差波动**，它是齿轮啸叫的主导来源。**齿轮设计师手里最有效的降噪手段，是把重合度从1.4提到1.7**，而做到它的两种办法——更多齿配更小模数，或加螺旋角——正是被用来做到它的两种办法。
:::
:::

## 中心距：比看上去更严的公差

未变位齿轮副按 $C = m ( N_1 + N_2 ) / 2$ 设计。把它装在稍大的中心距上它照样转——不会卡死——但同时发生三件事，第三件最让人意外。

1. **出现侧隙。**齿槽在分度圆上比齿宽出 $j \approx 2 \Delta C \tan \phi$。
2. **工作压力角升高。**节圆不再是基准圆；齿轮现在在与新中心距下基圆公切线相切于任意半径处相互滚动。渐开线函数正是联系两者的东西：

$$
\operatorname{inv} \phi_{\mathrm{op}} = \operatorname{inv} \phi + \frac{ 2 \tan \phi \; \Delta C }{ r_1 + r_2 }
$$

3. **重合度崩塌**，因为 $L$ 分子中的 $C \sin \phi$ 在增长，而两个齿顶圆项保持不变。

::: example 中心距敏感性，20/40模数3 {#ex-centre}
::: solution
| $\Delta C$ (mm) | $\phi_{\mathrm{op}}$ | 侧隙 $j$ (mm) | $m_p$ |
|---|---|---|---|
| 0 | $20.00^{\circ}$ | 0 | 1.635 |
| +0.05 | $20.17^{\circ}$ | 0.037 | 1.606 |
| +0.10 | $20.34^{\circ}$ | 0.074 | 1.578 |
| +0.20 | $20.67^{\circ}$ | 0.151 | 1.522 |
| +0.45 | $21.46^{\circ}$ | 0.354 | 1.388 |
| +0.90 | $22.72^{\circ}$ | 0.754 | 1.168 |
| +1.80 | $24.86^{\circ}$ | 1.668 | 0.779 |

**中心距多出半丝（半个十分之一毫米），重合度就损失二十分之一。**因此按 $\pm 0.1\ \mathrm{mm}$ 镗出的箱体——对通用机加工序这是可以接受的数字——就要付出约十分之一的重合度，约等于载荷分担收益的六分之一，且足以被听见。这就是为什么齿轮箱箱体要在一次装夹中镗孔、端盖螺栓拧紧，为什么轴承孔常在总装后铰削，为什么质量10级航空齿轮箱的中心距公差是 $\pm 0.013\ \mathrm{mm}$ 而不是 $\pm 0.1$。

**再看最后两行的形状。**$+ 0.9\ \mathrm{mm}$ 时重合度已跌破1.2，齿轮副在整个循环中趋近单齿对接触；$+ 1.8\ \mathrm{mm}$ 时已低于1.0，意味着齿轮在整个啮合上不再共轭，而要靠齿顶干涉部分地驱动。**这台齿轮箱没有任何一眼可见的毛病——轴转得轻松，侧隙看着充裕，而齿将在几千个循环内失效。**
:::

## 轮齿弯曲：机械工程里最古老的强度公式

::: definition 刘易斯公式 {#def-lewis}
把轮齿建模为一根在齿顶外角、沿啮合线方向加载的悬臂梁。在一条内接等强度抛物线与受载齿面相切的截面处切开它——实践中就在基圆处或略低于基圆——并对厚度 $t$、单位宽度的矩形截面写出弯曲应力 $\sigma = M c / I$：

$$
\sigma_F = \frac{6 W_t a}{b \, t^{2}}
$$

其中 $W_t$ 为传递载荷，$a$ 为载荷到危险截面的力臂，$b$ 为齿宽。写出 $t = Y' m$、$a = k' m$，它就化为**刘易斯（Lewis）公式**，

$$
\boxed{ \; \sigma_F = \frac{ W_t }{ b \, m \, Y } \; } \qquad Y = \frac{ t^{2} }{ 6 a m }
$$

其中 $Y$ 是**刘易斯齿形系数**，一个只依赖齿数与压力角的纯数。然后齿对着弯曲疲劳极限 $\sigma_{F,\lim}$ 并带安全系数校核，正如轴对着疲劳极限校核——因为它本来就是：**齿根是一根在啮合频率下循环的全反转弯曲疲劳试件。**
:::

刘易斯公式出自1892年，而它在本质上仍是今天每一套齿轮标准所做的事。它省略了什么值得列出来，因为每一项省略都是现代AGMA与ISO公式里的一个修正系数：

| 省略项 | 后果 | AGMA系数 | 典型值 |
|---|---|---|---|
| 齿根圆角的应力集中 | 实际齿根应力高30-50% | 并入 $Y$ / $J$ | 1.2-1.5 |
| 截面上的剪切与压缩 | 几个百分点 | 忽略 | — |
| 两对齿分担载荷 | $m_p > 1$ 处低15-20% | $1 / m_p$ 型 | 0.85 |
| 齿的变形与动力学过冲 | 载荷随速度上升 | $K_v$ | 1.05-1.6 |
| 不对中与轴的挠曲 | 载荷挤向一端 | $K_{H\beta}$ | 1.05-1.4 |
| 齿距不均 | 最刚的一对过载 | $K_{H\alpha}$ | 1.05-1.25 |
| 工作循环与起动峰值 | 真正的峰值，而非平均 | $K_A$ | 1.0-2.0 |

::: example 55 kW工业小齿轮的弯曲应力 {#ex-bend}
一台 $55\ \mathrm{kW}$、$730\ \mathrm{rev / min}$ 的鼓风机减速器以 $i = 5.22$ 运行，齿副为 $18 / 94$、模数 $6$、压力角 $20^{\circ}$、未变位，材料42CrMo4调质 $300\ \mathrm{HB}$，滚齿至AGMA质量8级，油池润滑。设计寿命为小齿轮 $10^{9}$ 转。取小齿轮齿宽 $b_1 = 75\ \mathrm{mm}$、大齿轮 $b_2 = 70\ \mathrm{mm}$、$K_A = 1.25$、齿根圆角系数 $K_F = 1.4$。

**答。**齿根处 $\sigma_F = 170\ \mathrm{MPa}$，对 $\sigma_{F,\lim} = 430\ \mathrm{MPa}$：$S_F = 2.5$。

::: solution
$$
T_1 = \frac{ 55\,000 }{ 730 \times 2 \pi / 60 } = 719.5\ \mathrm{N \cdot m} , \qquad d_1 = 6 \times 18 = 108\ \mathrm{mm} , \qquad W_t = \frac{ 2 \times 719.5 }{ 0.108 } = 13\,323\ \mathrm{N}
$$

危险截面厚度来自 [[#ex-geometry]] 的基圆公式，

$$
s_b = 2 r_b \! \left[ \frac{ \pi m }{ 2 d} + \operatorname{inv} \phi \right] = 2 \times 50.74 \times \left[ \frac{ \pi }{ 36 } + 0.014904 \right] = 10.37\ \mathrm{mm} = 1.728 \, m
$$

取标准力臂 $a = 1.2 \, m = 7.2\ \mathrm{mm}$，并以较窄的大齿轮齿宽为准，

$$
\sigma_F = K_F K_v \frac{1}{\bar{m}_p} \frac{ 6 W_t a }{ b \, s_b^{2} } = 1.4 \times 1.25 \times \frac{ 1 }{ 0.85 } \times \frac{ 6 \times 13\,323 \times 7.2 }{ 70 \times 10.37^{2} } = 2.059 \times 82.4 = \boxed{ 170\ \mathrm{MPa} }
$$

**这个数字平平无奇，而这正是重点。**$300\ \mathrm{HB}$ 调质齿轮在 $10^{9}$ 循环下的弯曲疲劳极限接近 $430\ \mathrm{MPa}$，所以齿只跑在其弯曲能力的40%上，弯曲失效永远不会发生。**换个问题：若弯曲单独决定设计，齿宽该是多少？$24.5\ \mathrm{mm}$。**这副齿轮有 $70\ \mathrm{mm}$ 齿宽是因为别的东西，而那件东西就是下一节。
:::
:::

## 表面耐久：为什么齿宽真正要的是70 mm

::: definition 点蚀与接触安全系数 {#def-pitting}
两个齿轮齿面是两个线接触的曲面体，节点处的赫兹压力来自为 [[mechanisms/cams]] 收尾的同一个 $p_0 = \sqrt{ F E^{*} / ( \pi b R ) }$。节点处的当量曲率半径由两条基圆切线决定，

$$
\frac{1}{R} = \frac{1}{r_1 \sin \phi} + \frac{1}{r_2 \sin \phi} \qquad \Rightarrow \qquad p_0 = \sqrt{ \frac{ W_t E^{*} }{ \pi b R } } \ , \qquad E^{*} = \frac{ E }{ 1 - \nu^{2} } = 113.7\ \mathrm{GPa}\ \text{（钢）}
$$

**与凸轮不同，$R$ 不是常数。**它是 $\rho_1 \rho_2 / ( \rho_1 + \rho_2 )$，其中 $\rho_i$ 是*齿面*的曲率半径，它在啮合线的两端——接触趋近小齿轮齿顶与大齿轮齿根处——趋于零。因此峰值压力不发生在节点，而在啮合的内端附近，且比节点值高10-20%。
:::

::: example 同一个小齿轮的点蚀校核 {#ex-pit}
::: solution
$$
r_1 = 54 , \quad r_2 = 282\ \mathrm{mm} \qquad \Rightarrow \qquad \frac{1}{R} = \frac{1}{ 54 \times 0.34202 } + \frac{1}{ 282 \times 0.34202 } = 0.05414 + 0.01041 = 0.06455
$$

$$
R = 15.50\ \mathrm{mm} \qquad p_0 = \sqrt{ \frac{ 1.25 \times 13\,323 \times 113\,700 }{ 0.85 \times \pi \times 70 \times 15.50 } } = \boxed{ 1\,185\ \mathrm{MPa} }
$$

对着 $300\ \mathrm{HB}$ 调质表面在 $10^{9}$ 循环下的 $\sigma_{H,\lim} = 1\,250\ \mathrm{MPa}$——**接触安全系数 $1.05$，而计入啮合两端10-$20\%$ 的应力集中后实际约为 $0.95$。**设计受点蚀限制，而诚实的结论是 $70\ \mathrm{mm}$ 是齿宽的*下限*，绝非宽裕值。

**现在把两个数字并排放。**弯曲只需要 $24.5\ \mathrm{mm}$ 齿宽；点蚀在相同的许用应力比下需要 $54\ \mathrm{mm}$。**这副齿轮比它在弯曲上存活所需的宽度宽2.9倍，纯粹是为了让它的表面活下来。**每个齿轮设计师起初都把这笔账算反：先校核弯曲，然后大吃一惊。由此得出的经验值值得背下：**调质钢工业级齿轮，点蚀说了算；渗碳磨齿齿轮，弯曲开始缩小差距；而氮化或调质铸造齿轮，点蚀更是压倒性地说了算。**
:::
:::

caption: 55 kW小齿轮的两个安全系数对齿宽，均已归一化使1.0为许用值。**点蚀曲线是平缓的那条——$S_H \propto \sqrt{b}$——这就是为什么用齿宽买表面寿命如此昂贵：宽度翻倍只买到41%的接触裕度。**弯曲曲线是 $S_F \propto b$，又陡又便宜。约 $38\ \mathrm{mm}$ 处的交点是两种失效模式等概率之点，而选了调质钢的设计师根本到不了那一点。

::: exercise 由点蚀定齿宽 {level=1 check="41"}
同一对 $18 / 94$ 模数6齿轮副改用渗碳磨齿的 $20\mathrm{MnCr5}$ 重制，$\sigma_{H,\lim} = 1\,500\ \mathrm{MPa}$、$\sigma_{F,\lim} = 850\ \mathrm{MPa}$，其余系数不变。**点蚀**校核要求多大齿宽？

::: solution
$p_0 \propto 1 / \sqrt{b}$，且 $b = 70\ \mathrm{mm}$ 时 $p_0 = 1\,185\ \mathrm{MPa}$，所以

$$
b = 70 \times \left( \frac{ 1\,185 }{ 1\,500 } \right)^{2} = 70 \times 0.6241 = \boxed{ 41\ \mathrm{mm} }
$$

**齿宽减少41%，而价格的减少还要大得多**，因为磨齿渗碳齿轮的价格是调质齿轮的数倍，省下的钱要跟这个比、而不是跟钢材的价钱比。在 $b = 41$ 处校核弯曲：$\sigma_F = 169.6 \times 65 / 41 = 269\ \mathrm{MPa}$，对 $850$，故 $S_F = 3.2$——**弯曲变得更不成问题，而表面成了设计的全部。**这正是渗碳齿轮的特征签名，也是航空齿轮要磨齿的原因：不为强度，为表面。
:::
:::

::: warning 点蚀到底是什么
点蚀不是"表面磨光了"。赫兹接触的最大**切应力**不在表面，而在表面以下 $0.78 b_h$ 处，那里的材料在表面受压、因而对在那里张开裂纹是免疫的。在齿轮上情况更糟，因为滑动速度在节线处变号：**节线以上，滑动把任何表面裂纹撬开；节线以下，滑动把裂纹压闭，后面还垫着一楔油。**观察到的结果是：点蚀从小齿轮齿面节线以下、最大切应力深度处开始；而所谓点蚀坑，是皮下裂纹被 $1\,000$ 个大气压峰值压力下楔入的油撑开、终于贯通到表面、掀起一片碎屑时的产物。

三条实际推论。**油的黏度有帮助：**更厚的油膜减少楔入作用，这就是一个正在点蚀的齿轮往往在加大黏度牌号后就得到缓解、而要加大尺寸还早得多的原因。**更硬的表面通过提高抗剪强度来帮忙，而不是通过提高屈服强度**，这就是布氏硬度与许用接触应力之间的经验关系如此接近线性的原因。**而跑合后的齿轮上少量初始点蚀是正常的、有益的**，因为点蚀坑会参与载荷分担、齿面会相互贴合；标准里的"许用"接触应力是一个设计寿命，不是无损伤门槛。
:::

## 动力学：啮合是一根刚度不断变化的弹簧

两对啮合的齿是两根并联的赫兹弹簧，而接触点沿啮合线行进时，齿对数在 $\lfloor m_p \rfloor$ 与 $\lceil m_p \rceil$ 之间变化。**于是啮合刚度在啮合频率上波动**，而对钢齿轮，单对齿单位齿宽刚度约为每毫米 $20\ \mathrm{N / \mu m}$——所以前面那副 $70\ \mathrm{mm}$ 的小齿轮每对齿的啮合刚度约为 $1.4 \times 10^{9}\ \mathrm{N / m}$，在其 $13.3\ \mathrm{kN}$ 载荷下变形约 $5\text{–}6\ \mu\mathrm{m}$。

这个数字要紧，因为**它与制造误差同量级。**AGMA质量8级齿轮的齿形与齿距误差为 $8$-$12\ \mu\mathrm{m}$；质量12级磨齿齿轮为 $2$-$3\ \mu\mathrm{m}$。当误差远大于弹性变形时，进入啮合的那对齿必须先被弯到位才能开始承载，而整个啮合循环上的载荷历史由误差主导、而非由几何主导。这就是动载系数 $K_v$ 的物理内涵：

| AGMA质量等级 | $V < 5\ \mathrm{m/s}$ | $V = 10$ | $V = 20$ | $V = 30$ |
|---|---|---|---|---|
| 6（铣齿） | 1.10 | 1.25 | 1.55 | — |
| 8（精滚齿） | 1.08 | 1.18 | 1.38 | 1.65 |
| 10（剃齿） | 1.05 | 1.12 | 1.25 | 1.45 |
| 12（磨齿） | 1.03 | 1.07 | 1.15 | 1.30 |
| 14（超级光整） | 1.02 | 1.05 | 1.10 | 1.22 |

油中钢齿轮的代表性公开数值，而表格的形状就是信息：**磨齿给你买的是速度上限，不是强度。**$4\ \mathrm{m/s}$ 时质量6级与质量12级差7%的载荷；$30\ \mathrm{m/s}$ 时差35%，而 $30\ \mathrm{m/s}$ 的齿轮箱用质量6级根本造不出来。

::: exercise 啮合频率与共振 {level=1 check="219"}
前面那个 $18$ 齿、$730\ \mathrm{rev / min}$ 的小齿轮，啮合频率是多少？若电机-小齿轮系统的第一阶扭转模态实测为 $110\ \mathrm{Hz}$，设计可接受吗？

::: solution
$$
f_{\text{mesh}} = \frac{ N_1 n }{ 60 } = \frac{ 18 \times 730 }{ 60 } = \boxed{ 219\ \mathrm{Hz} }
$$

**对着 $110\ \mathrm{Hz}$ 的扭转固有频率——比值 $0.50$，恰好压在常用 $1.5\!:\!1$ 间隔规则的红线上，不应被接受。**系统跑在固有频率的两倍上，在线性系统里这是响应*降低*的区域，但齿轮啮合不是线性的：$219\ \mathrm{Hz}$ 的刚度波动含有强二次谐波，而更重要的是，每个啮合循环过渡处的载荷反向是一列冲击串，它不管设计师愿不愿意都会找到 $110\ \mathrm{Hz}$。按便宜程度排序的补救措施：**把齿数改一**（17或19齿把啮合频率移到207或231 Hz，挪不了多少），**改传动比从而改小齿轮转速**，**在电机轴上加扭转减振器**，或**加长小齿轮轴颈重新调模**。第一种免费，最后一种才是真管用的。
:::
:::

$\eta = 0.985$ 的 $55\ \mathrm{kW}$ 减速器耗散

$$
P_{\mathrm{loss}} = 55\,000 \times ( 1 - 0.985 ) = 825\ \mathrm{W}
$$

静止空气中的灰铸铁箱体在 $40\ \mathrm{K}$ 温升下每平方米表面散约 $1.0$-$1.3\ \mathrm{kW}$，所以**$825\ \mathrm{W}$ 大约需要 $0.8\ \mathrm{m^{2}}$ 的有效表面积——一个 $500 \times 500\ \mathrm{mm}$ 的箱体只有约 $0.5\ \mathrm{m^{2}}$，齿轮箱会跑热。**标准对策按顺序是散热片、轴上风扇、油冷却器、更大的箱体；而标准错误是按轴心距定箱体大小、到验收试验时才发现热问题——那时油温冲到 $95^{\circ}\mathrm{C}$，密封件跟着完蛋。

**现在对比蜗杆。**同样 $55\ \mathrm{kW}$ 经过导程角 $5^{\circ}$、$\eta = 0.45$ 的蜗杆，耗散 $30.3\ \mathrm{kW}$——**超过输入功率的一半，是斜齿轮损耗的五十倍，却装在一个小得多的箱子里。**这就是蜗杆只用于低工作循环或低功率的原因，是它连续工作必须大幅降额的原因，是它先需要冷却器、后需要更强齿轮的原因，也是蜗杆齿轮箱的设计问题从来不是"它会不会断"而是"它会不会开锅"的原因。
:::
:::

## 斜齿轮：同一条渐开线，斜着拖过去

::: definition 斜齿轮几何 {#def-helical}
斜齿轮是一条齿向为圆柱上**螺旋角** $\psi$ 的螺旋线的直齿轮。它的一切都来自一个事实：**斜齿轮的端面是比它所用刀具的基圆更大的基圆的渐开线。**下标 $n$ 记法面（垂直于齿向），$t$ 记端面，

$$
m_n = m_t \cos \psi \qquad \tan \phi_t = \frac{ \tan \phi_n }{ \cos \psi } \qquad d = \frac{ m_n N }{ \cos \psi }
$$

而无论几何还是强度，这个齿轮表现得像一个

$$
\boxed{ \; N_v = \frac{ N }{ \cos^{3} \psi } \; }
$$

齿的**虚拟**或**当量直齿轮**。那个三次方来自椭圆：齿坐在分度圆柱被螺旋线截出的等效椭圆的端点上，其曲率半径为 $d / ( 2 \cos^{2} \psi )$，第三个余弦是载荷方向的投影。
:::

三条推论，按它们改变设计的程度排序。

**1. 重合度多出一个独立的第二项。**因为齿是沿一条斜线逐渐进入啮合、而不是整条齿宽突然进入，**轴向重合度**叠加到端面重合度上，

$$
m_F = \frac{ b \sin \psi }{ \pi m_n } \qquad m_{\text{total}} = m_p + m_F
$$

而与 $m_p$ 不同，它**没有上界**——齿宽与螺旋角允许多少就能买多少。直齿轮卡在1.6；$\psi = 20^{\circ}$、$b = 70\ \mathrm{mm}$、$m_n = 6$ 的斜齿轮达到2.96。**这就是斜齿轮在一切要求安静的场合取代直齿轮的最大单一原因。**

**2. 根切极限放松了。**既然齿轮表现得像 $N_v$ 齿，最少齿数变为 $N_{\min} = 17.1 \cos^{3} \psi$：$\psi = 20^{\circ}$ 时是15齿，$25^{\circ}$ 时是9齿。**斜齿轮小齿轮可以比直齿的小好几齿才被挖掉**，而在小齿轮直径决定中心距的齿轮箱里，三个齿就是整个包络。

**3. 你造出了一个轴向推力。**齿向是倾斜的，所以法向力有一个沿轴的分量：

$$
F_a = W_t \tan \psi
$$

对 $\psi = 20^{\circ}$ 的55 kW小齿轮，那是 $13\,323 \times 0.364 = 4\,850\ \mathrm{N}$ 的轴向载荷，压在一根此前不承受任何轴向力的轴上——于是一个推力轴承、一个轴肩、一个隔套和一叠垫片。**这就是税，而避税只有两个办法：把螺旋角归零，那就是直齿轮；或者在同一轮坯上把齿切成旋向相反的两半，那就是人字齿轮（双斜齿轮）**——它恰好抵消推力，代价是一条任何滚刀都切不到根的油槽。人字齿轮专为重型汽轮机与船舶减速器而造，正是因为 $10\,000\ \mathrm{kW}$ 下推力达一百千牛，而能承受它的轴承比齿轮还大。

::: widget plot
title: 总重合度对螺旋角
f: 1.688+70*sin(x*pi/180)/(pi*6)
x: 0, 30
y: 1.5, 3.6
caption: 那副55 kW齿轮的总重合度随螺旋角增长，齿宽与法面模数保持不变。**曲线近乎线性，因为 $m_F$ 就是全部故事**——端面项几乎不动，因为 $m_p$ 依赖 $N_v$ 与 $\phi_t$ 的两种方式部分抵消。设计师的天花板不是曲线，而是 $20^{\circ}$ 处那 $4\,850\ \mathrm{N}$ 轴向推力，它按 $\tan \psi$ 增长：**$15^{\circ}$ 是常见的折中，$20^{\circ}$ 是轴承已经在那儿时你用的，$30^{\circ}$ 是推力抵消的人字齿轮上你用的。**

## 锥齿轮、蜗杆、内齿轮与行星齿轮，各一段

**直齿锥齿轮**是圆锥上的渐开线齿，而整个设计都在**大端背锥**上做，因为齿在锥顶处缩到零。当量齿数为 $N_v = N / \cos \delta$，$\delta$ 为分锥半角，所以一对 $1 : 1$、压力角 $20^{\circ}$ 的锥齿轮表现得像一对 $28 / 28$ 的直齿轮副，可以用3号刀盘切制。它的弱点是任何安装距误差都会改变接触斑点，这就是为什么出厂时图样上规定研点接触斑点，也为什么重新调整过垫片却没查斑点的差速器会啸叫。

**螺旋锥齿轮**加上螺旋角，这使它们的重合度超过2、安静到足以用于汽车驱动桥——也让它们**对百分之一毫米的偏移敏感**，而汽车后桥的**准双曲面齿轮**正是有意利用这一点：小齿轮轴线低于大轮轴线，多换来一对啮合齿和一个更小的传动轴通道，代价是要求极压油的重滑动和4%的功率。

**蜗杆**是一支螺杆驱动一段蜗轮弧，它的全部性格来自两者间的滑动速度——静止时也高——这就是它们永远是青铜对钢、永远受效率限制、永远受热限制的原因。它们真正的优点是单级60:1的传动比、近乎无声的运行，以及青铜带来的吸振。它们的代价是最多60%的功率。

**内齿轮**——齿轮装在齿圈里——其内啮合的赫兹公式里两个曲率*相减*而非相加，给出大得多的当量半径，因而同尺寸下接触应力更低、弯曲强度更高。但它在*齿圈*一侧有一个比小齿轮那侧严苛得多的干涉极限，而且不能滚齿，只能插齿或拉齿，这就是它贵的原因。凡是包络是约束的地方都用它：行星齿轮箱、循环球式转向器，以及每一台自动变速器的最终传动。

**行星齿轮**把转矩分到 $n$ 个行星啮合上，这是造出又小又轻、却承受巨大转矩的齿轮箱的唯一办法。代价是一个行星架、$n$ 个行星轮轴承，以及"所有 $n$ 个行星轮必须均载"的要求——它们并不均载，除非齿圈能轴向浮动、或者行星架被故意做软。**五个行星轮的一级并不承受单个啮合的五倍载荷；设计良好的一级约承受3.5倍，设计糟糕的一级约承受2.5倍，其中一个行星轮干大部分工作，并在拆检时被发现有烧伤。**设计规则是：行星架与轴的扭转刚度必须远低于啮合刚度，让弹性变形去均化力流，而不是集中力流。

## 制造、精度等级与侧隙

AGMA质量等级从约4到14，它是对齿距、齿形与齿向误差的规范，不是某种笼统优秀的等级：

| 质量等级 | 工艺 | 齿距误差 | 典型用途 |
|---|---|---|---|
| 4-6 | 砂型铸造、锯切、铣齿 | 50-100 $\mu$m | 开式齿轮、矿山球磨机大齿圈 |
| 7-8 | 滚齿、插齿 | 15-30 $\mu$m | 工业减速器、农机 |
| 9-10 | 滚齿后剃齿 | 8-15 $\mu$m | 汽车变速器 |
| 11-12 | 磨齿 | 3-8 $\mu$m | 航空、机床、风电 |
| 13-14 | 精密磨齿、超级光整 | 1-3 $\mu$m | 主轴、陀螺驱动、航天 |

**工艺路线就是设计。**渗碳齿轮必须磨，因为它在淬硬时变形 $0.05$-$0.15\ \mathrm{mm}$；剃齿齿轮必须在相变温度以下调质，否则剃齿会撕裂。滚齿齿轮可以直接装进齿轮箱；磨齿齿轮必须装进一个轴承是在箱体清洗之后才装上的齿轮箱，因为轴承外圈下一颗 $30\ \mu\mathrm{m}$ 的切屑就是五分之一的质量等级。

**侧隙**是按住大齿轮时小齿轮空转过的弧长。它不是误差而是一个规定量，两台不同温度箱体间的热膨胀需要它、油膜需要它、中心距的公差链也需要它。标准最小值工业齿轮约 $0.10 \, m$、仪表齿轮 $0.02$-$0.04 \, m$，且它由**齿厚减薄**——把齿切得比名义值薄——来设定，绝不用拉开中心距来设定，理由列在 [[#ex-centre]] 的表里。

::: example 侧隙靠齿厚，不靠中心距 {#ex-backlash}
一对模数6齿轮副需要在分度圆上有 $0.20\ \mathrm{mm}$ 侧隙。比较靠减薄齿厚与靠拉开中心距两种做法。

**答。**靠齿厚：每个齿切薄 $0.10\ \mathrm{mm}$，中心距不动，重合度不变。

::: solution
靠中心距，读 [[#ex-centre]] 的表，$j = 0.20\ \mathrm{mm}$ 对应 $\Delta C \approx 0.27\ \mathrm{mm}$，此时

$$
\phi_{\mathrm{op}} \approx 20.9^{\circ}, \qquad m_p \approx 1.49 \quad \text{而原值为} \ 1.635
$$

**用齿厚买侧隙分文不花，用中心距买却要付出9%的重合度。**中心距侧隙唯一正确的场合，是一副设计中心距本就不同于 $m ( N_1 + N_2 ) / 2$ 的*变位*齿轮副，而即便如此，变位系数也是选来让所需侧隙从齿厚 $x_1$、$x_2$ 中自然得出，而不是从孔到孔的尺寸里得出。
:::
:::

## 选用齿轮：那棵没人印出来的决策树

::: example 选定传动级 {#ex-select}
为下列各例指定齿轮类型，并说明理由。

**(a)** 一台 $7.5\ \mathrm{kW}$、$1450\ \mathrm{rev / min}$ 降到 $48\ \mathrm{rev / min}$ 的输送机驱动，连续运转，水泥厂，预算紧张。
**(b)** 一个 $250\ \mathrm{W}$ 机器人腕关节，要求 $180 : 1$、回程误差小于 $0.05^{\circ}$。
**(c)** 一台 $2\ \mathrm{MW}$ 风机主传动，从 $14$ 升到 $1500\ \mathrm{rev / min}$，按20年不打开设计。
**(d)** 一台 $0.75\ \mathrm{kW}$ 输送机，断电时必须在 $15^{\circ}$ 斜坡上停止并保持。

**答。**

::: solution
**(a)** $i = 30.2$。两级斜齿、每级 $i \approx 5.5$ 得 $30.25$——只有齿数能整除时才算精确，所以用 $17 \times 19 / ( 51 \times 53 )$……实践中是**两级5.5与5.5的斜齿轮，或者若两轴必须垂直则一级斜齿5.5加一级蜗杆5.5。**平行轴输送机：**两级斜齿轮，调质，滚齿至质量8级，飞溅润滑，$\eta = 0.97$。**7.5 kW不值得渗碳；这台齿轮箱将受箱体限制，不受齿轮限制。

**(b)** $180 : 1$ 下 $0.05^{\circ}$ 的回程误差，折算到输入端是 $9\ \mathrm{mrad}$ 的空程，而任何渐开线轮系在任何价位都做不到，因为三级的侧隙会叠加。**答案谐波减速器或摆线（RV）减速器**，两者都让大量齿同时啮合并施加预紧。**注意这是摆线，不是渐开线**——十九世纪因与传动比绑定而抛弃的那条曲线，恰恰是传动比固定、精度是一切时你想要的。

**(c)** $i = 107$。没有单级能做到。**业界标准是一级 $i \approx 5$ 的行星加两级 $i \approx 4.6$ 的斜齿**，行星级在直径负担得起的低速端承受转矩。20年不打开意味着：渗碳磨齿18CrNiMo7-6，$S_H \ge 1.3$、$S_F \ge 2.0$，油液过滤等级 $\beta_{15} > 200$，以及——人们忘记的那部分——**齿圈齿数与小齿轮齿数互质**，使每个小齿轮齿每 $N_1 N_2$ 次啮合才碰到每个大轮齿一次，磨损铺满整个齿宽。

**(d)** $0.75\ \mathrm{kW}$，斜坡上保持。**导程角低于摩擦角的蜗杆**，这是自锁唯一真正正确的应用，因为它保持时耗散的功率为零——载荷是静态的、没有滑动，而静摩擦角高于动摩擦角。**警告是：在任何要紧的安全标准里，"自锁"都不是制动器的替代品**，因为蜗杆的静摩擦因数取决于温度、取决于油是否已流干、取决于传动最近是否被反拖过，而这些没有一样是风险评估能保证的。
:::
:::

::: exercise 变位后的最少齿数 {level=1 check="11"}
一个 $20^{\mathrm{\circ}}$ 小齿轮与齿条啮合。变位系数 $x = + 0.4$ 时，避免根切的最少齿数是多少？

::: solution
挖齿的是齿条的齿顶，而把齿条离齿轮中心移远 $x m$ 会使生成的齿根外移同样距离，于是干涉条件变为

$$
N_{\min} = \frac{ 2 \left( 1 - x \right)}{\sin^{2} \phi} = \frac{ 2 \times 0.6 }{ 0.11698 } = 10.26 \ \Rightarrow \ \boxed{ 11 }
$$

**比未变位的17便宜六个齿，而代价是三重的。**齿顶变窄——$x = + 0.4$ 时12齿小齿轮的齿顶会出尖，除非削短齿顶高——配对齿轮必须变位 $- 0.4$ 否则中心距改变，而这一对再也不能用目录齿轮替换。**这就是变位制度有表格、有诺模图、有自己一套记号的原因，也是变位齿轮的图样上标注的是量柱距与跨 $k$ 齿公法线长度、而不是一个简单的分度圆直径的原因。**
:::
:::

::: exercise 干涉极限处的重合度 {level=2 check="1.44"}
计算一对标准齿制 $13 / 13$、$20^{\circ}$ 齿轮的端面重合度。结果宽裕吗？

::: solution
取单位模数，$r_1 = r_2 = 6.5$、$r_a = 7.5$、$r_b = 6.108$、$C = 13$：

$$
L = 2 \sqrt{ 7.5^{2} - 6.108^{2} } - 13 \times 0.34202 = 2 \times 4.352 - 4.446 = 4.258\ \mathrm{mm}
$$

$$
p_b = \pi \cos 20^{\circ} = 2.952\ \mathrm{mm} \qquad \Rightarrow \qquad m_p = \frac{ 4.258 }{ 2.952 } = \boxed{ 1.44 }
$$

**对比 [[#ex-crr]] 中 $20 / 40$ 副的1.635。**13齿齿轮不只是离干涉极限更近——它还噪12%、每齿多承12%的载荷，因为它把啮合循环的56%耗在单对齿接触上，而不是36%。**这正是变位本应解决、却常常弄得更糟的那笔交易：在12齿处为消除根切而变位，同时也缩短了啮合线。**设计师想要12齿小齿轮时，诚实的答案通常是接受15齿、加大模数，而不是为三个齿跟几何硬拼。
:::
:::

::: exercise 斜齿轮小齿轮的当量齿数 {level=1 check="15"}
一个斜齿轮小齿轮要求在 $\phi_n = 20^{\circ}$ 的齿条上、以 $20^{\circ}$ 螺旋角未变位切制。避免根切的最少齿数是多少？

::: solution
斜齿轮表现得像 $N_v = N / \cos^{3} \psi$ 齿的直齿轮，故避免根切要求 $N_v \ge 17.1$：

$$
N \ \ge \ 17.1 \cos^{3} 20^{\circ} = 17.1 \times 0.8214 = 14.19 \ \Rightarrow \ \boxed{ 15 }
$$

**比直齿当量少两个齿，而在一个40 mm中心距的齿轮箱里，这是一个设计与两个设计的差别。**注意这个放松*不是*什么：不是齿更强了，也不是接触更温和了——而是刀具在垂直于齿向的平面里看，是在一个*更大*的等效分度圆上生成曲线，而更大的等效分度圆离渐开线停止存在的基圆更远。**同样的推理也是 $25^{\circ}$ 压力角买到更多的原因：$\psi = 25^{\circ}$ 时答案是9齿，$\psi = 30^{\circ}$ 配 $25^{\circ}$ 齿条时是7齿——此时轴向推力已成了设计的全部。**
:::
:::

::: exercise 蜗杆效率与自锁边界 {level=1 check="0.77"}
一个蜗杆传动导程角 $12^{\circ}$，运转温度下摩擦因数 $0.06$。效率是多少？冷机 $\mu = 0.12$ 时它自锁吗？

::: solution
$$
\phi = \arctan 0.06 = 3.43^{\circ} \qquad \eta = \frac{ \tan 12^{\circ} }{ \tan \left( 12 + 3.43 \right)^{\circ} } = \frac{ 0.2126 }{ 0.2762 } = \boxed{ 0.77 }
$$

冷机时 $\phi = 6.84^{\circ}$、$\lambda + \phi = 18.84^{\circ}$，仍低于 $90^{\circ}$，所以**两种状态都不自锁。**自锁边界是 $\lambda < \phi$，即热态 $\lambda < 3.4^{\circ}$、冷态 $\lambda < 6.8^{\circ}$——注意陷阱的方向：**按热态自锁设计的蜗杆在冷态会更可靠地自锁，但按冷态不自锁留足余量设计的蜗杆，热态效率已经掉到 $\eta \approx 0.45$ 了。**唯一真正可靠的一句话是：任何蜗杆都不应被当作保持载荷的唯一手段，每一条起重机标准都这么说。
:::
:::

::: exercise 锥齿轮当量齿数 {level=1 check="28"}
一对 $1 : 1$ 直齿锥齿轮各20齿、压力角 $20^{\circ}$。一个20齿锥齿轮坯表现得像哪个直齿轮？这对刀盘号意味着什么？

::: solution
分锥半角 $\delta = 45^{\circ}$，当量齿数为

$$
N_v = \frac{ N }{ \cos \delta } = \frac{ 20 }{ 0.7071 } = 28.3 \ \Rightarrow \ \boxed{ 28 }
$$

**这稳稳高于17齿的干涉极限——这就是为什么锥齿轮几乎从不根切，而它们的直齿对应物却常常根切。**锥齿轮的当量分度圆是实际分度圆的 $\sqrt{2}$ 倍，所以齿坐在更大的等效圆上、离渐开线耗尽之处更远。实际推论就是那套老式八把一组、1号到8号的刀盘，其中3号刀盘覆盖当量 $21.5^{\circ}$ 到 $29^{\circ}$：**一把3号刀既切这副锥齿轮、也切一个28齿直齿轮，这正是该制度发明时想要的经济性，也正是渐开线使之不再必要的与传动比的绑定。**
:::
:::

::: quiz
两个齿轮模数相同、齿宽相同、材料与热处理相同，承受相同载荷。齿轮A有17齿，齿轮B有60齿，各自与同一个60齿齿轮啮合。哪个说法正确？

- [ ] 齿轮A的齿更弯，所以弯曲更弱
- [x] 齿轮A的接触应力更高、重合度更低，且离干涉极限更近——同样省直径，罚三笔
- [ ] 齿轮B更安静只是因为它更大
- [ ] 两者受力相同，因为模数相同

::: solution
三笔罚单全落在A上。接触应力按 $1 / \sqrt{ R }$ 走，而 $1 / R = 1 / ( r_1 \sin \phi ) + 1 / ( r_2 \sin \phi )$，所以小齿轮 $R$ 更小、$p_0$ 更高——同等载荷下 $17 / 60$ 对 $60 / 60$ 约为 $1\,530$ 对 $1\,290\ \mathrm{MPa}$。重合度是1.60对1.85。而17恰好压在未变位干涉极限上，60则远未接近。**尽管如此仍用小齿轮的原因是：机器里的一切都随中心距缩放——箱体、轴、轴承与质量。齿轮设计就是这笔交易的谈判，别无其他。**
:::
:::

::: quiz
一台齿轮箱以超出名义值 $0.15\ \mathrm{mm}$ 的中心距装配，实测侧隙在规格之内。这台装配应被接受吗？

- [ ] 接受——侧隙是规定的验收判据，且已满足
- [x] 不接受，或至少不查接触斑点不接受，因为侧隙可能是拿中心距换的，代价是重合度
- [ ] 接受，只要油位正确
- [ ] 不接受——任何正的中心距误差无论侧隙如何都应拒收

::: solution
由 [[#ex-centre]] 的表，这副齿轮 $\Delta C = + 0.15\ \mathrm{mm}$ 给出 $j \approx 0.23\ \mathrm{mm}$ 侧隙、$m_p \approx 1.55$（原值1.635）——**一个正确的侧隙掩盖了5%的重合度损失与 $0.5^{\circ}$ 的工作压力角上升。**正确的验收判据是受载下的**接触斑点**（涂色或压痕试验显示斑点在齿面居中、不在齿顶或齿根），以及**量柱距**或跨棒距，它直接度量齿厚。**侧隙是症状，不是属性：同一个实测侧隙，可能意味着正确中心距上切得正确的齿轮，也可能意味着错误中心距上切薄的齿轮，而只有斑点试验能区分两者。**
:::

## 后续内容

齿轮是本课程两半的交汇之处。[[mechanisms/position-analysis]] 与 [[mechanisms/velocity-analysis]] 的**运动学**讲的是东西在哪、跑多快；齿轮以构造一劳永逸地了结这个问题，用一个整数——齿数比——取代三角方程的解。[[mechanisms/acceleration-analysis]] 与 [[mechanisms/machine-dynamics]] 的**动力学**讲的是运动学蕴含的力；齿轮把设计生涯的大部分花在其中之一的力上：赫兹接触压力。

认真对待这一点，引出三件事。**弹流润滑**解释了 [[#ex-pit]] 里那 $1\,185\ \mathrm{MPa}$ 为何没有摧毁表面，为什么 $150^{\circ}\mathrm{C}$ 下一层 $2\ \mu\mathrm{m}$ 的油膜才是世界上每台齿轮箱真正的承力构件；油膜厚度的思想在 [[fluid-mechanics/fluid-properties]] 引入。**接触疲劳**解释同一表面为什么在 $10^{9}$ 循环而非 $10^{3}$ 循环失效，它归 [[materials-science/failure]] 管。**传递误差动力学**解释齿轮噪声——在汽车座舱里，噪声是与强度同等硬性的设计约束——它归 [[vibrations/harmonic-excitation]] 管。

而你真会被叫去处理的那次失效，发生在一台校核过、判定合格的齿轮箱上，齿面剥落了。事故就写在本课最后一张表里：接触斑点移动了。一根轴在设计估算为 $0.05$ 的载荷下挠了 $0.08\ \mathrm{mm}$，按第一档载荷算好的鼓形量对第二档载荷是错的，斑点爬到了 $70\ \mathrm{mm}$ 齿宽的边缘，局部压力翻倍。**齿轮不会因为平均应力太高而失效。它们失效，是因为应力并不平均。**

::: summary
- **齿廓啮合基本定律**要求接触处的公法线通过固定的节点；渐开线通过让公法线成为一条与两个基圆相切的固定直线做到这一点，而它赢得世界是因为它的生成元素是一条直线——这把刀具变成了一条齿条。
- 齿轮由模数 $m$、齿数 $N$、压力角 $\phi$ 定义。**两个齿轮啮合当且仅当基圆齿距 $\pi m \cos \phi$ 相等**——模数与压力角都得对上。
- **对齿条的最少齿数是 $N_{\min} = 2 / \sin^{2} \phi$**：$14.5^{\circ}$ 时31.9，$20^{\circ}$ 时17.1，$25^{\circ}$ 时11.2。低于它，齿轮不是弱，是被挖。变位买到约六个齿，代价是互换性与中心距公差。
- **重合度 $m_p = L / p_b$** 是同时啮合齿对数的平均值；直齿轮为1.4-1.9。低于1.0，这对齿轮就不是轮系了。每十分之一的重合度约值每齿载荷的十分之一和好几分贝。
- **中心距是齿轮箱里最紧的公差。**$+ 0.05\ \mathrm{mm}$ 损失二十分之一重合度；$+ 0.9\ \mathrm{mm}$ 损失30%，而在侧隙量规上看着完全合格。
- **弯曲是 $\sigma_F = W_t / ( b m Y )$，点蚀是 $p_0 = \sqrt{ W_t E^{*} / ( \pi b R ) }$。**调质工业齿轮，点蚀所需齿宽是弯曲的2-3倍。先校点蚀。
- **动载系数 $K_v$ 讲的是制造质量，不是速度。**磨齿买的是速度上限；$4\ \mathrm{m/s}$ 时质量6级只比质量12级差7%。
- **斜齿轮贡献无上界的轴向重合度 $m_F = b \sin \psi / ( \pi m_n )$，按 $\cos^{3} \psi$ 放松根切极限，并造出轴向推力 $W_t \tan \psi$**——它必须被承受、被人字齿轮抵消、或作为安静的代价被接受。
:::
