::: warning 精确执行你的要求的机构
四杆机构给你一条曲线，你事后才发现它是什么。凸轮给你指定的那条曲线，这就是为什么当运动本身是要求、而不是达成它的手段时，凸轮是首选机构——配气机构、印刷滚筒、针织机、装配分度器。这份自由有代价，而代价不是以设计时间支付的，是以**力**支付的。你如此潇洒画出的轮廓的每一毫米，都是一个必须以几百兆帕的赫兹接触压力、透过一层只有头发丝十分之一厚的油膜、在升程内变号两次的滑动速度下传递的表面，而且从动件只许被推、不许被拉。**凸轮是一个包在接触力学问题外面的几何问题，外面又包着一个振动问题，而几何是其中容易的那三分之一。**
:::

## 构造：四条曲线，不是一条

拿卡尺绕任何一个盘形凸轮走一圈，你会发现图纸上有四个不同的"半径"，而把它们混为一谈是凸轮设计中最常见的错误。

**基圆**是以轴心为圆心的、实际加工出的金属的最小圆。它是制造基准，是图纸公差标注的对象。

**理论基圆**是基圆加上从动件接触元件的半径——对半径为$r_r$的滚子从动件，

$$
r_p = r_b + r_r
$$

它是从动件位于基圆上时滚子*中心*描出的圆，也是支配压力角的那个量。对平底或尖顶从动件，$r_r = 0$，两个圆重合，这就是只讨论这两种从动件的教科书可以假装只有一个圆的原因。

**节曲线**是滚子中心相对凸轮的路径——*描迹点*的轨迹。它是你真正从位移规律算出的曲线，而对直动对心滚子从动件，它就是

$$
r(\theta) = r_p + s(\theta)
$$

**轮廓**（或*工作曲线*）是金属表面：所有滚子位置的包络，即节曲线向内偏移$r_r$。它是刀具跟随的曲线，也是发生根切的那条曲线。

::: definition 凸轮的四个圆 {#def-circles}
对基圆半径$r_b$、驱动半径$r_r$、位移$s ( \theta )$的滚子从动件的盘形凸轮，四条曲线是

$$
r_{\mathrm{base}} = r_b , \qquad r_{\mathrm{prime}} = r_p = r_b + r_r , \qquad r_{\mathrm{pitch}} ( \theta ) = r_p + s ( \theta ) , \qquad r_{\mathrm{profile}} = \text{节曲线向内偏移} r_r
$$

基圆与轮廓是你要切出来的几何；理论基圆与节曲线是你要计算的几何。**对尖顶或平底从动件，$r_r = 0$，四条曲线塌缩成两条**，这就是初等教程里的对象似乎比真凸轮少的原因。
:::

::: example 是哪个半径？ {#ex-anatomy}
一张凸轮图纸标注基圆直径$\varnothing 40\ \mathrm{mm}$、直径$18\ \mathrm{mm}$的滚子从动件、最大升程$16\ \mathrm{mm}$。加工件上任何位置的最大半径是多少？*节*曲线的最大半径是多少？

**答案。**节曲线的最大半径是$r_p + h = (20 + 9) + 16 = 45\ \mathrm{mm}$。加工轮廓的最大半径是基圆加升程，$20 + 16 = 36\ \mathrm{mm}$——小九毫米，因为轮廓是把节曲线按滚子半径拉回来的结果。

::: solution
这两个数在每个角度恰好相差$r_r$，但它们的*曲率半径*不是：轮廓的曲率在凸侧是$\rho_{\mathrm{pitch}} - r_r$、在凹侧是$\rho_{\mathrm{pitch}} + r_r$，而决定刀具能否到达表面的正是曲率而不是半径。对机加工人员说"最大半径"而不说明是哪条曲线的，会得到一个在滚子接触的一切方向上都小九毫米的零件。
:::
:::

## 分类，以及每个选择的代价

| 族 | 接触 | 能推？ | 能拉？ | 磨损 | 用途 |
|---|---|---|---|---|---|
| 盘形，尖顶 | 点 | 是 | 否 | 严重 | 仅方案研究 |
| 盘形，滚子 | 线 | 是 | 否 | 中等 | 默认选择 |
| 盘形，平底 | 线/面 | 是 | 否 | 低 | 高速，不反转 |
| 盘形，球面（共轭雨刷式） | 面 | 是 | 否 | 低 | 平底会犁伤之处 |
| 端面凸轮 | 线 | 是 | 是 | 中等 | 两轴运动，分度 |
| 圆柱（鼓形）凸轮 | 线 | 是 | 是 | 中等 | 短空间内大位移 |
| 共轭（双）凸轮 | 线 | 是 | 是 | 低 | 精密，无需弹簧 |
| 开槽（预紧）凸轮 | 线 | 是 | 是 | 低 | 双滚子承载的从动件 |

**那张表里后果最严重的一栏是"能拉？否"。**弹簧封闭的从动件只能被推，所以循环中从动件想要背离凸轮加速的每一段，都是接触力正在跌向零的一段，而失去接触的凸轮不再有几何。**端面和圆柱凸轮可以做出两侧工作面，因而可以拉**，这就是分度鼓轮和印刷机递纸牙凸轮做成那样的原因，也是它们能比外表结实得多的弹簧封闭盘形凸轮转得更快的原因。

**力封闭与形封闭。**弹簧封闭的凸轮是*力封闭*的：只要弹簧还占上风，几何才有权威。共轭或雨刷式凸轮是*形封闭*的：几何永远有权威，代价是第二个接触必须预紧消除间隙，而这是一笔要用钱和对热膨胀的敏感度来付的公差链。

::: quiz
一台带平底从动件的盘形凸轮高速运转。设计者被告知从动件在升程末端跳离轮廓。把从动件换成等质量的滚子就解决了。为什么？

- [ ] 滚子的接触面积更小，因此接触压力更低
- [x] 平底根本无法跟随凹轮廓，所谓"跳离"是平底在一张它从未完全贴合过的表面上失去了一条边
- [ ] 滚子消除了滑动，而滑动才是跳离的原因
- [ ] 滚子增大了理论基圆半径，因此降低了压力角

::: solution
半对的答案是危险的那种。滚子确实降低了压力角，也确实没有消除滑动——滚子仍有少量蠕滑，更重要的是*从动件*仍在导轨里滑动。实际发生的是：平底从动件的接触要求是$\rho = r_0 + s + s'' > 0$，该式失效之处凸轮轮廓有一个平底架空的拐点：它两点接触或一条边接触，而"跳离"是一个冒充动力学失效的几何失效。有限半径的滚子可以跟随凹面——直到凹侧曲率半径小于滚子自己的半径为止。
:::
:::

## 位移线图就是设计

凸轮的一切都由一张图决定：升程对凸轮角。轮廓、力、应力、速度极限和失效模式全从它读出来。它首先必须检查的是**哪个导数连续**。

$$
s = h f ( x ) , \quad x = \frac{\theta}{\beta} , \qquad
v = \frac{h \omega}{\beta} f' ( x ) , \qquad
a = \frac{h \omega^{2}}{\beta^{2}} f'' ( x ) , \qquad
j = \frac{h \omega^{3}}{\beta^{3}} f''' ( x )
$$

四个无量纲系数$k_v , k_a , k_j$是$f', f'', f'''$的峰值，它们承载着运动规律的全部设计内容。

| 规律 | $f ( x )$ | $k_v$ | $k_a$ | $k_j$ | 首个不连续导数 |
|---|---|---|---|---|---|
| 等速 | $x$ | 1.000 | 0 | $\infty$ | 加速度，两端 |
| 抛物线 | $2x^{2}$，$1 - 2 ( 1 - x )^{2}$ | 2.000 | 4.000 | $\infty$ | 跃度，三点 |
| 简谐 | $\tfrac{1}{2} \left( 1 - \cos \pi x \right)$ | 1.571 | 4.935 | $\infty$ | 加速度，两端 |
| 摆线 | $x - \dfrac{\sin 2 \pi x}{2 \pi}$ | 2.000 | 6.283 | 39.48 | 跃度，两端 |
| 3-4-5多项式 | $3x^{2} - 2x^{3}$ | 1.500 | 6.000 | 12.0 | 加速度，两端 |
| 4-5-6-7多项式 | $35x^{4} - 84x^{5} + 70x^{6} - 20x^{7}$ | 2.188 | **7.513** | 52.50 | 无——$C^{3}$ |
| 5-6-7-8-9多项式 | $126x^{5} - 420x^{6} + 540x^{7} - 315x^{8} + 70x^{9}$ | 2.461 | 9.372 | 78.75 | 无——$C^{3}$ |
| 改进正弦 | 八段拼接 | 1.761 | 5.189 | 33.5 | 跃度，八点 |

::: exercise 推导：为什么多项式族是$C^{3}$的 {#deriv-continuity level=3}
两端接停歇的升程必须满足六个条件：归一化后$f , f' , f''$在$x = 0$处等于$0 , 0 , 0$，在$x = 1$处等于$1 , 0 , 0$。这是一端六个齐次条件、另一端三个，所以$n$次多项式需要$n + 1$个系数$\ge 6$，即3-4-5规律要求$n \ge 5$、4-5-6-7规律要求$n \ge 7$。

**3-4-5规律**$f = 3x^{2} - 2x^{3}$满足$f ( 0 ) = f ( 1 ) = 0$、$f' ( 0 ) = f' ( 1 ) = 0$——即两端斜率为零，这正是停歇所要求的——但$f'' ( 0 ) = 6 \ne 0$，所以加速度在升程开始的那一瞬*跳变*，从零跳到$6 h \omega^{2} / \beta^{2}$。跃度在内部恒为$- 12$，在端部无穷。

**4-5-6-7规律**额外满足$f'' ( 0 ) = f'' ( 1 ) = 0$，所以加速度从零开始、到零结束，跃度处处有限，在$x = 0.5$处峰值$k_j = 52.5$。它的代价在表里看得见：$k_a$从$6.00$升到$7.51$，**峰值加速度高百分之二十五**；$k_v$从$1.50$升到$2.19$，**峰值速度高百分之四十六**。

::: solution
**因此这笔权衡是明摆着的，而且不免费：**拼接处的光滑是用内部更高的峰值买的。这笔权衡在高速下通常划算，原因是3-4-5规律的无穷跃度是一个力的阶跃，而力的阶跃含有从动件自身固有频率所能响应的一切谐波。
:::
:::

::: quiz
一个凸轮必须在$90^{\circ}$内升$30\ \mathrm{mm}$，而机床以不能更改的固定转速运转。设计者把摆线规律换成4-5-6-7多项式，希望减小从动件峰值加速度。结果如何？

- [ ] 峰值加速度下降约百分之二十
- [x] 峰值加速度上升约百分之二十，峰值速度上升约百分之九
- [ ] 什么都不变，因为两个规律升程相同、角度相同
- [ ] 峰值加速度下降，但跃度变成无穷

::: solution
$7.513 / 6.283 = 1.196$。选4-5-6-7多项式是为了它的**有限跃度**——这对接触疲劳和噪声重要——不是为了它的加速度。如果约束是从动件跳离，多项式就是走错了方向：改进正弦的$k_a = 5.19$或抛物线规律的$4.00$更好，而两者都在别处付出代价。
:::

::: example 哪个规律，哪台机器 {#ex-lawchoice}
四个凸轮，都在同样的$120^{\circ}$内升同样的$20\ \mathrm{mm}$，都在同样的$600\ \mathrm{rev / min}$下，装在四台不同的机器上：一台使纱管穿过线环的针织机；一条给液体瓶子分度的包装线；一台把纸张送过轧点的印刷机递纸牙；一台把$20\ \mathrm{mm}$带钢送进模具的冲床送料器。哪个运动规律配哪台？

**答案。**先算公共比例因子：$\omega = 62.83\ \mathrm{rad / s}$，$\omega / \beta = 30.0\ \mathrm{s^{- 1}}$，于是$v_{\max} = 0.6 \, k_v\ \mathrm{m / s}$，$a_{\max} = 18 \, k_a\ \mathrm{m / s^{2}}$。

| 机器 | 疼在哪里 | 规律 | $k_a$ | $a_{\max}$ |
|---|---|---|---|---|
| 针织机 | 纱线张力跟随加速度；跃度阶跃会拉断纱 | 4-5-6-7 | 7.51 | $135\ \mathrm{m / s^{2}}$ |
| 瓶子分度 | 液体会晃；$0.2\ g$是泼洒限值 | 5-6-7-8-9，两步 | 9.37 | $169\ \mathrm{m / s^{2}}$——**但**在更长的角度上，所以真实数字由泼洒限值决定，不由规律决定 |
| 冲床送料 | 带钢惯性与必须在$2\ \mathrm{ms}$内卸掉的$1.5\ \mathrm{kN}$夹紧力 | 改进正弦 | 5.19 | $93\ \mathrm{m / s^{2}}$ |
| 递纸牙 | 形封闭，飞脱无关紧要；纸张自己的重量才是 | 摆线 | 6.28 | $113\ \mathrm{m / s^{2}}$ |

:::

## 压力角：凸轮的传动角

::: definition 压力角 {#def-psi}
凸轮的**压力角**$\psi$是接触点处两表面的公法线——凸轮施力的方向线——与从动件允许运动的方向之间的夹角。其余角$90^{\circ} - \psi$就是[[mechanisms/mechanisms-mobility]]中的传动角。对直动滚子从动件，

$$
\tan \psi = \frac{d s / d \theta - e}{\sqrt{r_b^{2} - e^{2}} + s + r_r}
$$

其中$e$是从动件偏距。导轨上的侧向推力是$F \tan \psi$，机械效率是$\left( 1 - \mu \tan \psi \right) / \left( 1 + \mu \tan \psi \right)$。
:::

压力角$\psi$是凸轮施力方向与从动件允许运动方向之间的夹角。它的余角是[[mechanisms/mechanisms-mobility]]的传动角换了个名字，并服从同一条规则：别让它进危险区，否则机构会卡死。

对偏距为零的直动滚子从动件，推导只要两行。接触法线过滚子中心并垂直于节曲线，所以

$$
\tan \psi = \frac{d r / d \theta}{r} = \frac{d s / d \theta}{r_p + s}
$$

而带偏距$e$、以正$e$抵抗升程的方向为正时，

$$
\boxed{ \; \tan \psi = \frac{d s / d \theta - e}{\sqrt{r_b^{2} - e^{2}} + s + r_r} \; }
\qquad
r = \sqrt{ \left( \sqrt{r_b^{2} - e^{2}} + s + r_r \right)^{2} + \left( \frac{d s}{d \theta} - e \right)^{2} }
$$

**立刻有两点推论，而且都是设计杠杆。**第一，$\psi$在$d s / d \theta$最大*且*$s$还小的地方最大——对对称规律这是升程中段，不是端部。第二，理论基圆半径$r_p$独自出现在分母里，所以**减小压力角唯一真正的办法是把凸轮做大**，其他一切花招都是权衡。

::: widget plot
f: atan(8.8126/(x+4.5))*180/pi
x: 12, 40
y: 5, 35
caption: $9\ \mathrm{mm}$升程、$128^{\circ}$、4-5-6-7规律的峰值压力角随理论基圆半径的变化。**曲线是$1 / r$，没有任何办法把它压平**——把$\tan \psi$从$25^{\circ}$降到$11^{\circ}$意味着把$r_p$从$14.4\ \mathrm{mm}$取到$40\ \mathrm{mm}$，那是直径两倍多、自身轴上惯量八倍的凸轮。**$25^{\circ}$线在$r_p = 14.4\ \mathrm{mm}$处被穿过，而这个凸轮的全部尺寸计算就是这一句。**
:::

**许用限值。**通常的许用值是直动从动件升程$\psi \le 25^{\circ}$、回程$\psi \le 35^{\circ}$，摆动从动件因侧向推力较小可到$\psi \le 45^{\circ}$。它们不是刚度限值，而是**侧向推力与效率**限值：导轨上的侧向力是$F \tan \psi$，它造成的摩擦力是$\mu F \tan \psi$，所以凸轮的机械效率是

$$
\eta = \frac{1 - \mu \tan \psi}{1 + \mu \tan \psi} \qquad \Rightarrow \qquad \eta = 0.53 \ \text{当} \ \psi = 25^{\circ} , \ \mu = 0.15
$$

**在设计压力角下，你输入凸轮的一半功丢在导轨里。**这不是不惜代价追求小压力角的论据；它是导轨长、用滚动轴承的凸轮可以跑到$30^{\circ}$、而轴套里的凸轮不能的原因。

::: example 偏距不是免费的 {#ex-offset}
下面算例中的气门凸轮在开启侧$s = 4.5\ \mathrm{mm}$处有$\left( d s / d \theta \right)_{\max} = 8.81\ \mathrm{mm / rad}$，在关闭侧同一升程处有$- 8.68\ \mathrm{mm / rad}$，$r_p = 24\ \mathrm{mm}$。一位工程师提议加$3\ \mathrm{mm}$偏距来减小压力角。

**答案。**开启侧取有利的符号，

$$
\tan \psi_{\mathrm{open}} = \frac{8.81 - 3.00}{24 + 4.5} = 0.2039 \ \Rightarrow \ \psi = 11.5^{\circ} \quad \text{对比} \quad \tan^{-1} \frac{8.81}{28.5} = 17.2^{\circ}
$$

关闭侧$d s / d \theta$符号相反，同一个偏距现在变成*相加*：

$$
\tan \psi_{\mathrm{close}} = \frac{| - 8.68 - 3.00 |}{28.5} = 0.4098 \ \Rightarrow \ \psi = 22.3^{\circ}
$$

::: solution
偏距把峰值从一侧工作面搬到另一侧，而且在一个方向上把最坏情形变坏的幅度大于在另一个方向上改善的幅度：$17.2^{\circ}$和$16.9^{\circ}$变成了$11.5^{\circ}$和$22.3^{\circ}$。**偏距是给两侧工作面本来就不对称的凸轮用的杠杆**——对开启角短、关闭角长的气门凸轮正是如此——**而对对称凸轮则是一笔负债。**偏距还把作用线移离导轨中心线，这要占布置空间，并在从动件杆上施加一个对称布置所没有的弯矩。
:::
:::

## 根切：轮廓切不出来的时候

::: definition 根切 {#def-undercut}
在节曲线曲率半径$\rho$小于滚子半径$r_r$之处，向内偏移$r_r$会自交、轮廓出现尖点，滚子从动件凸轮就**根切**了。形式化地，记$r = r_p + s$，$r' = d s / d \theta$，$r'' = d^{2} s / d \theta^{2}$，

$$
\rho = \frac{ \left[ r^{2} + r'^{2} \right]^{3 / 2} }{ r^{2} + 2 r'^{2} - r r'' } \qquad \text{要求是} \qquad \rho > r_r \ \ \text{只要} \ \ r^{2} + 2 r'^{2} - r r'' > 0
$$

对平底从动件，相应的要求是$r_0 + s + d^{2} s / d \theta^{2} > 0$处处成立。**根切是凸侧现象**：在节曲线的凹段，轮廓半径是$\left| \rho \right| + r_r$，比节半径大，什么也不会出尖。
:::

轮廓是节曲线向内偏移滚子半径。把一条曲线向内偏移超过它自己的曲率半径，它就会自交，而按图纸加工的机床会在本应实心的表面上切出一道沟。凸轮于是有了一个**尖点**：滚子骑在锋利的棱角上而不是设计好的表面上，升程偏离位移线图，而在高速下这个棱角是一个几小时就疲劳的应力集中源。

对径向往复滚子从动件，节曲线的带符号曲率半径是

$$
\rho = \frac{ \left[ r^{2} + \left( r' \right)^{2} \right]^{3 / 2} }{ r^{2} + 2 \left( r' \right)^{2} - r r'' } , \qquad r = r_p + s , \quad r' = \frac{d s}{d \theta} , \quad r'' = \frac{d^{2} s}{d \theta^{2}}
$$

轮廓在下列条件成立处是健全的：

$$
\phi = \rho - r_r > 0 \qquad \text{只要} \qquad r^{2} + 2 \left( r' \right)^{2} - r r'' > 0
$$

右边这个条件把检验限制在节曲线的**凸**段。在凹段$\rho$为负，轮廓半径是$\left| \rho \right| + r_r$——*更大*而不是更小——这就是滚子能跟住山谷、却跟不住同样弯曲的山脊的原因。**根切是凸侧现象。**

对**平底从动件**，轮廓曲率半径塌缩成一个漂亮简单的表达式，因为平底是一族直线而不是圆的包络：

$$
\boxed{ \; \rho_{\mathrm{profile}} = r_0 + s + \frac{d^{2} s}{d \theta^{2}} \; } \qquad \text{以及} \qquad \ell_{\mathrm{face}} = \left| \frac{d s}{d \theta} \right|_{\max} \times 1.25
$$

第一个必须处处为正，否则平底会架空一个凹腔、只在其边缘接触；第二个说的是从动件端面必须多宽，因为接触点会沿底面游走$\pm d s / d \theta$。

::: example 做不出来的平底从动件 {#ex-flatface}
**规范。**$h = 20\ \mathrm{mm}$，$\beta = 60^{\circ}$，3-4-5多项式，滚子或平底从动件。

**压力角。**$\left( d s / d \theta \right)_{\max} = k_v h / \beta = 1.5 \times 20 / 1.0472 = 28.65\ \mathrm{mm / rad}$，在$s = 10\ \mathrm{mm}$处。要$\psi \le 25^{\circ}$：

$$
r_p \ge \frac{28.65}{\tan 25^{\circ}} - 10 = 61.4 - 10 = 51.4\ \mathrm{mm}
$$

**滚子从动件，根切检验。**取$r_p = 51.4\ \mathrm{mm}$、$r_r = 10\ \mathrm{mm}$，最小凸侧节半径在$x = 1$处为$28.2\ \mathrm{mm}$，所以$\phi_{\min} = 18.2\ \mathrm{mm} > 0$。**健全。**凸轮最宽处$\varnothing 123\ \mathrm{mm}$。

**平底从动件，犁伤检验。**$\rho = r_0 + s + s''$，其中$s''_{\min} = - k_a h / \beta^{2} = - 6.00 \times 20 / 1.0966 = - 109.4\ \mathrm{mm}$，在$x = 1$处，那里$s = 20\ \mathrm{mm}$：

$$
r_0 > 109.4 - 20 = 89.4\ \mathrm{mm}
$$

而平底半宽必须是$1.25 \times 28.65 = 35.8\ \mathrm{mm}$。

::: solution
**平底需要一个$\varnothing 219\ \mathrm{mm}$的凸轮，来干滚子在$\varnothing 123\ \mathrm{mm}$上就能干的事——而它在这个尺寸下的压力角只有$16^{\circ}$，多出来的体积什么也没买到。**原因在两个公式里：压力角由$d s / d \theta$决定，它是$28.65\ \mathrm{mm}$；犁伤判据由$d^{2} s / d \theta^{2}$决定，它是$109.4\ \mathrm{mm}$——大四倍，因为$60^{\circ}$的角很短，而曲率按$1 / \beta^{2}$缩放、斜率只按$1 / \beta$缩放。
**这条一般规律是：**平底从动件在平缓、长角的升程上是*快*的从动件，那里它零滚子半径的运动学和低赫兹应力值得拥有；而在短促、尖锐的升程上它是*最坏*的从动件，那里$1 / \beta^{2}$项占主导，凸轮必须一直长大到比滚子凸轮还大。
:::
:::

## 尺寸计算流程

凸轮设计是一个定点迭代，而它两三轮就收敛，因为约束对$r_p$单调。

| 步骤 | 你做什么 | 可能失败之处 |
|---|---|---|
| 1 | 排出循环：升程、停歇、回程、停歇，以凸轮度计。总和必须是$360^{\circ}$ | 工艺需要的停歇不够 |
| 2 | 按$k_v , k_a , k_j$表为每段选运动规律 | 峰值加速度对弹簧太高 |
| 3 | 由$\psi_{\max}$定$r_p$ | 凸轮装不进包络空间 |
| 4 | 检验$\phi_{\min} > r_r$（滚子）或$\rho > 0$（平底） | 根切——增大$r_p$或放缓规律 |
| 5 | 计算$a_{\max}$，再把$m a_{\max}$与该升程处的弹簧力对比 | **凸轮飞脱**——常见的杀手 |
| 6 | 计算峰值接触力与赫兹应力 | 表面疲劳，磨损 |
| 7 | 检验从动件固有频率对激励 | 共振，噪声，配气机构振浪 |
| 8 | 数值生成轮廓，加上公差链，加工 | 刀具半径大于$\phi_{\min}$ |

**注意步骤5排在几何之后、应力之前，而实践中正是步骤5把你送回步骤2。**凸轮的几何几乎总是可行的；力历程常常不是。

## 算例：顶置凸轮轴的气门桃

**规范。**四冲程四缸发动机，双顶置凸轮轴，每缸四个气门，额定$6000\ \mathrm{rev / min}$，红线$6600\ \mathrm{rev / min}$。凸轮轴以曲轴半速转动。一个桃必须在$128^{\circ}$凸轮角内开启$h = 9.0\ \mathrm{mm}$的气门升程、全升程保持$102^{\circ}$、再用$130^{\circ}$关闭——合计$360^{\circ}$。配气机构是滚杯式，$18\ \mathrm{mm}$滚子、$14\ \mathrm{mm}$宽，基圆半径$15\ \mathrm{mm}$。配气机构的有效往复质量$m = 0.24\ \mathrm{kg}$，气门弹簧$k = 32\ \mathrm{N / mm}$，关闭座位上的安装载荷$200\ \mathrm{N}$。

**第1步——循环与规律。**$128 + 102 + 130 = 360^{\circ}$ ✓。两侧工作面都用4-5-6-7多项式：气门凸轮是一个$C^{3}$问题，因为跃度阶跃就是力阶跃，而力阶跃正是让配气机构尖叫的东西。

**第2步——运动学。**$\omega = 6000 \pi / 120 = 314.16\ \mathrm{rad / s}$（凸轮，不是曲轴）。

$$
\frac{\omega}{\beta_1} = \frac{314.16}{2.2340} = 140.63\ \mathrm{s^{-1}} \qquad \frac{\omega}{\beta_2} = \frac{314.16}{2.2689} = 138.46\ \mathrm{s^{-1}}
$$

| | 开启 | 关闭 |
|---|---|---|
| $v_{\max} = k_v h \omega / \beta$ | $2.77\ \mathrm{m / s}$ | $2.73\ \mathrm{m / s}$ |
| $a_{\max} = k_a h \omega^{2} / \beta^{2}$ | $1339\ \mathrm{m / s^{2}} = 137\ g$ | $1297\ \mathrm{m / s^{2}} = 132\ g$ |
| $j_{\max} = k_j h \omega^{3} / \beta^{3}$ | $1.31 \times 10^{6\,} \mathrm{m / s^{3}}$ | $1.25 \times 10^{6\,} \mathrm{m / s^{3}}$ |

**第3步——压力角。**$\left( d s / d \theta \right)_{\max} = 2.1875 \times 9.0 / 2.2340 = 8.81\ \mathrm{mm / rad}$，在$s = 4.5\ \mathrm{mm}$处，$r_p = 15 + 9 = 24\ \mathrm{mm}$：

$$
\tan \psi = \frac{8.81}{24 + 4.5} = 0.309 \ \Rightarrow \ \boxed{ \psi_{\max} = 17.2^{\circ} } \quad \text{开启}, \qquad 16.9^{\circ} \ \text{关闭}
$$

轻松在$25^{\circ}$之内。理论基圆可以缩到$14.4\ \mathrm{mm}$才碰限值——但请看步骤4。

**第4步——根切。**最小凸侧节曲线半径在开启段$x = 0.692$处为$\rho = 22.5\ \mathrm{mm}$，所以$\phi_{\min} = 22.5 - 9 = 13.5\ \mathrm{mm} > 0$。**健全，而且裕度很宽**：滚子长到$22\ \mathrm{mm}$轮廓才会出尖。4-5-6-7规律在这里挣到了它的饭钱——因为$f'' ( 0 ) = 0$，桃尖的轮廓是一段干净的$r_b$半径圆弧，而不是简谐规律留下的反曲犁伤。

**第5步——接触力与凸轮飞脱。**从动件方程是$m \ddot{s} = F_c - F_s$，所以

$$
F_c ( \theta ) = \underbrace{F_0 + k s ( \theta )}_{\text{弹簧}} + \underbrace{m \ddot{s} ( \theta )}_{\text{惯性，带符号}}
$$

| 凸轮角 | $s$ (mm) | $\ddot{s}$ (m/s²) | 弹簧 (N) | 惯性 (N) | $F_c$ (N) |
|---|---|---|---|---|---|
| $0^{\circ}$ 座位 | 0 | 0 | 200 | 0 | 200 |
| $38.4^{\circ}$ | 1.60 | $+1330$ | 251 | $+319$ | **553**（峰值） |
| $64^{\circ}$ 升程中点 | 4.50 | 0 | 344 | 0 | 344 |
| $89.6^{\circ}$ | 7.96 | $-1326$ | 455 | $-319$ | **135**（最小值） |
| $128^{\circ}$–$230^{\circ}$ 停歇 | 9.00 | 0 | 488 | 0 | 488 |
| $266^{\circ}$ | 8.12 | $-1288$ | 460 | $-309$ | 151 |

最小接触力是开启侧$89.6^{\circ}$处的$135\ \mathrm{N}$。凸轮飞脱始于这个数字到达零之处，而惯性项按$N^{2}$增长、弹簧项不增长，

$$
N_{\mathrm{float}} = 6000 \sqrt{ \frac{454.6}{318.9} } = 7163\ \mathrm{rev / min}
$$

**对比$6600\ \mathrm{rev / min}$的红线——裕度$8.5\ \%$。**这是量产发动机正常、健康的裕度。在$5000\ \mathrm{rev / min}$以下弹簧显得粗暴地过刚；它整个就是为最后$1600\ \mathrm{rev / min}$存在的。

x: 5000, 8000
y: -200, 350
caption: 配气机构最小接触力对**曲轴**转速的曲线。**曲线在$7163\ \mathrm{rev / min}$处穿过零，而形状就是全部故事：它是转速的开口向下抛物线，所以转速范围最后百分之十五吃掉了三分之二的裕度。** **把弹簧刚度翻倍会把交点推到$9500\ \mathrm{rev / min}$，代价是$488\ \mathrm{N}$的座位载荷、两倍的凸轮基圆磨损，以及一根装不进$18\ \mathrm{mm}$弹簧中心距的弹簧。**

**第6步——赫兹应力。**$553\ \mathrm{N}$的峰值力出现在$38.4^{\circ}$，那里节曲线半径为$50.1\ \mathrm{mm}$，所以轮廓是凸的、$\phi = 41.1\ \mathrm{mm}$。把接触当作两个圆柱，

$$
\frac{1}{R} = \frac{1}{9.0} + \frac{1}{41.1} \ \Rightarrow \ R = 7.38\ \mathrm{mm} , \qquad \frac{1}{E^{*}} = \frac{1 - \nu_{1}^{2}}{E_1} + \frac{1 - \nu_{2}^{2}}{E_2} = \frac{2 \times 0.91}{207\,000} \ \Rightarrow \ E^{*} = 113.7\ \mathrm{GPa}
$$

$$
p_0 = \sqrt{ \frac{F E^{*}}{\pi b R} } = \sqrt{ \frac{553 \times 113\,700}{\pi \times 14 \times 7.38} } = \boxed{ 439\ \mathrm{MPa} } , \qquad a = \sqrt{ \frac{4 F R}{\pi b E^{*}} } = 0.057\ \mathrm{mm}
$$

一条$0.114\ \mathrm{mm}$宽的接触带承受$553\ \mathrm{N}$——凸轮桃表面每平方毫米总共半牛顿，一遍又一遍，每分钟两千次。最大切应力是$0.30 p_0 = 132\ \mathrm{MPa}$，位于表面以下$0.78 a = 0.044\ \mathrm{mm}$处，这就是凸轮钢的硬化层深度取$0.3$–$0.8\ \mathrm{mm}$、不再更深的原因：**硬化层深到足以吞下切应力泡，一点不多，因为凸轮桃上过深的硬化层是软芯外面的一层脆壳，会剥落。**

**第7步——气门弹簧振浪。**弹簧丝径$d = 3.35\ \mathrm{mm}$，中径$D = 18\ \mathrm{mm}$，有效圈数$n = 6.5$，得$k = G d^{4} / ( 8 D^{3} n ) = 32.8\ \mathrm{N / mm}$，质量$25.4\ \mathrm{g}$。其一阶纵向固有频率是

$$
f_1 = \frac{1}{4} \sqrt{ \frac{k}{m_s} } = \frac{1}{4} \sqrt{ \frac{32\,800}{0.0254} } = 284\ \mathrm{Hz}
$$

凸轮在额定转速下转$50\ \mathrm{Hz}$，所以其五次谐波在$250\ \mathrm{Hz}$——距弹簧自身一阶振型$12\ \%$以内。**在$7163\ \mathrm{rev / min}$的飞脱转速下，五次谐波在$299\ \mathrm{Hz}$，已高于一阶振型。**所以配气机构几乎恰好在停止接触的那个转速上停止了"刚体从动件"问题：**凸轮飞脱与弹簧振浪结伴而来，而这个巧合才是钢弹簧配气机构真正的天花板。**超过它，选项不是更好的弹簧而是不同的原理——强制式（desmodromic）回位，或1989年以来取代一级方程式气门弹簧的气压弹簧——后者根本没有固有频率，因为它上面没有质量。

**第8步——凸轮转矩。**由虚功原理，瞬时转矩为$T = F_c \, d s / d \theta$，在$51.5^{\circ}$处峰值$3.82\ \mathrm{N \cdot m}$，在$307.5^{\circ}$处反向峰值$- 3.72\ \mathrm{N \cdot m}$，每个桃的均方根值$1.60\ \mathrm{N \cdot m}$。**一个循环的净功除摩擦外为零**——弹簧是理想储能器——所以凸轮轴驱动看到的是每桃$\pm 4\ \mathrm{N \cdot m}$的纯转矩脉动，每个发动机循环十六次，这是凸轮轴驱动在发动机五次谐波阶次上的扭转激励，也是凸轮轴相位器棘轮成为保养项目的原因。

## 生成轮廓

节曲线的一切意义在于：它是你计算的曲线，而轮廓是你切出的曲线。对直动对心滚子从动件盘形凸轮，令$X ( \theta ) = r_p + s ( \theta )$。滚子中心描出

$$
C ( \theta ) = \left( X \cos \theta , \; X \sin \theta \right)
$$

而轮廓是沿该曲线 内法线方向距离$r_r$的偏移。求导，切线为$\left( X' \cos \theta - X \sin \theta , \; X' \sin \theta + X \cos \theta \right)$，其中$X' = d s / d \theta$；把它旋转$90^{\circ}$并归一化就得到 内单位法线。于是

::: exercise 推导：轮廓作为数控路径 {#deriv-profile level=3}
证明直动对心滚子从动件盘形凸轮的轮廓为

$$
\boxed{ \;
\begin{aligned}
X_{\mathrm{prof}} &= X \cos \theta - r_r \, \frac{X' \sin \theta + X \cos \theta}{\sqrt{X^{2} + X'^{2}}} \\[4pt]
Y_{\mathrm{prof}} &= X \sin \theta + r_r \, \frac{X' \cos \theta - X \sin \theta}{\sqrt{X^{2} + X'^{2}}}
\end{aligned} \;}
$$

并用两个平凡情形检验：$\theta = 0$且$X' = 0$，以及任意$\theta$且$r_r = 0$。

::: solution
切矢为$\mathbf{t} = \left( X' \cos \theta - X \sin \theta , \; X' \sin \theta + X \cos \theta \right)$，$\left| \mathbf{t} \right| = \sqrt{X'^{2} + X^{2}}$。把$\mathbf{t}$旋转$- 90^{\circ}$得$\left( t_y , - t_x \right) = \left( X' \sin \theta + X \cos \theta , \; - X' \cos \theta + X \sin \theta \right)$；在$\theta = 0$、$X' = 0$处它是$\left( X , 0 \right)$，指向*外侧*，所以 内法线是它的负。从$C$减去 外单位法线的$r_r$倍即得上面两行。

**检验。**$\theta = 0$、$X' = 0$时：$X_{\mathrm{prof}} = X - r_r = r_p + s - r_r = r_b + s$且$Y_{\mathrm{prof}} = 0$——轮廓位于基圆加升程处，正该如此。$r_r = 0$时轮廓塌缩到节曲线上，那就是尖顶从动件。**通不过这两个检验的公式有符号错误，而这个公式里的符号错误是凸轮报废的头号单一原因。**
:::
:::

## 润滑：凸轮运行在所能有的最坏状态

凸轮接触是一个弹流润滑（EHL）接触对：滚子与桃面把对方弹性压平，其间的油在如此压力下变成玻璃态固体，而隔开承受半吉帕载荷两个表面的油膜**只有三百纳米厚**——比它 本该保护的磨削纹理还薄。

线接触的道森-希金森（Dowson–Higginson）最小油膜方程，

$$
\frac{h_{\min}}{R} = 3.63 \, U^{0.68} G^{0.49} W^{-0.073} , \qquad
U = \frac{\eta_0 u}{E^{*} R} , \quad G = \alpha E^{*} , \quad W = \frac{F}{E^{*} R L}
$$

其中$\eta_0$为常压黏度，$u$为滚动速度，$\alpha \approx 2.2 \times 10^{- 8}\ \mathrm{Pa^{- 1}}$为矿物油的压黏系数，对气门桃在峰值力点给出：

| 量 | 值 | 注记 |
|---|---|---|
| $u = \omega \sqrt{X^{2} + X'^{2}}$ | $8.17\ \mathrm{m / s}$ | 滚子中心速度，本质上是纯滚动 |
| $U$ | $7.8 \times 10^{- 11}$ | 极低——速度不大而模量巨大 |
| $G$ | $2\,500$ | 矿物油的正常值 |
| $W$ | $4.7 \times 10^{- 5}$ | 对如此小的接触对是重载 |
| $h_{\min}$ | $0.34\ \mu\mathrm{m}$ | |
| $\lambda = h_{\min} / R_q$ | $1.1$ | **混合润滑** |

**$\lambda \approx 1$意味着微凸体在接触。**磨削的凸轮桃$R_q \approx 0.3\ \mu\mathrm{m}$，而$0.34\ \mu\mathrm{m}$的油膜盖不住峰顶。世界上每一根量产凸轮桃都在混合状态下运行，而设计的回应不是试图逃离它，而是让固-固接触无害：与钢反应、生长出几十纳米厚、剪切方向很软的硫化铁或磷酸锌层的极压添加剂，*横向*于滑动方向铺陈、以便沟槽储油的表面纹理，以及$60\ \mathrm{HRC}$的硬度——让真正相遇的微凸体发生弹性而不是塑性变形。

一个凸轮桃以$18\ \mathrm{mm}$的凸轮廓面半径压向半径$10\ \mathrm{mm}$、宽$16\ \mathrm{mm}$的滚子。峰值接触力为$800\ \mathrm{N}$。两者均为钢，$E = 207\ \mathrm{GPa}$，$\nu = 0.3$。最大赫兹接触压力是多少？

::: solution

$$
\frac{1}{E^{*}} = \frac{2 \left( 1 - 0.09 \right)}{207\,000} \ \Rightarrow \ E^{*} = 113.7\ \mathrm{GPa} , \qquad
p_0 = \sqrt{ \frac{F E^{*}}{\pi b R} } = \sqrt{ \frac{800 \times 113\,700}{\pi \times 16 \times 6.0} } = 549\ \mathrm{MPa}

## 甩不掉的动力学

::: definition 凸轮飞脱 {#def-float}
弹簧封闭的从动件只能被**推**，不能被**拉**。把从动件方程写成 $m \ddot{s} = F_c - F_s$，其中 $F_s = F_0 + k s$，则接触力为

$$
F_c ( \theta ) = F_0 + k s ( \theta ) + m \ddot{s} ( \theta )
$$

而**凸轮飞脱**（cam float）就是 $\min_\theta F_c ( \theta )$ 首次触及零的转速。因为惯性项按 $N^{2}$ 缩放而弹簧项不缩放，

$$
N_{\mathrm{float}} = N_0 \sqrt{ \min_{\theta} \frac{F_0 + k s}{- m \ddot{s}} }
$$

其中最小值在 $\ddot{s} < 0$ 的区段上取。超过飞脱转速后从动件离开轮廓，气门或刀具不再跟随位移线图——而在发动机里，活塞会与气门相撞。
:::

算例里那个刚性从动件模型是个虚构，而高速凸轮设计的全部功夫，就在于知道它的三个虚构里哪一个最先咬人。

| 模型 | 固有频率 | 在气门桃处 | 何时咬人 |
|---|---|---|---|
| 刚性传动链、刚性接触 | —（接触力可以归零） | $7163\ \mathrm{rev / min}$ 飞脱 | $F_c \to 0$ |
| 刚性传动链、**赫兹**接触 $k_H$ | $f_H = \dfrac{1}{2 \pi} \sqrt{ \dfrac{k_H}{m} }$ | $4.6\ \mathrm{kHz}$ | 永不——是激励的$18$倍 |
| 弹簧**振浪**（弹簧自身质量） | $f_1 = \dfrac{1}{4} \sqrt{ \dfrac{k}{m_s} }$ | $284\ \mathrm{Hz}$ | $250\ \mathrm{Hz}$处的五次谐波 |

线接触的赫兹刚度可由约翰逊（Johnson）柱-面压入关系式导出，

$$
k_H = \frac{\pi E^{*} L}{4 \ln \left( 4 R / a \right)} = \frac{\pi \times 113\,700 \times 14}{4 \times \ln ( 4 \times 7.38 / 0.057 )} = 2.00 \times 10^{5}\ \mathrm{N / mm}
$$

它足够刚，$553\ \mathrm{N}$下的弹性压入量为 $553 / 2.00 \times 10^{5} = 0.0028\ \mathrm{mm}$——**两微米半"丢失的升程"，任何轮廓修正都消不掉，因为它随载荷变化，而载荷随转速变化。**$1000\ \mathrm{rev / min}$时气门比线图所示早开 $2.8\ \mu\mathrm{m}$；$6000\ \mathrm{rev / min}$时晚开 $2.8\ \mu\mathrm{m}$。凸轮设计师称之为"随载荷变形的线图"，要么无视它，要么在机器上、在运转速度下实测凸轮。

**振浪模态才是终结设计的那一个。**压缩弹簧并不充当无质量的弹簧刚度；它的第一阶纵向模态是弹簧上座在顶部几圈上跳动、而底部几圈纹丝不动，超过该频率后弹簧在其两端传递的力气门根本感受不到。解药不是更硬的弹簧，而是*更短、更胖*的弹簧——$f_1 \propto d / D^{2}$，所以线径不变、中径减半，振浪频率翻倍——而在最高端，用蜂簧（鼓形弹簧），其锥度使各阶模态频率不再均匀、把共振抹开。

::: exercise 弹簧振浪 {level=2 check="347"}
某气门弹簧由 $D = 18\ \mathrm{mm}$、$d = 3.35\ \mathrm{mm}$、$n = 6.5$ 圈有效圈数重新设计为 $D = 14\ \mathrm{mm}$，保持刚度 $k = 32.8\ \mathrm{N / mm}$ 与原高度不变。已知 $G = 79\ \mathrm{GPa}$、$\rho = 7850\ \mathrm{kg / m^{3}}$，新的第一阶纵向固有频率是多少？

::: solution
两个约束，两个未知数。刚度不变：$k = G d^{4} / ( 8 D^{3} n )$，故 $d^{4} / ( D^{3} n )$ 为常数。原高度不变：$L_{\mathrm{solid}} = n d$，故 $n d$ 为常数。把 $n = n_0 d_0 / d$ 代入刚度约束，

$$
\frac{d^{5}}{D^{3}} = \frac{d_0^{5}}{D_0^{3}} \ \Rightarrow \ d = d_0 \left( \frac{D}{D_0} \right)^{3 / 5} = 3.35 	imes \left( \frac{14}{18} \right)^{0.6} = 2.88\ \mathrm{mm} , \qquad n = \frac{6.5 \times 3.35}{2.88} = 7.56
$$

$$
m_s = \pi D n \times \frac{\pi d^{2}}{4} \times \rho = 2166\ \mathrm{mm^{3}} \times 7.85 \times 10^{- 6} = 17.0\ \mathrm{g}
$$

$$
f_1 = \frac{1}{4} \sqrt{ \frac{k}{m_s} } = \frac{1}{4} \sqrt{ \frac{32\,800}{0.0170} } = \boxed{ 347\ \mathrm{Hz} }
$$

**对比改动前的 $284\ \mathrm{Hz}$——中径缩小$22\ \%$换来$22\ \%$的增益。**缩放律是 $f_1 \propto \sqrt{1 / ( D d )}$，所以把弹簧做小是划算的，这正是高性能气门弹簧越做越胖、越做越矮而不是越做越高的原因。它*修不好*的是弹簧座与座槽应力——同样的载荷由横截面小 $14\ \%$ 的钢丝承担，这两处应力反而升高。
:::
:::

## 端面凸轮、圆柱凸轮、共轭凸轮与预紧凸轮

**端面凸轮**把工作表面放在垂直于轴线的圆环面上。它的天赋是能让从动件跟走一条闭合轮廓而无需换向，而且——因为轮廓可以做出两侧承推面、从动件以叉架夹持——**它们能拉也能推**，于是没有弹簧、没有飞脱、根本没有接触力约束。它的代价是：从动件到轴线的半径沿升程变化，所以"升程"是一条两轴路径而非标量，且压力角必须在每一点对局部半径校核。内半径过小的端面凸轮，无论轮廓画得多平缓，内端压力角都是 $90^{\circ}$。

**圆柱（鼓形，"Cromwell"）凸轮**在鼓面上开一条环槽，叉架里的从动件滚子走在槽中。它们给出大位移、能拉、且适合短轴向空间。代价是槽很贵——五轴球头刀路径、无法贯通进给——而鼓形锥角对从动件摆角设下硬限制。

**共轭（双轮廓）凸轮**是一个轮毂上的两条轮廓，一条管一个方向，从动件以叉架上的两个滚子被夹在中间。它们是形封闭的、精确的、不飞脱的。它们也是唯一误差*不自相消*的凸轮类型：驱动侧轮廓上的误差就是升程误差，另一侧轮廓上的误差则是预紧量的变化。它们用于针织机、印刷机递纸牙鼓轮，以及弹簧属于不可接受元件的包装线分度台。

**预紧（分裂）凸轮**是两条相同的轮廓沿轴向错开半个齿距，从动件在一根共用的弹簧滑座上带两个滚子。两条轮廓把滚子夹紧、消除间隙。这是用便宜办法解决共轭凸轮用昂贵办法解决的同一个问题，也是一台普通包装机能在每分钟$600$个循环下保持 $\pm 0.02\ \mathrm{mm}$ 的原因。

**检测永远用凸轮检查仪**：零件对着精密从动件或触针转动，升程对角度的记录与理论升程作差。**要紧的公差在升程上，不在半径上**——一个凸轮处处差 $\pm 0.03\ \mathrm{mm}$ 也能完美运转，而在 $10^{\circ}$ 范围内差 $\pm 0.005\ \mathrm{mm}$ 就能把自己抖散。对应到图样上的规则是：**在给定角度处对升程曲线给公差，而不是把轮廓当作几何尺寸给公差。**

::: quiz
一台凸轮-从动件装置大修时换上了直径比原件大 $2\ \%$ 的滚子，其余一切不变。机器现在运行得更差。发生了什么？

- [ ] 大滚子使接触更宽，因而增大了赫兹应力
- [x] 理论基圆变大、压力角变小了——但机器当初是按*旧轮廓*切出的，大滚子如今走在为小滚子生成的曲线上，于是升程规律错了
- [ ] 大滚子减少了接触滑动，润滑油膜随之崩溃
- [ ] 没有问题；滚子总是越大越好

::: solution
升程规律是由节曲线偏移 $r_r$ 生成的。若轮廓*不变*而滚子半径增大 $\Delta r$，滚子中心描出的是旧轮廓外移 $r_r + \Delta r$ 的曲线，那不再是设计所用的节曲线——从动件如今执行的是另一个运动，且误差在 $d s / d \theta$ 最大处最大。**这就是凸轮与从动件必须成对配套、绝不可互换的原因，也是"同等替换"滚子必须按图样上的滚子半径定尺寸、而不是按你刚拆下来的磨损件定尺寸的原因。**赫兹应力其实是*下降*的，因为当量半径变大了——这正是错误答案显得诱人的缘故。
:::
:::

## 凸轮与替代方案

| 需求 | 凸轮是对的选择，当 | 改用 |
|---|---|---|
| 规定运动、一个自由度 | 永远——这就是凸轮存在的理由 | 若规律近似正弦，用齿轮五杆或六杆机构 |
| 停歇 | 形封闭凸轮，或槽轮机构 [[mechanisms/mechanisms-mobility]] | 伺服分度驱动、棘轮或离合器 |
| 载荷下运动反向且必须*保持* | 永不——弹簧封闭凸轮保不住 | 端面凸轮或共轭凸轮、丝杠、伺服 |
| 大力量、低速度、短行程 | 不 | 肘节或偏心压力机 [[mechanisms/linkage-synthesis]] |
| 运动可更改 | 永不 | **伺服凸轮**：电子凸轮就是一张查找表 |
| 极高速、极低质量 | 是，配滚子与硬化表面 | 气动或强制式（desmodromic）气门复位 |
| 重复精度优于 $0.01\ \mathrm{mm}$ | 只有共轭凸轮加配套件才行 | 丝杠，或直接驱动 |

**伺服这个问题值得单独说一句。**执行存储位置曲线的无刷力矩电机，就是一台几何无限可变、没有赫兹应力、没有飞脱、没有磨损、换产不用换工装凸轮——而自1995年以来它几乎完全接管了包装、印刷与冲压送料。**它没有接管的是内燃机配气机构、针织机和高循环装配机**，三种场合的理由相同：凸轮以机械方式储存能量并免费归还，而伺服必须把从动件的动能与势能泵送过铜绕组和硅开关器件，在每分钟$1000$个循环下铜输了。**凸轮是机械设计里最便宜的能量回收装置。**

::: exercise 设计：一个转塔送料臂凸轮 {level=3 check="449"}
**规格。**一台回转送料臂带着总计 $5.5\ \mathrm{kg}$ 往复质量的工装。一个径向凸轮以 $55\ \mathrm{mm}$ 基圆半径上的 $12\ \mathrm{mm}$ 滚子，按4-5-6-7多项式在 $110^{\circ}$ 凸轮角内把它抬高 $40\ \mathrm{mm}$，停歇 $70^{\circ}$，再按改进正弦规律在 $110^{\circ}$ 内退回 $40\ \mathrm{mm}$，再停歇 $70^{\circ}$。刚度 $18\ \mathrm{N / mm}$、预紧力 $350\ \mathrm{N}$ 的弹簧把从动件压在凸轮上。导轨摩擦 $\mu = 0.08$。工作转速 $240\ \mathrm{rev / min}$。

**求（a）**推程最大压力角，**（b）**导轨最大侧推力及其引起的摩擦力，**（c）**从动件离开凸轮的转速。

::: solution
**答。**$\omega = 25.13\ \mathrm{rad / s}$，$r_p = 55 + 12 = 67\ \mathrm{mm}$，$\omega / \beta = 13.09\ \mathrm{s^{- 1}}$，$a_{\max} = 7.513 \times 0.040 \times 13.09^{2} = 51.5\ \mathrm{m / s^{2}} = 5.2\ g$。

**（a）**$\left( d s / d \theta \right)_{\max} = 2.1875 \times 40 / 1.9199 = 45.6\ \mathrm{mm / rad}$。在升程上对 $\left( d s / d \theta \right) / \left( r_p + s \right)$ 求极大值得

$$
\psi_{\max} = 28.2^{\circ} \quad \text{在} \ x = 0.457 \ \text{处（不在升程中点，因为分母还在增长）}
$$

**这超过了 $25^{\circ}$ 的许用值。**要把压力角压住 $25^{\circ}$ 需要 $r_p = 79.4\ \mathrm{mm}$，即基圆半径 $53\ \mathrm{mm}$，而可用空间只有 $55\ \mathrm{mm}$——所以凸轮半径小了 $24\ \mathrm{mm}$，设计要么把凸轮做大，要么加长推程角，要么改用 $k_v = 1.761$ 的改进正弦规律。

**（b）**侧推力为 $F_c \tan \psi$。它在 $x = 0.44$ 处达峰，此处 $F_c = 720\ \mathrm{N}$、$\tan \psi = 0.542$：

$$
F_{\mathrm{side}} = 391\ \mathrm{N} , \qquad F_{\mathrm{friction}} = 0.08 \times 391 = 31\ \mathrm{N}
$$

而有用的从动件力是 $720\ \mathrm{N}$——**传递力的$4.3\ \%$被扔在导轨里，而导轨上还压着 $391\ \mathrm{N}$ 要由它的轴承来承受的侧载。**

**（c）**凸轮飞脱：$F_c = F_0 + k s + m \ddot s$ 最先在推程的减速段归零。惯性项按 $N^{2}$ 缩放而弹簧项不缩放，于是

$$
N_{\mathrm{float}} = 240 \sqrt{ \min_{\theta} \frac{F_0 + k s}{- m \ddot{s}} } = 240 \sqrt{ 3.504 } = \boxed{ 449\ \mathrm{rev / min} }
$$

**这台机器的转速上限是其工作转速的$1.87$倍，而卡住它的不过是一根弹簧。**注意起决定作用的是*推程*而非回程，尽管回程用了更平缓的改进正弦规律：回程峰值加速度是 $35.6\ \mathrm{m / s^{2}}$，推程是 $51.5$，且在回程负加速度达峰之点弹簧缠得更紧。
:::

::: exercise 压力角定尺寸 {level=1 check="53"}
一个带直动对心滚子从动件（滚子半径 $10\ \mathrm{mm}$）的径向凸轮，按4-5-6-7多项式在 $90^{\circ}$ 凸轮角内升高 $25\ \mathrm{mm}$。使压力角不超过 $25^{\circ}$ 的最小**基圆**半径是多少？

::: solution
$\left( d s / d \theta \right)_{\max} = k_v h / \beta = 2.1875 \times 25 / 1.5708 = 34.8\ \mathrm{mm / rad}$，发生在 $x = 0.5$、此处 $s = 12.5\ \mathrm{mm}$。令 $\tan \psi = 0.4663$，

$$
r_p = \frac{34.8}{0.4663} - 12.5 = 74.7 - 12.5 = 62.2\ \mathrm{mm}
$$

在全部升程上对 $\left( d s / d \theta \right) / \left( r_p + s \right)$ 求极大值、而不是假定在升程中点，得 $r_p = 63.0\ \mathrm{mm}$，于是

$$
r_b = r_p - r_r = 63.0 - 10 = \boxed{ 53\ \mathrm{mm} }
$$

**升程中点估计与真实极大值之间这两毫米的差距，就是拿假定代替求导的代价**；在 $x = 0.457$ 处分子只比峰值低了$2\ \%$，分母却低了$6\ \%$，比值在此取胜。
:::
:::

::: exercise 平底从动件宽度 {level=1 check="15.8"}
一个平底从动件按改进正弦规律在 $120^{\circ}$ 凸轮角内升高 $15\ \mathrm{mm}$。从动件端面的最小半宽是多少？

::: solution
接触点沿端面游走 $d s / d \theta$ 的距离，其峰值为 $k_v h / \beta = 1.761 \times 15 / 2.0944 = 12.6\ \mathrm{mm}$。按惯例为棱边圆角与不对中留 $25\ \%$ 裕量，

$$
\ell = 1.25 \times 12.6 = \boxed{ 15.8\ \mathrm{mm} }
$$

**注意这对从动件设计意味着什么：**为了容纳 $15\ \mathrm{mm}$ 升程，端面直径要做到 $32\ \mathrm{mm}$，而偏心的接触力作用在从动件杆上的弯矩随这个半宽增长。**平底从动件只在 $d s / d \theta$ 小的时候才紧凑——长凸轮角配短升程——而这正是使它的犁伤判据得以满足的同一条件。**
:::
:::

::: exercise 凸轮转矩 {level=2 check="15.7"}
一个径向凸轮以**摆线**规律在 $300\ \mathrm{rev / min}$ 下、于 $120^{\circ}$ 凸轮角内把 $3\ \mathrm{kg}$ 从动件抬高 $30\ \mathrm{mm}$。压紧弹簧 $k = 25\ \mathrm{N / mm}$、预紧力 $150\ \mathrm{N}$。凸轮轴必须提供的峰值转矩是多少？发生在何处？

::: solution
由虚功原理，瞬时转矩为 $T = F_c \, d s / d \theta$，其中 $F_c = F_0 + k s + m \ddot{s}$。由 $\omega = 31.42\ \mathrm{rad / s}$、$\beta = 2.0944\ \mathrm{rad}$、$\omega / \beta = 15.0\ \mathrm{s^{- 1}}$ 及摆线规律 $f = x - \sin 2 \pi x / 2 \pi$，

$$
\frac{d s}{d \theta} = \frac{h}{\beta} \left( 1 - \cos 2 \pi x \right) = 14.32 \left( 1 - \cos 2 \pi x \right)\ \mathrm{mm / rad} , \qquad
m \ddot{s} = m h \left( \frac{\omega}{\beta} \right)^{2} 2 \pi \sin 2 \pi x = 20.25 \sin 2 \pi x\ \mathrm{N}
$$

两个因子在不同位置达峰——$d s / d \theta$ 在 $x = 1$，$m \ddot{s}$ 在 $x = 0.25$——所以乘积在两者之间达峰：

$$
T_{\max} = \boxed{ 15.7\ \mathrm{N \cdot m} } \quad \text{在} \ x = 0.562 \ \text{处} , \qquad T_{\mathrm{rms}} = 9.4\ \mathrm{N \cdot m}
$$

**注意峰值转矩既不在峰值力处**（$x = 1$ 处的 $900\ \mathrm{N}$，那里 $d s / d \theta$ 已回到零）**也不在峰值加速度处**（$x = 0.25$，那里 $d s / d \theta$ 还很小）。电机选型按 $T_{\mathrm{rms}}$，轴与键按 $T_{\max}$，两者之间$1.7$的比值正是凸轮轴驱动按转矩而非按功率选型的原因。**一个循环的净功为零**——凸轮给出去的能量弹簧又还了回来——所以这是驱动上的纯波动载荷：一台铭牌 $5\ \mathrm{kW}$ 的凸轮机械，从电网取的功率可能只有 $400\ \mathrm{W}$。
:::
:::

::: quiz
两个凸轮有相同的位移线图、相同的升程、相同的凸轮角，但凸轮A用3-4-5多项式，凸轮B用4-5-6-7多项式。以相同转速、相同从动件运行，哪个说法正确？

- [ ] 凸轮B的峰值加速度更低，因此是更好的高速选择
- [x] 凸轮B的峰值加速度更高，但跃度有限，所以它更安静、对接触更温和，而它需要更硬的弹簧
- [ ] 两者动力学上完全相同，因为升程曲线一样
- [ ] 凸轮A更平顺，因为它的加速度大小恒定

::: solution
$k_a$ 对3-4-5是 $6.00$，对4-5-6-7是 $7.51$，所以凸轮B的峰值惯性力多$25\ \%$、为避免飞脱需要多$25\ \%$的弹簧——但凸轮A的加速度在升程两端*跳变*，那是无穷大跃度；无穷大跃度就是力阶跃，力阶跃就是一记锤击，其频谱是平的。**凸轮A是更快的机器，也是更吵的机器；凸轮B是你真能装进汽车里的、慢一点的机器。**5-6-7-8-9多项式沿同一方向走得更远：$k_a = 9.37$，只用在跃度本身是设计变量的场合，比如 [[mechanisms/mechanisms-mobility]] 里那些要把一瓶液体停稳的分度驱动。
:::

## 后续内容

凸轮是本课程最后一个*形状*即设计的机构。在它之前的一切——四杆机构、曲柄滑块机构、槽轮机构——只有几根杆长供你选择；凸轮有一条连续轮廓，而这条轮廓是你*写*出来的。这就是它成为 [[mechanisms/linkage-synthesis]] 那套机器最终兑现之处：位移线图是一个函数，轮廓是它的偏移，而约束加在它的导数上。

由此引出三个方向。**接触力学**认真对待本课的 $439\ \mathrm{MPa}$：表面耐久、喷丸引入的残余应力、与滑动方向成 $45^{\circ}$ 的 $0.3\ \mu\mathrm{m}$ 纹理的作用，以及为什么几乎每个凸轮磨损问题的答案都是更硬的表面加更软的添加剂配方、而不是换一种几何。**转子动力学与振动**认真对待 $284\ \mathrm{Hz}$ 的振浪模态，工具在 [[vibrations/harmonic-excitation]] 与 [[vibrations/two-degrees-of-freedom]]。**摩擦学**认真对待 $\lambda = 1.1$，起点是 [[fluid-mechanics/fluid-properties]] 引入的黏度-压力响应。

而你在现场真正会撞上的失效模式，在一台跑了六年、十一号工位突然开始敲机的机器上，与上面三者都无关。它是轮廓在接触力最大处磨平了 $0.05\ \mathrm{mm}$，使该点的加速度改变了——改变量按升程对角度的*四阶*导数缩放——而从动件是照着一条已不存在的加速度曲线设计的，开始在一个过去能轻松通过的转速下离开凸轮。**凸轮不会断裂。凸轮先改变形状，然后断裂。**

::: summary
- 凸轮有四个圆——基圆、理论基圆、节曲线、轮廓——混用它们是这门课最常见的错误。理论基圆是 $r_b + r_r$，压力角公式里用的就是它。
- 运动规律由 $k_v , k_a , k_j$ 选定，绝不由升程曲线的形状选定。摆线 $6.28$，3-4-5 $6.00$，4-5-6-7 $7.51$，5-6-7-8-9 $9.37$，改进正弦 $5.19$：**连接处的光顺是用内部的峰值加速度买来的。**
- $\tan \psi = \left( d s / d \theta - e \right) / \left( \sqrt{r_b^{2} - e^{2}} + s + r_r \right)$。推程上把它压在 $25^{\circ}$ 以内；唯一真正有效的杠杆是更大的理论基圆，而峰值在升程中点、不在两端。
- 根切是凸侧现象：在 $r^{2} + 2 r'^{2} - r r'' > 0$ 处校核 $\rho > r_r$。对平底从动件判据是 $r_0 + s + s'' > 0$，它按 $1 / \beta^{2}$ 缩放，所以对短凸轮角毫不留情。
- $F_c = F_0 + k s + m \ddot s$。**凸轮飞脱是弹簧与 $N^{2}$ 的赛跑**，你在额定转速下设计的裕度随超出转速的平方缩水。
- 赫兹压力 $p_0 = \sqrt{F E^{*} / ( \pi b R )}$ 是几百兆帕，油膜是零点几微米：**每一台量产凸轮都在混合润滑下运行，而设计的回应是材料与添加剂，不是几何。**
- 三个频率决定转速上限：赫兹接触模态（kHz，从不是问题）、弹簧振浪模态（几百赫兹，通常是真正的限制）、接触丢失（凸轮飞脱）。它们按此顺序到来，而后两者总是一起来到。
- 凸轮不能拉。若运动必须被保持、被反向传递、或执行于一个可能反向的载荷，答案是形封闭凸轮或另一种机构，而不是一根更硬的弹簧。
:::
