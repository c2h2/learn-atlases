::: warning 精确执行你的要求的机构
四杆机构给你一条曲线，你事后才发现它是什么。凸轮给你指定的那条曲线，所以当运动本身就是要求时，凸轮是首选机构——配气机构、印刷滚筒、针织机、装配分度器。这份自由有代价，代价不是设计时间，而是**力**。轮廓的每一毫米都是一个表面，必须透过几百纳米厚的油膜传递几百兆帕的赫兹接触压力；而且力封闭的从动件只能被推、不能被拉。**一个常见错误是把凸轮设计当成画图练习：几何通常是容易的部分，限制实际凸轮的是接触应力、润滑和从动件动力学。**
:::

## 构造：四条曲线，不是一条

拿卡尺绕任何一个盘形凸轮走一圈，你会发现图纸上有四种不同的"半径"，把它们混为一谈是凸轮设计中最常见的错误。

**基圆**是实际加工金属上以轴为中心的最小圆。它是制造基准，图纸公差标在它上面。

**理论基圆**是基圆加上从动件接触元件的半径——对半径为$r_r$的滚子从动件，

$$
r_p = r_b + r_r
$$

它是从动件处于基圆上时滚子*中心*所描出的圆，也是决定压力角的量。对尖顶从动件$r_r = 0$，两圆重合。

**理论廓线**（节曲线）是滚子中心相对凸轮的轨迹——*迹点*的轨迹。它是你真正由位移规律计算出的曲线；对对心直动滚子从动件，它就是

$$
r(\theta) = r_p + s(\theta)
$$

**实际廓线**（工作曲线）是金属表面：所有滚子位置的包络，即理论廓线向内偏移$r_r$。它是刀具走的曲线，也是会发生根切的曲线。

::: definition 凸轮的四个圆 {#def-circles}
对基圆半径为$r_b$、驱动半径为$r_r$的滚子从动件、位移为$s ( \theta )$的盘形凸轮，四条曲线为

$$
r_{\mathrm{base}} = r_b , \qquad r_{\mathrm{prime}} = r_p = r_b + r_r , \qquad r_{\mathrm{pitch}} ( \theta ) = r_p + s ( \theta ) , \qquad r_{\mathrm{profile}} = \text{理论廓线偏移 } r_r
$$

基圆和实际廓线是你加工的几何；理论基圆和理论廓线是你计算的几何。**对尖顶从动件$r_r = 0$，四条曲线合并为两条。**（平底从动件没有与表面保持固定距离的迹点，其廓线要作为平底直线族的包络求出。）
:::

::: example 是哪个半径？ {#ex-anatomy}
凸轮图纸标注基圆直径$\varnothing 40\ \mathrm{mm}$，滚子从动件直径$18\ \mathrm{mm}$，最大升程$16\ \mathrm{mm}$。加工件上任何地方的最大半径是多少？*理论*廓线的最大半径是多少？

**答案。**理论廓线最大半径为$r_p + h = (20 + 9) + 16 = 45\ \mathrm{mm}$。加工出的实际廓线最大半径是基圆加升程，$20 + 16 = 36\ \mathrm{mm}$——少九毫米，因为实际廓线是理论廓线向内收一个滚子半径。

::: solution
两条曲线沿每条公法线相距$r_r$，但它们的*曲率半径*不同：实际廓线的曲率半径在凸段为$\rho_{\mathrm{pitch}} - r_r$，在凹段为$\left| \rho_{\mathrm{pitch}} \right| + r_r$；决定刀具能否加工出该表面的是曲率，而不是半径。向机加工人员报"最大半径"而不说明是哪条曲线，可能使零件在滚子接触处整整差一个滚子半径，即$9\ \mathrm{mm}$。
:::
:::

## 分类，以及每个选择的代价

| 类型 | 接触 | 能推？ | 能拉？ | 磨损 | 用途 |
|---|---|---|---|---|---|
| 盘形，尖顶 | 点 | 能 | 不能 | 严重 | 仅用于布局研究 |
| 盘形，滚子 | 线 | 能 | 不能 | 中等 | 默认选择 |
| 盘形，平底 | 线 | 能 | 不能 | 低 | 高速、无换向 |
| 盘形，球面（曲面）底 | 点/线 | 能 | 不能 | 低 | 平底所需凸轮过大时 |
| 端面凸轮，沟槽式 | 线 | 能 | 能 | 中等 | 双向运动、分度 |
| 圆柱（鼓形）凸轮 | 线 | 能 | 能 | 中等 | 短包络内的大位移 |
| 共轭（双）凸轮 | 线 | 能 | 能 | 低 | 精密、无需弹簧 |
| 预紧式凸轮 | 线 | 能 | 能 | 低 | 从动件带两个滚子 |

**表中影响最大的一项是"能拉？不能"。**力封闭从动件只能被推，因此凡是从动件需要比弹簧所能提供的更快减速之处，接触力都会趋向于零；失去接触的凸轮就不再控制运动。**沟槽式端面凸轮、圆柱凸轮和共轭凸轮有两个工作面，因而能拉**，这就是分度鼓和印刷机叼纸牙凸轮采用这种形式的原因。

**力封闭与形封闭。**弹簧封闭的凸轮是*力封闭*的：只有弹簧保持从动件接触时，几何才决定运动。共轭凸轮或沟槽凸轮是*形封闭*的：几何始终决定运动，代价是第二个接触必须预紧或按公差控制以消除间隙，这既花钱，又使装配对热膨胀敏感。

::: quiz
一个平底从动件盘形凸轮高速运行。设计者得知从动件在升程末端附近跳离轮廓。改用同样质量的滚子后问题消失。为什么？

- [ ] 滚子接触面积小，因而接触压力低
- [x] 平底不能跟随凹的轮廓段；在轮廓需要凹段的地方，平底架空其上、只在两边接触，因此运动偏离设计
- [ ] 滚子消除了滑动，而滑动是跳离的原因
- [ ] 滚子增大了理论基圆半径，因而降低了压力角

::: solution
半对的答案最危险。平底从动件（底面垂直于导路）的压力角为零，所以问题不在压力角；滚子也不能消除从动件在导路中的滑动。真正的原因是：平底从动件要求轮廓处处为凸，$\rho = r_b + s + s'' > 0$（$s'' = d^2 s / d\theta^2$）。该条件不满足时，位移规律所要求的轮廓有一段凹段，平底会架空它：两点接触，从动件不执行设计运动，结果看起来像动态跳离，其实是几何失效。有限半径的滚子能跟随凹面，只要凹面的曲率半径大于滚子自身半径。
:::
:::

## 位移线图就是设计

凸轮的一切都来自一张图：升程对凸轮转角。廓线、力、应力、速度极限和失效模式都从它读出。首先要检查的是**哪一阶导数最先间断**。

$$
s = h f ( x ) , \quad x = \frac{\theta}{\beta} , \qquad
v = \frac{h \omega}{\beta} f' ( x ) , \qquad
a = \frac{h \omega^{2}}{\beta^{2}} f'' ( x ) , \qquad
j = \frac{h \omega^{3}}{\beta^{3}} f''' ( x )
$$

三个无量纲系数$k_v , k_a , k_j$是$f', f'', f'''$的峰值大小，它们承载了运动规律的设计内容。

| 规律 | $f ( x )$ | $k_v$ | $k_a$ | $k_j$ | 最先间断的导数 |
|---|---|---|---|---|---|
| 等速 | $x$ | 1.000 | $\infty$ | $\infty$ | 速度，两端 |
| 等加速等减速 | $2x^{2}$, $1 - 2 ( 1 - x )^{2}$ | 2.000 | 4.000 | $\infty$ | 加速度，三处 |
| 简谐 | $\tfrac{1}{2} \left( 1 - \cos \pi x \right)$ | 1.571 | 4.935 | $\infty$ | 加速度，两端 |
| 摆线 | $x - \dfrac{\sin 2 \pi x}{2 \pi}$ | 2.000 | 6.283 | 39.48 | 跃度，两端 |
| 3-4-5 多项式 | $10x^{3} - 15x^{4} + 6x^{5}$ | 1.875 | 5.774 | 60.00 | 跃度，两端 |
| 4-5-6-7 多项式 | $35x^{4} - 84x^{5} + 70x^{6} - 20x^{7}$ | 2.188 | **7.513** | 52.50 | 直到跃度都连续——$C^{3}$ |
| 5-6-7-8-9 多项式 | $126x^{5} - 420x^{6} + 540x^{7} - 315x^{8} + 70x^{9}$ | 2.461 | 9.372 | 78.75 | 直到四阶导数都连续——$C^{4}$ |
| 修正正弦 | 三段正弦组合 | 1.760 | 5.528 | 69.47 | 跃度，两端 |

::: exercise 推导：为什么多项式族是$C^{3}$的 {#deriv-continuity level=3}
从一个停歇到另一个停歇的升程，归一化为$f(0) = 0$、$f(1) = 1$，必须在斜率和曲率上与停歇段衔接：$f'(0) = f''(0) = 0$，$f'(1) = f''(1) = 0$。证明这六个条件给出3-4-5多项式，求其两端的跃度，并证明再加上$f'''(0) = f'''(1) = 0$得到4-5-6-7多项式。比较二者的$k_v$与$k_a$。

::: solution
**六个条件**需要六个系数，即五次多项式。由$f'(0) = f''(0) = 0$和$f(0) = 0$，常数项、一次项和二次项为零，剩下$f = c_3 x^3 + c_4 x^4 + c_5 x^5$。$x = 1$处的三个条件
$$
c_3 + c_4 + c_5 = 1, \qquad 3 c_3 + 4 c_4 + 5 c_5 = 0, \qquad 6 c_3 + 12 c_4 + 20 c_5 = 0,
$$
给出$c_3 = 10$、$c_4 = -15$、$c_5 = 6$：即**3-4-5规律**。其跃度为$f''' = 60 - 360 x + 360 x^2$，故$f'''(0) = f'''(1) = 60$：加速度在起止处为零，但其斜率在升程开始的瞬间从$0$跳到$60\, h \omega^3 / \beta^3$——跃度有有限突变。
**八个条件**（两端再加$f''' = 0$）需要七次多项式，同样的步骤给出$f = 35 x^4 - 84 x^5 + 70 x^6 - 20 x^7$，即**4-5-6-7规律**。其跃度连续，两端为零，在$x = 0.5$处绝对值最大，为$52.5$。
**代价**见表：$k_a$从$5.774$升到$7.513$，**峰值加速度高30%**；$k_v$从$1.875$升到$2.188$，**峰值速度高17%**。衔接处的光滑是用内部更高的峰值换来的。高速时这通常值得，因为跃度突变意味着力的变化率突然改变，会激起从动件系统的固有振动。
:::
:::

一个凸轮须在$90^{\circ}$内升程$30\ \mathrm{mm}$，机器以不可改变的固定转速运行。设计者把摆线规律换成4-5-6-7多项式，希望降低从动件峰值加速度。结果如何？

- [ ] 峰值加速度下降约百分之二十
- [x] 峰值加速度上升约百分之二十，峰值速度上升约百分之九
- [ ] 不变，因为两种规律的升程和转角相同
- [ ] 峰值加速度下降，但跃度变为无穷大

::: solution
$7.513 / 6.283 = 1.196$，$2.188 / 2.000 = 1.094$。选4-5-6-7多项式是因为它的**跃度连续**（摆线规律的跃度在两端各突变$39.5$），这关系到振动和噪声，而不是加速度。若约束是从动件飞脱，多项式是走错了方向：修正正弦（$k_a = 5.53$）或等加速等减速规律（$4.00$）的峰值更低，二者在别处各有代价（等加速等减速规律有加速度突变）。
:::

::: example 哪个规律，哪台机器 {#ex-lawchoice}
四个凸轮，升程都是$20\ \mathrm{mm}$、转角都是$120^{\circ}$、转速都是$600\ \mathrm{r / min}$，装在四台不同的机器上：带纱嘴穿过线圈的针织机；分度输送一瓶液体的包装线；带纸张通过压区的印刷机叼纸牙；把$20\ \mathrm{mm}$钢带送进模具的压力机送料。各用哪种规律？

**答案。**先算公共比例因子：$\omega = 62.83\ \mathrm{rad / s}$，$\beta = 2.094\ \mathrm{rad}$，$\omega / \beta = 30.0\ \mathrm{s^{- 1}}$，故$v_{\max} = 0.020 \times 30.0 \, k_v = 0.6 \, k_v\ \mathrm{m / s}$，$a_{\max} = 0.020 \times 900 \, k_a = 18 \, k_a\ \mathrm{m / s^{2}}$。

| 机器 | 问题所在 | 规律 | $k_a$ | $a_{\max}$ |
|---|---|---|---|---|
| 针织 | 纱线张力随从动件加速度变化；突变会拉断纱线 | 4-5-6-7 | 7.51 | $135\ \mathrm{m / s^{2}}$ |
| 瓶子分度 | 液体晃动；负载的加速度历程必须光滑 | 5-6-7-8-9 | 9.37 | 此转角下为$169\ \mathrm{m / s^{2}}$——实际中加长分度转角，直到瓶子的加速度可以接受 |
| 压力机送料 | 钢带惯性；给定时间内峰值加速度最低 | 修正正弦 | 5.53 | $100\ \mathrm{m / s^{2}}$ |
| 叼纸牙 | 形封闭，飞脱无关；成熟的光滑规律即可 | 摆线 | 6.28 | $113\ \mathrm{m / s^{2}}$ |

::: solution
这道题的要点是**规律的排名不是固定的**。5-6-7-8-9多项式的$k_a$在表中最高，却是瓶子分度的合理选择，因为那里要紧的是瓶子加速度的光滑性（其跃度及更高阶导数），而不是从动件的峰值加速度——峰值再靠加长分度转角压下来。**运动规律是为凸轮及其负载一起选的，不是只为凸轮选的。**
:::

## 压力角：凸轮的传动角

::: definition 压力角 {#def-psi}
凸轮的**压力角**$\psi$是接触点处两表面公法线——凸轮推动的方向——与从动件可自由运动方向之间的夹角。其余角$90^{\circ} - \psi$起着[[mechanisms/mechanisms-mobility]]中传动角的作用。对偏距为$e$的直动滚子从动件，

$$
\tan \psi = \frac{d s / d \theta - e}{\sqrt{r_p^{2} - e^{2}} + s}
$$

其中$d s / d \theta$的单位是长度每弧度。导路上的侧推力为$F \tan \psi$，它在导路中引起的摩擦力为$\mu F \tan \psi$。
:::

压力角$\psi$是凸轮推动方向与从动件允许运动方向之间的夹角。与连杆机构的传动角一样，必须使它远离从动件在导路中卡死的范围。

对零偏距的直动滚子从动件，推导只需两行。接触法线通过滚子中心并垂直于理论廓线$r = r_p + s$；对极坐标曲线，法线与向径的夹角满足$\tan \psi = r' / r$，故

$$
\tan \psi = \frac{d r / d \theta}{r} = \frac{d s / d \theta}{r_p + s}
$$

有偏距$e$时（规定正的$e$在推程中减小压力角），

$$
\boxed{ \; \tan \psi = \frac{d s / d \theta - e}{\sqrt{r_p^{2} - e^{2}} + s} \; }
$$

**由此得出两点，都是设计手段。**第一，$\psi$在$d s / d \theta$大*且*$s$仍小之处最大——对对称规律是在升程中点略前，而不是在两端。第二，理论基圆半径$r_p$单独出现在分母中，所以**降低压力角的直接办法是加大凸轮**；偏距或加长推程角是替代办法，各有取舍。

::: widget plot
f: atan(8.8126/(x+4.5))*180/pi
x: 12, 40
y: 5, 35
caption: 4-5-6-7规律、$128^{\circ}$内升程$9\ \mathrm{mm}$时，峰值压力角的升程中点估计值随理论基圆半径（毫米）的变化。**曲线下降得很慢：在$r_p = 14.4\ \mathrm{mm}$处穿过$25^{\circ}$线，要降到$11^{\circ}$需$r_p = 40\ \mathrm{mm}$**——凸轮直径几乎三倍，宽度相同时绕自身轴线的转动惯量约为六十倍。（在整个推程内求得的精确最大值比该估计高零点几度。）
:::

**允许值。**直动滚子从动件常用的设计限值是$\psi \le 30^{\circ}$，许多设计者在受载推程中取$25^{\circ}$以留余量；摆动从动件可容许更大的值，约至$45^{\circ}$。这些不是刚度限值，而是**侧推力和摩擦**限值：导路上的侧向力为$F \tan \psi$，由此产生的摩擦力为$\mu F \tan \psi$；在$\psi = 25^{\circ}$、$\mu = 0.15$时，简单导路中它为传递力的$0.15 \times 0.466 = 7\ \%$。悬臂的从动件杆会按其杠杆比放大导路反力，随着$\psi$增大，摩擦可能接近驱动力而使从动件卡死。这就是为什么导路长、用滚动轴承的凸轮可以在$30^{\circ}$下运行，而短滑动衬套的凸轮不行。

::: example 偏距不是免费的 {#ex-offset}
下文算例中的气门凸轮，开启侧在$s = 4.5\ \mathrm{mm}$处$\left( d s / d \theta \right)_{\max} = 8.81\ \mathrm{mm / rad}$，关闭侧在同一升程处为$- 8.68\ \mathrm{mm / rad}$，$r_p = 24\ \mathrm{mm}$。一位工程师提议用$3\ \mathrm{mm}$偏距来降低压力角。

**答案。**有偏距时，$\sqrt{r_p^2 - e^2} + s = \sqrt{576 - 9} + 4.5 = 23.81 + 4.5 = 28.31\ \mathrm{mm}$。在开启侧，取有利的偏距方向，

$$
\tan \psi_{\mathrm{open}} = \frac{8.81 - 3.00}{28.31} = 0.2052 \ \Rightarrow \ \psi = 11.6^{\circ} \quad \text{对比} \quad \tan^{-1} \frac{8.81}{28.5} = 17.2^{\circ}
$$

在关闭侧$d s / d \theta$符号相反，同一偏距现在是*叠加*的：

$$
\tan \psi_{\mathrm{close}} = \frac{| - 8.68 - 3.00 |}{28.31} = 0.4126 \ \Rightarrow \ \psi = 22.4^{\circ}
$$

::: solution
偏距把峰值从一侧移到另一侧，并使最坏情况更坏：$17.2^{\circ}$和$16.9^{\circ}$变成$11.6^{\circ}$和$22.4^{\circ}$。**当一侧远比另一侧苛刻时——例如开启短而快、关闭长而慢——偏距有用；对对称凸轮它是负担。**偏距还使作用线偏离导路中心线，这占用空间并在从动件杆上产生弯矩。
:::
:::

## 根切：轮廓切不出来的时候

::: definition 根切 {#def-undercut}
滚子从动件凸轮在理论廓线曲率半径$\rho$小于滚子半径$r_r$之处发生**根切**：向内偏移$r_r$的曲线自相交，实际廓线出现尖点。形式上，令$r = r_p + s$、$r' = d s / d \theta$、$r'' = d^{2} s / d \theta^{2}$，

$$
\rho = \frac{ \left[ r^{2} + r'^{2} \right]^{3 / 2} }{ r^{2} + 2 r'^{2} - r r'' } \qquad \text{要求} \qquad \rho > r_r \ \ \text{凡} \ \ r^{2} + 2 r'^{2} - r r'' > 0 \ \text{之处}
$$

对平底从动件，相应要求为处处$r_b + s + d^{2} s / d \theta^{2} > 0$。**根切是凸侧现象**：在理论廓线的凹段，实际廓线半径为$\left| \rho \right| + r_r$，比理论廓线半径大，不会产生尖点。
:::

实际廓线是理论廓线向内偏移一个滚子半径。把一条曲线向内偏移超过其自身曲率半径，偏移曲线就会自相交，沿它走的刀具会切掉滚子所需的金属。凸轮于是有了**尖点**：滚子骑在尖角上而不是设计表面上，升程偏离位移线图，尖角又是应力集中处，很快磨损和疲劳。

对盘形滚子从动件，理论廓线的带符号曲率半径为

$$
\rho = \frac{ \left[ r^{2} + \left( r' \right)^{2} \right]^{3 / 2} }{ r^{2} + 2 \left( r' \right)^{2} - r r'' } , \qquad r = r_p + s , \quad r' = \frac{d s}{d \theta} , \quad r'' = \frac{d^{2} s}{d \theta^{2}}
$$

轮廓完好的条件是

$$
\phi = \rho - r_r > 0 \qquad \text{凡} \qquad r^{2} + 2 \left( r' \right)^{2} - r r'' > 0 \ \text{之处}
$$

右边的条件把检查限制在理论廓线的**凸**段。在凹段$\rho$为负，实际廓线半径为$\left| \rho \right| + r_r$——*更大*而不是更小——这就是滚子能跟随它无法作为凸脊跟随的凹谷的原因。

对**平底从动件**（底面垂直于导路），实际廓线曲率半径有一个简单表达式，因为廓线是直线族而不是圆族的包络：

$$
\boxed{ \; \rho_{\mathrm{profile}} = r_b + s + \frac{d^{2} s}{d \theta^{2}} \; } \qquad \text{且} \qquad \ell_{\mathrm{face}} = 1.25 \left| \frac{d s}{d \theta} \right|_{\max}
$$

第一式必须处处为正，否则平底架空在凹段上、只在边缘接触；第二式给出从动件底面的半宽，因为接触点沿底面偏离从动件轴线的距离为$d s / d \theta$；系数$1.25$是为边缘倒圆和不对中留的惯用余量。

$$
r_b > 86.7\ \mathrm{mm}
$$

底面半宽须为$1.25 \times 35.81 = 44.8\ \mathrm{mm}$。

:::

## 尺寸计算流程

凸轮设计是一个迭代过程，通常两三遍就收敛，因为几何约束都随$r_p$增大而改善。

| 步骤 | 做什么 | 可能出什么问题 |
|---|---|---|
| 1 | 布置循环：推程、停歇、回程、停歇，以凸轮度数计。总和须为$360^{\circ}$ | 停歇不够工艺用 |
| 2 | 从$k_v , k_a , k_j$表中为每段选运动规律 | 峰值加速度对弹簧来说太高 |
| 3 | 由$\psi_{\max}$确定$r_p$ | 凸轮装不进包络 |
| 4 | 检查$\phi_{\min} > 0$（滚子）或$\rho > 0$（平底） | 根切——加大$r_p$或放缓规律 |
| 5 | 计算$a_{\max}$，再把$m a$与该升程处的弹簧力比较 | **凸轮飞脱**——通常的限制 |
| 6 | 计算峰值接触力和赫兹应力 | 表面疲劳、磨损 |
| 7 | 把从动件和弹簧的固有频率与激励比较 | 共振、噪声、气门弹簧振颤 |
| 8 | 数值生成廓线，加公差，加工 | 刀具半径大于实际廓线最小凹半径 |

**第5步在几何之后、应力之前，而实践中正是第5步把你打回第2步。**凸轮的几何几乎总是可行的；力的历程却常常不可行。

## 算例：顶置凸轮轴的气门桃

**规格。**四冲程四缸发动机，双顶置凸轮轴，每缸四气门，额定转速$6000\ \mathrm{r / min}$，红线$6600\ \mathrm{r / min}$。凸轮轴以曲轴转速的一半旋转。一个凸桃须给出$h = 9.0\ \mathrm{mm}$的气门升程，在凸轮转角$128^{\circ}$内开启，全升程保持$102^{\circ}$，在$130^{\circ}$内关闭——共$360^{\circ}$。（较长的全升程停歇是为了使算术简单；实际气门凸桃在全升程处没有停歇。）从动件为对心滚子，直径$18\ \mathrm{mm}$、宽$14\ \mathrm{mm}$，基圆半径$15\ \mathrm{mm}$。配气机构的等效往复质量$m = 0.24\ \mathrm{kg}$，气门弹簧$k = 32\ \mathrm{N / mm}$，落座时安装载荷$200\ \mathrm{N}$。

**第1步——循环与规律。**$128 + 102 + 130 = 360^{\circ}$ ✓。两侧都用4-5-6-7多项式：其跃度连续，作用在配气机构上的力变化平滑，激起的振动较少。

**第2步——运动学。**额定发动机转速下凸轮转速为$3000\ \mathrm{r / min}$，$\omega = 3000 \times 2 \pi / 60 = 314.16\ \mathrm{rad / s}$。

$$
\frac{\omega}{\beta_1} = \frac{314.16}{2.2340} = 140.63\ \mathrm{s^{-1}} \qquad \frac{\omega}{\beta_2} = \frac{314.16}{2.2689} = 138.46\ \mathrm{s^{-1}}
$$

| | 开启 | 关闭 |
|---|---|---|
| $v_{\max} = k_v h \omega / \beta$ | $2.77\ \mathrm{m / s}$ | $2.73\ \mathrm{m / s}$ |
| $a_{\max} = k_a h \omega^{2} / \beta^{2}$ | $1337\ \mathrm{m / s^{2}} = 136\ g$ | $1296\ \mathrm{m / s^{2}} = 132\ g$ |
| $j_{\max} = k_j h \omega^{3} / \beta^{3}$ | $1.31 \times 10^{6}\ \mathrm{m / s^{3}}$ | $1.25 \times 10^{6}\ \mathrm{m / s^{3}}$ |

**第3步——压力角。**$\left( d s / d \theta \right)_{\max} = 2.1875 \times 9.0 / 2.2340 = 8.81\ \mathrm{mm / rad}$，位于$s = 4.5\ \mathrm{mm}$处，$r_p = 15 + 9 = 24\ \mathrm{mm}$；升程中点估计为

$$
\tan \psi = \frac{8.81}{24 + 4.5} = 0.309 \ \Rightarrow \ \psi = 17.2^{\circ} \ \text{开启}, \qquad 16.9^{\circ} \ \text{关闭}
$$

每侧的精确最大值为开启侧$\boxed{ \psi_{\max} = 17.3^{\circ} }$（凸轮转角$60.3^{\circ}$处），关闭侧$17.1^{\circ}$。远在$25^{\circ}$以内；估计表明理论基圆可缩小到约$14.4\ \mathrm{mm}$才达到限值——但见第4步。

**第4步——根切。**理论廓线凸段的最小曲率半径为$\rho = 22.5\ \mathrm{mm}$，位于$88.5^{\circ}$（开启段的$x = 0.69$），故$\phi_{\min} = 22.5 - 9 = 13.5\ \mathrm{mm} > 0$。**完好，裕度很大**：滚子半径即使达到$22.5\ \mathrm{mm}$也不会使廓线出现尖点。由于4-5-6-7规律在每段两端加速度为零，理论廓线的曲率在各段与基圆和全升程圆弧衔接处是连续的。

**第5步——接触力与凸轮飞脱。**从动件方程为$m \ddot{s} = F_c - F_s$，故

$$
F_c ( \theta ) = \underbrace{F_0 + k s ( \theta )}_{\text{弹簧}} + \underbrace{m \ddot{s} ( \theta )}_{\text{惯性，带符号}}
$$

| 凸轮转角 | $s$ (mm) | $\ddot{s}$ (m/s²) | 弹簧 (N) | 惯性 (N) | $F_c$ (N) |
|---|---|---|---|---|---|
| $0^{\circ}$ 落座 | 0 | 0 | 200 | 0 | 200 |
| $38.4^{\circ}$ | 1.13 | $+1319$ | 236 | $+317$ | **553**（峰值） |
| $64^{\circ}$ 升程中点 | 4.50 | 0 | 344 | 0 | 344 |
| $89.6^{\circ}$ | 7.87 | $-1319$ | 452 | $-317$ | **135**（最小） |
| $128^{\circ}$–$230^{\circ}$ 停歇 | 9.00 | 0 | 488 | 0 | 488 |
| $269^{\circ}$ | 7.86 | $-1277$ | 452 | $-307$ | 145 |

最小接触力为$135\ \mathrm{N}$，在开启侧$89.6^{\circ}$附近。$F_0 + k s + m \ddot s$首次降为零处失去接触；惯性项按$N^{2}$变化而弹簧项不变，临界点在$90.6^{\circ}$，该处弹簧力为$454.6\ \mathrm{N}$，额定转速下惯性项为$-319.0\ \mathrm{N}$：

$$
N_{\mathrm{float}} = 6000 \sqrt{ \frac{454.6}{319.0} } = 7163\ \mathrm{r / min}
$$

**而红线为$6600\ \mathrm{r / min}$——转速裕度8.5%**（力的裕度约18%）。在$5000\ \mathrm{r / min}$以下，弹簧显得比需要的硬得多；它是为转速范围的顶端而定的。

x: 5000, 8000

caption: 临界凸轮转角（$90.6^{\circ}$）处的接触力（牛）随**曲轴**转速（转每分）的变化。**曲线在$7163$转每分处过零。**它是转速的向下抛物线，所以在转速范围顶端裕度消失得很快：从$6000$到$6600$转每分，接触力从$136$降到$69$牛。更硬的弹簧可把过零点推高，代价是更高的落座载荷、接触应力和凸轮磨损。
:::

**第6步——赫兹应力。**峰值力$553\ \mathrm{N}$出现在$38.4^{\circ}$，该处理论廓线曲率半径为$48.3\ \mathrm{mm}$，故实际廓线为凸，$\phi = 39.3\ \mathrm{mm}$。把接触视为两个长$b = 14\ \mathrm{mm}$的钢圆柱（$E = 207\ \mathrm{GPa}$，$\nu = 0.3$），

$$
\frac{1}{R} = \frac{1}{9.0} + \frac{1}{39.3} \ \Rightarrow \ R = 7.32\ \mathrm{mm} , \qquad \frac{1}{E^{*}} = \frac{1 - \nu_{1}^{2}}{E_1} + \frac{1 - \nu_{2}^{2}}{E_2} = \frac{2 \times 0.91}{207\,000} \ \Rightarrow \ E^{*} = 113.7\ \mathrm{GPa}
$$

$$
p_0 = \sqrt{ \frac{F E^{*}}{\pi b R} } = \sqrt{ \frac{553 \times 113\,700}{\pi \times 14 \times 7.32} } = \boxed{ 442\ \mathrm{MPa} } , \qquad a = \sqrt{ \frac{4 F R}{\pi b E^{*}} } = 0.057\ \mathrm{mm}
$$

接触带只有$2a = 0.114\ \mathrm{mm}$宽，凸桃每转经过它一次——额定转速下每分钟$3000$次。最大剪应力为$0.30 p_0 = 133\ \mathrm{MPa}$，位于表面以下$0.79 a = 0.045\ \mathrm{mm}$处。因此凸轮表面的硬化层深度（通常为零点几毫米）远大于最大剪应力所在深度，使次表面应力峰值落在硬材料中，并为磨损和磨削留出余量。

**第7步——气门弹簧振颤。**弹簧钢丝$d = 3.35\ \mathrm{mm}$，中径$D = 18\ \mathrm{mm}$，有效圈数$n = 6.5$，$G = 79\ \mathrm{GPa}$，得$k = G d^{4} / ( 8 D^{3} n ) = 32.8\ \mathrm{N / mm}$，有效圈质量$m_s = \rho \, \pi D n \, \pi d^2 / 4 = 25.4\ \mathrm{g}$。弹簧两端均受约束（气门座与弹簧座），其一阶纵向（"振颤"）固有频率为

$$
f_1 = \frac{1}{2} \sqrt{ \frac{k}{m_s} } = \frac{1}{2} \sqrt{ \frac{32\,800}{0.0254} } = 568\ \mathrm{Hz}
$$

额定转速下凸轮频率为$50\ \mathrm{Hz}$，所以$f_1$约为凸轮频率的第$11$次谐波；在红线（$55\ \mathrm{Hz}$）时约为第$10$次，在飞脱转速（$59.7\ \mathrm{Hz}$）时约为第$9.5$次。升程曲线的谐波含量随阶次降低但并不为零，所以发动机转速升高时，更低阶、更强的谐波逼近振颤频率。**在转速范围顶端，刚性从动件模型同时因两个原因不再可靠：接触接近丧失，而弹簧自身的振动又改变了它施加的力。**再往上，设计者转向双弹簧或锥形（"蜂巢"）弹簧、强制式（desmodromic）配气机构，或者——一级方程式自1986年雷诺（Renault）EF15B发动机以来——气动气门回位，其气体弹簧的运动质量很小。

**第8步——凸轮转矩。**由虚功原理，凸轮轴瞬时转矩为$T = F_c \, d s / d \theta$，得正峰值$3.82\ \mathrm{N \cdot m}$（$51.5^{\circ}$处）、反向峰值$- 3.72\ \mathrm{N \cdot m}$（$307.5^{\circ}$处），每个凸桃的均方根值为$1.60\ \mathrm{N \cdot m}$。**除摩擦外，一个循环的净功为零**——在这个无摩擦模型中弹簧把储存的能量全部还回——因此凸轮轴驱动承受每个凸桃约$\pm 4\ \mathrm{N \cdot m}$的波动转矩。对一根轴上所有凸桃求和，这一波动转矩是凸轮轴驱动（链或带）的扭转激励，必须校核。

## 生成轮廓

理论廓线是计算的曲线，实际廓线是加工的曲线。对对心直动滚子从动件盘形凸轮，令$X ( \theta ) = r_p + s ( \theta )$。滚子中心的轨迹为

$$
C ( \theta ) = \left( X \cos \theta , \; X \sin \theta \right)
$$

实际廓线是沿该曲线内法线偏移$r_r$。求导得切向量$\left( X' \cos \theta - X \sin \theta , \; X' \sin \theta + X \cos \theta \right)$，$X' = d s / d \theta$；将其转过$90^{\circ}$并归一化即得内单位法向量。

::: exercise 推导：轮廓作为数控路径 {#deriv-profile level=3}
证明对心直动滚子从动件盘形凸轮的实际廓线为

$$
\boxed{ \;
\begin{aligned}
X_{\mathrm{prof}} &= X \cos \theta - r_r \, \frac{X' \sin \theta + X \cos \theta}{\sqrt{X^{2} + X'^{2}}} \\[4pt]
Y_{\mathrm{prof}} &= X \sin \theta + r_r \, \frac{X' \cos \theta - X \sin \theta}{\sqrt{X^{2} + X'^{2}}}
\end{aligned} \;}
$$

并用两种平凡情形检验：$\theta = 0$且$X' = 0$；以及任意$\theta$且$r_r = 0$。

::: solution
切向量为$\mathbf{t} = \left( X' \cos \theta - X \sin \theta , \; X' \sin \theta + X \cos \theta \right)$，$\left| \mathbf{t} \right| = \sqrt{X'^{2} + X^{2}}$。把$\mathbf{t}$转过$- 90^{\circ}$得$\left( t_y , - t_x \right) = \left( X' \sin \theta + X \cos \theta , \; - X' \cos \theta + X \sin \theta \right)$；在$\theta = 0$、$X' = 0$时它为$\left( X , 0 \right)$，指向*外*。从$C$减去$r_r$乘以这个外单位法向量，即得上面两式。

**检验。**$\theta = 0$、$X' = 0$时：$X_{\mathrm{prof}} = X - r_r = r_p + s - r_r = r_b + s$，$Y_{\mathrm{prof}} = 0$——廓线位于基圆加升程处，理应如此。$r_r = 0$时廓线退化为理论廓线，即尖顶从动件。不能通过这两项检验的公式有符号错误，而这里的符号错误会使廓线偏向错误的一侧——凸轮报废。
:::
:::

## 润滑：凸轮运行在困难的状态

凸轮接触是弹性流体动压润滑（EHL）接触：滚子和凸桃相互弹性压平，油的黏度在接触压力下升高几个数量级，而分隔两个承受数百兆帕的表面的油膜**只有几百纳米厚**——与它所要分隔的磨削表面的粗糙度相当。

线接触的道森–希金森（Dowson–Higginson）最小油膜厚度公式

$$
\frac{h_{\min}}{R} = 2.65 \, U^{0.70} G^{0.54} W^{-0.13} , \qquad
U = \frac{\eta_0 u}{E' R} , \quad G = \alpha E' , \quad W = \frac{F}{E' R b} , \quad E' = 2 E^{*}
$$

其中$\eta_0$为入口温度、大气压下的黏度，$u$为平均卷吸（滚动）速度，$\alpha$为黏压系数。取热机油$\eta_0 = 0.008\ \mathrm{Pa \cdot s}$、$\alpha = 2.2 \times 10^{- 8}\ \mathrm{Pa^{- 1}}$，在气门凸桃峰值力点得到：

| 量 | 值 | 说明 |
|---|---|---|
| $u = \omega \sqrt{X^{2} + X'^{2}} \, \phi / \rho$ | $6.6\ \mathrm{m / s}$ | 接触点沿廓线移动的速度；纯滚动时即平均卷吸速度 |
| $U$ | $3.2 \times 10^{- 11}$ | 低——速度适中，模量很高 |
| $G$ | $5\,000$ | 矿物油对钢的典型值 |
| $W$ | $2.4 \times 10^{- 5}$ | |
| $h_{\min}$ | $0.34\ \mu\mathrm{m}$ | |
| $\Lambda = h_{\min} / \sqrt{R_{q1}^2 + R_{q2}^2}$ | $0.8$ | **混合润滑**（两表面$R_q$均为$0.3\ \mu\mathrm{m}$） |

**$\Lambda < 1$意味着微凸体相互接触。**$R_q \approx 0.3\ \mu\mathrm{m}$的磨削凸桃和滚子，综合粗糙度为$0.42\ \mu\mathrm{m}$，$0.34\ \mu\mathrm{m}$的油膜盖不住峰顶。重载凸轮接触通常运行在混合润滑区，设计对策不是设法逃离它，而是使固体接触无害：形成保护性表面膜的抗磨和极压添加剂、精细的表面粗糙度，以及高表面硬度，使相遇的微凸体发生弹性而非塑性变形。

## 甩不掉的动力学

::: definition 凸轮飞脱 {#def-float}
力封闭从动件能被**推**而不能被**拉**。写出从动件方程$m \ddot{s} = F_c - F_s$，$F_s = F_0 + k s$，接触力为

$$
F_c ( \theta ) = F_0 + k s ( \theta ) + m \ddot{s} ( \theta )
$$

**凸轮飞脱**是$\min_\theta F_c ( \theta )$首次降为零时的转速。由于惯性项按$N^{2}$变化而弹簧项不变，若$\ddot{s}$按参考转速$N_0$计算，

$$
N_{\mathrm{float}} = N_0 \sqrt{ \min_{\theta} \frac{F_0 + k s}{- m \ddot{s}} }
$$

其中最小值在$\ddot{s} < 0$的区段上取。超过飞脱转速，从动件离开廓线，气门或工具不再按位移线图运动，而在干涉型发动机中气门可能撞上活塞。
:::

算例中的刚性从动件模型基于三种理想化，知道哪一种最先失效是高速凸轮设计的很大一部分。

| 模型 | 固有频率 | 对该气门凸桃 | 何时失效 |
|---|---|---|---|
| 刚性系统，刚性接触 | ——（接触力可降为零） | $7163\ \mathrm{r / min}$时飞脱 | $F_c \to 0$ |
| 刚性系统，**赫兹**接触$k_H$ | $f_H = \dfrac{1}{2 \pi} \sqrt{ \dfrac{k_H}{m} }$ | 约$6.5\ \mathrm{kHz}$ | 很少——超过凸轮频率的$100$倍 |
| 弹簧**振颤**（弹簧自身质量） | $f_1 = \dfrac{1}{2} \sqrt{ \dfrac{k}{m_s} }$ | $568\ \mathrm{Hz}$ | 凸轮频率的某个强谐波达到$f_1$ |

两圆柱线接触的赫兹趋近量由约翰逊的分析得到，

$$
\delta = \frac{F}{\pi E^{*} b} \left[ \ln \frac{4 R_1}{a} + \ln \frac{4 R_2}{a} - 1 \right] = \frac{553}{\pi \times 113\,700 \times 14} \left[ \ln \frac{36}{0.057} + \ln \frac{157}{0.057} - 1 \right] = 0.0015\ \mathrm{mm}
$$

（适用于同种材料的两物体），该载荷下的切线刚度约为$4 \times 10^{5}\ \mathrm{N / mm}$。峰值载荷下约$1.5\ \mu\mathrm{m}$的弹性趋近是随载荷变化的升程损失，而载荷又随转速变化；它与配气机构其余部分（摇臂、推杆、凸轮轴弯曲）的变形相比很小，这就是实际配气机构模型采用多质量模型的原因。

**振颤模态通常是限制设计的那个。**压缩弹簧不是无质量弹簧：在其一阶纵向模态中，两端受约束而中间各圈振动，在该频率附近弹簧作用在弹簧座上的力与$F_0 + k s$相差很大。由于$k \propto d^4 / ( D^3 n )$、$m_s \propto d^2 D n$，振颤频率$f_1 \propto d / ( D^{2} n )$：减小中径能大大提高它。变刚度弹簧和锥形（"蜂巢"）弹簧的各圈不同时振动，也被用来分散和抑制共振。

::: exercise 弹簧振颤 {level=2 check="694"}
一个气门弹簧由$D = 18\ \mathrm{mm}$、$d = 3.35\ \mathrm{mm}$、有效圈数$n = 6.5$改为$D = 14\ \mathrm{mm}$，保持刚度$k = 32.8\ \mathrm{N / mm}$和并紧高度不变。取$G = 79\ \mathrm{GPa}$、$\rho = 7850\ \mathrm{kg / m^{3}}$，两端约束，新的一阶纵向固有频率是多少？（以Hz为单位输入。）

::: solution
两个约束，两个未知数。刚度相同：$k = G d^{4} / ( 8 D^{3} n )$，故$d^{4} / ( D^{3} n )$不变。并紧高度相同：$L_{\mathrm{solid}} \approx n d$（只计有效圈），故$n d$不变。把$n = n_0 d_0 / d$代入刚度约束，

$$
\frac{d^{5}}{D^{3}} = \frac{d_0^{5}}{D_0^{3}} \ \Rightarrow \ d = d_0 \left( \frac{D}{D_0} \right)^{3 / 5} = 3.35 \times \left( \frac{14}{18} \right)^{0.6} = 2.88\ \mathrm{mm} , \qquad n = \frac{6.5 \times 3.35}{2.88} = 7.56
$$

$$
m_s = \pi D n \times \frac{\pi d^{2}}{4} \times \rho = 2167\ \mathrm{mm^{3}} \times 7.85 \times 10^{- 6}\ \mathrm{kg / mm^3} = 17.0\ \mathrm{g}
$$

$$
f_1 = \frac{1}{2} \sqrt{ \frac{k}{m_s} } = \frac{1}{2} \sqrt{ \frac{32\,800}{0.0170} } = \boxed{ 694\ \mathrm{Hz} }
$$

**改前为$568\ \mathrm{Hz}$——中径减小$22\ \%$，频率提高$22\ \%$。**在这两个约束下$m_s \propto d D$，故$f_1 \propto 1 / \sqrt{D d}$。这一改动*没有*改善的是钢丝应力：同样的载荷由直径小$14\ \%$的钢丝承担，簧圈中的剪应力升高（中径减小部分抵消），必须重新校核疲劳。
:::
:::

## 端面凸轮、圆柱凸轮、共轭凸轮与预紧凸轮

**端面凸轮**把工作面做在垂直于轴的圆盘端面上。做成沟槽、滚子在槽内运行时，**它们能拉也能推**，因此没有回位弹簧，也没有飞脱。代价是沟槽有两个侧面而一次只能有一个接触，所以接触换侧时滚子要反转，槽内间隙成为回差。

**圆柱（鼓形）凸轮**把沟槽绕在圆柱上，带动滚子从动件，从动件可平行于轴线移动，也可在摆臂上摆动。它们位移大、能拉能推、包络短。代价是沟槽难以精确加工，而且圆柱滚子各点想以不同速度运动，所以滚子与槽壁的接触存在不可避免的滑动。

**共轭（双）凸轮**是同一轮毂上的两个盘形廓线，各管一个方向，从动件带两个滚子。它们是形封闭的、精确的、不会飞脱。两条廓线必须作为配对件制造：一侧的误差是升程误差，另一侧的误差是预紧力变化。它们用于针织机、印刷机叼纸牙滚筒，以及不允许使用弹簧的分度传动。

**预紧式凸轮**用弹簧把两个滚子压在凸轮表面上，从而消除间隙，而无需把两条廓线按配对公差制造。它是对共轭凸轮靠精度解决的那个问题的一种较便宜的回答。

## 制造与检测

| 方法 | 典型廓线精度 | 成本 | 适用 |
|---|---|---|---|
| 按母模仿形铣 | $\pm 0.02\ \mathrm{mm}$ | 单件低，母模高 | 旧式生产、铸造毛坯 |
| 数控铣后磨削 | $\pm 0.005\ \mathrm{mm}$ | 中 | 现代默认 |

（精度为典型数量级；实际能力取决于机床和零件。）

**检测总是升程检测**：零件对着精密从动件或测头旋转，记录升程对转角，并与理论升程比较。**要紧的公差是升程及其导数的公差，而不是半径的公差**——半径上小而平缓的误差只使升程有小而平缓的变化，对动力学几乎无影响；而只有几微米、却短而急的误差会大大改变升程的二阶导数，也就改变了加速度。相应的图纸规则是：**在规定角度处给升程曲线标公差，而不是把廓线当几何尺寸标公差。**

::: quiz
一套凸轮从动件机构重新装配时换了一个直径比原来大$2\ \%$的滚子，其余不变。机器现在运行得更差了。发生了什么？

- [ ] 大滚子增大了赫兹应力，因为接触更宽
- [x] 廓线是为原滚子加工的；换大滚子后滚子中心不再描出设计的理论廓线，所以升程规律错了
- [ ] 大滚子减少了接触滑动，润滑膜崩溃
- [ ] 没有问题；大滚子总是更好

::: solution
实际廓线是由理论廓线向内偏移$r_r$生成的。若廓线*不变*而滚子增大$\Delta r$，滚子中心描出的是实际廓线向外偏移$r_r + \Delta r$的曲线，那不是设计的理论廓线：从动件执行的是另一种运动，误差在廓线曲率与圆差别最大处最大。**这就是凸轮与从动件要一起规定，替换滚子必须按图纸上的滚子半径而不是按磨损的旧件制造的原因。**赫兹应力实际上略有*下降*，因为综合曲率半径增大了，这正是第一个选项诱人的地方。
:::
:::

| 要求 | 凸轮合适的情况 | 替代方案 |
|---|---|---|
| 给定运动，单自由度 | 几乎总是——这是凸轮存在的理由 | 若规律接近正弦，可用齿轮五杆或六杆 |
| 停歇 | 形封闭凸轮，或槽轮机构（[[mechanisms/mechanisms-mobility]]） | 伺服分度驱动、棘轮或离合器 |
| 运动在载荷下换向且须*保持* | 仅当形封闭——力封闭凸轮无法抵抗换向载荷 | 端面或共轭凸轮、丝杠或伺服 |
| 大力、低速、短行程 | 很少 | 肘杆或偏心压力机（[[mechanisms/linkage-synthesis]]） |
| 运动可变 | 从不 | **伺服（"电子凸轮"）**：运动是一张存储的表 |
| 极高速度、极小质量 | 是，用滚子和硬表面 | 气动或强制式气门回位 |
| 重复精度优于$0.01\ \mathrm{mm}$ | 仅用共轭凸轮和配对件 | 丝杠或直接驱动 |

**伺服替代方案值得单独说一句。**执行存储位置曲线的伺服电机是一个可以用软件改变运动的凸轮，没有凸轮磨损，也不用换工装；在许多包装、印刷和压力机送料场合它已取代机械凸轮。机械凸轮仍保留在内燃机配气机构、针织机和许多高节拍装配机中。原因之一是能量：力封闭凸轮的从动件动能和弹簧能在每个循环内以机械方式交换，而伺服必须以电的方式提供和吸收这些能量，每个循环都在绕组和驱动器中产生损耗；在极高的循环频率和小运动量下，这在发热和电机尺寸上代价很高。

::: exercise 设计：一个转塔送料臂凸轮 {level=3 check="449"}
**规格。**一个回转送料臂带动总往复质量$5.5\ \mathrm{kg}$的工装。盘形凸轮，滚子半径$12\ \mathrm{mm}$，基圆半径$55\ \mathrm{mm}$，按4-5-6-7多项式在凸轮转角$110^{\circ}$内将其升起$40\ \mathrm{mm}$，停歇$70^{\circ}$，按修正正弦规律在$110^{\circ}$内返回$40\ \mathrm{mm}$，再停歇$70^{\circ}$。刚度$18\ \mathrm{N / mm}$、安装载荷$350\ \mathrm{N}$的弹簧使从动件保持在凸轮上。导路摩擦$\mu = 0.08$。运行转速$240\ \mathrm{r / min}$。

**求(a)**推程的峰值压力角，**(b)**导路上的峰值侧推力及其产生的摩擦力，**(c)**从动件离开凸轮时的凸轮转速。（(c)的答案以r/min为单位输入。）

::: solution
**基本量。**$\omega = 25.13\ \mathrm{rad / s}$，$r_p = 55 + 12 = 67\ \mathrm{mm}$，$\beta = 1.9199\ \mathrm{rad}$，$\omega / \beta = 13.09\ \mathrm{s^{- 1}}$，$a_{\max} = 7.513 \times 0.040 \times 13.09^{2} = 51.5\ \mathrm{m / s^{2}} = 5.2\ g$。

**(a)**$\left( d s / d \theta \right)_{\max} = 2.1875 \times 40 / 1.9199 = 45.6\ \mathrm{mm / rad}$。在整个升程内求$\left( d s / d \theta \right) / \left( r_p + s \right)$的最大值，得

$$
\psi_{\max} = 28.2^{\circ} \quad \text{位于} \ x = 0.457 \ \text{（在升程中点之前，那里 } s \text{ 还较小）}
$$

**这超过了$25^{\circ}$的设计允许值。**要保持$25^{\circ}$需$r_p = 79.4\ \mathrm{mm}$，即基圆半径$67.4\ \mathrm{mm}$，而现有为$55\ \mathrm{mm}$——要大$12.4\ \mathrm{mm}$。替代办法是加长推程角，或采用修正正弦推程（$k_v = 1.760$），在现有凸轮上得$\psi_{\max} = 23.4^{\circ}$。

**(b)**侧推力为$F_c \tan \psi$。其峰值在$x = 0.44$处，此处$F_c = 732\ \mathrm{N}$，$\tan \psi = 0.533$：

$$
F_{\mathrm{side}} = 390\ \mathrm{N} , \qquad F_{\mathrm{friction}} = 0.08 \times 390 = 31\ \mathrm{N}
$$

而传递的从动件力为$732\ \mathrm{N}$——**其中$4.3\ \%$损失于导路摩擦，导路轴承还须承受$390\ \mathrm{N}$的侧向载荷。**

**(c)**凸轮飞脱：$F_c = F_0 + k s + m \ddot s$首先在推程的减速段降为零。惯性项按$N^{2}$变化而弹簧项不变，故

$$
N_{\mathrm{float}} = 240 \sqrt{ \min_{\theta} \frac{F_0 + k s}{- m \ddot{s}} } = 240 \sqrt{ 3.504 } = \boxed{ 449\ \mathrm{r / min} }
$$

**飞脱转速是运行转速的$1.87$倍。**起决定作用的是推程而不是回程：回程修正正弦的峰值加速度为$5.528 \times 0.040 \times 13.09^2 = 37.9\ \mathrm{m / s^{2}}$，而推程为$51.5$；且回程中朝向凸轮的减速出现在接近全升程处，那里弹簧力大；单看回程，飞脱转速为$539\ \mathrm{r / min}$。
:::

::: exercise 压力角定尺寸 {level=1 check="53"}
一个对心滚子从动件盘形凸轮，滚子半径$10\ \mathrm{mm}$，按4-5-6-7多项式在凸轮转角$90^{\circ}$内升程$25\ \mathrm{mm}$。使压力角不超过$25^{\circ}$的最小**基圆**半径是多少？（以mm为单位输入。）

::: solution
$\left( d s / d \theta \right)_{\max} = k_v h / \beta = 2.1875 \times 25 / 1.5708 = 34.8\ \mathrm{mm / rad}$，出现在$x = 0.5$、$s = 12.5\ \mathrm{mm}$处。在该处令$\tan \psi = 0.4663$，

$$
r_p = \frac{34.8}{0.4663} - 12.5 = 74.7 - 12.5 = 62.2\ \mathrm{mm}
$$

在整个升程内求$\left( d s / d \theta \right) / \left( r_p + s \right)$的最大值而不假定在中点，得$r_p = 63.0\ \mathrm{mm}$，故

$$
r_b = r_p - r_r = 63.0 - 10 = \boxed{ 53\ \mathrm{mm} }
$$

升程中点估计略偏不安全：在中点稍前，斜率仍接近峰值，而升程（从而分母）较小，所以比值在那里略大。
:::
:::

::: exercise 平底从动件宽度 {level=1 check="15.8"}
一个平底从动件按修正正弦规律在凸轮转角$120^{\circ}$内升程$15\ \mathrm{mm}$。按惯用的$25\ \%$余量，从动件底面的最小半宽是多少？（以mm为单位输入。）

::: solution
接触点沿底面偏离从动件轴线$d s / d \theta$，其峰值为$k_v h / \beta = 1.760 \times 15 / 2.0944 = 12.6\ \mathrm{mm}$。加上为边缘倒圆和不对中留的$25\ \%$余量，

$$
\ell = 1.25 \times 12.6 = \boxed{ 15.8\ \mathrm{mm} }
$$

$15\ \mathrm{mm}$的升程需要约$32\ \mathrm{mm}$宽的底面，偏心接触力对从动件杆施加的弯矩随该偏距增大。**只有$d s / d \theta$小——转角长、升程小——时平底从动件才紧凑，这也正是使其凸性判据得到满足的条件。**
:::
:::

::: exercise 凸轮转矩 {level=2 check="15.7"}
一个盘形凸轮按**摆线**规律在凸轮转角$120^{\circ}$内将$3\ \mathrm{kg}$的从动件升起$30\ \mathrm{mm}$，转速$300\ \mathrm{r / min}$。回位弹簧$k = 25\ \mathrm{N / mm}$，安装载荷$150\ \mathrm{N}$。忽略摩擦，推程中凸轮轴须提供的峰值转矩是多少？出现在何处？（以N·m为单位输入转矩。）

::: solution
由虚功原理，瞬时转矩为$T = F_c \, d s / d \theta$，$F_c = F_0 + k s + m \ddot{s}$。$\omega = 31.42\ \mathrm{rad / s}$，$\beta = 2.0944\ \mathrm{rad}$，$\omega / \beta = 15.0\ \mathrm{s^{- 1}}$，摆线$f = x - \sin 2 \pi x / 2 \pi$，

$$
\frac{d s}{d \theta} = \frac{h}{\beta} \left( 1 - \cos 2 \pi x \right) = 14.32 \left( 1 - \cos 2 \pi x \right)\ \mathrm{mm / rad} , \qquad
m \ddot{s} = m h \left( \frac{\omega}{\beta} \right)^{2} 2 \pi \sin 2 \pi x = 127.2 \sin 2 \pi x\ \mathrm{N}
$$

力和斜率在不同位置达到峰值——$F_c$在$x = 1$处达到$900\ \mathrm{N}$，而那里$d s / d \theta$已回到零；$d s / d \theta$在$x = 0.5$处最大——所以乘积在二者之间达到峰值。在推程内计算$T(x)$：

$$
T_{\max} = \boxed{ 15.7\ \mathrm{N \cdot m} } \quad \text{位于} \ x = 0.562 , \qquad T_{\mathrm{rms}} = 9.4\ \mathrm{N \cdot m} \ \text{（推程内）}
$$

轴和键按$T_{\max}$设计，电机的热额定值按整个循环的均方根转矩选。**除摩擦外，整个循环的净功为零**——弹簧在回程中把推程时凸轮给它的能量还回——所以驱动主要承受波动载荷，可由飞轮或传动系统的惯量来平滑。
:::

::: quiz
两个凸轮升程相同、转角相同，凸轮A用3-4-5多项式，凸轮B用4-5-6-7多项式。以同一转速驱动同一从动件，哪种说法正确？

- [ ] 凸轮B峰值加速度更低，因而是更好的高速选择
- [x] 凸轮B峰值加速度更高，但跃度连续，激起的振动较少，且需要更硬的弹簧
- [ ] 二者动力学上完全相同，因为升程曲线相同
- [ ] 凸轮A更平稳，因为其加速度大小恒定

::: solution
3-4-5的$k_a$为$5.774$，4-5-6-7为$7.513$，所以凸轮B的峰值惯性力多$30\ \%$，需要相应更大的弹簧力来防止飞脱。但凸轮A的跃度在升程两端从零*突变*到$60\, h\omega^3/\beta^3$，力的变化率突然改变；而凸轮B的跃度从零平滑上升。**凸轮A允许用较轻的弹簧；凸轮B在对振动敏感的系统中运行更平稳。**5-6-7-8-9多项式在同一方向上走得更远：$k_a = 9.37$，用于高阶导数的光滑性比峰值加速度更重要的场合。
:::

## 后续内容

凸轮是本课程中以*形状*为设计本身的机构。四杆机构、曲柄滑块机构和槽轮机构各有少数几个杆长可供选择；凸轮则有一条连续的廓线，你把它写成一个函数。[[mechanisms/linkage-synthesis]]的思想——规定运动、导出几何——在这里得到最直接的体现：位移线图是一个函数，廓线是它的偏移，约束作用在它的导数上。

由此有三个方向。**接触力学**把本讲的$442\ \mathrm{MPa}$进一步展开：表面耐久性、表面硬化和喷丸产生的残余应力，以及表面粗糙度。**振动**把$568\ \mathrm{Hz}$的振颤模态和弹性从动件系统进一步展开，工具见[[vibrations/harmonic-excitation]]和[[vibrations/two-degrees-of-freedom]]。**摩擦学**把$\Lambda \approx 0.8$进一步展开，起点是[[fluid-mechanics/fluid-properties]]中介绍的黏度及其压力依赖性。

在运行多年的机器上最常遇到的失效是渐进的：廓线在接触力最大处磨损，升程的局部曲率改变；由于加速度是升程的二阶导数，一个只有几微米深、但转角很短的磨损形貌就能明显改变加速度和接触力。新机时远低于飞脱极限的从动件，此时可能在它过去从容运行的转速下开始离开凸轮。**凸轮通常在断裂之前先磨离其设计运动。**

::: summary
- 凸轮有四条曲线——基圆、理论基圆、理论廓线、实际廓线——混淆它们是本课题最常见的错误。理论基圆为$r_b + r_r$，压力角公式中用的是它。
- 运动规律按$k_v , k_a , k_j$选，绝不按升程曲线的形状选。$k_a$：修正正弦$5.53$，3-4-5 $5.77$，摆线$6.28$，4-5-6-7 $7.51$，5-6-7-8-9 $9.37$：**衔接处的光滑是用内部更高的峰值加速度换来的。**
- $\tan \psi = \left( d s / d \theta - e \right) / \left( \sqrt{r_p^{2} - e^{2}} + s \right)$。直动从动件应保持在约$25$–$30^{\circ}$以下；直接手段是加大理论基圆，峰值在升程中点附近，而不在两端。
- 根切是凸侧现象：在$r^{2} + 2 r'^{2} - r r'' > 0$处检查$\rho > r_r$。平底的判据是$r_b + s + s'' > 0$，而$s''$按$1 / \beta^{2}$变化，所以短转角要求大凸轮。
- $F_c = F_0 + k s + m \ddot s$。**凸轮飞脱是弹簧力与按$N^{2}$增长的惯性力之间的赛跑**，所以力的裕度随转速平方缩小。
- 赫兹压力$p_0 = \sqrt{F E^{*} / ( \pi b R )}$为几百兆帕，油膜为零点几微米：**重载凸轮通常运行在混合润滑区，设计对策是材料、表面粗糙度和添加剂，而不是几何。**
- 三个频率很重要：赫兹接触模态（千赫级，很少成问题）、弹簧振颤模态（数百赫兹，常是实际限制）和飞脱转速。在转速范围顶端，后两者往往同时到来。
- 力封闭凸轮不能拉。若运动须保持、反向传递或在可能换向的载荷下执行，答案是形封闭凸轮或别的机构，而不是更硬的弹簧。
:::
