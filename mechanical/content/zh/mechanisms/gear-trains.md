::: warning 传动比是精确的。其余一切都是近似的
带传动的速比随滑动漂移，链传动的速比每链节按弦节距振荡 $\pm 2\%$，摩擦传动的速比取决于载荷。**轮系的传动比是两个整数的精确之比，且在每一瞬间都精确，不是平均意义上精确。**就是这一条性质，让一切必须知道某物在哪里的机器——钟表、分度头、丝杠、机器人腕关节、飞机操纵部件——用齿轮而不用带，也是这门学科核心挫败感的来源：

**轮系能产生的传动比是一个可数的、坑坑洼洼的整数值集合，而你要的那个传动比几乎从不在里面。**

本课上半部分的一切都是这一条的推论。下半部分的一切是第二个伟大思想的推论——让轴动起来，你就多一个自由度，就能把任意大的传动比装进任意小的直径，代价是一份必须由什么东西承受的转矩反作用，以及一个若选错保持构件就可能塌缩为零的效率。
:::

## 你已经知道的内容

- **基圆齿距相等**——[[mechanisms/gears]] 里，两个齿轮啮合当且仅当 $\pi m_1 \cos \phi_1 = \pi m_2 \cos \phi_2$，这就是轮系里每个齿轮必须共用模数与压力角的原因。
- **瞬心与节点**——[[mechanisms/velocity-analysis]] 中的肯尼迪定理，是让传动比成为几何属性而非载荷属性的东西。
- **等效惯量**——[[mechanisms/acceleration-analysis]] 中的 $J_{\mathrm{eq}} = J / i^{2}$，它是一台伺服电机能搬动一吨重的原因，也是存在最优传动比的原因。
- **接触与弯曲强度**——[[mechanisms/gears]] 中的 $p_0$ 与 $\sigma_F$，它们决定轮系中每个齿轮的齿宽，而且*不会*随级数成比例改善。
- **格吕伯勒–库茨巴赫判据**——[[mechanisms/mechanisms-mobility]] 中的 $M = 3(N-1) - 2J_1$，你将用它发现周转轮系有两个自由度、因而需要两个驱动而不是一个。

## 简单轮系、复合轮系，与那个什么都不做的惰轮

::: definition 轮系传动比 {#def-trainvalue}
对齿轮 $1, 2, 3, \ldots$ 依次啮合的轮系，**轮系传动比**为

$$
e = \frac{\omega_{\mathrm{last}}}{\omega_{\mathrm{first}}} = \prod_{\text{meshes}} \left( - \frac{N_{\mathrm{driving}}}{N_{\mathrm{driven}}} \right)
$$

**简单轮系**中每个齿轮各占一轴、只带一个齿轮；传动比是各啮合比的乘积，符号随每次啮合交替。**复合轮系**中两个以上齿轮键接在同一根轴上、共享转速；传动比变为

$$
\boxed{ \; e = (- 1)^{k} \, \frac{ \textstyle\prod N_{\text{driving}} }{ \textstyle\prod N_{\text{driven}} } \; }
$$

其中 $k$ 是外啮合次数。**内啮合（齿圈）不改变方向、不贡献负号。**
:::

::: exercise 推导：惰轮为什么只改符号、其余不变 {#deriv-idler level=3}
::: solution
在 $N_1$ 主动轮与 $N_2$ 从动轮之间插入一个 $N_i$ 齿的齿轮。它被1驱动、驱动2，所以它在分母出现一次、在分子出现一次，

$$
e = \left( - \frac{N_1}{N_i} \right) \left( - \frac{N_i}{N_2} \right) = + \frac{N_1}{N_2}
$$

$N_i$ 恒等地消掉了。**所以惰轮根本不是变速元件；它是换向元件与填充中心距的元件，它的齿数是一个自由变量，应该花在真正需要的地方**——通常是用来让齿数互质（见下），偶尔用来够到一个箱体早已定死的中心距。

惰轮*确实*付出的代价是真实的。它多一个啮合，而一个啮合是1.5%的功率、一对轴承、一条油路、一段轴和一个固有频率。若齿数不精心选择，它还把自身轮齿与所接触齿轮陷入1:1的磨损配对。**"惰轮无所谓"之所以既是常见的考试答案、又是昂贵的工业事故，是因为第一句话为真、第二句话不为真。**
:::
:::

::: warning 猎齿齿数
若 $N_1$ 齿小齿轮驱动 $N_2$ 齿齿轮且 $d = \gcd ( N_1 , N_2 ) > 1$，则小齿轮1号齿只会碰到编号对 $d$ 取模余1的那 $N_2 / d$ 个轮齿——永远碰不到别的。$17 / 102$ 副的 $d = 17$，所以**小齿轮每个齿只接触大轮六个齿，大轮每个齿只被一个小齿轮齿接触，直到天荒地老。**

后果全是坏的，全是慢性的。某个齿上的任何制造误差，不再被摊开，而是每 $N_2/d$ 个大轮转重复出现在同一位置。任何材料夹杂每循环都在同一接触点受载。磨损的齿保持磨损，并把它的搭档磨出一个匹配的凹坑，于是这一对发展出恰好等于大轮自身频率的周期性激励——那正是振动分析师用来指认它的签名。**规则是让相邻齿数互质，或至少让它们的比有较大的公倍数——一个"猎齿"（hunting）齿数——让接触斑点在两个齿轮上缓缓游走。**把 $17 / 102$ 换成 $19 / 100$ 分文不花，把一切修好。

例外是有意的：**"猎齿蜗杆"是齿数与蜗轮毫无公因子的蜗杆；而当你*希望*一个可更换齿轮按匹配图案磨损时，会故意用非猎齿副**——这就是为什么有些机器规定一组齿轮必须成对更换，也是图样上写明这一点的原因。
:::

## 整数算术：哪些传动比存在

::: example 两级轮系凑 $23.4 : 1$ 减速器 {#ex-234}
一台输送机驱动需要精确的 $23.4 : 1$，用两级复合轮系，任何一级不超过 $7 : 1$，任何齿轮不超过100齿。

**答。**$23.4 = 117 / 5$。一个可用的拆分是 $5.400 \times 4.333$，即

$$
\frac{81}{15} \times \frac{65}{15} = 5.400 \times 4.3333 = 23.400 \quad \text{精确}
$$

::: solution
这算术是一场因子搜捕。$117 / 5 = a c / b d$ 要求对某个整数 $k$ 有 $ac = 117 k$、$bd = 5 k$，而 $b$ 与 $d$ 都得至少17齿，才能在 $20^{\circ}$、不变位下躲开根切。试 $k = 45$：$b d = 225 = 15 \times 15$、$ac = 5265 = 81 \times 65$，即上面那个答案——**而它通不过根切检验**，因为两个小齿轮都只有15齿。

试 $k = 90$：$bd = 450 = 25 \times 18$，但迫使 $ac = 10\,530$，其因子对是 $90 \times 117$ 起步——超过100齿的天花板。试 $k = 135$：$bd = 675 = 27 \times 25$、$ac = 15\,795 = 81 \times 195$——更糟。**不存在四个齿数都在17到100之间的两级解。**真正的答案是：

| 方案 | 齿数 | 评注 |
|---|---|---|
| 接受变位 | $81 / 15 \times 65 / 15$，两个小齿轮 $x = +0.15$ | 最便宜；传动比精确，两个变位小齿轮，无标准目录件 |
| 加一级 | $4.500 \times 5.200 \times 1.003$——实践用 $54 / 12 \times 78 / 15 \times 100 / 99$ | 多一个啮合、1.5%的功率、一道密封、一个固有频率 |
| 一级换行星 | $i = 5.400$ 行星加 $4.333$ 斜齿 | 最小最轻；行星级设计见 [[#ex-wind]] |
| 放宽规格 | $23.333 = (70 / 20) \times (100 / 15)$ | 误差 $0.29\ \%$；两个15齿小齿轮只需 $x = +0.12$ |

**这一节的教训不是算术，是最后一行。**$23.333 = (70 / 20) \times (100 / 15)$ 是精确的，只用合法齿数，离所求 $0.29\ \%$。**规定到三位有效数字的传动比，就是没给理由的传动比**；问机器拿这个数字干什么，若答案是"把带速定在百分之几以内"，就拿走这 $0.29\ \%$。**整数算术问题最便宜的解法几乎总是放宽规格，最贵的是加一级。**
:::
:::

::: example 造不出来的传动比：$\sqrt{2}$ {#ex-sqrt2}
某机构需要精确的 $\sqrt 2 = 1.41421356\ldots$，用齿轮实现。求最佳可得。

**答。**不存在。$\sqrt 2$ 是无理数而齿轮传动比是有理数，误差永远不可能为零。问题只是用多少齿轮能把误差压到多小。

::: solution
$\sqrt 2$ 的**连分数**是 $1 + 1 / ( 2 + 1 / ( 2 + \cdots ) )$，其渐近分数为

$$
\frac{1}{1} , \quad \frac{3}{2} , \quad \frac{7}{5} , \quad \frac{17}{12} , \quad \frac{41}{29} , \quad \frac{99}{70} , \quad \frac{239}{169} , \ldots
$$

而每个渐近分数都是分母不超过它的最佳有理逼近。**$\mathbf{99 / 70}$ 是100齿以下最佳单对齿轮**，误差 $5.1 \times 10^{- 5}$，即 $0.0036\ \%$。

两级则彻底改变局面。因为两级的误差相乘而非相加，复合轮系可以远比它的任何一级精确：

$$
\frac{58}{57} \times \frac{82}{59} = 1.414 \, 213 \, 50 \quad \Rightarrow \quad \text{误差} \ 6.3 \times 10^{- 8} \ \ ( 0.000 \, 006 \, 3 \, \% )
$$

**不比它大的齿轮，却比最佳单对好六百倍。**原因是 $58 / 57$ 与 $82 / 59$ 各自接近1、各自接近 $\sqrt [4]{2}$ 的校正量；**每一级都接近单位比的复合轮系是一台误差校正装置**，这正是对数螺旋凸轮或差动分度头所需 $\sqrt 2$ 的标准手法。代价是 $57$ 与 $59$ 是相邻奇数、与任何数都无公因子，所以齿轮相对其传递的转矩偏大，而整个部件是四个齿轮两根轴——若你当初对公差诚实一点，一对齿轮就够了。
:::
:::

::: exercise 猎齿齿数 {level=1 check="6"}
一个 $17$ 齿小齿轮驱动 $102$ 齿大轮。给定一个小齿轮齿，它一生能接触多少个不同的大轮齿？

::: solution
$\gcd ( 17 , 102 ) = 17$，任一小齿轮齿访问的大轮齿数为

$$
\frac{ N_2 }{ \gcd ( N_1 , N_2 ) } = \frac{ 102 }{ 17 } = \boxed{ 6 }
$$

**反过来更糟：那六个大轮齿中的每一个，在这台齿轮箱的一生中只被一个小齿轮齿敲击，别无其他。**把大轮改成100齿，传动比从6.000变成5.882——$2\ \%$ 的误差——而访问数从6跳到100，因为19与100（或17与100）互质。**这是轮系设计里最便宜的可靠性提升，也是最常被留在桌上不要的那一个，因为它从不出现在强度计算里。**
:::
:::

## 周转轮系：当一根轴动起来，什么变了

::: definition 威利斯方程 {#def-willis}
**周转**（行星）轮系至少有一个齿轮的轴在动。给运动参考系——**行星架**（系杆）——一个角速度 $\omega_c$，则每个齿轮在该系中的绝对速度都变为 $\omega_i - \omega_c$。**在行星架系中，轮系就是一个普通的定轴轮系**，其传动比 $e_0$ 是各啮合比的简单乘积，于是

$$
\boxed{ \; e_0 = \frac{ \omega_{\mathrm{last}} - \omega_c }{ \omega_{\mathrm{first}} - \omega_c } \;} \qquad \text{（**威利斯方程**，1849）}
$$

对太阳轮 $s$、行星轮 $p$、齿圈 $r$ 组成的单排行星轮系，行星架系中太阳轮到齿圈的传动比为 $e_0 = - N_r / N_s$（一次外啮合加一次内啮合，故符号为负），得到每个设计师都背的形式：

$$
\omega_s + \alpha \omega_r = ( 1 + \alpha ) \, \omega_c \ , \qquad \boxed{ \; \alpha = \frac{ N_r }{ N_s } \; } \quad \text{（**行星轮系结构参数**）}
$$

**一个方程，三个未知角速度。**任意两个定第三个，而这一组里的第三个构件就是反作用构件：它承载转矩却未必传递功率，而你选择保持哪个构件，是设计中后果最重大的一个决定。
:::

::: exercise 推导：列表法（叠加法） {#deriv-tabular level=3}
::: solution
威利斯方程是线性性的陈述，列表法则是把线性性当算术来执行。写两行，然后相加。

| | 行星架 $c$ | 太阳轮 $s$ | 行星轮 $p$ | 齿圈 $r$ |
|---|---|---|---|---|
| (1) 锁死整个部件，转一圈 | $+1$ | $+1$ | $+1$ | $+1$ |
| (2) 按住行星架，太阳轮转 $+x$ | $0$ | $+x$ | $- x \, N_s / N_p$ | $- x \, N_s / N_r$ |
| 求和 | $1$ | $1 + x$ | $1 - x N_s / N_p$ | $1 - x N_s / N_r$ |

第(1)行是刚体转动，它是受约束系统方程的一个解。第(2)行是按住行星架的定轴轮系解。**它们的和是解，因为支配关系——纯滚动约束——对角速度是线性的。**然后代入真实边界条件，解出 $x$。

该方法可推广到任何周转轮系，无论多复杂：**锁死，解定轴轮系，相加，施加约束。**它唯一的陷阱是第(2)行的符号，而避开陷阱的办法是数内啮合的次数——奇数次使 $e_0$ 为负，偶数次使之为正——而不是试图在脑中想象转动。
:::
:::

::: example 基本行星轮系，齿圈固定 {#ex-epi1}
$N_s = 20$，$N_p = 30$，$N_r = 80$。齿圈固定，太阳轮以 $1000\ \mathrm{rev / min}$ 转动。求行星架转速、行星轮自转、以及转矩比。

**答。**$\omega_c = 200\ \mathrm{rev / min}$，行星轮自转（绝对）$- 400\ \mathrm{rev / min}$，$T_c / T_s = 5$。

::: solution
$\alpha = 80 / 20 = 4$，代入 $\omega_s + \alpha \omega_r = ( 1 + \alpha ) \omega_c$ 且 $\omega_r = 0$，得

$$
\omega_c = \frac{ \omega_s }{ 1 + \alpha } = \frac{ 1000 }{ 5 } = 200\ \mathrm{rev / min} \quad \text{（与太阳轮同向）}
$$

用列表法，$N_s / N_r = 1 / 4$，齿圈固定意味着 $1 - x / 4 = 0$、$x = 4$，于是太阳轮行读作 $1 + 4 = 5$、行星架行是 $1$——同一个 $5 : 1$——行星轮行读作行星架速度的 $1 - 4 \times ( 20 / 30 ) = 1 - 2.667 = - 1.667$ 倍：

$$
\omega_p = - 1.667 \times 200 = - 333.3\ \mathrm{rev / min}
$$

**行星轮以 $333\ \mathrm{rev / min}$ 倒转，而行星架以 $200$ 带着它前进**——它的绝对运动是一种逆行滚动，这正是在固定内齿圈上纯滚动所要求的。对齿圈校核：$1 - 4 \times ( 20 / 80 ) = 0$ ✓。

转矩方面，三个构件的转矩必须满足 $T_s + T_r + T_c = 0$，且无损耗时净功为零。约束 $\omega_s + \alpha \omega_r - ( 1 + \alpha ) \omega_c = 0$ 使转矩矢量正比于它的法向：

$$
T_s : T_r : T_c = 1 : \alpha : - ( 1 + \alpha ) = 1 : 4 : - 5
$$

**所以行星架输出太阳轮五倍的转矩，而固定的齿圈把四倍于太阳轮的转矩反作用进箱体，却不传递一瓦。**这个反作用就是行星齿轮箱全部的结构内涵：箱体必须是环绕齿圈的封闭框架，而四倍转矩的齿圈正是行星齿圈被压装进箱体、而不是螺栓接到法兰上的原因。
:::
:::

::: exercise 两个构件都被驱动的周转轮系 {level=2 check="14"}
上面那副 $20 / 30 / 80$ 轮系，齿圈以 $+ 400\ \mathrm{rev / min}$ 转动，太阳轮以 $- 100\ \mathrm{rev / min}$ 转动。行星架转速是多少？

::: solution
$$
\omega_c = \frac{ \omega_s + \alpha \omega_r }{ 1 + \alpha } = \frac{ - 100 + 4 \times 400 }{ 5 } = \frac{ 1500 }{ 5 } = \boxed{ + 300\ \mathrm{rev / min} }
$$

**而这已经是一台差速器，不是轮系。**这副轮系现在有两个输入一个输出，正是自由度计数预言的：五个构件（机架、太阳轮、行星架、齿圈、行星轮）、四个转动副加两对齿轮副，$M = 3 ( 5 - 1 ) - 2 ( 4 ) - 1 ( 2 ) = 2$，它会毫无怨言地接受任意一对输入。**这是它的威力，也是它的危险。**定构件的行星轮系铭牌上只有一个数；差速器有一张二维地图，而不知道自己处在地图哪个角落的控制系统，会把机器开进错误的那个角落。

## 转矩、反作用，与功率实际去了哪里

::: definition 循环功率 {#def-circulating}
单构件保持的简单行星轮系中，被保持构件承载转矩但不承载功率，而**损耗等于基本轮系的损耗按行星架系中的相对速度求值**。以 $\eta_0$ 记行星架系（定轴轮系）效率，整排的损耗为

$$
P_{\mathrm{loss}} = ( 1 - \eta_0 ) \times \left| P_{\text{through the carrier-fixed train}} \right| = ( 1 - \eta_0 ) \, \left| T_s ( \omega_s - \omega_c ) \right|
$$

效率是该损耗除以**实际输入功率**。要盯住的是两者之比，

$$
\boxed{ \; \text{损耗份额} = ( 1 - \eta_0 ) \times \frac{ \left| \omega_{\mathrm{rel}} \right| }{ \left| \omega_{\mathrm{in}} \right| } \times \frac{ T_{\text{mesh}} }{ T_{\mathrm{in}} } \; }
$$

**其中含有相对速度与输入速度之比，而那个比值可以被做得任意大。**当它很大时，机器就处于**循环功率**状态：内部从一个构件流向另一个构件的功率，比机器从外部传递的还多，而损耗随内部流走、不随负荷走。
:::

::: example 四种构型的效率 {#ex-eff4}
对 [[#ex-epi1]] 的 $\alpha = 4$ 轮系，取行星架系中每对啮合 $\eta_0 = 0.98$：

| 构型 | 速比 $i$ | 损耗份额 | $\eta$ |
|---|---|---|---|
| 太阳轮入，行星架出，齿圈保持 | 5.000 | $0.02 \times \frac{4}{5} = 0.0160$ | 0.9840 |
| 行星架入，太阳轮出，齿圈保持 | 0.200 | $0.0160$ | 0.9840 |
| 齿圈入，行星架出，太阳轮保持 | 1.250 | $0.02 \times \frac{1}{5} = 0.0040$ | 0.9960 |
| 行星架入，齿圈出，太阳轮保持 | 0.800 | $0.0040$ | 0.9960 |

**答。**在任何速比下，保持**太阳轮**都比保持**齿圈**好四倍。

::: solution
完整算一个。齿圈保持，太阳轮以 $\omega_s$ 输入：则 $\omega_c = \omega_s / 5$，行星架系中太阳-行星相对速度为 $\omega_s - \omega_c = 0.8 \, \omega_s$，齿圈-行星相对速度为 $0 - \omega_c = - 0.2 \, \omega_s$。行星架系轮系承载 $T_s ( \omega_s - \omega_c ) = 0.8 \, T_s \omega_s$，而实际输入是 $T_s \omega_s$，所以损耗是输入的 $0.02 \times 0.8$，$\eta = 0.984$。

现在保持太阳轮、以 $\omega_r$ 驱动齿圈：$\omega_c = \alpha \omega_r / ( 1 + \alpha ) = 0.8 \, \omega_r$，行星架系中齿圈速度为 $\omega_r - \omega_c = 0.2 \, \omega_r$。行星架系轮系现在只承载 $0.2 \, T_r \omega_r$，输入是 $T_r \omega_r$，所以损耗是 $0.02 \times 0.2$，$\eta = 0.996$。

**物理原因值得直说：损耗发生在齿相互滑过之处，而齿以*相对*速度滑动。**保持相对速度最小的那个构件，你就造出了高效的机器。**保持齿圈——它的相对速度是 $\omega_c$，是一切量中很大的一块——你就造出了低效的那台。**对 $1 : 1$ 的速比比较这是舍入误差；对下一算例的无级变速器，这是变速器与电热器之差。
:::
:::

## 循环功率陷阱

以上一切都是良性的：损耗不过百分之几，效率表是一张选购清单。陷阱出现在**两个**构件被驱动的那一刻，因为从此内部功率流不再被外部功率流封顶。

::: example 一台效率塌缩的无级变速器 {#ex-variator}
[[#ex-epi1]] 的 $\alpha = 4$ 轮系，齿圈以 $100\ \mathrm{rev / min}$ 驱动，太阳轮由第二个受控源驱动。取 $\eta_0 = 0.98$，列出效率对太阳轮转速的表。

**答。**

| 太阳轮 $\omega_s$ | 行星架 $\omega_c$ | 齿圈输入 | 太阳轮功率 | 行星架输出 | 损耗 | $\eta$ |
|---|---|---|---|---|---|---|
| $- 450$ | $0$ | $450$ | $- 450$ | $0$ | $9.0$ | $- 0.02$ |
| $- 440$ | $1.82$ | $450$ | $- 440$ | $10.0$ | $8.84$ | $0.003$ |
| $- 400$ | $9.09$ | $450$ | $- 400$ | $50.0$ | $8.18$ | $0.093$ |
| $- 300$ | $27.3$ | $450$ | $- 300$ | $150.0$ | $6.55$ | $0.319$ |
| $- 200$ | $45.5$ | $450$ | $- 200$ | $250.0$ | $4.91$ | $0.545$ |
| $- 100$ | $63.6$ | $450$ | $- 100$ | $350.0$ | $3.27$ | $0.771$ |
| $0$ | $81.8$ | $450$ | $0$ | $450.0$ | $1.64$ | $0.996$ |

*（所有功率以 $\lambda = 1$ 为单位，即 [[#ex-epi1]] 的转矩尺度因子。）*

::: solution
配方永远是同样三步。**第一步：**从威利斯方程拿运动学，$\omega_c = ( \omega_s + \alpha \omega_r ) / ( 1 + \alpha )$。**第二步：**从约束法向拿转矩，$T_s : T_r : T_c = 1 : \alpha : - ( 1 + \alpha )$，故 $T_r = 4 \lambda$、$T_c = - 5 \lambda$。**第三步：**在行星架系中算损耗，那里太阳-行星相对速度为 $\omega_s - \omega_c$、齿圈-行星相对速度为 $\omega_r - \omega_c$，而两个构件的功率由构造等大反向：

$$
P_{\mathrm{loss}} = ( 1 - \eta_0 ) \left| T_s ( \omega_s - \omega_c ) \right| = 0.02 \times 1 \times | \omega_s - \omega_c |
$$

$\omega_s = - 440$ 时：$\omega_c = 1.82$，损耗 $0.02 \times 441.8 = 8.84$，有用输出 $10.0$。**这台机器效率 $0.3\ \%$。**把太阳轮推到 $- 450$，行星架停转而损耗仍是 $9.0$ 个单位——器件已变成一条**功率环流**：450个单位从齿圈流入，450个单位从太阳轮流回出去，9个单位在齿面上化为热毁灭，而没有任何东西作为功离开这台机器。

**读这张表的结构，别读它的数字。**行星架的有用输出是 $5 \lambda \omega_c$，而 $\omega_c$ 正比于 $\omega_s + 400$——两个很大、几乎相等的数之差。**损耗取决于啮合处的相对速度，而它一直很大。**任何用两个大转速之差求小转速的周转轮系都在除以一个小数，而效率就是那次除法的价格。一般规则：

$$
\boxed{ \; \eta \rightarrow 0 \ \text{当} \ | i - i_{\mathrm{lock}} | \rightarrow 0 \quad \text{（} \alpha \ \text{固定）} \; }
$$

**把这套代数倒过来说：两条路径速比只差一点点的差动驱动，是一台只要你向它索要接近锁死值的速比就能把它憋停的机器。**这并不稀奇：这就是老式液力机械无级变速器、某些风机差动驱动、以及某一款1960年代无级变速器都在速比范围中间设一个控制系统不得进入的"禁区"的原因。
:::
:::

## 行星轮系设计：三个条件，只有第一个是显然的

::: theorem 装配、邻接与相位条件 {#thm-assembly}
带 $n_p$ 个相同行星轮的多行星轮系，一般装不进去。它能装配，当且仅当三个相互独立的条件成立。

**1. 装配条件（齿的条件）。**太阳轮与齿圈同心、行星轮均布时，齿圈的内齿必须在每个行星轮位置都与太阳轮的齿对正。由于 $Z_r + Z_s$ 是直径所跨越的齿距数，要求是

$$
\boxed{ \; \frac{ Z_s + Z_r }{ n_p } = \text{整数} \; }
$$

**2. 邻接条件（尺寸条件）。**相邻行星轮不得重叠。记 $Z_p = ( Z_r - Z_s ) / 2$，由太阳轮中心-行星轮中心构成的三角形几何得

$$
\boxed{ \; \sin \frac{ \pi }{ n_p } > \frac{ Z_p }{ Z_s + Z_p } \; } \qquad \Longleftrightarrow \qquad \frac{ Z_p }{ Z_s } < \frac{ \sin ( \pi / n_p ) }{ 1 - \sin ( \pi / n_p ) }
$$

**3. 相位条件（角度条件）。**即使齿数对得上、行星轮装得下，每个行星轮轮齿的*角度*位置也必须正确，否则某个行星轮会骑在齿上而不是落在齿槽里。记第 $i$ 个行星轮的 $\gamma_i = ( Z_s + Z_r ) \theta_i / Z_r$，其中 $\theta_i$ 是其角位置，要求是所有 $\gamma_i$ 的小数部分相同。**对均布行星轮，这是齿数对 $n_p$ 取模的条件，也是学生设计中最常被违反的条件，因为它是草图上唯一看不见的那一个。**
:::

::: widget plot
title: 齿圈能容纳的最大行星轮，对行星轮个数
f: sin(pi/x)/(1-sin(pi/x))
x: 3, 8
y: 0, 4
caption: 邻接极限 $Z_p / Z_s < \sin ( \pi / n_p ) / [ 1 - \sin ( \pi / n_p ) ]$。**三个行星轮时，行星轮可以做到太阳轮的六倍；六个行星轮时，它甚至做不到太阳轮那么大。**这就是高传动比大转矩行星级用三四个行星轮而不用六个的原因：增加行星轮的诱惑，是把每个行星轮做小的诱惑；同样太阳轮直径下行星轮变小意味着太阳轮要变小，而同样转矩下太阳轮变小意味着每毫米齿宽的 $W_t$ 更高——而那正是同时决定弯曲应力与点蚀压力的量。**六个行星轮的总承载能力很容易反而低于四个。**
:::

::: example 一台 $5.5 : 1$ 行星级的参数设计 {#ex-proportion}
设计单排行星级的齿数：传动比 $5.5 : 1$，四个行星轮，太阳轮与齿圈 $20^{\circ}$ 不变位，所有齿数不超过125。

**答。**$Z_s = 24$，$Z_p = 42$，$Z_r = 108$，$n_p = 4$。

::: solution
先定速比：$i = 1 + \alpha = 1 + Z_r / Z_s = 5.5$，故 $Z_r = 4.5 \, Z_s$。**速比因此只固定了两个整数之比，此外什么都定不了**——无穷多组解，全由三个条件过滤。

几何：$Z_p = ( Z_r - Z_s ) / 2 = 1.75 \, Z_s$，所以 $Z_s$ 必须是4的倍数，$Z_p$ 才是整数。试 $Z_s = 20$：$Z_r = 90$、$Z_p = 35$。装配：$( 20 + 90 ) / 4 = 27.5$——**不通过**。试 $Z_s = 24$：$Z_r = 108$、$Z_p = 42$。

$$
\text{装配： } \frac{ 24 + 108 }{ 4 } = 33 \checkmark \qquad \text{邻接： } \sin 45^{\circ} = 0.7071 > \frac{ 42 }{ 24 + 42 } = 0.6364 \ \checkmark
$$

相位：$\gamma = ( Z_s + Z_r ) \theta / Z_r = 132 \times 90^{\circ} / 108 = 110^{\circ}$，以一个齿距（$360 / 108 = 3.333^{\circ}$）为单位的小数部分是 $110 / 3.333 = 33.0$ 整——**所以这里相位条件免费满足，因为装配条件恰好让 $\gamma$ 成了整数。**这不普遍；当它不满足时，补救办法是把某个行星轮的角位置有意错开整整一个齿距，也就是把行星架上行星销孔钻在一个不均布的分布圆上。**每个行星数为奇数或齿数比别扭的行星架，都有一个孔看着像加工错误、其实不是。**

**注意设计在哪些地方毫无选择权。**速比定死了 $Z_r / Z_s$；整数要求把 $Z_s$ 定成4的倍数；装配条件再在倍数之间做选择；邻接条件排除了四行星下 $Z_s = 32$ 及以上。**四个约束，一个自由度，答案是 $24 / 42 / 108$，否则免谈。**这就是行星轮齿数在图样上显得随意、实际上是图样上最不随意的数字的原因。
:::
:::

::: exercise 四个行星轮装得进去吗？ {level=2 check="1"}
一行星轮系 $Z_s = 20$、$Z_p = 40$、$Z_r = 100$。对四个行星轮检验装配与邻接条件，并给出传动比。

::: solution
$$
\text{装配： } \frac{ 20 + 100 }{ 4 } = 30 \ \checkmark \qquad \text{邻接： } \sin 45^{\circ} = 0.7071 > \frac{ 40 }{ 20 + 40 } = 0.6667 \ \checkmark
$$

**两条都满足，邻接检验还有 $6\ \%$ 的余量——行星轮装得下，传动比是 $i = 1 + 100 / 20 = \boxed{ 6 }$。**但看看余下的空间有多小。邻接余量按正弦算是 $0.7071 - 0.6667 = 0.0404$，对应齿圈节圆半径 $100\ \mathrm{mm}$ 时约 $1.2\ \mathrm{mm}$ 的行星轮顶隙——**而行星轮还必须躲开齿圈的齿顶、行星架的台肩、太阳轮的台肩，以及必须够到太阳-行星啮合的油路。**邻接检验以 $6\ \%$ 余量通过的设计，是一个行星轮轴承只能选无内圈滚针轴承的设计，因为没有地方放别的。**邻接条件是几何下限；真正定下行星轮尺寸的是润滑与轴承布置，而它们永远比那个正弦更不宽容。**
:::
:::

## 差速器：一台有两个答案的轮系

::: example 开式差速器，一个轮子在冰上 {#ex-diff}
一台轮距 $1.6\ \mathrm{m}$ 的前桥，在干柏油路上以 $14\ \mathrm{m / s}$ 过 $12\ \mathrm{m}$ 半径的弯。车轮半径 $0.31\ \mathrm{m}$。求两个车轮转速与行星齿轮（蜘蛛齿轮）的自转转速。然后：在冰面上，$\mu_{\mathrm{ice}} = 0.10$、$\mu_{\mathrm{dry}} = 0.90$、每个驱动轮压 $4000\ \mathrm{N}$，$3000\ \mathrm{N \cdot m}$ 的桥转矩有多大比例到达路面？

**答。**$442.5$ 与 $420.1\ \mathrm{rev / min}$，蜘蛛齿轮相对转速 $11.2\ \mathrm{rev / min}$；到达路面的转矩 **$8.3\ \%$**。

::: solution
运动学纯属几何。两个车轮走过的弧长比等于其半径比，

$$
\frac{ \omega_{\mathrm{in}} }{ \omega_{\mathrm{out} } } = \frac{ R - t / 2 }{ R + t / 2 } = \frac{ 11.2 }{ 11.8 } = 0.9492
$$

而开式差速器的定义性质是：行星架转速是两个半轴转速的**平均值**——$2:1$ 的蜘蛛关系 $\omega_L + \omega_R = 2\omega_c$，正是威利斯方程的 $\alpha = 1$ 情形。由 $\omega_{\mathrm{mean}} = V/r = 45.16\ \mathrm{rad/s} = 431.3\ \mathrm{rev/min}$，两个条件 $(\omega_{\mathrm{in}} + \omega_{\mathrm{out}})/2 = 431.3$ 与 $\omega_{\mathrm{in}}/\omega_{\mathrm{out}} = 11.2/11.8$ 给出

$$
\omega_{\mathrm{out}} = 431.3 \times \frac{ 2 \times 11.8 }{ 11.2 + 11.8 } = 442.5\ \mathrm{rev/min} \ , \qquad
\omega_{\mathrm{in}} = 431.3 \times \frac{ 2 \times 11.2 }{ 23.0 } = 420.1\ \mathrm{rev/min}
$$

而蜘蛛齿轮相对行星架的转速是每侧 $\left( 442.5 - 420.1 \right) / 2 = 11.2\ \mathrm{rev/min}$。
**稳态转弯时差速器几乎什么都没干——$5.1\ \%$ 的转速差——这正是全部要点：开式差速器是一台终生近乎锁死的机器，所以它的效率是 $98$–$99\ \%$，所以没人注意到它在那里，直到需要它的时候。**

**现在看冰面。**开式差速器永远平均分配转矩，因为蜘蛛齿轮没有任何办法反作用一个转矩差——转矩分配是 $\alpha = 1$ 的*运动学*推论，不是可调参数。于是两轮各得 $1500\ \mathrm{N \cdot m}$，冰面轮在

$$
T_{\mathrm{ice}} = \mu_{\mathrm{ice}} W r = 0.10 \times 4000 \times 0.31 = 124\ \mathrm{N \cdot m}
$$

处失去附着，总驱动转矩塌缩到 $3000$ 可用中的 $2 \times 124 = 248\ \mathrm{N \cdot m}$——**$8.3\ \%$。**本可吃下 $1116\ \mathrm{N \cdot m}$ 的干地轮，被故意只给了 $124$。

| 差速器 | 到达轮对的转矩 | 占桥转矩比例 |
|---|---|---|
| 开式（转矩偏置1:1） | $248\ \mathrm{N \cdot m}$ | $8.3\ \%$ |
| 限滑，偏置3.5:1 | $124 + 3.5 \times 124 = 558\ \mathrm{N \cdot m}$ | $18.6\ \%$ |
| 锁止（100 %） | $( 0.1 + 0.9 ) \times 4000 \times 0.31 = 1240\ \mathrm{N \cdot m}$ | $41.3\ \%$ |

**最后一行就是锁止差速器禁止在干路上使用的原因：**两轮都满附着时，锁死的桥强迫它们同速转动，而转弯时这意味着其中一个必须持续打滑 $3.5\ \%$，那是一个吃轮胎、敲转向节、给桥轴上劲的状态，而传动系储存的扭转能量要用一次冲击来付账。**限滑装置的全部艺术，就是在需要时做第三行、不需要时做第一行，而它的每一个版本——离合器组、齿轮耦合、托森（Torsen）、黏性耦合——都是让转矩偏置依赖转速差、而不是完全不依赖转速差的不同做法。**
:::

## 当一级必须干三级的活

::: definition 特殊周转轮系 {#def-special}
两个家族拿普通行星轮系的皮实，去换一个本来需要好几级才有的传动比。

**谐波（应变波）减速器。**一只薄壁柔性杯——**柔轮**——带 $Z_f$ 个外齿，被**波发生器**变形为椭圆，在长轴两端与一个带 $Z_c$ 个内齿的刚性**刚轮**及刚性输出啮合。因为柔轮在刚轮*内部*且少两个齿，波发生器每转一圈使它前移两个齿距：

$$
i = - \frac{ Z_f }{ Z_c - Z_f } = - \frac{ Z_f }{ 2 } \qquad \Rightarrow \qquad Z_f = 198 , \ Z_c = 200 \ \Longrightarrow \ i = - 99
$$

**构造上侧隙为零**（柔轮被弹性预紧压在刚轮上），位置重复精度近乎无穷，扭转刚度 $5$–$15\ \mathrm{N \cdot m / arcmin}$。代价：柔轮是一个**疲劳构件**，额定寿命约 $10^{8}$ 次弯曲循环，在连续 $100\ \mathrm{rev / min}$ 输入下**不到两年**；效率 $0.75$–$0.85$；$0.05$–$0.15\ \mathrm{N \cdot m}$ 与转矩无关的迟滞损耗，在轻载下主导效率；以及完全不容忍冲击。

**摆线（针轮）减速器。**一张带 $Z_r - 2$ 个滚子的摆线轮，经偏心轴在 $Z_r$ 个固定针齿内滚动。传动比 $i = Z_r / ( Z_r - Z_{\mathrm{disc}} )$，单级典型 $9$–$119$，**全部齿同时接触**——载荷分配系数 $K_\gamma \approx 1.01$，一切齿轮家族中最好，因为接触图案是几何强制的，不靠柔顺去均化。扭转刚度是同尺寸行星轮系的数倍，寿命 $30\,000$–$100\,000$ 小时，效率 $0.90$–$0.95$。代价是滚子通过频率上一个**类似整流的速度纹波**（这就是摆线轴需要在输出端、而不是电机端装高分辨率编码器的原因）、昂贵的磨削偏心滚子，以及每单位转矩两三倍到四倍于行星轮系的价格。
:::

| 家族 | 每级传动比 | $\eta$ | $K_\gamma$ | 侧隙 | 寿命 | 相对价格 |
|---|---|---|---|---|---|---|
| 渐开线直齿/斜齿 | $\le 7$ | 0.985 | 1.00 | 8–20 角分 | $10^{9}$ 循环 | 1.0 |
| 行星（3–4行星轮） | $\le 8$ | 0.984 | 1.05–1.15 | 5–15 角分 | $10^{9}$ 循环 | 1.5 |
| 摆线 | $\le 119$ | 0.92 | 1.01 | $< 1$ 角分 | $3 \times 10^{4}$–$10^{5}\ \mathrm{h}$ | 3.0 |
| 谐波 | $\le 200$ | 0.80 | 1.00 | 0 | $10^{8}$ 循环 | 4.0 |
| 蜗杆，自锁 | $\le 60$ | 0.40–0.77 | n/a | 15–40 角分 | 磨损限制 | 1.2 |

::: exercise 谐波减速器寿命 {level=2 check="1.9"}
一台谐波减速器柔轮 $Z_f = 198$ 齿、刚轮 $Z_c = 200$ 齿。给出传动比，并在柔轮额定 $10^{8}$ 次弯曲循环、输入 $100\ \mathrm{rev / min}$ 连续运转下估算寿命。

::: solution
$$
i = - \frac{ Z_f }{ Z_c - Z_f } = - \frac{ 198 }{ 2 } = - 99
$$

**而寿命才是决定应用的那个数字。**柔轮每经历一次波发生器转动就完成一次完整弯曲循环，所以 $100\ \mathrm{rev / min}$ 下它每分钟消耗 $10^{8}$ 次额度中的 $100$ 次：

$$
\frac{ 10^{8} \ \text{次循环} }{ 100 \ \mathrm{rev / min} } = 1.0 \times 10^{6} \ \mathrm{min} = 16{,}700 \ \mathrm{h} = \boxed{ 1.9 \ \text{年连续运转} }
$$

**就是这一次除法，让谐波减速器进了机器人腕关节、望远镜驱动与天线座架，而没进输送机驱动和风机。**它们是唯一寿命由弹性弯曲循环数而非接触疲劳决定的齿轮家族——而弯曲循环是按*时间*消耗的，不按*载荷*消耗，所以一台整夜空载怠工的谐波减速器，磨损速率与一台干活的完全相同。**接触疲劳的齿轮可以被工作循环救下来；弯曲构件不行。**
:::
:::

## 设计：一台 $1.5\ \mathrm{MW}$ 风机的 $100 : 1$ 齿轮箱 {#sec-winddesign}

::: example 三级的参数分配 {#ex-wind}
一台 $1.5\ \mathrm{MW}$ 风机转子转速 $15.0\ \mathrm{rev / min}$，发电机 $1500\ \mathrm{rev / min}$。总传动比 $100 : 1$。分配各级，求转矩、齿圈反作用，以及润滑系统必须带走的热。

**答。**行星-行星-斜齿，$5.500 \times 4.600 \times 3.952 = 99.995$；转子轴 $955\ \mathrm{kN \cdot m}$；最大齿圈反作用 $781\ \mathrm{kN \cdot m}$；热 $69\ \mathrm{kW}$。

::: solution
**各级速比。**两行星级加一斜齿级，选取使各级齿数都通过 [[#thm-assembly]] 三个条件：

| 级 | 类型 | $Z_s$ | $Z_p$ | $Z_r$ | $n_p$ | 速比 | $\eta$ |
|---|---|---|---|---|---|---|---|
| 1 | 行星，齿圈保持 | 24 | 42 | 108 | 4 | 5.500 | 0.9836 |
| 2 | 行星，齿圈保持 | 20 | 26 | 72 | 4 | 4.600 | 0.9844 |
| 3 | 斜齿，$83 / 21$ | — | — | — | — | 3.952 | 0.9850 |
| | | | | | **合计** | **99.995** | **0.9537** |

校核第1级：$( 24 + 108 ) / 4 = 33$ 整数 ✓；$\sin 45^{\circ} = 0.7071 > 42 / 66 = 0.6364$ ✓。第2级：$( 20 + 72 ) / 4 = 23$ ✓；$0.7071 > 26 / 46 = 0.5652$ ✓。**两级都是行星架入、太阳轮出、齿圈保持——一台增速机，正是风机需要的，而 [[#ex-eff4]] 的第一条曲线表明这正是该布置的高效方向。**

**力流。**转子转矩 $= 1.5 \times 10^{6} / ( 15.0 \times 2\pi / 60 ) = 954.9\ \mathrm{kN \cdot m}$：

| 构件 | 转速 | 转矩 | 注记 |
|---|---|---|---|
| 转子轴 = 第1级行星架 | 15.0 | $954.9\ \mathrm{kN \cdot m}$ | 4根臂，每根行星销 $239\ \mathrm{kN \cdot m}$ |
| 第1级齿圈（保持） | 0 | $781.3\ \mathrm{kN \cdot m}$ | **反作用进箱体，不传递任何东西** |
| 第1级太阳轮 = 第2级行星架 | 82.5 | $170.8\ \mathrm{kN \cdot m}$ | |
| 第2级齿圈（保持） | 0 | $133.7\ \mathrm{kN \cdot m}$ | |
| 第2级太阳轮 = 第3级小齿轮 | 379.5 | $36.5\ \mathrm{kN \cdot m}$ | |
| 发电机 | 1499.9 | $9.11\ \mathrm{kN \cdot m}$ | $1.500$ 中输出 $1.431\ \mathrm{MW}$ |

**箱体承受着 $781\ \mathrm{kN \cdot m}$，它从不出现在任何一根轴上。**这就是设计的全部结构内涵：齿圈压装进球墨铸铁箱体，箱体的职责是做一台封闭的转矩框架，而整个铸件按这个反作用定尺寸，不按它支承重量的多少。

**轮齿。**第1级模数 $m = 16\ \mathrm{mm}$：太阳轮节圆半径 $0.016 \times 24 / 2 = 0.192\ \mathrm{m}$，所以太阳-行星啮合共承 $170.8 \times 10^{3} / 0.192 = 889\ \mathrm{kN}$，每个行星轮 $222\ \mathrm{kN}$。刘易斯公式，$\sigma_{\mathrm{allow}} = 850\ \mathrm{MPa}$、$Y = 0.40$：

$$
b = \frac{ W_t }{ \sigma_{\mathrm{allow}} \, m \, Y } \times K_\gamma = \frac{ 222 \times 10^{3} }{ 850 \times 10^{6} \times 0.016 \times 0.40 } \times 1.10 = 45\ \mathrm{mm}
$$

**而设计用 $b = 70\ \mathrm{mm}$，因为说了算的是点蚀，不是弯曲**——[[mechanisms/gears]] 对那台 $55\ \mathrm{kW}$ 工业齿轮箱得出的同一结论，在两千倍的转矩上。齿圈节圆直径 $0.016 \times 108 = 1.73\ \mathrm{m}$，这就是一台 $1.5\ \mathrm{MW}$ 风机第一级的真身。

**热。**$1.500 \times ( 1 - 0.9537 ) = 69\ \mathrm{kW}$ 的热，在一台约 $3\ \mathrm{t}$ 的齿轮箱里——足以要求 $120$–$150\ \mathrm{l / min}$ 经过滤冷却的油，以及一台 $90\ \mathrm{kW}$、接入风机自身冷却回路的水冷器。**润滑系统不是风机齿轮箱的附件；它的失效模式——滤芯堵塞、泵密封、被玉米地糊住的冷却器——就是风机的失效模式。**

**为什么不用一级？**$i = 100$ 需要 $\alpha = 99$，于是 $Z_p = ( 99 - 1 ) Z_s / 2 = 49 \, Z_s$，邻接条件要求

$$
\sin \frac{ \pi }{ n_p } > \frac{ 49 Z_s }{ Z_s + 49 Z_s } = 0.980 \quad \Longrightarrow \quad n_p < 2.29
$$

**所以单级 $100 : 1$ 行星轮系只能有两个行星轮。**它的载荷分配系数会是 $K_\gamma = 1.05$——可观——但它没有冗余、有一个不均衡的双臂行星架、行星轮大到装不下第三个，以及一只 $99 \times 17 = 1683$ 齿的齿圈。**迫使风机齿轮箱做成三级的，是邻接条件，不是强度，也不是尺寸。**
:::
:::

::: exercise 为什么是三级不是两级 {level=3 check="2"}
上面那台 $1.5\ \mathrm{MW}$ 齿轮箱能否做成两个 $10 : 1$ 的行星级？对 $\alpha = 9$ 分别按三个与四个行星轮检验邻接条件，并给出装得下的最大行星轮数。

::: solution
$\alpha = 9$ 时：$Z_p = ( 9 - 1 ) Z_s / 2 = 4 Z_s$，于是

$$
\frac{ Z_p }{ Z_s + Z_p } = \frac{ 4 }{ 5 } = 0.800 \quad \Rightarrow \quad \sin \frac{ \pi }{ n_p } > 0.800 \ \Rightarrow \ \frac{ \pi }{ n_p } > 0.9273\ \mathrm{rad} \ \Rightarrow \ n_p < 3.39
$$

$$
n_p = 3 : \ \sin 60^{\circ} = 0.8660 > 0.800 \ \checkmark \qquad n_p = 4 : \ \sin 45^{\circ} = 0.7071 < 0.800 \ \times
$$

**所以最多 $\boxed{ 3 }$ 个行星轮，而两级方案并非不可能——只是更差。**三个行星轮给 $K_\gamma = 1.07$，对比四行星设计的 $1.10$，均载反而更好；你失去的是**全部 $955\ \mathrm{kN \cdot m}$ 现在经过三根行星销而不是四根，每根销承 $318$ 而不是 $239\ \mathrm{kN \cdot m}$，而行星轮轴承——风机行星级里真正受寿命限制的构件——被要求在同一直径下多给 $33\ \%$ 的 $L_{10}$ 寿命。**你失去的第二样东西是冗余：**$\alpha = 9$ 时齿圈反作用是行星架转矩的 $9 / 10$，所以单个 $10 : 1$ 级在一圈齿圈里保持 $859\ \mathrm{kN \cdot m}$，而不是一个 $781$ 加另一个 $134$，箱体于是变成按一个庞然大物定尺寸的单一铸件。**两级更便宜也更差；三级是邻接条件与轴承寿命共同算出来的答案。**

::: quiz 惰轮与齿数 {#quiz-idler}
某复合轮系第一级是 $19 / 95$，第二级是 $17 / 95$。哪个说法正确？

- [ ] 两级一样好，因为两个小齿轮齿数都是质数
- [x] 第一级是坏的那级：$95 = 5 \times 19$，故 $\gcd = 19$，每个大轮齿在这台齿轮箱的一生中只被一个小齿轮齿敲击
- [ ] 第二级更糟，因为 $17$ 不整除 $95$
- [ ] 都无所谓，因为接触图案总会绕着两个齿轮走

::: solution
**第一级是坏的那级。**$\gcd ( 19 , 95 ) = 19$，所以大轮95个齿中每个只被 $95 / 19 = 5$ 个小齿轮齿访问——而更糟的是，**每个大轮齿只被一个小齿轮齿敲击，永远如此。**$\gcd ( 17 , 95 ) = 1$，所以第二级在"打猎"：小齿轮1号齿走完全部95个大轮齿才回到家，每对齿在大轮每95转中相遇一次。

**这道题的要点是：看一眼看不出来，质不质数帮不上忙。**$19$ 是质数而 $19 / 95$ 是可得的最差配对，因为 $95$ 恰好是它的倍数；$17$ 是质数而 $17 / 95$ 完美。**检验是 $\gcd ( N_1 , N_2 ) = 1$，别无其他。**把第一级大轮从95齿改成96齿，速比动 $1.05\ \%$，访问数从5跳到95——**轮系设计里最便宜的可靠性提升，也是从不出现在强度计算里的那一个。**
:::
:::

::: quiz 循环功率 {#quiz-circ}
一台 $\alpha = 6$ 的周转轮系，齿圈由一个 $3600\lambda$ 单位的源以 $+ 600\ \mathrm{rev / min}$ 驱动，太阳轮由第二个源以 $- 3000\ \mathrm{rev / min}$ 驱动，其中 $\lambda$ 是转矩尺度因子 $T_s : T_r : T_c = 1 : 6 : - 7$。行星架转速是多少？效率大约多少？

- [x] $+ 86\ \mathrm{rev / min}$，约 $8\ \%$——有用输出小，因为它是两个大数之差，而损耗不小
- [ ] $+ 86\ \mathrm{rev / min}$，约 $98\ \%$，因为效率是啮合的属性、不是转速的属性
- [ ] $- 343\ \mathrm{rev / min}$，约 $98\ \%$
- [ ] 该布置不可能：行星轮系不能有两个输入

::: solution
**$+ 86\ \mathrm{rev / min}$，约 $8\ \%$。**威利斯方程给 $\omega_c = ( \omega_s + \alpha \omega_r ) / ( 1 + \alpha ) = ( - 3000 + 3600 ) / 7 = + 85.7$。功率账是

$$
P_{\mathrm{ring}} = 6 \lambda \times 600 = 3600 \lambda \quad \text{入}, \qquad
P_{\mathrm{sun}} = 1 \lambda \times ( - 3000 ) = - 3000 \lambda \quad \text{从太阳轮出}, \qquad
P_c = - 7 \lambda \times 85.7 = 600 \lambda \ \text{出}
$$

而损耗在行星架系中求值：$0.02 \times | \omega_s - \omega_c | = 0.02 \times 3086 = 61.7 \lambda$。对外部总输入 $6600 \lambda$，效率是 $\left( 600 - 61.7 \right) / 6600 = 8.2\ \%$。

**选项2是那个诱人的错误答案，而它错在一个值得精确说出的理由：$\eta_0$ 是啮合的属性，但*损耗*是 $\eta_0$ 乘以啮合处的相对速度，而相对速度由设计师对"保持哪个构件、其余转多快"的选择决定。**把太阳轮推到 $- 3600\ \mathrm{rev / min}$，行星架彻底停转：齿圈的 $3600 \lambda$ 原样从太阳轮送回，$72 \lambda$ 化为热毁灭，机器什么都不传递。**那就是一次憋停，而每台分流传动在它的地图上某处都有一台——设计问题是控制系统是否被允许开进去。**
:::
:::

::: exercise 刚性齿圈的代价 {level=2 check="0.61"}
一个四行星轮级按轴向浮动齿圈设计，达到 $K_\gamma = 1.10$。采购变更换成了定位刚性的齿圈，同一张图给出 $K_\gamma = 1.80$。该级的转矩额定值必须降到几折？

::: solution
承载能力按 $n_p / K_\gamma$ 走，而 $n_p$ 没变，所以

$$
\frac{ T_{\mathrm{rigid}} }{ T_{\mathrm{floating}} } = \frac{ K_{\gamma, \mathrm{floating}} }{ K_{\gamma, \mathrm{rigid}} } = \frac{ 1.10 }{ 1.80 } = \boxed{ 0.61 }
$$

**一次图纸改动删掉一个滑动配合和一处间隙，换来转矩额定值砍掉 $39\ \%$。**这个机理值得说透，因为它是浮动齿圈不是可选精修的原因。齿圈刚性时，四个行星轮必须同时被行星架销孔与齿圈内孔定位到齿厚的一小部分以内；$0.03\ \mathrm{mm}$ 的综合误差，按每毫米齿宽 $20\ \mathrm{N / \mu m}$ 的啮合刚度，就把工作载荷的几十个百分点压到最走运的那个行星轮上。**浮动齿圈彻底删掉了这个约束：齿圈沿轴向滑到它的齿均匀承载为止，公差链从力流里消失了。**代价是一个花键或鼓形齿定位、一道必须容忍浮动的密封，以及一条写着"齿轮未啮合到位前不得拧紧齿圈压板"的装配说明——而这正是会被无视的那条说明，其结果是一台挂着 $1.00$ 铭牌的 $0.61$ 机器。
:::

## 后续内容

- **效率是一张地图，不是一个数。**[[#ex-variator]] 的变速器曲线对每台分流传动都是同一个形状，而那些失败的机器——1970年代的液力机械无级变速器、1980年代差动喂带的带传动——失败是因为控制系统被允许停在曲线的平坦段上。设计交付物是画着禁区的地图，不是铭牌上的百分比。
- **下一层是控制系统。**两个构件被驱动的行星轮系是一台差速器，而一个构件由机器驱动而非被制动的差速器是一台**功率分流装置**——这就是混合动力汽车根本没有变速箱的原因，也是它的发动机可以在一个转速运转、车轮在另一个转速运转的原因。那是 [[control-systems]] 施加在传动系上的课题。
- **弹性是让算术成立的东西。**均载、鼓形、浮动齿圈、扭转软行星架，全是同一个手法：让变形去做公差链做不到的事。定量版本在 [[materials-science/mechanical-properties]] 与 [[vibrations/two-degrees-of-freedom]]——那里每毫米 $20\ \mathrm{N / \mu m}$ 的啮合刚度会以弹簧的身份重现于经典三质量扭转模型，决定齿轮箱第一阶扭转固有频率是否压在啮合频率之下。
- **齿形是一门独立的学问、一种独立的失效。**这里的一切把齿轮当作一个速比。[[mechanisms/gears]] 把它当作一个接触，而两种观点对 [[#ex-wind]] 风机齿轮箱哪一级先坏各执一词——算术说都不坏，点蚀计算说第3级，现场数据说行星轮轴承。
- **整数问题不会消失；它变成一次设计空间搜索。**当速比只是二十个约束之一——噪声、质量、效率、布置、与兄弟件通用——答案来自在计算机上枚举合法齿数，而这正是每台商用齿轮箱背后的行星轮系搜索所归结成的事。

::: summary 要点
- **齿轮传动比是两个整数的精确之比。**这是用齿轮的全部理由，也是轮系设计首先是数论问题、然后才是强度问题的全部理由。
- **惰轮只改符号与中心距。**它的齿数在轮系传动比里恒等消去；它的啮合、轴承、密封、损耗与固有频率不会消去。
- **让相邻齿数互质。**检验是 $\gcd ( N_1 , N_2 ) = 1$；任一齿数是不是质数不算数。非猎齿副按周期图案磨损，并以大轮自身频率的振动报告自己。
- **威利斯：$\omega_s + \alpha \omega_r = ( 1 + \alpha ) \omega_c$。**三个速度一个线性方程；列表法是它的叠加形式，对任何周转轮系、无论多复杂都管用。
- **转矩是 $1 : \alpha : - ( 1 + \alpha )$，被保持构件承载转矩不承载功率。**风机齿轮箱里最大的那个转矩永远到不了任何一根轴。
- **效率取决于你保持哪个构件**，因为损耗正比于啮合处的*相对*速度。$\alpha = 4$ 时，保持太阳轮而不是齿圈，值四倍的损耗差别。
- **两个构件被驱动就意味着循环功率。**当所需速比逼近锁死值，有用输出变成两个大数之差而损耗依旧很大，效率先归零再变负。每台分流传动的地图上都有这样一次憋停。
- **三个条件决定行星轮系：装配、邻接、相位。**$( Z_s + Z_r ) / n_p$ 为整数，$\sin ( \pi / n_p ) > Z_p / ( Z_s + Z_p )$，齿相位对齐。**迫使 $100 : 1$ 风机齿轮箱做成三级的是邻接条件，不是强度**——$\alpha = 99$ 时它只允许两个行星轮。
- **除非你允许，行星轮不会均载。**承载能力按 $n_p / K_\gamma$ 走；浮动齿圈买到 $K_\gamma = 1.05$–$1.10$，刚性齿圈让你赔上额定值的 $39\ \%$。
- **把速比选在 $\sqrt{ J_L / J_m }$ 的两倍因子以内，然后在转速与精度允许下选到最小。**加速高原很宽；折算侧隙正比于 $i$，它不宽。
:::

## 载荷分担：为什么四个行星轮不承四倍载

::: definition 载荷分配系数 {#def-loadshare}
若 $n_p$ 个行星轮完全均载，每个承 $T / n_p$，该级承一个啮合承载能力的 $n_p$ 倍。它们并不如此。AGMA 6102 的**载荷分配系数** $K_\gamma$ 定义为

$$
P_{\max} = \frac{ P_{\text{total}} }{ n_p } \, K_\gamma \qquad \Rightarrow \qquad \text{承载能力} \propto \frac{ n_p }{ K_\gamma }
$$

对制造良好、正确浮动的级，其推荐值为：

| 行星轮数 $n_p$ | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| $K_\gamma$（设计良好） | 1.05 | 1.07 | 1.10 | 1.12 | 1.15 |
| $K_\gamma$（刚性、制造差） | 1.25 | 1.50 | 1.80 | 2.20 | 2.60 |
| 净承载能力 $n_p / K_\gamma$（好） | 1.90 | 2.80 | 3.64 | 4.46 | 5.22 |
| 净承载能力（差） | 1.60 | 2.00 | 2.22 | 2.27 | 2.31 |

::: solution
**读最后两行。**设计良好的四行星轮级承3.64倍单啮合，不是四倍；设计糟糕的承2.22倍，**低于设计良好的两行星轮级。**而糟糕设计那一行会饱和：四个行星轮之后，再加什么也买不到，因为载荷早已找到自己的路径，多出的行星轮是空座的乘客。

物理原因是：行星轮只有都占据同样位置才能分担载荷，而它们做不到，因为行星架销孔镗到 $\pm 0.02\ \mathrm{mm}$，太阳轮与齿圈的定位到 $\pm 0.03\ \mathrm{mm}$，而啮合刚度是每毫米齿宽 $20\ \mathrm{N / \mu m}$——所以 $0.03\ \mathrm{mm}$ 的位置误差就是每毫米齿宽 $60\ \mathrm{N / \mu m \times mm}$ 的载荷不均，占工作载荷的几十个百分点。**补救措施全是同一思想的变体：让力流路径足够柔顺，使弹性变形去均载；或让某个构件能够浮动。**按有效性排序：**轴向浮动齿圈**（齿圈可沿轴向移动约半个齿深，自己找到最佳位置——仅此一项就找回大部分理想值）、**扭转软行星架**（故意做薄的行星架盖板，其扭角远大于齿距误差）、**调心行星轮轴承**让每个行星轮可以倾斜、以及**齿面鼓形**容忍不均载造成的不对中。**浮动齿圈加软行星架的级，六个行星轮能做到 $K_\gamma = 1.05$。刚性齿圈加硬行星架的级，四个行星轮就到 $K_\gamma = 2.5$，于是设计师后半生都在解释为什么这台齿轮箱的额定值只有轮齿能力的三分之一。**
:::

## 选择传动比：惯量、转速与天花板

::: example 伺服轴：最优传动比，以及你不会用它的原因 {#ex-inertia}
一台回转工作台带着 $0.40\ \mathrm{kg \cdot m^2}$ 的夹具与工件。电机是 $3\ \mathrm{kW}$ 交流伺服，$J_m = 2.0 \times 10^{-4}\ \mathrm{kg \cdot m^2}$、峰值转矩 $19\ \mathrm{N \cdot m}$，转速上限 $3000\ \mathrm{rev / min}$。什么传动比使工作台加速度最大？设计实际会用多少？

**答。**加速度最优 $\boxed{i_{\mathrm{opt}} = 44.7}$；设计实际用 $i \approx 20$。

::: solution
把载荷折算到电机侧并求导：电机转矩 $T_m$ 经传动比 $i$ 在载荷侧产生的角加速度为

$$
\alpha_L = \frac{ T_m \, i }{ J_m i^{2} + J_L }
$$

其导数为零处即 $J_m i^{2} = J_L$ 处取极大，

$$
i_{\mathrm{opt}} = \sqrt{ \frac{ J_L }{ J_m } } = \sqrt{ \frac{ 0.40 }{ 2.0 \times 10^{- 4 } } } = \sqrt{ 2000 } = 44.7 \ , \qquad \alpha_L = \frac{ 19 \times 44.7 }{ 0.40 + 0.40 } = 1062\ \mathrm{rad / s^2}
$$

::: widget plot
title: 载荷侧加速度对传动比，同一电机同一载荷
f: 19*x/(0.0002*x*x+0.4)
x: 1, 120
y: 0, 1100
caption: 上述伺服的 $\alpha_L = T_m i / ( J_m i^2 + J_L )$。**曲线在峰值附近出奇地平**——$i = 30$ 给 $983\ \mathrm{rad / s^2}$，$i = 60$ 给 $1018$，都在最优的 $8\ \%$ 以内——**而在低传动比一侧它掉下悬崖**，$i = 10$ 只得 $452$。**这个不对称就是惯量匹配规则的实际内涵：传动比取低了是严重损失，取高了是轻微损失，而"最优"是一片宽高原的中部。**所以这条规则应当读作"把 $i$ 保持在 $\sqrt{ J_L / J_m }$ 的两倍因子以内"，而不是一个要命中的靶心。
:::

**为什么设计不会用44.7。**$i = 44.7$ 时，工作台 $60\ \mathrm{rev / min}$ 的最高转速要求电机 $2680\ \mathrm{rev / min}$——在上限之内，但仅一点余量，而真正限制定位轴的是峰值转矩下的转速。更重要的是：

1. **齿轮箱自己有惯量。**$i = 45$ 的三级轮系在电机法兰处再贡献 $J_m i^2$ 的 $15$–$25\ \%$，把真实最优拉低 $7$–$12\ \%$，让本已平坦的高原更平。
2. **高原是平的，侧隙不是。**折算到载荷侧的侧隙 $j_{\mathrm{out}} = j_{\mathrm{in}} \times i$；$i = 45$、每级 $8$ 角分空程、共三级时，工作台有 $24 \times 45 / 60 = 18$ 角分的死区，对直径 $500\ \mathrm{mm}$ 的工作台就是边缘处 $1.3\ \mathrm{mm}$。**多数伺服轴里定下传动比的是定位精度，不是加速度。**
3. **高原是平的，价格不是。**每多一级，付出 $1.5\ \%$ 的功率、一道密封、一个固有频率、一嘴可能出事的齿。

**这条规则的诚实表述是：把 $i$ 选在 $\sqrt{ J_L / J_m }$ 的两倍因子以内，然后在转速与精度要求允许的范围内把它选到最小。**
:::
