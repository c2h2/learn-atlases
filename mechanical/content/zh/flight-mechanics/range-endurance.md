一架远程客机携带的燃油占起飞质量的四分之一甚至更多，而一架轻型飞机的油箱决定了一次越野飞行是否需要中途经停。由此产生两个问题：飞机用给定的燃油能飞多远（它的**航程**，range），以及能在空中停留多久（它的**航时**，endurance）？由于飞机在消耗燃油时变轻，两个答案都要通过对整个飞行过程中的燃油流量积分得到，其结果——**布雷盖航程方程**（Breguet range equation）——是飞机设计中最常用的公式之一。它表明航程取决于分属三个不同学科的三个数：气动效率$L/D$、发动机的耗油率，以及以起飞重量与着陆重量之比表示的结构效率。

本讲建立在[[flight-mechanics/steady-flight-performance]]中的极曲线、最小阻力和最小功率条件以及两架示例飞机的基础上。发动机如何产生推力、其耗油率为何如此，属于[[propulsion/thrust-efficiency]]和[[propulsion/gas-turbine-cycles]]的内容。

## 耗油率 {#sec-fuel}

喷气发动机产生推力，其燃油消耗与推力成比例；活塞发动机（或涡轮螺旋桨发动机）产生轴功率，其燃油消耗与功率成比例。用**重量**流率来度量燃油流量较为方便，这样它可以直接从飞机重量中减去。

::: definition 耗油率 {#def-sfc}
- 喷气发动机的**推力耗油率**$c_T$是单位时间内单位推力所消耗的燃油重量：
$$
\dot W_f = c_T\,T,\qquad [c_T] = \mathrm{N\,s^{-1}/N} = \mathrm{s^{-1}} .
$$
- 活塞发动机或涡轮螺旋桨发动机的**功率耗油率**$c_P$是单位轴功所消耗的燃油重量：
$$
\dot W_f = c_P\,P_{\text{shaft}},\qquad [c_P] = \mathrm{N/J} = \mathrm{m^{-1}} .
$$
发动机数据单中使用的以质量为基准的数值是$c_T/g$（单位为$\mathrm{mg\,N^{-1}\,s^{-1}}$）和$c_P/g$（**有效耗油率**，BSFC，单位为$\mathrm{kg/(kW\,h)}$）。
:::

工业界仍以“每磅推力每小时消耗的燃油磅数”给出$c_T$，这其实就是以$\mathrm{h^{-1}}$为单位的$c_T$。当前大涵道比涡轮风扇发动机巡航时$c_T \approx 0.5$–$0.6\ \mathrm{h^{-1}}$（截至2026年）；$0.55\ \mathrm{h^{-1}} = 1.528\times10^{-4}\ \mathrm{s^{-1}}$，即$15.6\ \mathrm{mg\,N^{-1}\,s^{-1}}$。轻型飞机活塞发动机在贫油巡航时的 BSFC 约为$0.25\ \mathrm{kg/(kW\,h)}$，即$c_P = 0.25 \times 9.80665/(3.6\times10^{6}) = 6.81\times10^{-7}\ \mathrm{m^{-1}}$。螺旋桨以效率$\eta_p$把轴功率转化为推力功率：$TV = \eta_pP_{\text{shaft}}$。

::: warning 质量、重量与小时
耗油率至少以四种单位制出现，相差一个$g = 9.81$或$3600$的错误是航程计算中最常见的错误。代入之前，把$c_T$换算为$\mathrm{s^{-1}}$（重量基准），把$c_P$换算为$\mathrm{m^{-1}}$（重量基准），并检查最终答案的单位：布雷盖航程必须以米为单位，航时必须以秒为单位。能发现大多数疏漏的合理性检查：一架窄体客机用约$12$–$15\ \mathrm{t}$燃油飞约$5000\ \mathrm{km}$；一架轻型飞机用$100\ \mathrm{kg}$燃油飞约$1000\ \mathrm{km}$。
:::

## 喷气式飞机的布雷盖航程方程 {#sec-jet-range}

巡航期间，飞机在每一瞬时都处于定常水平飞行，因此$L = W$，$T = D$。重量以燃油消耗的速率减小：
$$
\frac{\mathrm{d}W}{\mathrm{d}t} = -\dot W_f = -c_TT = -c_TD = -c_T\frac{W}{L/D}.
$$ {#eq-dwdt}
在时间$\mathrm{d}t$内飞过的距离为$\mathrm{d}x = V\,\mathrm{d}t$，故
$$
\mathrm{d}x = -\frac{V}{c_T}\,\frac{L}{D}\,\frac{\mathrm{d}W}{W} .
$$ {#eq-dx}
**比航程**（specific air range）$-\mathrm{d}x/\mathrm{d}W = V(L/D)/(c_TW)$是当前重量下每单位燃油重量所飞的距离；航程是它从初始重量$W_0$到最终重量$W_1$的积分。积分结果取决于重量减小时飞行员保持哪些量不变。

::: proposition 喷气式飞机的布雷盖航程与航时 {#prop-breguet-jet}
若巡航中真空速$V$、升阻比$L/D$和推力耗油率$c_T$保持不变，则航程和航时为
$$
R = \frac{V}{c_T}\,\frac{L}{D}\,\ln\frac{W_0}{W_1},\qquad
E = \frac{1}{c_T}\,\frac{L}{D}\,\ln\frac{W_0}{W_1} .
$$ {#eq-breguet-jet}
$V$不变且$L/D$不变（即$C_L$不变）要求密度与重量成比例地减小，因此飞机在消耗燃油时逐渐上升：这就是**巡航爬升**（cruise-climb）。
:::

::: proof
在$V$、$L/D$和$c_T$提到积分号外的情况下，从$W_0$到$W_1$积分[[#eq-dx]]：$R = (V/c_T)(L/D)\int_{W_1}^{W_0}\mathrm{d}W/W = (V/c_T)(L/D)\ln(W_0/W_1)$。对于航时，$\mathrm{d}t = \mathrm{d}x/V$，因而因子$V$消去。关于飞行状态：在固定的极曲线上$L/D$不变意味着$C_L$不变；$W = \tfrac12\rho V^2SC_L$在$V$和$C_L$不变时要求$\rho \propto W$。假设：准定常水平飞行（$L = W$，$T = D$，巡航爬升的爬升角可忽略），燃油是唯一减少的重量，$c_T$与推力状态和高度无关，无风。
:::

该方程把三个学科精确地分开：$V(L/D)$（更确切地说是$M(L/D)$，因为在固定马赫数下，涡轮风扇发动机的$c_T$大致与环境温度的平方根成比例变化，声速也是如此）属于气动设计者，$1/c_T$属于发动机设计者，$\ln(W_0/W_1)$属于结构设计者，因为每节省一千克结构都可以换成燃油。

::: example 喷气运输机的航程 {#ex-jet-range}
[[flight-mechanics/steady-flight-performance]]中的喷气运输机以$70\,000\ \mathrm{kg}$在$11\ \mathrm{km}$、马赫数$0.78$开始巡航，可用巡航燃油为$12\,000\ \mathrm{kg}$，$c_T = 0.55\ \mathrm{h^{-1}}$。求巡航爬升的航程和航时，以及巡航结束时的高度。
::: solution
由[[flight-mechanics/steady-flight-performance#ex-jet-md]]：巡航开始时$V = 230.15\ \mathrm{m/s}$，$C_L = 0.5809$，$L/D = 17.02$；巡航爬升保持这些值。$c_T = 0.55/3600 = 1.528\times10^{-4}\ \mathrm{s^{-1}}$，$\ln(70/58) = 0.18805$：
$$
R = \frac{230.15}{1.528\times10^{-4}} \times 17.02 \times 0.18805 = 4.821\times10^{6}\ \mathrm{m} = 4821\ \mathrm{km},
$$
$$
E = \frac{R}{V} = \frac{4.821\times10^{6}}{230.15} = 20\,950\ \mathrm{s} = 5.82\ \mathrm{h}.
$$
巡航结束时密度必须为$0.3639 \times 58/70 = 0.3015\ \mathrm{kg/m^3}$，在等温层中对应$12.19\ \mathrm{km}$：飞机上升了约$1200\ \mathrm{m}$。合理性检查：用$12\ \mathrm{t}$燃油飞约$4800\ \mathrm{km}$与上面警示中的数字相符；每小时耗油量$12\,000/5.82 = 2060\ \mathrm{kg/h}$等于整个飞行中$c_TD/g$的平均值（开始时$c_T D/g = 1.528\times10^{-4} \times 40\,340/9.807 \times 3600 = 2263\ \mathrm{kg/h}$，随重量成比例下降到$1875\ \mathrm{kg/h}$）。
:::
:::

### 其他巡航方案

空中交通管制很少允许连续的巡航爬升；客机在固定的飞行高度层巡航，并随着重量减轻以$600\ \mathrm{m}$（$2000\ \mathrm{ft}$）为一级阶梯爬升。两种等高度方案可以积分出封闭形式。

**等高度、等$C_L$。** 此时$L/D$不变，但速度必须按$V = \sqrt{2W/(\rho SC_L)}$减小。代入[[#eq-dx]]并积分$W^{-1/2}\,\mathrm{d}W$：
$$
R = \frac{2}{c_T}\sqrt{\frac{2}{\rho S}}\,\frac{\sqrt{C_L}}{C_D}\left(\sqrt{W_0} - \sqrt{W_1}\right).
$$ {#eq-range-const-h}
**等高度、等速度。** 此时$C_L$随重量减小，$L/D$随之改变，积分得到一个反正切公式（[[#exr-const-speed]]推导了它）。两种等高度方案的航程都略小于巡航爬升，因为随着重量减小，它们使飞机偏离其最佳$C_L$或最佳速度。

::: example 比较巡航方案 {#ex-programmes}
对$11\ \mathrm{km}$处的两种等高度方案，从相同的初始状态出发，重做[[#ex-jet-range]]。
::: solution
**等高度、等$C_L$：** 取$\rho = 0.3639$，$S = 122.6$，$C_L = 0.5809$，$C_D = 0.03413$，$\sqrt{W_0} = \sqrt{686\,466} = 828.53$，$\sqrt{W_1} = \sqrt{568\,786} = 754.18\ \mathrm{N^{1/2}}$：
$$
R = \frac{2}{1.528\times10^{-4}}\sqrt{\frac{2}{0.3639 \times 122.6}}\;\frac{\sqrt{0.5809}}{0.03413}\;(828.53 - 754.18) = 4.602\times10^{6}\ \mathrm{m}.
$$
速度从$230$降到$\sqrt{58/70} \times 230.15 = 209.5\ \mathrm{m/s}$。

**等高度、等速度：** 此时$q = 9639\ \mathrm{Pa}$固定，$D = qSC_{D0} + KW^2/(qS)$随重量减小。积分$\mathrm{d}x = -V\,\mathrm{d}W/(c_TD)$（用封闭形式，[[#exr-const-speed]]，或用数值方法）得$R = 4718\ \mathrm{km}$。升力系数从$0.581$降到$0.481$，**远离**$C_L^\ast = 0.691$，因此巡航中$L/D$从$17.02$降到$16.20$。

| 方案 | 航程 / km |
|---|---|
| 巡航爬升（布雷盖） | 4821 |
| 等高度、等速度 | 4718 |
| 等高度、等$C_L$ | 4602 |

合理性检查：三者相差在$5\,\%$以内，巡航爬升最好，而等$C_L$方案在这里最差，因为它牺牲了速度。阶梯爬升可以挽回大部分差距。
:::
:::

## 航程和航时的最佳速度 {#sec-best-speeds}

[[#eq-breguet-jet]]似乎提示应以$(L/D)_{\max}$飞行，但对于喷气式飞机，航程中包含的是$V(L/D)$，以稍低的$L/D$飞得更快反而更好。

::: proposition 航程和航时的最佳升力系数 {#prop-best-cl}
对于给定重量和高度下的抛物线型极曲线$C_D = C_{D0} + KC_L^2$：

| 飞机 | 最长航时 | 最远航程 |
|---|---|---|
| 喷气式（$c_T$不变） | $C_L/C_D$最大：$C_L = \sqrt{C_{D0}/K}$，在$V_{md}$ | $\sqrt{C_L}/C_D$最大：$C_L = \sqrt{C_{D0}/(3K)}$，在$3^{1/4}V_{md} = 1.316\,V_{md}$ |
| 螺旋桨式（$c_P$、$\eta_p$不变） | $C_L^{3/2}/C_D$最大：$C_L = \sqrt{3C_{D0}/K}$，在$V_{mp} = 0.760\,V_{md}$ | $C_L/C_D$最大：$C_L = \sqrt{C_{D0}/K}$，在$V_{md}$ |

在喷气式飞机的最远航程状态下，$C_D = \tfrac43C_{D0}$，$L/D = \tfrac{\sqrt3}{2}(L/D)_{\max} = 0.866\,(L/D)_{\max}$。
:::

::: proof
**喷气式航时：** 燃油流量为$c_TD$，在最小阻力时最小。**喷气式航程：** 比航程为$V/(c_TD)$；由$V = \sqrt{2W/(\rho SC_L)}$和$D = WC_D/C_L$，$V/D \propto C_L^{-1/2}C_L/C_D = \sqrt{C_L}/C_D$。使$\tfrac12\ln C_L - \ln(C_{D0} + KC_L^2)$最大：$\dfrac{1}{2C_L} = \dfrac{2KC_L}{C_{D0} + KC_L^2}$，故$C_{D0} = 3KC_L^2$，$C_L = \sqrt{C_{D0}/(3K)}$，$C_D = C_{D0} + C_{D0}/3$。于是$L/D = \sqrt{C_{D0}/(3K)}/(\tfrac43C_{D0}) = \tfrac{\sqrt3}{4}\cdot\tfrac{1}{\sqrt{KC_{D0}}} = \tfrac{\sqrt3}{2}(L/D)_{\max}$，速度比为$(C_L^\ast/C_L)^{1/2} = 3^{1/4}$。

**螺旋桨式：** 燃油流量为$c_PP_{\text{shaft}} = c_PDV/\eta_p$。航时要求功率$DV$最小，即[[flight-mechanics/steady-flight-performance#prop-min-power]]：$C_L = \sqrt{3C_{D0}/K}$。航程要求单位距离耗油$c_PD/\eta_p$最小，即阻力最小：$(L/D)_{\max}$。
:::

两类发动机之间的角色发生了“错位”，因为螺旋桨飞机的燃油流量跟随功率，而喷气式飞机的燃油流量跟随推力。对于轻型飞机，巡航中段质量（$1040\ \mathrm{kg}$）下的最远航程速度在海平面为$V_{md} = 37.0\ \mathrm{m/s}$——慢到没有人会这样飞；实际的轻型飞机以$55$–$65\ \mathrm{m/s}$巡航，接受约$11$而不是$12.5$的$L/D$，以换取短得多的飞行时间。对于$11\ \mathrm{km}$处的喷气运输机，$1.316\,V_{md} = 277.7\ \mathrm{m/s}$，马赫数$0.94$：已超过阻力剧增点，抛物线型极曲线在那里不成立，运输机实际的最远航程马赫数（约$0.76$–$0.80$）由波阻的出现决定。反过来说：在马赫数$0.78$时，抛物线型极曲线会把最远航程升力系数$0.399$置于低得多的高度上（[[#exr-altitude]]），而在那里发动机效率较低。

::: widget plot

## 螺旋桨飞机 {#sec-prop}

::: proposition 螺旋桨飞机的布雷盖航程与航时 {#prop-breguet-prop}
在$\eta_p$、$c_P$和$L/D$不变时，航程为
$$
R = \frac{\eta_p}{c_P}\,\frac{L}{D}\,\ln\frac{W_0}{W_1},
$$ {#eq-breguet-prop}
与以选定$C_L$飞行时的速度和高度无关。在等高度、等$C_L$条件下，航时为
$$
E = \frac{\eta_p}{c_P}\,\frac{C_L^{3/2}}{C_D}\,\sqrt{2\rho S}\,\left(W_1^{-1/2} - W_0^{-1/2}\right),
$$ {#eq-endurance-prop}
它在海平面和最小功率状态时最大。
:::

::: proof
重量按$\mathrm{d}W/\mathrm{d}t = -c_PP_{\text{shaft}} = -c_PDV/\eta_p$减小，故$\mathrm{d}x = V\,\mathrm{d}t = -\eta_p\,\mathrm{d}W/(c_PD) = -(\eta_p/c_P)(L/D)\,\mathrm{d}W/W$，积分即得[[#eq-breguet-prop]]。速度被消去了：螺旋桨飞机的航程取决于$L/D$，而不是$V(L/D)$。对于航时，$\mathrm{d}t = -\eta_p\,\mathrm{d}W/(c_PDV)$，其中$DV = W(C_D/C_L)\sqrt{2W/(\rho SC_L)}$：
$$
\mathrm{d}t = -\frac{\eta_p}{c_P}\,\frac{C_L^{3/2}}{C_D}\,\sqrt{\frac{\rho S}{2}}\,W^{-3/2}\,\mathrm{d}W,
$$
而$\int_{W_1}^{W_0}W^{-3/2}\,\mathrm{d}W = 2(W_1^{-1/2} - W_0^{-1/2})$，由此得[[#eq-endurance-prop]]。假设：与喷气式飞机相同，另加螺旋桨效率不变——在最长航时对应的低速下，这一假设偏于乐观。
:::

::: example 轻型飞机的航程和航时 {#ex-la-range}
轻型飞机在起飞质量$1100\ \mathrm{kg}$时携带$120\ \mathrm{kg}$可用燃油。取 BSFC $= 0.25\ \mathrm{kg/(kW\,h)}$，$\eta_p = 0.75$，求其静止空气中的最远航程，以及在海平面和$2000\ \mathrm{m}$高度的最长航时。
::: solution
$c_P = 6.810\times10^{-7}\ \mathrm{m^{-1}}$，$(L/D)_{\max} = 12.53$，$\ln(1100/980) = 0.11551$：
$$
R_{\max} = \frac{0.75}{6.810\times10^{-7}} \times 12.53 \times 0.11551 = 1.594\times10^{6}\ \mathrm{m} = 1594\ \mathrm{km}.
$$
对于航时，在$C_L = \sqrt{3 \times 0.030/0.05305} = 1.3025$时$(C_L^{3/2}/C_D)_{\max}$为$1.3025^{1.5}/0.120 = 12.39$。取$W_1 = 980g = 9610\ \mathrm{N}$，$W_0 = 10\,787\ \mathrm{N}$，$W_1^{-1/2} - W_0^{-1/2} = 0.010201 - 0.009628 = 5.725\times10^{-4}\ \mathrm{N^{-1/2}}$。在海平面，$\sqrt{2 \times 1.225 \times 16.2} = 6.300$：
$$
E = \frac{0.75}{6.810\times10^{-7}} \times 12.39 \times 6.300 \times 5.725\times10^{-4} = 4.92\times10^{4}\ \mathrm{s} = 13.7\ \mathrm{h},
$$
在$2000\ \mathrm{m}$处则小$\sqrt{0.8216}$倍：$12.4\ \mathrm{h}$。合理性检查：在最小功率状态（推力功率$28.7\ \mathrm{kW}$，轴功率$38.3\ \mathrm{kW}$），燃油流量为$0.25 \times 38.3 = 9.6\ \mathrm{kg/h}$，按初始重量计$120/9.6 = 12.5\ \mathrm{h}$——两者一致。实际的轻型飞机远达不到这一水平（约$5$–$6\ \mathrm{h}$和$1000$–$1200\ \mathrm{km}$），因为它们以$60\,\%$–$75\,\%$功率巡航，要保留备用燃油，而且其发动机和螺旋桨在理想状态所要求的极低功率和速度下效率较低。
:::
:::

## 风、备份油与任务 {#sec-wind}

有风时，重要的是单位燃油对应的相对地面距离。逆风分量为$V_w$时，地速为$V - V_w$，单位燃油地面航程为$(V - V_w)/\dot W_f$。最佳速度不再是静止空气中的值：逆风时它增大（与风对抗的时间更短），顺风时它减小。一条常用的经验法则是在静止空气最远航程速度上加上逆风分量的四分之一到二分之一。

::: example 逆风中的最远航程速度 {#ex-wind}
质量为$1040\ \mathrm{kg}$的轻型飞机在海平面迎着$10\ \mathrm{m/s}$的逆风飞行。求使每千克燃油的地面距离最大的速度，并与按静止空气最远航程速度飞行相比较。
::: solution
燃油质量流量为$\dot m_f = c_P\,DV/(\eta_p g)$，$D(V)$由极曲线给出，$W = 10\,199\ \mathrm{N}$。用数值方法使单位燃油地面航程$(V - 10)/\dot m_f$最大，峰值出现在$V = 40.2\ \mathrm{m/s}$，为$9.83\ \mathrm{km/kg}$。在静止空气最优速度$V_{md} = 37.0\ \mathrm{m/s}$时为$9.68\ \mathrm{km/kg}$，而在静止空气中以$37.0\ \mathrm{m/s}$飞行时为$13.27\ \mathrm{km/kg}$。顺风$10\ \mathrm{m/s}$时，最优速度降到$35.0\ \mathrm{m/s}$（$16.96\ \mathrm{km/kg}$）。合理性检查：$10\ \mathrm{m/s}$逆风对应的速度修正为$+3.2\ \mathrm{m/s}$，符合经验法则；修正速度带来的收益（$1.5\,\%$）与风本身造成的损失（$26\,\%$）相比很小。
:::
:::

实际任务还要加上滑行、起飞、爬升、下降和着陆的燃油，而且法规要求备份油——例如对于航线飞行，有应急燃油、飞往备降机场的燃油，以及用于一段等待时间的最后备份油（按欧盟规则，涡轮发动机飞机为30分钟等待）。在概念设计中（Raymer，Anderson），每一航段给定一个重量比$W_{i+1}/W_i$，巡航和待机的重量比由布雷盖方程得到，其余由统计数据得到，各重量比的乘积给出总燃油系数。把[[#eq-breguet-jet]]反过来，即得到所需航程的巡航重量比：
$$
\frac{W_1}{W_0} = \exp\left(-\frac{R\,c_T}{V\,(L/D)}\right).
$$ {#eq-fuel-fraction}

::: example 巡航 5000 km 所需燃油 {#ex-fuel}
在[[#ex-jet-range]]的条件下，从$70\,000\ \mathrm{kg}$开始，喷气运输机巡航爬升$5000\ \mathrm{km}$需要多少燃油？
::: solution
$Rc_T/(V\,L/D) = 5.0\times10^{6} \times 1.528\times10^{-4}/(230.15 \times 17.02) = 0.19501$，故$W_1/W_0 = e^{-0.19501} = 0.8228$，巡航燃油为$70\,000 \times (1 - 0.8228) = 12\,400\ \mathrm{kg}$。合理性检查：$4821\ \mathrm{km}$需要$12\,000\ \mathrm{kg}$，平均$2.49\ \mathrm{kg/km}$。多出的$179\ \mathrm{km}$只多耗$403\ \mathrm{kg}$，即$2.25\ \mathrm{kg/km}$，因为两次飞行都从$70\ \mathrm{t}$开始，多出的距离是在最后飞的，那时飞机重约$57.6\ \mathrm{t}$，耗油$c_TW/(g\,V\,L/D) = 1.528\times10^{-4} \times 57\,600/(230.15 \times 17.02) = 2.25\ \mathrm{kg/km}$。
:::
:::

### 商载–航程图 {#sec-payload-range}

航空公司问的不是“飞机能飞多远？”，而是“**带着这些商载**能飞多远？”。三个重量限制回答了这个问题：**最大起飞重量**（MTOW，由结构和性能决定）、**最大零燃油重量**（MZFW，由机翼弯曲决定——机翼中的燃油能减小翼根弯矩，机身中的商载则不能）以及油箱的**燃油容量**。在**使用空重**（OEW：结构、发动机、系统、机组、餐饮）固定的情况下，起飞重量为 OEW + 商载 + 燃油，**商载–航程图**画出商载与带着该商载可达航程之间的关系。

::: algorithm 绘制商载–航程图 {#alg-payload-range}
1. **最大商载** $= \text{MZFW} - \text{OEW}$。加油直到起飞重量达到 MTOW：燃油 $= \text{MTOW} - \text{MZFW}$。用[[#eq-breguet-jet]]从$W_0 = \text{MTOW}$到$W_1 = \text{MTOW} - \text{巡航燃油}$计算航程。这就是 A 点；A 点以左商载线是水平的。
2. **MTOW 下油箱加满。** 在 MTOW 不变的条件下以商载换燃油，直到油箱加满：商载 $= \text{MTOW} - \text{OEW} - \text{燃油容量}$。这是 B 点；在 A 与 B 之间，航程只通过对数增长。
3. **转场航程。** 油箱加满时卸去剩余商载：起飞重量降到 MTOW 以下，$W_1$随之减小，航程再次增大。这是 C 点，商载为零。
4. 在每种情况下，都要先从燃油中扣除备份油以及起飞、爬升和下降的燃油余量，再对巡航段应用布雷盖方程。
:::

对于 MTOW 为$78\ \mathrm{t}$、MZFW 为$60\ \mathrm{t}$、OEW 为$42\ \mathrm{t}$、燃油容量为$21\ \mathrm{t}$、备份油与余量合计$3\ \mathrm{t}$、巡航条件同[[#ex-jet-range]]（$V(L/D)/c_T = 25\,640\ \mathrm{km}$，假设不变）的喷气运输机：

| 点 | 商载 / t | 燃油 / t | $W_0$ / t | $W_1$ / t | 航程 / km |
|---|---|---|---|---|---|
| A（最大商载） | 18 | 18 | 78 | 63 | $25\,640\ln(78/63) = 5476$ |
| B（MTOW 下油箱加满） | 15 | 21 | 78 | 60 | $25\,640\ln(78/60) = 6727$ |
| C（转场） | 0 | 21 | 63 | 45 | $25\,640\ln(63/45) = 8626$ |

该图说明了为什么省油的发动机或更轻的结构价值如此之大：OEW 每减少一吨，在直到 A 点的每一航程上都多一吨商载；而在 A 点以外，它按 AB 段的斜率换取航程：每放弃一吨商载换得$(6727 - 5476)/3 = 417\ \mathrm{km}$，约为 A 点航程的$8\,\%$。

::: quiz
一架涡轮螺旋桨飞机和一架涡轮风扇飞机的$(L/D)_{\max}$都等于$16$。对于在固定高度上的静止空气巡航，哪个说法正确？
- [ ] 两者都应以$(L/D)_{\max}$飞行以获得最远航程。
- [x] 涡轮螺旋桨飞机应以$(L/D)_{\max}$飞行；涡轮风扇飞机应以更高的速度飞行，此时$L/D \approx 13.9$。
- [ ] 涡轮风扇飞机应以$(L/D)_{\max}$飞行；涡轮螺旋桨飞机应以最小功率速度飞行。
- [ ] 两者都应以最小功率速度飞行。
::: solution
对于螺旋桨飞机，燃油流量跟随功率，航程为$(\eta_p/c_P)(L/D)\ln(W_0/W_1)$，因此$(L/D)_{\max}$最好。对于喷气式飞机，航程中包含$V(L/D)$；最优点是$\sqrt{C_L}/C_D$最大，在$3^{1/4}V_{md}$处，此时$L/D = 0.866 \times 16 = 13.9$。
:::
:::

::: history
航程方程冠以法国飞机制造商路易·布雷盖（Louis Breguet）之名，但通常引用的最早发表的推导是科芬（J. G. Coffin）的《飞机航程与有效载荷研究》（“A study of airplane ranges and useful loads”），即 NACA 第 69 号报告，随 NACA 的第五次年度报告（1919年度）发布；布雷盖的名字如何与它联系在一起，并没有清楚的文献记载。该方程把航程分解为气动（$L/D$）、推进（$\eta_p/c_P$或$V/c_T$）和结构（$\ln W_0/W_1$）三个因素，从此一直指导着设计，从1920和1930年代的远距离纪录飞行，到每一种现代客机的尺寸确定；在后者中，每个因素的改进——超临界机翼与翼梢小翼、大涵道比涡轮风扇发动机、复合材料结构——都可以直接读作航程或燃油消耗的百分比收益。
:::

::: summary
- 喷气式燃油流量$= c_TT$（重量基准，$c_T$单位为$\mathrm{s^{-1}}$）；螺旋桨式燃油流量$= c_PP_{\text{shaft}}$（$c_P$单位为$\mathrm{m^{-1}}$），$TV = \eta_pP_{\text{shaft}}$。
- 喷气式：$R = (V/c_T)(L/D)\ln(W_0/W_1)$，$E = (1/c_T)(L/D)\ln(W_0/W_1)$（$V$、$C_L$不变的巡航爬升）。
- 螺旋桨式：$R = (\eta_p/c_P)(L/D)\ln(W_0/W_1)$；航时$\propto (C_L^{3/2}/C_D)\sqrt\rho$，在低空最好。
- 最佳$C_L$：喷气式航程为$\sqrt{C_{D0}/3K}$（速度$1.316V_{md}$，$L/D = 0.866(L/D)_{\max}$）；喷气式航时和螺旋桨式航程为$\sqrt{C_{D0}/K}$；螺旋桨式航时为$\sqrt{3C_{D0}/K}$。
- 等高度方案的航程比巡航爬升少百分之几；阶梯爬升可挽回大部分。
- 逆风时应以高于静止空气最远航程速度的速度飞行；运输机的巡航速度实际上由阻力剧增决定。
:::

## 习题

::: exercise 耗油率的换算 {level=1 check="16.4"}
某发动机数据单给出$c_T = 0.58\ \mathrm{lb/(lbf\,h)}$。把它表示为单位推力的质量流量，单位为$\mathrm{mg\,N^{-1}\,s^{-1}}$。（保留一位小数。）
::: solution
每磅力推力每小时消耗的燃油磅数是每单位重量每小时的重量：$c_T = 0.58\ \mathrm{h^{-1}} = 1.611\times10^{-4}\ \mathrm{s^{-1}}$。换为质量基准需除以$g$：$1.611\times10^{-4}/9.80665 = 1.643\times10^{-5}\ \mathrm{kg\,N^{-1}\,s^{-1}} = 16.4\ \mathrm{mg\,N^{-1}\,s^{-1}}$。
:::
:::

::: exercise 喷气式飞机的航程 {level=1 check="6941"}
一架远程喷气式飞机以$V = 240\ \mathrm{m/s}$、$L/D = 18$、$c_T = 0.50\ \mathrm{h^{-1}}$巡航，消耗其初始重量的$20\,\%$。求巡航爬升航程。（单位 km，取整数。）
::: solution
$c_T = 1.389\times10^{-4}\ \mathrm{s^{-1}}$，$\ln(1/0.8) = 0.22314$：$R = (240/1.389\times10^{-4}) \times 18 \times 0.22314 = 6.941\times10^{6}\ \mathrm{m} = 6941\ \mathrm{km}$。
:::
:::

::: exercise 螺旋桨飞机的航程 {level=1 check="3113"}
一架涡轮螺旋桨飞机的$\eta_p = 0.80$，BSFC $= 0.23\ \mathrm{kg/(kW\,h)}$，以$L/D = 15$巡航，消耗其初始重量的$15\,\%$。求航程。（单位 km，取整数。）
::: solution
$c_P = 0.23 \times 9.80665/3.6\times10^{6} = 6.265\times10^{-7}\ \mathrm{m^{-1}}$；$\ln(1/0.85) = 0.16252$；$R = (0.80/6.265\times10^{-7}) \times 15 \times 0.16252 = 3.113\times10^{6}\ \mathrm{m} = 3113\ \mathrm{km}$。
:::
:::

::: exercise 任务的燃油系数 {level=2 check="0.111"}
一架喷气式飞机在$V = 230\ \mathrm{m/s}$时$L/D = 17$，$c_T = 0.55\ \mathrm{h^{-1}}$，须巡航$3000\ \mathrm{km}$。巡航中消耗的燃油占巡航开始时重量的多少？（保留三位小数。）
::: solution
$Rc_T/(V\,L/D) = 3.0\times10^{6} \times 1.528\times10^{-4}/(230 \times 17) = 0.11720$；$W_1/W_0 = e^{-0.11720} = 0.8894$，故消耗初始重量的$1 - 0.8894 = 0.111$。
:::
:::

::: exercise 等待航时 {level=2 check="1.85"}
喷气运输机以$70\,000\ \mathrm{kg}$到达，须等待到燃油消耗使其降至$66\,000\ \mathrm{kg}$，以$(L/D)_{\max} = 17.28$、$c_T = 0.55\ \mathrm{h^{-1}}$飞行。它能等待多久？（单位为小时，保留两位小数。）
::: solution
$E = (1/c_T)(L/D)\ln(W_0/W_1) = (17.28/0.55\ \mathrm{h^{-1}}) \times \ln(70/66) = 31.42 \times 0.05884 = 1.85\ \mathrm{h}$。在本模型中，以$V_{md}$等待与高度无关；实际上喷气式飞机在高空等待，那里$c_T$较低。
:::
:::

::: exercise 喷气式飞机最远航程时的升阻比 {level=2 check="0.866"}
求喷气式飞机最远航程状态下的升阻比与$(L/D)_{\max}$之比。（保留三位小数。）
::: solution
在$C_L = \sqrt{C_{D0}/(3K)}$时，$KC_L^2 = C_{D0}/3$，$C_D = \tfrac43C_{D0}$；$L/D = \sqrt{C_{D0}/(3K)}/(\tfrac43C_{D0}) = \tfrac{3}{4\sqrt3}/\sqrt{KC_{D0}}$。除以$(L/D)_{\max} = 1/(2\sqrt{KC_{D0}})$得$\tfrac{3}{2\sqrt3} = \tfrac{\sqrt3}{2} = 0.866$。
:::
:::

::: exercise 巡航爬升的高度变化 {level=2}
证明在等温平流层中巡航爬升时，重量从$W_0$降到$W_1$所上升的高度为$\Delta h = (RT_{11}/g_0)\ln(W_0/W_1)$，并对[[#ex-jet-range]]求其数值。
::: solution
巡航爬升保持$\rho \propto W$。在等温层中$\rho = \rho_{11}\exp[-g_0(h - h_{11})/(RT_{11})]$（[[flight-mechanics/steady-flight-performance#eq-stratosphere]]），故$\rho_0'/\rho_1' = \exp[g_0\Delta h/(RT_{11})] = W_0/W_1$，$\Delta h = (RT_{11}/g_0)\ln(W_0/W_1)$。由$RT_{11}/g_0 = 287.05 \times 216.65/9.80665 = 6342\ \mathrm{m}$（标高）和$\ln(70/58) = 0.18805$：$\Delta h = 1193\ \mathrm{m}$，与例题中求得的$12.19\ \mathrm{km}$一致。
:::
:::

::: exercise 等速巡航 {#exr-const-speed level=3}
对于等高度、等真空速（因而$q$不变）的喷气式飞机，用抛物线型极曲线积分$\mathrm{d}x = -V\,\mathrm{d}W/(c_TD(W))$，推导航程的封闭形式，并对喷气运输机在$11\ \mathrm{km}$、马赫数$0.78$下从$70\,000$到$58\,000\ \mathrm{kg}$求其数值，以验证[[#ex-programmes]]中的$4718\ \mathrm{km}$。
::: solution
由$D = qSC_{D0} + KW^2/(qS)$且$q$不变，$\mathrm{d}x = -\dfrac{V}{c_T}\dfrac{\mathrm{d}W}{qSC_{D0} + KW^2/(qS)}$。令$u = W\sqrt{K/C_{D0}}/(qS)$，则$\mathrm{d}W = qS\sqrt{C_{D0}/K}\,\mathrm{d}u$，分母为$qSC_{D0}(1 + u^2)$：
$$
R = \frac{V}{c_T\sqrt{KC_{D0}}}\left[\tan^{-1}u_0 - \tan^{-1}u_1\right],\qquad u = \frac{W}{qS}\sqrt{\frac{K}{C_{D0}}} = \frac{C_L}{C_L^\ast}.
$$
数值：$qS = 9639 \times 122.6 = 1.1817\times10^{6}\ \mathrm{N}$；$u_0 = 0.5809/0.6910 = 0.8407$，$u_1 = 0.4813/0.6910 = 0.6965$；$\tan^{-1}0.8407 - \tan^{-1}0.6965 = 0.69904 - 0.60840 = 0.09064$；$V/(c_T\sqrt{KC_{D0}}) = 230.15/(1.528\times10^{-4} \times 0.028942) = 5.205\times10^{7}\ \mathrm{m}$；$R = 4718\ \mathrm{km}$。数值积分（例如在 100 个重量步长上用梯形公式）给出相同的值。
:::
:::

::: exercise 选择巡航高度 {#exr-altitude level=3 check="8530"}
喷气运输机在$70\,000\ \mathrm{kg}$、马赫数$0.78$时，要在多高的 ISA 高度上才能以其抛物线型极曲线的最远航程升力系数$C_L = 0.399$飞行？讨论它是否应当在那里巡航。（输入高度，单位 m，精确到 10 m。）
::: solution
要求$W = \tfrac12\rho(0.78a)^2SC_L$，即$\rho a^2 = 2W/(0.78^2SC_L)$。由于$\rho a^2 = \gamma p$，这只是关于压力的条件：$p = 2 \times 686\,466/(1.4 \times 0.6084 \times 122.6 \times 0.39897) = 32\,950\ \mathrm{Pa}$，在$h = 8530\ \mathrm{m}$处达到。讨论：在固定马赫数下，降低高度会提高$q$并使$C_L$减小而趋向航程最优值，但也会提高声速（真空速$+3.6\,\%$）；更重要的是，涡轮风扇发动机的$c_T$在更暖、更稠密的空气中以及在较低推力状态下会增大，而燃油代价通常超过这一小小的气动收益。航空公司在$10$–$12\ \mathrm{km}$巡航，那里的$C_L$接近对计入压缩性的实际极曲线使$M(L/D)$最大的值，该值高于抛物线型极曲线的$0.399$。完整的回答应利用发动机数据，在若干高度上计算比航程。
:::
:::
