定常直线飞行只是飞机飞行的一部分。要改变方向，飞机必须压坡度转弯；要从俯冲中改出，它必须产生大于其重量的升力；而每一次飞行都以沿跑道的加速滑跑开始，以减速滑跑结束。本讲沿用[[flight-mechanics/steady-flight-performance]]中飞机的质点模型来讨论这些**加速**机动：作用力仍是升力、阻力、推力和重力，但加速度不再为零。核心物理量是**过载**（load factor）——机翼承受的载荷是飞机自身重量的多少倍——它通过 V–n 图把飞机的性能与结构强度联系起来，飞行员感受到的“g”就是它。

圆周运动的运动学来自[[dynamics/particle-kinematics]]，法向和切向分量形式的牛顿第二定律来自[[dynamics/newtons-laws]]。

## 过载 {#sec-load-factor}

::: definition 过载 {#def-load-factor}
**过载**（载荷因数）是升力与重力之比，
$$
n = \frac{L}{W}.
$$
在定常水平飞行中$n = 1$。固定在飞机上、沿升力方向安装的加速度计以$g$为单位读出$n$；乘员感到自己的视重增大为$n$倍，结构的每一部分都承受其平飞惯性载荷的$n$倍。
:::

由于$L = nW = \tfrac12\rho V^2SC_L$，在速度$V$下要达到过载$n$，所需升力系数是同一速度下平飞升力系数的$n$倍。因此，可用的最大升力系数$C_{L,\max}$限制了低速时的过载：
$$
n_{\max,\text{aero}} = \frac{\tfrac12\rho V^2SC_{L,\max}}{W} = \left(\frac{V}{V_s}\right)^2,
$$ {#eq-n-stall}
其中$V_s$是 1 g 失速速度。等价地说，过载为$n$时的失速速度为$V_s\sqrt n$：一架平飞时以$27\ \mathrm{m/s}$失速的飞机，在$2\,g$转弯中以$38\ \mathrm{m/s}$失速。大多数失速–尾旋事故发生在低高度转弯中：飞行员向后拉杆以收紧转弯，却没有注意到失速速度已经升高。

## 水平转弯 {#sec-turn}

**受力图。** 在速度$V$不变、坡度为$\phi$的协调（无侧滑）水平转弯中，从飞机后方看：

- 重力$W$，竖直向下通过重心；
- 升力$L$，在对称面内垂直于机翼，从竖直方向向转弯中心倾斜$\phi$；
- 推力与阻力，沿航迹（垂直于纸面），大小相等、方向相反。

飞机在半径为$R$的水平圆周上运动，因此其加速度为$V^2/R$，指向圆心。

::: proposition 水平协调转弯 {#prop-turn}
在坡度为$\phi$、真空速为$V$的定常水平协调转弯中，
$$
n = \frac{1}{\cos\phi},\qquad
R = \frac{V^2}{g\tan\phi} = \frac{V^2}{g\sqrt{n^2 - 1}},\qquad
\omega = \frac{V}{R} = \frac{g\sqrt{n^2 - 1}}{V},
$$ {#eq-turn}
其中$\omega$为转弯角速度。
:::

::: proof
牛顿第二定律的竖直分量（无竖直加速度）：$L\cos\phi - W = 0$，故$n = L/W = 1/\cos\phi$。指向圆心的水平分量：$L\sin\phi = (W/g)\,V^2/R$。第二式除以第一式，得$\tan\phi = V^2/(gR)$，由此得$R$；而$\tan\phi = \sqrt{\sec^2\phi - 1} = \sqrt{n^2 - 1}$。以速度$V$在半径为$R$的圆周上运动的物体，其转弯角速度为$V/R$。假设：水平飞行，速度不变（推力平衡增大了的阻力），无侧滑，平坦且不旋转的地球。
:::

在坡度一定时，半径随$V^2$增大，角速度随$1/V$减小：快速飞机转的是又大又慢的圈子。仪表飞行程序采用**一级**（标准速率）转弯，即$3^\circ/\mathrm{s}$，两分钟转一整圈；[[#eq-turn]]表明，所需坡度$\tan^{-1}(\omega V/g)$随速度增大——$60\ \mathrm{m/s}$时为$17.8^\circ$——这就是客机以固定坡度（通常为$25^\circ$）而不是以标准速率转弯的原因。

转弯要付出功率。升致阻力为$KC_L^2qS = Kn^2W^2/(qS)$，是同一速度下平飞值的$n^2$倍：
$$
D = qSC_{D0} + \frac{Kn^2W^2}{qS}.
$$ {#eq-turn-drag}

::: example 60° 坡度转弯 {#ex-turn}
[[flight-mechanics/steady-flight-performance]]中的轻型飞机（$m = 1100\ \mathrm{kg}$，海平面$V_s = 26.92\ \mathrm{m/s}$）以$\phi = 60^\circ$、$V = 50\ \mathrm{m/s}$做水平转弯。求过载、转弯半径、转弯角速度、转一整圈的时间、转弯中的失速速度以及需用功率。
::: solution
$n = 1/\cos 60^\circ = 2.00$。$R = 50^2/(9.80665 \tan 60^\circ) = 2500/16.986 = 147.2\ \mathrm{m}$。$\omega = 50/147.2 = 0.3397\ \mathrm{rad/s} = 19.5^\circ/\mathrm{s}$，故转一整圈需$2\pi/0.3397 = 18.5\ \mathrm{s}$。转弯中的失速速度：$26.92\sqrt2 = 38.07\ \mathrm{m/s}$，因此飞机只比它高$31\,\%$。阻力：$q = 1531\ \mathrm{Pa}$；零升部分与平飞时相同，为$744.2\ \mathrm{N}$，升致部分为$4 \times 248.8 = 995.4\ \mathrm{N}$，总阻力$D = 1740\ \mathrm{N}$，而平飞时为$993\ \mathrm{N}$，故$P_R = 1740 \times 50 = 87.0\ \mathrm{kW}$。合理性检查：这超过了可用的$75\ \mathrm{kW}$，所以这一转弯无法持续：飞机将损失速度或高度。这些数字是典型的：轻型飞机的大坡度转弯半径约为$150\ \mathrm{m}$，一圈约需$20\ \mathrm{s}$。
:::
:::

### 转弯的限制

有三个因素限制飞机转弯的剧烈程度：

1. **气动限制**——升力系数不能超过$C_{L,\max}$，所以$n \le (V/V_s)^2$（[[#eq-n-stall]]）。
2. **结构限制**——过载不得超过飞机设计所依据的限制过载$n_{\text{lim}}$（见下一节）。
3. **推力（或功率）限制**——在**稳定**转弯中，推力必须等于阻力[[#eq-turn-drag]]。解出$n$，
$$
n_{\text{sust}} = \sqrt{\frac{qS}{KW^2}\left(T - qSC_{D0}\right)} .
$$ {#eq-n-sustained}
比这更急的转弯只能通过消耗动能或势能而短暂实现：这就是**瞬时**转弯。

::: proposition 角点速度 {#prop-corner}
在由气动限制起作用的速度范围内，转弯半径随速度增大而减小，转弯角速度随速度增大而增大；在由结构限制起作用的范围内，半径增大，角速度减小。因此最快的瞬时转弯角速度在**角点速度**
$$
V^\ast = \sqrt{\frac{2n_{\text{lim}}W}{\rho SC_{L,\max}}} = V_s\sqrt{n_{\text{lim}}},
$$ {#eq-corner}
处实现，此时两个限制同时达到，半径为$R^\ast = V^{\ast2}/(g\sqrt{n_{\text{lim}}^2 - 1})$。在气动边界上，半径趋近但永远达不到$V_s^2/g = 2(W/S)/(\rho gC_{L,\max})$。
:::

::: proof
在气动边界上$n = (V/V_s)^2$。于是$\omega = g\sqrt{V^4/V_s^4 - 1}/V$，其平方$g^2(V^2/V_s^4 - 1/V^2)$随$V$增大；而$R = V^2/(g\sqrt{V^4/V_s^4 - 1}) = V_s^2/(g\sqrt{1 - V_s^4/V^4})$随$V$减小并趋于$V_s^2/g$。在结构边界上$n = n_{\text{lim}}$为常数，由[[#eq-turn]]得$R \propto V^2$，$\omega \propto 1/V$。因此角速度沿第一条边界上升，沿第二条边界下降，其最大值位于两者的交点$(V/V_s)^2 = n_{\text{lim}}$。
:::

::: example 特技飞机的角点速度 {#ex-corner}
一架质量为$800\ \mathrm{kg}$的特技飞机，$S = 11.0\ \mathrm{m^2}$，$C_{L,\max} = 1.4$，$n_{\text{lim}} = 6.0$。求其在海平面的失速速度、角点速度、角点处的转弯半径和角速度，以及极限半径。
::: solution
$W = 7845\ \mathrm{N}$，$W/S = 713.2\ \mathrm{N/m^2}$。$V_s = \sqrt{2 \times 713.2/(1.225 \times 1.4)} = 28.84\ \mathrm{m/s}$；$V^\ast = 28.84\sqrt6 = 70.64\ \mathrm{m/s}$。在角点处，$\sqrt{n^2 - 1} = \sqrt{35} = 5.916$：
$$
R^\ast = \frac{70.64^2}{9.80665 \times 5.916} = 86.0\ \mathrm{m},\qquad
\omega^\ast = \frac{9.80665 \times 5.916}{70.64} = 0.8213\ \mathrm{rad/s} = 47.1^\circ/\mathrm{s}.
$$
极限半径为$V_s^2/g = 84.8\ \mathrm{m}$，因此在角点处半径已在其最小可能值的$1.4\,\%$以内。合理性检查：在角点处转$360^\circ$需$7.6\ \mathrm{s}$——但这只是瞬时的：在$70\ \mathrm{m/s}$时保持$6\,g$需要平飞值$36$倍的升致阻力，远远超出轻型飞机的推力，飞机会在几秒钟内损失速度。
:::
:::

### 拉起与筋斗

在垂直面内的机动中，重力不再以简单的方式垂直于航迹作用。在半径为$R$的圆周上拉起的最低点，升力既要支持重量，又要提供向心力：$L - W = (W/g)V^2/R$，故
$$
n = 1 + \frac{V^2}{gR}\quad\text{(拉起的最低点)},\qquad n = \frac{V^2}{gR} - 1\quad\text{(筋斗的顶点，倒飞)} .
$$ {#eq-pullup}
以$60\ \mathrm{m/s}$在半径$200\ \mathrm{m}$的圆周上拉起，需要$n = 1 + 3600/1961 = 2.84$。

## V–n 图 {#sec-vn}

飞机结构按一组**限制载荷**设计——使用中预期的最大载荷，结构在其作用下不得产生永久变形——以及**极限载荷**，通常为限制载荷的$1.5$倍，结构在其作用下至少数秒内不得破坏。对于机翼，这些载荷以过载表示，并随速度绘出。

::: definition V–n 图 {#def-vn}
**机动包线**或**V–n 图**画出飞机可能经受的过载随当量空速的变化。它的边界为
- 正、负**失速曲线**$n = \pm(V_E/V_{s\pm})^2$，其中$V_{s-}$是倒飞时的失速速度；
- 正、负**限制过载**$n_{\text{lim}+}$和$n_{\text{lim}-}$；
- **设计俯冲速度**$V_D$，即结构设计所依据的最高速度。

正失速曲线与$n_{\text{lim}+}$相交于**设计机动速度**$V_A = V_s\sqrt{n_{\text{lim}+}}$（即[[#prop-corner]]的角点速度）。在$V_A$以下，操纵面满偏会使机翼在达到限制载荷之前失速；在其以上，猛烈的满杆拉起可能使结构过载。
:::

限制过载由各类别的适航规章规定。按传统的美国 14 CFR Part 23 和 EASA CS-23 轻型飞机规章，正限制机动过载的最小值为：正常类$3.8$（对大多数轻型飞机而言；规章公式$2.1 + 24\,000/(W + 10\,000)$中$W$以磅计，上限为$3.8$），实用类$4.4$，特技类$6.0$；负值为正值的$0.4$倍（特技类为$0.5$倍）。自2017年起，Part 23 改为基于性能的要求，并把此类数值放入共识标准（ASTM F3116）中。对于运输类飞机，14 CFR 25.337 和 CS 25.337 要求至少为$2.5$（按同一公式，但不小于$2.5$且不大于$3.8$）和$-1.0$。这里列出这些数值只是为了解释该图；本讲讲授的是规章背后的原理，不能代替规章本身。

**突风**也会给机翼加载。以当量空速$V_E$飞入速度为$U$的锐边竖直突风，迎角改变$U/V$，升力改变$\tfrac12\rho_0V_E^2S\,a\,U/V_E$。实际的突风并不是锐边的，而且飞机在完全进入突风之前就已开始上升；适航规章（Part 23 的 Pratt 公式）引入了减缓因子$K_g$：
$$
\Delta n = \frac{\rho_0\,K_g\,U_{de}\,V_E\,a}{2\,W/S},\qquad K_g = \frac{0.88\,\mu_g}{5.3 + \mu_g},\qquad \mu_g = \frac{2\,W/S}{\rho\,\bar c\,a\,g},
$$ {#eq-gust}
其中$a$是飞机的升力线斜率（每弧度），$\bar c$是平均弦长，$U_{de}$是规章规定的“导出”突风速度（在经典的 Part 23 规章中，设计巡航速度下、$6100\ \mathrm{m}$以下为$15.24\ \mathrm{m/s}$，即$50\ \mathrm{ft/s}$）。突风过载随速度线性增长，与翼载成反比——因此轻小、翼载低的飞机对湍流最为敏感。

::: warning 限制载荷、极限载荷与失速速度
三个常见错误。(i) 把限制过载当作破坏载荷：结构在限制载荷下不得**屈服**，在其$1.5$倍以下不得**破坏**；按在$n_{\text{lim}}$处破坏来设计就取消了安全因数。(ii) 认为在$V_A$以下任何机动都是安全的：$V_A$只防护单个操纵面的一次满偏，不能防护快速反向操纵或俯仰与滚转的复合输入，后者曾折断过客机的尾翼。(iii) 忘记$V_s$从而$V_A$取决于重量：$V_A \propto \sqrt W$，所以轻载的飞机机动速度**更低**。
:::

## 起飞 {#sec-takeoff}

起飞分为：**地面滑跑**，从松刹车到以速度$V_{LO}$离地；**抬前轮**，抬头的几秒钟；以及到安全高度（轻型飞机为$15\ \mathrm{m}$即$50\ \mathrm{ft}$，运输类飞机为$10.7\ \mathrm{m}$即$35\ \mathrm{ft}$）的**空中段距离**。离地速度比起飞构型下的失速速度高出一定裕度，通常$V_{LO} \approx 1.1$–$1.2\,V_s$；对于运输类飞机，规章规定起飞安全速度$V_2$不小于基准失速速度的$1.13$倍。

**地面滑跑时的受力图**（飞机以机轮着地，沿跑道加速）：

- 推力$T$，向前；
- 气动阻力$D = qSC_{D,g}$，向后，$C_{D,g}$是地面滑跑姿态下的阻力系数（襟翼和起落架放下，地面效应使诱导阻力减小）；
- 升力$L = qSC_{L,g}$，向上，对应于地面滑跑时较小的升力系数；
- 重力$W$，向下；
- 跑道法向约束力合计为$N = W - L$，向上；滚动摩擦力$\mu_r N$，向后，混凝土跑道上$\mu_r \approx 0.02$，草地上为$0.04$–$0.10$。

::: proposition 地面滑跑距离 {#prop-ground-roll}
设加速力为$F(V) = T - D - \mu_r(W - L)$，则从静止到$V_{LO}$的地面滑跑距离为
$$
s_g = \frac{W}{g}\int_0^{V_{LO}}\frac{V\,\mathrm{d}V}{F(V)} = \frac{W}{2g}\int_0^{V_{LO}^2}\frac{\mathrm{d}(V^2)}{F(V)} .
$$ {#eq-ground-roll}
若推力不变，则$F = A - BV^2$，其中$A = T - \mu_rW$，$B = \tfrac12\rho S(C_{D,g} - \mu_rC_{L,g})$，且
$$
s_g = \frac{W}{2gB}\ln\frac{A}{A - BV_{LO}^2} \approx \frac{W\,V_{LO}^2}{2g\,F(0.7V_{LO})} .
$$ {#eq-ground-roll-closed}
:::

::: proof
沿跑道的牛顿第二定律：$(W/g)\,\mathrm{d}V/\mathrm{d}t = F(V)$。由$\mathrm{d}s = V\,\mathrm{d}t$得$\mathrm{d}s = (W/g)V\,\mathrm{d}V/F$，而$V\,\mathrm{d}V = \tfrac12\mathrm{d}(V^2)$；积分即得[[#eq-ground-roll]]。对于$F = A - BV^2$，令$u = V^2$：$\int_0^{V_{LO}^2}\mathrm{d}u/(A - Bu) = -\tfrac1B\ln(A - Bu)\big|_0^{V_{LO}^2}$，由此得到对数。关于近似：由于$F$是$u = V^2$的函数，$1/F(u)$在$0 \le u \le V_{LO}^2$上的积分接近$V_{LO}^2/F(\bar u)$，其中$\bar u = \tfrac12V_{LO}^2$，即$\bar V = V_{LO}/\sqrt2 = 0.707V_{LO}$——这是关于$V^2$的中点公式。假设：跑道水平，无风，$\mu_r$、$C_{L,g}$、$C_{D,g}$不变，忽略抬前轮。
:::

近似式显示了比例关系：$s_g \propto WV_{LO}^2/\bar F \propto W^2/(\rho\,S\,C_{L,\max}\,\bar F)$。因此（在推力一定时）起飞距离随重量的**平方**增长，并与密度成反比——高温高原机场和重载飞机需要长跑道。逆风$V_w$使离地时所需的地速降为$V_{LO} - V_w$，显著缩短滑跑距离。

轻型飞机以$1100\ \mathrm{kg}$从海平面的干燥短草跑道（$\mu_r = 0.03$）起飞，放起飞襟翼（$C_{L,\max} = 2.0$），以$1.1V_s$离地。地面滑跑中$C_{L,g} = 0.6$，$C_{D,g} = 0.055$，螺旋桨推力取为常数$2.8\ \mathrm{kN}$。求地面滑跑距离及其时间。
::: solution
$V_s = \sqrt{2 \times 665.9/(1.225 \times 2.0)} = 23.31\ \mathrm{m/s}$，$V_{LO} = 25.65\ \mathrm{m/s}$。$A = 2800 - 0.03 \times 10\,787 = 2476.4\ \mathrm{N}$；$B = \tfrac12 \times 1.225 \times 16.2 \times (0.055 - 0.03 \times 0.6) = 0.3671\ \mathrm{kg/m}$；$BV_{LO}^2 = 241.5\ \mathrm{N}$。
$$
s_g = \frac{10\,787}{2 \times 9.80665 \times 0.3671}\ln\frac{2476.4}{2234.9} = 1498 \times 0.10261 = 153.7\ \mathrm{m}.
$$
近似式：$F(0.7V_{LO}) = 2476.4 - 0.3671 \times 17.95^2 = 2358.1\ \mathrm{N}$，$s_g \approx 1100 \times 25.65^2/(2 \times 2358.1) = 153.4\ \mathrm{m}$——误差在$0.2\,\%$以内。时间为$\int_0^{V_{LO}}m\,\mathrm{d}V/F = 11.8\ \mathrm{s}$。合理性检查：平均加速度为$25.65/11.8 = 2.2\ \mathrm{m/s^2}$，约$0.22g$，是轻型飞机的典型值；$150\ \mathrm{m}$与公布的四座飞机地面滑跑距离相符。有$5\ \mathrm{m/s}$逆风时，相对地面的$V_{LO}$降到$20.65\ \mathrm{m/s}$，滑跑距离约降为$(20.65/25.65)^2 \times 154 = 100\ \mathrm{m}$。
:::
:::

对于多发飞机，规章要求在最不利时刻发生的发动机失效既可以通过在剩余跑道上停住来处置，也可以通过用其余发动机继续起飞来处置。**决断速度**$V_1$把这两种选择分开，而加速–停止距离与加速–继续起飞距离相等时的跑道长度称为**平衡场长**。其计算是[[#eq-ground-roll]]的直接推广，只是失效后的作用力不同。

## 着陆 {#sec-landing}

着陆是起飞的逆过程：在着陆构型下以约$1.3V_s$进近（对于运输类飞机，基准速度$V_{REF}$必须至少为基准失速速度的$1.23$倍），拉平，以约$1.15V_s$接地，在扰流板打开、刹车施加之前有一段短暂的自由滑跑，然后是刹车地面滑跑。刹车滑跑中的减速力为
$$
F = \mu_b(W - L) + D + T_{\text{rev}},
$$
其中$\mu_b \approx 0.3$–$0.5$是干跑道上的刹车系数（结冰时降到$0.05$–$0.1$），$D$是扰流板打开时的气动阻力（扰流板同时卸除升力，使机轮载荷增大），$T_{\text{rev}}$是反推力（如有）。在$\mu_b$、$C_L$和$C_D$不变且无反推力时，$F = A + BV^2$，其中$A = \mu_bW$，$B = \tfrac12\rho S(C_D - \mu_bC_L)$，且
$$
s_b = \frac{W}{2gB}\ln\frac{A + BV_{TD}^2}{A} .
$$ {#eq-landing}

::: example 喷气运输机的着陆滑跑 {#ex-landing}
喷气运输机以$60\,000\ \mathrm{kg}$在海平面着陆，$C_{L,\max} = 2.6$（全襟翼）。它以$1.15V_s$接地，自由滑跑$3\ \mathrm{s}$，然后以$\mu_b = 0.4$刹车；扰流板打开时$C_L = 0.10$，$C_D = 0.10$。不使用反推力。求着陆地面距离。
::: solution
$W = 588.4\ \mathrm{kN}$，$V_s = \sqrt{2 \times 588\,399/(1.225 \times 122.6 \times 2.6)} = 54.90\ \mathrm{m/s}$，所以进近速度为$1.3V_s = 71.4\ \mathrm{m/s}$，$V_{TD} = 63.13\ \mathrm{m/s}$。自由滑跑：$3 \times 63.13 = 189\ \mathrm{m}$（忽略这一阶段的轻微减速）。刹车滑跑：$A = 0.4 \times 588\,399 = 235\,360\ \mathrm{N}$；$B = \tfrac12 \times 1.225 \times 122.6 \times (0.10 - 0.04) = 4.506\ \mathrm{kg/m}$；$BV_{TD}^2 = 17\,957\ \mathrm{N}$。
$$
s_b = \frac{588\,399}{2 \times 9.80665 \times 4.506}\ln\frac{253\,317}{235\,360} = 6658 \times 0.07353 = 489.6\ \mathrm{m}.
$$
总地面距离$\approx 679\ \mathrm{m}$。合理性检查：忽略气动阻力时$V_{TD}^2/(2\mu_bg) = 508\ \mathrm{m}$，所以阻力只使刹车滑跑缩短$4\,\%$——刹车起主导作用。审定的着陆距离要长得多：它们包括从$15\ \mathrm{m}$（$50\ \mathrm{ft}$）开始的空中段距离，并乘以放大系数（干跑道为$1/0.6$），以涵盖驾驶技术和跑道状况的差异。
:::

::: quiz
两架相同的飞机以相同坡度做水平转弯，其中一架的真空速是另一架的两倍。比较它们的转弯半径和转弯角速度。
- [ ] 半径相同；较快的那架角速度为两倍。
- [ ] 半径为两倍；角速度相同。
- [x] 半径为四倍；角速度为一半。
- [ ] 半径为一半；角速度为四倍。
::: solution
坡度一定时过载$1/\cos\phi$相同，由[[#eq-turn]]得$R = V^2/(g\tan\phi) \propto V^2$，$\omega = g\tan\phi/V \propto 1/V$。
:::
:::

::: history
莱特兄弟（Wright brothers）在1899–1903年间的关键洞见是：飞机必须像自行车一样**压坡度**才能转弯，正因如此，他们在滑翔机和1903年“飞行者”号中设计了滚转操纵（机翼翘曲）。随着飞机变得更快、更灵活，结构要求开始以设计过载的形式给出，而随速度绘出的机动包线成为表达这些要求的标准方式。突风载荷在1930年代和1950年代的 NACA 研究中建立了合理的基础，其集大成者是普拉特（Kermit G. Pratt）与沃克（Walter G. Walker）修订的突风载荷公式（NACA 第 1206 号报告，1954年），它基于“1 减余弦”型突风和一个质量比参数，是 Part 23 突风条款所用的形式，在被离散突风和连续湍流分析补充之前也是 Part 25 所用的形式。今天形式的 V–n 图是每一部适航规章中的固定内容。
:::

::: summary
- 过载$n = L/W$；过载为$n$时的失速速度为$V_s\sqrt n$。
- 水平转弯：$n = 1/\cos\phi$，$R = V^2/(g\sqrt{n^2 - 1})$，$\omega = g\sqrt{n^2 - 1}/V$；升致阻力乘以$n^2$。
- 转弯受$C_{L,\max}$、$n_{\text{lim}}$以及（稳定转弯时）推力的限制；最快的瞬时转弯在角点速度$V_s\sqrt{n_{\text{lim}}}$处。
- V–n 图以失速曲线、限制过载和$V_D$为过载的边界；设计机动速度$V_A = V_s\sqrt{n_{\text{lim}}}$；极限载荷为限制载荷的$1.5$倍。
- 突风过载增量$\propto V_E/(W/S)$，并带有减缓因子。
- 地面滑跑$s_g = (W/g)\int V\,\mathrm{d}V/F$，对$F = A - BV^2$有封闭形式，且$\approx WV_{LO}^2/(2g\bar F)$，$\bar F$取在$0.7V_{LO}$处；它按$W^2/(\rho SC_{L,\max}\bar F)$变化。
- 着陆滑跑：减速力为$\mu_b(W - L) + D + T_{\text{rev}}$；刹车起主导作用。
:::

## 习题

::: exercise 转弯中的过载 {level=1 check="30.6"}
一架 1 g 失速速度为$25\ \mathrm{m/s}$的飞机以$\phi = 48^\circ$做水平转弯。求其在转弯中的失速速度。（单位 m/s，保留一位小数。）
::: solution
$n = 1/\cos 48^\circ = 1.4945$；$V_{s,\text{turn}} = 25\sqrt{1.4945} = 30.56\ \mathrm{m/s}$，即$30.6\ \mathrm{m/s}$。
:::
:::

::: exercise 客机转弯 {level=1 check="3149"}
一架客机以$25^\circ$坡度、真空速$120\ \mathrm{m/s}$转弯。求转弯半径。（单位 m，取整数。）
::: solution
$R = V^2/(g\tan\phi) = 14\,400/(9.80665 \times 0.46631) = 3149\ \mathrm{m}$。过载为$1.103$，角速度为$2.18^\circ/\mathrm{s}$，接近一级转弯。
:::
:::

::: exercise 拉起 {level=1 check="2.84"}
以$60\ \mathrm{m/s}$在半径$200\ \mathrm{m}$的圆周上拉起，求最低点处的过载。（输入$n$，保留两位小数。）
::: solution
$n = 1 + V^2/(gR) = 1 + 3600/(9.80665 \times 200) = 1 + 1.836 = 2.84$。
:::
:::

::: exercise 轻型飞机的稳定转弯 {level=2 check="1.86"}
轻型飞机（$W = 10\,787\ \mathrm{N}$，$S = 16.2\ \mathrm{m^2}$，$C_{D0} = 0.030$，$K = 0.05305$）的推力功率为$75\ \mathrm{kW}$。求它在海平面以$45\ \mathrm{m/s}$做水平转弯时所能保持的最大过载及坡度。（输入$n$，保留两位小数。）
::: solution
$T = 75\,000/45 = 1666.7\ \mathrm{N}$，$q = 1240.3\ \mathrm{Pa}$，$qS = 20\,093\ \mathrm{N}$，零升阻力$qSC_{D0} = 602.8\ \mathrm{N}$。由[[#eq-n-sustained]]：$n^2 = \dfrac{20\,093}{0.05305 \times 10\,787^2}(1666.7 - 602.8) = 3.255 \times 10^{-3} \times 1063.9 = 3.463$，$n = 1.86$，坡度$\cos^{-1}(1/1.86) = 57.5^\circ$。在这一速度下更陡的转弯会损失高度或速度。
:::
:::

::: exercise 设计机动速度 {level=2 check="52.5"}
轻型飞机（最大质量时$V_s = 26.92\ \mathrm{m/s}$ EAS）按正常类审定，$n_{\text{lim}} = 3.8$。求其设计机动速度$V_A$，以及质量为$850\ \mathrm{kg}$时的值。（输入最大质量下的$V_A$，单位 m/s，保留一位小数。）
::: solution
$V_A = V_s\sqrt{3.8} = 26.92 \times 1.9494 = 52.48\ \mathrm{m/s}$，即$52.5\ \mathrm{m/s}$（$102\ \mathrm{kt}$）。在$850\ \mathrm{kg}$时，$V_s$和$V_A$按$\sqrt W$变化：$52.48\sqrt{850/1100} = 46.1\ \mathrm{m/s}$。因此在湍流中以$50\ \mathrm{m/s}$飞行，在最大质量时是安全的，而在轻载时则不安全。
:::
:::

::: exercise 突风过载 {level=2 check="3.74"}
轻型飞机（$W/S = 665.9\ \mathrm{N/m^2}$，平均弦长$\bar c = 1.47\ \mathrm{m}$，升力线斜率$a = 5.0\ \mathrm{rad^{-1}}$）在海平面以$60\ \mathrm{m/s}$ EAS 飞入导出突风$U_{de} = 15.24\ \mathrm{m/s}$。利用[[#eq-gust]]求总过载$1 + \Delta n$。（保留两位小数。）
::: solution
$\mu_g = 2 \times 665.9/(1.225 \times 1.47 \times 5.0 \times 9.80665) = 15.09$；$K_g = 0.88 \times 15.09/20.39 = 0.6512$；$\Delta n = 1.225 \times 0.6512 \times 15.24 \times 60 \times 5.0/(2 \times 665.9) = 2.74$；$n = 3.74$，恰在机动限制$3.8$之下——对于轻型飞机，突风和机动施加的载荷相当。
:::
:::

::: exercise 重量与起飞距离 {level=2 check="21"}
利用近似式[[#eq-ground-roll-closed]]，并假设$0.7V_{LO}$处的加速力不变，若起飞质量增加$10\,\%$（仍以$1.1V_s$离地），地面滑跑距离增加百分之几？（取整数百分比。）
::: solution
$s_g \propto WV_{LO}^2$，而$V_{LO}^2 \propto W$，所以在$\bar F$不变时$s_g \propto W^2$：$1.1^2 = 1.21$，增加$21\,\%$。（实际上由于滚动摩擦$\mu_rW$增大，$\bar F$也会减小，因此实际增量略大一些。）
:::
:::

::: exercise 湿跑道着陆 {level=3 check="1190"}
取$\mu_b = 0.15$（纹理差的湿跑道），其余不变，重做[[#ex-landing]]。求刹车地面滑跑距离，并讨论运营人会采取什么措施。（输入刹车滑跑距离，单位 m，取整数。）
::: solution
$A = 0.15 \times 588\,399 = 88\,260\ \mathrm{N}$；$B = \tfrac12 \times 1.225 \times 122.6 \times (0.10 - 0.015) = 6.383\ \mathrm{kg/m}$；$BV_{TD}^2 = 25\,439\ \mathrm{N}$。$s_b = \dfrac{588\,399}{2 \times 9.80665 \times 6.383}\ln\dfrac{113\,700}{88\,260} = 4700 \times 0.25327 = 1190\ \mathrm{m}$，是干跑道值的$2.4$倍；加上自由滑跑，地面距离约为$1380\ \mathrm{m}$。此时气动阻力消耗的能量份额更大（没有它时为$V_{TD}^2/(2\mu_bg) = 1355\ \mathrm{m}$）。运营人会使用反推力和自动刹车，采用规章要求的更大的湿跑道着陆距离系数，以较低的重量或在逆风条件下着陆，或改飞更长的跑道；在污染跑道上还需要进行滑水检查（把$V_{TD}$与基于轮胎压力的滑水速度相比较）。
:::
:::

::: exercise 为短跑道而设计 {level=3}
一架与轻型飞机类似的四座飞机必须从高温高原草地跑道（$\sigma = 0.80$，$\mu_r = 0.05$）起飞，在$400\ \mathrm{m}$以内越过$15\ \mathrm{m}$高的障碍物。列出能减小起飞距离的设计参数，由比例关系$s_g \propto W^2/(\rho SC_{L,\max}\bar F)$估计每个参数的影响，并提出一套组合改进方案。
::: solution
由比例关系，地面滑跑距离随以下因素而减小：更轻的重量（$\propto W^2$）；更大的机翼面积或更高的$C_{L,\max}$（更有效的襟翼，开缝襟翼或富勒襟翼；$\propto 1/(SC_{L,\max})$）；更大的加速力（更大的功率，或采用恒速螺旋桨，它的静推力远大于定距巡航螺旋桨；在草地上使用更大的轮胎以减小滚动摩擦）。影响：在$\sigma = 0.80$时，即使不计发动机功率的损失（$1.132 \times 0.8 - 0.132 = 0.77$），滑跑距离也已是海平面值的$1/0.80 = 1.25$倍；草地使$\mu_rW$从$324$增大到$539\ \mathrm{N}$，约为典型推力$2.5\ \mathrm{kN}$的$9\,\%$。一套合理的组合：恒速螺旋桨（静推力约提高$20$–$30\,\%$），富勒襟翼使$C_{L,\max}$从$2.0$提高到约$2.4$（$-17\,\%$），以及对高温高原跑道的起飞重量加以使用限制。还必须加上到$15\ \mathrm{m}$的空中段（对于轻型飞机通常为地面滑跑距离的$40$–$60\,\%$），并把总距离与包含安全系数的审定数据相比较。好的回答还会指出，更大的机翼会增大巡航阻力（$C_{D0}S$）并降低巡航速度：这一权衡正是轻型飞机设计的核心。
:::
