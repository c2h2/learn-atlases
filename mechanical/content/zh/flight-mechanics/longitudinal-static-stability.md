前面几讲性能课把飞机视为质点：升力、阻力、推力和重力作用于一点，并假设俯仰力矩以某种方式得到了平衡。本讲要问的是如何平衡。定常飞行中的飞机必须**配平**（trimmed）——绕重心的总俯仰力矩必须为零——并且应当**静稳定**：如果一阵突风使机头抬起，由此产生的气动力矩应当把机头压回去。这两个性质都取决于重心的位置以及水平尾翼，而水平尾翼的任务恰恰就是提供这两个性质。分析所得到的是飞机装载手册中最重要的一个数：允许的重心位置范围。

气动方面的要素——气动中心、力矩系数$C_{m,ac}$和升力线斜率——来自[[aerodynamics/aerodynamic-forces]]和[[aerodynamics/thin-airfoil-theory]]；下洗来自[[aerodynamics/finite-wings]]。动稳定性研究飞机如何随时间恢复（或不恢复），是[[flight-mechanics/dynamic-modes]]的主题。

## 静稳定性 {#sec-static}

::: definition 静稳定性与配平 {#def-static-stability}
若飞机在迎角$\alpha_{\text{trim}}$处绕重心的俯仰力矩系数为零，$C_m(\alpha_{\text{trim}}) = 0$，则称飞机在该迎角下**配平**。若迎角从配平值稍微增大时产生低头力矩，则称飞机**俯仰静稳定**（具有正的**俯仰刚度**）：
$$
C_{m\alpha} = \frac{\partial C_m}{\partial\alpha} < 0 .
$$
$C_m$以抬头为正；$\alpha$从飞机的零升力线量起，因此$C_L = a\alpha$（$a$为全机的升力线斜率）。仅有稳定性并不能保证在有用的升力系数下配平：为此零升力矩必须为正，$C_{m0} > 0$，使直线$C_m(\alpha)$在正的$\alpha$处穿过零。
:::

“静”的含义是只考察**初始趋势**：恢复力矩的符号是否正确，而不管随后的运动是否衰减。静不稳定的飞机必定动不稳定；静稳定的飞机通常（但并非总是）动稳定。

单独一副普通机翼是一种很差的飞行器。它的升力作用在气动中心上，并伴有一个恒定力矩$C_{m,ac}$，对于正弯度翼型它是负的（低头）。如果重心在气动中心之前，机翼是稳定的，但不能在正升力下配平（$C_{m0} = C_{m,ac} < 0$）；如果重心在其后，机翼是不稳定的。飞翼用 S 形翼型或后掠加扭转的机翼使$C_{m,ac}$为正来解决这一问题；常规飞机则加装水平尾翼。

## 力矩方程 {#sec-moment}

**俯仰受力图。** 沿机翼的平均气动弦$\bar c$从其前缘量取距离，以$\bar c$的分数表示。在对称面内作用于飞机的力和力矩为：

- **翼身组合体**的升力$L_{wb}$，作用在其气动中心$h_{ac}\bar c$处，并伴有其恒定力矩$M_{ac} = qS\bar c\,C_{m,ac}$（机身使气动中心相对于机翼本身的气动中心前移，通常为$0.03$–$0.10\,\bar c$）；
- **水平尾翼**的升力$L_t$，作用在尾翼的气动中心上，位于翼身气动中心之后$l_t$处；
- **重力**，作用在位于$h\bar c$处的重心上；
- 推力和阻力，这里忽略它们的力矩（在大多数飞机上它们的作用线都靠近重心；推力线偏高或偏低的影响是对$C_{m0}$的修正，对于螺旋桨飞机还有对$C_{m\alpha}$的修正）。

尾翼处在机翼的下洗中，下洗使其迎角减小**下洗角**$\varepsilon$；尾翼还处在速度较低、受扰动的气流中，这用**尾翼效率**$\eta = q_t/q$（通常为$0.85$–$1.0$）表示。若尾翼相对于翼身零升力线的安装角为$i_t$，升降舵偏角为$\delta_e$（后缘向下为正），则
$$
\alpha_t = \alpha - \varepsilon + i_t,\qquad \varepsilon = \varepsilon_\alpha\,\alpha,\qquad C_{L,t} = a_t\alpha_t + a_e\delta_e ,
$$ {#eq-tail-alpha}
其中$a_t$是尾翼升力线斜率，$a_e = \tau a_t$是升降舵效能（对于典型的升降舵弦长与尾翼弦长之比，$\tau \approx 0.3$–$0.6$），$\varepsilon_\alpha = \mathrm{d}\varepsilon/\mathrm{d}\alpha$是下洗梯度。升力线理论给出，在椭圆载荷机翼的远下游，$\varepsilon = 2C_L/(\pi AR)$，因此初步估计为$\varepsilon_\alpha \approx 2a_{wb}/(\pi AR)$；在实际的尾翼位置上它要小一些。

::: definition 尾容量 {#def-tail-volume}
**水平尾容量**（horizontal tail volume coefficient）为
$$
\bar V_H = \frac{l_tS_t}{S\bar c},
$$
即尾翼面积绕翼身气动中心所扫过的“体积”$l_tS_t$与参考体积$S\bar c$之比。典型值：轻型飞机为$0.5$–$0.8$，喷气运输机为$0.8$–$1.2$。
:::

::: proposition 绕重心的俯仰力矩 {#prop-cm}
在上述假设下，绕重心的俯仰力矩系数为
$$
C_m = C_{m,ac} + C_L\,(h - h_{ac}) - \eta\bar V_H\,C_{L,t},
$$ {#eq-cm}
其中$C_L = C_{L,wb} + \eta(S_t/S)C_{L,t}$是全机升力系数。其斜率为
$$
C_{m\alpha} = a\,(h - h_{ac}) - \eta\bar V_H\,a_t(1 - \varepsilon_\alpha),\qquad
a = a_{wb} + \eta\frac{S_t}{S}a_t(1 - \varepsilon_\alpha).
$$ {#eq-cm-alpha}
:::

::: proof
对重心取矩，抬头为正。翼身升力作用在重心**之前**$(h - h_{ac})\bar c$处（若$h > h_{ac}$），产生抬头力矩$L_{wb}(h - h_{ac})\bar c$。尾翼升力作用在重心之后$l_t + (h_{ac} - h)\bar c$处，产生低头力矩$L_t[l_t + (h_{ac} - h)\bar c]$。加上$M_{ac}$：
$$
M = M_{ac} + L_{wb}(h - h_{ac})\bar c - L_tl_t + L_t(h - h_{ac})\bar c .
$$
含$(h - h_{ac})$的两项合并为$(L_{wb} + L_t)(h - h_{ac})\bar c = L(h - h_{ac})\bar c$。除以$qS\bar c$，并写出$L_t = \eta qS_tC_{L,t}$，即得[[#eq-cm]]。对$\alpha$求导，利用[[#eq-tail-alpha]]在$\delta_e$不变时的$\mathrm{d}C_{L,t}/\mathrm{d}\alpha = a_t(1 - \varepsilon_\alpha)$以及$\mathrm{d}C_L/\mathrm{d}\alpha = a$，即得[[#eq-cm-alpha]]。假设：小角度（不区分升力、阻力方向与法向、轴向），线性气动力，忽略推力和阻力的力矩以及各翼面的竖直偏移。
:::

## 中性点与静稳定裕度 {#sec-neutral-point}

[[#eq-cm-alpha]]对重心位置$h$是线性的：重心前移使$C_{m\alpha}$更负。存在一个位置使$C_{m\alpha} = 0$。

::: proposition 握杆中性点 {#prop-neutral-point}
当重心位于**握杆中性点**
$$
h_n = h_{ac} + \eta\bar V_H\,\frac{a_t}{a}\,(1 - \varepsilon_\alpha),
$$ {#eq-neutral-point}
时，俯仰刚度为零；对于其他任何位置，
$$
C_{m\alpha} = -a\,(h_n - h) = -a\,K_n,\qquad K_n = h_n - h,
$$ {#eq-static-margin}
其中$K_n$是**静稳定裕度**（static margin）。飞机静稳定的充要条件是重心位于中性点之前（$K_n > 0$）。中性点就是全机的气动中心（焦点）。
:::

::: proof
令[[#eq-cm-alpha]]为零并解出$h$：$a(h_n - h_{ac}) = \eta\bar V_Ha_t(1 - \varepsilon_\alpha)$，即[[#eq-neutral-point]]。把$\eta\bar V_Ha_t(1 - \varepsilon_\alpha) = a(h_n - h_{ac})$代回[[#eq-cm-alpha]]，得$C_{m\alpha} = a(h - h_{ac}) - a(h_n - h_{ac}) = a(h - h_n)$。由于$a > 0$，$C_{m\alpha} < 0 \iff h < h_n$。最后，绕点$h_n$的力矩不随$\alpha$变化——这正是气动中心的定义。
:::

静稳定裕度是重心与中性点之间以平均气动弦为单位的距离。轻型飞机视装载情况以约$0.05$–$0.25$的$K_n$飞行；运输机为$0.05$–$0.15$；一些电传操纵的作战飞机（从 F-16 开始）在亚声速时设计成很小甚至为负的裕度（“放宽静稳定性”），稳定性由控制系统提供（[[flight-mechanics/flight-control]]）。

::: example 轻型飞机的中性点 {#ex-neutral-point}
轻型飞机的$S = 16.2\ \mathrm{m^2}$，$AR = 7.5$，$\bar c = 1.47\ \mathrm{m}$，翼身升力线斜率$a_{wb} = 4.8\ \mathrm{rad^{-1}}$，气动中心$h_{ac} = 0.20$。其尾翼$S_t = 3.0\ \mathrm{m^2}$，$l_t = 4.5\ \mathrm{m}$，$a_t = 4.0\ \mathrm{rad^{-1}}$，$\eta = 0.90$。用升力线理论估计$\varepsilon_\alpha$，求中性点以及重心在$h = 0.30$时的静稳定裕度。
::: solution
$\bar V_H = 4.5 \times 3.0/(16.2 \times 1.47) = 0.5669$。$\varepsilon_\alpha = 2 \times 4.8/(\pi \times 7.5) = 0.4074$，故$1 - \varepsilon_\alpha = 0.5926$。全机升力线斜率：
$$
a = 4.8 + 0.90 \times \frac{3.0}{16.2} \times 4.0 \times 0.5926 = 4.8 + 0.3950 = 5.195\ \mathrm{rad^{-1}}.
$$
中性点：
$$
h_n = 0.20 + 0.90 \times 0.5669 \times \frac{4.0}{5.195} \times 0.5926 = 0.20 + 0.2328 = 0.4328 .
$$
在$h = 0.30$时：$K_n = 0.1328$，$C_{m\alpha} = -5.195 \times 0.1328 = -0.690\ \mathrm{rad^{-1}}$。合理性检查：尾翼使气动中心后移$0.23\bar c = 0.34\ \mathrm{m}$，$13\,\%$的静稳定裕度是轻型飞机在中等装载时的典型值。下洗很重要：若$\varepsilon_\alpha = 0$，尾翼项将是$0.39$而不是$0.23$。
:::
:::

::: warning 移动重心
方向很容易搞错：重心**后移**会减小静稳定裕度，使飞机**更不**稳定、操纵更轻；重心**前移**会增大稳定性，但配平和起飞抬前轮需要更多的升降舵。装载超出后限——行李放在后部、乘客移到后面、先消耗前部油箱的燃油——曾导致致命事故，因为飞机可能变得不稳定，飞行员的修正操纵随之会越来越大而不是逐渐消失。还要注意，中性点是飞机本身的属性，而静稳定裕度取决于装载；$h$是从**平均气动弦**的前缘量起的，而不是从机头量起。
:::

## 配平与升降舵 {#sec-trim}

升降舵改变尾翼升力，从而同时改变$C_L$和$C_m$。由[[#eq-cm]]和[[#eq-tail-alpha]]，对$\delta_e$的导数为
$$
C_{L\delta} = \eta\frac{S_t}{S}a_e,\qquad C_{m\delta} = C_{L\delta}(h - h_{ac}) - \eta\bar V_H\,a_e ,
$$ {#eq-elevator-derivs}
因此飞机的线性模型为
$$
C_L = C_{L0} + a\alpha + C_{L\delta}\delta_e,\qquad C_m = C_{m0} + C_{m\alpha}\alpha + C_{m\delta}\delta_e .
$$ {#eq-linear-model}
升降舵是很有效的力矩发生器（$C_{m\delta}$数值大且为负：后缘上偏产生抬头力矩），却是很弱的升力发生器（$C_{L\delta}$很小，而且升降舵上偏时它与所需的升力方向相反）。

::: proposition 配平升降舵偏角 {#prop-trim}
对于所需的升力系数$C_L$，配平升降舵偏角和配平迎角为
$$
\delta_{\text{trim}} = -\frac{C_{m0}\,a + C_{m\alpha}(C_L - C_{L0})}{\Delta},\qquad
\alpha_{\text{trim}} = \frac{(C_L - C_{L0})C_{m\delta} + C_{m0}C_{L\delta}}{\Delta},\qquad
\Delta = aC_{m\delta} - C_{m\alpha}C_{L\delta}.
$$ {#eq-trim}
单位升力系数所需的升降舵偏角为
$$
\frac{\mathrm{d}\delta_{\text{trim}}}{\mathrm{d}C_L} = -\frac{C_{m\alpha}}{\Delta} = \frac{a\,K_n}{\Delta},
$$ {#eq-elevator-gradient}
而$\Delta = a\left[C_{L\delta}(h_n - h_{ac}) - \eta\bar V_Ha_e\right]$与重心位置无关，因此该梯度与静稳定裕度成正比。
:::

::: proof
在[[#eq-linear-model]]中令$C_m = 0$并令$C_L$等于所需值，得到关于$\alpha$和$\delta_e$的两个线性方程；由克拉默法则得[[#eq-trim]]。$\delta_{\text{trim}}$对$C_L$求导得$-C_{m\alpha}/\Delta$，而$C_{m\alpha} = -aK_n$。对于$\Delta$，代入[[#eq-elevator-derivs]]中的$C_{m\delta}$以及$C_{m\alpha} = a(h - h_n)$：$\Delta = aC_{L\delta}(h - h_{ac}) - a\eta\bar V_Ha_e - a(h - h_n)C_{L\delta} = a[C_{L\delta}(h_n - h_{ac}) - \eta\bar V_Ha_e]$，其中$h$已消去。
:::

由于$\Delta < 0$，稳定的飞机（$K_n > 0$）要在更高的升力系数——即更低的速度——下配平，就需要更多的后缘上偏升降舵（$\delta$更负）。这就是飞行员所说的**速度稳定性**：要飞得更慢，就必须拉杆。随着重心后移，梯度变平，在中性点处升降舵偏角不再随速度变化。这给出了测定中性点的经典**飞行试验方法**：在两个或更多重心位置上测量$\mathrm{d}\delta/\mathrm{d}C_L$，然后线性外推到零。

::: example 轻型飞机的配平 {#ex-trim}
对于[[#ex-neutral-point]]的轻型飞机，取$C_{m,ac} = -0.05$，尾翼安装角$i_t = -2^\circ$，升降舵效能$\tau = 0.45$。重心在$h = 0.30$时，求巡航（$C_L = 0.40$）和进近（$C_L = 1.2$，忽略襟翼）时的配平升降舵偏角和配平迎角。
::: solution
$a_e = 0.45 \times 4.0 = 1.80\ \mathrm{rad^{-1}}$；$C_{L\delta} = 0.90 \times 0.1852 \times 1.80 = 0.300\ \mathrm{rad^{-1}}$；$C_{m\delta} = 0.300 \times 0.10 - 0.90 \times 0.5669 \times 1.80 = 0.030 - 0.9184 = -0.8884\ \mathrm{rad^{-1}}$。

在$\alpha = \delta_e = 0$时，尾翼升力系数为$a_ti_t = 4.0 \times (-0.03491) = -0.1396$，故$C_{L0} = 0.90 \times 0.1852 \times (-0.1396) = -0.02327$，由[[#eq-cm]]，$C_{m0} = -0.05 + (-0.02327)(0.10) - 0.90 \times 0.5669 \times (-0.1396) = -0.05 - 0.00233 + 0.07124 = 0.01891$。

$\Delta = 5.195 \times (-0.8884) - (-0.6898)(0.300) = -4.615 + 0.207 = -4.408$。

巡航，$C_L - C_{L0} = 0.4233$：
$$
\delta_{\text{trim}} = -\frac{0.01891 \times 5.195 + (-0.6898)(0.4233)}{-4.408} = -\frac{0.09824 - 0.2920}{-4.408} = -0.04395\ \mathrm{rad} = -2.52^\circ,
$$
$$
\alpha_{\text{trim}} = \frac{0.4233 \times (-0.8884) + 0.01891 \times 0.300}{-4.408} = 0.08401\ \mathrm{rad} = 4.81^\circ .
$$
进近，$C_L - C_{L0} = 1.2233$：$\delta_{\text{trim}} = -9.69^\circ$，$\alpha_{\text{trim}} = 14.05^\circ$。合理性检查：梯度为每单位$C_L$ $(-9.69 + 2.52)/0.8 = -8.97^\circ$，等于$aK_n/\Delta = 5.195 \times 0.1328/(-4.408)$ rad $= -8.97^\circ$；两个升降舵偏角都远在典型行程$-25^\circ$至$+15^\circ$之内。
:::
:::

**重心范围。** **重心后限**由稳定性决定：必须保留一个最小静稳定裕度（握杆的，以及更为关键的松杆的——见下文），通常为$5\,\%$。**重心前限**由操纵效能决定：重心很靠前时，升降舵必须能使飞机在着陆构型下以$C_{L,\max}$配平（包括襟翼的低头力矩以及地面效应中减小的下洗），并能在起飞时抬前轮。轻型飞机的允许范围通常为$\bar c$的$15$–$30\,\%$。

::: example 在飞行试验中确定中性点 {#ex-flight-test}
在轻型飞机的飞行试验中，在两种装载下测量了配平升降舵偏角随$C_L$的变化。重心在$h = 0.20$时斜率为每单位$C_L$ $-15.72^\circ$；在$h = 0.30$时为$-8.97^\circ$。估计中性点。
::: solution
由[[#eq-elevator-gradient]]，斜率对$h$是线性的，在$h_n$处为零。它每$0.10$弦长变化$6.75^\circ$，因此在$h = 0.30$之后$8.97/67.5 = 0.1329$处达到零：$h_n = 0.433$。合理性检查：这与[[#ex-neutral-point]]的估计一致——这是当然的，因为这些“测量值”是用同一模型算出来的；在真实试验中，测得的中性点才是可信的，因为下洗和机身效应很难预测。试验在安全的靠前位置进行，然后**外推**：没有人会为了找中性点而在中性点上飞行。
:::

## 松杆稳定性与操纵力 {#sec-stick-free}

到目前为止，升降舵一直保持固定（“握杆”）。在采用可逆（无助力）操纵系统的飞机上，飞行员可以松开驾驶杆，此时升降舵**浮动**到其气动铰链力矩为零的角度。升降舵的铰链力矩系数模型为
$$
C_h = \frac{H}{q_tS_ec_e} = C_{h0} + b_1\alpha_t + b_2\delta_e ,
$$ {#eq-hinge}
其中$S_e$、$c_e$为升降舵的面积和弦长；$b_1 = \partial C_h/\partial\alpha_t$和$b_2 = \partial C_h/\partial\delta_e$通常都为负（气动载荷把偏转了的升降舵推回中立位置，而尾翼迎角增大会把升降舵后缘向上推）。

::: proposition 松杆中性点 {#prop-stick-free}
若升降舵自由浮动（$C_h = 0$），则尾翼的有效升力线斜率减小为$a_t(1 - \tau b_1/b_2)$，松杆中性点在很好的近似下为
$$
h_n' = h_{ac} + \eta\bar V_H\,\frac{a_t}{a}\,(1 - \varepsilon_\alpha)\left(1 - \frac{\tau b_1}{b_2}\right).
$$ {#eq-stick-free}
当$b_1$与$b_2$同号时，$h_n' < h_n$：松开升降舵会使中性点前移，静稳定裕度减小。
:::

::: proof
在[[#eq-hinge]]中令$C_h = 0$，得$\delta_{\text{free}} = -(C_{h0} + b_1\alpha_t)/b_2$。尾翼升力变为$C_{L,t} = a_t\alpha_t + a_e\delta_{\text{free}} = a_t\alpha_t(1 - \tau b_1/b_2) - a_eC_{h0}/b_2$，因此它对$\alpha_t$的斜率为$a_t(1 - \tau b_1/b_2)$。用这一斜率重复[[#prop-neutral-point]]的推导，尾翼项中的$a_t$被替换为$a_t(1 - \tau b_1/b_2)$。关于近似：全机升力线斜率$a$中也含有尾翼斜率，但尾翼在$a$中所占份额很小（对轻型飞机为 8 %），因此$a$保留其握杆值。
:::

::: example 轻型飞机的松杆裕度 {#ex-stick-free}
轻型飞机升降舵的铰链力矩导数为$b_1 = -0.20\ \mathrm{rad^{-1}}$和$b_2 = -0.40\ \mathrm{rad^{-1}}$，$\tau = 0.45$。求松杆中性点、$h = 0.30$时的松杆静稳定裕度，以及当尾翼迎角增大$2^\circ$时自由升降舵浮动的角度。
::: solution
自由升降舵因子为$1 - \tau b_1/b_2 = 1 - 0.45 \times (-0.20)/(-0.40) = 1 - 0.225 = 0.775$。由[[#ex-neutral-point]]，握杆中性点的尾翼项为$0.2328$，故
$$
h_n' = 0.20 + 0.2328 \times 0.775 = 0.3804 ,
$$
$h = 0.30$时的松杆裕度为$0.080$，而握杆裕度为$0.133$。$\alpha_t$增大$2^\circ$使升降舵浮动$\Delta\delta = -(b_1/b_2)\Delta\alpha_t = -0.5 \times 2^\circ = -1^\circ$（后缘上偏），这抵消了尾翼迎角$2^\circ$变化中的$0.45 \times 1^\circ = 0.45^\circ$——即尾翼效能损失$22.5\,\%$。合理性检查：$h_n' < h_n$，符合命题的要求；$8\,\%$的松杆裕度对于中等装载的轻型飞机是可以接受的值。
:::
:::

设计者用气动补偿（角补偿、轴线后移补偿）来控制$b_1$和$b_2$，它们能减小铰链力矩和杆力，但如[[#eq-stick-free]]所示，也会影响松杆稳定性。

飞行员感受到的**杆力**与铰链力矩成正比：$F_s = G\,H = G\,\eta qS_ec_eC_h$，其中传动比$G$（rad/m）把升降舵偏角与驾驶杆行程联系起来。用配平条件消去$\alpha$和$\delta_e$，得到形如$F_s = A_1q + A_2(W/S)$的杆力，其中$A_2$与松杆静稳定裕度$h_n' - h$成正比，$A_1$包含配平调整片的设置。调整片被调到使所选配平速度$V_{\text{trim}}$下$F_s = 0$，此时该速度下的**杆力梯度**为
$$
\left.\frac{\mathrm{d}F_s}{\mathrm{d}V}\right|_{\text{trim}} = -\frac{2A_2\,(W/S)}{V_{\text{trim}}},
$$ {#eq-stick-force-gradient}
它与松杆静稳定裕度和翼载成正比，与配平速度成反比，并与调整片设置无关。适航规章要求稳定的杆力梯度（飞得更慢需要拉力，飞得更快需要推力），这就是为什么对于人工操纵的飞机，决定重心后限的通常是松杆裕度而不是握杆裕度。

::: quiz
一架飞机在$60\ \mathrm{m/s}$时松手配平。然后把它的重心后移（但仍在两个中性点之前），并在同一速度下重新配平。有什么变化？
- [ ] 单位$C_L$的升降舵偏角变得更陡，杆力梯度增大。
- [x] 对给定的速度变化所需的升降舵偏角变化和杆力都减小：飞机感觉更轻，稳定性更差。
- [ ] 没有变化，因为中性点是固定的。
- [ ] 飞机变得不稳定。
::: solution
升降舵偏角梯度[[#eq-elevator-gradient]]和杆力梯度[[#eq-stick-force-gradient]]都与（握杆或松杆）静稳定裕度成正比，而裕度随重心后移而减小。中性点是固定的，但裕度是到中性点的距离。
:::
:::

::: history
乔治·凯利爵士（Sir George Cayley）1804年的模型滑翔机就已在机翼之后安装了尾翼以获得稳定性；阿尔方斯·佩诺（Alphonse Pénaud）1871年的橡筋动力“planophore”之所以能稳定飞行，是因为其尾翼的安装角小于机翼——这一“纵向上反角”提供了$C_{m0} > 0$。相比之下，1903年的莱特“飞行者”号采用前置升降舵，在俯仰上是有意设计成不稳定的；莱特兄弟技术高超，能够驾驭它，但其后继机型都改用了后置尾翼。数学理论始于布赖恩（G. H. Bryan）与威廉斯（W. E. Williams）的《滑翔机的纵向稳定性》（“The longitudinal stability of aerial gliders”，*Proceedings of the Royal Society*，1904）以及布赖恩的著作《航空中的稳定性》（*Stability in Aviation*，1911）。中性点、静稳定裕度和松杆分析在1930和1940年代形成了教科书形式；珀金斯（C. D. Perkins）与黑格（R. E. Hage）的《飞机性能、稳定性与操纵》（*Airplane Performance, Stability and Control*，Wiley，1949）确立了此后大多数教材所遵循的体例。
:::

::: summary
- 俯仰静稳定性：$C_{m\alpha} < 0$；有用的配平还要求$C_{m0} > 0$，通常由相对机翼以负安装角安装的尾翼提供。
- 绕重心：$C_m = C_{m,ac} + C_L(h - h_{ac}) - \eta\bar V_HC_{L,t}$，尾容量$\bar V_H = l_tS_t/(S\bar c)$，下洗$\varepsilon = \varepsilon_\alpha\alpha$。
- 握杆中性点$h_n = h_{ac} + \eta\bar V_H(a_t/a)(1 - \varepsilon_\alpha)$；静稳定裕度$K_n = h_n - h$；$C_{m\alpha} = -aK_n$。
- 配平由关于$\alpha$和$\delta_e$的两个线性方程求得；升降舵梯度$\mathrm{d}\delta/\mathrm{d}C_L = aK_n/\Delta$与静稳定裕度成正比——这是飞行试验方法的基础。
- 重心后限由稳定性（最小裕度）决定，前限由高$C_L$和地面效应中的升降舵操纵效能决定。
- 浮动的升降舵使尾翼效能乘以$1 - \tau b_1/b_2$；松杆中性点位于握杆中性点之前，杆力梯度与松杆裕度成正比。
:::

## 习题

::: exercise 尾容量 {level=1 check="0.95"}
一架喷气运输机的$S = 122.6\ \mathrm{m^2}$，$\bar c = 4.19\ \mathrm{m}$，水平尾翼面积$S_t = 31\ \mathrm{m^2}$，其气动中心位于翼身气动中心之后$l_t = 15.8\ \mathrm{m}$处。求$\bar V_H$。（保留两位小数。）
::: solution
$\bar V_H = 15.8 \times 31/(122.6 \times 4.19) = 489.8/513.7 = 0.953$，即$0.95$——在运输机的常见范围之内。
:::
:::

::: exercise 由力矩斜率求静稳定裕度 {level=1 check="0.12"}
风洞试验给出重心在$h = 0.28$时$C_{m\alpha} = -0.66\ \mathrm{rad^{-1}}$，$a = 5.5\ \mathrm{rad^{-1}}$。求静稳定裕度。（输入$K_n$，以$\bar c$的分数表示，保留两位小数。）
::: solution
$K_n = -C_{m\alpha}/a = 0.66/5.5 = 0.12$，故$h_n = 0.40$。
:::
:::

::: exercise 不计下洗的中性点 {level=1 check="0.573"}
错误地假设$\varepsilon_\alpha = 0$（并相应地重新计算$a$），重新计算[[#ex-neutral-point]]的中性点。（输入$h_n$，保留三位小数。）
::: solution
$a = 4.8 + 0.90 \times 0.1852 \times 4.0 = 5.4667$；$h_n = 0.20 + 0.90 \times 0.5669 \times 4.0/5.4667 = 0.20 + 0.3733 = 0.573$。忽略下洗会把中性点放到偏后$0.14\bar c$（$0.21\ \mathrm{m}$）的位置，可能导致一个使实际飞机不稳定的重心后限。
:::
:::

::: exercise 满足裕度要求的重心后限 {level=2 check="0.35"}
对于轻型飞机，松杆中性点为$h_n' = 0.380$（$a$保留其握杆值），握杆中性点为$0.433$。设计者要求握杆裕度至少为$5\,\%$，松杆裕度至少为$3\,\%$。重心后限是多少？（输入$h$，保留两位小数。）
::: solution
握杆：$h \le 0.433 - 0.05 = 0.383$。松杆：$h \le 0.380 - 0.03 = 0.350$。较严的限制起作用：$h_{\text{aft}} = 0.350$。
:::
:::

::: exercise 重心前限处的配平升降舵 {level=2 check="-17.8"}
对于[[#ex-trim]]中的轻型飞机，重心在$h = 0.20$时，求$C_L = 1.2$时的配平升降舵偏角。（输入$\delta_{\text{trim}}$，单位为度，保留一位小数。）
::: solution
在$h = 0.20$时：$K_n = 0.2328$，$C_{m\alpha} = -5.195 \times 0.2328 = -1.2094$；$C_{m\delta} = 0.300 \times 0 - 0.9184 = -0.9184$；$C_{m0} = -0.05 + 0 + 0.07124 = 0.02124$；$\Delta = 5.195 \times (-0.9184) - (-1.2094)(0.300) = -4.771 + 0.363 = -4.408$（不变，与[[#prop-trim]]的预测一致）。$\delta = -[0.02124 \times 5.195 + (-1.2094)(1.2233)]/(-4.408) = -(0.1103 - 1.4795)/(-4.408) = -0.3106\ \mathrm{rad} = -17.8^\circ$。考虑到$-25^\circ$的行程以及襟翼和地面效应额外的低头力矩，$h = 0.20$已接近重心前限。
:::
:::

::: exercise 由飞行试验求中性点 {level=2 check="0.41"}
在一次飞行试验中，配平升降舵梯度$\mathrm{d}\delta/\mathrm{d}C_L$在$h = 0.21$时为$-12.0^\circ$，在$h = 0.31$时为$-6.0^\circ$。估计握杆中性点。（输入$h_n$，保留两位小数。）
::: solution
梯度每$0.10$弦长增大$6.0^\circ$，因此在$h = 0.31$之后$0.10$处达到零：$h_n = 0.41$。
:::
:::

::: exercise 浮动的升降舵 {level=2}
证明若$b_1 = 0$，则松杆中性点与握杆中性点重合；并从物理上解释为什么$b_2 \to 0$的过度补偿升降舵是危险的。
::: solution
$b_1 = 0$时因子$1 - \tau b_1/b_2 = 1$，故$h_n' = h_n$：尾翼迎角的变化不产生铰链力矩，因此$\alpha$变化时自由升降舵不动，自由尾翼的表现与固定尾翼一样。若$b_1 < 0$而$b_2 \to 0$，则$\tau b_1/b_2 \to +\infty$（两者均为负），因子变为很大的负数：$\alpha$增大时，浮动的升降舵后缘上偏得如此之多，以致尾翼**失去**升力——松杆中性点大幅前移，飞机在松手时变得不稳定，杆力接近于零甚至反向。过度补偿的操纵面曾导致事故，这就是适航规章要求稳定杆力梯度的原因。
:::
:::

::: exercise 确定水平尾翼尺寸 {level=3 check="2.55"}
为减轻尾翼重量和阻力，要重新设计轻型飞机，使其握杆中性点位于$h_n = 0.40$（而不是$0.433$），保持$l_t$、$a_t$、$\eta$和$\varepsilon_\alpha$不变。需要多大的尾翼面积？然后讨论在接受较小的尾翼之前你会检查哪些方面。（输入$S_t$，单位$\mathrm{m^2}$，保留两位小数。）
::: solution
令$s = S_t/S$。则$\bar V_H = (l_t/\bar c)s = 3.0612\,s$，$a = 4.8 + 0.90 \times 4.0 \times 0.5926\,s = 4.8 + 2.1333\,s$。条件$h_n - h_{ac} = 0.20$：
$$
\frac{0.90 \times 3.0612\,s \times 4.0 \times 0.5926}{4.8 + 2.1333\,s} = 0.20 \;\Longrightarrow\; 6.5306\,s = 0.96 + 0.42667\,s \;\Longrightarrow\; s = 0.15727,
$$
故$S_t = 0.15727 \times 16.2 = 2.55\ \mathrm{m^2}$，比现有的$3.0\ \mathrm{m^2}$小$15\,\%$。接受之前的检查：(i) 松杆中性点随之前移（到约$0.20 + 0.20 \times 0.775 = 0.355$），除非改变铰链力矩参数，否则可用的重心范围会缩小；(ii) 重心前限：升降舵操纵效能$C_{m\delta} \propto \bar V_H$下降$15\,\%$，因此必须重新检查带襟翼和在地面效应中以$C_{L,\max}$配平的能力，以及起飞抬前轮的能力——重心前限会后移；(iii) 两个限制之间的范围可能变得太小，不足以覆盖飞机必须承担的装载情况；(iv) 动稳定性（短周期阻尼，[[flight-mechanics/dynamic-modes]]）也取决于尾翼；(v) 尾旋改出和失速特性，它们取决于大迎角下的尾翼效能。实际上，尾翼尺寸是由所需尾翼面积随重心位置变化的“剪刀图”确定的，图中每个限制对应一条线。
:::
