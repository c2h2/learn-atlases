直线水平飞行的飞机关于其对称面是对称的，[[flight-mechanics/longitudinal-static-stability]]中的各力都作用在该平面内。来自侧面的突风、发动机失效、进近时的侧风或副翼偏转都会破坏这种对称性。此时飞机相对空气发生侧向滑移，出现三个新的量：侧力、绕竖轴的**偏航力矩**和绕纵轴的**滚转力矩**。本讲讨论关于它们的静态问题：飞机侧滑后是否会把机头转回相对气流方向（方向稳定性，或称“风标”稳定性）？侧滑是否会使飞机向远离侧滑的方向滚转（上反效应）？方向舵和副翼要多大，才能平衡发动机失效或侧风，或使飞机以有用的速率滚转？

滚转与偏航总是耦合在一起的——偏航改变两侧机翼的速度从而改变其升力，滚转使升力倾斜并使飞机侧滑——因此“横向”（滚转）稳定性和“航向”（偏航）稳定性要一起研究。它们的动态后果，即荷兰滚模态和螺旋模态，见[[flight-mechanics/dynamic-modes]]。

## 侧滑与横航向系数 {#sec-sideslip}

::: definition 侧滑角与横航向系数 {#def-sideslip}
取体轴系$x$向前、$y$指向右翼、$z$向下（坐标轴的完整定义见[[flight-mechanics/aircraft-equations-of-motion]]），设飞机相对空气的速度分量为$(u, v, w)$。**侧滑角**为
$$
\beta = \sin^{-1}\frac{v}{V} \approx \frac{v}{V},
$$
当相对气流来自右侧（飞机相对空气向其右方运动）时为正。侧力$Y$、滚转力矩$\mathcal{L}$（右翼下沉为正）和偏航力矩$N$（机头向右为正）以翼展$b$无量纲化：
$$
C_Y = \frac{Y}{qS},\qquad C_l = \frac{\mathcal{L}}{qSb},\qquad C_n = \frac{N}{qSb}.
$$
方向舵偏角$\delta_r$以后缘向左为正（产生机头向左的力矩）；副翼偏角$\delta_a$以产生正（右翼下沉）滚转力矩为正。
:::

对称飞行中的对称飞机有$C_Y = C_l = C_n = 0$，因此在一阶近似下，每个系数都是$\beta$、操纵面偏角和角速度的线性组合。对$\beta$的静导数是本讲的主题：
$$
C_{n\beta} = \frac{\partial C_n}{\partial\beta},\qquad C_{l\beta} = \frac{\partial C_l}{\partial\beta},\qquad C_{Y\beta} = \frac{\partial C_Y}{\partial\beta}.
$$

## 方向稳定性 {#sec-directional}

如果一阵突风使机头向左偏转，而飞机仍沿原航迹运动，则相对气流此时来自右侧：$\beta > 0$。方向稳定的飞机会产生机头向右的偏航力矩，像风向标一样转回迎风方向：

::: definition 方向（风标）稳定性 {#def-directional}
若
$$
C_{n\beta} > 0 ,
$$
则称飞机**方向稳定**。
:::

从侧面看，机身和发动机短舱的表现像一个细长体：机身前部的侧力作用在重心之前，给出**不稳定**的贡献$C_{n\beta,f} < 0$（对于轻型飞机通常为$-0.03$至$-0.10\ \mathrm{rad^{-1}}$）。机翼的贡献很小。稳定性由**垂直尾翼**提供。

**侧滑中垂直尾翼的受力图。** 面积为$S_v$、升力线斜率为$a_v$的垂直尾翼，其气动中心位于重心之后$l_v$处、滚转轴之上$z_v$处。侧滑时，垂尾处的气流被机身和机翼偏转（**侧洗**角$\sigma$，梯度为$\mathrm{d}\sigma/\mathrm{d}\beta$），那里的动压为$\eta_vq$。垂尾以迎角$\alpha_v = \beta(1 + \mathrm{d}\sigma/\mathrm{d}\beta)$迎向气流（在这一约定下侧洗叠加在侧滑上），并在其气动中心处产生向左的侧力$Y_v = -\eta_vqS_va_v\alpha_v$。

::: proposition 垂直尾翼对方向稳定性的贡献 {#prop-fin}
引入**垂尾容量**$V_v = l_vS_v/(Sb)$，垂直尾翼的贡献为
$$
C_{n\beta,v} = \eta_v\,V_v\,a_v\left(1 + \frac{\mathrm{d}\sigma}{\mathrm{d}\beta}\right),\qquad
C_{Y\beta,v} = -\eta_v\frac{S_v}{S}a_v\left(1 + \frac{\mathrm{d}\sigma}{\mathrm{d}\beta}\right),\qquad
C_{l\beta,v} = C_{Y\beta,v}\,\frac{z_v}{b},
$$ {#eq-fin}
效能为$\tau_r$的方向舵给出
$$
C_{n\delta r} = -\eta_v\,V_v\,a_v\,\tau_r,\qquad C_{Y\delta r} = \eta_v\frac{S_v}{S}a_v\tau_r,\qquad C_{l\delta r} = C_{Y\delta r}\,\frac{z_v}{b}.
$$ {#eq-rudder}
:::

::: proof
垂尾上的侧力为$Y_v = -\eta_vqS_va_v(1 + \mathrm{d}\sigma/\mathrm{d}\beta)\beta$，作用点相对重心为$(x, y, z) = (-l_v, 0, -z_v)$。力$(0, Y_v, 0)$在该点的力矩为$\mathbf{r}\times\mathbf{F} = (z_vY_v,\ 0,\ -l_vY_v)$。因此偏航力矩为$N = -l_vY_v = \eta_vqS_va_v(1 + \mathrm{d}\sigma/\mathrm{d}\beta)l_v\beta$，滚转力矩为$\mathcal{L} = z_vY_v$。除以$qSb$（侧力则除以$qS$）并对$\beta$求导，即得[[#eq-fin]]。后缘向左偏转$\delta_r$的方向舵使垂尾产生向**右**（$+y$）的升力$\eta_vqS_va_v\tau_r\delta_r$，按相同的力臂即得[[#eq-rudder]]。假设：垂尾气动力线性，$\beta$小，垂尾效能不受平尾位置的影响（实际上起端板作用的平尾会提高垂尾的有效展弦比，T 形尾翼尤其如此）。
:::

$C_{n\beta}$的典型总值为$0.05$–$0.15\ \mathrm{rad^{-1}}$（约每度$0.001$–$0.003$）。太小则飞机在偏航上游荡，容易出现荷兰滚；太大则会出现螺旋发散（见下文），并在湍流中令人不适。

::: example 轻型飞机的方向稳定性 {#ex-fin}
轻型飞机（$S = 16.2\ \mathrm{m^2}$，$b = 11.02\ \mathrm{m}$）的垂尾$S_v = 1.6\ \mathrm{m^2}$，$a_v = 3.0\ \mathrm{rad^{-1}}$，$l_v = 4.6\ \mathrm{m}$，$\eta_v = 0.95$，$\mathrm{d}\sigma/\mathrm{d}\beta = 0.10$；机身贡献$C_{n\beta,f} = -0.060\ \mathrm{rad^{-1}}$。求$C_{n\beta}$以及方向舵效能$\tau_r = 0.50$时的方向舵操纵效能$C_{n\delta r}$。在海平面以$50\ \mathrm{m/s}$飞行时，$5^\circ$侧滑产生多大的偏航力矩？
::: solution
$V_v = 4.6 \times 1.6/(16.2 \times 11.02) = 0.04122$。垂尾贡献：$C_{n\beta,v} = 0.95 \times 0.04122 \times 3.0 \times 1.10 = 0.1292\ \mathrm{rad^{-1}}$；总值$C_{n\beta} = 0.1292 - 0.060 = 0.0692\ \mathrm{rad^{-1}}$（每度$0.00121$）。方向舵：$C_{n\delta r} = -0.95 \times 0.04122 \times 3.0 \times 0.50 = -0.0587\ \mathrm{rad^{-1}}$。在$50\ \mathrm{m/s}$时，$q = 1531\ \mathrm{Pa}$，$qSb = 2.734\times10^{5}\ \mathrm{N\,m}$；对于$\beta = 5^\circ = 0.0873\ \mathrm{rad}$，$N = 0.0692 \times 0.0873 \times 2.734\times10^{5} = 1651\ \mathrm{N\,m}$，机头向右——转回迎风方向。合理性检查：垂尾提供的力矩约为机身不稳定力矩的两倍，这是典型的平衡；效能为垂尾一半的方向舵能保持的侧滑角为$\beta = -C_{n\delta r}\delta_r/C_{n\beta}$，即约$0.85\delta_r$。
:::
:::

## 滚转稳定性与上反效应 {#sec-dihedral}

不存在与滚转角成比例的力矩意义上的“滚转刚度”：在静止空气中倾斜的飞机，不会因倾斜本身而受到任何气动滚转力矩，因为相对于它的气流没有改变。倾斜的作用是使升力倾斜，于是飞机开始向较低的一侧机翼侧滑。**上反效应**就是由这一侧滑引起的滚转力矩。

::: definition 上反效应 {#def-dihedral-effect}
若侧滑产生的滚转力矩使飞机侧滑方向一侧的机翼抬起，即
$$
C_{l\beta} < 0 ,
$$
则称飞机具有**稳定的上反效应**。当$\beta > 0$（右翼下沉倾斜后向右侧滑）时，$C_l < 0$使飞机向左滚转，回到机翼水平。
:::

有几个因素对它有贡献。**几何上反角**$\Gamma$（机翼从翼根到翼尖向上倾斜$\Gamma$）：在侧滑$v$中，$v$垂直于右翼的分量为向上的$v\sin\Gamma$，使右翼迎角增大$\beta\Gamma$，而左翼迎角减小同样的量。**机翼后掠**：迎风一侧的机翼有效后掠角较小、升力较大——这一贡献与$C_L\tan\Lambda$成正比，因此在低速时增大。**机翼位置**：机身周围的横流在上单翼飞机上使迎风机翼的迎角增大（稳定），在下单翼飞机上使其减小（不稳定）。**垂直尾翼**：其侧力作用在滚转轴之上（[[#eq-fin]]中的$C_{l\beta,v}$），是稳定的。

::: proposition 几何上反角产生的滚转力矩 {#prop-dihedral}
对于翼展为$b$、梢根比为$\lambda = c_t/c_r$、剖面升力线斜率为$a$（每弧度）、上反角$\Gamma$很小的平直机翼，片条理论给出
$$
C_{l\beta,\Gamma} = -\frac{a\,\Gamma}{6}\,\frac{1 + 2\lambda}{1 + \lambda},
$$ {#eq-dihedral}
对于矩形机翼它等于$-a\Gamma/4$。
:::

::: proof
把每个半翼分成距中心线$y$处、宽为$\mathrm{d}y$的弦向片条。侧滑角为$\beta$时，右翼片条的迎角增大$\beta\Gamma$，左翼片条减小同样的量。每个片条的升力改变$\mathrm{d}L = \pm qac(y)\beta\Gamma\,\mathrm{d}y$，力臂为$y$；右翼增大的升力产生负的（左翼下沉）滚转力矩，左翼减小的升力也是如此。两半相加，
$$
\mathcal{L} = -2qa\beta\Gamma\int_0^{b/2}c(y)\,y\,\mathrm{d}y .
$$
对于线性梯形$c(y) = c_r[1 - (1 - \lambda)\,2y/b]$：
$$
\int_0^{b/2}c\,y\,\mathrm{d}y = c_r\left[\frac{b^2}{8} - (1 - \lambda)\frac{2}{b}\cdot\frac{b^3}{24}\right] = \frac{c_rb^2}{24}(1 + 2\lambda) .
$$
由$S = c_r(1 + \lambda)b/2$，$C_l = \mathcal{L}/(qSb) = -2a\beta\Gamma\,\dfrac{c_rb^2(1 + 2\lambda)/24}{c_r(1 + \lambda)b^2/2} = -\dfrac{a\beta\Gamma}{6}\dfrac{1 + 2\lambda}{1 + \lambda}$。假设：片条理论（每个片条只响应自身的当地迎角——它忽略了升力线理论中诱导速度的耦合，因此若$a$取二维斜率，会高估这一效应，许多教材改用三维斜率），小角度，无后掠机翼。
:::

只需要少量的上反效应：足以使飞机平缓地改平机翼，但又不能多到使荷兰滚阻尼变差，或使侧风着陆需要很大的副翼偏转。下单翼轻型飞机通常有$5^\circ$–$7^\circ$的几何上反角以克服翼身干扰效应；上单翼飞机为$1^\circ$–$3^\circ$；后掠翼运输机从后掠中获得了很大的上反效应，通常上反角很小，而许多上单翼后掠飞机采用**下反角**（负的$\Gamma$）。

## 滚转操纵 {#sec-roll-control}

两侧机翼上反向偏转的副翼使升力分布发生反对称变化。当飞机开始以角速度$p$滚转时，位于$y$处的每个片条都遇到附加的竖直速度$py$，它使片条迎角在**阻碍**滚转的方向上改变$py/V$：下行机翼迎角增大，上行机翼迎角减小。这就是**滚转阻尼**，它很快就与副翼力矩平衡，因此在一秒左右内就达到稳定滚转角速度。

::: proposition 用片条理论求滚转阻尼与副翼操纵效能 {#prop-roll}
对于平直梯形机翼，引入无量纲滚转角速度$\hat p = pb/(2V)$，
$$
C_{lp} = \frac{\partial C_l}{\partial\hat p} = -\frac{a}{12}\,\frac{1 + 3\lambda}{1 + \lambda},
\qquad
C_{l\delta a} = \frac{2a\tau_a}{Sb}\int_{y_1}^{y_2}c(y)\,y\,\mathrm{d}y ,
$$ {#eq-roll}
其中副翼位于展向站位$y_1$与$y_2$之间，效能为$\tau_a$（两侧机翼上分别偏转$\pm\delta_a$）。当力矩平衡时达到稳定滚转角速度：
$$
\frac{pb}{2V} = -\frac{C_{l\delta a}}{C_{lp}}\,\delta_a .
$$ {#eq-roll-rate}
:::

::: proof
**阻尼：** 右翼上$y$处以$py$向下运动的片条获得迎角$py/V$；升力的变化$qac\,(py/V)\,\mathrm{d}y$以力臂$y$作用并阻碍滚转，左翼的贡献相同。因此$\mathcal{L} = -2qa(p/V)\int_0^{b/2}cy^2\,\mathrm{d}y$。对于线性梯形，$\int_0^{b/2}cy^2\,\mathrm{d}y = c_r(b/2)^3(1 + 3\lambda)/12$，除以$qSb$和$\hat p = pb/(2V)$即得$C_{lp}$。**副翼：** 每个副翼片条的升力改变$qac\,\tau_a\delta_a\,\mathrm{d}y$，一侧机翼向上、另一侧向下，故$\mathcal{L} = 2qa\tau_a\delta_a\int_{y_1}^{y_2}cy\,\mathrm{d}y$。**稳定滚转：** $C_{l\delta a}\delta_a + C_{lp}\hat p = 0$。假设：片条理论，刚性机翼（副翼载荷下的机翼扭转会降低其效能，在高动压下甚至会使其反向——**副翼反效**），无侧滑。
:::

量$pb/(2V)$称为**螺旋角**（helix angle）：翼尖轨迹螺旋线的角度，以弧度计。1940年代吉尔鲁思（Gilruth）的 NACA 飞行品质准则要求满副翼时螺旋角约为$0.07$或以上；后来的规范（如 MIL-F-8785C）以更直接的方式表述这一要求，即对每类飞机和每个飞行阶段规定滚转通过给定角度所需的时间。由于$p = \hat p\cdot 2V/b$，满副翼时的滚转角速度随速度增大，直到受到杆力、副翼反效或滚转角速度限制器的限制。

::: example 轻型飞机的稳定滚转角速度 {#ex-roll}
轻型飞机的机翼（$b = 11.02\ \mathrm{m}$，$S = 16.2\ \mathrm{m^2}$，$\lambda = 0.70$，每个片条$a = 4.8\ \mathrm{rad^{-1}}$）的副翼位于半翼展的$60\,\%$至$95\,\%$之间，$\tau_a = 0.40$。求$C_{lp}$、$C_{l\delta a}$，以及在$30$和$50\ \mathrm{m/s}$时$\delta_a = 15^\circ$的稳定滚转角速度。
::: solution
翼根弦长和翼尖弦长：$c_r = 2S/[b(1 + \lambda)] = 32.4/(11.02 \times 1.7) = 1.729\ \mathrm{m}$，$c_t = 1.210\ \mathrm{m}$。滚转阻尼：$C_{lp} = -(4.8/12)(1 + 2.1)/1.7 = -0.729$。副翼积分，从$y_1 = 3.307\ \mathrm{m}$到$y_2 = 5.236\ \mathrm{m}$，$c(y) = 1.729(1 - 0.05444y)$：
$$
\int_{y_1}^{y_2}c\,y\,\mathrm{d}y = 1.729\left[\frac{y^2}{2} - 0.05444\frac{y^3}{3}\right]_{3.307}^{5.236} = 10.88\ \mathrm{m^3},
$$
故$C_{l\delta a} = 2 \times 4.8 \times 0.40 \times 10.88/(16.2 \times 11.02) = 0.234\ \mathrm{rad^{-1}}$。于是$\hat p = (0.234/0.729) \times 0.2618 = 0.0840$，$p = 0.0840 \times 2V/b$：在$30\ \mathrm{m/s}$时为$0.457\ \mathrm{rad/s} = 26.2^\circ/\mathrm{s}$，在$50\ \mathrm{m/s}$时为$43.6^\circ/\mathrm{s}$。合理性检查：$0.084$的螺旋角在上述范围内，而轻型飞机满副翼时的滚转角速度确实为$30^\circ$–$60^\circ/\mathrm{s}$。片条理论高估了两个力矩，但它们的比值——决定$\hat p$的正是这个比值——要准确得多。
:::
:::

**副翼反向偏航。** 下偏的副翼增大其所在机翼的升力从而增大诱导阻力，上偏的副翼则使之减小；结果是一个使机头偏**离**预期转弯方向的偏航力矩（$C_{l\delta a} > 0$时$C_{n\delta a} < 0$）。滚转本身还会增加这一效应，因为下行和上行机翼的升力矢量分别向前和向后倾斜（导数$C_{np}$，低速时为负）。飞行员用方向舵来补偿（“协调转弯”）；设计者用差动副翼或弗利兹副翼、扰流板（它在下行一侧减小升力并增加阻力，产生有利偏航）来减小它，在运输机上还使用自动偏航阻尼器（[[flight-mechanics/flight-control]]）。

## 不对称飞行：侧风与发动机失效 {#sec-asymmetric}

在定常不对称飞行中，三个方程必须同时平衡：
$$
C_{Y\beta}\beta + C_{Y\delta r}\delta_r + C_L\sin\phi = 0,\qquad
C_{l\beta}\beta + C_{l\delta a}\delta_a + C_{l\delta r}\delta_r = 0,\qquad
C_{n\beta}\beta + C_{n\delta a}\delta_a + C_{n\delta r}\delta_r + C_{n,T} = 0,
$$ {#eq-lateral-trim}
其中$\phi$是滚转角（升力分量$W\sin\phi \approx C_L\sin\phi\,qS$平衡任何侧力），$C_{n,T}$是不对称推力产生的偏航力矩。它们是配平方程[[flight-mechanics/longitudinal-static-stability#eq-trim]]在横向的对应形式。

::: example 带侧滑的侧风进近 {#ex-crosswind}
轻型飞机以$33\ \mathrm{m/s}$进近，侧风$6\ \mathrm{m/s}$来自右侧，采用压低一侧机翼的侧滑法使机身对准跑道。利用[[#ex-fin]]和[[#ex-roll]]中的导数、取$z_v = 0.90\ \mathrm{m}$的[[#eq-fin]]垂尾导数、上反角$\Gamma = 1.5^\circ$（片条理论，$\lambda = 0.7$）以及$+0.010\ \mathrm{rad^{-1}}$的下单翼贡献，求方向舵和副翼偏角（忽略$C_{n\delta a}$）。
::: solution
侧滑：相对气流来自右侧，$\beta = \sin^{-1}(6/33) = 10.48^\circ = 0.1829\ \mathrm{rad}$。上反效应：$C_{l\beta,\Gamma} = -(4.8 \times 0.02618/6)(2.4/1.7) = -0.0296$；垂尾，$C_{Y\beta,v} = -0.95 \times (1.6/16.2) \times 3.0 \times 1.10 = -0.3096$，$C_{l\beta,v} = -0.3096 \times 0.90/11.02 = -0.0253$；故$C_{l\beta} = -0.0296 - 0.0253 + 0.010 = -0.0448\ \mathrm{rad^{-1}}$。方向舵侧力和滚转：$C_{Y\delta r} = 0.95 \times 0.0988 \times 3.0 \times 0.5 = 0.1407$，$C_{l\delta r} = 0.1407 \times 0.90/11.02 = 0.01149$。

偏航平衡：$\delta_r = -C_{n\beta}\beta/C_{n\delta r} = -0.0692 \times 0.1829/(-0.0587) = 0.2155\ \mathrm{rad} = 12.3^\circ$（后缘向左，克服风标趋势使机头保持向左）。滚转平衡：
$$
\delta_a = -\frac{C_{l\beta}\beta + C_{l\delta r}\delta_r}{C_{l\delta a}} = -\frac{-0.00820 + 0.00248}{0.234} = 0.0245\ \mathrm{rad} = 1.4^\circ ,
$$
右翼下沉，即迎风一侧。侧力：$C_Y = -0.3096 \times 0.1829 + 0.1407 \times 0.2155 = -0.0263$；由$C_L = 2W/(\rho V^2S) = 0.998$，平衡它所需的滚转角为向迎风一侧$\sin^{-1}(0.0263/0.998) = 1.5^\circ$（实际上更大，因为机身也产生侧力）。合理性检查：方向舵是起限制作用的操纵面——$6\ \mathrm{m/s}$侧风就用去约一半行程——这就是轻型飞机的最大演示侧风约为$7$–$8\ \mathrm{m/s}$（$15\ \mathrm{kt}$）的原因。
:::
:::

**发动机失效。** 多发飞机的一台发动机失效时，工作发动机的推力和失效发动机（风车状态或顺桨）的阻力产生偏航力矩$N_T = (T + D_{\text{dead}})\,y_e$，其中$y_e$是发动机到中心线的横向距离。方向舵必须平衡它。由于方向舵力矩与$q$成正比，而$N_T$大致不变（对于螺旋桨飞机则随速度降低而增大），存在一个速度，低于它时满舵也不足以平衡：这就是**最小操纵速度**$V_{MC}$。对于不变的$N_T$和最大方向舵偏角$\delta_{r,\max}$，
$$
V_{MC} = \sqrt{\frac{2N_T}{\rho Sb\,\lvert C_{n\delta r}\rvert\,\delta_{r,\max}}} .
$$ {#eq-vmc}
审定规章允许在确定$V_{MC}$时向工作发动机一侧倾斜至多$5^\circ$（倾斜使升力偏转以抵消方向舵的侧力，从而减小侧滑和所需的方向舵偏角），并要求$V_{MC}$低于起飞安全速度。

::: example 轻型双发飞机的最小操纵速度 {#ex-vmc}
一架轻型双发飞机（$m = 2000\ \mathrm{kg}$，$S = 16.5\ \mathrm{m^2}$，$b = 11.6\ \mathrm{m}$，$C_{n\delta r} = -0.075\ \mathrm{rad^{-1}}$，$\delta_{r,\max} = 25^\circ$）的发动机距中心线$1.8\ \mathrm{m}$。起飞功率下每台发动机产生$2.5\ \mathrm{kN}$推力，风车状态的螺旋桨增加$0.3\ \mathrm{kN}$阻力。估算海平面的$V_{MC}$（机翼水平，零侧滑），并与$C_{L,\max} = 1.7$时的失速速度比较。
::: solution
$N_T = (2500 + 300) \times 1.8 = 5040\ \mathrm{N\,m}$。由$\delta_{r,\max} = 0.4363\ \mathrm{rad}$：
$$
V_{MC} = \sqrt{\frac{2 \times 5040}{1.225 \times 16.5 \times 11.6 \times 0.075 \times 0.4363}} = \sqrt{1313.7} = 36.2\ \mathrm{m/s}.
$$
失速速度为$\sqrt{2 \times 19\,613/(1.225 \times 16.5 \times 1.7)} = 33.8\ \mathrm{m/s}$，所以$V_{MC}$为$1.07V_s$。合理性检查：$V_{MC}$接近失速速度是轻型双发飞机的典型情况，这也是长期以来飞行训练强调发动机失效后要保持在“红线”$V_{MC}$速度以上的原因；低于它时，无论飞行员如何操纵，飞机都会向失效发动机一侧偏航和滚转。把失效螺旋桨顺桨可消除$D_{\text{dead}}$的大部分，使$V_{MC}$降低约$\sqrt{2500/2800}$倍，即$5\,\%$。
:::

::: warning 横航向导数的符号
不同书籍和公司的约定各不相同，符号错误会使导数的含义完全相反。在本课程中：风来自右侧时$\beta > 0$；$C_{n\beta} > 0$表示方向稳定；$C_{l\beta} < 0$表示稳定的上反效应；$\delta_r > 0$为后缘向左，给出$C_{n\delta r} < 0$；$\delta_a > 0$给出$C_{l\delta a} > 0$。一个常见错误是以为$C_{l\beta}$像$C_{m\alpha}$一样度量针对**滚转角**的恢复力矩：并非如此——这样的力矩并不存在——它度量的是由倾斜引起的**侧滑**所产生的滚转力矩。另一个错误是从机翼气动中心量取垂尾的力臂：对于$C_{n\beta}$，力臂是从重心量起的，而重心随装载而变。
:::

::: quiz
对于常规布局飞机，下列哪一项改变会增大稳定的上反效应（使$C_{l\beta}$更负）？
- [ ] 把机翼从上单翼位置改为下单翼位置
- [x] 在给定升力系数下增大机翼后掠角
- [ ] 减小几何上反角
- [ ] 把垂尾装在机身下方（腹鳍）而不是上方
::: solution
后掠产生与$C_L\tan\Lambda$成正比的上反效应。下单翼是不稳定的，减小上反角会减弱这一效应，而位于滚转轴之下的垂尾所产生的滚转力矩与位于其上的垂尾符号相反。
:::
:::

::: history
凯利（Cayley）1810年发表的《论空中航行》中的一部分论证了向上倾斜安装的机翼能提供滚转稳定性——这是对上反效应的最早表述——他本人及后来的模型滑翔机都利用了这一点。与大多数同时代人不同，莱特兄弟（Wright brothers）并不追求固有的横向稳定性；从1899年的风筝开始，他们就用**机翼翘曲**来操纵滚转。在1902年的滑翔机上，他们发现翘曲会产生反向偏航，可能把飞机拖入带侧滑的螺旋下降，于是他们把固定的垂直尾翼改为可动的，并使之与翘曲联动——这种滚转与偏航的组合操纵是此后每一架飞机的基础。作为独立铰接操纵面的副翼此后不久便得到普遍采用；本讲所用的滚转阻尼和副翼操纵效能的片条理论估算，从布赖恩（Bryan）的《航空中的稳定性》（*Stability in Aviation*，1911）起就出现在稳定性文献中。
:::

::: summary
- 侧滑$\beta \approx v/V$；系数$C_Y$、$C_l$、$C_n$以$qS$和$qSb$为参考。
- 方向稳定性$C_{n\beta} > 0$；机身是不稳定的，垂尾提供$\eta_vV_va_v(1 + \mathrm{d}\sigma/\mathrm{d}\beta)$，$V_v = l_vS_v/(Sb)$。
- 上反效应$C_{l\beta} < 0$来自几何上反角（片条理论为$-a\Gamma(1 + 2\lambda)/[6(1 + \lambda)]$）、后掠、上单翼和垂尾；下单翼是不稳定的。
- 滚转阻尼$C_{lp} = -(a/12)(1 + 3\lambda)/(1 + \lambda)$；稳定螺旋角$pb/2V = -C_{l\delta a}\delta_a/C_{lp}$。
- 副翼引起反向偏航；协调转弯需要方向舵。
- 定常不对称飞行要同时平衡侧力、滚转和偏航：侧风侧滑和单发失效配平；$V_{MC} \propto \sqrt{N_T/(\lvert C_{n\delta r}\rvert\delta_{r,\max})}$。
:::

## 习题

::: exercise 垂尾容量 {level=1 check="0.0412"}
求轻型飞机（$S_v = 1.6\ \mathrm{m^2}$，$l_v = 4.6\ \mathrm{m}$，$S = 16.2\ \mathrm{m^2}$，$b = 11.02\ \mathrm{m}$）的垂尾容量。（输入$V_v$，保留三位有效数字。）
::: solution
$V_v = 4.6 \times 1.6/(16.2 \times 11.02) = 7.36/178.5 = 0.0412$。典型值：轻型飞机为$0.02$–$0.05$，运输机为$0.06$–$0.09$（其发动机更靠外侧）。
:::
:::

::: exercise 矩形机翼的上反效应 {level=1 check="-0.0436"}
一副$a = 5.0\ \mathrm{rad^{-1}}$的矩形机翼（$\lambda = 1$）有$2^\circ$上反角。用片条理论求上反角引起的$C_{l\beta}$。（单位$\mathrm{rad^{-1}}$，保留三位有效数字。）
::: solution
$C_{l\beta} = -a\Gamma/4 = -5.0 \times 0.034907/4 = -0.0436\ \mathrm{rad^{-1}}$。
:::
:::

::: exercise 滚转阻尼 {level=1 check="-0.694"}
用片条理论求$a = 5.0\ \mathrm{rad^{-1}}$、梢根比$\lambda = 0.5$的机翼的$C_{lp}$。（保留三位有效数字。）
::: solution
$1 + 3\lambda = 2.5$，$1 + \lambda = 1.5$，故$C_{lp} = -(5.0/12) \times 2.5/1.5 = -0.41667 \times 1.6667 = -0.694$。同样斜率的矩形机翼为$-5.0/6 = -0.833$：梯形使面积向内侧移动，而那里由滚转引起的迎角较小。
:::
:::

::: exercise 满足稳定性目标的垂尾面积 {level=2 check="1.98"}
对于[[#ex-fin]]中的轻型飞机，其他量不变，多大的垂尾面积能使$C_{n\beta} = 0.10\ \mathrm{rad^{-1}}$？（输入$S_v$，单位$\mathrm{m^2}$，保留两位小数。）
::: solution
需要$C_{n\beta,v} = 0.10 + 0.060 = 0.160$。由于$C_{n\beta,v} \propto S_v$：$S_v = 1.6 \times 0.160/0.1292 = 1.98\ \mathrm{m^2}$，大$24\,\%$；若方向舵随垂尾按比例放大，方向舵操纵效能也按比例提高。
:::
:::

::: exercise 较高速度下的滚转角速度 {level=2 check="61.1"}
利用[[#ex-roll]]中满副翼时的螺旋角$pb/2V = 0.0840$，求$70\ \mathrm{m/s}$时的滚转角速度。（输入$p$，单位为度每秒，保留一位小数。）
::: solution
$p = 0.0840 \times 2 \times 70/11.02 = 1.0671\ \mathrm{rad/s} = 61.1^\circ/\mathrm{s}$——前提是飞行员仍能克服随$q$增大的杆力而施加满副翼。
:::
:::

::: exercise 螺旋桨顺桨时的最小操纵速度 {level=2 check="34.2"}
把失效螺旋桨顺桨，使其阻力可以忽略，重做[[#ex-vmc]]。（输入$V_{MC}$，单位 m/s，保留一位小数。）
::: solution
$N_T = 2500 \times 1.8 = 4500\ \mathrm{N\,m}$；$V_{MC} = 36.25\sqrt{4500/5040} = 34.25\ \mathrm{m/s}$，即$34.2\ \mathrm{m/s}$——此时仅略高于$33.8\ \mathrm{m/s}$的失速速度。
:::
:::

::: exercise 椭圆机翼上反效应的片条理论推导 {level=3}
对平面形状为椭圆的机翼$c(y) = c_0\sqrt{1 - (2y/b)^2}$重复[[#prop-dihedral]]的推导：求$C_{l\beta,\Gamma} = -k\,a\Gamma$中的常数$k$，并与矩形机翼（$k = 0.25$）和$\lambda = 0.5$梯形机翼的值比较。
::: solution
$\int_0^{b/2}c\,y\,\mathrm{d}y = c_0\int_0^{b/2}y\sqrt{1 - 4y^2/b^2}\,\mathrm{d}y$。令$u = 1 - 4y^2/b^2$，$\mathrm{d}u = -8y\,\mathrm{d}y/b^2$：积分为$c_0(b^2/8)\int_0^1\sqrt u\,\mathrm{d}u = c_0b^2/12$。面积为$S = \pi c_0b/4$。于是$C_{l\beta} = -2a\Gamma\,(c_0b^2/12)/(\pi c_0b^2/4) = -\dfrac{2a\Gamma}{3\pi}$，故$k = 2/(3\pi) = 0.212$。矩形：$0.25$；梯形$0.5$：$(1 + 1)/(6 \times 1.5) = 0.222$。弦长越集中于内侧，附加升力的力臂越小，每度上反角产生的上反效应越弱——这是梯形机翼需要稍大上反角的原因之一。
:::
:::

::: exercise 为双发飞机选择垂尾 {level=3}
设计者必须确定[[#ex-vmc]]中轻型双发飞机的垂尾和方向舵尺寸，使临界螺旋桨处于风车状态时$V_{MC} \le 1.05$倍失速速度，同时保持$C_{n\beta}$在$0.06$与$0.15\ \mathrm{rad^{-1}}$之间。现有设计的$C_{n\delta r} = -0.075\ \mathrm{rad^{-1}}$。求所需的方向舵操纵效能，并讨论如何获得它以及还有哪些方面会随之改变。
::: solution
$1.05V_s = 1.05 \times 33.79 = 35.48\ \mathrm{m/s}$。由[[#eq-vmc]]，$\lvert C_{n\delta r}\rvert \propto 1/V_{MC}^2$：$0.075 \times (36.25/35.48)^2 = 0.0783\ \mathrm{rad^{-1}}$，增加$4.4\,\%$。可选措施：加大方向舵弦长或展长（提高$\tau_r$或方向舵在$S_v$中的份额），加大垂尾（同时提高$C_{n\beta}$——检查上限和螺旋模态），加长尾力臂（机身更重），增大方向舵行程（受大偏角时方向舵上气流分离的限制），或减小$N_T$：使发动机更靠近中心线（受螺旋桨间隙限制），采用对转螺旋桨（消除由 P 因子引起的“临界发动机”不对称性），自动顺桨。好的回答还会检查$V_{MC}$时的脚蹬力（规章规定了最大值）、更大的垂尾对荷兰滚阻尼和侧风操纵的影响，并指出实际的$V_{MC}$是在飞行试验中以至多$5^\circ$的倾斜、在最不利的重心位置（靠后，方向舵力臂最短）下确定的。
:::
