上一讲以一个诊断结束：仅靠机体本身飞行的喷气运输机，其荷兰滚要四个周期才能使振幅减半，长周期处于临界，而短周期也只是勉强合格。一百年前，治疗的办法会是更大的垂尾或不同的尾翼。今天的办法是反馈：传感器测量运动，计算机算出操纵面指令，作动器驱动操纵面——连续不断，而且比飞行员快得多。本讲介绍飞机飞行控制的主要思想：**增稳**（改变模态的阻尼器）、**自动驾驶仪**（保持姿态、高度或航向的外回路），以及**电传操纵**控制律——在电传操纵中，飞行员的驾驶杆指令的是一种运动而不是操纵面偏角，机体甚至可以在没有计算机时是不稳定的。

所用的工具是[[control-systems/transfer-functions]]、[[control-systems/root-locus]]、[[control-systems/pid-control]]和[[control-systems/state-space]]中的工具；被控对象模型是[[flight-mechanics/aircraft-equations-of-motion]]中的线性状态空间模型，目标是[[flight-mechanics/dynamic-modes]]中的飞行品质要求。与每一个安全关键系统一样，实际的飞行控制系统要按照适航规章以及软件和硬件保证标准来设计、验证和审定；本讲讲授的是它们背后的原理。

## 飞行控制系统 {#sec-fcs}

在采用**机械（可逆）操纵**的飞机上，钢索和拉杆把驾驶杆和脚蹬直接连到操纵面上，飞行员能感受到气动铰链力矩（[[flight-mechanics/longitudinal-static-stability#sec-stick-free]]）。随着飞机变得更大、更快，这些力变得过大，于是引入了**助力操纵**——由飞行员的连杆驱动的液压作动器；由于它是不可逆的，需要一套**人感**系统（弹簧，或按动压调参的人感装置），给飞行员提供其所期望的杆力。一旦操纵面由作动器驱动，其指令就可以用电信号加以修改：**增稳系统**（SAS）在飞行员的输入上叠加来自角速度陀螺的、权限有限的小指令。**电传操纵**（FBW）则走到底：驾驶杆是一个电传感器，计算机计算每一个操纵面指令，机械连接被完全取消。

::: definition 飞机的反馈控制 {#def-fcs}
**飞行控制律**由飞行员指令$\mathbf u_p$和测得的状态$\mathbf y = \mathbf C\mathbf x$计算操纵面指令$\mathbf u$。把常增益线性控制律$\mathbf u = \mathbf u_p + \mathbf K\mathbf y$作用于被控对象$\dot{\mathbf x} = \mathbf A\mathbf x + \mathbf B\mathbf u$，得到闭环系统
$$
\dot{\mathbf x} = (\mathbf A + \mathbf B\mathbf K\mathbf C)\,\mathbf x + \mathbf B\,\mathbf u_p ,
$$ {#eq-closed-loop}
其特征值——**增稳后的模态**——随$\mathbf K$的选择而移动。**阻尼器**反馈角速度；**增稳**回路反馈角度（迎角、侧滑角）；**自动驾驶仪**在姿态、高度、航向或速度上闭合外回路。
:::

传感器有角速度陀螺（如今通常是激光陀螺或光纤陀螺，常装在惯性基准组件内）、加速度计、迎角和侧滑角传感器，以及测量动压、空速和高度的大气数据探头。由于所有稳定性导数都与动压成比例，增益要随飞行状态**调参**（scheduled）——通常随动压和马赫数——这样就不会要求一组增益从进近到巡航都适用。

## 俯仰阻尼器 {#sec-pitch-damper}

短周期阻尼由$M_q + M_{\dot\alpha}$决定（[[flight-mechanics/dynamic-modes#prop-short-period]]）。俯仰角速度陀螺和升降舵可以增大它：指令为
$$
\Delta\delta_e = K_q\,\Delta q + \Delta\delta_{e,\text{pilot}},
$$ {#eq-pitch-damper}
其中$K_q > 0$（抬头角速度指令升降舵后缘下偏，由于$M_{\delta e} < 0$，这产生低头力矩）。

::: proposition 带俯仰角速度反馈的短周期 {#prop-pitch-damper}
在短周期近似中，忽略升降舵的直接升力（$Z_{\delta e}$），俯仰阻尼器[[#eq-pitch-damper]]把$M_q$替换为$M_q + M'_{\delta e}K_q$，其中$M'_{\delta e} = M_{\delta e} + M_{\dot w}Z_{\delta e}$。闭环短周期特性为
$$
\omega_{sp}^2 = \frac{Z_\alpha(M_q + M'_{\delta e}K_q)}{u_0} - M_\alpha,\qquad
2\zeta_{sp}\omega_{sp} = -\left(M_q + M'_{\delta e}K_q + M_{\dot\alpha} + \frac{Z_\alpha}{u_0}\right).
$$ {#eq-sp-damper}
角速度反馈既增大阻尼比，也（略微）提高频率。
:::

::: proof
把$\Delta\delta_e = K_q\Delta q$代入短周期模型的俯仰方程$\Delta\dot q = (M_\alpha + M_{\dot\alpha}Z_\alpha/u_0)\Delta\alpha + (M_q + M_{\dot\alpha})\Delta q + M'_{\delta e}\Delta\delta_e$（升降舵对$\mathbf B_{\text{long}}$第三行的输入，[[flight-mechanics/aircraft-equations-of-motion#eq-a-long]]）。$\Delta q$的系数变为$M_q + M_{\dot\alpha} + M'_{\delta e}K_q$；这与把$M_q$替换为$M_q + M'_{\delta e}K_q$相同。于是由[[flight-mechanics/dynamic-modes#eq-sp]]即得上述公式。由于$M'_{\delta e} < 0$且$Z_\alpha < 0$，正的$K_q$使阻尼项增大，也使$\omega_{sp}^2$增大。假设：短周期近似的假设；理想（瞬时响应）的传感器和作动器；忽略$Z_{\delta e}$（它会略微改变$\Delta\dot\alpha$方程）。
:::

::: example 喷气运输机的俯仰阻尼器 {#ex-pitch-damper}
选择$K_q$，使喷气运输机巡航时的短周期阻尼比为$0.70$，并在包含$Z_{\delta e}$的完整四阶模型上校核结果。
::: solution
由[[flight-mechanics/aircraft-equations-of-motion#ex-long-derivs]]：$Z_\alpha/u_0 = -0.4059$，$M_\alpha = -0.7564$，$M_{\dot\alpha} = -0.0751$，$M_q = -0.2253\ \mathrm{s^{-1}}$，$M'_{\delta e} = -1.650 + (-3.26\times10^{-4})(-5.908) = -1.648\ \mathrm{s^{-2}}$。记$M_{qe} = -0.2253 - 1.648K_q$。于是
$$
\omega^2 = 0.4059\,(0.2253 + 1.648K_q) + 0.7564,\qquad 2\zeta\omega = 0.2253 + 1.648K_q + 0.0751 + 0.4059 .
$$
令$\zeta = 0.70$并求解（这是一个单变量方程，可试算或用求根程序）得$K_q = 0.493\ \mathrm{rad\ per\ rad/s}$（每度每秒俯仰角速度约对应$0.5^\circ$升降舵），$\omega_{sp} = 1.085\ \mathrm{rad/s}$。在二状态模型中计入$Z_{\delta e}$得$K_q = 0.488$；采用这一增益时，完整四阶闭环特征值为$-0.756 \pm 0.771\mathrm{i}$（$\omega_n = 1.080$，$\zeta = 0.700$）和$-0.00196 \pm 0.0485\mathrm{i}$（长周期，$\zeta = 0.040$）。合理性检查：阻尼器使短周期阻尼大约翻了一番，作为副产品，还把长周期阻尼从$0.028$提高到$0.040$——恰好达到 1 级。每$^\circ/\mathrm{s}$对应$0.5^\circ$的升降舵偏转是适度的权限；实际的阻尼器被限制在几度以内，使得一次故障不会造成大的扰动。
:::
:::

## 偏航阻尼器 {#sec-yaw-damper}

后掠翼喷气式飞机的荷兰滚阻尼非常小，因此偏航阻尼器必不可少；后掠翼喷气运输机从1950年代的第一代起就装有偏航阻尼器。最直接的控制律是把偏航角速度反馈到方向舵，$\Delta\delta_r = K_r\,\Delta r$，$K_r > 0$（机头向右的角速度指令方向舵后缘向左，产生机头向左的力矩）。在粗略的荷兰滚近似中，这只是给$N_r$加上了$N_{\delta r}K_r$。

这里有一个问题。在定常转弯中偏航角速度并不为零——它等于$r = \dot\psi\cos\phi$（[[flight-mechanics/aircraft-equations-of-motion#ex-turn-rates]]）——因此单纯的偏航阻尼器会在每次转弯时都施加**反对**转弯的方向舵，飞行员必须克服它。解决办法是**洗出滤波器**（washout filter），这是一种高通滤波器，它让荷兰滚的振荡偏航角速度通过，而阻断转弯中的稳态偏航角速度：
$$
\Delta\delta_r(s) = K_r\,\frac{\tau_ws}{\tau_ws + 1}\,\Delta r(s),
$$ {#eq-washout}
时间常数$\tau_w$为几秒：它要足够长，使荷兰滚振荡（周期约$6\ \mathrm{s}$）几乎不变地通过；又要足够短，使转弯的稳态偏航角速度在几秒钟内被洗出。在状态空间形式中，滤波器增加一个状态$x_w$，$\dot x_w = (r - x_w)/\tau_w$，指令为$K_r(r - x_w)$。

::: example 喷气运输机的偏航阻尼器 {#ex-yaw-damper}
对于喷气运输机的横向模型（[[flight-mechanics/aircraft-equations-of-motion#ex-lat-derivs]]，每弧度方向舵偏角对应$Y_{\delta r} = 2.532\ \mathrm{m\,s^{-2}}$，$L_{\delta r} = 0.288\ \mathrm{s^{-2}}$，$N_{\delta r} = -0.672\ \mathrm{s^{-2}}$），求$K_r = 1.0$的单纯偏航阻尼器和$K_r = 1.2$、$\tau_w = 3\ \mathrm{s}$的带洗出偏航阻尼器的闭环模态。在巡航中做$25^\circ$坡度的定常转弯时，二者各施加多大的方向舵？
::: solution
**单纯阻尼器**，$K_r = 1.0$：闭环矩阵$\mathbf A_{\text{lat}} + \mathbf b_{\delta r}K_r\mathbf e_r^{\mathsf T}$的特征值为$-0.327 \pm 0.953\mathrm{i}$（荷兰滚$\omega_n = 1.008$，$\zeta = 0.32$）、$-1.059$（滚转）和$-0.092$（螺旋）。螺旋根从$-0.0034$移到了$-0.092$：阻尼器在抵抗螺旋模态的缓慢偏航——以及任何转弯。

**带洗出的阻尼器**，$K_r = 1.2$，$\tau_w = 3\ \mathrm{s}$（五个状态）：荷兰滚$\omega_n = 0.85$，$\zeta = 0.32$；螺旋根保持在$-0.0027$附近，接近机体本身的值，其余的根是滚转模态（$-1.02$）以及与滤波器相关的一个实根$-0.70$。

$25^\circ$坡度的**定常转弯**：$\dot\psi = g\tan\phi/u_0 = 9.807 \times 0.4663/230.15 = 0.01987\ \mathrm{rad/s}$，$r = \dot\psi\cos\phi = 0.0180\ \mathrm{rad/s}$。单纯阻尼器持续指令$\delta_r = 1.0 \times 0.0180 = 0.018\ \mathrm{rad} = 1.0^\circ$反对转弯；带洗出的阻尼器在转弯建立后（经过几个$\tau_w$）指令为零。合理性检查：荷兰滚阻尼从$0.027$提高到$0.32$，稳妥地高于 1 级最低要求$0.08$，且$\zeta\omega = 0.27\ \mathrm{rad/s} > 0.15$；在给定增益下洗出会损失一点阻尼，这就是把增益从$1.0$提高到$1.2$的原因。
:::

## 增稳：放宽静稳定性 {#sec-relaxed}

按照充足的静稳定裕度确定尺寸的尾翼，比只按操纵要求确定尺寸的尾翼更大、更重，而且巡航中它的向下载荷会带来配平阻力。如果由计算机提供俯仰刚度，飞机就可以以很小甚至为负的静稳定裕度飞行——即**放宽静稳定性**（relaxed static stability，RSS）。反馈迎角，
$$
\Delta\delta_e = K_\alpha\,\Delta\alpha ,
$$
就给$M_\alpha$加上了$M'_{\delta e}K_\alpha$：一个人工静稳定裕度。

::: example 使不稳定的飞机稳定 {#ex-rss}
假设把喷气运输机的重心后移，直到$C_{m\alpha} = +0.10\ \mathrm{rad^{-1}}$（静稳定裕度为$-1.8\,\%$），于是$M_\alpha = +0.1375\ \mathrm{s^{-2}}$。求开环模态，以及恢复原来的$M_\alpha = -0.7564\ \mathrm{s^{-2}}$所需的迎角反馈增益。
::: solution
开环时，完整纵向模型的特征值为$-0.766$、$+0.102$和$-0.0238 \pm 0.0761\mathrm{i}\ \mathrm{s^{-1}}$：短周期振荡分裂成了两个实根，其中一个不稳定，倍幅时间为$\ln 2/0.102 = 6.8\ \mathrm{s}$——飞行员或许能暂时控制住这种俯仰发散，但无法精确地驾驶。增益：$K_\alpha = (-0.7564 - 0.1375)/(-1.648) = 0.542$（每弧度迎角对应的升降舵弧度）。取$\Delta\delta_e = 0.542\,\Delta w/u_0$，闭环特征值为$-0.361 \pm 0.850\mathrm{i}$和$-0.00155 \pm 0.0568\mathrm{i}$——几乎与原飞机完全相同。再加上俯仰阻尼器（$K_q = 0.488$）得$-0.763 \pm 0.774\mathrm{i}$，又是一个阻尼良好的短周期。合理性检查：反馈只是补回了因重心移动而失去的气动刚度。问题在于飞机现在**依赖**于这个回路：传感器或计算机故障会留下一架不稳定的飞机，这就是这类系统要采用多个余度通道的原因。
:::
:::

F-16 是第一种按放宽静稳定性（在亚声速时）设计、并以全权限电传操纵系统来提供稳定性的生产型飞机；RSS 在作战飞机中用于提高敏捷性，在运输机中则以温和的形式与燃油转输重心控制配合，用来减小配平阻力。

::: algorithm 设计增稳回路 {#alg-sas}
1. **建模。** 在设计飞行状态下对飞机线化（[[flight-mechanics/aircraft-equations-of-motion#eq-a-long]]或[[flight-mechanics/aircraft-equations-of-motion#eq-a-lat]]），并把作动器、传感器和滤波器的动态作为附加状态加入。
2. **目标。** 根据飞行品质要求，为需要改变的模态选择目标频率和阻尼比，并为不得受损的模态设定限制。
3. **选择回路。** 选择对不合格模态作用最直接的反馈（俯仰角速度到升降舵用于短周期阻尼，偏航角速度经洗出到方向舵用于荷兰滚阻尼，迎角到升降舵用于刚度），并用近似模态公式看清回路增强的是哪个导数。
4. **增益。** 改变增益，计算$\mathbf A + \mathbf B\mathbf K\mathbf C$的闭环特征值（根轨迹）；选择以最小权限满足目标的增益。
5. **鲁棒性。** 计入作动器和传感器滞后以及采样延迟，检查幅值裕度和相角裕度，并在质量、重心和飞行状态的变化范围内检查特征值；必要时按动压对增益调参。
6. **限幅与故障。** 设定权限限制，使作动器失控或传感器故障不会造成无法改出的异常姿态；检查回路饱和或断开时的响应。
7. 在非线性有人驾驶仿真中**验证**，最后进行飞行试验。
:::

## 自动驾驶仪 {#sec-autopilot}

自动驾驶仪通过在增稳后的飞机周围闭合外回路来保持某一飞行状态。在俯仰通道中，通常的结构是串级的：内层是俯仰角速度回路（阻尼器），其外是俯仰姿态回路，再外是高度或航迹回路，而速度由**自动油门**控制。在滚转和偏航通道中：偏航阻尼器，通过副翼的滚转角回路，以及指令滚转角的航向回路。

::: example 俯仰姿态保持 {#ex-attitude-hold}
在[[#ex-pitch-damper]]的俯仰阻尼器接通的情况下，加上比例姿态回路$\Delta\delta_e = K_q\Delta q + K_\theta(\Delta\theta - \theta_c)$，$K_\theta = 1.0$（rad/rad），油门固定。求闭环极点以及对指令姿态$\theta_c$的$1^\circ$阶跃的稳态响应。
::: solution
闭环矩阵$\mathbf A_{\text{long}} + \mathbf B_{\text{long}}[0,\ 0,\ K_q,\ K_\theta]$的特征值为$-0.625 \pm 1.448\mathrm{i}$（$\omega_n = 1.58\ \mathrm{rad/s}$，$\zeta = 0.40$）、$-0.252$和$-0.0148\ \mathrm{s^{-1}}$。长周期振荡消失了——姿态不再能自由地与速度相互交换——取而代之的是一个缓慢的实根（时间常数$68\ \mathrm{s}$）。稳态时，由$\mathbf 0 = \mathbf A_{cl}\mathbf x_{ss} - \mathbf B K_\theta\theta_c$：$\Delta\theta_{ss} = 0.703^\circ$，$\Delta u_{ss} = -12.1\ \mathrm{m/s}$，$\Delta\alpha_{ss} = 0.65^\circ$。仿真表明，姿态在$10\ \mathrm{s}$后达到$0.96^\circ$，然后随着飞机减速，在几分钟内逐渐下降到$0.70^\circ$。合理性检查：推力固定时，稳定的抬头姿态只能在较低的速度下保持（爬升消耗动能，然后稳定在阻力平衡所允许的速度上），而比例回路不能消除稳态误差。实际的自动驾驶仪对姿态误差加入积分作用，并用自动油门保持速度——两者结合使姿态保持与速度保持相互独立。
:::
:::

**高度保持**在姿态保持外面再包一个回路：$\theta_c = K_h(h_c - h) + \dots$，其中$\dot h = u_0\Delta\theta - \Delta w$（加上积分作用）。**航向保持**按航向误差成比例地指令滚转角，因为在协调转弯中$\dot\psi = g\tan\phi/u_0$。在每种情况下，内回路都必须比外回路快好几倍，使外回路看到的是一个“已经稳定下来”的内回路——这与机器串级控制中的带宽分离是同一原理（[[control-systems/pid-control]]）。

::: warning 滞后、限幅与增益的符号
给设计飞行控制回路的人三条警告。(i) **符号**：按本课程的约定，$M_{\delta e} < 0$且$N_{\delta r} < 0$，因此起稳定作用的角速度反馈从角速度到偏角的增益是**正**的；一个符号错误就会把阻尼器变成失稳器，而在整个链路（传感器、计算机、作动器、操纵面）中逐一检查每个符号是地面试验的标准内容。(ii) **滞后**：作动器（带宽约$10$–$30\ \mathrm{rad/s}$）、传感器滤波器、计算和采样（[[control-systems/digital-control]]）都会增加相位滞后；在理想元件下合适的增益可能引起振荡，飞行员输入与响应之间即使只有$0.1$–$0.2\ \mathrm{s}$的时间延迟，也会使操纵品质变差，并可能诱发**驾驶员诱发振荡**（PIO）。(iii) **饱和**：操纵面的行程和速率都是有限的；按线性方法设计的回路在作动器达到其速率限制时可能失去控制，好几起电传操纵飞行试验事件就是如此。
:::

## 电传操纵控制律 {#sec-fbw}

在对操纵面拥有全权限的情况下，控制律不必使升降舵与驾驶杆成比例地偏转。现代电传操纵控制律让驾驶杆指令的是一种**响应**：

- 在俯仰通道，驾驶杆指令**俯仰角速度与法向过载**的混合——低速时飞行员感受到的是俯仰角速度指令，高速时是过载（“g”）指令。$C^\ast$（法向加速度与俯仰角速度的加权和）之类的准则被用来塑造响应。松开驾驶杆即保持航迹：配平是自动的。
- 在滚转通道，驾驶杆指令**滚转角速度**；松开它即保持滚转角。
- **包线保护**限制迎角（使飞机在正常运行中不会因驾驶杆输入而失速）、过载（在[[flight-mechanics/manoeuvres-takeoff-landing#def-vn]]的结构限制以内）、滚转角和速度。
- **转弯协调与偏航阻尼**是自动的。

控制律就是一组像上面那样的反馈回路，其增益在整个飞行包线上调参，有消除稳态误差的积分器、塑造响应的指令滤波器，以及在传感器或计算机故障时用于降级模式的逻辑。

**余度与完整性。** 由于飞机离开控制系统就无法飞行，电传操纵架构采用多台独立的计算机（通常为三个或四个通道，往往采用由不同团队开发的**非相似**硬件和软件，以避免共模错误）、带表决和监控的多重传感器、独立的电源和液压源，以及随故障累积而逐步取消保护功能的**降级控制律**（按空客的术语，从“正常”到“备用”再到“直接”）。软件和机载电子硬件的审定标准（如 RTCA DO-178C 和 DO-254）要求提供证据，证明每一级故障的概率都足够低——对于运输类飞机的灾难性故障状态，通常为每飞行小时$10^{-9}$量级。

::: quiz
为什么运输机的偏航阻尼器要包含一个洗出（高通）滤波器？
- [ ] 为了滤除高频的传感器噪声
- [x] 使阻尼器不反对协调转弯中的稳态偏航角速度，同时仍能阻尼荷兰滚振荡
- [ ] 为了提高荷兰滚固有频率
- [ ] 为了使螺旋模态稳定
::: solution
在定常转弯中$r = \dot\psi\cos\phi \ne 0$。单纯的偏航角速度反馈会施加反对转弯的方向舵；洗出滤波器让荷兰滚（周期约$6\ \mathrm{s}$）的振荡偏航角速度通过，但去掉稳态分量，因此阻尼器在已建立的转弯中不起作用。滤除噪声是低通滤波的任务，而洗出使螺旋模态保持在接近机体本身的值，并不使之稳定。
:::
:::

::: history
1914年6月，劳伦斯·斯佩里（Lawrence Sperry）在巴黎附近的飞机安全竞赛（Concours de la Sécurité en Aéroplane）上，在一架寇蒂斯（Curtiss）水上飞机上演示了陀螺稳定器：他双手离开操纵机构飞行，而他的机械师走到机翼上——这是自动稳定的首次公开演示。以陀螺为基准的自动驾驶仪在1930年代变得普遍，偏航阻尼器随着1950年代的后掠翼喷气运输机成为标准配置。协和号（Concorde，1969年首飞）采用带机械备份的模拟式电传信号传输。NASA 的 F-8 数字电传操纵研究机于1972年5月25日由加里·克里尔（Gary E. Krier）在今天的阿姆斯特朗飞行研究中心首飞，是第一架采用数字电传操纵系统且没有机械备份的固定翼飞机，它使用的计算机源自阿波罗制导计算机；该项目一直持续到1985年。通用动力公司的 F-16（1974年首飞）把全权限电传操纵和放宽静稳定性带入了批生产，而空客 A320（1987年2月22日首飞，1988年4月在法国航空投入运营）是第一种采用数字电传飞行操纵和侧杆控制器的客机。
:::

::: summary
- 反馈$\mathbf u = \mathbf u_p + \mathbf K\mathbf y$把模态移到$\mathbf A + \mathbf B\mathbf K\mathbf C$的特征值上；增益按动压和马赫数调参。
- 俯仰阻尼器：$\delta_e = K_qq$给$M_q$加上$M'_{\delta e}K_q$；$K_q \approx 0.5$把喷气运输机的短周期阻尼从$0.38$提高到$0.70$。
- 带洗出$K_r\tau_ws/(\tau_ws + 1)$的偏航阻尼器能阻尼荷兰滚（$0.027 \to 0.32$）而不反对定常转弯。
- 迎角反馈恢复因放宽静稳定性而失去的刚度，代价是对回路的依赖。
- 自动驾驶仪在内层阻尼回路之外串接外回路（姿态、高度、航向）；比例式姿态保持会留下稳态误差和速度变化，除非加入积分作用和自动油门。
- 电传操纵控制律指令的是响应（角速度、过载），提供包线保护，并依赖按严格概率目标审定的余度、非相似架构。
:::

## 习题

::: exercise 阻尼器的升降舵指令 {level=1 check="1.5"}
某俯仰阻尼器的$K_q = 0.50$（每度每秒俯仰角速度对应的升降舵度数）。俯仰角速度为$3^\circ/\mathrm{s}$时，它指令多大的升降舵偏角？（单位为度。）
::: solution
$\Delta\delta_e = 0.50 \times 3 = 1.5^\circ$，后缘下偏，反抗抬头角速度。
:::
:::

::: exercise 洗出滤波器的转折频率 {level=1 check="0.333"}
某洗出滤波器的$\tau_w = 3\ \mathrm{s}$。求其转折频率。（单位 rad/s，保留三位小数。）
::: solution
转折频率为$\omega = 1/\tau_w = 0.333\ \mathrm{rad/s}$。约$1\ \mathrm{rad/s}$的荷兰滚高出三倍，以增益$\lvert\mathrm{i}\omega\tau_w/(\mathrm{i}\omega\tau_w + 1)\rvert = 3/\sqrt{10} = 0.95$和$18^\circ$的相位超前通过；持续一分钟的转弯实际上相当于零频率，因而被阻断。
:::
:::

::: exercise 反对转弯的方向舵 {level=1 check="0.99"}
一架飞机以$\dot\psi = 0.020\ \mathrm{rad/s}$、$\phi = 30^\circ$做定常转弯，装有$K_r = 1.0$（rad/rad/s）的单纯偏航阻尼器。它施加多大的方向舵偏角？（单位为度，保留两位小数。）
::: solution
$r = \dot\psi\cos\phi = 0.020 \times 0.8660 = 0.01732\ \mathrm{rad/s}$，故$\delta_r = K_rr = 0.01732\ \mathrm{rad} = 0.99^\circ$，在整个转弯期间一直保持并反对转弯；飞行员必须保持反向的脚蹬力。洗出滤波器可以消除它。
:::
:::

::: exercise 满足目标阻尼的俯仰阻尼器增益 {level=2 check="0.17"}
利用喷气运输机的导数和[[#eq-sp-damper]]，求使$\zeta_{sp} = 0.50$的俯仰阻尼器增益$K_q$。（输入$K_q$，单位 rad per rad/s，保留两位小数。）
::: solution
令$m = 0.2253 + 1.648K_q$。则$\omega^2 = 0.4059m + 0.7564$，$2\zeta\omega = m + 0.4810$。取$\zeta = 0.5$：$(m + 0.4810)^2 = 0.4059m + 0.7564$，即$m^2 + 0.5561m - 0.5250 = 0$，$m = 0.4980$，故$K_q = (0.4980 - 0.2253)/1.648 = 0.165$，保留两位小数为$0.17$。
:::
:::

::: exercise 人工静稳定裕度 {level=2 check="0.044"}
对于喷气运输机，$C_{m\alpha}$每变化一个单位，$M_\alpha$变化$-0.7564/0.55 = -1.375\ \mathrm{s^{-2}}$，且$C_{L\alpha} = 5.5$。加入$K_\alpha = 0.20$的迎角反馈。它使有效静稳定裕度增加多少？（以$\bar c$的分数表示增量，保留三位小数。）
::: solution
$\Delta M_\alpha = M'_{\delta e}K_\alpha = -1.648 \times 0.20 = -0.3297\ \mathrm{s^{-2}}$，相当于$\Delta C_{m\alpha} = -0.3297/1.375 = -0.2397$。静稳定裕度为$-C_{m\alpha}/C_{L\alpha}$，因此增加$0.2397/5.5 = 0.0436$——即$0.044$——约为平均气动弦的$4.4\,\%$。
:::
:::

::: exercise 改变航向所需的滚转角 {level=2 check="1.32"}
某航向保持自动驾驶仪指令$\phi_c = K_\psi(\psi_c - \psi)$，$K_\psi = 2.0$，滚转角限制为$25^\circ$。在$230\ \mathrm{m/s}$时，一旦滚转角在限制值上建立起来，改变$90^\circ$航向需要多长时间？（单位为分钟，保留两位小数。）
::: solution
指令滚转角为$2.0 \times 90^\circ = 180^\circ$，因此在转弯的大部分时间里限幅器保持$25^\circ$。转弯角速度$\dot\psi = g\tan 25^\circ/V = 9.80665 \times 0.46631/230 = 0.01988\ \mathrm{rad/s}$，所以在$25^\circ$限制下转过$90^\circ = 1.5708\ \mathrm{rad}$需要$79.0\ \mathrm{s} = 1.32\ \mathrm{min}$（最后一段，即指令降到$25^\circ$以下的最后$12.5^\circ$航向，需要的时间稍长一些）。
:::
:::

::: exercise 带作动器滞后的阻尼器的稳定性 {level=3}
用带俯仰阻尼器和一阶作动器$\delta_e = \delta_c/(\tau_as + 1)$、$\tau_a = 0.1\ \mathrm{s}$的模型描述喷气运输机的短周期。写出三状态模型，并解释（或计算）当$K_q$增大到远超设计值时闭环极点会发生什么变化。
::: solution
状态$(\Delta\alpha, \Delta q, \Delta\delta_e)$：$\Delta\dot\alpha = -0.406\Delta\alpha + \Delta q$（忽略$Z_{\delta e}$）；$\Delta\dot q = -0.726\Delta\alpha - 0.3005\Delta q - 1.648\Delta\delta_e$；$\Delta\dot\delta_e = (K_q\Delta q - \Delta\delta_e)/\tau_a$。从$\delta_c$到$q$的开环传递函数有三个极点（短周期极点对和位于$-10$的作动器极点）和一个零点（在$s = -0.406$，来自$\alpha$方程）。由于极点比零点多两个，根轨迹有两条位于$\pm 90^\circ$的渐近线，它们与实轴交于形心$(-0.706 - 10 + 0.406)/2 = -5.15$：随着$K_q$增大，一支趋向零点，而短周期极点对分离并趋向渐近线，变成一个阻尼随增益减小的振荡“作动器模态”。对于纯一阶滞后，理论上系统保持稳定（渐近线在左半平面），但加入传感器滤波器、采样延迟或二阶作动器会带来更多极点，使渐近线进入右半平面——高增益时失稳。这就是阻尼器增益受到限制、以及每一份飞行控制规范都包含相角裕度和幅值裕度要求的原因。
:::
:::

::: exercise 制定电传操纵系统的要求 {level=3}
你正在为一种新支线飞机的电传操纵系统俯仰通道编写顶层要求。列出你会对以下各项提出的要求：(a) 对飞行员驾驶杆的响应，(b) 包线保护，(c) 故障后的行为，(d) 鲁棒性；并说明每一项如何验证。
::: solution
好的回答包括：(a) 指令响应类型（低速时为俯仰角速度，高速时过渡为过载），以及短周期频率和阻尼的目标（取自飞行品质标准）、时间延迟（低于约$0.1\ \mathrm{s}$）、航迹无超调、自动配平和每 g 杆力/杆位移；通过线性分析、有人驾驶仿真（库珀–哈珀评分）和飞行试验验证。(b) 留有裕度的、低于失速的迎角保护，与 V–n 图相符的过载限制（例如光洁构型下$+2.5$/$-1.0$），低于$V_D$/$M_D$的高速保护，以及俯仰姿态限制；通过对所有边界情况的仿真和飞行试验验证。(c) 平缓降级：任何单一故障都不得导致失控；保护功能丧失时有明确提示的降级控制律；故障概率满足审定目标（灾难性状态为每飞行小时$10^{-9}$）；通过故障模式分析、故障树分析和铁鸟试验验证。(d) 在整个包线内、包括重心、质量的变化、气动不确定性、结构模态（陷波滤波器）和作动器速率限制在内的稳定裕度（例如$6\ \mathrm{dB}$幅值裕度和$45^\circ$相角裕度）；通过带不确定性模型的分析、蒙特卡罗仿真和地面共振试验验证。软件和硬件按适用的保证标准开发。
:::
