飞机最快能飞多快，最慢能飞多慢，能爬升得多陡，发动机停车后能滑翔多远，又能飞多高？这些都是**飞机性能**（aircraft performance）问题。在定常飞行中——没有加速度，因而所有的力都相互平衡——它们都可以由两项信息回答：飞机的**极曲线**（drag polar），它说明产生给定升力时有多大阻力；以及发动机提供的**可用推力或可用功率**。本讲先建立进行计算所用的标准大气，再由受力图建立定常飞行方程，然后推导经典结果：最小阻力与最小功率、最大速度、爬升率与爬升角、升限以及滑翔飞行。

气动力方面的内容来自[[aerodynamics/finite-wings]]（诱导阻力与奥斯瓦尔德效率因子）和[[aerodynamics/viscous-aerodynamics]]（摩擦阻力与压差阻力）；推进方面的内容——推力和功率如何随速度和高度变化——是[[propulsion/thrust-efficiency]]和[[propulsion/propellers]]的主题。这里两者都作为已知量。

全课程始终使用两架飞机，以便各讲之间的数值可以相互比较。它们是通用飞机，并不对应某一具体机型，但其数据在各自类别中具有代表性。

## 标准大气 {#sec-isa}

飞机性能强烈依赖于空气密度，而从海平面到客机巡航高度，密度约下降为原来的四分之一。为了比较飞机、进行适航审定和校准仪表，工程师使用一个由国际标准约定的模型大气。

::: definition 国际标准大气 {#def-isa}
**国际标准大气**（International Standard Atmosphere，ISA，ISO 2533:1975，在 $32\ \mathrm{km}$ 以下与 1976 年美国标准大气相同）把空气视为干燥的理想气体，$R = 287.05\ \mathrm{J\,kg^{-1}\,K^{-1}}$，在恒定重力加速度 $g_0 = 9.80665\ \mathrm{m/s^2}$ 下处于静力平衡，海平面值为
$$
T_0 = 288.15\ \mathrm{K},\qquad p_0 = 101\,325\ \mathrm{Pa},\qquad \rho_0 = 1.225\ \mathrm{kg/m^3},
$$
温度在**对流层**内随位势高度$h$以**温度递减率**$\lambda = 6.5\ \mathrm{K/km}$线性下降，直至$11\ \mathrm{km}$处的**对流层顶**，其上直到$20\ \mathrm{km}$（**平流层**下部）温度保持为$216.65\ \mathrm{K}$。**密度比**为$\sigma = \rho/\rho_0$。
:::

实际的天气各不相同——夏季的“ISA $+20$”天在每一高度上的温度都比标准值高$20\ \mathrm{K}$——但性能数据总是换算到 ISA 条件下并按 ISA 条件给出。

::: proposition 标准大气中的压力与密度 {#prop-troposphere}
在对流层内（$0 \le h \le 11\ \mathrm{km}$），$T = T_0 - \lambda h$，
$$
\frac{p}{p_0} = \left(\frac{T}{T_0}\right)^{g_0/(R\lambda)},\qquad
\frac{\rho}{\rho_0} = \left(\frac{T}{T_0}\right)^{g_0/(R\lambda) - 1},\qquad \frac{g_0}{R\lambda} = 5.2559 .
$$ {#eq-troposphere}
在$h_{11} = 11\ \mathrm{km}$以上的等温层中，$T = T_{11} = 216.65\ \mathrm{K}$，
$$
\frac{p}{p_{11}} = \frac{\rho}{\rho_{11}} = \exp\!\left[-\frac{g_0(h - h_{11})}{RT_{11}}\right],\qquad p_{11} = 22\,632\ \mathrm{Pa},\quad \rho_{11} = 0.3639\ \mathrm{kg/m^3}.
$$ {#eq-stratosphere}
:::

::: proof
两个假设：空气相对地球静止（静力平衡），且为理想气体。面积为$A$、厚度为$\mathrm{d}h$的一薄层水平空气重$\rho g_0 A\,\mathrm{d}h$，由其上下表面的压力差支撑，故$\mathrm{d}p = -\rho g_0\,\mathrm{d}h$（见[[fluid-mechanics/fluid-statics]]）。由$\rho = p/(RT)$，
$$
\frac{\mathrm{d}p}{p} = -\frac{g_0}{RT}\,\mathrm{d}h .
$$
在对流层内$\mathrm{d}h = -\mathrm{d}T/\lambda$，故$\mathrm{d}p/p = \dfrac{g_0}{R\lambda}\,\dfrac{\mathrm{d}T}{T}$；从海平面积分得$\ln(p/p_0) = \dfrac{g_0}{R\lambda}\ln(T/T_0)$，即[[#eq-troposphere]]的第一式。再由$\rho/\rho_0 = (p/p_0)(T_0/T)$，指数减一。数值为$9.80665/(287.05 \times 0.0065) = 5.2559$。在等温层中$T$为常数，$\mathrm{d}p/p = -g_0\,\mathrm{d}h/(RT_{11})$积分得指数函数；温度不变时$\rho \propto p$。$11\ \mathrm{km}$处的值由对流层公式得到，$T_{11}/T_0 = 216.65/288.15 = 0.75187$：$p_{11} = 101\,325 \times 0.75187^{5.2559} = 22\,632\ \mathrm{Pa}$，$\rho_{11} = p_{11}/(RT_{11}) = 0.3639\ \mathrm{kg/m^3}$。
:::

## 空速 {#sec-airspeeds}

气动力取决于**动压**$q = \tfrac12\rho V^2$，其中$V$是飞机相对空气的速度。皮托-静压系统测量总压与静压之差，在低马赫数下它恰好等于$q$；因此它无法区分在稀薄空气中飞得快的飞机和在稠密空气中飞得慢的飞机。这就是为什么要使用几种空速。

::: definition 真空速、当量空速与校正空速 {#def-airspeeds}
- **真空速**（true airspeed，TAS）$V$：飞机相对未扰动空气的速度。
- **当量空速**（equivalent airspeed，EAS）$V_E$：在海平面密度下给出相同动压的速度，$\tfrac12\rho_0V_E^2 = \tfrac12\rho V^2$，故$V_E = V\sqrt{\sigma}$。
- **校正空速**（calibrated airspeed，CAS）：消除了仪表误差和位置误差的空速表读数。空速表按海平面条件下的可压缩流关系式校准，因此在海平面和低速时 CAS 等于 EAS，在高速和高空时略大于 EAS（在 EAS 为$120\ \mathrm{m/s}$、高度为$10\ \mathrm{km}$时约大$5\ \mathrm{m/s}$）。
- **指示空速**（indicated airspeed，IAS）：仪表的示数，包含上述误差。
- **地速**：相对地面的速度，即真空速与风速的矢量和——[[dynamics/relative-motion]]中的风速三角形。
:::

由于升力和阻力取决于$q$，给定重量的飞机在每一高度上都以相同的**当量**空速（并且在很好的近似下以相同的指示空速）失速，这就是飞行员的速度限制以指示空速给出的原因。真空速决定飞机相对地面前进的快慢以及阻力消耗的功率（$P = DV$），在高空要大$1/\sqrt\sigma$倍。

::: warning 混用真空速与当量空速
本讲中凡含$\rho$的公式，都是把**真**空速$V$与**当地**密度$\rho$配合使用；这样乘积$\tfrac12\rho V^2$就等于$\tfrac12\rho_0V_E^2$。一个常见错误是把当量空速或指示空速与当地密度配用（或把真空速与海平面密度配用），这会使高空的动压被低估$\sigma$倍——在$11\ \mathrm{km}$处相差$3.4$倍。另一个常见错误是把功率算成阻力乘以**当量**空速：功率是$DV$，其中$V$为真空速。
:::

## 定常飞行方程 {#sec-steady}

**受力图。** 把飞机视为一个质点，沿一条直线航迹运动，航迹相对水平面倾斜**航迹角**$\gamma$（爬升时为正）。四个力作用在重心上：

- **重力**$W = mg$，竖直向下；
- **升力**$L$，垂直于航迹（垂直于相对气流），位于对称面内；
- **阻力**$D$，沿相对气流方向，与速度方向相反；
- **推力**$T$，假设沿航迹作用（忽略推力线与航迹之间的小夹角；其影响是把$T$换成$T\cos\epsilon_T$，把$L$换成$L + T\sin\epsilon_T$）。

假设俯仰力矩由尾翼平衡（这是[[flight-mechanics/longitudinal-static-stability]]的主题），因此这里只需考虑力的平衡。

::: proposition 定常飞行方程 {#prop-steady}
在定常、直线、对称飞行中，
$$
T - D - W\sin\gamma = 0,\qquad L - W\cos\gamma = 0 .
$$ {#eq-steady}
在水平飞行（$\gamma = 0$）中，它们简化为$T = D$和$L = W$。
:::

::: proof
对质心应用牛顿第二定律$\mathbf{F} = m\mathbf{a}$，由于速度的大小和方向都不变，$\mathbf{a} = \mathbf{0}$。沿航迹分解：推力向前，阻力向后，爬升时重力的分量$W\sin\gamma$向后。在对称面内垂直于航迹分解：升力向上，重力的分量$W\cos\gamma$向下。假设：刚性飞机，平坦且不旋转的地球（对客机速度下的性能计算已足够），机翼水平，无侧滑，推力沿航迹。
:::

气动力以机翼面积$S$为参考面积写出：$L = qSC_L$，$D = qSC_D$。两个系数之间的关系就是极曲线。

::: definition 抛物线型极曲线 {#def-polar}
对于光洁构型、低于阻力发散马赫数的飞机，阻力系数可以很好地表示为
$$
C_D = C_{D0} + KC_L^2,\qquad K = \frac{1}{\pi e\,AR},
$$ {#eq-polar}
其中$C_{D0}$是**零升阻力系数**（全机的摩擦阻力、压差阻力和干扰阻力，也称废阻力），$KC_L^2$是**升致阻力**，以[[aerodynamics/finite-wings]]中的诱导阻力为主；**奥斯瓦尔德效率因子**$e$（通常为$0.7$–$0.85$）同时计入了展向载荷偏离椭圆分布以及黏性阻力随升力增长这两方面的影响。
:::

极曲线是经验拟合，而不是定律：它在失速附近失效，因为那里的分离使阻力迅速增加；在阻力发散马赫数（运输机机翼约为$0.75$–$0.85$）以上也失效，因为那里出现了波阻。对于我们的两架飞机，$K_{\text{LA}} = 1/(\pi \times 0.80 \times 7.5) = 0.05305$，$K_{\text{JT}} = 1/(\pi \times 0.80 \times 9.5) = 0.04188$。

## 需用推力与最小阻力 {#sec-thrust-required}

在水平飞行中，需用推力等于阻力。把$C_L = W/(qS)$代入极曲线，
$$
T_R = D = qSC_{D0} + \frac{KW^2}{qS},\qquad q = \tfrac12\rho V^2 .
$$ {#eq-drag-v}
第一项零升阻力随$V^2$增长；第二项升致阻力随$1/V^2$减小，因为高速时只需很小的升力系数。两者之和存在最小值。

::: proposition 最小阻力 {#prop-min-drag}
对于抛物线型极曲线，水平飞行的阻力在零升阻力与升致阻力相等时最小。此时
$$
C_L^\ast = \sqrt{\frac{C_{D0}}{K}},\qquad
\left(\frac{L}{D}\right)_{\max} = \frac{1}{2\sqrt{KC_{D0}}},\qquad
D_{\min} = \frac{W}{(L/D)_{\max}} = 2W\sqrt{KC_{D0}},
$$ {#eq-min-drag}
对应的**最小阻力速度**为
$$
V_{md} = \sqrt{\frac{2W}{\rho S}}\left(\frac{K}{C_{D0}}\right)^{1/4}.
$$ {#eq-vmd}
:::

::: proof
在水平飞行中$D = W/(L/D) = W\,C_D/C_L$，因此在重量一定时，阻力最小意味着$C_D/C_L = C_{D0}/C_L + KC_L$最小。对$C_L$求导：$-C_{D0}/C_L^2 + K = 0$，故$C_L^{\ast2} = C_{D0}/K$，二阶导数$2C_{D0}/C_L^3 > 0$确认这是极小值。此时$KC_L^{\ast2} = C_{D0}$：两部分阻力相等。于是$C_D = 2C_{D0}$，$(L/D)_{\max} = \sqrt{C_{D0}/K}/(2C_{D0}) = 1/(2\sqrt{KC_{D0}})$。速度由$W = \tfrac12\rho V^2SC_L^\ast$得到。假设：$C_{D0}$和$K$为常数的抛物线型极曲线（无马赫数或雷诺数效应），水平飞行，$L = W$。
:::

[[#eq-min-drag]]的两个特点对后续所有内容都很重要。最小阻力和最大升阻比**与高度无关**：爬升到稀薄空气中只会使出现它们的速度提高$1/\sqrt\sigma$倍。而最小阻力对应的当量空速只取决于翼载$W/S$和极曲线。

::: example 喷气运输机在 11 km 的最小阻力 {#ex-jet-md}
求喷气运输机在$11\ \mathrm{km}$处的$(L/D)_{\max}$、最小阻力和最小阻力速度，并与马赫数$0.78$的巡航状态比较。
::: solution
$W = 70\,000 \times 9.80665 = 686.5\ \mathrm{kN}$；$W/S = 5599\ \mathrm{N/m^2}$。由$K = 0.04188$和$C_{D0} = 0.020$：
$$
C_L^\ast = \sqrt{0.020/0.04188} = 0.6910,\qquad (L/D)_{\max} = \frac{1}{2\sqrt{0.04188 \times 0.020}} = 17.28,\qquad D_{\min} = \frac{686.5}{17.28} = 39.74\ \mathrm{kN}.
$$
在$11\ \mathrm{km}$处，$\rho = 0.3639\ \mathrm{kg/m^3}$：
$$
V_{md} = \sqrt{\frac{2 \times 5599}{0.3639 \times 0.6910}} = 211.0\ \mathrm{m/s},
$$
马赫数为$211.0/295.1 = 0.715$，当量空速为$211.0\sqrt{0.2971} = 115.0\ \mathrm{m/s}$。在马赫数$0.78$时，$V = 230.2\ \mathrm{m/s}$，$q = \tfrac12 \times 0.3639 \times 230.2^2 = 9639\ \mathrm{Pa}$，$C_L = 5599/9639 = 0.5809$，$C_D = 0.020 + 0.04188 \times 0.5809^2 = 0.03413$，$D = 9639 \times 122.6 \times 0.03413 = 40.34\ \mathrm{kN}$，$L/D = 17.02$。合理性检查：比$V_{md}$快$9\,\%$只多付出$1.5\,\%$的阻力，因为阻力曲线在最小值附近很平坦——而飞机能更早到达目的地，这就是喷气式飞机以高于$V_{md}$的速度巡航的原因（见[[flight-mechanics/range-endurance]]）。$L/D \approx 17$是窄体客机的典型值。
:::
:::

## 需用功率 {#sec-power}

对于螺旋桨飞机，发动机提供的是功率而不是推力，自然的量是**需用功率**$P_R = DV$：
$$
P_R = \tfrac12\rho V^3SC_{D0} + \frac{2KW^2}{\rho V S}.
$$ {#eq-power-required}

::: proposition 最小功率 {#prop-min-power}
对于抛物线型极曲线，水平飞行的需用功率在升致阻力等于零升阻力的三倍时最小：
$$
C_{L,mp} = \sqrt{\frac{3C_{D0}}{K}},\qquad C_{D,mp} = 4C_{D0},\qquad
V_{mp} = 3^{-1/4}\,V_{md} = 0.760\,V_{md},
$$ {#eq-min-power}
最小功率为$P_{\min} = W\,V_{mp}\,C_{D,mp}/C_{L,mp}$，它随高度按$1/\sqrt\sigma$增长。
:::

::: proof
$P_R = DV = (W C_D/C_L)\,V$，由$W = \tfrac12\rho V^2SC_L$得$V = \sqrt{2W/(\rho SC_L)}$。因此
$$
P_R = W\sqrt{\frac{2W}{\rho S}}\;\frac{C_D}{C_L^{3/2}},
$$
所以在重量和高度一定时，功率最小意味着$C_L^{3/2}/C_D$最大。对$\ln(C_L^{3/2}/C_D) = \tfrac32\ln C_L - \ln(C_{D0} + KC_L^2)$求导并令其为零：$\dfrac{3}{2C_L} = \dfrac{2KC_L}{C_{D0} + KC_L^2}$，即$3C_{D0} + 3KC_L^2 = 4KC_L^2$，故$KC_L^2 = 3C_{D0}$。于是$C_D = 4C_{D0}$，$V_{mp}/V_{md} = (C_L^\ast/C_{L,mp})^{1/2} = 3^{-1/4}$。因子$\sqrt{2W/(\rho S)}$带来了对高度的$1/\sqrt\sigma$依赖。
:::

对于海平面的轻型飞机：$C_{L,mp} = \sqrt{3 \times 0.030/0.05305} = 1.302$，$V_{mp} = \sqrt{2 \times 665.9/(1.225 \times 1.302)} = 28.89\ \mathrm{m/s}$，$L/D = 1.302/0.120 = 10.85$，$P_{\min} = 10\,787 \times 28.89/10.85 = 28.71\ \mathrm{kW}$。失速速度——能够保持水平飞行的最低速度——
$$
V_s = \sqrt{\frac{2W}{\rho SC_{L,\max}}}
$$ {#eq-stall}
为$\sqrt{2 \times 665.9/(1.225 \times 1.5)} = 26.92\ \mathrm{m/s}$（$52\ \mathrm{kt}$），因此这架飞机的最小功率速度只比失速速度高$7\,\%$。这在轻型飞机中很典型；实际上，为了留有安全裕度，也因为螺旋桨效率在低速时下降，爬升速度和待机速度会选得稍高一些。

## 最大速度与飞行包线 {#sec-vmax}

最大平飞速度出现在曲线的高速分支上可用推力（或功率）等于需用推力（或功率）之处。对于**喷气式**飞机，其推力在给定高度上随速度变化很慢，在[[#eq-drag-v]]中令$T_A = D$并乘以$q$：
$$
SC_{D0}\,q^2 - T_A\,q + \frac{KW^2}{S} = 0
\quad\Longrightarrow\quad
V^2 = \frac{(T_A/W)(W/S) \pm (W/S)\sqrt{(T_A/W)^2 - 4KC_{D0}}}{\rho\,C_{D0}} .
$$ {#eq-vmax-jet}
取正号得最大速度，取负号得由推力决定的最小速度（它常常低于失速速度，因而无关紧要）。当$T_A/W = 2\sqrt{KC_{D0}} = 1/(L/D)_{\max}$时两根合并：此时飞机恰好只能以$V_{md}$保持水平飞行，其他速度都不行。这一高度就是**理论升限**（absolute ceiling）。

对于**螺旋桨**飞机，可用功率$P_A = \eta_p P_{\text{shaft}}$大致不随速度变化，$P_A = P_R$是关于$V$的四次方程，用数值方法或图解法求解。

::: example 喷气运输机在 11 km 的最大速度 {#ex-vmax}
在$11\ \mathrm{km}$处，喷气运输机的两台发动机在最大连续推力状态下共提供$T_A = 46\ \mathrm{kN}$。由抛物线型极曲线估算最大平飞速度，并加以评述。
::: solution
$T_A/W = 46\,000/686\,466 = 0.06701$；$4KC_{D0} = 4 \times 0.04188 \times 0.020 = 0.003351$；$\sqrt{0.06701^2 - 0.003351} = \sqrt{0.001140} = 0.03376$。于是
$$
V^2 = \frac{5599\,(0.06701 + 0.03376)}{0.3639 \times 0.020} = 7.752\times10^{4}\ \mathrm{m^2/s^2},\qquad V = 278.4\ \mathrm{m/s}.
$$
校核：$q = \tfrac12 \times 0.3639 \times 278.4^2 = 14\,106\ \mathrm{Pa}$，$C_L = 0.3970$，$C_D = 0.02660$，$D = 14\,106 \times 122.6 \times 0.02660 = 46.0\ \mathrm{kN}$。✓

结果是马赫数$278.4/295.1 = 0.94$——这正是要评述之处：抛物线型极曲线中没有波阻。在阻力发散马赫数（这类机翼约为$0.8$）以上，阻力急剧上升，实际的最大速度由这一阻力上升以及审定的最大使用马赫数$M_{MO}$（窄体客机通常为$0.82$）决定。合理性检查：方法是对的，但输入超出了它的适用范围；在较低高度上，最大速度对应的马赫数较低，极曲线的估算要好得多。
:::
:::

在低速端，包线以失速为界；在高速端，以推力或结构与压缩性限制为界；在顶端，以升限为界。把最小速度和最大速度随高度的变化画出来，就得到**飞行包线**，它在理论升限处闭合。

## 爬升飞行 {#sec-climb}

::: proposition 爬升率 {#prop-roc}
在定常爬升中，爬升率$V_v = V\sin\gamma$和爬升角为
$$
V_v = \frac{TV - DV}{W} = \frac{P_A - P_R}{W},\qquad \sin\gamma = \frac{T - D}{W},
$$ {#eq-roc}
其中$P_A - P_R$是**剩余功率**。对于小于约$15^\circ$的爬升角，可以很好地近似地取$D$和$P_R$为同一速度下的平飞值。
:::

::: proof
将[[#eq-steady]]中沿航迹的方程$T - D = W\sin\gamma$乘以$V$，并利用$V_v = V\sin\gamma$。关于近似：爬升时$L = W\cos\gamma$，因此升致阻力减小为$\cos^2\gamma$倍；在$\gamma = 15^\circ$时，$\cos^2\gamma = 0.933$。采用平飞阻力会略微高估$D$，从而略微低估爬升率——这是偏于保守的误差。用能量论证也得到同样的结果：剩余功率以$W\,\mathrm{d}h/\mathrm{d}t$的速率提高势能$Wh$。
:::

两个最优状态是不同的。**最陡爬升**（$\gamma$最大，越障时需要）使剩余**推力**$T - D$最大；对于推力不变的喷气式飞机，它出现在$V_{md}$。**最快爬升**（$V_v$最大，需要尽快到达某一高度时）使剩余**功率**最大；对于$P_A$不变的螺旋桨飞机，它出现在$V_{mp}$，对于喷气式飞机则出现在高于$V_{md}$的速度上，因为$P_A = T_AV$随速度增长（[[#exr-fastest-climb]]推导了这一结果）。

::: example 轻型飞机的爬升性能 {#ex-climb}
轻型飞机的$P_A = 0.75 \times 100 = 75\ \mathrm{kW}$，取为不随速度变化。求其海平面最大爬升率及相应速度，以及速度为$50\ \mathrm{m/s}$时的爬升率。
::: solution
$P_A$不变时，最大剩余功率出现在上面求得的最小功率速度$V_{mp} = 28.89\ \mathrm{m/s}$处，此时$P_R = 28.71\ \mathrm{kW}$：
$$
V_{v,\max} = \frac{75\,000 - 28\,713}{10\,787} = 4.29\ \mathrm{m/s}
$$
（$845\ \mathrm{ft/min}$）。在$V = 50\ \mathrm{m/s}$时：$q = 1531\ \mathrm{Pa}$，$D = 1531 \times 16.2 \times 0.030 + 0.05305 \times 10\,787^2/(1531 \times 16.2) = 744.2 + 248.8 = 993.1\ \mathrm{N}$，$P_R = 49.65\ \mathrm{kW}$，$V_v = (75\,000 - 49\,650)/10\,787 = 2.35\ \mathrm{m/s}$。合理性检查：对于一架$1.1$吨、$100\ \mathrm{kW}$的飞机，$4.3\ \mathrm{m/s}$大致是对的；最大爬升率时的爬升角为$\sin^{-1}(4.29/28.89) = 8.5^\circ$，处于平飞阻力近似成立的范围内。实际上，由于$\eta_p$在低速时下降，最大爬升率速度要飞得更接近$35$–$38\ \mathrm{m/s}$。
:::
:::

**升限。** 随着高度增加，活塞发动机的可用功率下降（大致与密度成正比，Gagg–Ferrar 关联式$P/P_0 = 1.132\sigma - 0.132$是非增压发动机常用的拟合式），而最小需用功率按$1/\sqrt\sigma$增长。**理论升限**是最大爬升率为零的高度；**实用升限**是最大爬升率降到$0.5\ \mathrm{m/s}$（$100\ \mathrm{ft/min}$）的高度。对于轻型飞机，它们分别约为$5550\ \mathrm{m}$和$4830\ \mathrm{m}$。对于推力大致随密度下降的喷气式飞机，理论升限位于$T_A = W/(L/D)_{\max}$处——与[[#eq-vmax-jet]]两根合并的条件相同。

## 滑翔飞行 {#sec-glide}

发动机处于慢车状态（$T = 0$）时，[[#eq-steady]]变为$D = -W\sin\gamma$和$L = W\cos\gamma$，其中$\gamma < 0$。

::: proposition 滑翔飞行 {#prop-glide}
在下滑角为$\theta = -\gamma$的定常滑翔中，
$$
\tan\theta = \frac{D}{L} = \frac{1}{L/D},\qquad
\text{从高度 } h \text{ 滑翔的距离} = h\,\frac{L}{D},\qquad
\text{下沉率 } V_{\text{sink}} = V\sin\theta .
$$ {#eq-glide}
最平缓的滑翔（静止空气中的最远距离）在$(L/D)_{\max}$即$V_{md}$时实现；最小下沉率（最长航时）在最小功率即$V_{mp}$时实现。
:::

::: proof
两个力方程相除，精确地得到$\tan\theta = D/L$——不需要小角度假设。直线滑翔的水平距离为$h/\tan\theta = h\,(L/D)$。下沉率为$V\sin\theta$；将沿航迹的平衡式$W\sin\theta = D$乘以$V$，得$V_{\text{sink}} = DV/W = P_R/W$，所以最小下沉率意味着最小需用功率。假设：静止空气中的定常滑翔，下降过程中$L/D$不变（严格地说，随着空气变稠密，$V$会减小，但在升力系数不变时，$L/D$从而下滑角保持不变）。
:::

::: example 在 3000 m 发动机失效 {#ex-glide}
轻型飞机在平坦地面以上$3000\ \mathrm{m}$处发动机失效。在静止空气中它能滑翔多远？在滑翔开始时应以多大真空速飞行？此时的下沉率是多少？若以海平面的下沉率计算，到达地面需要多长时间？
::: solution
$(L/D)_{\max} = 1/(2\sqrt{0.05305 \times 0.030}) = 12.53$，所以滑翔距离为$3000 \times 12.53 = 37.6\ \mathrm{km}$，下滑角为$\tan^{-1}(1/12.53) = 4.56^\circ$。最佳滑翔速度为$V_{md}$：在海平面$C_L^\ast = \sqrt{0.030/0.05305} = 0.7520$，$V_{md} = \sqrt{2 \times 665.9/(1.225 \times 0.7520)} = 38.02\ \mathrm{m/s}$；在$3000\ \mathrm{m}$处，真空速为$38.02/\sqrt{0.7421} = 44.14\ \mathrm{m/s}$（当量空速为$38.02\ \mathrm{m/s}$——飞行员全程保持同一指示空速）。$3000\ \mathrm{m}$处的下沉率为$44.14\sin 4.56^\circ = 3.51\ \mathrm{m/s}$；海平面处为$3.02\ \mathrm{m/s}$。即使按海平面下沉率计算，下降也不超过$3000/3.02 = 993\ \mathrm{s}$，约$17$分钟。合理性检查：$12.5$的滑翔比是轻型飞机的典型值（滑翔机可达$40$–$60$）；滑翔距离与重量无关，只有最佳滑翔速度与重量有关。
:::
:::

逆风$V_w$按地速的比例减小相对地面的滑翔距离：以空速$V$滑翔时为$h\,(L/D)(V - V_w)/V$。逆风时以高于$V_{md}$的速度滑翔更为有利，这就是滑翔机飞行员在逆风中要加速的原因。

::: quiz
一架涡轮喷气式飞机和一架活塞螺旋桨飞机都要以尽可能**陡**的角度爬升以越过障碍物。假设喷气式飞机推力不变、螺旋桨飞机功率不变，它们各应以什么速度飞行？
- [ ] 都以最小功率速度$V_{mp}$
- [x] 喷气式飞机以$V_{md}$；螺旋桨飞机以低于$V_{md}$的速度，在安全允许的范围内尽量接近失速速度
- [ ] 喷气式飞机以$V_{mp}$；螺旋桨飞机以$V_{md}$
- [ ] 都以最大速度
::: solution
最陡爬升使$T - D$最大。对于喷气式飞机，$T$不变，因此就是最小阻力：$V_{md}$。对于螺旋桨飞机，$T = P_A/V$随速度降低而增大，所以在$V_{md}$以下$T - D$继续增大（那里$D$变化平缓而$T$在增长）；最优点位于低速处，实际上受失速裕度和螺旋桨效率下降的限制。
:::
:::

::: history
乔治·凯利爵士（Sir George Cayley）分三部分发表的论文《论空中航行》（“On Aerial Navigation”，*Nicholson's Journal*，1809–1810）把固定翼飞机表述为一个在克服阻力的同时产生升力的问题，把今天所称的升力和阻力分开，并论证了机翼向上的（上反）角能提供滚转稳定性。奥托·李林塔尔（Otto Lilienthal）的《鸟类飞行——飞行艺术的基础》（*Der Vogelflug als Grundlage der Fliegekunst*，1889）以极曲线图的形式发表了弯度机翼升力和阻力的测量结果；莱特兄弟（Wright brothers）在1901年秋季对许多小型机翼模型进行的风洞试验，为他们设计1902年滑翔机和1903年“飞行者”号提供了数据。基于抛物线型极曲线的性能解析处理——需用推力曲线和需用功率曲线、最小阻力和最小功率——在1930和1940年代的教科书中成为标准内容；标准大气先由国际民航组织（ICAO）在国际上确定，后来又以 ISO 2533:1975 和1976年美国标准大气的形式确定，两者在低层大气中一致。
:::

::: summary
- 使用 ISA：在$11\ \mathrm{km}$以下$T = 288.15 - 0.0065h$（K，m），$p/p_0 = (T/T_0)^{5.2559}$，$\rho/\rho_0 = (T/T_0)^{4.2559}$；其上为等温层，按指数规律变化。
- 气动力取决于$q = \tfrac12\rho V^2 = \tfrac12\rho_0V_E^2$；真空速与当地密度配用，计算功率用真空速。
- 定常飞行：$T - D = W\sin\gamma$，$L = W\cos\gamma$；极曲线$C_D = C_{D0} + KC_L^2$，$K = 1/(\pi e AR)$。
- 最小阻力：$C_L^\ast = \sqrt{C_{D0}/K}$，$(L/D)_{\max} = 1/(2\sqrt{KC_{D0}})$，与高度无关。最小功率：$C_L = \sqrt{3C_{D0}/K}$，$V_{mp} = 0.760V_{md}$，$P_{\min} \propto 1/\sqrt\sigma$。
- 喷气式飞机的最大速度由二次方程[[#eq-vmax-jet]]求得；两根在理论升限处合并，$T_A/W = 1/(L/D)_{\max}$。
- 爬升率 = 剩余功率 / 重量；最陡爬升使剩余推力最大。
- 下滑角$\tan\theta = 1/(L/D)$；最远距离在$V_{md}$，最小下沉率在$V_{mp}$。
:::

::: solution
$V_s = \sqrt{2W/(\rho SC_{L,\max})} = \sqrt{2 \times 665.9/(1.225 \times 2.0)} = 23.31\ \mathrm{m/s}$，即$23.3\ \mathrm{m/s}$（$45\ \mathrm{kt}$），而光洁构型为$26.9\ \mathrm{m/s}$。两者之比为$\sqrt{1.5/2.0} = 0.866$。

::: solution
$(L/D)_{\max} = 1/(2\sqrt{0.040 \times 0.025}) = 1/(2 \times 0.03162) = 15.81$，即$15.8$，对应$C_L^\ast = \sqrt{0.025/0.040} = 0.791$。

已知轻型飞机在海平面的最小需用功率为$28.71\ \mathrm{kW}$，求其在 ISA 中$2000\ \mathrm{m}$高度的最小需用功率。（单位 kW，保留一位小数。）
::: solution
由[[#prop-min-power]]，重量一定时$P_{\min} \propto 1/\sqrt\sigma$：$28.71/\sqrt{0.8216} = 28.71/0.9064 = 31.68\ \mathrm{kW}$，即$31.7\ \mathrm{kW}$，对应真空速$28.89/0.9064 = 31.87\ \mathrm{m/s}$（当量空速相同）。

::: exercise 喷气运输机在巡航高度的爬升 {level=2 check="1.90"}
在$11\ \mathrm{km}$、马赫数$0.78$时，喷气运输机的阻力为$40.34\ \mathrm{kN}$（[[#ex-jet-md]]）。若发动机在该处提供$46\ \mathrm{kN}$推力，爬升率是多少？（单位 m/s，保留两位小数。）

$V_v = (T - D)V/W = (46.00 - 40.34) \times 10^3 \times 230.15/686\,466 = 1.90\ \mathrm{m/s}$（$374\ \mathrm{ft/min}$）。正是由于这一裕度很小，客机才随着燃油消耗、重量减轻而分阶梯爬升到最终的巡航高度。

::: exercise 逆风滑翔 {level=2 check="36"}
一架$L/D = 40$的滑翔机从$1500\ \mathrm{m}$高度以真空速$25\ \mathrm{m/s}$迎着$10\ \mathrm{m/s}$的定常逆风滑翔。它相对地面飞过多远？（输入距离，单位 km，取整数。）
::: solution
相对空气的下滑角为$\tan^{-1}(1/40) = 1.43^\circ$，所以下降$1500\ \mathrm{m}$所需时间为$1500/(25\sin 1.43^\circ) = 2400\ \mathrm{s}$。水平地速为$25\cos 1.43^\circ - 10 = 14.99\ \mathrm{m/s}$，所以距离为$2400 \times 14.99 = 35\,990\ \mathrm{m} \approx 36\ \mathrm{km}$——在小角度近似的精度内即$1500 \times 40 \times (25 - 10)/25 = 36\ \mathrm{km}$——而在静止空气中为$60\ \mathrm{km}$。
:::

::: exercise 喷气式飞机的最快爬升速度 {#exr-fastest-climb level=3}
对于推力$T$与速度无关、具有抛物线型极曲线的喷气式飞机，证明（采用平飞阻力）最大爬升率对应的速度为
$$
V^2 = \frac{W/S}{3\rho C_{D0}}\left[\frac{T}{W} + \sqrt{\left(\frac{T}{W}\right)^2 + 12KC_{D0}}\right],
$$
并验证它大于$V_{md}$。
::: solution
$WV_v = TV - \tfrac12\rho V^3SC_{D0} - 2KW^2/(\rho VS)$。对$V$求导并令其为零：$T - \tfrac32\rho V^2SC_{D0} + 2KW^2/(\rho V^2S) = 0$。乘以$\rho V^2/W$并令$x = \rho V^2$：$\tfrac32 (S/W)C_{D0}\,x^2 - (T/W)\,x - 2K(W/S) = 0$。正根为
$$
x = \frac{(T/W) + \sqrt{(T/W)^2 + 12KC_{D0}}}{3C_{D0}\,S/W},
$$
即所求结果。除以$V_{md}^2 = 2\sqrt{KC_{D0}}\,(W/S)/(\rho C_{D0})$并记$a = \sqrt{KC_{D0}}$：$V^2/V_{md}^2 = \left[T/W + \sqrt{(T/W)^2 + 12a^2}\right]/(6a)$。只有当$T/W > 2a$（理论升限条件）时才能爬升，此时方括号大于$2a + \sqrt{4a^2 + 12a^2} = 6a$，所以$V > V_{md}$，恰在理论升限处取等号。对于$11\ \mathrm{km}$处$T/W = 0.0670$、$a = 0.02894$的喷气运输机，比值为$V/V_{md} = 1.04$。物理上：剩余功率$TV - DV$在超过$V_{md}$后继续增大，因为$TV$线性增长，而$DV$仍几乎平坦。
:::

::: exercise 按爬升要求确定发动机功率 {level=3 check="107"}
用户要求轻型飞机在最大质量下于$2000\ \mathrm{m}$（ISA）处的爬升率不低于$3.0\ \mathrm{m/s}$。取$\eta_p = 0.75$，功率不随速度变化，功率随高度按 Gagg–Ferrar 关系$P/P_0 = 1.132\sigma - 0.132$下降，需要多大的海平面轴功率？讨论在选定发动机之前还应检查哪些方面。（输入轴功率，单位 kW，取整数。）
::: solution
在$2000\ \mathrm{m}$处，$\sigma = 0.8216$，$P_{\min} = 31.68\ \mathrm{kW}$（[[#exr-pmin-alt]]）。最大爬升率在$V_{mp}$处：$V_v = (P_A - P_{\min})/W$，故$P_A = 3.0 \times 10\,787 + 31\,677 = 64\,039\ \mathrm{W}$。功率递减因子为$1.132 \times 0.8216 - 0.132 = 0.7981$，因此海平面轴功率必须为$64\,039/(0.75 \times 0.7981) = 106\,990\ \mathrm{W}$，即约$107\ \mathrm{kW}$——比现有的$100\ \mathrm{kW}$增加$7\,\%$。选定之前：(i) 最大爬升率速度$31.9\ \mathrm{m/s}$（真空速）只比失速速度高$7\,\%$，在那里$\eta_p = 0.75$过于乐观——应采用螺旋桨特性图，在约$1.3V_s$的实用爬升速度下重新计算；(ii) 热天（ISA $+20$）会降低$2000\ \mathrm{m}$处的密度，从而同时降低发动机功率和爬升率；(iii) 检查低速爬升时的发动机冷却；(iv) 更大的发动机会增加质量，而$P_{\min}$按$W^{3/2}$成比例增大——需要迭代；(v) 适航爬升要求（CS-23 / 14 CFR Part 23）才是起决定作用的约束，必须在审定构型下校核。
:::
