飞往火星的航天器在旅途的大部分时间里绕太阳运行，但它从地球引力势阱的深处出发，在火星引力势阱的深处结束。没有哪个单一的二体问题能描述整个旅程，而精确的问题——航天器同时受太阳和几颗行星的吸引——没有封闭形式的解。然而，把三个二体问题拼接起来，就能得到一个精度惊人的初步设计：一条离开地球的双曲线，一条绕太阳的椭圆，以及一条到达目标的双曲线。这就是**拼接圆锥曲线法**（patched-conic method），行星际任务的初步规模正是这样确定的：它给出发射能量、出发和捕获变轨、飞行时间以及发射窗口，与精确数值设计的差别通常在百分之几以内。同样的图景解释了航天中最精妙的技巧——**引力辅助**（引力弹弓）：航天器飞越一颗行星，不消耗任何推进剂就获得或损失日心速度。本章以地球到火星的转移为例逐步建立这一方法，然后分析飞越。

本章用到[[orbital-mechanics/two-body-problem]]中的双曲线、[[orbital-mechanics/orbital-manoeuvres]]中的霍曼转移和奥伯特效应，以及[[orbital-mechanics/orbit-determination]]中的兰伯特问题。

## 拼接圆锥曲线的思想 {#sec-patched}

在行星附近，行星的引力占主导；远离行星时，太阳的引力占主导。拼接圆锥曲线法把这一点变成一条明确的规则：围绕每颗行星画一个球——其**影响球**（sphere of influence）——在球内只计行星的引力，在球外只计太阳的引力。在球内，轨迹是以行星为中心的双曲线；在球外，是以太阳为中心的圆锥曲线。在边界上，两者通过速度相加来匹配：航天器的日心速度等于行星的日心速度加上航天器在该处相对于行星的速度。

由于影响球虽然比行星大得多，但与行星到太阳的距离相比却很小，因此再作两个简化：在日心阶段，认为航天器在行星的*中心*出发和结束；在行星中心阶段，认为航天器在边界上的速度就是**双曲线剩余速度**$v_\infty$，即以行星为中心的双曲线在无穷远处的速度。

::: proposition 影响球 {#prop-soi}
质量为$m$、在距离$R$处绕太阳（质量$M \gg m$）运行的行星，其影响球半径为
$$
r_\mathrm{SOI} \approx R\left(\frac{m}{M}\right)^{2/5}.
$$ {#eq-soi}
在此半径以内，太阳的影响（作为对行星中心运动的摄动）相对地小于行星的影响（作为对日心运动的摄动）。
:::

::: proof
考虑位于日-行星连线上（最不利情形）、距行星$r \ll R$的航天器。**以行星为中心看：**主加速度为$Gm/r^2$；太阳的摄动是它对航天器的引力与对行星的引力之差，即潮汐项$\approx 2GMr/R^3$。两者之比为$\chi_p = 2Mr^3/(mR^3)$。**以太阳为中心看：**主加速度$\approx GM/R^2$；行星的摄动是它对航天器的引力$Gm/r^2$减去它对太阳的（小得多的）引力，所以比值$\chi_s \approx mR^2/(Mr^2)$。拉普拉斯判据采用比值较小的那个坐标系。边界$\chi_p = \chi_s$给出$r^5 = R^5m^2/(2M^2)$，即$r = 2^{-1/5}R(m/M)^{2/5}$。若对潮汐项按方向取平均而不取最不利情形，数值因子会改变，而惯用的定义把它略去，得到[[#eq-soi]]。这一结果是一个数量级上的边界，而非物理表面：指数$2/5$有意义，前置因子只是约定。
:::

对于地球，$r_\mathrm{SOI} = 1.496\times10^8\,(398\,600/1.327\,12\times10^{11})^{2/5} = 925\,000\ \mathrm{km}$——约145个地球半径，但只有一个天文单位的$0.6\,\%$。火星的影响球为$577\,000\ \mathrm{km}$，木星的为$48\times10^6\ \mathrm{km}$。月球相对于地球的影响球为$66\,000\ \mathrm{km}$。

## 日心转移 {#sec-heliocentric}

把行星轨道近似为圆形且共面（火星的偏心率为$0.093$，轨道倾角为$1.85^\circ$，所以这只是一阶近似）。最省的双脉冲转移就是日心霍曼椭圆，它在出发时与地球轨道相切，在到达时与目标轨道相切。在切点处它相对于各行星的速度就是双曲线剩余速度：
$$
v_{\infty,\text{出发}} = \sqrt{\frac{\mu_\odot}{R_1}}\left(\sqrt{\frac{2R_2}{R_1 + R_2}} - 1\right), \qquad
v_{\infty,\text{到达}} = \sqrt{\frac{\mu_\odot}{R_2}}\left(1 - \sqrt{\frac{2R_1}{R_1 + R_2}}\right),
$$ {#eq-vinf-hohmann}
它们与[[orbital-mechanics/orbital-manoeuvres]]中霍曼转移两次变轨的表达式相同——但在这里它们不是变轨：它们是航天器必须离开地球影响球和将要进入目标影响球的速度。

行星还必须处在正确的位置上。转移用时$t_H = \pi\sqrt{a_t^3/\mu_\odot}$，在此期间目标行星转过$n_2t_H$，所以出发时目标必须领先地球一个**相位角**
$$
\phi_0 = \pi - n_2t_H.
$$ {#eq-phase}
这一几何构型每隔一个**会合周期**重复一次，即较快的行星多绕一整圈所需的时间：
$$
T_\text{syn} = \frac{2\pi}{\lvert n_1 - n_2\rvert} = \frac{T_1T_2}{\lvert T_2 - T_1\rvert}.
$$ {#eq-synodic}

::: example 地球到火星：日心段 {#ex-earth-mars}
采用半径为$R_1 = 1.495\,98\times10^8\ \mathrm{km}$（地球）和$R_2 = 2.279\times10^8\ \mathrm{km}$（火星）的共面圆轨道，求霍曼转移的剩余速度、飞行时间、出发相位角和会合周期。
::: solution
$a_t = (R_1 + R_2)/2 = 1.8875\times10^8\ \mathrm{km}$。日心速度：地球$\sqrt{\mu_\odot/R_1} = 29.785\ \mathrm{km/s}$，火星$24.131\ \mathrm{km/s}$；在转移轨道上，近日点处$\sqrt{\mu_\odot(2/R_1 - 1/a_t)} = 32.728\ \mathrm{km/s}$，远日点处$21.483\ \mathrm{km/s}$。因此
$$
v_{\infty,\text{出发}} = 32.728 - 29.785 = 2.944\ \mathrm{km/s}, \qquad v_{\infty,\text{到达}} = 24.131 - 21.483 = 2.648\ \mathrm{km/s}.
$$
飞行时间$t_H = \pi\sqrt{(1.8875\times10^8)^3/1.327\,12\times10^{11}} = 2.236\times10^7\ \mathrm{s} = 258.8$天。火星的平均角速度为$360^\circ/686.8\ \mathrm{d}$，所以它在转移期间转过$135.7^\circ$，出发时必须领先地球$\phi_0 = 180^\circ - 135.7^\circ = 44.3^\circ$。会合周期：$T_\text{syn} = 365.26 \times 686.80/(686.80 - 365.26) = 780.2$天。

**校核：**真实的火星发射窗口大约每26个月开启一次（$780\ \mathrm{d} = 25.6$个月），典型的火星任务需要7–9个月；发射能量$C_3 = v_\infty^2 = 8.7\ \mathrm{km^2/s^2}$与真实火星任务处于同一量级，后者大致需要$8$到$17\ \mathrm{km^2/s^2}$，因火星轨道偏心且倾斜而随窗口不同。
:::
:::

对于往返任务，航天员或样品还必须在火星等待，直到行星的位置适合返回的霍曼转移：返回开始时，地球必须*落后*火星一个它在一次转移期间多转过的角度$n_1t_H - \pi = 75.1^\circ$，而到达火星时地球*领先*$75.1^\circ$。以相对角速度$360^\circ/780.2\ \mathrm{d}$消除这一差距需要$454.7$天，所以最小能量往返需要$2 \times 258.8 + 454.7 = 972$天——约两年零八个月。更快的“冲日型”往返是可能的，代价是多得多的$\Delta v$（常常利用金星飞越）。

## 从停泊轨道出发 {#sec-departure}

运载火箭先把航天器送入低停泊轨道；在那里进行一次变轨，使之进入具有所需$v_\infty$的逃逸双曲线。量$C_3 = v_\infty^2$（**特征能量**，双曲线比能量的两倍）是逃逸任务中通常用来表示运载火箭性能的方式。

::: proposition 从圆形停泊轨道入轨 {#prop-departure}
要以剩余速度$v_\infty$沿双曲线离开半径为$r_p$的圆形停泊轨道，需要在近拱点进行一次切向变轨
$$
\Delta v = \sqrt{v_\infty^2 + \frac{2\mu}{r_p}} - \sqrt{\frac{\mu}{r_p}}.
$$ {#eq-injection}
变轨必须在出发渐近线指向所需方向的位置进行：近拱点位于从渐近线方向量起的角度$\beta = \arccos(1/e)$处，$e = 1 + r_pv_\infty^2/\mu$——在与渐近线相反的一侧，使双曲线绕过来沿渐近线离去。
:::

::: proof
能量：双曲线的$\varepsilon = v_\infty^2/2$，所以它在$r_p$处的速度为$v_p = \sqrt{v_\infty^2 + 2\mu/r_p}$（取$a = -\mu/v_\infty^2$的活力公式）。那里的圆轨道速度为$\sqrt{\mu/r_p}$，在近拱点处两个速度都是水平的，所以变轨量就是它们之差。几何：由[[orbital-mechanics/two-body-problem]]，去向渐近线位于距近拱点真近点角$\theta_\infty = \arccos(-1/e)$处；近拱点方向与渐近线*反*方向之间的夹角为$180^\circ - \theta_\infty = \arccos(1/e) = \beta$。停泊轨道必须位于包含渐近线的平面内——这约束了发射时刻和方位角。
:::

::: example 离开地球飞往火星 {#ex-departure}
对于[[#ex-earth-mars]]中的霍曼转移，求从$300\ \mathrm{km}$圆形停泊轨道出发的入轨变轨量以及变轨位置。
::: solution
$r_p = 6678\ \mathrm{km}$，$v_\infty = 2.944\ \mathrm{km/s}$：
$$
\Delta v = \sqrt{2.944^2 + \frac{2 \times 398\,600}{6678}} - \sqrt{\frac{398\,600}{6678}} = 11.316 - 7.726 = 3.590\ \mathrm{km/s}.
$$
$e = 1 + 6678 \times 8.665/398\,600 = 1.1452$，$\beta = \arccos(1/1.1452) = 29.2^\circ$。渐近线必须沿地球的日心速度方向（以便在其上*加上*$2.944\ \mathrm{km/s}$），所以变轨点位于停泊轨道上、沿停泊轨道运动方向越过地球公转速度*反*方向$29.2^\circ$的那一点；双曲线随后使航天器转过$\theta_\infty = 150.8^\circ$到达所需的渐近线上。（停泊轨道平面必须包含渐近线方向，这确定了一天中的发射时刻。）

**校核：**变轨量只有$3.59\ \mathrm{km/s}$，其中仅仅逃逸就需要$3.20\ \mathrm{km/s}$。额外提供$2.94\ \mathrm{km/s}$的剩余速度只花$0.39\ \mathrm{km/s}$，因为变轨是在地球引力势阱的深处进行的——这就是奥伯特效应。
:::
:::

## 到达与捕获 {#sec-arrival}

在目标处，航天器以相对于行星的$v_\infty$到达。不变轨的话，它沿双曲线飞越而过。要被捕获，它必须在近拱点附近制动进入闭合轨道。对于偏心率为$e$、近拱点半径为$r_p$的捕获轨道，
$$
\Delta v_\text{捕获} = \sqrt{v_\infty^2 + \frac{2\mu}{r_p}} - \sqrt{\frac{\mu(1+e)}{r_p}}.
$$ {#eq-capture}
近拱点通过瞄准来选择：剩余速度为$v_\infty$、以近拱点$r_p$经过行星的双曲线，其**瞄准半径**（碰撞参数）——行星中心到来向渐近线的距离——为
$$
\Delta = r_p\sqrt{1 + \frac{2\mu}{r_pv_\infty^2}},
$$ {#eq-aiming}
这由角动量守恒$h = \Delta\,v_\infty = r_pv_p$得出。由于$\Delta > r_p$，引力会聚焦来向轨迹：行星捕获（或被击中）的是瞄准在一个比它本身更大的圆盘之内的一切。导航人员在 **B 平面**上指定瞄准点，该平面通过行星中心并垂直于来向渐近线。

::: example 在火星捕获 {#ex-capture}
[[#ex-earth-mars]]中的航天器以$v_\infty = 2.648\ \mathrm{km/s}$到达火星。求进入下列轨道所需的变轨量：(a) $300\ \mathrm{km}$高度的圆轨道；(b) 近拱点高度$300\ \mathrm{km}$、$e = 0.8$的椭圆轨道。(c) 多大半径的圆轨道使捕获变轨量最小？
::: solution
$r_p = 3396 + 300 = 3696\ \mathrm{km}$，$\mu = 42\,828\ \mathrm{km^3/s^2}$。双曲线近拱点速度$\sqrt{2.648^2 + 2 \times 42\,828/3696} = \sqrt{7.012 + 23.175} = 5.494\ \mathrm{km/s}$。

(a) 圆轨道速度$\sqrt{42\,828/3696} = 3.404$：$\Delta v = 2.090\ \mathrm{km/s}$。

(b) 椭圆的近拱点速度$\sqrt{42\,828 \times 1.8/3696} = 4.567$：$\Delta v = 0.927\ \mathrm{km/s}$。

(c) 对于圆轨道（$e = 0$），[[#eq-capture]]作为$r_p$的函数（令导数为零）在$r_p = 2\mu/v_\infty^2 = 12\,216\ \mathrm{km}$（高度$8820\ \mathrm{km}$）处取最小值，此处$\Delta v = v_\infty/\sqrt2 = 1.872\ \mathrm{km/s}$。

**校核：**捕获进入狭长椭圆的代价不到捕获进入低圆轨道的一半，这就是火星轨道器先捕获进入椭圆轨道、然后逐步降低远拱点的原因——常常通过**气动减速**（aerobraking），反复掠入高层大气，让阻力而不是推进剂来消耗能量。(c) 中的最优值很平缓：$r_p$减半或加倍只使代价增加百分之几。
:::
:::

::: warning 混淆坐标系、把速度相加 {#warn-frames}
拼接圆锥曲线法中最常见的错误是坐标系错误。$v_\infty$是*相对于行星*的速度；它既不是航天器的日心速度，也不是它在停泊轨道上的速度。入轨变轨量不是$v_\infty$，也不是$v_\infty$加逃逸速度；而是$\sqrt{v_\infty^2 + v_\text{esc}^2} - v_c$，速度按平方和相加，因为它们代表能量。日心速度按*矢量*相加：$\mathbf{v}_\odot = \mathbf{v}_\text{行星} + \mathbf{v}_\infty$，只有对霍曼转移两者才平行。最后，在每个阶段使用正确的$\mu$——转移椭圆用太阳的，双曲线用行星的。用地球的$\mu$计算火星捕获，结果看起来完全合理，但逃逸速度项错了三倍。
:::

## 引力辅助 {#sec-flyby}

不变轨而飞越行星的航天器保持其相对于行星的速度大小：它以剩余速度$\mathbf{v}_\infty^-$进入影响球，以大小相等、转过双曲线偏转角$\delta$的$\mathbf{v}_\infty^+$离开。然而在日心坐标系中行星在运动，把它的速度加到两个长度相等、方向不同的矢量上，得到的两个日心速度长度*不同*。航天器与行星交换了动量——对行星而言变化可以忽略，对航天器而言则很大。

::: proposition 飞越中的速度变化 {#prop-flyby}
剩余速度为$v_\infty$、近拱点半径为$r_p$的飞越使相对于行星的速度转过
$$
\delta = 2\arcsin\frac1e, \qquad e = 1 + \frac{r_pv_\infty^2}{\mu},
$$ {#eq-turn}
并使航天器的日心速度改变一个大小为
$$
\lVert\Delta\mathbf{v}\rVert = 2v_\infty\sin\frac{\delta}{2} = \frac{2v_\infty}{e}
$$ {#eq-flyby-dv}
的矢量。若航天器从行星*后方*（相对于行星的运动方向）经过，日心速度增大；若从前方经过，日心速度减小。
:::

::: proof
双曲线的偏转角已在[[orbital-mechanics/two-body-problem]]中求出，$e = 1 + r_pv_\infty^2/\mu$由$r_p = a(1-e)$及$a = -\mu/v_\infty^2$得出。由于拼接圆锥曲线法中的飞越在日心坐标系中是瞬时的，$\mathbf{v}_\odot^\pm = \mathbf{V}_p + \mathbf{v}_\infty^\pm$，行星速度$\mathbf{V}_p$相同，所以$\Delta\mathbf{v}_\odot = \mathbf{v}_\infty^+ - \mathbf{v}_\infty^-$：这是一个腰长为$v_\infty$、顶角为$\delta$的等腰三角形的底边，长度为$2v_\infty\sin(\delta/2) = 2v_\infty/e$。日心速度的平方变化$\lVert\mathbf{V}_p + \mathbf{v}_\infty^+\rVert^2 - \lVert\mathbf{V}_p + \mathbf{v}_\infty^-\rVert^2 = 2\mathbf{V}_p\cdot(\mathbf{v}_\infty^+ - \mathbf{v}_\infty^-)$，当转动使$\mathbf{v}_\infty$转向$\mathbf{V}_p$时为正。从行星后方（尾随一侧）经过会使轨迹沿行星运动方向弯过去，正是起到这种作用。
:::

对给定的$v_\infty$，最大的速度变化来自行星所允许的最近飞越（受大气、光环、辐射限制）。质量大、以高速接近的行星给出的“踢力”最大：木星能使航天器的日心速度改变每秒几十千米，地球和金星能改变每秒几千米——这仍足以让无法直接到达木星、土星和水星的运载火箭完成这些任务。

::: example 木星飞越 {#ex-jupiter}
航天器沿从地球出发的霍曼转移到达木星轨道（$R_J = 7.783\times10^8\ \mathrm{km}$，$\mu_J = 1.266\,87\times10^8\ \mathrm{km^3/s^2}$，木星半径$71\,492\ \mathrm{km}$），并在$r_p = 5$个木星半径处从尾随一侧飞越。求$v_\infty$、偏转角以及飞越后的日心速度。它是否足以逃离太阳？
::: solution
转移轨道（$a_t = 4.6414\times10^8\ \mathrm{km}$）：远日点速度$\sqrt{\mu_\odot(2/R_J - 1/a_t)} = 7.415\ \mathrm{km/s}$；木星的圆轨道速度$13.058\ \mathrm{km/s}$。航天器到达时比木星慢，所以木星从后方追上它：$v_\infty = 5.643\ \mathrm{km/s}$，方向与木星运动方向相反。（转移需$997$天。）

$e = 1 + 357\,460 \times 5.643^2/1.266\,87\times10^8 = 1.0899$，$\delta = 2\arcsin(1/1.0899) = 133.1^\circ$。

去向剩余速度是来向剩余速度转过$133.1^\circ$的结果：以沿木星运动方向和垂直于它的分量表示，$\mathbf{v}_\infty^+ = 5.643\,(\cos 46.9^\circ,\ \sin 46.9^\circ) = (3.859,\ 4.118)\ \mathrm{km/s}$。日心速度：$(13.058 + 3.859,\ 4.118) = (16.917,\ 4.118)$，速度大小$17.41\ \mathrm{km/s}$——增加了$10.0\ \mathrm{km/s}$，来自大小为$2v_\infty/e = 10.36\ \mathrm{km/s}$的速度变化。

木星距离处的太阳逃逸速度为$\sqrt{2\mu_\odot/R_J} = 18.47\ \mathrm{km/s}$：还差一点。更近的飞越（更大的$\delta$）就能做到：理论最大值是$\mathbf{v}_\infty^+$完全沿木星速度方向时的$13.06 + 5.64 = 18.70\ \mathrm{km/s}$。

**校核：**当来向$\mathbf{v}_\infty$恰好与木星速度反平行时，由对称性，尾随一侧和前导一侧的飞越给出相同的速度（转动从“向后”方向向哪一侧都一样）；一般情况下并非如此。不借助飞越，要在$5.2\ \mathrm{AU}$处直接从地球获得$17.4\ \mathrm{km/s}$，需要日心出发速度$\sqrt{17.41^2 + 2\mu_\odot(1/R_1 - 1/R_J)}$，即$41.7\ \mathrm{km/s}$——相对于地球的剩余速度为$11.9\ \mathrm{km/s}$，而霍曼转移只需$8.8\ \mathrm{km/s}$，发射能量相差很大（$C_3 = 141$对$77\ \mathrm{km^2/s^2}$）。
:::

实践中的飞越设计把每个日心段的兰伯特解（在选定日期的行星位置之间）与这样的要求结合起来：每次飞越时来向和去向$v_\infty$的大小相等，且两者夹角能以安全的近拱点实现——这是一个对日期的搜索，产生了旅行者号、伽利略号和卡西尼号等任务的多行星巡游轨道。对单一航段把发射能量画成出发日期和到达日期的函数，就得到**猪排图**（porkchop plot），其等值线显示发射窗口。

::: quiz
航天器从金星前方（前导一侧）飞越金星。在拼接圆锥曲线模型中，下列哪些说法正确？
- [x] 飞越前后它相对于金星的速度大小相同。
- [x] 它的日心速度减小。
- [ ] 它的日心速度不变，因为引力是保守力。
- [ ] 它必须使用推进剂才能改变日心速度。
::: solution
在行星坐标系中，飞越是一条保守的二体双曲线：进入时的$v_\infty$等于离开时的$v_\infty$。在太阳坐标系中金星在运动，前导一侧的飞越使$\mathbf{v}_\infty$转离金星的速度方向，降低了日心速度——这对向内落向水星很有用，水手10号以及后来的信使号（MESSENGER）和贝皮·科伦坡号（BepiColombo）都是这样做的。总能量是守恒的：航天器损失的能量由金星获得，其轨道速度的变化小到无法测量。
:::
:::

::: history
利用行星引力改变航天器路径的想法，出现在尤里·孔德拉秋克（Yuri Kondratyuk）约写于1918–1919年的手稿中，以及弗里德里希·灿德尔（Friedrich Zander）20世纪20年代的著作中。苏联探测器月球3号（Luna 3）于1959年10月利用月球引力弯曲其路径，从而拍摄了月球背面并传回照片。20世纪60年代初在喷气推进实验室工作的研究生迈克尔·米诺维奇（Michael Minovitch）系统地计算了飞越如何改变日心轨道；60年代中期，喷气推进实验室的加里·弗兰德罗（Gary Flandro）注意到木星、土星、天王星和海王星将在70年代末排列成可以让一个航天器依次访问全部四颗行星的位置。水手10号于1974年2月5日在飞往水星途中于金星完成了首次行星引力辅助。旅行者2号（1977年8月20日发射）和旅行者1号（1977年9月5日发射）利用了外行星的这一排列；旅行者2号飞越了全部四颗巨行星，于1989年到达海王星。
:::

## 后续内容 {#sec-next}

拼接圆锥曲线设计是精确轨道工作的起点：计入全部行星摄动的数值积分（[[orbital-mechanics/perturbations]]）和基于兰伯特问题的优化对它加以精化，飞行中的轨道修正机动则用[[orbital-mechanics/orbit-determination]]中的估计方法消除剩余误差。小推力电推进和多体动力学（经由日地拉格朗日点的转移，空间望远镜采用这种转移）则完全超出了拼接圆锥曲线的图景。

::: summary
- 拼接圆锥曲线：在行星影响球$r_\mathrm{SOI} \approx R(m/M)^{2/5}$之内用行星的二体问题，之外用太阳的；用$\mathbf{v}_\odot = \mathbf{V}_\text{行星} + \mathbf{v}_\infty$匹配速度。
- 日心霍曼转移给出出发和到达的剩余速度（地球-火星：$2.94$和$2.65\ \mathrm{km/s}$，$259$天）；出发相位角为$\pi - n_2t_H$（火星为$44^\circ$），窗口每隔一个会合周期（$780$天）重复。
- 入轨：$\Delta v = \sqrt{v_\infty^2 + 2\mu/r_p} - \sqrt{\mu/r_p}$，在距反向渐近线$\arccos(1/e)$角度的近拱点进行；$C_3 = v_\infty^2$。
- 捕获：$\Delta v = \sqrt{v_\infty^2 + 2\mu/r_p} - \sqrt{\mu(1+e)/r_p}$；椭圆捕获比圆轨道捕获省得多；用$\Delta = r_p\sqrt{1 + 2\mu/(r_pv_\infty^2)}$瞄准。
- 引力辅助：$v_\infty$大小不变但转过$\delta = 2\arcsin(1/e)$，使日心速度改变$2v_\infty/e$；从尾随一侧飞越使航天器加速。
:::

::: exercise 金星的影响球 {level=1 check="616"}
金星在$1.0821\times10^8\ \mathrm{km}$处绕太阳运行，$\mu = 324\,860\ \mathrm{km^3/s^2}$。求其影响球半径。（以千千米为单位输入，保留三位有效数字。）
::: solution
$r_\mathrm{SOI} = 1.0821\times10^8\,(324\,860/1.327\,12\times10^{11})^{2/5} = 1.0821\times10^8 \times 5.695\times10^{-3} = 616\times10^3\ \mathrm{km}$——约100个金星半径。

::: exercise 木星的发射窗口 {level=1 check="399"}
采用圆轨道（$R_\oplus = 1.496\times10^8\ \mathrm{km}$，$R_J = 7.783\times10^8\ \mathrm{km}$），求木星的公转周期以及地球-木星会合周期。（以天为单位输入会合周期，保留三位有效数字。）
::: solution
$T_J = 2\pi\sqrt{R_J^3/\mu_\odot} = 4334\ \mathrm{d}$（$11.87$年），$T_\oplus = 365.26\ \mathrm{d}$。$T_\text{syn} = 365.26 \times 4334/(4334 - 365.26) = 399\ \mathrm{d}$——木星窗口每13个月出现一次，因为木星运动缓慢，地球只需一年多一点就能多绕它一圈。

::: exercise 从较低的停泊轨道入轨 {level=1 check="3.63"}
从$200\ \mathrm{km}$高度的圆形停泊轨道出发，多大的入轨变轨量能给出$v_\infty = 3.00\ \mathrm{km/s}$？（以 km/s 为单位输入$\Delta v$，保留三位有效数字。）
::: solution

求从地球（$1.495\,98\times10^8\ \mathrm{km}$）到金星（$1.0821\times10^8\ \mathrm{km}$）的霍曼转移在出发和到达时的双曲线剩余速度以及飞行时间。出发渐近线相对于地球运动方向必须指向哪里？（以 km/s 为单位输入出发$v_\infty$，保留三位有效数字。）

$a_t = 1.2890\times10^8\ \mathrm{km}$。地球速度$29.785$；转移轨道远日点（在地球处）速度$\sqrt{\mu_\odot(2/R_1 - 1/a_t)} = 27.289\ \mathrm{km/s}$，所以$v_{\infty,\text{出发}} = 2.50\ \mathrm{km/s}$，指向与地球运动方向*相反*（航天器必须向内落）。在金星处：转移轨道近日点速度$37.73$，金星$35.03\ \mathrm{km/s}$，$v_{\infty,\text{到达}} = 2.71\ \mathrm{km/s}$。飞行时间$146\ \mathrm{d}$。

[[#ex-capture]]中的航天器改为直接捕获进入$500\ \mathrm{km}$高度的圆轨道。捕获变轨量是多少？（以 km/s 为单位输入$\Delta v$，保留三位有效数字。）

::: exercise 在金星处的偏转 {level=2 check="83.3"}

::: solution

::: exercise 捕获进入椭圆的最小代价 {level=3 check="1.32"}
证明对偏心率$e$固定的捕获轨道，当$r_p = 2\mu(1-e)/[v_\infty^2(1+e)]$时变轨量[[#eq-capture]]最小，且最小值为$v_\infty\sqrt{(1-e)/2}$。对以$v_\infty = 2.648\ \mathrm{km/s}$到达火星、$e = 0.5$的情形求其值，并检验最优近拱点在地面以上。（以 km/s 为单位输入最小$\Delta v$，保留三位有效数字。）
::: solution
记$\Delta v(r) = \sqrt{v_\infty^2 + 2\mu/r} - \sqrt{\mu(1+e)/r}$并求导：
$$
\frac{\mathrm{d}\Delta v}{\mathrm{d}r} = -\frac{\mu}{r^2\sqrt{v_\infty^2 + 2\mu/r}} + \frac{\sqrt{\mu(1+e)}}{2r^{3/2}}.
$$
令其为零得$2\sqrt{\mu} = \sqrt{(1+e)r}\,\sqrt{v_\infty^2 + 2\mu/r}$，即$4\mu = (1+e)(rv_\infty^2 + 2\mu)$，所以$r_p = 2\mu(1-e)/[v_\infty^2(1+e)]$。在这一半径处$2\mu/r_p = v_\infty^2(1+e)/(1-e)$，所以双曲线近拱点速度为$\sqrt{v_\infty^2 + v_\infty^2(1+e)/(1-e)} = v_\infty\sqrt{2/(1-e)}$，捕获轨道近拱点速度为$\sqrt{(1+e)\mu/r_p} = v_\infty(1+e)/\sqrt{2(1-e)}$。两者之差为$v_\infty\,[2 - (1+e)]/\sqrt{2(1-e)} = v_\infty\sqrt{(1-e)/2}$。对于火星：$r_p = 2 \times 42\,828 \times 0.5/(7.012 \times 1.5) = 4072\ \mathrm{km}$（高度$676\ \mathrm{km}$，在地面以上），$\Delta v_\text{min} = 2.648\sqrt{0.25} = 1.32\ \mathrm{km/s}$。对$e = 0.8$，该公式给出的近拱点在火星内部，所以起支配作用的是约束$r_p \ge R + h_\text{min}$，如[[#ex-capture]]所示。
:::
:::

::: exercise 最大可能的“踢力” {level=3 check="7.91" #exr-max-flyby}
对于近拱点固定为$r_p$的飞越，证明当$v_\infty$等于$r_p$处的圆轨道速度时日心速度变化$2v_\infty/e$最大，且最大值为$\sqrt{\mu/r_p}$。对掠过地球表面的飞越（$r_p = 6378\ \mathrm{km}$，忽略大气）求其值。（以 km/s 为单位输入最大值，保留三位有效数字。）
::: solution
$f(v) = 2v/(1 + r_pv^2/\mu)$。$f'(v) = 0$给出$1 + r_pv^2/\mu - 2r_pv^2/\mu = 0$，即$v^2 = \mu/r_p$，此时$e = 2$，$\delta = 60^\circ$，$f = 2v/2 = \sqrt{\mu/r_p}$。对于地球：$\sqrt{398\,600/6378} = 7.91\ \mathrm{km/s}$。对于在云顶处飞越的木星，同一公式给出$42\ \mathrm{km/s}$——这就是木星成为太阳系“大加速器”的原因。
:::

::: exercise 设计：火星采样返回时间线 {level=3}
只用霍曼转移以及共面圆轨道，(a) 画出一个离开地球、在火星采集样品并返回的任务的时间线，给出去程和返程的飞行时间以及最短停留时间；(b) 估算以下各项的总$\Delta v$：从$300\ \mathrm{km}$出发离开地球，在火星捕获进入近拱点高度$300\ \mathrm{km}$、$e = 0.8$的椭圆轨道，从该轨道出发返回地球，以及在地球直接再入大气（无捕获变轨）；(c) 列出这一理想化方案忽略的三种效应，并说明每一种使答案朝哪个方向变化。
::: solution
(a) 去程$258.8\ \mathrm{d}$；停留至少$454.7\ \mathrm{d}$（等待返回几何构型的时间）；返程$258.8\ \mathrm{d}$；总计约$972\ \mathrm{d}$。每次出发还必须等待相位角：去程为$44.3^\circ$（火星在前）；返程时地球落后火星$75.1^\circ$。
(b) 离开地球$3.590\ \mathrm{km/s}$（[[#ex-departure]]）；在火星捕获进入$e = 0.8$的椭圆$0.927\ \mathrm{km/s}$（[[#ex-capture]]）；从同一椭圆出发、回到$v_\infty = 2.648\ \mathrm{km/s}$，由对称性再需$0.927\ \mathrm{km/s}$；在地球再入无需推进（防热罩耗散$v_\infty = 2.94\ \mathrm{km/s}$以及落向地球的能量，到达速度约$11.3\ \mathrm{km/s}$）。总推进$\Delta v \approx 5.44\ \mathrm{km/s}$，不计在火星着陆和从火星上升，而后两者在真实的采样返回中占主导。
(c) 火星偏心且倾斜的轨道（使$v_\infty$随窗口不同变化多达几百米每秒，增减均有可能，并增加轨道面改变的代价）；在可行发射日期时行星的实际位置（真正的最优解是一个并不恰好是霍曼转移的兰伯特转移，通常$C_3$略高，但有时飞行时间更短）；出发时的有限推力和重力损失（使$\Delta v$增加百分之几）。真实的火星采样返回架构还包括火星轨道上的交会（[[orbital-mechanics/relative-motion-rendezvous]]）——这提醒我们，拼接圆锥曲线法能确定任务规模，但不能完成任务设计。
