运载火箭很少把卫星恰好送到它需要去的地方。地球静止卫星被释放到一条狭长的转移轨道上，必须抬高近地点并消除轨道倾角；载人飞船必须爬升到空间站的高度，并与空间站同时到达；对地观测卫星必须多年抵抗大气阻力以保持轨道。所有这些都是**轨道机动**：为改变轨道而有意施加的速度变化。其“货币”是速度增量$\Delta v$，因为通过火箭方程，$\Delta v$确定了推进剂质量，而推进剂质量正是航天器设计者最负担不起的东西。本章从[[orbital-mechanics/two-body-problem]]的二体结果出发，建立经典的机动：变轨的**脉冲**模型，为什么变轨最好在航天器最快的地方进行，圆轨道之间的**霍曼**转移和**双椭圆**转移，**轨道面改变**及其与转移的组合，以及调整时间而非形状的**调相**机动。由此得到的数字——从低轨道到地球静止轨道高度约$3.9\ \mathrm{km/s}$，再加上消除佛罗里达发射的轨道倾角所需的$0.4\ \mathrm{km/s}$——是每项任务推进剂预算的骨架。

## 脉冲近似与火箭方程 {#sec-impulsive}

化学火箭发动机工作几秒到几分钟，而轨道周期以小时计。因此把一次变轨看成一个**脉冲**是极好的近似：速度瞬时改变$\Delta\mathbf{v}$，位置不变。变轨前后的轨道是在变轨点相交的两条圆锥曲线；新轨道由新的状态矢量按[[orbital-mechanics/orbital-elements]]中的方法求出。

$\Delta v$的代价是推进剂。对于有效排气速度为$c = I_{sp}\,g_0$的火箭（$I_{sp}$为以秒计的比冲，$g_0 = 9.806\,65\ \mathrm{m/s^2}$），[[propulsion/rocket-fundamentals]]中推导的火箭方程给出
$$
\Delta v = I_{sp}\,g_0\ln\frac{m_0}{m_f}, \qquad \frac{m_p}{m_0} = 1 - e^{-\Delta v/(I_{sp}g_0)},
$$ {#eq-rocket}
其中$m_0$和$m_f$是变轨前后的质量，$m_p = m_0 - m_f$是消耗的推进剂。指数函数是一种“暴政”：比冲$I_{sp} \approx 320\ \mathrm{s}$的可贮存双组元发动机的$c = 3.14\ \mathrm{km/s}$，所以等于$c$的$\Delta v$要消耗初始质量的$63\,\%$。$\Delta v$预算沿任务累加（火箭方程对$\Delta v$可加，而对推进剂不可加），这就是它成为任务设计语言的原因。

对于小推力电推进，脉冲模型失效，其变轨持续数周；轨迹缓慢地螺旋展开，圆轨道之间转移所需的$\Delta v$趋近于圆轨道速度之差$\lvert v_{c1} - v_{c2}\rvert$，比脉冲变轨的代价大。对于大推力变轨，其精度在**有限推力损失**以内，对持续时间占轨道周期相当比例的变轨，这一损失为百分之几。

## 在哪里变轨：奥伯特效应 {#sec-oberth}

::: proposition 脉冲引起的能量变化 {#prop-oberth}
对以速度$\mathbf{v}$运动的航天器施加脉冲$\Delta\mathbf{v}$，其比机械能的变化为
$$
\Delta\varepsilon = \mathbf{v}\cdot\Delta\mathbf{v} + \tfrac12\Delta v^2.
$$
对于给定大小的$\Delta v$，当脉冲沿速度方向且航天器运动最快时——即在近拱点——能量增益最大。
:::

::: proof
脉冲期间位置不变，所以势能$-\mu/r$不变；只有动能变化：$\Delta\varepsilon = \tfrac12\lVert\mathbf{v} + \Delta\mathbf{v}\rVert^2 - \tfrac12v^2 = \mathbf{v}\cdot\Delta\mathbf{v} + \tfrac12\Delta v^2$。对固定的$\Delta v$，$\mathbf{v}\cdot\Delta\mathbf{v} \le v\,\Delta v$，两者平行时取等号，而$v$在近拱点最大。
:::

这就是**奥伯特效应**（Oberth effect）。这里能量并非在朴素意义上守恒：在引力势阱深处以高速喷出的排气带走的动能比在别处少，留给飞行器的就更多。在实践中这意味着：在近拱点变轨以抬高远拱点，在远拱点变轨以抬高近拱点（那里轨道速度是水平的，切向变轨只改变对面的拱点），以及尽可能在低处变轨以逃离行星。

::: example 同一次变轨在近地点与远地点 {#ex-oberth}
航天器位于$r_p = 6628\ \mathrm{km}$、$r_a = 42\,164\ \mathrm{km}$的地球同步转移轨道上。比较在近地点进行$0.100\ \mathrm{km/s}$切向变轨与在远地点进行同样变轨的效果。
::: solution
由[[orbital-mechanics/two-body-problem]]，$a = 24\,396\ \mathrm{km}$，$\varepsilon = -8.1694\ \mathrm{km^2/s^2}$，$v_p = 10.195\ \mathrm{km/s}$，$v_a = 1.6026\ \mathrm{km/s}$。

在近地点：$\Delta\varepsilon = 10.195 \times 0.1 + 0.005 = 1.0245\ \mathrm{km^2/s^2}$，新的$\varepsilon = -7.1449$，$a = 27\,894\ \mathrm{km}$，所以远地点升到$2a - r_p = 49\,160\ \mathrm{km}$——升高$6996\ \mathrm{km}$。

在远地点：$\Delta\varepsilon = 1.6026 \times 0.1 + 0.005 = 0.1653$，新的$a = 24\,900\ \mathrm{km}$，所以近地点升到$2a - r_a = 7635\ \mathrm{km}$——升高$1007\ \mathrm{km}$。

**校核：**能量增益之比等于速度之比$6.2$，且每次变轨只移动*对面的*拱点，拱点处的切向脉冲理应如此（变轨点仍是新轨道的拱点）。近地点变轨是抬高远地点的高效方法；远地点变轨是抬高近地点的高效方法。
:::
:::

## 霍曼转移 {#sec-hohmann}

最重要的机动是在半径为$r_1$和$r_2 > r_1$的两条共面圆轨道之间转移航天器。**霍曼转移**使用一个与两圆都相切的椭圆：其近拱点在内轨道上，远拱点在外轨道上。需要两次切向变轨——一次进入椭圆，一次离开椭圆。

::: proposition 霍曼转移 {#prop-hohmann}
沿与两圆都相切的半椭圆，从半径为$r_1$的圆轨道转移到半径为$r_2 > r_1$的共面圆轨道，两次脉冲和转移时间为
$$
\begin{aligned}
\Delta v_1 &= \sqrt{\frac{\mu}{r_1}}\left(\sqrt{\frac{2r_2}{r_1 + r_2}} - 1\right), \qquad
\Delta v_2 = \sqrt{\frac{\mu}{r_2}}\left(1 - \sqrt{\frac{2r_1}{r_1 + r_2}}\right),\\
t_H &= \pi\sqrt{\frac{(r_1 + r_2)^3}{8\mu}}.
\end{aligned}
$$ {#eq-hohmann}
用$R = r_2/r_1$和$v_{c1} = \sqrt{\mu/r_1}$表示，总量为
$$
\frac{\Delta v_H}{v_{c1}} = \sqrt{\frac{2R}{1+R}} - 1 + \frac{1}{\sqrt R} - \sqrt{\frac{2}{R(1+R)}}.
$$ {#eq-hohmann-norm}
:::

::: proof
转移椭圆的$r_p = r_1$，$r_a = r_2$，所以$a_t = (r_1 + r_2)/2$。由活力公式，它在近拱点的速度为$v_p = \sqrt{\mu(2/r_1 - 2/(r_1 + r_2))} = \sqrt{\mu/r_1}\sqrt{2r_2/(r_1+r_2)}$，在远拱点为$v_a = \sqrt{\mu/r_2}\sqrt{2r_1/(r_1+r_2)}$。在两个拱点处速度都是水平的，圆轨道速度也是如此，所以每次变轨都是切向的，其大小为速度之差：$\Delta v_1 = v_p - \sqrt{\mu/r_1}$，$\Delta v_2 = \sqrt{\mu/r_2} - v_a$。转移走过半个椭圆，用时为其周期的一半$\pi\sqrt{a_t^3/\mu}$。除以$v_{c1}$并把$\sqrt{\mu/r_2}$写成$v_{c1}/\sqrt R$，即得[[#eq-hohmann-norm]]。推导假设了脉冲变轨、共面圆轨道和二体运动；把变轨反过来，同样的公式适用于向内转移。
:::

在两条共面圆轨道之间使用两次脉冲的所有转移中，霍曼转移所需的总$\Delta v$最小；这一点直到霍曼提出它几十年后才得到严格证明（经典证明利用每次脉冲所能产生的能量和角动量变化，例如见 Prussing 和 Conway 的书）。用*三次*脉冲，答案就变了，如下一节所示。

归一化代价[[#eq-hohmann-norm]]并不会无限增长：它在$R = 15.58$处升到最大值$0.536$，然后*下降*，当$R \to \infty$时趋于$\sqrt2 - 1 = 0.414$——即逃逸的代价。非常遥远的圆轨道速度很慢，所以第二次变轨变得很小。

::: example 从近地轨道到地球静止轨道高度 {#ex-hohmann}
求从$300\ \mathrm{km}$高度的圆形停泊轨道到同一平面内地球静止轨道半径$42\,164\ \mathrm{km}$的霍曼转移：两次变轨、总量和转移时间。
::: solution
$r_1 = 6678\ \mathrm{km}$，$r_2 = 42\,164\ \mathrm{km}$，$a_t = 24\,421\ \mathrm{km}$。各速度：
$$
v_{c1} = 7.7258, \quad v_p = 10.1516, \quad v_a = 1.6078, \quad v_{c2} = 3.0747\ \mathrm{km/s}.
$$
$\Delta v_1 = 10.1516 - 7.7258 = 2.4258\ \mathrm{km/s}$，$\Delta v_2 = 3.0747 - 1.6078 = 1.4668\ \mathrm{km/s}$，总量$3.893\ \mathrm{km/s}$。转移时间$t_H = \pi\sqrt{24\,421^3/398\,600} = 18\,990\ \mathrm{s} = 5.28\ \mathrm{h}$。

**校核：**取$R = 6.314$，[[#eq-hohmann-norm]]给出$0.5038$，$0.5038 \times 7.7258 = 3.893\ \mathrm{km/s}$。两次变轨都增加速度，但最终的轨道速度（$3.07\ \mathrm{km/s}$）却小于初始速度（$7.73\ \mathrm{km/s}$）：航天器在爬升中减速，以动能换取势能。共面转移只有从赤道发射场出发才可能；我们在[[#ex-gto-plane]]中加上轨道面改变。
:::
:::

## 双椭圆转移 {#sec-bielliptic}

**双椭圆转移**使用两个半椭圆和三次变轨。第一次变轨在$r_1$处，使航天器进入远拱点位于中间半径$r_b > r_2$的椭圆；第二次变轨在$r_b$处，把近拱点抬高到$r_2$；第三次变轨在$r_2$处，使航天器减速进入圆轨道。它先*越过*目标，再折返回来。

记$R = r_2/r_1$，$B = r_b/r_1$，在每次变轨处应用活力公式得
$$
\frac{\Delta v_{BE}}{v_{c1}} = \sqrt{\frac{2B}{1+B}} - 1 + \sqrt{\frac2B}\left(\sqrt{\frac{R}{R+B}} - \sqrt{\frac{1}{1+B}}\right) + \sqrt{\frac{2B}{R(R+B)}} - \frac{1}{\sqrt R}.
$$ {#eq-bielliptic}
中间一次变轨在轨迹上最慢的点进行，那里改变近拱点很便宜；第一次变轨则利用了奥伯特效应。在$B \to \infty$的极限下，前两次变轨变成逃逸到无穷远和从无穷远返回，总量为$(\sqrt2 - 1)(1 + 1/\sqrt R)\,v_{c1}$。把这一极限与[[#eq-hohmann-norm]]比较，并把完整公式与霍曼转移的代价比较，得到经典结论：

- 对$R < 11.94$，霍曼转移比任何双椭圆转移都省；
- 对$11.94 < R < 15.58$，若$r_b$足够大，双椭圆转移更省；
- 对$R > 15.58$，每一个$r_b > r_2$的双椭圆转移都比霍曼转移省。

节省很小——至多百分之几——而转移时间长得多，因此双椭圆转移很少实际采用。它真正的启示是：霍曼转移只在其所属的那一类转移中是最优的。

::: example 半径比 15：霍曼转移与双椭圆转移 {#ex-bielliptic}
对$R = r_2/r_1 = 15$，把霍曼转移与经过$r_b = 40\,r_1$的双椭圆转移进行比较。从$300\ \mathrm{km}$停泊轨道（$r_1 = 6678\ \mathrm{km}$）出发，以 km/s 给出代价并给出转移时间。
::: solution
霍曼转移，由[[#eq-hohmann-norm]]取$R = 15$：
$$
\frac{\Delta v_H}{v_{c1}} = \sqrt{1.875} - 1 + 0.25820 - \sqrt{2/240} = 0.36931 + 0.25820 - 0.09129 = 0.5362.
$$
双椭圆转移，由[[#eq-bielliptic]]取$B = 40$：
$$
\frac{\Delta v_{BE}}{v_{c1}} = \underbrace{0.39686}_{\text{第1次变轨}} + \underbrace{0.22361\,(0.52223 - 0.15617)}_{=\,0.08186,\ \text{第2次变轨}} + \underbrace{0.31139 - 0.25820}_{=\,0.05319,\ \text{第3次变轨}} = 0.5319.
$$
取$v_{c1} = 7.7258\ \mathrm{km/s}$：霍曼转移$4.143\ \mathrm{km/s}$，双椭圆转移$4.109\ \mathrm{km/s}$，节省$33\ \mathrm{m/s}$（$0.8\,\%$）。

时间：霍曼转移$\pi\sqrt{(8\,r_1)^3/\mu} = 17.1\ \mathrm{h}$；双椭圆转移$\pi\sqrt{(20.5\,r_1)^3/\mu} + \pi\sqrt{(27.5\,r_1)^3/\mu} = 178.8\ \mathrm{h}$，长十倍以上。

**校核：**$R = 15$位于$11.94$和$15.58$之间，所以只有$r_b$足够大时双椭圆转移才占优；解$\Delta v_{BE} = \Delta v_H$得盈亏平衡点$r_b = 18.2\,r_1$，而$40\,r_1$超过了它。令$r_b \to \infty$可把代价降到$0.5212\,v_{c1}$，但时间趋于无穷。$0.8\,\%$的节省很难证明一次穿越辐射带、历时一周的转移是值得的。
:::

## 轨道面改变 {#sec-plane-change}

改变轨道平面，就是在新旧轨道的公共点上转动速度矢量，并可能同时改变其长度。

::: proposition 轨道面改变的代价 {#prop-plane-change}
使速度转过角度$\Delta i$、同时使速度大小从$v_1$变为$v_2$的脉冲，其大小为
$$
\Delta v = \sqrt{v_1^2 + v_2^2 - 2v_1v_2\cos\Delta i},
$$ {#eq-combined}
当速度大小$v$不变时，化为
$$
\Delta v = 2v\sin\frac{\Delta i}{2}.
$$ {#eq-plane}
组合变轨的代价永远不超过分别进行同样变化的代价$\lvert v_2 - v_1\rvert + 2\min(v_1, v_2)\sin(\Delta i/2)$。
:::

::: proof
$\Delta\mathbf{v} = \mathbf{v}_2 - \mathbf{v}_1$，在由$\mathbf{v}_1$、$\mathbf{v}_2$和$\Delta\mathbf{v}$构成的三角形（前两者夹角为$\Delta i$）中应用余弦定理即得[[#eq-combined]]。取$v_1 = v_2 = v$，$\Delta v^2 = 2v^2(1 - \cos\Delta i) = 4v^2\sin^2(\Delta i/2)$。对于分别进行的策略，取$v_1 \le v_2$并在较低速度时转动：先$\mathbf{v}_1 \to \mathbf{v}_1'$（长度仍为$v_1$，方向为$\mathbf{v}_2$的方向），再$\mathbf{v}_1' \to \mathbf{v}_2$（纯粹加长）。由三角不等式，$\lVert\mathbf{v}_2 - \mathbf{v}_1\rVert \le \lVert\mathbf{v}_1' - \mathbf{v}_1\rVert + \lVert\mathbf{v}_2 - \mathbf{v}_1'\rVert = 2v_1\sin(\Delta i/2) + (v_2 - v_1)$，仅当$\Delta i = 0$时取等号。变轨必须在两条轨道相交处——两个平面的节线上——进行，否则轨道面的改变量会小于预期。
:::

轨道面改变代价高昂：速度不变时转过$60^\circ$的代价与轨道速度本身相当，即使在低轨道上改变$10^\circ$也要$1.35\ \mathrm{km/s}$。由[[#prop-plane-change]]得出两条规则。第一，在速度最低处改变轨道面——在远拱点，或在转移之后的高轨道上。第二，把轨道面改变与速度改变合并在一次变轨中。

::: example 带轨道面改变的地球静止轨道转移 {#ex-gto-plane}
一颗从北纬$28.5^\circ$向正东发射的卫星位于轨道倾角为$28.5^\circ$的$300\ \mathrm{km}$圆形停泊轨道上。比较到达赤道地球静止轨道的三种方式：(a) 霍曼转移，然后在地球静止轨道半径处单独改变轨道面；(b) 霍曼转移，把全部轨道面改变与远地点变轨合并；(c) 分配轨道面改变，近地点$2.2^\circ$，远地点$26.3^\circ$。若卫星以$I_{sp} = 320\ \mathrm{s}$自行完成远地点变轨，对于策略 (b)，推进剂占其在转移轨道上质量的多大比例？
::: solution
由[[#ex-hohmann]]得各速度：$v_{c1} = 7.7258$，$v_p = 10.1516$，$v_a = 1.6078$，$v_{c2} = 3.0747\ \mathrm{km/s}$。

(a) $\Delta v_1 = 2.4258$，$\Delta v_2 = 1.4668$，在地球静止轨道处改变轨道面$2 \times 3.0747\sin 14.25^\circ = 1.5137$：总量$5.406\ \mathrm{km/s}$。

(b) 由[[#eq-combined]]得远地点变轨：$\sqrt{1.6078^2 + 3.0747^2 - 2(1.6078)(3.0747)\cos 28.5^\circ} = 1.8302\ \mathrm{km/s}$；总量$2.4258 + 1.8302 = 4.256\ \mathrm{km/s}$。

(c) 近地点变轨转过$2.2^\circ$：$\sqrt{7.7258^2 + 10.1516^2 - 2(7.7258)(10.1516)\cos 2.2^\circ} = 2.4495$；远地点变轨转过$26.3^\circ$：$1.7819$；总量$4.231\ \mathrm{km/s}$。

$1.830\ \mathrm{km/s}$远地点变轨的推进剂比例：$1 - \exp(-1830/(320 \times 9.80665)) = 0.442$。

**校核：**合并比分别进行节省$1.15\ \mathrm{km/s}$，因为在远地点转移速度和地球静止轨道速度都很小，而变轨同时*转动并加长*了速度。再分配又节省$25\ \mathrm{m/s}$：在近地点转过一个小角度几乎不增加代价（那里速度本来就要大幅加长，一个小的侧向分量增加不了多少）。$0.442$的推进剂比例就是从高纬度发射的地球静止卫星要携带接近其转移轨道质量一半的推进剂的原因——也是几乎无需改变轨道面的近赤道发射在这一市场上具有吸引力的原因。
:::

::: warning 把指向不同方向的速度相加 {#warn-vector}
$\Delta v$是矢量差的大小$\lVert\mathbf{v}_\text{后} - \mathbf{v}_\text{前}\rVert$。速度大小相减$v_\text{后} - v_\text{前}$只对不转动速度方向的切向变轨才正确。典型错误有：把轨道面改变与远地点变轨的合并计算成$v_{c2} - v_a = 1.47\ \mathrm{km/s}$（忘记了转动，转动使它增加到$1.83$）；把轨道面改变算成$v\,\Delta i$（小角度近似，在$60^\circ$时低$8\,\%$）；以及在偏离节线处改变轨道面，那样轨道倾角的改变量小于预期，还会移动节点。每次都要画出速度三角形。
:::

## 调相机动 {#sec-phasing}

对于交会，到达正确的*轨道*还不够；航天器必须在正确的时间到达轨道上正确的*位置*。**调相机动**调整沿轨道的位置。一个在同一圆轨道上落后目标角度$\Delta\phi$的航天器，进行一次切向反向变轨，进入一个周期较短、略小的椭圆；在调相轨道上运行$k$圈后，它回到变轨点，追上了$\Delta\phi$，再进行一次大小相等的正向变轨，恢复圆轨道。调相轨道的周期必须为
$$
T_\text{ph} = T\left(1 - \frac{\Delta\phi}{2\pi k}\right),
$$ {#eq-phasing}
其中$\Delta\phi$以弧度计（若航天器在前方而必须等待，则取加号）。半长轴由周期得出，变轨量由活力公式得出。注意这个违反直觉的方向：要追上，就要减速——落入更低、更快的轨道；要退后，就要加速。把机动分散到更多圈上可以减小$\Delta v$，代价是时间。

::: example 追赶空间站 {#ex-phasing}
一艘飞船和一个空间站位于同一条$400\ \mathrm{km}$高度的圆轨道上（$T = 5553.5\ \mathrm{s}$）；空间站在前方$10^\circ$。设计一个用一圈消除差距的调相机动，以及另一个用三圈的。
::: solution
一圈：$T_\text{ph} = 5553.5\,(1 - 10/360) = 5399.2\ \mathrm{s}$，所以$a_\text{ph} = \left[\mu(T_\text{ph}/2\pi)^2\right]^{1/3} = 6651.9\ \mathrm{km}$。变轨点（$r = 6778\ \mathrm{km}$）成为远拱点，近拱点位于$2a_\text{ph} - 6778 = 6525.8\ \mathrm{km}$——高度$148\ \mathrm{km}$。速度：圆轨道$7.6686$，调相轨道远拱点$\sqrt{\mu(2/6778 - 1/6651.9)} = 7.5956\ \mathrm{km/s}$，所以每次变轨$73.0\ \mathrm{m/s}$，总量$146\ \mathrm{m/s}$。

三圈：$T_\text{ph} = 5553.5\,(1 - 10/1080) = 5502.0\ \mathrm{s}$，$a_\text{ph} = 6736.1\ \mathrm{km}$，近拱点高度$316\ \mathrm{km}$，总$\Delta v = 47.8\ \mathrm{m/s}$。

**校核：**一圈的方案下降到$148\ \mathrm{km}$，那里大气阻力很严重；无论其$\Delta v$多少，它都是不可接受的。三圈的代价只有三分之一，而且近地点是安全的。真实的交会任务正是出于这些原因把调相分散到许多圈上。
:::
:::

::: quiz
一个圆轨道上的航天器短暂地**向后**（逆着速度）点火。下列哪些说法正确？
- [x] 变轨点成为新轨道的远拱点。
- [x] 其轨道周期减小。
- [ ] 半圈之后它比变轨前运动得更慢。
- [x] 如果目标原本在原轨道上紧靠它的前方，它在随后几圈中将倾向于追近目标。
::: solution
反向变轨降低能量，所以$a$和周期减小；变轨点处的速度仍是水平的，所以变轨点是拱点，而由于那里的速度现在低于圆轨道速度，它是远拱点。半圈之后航天器位于近拱点，比在原圆轨道上*更低*因而*更快*。周期更短，它更快地完成每一圈，从而追近原轨道上的目标——这是调相的基础。（在不到一圈的时间内，相对运动更为微妙；参见[[orbital-mechanics/relative-motion-rendezvous]]。）
:::
:::

::: history
德国土木工程师瓦尔特·霍曼（Walter Hohmann）在《天体的可达性》（*Die Erreichbarkeit der Himmelskörper*，慕尼黑，1925年）中分析了到达其他天体所需的能量，证明在双脉冲情形下，沿与出发轨道和到达轨道都相切的椭圆转移使推进剂最省——这就是今天以他命名的机动。赫尔曼·奥伯特（Hermann Oberth）的《飞向行星际空间的火箭》（*Die Rakete zu den Planetenräumen*，1923年）及其后来的工作阐述了在引力势阱深处高速变轨的优势，即今天所说的奥伯特效应。三脉冲的双椭圆转移通常归功于阿里·施特恩费尔德（Ary Sternfeld），他1934年发表在巴黎科学院《报告》（*Comptes rendus*）上的短文研究了越过目标轨道的转移。关于这些转移最优性的论断，直到20世纪60年代随着脉冲轨迹最优控制理论的发展才得到严格论证。
:::

## 后续内容 {#sec-next}

调相使追踪航天器到达目标几十千米以内；交会的最后阶段需要[[orbital-mechanics/relative-motion-rendezvous]]中的相对运动方程。*行星*轨道之间的霍曼转移与双曲线出发和到达相结合，是[[orbital-mechanics/interplanetary-trajectories]]的主题，奥伯特效应在那里的出发变轨中再次出现。正是[[orbital-mechanics/perturbations]]中的摄动使位置保持机动成为必要。

::: summary
- 大推力变轨用脉冲建模；火箭方程$m_p/m_0 = 1 - e^{-\Delta v/(I_{sp}g_0)}$把$\Delta v$换算为推进剂，$\Delta v$预算可以累加。
- $\Delta\varepsilon = \mathbf{v}\cdot\Delta\mathbf{v} + \tfrac12\Delta v^2$：在速度最高处沿速度方向变轨（奥伯特效应）。拱点处的切向变轨只移动对面的拱点。
- 霍曼转移：两次切向变轨，$\Delta v_1 = v_{c1}(\sqrt{2R/(1+R)} - 1)$，$\Delta v_2 = v_{c2}(1 - \sqrt{2/(1+R)})$，时间$\pi\sqrt{a_t^3/\mu}$；在双脉冲共面转移中是最优的。其归一化代价在$R = 15.58$处达到峰值$0.536$。
- 双椭圆转移越过目标；当$R > 11.94$且$r_b$很大时，以及当$R > 15.58$时对任何$r_b > r_2$，它都胜过霍曼转移——例如$R = 15$、$r_b = 40r_1$时为$0.532$对$0.536$——但时间代价很大。
- 轨道面改变的代价为$2v\sin(\Delta i/2)$：在速度最低处进行，并用$\Delta v = \sqrt{v_1^2 + v_2^2 - 2v_1v_2\cos\Delta i}$与速度改变合并。
- 调相：要追上，就减速进入周期更短的轨道；$T_\text{ph} = T(1 - \Delta\phi/2\pi k)$；圈数越多，$\Delta v$越小。
:::

## 习题

::: exercise 小型霍曼转移 {level=1 check="0.274"}
求从$300\ \mathrm{km}$高度的圆轨道到$800\ \mathrm{km}$高度的圆轨道的霍曼转移的总$\Delta v$。（以 km/s 为单位输入总量，保留三位有效数字。）
::: solution
$r_1 = 6678$，$r_2 = 7178$，$a_t = 6928\ \mathrm{km}$。$\Delta v_1 = \sqrt{\mu(2/6678 - 1/6928)} - \sqrt{\mu/6678} = 7.8640 - 7.7258 = 0.1382\ \mathrm{km/s}$；$\Delta v_2 = \sqrt{\mu/7178} - \sqrt{\mu(2/7178 - 1/6928)} = 7.4519 - 7.3162 = 0.1357\ \mathrm{km/s}$。总量$0.274\ \mathrm{km/s}$，与半径变化较小时预期的一样，接近圆轨道速度之差（$0.274$）。转移时间$47.8\ \mathrm{min}$。
:::

::: exercise 在地球静止轨道半径处改变轨道面 {level=1 check="0.536"}

::: exercise 一次变轨所需的推进剂 {level=1 check="399"}
一个$1000\ \mathrm{kg}$的航天器必须用比冲$I_{sp} = 300\ \mathrm{s}$的发动机进行一次$1.50\ \mathrm{km/s}$的变轨。它消耗多少推进剂？（以 kg 为单位输入质量，保留三位有效数字。）

::: exercise 地球静止卫星的定点位置迁移 {level=2 check="13.7"}
一颗地球静止卫星必须在调相轨道上运行五圈，沿地球静止轨道弧段向东（前方）移动$12^\circ$。求两次变轨的总$\Delta v$。（以 m/s 为单位输入总量，保留三位有效数字。）
::: solution
要向前移动，它的平均速度必须更快：需要周期更短的调相轨道。$T_\text{ph} = 86\,164\,(1 - 12/(360 \times 5)) = 85\,589.6\ \mathrm{s}$，$a_\text{ph} = \left[\mu (T_\text{ph}/2\pi)^2\right]^{1/3} = 41\,976.5\ \mathrm{km}$。$42\,164\ \mathrm{km}$处的变轨点成为远拱点；那里的速度为$\sqrt{\mu(2/42\,164 - 1/41\,976.5)} = 3.06779\ \mathrm{km/s}$，而原来为$3.07466$，反向变轨$6.87\ \mathrm{m/s}$，结束时再正向重复一次：总量$13.7\ \mathrm{m/s}$。（地球静止卫星的位置保持预算为每年几十米每秒，所以这样的迁移是负担得起的。）

::: exercise 抬高远地点或近地点 {level=2 check="6.94"}
利用[[#ex-oberth]]的结果，在近地点进行$0.1\ \mathrm{km/s}$变轨使对面拱点升高的量是在远地点进行同样变轨时的多少倍？用能量和角动量解释这一结果。（输入两个升高量之比，保留三位有效数字。）
::: solution
近地点变轨：远地点升高$49\,160 - 42\,164 = 6996\ \mathrm{km}$；远地点变轨：近地点升高$7635 - 6628 = 1007\ \mathrm{km}$；比值为$6.94$。能量变化为$v\,\Delta v$，在近地点大六倍。对面拱点的变化取决于$a$（能量）的变化，*以及*力臂：抬高狭长椭圆的远端拱点，每千米所需的能量比抬高近端拱点少，这解释了其余的差别。

::: exercise 为什么切向到达很重要 {level=2 check="1.044"}
比较从半径为$r_1$的圆轨道到半径为$r_2 = 4r_1$的圆轨道的两种方式：(a) 霍曼转移，由[[#eq-hohmann-norm]]；(b) 第一次切向变轨达到逃逸速度，然后当航天器在所得抛物线上到达$r_2$时进行第二次变轨使轨道圆化。（以$v_{c1}$的倍数输入 (b) 的代价，保留四位有效数字。）
::: solution
(a) $R = 4$：$\sqrt{8/5} - 1 + \tfrac12 - \sqrt{2/20} = 0.26491 + 0.5 - 0.31623 = 0.4487\,v_{c1}$。
(b) 第一次变轨$(\sqrt2 - 1)v_{c1} = 0.4142\,v_{c1}$。在抛物线上$h = \sqrt{2\mu r_1}$；在$r_2 = 4r_1$处速度为$\sqrt{2\mu/r_2} = 0.7071\,v_{c1}$，横向分量$h/r_2 = \sqrt2\,v_{c1}/4 = 0.3536\,v_{c1}$，径向分量$\sqrt{0.5 - 0.125}\,v_{c1} = 0.6124\,v_{c1}$。那里的圆轨道速度为$0.5\,v_{c1}$，水平方向，所以第二次变轨为$\sqrt{0.6124^2 + (0.5 - 0.3536)^2}\,v_{c1} = 0.6296\,v_{c1}$。总量$1.044\,v_{c1}$——是霍曼转移代价的两倍多。带着必须抵消的大径向速度到达是非常浪费的；切向出发和切向到达正是霍曼几何的要点。
:::

::: exercise 霍曼转移代价的峰值位置 {level=3 check="15.58"}
把[[#eq-hohmann-norm]]对$R$求导，证明最大值出现在$R^3 - 15R^2 - 9R - 1 = 0$的实根处，并求出它。（输入$R$，保留四位有效数字。）
::: solution
记$f(R) = \sqrt{2R/(1+R)} - 1 + R^{-1/2} - \sqrt2\,[R(1+R)]^{-1/2}$。于是
$$
f'(R) = \frac{1}{\sqrt{2R}\,(1+R)^{3/2}} - \frac{1}{2R^{3/2}} + \frac{\sqrt2\,(1 + 2R)}{2[R(1+R)]^{3/2}}.
$$
乘以$2R^{3/2}(1+R)^{3/2}$：$\sqrt2\,R - (1+R)^{3/2} + \sqrt2\,(1 + 2R) = 0$，即$\sqrt2\,(1 + 3R) = (1+R)^{3/2}$。平方得$2(1 + 3R)^2 = (1+R)^3$，展开即为$R^3 - 15R^2 - 9R - 1 = 0$。其唯一的正实根（从$R = 15$出发用牛顿法）为$R = 15.58$，此处$f = 0.5363$。平方可能引入增根；由于两边都为正，这个根满足未平方的方程。
:::

::: exercise 轨道面改变的最优分配 {level=3 check="2.2"}
对[[#ex-gto-plane]]中的转移，设$s$为在近地点完成的轨道面改变，$28.5^\circ - s$为在远地点完成的部分。写出总量$\Delta v(s)$，并用数值方法求使其最小的$s$。从物理上解释为什么最优值很小但不为零。（以度为单位输入$s$，保留一位小数。）
::: solution
$\Delta v(s) = \sqrt{v_{c1}^2 + v_p^2 - 2v_{c1}v_p\cos s} + \sqrt{v_a^2 + v_{c2}^2 - 2v_av_{c2}\cos(28.5^\circ - s)}$。逐点计算（或令$\mathrm{d}\Delta v/\mathrm{d}s = 0$并用牛顿法求解）：$\Delta v(0) = 4.2560$，$\Delta v(2^\circ) = 4.2316$，$\Delta v(2.2^\circ) = 4.2314$，$\Delta v(3^\circ) = 4.2349$——最小值在$s = 2.2^\circ$。从物理上看，在$s = 0$处，近地点变轨的$\mathrm{d}\Delta v/\mathrm{d}s$为零（在很大的同向变化上增加一个小的侧向分量，代价只是二阶的，$\propto s^2$），而远地点变轨的导数为有限的负值（在那里少转一度，节省是一阶的）。所以总应该把一部分轨道面改变移到近地点，直到那里的二阶代价赶上远地点的一阶节省为止。
:::

::: exercise 设计：离轨处置机动 {level=3}
地球静止卫星寿命终止时，必须按照国际空间碎片减缓准则的建议，被抬升到地球静止轨道弧段以上约$300\ \mathrm{km}$的处置轨道（坟墓轨道）。(a) 求霍曼转移的$\Delta v$。(b) 若卫星干质量为$2000\ \mathrm{kg}$，$I_{sp} = 290\ \mathrm{s}$，考虑到剩余推进剂的不确定性留$50\,\%$裕度，必须预留多少推进剂？(c) 讨论为什么推进剂测量是关键的不确定因素，以及近地轨道卫星能否采用同样的策略。
::: solution
(a) $r_1 = 42\,164$，$r_2 = 42\,464\ \mathrm{km}$；$R = 1.00712$。对于小变化，每次变轨约为$v_{c}\,(\Delta r/4r)$：$3.0747 \times 300/(4 \times 42\,164) = 5.47\ \mathrm{m/s}$；精确计算[[#eq-hohmann]]得$\Delta v_1 = 5.44$，$\Delta v_2 = 5.44\ \mathrm{m/s}$，总量$10.9\ \mathrm{m/s}$。
(b) 取$c = 290 \times 9.80665 = 2844\ \mathrm{m/s}$：$m_p = 2000\,(e^{10.9/2844} - 1) = 7.7\ \mathrm{kg}$；留$50\,\%$裕度，约$11.5\ \mathrm{kg}$。
(c) 失重环境下没有油量表：剩余推进剂只能通过推力器点火记录推算、由贮箱压力和温度估计，或通过加热贮箱并测量其热响应来估计，每种方法都有几千克的误差——与预留量相当，因此需要裕度。近地轨道卫星的情况不同：把它抬升开去需要多得多的$\Delta v$，而且会使它在轨道上停留非常长的时间；那里公认的策略正相反——降低近地点，使大气阻力在有限时间内把它清除（广泛采用的准则曾是25年，一些机构现在要求5年）——参见[[orbital-mechanics/perturbations]]。
:::
