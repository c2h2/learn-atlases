客机的巡航马赫数约为$0.78$–$0.85$。它的机翼是用本课程前半部分的不可压缩工具设计的，在低速下其行为与这些工具的预测一致。在巡航中则不然：在上表面加速的空气远在飞机达到声速之前就达到了声速，机翼上形成一个以激波为终结的超声速区，而在某一马赫数以上阻力急剧上升——这就是**阻力发散**，在人们理解它之前，它被称为“声障”。本章解释压缩性如何首先改变亚声速翼型流动（**普朗特-格劳特**法则及其改进），如何求出首次出现声速流动时的**临界马赫数**，在临界马赫数与阻力发散之间发生了什么，以及把阻力发散推向更高马赫数的两大设计发明：**后掠**和**超临界翼型**。

你需要用到[[fluid-mechanics/compressible-flow]]中的等熵关系式，[[aerodynamics/potential-flow]]和[[aerodynamics/thin-airfoil-theory]]中的势流与薄翼概念，以及[[aerodynamics/viscous-aerodynamics]]中的边界层。空气是$\gamma = 1.4$的完全气体；本章中$\beta$表示$\sqrt{1 - M_\infty^2}$（而不是激波角）。

## 线化位势方程

对于完全气体的定常、无旋、等熵流动，速度势$\phi$满足**全位势方程**
$$
\left(a^2 - u^2\right)\phi_{xx} - 2uv\,\phi_{xy} + \left(a^2 - v^2\right)\phi_{yy} = 0 ,
$$ {#eq-full-potential}
其中$u = \phi_x$，$v = \phi_y$，当地声速由能量方程给出，$a^2 = a_\infty^2 - \tfrac{\gamma - 1}{2}\left(u^2 + v^2 - V_\infty^2\right)$。（它就是连续方程$\nabla\cdot(\rho\nabla\phi) = 0$，其中密度已通过欧拉方程和等熵关系$dp = a^2d\rho$消去。）它是非线性的。对于小迎角的薄物体，可以把它线化。

::: proposition 线化小扰动方程 {#prop-linearised}
把速度写成自由来流加上小扰动，$u = V_\infty + u'$，$v = v'$，其中$u', v' \ll V_\infty$，扰动速度势为$\phi'$，$u' = \phi'_x$，$v' = \phi'_y$。若$M_\infty$既不接近$1$（大致$0.8 < M_\infty < 1.2$），也不很大（$M_\infty \gtrsim 5$），则在一阶近似下
$$
\left(1 - M_\infty^2\right)\phi'_{xx} + \phi'_{yy} = 0 ,
$$ {#eq-linearised}
压强系数为
$$
C_p = -\frac{2u'}{V_\infty} .
$$ {#eq-cp-linear}
:::

::: proof
把$u = V_\infty + u'$，$v = v'$代入[[#eq-full-potential]]并除以$a_\infty^2$。能量方程给出$a^2/a_\infty^2 = 1 - (\gamma - 1)M_\infty^2\left(u'/V_\infty + \tfrac12(u'^2 + v'^2)/V_\infty^2\right)$。合并各项，方程可整理为
$$
\left(1 - M_\infty^2\right)\phi'_{xx} + \phi'_{yy} = M_\infty^2\left[(\gamma + 1)\frac{u'}{V_\infty} + \ldots\right]\phi'_{xx} + M_\infty^2\left[(\gamma - 1)\frac{u'}{V_\infty} + \ldots\right]\phi'_{yy} + M_\infty^2\left[\frac{v'}{V_\infty}\left(1 + \frac{u'}{V_\infty}\right)\right]2\phi'_{xy},
$$
其中省略号表示二阶项。右端每一项都是一个扰动比与$\phi'$的二阶导数之积，因此只要$M_\infty^2(\gamma + 1)\,u'/V_\infty \ll |1 - M_\infty^2|$（在$M_\infty = 1$附近不成立）以及$M_\infty^2\,u'/V_\infty \ll 1$、$M_\infty^2\,v'/V_\infty \ll 1$（在高超声速下不成立），它就比左端相应的项小。略去它们即得[[#eq-linearised]]。对于压强，用二项式定理展开等熵关系$p/p_\infty = \left(1 - \tfrac{\gamma - 1}{2}M_\infty^2\left(\tfrac{2u'}{V_\infty} + \tfrac{u'^2 + v'^2}{V_\infty^2}\right)\right)^{\gamma/(\gamma - 1)}$，得$p/p_\infty \approx 1 - \gamma M_\infty^2u'/V_\infty$，再由$C_p = \tfrac{2}{\gamma M_\infty^2}(p/p_\infty - 1)$即得[[#eq-cp-linear]]。边界条件以同样的方式线化：在物面$y_b(x)$上$v'(x, 0) = V_\infty\,dy_b/dx$，施加在轴线上。
:::

当$M_\infty < 1$时方程是椭圆型的，像拉普拉斯方程一样——扰动向各个方向传播；当$M_\infty > 1$时它是双曲型的——一个波动方程，其特征线就是[[aerodynamics/oblique-shocks]]中的马赫线。亚声速情形可以变换为拉普拉斯方程。

## 普朗特-格劳特法则

::: theorem 普朗特-格劳特压缩性修正 {#thm-prandtl-glauert}
对于在[[#prop-linearised]]假设范围内的亚声速流中的薄翼型，自由来流马赫数为$M_\infty$时每一点的压强系数，与**同一翼型在同一迎角下**同一点的不可压缩值$C_{p,0}$之间的关系为
$$
C_p = \frac{C_{p,0}}{\sqrt{1 - M_\infty^2}} .
$$ {#eq-pg}
因此$c_l = c_{l,0}/\sqrt{1 - M_\infty^2}$，$c_m = c_{m,0}/\sqrt{1 - M_\infty^2}$：升力线斜率按同一因子增大，而气动中心仍位于四分之一弦点。
:::

::: proof
令$\beta = \sqrt{1 - M_\infty^2}$，定义新的坐标和势函数$\xi = x$，$\eta = \beta y$，$\hat\phi(\xi, \eta) = \beta\phi'(x, y)$。则$\phi'_{xx} = \hat\phi_{\xi\xi}/\beta$，$\phi'_{yy} = \beta\hat\phi_{\eta\eta}$，于是[[#eq-linearised]]成为$\beta\hat\phi_{\xi\xi} + \beta\hat\phi_{\eta\eta} = 0$：即$(\xi, \eta)$平面中的拉普拉斯方程。物面$y_b(x)$上的边界条件为$\phi'_y = V_\infty\,dy_b/dx$；由于$\phi'_y = \hat\phi_\eta$，它变为$\hat\phi_\eta = V_\infty\,dy_b/d\xi$——即变换平面中**形状相同**的物体的不可压缩条件。所以$\hat\phi$就是同一翼型的不可压缩扰动势，而扰动速度之间的关系为$u' = \phi'_x = \hat\phi_\xi/\beta = u'_0/\beta$。由[[#eq-cp-linear]]，$C_p = -2u'/V_\infty = C_{p,0}/\beta$。沿弦长对压强积分，$c_n$和$c_m$也同样乘以$1/\beta$，所以比值$c_m/c_l$不变，从而气动中心不变。假设：[[#prop-linearised]]的假设；此外，这一变换作用于线化的边界条件，即小迎角的薄物体。
:::

物理图像是：压缩性使空气在流向上变得“更硬”，因此物体的扰动向侧向传得更远（按因子$1/\beta$），流动以表面附近更大的扰动速度作出响应。在$M_\infty = 0.7$时该因子为$1.40$——低速下测得的升力曲线不经修正不能用于巡航。显然，该法则在$M_\infty \to 1$时失效，此时它预测无穷大的压强。

在更高的亚声速马赫数下，当地扰动不再很小，有两种改进与实验符合得更好。两者都是**对压强系数的修正**，结构相同（对小的$C_{p,0}$它们都退化为普朗特-格劳特法则）：
$$
\text{卡门-钱学森：}\quad C_p = \frac{C_{p,0}}{\beta + \dfrac{M_\infty^2}{1 + \beta}\,\dfrac{C_{p,0}}{2}}, \qquad
\text{莱通：}\quad C_p = \frac{C_{p,0}}{\beta + \dfrac{M_\infty^2\left(1 + \tfrac{\gamma - 1}{2}M_\infty^2\right)}{2\beta}\,C_{p,0}} .
$$ {#eq-kt-laitone}
卡门-钱学森公式（钱学森1939年，由冯·卡门的速度图法加上对等熵线的切线气体近似得到）是实践中用得最多的，特别是在面元法程序中；它在吸力峰附近与实测压强符合得更好。莱通（Laitone）公式（1951年）计入了当地马赫数的变化。对$M_\infty = 0.7$时的$C_{p,0} = -0.5$，三者分别给出$-0.70$（普朗特-格劳特）、$-0.78$（卡门-钱学森）和$-0.95$（莱通）。它们在吸力大的地方差别最大，而那里恰恰是决定临界马赫数的地方——因此预测的临界马赫数取决于所用的法则，相差百分之几。

::: example 马赫数0.6下剖面的升力 {#ex-pg-lift}
薄翼理论给出NACA 2412在$4^\circ$、不可压缩流中$c_l = 0.666$（[[aerodynamics/thin-airfoil-theory]]）。估算$M_\infty = 0.6$时的$c_l$以及该马赫数下的升力线斜率。
::: solution
$\beta = \sqrt{1 - 0.36} = 0.8$，所以$c_l = 0.666/0.8 = 0.833$，升力线斜率为$2\pi/0.8 = 7.85$每弧度（每度$0.137$）。零升迎角不变（$-2.08^\circ$）：普朗特-格劳特法则以零升点为中心缩放整条升力曲线。**合理性检验：**同一迎角下，从低速到$M = 0.6$升力增加25%，这与薄翼型的风洞数据一致；对整架飞机，同一法则（应用于有限翼展机翼公式中的剖面斜率）解释了为什么在高亚声速下升力线斜率以及阵风载荷更大。
:::
:::

## 临界马赫数

随着$M_\infty$增大，翼型上的最大当地速度——在吸力峰处——比自由来流增长得更快。在某一自由来流马赫数下，它达到当地声速。

::: definition 临界马赫数与临界压强系数 {#def-critical}
翼型（在给定迎角下）的**临界马赫数**$M_{cr}$是其表面上某处首次达到$M = 1$时的自由来流马赫数。**临界压强系数**$C_{p,cr}(M_\infty)$是在马赫数为$M_\infty$的自由来流中，当地马赫数恰为$1$的点上的压强系数。
:::

::: proposition 临界压强系数 {#prop-cpcr}
对于完全气体的等熵流动，
$$
C_{p,cr} = \frac{2}{\gamma M_\infty^2}\left[\left(\frac{1 + \tfrac{\gamma - 1}{2}M_\infty^2}{\tfrac{\gamma + 1}{2}}\right)^{\gamma/(\gamma - 1)} - 1\right].
$$ {#eq-cpcr}
它只依赖于$M_\infty$，而与翼型无关。
:::

::: proof
在边界层之外以及任何激波上游，流动是等熵的，滞止压强$p_0$处处相同，因此在当地马赫数为$M$的点上，$p/p_0 = \left(1 + \tfrac{\gamma - 1}{2}M^2\right)^{-\gamma/(\gamma - 1)}$，特别地$p/p_\infty = \left[\left(1 + \tfrac{\gamma - 1}{2}M_\infty^2\right)/\left(1 + \tfrac{\gamma - 1}{2}M^2\right)\right]^{\gamma/(\gamma - 1)}$。令$M = 1$，并利用$C_p = (p - p_\infty)/q_\infty$，其中$q_\infty = \tfrac12\rho_\infty V_\infty^2 = \tfrac12\gamma p_\infty M_\infty^2$（由$a^2 = \gamma p/\rho$），于是$C_p = \tfrac{2}{\gamma M_\infty^2}(p/p_\infty - 1)$。这就给出[[#eq-cpcr]]。假设：量热完全气体的等熵定常流动。
:::

数值：$M_\infty = 0.5$时$C_{p,cr} = -2.13$，$0.6$时$-1.29$，$0.7$时$-0.78$，$0.8$时$-0.43$，$M_\infty = 1$时为$0$。临界马赫数就在这样一点：翼型的最小压强系数按某一压缩性法则随$M_\infty$增大而绝对值增大，与下降的曲线[[#eq-cpcr]]相交。

::: algorithm 求临界马赫数 {#alg-mcr}
1. 求翼型在所需迎角下的不可压缩最小压强系数$C_{p,0,\min}$（由低速数据或面元法）。
2. 用压缩性法则——普朗特-格劳特法则[[#eq-pg]]或卡门-钱学森公式[[#eq-kt-laitone]]——对它进行缩放，得到$C_{p,\min}(M_\infty)$。
3. 对$M_\infty$求解$C_{p,\min}(M_\infty) = C_{p,cr}(M_\infty)$（用二分法，或以图解法求两条曲线的交点）。其根就是$M_{cr}$。
4. 检验吸力峰是否尖锐到使线化法则严重失准；注明所用的法则。
:::

## 超过临界：跨声速流动与阻力发散

在$M_{cr}$以上，上表面上的超声速区逐渐扩大。在其中，气流沿凸表面加速，压强持续下降；该区域以一道近乎正激波的**激波**终结，激波后的流动重新变为亚声速，压强跳升。随着$M_\infty$增大，超声速区扩大，激波增强并后移。出现两种阻力机制：激波本身的**波阻**（其熵增是一种滞止压强损失，表现为尾迹中的动量亏损），以及当穿过激波的压强跳跃对其下方的边界层而言过于陡峭时出现的**激波诱导分离**阻力。两者共同使阻力急剧上升。

**阻力发散马赫数**$M_{dd}$按惯例定义为$dc_d/dM_\infty = 0.1$时的马赫数；对常规剖面，它比$M_{cr}$高百分之几。超过阻力发散后，在流动变为完全超声速之前，阻力系数可能增大十倍。激波诱导分离还会引起非定常——**抖振**——以及俯仰力矩的变化（“马赫俯冲”，即随着压力中心后移出现的低头配平变化），这决定了运输机巡航速度的实际上限。

在初步设计中，一种广泛使用的经验估算是由梅森（Mason）推广到后掠翼的**科恩方程**（Korn equation）（《布局空气动力学》，*Configuration Aerodynamics*）：
$$
M_{dd} = \frac{\kappa_A}{\cos\Lambda} - \frac{t/c}{\cos^2\Lambda} - \frac{c_l}{10\cos^3\Lambda},
$$ {#eq-korn}
其中$t/c$是流向相对厚度，$c_l$是剖面升力系数，$\Lambda$是机翼后掠角（$\Lambda = 0$时它就是科恩原来的二维关系式$M_{dd} + c_l/10 + t/c = \kappa_A$），$\kappa_A$是“翼型技术因子”：NACA六系列剖面约为$0.87$，超临界剖面约为$0.95$。其精度在马赫数上为百分之几；它是用于选择$t/c$、$c_l$和后掠的趋势公式，不能代替跨声速计算或试验。

::: example 阻力发散与厚度 {#ex-korn}
(a) 估算无后掠、12%厚、$c_l = 0.6$的常规剖面和超临界剖面的$M_{dd}$。(b) 一个后掠$30^\circ$的运输机机翼采用超临界剖面，巡航时剖面升力系数为$0.5$。多大的相对厚度给出$M_{dd} = 0.85$？
::: solution
(a) 常规剖面：$M_{dd} = 0.87 - 0.12 - 0.06 = 0.69$。超临界剖面：$0.95 - 0.12 - 0.06 = 0.77$。在相同厚度和升力下，超临界外形带来$0.08$的马赫数增益。
(b) 由$\cos30^\circ = 0.8660$：$\kappa_A/\cos\Lambda = 1.0970$，$c_l/(10\cos^3\Lambda) = 0.5/6.495 = 0.0770$。于是$(t/c)/\cos^2\Lambda = 1.0970 - 0.0770 - 0.85 = 0.1700$，所以$t/c = 0.1700 \times 0.75 = 0.1275$，约为$12.7$%。
**合理性检验：**$M \approx 0.85$的现代运输机后掠角接近$30^\circ$，平均相对厚度为$10$–$13$%，内侧较厚（结构、燃油），外侧较薄。这个习题展示了核心的权衡：每一度后掠或每一点$M_{dd}$都要以厚度为代价，而厚度就是结构重量。
:::
:::

## 超临界翼型

常规剖面使气流在前缘附近加速到尖锐的吸力峰，随后是很长的逆压梯度；在$M_{cr}$以上，超声速区以一道强激波终结。**超临界翼型**（20世纪60年代由NASA兰利研究中心的理查德·惠特科姆（Richard Whitcomb）发展）的形状设计成**容许**超声速区存在，但使其激波保持较弱：

- **较平坦的上表面**，使超声速区较长而其中的气流加速不大；来自前缘区域的膨胀波在声速线上反射为压缩波，平缓地使气流减速，终结激波较弱（激波前的当地马赫数约为$1.2$或更低，低于会使湍流边界层分离的强度）；
- **较大的前缘半径**，以避免尖锐的吸力峰；
- **后部弯度**（后缘附近下表面呈尖凹形），使大部分升力在剖面后部、气流为亚声速的区域产生——“后加载”。

这一增益既可以用于在相同厚度下获得更高的$M_{dd}$（约$0.05$–$0.1$，参见[[#ex-korn]]），也可以用于在相同$M_{dd}$下采用更厚的剖面（机翼更轻、燃油更多、后掠更小、展弦比更大）。1980年代以来的客机大多采用第二种选择。代价是后部弯度带来的很大的低头$c_{m,ac}$，必须由平尾配平，以及后加载对边界层的敏感性。

::: quiz
在给定升力下，哪一种改变**不会**提高运输机机翼的阻力发散马赫数？
- [ ] 减小相对厚度
- [ ] 增大后掠
- [x] 增大翼载荷，使剖面升力系数升高
- [ ] 采用超临界剖面
::: solution
更高的剖面升力系数意味着更强的吸力峰以及更早、更强的激波：$M_{dd}$下降（[[#eq-korn]]中的$-c_l/10$项）。更薄的剖面、更大的后掠和超临界外形都会提高$M_{dd}$。
:::
:::

## 后掠

后掠的思想是：对于细长的后掠翼，只有自由来流**垂直于前缘**的分量决定压强分布；展向分量沿机翼滑过而不产生影响（对于无限长后掠翼上的无黏流动，这是精确的——“独立性原理”）。因此，在马赫数为$M_\infty$的气流中后掠$\Lambda$的机翼，就压缩性而言，其行为就像一个处在
$$
M_n = M_\infty\cos\Lambda
$$ {#eq-simple-sweep}
下的无后掠剖面。在$M_\infty = 0.85$、$\Lambda = 30^\circ$时，剖面感受到的是$M_n = 0.74$。**垂直于**前缘量取的剖面厚度和升力系数也比流向值大，这就是后掠形式的科恩方程中厚度项和升力项带有额外$\cos\Lambda$幂次的原因。实践中，在流动呈三维的翼根和翼尖处，$\cos\Lambda$的好处并不能完全实现，翼根和翼尖要作专门的外形设计（机身整流、翼根加厚、翼尖扭转），以使等压线保持后掠。

后掠是有代价的：在给定展长和机翼面积下，结构更长更重（沿结构量取的展长为$b/\cos\Lambda$）；升力线斜率和最大升力下降；后掠翼往往首先在副翼所在的翼尖处失速，从而引起上仰——这要通过负扭转、翼刀、前缘装置或精心的平面形状设计来处理。对于马赫数$0.78$–$0.85$的运输机，通常的折中是四分之一弦线后掠角$25$–$35^\circ$。

::: example 马赫数0.8下后掠翼的升力线斜率 {#ex-swept-slope}
一个运输机机翼$AR = 9$，半弦线后掠角$\Lambda_{c/2} = 30^\circ$，剖面斜率为$2\pi$每弧度。利用DATCOM升力线斜率公式的可压缩形式
$$
a = \frac{2\pi AR}{2 + \sqrt{AR^2\beta^2\left(1 + \tan^2\Lambda_{c/2}/\beta^2\right) + 4}},
$$
（其不可压缩形式见[[aerodynamics/finite-wings]]），求$M_\infty = 0$和$0.8$时机翼的升力线斜率，并将其增大倍数与二维普朗特-格劳特因子相比较。
::: solution
$\tan^2 30^\circ = 0.3333$。在$M_\infty = 0$，$\beta = 1$：根式为$\sqrt{81(1.3333) + 4} = \sqrt{112.0} = 10.58$，所以$a = 2\pi(9)/12.58 = 4.49$每弧度。在$M_\infty = 0.8$，$\beta^2 = 0.36$：$AR^2\beta^2(1 + \tan^2\Lambda/\beta^2) = 81(0.36 + 0.3333) = 56.16$，根式为$\sqrt{60.16} = 7.76$，$a = 56.55/9.76 = 5.80$每弧度。增大倍数为$1.29$，而剖面的普朗特-格劳特因子为$1/0.6 = 1.67$。**合理性检验：**有限翼展的后掠翼对压缩性的感受弱于其剖面，因为其升力线斜率部分受诱导迎角限制（诱导迎角不随$M$增长），也因为后掠降低了有效马赫数。29%的增大对阵风载荷仍然重要，因为阵风载荷与升力线斜率成正比。
:::
:::

::: warning 哪个马赫数，哪个系数
跨声速估算中有三个常见的失误。**在适用范围之外使用普朗特-格劳特法则：**对真实剖面，在约$M_\infty = 0.7$以上，以及在任何当地超声速的地方，线性法则低估吸力；求$M_{cr}$时用卡门-钱学森公式，在$M_{cr}$以上两者都不要用。**在后掠修正中混用流向量和法向量：**简单后掠理论使用$M\cos\Lambda$以及剖面的**法向**相对厚度和升力系数，用流向值表示分别为$(t/c)/\cos\Lambda$和$c_l/\cos^2\Lambda$。**把$M_{cr}$当作巡航极限：**运输机通常在机翼上带有弱激波、**高于**$M_{cr}$的条件下巡航；有用的极限是阻力发散和抖振，而不是声速流动的首次出现。
:::

::: application 跨声速面积律
对于$M = 1$附近的整架飞机，惠特科姆在1950年代初通过实验证明，波阻主要取决于横截面积沿纵向的分布（机身加机翼加尾翼，用垂直于飞行方向的平面截取），并在这一分布光滑时最小——这就是**面积律**。其最著名的结果是在机翼与机身连接处收腰的机身；在运输机上，同样的原理通过翼身整流罩、发动机短舱和上机身的外形设计更为隐蔽地加以应用。
:::

::: history
亚声速翼型的压缩性修正由路德维希·**普朗特**（Ludwig Prandtl）在1920年代初的讲课中提出，并由赫尔曼·**格劳特**（Hermann Glauert）在论文中给出证明（《压缩性对翼型升力的影响》，“The effect of compressibility on the lift of an aerofoil”，《皇家学会会刊》（*Proceedings of the Royal Society*），1928年）。钱学森（H. S. **Tsien**）与西奥多·**冯·卡门**（Theodore von Kármán）合作，于1939年发表了改进的公式。阿道夫·**布泽曼**（Adolf Busemann）在1935年罗马沃尔塔会议上提出后掠（针对超声速飞行）；后掠在亚声速下的好处在第二次世界大战期间在德国被认识到，并由NACA的罗伯特·T·**琼斯**（Robert T. Jones）于1945年独立发现。NASA兰利研究中心的理查德·**惠特科姆**（Richard Whitcomb）从1960年代初开始发展超临界翼型，一架装有超临界机翼的F-8于1971年3月9日在NASA飞行研究中心首飞，证实了所预测的增益。
:::

## 小结

::: summary
- 对于马赫数不太接近1的亚声速薄物体，扰动势满足$(1 - M_\infty^2)\phi'_{xx} + \phi'_{yy} = 0$，且$C_p = -2u'/V_\infty$。
- **普朗特-格劳特法则：**$C_p = C_{p,0}/\sqrt{1 - M_\infty^2}$；升力和力矩以同样方式缩放，气动中心不移动。卡门-钱学森公式和莱通公式在吸力较大时更精确。
- $C_{p,cr}(M_\infty) = \tfrac{2}{\gamma M_\infty^2}\left[\left(\tfrac{1 + 0.2M_\infty^2}{1.2}\right)^{3.5} - 1\right]$；$M_{cr}$就是缩放后的最小$C_p$与之相交处。对$C_{p,0,\min} = -1.2$：$0.575$（普朗特-格劳特），$0.553$（卡门-钱学森）。
- 在$M_{cr}$以上出现超声速区和激波；波阻和激波诱导分离导致阻力发散（$dc_d/dM = 0.1$）和抖振。
- 科恩-梅森公式：$M_{dd} = \kappa_A/\cos\Lambda - (t/c)/\cos^2\Lambda - c_l/(10\cos^3\Lambda)$，常规剖面$\kappa_A \approx 0.87$，超临界剖面$0.95$。
- 超临界剖面（平顶、大前缘半径、后部弯度）使激波保持较弱；后掠把有效马赫数降低到$M\cos\Lambda$。
:::

## 习题

::: exercise 普朗特-格劳特因子 {level=1 check="-0.700"}
翼型上某点在不可压缩流中$C_p = -0.5$。用普朗特-格劳特法则估算$M_\infty = 0.7$时同一点的$C_p$。（输入$C_p$。）
::: solution
$C_p = -0.5/\sqrt{1 - 0.49} = -0.5/0.714 = -0.700$。卡门-钱学森公式给出$-0.778$。
:::
:::

::: exercise 临界压强系数 {level=1 check="-0.779"}
求$M_\infty = 0.7$时的临界压强系数。（输入$C_{p,cr}$。）
::: solution
$C_{p,cr} = \tfrac{2}{1.4 \times 0.49}\left[\left(\tfrac{1 + 0.2 \times 0.49}{1.2}\right)^{3.5} - 1\right] = 2.915\left[(0.9150)^{3.5} - 1\right] = 2.915(0.7328 - 1) = -0.779$。
:::
:::

::: exercise 后掠翼的有效马赫数 {level=1 check="0.736"}
一个后掠$30^\circ$的机翼以$M_\infty = 0.85$飞行。按简单后掠理论，其剖面感受到的马赫数是多少？（输入$M_n$。）
::: solution
$M_n = 0.85\cos30^\circ = 0.736$。
:::
:::

::: exercise 马赫数0.7下的升力线斜率 {level=2 check="0.154"}
某薄剖面的不可压缩升力线斜率为$2\pi$每弧度。估算$M_\infty = 0.7$时的斜率。（以每度为单位输入。）
::: solution
$2\pi/\sqrt{0.51} = 8.80$每弧度$= 0.154$每度，比不可压缩的$0.110$高40%。
:::
:::

::: exercise 厚对称剖面的临界马赫数 {level=2 check="0.737"}
一个零迎角下12%厚的对称剖面$C_{p,0,\min} = -0.43$。用普朗特-格劳特法则求其临界马赫数。（输入$M_{cr}$。）
::: solution
用二分法求解$-0.43/\sqrt{1 - M^2} = C_{p,cr}(M)$：在$M = 0.73$，左端$-0.629$，右端$-0.662$；在$0.74$，左端$-0.639$，右端$-0.626$。根为$M_{cr} = 0.737$。卡门-钱学森公式给出$0.723$。
:::
:::

::: exercise 常规剖面的科恩方程 {level=2 check="0.69"}
估算$c_l = 0.6$时无后掠、12%厚的NACA六系列剖面的阻力发散马赫数。（输入$M_{dd}$。）
::: solution
$M_{dd} = 0.87 - 0.12 - 0.6/10 = 0.69$。超临界剖面（$\kappa_A = 0.95$）将给出$0.77$。
:::
:::

::: exercise 由压强系数求当地马赫数 {level=3 check="1.09"}
在$M_\infty = 0.7$的机翼上，吸力峰处的实测压强系数为$C_p = -1.0$。假设直到该点的流动是等熵的，求当地马赫数，并说明该处流动是否为超临界。（输入当地马赫数。）
::: solution
$p/p_\infty = 1 + \tfrac12\gamma M_\infty^2C_p = 1 - 0.343 = 0.657$。按等熵关系，$1 + 0.2M^2 = (1 + 0.2 \times 0.49)(p_\infty/p)^{1/3.5} = 1.098 \times 1.1275 = 1.238$，所以$M = \sqrt{1.19} = 1.09$。该处流动为当地超声速（与$C_p = -1.0 < C_{p,cr} = -0.78$一致），在吸力峰之后的某处必有一道激波终结超声速区；在当地马赫数低于约$1.2$–$1.3$时，这道激波足够弱，能使湍流边界层保持附着。
:::
:::

::: exercise 选择后掠与厚度 {level=3}
一种新的支线喷气机将以$M = 0.78$巡航，剖面升力系数约为$0.55$，采用超临界剖面。用科恩-梅森方程列表给出后掠角为$0$、$15$、$20$和$25^\circ$时使$M_{dd} = M_\text{巡航} + 0.02$的相对厚度。讨论还有哪些因素应当决定后掠（结构重量、最大升力与起降场地性能、失速特性、展长与展弦比），并论证你的选择。
::: solution
取$M_{dd} = 0.80$，$\kappa_A = 0.95$，$c_l = 0.55$：$t/c = \cos^2\Lambda\left(0.95/\cos\Lambda - 0.055/\cos^3\Lambda - 0.80\right)$。$\Lambda = 0$：$t/c = 0.95 - 0.055 - 0.80 = 0.095$。$\Lambda = 15^\circ$（$\cos = 0.9659$）：$0.9330(0.9835 - 0.0610 - 0.80) = 0.114$。$\Lambda = 20^\circ$（$0.9397$）：$0.8830(1.0110 - 0.0663 - 0.80) = 0.128$。$\Lambda = 25^\circ$（$0.9063$）：$0.8214(1.0482 - 0.0739 - 0.80) = 0.143$。好的答案应认识到：更大的后掠允许采用更厚的剖面（更轻、燃油容积更大），但代价是展向结构长度增加，$C_{L,\max}$和升力线斜率降低（需要更长的跑道或更复杂的襟翼），以及翼尖失速恶化；支线喷气机重视短场性能和低结构重量；因此选择约$20$–$25^\circ$的适中后掠，展向平均$t/c \approx 0.12$–$0.14$，再用跨声速CFD和风洞试验加以细化。任何自洽、论证充分的选择都是可以接受的。
:::
