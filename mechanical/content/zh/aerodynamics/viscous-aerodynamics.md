到目前为止一切都是无黏的，而无黏理论表现良好：它对机翼剖面升力线斜率、零升迎角和俯仰力矩的预测精确到百分之几以内。但它在二维中预测的阻力为零，也无法预测失速。这两者都来自一层空气，其厚度通常为一毫米到几厘米，在其中速度从势流值降到表面上的零——这就是**边界层**。本章研究翼型上的边界层：层流和湍流边界层有多厚、产生多大的摩擦；它们如何响应压强梯度，以及为什么会分离；从层流到湍流的转捩如何发生；表面摩擦与压差（“形状”）阻力如何合成剖面的型阻；分离如何决定最大升力；以及襟翼和缝翼如何提高这一最大值。

先修内容是[[fluid-mechanics/boundary-layers-drag]]，其中介绍了平板边界层及其基本关联式，以及[[aerodynamics/thin-airfoil-theory]]和[[aerodynamics/panel-methods]]中的无黏翼型理论。例题中海平面空气的$\rho_\infty = 1.225\,\mathrm{kg/m^3}$，$\mu_\infty = 1.789\times10^{-5}\,\mathrm{Pa\,s}$，运动黏度$\nu = \mu/\rho = 1.460\times10^{-5}\,\mathrm{m^2/s}$。

## 翼型上的边界层

路德维希·普朗特1904年的洞见是：在高雷诺数下，黏性的影响局限于紧贴表面的薄层和尾迹之中。在此之外流动是无黏的；在其内部，速度梯度$\partial u/\partial y$大到黏性应力与惯性同样重要，无论$\mu$多么小。由于这一层很薄，压强在其中沿厚度方向不变：壁面上的压强等于无黏流在其外缘施加的压强。因此无黏解确定了压强和外缘速度$u_e(x)$；边界层对它们作出响应。

在中等迎角的翼型上，边界层从前驻点开始，在那里最薄。沿上表面，气流先加速到吸力峰（**顺**压梯度，$dp/dx < 0$，它使边界层保持薄而为层流），然后向后缘减速（**逆**压梯度，$dp/dx > 0$）。在某处，通常在吸力峰附近或之后，边界层变为湍流。在后缘处，上下表面的边界层汇合成尾迹。

::: definition 边界层厚度与形状因子 {#def-thicknesses}
对于速度剖面为$u(y)$、外缘速度为$u_e$的边界层：

- **厚度**$\delta$（或$\delta_{99}$）是离壁面$u = 0.99\,u_e$处的距离；
- **位移厚度**$\delta^* = \int_0^\infty\left(1 - \dfrac{u}{u_e}\right)dy$是在无黏流中为得到相同的质量流量、壁面需要向外移动的距离——即边界层把外部流动推离物体的距离；
- **动量厚度**$\theta = \int_0^\infty\dfrac{u}{u_e}\left(1 - \dfrac{u}{u_e}\right)dy$度量动量亏损，从而度量阻力；
- **形状因子**为$H = \delta^*/\theta$：层流平板约为$2.59$，湍流平板约为$1.3$–$1.4$，在分离处升至约$3.5$（层流）或$2.5$–$3$（湍流）。

当地**表面摩擦系数**为$c_f = \tau_w/\left(\tfrac12\rho u_e^2\right)$，在长度$L$上的平均值为$C_f$。
:::

对于零压强梯度的平板，经典结果为（$\mathrm{Re}_x = u_ex/\nu$）：

| | 层流（布拉休斯，精确解） | 湍流（1/7次方律，经验公式） |
|---|---|---|
| 厚度 | $\delta = 5.0\,x/\sqrt{\mathrm{Re}_x}$ | $\delta = 0.37\,x/\mathrm{Re}_x^{1/5}$ |
| 位移厚度 | $\delta^* = 1.721\,x/\sqrt{\mathrm{Re}_x}$ | $\delta^* \approx \delta/8$ |
| 动量厚度 | $\theta = 0.664\,x/\sqrt{\mathrm{Re}_x}$ | $\theta \approx 7\delta/72$ |
| 当地摩擦 | $c_f = 0.664/\sqrt{\mathrm{Re}_x}$ | $c_f = 0.0592/\mathrm{Re}_x^{1/5}$ |
| 平均摩擦 | $C_f = 1.328/\sqrt{\mathrm{Re}_L}$ | $C_f = 0.074/\mathrm{Re}_L^{1/5}$ |

层流一栏是边界层方程的精确解。湍流一栏是由普朗特的七分之一次方速度剖面加上经验的壁面切应力定律得到的关联式；它在$5\times10^5 \lesssim \mathrm{Re}_L \lesssim 10^7$范围内与测量结果相符。在更高的雷诺数下使用**施利希廷**（Schlichting）关联式
$$
C_f = \frac{0.455}{\left(\log_{10}\mathrm{Re}_L\right)^{2.58}}
$$ {#eq-schlichting}
（适用到约$10^9$，精确到百分之几）。当边界层在转捩雷诺数$\mathrm{Re}_{x,tr}$之前为层流、之后为湍流时，平均摩擦的一种标准估算是：减去层流段所没有的湍流摩擦，再加上它实际具有的层流摩擦：
$$
C_f = \frac{0.074}{\mathrm{Re}_L^{1/5}} - \frac{A}{\mathrm{Re}_L}, \qquad A = \mathrm{Re}_{x,tr}\left(\frac{0.074}{\mathrm{Re}_{x,tr}^{1/5}} - \frac{1.328}{\mathrm{Re}_{x,tr}^{1/2}}\right),
$$ {#eq-mixed-cf}
对通常假设的$\mathrm{Re}_{x,tr} = 5\times10^5$，$A = 1742$。它假设湍流边界层的行为就像是从前缘开始发展的一样，这一近似的误差略微偏大。

::: example 机翼剖面上的表面摩擦 {#ex-friction}
一个弦长$2\,\mathrm{m}$的机翼在海平面以$60\,\mathrm{m/s}$飞行。把每个表面视为平板，在下列情况下估算每米展长的摩擦阻力：(a) 边界层全为层流，(b) 全为湍流，(c) 在$\mathrm{Re}_{x,tr} = 5\times10^5$之前为层流。在(c)中转捩发生在何处？在(a)和(b)中后缘处的边界层有多厚？
::: solution
$\mathrm{Re}_c = 60 \times 2/(1.460\times10^{-5}) = 8.22\times10^6$，$q_\infty = \tfrac12(1.225)(60)^2 = 2205\,\mathrm{Pa}$。
(a) $C_f = 1.328/\sqrt{8.22\times10^6} = 0.000463$；两个表面：$D' = 2C_fq_\infty c = 2(0.000463)(2205)(2) = 4.1\,\mathrm{N/m}$。
(b) $C_f = 0.074/(8.22\times10^6)^{0.2} = 0.00306$；$D' = 27.0\,\mathrm{N/m}$。（施利希廷公式[[#eq-schlichting]]给出$0.00310$，多1%。）
(c) $C_f = 0.00306 - 1742/8.22\times10^6 = 0.00285$；$D' = 25.2\,\mathrm{N/m}$。转捩位于$x_{tr} = 5\times10^5 \times 1.460\times10^{-5}/60 = 0.122\,\mathrm{m}$，即弦长的6%。

:::

## 压强梯度与分离

边界层的命运由压强梯度决定。在顺压梯度中，外部流动加速，并带动壁面附近的慢速流体一起运动。在逆压梯度中，压强力**阻碍**边界层中每一个质点的运动；快速的外层流体有足够的动量冲过去，而壁面附近的慢速流体却没有。它减速、停止并反向流动：壁面切应力降到零，边界层离开表面。这就是**分离**。在其下游有一个回流的低能流体区，无黏压强分布不再适用，无黏流所预示的物体后部的压强恢复也不会发生。

在不求解完整边界层方程的情况下，把边界层与压强分布联系起来的工具是动量积分。

::: proposition 冯·卡门动量积分方程 {#prop-momentum-integral}
对于外缘速度为$u_e(x)$的定常、二维、不可压缩边界层，
$$
\frac{d\theta}{dx} + \left(2 + H\right)\frac{\theta}{u_e}\frac{du_e}{dx} = \frac{c_f}{2} .
$$ {#eq-momentum-integral}
:::

::: proof
从边界层方程$u\,u_x + v\,u_y = u_e u_e' + \nu u_{yy}$和$u_x + v_y = 0$出发，其中压强梯度已写为$-\tfrac1\rho\,dp/dx = u_eu_e'$（外缘处的伯努利方程）。展开
$$
\partial_x\left[u(u_e - u)\right] + \partial_y\left[v(u_e - u)\right] + u_e'(u_e - u) = -\nu u_{yy}
$$
的左端并利用连续方程（$v_y = -u_x$），它化为$-(u\,u_x + v\,u_y - u_eu_e')$，所以这就是用速度亏损改写的动量方程。从$y = 0$积分到边界层之外的某一高度，那里$u = u_e$且$u_y = 0$。$\partial_y$项在两个积分限处都为零（壁面上$v = 0$，外部$u_e - u = 0$），而$-\nu\int u_{yy}\,dy = \nu u_y(0) = \tau_w/\rho$。由$\int u(u_e - u)\,dy = u_e^2\theta$和$\int(u_e - u)\,dy = u_e\delta^*$：
$$
\frac{d}{dx}\left(u_e^2\theta\right) + u_e u_e'\,\delta^* = \frac{\tau_w}{\rho}.
$$
展开导数并除以$u_e^2$，得$\theta' + 2\theta u_e'/u_e + \delta^*u_e'/u_e = \tau_w/(\rho u_e^2) = c_f/2$，这就是$\delta^* = H\theta$时的[[#eq-momentum-integral]]。假设：定常、二维、不可压缩的边界层流动（薄层，压强沿厚度不变）；它对层流边界层成立，用平均量表示时对湍流边界层同样成立。
:::

方程本身有三个未知量（$\theta$、$H$、$c_f$），因此要用关联式来封闭。对于层流边界层，最简单的封闭方法是思韦茨（Thwaites）方法。

::: algorithm 层流边界层的思韦茨方法 {#alg-thwaites}
已知由无黏解得到的$u_e(x)$，$x$从驻点（或前缘）量起：
1. 由下式计算动量厚度
$$
\theta^2(x) = \frac{0.45\,\nu}{u_e^6(x)}\int_0^x u_e^5\,dx .
$$ {#eq-thwaites}
2. 构造压强梯度参数$\lambda = \dfrac{\theta^2}{\nu}\dfrac{du_e}{dx}$。
3. 由思韦茨关联函数（有表可查；$\lambda = 0$时$H = 2.61$，$\ell = 0.22$）读出$H(\lambda)$和摩擦$c_f = 2\nu\,\ell(\lambda)/(u_e\theta)$。
4. 在$\lambda$降到约$-0.09$处预测**分离**。
:::

该方法基于思韦茨（1949年）的一个经验观察：对许多精确的层流解，组合$u_e\,d(\theta^2)/dx/\nu$非常接近$\lambda$的线性函数$0.45 - 6\lambda$，这使动量积分方程变为可积形式[[#eq-thwaites]]。在顺压梯度和轻度逆压梯度中，它对$\theta$的精度通常为5–10%，在分离点附近较差。对于平板（$u_e$为常数），它给出$\theta = \sqrt{0.45\nu x/u_e} = 0.671\,x/\sqrt{\mathrm{Re}_x}$，与精确的布拉休斯值$0.664\,x/\sqrt{\mathrm{Re}_x}$相差在1%以内。

::: example 线性减速流动中的层流分离 {#ex-thwaites}
一个层流边界层从$x = 0$开始，其外缘速度线性减小，$u_e = U(1 - x/L)$。思韦茨方法预测分离发生在何处？（这是豪沃思（Howarth）的经典检验算例；精确数值解在$x/L = 0.120$处分离。）
::: solution
令$\xi = x/L$，$\int_0^x u_e^5\,dx = U^5L\left[1 - (1 - \xi)^6\right]/6$，所以
$$
\theta^2 = \frac{0.45\,\nu L}{6U}\cdot\frac{1 - (1 - \xi)^6}{(1 - \xi)^6} = \frac{0.075\,\nu L}{U}\left[(1 - \xi)^{-6} - 1\right],
$$
又$du_e/dx = -U/L$，
$$
\lambda = \frac{\theta^2}{\nu}\left(-\frac UL\right) = -0.075\left[(1 - \xi)^{-6} - 1\right].
$$
令$\lambda = -0.09$：$(1 - \xi)^{-6} = 2.2$，所以$\xi = 1 - 2.2^{-1/6} = 0.123$。**合理性检验：**该方法与精确值$0.120$相差在3%以内。注意这一结果的含义：层流边界层在分离之前只能承受外缘速度下降12%——约$0.23\,q$的压强升高——而与雷诺数无关（雷诺数已从结果中消去）。湍流边界层的速度剖面饱满得多，能承受的压强升高要大得多。
:::
:::

::: warning 分离由压强梯度决定，而不是由速度决定
学生常常以为分离发生在流动最慢之处，或压强最高之处。实际上，分离发生在边界层被迫爬升的**逆**压梯度超出其动量所能承受之处。正如[[#ex-thwaites]]所示，层流边界层在不大的速度降之后就会分离，而且几乎与雷诺数无关；湍流边界层则能爬升大得多的逆压梯度。这就是为什么在临界雷诺数下，人为触发（湍流）的边界层能减小球或圆柱的阻力，也是为什么翼型的失速如此强烈地依赖于转捩发生的位置。第二个陷阱：无黏压强分布只在分离点之前有效。在分离点下游，不能对势流速度使用伯努利方程。
:::

## 转捩

层流边界层在某一临界雷诺数以上是不稳定的：小扰动——来流湍流、声波、表面粗糙度、振动——在二维边界层中以行波（**托尔明-施利希廷波**，Tollmien–Schlichting waves）的形式增长，然后破碎为湍流斑，湍流斑合并成完全的湍流。在安静来流中的平板上，不稳定性始于$\mathrm{Re}_x \approx 9\times10^4$附近，即动量厚度雷诺数$\mathrm{Re}_\theta \approx 200$，但转捩本身发生在更下游处，在普通风洞中从$\mathrm{Re}_x \approx 5\times10^5$起，在非常安静的风洞中可达$3\times10^6$或更高。顺压梯度使边界层稳定（这就是翼型前缘区域通常为层流的原因）；逆压梯度则使之强烈失稳。

在滑翔机、风力机和小型飞机所处的中等雷诺数（$10^5$–$2\times10^6$）下，翼型上的层流边界层常常在吸力峰之后的逆压梯度中、在变为湍流**之前**就发生分离；分离的剪切层随后变为湍流并再附，围成一个**层流分离泡**。短分离泡无害甚至有益；长分离泡增加阻力，而短分离泡在大迎角下的“破裂”是突然发生前缘失速的途径之一。工程预测采用$e^N$**方法**：线性稳定性理论计算最不稳定扰动沿表面的放大，并假设在它增长到$e^N$倍处发生转捩，对于安静的自由大气环境$N \approx 9$（在较嘈杂的风洞中较低）。这就是XFOIL的转捩判据。

## 型阻

剖面的**型阻**是摩擦阻力（壁面切应力的积分）与压差阻力（压强的积分；它不再相互抵消，因为边界层排挤了外部流动，后部的压强恢复不完全）之和。对于小迎角的流线型剖面，摩擦通常占总量的70–90%；对于钝体，压差阻力占主导。两者一起表现为尾迹中的动量亏损，型阻正是这样测量的：模型后方的一排总压探针测量尾迹，阻力为$D' = \rho\int u(V_\infty - u)\,dy$，即$c_d = 2\theta_\infty/c$，其中$\theta_\infty$是远下游尾迹的动量厚度。

::: proposition 斯夸尔-扬公式 {#prop-squire-young}
若后缘处边界层的总动量厚度（上下表面之和）为$\theta_{TE}$、形状因子为$H_{TE}$、外缘速度为$u_{TE}$，则剖面型阻系数近似为
$$
c_d = \frac{2\theta_{TE}}{c}\left(\frac{u_{TE}}{V_\infty}\right)^{(H_{TE} + 5)/2}.
$$ {#eq-squire-young}
:::

::: proof
尾迹中没有壁面，所以取$c_f = 0$的[[#eq-momentum-integral]]给出$d\theta/dx = -(2 + H)(\theta/u_e)\,du_e/dx$，即$d(\ln\theta)/d(\ln u_e) = -(2 + H)$。随着尾迹向下游运动，其外缘速度从$u_{TE}$恢复到$V_\infty$，形状因子从$H_{TE}$松弛趋向$1$。斯夸尔（Squire）和扬（Young）（1937年）根据测量结果假设，在这两个端点状态之间$H$随$\ln(u_e)$线性变化，于是$(2 + H)$在积分区间上的平均值为$2 + \tfrac12(H_{TE} + 1) = (H_{TE} + 5)/2$。积分得$\ln(\theta_\infty/\theta_{TE}) = \tfrac{H_{TE} + 5}{2}\ln(u_{TE}/V_\infty)$，再由$c_d = 2\theta_\infty/c$即得[[#eq-squire-young]]。假设：二维不可压缩尾迹，经验的$H$–$u_e$关系，以及后缘处为附着流；大多数黏性-无黏翼型程序都用这一公式把后缘边界层数据换算为阻力。
:::

为了快速估算，附着流剖面的型阻常写成两倍的平板摩擦（两个表面）乘以一个**形状因子**，后者计入了厚剖面上较高的速度和压差阻力。概念性飞机设计中广泛使用的一个关联式（雷默（Raymer），《飞机设计：概念方法》（*Aircraft Design: A Conceptual Approach*））为
$$
c_{d,\min} \approx 2C_f\left[1 + \frac{0.6}{(x/c)_m}\left(\frac tc\right) + 100\left(\frac tc\right)^4\right],
$$ {#eq-form-factor}
其中$(x/c)_m$是最大厚度所在的弦向位置；雷默还把它乘以另一个因子$1.34M^{0.18}$（再乘以一个后掠项），该因子在$M \approx 0.2$时接近$1$，这里略去。对于在最小阻力升力系数附近工作的常规剖面，它的精度大约为10%；它不适用于处在低阻范围内的层流翼型，也不适用于分离流。

::: example NACA 0012的最小阻力 {#ex-profile-drag}
估算光滑NACA 0012剖面在$\mathrm{Re} = 6\times10^6$时的最小型阻，(a) 假设完全湍流，(b) 假设两个表面上直到30%弦长为层流。在低湍流度风洞中光滑模型的实测值约为$0.0058$（艾博特和冯·多恩霍夫）。
::: solution
最大厚度位于30%弦长处，所以形状因子为$1 + (0.6/0.3)(0.12) + 100(0.12)^4 = 1 + 0.24 + 0.0207 = 1.261$。
(a) $C_f = 0.074/(6\times10^6)^{0.2} = 0.00326$，所以$c_d = 2(0.00326)(1.261) = 0.0082$。
(b) 由$\mathrm{Re}_{x,tr} = 0.3 \times 6\times10^6 = 1.8\times10^6$，[[#eq-mixed-cf]]给出$A = 1.8\times10^6(0.074/17.79 - 1.328/1342) = 5690$，$C_f = 0.00326 - 5690/6\times10^6 = 0.00231$，所以$c_d = 2(0.00231)(1.261) = 0.0058$。
**合理性检验：**含部分层流的估算与光滑模型的测量值相符；完全湍流的数值接近同一剖面在标准前缘粗糙度下的值（艾博特和冯·多恩霍夫给出在这一雷诺数下带粗糙度时约为$0.008$–$0.009$）。这一比较表明，剖面阻力在多大程度上取决于转捩发生的位置——这既取决于形状，也同样取决于表面光洁度、昆虫和雨水。
:::
:::

::: example 由后缘边界层数据求阻力 {#ex-squire-young}
某剖面在设计升力下的边界层计算给出：后缘处总动量厚度（两个表面）$\theta_{TE} = 0.0036\,c$，形状因子为$1.5$，外缘速度为$0.95\,V_\infty$。估算型阻系数。
::: solution
由[[#eq-squire-young]]，$c_d = 2(0.0036)(0.95)^{(1.5 + 5)/2} = 0.0072 \times 0.95^{3.25} = 0.0072 \times 0.8464 = 0.0061$。**合理性检验：**远下游的尾迹有$\theta_\infty = 0.0030\,c$，比后缘处小，因为尾迹正在加速恢复到$V_\infty$；忽略这一恢复（直接用$2\theta_{TE}/c$）会把阻力高估18%。$0.006$这个值对于接近最小阻力的常规剖面是典型的。
:::
:::

## 失速

随着迎角增大，吸力峰增高，其后的逆压梯度变陡。最终边界层分离，升力停止增长并下降，阻力和俯仰力矩突然变化：剖面**失速**了。实测的升力曲线表现出三种典型类型，由麦卡洛（McCullough）和高尔特（Gault）分类（NACA TN 2502，1951年）：

- **后缘失速**——湍流分离从后缘开始，随着$\alpha$增大逐渐前移；升力曲线平缓地弯过顶点并缓慢下降。这是厚剖面（厚度大于约12–15%）的典型情况。
- **前缘失速**——头部附近的短层流分离泡破裂，气流从前缘突然分离且不再再附；升力突然大幅下降。这是具有尖锐吸力峰的中等厚度剖面（约9–12%）的典型情况。
- **薄翼失速**——在非常薄的剖面上，前缘分离泡在小迎角下即形成，并随迎角稳定地伸长；升力曲线很早就弯曲，最大升力较低。

剖面的最大升力系数取决于其厚度、弯度、前缘半径和表面状况，并强烈依赖于雷诺数，因为$\mathrm{Re}$支配着转捩和边界层的动量。对于常规剖面，在$\mathrm{Re} = 6\times10^6$时$c_{l,\max}$通常为$1.4$–$1.7$；在$\mathrm{Re} \approx 3\times10^5$时可能为$1.0$–$1.2$。机翼的$C_{L,\max}$低于其剖面，因为展向升力分布使某个剖面首先达到其最大值（对无后掠机翼通常为剖面值的0.85–0.95，对后掠翼更小），设计者通过安排扭转和平面形状，使失速首先发生在内侧，从而保持副翼有效。

::: quiz
两个其他方面完全相同的光滑翼型模型，分别在弦长雷诺数$3\times10^5$和$6\times10^6$下试验。哪种说法最可能正确？
- [ ] 升力线斜率差别很大，但$c_{l,\max}$相同
- [x] 升力线斜率几乎相同，但$c_{l,\max}$和最小阻力差别很大
- [ ] 两者完全相同，因为几何形状相同
- [ ] 低$\mathrm{Re}$模型的$c_{l,\max}$更高，因为其边界层更薄
::: solution
附着流的升力线斜率主要由无黏物理决定，随$\mathrm{Re}$变化很小。最大升力和最小阻力是边界层现象：在$3\times10^5$时，边界层保持层流的距离更长，更容易分离（层流分离泡），且相对更厚，所以$c_{l,\max}$更低而$c_{d,\min}$更高。匹配雷诺数恰恰对这些量最为重要（[[aerodynamics/aerodynamic-forces]]）。
:::
:::

## 增升装置

飞机在起飞和着陆时飞得最慢，需要最大升力，而在巡航时需要最小阻力，因此机翼要改变形状：**增升装置**在低速飞行时提高$C_{L,\max}$，在巡航时收起。

- **后缘襟翼**增加弯度（薄翼理论[[aerodynamics/thin-airfoil-theory]]给出小偏角下的升力增量），开缝襟翼和富勒襟翼还增加弦长。**简单**襟翼只是把剖面后部铰接偏转；**开裂式**襟翼只偏转下表面；**开缝**襟翼留有一条缝隙，来自下方的高压空气通过缝隙为襟翼上表面的边界层补充能量，推迟襟翼上的分离并允许更大的偏角；**富勒**（Fowler）襟翼在偏转的同时向后移动，既增加弯度，也增加机翼面积和弦长。运输机采用双缝和三缝襟翼。
- **前缘装置**——缝翼、克鲁格襟翼、下垂前缘——不会显著增加给定迎角下的升力；它们降低头部的吸力峰，从而把前缘分离推迟到更大的迎角，提高$c_{l,\max}$。**缝翼**通过“缝隙效应”起作用：缝翼自身的环量降低了主翼上的吸力峰，而其后缘把一个新的边界层排入高速区域。

根据初步设计数据（雷默），剖面最大升力系数的典型增量为：简单襟翼或开裂式襟翼约$0.9$，单缝襟翼$1.3$，双缝襟翼$1.6$（富勒型襟翼还要再乘以弦长延伸比），缝翼约$0.3$–$0.4$；机翼的增量按带襟翼的展长比例和后掠而相应减小。真实运输机着陆时的$C_{L,\max}$约为$2.4$–$3$，而干净构型约为$1.4$–$1.6$。

::: example 带襟翼的着陆速度 {#ex-high-lift}
一架质量$70\,\mathrm{t}$、机翼面积$120\,\mathrm{m^2}$的运输机，干净构型$C_{L,\max} = 1.5$，缝翼和双缝襟翼完全放出时为$2.6$。求海平面失速速度，以及等于着陆构型失速速度$1.23$倍的进近速度。
::: solution
$W = 70\,000 \times 9.81 = 686.7\,\mathrm{kN}$。$V_s = \sqrt{2W/(\rho_\infty SC_{L,\max})}$：干净构型$\sqrt{2 \times 686\,700/(1.225 \times 120 \times 1.5)} = 78.9\,\mathrm{m/s}$；着陆构型$\sqrt{2 \times 686\,700/(1.225 \times 120 \times 2.6)} = 59.9\,\mathrm{m/s}$。进近速度为$1.23 \times 59.9 = 73.7\,\mathrm{m/s}$（143节）。**合理性检验：**失速速度按$\sqrt{1.5/2.6} = 0.76$的比例下降，因此着陆时需要吸收的动能降到干净机翼值的$0.58$，着陆距离相应缩短。接近140节的进近速度对这一级别的飞机是典型的；没有增升装置时它约为190节，着陆距离大约会加倍。
:::
:::

::: application 层流翼型
由于层流摩擦比湍流低得多，自1930年代末以来，人们就设计翼型形状，使边界层在弦长的很大一部分上保持层流：NACA六系列把最小压强点后移（到40–60%弦长处），使顺压梯度——以及随之而来的层流——延伸到那么远。其结果是一个“阻力桶”：在一段升力系数范围内阻力非常低，超出这一范围，吸力峰前移，转捩点随之跳到前方，阻力急剧上升。只有当表面足够光滑和清洁时，这一好处才能实现；昆虫、雨水和制造台阶都会触发转捩。现代复合材料滑翔机在机翼一半或更多弦长上保持层流；在后掠的运输机机翼上，横流不稳定性使自然层流难以实现得多，这至今仍是一个研究与发展课题。
:::

::: history
路德维希·**普朗特**（Ludwig Prandtl）于1904年在海德堡召开的国际数学家大会上，用一篇简短的论文提出了边界层概念，解释了分离以及无黏理论在壁面附近的失效。他的学生海因里希·**布拉休斯**（Heinrich Blasius）于1908年求解了平板层流边界层。西奥多·**冯·卡门**（Theodore von Kármán）于1921年发表了动量积分方程，为波尔豪森（1921年）和布赖恩·思韦茨（Bryan Thwaites，1949年）等近似方法开辟了道路。瓦尔特·**托尔明**（Walter Tollmien，1929年）和赫尔曼·**施利希廷**（Hermann Schlichting，1933年）计算了以他们命名的不稳定波的增长，美国国家标准局的盖伦·**舒鲍尔**（Galen Schubauer）和哈罗德·**斯克拉姆斯塔德**（Harold Skramstad）在一座极低湍流度风洞中通过实验证实了这些波（《国家标准局研究杂志》（*Journal of Research of the NBS*），1947年）。H·B·斯夸尔（H. B. Squire）和A·D·扬（A. D. Young）于1937年给出了他们的阻力公式，NACA艾姆斯实验室的乔治·**麦卡洛**（George McCullough）和唐纳德·**高尔特**（Donald Gault）于1951年对翼型失速的三种类型进行了分类。
:::

## 小结

::: summary
- 在高$\mathrm{Re}$下边界层很薄；沿其厚度的压强由外部无黏流施加。其积分特征量为$\delta^*$（位移厚度）、$\theta$（动量厚度，与阻力相关）和$H = \delta^*/\theta$。
- 平板摩擦：层流$C_f = 1.328/\sqrt{\mathrm{Re}_L}$（精确解），湍流$0.074/\mathrm{Re}_L^{0.2}$或$0.455/(\log_{10}\mathrm{Re}_L)^{2.58}$（经验公式）；转捩情形$0.074/\mathrm{Re}_L^{0.2} - A/\mathrm{Re}_L$。湍流摩擦是层流的数倍。
- 冯·卡门动量积分$\theta' + (2 + H)(\theta/u_e)u_e' = c_f/2$把边界层与压强分布联系起来；思韦茨方法对层流加以封闭，并预测在$\lambda \approx -0.09$处分离——在线性减速中仅约12%的速度下降之后。
- 转捩通过被放大的不稳定波发生；$e^N$（$N \approx 9$）是工程判据；在中等$\mathrm{Re}$下会出现层流分离泡。
- 型阻 = 摩擦阻力 + 压差阻力，以尾迹动量亏损的形式测量；斯夸尔-扬公式：$c_d = (2\theta_{TE}/c)(u_{TE}/V_\infty)^{(H_{TE}+5)/2}$。
- 失速类型：后缘失速、前缘失速、薄翼失速。$c_{l,\max}$强烈依赖于$\mathrm{Re}$。襟翼增加弯度（和弦长）；缝翼推迟前缘分离；运输机可达$C_{L,\max} \approx 2.5$–$3$。
:::

::: exercise 机翼的雷诺数 {level=1 check="5.14e6"}
求弦长$1.5\,\mathrm{m}$的机翼在海平面空气中以$50\,\mathrm{m/s}$飞行时的弦长雷诺数。（输入$\mathrm{Re}$。）
::: solution
$\mathrm{Re} = V_\infty c/\nu = 50 \times 1.5/(1.460\times10^{-5}) = 5.14\times10^6$。

::: exercise 转捩位置 {level=1 check="0.146"}
一个机翼在海平面以$50\,\mathrm{m/s}$飞行。若转捩发生在$\mathrm{Re}_x = 5\times10^5$处，它在前缘之后多远（按平板估算）？（以米为单位输入该距离。）
::: solution
$x_{tr} = \mathrm{Re}_{x,tr}\,\nu/V_\infty = 5\times10^5 \times 1.460\times10^{-5}/50 = 0.146\,\mathrm{m}$。
:::
:::

::: exercise 位移厚度 {level=1 check="0.81"}
求海平面$20\,\mathrm{m/s}$来流中的平板上，距前缘$0.3\,\mathrm{m}$处的层流位移厚度。（以mm为单位输入$\delta^*$。）
::: solution
$\mathrm{Re}_x = 20 \times 0.3/(1.460\times10^{-5}) = 4.11\times10^5$（仍为层流）。$\delta^* = 1.721 \times 0.3/\sqrt{4.11\times10^5} = 0.81\,\mathrm{mm}$；$\delta = 2.3\,\mathrm{mm}$，$\theta = 0.31\,\mathrm{mm}$，所以$H = 2.59$。
:::
:::

::: exercise 层流摩擦系数 {level=2 check="0.00297"}
模型试验中的一块平板在$\mathrm{Re}_L = 2\times10^5$时边界层完全为层流。求其平均表面摩擦系数，以及它与相同$\mathrm{Re}_L$下湍流值之比。（输入$C_f$。）
::: solution
$C_f = 1.328/\sqrt{2\times10^5} = 0.00297$。湍流公式给出$0.074/(2\times10^5)^{0.2} = 0.00646$，所以比值为$0.46$。在低$\mathrm{Re}$下差距较小；因此低$\mathrm{Re}$下层流段很长的模型试验会低估全尺寸（湍流）飞机的摩擦，这就是模型常常要人为触发转捩的原因。
:::
:::

::: exercise 用思韦茨方法计算平板 {level=2 check="0.671"}
对平板（$u_e = U$为常数）用思韦茨公式[[#eq-thwaites]]求$\theta\sqrt{\mathrm{Re}_x}/x$，并与布拉休斯值相比较。（输入该系数。）
::: solution
$\theta^2 = (0.45\nu/U^6)U^5x = 0.45\nu x/U$，所以$\theta = \sqrt{0.45}\,x/\sqrt{\mathrm{Re}_x} = 0.671\,x/\sqrt{\mathrm{Re}_x}$，而精确值为$0.664$——高1%。
:::
:::

::: exercise 失速速度的降低 {level=2 check="0.760"}
使$C_{L,\max}$从$1.5$提高到$2.6$的缝翼和襟翼，在给定重量下使失速速度降低为原来的多少倍？（输入新失速速度与旧失速速度之比。）
::: solution
$V_s \propto 1/\sqrt{C_{L,\max}}$，所以比值为$\sqrt{1.5/2.6} = 0.760$，与[[#ex-high-lift]]一致。
:::

::: exercise 层流分离前的压强升高 {level=3 check="0.234"}
在[[#ex-thwaites]]中，层流分离发生在$u_e/U = 1 - 0.123$处。把从减速开始到分离点的压强升高表示为初始动压$\tfrac12\rho U^2$的分数。然后用动量积分方程解释为什么湍流边界层能承受大得多的压强升高，以及这对翼型上表面压强恢复的设计意味着什么。
::: solution
由外缘处的伯努利方程，$(p - p_0)/(\tfrac12\rho U^2) = 1 - (u_e/U)^2 = 1 - 0.877^2 = 0.234$。湍流边界层的剖面更饱满（$H$更小，壁面附近动量更大），并有持续的湍流混合把高动量流体带到壁面；用动量积分的语言来说，它的$c_f$保持为正，而$\theta$增长得多得多，分离只在$H \approx 2.5$–$3$时才发生，这在实践中允许在恢复段上有$0.6\,q$或更大的压强升高。设计上的推论：使恢复区保持湍流（让转捩发生在逆压梯度开始处或之前，或用绊线强制转捩）；设计恢复段的形状，使湍流边界层恰好保持在分离边缘之前（这就是某些高升力翼型和滑翔机翼型所用的“斯特拉特福德”（Stratford）恢复背后的思想）；并接受层流翼型必须在其恢复段的陡峭部分之前结束层流段。
:::

::: exercise 选择增升装置 {level=3}
一种支线飞机设计需要在重量不变的情况下，把着陆失速速度从$62\,\mathrm{m/s}$（干净机翼，$C_{L,\max} = 1.5$）降低到$50\,\mathrm{m/s}$。需要多大的着陆$C_{L,\max}$？提出一种能达到这一要求的装置组合，讨论其代价（重量、复杂性、俯仰力矩、起飞阻力），并解释为什么起飞和着陆时的设置不同。
::: solution
$C_{L,\max} \propto 1/V_s^2$，所以要求为$1.5 \times (62/50)^2 = 2.31$。覆盖约60–70%展长的单缝襟翼大约可使机翼$C_{L,\max}$增加$0.6$–$0.8$——处于临界；带弦长延伸的富勒型单缝襟翼或双缝襟翼可增加约$1.0$，在平直机翼上无需前缘装置即可达到$2.4$–$2.5$；缝翼会增加裕度并改善失速特性，但代价是重量、维护以及失速时更大的抬头俯仰姿态。代价：襟翼滑轨和作动器增加重量和整流罩阻力；大的襟翼偏角产生低头俯仰力矩（薄翼理论，$\Delta c_{m,c/4} < 0$），平尾必须加以配平，这需要更大的平尾向下载荷和更大的平尾面积；放出的装置增加型阻和诱导阻力。起飞时阻力影响爬升梯度，因此使用较小的襟翼偏度（升力高于干净构型，阻力远小于着陆构型）；着陆时阻力是有益的，因此襟翼完全偏转。最终选择应当用试验数据或经过验证的CFD加以校核，因为$C_{L,\max}$无法由无黏理论预测。
