在马赫数1以上，机翼的空气动力学改变了性质。扰动不再能向上游传播，因此每个表面上的流动由该表面的倾角局部地决定；没有库塔条件，也没有亚声速意义上的环量；即使是无黏流动也有阻力——**波阻**——因为物体发出的波把动量和能量带到无穷远处。对于中等超声速马赫数下的薄机翼，阿克莱特（Ackeret）提出的线性理论用寥寥数行就刻画了这一切，并解释了为什么超声速机翼又薄、前缘尖锐、且后掠到马赫锥之后。在高超声速下——大致$M > 5$——线性理论失效：激波紧贴物体，激波后的温度高到足以使空气离解，于是由截然不同的近似（牛顿流、钝体、加热关联式）接手。

本章直接承接[[aerodynamics/oblique-shocks]]（斜激波、普朗特-迈耶膨胀、激波-膨胀波理论），并使用[[aerodynamics/compressible-airfoils]]中导出的线化位势方程。除非另有说明，空气是$\gamma = 1.4$的完全气体；全章$\lambda = \sqrt{M_\infty^2 - 1}$；$q_\infty = \tfrac12\rho_\infty V_\infty^2 = \tfrac12\gamma p_\infty M_\infty^2$。

## 线化超声速流动

对于超声速气流中的薄物体，扰动势满足[[aerodynamics/compressible-airfoils]]中的线化方程，
$$
\lambda^2\phi'_{xx} - \phi'_{yy} = 0, \qquad \lambda = \sqrt{M_\infty^2 - 1},
$$ {#eq-wave}
它在$M_\infty$既不接近$1$也非高超声速时成立。它就是一维**波动方程**，其中$x$扮演时间的角色。

::: proposition 超声速表面压强（线性理论） {#prop-ackeret-cp}
在薄二维表面上的线化超声速流动中，若表面对自由来流的当地倾角为$\theta$（以弧度计，表面迎向来流、即压缩来流时为正），则压强系数为
$$
C_p = \frac{2\theta}{\sqrt{M_\infty^2 - 1}} .
$$ {#eq-ackeret-cp}
每个表面都与另一个表面无关，一点上的压强只取决于该处的当地斜率。
:::

::: proof
[[#eq-wave]]的通解为$\phi' = f(x - \lambda y) + g(x + \lambda y)$，即沿两族马赫线$x \mp \lambda y = \text{常数}$传播的波，马赫线以马赫角倾斜（$\tan\mu = 1/\lambda$）。在物体上方（$y > 0$），扰动只能向下游和向外传播，因此只出现$x - \lambda y = \text{常数}$这一族：$\phi' = f(x - \lambda y)$。于是$u' = f'$，$v' = -\lambda f'$，所以$u' = -v'/\lambda$。上表面$y_u(x)$上的线化边界条件为$v' = V_\infty\,dy_u/dx$，所以$u' = -(V_\infty/\lambda)\,dy_u/dx$，$C_p = -2u'/V_\infty = (2/\lambda)\,dy_u/dx$。对上表面，正斜率$dy_u/dx$迎向来流，所以$\theta = dy_u/dx$。在物体下方，$\phi' = g(x + \lambda y)$，$u' = +v'/\lambda$，再由$v' = V_\infty\,dy_l/dx$得$C_p = -(2/\lambda)\,dy_l/dx$；在下表面，**负**斜率迎向来流，所以同样有$\theta = -dy_l/dx$和$C_p = 2\theta/\lambda$。假设：线化方程的假设（薄物体，小$\theta$，$M_\infty$不接近1也非高超声速）；忽略从其他表面反射的波以及波与波之间的相互作用。这是斜激波和普朗特-迈耶结果的小角度极限（见[[aerodynamics/oblique-shocks]]中关于弱激波的习题）。
:::

## 阿克莱特薄翼理论

用从弦线量起的中弧线$h_c(x)$和半厚度分布$h_t(x)$描述迎角为$\alpha$、弦长为$c$的薄翼型，于是相对于自由来流方向，表面为
$$
y_u = h_c + h_t - \alpha x, \qquad y_l = h_c - h_t - \alpha x .
$$
记$\langle f\rangle = \tfrac1c\int_0^c f\,dx$为沿弦向的平均值。

::: theorem 阿克莱特线化超声速翼型理论 {#thm-ackeret}
对于超声速气流中的薄翼型，在斜率的一阶近似下，
$$
c_l = \frac{4\alpha}{\sqrt{M_\infty^2 - 1}}, \qquad
c_d = \frac{4}{\sqrt{M_\infty^2 - 1}}\left[\alpha^2 + \left\langle\left(\frac{dh_c}{dx}\right)^2\right\rangle + \left\langle\left(\frac{dh_t}{dx}\right)^2\right\rangle\right].
$$ {#eq-ackeret}
升力只依赖于迎角（而不依赖于弯度或厚度）；波阻是三个非负部分之和，分别由升力、弯度和厚度引起。对于平板，载荷沿弦长均匀分布，因此压力中心和气动中心都位于**弦长中点**。
:::

::: proof
由[[#prop-ackeret-cp]]，$C_{p,u} = (2/\lambda)\,dy_u/dx$，$C_{p,l} = -(2/\lambda)\,dy_l/dx$。**升力。**在一阶近似下，升力是压强差沿弦长的积分：
$$
c_l = \frac1c\int_0^c\left(C_{p,l} - C_{p,u}\right)dx = -\frac{2}{\lambda c}\int_0^c\left(\frac{dy_l}{dx} + \frac{dy_u}{dx}\right)dx = -\frac{2}{\lambda c}\int_0^c\left(2\frac{dh_c}{dx} - 2\alpha\right)dx = \frac{4\alpha}{\lambda},
$$
因为在弦长两端$h_c = 0$。**阻力。**作用在斜率为$dy/dx$（相对于来流）的表面微元上的压强有一个流向分量：上表面为$(p_u - p_\infty)\,dy_u/dx\,dx$，下表面为$-(p_l - p_\infty)\,dy_l/dx\,dx$（参见[[aerodynamics/aerodynamic-forces]]中的轴向力积分，这里是在气流坐标系中）。因此
$$
c_d = \frac1c\int_0^c\left(C_{p,u}\frac{dy_u}{dx} - C_{p,l}\frac{dy_l}{dx}\right)dx = \frac{2}{\lambda}\left\langle\left(\frac{dy_u}{dx}\right)^2 + \left(\frac{dy_l}{dx}\right)^2\right\rangle .
$$
由于$dy_{u,l}/dx = h_c' \pm h_t' - \alpha$，平方和为$2(h_c' - \alpha)^2 + 2h_t'^2$，而$\langle h_c'\rangle = 0$消去了含$\alpha$的交叉项，即得[[#eq-ackeret]]。**力矩。**对平板，$C_{p,l} - C_{p,u} = 4\alpha/\lambda$是均匀的，所以对所有$\alpha$合力都作用在弦长中点；弯度附加一个与升力无关的力矩，所以弦长中点是气动中心。假设：[[#prop-ackeret-cp]]的假设；不计表面摩擦。
:::

厚度项取决于形状。对于相对厚度为$t/c$的**菱形**（双楔）剖面，处处$|h_t'| = t/c$，所以$\langle h_t'^2\rangle = (t/c)^2$，$c_{d,t} = 4(t/c)^2/\lambda$；对于由两段抛物线组成的**双凸**剖面，$h_t = 2t\,\tfrac xc\left(1 - \tfrac xc\right)$，$\langle h_t'^2\rangle = \tfrac43(t/c)^2$，$c_{d,t} = \tfrac{16}{3}(t/c)^2/\lambda$。在给定厚度下，处处斜率尽可能小的菱形剖面波阻最小；实践中尖棱在结构上不便，因此采用双凸或六边形剖面。

由此得出三个结论，它们塑造了每一架超声速飞机。第一，升力线斜率$4/\lambda$随马赫数下降：$M = 2$时为每弧度$2.31$，而亚声速时为$2\pi$。第二，厚度引起的波阻按$(t/c)^2$增长，因此超声速剖面很薄——3%到5%，而不是10%到15%。第三，在二维线性理论中弯度只增加阻力而不增加升力，因此超声速剖面几乎是对称的（真实三维机翼上仍使用弯度来调整展向载荷和进行配平）。

::: example 马赫数2.5下的双凸剖面 {#ex-biconvex}
一个5%厚的双凸剖面以$M_\infty = 2.5$、$\alpha = 3^\circ$飞行。用阿克莱特理论求$c_l$、波阻系数及其构成，以及不计和计入$0.005$的表面摩擦阻力系数时的升阻比。
::: solution
$\lambda = \sqrt{6.25 - 1} = 2.291$，$\alpha = 0.05236\,\mathrm{rad}$。于是$c_l = 4(0.05236)/2.291 = 0.0914$。升力引起的波阻为$4\alpha^2/\lambda = 0.00479$，厚度引起的为$\tfrac{16}{3}(0.05)^2/2.291 = 0.00582$，合计$0.0106$；所以无黏时$L/D = 8.6$，计入摩擦时为$0.0914/0.0156 = 5.9$。**合理性检验：**孤立超声速剖面的升阻比为$5$–$8$，而亚声速剖面为$50$–$100$，这就是超声速巡航如此耗油的原因。在这一迎角下，与升力无关的厚度阻力大于随升力变化的波阻——把剖面做薄有双重好处，因为它还允许更小的最佳迎角。
:::
:::

::: example 阿克莱特理论与激波-膨胀波理论的比较 {#ex-compare}
把线性理论与[[aerodynamics/oblique-shocks]]中的激波-膨胀波结果进行比较：(a) $\alpha = 5^\circ$、$M_\infty = 3$的平板，(b) 在马赫数2气流中迎向来流倾斜$10^\circ$的单个表面。
::: solution
(a) 线性理论：$c_l = 4(0.0873)/\sqrt8 = 0.1234$，$c_d = 4(0.0873)^2/\sqrt8 = 0.0108$。激波-膨胀波理论给出$0.1243$和$0.0109$：相差在1%以内。
(b) 线性理论：$C_p = 2(0.1745)/\sqrt3 = 0.2015$。精确的斜激波值为$C_p = \tfrac{2}{1.4 \times 4}(1.707 - 1) = 0.2523$：线性理论低20%。**合理性检验：**误差随转折角和马赫数增大，因为激波的压强升高是非线性的；在膨胀一侧，线性理论略微高估吸力。对平板而言，两个误差在升力中部分抵消，这就是(a)符合得如此之好的原因。对于中等超声速马赫数下几度的斜率，线性理论是可靠的——这恰恰是设计良好的超声速机翼的工作条件。
:::

## 超声速机翼：马赫锥与后掠

在三维机翼上，一点只影响其下游**马赫锥**（半顶角$\mu = \arcsin(1/M_\infty)$）内部的区域。由此产生两类前缘：

- **超声速前缘**位于从顶点发出的马赫锥**之前**——自由来流马赫数垂直于前缘的分量$M_\infty\cos\Lambda_{LE}$大于$1$。前缘附近的每个剖面都像二维超声速翼型那样工作，有附体激波和阿克莱特型压强；前缘必须是尖锐的，以避免脱体弓形激波及其阻力。
- **亚声速前缘**位于马赫锥**之内**——$M_\infty\cos\Lambda_{LE} < 1$。前缘附近的气流像在亚声速流中一样“预先知道”机翼的存在，因此前缘可以是圆的，可以承受前缘吸力，升力引起的波阻也较低。在$M_\infty = 2$时马赫角为$30^\circ$，因此后掠超过$60^\circ$的前缘是亚声速的。

这就是超声速运输机选择前缘大后掠的细长三角翼和尖拱形机翼的原因：它们在巡航时保持前缘为亚声速，把升力分布在很长的弦长上（这降低了升力引起的波阻，在三维中这一波阻既取决于展长，也取决于升力分布的长度），并在小相对厚度下提供很大的燃油容积。在低速下，同样的机翼部分地通过中等迎角下在上表面形成的稳定**前缘涡**产生升力，增加了“涡升力”——但这是在大迎角和大阻力下实现的，使起飞和着陆姿态很陡。

::: example 超声速剖面的最大升阻比 {#ex-ldmax}
对[[#ex-biconvex]]中的剖面（5%双凸，$M_\infty = 2.5$，摩擦$c_{d,f} = 0.005$），求最大$L/D$时的迎角及其值。
::: solution
写成$c_d = c_{d,0} + 4\alpha^2/\lambda$，其中$c_{d,0} = 0.005 + 0.00582 = 0.01082$。于是当两个阻力项相等，即$4\alpha^2/\lambda = c_{d,0}$时，$L/D = (4\alpha/\lambda)/(c_{d,0} + 4\alpha^2/\lambda)$最大，即$\alpha^* = \sqrt{c_{d,0}\lambda/4} = \sqrt{0.01082 \times 2.291/4} = 0.0787\,\mathrm{rad} = 4.5^\circ$，此时
$$
\left(\frac LD\right)_{\max} = \frac{1}{\sqrt{\lambda\,c_{d,0}}} = \frac{1}{\sqrt{2.291 \times 0.01082}} = 6.35 .
$$
**合理性检验：**这与[[aerodynamics/finite-wings]]中亚声速抛物线型极曲线的“两阻力项相等”结果相同。整架超声速飞机连同机身和有限翼展效应，利用后掠和细长平面形状的三维优势，在$M = 2$时可达约$7$–$8$的$L/D$；二维剖面给出的是偏悲观的估计。
:::
:::

::: warning 马赫数1附近和高超声速下的线性理论
因子$1/\sqrt{M_\infty^2 - 1}$使线性超声速理论在$M_\infty \to 1$时预测无穷大的升力线斜率和波阻；实际上跨声速流动是非线性的，各系数在略高于$M = 1$处达到有限的峰值。在约$M_\infty = 1.2$–$1.3$以下不要使用阿克莱特理论。在另一端，线性理论假设$M_\infty\theta \ll 1$；在$M_\infty = 10$时，即使$5^\circ$的表面也有$M_\infty\theta = 0.87$，线性压强严重失准（[[#ex-newton-wedge]]）。高马赫数下的控制参数是**高超声速相似参数**$K = M_\infty\theta$。
:::

## 高超声速流动

两者之间没有明确的界限，但在约$M_\infty = 5$以上，若干在较低速度下可以忽略的特征同时变得重要：

- **薄激波层。**斜激波角趋近于偏转角：在$M_\infty = 10$时，$15^\circ$楔的$\beta = 19.9^\circ$。激波与物体之间的区域很薄，激波与边界层强烈相互作用。
- **熵层。**钝头有一道强的弯曲弓形激波；穿过其近乎正激波部分的流线获得很大的熵增，形成一个高温、低密度的层，覆盖下游的物体表面。
- **黏性干扰。**边界层按$M_\infty^2/\sqrt{\mathrm{Re}}$增长，可以厚到改变物体的有效形状及其上的压强分布。
- **高温效应。**在激波后和边界层中转化为内能的动能使温度升高，足以激发分子振动（约$800\,\mathrm{K}$以上），使氧离解（从约$2000$–$2500\,\mathrm{K}$起）、氮离解（从约$4000\,\mathrm{K}$起），并使气体电离（约$9000\,\mathrm{K}$以上）。$\gamma$不再是常数；气体不再是量热完全气体。
- 高空的**低密度**，此时连续介质假设开始失效。

### 牛顿流

当$M_\infty \to \infty$且激波贴在表面上时，趋近表面微元的流动在撞击时失去其法向动量，然后沿表面滑动。这正是牛顿（1687年）的流体阻力模型——对于他所应用的低速流动它是错误的，但在高超声速下是一个有用的极限。

::: proposition 牛顿压强与修正牛顿压强 {#prop-newtonian}
在牛顿流中，与自由来流成$\theta$角、迎向来流的表面有
$$
C_p = 2\sin^2\theta ,
$$ {#eq-newtonian}
而背向来流的表面（“背风”面）有$C_p = 0$。利斯（Lees）的**修正牛顿**理论把因子$2$换成驻点值，
$$
C_p = C_{p,\max}\sin^2\theta, \qquad C_{p,\max} = \frac{2}{\gamma M_\infty^2}\left(\frac{p_{02}}{p_\infty} - 1\right),
$$ {#eq-mod-newtonian}
其中$p_{02}$是正激波后的滞止压强（瑞利皮托管公式）。对$\gamma = 1.4$，$M_\infty = 2$时$C_{p,\max} = 1.66$，$5$时为$1.81$，$10$时为$1.83$，并在$M_\infty \to \infty$时趋于$1.839$。
:::

::: proof
截面为$A$的流管遇到与自由来流成$\theta$角的平面表面微元，撞击其面积$A/\sin\theta$。质量流量为$\rho_\infty V_\infty A$，垂直于表面的动量（每单位质量$V_\infty\sin\theta$）被消灭；切向动量保留。法向动量的消灭率$\rho_\infty V_\infty A \cdot V_\infty\sin\theta$就是作用在微元上的法向力；把它分布在面积$A/\sin\theta$上，得到压强升高$p - p_\infty = \rho_\infty V_\infty^2\sin^2\theta$以及$C_p = 2\sin^2\theta$。背风面不受任何粒子撞击，所以$p = p_\infty$，$C_p = 0$（严格说来，在极高马赫数下$p \to 0$，给出$C_p = -2/(\gamma M_\infty^2)$，是个小量）。在驻点处，$\theta = 90^\circ$给出$C_p = 2$；但正激波后真实的滞止压强是$p_{02}$，于是利斯对公式进行缩放以与之匹配，得到[[#eq-mod-newtonian]]。瑞利皮托管公式$p_{02}/p_\infty = \left[\tfrac{(\gamma + 1)^2M_\infty^2}{4\gamma M_\infty^2 - 2(\gamma - 1)}\right]^{\gamma/(\gamma - 1)}\tfrac{1 - \gamma + 2\gamma M_\infty^2}{\gamma + 1}$给出所列的数值；当$M_\infty \to \infty$时，$C_{p,\max} \to \left[\tfrac{(\gamma + 1)^2}{4\gamma}\right]^{\gamma/(\gamma - 1)}\tfrac{4}{\gamma + 1} = 1.839$。假设：激波贴在物体上（严格说来$M_\infty \to \infty$且$\gamma \to 1$），粒子之间不相互作用，并忽略曲面上的离心效应。
:::

对于迎角为$\alpha$的平板，只有下表面受到来流冲刷，所以$c_n = 2\sin^2\alpha$，且
$$
c_l = 2\sin^2\alpha\cos\alpha, \qquad c_d = 2\sin^3\alpha, \qquad \frac LD = \cot\alpha .
$$ {#eq-newtonian-plate}
小角度下升力按$\alpha^2$增长——与线性超声速理论和亚声速理论截然不同——并在$\alpha = 54.7^\circ$时最大。

修正牛顿理论对高马赫数下的钝体、圆锥以及再入飞行器的迎风面效果很好，在那里它是快速估算压强以及返回舱气动系数的基础。对于二维楔，它的精度较差，因为即使在高马赫数下激波也远离表面。一个相关的结果是**马赫数无关原理**（奥斯瓦蒂奇（Oswatitsch），1951年），它指出在足够高的马赫数下，给定物体周围的压强**系数**和激波形状不再随$M_\infty$变化——这在上述$C_{p,\max}$的数值中可以看出。

::: example 马赫数10下的楔：三种理论 {#ex-newton-wedge}
一个$15^\circ$的楔面迎向马赫数$10$的气流（$\gamma = 1.4$）。比较由精确斜激波理论、牛顿理论、修正牛顿理论和阿克莱特线性理论得到的$C_p$。然后分别用牛顿理论和激波-膨胀波理论求$15^\circ$迎角平板的$c_l$和$c_d$。
::: solution
**精确解：**弱斜激波有$\beta = 19.9^\circ$，$M_{n1} = 3.41$，$p_2/p_\infty = 13.40$，所以$C_p = \tfrac{2}{1.4 \times 100}(12.40) = 0.177$。
**牛顿理论：**$2\sin^215^\circ = 0.134$。**修正牛顿理论：**$1.832\sin^215^\circ = 0.123$。**阿克莱特理论：**$2(0.2618)/\sqrt{99} = 0.0526$。
对于平板，激波-膨胀波理论给出$C_{p,l} = 0.177$，$C_{p,u} = -0.014$（上表面接近真空，$-2/(\gamma M_\infty^2) = -0.0143$），所以$c_l = 0.185$，$c_d = 0.050$；牛顿理论给出$c_l = 2\sin^215^\circ\cos15^\circ = 0.129$和$c_d = 2\sin^315^\circ = 0.035$。
**合理性检验：**线性理论在这里毫无用处（$M_\infty\theta = 2.6$）；牛顿理论抓住了数量级，但对这个二维楔偏低25–30%，因为其激波远离表面（$19.9^\circ$对$15^\circ$）。对于钝体和细长三维物体的迎风面，修正牛顿理论要好得多。在马赫数10下，背风的上表面贡献很小：高超声速升力几乎完全来自下表面。
:::

::: quiz
按照牛顿理论，高超声速流中$10^\circ$迎角平板的升阻比是多少？实际中是什么限制了它？
- [x] $\cot10^\circ = 5.7$；表面摩擦使之降低
- [ ] $\tan10^\circ = 0.18$；激波使之升高
- [ ] $2\pi$；黏性使之降低
- [ ] 无穷大，因为上表面处于真空中
::: solution
作用在平板上的压强力垂直于平板，所以$10^\circ$时$L/D = \cot\alpha = 5.67$。沿平板作用的摩擦只增加阻力而不增加升力，而在高超声速下由于升力系数较小，摩擦相对较大；实用的高超声速飞行器的$L/D$约为$1$–$4$（再入飞行器处于低端，乘波体和升力体处于高端）。
:::

### 高温与加热

完全气体的滞止温度为$T_0 = T_\infty\left(1 + \tfrac{\gamma - 1}{2}M_\infty^2\right)$。在平流层中$M_\infty = 7$时（$30\,\mathrm{km}$处$T_\infty = 226.5\,\mathrm{K}$），这给出$T_0 = 2450\,\mathrm{K}$——已足以开始使氧离解。对于以$7.5\,\mathrm{km/s}$从近地轨道再入的情形，滞止焓为$\tfrac12V_\infty^2 = 28\,\mathrm{MJ/kg}$；量热完全气体将达到约$28\,000\,\mathrm{K}$，但实际上大部分能量用于使空气离解（并部分电离），激波层温度大约为$6000$–$10\,000\,\mathrm{K}$。此时[[aerodynamics/oblique-shocks]]中的完全气体关系式失效：穿过强激波的密度比超过完全气体极限$(\gamma + 1)/(\gamma - 1) = 6$，激波层变得更薄，表面催化和辐射与对流一起成为传热机制。

决定性的设计洞见来自NACA艾姆斯实验室的H·朱利安·艾伦（H. Julian Allen）和阿尔弗雷德·埃格斯（Alfred Eggers）（1953年）：要经受住进入大气时的加热，飞行器应当是**钝**的，而不是尖的。钝体产生一道强的脱体弓形激波，把大部分动能在**远离**表面的气体中转化为热，其中大部分被气流带走，而驻点处的对流加热随头部半径增大而下降。萨顿（Sutton）和格雷夫斯（Graves）（NASA TR R-376，1971年）给出的驻点对流热流密度的一个广泛使用的工程关联式为
$$
\dot q_s \approx k\sqrt{\frac{\rho_\infty}{R_n}}\,V_\infty^3, \qquad k \approx 1.74\times10^{-4}\ \text{（国际单位制，地球大气）},
$$ {#eq-sutton-graves}
其中$\dot q_s$以$\mathrm{W/m^2}$计，$\rho_\infty$以$\mathrm{kg/m^3}$计，头部半径$R_n$以米计，$V_\infty$以$\mathrm{m/s}$计；它适用于化学平衡下的冷的完全催化壁，在其适用范围内精度约为10–20%。$1/\sqrt{R_n}$的依赖关系是艾伦和埃格斯论证的定量形式。

::: example 返回舱的驻点加热 {#ex-heating}
一个头部（防热罩）半径为$1\,\mathrm{m}$的再入返回舱以$7.0\,\mathrm{km/s}$通过$60\,\mathrm{km}$高度（$\rho_\infty \approx 3.1\times10^{-4}\,\mathrm{kg/m^3}$）。估算驻点对流热流密度，以及在同样条件下半径为$0.1\,\mathrm{m}$的尖头的热流密度。
::: solution
由[[#eq-sutton-graves]]，$\dot q_s = 1.74\times10^{-4}\sqrt{3.1\times10^{-4}/1}\,(7000)^3 = 1.74\times10^{-4} \times 0.01761 \times 3.43\times10^{11} = 1.05\times10^6\,\mathrm{W/m^2}$，约为$1.1\,\mathrm{MW/m^2}$。当$R_n = 0.1\,\mathrm{m}$时，热流密度大$\sqrt{10} = 3.16$倍：$3.3\,\mathrm{MW/m^2}$。**合理性检验：**$1\,\mathrm{MW/m^2}$量级的峰值对流热流密度是轨道再入返回舱的典型值，这就是返回舱防热罩宽大且曲率平缓、并采用烧蚀材料或耐高温可重复使用材料的原因。加热率依赖于$V^3$，所以它在轨道上比减速度更早达到峰值。
:::
:::

::: application 超声速与高超声速民用飞行
有两种超声速运输机投入过航线运营：图波列夫图-144和英法“协和”号（1969年3月2日首飞；1976—2003年定期航班），后者以约$M = 2.0$巡航，采用具有亚声速前缘的细长尖拱形三角翼、[[aerodynamics/oblique-shocks]]中分析过的那种可调进气道，而气动加热把它的结构限制为铝合金、巡航马赫数限制在约$2$。X-15研究机于1967年达到$M = 6.7$，探索了高超声速加热、控制和驾驶员界面。当前民用领域的兴趣集中在更安静的超声速设计上——通过机体外形设计来减弱地面听到的声爆——以及用于载人和载货的再入飞行器，它们正是应用了上述钝体原理。
:::

::: history
雅各布·**阿克莱特**（Jakob Ackeret）于1925年发表了超声速薄翼型的线化理论（《以超声速运动的机翼上的气动力》，“Luftkräfte auf Flügel, die mit größerer als Schallgeschwindigkeit bewegt werden”，《飞行技术与发动机飞艇杂志》（*Zeitschrift für Flugtechnik und Motorluftschiffahrt*））。阿道夫·**布泽曼**（Adolf Busemann）把该理论推进到二阶，并在1935年罗马沃尔塔会议上提出将后掠翼用于超声速飞行。1947年10月14日，查尔斯·**耶格尔**（Charles Yeager）上尉驾驶贝尔X-1超越声速。NACA艾姆斯实验室的H·朱利安·**艾伦**（H. Julian Allen）和阿尔弗雷德·**埃格斯**（Alfred Eggers）于1953年（NACA RM A53D28，后为第1381号报告）证明钝头外形能大大减轻进入大气时的加热，这是每一种载人再入返回舱背后的原理。莱斯特·**利斯**（Lester Lees）于1955年提出了修正牛顿压强定律。牛顿的正弦平方定律本身出现在《自然哲学的数学原理》（*Principia*，1687年）中。
:::

## 小结

::: summary
- 线性超声速理论：在每个表面上独立地有$C_p = 2\theta/\sqrt{M_\infty^2 - 1}$。
- 阿克莱特理论：$c_l = 4\alpha/\lambda$，$c_d = (4/\lambda)\left[\alpha^2 + \langle h_c'^2\rangle + \langle h_t'^2\rangle\right]$；气动中心位于弦长中点。厚度阻力为$4(t/c)^2/\lambda$（菱形）、$\tfrac{16}{3}(t/c)^2/\lambda$（双凸）。超声速剖面薄且几乎对称。
- 在中等$M$下对小斜率，线性理论精确到百分之几；它在$M = 1$附近以及$M_\infty\theta$不小时失效。
- 位于马赫锥内的前缘（$M_\infty\cos\Lambda_{LE} < 1$）是亚声速的，可以做成圆头；细长三角翼正是利用了这一点。
- 高超声速流动：薄激波层、熵层、黏性干扰、真实气体效应。牛顿理论$C_p = 2\sin^2\theta$；修正牛顿理论$C_{p,\max}\sin^2\theta$，其中$C_{p,\max} \to 1.839$。
- 滞止温度和加热随速度急剧上升；钝体（艾伦和埃格斯）以及$\dot q_s \propto \sqrt{\rho_\infty/R_n}V_\infty^3$指导防热罩设计。
:::

## 习题

::: exercise 超声速升力系数 {level=1 check="0.0806"}
用线性理论求马赫数$2$气流中$\alpha = 2^\circ$的薄平板的升力系数。（输入$c_l$。）
::: solution
$c_l = 4\alpha/\sqrt{M^2 - 1} = 4(0.03491)/\sqrt3 = 0.0806$。
:::
:::

::: exercise 厚度波阻 {level=1 check="0.00226"}
一个$t/c = 0.04$的菱形剖面以零迎角、$M_\infty = 3$飞行。用线性理论求其波阻系数。（输入$c_d$。）
::: solution
$c_d = 4(t/c)^2/\sqrt{M^2 - 1} = 4(0.0016)/\sqrt8 = 0.00226$。
:::
:::

::: exercise 牛顿压强 {level=1 check="0.5"}
对于与高超声速气流成$30^\circ$倾斜的表面，牛顿理论给出的压强系数是多少？（输入$C_p$。）
::: solution
$C_p = 2\sin^230^\circ = 2 \times 0.25 = 0.5$。
:::
:::

::: exercise 给定升力所需的迎角 {level=2 check="1.79"}
一架超声速飞机以$M_\infty = 1.6$飞行。按照线性理论，薄机翼剖面要得到$c_l = 0.1$需要多大的迎角？（以度为单位输入$\alpha$。）
::: solution
$\alpha = c_l\sqrt{M^2 - 1}/4 = 0.1 \times 1.249/4 = 0.0312\,\mathrm{rad} = 1.79^\circ$。
:::
:::

::: exercise 声速前缘 {level=2 check="60"}
在$M_\infty = 2$时，多大的前缘后掠角使前缘为声速前缘（既非亚声速也非超声速）？（以度为单位输入$\Lambda_{LE}$。）
::: solution
当$M_\infty\cos\Lambda_{LE} = 1$，即$\cos\Lambda_{LE} = 0.5$、$\Lambda_{LE} = 60^\circ$时，前缘为声速前缘——等价地，即前缘沿马赫锥，其半顶角为与飞行方向成$\mu = 30^\circ$。更大的后掠给出亚声速前缘。
:::
:::

::: exercise 滞止温度 {level=2 check="1320"}
求在$220\,\mathrm{K}$的空气中以$M_\infty = 5$飞行时的完全气体滞止温度。完全气体假设合理吗？（以K为单位输入$T_0$。）
::: solution
$T_0 = 220(1 + 0.2 \times 25) = 1320\,\mathrm{K}$。在这一温度下振动激发已很显著（因此$c_p$和$\gamma$变化百分之几），但离解尚不重要：完全气体值是一个尚可的初步估计，略微偏高。
:::

::: exercise 推导双凸剖面的厚度阻力 {level=3}
对于由两段抛物线组成、半厚度为$h_t = 2t\,\tfrac xc\left(1 - \tfrac xc\right)$的对称双凸剖面，证明$\langle(dh_t/dx)^2\rangle = \tfrac43(t/c)^2$，从而$c_{d,t} = \tfrac{16}{3}(t/c)^2/\sqrt{M_\infty^2 - 1}$。再证明：在弦长中点处最大厚度相同、两端厚度为零的所有厚度分布中，菱形剖面的线性理论波阻最小。
::: solution
$dh_t/dx = (2t/c)(1 - 2x/c)$，所以令$\xi = x/c$，$\langle(dh_t/dx)^2\rangle = 4(t/c)^2\int_0^1(1 - 2\xi)^2\,d\xi = 4(t/c)^2 \cdot \tfrac13$，[[#eq-ackeret]]给出$\tfrac{16}{3}(t/c)^2/\lambda$。关于最小值：在前半段，$\int_0^{c/2}h_t'\,dx = t/2$是固定的。由柯西-施瓦茨不等式，$\left(\int_0^{c/2}h_t'\,dx\right)^2 \le \tfrac c2\int_0^{c/2}h_t'^2\,dx$，所以$\int_0^{c/2}h_t'^2\,dx \ge t^2/(2c)$，等号仅在$h_t'$为常数时成立；后半段同理。因此$\langle h_t'^2\rangle \ge (t/c)^2$，由菱形剖面（常斜率$\pm t/c$）取到。双凸剖面是它的$\tfrac43$倍。
:::
:::

::: exercise 按头部半径确定防热罩尺寸 {level=3 check="1.73"}
一个货物返回舱必须使其峰值驻点对流热流密度低于$0.8\,\mathrm{MW/m^2}$，其轨道上最恶劣的点为$V_\infty = 7.0\,\mathrm{km/s}$、$\rho_\infty = 3.1\times10^{-4}\,\mathrm{kg/m^3}$。用萨顿-格雷夫斯关联式求最小头部半径。讨论防热罩设计者还必须考虑哪些因素（总加热量、辐射加热、减速度、稳定性、装载布置）。（以米为单位输入$R_n$。）
::: solution
由[[#eq-sutton-graves]]，$R_n = \rho_\infty\left(kV_\infty^3/\dot q_s\right)^2 = 3.1\times10^{-4}\left(1.74\times10^{-4} \times 3.43\times10^{11}/8\times10^5\right)^2 = 3.1\times10^{-4} \times (74.6)^2 = 1.73\,\mathrm{m}$（考虑到关联式10–20%的不确定度，设计者还会增加裕度）。更大、更钝的防热罩还会增加阻力并降低弹道系数$m/(C_DA)$，使返回舱在大气中更高、密度更低处减速——进一步降低峰值热流密度，但延长加热脉冲。其他需要考虑的因素：**积分**加热量（它决定烧蚀层厚度）、较高再入速度下来自激波层的辐射加热、峰值减速度（乘员或货物的限制）、气动稳定性（质心位于压力中心之前；质心偏置给出配平迎角以及用于操纵再入的升力）、运载火箭整流罩尺寸，以及针对关联式不确定度（这一不确定度很大）的裕度。真实设计要用数值模拟和电弧风洞试验加以校核。
:::
