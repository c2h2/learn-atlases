机翼、汽车车身、风力机叶片和冷却塔壳体，从流过它们的空气中感受到的都是同样的两样东西：垂直作用于表面每一个微元的**压强**，以及沿表面切向拖曳的**切应力**。除此之外别无其他。每一个气动力与气动力矩——托起一架$500\,\mathrm{t}$客机的升力、决定其燃油消耗的阻力、平尾必须平衡的俯仰力矩——都是这两种分布在物体表面上的积分。本章建立课程其余部分所依赖的“记账方法”：积分得到的力如何分解为升力与阻力，力与力矩如何无量纲化为系数，合力作用在哪里（压力中心，以及更有用的气动中心），以及一个系数可以依赖于哪些无量纲组合——这同时也就是风洞的理论。

先修内容是[[fluid-mechanics/bernoulli]]中的控制体与伯努利方程、[[fluid-mechanics/dimensional-analysis]]中的量纲分析，以及[[fluid-mechanics/boundary-layers-drag]]中关于边界层与阻力的概念。

## 压强与切应力：仅有的两种来源

设想一个弦长为$c$的二维翼型剖面，处于均匀来流中，远前方来流速度为$V_\infty$、密度为$\rho_\infty$、压强为$p_\infty$。**迎角**（angle of attack）$\alpha$是弦线（从前缘到后缘）与$V_\infty$方向之间的夹角。在上表面，空气加速，压强降到$p_\infty$以下；在下表面的大部分区域，压强接近或高于$p_\infty$。这一压强差沿弦向累加，就是升力的绝大部分来源。薄边界层的切应力$\tau_w$相比之下很小——在压强差为几千帕的地方，它通常只有几帕——但它沿表面作用，几乎平行于来流，因此是阻力的主要组成部分。

合力$\mathbf{R}$用两种参考坐标系来分解：

::: definition 升力、阻力、法向力与轴向力 {#def-lift-drag}
对于处在速度为$V_\infty$的来流中的物体，合气动力$\mathbf{R}$可以

- **相对于自由来流**分解：**阻力**$D$是平行于$V_\infty$的分量（以指向下游为正），**升力**$L$是垂直于$V_\infty$的分量（在对称面内以“向上”为正）；或者
- **相对于物体**分解：**轴向力**$A$是沿弦线的分量（以指向后缘为正），**法向力**$N$是垂直于弦线的分量。

对于二维剖面，力取单位展长上的值，并加撇号记作$L'$、$D'$、$N'$、$A'$，单位为$\mathrm{N/m}$。弦线与自由来流之间的迎角为$\alpha$，两种分解之间相差一个转角$\alpha$的旋转：
$$
L = N\cos\alpha - A\sin\alpha, \qquad D = N\sin\alpha + A\cos\alpha.
$$ {#eq-rotate}
:::

这个旋转值得亲手画一次。把弦线放在$x$轴上，自由来流从左方来、方向在其下方$\alpha$角。$N$沿$+y$方向（垂直于弦线），$A$沿$+x$方向。升力方向是$N$的方向反转$\alpha$角，阻力方向是$A$的方向旋转$\alpha$角；把$N$和$A$分别投影到新坐标轴上，就得到[[#eq-rotate]]。注意升力式中的**负**号：一个正的轴向力（沿抬头倾斜的弦线指向后方）有一个与升力方向**相反**的分量。

::: proposition 由表面分布求力 {#prop-surface-integrals}
设二维剖面在$0 \le x \le c$上的上、下表面为$y_u(x)$、$y_l(x)$，表面压强为$p_u$、$p_l$，壁面切应力为$\tau_u$、$\tau_l$（各自以拖曳表面向下游、即指向后缘为正）。则单位展长上
$$
\begin{aligned}
N' &= \int_0^c \left(p_l - p_u\right)dx + \int_0^c\left(\tau_u\,\frac{dy_u}{dx} + \tau_l\,\frac{dy_l}{dx}\right)dx, \\
A' &= \int_0^c \left(p_u\,\frac{dy_u}{dx} - p_l\,\frac{dy_l}{dx}\right)dx + \int_0^c \left(\tau_u + \tau_l\right)dx,
\end{aligned}
$$ {#eq-NA}
而对前缘的俯仰力矩（以**抬头**为正）为
$$
M'_{LE} = \int_0^c \left(p_u - p_l\right)x\,dx + (\text{含 } \tau \text{ 及 } y\,dp \text{ 的小项}),
$$ {#eq-mle}
对于切应力可以忽略的薄剖面，这些小项为零。
:::

::: proof
取上表面上长为$ds$的微元，它与弦线成$\theta$角，于是$dx = ds\cos\theta$，$dy_u = ds\sin\theta$。压强**指向**表面内部，沿内法线方向作用，在上表面该方向朝下并略朝前：其$(x, y)$分量为$(+\sin\theta, -\cos\theta)\,p_u\,ds$，即对法向力的贡献为$-p_u\,dx$，对轴向力的贡献为$+p_u\,dy_u$。切应力沿表面指向后缘，为$(\cos\theta, \sin\theta)\,\tau_u\,ds$：对法向力的贡献为$\tau_u\,dy_u$，对轴向力的贡献为$\tau_u\,dx$。在下表面，内法线朝上，因此压强对$N'$贡献$+p_l\,dx$，对$A'$贡献$-p_l\,dy_l$，而切应力同样贡献$\tau_l\,dy_l$和$\tau_l\,dx$。把这四部分贡献相加，并从前缘积分到后缘，即得[[#eq-NA]]。

对于力矩，作用在前缘后方距离$x$处的法向力微元$dN' = (p_l - p_u)\,dx$，按抬头为正的约定，对前缘产生力矩$-x\,dN'$（作用在机头后方的向上的力使机头**下俯**）。积分得$M'_{LE} = -\int_0^c (p_l - p_u)\,x\,dx$，即[[#eq-mle]]；轴向力微元的力臂为$y$，对薄剖面而言这些力臂很小。

处处叠加一个常数压强，沿闭合围线的贡献为$\oint p_\infty\,\mathbf{n}\,ds = \mathbf{0}$，因此在全部计算中可以用表压$p - p_\infty$代替$p$而不改变任何结果。假设：定常流动，闭合的二维围线，以及上述符号约定。
:::

这一命题不仅讲了算术，也讲了**物理**。升力（几乎全部）是上下表面压强**差**沿弦向的积分。阻力有压强部分——作用在与弦线倾斜的表面上的压强的轴向分量，再加上$N\sin\alpha$倾斜项——和摩擦部分。两者都无法一笔勾销：在真实流体中，一个完美的流线体仍有摩擦阻力，而一块垂直于来流的平板则几乎**只有**压差阻力。

## 无量纲系数

相似物体上的力随物体尺寸以及来流的**动压**而增大，
$$
q_\infty = \tfrac{1}{2}\rho_\infty V_\infty^2,
$$
它是在不可压缩流动中把自由来流等熵地滞止所得到的压强升高——是这个问题天然的压强尺度。用$q_\infty$乘一个参考面积（或长度）去除，就把这两者都消去了。

::: definition 力系数、力矩系数与压强系数 {#def-coefficients}
对于参考面积为$S$（对机翼而言是其平面面积）、参考长度为$\ell$（对机翼而言是平均气动弦长$\bar c$）的三维物体：
$$
C_L = \frac{L}{q_\infty S}, \qquad C_D = \frac{D}{q_\infty S}, \qquad C_M = \frac{M}{q_\infty S \ell}.
$$
对于二维剖面，取单位展长上的值，并以弦长$c$同时作为参考长度和（乘以单位展长后的）参考面积，**剖面系数**用小写字母表示：
$$
c_l = \frac{L'}{q_\infty c}, \qquad c_d = \frac{D'}{q_\infty c}, \qquad c_m = \frac{M'}{q_\infty c^2},
$$
法向力与轴向力的系数同样记为$c_n$、$c_a$。表面上一点的**压强系数**和**表面摩擦系数**为
$$
C_p = \frac{p - p_\infty}{q_\infty}, \qquad c_f = \frac{\tau_w}{q_\infty}.
$$
:::

参考面积是一种**约定**，而不是力所作用的某个物理面积。机翼用包括埋入机身部分在内的平面面积；飞艇用（体积）$^{2/3}$；汽车和骑车人用迎风面积。不注明参考面积的阻力系数没有意义，两个系数只有在参考面积相同时才能比较。

::: proposition 不可压缩流动中的压强系数 {#prop-cp-bernoulli}
在定常、不可压缩且无旋的流动中（或沿着来自自由来流的一条流线），当地速度为$V$的点上的压强系数为
$$
C_p = 1 - \left(\frac{V}{V_\infty}\right)^2.
$$ {#eq-cp-incomp}
因此在驻点处$C_p = 1$，凡$V = V_\infty$处$C_p = 0$，凡流动快于自由来流处$C_p < 0$；原则上没有下界。
:::

::: proof
在自由来流与该点之间应用伯努利方程，密度为常数且重力差可忽略，得$p + \tfrac{1}{2}\rho_\infty V^2 = p_\infty + \tfrac{1}{2}\rho_\infty V_\infty^2$。于是$p - p_\infty = \tfrac{1}{2}\rho_\infty\left(V_\infty^2 - V^2\right)$，除以$q_\infty$即得[[#eq-cp-incomp]]。在驻点处$V = 0$，所以$C_p = 1$。假设：沿来自自由来流的一条流线的定常、无黏、不可压缩流动（或处处无旋的流动，此时所有流线上的伯努利常数相同）。
:::

令$p - p_\infty = q_\infty C_p$，并以弦长为单位度量$x$（$\xi = x/c$），对于法向力中忽略摩擦的薄剖面，[[#eq-NA]]和[[#eq-mle]]成为
$$
c_n = \int_0^1 \left(C_{p,l} - C_{p,u}\right)d\xi, \qquad
c_{m,LE} = -\int_0^1 \left(C_{p,l} - C_{p,u}\right)\xi\,d\xi.
$$ {#eq-cn-cm}
测得的压强分布——来自风洞模型上的一排测压孔，或来自面元法程序——正是这样换算成力的。两个表面的$-C_p$对$\xi$的曲线是标准图示：两条曲线之间所围的面积就是$c_n$。

::: example 巡航中的轻型飞机 {#ex-cessna}
一架质量为$1100\,\mathrm{kg}$、机翼面积$S = 16.2\,\mathrm{m^2}$的轻型飞机在海平面（$\rho_\infty = 1.225\,\mathrm{kg/m^3}$，国际标准大气）以$V_\infty = 55\,\mathrm{m/s}$平飞巡航。求升力系数。若$C_{L,\max} = 1.6$，该重量下的失速速度是多少？
::: solution
在定常平飞中升力等于重力（忽略平尾载荷和推力倾斜）：$L = mg = 1100 \times 9.81 = 10\,791\,\mathrm{N}$。动压为
$$
q_\infty = \tfrac{1}{2}\rho_\infty V_\infty^2 = \tfrac{1}{2}(1.225)(55)^2 = 1853\,\mathrm{Pa},
$$
所以
$$
C_L = \frac{L}{q_\infty S} = \frac{10\,791}{1853 \times 16.2} = 0.360.
$$
失速时$L = W$且$C_L = C_{L,\max}$，所以
$$
V_s = \sqrt{\frac{2W}{\rho_\infty S\,C_{L,\max}}} = \sqrt{\frac{2 \times 10\,791}{1.225 \times 16.2 \times 1.6}} = 26.1\,\mathrm{m/s}\ (50.7\ \text{节}).
$$
**合理性检验：**巡航升力系数$0.2$–$0.6$、失速速度$45$–$55$节是四座轻型飞机的典型值；两速度之比为$\sqrt{1.6/0.360} = 2.11 = 55/26.1$，在重量不变时理应如此。
:::
:::

::: example 由法向力和轴向力求升力和阻力 {#ex-rotate}
一台与二维模型弦线对齐的风洞天平在$\alpha = 6^\circ$时测得$N' = 1200\,\mathrm{N/m}$，$A' = 40\,\mathrm{N/m}$。求$L'$、$D'$及升阻比。
::: solution
由$\cos 6^\circ = 0.99452$和$\sin 6^\circ = 0.10453$，[[#eq-rotate]]给出
$$
\begin{aligned}
L' &= 1200(0.99452) - 40(0.10453) = 1193.4 - 4.2 = 1189\,\mathrm{N/m}, \\
D' &= 1200(0.10453) + 40(0.99452) = 125.4 + 39.8 = 165\,\mathrm{N/m},
\end{aligned}
$$
所以$L'/D' = 7.2$。**合理性检验：**这里的阻力几乎全部（$125\,\mathrm{N/m}$）来自大法向力的倾斜，而不是轴向力。这就是阻力对测量角度的小误差如此敏感的原因：$\alpha$仅有$0.1^\circ$的误差就会使$D'$改变$1200 \times 0.00175 = 2.1\,\mathrm{N/m}$，超过百分之一。因此在给出阻力之前，天平要针对气流偏角进行校准。
:::
:::

::: warning 升力不是“向上的力”，阻力也不是“轴向力”
升力和阻力是相对于**自由来流方向**定义的，既不是相对于弦线，也不是相对于地面。爬升时，升力相对铅垂方向向后倾斜；在带坡度的转弯中，它向侧面倾斜；对风力机叶片而言，它大体**沿着**旋转平面，这正是它驱动风轮的原因。同样，大迎角下的翼型可以有**负的**轴向力（前缘吸力把剖面向前拉），而其阻力仍为正——倾斜项$N\sin\alpha$占主导。务必先画出自由来流方向，并以正确的$\alpha$方向使用[[#eq-rotate]]。
:::

## 力作用在哪里：压力中心与气动中心

分布载荷等效于作用在某一点上的单个合力，或者等效于作用在任一**其他**点上的同一个力加上一个力偶。空气动力学中这两种描述都使用，而结果表明第二种更有用。

::: definition 压力中心 {#def-cp}
剖面的**压力中心**是弦线上气动力矩为零的那一点，即合力作用线与弦线的交点。它到前缘的距离为
$$
x_{cp} = -\frac{M'_{LE}}{N'} \approx -\frac{M'_{LE}}{L'},
$$
近似式在小迎角下成立，此时$N' \approx L'$。
:::

对于有弯度的剖面，压力中心随迎角移动，当升力趋于零时它跑到无穷远：零升力时有弯度的剖面仍有一个低头力偶，而纯力偶没有作用线。早期以压力中心来思考的航空学者感到这很棘手。解决办法是选取一个**力矩**不变的参考点。

::: proposition 力矩转移与气动中心 {#prop-ac}
设$c_{m,x}$为对前缘后方弦长分数$x/c$处一点的剖面力矩系数，以抬头为正，并假设在升力线的线性段内，四分之一弦点力矩系数随升力线性变化：
$$
c_{m,c/4} = c_{m,0} + m_0\,c_l .
$$
则在小迎角下
$$
c_{m,x} = c_{m,c/4} + \left(\frac{x}{c} - \frac{1}{4}\right)c_l ,
$$ {#eq-transfer}
并且存在唯一一点，即**气动中心**，对该点的力矩系数与$c_l$无关。它位于
$$
\frac{x_{ac}}{c} = \frac{1}{4} - m_0 ,
$$ {#eq-xac}
对它的力矩系数等于零升力矩系数，$c_{m,ac} = c_{m,0}$。压力中心与它的关系为
$$
\frac{x_{cp}}{c} = \frac{x_{ac}}{c} - \frac{c_{m,ac}}{c_l}.
$$ {#eq-xcp-xac}
:::

::: proof
在小迎角下，合力在一阶近似下就是垂直于弦线作用的升力$L'$。一个力对点$P$的力矩依赖于$P$：把参考点向后移动$\Delta x$，就加上了作用在新点**前方**距离$\Delta x$处的升力的力矩，它是抬头的，为$+L'\,\Delta x$。于是$M'_x = M'_{c/4} + \left(x - c/4\right)L'$，除以$q_\infty c^2$即得[[#eq-transfer]]。代入线性模型，$c_{m,x} = c_{m,0} + \left(m_0 + x/c - 1/4\right)c_l$，它恰在$x/c = 1/4 - m_0$时与$c_l$无关，即得[[#eq-xac]]；剩下的常数是$c_{m,0}$，即零升力时的值。最后，压力中心是$c_{m,x} = 0$的点：$0 = c_{m,ac} + \left(x_{cp}/c - x_{ac}/c\right)c_l$，整理即得[[#eq-xcp-xac]]。假设：小迎角（$N' \approx L'$，轴向力的力臂可忽略）以及线性的$c_m$–$c_l$关系。
:::

气动中心是剖面形状的一种性质——对于不可压缩流中的薄翼型，它位于四分之一弦点（$m_0 = 0$，[[aerodynamics/thin-airfoil-theory]]将加以证明），而对于低速下的真实剖面，它与四分之一弦点相差在弦长的百分之一二以内。在超声速流中，它后移到大约弦长中点。把气动特性表示为**作用在气动中心的升力加上一个常力偶**$c_{m,ac}$，正是使[[flight-mechanics/longitudinal-static-stability]]中的纵向稳定性分析易于处理的原因。

::: example 由压强分布求力 {#ex-cp-integrate}
在$\alpha = 4^\circ$的薄剖面上，测得的压强差可以很好地拟合为$C_{p,l} - C_{p,u} = 1.6\,(1 - \xi)$，$\xi = x/c$，天平给出$c_a = 0.012$。求$c_n$、$c_{m,LE}$、$c_{m,c/4}$、压力中心，以及$c_l$、$c_d$。
::: solution
由[[#eq-cn-cm]]，
$$
c_n = \int_0^1 1.6\,(1 - \xi)\,d\xi = 0.800, \qquad
c_{m,LE} = -\int_0^1 1.6\,(1 - \xi)\,\xi\,d\xi = -1.6\left(\tfrac12 - \tfrac13\right) = -0.267 .
$$
压力中心位于$x_{cp}/c = -c_{m,LE}/c_n = 0.267/0.800 = 0.333$，即三角形载荷的形心，理应如此。把力矩转移到四分之一弦点，$c_{m,c/4} = c_{m,LE} + \tfrac14 c_n = -0.267 + 0.200 = -0.067$。旋转$\alpha = 4^\circ$，
$$
c_l = 0.800\cos 4^\circ - 0.012\sin 4^\circ = 0.797, \qquad
c_d = 0.800\sin 4^\circ + 0.012\cos 4^\circ = 0.068 .
$$
**合理性检验：**对于$c_l \approx 0.8$的真实剖面，这个阻力系数大得离谱（典型值约为$0.008$）。所给的压强分布没有**前缘吸力峰**——真实翼型的上表面$C_p$在机头处急剧下降到很大的负值，而朝前的头部面积把这一吸力转化为一个很大的**负**轴向力，抵消了$N\sin\alpha$的大部分。这个例子说明，为什么在任何用测压孔或面元法计算阻力的场合都必须精细地分辨前缘区域：漏掉吸力峰，得到的就是分离流中平板的阻力。
:::
:::

::: example 由试验数据确定气动中心 {#ex-ac}
某剖面的风洞试验在线性段内给出：$c_l = 0.2$时$c_{m,c/4} = -0.040$，$c_l = 1.0$时$c_{m,c/4} = -0.032$。求气动中心和$c_{m,ac}$。
::: solution
斜率为$m_0 = dc_{m,c/4}/dc_l = (-0.032 + 0.040)/(1.0 - 0.2) = 0.010$。由[[#eq-xac]]，
$$
\frac{x_{ac}}{c} = 0.25 - 0.010 = 0.240 ,
$$
由[[#eq-transfer]]在任一数据点上，$c_{m,ac} = -0.040 + (0.240 - 0.250)(0.2) = -0.042$（另一点同样给出$-0.032 - 0.010 = -0.042$）。**合理性检验：**力矩随升力增大而**减弱**低头趋势，说明升力作用在四分之一弦点之前，因此气动中心必在$c/4$之前——与所得结果一致。弦长百分之一的偏移是低速下真实剖面的典型值。
:::
:::

::: quiz
一个对称翼型处于小的正迎角，其气动中心位于四分之一弦点。它的压力中心在哪里？
- [ ] 在四分之一弦点之前，随$\alpha$增大而前移
- [x] 对每一个小$\alpha$都在四分之一弦点
- [ ] 在四分之一弦点之后，随$\alpha$减小而后移
- [ ] 在弦长中点
::: solution
由对称性，对称剖面在零升力时力矩为零，所以$c_{m,ac} = 0$，而[[#eq-xcp-xac]]对每一个$c_l \neq 0$都给出$x_{cp} = x_{ac}$。只有有弯度的剖面（$c_{m,ac} \neq 0$）的压力中心才会移动。
:::
:::

## 系数可以依赖于什么：相似性

为什么系数值得列表呢？因为对于几何相似的物体，系数只依赖于少数几个无量纲数——正是这一点使得在风洞中试验模型、再让全尺寸飞机上天成为合理的做法。

::: theorem 气动力的无量纲形式 {#thm-similarity}
设给定形状物体上的升力$L$只依赖于其尺寸$\ell$、姿态$\alpha$，以及自由来流的速度$V_\infty$、密度$\rho_\infty$、黏度$\mu_\infty$和声速$a_\infty$。则
$$
C_L = \frac{L}{q_\infty \ell^2} = f\!\left(\alpha,\ \mathrm{Re},\ M_\infty\right), \qquad
\mathrm{Re} = \frac{\rho_\infty V_\infty \ell}{\mu_\infty}, \qquad M_\infty = \frac{V_\infty}{a_\infty},
$$
$C_D$和$C_M$亦然。两个几何相似的物体在相同的$\alpha$、$\mathrm{Re}$和$M_\infty$下具有相同的系数（**动力相似**）。
:::

::: proof
这就是[[fluid-mechanics/dimensional-analysis]]中的白金汉$\Pi$定理。关系式$L = \phi(\ell, \alpha, V_\infty, \rho_\infty, \mu_\infty, a_\infty)$涉及七个量，其中一个（$\alpha$）本身已是无量纲的。六个有量纲的量涉及三个基本量纲$\mathsf{M}$、$\mathsf{L}$、$\mathsf{T}$，而$\rho_\infty$、$V_\infty$、$\ell$在量纲上相互独立（它们的幂的乘积不可能是无量纲的），因此可作为重复变量。其余三个有量纲的量各给出一个组合：$L/(\rho_\infty V_\infty^2 \ell^2)$、$\mu_\infty/(\rho_\infty V_\infty \ell) = 1/\mathrm{Re}$和$a_\infty/V_\infty = 1/M_\infty$。于是定理表明，一个无量纲组合是其他组合的函数，$L/(\rho_\infty V_\infty^2\ell^2) = g(\alpha, \mathrm{Re}, M_\infty)$；吸收因子$\tfrac{1}{2}$并以$\ell^2$或$S$为参考面积，即得定理的表述。假设：所列变量是仅有的重要变量——没有自由面（否则弗劳德数会出现），物体没有传热，表面光滑（否则相对粗糙度$k/\ell$会出现），来流湍流度低，以及$\gamma$固定的完全气体（对空气，比热比$\gamma = 1.4$；在高温下$\gamma$本身也成为一个参数）。
:::

雷诺数衡量惯性力与黏性力之比，它控制边界层：边界层在哪里变为湍流、是否分离以及在哪里分离，从而控制阻力和最大升力。马赫数衡量压缩性的重要程度；在大约$M_\infty = 0.3$以下，密度变化不到约百分之五，流动按不可压缩处理，这就是本课程前半部分的假设。

::: example 模型试验为何困难 {#ex-tunnel}
一个弦长$c = 1.5\,\mathrm{m}$的机翼在海平面（$\rho_\infty = 1.225\,\mathrm{kg/m^3}$，$\mu_\infty = 1.789\times10^{-5}\,\mathrm{Pa\,s}$，$a_\infty = 340.3\,\mathrm{m/s}$）以$V_\infty = 70\,\mathrm{m/s}$飞行。要试验一个十分之一缩比模型。(a) 求全尺寸的$\mathrm{Re}$和$M_\infty$。(b) 常压风洞需要多大风速才能匹配$\mathrm{Re}$？这可以接受吗？(c) 解决办法是什么？
::: solution
(a) $\mathrm{Re} = \rho_\infty V_\infty c/\mu_\infty = 1.225 \times 70 \times 1.5/1.789\times10^{-5} = 7.19\times10^6$，$M_\infty = 70/340.3 = 0.206$。

(b) 用同样的空气，$\mathrm{Re} \propto V_\infty c$，因此$c$小十倍的模型需要$V_\infty = 700\,\mathrm{m/s}$——马赫数$2.06$。流场中会出现真实飞机从未遇到的激波：匹配了$\mathrm{Re}$，却破坏了$M_\infty$相似。所得系数将毫无用处。

(c) 改变**气体状态**，而不是速度。以$V_\infty = 70\,\mathrm{m/s}$、相同温度（因此$a_\infty$和$M_\infty$不变）运行，但压强提高到十倍：由完全气体定律，$\rho_\infty$增大到十倍，而气体的黏度基本与压强无关，所以
$$
\mathrm{Re}_\text{模型} = \frac{(12.25)(70)(0.15)}{1.789\times10^{-5}} = 7.19\times10^6 .
$$
现在两个组合都匹配了。增压风洞正是这样做的；另一种办法用于低温风洞，即冷却气体，这同时提高$\rho$并降低$\mu$。**合理性检验：**模型上的动压是全尺寸值的十倍，因此模型单位面积上的载荷大十倍——这也是增压风洞模型用高强度钢加工的原因之一。
:::
:::

::: application 阅读翼型数据表
像艾博特（Abbott）与冯·多恩霍夫（von Doenhoff）的《机翼剖面理论》（*Theory of Wing Sections*）这样的剖面数据手册，对每个翼型和若干雷诺数给出升力曲线$c_l(\alpha)$、力矩曲线$c_{m,ac}(c_l)$和阻力极曲线$c_d(c_l)$，这些数据是在低湍流度风洞中、低马赫数下用二维模型测得的。有用的数值按固定顺序读取：零升迎角$\alpha_{L=0}$（正弯度时为负）、升力线斜率$a_0 = dc_l/d\alpha$（接近每弧度$2\pi$，即每度$0.11$）、最大升力系数与失速特性（强烈依赖于$\mathrm{Re}$）、$c_{m,ac}$（近乎常数），以及最小阻力和低阻“阻力桶”的范围（强烈依赖于$\mathrm{Re}$和粗糙度）。前两项来自无黏理论（[[aerodynamics/thin-airfoil-theory]]）；后两项需要边界层理论（[[aerodynamics/viscous-aerodynamics]]）。
:::

::: history
对气动力的系统测量比动力飞行更早。奥托·**李林塔尔**（Otto Lilienthal）用旋臂机和在自然风中测量了弯曲表面上的力，并于1889年出版了《鸟类飞行——航空的基础》（*Der Vogelflug als Grundlage der Fliegekunst*），书中的数表和极曲线图表明，弯曲表面产生升力的能力远胜于平板。威尔伯·**莱特**与奥维尔·**莱特**（Wilbur and Orville Wright）在1900—1901年发现，他们的滑翔机产生的升力比李林塔尔的数表和惯用的“斯米顿系数”（Smeaton coefficient，在他们的单位制中约为$0.005$）所预测的要小得多；根据滑翔机和风筝试验，他们得出该系数应接近$0.0033$的结论（现代值约为$0.00326$）。这并不能解释全部的不足，因此在1901年秋，他们在代顿建造了一座小型风洞，配有测量升力与阻力**比值**的天平，试验了约两百个模型翼面。这些数据设计出了成功的1902年滑翔机和1903年的“飞行者”号。雷诺（Reynolds）1883年的管流实验提供了相似参数，后来用它解释了为什么小模型试验会误判最大升力和阻力；而增压风洞——由马克斯·门克（Max Munk）倡导、1922年首次运行的NACA兰利变密度风洞——最早像[[#ex-tunnel]]那样着手解决这一问题。
:::

## 小结

::: summary
- 每一个气动力和气动力矩都是表面**压强**（法向）和**切应力**（切向）的积分。升力和阻力相对于自由来流定义，法向力和轴向力相对于弦线定义；两者相差一个转角$\alpha$的旋转，[[#eq-rotate]]。
- 系数用$q_\infty = \tfrac12\rho_\infty V_\infty^2$和注明的参考面积（对力矩还要加参考长度）去除。剖面系数用小写字母，取单位展长上的值。在不可压缩流动中$C_p = (p - p_\infty)/q_\infty = 1 - (V/V_\infty)^2$。
- $c_n$是下表面与上表面$C_p$曲线之间的面积；$c_{m,LE}$是它的一阶矩，[[#eq-cn-cm]]。要得到阻力，必须分辨前缘吸力峰。
- **压力中心**随升力移动，对有弯度的剖面在零升力时没有定义。**气动中心**是$c_m$与$c_l$无关的那一点；低速时它靠近四分之一弦点，且$x_{cp}/c = x_{ac}/c - c_{m,ac}/c_l$。
- 对给定形状，系数只依赖于$\alpha$、$\mathrm{Re}$和$M_\infty$（白金汉$\Pi$定理）。要在小模型上同时匹配$\mathrm{Re}$和$M_\infty$，需要密度更大的气体（增压或低温）。
:::

## 习题

::: exercise 动压 {level=1 check="3.00"}
求海平面来流（$\rho_\infty = 1.225\,\mathrm{kg/m^3}$）在$V_\infty = 70\,\mathrm{m/s}$时的动压。（以kPa为单位输入$q_\infty$。）
::: solution
$q_\infty = \tfrac12(1.225)(70)^2 = 3001\,\mathrm{Pa} = 3.00\,\mathrm{kPa}$。一个有用的参照：$70\,\mathrm{m/s}$约为$136$节，是典型的轻型双发飞机进近速度，而$3\,\mathrm{kPa}$只是大气压的百分之三——气动压强是叠加在很大的环境压强之上的小差值。
:::
:::

::: exercise 滑翔机的升力系数 {level=1 check="0.741"}
一架质量$500\,\mathrm{kg}$、机翼面积$12\,\mathrm{m^2}$的滑翔机在海平面以$30\,\mathrm{m/s}$平飞。求其升力系数（取$g = 9.81\,\mathrm{m/s^2}$）。（输入$C_L$。）
::: solution
$C_L = mg/(q_\infty S) = 500 \times 9.81 / \left(\tfrac12 \times 1.225 \times 30^2 \times 12\right) = 4905/6615 = 0.741$。这是典型的热气流盘旋升力系数：滑翔机以相当高的$C_L$缓慢盘旋。
:::
:::

::: exercise 由当地速度求压强系数 {level=1 check="-0.96"}
在低速流中，机翼上表面某点的当地速度是自由来流速度的$1.4$倍。求该点的压强系数。（输入$C_p$。）
::: solution
由[[#eq-cp-incomp]]，$C_p = 1 - 1.4^2 = 1 - 1.96 = -0.96$。当地压强比环境压强低$0.96\,q_\infty$。
:::
:::

::: exercise 由体轴天平求升力和阻力 {level=2 check="136"}
一个二维模型在$\alpha = 10^\circ$时$N' = 850\,\mathrm{N/m}$，$A' = -12\,\mathrm{N/m}$（轴向力指向前缘）。求$L'$和$D'$。（以N/m为单位输入$D'$。）
::: solution
$L' = 850\cos 10^\circ - (-12)\sin 10^\circ = 837.1 + 2.1 = 839\,\mathrm{N/m}$；$D' = 850\sin 10^\circ + (-12)\cos 10^\circ = 147.6 - 11.8 = 136\,\mathrm{N/m}$。负的轴向力就是前缘吸力；它**减小**了阻力，但阻力仍为正，对于定常二维流动中的物体理应如此。
:::
:::

::: exercise 有弯度剖面的压力中心 {level=2 check="0.35"}
某剖面的气动中心位于四分之一弦点，$c_{m,ac} = -0.05$。当$c_l = 0.5$时压力中心在哪里？（输入$x_{cp}/c$。）
::: solution
由[[#eq-xcp-xac]]，$x_{cp}/c = 0.25 - (-0.05)/0.5 = 0.25 + 0.10 = 0.35$。$c_l = 0.25$时它将位于$0.45$，$c_l = 0.05$时位于后缘：正弯度的低头力偶使压力中心随升力下降而后移。
:::
:::

::: exercise 由两点求气动中心 {level=2 check="0.27"}
某剖面的试验给出：$c_l = 0$时$c_{m,c/4} = -0.050$，$c_l = 0.8$时$c_{m,c/4} = -0.066$。确定气动中心的位置。（输入$x_{ac}/c$。）
::: solution
$m_0 = (-0.066 + 0.050)/0.8 = -0.020$，所以由[[#eq-xac]]，$x_{ac}/c = 0.25 - (-0.020) = 0.27$，且$c_{m,ac} = c_{m,0} = -0.050$。力矩随升力增大而更加低头，因此升力作用在四分之一弦点之后，气动中心也在其后。
:::
:::

::: exercise 失速速度与雷诺数 {level=2 check="2.91e6"}
一架质量$1200\,\mathrm{kg}$的飞机，$S = 16\,\mathrm{m^2}$，平均弦长$1.5\,\mathrm{m}$，$C_{L,\max} = 1.5$。求海平面失速速度以及该速度下以弦长为特征长度的雷诺数（$\mu_\infty = 1.789\times10^{-5}\,\mathrm{Pa\,s}$）。（输入$\mathrm{Re}$。）
::: solution
$V_s = \sqrt{2 \times 1200 \times 9.81/(1.225 \times 16 \times 1.5)} = \sqrt{800.8} = 28.3\,\mathrm{m/s}$，$\mathrm{Re} = 1.225 \times 28.3 \times 1.5/1.789\times10^{-5} = 2.91\times10^6$。在这一范围内最大升力强烈依赖于$\mathrm{Re}$，因此$C_{L,\max}$数据应取自接近$3\times10^6$的试验，而不是取自小风洞中$5\times10^5$的试验。
:::
:::

::: exercise 由压强分布求力矩 {level=3 check="-0.25"}
某薄剖面的$C_{p,l} - C_{p,u} = 3\,(1 - \xi)^2$，$\xi = x/c$。求$c_n$和$c_{m,LE}$，并确定压力中心的位置。（输入$c_{m,LE}$。）
::: solution
$c_n = \int_0^1 3(1-\xi)^2\,d\xi = 1$。$c_{m,LE} = -\int_0^1 3\xi(1-\xi)^2\,d\xi = -3\left(\tfrac12 - \tfrac23 + \tfrac14\right) = -3 \times \tfrac{1}{12} = -0.25$。于是$x_{cp}/c = 0.25/1 = 0.25$：载荷集中在头部附近，就像有迎角的真实翼型那样，其形心位于四分之一弦点。这一分布与薄翼理论中平板载荷的前两阶矩相同，而后者在前缘处集中得更为强烈。
:::
:::

::: exercise 用迎角斜率表示气动中心 {level=3}
风洞数据常常以$\alpha$而不是$c_l$为自变量给出。设在线性段内$c_l = a_0(\alpha - \alpha_{L=0})$，$c_{m,c/4} = c_{m,0} + b_0(\alpha - \alpha_{L=0})$，斜率$a_0$和$b_0$为常数。用$a_0$和$b_0$推导气动中心的位置，并证明对于四分之一弦点力矩不随迎角变化的任何剖面，气动中心都位于四分之一弦点。
::: solution
由[[#eq-transfer]]，$c_{m,x} = c_{m,0} + b_0(\alpha - \alpha_{L=0}) + (x/c - 1/4)a_0(\alpha - \alpha_{L=0})$。当$b_0 + (x/c - 1/4)a_0 = 0$时它与$\alpha$无关，即
$$
\frac{x_{ac}}{c} = \frac14 - \frac{b_0}{a_0},
$$
这就是$m_0 = b_0/a_0$时的[[#eq-xac]]（由链式法则，$dc_m/dc_l = (dc_m/d\alpha)/(dc_l/d\alpha)$）。若$b_0 = 0$，则气动中心位于$c/4$。两个斜率必须采用相同的角度单位；这样它们的比值就与单位无关。
:::
:::

::: exercise 规划增压风洞试验 {level=3 check="8"}
要在闭口回流式风洞中，以与全尺寸机翼在海平面相同的马赫数和雷诺数，试验一个八分之一缩比的机翼模型。风洞中空气的温度与海平面大气相同。(a) 需要多大的静压（以$101.3\,\mathrm{kPa}$的倍数表示）？(b) 讨论由此产生的两个实际问题以及一种替代方案。（对(a)输入压强比。）
::: solution
(a) 温度相同意味着$a_\infty$和$\mu_\infty$相同；于是$M_\infty$相同意味着$V_\infty$相同。由于$\mathrm{Re} = \rho_\infty V_\infty \ell/\mu_\infty$而$\ell$缩小为$1/8$，$\rho_\infty$必须增大到$8$倍，而在温度固定时$p \propto \rho$：风洞必须在$8$个大气压下运行。

(b) 模型上的动压是全尺寸值的八倍，因此模型及其支撑承受八倍的单位面积载荷并会产生变形——模型必须用刚硬的钢制造，而其气动弹性外形仍可能与飞行中不同。风洞壳体是一个大型压力容器，必须按适用的压力容器规范设计和检验，每更换一次模型都要泄压，因此效率很低。在相同马赫数下，驱动功率也与密度成比例增大。主要的替代方案是使用约$100\,\mathrm{K}$氮气的**低温**风洞：冷却提高了密度，同时降低了黏度和声速，因此能在适中的压强和不大的功率下大幅提高雷诺数——代价是隔热、结霜和模型材料方面的问题。两者之间的取舍是一个真正的工程选择，没有唯一正确的答案。
:::
:::
