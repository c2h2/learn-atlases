薄翼理论（[[aerodynamics/thin-airfoil-theory]]）仅由中弧线就给出了升力线斜率、零升迎角和俯仰力矩，但它对真实剖面的**压强分布**——头部的吸力峰、后部的压强恢复、厚度的影响——给不出任何可靠的结论，而正是这些决定了边界层在哪里分离以及剖面有多大阻力。精确的解析解只对特殊形状（圆柱、茹科夫斯基翼型）存在。**面元法**（panel method）则对**任意**形状数值求解势流问题：把表面分割成直线面元，每个面元上带有一层强度未知的源或涡，在每个面元的一点上施加无穿透表面流动的条件，就得到一组线性方程。用计算机求解这些方程，就得到各处的表面速度和压强。面元法是第一种在工业界常规使用的计算空气动力学方法，它与边界层计算耦合后，至今仍是翼型设计的日常工具。

本章从各个部件出发构建这一方法：源面和涡面，单个面元诱导的速度，线性方程组的组装，离散形式的库塔条件，以及判断面元解是否可信的各种检验。先修内容是[[aerodynamics/potential-flow]]中的基本流动和[[aerodynamics/thin-airfoil-theory]]中的库塔条件；所需的线性代数是高斯消元法。

## 源面与涡面

强度为$\Lambda$的点源产生径向速度$\Lambda/(2\pi r)$。把源沿一条曲线连续分布，单位长度上的强度为$\lambda(s)$（单位$\mathrm{m/s}$），就得到一个**源面**；把强度为$\gamma(s)$的涡连续分布，就得到一个**涡面**。源面的微元$ds$是强度为$\lambda\,ds$的点源，因此在距它$r$的点$P$处，源面诱导的速度势为
$$
\phi(P) = \int \frac{\lambda(s)}{2\pi}\ln r\,ds ,
$$
同样，涡面诱导$\phi(P) = -\int \frac{\gamma(s)}{2\pi}\theta\,ds$，其中$\theta$是从微元看去$P$的极角。每个微元都满足拉普拉斯方程，所以整个面也满足，叠加在均匀流上，结果仍是势流。

::: proposition 穿过面的速度跳跃 {#prop-jumps}
穿过当地强度为$\lambda$的源面，**法向**速度跳跃$\lambda$：紧贴源面两侧，面所诱导的法向分量分别为$+\lambda/2$和$-\lambda/2$（均指向离开面的方向），而切向速度连续。穿过强度为$\gamma$的涡面，**切向**速度跳跃$\gamma$，法向速度连续。
:::

::: proof
考虑面上一段长为$2a$、强度在局部为常数的短直线段，以及位于其中点上方高度$y$处的一点。该段诱导的法向速度为
$$
v = \int_{-a}^{a}\frac{\lambda}{2\pi}\,\frac{y\,d\xi}{\xi^2 + y^2} = \frac{\lambda}{\pi}\arctan\frac{a}{y} \;\longrightarrow\; \frac{\lambda}{2}\quad (y \to 0^+),
$$
由对称性，$y \to 0^-$时为$-\lambda/2$。面的其余部分距该点有限远，它诱导的速度穿过该段是连续的，所以跳跃完全来自局部贡献：$\Delta v_n = \lambda$。局部段的切向贡献由对称性为$\int \frac{\lambda}{2\pi}\frac{-\xi\,d\xi}{\xi^2 + y^2} = 0$，所以切向速度连续。对于涡面，涡微元的速度就是源微元的速度旋转$90^\circ$，因此法向和切向分量的角色互换：$\Delta v_t = \gamma$。（这也是[[aerodynamics/thin-airfoil-theory]]中所用的结果，在那里它由跨过面的小矩形上的环量导出。）假设：面是光滑的，其强度在所考虑的点处连续。
:::

其物理意义是：源面**把流动推离自身**，因此来流中一个封闭的源面可以使来流绕过一个物体；涡面在切向速度上产生**滑移**，这正是使翼型上表面速度高于下表面所需要的——即环量和升力。单独的源分布净环量为零，永远不能产生升力。

## 单个面元

把物面离散为$N$个直线**面元**。在每个面元上取强度为常数（最简单的选择；更好的程序采用线性或更高阶的变化）。我们需要单位强度的一个面元在任意处诱导的速度。

::: proposition 常强度源面元诱导的速度 {#prop-panel-velocity}
（在其自身的局部坐标中）沿$x$轴从$x = -a$到$x = a$放置、源强为常数$\lambda$的面元，在点$(x, y)$处诱导
$$
u = \frac{\lambda}{4\pi}\ln\frac{(x + a)^2 + y^2}{(x - a)^2 + y^2}, \qquad
v = \frac{\lambda}{2\pi}\left(\theta_2 - \theta_1\right),
$$ {#eq-panel-uv}
其中$\theta_1$和$\theta_2$是从面元起点$(-a, 0)$和终点$(a, 0)$看去该点的极角，因此$\theta_2 - \theta_1$是面元在该点所张的角。在面元本身上，$v = \pm\lambda/2$，而$u$除端点外是有限的。同一面元若带有强度为$\gamma$（顺时针为正）的涡面，则诱导$u = \frac{\gamma}{2\pi}(\theta_2 - \theta_1)$，$v = -\frac{\gamma}{4\pi}\ln\frac{(x + a)^2 + y^2}{(x - a)^2 + y^2}$。
:::

::: proof
位于$(\xi, 0)$的微元$d\xi$诱导径向速度$\lambda\,d\xi/(2\pi r)$，其中$r^2 = (x - \xi)^2 + y^2$，其分量为
$$
du = \frac{\lambda}{2\pi}\frac{(x - \xi)\,d\xi}{(x - \xi)^2 + y^2}, \qquad dv = \frac{\lambda}{2\pi}\frac{y\,d\xi}{(x - \xi)^2 + y^2}.
$$
把$du$从$\xi = -a$积分到$a$：令$w = (x - \xi)^2 + y^2$，$dw = -2(x - \xi)\,d\xi$，所以$u = -\frac{\lambda}{4\pi}\left[\ln w\right]_{-a}^{a} = \frac{\lambda}{4\pi}\ln\frac{(x + a)^2 + y^2}{(x - a)^2 + y^2}$。对$y > 0$积分$dv$：$v = \frac{\lambda}{2\pi}\left[-\arctan\frac{x - \xi}{y}\right]_{-a}^{a} = \frac{\lambda}{2\pi}\left[\arctan\frac{x + a}{y} - \arctan\frac{x - a}{y}\right]$，而方括号等于$\theta_2 - \theta_1$，因为对矢量$(X, y)$的角$\theta$有$\arctan(X/y) = \pi/2 - \theta$；对$y < 0$，只要一致地量取角度，同样的形式也成立，并给出符号的改变。在面元上（$y \to 0^+$，$|x| < a$），所张的角趋于$\pi$，所以$v \to \lambda/2$，与[[#prop-jumps]]一致。顺时针涡微元诱导$(V_r, V_\theta) = (0, -\gamma\,d\xi/2\pi r)$，即源微元的速度顺时针旋转$90^\circ$：$(du, dv)_\text{涡} = (dv, -du)_\text{源}$，并以$\gamma$代替$\lambda$，即得所述的涡面元公式。
:::

::: example 单个面元的近场与远场 {#ex-one-panel}
一个单位强度$\lambda = 1\,\mathrm{m/s}$的源面元从$x = -1\,\mathrm{m}$延伸到$x = 1\,\mathrm{m}$。求它在$(2, 0.5)\,\mathrm{m}$处诱导的速度，并与位于原点、总强度相同的点源的速度相比较。
::: solution
从面元起点看该点的角度为$\theta_1 = \arctan(0.5/3) = 9.46^\circ$，从终点看为$\theta_2 = \arctan(0.5/1) = 26.57^\circ$；面元所张的角为$17.10^\circ = 0.2985\,\mathrm{rad}$。由[[#eq-panel-uv]]，
$$
u = \frac{1}{4\pi}\ln\frac{3^2 + 0.5^2}{1^2 + 0.5^2} = \frac{1}{4\pi}\ln 7.4 = 0.159\,\mathrm{m/s}, \qquad v = \frac{0.2985}{2\pi} = 0.0475\,\mathrm{m/s}.
$$
位于原点、强度为$2a\lambda = 2\,\mathrm{m^2/s}$的点源，在距离$r = \sqrt{4.25} = 2.062\,\mathrm{m}$处给出沿$\mathbf{r}$方向的速度$2/(2\pi \times 2.062) = 0.154\,\mathrm{m/s}$：$u = 0.150$，$v = 0.037\,\mathrm{m/s}$。**合理性检验：**在距面元端点仅一个面元长度处，点源近似的$u$已在约6%以内，但$v$偏差21%；距离更大时两者越来越接近，这就是快速面元程序用点奇点（多极展开）代替远处面元、只对近邻面元计算精确公式的原因。
:::

## 源面元法

::: algorithm 无升力流动的源面元法 {#alg-source-panel}
1. **几何。**在物面上按**顺时针**顺序布置$N + 1$个点，并把它们连成$N$个直线面元。对面元$j$记录其长度$S_j$、单位切向量$\mathbf{t}_j$（沿行进方向）、外法向单位矢量$\mathbf{n}_j$，以及位于面元中点的**控制点**$\mathbf{x}_j$。令$\beta_j$为$\mathbf{V}_\infty$与$\mathbf{n}_j$之间的夹角。
2. **影响系数。**对每个控制点$i$和每个面元$j \ne i$，用[[#eq-panel-uv]]（先旋转到面元$j$的局部坐标中）计算面元$j$上单位强度的源在$\mathbf{x}_i$处诱导的速度，并取其沿$\mathbf{n}_i$的法向分量$I_{ij}$和沿$\mathbf{t}_i$的切向分量$J_{ij}$。自影响为$I_{ii} = \tfrac12$，$J_{ii} = 0$。
3. **流动相切方程。**要求每个控制点上的法向速度为零：
$$
\sum_{j=1}^{N} I_{ij}\,\lambda_j + V_\infty\cos\beta_i = 0, \qquad i = 1, \dots, N .
$$ {#eq-tangency}
4. **求解**关于$\lambda_j$的$N \times N$线性方程组（高斯消元法；对合理的面元划分，矩阵是满阵且对角占优的）。
5. **表面速度和压强。**在每个控制点上$V_i = V_\infty\,\mathbf{e}_\infty\cdot\mathbf{t}_i + \sum_{j} J_{ij}\lambda_j$，$C_{p,i} = 1 - (V_i/V_\infty)^2$。
6. **检验。**对封闭物体，$\sum_j \lambda_j S_j = 0$（无净源）；压差阻力$\sum_j C_{p,j}\,S_j\,\mathbf{n}_j\cdot\mathbf{e}_\infty$应接近零；结果应随$N$加倍而收敛。
:::

这些方程是边界条件的**离散**形式：物面只在控制点上是流线，在控制点之间容许少量渗漏。因此首先要检验的是随面元数的收敛性，并且面元应集中在曲率和速度梯度大的地方——翼型的前缘和后缘，通常采用**余弦分布**，$x_k = \tfrac c2\left(1 - \cos\tfrac{k\pi}{n}\right)$。

::: example 圆柱上的八个面元 {#ex-cylinder-8}
对来流$V_\infty$中半径为$R$的圆柱应用源面元法，使用八个等长面元，布置成其中一个面元正对来流（控制点位于圆柱周围$0^\circ, 45^\circ, \dots, 315^\circ$处）。给出源强和表面压强系数，并与精确解$C_p = 1 - 4\sin^2\theta$相比较。
::: solution
面元顶点位于圆上$\theta = 22.5^\circ \pm 45^\circ k$处，所以每个面元的长度为$S = 2R\sin22.5^\circ = 0.765R$，其中点位于半径$R\cos22.5^\circ = 0.924R$处。建立$8 \times 8$影响矩阵并求解[[#eq-tangency]]（一个简短的程序即可完成；由对称性，只有三个强度是不同的），以$\theta$从圆柱前方量起，得到

| 控制点 | 前方（$0^\circ$） | $\pm45^\circ$ | $\pm90^\circ$ | $\pm135^\circ$ | 后方（$180^\circ$） |
|---|---|---|---|---|---|
| $\lambda_j/(2\pi V_\infty)$ | $0.3765$ | $0.2662$ | $0$ | $-0.2662$ | $-0.3765$ |
| $V_j/V_\infty$ | $0$ | $1.414$ | $2.000$ | $1.414$ | $0$ |
| $C_p$（面元法） | $1.000$ | $-1.000$ | $-3.000$ | $-1.000$ | $1.000$ |
| $C_p$精确值 | $1$ | $-1$ | $-3$ | $-1$ | $1$ |

前方的源把迎面而来的气流推向两侧，后方的汇又把它吸回，而平行于来流的顶部和底部面元上的强度为零。**检验：**$\sum\lambda_jS_j = 2\pi V_\infty S\,(0.3765 + 2 \times 0.2662 + 0 - 2 \times 0.2662 - 0.3765) = 0$（物体封闭），控制点上的压强与精确解在所示的四位数字上一致。只用八个面元就在圆上得到这样的一致，部分是对称性带来的运气；在头部曲率急剧变化的翼型上，需要多得多的面元。
:::

## 升力：涡面元与库塔条件

源分布不能给出环量，因此有升力的物体需要涡。有两种经典的布置方式。

- **涡面元**（每个面元带有各自的涡强$\gamma_j$，没有源）。相切条件给出关于$N$个未知数的$N$个方程——但对于具有尖后缘的封闭物体，在面元划分很细的极限下解**不**唯一，正如连续问题的解不唯一一样（任何环量都是允许的）。必须加上库塔条件：在离散形式中，后缘处的$\gamma$为零；采用线性变化的强度时，在两个后缘节点上实现为$\gamma_1 + \gamma_{N+1} = 0$，采用常强度时，对与后缘相邻的两个面元实现为$\gamma_1 = -\gamma_N$。由于方程比未知数多一个，要舍去一个相切方程（通常是远离后缘的某个控制点上的方程）。
- **源加上一个统一涡强**（赫斯-史密斯（Hess–Smith）升力方法）。每个面元带有各自的源强$\lambda_j$，**以及**在所有面元上都相同的涡强$\gamma$。这给出$N + 1$个未知数：$N$个相切方程，再加上一个库塔方程，即与后缘相邻的两个面元上的切向速度大小相等，$V_1 = -V_N$（那里两个面元的切向量方向相反）。环量为$\Gamma = \gamma\sum_j S_j$，升力由压强或由库塔-茹科夫斯基定理求得。

::: algorithm 赫斯-史密斯升力面元法 {#alg-hess-smith}
1. 用余弦分布对翼型划分面元，按顺时针方向从后缘沿下表面到前缘，再沿上表面回到后缘。
2. 对每个控制点$i$和面元$j$，计算面元$j$上单位源（$I_{ij}$、$J_{ij}$）和单位涡（$I^\gamma_{ij}$、$J^\gamma_{ij}$）的法向和切向影响系数；由于$\gamma$是共同的，把涡系数对$j$求和：$B_i = \sum_j I^\gamma_{ij}$，$C_i = \sum_j J^\gamma_{ij}$（自身项：源的法向为$\tfrac12$，涡的切向为$\tfrac12$）。
3. 每个控制点上的相切条件：$\sum_j I_{ij}\lambda_j + B_i\gamma = -V_\infty\cos\beta_i$。
4. 库塔条件：$\left(\sum_j J_{1j}\lambda_j + C_1\gamma + V_{\infty,t1}\right) + \left(\sum_j J_{Nj}\lambda_j + C_N\gamma + V_{\infty,tN}\right) = 0$。
5. 求解$(N+1) \times (N+1)$方程组；计算$V_i$、$C_{p,i}$，并积分得到$c_l$、$c_m$和压差阻力$c_{d,p}$（它应趋于零）。
:::

::: example 两个面元的集中涡法 {#ex-lumped}
最简单的升力面元法把薄翼型当作其中弧线，并分为$N$个面元。每个面元在其四分之一弦点处带有一个点涡$\Gamma_j$，在其四分之三弦点处施加相切条件。（之所以选择四分之一/四分之三的布置，是因为对单个面元它恰好再现薄翼理论：位于$c/4$的涡在$3c/4$处诱导下洗$\Gamma/(2\pi\cdot c/2) = \Gamma/(\pi c)$，令其等于$V_\infty\alpha$得$\Gamma = \pi\alpha cV_\infty$，即$c_l = 2\pi\alpha$。）用两个面元手算迎角为$\alpha$、弦长为单位长度的平板。
::: solution
涡位于$x = 0.125$和$0.625$，控制点位于$0.375$和$0.875$。位于$x_v$的顺时针涡在$x$处诱导向下的速度$\Gamma/(2\pi(x - x_v))$（若$x < x_v$则向上），相切条件要求每个控制点上的合计等于$V_\infty\alpha$：
$$
\begin{aligned}
\frac{\Gamma_1}{2\pi(0.25)} + \frac{\Gamma_2}{2\pi(-0.25)} &= V_\infty\alpha, \\
\frac{\Gamma_1}{2\pi(0.75)} + \frac{\Gamma_2}{2\pi(0.25)} &= V_\infty\alpha,
\end{aligned}
\qquad\text{即}\qquad
\begin{aligned}
0.6366\,\Gamma_1 - 0.6366\,\Gamma_2 &= V_\infty\alpha, \\
0.2122\,\Gamma_1 + 0.6366\,\Gamma_2 &= V_\infty\alpha .
\end{aligned}
$$
相加：$0.8488\,\Gamma_1 = 2V_\infty\alpha$，所以$\Gamma_1 = 2.356\,V_\infty\alpha = \tfrac{3\pi}{4}V_\infty\alpha$，$\Gamma_2 = \Gamma_1 - V_\infty\alpha/0.6366 = \tfrac{\pi}{4}V_\infty\alpha$。总和为$\Gamma = \pi V_\infty\alpha$，所以$c_l = 2\Gamma/V_\infty = 2\pi\alpha$——精确。对前缘的力矩为$c_{m,LE} = -2(0.125\,\Gamma_1 + 0.625\,\Gamma_2)/V_\infty = -2\alpha(0.2945 + 0.4909) = -\tfrac{\pi}{2}\alpha = -c_l/4$，同样精确。**合理性检验：**四分之三的升力在前面板上，正如薄翼理论奇异的前缘载荷所要求的。离散方法并不分辨载荷位于面元内的**何处**，但它给出了正确的积分结果。对NACA 2412的中弧线，同一方法用2个面元给出$\alpha_{L=0} = -2.18^\circ$，4个给出$-2.10^\circ$，8个给出$-2.078^\circ$，收敛于薄翼理论值$-2.077^\circ$；力矩$c_{m,c/4}$收敛得较慢（$-0.035$、$-0.049$、$-0.052$，用32个面元时为$-0.053$）。
:::
:::

| 0012, $5^\circ$ | 160 | $0.602$ | $0.0002$ |
| 2412, $0^\circ$ | 160 | $0.255$ | $0.0001$ |
| 2412, $4^\circ$ | 160 | $0.737$ | $-0.0002$ |
::: solution
**收敛性。**升力在$40$个面元时已收敛到三位数字；压差阻力在势流中应严格为零，它大致按$1/N^{1.5}$下降，是离散误差的直接度量。$N = 20$时$0.005$的阻力可以与该剖面的全部黏性阻力相比——绝不要从纯面元法读取阻力。

**厚度。**薄翼理论对任何对称剖面在$5^\circ$时都给出$c_l = 2\pi(0.0873) = 0.548$；面元法给出$0.602$，约高10%。在无黏流动中，厚度**提高**升力线斜率：对茹科夫斯基剖面，精确斜率约为$2\pi(1 + 0.77\,t/c)$，对12%的厚度是$1.09$倍，这里的面元结果（$0.602/0.548 = 1.10$）与之相符。

**弯度。**对2412，薄翼理论在$0^\circ$时给出$c_l = 0.228$，在$4^\circ$时给出$0.666$；面元法给出$0.255$和$0.737$。在$\mathrm{Re} \approx 6\times10^6$下的实测值接近薄翼理论的数值，因为上表面向后缘增厚的边界层减小了有效弯度和环量，其减小量与厚度使之增大的量大致相当。这种抵消是幸运的，但并不可靠；黏性-无黏方法（见下文）能正确地预测它。**合理性检验：**由表中得到的0012升力线斜率$0.602/5 = 0.120$每度高于每弧度$2\pi$（每度$0.110$），这对无黏流中的厚剖面是预料之中的。
:::
:::

::: quiz
某封闭物体的源面元解给出$\sum_j\lambda_jS_j = 0.08V_\infty c$，显然不为零。这说明什么？
- [ ] 物体正在产生升力
- [x] 离散化或影响系数有误（面元太少、符号错误或法线方向错误）
- [ ] 流动是可压缩的
- [ ] 什么也不说明：只有对称物体的这个和才为零
::: solution
对于均匀来流中的任何封闭物体，总源强必须为零，因为在封闭表面内部不能产生净流体。很大的非零和意味着出了问题——常见的是顺时针面元中混入了一个逆时针排序的面元（内法线），自影响项有误，或者在表面急剧弯曲处面元过粗。升力是由涡产生的，而不是由源。
:::
:::

::: warning 面元程序出错而不自知
最常见的错误是几何方面的。**方向：**按顺时针排序时，外法线是行进方向的**左**法线；一个反向的面元会把该处的源变成汇，而解就悄无声息地错了。**自影响：**对角项是$+\tfrac12$（紧贴面元**外侧**的法向速度）；用$-\tfrac12$求解的是物体内部的流动。**后缘：**标准开口后缘的NACA剖面会留下一个缺口；要么把它封闭（如[[#ex-naca-panels]]中那样），要么在缺口上加一个面元。**面元密度：**在尖锐前缘附近面元太少会使吸力峰分辨不足，于是吸力峰显得太低且太靠后——所预测的分离和最大升力也随之出错。在信任一个新程序之前，务必检验$\sum\lambda_jS_j \approx 0$、$c_{d,p} \approx 0$以及随$N$的收敛性，并与已知的精确情形（圆柱、茹科夫斯基翼型）相比较。
:::

## 从无黏到黏性：黏性-无黏干扰

单独的面元法对黏性一无所知：没有摩擦阻力，没有分离，没有失速，升力线斜率略高。实用的设计程序把它与**边界层**计算结合起来。无黏的表面速度驱动积分型边界层解（层流、转捩、湍流——这是[[aerodynamics/viscous-aerodynamics]]的主题）；边界层的**位移厚度**$\delta^*$再反馈给无黏解，方法是加厚物体，或在每个面元上加一个“蒸腾”源强$\lambda = d(V\delta^*)/ds$；两者反复迭代（或者更好地，联立求解）直到一致。后缘之后的尾迹也用同样的方式模拟。其结果给出符合实际的压强分布、包括层流分离泡效应在内的阻力极曲线，以及附着流或轻度分离流中后缘失速的起始。

::: application XFOIL与三维面元程序
这类二维程序中最著名的是马克·德雷拉（Mark Drela）的**XFOIL**（1989年），它采用线性涡量面元法，与带有$e^N$转捩判据的积分边界层方程耦合，并用牛顿法联立求解。它广泛用于低雷诺数翼型（滑翔机、风力机、无人机），在附着流范围内对升力和力矩的预测，以及在中等$\mathrm{Re}$下对阻力的预测，通常与良好的风洞数据相差在百分之几以内。在三维情形，面元程序（在覆盖整架飞机的表面面元上布置源-偶极子，并有从机翼拖出的尾迹面）从1970年代起就是飞机布局空气动力学的主力工具，由于它只需要表面网格，至今仍用于低速载荷计算和初步设计。它们受到与所有势流相同的假设的限制：亚临界的附着流动。
:::

::: history
面元法诞生于道格拉斯飞机公司，约翰·**赫斯**（John Hess）和A·M·O·**史密斯**（A. M. O. Smith）在那里发展了用于任意三维物体无升力势流的表面源方法（道格拉斯报告ES 40622，1962年；《船舶研究杂志》（*Journal of Ship Research*），1964年），并在《任意物体绕流势流的计算》（*Calculation of potential flow about arbitrary bodies*，《航空科学进展》（*Progress in Aeronautical Sciences*）第8卷，1967年）中综述了整个方法，包括[[#alg-hess-smith]]的升力推广。这一方法之所以切实可行，只是因为数字计算机已经能够求解几百个未知数的稠密线性方程组。在随后的几十年里，与边界层计算耦合的二维面元程序成为标准的翼型设计工具，德雷拉的XFOIL（1989年）是其中最著名的例子。
:::

## 小结

::: summary
- 源面使法向速度产生跳跃$\lambda$；涡面使切向速度产生跳跃$\gamma$。源塑造绕物体的流动；涡给出环量和升力。
- 常强度面元在其自身坐标中诱导$u = \frac{\lambda}{4\pi}\ln(r_1^2/r_2^2)$和$v = \frac{\lambda}{2\pi}(\theta_2 - \theta_1)$；自诱导法向速度为$\lambda/2$。
- 源面元法在每个控制点上施加零法向速度条件，得到$N \times N$线性方程组；然后求$V_i$和$C_{p,i} = 1 - (V_i/V_\infty)^2$。
- 升力方法加入涡（涡面元，或赫斯-史密斯方法中的一个共同涡强）以及一个库塔条件方程。
- 检验$\sum\lambda_jS_j = 0$、$c_{d,p} \to 0$以及随$N$的收敛性；在前缘和后缘处加密面元。
- 无黏面元法高估真实剖面的升力线斜率；与边界层计算耦合（如XFOIL中那样）可给出阻力，以及直至轻度分离的符合实际的升力。
:::

## 习题

::: exercise 源面处的法向速度 {level=1 check="1.5"}
某源面的当地强度为$\lambda = 3\,\mathrm{m/s}$。它在紧贴自身两侧诱导的法向速度（大小）是多少？（以m/s为单位输入。）
::: solution
由[[#prop-jumps]]，为$\lambda/2 = 1.5\,\mathrm{m/s}$，在两侧都指向离开面的方向。
:::
:::

::: exercise 使源强之和闭合 {level=1 check="-0.3"}
一个封闭物体用四个等长面元划分。其中三个源强为$2.0$、$-0.5$和$-1.2\,\mathrm{m/s}$。要使解自洽，第四个必须是多少？（以m/s为单位输入。）
::: solution
在$S_j$相等时，$\sum\lambda_jS_j = 0$要求$\lambda_4 = -(2.0 - 0.5 - 1.2) = -0.3\,\mathrm{m/s}$。
:::
:::

::: exercise 一个集中涡 {level=1 check="0.329"}
把$3^\circ$迎角的薄平板模拟为位于其四分之一弦点的一个集中涡，并在其四分之三弦点施加相切条件。得到的升力系数是多少？（输入$c_l$。）
::: solution
如[[#ex-lumped]]所示，$\Gamma = \pi\alpha cV_\infty$，$c_l = 2\pi\alpha = 2\pi(0.05236) = 0.329$。
:::
:::

::: exercise 一个面元诱导的速度 {level=2 check="0.5"}
一个常强度$\lambda = 2\,\mathrm{m/s}$的源面元沿$x$轴从$x = -1\,\mathrm{m}$延伸到$x = 1\,\mathrm{m}$。求它在$(0, 1)\,\mathrm{m}$处诱导的速度分量。（以m/s为单位输入$v$。）
::: solution
由对称性$u = \frac{\lambda}{4\pi}\ln(2/2) = 0$。面元所张的角为$\theta_2 - \theta_1 = 135^\circ - 45^\circ = 90^\circ = \pi/2$，所以$v = \frac{2}{2\pi}\cdot\frac\pi2 = 0.5\,\mathrm{m/s}$，向上。
:::
:::

::: exercise 控制点上的压强 {level=2 check="-2.42"}
面元解在翼型头部附近的某控制点上给出切向速度$1.85V_\infty$。求该处的$C_p$，并说明若$M_\infty = 0.25$，压缩性是否已大到不可忽略。（输入$C_p$。）
::: solution
$C_p = 1 - 1.85^2 = -2.42$。当地马赫数约为$1.85 \times 0.25 = 0.46$（略大一些，因为当地温度较低），远高于$0.3$；不可压缩的面元结果应进行压缩性修正（见[[aerodynamics/compressible-airfoils]]）。
:::
:::

::: exercise 集中涡强度之比 {level=2 check="3"}
在平板的两面元集中涡解（[[#ex-lumped]]）中，前后两个涡之比$\Gamma_1/\Gamma_2$是多少？这个比值会随迎角变化吗？（输入该比值。）
::: solution
$\Gamma_1 = \tfrac{3\pi}{4}V_\infty\alpha$，$\Gamma_2 = \tfrac\pi4V_\infty\alpha$，所以比值为$3$，与$\alpha$无关：问题是线性的，所以每个强度都与$\alpha$成正比。这一比值反映了前重后轻的平板分布$\gamma \propto \sqrt{(c - x)/x}$；对精确分布在弦长前后两半上分别积分，得到$\left(\tfrac\pi4 + \tfrac12\right)/\left(\tfrac\pi4 - \tfrac12\right) = 4.5$，因此离散方法在得到正确总量的同时，在面元之间重新分配了载荷。
:::
:::

::: exercise 由源面元导出涡面元 {level=3}
从[[#prop-panel-velocity]]证明中的微元速度出发，证明强度为$\gamma$（顺时针为正）的常强度**涡**面元诱导$u = \frac{\gamma}{2\pi}(\theta_2 - \theta_1)$和$v = -\frac{\gamma}{4\pi}\ln\frac{(x + a)^2 + y^2}{(x - a)^2 + y^2}$，并推出紧贴面元上方的自诱导切向速度。解释为什么对于用涡面元划分的有升力物体，仅靠控制点上的相切条件不能确定其环量。
::: solution
位于$(\xi, 0)$、强度为$\gamma\,d\xi$的顺时针点涡在距离$r$处诱导$V_\theta = -\gamma\,d\xi/(2\pi r)$。令$\mathbf{r} = (x - \xi, y)$，顺时针切向为$(y, -(x - \xi))/r$，所以$du = \frac{\gamma}{2\pi}\frac{y\,d\xi}{r^2}$，$dv = -\frac{\gamma}{2\pi}\frac{(x - \xi)\,d\xi}{r^2}$——即源微元的$(dv, -du)$。完全按照证明中的方法积分，即得所述公式。紧贴面元上方所张的角为$\pi$，所以$u = \gamma/2$；紧贴下方为$-\gamma/2$：切向速度跳跃$\gamma$，正如[[#prop-jumps]]所述。关于环量：对带孔物体，连续问题容许一个单参数解族（每个环量对应一个解），因此随着$N$增大，离散的相切方程变得近乎奇异，或者给出一个依赖于面元划分任意细节的环量。必须把确定环量的物理条件——库塔条件——作为一个方程加进去。
:::
:::

::: exercise 规划一项面元法研究 {level=3}
要求你在$\mathrm{Re} = 1.5\times10^6$、$-2^\circ \le \alpha \le 10^\circ$范围内，计算一种新的15%厚滑翔机翼型的压强分布，以便在两种候选头部形状之间作出选择。规划这项研究：面元数量和分布、你将进行的检验、结果中哪些可信哪些不可信，以及你将如何引入黏性效应。至少给出一项你会采用的定量检验。
::: solution
好的答案应涵盖：(1) **面元划分**——160–250个面元，余弦分布，并在两种头部形状不同的前缘处进一步加密；每种情况分别用$N$和$2N$计算，只接受变化小于例如$c_l$为$0.005$、最小$C_p$为$0.05$的结果。(2) **验证**——计算一个厚度相近的NACA四位数字剖面，并与已发表的数据或独立程序相比较；计算存在精确结果的茹科夫斯基翼型或圆柱情形。(3) 每次计算都要进行的**检验**：$\sum\lambda_jS_j \approx 0$；由压强积分得到的$c_{d,p}$与预期的黏性阻力（约$0.006$）相比很小；后缘附近$C_p$光滑，且上下表面在该处数值相等（满足库塔条件）。(4) **可信的内容**——无黏吸力峰的高度和位置、压强梯度（区分两种头部形状的主要依据）以及随$\alpha$的变化趋势；不可信的是阻力、最大升力，以及精度优于约10%的升力线斜率。(5) **黏性效应**——用耦合的黏性-无黏程序（XFOIL类）求转捩位置、层流分离泡（在这一雷诺数下很可能出现）、阻力极曲线以及范围上端附近的后缘分离；如果决策事关重大，用风洞数据确认最终选择。
:::
