在亚声速流动中，空气“知道”有物体正在到来：压强扰动以声速向上游传播，流线在到达物体之前很远就已平滑地弯曲。在超声速流动中扰动做不到这一点，流动必须突然改变方向。当超声速气流被转向**朝向**自身时——在楔的头部、在压缩斜面上、在凹角处——它通过一道很薄的**斜激波**完成转折，穿过斜激波时压强、密度和温度发生跳跃，马赫数下降。当它被转向**背离**自身时——绕过凸角时——它通过一束马赫波平滑地完成转折，即**膨胀**，穿过膨胀波时压强下降而马赫数增大。这两种基本单元足以计算由直线段组成的任何二维超声速外形上的压强，从而计算其升力和波阻：这就是**激波-膨胀波理论**，即本章最后一部分的主题。

先修内容是[[fluid-mechanics/compressible-flow]]中的一维可压缩流动和正激波关系式。全章中空气为比热比$\gamma = 1.4$的量热完全气体；下标$1$表示波前状态，$2$表示波后状态，$p_0$表示滞止压强（总压）。

## 马赫波

一个小扰动——壁面上的微小凸起、一个测压孔——向各个方向发出声波。在速度为$V > a$的气流中，每个波被向下游冲走的速度快于其扩展速度，随时间发出的波的包络是一个圆锥（在二维中是一对直线），其半顶角就是**马赫角**。

::: definition 马赫角与马赫波 {#def-mach-angle}
在马赫数$M > 1$的均匀气流中，无限弱的扰动只在一个楔形（或锥形）区域内被感受到，该区域由与流动方向成**马赫角**
$$
\mu = \arcsin\frac{1}{M}
$$
倾斜的**马赫波**所界定。流动速度垂直于马赫波的分量恰好等于声速，$V\sin\mu = a$。从一点发出的马赫波的上游是该点的**寂静区**。
:::

在$M = 1$时马赫角为$90^\circ$（波垂直于流动而驻立）；$M = 2$时为$30^\circ$；$M = 5$时为$11.5^\circ$。这一几何关系也说明了为什么超声速扰动是受限的：信息沿向下游倾斜的马赫波传播。有限强度的压缩是激波——比马赫角更陡的波——而有限强度的膨胀是一束马赫波。

## 斜激波关系式

考虑一道与上游流动成**激波角**$\beta$的直斜激波，它使气流转过**气流偏转角**$\theta$。把两侧的速度分解为垂直于激波的分量$u$和平行于激波的分量$w$。

::: proposition 斜激波就是正激波加上切向速度 {#prop-oblique}
穿过完全气体中的定常斜激波：
1. 切向速度分量不变，$w_1 = w_2$；
2. 压强、密度和温度的跳跃就是上游**法向马赫数**
$$
M_{n1} = M_1\sin\beta
$$
下的**正激波**跳跃，即
$$
\frac{p_2}{p_1} = 1 + \frac{2\gamma}{\gamma + 1}\left(M_{n1}^2 - 1\right), \qquad
\frac{\rho_2}{\rho_1} = \frac{(\gamma + 1)M_{n1}^2}{2 + (\gamma - 1)M_{n1}^2}, \qquad
M_{n2}^2 = \frac{1 + \tfrac{\gamma - 1}{2}M_{n1}^2}{\gamma M_{n1}^2 - \tfrac{\gamma - 1}{2}},
$$ {#eq-normal}
且$T_2/T_1 = (p_2/p_1)(\rho_1/\rho_2)$；
3. 下游马赫数为$M_2 = M_{n2}/\sin(\beta - \theta)$；
4. 滞止温度不变，滞止压强下降，其比值$p_{02}/p_{01}$与$M_{n1}$下的正激波相同。只有当$M_{n1} > 1$，即$\beta \ge \mu_1$时，激波才存在。
:::

::: proof
取一个跨在单位面积激波上的薄盒子作为控制体，其表面平行于激波。定常连续方程给出$\rho_1u_1 = \rho_2u_2$。沿激波方向分解的动量方程中没有压强贡献（压强垂直于表面作用，而侧面的贡献相互抵消），所以$\rho_1u_1w_1 = \rho_2u_2w_2$；除以连续方程得$w_1 = w_2$。垂直于激波的动量方程给出$p_1 + \rho_1u_1^2 = p_2 + \rho_2u_2^2$，定常绝热能量方程给出$h_1 + \tfrac12(u_1^2 + w_1^2) = h_2 + \tfrac12(u_2^2 + w_2^2)$，由于$w_1 = w_2$，它变为$h_1 + \tfrac12u_1^2 = h_2 + \tfrac12u_2^2$。这三个关于法向分量的方程与以$u$代替$V$的正激波方程**完全相同**，所以它们的解就是[[fluid-mechanics/compressible-flow]]中法向马赫数$u_1/a_1 = M_1\sin\beta$下的正激波解，即[[#eq-normal]]。激波后的速度与激波成$\beta - \theta$角，所以其法向分量为$V_2\sin(\beta - \theta)$，由此得$M_2 = M_{n2}/\sin(\beta - \theta)$。滞止温度守恒，因为$h + \tfrac12V^2$守恒；熵增与正激波相同（它只依赖于法向跳跃），而在$T_0$不变时$p_{02}/p_{01} = e^{-\Delta s/R}$，所以滞止压强比就是正激波的值。热力学第二定律要求$\Delta s \ge 0$，这只在$M_{n1} \ge 1$时成立。假设：激波之外为定常、绝热、无黏流动；$\gamma$为常数的完全气体；激波很薄（其厚度为几个平均自由程）。
:::

还需要把几何关系与偏转角联系起来。由于$\tan\beta = u_1/w$且$\tan(\beta - \theta) = u_2/w$，两者的$w$相同，所以它们之比就是速度比，即密度比的倒数：

::: theorem θ–β–M关系 {#thm-theta-beta-m}
在马赫数为$M_1$的气流中，激波角为$\beta$的斜激波所产生的偏转角$\theta$由下式给出：
$$
\tan\theta = 2\cot\beta\,\frac{M_1^2\sin^2\beta - 1}{M_1^2\left(\gamma + \cos2\beta\right) + 2} .
$$ {#eq-tbm}
对每个$M_1$，偏转角在$\beta = \mu_1$（马赫波）和$\beta = 90^\circ$（正激波）处为零，在两者之间有一个最大值$\theta_{\max}(M_1)$。当$\theta < \theta_{\max}$时有两个解：**弱**激波（$\beta$较小，下游通常为超声速）和**强**激波（$\beta$较大，下游总是亚声速）。
:::

::: proof
由$\tan(\beta - \theta)/\tan\beta = u_2/u_1 = \rho_1/\rho_2 = r$以及$\tan(\beta - \theta) = (\tan\beta - \tan\theta)/(1 + \tan\beta\tan\theta)$，解出$\tan\theta$：
$$
\tan\theta = \frac{(1 - r)\tan\beta}{1 + r\tan^2\beta}.
$$
令$s = \sin\beta$，由[[#eq-normal]]有$r = \left[2 + (\gamma - 1)M_1^2s^2\right]/\left[(\gamma + 1)M_1^2s^2\right]$，$1 - r = 2(M_1^2s^2 - 1)/\left[(\gamma + 1)M_1^2s^2\right]$，所以
$$
\tan\theta = \frac{2\tan\beta\left(M_1^2s^2 - 1\right)}{(\gamma + 1)M_1^2s^2 + \left[2 + (\gamma - 1)M_1^2s^2\right]\tan^2\beta}.
$$
分子分母同除以$\tan^2\beta$，并利用$s^2\cot^2\beta = \cos^2\beta$：分母变为$M_1^2\left[(\gamma + 1)\cos^2\beta + (\gamma - 1)\sin^2\beta\right] + 2 = M_1^2(\gamma + \cos2\beta) + 2$，即得[[#eq-tbm]]。分子在$M_1\sin\beta = 1$（$\beta = \mu_1$）处为零，$\cot\beta$在$\beta = 90^\circ$处为零；$\theta$在两者之间为正且连续，所以它有最大值，每一个更小的正$\theta$都被取到两次。在强激波解处$\beta$接近$90^\circ$，因此$M_{n1}$接近$M_1$，正激波关系式使$M_{n2}$——从而$M_2$——为亚声速。
:::

::: algorithm 求解斜激波 {#alg-oblique}
已知$M_1$和偏转角$\theta$（楔的半顶角或斜面角）：
1. 检验是否附体：求$\theta_{\max}(M_1)$（对$\beta$求[[#eq-tbm]]的最大值，或查图）。若$\theta > \theta_{\max}$，激波**脱体**，以弯曲形状驻立在物体前方；停止。
2. 在$\mu_1 = \arcsin(1/M_1)$与$\theta_{\max}$对应的$\beta$之间，用二分法或对[[#eq-tbm]]的牛顿迭代（或由$\theta$–$\beta$–$M$图）求弱激波的激波角$\beta$。除非下游很高的反压迫使出现强激波，否则采用弱激波解。
3. 计算$M_{n1} = M_1\sin\beta$，然后由正激波关系式[[#eq-normal]]求$p_2/p_1$、$\rho_2/\rho_1$、$T_2/T_1$、$M_{n2}$和$p_{02}/p_{01}$。
4. 计算$M_2 = M_{n2}/\sin(\beta - \theta)$。
5. 检验：$M_2 < M_1$，$p_2 > p_1$，且$p_{02}/p_{01} < 1$，对弱激波接近$1$。
:::

::: example 马赫数2下的10°楔 {#ex-wedge}
一个半顶角为$10^\circ$的对称楔以零迎角在$p_1 = 26.5\,\mathrm{kPa}$、$T_1 = 223\,\mathrm{K}$（约$10\,\mathrm{km}$高度）的空气中以$M_1 = 2$飞行。求激波角、表面压强和温度、楔表面上的马赫数以及滞止压强损失。
::: solution
$\theta_{\max}(2) = 23.0^\circ > 10^\circ$，所以激波附体。在弱支上求解[[#eq-tbm]]得$\beta = 39.3^\circ$（大于马赫角$30^\circ$，理应如此）。于是$M_{n1} = 2\sin39.3^\circ = 1.267$，且
$$
\frac{p_2}{p_1} = 1 + \frac{2.8}{2.4}\left(1.267^2 - 1\right) = 1.707, \qquad \frac{\rho_2}{\rho_1} = 1.458, \qquad \frac{T_2}{T_1} = \frac{1.707}{1.458} = 1.170,
$$
所以$p_2 = 45.2\,\mathrm{kPa}$，$T_2 = 261\,\mathrm{K}$。激波后的法向分量为$M_{n2} = 0.806$，$M_2 = 0.806/\sin(39.3^\circ - 10^\circ) = 1.64$。滞止压强比为$p_{02}/p_{01} = 0.985$。**合理性检验：**$M_2$仍为超声速（弱支）；只损失了$1.5$%的滞止压强，而$M = 2$的正激波损失$28$%（$p_{02}/p_{01} = 0.721$）——用斜激波使气流转折比用正激波使之减速有效得多，这就是超声速进气道的原理。同一楔的强激波解将有$\beta = 83.7^\circ$，$M_2 = 0.60$，$p_2/p_1 = 4.44$。
:::
:::

## 脱体、反射与相交

如果楔角超过$\theta_{\max}(M_1)$，就没有附体的直激波能使气流转折。此时激波脱离物体，以弯曲的**脱体**（弓形）激波驻立在物体前方：在驻点流线上它垂直于流动，离轴线越远越倾斜、越弱，直到在远处趋近于马赫波。超声速流中的每一个钝体都有这样的弓形激波，在激波与头部之间有一个亚声速流区。由于在空气中$\theta_{\max}$从不超过$45.6^\circ$，比这更尖的楔在足够高的马赫数下会有附体激波，而钝头则永远不会。

当斜激波遇到固壁时，其后的气流已被转向**朝向**壁面，必须再被转回到平行于壁面。第二道激波——**反射激波**——完成这一转折，使气流转过同样的角度$\theta$，但此时的起始马赫数是较低的$M_2$。由于$M_2 < M_1$，反射激波不是入射激波的镜像：它与壁面的夹角不同于入射激波。若$\theta > \theta_{\max}(M_2)$，正规反射不可能发生，于是形成**马赫反射**，在壁面处有一段近乎正激波的“马赫杆”。激波反射使超声速风洞试验段、进气道和喷管中的流动变得复杂。

::: example 壁面上的正规反射 {#ex-reflection}
一股马赫数$2.8$的气流被一个斜面转折$10^\circ$，所产生的激波打在一面平行于原始来流的直壁上。求入射激波角和反射激波角，以及反射激波后的马赫数和压强。
::: solution
**入射激波**（$M_1 = 2.8$，$\theta = 10^\circ$）：$\beta_1 = 28.9^\circ$，$M_{n1} = 1.355$，$p_2/p_1 = 1.975$，$M_2 = 2.34$。
**反射激波**（$M_2 = 2.34$，$\theta = 10^\circ$；$\theta_{\max}(2.34) \approx 28^\circ$，所以可以发生正规反射）：相对于区域2中的流动$\beta_2 = 33.8^\circ$，$p_3/p_2 = 1.809$，$M_3 = 1.95$。
区域2的流动与壁面成$10^\circ$，所以反射激波与壁面成$\beta_2 - \theta = 23.8^\circ$角，而入射激波与壁面成$28.9^\circ$：反射比入射更平缓。反射激波后的压强为$p_3/p_1 = 1.975 \times 1.809 = 3.57$。
**合理性检验：**两次$10^\circ$的弱激波转折给出的总压强升高大于一次$10^\circ$转折（$3.57$对$1.98$），理应如此，因为气流被压缩了两次；而反射激波虽然使气流转过同样的角度，其压强比却略弱（$1.81$对$1.98$），因为它作用在较低的马赫数上。这种非镜像的几何关系提醒我们，不能单凭对称性论证画出激波图形。
:::
:::

::: warning 选择解支，以及度与弧度
对给定的$M_1$和$\theta$有两个激波解，在错误位置开始的计算器或迭代会收敛到错误的解。外流中楔、斜面和翼型上的附体激波是**弱**激波；强激波解只在下游压强被迫升高时（例如内流中的收缩）以及作为脱体弓形激波的中央部分时才出现。第二种错误是把以度计的$\theta$代入需要弧度的小角度公式（如弱激波近似和阿克莱特近似），或者使用小于马赫角的$\beta$——这会给出$M_{n1} < 1$以及热力学第二定律所禁止的“膨胀激波”。
:::

## 普朗特-迈耶膨胀

在角度为$\theta$的凸角处，超声速气流转向**背离**自身。没有任何东西迫使发生突然的跳跃：转折通过从角点发出的一束中心马赫波完成，每一道马赫波使气流转过一个无穷小的角度。穿过每一道波的流动都是等熵的，因此整个膨胀也是等熵的。

::: proposition 普朗特-迈耶函数 {#prop-prandtl-meyer}
在定常、等熵的二维膨胀中，流动方向与马赫数之间的关系为
$$
\theta_2 - \theta_1 = \nu(M_2) - \nu(M_1), \qquad
\nu(M) = \sqrt{\frac{\gamma + 1}{\gamma - 1}}\arctan\sqrt{\frac{\gamma - 1}{\gamma + 1}\left(M^2 - 1\right)} - \arctan\sqrt{M^2 - 1},
$$ {#eq-prandtl-meyer}
其中$\theta_2 - \theta_1$是气流背离自身转过的角度。压强、温度和密度由滞止参数不变时的等熵关系式求得，例如
$$
\frac{p_2}{p_1} = \left[\frac{1 + \tfrac{\gamma - 1}{2}M_1^2}{1 + \tfrac{\gamma - 1}{2}M_2^2}\right]^{\gamma/(\gamma - 1)} .
$$ {#eq-isentropic-p}
函数$\nu(M)$在$M = 1$时为零，在$M \to \infty$时趋于$\nu_{\max} = \tfrac\pi2\left(\sqrt{(\gamma + 1)/(\gamma - 1)} - 1\right) = 130.5^\circ$。
:::

::: proof
考虑单独一道马赫波，它使气流背离自身转过小角度$d\theta$，速度从$V$变为$V + dV$。穿过弱波时切向速度守恒（与任何激波一样，[[#prop-oblique]]）；波与来流成$\mu$角，与出流成$\mu + d\theta$角，所以$V\cos\mu = (V + dV)\cos(\mu + d\theta)$。展开到一阶，$V\cos\mu = V\cos\mu - V\sin\mu\,d\theta + dV\cos\mu$，所以
$$
d\theta = \cot\mu\,\frac{dV}{V} = \sqrt{M^2 - 1}\,\frac{dV}{V},
$$
因为$\sin\mu = 1/M$。由$V = Ma$以及绝热关系$a^2 = a_0^2/\left(1 + \tfrac{\gamma - 1}{2}M^2\right)$，$dV/V = dM/M + da/a = \dfrac{dM}{M\left(1 + \tfrac{\gamma - 1}{2}M^2\right)}$。因此
$$
d\theta = \frac{\sqrt{M^2 - 1}}{1 + \tfrac{\gamma - 1}{2}M^2}\,\frac{dM}{M},
$$
从$M = 1$积分（采用标准代换$t = \sqrt{M^2 - 1}$）即得所述的$\nu(M)$；两个状态之间的转折角就是$\nu$值之差。当$M \to \infty$时两个反正切都趋于$\pi/2$，给出$\nu_{\max}$。每道波在一阶近似下是等熵的（穿过弱压缩波或弱膨胀波的熵变是其强度的三阶小量），所以一束无穷小波是等熵的，[[#eq-isentropic-p]]适用。假设：完全气体的定常、二维、无黏流动；简单波区（只有一族波）。
:::

同一个函数也描述沿光滑凹壁的渐进（等熵）**压缩**，只要马赫波尚未汇聚成激波。值得记住的数值：$\nu(1.5) = 11.91^\circ$，$\nu(2) = 26.38^\circ$，$\nu(3) = 49.76^\circ$。

::: example 绕角膨胀 {#ex-expansion}
一股$p_1 = 100\,\mathrm{kPa}$、马赫数$1.5$的气流绕过一个$15^\circ$的凸角。求下游马赫数和压强，以及膨胀扇前后马赫波的角度。
::: solution
$\nu(1.5) = 11.91^\circ$，所以$\nu(M_2) = 26.91^\circ$，由此得$M_2 = 2.02$（数值反解[[#eq-prandtl-meyer]]）。由[[#eq-isentropic-p]]，
$$
\frac{p_2}{p_1} = \left[\frac{1 + 0.2(1.5)^2}{1 + 0.2(2.02)^2}\right]^{3.5} = 0.455, \qquad p_2 = 45.5\,\mathrm{kPa}.
$$
膨胀扇的前马赫波与上游流动成$\mu_1 = \arcsin(1/1.5) = 41.8^\circ$；后马赫波与下游流动成$\mu_2 = \arcsin(1/2.02) = 29.7^\circ$，而下游流动已背离转过$15^\circ$，所以从**上游**方向量起它位于$29.7^\circ - 15^\circ = 14.7^\circ$。因此膨胀扇占据以角点为中心、从上游方向量起$41.8^\circ$到$14.7^\circ$之间的楔形区域。**合理性检验：**在这一马赫数下，$15^\circ$的膨胀使压强降到不足一半，而滞止压强不变——膨胀是无损失的。
:::

## 激波-膨胀波理论

现在可以精确地（对无黏流动而言）分析超声速流中由直线段组成的二维物体：凡是表面转向来流处有一道斜激波，凡是表面背离来流处有一个普朗特-迈耶膨胀，沿每一直线段为均匀流动。对分段为常数的压强积分，即得升力和**波阻**——这是在无黏超声速流动中存在的阻力，因为激波带来了熵增，前后的压强不再相互抵消。（离开物体的波之间的相互作用，例如膨胀扇追上激波，在最简单的形式中被忽略；它们影响离开表面的流场，但不影响直边物体的表面压强。）

::: quiz
在激波-膨胀波理论中，超声速气流中小正迎角的平板在前缘处有
- [ ] 下表面的膨胀和上表面的激波
- [x] 下表面的激波和上表面的膨胀
- [ ] 两个表面上都是激波，任何地方都没有膨胀
- [ ] 根本没有波，因为平板厚度为零
::: solution
在正迎角下，下表面使迎面气流转向自身（压缩：激波），上表面使之背离（膨胀扇）。在后缘处两者的作用互换，使两股气流以相同的压强和几乎相同的方向离开。两个表面之间的压强差给出垂直于平板的法向力，即使没有摩擦，它也有阻力分量$N\sin\alpha$：这就是升力引起的波阻。
:::
:::

::: example 马赫数3下的平板 {#ex-flat-plate}
一块平板在马赫数$3$的气流中处于$\alpha = 5^\circ$。用激波-膨胀波理论求两个表面上的压强系数以及升力系数和波阻系数。
::: solution
用压强比表示的压强系数为$C_p = \dfrac{2}{\gamma M_1^2}\left(\dfrac{p}{p_1} - 1\right)$，因为$q_1 = \tfrac12\gamma p_1M_1^2$。
**下表面：**$\theta = 5^\circ$的斜激波：$\beta = 23.1^\circ$，$p_l/p_1 = 1.454$，$M_l = 2.75$，所以$C_{p,l} = \tfrac{2}{1.4 \times 9}(0.454) = 0.0721$。
**上表面：**膨胀$5^\circ$：$\nu(3) = 49.76^\circ \to 54.76^\circ$，$M_u = 3.27$，由[[#eq-isentropic-p]]，$p_u/p_1 = 0.668$，所以$C_{p,u} = -0.0528$。
法向力系数为$c_n = C_{p,l} - C_{p,u} = 0.1249$，垂直于平板，所以
$$
c_l = c_n\cos\alpha = 0.1243, \qquad c_d = c_n\sin\alpha = 0.0109 .
$$
**合理性检验：**升阻比为$\cot5^\circ = 11.4$，对于垂直于平板的压强力理应如此。[[aerodynamics/supersonic-hypersonic]]中的线化理论给出$c_l = 4\alpha/\sqrt{M^2 - 1} = 0.1234$和$c_d = 4\alpha^2/\sqrt{M^2 - 1} = 0.0108$，相差在1%以内。还要注意不对称性：压缩面的贡献（$0.072$）大于膨胀面（$0.053$），这是一种随$\alpha$和$M$增大的非线性效应。
:::
:::

::: example 零迎角的菱形翼型 {#ex-diamond}
一个半顶角$\varepsilon = 5^\circ$的对称菱形（双楔）剖面（最大厚度位于弦长中点，$t/c = \tan5^\circ = 0.0875$）以零迎角、$M_1 = 2$飞行。求其波阻系数。
::: solution
由对称性只考虑上表面。**前表面：**$\theta = 5^\circ$的激波：$\beta = 34.3^\circ$，$p_2/p_1 = 1.315$，$M_2 = 1.82$。**肩部：**膨胀$2\varepsilon = 10^\circ$：$\nu(1.82) = 21.3^\circ \to 31.3^\circ$，$M_3 = 2.18$，$p_3/p_2 = 0.568$，所以$p_3/p_1 = 0.748$。用系数表示，$C_{p2} = \tfrac{2}{1.4 \times 4}(0.315) = 0.1126$，$C_{p3} = -0.0901$。在每个表面上，前表面（投影高度$t/2$）以$C_{p2}$向后推，后表面以$-C_{p3}$向后拉；按单位弦长计
$$
c_d = 2\left(C_{p2} - C_{p3}\right)\frac{t/2}{c} = 2(0.2027)(0.04374) = 0.0177 .
$$
**合理性检验：**对菱形，线化理论给出$c_d = 4(t/c)^2/\sqrt{M^2 - 1} = 4(0.0875)^2/\sqrt3 = 0.0177$——三位数字相同。$0.018$的波阻是相当的亚声速剖面摩擦阻力的三倍，这就是超声速机翼很薄的原因：波阻随相对厚度的平方增长。
:::
:::

::: application 超声速进气道
喷气发动机的压气机需要亚声速空气，因此超声速飞机必须以尽可能小的滞止压强损失，把进气从飞行马赫数减速到约$M = 0.5$。$M = 2.5$下的单道正激波只保留$p_{02}/p_{01} = 0.499$的滞止压强。一个$10^\circ$斜面先产生一道斜激波（$p_0$比$0.976$，$M = 2.09$），其后的正激波保留$0.681$：总计$0.664$。两个$8^\circ$斜面（$M = 2.17$，然后$1.87$）再加一道正激波，给出$0.764$。每增加一道斜激波都以长度、重量、边界层抽吸为代价换取总压恢复，而对于必须在一定马赫数范围内工作的飞机，还需要可调几何。民用超声速运输机采用的就是这种可调斜板的矩形进气道。
:::

::: history
威廉·**朗肯**（William Rankine，1870年）和皮埃尔-亨利·**于戈尼奥**（Pierre-Henri Hugoniot，1887—1889年）推导了穿过正激波的跳跃条件。路德维希·**普朗特**（Ludwig Prandtl，1907年）和他的学生特奥多尔·**迈耶**（Theodor Meyer，1908年的哥廷根博士论文）给出了斜激波以及以他们命名的中心膨胀扇的理论。在1920年代和1930年代，苏黎世的雅各布·**阿克莱特**（Jakob Ackeret）和德国的阿道夫·**布泽曼**（Adolf Busemann）把这些结果应用于超声速翼型，并建造了超声速风洞；布泽曼的**激波极曲线**给出了[[#eq-tbm]]的图解法，他在1935年罗马沃尔塔会议上的论文把超声速翼型理论推广到偏转角的二阶，并提出了后掠翼的思想。NACA的《可压缩流动的方程、表格和图表》（*Equations, tables, and charts for compressible flow*，NACA第1135号报告，1953年）把斜激波和普朗特-迈耶关系汇编成图表，工程师们使用了几十年。
:::

## 小结

::: summary
- 超声速流中的无限小扰动沿与流动成$\mu = \arcsin(1/M)$的马赫波传播。
- 斜激波就是法向分量$M_{n1} = M_1\sin\beta$上的正激波加上不变的切向速度；$M_2 = M_{n2}/\sin(\beta - \theta)$。
- $\theta$–$\beta$–$M$关系：$\tan\theta = 2\cot\beta\,(M_1^2\sin^2\beta - 1)/\left[M_1^2(\gamma + \cos2\beta) + 2\right]$，有弱支和强支以及最大偏转角（$M = 2$时为$23.0^\circ$，$M \to \infty$时为$45.6^\circ$）；超过它激波就脱体。
- 壁面反射不是镜像：反射激波作用在入射激波后较低的马赫数上。
- 膨胀是等熵的：$\Delta\theta = \nu(M_2) - \nu(M_1)$，其中$\nu$为普朗特-迈耶函数；$\nu(2) = 26.38^\circ$。
- 激波-膨胀波理论给出直边物体上精确的无黏压强：$5^\circ$、$M = 3$的平板有$c_l = 0.124$、$c_d = 0.011$；$M = 2$下5°菱形翼型有$c_d = 0.018$。
:::

::: exercise 穿过斜激波的压强比 {level=1 check="2.458"}
一道与马赫数$3$的气流成$30^\circ$倾斜的激波：求法向马赫数以及穿过它的静压比。（输入$p_2/p_1$。）
::: solution
$M_{n1} = 3\sin30^\circ = 1.5$，$p_2/p_1 = 1 + \tfrac{2.8}{2.4}(1.5^2 - 1) = 2.458$。（由[[#eq-tbm]]，此时偏转角为$\theta = 12.8^\circ$。）
:::

::: exercise 一个普朗特-迈耶函数值 {level=1 check="26.38"}
计算$\gamma = 1.4$时普朗特-迈耶函数在$M = 2$处的值。（以度为单位输入$\nu$。）
::: solution
$\nu(2) = \sqrt6\arctan\sqrt{3/6} - \arctan\sqrt3 = 2.4495 \times 0.6155 - 1.0472 = 0.4604\,\mathrm{rad} = 26.38^\circ$。
:::

::: exercise 马赫数3下的15°斜面 {level=2 check="2.82"}
马赫数$3$的气流遇到一个$15^\circ$的压缩斜面。求激波角、下游马赫数和压强比。（输入$p_2/p_1$。）
::: solution
$\theta_{\max}(3) = 34.1^\circ$，所以激波附体。[[#eq-tbm]]的弱激波解为$\beta = 32.2^\circ$；$M_{n1} = 3\sin32.2^\circ = 1.600$，$p_2/p_1 = 1 + \tfrac{2.8}{2.4}(1.6^2 - 1) = 2.82$，$M_{n2} = 0.668$，$M_2 = 0.668/\sin17.2^\circ = 2.25$，$p_{02}/p_{01} = 0.895$。
:::
:::

::: exercise 马赫数2下的10°膨胀 {level=2 check="0.548"}
马赫数$2$的气流绕过一个$10^\circ$的凸角膨胀。求$M_2$和$p_2/p_1$。（输入$p_2/p_1$。）
::: solution
$\nu(M_2) = 26.38^\circ + 10^\circ = 36.38^\circ$，所以$M_2 = 2.38$；$p_2/p_1 = \left[(1 + 0.2 \times 4)/(1 + 0.2 \times 2.385^2)\right]^{3.5} = 0.548$。
:::

::: exercise 激波会附体吗？ {level=2 check="22.97"}
马赫数$2$的气流能够产生附体激波的最大楔半顶角是多少？半顶角为$25^\circ$的楔会有附体激波吗？（以度为单位输入$\theta_{\max}$。）
::: solution
在$M_1 = 2$时对$\beta$求[[#eq-tbm]]的最大值，得$\theta_{\max} = 22.97^\circ$，位于$\beta = 64.7^\circ$。$25^\circ$的楔超过了它，因此其激波脱体，以弯曲的弓形激波驻立在头部前方，头部处为亚声速流动。
:::

::: exercise 弱激波近似 {level=3}
证明对于小偏转角$\theta$（以弧度计），穿过弱斜激波的压强升高为
$$
\frac{p_2 - p_1}{p_1} \approx \frac{\gamma M_1^2}{\sqrt{M_1^2 - 1}}\,\theta ,
$$
即$C_p \approx 2\theta/\sqrt{M_1^2 - 1}$，并证明弱膨胀给出同样的结果，只是$\theta$为负。在$M_1 = 2$下对$\theta = 2^\circ$和$\theta = 10^\circ$与精确值进行比较。
::: solution
对弱波$\beta \approx \mu$。记$M_1^2\sin^2\beta - 1 = \epsilon$，为小量。由$\beta \approx \mu$时的[[#eq-tbm]]，以及$\tan\mu = 1/\sqrt{M_1^2 - 1}$和$\cos2\mu = 1 - 2/M_1^2$：$\theta \approx 2\sqrt{M_1^2 - 1}\,\epsilon/\left[M_1^2(\gamma + 1) - 2 + 2\right] = 2\sqrt{M_1^2 - 1}\,\epsilon/\left[(\gamma + 1)M_1^2\right]$。压强跳跃为$(p_2 - p_1)/p_1 = 2\gamma\epsilon/(\gamma + 1)$。消去$\epsilon$即得结果。对于膨胀，普朗特-迈耶关系$d\theta = \sqrt{M^2 - 1}\,dV/V$与动量关系$dp = -\rho V\,dV$给出，对背离流动的转折$d\theta$，$dp/p = -\gamma M^2\,dV/V = -\gamma M^2\,d\theta/\sqrt{M^2 - 1}$——即转折方向取反的同一公式。在$M_1 = 2$下检验（$\gamma M^2/\sqrt{M^2 - 1} = 3.233$）：对$2^\circ$，近似给出$0.113$，精确值为$0.118$；对$10^\circ$，近似给出$0.564$，精确值为$0.707$。线性近似低估了压缩，低估量随偏转角增大——这是[[aerodynamics/supersonic-hypersonic]]中线化超声速理论的基础，也是其局限所在。
:::

::: exercise 设计外压式进气道 {level=3 check="0.764"}
对以$M = 2.5$巡航的民用超声速飞机，比较以下进气道的滞止压强恢复：(a) 单道正激波的皮托式进气道，(b) 单个$10^\circ$斜面加一道正激波，(c) 两个$8^\circ$斜面加一道正激波。然后讨论实践中限制斜面数目的因素，以及在非设计马赫数下会发生什么。（输入情形(c)的恢复系数$p_{0,\text{末}}/p_{01}$。）
::: solution
(a) $2.5$下的正激波：$p_{02}/p_{01} = 0.499$。(b) 斜面：$\beta = 31.9^\circ$，$M_{n1} = 1.32$，$p_0$比$0.976$，$M = 2.09$；$2.09$下的正激波：$0.681$；乘积$0.664$。(c) 第一个斜面：$M = 2.17$，$p_0$比$0.987$；从$2.17$开始的第二个斜面：$M = 1.87$，$p_0$比$0.990$；$1.87$下的正激波：$0.781$；乘积$0.764$。每道斜激波都更弱，最后的正激波发生在更低的马赫数下。在许多小斜面的极限下（等熵压缩面），恢复系数趋近$1$，但进气道变得又长又重，斜面上的边界层增厚，必须将其抽吸掉，以防在激波打到边界层处发生分离，而且斜激波只在一个马赫数下才汇聚于唇口。在其他马赫数下，激波会偏离唇口（溢流并增加阻力）或进入进气道内部；采用可调斜板、抽吸和旁路门来保持激波系的位置，并且必须避免不稳定的激波位置（“不起动”或“喘振”）。
:::
