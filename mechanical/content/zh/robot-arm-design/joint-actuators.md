[[robot-arm-design/arm-specification]]把负载与臂展化成了每个关节的一列数字：峰值力矩、连续（rms）力矩、最高角速度与角重复性。本章挑选交付这些数字的部件——电机、驱动电机的电子器件，以及告诉控制器转子在哪里的编码器。机械臂里出现三类电机，它们大致对应三类机械臂：桌面与教学臂里的**航模舵机**、低成本臂和3D打印机衍生设计里的**步进电机**，以及每一台工业与协作机械臂里运行磁场定向控制的**无刷永磁电机**。我们先看各自能与不能，然后深入无刷关节：它的常数、热极限、磁场定向控制、驱动器及其母线电压，还有编码器。这里假定已具备[[mechatronics/electric-actuators]]的电机模型（转矩常数、反电动势、直流电机方程）与[[mechatronics/sensors]]的编码器基础；本章做的事是把它们应用到一个关节上。

## 关节执行器必须做到什么 {#sec-requirements}

机器人关节对电机是个苛刻的地方。由[[robot-arm-design/arm-specification]]中示例机械臂的肩部可知，关节输出必须给出约$180\,\mathrm{N\,m}$的峰值和$100\text{–}130\,\mathrm{N\,m}$的连续力矩，转速最高$3.1\,\mathrm{rad/s}$，而且必须

- **长时间零速保持**：对抗重力把臂悬住——这种负载产热却不做机械功；
- **极低速度下平稳**：机械臂趋近零件或走慢速路径时要蠕动，转矩脉动会直接反映到工具端；
- **上电即知位置**：一台必须把每个关节开到开关上才能回零的机械臂，轻则碍事，在拥挤的工作单元里则危险；
- **质量小、尺寸小**：对后面的每个关节来说，这枚执行器本身就是负载；
- **带抱闸**：断电时把臂悬住。

因此，力矩密度（每千克的力矩）、静止时不通电不过热地产出力矩的能力、位置测量的品质，才是这里的品质因数，胜过效率或最高转速。

## 航模舵机 {#sec-hobby}

**航模（RC）舵机**是装在塑料小盒里的完整位置伺服系统：一台小有刷直流电机、一串传动比为几百的正齿轮轮系、输出轴上一个电位器，再加一个小控制器，把电位器电压与指令位置相比较。指令是每$20\,\mathrm{ms}$一个的脉冲，其宽度通常为$1.0$到$2.0\,\mathrm{ms}$（有些舵机接受$0.5$到$2.5\,\mathrm{ms}$），映射到输出角上约$90°$到$180°$的范围。

转矩在规定的电源电压下以kg·cm计，称为**堵转转矩**（$1\,\mathrm{kg\,cm} = 9.81\,\mathrm{N}\times0.01\,\mathrm m = 0.0981\,\mathrm{N\,m}$）。堵转转矩是满电压下能把电机顶停的力矩；它不是连续定额，让舵机在堵转力矩附近保持负载，几分钟内就会过热。

航模舵机非常适合学习：便宜、自成一体，对负载一百克上下的桌面臂已经够用。它们的短处同样明显。控制器是一个带死区的比例环：输出会停在目标附近约$\pm1°$内的任何地方，齿轮回差又添上同样量级。用户接触不到电机电流，所以舵机不能做转矩控制，也感知不到碰撞。标准舵机不向外部反馈位置——控制器只是假定舵机已经到位。“智能”串行总线舵机通过报告位置、负载（电流的估计值）和温度、并接受速度与转矩限值来改进，是小臂常见的升级选择。

::: example 用航模舵机的桌面臂负载 {#ex-hobby}
一台桌面臂的肩关节使用额定堵转$20\,\mathrm{kg\,cm}$的舵机。水平位姿下悬于肩部之外的有：上臂连杆（$0.15\,\mathrm{kg}$，在$0.10\,\mathrm m$处）、肘部舵机（$0.06\,\mathrm{kg}$，在$0.15\,\mathrm m$处）、带腕与夹爪的前臂（$0.05\,\mathrm{kg}$，在$0.22\,\mathrm m$处）。负载在距肩轴$0.30\,\mathrm m$处。把堵转转矩的一半当作可用保持力矩，这支臂能保持多大的负载？
::: solution
堵转转矩$T_s = 20\times0.0981 = 1.96\,\mathrm{N\,m}$；可用$0.98\,\mathrm{N\,m}$。臂自身的重力力矩为$9.81\,(0.15\times0.10 + 0.06\times0.15 + 0.05\times0.22) = 9.81\times0.035 = 0.343\,\mathrm{N\,m}$。负载至多可添$0.98 - 0.343 = 0.637\,\mathrm{N\,m}$，所以$m = 0.637/(9.81\times0.30) = 0.217\,\mathrm{kg}$，约$200\,\mathrm g$。

**合理性检验。**用这样的舵机装配、臂展约$0.3\,\mathrm m$的桌面臂，出厂标称负载通常就是几百克，与本估计一致。臂自身结构只重$0.26\,\mathrm{kg}$，却已用掉可用力矩的三分之一。
:::
:::

## 步进电机及其在机械臂中为何薄弱 {#sec-steppers}

混合式步进电机（[[mechatronics/electric-actuators]]）的转子通常有$50$个齿、两相，每转$200$个整步。步进电机对小臂有吸引力，因为它们便宜、低速下相对体积而言力矩大，而且可以靠数步数开环定位。若干低成本机械臂——尤其是源自3D打印机电子学的——就使用它们。它们在机器人关节里的弱点，源于它们产生转矩的方式。

::: proposition 混合式步进电机的静态转矩–转角特性 {#prop-stepper}
保持相电流固定（在某整步或细步位置），一台有$N_r$个转子齿的混合式步进电机给出的恢复转矩，随转子偏离平衡位置的偏差$\theta$近似呈正弦：
$$
T(\theta) = -T_h\sin(N_r\theta),
$$ {#eq-stepper-torque}
其中$T_h$为保持转矩。因此，稳态负载力矩$T_L < T_h$会把转子推开一个**负载角**$\theta_L = \arcsin(T_L/T_h)/N_r$，平衡点附近的小信号刚度为$k = N_rT_h$。
:::

::: proof
转矩来自磁场共储能随转子位置的变化。转子齿与定子齿齿距相同，机械角为$2\pi/N_r$，所以共储能——从而转矩——以该周期随$\theta$周期变化；在通常的齿形下基波占主导，给出$T = -T_h\sin(N_r\theta)$（负号表示转矩把转子拉回$\theta = 0$）。带负载平衡时$T_h\sin(N_r\theta_L) = T_L$，即得$\theta_L$。刚度为$-\mathrm dT/\mathrm d\theta$在$\theta = 0$处的值，即$N_rT_h$。
:::

有三条推论对机械臂要紧。

1. **位置误差随负载增大，而控制器看不见它。**一台步进电机带着相当于保持转矩一半的负载时，会停在比步数所示位置落后$\arcsin(0.5)/50 = 0.0105\,\mathrm{rad} = 0.6°$——整步的三分之一——的地方。细步驱动帮不上忙：它改变的是平衡位置，不是刚度。
2. **越过$T_h$就失步。**一旦负载超出可用转矩——碰撞中或过猛的加速中——转子就跳到下一个稳定位置，一步差四个整步（$2\pi/N_r$），步数从此与位置不符，直到回零之前每一段后续运动都是错的。可用转矩随转速陡降，所以失步多发生在快速运动里。
3. **没有转矩控制。**驱动器设定的是相电流而不是转矩，所以步进电机臂做不成柔顺的，不能从电流检测接触，也不能做重力补偿：它只是一直满电流运行，无论保持与否，并且发烫。

**闭环步进电机**带上编码器和按实测转子位置调整电流与换向角的驱动器，解决了失步问题和恒流发热。此后它的表现就是一台带粗糙驱动器的多极对无刷电机（步进电机**就是**50对极的同步电机），只是仍比同力矩的无刷关节更重、更不平顺。对转矩脉动和转矩控制都不在意的低成本机械臂，它是合理选择。

::: quiz
一台步进电机驱动的机械臂在拿起一件比平时更重的零件后，停在了比预期低$2\,\mathrm{mm}$的位置，但控制器报告各关节恰好位于指令步数。最可能的解释是什么？
- [ ] 丢了一步，所以步数错了
- [x] 重力力矩增大使肩部步进电机的负载角变大
- [ ] 细步分辨率太粗
- [ ] 编码器装偏了
::: solution
控制器对步数的报告没错；转子落后于其电气平衡位置$\theta_L = \arcsin(T_L/T_h)/N_r$，$T_L$越大这个落后越多。转子侧$0.6°$经$20{:}1$的减速后是关节处$0.03°$，在$1\,\mathrm m$处是$0.5\,\mathrm{mm}$——若传动比更低或负载更接近$T_h$还会更多。丢一步则是转子角$7.2°$的跳变，而开环步进电机根本没有编码器。
:::
:::

## 无刷关节电机 {#sec-brushless}

工业与协作机械臂使用**永磁同步电机**（PMSM；“无刷直流”与“无刷交流伺服”这些叫法常被宽松地用于同一类机器）：磁体在转子上，三相绕组在装得下、能导热散走的定子上，换向由编码器引导、电子完成。在关节里有两种形态。自带轴承、轴和编码器的**带壳伺服电机**螺栓连接到减速器上；大型工业臂上这是常态。**无框**电机（kit电机）只有定子环和转子环，直接装在关节壳体里、用关节自己的轴承；转子空心时把中心留给走线，紧凑协作关节里这是常态。关节用无框电机极对数多（典型8–20对极）、轴向短、直径大，因为在给定电流密度下，转矩随气隙直径的平方大致增长。

### 三相电机的转矩与电压常数

对单台直流电机，SI单位下$K_t = K_e$（[[mechatronics/electric-actuators]]）。三相电机的数据手册把这件事弄复杂了：它们混用峰值和rms值、相量和线–线量。

::: proposition PMSM的转矩与反电动势常数 {#prop-kt-ke}
一台有$p$对极、每相（峰值）磁体磁链$\psi_m$的PMSM，通与反电动势同相、幅值为$\hat\imath$的正弦相电流（即$i_d = 0$），产生的转矩为
$$
T = \tfrac32\,p\,\psi_m\,\hat\imath = \tfrac{3}{\sqrt2}\,p\,\psi_m\,I_{\text{rms}} .
$$ {#eq-pmsm-kt}
相反电动势的幅值为$p\psi_m\omega$，故线–线反电动势常数为$K_{e,LL}^{\text{rms}} = \sqrt{3/2}\,p\psi_m$，单位$\mathrm{V_{rms}\,s/rad}$。于是
$$
K_t^{\text{rms}} = \sqrt3\,K_{e,LL}^{\text{rms}},\qquad K_t^{\text{pk}} = \tfrac{\sqrt3}{2}\,K_{e,LL}^{\text{pk}},
$$ {#eq-kt-ke}
其中$K_t^{\text{rms}}$是每rms相安培的转矩，$K_t^{\text{pk}}$是每峰值相安培的转矩。
:::

::: proof
各相反电动势为$e_k = p\psi_m\omega\cos(\theta_e - 2\pi k/3)$，$k = 0, 1, 2$；$i_d = 0$时电流为$i_k = \hat\imath\cos(\theta_e - 2\pi k/3)$。转换的电功率为$\sum_k e_ki_k = p\psi_m\omega\hat\imath\sum_k\cos^2(\theta_e - 2\pi k/3) = \tfrac32p\psi_m\omega\hat\imath$，因为对任何$\theta_e$三个$\cos^2$项之和都是$3/2$。令其等于$T\omega$（功率平衡，与直流电机一样），并以$\hat\imath = \sqrt2I_{\text{rms}}$代入，即得[[#eq-pmsm-kt]]。线–线电动势是互差$120°$的两相电动势之差，其幅值为相幅值的$\sqrt3$倍：$\hat e_{LL} = \sqrt3p\psi_m\omega$，故$K_{e,LL}^{\text{pk}} = \sqrt3p\psi_m$，$K_{e,LL}^{\text{rms}} = \sqrt{3/2}\,p\psi_m$。相除：$K_t^{\text{rms}}/K_{e,LL}^{\text{rms}} = (3/\sqrt2)/\sqrt{3/2} = \sqrt3$，$K_t^{\text{pk}}/K_{e,LL}^{\text{pk}} = (3/2)/\sqrt3 = \sqrt3/2$。
:::

注意转矩不随时间变化——三相的贡献之和是一个常数——这就是正弦驱动的PMSM没有本征换向脉动的原因。剩下的脉动来自**齿槽转矩**（磁体对定子齿的吸引，不通电也存在）、非正弦的反电动势、以及电流测量与编码器角度的误差。关节电机的设计要压低齿槽（磁体或斜槽斜极、分数槽绕组），关节处残余的脉动还会被减速比进一步减小。

::: warning 每个电机常数都要核对约定
两台相似电机的数据手册可能对同一台机器给出“$K_t = 0.11\,\mathrm{N\,m/A}$”和“$K_t = 0.078\,\mathrm{N\,m/A}$”：前者按rms安培，后者按峰值安培（$0.11/\sqrt2 = 0.078$）。反电动势常数有按相或按线–线、峰值或rms之分，单位有$\mathrm{V/(rad/s)}$或$\mathrm{V/krpm}$之别。按错误约定组态的驱动器，电流限值会错$\sqrt2$倍，转矩估计会错$\sqrt2$或$\sqrt3$倍，弱磁点也随之错位。把约定写在每个常数旁边，并用[[#eq-kt-ke]]核对：转动电机测出线–线反电动势，在台架上测出每安培转矩，看两者是否一致。
:::

### 铜损、电机常数与热极限

把臂静止悬住不转换任何功率，但绕组里的电流照样耗热。衡量这一点的品质因数是**电机常数**。

::: definition 电机常数 {#def-km}
**电机常数**$K_m$是每单位铜损平方根所产出的转矩：
$$
K_m = \frac{T}{\sqrt{P_{\text{Cu}}}},\qquad P_{\text{Cu}} = 3I_{\text{rms}}^2R_{ph} = \tfrac32I_{\text{rms}}^2R_{LL},
$$ {#eq-km}
单位$\mathrm{N\,m/\sqrt W}$；于是$K_m = K_t^{\text{rms}}/\sqrt{3R_{ph}}$，其中$R_{ph}$为相电阻，星形绕组线–线电阻为$R_{LL} = 2R_{ph}$。$K_m$与匝数无关（为不同电压重绕电机时，$K_t$与$R$一起变），并随电机尺寸陡增：对几何相似的电机，大致按体积的$5/6$次方增长。
:::

连续转矩定额的含义是：在规定环境与安装条件下，铜损（连同铁损和摩擦损耗）恰好把绕组加热到允许温度的那个转矩。稳态下绕组高出环境$\Delta T = P R_{th}$，其中$R_{th}$为绕组到环境的热阻（K/W），温度按热时间常数$\tau_{th}$逼近该温升——绕组相对定子以秒计，整台电机加关节壳体以分钟到几十分钟计。两个温度效应闭合成一个正反馈环：铜电阻每开尔文升高约$0.39\,\%$，使损耗增大；钕铁硼磁体的剩磁每开尔文下降约$0.1\,\%$，使$K_t$减小，同样的转矩需要更大的电流。

**峰值转矩**受的是另一类限制：驱动器的电流限值、磁饱和（转矩不再与电流成正比，通常在连续电流的两到四倍以上）与足以使磁体退磁的电流。它只能维持到绕组来不及热起来的短时间——一秒或几秒。

::: example 为肩关节选择无框电机 {#ex-frameless}
示例机械臂的肩关节经传动比$N = 100$、效率$0.80$的减速器，要求在关节输出端有峰值$180\,\mathrm{N\,m}$、连续$130\,\mathrm{N\,m}$。一台备选的无框电机有$K_t = 0.11\,\mathrm{N\,m/A_{rms}}$、$K_m = 0.35\,\mathrm{N\,m/\sqrt W}$，装入关节壳体后绕组到$40\,°\mathrm C$环境的热阻$R_{th} = 2.0\,\mathrm{K/W}$；目录上的$K_m$按绕组温度$20\,°\mathrm C$给出。求电机侧的转矩、电流与铜损，以及连续转矩下绕组的稳态温度。
::: solution
**电机侧转矩：**$T_{m,\text{cont}} = 130/(100\times0.80) = 1.63\,\mathrm{N\,m}$，$T_{m,\text{pk}} = 180/80 = 2.25\,\mathrm{N\,m}$。

**电流：**$I_{\text{cont}} = 1.63/0.11 = 14.8\,\mathrm{A_{rms}}$；$I_{\text{pk}} = 2.25/0.11 = 20.5\,\mathrm{A_{rms}}$（每相峰值$28.9\,\mathrm A$）。

**$20\,°\mathrm C$下的铜损：**$P = (T/K_m)^2 = (1.63/0.35)^2 = 21.6\,\mathrm W$（连续），$(2.25/0.35)^2 = 41.3\,\mathrm W$（峰值）。

**绕组温度：**第一个估计是$40 + 2.0\times21.6 = 83\,°\mathrm C$。在$83\,°\mathrm C$时电阻为$20\,°\mathrm C$值的$1 + 0.0039\times63 = 1.25$倍，于是损耗为$27\,\mathrm W$、温度$94\,°\mathrm C$；迭代$T_w = 40 + 2.0\times21.6\,[1 + 0.00393(T_w - 20)]$收敛到$T_w = 96\,°\mathrm C$，$P = 28\,\mathrm W$。（直接解：$T_w = (40 + 43.1\times(1 - 0.0786))/(1 - 43.1\times0.00393) = 96\,°\mathrm C$。）

$96\,°\mathrm C$是否可接受取决于绝缘等级，而在关节里更常取决于四邻：应变波减速器的润滑脂、编码器的电子器件，以及人可能触碰的壳体。关节设计者通常把人可触碰的壳体压在远低于$60\,°\mathrm C$、绕组压在远低于绝缘限值的地方。若裕量太小，可选项有：$K_m$更高的电机（更大、更重）、通往臂结构的更好热路径（更低的$R_{th}$）、或降低连续转矩——例如长时间等待时上抱闸（[[robot-arm-design/arm-specification]]）。

**合理性检验。**关节里的$28\,\mathrm W$约是一把电烙铁的功率，却装在一个拳头大的壳体内——需要认真对待，不意外。
:::

## 磁场定向控制 {#sec-foc}

电机产出的转矩，正比于定子电流中（电气角上）与磁体磁通垂直的那个分量。**磁场定向控制**（FOC）测量相电流，把它们变到随转子旋转的坐标系里，在那里用普通PI控制器调节这两个分量。这两个变换是线性的、快的——电机控制微控制器上只需几微秒——它们把一台三相交流机器变得像一台带两个独立电流的直流电机。

::: definition 克拉克变换与帕克变换 {#def-clarke-park}
对满足$i_a + i_b + i_c = 0$的相电流$i_a$、$i_b$、$i_c$，（幅值不变的）**克拉克变换**给出静止正交坐标系中的分量
$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3},
$$ {#eq-clarke}
**帕克变换**再把它们旋转到与转子磁体轴（$d$，直轴）及其电气超前$90°$的轴（$q$，交轴）对齐的坐标系：
$$
\begin{aligned}
i_d &= \phantom{-}i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\\
i_q &= -i_\alpha\sin\theta_e + i_\beta\cos\theta_e .
\end{aligned}
$$ {#eq-park}
这里$\theta_e = p\,\theta_m - \theta_0$是**电气角**：编码器读出的机械转子角乘极对数，再减去编码器零位与磁体轴之间的偏置$\theta_0$。幅值恒定、随转子旋转的平衡正弦电流，会变成恒定的$i_d$和$i_q$。
:::

在$dq$坐标系里电机满足
$$
\begin{aligned}
v_d &= R\,i_d + L_d\frac{\mathrm di_d}{\mathrm dt} - \omega_eL_q\,i_q,\\
v_q &= R\,i_q + L_q\frac{\mathrm di_q}{\mathrm dt} + \omega_eL_d\,i_d + \omega_e\psi_m,\\
T &= \tfrac32\,p\,\bigl[\psi_m\,i_q + (L_d - L_q)\,i_di_q\bigr],
\end{aligned}
$$ {#eq-dq-model}
其中$\omega_e = p\omega$，$R$、$L_d$、$L_q$均为相量（幅值不变标定）。对关节里常见的表贴磁体电机$L_d \approx L_q$，磁阻项消失，$T = \tfrac32p\psi_mi_q$：转矩只正比于$i_q$，而$i_d$保持为零以免浪费电流。负的$i_d$抵消磁体磁通，用于**弱磁**：它降低反电动势，让转速超出母线电压本来允许的界限，代价是多耗电流。

::: algorithm 磁场定向电流控制的一拍 {#alg-foc}
每个PWM周期（关节驱动器典型$10\text{–}40\,\mathrm{kHz}$，即每$25\text{–}100\,\mathrm{\mu s}$）：
1. 在PWM周期中段（开关噪声最小处）采样两路相电流（第三路为$-i_a - i_b$），并从编码器读转子角。
2. 计算$\theta_e = p\theta_m - \theta_0$，作克拉克变换[[#eq-clarke]]与帕克变换[[#eq-park]]，得$i_d$、$i_q$。
3. 与参考值比较：$i_q^* = T^*/(\tfrac32p\psi_m)$来自速度环的转矩指令，$i_d^* = 0$（弱磁时为负）。
4. 两个PI控制器得$v_d^*$、$v_q^*$，并叠加[[#eq-dq-model]]给出的解耦前馈$-\omega_eL_qi_q$与$\omega_eL_di_d + \omega_e\psi_m$，使每个PI只面对$R + Ls$。
5. 把电压矢量限制在母线所能提供的范围内，$\sqrt{v_d^2 + v_q^2} \le V_{dc}/\sqrt3$，积分器带抗饱和。
6. 作帕克与克拉克的逆变换，算出PWM占空比（空间矢量调制），并补偿驱动器的死区时间。
:::

::: example 从相电流到转矩 {#ex-foc}
某瞬间电气角为$\theta_e = 30°$，驱动器测得$i_a = -5.0\,\mathrm A$、$i_b = 10.0\,\mathrm A$。求$i_d$、$i_q$；若$p\psi_m = 0.0519\,\mathrm{V\,s/rad}$，转矩是多少（电机同[[#ex-frameless]]）。
::: solution
$i_c = -i_a - i_b = -5.0\,\mathrm A$。克拉克：$i_\alpha = -5.0\,\mathrm A$，$i_\beta = (-5.0 + 20.0)/\sqrt3 = 8.660\,\mathrm A$。帕克，用$\cos30° = 0.8660$、$\sin30° = 0.5$：
$$
\begin{aligned}
i_d &= -5.0(0.8660) + 8.660(0.5) = -4.330 + 4.330 = 0,\\
i_q &= 5.0(0.5) + 8.660(0.8660) = 2.5 + 7.5 = 10.0\,\mathrm A.
\end{aligned}
$$
所以电流矢量是幅值$10\,\mathrm A$（峰值）的纯$q$轴电流，$T = \tfrac32\times0.0519\times10.0 = 0.778\,\mathrm{N\,m}$。

**与rms常数核对：**$10\,\mathrm A$峰值即$7.07\,\mathrm A_{\text{rms}}$，$0.11\times7.07 = 0.778\,\mathrm{N\,m}$。✓
:::
:::

角度偏置$\theta_0$与电流测量同等重要。若驱动器对磁体轴的认识错了$\delta$，它口中的$i_q$实际只有$i_q\cos\delta$是产转矩电流，于是每安培转矩损失$1 - \cos\delta$，分量$i_q\sin\delta$进了$d$轴。$10°$的误差只损失$1.5\,\%$的转矩，却有$17\,\%$的电流跑到了错误的轴上；错到$90°$时电机完全不产转矩，而符号错了速度环就发散。所以驱动器在调试时测出$\theta_0$（沿固定轴通电、让转子自行对齐）并存下来——这也是关节编码器采用绝对式的原因之一。

## 驱动器与母线电压 {#sec-drives}

**驱动器**（伺服放大器、逆变器）是一个三相桥，含六个功率开关、电流传感器、一颗运行[[#alg-foc]]及其上各环的微控制器、栅极驱动器和保护（过流、过压、过热、短路）。机械臂里以两种架构为主：

- **低压驱动器**，直流母线$24\text{–}60\,\mathrm V$，常见$48\,\mathrm V$。协作臂上常见：驱动器装在每个关节内（**一体化关节模块**），母线贯穿整支臂，特低电压让电气安全大大简化。开关用MOSFET；氮化镓晶体管因开关更快、损耗更低、能把驱动器做得更小，正越来越多地投入使用（截至2026年）。
- **高压驱动器**，直流母线约$300\,\mathrm V$（来自$230\,\mathrm V$单相市电）或$560\text{–}700\,\mathrm V$（来自$400\text{–}480\,\mathrm V$三相电），开关用IGBT或碳化硅。工业臂上常见：驱动器装在控制柜里，电机功率穿过臂内电缆。电压更高，同一台电机能达到更高转速，电缆里电流更小。

母线电压限制转速，因为驱动器必须先越过电机的反电动势。采用空间矢量调制时，可用的最大相电压幅值为$V_{dc}/\sqrt3$；稳态、$i_d = 0$时，所需相电压幅值是[[#eq-dq-model]]中$\bigl(R\hat\imath + \omega_e\psi_m,\ \omega_eL\hat\imath\bigr)$的模（$q$与$d$分量）。

::: example 48 V母线够用吗？ {#ex-bus}
[[#ex-frameless]]的电机有$p = 10$对极，相电阻$R = 0.033\,\Omega$，相电感$L = 0.10\,\mathrm{mH}$，$p\psi_m = 0.0519\,\mathrm{V\,s/rad}$。经$N = 100$关节须达到$3.14\,\mathrm{rad/s}$，同时还要输出峰值转矩（$\hat\imath = 28.9\,\mathrm A$）。检查$48\,\mathrm V$与$24\,\mathrm V$母线是否足够，理论电压只取$95\,\%$留给死区时间等裕量。
::: solution
电机转速$\omega = 314\,\mathrm{rad/s}$（$3000\,\mathrm{rev/min}$）；电气角速度$\omega_e = 10\times314 = 3140\,\mathrm{rad/s}$。
反电动势幅值：$p\psi_m\omega = 0.0519\times314 = 16.3\,\mathrm V$。电阻压降：$0.033\times28.9 = 0.95\,\mathrm V$。电抗压降：$\omega_eL\hat\imath = 3140\times1.0\times10^{-4}\times28.9 = 9.09\,\mathrm V$，与它们正交。
$$
\hat v = \sqrt{(16.3 + 0.95)^2 + 9.09^2} = 19.5\,\mathrm V .
$$
可用电压：$48\,\mathrm V$母线上为$0.95\times48/\sqrt3 = 26.3\,\mathrm V$——够用，还有$35\,\%$裕量。$24\,\mathrm V$时$0.95\times24/\sqrt3 = 13.2\,\mathrm V$——不够；解$\hat v(\omega) = 13.2\,\mathrm V$可知，峰值转矩下电机最高只能到约$208\,\mathrm{rad/s}$，即关节转速$2.1\,\mathrm{rad/s}$（$119\,\mathrm{°/s}$）而不是$180\,\mathrm{°/s}$。

**观察。**10对极在$3000\,\mathrm{rev/min}$时，电抗压降超过反电动势的一半。多极对关节电机在高速下受电感造成的电压限制——这就是驱动器要用弱磁、或低压母线的绕组要选少匝（$K_t$更低、电流更大）的原因。
:::
:::

机械臂减速或下放负载时，电机变成发电机，把能量送回母线。母线电压低、电容又有限，收不了多少：把示例机械臂的肩部从$3.14\,\mathrm{rad/s}$刹停，释放$\tfrac12\times7.03\times3.14^2 = 35\,\mathrm J$动能（再减去损耗），而$2\,\mathrm{mF}$的母线电容从$48$充到$56\,\mathrm V$只存$0.83\,\mathrm J$。这些能量只能去别处：给其他关节、送回电源（若电源能收），或灌进由斩波器在母线电压升高时投入的**制动电阻**——它是每支臂电源设计的标准部件，也是调试时过压跳闸的常见来源。

## 编码器 {#sec-encoders}

编码器给驱动器换向用的转子角、给速度环速度、给位置环关节角。[[mechatronics/sensors]]已介绍增量式与绝对式编码器；这里看关节需要什么。

::: definition 增量式与绝对式关节编码器 {#def-encoders}
**增量式**编码器输出两路正交方波（A与B），常带每转一个的零位脉冲；对每周期四个边沿全部计数（×4解码），$n$线给出每转$4n$个计数。它测量的是角的**变化**，所以绝对位置必须在上电后靠回零求得。**绝对式**编码器对一个旋转圈内的每个位置（**单圈**），或跨越多圈（**多圈**，计数由电池供电的电子器件、一组单圈编码器齿轮系或维冈德（Wiegand）取能传感器保持）给出唯一的码字，通常经串行接口输出（SSI、BiSS-C、EnDat及若干厂商协议）。**分辨力**是最小可报告的变化，$b$位编码器为$2\pi/2^b$；**精度**是一转内报告角与真实角之间的最大差。
:::

关节里占主导的传感原理有两种：

- **光学式**编码器用光源和光电探测器阵列读取玻璃或金属码盘/码环上的细光栅，在刻线之间对模拟正弦与余弦信号插值。它们给出最高的分辨力与精度，但怕脏污和凝露，必须密封。工业伺服电机的轴端光学编码器典型分辨$2^{20}$到$2^{26}$线每转（截至2026年）。
- **磁式**编码器感受磁体。最便宜的是**同轴式（on-axis）**设计：轴端一个径向充磁磁体，下面是霍尔芯片，典型12–14位有效位——用于换向很好，用于关节定位不够。**离轴式（off-axis）**设计用磁阻或霍尔读头读多极充磁环，可达18–20位以上；适合空心轴，耐脏耐油。感式与容式编码器填补类似空位。

分辨力不是精度。码环最大的误差通常来自安装：若环的中心在半径$r$处偏了$e$，读数就带有幅值$e/r$弧度的每转一次误差。半径$30\,\mathrm{mm}$的环有$50\,\mathrm{\mu m}$偏心，即$1.7\,\mathrm{mrad}$（$5.7$角分）——是19位编码器单步的两百倍还多。两个相隔$180°$的读头取平均能恰好消去偏心误差（误差在两读头处异号），精密关节编码器因此常用双读头；剩下的误差由厂商或在关节装调时标定。

### 一个编码器还是两个 {#sec-dual-encoder}

带减速器的关节可以在电机侧、输出侧或两侧都测角。

- **电机侧编码器**直接看转子：换向非它不可，而且由于关节角是$\theta_m/N$，它折算到关节的分辨力细$N$倍。但它隔着减速器看关节角，回差、负载下的扭转变形、减速器自身的运动学误差（[[robot-arm-design/gear-reducers]]）对它都是隐形的。
- **输出侧编码器**在减速器之后测关节角，上述误差不进入测量位置。它需要是绝对式的（不必多圈——关节转过不足一转或几转），而且因为不再有传动比放大分辨力，它本身必须分辨力足够高。

**双编码器关节**两头都有。驱动器用编码器（电机侧）做换向、闭合速度环（细、快、与电机转矩同处一地——见[[robot-arm-design/joint-control]]）；位置环用输出编码器，或者用经两编码器缓变差修正后的电机编码器。差值$\theta_m/N - \theta_{\text{out}}$同时也是减速器的扭转变形；配合减速器的扭转刚度，它给出**关节力矩**的估计——关节力矩传感器的廉价替身，用于碰撞检测。输出编码器还让控制器能够检查电机编码器（以及减速器）的故障，安全功能正用得上。

::: example 三种编码器配置下的尖端分辨力 {#ex-encoder}
示例机械臂的TCP距肩轴$0.90\,\mathrm m$，$N = 100$。求一个计数对应的尖端移动：(a) 17位电机侧编码器；(b) 19位输出侧编码器；(c) 装在输出端的14位同轴磁编码器。
::: solution
(a) 每计数关节角$2\pi/(2^{17}\times100) = 4.79\times10^{-7}\,\mathrm{rad}$；尖端$0.90\times4.79\times10^{-7} = 0.43\,\mathrm{\mu m}$。
(b) $2\pi/2^{19} = 1.20\times10^{-5}\,\mathrm{rad}$；尖端$10.8\,\mathrm{\mu m}$。
(c) $2\pi/2^{14} = 3.83\times10^{-4}\,\mathrm{rad}$；尖端$345\,\mathrm{\mu m}$。

解读：(a)的分辨力远超需要，但它折算到关节的**精度**只是减速器的精度——应变波减速器的传动误差典型在角分量级（$290\,\mathrm{\mu rad}$，尖端$0.26\,\mathrm{mm}$）。(b)只有当自身精度标定到同等水平，才能满足[[robot-arm-design/arm-specification]]的$\pm0.05\,\mathrm{mm}$预算。(c)只适合做换向或粗略检查。真正满足规格的设计是双编码器：(a)供速度环，(b)供位置。
:::
:::

::: history
多数绝对式编码器采用的反射二进制码——相邻码字只有一位不同，故在跳变边界上取读也不会错得离谱——由贝尔实验室的弗兰克·格雷（Frank Gray）于1953年（1947年提交申请）为脉冲编码通信取得专利，很快被用于轴编码器。磁场定向控制约于1970年由西门子的费利克斯·布拉施克（Felix Blaschke）提出，达姆施塔特工业大学的卡尔·哈塞（Karl Hasse）几乎同时独立提出；但要等到1980年代和1990年代便宜而快速的数字信号处理器，它才成为标准做法。它进入机器人关节，跟随的是1980年代工业机器人从液压与有刷直流驱动改换无刷交流伺服电机的潮流。一体化关节模块——电机、减速器、编码器、抱闸与驱动器共装在一个空心壳体内——在2000年代和2010年代成为协作机械臂的积木块。
:::

## 后续内容 {#sec-leads}

电机在电机轴上产生转矩，编码器测量电机角；它们与连杆之间隔着减速器：减速器放大转矩、减小转速、把电机惯量乘$N^2$，还添上回差、柔顺与摩擦。[[robot-arm-design/gear-reducers]]接住这部分，[[robot-arm-design/joint-control]]则围绕整个关节合上电流、速度与位置环。

::: summary
- 航模舵机是带电位器的完整位置环；桌面臂够用，但有死区、回差、没有转矩控制。kg·cm标称的是堵转转矩：$1\,\mathrm{kg\,cm} = 0.0981\,\mathrm{N\,m}$。
- 步进电机带着负载保持位置时有负载角误差$\arcsin(T_L/T_h)/N_r$，越过$T_h$会失步，一直满电流运行，且没有转矩控制；闭环步进只解决了其中一部分。
- 无刷PMSM关节（带壳或无框）占主导：$T = \tfrac32p\psi_m\hat\imath$，$K_t^{\text{rms}} = \sqrt3K_{e,LL}^{\text{rms}}$。每个常数都要核对约定。
- $K_m = T/\sqrt{P_{\text{Cu}}}$决定悬臂产热。连续转矩是热限制（$\Delta T = PR_{th}$，电阻随温升0.39 %/K）；峰值转矩受电流、饱和与退磁限制。
- FOC：克拉克与帕克变换把相电流变到$i_d$、$i_q$；带解耦的PI环调节它们；表贴磁体电机里$T \propto i_q$；编码器偏置$\theta_0$必须正确。
- 母线电压限制转速：所需$\hat v = \lvert(R\hat\imath + \omega_e\psi_m,\ \omega_eL\hat\imath)\rvert \le V_{dc}/\sqrt3$。再生能量要有去处。
- 编码器：增量式需要回零，绝对式不需要；分辨力$2\pi/2^b$不是精度；偏心误差为$e/r$，两个对置读头可消去。双编码器在电机侧得到精细的换向与速度，在输出侧得到真实关节角（以及力矩估计）。
:::

## 习题

::: exercise 换算舵机的力矩额定值 {level=1 check="2.4525"}
一只航模舵机标称堵转转矩$25\,\mathrm{kg\,cm}$。用N·m表示它（取$g = 9.81\,\mathrm{m/s^2}$）。（输入的转矩以N·m为单位。）
::: solution
$25\,\mathrm{kg\,cm} = 25 \times 9.81\,\mathrm N\times0.01\,\mathrm m = 2.4525\,\mathrm{N\,m}$。记住这是堵转值；可用的连续转矩大约只有它的三分之一到二分之一。
:::

::: exercise 步进电机的负载角 {level=1 check="0.6"}
一台混合式步进电机有$50$个转子齿、保持转矩$2.0\,\mathrm{N\,m}$，正保持$1.0\,\mathrm{N\,m}$的稳态负载。它的转子偏离电气平衡位置多少？（输入的角度以度为单位。）
::: solution
$\theta_L = \arcsin(1.0/2.0)/50 = (\pi/6)/50 = 0.01047\,\mathrm{rad} = 0.6°$，是$1.8°$整步的三分之一。
:::

::: exercise 由电机常数求铜损 {level=1 check="25"}
一台关节电机$K_m = 0.40\,\mathrm{N\,m/\sqrt W}$，保持$2.0\,\mathrm{N\,m}$的恒力矩。铜损是多少？（输入的功率以W为单位。）
::: solution
$P = (T/K_m)^2 = (2.0/0.40)^2 = 25\,\mathrm W$。转矩翻倍损耗翻四倍——这就是大型机械臂里用弹簧或配重做重力补偿有吸引力的原因。
:::

::: exercise 由反电动势测量求转矩常数 {level=2 check="0.6616"}
一台PMSM以$1000\,\mathrm{rev/min}$旋转时，产生线–线反电动势$40\,\mathrm V$（rms）。求其每rms安培的转矩常数。（输入的$K_t$以N·m/A为单位，保留四位小数。）
::: solution
$K_{e,LL}^{\text{rms}} = 40/104.72 = 0.3820\,\mathrm{V\,s/rad}$。由[[#eq-kt-ke]]，$K_t^{\text{rms}} = \sqrt3\times0.3820 = 0.6616\,\mathrm{N\,m/A_{rms}}$。若按峰值安培计则为$0.6616/\sqrt2 = 0.4678\,\mathrm{N\,m/A}$。
:::

::: exercise 帕克变换 {level=2 check="3.186"}
$\theta_e = 45°$时驱动器测得$i_a = 3.0\,\mathrm A$、$i_b = 5.0\,\mathrm A$。求$i_q$。（输入的$i_q$以A为单位，保留三位小数。）
::: solution
$i_\alpha = 3.0$，$i_\beta = (3.0 + 10.0)/\sqrt3 = 7.506\,\mathrm A$。$i_q = -3.0\sin45° + 7.506\cos45° = -2.121 + 5.307 = 3.186\,\mathrm A$；$i_d = 3.0\cos45° + 7.506\sin45° = 7.429\,\mathrm A$。静止的表贴磁体电机中出现这么大的$i_d$，提示编码器偏置有误：大部分电流没有产生转矩。
:::

::: exercise 廉价编码器的尖端分辨力 {level=2 check="326"}
一支机械臂每个关节输出端用14位同轴磁编码器。TCP距基座关节轴$0.85\,\mathrm m$时，基座关节一个计数对应尖端移动多少？（输入的距离以µm为单位，取整到µm。）
::: solution
$0.85\times2\pi/2^{14} = 0.85\times3.835\times10^{-4} = 3.26\times10^{-4}\,\mathrm m = 326\,\mathrm{\mu m}$。还不必考虑精度，这样的臂除非同时使用电机侧编码器，重复性就不可能优于大约三分之一个毫米。
:::

::: exercise 码环的偏心 {level=2 check="0.4"}
一个半径$25\,\mathrm{mm}$的离轴编码器环安装偏心$10\,\mathrm{\mu m}$，由单个读头读取。每转一次的角误差幅值是多少？（以mrad输入。）$180°$处再加一个读头会怎样？
::: solution
$e/r = 10\times10^{-6}/0.025 = 4.0\times10^{-4}\,\mathrm{rad} = 0.4\,\mathrm{mrad}$（$1.4$角分）。两个读头看到的误差异号；其平均恰好消去一次谐波，只剩码环自身刻划与形状造成的高阶误差。
:::

::: exercise 计电阻温升的绕组稳态温度 {level=3 check="96.0"}
设$20\,°\mathrm C$铜损为$P_{20}$、热阻$R_{th}$、环境温度$T_a$、电阻温度系数$\alpha = 0.00393\,\mathrm{K^{-1}}$，证明稳态绕组温度为$T_w = \dfrac{T_a + P_{20}R_{th}(1 - 20\alpha)}{1 - \alpha P_{20}R_{th}}$，并说明何时不存在稳态温度。代入$P_{20} = 21.56\,\mathrm W$、$R_{th} = 2.0\,\mathrm{K/W}$、$T_a = 40\,°\mathrm C$计算。（输入的$T_w$以°C为单位，保留一位小数。）
::: solution
稳态时$T_w = T_a + R_{th}P_{20}[1 + \alpha(T_w - 20)]$。把含$T_w$的项归并：$T_w(1 - \alpha P_{20}R_{th}) = T_a + P_{20}R_{th}(1 - 20\alpha)$，即得公式。若$\alpha P_{20}R_{th} \ge 1$则无正解：损耗随温度增长快于散热，绕组发生热失控（实践中会一直烧到损毁或保护跳闸）。此处$P_{20}R_{th} = 43.12\,\mathrm K$，$\alpha P_{20}R_{th} = 0.1695$，分子$40 + 43.12\times0.9214 = 79.73$，故$T_w = 79.73/0.8305 = 96.0\,°\mathrm C$。这里忽略的磁体$K_t$随温下降，还会让电流与温度再高一点。
:::

::: exercise 制动能量去了哪里？ {level=3}
示例机械臂的肩部（绕关节的惯量$7.03\,\mathrm{kg\,m^2}$）在$0.3\,\mathrm s$内从$3.14\,\mathrm{rad/s}$刹停，同时把负载的质心下降$0.10\,\mathrm m$（负载$5\,\mathrm{kg}$，其余质量按比例下降，共释放势能$12\,\mathrm J$）。$48\,\mathrm V$母线有电容$2\,\mathrm{mF}$，必须保持在$56\,\mathrm V$以下；其他关节空闲，电源不能接受反向功率。估算回馈的能量，说明电容收不下它，并为把母线钳位在$56\,\mathrm V$选一只制动电阻（阻值与能量定额）。关于损耗要说明你的假设。
::: solution
可用能量：动能$\tfrac12\times7.03\times3.14^2 = 34.7\,\mathrm J$加势能$12\,\mathrm J$，约$47\,\mathrm J$。减速器（反向驱动时效率大约$0.7$）、铜损与驱动器损耗掉一部分，约$60\,\%$被回馈：$0.3\,\mathrm s$里约$28\,\mathrm J$，平均约$94\,\mathrm W$，制动初期峰值可能有两倍。$48$到$56\,\mathrm V$之间的电容吸收$\tfrac12C(56^2 - 48^2) = 0.83\,\mathrm J$，只有需求的三十分之一。在母线到$56\,\mathrm V$时投入的制动电阻必须吸收峰值功率：$R \le V^2/P = 56^2/200 = 15.7\,\mathrm\Omega$，取$10\,\mathrm\Omega$（$56\,\mathrm V$下$314\,\mathrm W$，明显高于峰值）。每次刹停的能量约$28\,\mathrm J$；若每两秒刹停一次，平均耗散约$14\,\mathrm W$，脉冲能量定额必须超过$28\,\mathrm J$。更好的设计是让能量与同时正在加速的其他关节共享，或者用双向电源。
:::

::: exercise 为低成本教学臂选执行器 {level=3}
一家公司想做一台六轴教学臂：负载$0.5\,\mathrm{kg}$、臂展$0.45\,\mathrm m$、重复性±0.2 mm，而零售价排除了每个关节都用无框电机和谐波减速器。就(a)肩关节与(b)腕关节，比较：航模或串行总线舵机；带同步带或行星减速的闭环步进电机；带行星或摆线减速的小型无刷电机。推荐一种组合，并说明用户会感受到什么。
::: solution
好的回答会先算肩部重力力矩（例如$0.5\,\mathrm{kg}$在$0.45\,\mathrm m$处，加上约$1.5\,\mathrm{kg}$臂重在$0.2\,\mathrm m$处，得$9.81\times0.525 \approx 5\,\mathrm{N\,m}$，峰值$8\text{–}10\,\mathrm{N\,m}$），指出这超出最大航模舵机在合理工作循环下的能力，而$0.45\,\mathrm m$处的±0.2 mm要求每个关节约$0.15\,\mathrm{mrad}$（30角秒）——超出电位器舵机。肩、肘用闭环步进加同步带或低回差行星减速是稳妥的成本选择（低速力矩大，编码器消除失步），但没有转矩控制，碰撞检测只能用跟随误差阈值。小型无刷电机配FOC加摆线或行星减速更贵，但带来转矩控制、安静的运动和基于电流的碰撞检测——课堂上很值钱。腕关节在$0.5\,\mathrm{kg}$下用带位置反馈的串行总线舵机足够，只要其回差在短力臂上可接受（$0.06\,\mathrm m$处$1°$就是$1\,\mathrm{mm}$——对±0.2 mm太多，所以需要低回差减速级或输出编码器）。用户会注意到：低速下步进的噪声与振动；不用无刷关节就没有拖动示教；以及装增量式编码器的关节启动时必须回零——除非装上绝对式编码器。
:::
