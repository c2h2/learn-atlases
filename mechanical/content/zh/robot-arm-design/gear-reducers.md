[[robot-arm-design/joint-actuators]]里选出的电机只在每分钟几千转下产出约$2\,\mathrm{N\,m}$；它驱动的肩却需要每秒几弧度的$180\,\mathrm{N\,m}$。两者之间是**减速器**，它做的事远不止放大转矩。它把电机的惯量乘上传动比的平方，使转子在动力学上能压过连杆。它添上回差和一根软的非线性弹簧，使负载下的关节角不再是电机角除以传动比。它因摩擦损耗功率，这决定了人能否徒手推开机械臂。而且关节的寿命与抗碰撞能力，瓶颈常常在它。本章比较关节采用的三大减速器族系——**行星**、**摆线**与**应变波**——然后看低传动比的替代方案**准直接驱动**（quasi-direct drive，QDD），最后以示例机械臂肩关节的选型流程收尾。渐开线齿轮的几何、受力与额定值在[[machine-design/gear-design]]，轮系在[[mechanisms/gear-trains]]；这里把减速器当作一个有传动比、刚度曲线、效率和寿命的部件。

## 关节减速器必须做到什么 {#sec-reducer-requirements}

工业臂的关节传动比常在约$50$到$200$之间；协作臂每个关节约$50$到$160$；腿式机器人与一些力控臂取$6$到$10$。无论传动比多少，机器人关节的减速器都被要求一种不寻常的性质组合：

- **回差与空程为零或极小**，因为肩部的任何多余间隙都会在工具端被臂展放大（[[robot-arm-design/arm-specification]]）：$0.9\,\mathrm m$处一角分就是$0.26\,\mathrm{mm}$。
- **扭转刚度高**，关节受力后不拧转，且关节固有频率（它限制伺服带宽，[[robot-arm-design/joint-control]]）要高。
- **转矩密度高、中空大**，关节才小且轻，电缆才穿得过去。
- **耐倾覆力矩**，因为减速器的输出端通常要经整体式输出轴承扛着连杆。
- **瞬时转矩大**，应付急停与碰撞，并在真实工作循环下有长寿命。

没有任何一种型式在所有方面都最好，这就是机械臂常常混用的原因：大关节用摆线或应变波单元，腕用应变波或行星单元。

## 行星减速器 {#sec-planetary}

一行星（周转）级有一个中央**太阳轮**、三个以上既与太阳轮又与内齿**圈**啮合的**行星轮**，和一个支撑行星轮轴的**行星架**。内齿圈固定、太阳轮输入、行星架输出时，它是用直齿或斜齿得到约$3$到$10$的传动比最紧凑的办法，且载荷由各行星轮分担。

::: proposition 行星级的传动比 {#prop-planetary}
一行星级的太阳轮有$Z_s$齿、内齿圈有$Z_r$齿，则太阳轮、内齿圈与行星架的角速度满足威利斯（Willis）关系式
$$
\frac{\omega_s - \omega_c}{\omega_r - \omega_c} = -\frac{Z_r}{Z_s}.
$$ {#eq-willis}
内齿圈固定（$\omega_r = 0$）、太阳轮输入、行星架输出时，传动比为
$$
N = \frac{\omega_s}{\omega_c} = 1 + \frac{Z_r}{Z_s}.
$$ {#eq-planetary-ratio}
:::

::: proof
以行星架为参考系，行星轮轴静止，这一级就是一般轮系：太阳轮到行星轮（外啮合，转向相反）、行星轮到内齿圈（内啮合，转向不变），故太阳轮与内齿圈转向相反、速比为$Z_r/Z_s$，行星轮齿数消去。相对行星架，两者速度为$\omega_s - \omega_c$与$\omega_r - \omega_c$，即得[[#eq-willis]]。令$\omega_r = 0$：$\omega_s - \omega_c = (Z_r/Z_s)\,\omega_c$，故$\omega_s/\omega_c = 1 + Z_r/Z_s$。（装配还要求行星轮——齿数$Z_p$、同模数——满足$Z_r = Z_s + 2Z_p$，且$n$个均布行星轮要求$(Z_s + Z_r)/n$为整数。）
:::

太阳轮$12$齿、内齿圈$60$齿给出$N = 6$；两级这样级联得$36$，三级得$216$。每一级都带来长度、质量，以及一份回差与摩擦的啮合，所以机械臂里的行星减速器很少超过两三级；需要$100{:}1$的关节通常改用别的型式。

其长处是效率高（额定负载下每级典型$94\text{–}97\,\%$）、中等传动比下可反向驱动、便宜、随处可得。短处是回差：渐开线齿轮要转动就得留齿侧间隙，精密行星减速器（截至2026年）通常标称回差$1$到$5$角分，普通品$10$角分以上。采用预紧、开缝或弹簧加载的行星轮可以压低回差，代价是摩擦。因此行星减速器常见于小臂的腕、低传动比的准直接驱动，以及两级摆线减速器的第一级。

## 摆线减速器 {#sec-cycloidal}

摆线减速器用一块**摆线轮**取代渐开线齿轮：其外缘是一条有$Z_c$个瓣的外摆线，在一圈$Z_c + 1$个圆柱**针齿销**内滚动。输入轴上的偏心轮驱动摆线轮沿小圆公转；因为摆线轮比针齿少一个瓣，偏心轮每转一周，摆线轮就倒退一个瓣。摆线轮上的孔与输出法兰上的销配合，拾取摆线轮的缓慢自转而忽略其摆动。两片相差$180°$的摆线轮平衡偏心惯性力。

::: proposition 单级摆线的传动比 {#prop-cycloidal}
针齿圈固定、偏心轮输入、从摆线轮的自转取输出，$Z_c$瓣的摆线轮配$Z_c + 1$个针齿的针圈给出
$$
N = \frac{\omega_{\text{in}}}{\omega_{\text{out}}} = -Z_c ,
$$ {#eq-cycloidal-ratio}
负号表示输出与输入转向相反。
:::

::: proof
摆线轮在针齿圆上纯滚动，于是像行星排的分析那样，把偏心轮当作“行星架”。相对偏心轮，摆线轮与针圈构成齿数为$Z_c$与$Z_c + 1$的内啮合副，同向转动、速比为$(Z_c + 1)/Z_c$：$(\omega_d - \omega_e)/(\omega_p - \omega_e) = (Z_c + 1)/Z_c$。令$\omega_p = 0$：$\omega_d = \omega_e - \omega_e(Z_c + 1)/Z_c = -\omega_e/Z_c$。
:::

$39$瓣对$40$针单级就得$39{:}1$。同时有很多瓣在接触——理论上约一半分担载荷——且接触是凸面与凹面之间的滚动，所以摆线减速器刚度高、耐冲击载荷（瞬时与急停转矩定额通常是额定转矩的好几倍）、空程极小，典型约一角分。工业臂大关节采用的两级型，加了一个正齿或行星的第一级来驱动两三个偏心轴；其传动比为$N = 1 + (Z_2/Z_1)Z_p$，其中$Z_2/Z_1$为第一级传动比、$Z_p$为针齿数，得到约$30$到$200$的传动比，中空大，且整体式输出轴承承受连杆的倾覆力矩。效率典型$75\text{–}90\,\%$；同转矩下比应变波减速器重。

## 应变波（谐波）减速器 {#sec-strain-wave}

应变波减速器有三个零件。**波发生器**是装了薄柔性球轴承的椭圆凸轮。**柔轮**是一个带外齿的薄壁钢杯（或帽），波发生器压入其内把口缘撑成椭圆。**刚轮**是一个刚性内齿圈，齿数比柔轮多两个，只在椭圆长轴两端附近与柔轮啮合。波发生器转动时，啮合区绕圈移动，波发生器每转一周，柔轮相对刚轮前进两个齿。

::: proposition 应变波减速器的传动比 {#prop-strain-wave}
柔轮齿数$Z_f$、刚轮$Z_c = Z_f + 2$，波发生器输入：
$$
\begin{aligned}
N &= -\frac{Z_f}{Z_c - Z_f} = -\frac{Z_f}{2} &&\text{（刚轮固定，柔轮输出）},\\
N &= \frac{Z_c}{Z_c - Z_f} = \frac{Z_c}{2} &&\text{（柔轮固定，刚轮输出）}.
\end{aligned}
$$ {#eq-strain-wave-ratio}
:::

::: proof
波发生器充当行星架，相对它柔轮与刚轮构成内啮合副：$(\omega_f - \omega_w)/(\omega_c - \omega_w) = Z_c/Z_f$。刚轮固定时$\omega_f = \omega_w(1 - Z_c/Z_f) = -\omega_w(Z_c - Z_f)/Z_f$，故$N = \omega_w/\omega_f = -Z_f/(Z_c - Z_f)$。柔轮固定时$-\omega_w = (Z_c/Z_f)(\omega_c - \omega_w)$，故$\omega_c = \omega_w(Z_c - Z_f)/Z_c$，$N = Z_c/(Z_c - Z_f)$，转向相同。
:::

柔轮$200$齿单级就得$100{:}1$；标准传动比约从$30$到$160$。减速器中空大、零件少、质量低——而且齿被椭圆变形预紧、同时约$30\,\%$的齿在啮合——回差基本为零。这些特性使它成为紧凑臂、协作臂与空间机构的首选减速器。

它的短处都来自反复挠曲。**扭转刚度偏低且非线性**，随载荷增大（进入啮合的齿增多）而升高；**效率**随转速、负载、温度与润滑剂剧烈变化，从额定负载下的约$85\,\%$到轻载或低温下远低于$50\,\%$；转矩–扭角曲线上有**迟滞**环；还有小幅**传动误差**，典型在角分量级、带波发生器每转两次的图形，表现为波发生器转速$2\times$频率处的振动源；过载时齿会跳开（**跳齿**，ratcheting），损伤减速器。寿命通常由波发生器的轴承决定。

::: example 三种方案实现100:1的关节 {#ex-three-ways}
求恰好给出$100$减速比所需的齿数：(a) 应变波减速器；(b) 两级摆线减速器；(c) 行星级；并比较转矩穿过的啮合副数。
::: solution
(a) 应变波、刚轮固定：$\lvert N\rvert = Z_f/2 = 100$需要$Z_f = 200$、$Z_c = 202$。一个挠啮合副，同时啮合的齿很多。

(b) 两级摆线：$N = 1 + (Z_2/Z_1)Z_p = 100$需要$(Z_2/Z_1)Z_p = 99$，例如$Z_p = 33$个针齿、第一级$Z_2/Z_1 = 3$（比如$16$与$48$齿）。两级：一级高速低转矩的正齿轮啮合，然后是摆线接触。

(c) 行星：$100 = 5\times5\times4$，三级，例如太阳轮$18$/内齿圈$72$（$N = 5$）两次、太阳轮$24$/内齿圈$72$（$N = 4$）一次。三个啮合副串联，各有回差；最后一级要扛全部$180\,\mathrm{N\,m}$。

**比较。**应变波与摆线方案用一两级紧凑结构达到$100{:}1$，回差可忽略；行星要三级、更长、回差累积——但其效率（$0.96^3 \approx 0.88$）仍胜过另外两种。这就是行星用于低传动比、其余两种用于高传动比的原因。
:::
:::

## 扭转刚度、空程与迟滞 {#sec-stiffness}

锁住减速器的输入，在输出端加载：把转矩升到额定值、翻到负的额定值再退回来，记录扭角。得到的是一条类似下图的环。目录用几个数字描述它。

::: definition 扭转刚度、空程与迟滞损失 {#def-stiffness}
对输入锁定的减速器，输出扭角$\theta$对输出转矩$T$的曲线上有：
- **回差**：零转矩下的自由间隙，来自齿侧间隙（预紧的应变波与摆线单元中基本为零）；
- **空程**：一个小而明确规定的转矩（典型为额定值的$\pm3\,\%$）下的扭角，把回差与接触初期极软的区段合并计之；
- **迟滞损失**：各向加载到额定转矩后回到零转矩时环的宽度，来自啮合与轴承中的摩擦；
- **扭转刚度**：斜率$\mathrm dT/\mathrm d\theta$，通常以分段线性给出：$0 \le T \le T_1$段为$K_1$，$T_1 < T \le T_2$段为$K_2$，$T_2$以上为$K_3$，应变波减速器满足$K_1 < K_2 < K_3$。转矩$T$下的扭角由逐段相加：
$$
\theta(T) = \frac{\min(T, T_1)}{K_1} + \frac{\max\bigl(\min(T, T_2) - T_1,\,0\bigr)}{K_2} + \frac{\max(T - T_2,\,0)}{K_3}.
$$ {#eq-twist}
:::

::: example 负载下肩关节的扭转 {#ex-windup}
设[[robot-arm-design/arm-specification]]示例机械臂的肩关节用一台应变波减速器，其（量级取自该转矩级目录的示意值）$K_1 = 5.4\times10^4$、$K_2 = 7.8\times10^4$、$K_3 = 1.0\times10^5\,\mathrm{N\,m/rad}$，$T_1 = 29$、$T_2 = 108\,\mathrm{N\,m}$。求$95.2\,\mathrm{N\,m}$静重力力矩下的扭角、$0.9\,\mathrm m$处对应的尖端位移、拿掉$5\,\mathrm{kg}$负载（$\tau_g = 51.0\,\mathrm{N\,m}$）后的变化，以及臂绕该关节摆动的最低固有频率。
::: solution
**满载扭角**，按[[#eq-twist]]：
$$
\theta = \frac{29}{5.4\times10^4} + \frac{95.2 - 29}{7.8\times10^4} = 5.37\times10^{-4} + 8.49\times10^{-4} = 1.39\times10^{-3}\,\mathrm{rad}\ (4.8\ \text{角分}).
$$
尖端位移$0.9\times1.39\times10^{-3} = 1.25\,\mathrm{mm}$。

**拿掉负载后：**$\theta = 5.37\times10^{-4} + (51.0 - 29)/7.8\times10^4 = 8.19\times10^{-4}\,\mathrm{rad}$，尖端$0.74\,\mathrm{mm}$。于是拿起负载会使尖端下坠$0.51\,\mathrm{mm}$——重复性规格要求的十倍——除非控制器测出扭角（输出编码器）或按刚度模型补偿。

**固有频率：**工作点附近割线刚度为$95.2/1.39\times10^{-3} = 6.9\times10^4\,\mathrm{N\,m/rad}$，切线刚度为$K_2 = 7.8\times10^4$。连杆惯量$7.03\,\mathrm{kg\,m^2}$悬在这根弹簧上摆动（电机侧被伺服牢牢握死）时，$f = \frac{1}{2\pi}\sqrt{7.8\times10^4/7.03} = 16.8\,\mathrm{Hz}$；零转矩附近用$K_1$，为$14.0\,\mathrm{Hz}$。

**合理性检验。**$10\text{–}20\,\mathrm{Hz}$的最低结构模态、满载下毫米量级的下垂，正是这一尺度轻质机械臂的典型特征，也正是它们的位置环只调到几赫兹、标定要计入关节柔顺（[[robot-arm-design/calibration]]）的原因。减速器通常是关节里最软的元件，但不是唯一的：[[robot-arm-design/links-and-structure]]会把连杆与轴承也写进挠度预算。
:::
:::

::: warning 目录刚度不是关节的刚度
目录刚度描述的是单独的减速器——在刚性台架上夹好测的。装进关节后，其输入端面对的是电机的伺服刚度（有限值，超出伺服带宽后为零），输出法兰坐在关节的输出轴承与壳体上，安装螺栓与壳体本身也会扭。实测关节刚度通常远低于减速器目录值。在采信任何挠度或固有频率预测之前，先测装好的关节——锁住电机、在输出端用杠杆挂砝码施加已知转矩、读输出编码器或百分表。
:::

## 效率与反向可驱动性 {#sec-efficiency}

减速器的**正向效率**$\eta_f$是电机驱动负载时输出功率与输入功率之比。**反向效率**$\eta_b$适用于负载反过来驱动电机的场合——人推机械臂、臂靠重力下放、关节减速。由于损耗主要是正比于传递载荷的摩擦，$\eta_b$低于$\eta_f$；若摩擦足够大，$\eta_b$会跌到零：减速器**自锁**（小导程角的蜗杆即如此，[[machine-design/gear-design]]）。机器人减速器不自锁，但许多很难反驱。目录会给出**反向驱动转矩**：电机未通电时，把输入端转动起来所需的输出转矩。

人要搬动未上电的关节所须施加的转矩，是减速器的反向驱动转矩加上电机齿槽与摩擦转矩的$N$倍；人感受到的惯量是连杆惯量加$N^2J_m$。

::: proposition 透过减速器，输出端看到什么 {#prop-reflected}
转子惯量$J_m$、摩擦转矩$T_{f,m}$的电机，经传动比为$N$的理想减速器，在输出端表现为惯量与摩擦转矩
$$
J_{\text{refl}} = N^2J_m,\qquad T_{f,\text{refl}} = N\,T_{f,m},
$$ {#eq-reflected}
而正向驱动时，电机转矩$T_m$在输出端成为$\eta NT_m$。
:::

::: proof
电机角$\theta_m = N\theta$。转子动能为$\tfrac12J_m\dot\theta_m^2 = \tfrac12(N^2J_m)\dot\theta^2$，正是惯量$N^2J_m$以输出转速旋转时的动能。摩擦转矩$T_{f,m}$耗散功率$T_{f,m}\dot\theta_m = (NT_{f,m})\dot\theta$，正是输出转速下一个$NT_{f,m}$转矩的耗散。计入减速器损耗后，电机功率$T_m\dot\theta_m$的$\eta$份额到达输出端，得$\eta NT_m$。
:::

平方带来巨大差别。转子惯量$1.2\times10^{-4}\,\mathrm{kg\,m^2}$的无框电机，经$N = 100$反射出$1.2\,\mathrm{kg\,m^2}$——约占[[robot-arm-design/arm-specification]]整支伸直臂的六分之一——而经$N = 9$只反射$0.0097\,\mathrm{kg\,m^2}$。反射惯量要紧有三点原因：加速时它吃掉电机转矩；碰撞中打在障碍物或人身上的有效质量包含它（[[robot-arm-design/arm-safety]]）；而且它经减速器的弹簧与连杆耦合，构成[[robot-arm-design/joint-control]]里的双质量共振。

## 准直接驱动 {#sec-qdd}

**准直接驱动**（QDD）用一台大直径、高转矩电机配一级低传动比，通常是$6$到$10$的行星级。它的种种好处全由[[#eq-reflected]]而来：反射惯量与摩擦都小，于是关节是**透明**的——电机电流能很好地代表输出转矩，不加力矩传感器也能感知外力，关节容易反驱，冲击由电机而非轮齿吸收。腿式机器人正因为这些而采用QDD关节，触觉设备与一些研究臂、低成本臂亦然。

代价是转矩。取$N = 9$，示例机械臂的肩需要电机出$180/9 = 20\,\mathrm{N\,m}$峰值、约$14\,\mathrm{N\,m}$连续——是[[robot-arm-design/joint-actuators]]那台电机的十倍，因此重得多——更糟的是，对抗重力悬住臂的损耗按$(T/K_m)^2$计，$T$大了十倍，只有大得多的$K_m$、也就是大得多的电机才付得起。因此QDD适合重力力矩相对动力学与接触力矩很小的场合：腿（步间卸载）、轻型臂，以及带重力平衡的机械臂的远端关节。

::: example 肩关节：带减速器还是准直接驱动？ {#ex-qdd}
比较驱动示例机械臂肩关节的两种方案：(A) [[robot-arm-design/joint-actuators]]的电机（$K_m = 0.35\,\mathrm{N\,m/\sqrt W}$，$J_m = 1.2\times10^{-4}\,\mathrm{kg\,m^2}$，摩擦$0.02\,\mathrm{N\,m}$）配$N = 100$；(B) 一台大型QDD电机（$K_m = 1.5\,\mathrm{N\,m/\sqrt W}$，$J_m = 1.0\times10^{-3}\,\mathrm{kg\,m^2}$，摩擦$0.02\,\mathrm{N\,m}$）配$N = 9$。求：保持$95.2\,\mathrm{N\,m}$重力力矩时的铜损（悬持时忽略减速器损耗）、人在关节处感到的摩擦，以及把反射电机惯量折算成$0.9\,\mathrm m$外工具处等效质量的结果。
::: solution
**悬持损耗：**(A) $T_m = 0.952\,\mathrm{N\,m}$，$P = (0.952/0.35)^2 = 7.4\,\mathrm W$。(B) $T_m = 10.6\,\mathrm{N\,m}$，$P = (10.6/1.5)^2 = 50\,\mathrm W$——尽管B的电机$K_m$大四倍（质量好几倍），损耗仍有七倍。

**关节处的摩擦**（$NT_{f,m}$）：(A) $2.0\,\mathrm{N\,m}$，还要加上应变波减速器自身的反向驱动转矩（通常大得多）；(B) $0.18\,\mathrm{N\,m}$，再加一点行星级的损耗。人在工具端，(B)下感到几牛，(A)下是几十牛。

**工具端的等效质量**（$N^2J_m/r^2$）：(A) $1.2/0.81 = 1.48\,\mathrm{kg}$；(B) $0.081/0.81 = 0.10\,\mathrm{kg}$。

**结论：**QDD赢在透明性与碰撞质量，输在悬持发热与电机质量上。对肩部大部分时间都在对抗重力悬持负载的机械臂，除非用弹簧或配重平衡重力，带减速器的关节才是合理选择。
:::
:::

## 额定转矩、瞬时转矩与寿命 {#sec-rating}

减速器目录给出几条转矩限值，各对应一种不同的失效：

- **额定转矩**$T_r$：减速器在**额定输入转速**$n_r$下达到**额定寿命**$L_r$（典型几千到几万小时）时的转矩；寿命通常是轴承的（波发生器轴承、偏心轴轴承）或齿面的疲劳。
- **峰值（重复）转矩**：正常循环中加减速的限值。
- **平均转矩限值**：允许连续作用的最大三次方平均转矩（见下）。
- **瞬时转矩**：罕见事件的限值——急停、碰撞——在其寿命内允许发生的次数有限；超过它有断齿风险，应变波单元还会跳齿。

变化工作循环下的寿命，像滚动轴承（[[machine-design/bearings]]）那样，用按各转矩下转数加权的**三次方平均转矩**估算。设循环分为$j$段，输出转矩$\lvert T_j\rvert$、输入转速$n_j$、历时$t_j$：
$$
T_{av} = \left(\frac{\sum_j n_jt_j\lvert T_j\rvert^3}{\sum_j n_jt_j}\right)^{1/3},\qquad n_{av} = \frac{\sum_j n_jt_j}{\sum_j t_j},\qquad L \approx L_r\left(\frac{T_r}{T_{av}}\right)^3\frac{n_r}{n_{av}} .
$$ {#eq-reducer-life}
这一形式见于应变波与摆线目录（有的用略异于3的指数），是从滚动轴承的$L_{10}$寿命沿袭的经验额定关系：它给出$90\,\%$的单元能达到或超过的寿命，不是保证。零速段不计权重，因为静止轴承不累积疲劳循环——但带载静止还可能带来别的损伤（振动下的假布氏压痕），必须留在静强度与平均转矩限值之内。

::: example 肩关节减速器的选型 {#ex-select}
就示例机械臂的肩关节：输出峰值转矩$180\,\mathrm{N\,m}$（含裕量）、关节转速$3.14\,\mathrm{rad/s}$；电机同[[robot-arm-design/joint-actuators]]，峰值转矩$2.25\,\mathrm{N\,m}$、转子惯量$J_m = 1.2\times10^{-4}\,\mathrm{kg\,m^2}$、最高转速$5000\,\mathrm{rev/min}$；连杆惯量$7.03\,\mathrm{kg\,m^2}$、重力力矩$95.2\,\mathrm{N\,m}$、要求加速度$6.0\,\mathrm{rad/s^2}$。[[robot-arm-design/arm-specification]]的工作循环给出输出转矩$137$、$95.2$、$53.0\,\mathrm{N\,m}$，各历时$0.3$、$0.4$、$0.3\,\mathrm s$，平均关节转速$1.57$、$3.14$、$1.57\,\mathrm{rad/s}$，随后静止$1.0\,\mathrm s$。一个$N = 100$、效率$0.80$的应变波备选件有（示意）额定转矩$T_r = 100\,\mathrm{N\,m}$（$n_r = 2000\,\mathrm{rev/min}$下$L_r = 7000\,\mathrm h$），峰值重复转矩高于$180\,\mathrm{N\,m}$。核算传动比、加速度与寿命。
::: solution
**转速：**$N \le (5000\times2\pi/60)/3.14 = 524/3.14 = 167$；$N = 100$时电机最高转速对应关节$5.2\,\mathrm{rad/s}$——为[[robot-arm-design/joint-actuators]]的母线电压限制留了裕量。

**加速度**（计及反射惯量）：从水平位姿可用的关节加速度为
$$
\alpha = \frac{\eta NT_{m,\text{pk}} - \tau_g}{N^2J_m + J_L} = \frac{0.80\times100\times2.25 - 95.2}{1.20 + 7.03} = \frac{84.8}{8.23} = 10.3\,\mathrm{rad/s^2} \;>\; 6.0 . \checkmark
$$
对照：$N = 50$得$(90 - 95.2)/(0.30 + 7.03) < 0$：电机连臂都悬不住。传动比的下界由重力定，上界由转速定。

**寿命：**输入转速$n = 100\times\omega\times60/2\pi$为$1500$、$3000$、$1500\,\mathrm{rev/min}$，静止段为$0$。于是
$$
T_{av} = \left(\frac{1500(0.3)137.4^3 + 3000(0.4)95.2^3 + 1500(0.3)53.0^3}{1500(0.3) + 3000(0.4) + 1500(0.3)}\right)^{1/3} = 102.6\,\mathrm{N\,m},
$$
$n_{av} = (450 + 1200 + 450)/2.0 = 1050\,\mathrm{rev/min}$，于是
$$
L \approx 7000\left(\frac{100}{102.6}\right)^3\frac{2000}{1050} = 12\,400\,\mathrm h .
$$
按两班倒（每年运行$\approx 4000\,\mathrm h$）算是约三年——对工业产品太短，何况这个循环还偏保守（臂全程水平）。按立方律，大一档、额定转矩约翻倍的型号可把寿命提高到约八倍，代价是质量与惯量。急停的瞬时转矩也要校核：设要在$0.1\,\mathrm s$内把臂从全速刹停，需要$7.03\times31 + 95 \approx 320\,\mathrm{N\,m}$——远高于峰值重复转矩，所以它必须落在瞬时定额以内，否则急停要放得更软。

**合理性检验。**寿命由转矩的立方决定，质量估算$10\,\%$的误差就是寿命$30\,\%$的误差——这是迭代质量预算的又一理由。
:::
:::

## 比较与选择 {#sec-compare}

| 属性（典型值，截至2026年） | 精密行星 | 摆线（含两级） | 应变波 |
|---|---|---|---|
| 单级传动比 | 3–10 | 30–200（两级）；10–100（单级） | 30–160 |
| 回差/空程 | 回差1–10角分 | 空程≈1角分 | 回差≈0；空程<1角分 |
| 扭转刚度 | 中等 | 高 | 较低，非线性 |
| 额定负载下效率 | 每级94–97 % | 75–90 % | 60–85 %，强烈依赖负载与温度 |
| 反向可驱动性 | 低传动比时好 | 差至中等 | 差至中等 |
| 耐冲击 | 中等 | 高 | 有限（跳齿） |
| 质量、尺寸、中空 | 轻；中空小 | 较重；中空大 | 最轻；中空大 |
| 常用关节 | 腕、QDD、第一级 | 工业臂的基座、肩、肘 | 紧凑与协作臂的全部关节 |

::: algorithm 关节减速器的选型 {#alg-select}
1. 由关节要求定出**传动比窗口**：$N \le \omega_{m,\max}/\dot q_{\max}$（转速，并为母线电压留裕量），且$N$要大到使$\eta NT_{m,\text{pk}}$覆盖含反射惯量项$N^2J_m\ddot q$的峰值转矩、$\eta NT_{m,\text{cont}}$覆盖rms转矩。
2. 按表选**类型**：冲击载荷与刚度偏向摆线，质量与紧凑偏向应变波，透明性与反向可驱动性偏向低传动比行星。
3. 选**规格**：峰值重复转矩高于循环峰值；瞬时转矩高于急停与碰撞转矩；平均转矩限值高于$T_{av}$。
4. 按现实循环用[[#eq-reducer-life]]校**寿命**。
5. 对照尖端预算（[[robot-arm-design/arm-specification]]、[[robot-arm-design/links-and-structure]]）校**刚度与空程**，对照预期伺服带宽校最低固有频率（[[robot-arm-design/joint-control]]）。
6. 校**输出轴承**的力矩容量对连杆载荷，以及rms转速与转矩下的效率与发热。
7. 更新关节质量与惯量，与电机选型一起迭代。
:::

::: history
行星齿轮系历史悠久——安提基特拉（Antikythera）机构（公元前二或一世纪）就含周转轮系——其运动学由罗伯特·威利斯（Robert Willis）在《机构原理》（*Principles of Mechanism*，1841）中系统化。摆线减速器由德国工程师洛伦茨·布拉伦（Lorenz Braren）于1920年代发明，其设计被广泛授权，至今仍以基本相同的形态生产。应变波传动由C·沃尔顿·缪瑟（C. Walton Musser）于1950年代发明并于1959年获专利；它随阿波罗月球车登上月面，并被用于沙因曼（Victor Scheinman）1969年的斯坦福臂。主导工业臂大关节的两级摆线减速器出现于1980年代——电动工业机器人那时正需要刚度大、紧凑、耐冲击、空程小的关节。准直接驱动关节由2010年代MIT等地建造的腿式机器人推广开来，那些机器人需要透明、耐冲击的执行器。
:::

::: summary
- 传动比：行星每级$1 + Z_r/Z_s$；摆线$-Z_c$（单级）、$1 + (Z_2/Z_1)Z_p$（两级）；应变波$-Z_f/2$（刚轮固定）。
- 行星：效率高、可反驱、便宜，但有回差、单级传动比低。摆线：刚、耐冲击、约1角分、较重。应变波：轻、紧凑、零回差，但刚度低且非线性、效率多变、会跳齿。
- 转矩–扭角曲线有空程、迟滞与分段刚度$K_1 < K_2 < K_3$；负载下的扭转在尖端可达毫米量级，轻臂的最低关节模态为$10\text{–}20\,\mathrm{Hz}$。
- 透过减速器，输出端看到$N^2J_m$与$NT_{f,m}$：高传动比把连杆对电机隐藏起来，却使关节难反驱、碰撞时有效质量大。
- 准直接驱动（$N \approx 6\text{–}10$）透明、耐冲击，但需要大电机，怕重力负载。
- 按峰值、瞬时与平均转矩定规格；用三次方平均转矩估寿命，$L \approx L_r(T_r/T_{av})^3(n_r/n_{av})$；与电机和质量预算一起迭代。
:::

## 习题

::: exercise 两级行星减速器 {level=1 check="25"}
一台行星减速器有两个相同的级，每级太阳轮$18$齿、内齿圈$72$齿（内齿圈固定、太阳轮输入、行星架输出）。总传动比是多少？行星轮有多少齿？（输入的总传动比$N$。）
::: solution
每级$1 + 72/18 = 5$；总传动比$5^2 = 25$。行星轮有$(72 - 18)/2 = 27$齿；用三颗行星轮时$(18 + 72)/3 = 30$为整数，故可以均布。
:::
:::

::: exercise 应变波减速器的传动比 {level=1 check="80"}
一台应变波减速器的柔轮有$160$齿。刚轮固定时，波发生器到柔轮的传动比大小是多少？（输入$\lvert N\rvert$。）
::: solution
$\lvert N\rvert = Z_f/2 = 160/2 = 80$，柔轮转向与波发生器相反。若柔轮固定、刚轮（$162$齿）输出，则传动比为$162/2 = 81$，转向相同。

::: exercise 反射惯量 {level=1 check="1.296"}
一台电机转子惯量$8.0\times10^{-5}\,\mathrm{kg\,m^2}$，经$120{:}1$的减速器驱动关节；减速器自身输入侧的惯量（波发生器或太阳轮与输入轴）为$1.0\times10^{-5}\,\mathrm{kg\,m^2}$。它们在关节处添上多少惯量？（以kg·m²输入，保留三位小数。）
::: solution
$N^2(J_m + J_r) = 14\,400\times9.0\times10^{-5} = 1.296\,\mathrm{kg\,m^2}$。减速器的输入件随电机转速旋转、同样按$N^2$反射，不可漏算：这里它们添$0.144\,\mathrm{kg\,m^2}$。
:::

::: exercise 摆线传动比 {level=2 check="121"}
一台两级摆线减速器的第一级传动比$Z_2/Z_1 = 3$，针齿圈有$40$个针齿。求总传动比。（输入$N$。）
::: solution
$N = 1 + (Z_2/Z_1)Z_p = 1 + 3\times40 = 121$。

用[[#ex-windup]]的刚度数据，求输出转矩$60\,\mathrm{N\,m}$时减速器的扭角。（以角分输入，保留两位小数。）
::: solution

::: exercise 更轻工作循环下的寿命 {level=2 check="61700"}
在[[#ex-select]]中，设一组现实位姿把三次方平均转矩降到$T_{av} = 60\,\mathrm{N\,m}$，平均输入转速仍为$1050\,\mathrm{rev/min}$。估算寿命。（以小时输入$L$，保留三位有效数字。）

::: exercise 固有频率与传动比 {level=3}
一个关节的连杆惯量为$J_L$、减速器刚度为$k$，经传动比$N$由惯量$J_m$的电机驱动。把电机侧建模为自由（无伺服刚度）。证明关节的扭转固有频率为$\omega = \sqrt{k\,(1/J_L + 1/(N^2J_m))}$，并代入$J_L = 7.03\,\mathrm{kg\,m^2}$、$k = 7.8\times10^4\,\mathrm{N\,m/rad}$、$J_m = 1.2\times10^{-4}\,\mathrm{kg\,m^2}$、$N = 100$求值。与[[#ex-windup]]中电机侧固定的数值比较，并说明各自何时适用。
::: solution
把电机折算到输出端：惯量$N^2J_m$，角度$\theta_m/N$。两个惯量由弹簧$k$相连、无接地时的非零固有频率为$\omega^2 = k(1/J_1 + 1/J_2)$（由方程$J_1\ddot x_1 = -k(x_1 - x_2)$、$J_2\ddot x_2 = k(x_1 - x_2)$，相对坐标满足$\ddot x_r = -k(1/J_1 + 1/J_2)x_r$）。数值：$1/7.03 + 1/1.20 = 0.142 + 0.833 = 0.976$；$\omega = \sqrt{7.8\times10^4\times0.976} = 276\,\mathrm{rad/s}$，$f = 43.9\,\mathrm{Hz}$。电机被牢牢握住时$f = 16.8\,\mathrm{Hz}$（[[#ex-windup]]）。电机固定时的频率（从电机侧看出的“反共振”）适用于伺服在该频率上足够刚的情形；电机自由时的频率（共振）则是速度环在自身带宽之上看到的。两者都出现在电机侧频响里——见[[robot-arm-design/joint-control]]。
:::

::: exercise 腕关节的传动比窗口 {level=3 check="62.8"}
一个腕关节须达到$10\,\mathrm{rad/s}$、输出$12\,\mathrm{N\,m}$峰值（含$4\,\mathrm{N\,m}$重力），同时使$0.05\,\mathrm{kg\,m^2}$的输出惯量以$160\,\mathrm{rad/s^2}$加速。其电机峰值转矩$0.30\,\mathrm{N\,m}$、转子惯量$1.0\times10^{-5}\,\mathrm{kg\,m^2}$、最高转速$6000\,\mathrm{rev/min}$；减速器效率$0.75$。求转速允许的最大传动比、转矩（含反射惯量）允许的最小传动比，并说明窗口是否存在。（输入最大传动比，保留一位小数。）
::: solution
**转速：**$\omega_{m,\max} = 6000\times2\pi/60 = 628.3\,\mathrm{rad/s}$，故$N \le 62.8$。
**转矩：**要求$0.75\,N\times0.30 \ge 4 + (0.05 + N^2\times10^{-5})\times160$，即$0.225N \ge 12 + 0.0016N^2$。二次式$0.0016N^2 - 0.225N + 12 \le 0$的根为$N = [0.225 \pm \sqrt{0.0506 - 0.0768}]/0.0032$；判别式为负，所以**没有**传动比能满足要求：即使传动比最优，电机也供不出$12\,\mathrm{N\,m}$加自身反射惯量所需。最优传动比$N = 0.225/0.0032 = 70$（惯量匹配）也在转速上限之上。需要更大的电机——例如峰值$0.45\,\mathrm{N\,m}$给出$0.3375N \ge 12 + 0.0016N^2$，在$45.3 \le N \le 165.7$内成立，配上转速上限得窗口$45.3 \le N \le 62.8$；一台$50{:}1$的应变波单元即可胜任。
:::

::: exercise 为协作机械臂选择减速器 {level=3}
一台$7\,\mathrm{kg}$负载的七轴协作臂必须能拖动示教、能凭电机电流检测碰撞、碰撞时的有效质量要低、重复性达到±0.05 mm。讨论肩关节与腕关节的减速器类型与传动比选择，包括关节力矩传感器或双编码器的作用。
::: solution
好的回答是这样的：重复性与紧凑性主张所有关节都用应变波减速器（零回差、轻、中空），肩、肘用$100$–$160$左右，腕用$100$。但这样的传动比使关节难反驱，外力被减速器的摩擦（随温度与负载而变）掩盖，于是基于电流的碰撞检测与拖动示教变得粗糙；常见的补救是在减速器输出端加关节力矩传感器（弹性体上的应变片），或用减速器自身柔顺作传感器的双编码器变形测量（更便宜，但非线性、有迟滞）。碰撞时远端关节的有效质量由反射电机惯量$N^2J_m$主导；肩部用更低的$N$（摆线，或行星加应变波，在$\approx 50$）配更大的电机能降低它，但会加重重力方向的发热，可考虑弹簧重力补偿。$N \approx 8$的QDD设计透明性最好，但肩部重力力矩（$7\,\mathrm{kg}$负载在$\approx 0.8\,\mathrm m$臂展下为数百N·m）会需要很重的电机。回答应以一个站得住脚的分组收尾，例如全臂应变波加力矩传感器，并附上述理由。
:::
