选好了关节，机械臂还需要一副身体：把关节撑开的连杆、承受那些不该由减速器承受的载荷的轴承、容纳电机并把热导走的壳体，以及电缆穿过转动关节的通路。机械臂的连杆是一道不寻常的结构题。应力很低——一根比例合适的铝管里不过几兆帕——所以强度很少决定什么。决定设计的是**单位质量的刚度**：结构在负载下每弯一毫米，末端就多一毫米误差；结构每多一公斤，其后的关节就要多举起、多加速一公斤；而结构的最低固有频率封顶了伺服能调多快。本章为[[robot-arm-design/arm-specification]]的示例机械臂建立末端挠度预算——关节柔顺、连杆弯曲、轴承倾覆逐项相加——并指出哪一项主导（通常不是连杆）。然后是材料、管材、承受力矩载荷的轴承、走线和热效应。梁的挠度见[[mechanics-of-materials/beam-deflection]]，扭转见[[mechanics-of-materials/torsion]]，滚动轴承见[[machine-design/bearings]]，复合材料见[[solid-mechanics/composites]]；本章是应用它们。

## 为什么是刚度而不是强度 {#sec-stiffness-not-strength}

考虑示例机械臂的上臂：一根$400\,\mathrm{mm}$长的铝管，顶着肘部、前臂、腕部和负载。根部弯矩等于肩力矩，加速过程至多$137\,\mathrm{N\,m}$。外径$90\,\mathrm{mm}$、壁厚$3\,\mathrm{mm}$的管（$I = 7.77\times10^{-7}\,\mathrm{m^4}$）中弯曲应力为
$$
\sigma = \frac{Mc}{I} = \frac{137\times0.045}{7.77\times10^{-7}} = 7.9\,\mathrm{MPa},
$$
比6061-T6这类结构铝合金的屈服强度（约$240\text{–}275\,\mathrm{MPa}$）低约三十倍。这根管还可以薄得多才会断裂——而远在那之前它就已经太柔了。衡量一个结构对机械臂优劣的是两个数：

::: definition 比刚度与刚度预算 {#def-specific-stiffness}
材料的**比刚度**是$E/\rho$，弹性模量除以密度。对给定长度和截面形状的梁的弯曲，自重下的挠度按$\rho/E$定标，而给定刚度所需的质量对给定截面形状按$\rho/E$定标。机械臂的**刚度预算**是在规定载荷（通常是额定负载在最不利位姿下）下末端挠度各来源的清单：关节减速器、关节轴承、连杆的弯曲与扭转，以及壳体。
:::

| 材料（典型值） | $E$ (GPa) | $\rho$ (kg/m³) | $E/\rho$ (MN m/kg) | 线胀系数（$10^{-6}$/K） | 说明 |
|---|---|---|---|---|---|
| 结构钢 | 200 | 7850 | 25 | 12 | 刚、重、便宜；基座和大型铸件 |
| 铝合金（6061-T6、铸造A356-T6） | 69–72 | 2680–2700 | 26 | 21–24 | 连杆与壳体的默认选择；机加工或铸造 |
| 镁合金 | 45 | 1800 | 25 | 26 | 轻质铸件；需要防腐蚀 |
| 钛合金（Ti-6Al-4V） | 114 | 4430 | 26 | 9 | 昂贵；用于单位质量强度要紧的地方 |
| CFRP，准各向同性层合板 | 50–70 | 1550–1600 | 32–44 | ≈ 2–4 | 管材与板材；与金属接头胶接需要小心 |
| CFRP，单向沿纤维方向 | 120–140 | 1550–1600 | 75–90 | ≈ 0 | 管的弯曲刚度的上限 |

来源：手册值（如Callister与Rethwisch；Budynas与Nisbett）；复合材料性能强烈依赖纤维、铺层和纤维体积分数。引人注目的是前四行：**钢、铝、镁、钛的比刚度全都相同**，约$25\,\mathrm{MN\,m/kg}$。换材料改变的是给定刚度零件的尺寸，而不是它的质量。铝赢在连杆上，是因为同样质量下它的零件更粗——截面可以做得更大，这对屈曲和下面要谈的几何很重要——又因为它易于机加工和铸造。只有在比刚度上超过金属的是纤维复合材料，而且实用铺层下也只高约$1.5$倍。

## 管材：把材料放到离轴线远处 {#sec-tubes}

::: proposition 定质量薄壁管的弯曲刚度 {#prop-tube}
平均直径$D$、壁厚$t \ll D$的薄壁圆管的惯性矩为$I \approx \pi D^3t/8$，单位长度质量$m' = \rho\pi Dt$。在单位长度质量给定时，
$$
I = \frac{m'D^2}{8\rho},
$$ {#eq-tube-I}
所以弯曲刚度随直径的平方增长，管形连杆在给定载荷下的挠度按$1/D^2$下降。扭转常数$J \approx \pi D^3t/4 = m'D^2/(4\rho)$的表现相同。
:::

::: proof
对半径$R = D/2$、壁厚$t$的薄圆环，每个面积微元$\mathrm dA = tR\,\mathrm d\phi$到弯曲轴的距离都是$y = R\sin\phi$，所以$I = \int y^2\,\mathrm dA = tR^3\int_0^{2\pi}\sin^2\phi\,\mathrm d\phi = \pi tR^3 = \pi D^3t/8$。面积为$A = \pi Dt$，故$m' = \rho\pi Dt$且$t = m'/(\rho\pi D)$。代入得$I = \pi D^3/8\times m'/(\rho\pi D) = m'D^2/(8\rho)$。极惯性矩为$J = \int R^2\,\mathrm dA = 2\pi tR^3 = 2I$。对长度和载荷给定的梁，挠度正比于$1/(EI)$，于是正比于$1/D^2$。
:::

这个命题解释了为什么机械臂的连杆是大直径薄壁管或空心铸件，为什么协作机械臂相对其负载显得“粗”。限制来自几何和极薄壁的**局部屈曲**：$D/t$增大时，管壁会在远低于屈服应力下受压起皱，而且很难往它上面装任何东西。机加工铝连杆管常见的$D/t$约$15$到$40$；薄壁复合材料管更高，接头安装处做局部加强。中间的空腔不是白留的：它走电缆。

## 末端挠度预算 {#sec-budget}

静载荷下，机械臂每个柔顺元件都变形一点，小变形下这些效果**叠加**：末端挠度是各项贡献之和，每项都按其余部分刚性来计算。贡献分两类。

- 某处的**转动柔顺**（减速器扭转、轴承倾覆、连杆受弯端部转动）把它之外的一切转过一个小角$\theta$；末端移动$\theta$乘转动轴到末端的垂直距离。
- 连杆端部的**平移变形**把它之外的一切平移那个量。

于是一根受弯的连杆贡献两次：它的端部位移$\delta$，加上它的端部转角$\theta$乘端部到末端的距离。对长$L$、弯曲刚度$EI$、承受端向力$P$、端部力偶$M$和自重$w$（单位长度）的悬臂连杆（[[mechanics-of-materials/beam-deflection]]）：
$$
\delta = \frac{PL^3}{3EI} + \frac{ML^2}{2EI} + \frac{wL^4}{8EI},\qquad \theta = \frac{PL^2}{2EI} + \frac{ML}{EI} + \frac{wL^3}{6EI}.
$$ {#eq-cantilever}

::: example 示例机械臂的末端挠度预算 {#ex-budget}
用[[robot-arm-design/arm-specification]]的质量表和下列数据，建立水平伸展位姿下示例机械臂带$5\,\mathrm{kg}$负载时的竖直末端挠度预算：
- 上臂：铝管（$E = 69\,\mathrm{GPa}$），$L = 0.40\,\mathrm m$，$D = 90\,\mathrm{mm}$，$t = 3.0\,\mathrm{mm}$，其$4.0\,\mathrm{kg}$按均布处理；端部顶着肘部执行器、前臂、腕和负载（$12.5\,\mathrm{kg}$，端向力$P = 122.6\,\mathrm N$）以及肘部之外各件的力偶（$M = 38.3\,\mathrm{N\,m}$）；
- 前臂：铝管$L = 0.35\,\mathrm m$，$D = 75\,\mathrm{mm}$，$t = 2.5\,\mathrm{mm}$，$2.0\,\mathrm{kg}$均布；端部顶着腕和负载（$P = 78.5\,\mathrm N$）以及负载对腕心的力偶（$M = 7.4\,\mathrm{N\,m}$）；
- 关节2：[[robot-arm-design/gear-reducers]]中的应变波减速器（$95.2\,\mathrm{N\,m}$下扭转$1.39\,\mathrm{mrad}$）；
- 关节3：较小的减速器，在其载荷$38.3\,\mathrm{N\,m}$下的有效刚度为$3.0\times10^4\,\mathrm{N\,m/rad}$；
- 关节5：$1.0\times10^4\,\mathrm{N\,m/rad}$，受力$7.9\,\mathrm{N\,m}$；
- 关节1轴承：交叉滚子轴承，抗倾刚度$1.0\times10^6\,\mathrm{N\,m/rad}$，倾覆力矩$110\,\mathrm{N\,m}$。

到末端（负载质心）的距离：关节1和2处$0.90\,\mathrm m$，肘部$0.50\,\mathrm m$，腕心（关节5）$0.15\,\mathrm m$。（关节3、关节5和轴承的刚度值是示意性的。）
::: solution
**截面。**上臂$I = \tfrac{\pi}{64}(90^4 - 84^4)\,\mathrm{mm^4} = 7.77\times10^{-7}\,\mathrm{m^4}$，$EI = 5.36\times10^4\,\mathrm{N\,m^2}$；前臂$I = \tfrac{\pi}{64}(75^4 - 70^4) = 3.75\times10^{-7}\,\mathrm{m^4}$，$EI = 2.58\times10^4\,\mathrm{N\,m^2}$。

**上臂**由[[#eq-cantilever]]取$w = 98.1\,\mathrm{N/m}$：$\delta = 0.112\,\mathrm{mm}$，$\theta = 0.488\,\mathrm{mrad}$；对末端的贡献$0.112 + 0.488\times0.50 = 0.356\,\mathrm{mm}$。

**前臂**取$w = 56.1\,\mathrm{N/m}$：$\delta = 0.065\,\mathrm{mm}$，$\theta = 0.301\,\mathrm{mrad}$；对末端的贡献$0.065 + 0.301\times0.15 = 0.110\,\mathrm{mm}$。

**关节与轴承。**关节2：$1.39\times0.90 = 1.247\,\mathrm{mm}$；关节3：$(38.3/3.0\times10^4)\times0.50 = 0.638\,\mathrm{mm}$；关节5：$(7.9/1.0\times10^4)\times0.15 = 0.119\,\mathrm{mm}$；关节1轴承：$(110/10^6)\times0.90 = 0.099\,\mathrm{mm}$。

| 贡献 | 末端挠度（mm） | 占比 |
|---|---|---|
| 关节2减速器 | 1.247 | 49 % |
| 关节3减速器 | 0.638 | 25 % |
| 上臂弯曲 | 0.356 | 14 % |
| 关节5减速器 | 0.119 | 5 % |
| 前臂弯曲 | 0.110 | 4 % |
| 关节1轴承倾覆 | 0.099 | 4 % |
| **合计** | **2.57** | |

**解读。**下垂的四分之三来自关节2和3的减速器；连杆的贡献不到五分之一。把连杆做刚几乎没用；更管用的是刚度更大的肩部减速器（大一号）、能测出扭转的输出编码器，或控制器里的柔顺模型。这一垂量对给定负载是重复的，所以它费的是精度而不是重复性——但抓起负载时它会变化约半毫米，这就是柔顺模型是[[robot-arm-design/calibration]]一部分的原因。

**合理性检验。**满负载满臂展下两三毫米量级的下垂，对带应变波关节的轻质机械臂是可信的，也正是标定中要建模关节柔顺的原因；同样臂展、用更大摆线减速器和铸件的刚性工业机械臂，下垂要小好几倍。
:::
:::

预算也显出动力学的一面。每个柔顺元件都是惯性与惯性之间的弹簧，最软的弹簧定下最低的固有频率。关节2的减速器在[[robot-arm-design/gear-reducers]]中给出约$17\,\mathrm{Hz}$的模态；上臂本身作为顶端带远端$12.5\,\mathrm{kg}$的悬臂梁，弯曲刚度$3EI/L^3 = 2.5\times10^6\,\mathrm{N/m}$，一阶模态约$\frac{1}{2\pi}\sqrt{2.5\times10^6/(12.5 + 0.24\times4.0)} = 69\,\mathrm{Hz}$（$0.24$是均质悬臂梁自重惯用的等效质量因子）。目标是结构模态远高于关节模态：这样调在关节模态以下的关节伺服就永远不会激励结构。

::: warning 别忘了壳体和零件之间的接头
用连杆管和减速器目录刚度搭出的预算，预测的挠度常常明显小于真实机械臂上测到的。漏掉的柔顺在中间的零件上：管与壳体相连的螺栓法兰（薄法兰会弯；相对管径过小的螺栓圆会把载荷集中起来）、减速器在壳体上的安装、会变形的薄电机壳体，以及关节的输出轴承。用有限元给壳体建模（[[finite-element-method]]），让传力路径短而直接，法兰做厚、螺栓圆做大，然后测量装配好的机械臂：在法兰上挂已知重物，用百分表或激光跟踪仪读挠度，再逐关节锁定，与预算逐项对照。
:::

## 关节轴承与力矩载荷 {#sec-bearings}

每个关节都必须承受其外连杆的全部载荷系：轴向力、径向力、绕关节轴的转矩（由减速器承受），以及**绕垂直于关节轴的轴的力矩**——倾覆力矩。轴线竖直的基座关节里，伸直的机械臂的整个重量造成一个与肩力矩同量级的倾覆力矩。这个力矩必须进轴承，不能进减速器——减速器的齿和柔轮只能容忍很小的不对中。

::: proposition 力矩载荷下轴承的支反力 {#prop-bearing-pair}
载荷中心相距$a$的两个轴承支撑的轴，在其中部受径向力$F$、受绕垂直于轴线之轴的力偶$M$。轴承的径向支反力为
$$
R_{1,2} = \frac F2 \pm \frac Ma .
$$ {#eq-bearing-pair}
:::

::: proof
轴的受力图：中点处的外力$F$、外力偶$M$，以及在中点两侧各$a/2$处的轴承支反力$R_1$和$R_2$（以与$F$相反的方向为正）。力平衡：$R_1 + R_2 = F$。对中点取矩：$(R_1 - R_2)\,a/2 = M$。解得$R_1 = F/2 + M/a$，$R_2 = F/2 - M/a$。
:::

[[#eq-bearing-pair]]的教益是支反力按$1/a$增长：由靠得很近的两个轴承承担的力矩会产生极大的轴承力。取$F = 200\,\mathrm N$、$M = 60\,\mathrm{N\,m}$、$a = 50\,\mathrm{mm}$，支反力为$1300\,\mathrm N$和$-1100\,\mathrm N$（第二个轴承被拉向另一侧）：主导的是力矩而不是重量。长的关节可以把轴承分开得远些；紧凑的机器人关节不能，这就是关节使用在单个短小单元内承受力矩载荷的轴承的原因：

- **交叉滚子轴承**：一行圆柱滚子夹在V形沟道圈之间，相邻滚子互成$90°$交叉，使每个轴向方向都有一半滚子受力。一个薄轴承同时承受径向、轴向和力矩载荷，且抗倾刚度高。它是多数应变波单元的整体输出轴承，也是紧凑机械臂关节的常用轴承。
- **成对安装的角接触球轴承或圆锥滚子轴承**，**背对背**（O形布置）安装：接触线向外发散，于是载荷中心之间的有效跨距大于轴承的实际间距，提高了力矩承载能力和抗倾刚度。两级摆线减速器就用这样的轴承对作输出轴承。
- **四点接触球轴承**：单列，能承受双向轴向力和中等力矩；常作基座中的回转支承。

轴承要**预紧**——轴向压紧，使任何滚动体都从不卸载——因为关节轴承里的游隙是输出编码器看得见、控制器却去不掉的回差，而且预紧提高刚度。预紧的代价是摩擦，摩擦牺牲反向可驱动性和热；取舍是关节设计的一部分。在工作循环下的额定寿命和最不利力矩（含急停和碰撞）下的静安全因数，按[[machine-design/bearings]]校核。

::: example 交叉滚子轴承与轴承对的选择 {#ex-bearing}
示例机械臂的基座关节必须承受至多$250\,\mathrm{N\,m}$的倾覆力矩（重力加加速和一次急停）和$300\,\mathrm N$的径向力。关节壳体允许的轴向长度为$60\,\mathrm{mm}$。(a) 用轴线相距$45\,\mathrm{mm}$的两个深沟球轴承，径向支反力是多少？(b) 一个外径相同的交叉滚子轴承的目录力矩额定值为$400\,\mathrm{N\,m}$（示意值）。你选哪个？
::: solution
(a) 由[[#eq-bearing-pair]]，$R_{1,2} = 300/2 \pm 250/0.045 = 150 \pm 5556\,\mathrm N$：$5706\,\mathrm N$和$-5406\,\mathrm N$。仅仅因为力矩，每个轴承就要承受近$6\,\mathrm{kN}$的径向载荷——是外加径向力的十九倍。能装进$60\,\mathrm{mm}$壳体、直径合空心关节的深沟球轴承在静载下也许撑得住，但带内部游隙时它们在这种载荷下的抗倾刚度会很差，力矩常来时寿命也短。

(b) 交叉滚子轴承在一列内承受这个力矩，力矩额定值为最不利情形的$1.6$倍、抗倾刚度高，轴向长度也许只用三分之一，给制动器和编码器留下空间。它是自然的选择；剩下的校核是工作循环下的额定寿命（用目录的当量载荷法）和选定预紧下的摩擦力矩。
:::
:::

## 连杆的材料与制造 {#sec-materials}

三种构造占主导（截至2026年）：

- **机加工铝**管与壳体，用于小批量和原型：精确、快、易改，但单件贵、形状受限。
- **铸造铝**（砂型、金属型或高压压铸）或**铸造镁**：带筋、凸台和线缆通道的复杂空心形状一个零件搞定，量大便宜，轴承座和法兰经机加工后精度够用。多数量产的工业与协作机械臂用铸件。铸铁和钢用于基座和重型机器人的大臂——基座处的质量无害，阻尼还受欢迎。
- **碳纤维增强聚合物**（CFRP）管与金属端接件胶接：实用铺层下比刚度最高约为铝的$1.5$倍，沿管的线胀系数近乎为零。难处在接头（胶接或胶接加销的金属接头，柔顺可能由它主导）、损伤容限（一次磕碰可能造成隐形的分层）、成本，以及电学行为（CFRP导电，胶接与接地必须设计）。CFRP划算的地方是连杆弯曲占预算大头的高细长连杆，以及每千克都金贵的机械臂。

增材制造（铝或钛的激光粉末床熔融，以及用于轻臂的纤维增强聚合物打印）用于支架、原型和一体化线缆通道，在小批量生产件中也用得越来越多。

## 电缆穿过转动关节的走线 {#sec-cables}

每个关节都要把功率和信号传给其外的关节。线缆束是机械臂现场故障的常见原因：弯得太紧、扭得太多、被棱边磨损、或在关节处被强行挤过一点的电缆，会在数百万次循环后疲劳失效。方法有四种。

1. **穿过空心轴**：线缆束沿关节轴穿过空心的电机、减速器和轴承。关节转动时，线缆束绕自身轴线**扭转**而不是弯曲——这是电缆能承受的最柔和载荷。耐扭转的机器人电缆以单位自由长度允许的扭转角规定（数据表常给$\pm180°$到$\pm360°$每米这类数字）；束在卡夹之间要有足够的自由长度，以摊开关节的转角范围。
2. **外部走线，盘成服务环或用管线包**：关节外的一段电缆环随关节弯曲，由弹簧回线器或电缆拖链导向。检修更简单，工业机械臂上工具的过程电缆常用，但体积大且易挂绊。
3. **滑环**：在无限转动的关节上靠滑动触点传递功率和信号——当某关节必须连续转动时少不了它（某些基座关节、工具法兰、拧螺丝或抛光时的腕滚转）。滑环引入接触电阻和电噪声、会磨损、需维护，除非数据用非接触（感应式或光学）传输，否则限制可靠通过的数据速率。多数关节靠把转角限制在约$\pm1$到$\pm2$圈来避开滑环。
4. **减少导线数目**：最有效的措施。驱动器装在控制柜里时，每个轴都要有电机相线、保护接地、抱闸线和编码器电缆穿过其后的所有关节；驱动器装进每个关节（一体化关节模块）后，整条臂只需一条直流母线和一条现场总线穿过。

::: example 数一数穿过肩部的导线 {#ex-cables}
数一数六轴机械臂穿过肩部（关节2）的导线数目：(a) 中央驱动器：每轴三根电机相线、一根保护接地、两根抱闸线和四根编码器线（电源与串行数据），外加十二根工具I/O线；(b) 一体化关节驱动器：两根$48\,\mathrm V$母线线、保护接地、一根四线EtherCAT链路、安全通道四根线，以及同样的十二根工具线。
::: solution
(a) 肩部之外有关节3到6：$4\times(3 + 1 + 2 + 4) = 40$根，再加$12$根工具线：$52$根导线，分好几根电缆，其中还有粗的电力电缆。
(b) $2 + 1 + 4 + 4 + 12 = 23$，而且只有母线两根导线通过大电流；线缆束的截面约为(a)的三分之一，且不随关节数增长。

一体化设计正是协作机械臂能把一切穿过口径不大的空心关节的原因。代价是每个关节里都有电子器件——密封壳体内的热，以及暴露在机械臂振动中的驱动器——还有必须同时承载所有关节峰值电流的母线（$48\,\mathrm V$下的$6\times20\,\mathrm A$，最坏情形$120\,\mathrm A$，母线导线按它选）。
:::
:::

## 热效应 {#sec-thermal}

热从关节电机（[[robot-arm-design/joint-actuators]]中每个大关节$20\text{–}30\,\mathrm W$）、一体化关节里的驱动器、减速器摩擦和环境进入结构。要紧的有两个效应。

**热膨胀**改变连杆长度。长$L$、线胀系数$\alpha$的连杆升温$\Delta T$后伸长$\alpha L\Delta T$：对铝（$\alpha = 23.6\times10^{-6}\,\mathrm{K^{-1}}$），$10\,\mathrm K$作用在$0.75\,\mathrm m$上给出$0.18\,\mathrm{mm}$，是一台好机械臂重复性的好几倍。这一效应给定温度下可重复，但在需要几十分钟到一小时的预热过程中漂移。补救办法是先预热再干精度活（热机状态下标定，[[robot-arm-design/calibration]]）、测温度并在运动学模型中补偿，或者——对要求最苛刻的场合——用CFRP连杆（沿管的$\alpha$近于零：同样情形下只有$0.0075\,\mathrm{mm}$）。

::: example 示例机械臂的预热漂移 {#ex-thermal}
生产一小时后，示例机械臂的上臂比标定时的温度高了$10\,\mathrm K$，前臂高了$6\,\mathrm K$。两者都是铝（$\alpha = 23.6\times10^{-6}\,\mathrm{K^{-1}}$）。臂水平伸直时腕心向外移动多少？换成CFRP管（沿管$\alpha \approx 1\times10^{-6}\,\mathrm{K^{-1}}$）是多少？与±0.05 mm的重复性相比各如何？
::: solution
铝：$\Delta r = \alpha(L_2\Delta T_2 + L_3\Delta T_3) = 23.6\times10^{-6}(0.40\times10 + 0.35\times6) = 23.6\times10^{-6}\times6.1 = 1.44\times10^{-4}\,\mathrm m = 0.144\,\mathrm{mm}$，几乎是重复性的三倍。CFRP管：$1\times10^{-6}\times6.1 = 6.1\,\mathrm{\mu m}$，可以忽略——尽管两端的铝合金关节壳体和接头仍会伸长，真实CFRP机械臂的收获比这个数字小。

臂伸直时漂移是径向的；其他位姿下它朝别的方向移动工具，所以不能用一个固定偏置除掉。测连杆温度并在运动学模型里缩放连杆长度，或在精度作业前跑一个预热循环，是惯用的治法。

**合理性检验。**$0.14\,\mathrm{mm}$约为臂展的$5000$分之一，与$\alpha\Delta T \approx 2\times10^{-4}$一致。
:::
:::

**结构就是散热体。**密封壳体内的关节电机要排出损耗，除了经壳体与连杆的导热、再经机械臂表面的自然对流与辐射，别无去处；[[robot-arm-design/joint-actuators]]中限制连续力矩的热阻$R_{th}$主要就是这条路径的热阻。好的热设计让定子与厚铝壳紧密贴合，别在发热关节上盖塑料罩，并把协作机械臂可触碰表面的温度控制在安全范围内。复合材料连杆隔热而不导热，所以CFRP机械臂要靠关节壳体自己散热。

::: quiz
一台铝机械臂冷机测试时重复到±0.02 mm，但每班前40分钟放置的零件漂移约0.1 mm。最可能的原因和最便宜的补救是什么？
- [ ] 编码器分辨率；换更高分辨率的编码器
- [ ] 减速器回差；换预紧减速器
- [x] 关节升温带动连杆热伸长；生产前先跑预热循环
- [ ] 连杆在负载下弯曲；换更粗的管
::: solution
开机后几十分钟出现、然后停下的漂移是热性的：关节电机加热壳体和连杆，使它们伸长$\alpha L\Delta T$——$0.1\,\mathrm{mm}$约相当于$0.75\,\mathrm m$铝升温$6\,\mathrm K$。编码器分辨率和回差不随时间变化；负载弯曲不漂移。预热程序（或温度补偿）是最便宜的补救。
:::
:::

::: history
早期的工业机器人，如1961年的液压Unimate，用沉重的铸钢和焊接钢结构，刚度来自质量。1970年代到1980年代转向电力驱动，以ASEA的IRB 6和PUMA这类机械臂为首，带来了铸铝连杆和追求低质量的开端。轻量机器人作为一个研究计划在德国航空航天中心（DLR）成形，其1990年代到2000年代为航天应用建造的LightWeight Robot系列机械臂，结合了薄壁连杆、一体化关节电子器件、空心轴走线和关节力矩传感；第三代达到了质量与负载之比约为一的水平，其设计转移到了工业界，成为商品化的轻量臂。碳纤维连杆从1990年代起出现在高速并联机器人和研究臂上，其比刚度和低热膨胀足以抵消成本。
:::

## 后续内容 {#sec-leads}

结构定下了关节承载的质量——把它们送回[[robot-arm-design/arm-specification]]的选型计算——也定下了关节控制器必须与之共处的柔顺和固有频率，这正是[[robot-arm-design/joint-control]]的起点。

::: summary
- 机械臂连杆为比刚度而设计，不为强度：应力通常是几MPa。
- 钢、铝、镁、钛的$E/\rho \approx 25\,\mathrm{MN\,m/kg}$都一样；只有纤维复合材料更好，实用铺层下高约1.5倍。铝赢在截面尺寸、机加工和铸造。
- 定质量下薄管的$I = m'D^2/(8\rho)$：让连杆大直径、薄壁，以局部屈曲和可安装为限。
- 用叠加法搭末端挠度预算：连杆端部位移加端转角乘到末端的距离，关节扭转乘距离，轴承倾覆乘距离。轻质机械臂里通常是减速器主导。
- 力矩载荷需要交叉滚子轴承或预紧的背对背轴承对；相距$a$的两轴承的支反力是$F/2 \pm M/a$。
- 电缆穿空心轴（扭而不弯），工具电缆留服务环，滑环只用于连续转动，用一体化驱动器和现场总线减少导线数目。
- 热伸长（$\alpha L\Delta T$）造成预热漂移；结构就是电机的散热体。
:::

## 习题

::: exercise 连杆的弯曲应力 {level=1 check="31.7"}
一根直径$30\,\mathrm{mm}$的实心铝棒用作连杆，根部弯矩$84\,\mathrm{N\,m}$。求最大弯曲应力。（输入的应力以MPa为单位，保留一位小数。）
::: solution
$\sigma = Mc/I = 32M/(\pi d^3) = 32\times84/(\pi\times2.7\times10^{-5}) = 31.7\,\mathrm{MPa}$。同质量、直径$60\,\mathrm{mm}$的管挠度约为其四分之一，应力也低得多；两者都离屈服很远。
:::
:::

::: exercise 热伸长 {level=1 check="0.142"}
一根长$0.40\,\mathrm m$的铝前臂（$\alpha = 23.6\times10^{-6}\,\mathrm{K^{-1}}$）升温$15\,\mathrm K$。它伸长多少？（输入伸长量以mm为单位，保留三位小数。）
::: solution
$\Delta L = \alpha L\Delta T = 23.6\times10^{-6}\times0.40\times15 = 1.416\times10^{-4}\,\mathrm m = 0.142\,\mathrm{mm}$。
:::
:::

::: exercise 轴承支反力 {level=1 check="2050"}
一个关节轴的两个轴承载荷中心相距$40\,\mathrm{mm}$。轴在中部受径向载荷$100\,\mathrm N$和倾覆力矩$80\,\mathrm{N\,m}$。求较大的那个轴承支反力。（输入以N为单位。）
::: solution
$R = F/2 + M/a = 50 + 80/0.040 = 50 + 2000 = 2050\,\mathrm N$；另一个是$-1950\,\mathrm N$。跨距加倍则力矩引起的部分减半。
:::
:::

::: exercise 定质量下的管刚度 {level=2 check="1.778"}
一根直径$60\,\mathrm{mm}$的铝连杆管换成直径$80\,\mathrm{mm}$、单位长度质量相同的管（薄壁近似）。弯曲刚度增大为几倍？（输入倍数，保留三位小数。）
::: solution
由[[#eq-tube-I]]，$m'$给定时$I \propto D^2$：倍数$(80/60)^2 = 1.778$。壁厚按$60/80 = 0.75$变薄。
:::
:::

::: exercise 关节对末端挠度的贡献 {level=2 check="78"}
一个扭转刚度$1.5\times10^4\,\mathrm{N\,m/rad}$的腕关节承受重力力矩$6.5\,\mathrm{N\,m}$，工具中心点离其轴$0.18\,\mathrm m$。关节的扭转对末端挠度贡献多少？（输入的挠度以µm为单位，取整µm。）
::: solution
$\theta = 6.5/1.5\times10^4 = 4.33\times10^{-4}\,\mathrm{rad}$；对末端的贡献$0.18\times4.33\times10^{-4} = 7.8\times10^{-5}\,\mathrm m = 78\,\mathrm{\mu m}$——仅一个腕关节就超过多数机械臂的重复性。
:::
:::

::: exercise CFRP上臂 {level=2 check="0.273"}
用尺寸相同、轴向模量$90\,\mathrm{GPa}$的CFRP管重做[[#ex-budget]]的上臂贡献，载荷保持不变。（输入其对末端的贡献，以mm为单位，保留三位小数。）值得吗？
::: solution
所有弯曲项按$1/E$定标：$0.356\times69/90 = 0.273\,\mathrm{mm}$。管的质量从$0.89$降到$0.52\,\mathrm{kg}$（$\rho = 1600\,\mathrm{kg/m^3}$）。总预算只从$2.57$降到$2.49\,\mathrm{mm}$，因为连杆弯曲占比很小；CFRP管的回报在省下的质量（以及减小的热伸长），不在挠度。
:::
:::

::: exercise 穿空心轴的电缆 {level=2}
某关节转角范围为$\pm270°$，其线缆束的额定值为单位自由长度$\pm180°$扭转。束在关节两侧的卡夹之间需要多长自由长度？卡夹装得更近会怎样？若空间不够，还有什么办法满足转角范围？
::: solution
束要在每个方向承受$270°$扭转，所以需要$270/180 = 1.5\,\mathrm m$自由长度——通常远超单个关节装得下的长度。卡夹装得更近会使扭转集中，抬高导体和绝缘层的剪应变，急剧缩短其疲劳寿命。补救：把关节范围降到任务所需（例如$\pm180°$只需$1.0\,\mathrm m$）；把束绕成涡卷形或发条状（在外壳内卷绕的扁电缆，如同汽车转向柱里的），让转动展开一个涡卷而不是扭一直束；用旋转导线导向件把转动变成排线的弯曲；低电流信号则用滑环。
:::
:::

::: exercise 带端部力偶的连杆挠度 {level=3 check="0.200"}
由弯曲方程$EIv'' = M(x)$推导端部受力偶$M$的悬臂梁的端转角$\theta = ML/(EI)$和端位移$\delta = ML^2/(2EI)$。然后在[[#ex-budget]]中只求$M = 38.3\,\mathrm{N\,m}$单独产生的上臂各项及其合并的末端贡献$\delta + 0.5\,\theta$。（输入的末端贡献以mm为单位，保留三位小数。）
::: solution
端部受力偶时弯矩处处为$M$，于是$EIv'' = M$，$EIv' = Mx$（$v'(0) = 0$），$EIv = Mx^2/2$（$v(0) = 0$）。在$x = L$处：$\theta = ML/(EI)$，$\delta = ML^2/(2EI)$。取$EI = 69\times10^9\times7.767\times10^{-7} = 5.359\times10^4\,\mathrm{N\,m^2}$：$\theta = 38.3\times0.40/5.359\times10^4 = 2.859\times10^{-4}\,\mathrm{rad}$，$\delta = 38.3\times0.16/(2\times5.359\times10^4) = 5.72\times10^{-5}\,\mathrm m$。末端贡献$0.0572 + 0.5\times0.2859 = 0.200\,\mathrm{mm}$——超过上臂总量$0.356\,\mathrm{mm}$的一半：弯曲主要是远端各件的力偶做的，而不是它们作为力的重量。
:::
:::

::: exercise 把末端挠度减半 {level=3}
示例机械臂$2.57\,\mathrm{mm}$的预算必须为新产品减半。用[[#ex-budget]]的预算提出并评估改动，给出质量与金钱上的代价。单项改动哪个收益最大？只改连杆的任何组合够不够？
::: solution
一份好的答案从占比入手：连杆合计$0.47\,\mathrm{mm}$，所以即使连杆绝对刚性也还剩$2.1\,\mathrm{mm}$——只改连杆不可能把预算减半。关节2的减速器（$1.25\,\mathrm{mm}$）是最大项：大一号通常使刚度翻倍左右（$-0.6\,\mathrm{mm}$），代价是肩部多$1\text{–}1.5\,\mathrm{kg}$（对关节2自己的载荷无害，但关节1和基座要多承载）。关节3的减速器（$0.64\,\mathrm{mm}$）同理；那里换更刚的会加上关节2必须承载的质量（所以要迭代选型）。另一条路是硬件不动而做补偿：给关节2和3装输出编码器直接测扭转，把它们的贡献从**位置**误差里除掉（控制器驱的是输出端的目标），花两只编码器的代价解决$1.9\,\mathrm{mm}$；或控制器里放柔顺模型，最便宜但只和模型一样准（非线性、有滞环）。一份可辩护的方案：关节2和3的输出编码器加上刚度$1.5\times$的关节3壳体，未补偿的结构挠度约为$0.36 + 0.11 + 0.12 + 0.10 = 0.7\,\mathrm{mm}$。
:::
