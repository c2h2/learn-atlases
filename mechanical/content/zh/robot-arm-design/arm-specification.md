机械臂的起点是客户的一句话：“从输送机上取4 kg的铸件，放到700 mm外的夹具里，每6秒一次，精度到十分之一毫米。”在任何人选电机之前，这句话必须先变成技术规格——多少个关节、什么构型、多大的臂展、负载、速度和重复性——而技术规格又必须变成对每一个关节的要求：它必须给出的峰值与连续力矩、必须达到的速度，以及在末端允许引入的角误差。本章两件事都做：概述在用的运动构型及各自的适用场合，按数据表和ISO 9283的方式定义臂展、负载、速度、重复性与精度，然后按静力重力力矩预算、动力学力矩预算、热（rms）校核和末端误差预算，为一台现实的六轴机械臂（5 kg负载、850 mm臂展）做关节选型计算。构型背后的运动学见[[robotics/forward-kinematics]]和[[robotics/inverse-kinematics]]，关节力矩与末端力的关系见[[robotics/jacobians]]，运动方程见[[robotics/manipulator-dynamics]]；本章把它们当作工具使用。

## 从任务到技术规格 {#sec-task}

一份好的技术规格列出驱动设计的各个量，以及每个量成立的条件。对机械设计最要紧的是：

- **负载**：机械臂法兰处所承载的质量，**包括**夹爪或工具在内，以及其质心相对法兰的位置。
- **臂展与工作空间**：工具中心点（TCP）必须到达的区域，以及以哪些姿态到达。
- **速度与节拍时间**：关节速度、TCP速度，以及一次参考运动所需的时间。
- **重复性与精度**：机械臂回到示教位姿的接近程度，以及到达由模型算出的位姿的接近程度。
- **环境与工况**：工作周期、环境温度、洁净度或冲洗要求，以及机械臂是否与人一同作业（这会给速度和力设置上限，见[[robot-arm-design/arm-safety]]）。

前四项相互作用。负载不变而臂展加倍，肩部的重力力矩大约加倍，**而且**该关节给定的角度误差在末端产生的误差也加倍；更快的节拍抬高加速力矩和每台电机的发热。因此技术规格是一组权衡，而下面这些计算的目的，就是在每一项定死之前先把它计价。

## 自由度与运动构型 {#sec-layouts}

::: definition 机械臂的自由度 {#def-dof}
串联机械臂的**自由度**（DoF）是独立驱动关节的数目，通常等于电机的数目。空间中的刚体有六个自由度（三个位置、三个姿态），所以机械臂要在工作空间内的任意位置**且**以任意姿态放置它的工具，就需要**六**个关节。不足六关节的机械臂只能到达位姿的一个子集；超过六关节的则是**冗余的**：给定的工具位姿可由连续统般的关节构型到达（即[[robotics/jacobians]]中的自运动，或零空间）。
:::

少几个关节并不只是更差：每去掉一个关节，就少一台电机、一个减速器、一个编码器、一个制动器、一段过线回路，而剩下的关节更刚、更便宜。诀窍在于不多不少，恰好给任务所需的自由度。

| 构型 | 自由度 | 工具的自由度 | 典型用途 | 说明 |
|---|---|---|---|---|
| SCARA | 4 | $x$、$y$、$z$、绕竖直轴转动 | 装配、台面上的拾放作业 | 两根平行的竖直转动轴，加一根竖直的螺槽轴；重力由轴承承受，因此极快 |
| 铰接式码垛机 | 4（有时5） | $x$、$y$、$z$、绕竖直轴转动 | 纸箱与袋装物码垛 | 平行四边形机构使法兰保持水平，因而无需腕俯仰关节 |
| 五轴铰接式 | 5 | 位置＋两个转动 | 用轴对称焊枪焊接、点胶、简单机床上下料 | 工具绕自身轴线的滚转不受控——若工具轴对称则无碍 |
| 六轴铰接式、球形腕 | 6 | 完整位姿 | 通用工业作业 | 三个腕轴交于一点：有封闭形式的逆运动学解（皮珀） |
| 六轴偏置腕 | 6 | 完整位姿 | 许多协作机械臂 | 肩、肘与腕1轴相互平行；仍有封闭形式解，避开了工作空间正中的腕奇异位形，但存在其他奇异位形 |
| 七轴 | 7 | 完整位姿＋一个自运动 | 协作与研究用臂、绕开障碍作业 | 工具位姿不变时肘部可摆动；能规避奇异位形和关节限位，但成本更高、逆运动学更难 |

带球形腕的**六轴铰接机械臂**是基准设计。关节1（基座或腰部）绕竖直轴转动；关节2（肩）与关节3（肘）是两根平行的水平轴，用来定位腕心；关节4、5、6（腕滚转、俯仰、滚转）确定工具姿态。这种解耦使机械臂容易分析：前三个关节在长力臂上承载，需要很大力矩；腕关节力臂短，需要高速度和小力矩。这一分工是关节选型计算的第一个事实。

**SCARA（选择顺应性装配机器人臂）**把它的两根大转动轴竖直放置。重力便沿轴线作用而由轴承承受，不由电机承受，于是关节力矩纯属惯性力矩；机械臂在竖直方向上刚、在水平方向上柔——这便于把销钉推入孔中——短程运动的节拍远低于一秒是家常便饭。它的工作空间是水平面内的一个圆环乘以竖直轴的行程，而且不能使工具倾斜。

**七轴**机械臂在研究中是常态、在协作产品中也常见，因为冗余关节能在工具保持不动的同时把肘部移离人员、夹具和关节限位，而且有了七个关节，任务中途遇到的奇异构型通常总能避开。代价是运动链最重的部位多一个执行器，以及控制器中多一个冗余解析问题。

## 工作空间与臂展 {#sec-workspace}

::: definition 臂展与工作空间 {#def-reach}
**可达工作空间**是机械臂至少能以一种姿态到达的TCP位置之集；**灵巧工作空间**是其中以一切姿态都可到达的子集。数据表上标的**臂展**是机械臂完全伸展时，从基座轴（关节1）到手腕处某一参考点的最大水平距离——通常是腕心或法兰，数据表会写明是哪一个。
:::

由定义可引出三条实务要点。

1. **看清臂展量到哪个点。**工具自带长度。一台臂展850 mm量到法兰的机械臂装了150 mm长的夹爪，指尖就能伸到至多1000 mm——但仅限朝外指的时候；朝下指时它对水平臂展毫无贡献，反而从高度里扣掉一截。
2. **不要打算在满臂展下作业。**完全伸展时肩与肘共线，是奇异构型（[[robotics/jacobians]]）：机械臂无法沿径向移动TCP，实现给定TCP速度所需的关节速度无界增长，重力力矩也达到最大。一条有用的规则是把工作区域保持在臂展的约80–90 %以内。
3. **灵巧工作空间比可达工作空间小得多。**在近边界和近基座处，工具只能取有限的几种姿态。需要工具在一切方向上倾斜±45°的任务，必须整个放进灵巧区域，而这要靠厂商的仿真软件或一次快速的逆运动学扫描才能看出来。

对于上臂长$a_2$、前臂长$a_3$（肩到肘、肘到腕心）的铰接臂，腕心可到达以肩为中心、内外半径为$\lvert a_2 - a_3\rvert$与$a_2 + a_3$的球壳，再被关节限位和机械臂自己的基座切掉一块。$a_2$与$a_3$接近相等时腕能靠近肩部；前臂短则工作空间正中留一个大洞。

## 负载、速度与节拍时间 {#sec-payload-speed}

额定**负载**是机械臂满速满加速度下能携带的最大质量，**且质心位于相对法兰的某个规定位置**。数据表会附上**负载图**：允许的质量随质心距法兰的距离（沿工具轴线方向和侧向）变化，以及绕腕轴允许的惯性矩。这些限制来自腕关节：关节5承受负载重量乘以其质心到关节5轴的偏距，关节4和6承受负载绕各自轴的惯性矩。一台5 kg的机械臂往往只能在法兰外约50–100 mm以内带满它的5 kg，装在长工具上就要小得多。

速度有两种规定方式。**关节速度**以度每秒计，等于电机最高转速除以传动比；小型工业机械臂（截至2026年）的典型值是基座轴180–360°/s、腕部400–1000°/s。**TCP速度**由关节速度和雅可比矩阵导出；在距转轴$r$处、轴以$\dot q$转动时，它为$r\dot q$。协作机械臂的设计速度通常更慢，且有人在场时被限制在风险评估中商定的TCP速度（常为每秒几百毫米到约1 m/s）。

这两个数都不说明一次真实运动要花多长时间，因为短运动从不到达最高速度：它们由加速和整定时间主导。这就是许多厂商按一条参考拾放路径给出**节拍时间**的原因，例如常用的“抬25 mm——横移300 mm——降25 mm”再返回。对选型计算，有用的量是关节加速度，它直接转化为力矩。

## 重复性与精度 {#sec-repeatability}

这两个词在口头中常混用，在数据表上则从不混用。

::: definition 位姿重复性与精度（ISO 9283）{#def-repeatability}
命令机械臂$n$次（ISO 9283取$n = 30$）以同样的接近方式到达同一位姿，测得到达位置$\mathbf x_j$。设$\bar{\mathbf x}$为其均值（形心），$l_j = \lVert \mathbf x_j - \bar{\mathbf x}\rVert$为各点到形心的距离，其均值为$\bar l$、标准差为$S_l$。**位置重复性**为
$$
RP = \bar l + 3S_l .
$$ {#eq-rp}
**位置精度**是命令位置$\mathbf x_c$到形心的距离，$AP = \lVert \bar{\mathbf x} - \mathbf x_c\rVert$。数据表通常把$RP$写成“±0.03 mm”，即包含几乎一切到达位置的球的半径。
:::

重复性度量的是**分散**；精度度量的是**偏差**。二者成因不同，治法也不同：

- 重复性受制于每次到达时不一样的东西：编码器分辨率与噪声、齿轮回差和摩擦中不重复的那部分、伺服整定、试验中的热漂移。只要位置是靠点动机械臂**示教**得到的，重复性就要紧——因为机械臂此后只需回到原处。
- 精度受制于一切使模型与真实机械臂不符的因素：连杆长度与关节偏距偏离名义值、连杆和减速器在负载下的变形、热膨胀。这些在很大程度上是重复的，所以不坏重复性。只要位置是**计算**出来的——来自CAD数据、来自相机或由离线程序——精度就要紧，而它可以靠标定（[[robot-arm-design/calibration]]）改善。

作为指南（典型范围，截至2026年）：小型六轴工业机械臂的重复性约为±0.01–0.03 mm，协作机械臂±0.02–0.1 mm，承重100 kg以上的大型机械臂±0.05–0.1 mm。绝对精度很少公布；未标定的机械臂通常偏差零点几毫米到几毫米，厂商标定一般能把它降到零点几毫米。

::: warning 重复性指标不是精度指标
读到“重复性±0.02 mm”就打算用相机定位到0.05 mm来抓取零件的买方会失望：相机给出的是**算出的**位姿，所以要紧的是机械臂的绝对精度（再加手眼标定），而它很可能比重复性差十倍到一百倍。两个都要规定，写明哪些任务要哪一个，并按ISO 9283的方式分别试验——重复性在额定负载下、固定接近方向测，精度对着激光跟踪仪这类外部测量测。
:::

## 关节选型计算：静力重力力矩预算 {#sec-gravity}

铰接臂肩部和肘部承受的最大单项载荷，通常是它们之外一切东西的重量。只要机械臂通电它就存在，因而既定下峰值力矩（叠加加速力矩之后），也定下连续力矩的大部分。

::: proposition 转动关节处的静力重力力矩 {#prop-gravity-torque}
设关节$i$绕经过点$O_i$的单位轴$\mathbf z_i$转动，其远端各刚体的质量为$m_k$、质心在$\mathbf r_k$。静力平衡时关节$i$必须由电机提供的力矩为
$$
\tau_{g,i} = -\,\mathbf z_i\cdot\sum_{k\,\text{远端}} (\mathbf r_k - O_i)\times m_k\mathbf g ,
$$ {#eq-gravity-torque}
其中$\mathbf g$为重力矢量。对水平关节轴，它就是$g\sum_k m_k\,d_k$，$d_k$为质心$k$到轴沿垂直于轴方向度量的水平距离。对竖直关节轴，$\tau_{g,i} = 0$。
:::

::: proof
取关节$i$远端的一切为分离体（画一下：作用在$\mathbf r_k$处各重量$m_k\mathbf g$，以及关节处来自近端连杆的约束力和约束力偶；约束力偶沿$\mathbf z_i$的分量就是关节力矩$\tau_i$，另两个分量由轴承承受）。对$O_i$的力矩平衡给出$\tau_i\mathbf z_i + \mathbf M_\perp + \sum_k(\mathbf r_k - O_i)\times m_k\mathbf g = \mathbf 0$，其中$\mathbf M_\perp \perp \mathbf z_i$是轴承力偶。与$\mathbf z_i$作点积消去$\mathbf M_\perp$，即得[[#eq-gravity-torque]]。等价地，$\tau_g = \partial P/\partial\mathbf q$是势能的梯度，见[[robotics/manipulator-dynamics]]。对水平轴且$\mathbf g = -g\,\mathbf e_z$，三重积化为$g$乘水平力臂；对竖直轴，$\mathbf z_i\parallel\mathbf g$，于是每一项$(\mathbf r_k - O_i)\times\mathbf g$都垂直于$\mathbf z_i$，力矩消失。
:::

力臂最大时力矩最大，而对铰接臂的肩部来说，那就是机械臂水平伸展。在这一位姿下选型计算虽偏保守却是惯例：机械臂**确实**会被要求走到那里去。

::: example 一台5 kg、850 mm六轴臂的重力力矩预算 {#ex-gravity}
一台带球形腕的六轴机械臂，上臂$a_2 = 400\,\mathrm{mm}$（肩到肘）、前臂$a_3 = 350\,\mathrm{mm}$（肘到腕心）；法兰在腕心之外$100\,\mathrm{mm}$，于是量到法兰的臂展为$850\,\mathrm{mm}$（肩相对关节1的偏距略去不计）。额定负载$5.0\,\mathrm{kg}$（含夹爪），其质心在法兰外$50\,\mathrm{mm}$。按初步布局估计的质量：上臂结构$4.0\,\mathrm{kg}$，质心在中点；肘部执行器（关节3的电机、减速器、制动器、编码器）$2.5\,\mathrm{kg}$，在肘部；前臂结构$2.0\,\mathrm{kg}$，在中点；腕部组件（关节4–6）$3.0\,\mathrm{kg}$，在腕心。求机械臂水平伸展时关节2与关节3的静力重力力矩。
::: solution
**关节2的分离体**：肩部之外的一切；受力是下面五个重量，方向都竖直向下；肩轴承提供竖直反力和绕垂直于$\mathbf z_2$的两条水平轴的力偶；关节力矩$\tau_2$绕$\mathbf z_2$作用。机械臂水平时，力臂就是各质心到肩轴的距离：

| 项目 | $m$ (kg) | 到J2的$d$ (m) | $m\,d$ (kg m) | 到J3的$d$ (m) | $m\,d$ (kg m) |
|---|---|---|---|---|---|
| 上臂 | 4.0 | 0.200 | 0.800 | — | — |
| 肘部执行器 | 2.5 | 0.400 | 1.000 | 0 | 0 |
| 前臂 | 2.0 | 0.575 | 1.150 | 0.175 | 0.350 |
| 腕部组件 | 3.0 | 0.750 | 2.250 | 0.350 | 1.050 |
| 负载 | 5.0 | 0.900 | 4.500 | 0.500 | 2.500 |
| **合计** | 16.5 | | **9.700** | | **3.900** |

由[[#eq-gravity-torque]]，
$$
\tau_{g,2} = 9.81\times9.700 = 95.2\,\mathrm{N\,m},\qquad \tau_{g,3} = 9.81\times3.900 = 38.3\,\mathrm{N\,m}.
$$
负载不到运动质量的三分之一，却贡献了肩力矩的$4.50/9.70 = 46\,\%$，因为它坐在力臂的末端。腕部组件以$3.0\,\mathrm{kg}$又贡献了$23\,\%$：腕部每省一克，在肩部值的东西约是上臂省一克的四倍。

**合理性检验。**把一个$16.5\,\mathrm{kg}$的质量放在质量加权平均半径$9.70/16.5 = 0.59\,\mathrm m$处会给出同样的力矩——约为臂展的$60\,\%$，对一个重件靠尖端的链来说是说得通的。
:::
:::

腕关节用负载图按同样的方式选型。若关节6的执行器与法兰（$0.8\,\mathrm{kg}$，质心$70\,\mathrm{mm}$在关节5轴外）和负载（$5.0\,\mathrm{kg}$在$150\,\mathrm{mm}$处）从关节5水平悬挂，则$\tau_{g,5} = 9.81\,(0.8\times0.07 + 5.0\times0.15) = 7.9\,\mathrm{N\,m}$——比肩部低一个数量级，与构型的预言一致。关节4和6只有当负载质心偏离其轴时才承受重力力矩；关节1轴竖直，只要基座水平就完全不受重力力矩。

## 加上动力矩 {#sec-dynamic}

关节加速时，电机还要提供惯性力矩。由[[robotics/manipulator-dynamics]]，$\boldsymbol\tau = M(\mathbf q)\ddot{\mathbf q} + C(\mathbf q,\dot{\mathbf q})\dot{\mathbf q} + \mathbf g(\mathbf q) + \boldsymbol\tau_f$，其中$\boldsymbol\tau_f$是摩擦。初步选型时有用的简化是在最不利位姿下一次只从一个关节的静止开始加速：于是$\dot{\mathbf q} = \mathbf 0$，科里奥利项消失，关节$i$需要$\tau_i = m_{ii}\ddot q_i + g_i$。质量矩阵的对角元$m_{ii}$是在该位姿下远端一切绕关节轴的转动惯量——用平行移轴公式从同一张质量表算出。待质量数据更准之后，再用完整模型仿真真实轨迹来校核耦合运动与科里奥利项。

电机自己的转子也要加速，从关节侧看它贡献$N^2J_m$（反射惯量，[[robotics/manipulator-dynamics]]），可以大到与连杆惯量相当。转子力矩在齿轮箱**之前**由电机给出，所以最干净的分账办法是：从连杆侧定**关节输出**力矩（本章），选定电机与传动比后再在电机轴上补$J_m N\ddot q$（[[robot-arm-design/gear-reducers]]）。

::: example 肩部与肘部的峰值力矩 {#ex-dynamic}
对[[#ex-gravity]]的机械臂，估计伸直状态绕关节2的惯量：两根臂结构按均质细杆处理（$I_G = mL^2/12$），其余按质点处理。轨迹发生器把关节2限制在$\ddot q_2 = 6.0\,\mathrm{rad/s^2}$、关节3限制在$9.0\,\mathrm{rad/s^2}$。求峰值力矩，以及取1.3安全因数后的要求。
::: solution
**关节2。**由平行移轴公式，$I_2 = \sum_k (I_{G,k} + m_kd_k^2)$：
$$
\begin{aligned}
I_2 &= \underbrace{4.0(0.20)^2 + \tfrac{4.0(0.40)^2}{12}}_{\text{上臂 }0.213} + \underbrace{2.5(0.40)^2}_{0.400} + \underbrace{2.0(0.575)^2 + \tfrac{2.0(0.35)^2}{12}}_{\text{前臂 }0.682} + \underbrace{3.0(0.75)^2}_{1.688} + \underbrace{5.0(0.90)^2}_{4.050}\\
&= 7.03\,\mathrm{kg\,m^2}.
\end{aligned}
$$
从水平位置向上加速，$\tau_2 = I_2\ddot q_2 + \tau_{g,2} = 7.03\times6.0 + 95.2 = 42.2 + 95.2 = 137\,\mathrm{N\,m}$。

**关节3。**绕肘轴，$I_3 = 2.0(0.175)^2 + \tfrac{2.0(0.35)^2}{12} + 3.0(0.35)^2 + 5.0(0.50)^2 = 0.0817 + 0.3675 + 1.25 = 1.70\,\mathrm{kg\,m^2}$，于是$\tau_3 = 1.70\times9.0 + 38.3 = 15.3 + 38.3 = 53.6\,\mathrm{N\,m}$。

**要求。**计入模型不确定度、摩擦和控制器裕度取1.3的因数，关节2在关节输出侧约需$180\,\mathrm{N\,m}$峰值，关节3约需$70\,\mathrm{N\,m}$峰值。

**合理性检验。**只有负载一项就是$5.0\times0.9^2 = 4.05\,\mathrm{kg\,m^2}$，占$I_2$的$58\,\%$——与它在重力力矩中占$46\,\%$相一致，因为惯量以距离的平方加权。肩部由重力主导（$95$对$42\,\mathrm{N\,m}$）；对没有重力力矩的基座关节1，同一$I_1 \approx I_2$（臂水平伸展）在同样加速度下给出纯惯性的$42\,\mathrm{N\,m}$，这就是同一台机械臂的基座与肩关节往往用不同大小执行器的原因。
:::
:::

## 热校核：rms力矩 {#sec-rms}

电机可以输出一两秒峰值力矩，但发热与电流的平方成正比，而电流与力矩成正比。因此它的连续额定值要同一个重复周期上的均方根力矩来比较。

::: definition 工作周期的rms力矩 {#def-rms}
对以周期$T$重复的关节力矩$\tau(t)$，**rms力矩**为
$$
\tau_{\text{rms}} = \sqrt{\frac1T\int_0^T\tau^2(t)\,\dd t} \;=\; \sqrt{\frac{\sum_j \tau_j^2\,t_j}{\sum_j t_j}}
$$ {#eq-rms}
其中周期由若干段恒力矩$\tau_j$、各持续$t_j$组成。若$\tau_{\text{rms}}$在实际环境温度和安装方式下不超过连续力矩额定值，且周期相对于电机的热时间常数（关节电机为几分钟）足够短，使绕组看到的是平均发热而不是一个个峰值，则关节热上合格。
:::

其依据是铜耗为$i^2R$而$i \propto \tau$，于是平均发热与$\tau^2$的均值成正比；[[mechatronics/electric-actuators]]对单轴给出同样的校核。rms力矩还馈入减速器寿命计算，它依赖另一种平均（三次方平均，[[robot-arm-design/gear-reducers]]）。

::: example 拾放周期中肩关节的rms力矩 {#ex-rms}
在一个$2.0\,\mathrm s$的周期里，示例机械臂的肩关节接近水平：向上加速$0.3\,\mathrm s$（$137\,\mathrm{N\,m}$），匀速运动$0.4\,\mathrm s$（$95.2\,\mathrm{N\,m}$），减速$0.3\,\mathrm s$（$95.2 - 42.2 = 53.0\,\mathrm{N\,m}$），然后等待$1.0\,\mathrm s$让夹爪干活。求rms力矩：(a) 等待期间电机托住机械臂；(b) 等待期间施加抱闸制动器。
::: solution
(a) $\tau_{\text{rms}} = \sqrt{\dfrac{137.4^2(0.3) + 95.2^2(0.4) + 53.0^2(0.3) + 95.2^2(1.0)}{2.0}} = \sqrt{\dfrac{5663 + 3622 + 842 + 9055}{2.0}} = 97.9\,\mathrm{N\,m}$。

(b) 制动器合上时，等待期间的力矩为零：$\tau_{\text{rms}} = \sqrt{(5663 + 3622 + 842)/2.0} = 71.1\,\mathrm{N\,m}$。

(a)的rms力矩几乎不比静力重力力矩大：在一个让臂保持伸展的周期里，让电机发热的是把臂托住这件事本身，而不是运动。制动器把发热削减$1 - 71.1^2/97.9^2 = 47\,\%$——但制动器结合与释放要几十毫秒并且会磨损，所以它适合几秒钟的等待，不适合快周期里的短暂停。还要注意这个周期是悲观的，因为真实路径很少让臂一直水平。于是关节2的执行器必须给出约$180\,\mathrm{N\,m}$峰值和$100\text{–}130\,\mathrm{N\,m}$连续（带裕度的rms）。
:::
:::

## 速度与功率 {#sec-speed}

关节速度由节拍时间和TCP速度定。关节2取$180\,\mathrm{°/s} = 3.14\,\mathrm{rad/s}$时，$0.9\,\mathrm m$处的负载以$2.8\,\mathrm{m/s}$运动。关节输出侧的机械功率是$\tau\dot q$；若满速时就需要满峰值力矩，关节2将需要$137\times3.14 = 430\,\mathrm W$。实际上峰值力矩出现在低速（运动起步），最高速度出现在中等力矩，所以真实峰值功率更低，但电机与驱动器的转矩–转速曲线必须包含轨迹的**每一个**$(\dot q, \tau)$点，而不只是两个极值点。速度还定下传动比：最高转速$5000\,\mathrm{rev/min}$（$524\,\mathrm{rad/s}$）的电机经传动比$N$后关节速度为$524/N\,\mathrm{rad/s}$，所以这个关节要$N \le 524/3.14 = 167$——这就是[[robot-arm-design/gear-reducers]]中展开的那场权衡的开端。

## 末端的误差预算 {#sec-error-budget}

重复性规格必须摊到各个关节头上。关节角的小误差$\delta\mathbf q$使TCP移动$\delta\mathbf x = J(\mathbf q)\,\delta\mathbf q$（[[robotics/jacobians]]）。对单个转动关节，尖端移动$r_i\,\delta q_i$，其中$r_i$是关节轴到TCP的距离；独立的随机误差按平方和开方叠加。

::: proposition 独立关节误差引起的末端误差 {#prop-error-budget}
若关节角误差$\delta q_i$独立、零均值、标准差为$\sigma_i$，且$r_i$是轴$i$到TCP的垂直距离，则TCP位置误差的标准差满足
$$
\sigma_x^2 \le \sum_i r_i^2\sigma_i^2 ,
$$ {#eq-error-budget}
当所有关节轴平行时在最不利方向取等号。取等值$\sigma_i = \sigma_q$时，$\sigma_x \le \sigma_q\sqrt{\sum_i r_i^2}$。
:::

::: proof
对转动关节，$J$的平移部分的列为$\mathbf z_i\times(\mathbf p - \mathbf o_i)$，长度$r_i$。于是$\delta\mathbf x = \sum_i \mathbf j_i\,\delta q_i$，对独立零均值误差有$\E\lVert\delta\mathbf x\rVert^2 = \sum_i\lVert\mathbf j_i\rVert^2\sigma_i^2 = \sum_i r_i^2\sigma_i^2$。这是三个方向上求和的总方差，它对任何一个方向的方差都是上界；当各列平行（所有轴平行且机械臂在一个平面内）时，全部方差落在一个方向上，界被取到。
:::

误差预算把关节误差当作随机的。系统性误差——一根连杆长了$0.2\,\mathrm{mm}$、减速器在负载下固定扭过一个角度——并不逐次散布，它们属于**精度**预算，在那里线性相加，并且大多能被标定除掉。

::: example 为±0.05 mm所需的关节重复性 {#ex-error-budget}
[[#ex-gravity]]的机械臂必须在臂伸直（最不利位姿）、TCP位于负载质心处时达到$RP = 0.05\,\mathrm{mm}$。关节4与关节6与前臂和工具对正，其轴穿过TCP；关节5距TCP$0.15\,\mathrm m$。把$RP$当作$3\sigma_x$，若各关节均摊，求每个关节需要的角重复性，并与关节输出侧19位绝对编码器的分辨率比较。
::: solution
力臂：$r_1 = 0.90$（到基座轴的水平距离）、$r_2 = 0.90$、$r_3 = 0.50$、$r_4 = 0$、$r_5 = 0.15$、$r_6 = 0\,\mathrm m$。于是
$$
\sqrt{\textstyle\sum r_i^2} = \sqrt{0.81 + 0.81 + 0.25 + 0.0225} = 1.376\,\mathrm m .
$$
取$\sigma_x = 0.05/3 = 0.0167\,\mathrm{mm}$，[[#eq-error-budget]]给出
$$
\sigma_q = \frac{1.67\times10^{-5}\,\mathrm m}{1.376\,\mathrm m} = 1.21\times10^{-5}\,\mathrm{rad} = 12\,\mathrm{\mu rad}\ (2.5\ \text{角秒}).
$$
每个关节必须回到$3\sigma_q = 36\,\mathrm{\mu rad} = 7.5\ \text{角秒}$以内。19位编码器的步距为$2\pi/2^{19} = 12.0\,\mathrm{\mu rad}$——单它自己就刚刚好，给回差、摩擦和伺服误差什么也没剩。电机侧编码器隔着$100{:}1$的减速器看要细$100$倍，但减速器的空程就进了预算。这正是[[robot-arm-design/joint-actuators]]和[[robot-arm-design/gear-reducers]]主张双编码器和低回差减速器的理由。

**合理性检验。**$7.5$角秒在$0.9\,\mathrm m$处是$0.9\times36\times10^{-6} = 33\,\mathrm{\mu m}$——与目标同一量级，本来就必须如此，因为和式由关节1和2主导。
:::
:::

同样的力臂还给**刚度**要求定标：关节2的扭转柔顺若在负载下扭过$\Delta q$，就使TCP移动$0.9\,\Delta q$。这一变形是重复的，所以坏的是精度而不是重复性——除非零件之间的负载不一样。包含连杆弯曲在内的完整变形预算在[[robot-arm-design/links-and-structure]]。

## 一套选型计算流程 {#sec-procedure}

::: algorithm 串联机械臂的关节选型计算 {#alg-sizing}
1. **写下技术规格**：负载及其质心与惯量、臂展、工作空间与姿态、节拍与速度、重复性与精度、环境、是否协作。
2. **选择构型**：任务所需的自由度数（[[#sec-layouts]]），再选能覆盖工作空间且离边界有裕度的连杆长度。
3. **估计质量**：按初步布局或类似机械臂估出连杆与执行器的质量；执行器通常占大头。
4. **静力重力力矩**：在最不利位姿下逐关节计算（[[#prop-gravity-torque]]）。
5. **动力矩**：由加速度限值算，用最不利位姿的对角惯量；然后得每个关节的峰值力矩，乘安全因数（1.2–1.5）。
6. **rms力矩**：在代表性周期上算（[[#def-rms]]），以及峰值功率和转矩–转速点。
7. **误差与刚度预算**：在末端分摊（[[#prop-error-budget]]），化成每个关节的角重复性、编码器分辨率和扭转刚度。
8. **选择执行器**（[[robot-arm-design/joint-actuators]]、[[robot-arm-design/gear-reducers]]），然后*更新质量*：用真实件代回第3步，从第4步重做，直到数字不再变化。
:::

第8步是迭代咬合的地方：肘部和腕部执行器是肩部的负载。若[[#ex-gravity]]中的腕部组件从$3.0$增到$4.0\,\mathrm{kg}$，肩重力力矩增加$9.81\times0.75 = 7.4\,\mathrm{N\,m}$，惯量增加$0.56\,\mathrm{kg\,m^2}$，这可能把肩推进下一号执行器，而下一号又在基座处增加质量（无害）——但若肘部执行器变大，肩就要再次付出代价。结果是重臂只会越来越重，而轻量腕部执行器极其值钱。

::: history
第一批为计算机控制设计的电动机械臂出自大学实验室。1969年，沙因曼（Victor Scheinman）在斯坦福大学造出斯坦福臂：一台六轴机械臂，带一个滑动的棱柱关节、电动电机、谐波齿轮减速器（harmonic drive）和装在关节上的电位器与编码器，小到当时的计算机就能驱动。沙因曼后来设计了MIT臂，再后来为Unimation公司（由通用汽车出资）设计了1978年交付的PUMA，其全转动副六轴、带球形腕的构型成为后来铰接臂的样板。同年，日本山梨大学的牧野博（Hiroshi Makino）演示了SCARA概念：两根竖直转动轴造出在水平面内柔顺、竖直方向上刚的机械臂，它在1980年代初投产，使高速装配机器人变得寻常。试验机械臂的标准方法ISO 9283（《操作式工业机器人——性能指标与相关试验方法》（*Manipulating industrial robots — Performance criteria and related test methods*））于1990年首次发布，现行版本出自1998年。
:::

## 后续内容 {#sec-leads}

本章导出的关节要求——峰值与rms力矩、速度、角重复性和刚度——是本课程其余各章的输入。[[robot-arm-design/joint-actuators]]选出产生它们的电机、驱动器和编码器；[[robot-arm-design/gear-reducers]]选择传动比和减速器类型；[[robot-arm-design/links-and-structure]]设计刚到不浪费预算的连杆；而[[robot-arm-design/joint-control]]合上把硬件变成伺服系统的回路。

::: summary
- 给任务恰好所需的自由度：竖直工具的平面作业4个（SCARA型），轴对称工具5个，完整位姿6个，靠冗余绕开障碍与奇异的7个。
- 铰接臂中关节1–3力臂长、需要大力矩；腕部力臂短、需要速度。腕上的质量代价最高。
- 臂展量到某个规定的点，通常是腕心或法兰；在其约80–90 %以内作业，远离伸直的奇异位形。灵巧工作空间比可达工作空间小得多。
- 重复性（$RP = \bar l + 3S_l$，ISO 9283）是分散，精度是偏差。示教的位置需要重复性；算出的位置需要精度，而精度需要标定。
- 静力重力力矩$\tau_{g,i} = g\sum m_kd_k$绕水平轴，绕竖直轴为零；加速加$m_{ii}\ddot q_i$，峰值再乘1.2–1.5的安全因数。
- 用$\tau_{\text{rms}} = \sqrt{\sum\tau_j^2t_j/\sum t_j}$对电机做热校核；对抗重力托住机械臂往往占主导。
- 关节误差到末端误差：$\sigma_x \le \sqrt{\sum r_i^2\sigma_i^2}$。在0.9 m处做到±0.05 mm，每个关节需要几个角秒。
- 迭代：执行器的质量是其后关节的负载。
:::

## 习题

::: exercise 小型机械臂的肩关节力矩 {level=1 check="23.544"}
一台水平保持的两连杆机械臂在距肩轴$0.60\,\mathrm m$处带有$3.0\,\mathrm{kg}$的负载；肩部之外的结构与执行器共$2.0\,\mathrm{kg}$，质心距轴$0.30\,\mathrm m$。求肩部的静力重力力矩。（输入的力矩以N·m为单位。）
::: solution
$\tau_g = g\sum m_kd_k = 9.81\,(3.0\times0.60 + 2.0\times0.30) = 9.81\times2.40 = 23.544\,\mathrm{N\,m}$。
:::
:::

::: exercise 由关节速度求TCP速度 {level=1 check="2.670"}
一台机械臂的关节1以$180\,\mathrm{°/s}$转动，TCP距其轴$0.85\,\mathrm m$，其余关节不动。TCP运动多快？（输入的速度以m/s为单位，保留三位小数。）
::: solution
$\dot q = 180\,\mathrm{°/s} = \pi\,\mathrm{rad/s}$；$v = r\dot q = 0.85\pi = 2.670\,\mathrm{m/s}$。这远高于人附近通常允许的速度，这也是协作运行限制TCP速度而非关节速度的一个原因。
:::
:::

::: exercise 由试验数据求重复性 {level=1 check="0.024"}
在一次ISO 9283试验中，对同一位姿访问30次，到达位置到其形心的距离均值为$\bar l = 0.012\,\mathrm{mm}$、标准差为$S_l = 0.004\,\mathrm{mm}$。形心距命令位置$0.41\,\mathrm{mm}$。写出位置重复性与位置精度。（输入的$RP$以mm为单位。）
::: solution
$RP = \bar l + 3S_l = 0.012 + 0.012 = 0.024\,\mathrm{mm}$，写成±0.024 mm。$AP = 0.41\,\mathrm{mm}$。这台机械臂的重复性比精度好十七倍——未标定机械臂的典型情形。

::: exercise 负载加大后的肘关节力矩 {level=2 check="48.069"}
[[#ex-gravity]]的机械臂另有$7.0\,\mathrm{kg}$负载的型号，质心位置不变，其余不变。求臂水平时关节3的新静力重力力矩。（输入的力矩以N·m为单位，保留三位小数。）
::: solution
对肘轴：$\sum m d = 2.0\times0.175 + 3.0\times0.35 + 7.0\times0.50 = 0.35 + 1.05 + 3.50 = 4.90\,\mathrm{kg\,m}$，于是$\tau_{g,3} = 9.81\times4.90 = 48.069\,\mathrm{N\,m}$，比$5\,\mathrm{kg}$时多$26\,\%$。肩部从$95.2$涨到$9.81\times11.5 = 112.8\,\mathrm{N\,m}$——而且实际上肘部执行器也得跟着加大，肩又要再付一次账。
:::

::: exercise 读负载图 {level=2 check="0.192"}
某腕部的关节5执行器最多可承受$10\,\mathrm{N\,m}$的静力重力力矩。关节5之外的腕部零件自己贡献$0.56\,\mathrm{N\,m}$。对$5.0\,\mathrm{kg}$的负载，其质心最多允许离关节5轴多远？（输入的距离以m为单位，保留三位小数。）
::: solution
负载最多可贡献$10 - 0.56 = 9.44\,\mathrm{N\,m}$，于是$d \le 9.44/(5.0\times9.81) = 9.44/49.05 = 0.192\,\mathrm m$。若法兰在关节5轴外$0.10\,\mathrm m$，质心最多允许在法兰外$92\,\mathrm{mm}$：长夹爪很快就会迫使降低负载。腕部加速期间的动力矩还会进一步压低允许值，这就是厂商按完整动力学画负载图的原因。
:::

::: exercise 关节的rms力矩 {level=2 check="35.53"}
某关节的周期是：$80\,\mathrm{N\,m}$持续$0.2\,\mathrm s$，$30\,\mathrm{N\,m}$持续$0.6\,\mathrm s$，$-20\,\mathrm{N\,m}$持续$0.2\,\mathrm s$，$25\,\mathrm{N\,m}$持续$1.0\,\mathrm s$。求rms力矩。（输入的力矩以N·m为单位，保留两位小数。）
::: solution
$\sum\tau^2t = 6400(0.2) + 900(0.6) + 400(0.2) + 625(1.0) = 1280 + 540 + 80 + 625 = 2525\,\mathrm{N^2\,m^2\,s}$，除以$T = 2.0\,\mathrm s$，于是$\tau_{\text{rms}} = \sqrt{2525/2.0} = \sqrt{1262.5} = 35.53\,\mathrm{N\,m}$。负的那一段和正的一样使电机发热：平方消掉了符号。80 N·m的峰值则须另行校核，要落在该力矩出现之转速下电机的峰值力矩之下。
:::

::: exercise 更严规格下的关节重复性 {level=2 check="7.27"}
对[[#ex-error-budget]]的机械臂与位姿，重复性目标收紧为$RP = 0.03\,\mathrm{mm}$（$= 3\sigma_x$）。若各关节均摊，每个关节允许的角误差标准差$\sigma_q$是多少？（输入的$\sigma_q$以µrad为单位，保留两位小数。）
::: solution
$\sigma_x = 0.01\,\mathrm{mm} = 1.0\times10^{-5}\,\mathrm m$；$\sigma_q = 1.0\times10^{-5}/1.376 = 7.27\times10^{-6}\,\mathrm{rad} = 7.27\,\mathrm{\mu rad}$（1.5角秒）。19位输出编码器（步距12.0 µrad，量化标准差$12.0/\sqrt{12} = 3.5\,\mathrm{\mu rad}$）自己就要用掉一半的额度；需要20位或21位编码器，或者给腕关节更松份额的不均等分摊。

::: exercise SCARA为什么快 {level=2}
SCARA头两个关节的轴是竖直的。用[[#prop-gravity-torque]]说明关节电机承受什么载荷、轴承承受什么载荷，并说明为什么负载与臂展相同的SCARA比铰接臂能跑更短的节拍。它放弃了什么？
::: solution
竖直轴时$\mathbf z_i\parallel\mathbf g$，每一项$(\mathbf r_k - O_i)\times m_k\mathbf g$都是水平的，沿$\mathbf z_i$的分量为零：电机不承受重力力矩，只承受惯性力矩$m_{ii}\ddot q_i$（以及摩擦）。重量及其倾覆力偶由关节轴承（交叉滚子轴承或角接触轴承成对，[[robot-arm-design/links-and-structure]]）和结构承受。既然全部转矩能力都可用于加速，而且连杆可以做成平面内的短而刚的铸件，同样的电机就能用更高的加速度，且电机在保持位置时不发热。SCARA放弃的是：不能使工具倾斜（只能绕竖直轴转动），工作在臂下方一个水平环形工作空间里，竖直行程也小。
:::

::: exercise 重力力矩作为梯度 {level=3}
对一个关节2与关节3平行且水平的平面机械臂，连杆长$a_2$、$a_3$，关节角$q_2$（自水平量起）与$q_3$（相对角），肘部有质点质量$m_a$、尖端有$m_b$，写出势能$P(q_2, q_3)$，并证明$\partial P/\partial q_2$与$\partial P/\partial q_3$和[[#eq-gravity-torque]]一致。$q_2$、$q_3$为何值时关节2力矩最大？
::: solution
高度：肘部$a_2\sin q_2$，尖端$a_2\sin q_2 + a_3\sin(q_2 + q_3)$。于是$P = m_ag\,a_2\sin q_2 + m_bg\,[a_2\sin q_2 + a_3\sin(q_2 + q_3)]$。于是
$\partial P/\partial q_2 = g[(m_a + m_b)a_2\cos q_2 + m_ba_3\cos(q_2 + q_3)]$，$\partial P/\partial q_3 = g\,m_ba_3\cos(q_2 + q_3)$。到关节2的水平距离是$a_2\cos q_2$（肘）与$a_2\cos q_2 + a_3\cos(q_2 + q_3)$（尖端），到关节3的是$a_3\cos(q_2 + q_3)$（尖端）：恰好就是$g\sum m_kd_k$。当两个余弦同为$\pm1$且同号时关节2力矩的绝对值最大，即$q_2 = 0$或$\pi$且$q_3 = 0$：臂水平伸展，正是[[#ex-gravity]]中假设的情形。
:::

::: exercise 为机床上下料定技术规格 {level=3}
一台数控车床要从旁边的料盘装入至多$3\,\mathrm{kg}$的钢坯料（直径$60\text{–}100\,\mathrm{mm}$、长度至多$150\,\mathrm{mm}$），并把完工件放回。卡盘在机床门内$600\,\mathrm{mm}$处，操作者手工在机器人旁装料。写出一份技术规格（自由度、臂展、含夹爪的负载、速度、重复性），并逐个论证据理。然后按[[#ex-gravity]]的方法估肩重力力矩，写明你的质量假设。
::: solution
一份好的答案：**自由度**——6个，因为坯料须沿主轴轴线水平送进卡盘，又要从料盘竖直抓起；双夹爪（一爪拿坯料、一爪拿完工件）省一趟行程，需要第六轴来完成换位。**负载**——两个零件加双夹爪：$2\times3 + 2.5 \approx 8.5\,\mathrm{kg}$，所以选$10\,\mathrm{kg}$级机械臂，并按负载图校核双夹爪的偏距。**臂展**——卡盘在门内$600\,\mathrm{mm}$，加上机器人基座到门的距离（$\approx 400\,\mathrm{mm}$）再加夹爪长度，TCP到法兰约$1.1\,\mathrm m$，于是臂展约$1.3\,\mathrm m$才能保持在85 %以内。**重复性**——卡盘爪约能容$0.2\,\mathrm{mm}$的径向误差，且位置是示教的，所以±0.05 mm绰绰有余。**速度**——车床周期（设90 s）很长，上下料花15–20 s；既然操作者在臂旁作业，宜用协作机械臂，或降速运行、带速度和间隔监控的单元（[[robot-arm-design/arm-safety]]）。**肩力矩**——例如结构与执行器$25\,\mathrm{kg}$、平均半径$0.6\,\mathrm m$，负载$8.5\,\mathrm{kg}$在$1.35\,\mathrm m$处：$\tau_g = 9.81(15 + 11.5) \approx 260\,\mathrm{N\,m}$；计入加速与裕度后，峰值要求约$400\,\mathrm{N\,m}$。答案应指出负载占主导，以及用更轻的单夹爪跑两趟能把负载降下来。
:::
