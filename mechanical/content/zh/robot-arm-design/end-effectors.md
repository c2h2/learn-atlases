机械臂把一个法兰送到某个位姿；干活的是**末端执行器**。它是机器人单元中最常定制、最常更换、也最常为生产事故负责的部分：零件在快行程顶端从指间滑出，吸盘掉下了覆有打印膜的纸箱，销钉插到一半卡死在孔里。本章介绍夹爪的主要族系——平行夹爪、自适应、真空、磁式和柔性——以及决定抓取是否保得住的力学：接触模型与摩擦锥、形封闭与力封闭、抓取品质，以及零件被加速时所需的夹持力。然后是夹爪周围的硬件：工具快换装置、腕部力–力矩传感器，以及装配用的被动与主动柔顺。使用力反馈的控制器（阻抗、导纳、混合控制）在[[robotics/robot-control]]；承载工具的机械臂的关节力矩与刚度在[[robot-arm-design/joint-control]]。末端执行器加上的一切——质量、长度、指间的一个夹挤点——也都进入机械臂的负载预算和[[robot-arm-design/arm-safety]]的安全评估。

## 末端执行器的族系 {#sec-families}

**平行夹爪**使两个（有时三个）手指对称地朝一条中心线合拢。对机加工件、纸箱和任何有两个平行面的东西，它们是默认选择。

- **气动**夹爪用活塞经楔块、杠杆或齿条驱动钳口。就尺寸而言紧凑、皮实、有力：一只缸径25 mm的活塞在500 kPa表压下，还未乘机构的增力比就已经给出$p A = 500\times10^3\times\pi(0.0125)^2 = 245\,\mathrm N$。它们要么全闭要么全开——夹持力由供气压力定，位置只在两端点处可知（靠磁性或电感开关）。
- **电动**夹爪用电机经丝杠、同步带或齿条驱动钳口。它们能设定夹持力（靠电机电流）、行程和速度，并能报告钳口位置——它兼作对零件的一次测量（“这是20 mm的衬套还是22 mm的？”）。同尺寸下力比气动夹爪小，而自锁丝杠能在断电后保持夹持，这对安全要紧。

**自适应（欠驱动）夹爪**的手指有两或三个指节，而驱动它们的执行器少于关节数，靠连杆、腱和弹簧传动。当近指节碰到物体时它停住、远指节继续合拢，于是手指在不被告知几何形状的情况下包裹住不规则的物体。物流中的多样物件和协作应用偏爱它们；代价是抓取构型、进而零件在手内的准确位置，都取决于物体。

**真空夹爪**靠吸盘或海绵吸垫两侧的压力差保持。它们在包装、板材、玻璃和纸箱搬运中占统治地位：只需接近一个面，花费小，能从料堆顶部取件。真空要么由压缩空气驱动的**射流真空发生器**（venturi ejector）产生（快、紧凑、无运动件，但是压缩空气的持续消费者，除非带有达到真空度后即切断空气的节能阀），要么由**电动泵或风机**产生（不用压缩空气，对纸板这类多孔或漏气表面还能提供大流量）。

**磁夹爪**保持铁磁性零件。电磁铁断电即失去保持，这是一种危险；**可切换永磁铁**（机械或气动转动切换）和**电永磁体**（用电流脉冲切换、保持时不耗电）在断电后仍保住零件。保持力对零件的依赖极大：数据表值指的是厚、低碳钢、接触面清洁平整的情形，薄板（会磁饱和）、油漆、氧化皮或零点几毫米的气隙都会使它大幅下降——厂商公布降额曲线，必须使用。

**柔性夹爪**用柔顺材料贴合物体。**Fin Ray**型手指朝被压的物体弯过去而不是被顶开；**气动网络（PneuNet）执行器**是带内腔的弹性体，充气时卷曲；**颗粒阻塞**（granular jamming）夹爪把充满颗粒的膜压到物体周围再抽真空，颗粒便锁成物体形状的整体铸型；静电吸附和仿壁虎干性黏附垫保持扁平易损的零件。它们温柔且容得下位置误差，适合食品、水果和混装物件，但夹持力、刚度和精度与刚性手指相比都低。

::: definition 靠力（摩擦）和靠形状抓取 {#def-grip-modes}
**摩擦抓取**只靠接触处的摩擦保持物体：夹爪以法向力压，切向的摩擦力承担物体的重量和惯性力。**形状抓取**靠手指的几何——凹座、台阶或零件下方的钩——保持物体，于是载荷由法向接触力承担，即使没有摩擦，物体也无法沿受载方向脱手。多数实际抓取是混合的：成形的台阶手指靠形状承重，摩擦只用于剩下的方向。
:::

设计使摩擦抓取变成形状抓取的手指，是夹爪设计中最有效的单项改进。$\mu = 0.3$的摩擦抓取需要超过它承载的三倍的夹挤力；带台肩托住零件下方的手指直接承重，夹挤力只需让零件贴住台肩。

## 抓取力学 {#sec-mechanics}

### 接触模型与摩擦锥

把每个手指–物体接触建模为作用在物体表面一点$\mathbf r$上、法向单位内法线为$\mathbf n$。标准模型有三个（索尔兹伯里（Salisbury），1982）：

- **无摩擦点接触**只传递法向力$f_n\mathbf n$，$f_n \ge 0$；
- **带摩擦点接触**传递**摩擦锥**内的任意力——系数$\mu$的库仑定律；
- **软手指接触**（一个小接触斑的垫）还传递绕法向的有限力偶。

::: definition 摩擦锥 {#def-friction-cone}
在库仑摩擦系数为$\mu$的点接触处，接触能传递力$\mathbf f = f_n\mathbf n + \mathbf f_t$（$\mathbf f_t \perp \mathbf n$）而不滑动，当且仅当
$$
f_n \ge 0\quad\text{且}\quad \lVert\mathbf f_t\rVert \le \mu f_n ,
$$ {#eq-cone}
即$\mathbf f$位于以法线为轴、半顶角$\arctan\mu$的圆锥之内。每个接触力对物体产生一个**力旋量**$\mathbf w = (\mathbf f, \mathbf r\times\mathbf f)\in\R^6$（平面情形$(f_x, f_y, (\mathbf r\times\mathbf f)_z)\in\R^3$）。
:::

夹爪设计用的摩擦系数很不确切——取决于垫的材料、表面粗糙度、油分和灰尘。橡胶或聚氨酯垫在清洁干燥金属上的初设值常用0.3–0.5，油滑表面降到0.1–0.2；对实际垫和零件的测量值永远更好。$\mu = 0.3$时锥的半顶角是$\arctan0.3 = 16.7^\circ$；$\mu = 0.5$时是$26.6^\circ$。

### 形封闭与力封闭

::: definition 形封闭与力封闭 {#def-closure}
若把接触当作无摩擦时，接触能阻止物体的任何运动——任何小刚体运动都会使某个接触发生嵌入——则称抓取处于**形封闭**。等价地说，带非负法向力的接触力旋量正张成整个力旋量空间。若带摩擦时接触能抵抗任意外力旋量——对每个$\mathbf w_{\mathrm{ext}}$，存在其接触力都在各自摩擦锥内、合力旋量为$-\mathbf w_{\mathrm{ext}}$的一组接触力——则称抓取处于**力封闭**。
:::

形封闭需要很多接触：平面物体至少4个无摩擦接触，空间物体至少7个（结果可上溯到十九世纪的勒洛（Reuleaux），一般性证明出自Markenscoff、Ni与Papadimitriou，1990）。夹具和形状抓取手指使用它。力封闭是两指夹爪所能达到的，而它对两个接触的条件很简单。

::: proposition 两接触的力封闭（对置抓取）{#prop-antipodal}
在摩擦系数$\mu$的两个点接触下抓取平面物体，抓取处于力封闭当且仅当连接两接触点的线段严格位于两个摩擦锥之内——即线段与每个内法线方向的夹角小于$\arctan\mu$。这样的抓取称为**对置（antipodal）**。
:::

::: proof
**充分性。**设接触点为$\mathbf r_1$、$\mathbf r_2$，取$\mathbf e = (\mathbf r_2 - \mathbf r_1)/\lVert\mathbf r_2 - \mathbf r_1\rVert$。若$\mathbf e$严格在锥1内而$-\mathbf e$严格在锥2内，手指就能在接触1施加内部夹挤$s\mathbf e$、在接触2施加$-s\mathbf e$（$s>0$）；这两个力合力和合力偶为零（作用于同一直线），且严格位于锥内，所以任何小的附加力$\Delta\mathbf f_1$、$\Delta\mathbf f_2$都可加上而不出锥，大力则靠放大$s$得到（锥对正比缩放不变）。剩下要证接触能一阶地产生任意平面力旋量$(F_x, F_y, M)$：二维锥内部的力张遍一切力的方向，而力偶$M$由两接触处一对垂直于$\mathbf e$、等值反向的力产生（力偶臂为$\lVert\mathbf r_2 - \mathbf r_1\rVert$的力偶），这总是可得，因为每个锥绕接近$\pm\mathbf e$的方向都有非零的半顶角。于是任何力旋量都能平衡：力封闭。

**必要性。**设线段在锥1之外。考虑纯夹挤，或更一般地，一个试图让物体绕经过接触2的轴、朝使接触1滑动的方向转动的外力旋量。接触2处任何力对$\mathbf r_2$的矩为零，所以对$\mathbf r_2$的力矩只能来自接触1：$(\mathbf r_1 - \mathbf r_2)\times\mathbf f_1$；同时力必须平衡，$\mathbf f_1 + \mathbf f_2 = -\mathbf F_{\mathrm{ext}}$。对一个力为零、绕$\mathbf r_2$有力偶的外力旋量，$\mathbf f_2 = -\mathbf f_1$必须落在锥2内而$\mathbf f_1$落在锥1内，于是$\mathbf f_1$既在锥1内又在锥2的反向之内。力矩$(\mathbf r_1 - \mathbf r_2)\times\mathbf f_1$的符号由力$\mathbf f_1$指向连线$\mathbf r_1\mathbf r_2$的哪一侧决定；若$\mathbf e$与$-\mathbf e$都不在锥1内，整个锥就落在过两接触点的直线的同一侧，只能产生一种符号的力矩，另一种符号的外力矩便无法抵抗。（若线段恰在锥的边界上，力矩只能靠锥边缘上的力来抵抗，即处于临界滑动，而“严格”二字已把它排除。）
:::

::: example 平行夹爪夹锥度零件 {#ex-taper}
一只带平聚氨酯垫（$\mu = 0.3$，假定）的平行夹爪抓取一个两夹持面不平行、而是以半角$\alpha$对称收出锥度的零件（一个楔）。对哪些$\alpha$抓取仅靠夹挤就能保住？$\alpha = 10^\circ$和$\alpha = 20^\circ$时各会发生什么？
::: solution
钳口沿连接两接触点的直线移动，而两面的内法线与该直线的夹角为$\alpha$。由[[#prop-antipodal]]，抓取处于力封闭当且仅当$\alpha < \arctan\mu = \arctan0.3 = 16.7^\circ$。

物理上：每个垫以钳口力$F$沿闭合方向压。在斜面上分解，得到法向力$F\cos\alpha$和沿面把零件推出钳口的切向分量$F\sin\alpha$（垫向楔的薄端滑）。摩擦至多抵抗$\mu F\cos\alpha$，所以零件保住当$\tan\alpha < \mu$。$\alpha = 10^\circ$时$\tan\alpha = 0.176 < 0.3$：保得住，还有$0.3 - 0.176$的摩擦裕度去承担其他载荷。$\alpha = 20^\circ$时$\tan\alpha = 0.364 > 0.3$：零件从钳口射出，而越使劲越糟，因为推出分量与$F$的增长和摩擦一样快。

**合理性检验。**铸件和模塑件常有1–3°的脱模斜度，那些都稳稳保住。锥形或楔形零件需要成形手指（形状抓取）——把垫加工成锥度，使接触法线重新沿闭合方向。
:::
:::

### 抓取品质

物体的众多力封闭抓取中，有的比其他的更好。用得最广的度量是**费拉里与坎尼（Ferrari and Canny）**（1992）提出的：用几条边缘向量近似每个摩擦锥，算出沿这些边缘的单位法向力的力旋量，取它们全部构成的凸包。**$\varepsilon$-度量**是力旋量空间中能以原点为球心放入该凸包内的最大球的半径：抓取在单位总指力下（沿一切方向）所能抵抗的最小外力旋量。$\varepsilon = 0$的抓取不处于力封闭；越大越好。由于力和力矩量纲不同，力矩先除以一个特征长度（例如物体的半径）。料箱拣选的抓取规划器用这类度量结合实务项——抓取点到质心的距离、接近的避让、位姿的可达性（[[robotics/inverse-kinematics]]）——给候选抓取排序。

## 加速下的夹持力 {#sec-grip-force}

夹爪必须施加的力不是由零件重量定的，而是由它的重量*加上*运动的惯性载荷定的，再为摩擦的不确定和冲击留裕度。

::: proposition 摩擦抓取所需的夹持力 {#prop-grip}
质量为$m$的零件由$n$个手指夹持，各以法向力$F$压紧，一切接触处的摩擦系数为$\mu$，零件上的载荷（重力加惯性力）平行于接触面。若零件的加速度为$\mathbf a$，则抓取以安全因数$S$保住零件，若
$$
n\,\mu F \ \ge\ S\,m\,\lVert\mathbf g' \rVert ,\qquad \mathbf g' = \mathbf g - \mathbf a ,
$$ {#eq-grip}
其中$\mathbf g$是重力加速度矢量，于是$\mathbf g'$是零件参考系中看到的“等效重力”。竖直向上加速度$a$时$\lVert\mathbf g'\rVert = g + a$。安全因数常取$2$以上，用来覆盖$\mu$的不确定、起停冲击和垫的磨损。
:::

::: proof
在夹爪的加速参考系中，零件在接触力、重量$m\mathbf g$和惯性（达朗贝尔）力$-m\mathbf a$下平衡：接触必须提供切向力$-m(\mathbf g - \mathbf a)$，其大小为$m\lVert\mathbf g'\rVert$，因为按假设它位于接触面内。相对而夹的手指的法向力相互抵消（那是内部夹挤）。由[[#eq-cone]]，接触不滑动所能提供的最大总切向力为$\sum\mu F = n\mu F$。所以零件在$n\mu F \ge m\lVert\mathbf g'\rVert$时保住，加上裕度$S$即得所述条件。若载荷有一部分沿闭合方向作用，它由一个手指的法向力（形状）承担，摩擦的要求随之降低，所以[[#eq-grip]]对那种情形是偏保守的。
:::

::: example 快速取件的夹持力 {#ex-grip}
一只两指电动平行夹爪靠两个竖直面夹取一个$1.5\,\mathrm{kg}$的钢支架（重力平行于垫），$\mu = 0.3$。机械臂以竖直加速度至多$6\,\mathrm{m/s^2}$提起它，搬运途中又沿垫面施加水平加速度至多$8\,\mathrm{m/s^2}$。(a) 仅考虑提升，取$S = 2$求每指的所需夹持力。(b) 规划器有时把提升和搬运混合，于是两个加速度同时出现。重算。(c) 夹爪额定最大$140\,\mathrm N$。够用吗？带台肩的形状抓取手指会改变什么？
::: solution
(a) $\lVert\mathbf g'\rVert = g + a = 9.81 + 6 = 15.81\,\mathrm{m/s^2}$。由[[#eq-grip]]，$F \ge \dfrac{S\,m(g + a)}{n\mu} = \dfrac{2\times1.5\times15.81}{2\times0.3} = 79.1\,\mathrm N$每指。

(b) 两个加速度都有时，在$z$向上的坐标系中$\mathbf g' = (-8, 0, -15.81)\,\mathrm{m/s^2}$（水平部分符号无所谓），于是$\lVert\mathbf g'\rVert = \sqrt{8^2 + 15.81^2} = 17.72\,\mathrm{m/s^2}$，$F \ge 2\times1.5\times17.72/0.6 = 88.6\,\mathrm N$。

(c) $88.6\,\mathrm N < 140\,\mathrm N$，所以按额定力夹爪够用——前提是额定值适用于所用的手指长度（夹爪对长手指要降额，因为钳口导轨承受力矩），且把力设在约$90$–$100\,\mathrm N$而不是留在最大，那会在零件上压出印子并浪费能量。一个从下方托住支架的台肩手指会把载荷的竖直部分交给形状来承担：那时只有水平$8\,\mathrm{m/s^2}$需要摩擦，$F \ge 2\times1.5\times8/0.6 = 40\,\mathrm N$，不到一半。

**合理性检验。**静止情形（$a = 0$）的要求是每指$49\,\mathrm N$，约为重量（$14.7\,\mathrm N$）的$3.3$倍分摊到两个手指——因数$S/\mu = 6.7$由$n = 2$分担。对摩擦抓取，力只有零件重量几倍的夹爪是不够的。
:::
:::

::: warning 额定夹持力不是保持力
夹爪数据表上的力是法向（夹挤）力，通常规定在某个手指长度和供气压力下。它能保持的载荷是每指该值乘$\mu$——也许只有其中三分之一——长手指、油滑零件或磨损的垫下还要少。混淆这两者是夹爪选型中最常见的错误。紧随其后的是另外两个：忘了快行程的惯性载荷（$10\,\mathrm{m/s^2}$的协作臂把等效重量翻倍），以及忘了急停时会发生什么——臂在急停中的减速度远超正常运动，设计不足的抓取恰在可能有人靠近的时刻放开零件（[[robot-arm-design/arm-safety]]）。
:::

## 真空夹爪 {#sec-vacuum}

吸盘密封在表面上，内部绝对压力$p_i$低于环境压力$p_a$，于是压力差$\Delta p = p_a - p_i$作用在密封圈围住的有效面积$A$上，把吸盘压向表面。

::: proposition 吸盘的保持力 {#prop-vacuum}
垂直于表面的理论保持力为$F_{\mathrm{th}} = \Delta p\,A$。对用$k$个吸盘以加速度$\mathbf a$提起质量$m$的零件，照[[#prop-grip]]写$\mathbf g' = \mathbf g - \mathbf a$，并把它分成沿吸盘轴向的分量$g'_n$（把零件拉脱）和平行于表面的分量$g'_t$（使它滑动），吸盘以安全因数$S$保持，若
$$
k\,\Delta p\,A\ \ge\ S\,m\left(g'_n + \frac{g'_t}{\mu}\right),
$$ {#eq-vacuum}
其中$\mu$是吸盘唇缘与零件间的摩擦系数。
:::

::: proof
大气在密封面积上以$p_aA$压零件外表面，被抽真空的吸盘以$p_iA$压内表面；每个吸盘指向吸盘的净力为$\Delta p\,A$。在加速参考系中零件还带着$m\mathbf g'$。沿轴的分量$mg'_n$必须直接平衡：唇缘与零件间剩下的接触（法向）力为$N = k\Delta pA - mg'_n$，它必须为正。切向分量$mg'_t$由唇缘摩擦承担，至多$\mu N$。要求$\mu(k\Delta pA - mg'_n) \ge mg'_t$即得$k\Delta pA \ge m(g'_n + g'_t/\mu)$，而裕度$S$加在载荷一边。
:::

摩擦项正是为什么在*竖直*面上保持零件、或快速侧向移动零件的真空搬运，需要的真空力远大于仅提升：$\mu = 0.5$时侧向载荷算双倍。供应商手册同样列出三种载荷工况（水平面竖直提起、水平面侧向移动、竖直面）并建议：光滑致密零件安全因数至少1.5，多孔、粗糙、油污或柔性零件2以上。

::: example 钢板的真空夹爪 {#ex-vacuum}
一块$600\times400\times1.5\,\mathrm{mm}$的钢板（$\rho = 7850\,\mathrm{kg/m^3}$）用四个有效直径$40\,\mathrm{mm}$的平吸盘从料堆上提起，$\Delta p = 60\,\mathrm{kPa}$（比大气压低60 kPa的真空）。机械臂同时以竖直$5\,\mathrm{m/s^2}$、水平$5\,\mathrm{m/s^2}$加速它；微油板上的唇缘摩擦取$\mu = 0.5$。按$S = 2$校核抓取。
::: solution
**质量。**$m = 7850\times0.6\times0.4\times0.0015 = 2.83\,\mathrm{kg}$。取$z$向上、钢板水平，则$g'_n = g + a_v = 14.81\,\mathrm{m/s^2}$，$g'_t = 5\,\mathrm{m/s^2}$。所需：$S\,m(g'_n + g'_t/\mu) = 2\times2.83\times(14.81 + 10.0) = 140\,\mathrm N$。

**可得。**$A = \pi(0.020)^2 = 1.257\times10^{-3}\,\mathrm{m^2}$，于是$\Delta pA = 60\times10^3\times1.257\times10^{-3} = 75.4\,\mathrm N$每吸盘，四个共$302\,\mathrm N$。比值$302/140 = 2.15$是叠加在安全因数2之上的，所以设计裕度充裕——这是恰当的，因为平吸盘在油污板上的唇缘密封、以及薄板在吸盘之间的下垂，都会削减真实的力。

**合理性检验。**静载荷只有$27.7\,\mathrm N$；动载荷和安全因数把它乘了五。设计者还会做两项校核：板在吸盘之间下垂时边缘不会剥离（吸盘间距），以及真空用开关监控，使机械臂在真空建立之前不动作、真空丧失时安全停止。
:::
:::

::: warning 表压真空、绝对压力与海拔
真空的写法有好几种：大气压之下的压强（“60 kPa真空”、表压“−0.6 bar”）、占完全真空的百分比（“60 %真空”），或绝对压力（“41 kPa绝对”）。用力公式需要的是*差*$\Delta p$。由于$\Delta p$永不能超过环境压力，在海平面（$101.3\,\mathrm{kPa}$）工作的夹爪在高海拔会失去能力：1500 m处标准大气约给出$84.6\,\mathrm{kPa}$，于是能达到85 %真空的喷射器只给出$\Delta p \approx 72\,\mathrm{kPa}$，而不是$86\,\mathrm{kPa}$。
:::

吸盘的选择和真空度同样要紧。**平吸盘**抗切、准确定位零件；**波纹吸盘**（1.5或2.5波）补偿高度差和倾斜，抽真空时把零件轻轻抬起，代价是横向刚度——吊在波纹吸盘上的零件在快行程中会摆动。材料从丁腈橡胶（油污零件）到硅橡胶（食品、高温，但可能留下毁掉涂装的析出物）再到聚氨酯（耐磨）。纸板一类多孔零件持续漏气，所以真空发生器按漏气流量选型，实际能达到的$\Delta p$要在真实材料上测量。

## 工具快换装置与机械接口 {#sec-changers}

机器人法兰遵循ISO 9409-1，它规定了螺栓节圆、孔型和定心特征（例如标注为ISO 9409-1-50-4-M6的法兰，节圆50 mm、四个M6孔）。末端执行器直接螺栓在它上面，或经**工具快换装置**：机器人上的母盘和每把工具上的子盘，靠气动或电动驱动的机构（钢球、凸轮或活塞）锁紧，且其设计要保证断气断电时保持锁定。快换装置通过端面上的模块把压缩空气、真空、电信号、电源有时还有以太网传过去，并识别当前工具，让控制器装入正确的TCP和负载参数。工具架把空闲工具保持在已知位置，并有传感器在机器人对接前确认工具已就位。

快换装置增加质量（通常几百克到几千克）和长度，而每毫米长度都把负载质心移离法兰。机械臂的负载额定值带质心偏距和惯量限制给出，所以预算要写成**力矩**：一台额定$10\,\mathrm{kg}$、质心离法兰$100\,\mathrm{mm}$的机械臂，其腕部承受的力矩为$10\times9.81\times0.1 = 9.8\,\mathrm{N\,m}$；若快换装置、力传感器和夹爪的工具串质心外伸$180\,\mathrm{mm}$，就只剩大约$9.8/(9.81\times0.18) = 5.6\,\mathrm{kg}$的总质量——这还没算零件。最终裁决靠厂商的负载图，不是这个估算。

## 腕部力–力矩传感器 {#sec-ft}

法兰与工具之间的六轴**力–力矩（F/T）传感器**测它传递的三个力分量和三个力偶分量。多数用机加工弹性件上的应变片（箔式或硅），用标定矩阵把六路以上的电桥信号映射成力旋量（[[mechatronics/sensors]]）；也有电容式和光学式。5–20 kg级机械臂的工业典型传感器量程为几百牛顿，分辨率从几百分之一到十分之几牛（厂商数据，截至2026年）。每个关节都带力矩传感的机械臂可以通过雅可比矩阵的转置（[[robotics/jacobians]]）不用腕部传感器来估计工具力旋量，但精度较差，因为关节摩擦和模型误差会进入估计。

传感器测的是它*以下*的一切：工具的重量、运动中的惯性力、电缆的拉力，以及缓慢漂移的偏置。要能测几牛的接触力，必须先把工具重量和偏置去掉。在传感器坐标系中工具重量为$m R^{\mathsf T}\mathbf g$，其中$R$是传感器在基坐标系中的姿态，它作用在工具的质心$\mathbf c$处，于是工具未受接触时的读数为
$$
\mathbf F_{\mathrm{meas}} = \mathbf F_0 + mR^{\mathsf T}\mathbf g,\qquad \mathbf M_{\mathrm{meas}} = \mathbf M_0 + \mathbf c\times(mR^{\mathsf T}\mathbf g),
$$ {#eq-ft-gravity}
偏置为$\mathbf F_0$、$\mathbf M_0$。在若干姿态下记录读数，就得到关于$\mathbf F_0$、$m$、$\mathbf M_0$和$m\mathbf c$的线性方程组。

::: example 辨识工具的质量与质心 {#ex-ft}
腕部传感器的$z$轴由法兰指向工具。工具竖直下挂时读得$F_z = 14.32\,\mathrm N$；竖直上指时$F_z = -9.22\,\mathrm N$。工具水平（传感器$x$轴朝下）时读得$M_y = 0.94\,\mathrm{N\,m}$（已除去力偶偏置）。求工具质量、力偏置及其质心沿$z$的距离。若在工具偏离竖直$30^\circ$时略去重力补偿，会引入多大的接触力误差？
::: solution
下指时重力沿传感器$+z$：$F_z = F_{0z} + mg$；上指时沿$-z$：$F_z = F_{0z} - mg$。两式相减，$2mg = 14.32 + 9.22 = 23.54\,\mathrm N$，故$mg = 11.77\,\mathrm N$、$m = 1.20\,\mathrm{kg}$；相加，$F_{0z} = (14.32 - 9.22)/2 = 2.55\,\mathrm N$。水平且$x$朝下时，重量在传感器系中为$(mg, 0, 0)$，取$\mathbf c = (0, 0, c_z)$，则$\mathbf c\times\mathbf F = (0,\ c_z\,mg,\ 0)$，所以$c_z = 0.94/11.77 = 0.080\,\mathrm m = 80\,\mathrm{mm}$。

倾斜$30^\circ$时，未补偿的重量表现为沿$z$的$mg\cos30^\circ = 10.2\,\mathrm N$和侧向的$mg\sin30^\circ = 5.9\,\mathrm N$，外加$c_z mg\sin30^\circ = 0.47\,\mathrm{N\,m}$的力偶——于是想以$5\,\mathrm N$压紧的力控制器会看到同样量级的幻影力，把工具推离或压进表面。用[[#eq-ft-gravity]]补偿后，残差由$m$、$\mathbf c$的精度和偏置漂移决定，通常为十分之几牛。

**合理性检验。**$1.2\,\mathrm{kg}$、$80\,\mathrm{mm}$是个合理的小夹爪；实践中用六个以上姿态、按最小二乘拟合参数，如[[robot-arm-design/calibration]]。
:::
:::

## 装配中的柔顺 {#sec-compliance}

把销钉插进间隙只有百分之几毫米的孔，超出了任何机械臂的精度。装配之所以能成功，是因为允许零件**柔顺**：只要横向误差小于倒角，倒角就能引导销钉；而柔性腕让销钉在接触力下侧移和倾斜。两种失效模式限制了这一点：**楔紧**，销钉倾斜并与孔在两点接触；**卡死**，所加的力落在两个接触的摩擦锥之内，于是越使劲越插不进（二者皆由惠特尼（Whitney）在1980年代分析）。

**被动柔顺。****远程中心柔顺**（remote centre compliance，RCC）是查尔斯·斯塔克·德雷珀实验室（Charles Stark Draper Laboratory）1970年代末开发的，是用弹性体剪切垫或弹簧元件做成的腕，其布置使它的**柔顺中心**——横向力产生纯平移、力偶产生纯转动的那个点——位于器件之外、靠近销钉尖端。倒角上的横向接触力就使销钉侧移而不倾斜，两点接触产生的力偶使它绕尖端转回对正。RCC以横向刚度$K_x$（典型为每毫米几十牛）和转动刚度$K_\theta$表征；纠正误差$e$所需的横向力为$K_xe$，它必须远低于会损伤零件或使倒角接触粘合的力。被动柔顺快且无需控制，但它只对一种几何调校过，且自由运动时工具会晃动；许多RCC带气动锁用于搬运。

**主动柔顺。**有了腕部F/T传感器（或关节力矩传感），控制器能让机械臂表现得像可编程的弹簧–阻尼器——**阻抗控制**或**导纳控制**——或在某些方向调节力、另一些方向调节位置——**混合控制**（[[robotics/robot-control]]）。一种典型的插入策略：横向低刚度、带设定下压力接近；接触后按螺旋或倾斜图案搜索，直到力下降（销钉找到孔）；在力控下插入；触底时力上升即判完成。主动柔顺适应任何几何并报告发生了什么，但带宽受控制回路限制，因此比调得好的被动器件慢，而且能稳定呈现的刚度受[[robot-arm-design/software-stack]]中的回路时延限制。

**内置柔顺。**带关节力矩传感和准直接驱动的协作机械臂（[[robot-arm-design/gear-reducers]]）天生柔顺，柔性夹爪和波纹吸盘在接触处加上柔顺。柔顺的一切形式都是用位置精度换误差容忍；设计问题在于把它放在链中的哪个位置。

## 手指设计 {#sec-fingers}

多数夹爪是买来的；要为每个零件设计的是手指。经验丰富的设计师逐条过一遍的清单：

- **为形状抓取成形。**与零件匹配的凹座、V形槽或台阶靠几何承重，并把零件定心在手内。圆柱夹在平钳口与V形槽之间会自定心，摩擦还得到增益（见习题）。要为零件的公差带和取件时的定位误差留间隙。
- **垫。**可更换的聚氨酯或橡胶垫增大摩擦并保护零件；其硬度（常用Shore A 60–90）在摩擦与贴合对磨损和定位精度之间取舍。零件在手内的位置必须准确时要用硬手指。
- **长度与质量。**长手指能伸进夹具，但允许的夹持力下降（夹爪的钳口导轨承受力乘指长的力矩），还给钳口驱动增加惯量。手指在不妨碍接近的前提下尽量短，并按夹爪的力矩额定值校核。
- **刚度与材料。**手指用机加工铝或钢，或为快速迭代用3D打印聚合物（尼龙PA12及类似材料）——打印手指便宜到调试期间每周重做一版也不心疼，但必须校核夹持力下的变形和蠕变。
- **从平面上取件。**薄的指尖或指甲状的刃口能从桌面拾取薄片零件；锥形指尖允许挤进密排的零件之间。
- **传感与安全。**钳口位置反馈检查零件在位和尺寸是否正确；手指不应制造新的挤压点或安全评估不得不处理的新锐边（[[robot-arm-design/arm-safety]]）。

::: algorithm 末端执行器的选择 {#alg-select}
1. **给零件定性**：质量、尺寸范围、材料、表面（多孔、油污、易损）、公差、如何供件（料仓、输送机、料箱），以及抓取之后要对它做什么（放置精度、插入、姿态）。
2. **选原理**：有相对面的零件用刚性平行钳口；平的或顶部可接近的零件用真空；钢板与坯料用磁；多样或易损件用自适应或柔性手指；混合任务用组合（真空加手指）。
3. **定夹持**：含加速度和安全因数的夹持力或真空力（[[#eq-grip]]、[[#eq-vacuum]]），包括急停减速度；尽可能按形状抓取设计手指。
4. **校核机械臂**：工具总质量、质心和惯量对照负载图；夹爪的行程与动作时间放进节拍预算。
5. **按需加传感与柔顺**：钳口位置或真空开关检零件在位；接触作业用F/T传感器或被动柔顺；一臂多工具用快换装置。
6. **评估安全与失效模式**：断气断电时的行为（零件还保得住吗）？挤压点？锐边？把这些写进风险评估。
7. **试制并试验**：用真实零件以生产速度运行，测数千次循环中的滑落和掉件率。
:::

::: quiz
一个物流单元要从托盘上拣取0.5–12 kg的密封纸箱。通常选哪种末端执行器，其选型的主要问题是什么？
- [ ] 两指平行夹爪，按最大箱宽选型。
- [x] 带海绵吸垫或多个吸盘的真空夹爪，配电动风机或大流量发生器，按纸板的漏气流量、以及带动载荷的最重箱子选型。
- [ ] 电磁夹爪，按最重箱子的重量选型。
- [ ] 颗粒阻塞柔性夹爪，按箱子的棱角选型。
::: solution
托盘上的箱子只能从顶部接近且大小不一，所以真空是自然选择。纸板多孔，印刷膜和胶带使密封不严，所以发生器必须提供足够流量，在漏气之下保持所需的$\Delta p$——要在真实纸箱上测——且力要按最重的箱子含加速度和安全因数覆盖，由[[#eq-vacuum]]。重箱在快行程中常另用货叉或抱夹（形状抓取）托住。磁铁吸不住纸板；阻塞夹爪对12 kg太弱太慢；平行夹爪需要两个侧面的接近空间，码得紧紧的托盘给不了。
:::
:::

::: history
第一台工业机器人——1961年安装在通用汽车工厂的Unimate——用一个简单的双钳口夹爪卸载压铸件，此后几十年夹爪都停留在简单、任务专用的装置。研究性的手随之而来：索尔兹伯里（Kenneth Salisbury）的斯坦福/JPL手（1982），三个手指各三个关节，并附带着他的接触类型与抓取机动性分析；犹他/麻省理工手（1980年代）探索了腱驱动的灵巧性。远程中心柔顺出自德雷珀实验室1970年代末由惠特尼（Daniel Whitney）主导的机器人装配研究，它还产出了楔紧与卡死理论。费拉里与坎尼的抓取品质度量（1992）成为抓取规划的标准工具。柔性夹爪兴起于2000年代到2010年代：布朗（Brown）及其同事的颗粒阻塞夹爪发表于2010年，怀特赛兹（Whitesides）小组的弹性体PneuNet执行器约在2011年。法兰接口的标准是ISO 9409-1（现行版本2004年）。
:::

::: summary
- 族系：平行夹爪（气动：力大、两个位置；电动：力与位置可控）、自适应欠驱动手指、真空（喷射器或泵/风机；平吸盘或波纹吸盘）、磁（优先可切换或电永磁）、柔性（Fin Ray、PneuNet、阻塞、黏附）。
- 宁要形状抓取不要摩擦抓取：成形手指靠几何承重，把所需夹持力降几倍。
- 库仑接触在顶角为$\arctan\mu$的锥内传递力。形封闭至少需要4（平面）或7（空间）个无摩擦接触；两指力封闭要求两接触连线在两个摩擦锥内（[[#prop-antipodal]]）。费拉里–坎尼的$\varepsilon$-度量给抓取排序。
- 夹持力：$n\mu F \ge S\,m\lVert\mathbf g - \mathbf a\rVert$，$S \ge 2$；要计入快行程和急停；额定夹挤力不是保持力。
- 真空：$k\Delta pA \ge S\,m(g'_n + g'_t/\mu)$；$\Delta p$是相对环境的差，随海拔变小；多孔应用按漏气流量选型。
- ISO 9409-1法兰；快换装置失效保锁并传递介质；工具串预算按绕法兰的力矩写。
- 腕部F/T传感器需要重力与偏置补偿，$\mathbf F = \mathbf F_0 + mR^{\mathsf T}\mathbf g$，$\mathbf M = \mathbf M_0 + \mathbf c\times mR^{\mathsf T}\mathbf g$。
- 柔顺：被动RCC把柔顺中心放在销尖附近；主动阻抗/导纳/混合控制适应任何几何但较慢；剩下的交给倒角和间隙。
:::

## 习题

::: exercise 吸盘的力 {level=1 check="197.9"}
一个平吸盘有效直径$60\,\mathrm{mm}$，在低于大气压$70\,\mathrm{kPa}$下工作。它的理论保持力是多少？（输入的力以N为单位，四位有效数字。）
::: solution
$F = \Delta pA = 70\times10^3\times\pi(0.030)^2 = 70\times10^3\times2.827\times10^{-3} = 197.9\,\mathrm N$。
:::
:::

::: exercise 摩擦锥角 {level=1 check="26.57"}
垫的$\mu = 0.5$时摩擦锥的半顶角是多少？（输入的角度以度为单位，四位有效数字。）
::: solution
$\arctan0.5 = 26.57^\circ$。由[[#prop-antipodal]]，对锥度半角小于此值的两个面，两指抓取靠摩擦就能保住。
:::

::: exercise 气动夹爪的力 {level=1 check="245.4"}
气动夹爪的活塞缸径$25\,\mathrm{mm}$，供气压$500\,\mathrm{kPa}$表压。忽略摩擦和机构比，活塞产生多大的力？（输入的力以N为单位，四位有效数字。）
::: solution
$F = pA = 500\times10^3\times\pi(0.0125)^2 = 245.4\,\mathrm N$。这里表压是对的，因为活塞另一侧作用着大气压。钳口力由数据表上的机构增力比和效率得出。
:::

::: exercise 小零件的夹持力 {level=2 check="27.62"}
一个$0.8\,\mathrm{kg}$的零件由两个手指以$\mu = 0.4$夹持，以$4\,\mathrm{m/s^2}$的向上加速度提升。安全因数为2时每指须施加多大的法向力？（输入的力以N为单位，四位有效数字。）
::: solution
由[[#eq-grip]]，$F = S\,m(g + a)/(n\mu) = 2\times0.8\times13.81/(2\times0.4) = 27.62\,\mathrm N$。
:::

::: exercise 高海拔的真空 {level=2 check="71.9"}
一台真空喷射器达到85 %真空（内部绝对压力为环境的15 %）。厂区海拔处环境压力为$84.6\,\mathrm{kPa}$。喷射器达到的压力差是多少？（输入的$\Delta p$以kPa为单位，三位有效数字。）
::: solution
$\Delta p = 0.85\times84.6 = 71.9\,\mathrm{kPa}$，对比海平面的$0.85\times101.3 = 86.1\,\mathrm{kPa}$：同一夹爪保持力损失16 %。

::: exercise 由两个读数求工具质量 {level=2 check="1.223"}
腕部F/T传感器在工具下挂时读得$F_z = 20.0\,\mathrm N$，上指时$F_z = -4.0\,\mathrm N$。求工具质量和传感器的$z$偏置。（输入的质量以kg为单位，四位有效数字；取$g = 9.81\,\mathrm{m/s^2}$。）
::: solution
如[[#ex-ft]]，$2mg = 20.0 + 4.0 = 24.0\,\mathrm N$，故$mg = 12.0\,\mathrm N$、$m = 12.0/9.81 = 1.223\,\mathrm{kg}$；偏置为$(20.0 - 4.0)/2 = 8.0\,\mathrm N$——很大，说明传感器应当重新调零，或者有电缆在拉工具。
:::

::: exercise V形槽手指 {level=2}
一个圆柱夹在平钳口与对称V形槽钳口之间，V槽两翼面的内法线与闭合方向成$\pm\gamma$。钳口力为$F$，一切接触处摩擦系数$\mu$。求摩擦能抵抗的沿圆柱轴线的最大力，并把$90^\circ$V槽（$\gamma = 45^\circ$）与两个平钳口比较。
::: solution
平钳口以$F$压。V槽处两个翼面法向力$N$与它平衡：$2N\cos\gamma = F$，故$N = F/(2\cos\gamma)$。轴向摩擦受一切法向力之和的限制：$\mu(F + 2N) = \mu F(1 + 1/\cos\gamma)$。两个平钳口是$2\mu F$。取$\gamma = 45^\circ$：$\mu F(1 + 1.414) = 2.41\,\mu F$，增益21 %，而且槽还使圆柱自定心、靠形状抵抗侧滑。更深的槽（$\gamma \to 90^\circ$）理论上让因数无上界，但那时两翼会楔住零件并要求很大的开爪力——实用上限是$\gamma$约为$60^\circ$（即$60^\circ$的夹角）。
:::
:::

::: exercise RCC的纠偏力 {level=2 check="24"}
一台远程中心柔顺装置的横向刚度为$30\,\mathrm{N/mm}$。销钉带着$0.8\,\mathrm{mm}$的横向误差到达一个带倒角的孔。销钉被推回对正后，RCC对它施加多大的横向力？（输入的力以N为单位。）
::: solution
$F = K_xe = 30\times0.8 = 24\,\mathrm N$。在$45^\circ$倒角上，这个横向力须由插入力分解而来，它与插入力大致相当再加上摩擦，所以销钉沿倒角滑下时臂要以略大于$24\,\mathrm N$的力推；更软的RCC把两者都降下来，代价是自由运动中晃动更大。
:::

::: exercise 两指抓取的力封闭 {level=3}
边长$40\,\mathrm{mm}$的方块在平面内于两点被夹：一点在左面中点，另一点在右面中点上方$10\,\mathrm{mm}$处。$\mu = 0.3$时抓取是否力封闭？使它力封闭所需的最小$\mu$是多少？
::: solution
连接两接触点的线段从$(0, 20)$到$(40, 30)$（mm），与水平成$\arctan(10/40) = 14.0^\circ$。两个内法线都是水平的（左面指向$+x$，右面指向$-x$），所以线段与每个法线成$14.0^\circ$。由于$\arctan0.3 = 16.7^\circ > 14.0^\circ$，线段位于两锥之内，由[[#prop-antipodal]]抓取力封闭。临界摩擦因数是$\tan14.0^\circ = 0.25$：低于它，方块会在夹挤自身作用下转出夹爪。裕度（$16.7^\circ$对$14.0^\circ$）很小：稍滑的表面就会丢爪，所以抓取规划器会选正对的接触点（$0^\circ$），它把裕度最大化。
:::

::: exercise 设计：混装机加工件的夹爪 {level=3}
一个机床上下料单元要给车床装入三个家族的钢零件：直径$20$–$40\,\mathrm{mm}$、至多$2.5\,\mathrm{kg}$的轴；直径$80$–$120\,\mathrm{mm}$、至多$3\,\mathrm{kg}$的法兰；直径$15\,\mathrm{mm}$的小衬套。机械臂（额定$10\,\mathrm{kg}$）最高$8\,\mathrm{m/s^2}$。零件轻度上油。提出一个末端执行器：原理、手指、夹持力、传感，以及断电断气时单元如何应对。写明你的假设。
::: solution
一个合理的设计。**原理**：双夹爪（两把平行夹爪在同一个法兰上互成$90^\circ$），一次行程就能卸完工件、装毛坯——这是机床上下料的标准。电动夹爪可按零件家族设力与行程，并报告钳口位置（零件在位、尺寸正确）；若有压缩空气且各家族能共用一个行程，气动夹爪是备选。**手指**：内表面做台阶V形槽（容纳轴和衬套），朝外做台阶，从孔或外缘夹法兰，并使每个零件坐到台肩上（轴向形状抓取）。**夹持力**：设油滑钢对硬化手指的$\mu = 0.15$。$3\,\mathrm{kg}$的法兰在最不利姿态全靠摩擦保持时，$\lVert\mathbf g'\rVert \le g + 8 = 17.8\,\mathrm{m/s^2}$、$S = 2$，由[[#eq-grip]]得每指$F \ge 2\times3\times17.8/(2\times0.15) = 356\,\mathrm N$——对多数紧凑电动夹爪太大，这就是需要台肩（形状抓取）的原因：轴向载荷由形状承担后，摩擦只需承担横向分量。轴则叠加上一题V形槽的因数。**负载**：两把夹爪（$2\times1.5\,\mathrm{kg}$）、过渡盘（$0.5\,\mathrm{kg}$）和一个$3\,\mathrm{kg}$的零件共$6.5\,\mathrm{kg}$；质心和惯量对照机械臂的负载图校核。**传感**：每把夹爪的钳口位置、车床卡盘合爪前的零件在位检查，以及向手指吹屑的气吹喷嘴。**失效**：自锁驱动（或带液控单向阀的弹簧助力气动夹爪）在断电断气时保持夹持；臂的制动器保持其位置；风险评估要覆盖急停中脱落的零件——那是夹持的最不利情形，因为急停减速度可能超过$8\,\mathrm{m/s^2}$。
:::

## 延伸阅读

《斯普林格机器人手册》（*Springer Handbook of Robotics*）的抓取与末端执行器章节完整覆盖了接触模型、封闭与抓取品质并附充分文献；Lynch与Park在他们关于抓取与操作的章节论述形封闭与力封闭；梅森（Mason）的《机器人操作力学》（*Mechanics of Robotic Manipulation*，2001）对摩擦与封闭的处理十分细致。Monkman、Hesse、Steinmann与Schunk的《机器人夹爪》（*Robot Grippers*，2007）是夹爪原理与设计的实用综述。真空与夹爪厂商出版的选型手册里有上文用到的载荷工况，值得一读——只需留意其数字针对各自的产品。
