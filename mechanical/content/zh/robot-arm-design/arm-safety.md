工业机器人是一台能以数米每秒移动数千克质量的机器，其运动方向旁观者难以预测，而且只有当什么东西叫它停它才停。有记录的第一起因工业机器人致死的事故发生在1979年，而其间的危险——撞击、机械臂与固定物之间的压溃与夹持、从夹爪飞出的零件、维护期间的意外启动——自此再未改变。改变的是让机械臂变安全的方式：从把人挡在外的围栏，到与人共享工作空间、并自我限制速度、分离距离、力与功率的机械臂。本章面向制造机械臂、并把它们集成到单元中的人，讲这套安全的工程学：风险评估、机器人安全标准（ISO 10218与ISO/TS 15066）、协作运行的四种模式及其背后的分离距离与能量计算、功能安全与性能等级（ISO 13849-1）、停止类别（IEC 60204-1），以及实现这一切的硬件——安全额定控制器、安全转矩关断与制动器。本章建立在[[mechatronics/system-integration]]的机器安全总论、[[robot-arm-design/joint-control]]的机械臂停止行为，以及[[robot-arm-design/end-effectors]]的末端执行器之上——后者往往是协作应用中最危险的部分。

::: warning 本章讲原理，不讲合规
机器人安全是一个受监管的领域。这里引用的标准只做摘要与转述，不作转载；它们的确切要求、表格与限值必须取自现行版本，而版本会不时修订（ISO 10218在2025年修订过）。算例中标明何处是为演示而选的假设值，这些数值不得用作设计值。真实的机器人单元由合格人员按其使用地适用的标准与法规设计、验证并形成文件，这里没有任何算例是获批准的设计。
:::

## 风险评估 {#sec-risk}

每一项安全设计都从**风险评估**出发，取ISO 12100（《机械安全 设计通则 风险评估与风险减小》，2010年）之义——那是所有机器的基础标准。

::: definition 危险、风险与风险减小 {#def-risk}
**危险**是潜在的伤害来源（运动的机械臂、夹爪手指间的夹点、坠落的零件、弹簧或压缩空气中的储能）。**危险状态**是人暴露于危险的情境。**风险**兼有潜在伤害的**严重度**与其发生的**概率**，概率又取决于暴露的频率与持续时间、危险事件发生的概率、以及避免或限制伤害的可能性。**风险减小**按优先次序(1)**本质安全设计措施**、(2)**安全防护与补充保护措施**、(3)**使用信息**——“三步法”——降低严重度或概率，直到残余风险可接受。
:::

::: algorithm 风险评估与风险减小（依ISO 12100） {#alg-risk}
1. **确定机器的边界**：预期使用与合理预期误用、生命周期的所有阶段（运输、安装、调试、生产、示教、维护、清洁、退役）、涉及的人（操作员、维护人员、旁观者）及其培训。
2. **辨识每个阶段的危险与危险状态**——对机械臂：机械臂、工具与零件的撞击与夹持；抛出的零件；意外启动；电气、气动与热危险；人机工效；工艺特有的危险（激光、焊接电弧、锋利刀片）。
3. **估计**每一项的风险：严重度、暴露、概率、避免的可能性。
4. **评价**是否需要减小风险。
5. **减小风险**，按三步法，然后回到第2步：每项保护措施都可能引入新的危险（光幕诱人把手伸过它；降速模式诱人站得更近）。
6. **记录**评估、措施与验证；残余风险写入使用信息。
:::

对机器人应用，本质安全措施往往最有效却最少被用：更轻的臂与夹爪，圆角与带衬垫的表面，机械臂与固定结构之间没有夹点（间隙至少有所涉身体部位那么大，或者根本没有间隙），更低的最高速度，机械臂物理上无法离开的工作空间（机械挡块），以及发不出挤压力量的夹爪。安全防护——固定式防护装置、联锁门、光幕、激光扫描仪，以及下面的协作技术——处理剩下的部分。

## 机器人安全标准 {#sec-standards}

除了通用机械标准，对机械臂有三份核心文件。

- **ISO 10218-1**规定机器人本体的安全要求：机械臂的*制造商*必须提供什么——停止功能、速度与位置限制、示教器的使能装置与急停、手动模式下的降速、驱动动力断开时移开机械臂以解救被困人员的手段、公布的停止时间与停止距离，以及安全相关控制系统的性能。
- **ISO 10218-2**规定机器人系统、应用与单元的要求：*集成商*必须做什么——布局、安全防护、末端执行器、工件、安全功能的集成，以及验证。
- **ISO/TS 15066**（2016年）是一份技术规范，给出**协作**运行的指南，包括速度与分离监控的分离距离公式，以及其附录A中用于功率与力限制的、含接触力与压强限值的人体模型。

ISO 10218在2006年以第1部分、2011年以第2部分成为两部分的标准，当时第1部分也做了修订。**两部分都在2025年发布了修订版。**据公开描述，2025年修订重排了要求、把功能安全要求写得更明确、把协作当作*应用*的属性而非机器人的属性——反映出没有哪台机器人能脱离其工具、任务与布局而单独对协作是安全的——把ISO/TS 15066的大量指南吸收进标准本身，并增加了网络安全中影响安全部分的要求。本章的描述沿用2011年版与ISO/TS 15066引入、至今仍在使用的基本概念；设计者必须以其产品与市场所适用版本的现行文本为准。在欧盟，这些标准在机械立法下是协调标准——《机械指令》2006/42/EC已被《机械法规》（EU）2023/1230取代、后者自2027年1月起适用——符合协调标准即推定符合相应的法律要求。

几条在机器人标准中反复出现、值得牢记的要求：

- **手动降速**：从示教器移动机械臂时，工具中心点的速度限制在$250\,\mathrm{mm/s}$，除非另有进一步措施。
- **使能装置**：手动运动要求把三位使能开关按在其中位；松开它*或用力捏紧它*（惊恐反应）都会令机械臂停止。
- 示教器与单元处的**急停**，优先于其他所有功能。
- **停止数据**：制造商针对所提供的停止类别、针对速度、伸展与负载的组合，公布主要轴的停止时间与停止距离，使集成商能够计算安全距离。

## 让机械臂停止 {#sec-stopping}

**IEC 60204-1**（《机械安全 机器的电气设备》）定义了三个**停止类别**：

| 类别 | 发生什么 | 机械臂的典型用途 |
|---|---|---|
| 0 | 立即切断执行器的动力（非受控停止）；在机械臂上，即关断驱动器转矩并合上保持制动器 | 急停、故障反应、失电 |
| 1 | 借助仍可供给执行器的动力实现受控停止，停止后再切断动力 | 大多数机械臂上的急停与保护性停止 |
| 2 | 保持执行器供电的受控停止 | 协作运行的保护性停止（安全监控停止） |

**急停**（ISO 13850）按风险评估必须是0类或1类。**保护性停止**由门开关或扫描仪一类防护装置触发，可以是0、1或2类。在驱动器里，它们对应IEC 61800-5-2的安全子功能：**安全转矩关断**（STO，以硬件切断栅极驱动电源，使电机发不出转矩——0类）、**安全停止1**（SS1：先减速，再STO——1类）、**安全停止2**（SS2：先减速，再以**安全运行停止**（SOS）带电监视静止——2类），另有**安全速度限制**（SLS）、**安全位置限制**（SLP）与**安全制动控制**（SBC）。

即便急停，机械臂通常也宁选1类而不是0类，有两个原因。带电机的受控停止比单靠制动器刹得更狠，所以机械臂停得*更早*；而且能让工具留在编程路径上，而六个制动力矩不同的关节一起抱闸，会把工具甩上一条没有计划过的曲线。

::: example 0类与1类停止距离的对比 {#ex-stop}
某机械臂的工具以$1.5\,\mathrm{m/s}$运动时触发停止。假设（演示用数值）1类停止中控制器在$10\,\mathrm{ms}$内反应、随后沿路径以$10\,\mathrm{m/s^2}$给工具减速，而0类停止中保持制动器在STO后$30\,\mathrm{ms}$接合、随后以相当于$5\,\mathrm{m/s^2}$的减速度给工具减速。比较停止距离。
::: solution
对以速度$v$走完反应时间$t_r$、随后以恒定减速度$a$制动的过程，距离为$s = vt_r + v^2/(2a)$。

1类：$s = 1.5\times0.010 + 1.5^2/(2\times10) = 0.015 + 0.1125 = 0.128\,\mathrm m$。

0类：$s = 1.5\times0.030 + 1.5^2/(2\times5) = 0.045 + 0.225 = 0.270\,\mathrm m$。

受控停止的距离短一半，而且留在路径上。非受控停止仍然需要——它正是驱动器或控制器失效时会发生的事，也是对停止功能本身出故障的反应——所以安全距离必须按安全功能真正保证的那个停止来算。若受控制动由安全控制器监视（带监视减速的SS1），它可以被信任；若不被监视，就得按0类距离。**合理性检验。**二次项占主导，所以速度减半、制动段缩为四分之一——这就是人附近降速的依据。
:::
:::

机器人关节上的**制动器**是弹簧施加、通电释放的保持制动器：断电时把臂悬住，并在0类停止中作为最后手段，但它们不是按工作制动器设计的，从全速反复急停会把它们磨坏。其保持力矩必须在最不利位姿、带最重工具与最重零件时超过重力力矩并留有余量；须定期检验（向关闸的制动器指挥一个转矩并检查关节是否不动），安全控制器可通过安全制动控制与安全制动试验把这一功能自动化。垂直与重力加载的轴是要害：失去制动的关节会坠落。

## 安全额定控制 {#sec-safety-control}

机器人的运动控制器是一套复杂、频繁更新的软件系统，安全不托付给它（[[robot-arm-design/software-stack]]）。安全功能运行在控制系统中独立的**安全额定**部分：双通道安全控制器（两颗处理器由冗余输入计算同一功能并比较结果）、安全额定编码器或冗余位置测量、驱动器内带反馈的STO与制动控制，以及来自急停、使能装置、门开关与传感器的安全额定输入。现代机械臂控制器在这一层实现一组可配置的**安全功能**：安全的关节与笛卡尔位置限制（虚拟墙、禁入区、工具姿态锥）、关节与工具的安全速度限制、动量与功率限制、力限制，以及停止时间与停止距离的监视。一旦违例即触发保护性停止。

::: definition 性能等级（ISO 13849-1） {#def-pl}
ISO 13849-1（现行版本2023年）以**性能等级**PL a（最低）到e（最高）为控制系统安全相关部分执行安全功能的能力分级，其由**每小时危险失效的平均概率**$\mathrm{PFH}_D$定义：

| PL | $\mathrm{PFH}_D$（每小时） |
|---|---|
| a | $10^{-5}$至低于$10^{-4}$ |
| b | $3\times10^{-6}$至低于$10^{-5}$ |
| c | $10^{-6}$至低于$3\times10^{-6}$ |
| d | $10^{-7}$至低于$10^{-6}$ |
| e | $10^{-8}$至低于$10^{-7}$ |

达到的PL取决于架构的**类别**（B、1、2、3、4——从单通道到高诊断覆盖率冗余）、每个通道的**危险失效平均时间**、**诊断覆盖率**与针对**共因失效**的措施，以及系统性（设计与软件）故障的规避。每个安全功能**所需的**性能等级$\mathrm{PL_r}$由风险定出：标准的风险图谱使用严重度（S1轻微、S2严重）、暴露的频率或持续时间（F1、F2）与避免的可能性（P1、P2），从S1-F1-P1的$\mathrm{PL_r}$ a到S2-F2-P2的e。
:::

IEC 62061以**安全完整性等级**（SIL 1–3）为同样的功能分级，PL d大致对应SIL 2、PL e大致对应SIL 3。对工业机器人，ISO 10218-1的2011年版要求安全相关控制功能在3类架构上达到PL d，除非风险评估另有论证；这一要求被广泛用作基线，而每个功能的具体要求须查现行版本。

::: example 停止功能的性能等级 {#ex-pl}
一个保护性停止功能由串联的三个子系统组成：安全激光扫描仪（数据手册：PL d，$\mathrm{PFH}_D = 5.0\times10^{-8}\,\mathrm{h^{-1}}$）、安全控制器（PL e，$\mathrm{PFH}_D = 1.0\times10^{-9}\,\mathrm{h^{-1}}$）与双通道接线的驱动器STO（PL e，$\mathrm{PFH}_D = 1.2\times10^{-8}\,\mathrm{h^{-1}}$）。（这些数值仅为演示。）风险评估给出S2（可能重伤）、F2（频繁暴露）与P1（一定条件下可能避免）。要求哪个PL？功能又达到什么？
::: solution
**所需。**风险图谱上，S2-F2-P1给出$\mathrm{PL_r} = $ d。

**所达。**串联子系统的危险失效率相加：$\mathrm{PFH}_D = 5.0\times10^{-8} + 1.0\times10^{-9} + 1.2\times10^{-8} = 6.3\times10^{-8}\,\mathrm{h^{-1}}$。数值上这落在PL e段（$10^{-8}$到$10^{-7}$），但功能的定级不能高过其最弱子系统的PL：扫描仪是PL d，所以功能达到PL d。由于$\mathrm{PL} = \mathrm{PL_r}$，要求得到满足。

**合理性检验。**每小时$6.3\times10^{-8}$即约$1.6\times10^7$小时一次危险失效，合连续运行约1800年——而这只是单元里的一个功能。只有系统性要求（设计过程、软件验证、接线正确、定期试验）同时满足，这个数字才有意义；安全功能的真实失效多数是系统性的（被短接的联锁、错误的组态），而不是随机的。
:::
:::

## 协作运行 {#sec-collaborative}

协作意味着人在机械臂自动运行期间与臂在共享空间里工作。机器人标准与ISO/TS 15066描述了四条使这变安全的路子；一个应用可以把它们组合起来。

::: definition 四种协作运行模式 {#def-collab}
- **安全监控停止**（SMS）：人进入协作工作空间之前机械臂停止（2类，静止由安全控制器监视），人在期间保持停止；人离开后自动恢复。例：人装载夹具时机械臂等待。
- **手动引导**（HG）：操作者通过工具附近一个带使能开关与急停的导引装置直接用手移动机械臂，机械臂以安全额定的降低速度运行。例：借助机械臂定位重负载。
- **速度与分离监控**（SSM）：机械臂与人可以同时在工作空间里运动；传感器测量分离距离，安全控制器在分离降到保护性分离距离以下之前把臂减速并停止。
- **功率与力限制**（PFL）：允许机械臂（连同其工具与零件）接触人，但机械臂的设计与控制使一次接触传递的力、压强与能量保持在预期不致伤害的限值以下。
:::

### 速度与分离监控

SSM的思想是一场比赛：检测到有人接近时，机械臂必须能在人够到它之前停住——并且已经停住。**保护性分离距离**收纳了这场比赛里能被走完的所有距离。

::: proposition 保护性分离距离 {#prop-ssm}
设人以速度$v_h$接近而机械臂以速度$v_r$向其运动。设$T_r$是系统的反应时间（从传感器检测、处理与安全控制器反应直到开始停止），$T_s$是机械臂的停止时间，期间它走完停止距离$S_s$。那么检测时刻的分离至少应为
$$
S_p = \underbrace{v_h(T_r + T_s)}_{S_h} + \underbrace{v_rT_r}_{S_r} + S_s + C + Z_d + Z_r ,
$$ {#eq-ssm}
其中$C$是**侵入距离**（身体部位在被检测到之前能朝危险伸多远），$Z_d$是传感系统对人的位置不确定度，$Z_r$是机械臂的位置不确定度。这是ISO/TS 15066给出的形式，该标准也允许速度随时间变化。
:::

::: proof
在人被检测的时刻$t_0$，把人放在沿接近线距臂最近点$d$处。在$[t_0, t_0 + T_r]$期间系统尚未开始停止：人向臂走$v_hT_r$，臂向人走$v_rT_r$。停止期间，$[t_0 + T_r, t_0 + T_r + T_s]$，人再走$v_hT_s$，臂走完其停止距离$S_s$。若这些接近距离之和小于$d$，接触就不发生：$d > v_h(T_r + T_s) + v_rT_r + S_s$。检测出的位置，人可能有至多$Z_d$、机械臂可能有至多$Z_r$的误差，而且传感器可能在某个身体部位已越过被检测位置突出$C$之后才检测到人；把这些最坏情形加上即得[[#eq-ssm]]。假设是恒定（最坏情形）速度与直线接近；速度随时间变化时，乘积换成速度在同样区间上的积分。
:::

人的接近速度若不实测，取自ISO 13855（《相对于人体接近的安全防护装置的定位》）：行走接近$1.6\,\mathrm{m/s}$，短距离内的手与臂运动$2.0\,\mathrm{m/s}$。同一标准给出不同传感器的侵入距离；对在地面以上高度$H$（mm）的水平面检测腿部的激光扫描仪，给出$C = 1200\,\mathrm{mm} - 0.4H$，但不小于$850\,\mathrm{mm}$——这是一个大项，因为它计入了手臂越过检测平面向前伸。

::: example 带激光扫描仪的速度与分离监控 {#ex-ssm}
一台装在地板上的安全激光扫描仪在$H = 300\,\mathrm{mm}$处监控对某机械臂的接近。其测量不确定度$Z_d = 0.10\,\mathrm m$；机械臂的位置不确定度$Z_r = 0.02\,\mathrm m$。系统反应时间$T_r = 0.10\,\mathrm s$。全速$v_r = 1.0\,\mathrm{m/s}$时，机械臂公布的停止数据给出$T_s = 0.30\,\mathrm s$内$S_s = 0.15\,\mathrm m$（与恒定减速度$3.33\,\mathrm{m/s^2}$相符）。(a) 求保护性分离距离。(b) 按降低速度$0.25\,\mathrm{m/s}$重新计算，假设减速度相同。(c) 若换用一套直接跟踪人体、$C = 0.20\,\mathrm m$的传感系统，布局会怎样改变？（全部为演示数值。）
::: solution
(a) $C = 1200 - 0.4\times300 = 1080\,\mathrm{mm} = 1.08\,\mathrm m$（高于850 mm的下限）。取$v_h = 1.6\,\mathrm{m/s}$：$S_h = 1.6(0.10 + 0.30) = 0.64\,\mathrm m$，$S_r = 1.0\times0.10 = 0.10\,\mathrm m$，$S_s = 0.15\,\mathrm m$。总计：$S_p = 0.64 + 0.10 + 0.15 + 1.08 + 0.10 + 0.02 = 2.09\,\mathrm m$。

(b) $0.25\,\mathrm{m/s}$时：$T_s = 0.25/3.33 = 0.075\,\mathrm s$，$S_s = 0.25^2/(2\times3.33) = 0.0094\,\mathrm m$，$S_h = 1.6(0.10 + 0.075) = 0.28\,\mathrm m$，$S_r = 0.025\,\mathrm m$。总计：$S_p = 0.28 + 0.025 + 0.009 + 1.08 + 0.12 = 1.51\,\mathrm m$。典型布局把这套距离用作**警告区**：约2.1 m处机械臂减速到0.25 m/s；1.5 m处停止（安全监控停止）；人离开后恢复。

(c) $C = 0.20\,\mathrm m$时距离降为全速$1.21\,\mathrm m$、降速$0.63\,\mathrm m$。侵入距离是**传感器及其安装**的属性，曾是最大的单项——这就是直接人体跟踪（若能达到所需性能等级）允许单元紧凑得多的原因。

**合理性检验。**降速时人的项$S_h$与侵入距离占主导；机械臂自身运动的贡献不到4 cm。低于某个速度后，让臂再慢也省不下多少：剩下的距离是人在反应时间里的自身接近。缩短$T_r$在任何速度下都有帮助。
:::
:::

### 功率与力限制

PFL允许机械臂接触人。要区分两种接触：**瞬态接触**，自由空间中短暂的撞击、之后人的身体部位可以弹开（臂打到一只没被夹住的手），与**准静态接触**，身体部位被夹在机械臂与固定物之间，力一直持续到臂退让。夹持危险得多：没有回弹，而且只要臂还在推，力就一直上升。

ISO/TS 15066的附录A提供一个**人体模型**，把人体划分为区（头、躯干、臂、手、腿及其部位），为每一区给出准静态接触的最大许用压强与最大许用力，其由疼痛起始的研究导出。对瞬态接触它允许更高的值——多数区可到准静态值的两倍，头与面部另有更严的处理。它还为每一区给出有效质量与有效弹簧常数，以便把许用力换算成许可速度。表格本身必须取自该规范（或其在ISO 10218-2:2025中的后续内容）；本章不转载它们。

::: proposition 瞬态接触的许可速度（能量模型） {#prop-pfl}
把瞬态碰撞建模为两体撞击：身体区（有效质量$m_H$、弹簧常数$k$）被压缩到相对运动停止，全部相对动能存为弹性能。若机器人的有效质量为$m_R$、接触时相对速度为$v_{\mathrm{rel}}$，则峰值接触力为
$$
F = v_{\mathrm{rel}}\sqrt{\mu k},\qquad \mu = \left(\frac{1}{m_H} + \frac{1}{m_R}\right)^{-1},
$$ {#eq-pfl}
于是对许用力$F_{\max}$，许可相对速度为$v_{\max} = F_{\max}/\sqrt{\mu k}$。ISO/TS 15066把机器人的有效质量估计为$m_R = M/2 + m_L$，其中$M$是机器人运动部分的总质量，$m_L$是有效负载（工具与其加工件）。
:::

::: proof
在两体的质心参考系中，相对运动表现为一个以$v_{\mathrm{rel}}$运动、质量为$\mu = m_Hm_R/(m_H + m_R)$的单体；其动能为$\tfrac12\mu v_{\mathrm{rel}}^2$（质心的动能不受内部接触力改变，也存不起来）。最大压缩$x$处相对速度为零，若为线性弹簧$F = kx$且无损耗，则$\tfrac12\mu v_{\mathrm{rel}}^2 = \tfrac12kx^2 = F^2/(2k)$。解出$F = v_{\mathrm{rel}}\sqrt{\mu k}$。这些假设——线性刚度、无阻尼与塑性变形、身体区自由（未被夹住）、机器人保持速度直到最大压缩——使力的估计在多数情形偏保守，但对夹持无效，因为夹持时身体部位无法回弹。有效质量法则$M/2 + m_L$是对典型机械臂带动其工具的经验近似；对任何特定姿态它都不精确。
:::

::: example 瞬态手部接触的许可速度 {#ex-pfl}
一台协作臂运动部分总质量$M = 20\,\mathrm{kg}$，带着工具与工件共$m_L = 2\,\mathrm{kg}$。本例**假设**一个手部区，有效质量$m_H = 0.6\,\mathrm{kg}$、有效弹簧常数$k = 75\,\mathrm N/\mathrm{mm}$、瞬态许用力$280\,\mathrm N$（取这些值只为与规范的量级相当；真实设计取自标准）。求许可速度，并对$8\,\mathrm{kg}$负载重复一遍。
::: solution
$m_R = M/2 + m_L = 10 + 2 = 12\,\mathrm{kg}$。$\mu = (1/0.6 + 1/12)^{-1} = (1.667 + 0.083)^{-1} = 0.571\,\mathrm{kg}$。取$k = 75\times10^3\,\mathrm{N/m}$，$\sqrt{\mu k} = \sqrt{0.571\times75\,000} = 207\,\mathrm{N\,s/m}$，故$v_{\max} = 280/207 = 1.35\,\mathrm{m/s}$。

$m_L = 8\,\mathrm{kg}$时：$m_R = 18\,\mathrm{kg}$，$\mu = (1.667 + 0.056)^{-1} = 0.580\,\mathrm{kg}$，$\sqrt{\mu k} = 209\,\mathrm{N\,s/m}$，$v_{\max} = 1.34\,\mathrm{m/s}$——几乎没变，因为折合质量由更轻的身体主导，也就是手。对重的身体区（例如躯干，有效质量几十千克），机器人的质量占主导，许可速度随负载明显下降。

**合理性检验。**自由手瞬态接触用$1\,\mathrm{m/s}$量级的速度，而夹持情形与头部要低得多——这正是协作应用通常采用的。**压强**限值也必须校核：锋利的工具缘把同样的力聚到几平方毫米上，远未到力限值就可能超过许用压强——这就是协作工具要做成圆角、加衬垫的原因。
:::
:::

::: widget plot

x: 0.5, 40
y: 0, 3
sliders: F=280:50:500:10; k=75:5:150:5; m=0.6:0.5:40:0.1
labels: v_{\max}\ (\mathrm{m/s})
caption: 由[[#eq-pfl]]得出的许可相对速度对机器人有效质量$m_R$（kg）的曲线，身体区有效质量$m$（kg）、弹簧常数$k$（N/mm）、许用力$F$（N）——滑块取值全部为演示值，不取自标准。对轻的身体区（$m$小），曲线很快变平：增加负载改变不了多少。把$m$升到躯干量级，许可速度随机器人变重而持续下降。
:::

**夹持**需要不同的分析：限制力的不是能量，而是臂在检测到接触并退让之前推得多狠。协作臂由关节力矩传感器、或由实测电机电流与动力学模型预测之间的残差（动量观测器）检测接触，并反应为停止，最好再稍微倒退以松开被困的部位。在检测到之前，被夹的身体部位一直按臂的速度被压缩。

::: example 夹持期间的力超调 {#ex-clamp}
一台以$0.5\,\mathrm{m/s}$运动的臂向靠在夹具上的一只手合拢。接触检测从首次接触算起、到开始停止耗时$10\,\mathrm{ms}$；手的弹簧常数取$75\,\mathrm{N/mm}$（假设）。估计臂甚至还没来得及开始停止时已达到的夹持力，以及把它保持在$140\,\mathrm N$以下（本例假设的限值）所允许的臂速。
::: solution
若臂在检测前保持速度，压缩量$x = vt_d = 0.5\times0.010 = 5\,\mathrm{mm}$，力$kx = 75\times5 = 375\,\mathrm N$——这还没算制动，而臂的停止距离还要往上加。要低于$140\,\mathrm N$，压缩必须小于$140/75 = 1.87\,\mathrm{mm}$，即$v < 1.87\,\mathrm{mm}/10\,\mathrm{ms} = 0.187\,\mathrm{m/s}$，计入检测后的停止距离还要更低。**合理性检验。**这就是有夹持危险的应用在夹持区低速运行、或干脆消除夹持几何（工具运动可及之处不设固定面，或留最小间隙）的原因，后者才是本质安全的解法。
:::
:::

::: remark 用测量验证PFL
算出来的速度只是起点。ISO/TS 15066及其后的实践通过在实际危险点用仿人体测量装置**测量**接触力与压强来验证PFL应用——那是带弹簧与阻尼垫、模仿身体区刚度的测力计，配压强敏薄膜——按真实程序的速度、负载与位姿测。程序、工具或布局有任何变更后都要重复测量，因为PFL是整个应用的属性，不是机械臂的属性。
:::

## 拼在一起 {#sec-together}

一个安全的协作应用跨层组合各项措施：

- **机械臂**（制造商，ISO 10218-1）：带限制功能的安全额定控制器（位置、速度、力、功率、动量）、带监视减速的1、2类停止、STO与安全制动控制、可靠的接触检测、公布的停止数据、解救被困人员的手段。
- **工具与工件**（集成商，ISO 10218-2）：圆角、带衬垫的几何；能在急停中保住的夹持（[[robot-arm-design/end-effectors]]）；夹爪力受限或手指夹点有护罩；工件上没有锐边，无法避免时改用别的协作模式。
- **布局**：没有夹持几何，或在近旁降速；按[[#eq-ssm]]布置传感器；协作与非协作区域界限分明。
- **验证**：每个安全功能都经过试验，PL算出并记录在案，力经过测量，使用信息写成文件，并且任何变更后整体重新验证。

::: quiz
某集成商买了一台标榜“协作”的机械臂，装上一个带切包装胶带刀片的夹爪。对应用的安全这意味着什么？
- [ ] 什么都不意味着：臂通过了协作认证，应用也就通过了。
- [ ] 只需把夹爪的质量填进机械臂的负载设置。
- [x] 需要一次新的风险评估；刀片造成切割危险，功率与力限制对付不了，所以在人能够到之处需要另一种方法（防护、速度与分离监控或监控停止）。
- [ ] 把臂的力限值调低，直到刀片安全。
::: solution
协作是**应用**的属性：机械臂、工具、工件、任务与布局加在一起。刀片把力聚到极小面积上，机械臂能派上用场的任何力都会超过许用压强；限力不可能让它安全。风险评估必须覆盖刀片，而应用必须防止与它接触——例如刀片暴露时把人挡在可及之外，或用可缩回、带护罩的刀片。
:::
:::

::: history
1979年1月25日，Robert Williams在福特汽车位于密歇根州弗拉特罗克（Flat Rock）的铸造厂被一台取件机器人撞倒身亡——这是有记录的第一起工业机器人致死事故；1981年，Kenji Urada在日本川崎重工的一家工厂里、在一台机器人的动作包络内作业时遇难。此类事故催生了第一部机器人安全标准ANSI/RIA R15.06（1986年于美国发布），以及ISO 10218——1992年首发，其后分为机器人部分（2006年）与机器人系统部分（2011年）。2011年版把协作运行引入标准，2016年ISO/TS 15066跟进，附其基于疼痛阈值研究、用于功率与力限制的人体模型。其间，功能安全已由IEC 61508（1998–2000年）与ISO 13849-1（2006年）建立在概率基础上；修订后的ISO 10218两部分于2025年出现。
:::

::: summary
- 从覆盖生命周期所有阶段与所有使用者的ISO 12100风险评估出发；先本质安全设计、再安全防护、后使用信息来减小风险；要迭代，因为措施会制造危险。
- ISO 10218-1（机器人）与-2（应用与集成），2025年修订——修订把协作视为应用的属性、吸收ISO/TS 15066的指南、增加网络安全要求；以现行文本为准。手动降速$250\,\mathrm{mm/s}$、三位使能装置、公布的停止数据。
- IEC 60204-1停止类别：0（断电、抱闸）、1（受控停止后断电）、2（受控停止、保持供电）；驱动器里的STO、SS1、SS2/SOS、SLS、SBC（IEC 61800-5-2）。1类通常停得更短且留在路径上，但距离必须按保证的停止来算。
- 安全功能跑在带STO与制动器的安全额定冗余控制器里，不在运动软件里。PL a–e按$\mathrm{PFH}_D$定级（d为$10^{-7}$–$10^{-6}$，e为$10^{-8}$–$10^{-7}$）；串联率相加；最弱子系统的PL限制整个功能。机器人安全功能典型为PL d、3类架构。
- 协作模式：安全监控停止、手动引导、速度与分离监控、功率与力限制。
- SSM：$S_p = v_h(T_r + T_s) + v_rT_r + S_s + C + Z_d + Z_r$，行走$v_h = 1.6\,\mathrm{m/s}$，取自ISO 13855；侵入距离$C$常常占主导。
- PFL：身体区的力与压强限值（ISO/TS 15066附录A）；瞬态接触$F = v_{\mathrm{rel}}\sqrt{\mu k}$，$m_R = M/2 + m_L$；夹持受检测时间与速度限制；以测量验证。
:::

## 习题

::: exercise 人的项 {level=1 check="0.528"}
一个速度与分离计算中，反应时间为$0.08\,\mathrm s$、臂停止时间为$0.25\,\mathrm s$。取$v_h = 1.6\,\mathrm{m/s}$，求人走完的距离$S_h$。（输入$S_h$，以m为单位。）
::: solution
$S_h = v_h(T_r + T_s) = 1.6\times(0.08 + 0.25) = 0.528\,\mathrm m$。

::: exercise 降速下的停止距离 {level=1 check="31.25"}
某臂以$4\,\mathrm{m/s^2}$的恒定减速度停止。从$0.5\,\mathrm{m/s}$起的制动距离是多少（不含反应时间）？（输入距离，以mm为单位。）
::: solution
$v^2/(2a) = 0.25/8 = 0.03125\,\mathrm m = 31.25\,\mathrm{mm}$。从$1.0\,\mathrm{m/s}$起会是四倍，$125\,\mathrm{mm}$。
:::

::: exercise 机器人的有效质量 {level=1 check="18"}
按ISO/TS 15066的近似，运动部分共$30\,\mathrm{kg}$、带$3\,\mathrm{kg}$工具与工件的机械臂，有效质量是多少？（输入质量，以kg为单位。）
::: solution
$m_R = M/2 + m_L = 15 + 3 = 18\,\mathrm{kg}$。
:::

::: exercise 扫描仪的侵入距离 {level=1 check="1040"}
一台安全激光扫描仪在地面以上$400\,\mathrm{mm}$的水平面检测腿部。ISO 13855的规则$C = 1200\,\mathrm{mm} - 0.4H$（下限$850\,\mathrm{mm}$）给出什么侵入距离？（输入$C$，以mm为单位。）
::: solution
$C = 1200 - 0.4\times400 = 1040\,\mathrm{mm}$，高于下限。抬高扫描面会减小$C$，但面太高会允许人从下面爬入，所以标准限制了高度。
:::

::: exercise 串联失效率 {level=2 check="4e-8"}
某安全功能串联使用光幕（$\mathrm{PFH}_D = 2.0\times10^{-8}\,\mathrm{h^{-1}}$，PL e）、安全继电器（$5.0\times10^{-9}$，PL e）与驱动器STO（$1.5\times10^{-8}$，PL e）。求总$\mathrm{PFH}_D$与PL。（输入总值，以h⁻¹为单位。）
::: solution
$2.0\times10^{-8} + 0.5\times10^{-8} + 1.5\times10^{-8} = 4.0\times10^{-8}\,\mathrm{h^{-1}}$，落在PL e段（$10^{-8}$到低于$10^{-7}$），且每个子系统都是PL e，所以在系统性要求满足的前提下功能可达PL e。
:::
:::

::: exercise 许可速度 {level=2 check="1.12"}
假设（演示数值）某身体区有效质量$3.0\,\mathrm{kg}$、弹簧常数$25\,\mathrm{N/mm}$，瞬态许用力$280\,\mathrm N$，机器人有效质量$15\,\mathrm{kg}$。按[[#eq-pfl]]许可相对速度是多少？（输入速度，以m/s为单位。）
::: solution
$\mu = (1/3 + 1/15)^{-1} = (0.4)^{-1} = 2.5\,\mathrm{kg}$；$\sqrt{\mu k} = \sqrt{2.5\times25\,000} = 250\,\mathrm{N\,s/m}$；$v_{\max} = 280/250 = 1.12\,\mathrm{m/s}$。
:::
:::

::: exercise 检测延时造成的夹持力 {level=2 check="150"}
以$0.25\,\mathrm{m/s}$运动的臂需要$8\,\mathrm{ms}$来检测夹持接触。设身体刚度为$75\,\mathrm{N/mm}$（假设），若臂在那之前保持速度，检测时达到什么力？（输入力，以N为单位。）
::: solution
$x = 0.25\times0.008 = 2.0\,\mathrm{mm}$；$F = 75\times2.0 = 150\,\mathrm N$。检测时间或速度减半，力也减半；检测后的停止距离还要往上加。
:::

::: exercise 所需性能等级 {level=2}
对每种危险情形，按[[#def-pl]]描述的风险图谱求$\mathrm{PL_r}$（S2-F2-P2 → e，S2-F2-P1 → d，S2-F1-P2 → d，S2-F1-P1 → c，S1-F2-P2 → c，S1-F2-P1 → b，S1-F1-P2 → b，S1-F1-P1 → a）：(a) 维护技师偶尔进入一台50 kg负载机械臂的单元；(b) 操作员每小时多次在一台小型协作臂旁边装卸夹具，手指可能被夹爪夹到；(c) 旁观者走过一个单元边界，那里一条慢速输送机可能卷住衣袖。为每个参数给出理由。
::: solution
(a) 重臂可能造成严重、不可逆的伤害（S2）；进入是偶然且短暂的（F1）；这样的臂运动快于人能反应的速度，避免可能性小（P2）：PL d。(b) 小夹爪夹手通常是轻微、可逆的伤害（S1）——前提是夹爪力有限；暴露频繁（F2）；操作员看得见慢速夹爪，可以避免（P1）：PL b——但若夹爪能挤碎东西（高力），则适用S2，结果为PL d。(c) 输送机卷入可能严重（S2），过路者暴露频繁（F2），但低速下可以避免（P1）：PL d。本练习的要旨是参数必须论证并记录在案；边界上的选择要保守。
:::

::: exercise 速度可变时分离距离的推导 {level=3}
把[[#prop-ssm]]推广到臂在停止期间对人的速度在$T_s$内从$v_r$线性降到零、而人的速度为$v_h(t)$的情形。证明臂的项变成$v_rT_r + \tfrac12v_rT_s$，并解释为什么ISO/TS 15066仍然要求用**实测**的停止距离$S_s$而不是这个公式。
::: solution
臂接近$\int_{t_0}^{t_0 + T_r}v_r\,dt + \int_{t_0 + T_r}^{t_0 + T_r + T_s}v_r\bigl(1 - (t - t_0 - T_r)/T_s\bigr)dt = v_rT_r + \tfrac12v_rT_s$，人接近$\int_{t_0}^{t_0 + T_r + T_s}v_h(t)\,dt$，匀速时化简为$v_h(T_r + T_s)$。故匀减速时$S_s = \tfrac12v_rT_s$。真实机械臂不是匀减速：停止距离取决于位姿（惯量）、负载、哪些关节在动、停止类别；制动器有接合延时，力矩随温度与磨损而变；要紧的距离是臂上离人最近点的距离，不是工具的。因此标准要求按相关条件测得的停止数据（取制造商数据，或在应用中实测），安全控制器还可以监视停止性能，不达标就更狠地停臂。
:::
:::

::: exercise 一台协作码垛机的安全方案 {level=3}
一台协作臂在包装线末端码放12 kg的纸箱。操作者在臂两侧的两个工位更换满垛，约每20分钟一次，期间臂继续在另一垛上工作。提出一个安全方案：危险、各区域的协作模式、传感器及其布置、速度、安全功能及其PL，以及你会用测量验证什么。说明假设。
::: solution
一个合理方案。**危险**：臂与纸箱的撞击（负载重：12 kg加夹爪，PFL限值会被迫把速度压得极低）；纸箱与托盘或立柱之间的夹持；真空夹爪掉箱；换垛区。**模式**：主运动不用PFL——负载太重、运动太快。用区域感知的SSM（或按区的SMS）：每个工位一台安全激光扫描仪，或工位入口带屏蔽的光幕，把每侧划成警告区（臂减速到一个降速值，并用安全位置限制把自己限制在远侧托盘上）与保护区（臂在这一侧或能够到这一侧时停止）。**距离**：按[[#eq-ssm]]用降速满载下实测的停止数据、ISO 13855的接近速度与侵入距离、扫描仪的容差区来算；臂的安全区限制使其物理上留在远侧，只要人在近侧托盘，人便从不分享可及空间。**安全功能**：保护性停止（带监视减速的1类，兜底0类）、安全位置限制（对被占一侧的禁入区）、安全速度限制、真空丧失检测——夹爪设计为急停中保住，或给纸箱加机械托承。每个$\mathrm{PL_r}$由风险图谱定——很可能是d（S2、F2、P1）——按3类实现。**验证**：每个区、每个功能的功能试验；配置速度与负载下停止距离的测量；用最重纸箱在最大伸展下校核区域限制；定期复检（扫描仪区域、制动试验）。本方案是应用本章原理的示例；真实的码垛机由合格工程师按现行标准设计并验证。
:::

## 延伸阅读

标准本身——ISO 12100、ISO 10218-1与-2（现行版本）、ISO/TS 15066、ISO 13849-1与-2、ISO 13850、ISO 13855、IEC 60204-1与IEC 61800-5-2——是第一手资料，设计时必须使用。《机器人手册》（Springer Handbook of Robotics）的机器人安全一章讲解协作安全的背景与其下的伤害研究。各国的职业安全机构与机器人行业协会发布指南与案例研究，展示标准如何落到真实单元上。
