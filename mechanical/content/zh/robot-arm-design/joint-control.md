[[robotics/robot-control]]用一个刚性关节与理想转矩说明了为什么带重力补偿的PD控制管用、计算力矩控制又添了什么。真实关节并不是那个被控对象。它的转矩要经过一个有带宽、有延时的电流环；它的位置由一台有分辨率的编码器测得，并以有限速率采样；它的减速器有会黏会滑的摩擦，还有一根弹簧让连杆能相对电机振铃；而它的惯量在收臂与伸臂之间会变化好几倍。本章讲的正是控制这样的关节：几乎每台伺服驱动器都采用的电流、速度、位置三环**级联**，如何为它们选择带宽并在实机上整定，把一台够用的伺服变成一台好伺服的三项添加——**前馈**、**重力补偿**与**摩擦补偿**——以及最后，如何与**关节柔顺**及共振相处，靠陷波滤波器与明智的带宽上限。贯穿全章的例子是[[robot-arm-design/arm-specification]]中规定的机械臂的肩关节，电机取自[[robot-arm-design/joint-actuators]]，应变波减速器取自[[robot-arm-design/gear-reducers]]。经典控制背景——PID、伯德图、稳定裕度、采样数据系统——见[[control-systems/pid-control]]、[[control-systems/frequency-response]]与[[control-systems/digital-control]]。

## 级联 {#sec-cascade}

::: definition 级联的关节伺服 {#def-cascade}
**级联**关节伺服由三个嵌套环组成，每个环调节一个量，其参考值来自包住它的外环的输出：
- **电流（转矩）环**，最内层：用磁场定向控制调节电机中的$i_q$（与$i_d$），参考值来自速度环；
- **速度环**：调节电机转速，通常用PI控制器，参考值来自位置环；
- **位置环**，最外层：调节关节角，通常用比例控制器，参考值来自轨迹发生器。
轨迹的前馈项（速度、转矩）加到内环的输入上。
:::

这种安排不是口味问题。每个内环都使下一个外环看到的被控对象更简单：电流环把一台带有电阻、电感与反电动势的电机变成近乎理想的转矩源；速度环把一台带有摩擦与扰动的惯量变成近乎理想的速度源。每个环都有一个顺理成章的位置来施加限值——最大电流、最大转速——使饱和在它发生的地方被处理。而且这些环可以从内向外逐一整定。

代价是每个环必须比包住它的环快得多，否则外环会把内环的动态当作未建模的滞后。通常的规则是相邻两环之间保持约$3$到$10$倍的**带宽分离**。机械臂关节中的典型数值（截至2026年）：

| 环 | 采样率 | 闭环带宽 | 控制器 | 运行于 |
|---|---|---|---|---|
| 电流 | 10–40 kHz（PWM同步） | 1–3 kHz | 每轴PI（$d$、$q$） | 驱动器 |
| 速度 | 2–10 kHz | 20–200 Hz（电机侧；柔顺关节更低） | PI（+滤波器） | 驱动器 |
| 位置 | 1–8 kHz | 5–30 Hz | P（+前馈） | 驱动器或关节控制器 |
| 轨迹/插补 | 250 Hz–1 kHz | — | 经现场总线下发设定点 | 机器人控制器 |

带宽每环大致低十倍，而位置环那几赫兹到几十赫兹的带宽，就是用户所感受到的机械臂的刚度与跟踪精度。低端适用于带柔顺应变波关节的轻型机械臂；刚硬的工业机械臂能达到高端。

## 电流环 {#sec-current}

磁场定向电流控制器（[[robot-arm-design/joint-actuators]]）的每个轴，在解耦前馈之后看到的被控对象，是从电压到电流的$1/(R + Ls)$。

::: proposition 用零极点对消整定的PI电流环 {#prop-current-loop}
对于被控对象$G(s) = 1/(R + Ls)$与PI控制器$C(s) = K_p + K_i/s$，取
$$
K_p = \omega_cL,\qquad K_i = \omega_cR
$$ {#eq-current-pi}
开环就成为$\omega_c/s$，闭环成为一阶系统$\omega_c/(s + \omega_c)$，带宽为$\omega_c$，无延时时的相角裕度为$90°$。回路中的一个纯时间延时$T_d$会把相角裕度降到$90° - \omega_cT_d$（以度计，其中$\omega_cT_d$由弧度换算）。
:::

::: proof
$C(s)G(s) = \dfrac{K_ps + K_i}{s}\cdot\dfrac{1}{Ls + R} = \dfrac{K_p(s + K_i/K_p)}{sL(s + R/L)}$。当$K_i/K_p = R/L$时两因子对消，剩下$K_p/(Ls) = \omega_c/s$。闭环为$\dfrac{\omega_c/s}{1 + \omega_c/s} = \dfrac{\omega_c}{s + \omega_c}$。开环幅值在$\omega = \omega_c$处为$1$、相角为$-90°$，裕度$90°$。延时把开环乘以$e^{-sT_d}$，其幅值为1、相角为$-\omega T_d$，它不移动穿越频率，并在该处从相角中减去$\omega_cT_d$。
:::

限制带宽的正是延时。数字电流环测量电流、计算、在下一个PWM周期施加新的占空比；从测量到生效的延时典型约为$1.5$个采样周期（一拍用于计算与更新，半拍用于PWM的零阶保持）。

::: example 整定肩关节的电流环 {#ex-current}
肩关节电机的相电阻$R = 0.033\,\Omega$、电感$L = 0.10\,\mathrm{mH}$；驱动器的PWM与电流采样运行在$20\,\mathrm{kHz}$。求电流环带宽为$2\,\mathrm{kHz}$与$1\,\mathrm{kHz}$时的PI增益，以及各自的相角裕度。
::: solution
延时$T_d = 1.5/20\,000 = 75\,\mathrm{\mu s}$。

$2\,\mathrm{kHz}$：$\omega_c = 12\,566\,\mathrm{rad/s}$；$K_p = 12\,566\times1.0\times10^{-4} = 1.26\,\mathrm{V/A}$，$K_i = 12\,566\times0.033 = 415\,\mathrm{V/(A\,s)}$。延时耗去的相角$\omega_cT_d = 0.942\,\mathrm{rad} = 54°$：裕度$36°$——太少；电流会超调、振铃。

$1\,\mathrm{kHz}$：$K_p = 0.628\,\mathrm{V/A}$，$K_i = 207\,\mathrm{V/(A\,s)}$；延时耗去$27°$，裕度$63°$——一个阻尼良好的环。

**经验法则。**有$1.5$拍延时时，电流环带宽取PWM频率的约$1/20$，可得舒适的裕度。$1\,\mathrm{kHz}$的环仍然比下文要设计的速度环快二十倍，因此速度环可以把转矩当作瞬时的。
:::
:::

两个实际要点。增益取决于$L$与$R$，而它们在变：大电流下铁心饱和使$L$下降，绕组由冷变热使$R$上升$40\,\%$。因此零极点对消只是近似的，驱动器要么按电流与温度调度增益，要么接受裕度的部分损失。而且电流环的整定必须把电压极限放在心上：当反电动势用尽了母线电压时（[[robot-arm-design/joint-actuators]]），电流环饱和，必须对它的积分器做抗饱和处理。

## 速度环 {#sec-velocity}

对于理想的转矩源，刚性关节从电机转矩$T_m$到电机转速$\omega_m$看到的机械被控对象，是折算到电机侧的总惯量，
$$
J_{\text{tot}} = J_m + \frac{J_L}{N^2},
$$
再加上摩擦。对伸臂状态的肩部，$J_{\text{tot}} = 1.2\times10^{-4} + 7.03/100^2 = 8.23\times10^{-4}\,\mathrm{kg\,m^2}$；收臂空载时$J_L$可能降到五分之一，$J_{\text{tot}}$降到约$2.6\times10^{-4}$。速度环必须在这一范围内工作。

刚性被控对象$1/(J_{\text{tot}}s)$上的PI速度控制器$T_m^* = K_v\bigl(1 + \omega_i/s\bigr)(\omega_m^* - \omega_m)$给出开环
$$
L(s) = \frac{K_v}{J_{\text{tot}}s}\left(1 + \frac{\omega_i}{s}\right),
$$ {#eq-velocity-loop}
当$\omega_i \ll \omega_v$时，它大约在$\omega_v = K_v/J_{\text{tot}}$处穿越1。积分转折频率$\omega_i$取在低于穿越频率约$4$倍处（在该处损失约$14°$相角），用来消除稳态扰动——首先最重要的是重力与摩擦——而不侵蚀裕度。

**速度测量。**速度并不是测出来的，而是由编码器位置差分算出来的，$\hat\omega = \Delta\theta/T_s$，这把速度量化到每采样周期一个计数的台阶：一部17位电机编码器以$4\,\mathrm{kHz}$采样，给出电机侧$2\pi/2^{17}\times4000 = 0.19\,\mathrm{rad/s}$的台阶。高速度增益会把这一量化放大成转矩噪声与听得见的嘶声，所以速度估计要滤波（或由观测器得到），而滤波器的相位滞后会加入延时预算。高分辨率的电机编码器对速度环的意义不亚于对位置。

## 关节柔顺与共振 {#sec-flexibility}

刚性模型在关节的扭转共振频率之上失效。减速器与关节结构在电机与连杆之间充当弹簧（[[robot-arm-design/gear-reducers]]），而速度环测的是电机，不是连杆。

::: proposition 从电机侧看双质量关节 {#prop-two-mass}
设电机惯量$J_m$经比为$N$、扭转刚度为$k$（在输出侧）的减速器连到惯量为$J_L$的连杆上，并与弹簧并联阻尼$c$。折算到电机侧（$J_L' = J_L/N^2$，$k' = k/N^2$，$c' = c/N^2$），从电机转矩到电机转速的传递函数为
$$
\frac{\omega_m}{T_m}(s) = \frac{J_L's^2 + c's + k'}{s\,\bigl[J_mJ_L's^2 + (J_m + J_L')(c's + k')\bigr]}.
$$ {#eq-two-mass}
它在$\omega_a = \sqrt{k'/J_L'} = \sqrt{k/J_L}$处有一个**反共振**（一对阻尼很弱的零点），在$\omega_r = \sqrt{k'(1/J_m + 1/J_L')} = \omega_a\sqrt{1 + r}$处有一个**共振**（一对阻尼很弱的极点），其中$r = J_L'/J_m$是**惯量比**。相对于刚性模型$1/(J_{\text{tot}}s)$，远低于$\omega_a$处增益不变，远高于$\omega_r$处增益高$1 + r$倍。
:::

::: proof
电机侧的运动方程，$\theta_m$与$\theta_L'$为电机角与乘以$N$的连杆角：$J_m\ddot\theta_m = T_m - k'(\theta_m - \theta_L') - c'(\dot\theta_m - \dot\theta_L')$，且$J_L'\ddot\theta_L' = k'(\theta_m - \theta_L') + c'(\dot\theta_m - \dot\theta_L')$。拉氏形式下，第二式给出$\theta_L' = \dfrac{c's + k'}{J_L's^2 + c's + k'}\theta_m$。代入第一式：$T_m = \theta_m\left[J_ms^2 + (c's + k')\dfrac{J_L's^2}{J_L's^2 + c's + k'}\right]$，于是$\dfrac{\theta_m}{T_m} = \dfrac{J_L's^2 + c's + k'}{s^2[J_mJ_L's^2 + (J_m + J_L')(c's + k')]}$，而$\omega_m = s\theta_m$即得[[#eq-two-mass]]。当$c' = 0$，分子在$s^2 = -k'/J_L'$处为零，方括号在$s^2 = -k'(J_m + J_L')/(J_mJ_L')$处为零，即$\omega_a^2$与$\omega_r^2$；二者之比为$(J_m + J_L')/J_m = 1 + r$。当$s \to 0$，函数趋于$1/[(J_m + J_L')s]$，即刚性模型；当$s \to \infty$，它趋于$1/(J_ms)$，即大了$(J_m + J_L')/J_m = 1 + r$倍。
:::

物理图像是：低频下电机与连杆一起运动。在$\omega_a$处，连杆在弹簧上以反相摆动而电机几乎没有动作——电机编码器什么也看不见，连杆却在振荡——在$\omega_r$之上，弹簧隔开了连杆，电机只看到自己的惯量。对肩部，$k = 7.8\times10^4\,\mathrm{N\,m/rad}$、$J_L = 7.03\,\mathrm{kg\,m^2}$给出$f_a = 16.8\,\mathrm{Hz}$；由$r = 0.703/0.12 = 5.86$，$f_r = 16.8\sqrt{6.86} = 43.9\,\mathrm{Hz}$。

三条推论左右着整定。

1. **增益裕度缩小$1 + r$倍。**在刚性模型上设计的速度环，其真实的高频穿越在$K_v/J_m$而非$K_v/J_{\text{tot}}$，比设计值高$1 + r$倍，而那里延时与滤波器要花去多得多的相角。大惯量比——轻电机经高传动比驱动沉重的伸臂——正是关节调不硬的经典原因。伺服实践中的经验法则把舒适范围定在$r$低于约$5$到$10$。
2. **负载只在反共振以下受控。**在$\omega_a$以上电机与连杆不再一起运动，于是带宽超过$\omega_a$的速度环紧控着电机，而连杆却在振铃。因此柔顺关节速度环的实际带宽保持在$\omega_a$及以下，位置环带宽还要比它低$3$倍以上。
3. **其他每一个共振也要检查。**联轴器、电机安装座、连杆的弯曲模态与基座都会增添模态。高于速度穿越频率的模态，只要其共振峰把回路增益在相角恶劣的地方抬到1以上，就仍会引起振荡；这正是**陷波滤波器**的用处。

::: definition 陷波滤波器 {#def-notch}
以$\omega_n$为中心的**陷波滤波器**是二阶的
$$
F(s) = \frac{s^2 + 2\zeta_z\omega_ns + \omega_n^2}{s^2 + 2\zeta_p\omega_ns + \omega_n^2},\qquad \zeta_z < \zeta_p ,
$$ {#eq-notch}
远离$\omega_n$处增益为1，深度为$\lvert F(j\omega_n)\rvert = \zeta_z/\zeta_p$，宽度随$\zeta_p$增大。它与速度控制器串联，用来抵消被控对象的一个共振峰。它在$\omega_n$以下添加相位滞后，在其以上添加相位超前。
:::

::: example 肩关节的速度环与陷波 {#ex-velocity}
按刚性模型带宽$15\,\mathrm{Hz}$（略低于$f_a = 16.8\,\mathrm{Hz}$）设计肩关节的PI速度环，取$J_{\text{tot}} = 8.23\times10^{-4}\,\mathrm{kg\,m^2}$。求真实的高频穿越频率。频率扫描随后显示第二个模态——电机安装座共振——在$380\,\mathrm{Hz}$，峰值比刚性直线高$15\,\mathrm{dB}$。若速度环运行在$4\,\mathrm{kHz}$、总延时$375\,\mathrm{\mu s}$，回路会在那里振荡吗？设计一个陷波来压制它，并求出它在穿越频率处的相角代价。
::: solution
**增益**：$\omega_v = 2\pi\times15 = 94.2\,\mathrm{rad/s}$，$K_v = \omega_vJ_{\text{tot}} = 0.0776\,\mathrm{N\,m\,s/rad}$（电机侧），$\omega_i = \omega_v/4 = 23.6\,\mathrm{rad/s}$。

**真实穿越**：$f_r = 43.9\,\mathrm{Hz}$以上被控对象为$1/(J_ms)$，所以开环在$K_v/J_m = 0.0776/1.2\times10^{-4} = 647\,\mathrm{rad/s} = 103\,\mathrm{Hz}$处穿越1。那里延时耗去$647\times375\times10^{-6} = 0.243\,\mathrm{rad} = 14°$，PI的积分项约$2°$——裕度仍然不错，但回路的穿越比设计值高七倍，这就是噪声与量化比刚性设计预测更糟的原因。

**380 Hz模态**：在高频直线上，$380\,\mathrm{Hz}$处的回路增益为$103/380 = 0.27$，即$-11.3\,\mathrm{dB}$；共振峰加上$15\,\mathrm{dB}$，得$+3.7\,\mathrm{dB}$——在1以上。那里的相角约$-90°$来自类积分器的被控对象，$-51°$来自延时（$2\pi\times380\times375\times10^{-6}\,\mathrm{rad}$），再经共振本身还可多至$-180°$：回路极有可能在约$380\,\mathrm{Hz}$振荡——听起来是关节的一声尖啸。

**陷波**：中心$f_n = 380\,\mathrm{Hz}$，$\zeta_z = 0.05$，$\zeta_p = 0.5$：深度$0.05/0.5 = 0.1$（$-20\,\mathrm{dB}$），把峰压到$3.7 - 20 = -16.3\,\mathrm{dB}$。由[[#eq-notch]]取$s = j2\pi\times103$，它在$103\,\mathrm{Hz}$穿越处的代价：幅值$-0.35\,\mathrm{dB}$，相角$-14.6°$。穿越处的总相位滞后升到约$31°$，仍留下接近$60°$的裕度。

**注意事项。**结构模态的频率随机械臂的位姿与负载而变。比这一变化更窄的陷波在其他位姿下毫无用处；要么把陷波做宽（更大的$\zeta_p$，更多的相角代价），要么随位姿调度，要么从机械上消除该模态（更硬的安装座）。
:::
:::

## 位置环与前馈 {#sec-position}

速度环带宽为$\omega_v$时，位置环看到的大约是一个积分器：速度指令进、位置出。于是比例控制器$\omega^* = K_{pp}(q_d - q)$给出带宽为$K_{pp}$的一阶闭环，它必须远低于$\omega_v$（低$3$到$5$倍）。

::: proposition 比例位置环的跟随误差 {#prop-following}
若速度环是理想的、位置环为$\dot q = K_{pp}(q_d - q) + \dot q_{ff}$，则对以恒定速度$v$运动的参考：
- 无前馈（$\dot q_{ff} = 0$）时，稳态跟随误差为$e = q_d - q = v/K_{pp}$；
- 有速度前馈$\dot q_{ff} = \dot q_d$时，误差衰减到零。
:::

::: proof
误差满足$\dot e = \dot q_d - \dot q = \dot q_d - \dot q_{ff} - K_{pp}e$。无前馈且$\dot q_d = v$时：$\dot e = v - K_{pp}e$，其稳态为$e = v/K_{pp}$。有$\dot q_{ff} = \dot q_d$时：$\dot e = -K_{pp}e$，所以$e(t) = e(0)e^{-K_{pp}t} \to 0$。
:::

$K_{pp} = 30\,\mathrm{s^{-1}}$（带宽$4.8\,\mathrm{Hz}$）、肩关节以$3.14\,\mathrm{rad/s}$运动时，无前馈的跟随误差将是$3.14/30 = 0.105\,\mathrm{rad} = 6°$——工具处$94\,\mathrm{mm}$。单靠反馈去跟踪一条快路径毫无指望；反馈在那里是为了纠正误差，而**前馈**负责干活：

- **速度前馈**：把$\dot q_d$（折算到电机侧要乘$N$）加到速度参考上。
- **转矩（加速度）前馈**：把轨迹所需的、由机械臂模型算出的转矩加到电流参考上：$\boldsymbol\tau_{ff} = M(\mathbf q_d)\ddot{\mathbf q}_d + C(\mathbf q_d, \dot{\mathbf q}_d)\dot{\mathbf q}_d + \mathbf g(\mathbf q_d) + \boldsymbol\tau_f(\dot{\mathbf q}_d)$——即把[[robotics/robot-control]]的计算力矩律当前馈用，使速度环的积分器不必从误差中攒出加速力矩。即便粗略的版本（只取对角惯量，$m_{kk}\ddot q_{d,k}$）也能消掉加速期间的大部分误差。

前馈需要一条平滑的轨迹——加速度至少连续，最好加加速度有界（[[robotics/trajectory-planning]]）——因为加速度指令里的阶跃会变成转矩里的阶跃，激励关节共振。

**用哪个编码器来闭位置环？**位置环若用电机编码器，它快、与电机同位（collocated），却对减速器的扭转与传动误差视而不见。位置环若用双编码器关节的输出编码器（[[robot-arm-design/joint-actuators]]），它控制的正是用户在意的连杆角，但回路现在跨过柔顺的减速器（不同位），其带宽必须远低于$\omega_a$才能保持稳定。常见的折中：速度环用电机编码器，位置环用电机编码器再加一个经缓慢滤波的修正量，其大小等于两个编码器之差。

## 重力补偿 {#sec-gravity}

重力是大、缓变、随构型而变的力矩。没有模型时，速度环的积分器必须供出它，这在稳态是管用的，却有两个坏影响：快速运动期间积分器跟不上变化的重力力矩；上电时——或抱闸任何时候松开时——机械臂会下坠，直到积分器攒够了输出。

**重力补偿**把由机械臂质量模型算出的$\mathbf g(\mathbf q)$直接加到转矩指令上（[[robotics/robot-control]]证明了PD加重力补偿对刚性机械臂是全局稳定的）。它的精度取决于已知负载：距离$d$处一块质量误差$\Delta m$会留下$\Delta m\,g\,d$的转矩误差让积分器去消除。因此机械臂都让用户输入负载及其质心，或在若干试验位姿下由关节力矩估计它们。

::: example 抱闸松开时的下坠 {#ex-drop}
肩关节运行在$K_v = 0.0776\,\mathrm{N\,m\,s/rad}$与$K_{pp} = 30\,\mathrm{s^{-1}}$（都在电机侧，$N = 100$）。臂伸直（重力力矩$95.2\,\mathrm{N\,m}$）时松开抱闸。(a) 无重力补偿时，$0.9\,\mathrm m$外的工具下坠多远之后积分器才接管？(b) 有重力补偿、但输入的负载质量低了$1\,\mathrm{kg}$时呢？
::: solution
在积分器起作用之前，级联表现得像一根弹簧。电机位置误差$e_m$产生速度指令$K_{pp}e_m$，而在静止时产生转矩$K_vK_{pp}e_m$：电机侧刚度为$K_vK_{pp} = 0.0776\times30 = 2.33\,\mathrm{N\,m/rad}$。到关节上，关节误差$e$对应电机误差$Ne$，而电机转矩乘以$N$，所以关节刚度为$N^2K_vK_{pp} = 10^4\times2.33 = 2.33\times10^4\,\mathrm{N\,m/rad}$。

(a) 重力力矩$95.2\,\mathrm{N\,m}$给出$e = 95.2/2.33\times10^4 = 4.1\,\mathrm{mrad}$，工具处下坠$0.9\times4.1 = 3.7\,\mathrm{mm}$，由积分器在几倍$1/\omega_i = 42\,\mathrm{ms}$之内收回——一次看得见的下沉，若工具离零件很近还是危险。（实践中驱动器也会在打开抱闸之前预加转矩，那是同一种补偿的粗陋形式。）

(b) 转矩误差为$1\times9.81\times0.9 = 8.8\,\mathrm{N\,m}$，瞬态下坠$0.38\,\mathrm{mrad}$、工具处$0.34\,\mathrm{mm}$：好了一个数量级，也说明了负载辨识为何要紧。

**合理性检验。**伺服给出的$2.3\times10^4\,\mathrm{N\,m/rad}$的关节刚度，不到减速器$7.8\times10^4$的三分之一——低频下，在积分器起作用之前，最软的弹簧是伺服，不是减速箱。
:::
:::

## 摩擦及其补偿 {#sec-friction}

齿轮关节里的摩擦主要来自减速器（齿面接触、波发生器轴承）与密封件和轴承。它很大——应变波关节里常常是额定转矩的百分之几到百分之十几——并且随速度、载荷、温度与磨损而变。

::: definition 静摩擦模型 {#def-friction}
阻碍以速度$v$运动的关节的摩擦力矩$\tau_f$，按由粗到细依次建模为
- **库仑**：$\tau_f = \tau_c\,\sgn(v)$，大小恒定、方向阻碍运动；
- **库仑加黏性**：$\tau_f = \tau_c\,\sgn(v) + b\,v$；
- **斯特里贝克**：$\tau_f = \bigl[\tau_c + (\tau_s - \tau_c)\,e^{-(\lvert v\rvert/v_s)^\delta}\bigr]\sgn(v) + b\,v$，其中$\tau_s > \tau_c$为静（启封）摩擦，$v_s$为斯特里贝克速度——摩擦由$\tau_s$向$\tau_c$跌落所对应的速度，$\delta$为形状指数（常取$1$或$2$）。
$v = 0$时，摩擦力矩取$[-\tau_s, \tau_s]$内能平衡外加转矩的任意值（黏着）。LuGre模型一类的动态模型添加内部状态来描述预滑动位移与迟滞。
:::

::: widget plot

:::

摩擦以三种典型方式伤害关节伺服：

- **黏滑**于低速：在斯特里贝克曲线的下降段，关节黏住，转矩攒到把它挣脱，它向前一冲，慢下来，又黏住。工具沿慢速路径一顿一顿地移动。
- **振荡（极限环）**在设定点附近：积分作用把关节挣脱之后推过目标，然后又把它推回来，如此无穷。
- **换向误差**（象限毛刺）：关节换向时，摩擦从$+\tau_c$跳到$-\tau_c$，在积分器把输出扫过$2\tau_c$之前，关节都在落后。在工具画出的圆上，每个关节换向之处都会露出一个小凸起。

**补偿**把摩擦力矩的一个估计值$\hat\tau_f$加到转矩前馈上。用**指令**速度$\dot q_d$、而非实测速度，可避免把噪声反馈进去；把$\sgn(v)$换成$\tanh(v/\varepsilon)$一类光滑函数，可避免零速处的抖振。由于摩擦随温度与载荷而变，模型按关节逐一辨识（让关节以一系列恒速在两个方向运转并记录转矩），常常在若干温度下各做一次；剩下的残差交给积分器，或交给一个**扰动观测器**——它由指令转矩与实测加速度所隐含的转矩之差来估计未知转矩。

::: example 肩关节的换向误差 {#ex-friction}
肩关节在关节侧有库仑摩擦$\tau_c = 6\,\mathrm{N\,m}$，级联在积分作用之前的关节刚度为$2.33\times10^4\,\mathrm{N\,m/rad}$（[[#ex-drop]]）。估计关节换向时工具（$0.9\,\mathrm m$）处的瞬态位置误差，(a) 无摩擦补偿，(b) 采用有$80\,\%$准确度的模型。
::: solution
(a) 换向时摩擦力矩改变$2\tau_c = 12\,\mathrm{N\,m}$。在积分器把自己的输出改变同样多之前，比例部分必须供出它，所以关节误差峰值约$12/2.33\times10^4 = 0.52\,\mathrm{mrad}$：工具处$0.46\,\mathrm{mm}$——是重复性的十倍。

(b) 前馈供出跳变的$80\,\%$；余下$2.4\,\mathrm{N\,m}$给出$0.10\,\mathrm{mrad}$、$0.09\,\mathrm{mm}$。

**解读。**摩擦补偿在换向处换来路径精度提高一个数量级，决定结果的是摩擦模型的质量，而不是反馈增益。更硬的反馈也有帮助，但它受上文讨论的共振限制。
:::
:::

::: warning 在一个位姿整定、在另一个位姿运行
收臂空载（低惯量、低惯量比、高共振频率）整定的关节，在伸臂加载（高惯量、高比值、更低的共振）时可能振荡——而伸臂整定的关节收臂时会迟钝、过阻尼。增益必须在惯量的两端校核：$J_L$最小与最大，有载与空载，低温与高温（摩擦、电机电阻）。当范围宽到一组增益应付不来时，就随构型调度增益——关节惯量$m_{kk}(\mathbf q)$可由机械臂模型给出——或用当前的惯量估计值对速度环增益做归一化。
:::

## 采样率与延时 {#sec-sampling}

每个数字环都贡献延时：零阶保持约半个采样周期，再加计算与通信。延时$T_d$在频率$\omega$处耗去相角$\omega T_d$，所以在穿越频率$\omega_c$处耗去$360°\,f_cT_d$。要把它控制在约$20°$以内，总延时必须小于约$1/(18f_c)$，按$1.5$到$2$个周期延时计，要求采样率约为穿越频率的$20$到$40$倍。这就是本章开头那张表中各速率的由来。

轨迹发生器跑得更慢，典型$250\,\mathrm{Hz}$到$1\,\mathrm{kHz}$（[[robot-arm-design/software-stack]]），经EtherCAT一类现场总线下发设定点。驱动器必须在自己的位置环速率上在设定点之间**插补**（线性或三次样条）；否则位置参考就是现场总线速率上的一个阶梯，会激励关节在该频率及其谐波上振荡。设定点到达时刻的任何抖动都会变成位置误差，其大小等于速度乘以定时误差，这就是现场总线周期要与驱动器的时钟同步的原因（EtherCAT的分布式时钟正是为此而生）。

## 一套整定流程 {#sec-procedure}

::: algorithm 关节伺服的调试 {#alg-tuning}
1. **电流环。**测出$R$与$L$（驱动器的自整定会施加电压阶跃），按[[#eq-current-pi]]把PI设在PWM频率约$1/20$处，并检查电流阶跃：上升时间约$0.35/f_c$，小超调。
2. **辨识机械特性。**机械臂摆在其最利于控制的刚硬位姿（惯量最大），在低增益速度闭环下用线性调频或随机转矩激励关节，记录电机侧频率响应。从低频斜率读出$J_{\text{tot}}$，从高频斜率读出$J_m$，读出$f_a$、$f_r$与任何更高阶模态。在收臂位姿重复一遍。
3. **速度环。**按刚性模型带宽不超过$f_a$设$K_v$，$\omega_i \approx \omega_v/4$。对峰值逼近单位回路增益的模态加陷波滤波器；若量化噪声可闻，对速度估计加低通滤波。在两个位姿下检查相角裕度与增益裕度（目标约$45°$与$6\,\mathrm{dB}$以上）。
4. **位置环。**把$K_{pp}$设到比速度带宽低约$3$到$5$倍（rad/s），加速度速度前馈（$100\,\%$），然后加由模型算出的转矩前馈。
5. **重力与摩擦。**辨识质量模型（由许多静力位姿下的关节力矩）与摩擦曲线（两方向恒速运转）；把两者都加入前馈。
6. **验证。**满载全速跑真实轨迹；测量跟随误差、到目标的整定时间、圆试验上的换向误差与输出编码器误差；冷机、热机各重复一遍。只对测量结果指向的那一步重新整定。
:::

::: quiz
整定之后，某肩关节只在收臂空载时才在约400 Hz发出啸叫。哪个改动最合适？
- [ ] 增大位置环增益
- [ ] 去掉速度前馈
- [x] 在啸叫频率处添加或重新整定一个陷波滤波器，并同时检查伸臂位姿
- [ ] 增大速度环的积分增益
::: solution
固定频率的高音调，是速度环正驱动进振荡的一个共振。收臂位姿下关节惯量更低，于是回路增益$K_v/J$更高，共振峰能碰到单位增益。该频率处的陷波（或随位姿调度增益）能把它消掉；位置增益、前馈与积分增益作用的频率低得多。
:::
:::

::: history
比例–积分–微分律由尼古拉·米诺尔斯基（Nicolas Minorsky）于1922年在船舶自动操舵分析中提出，第一批广为使用的整定规则由约翰·齐格勒（John Ziegler）与纳撒尼尔·尼科尔斯（Nathaniel Nichols）于1942年发表。电流–速度–位置的级联结构脱胎于二十世纪中叶机床与轧机电力传动的控制，并随1980年代的数字伺服驱动器而普及。润滑副中的摩擦–速度关系由理查德·斯特里贝克（Richard Stribeck）在1902年发表的滑动轴承与滚动轴承实验中测绘；机器中摩擦补偿的系统研究则晚得多，突出的贡献有布莱恩·阿姆斯特朗-埃卢弗里（Brian Armstrong-Hélouvry）1990年代初的综述与专著，以及卡努达斯·德维特（Canudas de Wit）与同事们的LuGre动态摩擦模型（1995）。马克·斯庞（Mark Spong）1987年的弹性关节机器人模型——电机与连杆由弹簧耦合——把关节柔顺变成了机器人控制的标准内容。
:::

## 后续内容 {#sec-leads}

关节伺服如今成了一组性态良好的位置（或转矩）执行器，以几百到一千赫兹接受设定点。[[robot-arm-design/software-stack]]在它们之上搭建各层——机器人描述、ROS 2控制、运动规划——而[[robot-arm-design/calibration]]让它们收到的设定点对应工具真正所在的位置。

::: summary
- 关节伺服是级联：电流（1–3 kHz带宽）包速度（几十到二百来Hz）包位置（几到30 Hz），环间带宽分离3–10倍。整定从里向外。
- 电流环：PI取$K_p = \omega_cL$、$K_i = \omega_cR$；延时（$\approx 1.5$个PWM周期）把$\omega_c$限制在约PWM频率的$1/20$。
- 速度环：$K_v = \omega_vJ_{\text{tot}}$，$\omega_i \approx \omega_v/4$；由编码器差分得到的速度经过量化，必须滤波。
- 柔顺关节有反共振$\omega_a = \sqrt{k/J_L}$与共振$\omega_r = \omega_a\sqrt{1 + r}$；$\omega_r$以上电机只见自己的惯量，于是回路增益是刚性设计的$1 + r$倍。速度带宽保持在$\omega_a$及以下、$r$保持中等；更高阶的模态用陷波。
- 比例位置控制落后$v/K_{pp}$；由轨迹与模型给出的速度与转矩前馈承担跟踪。
- 重力补偿消除抱闸松开时与运动中的下坠；它需要负载参数。
- 摩擦（库仑、黏性、斯特里贝克）引起黏滑、振荡与换向误差；用由指令速度驱动的模型来补偿，残差交给积分器或观测器。
- 每组整定都要在惯量、负载与温度的极端下检查；以20–40倍于穿越频率的速率采样，并对设定点插补。
:::

## 习题

::: exercise 电流环增益 {level=1 check="0.942"}
某电机相绕组$R = 0.15\,\Omega$、$L = 0.30\,\mathrm{mH}$。按零极点对消求电流环带宽$500\,\mathrm{Hz}$的$K_p$。（输入的$K_p$以V/A为单位，保留三位小数。）
::: solution
$\omega_c = 2\pi\times500 = 3142\,\mathrm{rad/s}$；$K_p = \omega_cL = 3142\times3.0\times10^{-4} = 0.942\,\mathrm{V/A}$；$K_i = \omega_cR = 471\,\mathrm{V/(A\,s)}$。
:::
:::

::: exercise 跟随误差 {level=1 check="0.04"}
某关节带比例位置环$K_{pp} = 50\,\mathrm{s^{-1}}$、无前馈，跟随$2.0\,\mathrm{rad/s}$的斜坡。它的稳态跟随误差是多少？（输入误差，以rad为单位。）
::: solution
$e = v/K_{pp} = 2.0/50 = 0.04\,\mathrm{rad} = 2.3°$。速度前馈能把它消除。
:::
:::

::: exercise 由反共振求共振 {level=1 check="54.2"}
某关节电机侧的频率响应显示反共振在$18\,\mathrm{Hz}$，惯量比$r = 8.06$。共振在什么频率？（以Hz为单位输入，保留一位小数。）
::: solution
$f_r = f_a\sqrt{1 + r} = 18\times\sqrt{9.06} = 18\times3.010 = 54.2\,\mathrm{Hz}$。
:::
:::

::: exercise 含延时的相角裕度 {level=2 check="48"}
一个按零极点对消设计的电流环带宽为$1.25\,\mathrm{kHz}$；PWM运行在$16\,\mathrm{kHz}$，延时为$1.5$个PWM周期。求相角裕度。（以度为单位输入，取整到度。）
::: solution
$T_d = 1.5/16\,000 = 93.75\,\mathrm{\mu s}$；$\omega_cT_d = 2\pi\times1250\times93.75\times10^{-6} = 0.736\,\mathrm{rad} = 42.2°$；裕度$90 - 42.2 = 47.8 \approx 48°$。若驱动器晚整整一拍才施加新占空比（延时$2.5$个周期），滞后将是$70.3°$、裕度不足$20°$：更新方式与PWM频率同等要紧。
:::

::: exercise 伺服刚度 {level=2 check="1.5"}
某传动比$N = 120$的关节有电机侧增益$K_v = 0.05\,\mathrm{N\,m\,s/rad}$与$K_{pp} = 40\,\mathrm{s^{-1}}$。一个$43.2\,\mathrm{N\,m}$的力矩扰动施加在关节上。积分器起作用之前的瞬态关节误差是多少？（以mrad为单位输入。）
::: solution
关节刚度$N^2K_vK_{pp} = 14\,400\times0.05\times40 = 28\,800\,\mathrm{N\,m/rad}$；误差$43.2/28\,800 = 1.5\times10^{-3}\,\mathrm{rad} = 1.5\,\mathrm{mrad}$。
:::

::: exercise 陷波的深度 {level=2 check="-26.0"}
某陷波滤波器$\zeta_z = 0.02$、$\zeta_p = 0.4$。中心频率处的深度是多少？（以dB为单位输入，保留一位小数。）
::: solution
$20\log_{10}(0.02/0.4) = 20\log_{10}0.05 = -26.0\,\mathrm{dB}$。它的宽度主要由$\zeta_p = 0.4$决定，它也决定了滤波器在中心频率以下添加的相位滞后。
:::

::: exercise 摩擦辨识 {level=2}
让关节以若干恒速运转并记录电机转矩（已折算为关节力矩）：$+0.1\,\mathrm{rad/s}$：$7.2\,\mathrm{N\,m}$；$+0.5$：$8.0$；$+1.0$：$9.0$；负速度取镜像值。用两个较高的速度拟合库仑加黏性模型，并评论$0.1\,\mathrm{rad/s}$那一点。
::: solution
由$0.5$与$1.0\,\mathrm{rad/s}$：$b = (9.0 - 8.0)/0.5 = 2.0\,\mathrm{N\,m\,s/rad}$，$\tau_c = 8.0 - 2.0\times0.5 = 7.0\,\mathrm{N\,m}$。模型预测$0.1\,\mathrm{rad/s}$处为$7.2\,\mathrm{N\,m}$，与测量相符，所以这一速度下没有明显的斯特里贝克下凹；要找到$\tau_s$与$v_s$，需要在更低速度（比如$0.005$–$0.05\,\mathrm{rad/s}$）的测试与从静止出发的启封试验。数据中必须先扣除重力（在重力恒定的位姿下运转并对两方向取平均，或用水平轴）。
:::

::: exercise 由惯量比决定的带宽上限 {level=3}
利用[[#eq-two-mass]]证明：若速度环在刚性模型上设计，穿越频率为$\omega_v$且$\omega_v \ll \omega_a$，则其高频（$\omega \gg \omega_r$）开环增益为$(1 + r)\omega_v/\omega$，从而延时$T_d$把刚性模型带宽限制到大致$\omega_v < \varphi_{\max}/[(1 + r)T_d]$，其中$\varphi_{\max}$是允许耗在延时上的相角（弧度）。代入$r = 5.86$、$T_d = 375\,\mathrm{\mu s}$、$\varphi_{\max} = 30°$求值，并讨论设计者能改变什么。
::: solution
取$K_v = \omega_vJ_{\text{tot}}$，而高频下被控对象为$1/(J_mj\omega)$，开环幅值为$K_v/(J_m\omega) = \omega_vJ_{\text{tot}}/(J_m\omega) = (1 + r)\omega_v/\omega$（PI的积分项在那里可忽略）。它在$\omega_c = (1 + r)\omega_v$处穿越1，那里延时耗去$\omega_cT_d$。要求$\omega_cT_d < \varphi_{\max}$即得$\omega_v < \varphi_{\max}/[(1 + r)T_d]$。数值：$\varphi_{\max} = 0.524\,\mathrm{rad}$，故$\omega_v < 0.524/(6.86\times3.75\times10^{-4}) = 204\,\mathrm{rad/s}$（$32\,\mathrm{Hz}$）。设计者可以减小$r$（更大惯量的电机，或更低的传动比——它使$J_m$相对$J_L/N^2$变大），减小延时（更快的环路速率、更少的滤波、更快的编码器接口），或接受更低的带宽。注意对这个关节来说，反共振（$16.8\,\mathrm{Hz}$）本来就是更紧的限制。
:::

::: exercise 规划一台新机械臂的调试 {level=3}
你要在一台新六轴机械臂首次客户演示（两周后）之前负责其关节伺服的调试。写一份计划：你将在每个关节上做的测量、先后次序、需要的工具与测试软件、验收判据（带数字，可用本章的例子），以及风险——包括调试期间的安全风险。
::: solution
好的计划按[[#alg-tuning]]逐关节推进，从腕向里或从基向外（先做腕常见，因为它的整定不依赖其他关节的增益，但基座与肩承载着风险），内容包括：电流环的驱动器自整定与阶跃响应检查；每关节两个以上位姿、带数据记录的频率响应测量；在最恶劣位姿下给出裕度指标（≥ 45°、≥ 6 dB）的速度环设计；列出各陷波及其频率；位置环及其跟随误差限值（例如带前馈全速运动中< 1 mrad，100 ms内收敛到±10 µrad以内）；负载与摩擦辨识；用ISO 9283风格的重复性跑动与圆试验验证。工具：带示波器与伯德功能的驱动器软件、不低于1 kHz的数据记录仪、输出编码器或激光跟踪仪检查。安全：调试在降低的速度与转矩限值下进行；机械臂处于已清空并装围栏的区域；使能装置与急停握在手中；增益调高之前检查抱闸；承受重力力矩的关节加以支撑，或让机械臂处于失稳也不会把臂甩向地面或操作员的位姿下测试（[[robot-arm-design/arm-safety]]）。风险：随位姿移动的共振、摩擦的热漂移、快速多关节运动中未经测试的关节间耦合——留出带载全速试验的时间。
:::
