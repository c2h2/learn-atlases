一个铁路车轮、一个涡轮盘、一根连杆、一辆自行车的车架管，还有你充电线里的金属丝，有一个共同点：**它们是把固态金属推过屈服点、直到它取得新形状而制成的，而且因此变得更强。**铸造靠放弃组织来获得形状；切削加工靠把组织一片片切屑扔掉来获得形状；成形靠*移动*组织来获得形状——如果做得得当，就把组织移动到载荷将要走的方向上。

这就是体积成形工艺的全部理由，而这个理由用三种货币来计价。**金相学上的**：锻造焊合铸件的收缩疏松，打碎它的粗枝晶和偏析带，把夹杂物和析出相沿零件轮廓排成**流线**——值 20-40 % 的疲劳强度，横向于流线的韧性更是多得多的提升。**经济上的**：一个锻件或挤压件是每分钟一个零件的近净形，而机加工件是每小时一个零件，还从一块两倍质量的坯料开始。**力学上的**：冷加工*强化*产品——冷拉高碳钢丝的抗拉强度可超过 2 GPa，约为同种钢退火态的三倍——所以这个工艺同时也是一道强化处理。代价是成形需要**力**：兆牛级的力，于是一台价值数百万的机器，和一副价值数万、还会磨损的模具。本课讲的就是计算这个力，因为力决定机器，机器决定尺寸，而尺寸和模具决定成本。

::: warning 成形出错的五种方式
**把热和冷搞混。**分界不是一个固定的温度，而是**再结晶温度**，约为 $0 . 4 { - } 0 . 5 \ T _ { m }$（以开尔文计）：铅和锡的再结晶温度低于室温（所以它们在室温就是热加工），铝约 $1 5 0 { - } 2 5 0 \ \mathrm { ^ { \circ } C }$ ，铁 $4 5 0 { - } 6 0 0 \ \mathrm { ^ { \circ } C }$ ，钨超过 $1 { , } 2 0 0 \ \mathrm { ^ { \circ } C }$ 。工业热加工在远高于它的温度进行——铝合金约 $3 5 0 { - } 5 0 0 \ \mathrm { ^ { \circ } C }$ ，钢约 $9 0 0 { - } 1 { , } 2 5 0 \ \mathrm { ^ { \circ } C }$ 。在其下加工，金属加工硬化，越打越硬，回弹，可能开裂；在其上加工，它软化的速度和硬化一样快，只需要一小部分的力，却会沾上氧化皮、丢掉公差。**按热锻数据表设计的“冷锻”件，是一副会被撑裂的模具。** **设计一个填不满的锻件。**模锻需要金属在十亿帕的压力下到达型腔的每个角落，还需要模具*造得出来*——也就是说要有分型面、$5 { - } 7 ^ { \circ }$ 的模锻斜度、$3 { - } 6 ~ \mathrm { m m }$ 的圆角半径，而且完全不许有凹陷。画出机加工级内圆角锻支架的设计师，画的是一副只有电火花才能加工的模具，一副会很早就在那个角上开裂的模具。**因为材料“软”就低估力。**力是**工作温度和应变速率下的流变应力**乘以面积再乘以一个约束因子——而摩擦和飞边带来的约束因子是 2 到 10。$1 { , } 1 0 0 \ \mathrm { ^ { \circ } C }$ 的钢流变应力可能只有 $8 0 \ \mathrm { M P a }$ ，模锻平均压力却接近 $8 0 0 \ \mathrm { M P a }$ （第 4 节），因为飞边通道是一个节流口，而模面咬住工件。**忘了机器是弹性的。**轧机或压力机在几兆牛载荷下会伸长零点几毫米，所以空载时设定为 $2 3 . 6 2 \ \mathrm { m m }$ 的辊缝，在轧制力下张开到 $2 4 . 0 0 \ \mathrm { m m }$ （第 3 节）。**轧机弹跳**不是缺陷，它是厚度控制是反馈回路而不是一个设定的原因。**拿铸件来成形，还管它叫锻件。**如果坯料是有疏松的铸件而变形量又小，疏松就留在原地，流线沿着原来的枝晶走，这个“锻件”就带着铸件的性能、锻件的成本。锻件的坯料必须是轧制或锻造坯，技术条件通常要求相对铸锭的锻造比至少约 3:1 到 4:1，才认为铸态组织已被打碎。
:::

::: example 锻与铸：连杆 {#ex-rod level=3}
一根钢连杆承受完全反转的惯性载荷叠加压缩的燃烧载荷，失效方式是油孔圆角处的疲劳。两条路线：微合金钢铸件和调质 42CrMo4 锻件，两者都经机加工和喷丸。

## 2. 力：流变应力、面积与约束因子

::: definition 流变应力与成形载荷 {#def-flow}
成形分析从材料在工作温度和应变速率下的**真应力–真应变**曲线开始，通常拟合为

$$
\sigma \; = \; K \varepsilon ^ { n } \qquad \Longrightarrow \qquad { \bar { \sigma } } \; = \; { \frac { 1 } { \varepsilon } } \int _ { 0 } ^ { \varepsilon } K \varepsilon ^ { \prime n } \, d \varepsilon ^ { \prime } \; = \; { \frac { K \varepsilon ^ { n } } { 1 + n } } \; = \; { \frac { \sigma _ { \text{终} } } { 1 + n } }
$$

其中 $n$ 是加工硬化指数——而进入载荷计算的是平均流变应力，不是最终值。成形力则永远是同样三样的乘积：

$$
F \; = \; \underbrace { { \bar { \sigma } } } _ { \text{材料} } \; \times \; \underbrace { A } _ { \text{接触面积} } \; \times \; \underbrace { Q } _ { \text{约束因子} }
$$

约束因子 $Q$ 是一切微妙之处所在，它有三个来源。模面上的**摩擦**阻止表面扩展，于是内部被夹在两块夹紧的板之间挤压——一种三向压缩状态，其中维持屈服所需的压强朝中心升到远高于流变应力；这就是下面推导的**摩擦峰**，在一个锻件或一道轧制里值 2-8 倍。**多余功**——模角附近和中心的金属因为几何的强迫必须比平均变形更多——再加 10-30 %。模锻的**飞边与飞边桥几何**可以再加 3-10 倍因子，因为金属必须挤过一条薄、长、高摩擦的通道才能充满模腔，于是型腔内的压强就由那条通道决定，而与工件根本无关。

两个值得背下来的推论。**热金属软，并不意味着载荷小**：在第 4 节的例子里，$1 { , } 1 0 0 \ \mathrm { ^ { \circ } C }$ 、流变应力 $8 0 \ \mathrm { M P a }$ 的钢需要约 $7 6 0 \ \mathrm { M P a }$ 的模锻平均压力。而**限制轧机的不只是力，还有功率**：功率等于力矩乘以轧辊转速，热带钢轧机的每个精轧机架都配有数兆瓦的主电机，才能跟上约 $1 { , } 0 0 0 \ \mathrm { m / m i n }$ 量级的带速。
:::

::: proof 摩擦峰：为什么锻件中心的压强最高 {#proof-hill}
取厚 $h$ 的板坯在平模间压缩，半宽 $a$ ，在距中心 $x$ 处切一个宽 $d x$ 的竖直单元。单元的横向平衡给出

$$
\frac { d \sigma _ { x } } { d x } \; = \; { \frac { 2 \tau } { h } }
$$

其中 $\tau$ 是界面切应力。用常数摩擦因子 $\tau = m \sigma _ { y } / 2$ （按特雷斯卡（Tresca）准则，完全粘着时 $m = 1$ ）和平面应变下的屈服准则 $p - \sigma _ { x } = \sigma _ { y }$ （$p$ 为模面压强，$\sigma _ { y }$ 为平面应变流变应力），从自由边缘（$\sigma _ { x } = 0$ ）积分得

$$
p ( x ) \; = \; \sigma _ { y } \left[ \, 1 \; + \; { \frac { m } { h } } ( a - x ) \, \right] \qquad \text{而库仑（Coulomb）摩擦 } \tau = \mu p \text{ 时，} \qquad p ( x ) \; = \; \sigma _ { y } \, \exp \! \left[ { \frac { 2 \mu } { h } } ( a - x ) \right]
$$

**压强随模宽与工件厚度之比呈指数（最好情形是线性）增长，而且中心最大。**$a / h = 1 0$ 、$\mu = 0 . 1$ 时，中心压强是流变应力的 $e ^ { 2 } = 7 . 4$ 倍；$a / h = 2$ 时只有 1.5 倍。由此得出图中的三条实用规则：**薄而宽的零件，其机器尺寸由摩擦决定而不是由材料决定**；**润滑靠攻击指数起作用**，这就是玻璃润滑剂在钛和高温合金锻造中如此重要的原因；而**粘着正是锻件表面纹理成为模具复制品的原因**，因为一旦 $\tau = \mu p$ 超过金属的剪切屈服强度 $k = \sigma _ { y } / { \sqrt { 3 } }$ ，再大的压强也不能让表面滑动，金属是绕着一块粘在它上面的模具变形的。
:::

:::

## 3. 轧制

::: definition 几何、力与弹跳 {#def-rolling}
板带轧制是一道靠自身摩擦把工件拽进去的连续镦粗。整个几何就是一个直角三角形：半径 $R$ 的轧辊把厚度从 $h _ { 0 }$ 减到 $h _ { 1 }$ ，所以

$$
\Delta h \; = \; h _ { 0 } - h _ { 1 } , \qquad L \; = \; { \sqrt { R \, \Delta h } } \qquad \text{（接触长度，} \Delta h \ll R \text{）}
$$

接触面积 $A = w L$ 。力、力矩和功率随之而来，其中约束因子 $Q _ { x }$ 计入摩擦峰以及带钢很宽（平面应变，所以轻压下 $Q _ { x } \approx 1 . 2$ ，重压下可达 2）这两件事：

$$
F \; = \; { \bar { \sigma } } \, Q _ { x } \, w L , \qquad T \; = \; { \frac { F L } { 2 } } \ \text{每辊 } ( \text{力臂 } \approx L / 2 ) , \qquad P \; = \; 2 \, T \, \omega \; + \; \text{损失}
$$

两个极限决定一台轧机能干什么。**咬入条件**（下面推导）说摩擦必须能把带钢拉进来：$\mu \geq \tan \alpha$ ，其中 $\alpha$ 是接触角，$\cos \alpha = 1 - \Delta h / 2 R$ ，所以**每道最大压下量是 $\Delta h _ { \max } = 2 R \left( 1 - 1 / \sqrt { 1 + \mu ^ { 2 } } \right) \approx R \mu ^ { 2 }$** ——这就是为什么热轧（摩擦大，带氧化皮的钢 $\mu$ 约为 $0 . 3 { - } 0 . 4$ ）一道能压下几十毫米，而油润滑冷轧（$\mu \approx 0 . 0 5$ ）在同样的轧辊上每道远不到一毫米——对薄带来说，这仍是厚度的一大部分。**轧机弹跳**：机架、压下螺丝和轧辊按 $\delta = F / G$ 弹性伸长，$G$ 是**轧机刚度系数**，典型为每毫米几兆牛，所以出口厚度是

$$
h _ { 1 } \; = \; s \; + \; { \frac { F } { G } } \qquad ( s \ \text{为辊缝设定值} )
$$

而 $F$ 本身又依赖 $h _ { 1 }$ ，所以厚度是一个**反馈问题**，实践中由读测厚仪和张力的液压厚度自动控制回路解决，在旧时代则由操作工盯着压下螺丝上的一道刻线解决。
:::

::: proof 咬入条件 {#proof-bite}
在入口处，轧辊以与竖直方向成接触角 $\alpha$ 的法向力 $N$ 咬住带钢，摩擦力 $\mu N$ 与带钢成 $\alpha$ 角。沿轧入方向分解：摩擦以 $\mu N \cos \alpha$ 把带钢**拉入**，法向反力以 $N \sin \alpha$ 把它**推出**（取初始接触处，那里角度最大）。带钢被拉入的条件是

$$
\mu N \cos \alpha \; > \; N \sin \alpha \qquad \Longleftrightarrow \qquad \mu \; > \; \tan \alpha
$$

而接触角满足 $\cos \alpha = 1 - \Delta h / 2 R$ ，所以还能咬得住的最大压下量是

$$
\Delta h _ { \max } \; = \; 2 R ( 1 - \cos \alpha _ { \max } ) \; = \; 2 R \left( 1 - { \frac { 1 } { \sqrt { 1 + \mu ^ { 2 } } } } \right) \; \approx \; R \mu ^ { 2 }
$$

**这就是热轧作为重工艺、冷轧作为轻工艺存在的原因。**$\mu = 0 . 4$ （热钢对钢，带氧化皮）、$R = 3 0 0 \ \mathrm { m m }$ 时，$\Delta h _ { \max } = 4 3 \ \mathrm { m m }$ （近似式给出 48）——粗轧机能从板坯上大口压下，限制它的通常是力、力矩和电机，而不是咬入。$\mu = 0 . 0 5$ （油润滑冷轧）时，同样的轧辊被限制在 $0 . 7 5 \ \mathrm { m m }$ ，这就是为什么冷轧机在薄带上用小工作辊、在一两毫米厚的带钢上每道压下零点几毫米，也是为什么**保护表面和轧辊的润滑剂，同时也限制了咬入**。
:::

::: example 一道轧制：力、力矩、功率与弹跳 {#ex-roll level=3 check="3.8"}
低碳钢带钢宽 $3 0 0 \ \mathrm { m m }$ 、厚 $3 0 \ \mathrm { m m }$ ，在直径 $6 0 0 \ \mathrm { m m }$ 的轧辊上以 $1 0 0 \ \mathrm { r p m }$ 减薄到 $2 4 \ \mathrm { m m }$ 。该道次温度和应变速率下的平均流变应力是 $2 5 0 \ \mathrm { M P a }$ （一道低温、快速的道次），约束因子 1.2。求轧制力。（输入 MN，保留一位小数。）

$$
L = { \sqrt { 3 0 0 \times 6 } } = 4 2 . 4 \ \mathrm { m m } , \qquad A = 4 2 . 4 \times 3 0 0 = 1 2 \, 7 3 0 \ \mathrm { m m ^ { 2 } }
$$
$$
F = 2 5 0 \times 1 . 2 \times 1 2 \, 7 3 0 = 3 . 8 2 \ \mathrm { M N } , \qquad T = { \frac { F L } { 2 } } = { \frac { 3 . 8 2 \times 1 0 ^ { 6 } \times 0 . 0 4 2 4 } { 2 } } = 8 1 \ \mathrm { k N m }
$$
$$
P = 2 T \omega = 2 \times 8 1 \times 1 0 ^ { 3 } \times { \frac { 2 \pi \times 1 0 0 } { 6 0 } } = { \bf 1 . 7 \ M W } \qquad ( \text{未计损失，损失再加 } 1 0 { - } 2 0 \ \%)

**力是 3.8 MN（约 390 吨力），力矩每辊 81 kNm，功率 1.7 MW——按热带钢轧机的标准是一个中等的机架。**再看弹跳：轧机刚度系数 $G = 1 0 \ \mathrm { M N / m m }$ 时，机架和轧辊伸长 $3 . 8 2 / 1 0 = 0 . 3 8 \ \mathrm { m m }$ ，所以**辊缝必须设到 $2 3 . 6 2 \ \mathrm { m m }$ 才能轧出 $2 4 . 0 0 \ \mathrm { m m }$** ——而 $F$ 随温度、张力、来料厚度而变，那 $0 . 3 8 \ \mathrm { m m }$ 是个移动靶，这就是厚度控制的全部内容。再看咬入：$\cos \alpha = 1 - 6 / 6 0 0 = 0 . 9 9$ 得 $\alpha = 8 . 1 ^ { \circ }$ 、$\mu _ { \text{所需} } = 0 . 1 4$ ，热态轻松满足。把同一道轧制改成 $\mu = 0 . 0 6$ 的油冷轧，最大压下量塌缩到约 $R \mu ^ { 2 } = 3 0 0 \times 0 . 0 6 ^ { 2 } = 1 . 1 \ \mathrm { m m }$ ，那 6 mm 是永远不会发生的。

::: definition 轧机、孔型与板形 {#def-mills}
**二辊**（可逆，每向一道）、**三辊**（工件在直径不同的上下辊之间上下穿行，用于棒材的古老而皮实的布置）、**四辊**（工作辊由大辊支承，中厚板和带钢的通用选择）、**多辊/森吉米尔**（小工作辊加两三排支承环，用于硬薄带和箔材）、**连轧**（多个机架串联，各分担一部分压下量，机架间张力控制板度和厚度——热带钢轧机把约 200–250 mm 厚的板坯轧成几毫米厚的卷），以及**型钢和棒材轧机**（轧辊上一序列槽型——箱型孔、椭圆孔、方孔——把坯料经许多道次走成型钢、角钢或钢轨）。

型钢轧机的孔型设计是一道体积守恒的设计练习：同样的体积必须通过每个机架，所以面积随速度下降而减小，而孔型必须**充满**——欠充满则截面超差、翼缘起浪；过充满则金属挤进辊缝，形成飞翅。扁平产品的形状是应力问题：辊缝并不均匀，因为轧辊在载荷下弯曲（靠把轧辊磨出微凸的**辊型凸度**修正，现代轧机则靠**液压弯辊**和**窜辊或连续变凸度辊**），也因为辊身中部受热膨胀（**热凸度**，靠异形冷却水集管控制）。中部比边部长的带钢是**中浪**；边部长的是**边浪**；两者都不平。两种都在轧机里产生，两种都要等卷打开才看得见。
:::

## 4. 锻造

::: definition 自由锻、模锻，以及决定载荷的飞边 {#def-forging}
**自由锻**把加热的坯料夹在平的或成形但从不封闭它的工具之间；金属从未受约束的地方流动，所以可锻的形状是轴对称或棱柱形的——盘、环、轴、阶梯轴，直到用数百吨钢锭锻成的大型汽轮机转子。力就是普通的摩擦峰值 $F = { \bar { \sigma } } Q w L$ ，$Q$ 取 1.5-3，公差是一米上 $\pm 5 \ \mathrm { m m }$ 。**模锻（闭式模锻）**把金属封闭在两块于**分模线**处合拢的模块切出的型腔里；放上坯料，压力机合模，金属充满模腔，直到一层多余的薄筋——**飞边**——流入模具周围一条浅的飞边桥。飞边不是缺陷而是**液压节流口**：它在模腔内的金属之前冷却结硬，变得极难被推过，从而把模具内的压力抬升到足以充满圆角。它花掉相当一部分钢材（常为 10-30 %）和一副切边模，也是模锻载荷是普通压缩载荷数倍的原因。

设计词汇表由模具决定，不由设计师决定：**分模线**（通常在零件最厚处，而且总会留下一条必须磨掉或机加工掉的飞边线）、让锻件能脱模的 $5 { - } 7 ^ { \circ }$ **模锻斜度**、内角处 $3 { - } 6 ~ \mathrm { m m }$ 的**圆角半径**（尖锐的内圆角既是填不满的角，也是模具上的裂纹）、**连接筋**（两个凸台之间一条薄筋，之后被机加工掉，因为模具做不出槽）、**预成形与中间坯**型槽（一到三个预备型腔，把金属放到正确的位置，让终成形槽能充满而不折叠），以及**公差**：小型钢锻件 $\pm 0 . 5 \ \mathrm { m m }$ ，冷锻件 $\pm 0 . 1 \ \mathrm { m m }$ 。

机器按它们输出的是**力**还是**能量**来划分。机械或液压**压力机**以可控的行程施加可控的力，应变速率 $1 { - } 3 0 \ \mathrm { s ^ { - 1 } }$ ，用于模锻、等温锻造和任何必须充满的活。**锤**（落锤或双动锤）每一锤输出固定能量，应变速率 $1 0 { - } 1 0 0 \ \mathrm { s ^ { - 1 } }$ ，对不完美的预成形很宽容。**螺旋压力机**和锤一样受能量限制，但打击较慢；卧式**平锻机**在棒料端部聚料。钛和高温合金这类对应变速率敏感的合金，通常在压力机上慢速锻造。
:::

::: example 钢法兰需要什么压力机 {#ex-press level=3 check="8.6"}
在 $1 { , } 1 0 0 \ \mathrm { ^ { \circ } C }$ 的闭式模中，把直径 $6 0 \ \mathrm { m m }$ 、长 $1 0 0 \ \mathrm { m m }$ 的 1045 钢棒镦粗成直径 $1 2 0 \ \mathrm { m m }$ 的法兰。该温度和应变速率下的流变应力是 $8 0 \ \mathrm { M P a }$ ；飞边厚 $4 \ \mathrm { m m }$ ，飞边桥宽 $1 0 \ \mathrm { m m }$ 。估算压力机所需的力。（输入 MN，保留一位小数。）

由体积不变，法兰厚 $2 5 \ \mathrm { m m }$ ，终成形模腔的投影面积是 $A = \pi \times 6 0 ^ { 2 } = 1 1 \, 3 1 0 \ \mathrm { m m } ^ { 2 }$ （半径 60 mm）。把金属挤过飞边桥所需压强的一个常用估算——用于厚 $h _ { f } = 4 \ \mathrm { m m }$ 、桥宽 $a _ { f } = 1 0 \ \mathrm { m m }$ 通道的摩擦峰结果——是

$$
p _ { \text{飞边} } \; = \; 2 \sigma _ { y } \left( 1 + { \frac { a _ { f } } { 2 h _ { f } } } \right) \; = \; 2 \times 8 0 \times ( 1 + 1 . 2 5 ) \; = \; 3 6 0 \ \mathrm { M P a }
$$

而模腔内的压强是这个飞边压强**加上**金属在自身摩擦峰下变形所需的压强——对 $2 \sigma _ { y }$ 取 2-3 的约束因子：

$$
p _ { \text{平均} } \; \approx \; p _ { \text{飞边} } + 2 . 5 \times 2 \sigma _ { y } \; = \; 3 6 0 + 4 0 0 \; = \; 7 6 0 \ \mathrm { M P a }
 \qquad \Longrightarrow \qquad F \; = \; 7 6 0 \times 1 1 \, 3 1 0 \; = \; { \bf 8 . 6 \ M N } \; \approx \; 8 8 0 \ \text{吨力}
$$

**近九百吨力，而同样的流变应力作用在同样的面积上、没有飞边和摩擦时还不到一兆牛——将近十倍的因子来自飞边和摩擦峰。**注意这个计算让什么变便宜、让什么变贵：**把飞边桥宽从 $1 0 \ \mathrm { m m }$ 减到 $6 \ \mathrm { m m }$ ，飞边压强降五分之一，省约 0.9 MN**；把飞边加厚则省得更多——但飞边太少模具就填不满，这正是模具设计师靠试验和仿真来权衡的地方。还要注意答案是一个**行程上的力**：同一件法兰用锤打，需要在坯料冷到 $9 5 0 \ \mathrm { ^ { \circ } C }$ 以下之前用三四锤把能量输入进去，那是另一套计算。
:::

## 5. 挤压

::: definition 把金属挤过孔洞 {#def-extrusion}
**正（直接）挤压**中，挤压筒里的坯料被挤压杆推动，金属沿挤压杆运动的方向流动，从远端的模孔流出，所以整个坯料沿筒壁滑动；**反（间接）挤压**中，模具装在空心挤压杆上，制品*穿过挤压杆*、逆着其运动方向流出，坯料不沿挤压筒滑动。**挤压比**是 $R _ { x } = A _ { 0 } / A _ { 1 }$ ，典型 10-100，单位体积的理想功与拉拔相同——对数应变乘以流变应力，$w = { \bar { \sigma } } \ln R _ { x }$ ——所以理想压力是

$$
p _ { \text{理想} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \qquad \Longrightarrow \qquad p _ { \text{正挤} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \; \underbrace { \psi _ { x } } _ { \text{模具，} 1 . 2 - 1 . 6 } \; \underbrace { e ^ { 4 \mu L / D } } _ { \text{挤压筒摩擦} } \qquad p _ { \text{反挤} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \, \psi _ { x }
$$

挤压筒摩擦因子来自直径 $D$ 的一薄片坯料的力平衡：筒壁面积 $\pi D \, d z$ 上的摩擦 $\mu p$ 与面积 $\pi D ^ { 2 } / 4$ 上的压力变化平衡，得 $d p / d z = 4 \mu p / D$ ，积分即得 $e ^ { 4 \mu L / D }$ （较小时 $\approx 1 + 4 \mu L / D$ ）。它就是两种机器之间争论的全部：它随坯料长度 $L$ 增长，所以正挤压机随着坯料被用完而损失压力（因而损失速度，因而损失温度均匀性）；这也是为什么钢挤压——坯料 $1 { , } 1 5 0 \ \mathrm { ^ { \circ } C }$ ，挤压筒 $4 0 0 \ \mathrm { ^ { \circ } C }$ ，润滑剂是一层 $0 . 2 \ \mathrm { m m }$ 的玻璃膜——用短坯料和大吨位压力机，而反挤压能用长坯料在近乎恒定的载荷下运行；大多数**空心**铝型材是用下面介绍的分流（舌形）模正挤压出来的。

模具本身是一块磨出截面形状的工具钢，带着定径带，定径带确定最终尺寸并控制**金属流动**：坯料中心附近的金属往往比远离中心的流得快，所以定径带长度处处相同的模具挤出的型材离开时会弯曲或扭曲，模具师傅靠在金属流得快处加长定径带（增加摩擦）、流得慢处缩短定径带来校正。空心型材用**分流（舌形）模**制造：坯料绕着模桥的桥腿分开，又在焊合室中高压下重新焊合，洁净的金属表面形成固相焊缝。缺陷也因此非常特定：**中心破裂或人字裂纹**（中心线上拉应力造成的内部裂纹，大模角配小压缩比时容易出现）、**挤压缩尾**（行程末段氧化的坯料表皮被卷入制品中心，这就是要留下压余的原因）、**表面撕裂**（速度或温度太高引起的热脆）、**模痕**，以及时效强化合金里的**淬火畸变**。
:::

::: proof 挤压与拉拔的理想功及最大变形量 {#proof-extrude}
取流变应力为 ${ \bar { \sigma } }$ 的理想刚塑性材料，在无摩擦、均匀的变形中把体积 $V$ 从截面积 $A _ { 0 }$ 变形到 $A _ { 1 }$ 。真应变是

$$
\varepsilon \; = \; \ln { \frac { L _ { 1 } } { L _ { 0 } } } \; = \; \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; = \; \ln R _ { x } \; = \; 2 \ln { \frac { d _ { 0 } } { d _ { 1 } } }
$$

（后两个等号靠体积不变），所以**单位体积的理想功**是 $w = { \bar { \sigma } } \varepsilon = { \bar { \sigma } } \ln R _ { x }$ ，而由虚功原理，理想压力或应力就是同一个量：

$$
p _ { \text{理想} } \; = \; { \bar { \sigma } } \ln { \frac { A _ { 0 } } { A _ { 1 } } } \qquad \text{而半锥角 } \alpha \text{ 的锥形模、摩擦系数 } \mu \text{ 时，} \qquad \sigma _ { d } \; = \; { \bar { \sigma } } \left( 1 + { \frac { \mu } { \tan \alpha } } \right) \ln { \frac { A _ { 0 } } { A _ { 1 } } }
$$

现在讲极限。**挤压**中功是压缩功且被挤压筒约束，所以它不会以颈缩失效，$R _ { x }$ 只受压力机和模具限制。**拉拔**中工件悬挂在被拉出的产品上：拉拔应力 $\sigma _ { d }$ 由离开模具的线材承受，而线材的强度是*已变形*金属的流变应力 ${ \bar { \sigma } } _ { 1 }$ 。若 $\sigma _ { d }$ 达到 ${ \bar { \sigma } } _ { 1 }$ ，线材会一路屈服到卷筒然后拉断。对刚塑性材料，${ \bar { \sigma } } _ { 1 } = { \bar { \sigma } }$ ，所以极限是

$$
\sigma _ { d } \; = \; { \bar { \sigma } } \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; < \; { \bar { \sigma } } \qquad \Longrightarrow \qquad \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; < \; 1 \qquad \Longrightarrow \qquad { \frac { A _ { 1 } } { A _ { 0 } } } \; > \; { \frac { 1 } { e } } \; = \; 0 . 3 7
$$

**理想情形每道最大面积减缩 $6 3 \ \ \%$ ，而计入摩擦、模角和多余功之后，实际通常是 30-45 % 。****这一个不等式就是线材车间的拉线上放五副模具而不是一副的原因，也是挤压能一道从 150 mm 坯料到 15 mm 型材而拉拔不能的原因。**
:::

::: example 挤压铝型材 {#ex-extrude level=3 check="3.15"}
直径 $1 5 0 \ \mathrm { m m }$ 、长 $3 0 0 \ \mathrm { m m }$ 的 6063 坯料在 $4 5 0 \ \mathrm { ^ { \circ } C }$ 下直接挤压成截面积 $1 { , } 5 0 0 \ \mathrm { m m } ^ { 2 }$ 的型材。取 ${ \bar { \sigma } } = 2 5 \ \mathrm { M P a }$ ，模具因子 $\psi _ { x } = 1 . 3$ ，挤压筒摩擦系数 $\mu = 0 . 1$ 。求行程开始时的挤压杆力。（输入 MN，保留两位小数。）

$$
R _ { x } = { \frac { \pi \times 7 5 ^ { 2 } } { 1 \, 5 0 0 } } = 1 1 . 8 , \qquad p _ { \text{理想} } = 2 5 \ln 1 1 . 8 = 6 1 . 7 \ \mathrm { M P a }
$$
$$
p _ { \text{正挤} } = 6 1 . 7 \times 1 . 3 \times e ^ { 4 \times 0 . 1 \times 3 0 0 / 1 5 0 } = 8 0 . 2 \times e ^ { 0 . 8 } = 8 0 . 2 \times 2 . 2 3 = 1 7 8 \ \mathrm { M P a }
 \qquad F = 1 7 8 \times 1 7 \, 6 7 0 = { \bf 3 . 1 5 \ M N }
$$

**约 3.2 MN（约 320 吨力），远在一台 150 mm 挤压筒压力机的能力之内，这种压力机的额定值通常是它的三倍以上。**余量是有意的：它应对更硬的合金、更冷的坯料和更高的挤压比，并让挤压杆能以型材需要的速度运行。速度的上限由温度决定，因为变形功使金属升温，出口太热就会撕裂型材表面。同一坯料的反挤压只需 $8 0 \ \mathrm { M P a }$ 和 $1 . 4 2 \ \mathrm { M N }$ ，**少 55 %** ，而且从行程的第一毫米到最后一毫米压力几乎恒定；正挤压中摩擦因子则随坯料变短而减小。代价是反挤压机不容易为空心型材支撑芯棒，而且它的挤压杆还得扛着模具和压余。
:::

## 6. 拉拔

::: definition 拉拔线材、棒材与管材 {#def-drawing}
拉拔是挤压那个做出更好产品的穷亲戚：金属是被**拉过**模具而不是推过的，所以长度只受机组能处理的线卷限制，而产品出来时带着模具的表面、直线度、公差和强度。模具是硬质合金或聚晶金刚石镶件，带半锥角为 $\alpha$ 的锥形入口（钢线典型为 $6 { - } 1 0 ^ { \circ }$ ），一段短的圆柱形**定径带**用来确定产品尺寸并把它擦亮，还有一个钟形出口，让线材离开时不会反刮过定径带。

应力就是上面推出的那个，$\sigma _ { d } = { \bar { \sigma } } ( 1 + \mu / \tan \alpha ) \ln ( A _ { 0 } / A _ { 1 } )$ ，而拉拔车间的一切都由其中的三个因子决定。**模角**在冗余功（大 $\alpha$ 产生死区和剪切锥，多花多达 30 % 的功）与摩擦（小 $\alpha$ 产生长、热、高法向力的接触面）之间做交易：最优值是几度的半锥角，压缩越大越大。**摩擦**就是钢线拉拔前要先做涂层（石灰、硼砂或磷酸盐涂层把干皂粉润滑剂带进模具，并防止焊到模具上）的原因，也是**粘上了金属的模具**先拉出划伤线材、再拉出撕裂线材的原因。**热**：几乎全部塑性功变成热——约 90 %，即泰勒–昆尼（Taylor–Quinney）系数——所以在 ${ \bar { \sigma } } = 5 0 0 \ \mathrm { M P a }$ 、$\varepsilon = 0 . 4$ 下，若热一点也不散出，线材一道就升温 $\Delta T = 0 . 9 \, { \bar { \sigma } } \varepsilon / \rho c _ { p } \approx 5 0 \ \mathrm { K }$ ，摩擦还会再加热；多道累积起来足以破坏润滑剂——这就是多道拉拔机组的**卷筒**要水冷、并兼作牵引的原因。

**管材拉拔**是把管子拉过模具，内部用**固定芯头**（装在芯杆上、位于模孔处，确定内孔）、**游动芯头**（靠摩擦力和压力自行保持在模孔中，可拉长的盘管）或**长芯棒**（一根硬棒随管子一起拉过、事后取出）。**空拉**是没有内部工具的拉拔——一种直径减缩，壁厚通常略有增加。而这个工艺的产品就是它无处不在的原因：拉拔棒材公差 $\pm 0 . 0 2 \ \mathrm { m m }$ 、$R _ { a }$ 为 $0 . 4 \ \mu \mathrm { m }$ ，拉拔管材内孔 $\pm 0 . 0 5 \ \mathrm { m m }$ ，冷拉高碳钢丝抗拉强度超过 $2 { , } 0 0 0 \ \mathrm { M P a }$ ——最强的廉价工程材料之一，而它的强度正是拉拔本身给的。
:::

::: example 从 8 mm 拉到 3.5 mm {#ex-draw level=3 check="5"}
退火低碳钢丝，直径 $8 . 0 \ \mathrm { m m }$ ，要拉到 $3 . 5 \ \mathrm { m m }$ 。需要几道？（输入道次数。）取每道最大面积减缩 $30 \ \ \%$ （由理想的 $6 3 \ \ \%$ 扣除摩擦、模角和硬化的影响），并取 ${ \bar { \sigma } } = 2 5 0 \ \mathrm { M P a }$ ，$\mu = 0 . 0 8$ ，$\alpha = 6 ^ { \circ }$ 。

每道的面积比是 $A _ { 1 } / A _ { 0 } = 0 . 7 0$ ，所以道次数为

$$
n \; = \; { \frac { \ln \left[ ( 3 . 5 / 8 . 0 ) ^ { 2 } \right] } { \ln 0 . 7 0 } } \; = \; { \frac { - 1 . 6 5 3 } { - 0 . 3 5 7 } } \; = \; 4 . 6 \qquad \Longrightarrow \qquad { \bf 5 \ passes }
$$

而最后一道承受的拉拔应力为

$$
\sigma _ { d } \; = \; 2 5 0 \left( 1 + { \frac { 0 . 0 8 } { \tan 6 ^ { \circ } } } \right) \ln ( 1 / 0 . 7 0 ) \; = \; 2 5 0 \times 1 . 7 6 \times 0 . 3 5 7 \; = \; 1 5 7 \ \mathrm { M P a }
$$

**五副模具、五个卷筒，总面积减缩 $8 1 \ \ \%$ 。**（$\bar { \sigma }$ 取常数是一种简化：线材逐道硬化，实际规程每道都要提高流变应力，并可能需要中间退火。） **摩擦项在理想功之上值 76 %：$\mu / \tan \alpha = 0 . 7 6$ ，所以模角和润滑剂加起来比变形本身还贵。** **这就是为什么线材车间的耗材是模具和润滑剂，也是为什么模具状态和润滑决定一条机组的断丝次数。**
:::

## 7. 成形带来什么，又花费什么

::: definition 成形与替代方案的对比 {#def-economics}
$$
\begin{array} { l l l l l }
& \textbf{铸造} & \textbf{锻造} & \textbf{挤压} & \textbf{机加工} \\ \hline
\text{相对密度} & 9 7 { - } 9 9 \ \ \% & 1 0 0 \ \ \% & 1 0 0 \ \ \% & 1 0 0 \ \ \% \\
\text{晶粒} & \text{等轴枝晶，有偏析} & \text{流线沿零件走} & \text{强轴向纤维} & \text{横切纤维} \\
\text{同合金疲劳强度} & 0 . 6 { - } 0 . 8 \times & 1 . 0 \times & 0 . 9 \times \text{（沿纤维）} & 0 . 8 { - } 1 . 0 \times \\
\text{公差} & \pm 1 { - } 3 \ \mathrm { m m } & \pm 0 . 3 { - } 1 \ \mathrm { m m } & \pm 0 . 1 { - } 0 . 5 \ \mathrm { m m } & \pm 0 . 0 2 \ \mathrm { m m } \\
R _ { a } \ [ \mu \mathrm { m } ] & 1 2 { - } 2 5 & 6 { - } 1 2 & 1 . 6 { - } 3 . 2 & 0 . 4 { - } 3 . 2 \\
\text{最小截面} & 5 \ \mathrm { m m } & 3 \ \mathrm { m m } \text{（铝）} & 0 . 8 \ \mathrm { m m } & \text{受刀具限制} \\
\text{工装} & \pounds 5 { - } 4 0 \mathrm { k } & \pounds 2 0 { - } 1 5 0 \mathrm { k } & \pounds 3 { - } 2 0 \mathrm { k } \text{ 每型材} & \text{无} \\
\text{速率} & \text{小时级} & 1 { - } 6 0 / \mathrm { m i n } & 0 . 1 { - } 1 \ \mathrm { m / s } & \text{每件数分钟} \\
\text{buy-to-fly 比} & 1 . 2 { - } 2 & 1 . 2 { - } 2 . 5 & 1 . 0 5 { - } 1 . 3 & 3 { - } 1 0
\end{array}
$$

规律是一致的，而且它不是可以两头占的权衡。**当零件需要那个组织时选成形**——疲劳、冲击、横跨流线的蠕变、耐压致密——**或者当批量让模具回本时**（算术见 [[manufacturing/process-selection]]），**或者当形状长而恒定**（挤压）**或简单而圆**（拉拔、镦粗）。**当形状有凹陷、有模具脱不出来的变截面、有芯棒够不着的孔，或批量低于盈亏平衡点时，避开成形**——这四条里每一条都是在模具报价*之前*做出的设计决定，而不是之后。

最后一行如今已经变成一条设计论据。一个机加工钛支架的 buy-to-fly 是 5-10，锻造的是 1.5-2.5；对一架要采购许多吨钛的机体，按轧材价格和五轴工时计算，这个差值是每个零件成本的一大块。**这就是为什么现代趋势是近净成形、只加工必须保证的面。**
:::

::: example 一个零件的四条路线 {#ex-routes level=3 check="1702"}
一个不锈钢阀体：空心圆柱，内孔 $6 0 \ \mathrm { m m }$ ，法兰面间 $1 1 0 \ \mathrm { m m }$ ，两个径向端口，316L，年产 20,000 件。机加工每小时 80 英镑。求锻造路线与铸造路线之间的盈亏平衡批量。（输入件数，取整。）

**砂型铸造加机加工。**铸件 34 英镑加 45 分钟机加工（60 英镑）= **94 英镑**，buy-to-fly 3.4，模样 6,500 英镑，而且阀体疏松到端口面有 2 % 会渗漏。**锻造加机加工。**三型槽模锻件 18 英镑加 18 分钟机加工（24 英镑）= **42 英镑**，无疏松，流线绕端口圆角走，模具费 95,000 英镑按每件 4.75 英镑摊销——所以是 **46.75 英镑**。**挤压管，机加工。**管坯 11 英镑加 12 分钟（16 英镑）= **27 英镑**，法兰从厚壁管的实心管壁上切出，端口径向加工，纤维沿轴向而不是绕端口圆角走——在中等压力下可以接受，对高负荷承压件不行。**棒料机加工。**约 50 英镑棒料加两小时机加工：**210 英镑**，无工装。

年产 20,000 件时，若管材路线的承压等级和纤维方向可以接受，它最便宜；若不可接受，锻造路线在成本*和*质量上都胜过铸造，而这个选择是拿模具对铸造路线的盈亏平衡点算出来的——铸造工装 6,500 英镑对 95,000 英镑：$( 9 5 , 0 0 0 - 6 , 5 0 0 ) / ( 9 4 - 4 2 ) = 1 , 7 0 1 . 9$ ，即 **1,702** 件。**年产 1,500 件时铸造赢，疏松被接受，或者重新设计零件，把端口处铸厚一点。**年产 100 件时就用棒料机加工，210 英镑一件，因为没有哪种工装值得买。
:::

## 习题

::: exercise 咬入角极限 {#ex-bite level=2 check="0.13"}
一台轧机轧辊直径 $5 0 0 \ \mathrm { m m }$ ，吃 $4 \ \mathrm { m m }$ 压下量。要让这道轧制能咬入，摩擦系数至少是多少？（$\mu$ 保留两位小数。）
::: solution
$\cos \alpha = 1 - \Delta h / 2 R = 1 - 4 / 5 0 0 = 0 . 9 9 2$ ，$\alpha = 7 . 2 5 ^ { \circ }$ ，$\mu _ { \min } = \tan \alpha = { \bf 0 . 1 3 }$ 。**热轧在 $\mu \approx 0 . 4$ 下运行，毫无问题；用油润滑、$\mu = 0 . 0 5$ 的冷轧只能吃约 $R \mu ^ { 2 } = 2 5 0 \times 0 . 0 5 ^ { 2 } = 0 . 6 3 \ \mathrm { m m }$ ，所以在这台轧机上做 4 mm 冷压下根本咬不进：轧辊会在带钢上打滑。**
:::
:::

::: exercise 轧机弹跳与厚度 {#ex-spring level=2 check="23.6"}
一台刚度系数 $8 \ \mathrm { M N / m m }$ 的轧机以 $3 . 2 \ \mathrm { M N }$ 的轧制力轧到出口厚度 $2 4 . 0 \ \mathrm { m m }$ 。辊缝必须设到多少？（输入 mm，保留一位小数。）
::: solution
$\delta = F / G = 3 . 2 / 8 = 0 . 4 0 \ \mathrm { m m }$ ，所以 $s = 2 4 . 0 - 0 . 4 = { \bf 2 3 . 6 \ m m }$ 。**而如果因为钢比计划温度低、轧制力升到 $4 . 0 \ \mathrm { M N }$ ，同一个设定就给出 $2 4 . 1 \ \mathrm { m m }$ ——$0 . 4 \ \ \%$ 的厚度误差。** **这种敏感性正是厚度控制必须是带测厚仪和液压辊缝控制的闭环的原因，也是轧机刚度系数要实测并随时更新的原因。**
:::
:::

::: exercise 更窄飞边桥的锻造载荷 {#ex-flash level=2 check="0.89"}
法兰例题里飞边桥在 $4 \ \mathrm { m m }$ 飞边上宽 $1 0 \ \mathrm { m m }$ ，给出 $p _ { \text{飞边} } = 3 6 0 \ \mathrm { M P a }$ 。若飞边桥减到 $6 \ \mathrm { m m }$ ，求飞边压强和总锻造载荷之比。（载荷比保留两位小数。）
::: solution
$p _ { \text{飞边} } = 2 \times 8 0 \times ( 1 + 6 / 8 ) = 2 8 0 \ \mathrm { M P a }$ ，所以总压强从 $3 6 0 + 4 0 0 = 7 6 0$ 降到 $2 8 0 + 4 0 0 = 6 8 0 \ \mathrm { M P a }$ ，载荷比为 $6 8 0 / 7 6 0 = { \bf 0 . 8 9 }$ 。**飞边桥砍 40 % 只换来载荷降 11 %——因为模腔自身的变形压强占总数一半以上，而飞边桥碰不到它。** **改为把飞边厚度加倍到 $8 \ \mathrm { m m }$ ，$p _ { \text{飞边} }$ 降到 $2 \times 8 0 \times ( 1 + 0 . 6 2 5 ) = 2 6 0 \ \mathrm { M P a }$ ，载荷降 $1 3 \ \ \%$ ——但更厚、更短的飞边也降低了充满模腔所需的背压，这就是为什么模具设计师靠试验和仿真、而不只靠算术来定它。**
:::
:::

::: exercise 挤压比与压力 {#ex-ext level=2 check="2.4"}
一根 $2 0 0 \ \mathrm { m m }$ 铝坯挤压成 $2 { , } 0 0 0 \ \mathrm { m m } ^ { 2 }$ 的型材。求挤压比，以及理想压力与 $1 0 { , } 0 0 0 \ \mathrm { m m } ^ { 2 }$ 型材之比。（压力比保留一位小数。）
::: solution
$R _ { x } = \pi \times 1 0 0 ^ { 2 } / 2 \, 0 0 0 = 1 5 . 7$ ，而 $p \propto \ln R _ { x }$ ，所以比值是 $\ln 1 5 . 7 / \ln 3 . 1 4 = 2 . 7 5 / 1 . 1 4 = { \bf 2 . 4 }$ 。**细五倍的产品只花 2.4 倍的理想压力。** **这个对数就是为什么挤压是制造细截面最便宜的办法，也是为什么一个车间的挤压极限图是按压杆载荷和坯料温度画的，而不是按型材画的。**
:::
:::

::: exercise 一道拉拔的最大减缩 {#ex-drawlvl level=2 check="43"}
用 $\sigma _ { d } = { \bar { \sigma } } ( 1 + \mu / \tan \alpha ) \ln ( A _ { 0 } / A _ { 1 } )$ ，$\mu = 0 . 0 8$ ，$\alpha = 6 ^ { \circ }$ ，若极限是 $\sigma _ { d } = { \bar { \sigma } }$ ，求每道最大面积减缩。（输入百分数，取整到个位。）
::: solution
$\ln ( A _ { 0 } / A _ { 1 } ) = 1 / 1 . 7 6 = 0 . 5 6 8$ ，$A _ { 1 } / A _ { 0 } = e ^ { - 0 . 5 6 8 } = 0 . 5 6 7$ ，所以减缩是 $1 - 0 . 5 6 7 = 0 . 4 3 3 \approx { \bf 4 3 \ \ \% }$ ，而车间用 30-35 % ，给磨损的模具、陈旧的润滑剂、略呈椭圆的盘条留出余地。**注意极限是由产品的强度而不是模具的强度定的。对高碳钢丝，索氏体化处理（patenting，拉拔前等温转变为细珠光体）正是使大的总减缩成为可能的工序。**
:::
:::

::: exercise 拉拔热 {#ex-heat level=3 check="49"}
钢丝以平均流变应力 $5 0 0 \ \mathrm { M P a }$ 、应变 $0 . 4$ 拉拔。若塑性功一点也没有散出线材，温升是多少？取 $\rho c _ { p } = 3 . 7 \ \mathrm { M J / m ^ { 3 } K }$ ，泰勒–昆尼（Taylor–Quinney）系数 $0 . 9$ 。（输入 K，取整。）
::: solution
$\Delta T = 0 . 9 \times 5 0 0 \times 1 0 ^ { 6 } \times 0 . 4 / 3 . 7 \times 1 0 ^ { 6 } = { \bf 4 9 \ K }$ 。**每道约五十度，还没算摩擦生热，而且它正比于减缩——这就是为什么高速多道机组在模具之间用水冷卷筒冷却线材，也是为什么道次规程既是力学计算也是热计算。**
:::
:::

::: exercise 再结晶，以及什么算热加工 {#ex-recryst level=3 check="700"}
钛的熔点是 $1 { , } 6 6 8 \ \mathrm { ^ { \circ } C }$ 。取再结晶温度为 $0 . 5 \ T _ { m }$ ，$2 5 0 \ \mathrm { ^ { \circ } C }$ 的成形是热加工还是冷加工？再结晶温度是多少 $^ { \circ } \mathrm { C } \mathrm { ? }$ （输入 $^ { \circ } \mathrm { C }$ ，取整到十位。）
::: solution
$T _ { m } = 1 { , } 9 4 1 \ \mathrm { K }$ ，$0 . 5 T _ { m } = 9 7 0 \ \mathrm { K } = { \bf 7 0 0 \ ^ { \circ } C }$ ——所以 $2 5 0 \ \mathrm { ^ { \circ } C }$ 对钛是**冷加工**，它会加工硬化、回弹，而且道次之间需要退火。**同样是 $2 5 0 \ \mathrm { ^ { \circ } C }$ ，对铅是热加工（0.87 $T _ { m }$ ），对铝也是热加工（0.56 $T _ { m }$ ），对镍是冷加工（0.30 $T _ { m }$ ）：炉子上的读数在你把它按开尔文除以熔点之前说明不了多少。** **这就是为什么"温锻"只有在点名合金时才是有意义的说法，也是为什么一张钛的工艺卡写了"在 $9 5 0 \ \mathrm { ^ { \circ } C }$ 锻造"，还必须写明是在 $\alpha + \beta$ 相区还是 $\beta$ 相区、用什么模具、应变速率多少。**

::: exercise 推导咬入条件并求值 {#ex-derivebite level=4 check="4.4"}
证明 $\Delta h _ { \max } = 2 R \mu ^ { 2 } / ( 1 + \mu ^ { 2 } )$ ，并求轧辊直径 $4 0 0 \ \mathrm { m m }$ 、$\mu = 0 . 1 5$ 时每道最大压下量。（输入 mm，保留一位小数。）
::: solution
摩擦以 $\mu N \cos \alpha$ 拉入，法向反力以 $N \sin \alpha$ 推出，咬入要求 $\mu > \tan \alpha$ ，所以 $\alpha _ { \max } = \arctan \mu$ ，$\cos \alpha _ { \max } = 1 / \sqrt { 1 + \mu ^ { 2 } }$ 。由 $\cos \alpha = 1 - \Delta h / 2 R$ ，
$$
\Delta h _ { \max } = 2 R \left( 1 - { \frac { 1 } { \sqrt { 1 + \mu ^ { 2 } } } } \right) = 4 0 0 \left( 1 - { \frac { 1 } { \sqrt { 1 . 0 2 2 5 } } } \right) = 4 0 0 \times 0 . 0 1 1 0 6 = { \bf 4 . 4 \ m m }
$$
由于小 $\mu$ 时 $1 - 1 / \sqrt { 1 + \mu ^ { 2 } } \approx \mu ^ { 2 } / 2$ ，$\Delta h _ { \max } \approx R \mu ^ { 2 }$ 。**精确表达式给出 $4 . 4 \ \mathrm { m m }$ ，近似式 $R \mu ^ { 2 } = 4 . 5 \ \mathrm { m m }$ ，差 $2 \ \ \%$ ——近似式是应该记住的，精确式是道次接近极限时该用的。** **注意平方的作用：摩擦加倍，能吃的压下量翻四倍，这就是为什么高摩擦的热轧是大压下工艺，而有润滑的冷轧是小压下工艺。**
:::
:::

::: exercise 由变形功推导轧制功率 {#ex-derivepower level=4 check="1.3"}
用 $P = { \bar { \sigma } } \varepsilon \dot { V }$ 计算例题板带（宽 $3 0 0 \ \mathrm { m m }$ ，$3 0 \to 2 4 \ \mathrm { m m }$ ，${ \bar { \sigma } } = 2 5 0 \ \mathrm { M P a }$ ，$1 0 0 \ \mathrm { r p m }$ ，轧辊 $6 0 0 \ \mathrm { m m }$ ）的理想轧制功率，并与力矩乘转速估计的 $1 . 7 \ \mathrm { M W }$ 比较。（输入 MW，保留一位小数——理想值。）
::: solution
$\varepsilon = \ln ( 3 0 / 2 4 ) = 0 . 2 2 3$ 。轧制速度 $v = \pi D N = \pi \times 0 . 6 \times 1 0 0 / 6 0 = 3 . 1 4 \ \mathrm { m / s }$ ，体积流量 $\dot { V } = w h _ { 1 } v = 0 . 3 0 0 \times 0 . 0 2 4 \times 3 . 1 4 = 0 . 0 2 2 6 \ \mathrm { m ^ { 3 } / s }$ 。于是
$$
P = 2 5 0 \times 1 0 ^ { 6 } \times 0 . 2 2 3 \times 0 . 0 2 2 6 = { \bf 1 . 3 \ M W }
$$
**理想估计是 $1 . 3 \ \mathrm { M W }$ ，力矩估计是 $1 . 7 \ \mathrm { M W }$ ；差额约为较大值的四分之一，就是约束因子 $Q = 1 . 2$ 和力臂 $L / 2$ 带进第二个估计的摩擦与多余功。轴承和传动损失还要另加在两者之上。** **理想功是一个下限：按它选电机，轧机的功率就不够。**
:::
:::

::: quiz 为什么同合金的锻件比铸件强 {#quiz-forgestrength}
- [ ] 因为锻造加热金属，热处理隐含其中
- [x] 因为锻造闭合了气孔、打碎了铸造组织、并把流线对齐到零件轮廓
- [ ] 因为锻造使金属加工硬化
- [ ] 因为锻件表面质量更好
::: solution
**全部致密性理由加在一起：相对密度从 97-99 % 到 100 % ，细等轴再结晶组织取代粗枝晶和偏析带，夹杂物和析出相构成的纤维沿形状走而不是被形状切断。** **加工硬化*不是*理由——热锻在再结晶温度以上，留下的硬化很少，而且疲劳优势在最终热处理之后仍然存在。表面质量比机加工过的铸件差，四条理由里它最不重要。**
:::
:::

::: quiz 为什么挤压能吃 90 % 的面积减缩而拉拔只能 40 % {#quiz-extrude-draw}
- [ ] 挤压模具比拉拔模具更硬
- [ ] 挤压是热的而拉拔是冷的
- [x] 挤压中工件被约束且处于压缩；拉拔中被拉出的产品必须不屈服地承受整个拉拔应力
- [ ] 挤压用润滑剂而拉拔不用
::: solution
**拉拔的极限是 $\sigma _ { d } < \sigma _ { y , \text{出口} }$ ：离开模具的线材悬挂着全部载荷，若应力超过它自己的流变应力，它就一路颈缩直到拉断。** **挤压中坯料在挤压筒里，应力状态是三向压缩，没有任何颈缩模式可用——所以 $R _ { x }$ 受压力机和模具限制，不受材料限制。冷热、润滑、模具硬度在这个区别面前都是二阶因素，而铝的冷（冲击）挤压常规就能达到 90 % 以上的面积减缩。**
:::
:::

## 后续内容

- **[[manufacturing/sheet-metal-forming|板料成形]]**把同样的流变应力带进一个完全不同的应力状态——拉伸和弯曲一层薄壳而不是压扁一块实心——随之而来的是成形极限图、回弹和拉深，这些在这里都没有对应物。
- **[[manufacturing/casting|铸造]]**供应本课要成形的坯料，而锻件坯料必须是变形坯的原因也在那里：压缩比不足的铸件，就是顶着锻件账单的铸件。
- **[[manufacturing/machining|切削加工]]**是剩下的活：飞边线、基准面和任何模具保证不了的轴承孔。
- **[[manufacturing/joining|连接]]**讲搅拌摩擦焊与搅拌摩擦加工，那是同样的塑性流动，只不过发生在工具轴肩之下而不是模具之中。
- **[[materials-science/dislocations-strengthening|位错与强化]]**是加工硬化、回复与再结晶背后的机理，也是这里每个力计算里 $\sigma = K \varepsilon ^ { n }$ 中 $n$ 的来历。
- **[[solid-mechanics/plasticity|塑性力学]]**给出本课当黑箱使用的屈服准则、流动法则和上下限定理，**[[solid-mechanics/stress-strain-3d|三维应力]]**给出让锻造压强达到流变应力十倍的应力状态。
- **[[manufacturing/process-selection|工艺选择]]**是第 7 节的模具成本与年产量相遇的地方。

::: history
**1784.** **亨利·科特（Henry Cort）**的搅炼法专利包括用槽辊把搅炼铁轧成条材，取代了大部分锤锻，使轧制成为一种结构工艺；三辊、继而四辊轧机，以及二十世纪的连续宽带钢轧机，塑造了现代轧制。**1797.** **约瑟夫·布拉马（Joseph Bramah）**为把软金属挤过模具制管的工艺取得专利——第一种挤压工艺。托马斯·伯尔（Thomas Burr）在 1820 年用液压机把它用于铅管，**1894** 年**亚历山大·迪克（Alexander Dick）**把挤压推广到铜和黄铜合金；铝挤压后来成为窗框、车辆结构和无数型材背后的工艺。**1831–1834.** 哈茨山的矿业官员**威廉·阿尔伯特（Wilhelm Albert）**为克劳斯塔尔的矿井制成第一批钢丝绳，较早证明了成束的拉拔铁丝比链条更强、更可靠。**1842.** **詹姆斯·内史密斯（James Nasmyth）**为蒸汽锤取得专利（弗朗索瓦·布尔东（François Bourdon）已于 1840 年在勒克鲁索造出一台），使大型轴类和锻件可以逐锤受控地锻造。**1930 年代.** 德国发展的磷化转化膜配皂类润滑剂使钢的冷挤压变得实用，它与冷镦和滚丝一起支撑起大批量紧固件工业；滚压螺纹具有不被切断的流线和表面压应力，疲劳性能优于切削螺纹。**1960–1970 年代.** 用于喷气发动机盘件的钛和镍基高温合金**等温锻与热模锻**，模具加热到接近工件温度并采用低应变速率，使最难加工的合金的模锻也接近净形。**1991.** **搅拌摩擦焊**由**韦恩·托马斯（Wayne Thomas）**及其同事在剑桥的焊接研究所（TWI）发明：由旋转工具产生、低于熔点的剧烈塑性流动，也是一系列固相搅拌摩擦工艺中的第一种。
:::

::: summary
**选成形是为了组织，不只是为了形状。**锻造闭合气孔、细化晶粒、把流线沿零件铺排，通常换来 20-40 % 的疲劳强度和更多的韧性；冷加工强化；近净成形省下 buy-to-fly。代价是力、机器和模具。
**力永远是 ${ \bar { \sigma } } \times A \times Q$ ，而 $Q$ 是有意思的那个因子。**工作温度和应变速率下的平均流变应力 $K \varepsilon ^ { n } / ( 1 + n )$ ，接触面积，以及摩擦峰、多余功和飞边带来的、最高约十倍的约束因子。锻造温度下流变应力 $8 0 \ \mathrm { M P a }$ 的钢，在法兰例题中需要 $7 6 0 \ \mathrm { M P a }$ ；难的不是金属，是界面。
**热与冷由再结晶划分，在 $0 . 4 { - } 0 . 5 \ T _ { m }$ （开尔文）。**在其上，几乎不留硬化，只要一小部分的力，但有氧化皮；在其下，硬化、回弹、更好的表面和公差。铅在室温是热加工，钛在 $2 5 0 \ \mathrm { ^ { \circ } C }$ 是冷加工。
**轧制是一道自己拽自己进去的镦粗。**$L = \sqrt { R \Delta h }$ ，$F = { \bar { \sigma } } Q w L$ ，$T = F L / 2$ ，$P = 2 T \omega$ ；咬入需要 $\mu \geq \tan \alpha$ ，所以 $\Delta h _ { \max } \approx R \mu ^ { 2 }$ ——在 600 mm 轧辊上热态约 43 mm，冷态 0.75 mm；而出口厚度是 $s + F / G$ ，这就是厚度控制是反馈回路的原因。
**锻造载荷由飞边决定。**$p _ { \text{飞边} } = 2 \sigma _ { y } ( 1 + a _ { f } / 2 h _ { f } )$ 加上模腔自身的摩擦峰，结果是普通压缩的数倍，最高约十倍。模锻斜度、圆角、分模线、连接筋和预成形不是惯例；它们决定模具填不填得满、切不切得动。
**挤压是一个对数，拉拔是一个极限。**$p = { \bar { \sigma } } \ln R _ { x }$ 乘以模具因子，正挤压再乘 $e ^ { 4 \mu L / D }$ 的挤压筒摩擦；但拉拔中被拉出的产品承受载荷，所以 $\ln ( A _ { 0 } / A _ { 1 } ) < 1$ ，理想 $6 3 \ \ \%$ 、实际每道 30-40 % 的减缩——于是一条线上有多副模具，并在线材延性耗尽处安排退火。
**成形的经济学是模具的经济学。**零点几毫米的公差，buy-to-fly 1.2-2.5，速率每分钟几十件，换来的是数万英镑的工装和一条必须被分模线允许的形状。低于盈亏平衡批量，成形是一种造出昂贵铸件的办法；高于它，机加工是一种造出昂贵锻件的办法。
:::
