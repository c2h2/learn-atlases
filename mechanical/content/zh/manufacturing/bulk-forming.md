一个铁路车轮、一个涡轮盘、一根连杆、一辆自行车的车架管，还有你充电线里的金属丝，有一个共同点：**它们是把固态金属推过屈服点、直到它取得新形状而制成的，而且因此变得更强。**铸造靠放弃组织来获得形状；切削加工靠把组织一片片切屑扔掉来获得形状；成形靠*移动*组织来获得形状——如果做得得当，就把组织移动到载荷将要走的方向上。

这就是体积成形工艺的全部理由，而这个理由用三种货币来计价。**金相学上的**：锻造焊合铸件的收缩疏松，打碎它的粗枝晶和偏析带，把夹杂物和析出相沿零件轮廓排成**流线**——值 20-40 % 的疲劳强度，横向于流线的韧性更是多得多的提升。**经济上的**：一个锻件或挤压件是每分钟一个零件的近净形，而机加工件是每小时一个零件，还从一块两倍质量的坯料开始。**力学上的**：冷加工*强化*产品——一根拉拔钢丝的抗拉强度是 2 GPa，而同样的钢退火后只有 400 MPa——所以这个工艺同时也是一道热处理。代价是成形需要**力**：兆牛级的力，于是一台价值数百万的机器，和一副价值数万、还会磨损的模具。本课讲的就是计算这个力，因为力决定机器，机器决定尺寸，而尺寸和模具决定成本。

::: warning 成形出错的五种方式
**把热和冷搞混。**分界不是一个温度，而是**再结晶温度**，约为 $0 . 4 { - } 0 . 5 \ T _ { m }$（以开尔文计）：铅和锡在室温就是热加工，铝在 $2 5 0 \ \mathrm { ^ { \circ } C }$ ，铁在 $6 0 0 \ \mathrm { ^ { \circ } C }$ ，钨在 $1 { , } 0 0 0 \ \mathrm { ^ { \circ } C }$ 。在其下加工，金属加工硬化，越打越硬，回弹，可能开裂；在其上加工，它软化的速度和硬化一样快，只需要五分之一的力，却会沾上氧化皮、丢掉公差。**按热锻数据表设计的“冷锻”件，是一副会被撑裂的模具。** **设计一个填不满的锻件。**模锻需要金属在十亿帕的压力下到达型腔的每个角落，还需要模具*造得出来*——也就是说要有分型面、$5 { - } 7 ^ { \circ }$ 的模锻斜度、$3 { - } 6 ~ \mathrm { m m }$ 的圆角半径，而且完全不许有凹陷。画出机加工级内圆角锻支架的设计师，画的是一副只有电火花才能加工的模具，一副在一千锤之内就会在那个角上开裂的模具。**因为材料“软”就低估力。**力是**工作温度和应变速率下的流变应力**乘以面积再乘以一个约束因子——而摩擦和飞边带来的约束因子是 2 到 10。热碳钢的流变应力是 $2 0 \ \mathrm { M P a }$ ，模锻压力却是 $1 { , } 5 0 0 \ \mathrm { M P a }$ ，因为飞边通道是一个节流口，而模面粘着工件。**忘了机器是弹性的。**轧机或压力机每兆牛载荷会伸长十分之几毫米，所以载荷下 $2 4 . 0 0 \ \mathrm { m m }$ 的零件，卸载后是 $2 3 . 6 2 \ \mathrm { m m }$ 。**轧机弹跳**不是缺陷，它是厚度控制是反馈回路而不是一个设定的原因。**拿铸件来成形，还管它叫锻件。**如果坯料是有疏松的铸件而变形量又小，疏松就留在原地，流线沿着原来的枝晶走，这个“锻件”就带着铸件的性能、锻件的成本。锻件的坯料必须是轧制或锻造坯，钢锭的压缩比至少 4:1，*锻制*二字才有意义。
:::

## 2. 力：流变应力、面积与约束因子

::: definition 流变应力与成形载荷 {#def-flow}
成形分析从材料在工作温度和应变速率下的**真应力–真应变**曲线开始，通常拟合为

$$
\sigma \; = \; K \varepsilon ^ { n } \qquad \Longrightarrow \qquad { \bar { \sigma } } \; = \; { \frac { 1 } { \varepsilon } } \int _ { 0 } ^ { \varepsilon } K \varepsilon ^ { \prime n } \, d \varepsilon ^ { \prime } \; = \; { \frac { K \varepsilon ^ { n } } { 1 + n } } \; = \; { \frac { \sigma _ { \text{终} } } { 1 + n } }
$$

其中 $n$ 是加工硬化指数——而进入载荷计算的是平均流变应力，不是最终值。成形力则永远是同样三样的乘积：

$$
F \; = \; \underbrace { { \bar { \sigma } } } _ { \text{材料} } \; \times \; \underbrace { A } _ { \text{接触面积} } \; \times \; \underbrace { Q } _ { \text{约束因子} }
$$

约束因子 $Q$ 是一切微妙之处所在，它有三个来源。模面上的**摩擦**阻止表面扩展，于是内部被夹在两块夹紧的板之间挤压——一种三向压缩状态，其中维持屈服所需的压强在中心升到 $2 \\sigma _ { y }$ ，边缘更高；这就是下面推导的**摩擦峰**，在一个锻件或一道轧制里值 2-8 倍。**多余功**——模角附近和中心的金属因为几何的强迫必须比平均变形更多——再加 10-30 %。模锻的**飞边与飞边桥几何**可以再加 3-10 倍因子，因为金属必须挤过一条薄、长、高摩擦的通道才能充满模腔，于是型腔内的压强就由那条通道决定，而与工件根本无关。

两个值得背下来的推论。**力对材料硬度的依赖，恰好在你不希望它那样、而不以你希望的那样**：$1 1 0 0 \ \mathrm { ^ { \circ } C }$ 的热碳钢流变应力 $2 0 \ \mathrm { M P a }$ ，模锻压力却是 $1 { , } 5 0 0 \ \mathrm { M P a }$ 。而**让轧机停下来的不是力，是功率**：$P = F v$ ，一台以 $1 { , } 5 0 0 \ \mathrm { m / m i n }$ 轧制的热带钢轧机，要用十兆瓦去干一件力上吊车就能举起的活。
:::

::: proof 摩擦峰：为什么锻盘中心的压强是边缘的两倍 {#proof-hill}
取厚 $h$ 的板坯在平模间压缩，半宽 $a$ ，在距中心 $x$ 处切一个宽 $d x$ 的竖直单元。单元的横向平衡给出

$$
\frac { d \sigma _ { x } } { d x } \; = \; { \frac { 2 \tau } { h } }
$$

其中 $\tau$ 是界面切应力。用特雷斯卡（Tresca）摩擦条件 $\tau = m \sigma _ { y } / 2$ （常数摩擦因子 $m$ ，界面粘着时成立）和平面应变下的屈服准则 $\sigma _ { y } = \sigma _ { z } - \sigma _ { x }$ ，从自由边缘（$\sigma _ { x } = 0$ ）积分得

$$
p ( x ) \; = \; \sigma _ { y } \left[ \, 1 \; + \; { \frac { m } { h } } ( a - x ) \, \right] \qquad \text{而库仑（Coulomb）摩擦 } \tau = \mu p \text{ 时，} \qquad p ( x ) \; = \; \sigma _ { y } \, \exp \! \left[ { \frac { 2 \mu } { h } } ( a - x ) \right]
$$

**压强随模宽与工件厚度之比呈指数（最好情形是线性）增长，而且中心最大。**$a / h = 1 0$ 、$\mu = 0 . 1$ 时，中心压强是流变应力的 $e ^ { 2 } = 7 . 4$ 倍；$a / h = 2$ 时只有 1.5 倍。由此得出图中的三条实用规则：**薄而宽的零件，其机器尺寸由摩擦决定而不是由材料决定**；**润滑靠攻击指数起作用**，钛锻件上好的玻璃润滑剂把峰值压强砍半；而**粘着正是锻件表面纹理成为模具复制品的原因**，因为一旦 $\tau = \mu p$ 超过金属的剪切屈服强度 $k = \sigma _ { y } / { \sqrt { 3 } }$ ，再大的压强也不能让表面滑动，金属是绕着一块粘在它上面的模具变形的。
:::

:::

## 3. 轧制

::: definition 几何、力与弹跳 {#def-rolling}
板带轧制是一道靠自身摩擦把工件拽进去的连续镦粗。整个几何就是一个直角三角形：半径 $R$ 的轧辊把厚度从 $h _ { 0 }$ 减到 $h _ { 1 }$ ，所以

$$
\Delta h \; = \; h _ { 0 } - h _ { 1 } , \qquad L \; = \; { \sqrt { R \, \Delta h } } \qquad \text{（接触长度，} \Delta h \ll R \text{）}
$$

接触面积 $A = w L$ 。力、力矩和功率随之而来，其中约束因子 $Q _ { x }$ 计入摩擦峰以及带钢很宽（平面应变，所以轻压下 $Q _ { x } \approx 1 . 2$ ，重压下可达 2）这两件事：

$$
F \; = \; { \bar { \sigma } } \, Q _ { x } \, w L , \qquad T \; = \; { \frac { F L } { 2 } } \ \text{每辊 } ( \text{力臂 } \approx L / 2 ) , \qquad P \; = \; 2 \, T \, \omega \; + \; \text{损失}
$$

两个极限决定一台轧机能干什么。**咬入条件**（下面推导）说摩擦必须能把带钢拉进来：$\mu \geq \tan \alpha$ ，其中 $\alpha$ 是接触角，$\cos \alpha = 1 - \Delta h / 2 R$ ，所以**每道最大压下量是 $\Delta h _ { \max } = 2 R \mu ^ { 2 } / ( 1 + \mu ^ { 2 } ) \approx 2 R \mu ^ { 2 }$** ——这就是为什么热轧（氧化皮充当固体润滑剂，$\mu \approx 0 . 4$ ）吃 30-50 % 的压下量，而油润滑冷轧钢（$\mu \approx 0 . 0 5 )$ 只吃 2-5 % 。**轧机弹跳**：机架、压下螺丝和轧辊按 $\delta = F / G$ 弹性伸长，$G$ 是**轧机刚度系数**，典型 $5 { - } 2 0 \ \mathrm { M N / m m }$ ，所以出口厚度是

$$
h _ { 1 } \; = \; s \; + \; { \frac { F } { G } } \qquad ( s \ \text{为辊缝设定值} )
$$

而 $F$ 本身又依赖 $h _ { 1 }$ ，所以厚度是一个**反馈问题**，实践中由读测厚仪和张力的液压厚度自动控制回路解决，在旧时代则由操作工盯着压下螺丝上的一道刻线解决。
:::

::: proof 咬入条件 {#proof-bite}
在入口处，轧辊以与竖直方向成接触角 $\alpha$ 的法向力 $N$ 咬住带钢，摩擦力 $\mu N$ 与带钢成 $\alpha$ 角。沿轧入方向分解：摩擦以 $\mu N \cos \alpha$ 把带钢**拉入**，法向反力以 $N \sin \alpha$ 把它**推出**。带钢被拉入的条件是

$$
\mu N \cos \alpha \; > \; N \sin \alpha \qquad \Longleftrightarrow \qquad \mu \; > \; \tan \alpha
$$

而接触角满足 $\cos \alpha = 1 - \Delta h / 2 R$ ，所以还能咬得住的最大压下量是

$$
\Delta h _ { \max } \; = \; 2 R ( 1 - \cos \alpha _ { \max } ) \; = \; 2 R \, { \frac { \mu ^ { 2 } } { 1 + \mu ^ { 2 } } } \; \approx \; 2 R \mu ^ { 2 }
$$

**这就是热轧作为重工艺、冷轧作为轻工艺存在的原因。**$\mu = 0 . 4$ （热钢对钢，带氧化皮）、$R = 3 0 0 \ \mathrm { m m }$ 时，$\Delta h _ { \max } = 9 4 \ \mathrm { m m }$ ——轧机吃得下钢锭板，限制它的是电机不是咬入。$\mu = 0 . 0 5$ （油润滑冷轧）时，同一台轧机被限制在 $1 . 5 \ \mathrm { m m }$ ，这就是为什么冷连轧机组要在 2,000 m/min 下用五个机架把 25 mm 的热轧卷减到 0.3 mm 薄板、每次吃 5-15 % ，也是为什么**保护表面和轧辊的润滑剂，恰恰就是阻止轧机咬入的东西**——最深的冷下压是干轧，或故意涂一层高摩擦的磷皂化膜让金属抓得住。
:::

::: example 一道轧制：力、力矩、功率与弹跳 {#ex-roll level=3 check="3.8"}
低碳钢带钢宽 $3 0 0 \ \mathrm { m m }$ 、厚 $3 0 \ \mathrm { m m }$ ，在直径 $6 0 0 \ \mathrm { m m }$ 的轧辊上以 $1 0 0 \ \mathrm { r p m }$ 减薄到 $2 4 \ \mathrm { m m }$ 。$1 { , } 0 0 0 \ \mathrm { ^ { \circ } C }$ 下的平均流变应力是 $2 5 0 \ \mathrm { M P a }$ ，约束因子 1.2。

$$
L = { \sqrt { 3 0 0 \times 6 } } = 4 2 . 4 \ \mathrm { m m } , \qquad A = 4 2 . 4 \times 3 0 0 = 1 2 \, 7 3 0 \ \mathrm { m m ^ { 2 } }
$$
$$
F = 2 5 0 \times 1 . 2 \times 1 2 \, 7 3 0 = 3 . 8 2 \ \mathrm { M N } , \qquad T = { \frac { F L } { 2 } } = { \frac { 3 . 8 2 \times 1 0 ^ { 6 } \times 0 . 0 4 2 4 } { 2 } } = 8 1 \ \mathrm { k N m }
$$
$$
P = 2 T \omega = 2 \times 8 1 \times 1 0 ^ { 3 } \times { \frac { 2 \pi \times 1 0 0 } { 6 0 } } = { \bf 1 . 7 \ M W } \qquad ( \text{未计损失，损失再加 } 1 0 { - } 2 0 \ \%)
$$

**力是 390 吨，力矩每辊 81 kNm，功率 1.7 MW——大约是现代化热带钢轧机的百分之一，而七分之一道轧制差不多就是这个数。**再看弹跳：轧机刚度系数 $G = 1 0 \ \mathrm { M N / m m }$ 时，机架和轧辊伸长 $3 . 8 2 / 1 0 = 0 . 3 8 \ \mathrm { m m }$ ，所以**辊缝必须设到 $2 3 . 6 2 \ \mathrm { m m }$ 才能轧出 $2 4 . 0 0 \ \mathrm { m m }$** ——而 $F$ 随温度、张力、来料厚度而变，那 $0 . 3 8 \ \mathrm { m m }$ 是个移动靶，这就是厚度控制的全部内容。再看咬入：$\cos \alpha = 1 - 6 / 6 0 0 = 0 . 9 9$ 得 $\alpha = 8 . 1 ^ { \circ }$ 、$\mu _ { \text{所需} } = 0 . 1 4$ ，热态轻松满足。把同一道轧制改成 $\mu = 0 . 0 6$ 的油冷轧，最大压下量塌缩到 $2 \times 3 0 0 \times 0 . 0 6 ^ { 2 } = 2 . 2 \ \mathrm { m m }$ ，那 6 mm 是永远不会发生的。
:::

::: definition 轧机、孔型与板形 {#def-mills}
**二辊**（可逆，每向一道）、**三辊**（工件在直径不同的上下辊之间上下穿行，用于棒材的古老而皮实的布置）、**四辊**（工作辊由大辊支承，中厚板和带钢的通用选择）、**多辊/森吉米尔**（小工作辊加两三排支承环，用于硬薄带和箔材）、**连轧**（四到六个机架串联，各减 20-35 % ，机架间张力控制板度和厚度——热连轧线五分钟内把 250 mm 板坯变成 2 mm 卷）、**行星轧机**（一鼓小辊，一道把 50 mm 板坯轧到 2 mm ），以及**型钢和棒材轧机**（轧辊上一序列槽型——箱型孔、椭圆孔、方孔、立轧孔、花孔——把坯料经二十道走成工字钢、角钢或钢轨）。

型钢轧机的孔型设计是一道体积守恒的设计练习：同样的体积必须通过每个机架，所以面积随速度下降而减小，而孔型必须**充满**——欠充满则截面超差、翼缘起浪；过充满则金属跑进圆角和辊缝，形成飞翅，最终沿中心线形成**鱼腹折叠裂纹**。扁平产品的形状是应力问题：辊缝并不均匀，因为轧辊在载荷下弯曲（**凸度**，靠把轧辊磨成微凸的辊型修正——*辊身曲线*——现代轧机则靠**液压弯辊**和**窜辊或变凸度辊**），也因为辊身中部受热膨胀（**热凸度**，靠异形冷却水集管控制）。中部比边部长带钢是**中浪**，永远压不平；边部长的是**边浪**，会在客户的压机上起浪。两种都在轧机里产生，两种都要等卷打开才看得见。
:::

## 4. 锻造

::: definition 自由锻、模锻，以及决定载荷的飞边 {#def-forging}
**自由锻**把加热的坯料夹在平的或成形但从不封闭它的工具之间；金属从未受约束的地方流动，所以可锻的形状是轴对称或棱柱形的——盘、环、轴、阶梯轴、汽轮机 400 吨的转子、风电塔轴承 25 吨的环。力就是普通的摩擦峰值 $F = { \bar { \sigma } } Q w L$ ，$Q$ 取 1.5-3，公差是一米上 $\pm 5 \ \mathrm { m m }$ 。**模锻（闭式模锻）**把金属封闭在两块于**分模线**处合拢的模块切出的型腔里；放上坯料，压力机合模，金属充满模腔，直到一层多余的薄筋——**飞边**——流入模具周围一条浅的飞边桥。飞边不是缺陷而是**液压节流口**：它在模腔内的金属之前冷却结硬，变得极难被推过，从而把模具内的压力抬升到足以充满圆角。它花掉 5-15 % 的钢材和一副切边模，也是模锻载荷是普通压缩载荷三到十倍的原因。

设计词汇表由模具决定，不由设计师决定：**分模线**（通常在零件最厚处，而且总会留下一条必须磨掉或机加工掉的飞边线）、让锻件能脱模的 $5 { - } 7 ^ { \circ }$ **模锻斜度**、内角处 $3 { - } 6 ~ \mathrm { m m }$ 的**圆角半径**（尖锐的内圆角既是填不满的角，也是模具上的裂纹）、**连接筋**（两个凸台之间一条薄筋，之后被机加工掉，因为模具做不出槽）、**预成形与中间坯**型槽（一到三个预备型腔，把金属放到正确的位置，让终成形槽能充满而不折叠），以及**公差**：小型钢锻件 $\pm 0 . 5 \ \mathrm { m m }$ ，冷锻件 $\pm 0 . 1 \ \mathrm { m m }$ 。

机器按它们输出的是**力**还是**能量**来划分。机械或液压**压力机**以可控的行程施加可控的力，应变速率 $1 { - } 3 0 \ \mathrm { s ^ { - 1 } }$ ，用于模锻、等温锻造和任何必须充满的活。**锤**（空落式或双动式）每一锤输出固定能量，应变速率 $1 0 { - } 1 0 0 \ \mathrm { s ^ { - 1 } }$ ，对不完美的预成形很宽容，用于大型自由锻和钛。高应变速率机器——**螺旋压力机**、**高速液压机**、**镦锻机**——以力换速率，正是它们让一小时 200 根连杆成为可能。
:::

::: example 钢法兰需要什么压力机 {#ex-press level=3 check="860"}
在 $1 { , } 1 0 0 \ \mathrm { ^ { \circ } C }$ 的闭式模中，把直径 $6 0 \ \mathrm { m m }$ 、长 $1 0 0 \ \mathrm { m m }$ 的 1045 钢棒镦粗成直径 $1 2 0 \ \mathrm { m m }$ 的法兰。该温度和应变速率下的流变应力是 $8 0 \ \mathrm { M P a }$ ；飞边厚 $4 \ \mathrm { m m }$ ，飞边桥宽 $1 0 \ \mathrm { m m }$ 。

终成形模腔的投影面积是 $A = \pi \times 6 0 ^ { 2 } = 1 1 \, 3 1 0 \ \mathrm { m m } ^ { 2 }$ 。把摩擦峰结果用于厚 $h _ { f } = 4 \ \mathrm { m m }$ 、桥宽 $a _ { f } = 1 0 \ \mathrm { m m }$ 的通道，把金属挤过飞边桥所需的压强是

$$
p _ { \text{飞边} } \; = \; 2 \sigma _ { y } \left( 1 + { \frac { a _ { f } } { 2 h _ { f } } } \right) \; = \; 2 \times 8 0 \times ( 1 + 1 . 2 5 ) \; = \; 3 6 0 \ \mathrm { M P a }
$$

而模腔内的压强是这个飞边压强**加上**金属在自身摩擦峰下变形所需的压强——对 $2 \sigma _ { y }$ 取 2-3 的约束因子：

$$
p _ { \text{平均} } \; \approx \; p _ { \text{飞边} } + 2 . 5 \times 2 \sigma _ { y } \; = \; 3 6 0 + 4 0 0 \; = \; 7 6 0 \ \mathrm { M P a }
 \qquad \Longrightarrow \qquad F \; = \; 7 6 0 \times 1 1 \, 3 1 0 \; = \; 8 . 6 \ \mathrm { M N } \; \approx \; { \bf 8 6 0 \ t }
$$

**八百六十吨，为一个如果温热、无润滑、又无处可去的话你用手就能捏扁的零件——十倍因子的全部来源是飞边和摩擦峰。**注意这个计算让什么变便宜、让什么变贵：**把飞边桥从 $1 0 \ \mathrm { m m }$ 减薄到 $6 \ \mathrm { m m }$ ，飞边压强降四分之一，省 90 吨**；把飞边加厚则省得更多——但飞边太少模具就填不满，这正是模具设计师靠试验和仿真来权衡的地方。还要注意答案是一个**行程上的力**：同一件法兰用锤打，需要在坯料冷到 $9 5 0 \ \mathrm { ^ { \circ } C }$ 以下之前用三四锤把能量输入进去，那是另一套计算，也是一个只有锤的车间做不了薄壁模锻件的原因。
:::

## 5. 挤压

::: definition 把金属挤过孔洞 {#def-extrusion}
**正（直接）挤压**中，挤压筒里的坯料被挤压杆推动，金属*朝着*挤压杆流动，从远端的模孔流出；**反（间接）挤压**中，模具装在挤压杆上，金属*穿过挤压杆*流动，坯料不沿挤压筒滑动。**挤压比**是 $R _ { x } = A _ { 0 } / A _ { 1 }$ ，典型 10-100，单位体积的理想功与拉拔相同——对数应变乘以流变应力，$w = { \bar { \sigma } } \ln R _ { x }$ ——所以理想压力是

$$
p _ { \text{理想} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \qquad \Longrightarrow \qquad p _ { \text{正挤} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \; \underbrace { \psi _ { x } } _ { \text{模具，} 1 . 2 - 1 . 6 } \; \underbrace { \left( 1 + { \frac { 2 \mu L } { D } } \right) } _ { \text{挤压筒摩擦} } \qquad p _ { \text{反挤} } \; = \; { \bar { \sigma } } \, \ln R _ { x } \, \psi _ { x }
$$

挤压筒摩擦项就是两种机器之间争论的全部：它随坯料长度 $L$ 增长，所以正挤压机随着坯料被用完而损失压力（因而损失速度，因而损失温度均匀性）；这也是为什么钢挤压——坯料 $1 { , } 1 5 0 \ \mathrm { ^ { \circ } C }$ ，挤压筒 $4 0 0 \ \mathrm { ^ { \circ } C }$ ，润滑剂是一层 $0 . 2 \ \mathrm { m m }$ 的玻璃膜——用短坯料和巨型压力机，而铝的反挤压能用长坯料恒载运行，还能通过芯棒必须从挤压杆上得到支撑的模具挤出**空心**截面。

模具本身是一块磨出截面形状的工具钢，带着 $1 { - } 3 \ \mathrm { m m }$ 的定径带，定径带确定最终尺寸并控制**金属流动**：外行的模具让离定径带最近的金属流得最快，于是型材离开时会**翘曲**（弯曲），模具师傅靠**修磨定径带（washering）**来校正——在金属必须流得快的地方把它开宽。复杂型材用**分流组合模（焊合模）**制造：坯料绕着芯棒支架（分流针）分开，又在挤压筒内巨大的静水压力下重新焊合（这就是为什么挤压做空心管和结构空心截面做得那么好：焊合界面是 $6 0 0 \ \mathrm { M P a }$ 压力和 $4 5 0 \ \mathrm { ^ { \circ } C }$ 下的洁净金属对金属接触）。缺陷也因此非常特定：**中心破裂**（模口处拉应力造成的内部纵向裂纹，由模角太小或速度太高引起）、**缩尾**（挤压垫让金属绕过它流动时，坯料末端中心的空腔）、**模痕**（模具磨损造成的周期性凸脊）、**中心破裂与人字裂纹**，以及时效强化合金里的**淬火畸变**。
:::

::: proof 挤压与拉拔的理想功及最大变形量 {#proof-extrude}
取流变应力为 ${ \bar { \sigma } }$ 的理想刚塑性材料，在无摩擦、均匀的变形中把体积 $V$ 从截面积 $A _ { 0 }$ 变形到 $A _ { 1 }$ 。真应变是

$$
\varepsilon \; = \; \ln { \frac { L _ { 1 } } { L _ { 0 } } } \; = \; \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; = \; \ln R _ { x } \; = \; 2 \ln { \frac { d _ { 0 } } { d _ { 1 } } }
$$

（后两个等号靠体积不变），所以**单位体积的理想功**是 $w = { \bar { \sigma } } \varepsilon = { \bar { \sigma } } \ln R _ { x }$ ，而由虚功原理，理想压力或应力就是同一个量：

$$
p _ { \text{理想} } \; = \; { \bar { \sigma } } \ln { \frac { A _ { 0 } } { A _ { 1 } } } \qquad \text{而半锥角 } \alpha \text{ 的锥形模、摩擦系数 } \mu \text{ 时，} \qquad \sigma _ { d } \; = \; { \bar { \sigma } } \left( 1 + { \frac { \mu } { \tan \alpha } } \right) \ln { \frac { A _ { 0 } } { A _ { 1 } } }
$$

现在讲极限。**挤压**中功是压缩功且被挤压筒约束，所以它不会以颈缩失效，$R _ { x }$ 只受压力机和模具限制。**拉拔**中工件悬挂在被拉出的产品上：拉拔应力 $\sigma _ { d }$ 由离开模具的线材承受，而线材的强度是*已变形*金属的流变应力 ${ \bar { \sigma } } _ { 1 }$ 。若 $\sigma _ { d }$ 达到 ${ \bar { \sigma } } _ { 1 }$ ，线材会一路屈服到卷筒然后拉断。对刚塑性材料，${ \bar { \sigma } } _ { 1 } = { \bar { \sigma } }$ ，所以极限是

$$
\sigma _ { d } \; = \; { \bar { \sigma } } \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; < \; { \bar { \sigma } } \qquad \Longrightarrow \qquad \ln { \frac { A _ { 0 } } { A _ { 1 } } } \; < \; 1 \qquad \Longrightarrow \qquad { \frac { A _ { 1 } } { A _ { 0 } } } \; > \; { \frac { 1 } { e } } \; = \; 0 . 3 7
$$

**理想情形每道最大面积减缩 $6 3 \ \ \%$ ，而计入摩擦、模角、硬化和拉拔热之后，实际是 30-45 % 。****这一个不等式就是线材车间的拉线上放五副模具而不是一副的原因，也是挤压能一道从 150 mm 坯料到 15 mm 型材而拉拔不能的原因。**
:::

::: example 挤压铝型材 {#ex-extrude level=3 check="198"}
直径 $1 5 0 \ \mathrm { m m }$ 、长 $3 0 0 \ \mathrm { m m }$ 的 6063 坯料在 $4 5 0 \ \mathrm { ^ { \circ } C }$ 下直接挤压成截面积 $1 { , } 5 0 0 \ \mathrm { m m } ^ { 2 }$ 的型材。取 ${ \bar { \sigma } } = 2 5 \ \mathrm { M P a }$ ，模具因子 $\psi _ { x } = 1 . 3$ ，挤压筒摩擦系数 $\mu = 0 . 1$ 。

$$
R _ { x } = { \frac { \pi \times 7 5 ^ { 2 } } { 1 \, 5 0 0 } } = 1 1 . 8 , \qquad p _ { \text{理想} } = 2 5 \ln 1 1 . 8 = 6 2 \ \mathrm { M P a }
$$
$$
p _ { \text{正挤} } = 6 2 \times 1 . 3 \times \left( 1 + { \frac { 2 \times 0 . 1 \times 3 0 0 } { 1 5 0 } } \right) = 6 2 \times 1 . 3 \times 1 . 4 = 1 1 2 \ \mathrm { M P a }
 \qquad F = 1 1 2 \times 1 7 \, 6 7 0 = { \bf 1 \, 9 8 0 \ k N }
$$

**两千千牛——200 吨——压在一台 6 英寸压力机上，其挤压杆的额定值是 1,000-1,500 吨。**压力机故意选大：多余的容量买到挤压杆速度，而挤压杆速度正是对抗慢挤压造成的冷却、保住坯料温度的东西（6063 坯料以 $4 5 0 \ \mathrm { ^ { \circ } C }$ 进入，出口型材不得超过约 $5 2 0 \ \mathrm { ^ { \circ } C }$ ，这把速度限制在模口处 $1 0 { - } 4 0 \ \mathrm { m m / s }$ ）。同一坯料的反挤压只需 $6 2 \times 1 . 3 = 8 0 \ \mathrm { M P a }$ 和 142 吨，**少 28 %** ，而且从行程的第一毫米到最后一毫米保持压力恒定。代价是反挤压机不容易为空心型材支撑芯棒，而且它的挤压杆还得扛着模具和压余。
:::

## 6. 拉拔

::: definition 拉拔线材、棒材与管材 {#def-drawing}
拉拔是挤压那个做出更好产品的穷亲戚：金属是被**拉过**模具而不是推过的，所以坯料长度只受不会把它压垮的重量限制，而产品出来时带着模具的表面、直线度、公差和强度。模具是硬质合金或聚晶金刚石镶件，钢线总入口角 $1 7 { - } 2 1 ^ { \circ }$ 、铝棒 $6 0 { - } 7 0 ^ { \circ }$ ，**定径带**为线径的 $0 . 1 { - } 0 . 3$ 倍，用来确定产品尺寸并把它擦亮，还有一个钟形出口，让线材离开时不会反刮过定径带。

应力就是上面推出的那个，$\sigma _ { d } = { \bar { \sigma } } ( 1 + \mu / \tan \alpha ) \ln ( A _ { 0 } / A _ { 1 } )$ ，而拉拔车间的一切都由其中的三个因子决定。**模角**在冗余功（大 $\alpha$ 产生死区和剪切锥，多花多达 30 % 的功）与摩擦（小 $\alpha$ 产生长、热、高法向力的接触面）之间做交易：钢的最优值是 $\alpha \approx 5 { - } 8 ^ { \circ }$ ，铝是 $1 0 { - } 1 5 ^ { \circ }$ 。**摩擦**就是钢线要先过石灰再过肥皂（磷酸盐涂层携带润滑剂并防止焊到模具上）的原因，是铝棒干拉或用蜡的原因，也是**粘上了金属的模具**先拉出划伤线材、再拉出撕裂线材的原因。**热**：在 $\sigma = 5 0 0 \ \mathrm { M P a }$ 、$\varepsilon = 0 . 4$ 下，几乎全部塑性功变成热，若热不能经传入模具的传导和线材的辐射散出，温度就升高 $\Delta T = 0 . 9 \, { \bar { \sigma } } \varepsilon / \rho c _ { p } \approx 5 0 \ \mathrm { K }$ ，足以毁掉润滑剂——这就是多道棒材机组的**卷筒**要水冷、并兼作牵引机的原因。

**管材拉拔**是把管子拉过**芯棒**（一支长的锥形塞，确定内孔，用于内孔减缩小的长管）或拉过一个**浮动塞**（一支鼓形塞，由模具带入内孔并自定位，用于短厚壁管）或拉过一根**棒**（实心棒拉入内孔、事后再拔出，用于极小内孔）。**沉拉**是无芯棒、内孔不变的拉拔——纯粹的直径减缩，使壁厚增加。而这个工艺的产品就是它无处不在的原因：拉拔棒材公差 $\pm 0 . 0 2 \ \mathrm { m m }$ 、$R _ { a }$ 为 $0 . 4 \ \mu \mathrm { m }$ ，拉拔管材内孔 $\pm 0 . 0 5 \ \mathrm { m m }$ ，冷拉钢丝抗拉强度 $2 { , } 1 0 0 \ \mathrm { M P a }$ ——是工程师花几分之一英镑一公斤就能买到的最强块体材料，而且每拉一米就更强一点。
:::

::: example 从 8 mm 拉到 3.5 mm {#ex-draw level=3 check="5"}
退火低碳钢丝，直径 $8 . 0 \ \mathrm { m m }$ ，要拉到 $3 . 5 \ \mathrm { m m }$ 。取每道最大面积减缩 $30 \ \ \%$ （由理想的 $6 3 \ \ \%$ 扣除摩擦、模角和硬化的影响），并取 ${ \bar { \sigma } } = 2 5 0 \ \mathrm { M P a }$ ，$\mu = 0 . 0 8$ ，$\alpha = 6 ^ { \circ }$ 。

每道的面积比是 $A _ { 1 } / A _ { 0 } = 0 . 7 0$ ，所以道次数为

$$
n \; = \; { \frac { \ln \left[ ( 3 . 5 / 8 . 0 ) ^ { 2 } \right] } { \ln 0 . 7 0 } } \; = \; { \frac { - 1 . 6 5 3 } { - 0 . 3 5 7 } } \; = \; 4 . 6 \qquad \Longrightarrow \qquad { \bf 5 \ passes }
$$

而最后一道承受的拉拔应力为

$$
\sigma _ { d } \; = \; 2 5 0 \left( 1 + { \frac { 0 . 0 8 } { \tan 6 ^ { \circ } } } \right) \ln ( 1 / 0 . 7 0 ) \; = \; 2 5 0 \times 1 . 7 6 \times 0 . 3 5 7 \; = \; 1 5 7 \ \mathrm { M P a }
$$

**五副模具、五个卷筒、一台电机、总面积减缩 $8 1 \ \ \%$ ——加一次中间退火，因为三道之后位错密度已升得足够高，线材的延性几乎耗尽，会在第四副模具里拉断。** **摩擦项在理想功之上值 76 %：$\mu / \tan \alpha = 0 . 7 6$ ，所以模角和润滑剂加起来比变形本身还贵。** **这就是为什么线材车间的耗材是模具和润滑剂，为什么模具要重新研磨几十次，为什么好车间和差车间的差距要用每千米断丝数来衡量。**
:::

## 7. 成形带来什么，又花费什么

::: definition 成形与替代方案的对比 {#def-economics}
$$
\begin{array} { l l l l l }
& \textbf{铸造} & \textbf{锻造} & \textbf{挤压} & \textbf{机加工} \\ \hline
\text{相对密度} & 9 7 { - } 9 9 \ \ \% & 1 0 0 \ \ \% & 1 0 0 \ \ \% & 1 0 0 \ \ \% \\
\text{晶粒} & \text{等轴枝晶，有偏析} & \text{流线沿零件走} & \text{强轴向纤维} & \text{横切纤维} \\
\text{同合金疲劳强度} & 0 . 6 { - } 0 . 8 \times & 1 . 0 \times & 0 . 9 \times \text{（沿纤维）} & 0 . 8 { - } 1 . 0 \times \\
\text{公差} & \pm 1 { - } 3 \ \mathrm { m m } & \pm 0 . 3 { - } 1 \ \mathrm { m m } & \pm 0 . 1 { - } 0 . 5 \ \mathrm { m m } & \pm 0 . 0 2 \ \mathrm { m m } \\
R _ { a } \ [ \mu \mathrm { m } ] & 1 2 { - } 2 5 & 6 { - } 1 2 & 1 . 6 { - } 3 . 2 & 0 . 4 { - } 3 . 2 \\
\text{最小截面} & 5 \ \mathrm { m m } & 3 \ \mathrm { m m } \text{（铝）} & 0 . 8 \ \mathrm { m m } & \text{受刀具限制} \\
\text{工装} & \pounds 5 { - } 4 0 \mathrm { k } & \pounds 2 0 { - } 1 5 0 \mathrm { k } & \pounds 3 { - } 2 0 \mathrm { k } \text{ 每型材} & \text{无} \\
\text{速率} & \text{小时级} & 1 { - } 6 0 / \mathrm { m i n } & 0 . 1 { - } 1 \ \mathrm { m / s } & \text{每件数分钟} \\
\text{buy-to-fly 比} & 1 . 2 { - } 2 & 1 . 2 { - } 2 . 5 & 1 . 0 5 { - } 1 . 3 & 3 { - } 1 0
\end{array}
$$

规律是一致的，而且它不是可以两头占的权衡。**当零件需要那个组织时选成形**——疲劳、冲击、横跨流线的蠕变、耐压致密——**或者当批量让模具回本时**（算术见 [[manufacturing/process-selection]]），**或者当形状长而恒定**（挤压）**或简单而圆**（拉拔、镦粗）。**当形状有凹陷、有模具脱不出来的变截面、有芯棒够不着的孔，或批量低于盈亏平衡点时，避开成形**——这四条里每一条都是在模具报价*之前*做出的设计决定，而不是之后。

最后一行如今已经变成一条设计论据。一个机加工钛支架的 buy-to-fly 是 5-10，锻造的是 1.5-2.5；在一架用钛的 20 吨机身里，按车间产品每公斤 12 英镑、五轴工时每小时 110 英镑算，这个差值比工艺之间的差值更值钱。**这就是为什么现代趋势是近净成形、只加工必须保证的面，也是为什么"净形锻造"这个说法是商业论据而不是技术论据。**
:::

::: example 一个零件的四条路线 {#ex-routes level=3 check="1880"}
一个不锈钢阀体：空心圆柱，内孔 $6 0 \ \mathrm { m m }$ ，法兰面间 $1 1 0 \ \mathrm { m m }$ ，两个径向端口，316L，年产 20,000 件。

**砂型铸造加机加工。**铸件 34 英镑加 45 分钟机加工 = **95 英镑**，buy-to-fly 3.4，而且阀体疏松到端口面有 2 % 会渗漏。**锻造加机加工。**三型槽模锻件 18 英镑加 18 分钟机加工 = **48 英镑**，无疏松，流线绕端口圆角走，模具费 95,000 英镑按每件 4.75 英镑摊销——所以是 **53 英镑**。**挤压管，机加工。**拉拔/挤压管坯 11 英镑加 12 分钟 = **35 英镑**，端口径向钻削加工，而流线绕内孔的方向对承压件来说是错的——在这个压力下可以接受，在十倍压力下不行。**锻造，深孔钻镗孔，再机加工。**53 英镑减去镗孔 = **46 英镑**，工装 120,000 英镑。

年产 20,000 件时，锻造路线在成本*和*质量上都赢，而决定是拿模具对铸造路线的盈亏平衡点算出来的——铸造工装 6,500 英镑对 95,000 英镑：$( 9 5 , 0 0 0 - 6 , 5 0 0 ) / ( 9 5 - 4 8 ) = { \bf 1 \, 8 8 0 }$ 件。**年产 1,500 件时铸造赢，疏松被接受，或者重新设计零件，把端口处铸厚一点。**年产 100 件时就用棒料机加工，210 英镑一件，没人抱怨，因为图纸本来就是为样机画的。
:::

## 习题

::: exercise 咬入角极限 {#ex-bite level=2 check="0.13"}
一台轧机轧辊直径 $5 0 0 \ \mathrm { m m }$ ，吃 $4 \ \mathrm { m m }$ 压下量。要让这道轧制能咬入，摩擦系数至少是多少？（$\mu$ 保留两位小数。）
::: solution
$\cos \alpha = 1 - \Delta h / 2 R = 1 - 4 / 5 0 0 = 0 . 9 9 2$ ，$\alpha = 7 . 2 5 ^ { \circ }$ ，$\mu _ { \min } = \tan \alpha = { \bf 0 . 1 3 }$ 。**热轧在 $\mu \approx 0 . 4$ 下运行，毫无问题；用油润滑、$\mu = 0 . 0 5$ 的冷轧只能吃 $2 \times 2 5 0 \times 0 . 0 5 ^ { 2 } = 1 . 2 5 \ \mathrm { m m }$ ，这就是为什么在这台轧机上做 4 mm 冷压下，轧辊只会原地打滑，磨着轧辊什么也不干。**
:::
:::

::: exercise 轧机弹跳与厚度 {#ex-spring level=2 check="23.6"}
一台刚度系数 $8 \ \mathrm { M N / m m }$ 的轧机以 $3 . 2 \ \mathrm { M N }$ 的轧制力轧到出口厚度 $2 4 . 0 \ \mathrm { m m }$ 。辊缝必须设到多少？（输入 mm，保留一位小数。）
::: solution
$\delta = F / G = 3 . 2 / 8 = 0 . 4 0 \ \mathrm { m m }$ ，所以 $s = 2 4 . 0 - 0 . 4 = { \bf 2 3 . 6 \ m m }$ 。**而如果因为钢比计划温度低 $3 0 \ \mathrm { K }$ 、轧制力升到 $4 . 0 \ \mathrm { M N }$ ，同一个设定就给出 $2 4 . 1 \ \mathrm { m m }$ ——$3 \ \ \%$ 的温度误差换来 $0 . 4 \ \ \%$ 的厚度误差。** **这种敏感性正是厚度控制必须是带测厚仪和液压压下螺丝的闭环的全部原因，也是一台轧机的"轧机刚度系数"是工艺工程师每周重新标定的数值的全部原因。**
:::
:::

::: exercise 更薄飞边的锻造载荷 {#ex-flash level=2 check="0.95"}
法兰例题里飞边桥在 $4 \ \mathrm { m m }$ 飞边上宽 $1 0 \ \mathrm { m m }$ ，给出 $p _ { \text{飞边} } = 3 6 0 \ \mathrm { M P a }$ 。若飞边桥减到 $6 \ \mathrm { m m }$ ，求飞边压强和总锻造载荷之比。（载荷比保留两位小数。）
::: solution
$p _ { \text{飞边} } = 2 \times 8 0 \times ( 1 + 6 / 8 ) = 3 2 0 \ \mathrm { M P a }$ ，所以总压强从 $3 6 0 + 4 0 0 = 7 6 0$ 降到 $3 2 0 + 4 0 0 = 7 2 0 \ \mathrm { M P a }$ ，载荷比为 $7 2 0 / 7 6 0 = { \bf 0 . 9 5 }$ 。**飞边桥砍 40 % 只换来载荷降 5 %——因为模腔自身的变形压强占总数一半以上，而飞边桥碰不到它。** **真正起作用的杠杆是飞边厚度：把它加倍到 $8 \ \mathrm { m m }$ ，$p _ { \text{飞边} }$ 降到 $2 \times 8 0 \times ( 1 + 0 . 6 2 5 ) = 2 6 0 \ \mathrm { M P a }$ ，载荷降 $1 3 \ \ \%$ ——而同样是飞边厚度，也承担着模腔填不满的风险，这就是为什么模具设计师靠试验而不是靠算术来定它。**
:::
:::

::: exercise 挤压比与压力 {#ex-ext level=2 check="2.4"}
一根 $2 0 0 \ \mathrm { m m }$ 铝坯挤压成 $2 { , } 0 0 0 \ \mathrm { m m } ^ { 2 }$ 的型材。求挤压比，以及理想压力与 $1 0 { , } 0 0 0 \ \mathrm { m m } ^ { 2 }$ 型材之比。（压力比保留一位小数。）
::: solution
$R _ { x } = \pi \times 1 0 0 ^ { 2 } / 2 \, 0 0 0 = 1 5 . 7$ ，而 $p \propto \ln R _ { x }$ ，所以比值是 $\ln 1 5 . 7 / \ln 3 . 1 4 = 2 . 7 5 / 1 . 1 4 = { \bf 2 . 4 }$ 。**细五倍的产品只花 2.4 倍的压力，别的什么都不多花——不多一台机器，不多一套模具，只多一个更慢的挤压杆和一副更长的模具。** **这个对数就是为什么挤压是制造细截面最便宜的办法，也是为什么一个车间的挤压极限图是按压杆载荷和坯料温度画的，而不是按型材画的。**
:::
:::

::: exercise 一道拉拔的最大减缩 {#ex-drawlvl level=2 check="43"}
用 $\sigma _ { d } = { \bar { \sigma } } ( 1 + \mu / \tan \alpha ) \ln ( A _ { 0 } / A _ { 1 } )$ ，$\mu = 0 . 0 8$ ，$\alpha = 6 ^ { \circ }$ ，若极限是 $\sigma _ { d } = { \bar { \sigma } }$ ，求每道最大面积减缩。（输入百分数，取整到个位。）
::: solution
$\ln ( A _ { 0 } / A _ { 1 } ) = 1 / 1 . 7 6 = 0 . 5 6 7$ ，$A _ { 1 } / A _ { 0 } = 0 . 5 6 7$ ，所以减缩是 $1 - 0 . 5 6 7 = 0 . 4 3 3 \approx { \bf 4 3 \ \ \% }$ ，而车间用 30-35 % ，给磨损的模具、陈旧的润滑剂、略呈椭圆的盘条留出余地。**注意极限是由产品的强度而不是模具的强度定的：线材越硬，能吃的道次越少，这就是为什么高碳胎圈钢丝只用 15-20 % 的减缩拉拔，也是为什么索氏体化处理（patenting，拉拔前的一道等温热处理）——为的是让它根本拉得动。**
:::
:::

::: exercise 拉拔热 {#ex-heat level=3 check="49"}
钢丝以平均流变应力 $5 0 0 \ \mathrm { M P a }$ 、应变 $0 . 4$ 拉拔。若塑性功一点也没有散出线材，温升是多少？取 $\rho c _ { p } = 3 . 7 \ \mathrm { M J / m ^ { 3 } K }$ ，泰勒–昆内（Taylor–Quenenne）系数 $0 . 9$ 。（输入 K。）
::: solution
$\Delta T = 0 . 9 \times 5 0 0 \times 1 0 ^ { 6 } \times 0 . 4 / 3 . 7 \times 1 0 ^ { 6 } = { \bf 4 9 \ K }$ 。**五十度，足以让皂类润滑剂碳化、让拉拔产品的回火变软、让模具磨损率翻上好几倍——而且它正比于减缩，这就是为什么高速多道棒材机组在每道之间放水冷卷筒，也是为什么棒材机组的道次规程既是力学计算也是热计算。**
:::
:::

::: exercise 再结晶，以及什么算热加工 {#ex-recryst level=3 check="700"}
钛的熔点是 $1 { , } 6 6 8 \ \mathrm { ^ { \circ } C }$ 。取再结晶温度为 $0 . 5 \ T _ { m }$ ，$2 5 0 \ \mathrm { ^ { \circ } C }$ 的成形是热加工还是冷加工？再结晶温度是多少 $^ { \circ } \mathrm { C } \mathrm { ? }$ （输入 $^ { \circ } \mathrm { C }$ ，取整到十位。）
::: solution
$T _ { m } = 1 { , } 9 4 1 \ \mathrm { K }$ ，$0 . 5 T _ { m } = 9 7 0 \ \mathrm { K } = { \bf 7 0 0 \ ^ { \circ } C }$ ——所以 $2 5 0 \ \mathrm { ^ { \circ } C }$ 对钛是**冷加工**，它会加工硬化、回弹，而且道次之间需要退火。**同样是 $2 5 0 \ \mathrm { ^ { \circ } C }$ ，对铅是热加工，对铝是温加工，对镍是冷加工：炉子上的读数在你把它除以熔点之前什么也不告诉你。** **这就是为什么"温锻"只有在点名合金时才是有意义的说法，也是为什么一张只写"在 $9 5 0 \ \mathrm { ^ { \circ } C }$ 锻造"、不写"在 $\beta$ 相区、等温模具、$1 0 ^ { - 2 } \ \mathrm { s ^ { - 1 } }$ "的工艺卡不是一张工艺卡。**

::: exercise 推导咬入条件并求值 {#ex-derivebite level=4 check="8.8"}
证明 $\Delta h _ { \max } = 2 R \mu ^ { 2 } / ( 1 + \mu ^ { 2 } )$ ，并求轧辊直径 $4 0 0 \ \mathrm { m m }$ 、$\mu = 0 . 1 5$ 时每道最大压下量。（输入 mm，保留一位小数。）
::: solution
摩擦以 $\mu N \cos \alpha$ 拉入，法向反力以 $N \sin \alpha$ 推出，咬入要求 $\mu > \tan \alpha$ ，所以 $\alpha _ { \max } = \arctan \mu$ ，$\cos \alpha _ { \max } = 1 / \sqrt { 1 + \mu ^ { 2 } }$ 。由 $\cos \alpha = 1 - \Delta h / 2 R$ ，
$$
\Delta h _ { \max } = 2 R \left( 1 - { \frac { 1 } { \sqrt { 1 + \mu ^ { 2 } } } } \right) \approx { \frac { 2 R \mu ^ { 2 } } { 1 + \mu ^ { 2 } } } = { \frac { 4 0 0 \times 0 . 0 2 2 5 } { 1 . 0 2 2 5 } } = { \bf 8 . 8 \ m m }
$$
**精确表达式给出 $8 . 8 \ \mathrm { m m }$ ，近似式 $2 R \mu ^ { 2 } = 9 . 0 \ \mathrm { m m }$ ，差 $2 \ \ \%$ ——近似式是应该记住的，精确式是道次接近极限时该用的。** **注意平方的作用：摩擦加倍，能吃的压下量翻四倍，这就是为什么带着氧化皮摩擦的热轧是重工艺，为什么钢铁工业花八十年试图*增大*热轧的摩擦（线材的磷皂化润滑，管材的草酸），又花八十年试图为板带降低它。**
:::

::: exercise 由变形功推导轧制功率 {#ex-derivepower level=4 check="1.3"}
用 $P = { \bar { \sigma } } \varepsilon \dot { V }$ 计算例题板带（宽 $3 0 0 \ \mathrm { m m }$ ，$3 0 \to 2 4 \ \mathrm { m m }$ ，${ \bar { \sigma } } = 2 5 0 \ \mathrm { M P a }$ ，$1 0 0 \ \mathrm { r p m }$ ，轧辊 $6 0 0 \ \mathrm { m m }$ ）的理想轧制功率，并与力乘转矩估计的 $1 . 7 \ \mathrm { M W }$ 比较。（输入 MW，保留一位小数——理想值。）
::: solution
$\varepsilon = \ln ( 3 0 / 2 4 ) = 0 . 2 2 3$ 。轧制速度 $v = \pi D N = \pi \times 0 . 6 \times 1 0 0 / 6 0 = 3 . 1 4 \ \mathrm { m / s }$ ，体积流量 $\dot { V } = w h _ { 1 } v = 0 . 3 0 0 \times 0 . 0 2 4 \times 3 . 1 4 = 0 . 0 2 2 6 \ \mathrm { m ^ { 3 } / s }$ 。于是
$$
P = 2 5 0 \times 1 0 ^ { 6 } \times 0 . 2 2 3 \times 0 . 0 2 2 6 = { \bf 1 . 3 \ M W }
$$
**理想估计是 $1 . 3 \ \mathrm { M W }$ ，实测的力乘转矩值是 $1 . 7 \ \mathrm { M W }$ ，所以 $3 0 \ \ \%$ 的功率花在多余功、摩擦滑动、轧辊变形和传动损失上——一个典型数字，也是两种方法用于不同问题的原因：功法用来问"物理上值多少"，力法用来问"电机必须多大"。** **永远不要混用：把理想功率报给电机厂家，换来的就是一台第一道就跳闸的轧机。**
:::

::: quiz 为什么同合金的锻件比铸件强 {#quiz-forgestrength}
- [ ] 因为锻造加热金属，热处理隐含其中
- [x] 因为锻造闭合了气孔、打碎了铸造组织、并把流线对齐到零件轮廓
- [ ] 因为锻造使金属加工硬化
- [ ] 因为锻件表面质量更好
::: solution
**全部致密性理由加在一起：相对密度从 97-99 % 到 100 % ，细等轴再结晶组织取代粗枝晶和偏析带，夹杂物和析出相构成的纤维沿形状走而不是被形状切断。** **加工硬化*不是*理由——热锻在再结晶温度以上，根本不留硬化，而且疲劳优势在最终热处理之后仍然存在。表面质量比机加工过的铸件差，四条理由里它最不重要。**
:::
:::

::: quiz 为什么挤压能吃 90 % 的面积减缩而拉拔只能 40 % {#quiz-extrude-draw}
- [ ] 挤压模具比拉拔模具更硬
- [ ] 挤压是热的而拉拔是冷的
- [x] 挤压中工件被约束且处于压缩；拉拔中被拉出的产品必须不屈服地承受整个拉拔应力
- [ ] 挤压用润滑剂而拉拔不用
::: solution
**拉拔的极限是 $\sigma _ { d } < \sigma _ { y , \text{出口} }$ ：离开模具的线材悬挂着全部载荷，若应力超过它自己的流变应力，它就一路颈缩直到拉断。** **挤压中坯料在挤压筒里，应力状态是三向压缩，没有任何颈缩模式可用——所以 $R _ { x }$ 受压力机和模具限制，不受材料限制。冷热、润滑、模具硬度在这个区别面前都是二阶因素，而铝的冷挤压在冷态就能吃 90 % 的减缩。**
:::
:::

## 后续内容

- **[[manufacturing/sheet-metal-forming|板料成形]]**把同样的流变应力带进一个完全不同的应力状态——拉伸和弯曲一层薄壳而不是压扁一块实心——随之而来的是成形极限图、回弹和拉深，这些在这里都没有对应物。
- **[[manufacturing/casting|铸造]]**供应本课要成形的坯料，而锻件坯料必须是变形坯的原因也在那里：压缩比不足的铸件，就是顶着锻件账单的铸件。
- **[[manufacturing/machining|切削加工]]**是剩下的活：飞边线、基准面和任何模具保证不了的轴承孔。
- **[[manufacturing/joining|连接]]**讲搅拌摩擦焊与搅拌摩擦加工，那是同样的塑性流动，只不过发生在工具轴肩之下而不是模具之中。
- **[[materials-science/dislocations-strengthening|位错与强化]]**是加工硬化、回复与再结晶背后的机理，也是这里每个力计算里 $\sigma = K \varepsilon ^ { n }$ 中 $n$ 的来历。
- **[[solid-mechanics/plasticity|塑性力学]]**给出本课当黑箱使用的屈服准则、流动法则和上下限定理，**[[solid-mechanics/stress-strain-3d|三维应力]]**给出让锻造压强达到流变应力十倍的应力状态。
- **[[manufacturing/process-selection|工艺选择]]**是第 7 节的模具成本与年产量相遇的地方。

::: history
**1700 年代。**轧制作为轧铅板和铜板的轧机起步，到 **1766** 年亨利·科特（Henry Cort）为搅炼铁条取得的槽辊专利已使它成为结构工艺；一个世纪之内，钢轨轧机以每分钟一吨的速度轧 100 英尺长的钢轨，而 1860 年代的**三辊可逆轧机**和 1920 年代省力的四辊轧机，就是此后每一台中厚板轧机的雏形。**1797。** **挤压压力机的原理**在英国由约瑟夫·布拉马（Joseph Bramah）为铅管取得专利——挤压杆把金属推过模具，正是布拉马压力机与生俱来的用途——该工艺在 **1888** 年为黄铜和铜复兴，然后在 **1930-40 年代**为铝复兴，当时飞机和建筑业对连续结构型材的需求把它变成了今天制造窗框、自行车车架和公交车地板的工艺。**1820-30 年代。**拉拔线材机械化：拉拔台，然后是连续多段式机组，随之而来的发现是拉拔铁线比任何铸造或锻造的它都强——悬索桥的钢丝绳和矿井的提升绳，以及 1840 年代让高碳钢丝根本拉得动的**索氏体化（patenting）**热处理。**1885。** **詹姆斯·纳斯密斯（James Nasmyth）**的蒸汽锤（1842 年专利，1843 年造成）以及随后克虏伯（Krupp）的锻钢炮，确立了重型工程可以被*锻制*而不必铸造，而大锻工们的论争——锻轴比铸轴安全——由铁路车轴的断裂统计一锤定音。**1930-40 年代。**当电动螺旋压力机、磷皂化润滑和低碳冷镦钢丝同时到位，**冷锻与冷镦**成为可能，紧固件工业由此发明：一颗螺栓在四个工位上以每分钟 200 件制成，加工硬化，滚轧螺纹的疲劳强度是切削螺纹的两倍，因为纤维是连续的。**1950-60 年代。** **精密锻造与等温锻造**：为喷气发动机在钛和高温合金上锻到 $\pm 0 . 1 \ \mathrm { m m }$ ，用热模具和低挤压杆速度，以及 **1962** 年让不可能的合金根本能够成形的**粉末冶金**与**快速凝固**路线。**1991。** **搅拌摩擦焊**，由韦恩·托马斯（Wayne Thomas）及其同事在国际焊接研究所（The Welding Institute）取得专利，用旋转轴肩做本课用压力机做的事——熔点以下的剧烈塑性流动——并开创了一个固相工艺家族（搅拌摩擦加工、原位复合材料、异种金属连接），而在移动金属的唯一办法是熔化或压碎的年代，它们是不可想象的。
:::

::: summary
**选成形是为了组织，不只是为了形状。**锻造闭合气孔、细化晶粒、把流线沿零件铺排，换来 20-40 % 的疲劳和大量的韧性；冷加工强化；近净成形省下 buy-to-fly。代价是力、机器和模具。
**力永远是 ${ \bar { \sigma } } \times A \times Q$ ，而 $Q$ 是有意思的那个因子。**工作温度和应变速率下的平均流变应力 $K \varepsilon ^ { n } / ( 1 + n )$ ，接触面积，以及摩擦峰、多余功和飞边带来的 2-10 倍约束因子。热低碳钢流变应力 $2 0 \ \mathrm { M P a }$ ，锻造压强却是 $1 { , } 5 0 0 \ \mathrm { M P a }$ ；难的不是金属，是界面。
**热与冷由再结晶划分，在 $0 . 4 { - } 0 . 5 \ T _ { m }$ （开尔文）。**在其上，不硬化，五分之一的力，但有氧化皮；在其下，硬化、回弹、更好的表面和公差。铅在室温是热加工，钛在 $2 5 0 \ \mathrm { ^ { \circ } C }$ 是冷加工。
**轧制是一道自己拽自己进去的镦粗。**$L = \sqrt { R \Delta h }$ ，$F = { \bar { \sigma } } Q w L$ ，$T = F L / 2$ ，$P = 2 T \omega$ ；咬入需要 $\mu \geq \tan \alpha$ ，所以 $\Delta h _ { \max } \approx 2 R \mu ^ { 2 }$ ——热态 94 mm，冷态 1.5 mm；而出口厚度是 $s + F / G$ ，这就是厚度控制是反馈回路的原因。
**锻造载荷由飞边决定。**$p _ { \text{飞边} } = 2 \sigma _ { y } ( 1 + a _ { f } / 2 h _ { f } )$ 加上模腔自身的摩擦峰，结果是普通压缩的三到十倍。模锻斜度、圆角、分模线、连接筋和预成形不是惯例；它们决定模具填不填得满、切不切得动。
**挤压是一个对数，拉拔是一个极限。**$p = { \bar { \sigma } } \ln R _ { x }$ 乘以模具因子，正挤压再乘 $( 1 + 2 \mu L / D )$ 的挤压筒摩擦；但拉拔中被拉出的产品承受载荷，所以 $\ln ( A _ { 0 } / A _ { 1 } ) < 1$ ，理想 $6 3 \ \ \%$ 、实际每道 30-40 % 的减缩——于是五副模具、两次退火、一条长线。
**成形的经济学是模具的经济学。**公差 $\pm 0 . 1 \ \mathrm { m m }$ ，$R _ { a } \ 1 . 6$ ，buy-to-fly 1.2-2.5，速率每分钟几十件，换来的是 20,000-150,000 英镑的工装和一条必须被分模线允许的形状。低于盈亏平衡批量，成形是一种造出昂贵铸件的办法；高于它，机加工是一种造出昂贵锻件的办法。
:::
