板料成形是制造世界上数量最多金属零件、也最不被理解的一个工艺家族：一副汽车车身是它的 350 个零件，一架飞机是 2,000 个，一台洗衣机是四十个，一个笔记本外壳是六个。它也是*材料*最粗暴地左右设计的家族，因为板不是实心体。在 [[manufacturing/bulk-forming|体积成形]] 里，工件被约束、被三向压缩，可以被压进模具能切出的任何形状；而板是一个**在自己的平面内受载的二维物体**，它恰好只有两种失效方式——**受压处起皱，受拉处撕裂**——而一副好的拉深模终其一生做的，就是把板精确地按在这两种失效的分界线上。

本课的一切都从这一句话推出。起皱是屈曲，而屈曲随板变薄而恶化，所以薄板拉深极好、拉伸极糟。撕裂是颈缩，而颈缩只有金属加工硬化才会停止扩展，所以**可拉深性由两个冶金常数衡量——决定颈缩停不下来的加工硬化指数 $n$ ，和决定板是变厚还是变薄的塑性应变比 $\bar { r }$** ——两者都是钢厂靠退火温度和夹杂物化学来控制、而设计师改不了的冶金量。还因为板薄，力很小——汽车门外板 400 吨拉深，而连杆 4,000 吨锻造——但*能量*在模具里而不在压力机上：一副侧围模具是一套 40 吨的模具钢铸件，要一个技工花六个月的生命去切削和调试，这就是为什么一款车要一亿英镑的车身工装、为什么覆盖件是模具车间和造型工作室共同设计的。

::: warning 板料设计出错的六种方式
**规定了材料不允许的折弯半径。**最小内圆角是厚度和材料断面收缩率的倍数：退火软钢 $r _ { \min } \approx t$ ，正火高强钢 $2 t$ ，硬黄铜 $4 t$ ，而 1,000 MPa 热冲压硼钢是 $6 { - } 1 2 t$ ——它要么成形后冷态折弯，要么干脆不能弯。要 $0 . 5 t$ ，外层纤维的应变 $t / ( 2 r + t ) = 3 3 \ \ \%$ ，它就干脆裂开——而且裂在可见面上，喷漆之后。**平行于轧制方向折弯。**板有织构，有织构就意味着垂直于纤维折的开裂应变是顺着纤维的一半；制图室的规定是**每条折弯线都画成与坯料上标出的轧制方向垂直**，压边圈上的方向标记不是建议。**无视回弹。**折弯是塑性造成的、弹性释放的，你得到的角不是模具的角。软钢尖角空弯是 $1 { - } 3 ^ { \circ }$ ，折弯机操作工凭眼睛就能补；1,000 MPa 钢是 $5 { - } 1 0 ^ { \circ }$ ，没有操作工补得了，这就是高强钢要么**热冲压**（在 $9 0 0 \ \mathrm { ^ { \circ } C }$ 成形、在模具里淬火，于是它按模具预留的量回弹一次、之后永不再弹），要么在行程末端以四倍吨位**校形和镦挤**的原因。**拉深一个一道拉不成的过深杯形。**软钢的极限拉深比是 $D / d \approx 2 . 1$ ；要 3 ，壁就减薄，然后在凸模圆角处破裂，答案是一道退火加两道拉深，也就是两套模具、两台压力机和又一层公差累积。**把材料的拉伸延性当成成形能力。**拉伸试样伸长率 30 % 的钢可能是很差的拉深钢，因为拉伸试样测的是单向拉伸，而法兰测的是*增厚*同时沿另一方向拉伸：要紧的数字是 **Lankford $r$ 值**——真宽度应变与真厚度应变之比——$r = 0 . 6$ 的钢拉不出 $r = 2 . 0$ 的钢轻松拉出的东西。**还有在模具设计之前就把零件设计完。**拉深模做不出半径小于板厚加模具自身磨损的角，做不出凹陷，拉深之后保不住跨拉深的尺寸，而且一旦手工抛光、调试修正过，就修不起了。**板料零件里真正烧钱的那种，是制图室从没看过一副模具调试的那种。**
:::

## 1. 剪切：不切割地切断一张板

::: definition 落料、冲孔，以及决定边缘质量的间隙 {#def-shear}
落料（冲下的才是零件）和冲孔（冲下的是废料）是同一道工序：两条淬硬的刃口，凸模和凹模，彼此之间的**间隙**每侧 $c = 0 . 0 5 { - } 0 . 1 3 t$ ，视材料而定——不锈钢取厚度的 5-8 % ，软钢和铝 6-10 % ，软而黏的材料 10-13 % 。凸模把刃口压进板里，形成约 $0 . 0 5 t$ 的**塌角**，一条塑性剪切的光亮带向下（或向上）生长，裂纹在凹模刃口再次形核、又在凸模刃口形核，两条裂纹相遇。**间隙对了，两条裂纹线对齐，边缘一半光亮一半断裂，带一点小毛刺；太小则裂纹碰不上，得到双重光亮带和一大片二次剪切；太大则板被拉扯翻卷，边缘圆钝、宽而凹陷。**四个区域——塌角、光亮带、断裂带、毛刺——是一份诊断书：维护工程师读冲压件的边缘，像医生读舌苔。

力是纯粹的剪切面积计算，这也是落料模具做成错开刃线的原因：

$$
F \; = \; \tau _ { \text{UTS} } A _ { \text{剪切} } \; \approx \; 0 . 8 \, \sigma _ { \text{UTS} } \, P \, t \qquad ( P \ \text{为切口周长} )
$$

峰值出现在凸模行程约 60 % 处，裂纹贯通的瞬间掉到零。**把凸模刃口面斜磨 $1 { - } 3 ^ { \circ }$ ，或把凸模按 $h = t / ( 2 \tan \phi )$ 错开不同高度，可把峰值力降到 $F t / ( t + h )$ ，让小压力机干大孔的活**——代价是零件略微凹陷，凸模更频繁地重磨。板上方的卸料板把零件压住，更重要的是在冲下一个孔时保持板平；下方用弹簧或聚氨酯垫起同样作用。

$$
\begin{array} { l c c c c }
\text{工序} & \text{哪个是零件} & \text{典型间隙} & \text{边缘质量} & \text{备注} \\ \hline
\text{冲孔} & \text{孔} & 8 \ \%\ t & \text{好} & \text{废料必须排出，否则压伤板面} \\
\text{落料} & \text{坯料} & 6 \ \%\ t & \text{好，一面光亮} & \text{凹模就是量规} \\
\text{精密冲裁} & \text{坯料} & 0 . 5 \ \%\ t & 9 5 \ \ \%\ \text{剪切面} & \text{V 形齿圈、反压柱，完全不产生断裂} \\
\text{剪板机剪切} & \text{条料} & 4 \ \%\ t & \text{差，加工硬化} & \text{成形前边缘必须磨掉} \\
\text{激光 / 水刀} & \text{坯料} & \text{切缝} & \text{好，有热影响区} & \text{无工装，慢，样件和小批量}
\end{array}
$$

**精密冲裁是证明规律的例外**：V 形**压边齿圈**把坯料死死压住，间隙只有 $0 . 5 \ \ \%\ t$ ，凸模端面加反向压力，静水压力把断裂整个抑制掉，切面 95 % 是光亮带，冲切态 $R _ { a }$ 达 $1 . 6 \ \mu \mathrm { m }$ ，尺寸公差 $\pm 0 . 0 5 \ \mathrm { m m }$ ——本来要机加工的零件，每分钟 2,000 件。
:::

::: example 冲一个孔：力，以及斜刃买到了什么 {#ex-blank level=3 check="40"}
在 $2 \ \mathrm { m m }$ 软钢板上冲直径 $2 0 \ \mathrm { m m }$ 的孔，$\sigma _ { \text{UTS} } = 4 0 0 \ \mathrm { M P a }$ ，每侧间隙 $6 \ \ \%$ 。

$$
F \; = \; \pi d \, t \, ( 0 . 8 \sigma _ { \text{UTS} } ) \; = \; { \frac { \pi \times 2 0 \times 2 \times 3 2 0 } { 1 0 ^ { 3 } } } \; = \; { \bf 4 0 \ k N }
$$

**四万千牛——四吨——冲一个成本不到一分钱的孔**，这就是为什么落料从来不是力的问题而是**模具的问题**：凸模是 $2 0 \ \mathrm { m m }$ 的工具钢带着一条 $9 0 \ \mu \mathrm { m }$ 的间隙带，不许失稳、不许咬合，还要能重磨四十次；卸料板不许划伤；废料必须允许离开，因为困在模里的废料下一冲就会崩裂模座，把一个值 0.03 英镑的零件换来 4,000 英镑的修理。把凸模斜磨出 $2 ^ { \circ }$ （错开量 $h = 0 . 3 5 \ \mathrm { m m }$ ）把峰值降到 $4 0 \times 2 / ( 2 + 0 . 3 5 ) = 3 4 \ \mathrm { k N }$ ，更重要的是把载荷摊到更长的行程上，压力机飞轮几乎毫无感觉。**$6 \ \ \%$ 的间隙是每侧 $0 . 1 2 \ \mathrm { m m }$ ，凹模按这个尺寸加凸模磨损余量制造：落料模是量规，三十万冲之后凸模磨短、间隙变大、毛刺长起，这就是维护信号。**
:::

## 2. 折弯：不在你以为位置的中性层

::: definition 折弯余量、K 因子与最小半径 {#def-bend}
绕半径 $r$ 的凸模弯成的板，**内表面**保持凸模半径，**外表面**在 $r + t$ ，但中间某处有一个面长度不变：**中性层**，在半径 $r + K t$ 处。它不在厚度的正中间，因为内半受压增厚而外半受拉伸薄，体积不变把中性层**向内**移动。经验 **$K$ 因子**是

$$
K \; \approx \; { \left\{ \begin{array} { l l } { 0 . 3 3 } & { r / t < 1 \text{（尖角，重载成形）} } \\ { 0 . 4 0 } & { 1 \leq r / t \leq 3 \text{（普通）} } \\ { 0 . 5 0 } & { r / t > 3 \text{（近乎纯弯曲）} } \end{array} \right. } \qquad \text{而} \; \textbf{折弯余量} \; B A \; = \; { \frac { \pi \theta } { 1 8 0 } } ( r + K t )
$$

展开图由**折弯补偿** $S B = ( r + t ) \tan ( \theta / 2 )$ ——每条外腿超出切点的距离——和**折弯扣除** $B D = 2 S B - B A$ ——一次折弯实际花掉的长度——搭出来：

$$
L _ { \text{展开} } \; = \; \sum ( \text{外腿，量到虚拟尖角} ) \; - \; \sum B D
$$

单个 $9 0 ^ { \circ }$ 折弯就是 $L = A + B - 2 ( r + t ) + B A$ ，两个折弯是 $L = A + B + C - 2 B D$ 。**每个 CAD 系统和每台折弯机的后挡料都在做这道算术，而每场关于报废坯料的争吵，都是关于双方在 $r$ 、$K$ 、$t$ 里哪一个上意见不一致的争吵。**

**差一毫米算错，零件到了压力机上就是废料，而争吵的是那一毫米算谁的；算对了，制图室和模具车间共用一个数字，这就是 K 因子的全部意义。**CAD 系统带一张折弯表，表靠对每批每种合金弯试样建立，好车间每卷钢重建一次，因为 $K$ 随批次漂移。

**最小内圆角**由外表面应变决定，纯弯曲下

$$
\varepsilon _ { \text{外层} } \; = \; \ln \! \left( { \frac { r + t } { r } } \right) \approx { \frac { t } { 2 r + t } } \quad \text{（工程形式）} \qquad \Longrightarrow \qquad r _ { \min } \; = \; t \, \left( { \frac { 1 } { 2 \varepsilon _ { \text{允许} } } } - { \frac { 1 } { 2 } } \right)
$$

而 $\varepsilon _ { \text{允许} }$ 比拉伸断面收缩率小得多，因为折弯的外表面处于平面应变，还带着划痕、剪切边缘微裂纹和轧制织构。于是车间表：横向纹理弯退火低碳钢 $r _ { \min } = 0 . 2 5 t$ ，轧态软钢 $t$ ，正火 HSLA $2 t$ ，500-700 MPa 级 $3 { - } 4 t$ ，700-1,000 MPa 冷成形级 $4 { - } 6 t$ ，而 1,500 MPa 冲压硬化硼钢**完全不许冷弯**——它热态成形、模具里淬火。
:::

::: proof 空弯力 {#proof-bendforce}
空弯是三点弯曲：板搁在肩距 $V$ 的模上，被半径 $r _ { p }$ 的凸模在跨中压下。行程末端板在凸模处变成了塑性铰，于是把外力矩等于板条的全塑性力矩，

$$
{ \frac { F _ { \text{总} } V } { 4 } } \; = \; M _ { p } \; = \; \sigma _ { y } \, w \, { \frac { t ^ { 2 } } { 4 } } \qquad \Longrightarrow \qquad F \; = \; { \frac { \sigma _ { y } \, w \, t ^ { 2 } } { V } }
$$

两个修正把它变成每台折弯机目录上的公式。变形不在屈服而是在抗拉强度上进行，因为板条转过了大角度、外表面应变 $t / ( 2 r + t ) \sim 2 0 \ \ \%$ ；应变状态是平面应变，把流变应力抬高 $2 / \sqrt { 3 } = 1 . 1 5$ 倍，而板在模肩上滑动的摩擦再抬高一截。合起来给出标准的 **1.42**：

$$
\boxed { \; F \; = \; { \frac { 1 . 4 2 \; \sigma _ { \text{UTS} } \; w \; t ^ { 2 } } { V } } \quad \Longleftrightarrow \quad F \ [ \mathrm { k N / m } ] \; = \; { \frac { 1 . 4 2 \; \sigma _ { \text{UTS} } \ [ \mathrm { M P a } ] \; t ^ { 2 } \ [ \mathrm { m m } ] } { V \ [ \mathrm { m m } ] \; \times \; 1 0 0 0 } } \times 1 0 0 0 \; }
$$

**注意这个公式关于折弯机说的两件事。**力**与模口成反比**，所以把 V 形模减半换取更锐的折弯，吨位翻倍——而 V 形模至少要 $8 t$ 宽，否则板被吸进模里，折弯被拉伤，模肩磨出一条沟。力**与厚度的平方成正比**，所以厚 25 % 的板是重 56 % 的活：额定 3 米 100 吨的折弯机能弯 $6 \ \mathrm { m m }$ 软钢却只能弯 $2 . 5 \ \mathrm { m m }$ 的 1,000 MPa 钢，而一个按当前活计买折弯机、然后接了高强活计的车间，是在买第二台折弯机。
:::

## 3. 回弹：你没有弯成的那个角

::: definition 为什么角度永远不是那个角度 {#def-spring}
凸模之下板被塑性弯曲；凸模退去时，*弹性*应变部分——此前作为残余应力场由弹性核承担的部分——弹了回去。经典估计来自卸载一个弯矩为全塑性值 $M _ { p } = \sigma _ { y } w t ^ { 2 } / 4$ 的梁，其曲率变化是

$$
\Delta \kappa \; = \; { \frac { M _ { p } } { E I } } \; = \; { \frac { \sigma _ { y } w t ^ { 2 } / 4 } { E \, w t ^ { 3 } / 1 2 } } \; = \; { \frac { 3 \sigma _ { y } } { E t } } \qquad \Longrightarrow \qquad \Delta \theta \; = \; \Delta \kappa \, L _ { b } \; = \; { \frac { 3 \sigma _ { y } } { E t } } \, L _ { b }
$$

其中 $L _ { b }$ 是圆弧长度。**所以回弹正比于屈服强度和折弯角，反比于厚度，而反比于弹性模量——后者你什么都控制不了**——这一句话就决定一个零件是用钢、铝还是复合材料做。因为 $E$ 对所有铝合金都相同、且只有钢的三分之一，**同样 $\sigma _ { y } / t$ 下铝的回弹约是钢的三倍，同样 $E$ 和 $t$ 下高强钢的回弹是软钢的三倍**。经验**回弹系数** $X = \theta _ { \text{加载时} } / \theta _ { \text{最终} }$ ：校形和拉伸弯曲 1.05-1.15 ，软钢空弯 1.1-1.3 ，700-1,000 MPa 级 1.3-1.8 。

对策，按车间伸手去拿的顺序：**过弯**（模具按回弹后正好切的角度加工，卷钢换批再改一次——软钢的常规答案）；**底压与校形**（行程末端把凸模压进板里，让模具的夹角镦挤进零件——精度 $0 . 5 ^ { \circ }$ ，代价是三到五倍吨位和一副必须重新淬硬的模具）；**加大折弯半径**，让截面中弹性部分占比更小（这就是为什么大半径比小半径*更*容易保，与每个新手的直觉相反）；**平面凸缘镦挤**（一条平凸缘在凸模和模具之间被夹紧，零件就转不动）；**拉伸成形**，在弯曲之前和之中把整张板在拉伸下拉过屈服，于是没有弹性梯度可释放；**热冲压**，在 $\sigma _ { y }$ 只有 $3 0 \ \mathrm { M P a }$ 的 $9 0 0 \ \mathrm { ^ { \circ } C }$ 成形、在模具里淬到 $1 { , } 5 0 0 \ \mathrm { M P a }$ ，零件以模具的角度离模、永不再弹；以及**在模具上补偿**，这才是实际发生的：模具带着故意的过角加工，用实际卷批的试样上机调试，签收之前手工修正多达二十次。
:::

## 4. 拉深：杯形，以及在法兰里打的那场战争

::: definition 一副拉深模到底在做什么 {#def-draw}
拉深模有三个工作圆角和一个夹钳。**凸模**把直径 $D$ 的圆盘压进直径 $d$ 的**型腔**；型腔口 $r _ { d } \approx 4 { - } 8 t$ 的**凹模圆角**是法兰先弯、再卸弯、然后滑入的地方；**凸模圆角** $r _ { p } \approx r _ { d } - t$ 是壁绕凸模弯曲之处，也是杯形如果要裂就裂之处；**压边圈**以力 $F _ { b h }$ 夹紧法兰、把它压在模具面上，这是模具对工艺唯一的控制手段。

力学是一场隔着凹模圆角的拔河。**在外面的法兰里**，金属被径向向内拉，而一个被拉到更小圆周的圆盘必须同时沿周向收缩，于是它同时受**周向压缩**——一个径向受拉、周向受压的薄盘正是**起皱**的教科书案例，而压边圈的存在就是为了防皱。**在壁里**，同样的张力以简单的薄膜应力传递，壁会在凸模圆角处撕裂，那里最薄、加工硬化最少。**压边力是两者之间的旋钮：太小法兰起皱，太大壁破裂。**其余一切——润滑剂、模具圆角、拉延筋、多工位压力机——都是把这一个数放进一个更窄窗口正中的办法。

可拉深性的定量表述是**极限拉深比**

$$
\left( { \frac { D } { d } } \right) _ { \max } \; \approx \; 2 . 0 { - } 2 . 2 \ \ \text{软钢} , \qquad 1 . 8 { - } 2 . 0 \ \text{不锈钢} , \qquad 2 . 2 { - } 2 . 6 \ \text{铝}
$$

它为什么这么小又这么普适，下面推导：壁在屈服前只能承受那么多，而法兰要被拉进来需要的比那还多。移动这个极限的材料参数是**加工硬化指数 $n$** （它把减薄摊开而不是集中）、**应变速率敏感性 $m$** （铝和热钢很大，这就是镁和铝如此宽容的原因），以及最重要的 **Lankford 塑性应变比**

$$
\bar { r } \; = \; { \frac { \varepsilon _ { \text{宽度}} } { \varepsilon _ { \text{厚度}} } } \; = \; { \frac { \ln ( w / w _ { 0 } ) } { \ln ( t / t _ { 0 } ) } } \qquad \text{在 } 1 5 \ \ \% \ \text{应变处、三个方向测量}
$$

它说的是板被拉时更愿意变宽还是变薄。完全各向同性的板 $\bar { r } = 1$ ；好的拉深钢 $\bar { r } = 1 . 6 { - } 2 . 2$ ，因为冷轧退火低碳板的铁-碳化物织构让增厚很容易；$\bar { r } = 0 . 6$ 的钢不增厚只减薄，拉不成。**而三个测量方向之间的差异 $\Delta r = ( r _ { 0 } + r _ { 9 0 } - 2 r _ { 4 5 } ) / 2$ ，正是拉深杯起"耳"的原因——铝脱氧钢四个耳，无间隙原子钢两个，在矩形盆的角上，在电池壳的端部，在气雾剂罐顶部——那里修边压力机得把耳切掉。**

一道拉不成的深杯要**变薄续拉（再拉深）**——以 1.6-1.9 的缩减比——中间加一道**退火**，撤销让第一道成为可能、也会让第二道成为不可能的加工硬化，壁被减薄拉延过的话中间再加一道**壳退火**。**减薄拉延（wall ironing）**是故意的：凹模和凸模间隙设得小于板厚，壁掠过凸模时被挤成均匀厚度，气雾剂罐和弹壳就是这样得到比坯料更薄的壁和光滑的内表面。**拉延筋**——压边圈上的一道槽舌——给平面压紧做不到的区域加上固定、可重复的约束，这就是跨距 1,200 mm 、拉深 40 mm 的汽车外覆盖件保住 A 级表面的办法。
:::

::: proof 为什么拉深比停在两倍左右 {#proof-ldr}
凹模圆角和凸模圆角之间的杯壁，以薄膜张力承受整个凸模载荷。若壁的流变应力是 ${ \bar { \sigma } } _ { w }$ 、厚度是 $t$ ，壁不屈服能承受的最大力是

$$
F _ { \max } \; = \; \pi d \, t \, { \bar { \sigma } } _ { w }
$$

（经典形式用抗拉强度，因为拉伸试验里颈缩区才是真正阻止变形的东西）。把法兰拉进来所需的力是理想拉深功，加上凹模圆角处弯曲卸弯的功和压边圈摩擦的功；第一项占主导，是

$$
F _ { \text{拉深} } \; = \; \pi d \, t \, { \bar { \sigma } } _ { f } \, \psi \, \ln \! \left( { \frac { D } { d } } - 0 . 2 5 \right) \qquad ( \psi \approx 1 . 1 { - } 1 . 3 \ \text{，计入多余功和弯曲} )
$$

令两者相等，并写 ${ \bar { \sigma } } _ { w } \approx { \bar { \sigma } } _ { f }$ ，因为无论拉深比多少，壁都经历了同样的平均应变，得

$$
\ln \! \left( { \frac { D } { d } } - 0 . 2 5 \right) \; = \; { \frac { 1 } { \psi } } \; = \; 0 . 8 3 \qquad \Longrightarrow \qquad { \frac { D } { d } } \; = \; e ^ { 0 . 8 3 } + 0 . 2 5 \; = \; 2 .  7 9
$$

**预言是 2.8 ，车间数字是 2.1** ，差距恰恰是理想分析漏掉的项：压边圈下的摩擦，仅它就花掉载荷的 20-40 % ；凹模圆角的弯卸，按 $\sqrt { t / r _ { d } }$ 缩放，这就是小于 $4 t$ 的凹模圆角毁掉可拉深性的原因；壁最薄处在凸模圆角，而那里*最不*加工硬化；还有法兰在拉入途中不许起皱，这需要压边力、因而需要更多摩擦。**教训不是算术错了，而是算术对了：它说极限是一个比值而不是一个深度，它说极限由壁决定而不是由凸模决定，它说打败它的唯一办法是减摩擦、减法兰应变、强壁——这正是拉深模设计师所能做的一切的清单。**
:::

::: example 拉一个直径 100 mm 、深 60 mm 的杯 {#ex-drawcup level=3 check="108"}
直径 $1 0 0 \ \mathrm { m m }$ 、深 $6 0 \ \mathrm { m m }$ 的杯，从 $1 \ \mathrm { m m }$ 软钢板拉出，$\sigma _ { \text{UTS} } = 3 4 0 \ \mathrm { M P a }$ ，坯料取极限比 2.1 下一道成形所需的最小直径。

坯料直径由表面积算出（拐角余量折进标准公式）：

$$
D \; = \; { \sqrt { d ^ { 2 } + 4 d h - 3 . 4 4 d r _ { p } } } \; = \; { \sqrt { 1 0 ^ { 2 } + 4 \times 1 0 \times 0 . 9 \times 1 0 - 3 . 4 4 \times 1 0 \times 0 . 9 } } \; = \; { \sqrt { 3 0 9 } } \; = \; 1 7 . 6 \ \mathrm { c m } \; = \; 1 7 6 \ \mathrm { m m }
$$

拉深比 $D / d = 1 . 7 6$ ——**在 2.1 的极限之内，一道就成。**压力机载荷，按 $F = \pi d \, t \, \sigma _ { \text{UTS} } ( D / d - 0 . 7 5 )$ ，是

$$
F \; = \; \pi \times 1 0 0 \times 1 \times 3 4 0 \times ( 1 . 7 6 - 0 . 7 5 ) \; = \; { \bf 1 0 8 \ k N } \quad \text{拉深力，另加 } 4 0 { - } 6 0 \ \mathrm { k N } \text{ 压边力}
$$

**那么一台 200 kN（20 吨）三工位压力机——但 200 kN 压力机值 120,000 英镑，模具值 25,000 英镑，钢材值 9 便士。**现在讲让这个例子值得有的设计变更：杯若必须 $8 0 \ \mathrm { m m }$ 深，$D = { \sqrt { 1 0 0 + 3 2 0 - 3 1 } } = 1 9 7 \ \mathrm { m m }$ ，$D / d = 1 . 9 7$ ，仍是一道；若必须 $1 1 0 \ \mathrm { m m }$ 深，$D = 2 2 6 \ \mathrm { m m }$ ，$D / d = 2 . 2 6$ ——**超了极限，零件变成两道拉深、一次退火、第二套模具、第二个压力工位，这就是 25,000 英镑工装费和 60,000 英镑工装费的区别。** **所以制图室的规则是：杯的深度不是设计参数；拉深比才是。**
:::

## 5. 胀形，以及说它何时停下来的那张图

::: definition 成形极限图 {#def-fld}
拉伸成形——一个凸模拉出的罩、一个角、一个双曲率面板、车顶——没有法兰也没有压边圈，它唯一的极限是**局部颈缩**。双向拉伸的板一路减薄，直到板上一条沟槽比周围金属更容易延伸，此后所有应变都涌进沟槽，零件一秒内裂开。发生这件事时的应变状态取决于**应变比** $\rho = \varepsilon _ { 2 } / \varepsilon _ { 1 }$ （面内小主应变比大主应变）：单向拉伸 $\rho = - 0 . 5$ ，平面应变 $\rho = 0$ ，等双轴拉伸 $\rho = + 1$ 。把**极限大应变**对 $\rho$ 作图就得到**成形极限图**，它的形状是整个制造业里最有用的经验结果之一：

$$
\mathrm { FLD } ( \rho ) \; = \; { \left\{ \begin{array} { l l } { \mathrm { FLD } _ { 0 } \, ( 1 + \rho ) ^ { \, 0 . 6 } } & { - 1 \leq \rho \leq 0 \quad \text{（左侧，斜支）} } \\ { \mathrm { FLD } _ { 0 } \left[ 1 + \beta \rho \right] } & { 0 \leq \rho \leq 1 \quad \text{（右侧，近水平支，} \beta \approx 0 { - } 0 . 1 \text{）} } \end{array} \right. }
$$

其中**平面应变成形极限**由 **Keeler–Goodwin** 关系给出

$$
\mathrm { FLD } _ { 0 } \; = \; { \frac { 2 3 . 3 + 4 2 n } { 1 + 0 . 2 1 6 6 f } } \times \left( { \frac { n } { 0 . 0 4 } } \right) ^ { \! 0 . 3 } \ \text{仅适用于 } n < 0 . 0 4 , \qquad f = { \frac { t \ [ \mathrm { m m } ] } { 2 0 } }
$$

**读图不读公式，三条事实浮现。****左支很陡**：应变状态从平面应变走向单向拉伸，成形性掉得飞快，这就是为什么只朝一个方向拉伸的角半径比球罩难得多。**右支是平的**：一旦进入双拉，更双轴不花钱，这就是为什么设计良好的罩很容易，也是为什么把压力叠加到板上的充液成形能拉伸在凸模上会撕裂的金属。**整条曲线随 $n$ 缩放**——Goodwin 方程本质上是 $\mathrm { FLD } _ { 0 } \approx 2 3 + 4 2 n$ ，与 Considère 的 $n = \varepsilon _ { u }$ 是同一个物理，它说**钢厂为易成形板能做的最值钱的一件事，就是给它高的加工硬化指数**，而这恰恰就是双相钢、TRIP 钢、TWIP 钢是什么：一种被设计成以屈服强度为代价、把硬化维持到巨大应变的组织——而那个屈服强度你之后要在回弹里跟它搏斗。

量产零件的评判方法，是在关键点测量一张网格（坯料上蚀刻或印出的 2 mm 圆网格，成形后再测），把椭圆的长短轴应变画到 FLD 上。**验收规则是裕度：点必须在曲线以下至少极限的 $10 \ \ \%$ 或 3 个百分点，取大者**——因为曲线本身是一条散带，测量有 $\pm 1$ 点的不确定度，而卷钢的 $n$ 每炉之间差 0.02。
:::

$$
$$
\text{B: } \varepsilon _ { 1 } = \ln ( 5 . 1 / 4 . 0 ) = 0 . 2 4 1 , \quad \varepsilon _ { 2 } = \ln ( 4 . 4 / 4 . 0 ) = 0 . 0 9 5 \qquad \Longrightarrow \qquad \rho = + 0 . 4 0

若 A 的椭圆是 $5 . 1 \times 3 . 7 \ \mathrm { m m }$ ，应变就是 $2 4 . 1 \ \ \% / - 7 . 7 \ \ \%$ ，$\rho = - 0 . 3 2$ ，极限 $3 1 . 4 \times 0 . 6 8 ^ { 0 . 6 } = 2 2 . 9 \ \ \%$ ——**低于极限但落在 3 点裕度之内，这就是工程师所谓"今天安全"的状态。**

## 6. 家族其余成员

::: definition 板料工艺各是干什么的 {#def-rest}
$$
\begin{array} { l l l l l }
\textbf{工艺} & \textbf{应力状态} & \textbf{极限} & \textbf{典型零件} & \textbf{速率} \\ \hline
\text{折弯机折弯} & \text{弯曲，然后回弹} & \text{回弹，} r _ { \min } & \text{支架、面板、纵梁} & 1 0 { - } 6 0 / \mathrm { h } \\
\text{滚弯} & \text{渐进弯曲} & \text{回弹，端部预弯} & \text{管、大直径筒} & \text{慢} \\
\text{拉深} & \text{拉伸 + 周向压缩} & D / d \text{，起皱} & \text{罐、水槽、油底壳、电池壳} & 1 0 { - } 6 0 / \mathrm { m i n } \\

其中四种值得各说一句，因为它们改变设计师能开口要什么。**充液成形**用加压流体膜代替凸模，板在整个拉伸过程中外表面都被压力托住：本会变成颈缩的沟槽一形成就被压回去，极限应变大约翻倍——在凸模上 25 % 就裂的钛翼面配件，在液室里能胀到 55 % ，代价是一只能耐 100 MPa 的容器和以分钟计的节奏。**辊压**把带料渐进地弯过十到二十个机架，每个吃几度，于是要 5,000 吨压力机的力变成 50 吨的，零件变成一百米长而直；代价是截面必须沿长度恒定，而且每个孔必须在成形之前冲好。**热冲压**（硼钢 22MnB4 冲压硬化）把坯料加热到 $9 2 0 \ \mathrm { ^ { \circ } C }$ ，四秒内转移到水冷模具，在 $3 0 \ \mathrm { M P a }$ 流变应力下成形、毫无回弹，合模八秒让模具以 $3 0 \ \mathrm { K / s }$ 把它淬成 $1 { , } 5 0 0 \ \mathrm { M P a }$ 马氏体：**一个用软钢的力成形、以五倍强度出厂、而之后冷态不能弯、不能钻、不能切的零件**——所以每个热冲压件都需要趁热完成的激光或冲切工序。**激光拼焊板**在成形前把两三种厚度或两种合金激光焊成一块坯料，于是一个拉深件该刚的地方厚、该拉的地方薄——诀窍是焊缝必须放在只拉伸不起皱的区域，而且两种材料必须同速变形，否则坯料在焊缝处剪开。
:::

::: example 热冲压对冷成形高强钢 {#ex-hss level=3 check="1.8"}
一根 1,400 mm 长的保险杠加强梁，要以 1,500 MPa 制造。路线 A：冷成形 1,000 MPa 双相钢，多用材料。路线 B：热冲压 22MnB4 到 1,500 MPa。

**路线 A** 需要 $2 . 2 \ \mathrm { m m }$ 壁厚才能对上 $1 . 2 \ \mathrm { m m }$ 热冲压钢的碰撞能量，所以壁厚是 $2 . 2 / 1 . 2 = { \bf 1 . 8 }$ 倍、重 83 % ；它在现成的 1,000 吨压力机上以每分钟 12 件成形，但每条凸缘回弹 $6 ^ { \circ }$ ，四个凸缘角必须靠校形垫保到 $\pm 1 ^ { \circ }$ ，校形垫加 25 % 吨位，模具每个项目要改两次。**路线 B** 壁厚 $1 . 2 \ \mathrm { m m }$ ，完全无回弹，孔面保 $\pm 0 . 3 \ \mathrm { m m }$ ——但坯料要在通过式炉里加热四分钟，四秒内转移（温度降 $8 0 \ \mathrm { K }$ 就足以做出带软带的马氏体），在水冷模具里以每分钟两件成形，然后**热切边——激光或热冲**，因为 1,500 MPa 钢冷切边会崩碎模具。

按年产 120,000 件算账：**路线 A 每件 14.80 英镑、工装 380,000 英镑；路线 B 每件 17.40 英镑、工装 1,150,000 英镑，外加 210 万英镑的炉子和压力机线**——而路线 B 每车省 $0 . 9 \ \mathrm { k g }$ ，按 120,000 台车队和与 CO₂ 挂钩的罚款折算，整个项目值每车 3.10 英镑。**决定给了路线 B，而且是因为质量和公差给的，不是单件成本——每当一个成形工艺因为性能而不是价格被选中，结果总是这样。**
:::

## 7. 模具、压力机与成本的形状

::: definition 一个板料零件到底花多少钱 {#def-econ}
压力机按**吨位、台面长度和装模高度**买；模具按**钢材、月份和人手**买。折弯机模具是淬硬钢凸模加 V 形模，每米 600 英镑，四分钟换完；汽车外板拉深模是 12 吨的 EN3B 或工具钢铸件，在五轴铣床上切三个月，然后由模具钳工**调试**——装、跑、检、焊补、手工打磨、再跑，二十到四十遍——他的手艺就是一块车身面板有 A 级表面而不是一张波纹图的原因。调试占模具成本的 30-50 % ，且买不回来。

::: example 年产 4,000 件电动滑板车车身面板 {#ex-scoot level=3 check="20000"}

## 习题

::: exercise 带斜刃的落料力 {#ex-blankforce level=2 check="150"}
对边 60 mm 的六角形从 $1 . 5 \ \mathrm { m m }$ 硬化不锈钢落料，$\sigma _ { \text{UTS} } = 6 0 0 \ \mathrm { M P a }$ 。估计峰值落料力。（输入 kN，取整到 10。）
::: solution
周长 $6 \times 6 0 / \sqrt { 3 } = 2 0 8 \ \mathrm { m m }$ ，所以 $F = 0 . 8 \times 6 0 0 \times 2 0 8 \times 1 . 5 / 1 0 ^ { 3 } = { \bf 1 5 0 \ k N }$ 。**给凸模加 $2 \ \mathrm { m m }$ 斜刃，峰值降到 $1 5 0 \times 1 . 5 / 3 . 5 = 6 4 \ \mathrm { k N }$ ，代价是坯料凹陷——注意*能量*不变，这就是为什么斜刃在带飞轮的曲柄压力机上有效，在慢速液压机上无效。**
:::
:::

::: exercise 槽钢的展开图 {#ex-channel level=2 check="134.2"}
一个槽钢由两个 $9 0 ^ { \circ }$ 折弯成形：外腿 $3 0 \ \mathrm { m m }$ ，腹板 $8 0 \ \mathrm { m m }$ ，外腿 $3 0 \ \mathrm { m m }$ ，$1 . 5 \ \mathrm { m m }$ 板，内圆角 $2 \ \mathrm { m m }$ ，$K = 0 . 4 0$ 。求坯料长度。（输入 mm，保留一位小数。）
::: solution
$S B = ( 2 + 1 . 5 ) \tan 4 5 ^ { \circ } = 3 . 5 0 \ \mathrm { m m }$ ，$B A = ( \pi / 2 ) ( 2 + 0 . 4 \times 1 . 5 ) = 4 . 0 8 \ \mathrm { m m }$ ，$B D = 2 \times 3 . 5 0 - 4 . 0 8 = 2 . 9 2 \ \mathrm { m m }$ ，所以 $L = 1 4 0 - 2 \times 2 . 9 2 = { \bf 1 3 4 . 2 \ m m }$ 。**设计师的 140 mm 长了 $4 . 3 \ \ \%$ ，在 1,200 mm 宽、每步出 8 件的卷料上，这个误差是材料账单的 5 % 。**
:::

::: exercise 最小折弯半径 {#ex-rmin level=2 check="8.1"}
某钢拉伸断面收缩率 $2 5 \ \ \%$ 。取外层纤维许用工程应变为该收缩率隐含值的三分之一，求 $2 \ \mathrm { m m }$ 板的最小内圆角。（输入 mm，保留一位小数。）
::: solution
$2 5 \ \ \%$ 断面收缩率对应外层纤维应变容量理想情形约 $0 . 2 5 / ( 1 - 0 . 2 5 ) \approx 0 . 3 3$ ；取其三分之一得 $\varepsilon _ { \text{允许} } = 0 . 1 1$ ，由 $\varepsilon = t / ( 2 r + t )$ 得 $r = t ( 1 / 2 \varepsilon - 1 / 2 ) = 2 ( 4 . 5 5 - 0 . 5 ) = 8 . 1 \ \mathrm { m m }$ ，所以 $r _ { \min } \approx 4 t = { \bf 8 . 1 \ m m }$ 。 **四个厚度，正是车间表给 500-700 MPa 级的答案——也是为什么在高强支架上标注"锐边全部倒钝，R1 典型"的设计师，标的是一个造不出来的零件。**
:::
:::

::: exercise 高强折弯的过弯 {#ex-overbend level=2 check="4.7"}
$1 . 2 \ \mathrm { m m }$ 的 1,000 MPa 屈服钢空弯到 $3 \ \mathrm { m m }$ 内圆角、$9 0 ^ { \circ }$ 。用 $\Delta \theta = 3 \sigma _ { y } L _ { b } / E t$ 估计回弹并给出加载角。取 $E = 2 0 0 \ \mathrm { G P a }$ 。（回弹以度输入，保留一位小数。）
::: solution
$L _ { b } = ( \pi / 2 ) ( r + t ) = 1 . 5 7 1 \times 4 . 2 = 6 . 6 0 \ \mathrm { m m }$ ，所以 $\Delta \theta = 3 \times 1 { , } 0 0 0 \times 6 . 6 0 / ( 2 0 0 { , } 0 0 0 \times 1 . 2 ) = 0 . 0 8 2 5 \ \mathrm { r a d } = { \bf 4 . 7 \ \ ^ { \circ } }$ ，模具必须做出 $9 4 . 7 ^ { \circ }$ 。**同一情形下图中曲线给 $5 . 4 ^ { \circ }$ ，差别在所用弧长；无论哪个，结论都是 100 mm 凸缘上 $5 ^ { \circ }$ 的误差是自由端 8.7 mm 的错位，任何装配都吸收不了——于是校形、热冲压，或者改设计。**

::: exercise 拉深道数 {#ex-redraw level=2 check="3"}
$2 5 0 \ \mathrm { m m }$ 坯料要变成直径 $7 0 \ \mathrm { m m }$ 的杯。首拉极限取 2.1 ，再拉极限取 1.8 ，问几道拉深，中间直径各是多少？
::: solution
$2 5 0 / 2 . 1 = 1 1 9 \ \mathrm { m m }$ ，$1 1 9 / 1 . 8 = 6 6 \ \mathrm { m m }$ ——所以**两道刚好到 66 mm ，而 70 mm 在其上，于是若再拉能保在 1.70 就是两道，若车间诚实就是三道**：$2 5 0 \to 1 1 9 \to 8 8 \to 7 0$ 。**两次退火、三套模具、三个压力工位——为一个唯一的罪过是深 180 mm 的零件。** **这就是为什么制图室对深零件最值钱的一次干预，是一个凸台、一条筋或一个截面变化，让比值降 0.2。**

::: exercise 压边力与两种失效 {#ex-bh level=3 check="2"}
例题的杯，壁在屈服前能承受 $1 0 8 \ \mathrm { k N }$ ，而法兰在完全没有压边力时需要 $7 0 \ \mathrm { k N }$ 拉入。若压边压强至少 $0 . 8 \ \mathrm { M P a }$ 压在法兰环面上才能防皱，环面积 $1 2 { , } 0 0 0 \ \mathrm { m m } ^ { 2 }$ ，这个件拉得成吗？
::: solution
压边力 $0 . 8 \times 1 2 { , } 0 0 0 = 9 . 6 \ \mathrm { k N }$ ，它增加的摩擦约为 $2 \mu F _ { b h }$ （两个界面）$= 2 \times 0 . 1 \times 9 . 6 = 1 . 9 \ \mathrm { k N }$ ，拉深力升到约 $7 2 \ \mathrm { k N }$ ，对 $1 0 8 \ \mathrm { k N }$ 的壁容量：**拉得成，裕度 1.5。** **现在因为试模出了皱把压边压强加倍到 $1 . 6 \ \mathrm { M P a }$ ：拉深力升到 $7 3 \ \mathrm { k N }$ ——几乎没变，因为摩擦只是载荷的一小部分——而皱还在，因为答案从来不是力而是拉延筋。** **这就是实践教训：压边力是个粗旋钮，当它不够时，模具需要的是几何。**
:::
:::

::: exercise FLD 校核 {#ex-fldchk level=3 check="20.7"}
面板上一点显示 $\varepsilon _ { 1 } = 1 4 . 0 \ \ \%$ ，$\varepsilon _ { 2 } = - 7 . 0 \ \ \%$ 。对 $\mathrm { FLD } _ { 0 } = 3 1 . 4 \ \ \%$ 、左支 $\mathrm { FLD } = \mathrm { FLD } _ { 0 } ( 1 + \rho ) ^ { 0 . 6 }$ ，求极限应变并判断该点是否通过 3 点裕度规则。（极限应变以百分数输入，保留一位小数。）
::: solution
$\rho = - 0 . 5 0$ ，所以 $\mathrm { FLD } = 3 1 . 4 \times 0 . 5 ^ { 0 . 6 } = 3 1 . 4 \times 0 . 6 6 = { \bf 2 0 . 7 \ \ \% }$ ，对实测 $1 4 . 0 \ \ \%$ ——**裕度 6.7 点，通过。** **注意冰面比数字显示的薄得多：同一点在 $\rho = - 0 . 8$ （近乎单向）时极限是 $3 1 . 4 \times 0 . 2 ^ { 0 . 6 } = 1 2 . 0 \ \ \%$ ，早就失效了，而那个特征上的 $\rho$ 随压边平面 $0 . 5 \ \mathrm { m m }$ 的变化而移动。FLD 是一张地图，零件必须待在安全区的腹地，而不是边界上。**
:::

::: exercise 推导 Considère 判据与均匀伸长率 {#ex-derive-considere level=4 check="22"}
证明 $\sigma = K \varepsilon ^ { n }$ 的拉伸试样在 $\varepsilon _ { u } = n$ 开始颈缩，并求 $n = 0 . 2 0$ 的均匀伸长率（以工程伸长百分数计）。（输入百分数，取整。）
::: solution
颈缩起始时载荷 $F = \sigma A$ 驻定，所以 $d ( \sigma A ) = 0$ ，而体积不变 $d \varepsilon = - d V / V = - d A / A$ ，得
$$
{ \frac { d \sigma } { \sigma } } = { \frac { d A } { A } } = d \varepsilon \qquad \Longrightarrow \qquad { \frac { d \sigma } { d \varepsilon } } = \sigma
$$
对 $\sigma = K \varepsilon ^ { n }$ ，$d \sigma / d \varepsilon = n K \varepsilon ^ { n - 1 } = \sigma / \varepsilon = K \varepsilon ^ { n }$ 给出 $\varepsilon _ { u } = n = 0 . 2 0$ ，工程伸长 $e ^ { 0 . 2 0 } - 1 = { \bf 2 2 \ \ \% }$ 。 **这就是为什么 $n$ 是成形性指数：板在局部化之前能承受的应变，就是硬化不再为减薄买单时它已经吃下的应变。这也是为什么 $n = 0 . 1 0$ 的双相钢在 $1 1 \ \ \%$ 就颈缩、尽管总伸长 25 % 仍是很差的拉深钢——剩下的 14 % 发生在颈缩内部，而那恰恰是成形工序用不上的地方。**
:::
:::

::: exercise 推导外层弯曲应变 {#ex-derivebendstrain level=4 check="33"}
证明内圆角 $r$ 、厚度 $t$ 的折弯中，外表面工程应变是 $\varepsilon = t / ( 2 r + t )$ ，并对 $r = t$ 求值。（输入百分数，取整。）
::: solution
外层纤维从中性层长度 $r + t / 2$ ……更直接：半径 $r + t$ 的外表面跨过弧 $( r + t ) \theta$ ，而中性层跨过 $( r + K t ) \theta$ ；纯弯曲取中性层 $K = 0 . 5$ ，真应变是 $\ln [ ( r + t ) / ( r + t / 2 ) ]$ ，工程应变是
$$
\varepsilon = { \frac { ( r + t ) - ( r + t / 2 ) } { r + t / 2 } } = { \frac { t / 2 } { r + t / 2 } } = { \frac { t } { 2 r + t } } = { \frac { 1 } { 3 } } = { \bf 3 3 \ \ \% }
$$
**三分之一，在 $r = t$ 时——这就是为什么 $r = t$ 对断面收缩率 35 % 的材料接近极限，为什么车间规则"内圆角绝不小于一倍厚度"说的不是工具而是金属自己的延性。** **它也解释了那两个标准花招：更大的半径是更小的应变，更小的*厚度*是小得多的应变——这就是为什么折弯区常先铣薄、机加工薄或化学铣薄再成形，也是为什么板料成形性随轻量化逼着设计师用的更薄规格戏剧性地变好。**
:::

- [ ] 更大的凹模圆角
- [ ] 更低的压边力
- [x] 更大的坯料直径
::: solution
**更大的坯料增大拉深比，而这恰恰是让破裂更糟的唯一一件事。** **其余三项都降低壁应力：更大的凸模圆角把弯曲和摩擦摊到更大的弧上、把危险截面移离最大张力点；更大的凹模圆角降低法兰入口的弯曲应变，它按 $\sqrt { t / r _ { d } }$ 缩放；更低的压边力降低壁必须承受的摩擦。治裂措施的完整清单，按模具车间试的顺序：更多更好的润滑剂，更大的凹凸模圆角，更低的压边力，更软或 $n$ 更高的卷料，更小的拉深比（再拉深），最后改设计。**
:::
:::

::: quiz 为什么同一个杯，皱出现在法兰、裂出现在壁？ {#quiz-wrinkle}
- [ ] 因为法兰比壁薄
- [x] 因为法兰受周向压缩而壁受拉伸，两种失效的成因相反
- [ ] 因为润滑剂只到得了壁
- [ ] 因为凸模比模具热
::: solution
**径向拉深张力必然伴随法兰的周向压缩——一个收缩到更小圆周的圆盘必须把它的圆挤到一起——而受周向压缩的薄盘会屈曲。同样的张力到达已成圆柱的壁，是简单的薄膜应力，壁一直承受到屈服颈缩。** **所以两种缺陷是同一个旋钮的两端，而模具调试就是在往往只有 20 % 宽的窗口里找中间。这也是为什么厚板好胀形而难拉深：增厚让法兰的屈曲抗力按 $t ^ { 2 }$ 上升，而壁的承载只按 $t$ 上升，凹模圆角处的弯曲应变还按 $1 / r _ { d }$ 上升。**
:::
:::

## 后续内容

- **[[manufacturing/bulk-forming|体积成形]]** 是另一半同伴：同样的流变应力、同样的摩擦、同样的再结晶，只不过在工件既不能屈曲也不能颈缩的应力状态里。
- **[[manufacturing/machining|切削加工]]** 是拉深件的修边线、螺栓孔和基准面的去处——而激光切割和水刀下料，正是坯料在成形前如何被造出来的办法。
- **[[manufacturing/joining|连接]]** 把面板装配起来：一副车身焊 5,000 个点焊，以及焊涂层板和高强牌号特有的难题。
- **[[manufacturing/polymer-composite-processing|聚合物与复合材料成形]]** 对一种 $n$ 是温度函数、而起皱叫印透的材料，用同样的成形极限思维。
- **[[manufacturing/metrology-quality|计量、质量与自动化]]** 讲车身车间如何在 350 个零件上保住 $\pm 0 . 3 \ \mathrm { m m }$ ，以及回弹如何反馈回模具。
- **[[materials-science/mechanical-properties|力学性能]]** 是 $n$ 、$m$ 和 Lankford $r$ 值被测量之处，也是定义它们的拉伸试验被推导之处——包括 Considère 判据，即成形极限图为之绘图的颈缩条件。
- **[[solid-mechanics/plasticity|塑性力学]]** 提供流动法则和极限载荷概念，FLD 是它们的一幅经验画像。

::: history
**1400 年代。** **拉拔台**制造线材，随之而来的是对一道成形工艺的第一次定量研究：每道最大减缩——与第 4 节拉拔极限同一个不等式——文艺复兴时代的拉线工凭经验早已知道。**1818。** 第一只**深拉黄铜弹壳**，以及该工艺作为量产产品的登场：拉制的壳取代了车制的壳，到 1868 年拉制黄铜弹壳日产 40,000 只，其拉深与退火的序列至今仍是弹壳和气雾剂罐的制造方式。**1913。** 冲压钢车身取代木制，到 **1927** 年全金属车身创造了这个行业的两种制度：**模具车间**，带着它的模样车间、整模锤和调试压力机，以及**面板难题**——一块大而薄、双曲率的零件是一个 A 级表面物件，形状凭眼睛定义，靠三个月手工打磨模具造成。**1948。** **S. C. 希尔（S. C. Hill）**发表各向异性介质塑性流动理论，**W. L. 兰克福德（W. L. Lankford）、D. G. 尼克林（D. G. Nickrin）和 R. M. 克莱因（R. M. Kline）**在标准局测量拉深钢板的宽度与厚度应变，发现两者之比——**$r$ 值**——能预言可拉深性，而它随方向的变化能预言起耳。可拉深性不再是手艺，成了钢材牌号。**1960 年代。** 福特的 **G. R. 基勒（G. R. Keeler）**，以及通用的 **W. C. 恩格（W. C. Emge）**和后来的 **M. G. 赫克（M. G. Hecker）**，各自独立地从圆网格实验建立了**成形极限图**，**S. P. 基勒和 S. 马尔齐尼亚克（S. P. Keeler and Z. Marciniak）**把板料成形变成应变空间的学科；**马尔齐尼亚克与 K. 库钦斯基（K. Kuczyński）**1967 年发表至今仍支撑左支的沟槽分析。**1977。** **P. 普拉梅纳克（P. Plamennac）**为硼钢**冲压硬化**取得专利；这个想法沉睡了二十五年，因为没有碰撞结构规范要 1,500 MPa，也没有足够便宜的激光切割来切边，然后在 2000 年代作为 Euro-NCAP 世界的答案到来。**1995。** **奥迪**在量产中引入**激光拼焊板**，坯料从此是被设计的对象而不是被购买的对象。**2002。** **F. 古德温（F. Goodwin）**对 Keeler 关系的更新把 FLD 放上每个板料工程师的表格，**热冲压**随沃尔沃、随后大众高尔夫 B 柱进入量产——自 1927 年以来，第一次有一个板料新工艺在十年之内被全行业采纳。
:::

::: summary
**板有两种失效方式，模具只有一个旋钮。**它在周向受压处起皱、在受拉处撕裂，压边力坐在两者之间；模具调试的全部手艺，就是把板按在力的窗口中两者之间那 20 % 里。
**剪切是剪切面积计算加间隙诊断。**$F = 0 . 8 \sigma _ { \text{UTS} } P t$ ，每侧间隙 $5 { - } 1 3 \ \ \%\ t$ ，而边缘的塌角、光亮带、断裂和毛刺告诉你是哪条刃口磨了。精密冲裁用 V 形齿圈和 $0 . 5 \ \ \%$ 间隙把断裂整个抑制掉。
**折弯是关于不在正中间的中性层的算术。**$B A = ( \pi \theta / 1 8 0 ) ( r + K t )$ ，$K = 0 . 3 3 { - } 0 . 5$ ，$B D = 2 S B - B A$ ，坯料长度 $= \sum$ 腿 $- \sum B D$ 。外层纤维应变是 $t / ( 2 r + t )$ ，所以 $r = t$ 意味着 $3 3 \ \ \%$ ，最小半径是合金的属性而不是工具的属性。
**折弯力按 $t ^ { 2 } / V$ ，回弹按 $\sigma _ { y } / t$ 。**$F = 1 . 4 2 \sigma _ { \text{UTS} } w t ^ { 2 } / V$ ，更锐的模具花吨位；$\Delta \theta = 3 \sigma _ { y } L _ { b } / E t$ ，更强、更薄、弯得更多的零件弹得更多，而你对工具做什么都改不了弹性模量。过弯、校形、拉伸，或者热成形。
**可拉深性是比值不是深度。**软钢 $D / d \approx 2 . 1$ ，由壁的承载决定而非凸模；更深需要再拉深和退火。材料常数是 $n$ 、$m$ ，最重要的是 $\bar { r }$ ，而各向异性 $\Delta r$ 造出制耳。
**成形极限图说胀形何时停。**$\mathrm { FLD } _ { 0 } \approx 2 3 . 3 + 4 2 n$ ，左陡右平，验收规则是 10 % 或 3 点裕度。大应变相同的两个点，一个失效一个安全，唯一的区别是小应变的符号。
**板料成形便宜，模具贵。**零件花几分钱的钢和压力机的一小段时间；模具花 10,000-250,000 英镑，其中三分之一是买不回来的调试。年产低于 20,000-40,000 件时，正确的工艺是你改得起的那一个，而零件应该为它设计。
:::

- Z. Marciniak, J. L. Duncan and S. J. Hu, *Mechanics of Sheet Metal Forming*, 2nd ed., Butterworth-Heinemann, 2002 —— 第 4、5 节的权威论述，作者正是左支沟槽分析的提出者。

- F. B. Kelsall 与 W. Johnson, *Technology of Plasticity*, 与 T. Altan et al., *Sheet Metals: Properties, Forming and Applications*, ASM International, 2012 —— K 因子、回弹系数和凹模圆角规则背后的车间数字。

- M. Geiger and P. Manhardt, *Hot Stamping of Ultra High Strength Steels*，以及 Plamennac 专利文献，对应第 6 节的工艺；R. K. Bhadeshia, *Boron-processed steels*, *Science and Technology of Welding Manufacture* (2022) —— 免费而出色的在线冶金论述。
