气缸体、机床床身、机床立柱、风机轮毂、内部带冷却流道的涡轮叶片、电梯对重，全都是用同一种方法做出来的：**把金属熔化，浇进零件的阴模里，让它冻结。**本课程里没有别的工艺能做到这一点。成形需要能塑性流动的材料，而铸铁不能；切削加工需要够得着的刀具，而气缸体有一半是够不着的；增材需要一层一层堆，而四十吨的轮毂要堆一年。铸造是最古老的金属加工工艺，比别的早四千年，而且至今仍是唯一能**用脆性材料做出中空、复杂、笨重零件**的工艺——而这类零件占了现代世界地基的很大一块。

但它也是最难控制的工艺，因为一切都发生在一千五百度、一个封闭的砂箱里，只持续九十秒，而出错与否的证据要等砂子破开才看得见。本课讲你真正能控制的三件事：**金属如何凝固**（形核、晶粒长大、收缩、契弗林诺夫（Chvorinov）法则），**金属如何进入**（浇注系统、流动性、湍流），以及**铸型如何制造**（砂型、壳型、熔模、金属型、压铸型）。这三件事都做对，铸件就是健全的；做错任何一件，你会在客户的产品里发现缺陷。

::: warning 铸件报废的五种方式
**先凝固的冒口。**冒口是一个液态金属储液腔，它唯一的工作是在铸件凝固收缩时补上最后一立方毫米。如果它比铸件先凝固，它就不是冒口，而是一块用缩孔“焊”在铸件上的昂贵废铁。**规则是冒口必须最后凝固，永远如此**，这靠几何来保证——冒口需要比它补缩的对象更大的体积表面积比——或者靠冷铁，或者靠发热保温，而且它由第 2 节的契弗林诺夫法则来校核，不靠眼睛。**设计出补不到的截面。**$8 \ \mathrm { m m }$ 壁上的一个 $3 0 ~ \mathrm { m m }$ 凸台，凝固时间比壁厚晚九倍，因为凝固时间随模数的平方增长；它是一个热节，而凝固区间宽的合金里的热节，恰恰在零件受载的位置产生缩松。**湍流浇注。**浇道里的金属液雷诺数达七万，湍流三十倍，而铸型里的湍流不是温柔地搅拌——它把砂子从型壁冲下来，把氧化皮卷进去，把空气沿直浇道泵下去。每条浇注系统规则（直浇道充满、内浇道宽而薄、不得突落、不得尖角、末端放过滤器）都是湍流规则。**浇注温度太低，或太高。**太低，金属在浇道里冻住——浇不足——或者两股金属相遇却焊不上，成为冷隔。太高，金属与铸型反应，溶解更多气体，收缩更大，粘砂。窗口往往只有 $3 0 \ \mathrm { K }$ 宽，而浇注工擅自放宽它，正是一段缺陷史的开端。**铸图纸，而不是铸铸件。**一张没有拔模斜度、没有圆角、分型线穿过加工面、芯孔小到做不出砂芯、没有收缩余量的图纸，不是铸件图纸。模样车间照样做，铸造厂照样浇，然后零件会超差、拉毛地送来，加工面上露着分型线。
:::

## 2. 铸件如何凝固

::: definition 形核、晶粒与冷却速度 {#def-nucleation}
液体并不会仅仅因为低于凝固点就变成固体。制造新的固体表面要耗能——界面能 $\gamma$ ——而获得的体积自由能与过冷度 $\Delta T$ 成正比，所以半径为 $r$ 的固体胚芽使自由能改变

$$
\Delta G \; = \; { \frac { 4 } { 3 } } \pi r ^ { 3 } \Delta G _ { v } \; + \; 4 \pi r ^ { 2 } \gamma \qquad \Longrightarrow \qquad r ^ { * } \; = \; - \, { \frac { 2 \gamma } { \Delta G _ { v } } } \; \approx \; { \frac { 2 \gamma T _ { m } } { \Delta H _ { f } \, \Delta T } }
$$

小于 $r ^ { * }$ 的胚芽会重新溶掉；液体必须过冷到能存在稳定晶核为止，而所需的过冷度与 $\Delta T$ 成反比。**这就是为什么真实铸件要几十度过冷才开始凝固，为什么干净干燥的坩埚能把金属保持在凝固点以下很远处不凝固，也是为什么孕育处理有效**：悬浮的 Ti、B、Mg 或 FeSi 颗粒提供了一个半径本来就大于 $r ^ { * }$ 的表面，于是形核在几度过冷下发生，晶粒数目上升两个数量级。晶粒尺寸大致按 $d \propto { \dot { T } } ^ { - 1 / 3 }$ 跟随冷却速度，这既是激冷铸件强、厚截面铸件弱的全部原因，也是铸造工说*你看到的截面就是你得到的组织*的全部原因。

凝固随后以**枝晶**方式进行：一旦界面前沿的液体过冷超过界面所能排出的热量，平面界面就不稳定，于是界面破碎成不断生长、分叉、回填的指状物。枝晶臂之间是最后凝固的液体，固体排出的全部碳、硫、磷和共晶形成元素都坐在里面——**枝晶偏析**，一种均匀化退火能消除、而铸件没有时间消除的显微偏析。界面是保持**柱状**（背离激冷面生长，单一晶向，各向异性）还是破碎成**等轴晶**，取决于温度梯度 $G$ 与生长速度 $R$ 之比：$G / R$ 高时柱状生长稳定，而凝固区间宽、梯度低、有孕育颗粒的合金转为等轴——这正是铸造厂想要的，因为柱状枝晶是织构，而织构就是各向异性。
:::

::: definition 收缩：无法从设计上消除、只能补缩的缺陷 {#def-shrinkage}
液态金属比同种金属的固体密度低，所以铸件的收缩分三个阶段：**液体**在冷却到浇注温度时收缩（由直浇道补上，无害），**凝固中**的金属按液固密度差收缩——**这才是产生孔洞的那一个**——**固体**在冷却到室温时收缩，这就是付给模样工的收缩余量。

$$
\begin{array} { l c c l }
\textbf{合金} & \textbf{液固收缩} & \textbf{到 } 2 0 \ \ {} ^ { \circ } \mathrm { C } \textbf{的总线收缩} & \textbf{凝固特征} \\ \hline
\text{灰铸铁} & 1 . 3 \ \ \% & 1 . 0 \ \ \% & \text{石墨膨胀抵消了大部分} \\
\text{球墨铸铁} & 1 . 5 \ \ \% & 1 . 0 \ \ \% & \text{需要铁水中最大的冒口} \\
\text{Al--Si 356/A356} & 6 . 2 \ \ \% & 1 . 1 \ \ \% & \text{近共晶，补缩性好} \\
\text{碳钢} & 6 . 6 \ \ \% & 2 . 0 \ \ \% & \text{凝固区间宽，难补缩} \\
\text{锡青铜} & 1 0 \ \ \% & 1 . 3 \ \ \% & \text{最差；在 } 2 0 0 \ \mathrm { K } \text{ 上是糊状} \\
\text{镁合金 AZ91} & 4 . 0 \ \ \% & 0 . 8 \ \ \% & \text{收缩小，但会燃烧}
\end{array}
$$

两个事实组织了整个冒口设计。**灰铸铁几乎不收缩**，因为在共晶温度析出的石墨按体积膨胀 $3 \ \ \%$ ，填满了奥氏体留下的空间——这就是为什么灰铸铁铸件只需同形状钢铸件一小部分的补缩量就能做到健全，也是为什么一个被*约束*住不许收缩的灰铸铁铸型仍会开裂。**而凝固区间宽的合金不会留下一个可以补缩的单一孔洞；它以枝晶臂的糊状物凝固，液体被困在臂间彼此孤立的液池里，任何冒口都够不着，你得到的取而代之的是细密的、弥散的**缩松**——这就是为什么近共晶合金（含 11-13 % Si 的 Al-Si、灰铸铁、多数青铜）是铸造厂的心头好，也是为什么 6061 这种宽凝固区间的铝合金是糟糕的砂型铸件、却是优秀的挤压料。**
:::

::: proof 契弗林诺夫法则：为什么凝固时间随模数的平方变化 {#proof-chvorinov}
把铸型当作初始温度为 $T _ { 0 }$ 的半无限大体，其表面在 $t = 0$ 时被带到界面温度 $T _ { i }$ 。进入铸型的热流密度按

$$
q ^ { \prime \prime } ( t ) \; = \; { \frac { k _ { m } ( T _ { i } - T _ { 0 } ) } { \sqrt { \pi \alpha _ { m } t } } } \; = \; { \frac { b _ { m } ( T _ { i } - T _ { 0 } ) } { \sqrt { \pi t } } } , \qquad b _ { m } = { \sqrt { k \rho c _ { p } } } \ \ {\text{蓄热系数} }
$$

衰减，而到时刻 $t$ 为止单位面积吸收的能量是它的积分，

$$
Q ^ { \prime \prime } ( t ) \; = \; \int _ { 0 } ^ { t } q ^ { \prime \prime } \, d t \; = \; 2 \, b _ { m } ( T _ { i } - T _ { 0 } ) \, { \sqrt { \frac { t } { \pi } } }
$$

现在说铸件凝固完毕时，铸型恰好吸收了全部潜热，$\rho L V = A Q ^ { \prime \prime }$ 。解出

$$
t \; = \; \pi \left[ { \frac { \rho L } { 2 \, b _ { m } ( T _ { i } - T _ { 0 } ) } } \right] ^ { 2 } \left( { \frac { V } { A } } \right) ^ { 2 } \; \equiv \; B \, M ^ { 2 } \qquad \text{其中 } M = V / A
$$

**契弗林诺夫法则，常数由推导而非拟合而来。**对进入湿型砂的灰铸铁（$\rho = 7 { , } 0 0 0 \ \mathrm { k g / m ^ { 3 } }$ ，$L = 2 4 0 \ \mathrm { k J / k g }$ ，$b _ { m } \approx 5 0 0 \ \mathrm { J \, m ^ { - 2 } K ^ { - 1 } s ^ { - 1 / 2 } }$ ，$T _ { i } - T _ { 0 } \approx 1 { , } 1 7 5 \ \mathrm { K }$ ）它给出 $B = 6 . 4 \ \mathrm { s / m m ^ { 2 } }$ ，而标定测得的是 $2 . 4 \ \mathrm { s / m m ^ { 2 } }$ ——同一量级，三倍的因子是推导忽略的过热度、铸件收缩离开铸型时形成的气隙，以及铸型并非真正半无限大这几个因素。**这就是为什么使用时 $B$ 取拟合值而绝不用推导值；指数二才是物理，常数是铸造厂。**
:::

::: example 标定铸型，再预测铸件 {#ex-chvorinov level=3 check="9.1"}
一根 $2 5 \ \mathrm { m m }$ 方截面的灰铸铁试棒，长到可以忽略端部，在给定湿型砂铸型中 $9 5 \ \mathrm { s }$ 凝固完毕。求同一铸型中 $6 0 \ \mathrm { m m }$ 方棒的凝固时间。

对边长为 $a$ 的长方棒，$M = V / A = a ^ { 2 } / 4 a = a / 4$ ，所以

$$
B \; = \; { \frac { t } { M ^ { 2 } } } \; = \; { \frac { 9 5 } { 6 . 2 5 ^ { 2 } } } \; = \; 2 . 4 3 \ \mathrm { s / m m ^ { 2 } }
 \qquad \Longrightarrow \qquad
t ( 6 0 ) \; = \; 2 . 4 3 \times 1 5 ^ { 2 } \; = \; 5 4 7 \ \mathrm { s } \; = \; { \bf 9 . 1 \ m i n }
$$

**整个答案都在比值里：$( 6 0 / 2 5 ) ^ { 2 } = 5 . 8$ ，所以厚 2.4 倍的棒要晚 5.8 倍凝固完。**把它读成一条设计警告。壁厚两倍粗的凸台晚四倍凝固；三倍粗，晚九倍；而铸件上任何比邻居晚凝固的部位，按定义就是必须补缩或消除的热节。真实铸型的 $B$ 也随一切变化：金属型里更低，型芯旁更高（型芯是隔热体，这就是芯孔是热节的原因），热的第二型比冷的第一型更高，搁置已久、持续排气铸型还要更高。铸造厂按合金和铸型类型保存 $B$ 值表，并在型砂每次变更后重新测量。
:::

## 3. 让金属进入：浇注系统、流动性与湍流

::: definition 浇注系统，以及它必须守住的规则 {#def-gating}
**浇注系统**是浇包与型腔之间的管路：**直浇道**（垂直下降通道）、**沉淀井（直浇道窝）**（消掉下落能量的杯子）、**横浇道**（分配的水平通道）、**内浇道**（最后、最窄的节流口，控制充型速度）、**冒口**（补缩，永远不是浇注），以及**出气孔和过滤器**。它的工作是**在规定时间、不产生湍流、不夹入渣和气的条件下充满型腔，而且充满之前不能凝固**——而这四个要求互相冲突。

流动靠重力驱动，所以液位头 $h$ 下内浇道的速度是伯努利（Bernoulli）速度，再乘以一个流量系数折减，

$$
v \; = \; C _ { d } { \sqrt { 2 g h } } \qquad \Longrightarrow \qquad A _ { \text{内浇道} } \; = \; { \frac { V _ { \text{铸件} } } { t _ { \text{充型} } \, C _ { d } { \sqrt { 2 g h } } } }
$$

实用内浇道的 $C _ { d } \approx 0 . 7$ 。而该内浇道中的雷诺数是 $1 0 ^ { 4 } { - } 1 0 ^ { 5 }$ ——**湍流三十倍**——因为金属液又重又稀：浇注温度下灰铸铁的运动黏度约 $7 \times 1 0 ^ { - 7 } \ \mathrm { m } ^ { 2 } / \mathrm { s }$ ，只有水的五分之一。铸型里的湍流不是混合上的不便；它把砂子从型壁冲下（夹杂物），把氧化皮折进表面（渣线，在疲劳件里是裂纹源），而且——最糟的是——让直浇道**抽吸**，把空气沿下落液流卷进型腔。因此有三条凌驾于一切浇注规则之上的规则：**直浇道必须充满**（其截面积必须随金属加速而收缩，见下面的推导），**内浇道必须宽而薄而非圆形**（宽薄的内浇道在给定面积下速度低，且表面面积比高，在浇注末期先冻住，所以它会在冒口补缩之前先冻死），以及**金属必须以尽可能慢的速度、从最厚处进入型腔**，绝不迎着型芯。

**流动性**——金属在冻住之前能流多远——用螺旋试样测定，几乎完全由**液相线以上的过热度**和凝固区间决定：在一个温度上凝固的共晶合金流起来像水（Al-Si 356 螺旋长 $1 4 0 \ \mathrm { m m }$ ，灰铸铁 $1 { , } 2 0 0 \ \mathrm { m m } )$ ，而宽凝固区间的合金流一小段就变成浆糊。浇注温度提高 $3 0 \ \mathrm { K }$ 大约使螺旋长度翻倍，这就是为什么“把铁水烧热点”是浇注工对浇不足的第一反应，也是第二个答案——粘砂、夹气、缩松——的开端。
:::

::: example 20 kg 铁铸件的浇道截面积 {#ex-gate level=3 check="4.8"}
一个 $2 0 ~ \mathrm { k g }$ 灰铸铁铸件要求在 $3 \ \mathrm { s }$ 内充满，内浇道以上金属液头 $4 0 0 \ \mathrm { m m }$ 。$C _ { d } = 0 . 7$ 。

$$
V = { \frac { 2 0 \ \mathrm { k g } } { 7 . 1 \ \mathrm { g / c m ^ { 3 } } } } = 2 { , } 8 1 7 \ \mathrm { c m ^ { 3 } } , \qquad v = 0 . 7 { \sqrt { 2 \times 9 . 8 1 \times 0 . 4 0 0 } } = 1 . 9 6 \ \mathrm { m / s }
$$
$$
A \; = \; { \frac { 2 \, 8 1 7 \ \mathrm { c m ^ { 3 } } } { 3 \ \mathrm { s } \times 1 9 6 \ \mathrm { c m / s } } } \; = \; { \bf 4 . 8 \ c m ^ { 2 } }
$$

把它分成两个 $4 0 \times 6 \ \mathrm { m m }$ 的内浇道而不是一个，并检查流态：$4 0 \times 6$ 内浇道的水力直径是 $4 \times 2 4 0 / 9 2 = 1 0 . 4 \ \mathrm { m m }$ ，所以 $\mathrm { R e } = 1 . 9 6 \times 0 . 0 1 0 4 / 7 \times 1 0 ^ { - 7 } = 2 9 { , } 0 0 0$ ——**仍然是湍流**，而且永远是。所以浇道面积不是为层流选的，那不可能；它是为了让**速度**低到不冲刷铸型而选的，对铁水而言这意味着靠宽而薄的内浇道把浇口面速度控制在约 $0 . 5 \ \mathrm { m / s }$ 以下，并在型腔正上游放一个陶瓷过滤器（$3 { - } 5 \ \mathrm { m m }$ 孔，每英寸 $1 0 { - } 2 0$ 孔），拦住湍流反正制造出来的东西。
:::

::: proof 直浇道必须随下落收缩 {#proof-sprue}
从高度 $H$ 的直浇道顶部自由下落的金属，在深度 $z$ 处速度为 $v ( z ) = { \sqrt { 2 g z } }$ ，在底部为 $v _ { 3 } = { \sqrt { 2 g H } }$ 。没有壁面约束的液流要满足质量守恒 $A ( z ) v ( z ) = A _ { 3 } v _ { 3 }$ ，所以

$$
A ( z ) \; = \; A _ { 3 } \, { \frac { v _ { 3 } } { v ( z ) } } \; = \; A _ { 3 } \, { \sqrt { \frac { H } { z } } }
$$

因此**等截面**的直浇道不可能充满：金属加速离开壁面，其内压降到大气压以下，缝隙就把空气和熔渣从顶部吸下来——直浇道变成了抽吸喷嘴，铸件里满是气体和夹杂。图中给出所需的锥度：$z = H$ 处面积为 $A _ { 3 }$ ，$z = H / 4$ 处为 $2 A _ { 3 }$ ，$z = H / 9$ 处为 $3 A _ { 3 }$ ，到顶部发散，这就是为什么真实直浇道从 $z \approx H / 9$ 开始、做成底面积的 $3 { - } 4 \times$ ，然后导入沉淀井，在那里耗散下落能量。

**这就是传统浇注系统比例的由来。**以直浇道底部面积为 1，经典的 $1 : 3 : 4$ （直浇道：横浇道：内浇道）或 $1 : 2 : 1$ 系统，说的是节流口在哪里：**内浇道必须是最小的节流口**，这样系统才能充满、金属靠液头支撑；而横浇道必须比直浇道自然收缩所要求的更小，这样直浇道才永远不会缺流。次序弄错，节流口就移到上游，直浇道半满运行，所有关于湍流的规则都不再朝你要的方向起作用。
:::

## 4. 制造铸型

::: definition 砂型、壳型、蜡做的壳 {#def-moulds}
**湿型砂**是 90 % 的硅砂或铬铁矿砂，用 5-11 % 膨润土和 2-5 % 水黏结，再加一点煤粉以改善表面质量、并烧出一层防止机械粘砂的碳膜。“湿”指未烘干。它在砂箱里围绕模样紧实，起出模样，合箱，几分钟内浇注。它几乎不要钱，自动线上四十秒造一型，什么尺寸的零件都收，给出 $1 0 0 \ \mathrm { m m }$ 上 $\pm 1 . 5 \ \mathrm { m m }$ 和二十的 $R _ { a }$ 。它的弱点正如你所料：型砂湿的时候强度低，所以薄截面和深型芯很难；它含水，所以会放出氢，不能用于溶解气体的铝或铜合金；而且模样会磨损。

**化学（自硬）黏结**给型砂裹上在室温固化的树脂和催化剂——二氧化碳硬化的水玻璃、酸硬化的呋喃酚醛，或尿烷。铸型硬、尺寸稳定、不含氮和水，能把 $1 \ \mathrm { m }$ 的球墨铸铁铸件做到 $\pm 0 . 8 \ \mathrm { m m }$ 。每型更慢更贵，这就是它用于中重型单件小批生产、而不是汽车发动机缸体的原因。

**壳型铸造**把树脂覆膜砂吹到加热的金属模样上；贴着模样的砂固化成 $5 { - } 1 5 \ \mathrm { m m }$ 的硬壳，其余落下。两片壳粘起来，放进砂箱浇注。表面极好（$R _ { a } \ 6$ ，公差 $\pm 0 . 5 \ \mathrm { m m } )$ ，铸型薄而刚，型芯容易清出——凸轮轴、连杆、液压阀块和小型齿轮箱在年产 50,000-500,000 件时就是这么做的。

**熔模铸造**把一簇蜡模（或 3D 打印模样）浸入硅石浆料、撒砂、干燥，重复五到八次，做出陶瓷壳，然后把蜡熔掉（**用高压釜蒸，不是烧，这样壳不会裂**），把壳焙烧到 $1 { , } 0 0 0 \ \ {} ^ { \circ } \mathrm { C }$ 并浇注。没有分型线，所以没有飞边，也不需要拔模斜度；表面是陶瓷的表面，即 $R _ { a } \ 3$ ；公差是 $2 5 \ \mathrm { m m }$ 上 $\pm 0 . 1 \ \mathrm { m m }$ ；合金凡是能熔的都行，包括别的工艺都不答应的镍基高温合金和钛。成本按件计，不按模计：每公斤 8-20 英镑，首次交货期六周。

**型芯**是做出内腔的砂块。它们在芯盒里吹制、固化，用**芯头**（定位用的小凸台）粘进铸型，而且**必须排气**——型芯是一个装满空气和黏结剂气体的砂袋，金属若不能把它排走就会把它压塌，这就是所谓**呛火（芯气孔）**缺陷：一个光滑的、呈型芯表皮形状的孔洞，通常在上表面之下。型芯也是芯孔成为热节的原因：砂子隔热，所以带芯截面比同形状的实心截面晚凝固。
:::

::: example 模样尺寸：三种余量，不只一种 {#ex-pattern level=3 check="255"}
钢铸件在完工的机加工图纸上的尺寸是 $2 5 0 \ \mathrm { m m }$ 。模样尺寸是多少？

**收缩余量。**钢从浇注到 $2 0 \ \ {} ^ { \circ } \mathrm { C }$ 的总线收缩是 $2 . 0 \ \ \%$ ，所以模样工按**收缩率标尺**作图，$2 5 0 \times 1 . 0 2 0 = 2 5 5 . 0 \ \mathrm { m m }$ 。（灰铸铁和球墨铸铁 $1 . 0 \ \ \%$ ，Al-Si $1 . 1 \ \ \%$ ，锡青铜 $1 . 3 \ \ \%$ ，镁 $0 . 8 \ \ \%$ 。这个比例是*铸件*尺寸的百分比，要施加到模样上的每一个尺寸，包括芯头。）

**机械加工余量。**图纸尺寸是加工后的尺寸，所以铸件到货时必须留有可切掉的金属：$4 0 0 \ \mathrm { m m }$ 的钢铸件表面留 $3 \ \mathrm { m m }$ ，所以该面的模样在收缩率标尺之前是 $2 5 0 + 2 \times 3 = 2 5 6 \ \mathrm { m m }$ ，施加之后是 $2 6 1 . 1 \ \mathrm { m m }$ 。

**拔模斜度。**模样必须起出，所以平行于起模方向的面在铸型上给 $1 { - } 2 ^ { \circ }$ 、在型芯上给 $2 { - } 3 ^ { \circ }$ ，这意味着模样尺寸在锥度的一端测量，另一端相差 $\tan ( 2 ^ { \circ } ) \times$ 高度——$1 0 0 \ \mathrm { m m }$ 高的凸台差 $3 . 5 \ \mathrm { m m }$ 。

**对所提问题的答案是 $2 5 5 \ \mathrm { m m }$ ，而模样车间需要的答案是一张标着收缩率标尺、机械加工余量和拔模方向的图纸。**只画加工后零件的铸件图纸，是逼着模样车间重新设计，而在模样车间重新设计，正是公差丢失的方式。
:::

## 5. 补缩：定向凝固、冒口与冷铁

::: definition 让它从远端向浇口方向凝固 {#def-riser}
液态金属比同种金属的固体占更大体积，所以每个铸件里都必须有某个地方保留液体到最后一刻——而且那个地方必须是**最后凝固的位置**，否则毫无用处。因此补缩是一个只有一条规则的几何问题：

$$
t _ { \text{冒口} } \; > \; t _ { \text{铸件} } \qquad \Longleftrightarrow \qquad M _ { \text{冒口} } \; = \; \left( { \frac { V } { A } } \right) _ { \text{冒口} } \; \geq \; 1 . 1 { - } 1 . 3 \times \; M _ { \text{铸件} }
$$

对坐在铸件顶部、直径 $D$ 、高 $h = 2 D$ 、底面不冷却（它是通向铸件的口）而顶面和侧面冷却的圆柱冒口，

$$
V = { \frac { \pi D ^ { 2 } h } { 4 } } = { \frac { \pi D ^ { 3 } } { 2 } } , \qquad A = \pi D h + { \frac { \pi D ^ { 2 } } { 2 } } = { \frac { 5 \pi D ^ { 2 } } { 2 } }
 \qquad \Longrightarrow \qquad M = { \frac { D } { 5 } }
$$

所以所需冒口直径为 $D = 5 M _ { \text{required } }$ 。三种装置只买时间、不买金属：**发热保温套**（一层把热量辐射回去、削减有效冷却面积的化学毯，凝固时间最多值六倍），**冷铁**（埋进铸型、局部加大冷却的钢板或铁块，用来把热节*挪进*冒口而不是消除它），以及铸件一侧的**保温材料**，作用相反。**冒口效率**——每单位冒口金属所补缩的铸件质量——敞开式顶冒口通常 1:1 到 3:1，保温套良好的可达 5:1 到 10:1，而每一克冒口金属都是必须切掉、打磨、重熔的金属。
:::

::: example 为钢板设计顶冒口 {#ex-riser level=3 check="70"}
一块 $2 0 0 \times 2 0 0 \times 3 0 \ \mathrm { m m }$ 的碳钢板，用单个 $h = 2 D$ 的圆柱顶冒口补缩。

$$
V _ { c } = 1 { , } 2 0 0 \ \mathrm { c m ^ { 3 } } , \qquad A _ { c } = 2 ( 2 0 \times 2 0 ) + 4 ( 2 0 \times 3 ) = 1 { , } 0 4 0 \ \mathrm { c m ^ { 2 } } , \qquad M _ { c } = 1 . 1 5 4 \ \mathrm { c m }
$$
$$
M _ { r } \geq 1 . 2 \, M _ { c } = 1 . 3 8 5 \ \mathrm { c m } \qquad \Longrightarrow \qquad D \; = \; 5 M _ { r } \; = \; 6 . 9 \; \approx \; { \bf 7 0 \ m m }
$$

那个冒口容纳 $\pi D ^ { 3 } / 2 = 5 2 1 ~ \mathrm { c m } ^ { 3 }$ ，即 $4 . 1 ~ \mathrm { k g }$ 钢，而钢板是 $9 . 4 ~ \mathrm { k g }$ ：**收得率 $70 \ \ \%$ ，**那 $3 0 \ \ \%$ 以一小部分成本回到熔炼车间——但它还得切掉，切口还得打磨，浇冒口还得回炉。加上浇注系统的 $1 . 5 ~ \mathrm { k g }$ ，收得率是 $62 \ \ \%$ ，这是钢砂型铸件的典型值，也是钢铸件按交付公斤而非熔化公斤计价的原因。**并注意这个计算假设了什么：冒口只补缩这块板，铸型处处相同，冒口在补缩完成之前不会沿自身直径冻透。三个假设在实践中都要靠凝固模拟或带热电偶的试验铸件来校核，而两者都不便宜。**
:::

\text{铸钢（2 \% C 到低合金）} & 2 5 0 { - } 6 5 0 \ \mathrm { M P a } / 2 0 \ \% & 1 { , } 8 2 0 \ \mathrm { K } & \text{别的工艺做不出的形状里的韧性与可焊性} \\
\text{镍基高温合金（IN738，单晶）} & 7 0 0 \ \mathrm { M P a } / 1 { , } 2 0 0 \ \mathrm { K } & 1 { , } 6 8 0 \ \mathrm { K } & 0 . 8 \ T _ { m } \text{ 下的 } \gamma ^ { \prime } \text{，陶瓷型芯上铸造，一片一个晶} \\
\text{Ti-6Al-4V} & 8 3 0 \ \mathrm { M P a } / 1 2 \ \% & 1 { , } 9 0 0 \ \mathrm { K } & \text{真空或惰性气体中浇入可溶出壳型，否则免谈}
\end{array}
$$

掉出四条规则。**压铸合金只有锌、铝、镁和小件黄铜**，因为 $1 { , } 8 0 0 \ \mathrm { K }$ 的铁和钢会溶解钢模并使其开裂；推论是压铸件不能做固溶处理，因为夹气膨胀会使它起泡——这就是为什么压铸件的销售说明是“不可热处理、不可焊接”，也是为什么结构件改用**低压**或**挤压**铸造的原因。**铝铸件要精炼除气**——旋转叶轮通氩或氮，或六氯乙烷棒——并用减压机检验（真空下凝固的小样块；起泡即说明熔体含气），因为氢在固体铝中的溶解度只有液体中的二十分之一，每一立方厘米溶解气体都会变成气孔。**球墨铸铁是靠浇入 $0 . 0 3 { - } 0 . 0 6 \ \ \%$ 的镁做出来的**，通常以包内砂堤中的 Ni-Si-Mg 中间合金形式加入，而镁在十五分钟的计时器上向大气损失，这就是为什么每包都要测球化率，也是为什么一次处理后的最后一包不等于第一包。**而耐火合金——镍、钛、钨——只能在陶瓷壳型中配陶瓷型芯、在真空或惰性气氛熔炼下铸造，这就是涡轮叶片为什么值那个价钱的原因**，也是[[manufacturing/additive-manufacturing]]被发明的原因。
:::

## 7. 缺陷，以及它们的代价

::: definition 缺陷分类表 {#def-defects}
$$
\begin{array} { l l l l }
\textbf{缺陷} & \textbf{外观} & \textbf{成因} & \textbf{对策} \\ \hline
\text{缩孔} & \text{粗糙、发暗、不规则，在热节处} & \text{补缩用尽} & \text{更大或位置更好的冒口、冷铁、保温套、降低浇注温度} \\
\text{缩松} & \text{枝晶间细密海绵状} & \text{凝固区间宽，孤立液池} & \text{近共晶合金、加快凝固、热等静压} \\
\text{气孔} & \text{光滑圆球，常在上表面之下} & \text{溶解气体、湿铸型、未排气型芯} & \text{精炼除气、干工具、排气、降低浇注温度} \\
\text{呛火（芯气孔）} & \text{光滑孔洞，呈型芯表面形状} & \text{型芯气体排不出} & \text{芯排气、无油芯砂、减少黏结剂} \\
\text{浇不足} & \text{圆头的、未充满的角} & \text{金属在型腔充满前冻住} & \text{加快充型、提高浇注温度、加厚截面、加强保温} \\
\text{冷隔} & \text{两股金属相遇处的折痕} & \text{氧化皮或冷壁阻碍焊合} & \text{单一浇道路径、提高浇注温度、避免分流} \\
\text{热裂} & \text{沿最后凝固晶界的裂纹} & \text{收缩受阻于不肯让位的铸型} & \text{强度低/可溃缩的型芯、圆角、避免截面突变、控制 S} \\
\text{夹杂 / 夹渣} & \text{带棱角的异物块} & \text{湍流、浇包浮渣、冲刷型壁} & \text{过滤器、挡渣、阻渣坝、充满直浇道、加宽内浇道} \\
\text{结疤 / 机械粘砂} & \text{表面一层砂壳} & \text{金属挤进砂粒之间} & \text{涂料、更紧的紧实、煤粉、铬铁矿面砂} \\
\text{硬点} & \text{局部白口（未石墨化）斑块} & \text{冷得太快，或截面过大} & \text{退火，或挪开你无意放下的那块冷铁} \\
\text{芯偏移} & \text{偏心的孔} & \text{浇注时型芯浮起，或芯头磨损} & \text{芯头、芯撑，检查芯盒} \\
\text{翘曲} & \text{落砂后铸件不平整} & \text{受阻收缩留下残余应力} & \text{对称截面、热态落砂、去应力退火}
\end{array}
$$

缺陷的经济学不是零件的价值。一个在铸造厂报废的 23 英镑铸件损失 23 英镑和一周；同一个缺陷在客户的齿轮箱里被发现，损失一次拆解、一次可追溯性调查，和一次比全年利润还贵的供应商审核。**这就是为什么铸造厂真正的产品是凝固方案**——那张画着冒口、冷铁、浇道和热电偶位置的图纸——也是为什么这个方案如今在模样开工之前先由模拟来制定。
:::

::: example 砂型铸件的成本 {#ex-cost level=3 check="23.2"}
$5 { , } 0 0 0$ 件灰铸铁壳体，净重 $8 . 0 ~ \mathrm { k g }$ ，含冒口和浇道的浇注毛重 $1 3 . 0 ~ \mathrm { k g }$ 。金属运到铸型旁每公斤 0.95 英镑，造型与落砂按毛重每公斤 0.55 英镑，模样 6,500 英镑，清理打磨按净重每公斤 0.30 英镑。

$$
\underbrace { 1 3 . 0 \times 0 . 9 5 = 1 2 . 3 5 } _ { \text{金属，毛重} } \; + \; \underbrace { 1 3 . 0 \times 0 . 5 5 = 7 . 1 5 } _ { \text{造型} } \; + \; \underbrace { 6 { , } 5 0 0 / 5 { , } 0 0 0 = 1 . 3 0 } _ { \text{模样} } \; + \; \underbrace { 8 . 0 \times 0 . 3 0 = 2 . 4 0 } _ { \text{清理} } \; = \; { \bf \pounds 2 3 . 2 0 }
$$

对 $8 ~ \mathrm { k g }$ 的净重而言，即**每交付公斤 2.90 英镑**，还没算机加工，而法兰的机加工会加得比铸造还多。注意钱在哪里：**金属按毛重计价，所以那 $5 ~ \mathrm { k g }$ 冒口和浇道在 23.20 英镑里占了 4.75 英镑——成本的 20 % 是你将要重熔的金属。**用更好的补缩方案把冒口系统削减三分之一，值每件 1.60 英镑，这就是为什么铸造厂对带厚凸台的“简单”铸件，报价反而比截面处理得当的复杂铸件更高。
:::

## 习题

::: exercise 收缩率标尺 {#ex-shrinkrule level=2 check="255"}
碳钢铸件的一个尺寸为 $2 5 0 \ \mathrm { m m }$ ，不允许机加工。模样尺寸必须是多少？（以 mm 为单位，取整到毫米。）
::: solution
钢的总线收缩是 $2 . 0 \ \ \%$ ：$2 5 0 \times 1 . 0 2 0 = { \bf 2 5 5 \ m m }$ 。**模样车间按收缩率标尺工作——钢用刻度长 $2 \ \ \%$ 的标尺，铁用 $1 \ \ \%$ ——模样上的每一个尺寸，包括芯头和拔模斜度，都按这把尺子做。****漏掉它，铸件在 $2 5 0 \ \mathrm { m m }$ 的面上短 $5 \ \mathrm { m m }$ ，客户那里再多的机加工也救不回来。**
:::
:::

::: exercise 更薄钢板的冒口直径 {#ex-riser2 level=2 check="60"}
一块 $2 0 0 \times 2 0 0 \times 2 5 \ \mathrm { m m }$ 的钢板由单个 $h = 2 D$ 、底部保温的圆柱顶冒口补缩。所需冒口模数取铸件模数的 $1 . 2 \times$ 。求 $D$ 。（以 mm 为单位。）
::: solution
$M _ { c } = 1 { , } 0 0 0 / 1 { , } 0 0 0 = 1 . 0 0 \ \mathrm { c m }$ ，所以 $M _ { r } \geq 1 . 2 0 \ \mathrm { c m }$ ，$D = 5 M _ { r } = 6 . 0 \ \mathrm { c m } = { \bf 6 0 \ m m }$ 。**对 $h = 2 D$ 的冒口，$D = 5 M$ 这个结果值得背下来，同样值得记住的是它只是起点不是答案：它假设冒口只补缩这块板、铸型均匀、冒口颈不会先冻——而冒口颈作为储液腔与铸件之间唯一的金属，恰恰通常是最先冻住的。**
:::
:::

::: exercise 给定浇道的充型时间 {#ex-fill level=2 check="3.2"}
一个 $1 { , } 5 0 0 ~ \mathrm { c m } ^ { 3 }$ 的铸件，内浇道总面积 $3 . 0 ~ \mathrm { c m } ^ { 2 }$ ，液头 $2 5 0 \ \mathrm { m m }$ ，$C _ { d } = 0 . 7$ 。求充型时间。（以秒为单位，保留一位小数。）
::: solution
$v = 0 . 7 { \sqrt { 2 \times 9 . 8 1 \times 0 . 2 5 } } = 1 . 5 5 \ \mathrm { m / s }$ ，$Q = 1 5 5 \times 3 . 0 = 4 6 5 \ \mathrm { c m ^ { 3 } / s }$ ，$t = 1 \, 5 0 0 / 4 6 5 = { \bf 3 . 2 \ s }$ 。**$1 . 5 \ \mathrm { k g }$ 的铸件三秒充满是合适的；经验法则是型腔应在 1-10 秒内充满，快到没充满之前不会冻住，慢到不会冲刷铸型。一个在砂型里要四十秒才充满的铸件，通常在最后一英寸充满之前，浇道早就冻住了。**
:::
:::

::: exercise 热节倍数 {#ex-hotspot level=2 check="9"}
直径 $3 0 \ \mathrm { m m }$ 的圆柱凸台接在厚 $1 0 \ \mathrm { m m }$ 的壁上。凸台比壁厚晚多少倍凝固？
::: solution
凝固时间随 $M ^ { 2 }$ 增长，而长圆柱的 $M$ 是 $D / 4$ ，所以倍数是 $3 0 ^ { 2 } / 1 0 ^ { 2 } = { \bf 9 }$ 。**晚九倍，而铸件其余部分早已凝固、再也补不到它。** **对策在图纸上：凸台不超过壁厚的 $1 . 5 \times$ ，以 $6 { : } 1$ 过渡进壁厚；如果接头必须厚，就在那里放冷铁，让整个区域一起凝固。**
:::
:::

::: exercise 铸件收得率 {#ex-yield level=2 check="61"}
铸件离开清理车间时净重 $8 . 0 ~ \mathrm { k g }$ ；浇注时含冒口和浇道重 $1 3 . 2 ~ \mathrm { k g }$ 。铸件收得率是多少？（以百分数表示，取整。）
::: solution
$1 0 0 \times 8 . 0 / 1 3 . 2 = { \bf 6 1 \ \ \% }$ 。**中等复杂度的砂型铸件收得率 55-70 % 属正常；简单形状的压铸件和熔模铸件 85-95 %；带三个冒口和厚重补缩头的钢铸件 40 %。****被切掉的金属并没有丢——它以制造成本约 $5 \ \ \%$ 的代价回到炉子——但它被熔化、搬运、切割、打磨和计量过，而熔化它要花 $1 . 4 \ \mathrm { M J / k g }$ 。收得率是铸造厂对成本和碳的最大单杆，而它由补缩方案决定，补缩方案由设计师的截面设计决定。**
:::
:::

::: exercise 靠冷却速度细化晶粒 {#ex-grain level=3 check="10"}
同一铸件上，激冷面处冷却速度为 $1 0 0 \ \mathrm { K / s }$ ，中心为 $0 . 1 \ \mathrm { K / s }$ 。按 $d \propto { \dot { T } } ^ { - 1 / 3 }$ 律，中心的晶粒大多少倍？
::: solution
$( 1 0 0 / 0 . 1 ) ^ { 1 / 3 } = 1 0 0 0 ^ { 1 / 3 } = { \bf 1 0 }$ 。**晶粒大十倍，按霍尔-佩奇（Hall–Petch）相当于 $3 0 { - } 6 0 \ \mathrm { M P a }$ 的屈服强度，疲劳强度和气密性的差距还要大得多——同一个铸件，同一包铁水，相距三厘米。****这就是为什么铸件标准按规定截面的单铸试棒报价，也是为什么设计师按手册薄截面数值计算却画出厚截面，犯的不是算术错误而是工艺错误。**
:::
:::

::: exercise 保温套买到了什么 {#ex-sleeve level=3 check="6.25"}
发热保温套把冒口的有效冷却面积减到裸冒口的 $4 0 \ \ \%$ 。按契弗林诺夫法则，凝固时间增加多少倍？
::: solution
$t \propto ( V / A ) ^ { 2 }$ 而 $V$ 不变，所以倍数是 $( 1 / 0 . 4 ) ^ { 2 } = { \bf 6 . 2 5 }$ 。**这就是为什么用 40 英镑的保温套代替 400 英镑的冒口——也是为什么保温套的性能必须当作过程变量来管理：受潮或开裂的保温套，或与铸型之间有缝隙的保温套，只给出六倍里的一小部分，铸件就在二月的某个星期二变得不健全。****同样的算术，是冒口绝不能偶然贴着钢板冷铁放置的原因，也是冷铁要放在你希望金属先凝固之处的原因。**
:::
:::

::: exercise 推导并使用临界晶核 {#ex-nuc level=4 check="0.8"}
证明 $r ^ { * } = 2 \gamma T _ { m } / ( \Delta H _ { f } \Delta T )$ ，并对铁（$\gamma = 0 . 2 0 \ \mathrm { J / m ^ { 2 } }$ ，$T _ { m } = 1 { , } 8 1 1 \ \mathrm { K }$ ，$\Delta H _ { f } = 1 . 8 4 \times 1 0 ^ { 9 } \ \mathrm { J / m ^ { 3 } } )$ 在过冷度 $1 , 1 0 , 1 0 0 \ \mathrm { K }$ 下求值。多大的过冷度使直径 $1 . 0 \ \mu \mathrm { m }$ 的孕育颗粒恰好大到足以形核？
::: solution
在 $\Delta G = { \textstyle { \frac { 4 } { 3 } } } \pi r ^ { 3 } \Delta G _ { v } + 4 \pi r ^ { 2 } \gamma$ 中令 $d ( \Delta G ) / d r = 0$ ，其中 $\Delta G _ { v } = - \Delta H _ { f } \Delta T / T _ { m }$ ，得 $r ^ { * } = 2 \gamma T _ { m } / ( \Delta H _ { f } \Delta T ) = 3 . 9 4 \times 1 0 ^ { - 7 } / \Delta T \ \mathrm { m }$ ：

$$
\Delta T = 1 \ \mathrm { K } \Rightarrow r ^ { * } = 3 9 4 \ \mathrm { n m } , \qquad 1 0 \ \mathrm { K } \Rightarrow 3 9 \ \mathrm { n m } , \qquad 1 0 0 \ \mathrm { K } \Rightarrow 3 . 9 \ \mathrm { n m }
$$

半径 $0 . 5 \ \mu \mathrm { m } = 5 0 0 \ \mathrm { n m }$ 的颗粒在 $r ^ { * } \leq 5 0 0 \ \mathrm { n m }$ 时稳定，即 $\Delta T \geq 3 9 4 / 5 0 0 = { \bf 0 . 8 \ K }$ 。**这就是孕育处理的全部机理，一行写完：一颗 $1 \ \mu \mathrm { m }$ 的硅铁颗粒让液体在不到一开尔文的过冷下凝固，而纯净的铁需要几十度，它把晶核数目乘以两三个数量级。同样的逻辑说明为什么型壁是比型腔中部更好的形核基底，为什么激冷面晶粒细小，为什么过热浇注（会溶掉晶核）得到粗大组织——铸造厂测量过热度像测量温度一样认真，就是这个原因。**
:::
:::

::: exercise 推导冒口的标度律及其代价 {#ex-riserscale level=4 check="2.8"}
证明底面保温、$h = 2 D$ 的圆柱冒口有 $M = D / 5$ ，且其体积按 $t ^ { 3 / 2 }$ 标度。若铸件模数翻倍，冒口体积增大多少倍？
::: solution
$h = 2 D$ 时，$V = \pi D ^ { 2 } h / 4 = \pi D ^ { 3 } / 2$ ，冷却面积是圆柱侧面加顶面，$A = \pi D h + \pi D ^ { 2 } / 2 = 2 \pi D ^ { 2 } + { \textstyle { \frac { 1 } { 2 } } } \pi D ^ { 2 } = { \textstyle { \frac { 5 } { 2 } } } \pi D ^ { 2 }$ ，所以 $M = V / A = D / 5$ 。由于 $t \propto M ^ { 2 }$ ，$D = 5 M \propto t ^ { 1 / 2 }$ ，$V _ { r } = \pi D ^ { 3 } / 2 \propto t ^ { 3 / 2 }$ 。**模数翻倍使所需冒口体积乘以 $2 ^ { 3 / 2 } = { \bf 2 . 8 }$ ，截面增大十倍则乘以 32。****这就是重型铸件被垃圾桶大小的冒口包围的原因，是一吨以上要用空心保温冒口的原因，是冷铁价值千金的原因，也是设计师能为铸件做的最大一件事——让截面薄、匀、有过渡——的原因：补缩成本对截面是超线性的，而且要用金属、人工、能量和整活收得率来付。**
:::

::: quiz 气孔还是缩孔 {#quiz-porosity}
一个钢铸件的射线照片显示，厚重凸台上表面之下聚集着发暗、不规则、树枝状的孔洞，铸件其余部分干净。首选对策是
- [ ] 延长熔体精炼时间
- [x] 给那个凸台更好的补缩——更大或位置更好的冒口、保温套，或用冷铁把热节挪走
- [ ] 降低浇注温度、放慢浇注
- [ ] 给型芯排气
::: solution
**不规则、树枝状、发暗、位于最后凝固处，就是缩孔，不是气孔：气孔是球形、光滑、弥散分布的。****降低浇注温度会让补缩更糟，给型芯排气对实心凸台毫无作用。正确的顺序是先找到最后凝固的位置（靠模拟、靠模数法则，或靠热电偶），然后要么补缩它，要么让它不再最后凝固。**
:::
:::

::: quiz 为什么钢支架不能压铸 {#quiz-diecast}
因为
- [ ] 钢熔化太贵
- [ ] 压铸做不出支架形状
- [x] $1 { , } 8 0 0 \ \mathrm { K }$ 的钢水会冲蚀、粘焊并热疲劳开裂钢模，所以该工艺限于低熔点合金
- [ ] 压铸件总是多孔，钢会更糟
::: solution
**压铸是把金属液以 $3 0 { - } 1 5 0 \ \mathrm { M P a }$ 喷入抛光工具钢模具、模间水冷的工艺；铁和钢在其浇注温度下会溶解模具表面、与其焊合，并在几百模内把它热裂。****$4 2 0 \ \ {} ^ { \circ } \mathrm { C }$ 的锌、$6 6 0 \ \ {} ^ { \circ } \mathrm { C }$ 的铝和 $6 8 0 \ \ {} ^ { \circ } \mathrm { C }$ 的镁温和到模具能活一百万模；这就是压铸合金清单的全部。多孔这一点是真的但居次——它正是压铸件不热处理、不焊接，结构件改用低压或挤压铸造的原因。**
:::

## 后续内容

- **[[manufacturing/bulk-forming|体积成形工艺]]**正是铸造弱点的解药：铸态组织多孔而粗大，而锻造焊合孔隙、排布流线——见该课中两者疲劳强度的差距。
- **[[manufacturing/joining|连接]]**讲可焊性，它既是焊接问题也是铸造问题：灰铸铁只有预热加镍基焊材才能焊，铸件上的一次“焊补”是一道有规程的冶金操作。
- **[[manufacturing/machining|切削加工]]**从铸造结束的地方开始——铸态表皮又硬又有氧化皮又含砂，对砂型铸件的第一刀是一把刀这辈子最难受的一刀。
- **[[manufacturing/polymer-composite-processing|聚合物与复合材料成型]]**是伪装的铸造：注塑就是在模具只有 $8 0 \ \ {} ^ { \circ } \mathrm { C }$ 的温度下对聚合物做高压压铸，补缩、浇注、收缩是同一批问题。
- **[[manufacturing/additive-manufacturing|增材制造]]**拿走了铸造唯一做不到的事——换形状不换工装——并为此在速率上付账。
- **[[materials-science/phase-diagrams|相图]]**提供本课当作过程变量使用的凝固区间、共晶与偏析，**[[materials-science/phase-transformations|相变]]**提供多数铸件事后的热处理。
- **[[manufacturing/process-selection|制造工艺及其选择]]**是铸造工艺在成本、公差和批量上与其他一切竞争的地方。

::: history
**约公元前 3200 年。**最早的金属加工是铸造而不是锻造：巴尔干和喀尔巴阡的山铜珠与斧钺浇在开放式石模里，一千年之内出现两半式闭式铸型，两千年之内出现失蜡法和有意把锡掺进铜里炼青铜——一个发明得如此之早、如此之成功的工艺，以致一个时代以合金而不是以工具命名，而合金本身就是铸造冶金学家的胜利：锡让铜变流畅，没有别的元素比它做得更好。**15 世纪前后。**中国和随后欧洲的铸炮厂让铸造成为重工业：三吨青铜炮在坑上土石模中铸出，缓慢冷却，然后镗削——而推动镗床、刀架和机床工业的，是镗炮而不是铸炮，三个世纪后威尔金森（Wilkinson）、莫兹利（Maudslay）与惠特沃斯（Whitworth）继承了这条线索。**19 世纪 90 年代—20 世纪 20 年代。**机械湿型造型：造型机和  overhead 悬挂输送线取代了泥膏地台，而美国西部的**膨润土**黏结砂只需东部黏土一半的水、四分之一紧实功的发现，给了现代铸型强度、溃散性和存放期。于是一型一分半钟造成，一台汽车缸体九十秒造成。**1930 年。**布拉格的**博胡斯拉夫·契弗林诺夫（Bohuslav Chvorinov）**根据实测凝固时间发表法则 $t = B ( V / A ) ^ { 2 }$ ，给了铸造界唯一的定量设计定律，让冒口设计从一门传统变成一道计算；凯恩（Caine）方法和 20 世纪 50 年代的模数法把它变成了一张表。**1943 年。****约翰内斯·克罗宁（Johannes Croning）**的壳型工艺给出在加热金属模样上制成的薄而刚的树脂黏结铸型，铸件质量好到可以顶替本要机加工的锻件：凸轮轴、连杆、液压阀。**1948 年。**国际镍公司的**H. 莫罗（H. Morrogh）**与独立地**R. E. 海斯（R. E. Heise）**证明加镁能使石墨长成球状而非片状，球墨铸铁赋予铸铁前所未有的延性和疲劳强度——这一工艺史上最重大的单次冶金事件，花了十年才被相信。（R. Geller 1936 年的德国专利其实先做出来了，但作为商业机密被雪藏。）**20 世纪 40—70 年代。****熔模铸造**随喷气发动机从牙科实验室走进航空工业：陶瓷壳，冷却流道的耐火型芯，然后是定向凝固直至单晶叶片，于是 1945 年以毫米公差铸出的零件到 1980 年以十分之一毫米铸出，用的是一种根本无法锻造的合金。**20 世纪 80 年代。**凝固与充型**模拟**——从 20 世纪 70 年代各大学课题组到 SDT、MAGMA 和 ProCAST——在模样开工之前算出凝固顺序、充型模式和孔隙率，把试验铸件从一种发现变成一次验证，并把铸造厂的核心工件从模样车间搬到屏幕上。
:::

::: summary
**铸造是唯一能用脆性材料做出中空、复杂、笨重零件的工艺**，它在形状、材料、尺寸和低批量低工装上取胜。它在凝固收缩和铸态性能上吃亏，本课的每一个设计决策都是保住胜势、尽量少付代价的努力。
**凝固由两个平方支配。**形核需要过冷，$r ^ { * } = 2 \gamma T _ { m } / ( \Delta H _ { f } \Delta T )$ ，孕育处理靠给液体一颗本来就大于 $r ^ { * }$ 的颗粒起效；凝固时间是契弗林诺夫的 $t = B ( V / A ) ^ { 2 }$ ，$B$ 取拟合而非推导。第二个平方派生出一的一切：热节就是模数大于邻居的截面，冒口的模数还必须更大，三倍壁厚的凸台晚九倍凝固。
**补缩是几何。**底面保温、$h = 2 D$ 冒口的 $M = D / 5$ ，$M _ { r } \geq 1 . 2 M _ { c }$ ，冷铁用来挪热节而不是消热节，保温套花 40 英镑代替 400 英镑买时间——以及按 $t ^ { 3 / 2 }$ 增长的冒口体积，这就是截面设计胜过冒口设计的原因。
**浇注是湍流问题。**$A = V / ( t _ { \text{充型} } C _ { d } \sqrt { 2 g h } )$ ，雷诺数永远是 $1 0 ^ { 4 } { - } 1 0 ^ { 5 }$ ，直浇道必须按 $\sqrt { H / z }$ 收缩否则抽吸，内浇道必须是最小且最扁平的节流口，金属必须慢速从最厚处进入，过滤器兜住设计没能防住的东西。
**铸型就是公差。**湿型砂便宜、快、$1 0 0 \ \mathrm { m m }$ 上 $\pm 1 . 5 \ \mathrm { m m }$ ；自硬砂稳定到 $\pm 0 . 8$ ；壳型 $R _ { a } \ 6$ ；熔模没有分型线、不需要拔模、按件计价；而模样在承载任何尺寸之前，必须先承载三种余量——收缩、加工、拔模。
**认识合金和它们的独门绝技。**灰铸铁因石墨膨胀而收缩小；球墨铸铁需要镁而镁在计时器上流失；铝必须除气且不能浇在湿砂里；压铸限于锌、铝、镁和小件黄铜，其产品不能热处理、不能焊接；耐火合金只能在真空中浇进陶瓷壳，这就是它们贵的原因。
**先诊断孔洞，再对症下药。**光滑圆球是气孔，要更干、更凉、更干净的金属；最后凝固处粗糙的树枝状孔洞是缩孔，要更热、补得更好的金属。对策相反，用错就是缺陷变成合同。
:::

## 延伸阅读

- J. Campbell，*Castings: The Metallurgy, Design and Production of Castings*，第 2 版，Butterworth-Heinemann，2003——缺陷之书，以及“几乎每个缺陷都是一条 bifilm（熔体中本来就有的氧化膜折叠）”的论点。
- D. Apelian、R. Toder 与 L. H. Han 主编，*ASM Handbook, Volume 15: Casting*，ASM International，2008——第 1 节的逐工艺能力数据、第 7 节的缺陷图谱、第 6 节的包内冶金。
- R. Elliott，*Castings Technology*，Butterworth-Heinemann，1996——凝固、形核、共晶生长与铸造合金冶金，出自亲手测量过它们的人。
- A. J. Reid，*The Quality Castings Handbook: Designing Castings for Quality and Profit*，CRC Press，2016——第 3、4 节的设计规则、模样余量与浇注实践，出自见过这种错误每一个版本的顾问。
- P. V. Ribblett，*Standards for Metalcastings: A Guide to the Use of International Standards*，ASM International，2002——第 1、7 节的公差、冶金和健全性标准到底说了什么，以及如何在图纸上引用它们。
- C. W. Ammon，*Metal Casting*，Tab Books，1979——小铸造厂、手工铸型、模样和芯盒，至今仍是这个过程不自动化时是什么滋味最好的描述。
