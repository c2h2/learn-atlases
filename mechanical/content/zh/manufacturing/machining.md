切削加工是其他工艺拿来做标尺的那个工艺，也是最好永远没被发明出来的那个。它是制造金属零件的唯一一条**靠去除材料来造形状**的路，这意味着它浪费金属、消耗能量、折断刀具，还留下一个表面——其属性属于一层被剧烈剪切、热循环、加工硬化的表皮，而不属于基体。每个正经的制造工程师的第一直觉都应该是把零件成形或铸造、只加工必须保证的面——而这个直觉不总是对的，原因是切削加工有四点别的工艺比不了的优点：**它能造出刀具够得着的任何形状，用任何材料，达到机器刚度保得住的任何公差，而且完全不需要零件专用工装。**铸件做不出 1,200 MPa 钢里 0.01 mm 的孔；锻件做不出内部冷却流道；模具做不出 3 米焊接框架一年四十件。切削加工能，而且能周五还不存在的图纸、周一就开工。

这就是全部的商业论据，也是钱流向切削加工的原因：**切削钛合金飞机支架的 buy-to-fly 比是 5-10**——每千克进入飞机的金属，就有五到十千克车间产品被变成切屑——**而一个喷气发动机盘件的切削时间是每小时 200 英镑的机器四十小时**，而变成它的锻件只值 2,000 英镑。本课讲的就是决定这些数字的物理：切屑是什么，刀具为什么磨损，要多少功率，得到什么表面，以及切削在哪里不再是答案。

::: warning 切削出错的七种方式
**因为切削是默认选项就选它。**图纸上每个带 $\pm 0 . 1 \ \mathrm { m m }$ 尺寸和 $1 . 6 \ \mu \mathrm { m }$ 光洁度的零件，都是被设计进每小时 40 英镑机时的零件。问题从来不是"这能加工吗"，而是"这个公差花多少钱、买到了什么"——见 [[manufacturing/process-selection]]。**规定图纸并不需要的公差。**一个孔的成本每收紧一个 IT 等级都陡然上升：IT11–12 的钻孔是一分钟，IT7 的铰孔几分钟，IT5 的珩磨孔十分钟，IT3–4 的研磨孔是一小时加一个技师。**"所有表面 $R _ { a } \ 0 . 8 "$ 是机械工程里最贵的一句话。** **把刀具用到报废而不是用到最优。**泰勒指数意味着，对 $n = 0.25$ 的硬质合金，200 m/min 的刀具寿命是 100 m/min 的十六分之一；按操作工喜欢的速度跑的车间，要么在付刀具的钱，要么在付机时的钱，而最优的算术只有两行。**无视尺寸效应。**钢的比切削能在 $0 . 3 \ \mathrm { m m }$ 切屑时是 $2 { - } 3 \ \mathrm { J / m m ^ { 3 } }$ ，在 $1 0 \ \mu \mathrm { m }$ 时是它的好几倍，因为切屑厚度接近刀刃半径（无论多锋利都有 $2 { - } 1 0 \ \mu \mathrm { m }$ ）时，越来越多的功花在犁削和挤压上，而不是切削上。**微细切削是一门不同的物理、一台不同的机器。** **把逆铣和顺铣搞混。**逆（传统）铣中刀齿从零厚度切入、摩擦、然后把工件沿工作台往上拽；顺铣中刀齿从满厚度切入、工作台进给帮着切。顺铣表面更好、刀具更久、加工硬化更少，而且只有工作台的丝杠间隙被消除时才可用——这就是为什么每台老式手动铣床必须逆铣、而每台数控铣床能够也应当顺铣。**让机器颤振。**颤振是自激的：刀齿留下的波被下一个刀齿切掉，主轴转速不对时两者相互加强。它赔上表面、刀片有时赔上主轴轴承，而对策不是减速，是**把转速改变 15-20 %** ，或换不等齿距的铣刀。**加工一个本该成形的零件，或成形一个本该加工的零件。**一块 4,000 件的不锈钢支架从板材加工、buy-to-fly 为 6，就是 300 英镑的零件，而 60,000 英镑的冲压模具能以 40 英镑做出来——而 40 件的样机"成形"在 60,000 英镑的冲压模具里，就是永远造不出来的样机。**还有，永远别忘了危险：**旋转的卡盘和主轴、飞溅的切屑和灼热的铁屑、锋利的边、冷却液雾和皮肤接触、铸铁、复合材料和含铍合金的粉尘、镁和钛细屑的着火风险，以及超过额定转速运转的砂轮的爆裂能量。切削加工只能在经过适当培训、有防护罩、护目镜、抽排和监督的条件下进行。
:::

## 1. 切屑是什么

::: definition 剪切面、力圆，以及三种切屑 {#def-chip}
摇动车床的手柄，刀具并不像刀那样"切"。它**沿一条与表面成 $2 0 { - } 3 5 ^ { \circ }$ 的窄平面剪切金属**，切屑沿该平面上行、越过刀具的前刀面。其余一切随之而来。**切屑厚度比** $r = t _ { 1 } / t _ { 2 }$ （未切层比切后，因为切屑比它来的那一层厚、被压缩过，恒小于 1）几何上确定了剪切面角 $\phi$ ，刀具上的力分解成一个干净的圆：

$$
\tan \phi \; = \; { \frac { r \cos \alpha } { 1 - r \sin \alpha } } , \qquad
F _ { s } = F _ { c } \cos \phi - F _ { t } \sin \phi , \qquad
\mu \; = \; { \frac { F _ { t } + F _ { c } \tan \alpha } { F _ { c } - F _ { t } \tan \alpha } }
$$

其中 $F _ { c }$ 是切削力（消耗功率的分量，$P = F _ { c } V )$ ，$F _ { t }$ 是进给力。**剪切面上的切应力**随之是 $\tau _ { s } = F _ { s } / ( w t _ { 1 } / \sin \phi )$ ，其中 $w t _ { 1 } / \sin \phi$ 是剪切面的面积——剪切面从刀尖以角度 $\phi$ 一直延伸到自由表面。它通常明显高于在退火金属上慢速试验测得的剪切屈服强度，因为剪切区是一个 $1 0 0 { - } 3 0 0 \ \ \%$ 应变、$1 0 ^ { 3 } { - } 1 0 ^ { 6 } \ \mathrm { s ^ { - 1 } }$ 应变速率、几百度的区域。

**切屑形态**告诉你材料做了什么，它是机工的诊断书：

$$
\begin{array} { l l l l }
\textbf{切屑} & \textbf{材料} & \textbf{正在发生什么} & \textbf{后果} \\ \hline
\text{连续，带状} & \text{软钢、铝、铜（延性，高 } n ) & \text{均匀剪切} & \text{表面好；长条缠绕工件} \\
\text{连续 + 积屑瘤} & \text{低碳钢、不锈钢、钛} & \text{前刀面上的焊合层} & \text{表面差、尺寸偏大，然后整块脱落成凹坑} \\
\text{不连续，粒状} & \text{灰铸铁、含铅黄铜} & \text{刀前开裂} & \text{表面好但粉尘磨蚀、刀具磨损} \\
\text{锯齿（分段）} & \text{Ti-6Al-4V、Inconel、45 HRC 钢} & \text{绝热剪切带} & \text{崩刃、振动、刀具断裂} \\
\text{螺旋 / C 形} & \text{同上，带断屑槽} & \text{几何强迫卷曲} & \text{唯一出得了深孔的切屑}
\end{array}
$$

**积屑瘤**是其中最重要、在车间里最不被理解的一种：在 $3 0 0 { - } 5 0 0 \ \mathrm { ^ { \circ } C }$ 和高压下，一部分切屑焊在前刀面上，长到刀刃半径的两三倍，然后崩落——于是工件正被一把暂时更锐、然后更钝、然后缺席的刃切削。这就是为什么慢速切削的低碳钢表面反而比快速切同一种钢差（积屑瘤需要时间和中等温度才能形成），为什么往钢里加硫和铅使它"易切削"（夹杂物是现成的裂纹路径和固体润滑剂），为什么答案通常是更高速度、抛光前刀面、充分冷却——而不是更低。
:::

::: proof 剪切面角与摩擦角 {#proof-merchant}
剪切区体积不变说穿过该平面的金属不生不灭，所以厚 $t _ { 1 }$ 的未切层变成厚 $t _ { 2 }$ 的切屑，沿角度 $\phi$ 的剪切面上行。由剪切面切出的三角形的几何（刀具前角 $\alpha )$ ，

$$
t _ { 1 } = l _ { c } \sin \phi , \qquad t _ { 2 } = l _ { c } \cos ( \phi - \alpha ) \qquad \Longrightarrow \qquad r = { \frac { t _ { 1 } } { t _ { 2 } } } = { \frac { \sin \phi } { \cos ( \phi - \alpha ) } }
$$

交叉相乘、展开 $\cos ( \phi - \alpha )$ 、再除以 $\cos \phi$ 得

$$
r ( \cos \phi \cos \alpha + \sin \phi \sin \alpha ) \; = \; \sin \phi \; \Longrightarrow \; r ( \cos \alpha + \tan \phi \sin \alpha ) \; = \; \tan \phi \; \Longrightarrow \; \tan \phi \; = \; { \frac { r \cos \alpha } { 1 - r \sin \alpha } }
$$

摩擦方面，把测得的力分解到刀具前刀面上：$F _ { c }$ 沿切削方向、$F _ { t }$ 垂直于已加工表面（把刀推离工件），则前角为 $\alpha$ 的前刀面上的摩擦力和法向力是 $F = F _ { c } \sin \alpha + F _ { t } \cos \alpha$ 和 $N = F _ { c } \cos \alpha - F _ { t } \sin \alpha$ ，于是前刀面上的摩擦系数是

$$
\mu \; = \; { \frac { F } { N } } \; = \; { \frac { F _ { c } \tan \alpha + F _ { t } } { F _ { c } - F _ { t } \tan \alpha } } \; = \; \tan \beta
$$

而 **Merchant 关系** $2 \phi + \beta - \alpha \approx 9 0 ^ { \circ }$ ——在假定抗切强度 $\tau _ { s }$ 和摩擦角 $\beta$ 都与 $\phi$ 无关的前提下，取使切削力最小的 $\phi$ 推出——说的是剪切面停在材料自身抗切强度与刀具摩擦相平衡之处。它不精确——有时与实测差几度，常常差得多，现代做法是测量 $\phi$ 和 $\mu$ 并用测量值——但它就是切削刀具前角这样选的原因：**更大的 $\alpha$ 抬高 $\phi$ ，剪切面变短，剪切应变、力和功率随之下降，这就是为什么铝用 $2 0 ^ { \circ }$ 正前角切、淬硬钢用 $6 ^ { \circ }$ 负前角切——负前角让脆的刃口有强度活下来。**
:::

::: example 一次实测的正交切削 {#ex-merchant level=3 check="34.0"}
铝合金正交车削，$\alpha = 1 0 ^ { \circ }$ ，宽 $5 \ \mathrm { m m }$ ，未切厚度 $0 . 5 \ \mathrm { m m }$ ，测得 $F _ { c } = 1 1 7 7 \ \mathrm { N }$ ，$F _ { t } = 5 6 8 \ \mathrm { N }$ ，长度比 $l _ { 1 } / l _ { 2 } = 0 . 6 1 3$ （即 $r = 0 . 6 1 3 )$ ，$V = 1 0 0 \ \mathrm { m / m i n }$ 。

$$
\tan \phi = { \frac { 0 . 6 1 3 \cos 1 0 ^ { \circ } } { 1 - 0 . 6 1 3 \sin 1 0 ^ { \circ } } } = { \frac { 0 . 6 0 4 } { 0 . 8 9 4 } } = 0 . 6 7 6 \qquad \Longrightarrow \qquad \phi = { \bf 3 4 . 0 ^ { \circ } }
$$
$$
\mu = { \frac { 5 6 8 + 1 1 7 7 \tan 1 0 ^ { \circ } } { 1 1 7 7 - 5 6 8 \tan 1 0 ^ { \circ } } } = { \frac { 7 7 6 } { 1 0 7 7 } } = 0 . 7 2 \qquad ( \beta = 3 5 . 8 ^ { \circ } )
$$
$$
F _ { s } = 1 1 7 7 \cos 3 4 ^ { \circ } - 5 6 8 \sin 3 4 ^ { \circ } = 9 7 5 - 3 1 8 = 6 5 7 \ \mathrm { N } , \qquad A _ { s } = { \frac { 5 \times 0 . 5 } { \sin 3 4 ^ { \circ } } } = 4 . 4 7 \ \mathrm { m m ^ { 2 } }
$$
$$
\tau _ { s } = { \frac { 6 5 7 } { 4 . 4 7 } } = 1 4 7 \ \mathrm { M P a } , \qquad P = { \frac { F _ { c } V } { 6 0 } } = { \frac { 1 1 7 7 \times 1 0 0 } { 6 0 } } = 1 . 9 6 \ \mathrm { k W } , \qquad u = { \frac { 1 9 6 2 } { 4 1 6 7 \ \mathrm { m m ^ { 3 } / s } } } = 0 . 4 7 \ \mathrm { J / m m ^ { 3 } }
$$

**拿物理校核这两个数。**Merchant 关系给出 $2 \phi + \beta - \alpha = 6 8 . 1 + 3 5 . 8 - 1 0 = 9 3 . 9 ^ { \circ }$ ，距预言的 $9 0 ^ { \circ }$ 在 $4 ^ { \circ }$ 之内——理论管用。比能 $0 . 4 7 \ \mathrm { J / m m ^ { 3 } }$ 恰是铝的手册值（ $0 . 4 { - } 0 . 7 \ \mathrm { J / m m ^ { 3 } }$ ，钢是 $2 { - } 3 . 5$ ，铸铁 2.5），而 $1 4 7 \ \mathrm { M P a }$ 的切应力，对一种被大应变强化的铝合金来说是合理的剪切流动应力。**功率这个数要记在脑子里：以重载率切削铝要两千瓦——而磨钢（第 3 节）每立方毫米的能量约是它的五十倍。**
:::

## 2. 热、刀具寿命与刀具

::: definition 热去了哪里，刀具为什么死 {#def-heat}
大约**切削功的 60-75 % 变成切屑里的热，15-25 % 进入工件，5-20 % 进入刀具**——分配由切屑的速度和导热率决定，这就是为什么切削铝（一台会走路的散热器）是凉的，而切削钛（切屑带着热离开）不是。到达刀具的热几乎全部落在前刀面刃后一粒沙大小的点上： 新切出的、化学上饥渴的、$6 0 0 { - } 9 0 0 \ \mathrm { ^ { \circ } C }$ 的切屑底面，以 $2 { - } 4 \ \mathrm { G P a }$ 的接触压力在涂层硬质合金上以 $1 { - } 3 \ \mathrm { m / s }$ 滑过。**刀具磨损就是这个界面**，机理有五种，永远组合出现：

$$
\begin{array} { l l l l }
\textbf{机理} & \textbf{位置} & \textbf{条件} & \textbf{防御} \\ \hline
\text{磨粒磨损} & \text{后刀面、月牙洼} & \text{硬颗粒（碳化物、氧化物、铸件表皮里的砂）} & \text{更硬的刀具、倒棱刃口} \\
\text{黏结} & \text{前刀面} & T > 3 0 0 \ \mathrm { ^ { \circ } C } 、 \text{亲和力} & \text{惰性涂层（Al}_2\text{O}_3\text{）、前角、冷却} \\
\text{扩散} & \text{月牙洼} & T > 7 0 0 \ \mathrm { ^ \circ C } 、 \text{互溶度} & \text{金刚石不切钢（碳亲和力）} \\
\text{氧化} & \text{两个刀面} & T > 5 0 0 \ \mathrm { ^ \circ C } 、 \text{氧} & \text{抗氧化涂层} \\
\text{塑性流动} & \text{刃口} & \text{高温高压使刃口软化} & \text{压应力涂层、厚牌号} \\
\text{断裂、崩刃} & \text{刃口、刀尖} & \text{冲击、颤振、断续切削} & \text{更韧的牌号、刃口钝化、平缓切入}
\end{array}
$$

**刀具寿命方程**是把这一切组织起来的经验定律——**泰勒** $V T ^ { n } = C$ ，$V$ 以 m/min 计，$T$ 是切到规定磨损的分钟数（约定精加工后刀面磨损 $0 . 3 \ \mathrm { m m }$ ，粗加工 $0 . 6 \ \mathrm { m m }$ ），$n$ 是斜率，$C$ 是一分钟寿命时的速度：

$$
V T ^ { n } = C \qquad \Longleftrightarrow \qquad { \frac { T _ { 2 } } { T _ { 1 } } } = \left( { \frac { V _ { 1 } } { V _ { 2 } } } \right) ^ { 1 / n } \qquad \Longrightarrow \qquad n = { \frac { \log V _ { 2 } - \log V _ { 1 } } { \log T _ { 1 } - \log T _ { 2 } } }
$$

$$
\begin{array} { l c c c c c }
& \text{高速钢} & \text{硬质合金} & \text{金属陶瓷} & \text{陶瓷} & \text{PCBN / 金刚石} \\
n & 0 . 0 8 { - } 0 . 1 5 & 0 . 2 0 { - } 0 . 3 5 & 0 . 3 { - } 0 . 4 & 0 . 4 { - } 0 . 6 & 0 . 5 { - } 0 . 9 \\
\text{可用界面温度} & 6 0 0 \ \mathrm { ^ \circ C } & 9 0 0 \ \mathrm { ^ \circ C } & 1 0 0 0 \ \mathrm { ^ \circ C } & 1 2 0 0 \ \mathrm { ^ \circ C } & 1 3 0 0 { - } 1 5 0 0 \ \mathrm { ^ \circ C } \\
\text{钢上典型 } V & 2 5 { - } 4 0 \ \mathrm { m / m i n } & 1 5 0 { - } 3 0 0 & 2 0 0 { - } 3 5 0 & 3 0 0 { - } 6 0 0 & 1 0 0 { - } 2 0 0 \text{（硬车）}
\end{array}
$$

**指数就是全部的故事。**$n = 0 . 2 5$ 时，速度翻倍赔掉 $2 ^ { 4 } = 1 6$ 倍寿命；$n = 0 . 6$ （陶瓷）只赔 $2 ^ { 1 . 7 } = 3 . 2$ 倍。**这就是为什么切削速度的历史是刀具材料的历史，为什么一个车间从 150 m/min 改跑 300 m/min 的决定不是关于刀具的决定而是关于 $n$ 的决定，因而取决于刀片是涂层硬质合金、金属陶瓷还是陶瓷。**进给比速度便宜，切深最便宜——取硬质合金切钢典型指数的扩展泰勒关系 $V T ^ { 0 . 2 5 } f ^ { 0 . 6 } a _ { p } ^ { 0 . 3 } = C$ 说，进给增 $25 \ \ \%$ 花的寿命等于速度增 $14 \ \ \%$ （ $1 . 2 5 ^ { 0 . 6 } = 1 . 1 4$ ），而去除率提高的是 $25 \ \ \%$ 而不是 $14 \ \ \%$ ，这就是为什么车间要多去金属时第一个加的是进给、最后加的才是速度。

**切削液**干四件事（冷却、润滑刀-屑界面、冲屑、保护表面），花三样钱（零件成本的 5-15 %：购置、油槽、过滤、油雾回收和废液处理；健康与滑倒隐患；以及切削液劣化时的废品质量问题）。自 1990 年代以来行业的回答是能去掉就去掉——**干切削**（抛光前刀面加刀片热障涂层）、**微量润滑 MQL**（每小时 $2 { - } 1 0 0 \ \mathrm { m l }$ 酯类喷成细雾精确打在楔区，以 $1 \ \ \%$ 的用量干完润滑的活），以及需要强行排屑的内孔用高压刀具内吹气或 $\mathrm { C O } _ { 2 }$ 。**活下来的经验法则：低速切延性材料（积屑瘤是问题时）和铸铁（粉尘是问题时）切削液帮助最大；高速硬质合金切钢时帮助最小，此时满溢水柱的热循环比热本身更是刀片开裂的原因。**
:::

::: proof 最便宜的速度，与产量最高的速度 {#proof-tayloropt}
固定一刀的每件切削时间是 $t _ { m } = A / V$ ，刀具寿命是 $T = ( C / V ) ^ { 1 / n }$ ，所以每件消耗的刀具数是 $t _ { m } / T$ 。若 $t _ { i }$ 是每次换刀损失的时间（换刀加转位），$t _ { c }$ 是工件装卸时间，每件生产时间是

$$
T _ { p } ( V ) \; = \; { \frac { A } { V } } + t _ { c } + t _ { i } \, { \frac { A / V } { ( C / V ) ^ { 1 / n } } }
$$

对 $V$ 求导并令其为零，

$$
- \, { \frac { A } { V ^ { 2 } } } + { \frac { t _ { i } A } { C ^ { 1 / n } } } \left( \frac { 1 } { n } - 1 \right) V ^ { 1 / n - 2 } = 0 \qquad \Longrightarrow \qquad V ^ { 1 / n } = C ^ { 1 / n } \, { \frac { n } { t _ { i } ( 1 - n ) } }
$$

回代到刀具寿命，

$$
\boxed { \; T _ { \text{最优} } \; = \; t _ { i } \left( { \frac { 1 } { n } } - 1 \right) \; \Longleftrightarrow \; V _ { \text{最优} } = { \frac { C } { T _ { \text{最优} } ^ { n } } } \; }
$$

**这个结果里有两件事比代数更值钱。**第一，**最优刀具寿命是换刀时间的倍数，倍数是 $1 / n - 1$** ：硬质合金（ $n = 0 . 2 5 )$ 是 3，高速钢（ $n = 0 . 1 )$ 是 9，陶瓷（ $n = 0 . 5 )$ 是 1。**硬、脆、耐磨、高 $n$ 的刀具应该用短寿命；软、韧、便宜、低 $n$ 的刀具应该用长寿命。**这违反直觉，这就是为什么刀具供应商推荐的速度通常保守。第二，**求最低成本而非最高产量时，把 $t _ { i }$ 换成 $t _ { i } + C _ { t } / M$ ，$C _ { t }$ 是每刃刀具成本、$M$ 是每分钟机时费率**——刀具成本以等效时间的形式进入，最优寿命变长为 $T = ( 1 / n - 1 ) ( t _ { i } + C _ { t } / M )$ 。**一个切削刃相对一分钟机时越贵，每个刃就该用得越久。**
:::

::: example 该跑的速度 {#ex-toollife level=3 check="190"}
硬质合金车软钢轴：$n = 0 . 2 5$ ，$C = 2 5 0 \ \mathrm { m / m i n }$ ，换刀时间 $t _ { i } = 1 \ \mathrm { m i n }$ ，每个切削刃 6 英镑，机时 60 英镑/小时（1 英镑/分钟）。求最高产量和最低成本的切削速度。（输入最高产量速度，单位 m/min，取整到 10。）

$$
\text{最大生产率： } \; T _ { \text{最优} } = 1 \times ( 4 - 1 ) = 3 \ \mathrm { m i n } \qquad \Longrightarrow \qquad V = { \frac { 2 5 0 } { 3 ^ { 0 . 2 5 } } } = { \bf 1 9 0 \ m / m i n }
$$
$$
\text{最低成本： } \; t _ { \text{等效} } = 1 + { \frac { 6 } { 1 } } = 7 \ \mathrm { m i n } \qquad \Longrightarrow \qquad T _ { \text{最优} } = 7 \times 3 = 2 1 \ \mathrm { m i n } , \; V = { \frac { 2 5 0 } { 2 1 ^ { 0 . 2 5 } } } = 1 1 7 \ \mathrm { m / m i n }
$$

**机器是瓶颈、订单排满，就跑一百九十米一分钟；车间有富余产能、切削刃昂贵，就跑一百二十左右。**两个设定下的刀具寿命差七倍，每个切削刃去的金属（正比于 $V T$ ）差约四倍——这就是全部论据，也是为什么"我该跑什么速度"不是关于材料、刀具或工件的问题，而是关于工厂状态的问题。**还要注意两个最优的共性：都不是把刀具用到报废的速度，也不是目录上保守的速度。**
:::

## 3. 机床

::: definition 车削、镗削，以及一个尖点的运动学 {#def-turn}
车削是最古老最简单的工艺：工件转、刀具进给，扫出的面是回转面。全部算术是四个数：

$$
V = { \frac { \pi D N } { 1 0 0 0 } } \ [ \mathrm { m / m i n } ] , \qquad v _ { f } = f N \ [ \mathrm { m m / m i n } ] , \qquad
\mathrm { M R R } = a _ { p } \, f \, V \times 1 0 ^ { 3 } / 6 0 \ [ \mathrm { m m ^ { 3 } / s } ] , \qquad P = { \frac { F _ { c } V } { 6 0 \times 1 0 ^ { 3 } \eta } } \ [ \mathrm { k W } ]
$$

其中 $a _ { p }$ 是切深，$f$ 是每转进给，切削力由**比切削力**给出 $F _ { c } = k _ { c } a _ { p } f$ （钢 $k _ { c } \approx 1 { , } 5 0 0 { - } 3 { , } 0 0 0 \ \mathrm { N / m m ^ { 2 } }$ ，随切屑变厚而下降——第 1 节的尺寸效应）。车一个台阶的**机床时间**是 $t _ { m } = L / ( f N )$ 加引入和吃刀，它是报价工程师乘以机时费率的数字；**功率**是阻止他加快的东西。

建立在这一个尖点上的工艺就是整个"圆"的世界：**车端、镗孔**（刀具在里面，把镗杆的刚度换成刀系的刚度，这就是为什么内孔比外圆难保、超过 $3 \times$ 直径的孔需要防振镗杆）、**车螺纹**（单齿或多齿，梯形螺纹和滚珠丝杠用**旋风铣**）、**切断与切槽**、**网纹滚花**、**辊压光**（不是切削而是车床上做的成形工序，给出 $0 . 2 \ \mu \mathrm { m }$ 的 $R _ { a }$ 和压应力表面），以及带动力刀具的车床上的**车铣**——在同一次装夹里加工小平面、键槽和横孔，不必把零件搬到铣床上。

现代车床是**车削中心**：一个或两个刀塔、副主轴、动力刀具、棒料机、接料器——它擅长的是延性材料里每小时 20-200 件的轴对称零件。它的典型失效是**细长件**：$5 0 0 \times 2 0 \ \mathrm { m m }$ 的轴顶在两顶尖间，刀具在跨中时，哪怕 $1 0 0 \ \mathrm { N }$ 的径向力也使它挠曲 $F L ^ { 3 } / 4 8 E I \approx 0 . 1 7 \ \mathrm { m m }$ ，零件出来呈腰鼓形、带振纹，答案是一具中心架、更小的刀尖圆弧，或者换一个工艺。
:::

::: example 功率、力与机床时间账单 {#ex-power level=3 check="6.6"}
$6 0 \ \mathrm { m m }$ 直径钢轴车削 $a _ { p } = 3 \ \mathrm { m m }$ ，$f = 0 . 3 \ \mathrm { m m / r e v }$ ，$V = 2 0 0 \ \mathrm { m / m i n }$ ，$k _ { c } = 2 { , } 2 0 0 \ \mathrm { N / m m ^ { 2 } }$ ，主轴效率 $8 5 \ \ \%$ 。求刀尖处的切削功率、电机功率和机床时间。（输入刀尖处功率，单位 kW，保留一位小数。）

$$
F _ { c } = 2 2 0 0 \times 3 \times 0 . 3 = 1 9 8 0 \ \mathrm { N } , \qquad P _ { c } = { \frac { 1 9 8 0 \times 2 0 0 } { 6 0 \times 1 0 ^ { 3 } } } = { \bf 6 . 6 \ k W } \ \text{（刀尖处）} , \qquad P _ { \text{电机} } = { \frac { 6 . 6 } { 0 . 8 5 } } = 7 . 8 \ \mathrm { k W }
$$
$$
\mathrm { M R R } = { \frac { 3 \times 0 . 3 \times 2 0 0 \times 1 0 ^ { 3 } } { 6 0 } } = 3 { , } 0 0 0 \ \mathrm { m m ^ { 3 } / s } = 1 8 0 \ \mathrm { c m ^ { 3 } / m i n } , \qquad u = { \frac { 6 6 0 0 } { 3 0 0 0 } } = 2 . 2 \ \mathrm { J / m m ^ { 3 } }
$$

**一分钟一百八十立方厘米——每 2.7 秒一个 $2 0 \ \mathrm { m m }$ 的钢立方——电机花八千瓦。**看时间账单：沿 $6 0 \ \mathrm { m m }$ 轴的 $2 0 0 \ \mathrm { m m }$ 长度走这一刀需 $t _ { m } = 2 0 0 / ( 0 . 3 \times 1 0 6 1 ) = 0 . 6 3 \ \mathrm { m i n }$ （ $N = 1 0 0 0 \times 2 0 0 / ( \pi \times 6 0 ) = 1 { , } 0 6 1 \ \mathrm { r p m } )$ ，按每小时 60 英镑算切削 63 便士，装卸 30 便士，刀片 12 便士。**即使在这里、切削是最大的一项，1.05 英镑里也约有 40 % 根本不是切削；在多次装夹、尺寸短小的精加工件上，切削往往只占成本的少数**——这就是为什么砍切削成本最快的办法是改分模线、改基准或改批量，最慢的办法是买更快的主轴。
:::

::: definition 铣削，以及让它歌唱或尖叫的那个波 {#def-mill}
铣削是把车削的切削运动剁成 $z$ 段小弧——它所有的好与坏都由此而来。**顺（下）铣**中刀齿以满切屑厚度切入、工作台带着工件*顺着*刀具走：切屑形成干净、表面更好、刀具更久，而力把工件拉进切削——在有间隙的手动机床上危险，在预紧滚珠丝杠的数控机床上正常。**逆（传统）铣**让刀齿在加工硬化的表面上从零厚度开始、摩擦、把工件推离切削；它是老式手动铣床上唯一安全的选择，也是手铣表面比机铣表面难看的原因。

金属去除率和功率是

$$
\mathrm { M R R } = a _ { e } \, a _ { p } \, v _ { f } \ [ \mathrm { m m ^ { 3 } / m i n } ] , \qquad v _ { f } = f _ { z } \, z \, N , \qquad P = { \frac { u \ \mathrm { M R R } } { 6 \times 1 0 ^ { 4 } \, \eta } } \ [ \mathrm { k W } ] , \qquad F _ { z } = k _ { c } \, a _ { p } \, f _ { z } \\ \text{其中 } u \text{ 以 } \mathrm { J / m m ^ { 3 } } \text{ 计，} \eta \text{ 为主轴效率，} F _ { z } \text{ 为决定铣刀是否偏斜的齿载荷}
$$

而**刀齿通过频率** $f _ { t p } = N z / 6 0$ 是决定切削安静与否的数字。铣削（和车削、镗削一样）**即使刀具锋利、机器做工良好也可能不稳定**，因为刀具和主轴总有某个柔性振动模态：每个刀齿留下一条波状表面，下一个刀齿切掉那条波，若波的相位合适，切屑厚度的变化就喂养了造成它的振动。这就是**再生颤振**，它产生稳定性叶瓣图：对每个整数 $k = 0 , 1 , 2 , \dots$ （近似地）存在一个主轴转速

$$
N _ { k } \; \approx \; { \frac { 6 0 \, f _ { n } } { z \left( k + 1 \right) } }
$$

使得相邻两齿之间恰好容纳整数个振动波，前一齿留下的波与后一齿的振动同相，切屑厚度几乎不变，**稳定切深出现局部峰值**（实际上略高于 $N _ { k }$ ）。固有频率 $f _ { n } = 1 { , } 0 0 0 \ \mathrm { H z }$ 、$z = 4$ 的立铣刀，峰值位于约 15,000、7,500、5,000、3,750 和 $3 { , } 0 0 0 \ \mathrm { r p m}$ ——而在它们之间，比如 6,000 rpm，稳定切深可能只有峰值处的一小部分。**实用结论有三条：切削颤振时把速度改 15-20 % 而不是减切深；不等齿距（82°/88°/90°）的铣刀把叶瓣抹平，任何深槽都值得买一把；机器的"高速主轴"不是营销卖点而是稳定性工具，因为最高最宽的叶瓣位于刀齿通过频率接近 $f _ { n }$ 处，对刚性好的刀具这意味着很高的主轴转速。**

铣削的其余部分是刀具分类学：**面铣刀**（可转位，60-160 mm，平面度主力）、**立铣刀**（整体硬质合金，铝用 2-4 齿大螺旋角抛光刀槽，钢用 5-7 齿变齿距，精加工 8-12 齿）、**球头刀**（加工双曲率模具唯一像样的办法，行距决定残留高度）、**壳式立铣刀和模块化镗头**用于大平面、**键槽铣刀**、**成形刀**，以及**摆线刀路与自适应间隙刀路**——它们让径向切宽保持小而恒定（典型为刀具直径的 5-15 %，刃长全部参与切削），于是即使淬硬工具钢也能粗铣而不让任何一齿过载。
:::

::: example 粗铣型腔：主轴干得动吗 {#ex-mill level=3 check="8.9"}
软钢板上的 $2 0 0 \times 1 2 0 \ \mathrm { m m }$ 型腔用 $8 0 \ \mathrm { m m }$ 面铣刀粗铣，$z = 6$ ，$n = 1 { , } 5 0 0 \ \mathrm { r p m }$ ，$f _ { z } = 0 . 1 5 \ \mathrm { m m }$ ，$a _ { p } = 3 \ \mathrm { m m }$ ，切宽 $a _ { e } = 6 0 \ \mathrm { m m }$ ，$k _ { c } = 2 { , } 2 0 0 \ \mathrm { N / m m ^ { 2 } }$ （ $u = 2 . 2 \ \mathrm { J / m m ^ { 3 } }$ ），主轴效率 0.85。（输入切削处功率，单位 kW，保留一位小数。）

$$
v _ { f } = 0 . 1 5 \times 6 \times 1 5 0 0 = 1 { , } 3 5 0 \ \mathrm { m m / m i n } , \qquad \mathrm { M R R } = 6 0 \times 3 \times 1 3 5 0 = 2 4 3 { , } 0 0 0 \ \mathrm { m m ^ { 3 } / m i n } = 4 { , } 0 5 0 \ \mathrm { m m ^ { 3 } / s }
$$
$$
P = { \frac { u \times \mathrm { M R R } } { 6 \times 1 0 ^ { 4 } } } = { \frac { 2 . 2 \times 2 4 3 { , } 0 0 0 } { 6 0 { , } 0 0 0 } } = { \bf 8 . 9 \ k W } \quad \text{切削点 } ( \text{电机 } 1 0 . 5 \ \mathrm { k W } ， \eta = 0 . 8 5 ) , \qquad F _ { z } = 2 2 0 0 \times 3 \times 0 . 1 5 = 9 9 0 \ \mathrm { N }
$$

**九千瓦，在一台"15 kW"加工中心上看起来很宽裕——而 $2 0 0 \times 1 2 0 \times 3 0 \ \mathrm { m m }$ 的型腔、$7 2 0 \ \mathrm { c m ^ { 3 } }$ 的钢，只需 $7 2 0 { , } 0 0 0 / 2 4 3 { , } 0 0 0 = 3 . 0$ 分钟切削。**陷阱是机器的**低速扭矩**：一台在基速（比如 $3 { , } 0 0 0 \ \mathrm { r p m }$ ）以上额定 15 kW 的主轴，在基速以下受扭矩限制，所以 $1 { , } 5 0 0 \ \mathrm { r p m }$ 时只能给出 $7 . 5 \ \mathrm { k W }$ ——少于这一刀在电机端需要的 $1 0 . 5 \ \mathrm { k W }$ ——而 $6 0 0 \ \mathrm { r p m }$ 时只有 $3 \ \mathrm { k W }$ 。**永远要扭矩-转速曲线，永远别信峰值功率。**
:::

::: definition 钻削，以及工业界最烂的两毫米切削 {#def-drill}
麻花钻是两把单点刀由一条**横刃**连起来——而横刃的切削速度在钻头轴线处降到零、前角是很大的负值，几乎不切。它把金属向外**挤压**，约占一半的进给力（但只占扭矩的一小部分），让钻头跑偏，这就是为什么一个钻出的孔在别的任何事出错之前位置已经偏了 $\pm 0 . 2 \ \mathrm { m m }$ 。于是整套钻尖几何词汇：**修磨横刃**（118° 或 140° 钻尖磨横刃，让横刃剪切而不是挤压，进给力减半）、$2 0 \ \mathrm { m m }$ 以上孔用**可转位钻头换硬质合金刀片**、**枪钻**（单槽管状，内冷直达刀尖、切屑沿外侧排出，用于深达一百倍直径以上的孔）、**BTA 与喷射钻**（冷却液走环空、切屑从钻管内孔退回；用于轴、轧辊和管板上较大直径的长孔），以及数控上的**啄钻**（每 $0 . 5 { - } 2 \times$ 直径退一次断屑，花掉 30 % 节拍，而超过 $3 \times$ 直径的钢孔躲不掉）。

钻头的数字：$v _ { f } = f N$ ，$2 0 \ \mathrm { m m }$ 钻头在软钢上每转 $0 . 2 5 \ \mathrm { m m }$ 要几千牛的进给力和约 $3 0 \ \mathrm { N \, m }$ 的扭矩（ $M \approx k _ { c } f D ^ { 2 } / 8$ ），一半进给力被横刃吃掉，而**机床时间** $t _ { m } = ( L + \text{越程} ) / ( f N )$ 。钻削是低功率、高进给力、受排屑限制的工艺，失效模式是钻头折断（脆性、突然、在多轴头里昂贵）、孔偏，以及不锈钢和钛上毁掉后面铰刀的硬化涂抹入口边。
:::

::: definition 磨削，以及为什么有人肯花十倍能量 {#def-grind}
磨削是**几千个随机取向、负前角、边磨边钝的磨粒**的切削，每个磨粒切 $0 . 1 { - } 1 \ \mu \mathrm { m }$ 的屑，砂轮线速 $3 0 { - } 4 0 \ \mathrm { m / s }$ （高速磨削到 $1 0 0 \ \mathrm { m / s } )$ 。钢上比能 $u _ { g } = 2 0 { - } 5 0 \ \mathrm { J / m m ^ { 3 } }$ ，**是车削的十到二十倍**，原因是第 1 节的尺寸效应推到极限：$0 . 5 \ \mu \mathrm { m }$ 的切屑对上 $1 { - } 5 0 \ \mu \mathrm { m }$ 的磨粒半径，大部分能量是犁和挤，而这些能量大部分变成**工件里的**热，因为切屑太小带不走。

$$
P = F _ { t } \, v _ { s } , \qquad u _ { g } = { \frac { P } { \mathrm { M R R } } } , \qquad G = { \frac { \text{去除工件体积} } { \text{磨损砂轮体积} } }
$$

（陶瓷结合剂刚玉砂轮磨钢时 $G$ 约为 5-100，CBN 可达数千。）这堆热是磨削唯一的大问题。当**比功率** $P ^ { \prime } = P / b$ （每 mm 砂轮接触宽度的功率）超过一个取决于工件速度、切深和接触长度的极限（Malkin 烧伤判据；实践中对每种砂轮和工况靠试验确定）时，表面温度升到几百度，产生**烧伤**：回火色的氧化膜、重新奥氏体化再淬火的层、残余奥氏体，以及——昂贵的那个——深几十到几百微米、通常横跨磨削方向的**磨削裂纹**，零件上服役之前一直隐形。防御手段是砂轮自身的软（**软牌号**、**疏松组织**、**自锐**结合剂）、以正确压力送进接触弧的**冷却液**、**缓进给磨削**（切深达 $1 0 \ \mathrm { m m }$ 的深切、极慢的工件速度，靠软而疏松的砂轮和大量压入长接触弧的冷却液才做得到）、**高速 CBN 砂轮**（以切代犁），以及给砂轮**修整**露出新磨粒。

砂轮的代号是一句话：**磨料**（A = 刚玉切钢，C = 碳化硅切铸铁和碳化物，CBN 切淬硬钢，金刚石切硬质合金、陶瓷和玻璃）、**粒度**（46 粗到 1200 研磨）、**组织**（间距）、**硬度**（结合剂抓得多紧）、**结合剂**（陶瓷 V、树脂 B、金属 M、电镀 E）。磨削之所以存在，因为它是加工 65 HRC 轴承滚道、硬质合金刀片、陶瓷基板、磨到 $3 \ \mu \mathrm { m }$ 的螺纹和 $R _ { a } \ 0 . 2 \ \mu \mathrm { m }$ 的**唯一**办法——也因为温和的磨削能留下有利于疲劳寿命的残余压应力，而粗暴的磨削留下的残余拉应力则会毁掉它。
:::

$$
$$

$$

**五千瓦，一分钟去掉 $1 2 \ \mathrm { c m ^ { 3 } }$ 的钢——对比车削例题 $6 . 6 \ \mathrm { k W }$ 去 $1 8 0 \ \mathrm { c m ^ { 3 } / m i n }$ ：$0 . 4 2$ 对 $0 . 0 3 7 \ \mathrm { k W }$ 每立方厘米每分钟，磨削的单位体积能量贵十一倍。**再看烧伤裕度：$0 . 1 7 \ \mathrm { k W / m m }$ 这一刀是安全的，并且一直安全到砂轮**堵塞**（气孔被切屑糊住）为止——那时摩擦取代切削，切向力、因而功率和热量，能在几分钟内翻好几倍。**这就是为什么磨削同时用主轴功率和声发射监控，为什么磨过的曲轴上的烧伤是用硝酸酒精腐蚀零件、找黑斑找出来的，而不是用量具量的。**
:::

## 4. 切削留下了什么

::: definition 进给刀痕、光洁度阶梯与公差阶梯 {#def-finish}
车削表面的理论粗糙度由刀具几何决定，不由机器精度决定：进给 $f$ 、刀尖圆弧半径 $r _ { \varepsilon }$ 时，进给刀痕的峰谷高度是

$$
R _ { \max } \; = \; { \frac { f ^ { 2 } } { 8 \, r _ { \varepsilon } } } \qquad \Longrightarrow \qquad R _ { a } \approx { \frac { R _ { \max } } { 4 } } \approx { \frac { f ^ { 2 } } { 3 2 \, r _ { \varepsilon } } }
$$

这是制造业里设计师读完就忽略、然后自付代价的唯一公式。**$0 . 2 \ \mathrm { m m }$ 进加 $0 . 8 \ \mathrm { m m }$ 刀尖圆弧给出 $6 . 3 \ \mu \mathrm { m }$ 峰谷，约 $R _ { a } \ 1 . 6$ ；进给减半到 0.1 得 $R _ { a } \ 0 . 4$ ，正是多数图纸要的光洁度，这就是为什么机工在精刀上的第一招是更小的进给而不是更好的机床。**$R _ { a } \ 0 . 2$ 以下进给刀痕公式不再适用，因为表面由摩擦、积屑瘤、振动和机床导轨造成，工艺必须换：辊压光、珩磨、研磨、抛光。

$$
\begin{array} { l c c l c c }
\textbf{工艺} & \text{公差（典型）} & R _ { a } \ [ \mu \mathrm { m } ] & \textbf{工艺} & \text{公差} & R _ { a } \ [ \mu \mathrm { m } ] \\ \hline
\text{火焰 / 等离子切割} & \pm 1 { - } 3 \ \mathrm { m m } & 2 5 & \text{铰孔} & \pm 0 . 0 1 { - } 0 . 0 5 & 1 . 6 \\
\text{砂型铸造} & \pm 1 { - } 3 & 1 2 { - } 2 5 & \text{镗孔} & \pm 0 . 0 1 { - } 0 . 0 5 & 0 . 8 { - } 3 . 2 \\
\text{热锻} & \pm 0 . 3 { - } 1 & 6 { - } 1 2 & \text{精车} & \pm 0 . 0 1 { - } 0 . 0 3 & 0 . 4 { - } 1 . 6 \\
\text{轧制 / 挤压} & \pm 0 . 1 { - } 0 . 5 & 1 . 6 { - } 6 & \text{精铣} & \pm 0 . 0 2 { - } 0 . 0 5 & 0 . 8 { - } 1 . 6 \\
\text{钻孔} & \pm 0 . 1 { - } 0 . 5 & 3 . 2 { - } 1 2 & \text{磨削} & \pm 0 . 0 0 2 { - } 0 . 0 1 & 0 . 2 { - } 0 . 8 \\
\text{粗铣 / 粗车} & \pm 0 . 0 5 { - } 0 . 2 & 3 . 2 { - } 1 2 & \text{珩磨} & \pm 0 . 0 0 2 { - } 0 . 0 0 5 & 0 . 0 5 { - } 0 . 4 \\
\text{钻加铰} & \pm 0 . 0 2 { - } 0 . 0 5 & 1 . 6 { - } 3 . 2 & \text{研磨} & \pm 0 . 0 0 0 5 { - } 0 . 0 0 2 & 0 . 0 1 { - } 0 . 1
\end{array}
$$

**把两道阶梯放在一起读，出来一句话：公差和粗糙度用同一种货币购买，而 $\pm 0 . 0 1 \ \mathrm { m m }$ 和 $R _ { a } \ 0 . 4$ 以下汇率残酷。**阶梯还说了另一件事：**工艺是一个序列，不是一个选择**：一个孔先钻、再镗、再铰、再珩，每一步的存在都是为了纠正上一步的误差、并留下下一步切得动的余量。在 $4 0 \ \mathrm { m m }$ 厚法兰上标 $\pm 0 . 0 1 \ \mathrm { m m }$ 、$R _ { a } \ 0 . 4$ 孔的设计师，标的是四台机器加一套能让零件以同一基准面对四台机器的夹具——而夹具比切削贵。
:::

::: example 选进给 {#ex-finish level=3 check="0.18"}
车一个内孔要用 $1 . 2 \ \mathrm { m m }$ 刀尖圆弧保 $R _ { \max } \leq 3 . 2 \ \mu \mathrm { m }$ 。进给多少，花多少时间？（输入进给量，单位 mm/rev，保留两位小数。）

$$
f \; = \; { \sqrt { 8 \, r _ { \varepsilon } \, R _ { \max } } } \; = \; { \sqrt { 8 \times 1 . 2 \times 0 . 0 0 3 2 } } \; = \; { \sqrt { 0 . 0 3 0 7 } } \; = \; { \bf 0 . 1 8 \ m m / r e v }
$$

**对比同一把刀粗车用的 $0 . 3 5 \ \mathrm { m m }$ ，精刀同样面积花 1.9 倍时间**——注意买光洁度的*另一*条路是更大的刀尖圆弧，时间上免费，但赔上颤振风险，因为更大的圆弧会加大细长杆上的径向力。**量产件上通常的答案是修光刃（wiper）刀片：刀尖后面一小段平刃把进给痕抹平，在同样光洁度下进给约可达普通刀片的两倍。**
:::

## 5. 当切屑是错误的刀具

::: definition 特种加工，以及它们为什么存在 {#def-nconv}
这些工艺中的每一个都因为三句话中的一句而存在：**"材料比任何刀具都硬"**、**"形状没有刀具入口"**、或者**"力会把工件顶弯"**。

$$
\begin{array} { l l l l l l }
\textbf{工艺} & \textbf{机理} & \textbf{材料限制} & \textbf{公差} & R _ { a } \ [\mu\mathrm { m } ] & \textbf{MRR} \\ \hline
\text{电火花成形加工} & \text{千万次火花熔化并抛出} & \text{任何导体} & \pm 0 . 0 0 5 \ \mathrm { m m } & 0 . 2 { - } 1 . 5 & 5 { - } 5 0 0 \ \mathrm { m m ^ { 3 } / m i n } \\
\text{线切割} & \text{行进的 } 0 . 1 { - } 0 . 4 \ \mathrm { m m } \text{ 黄铜丝} & \text{任何导体} & \pm 0 . 0 0 2 \ \mathrm { m m } & 0 . 1 { - } 0 . 4 & \text{切缝 } 0 . 2 5 \ \mathrm { m m } \\
\text{电解加工} & \text{阳极溶解} & \text{任何导体} & \pm 0 . 0 5 \ \mathrm { m m } & 0 . 4 { - } 1 . 6 & 1 0 0 { - } 5 { , } 0 0 0 \ \mathrm { m m ^ { 3 } / m i n } \\
\text{激光切割} & \text{用 } \mathrm { N } _ { 2 } \text{ 或 } \mathrm { O } _ { 2 } \text{ 熔化吹除} & \text{几乎任何} & \pm 0 . 0 5 \ \mathrm { m m } & 6 { - } 2 5 & \text{受板厚限制} \\
\text{水刀 / 磨料射流} & \text{300-400 MPa 冲蚀} & \text{任何} & \pm 0 . 1 \ \mathrm { m m } & 3 { - } 1 2 & \text{慢，冷} \\
\text{电子束} & \text{真空，} 6 0 { - } 1 5 0 \ \mathrm { k V } \text{ 电子} & \text{几乎任何} & \pm 0 . 0 5 & 3 & \text{深而窄} \\
\text{化学铣切} & \text{透过掩模腐蚀} & \text{板材，化学上} & \pm 0 . 0 5 \ \mathrm { m m } & 1 . 6 { - } 3 . 2 & \text{完全没有力} \\
\text{超声加工} & \text{悬浮液，} 2 0 \ \mathrm { k H z } \text{ 工具} & \text{玻璃、陶瓷、石材} & \pm 0 . 0 2 & 0 . 4 & \text{极慢}
\end{array}
$$

**电火花加工**是每个工程师必须懂的那个，因为它是做模具的工艺。电极（石墨、铜或铜钨）在去离子水或油的介质液流中被送向工件；间隙缩到 $1 0 { - } 5 0 \ \mu \mathrm { m }$ 时电场击穿介质，通道形成，等离子体达到 $1 0 { , } 0 0 0 \ \mathrm { K }$ ，一个熔化金属的小坑被炸走；介质冲走碎屑，并在下一个 $0 . 5 { - } 3 0 0 \ \mu \mathrm { s }$ 、$5 { - } 1 0 0 \ \mathrm { A }$ 的脉冲之前恢复绝缘。**什么都不碰什么，工件硬度无关紧要——65 HRC 的模腔和软钢一样好加工——而电极以去除体积的 0.5-5 % 磨损，这就是为什么电极要被设计、加工、像刀具一样付钱。**代价是 $1 { - } 1 0 \ \mu \mathrm { m }$ 深、必须为疲劳关键件去除的**重铸层**（再凝固的微裂纹金属）、一个**热影响区**、线上的一段**锥度**（丝在液流中的偏移造成，靠摆头修正），以及一张**麻点场般的表面**，其 $R _ { a }$ 随脉冲能量下降而改善、去除率也随之下降。**线切割**尤其已从模具车间工艺变成主要生产工序：涡轮叶片平台、定子叠片、手术器械，以及任何会毁掉冲头的高温合金通孔轮廓件。
:::

::: example 淬硬工具钢里的一个 40 mm 深腔 {#ex-edm level=3 check="16.0"}
需要在 60 HRC 的 1.2344 工具钢里做一个 $1 2 0 \times 8 0 \times 4 0 \ \mathrm { m m }$ 深、内圆角 $5 \ \mathrm { m m }$ 的腔，用于一副只做 30 件的模具。比较硬铣和电火花成形加工。（输入硬铣粗加工时间，单位 h，保留一位小数。）

**铣削**在硬度和圆角上都有问题：用 $1 0 \ \mathrm { m m }$ 刀具以 $a _ { p } = 0 . 2 \ \mathrm { m m }$ 、$a _ { e } = 5 \ \mathrm { m m }$ 、$v _ { f } = 4 0 0 \ \mathrm { m m / m i n }$ 硬铣 $6 0 \ \mathrm { H R C }$ 钢，去除率为 $0 . 2 \times 5 \times 4 0 0 = 4 0 0 \ \mathrm { m m ^ { 3 } / m i n }$ ，所以 $1 2 0 \times 8 0 \times 4 0 = 3 8 4 { , } 0 0 0 \ \mathrm { m m ^ { 3 } }$ 的腔是 $9 6 0 \ \mathrm { m i n } = { \bf 1 6 . 0 \ h }$ 每小时 150 英镑的五轴——还没算精加工；而 $5 \ \mathrm { m m }$ 圆角迫使直径不超过 $1 0 \ \mathrm { m m }$ 的刀具伸到 $4 0 \ \mathrm { m m }$ 深——$4 \times$ 直径的悬伸，在淬硬钢里易颤振。**电火花成形加工**用加工出来的石墨电极，这个尺寸下粗规格去除率约 $4 0 0 \ \mathrm { m m ^ { 3 } / m i n }$ ，所以腔要约 $1 6 \ \mathrm { h }$ 粗加工加 $3 \ \mathrm { h }$ 精修火花，在每小时 80 英镑、可无人值守的机器上，**完全没有圆角问题**——电极上直接就有那个圆角——外加 $5 \ \mathrm { h }$ 做电极。**线切割**做不出盲腔，但同一副模具上的通轮廓它能在约两小时里粗精一次切完，$\pm 0 . 0 0 3 \ \mathrm { m m }$ 。

$$
\text{电火花路线： } \; 1 9 \ \mathrm { h } \times \pounds 8 0 + 5 \ \mathrm { h } \times \pounds 6 0 + \pounds 1 4 0 \ \text{石墨} = \pounds 1 { , } 9 6 0 \qquad \text{对比硬铣： } \; 1 8 \ \mathrm { h } \times \pounds 1 5 0 + \pounds 4 0 0 \ \text{刀具} = \pounds 3 { , } 1 0 0
$$

**而且电火花的模具本身更好：角上没有刀痕、没有振纹，模具抛光工一小时而不是一天就能抛成镜面。** **30 件无关紧要——这是模具不是产品——这正是要点：电火花的经济性由材料硬度和形状难度决定，与数量完全无关。**（实际上模具工还会在淬火前、在软的退火钢里把型腔粗加工出来，只留零点几毫米给电火花或硬铣，这会把两条路线的时间都缩短好几倍。）
:::

## 6. 切削加工是干什么用的

::: definition 工艺地图中的切削加工 {#def-econ}
切削加工的四种能力与四种代价，并排放着：

$$
\begin{array} { l l }
\textbf{能力} & \textbf{代价} \\ \hline
\text{刀具够得着的任何几何，包括凹陷和内腔} & \text{buy-to-fly 2-10：切屑按车间产品价格付了钱} \\
\text{任何材料，包括别的工艺切不动的} & \text{每去除材料 } 0 . 4 { - } 5 0 \ \mathrm { J / m m ^ { 3 } } \text{，大多变成热} \\
\text{公差到 } \pm 1 \ \mu \mathrm { m } \text{、} R _ { a } \ 0 . 0 1 \ \mu \mathrm { m } \text{（恒温恒尘室里研磨）} & \text{工装近乎为零，但夹具和计量不是} \\
\text{无零件专用工装：周一来图纸，周二出零件} & \text{表面是一层剪切过、硬化过、热改变过的表皮}
\end{array}
$$

**切削件的成本**是

$$
c \; = \; \underbrace { m _ { 0 } ( 1 + s ) } _ { \text{坯料，含损耗} } \; + \; \underbrace { M _ { w } \, t _ { m } } _ { \text{机床时间} } \; + \; \underbrace { M _ { w } \, t _ { \text{装调} } / N } _ { \text{装调，摊销} } \; + \; \underbrace { C _ { t } \, t _ { m } / T _ { \text{刀具}} } _ { \text{刀具} } \; + \; \underbrace { C _ { \text{切削液}} + C _ { \text{切屑}} } _ { \text{耗材} } \; + \; \underbrace { C _ { \text{检验}} } _ { \text{质量} }
$$

它的结构就是行业行为如此的原因：**机床时间占主导，机床时间几乎正比于去除体积除以 MRR，而去除体积是设计师做的决定。**三个杠杆按效力排序：(1) 买或成形近净坯料，让要去的更少；(2) 把所有特征放进一次装夹，让零件在一台机床时间里而不是三台里加工完；(3) 然后、而且只有然后，优化切削。**更快的主轴只缩短机床时间里切削的那一部分；近净形坯料则把切削本身省掉。**

最后那句话是整课铺垫到这里的。**切削加工是当公差、材料、几何或数量把其他一切排除之后你使用的工艺。**它是制造金属零件最灵活、最精确、最普适、也最浪费的方式，而把它当默认选项的设计，是一个没有问过其他七个工艺能做什么的设计。
:::

::: exercise 精加工进给 {#ex-feedfin level=2 check="0.14"}

::: exercise 推导剪切面角关系 {#ex-deriveshear level=4 check="29.0"}
由 $t _ { 1 } = l _ { c } \sin \phi$ 和 $t _ { 2 } = l _ { c } \cos ( \phi - \alpha )$ ，推导 $\tan \phi = r \cos \alpha / ( 1 - r \sin \alpha )$ 并对 $r = 0 . 5$ 、$\alpha = 1 5 ^ { \circ }$ 求值。（以度输入，保留一位小数。）
::: solution
$r = \sin \phi / \cos ( \phi - \alpha ) = \sin \phi / ( \cos \phi \cos \alpha + \sin \phi \sin \alpha )$ 。取倒数、除以 $\cos \phi$ ：
$$
{ \frac { 1 } { r } } \; = \; { \frac { \cos \phi \cos \alpha + \sin \phi \sin \alpha } { \sin \phi } } \; = \; \cos \alpha \cot \phi + \sin \alpha \qquad \Longrightarrow \qquad \tan \phi = { \frac { r \cos \alpha } { 1 - r \sin \alpha } } = { \frac { 0 . 4 8 3 } { 0 . 8 7 1 } } = 0 . 5 5 5
$$
所以 $\phi = { \bf 2 9 . 0 ^ { \circ } }$ 。 **注意两个极限：$\alpha = 0$ 时 $\phi = \arctan r$ ；$\alpha$ 升向 $\phi$ 时剪切面转动、应变下降——这就是正前角切得更省力的全部原因，直到刃口弱得活不过切削。**
:::

::: exercise 推导成本最优刀具寿命 {#ex-derivecost level=4 check="24"}
求每件最低成本而非最高产量时，$T _ { \text{最优} } = t _ { i } ( 1 / n - 1 )$ 中的换刀时间 $t _ { i }$ 换成 $t _ { i } + C _ { t } / M$ ，$C _ { t }$ 是每刃刀具成本、$M$ 是每分钟机时费率。求 $n = 0 . 2 5$ 、$t _ { i } = 2 \ \mathrm { m i n }$ 、$C _ { t } = \pounds 6$ 、$M = \pounds 1 / \mathrm { m i n }$ 的成本最优刀具寿命，并说明这一替换从何而来。（输入刀具寿命，单位分钟。）
::: solution
每件成本是 $M ( A / V + t _ { c } ) + ( M t _ { i } + C _ { t } ) ( A / V ) / T$ ：每次换刀的代价是损失的机时加上刀刃本身，除以 $M$ 后一次换刀"花费" $t _ { i } + C _ { t } / M$ 分钟，产量最优的推导以这个时间原样成立。这里 $t _ { \text{等效} } = 2 + 6 / 1 = 8 \ \mathrm { m i n }$ ，所以 $T _ { \text{最优} } = 8 \times 3 = { \bf 2 4 \ m i n }$ 。 **是产量最优寿命 6 min 的四倍：当刀具相对机时昂贵时，机器等刀具的时间远少于会计等刀具账单的时间。两个最优夹住每个真实车间的工作点，说不出自己在括号哪一端的车间，是在按习惯运转。**
:::
:::

::: quiz 为什么数控机床上首选顺铣？ {#quiz-climb}
- [ ] 因为它产生更长的切屑
- [x] 因为切屑不经摩擦就形成，表面、刀具寿命和加工硬化全都改善
- [ ] 因为它需要更少主轴功率
- [ ] 因为工件松脱时它更安全
::: solution
**逆铣中刀齿以零厚度切入、摩擦到咬住，这一摩擦磨出硬化表皮、烧伤后刀面、留下更差的表面。** **顺铣从满厚度开始；力还把工件压向工作台而不是抬起。功率基本相同，安全性更差——丝杠有间隙时顺铣会把工作台和工件一起拽过切削，这正是手动机床逆铣、而数控机床（预紧丝杠、夹紧工作台）顺铣的原因。**
:::

::: quiz 一个磨过的零件出现回火色，磁粉探伤不合格。发生了什么？ {#quiz-burn}
- [ ] 砂轮太软
- [ ] 冷却液浓度太高
- [x] 单位宽度功率超过烧伤阈值，表面再硬化并开裂
- [ ] 工件速度太低，把接触弧冷却了
::: solution
**烧伤是热失效：功率数 $P ^ { \prime } = P / b ^ { \prime }$ 升过砂轮阈值——因为砂轮堵塞、该修没修、或进给被硬推——表面达到奥氏体化区间，被冷却液淬成脆的、易裂的未回火马氏体，其下带有磨削裂纹。** **更软的砂轮、更松的组织、更锐的修整、对准接触弧的喷嘴、更低的进给都能减轻；更低的工件速度让事情更糟而不是更好，因为它拉长了单位面积的接触时间。**
:::

::: summary
**切屑是一个剪切面，不是一刀。**金属沿 $2 0 { - } 3 5 ^ { \circ }$ 的面剪切；$\tan \phi = r \cos \alpha / ( 1 - r \sin \alpha )$ ；面上的切应力高于慢速试验的抗切强度，因为应变约为 $200 \ \ \%$ 、速率达 $1 0 ^ { 3 } { - } 1 0 ^ { 6 } \ \mathrm { s ^ { - 1 } }$ ；而切屑形态——带状、积屑瘤、粒状、锯齿——是材料、速度和温度的诊断书。
**功率是比能乘去除率。**钢花 $2 { - } 3 . 5 \ \mathrm { J / m m ^ { 3 } }$ ，铝 $0 . 4 { - } 0 . 7$ ，铸铁 2.5，磨削 20-50——车削的十倍，因为 $0 . 5 \ \mu \mathrm { m }$ 的切屑对上 $2 0 \ \mu \mathrm { m }$ 的磨粒半径是犁而不是切。低于最小切屑厚度，什么都不被切。
**刀具寿命是 $V T ^ { n } = C$ ，指数是材料的传记。**速度翻倍赔 $2 ^ { 1 / n }$ 倍寿命：硬质合金十六倍，陶瓷三倍。最优是产量取 $T = t _ { i } ( 1 / n - 1 )$ ，成本取更长——高 $n$ 的硬刀该用短寿命，除了算术没人不惊讶。
**刀具材料是硬度换韧性，涂层是两头都要的办法。**高速钢 $6 0 0 \ \mathrm { ^ { \circ } C }$ ，硬质合金 $9 0 0 \ \mathrm { ^ \circ C }$ ，陶瓷 $1 2 0 0 \ \mathrm { ^ { \circ } C }$ ，CBN $1 4 0 0 \ \mathrm { ^ { \circ } C }$ ；几微米的 TiN、TiAlN 或氧化铝涂层能换来可观的速度提升，而金刚石不能用来切钢。
**铣削的极限是颤振，颤振是相位问题。**$f _ { t p } = N z / 6 0$ 对刀具固有频率，稳定性叶瓣在 $N _ { k } \approx 6 0 f _ { n } / z ( k + 1 )$ 附近，三个对策：速度挪 15-20 %，不等齿距，更多静刚度。绝不在叶瓣内部"再慢点"。
**粗糙度和公差是一道阶梯。**$R _ { \max } = f ^ { 2 } / 8 r _ { \varepsilon }$ 定下进给和刀尖圆弧能给的光洁度；$\pm 0 . 0 1 \ \mathrm { m m }$ 和 $R _ { a } \ 0 . 4$ 以下工艺必须换成磨、珩、研，每一步都增加时间和成本。
**切削加工是灵活、精确、普适、浪费的最后手段。**它的成本由机床时间主导，机床时间由去除体积主导，而去除体积由设计师而不是机工决定。买更快的主轴之前，先买近净坯料。
:::

## 延伸阅读

- M. C. Shaw, *Metal Cutting Principles*, 2nd ed., Oxford University Press, 2005 —— 第 1 节的力学，附带多数教材不敢尝试的、对什么还不被理解的坦诚。
- E. M. Trent and P. K. Wright, *Metal Cutting*, 4th ed., Butterworth-Heinemann, 2000 —— 基于金相证据讲切屑形成、刀–屑界面、刀具磨损和刀具材料。
- S. Kalpakjian and S. R. Schmid, *Manufacturing Engineering and Technology*, 7th ed., Pearson, 2014 —— 对工科学生讲第 2 到第 5 节最清楚的教材。
- Y. Altintas, *Manufacturing Automation: Metal Cutting Mechanics, Machine Tool Vibrations, and CNC Design*, 2nd ed., Cambridge University Press, 2012 —— 切削力、再生颤振和稳定性叶瓣图，讲得严谨。
- S. Malkin and C. Guo, *Grinding Technology: Theory and Applications of Machining with Abrasives*, 2nd ed., Industrial Press, 2008 —— 第 3 节的磨削能量、温度和烧伤极限。
- *Machinery's Handbook*（Industrial Press，定期修订）—— 进给与速度数据、公差表和钻尖几何，也是多数车间书架上的那本书。
