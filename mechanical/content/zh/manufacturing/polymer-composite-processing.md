聚合物是地球上用量最大的工程材料，也是机械工程师最不了解的材料，因为他们学过的关于金属的一切，在聚合物物理的第一句话起就不再成立。**聚合物零件不是铸出来、锻出来或加工出来的：它是在 1000 个大气压的压力下、在比任何金属所见温度高 200 度的温度下，被浇注、拉伸、吹胀或挤压成形的——而最打破直觉的是，成品的性能不是材料的性能。它们是*工艺留下的*材料的性能。**同样一种聚丙烯的两个注塑件，一个模温 $2 0 \ \mathrm { ^ \circ C }$ 、一个 $7 0 \ \mathrm { ^ \circ C }$ ，刚度相差 15 %，冲击强度相差 40 %，收缩相差 30 %，表面光泽完全不同，而两者对树脂来说都"符合规格"。一个单向拉伸 3.5 倍、另一向 2.5 倍的聚乙烯瓶，比一个完全没拉伸的同种管坯韧十倍。一块有一层 5° 褶皱的碳纤维翼面蒙皮，其压缩强度只有没有褶皱的同块蒙皮的一半，而它的重量、尺寸和超声检测曲线都不会告诉你你拿到的是哪一块。

这就是本讲的主题。**金属加工改变形状；聚合物和复合材料加工在同一三十秒里改变形状*以及*显微组织*以及*纤维构型*以及*残余应力，而这一切都由机器操作员能看到的那几个温度、压力和时间控制。**对设计者的结果是：一个模塑件必须连同它的模具一起设计，一个层压件必须连同它的铺层表、工装和检测方法一起设计——而一个模塑件的图纸是一份关于工艺的法律文件，不只是关于几何的。

::: warning 聚合物与复合材料加工出错的九种方式
**把聚合物熔体当作一种有黏度的液体。**聚合物熔体是*剪切变稀*的（其黏度在料筒与浇口之间下降 30-100 倍）、*弹性*的（它记得自己的形状并在离模时膨胀）、*时间相关*的（其松弛时间 0.01-10 s，与每个工艺时间相当，所以它的德博拉数从不低于 1 太多）而且*对温度极其敏感*（20 °C 的变化让黏度变一倍）。**数据表上单一的"黏度"数字——熔体流动指数——只是那张曲面上的一点，在一个剪切速率下测得，它是质量控制数字，不是设计数字。****用壁厚不均的零件设计模具。**厚的地方就是缩痕、空隙、翘曲和八秒周期的来源。**壁厚均匀，实在做不到时用不超过 3:1 的平缓过渡，是模塑设计第一条也最值钱的规则。****忽视"沿流动方向"与"垂直流动方向"收缩的差异。**无增强非晶零件收缩 0.4-0.7 %；半结晶的 1.5-3 %；30 % 玻纤增强尼龙沿流动 0.3 %、垂直 0.9 %，而**正是这种各向异性让一条 200 mm 的增强筋翘曲 2 mm。****埋入金属嵌件却不考虑聚合物的热膨胀。**聚酰胺的膨胀系数是 $8 0 \times 1 0 ^ { - 6 } \ \mathrm { K ^ { - 1 } }$ ，黄铜是 19。一个尼龙壳体里模压的黄铜衬套，在 $- 3 0$ 到 $+ 9 0 \ \mathrm { ^ \circ C }$ 之间循环，其抱紧力变化 11 %，在低温端衬套就松了。**把复合材料零件当作带铺层的金属零件设计。**层压板不是"塑料里掺了纤维"：它是**一叠面内性能由你选择、而厚度方向性能你无法控制的各向异性层**，而 80 % 的复合材料失效是**分层和纤维褶皱**，不是纤维断裂。**假定手糊的 30 % 纤维体积分数和预浸料的 60 % 是同一种材料。**不是：纤维方向的刚度大致与纤维体积成正比，所以手糊件刚度只有一半、压缩强度只有三分之一、重量却翻倍。****为了节省周期时间而快速灌注。**树脂走阻力最小的路径——丝束*之间*渗透率高 1000 倍的通道——而每根丝束*内部*渗透率 $1 0 ^ { - 1 5 } \ \mathrm { m ^ { 2 } }$ 的树脂永远填不满。**你得到一个流动前沿 100 % 湿润、而每个束束内部 2 % 空隙的零件，它压缩时以许用值的一半破坏。****按时间表而不是按固化度固化热固性材料。**固化度决定玻璃化转变，玻璃化转变决定最高使用温度和耐化学性；模具低 15 °C 时做的"五分钟"固化，是一个通不过热水浸泡试验的零件。****想把复合材料零件做大、手糊来省钱。**低批量复合材料零件的成本 60-70 % 是人工，出路只有减少零件、加大模具、更快的树脂、自动铺放和——批量下真正有效的那一条——更短的固化。
:::

## 1. 加工中的聚合物是什么

::: definition 三个家族，以及决定一切的两个温度 {#def-families}
每一种聚合物工艺都是两个温度和一个压力的谈判。**$T _ { \mathrm { g } }$ ，玻璃化转变**，是非晶链段停止协同滑移之处：低于它，材料是模量 2-3.5 GPa 的硬脆玻璃；高于它 20 °C，是 10-100 MPa 的橡胶态、革状、韧性固体。**$T _ { \mathrm { m } }$ ，熔点**，只对规则到能堆入晶体的链存在，是这些晶体缴械之处：聚乙烯 $1 3 5 \ \mathrm { ^ \circ C }$ ，聚丙烯 $1 6 5 \ \mathrm { ^ \circ C }$ ，尼龙 6,6 $2 6 5 \ \mathrm { ^ \circ C }$ ，PEEK $3 4 3 \ \mathrm { ^ \circ C }$ 。**半结晶聚合物的加工发生在 $T _ { \mathrm { m } } + 3 0$ 到 $+ 8 0 \ \mathrm { ^ \circ C }$ ，非晶的在 $T _ { \mathrm { g } } + 1 0 0$ 到 $+ 1 5 0 \ \mathrm { ^ \circ C }$ ，而整个工艺窗口就在"能流动"和"降解"之间——对聚甲醛或增塑 PVC 来说，这个窗口只有 15 °C，这就是这两种材料难加工的原因。**

$$
\begin{array} { l c c c l l }
& T _ { \mathrm { g } } \ [ ^ { \circ } \mathrm { C } ] & T _ { \mathrm { m } } \ [ ^ { \circ } \mathrm { C } ] & \text{熔体} \ [ ^ { \circ } \mathrm { C } ] & \text{分解} \ [ ^ { \circ } \mathrm { C } ] & \text{窗口} \\ \hline
\text{LDPE} & - 1 1 0 & 1 1 0 & 1 5 0 { - } 2 6 0 & 3 0 0 & \text{宽} \\
\text{PP（均聚）} & 0 & 1 6 5 & 2 0 0 { - } 2 7 0 & 3 0 0 & \text{宽} \\
\text{ABS} & 1 0 5 & - & 2 2 0 { - } 2 6 0 & 2 8 0 & \text{中等} \\
\text{PA 6} & 5 0 & 2 2 0 & 2 5 0 { - } 2 9 0 & 3 1 0 & \text{中等} \\
\text{PC} & 1 4 7 & - & 2 9 0 { - } 3 3 0 & 3 6 0 & \text{中等} \\
\text{POM（甲醛）} & - 5 0 & 1 7 5 & 1 8 5 { - } 2 0 5 & 2 1 5 & \text{窄} \\
\text{PVC（硬）} & 8 2 & - & 1 6 0 { - } 1 9 0 & 2 0 0 & \text{窄} \\
\text{PEEK} & 1 4 3 & 3 4 3 & 3 7 0 { - } 4 0 0 & 5 0 0 & \text{宽，贵}
\end{array}
$$

三个家族按加热时的表现自动分类，而家族决定工艺。**热塑性塑料**（全部注塑量的 85 %：PP、PE、PS、PVC、PA、PC、POM、PET，以及工程类的 PBT、PPS、PAI、PEEK）是只靠次级键结合的线型或支化链，所以它们可逆地熔化、流动、凝固——可以重熔，这使它们可回收，也把最高使用温度限制在远低于 $T _ { \mathrm { g } }$ 的水平。**热固性材料**（环氧、酚醛、不饱和聚酯、三聚氰胺、聚氨酯、有机硅）以低黏度预聚物开始，*反应*成无限网络：不能重熔，再热会碳化，反应通常不可逆并放热、有时放出挥发分——而关键的加工事实是——**热固性材料的黏度随加热先降、凝胶后永远上升，所以它的加工窗口是与自身化学的赛跑。****弹性体**轻度交联（链的 1-3 mol %），可以拉伸 300-700 % 并回弹；它们在未交联时成形、之后再交联，这就是橡胶加工是关于*焦烧*（意外的提前固化）和*欠硫*的故事的原因。

**聚合物工艺留下的显微组织是自身热历史的四层记录**，与数据表描述的不是一回事：一层几微米厚的**冻结表皮**，由取向或玻璃态材料构成，在头半秒里贴着 $4 0 \ \mathrm { ^ \circ C }$ 的钢壁形成，具有没人规定过的材料的性能；一层**剪切取向层**，喷泉流把链和纤维沿流动方向铺平的地方；一个**横向芯层**，那里的材料静止、凉、慢，纤维直立着；以及在半结晶件里，**尺寸和结晶度由冷却速度决定的球晶结构**——贴着冷模淬出的 $5 { - } 3 0 \ \ \%$ 结晶度对缓冷的 $4 5 { - } 5 5 \ \ \%$ ，其间相差 10 % 的收缩、30 % 的刚度、更差的冲击和完全不同的耐化学性。**这就是为什么同一种树脂的"注塑级"和"挤出级"是不同的产品，为什么使用前退火的模塑件尺寸会变，为什么半结晶零件绝不可以从缓冷的棒材上加工下来然后指望它保持平直。**
:::

::: definition 为什么熔体完全不像液体 {#def-melt}
聚合物熔体是一根一米长、一万单体长的意大利面，与每个邻居缠结在一起，而缠结是暂时的绳结，在 $1 0 ^ { - 3 }$ 到 10 s 内滑脱。四个推论主导每一种工艺：

**剪切变稀。**在缠结分子量以上，黏度按 $M _ { w } ^ { \, 3 . 4 }$ 变化，而剪切下线团取向、绳结滑脱，所以黏度随剪切速率按**幂律**下降，

$$
\tau = K \, { \dot { \gamma } } ^ { n } \quad \Longleftrightarrow \quad \eta _ { \mathrm { a p p } } = K \, { \dot { \gamma } } ^ { \, n - 1 } , \qquad n = 0 . 2 { - } 0 . 8
$$

$n = 1$ 是你永远遇不到的水。**聚丙烯在 $2 3 0 \ \mathrm { ^ \circ C }$ 下，在螺杆的 $1 0 0 \ \mathrm { s ^ { - 1 } }$ 处表观黏度 $1 0 0 0 \ \mathrm { P a \, s }$ ，在浇口的 $1 0 ^ { 5 } \ \mathrm { s ^ { - 1 } }$ 处 $2 2 \ \mathrm { P a \, s }$ ——45 倍。****这是聚合物加工中最有用的单一事实：熔体恰好在你最需要它流动的地方变稀，这就是 0.5 mm 壁厚的零件能够被填满的原因，也是你为水学过的压降计算错了两个数量级的原因。**长链支化让 $n$ 更小（一种在浇口里流得顺畅、在型坯中保持熔体强度的"宽"熔体）；窄分布和低分子量让它更大。

**温度依赖性。**流动是热激活的，激活能 $2 0 { - } 8 0 \ \mathrm { k J / m o l }$ ，所以 $\eta \propto \exp ( E _ { \eta } / R T )$ ，

$$
{ \frac { \eta ( T _ { 1 } ) } { \eta ( T _ { 2 } ) } } \; = \; \exp \! \left[ { \frac { E _ { \eta } } { R } } \left( { \frac { 1 } { T _ { 1 } } } - { \frac { 1 } { T _ { 2 } } } \right) \right] \; \approx \; 2 \quad \text{for a } 2 0 { - } 3 0 \ \mathrm { ^ \circ C } \text{ change}
$$

**这意味着料筒温度首先是黏度控制、其次才是温度控制，也是"熔体太冷"和"缺料"是同一句话的原因。**这也是聚合物加工窗口如此之窄的原因：流动路径末端需要的黏度由几何决定，如果熔体比你以为的多冷了 20 °C，黏度翻倍，零件最后 20 mm 就冻住了。

**弹性记忆。**让熔体变稀的同样那些缠结也储存能量，并在应力消失时释放。从口模挤出的熔体**离模膨胀**到口模直径的 1.2-2.0 倍；拐角里的熔体往回顶；被棒搅拌的熔体沿棒爬上（魏森贝格效应）；一个在半秒内以 $8 0 \ \mathrm { M P a }$ 充填的模塑件含有冻结的几 MPa 应力，将用接下来的一周把零件拉离形状。**决定这一切是否要紧的无量纲数是德博拉数 $\mathrm { D e } = \lambda / t _ { \mathrm { p r o c e s s } }$ ，松弛时间除以工艺时间——而对聚合物，对它被发明出的几乎每一种工艺，它都在 0.01 到 10 之间。**金属和水的德博拉数是 $1 0 ^ { - 1 2 }$ ；聚合物生活在 $\mathrm { D e } \approx 1$ ，这是聚合物加工是一门艺术的深层原因：材料在同一个操作里既是流动的黏性液体又是回弹的弹性固体，而比例是工艺工程师旋转的旋钮。

**拉伸变硬。**拉伸熔体，其黏度*上升*，常常 10-100 倍，因为链取向并无法相互滑过。长链支化的熔体（LDPE，以及为热成型和吹塑特制的牌号）强烈变硬，这就是 300 mm 长的熔融**型坯**能悬挂六秒而不颈缩断裂的原因。**这就是为什么为挤出涂膜买的"同一种"聚乙烯在吹塑中失败，为什么热成型牌号按'熔体强度'出售——一个与固体零件任何性能都无关的数字。**
:::

::: example 浇口让熔体变稀多少？ {#ex-shear level=2 check="22"}
某种聚丙烯在剪切速率 $1 0 0 \ \mathrm { s ^ { - 1 } }$ 下 $\eta = 1 0 0 0 \ \mathrm { P a \, s }$ ，幂律指数 $n = 0 . 4 5$ 。它在 $0 . 4 \ \mathrm { m m }$ 浇口的 $1 0 ^ { 5 } \ \mathrm { s ^ { - 1 } }$ 处表观黏度是多少？

$$
\eta \; = \; 1 0 0 0 \left( { \frac { 1 0 ^ { 5 } } { 1 0 0 } } \right) ^ { 0 . 4 5 - 1 } \; = \; 1 0 0 0 \times 1 0 ^ { - 1 . 6 5 } \; = \; { \bf 2 2 \ P a \, s }
$$

**稀了四十五倍。**实际后果是：模具的充填由*浇口*主导，而不是由型腔主导：浇口 22 Pa·s 在 0.4 mm 缝隙上产生的每毫米压降，超过 1000 Pa·s 熔体在 3 mm 型腔里任何地方产生的压降，而一旦浇口冻结（它在一到三秒内冻结），保压压力与零件断联，收缩就此定格。**这就是为什么"浇口冻结时间"是注塑工设定保压时间的依据，为什么凸台处凹陷的零件几乎总是浇口冻得太早，而不是机器保压太弱。**
:::

## 2. 注塑：三十秒里的四种不同工艺

::: definition 机器、周期，以及钱花在哪里 {#def-irm}
注塑机是一台**带加热器的螺杆泵**加一台**带冷手指的压力机**。螺杆以 $3 0 { - } 3 0 0 \ \mathrm { r p m }$ 对着 $5 { - } 2 0$ bar 的背压旋转，在三个区段输送、压缩、剪切并熔化颗粒料，在其端部计量出精确的**注射量**；然后停止旋转、变为一根柱塞，把那一注射量以 $5 0 { - } 5 0 0 \ \mathrm { c m ^ { 3 } / s }$ 和 $2 0 { - } 1 5 0 \ \mathrm { M P a }$ 的注射压力推入闭合的模具；然后保压，让零件收缩抱紧型芯；然后冷却；然后开模，半模顶出零件。四个阶段是**充填**（0.5-5 s，喷泉流铺出皮芯结构）、**压实**（1-10 s，40-80 % 的注射压力，强行补入热收缩需要的额外材料）、**保压与冷却**（5-60 s，只做导热的闲事）、**开模-顶出-合模**（3-10 s）。

**经济性全在模具和周期。**一副技术件的生产模具要 £30,000-150,000 的模具钢（P20 或 1.2344 预硬 30 HRC，寿命 50 万模次；光学表面用淬硬 420 不锈钢 50 HRC 抛光到 N1，寿命 200 万模次），切削和试模要 6-16 周，必须摊销。机器按吨位计 £25-80 一小时。材料 £1-8/kg，而手里的零件通常含有其重量 1.2-1.4 倍的购料树脂，因为主流道和流道要么被回收粉碎（每回收一次纤维变短、冲击强度降 10-20 %），要么报废。**这个工艺的三个杠杆，按对成本的影响排序：型腔数（4 腔模具把单件机器时间减四分之三、模具加 40 %）、冷却时间（周期的 60-70 %，也是唯一由物理决定的部分）、周期的空转时间（开模-顶出-合模和机器人，好的单元能压到 3 s）。**

机器的选定要凭两个数字，任何一个弄错都是常见而昂贵的错误。**注射量：**零件加流道应为螺杆最大注射量的 30-80 %，因为注射量太小会让熔体在料筒里待上几分钟（降解颜色和玻纤增强尼龙），而且螺杆计量不准。**锁模力：**型腔内的压力试图以等于*平均型腔压力乘投影面积*的力把模具撑开，机器的吨位必须带裕量超过它：

$$
F _ { \mathrm { c l a m p } } \; \geq \; 1 . 1 \times { \bar { p } } \, A _ { \mathrm { p r o j } } \qquad \left[ 1 \ \mathrm { t o n n e } \approx 9 . 8 \ \mathrm { k N } \right]
$$

薄壁、长流程或玻纤填充件取 $\bar { p } = 3 0 { - } 6 0 \ \mathrm { M P a }$ 。**锁模不足是自限而明显的（模具溢料飞边、零件超重、模次波动）；锁模过度是无声而昂贵的（模具排气槽被压闭，空气出不去，零件在流动末端烧焦——"柴油效应"烧蚀，那是被困空气的压缩点火，看起来和烧焦的树脂一模一样，因为它就是）。**
:::

::: definition 冷却：周期中唯一由物理决定的部分 {#def-cool}
注塑周期里除了冷却时间，一切都可以商量：充快点、压久点、早点开模、放个机器人。**冷却时间由导热决定，它是整个周期的地板。**全厚 $s$ 的零件，两侧由表面处于 $T _ { w }$ 的模具冷却，必须让*中心线*降到顶出温度 $T _ { e }$ 以下（那是零件自身刚度下的热变形温度，不是你挑的温度）。平板问题的一项傅里叶解给出

$$
t _ { \mathrm { c o o l } } \; = \; { \frac { s ^ { 2 } } { \pi ^ { 2 } \alpha } } \; \ln \! \left[ { \frac { 8 } { \pi ^ { 2 } } } \, { \frac { T _ { \mathrm { m e l t } } - T _ { w } } { T _ { e } - T _ { w } } } \right] \qquad \alpha = { \frac { k } { \rho c _ { p } } } \approx ( 0 . 0 7 { - } 0 . 1 3 ) \ \mathrm { m m ^ { 2 } / s }
$$

**要从中读出的是：时间按壁厚的平方增长，而且几乎与熔体温度无关。**壁厚加倍，周期翻四倍：这就是为什么"均匀，且在刚度允许下尽量薄"是模塑设计的全部，也是为什么一条筋（以 $t ^ { 3 }$ 换来弯曲刚度，几乎不增加冷却时间，因为它的热逃进相邻的壁里）比加厚更值钱。每一种商用塑料的热扩散率都在 $0 . 1 \ \mathrm { m m ^ { 2 } / s }$ 的两倍以内——聚合物都是好的绝热体——所以**任何换材料的办法都不会让零件冷却得快多少。**真正有效的，按价值排序：

$$
\begin{array} { l l l }
\textbf{措施} & \textbf{对冷却时间的影响} & \textbf{成本} \\ \hline
\text{更薄、均匀的壁厚} & \propto s ^ { 2 } \ ( \text{平方律！} ) & \text{设计，即免费} \\
\text{随形冷却水道} & - 2 0 \text{ 至 } - 4 0 \ \% & \text{增材制造的镶件} \\
\text{加大水量，湍流} & - 1 0 \text{ 至 } - 2 0 \ \% & \text{£500 的管路} \\
\text{铍铜或铝镶件} & \text{局部 } - 1 0 \text{ 至 } - 3 0 \ \% & \text{每个镶件 £2-10k} \\
\text{冷模具，热零件} & - 3 0 \ \% \text{（表面更差）} & \text{免费，而且是馊主意} \\
\text{真空或"冷皮"周期} & - 4 0 \ \% & \text{一台专用机器}
\end{array}
$$

**随形冷却是三十年来注塑里唯一真正的新思想：**激光打印的铍铜或马氏体时效钢镶件，冷却水道以恒定 6 mm 的距离跟随零件表面，而不是必须绕开型芯的钻孔直水道，值周期的 20-40 %——更重要的是——消除了引起一半翘曲的*零件两侧温差*。它的价格是钻孔镶件的三到五倍，如今在高产量光学件和汽车模具上已是标配。
:::

$$

$$

::: definition 充填型腔：熔体做什么，留下什么 {#def-fill}
熔融聚合物不像水那样沿管道推进；它**喷泉**。熔体到达流动前沿，铺展在生长的凝固皮层表面上，然后自我翻卷——所以前沿处的材料*永远是新鲜熔体*，而壁面处的材料*是最早到达、被拉平压在冷表面上的材料*。三个推论随之而来，它们就是模塑件各向异性的原因。

**皮芯结构。**喷泉流加上壁面巨大的剪切，把链（以及任何纤维）沿流动方向拉平，而 $4 0 \ \mathrm { ^ \circ C }$ 的钢在它们松弛之前把它们冻在那里。结果是**一层 20-100 μm 高度取向的表皮、一个过渡层、一个松弛的横向取向芯层**——30 % 玻纤增强件沿流动的模量比垂直方向高 30-50 %，而**沿流动收缩 0.2-0.4 %、垂直 0.8-1.2 %**。这种各向异性，在一个带筋带凸台的零件上积分起来，就是模塑件翘曲的原因，也是为什么模塑件的收缩以两个数字给出、为什么模具按两者折中的"收缩率"加工。

**熔接（熔合）线。**两条流动前沿相遇之处——孔的周围、第二个浇口、或型芯针的末端——以小角度相遇，链必须跨过界面扩散才能结合。**扩散需要几秒；界面在不到一秒内冻结。**所以熔接线是真实的不连续：**无填充非晶聚合物为基体强度的 50-70 %，半结晶的 20-40 %，含 30 % 玻纤时 10-30 %，因为纤维平行于界面排列、什么都不桥接。**对策全在温度和压力：更热的模具和熔体、熔接处更厚的截面、一个**冷料井**接住碰过流道壁的材料、熔接处一条深 $0 . 0 2 \ \mathrm { m m }$ 的**排气槽**（让空气在被压缩烧焦之前出去）、**加大或改位的浇口**让两前沿以大角度相遇、或流道上一处**凸台**迫使新鲜熔体横穿接头。**而设计者的对策，比以上全部更好：把孔挪走。**

**流程长度与"流动比"。**熔体在普通零件里大约能流动**自身壁厚的 100-150 倍**，在带热流道和真空辅助模具的薄壁件里 300 倍；超过之后所需压力超出机器能力。**流动比** $L / t$ （$L$ 是浇口到*最远点*的距离，不是最长路径）是模流分析报告的第一项，$L / t > 2 0 0$ 的零件需要更多浇口、更厚的壁、或换一个零件。**新模具"缺料"最常见的原因不是机器，而是一条浅了 0.05 mm 的排气槽，第二常见的是壁厚比模型假设薄了 15 %。**

**PVT 行为与缩痕。**聚合物熔体可以大量压缩——$1 5 0 \ \mathrm { M P a }$ 下比零压时致密 10-20 %——冷却时再收缩 5-15 %，结晶的话再多 5-10 %。**保压的存在就是为了补回那部分收缩，而保压只在从螺杆到最后冻结点（"最后冻结点"，永远是最厚的地方）存在一条未冻材料通道时才有效。**浇口一旦冻结，零件在液压上被隔离、自由收缩，这就是为什么**保压时间按浇口冻结时间设定且不再加长**——多保的时间只买来周期。当最后冻结点是名义壁厚后面的凸台或筋时，它收缩并把可见表面一起拉进去：**缩痕，它不是工艺的缺陷而是厚截面的几何后果，对策是把凸台掏空、筋取壁厚的 60 %，而不是加大保压。**
:::

::: example 浇口中的剪切热 {#ex-sheat level=3 check="35"}
一条深 $0 . 4 \ \mathrm { m m }$ 、宽 $4 \ \mathrm { m m }$ 的侧浇口以 $5 0 0 0 \ \mathrm { s ^ { - 1 } }$ 的剪切速率通过熔体 5 ms，表观黏度 $5 0 0 \ \mathrm { P a \, s }$ 。这段时间里熔体产生多少热？温度如何变化？取 $\rho c _ { p } = 1 . 8 \times 1 0 ^ { 6 } \ \mathrm { J / m ^ { 3 } K }$ 。

$$
\dot { q } = \eta \, { \dot { \gamma } } ^ { 2 } = 5 0 0 \times 5 0 0 0 ^ { 2 } = 1 . 2 5 \times 1 0 ^ { 1 0 } \ \mathrm { W / m ^ { 3 } }
$$

$$
\Delta T = { \frac { { \dot { q } } \, \Delta t } { \rho c _ { p } } } = { \frac { 1 . 2 5 \times 1 0 ^ { 1 0 } \times 0 . 0 0 5 } { 1 . 8 \times 1 0 ^ { 6 } } } = { \bf 3 5 \ \mathrm { ^ \circ C } }
$$

**熔体到达型腔时比离开喷嘴时热了三十五度，而机器里没有任何热源放了这些热。****这就是为什么冷流道浇口里的材料可测得比料筒里的熔体更热，为什么可以用很小的浇口给黏性工程树脂"剪切加热"以充满薄壁件，以及——反过来——为什么玻纤增强尼龙上过大的浇口会烧焦：同样的耗散集中在富纤维、低导热的皮层上，就是浇口在料筒从未过热的情况下烧损的方式。****它也是半结晶零件"流动诱导结晶"表皮背后的机理，也是从玻璃纤维生长出的横晶层背后的机理——而横晶层正是增强零件的收缩不等于纯树脂收缩的原因。**
:::

::: definition 设计零件、浇口和模具 {#def-design-irm}
**零件规则，以及每条的理由。**均匀壁厚，多数零件 1-4 mm，薄壁包装 0.5-1.5 mm，过渡不陡于 3:1，绝不突然加厚。**每个内圆角取 0.5 倍壁厚、每个外圆角取 1.5 倍壁厚**——为了模具（尖锐内角是模具里会开裂的应力集中源，尖锐外角是顶出必伤的模塑件）、为了熔体（尖角是流动停滞、熔接线形成之处）、也为了零件（$- 3 0 \ \mathrm { ^ \circ C }$ 玻纤增强尼龙里的尖角是一条尚未发生的裂纹）。**每个垂直面 1-2° 脱模斜度，咬花面 3-5°**，因为模塑件收缩*抱紧*型芯、*离开*型腔壁，零斜度的型芯顶出时会纵向划伤。**尽量避免侧凹；避不开就全部放在同一分型线或同一侧**，因为每个侧凹都是一个**抽芯**（斜导柱、顶块、旋转脱模），每个都是 £3,000-15,000 的模具、一个维护项目、飞边和痕迹的来源。**筋取名义壁厚的 50-60 %，间距 2-3 倍壁厚，绝不在两面墙上彼此相对。****凸台掏孔并用圆角过渡，绝不实心。****卡扣按应变设计：无填充尼龙 2-4 %，聚碳酸酯 1-1.5 %，增塑的 0.5 %，而且按*应变*而不是应力设计，因为模塑件的蠕变意味着一个在 $6 0 \ \mathrm { ^ \circ C }$ 下保持偏转一年的卡扣会失去一半保持力。**

**浇口设计。**浇口是一个其职责是在正确时刻冻结的节流段，值得知道的有五个家族。**侧浇口和扁平搭接浇口**（主力军，全深或部分深度，分型线上留痕迹）。**潜伏式（隧道）浇口**，在分型线下方切削，顶出时剪断，可见面无痕，可自动断浇口。**点浇口**用于外观件，0.5-1.5 mm，留下小痕迹，是三板模唯一的选择。**薄膜和飞边浇口**用于薄而宽而平的零件，整个分型线进料，熔接线和取向最小化——代价是一道去飞边工序。**扇形和环形浇口**用于管子，让流动前沿对称、浇口对面没有熔接线。**流道系统要么"自然平衡"（等路径、等时间，对不对称零件组不可能），要么"完全平衡"（按构造等路径，1:2:4 规则），而注塑工用手持测温枪和秒表调整差异。****热流道**删去主流道和冷流道——20-40 % 的材料和 1-3 s 的周期——代价是每副模具 £5,000-30,000、一个控制箱、以及一整类新缺陷（一个冷点、一个烧损的喷嘴尖、一次要四小时的换料）。

**模具。**光学件和 200 万模次寿命用淬硬抛光钢；技术件用 **30 HRC 的 P20**；必须冷却热点处用**铍铜**；5 万模次的过渡模具或低批量零件用**铝（2244/7075）**，加工时间只要三分之一、能抛光到像样的表面，但必须镀镍以抗玻纤树脂的磨蚀和阻燃树脂的腐蚀。**排气槽深 0.02-0.03 mm、宽 5-10 mm，开在分型线上或排气台上，而它们是全世界每副模具上设计最不足的特征。****冷却是钻 8-10 mm 的水道，间距 3-5 倍壁厚，距表面恒定距离，型芯周围用隔板式或喷泉式水道，且应当湍流（Re > 10,000）——对 8 mm 水道意味着 1.5 m/s 和每分钟 12 升，而多数模具跑在这个流量的三分之一，因为有人为了止漏把阀门关小了。**
:::

## 3. 挤出：连续的模塑

::: definition 螺杆是三台机器合一 {#def-extrude}
一台 90 mm、长径比 24 的单螺杆挤出机以 $2 0 { - } 2 0 0 \ \mathrm { r p m }$ 旋转，在一个机筒里做三件物理上不同的工作，而知道自己在哪个区段，是诊断挤出问题的方法。

**区段 1，固体输送**（加料口，长 4-6 个直径，深度是计量段的三倍）：颗粒料被*冷却*的机筒壁的摩擦拖向前，并像瓶中的软木塞一样沿螺棱推进。物理与粉料料仓相同：**料塞与钢之间的摩擦系数**（0.2-0.4，取决于机筒是否水冷）决定输送多少料，这就是为什么**加料口过热会让挤出机断料，为什么每台挤出机都有水冷、特意粗糙化、尺寸宽裕的加料段。**断料的挤出机会波动，而波动的挤出机做出波纹状的产品。

**区段 2，熔融**（过渡段，8-12 个直径）：一层熔体从机筒壁被剪切下来，挤入固体料塞与螺棱之间的流道，形成**熔池**并不断长大，直到固体床被挤到对面螺棱上消失。**"熔点"——最后一点固体消失之处——应当在计量段开始前 1-2 个直径处；如果更晚，未熔的细粉到达口模，产品上就有"晶点"（毁掉薄膜和涂层的透明鱼眼）。****屏障（Maddock）螺杆**在流道上加一副副螺棱，强迫每一点固体通过薄的剪切间隙，熔化长度减半、温度波动减半，除少数热敏物料外已是所有螺杆的标配。

**区段 3，熔体泵送**（计量段，8-10 个直径，深 $0 . 0 7 D$ ）：现在它是一台泵，其输出是经典的拖曳流减压力的结果，

$$
Q \; = \; \underbrace { { \tfrac { 1 } { 2 } } \pi ^ { 2 } D ^ { 2 } h N \sin \theta \cos \theta } _ { \text{拖曳流 } \propto N } \; - \; \underbrace { { \frac { \pi D h ^ { 3 } \sin ^ { 2 } \theta } { 1 2 \mu } } { \frac { \mathrm { d } p } { \mathrm { d } z } } } _ { \text{压力流 } \propto \Delta p / \mu }
$$

**这在 $Q$ 对 $\Delta p$ 图上是一条直线，而口模自身的特性 $Q = K _ { \mathrm { d i e } } \, \Delta p / \mu$ 是另一条过原点的直线。它们的交点就是工作点**——这个小图解释了四件否则显得武断的事：为什么更热的机筒（更低的 $\mu$ ）让口模*更*高产而螺杆*更*失控；为什么磨损的螺杆（更深的 $h$ ）失去产量并让挤出机对口模压力变化敏感；为什么凡必须保持厚度的东西（电线包覆、片材、医用管）都在口模入口装**熔体泵**或**齿轮泵**，因为它把口模压力与螺杆解耦；以及为什么"线速度老是漂移"的答案几乎总是加料段温度。

**口模是一个有形状的压降。**片材模口沿其 1-3 m 宽度设有**阻流棒**和**挠性螺栓**，操作员可把流量修整到 $\pm 0 . 0 5 \ \mathrm { m m }$ ；管材模口是带鱼雷头和芯棒的环形**十字头**；异型材模口的内腔由工匠手工抛光数周，因为熔体必须以相同速度到达截面的每一点，否则型材会扭曲、塌陷并带内应力。**任何口模的设计规则是出口速度均匀，而实现它的工具是可变的定型段长度——截面薄、流速快处取长，厚处取短。****极限由熔体设定：壁面剪切应力超过 $0 . 1 { - } 0 . 4 \ \mathrm { M P a }$ 表面变暗（**鲨鱼皮**），超过约 $0 . 4 \ \mathrm { M P a }$ 或剪切速率 $1 0 ^ { 4 } \ \mathrm { s ^ { - 1 } }$ ，整个挤出物变得波纹、螺旋或分叉（**整体熔体破裂**），那是壁面滑移失稳，不是温度问题。对策是降低产量、更热的口模、带长收敛入口的**流线型（流变增强）口模**、100-200 目的**模体过滤网**，或 5-10 % 让熔体在壁面滑移的氟聚合物**加工助剂。**

**而熔体离模时膨胀** 20-100 %，因为收敛流中储存的弹性能量被释放。**所以口模按目标截面的*反向*设计：直径靠膨胀、壁厚靠牵引，两者由牵引速度设定。**牵伸比 $\mathrm { D D R } = A _ { \mathrm { d i e } } / A _ { \mathrm { p r o d u c t } }$ 是挤出机的拉伸比版本，也是 100 mm 管材线以 1-3 m/min 运行而熔体以 10 m/min 离模的原因。
:::

::: example 挤出机的能耗账单 {#ex-energy level=3 check="30"}
一台共混挤出机以 $0 . 1 5 \ \mathrm { k W h / k g }$ 的比机械能生产 $2 0 0 \ \mathrm { k g / h }$ 的 30 % 玻纤增强尼龙 6,6。需要多少轴功率？与熔体实际需要的热量相比如何？

$$
P = 0 . 1 5 \times 2 0 0 = { \bf 3 0 \ k W }
$$

**热力学最低限度只是显热：尼龙从 $2 5 \ \mathrm { ^ \circ C }$ 到 $2 8 0 \ \mathrm { ^ \circ C }$ 、$c _ { p } \approx 2 . 0 \ \mathrm { k J / k g \, K }$ 是 $5 1 0 \ \mathrm { k J / k g } = 0 . 1 4 \ \mathrm { k W h / k g }$ ，加上 $7 0 \ \mathrm { k J / k g }$ 的潜热，得 $0 . 1 7 \ \mathrm { k W h / k g }$ ——*比*输入的机械能还*多*。****这不是矛盾，而是设计点：现代挤出机怠速时 40-60 % 的热来自机筒加热器，而*移除*其余的冷却水，因为在 400 rpm 和 $0 . 3 \ \mathrm { k W h / k g }$ 下，螺杆的剪切生热本身就超过熔化所需，机器必须被冷却。****这就是为什么比较双螺杆与单螺杆时要问"比能耗"这个数字，为什么深流道的屏障螺杆能省 20 % 驱动功率，为什么挤出生产线的冷却水回路比加热回路更大。**

::: definition 吹塑、热成型，以及充气聚合物的其他方式 {#def-blow}
**挤出吹塑**做出所有不是拉伸吹塑的中空制品：油箱、洗涤剂瓶、风管、200 升桶。挤出一根熔融**型坯**——一根最长达 3 m、靠自重悬挂的熔体管——模具合上，20-40 bar 的空气把它吹贴到冷壁上。**全部技术都在型坯自身的重量上。**壁太薄的熔体会下垂，让瓶顶变薄；太厚的熔体浪费树脂且永远冷不完。答案是**轴向程序控制**：液压或电动伺服机构移动芯轴，在型坯悬挂的六秒里把口模间隙改变二十次，使壁厚上厚下薄，恰好抵消下垂。**环向程序控制**用模具自身的拉伸做同样的事。**HDPE 是首选材料，因为它的长链支化给出熔体强度**（线型茂金属或 PP 会下垂，不用长链支化牌号就不能用），而**多层**版本共挤出六层或九层做油箱：HDPE / 黏结层 / EVOH 阻隔层 / 黏结层 / 回收 HDPE / 黏结层 / HDPE，占壁厚 5 % 的 EVOH 完成 99 % 的汽油蒸气阻隔。

**注塑拉伸吹塑**做出世界上每一个碳酸饮料瓶和水瓶，它是本讲中*工艺制造材料*的最漂亮例子。管坯（一个注塑的试管，500 ml 瓶用 10 g）在红外炉中复热到 $1 0 5 { - } 1 1 0 \ \mathrm { ^ \circ C }$ ——**恰在 $7 8 \ \mathrm { ^ \circ C }$ 玻璃化转变之上，不能再高，否则 PET 结晶变白**——然后拉伸杆以 0.3 s 冲入，同时 30-40 bar 的空气把它吹胀。**拉伸比轴向 2.5-4.0、环向 3.5-4.0，同时做两件事：使非晶链取向，并引发*应变诱导结晶*，把 PET 从 5 % 结晶带到 25-30 %。**与未拉伸的瓶相比，结果是**冲击强度约十倍、刚度两倍、气体阻隔六倍、耐环境应力开裂四倍**——这就是为什么你捏 PET 瓶会看到它发白，为什么在炉里过热的瓶底部又脆又紫。**两阶段工艺（注塑、冷却、烘炉复热、拉伸吹塑）做出必须承受 6 bar 的碳酸瓶；单阶段（注塑、保温、同一机器拉伸吹塑）做水瓶和 300 ml 药用圆瓶，因为不复热而更便宜。**

**热成型**取一张**片材**（挤出或压延的，0.2-6 mm），夹紧，用辐射陶瓷加热元件加热到高于其成型温度 $1 0 { - } 3 0 \ \mathrm { ^ \circ C }$ 直到表面下垂，然后用真空、压缩空气或机械助压把它成型在模具上或模具内。**非晶片材（HIPS、PET-G、ABS、PVC）的成型窗口宽 30-40 °C，容易；半结晶的（PP、PE、PA）只有 5-10 °C，是一门艺术，因为在 $T _ { \mathrm { m } } - 2 0 \ \mathrm { ^ \circ C }$ 片材像黄油一样流，在 $T _ { \mathrm { m } } - 4 0 \ \mathrm { ^ \circ C }$ 它弹性回弹并发白。****壁厚不是设计出来的，是继承来的：穹顶按其拉深比变薄，球冠的经典估计是**

$$
{ \frac { t } { t _ { 0 } } } \; \approx \; { \frac { 1 } { \sqrt { D } } } \qquad D = \text{局部拉深比}
$$

**所以深度为壁厚尺度四倍的杯子，在拐角处薄到一半，而拐角正是零件受载之处。**对策是**助压塞**（缓慢的机械或气动鼓泡，在模具闭合*之前*把片材拉进拐角，值拐角厚度的 30-50 %）、匹配机械对模（**气压成型**，5-8 bar，能在 1 mm 壁上保持 2 mm 的纹理），以及**同一工位内切边**，让零件下线即成品。**经济性：片材占零件成本的 60-80 %，所以热成型在零件大而薄而浅时胜出（浴缸、行李箱衬里、泡罩包装、酸奶杯），在拉深深或拐角要紧时落败。**卷料线每分钟做 40-100 个杯；1.2 × 1.2 m 压板的片材机每小时做 4-10 个，模具是一块机加工铝甚至 MDF。

**滚塑**做出大而无缝、一米以上的中空制品——水箱、皮划艇、路障、拖拉机油箱——把**粉末聚乙烯**（100 目，占模具体积的 1-2 %）装入封闭模具，在双轴 2-8 rpm 旋转中烘烤。**壁厚均匀，因为它是同一种粉末粘在处处相同的壁上；工艺中任何地方都没有压力，所以模具不承受锁模载荷，价格只有注塑模具的十分之一。**周期慢（20-60 分钟，因为粉末隔热），公差最好也就 $\pm 1 \ \mathrm { m m }$ ，零件 5-500 kg。**失效模式是"搭桥"**——粉末到不了深拐角或内圆角——对策是在拐角处**铆、压痕或焊上加强筋**，因为滚塑件除非事后焊接，不能有嵌件。
:::

::: example 瓶子的两个拉伸比 {#ex-bottle level=3 check="8.75"}
一个 500 ml PET 瓶以轴向 2.5 倍、环向 3.5 倍拉伸吹塑。总面积拉伸比是多少？对壁厚做什么？

$$
{ \frac { A _ { \mathrm { p r e f o r m } } } { A _ { \mathrm { b o t t l e } } } } \times A _ { \mathrm { w a l l } } \quad \Longrightarrow \quad \text{面积比 } = 2 . 5 \times 3 . 5 = { \bf 8 . 7 5 }
$$

**壁厚被减薄 8.75 倍，其中的分子一个方向被拉 2.5 倍、另一方向 3.5 倍，这就是"双向拉伸"的含义，就是 12 μm 薄的壁能保住 6 bar 二氧化碳九个月的原因。****记住两个数字。500 ml 瓶的瓶身壁厚 25-30 μm——比保鲜膜还薄——而你手里没有比它更强的东西，因为取向就是免费的强度。而 8.75 的面积比就是管坯底部为什么 2.5 mm 厚：面积拉伸 8.75 倍后它必须出来是 0.28 mm，那正是瓶底站立所需。****设计者的收获是：拉伸吹塑件不能有尖角、深凸台或小半径上的模塑螺纹，因为材料到不了那里；而一个带把手、铰链和盖子的"整体"瓶子不是整体的，也永远不会是。**
:::

## 4. 热固性材料与橡胶：与时间赛跑

::: definition 凝胶点、玻璃化转变，以及为什么固化是状态不是时间 {#def-cure}
热固性材料以液体加工、以化学反应完成为固体，而反应有一个**凝胶点**：第一个无限大分子出现的时刻，材料不再是流动的液体，而变成蠕变的橡胶。**凝胶点之前你可以浇注、注射、浸渍或模压；之后你只能加热并等待。**黏度因此随温度先降（分子变短）、到达 $0 . 1 { - } 0 . 5 \ \mathrm { P a \, s }$ 的最低点、然后陡升不止——而热固性工艺的全部设计，就是**在黏度最低点完成成形，并在网络锁住形状缺陷之前把零件脱出模具**。

反应的程度是**固化度** $\alpha$ （0 = 未反应，1 = 完全反应），由差示扫描量热计放热测定，服从自催化定律

$$
{ \frac { \mathrm { d } \alpha } { \mathrm { d } t } } \; = \; \left( k _ { 1 } + k _ { 2 } \, \alpha ^ { m } \right) ( 1 - \alpha ) ^ { n } , \qquad k _ { i } = A _ { i } \exp \! \left( - { \frac { E } { R T } } \right)
$$

其中 $m \approx 0 . 6 { - } 1$ ，$n \approx 2 { - } 2 . 5$ ，$E = 5 0 { - } 7 0 \ \mathrm { k J / m o l }$ 。**工艺工程师必须知道这个方程的三件事。****它是自催化的**，所以速率开始最慢、在 $\alpha \approx 0 . 3$ 处达峰、随反应物耗尽而消亡——这就是固化有"诱导期"的原因，也是冷树脂装模、合模过早做出带气泡轨迹零件的原因。**它指数依赖温度**，$E = 6 0 \ \mathrm { k J / m o l }$ 时速率**每 $2 0 \ \mathrm { ^ \circ C }$ 翻倍**，模具低 $1 5 \ \mathrm { ^ \circ C }$ 让你花两倍周期。****它是放热的**：环氧放出 $5 0 0 { - } 6 0 0 \ \mathrm { J / g }$ ，若无散热会让自己升温 $4 5 0 \ \mathrm { ^ \circ C }$ 。**一个厚铸件、一次过快的灌注或一副设计糟糕的模压件会失控、碳化、点燃车间；固化曲线的升温速率就是为了把零件保持在模具温度 $1 0 \ \mathrm { ^ \circ C }$ 以内。**

**决定零件好坏的数字不是时间而是玻璃化转变，而玻璃化转变按 DiBenedetto 关系跟随固化度，**

$$
{ \frac { T _ { g } - T _ { g 0 } } { T _ { g \infty } - T _ { g 0 } } } \; = \; { \frac { \lambda \, \alpha } { 1 - ( 1 - \lambda ) \, \alpha } } \qquad \lambda \approx 0 . 4 { - } 0 . 6
$$

**这一行公式解释的热固性工艺失效比任何其他公式都多：随反应进行，$T _ { g }$ 上升，而 $T _ { g }$ 一旦到达固化温度，材料就玻璃化——链停止运动，反应速率塌落四个数量级，固化实际上停止。****所以在 $1 2 0 \ \mathrm { ^ \circ C }$ 固化的零件永远达不到高于 $1 2 0 \ \mathrm { ^ \circ C }$ 的玻璃化转变，无论它在那里待多久，而 $T _ { g \infty }$ 为 $1 9 0 \ \mathrm { ^ \circ C }$ 的树脂体系需要 $1 7 5 \ \mathrm { ^ \circ C }$ 以上的后固化才能接近它。****"固化曲线"因此是一条设计来恰好跑在玻璃化之前的温度轨迹，而通不过热水浸泡、溶剂擦拭或热气试验的零件，几乎总是固化到了时间而不是状态。**

**橡胶是同一个故事换了化学。**天然橡胶、SBR、BR、EPDM、丁腈、有机硅和氟橡胶以**未交联**（或几乎未交联）供货，与炭黑或白炭黑、锌、硫黄和促进剂混炼，在 $8 0 { - } 1 1 0 \ \mathrm { ^ \circ C }$ 下经挤出、压延、注塑或模压成形为发粘、脆弱、无用的**"生"**件。**硫化**——1-3 phr 的硫黄配锌/促进剂体系，$1 5 0 { - } 1 8 0 \ \mathrm { ^ \circ C }$ ——投入 1-3 mol % 的交联点，把它变成弹性体。**每种橡胶配方数据表上的两个数字是焦烧时间 $t _ { \mathrm { s } } 2$ （固化开始之时，它必须长到能熬过注塑的热流道）和 $t _ { \mathrm { c } } 9 0$ （固化到 90 % 之时，典型 $1 7 0 \ \mathrm { ^ \circ C }$ 下 3-8 分钟）**，两者都在振荡盘流变仪上测量，以网络形成时上升的转矩报告。**欠硫化，零件发粘、脆弱、会喷霜；过硫化，硫交联变短、变硬、变脆，疲劳寿命崩溃；在模具里焦烧，流道堵塞，模具要拆下重新镀铬。**轮胎在双平板硫化机中以 $1 6 5 { - } 1 7 5 \ \mathrm { ^ \circ C }$ 、25-35 bar 固化 12-18 分钟，靠充氮气的**硫化囊**（氮气预热过，所以囊不抢热；氮透过橡胶的扩散比空气慢 4 倍，所以漏得少、轮胎花纹更清晰）；硫化机打开，90 秒后轮胎下线，全厂的产量由那 15 分钟决定。
:::

::: example $1 2 0 \ \mathrm { ^ \circ C }$ 的固化能走多远？ {#ex-cure level=3 check="77"}
某种环氧 $T _ { g 0 } = 5 \ \mathrm { ^ \circ C }$ ，$T _ { g \infty } = 1 9 0 \ \mathrm { ^ \circ C }$ ，$\lambda = 0 . 5$ 。在 $1 2 0 \ \mathrm { ^ \circ C }$ 等温固化。它能达到的最高固化度是多少？

玻璃化在 $T _ { g }$ 到达 $1 2 0 \ \mathrm { ^ \circ C }$ 时停止反应，所以把 DiBenedetto 左边设为 $( 1 2 0 - 5 ) / ( 1 9 0 - 5 ) = 0 . 6 2 2$ 并求解

$$
{ \frac { 0 . 5 \, \alpha } { 1 - 0 . 5 \, \alpha } } = 0 . 6 2 2 \quad \Longrightarrow \quad 0 . 5 \alpha = 0 . 6 2 2 - 0 . 3 1 1 \alpha \quad \Longrightarrow \quad \alpha = { \frac { 0 . 6 2 2 } { 0 . 8 1 1 } } = { \bf 0 . 7 7 }
$$

**百分之七十七，并且永远停在那里：零件 23 % 未反应，永久地，它将用一生不断释放溶剂和增塑剂。****这就是为什么每种航空预浸料的固化周期都有升到 $1 8 0 \ \mathrm { ^ \circ C }$ 的升温和两小时保温，为什么" $2 0 \ \mathrm { ^ \circ C }$ 固化的双组分环氧胶接接头"被规定为 $T _ { g } \ 5 5 \ \mathrm { ^ \circ C }$ 、使用上限 $4 0 \ \mathrm { ^ \circ C }$ ，也是为什么毁掉一个热固性零件最快的办法是在后固化上省电。**
:::

::: definition 模压、传递模塑、RIM 与热固性工艺 {#def-thermoset}
**模压**是最古老、至今产量最大的热固性工艺：一份计量的料（酚醛粉料压成的片、BMC 颗粒、裁成形并预热到 $8 0 \ \mathrm { ^ \circ C }$ 的 25-30 % 玻纤 SMC 片）投入 $1 4 0 { - } 1 8 0 \ \mathrm { ^ \circ C }$ 的匹配钢模，压机以 $1 0 { - } 4 0 \ \mathrm { M P a }$ 闭合，物料流动并固化，零件在**每毫米厚度 30-60 秒**后顶出。**它是低速、低压、低取向的工艺，正是一个脆性、纤维填充、电绝缘零件想要的**：没有纤维磨短（玻璃丝保持长，强度是注塑件的 2-3 倍）、没有熔接线、近净成形、模具价格只有注塑模的五分之一。**代价是飞边（5-15 % 的材料，切掉）、人工投料和固化时间。**这样做出的**片状模塑料**是电气柜、1990 年代科尔维特的发动机罩、整体卫浴和变压器套管；同时注塑成型的**团状模塑料**是连接器、开关件和机舱下支架。

**传递模塑**把料放入料腔，通过流道挤入闭合的多腔模具，得到类似注射的充填而没有螺杆对纤维的损伤。**它是封装了半导体工业四十年的工艺**——每年 2 亿只塑封料，$1 7 5 \ \mathrm { ^ \circ C }$ 、7 MPa、90 秒的环氧固化，其中塑封料必须流过 100 mm 而不冲歪 0.3 mm 的金引线，这是黏度的故事，不是强度的故事。

**反应注射成型（RIM）**混合两种低黏度液体（聚氨酯用的多元醇和异氰酸酯，在 0.5 mm 撞击混合腔中 150-200 bar，混合 1-2 ms，然后注入 3 秒充满的模具）并在零件中固化。**所需合模压力只是投影面积的 $0 . 5 { - } 3 \ \mathrm { M P a }$ ，所以汽车保险杠需要 1-3 MN，而注塑机要 100 MN——这就是为什么 RIM 模具是铸铝甚至环氧的，价格十分之一，而且可以长 3 m。**脱模时间 2-5 分钟，零件是 4 mm 皮、30 % 玻纤增强（"HR-RIM"或"玻璃毡增强反应注射成型"），应用是保险杠、仪表板皮、卡车翼子板和农机罩。**RIM 的全部商业理由：它是不用万吨压机做出大而韧、A 级表面、低批量零件的唯一办法。**

**液态硅橡胶注塑**是同一招数换铂金硫化的有机硅：30,000 mPa·s 的液体、$1 7 0 \ \mathrm { ^ \circ C }$ 的冷流道模具、30-60 秒固化、许多牌号无需后固化，零件可食品接触、生物相容、$- 6 0$ 到 $2 0 0 \ \mathrm { ^ \circ C }$ 可用。**这就是奶嘴、手机防水密封圈和医用导管歧管都便宜的原因。**
:::

## 5. 复合材料：工艺*就是*零件

::: definition 制造复合材料零件的两条路，以及由此而来的一切 {#def-composite}
复合材料零件是**纤维，放在载荷要它们去的地方，被一种在纤维之间传力、并保护纤维互不伤害的树脂固定**。工艺的一切，就是一场把纤维以正确的**体积分数**（目标 55-65 %，纤维方向的强度和刚度几乎与之成正比）、正确的**取向**、让树脂**到达包括每根丝束内部在内的每个地方**、并且**没有空隙、没有褶皱、没有富树脂袋**的战斗。工艺只有两个家族，而家族之间的选择是复合材料设计中最大的单一决定。

**湿法工艺：树脂以液体进入干纤维。**手糊和喷射（一个工人一把刷子做 1-2 m²/h，纤维 25-30 %，苯乙烯排放使它成为受监管职业）、**树脂传递模塑**（干纤维放在夹紧闭钢模中，树脂以 2-10 bar 在 5-30 分钟内注入，一副 10,000 模次的模具 £300-800k，从 3 分钟的汽车件到 30 分钟的航空件之间任何地方的首选工艺）、**真空辅助树脂传递模塑**（单面模具上干布层叠，脱模布、导流网、真空袋和真空，树脂以 1 bar 压差在 2-8 小时内被吸入，做出 60 m 风机叶片壳体和船体的工艺），以及**薄膜辅助灌注**的各种变体。**它们全部的物理都是达西定律穿过纤维床，**

$$
\mathbf { v } \; = \; - \, { \frac { \mathsf { \mathbf { K } } } { \phi \, \mu } } \, \nabla p \qquad \Longrightarrow \qquad L \; = \; { \sqrt { \frac { 2 \, K \, \Delta p \, t } { \phi \, \mu } } } \qquad \Longrightarrow \qquad t \; = \; { \frac { \phi \, \mu \, L ^ { 2 } } { 2 \, K \, \Delta p } }
$$

**渗透率 $\mathsf { K }$ 在真实预制体上跨越十四个数量级：丝束内部 $1 0 ^ { - 1 5 } \ \mathrm { m ^ { 2 } }$ ，织物丝束之间横向 $1 0 ^ { - 1 2 } \ \mathrm { m ^ { 2 } }$ ，单向对齐预制体纵向 $1 0 ^ { - 9 } \ \mathrm { m ^ { 2 } }$ ，专用导流介质内 $1 0 ^ { - 7 } \ \mathrm { m ^ { 2 } }$ 。****所以流动前沿随时间的平方根推进，而不是随时间，而且沿导流介质比横穿织物快 1000 倍——这就是为什么每次灌注都有分布介质，为什么流动前沿是椭圆，为什么最后填满的永远是你没放排气口的那个角。**

**干法工艺：树脂已经在了。****预浸料**——连续纤维在工厂预浸 B 阶段环氧至重量 30-35 %，$- 1 8 \ \mathrm { ^ \circ C }$ 冷藏，保质期六个月，室温"外放时间"10-30 天——手工或机器铺入模具，盖上脱模布、吸胶毡、导流网和真空袋，在**高压釜**中以 6 bar 氮气和 $1 2 0 { - } 1 8 0 \ \mathrm { ^ \circ C }$ 固化 1-2 小时。**它给出 60 % 纤维、0.5-1 % 空隙、厚度公差 3 % 的 1.5 mm 板、可重复的结构性能——这就是为什么 1985 年以来每一架飞机的主承力结构都这样制造，也是为什么它贵：材料价格是湿法树脂加纤维的三倍，高压釜 £5-30 M、每公斤零件耗 3-5 kWh，一天一炉就是好周。****非高压釜预浸料**在烘箱里用一巴真空袋做同样的事，其全部技术依据是**在树脂凝胶之前压实层压板**——一个 30-60 分钟的窗口，在此期间真空袋必须在黏度仍在下降时挤出每一个空隙——空隙含量 1.5-2.5 % 对高压釜的 0.5-1 %，每 1 % 空隙约损失 10 % 的层间剪切强度。

**湿法工艺核心的、不留情面的问题是两股流同时发生而速度不同。**树脂沿丝束**间**通道（渗透率 $1 0 ^ { - 9 } \ \mathrm { m ^ { 2 } }$ ）狂奔，而丝束**内**的孔隙（$1 0 ^ { - 1 5 } \ \mathrm { m ^ { 2 } }$ ）只能靠纤维束自身的毛细压力填充，那至多几个 bar。**让宏观流动前沿 30 分钟到达真空口，丝束里还有 2 % 的空气，而一旦凝胶开始，之后多大的真空都除不掉它。**对策全在两股流的比值上：$1 0 0 { - } 2 0 0 \ \mathrm { m P a \, s }$ 而不是 400 的树脂、让纤维表面可润湿的纤维**浸润剂**、模具充满后真空下 30-60 分钟的**浸渍**，以及**最后一个小时把模具背压到 2-6 bar**——这正是现代叶片根灌注周期实际做的事。
:::

::: example 从未填满的丝束 {#ex-infuse level=4 check="78"}
一束碳纤维 5 mm 宽。其**丝束内**渗透率 $1 0 ^ { - 1 5 } \ \mathrm { m ^ { 2 } }$ ，树脂黏度 $0 . 3 \ \mathrm { P a \, s }$ ，纤维束表面可用的毛细压力 2 bar。这束丝要多久才能浸透？

$$
t \; = \; { \frac { \mu \, L ^ { 2 } } { 2 \, K \, \Delta p } } \; = \; { \frac { 0 . 3 \times 0 . 0 0 2 5 ^ { 2 } } { 2 \times 1 0 ^ { - 1 5 } \times 2 \times 1 0 ^ { 5 } } } \; = \; { \frac { 1 . 8 8 \times 1 0 ^ { - 6 } } { 4 \times 1 0 ^ { - 1 0 } } } \; = \; 4 6 9 0 \ \mathrm { s } \; = \; { \bf 7 8 \ m i n }
$$

**5 mm 的丝束靠毛细作用填满要七十八分钟——而模具的流动前沿 35 分钟就到了真空口。****一行算式就是"干丝束"问题的全部，它解释了灌注实践的四个事实。为什么快速灌注做出的零件通过一切目视和尺寸检查，而冲击后压缩却以许用值的 60 % 破坏。为什么周期在模具充满后还要有一个小时的"浸渍"保温。为什么树脂黏度是技术数据表上争论最多的性能，为什么灌注树脂被配成 100-200 mPa·s 而不再低，因为再低树脂就沿导流介质排走、把织物丢在身后。以及为什么无法接受主承力结构中 2 % 丝束内空隙的航空工业，仍然为高压釜付钱。**
:::

::: definition 铺放纤维：手工、机器与铺层表 {#def-placement}
**铺层表是复合材料零件的源代码。**层压板以铺层取向和厚度的叠层规定——翼面蒙皮写作 `[148/45/-45/0₂/90/0₂/-45/45/148₁₆]` ——而规则像任何公差一样严格：**均衡**（每个 $+ 4 5 ^ { \circ }$ 配一个 $- 4 5 ^ { \circ }$ ，否则零件受拉时扭转）、**关于中面对称**（否则固化时卷曲，这与不对称焊缝是同一个热残余应力论证）、**同向铺层相邻不超过四层**（否则分层韧性崩溃、屈曲波形无人阻止）、**表面层至少 $1 0 \ \ \%$ 取 $\pm 4 5 ^ { \circ }$** （把表面压住以抵抗受压屈曲），以及**每个铺层削减取 20:1 的斜率**（厚度的阶跃变化是分层的起点，航空不接受每层削减少于 20 层的过渡；汽车以它的 3 分钟周期接受 6:1，并在疲劳上付出代价）。

**干布的手糊**是每人每小时 1-2 m²，纤维 25-35 %，强度取决于操作员，空隙含量没人测。**自动铺带（ATL）**以 10-15 m/min 铺放 75-300 mm 宽的预浸带，热辊在线压实，它造出飞机机身筒段：787 的前机身是四台 ATL 机器连续运行数周，把 300 mm 的带铺到 6 m 直径的型架上。**自动铺丝（AFP）**最多同时铺放 32 根丝束，每根 3.2-6 mm 宽、各自独立定角，依曲率以 1-7 m/min 铺到五轴型架或型芯上。**它独一无二的能力是变曲率纤维：丝束角度每 25 mm 改变 1°，力流可以绕着孔或舱门开口走，而不是被它们切断，值一副机翼 10-20 % 的重量。**它的特征缺陷同样独一无二：相邻丝束间的**间隙与搭接**、**饥饿**（变曲率丝束在凹面上离开模具形成的富树脂三角）、以及跨角的**搭桥**。**宽到留下 1 mm 树脂条的丝束间隙，损失局部压缩强度的 10-20 %，而隆起丝束下的富树脂袋是裂纹起点。**

**干法预制**是让灌注经济的原因：**无纬布**（0°、90°、±45° 的单向层用线缝在一起，300-1200 gsm，比同性能机织布便宜 20 %、压缩性能好 10 %，因为纤维不弯曲）、**2.5-D 织造**（经纱环状穿过厚度，织物剪开不散、能铺覆 300 mm 半径）、**3-D 织造与编织**（真正的厚度方向纤维，把 I 型断裂韧性乘以三到五倍，也是做出可钻孔复合材料零件的唯一办法），以及**热塑性网状粘结剂**（铺层间撒 3 % 聚乙烯粉末，熔化后把叠层固定在一起）。**这些无一例外地损失纤维方向的强度、买来损伤容限，而这正是一个设计者应当有意识地在做的权衡。**

**完全不是铺层的工艺：****缠绕**（浸胶丝束以计算角度绕到旋转芯轴上，1-3 m/min，它做出世上每一个压力容器、火箭发动机壳体和管材，因为它是唯一把纤维恰好放在环向应力处的工艺）；**拉挤**（纤维连续拉过树脂槽、预成型模具和 5-10 m 长的加热模具，$0 . 5 { - } 5 \ \mathrm { m / m i n }$ ，出来的是**60-70 % 纤维**的等截面型材，是所有结构工艺中最高的比强度和比刚度——拉挤碳板纤维方向的性能在高压釜预浸料的 10 % 以内而价格五分之一，它的弱点是垂直纤维的一切只有三分之一强，而且零件必须是直棱柱）；**编织**（纤维锭围绕移动芯轴旋转，做出 ±(20-70)° 无缝的管或梁）；以及**热塑性复合材料**，工业当前的痴迷，因为 PEEK、PEKK 或 PP-碳带**没有保质期、没有冷库、没有固化反应、没有高压釜**，可以**焊接**而不是螺接或共固化，可以**5 分钟周期成型**，原则上可以**重熔回收**——代价是熔体黏度太高，浸渍一束纤维要几分钟而不是几秒钟，加工温度 $4 0 0 \ \mathrm { ^ \circ C }$ 。
:::

## 6. 出什么错、怎么发现、代价几何

::: definition 缺陷清单，以及真正杀死结构的三个 {#def-defects}
复合材料或模塑件里几乎可以有任何东西，而工业界已经——昂贵地、主要从飞机上——学会了：多数缺陷无害，少数不是。

**大体无害：**1 % 以下的气孔；一条富树脂带；颜色或光泽差异；顶出痕迹；非可见面 0.1 mm 深的缩痕；表面的一根纤维头；搭桥铺层引起的轻微厚度变化。**严重：**一个**干斑**（未浸渍区，一个尚未开始的分层）；一个**厚度方向的褶皱**；**超过 2 % 的空隙**；铺放层压板中的**间隙或搭接**；一个**外来物**（吸胶毡纤维、一片脱模膜、一只手套——机身蒙皮报废的经典原因）；一个**吻合粘接**（面对面接触、不传递拉力、在穿透法超声扫描上什么都不显示）。

**杀死结构的是褶皱、分层和冲击这三个。**

**褶皱。**压缩翼缘中一个 5° 的面外纤维褶皱——来自跨圆角搭桥的铺层、错位的带、或被铺覆而非裁剪的预制体——**把压缩强度降低 40-60 %**，其机理是让纤维在零件其余部分还在 0.1 % 应变时就在 0.2 % 应变下局部屈曲。**它几乎不可见，穿透法超声扫描几乎看不见它，它是研制阶段复合材料结构试验失败的头号原因。**对策是几何的（圆角半径至少为层压板厚度的 5 倍，铺层削减斜率）、程序的（按样板做**满贴**而不是**贴模**铺放，用**格构**或**剪口**让织物剪切而不屈曲），以及检测的（验证载荷下的**数字图像相关**应变图，褶皱在开裂之前很久就显示为应变异常）。

**几乎不可见的冲击损伤。**一把掉落的扳手、一次工装坠落、一场冰雹、一块跑道石子。**主承力结构的设计要求是：2 mm 板上的 6.5 J 冲击（3.25 J/mm）——留下一个要用指甲摸才感觉到的凹坑——不得把压缩强度降低一半以上。**实际上通常就是降低一半以上：损伤是 3 mm 凹坑下**一个 15-25 mm 宽的亚表面分层**，冲击点处一条**横向纤维裂纹**，冲击后压缩强度从 500 MPa 跌到 240-300 MPa。**这就是为什么每架复合材料机体都有一项用敲击检测和超声扫描组成的成文检测任务，为什么复合材料结构按"无扩展"或"安全寿命"哲学而不是金属结构的"裂纹扩展"哲学设计，也是为什么关于 787 的最大技术争论不是重量而是检测间隔。**

**分层**是复合材料自己的失效模式，因为厚度方向除了树脂什么都没有。它的抗力：增韧航空环氧的 $G _ { \mathrm { I C } } = 3 0 0 { - } 5 0 0 \ \mathrm { J / m ^ { 2 } }$ （脆性树脂是 100，这就是 1970 年代的硼纤维和早期碳纤维层压板作为结构如此令人失望的原因），提高它靠树脂热塑性颗粒增韧、靠共固化而不是二次胶接、靠厚度方向纤维，以及靠 **Z 向钉扎**——以 5 mm 间距把 0.2 mm 的钉打入厚度方向，损失 3 % 的压缩强度，换来两倍的裂纹扩展寿命。

**还有环境。**复合材料的许用值以**"热湿"**状态给出：1 % 吸水率、$9 0 \ \mathrm { ^ \circ C }$ ，此时基体接近其玻璃化转变，压缩强度比干态低 30-50 %，开口强度低 25 %。**一个被螺丝刀撬过、用错砂轮片打磨过、或泡在舱底水里的层压板是另一个结构。而碳纤维对铝是一个电偶对，在盐水里有 0.6 V 的驱动力：隔离物是一层玻璃布、一条密封胶条，加上金属上的阳极氧化加底漆——这是每架复合材料机体上被重复最多的维护指令。**
:::

::: definition 检测与成本：争论真正所在 {#def-econ}
**检测。**主力是**穿透法超声**：零件两侧一对 1-5 MHz 水浸换能器，水耦合，以 0.5-1 m²/min 扫描，给出 **C 扫描图**，分层是一团黑、干斑是一片边缘模糊的黑区。它能发现任何反射或吸收声音的东西——除了**吻合粘接**和**平行于表面的平面褶皱**——正是这两种缺陷推动了二十年的非线性超声、红外热成像研究，以及生产中的**在线监测**（模具里的介电或超声传感器实时监视树脂流动和固化，如今在叶片根灌注线上已是标配）。**敲击检测**——一枚硬币，或一把带加速度计的标准小锤——在训练有素的检测员手里能发现 2 mm 表面下 20 mm 的分层，而它是世界上大多数复合材料结构得到的唯一检测。**验证试验**（加载到 1.2 倍限制载荷，带应变片和声发射监测）抓住粗大的制造错误，而**每一高压釜炉次随炉牺牲板的剩余强度试验**把零件与工艺绑在一起。

**成本。**诚实的数字，按每公斤成品结构：**钢 £1.5-2，铝 £6-10，机加钛件 £150-400，湿法缠绕碳管 £25-50，灌注成型碳板 £60-120，高压釜固化预浸料主承力结构 £150-300。****纤维占材料成本的 50-70 %**（标准模量航空碳丝束 £20-30/kg，汽车中模量 £12-20，风机丝束 £8-12，环氧树脂 £6-10，干玻璃布 £2-3），而**低批量时人工占一切成本的 60-70 %**。由此得出决定每个复合材料商业案例的交叉点：

$$
c ( N ) \; = \; { \frac { F _ { \mathrm { t o o l } } } { N } } + c _ { \mathrm { u n i t } } \qquad \text{with} \qquad F _ { \mathrm { t o o l } } ^ { \mathrm { s t e e l } } \approx 1 . 5 \times 1 0 ^ { 6 } , \quad c _ { \mathrm { u n i t } } ^ { \mathrm { s t e e l } } \approx \pounds 4 5
$$

**一块冲压钢外板 £45 一件、配 £1.5 M 的冲压模具；复合材料等价件 £180 一件、配 £400 k 的高压釜模具。复合材料模具在任何批量下都便宜，而复合材料零件贵四倍——所以复合材料住在每个市场的低批量、高价值角落里，而走出那个角落的唯一办法是更短的固化，不是更便宜的纤维。****这就是"为什么没有碳纤维汽车"问题的真正内容：不是 £20/kg 的纤维，而是 15 分钟的固化对 4 秒的冲压行程、年产 2 万的产线对年产 30 万的产线，以及一个不能用锤子、点焊机和腻子修理的总装车间。**
:::

## 习题

::: exercise 剪切变稀 {#ex-pl level=2 check="126"}
某种尼龙 6,6 熔体的幂律指数 $n = 0 . 3 0$ 。它在 $1 0 { , } 0 0 0 \ \mathrm { s ^ { - 1 } }$ 下的表观黏度比 $1 0 \ \mathrm { s ^ { - 1 } }$ 下低多少倍？（倍数取整作答。）
::: solution
$\eta ( 1 0 ^ { 4 } ) / \eta ( 1 0 ) = ( 1 0 ^ { 3 } ) ^ { \, n - 1 } = 1 0 ^ { 3 \times ( - 0 . 7 0 ) } = 1 0 ^ { - 2 . 1 } = 1 / 1 2 6$ ，所以倍数为 ${ \bf 1 2 6 }$ 。**剪切速率换两个半数量级，黏度就换两个半数量级——这就是为什么注塑机能以 100 Pa·s 的熔体通过 0.4 mm 浇口而不用液压机，也是为什么模流分析里的"黏度"是一个有 40 个值的场，不是一个数。**
:::
:::

::: exercise 壁厚的决定 {#ex-wall level=2 check="8.8"}
一个零件以 $4 \ \mathrm { m m }$ 壁厚成型时冷却时间 18 s。用加强筋重新设计，壁厚可在同样刚度下降到 $2 . 8 \ \mathrm { m m }$ 。新的冷却时间是多少？（以秒作答，保留一位小数。）
::: solution
$t \propto s ^ { 2 }$ ，所以 $t = 1 8 \times ( 2 . 8 / 4 ) ^ { 2 } = 1 8 \times 0 . 4 9 = { \bf 8 . 8 \ s }$ 。**26 s 周期上省下九秒就是 35 % 的增产，代价是一组筋而不用新的模具钢——这就是为什么零件的模流评审几乎总是关于筋的谈话，为什么"做均匀、做薄"是每本模塑设计指南的第一句话。**
:::
:::

::: exercise 吹膜取向 {#ex-bur level=3 check="24"}
一个薄膜口模平折宽 $6 0 \ \mathrm { m m }$ ，膜泡被压平到 $1 8 0 \ \mathrm { m m }$ ，牵引机把薄膜拉薄到口模间隙的八分之一。求吹胀比、牵引比和总面积拉伸比。
::: solution
$\mathrm { B U R } = 1 8 0 / 6 0 = 3$ （环向取向），$\mathrm { T U R } = 8$ （纵向取向），面积拉伸比 $3 \times 8 = { \bf 2 4 }$ 。**二十四倍，按 3:8 分配在两个方向——这就是为什么背心袋沿机器方向撕开而不横向撕开，为什么"均衡"薄膜需要 BUR × TUR 在应用允许下尽量均分，也是为什么这两个比是薄膜厂仅有的两个性能控制。**
:::
:::

::: exercise 挤出机能耗 {#ex-se level=2 check="0.2"}
一台 30 kW 驱动的单螺杆挤出机以 $1 5 0 \ \mathrm { k g / h }$ 运行。其比机械能是多少 kWh/kg？
::: solution
$\mathrm { S M E } = 3 0 / 1 5 0 = { \bf 0 . 2 \ k W h / k g }$ 。**对尼龙约 $0 . 1 7 \ \mathrm { k W h / k g }$ 的热力学最低限度来说，这是一台泵送良好的挤出机；对聚乙烯（熔化焓小、$c _ { p } \Delta T$ 短）的 $0 . 0 5 { - } 0 . 0 8 \ \mathrm { k W h / k g }$ 来说，它是一台浪费的。先问这个数字再问产量：屏障螺杆、更深的流道和冷却料筒通常能砍掉 15-25 %。**
:::
:::

::: exercise 热成型拐角厚度 {#ex-thermo level=3 check="1.5"}
一张 $3 \ \mathrm { m m }$ 的 ABS 板成型为 $2 0 0 \times 2 0 0 \ \mathrm { m m }$ 、深 $1 5 0 \ \mathrm { m m }$ 的矩形盒。拐角处局部拉深比为 4。用 $t = t _ { 0 } / { \sqrt { D } }$ 估算拐角厚度。（以 mm 作答，保留一位小数。）
::: solution
$t = 3 / { \sqrt { 4 } } = { \bf 1 . 5 \ m m }$ 。**拐角处壁厚减半，而那里正是零件受载之处、筋焊接之处，也是真空成型刚刚做出的零件上最弱的一平方毫米。助压塞、机械对模、或让片材在接触前先滑动的更深圆角，能买回 30-50 %；一个指定 3 mm 板做 150 mm 深盒而没问过这个问题的设计者，指定的是一个会在拐角开裂的零件。**
:::
:::

::: exercise 丝束浸渍 {#ex-tow level=4 check="10.4"}
在上面的丝束浸渍算例中，树脂黏度 $0 . 3 \ \mathrm { P a \, s }$ ，毛细压力 2 bar。如果树脂加热到 $0 . 1 \ \mathrm { P a \, s }$ 、模具背压到 5 bar，78 分钟的丝束填充时间变成多少？（以分钟作答。）
::: solution
$t \propto \mu / \Delta p$ ，所以 $t = 7 8 \times ( 0 . 1 / 0 . 3 ) \times ( 2 / 5 ) = 7 8 \times 0 . 1 3 3 = { \bf 1 0 . 4 \ m i n }$
:::
:::

::: exercise 纤维体积分数 {#ex-vf level=2 check="2"}
一个手糊层压板纤维体积分数 30 %，一个预浸料层压板 60 %。按 $E _ { 1 } \approx V _ { f } E _ { f }$ ，两者纤维方向模量之比是多少？
::: solution
$6 0 / 3 0 = { \bf 2 }$ 。**同样厚度两倍刚度，压缩和疲劳强度也大约两倍——这就是为什么"同样的层压板，手糊的"不是同一种材料、也永远不可能是。等刚度下的重量惩罚也约 2:1，因为多出的厚度主要是树脂，它在纤维方向几乎不贡献什么、在重量上贡献一切。**
:::
:::

::: exercise 推导平方律 {#ex-derive-cool level=4 check="4"}
从 $t _ { \mathrm { c o o l } } = ( s ^ { 2 } / \pi ^ { 2 } \alpha ) \ln [ ( 8 / \pi ^ { 2 } ) ( T _ { \mathrm { m e l t } } - T _ { w } ) / ( T _ { e } - T _ { w } ) ]$ 出发，证明几何相似零件的冷却时间按 $s ^ { 2 }$ 变化，并求壁厚减半时它变化的倍数。（以倍数作答。）
::: solution
对数里的每一项都是温差，没有一项随零件尺寸缩放，所以同温下几何相似零件的整个括号是常数，$t \propto s ^ { 2 } / \alpha$ 。壁厚减半得倍数 ${ \bf 4 }$ 。**同样的论证用于任何扩散控制的过程：25 mm 壁厚不是 4 mm 的六倍周期而是四十倍，而"零件太贵"的答案几乎总在图纸上。**
:::
:::

::: exercise 推导灌注定律 {#ex-derive-darcy level=4 check="4"}
对孔隙率 $\phi$ 的预制体在一维、恒压下浸渍积分达西定律，写出灌注时间对 $\mu$ 、$L$ 、$K$ 、$\Delta p$ 的依赖。如果树脂黏度从 $0 . 4$ 降到 $0 . 1 \ \mathrm { P a \, s }$ ，时间降多少倍？
::: solution
达西速度 $v = - ( K / \phi \mu ) \, \mathrm { d } p / \mathrm { d } x$ ；前沿在 $L$ 处压降固定为 $\Delta p$ ，梯度为 $\Delta p / L$ ，所以 $\phi \, \mathrm { d } L / \mathrm { d } t = K \Delta p / ( \phi \mu L ) \times \phi$ ，即 $L \, \mathrm { d } L = ( K \Delta p / \phi \mu ) \, \mathrm { d } t$ ，得

$$
L ^ { 2 } = { \frac { 2 K \Delta p } { \phi \mu } } \, t \qquad \Longrightarrow \qquad t = { \frac { \phi \, \mu \, L ^ { 2 } } { 2 K \, \Delta p } }
$$

**时间与黏度成正比、与距离的平方成正比、与驱动压力成反比。**倍数为 $0 . 4 / 0 . 1 = { \bf 4 }$ 。**这就是为什么灌注温度下、在该温度下放置 30 分钟后测得的树脂黏度，是决定一副模具能否被填满的数字——也是为什么真空从 0.5 倍到 1 bar 只买两倍，而把树脂加热 $2 5 \ \mathrm { ^ \circ C }$ 能买四倍。**
:::
:::

::: exercise 玻璃化 {#ex-vitr level=3 check="80"}
另一种环氧 $T _ { g 0 } = 0 \ \mathrm { ^ \circ C }$ ，$T _ { g \infty } = 2 1 0 \ \mathrm { ^ \circ C }$ ，$\lambda = 0 . 5$ ，在 $1 4 0 \ \mathrm { ^ \circ C }$ 固化。它能达到的最大固化度是多少？（以百分数作答。）
::: solution
令 $T _ { g } = 1 4 0 \ \mathrm { ^ \circ C }$ 得 $1 4 0 / 2 1 0 = 0 . 6 6 7 = 0 . 5 \alpha / ( 1 - 0 . 5 \alpha )$ ，所以 $0 . 5 \alpha = 0 . 6 6 7 - 0 . 3 3 3 \alpha$ ，$\alpha = 0 . 6 6 7 / 0 . 8 3 3 = { \bf 0 . 8 0 }$ ，即 ${ \bf 8 0 \ \% }$ 。**剩下的 20 % 在那个温度下永不反应。$1 9 0 \ \mathrm { ^ \circ C }$ 后固化把同一个零件带到 $\alpha = 0 . 9 5$ 、$T _ { g } \ 1 9 0 \ \mathrm { ^ \circ C }$ ，两种状态之间差的是热湿压缩强度的 40 % 和耐溶剂性的全部。**
:::
:::

::: quiz 一个模塑件内部凸台上方有 0.3 mm 的缩痕。哪个改动从根源上解决它？ {#quiz-sink}
- [ ] 保压压力提高 20 %
- [ ] 保压时间延长 3 s
- [x] 把凸台掏空，其筋降到壁厚的 60 %
- [ ] 熔体温度提高 15 °C
::: solution
**缩痕是一个厚截面在收缩而身后没有东西补料，所以对策是几何的。加大保压只在浇口冻封之前有效，而浇口一旦冻结（这就是保压时间按浇口冻结时间设定的原因），额外压力只让零件更重、应力更高、脱模更难。更热的熔体收缩更多而不是更少。掏空凸台移除了引起缩痕的那个收缩材料库——而且免费，因为它是一次图纸改动。**
:::
:::

::: quiz 一个灌注成型件通过一切目视检查，但冲击后压缩以许用值的 60 % 破坏。最可能的原因是什么？ {#quiz-void}
- [ ] 模具温度太低
- [ ] 纤维体积分数太高
- [x] 灌注太快导致纤维丝束内部干芯
- [ ] 树脂过固化
::: solution
**宏观流动前沿到达了每个浇口，所以零件看着是湿的；但丝束内渗透率比丝束间低一百万倍，前沿一快束束就没填满。丝束内空隙是压缩和冲击后压缩不达标、其余一切正常的经典原因。模具温度低只减慢固化而不留空隙；高纤维分数提高强度；过固化是另一种失效（脆，表现为延伸率低）。****诊断方法是金相切片——抛光腐蚀后的见证板切片中，干丝束显示为一圈未填充纤维丝的白色环——而对策是更慢的前沿、更低的黏度、浸渍保温和背压。**
:::

## 本讲的后续内容

- **[[materials-science/material-families|材料家族]]**是聚合物家族、它们的 $T _ { \mathrm { g } }$ 和 $T _ { \mathrm { m } }$ 以及耐化学性的来源；本讲讲它们在 $2 5 0 \ \mathrm { ^ \circ C }$ 和 1000 bar 下发生了什么。
- **[[heat-transfer/transient-conduction|非稳态导热]]**是本讲每一个冷却时间、周期时间和固化升温数字背后的数学——傅里叶数就是注塑经济学的全部。
- **[[fluid-mechanics/fluid-properties|流体性质]]**和 **[[fluid-mechanics/pipe-flow|管流]]**提供幂律熔体打破的压降机器；第 3 节的口模设计就是把 $\mu$ 换成 $K { \dot { \gamma } } ^ { n - 1 }$ 的哈根-泊肃叶。
- **[[materials-science/phase-transformations|相变]]**是聚合物结晶的阿夫拉米动力学，这就是模具冷却速度决定半结晶零件的收缩、雾度和耐化学性的原因。
- **[[solid-mechanics/composites|复合材料]]**是铺层表所依据的力学——经典层压板理论、$A B D$ 矩阵、蔡-吴和 Puck 判据，以及第 6 节分层背后的能量释放率。
- **[[materials-science/failure|失效]]**涵盖热塑性零件的蠕变、应力开裂和疲劳，以及层压板的亚临界分层扩展。
- **[[manufacturing/additive-manufacturing|增材制造]]**是第 2 节随形冷却镶件被打印出来的地方，也是同样的热塑性和热固性化学以丝材、光敏树脂或粉末床的形式出现的地方。
- **[[manufacturing/metrology-quality|计量、质量与自动化]]**是 C 扫描、在线视觉和 200 万模次模具统计过程控制所在的地方。
- **[[materials-science/corrosion|腐蚀]]**涵盖碳纤维对铝的电偶对，以及使每种环氧在使用中增塑的水分。

**1839-1844。** **查尔斯·固特异（Charles Goodyear）**在负债入狱十年之后，发现天然橡胶与硫黄混合加热后变成一种热不软、冷不脆的材料；1844 年的专利让**硫化**成为一种工艺，并创建了一个 180 年后仍在争论固化曲线的行业。**1862。** **亚历山大·帕克斯（Alexander Parkes）**在伦敦国际博览会上展示"帕克辛"——一种从口模挤出的硝化纤维清漆，历史上第一次聚合物**挤出**。**1870。** 海厄特（Hyatt）的**赛璐珞**带来热塑性塑料 120-150 °C、20 MPa 的**模压**，做出了台球、梳子，二十年后还有照相胶片。**1907-1912。** **利奥·贝克兰（Leo Baekeland）的电木（Bakelite）**：酚醛树脂被驱动到 **B 阶段**，再在加热模具中受压固化——第一种完全合成的热固性材料、第一种无法熔化的材料，以及"模塑料"一词的诞生。**1920-1935。** **施陶丁格（Staudinger）**让化学界相信聚合物是一个一万原子长的**分子**而不是胶体，本讲的每一句话都建立在这一发现之上；**杜邦的卡罗瑟斯（Carothers）**主持的工作产出**氯丁橡胶**（1931）和**尼龙 6,6**（1935），*纺、挤、拉*成为工业动词。**1933-1940。** ICI 的**吉布森（Gibson）和福西特（Fawcett）**在 1400 bar、170 °C 下意外做出**聚乙烯**（1933）；为英国皇家空军做**雷达电缆绝缘**使它到 1940 年成为大宗商品，吹膜和塑料袋十年内随之而来。**1941-1953。** **温菲尔德（Whinfield）和迪克森（Dickson）**在印花厂协会为聚对苯二甲酸乙二醇酯申请专利（1941）；**杜邦**买下许可，花十年解决染色问题并推出**达可纶（Dacron）**（1953），把一种脆性瓶用树脂变成地球上学量最大的纤维。**1953-1955。** **卡尔·齐格勒（Karl Ziegler）**发现了制造线型聚乙烯的金属有机催化剂，**朱利奥·纳塔（Giulio Natta）**把同样的化学变成等规聚丙烯；两人共享 1963 年诺贝尔奖，合起来占今天全部塑料产量的一半。**1946。** **詹姆斯·沃森·亨德里（James Watson Hendry）**造出第一台**往复螺杆注塑机**：第一次由一根螺杆完成熔化、混合和计量，熔体均匀出来，薄壁和玻纤填充成型成为可能，注塑成为它今天的模样。**往复螺杆之于塑料，如同药皮焊条之于焊接。****1940-1950 年代。** **玻璃纤维走向结构**：战时雷达整流罩、1950 年代的玻璃钢船热潮、**缠绕成型的**北极星导弹壳体（1959）——第一种从纤维向外设计、而不是从实心向内机加的结构。**1960 年代。** **航空预浸料体系**围绕商业上失败的**硼纤维**被发明：**高压釜固化、脱模布、吸胶毡、真空袋、C 扫描和许用性能体系**都始于它，今天每一副在役结构复合材料都还在使用它们。**1961-1972。** 联合碳化物的**罗杰·培根（Roger Bacon）**以拉伸人造丝前驱体制出高模量碳纤维（1961）；**东丽（Toray）铃木修（Osamu Suzuki）**的团队在日本把 **PAN** 路线工业化（1969-71），1972 年波音购买东丽纤维用于 737 的客舱地板——230 GPa 标准模量 PAN 纤维的起点，787 就建在它上面。**1969。** **波音 747** 带着硼增强长桁首飞，复合材料重量占比不到 1 %，工业界由此断定复合材料是小众、低速、昂贵的材料；这个结论它守了二十年。**1966-1988。** **模塑革命**：热流道、施乐公司 **H. M. 奥特沃特（H. M. Outwater）**1966 年的计算机模拟充填、**王（Wang）和肯尼迪（Kennedy）**成为工业模流软件的模型、阀式浇口、**结构发泡**和**气辅**工艺，以及模具前门的机器人，它把操作员从周期中拿走、把周期时间砍掉三分之一。**1983-1988。** **空客 A310-300 的碳纤维垂尾**（1983），随后 **A320** 的水平尾翼：客机上第一批碳纤维预浸料主承力结构，"重量占比 50 %"轨迹的起点。**1988-1995。** **闭模工艺上岸**：科尔维特车身的树脂传递模塑（1972 年起）、1980 年代末的 **SCRIMP** 和 **VARTM** 专利，以及最终杀死开放手糊的排放法规——被苯乙烯赶出车间的空气，正如被零件握在手里。**1990-2000 年代。** **风机叶片**从 20 m 手糊长到 60 m 灌注壳体，一次走完树脂路径、六小时固化：按体积史上最大的复合材料结构，也是这个行业的廉价丝束需求让碳纤维对航空变得负担得起的行业。**2008。** **波音 787** ：重量 50 % 复合材料，机身筒段在四个自动化单元中铺放缠绕、在史上最大高压釜中固化，第一架按**几乎不可见损伤**要求而不是裂纹止裂要求认证的机体。**2013。** **宝马 i3** 带着 4 分钟湿法模压和 24 小时成车结构上市，商业上失败——关于"一种能快速制造的材料"与"一家能快速制造的工厂"之差，史上最贵的一课。**2013-2015。** **空客 A350 XWB** 首飞并以 53 % 复合材料投入服役，翼面盖板宽 7 m、长 50 m，问题从"能不能做"变成"能不能每月六十架地做"。**2000-2020 年代。** **热塑性的转向与清算**：非高压釜预浸料固化了风机行业的叶片成本，激光焊和超声焊热塑性机体走出演示阶段，每年 4 亿吨聚合物被生产出来，而累计回收率只有 9 %——人们发现，一种设计为在 250 °C 成形一次的材料，极难再成形一次。
:::

::: summary
**聚合物熔体是剪切变稀、弹性、温度敏感、拉伸变硬的，其德博拉数从不低于 1 太多。**$\eta = K { \dot { \gamma } } ^ { \, n - 1 }$ ，$n = 0 . 2 { - } 0 . 8$ ，所以熔体在料筒与浇口之间变稀 30-100 倍；$\eta \propto \exp ( E _ { \eta } / R T )$ ，所以 $2 0 \ \mathrm { ^ \circ C }$ 就是一倍；熔体会膨胀、爬棒、记仇。**不存在单一的黏度。**
**注塑是三十秒里的四种工艺，而冷却占其中 60-70 %。**$t _ { \mathrm { c o o l } } = ( s ^ { 2 } / \pi ^ { 2 } \alpha ) \ln [ { \frac { 8 } { \pi ^ { 2 } } } ( T _ { \mathrm { m e l t } } - T _ { w } ) / ( T _ { e } - T _ { w } ) ]$ ，每种塑料都有 $\alpha \approx 0 . 1 \ \mathrm { m m ^ { 2 } / s }$ ，而壁厚是周期的**平方**。均匀壁厚、用筋不加厚、模温在图纸上选定。
**喷泉流把零件的各向异性写进零件。**一层冻结表皮、一层取向剪切层、一个横向芯层；沿流动 0.3 %、垂直 0.9 % 的收缩；含玻纤时只有基体强度 20-40 % 的熔接线；以及最后冻结点在哪就在哪的缩痕。**先挪厚截面，再挪浇口，最后才跟机器吵架。**
**挤出是一台三机合一的螺杆和一个压降口模。**拖曳流减压流对抗 $Q \propto \Delta p / \mu$ ，一个随黏度移动的工作点，一个离模膨胀 20-100 %、必须靠牵引拉回来补偿的熔体，以及一个表面开始破坏的 $0 . 1 \ \mathrm { M P a }$ 壁面剪切应力上限。
**热固性材料是与自身凝胶点的赛跑，胜负在玻璃化转变。**$\mathrm { d } \alpha / \mathrm { d } t = ( k _ { 1 } + k _ { 2 } \alpha ^ { m } ) ( 1 - \alpha ) ^ { n }$ 每 $2 0 \ \mathrm { ^ \circ C }$ 翻倍、放出 $5 5 0 \ \mathrm { J / g }$ ，并**在 $T _ { g }$ 到达固化温度时停止**——所以 $1 2 0 \ \mathrm { ^ \circ C }$ 固化永不超过 77 %，固化到时间而不是状态的零件遇热就坏。
**复合材料是把树脂送进丝束，而两股流相差一百万倍。**达西给出 $L \propto { \sqrt { K \Delta p t / \phi \mu } }$ ，丝束间渗透率 $1 0 ^ { - 9 } \ \mathrm { m ^ { 2 } }$ 、丝束内 $1 0 ^ { - 1 5 } \ \mathrm { m ^ { 2 } }$ ，所以快前沿做出看着湿、束束干的零件；对策是浸渍、低黏度和背压。
**三个缺陷杀死结构：褶皱、分层和冲击。**5° 褶皱损失一半压缩强度而什么都显示不出；6.5 J 坠落做出看不见的 20 mm 分层、冲击后压缩减半；许用值按热湿给出是有原因的。
**复合材料的成本是固化，不是纤维。**丝束 £20/kg，固化后的高压釜件 £150-300/kg，低批量时人工占成本 60-70 %，与冲压钢在 8,000 件/年的交叉点，从未被任何更便宜的纤维移动过。
:::

## 延伸阅读

- J. R. T. Dealy 和 K. F. Wissbrun 著，*Melt Processing of Polymers*，Hanser，1999 —— 认真而可读地讲完第 1 节的流变学，仍是解释熔体为什么这样表现的最佳著作。
- M. T. Shaw 和 T. I. Advani 著，*An Introduction to Polymer Processing*，以及 C. Rauwendaal 著，*Polymer Extrusion*，第 5 版，Hanser，2014 —— 第 3 节的螺杆、口模和工作点图，附加工者真正使用的设计规则。
- P. J. Kennedy 和 C. Li 著，*Flow and Interaction in Injection Moulding*，以及 **Moldflow / Autodesk Simulation** 技术文档 —— 每次现代模具评审背后的充填、保压、冷却和翘曲预测。
- S. G. Advani 和 C. L. Hsiao 著，*Flow and Rheology in Polymer Composites Manufacturing*，以及 A. C. Long 著，*Composite Materials and Manufacturing*，用于第 5 节的达西定律浸渍、预制体渗透率和灌注。
- I. A. Campbell 著，*Manufacturing Processes for Advanced Composites*，Elsevier，2004 —— 第 5 节每种工艺的诚实比较，出自调查过失效的人之手。
- R. M. Jones 著，*Mechanics of Composite Materials*，以及 J. R. Vinson 著，*The Behavior of Structures Composed of Composite Materials*，用于铺层表的力学；**CMH-17 复合材料手册第 17 卷**，用于许用值、环境折减和损伤容限要求。
- A. V. Dukkipati 与**塑料工程师学会的 *Injection Molding Handbook***，以及 **H. P. Schott 和 G. W. Ehrenstein 著，*Polymer Materials: Data Sheets and Properties***，用于机器和数据表上的数字。
- **ISO 295、ISO 20753、ISO 11443（熔体流变）**、**ISO 14125 和 CMH-17（复合材料许用值）**以及 **EN 13462 / ASTM D2565（塑料老化）**，规格书必须引用的标准。
