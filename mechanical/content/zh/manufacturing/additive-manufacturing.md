增材制造是唯一一个零件的几何、显微组织和残余应力都由同一样东西决定的一类工艺：零件中某一点从粉末或丝材变成成品固体的热历史。这一个事实解释了增材制造所有的好处，也解释了它所有的难处。好处在于，逐层堆积的工艺能做出任何刀具到不了的几何——支架内部封闭的点阵、跟随涡轮叶片表面的冷却流道、把二十个机加零件和十四个紧固件并成一个整体的支架。难处在于，同样的逐层堆积意味着零件有一个不是轧制方向的晶粒方向、一个阶梯状表面、一个取决于你往哪个方向加载的强度、一个零件还没离开构建板就已达到屈服点的残余应力，以及一个取决于某个星期二下午氩气流量的孔隙群体。**机加坯料是一种已知材料在一个未知形状里；增材制造零件是一个已知形状在一种你必须自己表征的材料里。**

增材制造提出的工程问题从来不是"机器能不能打印它"——机器几乎能打印你给它的任何东西。问题是：**出来的东西性能如何，我要对机器、粉末、气氛、构建板、后处理和检测做些什么，才能让这些性能可重复到能放进一架飞机、一个人工髋关节或一个压力容器？**答案是一长串工艺物理、热力学、粉末冶金和质量控制，本讲的全部内容就是这条链条。

::: warning 增材制造项目出错的九种方式
**把增材制造当作一种工艺而不是一个家族。**"我们要 3D 打印它"不是一个制造决策。0.2 mm 层的 FDM、30 μm 层的 LPBF、18 % 烧结收缩的黏结剂喷射、5 mm 焊道宽的 DED，是四种不同的工艺、四套不同的设计规则、四组不同的性能、四种不同的成本结构。**先指定工艺家族、机器、参数集、粉末批次和后处理路线，再叫它增材制造。****为 CAD 模型设计而不是为成形件设计。**CAD 模型是一个愿望。成形件有阶梯表面，有因为熔池形状而不是 45° 的 45° 悬垂，有因为光斑尺寸而不是 0.4 mm 的 0.55 mm 壁，有一个因为表面半烧结粉末而小了 0.3 mm 的孔。**按成形包络设计，而不是按模型，并把关键尺寸放在机加工特征上。****忽视构建方向。**沿 Z 测试的 LPBF 拉伸棒伸长率只有同一根棒沿 X 测试的 60–80 %，因为原 β 柱状晶和未熔合缺陷都沿构建方向排列。一个设计成"各向同性"的点阵，如果建在 45° 阶梯上，就不是各向同性的。**先指定加载方向，再指定构建方向，再指定后处理，然后画图。****不为后处理做预算。**零件下板时带着焊在其上的支撑、屈服点的残余应力、Ra 10–20 μm 的表面粗糙度，和一种谁都不想要的显微组织。把它从板上切下、去除支撑、去应力退火、热等静压、机加工关键面并检测，可能比建造本身还贵。**对典型的航空 LPBF 支架，后处理和检测加起来的成本与建造本身相当，而且常常更多。****假定粉末就是材料。**气雾化 316L 粉末不是 316L：它有 200–400 ppm 的氧、一个取决于雾化气体的氮含量、制造内部孔隙的卫星颗粒，以及一个每回收一次就变一次的粒度分布。**规定粉末、批次、回收历史和氧含量上限，先测粉末再测零件。****跳过鉴定。**一块机加 7075-T651 板有四十年的许用值。你的机器、你的参数、你的粉末、你的后处理做出来的 LPBF AlSi10Mg 支架，只有你从自己的试件生成的许用值。**如果你不能从至少三十根三个方向、两种热处理状态的试件做出统计有效的数据集，你就没有一种材料，你只有一个原型。****不为去除做设计。**一个没有出粉孔的封闭型腔会困住永远出不来的粉末。一个 0.2 mm 杆、0.3 mm 孔的点阵清不干净。内部流道里的支撑够不着。**先设计排粉路径再设计型腔，粉末去不掉就别做型腔。****过度设计点阵。**一个取代实壁的点阵省了 80 % 的质量、20 % 的刚度，然后设计者为了补刚度又加第二层点阵，零件比原来还重。**在点阵干活的地方用它——吸能、热管理、骨长入、重量关键的次级结构——不在它干活的地方用实壁以外的东西。****假定机器的"标准参数"就是你的参数。**机器厂商的参数集是起点，不是合格工艺。同一台机器、同一种合金、同一套参数，根据粉末批次、铺粉刮刀磨损、腔室温度和氧含量，可以做出 99.9 % 致密或 97 % 致密。**在你自己的机器上用你自己的粉末鉴定你自己的参数，并监控它们。**
:::

## 1. 增材到底是什么：层、道与热历史

::: definition 增材制造的七个家族（ISO/ASTM 52900） {#def-am-families}
标准按*材料如何被连接*而不是按什么机器制造，把增材制造工艺分为七个家族：

$$
\begin{array} { l l l l }
\textbf{家族} & \textbf{原料形态} & \textbf{结合机理} & \textbf{典型材料} \\ \hline
\text{材料挤出（FFF/FDM）} & \text{丝材、浆料} & \text{热熔合、溶剂} & \text{PLA、ABS、PA、PC、PEEK} \\
\text{光敏树脂槽聚合（SLA/DLP）} & \text{液态树脂} & \text{紫外交联} & \text{丙烯酸酯、环氧、陶瓷浆料} \\
\text{粉末床熔融（PBF-LB/EB）} & \text{粉末，20--60 } \mu\text{m} & \text{激光或电子束熔化} & \text{Ti-6Al-4V、316L、AlSi10Mg、IN718} \\
\text{黏结剂喷射（BJ）} & \text{粉末 + 液态黏结剂} & \text{粘附，然后烧结} & \text{SS316L、H13、WC-Co、砂} \\
\text{材料喷射（PolyJet/MJ）} & \text{光敏树脂液滴} & \text{紫外固化} & \text{多材料树脂、蜡} \\
\text{定向能量沉积（DED）} & \text{丝材或粉末} & \text{激光/电弧/电子束熔化} & \text{Ti-6Al-4V、316L、IN718、工具钢} \\
\text{层压成形（LOM/UAM）} & \text{板材、箔材} & \text{胶粘或超声} & \text{纸、塑料、铝、钛箔} \\
\end{array}
$$

对设计要紧的区别是**原料形态**，因为它决定最小特征尺寸和表面质量。光敏树脂槽工艺固化一个 25–100 μm 的像素，所以做出最细的特征。粉末床工艺在 20–60 μm 的粉末层上熔一个 60–120 μm 的光斑，所以分辨率是 100–200 μm，表面由粉末粒径决定。材料挤出工艺沉积一条 200–800 μm 宽的丝道，所以分辨率是 0.2–0.8 mm。DED 工艺熔一条 1–5 mm 的焊道，所以分辨率是毫米级。**规则是：能保持的特征尺寸约为工艺"像素"的两倍，表面粗糙度约为像素尺寸。**
:::

::: definition 阶梯效应、构建方向与各向异性 {#def-staircase}
层工艺做不出光滑表面。与构建板成 $\theta$ 角的表面被建成一叠高 $h$ （层厚）、宽 $h / \tan \theta$ 的台阶，该阶梯的理论粗糙度是

$$
R _ { a , \text{staircase } } \; = \; { \frac { h \cos \theta } { 4 } } \qquad { \bigl [ } \theta \; = \; \text{相对构建板的角度，} h \; = \; \text{层厚 } { \bigr ] }
$$

（垂直于表面量得的峰谷高度为 $h \cos \theta$ 的锯齿波；见 [[#ex-derive-staircase]]）。45° 表面、30 μm 层厚时，$R _ { a } = 5 . 3 \ \mu \mathrm { m }$ ；100 μm 层厚时为 $1 8 \ \mu \mathrm { m }$ 。接近垂直的表面（$\theta \to 9 0 ^ { \circ }$）阶梯消失，粗糙度改由粉末或丝道宽度决定；在很平缓的表面上，模型中的台阶变得又长又平，粗糙度由台阶边缘主导。**实际后果是：增材制造零件的表面质量取决于它在构建中的方位，而给出最好表面的方位通常给出最差的强度，因为阶梯垂直于载荷。**

**构建方向**（约定为 Z）造成三种各向异性：

- **几何各向异性**：阶梯、水平面与垂直面不同的表面粗糙度，以及典型为 XY 向 ±0.1–0.3 mm、Z 向 ±0.15–0.5 mm 的尺寸精度。
- **显微组织各向异性**：LPBF 中每条熔道以背离熔合线生长的柱状晶凝固，而由于熔道层层堆叠，晶粒逐层外延生长成可跨越数百层的**强织构柱状组织**。Ti-6Al-4V 中沿 Z 的原 β 晶粒长 100–500 μm；316L 中柱状晶宽 50–200 μm，可贯穿零件全高。
- **缺陷各向异性**：未熔合缺陷、未熔粉末和锁缩孔在 XY 平面被压扁，因此**在 Z 向加载的疲劳中充当裂纹型缺陷**，这就是 LPBF Ti-6Al-4V 的 Z 向疲劳强度比 XY 向低 30–50 % 的原因。

**工程师的规则：设计零件使主拉应力位于 XY 平面；做不到时，把 Z 向性能折减 30–50 %，并在你折减的那个方向测试件。**
:::

::: definition 热历史：一百万次微型焊接 {#def-thermal-history}
金属增材制造零件中的每一点都经历其他任何制造工艺都不产生的热循环。一个 100 层 LPBF 构建中半高处的点：

1. 激光经过时被**熔化**于 $2 0 0 0 { - } 3 0 0 0 \ \mathrm { ^ \circ C }$ 并以 $1 0 ^ { 3 } { - } 1 0 ^ { 6 } \ \mathrm { K / s }$ **淬火**。
2. 被其上方沉积的各层**再加热**：紧接着的一两层会使它重熔或接近重熔，再往后几层把它加热到发生相变和析出的温度区间，之后每一层对它的加热越来越弱——而在每一层之内，它还被每条相邻熔道加热。
3. 若腔室预热，则在构建期间（数小时到数天）**保温**。
4. 构建结束后 4–24 小时**冷却**到室温。

冷却速度决定显微组织：LPBF 316L 具有亚微米胞尺寸的胞晶-枝晶亚结构，胞壁充当位错势垒，使其屈服强度达约 450–600 MPa——约为退火态变形 316L 的两倍。再加热循环决定析出状态：LPBF AlSi10Mg 成形态是过饱和铝基体加细密共晶硅网络，抗拉强度约 450 MPa 但伸长率只有百分之几；约 $3 0 0 \ \mathrm { ^ \circ C }$ 的去应力退火把网络打碎成硅颗粒，伸长率约翻一番，代价是强度下降。热历史还决定残余应力：加热的构建板能让少量应力在构建期间松弛，但大部分要留到构建后的去应力退火。**后果是增材制造零件的性能不是材料性能而是工艺性能。**同样的 Ti-6Al-4V 粉末、同样的合金、同样的机器，可以做出约 1000–1100 MPa 屈服强度、伸长率只有百分之几的材料（成形态，高冷却速度，细 $\alpha ^ { \prime }$ 马氏体），也可以做出约 850–950 MPa、伸长率 10–15 % 的材料（约 $9 2 0 \ \mathrm { ^ \circ C }$ 热等静压后，马氏体分解为较粗的片层 $\alpha { + } \beta$ 组织）。**你在增材图纸上不写"Ti-6Al-4V"；你写"按 ASTM F3001 的 Ti-6Al-4V ELI，LPBF，参数集 X，粉末批次 Y，热等静压制度 Z，三个方向的试件"。**
:::

## 2. 聚合物增材制造：FDM、SLA 与 SLS

::: definition 熔融长丝制造（FFF/FDM）：丝道、结合与各向异性 {#def-fdm}
热塑性丝材（直径 1.75 或 2.85 mm）由齿轮式或直驱挤出机送入加热喷嘴，熔化后作为一条**丝道**（挤出丝材的横截面）沉积在构建板或上一层上。喷嘴直径为 0.2–0.8 mm；由于离模膨胀和压力驱动流动，丝道宽度为喷嘴直径的 1.0–1.5 倍；层厚为 50–300 μm，通常为喷嘴直径的 60–80 %。

丝道以熔融温度（取决于聚合物为 $2 0 0 { - } 4 0 0 \ \mathrm { ^ \circ C }$ ）沉积在底板温度的基体上（$4 0 { - } 1 5 0 \ \mathrm { ^ \circ C }$ ）。两条丝道通过聚合物链跨越界面的**互扩散**（蠕动）结合，结合强度取决于界面停留在 $T _ { g }$ 以上（非晶聚合物）或结晶温度 $T _ { c }$ 以上（半晶聚合物）的时间。链段互扩散之前，两条丝道必须先流动接触，Frenkel（1945）的粘性烧结模型给出两个半径为 $r$ 的相切圆柱或球之间的颈部半径 $x$ 为

$$
{ \frac { x } { r } } \; = \; \left( { \frac { 3 \gamma \, t } { 2 \eta \, r } } \right) ^ { 1 / 2 }
$$

其中 $\gamma$ 是表面张力，$\eta$ 是熔体粘度，$t$ 是界面保持足够热、能够流动的时间。**问题就在这个时间上：颈部只按 $\sqrt { t }$ 增长，丝道冷却时粘度急剧上升，而界面在 $T _ { g }$ 以上停留远不到一秒，这个时间由丝道尺寸、打印速度以及底板和腔室温度决定。**这就是 FDM 的 Z 向强度只有基体材料 30–70 % 的原因，也是半晶聚合物（PA12、PEEK）结合比非晶聚合物（ABS、PC）更差的原因：界面处的结晶在链段来得及蠕动之前就把它们冻结了。

FDM 的**各向异性**是所有增材制造工艺中最大的。沿丝道方向（X）加载的拉伸棒与基体聚合物一样强。横跨丝道方向（Y，面内）的棒为基体的 70–90 %，因为载荷通过丝道间结合传递。沿 Z（穿过层）的棒为基体的 30–60 %，因为层间结合弱于丝道间结合（丝道沉积在冷表面上，冷却更快）。**对一个功能件 FDM 零件，规则是：让载荷沿丝道方向；做不到时，把零件在 Z 向加厚 2–3 倍。**
:::

::: definition 光聚合：SLA、DLP 与 MSLA {#def-sla}
一槽液态光敏树脂被紫外光选择性固化。其物理是入射强度 $I _ { 0 }$ 在树脂中的 **Beer-Lambert 吸收**：

$$
I ( z ) \; = \; I _ { 0 } \, e ^ { - z / D _ { p } }
$$

其中 $D _ { p }$ 是**透射深度**（强度降到表面值的 $1 / e$ 处的深度，丙烯酸酯和环氧树脂典型为 50–150 μm）。光引发剂吸收光并产生自由基（或阳离子），使单体和低聚物链交联。当局部**曝光剂量** $E = I \times t$ （辐照度 × 时间）超过**临界剂量** $E _ { c }$ （典型为 5–30 mJ/cm²）时树脂凝胶化。对 Beer-Lambert 定律积分得到固化深度的 **Jacobs 方程**：

$$
C _ { d } \; = \; D _ { p } \, \ln { \frac { E } { E _ { c } } } \; = \; D _ { p } \, \ln { \frac { I _ { 0 } \, t } { E _ { c } } }
$$

**过固化** $\delta = C _ { d } - t _ { \text{layer } }$ 是目标层以下不期望固化的深度。少量过固化（10–30 μm）对粘结各层是必要的；大量过固化（50 μm 以上）会破坏 Z 向分辨率并把零件焊死在之前的层上。**因此曝光时间是粘附与分辨率之间的折中，是 SLA 中最重要的单一参数。**

三种变体占主导地位：

- **SLA（激光扫描）**：紫外激光（355 或 405 nm）由检流计振镜在树脂表面扫描。光斑尺寸 50–150 μm，层厚 25–100 μm，XY 分辨率 50–100 μm。原始工艺（Hull，1984）。
- **DLP（数字光处理）**：由 DMD（数字微镜器件）或 LCD 掩模一次性投影整层。像素尺寸 25–100 μm，无论零件几何如何，每层时间 1–10 s。对许多小零件更快，但像素网格在曲面上产生"锯齿"伪影。
- **MSLA（掩模 SLA）**：LCD 屏（405 nm）充当动态掩模。便宜（200–5 000 美元），50 μm 像素，25–50 μm 层厚。消费级主力。

**树脂收缩**是光聚合增材制造的阿喀琉斯之踵。固化时的体积收缩为 2–8 %，产生内应力、翘曲和与构建板的分层。低收缩树脂（环氧基，1–3 %）存在，但更慢、更脆。**每个 SLA 零件都是一次翘曲计算：线收缩应变为 $\varepsilon _ { \text{shrink } } \approx ( \Delta V / V ) / 3$ ，5 % 的体积收缩给出 1.7 % 的线应变——17 000 με，与玻璃态聚合物的屈服应变同一量级。只有树脂凝胶之后发生的那部分收缩会被锁成应力，这就是缓慢分段固化和后固化能减少翘曲的原因。**
:::

::: definition 聚合物 SLS：烧结窗口与粉末床 {#def-sls-polymer}
选区激光烧结铺一层 60–120 μm 的聚合物粉末（通常为 PA12、PA11、TPU 或 PA12-碳纤维复合材料），用 20–40 W 的 $\mathrm { C O } _ { 2 }$ 激光（10.6 μm）熔合表面。零件之外的粉末床充当支撑，因此**不需要支撑结构**，零件可以有任何几何形状。粉末床保持在略低于熔点的温度（$T _ { \text{bed } } \approx T _ { m } - 2 0 { - } 4 0 \ \mathrm { ^ \circ C } $）以减小热变形。

关键的材料性能是**烧结窗口**：结晶起始温度 $T _ { c }$ 与熔点 $T _ { m }$ 之间的温度范围。对 PA12，$T _ { m } \approx 1 7 8 \ \mathrm { ^ \circ C }$ ，$T _ { c } \approx 1 5 5 \ \mathrm { ^ \circ C }$ ，窗口为 23 °C。如果窗口窄于约 20 °C，粉末在烧结之前就结晶，零件又弱又不均匀。这就是 PA12 主导 SLS、而烧结窗口窄的 PLA 几乎从不使用的原因。

SLS 的**表面质量**为 $R _ { a }$ 10–20 μm——颗粒感强，因为表面是一层部分熔合的粉末颗粒皮。内部致密度通常为 95–99 %。**力学性能**是准各向同性的（与 FDM 不同），因为粉末取向随机，但 Z 向强度为 XY 向的 70–90 %，因为层间熔合略不完全。**SLS 及其近亲多射流熔融，是能用工程热塑性塑料制造功能件、近乎各向同性、自支撑零件的聚合物增材制造工艺，这就是它们领先"最终用途聚合物零件"市场的原因。**
:::

::: example FDM 丝道宽度与构建时间 {#ex-fdm-time level=3 check="14"}
一个 50 mm × 50 mm × 20 mm 的 ABS 块用 0.4 mm 喷嘴、0.2 mm 层厚、100 % 填充、0.45 mm 丝道宽度、60 mm/s 打印速度打印。估算构建时间，在沉积时间上加 10 % 作为空行程、回抽和换层时间。（以小时作答。）

::: example SLA 固化深度与过固化 {#ex-sla-cure level=3 check="230"}

$$
E \; = \; I _ { 0 } \, t \; = \; 1 5 \times 1 0 \; = \; 1 5 0 \ \mathrm { m J / c m ^ { 2 } }
$$

$$
C _ { d } \; = \; D _ { p } \, \ln { \frac { E } { E _ { c } } } \; = \; 1 0 0 \, \ln { \frac { 1 5 0 } { 1 5 } } \; = \; 1 0 0 \times 2 . 3 0 3 \; = \; { \bf 2 3 0 \ \mu m }
$$

过固化是 $\delta = 2 3 0 - 5 0 = 1 8 0 \ \mu \mathrm { m }$ ——**太多了**。固化深度是层厚的 4.6 倍，所以树脂固化贯穿四层，零件与其下方的一切焊死。要得到 50 μm 的过固化（$C _ { d } = 1 0 0 \ \mu \mathrm { m }$ ），曝光必须降到 $E = E _ { c } \, e ^ { C _ { d } / D _ { p } } = 1 5 \times e ^ { 1 } = 4 1 \ \mathrm { m J / c m ^ { 2 } }$ ，在 $1 5 \ \mathrm { m W / c m ^ { 2 } }$ 下即 $t = 2 . 7 \ \mathrm { s }$ 。**曝光时间是 SLA 中必须鉴定的参数，而数据表数值对你的树脂批次、你的灯龄和你的层厚几乎从来是不对的。**

## 3. 金属增材制造：粉末床熔融、定向能量沉积与黏结剂喷射

::: definition 激光粉末床熔融（LPBF / PBF-LB）：熔池与能量密度 {#def-lpbf}
200–1000 W 的光纤激光（1070 nm）由检流计振镜在惰性气氛（氩气，某些钢用氮气；钛合金氧含量保持在约 0.1 % 以下，钢在千分之几以下）下扫过一层 20–60 μm 的金属粉末（粒径 20–60 μm，气雾化，球形）。激光熔出一条 100–200 μm 宽、50–150 μm 深的熔道；扫描间距为 80–150 μm，所以相邻熔道重叠约 20–50 %；扫描图案在层间旋转 $6 7 ^ { \circ }$ 以避免择优晶向。

支配工艺的唯一参数是**体积能量密度**：

$$
E _ { v } \; = \; { \frac { P } { v \, h \, t } } \quad [ \mathrm { J / m m ^ { 3 } } ]
$$

其中 $P$ 是激光功率（W），$v$ 是扫描速度（mm/s），$h$ 是扫描间距（mm），$t$ 是层厚（mm）。对 Ti-6Al-4V，获得 $> 9 9 . 5 \ \%$ 相对密度的"可加工窗口"大致是 $E _ { v } = 4 0 { - } 8 0 \ \mathrm { J / m m ^ { 3 } }$ 。低于 30 时熔道不重叠，出现**未熔合**孔隙；高于 100 时熔池进入**匙孔**模式（汽化金属的反冲压力超过表面张力，在熔池中打出一个空腔），出现**匙孔孔隙**。**窗口只有 2–3 倍宽，这就是 LPBF 是一个需要鉴定的工艺、而不是一台可以买来的机器的原因。**

熔池是一个微小、剧烈、短命的物体：100 μm 宽，100 μm 深，$2 5 0 0 \ \mathrm { ^ \circ C }$ 热，以 0.5–2 m/s 移动，热梯度 $1 0 ^ { 6 } { - } 1 0 ^ { 7 } \ \mathrm { K / m }$ ，冷却速度 $1 0 ^ { 5 } { - } 1 0 ^ { 6 } \ \mathrm { K / s }$ 。池内的 **Marangoni 流**——由表面张力的温度依赖性 $\mathrm { d } \gamma / \mathrm { d } T$ 驱动——决定熔池是宽而浅（从热中心向外流，$\mathrm { d } \gamma / \mathrm { d } T < 0$ ，如洁净的低硫低氧熔体）还是窄而深（向内流，$\mathrm { d } \gamma / \mathrm { d } T > 0$ ，当硫、氧等表面活性元素以几十到几百 ppm 存在时）。**这正是两炉"同样的"不锈钢焊接表现不同的同一效应，也是粉末化学成分与激光功率同等重要的原因之一。**

LPBF 的**缺陷分类**是：

- **未熔合（LoF）**：熔道之间或层之间熔化不完全。扁平、不规则、裂纹状、平行于构建平面，内部常有未熔颗粒。对疲劳最坏的缺陷，因为它的表现如同一条与其投影尺寸相当的预存裂纹。
- **匙孔孔隙**：球形，10–100 μm，蒸气空腔坍塌并困住气体时形成。球形孔隙比 LoF 危害小，但仍会缩短疲劳寿命，近表面时尤甚。
- **球化（balling）**：长液柱因 Plateau–Rayleigh 失稳而破碎成液滴，下层润湿不良时更甚。造成粗糙表面和散粉，污染后续的层。
- **飞溅**：被喷出的液滴（来自匙孔坍塌或 Marangoni 喷射）落在粉末床上，在下一层中形成夹杂。
- **分层剥离**：零件因残余应力超过与板的附着力而从构建板上剥落。最灾难性的失效模式：零件报废，粉末被污染，机器需要清理。
:::

::: definition 电子束粉末床熔融（EB-PBF）：真空、预热与氧化皮剥离 {#def-ebpbf}
电子束（典型为 60 kV、几千瓦）在真空（$1 0 ^ { - 4 } \ \mathrm { mbar }$ ）中由电磁线圈偏转扫过粉末床。束流先在整个粉末床上扫描预热，把粉末床加热到 $6 0 0 { - } 1 1 0 0 \ \mathrm { ^ \circ C }$ （Ti-6Al-4V 约 700 °C，TiAl 超过 1000 °C），然后按零件图案熔化。真空消除了氧化，因此**活性合金（TiAl、NbSi、Ta）可以加工而不脆化**。高预热温度消除了构建期间的残余应力，因此**裂纹敏感合金（TiAl、W、某些工具钢）可以不发生热裂纹地建造**。

代价是：

- **束流快，结果粗**：束流靠电磁偏转、没有运动部件，可分成多个熔池，构建速率与单激光 LPBF 相当或更高，但它使用更粗的粉末（45–105 μm）和更厚的层（50–100 μm）。
- **表面更粗**：束斑比激光大，零件周围轻度烧结的粉末留下一层粗糙表皮，必须用喷砂或机加工去除。$R _ { a }$ 典型为 20–40 μm，而 LPBF 约为 8–15 μm。
- **"吹粉"（smoke）**：束流在粉末中沉积负电荷。如果粉末床没有先被预热扫描轻度烧结，带电颗粒相互排斥，整层粉末被吹成一团粉云。每一层的预热扫描就是为了防止这一点。
- **粉末回收**：零件周围的粉末轻度烧结成"饼块"，必须用同种粉末喷砂打散，再筛分后重用。

**EB-PBF 是 TiAl（GE 的低压涡轮叶片）、裂纹敏感合金、以及真空省去惰性气体回路的应用的首选工艺。它不是大批量、细特征或低成本活计的首选工艺。**
:::

::: definition 定向能量沉积（DED）：丝材、粉末与修复 {#def-ded}
聚焦能量源（激光、电弧或电子束）把一股粉末或丝材熔化到基体上，以 1–5 mm 宽、0.5–2 mm 高的焊道堆积零件。加工头在 5 轴机器上移动，所以零件可以在已有表面上建造——**这才是杀手级应用：修复磨损的涡轮叶片、报废的模具或腐蚀的轴**。

两种原料变体：

- **送粉 DED**：同轴或侧向喷嘴把粉末喷入熔池。**捕获效率**（真正熔化进沉积层的粉末比例）为 50–80 %；其余损失。沉积速率：激光 0.5–5 kg/h，电弧 2–10 kg/h。稀释（沉积层中来自熔化基体的比例）为 5–30 %，必须控制，因为它改变沉积层的成分。
- **送丝 DED**：填充丝材被送入熔池。捕获效率为 100 %（丝材全部熔化）。沉积速率：激光 1–10 kg/h，电弧 5–20 kg/h（电弧送丝增材制造，WAAM）。显微组织是铸造的，柱状晶粗大，成形表面有焊道波纹造成的 0.5–1 mm 量级的波纹度——**零件必须机加工到最终尺寸，每面留 1–3 mm 机加工余量。**

**沉积层的成分**由稀释率 $D$ 决定：

$$
C _ { \text{deposit } } \; = \; ( 1 - D ) \, C _ { \text{feedstock } } + D \, C _ { \text{substrate } }
$$

这与焊接的混合规则相同（见 [[manufacturing/joining|连接工艺]]）。对修复，稀释必须低到使沉积层化学成分在规格之内，热输入必须低到使基体不过回火。**因此镍基高温合金涡轮部件的激光 DED 修复使用低功率和适度送粉——例如 200 W、5 mm/s，线能量 $P / v = 4 0 \ \mathrm { J / m m }$ ——以保持稀释和热影响区都小，因为过热会使基体强化用的 $\gamma ^ { \prime \prime }$ 和 $\gamma ^ { \prime }$ 析出相溶解或粗化，降低其局部强度。**
:::

::: definition 黏结剂喷射：生坯、烧结与收缩 {#def-binder-jet}
液态黏结剂以喷墨方式打印到粉末床上，把颗粒粘合成一个理论密度 50–60 % 的**生坯**。生坯经过固化、清粉，然后在炉中**烧结**（钢约 1 100–1 400 °C，硬质合金可达约 1 500 °C）致密化到 90–99 %。若达到全致密，线烧结收缩为：

$$
\varepsilon _ { \text{linear } } \; = \; 1 - \left( { \frac { \rho _ { \text{green } } } { \rho _ { \text{theoretical } } } } \right) ^ { 1 / 3 }
$$

生坯密度 55 % 时，线收缩为 $1 - 0 . 5 5 ^ { 1 / 3 } = 1 - 0 . 8 1 9 = 1 8 . 1 \ \%$ 。**零件在每个方向收缩 18 %，而且收缩必须是各向同性的，否则零件变形。**各向同性收缩要求均匀的生坯密度、均匀的粉末堆积和均匀的烧结——这三点在 100 mm 高的零件上都很难做到。

黏结剂喷射的**优点**是速度（无激光、无熔化、无热应力、无支撑）和成本（无激光、可用更便宜更细的 MIM 级粉末、一个构建箱内可嵌套大量零件）。**缺点**是烧结收缩（烧结后尺寸公差 ±0.5 %，而 LPBF 为 ±0.1 mm）、材料范围有限（SS316L、H13、WC-Co 和少数几种），以及烧结件是粉末冶金产品，有 2–8 % 残余孔隙，疲劳强度比锻件低 30–50 %。

**熔渗**是一种变体：轻度烧结的钢骨架用熔融青铜或铜熔渗，以填充孔隙、得到致密零件。熔渗件是复合材料，不是实心金属，其性能介于两组元之间。
:::

::: example LPBF 能量密度与可加工窗口 {#ex-ev-density level=3 check="71"}
一次 Ti-6Al-4V 的 LPBF 构建使用 $P = 2 8 0 \ \mathrm { W }$ ，$v = 1 2 0 0 \ \mathrm { m m / s }$ ，$h = 1 1 0 \ \mu \mathrm { m }$ ，$t = 3 0 \ \mu \mathrm { m }$ 。计算体积能量密度并判断参数是否在可加工窗口内。（以 J/mm³ 填写 $E _ { v }$ 。）

$$
E _ { v } \; = \; { \frac { P } { v \, h \, t } } \; = \; { \frac { 2 8 0 } { 1 2 0 0 \times 0 . 1 1 0 \times 0 . 0 3 0 } } \; = \; { \frac { 2 8 0 } { 3 . 9 6 } } \; = \; { \bf 7 1 \ \mathrm { J / m m ^ { 3 } } }
$$

**71 J/mm³ 位于 Ti-6Al-4V 窗口（40–80 J/mm³）的中部，所以这些参数应能产生致密度 $> 9 9 . 5 \ \%$ 的材料。**如果扫描速度降到 800 mm/s（为了适应粗粉末而增加熔深），$E _ { v }$ 会升到 $1 0 6 \ \mathrm { J / m m ^ { 3 } }$ ——**超过匙孔阈值，零件会出现球形孔隙。**如果扫描间距加宽到 150 μm（为了加快构建），$E _ { v }$ 会降到 $5 2 \ \mathrm { J / m m ^ { 3 } }$ ——仍在窗口内，但对 200 μm 宽的熔道，相邻熔道的重叠会从 45 % 降到 25 %，熔道边界处可能出现未熔合孔隙。**能量密度是必要条件而非充分条件：熔道重叠、扫描旋转和粉末堆积密度同样重要。**
:::

::: example DED 稀释与修复化学成分 {#ex-ded-dilution level=3 check="4.47"}
一个 IN738 部件（约 0.9 % Nb）用 IN718 粉末（名义 5.1 % Nb；IN718 规格范围为 Nb + Ta 4.75–5.5 %）进行激光 DED 堆焊。测得稀释率为 15 %。沉积层的 Nb 含量是多少，是否在 IN718 范围之内？（以 % Nb 作答，保留两位小数。）

$$
C _ { \text{deposit } } \; = \; ( 1 - 0 . 1 5 ) \times 5 . 1 + 0 . 1 5 \times 0 . 9 \; = \; 4 . 3 4 + 0 . 1 4 \; = \; { \bf 4 . 4 7 \ \% \ Nb }
$$

**沉积层低于 IN718 的范围：它既不是填充金属也不是基体，而是第三种合金，其性能必须单独鉴定。**如果基体也是 IN718，稀释根本不会改变成分。Nb 含量较低也有一个好处：它减少了 Nb 偏析，而 Nb 偏析会在枝晶间形成脆性的 Laves 相。 **稀释计算与焊接相同（见 [[manufacturing/joining|连接工艺]]），同样的规则适用：沉积层不是填充金属，首先要检查的是混合成分是否在规格之内。**
:::

## 4. 残余应力、变形与热撕裂

::: definition 增材制造中的残余应力：逐层淬火 {#def-res-am}
金属增材制造零件中的每一层都是一条小小的焊道，热态沉积、淬火，并被下面的冷材料约束。热应变为 $\varepsilon _ { \text{thermal } } = \alpha \, \Delta T$ ，如果该层完全受约束，应力为

$$
\sigma _ { \text{thermal } } \; = \; { \frac { E \, \alpha \, \Delta T } { 1 - \nu } }
$$

对 Ti-6Al-4V，$\Delta T = 1 0 0 0 \ \mathrm { K }$ ：$\sigma = 1 1 4 \ 0 0 0 \times 8 . 6 \times 1 0 ^ { - 6 } \times 1 0 0 0 / 0 . 6 6 = 1 4 9 0 \ \mathrm { M P a }$ ——**远高于 880 MPa 的屈服强度**。金属屈服，残余应力被封顶在屈服强度，与焊接完全一样（见 [[manufacturing/joining|连接工艺]]）。屈服的临界温差是

$$
\Delta T _ { \text{crit } } \; = \; { \frac { \sigma _ { Y } \, ( 1 - \nu ) } { E \, \alpha } }
$$

对 Ti-6Al-4V：$\Delta T _ { \text{crit } } = 8 8 0 \times 0 . 6 6 / ( 1 1 4 \ 0 0 0 \times 8 . 6 \times 1 0 ^ { - 6 } ) = 5 9 2 \ \mathrm { K }$ 。对 AlSi10Mg：$\Delta T _ { \text{crit } } = 2 4 0 \times 0 . 6 7 / ( 7 0 \ 0 0 0 \times 2 2 \times 1 0 ^ { - 6 } ) = 1 0 4 \ \mathrm { K }$ 。**铝合金在仅 100 K 的温差下就屈服，这就是 LPBF 铝比钛难建得多的原因：每一层的热循环都超过 100 K，所以零件在每一道都在屈服再屈服，累积变形巨大。**

典型的 LPBF 应力分布（Mercelis 和 Kruth，2006）正是这一机理所预测的：每一新层冷却时在下层之上收缩而被拉伸，所以顶部各层和自由表面承受很大的拉应力，由内部的压应力平衡；零件还在板上时，这些应力可以接近屈服强度。**零件还没离开构建板应力就已存在，从板上切下会把其中一部分释放为变形。**
:::

::: definition 变形与悬臂问题 {#def-distortion}
变形是残余应力的宏观后果：零件弯曲、卷曲或从板上剥离。最简单的情况是**悬臂**——下面没有支撑的水平悬垂。悬垂热态沉积、冷却、收缩。收缩被下面的材料抵抗，于是悬垂向上卷曲。卷曲角为：

$$
\theta _ { \text{curl } } \; \approx \; { \frac { \alpha \, \Delta T \, L } { t } }
$$

其中 $L$ 是悬垂长度，$t$ 是收缩层的厚度。10 mm 悬垂、30 μm 层厚、$\alpha = 8 . 6 \times 1 0 ^ { - 6 } \ \mathrm { K ^ { - 1 } }$ 、$\Delta T = 1 0 0 0 \ \mathrm { K }$ ：$\theta = 8 . 6 \times 1 0 ^ { - 6 } \times 1 0 0 0 \times 1 0 / 0 . 0 3 = 2 . 8 7 \ \mathrm { r a d } \approx 1 6 4 ^ { \circ }$ 。**小角度公式早已失效，但结论很清楚：没有锚固的悬垂不可能保持平直——它会卷起并剥离。**这就是 LPBF 零件每个悬垂下面都有支撑的原因：支撑不是为了把零件托住（粉末做这件事），而是为了**把悬垂锚定在板上并阻止卷曲**。

**整个零件的变形**是残余应力对截面的积分。高而薄的墙比矮而厚的墙变形更大，因为热梯度更大而弯曲刚度更低。变形按以下规律缩放：

$$
\delta _ { \text{distortion } } \; \propto \; { \frac { \alpha \, \Delta T \, H ^ { 2 } } { t _ { \text{wall } } ^ { 2 } } }
$$

其中 $H$ 是零件高度，$t _ { \text{wall } }$ 是壁厚（[[#proof-distortion]]）。**高度加倍使变形变为四倍；壁厚加倍使其变为四分之一。这就是 LPBF 零件设计时要留大圆角、厚底座、低重心的原因，也是 200 mm 高的薄壁支架是变形噩梦、而 50 mm 高的敦实支架轻而易举的原因。**
:::

::: definition 热撕裂与工艺可焊性 {#def-hot-tearing}
热撕裂（凝固裂纹）发生在金属处于**糊状区**——部分液态、部分固态——而收缩应变超过液体补缩能力时。枝晶臂之间的液膜被拉开，裂纹形成。敏感性取决于**凝固区间** $\Delta T _ { \text{solid } } = T _ { \text{liquidus } } - T _ { \text{solidus } }$ ：

- **敏感性低**：纯金属、近共晶合金和凝固区间窄的合金——316L（约 30–50 °C）、Ti-6Al-4V（约 50–60 °C），以及 AlSi10Mg，其充足的共晶液体会回填任何张开的裂纹。
- **敏感性高**：7075、2024 等高强变形铝合金（凝固区间远超 100 °C），以及 IN738LC、CM247LC 等 γ′ 强化镍基高温合金，后者因凝固裂纹、液化裂纹和应变时效裂纹共同作用而开裂。**没有专门措施时，这些合金极难用 LPBF 建造出无裂纹零件。**

**热撕裂敏感性**可以从凝固区间和应变速率估算：

$$
\text{HTS } \; \propto \; \Delta T _ { \text{solid } } \times { \dot { \varepsilon }} _ { \text{shrinkage } }
$$

LPBF 中的应变速率为 $1 { - } 1 0 \ \mathrm { s ^ { - 1 } }$ 量级（冷却速度为 $1 0 ^ { 5 } \ \mathrm { K / s }$ ，凝固区间 100 K，所以在糊状区的时间是 1 ms，而该时间内的应变是 0.1–1 %）。**应变速率比铸造高 1000 倍，这就是 TIG 焊得很好的合金在 LPBF 中开裂的原因。**

补救措施是：**提高预热温度**（减小 $\Delta T$ ，减小应变速率，并允许蠕变松弛——研究用机器把基板加热到几百甚至一千多摄氏度，已减少了 γ′ 高温合金的开裂）、**使用 EB-PBF**（其高温粉末床有同样效果）、**修改合金**（Martin 等人 2017 年在 *Nature* 上报道，向 7075 和 6061 粉末中加入锆基形核纳米颗粒，使柱状晶变为等轴晶，裂纹随之消失），或**更换工艺**（使用冷却速度更低的 DED，或使用 AlSi10Mg 这样的抗裂合金代替 Al 7075）。
:::

::: proof 变形如何随几何缩放 {#proof-distortion}
考虑一堵 LPBF 建造的高 $H$ 、厚 $t$ 、长 $L$ （$L \gg H \gg t$ ）的墙。每一层在熔融温度 $T _ { m }$ 沉积并冷却到基板温度 $T _ { 0 }$ 。该层的热应变为 $\varepsilon _ { \text{th } } = \alpha \, \Delta T$ ，其中 $\Delta T = T _ { m } - T _ { 0 }$ 。该层被下面的材料约束，所以处于拉伸状态（若它屈服，则下面的 $\alpha \Delta T$ 应换成屈服应变 $\sigma _ { Y } ( 1 - \nu ) / E$ ，这给变形设了上限）。零件从板上切下后，残余应力释放，零件弯曲。

双层的曲率 $\kappa$ （一层热应变为 $\varepsilon _ { \text{th } }$ 的层粘结在零应变的基板上）由 Stoney 方程给出：

$$
\kappa \; = \; { \frac { 6 \, \varepsilon _ { \text{th } } \, h _ { f } } { t ^ { 2 } } } \; = \; { \frac { 6 \, \alpha \, \Delta T \, h _ { f } } { t ^ { 2 } } }
$$

其中 $h _ { f } \ll t$ 是受应变层的厚度——几层深，由工艺而不是由壁厚决定。高为 $H$ 的悬臂梁的端部挠度是：

$$
\delta \; = \; { \frac { \kappa \, H ^ { 2 } } { 2 } } \; = \; { \frac { 3 \, \alpha \, \Delta T \, h _ { f } \, H ^ { 2 } } { t ^ { 2 } } }
$$

**这三个缩放律是要记住的。**变形按 $H ^ { 2 }$ 缩放：**高度加倍使变形变为四倍**，这就是高零件要带支撑、带点阵底座或带预变形几何建造的原因。由于 $h _ { f }$ 由工艺固定，它按 $1 / t ^ { 2 }$ 缩放：**壁厚加倍使变形变为四分之一**，这就是薄壁零件最难建造的原因。它还按 $\alpha \, \Delta T$ 缩放：**铝（$\alpha = 2 2 \times 10^ { - 6 }$ ）在同样 $\Delta T$ 下的变形是钛（$\alpha = 8 . 6 \times 10^ { - 6 }$ ）的 2.5 倍**，这就是 LPBF 铝是变形问题、而 LPBF 钛是残余应力问题的原因。$\blacksquare$
:::

:::

## 5. 面向增材制造的设计：点阵、拓扑优化与零件集成

::: definition 点阵结构与 Gibson-Ashby 缩放 {#def-lattice}
点阵是杆件（或板件）的周期性阵列，用相对密度 $\bar { \rho } = \rho ^ { * } / \rho _ { s }$ 为 0.05–0.5 的结构填充一个体积。其力学性能按 **Gibson-Ashby 关系**随相对密度缩放：

$$
{ \frac { E ^ { * } } { E _ { s } } } \; = \; C _ { 1 } \, { \bar { \rho } } ^ { \, n } \qquad { \frac { \sigma _ { \text{yield } } ^ { * } } { \sigma _ { \text{yield,} s } } } \; = \; C _ { 3 } \, { \bar { \rho } } ^ { \, m }
$$

其中**弯曲主导**结构（开孔泡沫、Kelvin 胞）$n = 2$ 、$m = 1 . 5$ （泡沫 $C _ { 1 } \approx 1$ 、$C _ { 3 } \approx 0 . 3$ ），而杆件轴向受力的**拉伸主导**点阵 $n = m = 1$ 。**八面体桁架**（每个节点汇交 12 根杆，由堆积的八面体和四面体的棱构成）是标准的拉伸主导点阵：Deshpande、Fleck 和 Ashby（2001）给出 $E ^ { * } / E _ { s } \approx \bar { \rho } / 9$ 、$\sigma ^ { * } / \sigma _ { Y , s } \approx \bar { \rho } / 3$ 。

杆径 $d$ 、杆长 $l$ 的八面体桁架的**相对密度**（忽略节点处的重叠，适用于细长杆）是：

$$
{ \bar { \rho } } _ { \text{octet } } \; = \; { \frac { 3 { \sqrt { 2 } } \, \pi } { 2 } } \left( { \frac { d } { l } } \right) ^ { 2 } \; \approx \; 6 . 6 6 \left( { \frac { d } { l } } \right) ^ { 2 }
$$

$d / l = 0 . 1$ （0.2 mm 粗、2 mm 长的杆）时：$\bar { \rho } = 6 . 6 6 \times 0 . 0 1 = 0 . 0 6 7$ ，所以点阵致密度为 6.7 %，其模量为 $E ^ { * } / E _ { s } = 0 . 0 6 7 / 9 = 7 . 4 \times 1 0 ^ { - 3 }$ ——**比实心低 135 倍**。点阵不是轻量化结构；它是一种提供单位质量刚度、吸能、热表面积或骨长入的**功能梯度材料**。

**点阵的设计规则是：**（1）最小杆径由工艺决定（LPBF 为 0.15–0.3 mm，FDM 为 0.4 mm，黏结剂喷射烧结收缩后为 0.5 mm）；（2）晶胞必须允许排粉（LPBF 常用的指南是出粉开口至少约 0.5–1 mm，远大于颗粒本身，因为部分烧结的粉末会桥接小缝隙）；（3）点阵必须锚固在实体蒙皮（0.3–0.5 mm）上，把载荷分布到杆件；（4）除非拓扑近乎各向同性，否则点阵是各向异性的（八面体桁架和 Kelvin 胞只是轻度各向异性；简单立方沿杆方向刚、受剪时很柔）。
:::

::: definition 拓扑优化：SIMP 与密度法 {#def-topopt}
拓扑优化问的是：**给定一个设计空间、一组载荷、一组约束和一个目标（最小柔度、最小质量、最大频率），材料的最优分布是什么？**标准方法是 **SIMP**（带惩罚的各向同性实心材料）：把设计空间划分为单元网格，每个单元赋予密度 $\rho _ { e } \in [ 0 , 1 ]$ ，单元刚度按以下插值

$$
E _ { e } \; = \; E _ { \min } \; + \; ( E _ { s } - E _ { \min } ) \, \rho _ { e } ^ { \, p }
$$

其中 $p = 3$ 是惩罚指数（它把密度推向 0 或 1，因为中间密度下刚度被惩罚），$E _ { \min }$ 是一个小刚度以避免刚度矩阵奇异。优化在体积约束 $\sum \rho _ { e } V _ { e } \le V ^ { * }$ 下用基于梯度的优化（MMA，移动渐近线法）最小化柔度 $C = \mathbf { f } ^ { \mathrm { T } } \mathbf { u }$ （其中 $\mathbf { K } \mathbf { u } = \mathbf { f }$ ）。

结果是一个**密度场**——一张材料该往哪里去的灰度图。密度场通过阈值化（密度 > 0.5 → 实心）和网格化（移动立方体法）转换为几何，然后光顺（Tikhonov 滤波、基于 PDE 的光顺），最后**面向增材制造约束重新优化**（悬垂角、最小特征尺寸、构建方向）。

**拓扑优化出的形状不是最终形状。**它是一个告诉你载荷路径在哪里的起点，设计师必须随后解读它：加蒙皮、加厚细杆、加安装特征、加平底、去掉悬浮岛，让它可制造。**一个未经重新解读的拓扑优化支架，是一个造不出来、检不了、也鉴定不了的支架。**
:::

::: definition 零件集成与设计自由红利 {#def-consolidation}
增材制造最有价值的不是点阵、也不是拓扑优化形状的应用——而是**零件集成**：用一个打印零件取代一组机加零件和紧固件的组件。典范例子是 GE 为 **CFM LEAP** 发动机制造的燃油喷嘴头：约 20 个钎焊和焊接零件组成的组件，被单个钴铬合金 LPBF 零件取代，GE 称其轻 25 %、耐久 5 倍。

集成的**设计自由红利**是：

- **更少的界面**：没有紧固件、没有密封、没有焊缝、没有公差累积。每个界面都是一个潜在的泄漏点、一个疲劳源和一笔装配成本。
- **内部特征**：跟随表面的随形冷却流道、带平滑弯头的内部流体通道、嵌入式传感器、梯度孔隙过滤器。
- **优化的载荷路径**：材料去往载荷去的地方，而不是铣刀能够到的地方。
- **缩短供应链**：一个零件、一张订单、一次检验、一个批次。

集成的**设计自由代价**是：

- **一种材料**：你无法把一个钛支架、一个橡胶密封和一个铝壳体集成在一起。集成零件是一种合金，而你消除的界面同时也是材料边界。
- **一种失效模式**：如果集成零件开裂，整个就是废品。如果组件开裂，你换一个紧固件。
- **一次鉴定**：集成零件必须作为单个部件鉴定，包含所有载荷工况、所有损伤容限、所有检测要求。组件是逐个零件鉴定的，界面是试验过的。
- **一条供应链**：如果增材机器停机，零件就造不出来。如果数控车间停机，你还有三个备份。
:::

::: definition 悬垂、自支撑角与支撑 {#def-overhangs}
粉末床工艺中水平或接近水平的表面，其下方没有材料支撑熔池。熔池下塌，粉末掉进熔道，表面粗糙。**自支撑角**是表面能够自支撑的最小角度（从构建板量起）：

- **LPBF 金属**：与水平面成 45°（与垂直面成 45°）。低于 45° 时表面粗糙（$R _ { a }$ 20–40 μm，而垂直面为 8–15 μm），尺寸精度变差（±0.2–0.5 mm，而垂直面为 ±0.1 mm），孔隙率升高（熔池塌入下方粉末）。
- **EB-PBF**：可以做比 LPBF 更平缓的悬垂，因为轻度烧结的粉末床能支撑悬垂，而高温构建的残余应力很小；支撑主要用作散热体。
- **FDM**：与水平面约成 45°（"45° 规则"），因为每条丝道需要一部分搭在下一层丝道上；两个支点之间的短水平桥可以跨过。
- **SLA**：0°（零件锚定在板上，树脂支撑悬垂），但 FEP 膜上的剥离力限制了悬垂面积。

**支撑**是把悬垂锚定到板上或零件上的牺牲结构。在 LPBF 中，支撑通常是致密块（用于锚固）或点阵（便于去除），通过切割、打磨或化学腐蚀去除。**每个支撑都会留下一个痕迹：支撑被切掉处的 0.2–0.5 mm 小坑，它是应力集中也是表面缺陷。设计规则是：最小化支撑面积，把支撑放在非关键表面，并在后处理成本中计入支撑去除的预算。**
:::

::: example 八面体桁架点阵设计 {#ex-octet level=3 check="15"}
一个 316L 的八面体桁架点阵（$E _ { s } = 1 9 3 \ \mathrm { G P a }$ ，$\sigma _ { Y , s } = 2 0 5 \ \mathrm { M P a }$ ），杆长 $l = 2 \ \mathrm { m m }$ ，杆径 $d = 0 . 3 \ \mathrm { m m }$ 。计算相对密度、有效模量和压缩屈服强度。（以百分数填写相对密度。）

$$

$$

$$
{ \frac { E ^ { * } } { E _ { s } } } \; \approx \; { \frac { \bar { \rho } } { 9 } } \; = \; 0 . 0 1 6 7 \quad \Longrightarrow \quad E ^ { * } \; \approx \; 3 . 2 \ \mathrm { G P a }
$$

$$
{ \frac { \sigma _ { Y } ^ { * } } { \sigma _ { Y , s } } } \; \approx \; { \frac { \bar { \rho } } { 3 } } \; = \; 0 . 0 5 0 \quad \Longrightarrow \quad \sigma _ { Y } ^ { * } \; \approx \; 1 0 \ \mathrm { M P a }

**该点阵致密度 15 %，模量是实心 316L 的 1/60，屈服强度是 1/20。**（$d / l = 0 . 1 5$ 时杆已不算很细长，节点重叠使真实密度略低；这些数值应视为估计。）**设计问题从来不只是"点阵够不够强"，而是"点阵在干什么"——对热交换器或吸能器，3 GPa 和 10 MPa 也许绰绰有余；对主承力结构，同样质量的实壁通常抗弯刚度更高。**

## 6. 后处理、表面质量与质量

::: definition 表面质量、支撑去除与成形表面 {#def-surface-am}
增材制造零件的成形表面粗糙度由工艺决定：

| 工艺 | 成形 $R _ { a }$ （$\mu \mathrm { m }$ ） | 主导粗糙度来源 |
|---------|------------------------------------------|--------------------------|
| SLA/DLP | 1–5 | 像素尺寸、层线 |
| FDM | 5–15 | 丝道宽度、阶梯 |
| SLS | 10–20 | 粉末粒径 |
| LPBF | 8–20 | 粉末粘附、阶梯 |
| EB-PBF | 15–30 | 烧结皮、粉末 |
| DED | 50–200 | 焊道波纹 |
| 黏结剂喷射 | 10–25 | 粉末粒径 |

**粉末床工艺中粗糙度的主导来源不是阶梯，而是表面上部分烧结的粉末颗粒。**一个部分熔合到表面的 30 μm 粉末颗粒造成 15 μm 的凸起，这些凸起的分布给出 10–15 μm 的 $R _ { a }$ ——与砂铸表面相当。**要在增材制造零件上获得机加工表面质量（$R _ { a } < 1 . 6 \ \mu \mathrm { m }$ ）的唯一方法是机加工，而机加工的唯一方法是在关键表面留机加工余量（0.3–0.5 mm）并为机加工工序做预算。**

**支撑去除**是手工或半自动操作：用斜口钳剪掉支撑、打磨痕迹、喷砂表面。对内部流道，**磨料流加工（AFM）**把含磨料的聚合物压过流道，把内表面抛光到 $R _ { a } < 1 . 6 \ \mu \mathrm { m }$ 。对铝零件，在热碱槽中**化学腐蚀**几分钟就能去除几十微米，通过优先溶解凸起的颗粒使表面光滑。**对复杂内部几何，后处理成本可能超过建造成本，后处理周期可能超过建造周期。**
:::

::: definition 热等静压、热处理与显微组织 {#def-hip}
**热等静压（HIP）**使零件在 900–1 200 °C 下承受 100–200 MPa 氩气 2–4 小时。静水压力通过蠕变和扩散焊合闭合内部孔隙，温度使显微组织均匀化。效果是：

- **孔隙率**：HIP 靠蠕变和扩散焊合闭合内部孔隙，小孔隙最快。它无法闭合与表面连通的孔隙（气体直接进入其中），而充有不溶性氩气的孔隙能缩小，但在随后的热处理中会重新张开。**HIP 不是烂参数的补救；它是好参数的抛光。**
- **疲劳寿命**：HIP 使 LPBF Ti-6Al-4V 在 $1 0 ^ { 6 }$ 周次下的疲劳寿命提高 30–100 %，因为引发裂纹的孔隙被消除。改善在周次高时最大（裂纹萌生阶段主导），在周次低时最小（裂纹扩展阶段主导）。
- **延性**：HIP（铝合金约 $5 0 0 \ \mathrm { ^ \circ C }$ ）使 LPBF AlSi10Mg 的伸长率提高数倍，因为 Si 网络打碎并粗化，代价是失去大部分成形态强度。
- **显微组织**：约 $9 2 0 \ \mathrm { ^ \circ C }$ 的 HIP 把 LPBF Ti-6Al-4V 的 $\alpha ^ { \prime }$ 马氏体分解为较粗的片层 $\alpha { + } \beta$ 组织，使屈服强度降低约 10–15 %，伸长率约翻一番。

增材制造零件的**热处理**遵循与常规热处理相同的规则，只多一条：**去应力退火必须在零件从板上切下之前完成**，因为切割会释放残余应力并使零件变形。LPBF Ti-6Al-4V 的标准顺序是：$7 0 0 \ \mathrm { ^ \circ C }$ 去应力退火 2 小时（在炉中、在板上）→ 从板上切下 → 去除支撑 → 热等静压（例如 $9 2 0 \ \mathrm { ^ \circ C }$ / 100 MPa / 2 h，在 ASTM F3001 允许的范围内）→ 机加工关键面 → 检测。
:::

::: definition 粉末处理、回收与质量控制 {#def-powder}
金属增材制造粉末是一项昂贵的投入：2020 年代中期的示意价格为 316L 每公斤几十美元，IN718 等镍合金稍高，Ti-6Al-4V 每公斤几百美元。机器里的大部分粉末并不被消耗：未熔化的粉末经筛分后重用，所以每个零件购买的粉末量是零件质量加上支撑、飞溅和筛分损失——典型为零件质量的 1.2–2 倍——直到回收粉末达到其重用极限。

**粉末降解**发生在每一个循环：粉末暴露于激光、气氛和铺粉刮刀。机理是：

- **吸氧**：粉末表面氧化，钛和铝尤甚。氧含量随每次重用逐渐升高，例如 Ti-6Al-4V ELI 成品零件的氧含量上限为 0.13 %（1 300 ppm），所以粉末必须在达到之前退役。**对活性合金，氧含量是最重要的单一粉末质量指标。**
- **颗粒粗化**：细粉被筛除去，卫星粉（附着在大颗粒上的小颗粒）不会，粒径分布向粗移。更粗的粉末需要更厚的层和更高的能量密度。
- **形貌变化**：球形颗粒在反复热循环后变得不规则，降低流动性和堆积密度。
- **污染**：铺粉刮刀、构建板和上一个零件引入外来颗粒。断裂刮刀带入钛零件的 50 μm 钨夹杂是裂纹源。

增材制造零件的**质量控制**是三层问题：

1. **在线监控**：熔池相机（光电二极管、高速相机）、声学传感器、逐层成像。目标是在缺陷形成时而不是零件建成后检测到它。**还没有任何在线监控系统可靠到能实时拒绝一层，但它们全都足以标记异常以供建成后检测。**
2. **建成后无损检测**：X 射线 CT（金标准，10–50 μm 分辨率，贵且慢）、超声（快、便宜、限于简单几何）、渗透检测（仅表面缺陷）、涡流（表面和近表面）。**CT 是唯一能在复杂几何中找到内部 LoF 缺陷的方法，这也是检测在认证增材零件成本中占很大比例的原因之一。**
3. **试棒试验**：拉伸棒、疲劳棒、断裂韧度试样，与零件同批建造、按构建方向、用同一粉末批次、经同样后处理。**试棒是零件的出生证明，没有它零件就没有许用值。**
:::

::: example 表面质量改善 {#ex-surface-am level=3 check="50"}
一个 LPBF 316L 零件的成形 $R _ { a }$ 为 12 μm。图纸要求密封面 $R _ { a } \leq 1 . 6 \ \mu \mathrm { m }$ 。附着的粉末颗粒最多高出名义表面 40 μm，切削还必须再深入名义表面以下 10 μm 才能清除颗粒间的谷底。最小的后处理路线是什么，最少要去除多深的材料？（以 μm 填写深度。）

要达到 $R _ { a } = 1 . 6 \ \mu \mathrm { m }$ ，必须切到粉末颗粒及其间的谷底以下：至少 $4 0 + 1 0 = { \bf 5 0 \ \mu m }$ 。实践中 CAD 模型上的机加工余量更大，以同时覆盖变形和定位误差。路线是：

1. **铣削**密封面，留 0.3 mm 余量（CAD 模型上的机加工余量）。
2. **精加工**：先喷砂再抛光，或磨削，或研磨。

**替代方案——试图抛光成形表面——行不通，因为粉末颗粒附着并不均匀，抛光会在颗粒脱落处产生凹坑。规则是：表面质量要紧就机加工它，要机加工它就在设计中留余量。**
:::

## 7. 经济性：增材制造何时赢、何时输

::: definition 增材制造成本模型 {#def-am-cost}
增材制造零件的成本是：

$$
c _ { \text{part } } \; = \; { \frac { C _ { \text{machine } } \, t _ { \text{build } } } { N _ { \text{parts } } } } \; + \; k _ { \text{powder } } \, C _ { \text{powder } } \, m _ { \text{part } } \; + \; C _ { \text{labour } } \; + \; C _ { \text{post } } \; + \; C _ { \text{inspect } }
$$

其中 $C _ { \text{machine } }$ 是机器小时费率（金属 LPBF 约每小时 100–300 美元，含折旧、气体和电力；聚合物 FDM 低得多），$t _ { \text{build } }$ 是建造时间，$N _ { \text{parts } }$ 是每次建造的零件数，$k _ { \text{powder } }$ 是每单位零件质量消耗的粉末质量（1.2–2，计入支撑、飞溅和筛分损失），$C _ { \text{powder } }$ 是每 kg 粉末成本，$m _ { \text{part } }$ 是零件质量，$C _ { \text{labour } }$ 是操作工时（装夹、取件、去支撑），$C _ { \text{post } }$ 是后处理成本（热等静压、机加工、喷砂），$C _ { \text{inspect } }$ 是检测成本（CT、试棒、无损检测）。

**占主导地位的是机器时间和后处理。**一个示意性的航空钛合金 LPBF 支架，单件建造（全部以美元计）：

| 项目 | 成本（美元） |
|------|------|
| 机器时间（20 h，每小时 200） | 4 000 |
| 粉末（零件 2 kg，消耗 3 kg，每 kg 300） | 900 |
| 人工（4 h，每小时 60） | 240 |
| 后处理（去应力、热等静压、机加工、喷砂） | 3 500 |
| 检测（CT、试棒） | 2 000 |
| **总计** | **10 640** |

**机器时间占总成本 38 %，后处理 33 %，检测 19 %，因为零件离开机器时并未完成，在被扫描之前也不被信任；粉末虽然每公斤很贵，却不到 10 %。**
:::

::: example 盈亏平衡：增材制造 vs 常规机加工 {#ex-breakeven level=3 check="13.3"}
（a）一个钛支架从锻坯机加工每件 20 000 美元（含 90 % 的买飞比废料），另加 5 000 美元夹具；用 LPBF 打印每件 14 000 美元，无夹具。（b）一个简单铝支架机加工每件 500 美元，另加 20 000 美元夹具；用 LPBF 每件 2 000 美元。分别求盈亏平衡批量。（填写情形（b）的盈亏平衡批量，保留一位小数。）

（a）常规单件成本为 $c _ { \text{conv } } = 2 0 \ 0 0 0 + 5 0 0 0 / N$ ，增材单件成本为 $c _ { \text{AM } } = 1 4 \ 0 0 0$ （无夹具、无摊销）。令两者相等：

$$
2 0 \ 0 0 0 + { \frac { 5 0 0 0 } { N } } \; = \; 1 4 \ 0 0 0 \quad \Longrightarrow \quad { \frac { 5 0 0 0 } { N } } \; = \; - 6 0 0 0
$$

**该方程没有正解：增材在每个批量都更便宜，因为增材单件成本低于常规单件成本，而且没有夹具要摊销。**（b）只有当常规单件成本低于增材单件成本时才存在盈亏平衡：

$$
N ^ { * } \; = \; { \frac { C _ { \text{fixture } } } { c _ { \text{AM } } - c _ { \text{conv } } } } \; = \; { \frac { 2 0 \ 0 0 0 } { 2 0 0 0 - 5 0 0 } } \; = \; { \frac { 2 0 \ 0 0 0 } { 1 5 0 0 } } \; = \; { \bf 1 3 . 3 \ 件 }
$$

**13 件时增材仍略便宜（机加工每件 $5 0 0 + 2 0 \ 0 0 0 / 1 3 = 2 0 3 8$ 美元）；从 14 件起，夹具成本摊平，常规机加工获胜。盈亏平衡批量是夹具成本被摊平的零件数，而对增材它几乎总在 50 以下，因为增材没有夹具。** **真正的问题不是"我需要多少件"，而是"增材单件成本有没有竞争力"——对复杂、小批量、高价值零件，答案是有的。**
:::

## 习题

::: exercise FDM 各向异性与设计 {#ex-fdm-aniso level=2 check="2"}
一个 PA12（本色）FDM 零件沿丝道方向（X）的拉伸强度为 50 MPa，沿 Z 为 36 MPa。一个支架沿 Z 承受 36 MPa 拉伸应力。对破坏的安全系数是多少？若安全系数必须为 2.0，Z 向承载截面必须增大多少倍？（填写倍数。）

::: solution
许用系数是 $3 6 / 3 6 = 1 . 0$ ——**没有裕度**。要达到 SF = 2.0，应力必须减半，即在 Z 方向把横截面积加倍。Z 向厚度必须增大 **2.0** 倍，比如从 5 mm 到 10 mm。**替代方案是在构建中把零件旋转 90°，使载荷沿 X，那里强度是 50 MPa、安全系数是 $5 0 / 3 6 = 1 . 3 9$ ——仍不到 2.0，但接近得多，而且截面只需增大 44 % 而不是 100 %。**
:::
:::

::: exercise SLA 曝光与分辨率 {#ex-sla-res level=3 check="0.91"}
一种丙烯酸酯树脂的 $D _ { p } = 8 0 \ \mu \mathrm { m }$ ，$E _ { c } = 1 0 \ \mathrm { m J / c m ^ { 2 } }$ 。目标层厚 50 μm，目标过固化 30 μm（所以 $C _ { d } = 8 0 \ \mu \mathrm { m }$ ）。需要什么曝光剂量？在 $I _ { 0 } = 3 0 \ \mathrm { m W / c m ^ { 2 } }$ 下曝光时间是多少？（以秒填写时间。）

::: solution
$$
E \; = \; E _ { c } \, e ^ { C _ { d } / D _ { p } } \; = \; 1 0 \, e ^ { 8 0 / 8 0 } \; = \; 1 0 \, e \; = \; 2 7 . 2 \ \mathrm { m J / c m ^ { 2 } }
$$

$$
t \; = \; E / I _ { 0 } \; = \; 2 7 . 2 / 3 0 \; = \; { \bf 0 . 9 1 \ s }
$$

**曝光不到一秒，这就是 DLP 和 MSLA 快的原因。曝光对过固化的敏感度是指数式的：过固化从 30 增到 50 μm（增加 67 %）使曝光增加 $e ^ { 2 0 / 8 0 } = 1 . 2 8$ ，即增加 28 %：所需剂量随固化深度指数增长。**
:::
:::

::: exercise LPBF 工艺窗口 {#ex-lpbf-window level=3 check="47.6"}
一次 316L 的 LPBF 构建使用 $P = 2 0 0 \ \mathrm { W }$ ，$v = 1 0 0 0 \ \mathrm { m m / s }$ ，$h = 1 0 0 \ \mu \mathrm { m }$ ，$t = 3 0 \ \mu \mathrm { m }$ 。计算 $E _ { v }$ 。若扫描间距为加快构建加宽到 140 μm，新的 $E _ { v }$ 是多少，是否仍在 316L 窗口（30–80 J/mm³）内？（以 J/mm³ 填写新的 $E _ { v }$ 。）

::: solution
$$
E _ { v 1 } \; = \; { \frac { 2 0 0 } { 1 0 0 0 \times 0 . 1 0 0 \times 0 . 0 3 0 } } \; = \; { \frac { 2 0 0 } { 3 . 0 } } \; = \; 6 6 . 7 \ \mathrm { J / m m ^ { 3 } } \quad \checkmark
$$

$$
E _ { v 2 } \; = \; { \frac { 2 0 0 } { 1 0 0 0 \times 0 . 1 4 0 \times 0 . 0 3 0 } } \; = \; { \frac { 2 0 0 } { 4 . 2 } } \; = \; { \bf 4 7 . 6 \ \mathrm { J / m m ^ { 3 } } }
$$

**47.6 J/mm³ 仍在 316L 窗口（30–80）内，但对 200 μm 宽的熔道，相邻熔道重叠从 50 % 降到 30 %，尽管能量密度名义上足够，熔道边界处仍可能出现未熔合孔隙。教训：$E _ { v }$ 是筛选参数，不是充分条件。**
:::
:::

::: exercise 黏结剂喷射的烧结收缩 {#ex-bj-shrink level=2 check="18.1"}
一个黏结剂喷射 316L 零件的生坯密度为理论密度的 55 %。烧结到全致密时线收缩是多少？100 mm × 50 mm × 20 mm 生坯烧结后的尺寸是多少？（以百分数填写收缩。）

::: solution
$$

::: exercise 推导：阶梯粗糙度公式 {#ex-derive-staircase level=4 check="5.3"}
推导与构建板成 $\theta$ 角、以层厚 $h$ 建造的表面的阶梯粗糙度公式 $R _ { a } = h \cos \theta / 4$ 。取 $h = 3 0 \ \mu \mathrm { m }$ 、$\theta = 4 5 ^ { \circ }$ 求值。（以 μm 填写 $R _ { a }$ 。）

::: solution
每个台阶有高 $h$ 的竖直立面和宽 $w = h / \tan \theta$ 的水平踏面；轮廓的中线沿名义斜面、穿过各台阶角点。因此每个台阶是一个直角三角形，其斜边长 $\sqrt { h ^ { 2 } + w ^ { 2 } } = h / \sin \theta$ ，位于中线上。它垂直于中线的高度是

$$
R _ { t } \; = \; { \frac { h \, w } { \sqrt { h ^ { 2 } + w ^ { 2 } } } } \; = \; { \frac { h \cdot h / \tan \theta } { h / \sin \theta } } \; = \; h \cos \theta .
$$

粗糙度从把轮廓上下面积等分的中线量起，所以轮廓是绕自身中线、峰谷高度为 $h \cos \theta$ 的锯齿波。侧边为直线、峰谷高度为 $R _ { t }$ 的锯齿波，其偏差 $y$ 在 $- R _ { t } / 2$ 与 $+ R _ { t } / 2$ 之间均匀分布，所以

$$
R _ { a } \; = \; { \frac { 1 } { L } } \int _ { 0 } ^ { L } | y ( x ) | \, \mathrm { d } x \; = \; { \frac { R _ { t } } { 4 } } \; = \; { \frac { h \cos \theta } { 4 } } .
$$

$h = 3 0 \ \mu \mathrm { m }$ 、$\theta = 4 5 ^ { \circ }$ 时：$R _ { a } = 3 0 \times 0 . 7 0 7 / 4 = { \bf 5 . 3 \ \mu m }$ 。极限校核：竖直壁（$\theta = 9 0 ^ { \circ }$ ）没有台阶，$R _ { a } = 0$ ；当 $\theta \to 0$ 时踏面变得很长，模型给出的 $h / 4$ 并不能很好地描述一个实际上平坦、只偶有台阶边缘的表面。$\blacksquare$
:::
:::

::: exercise 推导：由 Beer-Lambert 定律推导 Jacobs 方程 {#ex-derive-jacobs level=4 check="2.3"}
由 Beer-Lambert 定律和凝胶判据推导 Jacobs 方程 $C _ { d } = D _ { p } \ln ( E / E _ { c } )$ ，并求表面剂量为临界剂量十倍时的 $C _ { d } / D _ { p }$ 。（填写 $C _ { d } / D _ { p }$ ，保留两位有效数字。）

::: solution
Beer-Lambert 定律给出深度 $z$ 处的强度：

$$
I ( z ) \; = \; I _ { 0 } \, e ^ { - z / D _ { p } }
$$

深度 $z$ 处的曝光剂量为 $E ( z ) = I ( z ) \, t = I _ { 0 } \, t \, e ^ { - z / D _ { p } } = E _ { 0 } \, e ^ { - z / D _ { p } }$ ，其中 $E _ { 0 } = I _ { 0 } t$ 是表面剂量。树脂在局部剂量等于临界剂量时凝胶：$E ( C _ { d } ) = E _ { c }$ 。因此：

$$
E _ { c } \; = \; E _ { 0 } \, e ^ { - C _ { d } / D _ { p } } \quad \Longrightarrow \quad { \frac { E _ { 0 } } { E _ { c } } } \; = \; e ^ { C _ { d } / D _ { p } } \quad \Longrightarrow \quad \boxed { \; C _ { d } \; = \; D _ { p } \, \ln { \frac { E _ { 0 } } { E _ { c } } } \; } \quad \blacksquare
$$

$E _ { 0 } = 1 0 \, E _ { c }$ 时：$C _ { d } / D _ { p } = \ln 1 0 = { \bf 2 . 3 }$ 。

**其物理内涵是：固化深度正比于透射深度（树脂的材料性能），而对曝光剂量（工艺变量）是对数关系。对数意味着固化深度对曝光的大变化不敏感、而对 $E _ { c }$ 附近的小变化非常敏感——工艺窗口在曲线的底部，不在顶部。**
:::
:::

::: exercise 变形缩放 {#ex-distort-scale level=3 check="32"}
一堵 100 mm 高的 LPBF 墙在顶部变形 2 mm。若高度增到 200 mm 且壁厚减半，新的变形是多少？（以 mm 作答。）

::: solution
由变形缩放 $\delta \propto H ^ { 2 } / t ^ { 2 }$ ：

$$
{ \frac { \delta _ { 2 } } { \delta _ { 1 } } } \; = \; \left( { \frac { H _ { 2 } } { H _ { 1 } } } \right) ^ { 2 } \left( { \frac { t _ { 1 } } { t _ { 2 } } } \right) ^ { 2 } \; = \; 2 ^ { 2 } \times 2 ^ { 2 } \; = \; 1 6
$$

$$
\delta _ { 2 } \; = \; 1 6 \times 2 \; = \; { \bf 3 2 \ m m }
$$

**变形增大 16 倍——零件从板上剥离。设计对策是加支撑、加厚壁、降低高度，或把零件拆成两次较矮的建造。**
:::
:::

::: exercise DED 沉积速率与经济性 {#ex-ded-rate level=3 check="1.25"}
一台送丝 DED 系统以 4 kg/h 沉积 316L。一个 5 kg 支架需要多少小时沉积完？若小时费率 150 美元，机器成本是多少？与 50 cm³/h 的 LPBF 比较（密度 8 000 kg/m³，机器费率每小时 250 美元）。（以小时填写 DED 沉积时间。）

::: solution
**DED**：$t = 5 / 4 = 1 . 2 5 \ \mathrm { h }$ ，机器成本 $= 1 . 2 5 \times 1 5 0 = 1 8 8 \ \text{美元}$ 。

**LPBF**：体积 $= 5 / 8 0 0 0 = 6 2 5 \ \mathrm { c m ^ { 3 } }$ ，时间 $= 6 2 5 / 5 0 = 1 2 . 5 \ \mathrm { h }$ ，机器成本 $= 1 2 . 5 \times 2 5 0 = 3 \ 1 2 5 \ \text{美元}$ 。

**DED 快 10 倍（4 kg/h 对 0.4 kg/h），机器时间便宜约 17 倍，因为小时费率也更低。代价是分辨率：DED 做 2 mm 焊道，LPBF 做 60 μm 熔道。DED 零件需要 2–3 mm 机加工余量，这会去除沉积材料的 20–40 % 并增加机加工成本。对 5 kg 的敦实支架，DED 获胜；对 0.05 kg 的点阵支架，LPBF 获胜。**
:::

::: quiz LPBF 工艺物理 {#quiz-lpbf}
激光粉末床熔融中，体积能量密度 $E _ { v }$ 过高时会发生什么？

- [ ] 未熔合孔隙增加
- [x] 匙孔孔隙以球形气孔形式出现
- [ ] 熔池变得更宽更浅
- [ ] 零件变形更小

::: solution
**匙孔孔隙。**当 $E _ { v }$ 超过匙孔阈值（Ti-6Al-4V 约 80–120 J/mm³）时，汽化金属的反冲压力超过表面张力，在熔池中打出一个蒸气空腔。空腔坍塌并把氩气截留为球形孔隙。未熔合孔隙发生在相反的极端——$E _ { v }$ 太低、熔道不重叠时。随 $E _ { v }$ 增大熔池变得更窄更深（不是更宽更浅），变形增大（不是减小），因为热梯度更陡。
:::
:::

::: quiz 面向增材制造的设计 {#quiz-dfam}
下列哪个是 LPBF 金属正确的自支撑角（从构建板量起）？

- [ ] 30°——低于 30° 熔池下塌
- [x] 45°——低于 45° 表面粗糙且孔隙增加
- [ ] 60°——低于 60° 零件从板上剥离
- [ ] 70°——低于 70° 粉末坍塌

::: solution
**45°。**低于从构建板起 45° 时，熔池下面没有固体基板，塌入松散粉末，产生粗糙多孔的表面。零件不会在 45° 时从板上剥离（那是变形问题，是另一种机理），粉末也不会在 70° 时坍塌（铺粉刮刀把它压实）。45° 规则是指南不是定律：某些机器和参数集能以退化的质量做到 30° 悬垂，某些设计即使 60° 也需要支撑，如果悬垂很大的话。
:::

## 本讲的后续内容

- **[[manufacturing/process-selection]]** —— 增材制造是工艺选择树的一个分支，选择逻辑（复杂度、批量、材料、公差、表面质量）对增材制造和对其他所有工艺是一样的。区别在于增材制造的成本与复杂度无关，这打破了常规权衡。
- **[[manufacturing/joining]]** —— DED 是一个带数控头的焊接工艺，热循环、稀释、热影响区和残余应力是同样的物理。LPBF 熔池是一次微型焊接，凝固裂纹模型是同一个。
- **[[manufacturing/machining]]** —— 增材零件在每个关键面都需要机加工，机加工成本占零件成本的 20–50 %。设计必须包含机加工余量、夹具基准和刀具可达性。
- **[[manufacturing/polymer-composite-processing]]** —— FDM 是挤出工艺，SLS 是烧结工艺，SLA 是固化工艺。聚合物物理（粘度、结晶、固化动力学）与注塑和挤出相同。
- **[[manufacturing/metrology-quality]]** —— 增材制造的质量问题就是鉴定问题：零件不是材料，材料不是数据表，数据表不是标准。试棒计划、CT 扫描和统计过程控制与任何受监管制造相同。
- **[[materials-science/phase-transformations]]** —— LPBF 显微组织是一个冷却速度为 $1 0 ^ { 5 } { - } 1 0 ^ { 6 } \ \mathrm { K / s }$ 的凝固问题，比熔模铸造快 1000 倍。相变、析出动力学和织构都与变形合金不同。
- **[[materials-science/defects-diffusion]]** —— 烧结（黏结剂喷射、SLS）是扩散过程，Frenkel 模型、Coble 蠕变模型和粗化动力学与粉末冶金相同。
- **[[solid-mechanics/composites]]** —— 点阵结构是一类多孔材料，Gibson-Ashby 缩放与泡沫相同。LPBF 零件的各向异性与单向复合材料相同：一个方向强、另一个方向弱，设计必须同时考虑两者。
- **[[design-process/design-for-manufacture]]** —— 面向增材制造的设计（DfAM）是面向制造的设计（DFM）的子集，原则相同：面向工艺设计，而不是面向模型设计。区别在于增材制造的工艺约束是热学的（残余应力、变形、热撕裂）而不是力学的（刀具可达、拔模角、最小壁厚）。

::: history 增材制造：从快速原型到生产 {#history-am}
**1981。** 名古屋市工业研究所的小玉秀男（Hideo Kodama）在 *Review of Scientific Instruments* 上发表《用光硬化聚合物自动制作三维塑料模型的方法》，描述通过掩模或扫描光纤用紫外光逐层固化光敏聚合物——这是最早公开发表的增材工艺描述之一。

**1984–1986。** 在 Ultra Violet Products 公司工作的查尔斯（查克）·赫尔（Charles (Chuck) Hull）申请美国专利 4 575 330《通过立体光刻制造三维物体的装置》（1984 年申请，1986 年授权）：紫外激光在光敏树脂槽表面描出每一层，下方的平台逐层下降。赫尔于 1986 年联合创立 3D Systems，STL 文件格式即来自其软件。

**1986–1989。** 得克萨斯大学奥斯汀分校的卡尔·德卡德（Carl Deckard）和约瑟夫·比曼（Joseph Beaman）开发出**选区激光烧结**（SLS），用激光逐层熔合粉末床。大学把它授权给 DTM 公司，3D Systems 于 2001 年收购了 DTM。

**1989。** 斯科特·克伦普（S. Scott Crump）和丽莎·克伦普（Lisa Crump）为**熔融沉积成形**（FDM）申请专利并创立 Stratasys；其第一台机器 3D Modeler 于 1992 年发货。2009 年 FDM 关键专利到期后，开源的 RepRap 项目帮助丝材打印机成为消费产品。

**1989–1993。** MIT 的伊曼纽尔·萨克斯（Emanuel Sachs）、迈克尔·西玛（Michael Cima）及其同事发明"三维打印"——即**黏结剂喷射**——1993 年获得专利（US 5 204 055），授权给 Soligen、Z Corporation 和 ExOne 等公司。

**1995–1996。** 慕尼黑的 EOS 推出 EOSINT M 250 直接金属激光烧结机（1995）。1996 年，亚琛弗劳恩霍夫激光技术研究所（ILT）的威廉·迈纳斯（Wilhelm Meiners）、康拉德·维森巴赫（Konrad Wissenbach）和安德烈斯·加塞尔（Andres Gasser）申请德国专利 DE 196 49 865，内容是用激光把逐层铺放的金属粉末完全熔化——即**选区激光熔化**，今天激光粉末床熔融的基础。

**1990 年代后期。** 桑迪亚国家实验室开发出送粉式定向能量沉积工艺**激光工程化净成形**（LENS），由 Optomec 商业化。Arcam 于 1997 年在瑞典默恩达尔（Mölndal）成立，开发**电子束熔化**；其第一台商用机器 EBM S12 于 2002 年发货。

**2015。** ISO 和 ASTM 联合发布术语标准 ISO/ASTM 52900，其中给出本讲使用的七个工艺类别（2021 年修订）。

**2016。** CFM LEAP 发动机投入运营，装有 GE 用 LPBF 制造的钴铬合金燃油喷嘴头，取代约 20 个零件的组件；GE 位于亚拉巴马州奥本的工厂于 2021 年交付第 100 000 个喷嘴头。同年 GE 收购 Arcam 和 Concept Laser，组建 GE Additive。**LEAP 喷嘴是增材制造作为生产工艺、而不是原型工艺的典型案例。**
:::

::: summary 增材制造 {#summary-am}
- **增材制造是七个工艺，不是一个。**材料挤出（FDM）、光敏树脂槽聚合（SLA/DLP）、粉末床熔融（LPBF/EB-PBF）、黏结剂喷射、材料喷射、定向能量沉积和层压成形，物理不同、设计规则不同、性能不同、成本不同。"3D 打印它"不是制造决策。
- **零件有构建方向，而构建方向就是晶粒方向。**LPBF 零件是各向异性的：Z 向伸长率是 XY 的 60–80 %，Z 向疲劳强度比 XY 低 30–50 %，Z 向疲劳寿命由在 XY 平面扁平的未熔合缺陷主导。把载荷路径设计在 XY 平面，对 Z 折减，并在你折减的那个方向测试件。
- **热历史就是显微组织。**每一层都是以 $1 0 ^ { 5 } { - } 1 0 ^ { 6 } \ \mathrm { K / s }$ 淬火、随后被上方各层再加热的微型焊缝。冷却速度决定胞和晶粒尺寸，再加热决定析出状态，热历史决定残余应力。同样的粉末、同样的合金、同样的机器，随参数集和后处理不同可以产生差别很大的强度和延性。
- **体积能量密度 $E _ { v } = P / ( v \, h \, t )$ 是 LPBF 的主变量。**低于 30–40 J/mm³ 出现未熔合孔隙；高于 80–120 J/mm³ 出现匙孔孔隙。窗口只有 2–3 倍宽，找到它的唯一方法是在你的机器上用你的粉末做密度矩阵。
- **零件离开构建板之前残余应力就在屈服点。**屈服强度天花板（$\sigma _ { \text{res } } = \min ( E \alpha \Delta T / ( 1 - \nu ) , \sigma _ { Y } )$ ）适用于每一层。变形按 $H ^ { 2 } / t ^ { 2 }$ 缩放：高度加倍变形变为四倍，壁厚加倍变形变为四分之一。适度预热几乎不改变残余应力；EB-PBF 那样的高温粉末床之所以有效，是因为屈服强度低、应力在构建期间蠕变松弛。
- **热撕裂杀死裂纹敏感合金。**Al 7075、IN738LC 和某些工具钢的凝固区间宽到 LPBF 的应变速率（$1 { - } 1 0 \ \mathrm { s ^ { - 1 } }$ 量级）会把液膜拉开。补救是高预热、EB-PBF、改变合金成分或换合金。
- **点阵不是轻量化结构；它们是功能材料。**Gibson-Ashby 缩放意味着致密度 5 % 的弯曲主导点阵（$E ^ { * } / E _ { s } \approx { \bar { \rho } } ^ { 2 }$ ）只有实心模量的约 0.25 %，即使拉伸主导的八面体桁架（$\approx \bar { \rho } / 9$ ）也只有约 0.6 %。在点阵干活的地方用它（热、生物、吸能），不在它干活的地方用实壁。
- **后处理占零件成本的 30–70 %。**去支撑、去应力退火、热等静压、机加工、喷砂和检测不是可选项。在设计中为它们做预算，留机加工余量，把关键尺寸放在机加工特征上。
- **粉末就是材料。**吸氧、颗粒粗化、卫星粉污染和回收历史在每个循环改变粉末。规定粉末、批次、回收次数上限和氧含量，先测粉末再测零件。
- **复杂度免费、批量低、交付周期要紧时，增材制造获胜。**与常规机加工的盈亏平衡对大多数几何是 10–50 件。对复杂、集成、小批量、高价值零件（航空、医疗、工装），增材制造在每个批量都获胜。对简单、大批量、低成本零件，注塑和机加工获胜。
:::
