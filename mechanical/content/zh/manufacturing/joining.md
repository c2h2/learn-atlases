接头是结构从一个零件变成一个组件的地方，也是结构破坏开始的地方。这不是悲观的观点，而是从自由轮（Liberty ships）以来每一本疲劳教科书和每一份事故调查报告的内容：**焊接桥梁的母材是一种均匀、各向同性、延性、可检测、强度可以算准到 5 % 以内的材料，而焊缝是一种不均匀、各向异性、铸造组织、带残余应力、带缺口、含缺陷的复合材料，其强度只能靠试验和检测来给出下限。**接头设计的全部内容由这一不对称性推出，而接头的*选用*全部由第二个事实推出：接头通常是整个组件里最贵的东西，因为它是唯一不增加任何功能的工序。翼梁有功能；翼梁与腹板接缝上一条 40 mm 的角焊缝存在，只是因为翼梁无法整体做出，而它要花钱、花工时、产生变形、需要检测——如果它处在疲劳关键部位——还会赔上整架飞机。

所以工程师面对接头的工作是依次回答四个问题。**第一：这个接头非得存在吗？**焊接框架上一半的焊缝存在，只是因为钢板从轧机出来只有 2 m 宽；支架上一半的螺栓存在，只是因为设计者拿不定主意。**第二：能不能用一种根本不留下接头的工艺做出来**——铸件、锻件、轧制坯料、旋压壳体、搅拌摩擦焊壁板、液压成形管？**第三：如果接头不可避免，就把它放在应力所在处、放在接头擅长的受力方向上、放在工艺能够到的几何位置、放在工艺能够容忍的材料上。**受剪的焊缝强度是受拉的焊缝的两倍；加工过的、带圆角的、连续细节处的焊缝是缺口处焊缝的两倍；看得见的焊缝是看不见的焊缝的三倍。**第四：按照接头的制造方式和检测方式来设计接头**，因为一个无法检测的接头，其强度全凭焊工在某个潮湿星期二的手气。

::: warning 接头出错的九种方式
**按母材强度来设计焊缝。**一条按 S355 静强度计算的角焊缝能通过静力计算，却会在几十万次循环内破坏，因为焊趾就是一条 1 mm 的裂纹，而细节的疲劳类别并不在乎你花钱买了什么钢号。**忽视残余应力。**焊缝从 1500 °C 冷却，被一吨冷的钢材约束着，因此最终处于拉伸屈服应力。你无法靠小心把它减小，只能移动它（喷丸、辊校、退火），或者绕开它设计——而你随后关于把使用应力"叠加"到残余应力上的任何计算都是错的，因为残余应力已经在屈服平台上，会自行松弛。**把焊缝放在做不出来的地方。**封闭箱形里 40 mm 深的角焊缝、焊枪够不到的焊根、焊工只能从一侧仰焊的位置、无法充氩保护的焊根：这些全都出自从未拿过焊枪的人之手，全都产生 60 % 的未熔合。**要从焊枪的角度来规定焊缝，或者让车间在报价阶段就告诉你做不到。****焊接热处理合金却假装它还是热处理状态。**一个 6082-T6 框架对接焊起来之后，其接头是 T4 状态，屈服强度减半，而且软化区比肉眼可见的热影响区宽三倍；15-5PH、7075、4340 和 17-4PH 都是同一个故事换了颜色。**要么按焊后性能设计，要么焊后进行热处理；如果选后者，要在图纸上写明，并为变形留出余量。****沿板厚方向加载钢板。**钢板是轧制的，所以在轧制平面内强、沿厚度方向弱——层状撕裂只需要面内抗拉强度 40 % 的应力，并从硫化物夹杂处起裂。喉厚垂直于板面受力的角焊缝正是这种情况，它是管节点错误构造中最常见的断裂。**假定填充金属与母材相同。**它从来不相同：焊缝金属是一个稀释 40 % 的铸件，具有柱状组织、熔合线处不同的成分，以及取决于热输入和层间温度的韧性。**不规定检测要求。**没有验收标准的焊缝就是一件装饰品。写明标准（EN ISO 5817 B、C 或 D 级；AWS D1.1 表 6.1）、方法、比例（10 % 还是 100 %），以及返修费用由谁承担。**螺栓连接在未加工的支承面上。**端面不平、不垂直于螺栓轴线的螺栓连接会使螺栓受弯，而一根受弯的 M16 会损失一半疲劳强度；一个垫圈或一个沉台面不花什么钱。**胶接接头然后让它受剥离。**胶粘剂抗剪强、抗拉弱——一条 25 mm 搭接用抗剪强度 30 MPa 的环氧胶粘剂，每毫米宽度能承载 750 N，而同一个接头像翻书一样打开时，在 5 MPa 下以十分之一的载荷剥离。如果你无法让胶粘剂受剪，就不要用胶粘剂。
:::

## 1. 焊缝是铸件，旁边是热影响区

::: definition 熔焊、热循环与三个区域 {#def-fus}
每一种熔焊工艺做的都是同一件事：往一小块体积里输入足够的热把它熔化，使熔池隔绝空气，然后让它凝固。输入的热量是**净热输入**

$$
E \; = \; \eta \, { \frac { V I } { v } } \quad [ \mathrm { J / m m } ]
$$

其中 $V$ 是电弧电压，$I$ 是电流，$v$ 是焊接速度，$\eta$ 是热效率——手工电弧焊 0.6，熔化极电弧焊 0.7-0.8，钨极惰性气体保护焊 0.6，埋弧焊 0.8-1.0，电子束焊 0.7，激光焊 0.2-0.5（取决于金属实际吸收了光束的多少）。$E$ 是决定焊缝显微组织、变形和力学性能的单一数字，焊工通过它的四个变量中的后三个来控制它。

让热源沿板面移动，金属中任意一点都经历一个**热循环**：以 $1 0 { - } 1 0 0 \ \mathrm { ^ \circ C / s }$ 的速率升温到一个随距焊缝距离衰减的峰值，熔池本身在固相线以上停留一两秒，而对钢来说决定组织的是冷却速度。穿过 $8 0 0 { - } 5 0 0 \ \mathrm { ^ \circ C }$ 窗口（奥氏体发生转变的区间）的冷却时间是冶金学家使用的数字，记作 $t _ { 8 / 5 }$；从激光焊的约 1 s 到厚板埋弧焊的 30-60 s，这就是同一种钢、同一种焊材，焊缝可以是韧性好的针状铁素体、也可以是脆性上贝氏体的原因。

电弧旁的金属分为三个区域，每个区域的破坏方式不同：

$$
\begin{array} { l l l l }
\textbf{区域} & \textbf{峰值温度} & \textbf{发生了什么} & \textbf{冷却后是什么} \\ \hline
\text{焊缝金属} & \text{液相线以上} & \text{一个铸件，以 } 1 { - } 1 0 \ \mathrm { K / m m } \text{ 凝固} & \text{柱状枝晶，稀释 } 4 0 \% \text{，各向异性} \\
\text{粗晶热影响区} & 1 1 0 0 ^ { \circ } \mathrm { C } \text{ 至固相线} & \text{晶粒在 } 1 3 0 0 \ \mathrm { ^ \circ C } \text{ 下长大数秒} & \text{脆性；限制韧性的区域} \\
\text{细晶热影响区} & A _ { c 3 } \text{ 至 } 1 1 0 0 \ \mathrm { ^ \circ C } & \text{完全重奥氏体化，细密重新形核} & \text{往往优于母材} \\
\text{临界两相热影响区} & A _ { c 1 } \text{ 至 } A _ { c 3 } & \text{部分转变，混合条带} & \text{不均匀，一条裂纹路径} \\
\text{亚临界 / 过时效区} & A _ { c 1 } \text{ 以下} & \text{回火，析出相粗化} & \text{在沉淀硬化合金中是软区}
\end{array}
$$

**稀释**指的是焊缝金属一部分是填充金属、一部分是熔化母材这一事实：稀释率为 $D$（高熔敷率工艺典型为 0.25，浅熔深的钨极氩弧焊打底焊道为 0.6-0.8）时，

$$
C _ { \text{weld } } \; = \; ( 1 - D ) \, C _ { \text{filler } } + D \, C _ { \text{parent } }
$$

而在焊缝金属与母材之间存在一条一两颗晶粒宽、成分从母材连续过渡到名义焊缝成分的**混合区**。这条几百微米宽的带子，就是异种金属焊缝破坏的位置，就是用低合金焊材焊高碳钢时硬脆相出现的位置，也是不锈钢焊缝焊在碳钢上做出硬到足以开裂的马氏体的位置。

最后是**凝固组织**：焊缝池是工业中冷却最快的铸件之一（熔合线处 $1 0 ^ { 3 } { - } 1 0 ^ { 6 } \ \mathrm { K / s }$），它在母材晶粒上外延凝固，所以整条焊缝是一束背离熔合线生长的柱状晶，因此具有**织构和各向异性**——轧制板上的一条焊缝，垂直于柱状晶方向比沿晶方向弱 20-40 %，韧性也低得多，这就是为什么焊缝从不被规定为"与母材等强"，而总是规定为"经试验达到 $X \ \mathrm { M P a }$ ，$Y \ \mathrm { J }$ ，$Z \ \mathrm { ^ \circ C }$"。
:::

::: proof 热影响区有多宽？ {#proof-haz}
速度 $v$ 移动的热源在身后留下一条尾迹，其中质点的温度大致随它离开电弧的距离 $x$ 指数衰减。对于线热源（板足够厚、热流按二维传播的长直焊缝），尾迹为

$$
T ( x ) - T _ { 0 } \; \approx \; \left( T _ { p } - T _ { 0 } \right) \exp \left( - { \frac { v x } { 2 \alpha } } \right)
$$

其中 $\alpha = \lambda / \rho c$ 是热扩散率（钢约 $6 \ \mathrm { m m ^ { 2 } / s }$ ，铝 $8 5 \ \mathrm { m m ^ { 2 } / s }$ ），$T _ { p }$ 是轴线上的峰值温度。尾迹的妙处在于**任意两条等温线之间的距离根本不依赖峰值温度**：若 $T _ { 1 }$ 和 $T _ { 2 }$ 分别出现在 $x _ { 1 }$ 和 $x _ { 2 }$ ，

$$
\frac { T _ { 1 } - T _ { 0 } } { T _ { 2 } - T _ { 0 } } \; = \; \exp \left( \frac { v ( x _ { 2 } - x _ { 1 } ) } { 2 \alpha } \right) \qquad \Longrightarrow \qquad \boxed { \; w _ { 1 2 } \; = \; { \frac { 2 \alpha } { v } } \, \ln \frac { T _ { 1 } - T _ { 0 } } { T _ { 2 } - T _ { 0 } } \; }
$$

对钢取 $v = 5 \ \mathrm { m m / s }$ ，把熔合线取在 $1 5 0 0 \ \mathrm { ^ \circ C }$ ，把转变热影响区的下边界取在 $7 5 0 \ \mathrm { ^ \circ C }$ ，$T _ { 0 } = 2 5 \ \mathrm { ^ \circ C }$ ，

$$
w \; = \; { \frac { 2 \times 6 } { 5 } } \ln { \frac { 1 4 7 5 } { 7 2 5 } } \; = \; 2 . 4 \times 0 . 7 1 \; = \; 1 . 7 \ \mathrm { m m }
$$

**这对电弧焊是正确的数量级，其中包含的两个比例关系正是应当记住的。**热影响区**与焊接速度成反比**——这就是为什么 $2 \ \mathrm { m / m i n }$ 的激光焊有一条要显微镜才能找到的热影响区，而手工气割焊有一条用尺子就能读出的热影响区。它**与热扩散率成正比**——这就是为什么铝的热扩散率是钢的十四倍，在同样速度下热影响区反而*更宽*，尽管焊薄件要容易得多。**指数尾迹还解释了与硬度最相关的那个数字：熔合线处的冷却速度是 $v ( T _ { p } - T ) / 2 \alpha$ ，所以快焊冷却快，而在可淬硬钢中快焊会做出马氏体。**
:::

::: example 能焊吗？碳当量 {#ex-ce level=3 check="0.56"}
一台压力容器筒体是 $2 2 \ \mathrm { m m }$ 的某种钢，成分为 $0 . 2 2 \ \mathrm { C }$ ，$1 . 2 \ \mathrm { M n }$ ，$0 . 2 5 \ \mathrm { C r }$ ，$0 . 1 5 \ \mathrm { M o }$ ，$0 . 1 0 \ \mathrm { V }$ ，$0 . 4 0 \ \mathrm { N i }$ ，$0 . 2 0 \ \mathrm { C u }$ 。需要预热吗？

$$
\mathrm { C E } \; = \; \mathrm { C } + { \frac { \mathrm { M n } } { 6 } } + { \frac { \mathrm { C r } + \mathrm { M o } + \mathrm { V } } { 5 } } + { \frac { \mathrm { N i } + \mathrm { C u } } { 1 5 } } \; = \; 0 . 2 2 + 0 . 2 0 + 0 . 1 0 + 0 . 0 4 \; = \; { \bf 0 . 5 6 }
$$

**焊接性：差。**碳当量 0.56 处于标尺顶端，所以焊接工艺要求 $1 5 0 { - } 2 0 0 \ \mathrm { ^ \circ C }$ 预热、层间温度上限 $2 5 0 \ \mathrm { ^ \circ C }$ 、在 $3 0 0 \ \mathrm { ^ \circ C }$ 烘干的低氢焊材、满足要求的最小焊缝尺寸，如果接头约束严重还要做两小时 $2 5 0 \ \mathrm { ^ \circ C }$ 的后热。**另一个答案，也是设计者本应最先给出的答案，是改用碳当量 0.40 的 HSLA 钢，上面这些就全都不需要了。**
:::

## 2. 各种工艺

::: definition 电弧焊工艺，以及各自的用途 {#def-arc}
电弧是一根 6000 K、长 2-4 mm、17-40 V、50-1600 A 的电离气体柱。区分各种电弧焊工艺的一切，在于**如何防止熔融金属接触氧和氮、填充金属如何送入、工件接受电弧功率的多少。**

$$
\begin{array} { l l l l l l }
\textbf{工艺} & \textbf{保护} & \textbf{填充金属} & \textbf{熔敷率} & \textbf{典型 } E \ [ \mathrm { J / m m } ] & \textbf{用途} \\ \hline
\text{SMAW（手工焊条）} & \text{燃烧的药皮套筒} & \text{焊条本身} & 1 { - } 3 \ \mathrm { k g / h } & 5 0 0 { - } 2 0 0 0 & \text{现场、厚件、任何金属、不怕风} \\
\text{GMAW（MIG/MAG）} & \text{气体（Ar/CO}_2) & \text{盘装焊丝} & 2 { - } 8 \ \mathrm { k g / h } & 3 0 0 { - } 1 5 0 0 & \text{批量生产、1-10 mm、机器人} \\
\text{FCAW（药芯焊丝）} & \text{气体或自保护} & \text{药芯焊丝} & 3 { - } 1 0 \ \mathrm { k g / h } & 6 0 0 { - } 2 5 0 0 & \text{船厂、现场、高熔敷率} \\
\text{GTAW（TIG）} & \text{惰性气体} & \text{手工送丝或不填} & 0 . 3 { - } 1 \ \mathrm { k g / h } & 1 5 0 { - } 6 0 0 & \text{打底、薄件、不锈钢、钛、质量} \\
\text{SAW（埋弧）} & \text{40 mm 厚的焊剂层} & \text{光焊丝，1-4 根} & 5 { - } 20 \ \mathrm { k g / h } & 2 0 0 0 { - } 6 0 0 0 & \text{长直焊缝、10-100 mm} \\
\text{螺柱焊} & \text{陶瓷环} & \text{螺柱本身} & 4 0 0 / \mathrm { h } & 1 0 0 { - } 4 0 0 & \text{剪力连接件、堆焊}
\end{array}
$$

这张表里有四个细节比表本身更值钱。**(1) 保护气体是工艺参数，不是耗材：**氩-18 % 二氧化碳在钢上给出冷静、穿透力强、射流过渡的电弧；纯二氧化碳更热、氧化性更强、更便宜、飞溅更大；氩-2 % 氧让不锈钢润湿得极好；氦提高电弧电压，用于厚铝和铜；而二氧化碳与铝、镁、钛化学不相容，这就是这些金属只在氩或氦中焊接的原因。**(2) GMAW 的熔滴过渡方式是一次相变：**在约 180 A 以下，焊丝每秒钟向熔池短路二十次（干净、温度低、适合薄板、熔敷率低）；超过该直径的临界电流后，金属以 70 m/s 的细雾状过渡（平滑、熔深大、速度快，但 4 mm 以下不能用，会烧穿）；脉冲射流过渡一个脉冲送一滴，用一半的热买到射流过渡。**(3) 埋弧焊是熔敷率的冠军、位置的囚徒**——1600 A 通过埋在熔渣下的光焊丝，99 % 的金属和电弧热进入接头，无光、无烟、无飞溅，而且焊缝必须平位置下行，否则焊瘤会掉下来。**(4) 钨极氩弧焊是当你必须把活干对时用的工艺：**电弧在不熔化电极上引燃，填充金属手工点入或由机器推入，熔敷率只有熔化极电弧焊的五分之一——但它是唯一没有熔剂、没有飞溅、不吸氧的电弧焊工艺，所以世界上每一条管焊缝的打底焊道、每一个钛和铝的接头都由它完成。

**焊接位置**是成本的另一半。熔池会往里流的焊缝（平焊，PA/1G）可以用任意电流焊出深、润湿好、便宜的焊道；熔池会往下掉的焊缝（仰焊，PE/4G）必须用小的、冷的、快的参数，以三分之一的速度，由资格更高的焊工来焊，这就是一条设计成平焊的框架比同样一条侧着焊的框架便宜 40 % 的原因。**管焊工的资格考试是 6G 位置——一根 45° 固定的管子，焊工从平焊经过立焊到仰焊而不许转动工件——在某种工艺和材料上通过 6G 资格的焊工，就具备了一切较易位置的资格。**
:::

::: definition 电阻焊、固相焊与束流焊 {#def-solid}
**电阻焊**在你想要的地方产生热量，靠的是电路中故意设置的高电阻处（即待焊界面）的焦耳热：$Q = 0 { . } 2 4 I ^ { 2 } R t$ 焦耳，$I$ 为 4-15 kA，来自水冷铜电极，压力 4-8 kN，持续 100-200 ms。**点焊**两块车身钢板，五分之一秒内做出一个 5-6 mm 的熔化熔核，不用填充金属、不用气体、不需要手艺、没有烟，生产线上每分钟 40-60 个点；熔核直径必须至少 $4 { \sqrt { t } }$ 到 $5 t$ ，否则会被拔出来，其强度是熔核沿自身圆周的抗剪强度，

$$
F \; \approx \; \sigma _ { \text{UTS } } \, \pi d t
$$

对 1.5 mm、380 MPa 的板配 5.5 mm 熔核，约为 10 kN。缺陷全都与电流和压力有关：**喷溅**（电流太大，熔池爆开，留下多孔、飞溅的接头）、**虚焊**（电流太小或压力太大，界面从未熔化，"熔核"只有冷凿宽的一点接触），以及**电极压痕与磨损**——这就是电极头每隔几百个点要修磨一次、焊接电流必须逐周波监控的原因。**缝焊**（滚轮铜轮）做出油箱或饮料罐那种密封搭接；**凸焊和压花焊**用一个 20 kVA 脉冲一次做出支架上的二十个点；**顶锻和闪光对焊**做出钢轨——用 300 m 长的钢轨焊成 100 m 的连续轨道，飞边轧掉，接头在线正火。

**固相工艺**从不熔化任何东西，因此完全不继承铸件的毛病——没有偏析、没有气孔、没有稀释、没有马氏体，还能做热力学上不可能熔焊的异种金属接头。**摩擦焊**让一个零件在 10-30 kN 压力下相对另一个旋转，直到界面达到熔点的 0.8 倍而进入塑性，然后在 40 kN 下顶锻；它用 4 s 把 60 mm 的轴接到 40 mm 的轴上，接头和较弱零件一样强。**搅拌摩擦焊**1991 年发明于焊接国际研究所（The Welding Institute），把一支硬化钢或立方氮化硼做的带轴肩搅拌针扎进接缝，以 200-1000 rpm 旋转，拖着一吨塑化金属绕针流动：结果是一条锻造的、细晶的、强度为母材 0.8 倍的接头，可焊 25 mm 厚的铝或 12 mm 厚的钢，无填充金属、无烟、无弧光，收缩只有熔焊的 5 %——这就是航天飞机外储箱、A350 的机身壁板、船舶铝上层建筑和散热器行业全部采用搅拌摩擦焊的原因。**扩散焊**把两个平整零件在真空中保持于熔点的 0.5 倍、5-20 MPa 压力下保持数小时，界面逐原子消失；它做出夹层结构、蜂窝面板和带中间层的钛-钢接头，其公差要求是整个粘接面上几微米的平面度。**超声焊**让两块搭接板在 20 kHz 和 1 kN 下相互摩擦，直到氧化膜破碎、金属焊合；每一个电池极耳、每一个导线端子、世界上 90 % 的塑料包装（那里其实是局部熔化）都由它做出。**辊焊、爆炸焊和冷焊**是奇异的小尾巴：由两根铸锭轧出的双金属带、把 10 mm 钛爆炸复层到 40 mm 钢反应器壳体上，以及冷压的铝接线端子。

**束流工艺**用电弧的 10 MW/m³ 换来聚焦后的 10⁹-10¹² W/m²。**电子束焊**在真空中发射 30-150 kV 的电子；光束聚焦到 0.1 mm，金属汽化并吹出一个贯穿截面的**小孔**，一道焊出 100 mm 深、1 mm 宽、热影响区 0.1 mm 的焊缝——为此你要付出真空室、0.05 mm 的装配间隙，以及 30 % 变成 X 射线的束流能量。**激光焊**在空气中用 1-20 kW 的光纤或 $\mathrm { C O } _ { 2 }$ 光束、以 1-6 m/min 通过光学系统做同样的事——其真正的工业形态是**激光-电弧复合**焊头，在小孔旁加一条 MIG 电弧，以桥接激光无法容忍的装配间隙。**经济学很简单：束流工艺买到速度和只有电弧五分之一的热影响区，付出的是设备成本、装配公差和接头可达性的光学限制；它在批量大、截面厚、或工件薄且变形关键时胜出。**
:::

## 3. 焊接性：金属被熔化时会做什么

::: definition 钢、不锈钢、铝、钛、铸铁、铜 {#def-weld}
**碳钢和低合金钢**占全部焊接的大多数，它们的故事一句话就能讲完：*冷却速度决定你是否得到马氏体，而马氏体加氢加约束，在 24-48 小时后给出冷裂纹。*控制手段就是碳当量算例中的四个杠杆——预热（减慢冷却并让氢扩散出去）、**低氢**焊条（H4 级碱性焊材，扩散氢低于 $4 \ \mathrm { m l / 1 0 0 \ g }$ ，存放在加热柜里，绝不放在潮湿棚子里）、**$2 5 0 { - } 3 0 0 \ \mathrm { ^ \circ C }$ 保温两小时的后热**，在氢来得及聚集到缺口之前把它烤出去，以及**$6 0 0 { - } 6 5 0 \ \mathrm { ^ \circ C }$ 的焊后热处理**（每 $2 5 \ \mathrm { m m }$ 厚度一小时）来回火马氏体并消除残余应力——后者是四者中唯一既管硬度又管应力的。**热裂纹**是钢的另一个问题：一层低熔点硫化物或磷化物共晶在凝固区间被撕开，对策是控制锰硫比高于 20、用含 3-8 % 锰的焊材把最后几滴熔体烧结在一起、以及让焊缝形状宽大于深，使枝晶在中间相遇而不是形成一条脆弱的中心线平面。

**奥氏体不锈钢**有三个自己的问题。**敏化：**在 550 到 $8 0 0 \ \mathrm { ^ \circ C }$ 之间停留——每一条不锈钢焊缝的热影响区都必然如此，停留数秒——铬的碳化物在晶界析出，使晶界低于让钢不锈钢的 12 % 铬，于是接头在酸中被晶间腐蚀吃掉。对策是碳低于 $0 . 0 3 \ \ \%$ 的"L"级、用钛（321）或铌（347）**稳定化**的牌号把碳锁住，或者 $1 0 5 0 \ \mathrm { ^ \circ C }$ 固溶处理后水淬。**热裂纹：**奥氏体焊缝金属凝固区间短、柱状组织，所以对硫是缺口敏感的，答案是**许尔姆勒（Schaeffler）、DeLong 或 WRC 相图**，它们以铬当量为横轴、镍当量为纵轴，显示全奥氏体焊缝会开裂，而同一条焊缝含 4-12 % **δ 铁素体**就不会——铁素体吸收硫并打散枝晶。这就是为什么 316 母材上故意超合金化地用 308 焊材，为什么焊工铁素体仪读数 5-10 是规格要求而不是个人偏好。**还有热氧化皮色：**不锈钢焊缝上的彩虹氧化膜本身贫铬，必须用硝酸-氢氟酸凝胶酸洗或电解清洗去除，否则"不锈钢"焊缝一个月内就会生锈。

**铝的焊接量仅次于钢**，而它在五个战线上反扑：熔点 $2 0 5 0 \ \mathrm { ^ \circ C }$ 、以冷夹杂形式漂浮在熔池里的**氧化膜** $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$（因此 TIG 用交流的清理作用，焊前要钢丝刷和化学侵蚀）；**氢孔隙**，因为液态铝溶解的氢是固态的二十倍，而熔池一秒钟就凝固（因此焊丝要干燥、清洁、无油，环境不能潮湿）；**热导率是钢的三倍**，需要更大的焊机，厚板还要预热；**熔化前没有颜色变化**，焊工看不见金属马上就要塌落；以及最重要的**热处理的损失**。沉淀硬化的 6xxx 或 2xxx 合金的焊接接头，其热影响区已被焊接过程固溶化，如今处于 **T4** 状态，屈服强度约为母材的一半，而且软化区比可见的变色带宽好几倍；不可热处理的 5xxx 合金什么也恢复不了，同样以那种方式失去加工硬化。**设计者的选择是：用 5xxx 合金并按焊后强度设计；用 6xxx 合金并接受热影响区是 T4；或者焊完之后再做固溶处理和时效——可以做到，很贵，而且会使组件变形。**

**钛在氩气中焊得漂亮，在空气中焊得灾难：**$6 0 0 \ \mathrm { ^ \circ C }$ 以上它贪婪地吸收氧、氮和氢，焊缝表面用颜色讲出全部故事——**稻黄色和银白色可接受，浅蓝色勉强，深蓝和紫色意味着报废，灰色、白色或粉状意味着金属吸收了太多气体，已成脆性的 α 硬化层，会碎裂。**因此要有拖罩和背面保护气、管内充气堵头、局部铜冷却块，关键工件还要用密封腔并把氧含量监控在 1000 ppm 以下。**铸铁**只能作为修理来焊，不能作为制造：镍或镍铁焊材、小电流、$2 0 0 { - } 4 0 0 \ \mathrm { ^ \circ C }$ 预热、短道并锤击、层间温度保持在 $1 5 0 \ \mathrm { ^ \circ C }$ 以下、埋入石灰中缓冷——因为石墨要求的快冷会做出白色切不动的渗碳体焊缝，而约束要求的慢冷会在热影响区做出马氏体，焊工整个活都在这两种失败之间走钢丝。**铜及其合金**因为把热导走，同截面需要钢的三倍电流、$2 0 0 { - } 4 0 0 \ \mathrm { ^ \circ C }$ 预热，并且要用脱氧或无氧材料——而且铜绝不能靠近焊缝接触钢，因为液态铜在 $9 0 0 \ \mathrm { ^ \circ C }$ 会沿晶界渗入奥氏体并使其开裂：**铜害**，这就是焊接车间禁止在钢生产线上使用铜接地夹和镀铜夹具的原因。
:::

## 4. 设计接头

::: definition 焊接设计的十一条规则 {#def-design}
十一条规则，每一条都是一次失效的记忆：

1. **把焊缝放在剪切状态，绝不让它沿喉厚受拉。**角焊缝的喉厚是 $0 . 7 0 7 s$ ，许用剪应力约为 $0 . 6 f _ { u } / { \sqrt { 3 } }$ ；同一条焊缝垂直于喉厚加载就是一个受缺口的铸件，许用值减半。
2. **把焊缝离开最高应力区，离开机械加工。**梁跨中翼缘上的焊缝就是处在疲劳极限上的焊缝；同样一条焊缝移到支座处的中性轴上，不花一分钱。
3. **让力流连续。**一块要传 500 kN 的板，需要它的焊缝、角撑板、连接板和母板在一条线上；力通过一条焊缝拐一个弯，就是通过一个缺口拐一个弯。
4. **处理好焊趾细节。**角焊缝的疲劳强度由焊缝汇入板面的角度决定：60° 的焊趾优于 120° 的，重熔或 TIG 清根的焊趾值 30-40 %，磨平并带圆角的焊趾值一倍。
5. **关于中性轴对称。**焊缝向自己收缩，所以把焊缝对称地布置在截面中性轴两侧和板中面两侧，零件出来就是直的。
6. **为工艺的可达性留余地。**焊枪是一个锥；规定一条你能向焊工演示如何做出的焊缝，把可达角度、伸出长度、保护气和垫板画在图上。
7. **不要在收缩时把接头夹死。**自由收缩的焊缝收缩并屈服；被刚性夹紧的焊缝收缩并开裂。点固、松开、让它动。
8. **避免沿板厚方向加载钢板。**板是层状材料；喉厚被垂直于表面拉出的角焊缝，应改为一块贯穿的板、一个铸节点、一个钻后铰的孔，或保证厚向断面收缩率的 Z 向钢板。
9. **疲劳和密封用连续焊缝，静载才用断续焊缝。**断续角焊缝在疲劳结构里是一串裂纹起点，在容器里是一条泄漏路径；只有当载荷是静载、接头刚度大、焊缝存在的目的只是防止屈曲时，它才是合理的。
10. **让厚度变化平缓。**不同厚度板之间的焊缝需要 1:4 的斜坡或台阶错开，否则截面突变是一个应力集中源，会盖过焊缝自身的。
11. **设计接头时一起设计检测。**焊接工字梁的全焊透对接缝做 100 % 超声检测；角焊缝做目视检测，其尺寸就是图纸上写的，所以图纸必须用毫米的焊脚来写，而不是"周围焊满"。
:::

::: definition 疲劳：为什么钢号无关紧要 {#def-fatigue}
焊接接头的疲劳强度不是材料性能。它是**细节的几何属性**，在每个规范中都以**细节类别**列表——即该细节在 $2 \times 1 0 ^ { 6 }$ 次常幅循环下能承受的名义应力幅，钢在 $\log \Delta \sigma$ 对 $\log N$ 图上的斜率取 $m = 3$ ：

$$
N \; = \; 2 \times 1 0 ^ { 6 } \left( { \frac { F _ { c } } { \Delta \sigma } } \right) ^ { 3 } \qquad \Longleftrightarrow \qquad \Delta \sigma \; = \; F _ { c } \left( { \frac { 2 \times 1 0 ^ { 6 } } { N } } \right) ^ { 1 / 3 }
$$

$$

\text{140} & \text{磨平对接缝，100\% 检测} & 1 4 0 & \text{63} & \text{横向加劲肋，} e > 2 5 \ \mathrm { m m } & 6 3 \\

\end{array}
$$

**关于这张表的三个事实就是焊接疲劳的全部。****第一，$F _ { c }$ 对 S235 和 S690 是一样的**——在焊接疲劳细节上，更高强度的钢什么也买不来，这是设计者最贵的一课，也是最值钱的一课。**第二，原因是残余应力**：焊缝处于拉伸屈服应力，所以一个名义上零到零的载荷循环，实际上是从 $+ \sigma _ { Y }$ 向下再回来的平均应力循环，而全拉伸下的疲劳对施加的平均应力不敏感。**第三，裂纹从一开始就在那里**：每一个焊趾都是一条 0.1-1 mm 的几何裂纹，其根部半径与焊缝自身表面同量级，所以疲劳寿命几乎全部是裂纹*扩展*，而扩展速率取决于 $\Delta K$ ，不取决于钢的屈服强度。

推论都很实用。**你统计的是应力幅，不是最大应力**（因此才有 Miner 线性累积和起重机或船舶的谱载荷）。**类别由细节几何和检测决定，而不是由焊缝尺寸决定**——加劲肋上更大的焊缝让接头更刚、焊趾更尖、类别*更差*，这就是规范把有效喉厚封顶在 $2 5 \ \mathrm { m m }$ 的原因，也是对疲劳裂纹做"加大焊缝"式修理是最糟糕修理的原因。**而所有的改善方法都针对焊趾**：TIG 重熔（重画焊趾并让它进入受压）、**锤击**和**敲除**（向表面射入 1-3 mm 的塑性压应力，换来 40-80 %）、**开槽重焊**（在焊趾处开 K 形坡口，再以 30-45° 引出角重焊，值一倍），以及生产线上的**超声冲击处理**。**它们全部靠同一个机理起作用：疲劳裂纹不会从受压表面长出来，所以你不是在加强接头，而是把裂纹埋进压应力里。**
:::

## 5. 变形与残余应力：焊缝由着性子来

::: definition 为什么每条焊缝都处于屈服应力，以及这对零件意味着什么 {#def-distort}
熔融金属是 1500 °C，而一寸之外的板是冷的。当焊缝池凝固并冷却时，它想要以 $\alpha \Delta T \approx 12 \times 1 0 ^ { - 6 } \times 8 0 0 = 1 . 0 \ \ \%$ 的热应变收缩，而周围一吨的钢不允许它这么做。于是焊缝进入拉伸，它旁边的板进入压缩，而**整个过程被屈服应力封顶，因为应力一旦达到屈服，金属就直接伸长，阻止应力继续上升。**因此，沿焊缝方向的残余应力，作为一阶且相当好的近似，是

$$
\sigma _ { \text{residual } } \; = \; \min \left( E \alpha \, \Delta T , \; \sigma _ { Y } \right) \qquad \text{so that} \qquad \Delta T _ { \text{critical } } = { \frac { \sigma _ { Y } } { E \alpha } } \approx { \frac { 3 5 0 } { 2 . 4 } } \approx 1 5 0 \ \mathrm { ^ \circ C }
$$

**这意味着结构钢中的每一条焊缝都曾被远大于 150 °C 的温差约束过，如今正处在拉伸屈服应力上，无论焊工做了什么。**两侧的板必须受压以维持截面平衡，所以对接焊缝上的残余应力分布是那个经典形状：在焊缝和热影响区上是 $\sigma _ { Y }$ 的拉伸平台，穿过零点到板边缘宽大的压缩区。**这一个事实解释了让每个新工程师困惑的四件事：为什么焊接接头的疲劳强度与钢号无关（平均应力已经在屈服）；为什么焊接框架的尺寸从来不是图纸上写的（板已经移动了）；为什么焊缝在使用中不会"松弛"（它已经在平台上）；以及为什么退火有效（把整个零件加热到 $6 0 0 \ \mathrm { ^ \circ C }$ 让受压区蠕变，应力降到该温度下金属的蠕变松弛水平，几乎为零）。**

焊缝能施加的**收缩力**以其自身屈服应力乘以其自身面积为上限，$F \approx \sigma _ { Y } A _ { w }$ ——6 mm 角焊缝有 $1 8 \ \mathrm { m m ^ { 2 } }$ 的喉部面积，能拉出 $6 \ \mathrm { k N }$ ；20 mm 方坡口对接焊缝的焊道能沿每米焊缝拉出 $1 0 0 \ \mathrm { k N }$ ；40 mm 板中的多道焊缝能拉到足以让腹板屈曲。这个力产生三种特征变形，每种有不同的对策：

$$
\begin{array} { l l l l }
\textbf{变形} & \textbf{原因} & \textbf{大小} & \textbf{控制} \\ \hline
\text{纵向收缩} & \text{焊缝沿自身长度变短} & \text{每米对接缝 } 0 . 5 { - } 2 \ \mathrm { m m } & \text{收缩余量，从中间向外焊} \\
\text{横向收缩} & \text{焊缝横向变短} & \text{每条焊缝 } 1 { - } 3 \ \mathrm { m m } & \text{减少焊道数，减小坡口角度} \\
\text{角变形} & \text{板上表面比下表面收缩得多} & \text{每个单 V 形坡口 } 1 { - } 3 ^ { \circ } & \text{双 V 形，返步焊，预倾角} \\
\text{屈曲 / 翘曲} & \text{压缩超过板的刚度} & \text{灾难性，突然} & \text{对称，刚性固定，焊后校平} \\
\text{焊缝面塌陷} & \text{大电流下根部间隙闭合} & 1 { - } 3 \ \mathrm { m m } & \text{根部间隙余量，垫板，衬垫}
\end{array}
$$

**控制手段的等级是固定的，车间会按这个顺序告诉你：把焊缝设计掉（更薄、更少、断续、对称）；让它关于两个轴都对称；给出预倾角或收缩余量（2° 的预倾角抵消 2° 的角变形，3 mm 的长度余量抵消一米对接焊缝）；用让热量绕着零件走而不是单向推进的焊接顺序（返步焊，或板上的"v"形和"分段"顺序）；夹紧只夹到让它贴基准面的程度，绝不多夹；事后用压机、辊校、线状加热（焊旁摆一条焊枪加热线，它收缩把零件拉回来）或局部喷丸来校平。****唯一永远无效的手段是夹得更紧：被刚性约束的焊缝不会保持平直，它会开裂。**
:::

::: proof 焊缝要热到多少度才会屈服？ {#proof-rescap}
取一根长 $L$ 的杆，在温度 $T _ { \text{ref } }$ 下无约束，把两端固定着冷却 $\Delta T$ ，并设它为理想弹塑性、屈服应力 $\sigma _ { Y }$ 。约束强加的应变就是自由收缩本应产生的应变，

$$
\varepsilon \; = \; \alpha \, \Delta T \qquad \Longrightarrow \qquad \sigma \; = \; E \varepsilon \; = \; E \alpha \, \Delta T \quad \text{provided } \sigma \leq \sigma _ { Y }
$$

所以杆开始屈服时的温差是

$$
\Delta T _ { \text{crit } } \; = \; { \frac { \sigma _ { Y } } { E \alpha } } \; = \; { \frac { 6 4 0 } { 2 0 0 { , } 0 0 0 \times 1 2 \times 1 0 ^ { - 6 } } } \; = \; { \frac { 6 4 0 } { 2 . 4 } } \; = \; { \bf 2 6 7 \ \mathrm { ^ \circ C } }
$$

对 640 MPa 的高强度结构钢如此，对 S355 则是 $3 5 0 / 2 . 4 = 1 4 6 \ \mathrm { ^ \circ C }$ 。**焊缝从 1500 °C 的凝固温度冷却到室温，甚至从未超过 $A _ { c 1 }$ 的金属也要摆动几百度，所以每一道曾经焊过的熔焊接头，这个判据都被超出三到十倍。**三个推论立刻成立。**残余应力是材料属性，不是工艺水平属性**——你无法靠焊接技术逃掉它，只能重新分布它。**它随 $\sigma _ { Y }$ 缩放，而不随焊接量的多少缩放**，所以高强度钢中一条小心的小电流焊缝，与一条马虎的大焊缝有相同的峰值残余应力，只是区域更小。**这也是为什么疲劳类别对所有钢号都一样："零到拉伸"循环的平均应力是 $\sigma _ { Y }$ ，无论你买了什么钢号，而裂纹不在乎你买板花了多少钱。**
:::

::: example 平直度的账单 {#ex-distort level=3 check="146"}
一块 $1 2 \ \mathrm { m m }$ 的板沿 $1 2 0 0 \ \mathrm { m m }$ 面板的一条边用单 V 形坡口对接焊，框架必须从夹具上取下时平直度达到 $2 \ \mathrm { m m }$ 。估算残余应力，并决定拿变形怎么办。

$$
\Delta T _ { \text{crit } } = { \frac { 3 5 0 } { 2 0 0 { , } 0 0 0 \times 1 2 \times 1 0 ^ { - 6 } } } = { \bf 1 4 6 \ \mathrm { ^ \circ C } } \qquad \Longrightarrow \qquad \sigma _ { \text{residual } } = \sigma _ { Y } = 3 5 0 \ \mathrm { M P a }
$$

**焊缝处于屈服，面板会翘曲。**收缩力是 $F \approx \sigma _ { Y } A _ { w } = 3 5 0 \times 6 0 = 2 1 \ \mathrm { k N }$ ，作用在板边上，而面板对这种弯曲的抵抗远不是它的名义刚度，因为焊缝旁的金属本身已经屈服。**实测的 $1 2 \ \mathrm { m m }$ 板单 V 形对接焊缝给出 1-3° 的角变形和每米 1-2 mm 的横向收缩，所以一条 $1 2 0 0 \ \mathrm { m m }$ 的不对称面板边焊缝，靠焊枪旁再怎么小心也保不住 $2 \ \mathrm { m m }$ 。**三个答案，按好车间给出的顺序：**在对边再放一条焊缝**（一对对称的焊缝收缩成纯缩短而无弯曲，代价是多一道焊）；**或者以 3° 预倾角焊接**，让收缩把它拉平；**或者焊完再用凹面上 $\phi 2 0 \ \mathrm { m m }$ 的焊枪加热线配合后面的水淬来校直**，这是一门手艺活，便宜，而且完全无法写进规格。**图纸应当写的不是"焊直焊平"，而是可接受的变形量、基准在哪里、以及是否允许校平。**
:::

## 6. 不熔化任何东西的连接

::: definition 钎焊与软钎焊：由毛细管做出的接头 {#def-braze}
钎焊和软钎焊用**熔点低于零件固相线的填充金属**连接两个表面，所以零件从不熔化、从不铸造、从不淬火、从不失去热处理——接头是它们之间薄薄的一层异种合金，靠润湿和扩散保持，而不是靠熔合。分界线按惯例是 $4 5 0 \ \mathrm { ^ \circ C }$ ：以下是**软钎焊**（锡基钎料，$1 8 0 { - } 2 2 0 \ \mathrm { ^ \circ C }$ ，$3 0 { - } 5 0 \ \mathrm { M P a }$ ，做的是电气连接），以上是**钎焊**（铜、银、铝或镍基钎料，$5 5 0 { - } 1 1 0 0 \ \mathrm { ^ \circ C }$ ，在钢上 $1 5 0 { - } 3 0 0 \ \mathrm { M P a }$ ）。钎料不是把接头"粘"起来：它**润湿**清洁的金属，而润湿是一个表面能的问题——液体的表面能低于固体的表面能时液体就润湿固体，这就是熔融银在清洁铜上形成几度接触角、并爬进它看不见尽头的缝隙的原因。

这种爬行是**毛细作用**，它就是钎焊设计规则的全部。把钎料拉进宽度 $\delta$ 的缝隙的压力是 $\Delta p = 2 \gamma \cos \theta / \delta$ ，而由此产生的、对抗钎料自身黏度的流动遵循 Lucas 型定律，

$$
L \; \sim \; \left( { \frac { \gamma \, \delta \, \cos \theta } { \eta } } \, t \right) ^ { 1 / 2 }
$$

所以**流动距离随缝隙的平方根增长**——间隙加倍，渗透深度变成 1.4 倍，接头强度却低一半，因为钎料长出粗大组织、搭接承受更低的剪应力。因此每种钎料的设计间隙都是 $0 . 0 3 { - } 0 . 0 8 \ \mathrm { m m }$ ，以区间形式给出，并通过**按钎焊温度而不是室温来加工零件尺寸**来实现——冷态装配在黄铜接头上的钢管热了会松，在钢管上的钢管热了会紧。**钎焊是一个公差工艺：接头必须按毛细管来设计，缝隙随钎料流入而闭合，搭接长度为厚度的 3-6 倍，并给空气留一条出路。**

实用钎料家族：**铜磷**（$7 3 0 \ \mathrm { ^ \circ C }$ ，便宜，在铜上自钎剂，对镍和钢是毒药——磷化膜使其脆化）；**银铜锌**，含银 20-45 %（$6 2 0 { - } 7 6 0 \ \mathrm { ^ \circ C }$ ，主力军，流成光亮的圆角，$8 0 0 \ \mathrm { ^ \circ C }$ 以上会**出现锌挥发**，既毁接头又毁焊工肺）；**银镉**用于管道（已禁用）；**镍基**（Ni-Cr-B）用于钢刀具上的硬质合金刀片和酸中的不锈钢；**铝硅**（4047，$5 7 7 \ \mathrm { ^ \circ C }$ ）用于铝，这就是做出**世界上每一个汽车散热器**的工艺——3003 芯材两面复合 4343 钎料合金，在 $6 0 0 \ \mathrm { ^ \circ C }$ 的连续式炉中 30 秒完成，$\mathrm { K A l F _ { 4 } { - } K A l F _ { 3 } }$ 钎剂残留为无害玻璃，所以没有钎剂残渣。**真空炉钎焊**用 $\mathrm { A g { - } C u { - } T i }$ 做出钛对不锈钢、陶瓷对金属和蜂窝冷却叶片根部，因为钛自身对钎料中活性钛的吸气作用正是其结合机制，而这只在 $1 0 ^ { - 4 }$ mbar 以下有效。**而钎剂不是可选项**：它是一种在氧化膜形成时就将其溶解的盐，没有钎剂做出的钎焊接头是一条看起来像接头的冷搭接。

**软钎焊**值得一整段，因为它是地球上批量最大的连接工艺。共晶 $\mathrm { S n } { - } 3 7 \mathrm { P b }$ 在单一的 $1 8 3 \ \mathrm { ^ \circ C }$ 熔化，这就是它成为基准的原因；无铅替代品（$\mathrm { S n { - } 3 . 0 A g { - } 0 . 5 C u }$ ，$2 1 7 { - } 2 2 0 \ \mathrm { ^ \circ C }$ ）是 2006 年 RoHS 指令强加给行业的，让电子行业花了十年重新学习——更高的工艺温度、更差的润湿、更多的**锡须**（纯锡在室温长出的单晶细丝，会短路电路板，这就是航空航天至今禁止纯锡镀层的原因），以及一个在 $1 2 5 \ \mathrm { ^ \circ C }$ 下的**蠕变**如今成为芯片球栅阵列寿命极限的接头。**软钎焊接头是一个熔点只比使用温度高一点的冶金接头，每个可靠性工程师的一生都花在这个差距上。**
:::

$$

$$

**十四毫米的搭接，是杆厚的 1.4 倍——而它演示的设计规则，每本钎焊手册都当作奇闻写出来，而每个设计者都应当当作警告来读：钎焊或胶接搭接的有效搭接长度约为被粘件厚度的 $1 { - } 2$ 倍，超过之后多出的长度几乎不承载。****原因和胶接一样是剪滞问题（见下文）：载荷在搭接的两端传递，一旦整根杆已被加载，接头中部什么也没做。****所以钎焊接头是按被连接件设计的，不是按钎料设计的：把搭接从 14 mm 做到 40 mm 买不到强度，只添了 26 mm 的质量和变形，还给钎剂提供了一个藏身之处。**

::: definition 胶接：你会误用的最强接头 {#def-adh}
胶粘剂传力靠的是**被挤入表面在表面真正抓得住的尺度上**。三种机理共同起作用，其比例是五十年来争论的主题：**机械互锁**进入粗糙表面（这就是打磨、喷砂和可剥离层是生产胶接主力军的原因）、**物理吸附**——几个纳米间隙上的范德华吸引力，单位面积上巨大，但前提是胶粘剂对*全部*金属都*那么*近，这要求它润湿表面——以及**化学结合**，来自硅烷偶联剂或底胶，一头朝向金属氧化物、另一头朝向树脂。**实际后果正是决定成败的那一条：胶粘剂只和表面一样强，而表面被污染、氧化、磨过、用脱模剂加工过、或被戴手套的手摸过，这些没有一样是图纸管得到的。十分之九的胶接接头失效是表面处理失效。**所以整个胶接技术是一门表面技术：**临界表面能**试验（用已知表面张力的墨水滴擦表面；环氧需要 36-40 mN/m，它润湿不了表面能 25 的轧制涂油铝板）、航空铝的铬酸或硫酸-硫酸钠侵蚀、长出 1 μm 多孔氧化层让树脂咬入的阳极氧化（CAC 和 FPL）、聚丙烯保险杠的等离子或火焰处理，以及人人都违反的"一小时内上底胶、八小时内胶接"的 30 分钟窗口。

接头设计源于胶粘剂唯一的弱点：**结构环氧胶膜有 25-35 MPa 的搭接剪切强度，而剥离和劈裂强度只有 3-8 MPa。**所以：**让胶受剪，绝不让它受剥离；让零件足够刚，不让它们把接头掰开；胶层保持在 $0 . 0 5 { - } 0 . 2 5 \ \mathrm { m m }$ （越厚抗剪越弱，因为同样载荷下胶自身的剪应变更大，而且越厚意味着缺陷越多、固化残余应力越大）；提供正面限位（金属对金属的凸台、固化后留存的胶条或铆钉），让胶永远不承受组件的重量和搬运载荷；并把失效设计在被粘件上。**搭接中的载荷分布是**剪滞**的经典结果：以 $G _ { a }$ 为胶的剪切模量，$t$ 和 $E$ 为被粘件的厚度和模量、$s$ 为胶层厚度，

$$
\beta \; = \; { \sqrt { \frac { 2 G _ { a } } { E \, t \, s } } } \qquad \Longrightarrow \qquad { \frac { \tau ( x ) } { \bar { \tau } } } \; = \; { \frac { \beta L } { 2 } } \, { \frac { \cosh ( \beta L x / 2 ) } { \sinh ( \beta L / 2 ) } }
$$

而载荷传递长度是 $1 / \beta$ ，对 $1 . 5 \ \mathrm { m m }$ 铝板上的环氧胶是 **2-7 mm**。**所以 25 mm 的搭接是四个传递长度，加倍到 50 mm 几乎不增加强度，却让两端的剥离翻了一倍。**工艺地图的其余部分很短：**胶膜**（FMS-310 和 Hysol EA9394 一类，在 $1 2 0 { - } 1 8 0 \ \mathrm { ^ \circ C }$ 、0.4 MPa 下高压釜固化，这就是飞机翼面壁板与长桁的胶接需要一台机库大小的高压釜的原因）；**双组分膏状胶**（车身车间 20-60 分钟的开放时间，胶沿发动机罩的包边挤出一条，在涂装线上 $1 7 5 \ \mathrm { ^ \circ C }$ 烤 20 分钟固化，这就是胶必须经受住会把水烧开的烘烤的原因）；**厌氧胶和氰基丙烯酸酯**（螺纹锁固剂和 5 秒定位胶，两者都只在缺氧时固化，两者都脆）；以及**胶铆混合接头**，这才是飞机真正用的——胶承受剪切和疲劳，铆钉阻止裂纹扩展并让壁板可拆，组合的价值超过两者之和的两倍。
:::

::: definition 螺纹紧固件与铆钉：可以拆开的接头 {#def-thread}
螺栓不是销钉，它是一根**把零件挤在一起的弹簧**，螺栓连接的一切性质都由预紧力推出。拧紧它，你做的功 85-90 % 花在头部下的端面摩擦，其余的 40-50 % 花在螺纹螺旋面，只有 10-15 % 花在拉伸杆身——这就是扭矩-预紧力关系如此不可靠的原因，

$$
T \; = \; K \, D \, F _ { i }
$$

$K$ 从 0.10（上蜡、二硫化钼）到 0.40（生锈，或带尼龙锁紧环的螺母）都有可能，而这就是按扭矩规定的接头，其**预紧力散布达 $\pm 3 0 \ \ \%$ ，对应 $\pm 1 5 \ \ \%$ 的扭矩散布**的原因。预紧力本身取保证载荷的 60-75 %，因为低于它，接头在中等拉力下就分离；高于它，螺栓已在屈服，第二次拧紧就会拧断。

$$
\begin{array} { l c c c c }
& \text{性能等级} & \sigma _ { \min } \ [ \mathrm { M P a } ] & \sigma _ { 0 . 2 , \min } \ [ \mathrm { M P a } ] & A _ { s } \ [ \mathrm { m m ^ { 2 } } ] \\ \hline
\text{M8} & 8 . 8 & 8 0 0 & 6 4 0 & 3 6 . 6 \\
\text{M12} & 8 . 8 & 8 0 0 & 6 4 0 & 8 4 . 3 \\
\text{M16} & 8 . 8 / 1 0 . 9 & 8 0 0 / 1 0 0 0 & 6 4 0 / 9 4 0 & 1 5 7 \\
\text{M20} & 1 0 . 9 & 1 0 0 0 & 9 4 0 & 2 4 5 \\
\text{M24} & 1 2 . 9 & 1 2 0 0 & 1 1 0 0 & 3 5 3
\end{array}
$$

两个推论主导设计。**疲劳：**螺栓和被夹紧的零件是两根并联弹簧，螺栓只看到外载变化的一个分数 $\Phi = k _ { b } / ( k _ { b } + k _ { m } )$ ——长螺栓在厚而软的接头中典型为 0.15-0.20，短螺栓在刚性接头中为 0.4-0.6。**一根承担 40 kN 载荷循环 20 % 的螺栓，应力幅 16 MPa，寿命无限；同一根螺栓在刚性法兰中应力幅 45 MPa，寿命有限。这就是为什么软垫片有利于螺栓连接的疲劳、为什么长螺栓比短螺栓好、为什么带薄垫圈的"硬"接头才是失效发生的地方。****滑移：****高强度摩擦型**（预紧、抗滑移临界）连接靠摩擦传力，$\mu n F _ { i }$ ，喷砂表面 $\mu = 0 . 4 { - } 0 . 5$ ，所以螺栓永不在孔中承压，没有松动、没有微动，接头表现如一整块——这就是每栋钢结构建筑和每座桥都用它的原因，为什么它们必须用**转角法**安装（把标记的扳手在拧贴合之后再转 $1 / 3$ 圈，让螺栓达到屈服，这是最便宜可靠的预紧方法）、用标定扳手、或用**扭剪型螺栓**（其花键头在预紧力达到时拧断）。

**铆钉**因四个理由而存活。**它不会松**（实心铆钉以过盈配合填满孔并在其中加工硬化）。**它是破损安全的**——贯穿搭接的裂纹会在下一个铆钉孔处停下，这就是客机行业始终无法放弃铆钉的原因。**安装瞬间不需要两侧可达**（抽芯铆钉和锁螺栓类，后者是预紧的环槽型，实为伪装的承力螺栓）。**而且它对表面状态、油、漆和操作者不敏感。**实心铆钉冷镦成直径 1.5 倍杆径、高 1.5 倍杆径的镦头，这是一个与冷镦相同冶金学的成形工序：合金必须有 600 系或退火 2024 的延展性，而 7050 铆钉是制成、淬火、$- 2 0 \ \mathrm { ^ \circ C }$ 储存、并在一个班次内钉完以免在盒子里时效的。**这笔交易是诚实的：铆接搭接比焊接的重，装配工时贵三倍，但检测、现场修理和损伤容限认证容易得多——对一架服役 25 年、有裂纹检查间隔的机体，这一点每次都赢过重量。**
:::

从 $T ( x ) - T _ { 0 } = ( T _ { p } - T _ { 0 } ) \exp ( - v x / 2 \alpha )$ 出发，推导 $w _ { 1 2 } = ( 2 \alpha / v ) \ln [ ( T _ { 1 } - T _ { 0 } ) / ( T _ { 2 } - T _ { 0 } ) ]$ ，并对 $\alpha = 8 5 \ \mathrm { m m ^ { 2 } / s }$ （铝）、$v = 2 0 \ \mathrm { m m / s }$ 、$T _ { 1 } = 6 5 0$ 、$T _ { 2 } = 4 0 0$ 、$T _ { 0 } = 2 5 \ \mathrm { ^ \circ C }$ 求值。（以 mm 作答，保留一位小数。）
::: solution
把两条等温线方程相除就完全消去了 $T _ { p }$ ：$( T _ { 1 } - T _ { 0 } ) / ( T _ { 2 } - T _ { 0 } ) = \exp [ v ( x _ { 2 } - x _ { 1 } ) / 2 \alpha ]$ ，即得结果。数值上，$w = ( 2 \times 8 5 / 2 0 ) \ln ( 6 2 5 / 3 7 5 ) = 8 . 5 \times 0 . 5 1 1 = { \bf 4 . 3 \ m m }$ 。**铝上四毫米的固溶态热影响区，而速度是钢焊的四倍——扩散率项赢了，这就是铝焊接结构有一条用尺子能量到的软区、而钢结构有一条要用显微硬度扫描测到的软区的原因。**
:::
:::

::: quiz 一个 S690 钢的焊接疲劳细节被发现寿命不足。哪种改动有效？ {#quiz-fatigue}
- [ ] 把钢材换成 S960
- [ ] 把角焊缝从 6 mm 加大到 10 mm
- [x] 对焊趾做 TIG 清根或敲除，让它进入受压
- [ ] 在炉中对组件做去应力退火
::: solution
**只有第二类改动能移动细节类别。钢号无关，因为残余应力已经在屈服；更大的焊缝让焊趾角更糟、接头更刚，甚至可能降低类别；退火能消除残余应力，却把焊趾处 1 mm 的几何缺口留在原地，而那才是真正控制裂纹的东西。****TIG 重熔、敲除、锤击和超声冲击处理都靠同一机理起作用——把裂纹起点埋进 1-3 mm 的压应力——值 40-80 %。**
:::
:::

::: quiz 一个钛支架从夹具上取下时焊缝表面发灰、无光、呈粉状。这意味着什么？ {#quiz-ti}
- [ ] 表面没问题，用钢丝刷刷掉就行
- [ ] 焊缝焊透过头了
- [x] 焊缝吸收了氧和氮，已经脆化——报废
- [ ] 氩气太纯了
::: solution
**钛的颜色就是一张吸气曲线：银白和稻黄可接受，浅蓝勉强，深蓝和紫色报废，灰、白或粉状意味着 α 硬化层吸满了间隙氧和氮，已经脆到会碎。****原因永远在保护上，不在焊接上：没有拖罩、焊根背面没有保护气、车间有穿堂风、或焊枪的气流分布器堵了。对策是保护罩、孔内充气堵头、焊根后面的铜冷却块——关键工件还要监控保护气的氧含量。**
:::

## 本讲的后续内容

- **[[manufacturing/machining|机械加工]]**讲的是机加工法兰对比焊接法兰贵多少，以及在机加工基准上施焊对公差链的影响。
- **[[manufacturing/process-selection|工艺选择]]**把连接工艺与成形工艺放到同一张成本-批量地图上。
- **[[manufacturing/casting|铸造]]**和 **[[manufacturing/additive-manufacturing|增材制造]]**是整体做出零件、从而完全避开接头的两条路，而两者都继承了焊缝自身的缺陷：收缩、气孔和残余应力。
- **[[materials-science/phase-transformations|相变]]**是第 1 节和第 3 节的冶金学——连续冷却转变图是 $t _ { 8 / 5 }$ 成为关键数字的原因，也是预热有效的原因。
- **[[materials-science/failure|失效]]**提供焊缝缺陷的断裂力学、细节类别背后的疲劳裂纹扩展律，以及让焊接接头以静力计算无法预测的方式破坏的氢致和应力腐蚀机理。
- **[[materials-science/corrosion|腐蚀]]**涵盖钢-铝接头构成的电偶对、铆钉头下的缝隙腐蚀，以及第 3 节的敏化不锈钢。
- **[[solid-mechanics/fracture-mechanics|断裂力学]]**把热影响区里一条 6 mm 的表面裂纹变成一个应力水平，把漏前不破要求变成一个检测间隔。
- **[[machine-design/fasteners-joints|紧固件与螺栓连接]]**是第 6 节的螺栓变成带垫片、压板、分离判据和疲劳校核的完整接头计算的地方，而 **[[design-process/design-for-manufacture|面向制造与装配的设计]]**是焊、胶、栓的选择变成零件数、紧固件数和装配时间的地方。

::: history
**1802。** **汉弗莱·戴维（Humphry Davy）**在用电解法分离出钠和钾之后，让 100 A 通过空气中的碳棒并描述了电弧——重点是光，皇家学会的观众花钱看的是它；焊接还要等四十年。**1877-1892。** 电弧变成接头：德梅里唐斯（De Méritens）用碳弧熔化铅和黄铜（1881），**N. G. 斯劳森（N. G. Slawson）**在布鲁克林焊接船体板（1885），而**C. L. 科芬（C. L. Coffin）**1892 年让金属电极熔化进接头的专利，是此后每一根焊条的祖先。**1904-1907。** **药皮焊条**到来：霍尔斯特伦（Holstrom）和戈德鲍姆（Goldbaum）1904 年的瑞典专利，以及**奥斯卡·谢尔贝里（Oscar Kjellberg）**1906-07 年的药皮焊条，后者创办了**ESAB**。纤维素加矿物的药皮分解成保护气体和熔渣，让电弧稳定、把氧挡在外面——而且关键的是——让焊接可以在户外、在船厂、在雨里进行。**焊接从此不再是实验室的奇技淫巧，而成为一种建造工艺。****1917-1918。** 第一批全焊接驳船和第一批焊接锅炉管，以及佩科（Pecot）的《电弧焊》，第一部英文教科书。**1920-1942。** **许尔舍（Hoelscher）**1919 年用气体保护电弧的专利，在国家标准化局成为**钨极惰性气体保护焊**，随后商业上成为林德公司的"Heliarc"工艺（1941-42），让铝、镁、钛和不锈钢可以批量焊接；**埋弧焊**由琼斯（Jones）、肯尼迪（Kennedy）和多内尔（Donnell）于 1935-37 年取得专利，锅炉和压力容器行业立即采纳。**1939-1945。** **自由轮**：2700 艘焊接船体的船在十八个月内造成，一家船厂四十一天一艘——而从 1943 年 2 月起——其中 200 艘开裂，有的在北大西洋断成两截。**这次调查创建了断裂力学工业**：佩里尼（Pellini）和罗伯茨（Roberts）的落锤试验，格里菲斯（Griffith）的表面能论证被复活，韧脆转变温度，裂纹阻止板，铆接对焊接之争由钢的质量而非设计来裁决。**世界上每一本断裂力学教科书都是自由轮的一条脚注。****1940。** **迪尔登（Dearden）和奥尼尔（O'Neill）**的碳当量公式发表于《焊接杂志》，给车间一个在决定要不要点预热枪之前可以查的数字，八十年后它仍挂在车间墙上。**1948。** 光焊丝盘送的**熔化极气体保护焊**在霍巴特兄弟公司开发出来，熔敷率大约翻倍；**联合碳化物公司**1953 年的短路"快速循环"电弧让薄板可以焊而不烧穿。**1950 年代。** **电阻焊**与**汽车**：现代车身是 4000-6000 个点焊，由 5000 kVA 的焊钳以每分钟 40 个焊成，移动点焊和凸焊做出油箱、座椅骨架和车轮。**1953-1956。** **巴顿研究所的奇科夫（Chikov）**为**摩擦焊**申请专利并演示；**1958-1962。** **卡尔-海因茨·施泰格瓦尔德（Karl-Heinz Steigerwald）**为**电子束焊**申请专利，第一台生产机器在比利时运行；激光器 1960 年问世，1970 年代走进焊接车间。**1991 年 10 月。** **焊接国际研究所的韦恩·托马斯（Wayne Thomas）、戴维·威廉姆斯（David Williams）和彼得·阿什利（Peter Ashley）**为**搅拌摩擦焊**提交专利：旋转的带轴肩搅拌针，无电弧、无填充金属、无烟、无凝固，25 mm 铝的接头和板材一样强。十年之内，航天飞机外储箱、A350 的机身壁板、212 型潜艇的艇体和散热器行业都转向了它，而它是二十世纪发明的、在发明后十年内成为批量生产工艺的唯一连接方法。**1994-2006。** **RoHS 指令**迫使电子行业放弃锡铅钎料，随之而来的是十年重新学习——更高的回流温度、更好的板面镀层、无铅接头在 $1 2 5 \ \mathrm { ^ \circ C }$ 下的蠕变、底部填充胶的回归——这是制造史上最大一场不事张扬的材料工程计划。**2000-2020 年代。** 船体板和车身上的**激光-电弧复合焊**、每一辆铝车身上的**胶接**（奥迪 A8 的空间框架在同一个接头里激光焊、胶接和铆接）、异种汽车结构的**摩擦塞焊与搅拌摩擦焊**、让"接头"成为冶金结合问题而非几何问题的**增材制造**，以及**焊缝质量传感器**——电弧电流、声学和热成像监控，终于让焊接成为可检测的工艺而非手艺活。
:::

::: summary
**焊缝是铸件，它的邻居是热处理合金。**净热输入 $E = \eta V I / v$ 决定冷却速度，冷却速度决定组织，组织决定接头是韧、是硬、还是裂。热影响区的宽度按 $2 \alpha / v$ 缩放，这就是激光焊的热影响区看不见、气割焊的热影响区看得见的原因。
**焊接性是一个数字，这个数字就是碳当量。**$\mathrm { C E } = \mathrm { C } + \mathrm { M n } / 6 + ( \mathrm { C r } + \mathrm { M o } + \mathrm { V } ) / 5 + ( \mathrm { N i } + \mathrm { C u } ) / 1 5$ ；低于 0.35 随意焊，高于 0.6 要预热、烘干焊条、做后热。敌人是马氏体加扩散氢加约束，裂纹两天后到。
**不锈钢要铁素体，铝会退火，钛要氩气，铸铁要耐心，铜要电流。**4-12 % δ 铁素体防热裂；6xxx-T6 的热影响区是 T4；钛焊缝的颜色就是它的含气量；镍电极加 $3 0 0 \ \mathrm { ^ \circ C }$ 预热；三倍的电流，加上接头附近不许有铜。
**每条焊缝都处于拉伸屈服应力。**$\sigma _ { \text{res } } = \min ( E \alpha \Delta T , \sigma _ { Y } )$ ，而 $\Delta T _ { \text{crit } }$ 是 150-270 °C，所以它永远在天花板上。这就是焊接疲劳强度是*细节*的属性而非钢的属性的原因，为什么类别是 160、125、80、63、45 MPa 无论你买了什么，为什么唯一的对策在焊趾：清根它、喷丸它、或把裂纹埋进压应力。
**变形也不是工艺水平问题。**焊缝按自身长度约 1 % 收缩，收缩力是 $\sigma _ { Y } A _ { w }$ ，零件就会动。靠设计控制它（对称、减少焊道、减小坡口角），靠预倾角和焊接顺序，事后靠线状加热——绝不是靠夹得更紧。
**钎焊是毛细管，胶接是表面。**钎焊间隙是 $0 . 0 3 { - } 0 . 0 8 \ \mathrm { m m }$ ，有效搭接是 1-2 个厚度；胶粘剂需要高于 36 mN/m 的表面能、$0 . 1 5 \ \mathrm { m m }$ 的胶层、受剪而绝不受剥离，以及几毫米的载荷传递长度——它让长搭接毫无用处。
**螺栓是弹簧，扭矩不是预紧力。**$T = K D F$ ，$K$ 从 0.10 到 0.40，所以按扭矩规定的接头夹紧力散布 $\pm 3 0 \ \ \%$ ；螺栓只看到外载的 $\Phi = k _ { b } / ( k _ { b } + k _ { m } )$ ，这就是柔性、长螺栓接头疲劳寿命无限、而刚性短螺栓接头做不到的原因。
:::
