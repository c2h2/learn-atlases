机床是一种以受控方式制造误差的装置。它把零件夹持在几微米以内，把切削刃沿程序路径移动控制在几微米以内，并去除材料使最终尺寸落在通常 25–100 μm 宽的公差带内。图纸上的每个数字都是关于一次尚未进行的测量的陈述，而你做的每次测量都带着一个通常为你要验证的公差 5–20 % 的不确定度。**现代制造的整个大厦——可互换零件、免装配的装配、不做 100 % 检验的质量控制、不做破坏性试验的认证——建立在这样一个命题之上：你能把尺寸测得比造得更准，而且测量可溯源到在哥德堡和在广州一样的米的定义。**当这个命题失效时，零件就装不上，轴承就发热，涡轮叶片就擦碰，飞机就停飞。

计量学是研究这个命题的科学。统计过程控制是不测每个零件而把机器保持在公差带内的科学。数控与自动化是执行制造的机器的工程学。质量体系是证明你是有意做到的文书工作。本讲涵盖全部四者，因为它们是同一门学问：**在一个每个工艺都有分布、每次测量都有不确定度、每个客户都要一个数字的世界里，对几何误差的控制。**

::: warning 计量与质量出错的九种方式
**把精密度与准确度混为一谈。**一台 CMM 以 0.1 μm 的一致性重复读出同一个错误数字 50 次，它是精密而错误的。一把校准可溯源到国家基准、但读数散布 ±0.05 mm 的卡尺，平均而言是准确的，但不精密。**准确度是溯源性；精密度是重复性；两者都需要，而且证明方式不同——前者用校准基准，后者用量具 R&R 研究。****测量而不做不确定度预算。**没有不确定度的测量是一个数字，不是一个结果。如果你报告"25.003 mm"而不说"95 % 置信度下 ±0.004 mm"，你就没有告诉客户零件是否在公差内的任何信息，因为你没有告诉他们*你*是否知道零件是否在公差内。**经验法则是测量不确定度不应超过公差的约 10 %；远大于此时，靠近极限的每个零件都落在测量无法判定的区域里，你需要的是更好的仪器，不是更好的操作员。****忽视量具 R&R。**如果测量系统自身的散布用掉公差带的 30 %，靠近任一极限的零件就会经常被误判：好件被拒、坏件被收。按 AIAG 指南，量具 R&R 研究（重复性 + 再现性）低于 10 % 为可接受；10–30 % 视应用可能可接受；高于 30 % 不可接受。**量具变差叠加在观测散布上，所以坏量具会让有能力的工艺看起来*更差*——更危险的是，它使靠近极限的单件接受/拒收判定不可靠。****按图纸而不是按工艺定公差。**车削直径上 $\pm 0 . 0 1 \ \mathrm { m m }$ 的公差，是在声明工艺能达到 $C _ { p k } \geq 1 . 3 3$ ，对数控车床这意味着 $6 \sigma$ 散布 $< 0 . 0 1 5 \ \mathrm { m m }$ ——可以做到，但只有靠刚性装夹、锋利刀具和被切削力推着不动的零件。**规定工艺守得住的公差，否则就接受报废、返工和关于压线零件的争论。****把通止规当测量用。**通止规是属性量具：它告诉你"在"或"不在"，不告诉你"差多少"。如果尺寸正在向极限漂移，量具不知道，你最先知道的是 200 个零件报废了。**对任何会漂移的尺寸（刀具磨损、热生长、夹具磨损），用计量型量具和控制图。****不计算热膨胀。**钢的膨胀系数为 $1 1 . 7 \times 1 0 ^ { - 6 } \ \mathrm { K ^ { - 1 } }$ 。一个 100 mm 钢零件在 $2 5 \ \mathrm { ^ \circ C }$ 时比在 $2 0 \ \mathrm { ^ \circ C }$ 参考温度下长 5.8 μm；如果它被拿去对着温度不同（或材料不同）的量具趁热测量，这个差值就直接进入结果。**对几十微米或更严的公差，温度可能是比仪器更大的误差源，所以零件必须在测量室里放置到与室温一致——刚下机床的重型零件可能要几个小时——否则就必须对测量做热膨胀修正。****按供应商的数据接受、按自己的数据拒收。**供应商的 CMM 说 25.002，你的 CMM 说 25.008，图纸说 $2 5 . 0 0 0 \pm 0 . 0 1 0$ ，而两个测量在各自的不确定度内都是对的。**解决办法不是争论谁对，而是把两台 CMM 对着一块校准量块比较，找出那 6 μm 的系统偏差——它通常是测头校准误差、热补偿误差或拟合算法的差异（最小二乘 vs 最小区域）。****在 PPAP 里跳过测量系统分析。**客户的 PPAP 要求包括对控制计划中所列量具做测量系统分析。如果你没有，PPAP 被拒，零件不获批，项目延期。**MSA 不是文书工作；它是你的接受/拒收判定基于数据而不是基于运气的证明。****自动化一个烂工艺。**一台带在线量具和刀具寿命补偿环的数控机床，如果装夹偏了 0.02 mm，会造出 10 000 个一致地错的零件。**自动化放大你喂给它的任何东西。先修好工艺，再自动化它。**
:::

## 1. 测量、溯源与不确定度

::: definition 计量学、溯源性与校准等级链 {#def-traceability}
**计量学**是测量的科学，**溯源性**是测量结果的一个属性：结果能通过一条不间断的、有文件记录的校准链追溯到基准（通常是 SI 单位制），每一环贡献一个已声明的不确定度。车间千分尺的链条如下：

$$
\begin{array} { r l }
\text{SI 米（由 } c \text{ 和 } \Delta \nu _ { \mathrm { Cs } } \text{ 定义）} & \\
\quad \downarrow & \text{国家计量院（NPL、PTB、NIST）：稳频激光，相对不确定度} \sim 1 0 ^ { - 1 1 } \\
\quad \downarrow & \\
\text{K 级量块（干涉法校准）} & \sim { \pm } 0 . 0 3 \ \mu \mathrm { m } \text{（在 } 2 5 \ \mathrm { m m } \text{ 处）} \\
\quad \downarrow & \\
\text{0 级或 1 级工作量块（比较法校准）} & \sim { \pm } 0 . 1 \ \mu \mathrm { m } \\
\quad \downarrow & \\
\text{车间千分尺（对工作量块校准）} & { \pm } 1 { - } 2 \ \mu \mathrm { m } \\
\quad \downarrow & \\
\text{用该千分尺测量的零件} & { \pm } 2 { - } 5 \ \mu \mathrm { m } \\
\end{array}
$$

链条上的每一环都是由认可实验室（按 ISO/IEC 17025）执行的校准，证书上写明测得值、扩展不确定度和包含因子。**没有不确定度声明的校准证书不是校准；它是一次合格/不合格试验。**校准间隔由仪器的漂移历史决定，而不是由日历决定：每年漂移 0.5 μm 的 CMM 可以两年校准一次；每月漂移 2 % 的扭矩扳手必须每月校准或更换。

几何计量的**参考条件**是 $2 0 . 0 0 0 \ \mathrm { ^ \circ C }$ （ISO 1 标准参考温度，1931 年国际上采用，是接近一般车间条件的整数）。**地球上每张工程图纸上的每个尺寸都是在 $2 0 \ \mathrm { ^ \circ C }$ 定义的，而每个不在 $2 0 \ \mathrm { ^ \circ C }$ 进行的测量都必须做热膨胀修正——或者证明修正量小于测量不确定度。**
:::

::: definition 测量不确定度：GUM 框架 {#def-uncertainty}
《测量不确定度表示指南》（GUM，JCGM 100:2008）定义了量化与测量结果相关联的疑虑的程序。**合成标准不确定度**是各不确定度分量的平方和根：

$$
u _ { c } \; = \; { \sqrt { \sum _ { i = 1 } ^ { N } c _ { i } ^ { 2 } \, u _ { i } ^ { 2 } } } \qquad c _ { i } \; = \; { \frac { \partial f } { \partial x _ { i } } }
$$

其中 $u _ { i }$ 是输入量 $x _ { i }$ 的标准不确定度，$c _ { i }$ 是**灵敏系数**（测量函数 $f$ 对 $x _ { i }$ 的偏导数）。对直接长度比较，$c _ { i } = 1$ ，公式退化为简单的 RSS。

分量分为两类：

- **A 类**（统计的）：由重复观测评定。$u _ { A } = s / { \sqrt { n } }$ ，其中 $s$ 是样本标准差，$n$ 是观测次数。
- **B 类**（其余一切）：由证书、制造商规格、经验或假定的分布评定。对半宽为 $a$ 的矩形（均匀）分布：$u _ { B } = a / { \sqrt { 3 } }$ 。对三角分布：$u _ { B } = a / { \sqrt { 6 } }$ 。对声明 $k = 2$ 包含因子的正态分布：$u _ { B } = U / 2$ 。

**扩展不确定度**是 $U = k \, u _ { c }$ ，其中 $k = 2$ 给出约 95 % 置信度（对自由度足够的正态分布）。测量结果报告为：

$$
L \; = \; { \bar { L } } \, \pm \, U \quad [ \text{在 } k = 2 \text{，} 9 5 \ \% \text{ 置信度下} ]
$$

**符合性评定的判定规则（ISO 14253-1）：**若 ${ \bar { L } } + U \leq \mathrm { U S L }$ 且 ${ \bar { L } } - U \geq \mathrm { L S L }$ 则零件**接受**；若 ${ \bar { L } } - U > \mathrm { U S L }$ 或 ${ \bar { L } } + U < \mathrm { L S L }$ 则**拒收**；否则为**不确定区**。不确定区的宽度就是测量不确定度，这就是在一个实验室"符合图纸"的零件在另一个实验室可能"不符合图纸"的原因。**经验法则是扩展不确定度不应超过公差宽度的 10 %（10:1 规则），这意味着 $\pm 0 . 0 1 \ \mathrm { m m }$ 的公差要求 $\leq 0 . 0 0 2 \ \mathrm { m m }$ 的测量不确定度——用校准过的千分尺可以做到，用游标卡尺不行。**
:::

::: definition 接触式与非接触式测量：CMM、扫描仪与干涉仪 {#def-instruments}
仪器的选择是准确度、速度和几何之间的折中：

$$
\begin{array} { l l l l l }
\textbf{仪器} & \textbf{准确度} & \textbf{速度} & \textbf{测量对象} & \textbf{局限} \\ \hline
\text{千分尺} & { \pm } 1 { - } 2 \ \mu\text{m} & \text{10 s/件} & \text{1D：直径、厚度} & \text{依赖操作者，1 点} \\
\text{游标卡尺} & { \pm } 2 0 \ \mu\text{m} & \text{5 s/件} & \text{1D：粗略尺寸} & \text{阿贝误差、余弦误差} \\
\text{内径量缸表} & { \pm } 2 { - } 5 \ \mu\text{m} & \text{30 s/孔} & \text{1D：孔径、圆度} & \text{依赖对中} \\
\text{平板 + 指示表} & { \pm } 2 { - } 1 0 \ \mu\text{m} & \text{数分钟/件} & \text{2D：平面度、平行度} & \text{手工，操作者技能} \\
\text{CMM（触发式）} & { \pm } ( 1 . 5 { + } L / 3 0 0 ) \ \mu\text{m} & \text{5--60 min/件} & \text{3D：点、形状、GD\&T} & \text{慢，测头限制几何} \\
\text{CMM（扫描式）} & { \pm } ( 2 { + } L / 2 5 0 ) \ \mu\text{m} & \text{2--20 min/件} & \text{3D：连续曲面} & \text{测杆挠曲，速度受限} \\
\text{激光/激光雷达扫描仪} & { \pm } 1 5 { - } 5 0 \ \mu\text{m} & \text{1--5 min/件} & \text{3D：点云、自由曲面} & \text{依赖表面，无内孔} \\
\text{结构光} & { \pm } 5 { - } 2 0 \ \mu\text{m} & \text{1--5 min/件} & \text{3D：点云} & \text{反光表面，小零件} \\
\text{X 射线 CT} & { \pm } 1 0 { - } 5 0 \ \mu\text{m} & \text{10--120 min/件} & \text{3D：内部 + 外部} & \text{成本、尺寸限制、密度对比} \\
\text{激光干涉仪} & { \pm } 0 . 5 \ \mu\text{m/m（空气中）} & \text{连续} & \text{1D：位移、直线度} & \text{对准、空气折射率} \\
\text{光学比较仪} & { \pm } 5 \ \mu\text{m} & \text{1 min/件} & \text{2D：轮廓、小零件} & \text{仅 2D，手工} \\
\end{array}
$$

**CMM**（三坐标测量机）是几何计量的主力。带触发式测头的桥式 CMM 通过偏转测杆直到内置开关跳开来测量一个点；机器从三个光栅尺（分辨率通常为 $0 . 1 \ \mu \mathrm { m }$ 或更细）读出测尖的 $( x , y , z )$ 。准确度按 $E _ { 0 , M } = A + L / K$ （ISO 10360）规定，其中 $A$ 是探测误差（1–2 μm），$L$ 是测量长度，$K$ 是因子（300–500）。对 $1 . 5 + L / 3 0 0$ 的机器测 500 mm：$E = 1 . 5 + 5 0 0 / 3 0 0 = 3 . 2 \ \mu \mathrm { m }$ 。**$L / K$ 项汇集了机器各轴的光栅尺、直线度和垂直度误差，这就是最大允许误差随被测长度增大的原因。**

**阿贝原则**指出测量轴线应与被测量的尺寸轴线共线。如果两者偏置距离 $e$ （**阿贝偏置**），导轨的角度误差 $\theta$ 产生位移误差：

$$
\varepsilon _ { \text{Abbe } } \; = \; e \, \sin \theta \; \approx \; e \, \theta
$$

$e = 1 0 0 \ \mathrm { m m }$ 、$\theta = 5$ 角秒 $= 2 4 . 2 \ \mu \mathrm { r a d }$ 时：$\varepsilon = 2 . 4 \ \mu \mathrm { m }$ 。**卡尺在设计上就违反阿贝原则（尺身在读数面一侧，偏置 10–20 mm），这是无论你读得多仔细都不能指望卡尺优于百分之几毫米的原因之一。三轴 CMM 无法同时在三个轴上满足阿贝原则，所以要测绘其导轨角度误差并用软件补偿。**
:::

## 2. 公差、配合与几何尺寸标注

::: definition ISO 公差体系：IT 等级与基本偏差 {#def-iso-tol}
ISO 286 体系把一个公差定义为**公差单位** $i$ （名义尺寸 $D$ 的函数）与一个定义 **IT 等级**的倍数的乘积：

$$
i \; = \; 0 . 4 5 \, { \sqrt [ 3 ] { D } } \; + \; 0 . 0 0 1 \, D \quad [ \mu \mathrm { m } , \ D \text{ 以 mm 计} ]
$$

IT 等级从 IT01（最精，用于量块）到 IT18（最粗，用于铸件和焊接件）。标准等级及其倍数为：

$$
\begin{array} { c c c c c c c c c }
\text{等级} & \text{IT5} & \text{IT6} & \text{IT7} & \text{IT8} & \text{IT9} & \text{IT10} & \text{IT11} & \text{IT12} \\
\text{倍数} & 7 i & 10 i & 16 i & 25 i & 40 i & 64 i & 100 i & 160 i \\
\text{典型用途} & \text{轴承} & \text{精密} & \text{定位} & \text{一般} & \text{一般} & \text{钣金} & \text{焊接} & \text{铸造} \\
& \text{座孔} & \text{配合} & & \text{配合} & \text{粗活} & & \text{结构件} & \\
\end{array}
$$

表中的 $D$ 取每个尺寸段的几何平均。50 mm 特征（大于 30 至 50 mm 段）：$D = { \sqrt { 3 0 \times 5 0 } } = 3 8 . 7 \ \mathrm { m m }$ ，$i = 0 . 4 5 \times 3 . 3 8 + 0 . 0 3 9 = 1 . 5 6 \ \mu \mathrm { m }$ ，IT7 $= 1 6 \times 1 . 5 6 = 2 5 . 0 \ \mu \mathrm { m }$ ——即表列值 25 μm。**小尺寸下立方根项主导（它代表守住一个小特征的难度），大尺寸下线性项主导（它代表累积的直线度和热误差）。**

**基本偏差**（字母代号：轴用 a–z，孔用 A–Z）确定公差带相对名义尺寸的位置。最常见的配合是：

- **间隙配合**：H11/c11（松转动）、H8/f7（精密转动）、H7/g6（滑动：50 mm 处间隙 9–50 μm）、H7/h6（定位间隙）。
- **过渡配合**：H7/k6（定位过渡：50 mm 处从 23 μm 间隙到 18 μm 过盈）、H7/n6（较紧的定位过渡）。
- **过盈配合**：H7/p6（定位过盈：50 mm 处过盈 1–42 μm）、H7/s6（中等压入，压装或加热轮毂装配）。

**基孔制（H）是默认：孔公差固定，改变轴公差以达到所需配合。这是因为孔比轴难变（铰刀只做一种尺寸；车刀能做任意尺寸）。**
:::

::: definition 几何尺寸与公差（GD&T）：基准参考系 {#def-gdt}
孔位上 $\pm 0 . 1 \ \mathrm { m m }$ 的尺寸公差是一个（XY 内的）方形公差带——孔心可以在 $0 . 2 \times 0 . 2 \ \mathrm { m m }$ 的方块内任何地方。位置公差是一个圆形公差带——孔心必须在给定直径的圆内。**方块的角点距理论位置 $0 . 1 { \sqrt { 2 } } = 0 . 1 4 1 \ \mathrm { m m }$ ，所以 $\phi 0 . 2 8 3$ 的位置公差带包含整个方块，面积多 57 %。沿对角线偏 0.14 mm 的孔被方块接受，而沿坐标轴偏 0.11 mm 的孔却被拒收——尽管对销的装配而言，只有到理论位置的距离才重要。圆形公差带与功能一致；方形不一致。**

GD&T（ASME Y14.5 或 ISO 1101）把几何公差分为五类（ASME Y14.5-2009 中为 14 项；2018 版删去同轴度和对称度，剩 12 项）：

$$
\begin{array} { l l l }
\textbf{类别} & \textbf{公差项目} & \textbf{需要基准？} \\ \hline
\text{形状} & \text{平面度、直线度、圆度、圆柱度} & \text{否（自参考）} \\
\text{方向} & \text{垂直度、倾斜度、平行度} & \text{是（一个基准）} \\
\text{位置} & \text{位置度、同轴度、对称度} & \text{通常（一至三个基准）} \\
\text{轮廓} & \text{线轮廓度、面轮廓度} & \text{可选} \\
\text{跳动} & \text{圆跳动、全跳动} & \text{是（一个基准轴）} \\
\end{array}
$$

**基准参考系**是由 3-2-1 规则建立的三个相互垂直的平面（A、B、C）：三个接触点定义第一基准（一个平面），两个定义第二基准（一条线），一个定义第三基准（一个点）。**基准不是零件的一个特征；它是零件特征与之关联的一个理论构造。基准特征模拟体（CMM 的卡盘、虎钳或夹具）必须复现基准约束，否则测量毫无意义。**

**材料边界修饰符**——最大实体要求（MMC，$\boxed{M}$ ）、最小实体要求（LMC，$\boxed{L}$ ）和独立原则（RFS，无符号）——允许在特征不处于最大实体状态时放宽几何公差。$\phi 1 0 \pm 0 . 2$ 孔上 $\phi 0 . 1 \boxed { M }$ 的位置公差适用于最大实体尺寸 $\phi 9 . 8$ ；孔做成 $\phi 1 0 . 2$ 时偏离最大实体 0.4 mm，于是获得 0.4 mm 补偿公差，位置可偏至 $\phi 0 . 5$ ，因为能装进最大实体孔的销仍能装配。**MMC 是 GD&T 中最有用的工具之一：它把公差与装配功能联系起来，并能在不影响可装配性的情况下成倍放大间隙孔的可用位置公差。**
:::

::: definition 量规：属性与计数值，以及量具 R&R {#def-gauging}
**量规**是做出符合性判定（接受/拒收）而不是报告测量的装置。两种类型是：

- **属性量规**：通止塞规、螺纹量规、卡规、功能量规。它们快（每件 2–5 s）、便宜、不怕操作者，但不提供工艺趋势信息。**通规按特征的最大实体极限制造（最小的孔、最大的轴），止规按最小实体极限制造。通规还在零件公差之内留有一个小的磨损裕量（零件公差的百分之几），使量规能磨损一段时间后才开始接受超出极限的零件。**
- **计量型量具**：千分尺、量缸表、CMM、指示表。它们报告一个数字，可以画在控制图上、做趋势、用于工艺调整。**计量型量具比属性量规贵、用起来慢，但它给你预防缺陷而不是分拣缺陷的信息。**

**量具重复性与再现性（GR&R）**量化测量系统对观测变差的贡献。典型研究（AIAG MSA 手册第 4 版）是 3 名评价人 × 10 个零件 × 2–3 次试验（60–90 次测量），用 ANOVA 或均值-极差法分析。结果是：

$$
\sigma _ { \text{gauge } } ^ { 2 } \; = \; \sigma _ { \text{repeatability} } ^ { 2 } \; + \; \sigma _ { \text{reproducibility} } ^ { 2 } \; = \; \sigma _ { \text{EV} } ^ { 2 } \; + \; \sigma _ { \text{AV} } ^ { 2 }
$$

其中 EV（设备变差）是操作者内变差，AV（评价人变差）是操作者间变差。接收准则是：

- $\sigma _ { \text{gauge } } / \sigma _ { \text{total } } < 0 . 1 0$ （10 %）：可接受。
- $0 . 1 0 < \sigma _ { \text{gauge } } / \sigma _ { \text{total } } < 0 . 3 0$ ：有条件接受，建议改进。
- $\sigma _ { \text{gauge } } / \sigma _ { \text{total } } > 0 . 3 0$ ：不可接受，必须改进或更换量具。

**由于方差相加，$\sigma _ { \text{obs} } ^ { 2 } = \sigma _ { \text{process} } ^ { 2 } + \sigma _ { \text{gauge} } ^ { 2 }$ ：GR&R 为观测变差的 30 % 时，工艺标准差是观测值的 $\sqrt { 1 - 0 . 3 ^ { 2 } } = 0 . 9 5$ ，所以你算出的能力约偏保守 5 %——真实 $C _ { p k }$ 1.40 显示为 1.33。更大的代价在极限附近：距极限一个量具散布以内的单件，其判定几乎是随机的。**
:::

::: example 公差累积：轴承座 {#ex-stackup level=3 check="0.56"}
一个轴承（宽度 15.000 ± 0.010 mm）靠在壳体孔的台肩上，由槽内的卡环轴向固定；轴承把卡环推向槽的远侧面。轴向游隙 =（台肩到槽近侧面）+（槽宽）−（轴承宽度）−（卡环厚度）。尺寸链上的尺寸为：

| 特征 | 名义值 | 公差 |
|---------|---------|-----------|
| 壳体台肩到槽近侧面 | 15.00 | ±0.05 |
| 轴承宽度 | 15.00 | ±0.01 |
| 卡环厚度 | 1.20 | ±0.05 |
| 槽宽 | 1.60 | ±0.05 |

最坏情况下的最大轴向游隙是多少（以 mm 计）？

名义游隙为 $1 5 . 0 0 + 1 . 6 0 - 1 5 . 0 0 - 1 . 2 0 = 0 . 4 0 \ \mathrm { m m }$ 。最坏情况最大值取正项最大、负项最小：

$$
\delta _ { \max } \; = \; ( 1 5 . 0 5 + 1 . 6 5 ) - ( 1 4 . 9 9 + 1 . 1 5 ) \; = \; 1 6 . 7 0 - 1 6 . 1 4 \; = \; { \bf 0 . 5 6 \ \mathrm { m m } }
$$

$$
\delta _ { \min } \; = \; ( 1 4 . 9 5 + 1 . 5 5 ) - ( 1 5 . 0 1 + 1 . 2 5 ) \; = \; 1 6 . 5 0 - 1 6 . 2 6 \; = \; 0 . 2 4 \ \mathrm { m m }
$$

最坏情况累积为 $0 . 4 0 \pm 0 . 1 6 \ \mathrm { m m }$ 。若每个公差都是独立、对中工艺的 $\pm 3 \sigma$ 带，**平方和根**（统计）累积是：

$$
\delta _ { \text{RSS } } \; = \; { \sqrt { 0 . 0 5 ^ { 2 } + 0 . 0 1 ^ { 2 } + 0 . 0 5 ^ { 2 } + 0 . 0 5 ^ { 2 } } } \; = \; { \sqrt { 0 . 0 0 7 6 } } \; = \; \pm 0 . 0 8 7 \ \mathrm { m m } \quad ( 3 \sigma )
$$

所以几乎所有装配落在 $0 . 3 1 { - } 0 . 4 9 \ \mathrm { m m }$ ，而最坏情况为 $0 . 2 4 { - } 0 . 5 6 \ \mathrm { m m }$ 。**如果设计要求更小的端隙，办法是收紧三个 ±0.05 mm 的贡献项、装配时选配卡环厚度，或加一个吸收游隙的波形弹簧。**
:::

## 3. 统计过程控制

::: definition 过程能力：Cp、Cpk、Pp、Ppk {#def-capability}
**过程能力**把工艺散布与规范宽度比较。两个指数是：

$$
C _ { p } \; = \; { \frac { \mathrm { U S L } - \mathrm { L S L } } { 6 \, \sigma _ { \text{within } } } } \qquad C _ { p k } \; = \; \min \! \left( { \frac { \mathrm { U S L } - \mu } { 3 \, \sigma _ { \text{within } } } } , \; { \frac { \mu - \mathrm { L S L } } { 3 \, \sigma _ { \text{within } } } } \right)
$$

其中 $\sigma _ { \text{within } }$ 是**子组内**标准差（由平均极差估计：$\hat { \sigma } _ { \text{within } } = { \bar { R } } / d _ { 2 }$ ，$d _ { 2 }$ 取决于子组大小）。$C _ { p }$ 度量**潜在**能力（若工艺对中）；$C _ { p k }$ 度量**实际**能力（计入偏心）。工艺完美对中时 $C _ { p } = C _ { p k }$ 。

**性能指数** $P _ { p }$ 和 $P _ { p k }$ 使用**总体**标准差 $s$ （所有测量的样本标准差，包含子组间变差）：

$$
P _ { p } \; = \; { \frac { \mathrm { U S L } - \mathrm { L S L } } { 6 \, s } } \qquad P _ { p k } \; = \; \min \! \left( { \frac { \mathrm { U S L } - { \bar { x } } } { 3 \, s } } , \; { \frac { { \bar { x } } - \mathrm { L S L } } { 3 \, s } } \right)
$$

**$C _ { p k }$ 与 $P _ { p k }$ 的差别就是子组间变差：刀具漂移、批次间材料差异、温度循环。若 $C _ { p k } = 1 . 7$ 而 $P _ { p k } = 1 . 1$ ，工艺在子组内有能力但随时间没有——问题不是机器，是工艺管理（换刀、预热规程、材料控制）。**

$C _ { p k }$ 数值的解读：

$$
\begin{array} { c c c }
C _ { p k } & \text{缺陷率（ppm）} & \text{解读} \\ \hline
< 1 . 0 & > 2 7 0 0 & \text{无能力；需分拣或 100\% 检验} \\
1 . 0 & 2 7 0 0 & \text{勉强有能力} \\
1 . 3 3 & 6 3 & \text{有能力；批量生产的常见最低值} \\
1 . 6 7 & 0 . 6 & \text{高能力；新工艺的常见要求} \\
2 . 0 & 0 . 0 0 2 & \text{短期"六西格玛"散布} \\
\end{array}
$$

**缺陷率由正态分布计算：$p = \Phi ( ( \mathrm { L S L } - \mu ) / \sigma ) + 1 - \Phi ( ( \mathrm { U S L } - \mu ) / \sigma )$ 。对中工艺，$p = 2 \, \Phi ( - 3 \, C _ { p } )$ 。表中的 ppm 值（对中工艺）假定正态分布一直延伸到远尾部，而真实工艺很少如此：低于约 1 ppm 的数字是模型外推，不是预测。**
:::

::: definition 控制图：X-bar/R、p 图与 CUSUM {#def-control-charts}
**控制图**区分普通原因变差（工艺固有）与特殊原因变差（可归因于特定事件）。X-bar/R 图是计量值数据的主力：

$$
\text{X-bar 图：} \quad { \bar { \bar { x } } } \, \pm \, A _ { 2 } \, { \bar { R } } \qquad \text{R 图：} \quad D _ { 3 } \, { \bar { R } } \; \text{至} \; D _ { 4 } \, { \bar { R } }
$$

其中 ${ \bar { \bar { x } } }$ 是总均值，${ \bar { R } }$ 是平均极差，$A _ { 2 }$ 、$D _ { 3 }$ 、$D _ { 4 }$ 是取决于子组大小 $n$ 的常数：

$$
\begin{array} { c c c c c c c }
n & 2 & 3 & 4 & 5 & 10 \\ \hline
A _ { 2 } & 1 . 8 8 0 & 1 . 0 2 3 & 0 . 7 2 9 & 0 . 5 7 7 & 0 . 3 0 8 \\
D _ { 3 } & 0 & 0 & 0 & 0 & 0 . 2 2 3 \\
D _ { 4 } & 3 . 2 6 7 & 2 . 5 7 5 & 2 . 2 8 2 & 2 . 1 1 4 & 1 . 7 7 7 \\
d _ { 2 } & 1 . 1 2 8 & 1 . 6 9 3 & 2 . 0 5 9 & 2 . 3 2 6 & 3 . 0 7 8 \\
\end{array}
$$

**控制限是样本均值（$\sigma / { \sqrt { n } }$ ）的 $\pm 3 \sigma$ ，给出 0.27 % 的虚警率（370 个子组中 1 次）。西电（Western Electric）判异规则（连续 3 点中 2 点在同侧超 $2 \sigma$ 、连续 5 点中 4 点超 $1 \sigma$ 、连续 8 点在中心线一侧）以更高虚警率为代价提高对小偏移的灵敏度。**

对属性数据（合格/不合格、缺陷计数）：

- **p 图**：大小 $n$ 的样本中的不合格品率。中心线 $\bar { p }$ ，控制限 $\bar { p } \pm 3 { \sqrt { \bar { p } ( 1 - \bar { p } ) / n } }$ 。
- **c 图**：恒定大小单元中的缺陷数。中心线 $\bar { c }$ ，控制限 $\bar { c } \pm 3 { \sqrt { \bar { c } } }$ 。
- **u 图**：可变大小单元的单位缺陷数。

**CUSUM**（累积和）图对小偏移（0.5–1.5σ）比休哈特图更灵敏：

$$
C _ { i } ^ { + } \; = \; \max \! \left( 0 , \; C _ { i - 1 } ^ { + } + ( x _ { i } - \mu _ { 0 } ) - K \right) \qquad C _ { i } ^ { - } \; = \; \max \! \left( 0 , \; C _ { i - 1 } ^ { - } - ( x _ { i } - \mu _ { 0 } ) - K \right)
$$

其中 $K = 0 . 5 \sigma$ 是**参考值**（你想检测的偏移的一半，此处为 $1 \sigma$ ），信号为 $C _ { i } ^ { \pm } > H = 4 { - } 5 \sigma$ 。**对单值读数均值的 $1 \sigma$ 偏移，$K = 0 . 5 \sigma$ 、$H = 5 \sigma$ 的 CUSUM 平均约 10 个样本报警，而 $3 \sigma$ 限的休哈特图约需 44 个。**
:::

::: definition 抽样检验与 OC 曲线 {#def-sampling}
**验收抽样**基于样本决定接受或拒收一批，而不是检验每个单元。OC（操作特性）曲线给出**接受概率** $P _ { a }$ 随批不合格品率 $p$ 的变化：

$$
P _ { a } ( p ) \; = \; \sum _ { d = 0 } ^ { c } { \binom { n } { d } } \, p ^ { d } \, ( 1 - p ) ^ { n - d } \quad \text{（二项）} \qquad \approx \; \sum _ { d = 0 } ^ { c } { \frac { ( n p ) ^ { d } \, e ^ { - n p } } { d ! } } \quad \text{（泊松，} n \text{ 大 } p \text{ 小）}
$$

其中 $n$ 是样本量，$c$ 是接受数（允许的最大不合格品数）。OC 曲线上两个关键点：

- **AQL**（可接受质量水平）：$P _ { a } = 0 . 9 5$ 处的 $p$ （生产方风险 $\alpha = 0 . 0 5$ ——好批被拒的概率）。
- **LTPD**（批允许不合格品率）：$P _ { a } = 0 . 1 0$ 处的 $p$ （使用方风险 $\beta = 0 . 1 0$ ——坏批被接受的概率）。

**比值 $R = \mathrm { L T P D } / \mathrm { A Q L }$ 衡量方案的判别锐度。AQL = 1 %、LTPD = 5 %（$R = 5$ ）时，泊松 OC 曲线要求 $c = 3$ 、$n \approx 1 3 5$ ——为不算高的判别力付出大样本。减小 $n$ 的办法只有接受更高的 $\alpha$ 或 $\beta$ 、接受 AQL 与 LTPD 之间更大的间隔，或依靠有能力且受控的工艺而不是检验。**

**抽样不分拣好坏零件；它对批做判定。**$n = 5 0$ 、$c = 0$ 的抽样在 1 % 不合格率下接受 $0 . 9 9 ^ { 5 0 } = 6 0 . 5 \ \%$ 的批。若被拒的批经 100 % 筛选（纠正检验），平均出货质量约为 $p \, P _ { a } = 0 . 6 \ \%$ 不合格。100 % 检验也不完美——人工目视检验会漏掉相当一部分缺陷——**所以两者真正的替代是用控制图看护的有能力的工艺。**
:::

::: proof 缺陷率作为 Cpk 的函数 {#proof-cpk-ppm}
对均值 $\mu$ 、标准差 $\sigma$ 的正态分布，规范限外零件的比例是：

$$
p \; = \; P ( X < \mathrm { L S L } ) + P ( X > \mathrm { U S L } ) \; = \; \Phi \! \left( { \frac { \mathrm { L S L } - \mu } { \sigma } } \right) + 1 - \Phi \! \left( { \frac { \mathrm { U S L } - \mu } { \sigma } } \right)
$$

定义**对每个极限的能力指数**：$C _ { L } = ( \mu - \mathrm { L S L } ) / ( 3 \sigma )$ 、$C _ { U } = ( \mathrm { U S L } - \mu ) / ( 3 \sigma )$ ，于是 $C _ { p k } = \min ( C _ { L } , C _ { U } )$ 。则：

$$
p \; = \; \Phi ( - 3 C _ { L } ) + 1 - \Phi ( 3 C _ { U } ) \; = \; \Phi ( - 3 C _ { L } ) + \Phi ( - 3 C _ { U } )
$$

**对中**工艺，$C _ { L } = C _ { U } = C _ { p } = C _ { p k }$ ，于是：

$$
\boxed { \; p \; = \; 2 \, \Phi ( - 3 \, C _ { p k } ) \; }
$$

$C _ { p k } = 1$ 时：$p = 2 \, \Phi ( - 3 ) = 2 \times 0 . 0 0 1 3 5 = 0 . 0 0 2 7 = 2 7 0 0 \ \mathrm { p p m }$ 。$C _ { p k } = 1 . 3 3$ 时：$p = 2 \, \Phi ( - 4 ) = 2 \times 3 . 1 7 \times 1 0 ^ { - 5 } = 6 3 \ \mathrm { p p m }$ 。$C _ { p k } = 2$ 时：$p = 2 \, \Phi ( - 6 ) = 2 \times 9 . 9 \times 1 0 ^ { - 1 0 } = 0 . 0 0 2 \ \mathrm { p p m }$ 。

**$p$ 对 $C _ { p k }$ 的陡峭（快于指数）敏感性，是 $C _ { p k }$ 改善 0.3 个单位（从 1.0 到 1.33）使缺陷率降 43 倍的原因，也是汽车行业对关键尺寸坚持 $C _ { p k } \geq 1 . 3 3$ 的原因：$C _ { p k } = 1 . 0$ 时，日产 100 000 件的产线每天发出 270 个坏件，$C _ { p k } = 1 . 3 3$ 时每天发 6 个。** $\blacksquare$
:::

::: example 车削直径的 Cpk {#ex-cpk level=3 check="1.36"}
一台数控车床加工 $\phi 2 5 . 0 0 0 \pm 0 . 0 5 0 \ \mathrm { m m }$ 的直径。125 件的样本（25 个 5 件子组）给出 ${ \bar { \bar { x } } } = 2 5 . 0 1 5 \ \mathrm { m m }$ 、${ \bar { R } } = 0 . 0 2 0 \ \mathrm { m m }$ 。计算 $C _ { p }$ 和 $C _ { p k }$ 。（填写 $C _ { p k }$ 。）

$$
{ \hat { \sigma } } _ { \text{within } } \; = \; { \frac { { \bar { R } } } { d _ { 2 } } } \; = \; { \frac { 0 . 0 2 0 } { 2 . 3 2 6 } } \; = \; 0 . 0 0 8 6 \ \mathrm { m m }
$$

$$
C _ { p } \; = \; { \frac { 2 5 . 0 5 0 - 2 4 . 9 5 0 } { 6 \times 0 . 0 0 8 6 } } \; = \; { \frac { 0 . 1 0 0 } { 0 . 0 5 1 6 } } \; = \; 1 . 9 4
$$

$$
C _ { p k } \; = \; \min \! \left( { \frac { 2 5 . 0 5 0 - 2 5 . 0 1 5 } { 3 \times 0 . 0 0 8 6 } } , \; { \frac { 2 5 . 0 1 5 - 2 4 . 9 5 0 } { 3 \times 0 . 0 0 8 6 } } \right) \; = \; \min \! \left( { \frac { 0 . 0 3 5 } { 0 . 0 2 5 8 } } , \; { \frac { 0 . 0 6 5 } { 0 . 0 2 5 8 } } \right) \; = \; \min ( 1 . 3 6 , \; 2 . 5 2 )
$$

$$
C _ { p k } \; = \; { \bf 1 . 3 6 }
$$

**工艺有能力（$C _ { p k } > 1 . 3 3$ ）但未对中：均值高于名义值 15 μm，而 1.94 的 $C _ { p }$ 表明散布没问题。解决办法是 15 μm 的刀具偏置，它把 $C _ { p k }$ 提到 1.94，并把预期缺陷率从约 24 ppm（几乎全在上极限之外）降到约 0.006 ppm。$C _ { p } - C _ { p k }$ 之间 0.58 的差距就是工艺不对中的代价。**
:::

## 4. 数控机床与 CAM

::: definition 数控：轴、运动学与 G 代码 {#def-cnc}
**数控机床**是一个多轴定位系统，让切削刀具（或工件）沿程序路径移动。轴是：

$$
\begin{array} { l l l l }
\textbf{机床} & \textbf{轴} & \textbf{典型行程} & \textbf{定位精度} \\ \hline
\text{两轴车床} & X, Z & 300 \times 600 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{三轴铣床} & X, Y, Z & 500 \times 400 \times 400 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{五轴铣床} & X, Y, Z, A, C & 630 \times 560 \times 500 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{五轴联动} & X, Y, Z, B, C & 800 \times 700 \times 600 \ \mathrm{mm} & { \pm } 3 \ \mu\text{m} \\
\text{线切割 EDM} & X, Y, U, V & 500 \times 400 \times 300 \ \mathrm{mm} & { \pm } 2 \ \mu\text{m} \\
\text{CMM} & X, Y, Z & 1200 \times 1000 \times 800 \ \mathrm{mm} & { \pm } 1 . 5 \ \mu\text{m} \\
\end{array}
$$

三轴机床的 **21 项几何误差**（每个直线轴 6 项——定位、两个直线度、俯仰、偏摆和滚转——外加各轴对之间的 3 项垂直度误差）是体积精度的根本极限。典型五轴加工中心的体积精度在其全行程上为 10–25 μm，比单轴定位精度差 3–5 倍，因为垂直度误差和角度误差会累积。**激光干涉仪和激光跟踪仪测量（ISO 230 系列）测绘这些误差，数控系统以补偿表的形式施加补偿。补偿良好的机床达到 3–5 μm 体积精度；未补偿的只有 15–30 μm。**

**G 代码**（ISO 6983）是数控机床的编程语言。一个典型车削程序：

```
G97 S800 M03       (constant spindle speed, 800 RPM, CW)
G00 X52.0 Z2.0     (rapid to start position)
G01 Z-30.0 F0.15   (linear cut to Z-30, 0.15 mm/rev)
G01 X24.85 F0.10   (face to diameter 24.85, 0.10 mm/rev)
G00 X55.0 Z5.0     (rapid retract)
M30                 (end of program)
```

**后处理器**把 CAM 系统的刀轨数据（CLSF：刀具位置源文件）转换为机床专用的 G 代码，考虑机床的运动学（耳轴式 vs 摆头式）、轴行程极限、刀库容量和控制器方言（Fanuc、Siemens、Heidenhain、Haas）。**一个把 G01 放进快速移动模式的后处理器缺陷会让刀具以 30 m/min 撞进零件；一个不考虑 A = 90° 附近耳轴奇异性的后处理器会产生啃刀。**
:::

::: definition 机床精度、重复性与阿贝原则 {#def-machine-accuracy}
三个数字表征机床的定位性能（ISO 230-2）：

- **分辨率**：控制系统能指令和测量的最小增量。带光栅尺反馈的现代数控为 0.1 μm 或更细。不带光栅尺的机床（电机或丝杠上装旋转编码器），分辨率由编码器每转计数和丝杠导程决定。
- **重复性**：从同一方向重复指令同一目标位置时实际到达位置的散布。好机床：约 $\pm 1 { - } 2 \ \mu \mathrm { m }$ 。磨损机床：$\pm 5 { - } 1 0 \ \mu \mathrm { m }$ 。
- **定位精度（双向）**：从两个方向趋近时相对指令位置的最大偏差。单向与双向精度之差是**反向间隙**（滚珠丝杠和轴承中的空程），典型为 2–10 μm。

**阿贝原则**同样适用于机床。在加工中心上，光栅尺在导轨上，但切削刃在刀尖，距光栅尺 50–300 mm（**阿贝偏置**）。X 滑座 1 角秒的俯仰误差在刀尖产生 Z 向误差：

$$
\varepsilon \; = \; L _ { \text{tool} } \times \theta \; = \; 2 0 0 \times 4 . 8 5 \times 1 0 ^ { - 6 } \; = \; 1 . 0 \ \mu \mathrm { m } \quad \text{（每角秒、每 200 mm 刀长）}
$$

**5 角秒的俯仰误差配 200 mm 刀具产生 5 μm 误差——典型 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差的 10 %。这就是高精度加工中心把光栅尺放到尽可能靠近切削区、导轨的角度误差做到并调整到几角秒、主轴热生长（4 小时班次内使刀长变化 10–30 μm）用对刀仪补偿的原因。**
:::

::: definition CAM：刀轨、仿真与自适应加工 {#def-cam}
**CAM**（计算机辅助制造）从 CAD 模型生成刀轨坐标。关键决策是：

- **切削策略**：顺铣 vs 逆铣，之字形 vs 阶梯形 vs 轮廓平行，摆线（自适应开粗），螺旋插补。策略决定刀具载荷、表面质量和节拍时间。**在刚性好、无反向间隙的机床上，顺铣通常比逆铣留下更好的表面、刀具寿命更长，因为每个刀齿以最大切厚切入、以零切厚切出，而不是从零切厚开始、先摩擦后切削。**
- **行距与切深**：残留高度 $h _ { s } \approx { \delta ^ { 2 } } / ( 8 R )$ （半径 $R$ 的球头刀、行距 $\delta$ 、平面）决定表面质量。$R = 6 \ \mathrm { m m }$ 、$h _ { s } = 5 \ \mu \mathrm { m }$ 时：$\delta = { \sqrt { 8 \times 6 \times 0 . 0 0 5 } } = 0 . 4 9 \ \mathrm { m m }$ 。**行距是 CAM 中控制表面质量的参数。精加工时间与行数 $1 / \delta$ 成正比，而 $\delta \propto \sqrt { h _ { s } }$ ，所以残留高度减半，精加工时间乘以 $\sqrt { 2 } \approx 1 . 4$ 。**
- **仿真**：CAM 系统把刀轨对毛坯模型做仿真，检测啃刀、碰撞和未切材料。**一次仿真抓住一次撞机，就省下一次主轴维修、一个夹具和一个零件，代价只是几分钟的计算时间。**
- **自适应加工**：在线测头测量已加工表面并调整刀轨，补偿夹具挠曲、热生长和刀具磨损。**主轴上的接触测头也取代了手工找正：它在几秒内找到零件和基准，而不必用表手工打。**
:::

::: example 体积精度与 21 项误差 {#ex-volumetric level=3 check="9.5"}
一台五轴加工中心有如下误差（单位均为 μm）：

- 直线定位：X: ±3，Y: ±3，Z: ±4
- 直线度：XY: ±2，XZ: ±2，YZ: ±3
- 垂直度：XY: ±3，XZ: ±3，YZ: ±4
- 角度（俯仰/偏摆/滚转）：每轴 3 角秒

估算工作包络中心（X = Y = Z = 200 mm）处用 150 mm 刀具时的体积精度（以 μm 计）。

体积误差是所有贡献的 RSS：

$$
\varepsilon _ { \text{vol } } \; = \; { \sqrt { \varepsilon _ { \text{pos} } ^ { 2 } + \varepsilon _ { \text{straight} } ^ { 2 } + \varepsilon _ { \text{sq} } ^ { 2 } + \varepsilon _ { \text{Abbe} } ^ { 2 } } }
$$

$$
\varepsilon _ { \text{pos} } \; = \; { \sqrt { 3 ^ { 2 } + 3 ^ { 2 } + 4 ^ { 2 } } } \; = \; { \sqrt { 3 4 } } \; = \; 5 . 8 \ \mu \mathrm { m }
$$

$$
\varepsilon _ { \text{straight} } \; = \; { \sqrt { 2 ^ { 2 } + 2 ^ { 2 } + 3 ^ { 2 } } } \; = \; { \sqrt { 1 7 } } \; = \; 4 . 1 \ \mu \mathrm { m }
$$

$$
\varepsilon _ { \text{sq} } \; = \; { \sqrt { 3 ^ { 2 } + 3 ^ { 2 } + 4 ^ { 2 } } } \; = \; 5 . 8 \ \mu \mathrm { m } \quad \text{（在 200 mm 行程处）}
$$

$$
\varepsilon _ { \text{Abbe} } \; = \; 1 5 0 \times 3 \times 4 . 8 5 \times 1 0 ^ { - 6 } \; = \; 2 . 2 \ \mu \mathrm { m } \quad \text{（3 角秒，150 mm 刀具）}
$$

\varepsilon _ { \text{vol } } \; = \; { \sqrt { 3 4 + 1 7 + 3 4 + 4 . 8 } } \; = \; { \sqrt { 8 9 . 8 } } \; = \; { \bf 9 . 5 \ \mu m }
$$

## 5. 自动化生产系统

::: definition 制造单元、柔性系统与生产线 {#def-production-systems}
生产自动化的三个层级是：

$$
\begin{array} { l l l l }
\textbf{层级} & \textbf{配置} & \textbf{换产} & \textbf{批量} \\ \hline
\text{刚性（硬）自动化} & \text{专用组合机床自动线} & \text{数天--数周} & \text{> 100 000/年} \\
\text{柔性（软）自动化} & \text{CNC + 交换工作台 + FMS} & \text{数分钟} & \text{100--50 000/年} \\
\text{单元化制造} & \text{2--5 台 CNC + 机器人 + 在制品} & \text{数分钟--数小时} & \text{100--10 000/年} \\
\text{单件小批车间} & \text{通用机床} & \text{数小时--数天} & \text{1--500/年} \\
\end{array}
$$

**柔性制造系统**（FMS）是一组由自动物料搬运系统（输送机、AGV 或有轨制导车）连接、由中央计算机控制的 CNC 机床。FMS 无需人工干预就能生产其零件族内的任何零件。**FMS 是 1980 年代自动化的旗舰概念，许多装置令人失望：资本成本难以证明合理，调度和软件也比预期复杂。现代等价物是更小的"熄灯单元"：几台 CNC 配托盘库或机器人，在夜间和周末无人值守运行。**

**成组技术**（GT）按几何相似性（直径、长度、特征数、公差等级）把零件分类为族，让每个族通过一个专用的**制造单元**——一小群按 U 形布置的不同机床，配 1–3 名操作者。Opitz 系统这样的分类编码（5 位形状码加 4 位辅助码）描述每个零件，编码相近的零件在同一单元生产。**GT 的好处不是机床（它们和单件小批车间的 CNC 一样）而是流程：零件几小时或几天通过单元，而不是几周转遍车间；在制品减少；换产缩短，因为单元的机床专用于一个族。**
:::

::: definition 产线平衡与节拍时间 {#def-line-balance}
**节拍时间**是可用生产时间除以客户需求：

$$
T _ { \text{takt } } \; = \; { \frac { T _ { \text{available } } } { N _ { \text{demand } } } } \quad [ \text{s/件} ]
$$

**最少工位数**是：

$$
N _ { \min } \; = \; \left\lceil { \frac { \sum _ { i = 1 } ^ { M } t _ { i } } { T _ { \text{takt } } } } \right\rceil
$$

其中 $t _ { i }$ 是第 $i$ 项作业的时间，$M$ 是作业总数。**产线效率**是：

$$
\eta \; = \; { \frac { \sum t _ { i } } { N \times T _ { \text{takt } } } } \times 1 0 0 \ \%
$$

**空闲时间**（操作者等待的时间）是 $I = N \times T _ { \text{takt } } - \sum t _ { i }$ 。**产线平衡问题是在遵守优先约束（作业 B 不能在作业 A 完成前开始）的前提下，把 $M$ 项作业分配给 $N$ 个工位，使最大工位时间最小。问题是 NP 难的，但简单的启发式（如在遵守优先约束的前提下优先分配最长的可分配作业）对实际规模的产线通常接近最优。**
:::

::: definition 精益制造、六西格玛与工业 4.0 {#def-lean-sixsigma}
**精益制造**（丰田生产方式）是一种消除浪费（muda）的哲学：过量生产、等待、搬运、过度加工、库存、动作、缺陷。工具是：

- **5S**：整理、整顿、清扫、清洁、素养。一个缺了工具 10 秒内就能看出来的工作场所。
- **看板**：一个拉动系统，下游工位向上游工位发出增产信号。在制品以上限的看板卡数为限。
- **SMED**（快速换模）：把内部换产（停机做）转换为外部换产（运行时做），把换产时间降到 10 分钟以下。**把 4 小时的冲压换模减到 12 分钟，每次换模腾出近 4 小时的压机时间——可以用来生产，也可以用来更频繁地换模，使批量和库存缩小。**
- **Poka-Yoke**：防错。只能以一个方向装零件的夹具、检测漏装 O 形圈的传感器、到值就响的扭矩扳手。**防错是预防缺陷，而不是探测缺陷。**

**六西格玛**是一种把工艺变差降到百万机会 3.4 个缺陷（DPMO）的数据驱动方法：短期散布 $\pm 6 \sigma$ 在公差内（$C _ { p } = 2$ ），按惯例允许均值长期漂移 $1 . 5 \sigma$ ，于是离较近极限还剩 $4 . 5 \sigma$ （单侧 3.4 ppm）。DMAIC 循环：定义、测量、分析、改进、控制。**六西格玛是有预算的 SPC："改进"一步是试验设计（DOE），找出解释大部分变差的少数几个工艺变量；"控制"一步是一张控制图，检测这些变量何时漂移。**

**工业 4.0** 是把信息物理系统集成进制造：每台机器上的物联网传感器、实时仿真产线的数字孪生、基于振动和电流特征的预测性维护、跟踪每个零件每道工序的制造执行系统（MES）。**工业 4.0 的实际好处不是技术（大部分传感器和软件并不新）而是数据：一台报告自身主轴振动的机器能足够早地显示轴承在劣化，从而把更换安排进计划停机，而不是遭遇非计划停机。**
:::

::: example 产线平衡：一个 8 作业装配 {#ex-line-balance level=3 check="93.3"}
一个部件有 8 项作业，时间和优先关系如下：

| 作业 | 时间（s） | 紧前作业 |
|------|----------|-------------|
| A | 5 | — |
| B | 3 | A |
| C | 8 | A |
| D | 4 | B |
| E | 6 | B, C |
| F | 7 | D, E |
| G | 5 | E |
| H | 4 | F, G |

需求为每 8 小时班次（28 800 s）1 920 件。平衡产线并求其效率（以 % 计）。

$$
T _ { \text{takt } } \; = \; { \frac { 2 8 \ 8 0 0 } { 1 \ 9 2 0 } } \; = \; 1 5 \ \mathrm { s }
$$

$$
N _ { \min } \; = \; \left\lceil { \frac { 5 + 3 + 8 + 4 + 6 + 7 + 5 + 4 } { 1 5 } } \right\rceil \; = \; \left\lceil { \frac { 4 2 } { 1 5 } } \right\rceil \; = \; 3
$$

三个工位、每个至多 15 s，总共只有 3 s 余量，所以必须仔细检查优先约束。F + G + H = 16 s 放不进最后一个工位，因此把 G（只需 E）前移。一个可行分配是：

- 工位 1：A、C（13 s）
- 工位 2：B、E、G（14 s）——E 需要 B 和 C，G 需要 E
- 工位 3：D、F、H（15 s）——D 需要 B，F 需要 D 和 E，H 需要 F 和 G

$$
\eta \; = \; { \frac { 4 2 } { 3 \times 1 5 } } \; = \; { \frac { 4 2 } { 4 5 } } \; = \; { \bf 9 3 . 3 \ \% }
$$

**产线用理论最少的三个工位满足节拍，每个循环空闲时间为 $4 5 - 4 2 = 3 \ \mathrm { s }$ 。工位 3 恰好等于节拍，那里的任何扰动都会让整线停下；实际上，平衡得这么紧的产线需要在工位 3 前放一个小缓冲，或多留一点产能。**
:::

## 6. 质量体系与检验

::: definition 质量管理体系：ISO 9001、AS9100、IATF 16949 {#def-qms}
**质量管理体系**（QMS）是为达成质量目标而文件化的一组过程、程序和职责。主导机械行业的三个标准是：

- **ISO 9001:2015**：通用 QMS。过程方法、基于风险的思维、领导作用、持续改进。认证是向大型制造商供货的常见准入要求。
- **AS9100D**：航空 QMS。增加技术状态管理、首件检验（AS9102）、 假冒件防范、人因工程和产物安全。**AS9100 审核抽查车间里的过程、校准记录、不合格报告和纠正措施。审核员的问题永远是同一个："给我看证据。"**
- **IATF 16949:2016**：汽车 QMS。要求使用 AIAG 的"五大核心工具"：APQP、PPAP、FMEA、MSA 和 SPC。汽车标准比 AS9100 更规定性：它规定方法（控制图、能力指数、量具 R&R）而不只是结果。

**质量成本**通常用"1-10-100"经验规则来说明：一个预防成本为 1 的缺陷，在厂内发现并修复约花 10，到了客户那里约花 100。类别是：

$$
\begin{array} { l l }
\textbf{类别} & \textbf{例子} \\ \hline
\text{预防} & \text{培训、FMEA、SPC、防错} \\
\text{鉴定} & \text{检验、试验、审核、校准} \\
\text{内部失效} & \text{废品、返工、复检、停机} \\
\text{外部失效} & \text{保修、召回、责任、客户流失} \\
\end{array}
$$

**这些数字是示意，不是测得的常数，但方向可靠：从失效和鉴定挪到预防的钱，通常会成倍地回来，因为最便宜的缺陷是从未发生的缺陷。**
:::

::: definition FMEA、PPAP 与 APQP {#def-fmea}
**FMEA**（失效模式与影响分析）是识别潜在失效、其原因和后果、并给纠正措施排优先级的结构化方法。**风险顺序数**（RPN）是：

$$
\text{RPN } \; = \; S \times O \times D
$$

其中 $S$ （严重度，1–10）是失效的后果，$O$ （频度，1–10）是原因的频率，$D$ （探测度，1–10）是在失效到达客户之前探测到它的难度。**探测度评级是最容易随过程控制变化的那个：$D$ 为 9–10 意味着现行控制几乎肯定抓不住该失效，$D$ 为 1–2 意味着它被自动抓住或预防（防错）。FMEA 的价值不在 RPN 数字（它是序数、武断且可被操纵——2019 年的 AIAG–VDA FMEA 手册已用"措施优先级"表取代它），而在它逼出的对话："如果这条焊缝冷了会怎样？我们怎么会知道？如果我们无法知道呢？"**

**APQP**（先期产品质量策划）是汽车行业把新零件从概念带到生产的框架，分五个阶段：（1）计划和确定项目，（2）产品设计和开发，（3）过程设计和开发，（4）产品和过程确认，（5）反馈、评定和纠正措施。**PPAP**（生产件批准程序）是第 4 阶段末的交付物：一个 18 个要素的包（设计记录、FMEA、控制计划、MSA、能力研究、PPAP 样件、材料证书、外观批准件），证明供应商能按图纸、以所报的节拍、稳定地制造该零件。**3 级（默认提交等级）向客户提交保证书、样件和完整的支持数据。客户或批准、或临时批准、或拒收；PPAP 被拒意味着零件未获批准生产，项目延期。**
:::

::: example 机加工轴系的 FMEA {#ex-fmea level=3 check="160"}
一根机加工轴有一个 $\phi 2 5 \pm 0 . 0 1 3$ 的轴承轴颈。计算下面 FMEA 条目的 RPN。

| 项目 | 失效模式 | 后果 | S | 原因 | O | 现行控制 | D | RPN |
|------|-------------|--------|---|-------|---|----------------|---|-----|
| 轴颈 | 超差偏大 | 轴承装不上 | 8 | 刀具磨损 | 4 | 每 50 件 CMM | 5 | 160 |

RPN 是 $8 \times 4 \times 5 = 1 6 0$ 。**措施是通过增加带自动刀具补偿的在线量具把 $D$ 从 5 降到 2（量具测每一件，当趋势接近极限时对刀补偏）。新 RPN 是 $8 \times 4 \times 2 = 6 4$ 。该措施不改变 $S$ （后果仍然严重）也不改变 $O$ （原因仍是刀具磨损），但它把 $D$ 从"测量时发现"变成"预防其发生"。**
:::

## 习题

::: exercise 测量不确定度：合成与扩展 {#ex-unc-comb level=3 check="2.8"}
一块 50 mm 量块在 CMM 上测量。不确定度分量为：CMM 误差 $u _ { 1 } = 1 . 2 \ \mu \mathrm { m }$ ，热变形 $u _ { 2 } = 0 . 5 \ \mu \mathrm { m }$ ，校准 $u _ { 3 } = 0 . 3 \ \mu \mathrm { m }$ ，重复性 $u _ { 4 } = 0 . 4 \ \mu \mathrm { m }$ 。$k = 2$ 时的扩展不确定度 $U$ 是多少（以 μm 计）？

::: solution
$$
u _ { c } \; = \; { \sqrt { 1 . 2 ^ { 2 } + 0 . 5 ^ { 2 } + 0 . 3 ^ { 2 } + 0 . 4 ^ { 2 } } } \; = \; { \sqrt { 1 . 4 4 + 0 . 2 5 + 0 . 0 9 + 0 . 1 6 } } \; = \; { \sqrt { 1 . 9 4 } } \; = \; 1 . 3 9 \ \mu \mathrm { m }
$$

$$
U \; = \; 2 \times 1 . 3 9 \; = \; { \bf 2 . 8 \ \mu m }
$$

**CMM 误差主导（方差的 74 %）。2.8 μm 的扩展不确定度是 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差的 5.6 %——在 10:1 规则之内但不宽裕。对 $\pm 0 . 0 1 0 \ \mathrm { m m }$ 的公差，这台 CMM 不够格（占 0.020 mm 公差宽度的 14 %）。**
:::
:::

::: exercise 过程能力：Cpk 与缺陷率 {#ex-cpk2 level=3 check="0.67"}
一个孔规定为 $\phi 1 2 . 0 0 0 \, _ { - 0 . 0 0 0 } ^ { + 0 . 0 2 5 } \ \mathrm { m m }$ 。工艺均值 $\mu = 1 2 . 0 1 0 \ \mathrm { m m }$ ，$\sigma = 0 . 0 0 5 \ \mathrm { m m }$ 。计算 $C _ { p k }$ 和预期缺陷率。（填写 $C _ { p k }$ 。）

::: solution
$$
C _ { p k } \; = \; \min \! \left( { \frac { 1 2 . 0 2 5 - 1 2 . 0 1 0 } { 3 \times 0 . 0 0 5 } } , \; { \frac { 1 2 . 0 1 0 - 1 2 . 0 0 0 } { 3 \times 0 . 0 0 5 } } \right) \; = \; \min \! \left( { \frac { 0 . 0 1 5 } { 0 . 0 1 5 } } , \; { \frac { 0 . 0 1 0 } { 0 . 0 1 5 } } \right) \; = \; \min ( 1 . 0 , \; 0 . 6 6 7 )
$$

$$
C _ { p k } \; = \; { \bf 0 . 6 7 }
$$

缺陷率：$p = \Phi ( ( 1 2 . 0 0 0 - 1 2 . 0 1 0 ) / 0 . 0 0 5 ) + 1 - \Phi ( ( 1 2 . 0 2 5 - 1 2 . 0 1 0 ) / 0 . 0 0 5 ) = \Phi ( - 2 ) + 1 - \Phi ( 3 ) = 0 . 0 2 2 8 + 0 . 0 0 1 3 5 = 0 . 0 2 4 1 = 2 4 \ 1 0 0 \ \mathrm { p p m }$ 。

**工艺无能力（$C _ { p k } < 1 . 0$ ），缺陷率为 2.4 %。问题是偏心：均值高于名义值 10 μm，而下极限只有 2σ 之远。把工艺对中到 12.0125（中点）可得 $C _ { p k } = 0 . 8 3$ ——仍无能力，但缺陷率减半到约 12 400 ppm。真正的解决办法是把 $\sigma$ 降到 0.003 mm（更好的铰刀、更刚性的装夹）并对中工艺，得到 $C _ { p } = C _ { p k } = 1 . 3 9$ 。**
:::
:::

::: exercise 控制图控制限 {#ex-chart-limits level=3 check="10.034"}
一个 $n = 5$ 的 X-bar/R 图有 ${ \bar { \bar { x } } } = 1 0 . 0 2 0 \ \mathrm { m m }$ 、${ \bar { R } } = 0 . 0 2 5 \ \mathrm { m m }$ 。计算 X-bar 图的控制限。（以 mm 填写 UCL，保留三位小数。）

::: solution
$n = 5$ 时：$A _ { 2 } = 0 . 5 7 7$ 。

$$
\text{UCL } \; = \; 1 0 . 0 2 0 + 0 . 5 7 7 \times 0 . 0 2 5 \; = \; 1 0 . 0 2 0 + 0 . 0 1 4 4 \; = \; { \bf 1 0 . 0 3 4 \ \mathrm { m m } }
$$

$$
\text{LCL } \; = \; 1 0 . 0 2 0 - 0 . 0 1 4 4 \; = \; 1 0 . 0 0 6 \ \mathrm { m m }
$$

R 图控制限为 $D _ { 3 } { \bar { R } } = 0$ 和 $D _ { 4 } { \bar { R } } = 2 . 1 1 4 \times 0 . 0 2 5 = 0 . 0 5 3 \ \mathrm { m m }$ 。

**切勿拿这些控制限与规范比较：X-bar 控制限（$\pm 1 4 . 4 \ \mu \mathrm { m }$ ）描述的是子组*均值*，其散布比单个零件小 $\sqrt { 5 }$ 倍。单个零件的 $\hat { \sigma } = { \bar { R } } / d _ { 2 } = 0 . 0 2 5 / 2 . 3 2 6 = 0 . 0 1 0 7 \ \mathrm { m m }$ ，散布为 $\pm 3 2 \ \mu \mathrm { m }$ 。对 $1 0 . 0 0 0 \pm 0 . 0 5 0 \ \mathrm { m m }$ 的规范，$C _ { p } = 1 . 5 5$ ，但因均值偏高 20 μm，$C _ { p k } = 0 . 0 3 0 / 0 . 0 3 2 = 0 . 9 3$ ：工艺完全可以受控却没有能力。**
:::

::: exercise 抽样检验：OC 曲线 {#ex-oc-curve level=3 check="0.81"}
一批用 $n = 5 0$ 、$c = 2$ 抽样。批不合格品率 3 % 时被接受的概率是多少？

::: solution
用二项分布：

$$
P _ { a } \; = \; \sum _ { d = 0 } ^ { 2 } { \binom { 5 0 } { d } } \, 0 . 0 3 ^ { d } \, 0 . 9 7 ^ { 5 0 - d }
$$

$$
= \; 0 . 9 7 ^ { 5 0 } + 5 0 \times 0 . 0 3 \times 0 . 9 7 ^ { 4 9 } + 1 2 2 5 \times 0 . 0 0 0 9 \times 0 . 9 7 ^ { 4 8 }
$$

$$
= \; 0 . 2 1 8 + 0 . 3 3 7 + 0 . 2 5 6 \; = \; { \bf 0 . 8 1 }
$$

**一批 3 % 不合格的批有 81 % 的概率被接受。AQL（$P _ { a } = 0 . 9 5$ 处）约 1.7 %，LTPD（$P _ { a } = 0 . 1 0$ 处）约 10 %。这个抽样方案很松：它接受大多数不合格品率至多 3 % 的批，只在约 10 % 以上才拒收大多数批。对关键尺寸，这个方案不够格；对外观尺寸，它可以。**
:::
:::

::: exercise 深度千分尺中的阿贝误差 {#ex-abbe-depth level=2 check="1.2"}
一把带 50 mm 接杆的深度千分尺阿贝偏置为 50 mm。测微螺杆有 5 角秒的俯仰误差。位移误差是多少（以 μm 计）？

::: solution
$$
\varepsilon \; = \; e \times \theta \; = \; 5 0 \times 5 \times { \frac { \pi } { 1 8 0 \times 3 6 0 0 } } \; = \; 5 0 \times 2 4 . 2 \times 1 0 ^ { - 6 } \; = \; { \bf 1 . 2 \ \mu m }
$$

**1.2 μm 绝对值很小，但是 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差宽度的 2.4 %、$\pm 0 . 0 0 5 \ \mathrm { m m }$ 公差宽度的 12 %——仅这一个来源就已超出 10:1 规则。阿贝误差是手持量具不用于最严公差的原因之一。**
:::
:::

::: exercise FMEA 风险顺序数 {#ex-fmea-rpn level=2 check="160"}
一个焊接接头评为严重度 8（结构失效）、频度 4、探测度 5（仅目视检验）。RPN 是多少？哪些措施能降低它？

::: solution
$$
\text{RPN } \; = \; 8 \times 4 \times 5 \; = \; { \bf 1 6 0 }
$$

**这里最有效的单项措施是通过增加 100 % 渗透检测或自动超声检测把 $D$ 从 5 降到 2：RPN 降到 $8 \times 4 \times 2 = 6 4$ 。把 $O$ 从 4 降到 2（改进焊接工艺）得 $8 \times 2 \times 5 = 8 0$ 。把 $S$ 从 8 降到 4（增加冗余载荷路径）得 $4 \times 4 \times 5 = 8 0$ 。但要注意，RPN 把三个评级当作可互换的，而它们并不是：对严重度 8 的失效，降低频度（预防）通常优于增加检验，AIAG–VDA 的措施优先级方法正因此首先看严重度。**
:::
:::

::: exercise 推导：由二项分布推导 OC 曲线 {#ex-derive-oc level=4 check="0.37"}
推导 $n = 1 0 0$ 、$c = 0$ 的一次抽样方案的 OC 曲线。求 $p = 0 . 0 1$ 处的 $P _ { a }$ 。

::: solution
$c = 0$ 时，只有样本中发现零个不合格品批才被接受。从不合格品率为 $p$ 的批中抽 $n$ 件、发现零个不合格品的概率是：

$$
P _ { a } ( p ) \; = \; ( 1 - p ) ^ { n }
$$

这就是 $d = 0$ 的二项式：$P _ { a } = { \binom { n } { 0 } } p ^ { 0 } ( 1 - p ) ^ { n } = ( 1 - p ) ^ { n }$ 。

$n = 1 0 0$ 、$p = 0 . 0 1$ 时：

$$
P _ { a } \; = \; 0 . 9 9 ^ { 1 0 0 } \; = \; e ^ { 1 0 0 \ln 0 . 9 9 } \; = \; e ^ { - 1 . 0 0 5 } \; = \; { \bf 0 . 3 6 6 }
$$

**一批 1 % 不合格的批有 37 % 的概率被接受、63 % 的概率被拒收。AQL（$P _ { a } = 0 . 9 5$ 处）是 $p = 1 - 0 . 9 5 ^ { 1 / 1 0 0 } = 0 . 0 0 0 5 = 0 . 0 5 \ \%$ （500 ppm），LTPD（$P _ { a } = 0 . 1 0$ 处）是 $1 - 0 . 1 0 ^ { 1 / 1 0 0 } = 2 . 3 \ \%$ 。所以该方案在 500 ppm 时放行 95 % 的批，但对 2.3 % 不合格的批仍放行十分之一：零接受数方案在低缺陷率时对生产方很严，却没给使用方多少保护。** $\blacksquare$
:::
:::

::: exercise 推导：偏心工艺的 Cpk {#ex-derive-cpk level=4 check="1.0"}
一个工艺 $C _ { p } = 1 . 5$ ，均值相对中心偏移 $1 . 5 \sigma$ 。计算 $C _ { p k }$ 和缺陷率。（填写 $C _ { p k }$ 。）

::: solution
$C _ { p } = 1 . 5$ 时：公差宽度为 $6 \sigma \times 1 . 5 = 9 \sigma$ 。均值到最近极限的距离是：

$$
{ \frac { 9 \sigma } { 2 } } - 1 . 5 \sigma \; = \; 4 . 5 \sigma - 1 . 5 \sigma \; = \; 3 . 0 \sigma
$$

$$
C _ { p k } \; = \; { \frac { 3 . 0 \sigma } { 3 \sigma } } \; = \; { \bf 1 . 0 }
$$

缺陷率：$p = \Phi ( - 3 . 0 ) + \Phi ( - 6 . 0 ) = 0 . 0 0 1 3 5 + 0 . 0 0 0 0 0 0 5 \approx 1 3 5 0 \ \mathrm { p p m }$ 。

**同一工艺若对中（$\pm 4 . 5 \sigma$ ），缺陷率为 $2 \Phi ( - 4 . 5 ) = 6 . 8 \ \mathrm { p p m }$ 。1.5σ 的偏移——$\sigma = 5 \ \mu \mathrm { m }$ 的工艺上 7.5 μm 的偏置——把它升到 1 350 ppm，几乎全在一侧。（表中的 2 700 ppm 对应 $C _ { p k } = 1$ 的*对中*工艺，有两个尾部。）对中是最便宜的质量改进：一次刀具偏置换回约 200 倍的缺陷率。** $\blacksquare$
:::
:::

::: exercise 节拍时间与产线效率 {#ex-takt level=3 check="89.6"}
一条产线有 4 个工位，单件时间分别为 55、48、62、50 秒。需求为每 8 小时班次 480 件。计算节拍时间，找出瓶颈，并求把 2 s 工作从工位 3 移到工位 2 之前和之后的平衡效率 $\sum t _ { i } / ( N \, t _ { \max } )$ 。（填写重新平衡后的效率，以 % 计。）

::: solution
$$
T _ { \text{takt } } \; = \; { \frac { 2 8 \ 8 0 0 } { 4 8 0 } } \; = \; 6 0 \ \mathrm { s }
$$

瓶颈是 62 s 的工位 3，它超过 60 s 的节拍时间。**产线无法满足需求。**平衡效率（基于瓶颈）：

$$
\eta \; = \; { \frac { 5 5 + 4 8 + 6 2 + 5 0 } { 4 \times 6 2 } } \; = \; { \frac { 2 1 5 } { 2 4 8 } } \; = \; { \bf 8 7 \ \% }
$$

把 2 s 的工作从工位 3 移到工位 2（它有 12 s 余量），得到 55、50、60 和 50 s，所有工位都在节拍之内：

$$
\eta \; = \; { \frac { 2 1 5 } { 4 \times 6 0 } } \; = \; { \bf 8 9 . 6 \ \% }
$$

**重新平衡提高了效率（从 87 % 到 89.6 %），因为同样的工作分配在更短的循环里，而且产线现在能满足需求。所有工位单件时间相等时效率最大。**
:::
:::

::: quiz 测量不确定度 {#quiz-unc}
一个零件公差为 $\pm 0 . 0 2 0 \ \mathrm { m m }$ 。测量不确定度在 $k = 2$ 下为 $\pm 0 . 0 0 5 \ \mathrm { m m }$ 。测量不确定度与公差之比是多少，按 10:1 规则可接受吗？

- [ ] 5 % ——可接受
- [x] 12.5 % ——略差于 10:1 规则
- [ ] 10 % ——恰在极限上
- [ ] 50 % ——测量毫无用处

::: solution
公差宽度是 $2 \times 0 . 0 2 0 = 0 . 0 4 0 \ \mathrm { m m }$ 。扩展不确定度是 $0 . 0 0 5 \ \mathrm { m m }$ 。比值为 $0 . 0 0 5 / 0 . 0 4 0 = 1 2 . 5 \ \%$ 。按 10:1 规则（不确定度 $\leq$ 公差宽度的 $1 0 \ \%$ ），测量勉强——略差于该规则。**实际答案：测量能对大多数零件做出接受/拒收判定，但距极限 5 μm 以内的零件处于"不确定区"，应用更好的仪器或比较量具重新测量。**
:::
:::

::: quiz 过程能力 {#quiz-cpk}
一个工艺 $C _ { p } = 2 . 0$ 、$C _ { p k } = 1 . 0$ 。这告诉你什么？

- [ ] 工艺无能力且散布太宽
- [x] 散布没问题但工艺未对中
- [ ] 工艺已对中但散布太宽
- [ ] 测量系统很差

::: solution
**散布没问题但工艺未对中。**$C _ { p } = 2 . 0$ 意味着 $6 \sigma$ 散布放进公差还有 2 倍富余——散布极好。$C _ { p k } = 1 . 0$ 意味着最近的规范极限距均值只有 $3 \sigma$ ——工艺偏移了 $C _ { p } - C _ { p k } = 1 . 0$ 个 $3 \sigma$ 单位，即偏心 $3 \sigma$ 。**解决办法是简单的对中调整（一次刀具偏置、一片夹具垫片），而不是工艺改进。$C _ { p } - C _ { p k }$ 的差距就是不居中的代价，而它永远是最便宜的质量改进。**
:::

## 本讲的后续内容

- **[[manufacturing/machining]]** —— 机床守得住的公差是能力计算的输入。表面质量、刀具磨损和主轴热生长是 SPC 监控的变差来源。
- **[[manufacturing/process-selection]]** —— 一个工艺能达到的 IT 等级决定哪些工艺是候选。$\pm 0 . 0 0 5 \ \mathrm { m m }$ 的公差排除了铸造、锻造和钣金；$\pm 0 . 5 \ \mathrm { m m }$ 的公差排除了磨削和 EDM。
- **[[manufacturing/additive-manufacturing]]** —— 增材制造的成形公差通常为 $\pm 0 . 1 { - } 0 . 3 \ \mathrm { m m }$ ，对 50 mm 特征约为 IT12–IT14。增材零件上每个关键尺寸都要机加工，而机加工余量是一个公差累积问题。
- **[[manufacturing/joining]]** —— 焊缝检验（VT、PT、MT、RT、UT）是属性测量，其探测概率取决于缺陷取向、表面状况和检验员持证等级。POD（探测概率）曲线就是无损检测的 OC 曲线。
- **[[manufacturing/casting]]** —— 铸造公差通常为 IT14–IT17（100 mm 尺寸上约 $\pm 0 . 4 { - } 1 . 8 \ \mathrm { m m }$ ），尺寸精度取决于模样磨损、模具温度和收缩余量。模样要校准，模具要用红外测温控制，首件要扫描。
- **[[control-systems/pid-control]]** —— CNC 轴是一个 PID 控制的伺服系统。定位精度受伺服带宽、编码器分辨率和摩擦限制。阿贝误差是伺服无法抑制的扰动，因为它没有被测量。
- **[[control-systems/feedback-stability]]** —— 带刀具补偿的在线量具是一个反馈回路。若每次按测得误差的一个比例 $g$ 修正，$g > 1$ 时回路过校正而振荡，$g > 2$ 时发散；远小于 1 的增益还能避免把测量噪声反馈给刀具。采样间隔必须短于刀具磨损时间常数。
- **[[design-process/reliability-risk]]** —— FMEA 是制造与设计之间的桥：严重度评级来自设计（零件失效会怎样），频度评级来自工艺（原因多久发生一次），探测度评级来自检验计划（我们多大概率抓住它）。
- **[[design-process/design-for-manufacture]]** —— 公差累积、基准方案和量具可达性是 DFM 决策。一张给无法检验的特征标 $\pm 0 . 0 1 \ \mathrm { m m }$ 公差的图纸，是一张注定出错的图纸。

::: history 计量、质量与自动化：从螺纹到闭环 {#history-metrology}
**1841。** 约瑟夫·惠特沃斯（Joseph Whitworth）在英国土木工程师学会宣读《论统一的螺纹制》，提出每种直径采用单一标准的牙型和螺距。他在随后十年制造的能分辨百万分之一英寸的精密测长机，以及他的标准量规，使不同车间制造的零件能够相互装配成为现实。**互换性不只是设计概念；它也是计量概念。**

**1896–1901。** 瑞典埃斯基尔斯蒂纳国营步枪厂的检验员卡尔·爱德华·约翰松（Carl Edvard Johansson）研制出精密**量块**组，几十块量块研合即可组成数以千计的长度；他于 1901 年获得瑞典第 17017 号专利。量块成为国家长度基准与车间之间的环节。

**1924。** 西方电气公司工程部（不久成为贝尔电话实验室）的**沃尔特·A·休哈特（Walter A. Shewhart）**在 1924 年 5 月 16 日的一份备忘录中画出第一张**控制图**，用统计确定的界限把"可指定"原因与"机遇"原因造成的变差区分开。**1931 年**，他出版 *Economic Control of Quality of Manufactured Product*。

**1949。** 美国军方发布 MIL-P-1629，即**失效模式、影响与危害性分析**的程序。1960 年代 NASA 的承包商（包括阿波罗计划）使用了其变体，福特在 1970 年代采用 FMEA，1980 年代它成为汽车业的通行做法。

**1950。** 应日本科学技术联盟（JUSE）之邀，**W·爱德华兹·戴明（W. Edwards Deming）**为日本工程师和高层管理者讲授统计质量控制。JUSE 于 1951 年以他的名字设立**戴明奖**。

**1952。** MIT 伺服机构实验室根据约翰·T·帕森斯（John T. Parsons）的构想、在美国空军资助下，演示了第一台**数控铣床**：一台由穿孔带驱动的改装三轴 Cincinnati Hydro-Tel 铣床。**数控（以及后来的 CNC）让复杂几何可以重复制造，让换产成为软件问题。**

**1978–1990。** 大野耐一的《丰田生产方式》在日本出版（1978；英文版 1988）。约翰·克拉夫契克（John Krafcik）在《精益生产系统的胜利》（*Sloan Management Review*，1988）中首创"精益生产"一词，沃马克、琼斯和鲁斯的《改变世界的机器》（1990）使这些思想广为传播。

**1986–1987。** **摩托罗拉**发展出**六西格玛**（通常归功于工程师比尔·史密斯 Bill Smith），并于 1987 年在全公司推行，目标是每百万机会 3.4 个缺陷。

**1987。** ISO 发布 **ISO 9000** 质量管理标准系列，主要基于英国的 BS 5750。此后在 1994、2000、2008 和 2015 年修订。

**2000 年代至今。** 扫描式 CMM、光学扫描仪和 X 射线 CT 把检验从测少数几个点变成测整个表面和内部特征，在机测头把测量结果反馈给数控系统。**闭环加工单元——测量、补偏刀具、再切削——就是把控制图这个老思想做进了机床里。**

::: summary 计量、质量与自动化 {#summary-metrology}
- **测量要么可溯源，要么毫无意义。** 从 SI 米到车间千分尺的校准链必须不间断、有记录、在有效期内。没有不确定度声明的校准证书不是校准。
- **每次测量都有不确定度，它不应超过公差的约 10 %。** GUM 框架（A 类 + B 类、RSS、以 $k = 2$ 扩展）量化疑虑。不确定度越大，极限附近测量无法做出接受/拒收判定的区域就越宽。
- **阿贝原则支配仪器设计。** 测量轴线应与被测量的尺寸轴线共线。阿贝偏置 $e$ 与角度误差 $\theta$ 产生 $e \times \theta$ 的位移误差。卡尺在设计上违反阿贝原则。
- **GD&T 用圆形公差带取代方形公差带。** 刚好包住 $\pm 0 . 1$ 方形公差带的圆是 $\phi 0 . 2 8 3$ ，面积多 57 %，而且与销的实际装配方式一致。MMC 在特征不处于最大实体时给出补偿公差。基准参考系是三个平面，由 3-2-1 规则建立。
- **过程能力把工艺散布与公差宽度比较。** $C _ { p }$ 是潜在能力；$C _ { p k }$ 是实际能力。$C _ { p k } \geq 1 . 3 3$ 是批量生产的常见最低值，1.67 是新工艺的常见要求。对中工艺的缺陷率是 $p = 2 \Phi ( - 3 C _ { p k } )$ 。
- **控制图区分普通原因与特殊原因。** $\pm 3 \sigma$ 控制限的 X-bar/R 图有 0.27 % 的虚警率。CUSUM 图约 10 个样本检测 1σ 偏移，而不是约 44 个。西电判异规则以虚警为代价增加灵敏度。
- **验收抽样是一场统计赌博。** OC 曲线给出接受概率随批质量的变化。$n = 1 0 0$ 的 $c = 0$ 方案在 500 ppm 时接受 95 % 的批，但对 2.3 % 的批仍接受 10 %。抽样判定的是批，不分拣零件；它和人工 100 % 检验都不能取代有能力的工艺。
- **三轴机床有 21 项几何误差。** 体积精度比单轴定位精度差数倍。测出这些误差并在控制器中补偿，可以降低体积误差。刀尖的阿贝误差是刀长乘角度误差。
- **产线平衡确定节拍时间和工位数。** $T _ { \text{takt } } = T _ { \text{available } } / N _ { \text{demand } }$ 。最少工位数是 $\lceil \sum t _ { i } / T _ { \text{takt } } \rceil$ 。产线效率是 $\sum t _ { i } / ( N \times T _ { \text{takt } } )$ 。瓶颈是单件时间最长的工位。
- **质量成本遵循 1-10-100 经验规则。** 预防成本为 1 的缺陷，在厂内发现约花 10，到客户那里约花 100。最便宜的缺陷是从未发生的缺陷，最便宜的质量改进是对中工艺。
:::

## 延伸阅读

- **JCGM 100:2008 (GUM)** —— 《测量不确定度表示指南》（*Evaluation of measurement data — Guide to the expression of uncertainty in measurement*）。不确定度预算的权威参考：A 类与 B 类评定、合成与包含因子。
- **ISO 14253-1:2017** —— 产品几何技术规范中关于判定规则的标准，即第 1 节的接受/拒收/不确定区规则。
- **ISO 286-1:2010** —— 线性尺寸公差的 ISO 代号体系：IT 等级、基本偏差与配合。
- **ASME Y14.5-2018** —— *Dimensioning and Tolerancing*，ISO 对应标准为 **ISO 1101**。几何公差项目、基准参考系与材料边界修饰符。
- **AIAG《统计过程控制（SPC）》第 2 版（2005）**与 **AIAG《测量系统分析（MSA）》第 4 版（2010）**—— 控制图、能力与量具 R&R 的汽车业参考；另见 **AIAG–VDA《FMEA 手册》（2019）**和 AIAG《PPAP》手册。
- **Montgomery, D.C.** —— *Introduction to Statistical Quality Control*，第 8 版，Wiley，2019。标准教材：控制图、CUSUM、能力、验收抽样与试验设计。
- **Shewhart, W.A. (1931)** —— *Economic Control of Quality of Manufactured Product*，Van Nostrand，控制图的源头；以及 **Deming, W.E. (1986)** —— *Out of the Crisis*，MIT Press。
- **Groover, M.P.** —— *Automation, Production Systems, and Computer-Integrated Manufacturing*，第 5 版，Pearson。数控、柔性制造系统、成组技术与产线平衡。
