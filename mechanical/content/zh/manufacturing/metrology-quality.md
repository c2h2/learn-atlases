机床是一种以受控方式制造误差的装置。它把零件夹持在几微米以内，把切削刃沿程序路径移动控制在几微米以内，并去除材料使最终尺寸落在通常 25–100 μm 宽的公差带内。图纸上的每个数字都是关于一次尚未进行的测量的陈述，而你做的每次测量都带着一个通常为你要验证的公差 5–20 % 的不确定度。**现代制造的整个大厦——可互换零件、免装配的装配、不做 100 % 检验的质量控制、不做破坏性试验的认证——建立在这样一个命题之上：你能把尺寸测得比造得更准，而且测量可溯源到在哥德堡和在广州一样的米的定义。**当这个命题失效时，零件就装不上，轴承就发热，涡轮叶片就擦碰，飞机就停飞。

计量学是研究这个命题的科学。统计过程控制是不测每个零件而把机器保持在公差带内的科学。数控与自动化是执行制造的机器的工程学。质量体系是证明你是有意做到的文书工作。本讲涵盖全部四者，因为它们是同一门学问：**在一个每个工艺都有分布、每次测量都有不确定度、每个客户都要一个数字的世界里，对几何误差的控制。**

::: warning 计量与质量出错的九种方式
**把精密度与准确度混为一谈。**一台 CMM 以 0.1 μm 的一致性重复读出同一个错误数字 50 次，它是精密而错误的。一把 ±0.05 mm 但已溯源到 NIST 的卡尺，是准确而不精密的。**准确度是溯源性；精密度是重复性；两者都需要，而且证明方式不同——前者用校准基准，后者用量具 R&R 研究。****测量而不做不确定度预算。**没有不确定度的测量是一个数字，不是一个结果。如果你报告"25.003 mm"而不说"95 % 置信度下 ±0.004 mm"，你就没有告诉客户零件是否在公差内的任何信息，因为你没有告诉他们*你*是否知道零件是否在公差内。**判定规则是：如果测量不确定度超过公差的 10 %，该测量就无法做出接受/拒收判定，你需要的是更好的仪器，不是更好的操作员。****忽视量具 R&R。**如果量具消耗了公差带的 30 %，工艺就是在被一把自身有 30 % 时间超出公差的尺子评判。量具 R&R 研究（重复性 + 再现性）对关键尺寸必须显示低于公差的 $1 0 \ \%$ ，对次要尺寸低于 $2 0 \ \%$ 。**一个用坏量具（R&R $2 5 \ \%$ ）测出来看似有能力（$C _ { p k } = 1 . 5$ ）的工艺，实际上是不及格的（$C _ { p k , \text{true } } \approx 1 . 3$ ），而且客户会比您先发现。****按图纸而不是按工艺定公差。**车削直径上 $\pm 0 . 0 1 \ \mathrm { m m }$ 的公差，是在声明工艺能达到 $C _ { p k } \geq 1 . 3 3$ ，对数控车床这意味着 $6 \sigma$ 散布 $< 0 . 0 1 5 \ \mathrm { m m }$ ——可以做到，但只有靠刚性装夹、锋利刀具和被切削力推着不动的零件。**规定工艺守得住的公差，否则就接受 5 % 的零件报废、10 % 的零件"可疑"。****把通止规当测量用。**通止规是属性量具：它告诉你"在"或"不在"，不告诉你"差多少"。如果尺寸正在向极限漂移，量具不知道，你最先知道的是 200 个零件报废了。**对任何会漂移的尺寸（刀具磨损、热生长、夹具磨损），用计数值量具和控制图。****不计算热膨胀。**钢的膨胀系数为 $1 1 . 7 \times 1 0 ^ { - 6 } \ \mathrm { K ^ { - 1 } }$ 。一个 100 mm 钢零件在 $3 0 \ \mathrm { ^ \circ C }$ 的车间里于 $2 5 \ \mathrm { ^ \circ C }$ 下测量，比图纸要求大 5.8 μm，而 $2 0 \ \mathrm { ^ \circ C }$ 计量室里的 CMM 读数比 $3 0 \ \mathrm { ^ \circ C }$ 车间里钳工的千分尺小 5.8 μm。**对严于 20 μm 的公差，测量温度是比仪器更大的误差源，而且零件必须在 $2 0 . 0 { \pm } 0 . 5 \ \mathrm { ^ \circ C }$ 下按每 25 mm 厚度至少一小时保温后才能测量。****按供应商的数据接受、按自己的数据拒收。**供应商的 CMM 说 25.002，你的 CMM 说 25.008，图纸说 $2 5 . 0 0 0 \pm 0 . 0 1 0$ ，而两个测量在各自的不确定度内都是对的。**解决办法不是争论谁对，而是把两台 CMM 对着一块校准量块比较，找出那 6 μm 的系统偏差——它通常是测头校准误差、热补偿误差或拟合算法的差异（最小二乘 vs 最小区域）。****在 PPAP 里跳过测量系统分析。**客户的 PPAP 检查表要求图纸上每个尺寸都有量具 R&R。如果你没有，PPAP 被拒，零件不获批，项目延期。**MSA 不是文书工作；它是你的接受/拒收判定基于数据而不是基于运气的证明。****自动化一个烂工艺。**一台带在线量具和刀具寿命补偿环的数控机床，如果装夹偏了 0.02 mm，会造出 10 000 个一致地错的零件。**自动化放大你喂给它的任何东西。先修好工艺，再自动化它。**
:::

## 1. 测量、溯源与不确定度

::: definition 计量学、溯源性与校准等级链 {#def-traceability}
**计量学**是测量的科学，**溯源性**是测量结果的一个属性：结果能通过一条不间断的、有文件记录的校准链追溯到基准（通常是 SI 单位制），每一环贡献一个已声明的不确定度。车间千分尺的链条如下：

$$
\begin{array} { r l }
\text{SI 米（由 } c \text{ 和 } \Delta \nu _ { \mathrm { Cs } } \text{ 定义）} & \\
\quad \downarrow & \text{国家计量院（NPL、PTB、NIST）：激光干涉仪，} { \pm } 0 . 5 \ \mathrm { n m / m } \\
\quad \downarrow & \\
\text{0 级量块（干涉法校准）} & { \pm } 0 . 1 \ \mu \mathrm { m } \text{（在 } 2 5 \ \mathrm { m m } \text{ 处）} \\
\quad \downarrow & \\
\text{K1 级量块（传递标准）} & { \pm } 0 . 2 5 \ \mu \mathrm { m } \\
\quad \downarrow & \\
\text{车间千分尺（对 K1 量块校准）} & { \pm } 1 { - } 2 \ \mu \mathrm { m } \\
\quad \downarrow & \\
\text{CMM 上的零件} & { \pm } 2 { - } 5 \ \mu \mathrm { m } \\
\end{array}
$$

链条上的每一环都是由认可实验室（按 ISO/IEC 17025）执行的校准，证书上写明测得值、扩展不确定度和包含因子。**没有不确定度声明的校准证书不是校准；它是一次合格/不合格试验。**校准间隔由仪器的漂移历史决定，而不是由日历决定：每年漂移 0.5 μm 的 CMM 可以两年校准一次；每月漂移 2 % 的扭矩扳手必须每月校准或更换。

几何计量的**参考条件**是 $2 0 . 0 0 0 \ \mathrm { ^ \circ C }$ （ISO 1 参考温度，选它是因为它接近欧洲车间旧的"正常温度"，也因为钢的热膨胀在其附近大致线性）、相对湿度 $50 \ \%$ 和标准大气压。**地球上每张工程图纸上的每个尺寸都是在 $2 0 \ \mathrm { ^ \circ C }$ 定义的，而每个不在 $2 0 \ \mathrm { ^ \circ C }$ 进行的测量都必须做热膨胀修正——或者证明修正量小于测量不确定度。**
:::

::: definition 测量不确定度：GUM 框架 {#def-uncertainty}
《测量不确定度表示指南》（GUM，JCGM 100:2008）定义了量化与测量结果相关联的疑虑的程序。**合成标准不确定度**是各不确定度分量的平方和根：

$$
u _ { c } \; = \; { \sqrt { \sum _ { i = 1 } ^ { N } c _ { i } ^ { 2 } \, u _ { i } ^ { 2 } } } \qquad c _ { i } \; = \; { \frac { \partial f } { \partial x _ { i } } }
$$

其中 $u _ { i }$ 是输入量 $x _ { i }$ 的标准不确定度，$c _ { i }$ 是**灵敏系数**（测量函数 $f$ 对 $x _ { i }$ 的偏导数）。对直接长度比较，$c _ { i } = 1$ ，公式退化为简单的 RSS。

分量分为两类：

- **A 类**（统计的）：由重复观测评定。$u _ { A } = s / { \sqrt { n } }$ ，其中 $s$ 是样本标准差，$n$ 是观测次数。
- **B 类**（其余一切）：由证书、制造商规格、经验或假定的分布评定。对半宽为 $a$ 的矩形（均匀）分布：$u _ { B } = a / { \sqrt { 3 } }$ 。对三角分布：$u _ { B } = a / { \sqrt { 6 } }$ 。对声明 $k = 2$ 包含因子的正态分布：$u _ { B } = U / 2$ 。

**扩展不确定度**是 $U = k \, u _ { c }$ ，其中 $k = 2$ 给出约 95 % 置信度（对自由度足够的正态分布）。测量结果报告为：

$$
L \; = \; { \bar { L } } \, \pm \, U \quad [ \text{在 } k = 2 \text{，} 9 5 \ \% \text{ 置信度下} ]
$$

**符合性评定的判定规则（ISO 14253-1）：**若 ${ \bar { L } } + U \leq \mathrm { U S L }$ 且 ${ \bar { L } } - U \geq \mathrm { L S L }$ 则零件**接受**；若 ${ \bar { L } } - U > \mathrm { U S L }$ 或 ${ \bar { L } } + U < \mathrm { L S L }$ 则**拒收**；否则为**不确定区**。不确定区的宽度就是测量不确定度，这就是在一个实验室"符合图纸"的零件在另一个实验室可能"不符合图纸"的原因。**经验法则是测量不确定度不应超过公差的 10 %（10:1 规则），这意味着 $\pm 0 . 0 1 \ \mathrm { m m }$ 的公差要求 $\leq 0 . 0 0 2 \ \mathrm { m m }$ 的测量不确定度——用校准过的千分尺可以做到，用游标卡尺不行。**
:::

::: definition 接触式与非接触式测量：CMM、扫描仪与干涉仪 {#def-instruments}
仪器的选择是准确度、速度和几何之间的折中：

$$
\begin{array} { l l l l l }
\textbf{仪器} & \textbf{准确度} & \textbf{速度} & \textbf{测量对象} & \textbf{局限} \\ \hline
\text{千分尺} & { \pm } 1 { - } 2 \ \mu\text{m} & \text{10 s/件} & \text{1D：直径、厚度} & \text{依赖操作者，1 点} \\
\text{游标卡尺} & { \pm } 2 0 \ \mu\text{m} & \text{5 s/件} & \text{1D：粗略尺寸} & \text{阿贝误差、余弦误差} \\
\text{内径量缸表} & { \pm } 2 { - } 5 \ \mu\text{m} & \text{30 s/孔} & \text{1D：孔径、圆度} & \text{依赖对中} \\
\text{平板 + 指示表} & { \pm } 2 { - } 1 0 \ \mu\text{m} & \text{数分钟/件} & \text{2D：平面度、平行度} & \text{手工，操作者技能} \\
\text{CMM（触发式）} & { \pm } ( 1 . 5 { + } L / 3 0 0 ) \ \mu\text{m} & \text{5--60 min/件} & \text{3D：点、形状、GD\&T} & \text{慢，测头限制几何} \\
\text{CMM（扫描式）} & { \pm } ( 2 { + } L / 2 5 0 ) \ \mu\text{m} & \text{2--20 min/件} & \text{3D：连续曲面} & \text{测杆挠曲，速度受限} \\
\text{激光/激光雷达扫描仪} & { \pm } 1 5 { - } 5 0 \ \mu\text{m} & \text{1--5 min/件} & \text{3D：点云、自由曲面} & \text{依赖表面，无内孔} \\
\text{结构光} & { \pm } 5 { - } 2 0 \ \mu\text{m} & \text{1--5 min/件} & \text{3D：点云} & \text{反光表面，小零件} \\
\text{X 射线 CT} & { \pm } 1 0 { - } 5 0 \ \mu\text{m} & \text{10--120 min/件} & \text{3D：内部 + 外部} & \text{成本、尺寸限制、密度对比} \\
\text{激光干涉仪} & { \pm } 0 . 5 \ \mathrm{nm} & \text{连续} & \text{1D：位移、直线度} & \text{对准、空气折射率} \\
\text{光学比较仪} & { \pm } 5 \ \mu\text{m} & \text{1 min/件} & \text{2D：轮廓、小零件} & \text{仅 2D，手工} \\
\end{array}
$$

**CMM**（三坐标测量机）是几何计量的主力。带触发式测头的桥式 CMM 通过偏转测杆直到内置开关跳开来测量一个点；机器从三个光栅尺（通常为海德汉或雷尼绍，分辨率 $0 . 1 \ \mu \mathrm { m }$ ）读出测尖的 $( x , y , z )$ 。准确度按 $E _ { 0 , M } = A + L / K$ （ISO 10360）规定，其中 $A$ 是探测误差（1–2 μm），$L$ 是测量长度，$K$ 是因子（300–500）。对 $1 . 5 + L / 3 0 0$ 的机器测 500 mm：$E = 1 . 5 + 5 0 0 / 3 0 0 = 3 . 2 \ \mu \mathrm { m }$ 。**$L / K$ 项是机器导轨的直线度和垂直度误差，这就是 CMM 的准确度随零件尺寸而不是随机器尺寸退化的原因。**

**阿贝原则**指出测量轴线应与被测量的尺寸轴线共线。如果两者偏置距离 $e$ （**阿贝偏置**），导轨的角度误差 $\theta$ 产生位移误差：

$$
\varepsilon _ { \text{Abbe } } \; = \; e \, \sin \theta \; \approx \; e \, \theta
$$

$e = 1 0 0 \ \mathrm { m m }$ 、$\theta = 5$ 角秒 $= 2 4 . 2 \ \mu \mathrm { r a d }$ 时：$\varepsilon = 2 . 4 \ \mu \mathrm { m }$ 。**卡尺在设计上就违反阿贝原则（尺身在读数面一侧，偏置 10–20 mm），这就是无论你读得多仔细卡尺都测不到 20 μm 以内的原因。CMM 在 Z 轴遵守阿贝原则（光栅尺在滑枕上，与测头共线），但在 X 和 Y 违反它（光栅尺在横梁上，与测尖隔着测杆长度偏置）。**
:::

## 2. 公差、配合与几何尺寸标注

::: definition ISO 公差体系：IT 等级与基本偏差 {#def-iso-tol}
ISO 286 体系把一个公差定义为**公差单位** $i$ （名义尺寸 $D$ 的函数）与一个定义 **IT 等级**的倍数的乘积：

$$
i \; = \; 0 . 4 5 \, { \sqrt [ 3 ] { D } } \; + \; 0 . 0 0 1 \, D \quad [ \mu \mathrm { m } , \ D \text{ 以 mm 计} ]
$$

IT 等级从 IT01（最精，用于量块）到 IT18（最粗，用于铸件和焊接件）。标准等级及其倍数为：

$$
\begin{array} { c c c c c c c c c }
\text{等级} & \text{IT5} & \text{IT6} & \text{IT7} & \text{IT8} & \text{IT9} & \text{IT10} & \text{IT11} & \text{IT12} \\
\text{倍数} & 7 i & 10 i & 16 i & 25 i & 40 i & 64 i & 100 i & 160 i \\
\text{典型用途} & \text{轴承} & \text{精密} & \text{定位} & \text{一般} & \text{一般} & \text{钣金} & \text{焊接} & \text{铸造} \\
& \text{座孔} & \text{配合} & & \text{配合} & \text{粗活} & & \text{结构件} & \\
\end{array}
$$

$D = 5 0 \ \mathrm { m m }$ 时：$i = 0 . 4 5 \times 3 . 6 8 + 0 . 0 5 = 1 . 7 1 \ \mu \mathrm { m }$ 。IT7 $= 1 6 \times 1 . 7 1 = 2 7 . 4 \ \mu \mathrm { m } \approx 2 5 \ \mu \mathrm { m }$ （表列值）。**小尺寸下立方根项主导（它代表守住一个小特征的难度），大尺寸下线性项主导（它代表累积的直线度和热误差）。**

**基本偏差**（字母代号：轴用 a–z，孔用 A–Z）确定公差带相对名义尺寸的位置。最常见的配合是：

- **间隙配合**：H7/g6（转动配合，50 mm 处间隙约 $2 5 \ \mu \mathrm { m }$ ）、H7/f7（精密转动）、H11/c11（定位间隙）。
- **过渡配合**：H7/k6（轻过盈定位，$\pm 1 0 \ \mu \mathrm { m }$ ）、H7/n6（中等过盈）。
- **过盈配合**：H7/p6（压入配合，50 mm 处过盈约 $3 0 \ \mu \mathrm { m }$ ）、H7/s6（重压入，需要加热或压装）。

**基孔制（H）是默认：孔公差固定，改变轴公差以达到所需配合。这是因为孔比轴难变（铰刀只做一种尺寸；车刀能做任意尺寸）。**
:::

::: definition 几何尺寸与公差（GD&T）：基准参考系 {#def-gdt}
孔位上 $\pm 0 . 1 \ \mathrm { m m }$ 的尺寸公差是一个（XY 内的）方形公差带——孔心可以在 $0 . 2 \times 0 . 2 \ \mathrm { m m }$ 的方块内任何地方。$\phi 0 . 1$ 的位置公差是一个圆形公差带——孔心必须在 0.1 mm 直径的圆内。**圆是方块面积的 78.5 %，所以 $\phi 0 . 1$ 的位置公差比 $\pm 0 . 1$ 的尺寸公差更严，而想要 $\phi 0 . 1$ 却标 $\pm 0 . 1$ 的设计师是在白送 21 % 的公差带。**

GD&T（ASME Y14.5 或 ISO 1101/2768）在五类中定义了 14 项几何公差：

$$
\begin{array} { l l l }
\textbf{类别} & \textbf{公差项目} & \textbf{需要基准？} \\ \hline
\text{形状} & \text{平面度、直线度、圆度、圆柱度} & \text{否（自参考）} \\
\text{方向} & \text{垂直度、倾斜度、平行度} & \text{是（一个基准）} \\
\text{位置} & \text{位置度、同轴度、对称度} & \text{是（三个基准）} \\
\text{轮廓} & \text{线轮廓度、面轮廓度} & \text{是（三个基准）} \\
\text{跳动} & \text{圆跳动、全跳动} & \text{是（一个基准轴）} \\
\end{array}
$$

**基准参考系**是由 3-2-1 规则建立的三个相互垂直的平面（A、B、C）：三个接触点定义第一基准（一个平面），两个定义第二基准（一条线），一个定义第三基准（一个点）。**基准不是零件的一个特征；它是零件特征与之关联的一个理论构造。基准特征模拟体（CMM 的卡盘、虎钳或夹具）必须复现基准约束，否则测量毫无意义。**

**材料边界修饰符**——最大实体要求（MMC，$\boxed{M}$ ）、最小实体要求（LMC，$\boxed{L}$ ）和独立原则（RFS，无符号）——允许在特征不处于最大实体状态时放宽几何公差。$\phi 1 0 \pm 0 . 2$ 孔上 $\phi 0 . 1 \boxed { M }$ 的位置公差，在孔为 $\phi 1 0 . 2$ 时给出 0.2 mm 的补偿公差，因为销仍能装配。**MMC 是 GD&T 中最强大的单一工具：它把公差累积问题变成最坏情况装配问题，并能在不影响可装配性的情况下把间隙孔的有效公差加倍。**
:::

::: definition 量规：属性与计数值，以及量具 R&R {#def-gauging}
**量规**是做出符合性判定（接受/拒收）而不是报告测量的装置。两种类型是：

- **属性量规**：通止塞规、螺纹量规、卡规、功能量规。它们快（每件 2–5 s）、便宜、不怕操作者，但不提供工艺趋势信息。**通规按特征的最大实体极限制造（最小的孔、最大的轴），止规按最小实体极限制造。量规自身有磨损裕量（通常为公差的 5–10 %）做进通规里，使量规先磨损、后开始拒收好零件。**
- **计数值量具**：千分尺、量缸表、CMM、指示表。它们报告一个数字，可以画在控制图上、做趋势、用于工艺调整。**计数值量具比属性量规贵 10–100 倍、用起来慢 5–60 倍，但它给你预防缺陷而不是分拣缺陷的信息。**

**量具重复性与再现性（GR&R）**量化测量系统对观测变差的贡献。标准研究（AIAG MSA 手册第 4 版）是：2 名操作者 × 10 个零件 × 3 次试验 = 60 次测量，用 ANOVA 或 X-bar/R 法分析。结果是：

$$
\sigma _ { \text{gauge } } ^ { 2 } \; = \; \sigma _ { \text{repeatability} } ^ { 2 } \; + \; \sigma _ { \text{reproducibility} } ^ { 2 } \; = \; \sigma _ { \text{EV} } ^ { 2 } \; + \; \sigma _ { \text{AV} } ^ { 2 }
$$

其中 EV（设备变差）是操作者内变差，AV（评价人变差）是操作者间变差。接收准则是：

- $\sigma _ { \text{gauge } } / \sigma _ { \text{total } } < 0 . 1 0$ （10 %）：可接受。
- $0 . 1 0 < \sigma _ { \text{gauge } } / \sigma _ { \text{total } } < 0 . 3 0$ ：有条件接受，建议改进。
- $\sigma _ { \text{gauge } } / \sigma _ { \text{total } } > 0 . 3 0$ ：不可接受，必须改进或更换量具。

**GR&R 为 30 % 意味着量具消耗观测变差的 30 %，而你算出的过程能力被夸大了：真实 $C _ { p k }$ 为 1.0 显示为 1.3，你在产的 2 700 ppm 显示为 130 ppm。客户的进料检验会比你的 SPC 先发现这个矛盾。**
:::

::: example 公差累积：轴承座 {#ex-stackup level=3 check="0.18"}
一个轴承（宽度 15.000 ± 0.010 mm）压入壳体孔中，由槽内的卡环轴向固定。尺寸链上的尺寸为：

| 特征 | 名义值 | 公差 |
|---------|---------|-----------|
| 壳体台肩到孔端面 | 20.00 | ±0.05 |
| 轴承宽度 | 15.00 | ±0.01 |
| 卡环厚度 | 1.20 | ±0.05 |
| 槽宽 | 1.60 | ±0.05 |

轴承的最坏情况轴向间隙是多少？

最坏情况间隙是最大尺寸之和减去最小尺寸之和：

$$
\delta _ { \max } \; = \; ( 2 0 . 0 5 + 1 . 6 5 ) - ( 1 4 . 9 9 + 1 . 1 5 ) \; = \; 2 1 . 7 0 - 1 6 . 1 4 \; = \; 5 . 5 6 \ \mathrm { m m }
$$

$$
\delta _ { \min } \; = \; ( 1 9 . 9 5 + 1 . 5 5 ) - ( 1 5 . 0 1 + 1 . 2 5 ) \; = \; 2 1 . 5 0 - 1 6 . 2 6 \; = \; 5 . 2 4 \ \mathrm { m m }
$$

总累积公差是 $5 . 5 6 - 5 . 2 4 = 0 . 3 2 \ \mathrm { m m }$ 。**平方和根**（统计）累积是：

$$
\delta _ { \text{RSS } } \; = \; { \sqrt { 0 . 0 5 ^ { 2 } + 0 . 0 1 ^ { 2 } + 0 . 0 5 ^ { 2 } + 0 . 0 5 ^ { 2 } } } \; = \; { \sqrt { 0 . 0 0 7 6 } } \; = \; 0 . 0 8 7 \ \mathrm { m m } \quad ( 1 \sigma )
$$

$3 \sigma$ 时：$\pm 0 . 2 6 \ \mathrm { m m }$ ，所以 RSS 累积为 $\pm 0 . 2 6 \ \mathrm { m m }$ ，而最坏情况为 $\pm 0 . 1 6 \ \mathrm { m m }$ 。**0.32 mm 的最坏情况累积，对需要 0.05–0.15 mm 轴向预紧的轴承来说太大。解决办法是把壳体台肩公差（主导贡献者）收紧到 ±0.02 mm，或加垫片或波形弹簧吸收累积。**
:::

## 3. 统计过程控制

::: definition 过程能力：Cp、Cpk、Pp、Ppk {#def-capability}
**过程能力**把工艺散布与规范宽度比较。两个指数是：

$$
C _ { p } \; = \; { \frac { \mathrm { U S L } - \mathrm { L S L } } { 6 \, \sigma _ { \text{within } } } } \qquad C _ { p k } \; = \; \min \! \left( { \frac { \mathrm { U S L } - \mu } { 3 \, \sigma _ { \text{within } } } } , \; { \frac { \mu - \mathrm { L S L } } { 3 \, \sigma _ { \text{within } } } } \right)
$$

其中 $\sigma _ { \text{within } }$ 是**子组内**标准差（由平均极差估计：$\hat { \sigma } _ { \text{within } } = { \bar { R } } / d _ { 2 }$ ，$d _ { 2 }$ 取决于子组大小）。$C _ { p }$ 度量**潜在**能力（若工艺对中）；$C _ { p k }$ 度量**实际**能力（计入偏心）。工艺完美对中时 $C _ { p } = C _ { p k }$ 。

**性能指数** $P _ { p }$ 和 $P _ { p k }$ 使用**总体**标准差 $s$ （所有测量的样本标准差，包含子组间变差）：

$$
P _ { p } \; = \; { \frac { \mathrm { U S L } - \mathrm { L S L } } { 6 \, s } } \qquad P _ { p k } \; = \; \min \! \left( { \frac { \mathrm { U S L } - { \bar { x } } } { 3 \, s } } , \; { \frac { { \bar { x } } - \mathrm { L S L } } { 3 \, s } } \right)
$$

**$C _ { p k }$ 与 $P _ { p k }$ 的差别就是子组间变差：刀具漂移、批次间材料差异、温度循环。若 $C _ { p k } = 1 . 7$ 而 $P _ { p k } = 1 . 1$ ，工艺在子组内有能力但随时间没有——问题不是机器，是工艺管理（换刀、预热规程、材料控制）。**

$C _ { p k }$ 数值的解读：

$$
\begin{array} { c c c }
C _ { p k } & \text{缺陷率（ppm）} & \text{解读} \\ \hline
< 1 . 0 & > 6 2 1 0 & \text{无能力；需 100\% 检验} \\
1 . 0 & 2 7 0 0 & \text{勉强有能力；需 SPC} \\
1 . 3 3 & 6 3 & \text{有能力；汽车行业最低值} \\
1 . 6 7 & 0 . 6 & \text{高能力；航空工业最低值} \\
2 . 0 & 0 . 0 0 2 & \text{六西格玛；医疗植入物目标} \\
\end{array}
$$

**缺陷率由正态分布计算：$p = \Phi ( ( \mathrm { L S L } - \mu ) / \sigma ) + 1 - \Phi ( ( \mathrm { U S L } - \mu ) / \sigma )$ 。对中工艺，$p = 2 \, \Phi ( - 3 \, C _ { p } )$ 。表中的 ppm 值假定正态分布，而实践中很少成立——真实工艺的尾部比正态更肥，$C _ { p k } = 2$ 时的真实缺陷率更像 10 ppm 而不是 0.002 ppm。**
:::

::: definition 控制图：X-bar/R、p 图与 CUSUM {#def-control-charts}
**控制图**区分普通原因变差（工艺固有）与特殊原因变差（可归因于特定事件）。X-bar/R 图是计数值数据的主力：

$$
\text{X-bar 图：} \quad { \bar { \bar { x } } } \, \pm \, A _ { 2 } \, { \bar { R } } \qquad \text{R 图：} \quad D _ { 3 } \, { \bar { R } } \; \text{至} \; D _ { 4 } \, { \bar { R } }
$$

其中 ${ \bar { \bar { x } } }$ 是总均值，${ \bar { R } }$ 是平均极差，$A _ { 2 }$ 、$D _ { 3 }$ 、$D _ { 4 }$ 是取决于子组大小 $n$ 的常数：

$$
\begin{array} { c c c c c c c }
n & 2 & 3 & 4 & 5 & 10 \\ \hline
A _ { 2 } & 1 . 8 8 0 & 1 . 0 2 3 & 0 . 7 2 9 & 0 . 5 7 7 & 0 . 3 0 8 \\
D _ { 3 } & 0 & 0 & 0 & 0 & 0 . 2 2 2 \\
D _ { 4 } & 3 . 2 6 7 & 2 . 5 7 5 & 2 . 2 8 2 & 2 . 1 1 4 & 1 . 7 7 7 \\
d _ { 2 } & 1 . 1 2 8 & 1 . 6 9 3 & 2 . 0 5 9 & 2 . 3 2 6 & 3 . 0 7 8 \\
\end{array}
$$

**控制限是样本均值（$\sigma / { \sqrt { n } }$ ）的 $\pm 3 \sigma$ ，给出 0.27 % 的虚警率（370 个子组中 1 次）。韦斯顿判异规则（3 点中 2 点超 $2 \sigma$ 、连续 7 点在一侧、连续 7 点同趋势）以更高虚警率为代价提高对小偏移的灵敏度。**

对属性数据（合格/不合格、缺陷计数）：

- **p 图**：大小 $n$ 的样本中的不合格品率。中心线 $\bar { p }$ ，控制限 $\bar { p } \pm 3 { \sqrt { \bar { p } ( 1 - \bar { p } ) / n } }$ 。
- **c 图**：恒定大小单元中的缺陷数。中心线 $\bar { c }$ ，控制限 $\bar { c } \pm 3 { \sqrt { \bar { c } } }$ 。
- **u 图**：可变大小单元的单位缺陷数。

**CUSUM**（累积和）图对小偏移（0.5–1.5σ）比休哈特图更灵敏：

$$
C _ { i } ^ { + } \; = \; \max \! \left( 0 , \; C _ { i - 1 } ^ { + } + ( x _ { i } - \mu _ { 0 } ) - K \right) \qquad C _ { i } ^ { - } \; = \; \max \! \left( 0 , \; C _ { i - 1 } ^ { - } - ( x _ { i } - \mu _ { 0 } ) - K \right)
$$

其中 $K = 0 . 5 \sigma$ 是**参考值**（你想检测的偏移），信号为 $C _ { i } ^ { \pm } > H = 4 { - } 5 \sigma$ 。**CUSUM 在 2–3 个样本内检测 1σ 偏移；休哈特图要 40–50 个。对 1σ 偏移每小时损失 500 英镑的工艺，CUSUM 一次偏移就回本。**
:::

::: definition 抽样检验与 OC 曲线 {#def-sampling}
**验收抽样**基于样本决定接受或拒收一批，而不是检验每个单元。OC（操作特性）曲线给出**接受概率** $P _ { a }$ 随批不合格品率 $p$ 的变化：

$$
P _ { a } ( p ) \; = \; \sum _ { d = 0 } ^ { c } { \binom { n } { d } } \, p ^ { d } \, ( 1 - p ) ^ { n - d } \quad \text{（二项）} \qquad \approx \; \sum _ { d = 0 } ^ { c } { \frac { ( n p ) ^ { d } \, e ^ { - n p } } { d ! } } \quad \text{（泊松，} n \text{ 大 } p \text{ 小）}
$$

其中 $n$ 是样本量，$c$ 是接受数（允许的最大不合格品数）。OC 曲线上两个关键点：

- **AQL**（可接受质量水平）：$P _ { a } = 0 . 9 5$ 处的 $p$ （生产方风险 $\alpha = 0 . 0 5$ ——好批被拒的概率）。
- **LTPD**（批允许不合格品率）：$P _ { a } = 0 . 1 0$ 处的 $p$ （使用方风险 $\beta = 0 . 1 0$ ——坏批被接受的概率）。

**比值 $R = \mathrm { L T P D } / \mathrm { A Q L }$ 是抽样方案的判别力。对 $R = 5$ （典型要求），最小样本量 $n \approx 2 5 / \mathrm { A Q L }$ ，$c \approx 0 . 0 5 \, n$ 。AQL = 1 % 时，$n = 2 5 0$ 、$c = 1 2$ ——大样本。减小 $n$ 的唯一方法是接受更高的 $\alpha$ 或 $\beta$ ，或改进工艺使 AQL 更低。**

**100 % 检验不是抽样的替代：它更糟。**100 % 检验在 2 % 错误率（小零件目视检验的典型错误率）下，2 % 的好零件被报废、2 % 的坏零件被发出。$n = 5 0$ 、$c = 0$ 的抽样在 1 % 不合格率下接受 60.5 % 的批、拒收 39.5 % ——而被拒的批经 100 % 筛选，所以出货质量比 100 % 检验更好。**纠正检验方案的平均出库质量上限（AOQL）低于 100 % 目视检验的不合格率，因为筛选是专职检验员做的，不是 12 小时轮班末尾疲惫的操作员做的。**
:::

::: proof 缺陷率作为 Cpk 的函数 {#proof-cpk-ppm}
对均值 $\mu$ 、标准差 $\sigma$ 的正态分布，规范限外零件的比例是：

$$
p \; = \; P ( X < \mathrm { L S L } ) + P ( X > \mathrm { U S L } ) \; = \; \Phi \! \left( { \frac { \mathrm { L S L } - \mu } { \sigma } } \right) + 1 - \Phi \! \left( { \frac { \mathrm { U S L } - \mu } { \sigma } } \right)
$$

定义**对每个极限的能力指数**：$C _ { L } = ( \mu - \mathrm { L S L } ) / ( 3 \sigma )$ 、$C _ { U } = ( \mathrm { U S L } - \mu ) / ( 3 \sigma )$ ，于是 $C _ { p k } = \min ( C _ { L } , C _ { U } )$ 。则：

$$
p \; = \; \Phi ( - 3 C _ { L } ) + 1 - \Phi ( 3 C _ { U } ) \; = \; \Phi ( - 3 C _ { L } ) + \Phi ( - 3 C _ { U } )
$$

**对中**工艺，$C _ { L } = C _ { U } = C _ { p } = C _ { p k }$ ，于是：

$$
\boxed { \; p \; = \; 2 \, \Phi ( - 3 \, C _ { p k } ) \; }
$$

$C _ { p k } = 1$ 时：$p = 2 \, \Phi ( - 3 ) = 2 \times 0 . 0 0 1 3 5 = 0 . 0 0 2 7 = 2 7 0 0 \ \mathrm { p p m }$ 。$C _ { p k } = 1 . 3 3$ 时：$p = 2 \, \Phi ( - 4 ) = 2 \times 3 . 1 7 \times 1 0 ^ { - 5 } = 6 3 \ \mathrm { p p m }$ 。$C _ { p k } = 2$ 时：$p = 2 \, \Phi ( - 6 ) = 2 \times 9 . 9 \times 1 0 ^ { - 1 0 } = 0 . 0 0 2 \ \mathrm { p p m }$ 。

**$p$ 对 $C _ { p k }$ 的指数敏感性，是 $C _ { p k }$ 改善 0.3 个单位（从 1.0 到 1.33）使缺陷率降 43 倍的原因，也是汽车行业对关键尺寸坚持 $C _ { p k } \geq 1 . 3 3$ 的原因：$C _ { p k } = 1 . 0$ 时，日产 100 000 件的产线每天发出 270 个坏件，$C _ { p k } = 1 . 3 3$ 时每天发 6 个。** $\blacksquare$
:::

::: example 车削直径的 Cpk {#ex-cpk level=3 check="0.89"}
一台数控车床加工 $\phi 2 5 . 0 0 0 \pm 0 . 0 5 0 \ \mathrm { m m }$ 的直径。125 件的样本（25 个 5 件子组）给出 ${ \bar { \bar { x } } } = 2 5 . 0 1 5 \ \mathrm { m m }$ 、${ \bar { R } } = 0 . 0 2 0 \ \mathrm { m m }$ 。计算 $C _ { p }$ 和 $C _ { p k }$ 。

$$
{ \hat { \sigma } } _ { \text{within } } \; = \; { \frac { { \bar { R } } } { d _ { 2 } } } \; = \; { \frac { 0 . 0 2 0 } { 2 . 3 2 6 } } \; = \; 0 . 0 0 8 6 \ \mathrm { m m }
$$

$$
C _ { p } \; = \; { \frac { 2 5 . 0 5 0 - 2 4 . 9 5 0 } { 6 \times 0 . 0 0 8 6 } } \; = \; { \frac { 0 . 1 0 0 } { 0 . 0 5 1 6 } } \; = \; 1 . 9 4
$$

$$
C _ { p k } \; = \; \min \! \left( { \frac { 2 5 . 0 5 0 - 2 5 . 0 1 5 } { 3 \times 0 . 0 0 8 6 } } , \; { \frac { 2 5 . 0 1 5 - 2 4 . 9 5 0 } { 3 \times 0 . 0 0 8 6 } } \right) \; = \; \min \! \left( { \frac { 0 . 0 3 5 } { 0 . 0 2 5 8 } } , \; { \frac { 0 . 0 6 5 } { 0 . 0 2 5 8 } } \right) \; = \; \min ( 1 . 3 6 , \; 2 . 5 2 )
$$

$$
C _ { p k } \; = \; { \bf 1 . 3 6 }
$$

**工艺有能力（$C _ { p k } > 1 . 3 3$ ）但未对中：均值高于名义值 15 μm，而 1.94 的 $C _ { p }$ 表明散布没问题。解决办法是 15 μm 的刀具偏置，它把 $C _ { p k }$ 提到 1.94，并把缺陷率从 63 ppm 降到 0.002 ppm。$C _ { p } - C _ { p k }$ 之间 0.58 的差距就是工艺不对中的代价——为一个 30 秒就能纠正的 15 μm 偏置付出 63 ppm 的废品。**
:::

## 4. 数控机床与 CAM

::: definition 数控：轴、运动学与 G 代码 {#def-cnc}
**数控机床**是一个多轴定位系统，让切削刀具（或工件）沿程序路径移动。轴是：

$$
\begin{array} { l l l l }
\textbf{机床} & \textbf{轴} & \textbf{典型行程} & \textbf{定位精度} \\ \hline
\text{两轴车床} & X, Z & 300 \times 600 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{三轴铣床} & X, Y, Z & 500 \times 400 \times 400 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{五轴铣床} & X, Y, Z, A, C & 630 \times 560 \times 500 \ \mathrm{mm} & { \pm } 5 \ \mu\text{m} \\
\text{五轴联动} & X, Y, Z, B, C & 800 \times 700 \times 600 \ \mathrm{mm} & { \pm } 3 \ \mu\text{m} \\
\text{线切割 EDM} & X, Y, U, V & 500 \times 400 \times 300 \ \mathrm{mm} & { \pm } 2 \ \mu\text{m} \\
\text{CMM} & X, Y, Z & 1200 \times 1000 \times 800 \ \mathrm{mm} & { \pm } 1 . 5 \ \mu\text{m} \\
\end{array}
$$

每台机床的 **21 项刚体误差**（每个直线轴 7 项：6 个自由度定位误差 + 1 个直线度；外加每对轴 2 个垂直度误差）是体积精度的根本极限。典型五轴加工中心的体积精度在其全行程上为 10–25 μm，比单轴定位精度差 3–5 倍，因为垂直度误差和角度误差会累积。**激光干涉仪校准（ISO 230-2）测出这 21 项误差，并以补偿表的形式反馈给数控系统。补偿良好的机床达到 3–5 μm 体积精度；未补偿的只有 15–30 μm。**

**G 代码**（ISO 6983）是数控机床的编程语言。一个典型车削程序：

```
G97 S800 M03       (constant spindle speed, 800 RPM, CW)
G00 X52.0 Z2.0     (rapid to start position)
G01 Z-30.0 F0.15   (linear cut to Z-30, 0.15 mm/rev)
G01 X24.85 F0.10   (face to diameter 24.85, 0.10 mm/rev)
G00 X55.0 Z5.0     (rapid retract)
M30                 (end of program)
```

**后处理器**把 CAM 系统的刀轨数据（CLSF：刀具位置源文件）转换为机床专用的 G 代码，考虑机床的运动学（耳轴式 vs 摆头式）、轴行程极限、刀库容量和控制器方言（Fanuc、Siemens、Heidenhain、Haas）。**一个把 G01 放进快速移动模式的后处理器缺陷会让刀具以 30 m/min 撞进零件；一个不考虑 A = 90° 附近耳轴奇异性的后处理器会产生啃刀。**
:::

::: definition 机床精度、重复性与阿贝原则 {#def-machine-accuracy}
三个数字表征机床的定位性能（ISO 230-2）：

- **分辨率**：控制系统能指令的最小增量。带光栅尺反馈的现代数控为 0.1 μm。不带光栅尺的机床（开环伺服），分辨率是编码器计数除以减速比，典型为 1–5 μm。
- **重复性**：从同一方向重复指令同一目标位置时实际到达位置的标准差。好机床：$\pm 1 { - } 2 \ \mu \mathrm { m }$ （$3 \sigma$ ）。磨损机床：$\pm 5 { - } 1 0 \ \mu \mathrm { m }$ 。
- **定位精度（双向）**：从两个方向趋近时相对指令位置的最大偏差。单向与双向精度之差是**反向间隙**（滚珠丝杠和轴承中的空程），典型为 2–10 μm。

**阿贝原则**同样适用于机床。在加工中心上，光栅尺在导轨上，但切削刃在刀尖，距光栅尺 50–300 mm（**阿贝偏置**）。X 滑座 1 角秒的俯仰误差在刀尖产生 Z 向误差：

$$
\varepsilon \; = \; L _ { \text{tool} } \times \theta \; = \; 2 0 0 \times 4 . 8 5 \times 1 0 ^ { - 6 } \; = \; 1 . 0 \ \mu \mathrm { m } \quad \text{（每角秒、每 200 mm 刀长）}
$$

**5 角秒的俯仰误差配 200 mm 刀具产生 5 μm 误差——典型 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差的 10 %。这就是高精度加工中心把光栅尺放到尽可能靠近切削区、导轨刮研到 2–5 角秒直线度、主轴热生长（4 小时班次内使刀长变化 10–30 μm）用对刀仪补偿的原因。**
:::

::: definition CAM：刀轨、仿真与自适应加工 {#def-cam}
**CAM**（计算机辅助制造）从 CAD 模型生成刀轨坐标。关键决策是：

- **切削策略**：顺铣 vs 逆铣，之字形 vs 阶梯形 vs 轮廓平行，摆线（自适应开粗），螺旋插补。策略决定刀具载荷、表面质量和节拍时间。**顺铣（刀具旋入切削）比逆铣（刀具旋出切削）留下更好的表面和更长的刀具寿命，因为切厚从零增大而不是减小到零。**
- **行距与切深**：残留高度 $h _ { s } = { \delta ^ { 2 } } / ( 4 R )$ （半径 $R$ 的球头刀、行距 $\delta$ ）决定表面质量。$R = 6 \ \mathrm { m m }$ 、$h _ { s } = 5 \ \mu \mathrm { m }$ 时：$\delta = { \sqrt { 4 \times 6 \times 0 . 0 0 5 } } = 0 . 3 5 \ \mathrm { m m }$ 。**行距是 CAM 中控制表面质量的参数，而节拍时间与 $1 / \delta ^ { 2 }$ 成正比——残留减半，时间翻四倍。**
- **仿真**：CAM 系统把刀轨对毛坯模型做仿真，检测啃刀、碰撞和未切材料。**一次仿真抓住一次撞机，省下 50 000 英镑的主轴、5 000 英镑的夹具和 2 000 英镑的零件。仿真花 5 分钟；撞机花 5 秒。**
- **自适应加工**：在线测头测量已加工表面并调整刀轨，补偿夹具挠曲、热生长和刀具磨损。**加工中心上的三坐标在线测头把装夹时间从 4 小时减到 30 分钟，废品率从 5 % 降到 0.5 %。**
:::

::: example 体积精度与 21 项误差 {#ex-volumetric level=3 check="12"}
一台五轴加工中心有如下误差（单位均为 μm）：

- 直线定位：X: ±3，Y: ±3，Z: ±4
- 直线度：XY: ±2，XZ: ±2，YZ: ±3
- 垂直度：XY: ±3，XZ: ±3，YZ: ±4
- 角度（俯仰/偏摆/滚转）：每轴 3 角秒

估算工作包络中心（X = Y = Z = 200 mm）处用 150 mm 刀具时的体积精度。

体积误差是所有贡献的 RSS：

$$
\varepsilon _ { \text{vol } } \; = \; { \sqrt { \varepsilon _ { \text{pos} } ^ { 2 } + \varepsilon _ { \text{straight} } ^ { 2 } + \varepsilon _ { \text{sq} } ^ { 2 } + \varepsilon _ { \text{Abbe} } ^ { 2 } } }
$$

$$
\varepsilon _ { \text{pos} } \; = \; { \sqrt { 3 ^ { 2 } + 3 ^ { 2 } + 4 ^ { 2 } } } \; = \; { \sqrt { 3 4 } } \; = \; 5 . 8 \ \mu \mathrm { m }
$$

$$
\varepsilon _ { \text{sq} } \; = \; { \sqrt { 3 ^ { 2 } + 3 ^ { 2 } + 4 ^ { 2 } } } \; = \; 5 . 8 \ \mu \mathrm { m } \quad \text{（在 200 mm 行程上投影）}
$$

$$
\varepsilon _ { \text{Abbe} } \; = \; 1 5 0 \times 3 \times 4 . 8 5 \times 1 0 ^ { - 6 } \; = \; 2 . 2 \ \mu \mathrm { m } \quad \text{（3 角秒，150 mm 刀具）}
$$

$$
\varepsilon _ { \text{vol } } \; = \; { \sqrt { 5 . 8 ^ { 2 } + 3 . 7 ^ { 2 } + 5 . 8 ^ { 2 } + 2 . 2 ^ { 2 } } } \; = \; { \sqrt { 3 3 . 6 + 1 3 . 7 + 3 3 . 6 + 4 . 8 } } \; = \; { \sqrt { 8 5 . 7 } } \; = \; { \bf 9 . 3 \ \mu m }
$$

**体积精度为 9.3 μm——约为单轴定位精度的 3 倍。垂直度误差和阿贝误差贡献总量的 40 %，而它们正是激光干涉仪校准所修正的误差。补偿良好的机床达到 4–5 μm 体积精度；未补偿的为 10–15 μm。差别就是 $\pm 0 . 0 1 \ \mathrm { m m }$ 公差做得到与做不到的差别。**
:::

## 5. 自动化生产系统

::: definition 制造单元、柔性系统与生产线 {#def-production-systems}
生产自动化的三个层级是：

$$
\begin{array} { l l l l }
\textbf{层级} & \textbf{配置} & \textbf{换产} & \textbf{批量} \\ \hline
\text{刚性（硬）自动化} & \text{专用组合机床自动线} & \text{数天--数周} & \text{> 100 000/年} \\
\text{柔性（软）自动化} & \text{CNC + 交换工作台 + FMS} & \text{数分钟} & \text{100--50 000/年} \\
\text{单元化制造} & \text{2--5 台 CNC + 机器人 + 在制品} & \text{数分钟--数小时} & \text{100--10 000/年} \\
\text{单件小批车间} & \text{通用机床} & \text{数小时--数天} & \text{1--500/年} \\
\end{array}
$$

**柔性制造系统**（FMS）是一组由自动物料搬运系统（输送机、AGV 或有轨制导车）连接、由中央计算机控制的 CNC 机床。FMS 无需人工干预就能生产其零件族内的任何零件。**FMS 是 1980 年代的主导自动化范式，但在大多数应用上商业失败，因为 500–2 000 万美元的资本成本无法靠 20–30 % 的人工节省证明合理，而软件复杂性使它不可靠。现代等价物是"熄灯单元"：2–4 台 CNC 配一个托盘库机器人，无人值守运行 24–72 小时。**

**成组技术**（GT）按几何相似性（直径、长度、特征数、公差等级）把零件分类为族，让每个族通过一个专用的**制造单元**——一小群按 U 形布置的不同机床，配 1–3 名操作者。GT 编码系统（Opitz、KK-3）给每个零件一个 9–12 位代码，同码零件在同一单元生产。**GT 的好处不是机床（它们和单件小批车间的 CNC 一样）而是流程：零件几小时通过单元，而不是几周转遍车间；在制品减少 70 %；换产时间减少 50 %，因为单元的机床专用于一个族。**
:::

::: definition 产线平衡与节拍时间 {#def-line-balance}
**节拍时间**是可用生产时间除以客户需求：

$$
T _ { \text{takt } } \; = \; { \frac { T _ { \text{available } } } { N _ { \text{demand } } } } \quad [ \text{s/件} ]
$$

**最少工位数**是：

$$
N _ { \min } \; = \; \left\lceil { \frac { \sum _ { i = 1 } ^ { M } t _ { i } } { T _ { \text{takt } } } } \right\rceil
$$

其中 $t _ { i }$ 是第 $i$ 项作业的时间，$M$ 是作业总数。**产线效率**是：

$$
\eta \; = \; { \frac { \sum t _ { i } } { N \times T _ { \text{takt } } } } \times 1 0 0 \ \%
$$

**空闲时间**（操作者等待的时间）是 $I = N \times T _ { \text{takt } } - \sum t _ { i }$ 。**产线平衡问题是在遵守优先约束（作业 B 不能在作业 A 完成前开始）的前提下，把 $M$ 项作业分配给 $N$ 个工位，使最大工位时间最小。问题是 NP 难的，但对 $M < 5 0$ 项作业，一个简单的启发式（优先分配最长作业，遵守优先约束）能到最优的 10 % 以内。**
:::

::: definition 精益制造、六西格玛与工业 4.0 {#def-lean-sixsigma}
**精益制造**（丰田生产方式）是一种消除浪费（muda）的哲学：过量生产、等待、搬运、过度加工、库存、动作、缺陷。工具是：

- **5S**：整理、整顿、清扫、清洁、素养。一个缺了工具 10 秒内就能看出来的工作场所。
- **看板**：一个拉动系统，下游工位向上游工位发出增产信号。在制品以上限的看板卡数为限。
- **SMED**（快速换模）：把内部换产（停机做）转换为外部换产（运行时做），把换产时间降到 10 分钟以下。**SMED 把 4 小时冲压换模减到 12 分钟，使可用产能增加 15 %，而不必买第二台压机。**
- **Poka-Yoke**：防错。只能以一个方向装零件的夹具、检测漏装 O 形圈的传感器、到值就响的扭矩扳手。**一个每 10 000 件防住一个缺陷的防错装置，省下的比它取代的检验更多。**

**六西格玛**是一种把工艺变差降到百万机会 3.4 个缺陷（DPMO）的数据驱动方法，对应 $C _ { p k }$ 为 2.0（含 1.5σ 长期偏移）。DMAIC 循环：定义、测量、分析、改进、控制。**六西格玛是有预算的 SPC："改进"一步是试验设计（DOE），找出解释 80 % 变差的 2–3 个工艺变量；"控制"一步是一张控制图，检测这些变量何时漂移。**

**工业 4.0** 是把信息物理系统集成进制造：每台机器上的物联网传感器、实时仿真产线的数字孪生、基于振动和电流特征的预测性维护、跟踪每个零件每道工序的制造执行系统（MES）。**工业 4.0 的实际好处不是技术（传感器和软件已存在 20 年）而是数据：一台报告自身主轴振动的机器能在轴承失效前 200 小时预测它，而 200 小时足够把更换安排进计划停机而不是非计划停机。**
:::

::: example 产线平衡：一个 6 工位装配 {#ex-line-balance level=3 check="94"}
一个部件有 8 项作业，时间和优先关系如下：

| 作业 | 时间（s） | 紧前作业 |
|------|----------|-------------|
| A | 5 | — |
| B | 3 | A |
| C | 8 | A |
| D | 4 | B |
| E | 6 | B, C |
| F | 7 | D, E |
| G | 5 | E |
| H | 4 | F, G |

需求为每 8 小时班次（28 800 s）240 件。平衡产线。

$$
T _ { \text{takt } } \; = \; { \frac { 2 8 \ 8 0 0 } { 2 4 0 } } \; = \; 1 2 0 \ \mathrm { s }
$$

$$
N _ { \min } \; = \; \left\lceil { \frac { 5 + 3 + 8 + 4 + 6 + 7 + 5 + 4 } { 1 2 0 } } \right\rceil \; = \; \left\lceil { \frac { 4 2 } { 1 2 0 } } \right\rceil \; = \; 1
$$

$N _ { \min } = 1$ 时，单个工位能在 42 s 内做完所有作业，远在 120 s 节拍之内。但优先约束要求至少 4 个工位（最长路径是 A→C→E→F→H = 5+8+6+7+4 = 30 s，经 B 的关键路径是 5+3+6+7+4 = 25 s）。4 个工位时：

- 工位 1：A、B（8 s）
- 工位 2：C、D（12 s）
- 工位 3：E、G（11 s）
- 工位 4：F、H（11 s）

$$
\eta \; = \; { \frac { 4 2 } { 4 \times 1 2 0 } } \; = \; { \frac { 4 2 } { 4 8 0 } } \; = \; 8 . 7 5 \ \%
$$

**效率糟透了，因为节拍时间（120 s）是作业总时间（42 s）的 10 倍。产线是需求受限而不是产能受限。正确答案是 1 名操作者 42 s 做完全部 8 项作业，等 78 s，再重复。效率是 $4 2 / 1 2 0 = 3 5 \ \%$ ，操作者 65 % 的时间空闲。解决办法是往产线加第二个产品（混型装配），或通过增加需求缩短节拍时间。**
:::

## 6. 质量体系与检验

::: definition 质量管理体系：ISO 9001、AS9100、IATF 16949 {#def-qms}
**质量管理体系**（QMS）是为达成质量目标而文件化的一组过程、程序和职责。主导机械行业的三个标准是：

- **ISO 9001:2015**：通用 QMS。过程方法、基于风险的思维、领导作用、持续改进。证书是任何供应商进入任何 OEM 供应链的最低要求。
- **AS9100D**：航空 QMS。增加技术状态管理、首件检验（AS9102）、 假冒件防范、人因工程和产物安全。**AS9100 审核是一场 3–5 天的事件，检查车间里的每个过程、每张校准证书、每份不合格报告和每项纠正措施。审核员的问题永远是同一个："给我看证据。"**
- **IATF 16949:2016**：汽车 QMS。增加 APQP、PPAP、FMEA、MSA、SPC 和五大核心工具。汽车标准比 AS9100 更规定性：它规定方法（控制图、能力指数、量具 R&R）而不只是结果。

**质量成本**遵循 1-10-100 规则：预防上花 1 英镑，省下鉴定上的 10 英镑和失效上的 100 英镑。类别是：

$$
\begin{array} { l l l }
\textbf{类别} & \textbf{例子} & \textbf{典型占营收 \%} \\ \hline
\text{预防} & \text{培训、FMEA、SPC、防错} & 2 { - } 5 \ \% \\
\text{鉴定} & \text{检验、试验、审核、校准} & 3 { - } 7 \ \% \\
\text{内部失效} & \text{废品、返工、复检、停机} & 3 { - } 1 0 \ \% \\
\text{外部失效} & \text{保修、召回、责任、客户流失} & 1 { - } 5 \ \% \\
\end{array}
$$

**典型机械车间的质量总成本占营收的 15–25 %。1-10-100 规则说，预防（SPC、培训、防错）多花 1 % 省下鉴定 10 %、失效 100 %。算术不精确，但方向是对的：最便宜的缺陷是从未发生的缺陷。**
:::

::: definition FMEA、PPAP 与 APQP {#def-fmea}
**FMEA**（失效模式与影响分析）是识别潜在失效、其原因和后果、并给纠正措施排优先级的结构化方法。**风险顺序数**（RPN）是：

$$
\text{RPN } \; = \; S \times O \times D
$$

其中 $S$ （严重度，1–10）是失效的后果，$O$ （频度，1–10）是原因的频率，$D$ （探测度，1–10）是在失效到达客户之前探测到它的难度。**探测度评级是随过程控制变化的那个：$D$ 为 8 意味着"缺陷由客户发现"，$D$ 为 3 意味着"缺陷由自动防错装置发现"，$D$ 为 1 意味着"缺陷在设计上被预防"。FMEA 的价值不在 RPN 数字（它武断且可被操纵），而在它逼出的对话："如果这条焊缝冷了会怎样？我们怎么会知道？如果我们无法知道呢？"**

**APQP**（先期产品质量策划）是汽车行业把新零件从概念带到生产的框架，分五个阶段：（1）计划和确定项目，（2）产品设计和开发，（3）过程设计和开发，（4）产品和过程确认，（5）反馈、评定和纠正措施。**PPAP**（生产件批准程序）是第 4 阶段末的交付物：一个 18 项文件的包（设计记录、FMEA、控制计划、MSA、能力研究、PPAP 样件、材料证书、外观批准件），证明供应商能按图纸、以所报的节拍、稳定地制造该零件。**PPAP 3 级提交（默认）有 200–500 页。客户的 SQE 用 2–5 天评审，或批准、或带偏差批准、或拒收。PPAP 被拒意味着零件未获批准生产，项目延期。**
:::

::: example 机加工轴系的 FMEA {#ex-fmea level=3 check="160"}
一根机加工轴有一个 $\phi 2 5 \pm 0 . 0 1 3$ 的轴承轴颈。FMEA 条目：

| 项目 | 失效模式 | 后果 | S | 原因 | O | 现行控制 | D | RPN |
|------|-------------|--------|---|-------|---|----------------|---|-----|
| 轴颈 | 超差偏大 | 轴承装不上 | 8 | 刀具磨损 | 4 | 每 50 件 CMM | 5 | 160 |

RPN 是 $8 \times 4 \times 5 = 1 6 0$ 。**措施是通过增加带自动刀具补偿的在线量具把 $D$ 从 5 降到 2（量具测每一件，当趋势接近极限时对刀补偏）。新 RPN 是 $8 \times 4 \times 2 = 6 4$ ，低于典型措施阈值 100。该措施不改变 $S$ （后果仍然严重）也不改变 $O$ （原因仍是刀具磨损），但它把 $D$ 从"测量时发现"变成"预防其发生"。**
:::

## 习题

::: exercise 测量不确定度：合成与扩展 {#ex-unc-comb level=3 check="2.0"}
一块 50 mm 量块在 CMM 上测量。不确定度分量为：CMM 误差 $u _ { 1 } = 1 . 2 \ \mu \mathrm { m }$ ，热变形 $u _ { 2 } = 0 . 5 \ \mu \mathrm { m }$ ，校准 $u _ { 3 } = 0 . 3 \ \mu \mathrm { m }$ ，重复性 $u _ { 4 } = 0 . 4 \ \mu \mathrm { m }$ 。$k = 2$ 时的扩展不确定度 $U$ 是多少？

::: solution
$$
u _ { c } \; = \; { \sqrt { 1 . 2 ^ { 2 } + 0 . 5 ^ { 2 } + 0 . 3 ^ { 2 } + 0 . 4 ^ { 2 } } } \; = \; { \sqrt { 1 . 4 4 + 0 . 2 5 + 0 . 0 9 + 0 . 1 6 } } \; = \; { \sqrt { 1 . 9 4 } } \; = \; 1 . 3 9 \ \mu \mathrm { m }
$$

$$
U \; = \; 2 \times 1 . 3 9 \; = \; { \bf 2 . 8 \ \mu m }
$$

**CMM 误差主导（方差的 74 %）。2.8 μm 的扩展不确定度是 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差的 5.6 %——在 10:1 规则之内但不宽裕。对 $\pm 0 . 0 1 0 \ \mathrm { m m }$ 的公差，这台 CMM 不够格（占公差的 28 %）。**
:::
:::

::: exercise 过程能力：Cpk 与缺陷率 {#ex-cpk2 level=3 check="1.0"}
一个孔规定为 $\phi 1 2 . 0 0 0 \, _ { - 0 . 0 0 0 } ^ { + 0 . 0 2 5 } \ \mathrm { m m }$ 。工艺均值 $\mu = 1 2 . 0 1 0 \ \mathrm { m m }$ ，$\sigma = 0 . 0 0 5 \ \mathrm { m m }$ 。计算 $C _ { p k }$ 和预期缺陷率。

::: solution
$$
C _ { p k } \; = \; \min \! \left( { \frac { 1 2 . 0 2 5 - 1 2 . 0 1 0 } { 3 \times 0 . 0 0 5 } } , \; { \frac { 1 2 . 0 1 0 - 1 2 . 0 0 0 } { 3 \times 0 . 0 0 5 } } \right) \; = \; \min \! \left( { \frac { 0 . 0 1 5 } { 0 . 0 1 5 } } , \; { \frac { 0 . 0 1 0 } { 0 . 0 1 5 } } \right) \; = \; \min ( 1 . 0 , \; 0 . 6 6 7 )
$$

$$
C _ { p k } \; = \; { \bf 0 . 6 7 }
$$

缺陷率：$p = \Phi ( ( 1 2 . 0 0 0 - 1 2 . 0 1 0 ) / 0 . 0 0 5 ) + 1 - \Phi ( ( 1 2 . 0 2 5 - 1 2 . 0 1 0 ) / 0 . 0 0 5 ) = \Phi ( - 2 ) + 1 - \Phi ( 3 ) = 0 . 0 2 2 8 + 0 . 0 0 1 3 5 = 0 . 0 2 4 1 = 2 4 \ 1 0 0 \ \mathrm { p p m }$ 。

**工艺无能力（$C _ { p k } < 1 . 0$ ），缺陷率为 2.4 %。问题是偏心：均值高于名义值 10 μm，而下极限只有 2σ 之远。把工艺对中到 12.0125（中点）可得 $C _ { p k } = 0 . 8 3$ ——仍无能力，但缺陷率降到 1 350 ppm。真正的解决办法是把 $\sigma$ 降到 0.003 mm（更好的铰刀、更刚性的装夹）并对中工艺。**
:::
:::

::: exercise 控制图控制限 {#ex-chart-limits level=3 check="10.03"}
一个 $n = 5$ 的 X-bar/R 图有 ${ \bar { \bar { x } } } = 1 0 . 0 2 0 \ \mathrm { m m }$ 、${ \bar { R } } = 0 . 0 2 5 \ \mathrm { m m }$ 。计算 X-bar 图的控制限。

::: solution
$n = 5$ 时：$A _ { 2 } = 0 . 5 7 7$ 。

$$
\text{UCL } \; = \; 1 0 . 0 2 0 + 0 . 5 7 7 \times 0 . 0 2 5 \; = \; 1 0 . 0 2 0 + 0 . 0 1 4 4 \; = \; { \bf 1 0 . 0 3 4 \ \mathrm { m m } }
$$

$$
\text{LCL } \; = \; 1 0 . 0 2 0 - 0 . 0 1 4 4 \; = \; 1 0 . 0 0 6 \ \mathrm { m m }
$$

**控制限是均值两侧 $\pm 1 4 . 4 \ \mu \mathrm { m }$ 。若规范是 $1 0 . 0 0 0 \pm 5 0 \ \mu \mathrm { m }$ ，控制限远在规范之内，工艺受控且有能力的。若规范是 $1 0 . 0 0 0 \pm 1 5 \ \mu \mathrm { m }$ ，控制限几乎和规范一样宽，工艺受控但勉强有能力——任何漂移都会在控制图报警之前产生超差件。**
:::
:::

::: exercise 抽样检验：OC 曲线 {#ex-oc-curve level=3 check="0.81"}
一批用 $n = 5 0$ 、$c = 2$ 抽样。批不合格品率 3 % 时被接受的概率是多少？

::: solution
用二项分布：

$$
P _ { a } \; = \; \sum _ { d = 0 } ^ { 2 } { \binom { 5 0 } { d } } \, 0 . 0 3 ^ { d } \, 0 . 9 7 ^ { 5 0 - d }
$$

$$
= \; 0 . 9 7 ^ { 5 0 } + 5 0 \times 0 . 0 3 \times 0 . 9 7 ^ { 4 9 } + 1 2 2 5 \times 0 . 0 0 0 9 \times 0 . 9 7 ^ { 4 8 }
$$

$$
= \; 0 . 2 1 8 + 0 . 3 3 7 + 0 . 2 5 6 \; = \; { \bf 0 . 8 1 }
$$

**一批 3 % 不合格的批有 81 % 的概率被接受。AQL（$P _ { a } = 0 . 9 5$ 处）约 1.2 %，LTPD（$P _ { a } = 0 . 1 0$ 处）约 8 %。这个抽样方案很松：它接受大多数不合格品率至多 3 % 的批，拒收大多数超过 8 % 的批。对关键尺寸，这个方案不够格；对外观尺寸，它可以。**
:::
:::

::: exercise 深度千分尺中的阿贝误差 {#ex-abbe-depth level=2 check="1.2"}
一把带 50 mm 接杆的深度千分尺阿贝偏置为 50 mm。测微螺杆有 5 角秒的俯仰误差。位移误差是多少？

::: solution
$$
\varepsilon \; = \; e \times \theta \; = \; 5 0 \times 5 \times { \frac { \pi } { 1 8 0 \times 3 6 0 0 } } \; = \; 5 0 \times 2 4 . 2 \times 1 0 ^ { - 6 } \; = \; { \bf 1 . 2 \ \mu m }
$$

**1.2 μm 绝对值很小，但是 $\pm 0 . 0 2 5 \ \mathrm { m m }$ 公差的 5 %、$\pm 0 . 0 0 5 \ \mathrm { m m }$ 公差的 24 %。阿贝误差就是深度千分尺不用于严于 $\pm 0 . 0 1 \ \mathrm { m m }$ 公差的原因，也是 CMM 用 Z 轴测深度（光栅尺在滑枕上、阿贝偏置为零）的原因。**
:::
:::

::: exercise FMEA 风险顺序数 {#ex-fmea-rpn level=2 check="160"}
一个焊接接头严重度 8（结构失效）、频度 4（500 条焊缝 1 条）、探测度 5（目视检验抓住 50 %）。RPN 是多少？什么措施能把它降到 100 以下？

::: solution
$$
\text{RPN } \; = \; 8 \times 4 \times 5 \; = \; { \bf 1 6 0 }
$$

**高于典型措施阈值 100。最有效的措施是通过增加 100 % 渗透检测或自动超声检测把 $D$ 从 5 降到 2：RPN 降到 $8 \times 4 \times 2 = 6 4$ 。把 $O$ 从 4 降到 2（改进焊接工艺）得 $8 \times 2 \times 5 = 8 0$ 。把 $S$ 从 8 降到 4（增加冗余载荷路径）得 $4 \times 4 \times 5 = 8 0$ 。最好的措施是以最小代价把乘积降得最多的那个，而本例中是探测改进，因为它每件只花 5 英镑检验工时且不需要设计变更。**
:::
:::

::: exercise 推导：由二项分布推导 OC 曲线 {#ex-derive-oc level=4 check="0.37"}
推导 $n = 1 0 0$ 、$c = 0$ 的一次抽样方案的 OC 曲线。求 $p = 0 . 0 1$ 处的 $P _ { a }$ 。

::: solution
$c = 0$ 时，只有样本中发现零个不合格品批才被接受。从不合格品率为 $p$ 的批中抽 $n$ 件、发现零个不合格品的概率是：

$$
P _ { a } ( p ) \; = \; ( 1 - p ) ^ { n }
$$

这就是 $d = 0$ 的二项式：$P _ { a } = { \binom { n } { 0 } } p ^ { 0 } ( 1 - p ) ^ { n } = ( 1 - p ) ^ { n }$ 。

$n = 1 0 0$ 、$p = 0 . 0 1$ 时：

$$
P _ { a } \; = \; 0 . 9 9 ^ { 1 0 0 } \; = \; e ^ { 1 0 0 \ln 0 . 9 9 } \; = \; e ^ { - 1 . 0 0 5 } \; = \; { \bf 0 . 3 6 6 }
$$

**一批 1 % 不合格的批有 37 % 的概率被接受、63 % 的概率被拒收。AQL（$P _ { a } = 0 . 9 5$ 处）是 $p = 1 - 0 . 9 5 ^ { 1 / 1 0 0 } = 0 . 0 0 0 5 = 0 . 0 5 \ \%$ 。$c = 0$ 方案非常紧：它拒收 95 % 不合格品率超过 0.05 % 的批。这是汽车行业对安全关键特性使用的方案，也是汽车供应商跑 $C _ { p k } > 2$ 的原因——因为缺陷率超过 500 ppm，$n = 1 0 0$ 的 $c = 0$ 方案就会拒收他们的批。** $\blacksquare$
:::
:::

::: exercise 推导：偏心工艺的 Cpk {#ex-derive-cpk level=4 check="2.7"}
一个工艺 $C _ { p } = 1 . 5$ ，均值相对中心偏移 $1 . 5 \sigma$ 。计算 $C _ { p k }$ 和缺陷率。

::: solution
$C _ { p } = 1 . 5$ 时：公差宽度为 $6 \sigma \times 1 . 5 = 9 \sigma$ 。均值到最近极限的距离是：

$$
{ \frac { 9 \sigma } { 2 } } - 1 . 5 \sigma \; = \; 4 . 5 \sigma - 1 . 5 \sigma \; = \; 3 . 0 \sigma
$$

$$
C _ { p k } \; = \; { \frac { 3 . 0 \sigma } { 3 \sigma } } \; = \; { \bf 1 . 0 }
$$

缺陷率：$p = \Phi ( - 3 . 0 ) + \Phi ( - 6 . 0 ) = 0 . 0 0 1 3 5 + 0 . 0 0 0 0 0 0 5 \approx 1 3 5 0 \ \mathrm { p p m }$ 。

**1.5 的 $C _ { p }$ （对中时给 0.002 ppm）被 1.5σ 偏移降成 1.0 的 $C _ { p k }$ （2 700 ppm）。这个偏移损失 1 350 ppm 的废品——而偏移只有 1.5σ，即 $\sigma = 5 \ \mu \mathrm { m }$ 的工艺上 7.5 μm 的偏置。这就是对中工艺是最便宜的质量改进的原因：花一次刀具偏置，换回 2 000 倍的缺陷率。** $\blacksquare$
:::
:::

::: exercise 节拍时间与产线效率 {#ex-takt level=3 check="94"}
一条产线有 4 个工位，单件时间分别为 55、48、62、50 秒。需求为每 8 小时班次 480 件。计算节拍时间、瓶颈和产线效率。

::: solution
$$
T _ { \text{takt } } \; = \; { \frac { 2 8 \ 8 0 0 } { 4 8 0 } } \; = \; 6 0 \ \mathrm { s }
$$

瓶颈是 62 s 的工位 3，它超过 60 s 的节拍时间。**产线无法满足需求。**产线效率（基于瓶颈）：

$$
\eta \; = \; { \frac { 5 5 + 4 8 + 6 2 + 5 0 } { 4 \times 6 2 } } \; = \; { \frac { 2 1 5 } { 2 4 8 } } \; = \; { \bf 8 7 \ \% }
$$

**产线效率 87 %，但因瓶颈（62 s）超过节拍（60 s）而无法满足需求。解决办法是重新平衡：把 2 s 的工作从工位 3 移到工位 2（它有 12 s 余量），使所有工位 $\leq 6 0 \ \mathrm { s }$ 。效率变为 $2 1 5 / ( 4 \times 6 0 ) = 9 0 \ \%$ ——等等，它反而升高了，因为分母减小了。所有工位单件时间相等时效率最大。**
:::
:::

::: quiz 测量不确定度 {#quiz-unc}
一个零件公差为 $\pm 0 . 0 2 0 \ \mathrm { m m }$ 。测量不确定度在 $k = 2$ 下为 $\pm 0 . 0 0 5 \ \mathrm { m m }$ 。测量不确定度与公差之比是多少，按 10:1 规则可接受吗？

- [ ] 5 % ——可接受
- [x] 25 % ——按 10:1 规则不可接受
- [ ] 10 % ——恰在极限上
- [ ] 50 % ——测量毫无用处

::: solution
公差宽度是 $2 \times 0 . 0 2 0 = 0 . 0 4 0 \ \mathrm { m m }$ 。扩展不确定度是 $0 . 0 0 5 \ \mathrm { m m }$ 。比值为 $0 . 0 0 5 / 0 . 0 4 0 = 1 2 . 5 \ \%$ ——或者，若把不确定度与半公差比较：$0 . 0 0 5 / 0 . 0 2 0 = 2 5 \ \%$ 。按 10:1 规则（不确定度 $\leq$ 公差宽度的 $1 0 \ \%$ ），测量勉强。按更严的解读（不确定度 $\leq$ 半公差的 $1 0 \ \%$ ），不合格。**实际答案：测量能对大多数零件做出接受/拒收判定，但距极限 5 μm 以内的零件处于"不确定区"，应用更好的仪器或比较量具重新测量。**
:::
:::

::: quiz 过程能力 {#quiz-cpk}
一个工艺 $C _ { p } = 2 . 0$ 、$C _ { p k } = 1 . 0$ 。这告诉你什么？

- [ ] 工艺无能力且散布太宽
- [x] 散布没问题但工艺未对中
- [ ] 工艺已对中但散布太宽
- [ ] 测量系统很差

::: solution
**散布没问题但工艺未对中。**$C _ { p } = 2 . 0$ 意味着 $6 \sigma$ 散布放进公差还有 2 倍富余——散布极好。$C _ { p k } = 1 . 0$ 意味着最近的规范极限距均值只有 $3 \sigma$ ——工艺偏移了 $C _ { p } - C _ { p k } = 1 . 0$ 个 $3 \sigma$ 单位，即偏心 $3 \sigma$ 。**解决办法是简单的对中调整（一次刀具偏置、一片夹具垫片），而不是工艺改进。$C _ { p } - C _ { p k }$ 的差距就是不居中的代价，而它永远是最便宜的质量改进。**
:::

## 本讲的后续内容

- **[[manufacturing/machining]]** —— 机床守得住的公差是能力计算的输入。表面质量、刀具磨损和主轴热生长是 SPC 监控的变差来源。
- **[[manufacturing/process-selection]]** —— 一个工艺能达到的 IT 等级决定哪些工艺是候选。$\pm 0 . 0 0 5 \ \mathrm { m m }$ 的公差排除了铸造、锻造和钣金；$\pm 0 . 5 \ \mathrm { m m }$ 的公差排除了磨削和 EDM。
- **[[manufacturing/additive-manufacturing]]** —— 增材制造的成形公差是 $\pm 0 . 1 { - } 0 . 3 \ \mathrm { m m }$ ，即 IT14–IT16。增材零件上每个关键尺寸都要机加工，而机加工余量是一个公差累积问题。
- **[[manufacturing/joining]]** —— 焊缝检验（VT、PT、MT、RT、UT）是属性测量，其探测概率取决于缺陷取向、表面状况和检验员持证等级。POD（探测概率）曲线就是无损检测的 OC 曲线。
- **[[manufacturing/casting]]** —— 铸造公差是 IT14–IT17（100 mm 零件上 $\pm 0 . 3 { - } 3 \ \mathrm { m m }$ ），尺寸精度取决于模样磨损、模具温度和收缩余量。模样要校准，模具要用红外测温控制，首件要扫描。
- **[[control-systems/pid-control]]** —— CNC 轴是一个 PID 控制的伺服系统。定位精度受伺服带宽、编码器分辨率和摩擦限制。阿贝误差是伺服无法抑制的扰动，因为它没有被测量。
- **[[control-systems/feedback-stability]]** —— 带刀具补偿的在线量具是一个反馈回路。环路增益必须小于 1 以避免过校正（刀具绕目标振荡），而采样间隔必须短于刀具磨损时间常数。
- **[[design-process/reliability-risk]]** —— FMEA 是制造与设计之间的桥：严重度评级来自设计（零件失效会怎样），频度评级来自工艺（原因多久发生一次），探测度评级来自检验计划（我们多大概率抓住它）。
- **[[design-process/design-for-manufacture]]** —— 公差累积、基准方案和量具可达性是 DFM 决策。一张给无法检验的特征标 $\pm 0 . 0 1 \ \mathrm { m m }$ 公差的图纸，是一张注定出错的图纸。

::: history 计量、质量与自动化：从量块到数字孪生 {#history-metrology}
**1850 年代。** 约瑟夫·惠特沃斯（Joseph Whitworth）统一了英国螺纹标准，确立了**互换性**原则：不同工厂、不同时间、不同工人制造的零件无需锉配即可装配。其前提是一套在曼彻斯特和伦敦一样的测量体系。**互换性不是设计概念；它是计量概念。**

**1899。** **约翰内斯·赫兹（Johannes Hertz）**和**卡尔·凯伦伯格（Karl Kellenberger）**研制出第一套实用的**量块**（Johansson 量块，1896 年瑞典；赫兹的光学平晶，1899 年）。量块把微米交到车间手里：81 块的组块可以研合成 1 到 100 mm 之间 0.001 mm 增量的任何尺寸。**量块是国家基准与钳工千分尺之间的环节，是溯源链的基础。**

**1924。** **沃尔特·A·休哈特（Walter A. Shewhart）**（贝尔电话实验室）发明了**控制图**。他的洞见是工艺变差有两种原因——"可指定"（特殊）原因与"机遇"（普通）原因——而这种区分可以用统计方法做出，用 $\pm 3 \sigma$ 控制限。控制图是统计质量控制的基础，最终也是六西格玛的基础。

**1931。** 休哈特出版 *Economic Control of Quality of Manufactured Product*。**这本书确立了质量是一个统计问题而不是检验问题，且预防成本低于鉴定成本、鉴定成本低于失效成本。**

**1942。** **W·爱德华兹·戴明（W. Edwards Deming）**把休哈特的 SPC 方法引入日本工业。1950 到 1980 年间，日本把制造质量从"垃圾"变成世界一流，**戴明奖**（1951 年设立）成为质量运动的最高荣誉。**日本质量革命证明了 SPC 有效：丰田 1970 年代的缺陷率是美国汽车业的 1/100，而检验员更少、检验更少。**

**1952。** **约翰·T·帕森斯（John T. Parsons）**和**弗兰克·斯图伦（Frank Stulen）**在 MIT 研制出第一台**数控（NC）铣床**，由美国空军资助以加工复杂飞机翼面蒙皮。机器有 3 轴、穿孔带输入、±0.025 mm 定位精度。**数控机床是 20 世纪最重要的单项制造技术：它让复杂几何变得便宜，让换产变成一次软件更新，让设计者规定的公差成为机器达到的公差。**

**1961。** **NASA** 为阿波罗计划开发了 **FMEA**（失效模式与影响分析）。FMEA 是识别复杂系统单点失效的第一个系统方法。**FMEA 对质量的贡献是这个洞见：失效的严重度是设计属性，频度是工艺属性，探测度是检验属性——而三者的乘积是比任何单项都好的优先级工具。**

**1986。** 丰田的**今泉（Masafi Imaizumi）**和**小佐田（Takashi Osada）**发表了**丰田生产方式**，将**精益制造**成文化：准时化、自働化（带人字旁的自动化）、均衡化（heijunka）和改善（kaizen）。**精益是对这个事实的认识：缺陷的最大来源不是机器而是工艺：漫长的换产时间、大批量、高在制品，以及把缺陷藏到变得昂贵才暴露的"检验出来"心态。**

**1987。** **摩托罗拉**发起**六西格玛**，一种把工艺变差降到 3.4 DPMO 的方法论。**六西格玛是有预算和职业晋升通道的 SPC：黑带是全职工艺改进工程师，DMAIC 循环是结构化的问题解决方法，而 3.4 DPMO 目标是一个驱动工程的营销数字。**

**1991。** **ISO 9000** 质量管理标准族发布。**ISO 9001 是任何供应商进入任何 OEM 供应链的最低要求，证书是进入供应链的入场券。标准不是质量体系；它是质量体系的框架。质量在实施里，不在手册里。**

**2000 年代。** 带扫描测头的 **CMM**、**激光扫描仪**和**X 射线 CT** 把检验从点测量活动变成全场测量活动。5 分钟 CT 扫描产生 1000 万个点，而 30 分钟 CMM 程序产生 50 个点。**瓶颈从测量移到了数据分析：挑战不再是"我们能测吗"，而是"我们拿 1000 万个点怎么办"。**

**2011。** **西门子**和**GE** 开始部署**数字孪生**：与物理产线并行运行、吸收传感器数据并预测质量、产出和维护需求的制造过程实时仿真。**数字孪生是工业 4.0 的承诺：如果你能仿真工艺，你就能不停机地优化它；如果你能预测缺陷，你就能预防它。**

**2020 年代。** **在线计量**成为标配：激光对刀仪、接触测头和非接触量具在机床内、工序间测量零件，并把数据反馈给数控控制器自动补偿。**闭环加工单元——零件被测量、刀具被补偏、下一刀在无人干预下被调整——是 1952 年愿景的实现：一台让自己保持精确的机器。**
:::

::: summary 计量、质量与自动化 {#summary-metrology}
- **测量要么可溯源，要么毫无意义。** 从 SI 米到车间千分尺的校准链必须不间断、有记录、在有效期内。没有不确定度声明的校准证书不是校准。
- **每次测量都有不确定度，而不确定度必须小于公差的 10 %。** GUM 框架（A 类 + B 类、RSS、以 $k = 2$ 扩展）量化疑虑。若不确定度超过公差的 10 %，测量就无法做出接受/拒收判定。
- **阿贝原则支配仪器设计。** 测量轴线应与被测量的尺寸轴线共线。阿贝偏置 $e$ 与角度误差 $\theta$ 产生 $e \times \theta$ 的位移误差。卡尺违反阿贝原则；CMM 在 Z 向遵守它。
- **GD&T 用圆形公差带取代方形公差带。** $\phi 0 . 1$ 的位置公差比 $\pm 0 . 1$ 的尺寸公差更严。MMC 在特征不处于最大实体时给出补偿公差。基准参考系是三个平面，由 3-2-1 规则建立。
- **过程能力把工艺散布与公差宽度比较。** $C _ { p }$ 是潜在能力；$C _ { p k }$ 是实际能力。$C _ { p k } \geq 1 . 3 3$ 是汽车行业最低值；$C _ { p k } \geq 1 . 6 7$ 是航空工业最低值。对中工艺的缺陷率是 $p = 2 \Phi ( - 3 C _ { p k } )$ 。
- **控制图区分普通原因与特殊原因。** $\pm 3 \sigma$ 控制限的 X-bar/R 图有 0.27 % 的虚警率。CUSUM 图在 2–3 个样本内检测 1σ 偏移而不是 40–50 个。韦斯顿判异规则以虚警为代价增加灵敏度。
- **验收抽样是一场统计赌博。** OC 曲线给出接受概率随批质量的变化。$n = 1 0 0$ 的 $c = 0$ 方案拒收 95 % 不合格品率超过 500 ppm 的批。100 % 检验比抽样更糟，因为检验员的错误率（2 %）高于工艺缺陷率。
- **数控机床每组轴系有 21 项刚体误差。** 体积精度比单轴定位精度差 3–5 倍。激光干涉仪校准与补偿把体积误差降到 3–5 μm。刀尖的阿贝误差是刀长乘角度误差。
- **产线平衡确定节拍时间和工位数。** $T _ { \text{takt } } = T _ { \text{available } } / N _ { \text{demand } }$ 。最少工位数是 $\lceil \sum t _ { i } / T _ { \text{takt } } \rceil$ 。产线效率是 $\sum t _ { i } / ( N \times T _ { \text{takt } } )$ 。瓶颈是单件时间最长的工位。
- **质量成本遵循 1-10-100 规则。** 预防花 1 英镑，鉴定花 10 英镑，内部失效花 100 英镑，外部失效花 1 000 英镑。最便宜的缺陷是从未发生的缺陷，最便宜的质量改进是对中工艺。
:::

## 延伸阅读

- **JCGM 100:2008 (GUM)** —— *Joint Committee Guide in Metrology — Guide to the Expression of Uncertainty in Measurement*。不确定度预算的权威参考。读第 4 章（不确定度评定）和附录 G（10:1 规则）。
- **ISO 286-1:2010** —— *Geometrical product specifications (GPS) — ISO code system for tolerances on linear sizes*。IT 等级体系、基本偏差与配合表。
- **ASME Y14.5-2018** —— *Dimensioning and Tolerancing*。GD&T 标准：14 项几何公差、基准参考系、材料边界修饰符与解释规则。
- **AIAG SPC Manual, 2nd ed. (2020)** —— *Statistical Process Control*。汽车 SPC 参考：控制图、能力研究，以及 $C _ { p k }$ 与 $P _ { p k }$ 的解读。
- **AIAG MSA Manual, 4th ed. (2010)** —— *Measurement Systems Analysis*。量具 R&R 研究、偏倚/线性研究与属性一致性分析。
- **Montgomery, D.C. (2019)** —— *Introduction to Statistical Quality Control*, 8th ed. Wiley。标准教科书：SPC、能力、抽样、DOE 与六西格玛。
- **Schmitt, R.H. and Corney, J.R. (2010)** —— *Geometric Quality Control*. Springer。GD&T 的计量学：如何测量基准、如何评定轮廓公差、如何制造功能量规。
- **Groover, M.P. (2020)** —— *Automation, Production Systems, and Computer-Integrated Manufacturing*, 5th ed. Pearson。CNC、FMS、成组技术、产线平衡与工业 4.0。
- **Evans, R.L. and Lindsay, W.M. (2020)** —— *The Deming-Shewhart Cycle: A Practical Guide to Continuous Improvement*. ASQ Quality Press。SPC 的历史与实践：从休哈特的控制图到戴明的日本讲座再到六西格玛。
