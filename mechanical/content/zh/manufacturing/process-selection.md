本图谱前面的十一门课程，没有一门追问一件东西是怎样做出来的。静力学问一个支架承受什么载荷；材料力学问它能否挺过这些载荷；材料科学问它可能由什么做成。本课程问的是接下来的那个问题，而再多的分析也回答不了它：**在一座已经在运转的工厂里，怎样以那个公差、那种合金、那笔钱，造出二十万件那个形状的零件？**答案会改变图纸。它在图纸画完之前就改变它，这正是为什么工艺选择不是设计的最后一步，而是第三步。

每一种制造工艺都是对物质的极少数几种操作之一：**把它变成液体，让它冻成一个形状；让它保持固体，把它压成一个形状；不断去掉材料，直到剩下的就是那个形状；把两个形状合在一起；或者把形状一层层堆出来。**其余的一切——热处理、镀层、去毛刺、检验——改变的是某种性能或某个表面，而不是几何形状。这五种操作在一个物理方面彼此不同，而正是这一个不同，解释了它们几乎全部的经济学：**形状被赋予的那一瞬间，材料处于什么状态。**液体接受铸型的形状，因此也接受铸型的成本、公差和表面质量；固体抵抗变形，因此需要力、压力机和模具；切屑是一次次刀齿走刀切掉的，因此需要机床时间，而机床时间是车间里最贵的东西。公差、生产率、工装和零件尺寸，全都由这一点推出。

::: warning 工艺选择出错的五种方式
**规定一个没人需要的公差。**工程图纸上最昂贵的习惯，是在一个只用来定位盖板的尺寸上标注$\pm 0 . 0 1 \ \mathrm { m m }$。公差每比 IT11 收紧两级，成本大约**翻一番**，所以一个按 IT6 控制的孔，成本约为同一孔按 IT11 控制的六倍，而为保证它所需的夹具、为检验它所需的量规，以及随之而来的废品率，还要再往上加。规则是：公差必须**可追溯到某种功能**——配合、密封面、轴承座、光轴——没有功能的尺寸一律给 IT12 或一般公差注记。**为样机选工艺，却按每年十万件量产。**单件 180 英镑的机加工样件，按每天一千件算就是 1.8 亿英镑的错误，而当初只要 40,000 英镑的注塑模事后看来荒得可笑。盈亏批量是一道算术题，做起来不费事；见第 4 节。**只设计材料，不设计工艺。**一个壁厚从 $3 \ \mathrm { m m }$ 一步跳到 $3 0 ~ \mathrm { m m }$ 的铸件会不均匀收缩，在一个任何冒口都补不到的地方形成热节；一个在 $1 2 ~ \mathrm { m m }$ 厚壁上有 $2 \ \mathrm { m m }$ 凸台的塑件，会在凸台对面的表面上陷出一个凹坑；一个带尖内角的铣槽，需要球头刀以 $0 . 8 \ \mathrm { m m }$ 行距走四十分钟五轴时间，而一个 $6 \ \mathrm { m m }$ 的圆角半径本可以白白送你这个特征。**为并不存在的复杂度选择增材制造。**增材买到的是任何刀具都到不了的几何，和任何模具都摊不平的批量。它买不到便宜：钛粉末以 $1 0 0 ~ \mathrm { g / h }$ 堆积，一个 $2 ~ \mathrm { k g }$ 的支架要 3,200 英镑的机床时间，而锻件只要 88 英镑，人们肯付这笔钱的唯一理由是一条内部冷却通道。**定了基准却从不写下来。**一个零件完全可以照图加工合格，却在装配时失效，因为没有人说过其余一切从哪个面、哪个孔、哪根轴线量起。第 3 节的公差累积没有基准体系就毫无意义，而[[manufacturing/metrology-quality]]中的检验没有基准甚至无法开始。
:::

## 1. 对物质的五种操作

::: definition 工艺家族 {#def-families}
本课程中的每种工艺都属于五大家族之一，划分依据是形状被赋予时工件的状态：

$$
\begin{array} { l l l l l }
\textbf{家族} & \textbf{成形时的材料状态} & \textbf{代表工艺} & \textbf{典型 IT} & \textbf{典型 } R _ { a } \ [ \mu \mathrm { m } ] \\ \hline
\text{凝固} & \text{液态} & \text{砂型、熔模、压铸、离心、连续铸造} & 1 1 { - } 1 5 & 3 \mathrm { - } 2 5 \\
\text{体积成形} & \text{固态，屈服} & \text{轧制、锻造、挤压、拉拔} & 8 { - } 1 3 & 0 . 4 \mathrm { - } 1 2 \\
\text{板料成形} & \text{固态，薄板} & \text{剪切、弯曲、拉深、旋压} & 8 { - } 1 2 & 0 . 4 \mathrm { - } 3 . 2 \\
\text{材料去除} & \text{固态，切削} & \text{车削、铣削、钻削、磨削、电火花、激光} & 4 { - } 9 & 0 . 0 2 \mathrm { - } 3 . 2 \\
\text{增材} & \text{逐层堆积} & \text{粉末床、挤出、液槽、板材层叠} & 8 { - } 1 2 & 1 { - } 2 0 \\
\text{连接} & \text{界面} & \text{熔焊、固相焊、钎焊、胶接、螺纹} & \text{装配} & \text{装配}
\end{array}
$$

有三个推论贯穿整门课程。**从液体成形的工艺复现铸型表面**，所以它的表面质量就是铸型的表面质量，它的公差就是铸型的公差，而铸型磨损时两者一起退化。**靠屈服成形的工艺需要一个力**，与流变应力乘以面积成正比，而力决定了机床，机床决定了最大零件尺寸，模具决定了工装成本。**去除材料的工艺受限于一个以立方毫米每秒计的速度**，所以它的时间是去除体积除以那个速率——这就是为什么最便宜的零件是去掉材料最少的那个，也是为什么第 5 节里“buy-to-fly 比”这个说法是经济问题而不是环保猎奇。
:::

::: example 先分类，再争论 {#ex-classify level=3 check="3"}
一个灰铸铁齿轮箱壳体，$3 2 0 \times 2 4 0 \times 1 8 0 \ \mathrm { m m }$，壁厚 $4 \ \mathrm { m m }$，二十二个螺栓凸台，一个镗削到 H7 的轴承孔，一个平面度 $0 . 0 5 \ \mathrm { m m }$ 的盖板面，年产 8,000 件。

**凝固**成形主体：它是一个带内部凸台的中空盒子，这正是只有铸型才能做的形状类，而灰铸铁几乎无法成形，只能铸造。**材料去除**加工两个功能表面：IT7 的 H7 轴承孔和 $0 . 0 5 \ \mathrm { m m }$ 的盖板面在铸件上保不住，所以这个零件是*近*净形，要加工两道——一道铣面、一道镗孔，在加工中心上约 3 分钟。**连接**处理盖板和四个没有铸入的紧固件。**性能改变**（不是形状操作）用于铸造与机加工之间的去应力退火，没有它，铣面之后应力松弛，等壳体冷下来平面度就没了。

争论在于批量。年产 8 件时，同一个壳体用焊接结构件从实心料加工，因为一个模样加铸型要 9,000 英镑，八件铸件摊不平这笔钱。年产 800,000 件时，它用铝合金压铸、凸台机加工，因为铁不能压铸，而且壁厚可以降到 $2 . 5 \ \mathrm { m m }$。**零件还是那个零件；工艺是年批量的函数。**
:::

## 2. 四个问题，及其必须被追问的顺序

::: definition 真正决定工艺的是什么 {#def-four}
**1. 它由什么做成，这种合金允许这种工艺吗？**它能否不费一番坩埚之争就熔化、不重新氧化就浇注（钛不能在空气中铸造）？它有没有成形的延性——一条经验法则是室温伸长率低于约 $1 0 \ \%$ 就排除拉深和旋压，而热加工需要高于 $0 . 5 \ T _ { m }$（以开尔文计）且氧化皮不剥落的温度？它能切削吗——易切削黄铜的可加工性为 100，304 不锈钢只有 25，同一刀量下刀具寿命相差四倍。**2. 它属于哪个形状类？**回转体和棱柱体适合车削、轧制和挤压；盒状中空体适合铸造和板料；双曲面适合液压成形、旋压，或者谁都不适合；大平板适合中厚板和激光切割。**3. 多精，多光？**IT 等级和 $R _ { a }$ 决定哪些工艺还有资格入围，而它们正是最常被规定过头的两个数字。**4. 要多少？**批量决定你能摊销什么工装，而工装决定哪些工艺根本付得起。

顺序很重要。先问批量，你会选一种材料拒绝的工艺；最后问公差，你会发现你选的便宜工艺只能到 IT11，而图纸要的是 IT7。还有第五个问题不在清单上，却决定了大多数真实选择：**工厂里已经有什么，它一小时多少钱？**街角折弯机 45 英镑一小时的车间费率，和走廊那头五轴机床 140 英镑一小时的车间费率，比本课任何一张表都值钱。
:::

::: example 同一支架在三种批量下 {#ex-bracket level=3 check="91"}
一个铝 L 形支架，$1 1 0 \times 8 0 \times 6 0 ~ \mathrm { m m }$，壁厚 $5 \ \mathrm { m m }$，四个 H9 孔，一个平面度 $0 . 1 \ \mathrm { m m }$ 的面。候选方案：锯切坯料机加工、压铸，以及——仅作对比——铝粉打印。

**机加工。**1.9 kg 的 6082 棒料按每公斤 4.20 英镑是 8.00 英镑；三轴加工中心 0.42 小时按 75 英镑是 31.50 英镑；夹具 1,400 英镑，摊在你生产的任何数量上。单件成本 **39.50 英镑**，另加夹具。

**压铸。**金属 0.95 kg 的 A380 按每公斤 2.60 英镑是 2.47 英镑（铸件近净形，所以只用一半的金属）；400 吨压铸机上 22 秒的周期，按每小时 95 英镑是 0.58 英镑；切边模工序 0.22 英镑；为平面和四个孔加一道机加工，45 秒按 60 英镑，是 0.45 英镑；合计运行成本**每件 3.72 英镑**，另加一副 34,000 英镑的钢模。

**打印。**净重 0.95 kg，按 $6 0 ~ \mathrm { g / h }$ 和 60 % 粉末利用率是 26 小时机床、150 英镑一小时，即 3,900 英镑，另加去除支撑、热处理和平面加工。算它**每件 4,300 英镑**，完全不需要工装。

现在把工装乘以批量。**年产 50 件**：机加工 39.50 + 28 夹具 = **68 英镑**；压铸 3.72 + 680 模具 = **684 英镑**；打印 **4,300 英镑**。机加工以十倍胜出。**年产 5,000 件**：机加工 **39.80 英镑**，压铸 3.72 + 6.80 = **10.50 英镑**，打印 4,300 英镑——压铸获胜，模具十九周就回本。**年产 500,000 件**时，压铸件是 **3.79 英镑**，机加工件则是每年两千万英镑的荒唐。

机加工与压铸的盈亏平衡点是 $( 3 4 , 0 0 0 - 1 , 4 0 0 ) / ( 3 9 . 5 0 - 3 . 7 2 ) = 9 3 3$ 件。**大约一千件以下，不要做模具。**
:::

## 3. 公差是价格，而价格是规律

::: definition IT 等级与公差单位 {#def-it}
ISO 极限与配合体系由名义尺寸 $D$（毫米）定义一个数，**标准公差单位** $i$ ：

$$
i \ = \ 0 . 4 5 \sqrt [ 3 ] { D } \ + \ 0 . 0 0 1 \, D \qquad [ \mu \mathrm { m } ]
$$

并用它的倍数搭建各等级：$\mathrm { I T } 5 = 7 i$ ，$\mathrm { I T } 6 = 1 0 i$ ，$\mathrm { I T } 7 = 1 6 i$ ，$\mathrm { I T } 8 = 2 5 i$ ，$\mathrm { I T } 9 = 4 0 i$ ，$\mathrm { I T } 1 0 = 6 4 i$ ，$\mathrm { I T } 1 1 = 1 0 0 i$ ，$\mathrm { I T } 1 2 = 1 6 0 i$ 。立方根项是几何误差项——在没有任何东西被主动测量时，直线度、垂直度和位置误差随尺寸增长的方式——线性项是热变形与导轨项，每毫米 $1 \ \mu \mathrm { m }$ ，大约相当于钢在 $0 . 2 5 \ \mathrm { K }$ 温升下的膨胀，也大约相当于磨削机床床身的直线度。在车间见到的任何尺寸上立方根项都占主导：$D = 1 { , } 0 0 0 \ \mathrm { m m }$ 时两项分别是 $4 . 5$ 和 $1 . 0 \ \mu \mathrm { m }$ ，要到 $D = 9 { , } 5 0 0 \ \mathrm { m m }$ 才相交。

你应当能脱口而出的数字：在 $2 5 \ \mathrm { m m }$ 处，$\mathrm { I T } 6 = 1 3 \ \mu \mathrm { m }$ ，$\mathrm { I T } 7 = 2 1 \ \mu \mathrm { m }$ ，$\mathrm { I T } 8 = 3 3 \ \mu \mathrm { m }$ ，$\mathrm { I T } 1 1 = 1 3 0 \ \mu \mathrm { m }$ 。**钻孔是 IT11-IT12，铰孔是 IT7-IT8，镗刀能保住 IT8，磨削或珩磨的孔能到 IT6** 。而同一个等级，零件越大越贵：IT7 在 $2 5 \ \mathrm { m m }$ 是 $2 1 \ \mu \mathrm { m }$ ，在 $4 0 0 \ \mathrm { m m }$ 是 $5 9 \ \mu \mathrm { m }$ ，听起来更容易，其实不然，因为在 $4 0 0 \ \mathrm { m m }$ 上守住 $5 9 \ \mu \mathrm { m }$ ，意味着同时守住百万分之 $0 . 1 5$ 的直线度、垂直度、热稳定性和夹具误差。
:::

::: proof 公差统计分配：为什么五个零件每个都可以松一倍 {#proof-stack}
$n$ 个特征组成的尺寸链必须落在 $T$ 以内。按**极值法**理解，每个特征都朝同一方向处于自己的极限，所以均分公差 $t$ 时，

$$
T \; = \; \sum _ { i = 1 } ^ { n } t _ { i } \; = \; n t \qquad \Longrightarrow \qquad t \; = \; { \frac { T } { n } }
$$

按**统计法**理解，各特征的误差是方差相当的分布中相互独立的样本，所以和的方差等于方差之和。把每个公差写成 $k$ 倍标准差，

$$
T ^ { 2 } \ = \ \sum _ { i = 1 } ^ { n } t _ { i } ^ { 2 } \ = \ n t ^ { 2 } \qquad \Longrightarrow \qquad t \; = \; { \frac { T } { \sqrt { n } } }
$$

取 $n = 5$ 、$T = 0 . 5 \ \mathrm { m m }$ ，极值法要求每个特征 $t = 0 . 1 0 0 \ \mathrm { m m }$ ，而均方根法允许 $t = 0 . 5 / { \sqrt { 5 } } = 0 . 2 2 4 \ \mathrm { m m }$ ——**每个零件可以松 2.2 倍**，按上面那张图，这大约相当于每个特征成本减半。这笔节省是真实的，但它要用一笔必须明说的代价来买：RSS 结果是一个关于*总体*的陈述，只在过程均值保持居中、分布保持正态时成立，所以它要求过程控制，而且它保证会有一小部分装配体——$\pm 3 \sigma$ 下约 $0 . 3 \ \%$ ——落在 $T$ 之外。**超差装配体是安全隐患或保修索赔的场合用极值法；超差只是返工的场合作用 RSS，而且绝不在背后没有 Cpk 数字时使用 RSS。**见[[manufacturing/metrology-quality]]。
:::

## 4. 批量、工装与盈亏平衡的算术

::: definition 单件成本方程与盈亏平衡批量 {#def-breakeven}
生产 $N$ 次时一件的成本是

$$
c ( N ) \; = \; \underbrace { m } _ { \text{材料} } \; + \; \underbrace { w } _ { \text{加工} } \; + \; \underbrace { { \frac { T _ { \mathrm { t o o l } } + T _ { \mathrm { f i x } } } { N } } } _ \text{摊销工装} \; + \; \underbrace { f + q } _ { \text{精整、检验} } \; \Big / \; ( 1 - s )
$$

其中 $w$ 是按车间费率计的设备与人工时间，$s$ 是废品率，工装包括模样、锻模、铸型、电极和夹具。对机加工路线，加工成本随 $N$ 大致平坦；对成形路线则陡降，因为成形节拍短而模具贵。对两个候选方案，**盈亏平衡批量**是

$$
N ^ { * } \; = \; { \frac { \Delta T _ { \mathrm { t o o l } } } { \Delta w + \Delta m } } \; = \; { \frac { \text{额外工装} } { \text{每件节省} } }
$$

由此有三条推论。**工装只有在你将生产超过 $N ^ { * }$ 时才值得买**，而 $N ^ { * }$ 是一行就能算完的账，几乎没人在签模具单之前算它。**盈亏平衡对每件节省额敏感得残酷**：把贵工艺节拍砍半，$N ^ { * }$ 就翻倍，这就是为什么“便宜”的双腔模以一半速率生产，往往不如昂贵的四腔模。而**要紧的数量是寿命期总量，不是年产量**——一个车型活四年，一台工业泵活二十年，为一件二十年寿命的零件造一副只活四年的模具，结局不是重制就是核销。
:::

::: example 压铸对比砂型铸造 {#ex-breakeven level=3 check="2892"}
一个铝制杠杆，$1 . 4 \ \mathrm { k g }$ 。**砂型铸造**，铝模样 4,000 英镑：金属加造型每件 11.50 英镑，为得到 1.4 kg 要买 2.6 kg 的冒口和浇道金属。**高压压铸**，钢模 28,000 英镑：每件 3.20 英镑，买料 1.55 kg，并含一道机加工，因为模具把孔做到 IT11 而图纸要 IT8。

$$
N ^ { * } \; = \; { \frac { 2 8 , 0 0 0 - 4 , 0 0 0 } { 1 1 . 5 0 - 3 . 2 0 } } \; = \; { \frac { 2 4 , 0 0 0 } { 8 . 3 0 } } \; = \; 2 { , } 8 9 2 \ \text{件}
$$

低于它，用砂型。高于它，模具以每件 8.30 英镑回收，所以在年产 20,000 件时模具**十七周**回本，此后每年省 166,000 英镑。算术没有说的两件事，两件都属于决策：压铸件**只能用不粘模的合金**（没有 6061，没有 7075——要么 A380 或 B390，要么没有，见[[manufacturing/casting]]），而且压铸件**不能做固溶热处理**，否则起泡，因为它内部满是夹气。如果杠杆需要 T6 性能，压铸方案在任何批量下都是死路，那 8.30 英镑从来不存在。
:::

::: example 软模、过渡工装与判断错误的期权价值 {#ex-soft level=3 check="1400"}
同一种杠杆下个月要 40 件做外场试验，而商业计划书说，若试验成功则年产 60,000 件。

三条路线。**机加工加成形**：从板料做 40 件，每件 118 英镑：4,720 英镑，没有任何承诺，设计还可以改。**铝（软）模或低熔点合金模** 9,000 英镑，单件 5.80 英镑：试验共 9,232 英镑，而模具在表面被冲刷掉之前能做 3,000-8,000 模。**现在就上生产钢模**，28,000 英镑，无论试验成败设计都得冻结。

软模路线比机加工做试验贵 4,500 英镑，换来的是还能再做 3,000-8,000 件——这正是你想买的期权，因为它让你在花出 28,000 英镑之前先弄清批量是否真的存在。该报给经理的正确数字不是任何路线的单件成本，而是**对批量判断错误的代价**：产品失败时钢模损失 28,000 英镑，软模只损失 9,000 英镑。**一个无法撤销的制造决策必须按期定价权，而不是按单件成本。**同样的逻辑让电极、蜡模和 3D 打印模样成为铸件开发的标配第一步，也是为什么第 2 节支架例子里那副 1,400 英镑的夹具是车间里最便宜的工装，也是最常被漏进报价之外的那一个。
:::

## 5. 材料进，材料出：buy-to-fly、切屑与零件背后的能量

::: definition buy-to-fly 比，以及它为什么是经济数字 {#def-btf}
**buy-to-fly 比**（购买质量与装机质量之比）是购买的材料质量除以最终留在交付零件里的质量。一个机加工钛航空支架通常是 **5:1 到 10:1**；模锻件 1.5:1 到 2.5:1；打印件几何上 1.1:1，但算上粉末利用率、支撑和试棒后实际 1.5:1 到 3:1；冷精整螺栓 1.05:1；砂铸件算上冒口和浇道 1.5:1 到 2:1。

它之所以是经济数字，有三个相互叠加的理由。**切屑你要付钱**，按合金的价格付，而钛屑只值棒料的十分之一左右，因为并非所有切屑都能重熔成航空级棒材。**切屑的制造费你也要付**，按机床费率付，而机床费率是成本单上最大的数字：五轴每小时 110 英镑，对比钛每公斤 12 英镑，意味着一小时去除 1.2 kg 的粗加工，是用 110 英镑的人工去毁掉 14 英镑的金属。**还有炼成这种金属所耗的能量**，这是最终会出现在碳报告里的数字：钢型材约 $2 0 \ \mathrm { M J / k g }$ ，原生铝 $2 1 0 \ \mathrm { M J / k g }$ ，钛材 $5 0 0 \ \mathrm { M J / k g }$ 。扔掉四分之三公斤铝，就扔掉 $1 6 0 \ \mathrm { M J }$ ——超过一升汽油的能量——而零件还没产生任何用处。
:::

::: example 钛支架的三种做法 {#ex-titanium level=3 check="88"}
一个 Ti-6Al-4V 飞行支架，净重 $2 . 1 \ \mathrm { k g }$ ，四个关键加工面，年产 5,000 件。

**从锯切坯料机加工。**买 $1 2 \ \mathrm { k g }$ ，每公斤 12 英镑 = 144 英镑，去除其中 $9 . 9 \ \mathrm { k g } = 2 { , } 2 3 5 \ \mathrm { c m } ^ { 3 }$ 。在钛上以 70 bar 内冷、不错的 $1 5 ~ \mathrm { c m } ^ { 3 } / \mathrm { m i n }$ 粗加工要 149 分钟；四个精加工面 $4 0 0 ~ \mathrm { c m } ^ { 3 }$ 按 $3 ~ \mathrm { c m } ^ { 3 } / \mathrm { m i n }$ 要 133 分钟；钻孔攻丝 1.5 小时；第五轴三次重新装夹 1.2 小时；去毛刺倒棱 0.5 小时；装卸与检验 0.3 小时。**8.2 小时**按 110 英镑 = 902 英镑，加 144 英镑金属和 60 英镑检验：**每件 1,106 英镑**，buy-to-fly 5.7。这就是每个钛结构件的前三件要 40,000 英镑一件的原因。

**闭模模锻，再机加工。**买 $4 . 6 ~ \mathrm { k g }$ 棒料，12 英镑一公斤 = 55 英镑，飞边和切边损失 $2 . 5 ~ \mathrm { k g }$ ，按每公斤 3 英镑回收：净材料 **47.50 英镑**。4,000 吨摩擦压力机上锻造，0.05 小时按 180 英镑 = 9 英镑；切边 0.02 小时按 90 英镑 = 1.80 英镑；去应力退火加酸洗 9 英镑；抛丸 3 英镑；加工四个关键面，0.15 小时按 60 英镑 = 9 英镑；荧光渗透检测 6 英镑。运行成本 **85.30 英镑**，而 14,000 英镑的热锻模在年产 5,000 件时每件摊 2.80 英镑：**每件 88 英镑**，buy-to-fly 2.2。

**激光粉末床熔融打印。**净重 $2 . 1 \ \mathrm { k g }$ ，按生产性的 $1 0 0 ~ \mathrm { g / h }$ 是 21 小时机床、150 英镑一小时 = 3,150 英镑；粉末按 60 % 利用率是 $3 . 5 \ \mathrm { k g }$ ，45 英镑一公斤 = 158 英镑；去应力、热等静压加喷丸 380 英镑；去除支撑与表面精整 250 英镑；加工四个关键面，因为成形面是 $R _ { a } \ 1 2$ ，而垂直于建造方向的疲劳强度只有锻材的 65 %：200 英镑。**每件 4,140 英镑**，无工装，buy-to-fly 1.7。

现在按批量读出排序。模锻对机加工的盈亏平衡是 $1 4 , 0 0 0 / ( 1 1 0 6 - 8 5 ) = 1 3$ 件；对打印是 $1 4 , 0 0 0 / ( 4 1 4 0 - 8 5 ) = 4 $ 件。**大约十四件以上，锻支架就是满足图纸的最便宜方案，而打印件永远不是最便宜的——年产 5,000 件不是，五件也不是。**打印买到的不是低单件成本；它买到的是内部冷却流道、九个零件合并成一个的组件、以及模具脱不出、五轴刀具进不去的拓扑优化。为这些而买，付那 4,140 英镑；只因为它听起来时髦而买，就去付模具钱吧。
:::

## 6. 设计规则就是用工程图语言书写的工艺规则

::: definition 设计规则及其各自的工艺来源 {#def-dfm}
下面每条规则都是对一台机器、一把刀具或一股金属流动的物理约束，翻译成设计师不必知情也能遵守的话：

$$
\begin{array} { l l l }
\textbf{规则} & \textbf{因为} & \textbf{违反的后果} \\ \hline
\text{铸造与注塑面留 } 1 ^ { \circ } \text{ 拔模斜度} & \text{模样或零件必须离开铸型} & \text{拉毛的壁面、冲刷坏的铸型、粘住的零件} \\
\text{铸件内圆角 } = \text{壁厚} & \text{金属液填不进尖角，而且在那里收缩} & \text{收缩缩孔恰好出现在应力最大处} \\
\text{截面恒定，或以 } 6 { : } 1 \text{ 过渡} & \text{厚处最后凝固，需要补缩} & \text{一个冒口补不到的热节} \\
\text{槽内圆角 } \geq 1 . 2 \times \text{ 刀具半径} & \text{铣刀是一个圆柱} & \text{一个切不出的圆角，或刀路上 } 3 0 \% \text{ 的台阶} \\
\text{麻花钻孔深 } \leq 4 \times \text{ 直径} & \text{钻头是一根细长、冷却很差的悬臂梁} & \text{跑偏、折断，孔不在图纸说的位置} \\
\text{台阶处留螺纹退刀槽与砂轮越程槽} & \text{丝锥和砂轮不会在末端变细} & \text{螺栓顶死在盲孔里，或台阶磨不到} \\
\text{塑件壁厚在 } \pm 2 5 \ \% \text{ 以内且小于 } 4 \ \mathrm { m m } & \text{塑料冷却收缩，厚芯上方塌陷} & \text{光面上一个凹坑，和一件脱模就翘的零件} \\
\text{一个折弯半径、一个料厚、一个零件} & \text{折弯模具按一个半径一个料厚制造} & \text{无法预测的回弹，和每个折弯一次换模} \\
\text{翻边 } \geq 4 \times \text{ 料厚，孔离边 } \geq t & \text{板料在拉深圆角处变薄开裂} & \text{开裂的翻边，而返工的是模具} \\
\text{能一次装夹从一面加工就一次装夹} & \text{每次重新装夹都往尺寸链里加自己的公差} & \text{一个偏离你守住 } 0 . 0 2 \text{ 的面 } 0 . 0 8 \ \mathrm { m m } \text{ 的孔} \\
\text{一个基准，标记出来，测头够得着} & \text{没有基准的公差不叫公差} & \text{两家厂各做出一个都合格却装不到一起的零件} \\
\text{紧固件能直线拧入、从一侧装配} & \text{装配工只有两只手和一把定扭矩枪} & \text{18 分钟的装配，和壳体里一片掉进去的垫圈}
\end{array}
$$

这些规则不是对自由的限制；它们是工艺便宜的原因。铸件便宜，是因为模样沿一个方向起模；塑件便宜，是因为它沿一个方向顶出。**逆着拔模方向设计，就是要求工艺不再成其自身**，于是它变成一个型芯、一个滑块、一个斜顶、一次额外装夹，或者一个报废。
:::

::: example 零件数减少六成的壳体 {#ex-housing level=3 check="5.6"}
一个阀组：十四个零件——五个铸件、八个机加工隔圈垫片、一个盖板——二十二个紧固件、三个密封界面，装配 18 分钟，每小时 32 英镑，泄漏率让 4 % 的产量上了返修台。

重新设计问的是铸造问题而不是装配问题。**五个铸件合成一个**，内部流道用型芯铸出，易漏界面取消；八个隔圈变成同一本体上的三个镗孔；盖板保留，因为阀必须可维修。三个零件，九个紧固件，一个密封。

按单元装配法计时——拿取并放置一个零件 3 秒，递交并拧入一个紧固件 35 秒：

$$
6 \times 3 \; + \; 9 \times 35 \; = \; 3 3 3 \ \text{秒} \; = \; { \bf 5 . 6 } \ \text{分钟} \qquad \text{对比} \qquad 1 8 \ \text{分钟}
$$

按每小时 32 英镑，人工从 9.60 英镑变成 2.96 英镑，而发现 4 % 总体泄漏的泄漏试验几乎什么都查不出来了，因为少了十一个会漏的界面。铸件变贵了——带型芯的铸件 34 英镑，而它取代的那些简单件 11 英镑——总成本仍然下降，因为**装配体的成本由界面数量主导，而不是由零件成本主导**。这就是面向制造与装配的设计的一段话版本，其方法见[[design-process/design-for-manufacture]]。
:::

## 7. 系统化选择：筛选、排序与下包络线

::: definition 筛选与成本包络 {#def-envelope}
正式的选择，如[[materials-science/materials-selection]]和[[design-process/concept-selection]]，分两轮进行。**筛选**淘汰一切不能工作的：合金不能压铸，形状不能挤压因为它不是恒定截面，公差细过工艺能力，批量摊不平模具，材料不能焊到它必须焊的东西上。筛选是一组是/否过滤器，应当最先做、在纸面上做、一小时内做完，因为它免费，而且能消掉九成的争论。**排序**随后在成本、交货期、能力和风险上比较幸存者。

成本比较是人们做错的那一步，因为他们比较单件成本，而应当比较**实际批量下总成本的下包络线**——就是本课第一张图中曲线的形状。三点提醒。**包络线要按寿命期总量画，不按年产量画**，一个只活两年的产品配一副 40,000 英镑的模具，需要的是年产 40,000 件，不是总共 40,000 件。**包络线要用你真正会买的工装来画**，一个从未见过三维模型的供应商报的模具价一文不值。而当某个候选方案带着能力风险时，**包络线就不是决策**：一个便宜 20 % 、但在安全特征上有两百分之一逃逸率的工艺并不是便宜 20 % ，因为召回定价在尾部里。有纪律的说法是：按成本排序，然后按能力否决，绝不要把两者平均成一个掩盖否决权的单一分数。
:::

::: example 对真实清单做筛选 {#ex-screen level=3 check="2"}
一个聚合物卡扣，$4 0 \times 2 5 \times 3 \ \mathrm { m m }$ ，30 % 玻纤增强尼龙 6:6，年产 250,000 件，一个尺寸到 $\pm 0 . 0 5 \ \mathrm { m m }$ ，耐制动液，以 $0 . 8 \ \mathrm { m m }$ 过盈卡入。

**筛选 1，材料：**尼龙 6:6 + GF30 可注塑，与制动液相容，而在年产 250,000 件下无法机加工出可重复的卡接。机加工出局。**筛选 2，形状：**带钩和卡接凸台的卡扣只在一个方向上是恒定截面，所以挤压出局；它是实心小件，所以板料工艺出局；它不是金属，所以通常意义的铸造出局（而注塑*就是*铸造——见[[manufacturing/casting]]）。**筛选 3，公差：** $4 0 \ \mathrm { m m }$ 上 $\pm 0 . 0 5 \ \mathrm { m m }$ 是 $1 . 2 5 \ \mu \mathrm { m } / \mathrm { m m }$ ，属于注塑 H 级精度，而且只在由模具一半成形、不跨分型线的尺寸上才可实现。**筛选 4，批量：**年产 250,000 件把一副 22,000 英镑的四腔模摊到每件 0.022 英镑，纯属噪声。

两个候选幸存：**注塑成型**和**没有别的**。于是决策完全落在图纸上——分型线在哪里，哪个半模承担关键尺寸，玻璃纤维是横穿还是顺着卡接受力方向（从而浇口在哪里，因为纤维沿流动方向取向，而沿流动方向的强度是横向的 1.6 倍），以及 $0 . 8 \ \mathrm { m m }$ 过盈是注塑直接成形还是注塑后再定尺寸。**筛选留下一个工艺和四个设计决策，而那四个设计决策比工艺选择本身更值钱。**
:::

## 习题

::: exercise 级进模冲压对比激光切割加折弯 {#ex-stamp level=2 check="5626"}
$1 . 5 \ \mathrm { m m }$ 不锈钢板支架。激光切割加折弯，折弯模与夹具 2,400 英镑：每件 9.60 英镑。级进模冲压，模具 46,000 英镑：每件 1.85 英镑。求盈亏平衡批量。（以件为单位，取整。）
::: solution
$$
N ^ { * } = { \frac { 4 6 , 000 - 2 , 4 0 0 } { 9 . 6 0 - 1 . 8 5 } } = { \frac { 4 3 , 6 0 0 } { 7 . 7 5 } } = { \bf 5 { , } 6 2 6 \ p i e c e s }
$$
**年产 20,000 件时模具十四周回本；年产 600 件时它就是一笔 46,000 英镑的错误。**注意这个计算假设了什么：冲压件是*同一个零件*，而它不是——级进模做不出需要侧向抽芯的翻边唇，它比折弯机能守住更紧的重复精度，而客户把一个孔挪 2 mm 时它不能花 200 英镑改掉。**工装买到批量，丢掉柔性，而盈亏批量只是钱交叉的点，不是风险交叉的点。**
:::
:::

::: exercise 160 mm 的 IT8 是多少 {#ex-it8 level=2 check="65"}
计算标准公差单位，然后求名义尺寸 $1 6 0 \ \mathrm { m m }$ 的 IT8。（以 $\mu \mathrm { m }$ 为单位，取整到微米。）
::: solution
$i = 0 . 4 5 ( 1 6 0 ) ^ { 1 / 3 } + 0 . 0 0 1 ( 1 6 0 ) = 0 . 4 5 ( 5 . 4 3 ) + 0 . 1 6 = 2 . 4 4 3 + 0 . 1 6 = 2 . 6 0 \ \mu \mathrm { m }$ ，而 $\mathrm { I T } 8 = 2 5 i = { \bf 6 5 \ \mu m }$ 。**这是尺寸的 $0 . 0 4 \ \ \%$ ，而同一个等级在 $2 5 \ \mathrm { m m }$ 处是 $0 . 1 3 \ \ \%$ ：大零件相对地精密得多，而必须更好是机床、夹具和车间温度，不是操作工。**
:::
:::

::: exercise 统计法能松多少 {#ex-stack level=2 check="2"}
一个盖板由四个特征组成的隔圈堆定位，总间隙必须落在 $0 . 8 \ \mathrm { m m }$ 以内。若尺寸链按统计法而非极值法分配，每个特征的公差放宽多少倍？
::: solution
极值法：$t = 0 . 8 / 4 = 0 . 2 0 0 \ \mathrm { m m }$ 。均方根法：$t = 0 . 8 / \sqrt { 4 } = 0 . 4 0 0 \ \mathrm { m m }$ 。**2.0 倍**——相当于两级 IT ，按每个特征成本大约减半，这就是统计公差分配存在的全部理由。**它的代价是保证：RSS 的陈述只对均值保持居中的总体成立，所以它要求过程控制，而且它接受约 $0 . 3 \ \ \%$ 的装配体在 $\pm 3 \sigma$ 下装不上。**
:::
:::

::: exercise 废品率就是成本 {#ex-scrap level=2 check="33.2"}
材料 4.60 英镑，加工 0.35 小时按每小时 72 英镑，工装 5,200 英镑摊在 8,000 件上，精整与检验 1.40 英镑，废品率 $4 \ \ \%$ 且无一挽回。求单件成本。（以英镑为单位，保留一位小数。）
::: solution
运行成本 $4 . 6 0 + 2 5 . 2 0 + 0 . 6 5 + 1 . 4 0 = 3 1 . 8 5$ ，而每件废品必须由良品买单，所以 $c = 3 1 . 8 5 / 0 . 9 6 = { \bf \pounds 3 3 . 2 }$ 。**$4 \ \ \%$ 的废品率让一切贵 $4 . 2 \ \ \%$ ，包括你没有报废的那些材料。****这就是为什么过程能力指数是成本数字而不是质量数字：把废品率从 $4 \ \ \%$ 降到 $1 \ \ \%$ 值每件 1.03 英镑，年产 8,000 件就是 8,200 英镑，只花一名工艺工程师两周的时间。**
:::
:::

::: exercise 端铣一块板料要多久 {#ex-mill level=3 check="5.5"}
一块 $2 5 0 \times 1 6 0 \ \mathrm { m m }$ 的铸铁板以 $\varnothing 1 2 5 \ \mathrm { m m }$ 五刃铣刀端铣 $2 . 5 \ \mathrm { m m }$ 深，$v _ { c } = 2 2 0 \ \mathrm { m / m i n }$ ，每齿 $0 . 1 2 \ \mathrm { m m }$ ，每侧引入和超越 $1 5 \ \mathrm { m m }$ ，行距 $4 0 \ \mathrm { m m }$ ，行间快移 $0 . 2 5 \ \mathrm { m i n }$ 。求切削与快移总时间。（以分钟为单位，保留一位小数。）
::: solution
$n = 1 0 0 0 v _ { c } / ( \pi D ) = 2 2 0 \, 0 0 0 / ( \pi \times 1 2 5 ) = 5 6 0 \ \mathrm { r p m }$ ；$v _ { f } = n z f _ { z } = 5 6 0 \times 5 \times 0 . 1 2 = 3 3 6 \ \mathrm { m m / m i n }$ 。走刀长度 $1 6 0 + 3 0 = 1 9 0 \ \mathrm { m m }$ ，所以每刀 $0 . 5 7 \ \mathrm { m i n }$ 。走刀数 $= \lceil 2 5 0 / 4 0 \rceil = 7$ ，所以 $7 \times 0 . 5 7 = 3 . 9 5 \ \mathrm { m i n }$ 切削加 $6 \times 0 . 2 5 = 1 . 5 \ \mathrm { m i n }$ 快移：**5.5 分钟**，按每小时 90 英镑是 8.20 英镑——这还没算 6 分钟的装夹、4 分钟的程序校验，以及四十分之一的概率刀片撞上谁都没在铸件上看见的冒口台。
:::
:::

::: exercise 被扔掉的能量 {#ex-energy level=3 check="2520"}
一个 $6 \ \mathrm { k g }$ 的铝壳体从 $1 8 ~ \mathrm { k g }$ 的坯料加工而成。取原生铝 $2 1 0 \ \mathrm { M J / k g }$ ，仅切屑中就包含多少一次能源？（以 MJ 为单位。）
::: solution
$1 8 - 6 = 1 2 \ \mathrm { k g }$ 切屑，按 $2 1 0 \ \mathrm { M J / k g } = { \bf 2 { , } 5 2 0 \ M J }$ ，约等于六十升汽油的能量，只为做出一些最好也就是被重熔成砂型铸造用铝锭的切屑。**回收切屑大约只需原生能源的 $5 \ \ \%$ ，所以损失是真实的但不是无限的——更尖锐的损失是第 5 节里那 12,300 英镑的机床时间，没有任何熔炉能把它炼回来。****这里 3.0 的 buy-to-fly 比对机加工壳体很典型，对设计出来的壳体则是糟糕的：铸造或成形壳体是 1.2 到 1.5。**
:::
:::

::: exercise 最后几级公差值多少 {#ex-cost level=3 check="8"}
用本课的车间经验法则，一个特征从 IT11 收紧到 IT5 ，成本上升多少倍？
::: solution
六级，每两级翻一番：$2 ^ { 6 / 2 } = { \bf 8 }$ 。**而这条经验法则还低估了，因为 IT5 不是更好的 IT8——它是研磨，是第二台机床、第二个基准、受控的车间温度，是量规而不是千分尺。****当设计师要求“紧一点”时，就该报这个数：问清哪个 IT 等级，算出倍数，再问什么会坏。**
:::
:::

::: exercise 在两个废品率下推导盈亏平衡 {#ex-derive1 level=4 check="2501"}
工艺 1 每件 $w _ { 1 } = \pounds 1 2 . 0 0$ ，废品率 $1 \ \ \%$ ，无工装。工艺 2 每件 $w _ { 2 } = \pounds 4 . 0 0$ ，废品率 $3 \ \ \%$ ，工装 20,000 英镑。推导以交付良品计盈亏平衡批量并求值。
::: solution
一件*良品*的成本是所耗一切除以成品率，$c = ( w + T / N ) / ( 1 - s )$ ，所以
$$
{ \frac { w _ { 1 } } { 1 - s _ { 1 } } } = { \frac { w _ { 2 } + T / N } { 1 - s _ { 2 } } }
 \qquad \Longrightarrow \qquad
N ^ { * } = { \frac { T } { \; { \dfrac { w _ { 1 } ( 1 - s _ { 2 } ) } { 1 - s _ { 1 } } } - w _ { 2 } \; } }
$$
$$
N ^ { * } = { \frac { 2 0 \, 0 0 0 } { 1 2 . 0 0 \times 0 . 9 7 / 0 . 9 9 - 4 . 0 0 } } = { \frac { 2 0 \, 0 0 0 } { 1 1 . 7 6 - 4 . 0 0 } } = { \bf 2 { , } 5 0 1 \ p i e c e s }
$$
**对比忽略废品率得到的 $2 0 \, 0 0 0 / ( 1 2 - 4 ) = 2 { , } 5 0 0$ ，这里答案几乎不动——但只是因为两个废品率很接近。****若工艺 2 的废品率是 $8 \ \ \%$ ，它的良品成本就是 $4 . 0 0 / 0 . 9 2 = \pounds 4 . 3 5$ ，$N ^ { * }$ 升到 3,030，高出五分之一：一个每十二件废一件的快工艺，必须快得多才值得用，而忽略 $s$ 的报价就是最后要扯皮的报价。**
:::
:::

::: exercise 推导公差的尺寸标度 {#ex-derive2 level=4 check="18"}
由 $i = 0 . 4 5 \sqrt [ 3 ] { D } + 0 . 0 0 1 D$ 证明*相对*公差 $i / D$ 随 $D$ 增大而下降，并计算 $1 0 \ \mathrm { m m }$ 处的相对公差比 $1 0 0 0 \ \mathrm { m m }$ 处松多少倍。
::: solution
$i / D = 0 . 4 5 D ^ { - 2 / 3 } + 0 . 0 0 1$ ，随 $D$ 单调递减并趋于 $0 . 0 0 1$ ——线性项是一个下限，而对非常大的结构，最终起支配作用的正是导轨与热变形项。$D = 1 0$ 时，$i = 0 . 9 7 9 \ \mu \mathrm { m }$ ，$i / D = 0 . 0 9 8 \ \mu \mathrm { m / m m }$ ；$D = 1 0 0 0$ 时，$i = 5 . 5 0 \ \mu \mathrm { m }$ ，$i / D = 0 . 0 0 5 5$ ；比值是 **18**。**一个 $1 0 0 0 \ \mathrm { m m }$ 的机架按 IT7 ，其相对精度是 $1 0 \ \mathrm { m m }$ 销钉按 IT7 的十八倍，这听起来不可能，直到你想起它花多少钱：它意味着整整 $1 \ \mathrm { m }$ 的结构、夹具、温度计和测头都被控制在几个波长级的直线度以内，这就是为什么大型精密零件按单位公差计是贵的而不是便宜的。**
:::
:::

::: exercise 数一数结合面 {#ex-dfa level=3 check="5.6"}
一个由十四个零件、二十二个紧固件组成的装配体耗时十八分钟。一次面向装配的设计改版后剩六个零件、九个紧固件。用每个零件拿取放置 3 秒、每个紧固件递交加拧入 35 秒，求新的单台装配时间。（以分钟为单位，保留一位小数。）
::: solution
$6 \times 3 + 9 \times 35 = 3 3 3 \ \mathrm { s } = { \bf 5 . 6 \ m i n }$ ，对比 18 分钟。**节省不在零件上：在那十一个紧固件上——每一个都要一次递交、一次拾取、一次拧入、一次检查——也在那十一个不再需要对齐、拧紧、密封或试验的界面上。****最可靠的单条 DFA 动作，是对每个零件发问：它必须相对另一个零件运动吗？必须用不同的材料吗？必须为了维修而独立吗？若都不是，它就应该成为别的东西的一部分。**
:::
:::

::: quiz 年产 300 件 0.6 kg 带两个机加工凸台的铝杠杆 {#quiz-lever}
正确的首选是
- [ ] 高压压铸，因为铝压铸便宜
- [x] 砂型或熔模铸造，或棒料机加工，因为年产 300 件摊不平一副钢压铸模，而凸台反正要机加工
- [ ] 粉末床熔融，因为增材不需要工装
- [ ] 锻造，因为锻件强度高
::: solution
**压铸那副 25,000-40,000 英镑的模具在年产 300 件时单工装就摊 83-133 英镑一件，所以图纸“想要”的工艺在批量下付不起；而且无论什么工艺，凸台都必须加工到 IT8 ，机加工省不掉。****锻造也要模具，而这个尺寸的杠杆年产 300 件同样在它的盈亏点以下。增材不需要工装，但单件成本比两者高一个数量级。年产 300 件的诚实答案是：一副便宜的模样，一个砂型或熔模铸件，一副机加工夹具——或者干脆不铸造。**
:::

::: quiz 图纸在一个非配合尺寸上写 ±0.01 mm {#quiz-tol}
第一件要做的事是
- [ ] 报能保住它的工艺
- [ ] 买台更好的机床
- [x] 问这个尺寸是干什么的，放宽到 ±0.1 mm 会坏什么
- [ ] 加一条注记说它不重要
::: solution
**公差必须可追溯到功能。如果 $\pm 0 . 1 \ \mathrm { m m }$ 什么都不坏，那么 $\pm 0 . 0 1$ 的注记正让这个特征贵四倍，外加一副夹具、一把量规、一个检验频次、一个废品率，而理由到头来会发现只是一个习惯。****“加一条注记说它不重要”只会更糟，因为图纸从此包含两条互相矛盾的指令；正确的改法是改公差、在改版处签名、并说明理由。**

**1785 年。**马克·布鲁内尔（Marc Isambard Brunel）开始让“制造”机械化：他为朴次茅斯滑车车间安装的滑车制造机械，配上亨利·莫兹利（Henry Maudslay）的机床，是第一个由机器而不是木匠掌握精度的生产系统——三十二台机器把船用滑车做到手工配作从未达到的互换性，也是“precision”一词从今以后指机器属性而非人的属性的原因。**1798 年。**埃利·惠特尼（Eli Whitney）一万支滑膛枪的合同让“零件按样板制造、不经锉修即可装配”的观念广为流传——传说多于实绩，因为真正做成这件事的是 1820 年前斯普林菲尔德与哈珀斯费里的美国兵工厂体系——随之而来的是第 4 节整套工装与量规的经济学：互换件就是公差被*测量*过的零件，这就是本课与[[manufacturing/metrology-quality]]本是一门学问的原因。**1913 年。**亨利·福特（Henry Ford）的海兰帕克流水线迈出最后一步：按工厂而不是按工人设定的节拍把工件送到人面前，把 T 型车的装配时间从 12.5 小时砍到 1.5 小时，并让年产量——第 2 节的第四个问题——成为此后一个世纪里决定汽车、零件和工艺设计的事实。**20 世纪 50 年代。**田口玄一（Genichi Taguchi）的统计实验设计与质量损失函数，给波动而不是只给废品定价，日本汽车与电子工业对他的采纳使质量买在过程能力处，而不是买在检验处。**20 世纪 80 年代。**布斯罗伊德（Boothroyd）与杜赫斯特（Dewhurst）在马萨诸塞大学的面向装配设计工作，把装配体的零件数变成第 6 节单元装配法里可计算的成本，DFA 从此是一张电子表格而不是一种观点。**1986 年。**查克·赫尔（Chuck Hull）的立体光刻专利开启了增材制造，它作为原型工具卖了二十年，直到 2010 年代——以生产速率熔融钛与镍合金粉末——才来到第 5 节的那场争论里，在那里它比拼的是几何而不是价格。
:::

::: summary
**五种操作，不是五十种。**凝固、体积成形、板料成形、材料去除、增材——再加上连接与那些改变性能而不改变形状的加工。形状被赋予时材料的状态，决定了公差、速率、工装和零件尺寸，从而决定了成本。
**四个问题，按顺序。**材料、形状类、公差与表面质量、批量——然后是你自己那台机床的车间费率。换个顺序问，你就会选一种合金拒绝的工艺，或一个工艺保不住的公差。
**公差是价格。**$i = 0 . 4 5 \sqrt [ 3 ] { D } + 0 . 0 0 1 D$ ，$\mathrm { I T } 7 = 1 6 i$ ，IT11 以下每两级成本翻番：IT5 是 IT11 的八倍，而且是另一种工艺，不是更好的工艺。每个公差都必须可追溯到功能；尺寸链可按 $\sqrt { n }$ 每特征作统计分配——用过程控制来买，不是用乐观来买。
**批量决定其余一切。**$c ( N ) = m + w + T / N + ( f + q ) / ( 1 - s )$ ，$N ^ { * } = \Delta T _ { \mathrm { t o o l } } / \Delta c$ ；盈亏平衡是一行算术，它对每件节省和废品率敏感得残酷，而且必须按寿命期总量取。盈亏点以下，工艺再好，工装也是错误；盈亏点以上，操作工再好，机加工也是错误。
**材料进，材料出。**从冷精整螺栓的 1.05 到机加工钛支架的 10 的 buy-to-fly 比；每公斤 20 到 500 MJ 的蕴含能量随切屑扔掉；以及跟着去除体积而不是销售体积走的机床时间。最便宜的零件，是去掉材料最少的那个。
**规则是伪装的物理。**拔模斜度、圆角、恒定截面、孔深、刀具可达性、一个基准、一次装夹、少量界面——每一条都是一个型芯、一把刀具、一台压力机或一双手；违反一条不会救回规则，只会买回一个型芯、一个滑块、一次额外装夹或一个报废。
:::

## 延伸阅读

- M. P. F. Greulich、G. Boothroyd、P. Dewhurst 与 W. A. Knight 著，*Product Design for Manufacture and Assembly*，CRC Press——把第 6 节的单元装配法在真实产品上从头算到尾。
- A. C. Müller 与 M. K. Zwicker 主编，*Cost-Effective Manufacture of Mechanical Products*，Springer——盈亏平衡分析、工装摊销与第 3 节的过程能力表。
- H. A. Kuhn 与 VDI，*Expert System for Process Selection (PROST)* 及 VDI 手册 *Product Engineering*，Springer——把第 7 节的筛选与排序方法写成成文程序。
- S. Kalpakjian 与 S. R. Schmid，*Manufacturing Engineering and Technology*，Pearson——本课每张表背后的逐工艺细节。
- M. Ashby 与 K. Johnson，*Cambridge Engineering Selector* 与 *Materials Selection in Mechanical Design*，Butterworth-Heinemann——那些图表，以及阅读它们的诚实方式。
