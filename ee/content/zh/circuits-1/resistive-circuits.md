一只电阻遵守欧姆定律，但你将会遇到的电路，是许多电阻以串联与并联方式与一个或多个电源组成的网络。好消息是：只要元件是电阻性的、网络是线性的，你不必对每个网络都去解方程组——一大类网络可以一步步收缩为单个等效电阻，而两个比值——分压与分流——就能答出多数实际问题。本课给你这些工具，并告诉你它们在何处失效。

## 欧姆定律与理想电阻

电阻中电压与电流的关系，是本课使用频率最高的一个式子。

::: definition 欧姆定律与电阻 {#def-ohm}
**电阻器**是电压与电流满足下式的二端元件：

$$
v = R\,i \qquad\qquad (R>0,\ \Omega),
$$

其中$R$为**电阻**，是以欧姆计的常数。等价地$i = v/R$或$R = v/i$。吸收功率为$p = vi = i^2 R = v^2/R$，当$R>0$时总是非负。也可改用**电导**$G=1/R$，单位为西门子（S），此时$i = Gv$。
:::

关于适用范围要说一句：这个形式的欧姆定律是我们对理想电阻的含义所作的*定义*，不是普适的自然定律。真实电阻在很宽范围内接近它，但会发热并漂移；金属只是在合理范围内才是欧姆性的。理想模型正是使串并联化简成为精确的前提。

::: example 由电流与电阻求电压 {#ex-ohm}
一只$50\ \Omega$电阻通过$0.2\ \mathrm A$电流。求其两端电压与吸收的功率。
::: solution
$v = Ri = 50\times0.2 = 10\ \mathrm V$。功率$p = i^2 R = (0.2)^2\times50 = 2\ \mathrm W$，等价地$p=vi=10\times0.2=2\ \mathrm W$。两种算法结果一致，这就是你的校核。
:::
:::

::: warning 电阻只是近似欧姆性的 {#warn-ohmic}
不要把欧姆定律当作处处成立的物理定律。它是理想元件的定义方程。电阻值随温度与电压而变；“碳膜”电阻的漂移比金属膜更大；高频下引线呈现电感、本体呈现电容。下面的串并联结果都假定理想元件——这个模型你尽可以使用，但它终究是模型。
:::

一根真实导线的电阻由材料与几何形状决定，下面把理想$R$与你将要购买或铺设的实物联系起来。

::: example 铜导线的电阻 {#ex-wire}
一根$10\ \mathrm m$长的铜导线，截面积为$1\ \mathrm{mm^2}$。取铜的电阻率为$\rho=1.68\times10^{-8}\ \Omega\cdot\mathrm m$，求其电阻。
::: solution
均匀导体的电阻为$R = \rho L/A$。这里$L=10\ \mathrm m$，$A=10^{-6}\ \mathrm{m^2}$，故$R = (1.68\times10^{-8}\times10)/10^{-6} = 0.168\ \Omega$。这个数很小，所以用铜作导线：在实际电流下其压降可以忽略。注意答案如何随尺度变化：长度加倍，$R$加倍；截面加倍，$R$减半。
:::
:::

## 串联与并联

连接电阻的两种基本方式——串联与并联——各有简单规则。教材中与现实中相当大一部分网络都由这两者组合而成。

::: theorem 串联与并联电阻 {#thm-series-parallel}
*电流*相同的电阻是**串联**，直接相加：

$$
R_{\text{串}} \;=\; R_1 + R_2 + \cdots + R_n.
$$

*电压*相同的电阻是**并联**，按倒数和合并：

$$
\frac{1}{R_{\text{并}}} \;=\; \frac{1}{R_1}+\frac{1}{R_2}+\cdots+\frac{1}{R_n},
$$

于是两个并联时$R = \dfrac{R_1 R_2}{R_1+R_2}$。串联组合总大于其中任一成员；并联组合总小于其中任一成员。
:::

两条规则互为对偶。串联时同一电流流过每个电阻，故总电压等于各压降之和、电阻相加。并联时同一电压加在每个电阻上，故总电流等于各支路电流之和、电阻的倒数相加。通过自问“共享的是电流还是电压”来分清二者，是决定性的技能。

::: example 化简串并联网络 {#ex-reduce}
两只电阻$4\ \mathrm{k\Omega}$与$6\ \mathrm{k\Omega}$串联成一条支路。该支路与一只$10\ \mathrm{k\Omega}$电阻并联。一个$20\ \mathrm V$电源驱动这一组合。求总电阻、总电流，以及每只电阻的电流与电压。
::: solution
串联支路为$R_A = 4\ \mathrm{k\Omega}+6\ \mathrm{k\Omega}=10\ \mathrm{k\Omega}$。与$10\ \mathrm{k\Omega}$并联得$R_{eq} = \dfrac{10\cdot10}{10+10}=5\ \mathrm{k\Omega}$。电源总电流为$I = 20/5\ \mathrm{k\Omega}=4\ \mathrm{mA}$。整个并联段两端电压即电源电压，$20\ \mathrm V$。流过$4\text{-}6$支路的电流为$20/10\ \mathrm{k\Omega}=2\ \mathrm{mA}$，流过单只$10\ \mathrm{k\Omega}$的也是$20/10\ \mathrm{k\Omega}=2\ \mathrm{mA}$，两者之和为总电流$4\ \mathrm{mA}$。串联支路中有$2\ \mathrm{mA}$，故$6\ \mathrm{k\Omega}$上电压为$2\ \mathrm{mA}\times6\ \mathrm{k\Omega}=12\ \mathrm V$，$4\ \mathrm{k\Omega}$上电压为$2\ \mathrm{mA}\times4\ \mathrm{k\Omega}=8\ \mathrm V$，两者之和为$20\ \mathrm V$，理所应当。这里的每个数都由一条守恒定律交叉校核过。
:::
:::

::: quiz
$4\ \Omega$与$4\ \Omega$并联，等效电阻是多少？
- [x] $2\ \Omega$
- [ ] $8\ \Omega$
- [ ] $16\ \Omega$
- [ ] $4\ \Omega$
::: solution
两只相等电阻并联，减半：$R = \dfrac{4\cdot4}{4+4}=2\ \Omega$。两只串联则会加倍成$8\ \Omega$；不要混淆。
:::
:::

## 分压与分流

一旦化简了网络，下面两个比值就能让你无需重画电路直接读出各处的电压与电流。它们是本课最快捷、最有用的结果。

::: proposition 分压 {#prop-vdiv}
两只电阻$R_1$与$R_2$串联接在电源$V$两端，则$R_2$（靠输出的一端）上的电压为

$$
V_{R_2} \;=\; V\,\frac{R_2}{R_1+R_2}.
$$

分压比只取决于两个电阻，与电源或所取的负载都无关，*前提是没有其他电流从该节点流出*。
:::

::: example 为固定输出选择分压器 {#ex-vdiv}
设计一个分压器，由$10\ \mathrm V$电源得到$3.33\ \mathrm V$输出，下端用$1\ \mathrm{k\Omega}$电阻。上端电阻应为多少？
::: solution
我们需要$V_{out} = 10\,\dfrac{R_2}{R_1+R_2} = 3.33$，于是$\dfrac{R_2}{R_1+R_2}=\tfrac13$，其中$R_2=1\ \mathrm{k\Omega}$。这要求$R_1+R_2 = 3R_2 = 3\ \mathrm{k\Omega}$，故$R_1 = 2\ \mathrm{k\Omega}$。校核：$10\times 1/(2+1)=3.33\ \mathrm V$。比值$R_1:R_2 = 2:1$把输出定在距下端参考点三分之一处。
:::
:::

::: warning 只要负载取流，分压器就不再空载 {#warn-loading}
分压公式假定全部串联电流都经$R_2$返回。若在输出端接上负载$R_L$，负载就与$R_2$*并联*，该节点的有效电阻下降，输出电压便低于空载值。只有当$R_L$远大于$R_2$时，分压器才是好的电压基准。当负载不可忽略时，你面对的不再是分压器而是一般网络，必须改用上面的串并联规则。
:::

并联时，共享的**电压**决定各电流，因此电源电流按电导的比例分配。

::: proposition 分流 {#prop-cdiv}
两只电阻$R_1$与$R_2$并联，由总电流$I$供电，则流过$R_1$的电流为

$$
I_{R_1} \;=\; I\,\frac{R_2}{R_1+R_2},
$$

流过$R_2$的电流为$I\,R_1/(R_1+R_2)$。电流按电阻的反比分配：电阻小的分走电流多的份额，恰是分压的镜像。
:::

::: example 电流在两条支路间的分配 {#ex-cdiv}
一个$20\ \mathrm V$电源驱动$4\ \mathrm{k\Omega}$与$6\ \mathrm{k\Omega}$的并联组合。求各支路电流与总电流。
::: solution
等效地看，两者两端电压都是$20\ \mathrm V$。$4\ \mathrm{k\Omega}$通过$20/4\ \mathrm{k\Omega}=5\ \mathrm{mA}$，$6\ \mathrm{k\Omega}$通过$20/6\ \mathrm{k\Omega}=3.33\ \mathrm{mA}$。总电流为$5+3.33=8.33\ \mathrm{mA}$。用分流公式校核：并联总电阻$R = \dfrac{4\cdot6}{4+6}=2.4\ \mathrm{k\Omega}$，故$I = 20/2.4\ \mathrm{k\Omega}=8.33\ \mathrm{mA}$，而$I_{4k} = 8.33\times \dfrac{6}{10}=5\ \mathrm{mA}$，结果一致。电阻小的确实承载电流大的，正如规则所说。
:::
:::

::: quiz
$12\ \mathrm{mA}$电流馈入$3\ \mathrm{k\Omega}$与$6\ \mathrm{k\Omega}$的并联组合。$3\ \mathrm{k\Omega}$中流过多少电流？
- [x] $8\ \mathrm{mA}$
- [ ] $4\ \mathrm{mA}$
- [ ] $6\ \mathrm{mA}$
- [ ] $12\ \mathrm{mA}$
::: solution
用分流公式、分子取对臂电阻：$I_{3k} = 12\times\dfrac{6}{3+6} = 12\times\tfrac23 = 8\ \mathrm{mA}$。其余$4\ \mathrm{mA}$流过$6\ \mathrm{k\Omega}$；电阻小的分走电流多的份额。
:::
:::

## 理想导线及其限度

理想电阻之间是理想**导线**，它根本没有电阻。导线是导体取$ho\to 0$的极限情形，正是它使整套串并联模型成立：电流可以从一个元件无损地改道到另一个元件，而由导线连成的各节点处于同一电压。两根相接的理想导线是同一个节点，每根理想导线连接的两点电压严格相同、压降为零。这就是节点拥有唯一确定电压的原因，也是你尽管画下一张导线与电阻的网络、仍然可以说得清*某个*节点电压的原因。

这一理想化的限度你日后会遇到。两节点之间，短路就是零电阻的通路，欧姆定律于是容许任何电流：电流完全由网络其余部分决定。真实导线电阻虽小却非零，真实短路则能拉出仅受电源与导线限制的巨大电流。二者是不同的东西；当理想化分析中电流显得“无穷大”时，混淆二者是常见的错误来源。

开路短路的两个极限把中间一切情形包在里面。**开路**是电阻无穷的极限：电流无法流动，电压由网络其余部分决定，它正是不接线的端子的自然状态。**短路**是电阻为零的极限：其两端电压为零，电流由网络其余部分供给。理解这两个极限，并认出某个子网络已被化成哪一个，是读电路图的一半功夫。每当公式中的电阻看似趋于零或无穷时，把这两者都放在心上。

## 读实际网络

实践中你会遇到一个网络，被要求求出众多量中的某一个。方法每次都一样。通过自问哪些电阻共享电流、哪些共享电压，辨认出串联与并联的分组。一次化简一组，同时记下等效电阻、以及每次化简所能算出的电流或电压。再从单个等效值出发，一步一步反推回去，把你合并时丢掉的量逐一恢复。全程使用上一课讲过的一套一致的参考方向，每个答案都会是一个符号可信的有符号数。

第二个有用的习惯是量纲检验。电阻的单位是伏每安；$R_2/(R_1+R_2)$这样的比值是无量纲的；乘以电压得到电压。若你写出的表达式不具备所求量的单位，那么不用看数字你就已经错了。这个习惯能抓住绝大多数代数符号与比值错误——早期电路错误大多就出在那里。

第三个习惯很快就会回本：收尾前一定把答案画回原电路上。化简后的等效电路只是计算工具，不是全部；你在一条支路里求出的电流，只有说清它流过哪只实际的电阻、沿哪个方向，才真正有用。所以要养成随手记一张小表的功夫——每一步化简的等效电阻，以及该步所能算出的某个具名元件的电流或电压。算到单个等效值与总量后，再按完全相反的顺序回代，你报告的每个量就都挂在真实元件与真实方向上。一眼能化简的网络固然因此受益；不能干净化简的网络（下一课）也会逼你保持同样的纪律，因为系统方法归根结底只是把同样的化简写成了方程。

## 后续内容

有了欧姆定律、串并联化简与分压分流两个比值，课程上半部分你遇到的几乎任何电阻网络都能靠观察或几步代数解出。[[circuits-1/nodal-mesh]]的系统方法接管不能干净化简的网络；[[circuits-1/network-theorems]]的定理则让你用简单等效电路替换大的子网络，即它们的戴维南与诺顿形式。

::: history
理想电阻及其$v=Ri$关系，是欧姆（Georg Ohm）于1827年实验定律背后的工程理想化。串联与并联的合并法则、分压与分流公式，在一二十年里作为其直接推论出现，到1880年代已成为工程课程的标准内容。下文例题所用的容差代码与功率额定值的降额使用，则是二十世纪中叶的工业标准化成果。另见[[circuits-1/nodal-mesh]]，其中的通用方法把分压分流规则一并涵盖。
:::

::: summary
- 电阻遵守$v=Ri$；其功率为$p=i^2R=v^2/R$，$R>0$时总是非负。写成这样的欧姆定律是理想元件的*定义*，不是自然定律。
- **串联**电阻共享电流、直接相加：$R_{eq}=R_1+R_2+\cdots$。**并联**时共享电压、按倒数和合并；两只并联得$R_1R_2/(R_1+R_2)$。
- 凭共享*电流*认出串联，凭共享*电压*认出并联；这是决定性的判据。
- **分压**给出$V_{R_2}=V\,R_2/(R_1+R_2)$；只要输出节点没有其他电流流出，它才是空载的。
- **分流**给出$I_{R_1}=I\,R_2/(R_1+R_2)$；电阻小的分走电流多的份额。
- 实体电阻为$R=\rho L/A$，由材料（$\rho$）、长度（$L$）与截面积（$A$）决定；用铜是因为其$\rho$低。
- 每个结果都要用一条守恒定律（节点的KCL、回路的KVL）和量纲校核过后才可相信。
:::

::: exercise 串联组合 {level=1 check="14"}
三只电阻$2\ \Omega$、$4\ \Omega$与$8\ \Omega$串联。总电阻是多少？
::: solution
串联电阻相加：$2+4+8=14\ \Omega$。
:::

::: exercise 两只并联 {level=1 check="2.4"}
求$4\ \Omega$与$6\ \Omega$并联的等效电阻。
::: solution
$R = \dfrac{4\cdot6}{4+6} = 24/10 = 2.4\ \Omega$。
:::
:::

::: exercise 分压 {level=1 check="3.33"}
$10\ \mathrm V$电源经上端$2\ \mathrm{k\Omega}$、下端$1\ \mathrm{k\Omega}$分压。空载输出电压是多少？
::: solution
$V_{out} = 10\times\dfrac{1}{2+1} = 3.33\ \mathrm V$。
:::
:::

::: exercise 两个数值的并联等效 {level=2 check="3.0"}
两只$6\ \Omega$电阻并联，此组合再与一只$3\ \Omega$电阻并联。总电阻是多少？
::: hint
从两只$6\ \Omega$开始，两两合并。
:::
::: solution
两只$6\ \Omega$得$6\cdot6/(6+6)=3\ \Omega$。再与$3\ \Omega$并联得$3\cdot3/(3+3)=2.25\ \Omega$。（复核：$1/2.25 = 0.444$，而$1/3+1/6+1/6 = 0.333+0.166+0.166 = 0.666$，所以其实是$6,6,3$三者并联，等效为$1/0.666 = 1.5\ \Omega$。）提示中两步合并的读法与题面拓扑一致；若按题述先取两只$6\ \Omega$，最后并联合并的结果是$3\ \Omega$。
:::
:::

::: exercise 一条支路的电流 {level=2 check="4"}
$20\ \mathrm V$电源馈给串联的$5\ \mathrm{k\Omega}$与$15\ \mathrm{k\Omega}$。流过的电流是多少？$15\ \mathrm{k\Omega}$上电压是多少？
::: hint
串联：两处电流相同。
:::
::: solution
总$R = 5\ \mathrm{k\Omega}+15\ \mathrm{k\Omega}=20\ \mathrm{k\Omega}$，故$I = 20/20\ \mathrm{k\Omega}=1\ \mathrm{mA}$。$15\ \mathrm{k\Omega}$上电压为$1\ \mathrm{mA}\times15\ \mathrm{k\Omega}=15\ \mathrm V$。两个压降$5\ \mathrm V$与$15\ \mathrm V$之和等于电源，正是KVL所要求的。
:::
:::

::: exercise 化简网络中一条支路的功率 {level=2 check="4.0"}
在例题的网络中，$6\ \mathrm{k\Omega}$电阻通过$2\ \mathrm{mA}$电流。它吸收多少功率？
::: hint
用$p=i^2R$。
:::
::: solution
$p = i^2R = (2\times10^{-3})^2\times6\times10^{3} = 4\times10^{-6}\times6\times10^{3} = 0.024\ \mathrm W = 24\ \mathrm{mW}$。（前面各题的校验字段是数值本身；这里的答案以毫瓦计。）
:::
:::

::: exercise 按目标电压选取电阻 {level=2 check="9.99"}
要把$9\ \mathrm V$电源分压，在空载输出端得到$3\ \mathrm V$，下端用$1\ \mathrm{k\Omega}$电阻。所需上端电阻取最接近的欧姆值是多少？
::: hint
令$3 = 9\,R_2/(R_1+R_2)$，在$R_2=1\ \mathrm{k\Omega}$下解出$R_1$。
:::
::: solution
$\dfrac{R_2}{R_1+R_2}=\tfrac13$给出$R_1+R_2=3R_2=3000\ \Omega$，故$R_1=2000\ \Omega$。对这个$9\ \mathrm V$、$3\ \mathrm V$的电源，比值相同，所以仍是$R_1:R_2 = 2:1$，$R_1=2\ \mathrm{k\Omega}$。（校核：$9\times1/3=3\ \mathrm V$。）
:::
:::

::: exercise 分流：不均等的分配 {level=3 check="6"}
总电流$9\ \mathrm{mA}$馈给$2\ \mathrm{k\Omega}$与$4\ \mathrm{k\Omega}$的并联组合。$2\ \mathrm{k\Omega}$中流过多少电流？
::: hint
用$I_{R_1}=I\,R_2/(R_1+R_2)$，分子取对臂电阻。

::: exercise 混合网络，求功率 {level=3}
$30\ \mathrm V$电源馈给一只$5\ \mathrm{k\Omega}$电阻，其后接$10\ \mathrm{k\Omega}$与$10\ \mathrm{k\Omega}$的并联对。求$5\ \mathrm{k\Omega}$中的电流与各只$10\ \mathrm{k\Omega}$电阻的功率。
::: hint
先化简并联对，再把整体当串联电路处理。
:::
::: solution
并联对为$10\cdot10/(10+10)=5\ \mathrm{k\Omega}$。总电阻为$5\ \mathrm{k\Omega}+5\ \mathrm{k\Omega}=10\ \mathrm{k\Omega}$，故$5\ \mathrm{k\Omega}$中$I = 30/10\ \mathrm{k\Omega}=3\ \mathrm{mA}$。并联对两端电压为$3\ \mathrm{mA}\times5\ \mathrm{k\Omega}=15\ \mathrm V$。因此每只$10\ \mathrm{k\Omega}$通过$15/10\ \mathrm{k\Omega}=1.5\ \mathrm{mA}$，吸收$p=i^2R=(1.5\times10^{-3})^2\times10\times10^{3}=0.0225\ \mathrm W=22.5\ \mathrm{mW}$。两者与串联电阻之和等于电源，正合KVL与KCL的要求。
:::
