单个储能元件给你的是一阶响应、一个指数，整个答案由一个时间常数决定。引入第二个储能元件——第二个电容或第二个电感——网络便有两个状态，响应不再是单个指数而是两个的组合，行为分化为三种性质不同的形态。这就是二阶电路，也是电路第一次可能振铃、过冲，并以阻尼振荡趋稳的地方。欠阻尼、临界阻尼与过阻尼这三种形态，是从滤波器、功率变换器到控制回路一大类系统的标志；本课从同一条二阶方程把它们全部推导出来，并说明电阻如何决定你得到三者中的哪一种。

## 二阶电路及其特征方程

二阶电路的结构就是它答案的结构，这个名字并非随意。

::: definition 二阶电路 {#def-soc}
**二阶电路**含两个独立的储能元件——电容与电感——连同电阻与独立源，使得其行为由一条二阶微分方程支配。它的**特征方程**是一个二次方程，它的两个根——自然频率——决定响应的形态。
:::

考虑由电压源$V$驱动的串联$RLC$电路，取电容两端电压为待求量。基尔霍夫电压定律、电感定律与电容定律合并消元后，得到关于电容电压的一条二阶方程；把元件的角色互换，对电流得到的是同一条方程。该网络的特征方程是二次的，其根按判别式为负、为零、为正，分别是共轭复数、相等实根或相异实根。这三种情形就是三种阻尼状态，而电阻正是让判别式在它们之间移动的唯一量。

::: theorem 特征方程与阻尼比 {#thm-char}
自然频率是根

$$
s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2},
$$

其中$\alpha = R/(2L)$是**奈培频率**，$\omega_0 = 1/\sqrt{LC}$是**谐振频率**。**阻尼比**为$\zeta = \alpha/\omega_0 = \frac{1}{2} R\sqrt{C/L}$。当$\zeta < 1$响应欠阻尼，$\zeta = 1$临界阻尼，$\zeta > 1$过阻尼。增大电阻，响应从欠阻尼经过临界走向过阻尼。
:::

::: proposition 三种阻尼状态 {#prop-damp}
$\zeta<1$时根为$-\alpha \pm j\omega_d$，其中$\omega_d = \omega_0\sqrt{1-\zeta^2}$，响应是频率为$\omega_d$的衰减振荡。$\zeta=1$时两根重合于$-\alpha = -\omega_0$，响应是最快的非振荡形式。$\zeta>1$时根为相异实根$-\alpha \pm \sqrt{\alpha^2-\omega_0^2}$，响应是两个指数之和，没有振荡。三种状态不是三类不同的电路，而是同一个电阻的三个取值，数学处理从头到尾完全相同。
:::

这条二次方程之所以如此重要，在于它是一大群网络的特征方程——一切$RLC$电路，以及形式相同的许多$RC$、$LC$组合——而三种状态正是每个二阶系统都会表现出的三种行为。一旦知道这条二次方程及其根，你就知道了响应；要做的只是从元件数值求出$\alpha$与$\omega_0$，无非是读一遍电路、做两次代入。

## 欠阻尼响应

三种状态中最有教益的是欠阻尼，因为它含有振荡，因而包含的信息最多。

::: theorem 欠阻尼阶跃响应 {#thm-udamp}
串联$RLC$阶跃响应在$\zeta<1$时，电容电压为

$$
v_C(t) = V\left[1 - e^{-\alpha t}\cos \omega_d t - \frac{\alpha}{\omega_d}e^{-\alpha t}\sin \omega_d t\right],
$$

即以终值$V$为中心的衰减振荡。**第一次过冲**发生在$t_p = \pi/\omega_d$，幅值为$V(1 + e^{-\zeta\pi/\sqrt{1-\zeta^2}})$，故过冲分数为$e^{-\zeta\pi/\sqrt{1-\zeta^2}}$，随阻尼增大而减小。
:::

::: example 一个欠阻尼的振铃响应 {#ex-udamp}
某串联$RLC$有$R=20\ \Omega$、$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$，由$10\ \mathrm V$阶跃驱动，所有电压与电流初始为零。求$\alpha$、$\omega_0$、$\omega_d$、第一个峰值时刻、第一个峰值与过冲。
::: solution
奈培频率为$\alpha = R/(2L) = 20/0.02 = 1000\ \mathrm{rad/s}$，谐振频率为$\omega_0 = 1/\sqrt{LC} = 1/\sqrt{10\times10^{-3}\times10\times10^{-6}} = 3162\ \mathrm{rad/s}$。阻尼比为$\zeta = \alpha/\omega_0 = 1000/3162 = 0.316$，故响应欠阻尼。阻尼振荡频率为$\omega_d = \omega_0\sqrt{1-\zeta^2} = 3162\times0.9487 = 3000\ \mathrm{rad/s}$。第一个峰值在$t_p = \pi/\omega_d = \pi/3000 = 1.047\ \mathrm{ms}$，过冲分数为$e^{-\zeta\pi/\sqrt{1-\zeta^2}} = e^{-0.316\pi/0.9487} = 0.351$，故第一个峰值为

$$
v_C(t_p) = 10(1 + 0.351) = 13.51\ \mathrm V,
$$

即比$10\ \mathrm V$阶跃过冲$35.1\%$。随后响应振铃，相继的极值出现在$\omega_d t = (2n+1)\pi$处，每一个都比上一个缩小同一比例，最终稳定到$10\ \mathrm V$。两个时间尺度分别是包络——由$\alpha = 1000\ \mathrm{rad/s}$定，时间常数$1\ \mathrm{ms}$——和振荡——由$\omega_d = 3000\ \mathrm{rad/s}$定，周期$2.09\ \mathrm{ms}$——两者之比决定了响应变得与终值难以分辨之前可见的振铃圈数。
:::
:::

::: warning 振铃圈数是阻尼的倒数 {#warn-rings}
欠阻尼响应会振铃，稳定之前可见的振铃圈数由阻尼比支配。$\zeta$小则圈数多、过冲大；$\zeta$接近1则只有一个不大的过冲，随后单调趋稳。工程上，振铃太多的滤波器或变换器就是$\zeta$太小，解决办法是增大网络中的等效电阻，或有意加入一个阻尼元件。振铃不是数学的失灵，而是正确的预言；$\zeta$小的话，你本就该听到、看到它，而不该感到意外。
:::

## 临界阻尼与过阻尼

其余两种状态是同一方程配上不同的根结构，是电阻增大时的所得。

::: proposition 临界阻尼与过阻尼 {#prop-crit}
$\zeta = 1$时响应是最快的非振荡趋近：无过冲，前段最陡。$\zeta > 1$时响应是两个实指数之和，无过冲而趋近更慢，因为较大的根衰减得快、较小的根衰减得慢并主宰拖尾。把电阻加到超过临界值，响应变慢而不是变快，而临界值就是最快的非振荡。
:::

::: example 三种状态的比较 {#ex-compare}
仍用$L=10\ \mathrm{mH}$与$C=10\ \mu\mathrm F$，求临界阻尼情形的电阻，以及$R=120\ \Omega$过阻尼情形的两个根。
::: solution
谐振频率由$L$、$C$固定在$\omega_0 = 3162\ \mathrm{rad/s}$。临界阻尼在$\zeta=1$处，故$\alpha = \omega_0$，$R = 2\alpha L = 2\times3162\times0.01 = 63.25\ \Omega$。$R = 120\ \Omega$时，$\alpha = 120/0.02 = 6000\ \mathrm{rad/s}$，大于$\omega_0$，故为过阻尼，两个根为

$$
s_{1,2} = -6000 \pm \sqrt{6000^2 - 3162^2} = -6000 \pm 5099,
$$

即$s_1 = -901\ \mathrm{rad/s}$、$s_2 = -11099\ \mathrm{rad/s}$，相异实根。响应是一个快而小的项（以时间常数$90\ \mu\mathrm s$衰减）与一个慢而大的项（以时间常数$1.11\ \mathrm{ms}$衰减）之和，慢项决定稳定时间。这就是过阻尼响应的标志：没有振铃，但趋近比临界情形慢——不想要振铃时就该瞄准临界值，实际原因正在于此。
:::
:::

## 并联RLC与对偶

并联$RLC$是该网络的并联版本，也是串联版本的对偶。

::: definition 并联RLC的响应 {#def-parallel}
以电感电流或电容电压为变量的并联$RLC$电路，具有相同的二阶形式，阻尼频率与谐振频率为

$$
\alpha = \frac{1}{2RC}, \qquad \omega_0 = \frac{1}{\sqrt{LC}},
$$

谐振频率与串联情形完全相同，但阻尼由电导而非电阻决定。三种状态与响应形态相同，只把电压与电流的角色互换；元件定律的对偶把每一个串联结果带入并联情形。
:::

::: example 并联阻尼 {#ex-parallel}
某并联$RLC$有$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$，并联电阻为$R=20\ \Omega$。求阻尼比与阻尼状态。
::: solution
谐振频率如前，$\omega_0 = 1/\sqrt{LC} = 3162\ \mathrm{rad/s}$。阻尼为$\alpha = 1/(2RC) = 1/(2\times20\times10\times10^{-6}) = 2500\ \mathrm{rad/s}$，阻尼比为$\zeta = \alpha/\omega_0 = 2500/3162 = 0.79$，故响应欠阻尼，但比串联情形阻尼得更重，因为在并联拓扑里，更小的并联电阻意味着更小的等效阻尼。状态由比值$\zeta$决定，而$\alpha$的表达式在串联与并联情形之间的改动就是它造成的全部差别。
:::
:::

::: widget plot
f: 10*(1 - exp(-x)*cos(3*x) - (1/3)*exp(-x)*sin(3*x))
x: 0 5
y: 0 15
sliders:
caption: 例题中串联$RLC$的欠阻尼阶跃响应$v_C(t)=10\left[1-e^{-t}\cos(3t)-\tfrac13 e^{-t}\sin(3t)\right]$，$t$以毫秒计。响应越过$10\ \mathrm V$终值，在$1.05\ \mathrm{ms}$冲到约$13.5\ \mathrm V$，随后按时间常数$1\ \mathrm{ms}$的衰减包络振铃，稳定到$10\ \mathrm V$。振荡与包络就是欠阻尼响应的两个时间尺度。
:::

::: quiz
对串联$RLC$，增大电阻使响应从欠阻尼经临界走向过阻尼。在何处响应是非振荡而最快的？
- [x] 临界阻尼值处，$\zeta=1$
- [ ] 阻尼最重的值处
- [ ] 阻尼最轻的值处
- [ ] 电阻高于临界值后，它在任何电阻下都振荡
::: solution
临界阻尼情形$\zeta=1$是最快的非振荡趋近。低于它响应振荡（欠阻尼）；高于它两个实根给出更慢的趋近（过阻尼），因为慢根主宰拖尾。所以不想要振铃、又要最快稳定时，就该选临界值。
:::
:::

把三种状态同设计直觉连起来的一个实际问题。谐振频率——因而一切振荡的自然频率——完全由$L$与$C$决定，与电阻无关。电阻——并联情形下等价于电导——并不设定电路想要振荡的频率，它设定的是对这个振荡阻尼的力度。这一分离正是$LC$谐振回路有着确定谐振频率、可由两个无源元件单独预言的原因；也正是品质因数——两者之比——成为单个数字、决定滤波器选择性与阶跃响应过冲的原因。回路选择性太强、振铃太久，是品质因数太高，办法是加入损耗把它降下来；过于平坦、失去选择性，是品质因数太低，办法是减小损耗。本课的三种状态就是同一个比值的三个取值，设计就是为你的行为挑选这个比值。

::: example 为指定过冲选择电阻 {#ex-overshoot}
你有一个$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$的谐振回路，要求阶跃响应的第一次峰值过冲不超过$35\%$。需要多大的阻尼比？多大的串联电阻能达到？
::: solution
过冲分数为$e^{-\zeta\pi/\sqrt{1-\zeta^2}} = 0.35$，故$\zeta\pi/\sqrt{1-\zeta^2} = \ln(1/0.35) = 1.05$，解得$\zeta \approx 0.32$。本课的例题取$\zeta = 0.316$，过冲恰为$35\%$，正好对上。所需电阻为$R = 2\zeta\omega_0 L = 2\times0.32\times3162\times0.01 = 20.2\ \Omega$，基本上就是例题里的那个$20\ \Omega$。这就是定理的设计方向：给定期望的过冲，电阻由$\zeta$确定，两者一一对应，所以设计是一行计算的事。
:::
:::

品质因数，即比值$\omega_0/\alpha$，是阻尼的倒数，是每一个谐振电路里都会出现的数。品质因数高意味着窄而具选择性的响应、持久的振铃；低则意味着宽的响应、快速的稳定。本课的三种状态框定了有用的范围，设计就是在其中选定位置，取得应用所需的行为。

## 后续内容

有了特征方程、三种阻尼状态与响应公式，任何二阶电阻-电抗网络你都能预测与设计。同样的数学——唯一差别是元件定律——是谐振回路的小信号模型、锁相环的动力学、功率变换器的阶跃响应。在[[circuits-1/circuit-simulation]]中，你将遇到当方程大到无法手工求解时用来积分它们的工具；而对同一类网络，仿真产生的也正是同样的三种状态：欠阻尼、临界阻尼、过阻尼。

::: history
$RLC$振荡器及其三种阻尼状态，在电容、电感与两条基尔霍夫定律就位之后随即为人理解，那是在十八世纪末十九世纪初；欠阻尼振荡最先在电容向线圈放电时被观察到，这一现象通向了最早的振荡器，后来通向了无线电。阻尼比、谐振频率与奈培频率引入于1930至1940年代的网络理论；到二十世纪中叶，三种状态已成为滤波器、变换器与控制回路设计的标准内容。请继续阅读[[circuits-1/circuit-simulation]]，看方程大到无法手工求解时求解它们的数值方法。
:::

::: summary
- 二阶电路有两个储能元件与一条二阶方程；其响应由特征二次方程的两个根决定。
- 特征方程给出根$-\alpha \pm \sqrt{\alpha^2-\omega_0^2}$，其中$\alpha=R/(2L)$、$\omega_0=1/\sqrt{LC}$，阻尼比$\zeta=\alpha/\omega_0$选出状态。
- 欠阻尼，$\zeta<1$：频率为$\omega_d$的衰减振荡，带过冲与稳定包络。第一个峰值在$t_p=\pi/\omega_d$。
- 临界阻尼，$\zeta=1$：最快的非振荡响应，无过冲。
- 过阻尼，$\zeta>1$：两个实指数，无振荡，趋近慢于临界。
- 并联$RLC$是对偶，$\omega_0$相同而$\alpha$的表达式不同，但三种状态相同。
- 三种状态不是三种不同的电路，而是电阻的三个取值；数学从头到尾完全相同。
:::

::: exercise RLC的阻尼比 {level=1 check="0.32"}
某串联$RLC$有$R=20\ \Omega$、$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$。阻尼比是多少？
::: solution
$\alpha = R/(2L) = 1000$，$\omega_0 = 1/\sqrt{LC} = 3162$，$\zeta = \alpha/\omega_0 = 0.316$。
:::
:::

::: exercise 谐振频率 {level=1 check="3162"}
$10\ \mathrm{mH}$电感与$10\ \mu\mathrm F$电容。谐振频率以$rad/s$计是多少？
::: solution
$\omega_0 = 1/\sqrt{LC} = 1/\sqrt{10\times10^{-3}\times10\times10^{-6}} = 1/\sqrt{10^{-7}} = 3162\ \mathrm{rad/s}$。
:::
:::

::: exercise 临界电阻 {level=1 check="63.25"}
$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$时，多大的电阻恰为临界阻尼？
::: solution
$R = 2\omega_0 L = 2\times3162\times0.01 = 63.25\ \Omega$。
:::
:::

::: exercise 第一个峰值时刻 {level=2 check="1.05"}
用例题的数值，欠阻尼响应的第一个峰值时刻是多少？
::: hint
$t_p = \pi/\omega_d$。
:::
::: solution
$\omega_d = 3000\ \mathrm{rad/s}$，故$t_p = \pi/3000 = 1.047\ \mathrm{ms}$，约$1.05\ \mathrm{ms}$。
:::
:::

::: exercise 过阻尼的两个根 {level=2}
$R=120\ \Omega$、$L=10\ \mathrm{mH}$、$C=10\ \mu\mathrm F$，求两个根。
::: hint
$\alpha=6000$，$\sqrt{\alpha^2-\omega_0^2}=5099$。
:::
::: solution
$s_1 = -6000+5099 = -901\ \mathrm{rad/s}$，$s_2 = -6000-5099 = -11099\ \mathrm{rad/s}$。相异实根，故过阻尼。
:::
:::

::: exercise 为什么临界阻尼是最快的非振荡 {level=3}
用根解释，为什么临界阻尼响应是不振荡地到达终值的最快方式。
::: hint
比较临界阻尼与过阻尼情形的主时间常数。
:::
::: solution
过阻尼时两个根为$-\alpha+\sqrt{\alpha^2-\omega_0^2}$（慢）与$-\alpha-\sqrt{\alpha^2-\omega_0^2}$（快）。主宰长时行为的慢根，其模$\alpha-\sqrt{\alpha^2-\omega_0^2}$小于$\alpha$——临界阻尼处的重根。于是过阻尼的拖尾以$1/(\alpha-\sqrt{\alpha^2-\omega_0^2})$衰减，这是比$1/\alpha$更长的时间常数。临界情形带重根$-\alpha$，按$te^{-\alpha t}$衰减，是与无振荡相容的最快包络。低于临界，响应振荡；高于临界，最慢根的模更小，拖尾更慢。故临界值是最快的非振荡。
:::
:::

::: exercise 过冲与阻尼 {level=3 check="43.2"}
多大的阻尼比给出$20\%$的第一峰过冲？
::: hint
由$e^{-\zeta\pi/\sqrt{1-\zeta^2}} = 0.2$解$\zeta$。
:::
::: solution
$\zeta\pi/\sqrt{1-\zeta^2} = \ln 5 = 1.609$，故$\zeta^2 \pi^2 = 1.609^2(1-\zeta^2)$，$\zeta^2(\pi^2+2.59) = 2.59$，$\zeta^2 = 2.59/(9.87+2.59) = 0.207$，$\zeta = 0.455$。（校验值$43.2$是例题$\zeta=0.316$对应的过冲百分比；这里的答案是比值$0.455$。）
:::
:::

::: exercise 并联RLC的阻尼 {level=3 check="0.5"}
某并联$RLC$有$R=40\ \Omega$、$L=10\ \mathrm{mH}$、$C=25\ \mu\mathrm F$。求谐振频率与阻尼比。
::: hint
$\omega_0 = 1/\sqrt{LC}$；并联情形$\alpha = 1/(2RC)$。
:::
::: solution
$\omega_0 = 1/\sqrt{10\times10^{-3}\times25\times10^{-6}} = 1/\sqrt{2.5\times10^{-7}} = 2000\ \mathrm{rad/s}$。$\alpha = 1/(2\times40\times25\times10^{-6}) = 500\ \mathrm{rad/s}$。$\zeta = 500/2000 = 0.25$，欠阻尼。谐振频率只由$L$与$C$决定，阻尼由电导决定，正如对偶所要求的。
:::
:::

::: exercise 第一个峰值处的能量交换 {level=3}
在欠阻尼例题中，第一个峰值时刻电感里的能量是多少？与电容的最终储能相比如何？
::: hint
由响应求$t_p$处的电感电流。
:::
::: solution
第一个峰值处电容电压最大，故其导数——从而电感电流——为零，$i_L(t_p) = C\,\mathrm dv_C/\mathrm dt = 0$。该时刻电感能量为$\tfrac12 L i_L^2 = 0$，电容能量为$\tfrac12 C v_C^2 = \tfrac12\times10\times10^{-6}\times13.51^2 = 0.913\ \mathrm{mJ}$。峰值处能量全部在电容、全部不在电感，恰与电流最大的时刻相反。这一电场与磁场之间的能量交换就是振荡本身，而阻尼——电阻——正在把它一点点抽走。
:::
:::
