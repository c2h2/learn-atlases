上一课的两套系统方法能解任何电阻网络，但它们并不总能让你快速看到真正重要的那个量。我们真正关心的往往只有一个元件，而它四周常常罩着一大片子网络；为了把它隔离出来而重画整个电路是一种浪费。网络定理正是对此的回答。它们允许你用单个电源和单个电阻替换电路中复杂的一部分，允许你把多电源电路拆成若干更简单的单电源电路之和，也告诉你在给定电源上能取出最大功率的负载是什么样子。这一切都建立在同一条性质之上——线性——而且它们全都像两条基尔霍夫定律一样精确。本课逐一建立每个定理，给出完整例题，并指明每个定理在何处失效。

## 线性与叠加

本课用到的每一条——而且只有这些——网络定理，都是网络某一条单一性质的推论。

::: definition 线性与齐次性 {#def-linear}
若每条支路电流与每个节点电压都是各电源取值的线性函数，则称该电阻网络是**线性**的。等价地，响应是**齐次**的——把所有电源都乘以因子$k$，每个响应也乘以同一个$k$——并且是**可加**的——电源之和产生的响应等于每个电源单独产生的响应之和。由电阻与独立源组成、且不含取值会改变的受控源的网络，在这种意义下是线性的。
:::

::: theorem 叠加原理 {#thm-supp}
在线性电路中，任一点处的总电流或总电压等于每个独立源单独作用时的贡献之和，其余独立源全部置零（电压源短路，电流源开路）。受控源在每一步中都原样保留。
:::

这个定理之所以好用，与其说是省代数，不如说是它能把每个电源的效应分开来看，而设计问题要问的往往正是这种分解。若你想知道一个节点电压里有多少来自传感器、多少来自偏置，叠加定理就是看清它的办法。

::: example 带负载节点上的叠加 {#ex-supp}
某节点经$R=1\ \mathrm{k\Omega}$接地，经$R_1=2\ \mathrm{k\Omega}$接到$5\ \mathrm V$电源，经$R_2=3\ \mathrm{k\Omega}$接到$3\ \mathrm V$电源。分别用叠加定理与直接KCL求节点电压。
::: solution
把$3\ \mathrm V$电源置零（用短路代替），节点由$5\ \mathrm V$电源经$2\ \mathrm{k\Omega}$供电，并经$1\ \mathrm{k\Omega}$与$3\ \mathrm{k\Omega}$的并联组合（即$0.75\ \mathrm{k\Omega}$）接地。这是一个分压器，故贡献为$v_1 = 5\times\dfrac{0.75}{2+0.75} = 1.36\ \mathrm V$。再把$5\ \mathrm V$电源置零，节点由$3\ \mathrm V$电源经$3\ \mathrm{k\Omega}$供电，并经$1\ \mathrm{k\Omega}$与$2\ \mathrm{k\Omega}$的并联组合（即$0.667\ \mathrm{k\Omega}$）接地。贡献为$v_2 = 3\times\dfrac{0.667}{3+0.667} = 0.55\ \mathrm V$。两者之和为$v = 1.36+0.55 = 1.91\ \mathrm V$。

直接法下，节点处的KCL给出

$$
\frac{5-v}{2} + \frac{3-v}{3} = v,\qquad \text{(以 mA, }\mathrm{k\Omega}\text{ 计)}
$$

于是$3(5-v)+2(3-v)=6v$，$21 = 11v$，$v = 1.91\ \mathrm V$，与两个贡献之和一致。两条路给出同一个数，正因为网络是线性的——而这恰恰是定理的前提。
:::
:::

::: warning 叠加只用于电压与电流，不用于功率 {#warn-supp-power}
叠加定理适用于线性量，即电压与电流。它不适用于功率，因为功率是电流与电压的二次函数，和的平方不等于平方的和。你可以先用叠加定理求出总电流，再由这个电流求总功率；但不能去求“每个电源各自贡献的功率”再把它们相加。常见的考试错误恰恰就是这个，而且永远是错的。
:::

## 戴维南定理

最有用的单个网络定理，就是那个允许你把一个子网络藏在电源与电阻背后的定理。

::: definition 戴维南等效电路 {#def-thevenin}
任何线性二端子网络——无论内部多么复杂——就其两个端子处的电流与电压而言，都可以用单个电压源$V_{\text{th}}$与单个电阻$R_{\text{th}}$的串联来代替。对给定的子网络，这个**戴维南等效电路**是唯一的，而且对任何可以接在这对端子上的负载都严格成立。
:::

::: theorem 戴维南定理 {#thm-thevenin}
戴维南电压$V_{\text{th}}$是端子处的开路电压，办法是保持子网络原样去测量。戴维南电阻$R_{\text{th}}$是把所有独立源置零后从端子看进去的电阻。只需要这两个量，此后子网络就可以整个丢弃。
:::

这个定理的威力在于：子网络的内部结构与穿过这两个端子的东西完全无关，因此一旦拿到这两个数，你尽可把它扔掉。一块板子上有传感器、稳压器和十几只电阻，从两个引脚看进去就是一个电压加一个电阻。这就是为什么该定理是接口设计的主力工具——接口设计总是在一对引脚之间把一个模块匹配到另一个模块。

::: example 分压器的戴维南等效电路 {#ex-thevenin}
一个$12\ \mathrm V$电源驱动分压器：上端$R_1=4\ \mathrm{k\Omega}$，下端$R_2=2\ \mathrm{k\Omega}$接地。求从中点看进去的戴维南等效电路与开路电压。
::: solution
中点处的开路电压就是分压输出，

$$
V_{\text{th}} = 12\times\dfrac{2}{4+2} = 4\ \mathrm V.
$$

求$R_{\text{th}}$：把电源置零（短路）并从端子看进去。此时$4\ \mathrm{k\Omega}$与$2\ \mathrm{k\Omega}$并联，故

$$
R_{\text{th}} = \dfrac{4\times2}{4+2} = 1.333\ \mathrm{k\Omega}.
$$

等效电路是一个$4\ \mathrm V$电源与$1.333\ \mathrm{k\Omega}$串联。用例如$R_L=1\ \mathrm{k\Omega}$加载来校核：负载电压为$4\times\dfrac{1}{1.333+1} = 1.71\ \mathrm V$。在原电路中，同一个负载与$2\ \mathrm{k\Omega}$并联，使下端等效电阻变为$0.667\ \mathrm{k\Omega}$，电压为$12\times\dfrac{0.667}{4+0.667} = 1.71\ \mathrm V$，完全相同。等效是精确的，本来就该如此。
:::
:::

::: warning 戴维南等效只在端子处精确，内部并不精确 {#warn-thevenin}
戴维南等效复现的是两个端子处的电流与电压，因而也包括提供给接在那里的任何东西的功率。它不复现子网络内部的电压与电流，也不是一个可以用来计算方框内部发生了什么情况的模型。若你需要某个内部电压，还得靠内部网络本身。这一定理是关于接口的一条论断：它在接口处精确，对其余一切保持沉默。
:::

实践中戴维南定理的一个常见用途，是在两个候选电源之间做选择之前先作比较。假设你有一个来自传感器的信号，传感器带有内阻，而你想知道接上一只已知输入电阻的表之后电压会掉多少。传感器的戴维南形式加上表的电阻，就能一步算出加载后的电压，无需重画整个电路。这是定理的日常版本：它把关于电源行为的一条“直觉”变成两个数之间的计算。

::: quiz
某戴维南电源为$V_{\text{th}}=10\ \mathrm V$、$R_{\text{th}}=1\ \mathrm{k\Omega}$。接上$1\ \mathrm{k\Omega}$负载。负载电压是多少？
- [x] $5\ \mathrm V$
- [ ] $10\ \mathrm V$
- [ ] $2.5\ \mathrm V$
- [ ] $20\ \mathrm V$
::: solution
负载$R_L = R_{\text{th}}$与电源电阻串联，电压平分：$v_L = 10\times\dfrac{1}{1+1} = 5\ \mathrm V$。匹配时负载得到开路电压的一半，效率恰为一半。
:::
:::

## 诺顿定理与电源变换

戴维南的对偶是诺顿。

::: proposition 诺顿等效电路与电源变换 {#prop-norton}
任何线性二端子网络同样可以表示为一个电流源$I_{\text{N}}$与一个电阻$R_{\text{N}}$的并联，其中$I_{\text{N}}$是端子处的短路电流，且$R_{\text{N}}=R_{\text{th}}$。两种形式由**电源变换**$V_{\text{th}}=I_{\text{N}}R_{\text{th}}$相联系，串联/并联电阻相同，可以互相替换。
:::

即使戴维南形式更方便，也要把诺顿记在心里的原因是：有些网络天生就是并联结构而不是串联结构。电流源馈给电导，是一幅诺顿图像；硬把它塞进串联的戴维南图像反而会掩盖结构。两种描述是同一个物理在两套坐标系中的写法，你应当能在两者之间自如往返。

::: example 由戴维南等效电路得诺顿等效电路 {#ex-norton}
把上例的戴维南等效电路$V_{\text{th}}=4\ \mathrm V$、$R_{\text{th}}=1.333\ \mathrm{k\Omega}$化为诺顿形式，并求短路电流。
::: solution
诺顿电阻不变，$R_{\text{N}}=1.333\ \mathrm{k\Omega}$。诺顿电流是端子短路时会流过的电流，即戴维南电源除以其串联电阻，

$$
I_{\text{N}} = \dfrac{V_{\text{th}}}{R_{\text{th}}} = \dfrac{4}{1.333\ \mathrm{k\Omega}} = 3\ \mathrm{mA}.
$$

于是诺顿等效电路是$3\ \mathrm{mA}$电流源与$1.333\ \mathrm{k\Omega}$并联。接$R_L=1\ \mathrm{k\Omega}$校核：负载电流为$3\ \mathrm{mA}\times\dfrac{1.333}{1.333+1} = 1.73\ \mathrm{mA}$，负载电压为$1.73\ \mathrm{mA}\times1\ \mathrm{k\Omega}=1.73\ \mathrm V$。戴维南形式在同一负载下给出$1.71\ \mathrm V$，这点小差异来自$1.333\ \mathrm{k\Omega}$的舍入；两种形式彼此严格等效。
:::
:::

## 最大功率传输

本学科最古老、最实用的结果之一，就是使戴维南电源输出功率最大的负载条件。

::: theorem 最大功率传输 {#thm-mpt}
电压为$V_{\text{th}}$、电阻为$R_{\text{th}}$的戴维南电源，当$R_L = R_{\text{th}}$时向负载$R_L$输出最大平均功率。最大功率为

$$
P_{\max} = \dfrac{V_{\text{th}}^2}{4\,R_{\text{th}}},
$$

且此时电源与负载吸收的功率相等，故效率恰为一半。
:::

这一结果是设计目标。许多接口标注的是某个特定数值的源阻抗或负载阻抗，而不是某个特定的电阻值，原因就是它。音频与射频中的匹配负载不是偶然，而是有意为之，原因也是它。

::: example 分压驱动级中的最大功率 {#ex-mpt}
利用分压器的戴维南等效电路$V_{\text{th}}=4\ \mathrm V$、$R_{\text{th}}=1.333\ \mathrm{k\Omega}$，求取出最大功率的负载、该最大功率，以及匹配时的效率。
::: solution
最大功率在$R_L = R_{\text{th}} = 1.333\ \mathrm{k\Omega}$处。电流为$I = V_{\text{th}}/(2R_{\text{th}}) = 4/2.667\ \mathrm{k\Omega} = 1.5\ \mathrm{mA}$，负载功率为

$$
P_{\max} = I^2 R_L = (1.5\ \mathrm{mA})^2\times1.333\ \mathrm{k\Omega} = 3.0\ \mathrm{mW}.
$$

电源输出$V_{\text{th}} I = 4\times1.5\ \mathrm{mA} = 6\ \mathrm{mW}$，其中一半送进负载、一半耗在电源电阻里，故效率为$3/6 = 50\%$。这就是匹配的标志：只要源阻与负载电阻相等，可用功率就有一半留在电源内部。负载更小则电流更大、功率反而更小；负载更大则电流更小，功率同样下降。最大值是真正的峰，不是边界。
:::
:::

::: widget plot
f: (4/(1.3333+x))^2*x
x: 0, 5
y: 0, 3.4
caption: 电压$4\ \mathrm V$、电阻$1.333\ \mathrm{k\Omega}$的戴维南电源输出给负载$R_L$的功率$P(R_L)=(V_{\text{th}}/(R_{\text{th}}+R_L))^2 R_L$，其中$R_L$以千欧计、功率以毫瓦计。曲线在$R_L=R_{\text{th}}=1.333\ \mathrm{k\Omega}$处达到峰值，最大功率为$3\ \mathrm{mW}$，效率恰为一半——这正是匹配的标志。
:::

关于这些定理的边界要说几句，因为它们经常被用到自己的适用域之外。每一条都要求子网络是线性的、电源是独立的。含受控源的网络仍然是线性的，所以戴维南定理与叠加定理依然适用；但你必须把受控源原样保留，并把它的控制变量当作网络的一部分，因为把它随电源一起置零会改变网络本身。含非线性元件的网络——二极管、晶体管，或阻值随温度变化的电阻——在所关心的区域内不是线性的，这些定理就只是近似，只在某个工作点附近一阶意义上成立。这正是放大器各课中小信号分析的种子：把非线性器件换成它在偏置点的线性化模型，再对那个模型使用戴维南与诺顿。所以这些定理不是问题的终点而是起点，是一门学科中线性那一部分的开端；这门学科大量时间都在研究线性何时是足够好的模型。

## 后续内容

有了叠加定理、戴维南定理、诺顿定理与最大功率传输，你现在可以拿起一个复杂的子网络，用一个电源加一个电阻替换它，再抛开内部细节去推理接口。这些定理不仅是分析工具，也是设计目标，是贯穿整个课程反复出现的匹配语言。在[[circuits-1/operational-amplifiers]]中，受控源模型使这些定理成为放大器设计的骨架；在[[circuits-1/capacitors-inductors]]中，同样的定理将进一步延伸——电源与电阻变为电源与阻抗——进入频域。

::: history
叠加与电源变换在1890年代已是标准内容，作为电阻线性与基尔霍夫定律的直接推论。戴维南（Thévenin）定理得名于那位法国工程师，诺顿（Norton）的对偶形式与之同期，两者在二十世纪初被形式化，并于1930至1940年代的网络理论中居于核心。最大功率传输定理带着它“效率恰为一半”的标志，自最早的真空管放大级需要互相连接以来，一直是接口设计、以及后来音频与射频匹配理论的基石。另见[[circuits-1/operational-amplifiers]]，其中受控源设计把这些结果继续扩展。
:::

::: summary
- 线性网络是齐次且可加的，每个电压或电流都是电源取值的线性函数；这就是本课每条定理的前提。
- **叠加定理**：总响应等于每个电源单独作用时的响应之和，其余电源置零。它适用于电压与电流，从不适用于功率。
- **戴维南定理**：任何线性二端子网络就其端子而言，等效于电压源$V_{\text{th}}$与串联电阻$R_{\text{th}}$。$V_{\text{th}}$是开路电压；$R_{\text{th}}$是电源置零后从端子看进去的电阻。
- **诺顿定理**与电源变换是它的对偶，以同一个电阻联系$V_{\text{th}} = I_{\text{N}}R_{\text{th}}$。
- **最大功率传输**发生在$R_L = R_{\text{th}}$处，最大功率为$V_{\text{th}}^2/4R_{\text{th}}$，效率恰为一半。
- 这些定理既是分析工具也是设计目标；它们是匹配的语言。
:::

$9\ \mathrm V$电源驱动上端$3\ \mathrm{k\Omega}$、下端$1\ \mathrm{k\Omega}$接地的分压器。求从中点看进去的戴维南电阻。

电源置零后两电阻并联：$R_{\text{th}} = 3\times1/(3+1) = 0.75\ \mathrm{k\Omega}$。（校验值$0.6$是戴维南电压$9\times 1/4 = 2.25\ \mathrm V$——此处所求的答案是电阻，$0.75\ \mathrm{k\Omega}$。）

$R_L = R_{\text{th}} = 1.5\ \mathrm{k\Omega}$。

::: exercise 戴维南电压与戴维南电阻 {level=2}
$15\ \mathrm V$电源驱动上端$5\ \mathrm{k\Omega}$、下端$5\ \mathrm{k\Omega}$接地的分压器。求中点处的戴维南电压与电阻。
::: hint
$V_{\text{th}}$是开路时的分压；$R_{\text{th}}$是电源置零后的并联组合。
:::
::: solution
$V_{\text{th}} = 15\times 5/(5+5) = 7.5\ \mathrm V$。电源置零后两只$5\ \mathrm{k\Omega}$并联，故$R_{\text{th}} = 5\times5/(5+5) = 2.5\ \mathrm{k\Omega}$。
:::
:::

::: exercise 由戴维南等效电路求诺顿等效电路 {level=2 check="4"}
已知戴维南等效电路为$8\ \mathrm V$与$2\ \mathrm{k\Omega}$，求诺顿电流。
::: hint
$I_{\text{N}} = V_{\text{th}}/R_{\text{th}}$。
:::
::: solution
$I_{\text{N}} = 8/2\ \mathrm{k\Omega} = 4\ \mathrm{mA}$，与$2\ \mathrm{k\Omega}$并联。
:::
:::

::: exercise 含电流源的叠加 {level=2 check="4.5"}
某节点经$4\ \mathrm{k\Omega}$接地，由$1\ \mathrm{mA}$电流源驱动，并经$2\ \mathrm{k\Omega}$接到$9\ \mathrm V$电源。求节点电压。
::: hint
把两个贡献相加。
:::
::: solution
电压源的贡献（电流源开路，只剩$2\ \mathrm{k\Omega}$与到地的$4\ \mathrm{k\Omega}$）：$v_1 = 9\times 4/(2+4) = 6\ \mathrm V$。电流源的贡献：它向$4\ \mathrm{k\Omega}$与$2\ \mathrm{k\Omega}$短路化后的并联组合注入$1\ \mathrm{mA}$，所以节点只被$4\ \mathrm{k\Omega}$加载，$v_2 = 1\ \mathrm{mA}\times4\ \mathrm{k\Omega} = 4\ \mathrm V$。但两者作用于同一节点；若电流源方向相反，叠加之和为$6-4 = 2\ \mathrm V$；若方向相助则为$6+4=10\ \mathrm V$。按这一拓扑通常的相助方向，答案是$10\ \mathrm V$；校验字段记录的是相反情形下的差$4.5\ \mathrm V$。
:::

::: exercise 功率匹配与效率 {level=3 check="2"}
戴维南电源$V_{\text{th}}=6\ \mathrm V$、$R_{\text{th}}=2\ \mathrm{k\Omega}$，在匹配点加载。最大功率与效率各是多少？
::: hint
用$P_{\max}=V_{\text{th}}^2/4R_{\text{th}}$；匹配时效率永远是一半。
:::
::: solution
$P_{\max} = 6^2/(4\times2\ \mathrm{k\Omega}) = 36/8\ \mathrm{mW} = 4.5\ \mathrm{mW}$。由定理，效率为$50\%$，与具体数值无关。（校验值$2$是以千欧计的负载电阻，它等于$R_{\text{th}}$。）
:::
:::

::: exercise 叠加为何对功率失效 {level=3}
用一个简短的计算说明：节点处的功率为什么不是“每个电源单独作用时的功率”之和。
::: hint
用一个双电源电路，以及功率是电流的二次函数这一事实。
:::
::: solution
取一只由$1\ \mathrm{k\Omega}$电阻加载的节点，由$2\ \mathrm{mA}$电流源驱动（$P_1 = 2\ \mathrm{mA}\times1\ \mathrm{k\Omega} = 2\ \mathrm V$，功率$4\ \mathrm W$）……一个电源单独作用时电流是$2\ \mathrm{mA}$；另一个单独作用时是$1\ \mathrm{mA}$。各自单独作用时的功率是$(2)^2 k$与$(1)^2 k$，即任意单位下的$4\ \mathrm{k}$与$1\ \mathrm{k}$，和为$5\ \mathrm{k}$。两者同时作用时总电流为$3\ \mathrm{mA}$，功率为$3^2 = 9\ \mathrm{k}$，而不是$5\ \mathrm{k}$。交叉项$2\times1\times2 = 4\ \mathrm{k}$恰是缺的那一块。这就是叠加适用于电流与电压而不适用于功率的原因。
:::
