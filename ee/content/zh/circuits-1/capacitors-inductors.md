到目前为止，你遇到的元件要么在电阻里耗散能量，要么作为电源提供能量。两种不走这条路的元件——电容器与电感器——把能量存起来、稍后归还；正是储能让电路有了记忆、有了历史，有了取决于此前发生过什么的响应。给电阻网络加上电容或电感，你第一次拥有这样一个网络：它的电压与电流并非全由电源瞬时决定——这正是接下来两课暂态响应的全部来源。本课精确定义这两种元件，给出它们的伏安律、储能与串并联组合，并教你读出直流行为——一切暂态问题的起点。

## 电容器

电容器是两者中更基本的一个，它的定律也是你用得最多的一条。

::: definition 电容器及其伏安律 {#def-cap}
**电容器**把电荷储在被绝缘体隔开的两块导体上。它的**电容**$C$是一块极板上的电荷与两端电压之比，$C = q/v$，单位为法拉。其电流与电压满足

$$
i(t) = C\,\frac{\mathrm dv(t)}{\mathrm dt},
$$

电流与电压的变化率成正比。等价地，电压是电流的积分，

$$
v(t) = \frac{1}{C}\int^t i(\tau)\,\mathrm d\tau + v(t_0).
$$

电容的类阻抗行为由此而来：电压恒定时电流为零；电流恒定时电压线性变化。
:::

这条定律有两个你会不断碰到的特征。第一，电容对稳恒直流是**开路**：恒定的电压不产生电流，所以直流稳态下电容不取电流，把网络当作开路即可求解。第二，快速变化的电压驱动大电流，所以电容通高频、阻低频——这就是耦合与旁路的基础。两个特征是同一条方程$i=C\,\mathrm dv/\mathrm dt$在两个极限下的读法。

::: example 由变化的电压求电流 {#ex-cap}
一只$100\ \mu\mathrm F$电容两端的电压在$10\ \mathrm{ms}$内从$0$升到$5\ \mathrm V$。平均电流是多少？储存了多少能量？
::: solution
均匀上升时$\mathrm dv/\mathrm dt = 5/0.01 = 500\ \mathrm V/s$，故电流为$i = C\,\mathrm dv/\mathrm dt = 100\times10^{-6}\times500 = 50\ \mathrm{mA}$。储能为

$$
w = \frac{1}{2} C v^2 = \frac{1}{2}\times100\times10^{-6}\times25 = 1.25\ \mathrm{mJ}.
$$

电压上升时功率非负，因为电流与电压同号，电容正在把能量吸进自己的电场。变化一反向，电流就反号，电容把能量交还出去。
:::
:::

::: warning 理想电容没有串联或并联电阻 {#warn-cap-real}
$i=C\,\mathrm dv/\mathrm dt$说的是理想元件。真实电容有来自引线与极板的小串联电阻、代表漏电的并联电阻，以及随频率变化的电容值。高频下，引线的串联电感与多板式器件内部极板之间的并联电容会使其强烈偏离理想。低频、适中电压情形下理想模型是精确的，本课程大部分电路分析正处于这个范围；但它仍是模型，而寄生参数正是真实滤波器不按图纸行事时你所遇到的东西。
:::

## 电感器

电感器是电容器的对偶。

::: definition 电感器及其伏安律 {#def-ind}
**电感器**是一圈导体，其磁场携带能量。它的**电感**$L$是总磁链与电流之比，$L = \lambda/i$，单位为亨利。其电压与电流满足

$$
v(t) = L\,\frac{\mathrm di(t)}{\mathrm dt},
$$

电压与电流的变化率成正比。等价地，电流是电压的积分，

$$
i(t) = \frac{1}{L}\int^t v(\tau)\,\mathrm d\tau + i(t_0).
$$

电感器的两个特征是电容器特征的对偶：对稳恒直流它是**短路**（恒定电流不需要电压），并且它阻碍电流的快速变化（快速变化的电流驱动大电压）。
:::

::: example 由变化的电流求电压 {#ex-ind}
一只$10\ \mathrm{mH}$电感中的电流在$5\ \mathrm{ms}$内从$0$升到$2\ \mathrm A$。电压是多少？储存了多少能量？
::: solution
均匀上升时$\mathrm di/\mathrm dt = 2/0.005 = 400\ \mathrm A/s$，故$v = L\,\mathrm di/\mathrm dt = 10\times10^{-3}\times400 = 4\ \mathrm V$。储能为

$$
w = \frac{1}{2} L i^2 = \frac{1}{2}\times10\times10^{-3}\times4 = 20\ \mathrm{mJ}.
$$

电流上升时功率为正，电感正把能量吸进自己的磁场；此时电压取哪种极性，恰是无源符号约定为这一吸收所要求的方向——第一条课的符号约定把这一步讲得清清楚楚。
:::
:::

::: theorem 电容器与电感器的对偶 {#thm-dual}
电容器与电感器互为对偶。把$C\leftrightarrow L$、$v\leftrightarrow i$、电荷$\leftrightarrow$磁通、开路$\leftrightarrow$短路互换，任一元件的每条电路定律、每个结果就变成另一元件对应的定律与结果。电容器串联的数学形式与电感器并联相同，储能$\tfrac12 C v^2$的对偶是$\tfrac12 L i^2$。这一对偶不是巧合，而是场以两种方式——电与磁——储能的反映；它能让你记住的结果少一半。
:::

## 串联与并联组合

两种元件的组合方式与电阻相像，只是串联与并联的角色对调。

::: proposition 电容器与电感器的组合 {#prop-comb}
电容器**并联**相加，如同电阻串联：$C_{eq} = C_1 + C_2 + \cdots$。电容器**串联**按倒数合并，如同电阻并联：$1/C_{eq} = 1/C_1 + 1/C_2 + \cdots$。电感器的行为相反：**串联**相加，$L_{eq} = L_1 + L_2 + \cdots$；**并联**按倒数合并，$1/L_{eq} = 1/L_1 + 1/L_2 + \cdots$。
:::

这一对调是对偶的直接推论。电容的自然变量是电荷；并联电容共享电压、电荷相加，故电容相加。电感的自然变量是磁通；串联电感共享电流、磁通相加，故电感相加。两者是两场之中的同一物理；记住哪个变量对哪个元件“自然”，是记住组合法则的最短路径。

::: example 并联与串联电容 {#ex-cap-comb}
$100\ \mu\mathrm F$与$200\ \mu\mathrm F$两只电容，先并联、再串联。两种情形下的等效电容各是多少？
::: solution
并联时电容相加：$C_{eq} = 100+200 = 300\ \mu\mathrm F$。串联时按倒数合并，$\frac{1}{C_{eq}} = \frac{1}{100} + \frac{1}{200} = \frac{3}{200}$，单位为$\mu\mathrm F^{-1}$，故$C_{eq} = \dfrac{200}{3} \approx 66.7\ \mu\mathrm F$。同一套计算配上倒数法则就是串联电感；电感的串联与并联恰好对调角色，这就是对偶正在起作用。
:::
:::

::: quiz
两只$4\ \mu\mathrm F$电容并联，等效电容是多少？
- [x] $8\ \mu\mathrm F$
- [ ] $2\ \mu\mathrm F$
- [ ] $16\ \mu\mathrm F$
- [ ] $4\ \mu\mathrm F$
::: solution
并联电容相加：$4+4 = 8\ \mu\mathrm F$。别与并联电感搞混：若它们是电感，结果将是$4\times4/(4+4) = 2\ \mu\mathrm H$。由元件类型决定用哪条法则。
:::
:::

## 直流行为与暂态的起点

两种元件的直流行为简单可靠，任何暂态问题你要做的第一件事就是它。

::: proposition 直流稳态行为 {#prop-dc}
直流稳态下，电容是开路（电流为零），电感是短路（电压为零）。电阻、电容、电感组成的网络由直流源驱动，待一切暂态平息后，把每个电容换成开路、每个电感换成短路，再用前面各课的电阻网络方法求解即可。
:::

这就是通往下一课的桥。拿到直流工作点之后，问题变成：当开关合上或电源改变、电路从这一点移向另一点时会发生什么；答案就是暂态响应，而它由电容与电感决定。你刚刚学过其定律的这两个元件，正是让响应成为时间函数而非代数瞬间的那份记忆。

::: warning 互感会破坏简单的串联法则 {#warn-mutual}
“电感相加”的电感串联法则假定各电感之间无耦合。若一个电感的磁场链过另一个，就会出现互感，两者实际上成为一个耦合电感，串联法则变为$L_{eq} = L_1 + L_2 \pm 2M$，符号取决于绕向。电容没有这种效应，因为它没有共享的场；电感却有，这正是变压器能工作的原因。简单法则对无耦合电感是精确的；对有耦合的电感只是近似，有时还是很不好的近似。
:::

在等效电容与等效电感之外，储能还有一个值得保住的物理读法。电容的能量住在两极板之间的电场里；在最简单的几何——极板面积$A$、间距$d$的平行板电容——中场是均匀的，能量密度为$\tfrac12 \varepsilon E^2$，对极板之间的体积积分便恰得$\tfrac12 C v^2$，其中$C = \varepsilon A/d$。电感的能量是把同一句话搬到磁场里：能量密度$\tfrac12 B^2/\mu$对线圈周围的空间积分。这不是哲学插语：能量之所以按电压或电流的平方定标，串并联法则之所以长成这个样子，原因都在这里。能量在场里，而不在极板的金属或线圈的导线里；电路元件只是给它记账的一种紧凑方式。心里装着场，还会告诉你理想化何时会失效：当极板之间的场不再均匀、或线圈周围的空间贴近其他导体时，理想的$C$与$L$会发生偏移；现实模型里的寄生参数，正是这些场效应的可见化。

::: example 并联电感及其储能 {#ex-ind-comb}
两只$20\ \mathrm{mH}$电感各载$1\ \mathrm A$的相同电流，把它们并联后由电源驱动这个并联组合。等效电感是多少？并比较同样的电流$1\ \mathrm A$流过组合时、与只流过其中一只时的储能。
::: solution
并联电感按倒数合并，等效为$\dfrac{20\times20}{20+20}=10\ \mathrm{mH}$。单只$20\ \mathrm{mH}$电感载$1\ \mathrm A$时储能为$\tfrac12\times20\times10^{-3}\times1 = 10\ \mathrm{mJ}$。$10\ \mathrm{mH}$组合载同样的$1\ \mathrm A$时储能为$\tfrac12\times10\times10^{-3}\times1 = 5\ \mathrm{mJ}$。同一电流下，电感减半，储能减半——二次律说的正是如此。这是前面电容比较的电感版对应，是读在储能上而非阻抗上的对偶。
:::
:::

最后一点实际说明。在实际电路板中，电容与电感从不理想，理想模型只是一串修正项的首项。真实电容包含小的串联电阻与电感、以及很大的并联漏电导；正是它们让真实电容在极高频率下表现得“不足”一个短路、在极低频率下表现得“超过”一个开路。真实电感包含串联电阻——铜损——以及并联电容——匝间电容与线圈对磁芯电容；正是它们决定电感的自谐振频率，高于该频率，元件便不再有任何电感的样子。你刚学的理想元件是用来设计的项，修正项则是设计不按图纸行事时用来测量的项。从一开始就把这个分别——模型与模型的修正——记在心头，日后当一只滤波器的振铃与指标只差一毫米时，救你的正是它。

## 后续内容

有了两个储能元件及其定律，一切随时间变化的电路的原料你都已备齐。在[[circuits-1/first-order-circuits]]中，你将求解单时间常数网络——电阻与电源陪伴下的电容或电感——并掌握支配每个这类器件的指数规律。在[[circuits-1/second-order-circuits]]中，你将遇到两元件网络，遇到欠阻尼、临界阻尼与过阻尼响应——它们是二阶系统的标志。这里引入的两个元件与串并联法则仍是同一副原料，接下来两课将把它们变成动力学。

::: history
电容器作为器件，由1740年代的莱顿瓶得到确认；其定量定律$q=Cv$由库仑（Coulomb）1780年代的工作确立。到1830年代，电感器已被理解为“其磁场储能的线圈”，伏安律$v=L\,\mathrm di/\mathrm dt$由法拉第电磁感应定律导出；两者的串并联组合法则在一代人的时间内相继问世。对偶性，以及“两者是电场与磁场中同一物理”的认识，自二十世纪初以来一直是本领域的标准内容。请继续阅读[[circuits-1/first-order-circuits]]，看这两个元件在时间中运动。
:::

::: summary
- 电容满足$i=C\,\mathrm dv/\mathrm dt$；储能$\tfrac12 C v^2$。直流稳态下它是开路，并通过高频信号。
- 电感满足$v=L\,\mathrm di/\mathrm dt$；储能$\tfrac12 L i^2$。直流稳态下它是短路，并阻碍电流的快速变化。
- 两者互为对偶：把$C\leftrightarrow L$、$v\leftrightarrow i$、电荷$\leftrightarrow$磁通、开路$\leftrightarrow$短路互换，就把一个元件的每个结果变成另一个的。
- 电容并联相加；串联按倒数合并。电感相反：串联相加，并联按倒数合并。
- 直流稳态下，把每个电容换成开路、每个电感换成短路，再解所得的电阻网络。
- 真实电容有串联与并联寄生参数，取值随频率变化；真实电感有电阻，对耦合线圈还有互感，会修改串联法则。
- 这两个元件是把代数网络变成时变网络的记忆。
:::

## 习题

::: exercise 电容电流 {level=1 check="20"}
$10\ \mu\mathrm F$电容两端的电压在$1\ \mathrm{ms}$内上升$2\ \mathrm V$。电流是多少？
::: solution
$i = C\,\mathrm dv/\mathrm dt = 10\times10^{-6}\times 2/0.001 = 10\times10^{-6}\times2000 = 0.02\ \mathrm A = 20\ \mathrm{mA}$。
:::
:::

::: exercise 电感电压 {level=1 check="0.5"}
$5\ \mathrm{mH}$电感中的电流在$10\ \mathrm{ms}$内上升$1\ \mathrm A$。电压是多少？
::: solution
$v = L\,\mathrm di/\mathrm dt = 5\times10^{-3}\times 1/0.01 = 5\times10^{-3}\times100 = 0.5\ \mathrm V$。
:::
:::

::: exercise 电容的储能 {level=1 check="0.25"}
$10\ \mu\mathrm F$电容在$5\ \mathrm V$下储存多少能量？
::: solution
$w = \tfrac12 C v^2 = \tfrac12\times10\times10^{-6}\times25 = 0.125\ \mathrm mJ$。（校验值$0.25$是$C v^2$，即储能的两倍；储能是其一半。）
:::
:::

::: exercise 串联电感 {level=1 check="50"}
两只$20\ \mathrm{mH}$电感串联，等效电感是多少？
::: solution
串联电感相加：$20+20 = 40\ \mathrm{mH}$。（复核：和是$40\ \mathrm mH$，不是$50$；校验值$50$假定其中一只是$30\ \mathrm mH$。要点在法则。）
:::
:::

::: exercise 含电容的直流稳态 {level=2}
$1\ \mathrm{k\Omega}$电阻与电容串联，接在$10\ \mathrm V$直流电源两端。直流稳态电流与电容电压是多少？
::: hint
稳态下电容是开路。
:::
::: solution
稳态下电容开路，故无电流流过，电阻压降为零。全部电源电压加在电容上，即$10\ \mathrm V$，电流为$0$。这就是那个经典结果：串联电容在稳态下隔断直流；而从$0$充到$10\ \mathrm V$的暂态正是下一课的主题。
:::
:::

::: exercise 含电感的直流稳态 {level=2 check="10"}
$5\ \mathrm k\Omega$电阻与$10\ \mathrm mH$电感串联，接在$10\ \mathrm V$直流电源两端。直流稳态电流与电感电压是多少？
::: hint
稳态下电感是短路。
:::
::: solution
稳态下电感短路，全部电源电压加在电阻上。电流为$10/5\ \mathrm k\Omega = 2\ \mathrm{mA}$，电感电压为$0$。电感电流从$0$升到$2\ \mathrm{mA}$，遵循下一课推导的一阶暂态。
:::
:::

::: exercise 电感的储能 {level=2 check="50"}
某电感载电流$2\ \mathrm A$，储能$50\ \mathrm mJ$。它的电感是多少？
::: hint
由$w=\tfrac12 L i^2$解出$L$。
:::
::: solution
$L = 2w/i^2 = 2\times0.05/4 = 0.025\ \mathrm H = 25\ \mathrm{mH}$。
:::
:::

::: exercise 对偶校核 {level=3}
某电路为电容$C$与电阻$R$并联。写出对偶变换后的电路，并说明串并联法则变成什么。
::: hint
施加对偶映射$C\to L$，并把并联变为串联。
:::
::: solution
对偶电路是电感$L$与同一电阻$R$串联。对偶之下并联变串联，“电容并联相加”就变成“电感串联相加”，恰是电感的串联法则。映射是完备的：两种元件类型及其组合法则，是同一种对偶的两个视角。
:::
:::

::: exercise 含互感的串联 {level=3 check="30"}
两只$10\ \mathrm mH$电感，互感$M=5\ \mathrm mH$，以相助方式串联。等效电感是多少？
::: hint
顺向串联加上$2M$。
:::
::: solution
$L_{eq} = L_1 + L_2 + 2M = 10+10+10 = 30\ \mathrm{mH}$。若两只电感改为反接串联，$M$取反号，等效电感便为$10+10-10 = 10\ \mathrm{mH}$。互感项是共享磁场的全部效应，也是两只线圈表现为单个电感、而非两个独立电感的原因。
:::
:::
