电阻网络也能对电压做加、乘、除，只是方式固定且往往不方便。运算放大器改变了电路能做的事情的性质。借助一个有源元件和几只电阻，你就能实现正负两种符号的增益、把多个输入求和、取两个输入的差，并且——在本课程中第一次——对信号沿时间积分。这一切之所以能如此干净地成立，是因为理想运放给了你一个完美的前提：它的两个输入端电位相同；仅凭这一个前提，再结合基尔霍夫定律，本课的每个结果都随之成立。本课建立理想模型，为标准电路推出增益公式，然后指出模型在何处失效。

## 理想运放

把理想模型说的三条讲精确是值得的，因为每个结果都依赖它。

::: definition 理想运算放大器 {#def-opamp}
**理想运算放大器**有三条性质。其**开环增益**为无穷大，因此输出会一直驱动自己，直到两个输入端电压相等为止。其**差分输入电阻**为无穷大，因此两个输入端都不取电流。其**输出电阻**为零，因此输出就是一个电压源。输出电压是同相输入端减反相输入端，$v_+ - v_-$，再乘以无穷的增益，而流入与流出器件的电流完全由负载所需决定。
:::

对每一个计算真正要紧的推论是下面这条。

::: theorem 虚短与虚地 {#thm-vshort}
若运放工作在线性区并带有负反馈，则两个输入端电位相同（**虚短**），且两端都不取电流。若同相输入端接地，则反相输入端处于地电位（**虚地**）。这两条事实加上基尔霍夫定律，对任何电阻反馈网络都能确定输出。
:::

由此得到的方法短得惊人。在反相节点写基尔霍夫电流定律：能流动的电流只有两条——经输入电阻流入的和经反馈电阻流出的——因为运放输入端不取电流。这一条电流平衡方程就是每种反相电路的全部推导；结果是增益只由反馈比值决定，与运放自身的增益无关。这与无源分压器恰好相反：那里结果依赖电源；而这里结果对那个有源元件是鲁棒的——这正是这种器件的全部意义。

## 反相放大器与同相放大器

两种基本增益电路互为对偶，而且都由虚短直接得出。

::: proposition 反相放大器 {#prop-inverting}
输入电阻为$R_1$、反馈电阻为$R_f$的反相放大器，闭环增益为

$$
\frac{v_{\text{out}}}{v_{\text{in}}} = -\frac{R_f}{R_1}.
$$

负号表示输出反相。增益只取决于两只电阻的比值，与运放增益和负载都无关。
:::

::: example 反相增益 {#ex-inverting}
反相放大器$R_1 = 10\ \mathrm{k\Omega}$、$R_f = 40\ \mathrm{k\Omega}$。输入为$0.5\ \mathrm V$时输出是多少？反馈电流是多少？
::: solution
增益为$-R_f/R_1 = -4$。输出为$-4\times0.5 = -2\ \mathrm V$。流过$R_1$的电流为$0.5/10\ \mathrm{k\Omega} = 50\ \mu\mathrm A$；因为反相节点不取电流，它全部流过$R_f$，得$v_{\text{out}} = -50\ \mu\mathrm A\times40\ \mathrm{k\Omega} = -2\ \mathrm V$，结果一致。反相节点上的虚短正是分析如此简单的原因：从输入端看进去只有$R_1$到地，与反馈无关。
:::
:::

::: proposition 同相放大器 {#prop-noninverting}
反馈电阻为$R_f$（从输出接到反相输入端）、$R_1$（从反相输入端到地）的同相放大器，增益为

$$
\frac{v_{\text{out}}}{v_{\text{in}}} = 1 + \frac{R_f}{R_1},
$$

其中$R_f$为反馈电阻。输出与输入同相，增益是比值加一，所以这种形式能达到的最小增益为一。
:::

::: example 同相增益 {#ex-noninverting}
同相放大器$R_1 = 10\ \mathrm{k\Omega}$、$R_f = 40\ \mathrm{k\Omega}$。增益是多少？输入为$1\ \mathrm V$时的反馈电流是多少？
::: solution
增益为$1+R_f/R_1 = 1+4 = 5$。输入$1\ \mathrm V$时输出为$5\ \mathrm V$。由虚短，反相节点电位为$1\ \mathrm V$，所以流过$R_1$（从反相节点到地）的电流为$1/10\ \mathrm{k\Omega} = 100\ \mu\mathrm A$；这一电流由输出经$R_f$流过来：$40\ \mathrm{k\Omega}$上$5 - 1 = 4\ \mathrm V$对应$100\ \mu\mathrm A$，一致。这一电路的输入阻抗就是运放的无穷大输入电阻，远高于反相情形，这也是人们选它的通常原因。
:::
:::

::: warning 输出不能超出电源轨 {#warn-rails}
虚短假设只在运放确实能给出所需输出电压时才成立。若代数要求输出超出电源轨，器件就在某一条轨上饱和，虚短随之不再成立。检查算出的输出是否落在电源轨之内，是任何运放设计的标准第一步，因为一套代数正确、输出却越轨的电路，在实际中是比较器，不是放大器。
:::

## 跟随器、求和放大器与差分放大器

另外三种电路建立在同样两条事实之上——输入不取电流、两端电位相同。

::: proposition 电压跟随器 {#prop-follower}
把输出直接反馈到反相输入端，增益为一，输出等于反相节点电位，而后者等于输入。跟随器是一个单位增益缓冲器：它呈现极高的输入阻抗与极低的输出阻抗，因此能驱动一个本会把电源拖垮的负载。它的价值不在增益，而在阻抗变换。
:::

::: theorem 求和放大器 {#thm-summer}
多个输入$v_k$各经电阻$R_k$接到反相节点，并配有反馈电阻$R_f$时，输出为

$$
v_{\text{out}} = -R_f\sum_k \frac{v_k}{R_k}.
$$

反相节点是虚地，所以各输入电流互不干涉、简单相加。这就是最简单的线性加法器。
:::

::: example 加权求和 {#ex-summer}
求和放大器$R_f = 20\ \mathrm{k\Omega}$，两个输入：$v_1 = 1\ \mathrm V$经$R_1 = 10\ \mathrm{k\Omega}$，$v_2 = 1\ \mathrm V$经$R_2 = 20\ \mathrm{k\Omega}$。输出是多少？
::: solution
两个输入都处于虚地，故电流为$v_1/R_1 = 1/10\ \mathrm{k\Omega} = 100\ \mu\mathrm A$与$v_2/R_2 = 1/20\ \mathrm{k\Omega} = 50\ \mu\mathrm A$。合计$150\ \mu\mathrm A$流过$R_f$，得$v_{\text{out}} = -150\ \mu\mathrm A\times20\ \mathrm{k\Omega} = -3\ \mathrm V$。注意两个相等的输入给出的贡献并不相等，因为它们的电阻不同；电阻决定每个输入的权重，这正是求和放大器全部的设计自由。
:::
:::

差分放大器是四电阻网络，按定标的比例输出两个输入之差。它就是系统中每一个“把信号与参考值比较”的比较器背后的电路。

::: definition 差分放大器 {#def-diff}
反相侧接$R_1$、$R_f$，同相侧接$R_2$、$R_g$的**差分放大器**，输出为

$$
v_{\text{out}} = \left(1+\frac{R_f}{R_1}\right)\frac{R_g}{R_2+R_g}\,v_+ - \frac{R_f}{R_1}v_-,
$$

当电阻比满足$R_f/R_1 = R_g/R_2$时，化为干净的差$v_{\text{out}} = (R_f/R_1)(v_+ - v_-)$。
:::

::: example 两信号之差 {#ex-diff}
差分放大器$R_1 = 10\ \mathrm{k\Omega}$、$R_f = 20\ \mathrm{k\Omega}$，并取匹配对$R_2 = 10\ \mathrm{k\Omega}$、$R_g = 20\ \mathrm{k\Omega}$。$v_+ = 3\ \mathrm V$、$v_- = 1\ \mathrm V$时输出是多少？
::: solution
电阻比匹配：$R_f/R_1 = 20/10 = 2$，$R_g/R_2 = 20/10 = 2$，故该电路是理想的差分放大器，对差值的增益为二。输出为$2\times(3-1) = 4\ \mathrm V$。这一电路抑制两个输入的公共部分，只放大它们的差——当信号骑在你想去掉的共模之上时，要的正是这个。
:::
:::

## 积分器与微分器

由于理想模型允许输出达到与节点方程相容的任何电压，反馈通路里可以放任何元件，不只是电阻。把电容放进反馈通路，输入与输出的关系就从代数变成了积分。

::: definition 反相积分器 {#def-integrator}
输入电阻为$R$、反馈电容为$C$时，输出为

$$
v_{\text{out}}(t) = -\frac{1}{RC}\int^t v_{\text{in}}(\tau)\,\mathrm d\tau + \text{常数},
$$

即输入取负再积分，按$1/RC$定标。这就是对信号做积分的模拟电路，用于控制回路、波形产生，以及一切需要“曲线下累积面积”的场合。
:::

::: example 对阶跃积分 {#ex-int}
积分放大器$R = 10\ \mathrm{k\Omega}$、$C = 1\ \mu\mathrm F$。若施加$1\ \mathrm V$阶跃$10\ \mathrm{ms}$，输出改变多少？
::: solution
时间常数是$RC = 10\ \mathrm{k\Omega}\times1\ \mu\mathrm F = 10\ \mathrm{ms}$。恒定输入向电容注入恒定电流$v_{\text{in}}/R = 1/10\ \mathrm{k\Omega} = 100\ \mu\mathrm A$，电容电压以恒定速率$i/C = 100\ \mu\mathrm A/1\ \mu\mathrm F = 100\ \mathrm V/s$变化。$10\ \mathrm{ms}$内即改变$100\times0.01 = 1\ \mathrm V$；按反相惯例为负，故输出下降$1\ \mathrm V$。阶跃得到线性斜坡、且响应是一条直线，这是积分器的标志；它所用的数学与接下来各课的一阶响应完全相同。
:::
:::

微分器是它的对偶：电容与输入串联、反馈为电阻，按定标的比例输出输入的导数。它是同一器件把两个元件对调后的用法；产生尖峰边沿、对噪声敏感、因而很难用得干净的也正是这一电路，因为导数会放大任何真实信号中的高频成分。

caption: 例题中反相放大器的输入—输出关系$v_{\text{out}} = -4\,v_{\text{in}}$。负斜率的直线是线性反相增益的标志：输入加倍，输出加倍，符号相反。直线过原点，因为理想模型中没有失调。
:::

::: quiz
同相放大器$R_f = 20\ \mathrm{k\Omega}$、$R_1 = 10\ \mathrm{k\Omega}$。增益是多少？
- [x] $3$
- [ ] $2$
- [ ] $4$
- [ ] $1$
::: solution
同相增益为$1 + R_f/R_1 = 1 + 20/10 = 3$。很容易顺手写成反相的答案二，但同相形式多一个一，因为反馈设定的是输出在反相节点上所占的比例，而不是输入的一个负副本。
:::
:::

这些电路都只凭同样两条事实就能工作，其中的理由值得说透，因为它是本课最深的一点。理想运放是增益无穷大的理想压控电压源；正是无穷大的增益迫使两个输入等电位，无论反馈网络做什么。反馈网络——那些电阻——再通过让反相节点的电流平衡、或把输出分压回该节点，来设定输入与输出之间的关系。于是输出就是让节点方程成立的那个值，定答案的是电阻而不是增益。这与无源网络给人的直觉恰好相反：那里是电源决定电流、电阻只起限制作用。在运放的世界里，有源元件负责“做”，电阻负责“说”；这一颠倒正是器件如此强大、分析如此简短的原因，也是把有源电路设计与前面各课的无源网络分析彻底分开的唯一一条思想。

## 后续内容

有了理想模型、虚短和增益公式，你就能读懂并设计标准的线性放大器电路。理想模型也是运算放大器设计课程的出发点；同样的电路——增益、求和、差分、积分——在频域中带着有限的增益与带宽重新出现。在[[circuits-1/capacitors-inductors]]中你会遇到两个储能元件，它们的动力学正是积分器呈现上述行为的原因；在[[circuits-1/first-order-circuits]]中，单个时间常数的同一套数学，支配着你刚在积分器里看到的那种响应。

::: history
运算放大器作为实用器件，出现于1940年代，形态是增益极高的真空管放大器；在模拟计算中使用是它最初的用途——用电路对信号做加、减、积分与相乘。1960年代的集成电路版本让器件变得又小、又便宜、人人可得，带着虚短的理想模型遂成为固态时代最初几十年设计与分析的标准语言。求和放大器、差分放大器与积分器都源自模拟计算这段出身。请继续阅读[[circuits-1/capacitors-inductors]]，看使积分器成为可能的元件；再看[[circuits-1/first-order-circuits]]，看它们强加的动力学。
:::

::: summary
- 理想运放增益无穷大、输入电阻无穷大、输出电阻为零；线性反馈下两个输入同电位（虚短）、两端都不取电流（一端接地时另端即虚地）。
- 反相放大器增益为$-R_f/R_1$；同相放大器增益为$1 + R_f/R_1$。两者都由虚短与基尔霍夫定律直接得出。
- 电压跟随器是单位增益缓冲器，其价值是阻抗变换而非增益。
- 求和放大器输出$-R_f\sum v_k/R_k$；电阻设定权重，反相节点是虚地，故各贡献互不干涉。
- 电阻匹配的差分放大器输出$(R_f/R_1)(v_+ - v_-)$，并抑制输入的公共部分。
- 反馈通路中的电容把放大器变成积分器，响应为$-(1/RC)\int v_{\text{in}}\,\mathrm dt$；元件对调后的对偶电路是微分器。
- 模型只在输出不超过电源轨时精确；代数要求更大输出的电路是比较器，不是放大器。
:::

## 习题

::: exercise 反相增益 {level=1 check="-3"}
反相放大器$R_1=5\ \mathrm{k\Omega}$、$R_f=15\ \mathrm{k\Omega}$。增益是多少？
::: solution
$-R_f/R_1 = -15/5 = -3$。
:::
:::

::: exercise 同相增益 {level=1 check="2"}
同相放大器$R_f=10\ \mathrm{k\Omega}$、$R_1=10\ \mathrm{k\Omega}$。增益是多少？
::: solution
$1 + R_f/R_1 = 1+1 = 2$。
:::
:::

::: exercise 反相放大器的输出 {level=1 check="-0.6"}
增益为$-2$的反相放大器输入$0.3\ \mathrm V$。输出是多少？
::: solution
$-2\times0.3 = -0.6\ \mathrm V$。
:::
:::

::: exercise 跟随器的输入阻抗 {level=2}
为什么电压跟随器呈现极高的输入阻抗？对它所接的信号源而言，实际意义是什么？
::: hint
把输入电流与运放输入电阻联系起来。
:::
::: solution
同相输入端直接接到输入端，理想运放两个输入都不取电流，故输入电流为零，与信号源内阻无关。输入电流为零意味着输入电阻无穷大，信号源因此不受加载。实际中，输出电阻很高的信号源——光电二极管或压电器件——正需要这个：一只高输入电阻的缓冲器，让微小的信号电流不至于在源电阻上跌落殆尽。
:::
:::

::: exercise 三输入求和放大器 {level=2 check="-9"}
求和放大器$R_f=30\ \mathrm{k\Omega}$，三个输入均为$1\ \mathrm V$，各经$10\ \mathrm{k\Omega}$接入。输出是多少？
::: hint
反相节点是虚地；把输入电流求和后乘以$R_f$。
:::
::: solution
每个输入贡献$1/10\ \mathrm{k\Omega} = 100\ \mu\mathrm A$，总和为$300\ \mu\mathrm A$。输出为$-300\ \mu\mathrm A\times30\ \mathrm{k\Omega} = -9\ \mathrm V$。每个输入的增益为$-R_f/R = -3$。
:::
:::

::: exercise 差分放大器的电阻比 {level=2 check="30000"}
差分放大器$R_1=10\ \mathrm{k\Omega}$、$R_f=30\ \mathrm{k\Omega}$、$R_2=10\ \mathrm{k\Omega}$。$R_g$取何值（以欧计）时它是理想的差分放大器？
::: hint
让两个电阻比匹配。
:::
::: solution
匹配要求$R_f/R_1 = R_g/R_2$，故$R_g = R_f R_2/R_1 = 30\times10/10 = 30\ \mathrm{k\Omega}$。此时输出为$(30/10)(v_+-v_-) = 3(v_+-v_-)$，恰为三倍的差。
:::
:::

::: exercise 积分器时间常数 {level=3 check="20"}
积分器$R=5\ \mathrm{k\Omega}$、$C=4\ \mu\mathrm F$。时间常数$RC$是多少毫秒？
::: hint
电阻乘以电容。
:::
::: solution
$RC = 5\ \mathrm{k\Omega}\times4\ \mu\mathrm F = 5\times4\ \mathrm{ms} = 20\ \mathrm{ms}$。
:::
:::

::: exercise 饱和与电源轨 {level=3}
增益$-4$、电源轨$\pm 5\ \mathrm V$的反相放大器输入$1.5\ \mathrm V$。理论输出是多少？实际输出是多少？
::: hint
把代数结果与电源轨比较。
:::
::: solution
代数给出$-4\times1.5 = -6\ \mathrm V$，但输出最多只能到$-5\ \mathrm V$，于是在下轨饱和。实际输出是$-5\ \mathrm V$而不是$-6\ \mathrm V$；当初用来求$-6\ \mathrm V$的虚短假设，在反相节点上已不再成立。这就是放大器饱和的标志，也是检查电源轨成为标准第一步的原因。
:::
:::

::: exercise 微分器与高频极限 {level=3}
用电容阻抗说明：微分器为什么在高频放大的噪声比低频更严重。
::: hint
电容阻抗随频率下降。
:::
::: solution
微分器中电容与输入串联，其阻抗为$1/(j\omega C)$，随频率$\omega$升高而减小。高频下电容近乎短路，输入电流增大，而与这一电流成正比的输出也随之增大。多数噪声能量集中在高频，微分器因而把它强烈放大。这就是纯微分器几乎总是通过在反馈中串入电阻来使高频增益滚降的原因：用少量微分性能的损失，换取噪声增益的大幅下降。
:::
:::
