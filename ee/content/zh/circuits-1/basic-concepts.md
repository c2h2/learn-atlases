闭合一个开关，电荷便开始沿器件中的导线流动，能量随之传输，其中一部分以热、光或声的形式释放。**电路**就是电荷流过的这条闭合路径，而整个电气工程都始于一个问题：沿这条路径发生了什么。在分析任何电路之前，你都需要四个基本量——电荷、电流、电压与功率——以及一条把它们一致地联系起来的单一规则：关联参考方向。本课精确定义每一个量，从第一性原理出发算出真实的电流、电压与能量，并以两条守恒定律收尾：基尔霍夫电流定律与基尔霍夫电压定律，课程中的一切结果都由它们导出。

## 电荷、电流、漂移与尺度

电荷是产生电力的物质属性。它有两种等量异号的形式，其单位是**库仑**（C）。金属中的基本载流子是电子，其电荷为

$$
q_e = -1.60217\times10^{-19}\ \mathrm{C},
$$

而在半导体中还有带正电的**空穴**，它的行为就好像携带$+q_e$并朝相反方向运动。一库仑对应极其庞大的元电荷数目：一库仑相当于$1/(1.602\times10^{-19})\approx 6.242\times10^{18}$个电子。当你看到“一安培”的额定值时，那意味着大约六百亿亿（$6.24\times10^{18}$）个电子每秒钟穿过一条线。

::: definition 电荷 {#def-charge}
电荷$q$是以库仑计量的守恒标量。对连续分布，它写成密度$\rho$，单位为库仑每立方米，区域中的总电荷为$q=\int \rho\,\mathrm dv$。电荷可以在物体之间转移，但既不能被创造也不能被消灭；孤立系统中全部电荷之和为常数。
:::

承载信号与能量的是电荷的*运动*。电流是电荷流过某一选定截面的速率。

::: definition 电流 {#def-current}
流过某一曲面的**电流**$i(t)$是电荷穿过该曲面的速率，

$$
i(t)\;=\;\frac{\mathrm dq}{\mathrm dt}.
$$

其单位是**安培**（A），即每秒一库仑。在$t_0$与$t_1$之间穿过该面的净电荷为$\int_{t_0}^{t_1} i(t)\,\mathrm dt$。恒定的值称为**直流**（DC）；周期性改变符号的值称为**交流**（AC）。
:::

有一个微妙之处值得一次说清，因为它造成的早期符号错误比其他任何东西都多。金属导线中实际携带的电荷是朝一个方向运动的电子；而按照悠久的惯例，*电流*被取为相反方向。这个**常规电流**正是你始终要计算和测量的量，也是导线上箭头必须指向的方向。结果为负从不意味着出了什么差错；它只表示流动方向与你设定的参考方向相反。

::: example 由随时间变化的电荷求电流 {#ex-current}
流过某曲面的电荷为$q(t) = 4t^2 + 2t$库仑，$t$以秒计。求$t=1\ \mathrm s$时的电流，以及$t=0$到$t=1$之间穿过的净电荷。
::: solution
电流是导数，$i(t) = \mathrm dq/\mathrm dt = 8t + 2$安培。在$t=1$处得$i = 8 + 2 = 10\ \mathrm A$。该区间内的净电荷为$q(1)-q(0) = (4+2)-0 = 6\ \mathrm C$。作为校核，对同一区间积分电流，$\int_0^1 (8t+2)\,\mathrm dt = \left[4t^2+2t\right]_0^1 = 6\ \mathrm C$，结果完全一致。求导与积分是同一物理事实的两种读法。
:::
:::

::: warning 参考方向与符号 {#warn-conventional}
在一条导线上只选定一次参考方向，相对于它计算$i$，并在整个问题中保持不变。$i$为负只表示电荷沿参考方向的反方向流动。绝不要通过翻转你同样自行选定的电压符号去“纠正”一个负结果；两者是相互关联的。关联参考方向所要求的，是参考设定的一致性，而不是某个数的符号。
:::

平均电流可以很大，而每个电子的移动速度不过每秒几毫米，因为电流是一种*集体*效应：数量巨大的缓慢载流子。相形之下，*信号*在介质中以接近光速的很大比例传播。这就是为什么单看电子的漂移，你无法判断一盏灯有多快亮起。

::: quiz
一节电池提供$2\ \mathrm A$。$30$秒内有多少库仑穿过它？这大约是多少个电子？
- [x] $60\ \mathrm C$，约$3.7\times10^{20}$个电子
- [ ] $60\ \mathrm C$，约$6.2\times10^{19}$个电子
- [ ] $20\ \mathrm C$，约$3.7\times10^{19}$个电子
- [ ] $1800\ \mathrm C$，约$1.1\times10^{22}$个电子
::: solution
电荷为$q = i\,t = 2\times30 = 60\ \mathrm C$。除以元电荷，$60/(1.602\times10^{-19})\approx 3.74\times10^{20}$个电子。第一项正确。
:::
:::

## 电压、功率、能量与符号约定

电荷不会自己移动。它被电场推动，而单位电荷所花的力气就是**电压**。电压是驱动量，电流是随之而来的速率，两者的乘积是**功率**，即能量传输的速率。这三个量是本课以及此后一切内容的核心。

::: definition 电压 {#def-voltage}
两点$A$与$B$之间的**电压**（电势差）$v_{AB}$，是电场把一个单位正电荷从$A$移到$B$所做的功，

$$
v_{AB}\;=\;\frac{\text{转移的能量}}{\text{移动的电荷}}\;=\;\frac{\mathrm dW}{\mathrm dq}.
$$

其单位是**伏特**（V），即每库仑一焦耳。电压总是存在于*两点之间*；单个节点只有相对于某个选定的参考点——**地**或**公共端**——才有意义。
:::

::: definition 功率与能量 {#def-power}
输送到二端元件的**功率**是其两端电压与流过电流的乘积，

$$
p = v\,i,
$$

电压以伏、电流以安计时的单位是瓦特（W）。一段时间内传输的**能量**为$W = \int p\,\mathrm dt$，单位为焦耳。$p$的符号指明传输的方向：在关联参考方向下，$p>0$表示元件正在吸收（消耗）功率，$p<0$表示它正在提供（发出）功率。
:::

下面是你在本课程写下的每一个式子都会用到的一条约定。

::: intuition 关联参考方向（无源符号约定） {#psc}
对任何元件，你可以任意画出电流箭头，并用$+$与$-$标出电压极性。**关联参考方向**（passive sign convention，无源符号约定）规定：把电流箭头画成*从标$+$的端子流入*。此时吸收功率为$p=v\,i$，元件消耗能量时它为正。若电流改为从$-$端流入，则吸收功率为$-v\,i$。这条规则不只是记账：正是它使“正”意味着“吸收”，并使网络中每一份能量平衡都真实可靠。
:::

电阻是最常见的吸收者，电池是最常见的提供者。对它们各自进行估算与追问，正是你建立真实数量级感的方法。

::: example 电阻的功率 {#ex-resistor}
一只$4.7\ \mathrm{k\Omega}$电阻两端加$5\ \mathrm V$。求电流、它以热形式耗散的功率，以及五分钟里释放的能量。
::: solution
由欧姆定律，电流为$i = v/R = 5/4700 = 1.064\times10^{-3}\ \mathrm A = 1.064\ \mathrm{mA}$。功率为$p = v^2/R = 25/4700 = 5.32\ \mathrm{mW}$，等价地$p=vi$。在$t=300\ \mathrm s$内的能量为$E = p\,t = 5.32\times10^{-3}\times300 = 1.60\ \mathrm J$。注意功率为正，这正是一个把电能变为热的元件在关联参考方向下应当得到的结果。
:::
:::

::: example 电池提供的能量 {#ex-battery}
一只$12\ \mathrm V$的汽车电池以$2\ \mathrm A$的电流放电$5$小时。求它提供的功率与消耗的总能量。
::: solution
功率是乘积，$p = v\,i = 12\times2 = 24\ \mathrm W$。在$5\times3600 = 18000\ \mathrm s$内，能量为$E = p\,t = 24\times18000 = 4.32\times10^{5}\ \mathrm J = 432\ \mathrm{kJ}$。以常用的安时计，提供的电荷为$2\ \mathrm A\times5\ \mathrm h = 10\ \mathrm{Ah}$；能量是电荷乘以电压，故$E = 10\ \mathrm{Ah}\times12\ \mathrm V = 120\ \mathrm{Wh}$；而$432\ \mathrm{kJ}/3600 = 120\ \mathrm{Wh}$，两套单位一致。这些交叉校核正是你确认答案正确（而不只是貌似合理）的办法。
:::
:::

::: widget plot
f: 8*x + 2
x: 0, 1.5
y: 0, 15
caption: 例题中的电流$i(t)=8t+2\ \mathrm A$。它随时间线性上升；斜率$8\ \mathrm{A/s}$是电荷变化的速率。拖动滑块放置标记，从坐标轴上同时读出电流与时间。
:::

由于$p=v\,i$，设计任务通常只是一次代数变形。诀窍在于分清哪个量已知、哪个量所求，并保持参考方向不出错。

::: example 根据所需电流选择电阻 {#ex-design}
你需要由$12\ \mathrm V$电源经一只电阻得到$0.5\ \mathrm A$的电流。需要多大的电阻？应按怎样的连续功率额定值选择这只电阻？
::: solution
改写电流方程：$R = v/i = 12/0.5 = 24\ \Omega$。该电阻必须吸收的连续功率为$p = v\,i = 12\times0.5 = 6\ \mathrm W$。实践中你会选择一只$24\ \Omega$、额定值*高于*$6\ \mathrm W$的电阻，例如$10\ \mathrm W$，因为让元件工作在极限值会把它的温度推到额定范围的上缘并缩短寿命。
:::
:::

::: warning 功率是速率，额定值是上限 {#warn-power}
功率是能量传输的速率，不是能量本身；元件的功率额定值是*最大连续*速率，不是它能存储的东西。超过额定值，元件就会过热，而多数电阻远早于电流本身构成危险之前就已因热失控而失效。要有意识地降额：连续工作场合，所选额定值至少为计算功率的$1.5$到$2$倍。
:::

::: quiz
某一元件按电流从$+$端流入画出，$v=4\ \mathrm V$，$i=3\ \mathrm A$。它在吸收还是提供功率？多少？
- [x] 吸收$12\ \mathrm W$
- [ ] 提供$12\ \mathrm W$
- [ ] 吸收$7\ \mathrm W$
- [ ] 提供$7\ \mathrm W$
::: solution
在关联参考方向下（电流从$+$端流入），吸收功率为$p=vi=4\times3=12\ \mathrm W$。正号表示吸收，故第一项正确。若电流改从$-$端流入，同样的数字便意味着它在提供功率。
:::
:::

## 电源与一切网络都遵守的定律

最后一种要素，是理解提供能量的理想**电源**与塑造能量形状的理想**元件**。电源不管还接了什么，都维持指定的电压或电流。

::: definition 电压源与电流源 {#def-source}
**独立电压源**不论流出多大电流，都在其两端维持固定电压$v_s(t)$。**独立电流源**不论两端电压多大，都维持流过它的固定电流$i_s(t)$。**受控源（依赖源）**的取值正比于电路中*别处*的某个电压或电流；它是建模装置而非实体电池，画成菱形符号并标以增益$r$、$\mu$、$\beta$或$g$。
:::

一旦电源与元件组合成网络，两条直接来自守恒的定律便统辖全局，无论它多么复杂。

$$
\text{在每个节点上: }\ \sum_{k} i_k \;=\; 0 \qquad;\qquad \text{沿每个回路: }\ \sum_{k} v_k \;=\; 0.
$$

第一条是电荷守恒（节点不能积聚电荷），第二条是能量守恒（电荷沿闭合路径绕行一周回到原来的电位）。这就是**基尔霍夫电流定律（KCL）**与**基尔霍夫电压定律（KVL）**。它们不是近似，也不要求元件是线性的；对任何集总电路都成立。有了电阻的欧姆定律$v= Ri$与两条基尔霍夫定律，你就具备了精确求解电阻电路所需的一切——这正是下一课的内容。

## 单位、词头与读电路图

电学量跨越极大的范围，因此SI词头不是图方便，而是必需品。一纳法是$10^{-9}$ F，一微安是$10^{-6}$ A，一千欧是$10^{3}\ \Omega$，一兆欧是$10^{6}\ \Omega$。读电路图时，每个参考方向、每个$+$与$-$标记、每个电流箭头，都是设计者做出的选择；关联参考方向告诉你如何从这些选择解释每个元件的功率。电源与电阻构成一条不含其他元件的闭合路径——这正是学生应当能解的第一个例题：电源迫使电流流过电阻，KVL确定电压，$p=vi$确定两者的功率。若你能带着明确的参考方向干净利落地做到这一点，本课程余下的部分就只是规模问题了。

## 后续内容

电荷、电流、电压与功率都有了定义，关联参考方向也已就位，你现在可以读懂电路图上每个标注，并给每个量定出符号。在[[circuits-1/resistive-circuits]]中，这些定义将化为一套方法：把网络化为单个等效元件、分配电压与电流，并从容地处理实际器件。始终记住关联参考方向；每当符号看起来不对就回到它，因为出问题的几乎从不是符号本身，而是参考。

::: history
本课的语言形成于十九世纪初，其后在二十世纪精炼为理想化模型。伏打（Alessandro Volta）于1800年制成的伏打电堆提供了第一个可靠的持续电流源。欧姆（Georg Ohm）在多年细致测量之后，于1827年发表了电流—电压—电阻的定量关系。基尔霍夫（Gustav Kirchhoff）于1845年提出了两条守恒定律。理想电源与关联参考方向——正如现代分析所用的那样——在1880至1920年代的工程教材中定型。请继续阅读[[circuits-1/resistive-circuits]]，看这些定律应用于真实网络；系统求解方法见[[circuits-1/nodal-mesh]]。
:::

::: summary
- 电荷$q$（C）守恒；电流$i=\mathrm dq/\mathrm dt$（A）是它的流动速率。一库仑约含$6.242\times10^{18}$个元电荷。
- 电压$v$（V = J/C）是单位电荷的能量，驱动电流；它总是两点之间相对于参考点测得的。
- 功率$p=vi$（W）是能量传输的速率；能量为$W=\int p\,\mathrm dt$（J）。
- 在关联参考方向下（电流箭头指向$+$端流入），$p$为正表示元件吸收功率，$p$为负表示它提供功率。
- 独立源强加电压或电流；受控源是带增益的控制型建模元件。
- 节点的基尔霍夫电流定律$\sum i_k=0$与回路的基尔霍夫电压定律$\sum v_k=0$直接来自守恒，是后续各课的主力工具。
- SI词头（n, $\mu$, m, k, M）是必需的，不是可选的；总要根据词头校核答案的数量级。
:::

$10\ \mathrm C$的电荷以恒定速率在$2\ \mathrm s$内流过一个曲面。电流是多少？

一条导线标注了向右的参考电流，但实测电子实际向左漂移。标注的常规电流是正还是负？这个符号意味着什么？
::: hint
常规电流与电子流动方向相反。

标注的常规电流为负。这只告诉你电荷沿参考方向的反方向流动，与大小无关。保留参考方向并报告带符号的值，而不要悄悄把它翻正。

::: exercise 小负载的能量 {level=2 check="1080"}
一台器件在$3\ \mathrm V$下以$100\ \mathrm{mA}$恒流工作一小时。它消耗多少焦耳？
::: hint
先求功率，再乘以以整秒计的时间。
:::
::: solution
功率$p = vi = 3\times0.1 = 0.3\ \mathrm W$。一小时是$3600\ \mathrm s$。能量$= 0.3\times3600 = 1080\ \mathrm J$。若你算出$108\ \mathrm J$，说明你用了分钟；一律先化成秒。
:::
:::

::: exercise 电阻的电流与功率 {level=2}
一只$2\ \mathrm{k\Omega}$电阻两端电压为$4\ \mathrm V$。求以毫安计的电流与以毫瓦计的功率。
::: hint
用$i=v/R$，再用$p=v i$或$p=v^2/R$。

$i = 4/2000 = 2.0\ \mathrm{mA}$。功率$p = v^2/R = 16/2000 = 8\ \mathrm{mW}$。

::: exercise 双元件回路 {level=2}
一个电源与一个电阻构成单一回路。电源为$10\ \mathrm V$，其上端标$+$，电流$2\ \mathrm A$沿顺时针方向。给每个元件标定功率，并指出谁吸收、谁提供。
::: hint
对每个元件用关联参考方向；两个功率之和必为零。
:::
::: solution
电源把电流从其$+$端推出，故按关联参考方向其吸收功率为$p = -v i = -20\ \mathrm W$，即它提供$20\ \mathrm W$。电阻吸收$+20\ \mathrm W$。提供的等于吸收的，正如守恒所要求的。
:::
:::

::: exercise 估算漂移速度 {level=3}
铜的自由电子密度为$n=8.5\times10^{28}\ \mathrm{m}^{-3}$，导线截面$A=10^{-6}\ \mathrm{m^2}$。若通以$1\ \mathrm A$电流，估算电子漂移速度。
::: hint
用$i = n q A v_d$，其中$q$取电子电荷的大小。
:::
::: solution
改写为$v_d = i/(n q A) = 1/(8.5\times10^{28}\times1.602\times10^{-19}\times10^{-6}) = 7.34\times10^{-5}\ \mathrm{m/s}\approx0.07\ \mathrm{mm/s}$。电子以每秒不到一毫米的速度缓慢爬行，而信号本身在介质中近乎以光速传播。这是一次数量级估计，不是拿来对照精确值的数据。
:::
:::

::: exercise 电压为负时是提供还是吸收 {level=3 check="-4"}
某元件$v=-2\ \mathrm V$，电流$i=2\ \mathrm A$从$+$端流入。用关联参考方向，吸收功率是多少？它在吸收还是提供？
::: hint
直接计算$p=vi$，两个符号都保留。
:::
::: solution
$p = vi = (-2)(2) = -4\ \mathrm W$。吸收功率为负，意味着该元件实际在提供$4\ \mathrm W$。校验值$-4$记录的是带符号的吸收功率。
:::
:::
