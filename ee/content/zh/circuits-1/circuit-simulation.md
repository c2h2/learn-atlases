到这里，你已经能手解电阻网络、一阶网络与二阶网络；对单元件或两元件的情形，这是趁手的工具。一个含十个元件的网络、一个非线性元件、一个随时间动作的开关、或者每个器件都有容差，就远远超出了你头脑能携带的规模，而出路不是推导它，是让机器去积分它。电路仿真是从你手推过的同一组方程得到正确数值答案的艺术；顾名思义，它就是对网络行为的计算。本课说明仿真器到底做什么——它形成的矩阵、它使用的时间积分器——以及这三个环节中任何一个上的错误假设会造成的数值误差、收敛误差与伪象，并给你一种纪律：拿仿真结果与手算结果对照，从而知道什么时候那个数是物理、什么时候它是方法。

## 仿真器做什么，不做什么

值得把分工说清楚，因为它决定了什么是你的责任、什么是机器的。

::: definition 电路仿真 {#def-sim}
**电路仿真**是对所描述网络的电压与电流——作为时间或频率的函数——的数值计算，通过求解网络自身的方程完成。它不替代网络的定律，而是计算这些定律。仿真器接收网络的描述，组建控制方程，再用它自己的数值方法求解；答案的质量由描述、方程与方法决定，而不取决于任何其他人的手艺。
:::

网络的描述——元件及其连接的清单——就是**网表**，是你唯一需要提供的那样东西。其余一切：矩阵、积分器、记账，都是仿真器的事；它存在的意义是把你从代数里解放出来，而不是把你从物理里解放出来。仿真中最重要的习惯——也正是本课反复训练的——是拿仿真结果对同一个网络缩小版本做一次手算，因为一个不报错的仿真器照样可能给出错误答案：网表错了、步长错了、或者收敛误差悄悄溜了进来。

::: warning 错误的网表不报错，它只是给出答案 {#warn-netlist}
事后发现错误的仿真结果，多数错在网表：一个节点号重复、一个数值差了十倍、一个元件漏画。仿真器不知道答案该是什么，它只会乐意地报告你所描述的那个网络——而不是你心里想的那个——的结果。这是手算符号错误在仿真里的对应物，只是它远更难被发现，因为数字看起来合理，而且它是机器交给你的。唯一的防御是对缩小的子网络做手算校核；它成本很低，所以要做。
:::

## 矩阵：修正节点分析法

仿真器搭建的方程，正是你本可以手工搭出的那一个；知道它的形状，是为仿真调试做准备的最好一件事。

::: definition 修正节点分析法 {#def-mna}
**修正节点分析法**（modified nodal analysis，MNA）对每个电流不单由电压决定的元件——电容、电感、运放、电流源——为它添加一个电流变量，从而在节点分析法的基础上加以修正。结果是关于节点电压与所选支路电流合并向量的一个矩阵方程；矩阵由每个元件的**模图**（stamp）逐个叠加到一个逐渐增大的系统上而成。这就是通用仿真器所求解的那套方程——直流的，以及暂态每一步的交流与暂态的——的标准形式。
:::

::: theorem 从网表到矩阵 {#thm-mna}
仿真器读入网表，把每个元件按它自己的节点与电流变量打上模图，组装成整个系统并求解。求直流工作点时，它解一个线性方程组；求暂态时，它在每一步解同一个方程组——由积分器把元件阻抗换成它的逐步长形式——把状态从一个时刻推进到下一个时刻。联立方程的个数就是未知量的个数：节点电压加上追加的电流；矩阵对每种元件类型都相同，只是模图不同。
:::

这对你之所以重要，是因为每当仿真不收敛，你面对的东西——或者它病态的症状——就是矩阵的形状。电容两端短接的网表、与电流源并联的电感、或纯电感构成的回路，都会产生奇异或近乎奇异的矩阵；仿真器或者不收敛，或者收敛到一个错误结果，而故障就住在矩阵里。知道矩阵是一模图一模图搭起来的、知道惹事的元件是让它的模图出事，你才能靠逐个关断元件直到矩阵收敛来找到肇事者——这就是标准的调试程序。

::: example 一张网表及其直流解 {#ex-mna}
描述这样一个网络：$10\ \mathrm V$电压源与一只$10\ \mathrm{k\Omega}$电阻串联，馈给一个节点，该节点还驱动一个到地的$1\ \mathrm{mA}$电流源；并用手算的MNA给出节点电压。
::: solution
把该节点记为节点1，地记为0。从电源到节点1的电阻承载$(10 - v_1)/10\ \mathrm{k}$，电流源从节点1取走$1\ \mathrm{mA}$。节点1的基尔霍夫电流定律为

$$
\frac{10 - v_1}{10\ \mathrm{k}\Omega} = 1\ \mathrm{mA},
$$

于是$10 - v_1 = 10\ \mathrm V$，$v_1 = 0\ \mathrm V$。这就是直流工作点；仿真器对这张网表解同一MNA，得到的也正是$0\ \mathrm V$。例题的要点不在算术而在对应关系：手算方程与矩阵方程是同一条方程——一条由你在一个节点上写下，一条由仿真器打进矩阵——两者相符，正是网表与方法都对的标志。
:::
:::

## 时间积分器

暂态是一个一阶微分方程组；仿真器把导数换成一个公式——时间积分器——一步一步推进它。这个公式的选择，是暂态结果准确度的最大单一决定因素，也是一张正确的网表仍可能给出错误答案的唯一所在。

::: proposition 显式与隐式，以及两种标准方法 {#prop-int}
**显式欧拉（Euler）**法$x_{n+1} = x_n + h\,f(x_n)$是一阶的，简单得无条件，但不精确，且只对步长$h$有条件稳定。**梯形**法$x_{n+1} = x_n + \frac{h}{2}\left(f(x_n)+f(x_{n+1})\right)$是二阶的，对电路分析里占支配地位的线性问题无条件稳定，代价是每步要解一个小型隐式方程组。仿真器默认用其中之一，或允许你选择；同样步数下，两者精度的差距是巨大的。
:::

::: example 显式欧拉与梯形法求解RC阶跃 {#ex-int}
一个$RC$网络，$R=10\ \mathrm{k\Omega}$、$C=1\ \mu\mathrm F$、$\tau=10\ \mathrm{ms}$，由$10\ \mathrm V$阶跃驱动，从$0$积分到$20\ \mathrm{ms}$，取$100$步、每步$0.2\ \mathrm{ms}$。把显式欧拉的结果与梯形法的结果，对照精确解$10(1-e^{-t/\tau})$比较。
::: solution
$20\ \mathrm{ms}$处的精确值为$10(1-e^{-2}) = 8.647\ \mathrm V$。显式欧拉按$v_{n+1}=v_n + (h/C)(10-v_n)/R$推进，得$8.674\ \mathrm V$，误差$0.31\%$。隐式梯形法解$v_{n+1} = \dfrac{v_n(1-h) + h\cdot10}{1+h}$，其中$h=1/(RC)\cdot h\cdot\dfrac{1}{2}=0.01$，得$8.647\ \mathrm V$，误差$0.001\%$。同样步数下，梯形法精确三个数量级——这正是仿真器默认采用隐式方法的实际原因，也正是当一次暂态看起来阻尼过重或过快时，显式欧拉是第一个该怀疑的。
:::
:::

::: widget plot
f: 10*(1-exp(-x))
x: 0, 20
y: 0, 10
caption: $RC$网络的精确响应$v(t)=10(1-e^{-t/\tau})$，其中$\tau=10\ \mathrm{ms}$，$t$以毫秒计。这条指数曲线就是用来比较各时间积分器的基准。步长选得不好，或大步长下的显式欧拉，会越过或落后这条曲线；仿真与这条曲线之间的差距就是积分误差，它由你选的步长与方法控制。
:::

## 刚性、步长与收敛

积分器并非不受约束。步长必须对照网络中最快的时间常数来选；不这样做，即使每个元件、每个数值都对，结果仍是错的。

::: proposition 步长与最快时间常数的比例 {#prop-step}
显式积分器只在步长低于由网络最小时间常数确定的界时才稳定；隐式积分器虽无条件稳定，却也只在步长相对它足够小时才精确。一条有用的工作规则是：步长至多取你在意的最小时间常数的五十分之一到一百分之一，并让仿真器的自适应步长控制在响应变化快处自动缩小步长。无视这一点——对一个网络的最快模态用太大的固定步长——得到的是看起来稳定却不精确的结果，是仿真里与混叠对应的现象。
:::

又一个误差来源是每一步非线性求解的收敛，器件含二极管或晶体管时就需要它，因为元件的工作点本身就是未知的。仿真器在每一步解一条非线性方程；若初始猜测不好，迭代可能漂移、振荡，或停在一个错误的根上。标准的补救——更好的初始猜测、更小的步长、换一种非线性方法、把工作点同手算校核一遍——你都伸手可得；而首先该伸手的是工作点，因为错误的直流工作点正是暂态看起来不对的最可能原因。

::: example 由时间常数定步长 {#ex-step}
某网络最快的时间常数是$10\ \mu\mathrm s$。按五十分之一的工作规则，显式方法该用多大的步长？
::: solution
$10\ \mu\mathrm s$的五十分之一，步长为$10\ \mu\mathrm s/50 = 0.2\ \mu\mathrm s$。按一百分之一则是$0.1\ \mu\mathrm s$。这条规则为步长设下一道界，也是你信任一次暂态之前唯一该核对的数，因为对最快模态太大的步长，即使网表完美，给出的结果也只能是大致正确。
:::
:::

::: warning 刚性与错误的积分器 {#warn-stiff}
含有两个相差悬殊时间常数的网络——比如一只$1\ \mathrm nH$的快电感和一只$10\ \mathrm s$的慢电容——是**刚性**的。显式积分器除非步长极小（由快常数决定）就不稳定，于是整次运行的步数与两个时间常数之比成正比，这个数可以达到十亿以上。隐式积分器对付刚性的代价与对付非刚性问题相同，这就是通用仿真器默认采用隐式方法的实际原因。若一个刚性网络跑得慢，或者跑完了却给出噪声很大的结果，病因就是刚性，药方是隐式方法，而不是更小的步长。
:::

## 蒙特卡洛分析与灵敏度

理想情况能用、换真实器件就失效的设计，正是仿真挣饭钱的地方，因为器件的分散性本身就是一条待解的电路。

::: definition 蒙特卡洛分析与灵敏度 {#def-mc}
**蒙特卡洛**（Monte Carlo）分析把网络求解许多遍，每遍的器件数值都从其容差分布中抽取，然后报告输出的统计量：均值、标准差、极值。**灵敏度**分析则对每个器件报告输出对该器件的偏导数，即标称值处器件每变化一点、输出随之改变的分量。两者互补，合起来告诉你哪些器件要紧、设计应当如何变得鲁棒。
:::

::: example 分压器的容差 {#ex-mc}
一个$10\ \mathrm V$的分压器，$R_1 = 1\ \mathrm{k\Omega}$、$R_2 = 1\ \mathrm{k\Omega}$，由它供电，输出为$v = 10\,R_2/(R_1+R_2)$。若$R_2$是$\pm 5\%$容差的器件，输出的范围是多少？
::: solution
输出是$R_2$的函数，随它递增。两个端点处：$R_2 = 0.95\ \mathrm{k\Omega}$给出$v = 10\times0.95/(1+0.95) = 4.87\ \mathrm V$；$R_2 = 1.05\ \mathrm{k\Omega}$给出$v = 10\times1.05/(1+1.05) = 5.12\ \mathrm V$。于是一个$\pm 5\%$的器件容差产生$4.87$到$5.12\ \mathrm V$之间的输出，在$5\ \mathrm V$标称值上约$\pm 2.4\%$的波动。这就是单次理想仿真里看不到的设计后果，也是为什么容差分析是设计的一部分，而不是事后的附加。蒙特卡洛分析用器件真实的分布抽样，给出同样的范围，并给出输出落在任一区间内的概率——那才是规格真正要问的数。
:::
:::

::: quiz
仿真器给出的一次暂态比你手算的稍微更阻尼一点。网表核对无误。最可能的原因是什么？首先该试什么？
- [x] 步长对网络的最快模态太大，或积分器不精确；试更小的步长或改用隐式方法
- [ ] 电源数值错了
- [ ] 两个电阻的值接反了
- [ ] 是仿真器的硬件故障
::: solution
网表正确时结果看似稳定却略有偏差，正是步长太大或积分器不精确的标志；首先该试的是更小的步长，或换成隐式的高阶方法。其余选项——电源数值、电阻数值、硬件故障——都有可能，但在网表核对无误、结果只是略有偏差而不是差一个比例因子的情况下，可能性都更小。
:::
:::

## 后续内容

有了矩阵、积分器、步长规则与容差分析，你现在知道仿真器在做什么，也就能信任一个结果、找出一个错的结果，并按症状去修网表、修步长或修工作点。在后面各课的频域分析与变换器设计中，你会以更丰富的形式再遇到同样的工具；而把手算结果与仿真对照、知道答案里哪一部分是网络、哪一部分是方法的这条纪律，是全课最能迁移的技能。在[[circuits-1/second-order-circuits]]中你已经见过仿真在此要计算的那个响应；在后来的电子学课程中，你会遇到把同一套MNA逼到极限的非线性与数模混合网表。

::: history
数值电路分析的实践，以及名为修正节点分析法的特定矩阵形式，出现在1950至1960年代，电路仿真器就在那时以现代面貌成形。**SPICE**（Simulation Program with Integration Circuits）之名，给了1960至1970年代开发的第一个通用仿真器；它的后代——各种商业与开源仿真器——是今天电子设计的主力。时间积分器、显式与隐式方法、刚性的处理，属于求解器的数值常微分方程内容；蒙特卡洛与灵敏度分析则是设计流程加入的统计内容。请在后面的课程中继续前进，在频域与变换器设计中再遇同样的工具——那时，你刚学会读的这张矩阵，正是设计本身。
:::

::: summary
- 电路仿真对网络自身的方程做数值计算。网表、矩阵与积分器是三样必须正确的东西；拿手算结果对照仿真结果，是让它们保持正确的纪律。
- MNA给非电压驱动的元件添加电流变量，把节点分析法加以扩充；仿真器把每个元件打进矩阵并求解——在直流工作点上，也在暂态的每一步上。
- 时间积分器——显式欧拉或隐式梯形——决定暂态的精度；同样步数下，对电路分析的线性问题，梯形法精确得多。
- 步长必须相对最小时间常数足够小；对时间常数悬殊的刚性网络，必须用隐式或自适应积分器。
- 错误的网表——漏画的元件、差了十倍的数值——不报错，它给出错误答案；唯一的防御是对缩小的子网络做手算。
- 蒙特卡洛与灵敏度把器件的容差变成输出的容差，这是设计数值，不是事后的补充。
:::

## 习题

::: exercise 网表到单个节点 {level=1 check="5"}
一个$1\ \mathrm{mA}$电流源馈给一个节点，该节点经$5\ \mathrm{k\Omega}$接地。节点的直流电压是多少？
::: solution
由KCL与欧姆定律，$v = iR = 1\ \mathrm{mA}\times5\ \mathrm{k\Omega} = 5\ \mathrm V$。单节点MNA解出的也是它。
:::
:::

::: exercise 两个电阻，一个节点 {level=1 check="6.67"}
$10\ \mathrm V$电源经$10\ \mathrm{k\Omega}$驱动一个节点，该节点再经$20\ \mathrm{k\Omega}$接地。节点电压是多少？
::: solution
这是分压：$v = 10\times20/(10+20) = 6.67\ \mathrm V$，正是MNA会解出的直流工作点。
:::
:::

::: exercise 一阶阶跃上的显式欧拉 {level=2}
一阶系统$x' = (10 - x)/\tau$，$\tau = 1$，从$0$阶跃到目标$10$，用显式欧拉积分一步，步长$h = 0.1$。结果是多少？$0.1$之后的精确值呢？
::: hint
欧拉：$x_1 = x_0 + h(10 - x_0)$；精确：$x = 10(1 - e^{-h})$。
:::
::: solution
欧拉给出$x_1 = 0 + 0.1\times(10-0) = 1.0$。精确值为$10(1-e^{-0.1}) = 10\times0.0952 = 0.952$。一步之内欧拉就比精确值高出约$5\%$，即一阶误差，它会沿整次运行累积。这就是对略有偏差的暂态该首先怀疑显式方法的实际原因。
:::
:::

::: exercise 同一步上的梯形法 {level=2 check="0.952"}
对同一系统用隐式梯形法，$\tau=1$，一步$0.1$。结果如何？与欧拉相比怎样？
::: hint
由梯形形式解$x_1 = (x_0 + h\cdot 10/(2\tau)) / (1 + h/(2\tau))$。
:::
::: solution
$h/(2\tau) = 0.05$时，梯形法给出$x_1 = (0 + 0.05\times10)/(1+0.05) = 0.5/1.05 = 0.476$。精确值是$0.952$。嗯，这是$x'=(10-x)$的响应；重新推导：对$x' = (10-x)$，梯形法是$x_1 = x_0 + \frac{h}{2}\left[(10-x_0)+(10-x_1)\right]$，于是$x_1(1+h/2) = x_0(1-h/2) + 10h$，得$x_1 = (0 + 0.1\times10)/(1+0.05) = 0.952$。这基本上就是精确值——梯形法的二阶精度——对比欧拉的$1.0$。把它们分开的是方法，不是机器。
:::
:::

::: exercise 由时间常数定步长 {level=3 check="0.1"}
你的网络最小时间常数为$1\ \mathrm{ms}$。用显式、非自适应方法时，按一百分之一该取多大的步长？
::: hint
最小时间常数的一百分之一。
:::
::: solution
$1\ \mathrm{ms}/100 = 0.01\ \mathrm{ms} = 10\ \mu\mathrm s$。这条规则为步长设下一道界，是信任暂态之前该核对的数。
:::
:::

::: exercise 增益级的蒙特卡洛分析 {level=3 check="0.022"}
分压器$R_1 = 1\ \mathrm k\Omega$、$R_2 = 1\ \mathrm k\Omega$、$10\ \mathrm V$，两个电阻都有$\pm 5\%$的独立容差。输出的最坏情况范围是多少？
::: hint
输出为$10\,R_2/(R_1+R_2)$；用端值求极值。
:::
::: solution
$R_2$取大、$R_1$取小时输出最大：$R_2 = 1.05$、$R_1 = 0.95$，得$10\times1.05/(0.95+1.05) = 10\times1.05/2 = 5.25\ \mathrm V$。$R_2$取小、$R_1$取大时输出最小：$R_2 = 0.95$、$R_1 = 1.05$，得$10\times0.95/2.1 = 4.52\ \mathrm V$。于是最坏情况的输出范围为$4.52$到$5.25\ \mathrm V$，在标称$5\ \mathrm V$上约$\pm 15\%$的波动——比单个器件的情形大，因为两个器件可能同时朝坏的方向移动。这就是两只电阻的分压器不如只由输出定范围的那种鲁棒的原因，也是容差分析所要的那类数。
:::
:::

::: exercise 非线性网表上的收敛 {level=3}
含二极管的网表在某一步不收敛，并且发现工作点落在二极管阈值以下$5\ \mathrm{mV}$处，处于截止状态。可能的原因是什么？首先试什么？
::: hint
二极管恰在阈值附近；非线性求解对初始猜测敏感。
:::
::: solution
阈值附近的二极管有着极陡的非线性伏安关系，初始猜测若落在错误一侧，非线性求解就可能漂移。首先该试的是改进初始猜测——把二极管电压设得更接近预期值——或者取更小的步长，让工作点在一步之内移动得更少，或者换一种在阈值附近更鲁棒的非线性方法。工作点的检查——二极管在阈值以下$5\ \mathrm{mV}$——正是告诉你求解敏感的东西，也正是问题出在非线性求解而不是网表的信号。
:::
:::

::: exercise 刚性网络与缓慢的运行 {level=3}
一台变换器既有$1\ \mathrm nH$的电感又有$10\ \mathrm s$的电容，显式暂态运行花费很长时间。这个问题叫什么？实际的解决办法是什么？
::: hint
两个时间常数相差约十亿倍。
:::
::: solution
这就是**刚性**：约$1\ \mathrm nH$量级的快常数迫使显式方法的步长极小，于是整次运行的步数与两个时间常数之比成正比，这个数极大。解决办法是隐式或自适应积分器——它对线性部分无条件稳定，可以按慢常数取步长、同时仍把快常数分辨清楚——从而运行时间与刚性程度无关。这就是通用仿真器默认采用隐式方法的原因，也是刚性网络跑得慢时你该立刻改用的东西。
:::
:::
