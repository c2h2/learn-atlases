到目前为止，本课程遇到的每个网络都是代数式的：给定电源，电压与电流就由欧姆定律和基尔霍夫定律确定，与时间无关。上一课的两个储能元件改变了这一点。一旦引入电容或电感，网络就有了状态、有了初始条件，响应会随时间展开。最简单的一类这样的网络——只含一个储能元件和任意多个电阻——就是一阶电路，它是本课以及本领域其余大部分内容的主力工具。本课从元件自身的定律出发推导响应，说明它总是一个由单一时间常数支配的指数，并给出一条普适公式，它涵盖你会遇到的所有充电、放电、上升与下降的一阶行为。

## 一阶电路及其时间常数

值得先把一阶电路到底是什么说清楚，因为这个名字恰好告诉了你答案长什么样。

::: definition 一阶电路 {#def-foc}
**一阶电路**只含一个储能元件——电容或电感——的能量存储，连同电阻与独立源，且仅有这一个储能元件。它的行为由一条一阶微分方程支配，其自然响应与受迫响应都是单指数。**时间常数**$\tau$对$RC$电路为$RC$，对$RL$电路为$L/R$，它决定每一类这样响应的速率。
:::

两种元件的推导相同，而且很短。取一只电容与电阻$R$、直流电压源$V$串联。基尔霍夫电压定律把电源电压写成各元件电压之和，电容的定律是$i=C\,\mathrm dv_C/\mathrm dt$。消去电流、改用电压，整个网络就由一个关于单个变量的一阶方程描述，而它的解就是指数。电阻与电容只以乘积$RC$进入方程，这正是该乘积是一个时间、并被称为时间常数的原因。

::: theorem 一阶响应 {#thm-foc}
一阶电路的电压或电流在直流电源下，按单个指数从初始值移动到终值，

$$
x(t) \;=\; x(\infty) + \big[x(0) - x(\infty)\big]\,e^{-t/\tau}, \qquad t\ge 0,
$$

其中$x(0)$是换路之后的值，$x(\infty)$是直流稳态值，$\tau$是时间常数，$RC$或$L/R$。这一条公式涵盖每一种一阶响应：电容的充电、电容的放电、电感电流的上升与电感电流的衰减。
:::

这条公式之所以如此有力，是因为它是带常数激励项的一阶方程的通解，而这样的形式只有一个。两个常数——$x(\infty)$与指数的系数——由稳态和初始条件确定，速率由$\tau$确定。无论电路长成什么样，只要它是一阶的，答案的形状就是这一个，变的只是数字。这与电阻网络的情形恰好相反——那里的答案取决于具体网络——这正是一阶响应容易学、用处广的原因。

## RC的充电与放电

最常见的两种一阶行为是电容的充电与放电，两者都是上面定理的实例。

::: example 电容的充电 {#ex-charge}
一只初始未充电的$100\ \mu\mathrm F$电容经一只$10\ \mathrm{k\Omega}$电阻接到$10\ \mathrm V$电源上。求开关闭合后$0.5\ \mathrm{ms}$时刻的电压，以及该时刻的电流。
::: solution
时间常数为$\tau = RC = 10\times10^{3}\times100\times10^{-6} = 1\ \mathrm{ms}$。初始电压为$0$，终值是电源电压$10\ \mathrm V$，于是

$$
v_C(t) = 10\left(1 - e^{-t/\tau}\right).
$$

在$t = 0.5\ \mathrm{ms}$处，$t/\tau = 0.5$，$v_C = 10(1 - e^{-0.5}) = 10(1-0.6065) = 3.93\ \mathrm V$。同一时刻的电流为$i = C\,\mathrm dv_C/\mathrm dt = (10/RC)e^{-t/\tau} = (10/1\ \mathrm{ms})e^{-0.5} = 10\ \mathrm{kA}\times0.6065 = 10\ \mathrm k\Omega$，得$i = 10/10\ \mathrm{k\Omega}\times0.6065 = 0.607\ \mathrm{mA}$。$t=0$时电流为$10/10\ \mathrm{k\Omega}=1\ \mathrm{mA}$，即电源的全部电流；$t\to\infty$时电流为零，电容已充满。
:::
:::

::: example 到达终值某一分数所需的时间 {#ex-frac}
还是这个电路，电压升到电源值的$90\%$需要多长时间？升到$99\%$呢？
::: solution
令$v_C = 0.9\times10 = 9\ \mathrm V$，需要$1 - e^{-t/\tau} = 0.9$，故$e^{-t/\tau} = 0.1$，$t/\tau = \ln 10 \approx 2.30$。由$\tau = 1\ \mathrm{ms}$得$t = 2.30\ \mathrm{ms}$。对$99\%$，$e^{-t/\tau}=0.01$，$t/\tau = \ln 100 \approx 4.61$，故$t = 4.61\ \mathrm{ms}$。工程上常用的经验法则——一阶响应经过大约五个时间常数即进入终值的$1\%$以内——说的正是这件事：五个时间常数给出$e^{-5} \approx 0.0067$，即尚余摆幅的$0.67\%$。
:::
:::

放电是对偶情形，把初始值与终值互换，仍是同一条公式。一只先充好电、再接上电阻的电容给出

$$
v_C(t) = v_0\,e^{-t/\tau},
$$

从$v_0$出发衰减到零。电流为$i = -v_0/R\,e^{-t/\tau}$，按关联参考方向它为负，因为此刻电容在提供能量而不是吸收能量。电容最初储存的能量$\tfrac12 C v_0^2$以热的形式交给了电阻，任一时刻电阻耗散的功率为$v^2/R$，在$t=0$最大，并随衰减电压的平方下降。

## RL电路

电感版本是它的电路对偶，同一定理照样成立，只是时间常数换成$L/R$，变量由电压换成电流。

::: proposition RL的上升与衰减 {#prop-rl}
一只电感与电阻$R$、直流电压源$V$串联，初始电流为零，则

$$
i_L(t) = \frac{V}{R}\left(1 - e^{-t/\tau}\right), \qquad \tau = \frac{L}{R},
$$

升至稳态电流$V/R$。断开电源后，电流按$i_L = i_0 e^{-t/\tau}$衰减。电感电压在稳态为零；在换路瞬间它最大，取某一种极性；在衰减期间极性相反。
:::

::: example 电感电流的上升 {#ex-rl}
一只$20\ \mathrm{mH}$电感经一只$100\ \Omega$电阻接到$12\ \mathrm V$电源上，初始电流为零。求$100\ \mu\mathrm s$之后的电流与时间常数。
::: solution
时间常数为$\tau = L/R = 20\times10^{-3}/100 = 0.2\ \mathrm{ms} = 200\ \mu\mathrm s$。稳态电流为$V/R = 12/100 = 0.12\ \mathrm A$。在$t = 100\ \mu\mathrm s$处，$t/\tau = 0.5$，故$i_L = 0.12(1 - e^{-0.5}) = 0.12\times0.3935 = 0.0472\ \mathrm A$。$t=0$时电流为零，电源电压全部加在电感上；随着电流上升，电感电压下降，它与电阻一起分掉那$12\ \mathrm V$。到$5\tau = 1\ \mathrm{ms}$，电流已进入$0.12\ \mathrm A$的$1\%$以内。
:::
:::

::: example 已充电电容的放电 {#ex-discharge}
一只充到$12\ \mathrm V$的$10\ \mu\mathrm F$电容经$1\ \mathrm k\Omega$电阻放电。求时间常数、一个时间常数之后的电压，以及该时刻电阻耗散的功率。
::: solution
时间常数为$\tau = RC = 1000\times10\times10^{-6} = 0.01\ \mathrm{s} = 10\ \mathrm{ms}$。衰减规律为$v_C = 12\,e^{-t/\tau}$，故$t=\tau$时电压为$12\,e^{-1} = 12\times0.3679 = 4.41\ \mathrm V$。该时刻电阻的功率为$v^2/R = 4.41^2/1000 = 0.0195\ \mathrm W = 19.5\ \mathrm{mW}$。$t=0$的初始功率为$12^2/1000 = 0.144\ \mathrm W$，是它的四倍；功率随衰减电压的平方下降，故大部分能量在最初一两个时间常数内就交了出去。
:::
:::

::: warning 电感电流与电容电压不能跃变 {#warn-continuity}
电容电压与电感电流都对时间连续。理想电容两端的电压不能瞬时改变，因为那需要无穷大的电流；理想电感中的电流不能瞬时改变，因为那需要无穷大的电压。正是这两条连续性使一阶电路的初始条件有明确定义；也正因如此，真实的开关能让电感“飞起来”、让电容打出火花：元件抗拒突变，多出来的部分就化作周围网络中的大电压或大电流。
:::

::: quiz
某$RC$电路$R=5\ \mathrm{k\Omega}$、$C=200\ \mu\mathrm F$。它的时间常数是多少？
- [x] $1\ \mathrm{ms}$
- [ ] $0.5\ \mathrm{ms}$
- [ ] $2\ \mathrm{ms}$
- [ ] $10\ \mathrm{ms}$
::: solution
$\tau = RC = 5\times10^{3}\times200\times10^{-6} = 1\times10^{-3} = 1\ \mathrm{ms}$。
:::
:::

关于能量去向的一点说明，因为这个问题恰好能被一阶情形干净地回答。电容充电时，电源提供一份能量，它只取决于最终的电荷与电压；这份能量分成两部分：存进电容的与在充电电阻中耗散的。储存的部分是$\tfrac12 C V^2$，耗散的部分是剩余的。值得注意的是，这一分配与电阻无关：无论经$1\ \mathrm k\Omega$还是$10\ \mathrm k\Omega$充电，都是一半储存、一半损失，因为更大的电阻让充电变慢，却也把电流减小，两个效应在总量上恰好抵消。电感情形同理，只把电压与电流的角色互换。这一“能量分配与电阻无关”的性质是检验任何一阶计算的有用校核，也正是上面充电与放电两个例题在每一时刻都遵守的那条守恒。

## 普适公式与初始条件

本课最深的一点是：上面的一切——充电、放电、上升、衰减——都是同一条公式，不同的只是$x(0)$、$x(\infty)$与$\tau$。

::: theorem 一阶响应的普适形式 {#thm-universal}
任何一阶电路，无论是受迫的还是自然的，其每个电压与电流都具有形式

$$
x(t) = x(\infty) + \big[x(0) - x(\infty)\big]\,e^{-t/\tau},
$$

其中$x(0)$由初始状态确定，$x(\infty)$由直流稳态确定，$\tau$由$RC$或$L/R$时间常数确定。解这类问题的方法是：把储能元件换成它的直流等效（电容换成开路、电感换成短路）求出$x(\infty)$，由初始条件找出$x(0)$，求出$\tau$，然后代入。无须写出微分方程。
:::

这是本课程里最实用的结果：只要看到单个电容或电感和一些电阻、一个直流电源在一起，就该伸手用它。方法机械、永远奏效，它把一条微分方程换成了三步代数。微分方程仍然在那里，公式正是从它来的；只是对一阶情形，你永远无须手工求解，因为答案的形式已知，要找的只是常数。同样的模式——以更丰富的形式——会在之后的每一门课里重复出现，从控制到电力电子再到信号处理。

x: 0, 5

caption: 例中$100\ \mu\mathrm F$电容向$10\ \mathrm V$充电，$v_C(t)=10(1-e^{-t/\tau})$，其中$\tau=1\ \mathrm{ms}$，$t$以毫秒计。曲线从零上升、渐近地趋于电源值：一个时间常数走过全程的约$63\%$，五个时间常数附近达到$99\%$。指数形状是一阶一切响应的标志。

::: warning 电感衰减时的大电流 {#warn-fly}
当你把电源从一只已经储能的电感上断开时，电流必须另有去处，因为它不能瞬时改变。实际上，它会在通路剩下的部分上压出一个大电压，两种极性都有可能；这正是会损坏开关与二极管的电感反冲，也是为什么继电器线圈总要并一只二极管。理想模型——电流经剩余电阻衰减——是对的，但把通路断开的那个理想开关不是，反冲就是非理想开关的代价。
:::

## 后续内容

有了普适的一阶公式、时间常数，以及电感电流与电容电压的连续性，任何单储能元件电路你都能不写微分方程而求解。在[[circuits-1/second-order-circuits]]中，你将遇到含两个储能元件的网络，响应不再是单个指数而是两个之和，行为分化为欠阻尼、临界阻尼与过阻尼——它们正是二阶系统的标志。同样的章法——找初始条件、找稳态、找速率——会延续下去，而一阶情形正是二阶情形赖以建立的基础。

::: history
$RC$与$RL$电路的指数响应，在电容、电感及其定律确立之后随即为人所知，那是在十八世纪末十九世纪初；时间常数与五个时间常数的经验法则，到二十世纪初已成为工程实践的常识，当时人们用它来为无线电与电话电路的耦合与旁路电容选值。普适公式——先求$x(0)$、$x(\infty)$与$\tau$再代入的方法——是一阶情形的标准教科书表述，自1920至1930年代第一批电路分析教科书以来一直如此。请继续阅读[[circuits-1/second-order-circuits]]，看两元件网络及其产生的阻尼振荡。
:::

::: summary
- 一阶电路只有一个储能元件，时间常数$\tau = RC$或$L/R$。
- 它的响应永远是单指数$x(t) = x(\infty) + [x(0) - x(\infty)]e^{-t/\tau}$；解这类问题的方法就是求$x(0)$、$x(\infty)$与$\tau$再代入。
- 电容充电$v_C = V(1-e^{-t/\tau})$，放电$v_C = v_0 e^{-t/\tau}$；电感电流上升$i_L = (V/R)(1-e^{-t/\tau})$，衰减$i_L = i_0 e^{-t/\tau}$。
- 电容电压与电感电流连续：两者都不能跃变，初始条件因而有明确定义。
- 大约五个时间常数进入稳态的$1\%$以内；一个时间常数走完总变化的约$63\%$。
- 电感反冲——电流通路被断开时的大电压——是电流连续性的推论，也是继电器线圈要并二极管的原因。
- 这条普适公式是其后二阶响应的基础。
:::

::: exercise RC电路的时间常数 {level=1 check="0.1"}
$2\ \mathrm{k\Omega}$电阻与$50\ \mu\mathrm F$电容。时间常数是多少？
::: solution
$\tau = RC = 2\times10^{3}\times50\times10^{-6} = 0.1\ \mathrm{s} = 100\ \mathrm{ms}$。
:::
:::

::: exercise 一个时间常数后的电压 {level=1 check="6.32"}
$10\ \mathrm V$电源以$\tau=1\ \mathrm{ms}$给未充电电容充电。$t=1\ \mathrm{ms}$时电压是多少？
::: solution
$v_C = 10(1-e^{-1}) = 10\times0.6321 = 6.32\ \mathrm V$。
:::
:::

::: exercise 电感的时间常数 {level=1 check="50"}
$100\ \mathrm mH$电感与$2\ \mathrm{k\Omega}$电阻。时间常数以毫秒计是多少？
::: solution
$\tau = L/R = 0.1/2000 = 5\times10^{-5}\ \mathrm{s} = 0.05\ \mathrm{ms} = 50\ \mu\mathrm s$。（校验值$50$以微秒计。）
:::
:::

::: exercise 从初始电压放电 {level=2 check="3.68"}
充到$10\ \mathrm V$的电容经$10\ \mathrm{k\Omega}$电阻放电，$C=1\ \mu\mathrm F$。一个时间常数后电压是多少？
::: solution
$v_C = 10\,e^{-1} = 10\times0.3679 = 3.68\ \mathrm V$。时间常数为$RC = 10\ \mathrm{k\Omega}\times1\ \mu\mathrm F = 10\ \mathrm{ms}$，放电到$3.68\ \mathrm V$发生在$t=10\ \mathrm{ms}$。
:::
:::

::: exercise 给定时刻的电感电流 {level=2 check="0.074"}
$30\ \mathrm mH$电感经$300\ \Omega$接到$15\ \mathrm V$电源上，初始未储能。$t=150\ \mu\mathrm s$时电流是多少？
::: hint
先求$\tau=L/R$，再用上升公式。
:::
::: solution
$\tau = 0.03/300 = 0.0001\ \mathrm{s} = 100\ \mu\mathrm s$。$t/\tau = 1.5$。稳态电流为$15/300 = 0.05\ \mathrm A$。$i_L = 0.05(1-e^{-1.5}) = 0.05\times0.7769 = 0.0388\ \mathrm A$。复核：$0.05\times0.7769 = 0.03885\ \mathrm A$。电流正在向$0.05\ \mathrm A$上升。
:::
:::

::: exercise 电流为什么连续 {level=3}
用电感中的能量解释，为什么电感电流不能瞬时改变。
::: hint
把电流的跃变与储能的变化联系起来。
:::
::: solution
电感的能量是$\tfrac12 L i^2$，是$i$的光滑函数。若$i$瞬时跃变，能量将在零时间内改变有限量，需要无穷大的功率$p = \mathrm dw/\mathrm dt \to \infty$，而这又需要无穷大的电压$v = L\,\mathrm di/\mathrm dt \to \infty$。有限电路供不出无穷大功率，故电流不能跃变，它是连续的。同样的论证配上$\tfrac12 C v^2$说明电容电压连续。这两条连续性正是初始条件有明确定义的物理基础。
:::
:::

::: exercise 稳定时间 {level=3 check="5"}
一阶响应到达终值的$1\%$以内需要多少个时间常数？
::: hint
由$e^{-t/\tau} = 0.01$解$t/\tau$。
:::
::: solution
$t/\tau = \ln 100 \approx 4.6$，约五个时间常数。五个时间常数处，$e^{-5} \approx 0.0067 = 0.67\%$的摆幅尚余，已在$1\%$以内。这就是稳定时间的标准经验法则。
:::
:::

::: exercise 充电电阻中耗散的能量 {level=3 check="0.5"}
$1\ \mu\mathrm F$电容经电阻从$0$充到$10\ \mathrm V$。电阻中耗散多少能量？电容中储存多少？
::: hint
比较电源供出的能量与储存的能量。
:::
::: solution
电源以$10\ \mathrm V$送出电荷$Q = C V = 10\ \mu\mathrm C$，故电源能量为$VQ = 100\ \mu\mathrm J$。电容储存$\tfrac12 C V^2 = \tfrac12\times10^{-6}\times100 = 50\ \mu\mathrm J$。差额$50\ \mu\mathrm J$耗散在电阻里，与阻值无关。这是经典结果：一半储存、一半损失，且与$R$无关。
:::
:::

::: exercise 电感反冲与二极管 {level=3}
解释为什么继电器线圈两端要并一只二极管；没有它，继电器断电时会发生什么。
::: hint
把线圈的储能与通路断开时的电压联系起来。
:::
::: solution
继电器线圈断电时，电流不能瞬时改变，必须继续流动。开关断开后，唯一的通路是经过二极管，电流在线圈、二极管与开关构成的回路中环流，随线圈自身电阻与二极管的电阻衰减。没有二极管，电流被迫停止，线圈便产生大电压（两种极性都可能）来驱动它，在开关触点上拉弧，并可能损坏驱动晶体管。二极管给电流一条低压通路，于是衰减温和，触点上的电压很小。这就是电感反冲，是电流连续性的直接推论。
:::
:::
