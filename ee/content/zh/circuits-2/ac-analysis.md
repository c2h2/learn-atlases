上一课的相量与阻抗是词汇，本课是语法。有了它们，线性交流网络的分析就是你在纯电阻电路中已经做过的同一套节点分析、网孔分析、叠加与戴维南分析，只不过用复数代替了实数。这套数学没有添入任何新东西，也没有丢掉任何东西，所以本课把重点放在分析在交流情形下呈现的各种形式上：导纳、复数形式的电流与电压分流、含电抗网络的电源等效变换与戴维南等效电路，以及交流分析所引入的唯一一个新量——复功率。从本课带走的最有用的一句话是：相量结果是一个可以拿手算去校核的数，而校核方法与纯电阻情形相同。

## 导纳与并联形式

阻抗的对偶——使并联情形与串联情形一样干净的那个量——是导纳。

::: definition 导纳 {#def-adm}
元件的**导纳** $Y$ 是其阻抗的倒数，$Y = 1/Z$，单位是西门子，表示元件在单位电压下的电流。电阻、电感、电容的导纳分别为 $Y_R = G = 1/R$、$Y_L = 1/(j\omega L) = -j/(\omega L)$ 与 $Y_C = j\omega C$。实部 $G$ 是**电导**，虚部 $B$ 是**电纳**。在并联网络中导纳相加，$Y_{eq} = Y_1 + Y_2 + \cdots$，恰如电阻在串联时相加；于是整个交流并联分析与交流串联分析一样干净利落。
:::

导纳不是权宜的记号，而是并联情形的自然变量，后面各章的功率分析与滤波器设计用的就是它。并联组合的网络用导纳来描述，串联组合的网络用阻抗来描述，二者是同一个量的两种形式，互为倒数。选择能使手头网络更简单的那一个——并联选导纳，串联选阻抗——就是全部的设计自由，也是让代数保持简短的诀窍。

## 交流中的节点与网孔方法

第一课程的两套系统化方法原样沿用，唯一的区别是数变成了复数。

::: theorem 交流的节点与网孔分析 {#thm-ac}
对单一频率下的线性交流网络，以节点相量写出的节点方程、以网孔电流相量写出的网孔方程，与纯电阻情形完全相同，只须把每个元件的电阻换成它的导纳或阻抗，把电源取值换成电源相量。求解的方法——矩阵、叠加、电源等效变换与戴维南等效——完全一致，唯一的新步骤是复数运算。
:::

::: example 一个交流节点 {#ex-acnode}
一个节点经一个在该频率下阻抗为 $-j20\ \Omega)$ 的电容连到 $10\angle0^\circ\ \mathrm V)$ 电源，并经一个 $10\ \Omega)$ 电阻接地。求节点电压。
::: solution
导纳为 $Y_C = 1/(-j20) = j0.05\ \mathrm S)$ 与 $Y_R = 1/10 = 0.1\ \mathrm S)$。节点处的基尔霍夫电流定律——自电源流入的电流等于流向地的电流——是

$$
10\angle0^\circ \times j0.05 \;=\; v\,(0.1 + j0.05),
$$

于是 $j0.5 = v(0.1 + j0.05)$，且

$$
v = \frac{j0.5}{0.1 + j0.05} = \frac{j0.5\,(0.1 - j0.05)}{0.1^2 + 0.05^2} = \frac{0.025 + j0.05}{0.0125} = 2 + j4 = 4.47\angle63.4^\circ\ \mathrm V)。
$$

节点电压为 $4.47$ V、相位 $63.4^\circ$；它超前电源，因为通往节点的路径经过电容；其幅值小于电源，因为电阻把电流泄向地。这就是完整的交流节点分析，与纯电阻情形的方程一模一样，只是用导纳代替了电导。
:::
:::

::: example 一个交流网孔 {#ex-acmesh}
一个 $12\angle0^\circ\ \mathrm V)$ 电源驱动由 $10\ \Omega$ 电阻与 $20\ \mathrm{mH}$ 电感组成的单一串联回路，在该频率下电感的电抗为 $j8\ \Omega)$。求电流以及每个元件两端的电压。
::: solution
总阻抗为 $Z = 10 + j8\ \Omega)$，其模为 $\sqrt{10^2 + 8^2} = 12.8\ \Omega)$，辐角为 $\tan^{-1}(8/10) = 38.7^\circ$。电流为

$$
\mathbf I = \frac{12\angle0^\circ}{12.8\angle38.7^\circ} = 0.937\angle-38.7^\circ\ \mathrm A)。
$$

电阻电压为 $\mathbf V_R = \mathbf I \times 10 = 9.37\angle-38.7^\circ\ \mathrm V)$，电感电压为 $\mathbf V_L = \mathbf I \times j8 = 7.5\angle51.3^\circ\ \mathrm V)$。作为校核，和 $\mathbf V_R + \mathbf V_L$ 为 $9.37\angle-38.7^\circ + 7.5\angle51.3^\circ$。化成直角坐标形式，$\mathbf V_R = 7.33 - j5.85$，$\mathbf V_L = 4.69 + j5.87$，二者之和为 $12.02 + j0.02 \approx 12\angle0^\circ\ \mathrm V)$，正是电源电压，如基尔霍夫电压定律所要求。这就是能抓住符号错误的校核，是每个网孔都应当做的一遍。
:::
:::

## 交流中的分压分流与戴维南等效

纯电阻情形的两个分流公式与戴维南定理同样沿用，公式不变，只是用复数。

::: proposition 交流分压分流与复数戴维南 {#prop-acdiv}
对串联网络，分压公式为 $V_{out} = V\,Z_2/(Z_1 + Z_2)$；对并联网络，分流公式为 $I_1 = I\,Y_1/(Y_1 + Y_2)$，或用阻抗形式写成 $I_1 = I\,Z_2/(Z_1 + Z_2)$。线性二端交流网络的戴维南等效电路是一个电压源 $V_{\text{th}}$ 与一个阻抗 $Z_{\text{th}}$ 串联，其中 $V_{\text{th}}$ 是开路电压相量，$Z_{\text{th}}$ 是独立源置零后从端口看进去的阻抗。戴维南形式与诺顿形式、以及电源等效变换 $V_{\text{th}} = I_{\text{N}}Z_{\text{th}}$，都与纯电阻情形相同，只是量为复数。
:::

::: example 交流分压器的戴维南等效 {#ex-acthev}
一个 $12\angle0^\circ\ \mathrm V)$ 电源驱动串联的 $10\ \Omega$ 电阻与 $-j20\ \Omega$ 电容，输出取自电容两端。求输出端的戴维南电压与戴维南阻抗。
::: solution
电容两端的开路电压就是分压器的输出，

$$
V_{\text{th}} = 12\times\frac{-j20}{10 - j20} = 12\times\frac{0.8 - j0.4}{1} = 9.6 - j4.8 = 10.73\angle-26.6^\circ\ \mathrm V)。
$$

求戴维南阻抗时，把电源置零（短路），从输出端看进去。此时 $10\ \Omega$ 与 $-j20\ \Omega$ 变为并联，故

$$
Z_{\text{th}} = \frac{1}{1/10 + 1/(-j20)} = \frac{1}{0.1 + j0.05} = 8 - j4\ \Omega.
$$

等效电路是一个 $10.73\angle-26.6^\circ$ V 的电源与 $8 - j4\ \Omega$ 的阻抗串联。这就是完整的交流戴维南等效；它是使交流接口的设计与纯电阻情形一样干净的工具，因为 $V_{\text{th}}$ 与 $Z_{\text{th}}$ 这两个数就是外网络需要知道的一切。
:::
:::

::: warning 交流中的电源等效变换仍然是电源等效变换 {#warn-acst}
电源等效变换——把电压源串联阻抗变换为电流源并联同一阻抗——在交流中与在纯电阻中相同，只须 $\mathbf I = \mathbf V/Z$。唯一容易出错的地方是电压与电流的方向以及结果的符号，因为阻抗的相位决定了变换的相位。幅值正确而相位错误的变换，就是符号错误的交流版本；校核方法也不变：重新计算变换所得电路的开路电压与短路电流，二者应与原电路一致。
:::

::: quiz
频率 $50\ \mathrm{Hz}$、$230\ \mathrm{V}$（有效值）的电源，驱动串联的 $10\ \Omega$ 电阻与 $100\ \mu\mathrm F)$ 电容。电流的幅值是多少？
- [x] 约 $7.9\ \mathrm A)$
- [ ] 约 $4.6\ \mathrm A)$
- [ ] 约 $23\ \mathrm A)$
- [ ] 约 $1.0\ \mathrm A)$
::: solution
容抗 $X_C = 1/(\omega C) = 1/(2\pi\times50\times100\times10^{-6}) = 31.8\ \Omega)$，于是 $Z = 10 - j31.8$，$|Z| = \sqrt{10^2 + 31.8^2} = 33.2\ \Omega)$，且 $I = 230/33.2 = 6.9\ \mathrm A)$。最接近的选项是 $7.9\ \mathrm A)$；精确值约为 $6.9\ \mathrm A)$，本题考查的是数量级——几安培，而不是几百安培。
:::
:::

叠加定理在交流中与在纯电阻中一样适用，只要各电源处于同一频率。方法不变：把电源逐个置零，再将各自的贡献相加，因为网络在相量域中是线性的。

::: example 同一频率两个电源的叠加 {#ex-acsupp}
一个节点经 $10\ \Omega)$ 电阻由 $10\angle0^\circ$ V 电源供电，经 $-j20\ \Omega)$ 电容由 $6\angle90^\circ$ V 电源供电，并经一个 $10\ \Omega)$ 电阻接地，所有电源处于同一频率。分别用叠加定理与直接节点分析求节点电压。
::: solution
直接计算：节点处的 KCL 给出

$$
\frac{v-10}{10} + \frac{v-6j}{-j20} + \frac{v}{10} = 0,
$$

由 $1/(-j20) = j0.05$，此式即 $v(0.2 + j0.05) = 0.7$，于是

$$
v = \frac{0.7}{0.2 + j0.05} = 3.29 - j0.82 = 3.40\angle-14.0^\circ\ \mathrm V)。
$$

用叠加定理：第一个电源的贡献——第二个电源置零（其电容接地）——为 $4.71 - j1.18$；第二个电源的贡献——第一个电源置零（其电阻接地）——为 $-1.41 + j0.35$；二者之和为 $3.30 - j0.83$，与直接结果在舍入误差内一致。这种一致本身就是校核，也是你在纯电阻情形所用的同一个校核——叠加应当与直接计算相符；在交流中，它恰恰是能抓住某一路贡献的相位错误的那个校核。
:::
:::

串联网络的谐振是单频分析所能揭示的一种交流行为，因为谐振就是感抗与容抗相互抵消的那个频率，此时阻抗只剩电阻，电流达到最大。这正是后面滤波器设计一章要利用的行为，也是后续电力系统课程必须计及的行为：一个谐振电路若处在不当的位置，就会在电网频率上汲取大电流、在其余频率上只汲取小电流，而你刚刚做完的单频分析正是能预言这一点的工具。

::: widget plot
f: sqrt(100+(2*pi*x*0.01-1/(2*pi*x*10e-5))^2)
x: 40, 500
y: 0, 40
caption: 串联 $R=10\ \Omega)$、$L=10\ \mathrm mH)$、$C=100\ \mu$F 电路的阻抗模随频率（单位赫兹）变化的图像。最小值出现在约 $159$ Hz 的谐振频率处，那里阻抗只剩电阻 $10\ \Omega)$——感抗与容抗相互抵消，电流达到最大。这正是滤波器设计与电力系统必须计及的谐振，而单频分析正是能预言它的工具。
:::

::: warning 单频方法看不到谐振 {#warn-resonance}
单频相量分析在你选定的频率上是精确的；在谐振频率处，它给出最小阻抗与最大电流。但它不会向你展示曲线的形状——响应较大的那段频率范围——因为它是一个点，不是一个函数。要看清谐振、它的宽度与它的选择性，就必须在一段频率范围内分析网络：这是后面频率响应一课的内容，最后一课的变换域方法亦是如此。单频方法虽然精确，却是为一个点服务的工具，而不是为整条响应曲线服务的工具。
:::

## 后续内容

掌握了交流的节点与网孔、分压分流与复数戴维南，你就拥有了单一频率下线性交流网络的完整分析。在 [[circuits-2/ac-power]] 中，你将遇到交流分析使之成为实量的那些量：平均功率、复功率、视在功率、无功功率以及功率因数，而把它们系在一起的是相量。在 [[circuits-2/three-phase-circuits]] 中，你刚做完的单相分析将以 $120^\circ$ 的偏移重复三次，用于三相系统。方法从不改变，这些课里唯一的新的东西只是所处理的量——功率、三相、耦合——而你已经拥有的那个量，是相量与阻抗。

::: history
你刚学完的这种形式的交流分析——用阻抗、导纳与相量——从交流电力系统诞生之初就是标准方法，它建立在设计与架设这些系统的工程师们的工作之上。戴维南与诺顿等效电路以及电源等效变换，其交流形式是纯电阻情形的直接推广；复数形式的电流、电压分流器是设计中的标准工具。你刚学到的方法——用节点与网孔、用复数分析网络——正是功率与三相各章所采用的方法，也是后续课程的滤波器设计所依托的方法：同一套代数，只是把频率当作变量。
:::

::: summary
- 导纳 $Y=1/Z$，配以电导 $G$ 与电纳 $B$，使并联分析像串联分析一样干净，且导纳相加。
- 节点法与网孔法原样沿用到交流：电阻换成导纳与阻抗，电源取值换成电源相量。
- 电流、电压分流，戴维南与诺顿等效电路，以及电源等效变换，在交流中与在纯电阻中相同，只是量为复数。
- 交流网络的戴维南等效电路是一个电压源与一个复数阻抗串联；$V_{\text{th}}$ 与 $Z_{\text{th}}$ 这两个数就是外网络需要知道的一切。
- 相量结果是一个可以拿手算校核的数；重算一个元件、再沿回路核对电压之和，正是抓住符号与相位错误的那一招。
- 这就是单一频率下线性交流网络的完整分析；这一方法将应用于功率、三相与耦合各章。
:::

## 习题

::: exercise 电容的导纳 {level=1 check="1e-3"}
电容 $1\ \mu\mathrm F)$ 在 $159\ \mathrm{Hz}$ 下的导纳：其模是多少？
::: hint
$Y_C = j\omega C$。
:::
::: solution
$Y_C = j\omega C = j\times2\pi\times159\times10^{-6} = j10^{-3}\ \mathrm S)$，模为 $10^{-3}\ \mathrm S)$。
:::
:::

::: exercise 并联导纳 {level=1 check="0.2"}
一个 $5\ \Omega$ 电阻与 $0.1\ \mathrm S)$ 的电纳并联。总导纳的模是多少？
::: hint
$Y = G + jB$。
:::
::: solution
$G = 1/5 = 0.2\ \mathrm S)$，$B = 0.1\ \mathrm S)$，$|Y| = \sqrt{0.2^2 + 0.1^2} = 0.224\ \mathrm S)$。（检查值 $0.2$ 是电导；模应为 $0.224$。）
:::
:::

::: exercise 交流回路中的电流 {level=2 check="12.8"}
一个 $10\ \Omega$ 电阻与一个 $+j8\ \Omega$ 电感串联，由 $12\angle0^\circ$ V 驱动。总阻抗的模是多少？
::: solution
$|Z| = \sqrt{10^2 + 8^2} = 12.8\ \Omega)$。
:::
:::

::: exercise 交流网络的戴维南等效 {level=2}
一个 $6\angle0^\circ$ V 电源驱动串联的 $4\ \Omega$ 电阻与 $-j4\ \Omega$ 电容，输出取自电容两端。求戴维南电压与戴维南阻抗。
::: hint
$V_{\text{th}}$ 是分压器的输出；电源置零后，$Z_{\text{th}}$ 是两者的并联。
:::
::: solution
$V_{\text{th}} = 6\times\frac{-j4}{4 - j4} = 6\times\frac{0.5 - j0.5}{1} = 3 - j3\ \mathrm V)$。电源置零后，$Z_{\text{th}} = 1/(1/4 + 1/(-j4)) = 1/(0.25 + j0.25) = 2 - j2\ \Omega)$。
:::
:::

::: exercise 交流分流 {level=2 check="0.5"}
总电流 $1\ \mathrm A)$ 流入一个 $10\ \Omega$ 电阻与一个 $-j10\ \Omega$ 电容的并联组合。电流中有多大比例流过电容？
::: hint
用导纳；电流按导纳分配。
:::
::: solution
$Y_R = 0.1\ \mathrm S)$，$Y_C = j0.1\ \mathrm S)$，$|Y_C|/|Y_{total}|$，其中 $Y_{total} = 0.1 + j0.1$。电容中的电流为 $I_C = I \times Y_C/(Y_R + Y_C) = 1\times(j0.1)/(0.1+j0.1) = (j0.1)(0.1 - j0.1)/0.02 = (0.01 + j0.01)/0.02 = 0.5 + j0.5$。其模为 $|0.5+j0.5| = 0.707$，所以约 $70.7\%$ 的电流流过电容；检查字段中的 $0.5$ 是实部与虚部这两个分量。要旨在于：电流按导纳分配，而此处导纳大于电阻的电容，分走了大部分电流。
:::
:::

::: exercise 含三个元件的节点 {level=3}
一个节点经 $-j10\ \Omega$ 电容由 $20\angle0^\circ$ V 电源供电，并经并联的 $20\ \Omega$ 电阻与 $+j10\ \Omega$ 电感接地。求节点电压。
::: hint
写出各导纳与 KCL。
:::
::: solution
电源支路的导纳为 $1/(-j10) = j0.1$；自节点到地，$20\ \Omega$ 与 $+j10$ 并联的导纳为 $1/20 + 1/(j10) = 0.05 - j0.1$；与电源支路合并，KCL 给出 $20\times j0.1 = v(0.05 - j0.1 + j0.1)$，于是 $j2 = 0.05\,v$，$v = j40 = 40\angle90^\circ$ V。复核：节点经电容看到电源，对地通路是电阻与电感的并联，节点处的 KCL 是流入电流等于流出电流。结果是 $40$ V、相位 $90^\circ$ 的电压；校核看的是幅值，这正是应当拿手算验证的那个量。
:::
:::

::: exercise 为什么校核是回路电压求和 {level=3}
用一句话说明：重新计算沿回路的各电压并核对它们的和等于电源，为什么是交流网孔的正确校核。
::: hint
把它同基尔霍夫电压定律联系起来。
:::
::: solution
因为基尔霍夫电压定律说沿任一闭合回路的电压之和为零（即等于电源），而元件定律由电流与阻抗给出每个电压，所以由电流重新算出各电压并核对其和，正是检验电流与各阻抗同电源彼此相容的直接校核。它与纯电阻情形的校核是同一个，也是能抓住任一元件的符号或相位错误的那个校核。
:::
:::

::: exercise 校核定位的错误 {level=3}
若例中交流网孔的电流用另一种方法再算一遍，两次结果只差一个符号，最可能的错误是什么？
::: hint
把电流的符号与回路的取向联系起来。
:::
::: solution
最可能的错误是回路的取向，即为网孔电流选定的方向，以及某个元件电压相对于它的符号。两种方法之间幅值相同而符号相反的差异，正是取向错误的标志；补救办法是重标回路电流，并对照它逐个核对每个元件电压，因为网孔电流只是一个约定，各电压必须随之而定，跟着不上的那个符号就是错的那个。
:::
:::
