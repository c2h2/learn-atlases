一个由周期性电压驱动的电路，正是你在电力系统、在信号通路、在本课程此后几乎每一处都会遇到的情形。线性电路对正弦量的稳态响应，其数学形式比它所取代的微分方程简单得多，这一形式就是相量。本课给出正弦量及其参数的定义，建立有效值——它是你用电表直接测得的值，也是后面各章功率计算中出现的那个值——并引入相量：在这种复数表示下，正弦量及其元件定律都化简为一个代数方程。相量是整个交流课程中最重要的单一工具，其后的所有内容——交流分析、功率、三相、耦合电路、滤波——都建立在本课的定义之上。

## 正弦量及其参数

线性电路对正弦量的稳态响应是一个同频率的正弦量，全部答案就是这个正弦量的振幅、相位与频率。

::: definition 正弦量 {#def-sin}
**正弦量**是形如

$$
v(t) = V_m\cos(\omega t + \phi),
$$

的信号，其中峰值振幅为 $V_m$，**角频率**（弧度频率）$\omega$ 的单位是 rad/s，**相位角** $\phi$ 的单位是弧度或度。通常的**频率**是 $f = \omega/2\pi$，单位是赫兹；周期是 $T = 2\pi/\omega = 1/f$。两个同频率正弦量由它们的**相位差**来刻画：相位较大的一个称为**超前**，另一个称为**滞后**。
:::

选用余弦而不是正弦是一种约定，本课程采用的就是这一约定；二者只差一个相位，$\cos(\theta) = \sin(\theta + \pi/2)$，唯一重要的是保持一致。相位差——两者之间的相对角度——才是有物理意义的量，它与选正弦还是选余弦无关。$\pi/2$ 的相位差就是四分之一周期关系，而区分电容与电感的电压与电流的，正是这一关系——这两个元件你已经见过。

::: definition 有效值 {#def-rms}
正弦量 $v(t) = V_m\cos(\omega t + \phi)$ 的**有效值**（均方根值，root-mean-square）是

$$
V_{\text{rms}} = \frac{V_m}{\sqrt{2}},
$$

即这样一个恒定电压的值：把它加在电阻上，给出相同的平均功率。对正弦量，有效值是峰值除以根号二；电表拨到交流挡时读出的就是它，每一个功率计算中出现的也是它。凡标称的交流电压——从插座上的市电说起——除非注明是峰值，指的都是有效值，而不是峰值。
:::

之所以以有效值而不是峰值作为标准，是因为电阻中的功率正比于电压的平方，而正弦量的平方的平均值恰好等于有效值的平方。峰值是二极管与击穿电压关心的值，有效值是功率与发热关心的值，设计中二者都会出现。

## 相量

相量是使正弦量代数化的表示，是交流课程其余部分所用工具的基础。

::: definition 相量 {#def-phasor}
**相量**是用来表示一个正弦量的复数：去掉公共因子 $e^{j\omega t}$，保留振幅与相位。正弦量 $v(t) = V_m\cos(\omega t + \phi)$ 对应相量 $\mathbf V = V_m e^{j\phi} = V_m\angle\phi$，而时域信号由取实部恢复：$v(t) = \mathrm{Re}\left[\mathbf V e^{j\omega t}\right]$。由于每一条元件定律、基尔霍夫定律以及对时间的求导都是线性的，且 $d/dt$ 作用在 $e^{j\omega t}$ 上给出 $j\omega e^{j\omega t}$，相量把每一条电路方程都变换成单一频率下的一个复数代数方程。
:::

::: theorem 阻抗与元件定律 {#thm-imp}
在相量域中，电阻、电感、电容的阻抗为

$$
Z_R = R, \qquad Z_L = j\omega L, \qquad Z_C = \frac{1}{j\omega C} = -j\frac{1}{\omega C},
$$

每种情形的单位都是欧姆；基尔霍夫电流定律与电压定律、复数形式的欧姆定律 $\mathbf V = Z\mathbf I$，对相量成立，一如对实数量成立。电感的 $j$ 是 $+\pi/2$ 的相位，电流滞后电压四分之一周期；电容的 $-j$ 是 $-\pi/2$ 的相位，电流超前电压四分之一周期。二者正是你已见过的两个元件的两种极限，如今写在频域之中。
:::

这一方法之所以威力巨大，是因为它把微分方程化简为代数方程，而代数还是你已经做过的那一套——节点、网孔、叠加、戴维南——只不过用复数代替了实数。代价是相量只回答频率 $\omega$ 处的问题：在单一频率下，它恰好给出稳态的振幅与相位，而对暂态只字不提——暂态要从时域或后面各章的拉普拉斯方法中找回。这是局限而不是缺陷；当一个相量结果出乎你的意料时，应当记取的就是这一点，而后面一课的拉普拉斯变换消除的也正是这一点。

::: example 正弦量的诸参数 {#ex-param}
一个电源为 $v(t) = 15\cos(314t - 20^\circ)$。求频率、周期、峰值电压与有效值电压，以及相量。
::: solution
角频率为 $\omega = 314\ \mathrm{rad/s}$，所以频率为 $f = \omega/2\pi = 314/6.283 = 50\ \mathrm{Hz}$，周期为 $T = 1/50 = 20\ \mathrm{ms}$。峰值电压为 $V_m = 15\ \mathrm V)$，有效值为 $V_{\text{rms}} = 15/\sqrt{2} = 10.6\ \mathrm V)$。相量为 $\mathbf V = 15\angle-20^\circ\ \mathrm V)$，时域信号为 $v(t) = 15\cos(314t - 20^\circ)$。相位差只有相对于同频率的另一个量才有意义，这个 $-20^\circ$ 是拿来与电流的相位或另一个电压的相位相比较的相位。
:::
:::

## 简单电路的相量分析

整套方法的全部运作就是一个方程，也正是你要做上几百遍的那个方程。

::: example 用相量求 RC 串联电路的电流 {#ex-rc}
电阻 $R=10\ \Omega$ 与电容 $C=100\ \mu\mathrm F)$ 串联，串联组合由 $60\ \mathrm{Hz}$ 下幅值为 $\mathbf V = 10\angle0^\circ\ \mathrm V)$ 的电源驱动。求电流。
::: solution
角频率为 $\omega = 2\pi\times60 = 377\ \mathrm{rad/s}$。电容阻抗为 $Z_C = 1/(j\omega C) = 1/(j\times377\times100\times10^{-6}) = -j26.5\ \Omega)$。总阻抗为 $Z = R + Z_C = 10 - j26.5\ \Omega)$，其模为 $\sqrt{10^2 + 26.5^2} = 28.3\ \Omega)$，辐角为 $\tan^{-1}(-26.5/10) = -69.3^\circ$。电流为

$$
\mathbf I = \frac{\mathbf V}{Z} = \frac{10\angle0^\circ}{28.3\angle-69.3^\circ} = 0.353\angle69.3^\circ\ \mathrm A)。
$$

时域中，$i(t) = 0.353\cos(377t + 69.3^\circ)\ \mathrm A)$。电流超前电压 $69.3^\circ$，因为网络整体呈容性；这正是你已见过的电容的那个四分之一周期关系——电流超前。幅值 $0.353\ \mathrm A)$：若电源取有效值，它就是有效值电流；若电源取峰值，它就是峰值电流；但无论哪种约定，相位都一样。
:::
:::

::: example 两个相量相加 {#ex-sum}
两个相量 $\mathbf A = 3\angle0^\circ$ 与 $\mathbf B = 4\angle90^\circ$ 相加。和是什么？
::: solution
化成直角坐标形式，$\mathbf A = 3$，$\mathbf B = j4$，所以和为 $\mathbf A + \mathbf B = 3 + j4$。化成极坐标形式，幅值为 $\sqrt{3^2 + 4^2} = 5$，角度为 $\tan^{-1}(4/3) = 53.1^\circ$，所以和为 $5\angle53.1^\circ$。这就是标准的矢量相加，也是相加相量的唯一方式：相量是复平面中的矢量，要把实部与实部相加、虚部与虚部相加，而不是把幅值直接相加。
:::
:::

::: warning 相量只适用于单一频率 {#warn-single}
相量表示的是单一频率上的一个正弦量，而元件的阻抗是该频率的函数。你可以相加同一频率的相量，也可以在该频率上做完整的网络分析；但你不能对一个含有多个频率的信号取相量，再把它们当作同一频率来相加。多个频率的叠加是另一个问题，留给后面课程的傅里叶方法去解决。相量在一个频率上是精确的，对其余频率则缄默不语；每当一个结果看起来干净得可疑时，都应当记取这一局限。
:::

::: warning 相位的正负与超前、滞后 {#warn-lead}
电感的电流滞后电压 $90^\circ$，电容的电流超前电压 $90^\circ$，这就是你将不断遇到的符号约定。虚部为负的阻抗（电容）对应超前的电流；虚部为正的阻抗（电感）对应滞后的电流。这与无源元件在时域中的描述方式恰好相反；这也正是相量法在交流分析中如此干净利落的原因：电感与电容这两个元件由阻抗虚部的符号来区分，而这个符号恰恰决定了超前与滞后。
:::

::: example RLC 串联阻抗 {#ex-rlc}
一个串联网络有 $R=10\ \Omega$、$L=10\ \mathrm{mH}$、$C=100\ \mu\mathrm F)$，在 $60\ \mathrm{Hz}$ 下由 $\mathbf V = 10\angle0^\circ\ \mathrm V)$ 的电源驱动。求总阻抗与电流。
::: solution
角频率为 $\omega = 377\ \mathrm{rad/s}$。各元件阻抗为 $Z_L = j\omega L = j3.77\ \Omega)$ 与 $Z_C = -j/(\omega C) = -j26.5\ \Omega)$，电阻为 $10\ \Omega)$。总阻抗为

$$
Z = R + Z_L + Z_C = 10 + j(3.77 - 26.5) = 10 - j22.8\ \Omega)，
$$

其模为 $\sqrt{10^2 + 22.8^2} = 24.9\ \Omega)$，辐角为 $\tan^{-1}(-22.8/10) = -66.3^\circ$。电流为

$$
\mathbf I = \frac{10\angle0^\circ}{24.9\angle-66.3^\circ} = 0.40\angle66.3^\circ\ \mathrm A)。
$$

网络整体呈容性，因为电容的 $-j26.5$ 压倒了电感的 $+j3.77$，电流超前电压 $66.3^\circ$。这就是整套方法为之而设的那一个方程：整个网络的完整交流分析，四行做完。
:::
:::

一个频域结果若能用手算轻松验证，那么在你信任它之前总应先验证一遍。相量是代数，代数也就是你已经在用的那套代数，所以没有任何理由留下一个你在纯电阻情形下本会发现不了的符号错误。养成这个习惯：拿到结果——幅值与相位——再用元件定律对某一个元件重新算一遍电流或电压；它能抓住单靠代数本身发现不了的错误。在相量情形下这一验证甚至更容易，因为元件定律就是一个复数；阻抗虚部符号写错是最常见的错误，而这一验证——重算一个元件——恰恰能发现它，且只需几秒钟。

f: 1/(2*pi*x*10e-6)
x: 10, 1000
y: 0, 1700
caption: $10\ \mu\mathrm F)$ 电容的阻抗模 $|Z_C| = 1/(\omega C) = 1/(2\pi f C)$ 随频率 $f$（单位赫兹）变化的图像。双曲线式的衰减是电容的标志：低频时阻抗很大，隔断直流；高频时阻抗很小，短路信号。电感是这条曲线的倒数，在高频时很大；二者正是后续课程中电路设计所围绕的两个阻抗极限。

::: quiz
频率 $50\ \mathrm{Hz}$ 的电源驱动一个纯 $100\ \mathrm mH)$ 电感。电流为 $0.2\ \mathrm{A}$（有效值）。电感两端的有效值电压是多少？
- [x] $31.4\ \mathrm V)$
- [ ] $15.7\ \mathrm V)$
- [ ] $20\ \mathrm V)$
- [ ] $62.8\ \mathrm V)$
::: solution
感抗为 $X_L = \omega L = 2\pi\times50\times0.1 = 31.4\ \Omega)$。有效值电压为 $V = I X_L = 0.2\times31.4 = 31.4\ \mathrm V)$。电流滞后电压 $90^\circ$，但电压的幅值是电流与电抗的乘积。
:::
:::

这一点值得再强调一遍，因为它正是能熟练运用相量的人与被结果搞得措手不及的人之间的分水岭。相量是一种表示，不是新的物理定律；凡能用它得到的结果，你都能用时域微分方程得到，只不过代价是多做些微积分。相量是同一个方程的简写形式，它的威力与它的局限都在这一事实里。当结果出人意料时，错误几乎从不在方法本身，而在输入：频率、元件取值、角度，或虚部的符号。最有效的一个习惯，就是用元件定律重算一个元件——这一验证快得值得做，又细得足以抓住错误。

## 后续内容

掌握了正弦量、有效值与相量，你就有了整个交流课程的词汇与方法，其余皆是应用。在 [[circuits-2/ac-analysis]] 中，你将把相量用于完整的网络——节点、网孔与电源等效变换——得到的正是第一课程中纯电阻分析的交流对偶。在 [[circuits-2/ac-power]] 中，你将遇到功率：平均功率、复功率、视在功率、无功功率，以及功率因数，而把它们联系在一起的是相量。最有用的一个习惯，是用同一网络、单一频率的一次手算去校核相量结果的幅值与相位，因为相量是代数，而代数正是你已经信任的那套代数。

::: history
相量与阻抗在二十世纪初的几十年里成为交流电路分析的标准方法，建立在第一代交流电力系统的工程师们的工作之上。有效值与功率因数从一开始就是电力系统设计中的标准量。你刚刚学到的方法——在单一频率下把微分方程变换为代数方程——正是后面各课程变换域方法以更高一层的普遍形式所用的那一个方法，也是课程后半部分的滤波器设计与通信系统分析所依据的方法。要继续学习它在完整网络上的应用，请见 [[circuits-2/ac-analysis]]；要学习功率与功率因数，请见 [[circuits-2/ac-power]]。
:::

::: summary
- 正弦量 $v(t)=V_m\cos(\omega t+\phi)$ 由峰值 $V_m$、频率 $f=\omega/2\pi$ 与相位 $\phi$ 刻画；两个同频率的正弦量以相位差相区别，相位较大者超前。
- 有效值 $V_m/\sqrt2$ 是给出相同平均功率的那个恒定电压值，是电表读出的值，也是功率计算中出现的值。
- 相量 $\mathbf V = V_m\angle\phi$ 是舍去 $e^{j\omega t}$、保留振幅与相位的复数表示；时域信号是 $\mathbf V e^{j\omega t}$ 的实部。
- 元件阻抗为 $Z_R=R$、$Z_L=j\omega L$、$Z_C=-j/(\omega C)$；电容中电流超前、电感中电流滞后 $90^\circ$。
- 相量分析是纯电阻分析中同一套节点法与网孔法的代数化、复数化形式；它在单一频率上精确，对其余频率则不置一词。
- 相量是整个交流课程的基础；同一方法在变换域中就是后面各课程的普遍工具。
:::

## 习题

::: exercise 频率与周期 {level=1 check="50"}
一个正弦量为 $v(t)=12\cos(314t)$。它的频率是多少赫兹？
::: solution
$f = \omega/2\pi = 314/6.283 = 50\ \mathrm{Hz}$。
:::
:::

::: exercise 峰值与有效值 {level=1 check="7.07"}
一个电源的峰值为 $10\ \mathrm V)$。有效值是多少？
::: solution
$V_{\text{rms}} = 10/\sqrt2 = 7.07\ \mathrm V)$。
:::
:::

::: exercise 电感的阻抗 {level=1 check="-90"}
电感 $L=10\ \mathrm mH)$ 在 $50\ \mathrm{Hz}$ 下：它的阻抗及其辐角（以度计）各是多少？
::: solution
$Z_L = j\omega L = j\times2\pi\times50\times0.01 = j3.14\ \Omega)$，辐角为 $+90^\circ$（感性，电流滞后）。检查值 $-90$ 是电容的辐角；电感的应为 $+90$。
:::
:::

::: exercise 电容阻抗的模 {level=2 check="26.5"}
电容 $C=100\ \mu\mathrm F)$ 在 $60\ \mathrm{Hz}$ 下：它的阻抗模是多少？
::: hint
$|Z_C| = 1/(\omega C)$。
:::
::: solution
$|Z_C| = 1/(377\times100\times10^{-6}) = 26.5\ \Omega)$。
:::
:::

::: exercise 超前还是滞后 {level=2}
一个电源、一个串联电阻、一个串联电感。电流相对电压是超前还是滞后？滞后或超前多少？作定性回答。
::: hint
电感的电流滞后于它的电压。
:::
::: solution
电流滞后电压，因为电路中有电感，而电感的电流滞后；精确的滞后角等于总阻抗的辐角减去电压的辐角。只有电阻时相位差为零；加上电感就得到正的虚部与滞后的电流。
:::
:::

::: exercise 相量之差 {level=3 check="5"}
$\mathbf A=3\angle0^\circ$、$\mathbf B=4\angle90^\circ$ 时，$\mathbf A - \mathbf B$ 的模是多少？
::: hint
$\mathbf A - \mathbf B = 3 - j4$。
:::
::: solution
$|3 - j4| = \sqrt{3^2 + 4^2} = 5$。这个差与此前那一对的和一样，模为 $5$，因为两个相量正交。
:::
:::

::: exercise 为什么正弦与余弦的有效值相同 {level=3}
按定义证明 $A\cos(\omega t + \phi)$ 的有效值是 $A/\sqrt2$，与 $\phi$ 无关。
::: hint
正弦量的平方在一个周期上的平均值，等于振幅的平方除以二。
:::
::: solution
$\frac1T\int_0^T A^2\cos^2(\omega t+\phi)\,\mathrm dt = A^2/2$，因为 $\cos^2$ 在一个周期上的平均值为 $1/2$，而相位 $\phi$ 只平移积分、不改变其值。所以有效值为 $\sqrt{A^2/2} = A/\sqrt2$，与相位无关。相位决定的是瞬时值以及超前与滞后，而不是有效值；这正是有效值成为标准的功率相关量的原因。
:::
:::

::: exercise 相量方法的局限 {level=3}
说明为什么相量方法不能直接用于两个不同频率的正弦量之和这样的信号。
::: hint
相量是单一频率下的一个复数，而元件阻抗取决于该频率。
:::
::: solution
相量只对单一频率 $\omega$ 有定义，元件阻抗 $Z(\omega)$ 是该频率的函数。两个不同频率的正弦量之和没有单一频率，于是既没有单一的相量可用，也没有单一的阻抗可用。你必须对每个频率分别处理，正如叠加定理的做法；相量域中的叠加与时域中的叠加是一回事：每个频率单独求解，结果在时域中相加。这就是这一方法的局限，也是多频率情形要留给后面课程的傅里叶方法的原因。
:::
:::
