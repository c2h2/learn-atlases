十字军的暴力打击了谁？一个词的回答已经是一种歪曲。1095年11月，乌尔班二世（Urban II）在克莱蒙（Clermont）宣讲了后来被称为第一次十字军的那次远征。1099年7月15日，那次远征攻取了耶路撒冷。在第一次十字军期间，莱茵兰的犹太社区遭到攻击。1187年，萨拉丁（Saladin）在哈廷（Hattin）得胜并夺取耶路撒冷。1204年4月13日，第四次十字军洗劫了君士坦丁堡，一座基督教城市。1212年，拉斯纳瓦斯-德托洛萨（Las Navas de Tolosa）之战在伊比利亚打响。1291年，阿克（Acre）陷落，大陆上的十字军诸公国终结。黎凡特的穆斯林、莱茵兰的犹太人、君士坦丁堡的希腊基督徒与伊比利亚的穆斯林军队，不是同一个目标的不同外衣。

这些远征作为忏悔被宣讲，作为战争被打了。宗教的框架是真实的。它不选择受害者。本章不给出军队规模或死亡总数。年表一个也没有锁定，而为制造效果发明的数字不会告诉你暴力打击了谁。它只会让一场布道、一场战役与一次洗劫看起来像一场可计量的战役。

## 一场布道不是一份逐字记录

乌尔班在克莱蒙的宣讲是第一次十字军通常的起点。关于他说了什么的记述是事后写成的，而且彼此不一致。本章不发明一篇演说，也不把报道出来的呼喊当作史料。就诸记述共享的目标作转述：那次远征被宣讲为对东部基督徒的救助与一场前往耶路撒冷的旅程，凡许愿者附带一项属灵特权。史家们对于十字军这个词的边缘意见不一：它必须系得多么紧于教皇的特权，伊比利亚的诸战争是否属于其内，1095年是一个开端还是后来贴在一种更长久的圣战习惯上的名字。这场分歧并不从与这些远征相连的暴力记录中除去莱茵兰攻击或1204年的洗劫。

1098年，西多（Cîteaux）的西多会开端标记了一种在战争旁边的新修道生活，它不是那场布道的起因，也不是战事的避难所。从1095年的克莱蒙到1098年的西多是三年。一座经过改革的修道院与一次被宣讲的远征可以共享一个十年而不共享一个动机。一个更早院宅的土地型修道主义，即910年的克吕尼（Cluny），又是另一个故事，在[[christendom/lords-and-peasants]]里讲述。

那次远征于1099年7月15日攻取了耶路撒冷。城里的人被杀死。犹太人与穆斯林在被打击者之中。本图谱不说有多少，也不描述杀戮的方式。杀戮的事实是攻取的一部分。一项忏悔的誓愿没有阻止它。一些人被饶恕或被赎回，所以一个说所有人皆死的句子是一份伪装的死亡总数，这里不予使用。诸史料在细节上不一致。这种分歧不是省略暴力的理由，也不是发明一个数字的许可。

在第一次十字军期间，故事还只能在耶路撒冷讲述之前，莱茵兰的犹太社区遭到了与那次远征有关之人的攻击。本图谱没有为那些攻击锁定年份，所以一个也不发明。一些地方主教试图庇护这些社区。庇护常常失败。一些人被杀死，一些人被逼向洗礼。这里是证据所能承受的描写限度。没有死亡总数，也没有对攻击如何实施的叙述。攻击者不是一场关于耶路撒冷的布道里点名的敌人。在克莱蒙说出的动机不是道路上被打击者的名单。

:::definition 十字军 {#def-crusade}
在本章，**十字军**是由拉丁基督教的权威作为忏悔战争宣讲的远征，附带一项与誓愿相连的特权。这个定义没有说暴力只有一个目标。它也没有说每一位基督教国王打的每一场战争都是十字军。史家们对于边缘案例意见不一。这个定义是一个工作限度，不是对这一时期每一场征战的裁决。
:::

:::definition 目标 {#def-target}
这里的**目标**是暴力打击的那个人或那个社区。目标不等同于宣讲中点名的敌人。一场布道可以指名耶路撒冷，而一支武装团伙攻击一个莱茵兰社区；一支更晚的十字军军队可以洗劫一座基督教城市。指认目标是一项历史工作。它不靠重复布道来定夺。
:::

:::theorem 目标是多重的 {#thm-plural}
十字军的暴力打击了不止一类的目标。它不只是拉丁基督教世界对穆斯林的防御，也不只是一桩只有一个受害者的罪行。这条论断涵盖战役、对城市的攻取，以及对本非军队宣言之敌的诸社区的攻击。它没有把这些类别压平成单一的道德类型，也没有给出死亡总数。
:::
:::proof
锁定的日期就是证据，读法是谁被打击。1099年7月15日，耶路撒冷被攻取，城里的人——包括犹太人与穆斯林——被杀死。在第一次十字军期间，莱茵兰的犹太人遭到攻击。1187年，萨拉丁——一位自有其政治、并非“东方”之象征的统治者——在哈廷击败拉丁军队并夺取耶路撒冷。1204年4月13日，一支十字军军队洗劫了君士坦丁堡。受害者包括一座基督教城市的基督教居民。恩里科·丹多洛（Enrico Dandolo）是与那次远征相连的威尼斯总督。1212年，拉斯纳瓦斯-德托洛萨是伊比利亚的一场战役，在基督教诸王与一支穆瓦希德（Almohad）军队之间。1291年，阿克陷落。大陆诸公国终结。这份清单不是一场战争，也不是一个敌人。

能够构成对这条论断的反证的，是一份每次远征都指名同一个敌人、而且没有任何相连的暴力落在犹太人或不落在希腊基督徒身上的记录。日期没有显示那份记录。一场真诚的布道也不能反驳这条论断。真诚是关于动机的证据。动机不是受害者名单。同样能够构成对这条论断的反证的，是一个论证：1204年在任何可用的意义上都不是十字军的暴力，因为那支军队已经如此彻底地放弃了誓愿，以至于洗劫只属于威尼斯与拜占庭的政治。答复比一场定义上的胜利更窄。那支军队是一支十字军军队。宣讲没有指名君士坦丁堡。受害者不会因为攻击者离开了更早的目标就变得不真实。仍然争论这个词的历史学家们，仍然有一个洗劫需要解释。

一部把十字军只叫作自卫的历史，必须把1099年删成一个进攻性的攻取，删掉莱茵兰，删掉1204。一部把它们只叫作罪行的历史，必须删掉作为忏悔宣讲的誓愿，删掉哈廷作为萨拉丁打赢的一场战役，并把拉斯纳瓦斯当作与屠杀非战斗人员同一行为的东西。两种删除都失败。复数性就是论证。它不是一份来自单一控诉或单一辩护的邀请。
:::

## 耶路撒冷被攻取，耶路撒冷被失去

从1099年7月15日耶路撒冷的攻取，到1187年萨拉丁夺取该城，是八十八年。1187减1099是88。哈廷与该城的失去是同一个年份，却不是同一个事件：先是一场战役，然后是一座城市。这八十八年不是一场有道德结局的围攻。在此期间存在着拉丁诸公国。本图谱没有锁定1187年之后试图收复耶路撒冷的诸远征的年份，所以那些年份不在这里发明。在该城的失去与1291年阿克的陷落之间，本章使用的年表锁定的是1204、1212与1291，不是一场连续的战争。

萨拉丁是一个政治行动者。他夺取了一座第一次十字军曾经夺取的城市。那个动词的对称不是辩解的对称，也不是把1187讲述成一个属灵工程受审判之刻的理由。它是谁持有耶路撒冷的改变。十字军不因城市易手而停止。1291年的阿克是一个更晚的终结，终结的是大陆诸公国，不是这个观念。从1099年到1291年是192年。这个跨度不是一个王国，也不是一场战争。

移动年份，拒绝单一的情节。克莱蒙是一场布道。1099是一座城市被攻取。1187是一场战役与一座城市的失去。图说里的八十八年是1187减1099，它是一个空隙，不是一种情绪。1204坐落在耶路撒冷的失去与拉斯纳瓦斯之间，它不是其中任何一场的一个篇章。1212在伊比利亚。1291终结了大陆的诸港口。六个圆点，不止一种类型的行为。八年的窗口在诸空隙旁边显得小。那个小就是要点。在概述里看上去相邻的事件，在线上相距很远。

:::example 八十八年 {#ex-eighty}
耶路撒冷于1099年7月15日被攻取，于1187年被萨拉丁夺取。使用年份数字，这个空隙有多长？这个空隙禁止你关于作为一场战争的“十字军”说什么？
:::solution
1187减1099是88。图说的“八十八年之后”就是那次减法。这个空隙禁止这样一个句子：攻取与失去是一场有单一结果的运动。哈廷与该城的陷落彼此共享1187年，不与1099年共享。1099年7月里的那个日子，没有为1187年锁定一个成对的日，所以这八十八是年份之差，不是天数。它也不是死亡总数，不是军队规模。
:::
:::

:::example 两座城市 {#ex-cities}
把1099年7月15日放在1204年4月13日旁边。两者都是对大城市的暴力进入。什么是相同的？在第二个案例里，谁被打击了，而一句“对穆斯林的战争”看不见？
:::solution
两者都是有日期的、针对一座城市的十字军暴力行为：耶路撒冷被攻取，君士坦丁堡被洗劫。年份之差是1204减1099，即105。不相同的是那座城市与那些人。1099年，那座城在穆斯林统治之下，被杀死的人包括穆斯林与犹太人。1204年4月13日，那座城是基督教的，受害者包括希腊基督徒。恩里科·丹多洛的那次远征仍然是一支十字军军队。一句说暴力只打击了穆斯林的话看不见他们。这105年没有把洗劫变成耶路撒冷攻取的续篇。它们使距离变得可见。
:::
:::

## 一座基督教城市

第四次十字军是对一张只有一个敌人的地图的最清楚的拦路石。宣讲没有指名君士坦丁堡。军队的首领们卷入了威尼斯的利益与一场拜占庭的继承争端。本章不为那种卷入的各个步骤定年，因为那些年份在这里没有锁定。它锁定洗劫：1204年4月13日。东罗马国家不在那一天终结。一个拉丁政权被强加于该城。希腊人的统治不是一份1204年能够擦去的脚注。按本图谱采用的定年，那个国家的终结是1453年5月29日君士坦丁堡的陷落。那个更晚的日期不是洗劫的含义。[[after-rome/byzantium]]是洗劫打断而没有终结的那份延续。

一些读者试图靠把1204开除出十字军来拯救十字军这个词。这种开除可以理解而不充分。如果十字军只意味着对穆斯林的暴力，那么一支十字军军队对一座基督教城市的洗劫就必须叫作别的东西，而那个别的东西将会是任何能让定义保持干净的东西。[[#thm-plural]]拒绝那种干净。洗劫之所以是十字军的暴力，是因为是谁做的、在何种誓愿与宣讲的旗号之下做的，不是因为受害者与布道相符。威尼斯的政治与一场王朝争端解释了这支军队如何抵达。它们没有把受害者解释掉。

有一个值得保留的反论。参与者把自己理解为在回应一次教皇的召唤。他们花费了资源。他们能够把远征中的死亡理解为宗教上有意义的。一部只说“罪行”的历史听不见那种自我理解，因而作为对宣讲的描写是失败的。我们承认那种自我理解。我们不让它剪辑这场洗劫。能够构成对多重目标论断的反证的，不是一颗虔诚的动机。那是这样一些证据：君士坦丁堡没有被洗劫，或者不是被这支军队洗劫。日期说的不是这样。

:::example 一句虚构的辩解 {#ex-defence}
下面这句话是虚构的。“十字军战士作战只为保卫欧洲免于伊斯兰，而他们所打击的每一个人都是兵临城下的敌人。”

为什么1204年、莱茵兰诸攻击与拉斯纳瓦斯不能被提升为对这句话的支持？
:::solution
这句话是虚构的，而提升将要求那三个片段契合于一场抵御欧洲边缘单一穆斯林敌人的防御战争。它们不契合。第一次十字军期间的莱茵兰诸攻击，打击的是并非城下之军的犹太社区，而本图谱不会发明一个年份或一个死亡总数来让它们看上去像一场战役。1204打击了一座基督教城市。1212年的拉斯纳瓦斯是伊比利亚的一场战役，不是在一个单独的关口保卫一块大陆，也没有终结穆斯林在伊比利亚的政治权力。那句虚构的话把“欧洲”当作一个只有一个敌人的文明。[[sources/naming-europe]]就是那种用法失败的原因。这句话内部也失败：防御与关口描述不了1099年对耶路撒冷的一次进攻性攻取。
:::
:::

## 伊比利亚不是脚注，阿克不是情绪

1212年的拉斯纳瓦斯-德托洛萨在图上，是为了让十字军不止是一个黎凡特的故事。北方的基督教诸王对一支穆瓦希德（Almohad）军队作战。十字军式的特权与十字军式的语言在伊比利亚是现成的。史家们对于这场战役应当系于教皇的旗号多么紧意见不一。按这里使用的任何一种读法，它是伊比利亚的一场战役，在同一大致时期内，与东征相仿，在君士坦丁堡洗劫之后八年。1212减1204是8。八年没有把拉斯纳瓦斯变成1204的续篇。它们把两场不同的战争放在一起，好让任何一场都代表不了两场。

那场战役没有拯救欧洲。那个附着于高卢一场更早战斗的传说，在[[after-rome/islam-in-the-west]]里已被拒绝。拉斯纳瓦斯不是那个传说的第二份摹本。它也没有终结穆斯林在伊比利亚的统治。格拉纳达（Granada）于1492年1月2日投降，那个日期属于[[crises/year-1492]]，不属于1212年的教训。安达卢斯（al-Andalus）是一部政治史。一场战役是它的一个事件，不是它的意义。

阿克在1291年陷落。大陆上的十字军诸公国终结。从1095年的克莱蒙到阿克是196年。1291减1095是196。那个跨度里没有一样东西是一个统帅、一个王国或一个结局。贸易与朝圣没有因为一座港口陷落就变得不可想象，这就是[[christendom/towns-and-learning]]能够把阿克放在一位神学家的死旁边、而不把两者变成一个过程的原因。更晚的十字军计划曾被宣讲。本图谱不在这一条线上锁定它们的年份，所以不给它们一个虚假的日期。这个观念比大陆诸公国更长命。大陆诸公国没有比1291年更长命。

:::example 不是一段跨度 {#ex-span}
从1095年的克莱蒙到1291年阿克的陷落，年份数字之间相隔多少年？说出这段跨度内部阻止它成为一场战争的两个锁定事件，并各说它发生在何处。
:::solution
1291减1095是196。在跨度之内，1204年4月13日是君士坦丁堡——一座基督教城市——的洗劫，1212年是伊比利亚的拉斯纳瓦斯。任何一个事件都足以打断“黎凡特的一场战争”。1187年，哈廷与耶路撒冷的失去，从另一个方向再次打断它：1099年攻取的那座城并没有在整个跨度里被持有。这196年是几场战争的容器。它们不是一场征战的时长，也不是一个伤亡数字。
:::
:::

:::warning 只算自卫，或只算罪行
通常的一对迷思朝着相反的方向劈开同一份清单。一个迷思说十字军是欧洲在自卫，于是没有莱茵兰的位置，没有1099年的一次进攻性攻取的位置，也没有1204年被洗劫的一座基督教城市的位置。另一个说它们是一桩单独的罪行，于是否则没有一场作为忏悔宣讲的誓愿的位置，没有哈廷作为萨拉丁之胜利的位置，也没有一场战役与一次对社区的攻击之区别的位置。多重目标是那个纠正。它们不是发明军队规模或死亡总数的许可。
:::

一个算例使诸类别保持分开。取年份实际支持的四种情形。1099年7月耶路撒冷的一位穆斯林居民，坐落在一座正被攻取的城里，可能被杀、被饶恕或被赎回：诸史料不一，我们不计数。第一次十字军期间莱茵兰的一个犹太家庭，遭到与那次远征有关之人的攻击，尽管布道曾经指名另一个目标。1204年4月13日君士坦丁堡的一位希腊基督徒，坐落在一座被十字军军队洗劫的城里。1212年拉斯纳瓦斯的一名穆瓦希德士兵，处在一场军队之间的战役之中，这与莱茵兰诸攻击不是同一个行为。“欧洲的敌人”干净地覆盖不了其中任何一项。“穆斯林”漏掉了第二项与第三项。“十字军暴力的受害者”只有在诸类别保持分明的前提下方才可用。[[#thm-plural]]就是那句可用的句子，限度写在里面。

:::quiz
1291年阿克的陷落最宜描述为以下哪一项？
- [ ] 每一种十字军观念的终结，以及一个再没有此类项目的欧洲的开始。
- [ ] 证明第一次十字军自1095年起是一场单独的战争。
- [x] 大陆上十字军诸公国的终结，不是一场单独连续战争的终结。
- [ ] 君士坦丁堡的洗劫，发生在同一天。
:::solution
年表说阿克在1291年陷落，大陆诸公国终结。君士坦丁堡是在1204年4月13日被洗劫的，不在1291年。从1095年到1291年是196年、数种类型的事件，[[#ex-span]]做了计算。后来的诸项目存在过。它们的年份不在这里发明。诸公国的终结不是一个观念的死亡。
:::
:::

:::history 一场布道，一座城市，另一座城市
1095年11月，乌尔班二世在克莱蒙宣讲了后来被称为第一次十字军的那次远征，耶路撒冷于1099年7月15日被攻取。1204年4月13日，与恩里科·丹多洛相关的第四次十字军洗劫了君士坦丁堡。十字军的暴力不只是对穆斯林的暴力。
:::

## 通向何处

[[christendom/towns-and-learning]]把阿克的陷落放在第四次拉特兰公会议与阿奎那的死旁边，并拒绝把三者变成一个过程。[[christendom/exclusion]]是拉丁基督教世界内部对犹太人与穆斯林的法律标记，是与莱茵兰诸攻击不同的一个行为，也不是对它们的替代。[[christendom/popes-and-kings]]是那场关于职位的争夺，它解释不了这些目标。被第四次十字军洗劫的东罗马国家是[[after-rome/byzantium]]。伊比利亚及别处更长久的伊斯兰政治史是[[after-rome/islam-in-the-west]]。1492年的格拉纳达，不是拉斯纳瓦斯，才是属于[[crises/year-1492]]的投降。一个像“十字军诸战争”这样的标签如何藏起若干论断，是[[sources/argument]]的事务。

:::summary
- 1095年11月的克莱蒙宣讲了一次远征。耶路撒冷于1099年7月15日被攻取。关于布道的记述是后来的，且彼此不一致。这里不发明演说。
- 在第一次十字军期间，莱茵兰的犹太人遭到攻击。那些攻击没有锁定年份，也没有锁定死亡总数。
- 1187年的哈廷与萨拉丁对耶路撒冷的夺取，在1099年之后八十八年。它们不与1099年同为一场战争。
- 1204年4月13日，一支十字军军队洗劫了君士坦丁堡，一座基督教城市。东罗马国家不在那一天终结。
- 1212年的拉斯纳瓦斯是伊比利亚的一场战役。它没有拯救欧洲，也没有终结穆斯林在那里的统治。
- 阿克在1291年陷落。大陆诸公国终结。十字军的观念没有被定年已死。
- 只算自卫与只算罪行，各删除这份清单的一部分。多重目标是那条论断，不含军队规模或死亡总数。
:::

## 习题

:::exercise 两次攻取之间的空隙 {level=1 check="88"}
使用年份数字，1099年耶路撒冷的攻取与1187年萨拉丁夺取该城之间相隔多少年？（请输入年数。）
:::solution
1187减1099是88。那张图的图说以文字说出了同一个空隙。哈廷属于1187年，不属于1099年。这八十八年不是一场征战，也不是一份伤亡名单。
:::
:::

:::exercise 从布道到港口 {level=1 check="196"}
1095年的克莱蒙与1291年阿克的陷落之间相隔多少年？（请输入年数。）
:::solution
1291减1095是196。这段跨度内含一次攻取、一次失去、对另一座城市的洗劫、伊比利亚的一场战役，以及大陆诸公国的终结。它不是一场战争的长度。
:::
:::

:::exercise 1204年的城市是哪座 {level=1 check="Constantinople"}
第四次十字军于1204年4月13日洗劫了哪座城市？（请输入城市的名字。）
:::solution
君士坦丁堡。那座城是基督教的，受害者包括希腊基督徒。这个日期不是阿克的陷落，也不是耶路撒冷的攻取。恩里科·丹多洛与那次远征相关。东罗马国家在洗劫之后延续。
:::
:::

:::exercise 为什么莱茵兰在这里没有年份 {level=2}
一部教科书把对莱茵兰犹太人的攻击定在你无法在本图谱年表中找到的年份，并加上一个死亡总数。你应当说什么？那个发明的精确会掩盖哪一个关于目标的问题？
:::solution
说攻击发生在第一次十字军期间，不要发明年份或死亡总数。年表为那次远征锁定的是1095年11月与1099年7月15日，不是莱茵兰的一个单独年份。一个虚假的年份会让那些攻击看上去像一场已知规模的、有日期的战役。随之消失的问题是：谁被打击——那些不是为耶路撒冷指名的敌人的犹太社区。[[#def-target]]使布道与受害者分开。一些主教试图庇护诸社区。如果那个片段只是一个数字，那个事实同样会消失。
:::
:::

:::exercise 两座城市，两种人 {level=2}
把1099年7月15日放在1204年4月13日旁边。在第二个片段里，谁会遭到打击，而一句“十字军的暴力只打击了穆斯林”看不见？包含年份之差。
:::solution
1204减1099是105。1099年7月15日的耶路撒冷是一座穆斯林统治之下的城市，被杀死的人包括穆斯林与犹太人。1204年4月13日的君士坦丁堡是一座被十字军军队洗劫的基督教城市。希腊基督徒在被打击者之中。那句只谈穆斯林的话看不见他们。这105年没有把洗劫变成攻取的继续。[[#def-target]]把宣讲中点名的敌人与暴力触及的人分开。比较之中没有军队规模的位置，也没有死亡总数的位置。
:::
:::

:::exercise 没有传说的伊比利亚 {level=2}
为什么1212年的拉斯纳瓦斯-德托洛萨表明十字军不只是一个黎凡特的故事？为什么它不得被讲述成拯救了欧洲或终结了穆斯林在伊比利亚统治的那场战役？
:::solution
这场战役在伊比利亚，在基督教诸王与一支穆瓦希德军队之间，在君士坦丁堡洗劫之后八年。1212减1204是8。那八年没有使它成为1204的续篇，而它们确实把一场非黎凡特的战争放在了与耶路撒冷和阿克同一条线上。它不是在西部伊斯兰那章里被拒绝的那个传说——一场战役拯救一块大陆。格拉纳达于1492年1月2日投降，那是另一个事件、另一章。一场战役不是安达卢斯的政治史。史家们对于拉斯纳瓦斯应当系于教皇的特权多么紧意见不一。这场分歧不把战役挪到黎凡特。
:::
:::

:::exercise 什么会推翻多重目标的论断 {level=3}
[[#thm-plural]]说十字军的暴力打击了不止一类的目标。什么样的证据会构成对那条论断的反证？为什么一段对乌尔班宣讲的真诚记述——即便我们有一份逐字记录——单凭自身也不足够？
:::hint
寻找一个贯穿始终的敌人，包括在君士坦丁堡与在莱茵兰。动机不是受害者名单。不要在回答里发明演说或死亡总数。
:::
:::solution
如果每次远征都指名同一个敌人，而且没有任何相连的暴力落在犹太人或希腊基督徒身上，这条论断就会失败。一份莱茵兰在第一次十字军期间未受触动、并且1204年4月13日未曾发生或不是十字军军队所为的记录，会构成反证。一场真诚的布道不会。克莱蒙的诸记述是后来的，彼此不一致，而本章不发明逐字记录。即便一份真实的逐字记录，也将是所宣讲之物的证据，不是道路上或在君士坦丁堡谁被打击的证据。[[#def-target]]就是那个区分。拉斯纳瓦斯可以保持为一场军队之间的战役，而拯救不了单一敌人的故事，因为伊比利亚已经是一张第二地图。
:::
:::

:::exercise 一场虚构的布道与一种真实的攻击 {level=3}
下面这句布道的话是虚构的。“这次远征只打击耶路撒冷的持有者。”在第一次十字军期间，武装的人攻击了莱茵兰的犹太社区。这场布道能证明什么，不能证明什么？不要给出年份或死亡总数。
:::hint
把一个宣示的目标与一份被打击者的名单分开。诸攻击的日期只到“在第一次十字军期间”。试图庇护诸社区的主教们是这个片段的一部分，不是一个可以丢掉的细节。
:::
:::solution
那句虚构的话可以例示一个宣示的目标。它不能证明这个目标是唯一的暴力，因为它是虚构的，也因为莱茵兰诸攻击是第一次十字军记录的一部分。那些攻击没有锁定的年份，也没有锁定的死亡总数。一些主教试图庇护诸社区，而庇护常常失败。布道，即便一份真实的布道只说过这个，也仍然不是一份受害者名单。被逼向洗礼的人与被杀死的人，不是“耶路撒冷的持有者”。[[#thm-plural]]立得住。把那句虚构的话提升为证据将需要一份逐字记录，而本图谱没有；即便有那份逐字记录，也抹不掉那些攻击。
:::
:::
