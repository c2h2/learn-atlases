十字军的暴力打击了谁？用一个词来回答，本身就已是歪曲。1095年11月，乌尔班二世（Urban II）在克莱蒙（Clermont）号召发动后来所称的第一次十字军东征。1099年7月15日，这支远征军攻占耶路撒冷。第一次十字军期间，莱茵兰的犹太社区遭到袭击。1187年，萨拉丁（Saladin）在哈廷（Hattin）获胜，并夺取耶路撒冷。1204年4月13日，第四次十字军洗劫了基督教城市君士坦丁堡。1212年，伊比利亚发生了拉斯纳瓦斯-德托洛萨（Las Navas de Tolosa）之战。1291年，阿克（Acre）陷落，十字军在大陆上的公国随之终结。黎凡特的穆斯林、莱茵兰的犹太人、君士坦丁堡的希腊基督徒和伊比利亚的穆斯林军队，并不是同一个目标换了不同的装束。

这些远征以赎罪之名号召，却作为战争来进行。宗教框架是真实的，但它并不决定谁成为受害者。本章不给出军队规模或死亡总数。年表没有确定任何一个这样的数字，而为渲染效果杜撰的数字也不能告诉你暴力打击了谁，只会让一场布道、一场战役和一次洗劫看起来像同一场可以计量的战事。

## 布道不是逐字记录

乌尔班在克莱蒙的布道，通常被视为第一次十字军的起点。关于他说了什么的记述都是事后写成的，而且彼此不符。本章不会杜撰一篇演说，也不会把记述中的口号当作文献。转述各记述共有的目标：这次远征被宣讲为援助东方基督徒、前往耶路撒冷的旅程，立誓者可获得一项属灵特权。“十字军”一词的边界在哪里，史家意见不一：它必须与教皇特权挂钩到什么程度，伊比利亚的战争是否算在其内，1095年究竟是开端，还是后人给一种更久远的圣战传统贴上的名称。这些分歧并不能把莱茵兰的袭击或1204年的洗劫，从与这些远征相关的暴力记录中删去。

1098年西多会在西多（Cîteaux）创立，标志着在战争之外出现了一种新的修道生活；它既不是那场布道的起因，也不是躲避战事的避难所。从1095年的克莱蒙到1098年的西多是三年。一座改革后的修道院和一次被号召的远征可以同处一个十年，却不必出于同一动机。更早的修院克吕尼（Cluny，910年）所代表的拥有大地产的修道制度，则是另一回事，见[[christendom/lords-and-peasants]]。

1099年7月15日，远征军攻占耶路撒冷。城中居民遭到杀戮，犹太人和穆斯林都在其中。本图谱不说明人数，也不描述杀戮的方式。杀戮是攻城的一部分，赎罪的誓愿并没有阻止它。有些人得以幸免或被赎出，所以“所有人都死了”这样的句子其实是一个变相的死亡总数，这里不用。史料在细节上互有出入。这种出入既不是略去暴力的理由，也不是杜撰数字的许可。

第一次十字军期间——在故事还只集中于耶路撒冷之前——莱茵兰的犹太社区遭到与远征有关的人袭击。本图谱没有确定这些袭击的年份，这里也不杜撰。一些当地主教曾试图庇护这些社区，但庇护往往失败。有些人被杀，有些人被逼受洗。这就是此处证据所能支撑的描述程度：没有死亡总数，也不叙述袭击如何进行。袭击者所针对的，并不是那场关于耶路撒冷的布道所点名的敌人。在克莱蒙宣布的动机，并不是一份路上受害者的名单。

:::definition 十字军 {#def-crusade}
本章所说的**十字军**，指由拉丁基督教权威作为赎罪战争号召的远征，立誓者可获得特权。这一定义并不意味着暴力只有一个目标，也不意味着基督教国王打的每一场仗都是十字军。对于边缘案例，史家意见不一。这一定义是一条工作界限，而不是对这一时期每场战事的裁决。
:::

:::definition 目标 {#def-target}
这里的**目标**指遭到暴力打击的个人或群体。目标并不等同于宣讲中点名的敌人。一场布道可以指向耶路撒冷，而一伙武装人员却袭击了莱茵兰的一个社区；后来的一支十字军也可以洗劫一座基督教城市。指认目标是一项历史研究工作，不能靠复述布道来解决。
:::

:::theorem 目标不止一种 {#thm-plural}
十字军的暴力打击的目标不止一种。它不只是拉丁基督教世界抵御穆斯林的防卫，也不只是只有一类受害者的一桩罪行。这一论断涵盖战役、攻城，以及对并非军队所宣布之敌的社区的袭击。它不把这些不同类型压缩成单一的道德类型，也不给出死亡总数。
:::
:::proof
证据就是已确定的日期，关键在于看谁遭到打击。1099年7月15日，耶路撒冷被攻占，城中居民——包括犹太人和穆斯林——遭到杀戮。第一次十字军期间，莱茵兰的犹太人遭到袭击。1187年，萨拉丁——一位有自身政治考量的统治者，而不是“东方”的象征——在哈廷击败拉丁军队，夺取耶路撒冷。1204年4月13日，一支十字军洗劫了君士坦丁堡，受害者中包括这座基督教城市的基督徒居民；与这次远征相关的是威尼斯总督恩里科·丹多洛（Enrico Dandolo）。1212年的拉斯纳瓦斯-德托洛萨之战，是伊比利亚的基督教国王们与穆瓦希德（Almohad）军队之间的一场战役。1291年，阿克陷落，大陆上的公国终结。这份清单说的不是同一场战争，也不是同一个敌人。

能够推翻这一论断的，是这样一份记录：每一次远征都指向同一个敌人，而且没有任何相关的暴力落到犹太人或希腊基督徒头上。日期显示的并非如此。真诚的布道也驳不倒这一论断，因为真诚证明的是动机，而动机不是受害者名单。另一种可能的反驳是证明1204年在任何可用的意义上都不算十字军暴力：那支军队已经彻底背弃了誓愿，因而那次洗劫只属于威尼斯和拜占庭的政治。我们的回答比在定义上取胜要窄：那支军队是十字军，宣讲中并没有点名君士坦丁堡，而受害者并不因攻击者偏离了原先的目标就变得不真实。为这个词争论不休的史家，仍然需要解释那次洗劫。

把十字军仅仅说成自卫的历史，就得删掉1099年那次进攻性的攻城，删掉莱茵兰，删掉1204年。把十字军仅仅说成罪行的历史，则得删掉赎罪的誓愿，删掉萨拉丁打赢的哈廷之战，还得把拉斯纳瓦斯之战当作与屠杀非战斗人员同一性质的行为。两种删法都站不住。论证的要点正是目标的多样性，它不是要人在单一的控诉和单一的辩护之间二选一。
:::

## 耶路撒冷的攻占与失守

从1099年7月15日攻占耶路撒冷，到1187年萨拉丁夺回该城，相隔八十八年：1187减1099是88。哈廷之战与该城失守同在一年，却不是同一件事：先是一场战役，然后是一座城市。这八十八年并不是一场有道德结局的围城战，其间存在着若干拉丁公国。本图谱没有确定1187年之后为收复耶路撒冷而发动的各次远征的年份，这里也不杜撰。在该城失守与1291年阿克陷落之间，本章所用的年表确定的是1204年、1212年和1291年，而不是一场连续不断的战争。

萨拉丁是一个政治人物。他夺取了第一次十字军曾经攻占的城市。动词上的对称并不意味着正当性上的对称，也不能据此把1187年讲成一项属灵事业受到审判的时刻。那只是耶路撒冷换了主人。十字军并没有因为城市易手而停止。1291年的阿克是后来的一个终结，终结的是大陆上的公国，而不是十字军的观念。从1099年到1291年是192年，这段跨度既不是一个王国，也不是一场战争。

移动年份，但不要套用单一的情节。克莱蒙是一场布道；1099年是攻占一座城市；1187年是一场战役和一座城市的失守。图注中的八十八年就是1187减1099，它是一段间隔，而不是一种情绪。1204年位于耶路撒冷失守与拉斯纳瓦斯之战之间，却不属于其中任何一章。1212年在伊比利亚。1291年，大陆上的港口不复为十字军所有。六个圆点，代表的不止一种行为。与这些间隔相比，八年的窗口很小，这正是要点所在：概述中看似相邻的事件，在时间线上相距甚远。

:::example 八十八年 {#ex-eighty}
耶路撒冷于1099年7月15日被攻占，于1187年被萨拉丁夺取。按年份数字计算，两者相隔多久？这段间隔使你不能把“十字军”当作一场战争说些什么？
:::solution
1187减1099是88，图注中的“八十八年后”就是这道减法。这段间隔排除了这样的说法：攻占与失守是同一场战事，只有一个结果。哈廷之战和该城陷落同属1187年，而不与1099年同属一事。1099年7月的那一天在1187年并没有确定的对应日期，所以八十八是年份之差，而不是天数。它也不是死亡总数，不是军队规模。
:::
:::

:::example 两座城市 {#ex-cities}
把1099年7月15日与1204年4月13日对照。两者都是以暴力进入一座大城市。它们有什么相同之处？在第二个事件中，谁遭到了打击，而“对穆斯林的战争”这种说法却看不到？
:::solution
两者都是有确切日期的、针对城市的十字军暴力：一次是攻占耶路撒冷，一次是洗劫君士坦丁堡。年份之差是1204减1099，即105。不同的是城市和人。1099年，这座城市处于穆斯林统治之下，被杀的人中有穆斯林和犹太人。1204年4月13日，这座城市是基督教城市，受害者中有希腊基督徒。恩里科·丹多洛参与的这次远征仍然是十字军。说暴力只打击了穆斯林的句子，看不到这些人。这105年并没有使洗劫成为攻占耶路撒冷的续篇，而是让两者之间的距离清晰可见。
:::
:::

## 一座基督教城市

第四次十字军最清楚地挡住了“只有一个敌人”的地图。宣讲中并没有点名君士坦丁堡，但军队首领卷入了威尼斯的利益和拜占庭的皇位继承纠纷。本章不为这一卷入过程的各个步骤定年，因为那些年份在这里没有确定；本章确定的是洗劫的日期：1204年4月13日。东罗马国家并没有在那一天终结。一个拉丁政权被强加给这座城市，但希腊人的统治并不是一条能被1204年抹去的脚注。按本图谱采用的定年，这个国家的终结是1453年5月29日君士坦丁堡的陷落。这一较晚的日期并不是那次洗劫的意义所在。[[after-rome/byzantium]]讲的是被洗劫打断却未被终结的那种延续。

有些读者试图把1204年排除在“十字军”之外，以挽救这个词。这种做法可以理解，但不够充分。如果“十字军”只指针对穆斯林的暴力，那么一支十字军洗劫一座基督教城市，就只能另起名目，而这个名目无非是能让定义保持干净的任何说法。[[#thm-plural]]拒绝这种干净。那次洗劫之所以属于十字军暴力，是因为行凶者是谁、打着何种誓愿与宣讲的旗号，而不是因为受害者符合布道中的描述。威尼斯的政治和王朝纠纷解释了这支军队是如何来到这里的，却不能把受害者解释掉。

有一种值得保留的反论：参与者认为自己是在响应教皇的号召，他们投入了资财，也可能把远征途中的死亡理解为有宗教意义的事。一部只说“罪行”的历史，听不到这种自我理解，因而无法准确描述当时的宣讲。我们承认这种自我理解，但不允许它删改那次洗劫。能够推翻“目标不止一种”这一论断的，不是虔诚的动机，而是证明君士坦丁堡没有遭到洗劫，或者并非这支军队所为。而日期表明事实并非如此。

:::example 一句虚构的辩护 {#ex-defence}
下面这句话为示例而虚构：“十字军战士作战只是为了保卫欧洲免受伊斯兰侵犯，他们打击的每一个人都是兵临城下的敌人。”

为什么1204年、莱茵兰的袭击和拉斯纳瓦斯之战，都不能被提升为支持这句话的证据？
:::solution
这句话是虚构的。要提升它，就需要这三件事都符合一场抵御欧洲边缘单一穆斯林敌人的防御战，而它们并不符合。第一次十字军期间莱茵兰的袭击，打击的是犹太社区，他们并不是兵临城下的军队；本图谱也不会为了让这些袭击看起来像一场战役，而杜撰年份或死亡总数。1204年打击的是一座基督教城市。1212年的拉斯纳瓦斯是伊比利亚的一场战役，并不是在某个关口保卫一块大陆，也没有终结穆斯林在伊比利亚的政权。这句虚构的话把“欧洲”当作只有一个敌人的文明，而[[sources/naming-europe]]说明了这种用法为什么站不住。这句话本身也自相矛盾：“防御”和“城下”描述不了1099年对耶路撒冷的进攻性攻占。
:::
:::

## 伊比利亚不是脚注，阿克也不是一种情绪

把1212年的拉斯纳瓦斯-德托洛萨之战放在图上，是为了表明十字军不只是黎凡特的故事。北方的基督教国王们与一支穆瓦希德军队作战。十字军的特权和十字军的话语在伊比利亚都可以援用。这场战役应在多大程度上与教皇的旗号挂钩，史家意见不一。按照本章采用的任何一种理解，它都是伊比利亚的一场战役，与东方的远征处于大致同一时期，比君士坦丁堡遭洗劫晚八年：1212减1204是8。这八年并没有使拉斯纳瓦斯成为1204年的续篇，而是把两场不同的战争放在一起，使任何一场都不能代表另一场。

这场战役并没有拯救欧洲。这一传说原本附会在高卢更早的一场战斗上，[[after-rome/islam-in-the-west]]已经否定了它。拉斯纳瓦斯不是那个传说的翻版，它也没有终结穆斯林在伊比利亚的统治。格拉纳达（Granada）于1492年1月2日投降，这个日期属于[[crises/year-1492]]，而不属于从1212年引出的什么教训。安达卢斯（al-Andalus）是一部政治史，一场战役只是其中的一个事件，而不是它的意义所在。

1291年，阿克陷落，十字军在大陆上的公国终结。从1095年的克莱蒙到阿克是196年：1291减1095是196。这段跨度中没有一样东西是统一的指挥、单一的王国或唯一的结局。贸易和朝圣并没有因为一个港口的陷落就变得不可想象，所以[[christendom/towns-and-learning]]可以把阿克与一位神学家的去世放在一起，而不把两者当作同一过程。后来也曾有人号召新的十字军计划。本图谱没有在这条时间线上确定它们的年份，因此不给它们虚假的日期。十字军的观念比大陆上的公国存续得更久，而这些公国没能延续到1291年之后。

:::example 并非一段跨度 {#ex-span}
从1095年的克莱蒙到1291年阿克陷落，年份数字之间相隔多少年？请说出这段跨度中两个使它不能被视为一场战争的已确定事件，并分别指出发生地点。
:::solution
1291减1095是196。在这段跨度中，1204年4月13日是君士坦丁堡这座基督教城市遭到洗劫，1212年是伊比利亚的拉斯纳瓦斯之战。其中任何一件都足以打破“黎凡特的一场战争”之说。1187年的哈廷之战和耶路撒冷失守，又从另一个方向打破了这一说法：1099年攻占的城市并没有在整个跨度内一直被控制。这196年容纳了好几场战争，它既不是一场战事的持续时间，也不是伤亡数字。
:::
:::

:::warning “只是自卫”还是“只是罪行”
常见的一对迷思，从相反的方向把同一份清单劈开。一种迷思说十字军是欧洲的自卫，于是容不下莱茵兰，容不下1099年的进攻性攻城，也容不下1204年遭洗劫的基督教城市。另一种说十字军是一桩单一的罪行，于是容不下作为赎罪而号召的誓愿，容不下萨拉丁打赢的哈廷之战，也容不下战役与袭击社区之间的区别。“目标不止一种”就是对两者的纠正，但这并不允许杜撰军队规模或死亡总数。
:::

用一个推演来把各种类型区分开。取日期确实能支持的四种情形。1099年7月耶路撒冷的一位穆斯林居民，身处一座被攻占的城市，可能被杀、幸免或被赎出——史料说法不一，我们不作统计。第一次十字军期间莱茵兰的一个犹太家庭，遭到与远征有关的人袭击，尽管布道指向的是另一个目标。1204年4月13日君士坦丁堡的一位希腊基督徒，身处一座被十字军洗劫的城市。1212年拉斯纳瓦斯的一名穆瓦希德士兵，身处两军交战的战场，这与莱茵兰的袭击不是同一种行为。“欧洲的敌人”这一说法不能干净地涵盖其中任何一种；“穆斯林”漏掉了第二种和第三种；“十字军暴力的受害者”只有在各种类型保持区分时才可以使用。[[#thm-plural]]正是这样一句可用的话，其中已写明了限度。

:::quiz
对1291年阿克的陷落，以下哪种描述最恰当？
- [ ] 一切十字军观念的终结，此后欧洲再无此类计划。
- [ ] 证明第一次十字军是一场从1095年开始的单一战争。
- [x] 十字军在大陆上的公国的终结，而不是一场连续战争的终结。
- [ ] 君士坦丁堡遭洗劫，两件事发生在同一天。
:::solution
年表记载，阿克于1291年陷落，大陆上的公国随之终结。君士坦丁堡遭洗劫是在1204年4月13日，而不是1291年。从1095年到1291年是196年，其间有多种类型的事件，[[#ex-span]]已作计算。后来的十字军计划确实存在，但这里不杜撰它们的年份。公国的终结并不等于一种观念的消亡。
:::
:::

:::history 一场布道，一座城市，又一座城市
1095年11月，乌尔班二世在克莱蒙号召发动后来所称的第一次十字军东征；1099年7月15日，耶路撒冷被攻占。1204年4月13日，与恩里科·丹多洛相关的第四次十字军洗劫了君士坦丁堡。十字军的暴力并不只是针对穆斯林的暴力。
:::

## 通向何处

[[christendom/towns-and-learning]]把阿克的陷落与第四次拉特兰公会议、阿奎那之死放在一起，却拒绝把三者当作同一个过程。[[christendom/exclusion]]讲的是拉丁基督教世界内部对犹太人和穆斯林的法律标记，这与莱茵兰的袭击是不同的行为，也不能代替对后者的叙述。[[christendom/popes-and-kings]]讲的是围绕职位的争执，它解释不了这些目标。遭第四次十字军洗劫的东罗马国家，见[[after-rome/byzantium]]。伊比利亚及其他地方更长时段的伊斯兰政治史，见[[after-rome/islam-in-the-west]]。属于[[crises/year-1492]]的投降是1492年的格拉纳达，而不是拉斯纳瓦斯。“十字军战争”这样的标签如何掩盖了好几个论断，是[[sources/argument]]要处理的问题。

:::summary
- 1095年11月，克莱蒙号召了一次远征；1099年7月15日，耶路撒冷被攻占。关于那场布道的记述是后来写成的，而且彼此不符。这里不杜撰演说。
- 第一次十字军期间，莱茵兰的犹太人遭到袭击。这些袭击没有确定的年份，也没有确定的死亡总数。
- 1187年的哈廷之战和萨拉丁夺取耶路撒冷，在1099年之后八十八年。它们与1099年并非同一场战争。
- 1204年4月13日，一支十字军洗劫了基督教城市君士坦丁堡。东罗马国家并没有在那一天终结。
- 1212年的拉斯纳瓦斯是伊比利亚的一场战役。它没有拯救欧洲，也没有终结穆斯林在那里的统治。
- 1291年阿克陷落，大陆上的公国终结。十字军的观念并没有一个确定的消亡日期。
- “只是自卫”和“只是罪行”，都得删掉这份清单的一部分。“目标不止一种”才是本章的论断，其中不含军队规模或死亡总数。
:::

## 习题

:::exercise 两次夺城之间的间隔 {level=1 check="88"}
按年份数字计算，1099年攻占耶路撒冷与1187年萨拉丁夺取该城之间相隔多少年？（请输入年数。）
:::solution
1187减1099是88。图注用文字说出了同样的间隔。哈廷之战属于1187年，而不属于1099年。这八十八年既不是一场战事，也不是一份伤亡名单。
:::
:::

:::exercise 从布道到港口 {level=1 check="196"}
1095年的克莱蒙与1291年阿克陷落之间相隔多少年？（请输入年数。）
:::solution
1291减1095是196。这段跨度包含一次攻城、一次失守、对另一座城市的洗劫、伊比利亚的一场战役，以及大陆上公国的终结。它不是一场战争的长度。
:::
:::

:::exercise 1204年遭洗劫的是哪座城市 {level=1 check="Constantinople"}
第四次十字军于1204年4月13日洗劫了哪座城市？（请输入城市名称。）
:::solution
君士坦丁堡。这是一座基督教城市，受害者中包括希腊基督徒。这个日期既不是阿克的陷落，也不是耶路撒冷的攻占。与这次远征相关的是恩里科·丹多洛。洗劫之后，东罗马国家仍在延续。
:::
:::

:::exercise 为什么这里不给莱茵兰定年 {level=2}
一本教科书把莱茵兰犹太人遭袭的事件定在一个你在本图谱年表中找不到的年份，还加上了一个死亡总数。你应当怎样表述？这种杜撰的精确会掩盖哪个关于目标的问题？
:::solution
应当说这些袭击发生在第一次十字军期间，不要杜撰年份或死亡总数。年表为这次远征确定的是1095年11月和1099年7月15日，并没有为莱茵兰单独确定一个年份。虚假的年份会让这些袭击看起来像一场有明确日期、规模已知的战役，而随之消失的问题是：谁遭到了打击——那些并不是耶路撒冷布道所点名之敌的犹太社区。[[#def-target]]把布道与受害者区分开来。一些主教曾试图庇护这些社区，如果整件事只剩下一个数字，这一事实也会随之消失。
:::
:::

:::exercise 两座城市，两类人 {level=2}
把1099年7月15日与1204年4月13日对照。在第二件事中，谁可能遭到打击，而“十字军的暴力只打击了穆斯林”这句话却看不到？请写出年份之差。
:::solution
1204减1099是105。1099年7月15日的耶路撒冷是一座处于穆斯林统治下的城市，被杀的人中有穆斯林和犹太人。1204年4月13日的君士坦丁堡是一座被十字军洗劫的基督教城市，希腊基督徒也在受害者之列。只谈穆斯林的那句话看不到他们。这105年并没有使洗劫成为攻城的延续。[[#def-target]]把宣讲中点名的敌人与暴力实际波及的人区分开来。这一比较中，既不该有军队规模，也不该有死亡总数。
:::
:::

:::exercise 不带传说的伊比利亚 {level=2}
为什么1212年的拉斯纳瓦斯-德托洛萨之战表明十字军不只是黎凡特的故事？为什么又不能把它讲成拯救了欧洲、或终结了穆斯林在伊比利亚统治的那场战役？
:::solution
这场战役发生在伊比利亚，交战双方是基督教国王们与一支穆瓦希德军队，时间在君士坦丁堡遭洗劫八年之后：1212减1204是8。这八年并没有使它成为1204年的续篇，却确实把一场黎凡特以外的战争放在了与耶路撒冷、阿克同一条时间线上。它也不是“一场战役拯救一块大陆”的传说，这一传说已在讲西方伊斯兰的那一章中被否定。格拉纳达于1492年1月2日投降，那是另一件事，属于另一章。一场战役并不是安达卢斯的政治史。拉斯纳瓦斯与教皇特权应挂钩到什么程度，史家意见不一，但这一分歧并不会把这场战役挪到黎凡特。
:::
:::

:::exercise 什么能推翻“目标不止一种” {level=3}
[[#thm-plural]]认为十字军的暴力打击的目标不止一种。什么证据能够推翻这一论断？为什么一份对乌尔班布道的真诚记述——即使我们有逐字记录——本身仍不足够？
:::hint
找一找是否有一个贯穿始终的敌人，包括在君士坦丁堡和莱茵兰。动机不是受害者名单。回答中不要杜撰演说或死亡总数。
:::
:::solution
如果每次远征都指向同一个敌人，而且没有任何相关的暴力落到犹太人或希腊基督徒头上，这一论断就站不住了。一份显示第一次十字军期间莱茵兰未受波及、1204年4月13日的事件从未发生或并非十字军所为的记录，可以构成反证；真诚的布道则不能。关于克莱蒙的记述是后来写成的，而且彼此不符，本章不杜撰逐字记录。即使有一份真实的逐字记录，它证明的也只是宣讲了什么，而不是路上或君士坦丁堡里谁遭到了打击。[[#def-target]]正是这一区分。拉斯纳瓦斯可以仍被视为两军之间的战役，但这救不了“只有一个敌人”的故事，因为伊比利亚本身就是第二幅地图。
:::
:::

:::exercise 一句虚构的布道与一种真实的袭击 {level=3}
下面这句布道词为示例而虚构：“这次远征只打击耶路撒冷的占据者。”第一次十字军期间，武装人员袭击了莱茵兰的犹太社区。这句布道词能证明什么，不能证明什么？不要给出年份或死亡总数。
:::hint
把宣布的目标与遭到打击者的名单区分开来。这些袭击的时间只能确定为“第一次十字军期间”。试图庇护这些社区的主教也是这段历史的一部分，而不是可以略去的细节。
:::
:::solution
这句虚构的话可以用来说明一个宣布的目标，却不能证明这一目标就是唯一的暴力——因为它是虚构的，也因为莱茵兰的袭击是第一次十字军记录的一部分。这些袭击没有确定的年份，也没有确定的死亡总数。一些主教曾试图庇护这些社区，但庇护往往失败。即使真有一场布道只说了这句话，它也仍然不是受害者名单。被逼受洗的人和被杀的人，都不是“耶路撒冷的占据者”。[[#thm-plural]]依然成立。要把这句虚构的话提升为证据，就需要一份逐字记录，而本图谱没有；即便有，也抹不掉那些袭击。
:::
:::
