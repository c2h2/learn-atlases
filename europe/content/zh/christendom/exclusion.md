拉丁基督教的法律如何把人标记在外？公元1215年11月，英诺森三世（Innocent III）之下的第四次拉特兰公会议为一个它当作基督教的社会立法。第68条教规要求拉丁基督教世界内的犹太人与穆斯林以服饰相区别。1231年，格列高利九世（Gregory IX）批准了教皇宗教裁判所，一个针对异端的程序，那份诏书常被引作Excommunicamus。一条服饰规则与一个异端程序相隔十六年。1231减1215是16。它们不是同一条法律。它们都是关于范畴的法律。

一个范畴告诉一名官吏该标记谁、该查究谁，以及谁算作那条线另一边的普通基督徒。它没有告诉你每座城市都服从了，也没有告诉你任何一个人相信什么。西班牙宗教裁判所是另一个机构，由西克斯图斯四世（Sixtus IV）于1478年11月1日批准，它属于[[crises/year-1492]]。妇女的法律地位因身份、婚姻、城市与誓愿而异。本章不会概述“中世纪的女人”。多数人的生活不是这些法律。一部只写骑士，或只写大教堂的历史，已经把他们剪掉了。

## 一道法令是一道命令，不是一条街道

第68条教规是一项法律意志的证据。以转述、而不作为引用：公会议要求一种服饰上的区分，好让犹太人与穆斯林在拉丁基督教之地能够同基督徒区分开来。年表自己的措辞已经足够：他们要由服饰来标记。公会议并没有凭那道命令向每一条街道发放一套制服。后来的地方规则规定了徽章、颜色或衣装，而这些规定彼此不同。一枚覆盖全欧洲的徽章的单一图画，是一种后来的化简。本章不会为任何一个王国那个标记的版本发明一个年份，也不会把一条地方规则当作仿佛教规给它拍过一张照片来对待。

被点名的人不是一个法律拟制，也不仅仅是一个法律拟制。拉丁基督教世界内的犹太共同体有自己的礼拜、法律与学术。穆斯林共同体生活在某些被征服之地——包括伊比利亚与西西里的部分地方——的基督教诸王之下，而在安达卢斯（al-Andalus），穆斯林不是在一个伊斯兰政治体之内的一个被标记的少数。[[after-rome/islam-in-the-west]]是那张别的地图。第68条教规把犹太人与穆斯林想象在拉丁诸司法权之内。它不描述穆斯林统治者，也不穷尽它所标记的那些共同体。只把这个历史写成那个标记，就是重复那个公会议的化约。

执行是一个进一步的问题，而它不由教规的存在来断定。一些统治者与城镇比别的更热心。一些共同体谈判、缴纳，或一度生活在一项与那道法令不相符的地方习惯之下。一道必须被发出的命令，是那个标记本来还不是每个人的习惯的证据。它不是那道命令到处都被执行的证据。两个错误都常见。一个假装教规是不必要的，因为实践本来已经整齐划一。另一个假装实践是整齐划一的，因为教规存在。下面的[[#thm-decree]]拒绝两者，而算例里那座虚构的城镇表明了一条笔记为什么不能替代另一类证据。

拉斯纳瓦斯-德托洛萨（Las Navas de Tolosa）在1212年，在公会议之前三年。1215减1212是3。伊比利亚的一场战役与一条服饰规章是不同的行为。战役不创造教规，教规也不描述战役。[[christendom/crusades]]已经拒绝了那场一场战役拯救欧洲的传说。排斥不是那个传说以别的手段延续。它是关于生活在拉丁基督教权威之下的人的法律。

:::definition 范畴 {#def-category}
这里的**范畴**是权威能够适用的一个法律或神学标签：犹太人、穆斯林、异端，以及那个标签凭对照所暗示的普通基督徒。一个范畴不是信仰的普查，不是一个家户的描述，也不是每一个被如此标签的人都符合法律所用之定义的证据。
:::

:::definition 教皇宗教裁判所 {#def-inquisition}
本图谱在1231年锁定的**教皇宗教裁判所**，是由格列高利九世批准的一个针对异端的程序，那份诏书常被引作Excommunicamus，并委任了查究之人。它不是一种讯问的技术，本章不描述那种技术。它不是1478年11月1日批准的那个西班牙宗教裁判所。
:::

在一个教皇程序存在之前，主教们本来就已追诉异端。1231年的诏书不发明分歧，也不发明主教法庭。它使查究成为一件教皇的工具，并为这项工作任命查办员，常常是托钵修士。那是职位上的一项变更，正是[[christendom/popes-and-kings]]在别的争斗里研究的那一类：谁持有司法权，凭何种权威。那项变更不是对问题如何被提出的描述。本章不描述讯问。它不描述处决。那个程序可以以忏悔礼收场，或以一个人被移交给一座世俗法庭收场。那些是一场法律过程的结果。它们不是一本手册。

:::theorem 范畴被造成可用的 {#thm-usable}
第68条教规与1231年的教皇程序，是使范畴在法律上可用的行为。它们没有证明每一个共同体在实践中都被标记，也没有证明异端是被仅仅找到、而不是被建造为一个罪名的。这条论断没有说有异见是想象中的。
:::
:::proof
R. I. 穆尔（R. I. Moore）曾经论证：异端变成了一个权威能够追诉的范畴，在这些世纪里被建造，而不是作为一个现成的敌人被仅仅发现。本课把那呈现为一条论证，而不是一桩了结争论的事实。支撑那条论证的，就这里锁定的日期而言，正是界定本身的劳作。1215年11月，一个公会议为犹太人与穆斯林命令一个标记。1231年，一份诏书委托对异端的查究。相隔十六年，两者都是关于范畴的法律。必须界定一个标记、或委托一次查究的权威们，是在做某件事。发现一个在每座城市里本来都在场的、充分成形的敌人，将不需要那么多法律。

公允地说，能够构成对穆尔那条论证的反证的，是一条证据：诸公会议与诸诏书只是摹写了一个在每座城镇的实践里本来已经稳定的范畴，没有留下任何界定的劳作。一道必须命令一种区分的法令，是那种稳定性的糟糕证据。有异见的宣讲者与共同体本来存在，这仍然是可能的，而本课承认这种可能。瓦勒度派（Waldensian）的宣讲与清贫，是一个权威逐渐当作异端来处理的运动的相对清楚的例子。史家们对于那些被称为卡特里派（Cathars）的人是否构成一个二元论教会意见不一。这场分歧要紧。一个被建造的罪名仍然可以指向针对教士的真实批评者，而一个真实的批评者与一个统一的对抗教会不是一回事。两个句子都可以为真。本课的论断是那个更窄的。法律使一个范畴变得可用。可用性不是每一个被指控者心灵的誊本。

能够构成对[[#thm-usable]]自身的反证的，是一次可与普查相类的勘察，显示或者这些年份里不曾添加任何法律界定，或者每座城镇本来已经奉行一种整齐的标记与一种整齐的罪名。本图谱没有这样一次勘察。十字军的战争也被转向拉丁基督教世界内部那些被教会称为异端的人。本图谱没有为那些征伐锁定年份，所以一个也不发明。被锁定的工具仍是1231年的程序。
:::

## 十六年，两条法律

:::widget timeline
start: 1200
end: 1250
window: 5
events: 1215,第四次拉特兰; 1231,教皇宗教裁判所
caption: 移动年份。一条服饰规章与一个针对异端的程序相隔十六年。两者都是关于范畴的法律。
:::

那张图的十六年是1231减1215。窗口是五年，所以那两个圆点即便在一个短标尺上也不相邻。一个只记得“教会迫害局外人”的读者已经把它们熔在了一起。服饰是关于被如此识别的犹太人与穆斯林的规则，不是关于被指控教义错误的基督徒的规则。异端是一项针对那些教会自称属于自己的、然后把他们置于正统之外的人的指控。范畴不同。权力也不同：一个为拉丁基督教世界立法的公会议，一位委托一个程序的教皇。把它们熔在一起，就把每一个犹太人变成一个异端分子，把每一项异端指控变成一套服饰规则。两种熔合都不符合那些文本。

1215年6月仍然是《大宪章》，一位国王与其贵族之间的一次和平，正如[[christendom/popes-and-kings]]所论。1215年11月是这个公会议。同一个年份装着一份贵族的特许状与一次大公会议。英诺森三世是本图谱与两者一同点名的教皇，他在主持那个公会议的同时，站在了特许状的对立面。一个年份，两份文书，一位不在一个简单的教会对国王的故事任何一侧的教皇。排斥不是政治历史之后才添加的。它就在同几个月里。

:::example 十六年 {#ex-sixteen}
1215年11月与1231年的教皇程序之间相隔多少年？那个空隙禁止哪一种熔合？
:::solution
1231减1215是16。那张图以文字说出了同一个空隙。第68条教规是犹太人与穆斯林的一条服饰规则。Excommunicamus是一个针对异端的程序。十六年，加上主题之别，禁止那种把“迫害”当作一个行为、一个目标的句子。那个空隙是年份数字之别。它不是说中间的年份空无法律，也不是一个死亡总数。
:::
:::

:::example 同一个年份，两份文书 {#ex-same-year}
把1215年6月放在1215年11月旁边。分别点名每一份文书，并说一部只保留第一部的历史会出什么错。
:::solution
6月是《大宪章》，一位国王与其贵族之间的一次和平，不是一部现代宪法。11月是第四次拉特兰公会议，包括第68条教规。一部只保留那份特许状的历史，可以讲述一个贵族限制国王的故事，而从不提一条服饰规则，也不提一个基督教社会在同一个年份被立法。那种剪辑正是排斥如何变成一块事后添加的污斑，而不是那一年份的法律的一部分。英诺森三世把那些月份连接起来，而没有把它们变成一个纲领：他站在了特许状的对立面。那个公会议别的牧养规则，也不是那份特许状的条款。
:::
:::

:::theorem 一道法令不是一座城镇 {#thm-decree}
一条关于服饰的法令，是一项标记犹太人与穆斯林的法律意志的证据。它不是每一个犹太人或穆斯林共同体在实践中都被标记的证据。地方实践是一个进一步的问题，而它不靠重复那条教规来回答。
:::
:::proof
那条教规的文本，作为一道命令，显示了公会议要求什么。服从是第二桩事实，而诸史料因城镇与年代而不同。本章不会发明一个遵从率。能够构成对这条论断的反证的，是1215年11月之后的一次勘察，显示一种独特的服饰实际在每一座拉丁城镇被穿着。这里没有锁定这样一次勘察。一桩服从的轶事不会是那次勘察。一桩疏忽的轶事也不会废除那条教规。

下面这个虚构的例子是对两个错误的一个限度。它不是关于任何真实之地的证据。它显示逻辑上的口子：一道法令与一次地方观察是不同类型的存迹，而两者都不会自行提升为另一种。[[sources/evidence]]是一般规则。一座城镇的记录中的一份沉默，不是没有人被标记的证明，也不是那条教规被宣读并被服从的证明。
:::

## 被建造，而且也不是一个生命的全部

对一个纯粹“被建造”的故事的反论值得它自己的篇幅，因为穆尔的论证容易被过度解读。人们批评教士。人们形成追随者。一些信仰确实与诸公会议所谓正统相矛盾。如果“被建造”意味着“凭空发明”，那条论证就会是假的，而本章不按那种方式使用它。被建造意味着被造成可用：被命名，被列出，被交给一座法庭或一名查办员，被附上一项刑罚。一个运动可以是真实的，同时仍然被那个罪名重新塑形。史家们尤其对于那些被称为卡特里派的人的统一性意见不一。呈现这场分歧是那条论证的一部分，不是救一句更整洁句子的脚注。

妇女的法律地位横切本章的每一个范畴。一名贵族女继承人、一名维兰遗孀、一名修女、一名城市妇女与一名犹太妇女不分享一个法律人格。身份、婚姻财产、城镇习惯与宗教法律把她们分开。第68条教规，在施行的地方，把犹太妇女与穆斯林妇女标记为一个被标记的共同体的成员，而不是抽象的“女人”。一项异端指控可以作为信徒、也作为一家之主触及妇女。那种可能不是一部传记，也不是描述讯问的许可。多数妇女的生活不是第68条教规，也不是一份裁判所案卷。那些生活在这些特定法律之中的沉默，是关于这些法律为了什么而立的证据，不是那些妇女没有头脑的证据。[[sources/evidence]]说，一份沉默是关于谁被询问的证据。

“中世纪的女人”之所以失败，其结构性理由与“农奴”在[[christendom/lords-and-peasants]]中失败、“中产阶级”在[[christendom/towns-and-learning]]中失败相同。它给出一个主体，好让一部法律、一座市场与一个家户能够被当作她的例证。它们不是例证。它们是不同的尺度。一条服饰规则是一个范畴。一个异端程序是一个范畴。一名遗孀对一间作坊的控制是一桩地方经济事实。三者之中没有一个是其余者的真相。

骑士与大教堂是这门课程一直在拒绝的剪辑。一座大教堂是一座教堂，而且常常是一位领主。一名骑士是一个小精英集团里的一名武装成员。两者都在拉丁基督教世界之内。两者都不是那几个世纪的内容。一部只保留它们的历史，可以赞叹石头与荣誉，而不读第68条教规，不见1231年的程序，也不留意多数人是某人的法律之下的农民、市民、妇女、犹太人或穆斯林。那种剪辑是一种选择。它不是记录所含有的东西。

:::example 两个裁判所 {#ex-two}
教皇程序是1231年。西克斯图斯四世于1478年11月1日批准西班牙宗教裁判所。年份数字之间相隔多少年，第二个为什么不是一个仅仅沿用同一个名字的延续？
:::solution
1478减1231是247。二百四十七年不是一个官署的延续。第一个是十三世纪的拉丁教会内部一个针对异端的教皇程序。第二个是1478年为西班牙诸王冠批准的机构，在[[crises/year-1492]]里教授，不在这里。共享裁判所这个词，正是那种熔合发生的方式。[[#def-inquisition]]把它们分开。那个空隙不是一个关于两种程序各自如何讯问人的论断。本章不描述那个。
:::
:::

:::example 一条虚构的笔记 {#ex-note}
下面这句话为示例而虚构。它不是史料。“在虚构的米尔布里奇（Millbridge）镇，在公会议之后的那一年，一名旅行者没有在任何一个犹太人或穆斯林居民身上看到独特的服饰。”

即便作为逻辑，这条笔记不能做什么？而一份同形的真实记录，仍然不能对第68条教规做什么？
:::solution
米尔布里奇是虚构的，所以那条笔记关于1215年或任何一座城镇什么也不能证明。作为逻辑，它显示一个口子：一次地方的观察，若是真实的，将是关于一个地方的证据，不是一次对那个公会议的废除。一份同形的真实记录仍然不会抹去第68条教规。那条教规将仍然是一道命令。那条记录将仍然是一座城镇的存迹，而且只有当它是真实的、有日期的、并且真正关于服饰时才是。一座城镇不能证明每一座城镇都无视了那条教规，正如那条教规不能证明米尔布里奇服从了它。[[#thm-decree]]就是那种分开。提升那条笔记将需要一份真实的文书。把那条教规当作米尔布里奇的一张照片，将需要那道命令在那里被执行的证据。
:::
:::

后来的驱逐与改宗不是这条教规长大成人。1492年1月2日，格拉纳达（Granada）投降。1492年3月31日，《阿尔罕布拉法令》命令卡斯蒂利亚与阿拉贡的犹太人改宗或离去，期限是7月31日。那是一个年份内部的几桩事件，而[[crises/year-1492]]拒绝把它们坍缩成近代欧洲的诞生。1215年11月的一条服饰规则与1492年的一道驱逐令是不同的行为。从1215年到1492年是277年。1492减1215是277。距离就是要点。其间一些王国驱逐过犹太共同体。本图谱没有锁定那些年份，所以本章不发明它们，包括对英格兰。一个锁定年份的缺席，不是诸共同体的缺席。它是对本段可以定年之物的一个限度。

扬·胡斯（Jan Hus）在1415年被处以火刑，在康斯坦茨（Constance）公会议期间，在[[crises/war-and-schism]]所教授的那场权威危机之内。从1231年到1415年是184年。1415减1231是184。康斯坦茨的一场火刑不是格列高利九世的诏书，也不是第68条教规。这种比较制止了一种把每一次后来的追诉都当作1231年换了名目的习惯。西方大分裂与结束它的公会议不是本章的故事。年份已足以保持距离。

:::warning 一枚徽章，一个裁判所，一个女人
三个迷思把同一份证据收拾得整整齐齐。第一个说，因为第68条教规要求一个标记，每一个犹太人与穆斯林共同体都佩戴了它。一道法令不是一条街道。第二个说，1231年的教皇程序就是西班牙宗教裁判所。1478年的批准在247年之后，而且是另一个机构。第三个说，存在过一个中世纪的女人，其法律地位可以被概述。身份、婚姻、城市与誓愿把那个形象切割，直到它不再是一个主体。本章也不描述讯问。一套程序不是一种技术。
:::

:::quiz
哪一个配对在历史上是一个机构？
- [ ] 格列高利九世1231年的程序与1478年批准的西班牙宗教裁判所。
- [ ] 第68条教规与1212年的拉斯纳瓦斯的战役。
- [x] 两个配对都不是。一条服饰规则、一场战役、一个教皇程序与一个更晚的西班牙的机构是不同的行为。
- [ ] 1215年6月的《大宪章》与第68条教规，因为它们共享一个年份。
:::solution
共享一个年份，不把6月的贵族的和平与11月的公会议熔在一起。共享一个词，不把1231年与1478年熔在一起。1215减1212是3，而一场仍然不是一套服饰规则。[[#def-inquisition]]与[[#thm-decree]]是那些分开。正确的回答是：这些配对没有一个是同一个机构或同一个行为。
:::
:::

:::history 一个标记的公会议
1215年11月，英诺森三世之下的第四次拉特兰公会议凭第68条教规，要求拉丁基督教世界内的犹太人与穆斯林由服饰标记。那道法令不是对每座城市的描述。1231年，格列高利九世批准一个针对异端的教皇程序，它更晚且在法律上有别于1478年的西班牙宗教裁判所。
:::

## 通向何处

[[crises/year-1492]]装着格拉纳达、《阿尔罕布拉法令》与西班牙宗教裁判所的世界。它们不是第68条教规。[[crises/war-and-schism]]装着1415年扬·胡斯的火刑，以及始于1378年的那个分裂，那是与格列高利九世的程序不同的另一场权威危机。[[christendom/crusades]]是诸远征的暴力，包括第一次十字军期间对莱茵兰犹太人的攻击，那不是与一条服饰规章同一个行为。[[christendom/towns-and-learning]]是法人团体与路线在同一批世纪里坐落的地方，而它们不是一个中产阶级。[[christendom/lords-and-peasants]]是骑士的历史同样剪掉的不自由的多样。[[sources/evidence]]是如何阅读一份案卷、一条教规与一份沉默，而不把任何一样提升为一个它没有记录过的心灵。

:::summary
- 1215年11月，第68条教规要求拉丁基督教世界内的犹太人与穆斯林以服饰相区别。一道法令不是每座城镇的实践。
- 1231年，格列高利九世批准教皇宗教裁判所，一个针对异端的程序。它不是1478年11月1日的西班牙宗教裁判所。空隙是247年。
- 两条法律相隔十六年，关乎不同的范畴。服饰不是一项异端指控。
- 穆尔的论证——以一条论证的身份呈现——是异端被造成一项可用的罪名，而不是被仅仅找到。异见仍然可以是真实的。史家们对于那些被称为卡特里派的人的统一性意见不一。
- 本章不描述讯问，也不描述处决。一套程序不是一种技术。
- 妇女的法律地位有变化。没有一个中世纪的女人。多数人的生活不是这些法律。
- 1215年6月与1215年11月是同一个年份，不是同一份文书。排斥是政治故事之后添加的一块污斑。
- 后来的驱逐——包括1492年——与1415年胡斯的火刑，是不同距离上的不同行为。本图谱没有锁定的年份，不会被发明出来填那些空隙。
:::

## 习题

:::exercise 那张图上的空隙 {level=1 check="16"}
第四次拉特兰公会议与1231年的教皇程序之间相隔多少年？（请输入年数。）
:::solution
1231减1215是16。第68条教规与Excommunicamus是那两条法律。十六年禁止把它们当作一个行为来对待。那张图的图说用文字说出了同一个空隙。
:::
:::

:::exercise 两个机构 {level=1 check="247"}
1231年与西班牙宗教裁判所的批准之间相隔多少年？（请输入年数。）
:::solution
1478减1231是247。西克斯图斯四世的批准在1478年11月1日。这个距离就是为什么两者不是同一个名字之下的一个连续的机构。西班牙宗教裁判所属于1492年那一章，不属于对格列高利九世的程序的描述。
:::
:::

:::exercise 诏书的年份 {level=1 check="1231"}
本图谱把格列高利九世的针对异端的教皇程序定在哪一年？（请输入年份。）
:::solution
1231。常被引作的诏书是Excommunicamus。那个年份不是1215年11月，那是公会议；也不是1478年，那是西班牙的批准。那个程序不是一种讯问的技术。
:::
:::

:::exercise 为什么一条教规不是一条街道 {level=2}
一个读者说，第68条教规证明拉丁基督教世界的每一个犹太共同体在1215年11月之后都佩戴了一个独特的标记。解释这个错误，并说出那条教规确实证明了什么。
:::solution
那条教规证明一项法律意志：公会议为拉丁基督教世界内的犹太人与穆斯林命令一种服饰上的区分。它不证明服从。[[#thm-decree]]把命令与实践分开。地方规则后来规定了形式，而那些形式不是一套欧洲的制服。本图谱没有锁定一个遵从率，所以一个也不发明。一座无视那条教规的虚构城镇，也不会反驳那道命令。命令与街道是不同的存迹。
:::
:::

:::exercise 不是同一个裁判所 {level=2}
用西班牙宗教裁判所来回答一个关于1231年的问题，为什么是错误？用上那个年份之别与那个权威之别。
:::solution
1478减1231是247。格列高利九世批准一个针对异端的教皇程序。西克斯图斯四世于1478年11月1日批准一个西班牙诸王冠的机构。词是共享的。官署、世纪与政治体不是。[[#def-inquisition]]说出那种分开。把那个更晚的机构描述得仿佛它在1231年已经运作，就是把[[crises/year-1492]]坍缩进本章。两个年份都不是描述讯问的许可。
:::
:::

:::exercise 没有一个女人 {level=2}
为什么“中世纪的女人”作为本章法律地位的概述会失败？给出两条把那个形象切开的切割，并说出第68条教规关于妇女说了什么、没有说什么。
:::solution
那个形象之所以失败，是因为法律地位有变化。两条切割已经足够：身份，例如贵族女继承人对着维兰遗孀；以及宗教法律，例如一名修女对着一名犹太妇女——后者既生活在一个共同体的规范之下，又（在施行的地方）生活在一道基督教的服饰规则之下。城镇习惯与婚姻切割得更远。第68条教规若被施行，把犹太妇女与穆斯林妇女标记为一个被标记的共同体的成员。它没有创造一个叫作女人的主体，也没有描述多数妇女的生活。一份异端案卷同样是一个范畴，不是一部传记。这些法律中的沉默，不是妇女没有头脑的证据。
:::
:::

:::exercise 什么会构成对穆尔的反证 {level=3}
[[#thm-usable]]呈现了穆尔的论证：异端被造成一个可用的范畴，而不是被仅仅找到。什么样的证据会构成对那条论证的反证？为什么真实宗教异见的存在，单凭自身不是那个反驳？
:::hint
寻找一个在每座城镇本来已经稳定的范畴，好让诸公会议与诸诏书只是摹写它。罪名仍然被建造的同时，异见可以是真实的。不要描述一套讯问的程序。
:::
:::solution
如果诸公会议与诸诏书只是摹写了一个在每座城镇的实践里本来已经稳定的范畴，没有留给权威任何界定的、命名的、委任的劳作，那条论证就会失败。一道必须命令一个标记的法令，与一份必须委托查究的诏书，是那种现成的稳定性的别扭证据。真实的异见不能反驳那条论证。瓦勒度派的批评与其他宗教分歧可以是真诚的，而史家们对于那些被称为卡特里派的人是否一个教会仍然意见不一。一个真实的批评者与一个法庭能够处理的罪名不是同一个对象。[[#thm-usable]]已经承认异见不必是想象中的。它否认的是那个可用的法律范畴，是躺在街上被仅仅捡到的。回答里不属于对讯问的任何描述。1231年的诏书是一个官署，不是一种技术。
:::
:::

:::exercise 提升米尔布里奇 {level=3}
[[#ex-note]]里的那条笔记是虚构的。换一种情形：假设你发现一份真实的、有日期的记录，显示在一座真实的城镇，1215年11月之后五年，没有任何独特的服饰在用。你能得出什么，不能得出什么，而有什么是你仍然不被允许发明的？
:::hint
让[[#thm-decree]]保持在视野之内。一座城镇不是每一座城镇，而一条教规不会自行废除。五年不是你需要命名的一个新的行为之年。不要添加一个死亡总数或一种查究的方法。
:::
:::solution
你可以得出：若那份记录是真实的、并且真正关于服饰，那座城镇在那个时刻没有显示那个标记。你不能得出：第68条教规被废除了，每座城镇都无视了它，或没有一座城镇服从了它。那条教规将仍然是1215年11月的一道命令。那份记录将仍然是地方的。你仍然不会发明一个遵从率、一个死亡总数、为某个别的王国的徽章的一个年份，或对异端查究如何进行的任何描述。米尔布里奇本身仍然是虚构的，什么也不能证明。那座真实的城镇，与米尔布里奇不同，将只是城镇尺度的证据。[[sources/scale]]就是从一个街道到拉丁基督教世界的跳跃为什么在两个方向上都失败的原因。
:::
