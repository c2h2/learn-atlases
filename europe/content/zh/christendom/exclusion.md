拉丁基督教的法律如何把人划在界外？1215年11月，英诺森三世（Innocent III）主持的第四次拉特兰公会议，为一个它视为基督教社会的社会立法。第68条教规要求拉丁基督教世界中的犹太人和穆斯林以特殊服饰相区别。1231年，格列高利九世（Gregory IX）以一道常被称为Excommunicamus的诏书，批准设立教皇宗教裁判所，即一套针对异端的程序。服饰规定与异端程序相隔十六年：1231减1215是16。它们不是同一部法律，但都是关于身份类别的法律。

类别告诉官员该标记谁、该调查谁，以及谁算是界线另一侧的普通基督徒。它不能告诉你每座城镇都照办了，也不能告诉你任何一个人信仰什么。西班牙宗教裁判所是另一个机构，由西克斯图斯四世（Sixtus IV）于1478年11月1日批准设立，属于[[crises/year-1492]]的内容。妇女的法律地位因身份、婚姻、城镇和誓愿而异，本章不会概括出一个“中世纪妇女”。大多数人的生活并不等于这些法律。一部只写骑士或只写大教堂的历史，已经把这些人删去了。

## 法令是命令，不是街头实况

第68条教规是一种法律意志的证据。以下是转述，而非引文：公会议要求在服饰上加以区分，以便在拉丁基督教地区把犹太人和穆斯林与基督徒区别开来。年表本身的措辞就已足够：他们须以服饰相标记。公会议并没有通过这道命令给每条街道发一套统一的制服。后来的地方规定具体指定了徽章、颜色或衣着，而这些规定各不相同。“全欧洲佩戴同一种徽章”的图景，是后来的简化。本章不会为任何一个王国的标记形式杜撰年份，也不会把某条地方规定当作这条教规的写照。

被点名的这些人并不是法律拟制，至少不只是法律拟制。拉丁基督教世界中的犹太社区有自己的礼拜、律法和学术。在某些被征服的地区，包括伊比利亚和西西里的部分地方，穆斯林社区生活在基督教国王统治之下；而在安达卢斯（al-Andalus），穆斯林身处伊斯兰政权之中，并不是被标记的少数群体。那是[[after-rome/islam-in-the-west]]中的另一幅地图。第68条教规设想的是拉丁司法管辖之下的犹太人和穆斯林。它没有描述穆斯林统治者，也远不能涵盖它所标记的那些社区的全部。如果只把这段历史写成那个标记，就是在重复公会议的化约。

执行是另一个问题，并不因教规的存在而得到解答。有些统治者和城镇比别处更积极；有些社区通过谈判、缴纳钱款，或在一段时间里依照与法令不符的地方惯例生活。一道必须颁布的命令，恰恰说明这种标记原本并非人人遵行的习惯；但它并不证明这道命令在各地都得到了执行。两种错误都很常见：一种假装教规没有必要，因为实践本已整齐划一；另一种假装实践整齐划一，因为教规已经存在。下文的[[#thm-decree]]对两者都予以拒绝，而算例中那座虚构的城镇将说明，为什么一条记载不能替代另一类证据。

拉斯纳瓦斯-德托洛萨（Las Navas de Tolosa）之战发生在1212年，比这次公会议早三年：1215减1212是3。伊比利亚的一场战役和一条服饰规定是不同的行为。战役没有产生这条教规，教规也没有描述那场战役。[[christendom/crusades]]已经否定了“一场战役拯救欧洲”的传说。排斥并不是这一传说以其他手段的延续，而是关于生活在拉丁基督教权威之下的人们的法律。

:::definition 身份类别 {#def-category}
这里的**身份类别**指权威可以适用的法律或神学标签：犹太人、穆斯林、异端，以及通过对照而隐含的普通基督徒。类别不是信仰普查，不是对某个家庭的描述，也不能证明每个被贴上这一标签的人都符合法律所用的定义。
:::

:::definition 教皇宗教裁判所 {#def-inquisition}
本图谱定于1231年的**教皇宗教裁判所**，是格列高利九世以一道常被称为Excommunicamus的诏书批准的一套针对异端的程序，并委派专人进行调查。它不是一种审讯技术（本章不描述审讯），也不是1478年11月1日批准设立的西班牙宗教裁判所。
:::

在教皇程序出现之前，主教们就已经在追究异端。1231年的诏书既没有制造分歧，也没有创设主教法庭；它所做的，是把调查变成教皇的工具，并为此委派专员，这些专员常常是托钵修士。这是职位层面的变化，正是[[christendom/popes-and-kings]]在其他争端中所研究的那一类问题：谁掌握司法权，依据什么权威。这一变化并不描述如何提问。本章不描述审讯，也不描述处决。这套程序的结果可以是悔罪，也可以是把人移交世俗法庭。这些都是法律程序的结果，而不是一本操作手册。

:::theorem 类别被制造得可以使用 {#thm-usable}
第68条教规和1231年的教皇程序，是使身份类别在法律上可以使用的行为。它们并不证明每个社区在实践中都被标记了，也不证明异端只是被发现的，而不是被建构为一项罪名的。这一论断并不是说异见纯属想象。
:::
:::proof
R. I. 穆尔（R. I. Moore）认为，异端是在这几个世纪中被建构成一个权威可以追诉的类别，而不只是作为一个现成的敌人被发现。本章把这一观点作为一个论证提出，而不是作为一个终结争论的事实。就这里确定的日期而言，支持这一论证的正是界定工作本身：1215年11月，一次公会议下令标记犹太人和穆斯林；1231年，一道诏书委派对异端的调查。两者相隔十六年，都是关于身份类别的法律。必须界定标记、委派调查的权威，是在主动做事。倘若只是发现一个早已在每座城镇里完全成形的敌人，就不需要这么多法律。

公允地说，能够推翻穆尔这一论证的，是这样的证据：公会议和诏书只是照搬了一个在各城镇实践中早已稳定的类别，而没有留下任何界定的工作。一道必须下令加以区分的法令，恰恰难以证明这种稳定性。持异见的布道者和团体可能确实存在，本章承认这种可能。瓦勒度派（Waldensian）的布道与守贫，是一个权威后来逐渐当作异端处理的运动的较为清楚的例子。至于被称为卡特里派（Cathars）的人是否构成一个统一的二元论教会，史家意见不一。这一分歧很重要。一项被建构的罪名仍然可能针对真实的教士批评者，而真实的批评者并不等于一个统一的对立教会。两句话可以同时成立。本章的论断较窄：法律使一个类别变得可以使用，而可用性并不是每个被指控者内心的誊本。

能够推翻[[#thm-usable]]本身的，是一份类似普查的调查，表明这些年里没有增加任何法律界定，或者各城镇早已实行统一的标记和统一的罪名。本图谱没有这样的调查。十字军战争也曾被转而用于对付拉丁基督教世界内部被教会称为异端的人。本图谱没有为这些征讨确定年份，因此这里不杜撰。已确定的工具仍然是1231年的程序。
:::

## 相隔十六年的两部法律

:::widget timeline
start: 1200
end: 1250
window: 5
events: 1215,第四次拉特兰公会议; 1231,教皇宗教裁判所
caption: 移动年份。服饰规定与针对异端的程序相隔十六年。两者都是关于身份类别的法律。
:::

图上的十六年就是1231减1215。窗口是五年，所以即使在较短的标尺上，这两个圆点也不相邻。只记得“教会迫害外人”的读者，已经把两者熔为一体了。服饰规定针对的是被认定为犹太人和穆斯林的人，而不是被指控犯有教义错误的基督徒。异端罪名针对的则是教会视为自己人、继而又把他们划出正统之外的人。类别不同，权力也不同：一边是为拉丁基督教世界立法的公会议，一边是委派一套程序的教皇。把两者熔为一体，就会把每个犹太人都变成异端，把每项异端指控都变成服饰规定。两种熔合都与文本不符。

1215年6月仍然是《大宪章》，即国王与贵族之间的和约，正如[[christendom/popes-and-kings]]所论证的；1215年11月则是这次公会议。同一年里既有一份贵族特许状，又有一次大公会议。英诺森三世是本图谱在两件事中都提到的教皇：他主持公会议，同时反对那份特许状。同一年，两份文书，一位并不站在“教会对抗国王”这个简单故事任何一方的教皇。排斥并不是在政治史之后才添上去的，它就发生在同样的几个月里。

:::example 十六年 {#ex-sixteen}
1215年11月与1231年的教皇程序之间相隔多少年？这段间隔排除了哪一种熔合？
:::solution
1231减1215是16，图上以文字说出了同样的间隔。第68条教规是针对犹太人和穆斯林的服饰规定，Excommunicamus是针对异端的程序。十六年的间隔，加上主题的差异，排除了把“迫害”说成只有一个目标的单一行为。这段间隔是年份数字之差，并不意味着其间没有任何法律，也不是死亡总数。
:::
:::

:::example 同一年，两份文书 {#ex-same-year}
把1215年6月与1215年11月对照。分别说出每份文书是什么，并指出一部只保留前者的历史会出什么问题。
:::solution
6月是《大宪章》，即国王与贵族之间的和约，不是现代宪法。11月是第四次拉特兰公会议，其中包括第68条教规。一部只保留那份特许状的历史，可以讲一个贵族限制国王的故事，却始终不提同一年里出现的服饰规定，也不提一个基督教社会在同一年被立法规范。正是这种删改，使排斥变成了后来才添上的污点，而不是那一年法律的一部分。英诺森三世把这几个月连在一起，却并没有使它们成为同一个纲领：他反对那份特许状。公会议的其他牧灵规定，也不是那份特许状的条款。
:::
:::

:::theorem 法令不等于城镇 {#thm-decree}
关于服饰的法令，证明的是一种要标记犹太人和穆斯林的法律意志，而不是每个犹太社区或穆斯林社区在实践中都被标记了。地方实践是另一个问题，不能靠复述教规来回答。
:::
:::proof
教规的文本作为一道命令，显示了公会议的要求。服从是另一个事实，而史料因城镇和年代而异。本章不会杜撰一个遵行比例。能够推翻这一论断的，是一份1215年11月以后的调查，表明每座拉丁城镇的人都实际穿着同一种特殊服饰。这里没有确定这样的调查。某座城镇遵行的轶事不能充当这样的调查；某座城镇疏于执行的轶事，也不能废除这条教规。

下面这个虚构的例子，对这两种错误都设了限。它不是关于任何真实地方的证据，只用来显示逻辑上的缺口：法令和地方观察是不同类型的痕迹，哪一种都不会自动升格为另一种。一般原则见[[sources/evidence]]。一座城镇记录中的沉默，既不能证明没有人被标记，也不能证明这条教规曾被宣读并得到遵行。
:::

## 是被建构的，也不是生活的全部

对纯粹“建构”说的反论值得专门讨论，因为穆尔的论证很容易被过度解读。人们确实批评教士，确实形成了追随者群体；有些信仰也确实与公会议所说的正统相抵触。如果“建构”意味着“凭空捏造”，这一论证就是错的，而本章并不在这个意义上使用它。“建构”指的是使之可以使用：命名、列举、交给某个法庭或专员处理、附加刑罚。一个运动可以是真实的，同时又被这项罪名重新塑造。史家尤其在被称为卡特里派的人是否统一的问题上意见不一。呈现这一分歧本身就是论证的一部分，而不是用来保全一句更整齐的话的脚注。

妇女的法律地位贯穿本章的每一个类别。贵族女继承人、维兰遗孀、修女、城镇妇女和犹太妇女，并不共有同一种法律人格。身份、婚姻财产、城镇惯例和宗教法把她们区分开来。第68条教规在得到执行的地方，是把犹太妇女和穆斯林妇女作为被标记社区的成员来标记，而不是作为抽象的“妇女”。异端指控可能作为信徒、也作为家长而涉及妇女，但这种可能性既不是一部传记，也不是描述审讯的许可。大多数妇女的生活既不是第68条教规，也不是一份宗教裁判所的卷宗。这些生活在这些特定法律中的沉默，证明的是这些法律为何而立，而不是这些妇女没有思想。[[sources/evidence]]指出，沉默证明的是谁被问到了。

“中世纪妇女”之所以站不住，结构上的原因与[[christendom/lords-and-peasants]]中的“农奴”、[[christendom/towns-and-learning]]中的“中产阶级”站不住是一样的：它提供一个单一的主体，好让一部法律、一个市场和一个家庭都能被当作她的例证。但它们并不是例证，而是不同的尺度。服饰规定是一个类别，异端程序是一个类别，一位寡妇掌管作坊则是一个地方经济事实。三者中没有哪一个是其余两者的真相。

骑士和大教堂，正是本课程一直拒绝的那种删改。大教堂是教堂，也常常是领主；骑士是一个小小精英阶层中的武装成员。两者都在拉丁基督教世界之内，但都不是这几个世纪的全部内容。一部只保留他们的历史，可以赞美石头与荣誉，却从不读第68条教规，从不接触1231年的程序，也从不注意到大多数人是生活在某人法律之下的农民、市民、妇女、犹太人或穆斯林。这种删改是一种选择，而不是记录本身的内容。

:::example 两个宗教裁判所 {#ex-two}
教皇程序在1231年，西克斯图斯四世于1478年11月1日批准设立西班牙宗教裁判所。两个年份数字之间相隔多少年？为什么后者并不只是换了同一个名字的延续？
:::solution
1478减1231是247。二百四十七年并不意味着同一机构的延续。前者是十三世纪拉丁教会内部一套针对异端的教皇程序；后者是1478年为西班牙诸王国批准设立的机构，在[[crises/year-1492]]中讲授，而不在这里。两者都叫“宗教裁判所”，熔合就是这样发生的。[[#def-inquisition]]把它们区分开来。这段间隔并不涉及两套程序各自如何审问人，本章不描述这些。
:::
:::

:::example 一条虚构的记载 {#ex-note}
下面这句话为示例而虚构。它不是史料。“在虚构的米尔布里奇（Millbridge）镇，公会议召开后的第二年，一位旅行者在任何犹太居民或穆斯林居民身上都没有看到特殊服饰。”

即使仅作为逻辑，这条记载做不到什么？一份形式相同的真实记录，又仍然不能对第68条教规做什么？
:::solution
米尔布里奇是虚构的，所以这条记载对1215年或任何城镇都证明不了什么。作为逻辑，它显示出一个缺口：一次地方观察如果属实，也只是关于一个地方的证据，而不是对公会议决定的废除。一份形式相同的真实记录，同样不能抹去第68条教规。教规仍是一道命令；那份记录仍只是一座城镇的痕迹，而且只有在它真实、有日期、确实关于服饰时才是如此。一座城镇无法证明每座城镇都无视了这条教规，正如这条教规无法证明米尔布里奇遵行了它。[[#thm-decree]]说的正是这种区分。要提升这条记载，需要一份真实的文书；要把这条教规当作米尔布里奇的写照，则需要证明这道命令在那里得到了执行。
:::
:::

后来的驱逐和强制改宗，并不是这条教规的成年形态。1492年1月2日，格拉纳达（Granada）投降。1492年3月31日，《阿尔罕布拉法令》命令卡斯蒂利亚和阿拉贡的犹太人改宗或离境，期限为7月31日。这是同一年中的几件事，[[crises/year-1492]]拒绝把它们压缩成近代欧洲的诞生。1215年11月的服饰规定与1492年的驱逐令是不同的行为。从1215年到1492年是277年：1492减1215是277。要点正在于这段距离。其间曾有一些王国驱逐犹太社区，本图谱没有确定这些年份，所以本章不杜撰，英格兰也不例外。没有确定的年份，并不意味着这些社区不存在，而只是限制了这一段可以定年的内容。

1415年，扬·胡斯（Jan Hus）在康斯坦茨（Constance）公会议期间被处以火刑，这属于[[crises/war-and-schism]]所讲的权威危机。从1231年到1415年是184年：1415减1231是184。康斯坦茨的火刑既不是格列高利九世的诏书，也不是第68条教规。这一比较可以纠正一种习惯，即把后来的每一次追诉都当作换了名目的1231年。西方教会大分裂以及结束这场分裂的公会议不属于本章的故事，这个年份已足以标出两者之间的距离。

:::warning 一种徽章、一个宗教裁判所、一个“中世纪妇女”
三种迷思把同一批证据整理得过于整齐。第一种说，既然第68条教规要求标记，每个犹太社区和穆斯林社区就都佩戴了标记。但法令不等于街头实况。第二种说，1231年的教皇程序就是西班牙宗教裁判所。而1478年的批准晚了247年，是另一个机构。第三种说，存在一个法律地位可以一言以蔽之的“中世纪妇女”。但身份、婚姻、城镇和誓愿把这一形象切分得支离破碎，直到它不再成为一个主体。本章也不描述审讯。程序不是技术。
:::

:::quiz
以下哪一组在历史上是同一个机构？
- [ ] 格列高利九世1231年的程序与1478年批准设立的西班牙宗教裁判所。
- [ ] 第68条教规与1212年的拉斯纳瓦斯之战。
- [x] 两组都不是。服饰规定、战役、教皇程序和后来的西班牙机构是不同的行为。
- [ ] 1215年6月的《大宪章》与第68条教规，因为它们同在一年。
:::solution
同在一年，并不能把6月的贵族和约与11月的公会议熔为一体；同用一个词，也不能把1231年与1478年熔为一体。1215减1212是3，而一场战役仍然不是服饰规定。[[#def-inquisition]]和[[#thm-decree]]就是这些区分。正确答案是：这些组合中没有一组是同一个机构或同一种行为。
:::
:::

:::history 一次下令标记的公会议
1215年11月，英诺森三世主持的第四次拉特兰公会议以第68条教规要求拉丁基督教世界中的犹太人和穆斯林以服饰相标记。这道法令并不是对每座城镇的描述。1231年，格列高利九世批准了一套针对异端的教皇程序；这套程序时间更晚，在法律上也有别于1478年的西班牙宗教裁判所。
:::

## 通向何处

[[crises/year-1492]]讲的是格拉纳达、《阿尔罕布拉法令》和西班牙宗教裁判所的世界，它们都不是第68条教规。[[crises/war-and-schism]]讲的是1415年扬·胡斯的火刑，以及始于1378年的大分裂，那是与格列高利九世的程序不同的另一场权威危机。[[christendom/crusades]]讲的是远征中的暴力，包括第一次十字军期间对莱茵兰犹太人的袭击，那与服饰规定不是同一种行为。[[christendom/towns-and-learning]]讲的是同一时期的法人团体和商路，它们并不构成一个中产阶级。[[christendom/lords-and-peasants]]讲的是各种形式的不自由，骑士史同样把它们删去了。[[sources/evidence]]讲的是如何阅读卷宗、教规和沉默，而不把其中任何一样提升为它们从未记录过的人心。

:::summary
- 1215年11月，第68条教规要求拉丁基督教世界中的犹太人和穆斯林穿着特殊服饰。法令并不等于每座城镇的实践。
- 1231年，格列高利九世批准设立教皇宗教裁判所，即一套针对异端的程序。它不是1478年11月1日的西班牙宗教裁判所，两者相隔247年。
- 两部法律相隔十六年，涉及不同的身份类别。服饰规定不是异端指控。
- 穆尔的论证（作为一个论证而提出）认为，异端是被制造成一项可用的罪名，而不只是被发现的。异见仍然可以是真实的。被称为卡特里派的人是否统一，史家意见不一。
- 本章不描述审讯，也不描述处决。程序不是技术。
- 妇女的法律地位因人而异，并不存在一个统一的“中世纪妇女”。大多数人的生活并不等于这些法律。
- 1215年6月与1215年11月同在一年，却不是同一份文书。排斥并不是在政治故事之后才添上的污点。
- 后来的驱逐（包括1492年）和1415年胡斯的火刑，是相隔不同距离的不同行为。本图谱没有确定的年份，不会为了填补空白而杜撰。
:::

## 习题

:::exercise 图上的间隔 {level=1 check="16"}
第四次拉特兰公会议与1231年的教皇程序之间相隔多少年？（请输入年数。）
:::solution
1231减1215是16。第68条教规和Excommunicamus是这两部法律。十六年的间隔不允许把它们当作同一个行为。图注用文字说出了同样的间隔。
:::
:::

:::exercise 两个机构 {level=1 check="247"}
1231年与西班牙宗教裁判所获批设立之间相隔多少年？（请输入年数。）
:::solution
1478减1231是247。西克斯图斯四世的批准在1478年11月1日。正是这段距离，说明两者并不是沿用同一名称的同一个连续机构。西班牙宗教裁判所属于讲1492年的那一章，而不属于对格列高利九世程序的描述。
:::
:::

:::exercise 诏书的年份 {level=1 check="1231"}
本图谱把格列高利九世针对异端的教皇程序定在哪一年？（请输入年份。）
:::solution
1231年。常被引用的诏书是Excommunicamus。这一年不是1215年11月（那是公会议），也不是1478年（那是西班牙方面的批准）。这套程序不是一种审问技术。
:::
:::

:::exercise 为什么教规不等于街头实况 {level=2}
一位读者说，第68条教规证明，1215年11月以后拉丁基督教世界的每个犹太社区都佩戴了特殊标记。请指出这一错误，并说明这条教规确实证明了什么。
:::solution
这条教规证明的是一种法律意志：公会议下令拉丁基督教世界中的犹太人和穆斯林在服饰上加以区分。它不证明人们服从了。[[#thm-decree]]把命令与实践区分开来。后来的地方规定指定了具体形式，而这些形式并不是一套统一的欧洲制服。本图谱没有确定遵行比例，因此不杜撰。一座无视这条教规的虚构城镇，同样驳不倒这道命令。命令与街头实况是不同的痕迹。
:::
:::

:::exercise 不是同一个宗教裁判所 {level=2}
为什么用西班牙宗教裁判所来回答关于1231年的问题是错误的？请利用年份之差和权威来源的不同来说明。
:::solution
1478减1231是247。格列高利九世批准的是一套针对异端的教皇程序；西克斯图斯四世于1478年11月1日批准的，是西班牙诸王国的一个机构。两者共用一个词，但职位、世纪和政治体都不相同。[[#def-inquisition]]表述了这一区分。把后来的机构说得仿佛在1231年就已运作，就是把[[crises/year-1492]]压缩进了本章。两个年份都不允许描述审讯。
:::
:::

:::exercise 没有统一的“妇女” {level=2}
为什么“中世纪妇女”不能概括本章所说的法律地位？请举出两条把这一形象切分开来的界线，并说明第68条教规对妇女说了什么、没有说什么。
:::solution
这一形象之所以站不住，是因为法律地位因人而异。两条界线就足够了：一是身份，例如贵族女继承人与维兰遗孀；二是宗教法，例如修女与犹太妇女——后者既生活在本社区的规范之下，又在教规得到执行的地方受到基督教服饰规定的约束。城镇惯例和婚姻还会作进一步的切分。第68条教规如果得到执行，是把犹太妇女和穆斯林妇女作为被标记社区的成员来标记。它并没有创造出一个名为“妇女”的主体，也没有描述大多数妇女的生活。异端卷宗同样是一个类别，而不是一部传记。这些法律中的沉默，并不证明妇女没有思想。
:::
:::

:::exercise 什么能推翻穆尔的论证 {level=3}
[[#thm-usable]]介绍了穆尔的论证：异端是被制造成一个可以使用的类别，而不只是被发现的。什么证据能够推翻这一论证？为什么真实存在的宗教异见本身并不足以驳倒它？
:::hint
找一找是否有一个在每座城镇都早已稳定的类别，使公会议和诏书只是照搬而已。罪名被建构的同时，异见也可以是真实的。不要描述审问的程序。
:::
:::solution
如果公会议和诏书只是照搬了一个在各城镇实践中早已稳定的类别，而没有给权威留下任何界定、命名或委派的工作，这一论证就站不住了。一道必须下令加以标记的法令，一道必须委派调查的诏书，恰恰难以证明这种现成的稳定性。真实的异见驳不倒这一论证。瓦勒度派的批评和其他宗教分歧可以是真诚的，而被称为卡特里派的人是否构成一个教会，史家至今意见不一。真实的批评者与法庭可以处理的罪名，并不是同一种东西。[[#thm-usable]]已经承认异见未必出于想象，它否认的是：这个可以使用的法律类别是现成地摆在街上、被人直接捡起来的。回答中不应有任何关于审讯的描述。1231年的诏书设立的是一种职能，而不是一种技术。
:::
:::

:::exercise 提升米尔布里奇的记载 {level=3}
[[#ex-note]]中的记载是虚构的。现在假设你找到了一份真实的、有日期的记录，表明在某座真实的城镇，1215年11月之后五年并没有人穿着特殊服饰。你可以得出什么结论？不能得出什么结论？又有什么是你仍然不能杜撰的？
:::hint
把[[#thm-decree]]放在心上。一座城镇不等于每座城镇，教规也不会自行废止。五年后的那一年，不是你需要另行命名的新事件年份。不要添加死亡总数或调查方法。
:::
:::solution
如果那份记录真实，而且确实关于服饰，你可以得出结论：那座城镇在那个时候没有出现这种标记。你不能得出的结论是：第68条教规已被废止，每座城镇都无视了它，或者没有一座城镇遵行它。这条教规仍然是1215年11月的一道命令，那份记录仍然只是地方性的。你仍然不能杜撰遵行比例、死亡总数、其他王国徽章的年份，或任何关于异端调查如何进行的描述。米尔布里奇本身仍是虚构的，什么也证明不了；那座真实的城镇则与之不同，但也只能作为城镇层面的证据。[[sources/scale]]说明了，为什么从一条街跳到整个拉丁基督教世界，无论朝哪个方向跳都站不住。
:::
