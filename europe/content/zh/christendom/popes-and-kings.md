教皇与诸王在争什么？他们在争职位。谁任命一位主教，谁把神职的标记交给他，谁授予那个教座附随的土地与司法权，哪座法庭能够审判一位国王：这些才是问题。他们不是在打一场宗教与国家之间的现代战争，也不是在无意中建设民主。线上的那些文书彼此不同。把它们读成一部宪法，正是本章要阻止的错误。

格列高利七世（Gregory VII）于公元1073年成为教皇。公元1077年1月，亨利四世（Henry IV）在卡诺莎（Canossa）行忏悔礼。《沃尔姆斯协约》（Concordat of Worms）是公元1122年。《大宪章》（Magna Carta）是公元1215年6月一位国王与其贵族之间的和平，并于1225年重新颁布。西蒙·德·蒙福尔（Simon de Montfort）的公元1265年议会座落在一场内战之中。爱德华一世（Edward I）的公元1295年议会后来被称为模范议会。教皇诏书《唯一至圣》（Unam sanctam）是公元1302年。公元1309年，克雷芒五世（Clement V）开始了教皇长期驻跸阿维尼翁（Avignon）。一次忏悔、一项协约、一份贵族的特许状、一场战时的会议、一场国王的会议、一道诏书、一次驻跸的改变，不会因为能被放在同一条线上，就成为同一个故事。

## 任命，不是一桩私人争吵

以格列高利之名流传的改革有一个纲领，而这个纲领关乎职分如何被填补，以及持有者可以拿教会财产做什么。圣职买卖（simony）受到抨击，因为买来的职分既不是一次自由的选举，也不是一个属灵的行为。教士婚姻受到抨击，因为一位已婚的祭司可能把教会土地当作一家的遗产。平信徒叙任受到抨击，因为一位把指环与权杖递给主教的国王，是在授予神职的标记。教会自由（libertas ecclesiae），教会的自由，意味着摆脱那种平信徒的控制。它不意味着王国之内每个人的现代礼拜自由。犹太人、穆斯林以及教会称为异端的人，不是这份自由的受益人。他们的法律地位是[[christendom/exclusion]]的题目。

诸王没有把这个纲领听作一种私人的顾虑。一位主教是一位领主，正是[[christendom/lords-and-peasants]]给那个词的意义：土地、租税与法庭的持有者。谁叙任他，谁就在塑造政治地图。一位监督任命的国王声称自己在保卫国土，而且常常声称是教会的保护者而不是敌人。一位禁止那种监督的教皇，主张一种延及国王身上的司法权。两个句子都是关于职位的宣称。哪一个都不是说“国家”已经被发明出来然后又被击败。

更早的帝国加冕显示教皇与统治者本来就已配对。公元800年12月25日，利奥三世（Leo III）在罗马为查理曼（Charlemagne）加冕为帝。那个宣称是帝国性的，而它从君士坦丁堡提出异议，[[after-rome/carolingians]]对此有交代。公元962年，奥托一世（Otto I）加冕为帝。那是另一次加冕，不是同一场典礼的继续。从962年到1077年卡诺莎的忏悔，是115年。为一位统治者加冕与叙任一位主教是不同的行为。前者产生一个帝国宣称。后者填补一个教会职分。叙任权之争关乎后者，由仍然带着前者记忆的人进行。

公元1054年，涉及洪贝尔（Humbert）与米海尔·凯鲁拉里乌斯（Michael Cerularius）的相互绝罚，标记着拉丁教会与希腊教会之间一场更长的分裂。这一年是一个标记，不是全部故事。本章里的诸教皇是拉丁的教皇。他们与诸王的争吵不描述希腊教会，也不把君士坦丁堡变成拉丁改革的一个部门。在东部继续存在的那个国家是[[after-rome/byzantium]]。

:::definition 叙任 {#def-investiture}
在这场冲突里，**叙任**是把一个教会职分的标记交出去，尤其由一位平信徒统治者来交。指环与权杖是通常处于争议中的标记。叙任不是教皇与国王之间每一场争吵的名称，也不是征税、战争或一次个人羞辱的同义词。
:::

:::definition 职位 {#def-office}
这里的**职位**是一个司法权，带有填补它的程序，以及一个关于谁可以审判其持有者的宣称。职位不是一个人格，不是一个民族，也不是现代国家。两个人可以争夺一个职位，而两人都不打算制定一部宪法。
:::

:::theorem 卡诺莎没有终结这场冲突 {#thm-canossa}
从格列高利七世即位于1073年到《沃尔姆斯协约》的1122年，这场冲突是一场关于任命与司法权的冲突。亨利四世于1077年1月在卡诺莎行的忏悔，是这场冲突内部的一场场面，不是它的终结，也不是教皇对国家的胜利。
:::
:::proof
日期拒绝单一的高潮。格列高利在1073年成为教皇。四年之后，1077年1月，国王行忏悔礼并被赦免。德意志王国内部的反对没有停止：忏悔之后，一个对王位的对手宣称被提出。年表没有为那个对手宣称锁定日子，本章也不会发明一个。它愿意说的是：这场冲突活过了那场会面。1122年，《沃尔姆斯协约》仍有需要了结的东西。

按那份协约的通常读法，神灵的标记与世俗的权利被分开。当选的人从教会一方领受指环与权杖。他从统治者一方、凭一柄节杖而不是凭牧杖，领受世俗权产（regalia），即世俗的产业与世俗的义务。在德意志王国，统治者保有一种在场于选举的存在，而世俗叙任在祝圣之前。在意大利与勃艮第，通常的读法把世俗叙任放在祝圣之后。这是对那份安排之结构的转述，不是引用。结构本身就是证据。国王仍然在一个主教的形成之内。教皇没有废除平信徒的权力。任命被争论进一个区分，而不是被完整地让出。

能够构成对这条论断的反证的，是一份把1077年1月当作终结来对待的史料，双方都这样对待，或者一部把平信徒统治者从任命之中彻底除去的协约。沃尔姆斯没有做到那样。一份后来的复述可以纠缠于积雪与羞辱，生动而仍然是错误类型的解释。天气不是宪法。赦罪不是一场关于谁填补一个职位的争吵的终结。
:::

## 从一次忏悔到一项协约

从1077年到1122年的四十五年，是对那个迷思的最简单的检验。假如卡诺莎已经终结了这场冲突，沃尔姆斯就没有必要，或者它只会是一份已经取得之胜利的会议纪要。它两者都不是。它是一个关于标记与时机的妥协，由一位更晚的教皇与一位更晚的国王谈判：卡利克斯特二世（Callixtus II）与亨利五世（Henry V）。说出他们的名字要紧，因为这场冲突不是同一个一月里两个人之间的决斗。职分比其持有者更长命。格列高利的宣称与亨利四世的忏悔不会作为一桩私人故事到期，然后被一份不相干的特许状替换。谁叙任一位主教，仍然是那个问题。

有一个公平的反对意见。改革想必部分地成功了。主教们不再应当从一位国王手里领受指环与权杖，仿佛国王是神职的源头。那个变更是真实的，我们承认它。在分开两种标记上的成功，不是国王影响的废除，也不是一个与神灵的国家对峙的世俗国家的诞生。协约把统治者留在过程之内，尤其在德意志。想要一场干净胜利的读者必须删除那些条款。能够构成对我们这种读法的反证的，是一部说国王既不到场也不授产的沃尔姆斯文本。协约的通常读法说的不是这个。

同样的这些年份不是教皇政治的全部。改革的教皇制是拉丁的。1054年标记的那场分裂没有被一部德意志的协约医治。一部帝国之内关于叙任的安排不重组希腊教会，也不决定[[christendom/crusades]]从1095年的克莱蒙（Clermont）开始的那些十字军。从1077年的卡诺莎到1095年的克莱蒙，是十八年。一次忏悔与一场布道是不同的文书。一个不解释另一个。

:::example 从忏悔到协约 {#ex-worms}
卡诺莎是1077年1月。《沃尔姆斯协约》是1122年。两个年份数字之间相隔多少年？这个空隙对于一个把忏悔当作终结的故事说明了什么？
:::solution
1122减1077是45。四十五年之后仍然有一项安排要做，而这项安排把神灵的标记与世俗的权利分开，同时给统治者留下一个角色。假如忏悔曾经是终结，这个空隙本应是胜利之后的沉默。它不是。它是一场场面与一次妥协之间的距离。答案是年份数字之差，不是说期间每一年都被同一场争论占据的宣称。
:::
:::

:::example 一句关于卡诺莎的虚构判词 {#ex-invented}
下面这句话是虚构的。“卡诺莎之后，教皇统治了欧洲的诸王，而平信徒的任命停止了。”

要把这句话提升为证据需要什么？哪几个锁定的日期按它的现状构成反证？
:::solution
提升将要求有一份记录，其中平信徒叙任在1077年1月真的停止，并且欧洲的诸王——不是一个忏悔的国王——把教皇的统治接受为一项安定的司法权。这句话不是那条记录。1122年的沃尔姆斯构成反证，因为一部仍然把世俗权产给统治者的协约，不是平信徒任命的停止。1302年的《唯一至圣》以第二种方式构成反证：一个教皇在两个多世纪之后仍然觉得需要主张至尊，这是一种已经取胜的奇怪形态。那句虚构的话借用一次真实的忏悔，加上那次忏悔不曾有过的结果。
:::
:::

## 一场贵族的和平

只有拒绝通常的那种提升，《大宪章》才属于这条线。1215年6月，一位国王与其贵族缔结了一次和平。约翰王面对武装的贵族。这份文书限制了国王取钱与滥用封建权利（feudal incidents）的若干方式，确认英格兰教会的自由，并为他所覆盖的人设立程序，包括凭同侪与凭王国法律审判。它规定一个贵族委员会作为强制执行的手段。它是一场叛乱之内的政治安排。它不是现代国家的宪法，不是给每一个成年人投票权的授予，也不是民主或作为一般身份的自由的诞生。

王国里的多数人不是当事方。维兰大体在后来读者喜爱的那些程序之外。女性没有被给予一种新的政治人格。犹太人——在其出现之处——作为关于债务的条款的对象出现，而不是作为这次和平的作者。一份特许状可以在英格兰政治史上重要，同时仍然是一场贵族的和平。重要性不等于民主的起源。

这份特许状被重新颁布过。本图谱锁定的重新颁布是1225年，在第一次用印之后十年。从1215年6月到1225年，年份数字之差是十。重新颁布仍然是一份在政治之中被挤出来的王室特许状。后来的英格兰法律把1225年的文本当作获得确认的那份《大宪章》。那种法律上的来世是真实的。它没有把1215年的当事方变成一个民主的民族。后来的世纪把诸条款重新解释成一个关于自由的故事。那个重新解释是后来的使用。它不是那次和平曾经是什么。

英诺森三世（Innocent III）是本图谱与1215年一同点名的教皇。他站在贵族特许状的对立面。这个事实是一只有用的拦路石。一位教皇可以取国王的一侧反对贵族。这一年还在11月含有同一名教皇之下的第四次拉特兰公会议。6月与11月不是一个纲领。那个公会议关于服饰与类别的规则在[[christendom/exclusion]]。把特许状与公会议放进一个感伤的“西方的诞生”，就把贵族的限制与公会议的排斥两个都删掉了。

西蒙·德·蒙福尔的1265年议会常常被招募进一个后来的故事，那个故事叫它议会之母。年表自身的纠正立在那里：它是内战之中一场贵族的议会。各共同体的代表被召集，这就是后来的故事留意那次会议的原因。在国王处于贵族的胁迫之下时发出的一份召集令状，不是一部奠基的宪法，也不是英格兰已经成为民主制的证据。爱德华一世的1295年议会是一个不同的政治事实。一位国王召集它，为国王的用途，包括战争的需要。后来的写作者称它为模范议会。“模范”这个词是他们的话。从1265年到1295年是三十年。两场会议，两种局势，一个后来的习惯——把两者都当作一条通往现代代议制之路上的台阶。这个习惯才是要抵制之物。

:::theorem 这些文书不是一部自由的宪法 {#thm-instruments}
1215年6月的《大宪章》、1225年的重新颁布、1265年与1295年的议会，以及1302年的诏书《唯一至圣》，是职位与司法权的文书。它们不是一部自由的宪法，也不是民主的诞生。
:::
:::proof
每件文书都在为特定的人做一份工作。1215年的特许状是一位国王与其贵族之间的和平。1225年的重新颁布仍然是那类文本。1265年的会议是内战之中的贵族政治。1295年的会议是一位国王的议会，后来得了一个“模范”的绰号。《唯一至圣》是一道关于至尊的教皇宣称，不是一部英格兰制定法。一部自由的宪法，如果那个短语意味着给予每个成年人一种政治地位的安排，不是这些文本中任何一部所做的事。

能够构成对这条论断的反证的，是1215年特许状或1225年重新颁布中一个给每个成年人选举权的条款，或者一道1302年的、奠基一部世俗宪法而不是主张教皇司法权的诏书。两者都不是我们手里的文书。一个后来的重新解释可以真诚，而仍然是关于后来的读者的证据，不是关于1215年6月的证据。那张图的图说是同一个论证的缩影：这条线没有把它们变成一部宪法。
:::

:::example 特许状与重新颁布 {#ex-reissue}
1215年6月与1225年在某种意义下都是《大宪章》。两个年份数字之间相隔多少年？为什么重新颁布没有把第一份文本变成一部现代宪法？
:::solution
1225减1215是10。重新颁布表明这份特许状必须在一个后来的政治时刻被重新做成，这是一个会发生于一次和平、而不会发生于一部自我实施的宪法的事。当事方仍然是一位国王与那个能够迫使一位国王的政治共同体，不是成年的居民。十年的确认没有添加任何一个文本都不陈述的民主选举权。[[#thm-instruments]]是这套算术所服务的论断。
:::
:::

:::example 两场会议 {#ex-parliaments}
把1265年放在1295年旁边。两者在关于代议制的故事里后来都被称为议会。什么是相同的，什么不得被压平？
:::solution
两者都是英格兰王国里的会议，两者后来都被赋予奉承的名字：第一个是议会之母，第二个是模范议会。名字是后来的。不得被压平的是政治。1265年是内战之中西蒙·德·蒙福尔的议会。1295年是爱德华一世的议会。年份之差是1295减1265，即30。三十年加上会议召集者的改变，就足以挡住一个“议会”平滑地长成民主制的句子。两场会议都不是《唯一至圣》，都不是沃尔姆斯。
:::
:::

## 一道诏书，然后一次驻跸

《唯一至圣》，1302年，是这个时期另一端的教皇宣称。博尼法斯八世（Boniface VIII）在一场与法兰西的腓力四世（Philip IV of France）的争吵途中颁布了它。以转述、而不作为引用：这道诏书宣称救恩系于罗马教会，宣称顺服罗马的教宗是必要的，宣称世俗权力立于神权之下。诏书里的两剑之像属于那个宣称：两种权力都被说成归属于教皇之下。这是一个关于司法权的句子。它告诉你教皇宣称了什么。它没有告诉你诸王服从了，也没有奠基一个国家。

这道诏书没有了结与法兰西国王的争吵。本图谱没有为随后针对教皇其人的暴力锁定年份，所以这里不发明一个。锁定的是1309年的后续。克雷芒五世开始了教皇长期驻跸阿维尼翁。从1302年到1309年是七年。一个居住在法兰西王国轨道之内的教皇法庭，是一道刚刚宣布每个人间受造者都必须服从罗马教宗的诏书的奇怪纪念碑。这次驻跸不是诏书的胜利。它是关于那个职分坐落在哪里的另一个事实。本章不为驻跸的终结定年。开端已足以阻止1302年被讲述成最后的至尊。

:::example 诏书与驻跸 {#ex-avignon}
《唯一至圣》是1302年。阿维尼翁的驻跸始于1309年。这个空隙是多少年？为什么第二个事件不是第一个的胜利？
:::solution
1309减1302是7。一道关于教皇至尊的诏书之后七年，克雷芒五世在阿维尼翁的驻跸开始。驻跸显示那个职分在一位不同的教皇之下，移入一座法兰西轨道之内的城市。它没有显示腓力四世接受了诏书，也没有显示世俗权力已经被永久地置于从属地位。诏书里的一项宣称与一个居住之地是不同的文书。那张图停在诏书。驻跸是下一个锁定的事实，而它改变了图画。
:::
:::

:::warning 作为起源的卡诺莎与《大宪章》
两个迷思结伴而行。第一个说卡诺莎是教皇对国家的胜利。忏悔是真实的，胜利不是：沃尔姆斯在四十五年之后仍然在为任命讨价还价。第二个说《大宪章》是自由或民主的诞生。它是1215年6月一位国王与其贵族之间的一次和平，在1225年被重新颁布，后来又被人重新解释。一份贵族的特许状不是民主制。把它叫作民主制，是用删除它不曾包括的大多数人来赞美一份文书。
:::

:::quiz
哪一种描述符合本图谱锁定的《大宪章》？
- [ ] 给英格兰每个成年人投票权的那部宪法。
- [ ] 博尼法斯八世使诸王从属于教皇的那道诏书。
- [x] 1215年6月一位国王与其贵族之间的和平，后来被重新颁布、重新解释。
- [ ] 于1122年在各地终结平信徒叙任的那项协约。
:::solution
1215年6月是贵族的和平。1225年的重新颁布使它仍然是政治中的一份王室特许状。《唯一至圣》是1302年，沃尔姆斯是1122年。两者都不是《大宪章》。[[#thm-instruments]]拒绝一个民主的生日。那次和平遗漏的人——包括多数乡村佃户——正是那种奉承的起源故事失败的原因。
:::
:::

:::history 忏悔，然后是协约
格列高利七世于1073年成为教皇。1077年1月，亨利四世在卡诺莎行忏悔礼，而关于任命的冲突没有结束。1122年的《沃尔姆斯协约》把神灵的标记与世俗的权利分开，并且仍然把一位统治者留在一个主教的形成之内。
:::

## 通向何处

[[christendom/crusades]]接过的是一场教皇的布道——1095年11月在克莱蒙——它既不是一部叙任的协约，也不是一份贵族的特许状。[[christendom/exclusion]]停留在1215年11月，那时第四次拉特兰公会议为类别立法，与6月的那次和平同一年，却不是同一个行为。[[christendom/towns-and-learning]]是另一种类型的特权，城市与学术的特权，它同样不是一个中产阶级的宪法。一个论断、一个原因与一个标签的纪律在[[sources/argument]]。一个像“国家的诞生”这样的标签，其起作用的方式正是[[sources/argument]]所说标签起作用的方式：它藏起了它本来必须去证明的那个句子。1265年与1295年的英格兰会议还不是后来几个世纪的诸议会。[[crises/war-and-schism]]是权威在一种不同的张力之下的地方，包括始于1378年的西方大分裂。

:::summary
- 争夺的是职位：任命、属灵权威的标记、世俗的权利，以及对诸王的司法权。
- 1077年1月的卡诺莎是一次忏悔。它不是冲突的终结，也不是对国家的胜利。
- 1122年的《沃尔姆斯协约》把指环与权杖同世俗权产区分开，并且仍然给统治者们留下一个角色。
- 1215年6月的《大宪章》是一场贵族的和平，在1225年重新颁布。它不是民主或自由的诞生。
- 1265年的议会是一场内战的会议。1295年的议会是一场国王的会议。两个绰号都是后来的。
- 1302年的《唯一至圣》宣称教皇的至尊。1309年的阿维尼翁是一次驻跸，不是那个宣称的胜利。
- 一位教皇可以站在国王一边，正如英诺森三世对贵族特许状所做的那样。“教会对国家”太粗糙。
:::

## 习题

:::exercise 忏悔与协约之间的年数 {level=1 check="45"}
卡诺莎与《沃尔姆斯协约》的年份数字之间相隔多少年？（请输入年数。）
:::solution
1122减1077是45。卡诺莎是1077年1月。沃尔姆斯是1122年。这四十五年是“卡诺莎终结了一切”的故事无法吸收的空隙。它们是年份数字之差，不是期间每一场争论的日记。
:::
:::

:::exercise 到重新颁布的年数 {level=1 check="10"}
《大宪章》与本图谱锁定的重新颁布的年份数字之间相隔多少年？（请输入年数。）
:::solution
1225减1215是10。第一份文本是1215年6月。重新颁布是1225年。十年的政治重新颁布没有给特许状遗漏的人选举权，也没有把一场贵族的和平变成一部现代宪法。
:::
:::

:::exercise 从诏书到阿维尼翁的年数 {level=1 check="7"}
《唯一至圣》与教皇驻跸阿维尼翁的开始之间相隔多少年？（请输入年数。）
:::solution
1309减1302是7。诏书是1302年。克雷芒五世于1309年开始驻跸。七年已足以把一项关于至尊的宣称与教皇职分所在之地的改变分开。驻跸不是被服从的诏书。
:::
:::

:::exercise 为什么忏悔不是终结 {level=2}
一名读者说，亨利四世行了忏悔之后，教皇的权威在任命中已经取代了王权的权威。只用1077年与1122年，解释那个句子为什么站不住。不要发明任何一方的引文。
:::solution
1077年1月的忏悔是一位国王的一次和解行为，随后是赦罪。它没有陈述一部任命的新法律。1122年，沃尔姆斯仍然区分指环与权杖和世俗权产，并且按通常的读法，把德意志的统治者留在选举中与世俗权利授予之中。四十五年之后的一次妥协，不是一个王权已被取代的世界。[[#thm-canossa]]说出限度：场面，不是终结。不需要引文。协约的存在与形状就是反证。
:::
:::

:::exercise 和平里缺席的是谁 {level=2}
为什么“《大宪章》奠基了民主制”是一个坏句子，即便它的某些条款限制了国王？说出1215年6月的当事方，以及这次和平不曾变成选民的一个群体。
:::solution
当事方是一位国王与其贵族。这次和平限制若干王室的需索，并为其所覆盖的人规定程序。它没有给每个成年人投票权。维兰尤其没有被一份贵族的特许状变成民主的公民，女性也没有被给予一种新的政治地位。后来的重新解释可以把条款变成一个自由的故事。那种使用是后来的。1225年的重新颁布仍然是政治中的一份王室特许状。[[#thm-instruments]]就是那个拒绝。民主是用于贵族之间一场和平的错误名词。
:::
:::

:::exercise 内战与国王的召集 {level=2}
解释1265年与1295年的会议有何不同，不得把后来的绰号用作证据。包含年份之差。
:::solution
1295减1265是30。1265年，西蒙·德·蒙福尔在内战之中召集一次议会。它是贵族政治，无论召集代表这件事多么值得注意。1295年，爱德华一世为国王的用途召集一次议会。把第一个叫作议会之母，或把第二个叫作模范议会，是添加一个后来的情节。情节不是任何一场会议曾经是什么的史料。三十年与召集者的改变，就是使两者分开的那些事实。两者都不是自由的宪法。
:::
:::

:::exercise 什么会推翻职位的论断 {level=3}
[[#thm-canossa]]与[[#def-office]]说，争夺关乎职位、任命与司法权。什么样的证据会构成反证？为什么一段对亨利四世之受辱的生动记述不足以反驳它？
:::hint
问那些文书本来必须改关于什么：仅仅一次人身侮辱，或者一笔没有主教也没有法庭的税。然后问沃尔姆斯实际区分了什么。
:::
:::solution
如果存世的文书关乎一次人身侮辱或一笔钱的争吵，而从不关乎谁填补一个主教座、哪些标记被交出去、哪座法庭能够审判一位国王，这条论断就会失败。卡诺莎的受辱，无论多么生动，是对一次忏悔的描述。它没有表明任命无关紧要。沃尔姆斯以指环与权杖对世俗权产为轴心，这即便在同时是一场关于权力的争论时，也是关于职位的论证。《唯一至圣》以转述宣称对世俗统治者的司法权。想要击败职位读法的历史学家，必须表明这些区分是装饰性的。那些文本是围绕它们组织的。
:::
:::

:::exercise 关于特许状的一个更窄的句子 {level=3}
有人写下“《大宪章》是民主的诞生”。只用锁定的日期与当事方，说出错误在哪里。然后写一个可以为真的更窄的句子，并说出在重新扩大它之前，你仍然需要在1215年的文本里看到什么。
:::hint
从1215年6月与1225年的重新颁布出发。更窄的句子命名一位国王、贵族们与一次和平。把它朝民主制扩大将需要本章说并不存在的一个条款。
:::
:::solution
那个句子是错的，因为1215年6月是一位国王与其贵族之间的和平，在1225年重新颁布，而不是对每个成年人政治地位的授予。一个可以为真的更窄句子是：1215年6月，一位国王与其贵族缔结了一次限制若干王室需索的和平，并于1225年重新颁布。再次扩大将需要一个给非当事方的人选举权的条款，或一个把国王绑定到一个一般选举团的程序。文本没有做那样。把它当作自由宪章的后来读者，是关于后来的阅读的证据，包括十七世纪向后寻找一部宪法的习惯。它们不是民主在那次和平中诞生的证据。1265年与1295年修复不了那个句子。两者都是一个王国政治的会议，一个在内战之中，一个在爱德华一世之下，两者都不是民主的宪法。
:::
:::
