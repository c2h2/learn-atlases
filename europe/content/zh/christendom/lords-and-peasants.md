一个庄园是什么，农奴身份为什么不是一套制度？一幅熟悉的图画回答得太快。那幅图画说，从大约公元1000年到大约1300年，拉丁基督教世界是一座金字塔：顶端是一位国王，中间是骑士，底部是一个农民——他在每一条山谷里都是同一个人，向同一种领主欠着同样的劳役。这幅图好画，却不可能拿一条记录来检验。领主权很普遍。不自由也很普遍。这两个事实都不能从苏格兰到西西里生出一种法律身份，也都不能生出一个叫作“农民”的人格。

本章紧扣地租、劳役与法庭。它把1066年10月14日的战役和1086年的调查当作一次征服与那次征服的记录来对待，而不是当作一张欧洲的照片。它不会说出中世纪欧洲的人口。本图谱没有锁定这样一个数字，而为填满金字塔底部发明一个总数，只会给一张已经在超负荷工作的图增添虚假的精确。

## 领主权是对租税的权利

这些世纪里的人绝大多数以农业为生。这句话是真的，而且几乎无用。它没有说谁控制土地，土地上欠着什么，这笔义务是以天数、以谷物还是以钱币缴纳，也没有说义务被拒绝时哪座法庭受理争端。这些才是一座庄园使之可以回答的问题。它们是地方性的问题。一处地产上的真话并不免费旅行到下一条山谷，更不必说到另一个王国。[[sources/scale]]正是把地方事实与人们据此搭建的国家叙事分开的章节。这种分离从这里开始，因为农奴身份的那幅漫画恰恰就是这种越界。

领主不是单一的社会类型。领主可以是一位国王、一位俗界贵族、一位主教，或一座修道院。克吕尼（Cluny）创建的通常年代是910年。克吕尼是一座经过改革的修道院，同时也是一个大地主，对远离院址本身的土地与人持有权利。主教可以像俗界佃户持有地产那样持有地产。欠每周劳役（week-work）的农民，并不由于这个事实，就把劳役欠给住在田地边上一座木塔里的骑士。领主是权利的持有者。这些权利可以被购买、给予、争讼和记录，而持有者可以从来都不是那幅漫画所画的人。

封建主义这个词，作为历史学家的捆扎，比作为中世纪的法令更古老。史家们意见不一：这个捆扎是否值得保留。它把从一位上级持有的土地、军役、司法权，以及一套关于忠诚的道德语言捆在一起。这些东西各自都在某些地方存在过。它们没有作为同一个包裹到来，也没有束缚每一个耕作者。大陆的一些地区，有些土地以全自主地（allod）持有，没有任何领主。金字塔无法安放那类土地，除非把它叫作一幅图可以忽略的例外。在帝国里，一些法律上不自由的人充当骑士和管理者。不自由并不是图画底部一个耕作者的同义词。身份与职业是不同的事实。

:::definition 庄园 {#def-manor}
**庄园**是领主权与地租的单位：一位领主对土地与人的租税权利，通常还连同一座审理那些欠租税之人的法庭。它不是一个标准规模的农场，不是作为邻里共同体的村庄，也不是对拉丁基督教世界每一户乡村家庭的描述。
:::

:::definition 不自由 {#def-unfreedom}
在本章，**不自由**指的是一个捆扎，其中可以包括劳役、离开土地的限制、一个人婚姻或继承时的缴纳，以及在领主法庭应讯的义务。这个捆扎不是一种法律身份。一个人可以欠着沉重的劳役，却仍然对不上教科书里的农奴。另一个人可以主要欠钱，却在迁徙上受到限制。在一个调查使用那个更苛刻的标签之处，奴隶制不是这个捆扎里的另一个条目。
:::

这两个定义是刻意谦抑的。它们告诉你在记录里寻找什么。它们不告诉你将会找到什么。一部庄园习惯录（custumal），即一处地产的文字习惯，可能规定在领主直领地（demesne）——领主更直接经营的土地——上劳作的天数。它可能规定钱币。它可能两者都规定，再加上收割助礼（harvest boons）、一笔人在死亡时的缴纳，以及磨坊使用义务（suit of mill）。另一处地产的习惯录可能没有每周劳役而保留法庭。比较那些文书就是这项工作。把它们平均成“每周三天，处处如此”就是那幅漫画。

:::theorem 农奴身份不是一套欧洲制度 {#thm-not-one}
不自由在拉丁基督教世界很普遍，而从苏格兰到西西里，它不是一套法律制度。记录显示出劳役、钱币与司法权的不同配比。一座把国王、领主与单一一种农民码在一起的金字塔是一张图，不是那些记录服从的法律。这条论断没有说多数人自由，也没有给出一个人口。
:::
:::proof
证据是现存记录的形状，不是关于中世纪的一种情绪。调查、特许状与习惯录把义务就地固定。它们指名的租税不能互换：一天劳役不是一个先令，一个先令也不是离开地产的权利。同一个王国的调查对乡村人口使用好几个标签，正如1086年的末日审判调查（Domesday survey）所做的那样，那些标签本身就是反对单一身份的证据。教会领主、全自主地与不自由的骑士，是进一步的证据，表明“领主对农奴”不是乡村权力的全部。

能够构成对这条论断的反证的，是一条成文并且施行的共同规则，它为拉丁基督教世界的乡村人口固定一套劳役与一个身份名称。一表相似不是那条规则。假如我们拥有的每一部习惯录都陈述同样的天数、同样的缴纳与同样的迁徙限制，这条论断就会失败。记录做的不是这个。一个人口总数，即便本图谱锁定了这样一个总数，仍然不会是那条规则。对人的清点不是一部义务的法则。
:::

:::quiz
哪一句话能从[[#thm-not-one]]推出？
- [ ] 拉丁基督教世界的多数乡村人口不受领主支配。
- [ ] 每一处地产每周都欠同样的三天劳役。
- [x] 地租与法庭之间的相似，本身并不是一套法律制度。
- [ ] 本章已经为中世纪欧洲确定了一个人口。
:::solution
这条论断拒绝单一制度。它没有用一个领主消失的故事替换那个制度，也没有偷偷塞进一次普查。相似是承认的。同一不是。人口没有在本图谱中锁定，所以任何需要一个人口数目的句子都不能是这条论断的结论。
:::
:::

## 一座金字塔假装修决了什么

金字塔之所以像一种解释，是因为它用一道阶梯回答“谁发号施令”。这道阶梯藏起了法庭真正会问的问题。对什么发号施令？由谁欠下？在哪里强制执行？劳役被拒绝时可以用钱币追补吗？随地产继承，还是在领主换人时重新评定？一个佃户可以向一位领主佃有土地，却欠另一人的法庭以出庭义务。一座修道院可能持有地租，而一位俗界保护人（advocate）在同一个地方主张另一种权利。在领主主权里，线是交叉的，这是常态。金字塔画它们，仿佛它们已经被梳理整齐。

有一个公平的反对意见。在许多地区，领主收取地租，依附者不能自由走开，某种法庭受理由此产生的争端。如果“农奴身份”只是给那个聚簇命名，那么就有一套制度，而争吵只是关于一个词。我们承认那个聚簇。劳役、限制与司法权常常结伴而行，这正是比较得以可能的原因。一个聚簇仍然不是一部法典。一部法典会固定这个配比：多少天，婚姻是否被征税，这个人能否离开，哪座法庭审理这个诉讼，以及这些答案在约克郡和在西西里是否相同。这个聚簇让我们能够提出那些问题。把它叫作一套欧洲制度，才是关闭它们的那一步。

能够构成对那个回答的反证的，是[[#thm-not-one]]里已经指名的那条共同规则。地方习惯各不相同，若是这个回答为对，这正是我们会预期的。它不是一桩尴尬，需要平均到图形看上去干净为止。庄园、地租与法庭有用，正是因为它们可以被不同的内容填充。

同样的告诫适用于自由。在这些记录里，“自由”常常是一个特定的包裹：免除某些租税的自由，或在公开法庭而不是领主法庭应讯的自由。一个自由的佃户仍然可以欠地租。一个不自由的佃户仍然可以世袭地持有土地。帝国的不自由服役者（ministeriales），不自由而且武装，使那道阶梯显得格外愚蠢。身份是一个法律事实。它不是一级长着同一张脸的横档。

## 末日审判调查是一个王国的事

1066年10月14日，一位诺曼底公爵以战斗夺取了英格兰王国，然后又以安排巩固了它。成为威廉一世（William I）的那个人，并没有因为打赢那场战役就调查了欧洲。1086年，末日审判调查记录了它与继承者所持有的那个王国。从1066年到1086年，年份之差是二十年。这个调查是征服的记录，为一名想要权利与价值被言明的征服者而作。它既不是战役的日记，也不是农民对中间那二十年的记述。

:::widget timeline
start: 1050
end: 1100
window: 5
events: 1066,黑斯廷斯; 1086,末日审判调查
caption: 移动年份。一场战役和二十年之后的一次调查，是征服与征服的记录。调查不是欧洲。
:::

把这张图读作两种类型的事件，而不是读作一次兴起。第一个圆点是一场改变谁持有王国的战役。第二个是一次关于保有、人口与价值的文字查勘。线上的任何一点都不是法兰西、帝国、西西里、苏格兰或斯堪的纳维亚。如果那个窗口引诱你把这里看作一条欧洲的曲线，那份引诱就是错误本身。

这个调查能够支撑的东西有限而坚实。它把乡村人口分进不止一种身份。维兰（villeins）、边农（bordars）、索克曼（sokemen）与奴隶不是同义词，而调查自己使用好几个标签的做法，就是反对单一农奴的证据。索克曼在某些东部巡查区更显眼，却极不适合金字塔的最低一级：他们在领主的司法权之内，却不是与奴隶相同的法律对象。奴隶也在调查里，所以一个持有地产的不自由佃户甚至也不能穷尽1086年的英格兰。本章不把这些类别变成计数。把一个计数用作英格兰的人口就已经是进一步推论，而欧洲的人口是另一个题目。[[sources/evidence]]把史料与推论分开。末日审判调查是为一名统治者而做的调查的算例。

这个调查被建造来记录的变化，主要是领主的变化。这里的征服是一个政治事实，不是一个种族事实。耕作者没有因为一位公爵打赢一场战役而作为一族人被替换。这份文书不许可一个民族清空土地、另一个民族填满土地的故事。它许可的是一个关于保有制度的故事：谁向国王持有，那个保有何估值，哪些租税被主张。即便那个故事也是国王的故事。以镑、先令与便士计的价值，是一个用于评定、用于领主主权之主张的价值。它不是佃户记持的家庭账目。

女性在调查里作为持有者出现，比一座武装男子的金字塔所能预料的更常见；而她们作为劳动者、妻子与未被记录的穷人，从调查里消失。这两个事实都是关于记录的事实。关于一个女人意见的沉默，不是她没有头脑的证据。它是国王的查勘没有询问她的证据。同一条规则适用于那个劳役被列出、而他对领主的判断没有被列出的维兰。我们不会从这份沉默概括出“中世纪的女人”。这份拒绝在[[christendom/exclusion]]里为别的法律继续展开。这里的要点只是：一份庄园调查不是传记。

:::example 从黑斯廷斯到调查 {#ex-span}
黑斯廷斯定年为1066年10月14日。末日审判调查定年为1086年。本图谱把两个公元年份数字之差处理为后者减前者。这个跨度是多少年？不要把它换算成天数。调查的日子没有锁定。
:::solution
用年份数字相减。1086减1066是20。调查在战役之后二十年到来。这二十年是征服与对被征服王国的记录之间的空隙。它们不是说中间的年月空无所有，也不是说这是一个横跨欧洲的跨度。因为调查没有锁定任何一天，一个天数会假装年表并不给予的精确。
:::
:::

:::example 两种虚构的配比 {#ex-rents}
以下庄园是虚构的，地租也是虚构的。它们不是末日审判调查里的条目，也不是任何地方的典型。

虚构的韦斯特菲尔德（Westfield）庄园。一块保有欠三天每周劳役、每年四先令，以及领主法庭的出庭义务。

虚构的伊斯米尔（Eastmere）庄园。同样虚构规模的一块保有欠零天每周劳役，每年十八先令，一个女儿出嫁时的缴纳，以及领主法庭的出庭义务。

伊斯米尔每年在钱币上多欠多少先令？为什么这个差额没有告诉你哪块保有更不自由？
:::solution
十八减四是十四。伊斯米尔每年在钱币上多欠十四先令。这个差额并不度量不自由。韦斯特菲尔德每周欠三天劳役，伊斯米尔不欠。本图谱没有锁定一个能把一天折成先令的工资，所以那些天数和钱币不得加进同一个负担。两块虚构的保有都在领主法庭应讯。一块还在女儿出嫁时缴纳。配比不同。[[#thm-not-one]]就是这些配比所例证的论断。它们只是作为一个算通的逻辑来例证它。一笔虚构的地租不是史料。
:::
:::

:::theorem 一种配比不是一张图 {#thm-mix}
你无法从一张封建社会的总图上读出一座庄园劳役与钱币的配比。虚构的韦斯特菲尔德庄园与伊斯米尔庄园不是任何真实村庄与那些数字相符的证据。它们表明，一张陈述单一配比的图，早已离开了记录。
:::
:::proof
韦斯特菲尔德与伊斯米尔，都在[[#ex-rents]]里标明为虚构，共享一座法庭，而在劳役与钱币上不同。没有一道阶梯能预测你会遇到哪种配比。真实的习惯录还会加上这对虚构庄园有意略去的更多租税：收割助礼、死亡时的缴纳、磨坊使用义务。这些略去让比较保持可读。它们同时表明，即便一对谨慎的虚构庄园也不穷尽。

能够构成对这条论断的反证的，是一部在史家确实能够研究的地产上施行的法律，为这幅图应当适用的每一处固定劳役与钱币的唯一配比。一句重复那幅图的教科书句子不是那部法律。如果末日审判调查，或一连串大陆上的习惯录，陈述同一个完全相同的配比，这个虚构的对照就是一场戏法，这条论断就会失败。调查的多个类别指向相反方向。虚构的数字本身关于1086年什么也证明不了。只有记录能够做那件事。
:::

## 这二十年不是什么

有一种诱惑，把1086年当作英格兰变成一个完成形态的封建秩序的时刻，再把那个时刻输出出去。这个诱惑两次落空。领主主权与依附耕作比黑斯廷斯更古老。调查记录的那个王国早已有地产、租税与法庭；征服改变持有者，并加剧一种特定类型的记录。一个王国里的一个日期不是欧洲的生日。按910年这个通常年代，克吕尼已经是一个修道院地主。从910年到1066年是156年，从910年到1086年是176年。一座十世纪的院宅坐落在地租的历史之内。这两个间隔都不能使1066年成为领主主权本身的起点。

征服确实在顶层改变了英格兰的领主主权。直属封臣（tenants-in-chief）向国王持有。中间领主（mesne lords）向他们持有。那个层级是真实的，而它仍然不是漫画里的金字塔，因为土地上的人不是底层一种法律残渣。自由人与权贵之间一个保有制度的层级，可以与几种农民义务并存。把两者压进同一幅图画，正是一个关于诺曼保有制度的真实记述变成一个关于欧洲农奴身份的虚假记述的方式。

:::example 一句虚构的编年史句子 {#ex-sentence}
下面这句话是虚构的。“在黑斯廷斯之年，欧洲每一个农民每周都欠一位骑士三天劳役。”

要把这句话从一幅例证提升为证据，需要什么？哪一个锁定的史料是错误的引证对象？
:::solution
提升将要求有一条谈论欧洲而不只谈一个王国的记录，把义务定年到1066年而不是把黑斯廷斯用作道德装饰，并且真正调查了农民的劳役而不是统治者的主张。这句话还必须经受第二座配比不是三天的庄园的检验。末日审判调查是错误的引证对象。它是1086年对英格兰王国的调查，在战役之后二十年，为一名征服者而作。它没有说出这句话，而且即便英格兰每一条条目都与虚构的韦斯特菲尔德庄园相符，它也说不出这句话。西西里、苏格兰与帝国都在它之外。
:::
:::

:::example 战役旁边的调查 {#ex-beside}
把1066年10月14日放在1086年旁边。说出这对日期支持的一件事，和两件不支持的事。
:::solution
这对日期支持一个王国之内的政治序列：一次征服，然后，二十年之后，一次为征服者政权做的调查。它不支持对耕作者一族人的种族替换，也不支持任何把整个欧洲作为对象的句子。它同样不支持一个关于农民相信什么的论断。信仰不是国王的专员奉命去问的问题。这两个日期是两种类型的事件。一个罩住两者的窗口不会把它们熔成一个事实。
:::
:::

:::warning 金字塔与千篇一律的农民
通常的迷思是中世纪欧洲是一座由千篇一律的农民构成的封建金字塔，每个人向一位骑士欠同样的劳役。这个迷思之所以失败，是因为庄园是一捆权利而不是一个标准农场，也因为那些捆各不相同。末日审判调查——人们有时冲着迷思挥舞的那份记录——是对一个被征服王国的调查。它不是一部大陆的法律。把金字塔画成一部法令，并不能使它成为一部法令。
:::

同一幅图画还有一层误用。一旦农民是千篇一律的，任何后来的起义都可以被讲成“农民”的觉醒，任何早先的文书都可以被讲成制度已经完成。1381年的英格兰起义属于[[crises/war-and-schism]]，不只有农民参加。从一座庄园到那场起义的道路，不是一套制度在表达自身。地租、劳役与法庭仍然是正确的对象。它们不是一份脚本。

## 一个算例

拿[[#ex-rents]]里虚构的一对来看一句假话如何生长。一名写作者看着韦斯特菲尔德，看见三天，写下“中世纪农民每周欠三天”。仍然虚构的伊斯米尔已经在思想实验内部证伪了这句话：一块保有可以在领主之下，在他的法庭应讯，却不欠每周劳役。写作者随后把句子扩大到“欧洲的农民每周欠三天”。即便每一部真实的英格兰习惯录都与韦斯特菲尔德相符，这第二步也会失败。末日审判调查不是欧洲。对一个王国调查的真实描述，仍然是一块大陆的虚假描述。这就是[[sources/scale]]隔离出来的同一个尺度错误，只是用地的租而不用一个村庄的轶事在这里做一遍。

我们没有把三天折成钱币，也没有说十四先令是轻是重。没有锁定任何价格。两座庄园都是虚构的，所以那句一般句子的失败在任何档案被要求确认之前就已经可见。确认将意味着阅读习惯录，并说出哪些租税确实在文本里。这条论断说的是那些文本被允许不同。它不是那些文本的替代品。

一处真实的保有还将迫在一个虚构的伊斯米尔敞开的口子上做选择：那些天由谁来服，以及一笔婚姻缴纳是否只落在不自由佃户的女儿身上。一笔地租，若没有说明谁来缴纳的那个规则，就还不是一种身份。漫画跳过了那个规则，而规则正是多样性栖身之处。

:::quiz
伊斯米尔比韦斯特菲尔德多欠先令，却不欠每周劳役。两座庄园都是虚构的。由此得出什么？
- [ ] 伊斯米尔更不自由，因为钱币更多。
- [ ] 韦斯特菲尔德不是庄园，因为庄园必须只用钱币缴纳。
- [x] 劳役与钱币可以按不同方式配比，所以一笔地租不定义农奴身份。
- [ ] 数字是精确的，所以它们描述欧洲。
:::solution
精确不能把一幅虚构的例证变成一块大陆的事实。较多的钱币是配比的一部分。缺失的每周劳役是另一部分。[[#def-unfreedom]]允许两种配比。[[#thm-mix]]说一张图不能预先在两者之间做出选择。把韦斯特菲尔德叫作真实样式、把伊斯米尔叫作一桩例外，正是千篇一律的农民重新溜回来的方式。
:::
:::

:::history 一场征服与它的调查
1066年10月14日，一位诺曼底公爵，威廉一世，以战斗夺取英格兰王国，然后又以安排巩固它。1086年的末日审判调查为那个王国的统治者记录它。这里的征服是一个政治事实，不是一个种族事实，而调查不是一幅欧洲的图画。
:::

## 通向何处

[[christendom/popes-and-kings]]从领主的法庭移向教皇与诸王之间一场关于职分的争夺。这里的地租不引起那场争夺，那场争夺也不废除地租。[[christendom/crusades]]是在同一个拉丁基督教世界宣讲的诸场战争，而[[christendom/exclusion]]是后来的一个公会议以服饰标记犹太人与穆斯林之处。一个地方事实如何变成一句虚假的更大句子，在[[sources/scale]]。一次调查的沉默能证明什么、不能证明什么，在[[sources/evidence]]。1381年的英格兰起义，在[[crises/war-and-schism]]，不只有农民参加。[[crises/plague]]是本章拒绝预先编号的那场更晚的灾变。

:::summary
- 庄园是领主权与地租的单位，不是一个标准农场，也不是一个村庄的人格。
- 不自由是劳役、限制、缴纳与法庭的一个捆扎，而这个捆扎有变化。
- 封建金字塔是一张图。它不是一部从苏格兰到西西里的法律。
- 1086年的末日审判调查勘察的是黑斯廷斯（1066年）之后的英格兰王国。它不勘察欧洲。
- 一笔虚构的地租可以展示一种逻辑。只有当一条记录说出它时，它才成为证据。
- 除非一个汇率确实已知，天数与先令不得相加。本图谱一个也没有锁定。
- 调查里的一份沉默，是关于谁被征求意见的证据，不是一个人没有头脑的证据。
:::

## 习题

:::exercise 年份数字之差 {level=1 check="20"}
只用年份数字，1066年与1086年之间相隔多少年？（请输入年数。）
:::solution
1086减1066是20。答案是锁定的年份数字之差，不是天数。黑斯廷斯有一个日子：10月14日。调查的日子没有锁定，所以一个天数就是发明的精确。
:::
:::

:::exercise 虚构一对中的货币差额 {level=1 check="14"}
在[[#ex-rents]]里地租是虚构的。伊斯米尔每年欠十八先令，韦斯特菲尔德欠四先令。伊斯米尔每年多欠多少先令？（请输入先令数。）
:::solution
十八减四是14。这十四先令是一幅虚构例证内部的差额。它们不是末日审判调查的数字，不是工资，也不是哪块保有更不自由的度量。韦斯特菲尔德仍然欠三天每周劳役，而这个减法没有把它折成钱币。
:::
:::

:::exercise 谁的王国的调查 {level=1 check="1086"}
本图谱把对英格兰王国的末日审判调查定在哪一年？（请输入年份。）
:::solution
调查定年为1086年。在它之前的战役是1066年10月14日。1086年不是一个适用于欧洲的日期，也不是领主主权本身的开端。克吕尼，按通常年代910年，早在英格兰这两个日期之前很久就已经是一个地主。
:::
:::

:::exercise 为什么较多的钱币不是答案 {level=2}
一名学生说，伊斯米尔是更不自由的虚构庄园，因为十八先令多于四先令。解释这个错误，不要添加一个工资，也不要把虚构的数字当作一部真实的习惯录。
:::solution
[[#def-unfreedom]]里的不自由是一个捆扎，不是钱币的总和。伊斯米尔多欠先令，却不欠每周劳役。韦斯特菲尔德每周欠三天。没有锁定的汇率能把那些天折成先令，所以“更多钱币”不是“更不自由”。两者都欠出庭义务，而钱币的比较忽略了这一点。数字是虚构的。它们能够规训一个定义。它们不能被引作任何村庄缴纳了什么。
:::
:::

:::exercise 提升一句话 {level=2}
[[#ex-sentence]]里那句虚构的话说，在黑斯廷斯之年，欧洲每一个农民欠一位骑士三天。在这句话能够算作证据之前，一个史料必须是什么、或必须说什么？列出三项不同的条件。然后说明为什么一部英格兰庄园的相符条目仍然不够。
:::solution
那个史料必须关涉欧洲而不是一个王国，必须处理1066年而不是一个更晚的调查，并且必须记录农民的劳役而不是一名统治者的军事胜利。一处真实地欠三天的英格兰庄园，将支持关于那座庄园的一句地方句子。它不支持“每一个农民”，也不支持“欧洲”。即便如此，末日审判调查仍然是错误的文书，因为它是1086年的一个王国。一个地方的真话与一句大陆的句子是不同的尺度。
:::
:::

:::exercise 交错的线 {level=2}
一块保有着租自一座修道院。另一位领主主张佃户必须在那里应讯的那座法庭。为什么这种局面——领主主权常常生产的就是这一类——容不进一座被画成法律的封建金字塔？
:::solution
金字塔给每个人一个位置，在一位上级之下。这里地租与法庭分了家，于是两条线抵达同一块保有。修道院是一位领主，而不必是一名骑士；从910年起的克吕尼那种地主，本来就在提醒：领主是权利的持有者。佃户的不自由，若是那座法庭约束他，与他对修道院或许欠或许不欠的劳役并不相同。[[#thm-mix]]说没有一张图预先选择配比。一旦地租与司法权被允许成为分开的权利，交错的线正是我们会预期的。
:::
:::

:::exercise 什么会推翻这条论断 {level=3}
[[#thm-not-one]]说农奴身份不是一套欧洲制度。哪一类单一证据会构成对那条论断的反证？为什么现代教科书里一幅画得很好的金字塔不够，而三部真实习惯录之间的相似为什么也不够？
:::hint
要找的是一条固定配比的规则，不是一幅断言它的图画。问“一套制度”必须确定什么：天数、缴纳、迁徙，以及法庭。
:::
:::solution
能够推翻的证据，将是一条成文并且从苏格兰到西西里施行的共同规则，为乡村人口固定一套劳役与一个身份名称。教科书里的金字塔是一张现代图形。它不是中世纪的法律，所以不能推翻一个关于法律与习惯是什么的论断。三部彼此相似的习惯录显示的是一个聚簇：地租、限制、一座法庭。[[#thm-not-one]]已经承认聚簇。它只有在配比本身被固定并且共享时才失败——比较不再发现不同的天数、不同的钱币与不同的法庭。相似是探究的开端。一部法典才会是它的终结。
:::
:::

:::exercise 从一个村庄到一块大陆 {level=3}
一个虚构的村庄，叫它洛菲尔德（Lowfield），有一部貌似真实但是虚构的习惯录：佃户欠两天每周劳役。一名写作者下结论说：“欧洲的农民欠两天每周劳役。”只用本章的纪律，解释这个尺度错误。关于洛菲尔德，你能真实地说什么？末日审判调查能添加什么，又不能添加什么？
:::hint
[[sources/scale]]是关于这一类跳跃的本图谱章节。末日审判调查的政治单位是要点，不是第二笔虚构的地租。洛菲尔德是虚构的，所以它连村庄尺度上都不是证据。
:::
:::solution
洛菲尔德是虚构的，所以连那句地方句子也是假设的。尺度错误是从一部习惯录跳到一部大陆的法律。一部真实的洛菲尔德习惯录仍然不许可那个跳跃。末日审判调查只能就1086年的英格兰王国发言，而且只能用它记录的类别。它不能证实一个虚构的村庄，也不能证实欧洲，因为欧洲不是被勘察的单位。洛菲尔德的两天与虚构的韦斯特菲尔德的三天已经彼此不一致。那个不一致正是[[#thm-not-one]]拒绝单一制度的原因。
:::
:::
