如果大学不是中产阶级的诞生，那它是什么？这句恭维掩盖了制度本身。从1215年11月的第四次拉特兰公会议到1291年阿克（Acre）陷落，其间托马斯·阿奎那（Thomas Aquinas）于1274年去世。在这一个世纪里，一些城镇有了宣誓结成的政府，一些商人靠跨越各王国的贸易为生，一些教师和学生组成了享有法律特权的法人团体。这是三个事实，而不是一个正在兴起的阶级，也不是资本主义开始的时刻。

公社（commune）是享有特权、经宣誓结成的城市政府。大学是教师或学生的法人团体，享有组织学业的法律特权。这两种特权都不是现代意义上的中产阶级。本图谱没有为博洛尼亚（Bologna）、巴黎（Paris）或牛津（Oxford）确定创立年份。缺失的生日不是一个可以用整数填上的空格，而是一种有意的拒绝。不借助虚假的开端来讲述这一制度，正是本章的要旨。

## 誓言不等于阶级

这一时期的城镇是人口稠密之地，常有城墙和市场，过去或现在总有某位领主。人口稠密还不等于有了政府。所谓公社，是一群市民宣誓结社，并获得或夺取了在城墙之内审判、征税和管理的权利。领主可以是主教、伯爵或国王；特权可以是授予的，也可以是争来的。誓言界定谁属于这个团体，但并没有让街上的每个成年人都获得公民权。未宣誓的穷人、仆役，以及许多经商或做工的妇女，并不因此就成为公社的一员。意大利城镇后来有时会争论，范围更广的平民（popolo）是否应当分享官职。这种争论是真实的城市政治，却不是一个利益一致、前途相同的阶级的诞生。

官员的称谓各地不同，这种差异本身就提醒我们不要只讲一个故事。一座城市设执政官，另一座城市从外地聘请波德斯塔（podestà），第三座城市则凭借一份王室特许状：这些是持有特权的不同方式。集市、城墙和法庭可以存在于其中任何一种形式之下。但这些事物都不是一个名为“中产阶级”的社会学类型——这个说法把职业、文化和政治捆绑在一起，仿佛它们是同时诞生的。商人可以富有，却仍然彼此分裂；手工业者可以同住一条街，却没有共同的纲领。领主也可以住在城里，却仍然是[[christendom/lords-and-peasants]]意义上的领主，从城镇所消费的乡村收取地租。

:::definition 公社 {#def-commune}
**公社**是享有特权、经宣誓结成的城市政府，通常拥有法庭、市场、一部分征税权，以及作为团体行事的权利。它不是中产阶级，不是拥有普选权的现代市政机构，也不意味着城中的穷人实现了自治。
:::

:::definition 大学 {#def-university}
**大学**是教师或学生的法人团体，被承认享有组织学业、授予执教资格以及作为团体从事法律行为的特权。它不是一座建筑，不是一个生日，也不是“中世纪心灵”。“法人团体”一词并非学校专用，大学只是这种法律形式的一种用法。
:::

提到博洛尼亚，可以说它以法学著称，而且学生在其法人团体中分量非同寻常；提到巴黎，可以说它以神学著称，是教师的法人团体；提到牛津，可以说它是英格兰王国同类学府中的重镇。但这些句子都不是创立日期。如果某本书为其中一所大学的“诞生”给出一个年份，而这个年份不在本图谱的年表中，那么这里就不能使用它，也不要杜撰一个替代。这一制度体现在特权、学科和争执之中，而不在某一声发令枪响。

学科（faculty）是这种形式的一部分，而不是一套统一的课程。文科、神学、法学和医学以不同的组合出现。神学科并不是换了宗教词汇的法学科。学科内部的实践是论辩：提出问题，列出反驳，作出区分，给出答复。正因为有这种实践，一位教师去世并不会使法人团体解散：其他教师继续，学生也继续。分歧正是这一制度运转的方式。

:::theorem 特权不是中产阶级 {#thm-privilege}
公社和大学都是由特定团体持有的特权。它们本身并不创造中产阶级，也不创造资本主义经济。这一论断并不否认商业财富，否认的是人们常常强加给这种财富的那些额外说法。
:::
:::proof
证据在于这些制度的形式。誓言、特许状、执教资格、学科，各自指明一个团体和一项权利。它们都没有指明一个叫作中产阶级的阶级，也都没有阐述一种新的经济制度。在这些城镇，羊毛、布匹、谷物、葡萄酒以及来自更东方的货物的贸易是真实的，信贷与合伙经营也是真实的。本图谱没有确定任何贸易量、价格序列或百分比，因此这里一个也不杜撰。举办市场的特权并不是一套关于雇佣劳动和积累的理论。“资本主义”是一个更晚的词，把这些更进一步的内容捆在一起；在这里使用它，会把特权掩盖在一个标签之下。

能够推翻这一论断的，是一项自称正在创立这样一个阶级的特权，或者一项在本年表中已经确定的、以某所大学的诞生为起点衡量新经济的指标。这样的指标并不存在，可以挂靠它的生日也不存在。市民与学者之间可能发生争执；同一城市里的公社和大学，并不是同一个社会行动者。这种争执本身就是反对把它们捆在一起的日常证据。不能推翻这一论断的，是富商的存在。财富是承认的；阶级和经济制度，则是财富本身迈不出的那几步。
:::

有一种合理的反驳：一些家族确实以商业而非领主权为生，较大城镇的街道也确实日渐稠密。如果我们拒绝使用“中产阶级”，是不是在一个新的社会事实面前为一个词争吵？我们承认商业财富和城市人口密集这两个事实，拒绝的是这个标签附带的额外主张：这种财富构成一个政治立场一致的阶级，它始于某所学校的创立，它就是资本主义。更窄的表述才是诚实的：城镇拥有特权、市场和法人团体。比较研究可以追问谁在誓言之内、谁在誓言之外。那幅漫画跳过了这个问题，因为它早已认定了答案。

:::quiz
哪一句话符合[[#thm-privilege]]？
- [ ] 公社是经宣誓结成的，所以它是现代民主的诞生。
- [ ] 大学缺失的创立年份应当用一个整数补上，好让故事有个开端。
- [x] 经宣誓结成的城镇政府和学者的法人团体是特权，既不是中产阶级，也不是资本主义。
- [ ] 这些城镇里根本不存在商业财富。
:::solution
这一论断拒绝两种拔高：从特权拔高为阶级，从市场拔高为资本主义。它并不否认贸易。缺失的创立年份并不是让你去杜撰一个。誓言界定一个团体，却没有让每个居民都获得公民权，所以它也不是现代民主。
:::
:::

## 三个圆点，外加一个缺席的圆点

:::widget timeline
start: 1200
end: 1300
window: 10
events: 1215,第四次拉特兰公会议; 1274,阿奎那去世; 1291,阿克陷落
caption: 移动年份。一次公会议、一位神学家的去世和阿克的陷落同在一个世纪，但它们不是同一个过程。大学没有圆点，因为本图谱没有确定其创立年份。
:::

这幅图是一个关于哪些东西不该连起来的论证。1215年11月是英诺森三世（Innocent III）主持的第四次拉特兰公会议，与《大宪章》同年，但不是同一件事。[[christendom/popes-and-kings]]把6月的那份和约仍当作贵族的特许状。这次公会议为一个它视为基督教社会的社会立法：既有牧灵规定，也有[[christendom/exclusion]]当作身份类别法律来解读的服饰规定。公会议不是大学，尽管学校生存于教会的法律世界之中。

1274年托马斯·阿奎那去世，是一个人一生的终结，而不是某个过程的完成。1291年阿克陷落，标志着十字军在大陆上各公国的终结，[[christendom/crusades]]已经讲过。从公会议到阿奎那去世是59年：1274减1215是59。从他去世到阿克陷落是17年：1291减1274是17。两段间隔都不是原因。神学家不会因为开了一次公会议而死，港口也不会因为一位神学家去世而陷落。同处一个世纪——这正是时间窗口所显示的全部——并不等于共享一种机制。

大学没有圆点，这一缺席是有意的。在本章中，博洛尼亚、巴黎和牛津是制度，而不是时间线上的事件。把窗口边缘当作创立年份的读者，是把标尺误当成了事实。窗口边缘根本不是事件。不要把它拔高为起源之年，也不要从本年表之外引入一个年份来填补这个空白。

:::example 从公会议到阿奎那去世 {#ex-fifty-nine}
1215年的第四次拉特兰公会议与1274年托马斯·阿奎那去世之间相隔多少年？为什么这段跨度不是一个过程？
:::solution
1274减1215是59。这次公会议为拉丁基督教社会立法，其中包括下一章作为排斥来讨论的规定。阿奎那去世，则是一位多明我会士在论辩实践中走完了一生。五十九年并不使他的去世成为公会议的结果，也没有创立一所大学。图把它们放在同一条线上，是为了让你看到的是距离，而不是熔合。
:::
:::

:::example 从阿奎那去世到港口陷落 {#ex-seventeen}
1274年与1291年阿克陷落之间相隔多少年？把阿克陷落说成阿奎那去世的结果，错在哪里？
:::solution
1291减1274是17。阿克陷落，十字军在大陆上的各公国随之终结。这一军事和政治上的终结，丝毫不能用一位教师的去世来解释。十七个日历年并不承载因果。与东地中海的贸易，不会因为一座港口陷落就在概念上停止；教师的法人团体，也不会因为阿克陷落而解散。这两个圆点在一个世纪尺度的图上是邻居，在解释上却毫不相干。
:::
:::

:::example 一份虚构的授权书 {#ex-grant}
下面这段文字为示例而虚构。“伯爵授予虚构的米尔克罗斯（Millcross）镇的宣誓者每周六举办市场的权利，并准其在自己的法庭中审理该市场的纠纷。这一年，中产阶级诞生了。”

假如第一句出自一份真实的特许状，史家可以从中推断出什么？为什么即便如此，第二句也必须拒绝？
:::solution
假如第一句出自一份真实的特许状，它可以支持一项特权：一个特定的团体、一个市场、一个法庭。它不能支持人口数字，不能支持未宣誓者的看法，也不能支持市场上的价格。第二句并不是特权，而是一个后来的标签，而在本例中，它和这座城镇一样是虚构的。[[#thm-privilege]]指出，市场权利不是一个阶级的诞生。要拔高第二句，需要特许状本身使用这一类别，还需要一份为这一诞生定年的年表，而这两样我们都没有。即使逻辑清楚，米尔克罗斯仍然是虚构的。
:::
:::

## 论辩之中的一生

托马斯·阿奎那于1274年去世。他是多明我会士，属于托钵修士。托钵修士的活动集中在城镇和学校，而不只是在旧式修道院的田庄上。方济各会和多明我会的托钵修士讲道、靠施舍为生，也从事论辩。本图谱没有确定这两个修会的创立年份，因此这里都不给出。确定的事实是他的去世。应把它当作一种实践之中的一生，而不是“中世纪心灵”。并不存在这样一个单一的心灵。在他之前和之后，都有其他教师在论辩；他的一些结论在学校中受到争议。争议不是终结大学的丑闻，而是一个论辩者法人团体的日常工作。本章不会为1274年以后的这些争议定年，因为更晚的年份没有确定。

这种方法很寻常，却值得点明，因为“中世纪心灵”的说法使它隐而不见。先提出问题，再列出反驳，然后作出区分，最后给出答复。亚里士多德（Aristotle）是被评注的权威之一。评注不是抄录，而是在论证这位权威如何与一个基督教神学问题相契合，而这种契合可能失败。想把阿奎那当作他那个世纪之概括的读者，必须无视那些反驳，包括他的同僚在他去世后仍在不断提出的反驳。这个年份标志的是一次死亡，而这种实践并没有随他而去。

:::theorem 去世不等于创立 {#thm-death}
1274年托马斯·阿奎那的去世，为论辩实践中的一个人生定年。它并不为一种欧洲思维方式的诞生定年，也不为一所大学的创立定年。
:::
:::proof
年表确定了他的去世年份，却拒绝为博洛尼亚、巴黎或牛津给出创立年份。这种不对称就是证据：一个人的一生可以定位，而在本图谱中，一个制度的生日却不能。没有生日，学校所显示的仍是一个法人团体：执教资格、学科、论辩。一位教师去世后论辩仍在继续，这正是[[#def-university]]所描述的。要把1274年称为中世纪思想的终结，就需要一份显示论辩已经停止的史料。但论辩并没有停止。

能够推翻这一论断的，是本年表中已确定的、1274年巴黎或牛津的创立特许状，或者一份记录，显示学校把他的去世当作追问的终结。这里没有这样的特许状。不能推翻这一论断的，是他的重要性。一位重要的神学家可以在1274年去世，而不必成为整个文明的象征。重要不等于同一。托钵修士在城镇中的存在，显示了一种城市化的、好论辩的宗教生活，却不能说明欧洲在那一年获得了一颗心灵。
:::

同一个世纪里还有一场既非公社也非学校的征战。1241年，蒙古军队抵达匈牙利和列格尼察（Legnica）。这不是欧洲的终结，蒙古政权也不是拉丁城镇史的一条脚注。无论虚构的还是真实的公社，其周六市场都不能描述列格尼察；列格尼察也不能解释执教资格。[[sources/scale]]给出了这一警示的一般形式。这里的尺度分别是：一座城镇的特权、一位教师的去世、一个王国的战争，以及一次范围更广的入侵。在一个尺度上成立的句子，在另一个尺度上未必成立。从1215年到1241年是26年，从1241年到1274年是33年。这道算术只表明这场征战位于公会议与阿奎那去世之间，并不使它们构成一串因果。

## 商路，不作统计论断

贸易是这些城镇与下一场灾难相关的原因，但这种联系必须说得很窄。人和货物在流动，城镇人口稠密，商路把内陆集市、河港和海洋连接起来。[[crises/plague]]讲到，1347年10月墨西拿（Messina）报告了鼠疫，1348年和1349年鼠疫已遍及西欧大部分地区；人口密度和商路是这一过程的背景之一。本章并不主张贸易引起了鼠疫，只主张一部只有庄园的历史看不见这些路径。这里没有确定市民所占的百分比、集市的规模或船只的总数，所以一个也不列出。

城镇中的妇女并不是单一的法律人格。一些妇女经商，尤其是继续经营作坊的寡妇；一些妇女作为宗教妇女，生活在城市共同体中，这些共同体既不是旧式的封闭修道院，也不是大学。她们的地位因身份、婚姻财产和地方惯例而异，这种差异本身就是事实。[[christendom/exclusion]]在讨论关于服饰和异端的法律时，拒绝“中世纪妇女”这一概括；这种拒绝在讨论市场和学校时就从这里开始。一项提到教师和学生的大学特权，就其自身的措辞而言，基本上是男子的特权。执教资格中对妇女的沉默，证明的是谁被纳入了法人团体，而不是城中妇女没有经济或宗教生活。

托钵修士还带来了另一层联系，不应加以粉饰。为讲堂提供人手的同一场宗教运动，也可以为异端调查提供人手。阿奎那所属的多明我会，后来就有成员被委派执行1231年的教皇程序；[[christendom/exclusion]]描述了这一程序，但不描述审问。1231年早于1274年：1274减1231是43。一套程序和一次去世不是同一件事，但它们确实表明，这个世纪的“学术”并没有远离权力。论辩与司法权可以同处一个托钵修会之中。这是关于制度的事实，既不是事后添上的污点，也不是把托钵修士等同于裁判官的理由。

:::example 两个圆点之间的一场征战 {#ex-mongol}
按年份数字，1241年位于1215年与1274年之间。从公会议到蒙古征战相隔多少年？从这些征战到阿奎那去世又相隔多少年？你不能得出什么结论？
:::solution
1241减1215是26，1274减1241是33。这些征战抵达匈牙利和列格尼察，但不是欧洲的终结。你不能得出结论说：公会议引发了这些征战，这些征战导致了一位神学家的去世，或者某个公社的市场特权能描述其中任何一件事。这两道算术只是把第三类事件放在图上两个圆点之间。尺度仍然保持分开。军队规模不是答案的一部分。
:::
:::

:::warning 生日与阶级
两个迷思相互弥补。一个给巴黎、博洛尼亚或牛津加上本年表没有确定的创立年份，好让学术有一个开端；另一个把这个开端称为中产阶级的诞生，或资本主义的诞生，或现代心灵的诞生。描述一个法人团体并不需要这样的生日，而特权也不是阶级。阿克陷落和一位神学家的去世同处图上的一个世纪，却没有共同的原因。为大学添上一个杜撰的年份，会让图看起来更完整，却让历史更不真实。
:::

博洛尼亚、巴黎和牛津可以提及，它们的创立年份却不能给出。[[#thm-death]]把1274年的去世与任何创立区分开来。图注说明这一缺席是有意的。把标尺当作事件，就是杜撰一个年份。公社和大学都算某种法人团体，但并不是同一个团体，所以它们之间才会发生争执。

:::history 一次公会议、一次去世、一座港口
1215年11月，英诺森三世主持的第四次拉特兰公会议为拉丁基督教社会立法。托马斯·阿奎那于1274年去世，这是论辩实践中的一个日期，而不是中世纪心灵的写照。1291年，阿克陷落。三者同在一个世纪，却没有共同的原因。
:::

## 通向何处

[[christendom/exclusion]]把1215年11月的公会议解读为标记犹太人和穆斯林、并建立针对异端之程序的法律，而不是一所学校的诞生。[[crises/plague]]讲的是人口密度和商路如何遭遇一场本章未给出数字的灾难。[[crises/year-1492]]讲的是后来的一系列终结与驱逐，而不是公社的意义。[[christendom/crusades]]已经说明1291年终结了什么、又没有终结什么。[[sources/scale]]是让列格尼察、市场和学科各自留在不同句子里的方法。“城镇的兴起”这类标签，正如[[sources/argument]]所说的标签那样运作：它把关于特权的论断和关于阶级的论断捆在一起，再把接缝藏起来。

:::summary
- 公社是享有特权、经宣誓结成的城市政府，不是中产阶级，也不是普选的选民群体。
- 大学是教师或学生的法人团体，拥有授予执教资格的特权。本章提及博洛尼亚、巴黎和牛津，但不给出创立年份。
- 图上没有大学的圆点，因为本图谱没有确定其生日。窗口边缘不是事件。
- 1215年11月、1274年阿奎那去世和1291年阿克陷落同在一个世纪，却没有共同的原因。间隔依次是59年和17年。
- 阿奎那的去世为论辩之中的一个人生定年，而不为“中世纪心灵”定年。论辩仍在继续。
- 托钵修士属于城镇和学校。两个修会的创立年份都没有确定。1231年的程序不是1274年的去世。
- 贸易和人口密度对后来的鼠疫有意义，但这里不作统计论断，也不用“资本主义”一词。
- 1241年，蒙古征战抵达匈牙利和列格尼察。这既不是欧洲的终结，也不是某座城镇的特许状。
:::

## 习题

:::exercise 从公会议到阿奎那去世的年数 {level=1 check="59"}
1215年与1274年之间相隔多少年？（请输入年数。）
:::solution
1274减1215是59。第一个年份是第四次拉特兰公会议，第二个是托马斯·阿奎那去世。这段跨度不是一个过程，也不是某所大学的创立年份。
:::
:::

:::exercise 从阿奎那去世到阿克陷落的年数 {level=1 check="17"}
托马斯·阿奎那去世与阿克陷落之间相隔多少年？（请输入年数。）
:::solution
1291减1274是17。阿克陷落终结了十字军在大陆上的各公国，但它不是阿奎那去世的结果。十七年并不能把因果从一所学校传到一座港口。
:::
:::

:::exercise 阿奎那的确定年份 {level=1 check="1274"}
本图谱把托马斯·阿奎那的去世定在哪一年？（请输入年份。）
:::solution
1274年。这个年份标定的是论辩实践中的一次去世，而不是巴黎、博洛尼亚或牛津的创立，也不是中世纪心灵的诞生。图上标出了他的去世，却没有给大学一个圆点。
:::
:::

:::exercise 谁在誓言之外 {level=2}
一个公社经宣誓结成，拥有法庭和市场。为什么这还不是中产阶级？城中哪些人并不仅凭这一誓言就被包括在内？
:::solution
[[#def-commune]]把公社界定为一个享有特权的特定团体。誓言包括的是宣誓者，而不是每个居民。未宣誓的穷人、仆役，以及许多在城中劳作的妇女，不会因为别人宣了誓就成为治理者。富商也不会仅仅因为富有就构成一个政治阶级。[[#thm-privilege]]承认财富，拒绝阶级之说。后来关于扩大参与范围的争执，是进一步的城市政治，而不能证明最初的誓言就已造就了一个现代的人民。
:::
:::

:::exercise 米尔克罗斯能支持什么 {level=2}
根据[[#ex-grant]]中那份虚构的授权书，列出一份同样格式的真实特许状能够支持的两件事，以及即使米尔克罗斯真实存在也不能支持的两件事。授权书的第二句仍须拒绝。
:::solution
一份真实的特许状可以支持一个特定的宣誓团体，以及举办市场和设立市场法庭的特权。它不能支持这座城镇的人口数字，也不能支持未宣誓者的看法。关于中产阶级诞生的那句话仍然只是一个标签，而不是授权书的条款。价格、交易量以及与资本主义的比较都不在文本之中。米尔克罗斯是虚构的，所以在真实的特许状载明之前，连这项特权也只是推演的逻辑。
:::
:::

:::exercise 列格尼察不是学科 {level=2}
1241年，蒙古征战抵达匈牙利和列格尼察。一个学生说，这表明城市化的欧洲被摧毁了，因此大学一定是在此之后才创立的。请在不杜撰创立年份和军队规模的前提下，纠正其中的尺度错误。
:::solution
这些征战不是欧洲的终结，蒙古政权也不是一条脚注。它们与公社的特权、与执教资格属于不同的尺度。年表并没有说“城市化的欧洲”被摧毁了。无论在1241年之前还是之后，大学都没有确定的创立年份。从1241年到1274年是33年，这只是把阿奎那的去世放在征战之后，并不使这次去世成为一次重建。[[sources/scale]]是一般原则。军队规模无从得知，所以不为了让句子显得精确而添加任何数字。
:::
:::

:::exercise 窗口不是生日 {level=3}
一位读者说，某所著名学府一定创立于本章图的窗口边缘，否则时间线本来会把它标出来。请指出这一错误。关于博洛尼亚、巴黎和牛津，你可以说什么？又必须拒绝哪种说法？
:::hint
图注已经说明了为什么没有圆点。回答中不要补上创立年份。窗口边缘是标尺，而不是事件。
:::
:::solution
图的窗口是一种选定的标尺，为的是让1215年、1274年和1291年能够同时看到。它的边缘既不是事件，也不是创立。图注说明，大学没有圆点，是因为本图谱没有确定创立年份。你可以说，博洛尼亚、巴黎和牛津是学生或教师的法人团体，享有组织学业和授予执教资格的特权，而且学生或教师在其中的分量各有不同。你必须拒绝任何“这所学校创立于某年”的句子。为填补圆点而杜撰年份，会让图看起来完整，却让年表显得草率。[[#thm-death]]只允许把1274年当作一次去世。
:::
:::

:::exercise 什么能推翻特权论断 {level=3}
[[#thm-privilege]]认为，公社和大学本身并不创造中产阶级或资本主义。什么证据能够推翻这一论断？为什么一个富商家族的真实记载并不足够？
:::hint
去找一份把这个阶级当作自身类别来使用的文本，或者一项本年表本应确定的指标。论证中已经承认了财富。
:::
:::solution
如果某项特权声称自己正在创立中产阶级，或者本年表确定了一项以这些法人团体为起点的新经济制度的指标，这一论断就会站不住。一份只授予市场和法庭的特许状并没有这样说，虚构的米尔克罗斯授权书前后两句之间的落差正说明了这一点。一个富商家族显示的是商业财富，而这一论断承认这一点。财富还不是一种统一的政治立场，不是大学的宗旨，也还不是资本主义。市民与学者之间的争执指向相反的方向：这些团体可能彼此冲突。同样不能推翻这一论断的，是从本图谱之外引入的创立年份。一个杜撰的生日，承载不了这个生日本身并未记录的经济制度。
:::
:::
