大学若不是中产阶级的诞生，又是什么？这句恭维藏起了那个制度。从1215年11月的第四次拉特兰公会议到1291年阿克的陷落——其间托马斯·阿奎那（Thomas Aquinas）于1274年死去——的那一个世纪里，一些城镇有过宣誓的治理，一些商人跨越诸王国靠贸易为生，一些教师与学生组成了持有法律特权的法人团体。那是三个事实。它们不是一个兴起的阶级，也不是资本主义开始的时刻。

公社（commune）是一套宣誓的城市治理，持有特权。大学是一个教师、或学生的法人团体，持有组织学业的法律特权。两种特权都不是现代的中产阶级。本图谱没有为博洛尼亚（Bologna）、巴黎（Paris）或牛津（Oxford）锁定创始年份。那个缺席的生日不是一格要用一个整数去填的空白。它是一次拒绝。不带假开端地讲述这个制度，正是本章的要害。

## 一道誓言不是一个阶级

这个时期的一座城镇是一个稠密之地，常常有城墙，有一座市场，有一位领主坐落在它的过去或现在的某处。稠密还不是一个治理。公社是这样的事情：一群市民宣誓结社，取得——或夺到手——在城墙之内裁判、征税与管治的权利。领主可以是一位主教、一位伯爵或一位国王。特权可以被授予，也可以被榨出。誓言界定谁在这个团体之内。它没有给街上每一个成年人选举权。未宣誓的穷人、仆役，以及许多贸易或做工的妇女，并不因此就是那个公社。意大利的诸城镇后来有时争夺更宽泛的平民（popolo）是否应当分享诸职位。那场争夺是真实的城市政治。它不是一个只有一个利益、一个未来的阶级之诞生。

官员的称呼各地不同，这种多样本身就是一个警告，警告人们别去讲一个故事。一座城市里是执政官，另一座里是从外地请来的波德斯塔（podestà），第三座里是一份王室特许状：这些是持有一项特权的不同方式。一座集市、一道城墙与一座法庭可以坐落在其中任何一种之内。那些物件没有一个是一个叫作中产阶级的社会学类型，而那个短语把职业、文化与政治捆在一起，仿佛它们与生俱来是一体降生的。商人可以富有，而仍然彼此分裂。手艺人可以同一条街，而不同一个纲领。一位领主可以住在一座城镇里，而仍然是一位领主，就[[christendom/lords-and-peasants]]那个词的意义而言，从这座城镇所供养的乡村抽取地租。

:::definition 公社 {#def-commune}
**公社**是一套持有特权的宣誓城市治理：通常是一座法庭、一座市场、一份征税的份额，以及作为一个团体行动的权利。它不是一个中产阶级，不是一个带普遍选举权的现代市政体，也不是一个说这座城镇的穷人治理了他们自己的宣称。
:::

:::definition 大学 {#def-university}
**大学**是一个教师、或学生的法人团体，被承认识持有如下法律特权：组织学业、授予执教许可，以及作为一个团体在法律上行动。它不是一座建筑，不是一个生日，也不是中世纪的心灵。法人这个词并不为诸学校专享。大学是那种法律形式的一种用途。
:::

博洛尼亚可以为法律点名，也为学生握有非同寻常分量的一个法人团体点名。巴黎可以为神学点名，也为教师们的一个法人团体点名。牛津可以作为英格兰王国同类型的大学校点名。那些句子没有一句是一个创始日期。如果一本书为其中之一的“诞生”提供一个年份，而那个年份不在本图谱的年表里，那个年份在这里就不可用。不要发明一个替代品。这个制度可以在特权、学院与争吵中看见，不在发令枪里。

诸学院是这个形态的一部分，而不是一套课程。文学院、神学院、法学院与医学院以不同的组合出现。一个神学院不是一个换上宗教词汇的法学院。其中的实践是辩论：一个问题，若干质疑，若干区分，一项答复。正是这个实践，使一位教师的死不能关闭这个法人团体。别的教师继续。学生继续。分歧就是制度在运转。

:::theorem 特权不是中产阶级 {#thm-privilege}
一个公社与一个大学是一个界定团体持有的特权。它们单凭自身不创造一个中产阶级，也不创造一种资本主义经济。这条论断没有否认商业财富。它否认的是那份财富常常被要求背负的额外句子。
:::
:::proof
证据是诸制度的形态。一道誓言，一份特许状，一项执教许可，一个学院：每一个都点出一个团体与一项权利。它们没有一个点出一个叫作中产阶级的阶级，也没有一个陈述一种新的经济制度。羊毛、布匹、谷物、葡萄酒与更远东而来的货物的贸易在这些城镇是真实的。信贷与合伙是真实的。本图谱没有锁定任何数量、任何价格序列与任何百分比，所以一个也不发明。举办一座市场的特权，不是雇佣劳动与积累的理论。资本主义作为一个更晚的词，把那些更远的东西捆在一起。在这里使用它，会把那个特权藏在一个标签之下。

能够构成对这条论断的反证的，是一项宣称自己正在创建这样一个阶级的特权，或一个在本图谱年表里锁定的、以一所大学的生日为新经济起点的度量。没有这样一个度量，也没有这样一个可供它挂靠的生日。城市与学院可以争吵。同一座城市里的一个公社与一个大学不是一个社会行动者。那场争吵是反对那个捆扎的日常证据。不能构成对这条论断的反证的，是富裕商人的存在。财富是被承认的。阶级与经济制度，是财富单凭自身迈不出的那几步。
:::

有一个公平的反对意见。一些家族确实靠商业而非领主权为生，较大城镇的街道确实变密了。如果我们拒绝“中产阶级”，我们是不是在一个新的社会事实站到眼前的当口，为一个词争吵？我们承认商业财富与城市密度这两个事实。我们拒绝那个标签的额外宣称：这份财富是一个带一个政治的阶级，它始于一所学校的奠基，它就是资本主义。一个更窄的句子才是诚实的。城镇有特权、市场与法人团体。比较可以追问谁在那个誓言之内，谁在之外。那幅漫画跳过那个问题，因为那幅漫画早已知道答案。

:::quiz
哪一句话符合[[#thm-privilege]]？
- [ ] 公社是现代民主的诞生，因为它是宣誓的。
- [ ] 大学缺席的创始年份应当用一个整数填上，好让故事能够开始。
- [x] 一个宣誓的城镇治理与一个学者们的法人团体是特权，不是中产阶级，也不是资本主义。
- [ ] 商业财富在这些城镇根本不存在。
:::solution
这条论断拒绝两次提升：从一项特权到一个阶级，从一座市场到资本主义。它不否认贸易。一个缺席的创始年份不是邀请你去发明一个。一道誓言界定一个团体。它没有给每一个居民选举权，所以它也不是现代民主。
:::
:::

## 三个圆点，与一个缺席的

:::widget timeline
start: 1200
end: 1300
window: 10
events: 1215,第四次拉特兰; 1274,阿奎那之死; 1291,阿克陷落
caption: 移动年份。一个公会议、一位神学家的死与阿克的陷落共享一个世纪。它们不是一个过程。大学没有一个圆点，因为本图谱没有锁定一个创始年份。
:::

这张图是一个关于什么不该连线的论证。1215年11月是英诺森三世（Innocent III）之下的第四次拉特兰公会议，与《大宪章》同年，却不是同一个行为。[[christendom/popes-and-kings]]把6月的和平保有为一份贵族的特许状。那个公会议为一个它当作基督教的社会立法：牧养的规则，以及[[christendom/exclusion]]读作关于范畴之法律的服饰规则。公会议不是大学，尽管诸学校生活在教会的法律世界之下。

托马斯·阿奎那在1274年的死是一生的终结，不是一个过程的完成。阿克在1291年是大陆上十字军诸公国的终结，[[christendom/crusades]]已经讲过。从公会议到死亡是59年。1274减1215是59。从死亡到阿克是17年。1291减1274是17。两个空隙都不是原因。神学家不会因为一个公会议召开而死，一座港口也不会因为一位神学家死去而陷落。共享一个世纪——那已经是这个窗口显示的全部——不是共享一个机制。

大学没有一个圆点。那种缺席是刻意的。博洛尼亚、巴黎与牛津在本章是制度，不是线上的事件。把窗口的边缘当作创始的读者，是把一个标尺误当成了一个事实。那个边缘根本不是一个事件。不要把它提升为一个起源之年，也不要从这份年表之外输入一个年份来治愈这个空白。

:::example 从公会议到死亡 {#ex-fifty-nine}
1215年的第四次拉特兰公会议与1274年托马斯·阿奎那的死之间相隔多少年？为什么那段跨度不是一个过程？
:::solution
1274减1215是59。那个公会议为拉丁基督教社会立法，包括下一章作为排斥来处理的规则。那场死是一位多明我会士的一生终结于一种辩论的实践之内。五十九年没有使那场死成为那个公会议的结果，也没有奠基一所大学。那张图把它们放在同一条线上，好让你看见的是距离，不是一个熔合。
:::
:::

:::example 从死亡到港口 {#ex-seventeen}
1274年与1291年阿克的陷落之间相隔多少年？把那次陷落称为那场死的结果，会有什么不对？
:::solution
1291减1274是17。阿克陷落，大陆上的十字军诸公国终结。那个军事与政治的终结之中，没有任何东西由一位教师的死来解释。十七个历法年份携带不了一个原因。与东地中海的贸易不会因为一座港口陷落就在观念上停止，一个教师们的法人团体也不会因为阿克陷落就解散。那两个圆点在一个世纪尺度的图上是邻人，作为解释却是陌路人。
:::
:::

:::example 一份发明的授予 {#ex-grant}
下面这句话为示例而虚构。它不是史料。“伯爵授予虚构的米尔克罗斯（Millcross）镇的宣誓之民举办一座周六市场的权利，并在此他们自己的法庭里裁判那座市场的争端。就在这一年，中产阶级诞生了。”

如果第一句是一份真实的特许状，一位史家能从它推断出什么，而为什么连那时候第二句也必须被拒绝？
:::solution
如果第一句是一份真实的特许状，它会支撑一项特权：一个界定的团体，一座市场，一座法庭。它不会支撑一个人口，不会支撑未宣誓者的意见，也不会支撑市场里的价格。第二句不是特权。它是一个更晚的标签，而在本例里，它连同那座城镇一起是虚构的。[[#thm-privilege]]说一项市场权利不是一个阶级之诞生。提升第二句，将要求那份特许状使用那个范畴，并要求一份为那个诞生定年的年表。两者我们都没有。米尔克罗斯即使逻辑清楚，也仍然是虚构的。
:::
:::

## 辩论之中的一生

托马斯·阿奎那死于1274年。他是一名多明我会士，属于那些托钵修士：他们的劳作坐落在城市与诸学校之中，而不只在一种更古老修道院的地产之上。托钵修士——方济各会与多明我会——宣讲、以托钵为生、辩论。本图谱没有为这两个修会中的任何一个锁定创始年份，所以一个也不说。锁定的事实是那场死。把它用作一种实践之内的一生，而不是中世纪的心灵。不存在那样一颗单一的心灵。别的教师在他之前辩论，也在他之后辩论。他的一些结论在诸学校中被争论。争辩不是终结大学的丑闻。它是一个辩者们的法人团体的日常劳作。本章不会把那些争辩定年到1274年之后，因为更晚的年份没有锁定。

那个方法是寻常的，而值得说出，因为“中世纪的心灵”使它不可见。一个问题被提出。若干质疑被列出。若干区分被作出。一项答复被给出。亚里士多德（Aristotle）在所注释的诸权威之中。注释不是一份摹本。它是一场关于那个权威如何安放进一个基督教神学问题的辩论，而安放可能失败。一个要把阿奎那读成他的世纪的摘要的读者，必须无视那些质疑，包括那些他的同侪在那场死之后仍然不断提出的质疑。那个年份是一场死。那个实践没有随他死去。

:::theorem 一场死不是一个创始 {#thm-death}
托马斯·阿奎那在1274年的死，为一个在辩论的实践之内的一生定年。它没有为一种欧洲的思维方式的诞生定年，也没有为一所大学的创始定年。
:::
:::proof
这份年表锁定了那场死，而拒绝为博洛尼亚、巴黎或牛津锁定一个创始年份。那不对称就是证据。一生可以被安放。一个制度的生日，在本图谱里，不能。诸学校在没有生日的情况下显示的，是一个法人团体：执教许可、学院、辩论。辩论在一位教师死后继续，这正是[[#def-university]]所描述的。把1274年叫作中世纪思想的终结，将需要一条辩论停止了的史料。辩论没有停止。

能够构成对这条论断的反证的，是一份在本图谱这份年表里锁定的、为1274年的巴黎或牛津的创始特许状，或者一条诸学校把它的死当作追问之终结来对待的记录。这里没有这样一份特许状。不能构成对这条论断的反证的，是他的重要性。一位重要的神学家可以在1274年死去，而不成为一整个文明的象征。重要性不是同一性。托钵修士在城镇中的在场，显示了一种城市的、好辩论的宗教生活。它没有显示欧洲在那一年获得了一颗心灵。
:::

同一个世纪还含有一场既不是公社也不是学校的征战。1241年，蒙古军队抵达匈牙利与列格尼察（Legnica）。它们不是欧洲的终结，蒙古政治体也不是拉丁诸城镇的一条脚注。一个虚构的或真实的公社里的一场周六市场描述不了列格尼察。列格尼察也解释不了执教许可。[[sources/scale]]是这个警告的一般形式。这里的诸尺度是：一座城镇的特权，一位教师的死，一个王国的战争，以及一次更宽广的闯入。在一个尺度上为真的句子，在下一个尺度上不是为真的句子。从1215年到1241年是26年，从1241年到1274年是33年。这道算术只显示那场征战坐落在公会议与死亡之间。它没有使它们成为一个原因的序列。

## 路线，不带统计论断

贸易是这些城镇对下一场灾变要紧的原因，而那个联系必须收窄地说。人与货物在移动。城镇是稠密的。路线把内陆集市、河港与海洋连接起来。当[[crises/plague]]讲述鼠疫于1347年10月在墨西拿（Messina）被报告、并在1348年与1349年已在西欧的大部分地区时，密度与路线就是背景的一部分。本章没有宣称贸易引起了鼠疫。它宣称的只是：一部只有庄园的历史看不见那些道路。没有锁定任何市民的百分比、任何集市的规模与任何船只的总数，所以一个也不印出。

城镇中的妇女不是一个单一的法律人格。一些妇女经商，尤其作为延续一间作坊的寡妇。一些妇女作为过宗教生活的妇女，生活在既非旧式围院修道院、亦非大学的城市共同体里。她们的地位因身份、婚姻财产与地方习惯而不同。那个多样就是事实。[[christendom/exclusion]]在关于服饰与异端的法律上拒绝“中世纪的女人”这个概括。这种拒绝从这里开始，为市场与学校而开始。一项谈到教师与学生的大学特权，就它自己的声音而言，多半是一项男子的特权。执教许可之中对妇女的沉默，是关于谁被纳入法人的证据，不是关于城镇中的妇女没有经济或宗教生活的证据。

托钵修士造成一个进一步的联系，而它不该被打扮。给讲堂输送人员的同一场宗教运动，也能给对异端的查究输送人员。多明我会——阿奎那的修会——后来名列受委任于1231年教皇程序之人之中，[[christendom/exclusion]]描述那个程序，而不描述讯问。1231年在1274年之前。1274减1231是43。一套程序与一场死不是同一个事件。它们确实显示：本世纪的“学术”不是一场脱离权力的度假。辩论与司法权可以坐落在同一个托钵修会之中。那是一个关于诸制度的事实，不是事后添加的一块污斑，也不是把一个托钵修士坍缩成一个裁判官的理由。

:::example 两个圆点之间的一场征战 {#ex-mongol}
就年份数字而言，1241坐在1215与1274之间。从公会议到蒙古诸战役有多少年，从那些战役到阿奎那的死又有多少年？你不得得出什么？
:::solution
1241减1215是26。1274减1241是33。诸战役抵达匈牙利与列格尼察。它们不是欧洲的终结。你不得得出那个公会议引起了诸战役，或诸战役引起了一位神学家的死，或一座公社的市场特权描述了两者中任何一个。这两道加法只是把第三种类型的事件安放在那张图的两个圆点之间。尺度保持不坍缩。任何军队规模都不是答案的一部分。
:::
:::

:::warning 那个生日与那个阶级
两个迷思互相修补。一个为巴黎、博洛尼亚或牛津加上一个本图谱没有锁定的创始年份，好让学术可以有一个开端。另一个把那个开端叫作中产阶级的诞生，或资本主义的诞生，或一颗现代心灵的诞生。一个法人团体被描述并不需要这样一个生日，而一项特权不是一个阶级。阿克的陷落与一位神学家的死共享那张图的世纪，而不共享一个原因。为一所大学加上一个发明的年份，会让那张图看上去更完整，让历史看上去更不真。
:::

:::solution
博洛尼亚、巴黎与牛津可以被点名。它们的创始年份不能。[[#thm-death]]把1274年的那场死与任何创始分开。那张图的图说说那种缺席是刻意的。把一个标尺当作一个事件，就是发明一个年份。公社与大学都是某种法人团体，但它们不是同一个团体，这正是它们能够争吵的原因。
:::
:::

:::history 一个公会议，一桩死亡，一座港口
1215年11月，英诺森三世之下的第四次拉特兰公会议为拉丁基督教社会立法。托马斯·阿奎那死于1274年，那是一个在辩论的实践之内的日期，不是中世纪心灵的一幅肖像。阿克陷落，在1291年。三者共享一个世纪，不共享一个原因。
:::

## 通向何处

[[christendom/exclusion]]把1215年11月的那个公会议读作标记犹太人与穆斯林、并建造一个针对异端之程序的法律，而不是读作一所学校的诞生。[[crises/plague]]是密度与路线遭遇一场本章没有加过数字的灾变的地方。[[crises/year-1492]]是更晚的一组终结与驱逐，不是一个公社的意义。[[christendom/crusades]]已经说过1291年终结了什么，又没有终结什么。[[sources/scale]]是让列格尼察、一座市场与一个学院留在不同句子里的那个纪律。一个像“诸城镇的兴起”这样的标签，其起作用的方式正是[[sources/argument]]所说标签起作用的方式：它把一个关于特权的论断与一个关于阶级的论断捆在一起，然后把接缝藏起来。

:::summary
- 公社是一套持有特权的宣誓城市治理，不是一个中产阶级，也不是一个普遍选民团。
- 大学是一个教师或学生的法人团体，持有执教许可。博洛尼亚、巴黎与牛津被点名而没有创始年份。
- 那张图没有大学的圆点，因为本图谱没有锁定一个生日。窗口的边缘不是一个事件。
- 1215年11月、阿奎那在1274年的死、以及1291年的阿克，共享一个世纪而不共享一个原因。空隙是59年，然后是17年。
- 阿奎那的死为一个在辩论之内的一生定年。它没有为中世纪的心灵定年。辩论继续。
- 托钵修士属于城镇与诸学校。没有为诸修会锁定创始年份。1231年的一套程序不是1274年的那场死。
- 贸易与密度更晚对鼠疫要紧，不带统计论断，也不用资本主义这个词。
- 1241年蒙古诸战役抵达匈牙利与列格尼察。它们不是欧洲的终结，也不是一座城镇的特许状。
:::

## 习题

:::exercise 从公会议到死亡的年数 {level=1 check="59"}
1215年与1274年之间相隔多少年？（请输入年数。）
:::solution
1274减1215是59。第一个年份是第四次拉特兰公会议。第二个是托马斯·阿奎那的死。这段跨度不是一个过程，也不是一个大学的创始年份。
:::
:::

:::exercise 从死亡到阿克的年数 {level=1 check="17"}
托马斯·阿奎那的死与阿克的陷落之间相隔多少年？（请输入年数。）
:::solution
1291减1274是17。阿克的陷落终结了大陆上的十字军诸公国。它不是那场死的结果。十七年不从一所学校向一座港口传递一个原因。
:::
:::

:::exercise 阿奎那的锁定年份 {level=1 check="1274"}
本图谱把托马斯·阿奎那的死定在哪一年？（请输入年份。）
:::solution
1274。那个年份为一个在辩论的实践之内的一生定年。它没有为巴黎、博洛尼亚或牛津的创始定年，也没有为中世纪的心灵的诞生定年。那张图标记那场死，而让大学没有一个圆点。
:::
:::

:::exercise 谁在誓言之外 {level=2}
一个公社是宣誓的，持有一座法庭与一座市场。为什么那还不是一个中产阶级，而城镇里的谁并不单凭那道誓言就被包括进来？
:::solution
[[#def-commune]]把公社做成一个持有特权的界定团体。誓言包括宣誓的人，不是每一个居民。未宣誓的穷人、仆役，以及许多在城镇中劳作的妇女，不会因为别人的誓言而被变成治理者。富裕的商人不会因为富裕就是一个政治阶级。[[#thm-privilege]]承认那份财富，而拒绝那个阶级。一场更晚的、关于更宽参与的争夺将是进一步的城市政治，不是第一道誓言已经是一个现代人民的证明。
:::
:::

:::exercise 米尔克罗斯能支撑什么 {level=2}
用[[#ex-grant]]里那份虚构的授予，列出一份同形的真实特许状能够支撑的两件事，以及即使米尔克罗斯是真实的它也不能支撑的两件事。授予的第二句须保持被拒绝。
:::solution
一份真实的特许状能够支撑一个界定的宣誓团体，以及一座市场与一座市场法庭的特权。它不能支撑这座城镇的一个人口，也不能支撑没有宣誓的人们的意见。关于中产阶级诞生的那个句子将仍然是一个标签，不是授予的一个条款。价格、数量与同资本主义的比较不在文本里。米尔克罗斯是虚构的，所以连那个特权也只是一个算通的逻辑，直到一份真实的特许状说出它。
:::
:::

:::exercise 列格尼察不是一座学院 {level=2}
1241年，蒙古诸战役抵达匈牙利与列格尼察。一名学生说，这显示城市欧洲被摧毁了，因此大学必定是在那之后才被创建的。在不发明创始年份也不发明军队规模的前提下，纠正这个尺度。
:::solution
诸战役不是欧洲的终结，蒙古政治体不是一条脚注。它们与一座公社的特权、与一项执教许可是不同的尺度。“城市欧洲”的毁灭不是这份年表所说的。大学仍然没有锁定的创始年份，无论在1241年之前还是之后。从1241年到1274年是33年，它把一场死安放在诸战役之后，而没有把那场死变成一次重建。[[sources/scale]]是一般规则。军队规模不可得，所以一个也不添加来让句子显得精确。
:::
:::

:::exercise 一个窗口不是一个生日 {level=3}
一个读者说，一所伟大的学校必定创建于本章那张图的窗口边缘，否则那条线本来会把它标出来。解释这个错误。说出关于博洛尼亚、巴黎与牛津你被允许说什么，以及你必须拒绝哪个句子。
:::hint
图说已经说出为什么没有圆点。不要在回答里补一个创始年份。一个窗口的边缘是一个标尺，不是一个事件。
:::
:::solution
那张图的窗口是一把自己选定的标尺，好让1215年、1274年与1291年能被一起看见。它的边缘不是一个事件，不是一个创始。图说说大学没有一个圆点，因为本图谱没有锁定一个创始年份。你可以说：博洛尼亚、巴黎与牛津是学生或教师们的法人团体，持有组织学业与许可执教的特权，而学生们或教师们的分量有所不同。你必须拒绝任何形如“这所学校创建于”后面跟一个年份的句子。发明一个年份去填那个圆点，会让那张图看上去完成，让这份年表看上去马虎。[[#thm-death]]只允许1274作为一个死。
:::
:::

:::exercise 什么会推翻特权的论断 {level=3}
[[#thm-privilege]]说一个公社与一个大学单凭自身不创造一个中产阶级或资本主义。什么样的证据会构成对那条论断的反证？为什么一个富裕商人家族的真实报道单凭自身不够？
:::hint
寻找一个把那个阶级当作它自己的范畴来使用的文本，或一个本图谱本来必须锁定的度量。财富已经在论证里被承认。
:::
:::solution
如果一项特权陈述说它正在创建一个中产阶级，或者如果这份年表锁定了一个以这些法人团体为起点的新经济制度的度量，这条论断就会失败。一份只授予一座市场与一座法庭的特许状没有那样说，正如虚构的米尔克罗斯授予在它两个句子之间的落差所显示的。一个富裕的商人家族显示商业财富，那是这条论断承认的。财富还不是一个政治，不是一所大学的目的，还不是资本主义。城市与学院之间的争吵指向另一个方向：那些团体能够冲突。同样不能推翻这条论断的，是一个从本图谱之外输入的创始年份。一个发明的生日背负不了那个生日本身没有记录的一个经济制度。
:::
:::
