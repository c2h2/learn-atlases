为什么一个日期不是中性的标签？

日期看起来是历史中唯一不能被指控选边的部分。它是一个数字、一个月、一天。[[sources/evidence]]刚刚坚持说特许状和沉默都由某人所为。历法似乎坐在这些麻烦之下，仿佛年份是一个架子，事件是放到架子上的物件。事实并非如此。架子是有形状的。没有公元0年。罗马、不列颠和俄国没有从同一个10月撕掉同样的日子。在位纪年在命名一段时间之前先命名了一位国王，而恐怖统治或中世纪这样的绰号是一条关于这段时光价值的论断。有人从这个名字受益。本图谱的公开时间线印作BC，课文对同一套数字说公元前。这个差别是一种印刷约定，不是两个过去。

要点不是日期可有可无。要点是日期本身已经是一则小论证，看不见这则论证的读者会把一个真日期“纠正”成一个假日期。历法改革之前标注的日期不是错误，它是按当时通行的历法标注的日期。十月革命的两个标签是同一个事件。为了让减法看起来像普通算术而插入一个公元0年，不能修复这个计数，只能发明一个年份。

## 那个不在的年份

:::definition 历史纪年 {#def-count}
这里使用的**历史纪年**没有公元0年。公元前1年的后一年是公元1年。从公元前A年到公元B年的已过计数是A加B减1。从公元A年到较晚的公元B年，已过计数是B减A，不是把两端都算在内的计数。同一套数字在本站时间线上显示时，印作BC。BCE与BC是同一个数字的两种写法。
:::

:::theorem 跨越分界的跨度消去幽灵般的0 {#thm-elapsed}
从公元前1年到公元1年是1年，不是2年。一般地，从公元前A年到公元B年的已过计数是A加B减1。把公元前年份当作负整数、随后又忘记那个缺失之0的减法，是在数一个从未到来过的年。
:::
:::proof
年份的序列就是证据。公元前1年的前一年不是一个0，公元前1年的后一年是公元1年，没有任何标作0的东西站在它们之间。因此，从公元前1年之末到公元1年之末的一步是1年。公式是把这一事实为任意一对年份写出来：把两个数字相加，你就数了一个序列并不包含的0；减1，幽灵就掉了出去。检查最小的情形：1加1减1是1。再检查一个不跨越分界的情形，以免公式被习惯性地误用：从800年到843年，两者皆公元，已过计数是843减800，即43，不是44。两端都算在内的计数会把每个跨度都虚增1。本图谱不这样做。

能够反驳[[#thm-elapsed]]的，是历史纪年本身中的一个公元0年：一份文书、一个在位年、或一套纪年体系中一张天文表，其年为0，并且坐在公元前1年与公元1年之间。这样的东西不存在。不能构成反驳的，是在现代计算中使用负整数的便利。整数是工具，它们可以包含0；按这个纪年，过去不包含。为了减法方便而插入0的学生改变的是历法，而不是使它更清楚。同样不成立为反例的，是时间线拒绝显示公元0年：下图正是为展示这种拒绝而建，它不是一套0暗中回归的第二年表。
:::

挂在缺失之0上的名字，在课程记录中，是狄奥尼修斯·埃克西古斯（Dionysius Exiguus）。我们不给他一个属于他自己的年份，因为这里没有锁定他的任何年份，而一部带着发明日期的传记，只会给一课讲虚假精确的课文添加一个虚假精确。我们使用的是纪年，不是生平。实际的检验是那个不依赖他也能做的检验：把年份按顺序取来，拒绝从公元前1年跳到0，或从0跳到公元1年。

:::widget timeline
start: -5
end: 5
window: 1
events: -1,公元前1年; 1,公元1年
caption: 把年份移到0上。读数应显示没有公元0年，并显示从公元前1年到公元1年的距离是1年。
:::

在你相信一个看起来整洁的减法之前，先把年份移到0上。读数应说没有公元0年，并且从公元前1年到公元1年的距离是1年。事件标签写作公元前，是因为任务书就是这样命名它们的。本站别处把负年份印作BC，在那个读数里，请把BC读作课文所说的公元前。宽为一年的窗口是有意做小的，它不让你把缺口藏进一个世纪。

另有两段跨度，使这条规则不至于成为只对1与1这一对奏效的戏法。尤利乌斯·凯撒（Julius Caesar）于公元前44年3月15日被杀。维苏威火山在公元79年喷发，庞贝被掩埋。从公元前44年到公元79年的已过计数是44加79减1，即122。你可以分段看到同一个总数：从公元前44年到公元前1年是43年，从公元前1年到公元1年是1年，从公元1年到公元79年是78年，于是43加1加78是122。忘记那个缺失之0的整数捷径把44和79相加，得到123。多出的1是幽灵年，它不是庞贝的一年，也不是刺杀的一年。从公元前27年——屋大维（Octavian）被称为奥古斯都（Augustus）的那次安置——到公元117年图拉真（Trajan）之死，计数是27加117减1，即143，同一条错误的捷径给出144。两段跨度都不是衰落或复兴的故事，每一个都只是距离，而距离只与规则一样可靠。

:::example 从公元前1年到公元1年 {#ex-one}
从公元前1年到公元1年经过了多少年？哪一个整数运算会错误地回答2?
:::solution
使用[[#thm-elapsed]]。A是1,B是1，因此已过计数是1加1减1，即1。公元前1年的后一年是公元1年，没有公元0年可过。那个回答2的运算，要么把这些年当作整数1和-1来相减，要么干脆把数字相加就收手。无论哪种，它都数了一个历史序列并不包含的0。时间线放在那里，是让你可以移动到那个缺失的年份上，读出这种拒绝。答案是1年，不是2年，也不是0年。
:::
:::

:::example 一段跨越的跨度，与一段不跨越的 {#ex-cross}
计算从公元前44年到公元79年的已过计数，以及从800年到843年的已过计数。解释为什么这两个计算不是同一条规则的盲目套用。
:::solution
从公元前44年到公元79年，计数跨越分界，所以[[#def-count]]给出44加79减1，即122。分段看：44减1是43，从公元前1年到公元1年是一步1,79减1是78，于是43加1加78是122。把44和79相加得到123，就是插入了一个公元0年。从800年到843年，两个年份都是公元，所以计数是843减800，即43。你不相加，也不多减1。两端都算在内的计数会把那个跨度变成44，本图谱拒绝它。800年的加冕与843年的瓜分不是这里的主题，主题是：一条为跨越分界而设的规则，不得用在一个从未跨越的跨度上。
:::
:::

## 三次改革，三部历法

:::definition 旧历与新历 {#def-styles}
**旧历（Old Style）**指一个尚未采纳改革的邦国仍在使用的儒略历民事历。**新历（New Style）**指格里高利历。在一国自行切换之前写下的日期，是按该国当时所用历法书写的日期，不是一个等着被转译到消失的错误。
:::

:::theorem 改革之前的日期不是错误 {#thm-not-error}
罗马的切换、不列颠的切换和俄国的切换是三个行为，发生在三个日期，省略了三段互不相同的日名序列。一份文书的日期落在某个邦国尚未跳过的一天，那么它在当时生效的历法中就是正确的。按照“各国都在1582年切换”来纠正它，是用一个假日期替换一个真日期。
:::
:::proof
相继序列就是证据，它们互不一致。在罗马，1582年10月4日之后是1582年10月15日，日名10月5日到10月14日在那里没有被使用，那是十个名字。活过的下一天晚了一天，被一个前十个名字的标签称呼。人们没有弄丢生活中的10天，是标签跳了。在不列颠，1752年9月2日之后是1752年9月14日，没有用过的名字是9月3日到9月13日，十一个名字。在俄国，1918年1月31日（儒略历）的第二天是1918年2月14日（格里高利历），没有用过的名字是2月1日到2月13日，十三个名字。并非每个国家都在1582年切换：不列颠是一个等到1752年的锁定案例，俄国则等到1918年。

能够反驳[[#thm-not-error]]的，是不列颠或俄国确实在1582年跳过了10月那些天的证据，以至于一个不列颠或俄国的1582年10月10日已经不可能存在。年表说的是反面：它们的切换在1752年和1918年。一个不列颠的1582年10月10日是儒略历日期，在不列颠合法，不是什么应当“纠正”到10月20日或别的日子的谬误。同样会构成反驳的，是表明被跳过的名字是一段段经验的空白、而非被改名的相继日子。史料给出的是日期的相继，不是缺席数周的知觉。改革可以是真实的、地方的、容易误读的。误读才是本节要拦下的迷思。
:::

罗马的改革出自教皇格里高利十三世（Gregory XIII），课程记录因此把它定年为1582年。不列颠的改革是大不列颠议会的一项立法。俄国的改革是人民委员会的一项法令。三个权威，三个清晨。一封1752年9月3日伦敦的信件是反方向的问题案例：那个日名在不列颠没有被使用，因为9月2日之后是9月14日。一封1751年9月3日的信则平常。年份要紧，地点也要紧。“9月3日”不是抽象意义上的错误：只有在民事历已经废除那个名字的当地它才是错误，在历法尚未废除它的当地它是一个好日期。

俄国的算术有它自己的陷阱，值得慢慢做一遍，免得那十三个没有用过的名字被“纠正”成十四个。1918年1月31日的第二天是1918年2月14日。如果你把2月的标签从1数到14两头都算，你得到十四个名字，而你已把2月14日算了进去——而它是一个真实的日子，新历的第一天。没有出现的名字是1日到13日，共十三。从最后一个儒略历日到第一个格里高利历日，活过的时间是1天，是标签跳了。宣布俄国失去14天的学生，数了抵达本身。同样的纪律保护罗马和不列颠：不要把你降落的那1天算作你跳过的日子之一。

## 1917年：一个事件，两个日期

十月革命是旧历1917年10月25日，也是新历1917年11月7日。两个日期命名同一个事件。俄国尚未切换。切换在第二年，即1918年1月31日之后接2月14日，所以1917年的俄国民事日期仍是儒略历，而同一个夜晚的巴黎或伦敦日期是格里高利历。两个标签都不是另一个标签的错误。

连接二者的换算可以在锁定的那一对上核对，而不添加新的日子。10月有31天。给10月25日加13天：25加13是38,38减31是7，所以新历标签是11月7日。13是这两种官方历式在1917年仍然保有的距离，在配对本身上就看得见，它不是第三种历法。[[wars/revolutions-1917]]讲述这次夺权对战争和国家做了什么，本章不。一堂日期课变成政治叙事就是换了话题。属于这里的是那个双重名称，以及双重名称比1918年的改革更古老这一事实。

所谓二月革命是同年另一对锁定的日期，而它是另一个事件。按旧历它从1917年2月23日持续到3月3日；按新历这两个端点是1917年3月8日和3月16日。“二月”记录的是俄国的月名，在巴黎，同一场动荡是一件三月的事件。把任何一个月份称作谬误，就是混淆一个名字与一个错误，这正是[[#thm-not-error]]所禁止的失败。尼古拉二世（Nicholas II）于新历1917年3月15日退位，即旧历3月2日。那一天落在区间的两个版本之内：3月2日在2月23日与3月3日之间，3月15日在3月8日与3月16日之间。一次退位，两个标签。我们不再添加1917年的任何其他日子：年表锁定的就是这些，再多一天就是我们决定发明的日期。

用同样的方式检查二月的端点，然后停下。1917年在这里要紧的民事历法中不是闰年，所以二月有28天。给2月23日加13天：23加13是36,36减28是8，于是3月8日。给3月3日加13天，落在3月16日。给3月2日加13天，落在3月15日。算术只使用已被命名的日子，它不是邀请你拿日记去填满区间。

:::example 罗马的十月里一个不列颠的日子 {#ex-british-1582}
罗马在1582年10月4日之后接着是1582年10月15日。不列颠在1752年9月2日之后接着是1752年9月14日。一封伦敦的信件日期是1582年10月10日。这个日期是错误吗？一次错误的“纠正”会做出什么？
:::solution
这个日期不是错误。[[#thm-not-error]]把几次切换分开。不列颠没有在1582年采纳改革：伦敦的1582年10月10日是一个儒略历日期，用不列颠当时使用的历法书写，而不列颠一直用到1752年9月才弃用。在罗马，1582年10月5日到10月14日这些名字不是民事日，所以同一行字写在罗马就是另一种问题。地点是日期的一部分。一个把伦敦信件移动10天的纠正，或以格里高利已经改革了罗马为由宣布它无效的纠正，都会用一个臆造物替换一个真的旧历日期。这封信不会变成新历，除非有一条规则使它如此，而不列颠的规则定年为1752年。
:::
:::

:::example 十月的两个标签 {#ex-october}
说明旧历1917年10月25日与新历1917年11月7日如何能是一个日期，并说明俄国的1918年切换为什么没有使其中之一变错。
:::solution
给10月25日加13天。10月有31天，所以25加13是38,38减31是7，新历标签是11月7日。年表为同一场革命列出两个标签，并把历法切换放在1918年——那年1月31日之后是2月14日。1917年10月在那个清晨之前，因此俄国民事纪年与格里高利纪年出现分岔，两个名称在各自的历式里都是对的。[[#def-styles]]就是那个区分。要把它们拆成两场革命的，是相隔13天的两次夺权的证据，而那不是一个配对所记录的。政治叙事在[[wars/revolutions-1917]]，日期课到这一对为止。
:::
:::

## 已经在选边的名字

:::definition 时代标签 {#def-period}
**时代标签**是一条关于一段时光的论断，却戴着仿佛它是自然中一道接缝的面具。在位纪年是它的小号版本：它从一次即位起算，因而主张的是谁的即位算数。像恐怖统治或中世纪这样的绰号是它的大号版本：它主张这段时光是什么样子，通常还主张谁有理。日期，在我们有它们的地方，与绰号不是一回事。
:::

在位纪年最容易在它仍然只是一张公式时看见。下面这个子句是为说明而虚构的，它不是特许状：“于N王在位N年所颁。”即便作为玩具，这个子句已经选定了一位国王：计数从那位国王的即位开始，而不肯承认其即位的书写者就不会承认其年份。内战中的两座文书厅可以用两个在位年给同一个下午纪日。两个日期都可以是真诚的，它们却不是同一个架子上的中性标签，而是以历法形式写成的关于正统的主张。要把这个玩具提升为一次真在位的证据，需要一份真文书、一位真统治者，以及这套年表锁定的一个年份。玩具三样都没有，也不得靠氛围补给它。[[#def-period]]在这个公式里已经可见。[[sources/evidence]]会把未标明的玩具称为虚构的句子，而且它是对的。

恐怖统治是带有真日期的真惯例，而这个名字仍然是一条论断。作为一个被命名的时段，它按惯例从1793年9月持续到1794年7月27日——也叫热月9日（9 Thermidor）——罗伯斯庇尔（Robespierre）于当天垮台。日期是一道年表允许的括号，不是对法国大革命的定义，也不是它的对立面。[[revolutions/republic-and-terror]]把这道括号作为一个开战中的政府来讲授，它使用了特别法庭，并拒绝给出死者数目。本章同样拒绝这个数目，也拒绝任何关于人们如何被杀的描写。我们添加的，是日期作为标签总是唤起的那个问题：谁从这个名字受益？

想要用那道括号来审判整场革命的人受益。绰号把一场漫长的政治转变浓缩进它最令人恐惧的几个月，然后让这几个月代表其余的一切。想要把括号当作一个密封的例外来记住——对1789年或热月之后的年头无话可说——的人也受益。名字完成了密封。两种用法都是论证，哪一种都不是日期单独交给你的。1793年9月与1794年7月27日完全可以在没有绰号的情况下陈述。绰号一旦被当作像山脉一样的自然物，论证就被藏进了词里。在位纪年藏一位国王，恐怖统治藏一道判决。

中世纪藏着一道几何。“中间”只有在你已经选定两端之后才是中间：一个已经结束的古典世界，一个已经开始的现代世界。本图谱不为这个绰号锁定第一个或最后一个年份，也不会发明它们。给中世纪补充一个诞辰，恰恰是被缺失日期所禁止的那种虚假精确。谁受益？任何需要这些被如此命名的世纪成为两座峰之间的低谷的人，任何需要一条以沉闷为中枢的单一欧洲故事、好让后来的复兴或后来的国家看起来像惊醒的人。受益不是阴谋，它是情节的寻常优势。[[crises/city-states]]拒绝黑暗的中世纪让位于文艺复兴之光的情节，[[after-rome/successor-kingdoms]]拒绝把“黑暗时代”当作我们自己的论断。在这里，绰号已经够说明问题：它是一条关于时间中一道接缝的论断，而时间并不以那种方式长着接缝。接缝是我们画的，然后我们忘了是我们画的。

- [ ] 它纠正了退位：退位是新历3月15日，因此不可能在10月
:::solution
两个标签命名同一个事件，而[[#thm-not-error]]禁止把改革之前的历式当作错误。俄国的切换是1918年1月31日之后接1918年2月14日，那在1917年10月之后。二月革命是另一个事件，旧历定年为2月23日到3月3日，即新历3月8日到3月16日。退位——新历3月15日、旧历3月2日——落在那个较早的区间之内，不在10月。教科书只保留格里高利历的那一天，并没有变得更准确，而是提供的信息更少，并且把一个历法称呼为一个谬误。
:::
:::

:::warning 被“纠正”的日期，与被插入的0
两个迷思造成了大部分损害。第一个说，任何在一国历法改革之前的日期都是错的，应当一路挪动直到与1582年的罗马一致。不列颠自己的切换是1752年，俄国的切换是1918年。一个伦敦的1582年10月10日，不是某个被人办砸了的罗马日期。第二个迷思插入一个公元0年，好让公元前与公元像普通整数那样相减：从公元前1年到公元1年，插入法产出2年，而计数是1年。第三个更安静的迷思把恐怖统治或中世纪当作自然造出的接缝，而不是一个有人从中受益的名字。恐怖统治的日期，1793年9月到1794年7月27日，可以在没有判决的情况下陈述；中世纪则无法获得一个这套年表尚未锁定的诞辰。
:::

:::history
在罗马，1582年10月4日之后是1582年10月15日。在不列颠，1752年9月2日之后是1752年9月14日。在俄国，1918年1月31日之后的一天是1918年2月14日。三次改革都是真实的，它们不在同一个清晨，而在相关改革之前写下的日期不是错误。
:::

## 中性标签所藏的东西

一旦允许日期成为一种论证，好几个著名的纠正就当场瓦解。把1917年俄国的每一天都译成新历、然后扔掉旧历名称的历史学家，并没有把政治从纸面上移除，而是把一个文书厅的历法选为真实的那个。对身处格里高利历国家的读者来说，这个选择也许是方便的，但方便不是中立。保留两个名称，并说出每个名称属于哪种历式，才是更准确的句子。它也是把二月革命留在为其命名者的二月里、留在其报纸已用新历者的三月里的那个句子。[[wars/revolutions-1917]]随后可以讲述政治，而不必假装月份名称是一个关于天气的错误。

在位纪年与绰号是同一堂课的两种尺寸。一个按征服者的在位纪日的文书，已经把征服当作稳固来对待了。一个使用“在中世纪”这个短语的教师，已经承诺了“古典世界终结、现代世界开始、两者之间的那段是一个东西”的主张。你可以继续用这个绰号，只要你展示它的主张；你不能继续把它当架子。恐怖统治是检验，因为日期已锁定，而诱惑强烈。1793年9月到1794年7月27日是一道括号，“恐怖统治”则是你已决定的括号含义，而这个决定帮助某些故事、伤害另一些故事。说明这一点，否则日期已悄悄变成判决。

下一章追问：当日期和名字不再被允许独自完成主张之后，一条论断是什么。一个原因必须是本可别的东西。威斯特法利亚（Westphalia）或文艺复兴这样的标签打包一条论断，并且常常把它藏起来。你刚练过的已过计数不会解决那个问题，它只会使问题里面的年头保持诚实。那个问题在[[sources/argument]]。

## 通向何处

日期现在是一条带规则的小论断，不再是中性标签。[[sources/argument]]分开一条论断、一个原因与一个标签，并把反证保持在句子之内。1917年的双重日期在[[wars/revolutions-1917]]作为政治来讲述。那道称作恐怖统治的括号在[[revolutions/republic-and-terror]]作为一个政府来讲述。中世纪这个绰号在图谱拒绝黑暗中间的任何地方受压，从[[after-rome/successor-kingdoms]]和[[crises/city-states]]开始。

:::summary
- 没有公元0年。公元前1年的后一年是公元1年，从那一年到那一年的已过计数是1。
- 从公元前A年到公元B年的已过计数是A加B减1。从800年到843年，两者皆公元，是43，不是两端的44。
- 本站时间线把负年份印作BC，课文对同一套数字说公元前。
- 罗马在1582年10月4日之后接着是1582年10月15日。不列颠在1752年9月2日之后接着是1752年9月14日。俄国在1918年1月31日之后接着是1918年2月14日。
- 相关改革之前的日期不是错误。不列颠的1582年10月是一个儒略历日期，不是谬误。
- 十月革命是旧历1917年10月25日、新历1917年11月7日，一个事件，在1918年切换之前。
- 二月革命是旧历1917年2月23日到3月3日，或新历3月8日到3月16日。尼古拉二世退位于旧历3月2日，即新历3月15日。
- 在位纪年、恐怖统治与中世纪都是论断。恐怖统治的惯例括号是1793年9月到1794年7月27日。有人从名字中受益。
:::

## 习题

:::exercise 最小的跨度 {level=1 check="1"}
从公元前1年到公元1年经过了多少年？（请输入年数。）
:::solution
没有公元0年，所以已过计数是1加1减1，即1。答案2数了一个幽灵年。答案0把一个缺失的标签当作一个缺失的时长。年数是1。
:::
:::

:::exercise 越过喷发 {level=1 check="122"}
凯撒死于公元前44年，维苏威在公元79年喷发。从公元前44年到公元79年经过了多少年？（请输入年数。）
:::solution
跨度跨越分界，所以计数是44加79减1，即122。分段看，从公元前44年到公元前1年是43，从公元前1年到公元1年是1，从公元1年到公元79年是78，于是43加1加78是122。把44与79相加并在123停下的捷径插入了一个公元0年。答案是122。
:::
:::

:::exercise 罗马的第二天 {level=1}
1582年10月4日之后，罗马的民事日期是什么？两者之间有多少个日名没有被使用？
:::solution
1582年10月4日之后是1582年10月15日。没有使用的日名是10月的5、6、7、8、9、10、11、12、13和14日，共十个名字。活过的时间是1天。改革没有移除10天的经验，而是给第二天改了名。不列颠不同的相继——1752年9月2日之后接1752年9月14日——不是这个清晨，俄国的1918年相继也不是。
:::
:::

:::exercise 1582年的伦敦 {level=2}
以点明不列颠切换的方式解释，为什么一份日期为1582年10月10日的伦敦文书不得被改派给一个格里高利历的日子。
:::solution
不列颠的切换是1752年，那年9月2日之后接9月14日，而不是1582年。[[#thm-not-error]]说相关改革之前的日期不是错误。在伦敦，1582年10月10日是一个可用的儒略历日子。在罗马，1582年10月5日到10月14日的名字没有被使用，所以地点决定同一行字是平常还是不可能。把伦敦的日期挪去迎合格里高利的改革，是假装不列颠与罗马同时切换，而年表说它没有。文书保持旧历1582年10月10日；任何新历等值都必须作为换算给出，而不是作为对一个错误的纠正。
:::
:::

:::exercise 二月的两个区间 {level=2}
写出二月革命的旧历与新历区间，把退位置入两者之内，并说出你不得添加什么。
:::solution
旧历，区间是1917年2月23日到3月3日。新历，端点按13天换算为1917年3月8日与3月16日。1917年2月有28天，所以23加13落在3月8日，3月3日加13落在3月16日。尼古拉二世退位于旧历3月2日，即新历3月15日，落在两个区间之内。十月革命是更晚而不同的事件，旧历10月25日，新历11月7日。1917年不得添加其他任何一天。俄国的切换，1918年1月31日之后接1918年2月14日，在下一年，所以两个区间都没有因为使用它们所使用的历式而成为错误。两场革命的政治在[[wars/revolutions-1917]]，不在这些算术里。
:::
:::

:::exercise 谁受益 {level=2}
恐怖统治作为被命名的时段，惯例上是1793年9月到1794年7月27日。中世纪在本图谱没有锁定的诞辰。就每个名字说出它携带什么主张，以及当名字被当作天然接缝时谁受益。
:::solution
恐怖统治的日期可以在没有绰号的情况下陈述。绰号主张那道括号是一个独立而恐怖的对象，并且惯例上系于罗伯斯庇尔1794年7月27日的垮台。想要整场革命被那道括号定罪的人受益，想要把括号密封为一个例外、对它周围的年头无话可说的人同样受益。两者都是主张。[[revolutions/republic-and-terror]]讲授那个政府，我们不陈述死亡总数。中世纪主张一个古典的终结与现代的开端已被选定，而其间的一段是一个中间。没有锁定第一个或最后一个年份，因此一个也不发明。需要低谷、或需要一条以沉闷为中枢的单一欧洲故事的作者与教师，从这道接缝受益。[[#def-period]]涵盖两个名字。在位纪年是同一个装置在一个在位年尺度上的形态：那个虚构的子句“于N王在位N年”已经选定了一位国王。
:::
:::

:::exercise 幽灵年 {level=3}
一名学生用27加117计算从公元前27年到公元117年的跨度，得到144，并把多出的一年辩护为“只是年0，它使算术变得正常”。指出损害，并给出本图谱使用的计数。
:::hint
在纠正较大的例子之前，先比较最小的例子，公元前1年到公元1年。这个辩护正是[[#thm-elapsed]]所禁止的插入。
:::
:::solution
从公元前1年到公元1年，同样的辩护给出1加1，即2，但按顺序的年份是公元前1年然后公元1年，已过计数是1。多出的单位不是1年，而是那个纪年不包含的0。从公元前27年到公元117年，本图谱的计数是27加117减1，即143。学生的144是幽灵，大1年，并且无处安放：既不在奥古斯都公元前27年的安置里，也不在图拉真之死那一年里。为负整数把算术变“正常”改变的是历法。[[#def-count]]只在两个年份都是公元或都是公元前时允许通常的减法，如843减800得43，跨越分界的跨度不是那种情形。时间线是同一个拒绝在起点的图像：把它移到0上，读数应当否认这个学生插入的那一年。
:::
:::

:::exercise 十四还是十三 {level=3}
一位读者说俄国在1918年跳过了14天，因为民事日期从1月31日跳到2月14日，而14是新日期上的数字。差一错在哪里？同一个错误如何威胁罗马与不列颠的改革？
:::hint
列出没有出现的2月的名字，注意2月14日是在那个清单里，还是出现的那天。然后对1582年10月15日与1752年9月14日重复这个检验。
:::
:::solution
1918年1月31日之后的一天是1918年2月14日。没有出现的名字是2月1日到2月13日，共十三个。2月14日出现了，它是新历的第一天，不是被略去的标签之一。从1数到14两头都数的话，就把抵达算了进去，把十三变成了十四。活过的时间是1天，是标签跳了。在罗马，1582年10月15日出现了，被略去的名字是10月5日到14日，十个，不是十一个。在不列颠，1752年9月14日出现了，被略去的名字是9月3日到13日，十一个。[[#thm-not-error]]需要的是被略去的集合，而不是次日清晨印出的数字。每次改革之前的日期在旧历式中仍是好日期。十月革命仍在1917年，在这次跳跃之前，这正是10月25日与11月7日都被保留的原因。
:::
:::
