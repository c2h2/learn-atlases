为什么日期不是中性的标签？

在一部历史中，日期似乎是唯一不会被指责偏袒任何一方的部分：不过是一个数字、一个月份、一个日子。[[sources/evidence]]刚刚强调，特许状也好，沉默也好，都出自某人之手。历法似乎处在这些麻烦之下，仿佛年份是一排架子，事件只是摆在架上的物件。事实并非如此。架子本身有形状。没有公元0年。罗马、不列颠和俄国并不是从同一个十月里撕去同样的日子。在位纪年先指名一位国王，然后才指称一段时间；“恐怖统治”“中世纪”这类绰号，则是对那段时光价值的论断。总有人从这样的名称中获益。本图谱的公开时间线印作BC，课文对同样的数字则称公元前。这一差别只是印刷惯例，并不意味着有两个过去。

要点不在于日期可有可无，而在于日期本身已经是一个小小的论证；看不出这一论证的读者，会把真日期“纠正”成假日期。历法改革以前标注的日期并不是错误，而是按当时通行的历法标注的。十月革命的两个标签指的是同一个事件。为了让减法看起来像普通算术而插入公元0年，并不能修正计数，只是凭空造出一个年份。

## 不存在的那一年

:::definition 历史纪年 {#def-count}
这里使用的**历史纪年**没有公元0年：公元前1年的下一年是公元1年。从公元前A年到公元B年，经过的年数是A加B减1。从公元A年到较晚的公元B年，经过的年数是B减A，而不是把首尾两端都算进去。本站时间线显示同样的数字时印作BC。BCE与BC是同一数字的两种名称。
:::

:::theorem 跨越分界时，须去掉那个幽灵般的0 {#thm-elapsed}
从公元前1年到公元1年是1年，而不是2年。一般而言，从公元前A年到公元B年经过的年数是A加B减1。如果把公元前的年份当作负整数相减，又忘了那个缺失的0，就会多数出一个从未存在过的年份。
:::
:::proof
年份的先后序列本身就是证据。公元前1年的前一年不是0，公元前1年的下一年是公元1年，两者之间没有任何标作0的年份。因此，从公元前1年年末到公元1年年末，相隔1年。公式只是把这一事实推广到任意一对年份：把两个数字相加，就多算了序列中并不存在的0；减去1，幽灵便消失了。检验最小的情形：1加1减1等于1。再检验一个不跨越分界的情形，以免出于习惯误用公式：从800年到843年，两者都是公元纪年，经过的年数是843减800，即43，而不是44。把首尾两端都算进去，会使每个跨度都虚增1年。本图谱不这样计算。

能够推翻[[#thm-elapsed]]的，是历史纪年本身中存在公元0年：在这一纪元体系中，有一份文书、一段在位期或一张天文表的年份为0，并且位于公元前1年与公元1年之间。这样的东西并不存在。现代计算中使用负数的便利，则不构成反驳。整数只是工具，可以包含0；而按这种纪年，过去并不包含0。为了方便减法而插入0的学生，是改动了历法，而不是把它讲清楚了。时间线不显示公元0年，同样构不成反例：下图正是为了展示这种拒绝而设计的，并不是一套让0悄悄回归的第二种年表。
:::

根据课程记录，与这个缺失的0联系在一起的名字是狄奥尼修斯·埃克西古斯（Dionysius Exiguus）。我们不为他单列年份：这里没有锁定任何与他有关的年份，而一份带有杜撰日期的生平，只会在一堂讲虚假精确的课里再添一分虚假精确。我们用的是纪年，而非生平。实际的检验不必借助他也能完成：按顺序排列年份，拒绝从公元前1年跳到0，或从0跳到公元1年。

:::widget timeline

:::

在相信一个看似整齐的减法之前，先把年份移到0上。读数应显示没有公元0年，并且从公元前1年到公元1年相距1年。事件标签写作公元前，因为任务说明就是这样称呼的。本站其他地方把负年份印作BC，读数中的BC，请理解为课文所说的公元前。窗口宽度只有一年，是有意为之：它不让你把这个缺口藏进一个世纪里。

另外两个跨度表明，这条规则并非只对“1与1”这一对数字管用的把戏。尤利乌斯·凯撒（Julius Caesar）于公元前44年3月15日遇刺。公元79年维苏威火山喷发，庞贝被掩埋。从公元前44年到公元79年，经过的年数是44加79减1，即122。分段计算也能得到同样的总数：从公元前44年到公元前1年是43年，从公元前1年到公元1年是1年，从公元1年到公元79年是78年，43加1加78等于122。忘记缺失之0的整数捷径把44与79相加，得出123。多出的1年就是幽灵年，它既不属于庞贝，也不属于那次刺杀。从公元前27年屋大维（Octavian）获称奥古斯都（Augustus）的那次政治安排，到公元117年图拉真（Trajan）去世，年数是27加117减1，即143，同样的错误捷径则得出144。这两个跨度都不是衰落或复兴的故事，只是距离，而距离的可靠程度取决于规则。

:::example 从公元前1年到公元1年 {#ex-one}
从公元前1年到公元1年经过了多少年？哪种整数运算会错误地得出2？
:::solution
运用[[#thm-elapsed]]。A为1，B为1，所以经过的年数是1加1减1，即1。公元前1年的下一年就是公元1年，中间没有公元0年可以跨过。得出2的运算，要么把这两个年份当作整数1和-1相减，要么干脆把两个数字相加了事。无论哪种，都多算了历史序列中并不存在的0。时间线的作用，是让你移到那个缺失的年份上，读出这种拒绝。答案是1年，既不是2年，也不是0年。
:::
:::

:::example 跨越分界的跨度与不跨越分界的跨度 {#ex-cross}
计算从公元前44年到公元79年经过的年数，以及从800年到843年经过的年数，并说明为什么这两次计算不是对同一条规则的盲目套用。
:::solution
从公元前44年到公元79年跨越了分界，所以按[[#def-count]]，年数是44加79减1，即122。分段计算：44减1是43，从公元前1年到公元1年是1，79减1是78，43加1加78等于122。把44和79相加得出123，就等于插入了公元0年。从800年到843年，两个年份都是公元纪年，所以年数是843减800，即43。既不相加，也不再多减1。把首尾都算进去会使这个跨度成为44，本图谱不采用这种算法。800年的加冕和843年的瓜分不是这里的主题；主题是：为跨越分界而设的规则，不能用在从未跨越分界的跨度上。
:::
:::

## 三次改革，三种历法

:::definition 旧历与新历 {#def-styles}
**旧历（Old Style）**指尚未采纳改革的国家仍在使用的儒略历民用历法。**新历（New Style）**指格里高利历。一国自行改历之前写下的日期，是按该国当时所用历法写成的日期，而不是一个有待通过换算消除的错误。
:::

:::theorem 改革之前的日期不是错误 {#thm-not-error}
罗马、不列颠和俄国的改历是三个不同的行为，发生在三个不同的日期，略去的日名序列也各不相同。一份文书若注明的日期是某国当时尚未跳过的日子，那么按当时有效的历法，它的日期是正确的。若按各国都在1582年改历的假定去纠正它，就是用假日期替换真日期。
:::
:::proof
先后相继的日期序列就是证据，而它们彼此并不一致。在罗马，1582年10月4日之后是1582年10月15日，10月5日至10月14日这些日名在当地没有使用，共十个。实际过的第二天只晚了一天，却用了一个向前跳了十个名字的标签。人们并没有丢失十天的生活，跳过去的是标签。在不列颠，1752年9月2日之后是1752年9月14日，未使用的日名是9月3日至9月13日，共十一个。在俄国，1918年1月31日（儒略历）的次日是1918年2月14日（格里高利历），未使用的日名是2月1日至2月13日，共十三个。并非所有国家都在1582年改历：不列颠是一个等到1752年才改历的锁定案例，俄国则等到1918年。

能够推翻[[#thm-not-error]]的，是证明不列颠或俄国确实在1582年跳过了十月那些日子的证据——那样的话，不列颠或俄国的1582年10月10日就已不可能存在。年表所示恰恰相反：它们分别在1752年和1918年改历。不列颠的1582年10月10日是儒略历日期，在不列颠合法有效，并不是把10月20日或其他某个“纠正后”的日子写错了。同样能推翻这一论断的，是证明被跳过的日名是经验中的一段空白，而不是相继日子的改名。史料给出的是日期的相继，而不是几周意识的缺失。改革可以是真实的、局部的，也容易被误读。这种误读就是本节要破除的迷思。
:::

罗马的改革出自教皇格里高利十三世（Gregory XIII），课程记录因此将其定在1582年。不列颠的改革是大不列颠议会的一项立法，俄国的改革是人民委员会的一项法令。三个权威，三个清晨。伦敦一封注明1752年9月3日的信，则是反方向的问题案例：这个日名在不列颠并未使用，因为9月2日之后就是9月14日。注明1751年9月3日的信却很平常。年份要紧，地点也要紧。“9月3日”本身无所谓错误：只有在民用历法已经废除这一日名的地方它才是错误，在尚未废除的地方，它就是一个有效的日期。

俄国的算术自有陷阱，值得放慢做一遍，免得把十三个未使用的日名“纠正”成十四个。1918年1月31日的次日是1918年2月14日。若把二月的标签从1数到14、首尾都算，就得到十四个名字，而这已把2月14日算了进去——那是真实存在的一天，即新历的第一天。没有出现的日名是1日至13日，共十三个。从儒略历的最后一天到格里高利历的第一天，实际只过了一天，跳的是标签。宣称俄国丢了十四天的学生，把抵达的那一天也算进去了。同样的规矩也适用于罗马和不列颠：不要把落脚的那一天算作被跳过的日子。

## 1917年：一个事件，两个日期

十月革命发生在旧历1917年10月25日，也就是新历1917年11月7日。两个日期指的是同一个事件。当时俄国尚未改历。改历在第二年，即1918年1月31日之后接2月14日，所以1917年俄国的民用日期仍是儒略历，而巴黎或伦敦为同一夜所记的日期是格里高利历。两个标签都不是对方的错误。

连接二者的换算可以用锁定的这对日期核验，无需添加新的日子。10月有31天。10月25日加13天：25加13得38，38减31得7，所以新历标签是11月7日。13天是这两种官方历法在1917年仍相差的天数，从这对日期本身就看得出来，并不是第三种历法。这次夺权对战争和国家造成了什么后果，由[[wars/revolutions-1917]]讲述，本章不谈。日期课一旦变成政治叙事，就换了话题。属于这里的是这个双重名称，以及双重名称早于1918年改革这一事实。

所谓二月革命，是同一年另一对锁定的日期，而且是另一个事件。按旧历，它从1917年2月23日持续到3月3日；按新历，这两个端点是1917年3月8日和3月16日。“二月”记录的是俄国的月份名称；在巴黎，同一场动荡发生在三月。把两个月份中的任何一个称作谬误，都是把名称与错误混为一谈，而这正是[[#thm-not-error]]所禁止的。尼古拉二世（Nicholas II）于新历1917年3月15日退位，即旧历3月2日。这一天落在两个版本的区间之内：3月2日在2月23日与3月3日之间，3月15日在3月8日与3月16日之间。一次退位，两个标签。我们不再添加1917年的其他任何日子：年表锁定的就是这些，多加一天，就是我们决意杜撰的日期。

用同样的方法核验二月的端点，然后就此打住。在这里起作用的民用历法中，1917年不是闰年，所以二月有28天。2月23日加13天：23加13得36，36减28得8，即3月8日。3月3日加13天，是3月16日。3月2日加13天，是3月15日。这番算术只用到已经点名的日子，并不是邀请你用日记去填满这段区间。

:::example 罗马十月里的一个不列颠日期 {#ex-british-1582}
罗马在1582年10月4日之后接1582年10月15日，不列颠在1752年9月2日之后接1752年9月14日。伦敦一封信注明的日期是1582年10月10日。这个日期是错误吗？错误的“纠正”会造成什么后果？
:::solution
这个日期不是错误。[[#thm-not-error]]把几次改历区分开来。不列颠没有在1582年采纳改革：伦敦的1582年10月10日是儒略历日期，按不列颠当时所用的历法书写，而不列颠一直沿用这一历法，直到1752年9月。在罗马，1582年10月5日至10月14日这些日名不是民用日，所以同样的字样出现在罗马，就是另一种问题。地点是日期的一部分。若把这封伦敦信件挪动十天，或以格里高利已经改革了罗马历法为由宣布它无效，都是用虚构之物替换一个真实的旧历日期。除非有规则这样规定，这封信不会变成新历，而不列颠的这条规则定于1752年。
:::
:::

:::example 十月的两个标签 {#ex-october}
说明旧历1917年10月25日与新历1917年11月7日何以是同一个日期，并说明俄国1918年的改历为何没有使其中之一变成错误。
:::solution
10月25日加13天。10月有31天，所以25加13得38，38减31得7，新历标签是11月7日。年表为同一场革命给出两个标签，并把改历定在1918年——那年1月31日之后接2月14日。1917年10月早于那个清晨，因此俄国民用纪日与格里高利纪日彼此分岔，两个名称在各自的历法中都是正确的。[[#def-styles]]正是这一区分。能把它们拆成两场革命的，只能是相隔13天的两次夺权的证据，而这对日期记录的并不是这个。政治叙事见[[wars/revolutions-1917]]，日期课到这对日期为止。
:::
:::

## 已经选边的名称

:::definition 时代标签 {#def-period}
**时代标签**是关于一段时光的论断，却装扮成自然界中的一道接缝。在位纪年是它的小号版本：它从某次即位起算，因而断定了谁的即位算数。“恐怖统治”“中世纪”这样的绰号是大号版本：它断定这段时光是什么样子，通常还断定谁是对的。在我们掌握日期的地方，日期与绰号并不是一回事。
:::

在位纪年还只是一个格式时最容易看清。下面这个子句为说明而虚构，它不是特许状：“于N王在位第N年颁授。”即便只是玩具，这个子句也已选定了一位国王：计数从这位国王即位时开始，不承认其即位的书写者，也不会承认这一纪年。内战中的两座文书厅，可以用两位君主的在位年为同一个下午纪日。两个日期都可能出于真诚，但它们不是同一排架子上的中性标签，而是以历法形式写成的正统性主张。要把这个玩具当作某次真实在位的证据，需要一份真实的文书、一位真实的统治者，以及本年表锁定的一个年份。玩具一样也没有，也不能凭氛围替它补上。[[#def-period]]在这个格式中已经显现。[[sources/evidence]]会把未加标明的玩具称为虚构的句子，这样说是对的。

“恐怖统治”是一个有真实日期的真实惯例，但这个名称仍是一条论断。作为一个有名称的时段，它按惯例始于1793年9月，止于1794年7月27日，即热月9日（9 Thermidor）罗伯斯庇尔（Robespierre）倒台的那一天。这些日期是年表所允许的一个括号，既不是对法国大革命的定义，也不是它的反面。[[revolutions/republic-and-terror]]把这个括号作为一个处于战争中、动用特别法庭的政府来讲授，并拒绝给出死亡人数。本章同样拒绝给出这个数字，也拒绝描写人们如何被杀。我们补充的，是把日期当作标签时总会引出的问题：谁从这个名称中获益？

想用这个括号来评判整场革命的人获益。这个绰号把一场漫长的政治变革浓缩为最令人恐惧的几个月，再让这几个月代表其余的一切。想把这个括号记作一个封闭的例外、对1789年或热月以后的年份无话可说的人，同样获益——封闭正是由名称完成的。两种用法都是论证，而哪一种都不是单凭日期就能得出的。1793年9月与1794年7月27日完全可以不带绰号地陈述。一旦把绰号当作像山脉一样的自然之物，论证就藏进了这个词里。在位纪年藏着一位国王，“恐怖统治”藏着一个判决。

“中世纪”藏着一种几何。“中间”之所以是中间，前提是你已经选定了两端：一个已经终结的古典世界，一个已经开始的现代世界。本图谱不为这个绰号锁定起始年份或终止年份，也不会杜撰它们。为中世纪补上一个诞辰，恰恰是缺失的日期所禁止的那种虚假精确。谁获益？凡是需要把如此命名的几个世纪当作两座高峰之间的低谷的人，凡是需要一个中段沉闷的单一欧洲故事、好让后来的复兴或后来的国家显得像是觉醒的人。这种获益并非阴谋，而是情节的寻常优势。[[crises/city-states]]拒绝“黑暗的中段让位于文艺复兴之光”的情节，[[after-rome/successor-kingdoms]]拒绝把“黑暗时代”作为我们自己的论断。在这里，绰号本身已足以说明问题：它是关于时间中一道接缝的论断，而时间并不是那样分段生长的。接缝是我们画上的，画完之后，我们又忘了是自己画的。

一本教科书把俄国的1917年10月25日称为错误，只印1917年11月7日。这本教科书做了什么？
- [ ] 它应用了1582年10月4日的改革，而俄国早已采纳该改革
- [ ] 它发现二月革命与十月革命是同一个事件
- [x] 它删去了一个真实的旧历标签，而这个事件同时带有新历标签，且发生在1918年改历之前
- [ ] 它纠正了退位日期：退位在新历3月15日，因此不可能在10月
:::solution
两个标签指的是同一个事件，而[[#thm-not-error]]禁止把改革前的历法当作错误。俄国在1918年改历，1月31日之后接1918年2月14日，晚于1917年10月。二月革命是另一个事件，按旧历为2月23日至3月3日，按新历为3月8日至16日。退位日期——新历3月15日、旧历3月2日——落在这个较早的区间之内，不在10月。教科书只保留格里高利历的日子，并没有变得更准确，反而提供的信息更少，还把一种历法称为谬误。
:::
:::

:::warning 被“纠正”的日期与被插入的0
大部分损害出自两个迷思。第一个迷思认为，一国历法改革之前的任何日期都是错的，应当挪动到与1582年的罗马一致为止。而不列颠自己的改历在1752年，俄国在1918年。伦敦的1582年10月10日并不是某人弄错了的罗马日期。第二个迷思插入公元0年，好让公元前与公元的年份像普通整数那样相减：从公元前1年到公元1年，插入0会得出2年，而实际是1年。第三个更隐蔽的迷思，把恐怖统治或中世纪当作自然形成的接缝，而不是某些人从中获益的名称。恐怖统治的日期——1793年9月至1794年7月27日——可以不带判决地陈述；而中世纪无法获得一个本年表尚未锁定的诞辰。
:::

:::history
在罗马，1582年10月4日之后是1582年10月15日。在不列颠，1752年9月2日之后是1752年9月14日。在俄国，1918年1月31日的次日是1918年2月14日。三次改革都是真实的，但并不在同一个清晨；在相关改革之前写下的日期并不是错误。
:::

## 中性标签掩盖了什么

一旦承认日期可以是一种论证，好几种著名的纠正便当即瓦解。把1917年俄国的每一天都换算成新历、再丢掉旧历名称的历史学家，并没有把政治从纸面上清除出去，而是选定了某一个文书厅的历法作为真实的历法。对格里高利历国家的读者来说，这样选择也许方便，但方便并不等于中立。保留两个名称并说明各属哪种历法，才是更准确的写法。这样写，也能让二月革命对为它命名的人仍留在二月，对报纸已采用新历的人则在三月。这样，[[wars/revolutions-1917]]便可以讲述政治，而不必假装月份名称是一个关于天气的错误。

在位纪年和绰号是同一课的两种尺寸。按征服者的在位年纪日的文书，已经把征服视为稳固。使用“在中世纪”这个短语的教师，已经认可了这样的主张：一个古典世界终结了，一个现代世界开始了，二者之间的那一段是一个整体。你可以继续使用这个绰号，只要你把它的主张摆出来；但不能再把它当作架子。恐怖统治是一块试金石，因为日期已经锁定，而诱惑又很强。1793年9月至1794年7月27日是一个括号，“恐怖统治”则是你为这个括号认定的含义，这一认定会助长某些叙事，也会损害另一些叙事。要把这一点说出来，否则日期就已悄然变成判决。

下一章要问：当日期和名称不再被允许独自完成论断时，论断是什么。原因必须是本来可能不同的东西。“威斯特伐利亚（Westphalia）”或“文艺复兴”这样的标签包裹着一条论断，而且常常把它藏起来。你刚刚练习的年数计算解决不了这个问题，只能让问题中的年份保持诚实。这个问题见[[sources/argument]]。

## 通向何处

日期现在是一条附带规则的小论断，而不再是中性标签。[[sources/argument]]区分论断、原因与标签，并把反证留在句子之内。1917年的双重日期在[[wars/revolutions-1917]]中作为政治来讲述。名为“恐怖统治”的那个括号在[[revolutions/republic-and-terror]]中作为一个政府来讲述。凡是本图谱拒绝“黑暗中段”的地方，“中世纪”这个绰号都受到质疑，首先是[[after-rome/successor-kingdoms]]和[[crises/city-states]]。

:::summary
- 没有公元0年。公元前1年的下一年是公元1年，从前者到后者经过的年数是1。
- 从公元前A年到公元B年，经过的年数是A加B减1。从800年到843年，两者都是公元纪年，年数是43，而不是首尾都算的44。
- 本站时间线印作BC，课文对同样的数字称公元前。
- 罗马在1582年10月4日之后接1582年10月15日，不列颠在1752年9月2日之后接1752年9月14日，俄国在1918年1月31日之后接1918年2月14日。
- 相关改革之前的日期不是错误。不列颠1582年10月的日期是儒略历日期，不是谬误。
- 十月革命是旧历1917年10月25日、新历1917年11月7日，同一个事件，发生在1918年改历之前。
- 二月革命按旧历为1917年2月23日至3月3日，按新历为3月8日至16日。尼古拉二世于旧历3月2日即新历3月15日退位。
- 在位纪年、“恐怖统治”与“中世纪”都是论断。恐怖统治的惯例括号是1793年9月至1794年7月27日。总有人从名称中获益。
:::

## 习题

:::exercise 最小的跨度 {level=1 check="1"}
从公元前1年到公元1年经过了多少年？（请输入年数。）
:::solution
没有公元0年，所以经过的年数是1加1减1，即1。答案2多算了一个幽灵年。答案0把缺失的标签当成了缺失的时长。年数是1。
:::
:::

:::exercise 越过喷发 {level=1 check="122"}
凯撒于公元前44年遇刺，维苏威火山于公元79年喷发。从公元前44年到公元79年经过了多少年？（请输入年数。）
:::solution
这个跨度跨越分界，所以年数是44加79减1，即122。分段计算：从公元前44年到公元前1年是43，从公元前1年到公元1年是1，从公元1年到公元79年是78，43加1加78等于122。把44与79相加、止于123的捷径插入了公元0年。答案是122。
:::
:::

:::exercise 罗马的第二天 {level=1}
在罗马，1582年10月4日之后的民用日期是什么？两者之间有多少个日名未被使用？
:::solution
1582年10月4日之后是1582年10月15日。未使用的日名是10月5、6、7、8、9、10、11、12、13和14日，共十个。实际只过了一天。改革没有抹去十天的经验，只是给第二天改了名。不列颠的相继——1752年9月2日之后接1752年9月14日——不是这个清晨，俄国1918年的相继也不是。
:::
:::

:::exercise 1582年的伦敦 {level=2}
请点明不列颠的改历，解释为什么一份注明1582年10月10日的伦敦文书不应改记为格里高利历的某一天。
:::solution
不列颠的改历在1752年，那年9月2日之后接9月14日，而不是在1582年。[[#thm-not-error]]指出，相关改革之前的日期不是错误。在伦敦，1582年10月10日是一个可用的儒略历日子；在罗马，1582年10月5日至10月14日这些日名未被使用，所以同样的字样是寻常还是不可能，取决于地点。把伦敦的日期挪动以迎合格里高利的改革，等于假装不列颠与罗马同时改历，而年表表明并非如此。这份文书仍是旧历1582年10月10日；任何新历对应日期都只能作为换算给出，而不能作为对错误的纠正。
:::
:::

:::exercise 二月的两个区间 {level=2}
写出二月革命的旧历区间和新历区间，把退位日期放入两个区间之内，并说明哪些东西不得添加。
:::solution
按旧历，区间是1917年2月23日至3月3日。按新历，端点按13天换算为1917年3月8日和3月16日。1917年2月有28天，所以23加13落在3月8日，3月3日加13落在3月16日。尼古拉二世于旧历3月2日即新历3月15日退位，落在两个区间之内。十月革命是较晚的另一个事件，旧历10月25日，新历11月7日。1917年的其他日子一概不得添加。俄国的改历——1918年1月31日之后接1918年2月14日——在第二年，所以两个区间都不因使用各自的历法而成为错误。两场革命的政治见[[wars/revolutions-1917]]，不在这番算术之中。
:::
:::

:::exercise 谁获益 {level=2}
“恐怖统治”作为一个有名称的时段，惯例上是1793年9月至1794年7月27日；“中世纪”在本图谱中没有锁定的诞辰。请就每个名称说明它携带什么主张，以及当这个名称被当作自然接缝时谁会获益。
:::solution
恐怖统治的日期可以不带绰号地陈述。这个绰号主张这个括号是一个独立的恐怖对象，并按惯例与1794年7月27日罗伯斯庇尔的倒台相连。想让整场革命因这个括号而受谴责的人获益，想把这个括号封存为例外、对其前后年份无话可说的人也获益。两者都是主张。[[revolutions/republic-and-terror]]讲授那个政府，我们不给出死亡总数。“中世纪”主张古典的终结与现代的开端已经选定，二者之间的那一段是一个“中间”。起始和终止年份都未锁定，因此一个也不杜撰。需要一个低谷、或需要一个中段沉闷的单一欧洲故事的作者和教师，从这道接缝中获益。[[#def-period]]涵盖这两个名称。在位纪年是同一装置在一个在位期尺度上的形态：那个虚构的子句“于N王在位第N年”已经选定了一位国王。
:::
:::

:::exercise 幽灵年 {level=3}
一名学生用27加117计算从公元前27年到公元117年的跨度，得到144，并为多出的一年辩护说：“那只是年份0，它让算术变得正常。”请指出其危害，并给出本图谱使用的年数。
:::hint
在纠正较大的例子之前，先比较最小的情形：公元前1年到公元1年。这种辩护正是[[#thm-elapsed]]所禁止的插入。
:::
:::solution
从公元前1年到公元1年，同样的辩护会得出1加1，即2；但按顺序排列，年份是公元前1年、然后公元1年，经过的年数是1。多出的单位不是一年，而是这种纪年中并不存在的0。从公元前27年到公元117年，本图谱的年数是27加117减1，即143。学生的144是幽灵，多出1年，却无处安放：既不在公元前27年奥古斯都的那次安排之中，也不在图拉真去世的那一年。为了负整数而让算术变得“正常”，改变的是历法。[[#def-count]]只在两个年份同为公元或同为公元前时允许普通减法，例如843减800得43；跨越分界的跨度不属于这种情形。时间线展示的是同一种拒绝在原点处的图像：移到0上，读数应当否认这名学生插入的那一年。
:::
:::

:::exercise 十四还是十三 {level=3}
一位读者说，俄国在1918年跳过了14天，因为民用日期从1月31日跳到2月14日，而14是新日期上的数字。差一错误出在哪里？同样的错误又会怎样波及罗马和不列颠的改革？
:::hint
列出二月中没有出现的日名，注意2月14日是在这份清单里，还是确实出现的那一天。然后对1582年10月15日和1752年9月14日重复这一检验。
:::
:::solution
1918年1月31日的次日是1918年2月14日。没有出现的日名是2月1日至2月13日，共十三个。2月14日出现了，它是新历的第一天，而不是被略去的标签之一。从1数到14、首尾都算，就把抵达的那一天也算了进去，十三便成了十四。实际只过了一天，跳的是标签。在罗马，1582年10月15日出现了，被略去的日名是10月5日至14日，十个而不是十一个。在不列颠，1752年9月14日出现了，被略去的日名是9月3日至13日，十一个。[[#thm-not-error]]需要的是被略去的集合，而不是次日清晨印出的数字。每次改革之前的日期，在旧历中仍是有效的日期。十月革命仍在1917年，早于这次跳跃，这正是10月25日和11月7日都被保留的原因。
:::
:::
