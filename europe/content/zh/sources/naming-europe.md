“欧洲”这个名称指的是什么？单一的轮廓又把谁排除在外？

海岸线不等于民族，民族也不等于条约。“欧洲”这个词至少被要求承担四种互不重合的职能。它曾是古典时代的地理名称，与世界其他部分并列，不附属于任何政制。它曾是拉丁基督教世界的地图，共同的拉丁礼仪和一整套共同的排斥做法在其中充当了边界。它曾是一种均势观念，即戴着王冠的各国之间的一种外交习惯——这种习惯能够、也确实以均衡之名抹去过一个庞大的政治体。到了故事的晚期，它又成了一个条约组织：一份已签约政府的名单，以及一份未签约政府的名单。这不是同一对象的四幅草图，一幅比一幅清晰，直至呈现今天的轮廓；而是四种用法。对其中一种成立的句子，对其他几种可能并不成立。

本章要拒绝的诱惑，是先画出欧洲联盟，再倒着往回走，直到过去与之吻合。在这条回头路上，罗马的一次加冕成了早期的布鲁塞尔，一次宗教和约成了宪法草案，凡是生活在这片地理范围之内、却不在后来成员名单上的人，都被当作一种迟滞。这种回溯讨好了当下，也让更早的世纪变得无法理解，因为它强迫那些世纪去回答它们从未提出的问题。拜占庭（Byzantium）、安达卢斯（al-Andalus）、奥斯曼帝国、犹太社区和罗姆人都在这片地理范围之内，却常常被写在这个故事之外。711年、800年、1453年和1957年标记的是几幅不同的地图，而不是同一道上升阶梯的各级台阶，其中也没有哪一个是一块大陆的诞生。

## 名称不是土地

:::definition “欧洲”这个名称 {#def-name}
本章所说的**欧洲**，是人们用来指称一个地方、一个信众共同体、一项外交事业或一批签约国的名称。它不是只有一条边界、一个民族或一套价值观的自然事实。山脉、海洋和冬季是真实的，但它们本身并不决定谁属于这段历史。
:::

:::definition 地图 {#def-map}
这里所说的**地图**，是关于边界的论断。它说明谁算在内，谁被置于边缘，谁被写出去。这种论断可以是地理的、宗教的、外交的或法律的。论断变了，岩石并不会移动。把最新一幅地图当作土地本身的读者，会把此前的每一幅都描述错。
:::

:::theorem 四种用法，四种对象 {#thm-four}
古典地理名称、拉丁基督教世界的地图、均势观念，以及1957年3月25日建立的条约组织，不是同一种对象。关于其中一种的真实陈述，不能移用于其他几种。它们都不是一块大陆的诞生；711年、800年、1453年和1957年这四个日期，也不构成通向某个完成轮廓的单一上升过程。
:::

:::proof
这四种用法回答的是不同的问题，失灵的方式也各不相同。古典地理学家可以把已知的人居世界分为几个部分，把其中一部分冠以这个名称，而不必创立教会、王国或关税同盟——当时根本没有可以如此命名的欧洲国家。800年12月25日，教皇利奥三世（Leo III）为查理曼（Charlemagne）加冕，这是在拉丁西方提出的一项帝国主张。它没有废除君士坦丁堡的罗马国家，也没有描述安达卢斯。列强之间的均衡是一种外交习惯。1713年的《乌得勒支和约》和1815年6月9日维也纳会议的《最后议定书》，是国家之间的解决方案，既不是信条，也不是对一块陆地的界定。1772年、1793年和1795年对波兰—立陶宛的瓜分，表明同一种习惯可以抹掉一个庞大的政治体。1957年3月25日由《罗马条约》建立的欧洲经济共同体和欧洲原子能共同体（Euratom），是一份成员名单。身处这片地理范围之内、却不在这份名单上的国家，并不因此就在欧洲之外。

能够推翻[[#thm-four]]的，是一个从古典名称一直延续到1957年的单一机构，它凭自身的行为为其间每一个世纪划定了边界：一个文书机构、一次公会议，或一项界定这块大陆而非界定成员资格的条约。共用的词汇不是这样的机构。后来的读者能在同一条时间线上看到全部四个日期，并不意味着他发现了当时的人也在看着这条时间线。如果记录中确实出现了这样一个连续的界定性机构，这条论断就必须收窄或放弃。但本图谱视为已有定论的事物中，没有任何一个是这样的机构。
:::

这一区分说来容易，丢掉也容易。我们之所以伸手去抓单一的轮廓，是因为图谱有封面，课程有标题，而当下的政治论争又常常想要一个比自身更古老的文明主体。[[#def-name]]在一开始就挡住了这一步：名称是人们拿一个词所做的事。[[#def-map]]挡住了下一步，即把今年的边界当作一直存在、只是从前画得不好的边界。[[#thm-four]]则是检验。如果一段文字从希腊的地理用词滑到中世纪的拉丁教会，再滑到20世纪的条约，句子所指的对象却始终不变，那么这段文字就是保留了名词、偷换了话题。

:::quiz
按照本章的论证，下列哪一项是对这块大陆的界定？
- [ ] 欧洲经济共同体，因为一项条约终于使这一轮廓具有了法律效力
- [ ] 拉丁基督教世界，因为共同的礼仪就是拥有同一套价值观的共同文明
- [x] 都不是：每一项都是这个名称的一种用法，而用法不是土地本身
- [ ] 均势，因为外交发现了这块陆地的自然形状

[[#thm-four]]把四种用法分开，并拒绝把其中任何一种升格为这块大陆本身。欧洲经济共同体是一份日期为1957年3月25日的成员名单。拉丁基督教世界是一幅宗教地图，而不是一套统一的价值观。外交均势是国家之间的一项事业，它可以抹去一个国家，对波兰—立陶宛的瓜分就是如此。关于某一种用法的真实陈述，并不是对这片土地的界定。
:::

## 古典的名称

希腊和拉丁的地理学说把已知世界分为几个部分，欧洲是其中之一，与亚细亚以及利比亚（Libya，后世作者称之为阿非利加）并列。这种划分依据的是海洋、海岸和传承下来的故事，而不是某种政制，因为根本不存在可以依据的欧洲政制。一个从未问过哪位国王才算正统的学生，也可以学到这个名称。仅此一点，就足以把它与后来借用同一个词的每一项政治事业区分开来。

这个名称没有做到的事，与它做到的事同样重要。它没有把爱琴海的各个城市变成一个民族。城邦（polis）是由公民和领土构成的共同体，而不是某个希腊国家的行省——当时并没有希腊国家。共同的语言、崇拜和赛会是真实的，但它们不是政府。波斯在本图谱将于[[greece/persian-wars]]中再次讲到的那些统治者治下，是近在咫尺的一个大帝国，有它自己的政治。它不是一个名为“东方”的道德范畴；希腊人战胜一支波斯军队，也不是拯救了一块大陆。把这些战争读作欧洲自由的诞生，就是拿一个古典地理用词，硬塞进一个现代情节。

罗马从另一侧说明了同样的道理。罗马共和国以及后来的罗马帝国所统治的土地，后世地图会把它们分别归入欧洲、亚洲和非洲；而罗马人是用城市和帝国的语言来描述自己的世界，并不把它当作一项欧洲事业。公民权——[[rome/imperial-society]]将会讨论——可以扩展到极大的范围，却并不因此成为现代意义上的国籍。在这种扩展之下，被奴役者依然处于奴役之中。这段法律史中没有任何一点是在为某种欧洲精神投票。当西部帝系被按惯例定于476年终结时，东部帝国仍在延续；对于任何声称“欧洲”径直继承了罗马、却把君士坦丁堡排除在外的故事，这种延续都是致命的。我们将在[[sources/argument]]中把476年作为一个经过论证的论断来使用。这里只需说明：地理名称和帝国国家已经是两种不同的对象。

古典名称可以对海岸线描述得很精确，用作成员资格的检验却毫无用处。人们在这些被命名的部分之间迁移，崇拜四处传播，军队从地理学家视为边界的那片海的多处海岸招募兵员。这个名称指称的是一种关于世界的学说，而不是一个“够格者”的封闭俱乐部。后来的作者谈论“欧洲文明”，仿佛荷马（Homer）、一位贝鲁特的法学家和一位诺森布里亚（Northumbria）的修士都加入了同一个传统，这是在把古典的词当作他们自己经典谱系的标签。这个经典谱系也许值得争论，但它并不是那个地理名称本来的含义。

## 宗教地图

拉丁基督教世界是第二种用法，也是[[#def-map]]意义上的地图。它指称的是承认拉丁礼仪、在这一时期大部分时间里也承认教皇主张的教会，以及这些教会愿意计算在内的人。它并不涵盖所有基督徒，也不涵盖所有生活在大西洋与黑海之间的人。

800年12月25日，教皇利奥三世在罗马为查理曼加冕称帝。这一行为是一项主张：它在西方确立了一个与罗马主教相联系的皇帝称号。它既不是对仍从君士坦丁堡进行统治的罗马国家的描述，也不是对伊比利亚各社会的裁决。这次加冕有日期、有地点、有受益者，这些是一个事件的标志，而不是一块大陆诞生的标志。想要找一个诞辰的读者往往在这里止步，因为一顶皇冠是一幅令人满意的画面。[[#thm-four]]要求他们说清楚被加冕的是什么对象：被加冕的是一位皇帝，而不是欧洲。

拉丁教会与希腊教会之间的关系是一个漫长的过程，而不是一个开关。1054年，洪贝尔（Humbert）与米海尔·凯鲁拉里乌斯（Michael Cerularius）卷入的相互绝罚，为教科书提供了一个标志教会分裂的节点。但这个节点并不是故事的全部。人们并不是晚上入睡时还在共融之中，醒来就成了两个文明。把1054年当作“欧洲”选择拉丁一方的时刻，就是借一场教士之间的争执，把说希腊语的罗马世界从这块大陆上抹去。这场争执固然重要，却不是刻在岩石上的边界。

其他节点表明，这幅宗教地图不仅针对一个竞争的教会划界，也在人口内部划界。基辅的弗拉基米尔（Vladimir）受洗的传统年份是988年。这是罗斯（Rus'）皈依的传统标志，而不是一次信仰普查。统治者受洗是关于一个宫廷和一项政策的证据，它不能告诉你每个居民怎么想，正如官方宗教也不能告诉你这一点。1215年11月，第四次拉特兰公会议颁布第68条教规，要求拉丁基督教世界中的犹太人和穆斯林以服饰加以区别。这是一项关于排斥的法令，而不是对每座城镇实际做法的描述。它证明这幅宗教地图能够把生活在拉丁基督教土地上的人正式置于可见共同体的边缘。一幅需要给邻人佩戴标记的地图，不是一块大陆的中立轮廓，而是一条规定谁可以不带标记通行的规则。

十字军的历程表明，同一幅地图会攻击那些按另一种描述本应被视为同类的人。1095年11月，乌尔班二世（Urban II）在克莱蒙（Clermont）布道。1099年7月15日，第一次十字军攻占耶路撒冷。1187年，萨拉丁（Saladin）在哈丁（Hattin）之战后夺取耶路撒冷。1204年4月13日，第四次十字军洗劫了君士坦丁堡这座基督教城市，拉丁基督教军队在东罗马国家的首都摧毁了生命与权威。无论1204年还意味着什么——[[christendom/crusades]]把它当作一次十字军来讲述，而不是当作故事之外的意外——它对那种把基督教世界描绘为共同对外的一方的图景都是致命的。一幅宗教地图可以掉过头来攻击被它自己划到界线另一侧的基督徒。这是关于这幅地图的事实，而不是关于某种统一的欧洲心智的事实。

## 身在地理之内，被写在故事之外

“拜占庭”是西方对在东方延续的罗马国家的惯用称呼。这个名称本身就是一幅小地图：它让拉丁叙事把这个国家当作欧洲的邻居，而不是依然存续的罗马帝国。查士丁尼（Justinian）——其统治和法典属于[[after-rome/byzantium]]——统治的是一个宫廷使用希腊语的罗马国家。他不是法兰克人历史的脚注；800年一位法兰克人加冕称帝时，法兰克人也不是基督教世界的全部。从那次加冕到君士坦丁堡陷落，这个帝国又存续了几个世纪，自己铸币、立法、征税，以自己的声音辩论。如前所述，1204年拉丁十字军洗劫了它的首都。1453年5月29日，奥斯曼苏丹穆罕默德二世（Mehmed II）攻占君士坦丁堡，东罗马国家灭亡。奥斯曼的统治并不是巴尔干的“历史终结”，而是一座城市的主权更迭——这座城市处在“欧洲”这一名称的每一种诚实的地理用法之内。一部让欧洲故事在1453年止步于城墙之下的历史，已经把话题从地方换成了宗教资格。

安达卢斯也属于同样的纠正。711年，塔里克·伊本·齐亚德（Tariq ibn Ziyad）的军队渡海进入伊比利亚。这次渡海开启了半岛上一段漫长的伊斯兰政治史——[[after-rome/islam-in-the-west]]将予以讲述——而不是打断了一个早已完成的欧洲。756年，阿卜杜勒·拉赫曼一世（Abd al-Rahman I）建立科尔多瓦倭马亚埃米尔国。929年，阿卜杜勒·拉赫曼三世（Abd al-Rahman III）取得哈里发称号。科尔多瓦哈里发国既是伊比利亚的事实，也是地中海的事实。把它写成夹在西哥特前奏和基督教复兴之间的外来插曲，就是把宗教地图当作土地本身。人们记作图尔战役或普瓦捷战役的那一仗，传统日期是732年10月；一些学者依据《754年编年史》（Chronicle of 754），倾向于733年或734年。这个日期有争议，课文必须如实说明，而不是挑一个数字、把争论藏起来。无论采用哪一年，这场战役都没有“拯救欧洲”：袭扰仍在继续，查理·马特（Charles Martel）当时也还不是国王。一块大陆获救的故事是后来的传说。1212年的拉斯纳瓦斯—德托洛萨（Las Navas de Tolosa）之战和1492年1月2日格拉纳达的投降，是半岛上更晚的事件。它们更换了统治者，而1492年的那一件还与同年的其他事件并列。它们并不能回溯过去，把711年变成一个错误。

1492年的意义有争议，而且争议的原因很明确：这一年包含好几个事件，把它们压缩成一个，诞辰就是这样制造出来的。1月2日，格拉纳达投降。3月31日，《阿尔罕布拉法令》命令卡斯蒂利亚和阿拉贡的犹太人改宗或离境，期限为7月31日。8月3日，哥伦布（Columbus）从帕洛斯（Palos）启航。10月12日，他在加勒比海登陆。一次宗教驱逐、伊比利亚一个穆斯林政治体的终结和一次横渡大西洋，并不是同一个名为“近代欧洲诞生”的事件。在这项法令企图终结的那段历史中，犹太社区早已身在其中：在安达卢斯，在拉丁诸王国，也在规则不同的奥斯曼世界。这项法令是一项排斥政策的证据，而不是一块大陆终于成为它自己的证据。本图谱不给出离境人数。虚假的精确只会给这项政策披上一层统计数字的外衣。

罗姆人身在这片地理范围之内，却一再被写在故事之外：被写成流浪者，写成治安问题，写成一个历史可以推迟到脚注里再说的民族。本图谱没有锁定他们最初到来的年份，也不会杜撰一个。缺少锁定的年份，是我们这里所用年表的局限，而不是在断言这些人不在场，更不是允许把他们排除在本章所提的问题之外。一个容得下条约却容不下罗姆人的单一轮廓，已经表明自己是一种经典谱系，而不是一幅居民地图。在恰好没有带日期的法令的那些世纪里，犹太社区的情形也是如此。存在并不是从一部敌视你的法律提到你的那一刻才开始的。

奥斯曼帝国在国家的尺度上说明了这一点。1453年以后，苏丹从一座拉丁地图曾称之为帝都的城市进行统治。只要按照土地而不是礼仪来界定欧洲，奥斯曼在巴尔干和东地中海的势力在任何定义下都属于欧洲政治史。1683年9月12日，维也纳之围在卡伦山（Kahlenberg）被解除。这次解围是一个有确切日期的军事事件，而不是“欧洲对亚洲”的永恒事实。本图谱的年表之所以特意这样说，是因为这句口号是一种挥之不去的诱惑：抓住一场哈布斯堡（Habsburg）城市守住了的战役，把它改写成一块大陆的传记。奥斯曼帝国不是暂时驻扎在城墙错误一侧的亚洲，而是一个长期存在的政治秩序，统治着那个地理名称早已涵盖的许多土地。想让宗教地图与地理名称成为同一种对象的读者，就不得不凭定义把这个秩序推出欧洲。[[#def-map]]就是这种推挤的名称。

图尔战役的传统日期是732年10月，一些学者倾向于733年或734年。这场战役没有拯救欧洲，袭扰仍在继续，查理·马特当时也还不是国王。1453年5月29日，穆罕默德二世攻占君士坦丁堡，东罗马国家灭亡；奥斯曼的统治并不是巴尔干历史的终结。1683年9月12日的维也纳解围，也不是“欧洲对亚洲”的永恒事实。这句话把三个不同的事件当成了同一个文明情节，正是那条回头路换上了军装。
:::
:::

## 是均衡，不是轮廓

这个名称的第三种用法是均势观念。它属于一个由若干武装国家组成的世界，每个国家都担心其中某一国会变得无可抗衡。这种观念指称的是参与博弈的各方，而不是居民。一个村庄、一个少数群体，或一个被各方同意瓜分的王国，并不会因为可以拿来交易就变得“不那么欧洲”，只会变得更缺乏保护。

1713年，《乌得勒支和约》了结了一场围绕西班牙王位继承、进而围绕数个帝国版图而进行的战争。这项条约是列强之间的交易，既不是地理发现，也不是这块大陆获得宪法的时刻。1815年6月9日，维也纳会议的《最后议定书》为自1814年开始的谈判达成的解决方案画上句号。维也纳会议在拿破仑战败后重新安排了各国，却没有找到某种文明的天然边界。这两个日期之所以有用，恰恰因为它们晚近、具体、有文献可查。它们表明均势是一种以条约为载体的实践，而不是从古典名称中流淌出来的本能。

瓜分表明了这种实践的代价。1772年、1793年和1795年，俄国、普鲁士和奥地利瓜分波兰—立陶宛，直到这个联邦作为国家被彻底抹去。它曾是一个庞大的欧洲政治体，而不是地图上的空隙。只从瓜分国首都的视角书写的历史，可以把结果称为均衡的恢复；而这个联邦自己的历史，则必须称之为毁灭。两种描述可以援引同样的年份，却不是同一条论断。均势观念如果被允许伪装成不过是“欧洲在捍卫自己的形状”，就会把第二条论断藏进第一条之中。谁从这种掩盖中获益，并不神秘：获得领土的列强获益。这个故事也让那些希望欧洲史只是一部大国史、并把被抹去的政治体看作迟早要被填满的空白的人获益。

这还不是对每位大臣动机的裁决。动机是单一原因故事的藏身之所，[[sources/argument]]将拒绝这类故事。这里的论点要窄一些：外交观念和一块陆地是不同的对象。你可以描述乌得勒支、维也纳和历次瓜分，而无须判定“欧洲”在精神上从哪里开始。一旦把外交观念升格为这块大陆的定义，被抹去的国家在被推出政治地图的同时，也就被推出了定义。这就是[[#def-map]]借一套客气的词汇在做暴力的事。

均衡也并没有干干净净地继承那幅宗教地图。瓜分波兰—立陶宛的列强并不属于同一个教会。1648年10月24日的和约调整了《奥格斯堡和约》，并把加尔文派纳入帝国；它有时被拉来充当某种国家体系的诞生，而这个体系随后又“变成”了欧洲。这种解读是后来才有的。威斯特伐利亚并没有发明一套成形的现代主权理论。把1648年当作均衡变成一块大陆的时刻，就是在加冕与《罗马条约》之间又偷运进一个诞辰。那项和约的具体内容留给[[reformations/religious-war]]，标签的逻辑留给[[sources/argument]]。在这里，1648年是一个警告：不要一面添加第五个诞辰，一面假装没有这样做。

## 成员名单

第四种用法出现得很晚，却是当今读者最容易视为理所当然的一种。1951年4月18日，《巴黎条约》建立欧洲煤钢共同体，1952年生效。1957年3月25日，《罗马条约》建立欧洲经济共同体和欧洲原子能共同体。这些都是国家之间的条约，而条约有签约方。1957年的签约方是少数几个西欧国家的政府，既不是生活在大西洋与乌拉尔山之间各民族的名单，也不是公元800年生活在那里的各民族的名单。欧洲经济共同体是一份成员名单，而不是对这块大陆的界定。

名单可以变动，海岸线却不会移动，这正是[[#thm-four]]的实际检验。1973年1月1日，英国、爱尔兰和丹麦加入共同体。它们并不是在那天早上驶进了欧洲，而是加入了一个它们此前置身其外的条约组织。没有加入的国家，仍然留在地理把它们安放的位置上。1995年1月1日，奥地利、芬兰和瑞典加入欧洲联盟——这是同一机构谱系后来的名称。2004年5月1日，塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚加入。2007年，保加利亚和罗马尼亚加入。2013年7月1日，克罗地亚加入。2016年6月23日，英国公投决定脱离，2020年1月31日正式退出，过渡期于2020年12月31日结束。这些都是关于一份名单的制度事实。没有一项是地理发现，也没有一项能回溯过去，为800年加冕，或取消711年的资格。

若干欧洲国家不在1957年的名单上，原因与是否身处这个地方毫无关系：中立、独裁、占领、另属一个同盟，或国内对是否签约的争论。1957年，这块大陆的东部既有与莫斯科结盟的国家，也有这些国家统治下的人民。在他们后来加入之前一直把他们写在“欧洲”之外，就是把那条回头路反过来走：把当下的名单当作目标，把早先不在名单上当作不在历史之中。完整的制度叙述属于[[postwar/welfare-and-treaties]]和[[postwar/union]]，本章只需要这个范畴。关税同盟不是一种文明。而“拥有同一套价值观的文明”这样的论断，本图谱也不会提出，因为刚刚考察过的记录支撑不了它。

在相信一句把这四个点纳入同一情节的话之前，先让窗口扫过它们。从711年到800年是89年，算法是后一年减前一年，与本图谱把800年到843年算作43年所用的是同一惯例。从800年到1453年是653年，从1453年到1957年是504年。间隔才是要点。伊比利亚的一次征服、罗马的一次加冕、君士坦丁堡的陷落，以及在另一主权下于罗马签署的一项条约，并不是同一个过程在四个时刻拍下的照片。这幅图让你可以把它们放进同一个框架，但框架只是工具，而不是论证。

## 实例：一座城市，三幅地图

以君士坦丁堡为例，不让任何一句话把它吞没。

800年，这座城市是东方罗马帝国的都城。罗马的加冕并没有使这个都城迁移。一幅把800年当作欧洲奠基之年的拉丁基督教地图，就必须交代博斯普鲁斯海峡边的这座城市算什么：既不算欧洲，又不完全算外国。通常的处理办法，是把这个国家改称拜占庭，放在故事的一旁。这种改名是对地图的选择，而不是对这个宫廷如何自称的报道。

1204年，拉丁基督教十字军洗劫了这座城市。此时，宗教地图与这座城市已不只是不同，而是兵戎相见。任何“中世纪欧洲保卫了君士坦丁堡”之类的句子，对那一年的四月而言都是错的。守城者和攻城者都可以称为基督徒；按照这一名称的地理用法，攻城者也可以称为欧洲人。只有悄悄把“欧洲”重新定义为“拉丁一方”，这句话才能成立。

1453年，穆罕默德二世攻占这座城市，东罗马国家灭亡。奥斯曼的君士坦丁堡——后来在日常语言中称为伊斯坦布尔（Istanbul）——依然是这片地理范围之内的一座都城。犹太社区生活在奥斯曼统治之下，其中包括1492年法令颁布后离开伊比利亚的人。拉丁基督教世界的宗教地图描述不了这座城市，地理名称却可以。每当哈布斯堡、威尼斯、俄国或其他势力与苏丹争夺地位时，均势观念都会再次遇到这座城市。1957年的条约组织中，这座城市并不是签约方：土耳其不在1957年的名单上。一个断定这座城市在1453年离开了欧洲、或者只有后来的某项条约认可它才进入欧洲的读者，是把[[#def-name]]和界桩混为一谈了。

能够推翻这个实例的，是这座城市曾经移动过的证据，或者这些日期中确有一个界定的是这块大陆、而不是某种主权的证据。城市没有移动。这些日期界定的是主权更迭、一次洗劫和一次不在名单上的状态。三幅地图，一个地方，而这个地方正是检验地图的标准。

:::example 本图谱已经使用的一段时间跨度 {#ex-verdun}
《凡尔登条约》定于843年。本图谱把从800年到843年经过的年数算作43年。请用这两个年份算出这个数，并说明凡尔登没有创立什么。
:::solution
843减800等于43。这一减法是两个公元年份之间的规则：后一年减前一年，而不是把首尾两端都算进去，也不是一个关于进步的故事。凡尔登分割的是一份法兰克遗产，并没有创立法国和德国。43是一次加冕与一次家族分产之间的距离。把43当作“欧洲变成两个民族所用的时间”的读者，是添加了条约本身并不包含的情节。完整的政治解读属于[[after-rome/carolingians]]。这里的算术只是一个距离，外加一次拒绝。
:::
:::

:::example 从陷落到条约 {#ex-1453-1957}
从1453年到1957年经过了多少年？为什么这个数字不是复兴的尺度？
:::solution
1957减1453等于504。1453年5月29日，穆罕默德二世攻占君士坦丁堡，东罗马国家灭亡。1957年3月25日，《罗马条约》建立欧洲经济共同体和欧洲原子能共同体。这504年是一次主权更迭与一份成员名单之间的间隔。它们不是一段康复期，不是“欧洲”回归自身，也不能证明1453年被攻占的那座城市离开了这块大陆、直到一项条约把它请回来。奥斯曼在巴尔干的统治在这片地理范围之内持续存在。这段间隔是反驳单一上升过程的论据，这正是[[#thm-four]]所主张的。如果这两个事件是同一次诞生的不同阶段，行为的种类就应当一致，反证也就无从谈起。但两者种类并不一致。
:::
:::

:::example 一句虚构的编年史文字 {#ex-invented-birth}
下面这句话为示例而虚构，不是引文，也不是史料。“711年渡海之后，这片土地便从欧洲失落，直到后来一次基督教的胜利才将它夺回。”要把这句话升格为证据需要什么？在升格之前，哪些锁定的事实就已经不利于这一情节？
:::solution
升格需要：一条留存下来的存迹，其中写有这句话，或这句话是对它的公允转述；一个制作者；一个日期；以及一个目的。即便如此，这条存迹也只能表明有人提出过这一主张，本身并不能表明这一主张属实。推论仍须与句子分开，你还必须说明什么会构成对这一推论的反证。

不必伪造编年史，这一情节在年表面前就已经站不住脚。711年的渡海是伊比利亚内部一段政治史的开端，而不是失去了一块已经完成的大陆。756年的埃米尔国和929年的哈里发国是半岛上的政府，而不是一片空白。图尔战役的传统日期是732年10月，另有依据《754年编年史》提出的733年和734年之说，而这场战役并没有拯救欧洲。1492年1月2日格拉纳达的投降，只是这一年中的一个事件，同年还有《阿尔罕布拉法令》、一次启航和一次登陆。历史学家对1492年的意义存在争议，本图谱拒绝把它压缩成一次大陆的光复。这句虚构的话，是宗教地图在冒充一份产权登记簿。
:::
:::

:::example 两项条约，而不是一次诞生 {#ex-two-treaties}
把1951年4月18日和1957年3月25日并列。这两个日期各自确立了什么？要求它们回答哪个问题是错误的？
:::solution
1951年4月18日，《巴黎条约》建立欧洲煤钢共同体，1952年生效。1957年3月25日，《罗马条约》建立欧洲经济共同体和欧洲原子能共同体。两者都是国家之间的成员安排。它们既不回答“欧洲是什么？”，也不回答“这块大陆诞生于何时？”。拿这些问题去问一次签字的读者，是在倒用[[#def-map]]：法律边界作为名单是真实的，却被要求兼当土地本身。名单后来的变化，例如1973年1月1日和2020年1月31日，都是成员资格的变化。假如1951年或1957年界定的是这个地方，而不是一批签约方，这些变化就无法理解。
:::
:::

:::warning 倒着走出来的轮廓
常见的迷思认为，欧洲是一个拥有同一套价值观的文明，而当今的联盟不过是这一文明终于取得了法律形式。按照这个迷思，800年、1648年和1957年是台阶，711年和1453年是来自外部的威胁，犹太社区和罗姆人只是点缀。这个迷思站不住脚：因为[[#thm-four]]中的四种用法不是同一种对象；因为图尔战役的日期有争议，这场战役也没有拯救一块大陆；因为1453年终结了一个罗马国家，却没有终结巴尔干的历史；还因为一份成员名单可以增减国家，而土地本身并没有增减。一套统一的价值观不是史料，而是一句借用了这个名称的口号。
:::

:::history
800年12月25日，教皇利奥三世在罗马为查理曼加冕称帝。1453年5月29日，穆罕默德二世攻占君士坦丁堡，东罗马国家灭亡。1957年3月25日，《罗马条约》建立欧洲经济共同体和欧洲原子能共同体。只有把地理范围画得足够宽，宽到能容纳罗马、君士坦丁堡和那些签约国，这三项行为才同处一片地域；它们并不属于同一项事业。
:::

## 单一轮廓的代价

把被排除的人放回句子里，看着轮廓失去它的整洁。这种失去本身就是结论，而不是需要修补的问题。

一句古典地理的话，可以涵盖爱琴海、意大利、巴尔干和伊比利亚，而无须裁定哪种信仰才是正统。一旦信仰成为边界，说希腊语的基督徒和安达卢斯的穆斯林就必须被加上限定、作出解释，或者被剔除出去。一句均势的话，可以把苏丹算作一方势力，也把波兰—立陶宛联邦算作一方势力。一旦“欧洲”意味着拉丁西方加上它所青睐的继承者，苏丹就成了入侵者，联邦则成了可以牺牲的缓冲地带。一句关于成员名单的话可以很精确：这些政府签了约，那些没有签。但如果把对签字的精确升格为对谁在这块大陆上拥有历史的裁断，它就变成了错话。

被拉丁地图留在边缘的人，不是杂七杂八的剩余，而是检验本身。拜占庭是拉丁加冕并没有取代的罗马帝国。安达卢斯是“拯救欧洲”传说只能视之为威胁的伊比利亚秩序。奥斯曼帝国是1453年后君士坦丁堡的主权，是1683年兵临维也纳城下的军队，也是犹太人和其他人在其治下生活的政府。犹太社区存在于拉丁城市之中、安达卢斯之中和奥斯曼世界之中，也是1215年第68条教规和1492年《阿尔罕布拉法令》所针对的对象。罗姆人生活在这一名称所声称的土地上，而诞生故事里没有他们，因为诞生故事讲的是王冠和条约。一个整洁的轮廓，通常意味着刚刚下过一刀。[[#def-map]]要求你说明这一刀下在哪里、谁从中获益，以及哪条史料能显示刀口另一侧的人。

这并不是要把这个名称掏空，以致什么也说不了。古典名称有它的使用史，宗教地图有法令、加冕和洗劫，均势有条约和瓜分，成员名单有签约、加入和退出的日期。每一项都可以讲授。无法讲授的——因为它根本不存在——是那个据说以这一切为发展阶段的单一对象。下一章要提出一个本章一直在使用、却没有停下来讨论的先决问题：当有人声称某个民族其实并不在场，只因诞生故事忘了提到他们时，史料能支持什么，沉默又能支持什么。这个问题见[[sources/evidence]]。

## 通向何处

这个名称现在是一组用法，而不是一次诞生。[[sources/evidence]]追问特许状、调查或沉默究竟能见证什么，这是此类论证接下来所需的训练。被单一轮廓写出去的那些继承者，将在[[after-rome/byzantium]]、[[after-rome/islam-in-the-west]]和[[after-rome/carolingians]]中以其自身的地位得到讲授。作为法律和宗教实践的排斥，将在[[christendom/exclusion]]中再次出现。那些并不界定这块大陆的条约，将在[[postwar/welfare-and-treaties]]和[[postwar/union]]中再次出现。

:::summary
- “欧洲”是一个有多种用法的名称，而不是只有一条边界、一套价值观的自然对象。
- 古典地理名称、拉丁基督教世界的地图、均势观念和1957年3月25日的条约组织，是四种不同的对象。
- 711年、800年、1453年和1957年标记的是几幅不同的地图。它们之间的间隔，并不是向一块已完成大陆的缓慢逼近。
- 拜占庭、安达卢斯、奥斯曼帝国、犹太社区和罗姆人都在这片地理范围之内，却常常被写在故事之外。
- 图尔战役没有拯救欧洲，其日期也有争议；1683年并不是“欧洲对亚洲”的永恒事实。
- 1772年、1793年和1795年的瓜分以均衡之名抹去了一个庞大的政治体。均衡不是这片土地的轮廓。
- 欧洲经济共同体是一份成员名单。加入和退出改变的是名单，海岸线并不移动。
- 整洁的单一轮廓，通常意味着已经下过一刀。需要解释的正是这一刀。
:::

## 习题

:::exercise 从渡海到加冕 {level=1 check="89"}
按照“从公元A年到公元B年，经过的年数为B减A”的规则，从711年到800年经过了多少年？（请输入年数。）
:::solution
后一年减前一年，即800减711，等于89。按同一惯例，从800年到843年的跨度是43，这是本图谱对这种算法的核对。答案既不是首尾两年都算的计数，也不意味着这两个日期属于同一个过程。
:::
:::

:::exercise 从加冕到陷落 {level=1 check="653"}
按同一规则，从800年到1453年经过了多少年？（请输入年数。）
:::solution
1453减800等于653。800年12月25日的加冕与1453年5月29日君士坦丁堡的陷落相隔这么多年。这个数字衡量的是纪年上的距离，而不是走向后来某项条约的进步。
:::
:::

:::exercise 条约是什么 {level=1 check="1957"}
建立欧洲经济共同体和欧洲原子能共同体的《罗马条约》签署于哪一年？（请输入年份。）
:::solution
条约签署于1957年3月25日，年份是1957。它们建立的是两个有成员国的条约组织，而不是对这块大陆的界定。煤钢共同体更早：《巴黎条约》签于1951年4月18日，1952年生效。不要把这两项条约压缩成同一个诞辰。
:::
:::

:::exercise 两个日期，一座城市 {level=2}
1204年4月13日和1453年5月29日都与君士坦丁堡有关。请用几句话说明，为什么它们是不同种类的事件，又为什么两者都不是通向1957年3月25日的一步。
:::solution
1204年4月13日，第四次十字军洗劫了君士坦丁堡这座基督教城市，攻城者是拉丁基督徒。那一天，拉丁基督教世界的地图是一件针对东罗马首都的工具，而不是对统一的基督教一方的描述。1453年5月29日，穆罕默德二世攻占这座城市，东罗马国家灭亡，奥斯曼统治随之而来。这是一次主权更迭，而年表拒绝“巴尔干的历史就此终结”这一进一步的论断。1957年3月25日的《罗马条约》，则是晚得多的一批国家之间的一份成员名单。一次洗劫、一次征服和一次签字，彼此并不能互相说明。把它们排进同一个上升过程，就是“倒着走出来的轮廓”这一迷思：一个文明，早早被发现，最终由一项条约完成。这三件事始终是三件事。
:::
:::

:::exercise 会抹去国家的均衡 {level=2}
波兰—立陶宛在1772年、1793年和1795年遭到瓜分，作为国家被抹去。为什么不能把这件事讲成这块大陆只是在找到它的天然轮廓？
:::solution
这个联邦曾是一个庞大的欧洲政治体，而不是地图上的空隙。瓜分是俄国、普鲁士和奥地利的行为。均势叙事可以把结果描述为瓜分各国之间的均衡，但这种描述是关于这些强国利益的论断，既不是地理事实，也不能证明被抹去的国家原本就在欧洲之外。[[#def-map]]把“天然轮廓”这句话看作一幅冒充土地本身的地图。谁从中获益一目了然：夺取了领土的国家，以及任何希望欧洲史只包含幸存者的后来叙事。1713年的乌得勒支和1815年6月9日的维也纳，是列强之间的其他解决方案，它们同样没有发现某种文明。
:::
:::

:::exercise 一个虚构的诞辰 {level=2}
下面这句话为本题而虚构，不是史料：“800年，欧洲作为一个文明诞生；1453年，它从东方手中得救。”请指出哪些锁定的事实推翻了它；如果你用到图尔战役，也请说明围绕这场战役的争议。
:::solution
这句话是一个标签，而不是一份报道。800年12月25日的加冕给了查理曼一个拉丁西方的皇帝称号，却没有创立一个拥有同一套价值观的文明，也没有终结君士坦丁堡的罗马国家。1453年5月29日这座城市的陷落，终结的正是那个东罗马国家；它没有把拉丁基督教世界从“东方”手中解救出来，而奥斯曼的统治也不是巴尔干历史的终结。如果这句虚构的话倚仗的是更早的“拯救欧洲”传说，那么图尔战役的日期本身就有争议——732年10月，或733年、734年——而且它同样没有拯救欧洲：查理·马特当时还不是国王，袭扰仍在继续。1683年9月12日的维也纳解围，是把人引向同一传说的又一个诱饵，而它也不是“欧洲对亚洲”的永恒事实。要把这句虚构的话升格为证据，需要一条写有这句话的史料、一个制作者、一个目的，还需要把史料所显示的内容与后来读者的推论区分开来。即便如此，它所见证的也只是一项主张，而不是一次诞生。[[sources/evidence]]正是以这种区分为全部主题的一章。
:::
:::

:::exercise 名单之外，地方之内 {level=3}
一位读者说：“英国直到1973年都在欧洲之外，因为它不在欧洲经济共同体之内。”请用[[#def-map]]和[[#thm-four]]解释其中的混淆，并说明1973年1月1日改变了什么、没有改变什么。
:::hint
先问这位读者悄悄把四种用法中的哪一种升格成了定义。再问：按照这个名称的地理用法，英国在800年、1453年和1957年身在何处？
:::
:::solution
这位读者把第四种用法——条约组织——当成了土地本身。这正是[[#def-map]]所指出的错误：一条关于边界的论断（这里是成员资格的边界）被当作地方本身来使用。[[#thm-four]]指出，1957年3月25日的成员名单既不是古典名称，也不是拉丁基督教世界，也不是均势。英国不在1957年的名单上，却不在地理范围之外；在这份名单尚不存在的那些世纪里，它也不在欧洲政治史之外。1973年1月1日，英国、爱尔兰和丹麦加入共同体。改变的是名单；没有改变的是海岸线、此前的历史，以及仍未加入的那些国家的地位。同样的检验也适用于后来的历次加入，以及2020年1月31日的退出。一个国家可以退出一个条约组织，却不会因此掉出这块大陆，正如它并不是因为签字才进入这块大陆。
:::
:::

:::exercise 四个日期，没有阶梯 {level=3}
写一句包含711年、800年、1453年和1957年、又不把它们写成单一上升过程的话。然后说明什么证据会构成对你这句话的反证。
:::hint
为每个年份配上一种不同的对象：一次渡海、一次加冕、一次主权更迭、一次签字。反例会是一个确实在这四个日期之间都界定了边界的机构。
:::
:::solution
一句可以接受的话是：711年，一支军队渡海进入伊比利亚，开启了一段不归宗教地图所有的政治史；800年12月25日，一位教皇在罗马为一位法兰克国王加冕称帝，却没有终结东方的罗马国家；1453年5月29日，那个东方国家亡于穆罕默德二世，奥斯曼统治在这片地理范围之内延续下去；1957年3月25日，少数几个国家的政府签署了《罗马条约》，条约列出了成员，却没有界定这块大陆。这句话运用了[[#thm-four]]：它指出了种类各异的行为，也没有说每一项都为下一项作了准备。

能构成反证的，是一条史料，表明有一个连续存在的机构在这些日期之间界定了一条统一的欧洲边界，使那次渡海、那次加冕、那次陷落和那次签字确实是同一主体的相继行为。后来的教科书共用一个名词，做不到这一点。时间线组件也做不到：它可以在一个窗口里显示全部四个点，却按它自己的说明文字拒绝赋予它们诞生的地位。如果读者只有加上“于是欧洲出现了”这半句话，才能把这些日期连起来，那么加上的这半句就是迷思，而不是证据。
:::
