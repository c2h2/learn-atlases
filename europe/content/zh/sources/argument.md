论断、原因与标签之间有什么区别？

[[sources/time-and-names]]把中性的面孔从日期上撕了下来。一个年份可以藏着一个0、一场改革或一个判决，却仍然作为一个光秃秃的数字被印出来。本章把中性的面孔从使用那个数字的句子上撕下来。论断说出发生了什么，以及我们怎么知道。原因是一种更严格类型的论断：它点名某个本可别的东西，并且它有助于解释为什么发生的是这个，而不是那个。标签打包一条论断，常常是好几条，而且常常把它们藏起来。文艺复兴、专制主义（absolutism），以及把威斯特伐利亚（Westphalia）当作主权之诞生，都是标签。它们听起来像时间地图上的地点。它们是披着名词外衣的论证。

一旦你试图检验一个句子，这种区别就重要了。一条论断可以为真或为假，而检验有一个形状：支持它的证据，以及会构成反证的东西，在同一口气里说出，而不是事后道歉。一条原因如果本不可能别样，就通不过检验，因为那样的话它不解释任何差异。如果要求它独自做完全部工作，它同样通不过。一个标签以更安静的方式通不过检验。它感觉太大，不可能是假的。把它拆解成论断，是把它带回读者能够表示异议的那间屋子的方式。我们不会写一部某一个因素为一个后来事件做完全部工作的历史。我们不会说任何结果是预先注定的。这种拒绝的名称已经足够。这一课就是这个区别。

## 一个句子的三种差事

:::definition 论断 {#def-claim}
**论断**说出发生了什么，或过去的一段时期是什么样子，并且它说出我们怎么知道。一条可检验的论断会同时点名它的证据与它的反证。一句话如果说不出什么会构成对它的反证，它就还不是一条论断。它是一种情绪，或者它是一个标签。
:::

:::definition 原因 {#def-cause}
**原因**，在本章之中，是一个有助于解释一个结果、且本可别样的因素。一张时间表、一次干旱、一套教义或一个人的决断，只有在一个没有它的世界可以想象、并且会在我们在乎的那个方面有所不同时，才能作为原因。一个无论如何都会在那里的背景，还不是原因。一个原因不是解释的全部。
:::

:::definition 标签 {#def-label}
**标签**是一个打包了一条或多条论断、并让它们不带证据便旅行的名词。文艺复兴、专制主义，以及把威斯特伐利亚读作主权之诞生，都是标签。这个打包作为指针也许有用。它不是论断的替代品，它本身也不是史料。
:::

三种差事可以坐在同一个段落里而仍然被混淆，这就是下面的图把它们保持为分开的节点的原因。证据系于论断。反证也系于论断。标签系于论断，而在这幅画里，不直接系于证据。那条缺失的线就是这一课。你不被允许倚着名词而跳过存迹。把节点拖来拖去不会造出那条缺失的线。如果一个更丰富的论证有更多的链接，这幅图并没有否认它们。它只画出了本章愿意使用的角色。

:::widget graph
nodes: Claim; Evidence; Counter; Label
edges: Claim-Evidence; Counter-Claim; Label-Claim
algorithm: none
caption: 拖动一个节点。这些边是论证中的角色。一个标签系于一条论断，但它不是证据的替代品。
:::

按顺序读这些边。从Claim到Evidence：这个句子要对一条[[sources/evidence]]所定义的那种存迹负责，一条有制作者、有目的的存迹。从Counter到Claim：那个别扭的事实是句子的一部分，不是批评者到场时你才补上的脚注。从Label到Claim：这个名词只有作为一条你仍可拆解的论断的绰号才被允许。没有一条从Label到Evidence的边，因为一个绰号不会因为熟悉而变得更真。[[#def-label]]就是那条缺失的边，以文字写成。

## 一个你可以检验的句子

本课带编号的论断本身就是那个示例。它关于476年，而且刻意地乏味。在一个可检验的句子里，乏味是一种美德。令人兴奋的地方，通常就是一个标签被走私进来的地方。

:::theorem 476年，奥多亚塞（Odoacer）废黜了罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）；东部的帝国仍在继续；朱利乌斯·尼波斯（Julius Nepos）死于480年 {#thm-476}
这三条子句就是论断。476年的意义是有争议的，而这个论断没有把废黜变成罗马生活的终结、罗马法的终结，或罗马国家本身的终结。反证据在句子之内：东部仍在继续，而另一位西部的帝位宣称者一直活到480年。476年是一个惯例。它不是一个被目击的最后一天。
:::
:::proof
年表锁定了这三条子句与这场争议。奥多亚塞在476年废黜罗慕路斯·奥古斯都鲁斯。那是在意大利的一个行为，有日期、有作为者、有行为的受害者。东部的帝国仍在继续。它的继续不是一种情绪。它是一个仍在立法、征税、作战的国家，[[after-rome/byzantium]]将在查士丁尼（Justinian）之下与它相遇，而不把它当作一个脚注。朱利乌斯·尼波斯，一位对手的帝位宣称者，死于480年。从476年到480年，按通常的公元规则是四年，较晚减较早。一个最后一天不会留给对手皇帝四年可活。历史学家对476年意味着什么意见分歧。分歧是散文的一部分，而不是散文之下的低语。一些读者想要一个西部的覆亡。上面的子句不会把它交给他们。它们交给他们的是一次废黜、一次延续和一次死亡。

能够反驳[[#thm-476]]的，是东部的帝国在476年终结的证据，或尼波斯死于476年而不是480年的证据，或一份同时代的记录，它把“罗马的政治生活今天终结”作为一条以那次废黜曾经作为一个行为的方式被目击的事实——而不是作为后来的惯例。一部称476年为罗马之死的编年史教训，将是作者的教训，而[[sources/evidence]]禁止把那个教训提升为事件。同样会构成对那个论断的一个不诚实版本——一个假装争议并不真实的版本——的反驳的，是伪装本身。意义是有争议的。我们照说。[[rome/later-empire]]讲述更长的背景，从戴克里先（Diocletian）到尼波斯，它拒绝铅、基督教或腐化堕落作为一句话的原因。我们在这里也拒绝那个。论断之所以可检验，是因为每一条子句都可能被证伪。一个叫做“覆亡”的标签不能以同样的方式被证伪，因为它已经先作好了决定。
:::

把[[#thm-476]]放在一个标签旁边，区别就听得出来。“罗马的覆亡”打包了这样几条论断：一个叫做罗马的东西结束了；476年是它结束的那一天；东部的帝国不算作结束的那个东西，或者不算作罗马。这些都不在表面之上。名词在负责打包。拆开之后，第一条论断在你说出什么结束之前是含糊的：一个在意大利的朝廷，一个法律秩序，一种军事习惯，拉丁语的使用，城市的生活。第二条论断是那个惯例，而它有争议。第三条论断对东部的帝国来说是假的——它仍在继续——而对尼波斯来说是难堪的——他死于480年。反证据在任何人道歉之前就是现成的。把它从句子中略去是一个选择，而这个选择偏袒一个西部结束、一个中间时代开始的故事。受益者是那个需要一个干净铰链的说书人。[[#def-label]]点名那个装置。[[#def-claim]]点名那个修补。

四年是一个用途很大而算术很小的例子。它阻止铰链成为一个单一的点。它本身不告诉你那些年的意大利是什么样子，也不告诉你476年没有发生任何重要的事。一次废黜是重要的。重要与盖棺定论不是一回事。一个可检验的句子可以说废黜发生了，同时拒绝盖棺定论。一个标签什么都不能拒绝，因为它不是那种有反证据的对象。这就是为什么Counter节点接触Claim节点，而不接触Label节点。如果你要让反证据起作用，你就必须在制造一条论断。

:::example 拆解铰链 {#ex-unpack-476}
只使用[[#thm-476]]里的子句，把“罗马在476年覆亡了”改写为一条可检验的论断。说出你丢掉了这个口号的哪一部分，以及你必须提到什么争议。
:::solution
一个可检验的替换是：476年，奥多亚塞在意大利废黜了罗慕路斯·奥古斯都鲁斯；东部的帝国仍在继续；朱利乌斯·尼波斯死于480年；476年的意义是有争议的，而这次废黜是西部帝系的终结的一个惯例，不是罗马生活的终结。口号的那个“覆亡”已经被丢掉，因为它打包了一个叫做“罗马”之物的终结，却没有说是哪一个罗马。争议必须在句子之内。历史学家对意义意见分歧，而藏起分歧、保留年份，会把年份变回一个标签。从476年到480年的四年，是坐在论断内部的反证据，与东部的延续一起。[[rome/later-empire]]可以添上410年的劫掠与四世纪的诸敕令。那些添头对于拆解不是必需的，也不是一个单一原因。
:::
:::

## 标签隐藏什么

文艺复兴是一个关于重生论断的标签。标签说，某样东西曾经死去，或者沉睡，然后以新的方式重新学习、绘画或统治。这个论断在做大量的工作，而名词让它旅行，不必说出是什么死了、死在哪里、或任何人如何得知。[[crises/city-states]]把人文主义作为一种实践来讲授：古典拉丁语、教育、文书署、声名。它不是一种叫做现代性的个性，也不是一座城市之陷落生下的孩子。年表没有为文艺复兴锁定一个出生日期，本章也不会发明一个。一个没有锁定端点的绰号本身已经是一个警告。它可以被一直拉伸，直到它讨好作者喜欢的那些世纪。

谁受益？一个想要某一学人的一代人、或某一组意大利城市成为欧洲惊醒之时刻的作者，从重生故事受益。一个需要那代人之前的世纪是一个低谷的作者同样受益。这个受益是情节，是[[sources/time-and-names]]在名字中世纪里面发现的同一个情节。一旦标签被拆解，反证据很容易说出，而且它不需要对学问嗤之以鼻。人文主义的实践是真实的。它不是在一座黑暗大陆上拨下的一个开关。1453年之后希腊书籍的移动是一个真实的联系，而那一年作为人文主义之原因的意义，恰恰是标签所隐藏的那种额外论断。君士坦丁堡在1453年5月29日陷落。人文主义已经是一种实践。一句同时尊重这两个事实的句子是一条论断。“文艺复兴开始于那座城陷落之时”是一个把论断吃掉的标签。

专制主义是一个关于国王的论断的标签。拆开来，那个论断是说：早近代时期的王权是不受约束的，而且往往是一个宫廷向所有别的宫廷展示了它们的未来。这个名词让论断看起来像一个时代。[[states/composite-monarchy]]拒绝这个名词作为整个时代的名字，因为一个国家可以是一个统治者之下的若干王国、拥有若干法律。[[states/fiscal-military]]把一个自我张扬的君主制当作战争、税收与债务的一个解法，而不是全欧洲的模范。一个有特许状与一支船队的共和国，是一个坐在同一批世纪里的反例。你不必在这里讲那个共和国的历史，也能看清逻辑之点。如果标签是一条论断，这个共和国就会构成对它的反驳。而只要它还是一个标签，共和国就被称为例外，而例外被定义为一切不合身的东西。这就是名词保护自己的方式。例外增殖，名词留在原地。一条论断将不得不缩水。

威斯特伐利亚是那个挂着一个真实日子的标签，这使它成为最好的检验。1648年10月24日，《威斯特伐利亚和约》在明斯特（Münster）与奥斯纳布吕克（Osnabrück）订立。1648年1月，西班牙已在明斯特承认了联合省。这个和约调整了1555年9月25日的《奥格斯堡和约》，并把帝国内的加尔文派纳入其中。这些是行为，它们可以被检验。威斯特伐利亚的意义是有争议的。这场争议——这个句子有义务报告的争议——是：这些行为究竟是一个现代主权的诞生，而现代主权被理解为一个完成形态的国家体系理论，还是一个既存的诸强国之间关于帝国条款与宗教条款的一次和解。本图谱把这次和解取为文件所能承受的描述，而把那个完成形态的理论称为一种后来的读法。[[reformations/religious-war]]教授那场战争与诸和约。我们不重述它们，也不给它们一个单一原因。宗教在战争里面。它不是战争里的唯一的东西。一个叫做“主权之诞生”的标签只保留后来的理论，而丢掉条款。

谁从那个标签受益？任何想要一个现代国家的生日、干净到可以在一周内教完的人都受益。诸和约变成一次奠基，它们之前的一切都变成序言。国际法律师与教科书作者想要一条起跑线，并不是恶人。他们是让一个标签替论断干活的读者。会反驳主权诞生读法的，是年表已经说出的东西：这个和约没有发明那个完成形态的理论。会反驳我们更窄的论断的——和约调整了奥格斯堡、把加尔文派纳入帝国、并承认了一个西班牙在一月已经打过交道的共和国——将是做不到这些的和约文本。文本是证据。绰号“威斯特伐利亚”可以留下，作为指向1648年10月24日的一个指针，只要这个指针不被要求去奠基一个世界。

1492年是同一个装置用在一个拥挤的年份上，而1492年的意义是有争议的。这一年装着一场征服、一场驱逐、一次航行。把它叫作近代之诞生，就把这些事件打包进同一次惊醒。[[crises/year-1492]]把它们拆开。我们不在这里重述那些日子。逻辑之点就够了。一个年份数字可以准确，它里面的每一个事件可以真实，而缠在年份上的标签仍然是一条不曾被挣得的论断。对数字的准确不是对打包的准确。[[sources/time-and-names]]为历法讲过这一点。它对口号同样成立。

:::theorem 标签不会因为被重复就成为证据 {#thm-label}
文艺复兴、专制主义、以及作为主权之诞生的威斯特伐利亚，每一个都打包了一条论断，并把打包藏在一个名词里面。重复、熟悉、在章节标题里的一席之地，都不会把名词提升为史料。论断只有当它可以被拆解、可以在日期锁定之处安放日期、并暴露于反证据时，才能被保留。
:::
:::proof
这三个名词在使用中从未间断，这正是一个标签可以不带理由旅行的证据。它们没有一个是特许状、一个和约文本或一次调查。1648年10月24日的和约是一份史料。“主权之诞生”不是。人文主义的书籍与文书署的习惯是一种实践的证据。“文艺复兴”不是坐在它们旁边的又一份史料。国王的敕令是关于一个国王命令了什么的史料。“专制主义”不是他在多大程度上被服从的一个测量。[[#def-label]]与[[#def-claim]]分开这两对。一旦把这对分开，谁受益就看得见了：重生故事为一个惊醒的欧洲服务，专制主义故事为一个单一的国家模型服务，而主权故事为一个干净的生日服务。受益本身不会使论断为假。它们解释了这些名词为什么如此难以放下。

能够反驳[[#thm-label]]的，是一个显示这些名词中某一个本身就是[[sources/evidence]]意义上有制作者、有目的的存迹、而不是一束后来的打包的论证。一首使用某个词的该时期的诗，是那种用法的史料。它不证明现代的课程名词早已是一个自然事实。能够反驳一种更苛刻的读法——禁止一切标签的读法——的，是把一个绰号当作一个指针、并立刻把它拆开的无害用法。我们不禁止指针。我们禁止的是指针取代证据的那个时刻。那幅图里缺失的边，从Label到Evidence，就是同一条规则以墨水写成。
:::

:::example 那个作为和约的诞生 {#ex-westphalia}
在几句话里，把1648年的行为与“威斯特伐利亚创建了现代主权”这个标签分开。什么是争议，什么是后来的读法？
:::solution
1648年1月，西班牙在明斯特承认了联合省。1648年10月24日，《威斯特伐利亚和约》在明斯特与奥斯纳布吕克订立。它调整了1555年9月25日的《奥格斯堡和约》，并把帝国内的加尔文派纳入其中。这些就是一条论断所能承载的行为。威斯特伐利亚的意义是有争议的。把和约读作现代主权的完成形态理论的诞生，是一种后来的读法，本图谱不采用它。[[#thm-label]]把那种读法当作系于一条论断的标签，而不是证据。[[reformations/religious-war]]讲述那场战争，而不让诸和约发明一个国家体系。一个单一原因，宗教的或其他，这里没有供应。对那个生日的反证据，包括诸和约实际处理的有限的教会职务事务与帝国事务。威斯特伐利亚这个词的熟悉并不结束争议。
:::
:::

## 一条原因必须能够被证伪

[[#def-cause]]是这一课最常被跳过的部分，因为一条原因是奉承人的。它让作者看起来像找到了引擎的那个人。检验不客气，而且简单。它本可以别样吗？如果你点名的那个因素在故事的每一个版本里都将在场，你点名的是一个背景，不是一个原因。如果你点名了一个真实的因素、然后让它吃掉其他一切因素，你就写了一部单一原因的历史，而本章不会为任何后来的事件那样做。

七月危机是向前的案例，而且它只是一个指针。完整叙事在[[nations/toward-1914]]。我们不在这里讲它。我们不逐条推进最后通牒，也不描述一场战争。方法需要一个区分。历史学家对那场危机是一组选择还是一张时间表意见分歧。分歧是必需项，不是可选项。一张时间表可以约束一个政府，而仍然留下选择。只有在不同的选择是可能的、并且本来会重要的地方，一个约束才是那种更严格意义上的原因。一张被当作命运对待的时间表已经通不过[[#def-cause]]，因为命运不可能别样。讲授那场危机的章节必须把选择与约束保持在同一个画框里。本章只坚持两点：画框是可能的；以及像“通向战争之路”这样的标签，被当作一条没有出口的路来用，就又是标签的问题。从本章出发，那场危机中的任何结果，都不作为在任何人事先行动之前就注定的来教。

同一个检验保护476年，使它免于它的崇拜者。废黜发生了。它不是每一个后来的欧洲安排的原因，而东部的帝国的继续，正是阻止句子膨胀的那个事实。原因有一个尺度，它是[[sources/scale]]的主题。在这里，下面这点就够了：一个解释一切的原因，什么也不可检验地解释。你说不出什么会构成对它的反证。

因此，反证据不是在论断被鼓掌之后补上去的客套。它是论断的语法的一部分。如果东部的帝国与480年的死亡被留到一段反驳段落，[[#thm-476]]将是一个更坏的句子。读者本来会被邀请先相信铰链、之后再怀疑它，而许多读者永远到不了后面那个段落。把反证据放进带编号的论断，就是纪律。它使句子更长。它也使它诚实。标签之所以短，是因为它们解雇了保存反证据的职员。

:::example 一个发明出来的引擎 {#ex-invented-engine}
下面这句话为示例而虚构。它不是史料，也不是本图谱做出的论断。“威斯特伐利亚造成了现代国家，一旦那个原因就位，后来的欧洲的形态就不可能别样了。”什么是标签，什么是冒充的原因，这句话怎么失败？
:::solution
标签是现代国家之诞生，藏在威斯特伐利亚这个名字里面。冒充的原因是1648年10月24日的和约，被要求独自产生一个完整的后来形态。那是一部后来事件的单一原因的历史，本章拒绝它。它也通不过[[#def-cause]]，因为一个不给事物留下别样可能的因素，不是我们这个意义上的原因。它是一个穿日期的命运。威斯特伐利亚的意义是有争议的，而主权的完成形态理论是一种后来的读法，所以这句话对诸和约来说是假的，作为解释也是空的。反证据属于论断：1648年1月与1648年10月24日调整了一个宗教和约、承认了一个共和国，而它们没有奠基一个大陆。[[#thm-label]]是这句虚构的话打破的规则。提升为证据——[[sources/evidence]]意义上的——甚至无从开始，因为这句话除了我们之外没有制作者。
:::
:::

:::example 约束之下的选择 {#ex-july}
不在叙述危机的情况下，说出一个时间表能够对一个政府做什么，不能做什么，以及叙事住在哪里。提到年表所要求的分歧。
:::solution
一张时间表可以约束一个政府。它可以使某些序列代价高昂、仓促或难以逆转。它不能取消选择，也不能把一场危机变成命运。历史学家对七月危机是一组选择还是一张时间表意见分歧。分歧留在句子里面。完整叙事在[[nations/toward-1914]]，不在这里讲。[[#def-cause]]是你带进那一章的检验：一个因素只有当它本可别时，才赢得原因这个名字。一条像“没有出口的路”这样的标签，以专制主义和重生故事通不过它的同样方式，通不过[[#thm-label]]。没有死亡总数、没有最后通牒、没有战役属于这个答案。
:::
:::

:::quiz
按本章的检验，一个因素在什么时候不成其为一个原因？
- [ ] 当它有日期的时候，因为日期是标签
- [ ] 当反证据在同一个句子里被提到的时候
- [x] 当它本不可能别样时，或者当它被要求独自解释一个后来的事件时
- [ ] 当历史学家意见分歧的时候，因为分歧取消了那个因素
:::solution
[[#def-cause]]要求那个因素本可别。一部后来事件的单一原因的历史，即使那个因素是真实的，也通不过。日期不是问题。[[sources/time-and-names]]使日期可检验。反证据属于论断内部，所以提到它是成功，不是失败。分歧不取消一个因素。在七月危机里，分歧——选择还是时间表——是必须说出的东西之一，而叙事留在[[nations/toward-1914]]。

:::warning 吃掉证据的那个名词
常见的迷思说，一个时代有一种精神，而那种精神就是其中之人所做之事的原因。文艺复兴、专制主义、以及在威斯特伐利亚诞生的主权国家，是这个迷思宠爱的名词。它们作为原因失败，因为一种精神不可能别样；它们作为论断失败，因为没有任何指明过的东西会构成对它们的反证。它们作为标签成功，而这就是危险。476年，作为覆亡来读，是同一个穿了罗马衣裳的迷思。废黜发生了。东部的帝国仍在继续。尼波斯死于480年。意义是有争议的。一个后来危机中的时间表可以约束一个政府，而仍然留下选择。这些结果没有一个曾在某个名词里面完整等待着。
:::

:::history
476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。东部的帝国仍在继续，而朱利乌斯·尼波斯死于480年。1648年10月24日，《威斯特伐利亚和约》在明斯特与奥斯纳布吕克订立。前一组是一次带着反证据的废黜。后一次是一个意义有争议的和约，不是一个完成形态的主权理论的发明。
:::

## 当故事喧嚣起来时守住语法

在一个关于语法的章节里，语法是容易的；在一个关于一场战争、一场改革或一场革命的章节里，它是难的。那些后来的章节将挤满真实的原因：一场财政危机，一套教义，一套动员方案，一次投票。可以带走的纪律不是禁止解释。它是禁止两种捷径。第一种捷径让一个原因为每一个后来的章节做全部工作。第二种捷径用一个标签替换原因，然后把标签当作太体面而不能检验的东西。如果你发现自己在写一种精神、一个时代或一条路产生了结果，你就同时踏上了两种捷径。

你可以在任何你欣赏的句子上练习这个修补。问发生了什么，用一个固执的读者可以否认的子句去问。问你怎么知道，点名的是一条存迹，而不是一个教科书的传统。问什么会构成对那个子句的反证，并把那个反证据放在读者会在掌声之前遇到它的地方。然后问你的因素本可别吗。如果你想象不出别样，你手上是一个背景，而背景属于描述，不属于引擎。[[#thm-476]]之所以是范本，只因为事实小到足以装进一个句子。当事实变成一生、一座庄园、一个王国或一桩贸易，而一个在某个尺度上为真的句子被要求去做另一个尺度的工作时，[[sources/scale]]所要求的正是同一个语法。

跳过语法的人受益，并非谜。一个短标签放得进标题、考试题目和一场演说。一个可检验的句子放得进一条页边，有人可以在那里写下尼波斯死于480年，从而拒绝你的铰链。标签的好处是速度。代价是你再也分不清史料与口号，而那正是[[sources/evidence]]存在的目的所要教授的技艺。日期、论断、原因、标签是四种不同的工具。用最光鲜的那一件去干每一种活，正是一部欧洲概览变回迷思的方式。

## 通向何处

论断从此成为一种可以在公众面前被证伪的东西。[[sources/scale]]问：一个在某个尺度上为真的故事什么时候在另一个尺度上变假，那是一个原因走岔的下一个地方。476年的废黜被安放在[[rome/later-empire]]里一段更长的罗马史中。1648年的和约在[[reformations/religious-war]]里作为一个和约来教，而不是作为主权理论。七月危机——选择处于一张时间表之下——是[[nations/toward-1914]]，不在这里讲。文艺复兴与专制主义这两个标签在[[crises/city-states]]与[[states/composite-monarchy]]里再次承压。

:::summary
- 论断说出发生了什么、我们怎么知道，并且它把反证据包括在内。一句话如果没有任何会构成对它的反证的东西，它就还不是一条论断。
- 原因是一个本可别的因素。一个预先注定的背景不解释差异，而一个原因不是整部历史。
- 标签打包论断并把它们藏起来。文艺复兴、专制主义、以及作为主权之诞生的威斯特伐利亚，是标签，不是史料。
- 476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。东部的帝国仍在继续。朱利乌斯·尼波斯死于480年。476年的意义是有争议的。那是一个可检验的句子。
- 1648年10月24日，在明斯特与奥斯纳布吕克订立的和约调整了奥格斯堡，并把加尔文派纳入帝国。现代主权的完成形态理论是一种后来的读法。
- 1492年的意义是有争议的。一个拥挤的年份不会因为数字准确就是近代之诞生。
- 历史学家对七月危机是一组选择还是一张时间表意见分歧。一张时间表可以约束一个政府，而仍然留下选择。叙事在别处。
- 那幅图把证据与反证据系于论断，而把标签只系于论断。熟悉不是通向证据的一条边。
:::

## 习题

:::exercise 哪种差事 {level=1}
说出“专制主义解释了这个时代”这句话所做的差事：论断、原因，还是标签。
:::solution
这句话是一个在做原因的工作的标签。专制主义，按[[#def-label]]，打包了一条关于不受约束的诸王的论断，并把它呈现为一个时代的名字。当被要求“解释这个时代”时，它还冒充原因。它通不过[[#def-cause]]，因为一种时代精神不可能别样，而且它通不过那个禁止一个因素做完全部工作的禁令。[[states/composite-monarchy]]拒绝这个名词作为时代的名字。修补是关于一个特定的统治者、一种特定的税或一场特定的战争的论断，并允许反证据进来。
:::
:::

:::exercise 年数之差 {level=1 check="4"}
按照“从公元A年到公元B年的已过跨度是B减A”的规则，从476年到480年经过了多少年？（请输入年数。）
:::solution
480减476是4。这四年是罗慕路斯·奥古斯都鲁斯被废黜之后，朱利乌斯·尼波斯仍然在世的那段区间。它们是对以下论断的反证据：476年是罗马帝制生活本身的终结。它们不是一个衰落的故事，也不是一个首尾计入的五年的计数。答案是4。
:::
:::

:::exercise 说出那一天 {level=1}
1648年10月24日订立了什么，而本图谱拒绝把哪一个后来的读法当作诸和约自己的理论？
:::solution
《威斯特伐利亚和约》在明斯特与奥斯纳布吕克订立。它调整了《奥格斯堡和约》，并把加尔文派纳入帝国。1648年1月，西班牙已在明斯特承认了联合省。本图谱拒绝当作诸和约自己的理论的那个后来的读法，是现代主权的完成形态理论。威斯特伐利亚的意义是有争议的。[[#thm-label]]把那个生日留在诸标签中间。[[reformations/religious-war]]守住那场战争。
:::
:::

:::exercise 没有生日的重生 {level=2}
年表没有为文艺复兴锁定第一个年份。1453年5月29日是君士坦丁堡的陷落。为什么“文艺复兴开始于那座城陷落之时”是一个标签而不是一条论断？不用那个名词，你能点名哪一种实践？
:::solution
这句话把一个重生、一个原因、一个生日打包进一个由名词驱动的故事。文艺复兴的生日没有被锁定，所以这句话发明了一个[[sources/time-and-names]]本来就会拒绝的接缝。1453年5月29日那座城的陷落是一个真实事件。人文主义，按[[crises/city-states]]的用法，已经是一种古典拉丁语、教育、文书署与声名的实践。一条论断可以同时说出这两样东西。它不能让那座城的陷落成为一个已经在进行的实践的原因，也不能让“文艺复兴”替代证据。受益者是那个大陆正在惊醒的情节。[[#thm-label]]是规则。反证据是不等待1453年的那种实践。
:::
:::

:::exercise 一个名词，若干王国 {level=2}
如果专制主义被作为一条论断使用，为什么一个复合君主制构成对它的反驳？如果专制主义被作为标签保护起来，为什么它就不构成反驳？
:::solution
拆开之后，专制主义主张那个时期的王权不受约束，并且一个模型覆盖诸国家。一个复合君主制是一个统治者之下的若干王国、拥有若干法律。这个事实可以在一个强大的国王旁边为真，而它构成对那个不受约束的、整齐划一的模型的反驳。[[states/composite-monarchy]]正因如此拒绝这个名词作为整个时代的名字。如果这个名词只是一个标签，复合的案例就被归档为例外，而例外被定义为一切不合身的东西，于是这个名词永远遇不到反证据。[[#def-label]]描述了那种保护。一个财政—军事君主制仍然可以是战争与税收的一个真实的解法，正如[[states/fiscal-military]]所教授的，而不必是每一个国家的模式。修补是关于一个特定的王冠的论断，小到足以被证伪。
:::
:::

:::exercise 指针与叙事 {level=2}
一个同学要你在本章里用一个原因解释七月危机，好让后面那一章不必被读。你拒绝什么，你报告什么分歧，你把叙事送到哪里？
:::solution
你拒绝一部后来事件的单一原因的历史，你拒绝任何把结果教成在任何人事先行动之前就注定的教法。历史学家对七月危机是一组选择还是一张时间表意见分歧。你报告那个分歧。一张时间表可以约束一个政府，而仍然留下选择，而在这样远的距离上，[[#def-cause]]需要说的就是这些。叙事留在[[nations/toward-1914]]。在这里讲那些最后通牒会打破本章的限度，而发明一个死亡总数会打破本图谱。同学的要求是“路”这个标签，要求被当作证据。[[#thm-label]]说路不是通向证据的一条边。那幅图没有画这样一条边。
:::
:::

:::exercise 造一个可检验的句子 {level=3}
只用476与480，写出一个可检验的句子，它包括反证据，说出争议，而且不是“罗马覆亡了”这个口号。然后说，什么会构成对你的句子的反证。
:::hint
三条子句：一次废黜，一次延续，一次死亡。争议在意义上，不在奥多亚塞是否采取了行动上。
:::
:::solution
一个可以接受的句子就是[[#thm-476]]里的那个论断：476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯；东部的帝国仍在继续；朱利乌斯·尼波斯死于480年；476年的意义是有争议的，而这一年是一个西部废黜的惯例，不是罗马生活的终结。反证据是延续与到480年的四年，因为480减476是4。会构成对它的反证的是：东部的帝国在476年终结的证据，或尼波斯死于476年的证据，或一份记录，其中罗马政治生活的终结本身就是被目击的行为，而不是后来的解释。一个只是宣布一个覆亡的编年史教训不算那份记录。[[sources/evidence]]把教训留在作者那一侧的线旁。一个叫做覆亡的标签不会因为更短而变得更可检验。
:::
:::

缺失的边禁止你把那个名词当作它自己就触及诸和约。1648年1月，西班牙在明斯特承认了联合省。1648年10月24日，明斯特与奥斯纳布吕克产生了一个和约，它调整了奥格斯堡——1555年9月25日的和约——并把加尔文派纳入帝国。那些条款是一个关于和解的论断的证据。它们不是现代主权之完成形态理论的证据。那个理论是一种后来的读法，而威斯特伐利亚的意义是有争议的。[[#thm-label]]就是散文里的那条缺失之边。会构成对那幅画的反驳的，是显示那个标签本身就是一份史料，一条有制作者、有目的的存迹，而不是一束系于论断的打包。一个重复这个名词的章节标题做不到这一点。一个短名字的好用也做不到，只要这个名字被立刻拆开。如果诸和约曾用年表不给它们的那些词语宣布那个理论，那个关于后来的读法的论断就将不得不缩水。这里没有给它们那些词语。图可以被拖来拖去。拖拽不会发明那条被禁止的边。
