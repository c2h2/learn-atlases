论断、原因与标签之间有什么区别？

[[sources/time-and-names]]揭去了日期的中性外表：一个年份可以藏着一个0、一次改革或一个判决，却照样以光秃秃的数字印出来。本章要揭去的，是使用这个数字的句子的中性外表。论断说明发生了什么，以及我们如何知道。原因是更严格的一类论断：它指出某个本来可能不同的因素，并且有助于解释为什么发生的是这件事而不是那件事。标签则把一条论断——往往是好几条——打包起来，而且常常把它们藏起来。文艺复兴、专制主义（absolutism），以及把威斯特伐利亚（Westphalia）视为主权的诞生，都是标签。它们听起来像时间地图上的地名，实际上是披着名词外衣的论证。

一旦试图检验一个句子，这种区别就变得重要。论断可真可假，检验也有固定的形式：支持它的证据，以及可能构成反证的证据，要一并说出，而不是事后再来致歉。原因如果本来不可能不同，就通不过检验，因为那样它解释不了任何差异；如果要它独自承担全部解释，它同样通不过。标签通不过检验的方式更隐蔽：它显得太大，大到似乎不可能是错的。把它拆解成若干论断，才能把它带回读者可以提出异议的地方。我们不会写那种让单一因素包揽某个后来事件全部解释的历史，也不会说任何结果是预先注定的。点出这种拒绝就够了，这一课要讲的是其中的区别。

## 句子的三种职能

:::definition 论断 {#def-claim}
**论断**说明发生了什么，或过去某段时期是什么样子，并说明我们如何知道。可检验的论断会同时指出自己的证据和反证。一句话如果说不出什么会构成对它的反证，就还算不上论断，而只是一种情绪，或者一个标签。
:::

:::definition 原因 {#def-cause}
本章所说的**原因**，是有助于解释某一结果、而本来可能不同的因素。一张时间表、一场干旱、一套教义或某个人的决定，只有在可以设想一个没有它的世界、而那个世界在我们关心的方面会有所不同时，才能算作原因。无论如何都会存在的背景，还算不上原因。单个原因也不是全部解释。
:::

:::definition 标签 {#def-label}
**标签**是一个名词，它把一条或多条论断打包，让它们脱离证据四处流传。文艺复兴、专制主义，以及把威斯特伐利亚解读为主权的诞生，都是标签。这样的打包作为指引或许有用，但它不能代替论断，本身也不是史料。
:::

三种职能可以同处一段文字而依然混淆不清，所以下图把它们画成彼此分开的节点。证据连向论断，反证也连向论断。标签连向论断，但在这幅图上并不直接连向证据。缺的这条线就是本课的要点：你不能倚仗名词而跳过存迹。把节点拖来拖去，也造不出这条缺失的线。更丰富的论证或许有更多联系，这幅图并不否认它们，只是画出了本章愿意使用的几种角色。

:::widget graph
nodes: Claim; Evidence; Counter; Label
edges: Claim-Evidence; Counter-Claim; Label-Claim
algorithm: none
caption: 拖动节点。这些边代表论证中的各种角色。标签连向论断，但不能代替证据。
:::

按顺序读这些边。从Claim到Evidence：句子要对[[sources/evidence]]所界定的那种存迹负责，即有制作者、有目的的存迹。从Counter到Claim：那个令人为难的事实是句子的一部分，而不是等批评者出现才补上的脚注。从Label到Claim：这个名词只有作为一条仍可拆解的论断的简称，才被允许使用。从Label到Evidence没有边，因为简称不会因为耳熟就变得更真。[[#def-label]]就是用文字表述的这条缺失的边。

## 可以检验的句子

本课编号的论断本身就是示例。它关乎476年，而且有意写得平淡。对可检验的句子来说，平淡是一种美德；令人兴奋之处，往往正是标签被偷运进来的地方。

:::theorem 476年，奥多亚塞（Odoacer）废黜罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）；东部帝国继续存在；朱利乌斯·尼波斯（Julius Nepos）死于480年 {#thm-476}
这三个分句就是论断。476年的意义有争议，而这条论断并没有把这次废黜变成罗马生活、罗马法或罗马国家本身的终结。反证就在句子之内：东部依然延续，另一位西部帝位主张者一直活到480年。476年是一种惯例，而不是有人亲眼目睹的最后一天。
:::
:::proof
年表锁定了这三个分句以及这场争议。476年，奥多亚塞废黜罗慕路斯·奥古斯都鲁斯。这是发生在意大利的一个行为，有日期，有施行者，也有承受者。东部帝国继续存在。这种延续不是一种情绪，而是一个仍在立法、征税、作战的国家；[[after-rome/byzantium]]将在查士丁尼（Justinian）时代与它相遇，而不会把它当作脚注。帝位的另一位主张者朱利乌斯·尼波斯死于480年。按通常的公元规则，以后者减前者，从476年到480年是四年。真正的最后一天不会给一位对立皇帝留下四年的寿命。历史学家对476年的意义看法不一。这种分歧属于正文本身，而不是正文底下的低语。有些读者想要一个“西部的覆亡”，上面的分句不会给他们；它们给出的是一次废黜、一种延续和一次死亡。

能够推翻[[#thm-476]]的，是东部帝国在476年终结的证据，或尼波斯死于476年而非480年的证据，或者一份同时代的记录，表明“罗马的政治生活今日终结”是像那次废黜一样被目睹的事实，而不是后来的惯例。一部编年史若把476年说成罗马之死，那是作者的教训，而[[sources/evidence]]禁止把这种教训升格为事件。至于这条论断的不诚实版本——假装争议并不存在的版本——推翻它的正是这种假装本身。意义有争议，我们就照实说。[[rome/later-empire]]讲述从戴克里先（Diocletian）到尼波斯的更长背景，并拒绝用铅中毒、基督教或颓废一句话充当原因；我们在这里同样拒绝。这条论断之所以可检验，是因为每个分句都可能被证伪。名为“覆亡”的标签却不会以同样的方式被证伪，因为它事先已经下了结论。
:::

把[[#thm-476]]放在一个标签旁边，差别一听便知。“罗马的覆亡”打包了几条论断：名为罗马的某种东西终结了；476年是它终结的那一天；东部帝国不算作终结的那个东西，或者不算罗马。这些都不在字面上，打包是由名词完成的。拆开来看，第一条论断在你说清楚终结的是什么之前都很含糊：是意大利的一个宫廷、一种法律秩序、一种军事习惯、拉丁语的使用，还是城市生活？第二条论断就是那个惯例，而它有争议。第三条论断对东部帝国而言是错的，因为它继续存在；对尼波斯而言也说不通，因为他死于480年。反证早在任何人致歉之前就摆在那里。把它们排除在句子之外是一种选择，这种选择偏向于一个西部终结、中世纪开始的故事。获益的是需要一个干净转折点的讲述者。[[#def-label]]指出了这种手法，[[#def-claim]]指出了修补的办法。

四年是一笔用途很大的小算术。它让转折点不再是一个单一的点。它本身并不能告诉你那几年意大利的情形，也不能说明476年没有发生任何重要的事。废黜当然重要，但重要不等于终局。可检验的句子可以说废黜发生了，同时拒绝终局之说。标签却什么也拒绝不了，因为它根本不是那种会有反证的东西。所以Counter节点与Claim节点相连，而不与Label节点相连。想让反证起作用，你就必须是在提出论断。

:::example 拆解转折点 {#ex-unpack-476}
只用[[#thm-476]]中的分句，把“罗马在476年覆亡”改写成一条可检验的论断。说明你去掉了这个口号的哪一部分，以及你必须提及什么争议。
:::solution
一个可检验的改写是：476年，奥多亚塞在意大利废黜罗慕路斯·奥古斯都鲁斯；东部帝国继续存在；朱利乌斯·尼波斯死于480年；476年的意义有争议，这次废黜是标志西部帝系终结的惯例，而不是罗马生活的终结。口号中的“覆亡”被去掉了，因为它打包了“罗马”的终结，却没有说是哪一个罗马。争议必须写进句子。历史学家对其意义看法不一；隐去分歧而保留年份，会让年份重新变回标签。从476年到480年的四年，连同东部的延续，就是包含在论断之内的反证。[[rome/later-empire]]可以补充410年的劫掠和4世纪的历次敕令，但这些补充并不是拆解所必需的，也不构成单一原因。
:::
:::

## 标签掩盖了什么

文艺复兴是一个关于“重生”的论断的标签。按照这个标签，某种东西曾经死去或沉睡，后来又以新的方式重新学习、绘画或统治。这条论断承担了大量工作，而名词让它得以流传，不必说明死去的是什么、在哪里死去、人们又如何得知。[[crises/city-states]]把人文主义当作一种实践来讲：古典拉丁语、教育、文书机构、声名。它不是一个名叫“现代性”的人格，也不是某座城市陷落所生的孩子。年表没有为文艺复兴锁定诞辰，本章也不会杜撰一个。一个没有锁定起止点的简称，本身就是一个警告：它可以被一再拉伸，直到迎合作者偏爱的那几个世纪。

谁获益？想让某一代学者或某几座意大利城市成为欧洲觉醒时刻的作者，从重生故事中获益；需要把那代人之前的几个世纪说成低谷的作者，同样获益。所获之益就是情节，与[[sources/time-and-names]]在“中世纪”这个名称中发现的情节如出一辙。标签一旦拆开，反证很容易说出，而且无须贬低那些学问。人文主义的实践是真实的，但它并不是在一片黑暗大陆上拨动的开关。1453年以后希腊典籍的流传是真实的联系，而把那一年当作人文主义原因的意义，恰恰是标签所掩盖的那种额外论断。君士坦丁堡于1453年5月29日陷落，而人文主义当时已经是一种实践。同时尊重这两个事实的一句话，是一条论断；“文艺复兴始于那座城市陷落之时”，则是一个吞掉了论断的标签。

专制主义是一个关于国王的论断的标签。拆开来看，这条论断说的是：近代早期的王权不受制约，而且往往还说某一个宫廷向其他所有宫廷预示了它们的未来。这个名词让论断看起来像一个时代。[[states/composite-monarchy]]拒绝用这个名词命名整个时代，因为一个国家可以是同一位君主治下的几个王国，各有各的法律。[[states/fiscal-military]]把一个大肆张扬的君主国看作应对战争、税收和债务问题的一种方案，而不是全欧洲的范本。一个拥有特许状和一支船队的共和国，就是同一时期中的反例。不必在这里讲述那个共和国的历史，也能看清其中的逻辑：如果这个标签是一条论断，那个共和国就会构成反驳；只要它还是标签，共和国就被称为例外，而所谓例外，就是一切不符合的东西。名词就是这样自我保护的：例外越来越多，名词却纹丝不动。换作论断，就不得不收缩。

威斯特伐利亚是附带一个真实日子的标签，因此是最好的检验。1648年10月24日，《威斯特伐利亚和约》在明斯特（Münster）和奥斯纳布吕克（Osnabrück）缔结。1648年1月，西班牙已在明斯特承认联合省。这一和约调整了1555年9月25日的《奥格斯堡和约》，并把加尔文派纳入帝国。这些都是行为，可以检验。威斯特伐利亚的意义有争议，而这句话有义务交代这场争议：这些行为究竟是现代主权的诞生——即一套成形的国家体系理论的诞生——还是既有列强之间就帝国条款和宗教条款达成的一次解决。本图谱认为“解决”才是这些文件所能支撑的描述，而把那套成形的理论称为后来的解读。[[reformations/religious-war]]讲授这场战争和这些条约。我们不再复述，也不为它们指定单一原因。宗教是这场战争的一部分，但不是全部。名为“主权的诞生”的标签只保留了后来的理论，而丢掉了条款。

谁从这个标签中获益？凡是想为现代国家找一个生日、而且干净到一周就能教完的人，都会获益。条约变成了一次奠基，此前的一切都成了序言。国际法学者和教科书作者想要一条起跑线，并不因此就是恶人；他们只是让标签替论断做了工作的读者。能够推翻“主权诞生”这一解读的，是年表已经说明的事实：这一和约并没有发明那套成形的理论。能够推翻我们这条较窄论断的——和约调整了奥格斯堡和约，纳入了加尔文派，并承认了西班牙在1月已与之打过交道的一个共和国——则是并没有做这些事的条约文本。文本就是证据。“威斯特伐利亚”这个简称可以保留，用来指向1648年10月24日，只要不要求这个指引去奠定一个世界。

1492年是同样的手法用在一个事件密集的年份上，而1492年的意义也有争议。这一年包含一场征服、一次驱逐和一次航行。把它称为近代的诞生，就是把这些事件打包成同一次觉醒。[[crises/year-1492]]把它们重新拆开。我们不在这里复述那些日子，逻辑上的要点就够了：年份数字可以准确无误，其中的每个事件也都可以是真实的，而包裹这个年份的标签，仍然可能是一条未经证明的论断。数字的准确不等于打包的准确。[[sources/time-and-names]]就历法讲过这一点，它同样适用于口号。

:::theorem 标签不会因为反复使用而成为证据 {#thm-label}
文艺复兴、专制主义和作为主权诞生的威斯特伐利亚，都各自打包了一条论断，并把打包藏在名词之中。反复使用、耳熟能详、在章节标题里占有一席之地，都不能把名词升格为史料。论断只有在能够拆解、能在日期锁定之处标明日期、并接受反证检验的情况下，才能保留。
:::
:::proof
这三个名词一直被频繁使用，这本身就证明标签可以脱离理由而流传。它们没有一个是特许状、条约文本或调查记录。1648年10月24日的条约是史料，“主权的诞生”不是。人文主义的书籍和文书机构的习惯是一种实践的史料，“文艺复兴”并不是与之并列的又一份史料。王室敕令是国王下了什么命令的史料，“专制主义”却不是衡量他在多大程度上得到服从的尺度。[[#def-label]]和[[#def-claim]]把每一对区分开来。一经区分，谁获益就清楚了：重生故事服务于一个觉醒的欧洲，专制主义故事服务于单一的国家模式，主权故事服务于一个干净的生日。获益本身并不使这些论断为假，但它解释了这些名词为何如此难以放下。

能够推翻[[#thm-label]]的，是证明其中某个名词本身就是[[sources/evidence]]意义上有制作者、有目的的存迹，而不是后人的打包。那个时期的一首诗用了某个词，它是这种用法的史料，却不能证明现代课程表上的这个名词早已是自然事实。能够推翻另一种更苛刻解读——即一概禁止标签——的，是把简称当作指引并随即拆开的无害用法。我们不禁止指引，禁止的是指引取代证据的那一刻。图中从Label到Evidence的那条缺失的边，就是用笔墨画出的同一条规则。
:::

:::example 一次被当作诞生的和约 {#ex-westphalia}
用几句话把1648年的行为与“威斯特伐利亚奠定了现代主权”这一标签区分开来。什么有争议？什么是后来的解读？
:::solution
1648年1月，西班牙在明斯特承认联合省。1648年10月24日，《威斯特伐利亚和约》在明斯特和奥斯纳布吕克缔结。它调整了1555年9月25日的《奥格斯堡和约》，并把加尔文派纳入帝国。这些就是论断所能承载的行为。威斯特伐利亚的意义有争议。把和约读作一套成形的现代主权理论的诞生，是后来的解读，本图谱不采用。[[#thm-label]]把这种解读视为连向论断的标签，而不是证据。[[reformations/religious-war]]讲述这场战争，而不让这些条约去发明一个国家体系。这里不提供任何单一原因，无论是宗教的还是别的。反驳这个“生日”的证据，包括这些条约实际处理的那些有限的教会事务和帝国事务。“威斯特伐利亚”一词的耳熟能详，并不能终结这场争议。
:::
:::

## 原因必须可能被证伪

[[#def-cause]]是本课最常被跳过的部分，因为原因讨人喜欢：它让作者看上去像是找到了发动机的人。检验既不客气，又很简单：它本来可能不同吗？如果你指出的因素在故事的每一个版本中都必然存在，那么你指出的是背景，而不是原因。如果你指出了一个真实的因素，却让它吞没了其他所有因素，你写的就是单一原因的历史，而本章不会为任何后来的事件这样做。

七月危机是一个前瞻性的案例，在这里只作为指引。完整的叙述见[[nations/toward-1914]]，这里不讲。我们不逐一罗列最后通牒，也不描述战争。方法所需要的只是一个区分。历史学家对这场危机究竟是一系列选择还是一张时间表看法不一，这种分歧是必须交代的，而非可有可无。时间表可以约束一个政府，却仍然留下选择余地。约束只有在不同的选择确有可能、而且会产生影响时，才是那种更严格意义上的原因。被当作命运的时间表通不过[[#def-cause]]，因为命运不可能不同。讲授这场危机的那一章，必须把选择和约束放在同一个框架里。本章只坚持两点：这样的框架是可能的；而像“通往战争之路”这样的标签，如果被当作一条没有出口的路来用，就又回到了标签问题。从本章起，那场危机中的任何结果，都不能被讲成在任何人行动之前就已注定。

同样的检验也保护476年，使它免受其推崇者的夸大。废黜确实发生了，但它并不是后来欧洲一切格局的原因；东部帝国的延续，正是阻止这句话膨胀的事实。原因有其尺度，那是[[sources/scale]]的主题。在这里只需指出：一个解释一切的原因，解释不了任何可以检验的东西，因为你说不出什么会构成对它的反证。

因此，反证不是论断赢得掌声之后再补上的客套，而是论断语法的一部分。如果把东部帝国和480年的死亡留到另一段反驳文字里，[[#thm-476]]就会是一个更糟的句子：读者会被引导先相信转折点、后来才去怀疑，而许多读者根本读不到后面那段。把反证放进编号的论断，就是一种纪律。它使句子变长，也使句子诚实。标签之所以简短，是因为它们辞退了负责保管反证的人。

:::example 一台杜撰的发动机 {#ex-invented-engine}
下面这句话为示例而虚构。它不是史料，也不是本图谱提出的论断。“威斯特伐利亚造就了现代国家，这个原因一旦就位，欧洲后来的格局就不可能是别的样子。”哪里是标签？哪里是冒充的原因？这句话错在何处？
:::solution
标签是“现代国家的诞生”，藏在“威斯特伐利亚”这个名称里。冒充的原因是1648年10月24日的和约，它被要求独自造就后来的整个格局。这是对后来事件的单一原因史，本章不予接受。它也通不过[[#def-cause]]，因为一个不给其他可能留下余地的因素，不是我们所说的原因，而是一个标上了日期的命运。威斯特伐利亚的意义有争议，成形的主权理论是后来的解读，所以这句话对这些条约而言是错的，作为解释也是空洞的。反证应当写进论断：1648年1月和1648年10月24日的行为调整了一项宗教和约、承认了一个共和国，却没有奠定一块大陆。[[#thm-label]]就是这句虚构的话所违背的规则。至于[[sources/evidence]]意义上的升格为证据，根本无从开始，因为这句话除了我们之外没有别的制作者。
:::
:::

:::example 约束之下的选择 {#ex-july}
不叙述这场危机，说明时间表能对一个政府起什么作用、不能起什么作用，以及叙述在哪里展开。请提及年表要求交代的分歧。
:::solution
时间表可以约束一个政府：它可以使某些行动序列代价高昂、节奏紧迫或难以逆转。但它不能取消选择，也不能把危机变成命运。历史学家对七月危机究竟是一系列选择还是一张时间表看法不一，这种分歧要留在句子里。完整的叙述见[[nations/toward-1914]]，这里不讲。[[#def-cause]]是你带进那一章的检验：一个因素只有在本来可能不同的情况下，才配称为原因。像“没有出口的路”这样的标签，与专制主义和重生故事一样通不过[[#thm-label]]。死亡总数、最后通牒和战役都不属于这个答案。
:::
:::

:::quiz
按照本章的检验，一个因素在什么情况下算不上原因？
- [ ] 当它标有日期时，因为日期就是标签
- [ ] 当同一句话中提到了反证时
- [x] 当它本来不可能不同时，或者被要求独自解释一个后来的事件时
- [ ] 当历史学家看法不一时，因为分歧会抵消这个因素
:::solution
[[#def-cause]]要求这个因素本来可能不同。对后来事件的单一原因史，即使所说的因素真实存在，也通不过检验。问题不在日期，[[sources/time-and-names]]已经让日期变得可以检验。反证本就应在论断之内，所以提到它是成功而不是失败。分歧也不会抵消一个因素。在七月危机中，“选择还是时间表”的分歧正是必须说出的内容之一，而叙述留在[[nations/toward-1914]]。

:::warning 吞掉证据的名词
常见的迷思认为，每个时代都有一种精神，而这种精神就是那个时代的人们所作所为的原因。文艺复兴、专制主义和在威斯特伐利亚诞生的主权国家，是这一迷思最钟爱的名词。它们作为原因不成立，因为精神不可能不同；作为论断也不成立，因为没有任何明确的东西会构成对它们的反证。它们作为标签却很成功，危险正在于此。把476年读作“覆亡”，就是这个迷思换上了罗马的装束。废黜确实发生了，东部帝国继续存在，尼波斯死于480年，其意义有争议。后来某场危机中的时间表可以约束一个政府，却仍然留下选择余地。这些结果没有一个是早已完整地藏在某个名词里等待着的。
:::

## 故事喧嚣时守住语法

在讲语法的一章里，守住语法很容易；到了讲战争、改革或革命的章节，就难了。后面那些章节会充满真正的原因：财政危机、教义、动员计划、一次投票。可以带到那里的纪律并不是禁止解释，而是禁止两条捷径。第一条捷径让一个原因包揽后面每一章的全部解释。第二条捷径用标签代替原因，再把标签当作体面得无须检验的东西。如果你发现自己在写某种精神、某个时代或某条道路造成了某个结果，你就同时走上了这两条捷径。

你可以拿任何一个你欣赏的句子来练习这种修补。先问发生了什么，用一个固执的读者能够否认的分句来回答。再问你如何知道，指出一条存迹，而不是一种教科书传统。再问什么会构成对这个分句的反证，并把反证放在读者鼓掌之前就会读到的位置。然后问你的因素本来是否可能不同。如果你想象不出另一种可能，你手中的就是背景，而背景属于描述，不属于发动机。[[#thm-476]]之所以能做范本，只是因为其中的事实小到可以装进一句话。当事实变成一个人的一生、一座庄园、一个王国或一门贸易，而一个在某种尺度上为真的句子被要求承担另一种尺度的工作时，[[sources/scale]]要求的也是同样的语法。

谁从跳过语法中获益，并不神秘。短短的标签适合标题、考题和演讲；可检验的句子则适合页边，有人可以在那里写下尼波斯死于480年，从而否定你的转折点。标签的好处是快，代价是你再也分不清史料和口号，而这正是[[sources/evidence]]要教的本领。日期、论断、原因和标签是四种不同的工具。拿最光鲜的那一件去做所有的活，一部欧洲概览就是这样重新变回迷思的。

## 通向何处

论断如今是可以当众被证伪的东西。[[sources/scale]]要问：一个在某种尺度上真实的故事，何时会在另一种尺度上变得不真——那是原因出错的下一个地方。476年的废黜在[[rome/later-empire]]中被置于更长的罗马史之中。1648年的和约在[[reformations/religious-war]]中作为一项和约来讲授，而不是作为一种主权理论。七月危机——时间表之下的选择——见[[nations/toward-1914]]，这里不讲。文艺复兴和专制主义这两个标签，将在[[crises/city-states]]和[[states/composite-monarchy]]中再次受到检验。

:::summary
- 论断说明发生了什么、我们如何知道，并包含反证。一句话如果没有任何东西会构成对它的反证，就还算不上论断。
- 原因是本来可能不同的因素。预先确定的背景解释不了差异，单个原因也不是整部历史。
- 标签打包论断并把它们藏起来。文艺复兴、专制主义和作为主权诞生的威斯特伐利亚都是标签，不是史料。
- 476年，奥多亚塞废黜罗慕路斯·奥古斯都鲁斯。东部帝国继续存在。朱利乌斯·尼波斯死于480年。476年的意义有争议。这是一个可检验的句子。
- 1648年10月24日，在明斯特和奥斯纳布吕克缔结的和约调整了奥格斯堡和约，并纳入了加尔文派。成形的现代主权理论是后来的解读。
- 1492年的意义有争议。一个事件密集的年份，不会因为数字准确就成为近代的诞生。
- 历史学家对七月危机究竟是一系列选择还是一张时间表看法不一。时间表可以约束一个政府，却仍然留下选择余地。叙述在别处。
- 图中证据和反证都连向论断，标签只连向论断。耳熟并不是通向证据的边。
:::

## 习题

:::exercise 哪种职能 {level=1}
“专制主义解释了这个时代”这句话承担的是哪种职能：论断、原因，还是标签？
:::solution
这句话是一个在做原因之事的标签。按[[#def-label]]，专制主义打包了一条关于君主不受制约的论断，并把它作为一个时代的名称呈现出来。被要求“解释这个时代”时，它又冒充了原因。它通不过[[#def-cause]]，因为时代精神不可能不同；它也违反了不让单一因素包揽全部解释的禁令。[[states/composite-monarchy]]拒绝用这个名词命名那个时代。修补的办法是提出关于某位具体统治者、某种具体税收或某场具体战争的论断，并允许反证进入。
:::
:::

:::exercise 相隔的年数 {level=1 check="4"}
按照“从公元A年到公元B年，年数为B减A”的规则，从476年到480年经过了多少年？（请输入年数。）
:::solution
480减476等于4。这四年是罗慕路斯·奥古斯都鲁斯被废黜后朱利乌斯·尼波斯仍然在世的时段。它们是对“476年是罗马帝制生活本身的终结”这一论断的反证。它们不是衰落的故事，也不是首尾都算的五年。答案是4。
:::
:::

:::exercise 说出那一天 {level=1}
1648年10月24日缔结了什么？本图谱拒绝把哪种后来的解读当作这些条约本身的理论？
:::solution
《威斯特伐利亚和约》在明斯特和奥斯纳布吕克缔结。它调整了《奥格斯堡和约》，并把加尔文派纳入帝国。1648年1月，西班牙已在明斯特承认联合省。本图谱拒绝当作条约本身理论的后来解读，是一套成形的现代主权理论。威斯特伐利亚的意义有争议。[[#thm-label]]把那个“生日”归入标签，[[reformations/religious-war]]则讲述那场战争。
:::
:::

:::exercise 没有诞辰的重生 {level=2}
年表没有为文艺复兴锁定起始年份。1453年5月29日是君士坦丁堡陷落之日。为什么“文艺复兴始于那座城市陷落之时”是标签而不是论断？不用这个名词，你能指出什么实践？
:::solution
这句话把重生、原因和诞辰打包成一个由名词驱动的故事。文艺复兴的诞辰没有锁定，所以这句话杜撰了一道[[sources/time-and-names]]本就会拒绝的接缝。1453年5月29日那座城市的陷落是真实事件。按[[crises/city-states]]的用法，人文主义当时已经是一种由古典拉丁语、教育、文书机构和声名构成的实践。一条论断可以同时说出这两点，但不能让城市陷落成为一种早已开始的实践的原因，也不能让“文艺复兴”代替证据。获益的是“一块大陆正在觉醒”的情节。[[#thm-label]]就是规则，而不等1453年就已存在的那种实践就是反证。
:::
:::

:::exercise 一个名词，几个王国 {level=2}
如果把专制主义当作论断来使用，为什么复合君主国构成对它的反驳？如果把专制主义当作标签来保护，为什么复合君主国又构不成反驳？
:::solution
拆开来看，专制主义主张那个时期的王权不受制约，而且一种模式涵盖了各个国家。复合君主国是同一位君主治下的几个王国，各有各的法律。这一事实即便与一位强大的国王并存也可以成立，它反驳的是那种不受制约、整齐划一的模式。[[states/composite-monarchy]]正是因此拒绝用这个名词命名整个时代。如果这个名词只是标签，复合的情形就会被归为例外，而例外被界定为一切不符合的东西，于是这个名词永远碰不到反证。[[#def-label]]描述的正是这种保护。正如[[states/fiscal-military]]所讲，财政—军事君主国仍可以是应对战争和税收的一种真实方案，而不必是每个国家的模式。修补的办法是提出关于某一具体王权的论断，小到足以被证伪。
:::
:::

:::exercise 指引与叙述 {level=2}
一位同学要你在本章用一个原因解释七月危机，这样就不必读后面那一章了。你拒绝什么？你交代什么分歧？你把叙述指向哪里？
:::solution
你拒绝对后来事件作单一原因的解释，也拒绝任何把结果讲成在任何人行动之前就已注定的讲法。历史学家对七月危机究竟是一系列选择还是一张时间表看法不一，你要交代这一分歧。时间表可以约束一个政府，却仍然留下选择余地；在这样的距离上，[[#def-cause]]所需要的仅此而已。叙述留在[[nations/toward-1914]]。在这里讲述那些最后通牒会越出本章的界限，杜撰一个死亡总数则会违背本图谱。同学的要求，其实是让“道路”这个标签被当作证据。[[#thm-label]]表明，道路不是通向证据的边。图中也没有画这样一条边。
:::
:::

:::exercise 写一个可检验的句子 {level=3}
只用476年和480年，写出一个包含反证、交代争议、又不是“罗马覆亡了”这一口号的可检验句子。然后说明什么会构成对你这个句子的反证。
:::hint
三个分句：一次废黜，一种延续，一次死亡。争议在于意义，而不在于奥多亚塞是否采取了行动。
:::
:::solution
一个可以接受的句子就是[[#thm-476]]中的论断：476年，奥多亚塞废黜罗慕路斯·奥古斯都鲁斯；东部帝国继续存在；朱利乌斯·尼波斯死于480年；476年的意义有争议，这一年是标志西部一次废黜的惯例，而不是罗马生活的终结。反证是东部的延续和到480年为止的四年，因为480减476等于4。能够推翻它的，是东部帝国在476年终结的证据，或尼波斯死于476年的证据，或一份记录，表明罗马政治生活的终结本身就是被目睹的行为，而不是后来的解释。一部只宣告“覆亡”的编年史的教训，不算这样的记录；[[sources/evidence]]把这种教训留在作者那一边。名为“覆亡”的标签，不会因为更短就更可检验。
:::
:::

缺失的边禁止你把这个名词当作它本身就触及了条约。1648年1月，西班牙在明斯特承认联合省。1648年10月24日，明斯特和奥斯纳布吕克产生了一项和约，它调整了1555年9月25日的《奥格斯堡和约》，并纳入了加尔文派。这些条款是关于一次解决的论断的证据，而不是一套成形现代主权理论的证据。那套理论是后来的解读，而威斯特伐利亚的意义有争议。[[#thm-label]]就是用文字写出的那条缺失的边。能够推翻这幅图的，是证明这个标签本身就是史料，即一条有制作者、有目的的存迹，而不是连向论断的一束打包。一个重复这个名词的章节标题做不到这一点。简短名称的便利也做不到，只要这个名称被随即拆开。如果这些条约曾用年表并未赋予它们的措辞宣布过那套理论，那么“后来的解读”这一论断就不得不收缩；但这里并没有赋予它们这样的措辞。图可以随意拖动，拖动却造不出那条被禁止的边。
