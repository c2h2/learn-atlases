奥古斯都获得这个称号时，什么改变了，什么又被保留了下来？

官职共和国并不是在某一个晚上终止的。它经历了一小串有确切年代的标志性事件，被夺取、被掏空、被换上新的标签，而各个官职的名称却一直沿用。尤利乌斯·凯撒（Julius Caesar）于公元前44年3月15日遇刺。刺杀他的人并没有恢复一个稳定的共和国。公元前31年9月2日的亚克兴（Actium）之战，只留下了一位胜出的统帅。公元前27年，这位统帅屋大维（Octavian）获得了“奥古斯都”（Augustus）的称号。执政官、元老院和公民大会都延续了下来，君主制保留了这些形式。“共和国在某一天终结”是后人的一种简化，而本章拒绝的正是这种简化。

从提比略·格拉古（Tiberius Gracchus）的保民官任期到三月望日（Ides of March）之间，充斥着内战暴力和非常指挥权。本图谱没有锁定那些战役年份，我们不杜撰它们，也不一一叙述每场内战。锁定的年代所能告诉我们的，已经足够：一次未能恢复旧日竞争的刺杀，一场结束了那一代罗马统帅之间最后一场战争的战役，以及一套把共和国名号保留在一种新型权力之中的安排。

作为对这些官职的一份参与，自由从来不属于全体成年人。[[rome/republic]]把这一限度作为前面故事的核心，[[rome/slavery-and-conquest]]则说明，征服与奴隶制就是这些官职所争夺的帝国的内容。君主制并没有从那些从未拥有过普遍自由的人手中夺走普遍自由。它从政治阶层手中夺走的，是对最高指挥权的竞争，而被排斥者依然停留在原处。奴隶依然是奴隶。到公元212年，这句话依然成立。

## 三月望日

凯撒把年度官职制度本来要分割的那种权力集于一身：长期的指挥权，一场打进意大利的内战，一个不再是旧式短期应急职位的独裁官职，以及一种被他的敌人称为王权的至高地位。我们可以指出这种权力的积聚，而不必为每一步定年。刺杀之前的内战年份不在年表中，所以这里不给出数字。有确切年代的事实是他的死：公元前44年3月15日，他在罗马遇刺。刺杀者中，既有曾与他同僚任职的人，也有声称自己在捍卫共和国的人。

这种捍卫失败了。杀死那个独揽大权的人，并没有使罗马回到平等者之间的稳定竞争。政治阶层再次分裂，那些自称拯救了共和国的人被卷入了新的战争。我们不列出这些战场的名称和年代。下一个锁定的年代所记录的结果是：刺杀者并没有成为执政的一方。如果行省仍是长期的指挥权，军队仍指望将领给予回报，城中的各个官职又可以被下一轮的胜者一并揽入手中，那么除掉一个人，并不能恢复共和国。

这次刺杀不是罗马权力的终结，也不是奴隶的解放——奴隶根本不在刺杀者的争执之内。它不是回到公元前509年，那一年本身已经是记忆而不是文献。它本身也不是元首制。凯撒的继承人屋大维此时还不是奥古斯都。把3月15日当作自由终结的那个晚上，就是把屋大维、安东尼（Antony）和公元前27年的安排都压缩进同一个夜晚。从公元前44年到公元前27年，经过的年数是17年。这些年份，正是“一夜之间”这个故事的错误所在。

:::definition 作为标志的三月望日 {#def-ides}
这里的**三月望日**仅指公元前44年3月15日尤利乌斯·凯撒遇刺一事。它是一次有确切年代的政治刺杀。它既不是自由得以恢复的象征，也不是自由一击而亡的象征。共和国在那一天之前并不稳定，也没有在那一天重新建立。
:::

:::theorem 刺杀凯撒的人没有恢复一个稳定的共和国 {#thm-ides}
公元前44年3月15日的刺杀除掉了一个独揽大权的人，却没有恢复年度官员之间持久的竞争。内战一直持续，直到只剩下一位统帅。
:::
:::proof
年表中的下一个标志是公元前31年9月2日的亚克兴之战，而不是一代人的正常执政官统治。刺杀者声称他们是为共和国而行动，这里把它作为他们自己的说法来转述。随后的事态就是反驳其成功的证据：内战再起，然后是公元前27年一套既集中权力、又保留旧名号的安排。能够推翻这条论断的，是这样的证据：在公元前44年3月15日之后、亚克兴之战之前，元老院和公民大会重新按照旧日的竞争分配重大指挥权，而各武装对手也交出了这些指挥权。但通向亚克兴的道路并非如此。一个共和国被正式重建并随后正常运转的锁定年代，同样能够推翻它。但并没有这样的年代。
:::

:::example 十七年，而不是一个晚上 {#ex-seventeen}
计算从公元前44年到公元前31年、从公元前44年到公元前27年各自经过的年数。为什么在任何人追问那套安排的内容之前，“一夜之间”的故事就已经在这道算术题上站不住脚了？
:::solution
从公元前44年到公元前31年，经过的年数是13年；从公元前44年到公元前27年，是17年；从亚克兴之战到那套安排，31减27，是4年。一个让自由终结于公元前44年3月15日晚上的故事，必须假装亚克兴之战和“奥古斯都”这一称号与刺杀是同一件事。但它们不是。算术并不能说明公元前27年创造了什么样的政体，它只说明：对这三个年代来说，“一夜之间”是错误的形状。
:::
:::

:::quiz
公元前44年3月15日的刺杀造成了什么结果？
- [ ] 它恢复了一个由年度官员构成的稳定共和国
- [ ] 它终结了罗马的奴隶制和行省统治
- [x] 它杀死了凯撒，却没有恢复一个稳定的共和国
- [ ] 那一天屋大维获得了“奥古斯都”的称号
:::solution
论断见[[#thm-ides]]。“奥古斯都”这一称号属于公元前27年。奴隶制和行省都延续了下来。刺杀者并没有实现他们所宣称的恢复。从公元前44年到公元前27年经过了17年，这是不应把这些年代混为一谈的理由之一。
:::
:::

## 亚克兴

三月望日之后，罗马的统帅们利用征服所造就的军队和行省相互攻战。一个三人同盟一度掌权，并通过“公敌宣告”（proscription）杀害政敌。我们不描述这些杀戮，也不统计死者。这个同盟没有维持下去，其中一名成员被排挤出局，剩下的是屋大维与安东尼之间的战争。安东尼与克利奥帕特拉（Cleopatra）的联盟，使屋大维一方能够把这场战争说成既是对一位外国女王的战争，也是对一个罗马对手的战争。这种说法是政治宣传，而这场战役是一场内战。

公元前31年9月2日的亚克兴之战，是决定这场战争胜负的海战。年表给出了日、月、年。我们不叙述双方的阵形，也不杜撰任何一位统帅的言辞。屋大维的军队获胜，他成为曾经各自统率一方的那些人中最后留下的一位。由克利奥帕特拉统治、并被安东尼纳入自己阵营的那个埃及希腊化王国，没能作为罗马的对手存续下去。我们不给战役之后发生的那些死亡定年。亚克兴之战是我们可以使用的标志：罗马统帅之间的内战有了一个胜者。

赢得一场内战，还不等于一部政制。亚克兴之战后的那些日子里，屋大维掌握着所有举足轻重的军队，但他还没有获得那套安排将要授予他的称号。停在公元前31年9月2日，宣布帝国始于海上，就是把“一夜之间”的错误提前四年重犯一遍。从亚克兴之战到那套安排，经过的年数是4年。描述权力时，仍然必须使用共和国的那套形式语言：元老院依然存在，执政官也依然存在。但再也没有第二个罗马军阀统领着罗马世界的东半部了。

:::definition 作为结果的亚克兴 {#def-actium}
**亚克兴之战**是公元前31年9月2日屋大维击败安东尼的海战。它结束了那一代罗马统帅之间的最后一场内战。它在当天既没有授予“奥古斯都”的称号，也没有颁布一部新政制。它产生的是一个唯一的胜者。
:::

## 称号，以及保留下来的形式

公元前27年，屋大维获得了“奥古斯都”的称号。这个称号使他有别于所有其他官员，却没有称他为王。罗马人曾在拒绝王政的基础上建立起自己的传统认同。一个想在这座城市长久存续的君主制，不能用“王”这个字来自我标榜。它可以标榜的，是内战之后的和平、“公共之事”的恢复，以及一个在众人之中居于首位的人。历史学家把这一政体称为**元首制**（principate），这个词来自 *princeps*，意为“第一公民”。这是学者为一个保留了共和形式的君主制所取的名称，既不是对一个黄金时代的评价，也不是引自奥古斯都的话。他后来发表了一份关于自己功业的记述。我们把它当作他的自我陈述，而不是一部中立的编年史，也不复述其中的语句。

此后，他的法定权力又有过一些调整。本图谱没有锁定那个较晚的年份，所以我们不杜撰它，而且这条论断也不依赖于它。在公元前27年，格局已经清晰可见：他以一个称号而与众不同；他掌握着军事行省，即驻有军队的那些指挥区，而其他行省则交由元老院治理；他可以担任执政官，别人也照样担任执政官；元老院照常开会；*res publica* 一词也继续使用。君主制并不是因为不被说破而隐藏起来的，它是用一套否认“王”字的语汇说出来的。

保留下来的东西，并不是一块背后空无一物的布景。执政官继续选举产生，元老院仍是政治阶层的议事机构，行省仍有总督，公民大会依然存在，仕途依然是一系列官职的递进。一位从不触犯元首的元老，可以过上一种在一个个官职上都与他祖父相似的人生。差别在于最高层，而那正是内战胜负的所在。前一代人还可以期望某个对手在第二年获得重大指挥权；那套安排之后，重大指挥权全凭一人授予。当选执政官仍是一种荣誉，却不再是通往最高权力的道路。

继承问题也显示出同样的两面性。奥古斯都没有采用世袭的王号，但他仍然必须通过收养和分享权力来安排继承人。我们不叙述他家族中的死亡。一个拒绝“王”字的君主制，仍然面临君主的问题——由谁来做下一位君主——而一个由年度同僚构成的共和国，本不应有这个问题。

:::theorem 君主制保留了形式 {#thm-forms}
从公元前27年屋大维被称为奥古斯都起，一个人掌握了年度官职所无法容纳的至高权力，而各个官职、元老院和共和国的名号都延续了下来。这一政体是共和形式下的君主制，既不是这些形式的终结，也不是原来的那个共和国。
:::
:::proof
我们所依据的是年表中的那套安排：共和国的制度被保留了下来，同时被掏空。执政官、元老院、行省以及对王号的拒绝都延续着，与之相对的，是军事行省的集中，以及亚克兴之战后敌对统帅之间内战的终结。能够推翻这条论断的，是这样的证据：公元前27年之后，元老院和公民大会通常能够违背奥古斯都的意愿来决定重大指挥权，而且这是常规而不是危险的例外。但常规的格局恰恰相反。同样能够推翻它的，是他采用王号、废除各个官职的证据。但他并没有这样做。只有形式而没有至高权力，那是旧共和国；只有至高权力而没有形式，那是“一夜之间”的故事。那套安排两者都不是。
:::

有一种反驳把公元前27年称为一次恢复，而且是认真的。内战极其惨烈，奥古斯都既提供了旧有的语言，又独占了军队。我们不引用他本人的说法。一次由一个人分配军队的恢复，恢复的是和平和名位，而不是那种使共和国成为官职共和国的竞争。如释重负并不是一部政制。另一种反驳则说，这些形式是一场骗局，应当置之不理。这种说法同样站不住脚：法律、行省和仕途仍在使用这些官职。一个被掏空的制度，并不是一个不存在的制度。[[#thm-forms]]有意是双重的。去掉任何一半，那套安排就会变成漫画：要么是纯粹的延续，要么是纯粹的断裂。玛丽·比尔德（Mary Beard）的罗马通史，正是针对“罗马为后来的欧洲提供了单一教训”这种说法而写的。这里要拒绝的教训是：公元前27年要么拯救了自由，要么在一夜之间埋葬了自由。

:::example 一份不是编年史的记述 {#ex-not-a-chronicle}
奥古斯都后来发表了一份关于自己功业的记述。下面这句话是虚构的，并非取自那份记述。“在我获得称号的那一天，我写道，共和国已经完全恢复，每一个成年人都是自由的。”

那份真实的记述可以用来做什么？这句虚构的话错在哪里？
:::solution
那份真实的记述是他的自我陈述：它证明了他希望人们如何描述那套安排，包括拒绝王号和宣称恢复了“公共之事”。它不是一部中立的编年史，本章也不复述其中的语句。这句虚构的话添加了两个错误——旧日的竞争已经恢复，自由扩展到了每一个成年人——而且还冒充是他的原话。杜撰的引文即使标明了也不予采用，除非作为这种错误的标本。
:::
:::

:::example 执政官职位的前后对比 {#ex-consul}
以下两段描述都是示意性的，都不得用年表没有锁定的战役年份来填充。

- 内战之前，两名执政官就职。一项重大的对外指挥权，是元老院和选举在下一年仍可能授予某个对手的奖赏。
- 公元前27年之后的某一年，两名执政官就职。驻有主力军队的军事行省掌握在奥古斯都手中。其中一名执政官可能就是奥古斯都本人，或者是一个得到他青睐的人。

什么改变了？“什么都没有改变，因为仍然有两名执政官”这句话错在哪里？
:::solution
保留下来的是执政官的人数，改变的是执政官职位与最高权力之间的关系。那套安排之后，重大指挥权已不在选举所分配的奖赏之列。“什么都没有改变”是纯粹延续的漫画，“执政官不复存在”是纯粹断裂的漫画。[[#thm-forms]]要求同时看到留存下来的官衔，以及它不再包含的至高权力。这张示意图没有添加任何年表所省略的战役。
:::
:::

:::example 被排斥者：公元前27年并没有失去选票的人 {#ex-excluded}
说出三类人：公元前27年的安排对他们而言，并不是失去了一种他们此前拥有的政治平等。然后说出这一安排确实终结了其竞争的那个群体。
:::solution
成年女性公民在公元前27年之前既不投票，也不担任官职。奴隶在那一年之前是财产，之后依然是。行省中的大多数自由人不是罗马公民，在罗马的公民大会中没有份。对这三类人来说，根本没有可以剥夺的共和平等。失去了一场真实竞争的，是罗马男性中的任官阶层，即那些曾为指挥权而相争的显贵。他们的损失，就是君主制的政治内容。把它称为全体罗马人自由的终结，就是把显贵的不满强加到共和国早已排斥在外的人身上。
:::
:::

- [x] 他获得了“奥古斯都”的称号，共和国的官职在一种至高权力之下延续

:::warning 不是一夜之间
常见的迷思挑出一个夜晚——三月望日，或亚克兴之战后的那一夜，或公元前27年的那次会议——说自由就在那时终结。但这些年代无法叠在一起。从公元前44年到公元前27年是17年，这些年里有又一场内战，以及一套既是言辞上又是军事上的安排。另一个毛病出在“自由”这个词上。共和国曾是男性公民之间的竞争，按财富加权，对妇女、奴隶和大多数行省居民关闭。终结这种竞争是一个真实的政治变化，但把它称为自由本身的沦亡，就是让一部狭隘的政制借用一种普遍的哀悼。我们不杜撰奥古斯都的话，也不杜撰刺杀者的话。这些标志已经足够，而且它们是三个。
:::

尤利乌斯·凯撒于公元前44年3月15日遇刺，共和国并没有因此恢复。亚克兴之战发生在公元前31年9月2日。公元前27年，屋大维被授予“奥古斯都”的称号，共和国的官职在一种新的君主制之中延续。

## 通向何处

在公元前27年之后留存下来的形式，是城市、军队和公民身份实际运作的外壳。[[rome/imperial-society]]追问帝国的公民身份涵盖了什么，从公元79年被掩埋的一座城镇讲到公元212年的公民权授予，并拒绝“黄金时代”之说。被掏空的官职，就是[[rome/republic]]中界定的那些官职。依然是财产的人，属于[[rome/slavery-and-conquest]]所讲的那项制度。一个标签如何能够隐藏一个论断，是[[sources/argument]]所讨论的问题。

:::summary
- 凯撒于公元前44年3月15日被杀。刺杀者没有恢复一个稳定的共和国，内战随之而来。年表所省略的战役，我们不予定年。
- 公元前31年9月2日的亚克兴之战使屋大维成为胜者，但那时还没有“奥古斯都”的称号。从这场战役到那套安排，经过的年数是4年。
- 公元前27年，屋大维被称为奥古斯都。他没有采用王号。执政官、元老院和共和国的名号都延续了下来，但最高军事权力不再作为一项公开的奖赏延续。
- 这条论断是双重的：君主制保留了形式，而这些形式已不再组织至高权力。纯粹的延续与纯粹的断裂都是漫画。
- 从公元前44年到公元前27年是17年。“自由在一夜之间终结”在算术上就站不住脚，而且大多数成年人本来就不曾拥有那种自由。
- 元首制是历史学家给这个披着共和外衣的君主制所取的名称。它不是黄金时代，也不是引自奥古斯都的话。
- 人们常常讨论他权力的进一步调整，但本图谱没有锁定那个年份。公元前27年的安排已经足以支撑这条论断。
:::

## 习题

:::exercise 从三月望日到获得称号 {level=1 check="17"}
计算从公元前44年到公元前27年经过的年数。（请输入年数。）
:::solution
两个年份都在公元前。经过的年数是44减27，即17年。这是“一夜之间”的故事必须压缩掉的跨度，而不是战役的次数。

17
:::
:::

:::exercise 获得称号的年份 {level=1 check="27"}
屋大维在哪一年获得了“奥古斯都”的称号？只输入公元前的年份数字。（请输入数字。）
:::solution
那套安排定于公元前27年。刺杀在公元前44年，亚克兴之战在公元前31年。这个称号属于三个标志中的最后一个。

27
:::
:::

:::exercise 从亚克兴到那套安排 {level=1 check="4"}
计算从公元前31年到公元前27年经过的年数。（请输入年数。）
:::solution
经过的年数是31减27，即4年。亚克兴之战产生了一个胜者，“奥古斯都”的称号则在四年之后才出现。把这两个年代混为一谈，就是在更小的范围内重犯“一夜之间”的错误。

4
:::
:::

:::exercise 刺杀者没有实现的东西 {level=2}
公元前44年3月15日的刺杀者声称自己是在捍卫共和国。请在不杜撰引文的前提下，说明这一主张要读者相信什么，以及为什么[[#thm-ides]]在记录这次刺杀的同时，否认这一主张取得了成功。
:::solution
这一主张要我们相信：除掉凯撒，就能恢复官员之间稳定的竞争，仿佛他是唯一的障碍。转述一个主张并不等于认同它。从三月望日到亚克兴，走的是内战再起的道路。[[#thm-ides]]把真实发生的刺杀，与并未随之实现的政治纲领区分开来。能够推翻这一区分的，是在公元前44年至公元前31年之间锁定的一段正常的共和竞争时期，其间各武装对手都放下了武器。而下一个标志，恰恰是他们没能避免的那场战役。
:::
:::

:::exercise 保留下来，同时被掏空 {level=2}
列出公元前27年之后延续下来的三种共和形式，以及一种不再作为公开奖赏延续的权力。然后说明，为什么只列出这三种形式会错误地描述那套安排。
:::solution
执政官继续就职；元老院继续开会；拒绝称王的做法继续存在，共和国的名号也随之延续。最高军事指挥权则不再作为公开的奖赏延续：驻有主力军队的行省归奥古斯都掌握。只列出留存下来的形式，就会把公元前27年当作一次恢复，并到此为止。[[#thm-forms]]补上了掏空这一面。两句话缺一不可，而哪一句都不需要引用他本人的记述。
:::
:::

:::exercise 谁的自由 {level=2}
改写“公元前27年，罗马人民失去了他们的自由”这句话，使它指明谁失去了一场真实的竞争、谁被错误地包括了进来。保留这个年份。
:::solution
公元前27年，罗马男性公民中的任官阶层失去了对最高指挥权的公开竞争，而执政官、元老院和共和国的名号则在奥古斯都的至高权力之下延续。成年妇女、奴隶和大多数行省自由民在那一年并没有失去选票或官职，因为官职共和国从未给过他们这些东西。不加限定地说“罗马人民”，就是把显贵的损失强加给罗马所统治的每一个人。
:::
:::

:::exercise 恢复之说不构成反驳 {level=3}
一位历史学家说：“罗马人把公元前27年称为共和国的恢复。既然形式延续了下来，那就是共和国。你的双重论断是拒绝倾听。”请回应，并说明什么样的证据才真正能够推翻[[#thm-forms]]。
:::hint
倾听意味着转述他们的公共语汇，而不是服从它。要追问的不仅是这个政体希望被如何称呼，还有公元前27年之后重大指挥权掌握在谁的手中。
:::
:::solution
公共语汇是证据的一部分：他没有被称为王，各个官职延续，那套安排被说成是“公共之事”的回归。正因为如此，这条论断才说形式被保留了下来。但服从这套语汇，就等于让一个政体的称号否决了“军队掌握在谁手中”这个问题。他后来关于自己功业的记述是他的自我陈述，而不是我们必须采信的编年史，我们也不引用它。

按照[[rome/republic]]的界定，官职共和国是一种仍然能够授予最高指挥权的竞争。公元前27年之后，形式延续了，这种竞争却没有延续。对和平的感激，并不能把军事行省重新放回选举的奖赏之列。能够推翻[[#thm-forms]]的，是元老院和公民大会通常能在重大指挥权上压倒他的证据，或者他废除官职、以王的身份统治的证据。那套安排与这两种相反的情形都不相符。
:::
:::

:::exercise 一个不许添加的年份 {level=3}
你想叙述从刺杀到亚克兴之间的内战。一本参考书提供了两场著名战役，各有年份，但都不在本年表中。它还提供了公元前27年之后的一个较晚年份，那一年奥古斯都的权力在法律上有过一次重新安排。你如何处理这些年份？不用它们，你又如何讲述这段历史？
:::hint
年表的沉默是本图谱的一条规则，并不是主张那些空白期内什么都没有发生。讲述锁定的标志已经包含的结果。不要在拒绝那些缺失战役的年份时，又通过点出它们的名字把它们带回来。
:::
:::solution
不采用这些年份。不添加那些战役，也不添加那次较晚的重新安排。公元前44年3月15日，凯撒被杀，稳定的共和国没有回来。罗马统帅之间的内战一直持续到公元前31年9月2日，亚克兴之战使屋大维成为胜者。公元前27年，他被称为奥古斯都。执政官、元老院和共和国的名号延续了下来，而最高军事权力不再作为公开的奖赏延续。即使另一本书印出了一个年份，在本图谱中为进一步的法律调整给出一个精确年份，也是杜撰。

关于形式与至高权力的论断，从来不需要那些缺失的数字。它需要的是三个锁定年代之间的距离，以及第三个年代的内容。
:::
:::
