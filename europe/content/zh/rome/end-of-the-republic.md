当奥古斯都取了这个名号，改变了什么，又留下了什么？

官职的共和国不是在一个晚上停下来的。它经过一小串有标记的年代，被夺取、被掏空、被换了标签，而官职的名目一直沿用。尤利乌斯·凯撒（Julius Caesar）在公元前44年3月15日遇刺。杀死他的那些人没有恢复一个稳定的共和国。公元前31年9月2日的亚克兴（Actium）海战，只留下一名统帅站着。公元前27年，这位统帅屋大维（Octavian）被称为奥古斯都（Augustus）。执政官、元老院和集会延续下去。君主制保留了形式。「共和国在某一天终结」是后世的一种简化，而正是这种简化被本章拒绝。

从提比略·格拉古（Tiberius Gracchus）的保民官任期到三月十五（Ides of March）之间的年代，塞满了政治暴力的内战与非常指挥权。本图谱不锁定那些战斗年份。我们不编造它们，也不叙述每一场内战。锁定的年代已经能够教给我们的东西就已经够了：一场没有恢复旧日竞争的杀戮，一场终结那一代罗马统帅之间最后一场战争的战役，以及一套把共和名义保留在一种新型权力内部的安排。

自由，作为这些官职中的一份分享，从来不属于全体成年人。[[rome/republic]] 把那个限度放在早先故事的中央。[[rome/slavery-and-conquest]] 把征服与奴隶制作为那些官职所争夺的帝国的内容。君主制没有从从未持有过普遍自由的人手里拿走普遍自由。它把争夺最高指挥权的资格从政治阶层手里拿走，并把被排除者留在原地。奴隶依然是奴隶。这句话到了公元212年仍然是真的。

## 三月十五

凯撒把一年一度的长官制所设计来拆散的那类权力聚拢在自己一身：长期的指挥、一场被打进意大利的内战、一个不再是旧的紧急短差的独裁，以及一种被他的政敌称为王权的至上地位。我们能够在不给每一步定年的情况下说出这种聚拢。遇刺之前的内战诸年代不在年表里，所以这里不给它们数字。有年代的事实是那次死亡。公元前44年3月15日，他在罗马遇刺。凶手中有与他共过职的人，也有自称在保卫共和国的人。

保卫失败了。杀死那个压倒一切的人没有使罗马回到平等的稳定竞争。政治阶层再度分裂，自称挽救了共和国的人被卷进进一步的战争。我们不给那些战场点名或定年。结果由下一个锁定的年代记录：凶手们没有成为政府。如果行省仍然是长期的指挥，如果军队向一位将军讨取赏赐，如果城中的官职能够被下一轮的赢者打包，那么移除一人就恢复不了一个共和国。

这次暗杀不是罗马权力的终结，也不是奴隶的解放——奴隶们并不进入凶手们的争执。它不是回到公元前509年，那一年已经是记忆而不是文书。它本身也不是元首制。凯撒的继承人屋大维还不是奥古斯都。把三月十五当作自由终结的那个晚上，就把屋大维、安东尼（Antony）和公元前27年的安排塞进了同一个夜晚。从公元前44年到公元前27年，已过跨度是17年。这17年就是那个一晚上的故事里的错误。

:::definition 作为标记的三月十五 {#def-ides}
这里的**三月十五**只指公元前44年3月15日尤利乌斯·凯撒遇刺。它是一次有年代的政治杀戮。它不是自由得以恢复的象征，也不是自由一刀断气的象征。共和国在那一天之前并不稳定，也没有在那一天重新奠基。
:::

:::theorem 凯撒的凶手们没有恢复一个稳定的共和国 {#thm-ides}
公元前44年3月15日的暗杀移除了一个压倒一切的人。它没有恢复一年一度的长官之间持久的竞争。内战一直打到只剩一名统帅。
:::
:::proof
年表的下一个标记是公元前31年9月2日的亚克兴，不是一代人正常的执政官治理。凶手们的说法——他们为了共和国而行动——是作为他们自己的说法被报告的。随后的序列是反对其成功的证据：内战重起，然后是公元前27年一个集中权力同时保留旧名的安排。会构成对这条论断的反证的，是这样的证据：公元前44年3月15日以后、亚克兴以前，元老院和集会重新按旧的竞争分配大指挥权，而武装的对手们交回了这些指挥权。那不是通往亚克兴的路径。一个共和国被正式重建并随后实际运转的锁定年代，同样会构成反证。没有这样的年代。
:::

:::example 是十七年，不是一个晚上 {#ex-seventeen}
计算从公元前44年到公元前31年，以及从公元前44年到公元前27年的已过跨度。为什么一晚上的故事在任何人问这套安排的内容之前，就先输在这道算术上？
:::solution
从公元前44年到公元前31年，已过跨度是13年。从公元前44年到公元前27年是17年。从亚克兴到那套安排，31减27，是4年。一个把自由终结于公元前44年3月15日之夜的故事，必须假装亚克兴和奥古斯都这个名字与暗杀是同一件事。它们不是。算术没有说公元前27年造出了什么政体。它说的是：对三个年代而言，「一个晚上」是错误的形状。
:::
:::

:::quiz
公元前44年3月15日的暗杀做了什么？
- [ ] 它恢复了一个由一年一任长官构成的稳定共和国
- [ ] 它终结了罗马的奴隶制与行省治理
- [x] 它杀死了凯撒，没有恢复一个稳定的共和国
- [ ] 它是屋大维获得奥古斯都名字的那一天
:::solution
[[#thm-ides]] 就是论断。奥古斯都这个名字属于公元前27年。奴隶制与诸行省延续。凶手们没有得到他们自称要的那场恢复。从公元前44年到公元前27年17年的已过跨度，是不该把这些年代熔在一起的一个理由。
:::
:::

## 亚克兴

三月十五之后，罗马的统帅们用征服造成的军队与行省相互攻战。一个三人集团一度掌权，以公敌宣告（proscription）杀害政敌。我们不描述那些杀戮，也不数死者。那个集团没有持久。一个成员被挤了出去。剩下的战争在屋大维与安东尼之间。安东尼与克利奥帕特拉（Cleopatra）的联盟使屋大维一方能够把这场战争说成既是对外国女王的战争，也是对一个罗马对手的战争。这种呈现是政治。这场会战是一场内战。

公元前31年9月2日的亚克兴，是决定这场战争的海战。年表给出了日、月、年。我们不叙述阵列，也不编造任何一方统帅说过什么。屋大维的部队获胜。还曾统率过一方的诸人之中，最后站着的是他。克利奥帕特拉统治、安东尼把它绑进自己事业的埃及那个希腊化王国，作为罗马的对手没能存续。我们不给会战之后的死亡定年。亚克兴是允许我们使用的标记：罗马统帅之间的内战有了赢家。

赢下一场内战还不是一部政制。亚克兴之后的那些日子里，屋大维是那些要紧的军队的主人。他还没有带上那套安排将要给他的名字。停在公元前31年9月2日宣布帝国始于海上，是把一晚上的错误提前四年重演一遍。从亚克兴到那套安排，已过跨度是4年。共和国的形式仍然是权力必须在其中被描述的语汇。元老院还在，执政官还在。在罗马世界东半边领军号令的罗马战争军阀，不再会有第二个了。

:::definition 作为结果的亚克兴 {#def-actium}
**亚克兴**是公元前31年9月2日屋大维击败安东尼的海战。它终结了那一代罗马统帅之间的最后一场内战。它在当天既没有授予奥古斯都这个名字，也没有公布一部新政制。它产生了一个赢家。
:::

## 那个名号，与留下来的形式

公元前27年，屋大维获得奥古斯都这个名字。这个名字把他从所有其他长官中标示出来，又没有称他为王。罗马人曾经在拒绝王这件事上建立自己的传统认同。一座这样城市里打算长久的君主制，不能用王的字眼自我标榜。它可以用内战之后的和平、公共事务的恢复，以及一个在众人中居首的人来标榜。史家称这个政体为**元首制**（principate），一词来自 *princeps*，即第一人。这个词是一个学名，指一部保留共和形式的君主制。它不是说那个时代是黄金时代，也不是引自奥古斯都的话。他后来发表过一部自己功业的记述。我们把那部记述当作他的自辩，不当作中性的编年，也不抄录它的句子。

他法定权力的一些调整在此之后。本图谱不锁定那个较晚的年份，所以我们不编造它，而这条论断也不依赖它。公元前27年，形状已经可见。他由一个名字被标在别处。他握有军事行省，就是那些境内驻有军队的指挥权，其他行省留给元老院治理。他可以是执政官，别人也是执政官。元老院照常开会。*res publica* 一词继续使用。君主制没有因为不被说出而被藏起。它是在一个否认「王」这个字的语汇里被说出的。

留下来的不是幕布后面空无一物的画屏。执政官继续当选。元老院仍是政治阶层的议事会。行省仍然有总督。集会仍然存在。仕途仍是一串官职。一个从不与元首相犯的元老，可以过一种一个官职接一个官职、像他祖父的一生的一生。差别在顶上，而内战正是在顶上被决定的。上一代人还可以指望一个对手明年领走大指挥权。安排之后，大指挥权是一人之所予。当选执政官仍是一份荣誉。它不再是通往最高权力的路。

继任显出同一张双面。奥古斯都没有取世袭的王号。他仍然必须安排继承人，通过收养与共享的权力。我们不叙述他家中的死亡。一个拒绝「王」这个字的君主制，仍然有君主的问题——下一位君主——而一年一度同僚的共和国本不该有这个问题。

:::theorem 君主制保留了形式 {#thm-forms}
从公元前27年屋大维被称为奥古斯都起，一人持有年度长官制无法容纳的至上权力，而各官职、元老院与共和国的名号延续下去。这个政体是共和形式下的君主制，不是那些形式的终结，也不是原来那个共和国。
:::
:::proof
年表的那套安排正是我们所跟随的：共和国的制度被保留并被掏空。执政官、元老院、诸行省与对王名的拒斥延续着，与军事行省的集中、与亚克兴之后对手统帅间内战的终结相映衬。会构成对这条论断的反证的，是这样的证据：公元前27年以后，元老院与集会通常能把大指挥权违背奥古斯都的意愿选定，作为常规而不是危险的例外。常规模式恰好相反。同样会构成反证的，是他取了王的称号并废除各长官职的证据。他没有。没有至上权力的形式是旧共和国。没有形式的至上权力是一晚上的故事。两样都不是那套安排。
:::

有一条反对意见把公元前27年称为复辟，而且是认真的。内战可怕至极，而奥古斯都献上了旧语汇，外加对军队的独占。我们不引用他自己的偏好。一个由一人分配军队的复辟，恢复的是和平与名位，不是那个使共和国成为官职之共和国的竞争。欣慰不是政制。另一条反对意见说形式是骗局，应当无视。它也失败。法律、行省和仕途仍然使用着这些官职。一个被掏空的制度不是一个缺席的制度。[[#thm-forms]] 是故意双数的。扔掉任何一半，那套安排就变成了漫画：纯粹延续，或纯粹断裂。玛丽·比尔德（Mary Beard）对罗马的通史是逆着罗马对后来的欧洲只有一课的说法写的。这里要拒绝的一课，是说公元前27年要么拯救了自由，要么在一个夜里埋葬了它。

:::example 一部记述不是编年 {#ex-not-a-chronicle}
奥古斯都后来发表过一部自己功业的记述。下面这句话是编造的，也不取自那部记述。「在被命名的那一天，我写下共和国已经全然恢复，每一个成年人都是自由的。」

你可以把那部真实的记述用来做什么？那句编造的句子错在哪里？
:::solution
真实的记述是他的自辩：证据显示他愿意那套安排被怎样描述，包括对王名的拒斥和恢复公共事务的说法。它不是中性的编年，本章不抄录它的句子。编造的句子添加了两个虚假——旧的竞争已经回来，自由扩展到了每一个成年人——它还假称是他的话。编造的引文即使标明也被拒绝，标本除外。
:::
:::

:::example 执政官是什么：之前与之后 {#ex-consul}
两个描述都是示意图。哪一个都不许用年表没有锁定的战斗年份来填充。

- 内战以前，两名执政官就职。一个对外的大指挥权，是元老院和选举在明年仍然能够给一个对手的奖品。
- 公元前27年之后的一年，两名执政官就职。握着主力军队的军事行省在奥古斯都手里。一名执政官可能就是奥古斯都本人，或者是得他欢心的人。

什么变了？「什么都没有变，因为还有两名执政官」这句话假在哪里？
:::solution
执政官的人数是保留下来的东西。执政官与最高权力的关系是变掉的东西。安排之后，大指挥权不在选举所分配的奖品之列。「什么都没变」是纯粹延续的漫画。「执政官不复存在」是纯粹断裂的漫画。[[#thm-forms]] 既要求幸存的名位，也要求它不再容纳的至上权力。这个示意图没有添加年表留下的空白中的任何战役。
:::
:::

:::example 那些在公元前27年没有失去投票权的人 {#ex-excluded}
说出三类人：公元前27年的安排对他们并不是失去一种他们此前曾有过的政治平等。然后说出它确实关闭了一场竞争的那个群体。
:::solution
成年女性公民在公元前27年之前既不投票也不任长官。奴隶在那一年之前是财产，之后仍然是。诸行省里的大多数自由人不是罗马公民，在罗马的集会里没有份额。对这三类人，没有可供没收的共和平等。失去一场真实竞争的群体，是罗马男性的任官阶层，那些曾为指挥权相争的显贵。他们的失落就是君主制的政治内容。把它称为全体罗马人的自由之终结，就是把一个显贵的怨怼出口转让给共和国早已排除过的人们。
:::
:::

- [ ] 那一天，罗马世界每一个居民都失去了自由
- [x] 他被称为奥古斯都，共和官职在一个至上权力内部延续

在三个圆点上移动年份。空白是可见的：先是13年，然后是4年。最后一个圆点不是名号的崩解。它是保留名号的那套安排。停在公元前44年，你得到一次杀戮，没有一个政体。停在公元前31年，你得到一个赢家，没有一套安排。元首制就是三个圆点之间的关系。

:::warning 不是一个晚上
常见的迷思挑一个夜晚——三月十五，或亚克兴之后的那一夜，或公元前27年的那次议事——说自由终结于那时。这些年代就是不肯叠在一起。从公元前44年到公元前27年是17年，这17年包含又一场内战，以及一套既是言辞上的也是军事上的安排。另一个毛病是「自由」这个词。共和国曾经是男性公民之间的一场竞争，按财富加权，向妇女、奴隶和大多数行省居民关闭。终结那场竞争是真实的政治变更。把它称为自由本身的倒下，就是让一部狭隘的政制借用一种普世的哀悼。我们不编造奥古斯都的话，也不编造凶手们的话。这些标记已经够了，而它们是三个。
:::

尤利乌斯·凯撒在公元前44年3月15日遇刺。共和国没有因此恢复。亚克兴在公元前31年9月2日开战。公元前27年，屋大维被赐予奥古斯都这个名字，共和国的官职在一种新的君主制内部延续。
:::

## 通向何处

在公元前27年之后幸存下来的形式，是城市、军队与公民身份实际运行于其中的外壳。[[rome/imperial-society]] 问帝国的公民身份覆盖了什么，从公元79年一座被埋的城镇到公元212年的授予，并拒绝一个黄金时代。那些被掏空的官职，正是 [[rome/republic]] 里定义的官职。那些仍然是财产的人们，是 [[rome/slavery-and-conquest]] 的制度。一个标签如何能够藏起一条论断，是 [[sources/argument]] 的问题。

:::summary
- 凯撒在公元前44年3月15日被杀。凶手们没有恢复一个稳定的共和国。内战随之而来。年表没有收录的战役，我们不给它们定年。
- 公元前31年9月2日的亚克兴让屋大维成了赢家。它还还不是奥古斯都这个名字。从会战到那套安排的已过跨度是4年。
- 公元前27年，屋大维被称为奥古斯都。他没有取王的称号。执政官、元老院与共和的名号延续下去。最高的军事权力不再作为公开的奖品延续。
- 论断是双数的：君主制保留了形式，而形式不再组织那个至上权力。纯粹延续与纯粹断裂都是漫画。
- 从公元前44年到公元前27年是17年。「自由终结于一个晚上」过不了算术。多数成年人本来就没有持有那种自由。
- 元首制是史家给这个披着共和外衣的君主制起的名字。它不是黄金时代，也不是引自奥古斯都的话。
- 他权力的进一步调整常常被讨论。本图谱不锁定那个年份。公元前27年的安排已经足以支撑这条论断。

## 习题

:::exercise 从三月十五到那个名号 {level=1 check="17"}
计算从公元前44年到公元前27年的已过跨度。（请输入年数。）
:::solution
两个年份都是公元前。已过跨度是44减27，等于17年。这是一个晚上的故事必须压扁的跨度。它不是战役的次数。

17
:::
:::

:::exercise 那个名号的年份 {level=1 check="27"}
屋大维在哪一年获得奥古斯都这个名字？只输入公元前数字。（请输入数字。）
:::solution
那套安排定年为公元前27年。暗杀是公元前44年。亚克兴是公元前31年。名字属于三个标记里的最后一个。

27
:::
:::

:::exercise 从亚克兴到安排 {level=1 check="4"}
计算从公元前31年到公元前27年的已过跨度。（请输入年数。）
:::solution
已过跨度是31减27，等于4年。亚克兴产生一个赢家。奥古斯都这个名字在四年之后到来。把这两个年代熔在一起，就是在一个更小的空间里重演一晚上的错误。

4
:::
:::

:::exercise 凶手们没有达成的事 {level=2}
公元前44年3月15日的刺杀者们说他们在保卫共和国。在不编造引文的情况下，说明那个主张要求读者相信什么，以及为什么 [[#thm-ides]] 在记录那次杀戮的同时拒绝它的成功。
:::solution
那个主张要我们相信：移除凯撒就会恢复长官之间稳定的竞争，仿佛他是唯一的障碍。报告一个主张不是背书它。从三月十五到亚克兴的路是重起的内战。[[#thm-ides]] 把杀戮——它是真实的——同纲领分开，纲领并没有随之而来。会构成对这种分离的反证的，是一段在公元前44年和公元前31年之间锁定的正常共和竞争，其中武装的对手们各自收兵。下一个标记是他们没有躲开的那场会战。
:::
:::

:::exercise 保留，并且掏空 {level=2}
列出公元前27年之后延续下来的三种共和形式，以及一项不再作为公开奖品延续的权力。然后说明只列那三种形式为什么会把那套安排描述错。
:::solution
执政官继续就职。元老院继续开会。不称王的拒斥继续着，连同共和国的名号。最高的军事指挥权不再作为公开的奖品延续：握着主力军队的行省坐在奥古斯都一边。只列幸存的形式，就是把公元前27年当作复辟然后止步。[[#thm-forms]] 补上那次掏空。两句话都需要，而哪一句都不需要引用他自己的记述。
:::
:::

:::exercise 谁的自由 {level=2}
重写「公元前27年，罗马人民失去了他们的自由」这句话，使它点名谁失去了一场真实的竞争，谁被错误地包括在内。保留年份。
:::solution
公元前27年，罗马男性公民的任官阶层失去了对最高指挥权的公开竞争，而执政官、元老院与共和的名号在奥古斯都的至上权力内部延续。成年妇女、奴隶和大多数行省自由民在那一年没有失去投票权或官职，因为官职的共和国不曾给过他们那些东西。不加限定的「罗马人民」，是把一个显贵的失落出口给罗马统治的每一个人。
:::
:::

:::exercise 复辟不是驳倒 {level=3}
一位史家说：「罗马人把公元前27年称为共和国的复辟。如果形式延续着，它就是共和国。你的双数论断是拒绝倾听。」请答复。说出什么证据才算真正构成对 [[#thm-forms]] 的反证。
:::hint
倾听意味着报告他们的公开语汇，不是服从它。问公元前27年之后大指挥权坐在哪里，不只是问这个政体愿意被叫什么。
:::
:::solution
公开语汇是证据的一部分：他不被称为王，各长官职延续，那套安排是作为公共事务的回归被提供的。这正是论断说形式被保留的原因。服从语汇，就是让一个政体的称号否决军队坐在哪里这个问题。他后来那部功业记述是他的自辩，不是我们必须采纳的编年，我们不引用它。

官职的共和国，按 [[rome/republic]] 的定义，是一场仍能把最高指挥权授予出去的竞争。公元前27年之后，形式延续，那场竞争没有延续。对和平的感激不会把军事行省放回选举奖品的行列。会构成对 [[#thm-forms]] 反证的，是元老院与集会通常在大指挥权上压过他的证据，或者他废除官职、以王身份统治的证据。那套安排两头都不符合。
:::
:::

:::exercise 一个你不许添加的年份 {level=3}
你想叙述那次杀戮与亚克兴之间的内战。一部参考书提供两场著名战役，各带一个年份，而两个都不在这份年表里。它还提供一个公元前27年之后的较晚年份，属于对奥古斯都权力的一次法律重排。这些年你怎么办？没有它们你怎么讲这个故事？
:::hint
年表的沉默是本图谱的一条规则，不是主张那些空白里空无一物。讲锁定的标记已经包含的结果。不要在拒绝缺失战役的年份的同时，把它们的名字带回来。
:::
:::solution
把年份留着不加。不添加那些战役，也不添加那次较晚的重排。公元前44年3月15日，凯撒被杀，稳定的共和国没有回来。罗马统帅之间的内战一直继续，直到公元前31年9月2日，亚克兴让屋大维成了赢家。公元前27年，他被称为奥古斯都。执政官、元老院与共和的名号延续，最高的军事权力不再作为公开的奖品延续。对一次进一步的法律调整，本图谱里给出精确年份就会是编造，即便另一本书印得出一个。

关于形式与至上权力的那条论断从来不需要缺失的数字。它需要的是锁定的三个年代之间的距离，以及第三个年代的内容。
:::
