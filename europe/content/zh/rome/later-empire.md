为什么476年是一个惯例？

公元476年，奥多亚塞（Odoacer）废黜了罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）。教科书常常以那次废黜为罗马帝国收尾。这个收尾是一个惯例：不是罗马生活的终结，不是罗马国家的终结，也不是一则道德教训。东部的帝国仍在继续。朱利乌斯·尼波斯（Julius Nepos），一位对手的帝位宣称者，死于公元480年，按已过计数是4年之后。一个需要西部只死在一个时刻的故事，必须忽略尼波斯，忽略东部，忽略围绕那个年份的更漫长的变化：公元410年的洗劫，一代接一代的军事与政治崩坏，以及一个仍在运用罗马法、地产、城市与基督教制度的社会。

本章挪动那个终点。它从史家打包出的、被称为三世纪危机的时段讲起，公元235年到公元284年；然后是自公元284年起的戴克里先（Diocletian），公元312年10月28日的米尔维安桥（Milvian Bridge），公元313年的宽容，公元325年的公会议，以及公元330年5月11日君士坦丁堡的落成。至于官方的基督教宗教，它只是开了个头，在公元380年与公元391年。[[after-rome/christianisation]]继续那个题目。铅、基督教与腐化堕落被拒绝作为对公元476年的解释。彼得·希瑟（Peter Heather）的《罗马帝国的覆亡》（*The Fall of the Roman Empire*）把西部的军事损失当作真实的。它是一种讲述，不是神谕。其他史家强调安置与那些延续下来的东西。史家意见不一。西部政府的真实崩坏与一个惯例性的年份，可以同时成立。

## 五十年的标签，不是一个事件

从公元235年到公元284年，已过计数是49年。三世纪危机是史家的一个打包，不是一场战役、一朝统治或一个下午。在这道括号之内，不需要额外的年份，皇帝就被频繁地立起又推翻，许多人死于暴力。莱茵河、多瑙河和东部的边疆在交叠的几代人里承受压力。有一段时间，一些地区与中央决裂。铸币与税收陷入紧张，城市发现旧日的市政开支越来越难以为继。年表锁定了235与284，也锁定了这个标签把它们捆为一个时段的判断。它没有在括号之内锁定任何一个内战年份，所以我们也不发明一个。

史家对"危机"这个词的分量意见不一。一些人看到元首制与此后之间的一道断裂。另一些人看到的是一连串惨烈的战争：一些地区受损远甚于另一些地区，而精英、语言与土地占有延续了下去。会构成对使用这个标签本身之反驳的，是从公元235年到公元284年政府、军队与税收的寻常延续。这几十年看起来并非如此。会构成把这个标签称作单一事件之反驳的，是它的长度。49年各不相同的战争是一个时期。

:::definition 三世纪危机 {#def-crisis}
**三世纪危机**是史家为公元235年到公元284年这段时期所加的标签。它把频繁而暴烈的统治者更替、多条边疆上的压力、财政紧张与地区性分离的事件捆在一起。它不是单一事件，也不是罗马国家的覆亡。下一个世纪的帝国仍然是罗马的，是从这段时期里重建起来的。
:::

:::theorem 危机是一个打包，而戴克里先的统治不是它的最后一个下午 {#thm-bundle}
公元235–284年是史家对诸种危机的一个打包，不是单一事件。戴克里先自公元284年起，标记的是打包之后对统治的重建，不是一场已经完成的崩溃的终结。
:::
:::proof
年表把这道括号与戴克里先的年份一并给出。战争、篡位者与地区的多样，正是"打包"这个名词恰当的理由。他的统治开启了一种经过改组的君主制：同僚分共享有帝位，一张更密的行省与财政地图，一套比元首制的共和外衣更公然属于君主制的宫廷。会构成对这条论断之反驳的，是证明235–284年是一场战役，或证明公元284年什么都没改变的任何证据。共享统治与财政重建就是那个改变。同样会构成反驳的，是把单一原因说成全部49年的意义。没有任何这样一个原因被锁定。
:::

重建重建的是这些能力：征税，统率军队，把一个统治者呈现为不止是一名拒绝王号的行政官。[[rome/end-of-the-republic]]已经把最高权力的变更安放在公元前27年，而形式被保留。戴克里先的宫廷让这份最高权力更难被误认。本图谱没有锁定每一位同僚获任的年份，所以共享统治没有时间表。共享帝位覆盖了几条边疆，也没有终结内战。下一批有日期的事实，是公元312年罗马帝位宣称者之间的一场战役，与公元313年的一项协议。共享统治是一种技术，不是和平。

:::example 四十九年，以及一个下午的错误 {#ex-forty-nine}
计算从公元235年到公元284年的已过计数。一份概述说这场危机"持续了一瞬，直到戴克里先终结了罗马的麻烦"。这个计数对那句话做了什么？
:::solution
已过计数是284减235，即49年。一瞬不会持续49年。公元284年结束的是史家的括号。它没有结束罗马的麻烦，也没有结束内战。米尔维安桥还在前面，在公元312年。[[#thm-bundle]]把一次重建与"麻烦已经结束"的幻想分开。
:::
:::

## 从米尔维安桥到一座新首都

公元312年10月28日，按通常的定年，君士坦丁（Constantine）在米尔维安桥击败了马克森提乌斯（Maxentius）。这场战役是一场关于哪位罗马帝位宣称者占据西部的内战。它没有决定帝国的宗教，也没有创建一座教会。后来的基督教作家讲述君士坦丁曾在一个基督教的标记之下作战。我们不引用那个讲述，也不把那次异象当作事实。"通常的定年"意思是：我们讲授这一天，而不提供另一个数字。

公元313年，君士坦丁与李锡尼（Licinius）商定了一项宽容政策，后来被称为《米兰敕令》。这个名字是后来的。以下是转述，不作为他们的话：这项政策在其他崇拜之旁允许基督教的崇拜，以这对合伙者的政策身份终结了对基督徒的迫害，并发还了迫害所夺取的财产。宽容不是设立国教。从公元313年到公元325年的公会议是12年的已过计数，从公元313年到公元380年的敕令则是67年。这对合伙者本身没有维持下去。本图谱没有锁定君士坦丁与李锡尼后来开战的那一年，所以我们不发明它。政策与这个政治搭配是不同的事实。

公元325年的尼西亚（Nicaea）公会议是另一种行为。君士坦丁召集了主教们。他们争论圣子与圣父的关系——在那场与阿里乌（Arius）相联的争论之中——并通过了一份信经。转述，不作引用：公会议把圣子视为与圣父同具完全的神性，并拒绝了阿里乌的教导。界定正统，也就是界定谁在正统之外。皇帝在场的，正是教义被定下的那个房间，而基督教此时还不是官方宗教。争论没有在公元325年停止。公元451年的卡尔西顿（Chalcedon）是一次更晚的教义分裂，它属于[[after-rome/christianisation]]。说出它的名字，只是警告不要把尼西亚当作基督教分歧的终点。

公元330年5月11日，按传统的日期，君士坦丁为君士坦丁堡举行了落成奉献——那座古老的希腊城市拜占庭（Byzantium）被重建为帝国首都。我们讲授这个标记，不假装目睹过那场典礼。这次落成没有在一日之间创造一个新文明，也没有因为给东部的罗马国家改名就终结它。它给了那个国家一座比西部帝位更长寿的首都，这就是为什么公元476年不能是作为国家的罗马的终结。从公元330年到公元476年的已过计数是146年：一座首都的寿命，不是序章。[[after-rome/byzantium]]讲述后来的历史。

:::definition 宽容不是设立国教 {#def-toleration}
公元313年的协议，后来被称为《米兰敕令》，是一项**宽容**政策。这个名字是后来的。政策允许基督教的崇拜。它没有把基督教定为官方宗教，也没有描述每一个居民相信什么。官方宗教在这里定年为公元380年。
:::

:::theorem 312、313、325与330这些年份是不同的行为 {#thm-kinds}
米尔维安桥、宽容、尼西亚公会议与君士坦丁堡的落成，不构成一次归信。一场战役、一项许可、一条教义的界线与一座首都，是四个行为。
:::
:::proof
年表把它们分开：先是312年10月28日，然后是313年，然后是325年，然后是330年5月11日。从312年到313年，已过计数是一年；从313年到325年是十二年；从325年到330年是五年。一位对手被击败，一场迫害被放下，一份信经被通过，一座城市被奉献。会构成对这条论断之反驳的，是某一份公元312年的文献同时包含宽容、信经与落成。这样的文献不存在。桥边那个标记的故事把战役拉向一次归信。分开的数字抵抗这种拉扯。把公元313年称作设立国教，也会挫败这条论断。[[#def-toleration]]把这项许可与公元380年分开放置。
:::

:::example 从许可到官方宗教 {#ex-sixty-seven}
计算从公元313年到公元380年的已过计数，以及从公元380年到公元391年的已过计数。每个计数各自禁止什么？
:::solution
从313年到380年，已过计数是67年。从380年到391年是11年。前者禁止把宽容与官方宗教当作同一步。后者禁止把公元391年的措施与公元380年的敕令当作同一个行为。那些措施限制公共的多神教崇拜。它们不是一次信仰的清点。
:::
:::

:::quiz
公元313年的协议是什么？
- [ ] 基督教成为官方宗教的时刻
- [ ] 一次通过了尼西亚信经的公会议
- [x] 一项宽容政策，后来被称为《米兰敕令》，而这个名字是后来的
- [ ] 罗慕路斯·奥古斯都鲁斯的废黜
:::solution
[[#def-toleration]]与年表一致。官方宗教是公元380年。尼西亚是公元325年。废黜是公元476年。公元313年的协议是宽容，只是披了一个后来的名字。公元312年的战役不是这项协议。
:::
:::

## 官方宗教，只是开了头

公元380年的《帖撒罗尼迦敕令》把基督教定为帝国的官方宗教。把这句话当作法律来读。皇帝的信经成为国家的信经，而其他基督教的立场可能被视为异端。执行是一个过程，不是开关。主教、法庭与习惯并不同步移动，而公元380年不是一次信仰的清点。没有任何服从比例的百分比被锁定，所以一个也不给出。

公元391年，与狄奥多西（Theodosius）相联的措施限制了公共的多神教崇拜。禁止公共献祭，并不是每一处私人或乡间的实践都在那一年停下的证据。从380年到391年的这11年，把官方地位与对公共崇拜的禁令分开了。

这两个行为只是开启了基督教化。[[after-rome/christianisation]]继续讲它们，包括那些没有改变的东西：罗马法、地产与税收。基督教化不是一种欧洲精神的到来，也不是多神教理性的退场。这里没有任何东西导致公元476年。东部的帝国成了官方基督教的帝国，并且延续了下去。西部帝位，按惯例的定年，是在一个基督教帝国内部终结的。一个被延续的那一半也共享的原因，不可能是那个分别。从公元380年到公元476年的已过计数是96年。

## 洗劫、废黜与宣称者

公元410年8月24日，阿拉里克（Alaric）率领的西哥特人（Visigoths）洗劫了罗马。这次洗劫震撼了一座很久很久没有被外国军队攻取过的城市。它不是西部帝位的终结。宫廷已经不再与那座城市等同。我们不给宫廷的迁移定年，因为那一年没有被锁定。帝位在洗劫之后继续。它的惯例性终结是公元476年，按已过计数是66年之后。阿拉里克没有扶立奥多亚塞，也没有碰那座在公元330年奉献的首都。

在410年与476年之间，主要由罗马人称为蛮族的那些族群征募的军队，与西部的皇帝们讨价还价，有时甚至处置他们。"蛮族"是一句罗马人的骂名，后来成了一个时代标签，不是一种解释。哥特人及其他族群早已在军事体制之内。本章不逐一讲述每个王朝。未被锁定的篡位，就会是三世纪这个打包里已经拒绝过的虚假精确。

公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。这个名字回响着一则没有日期的建城传说，这就是为什么这次废黜能充当干净利落的一页终篇。被废黜的人是意大利的一位孩童皇帝，不是奠基者。按通常的记载，奥多亚塞没有取用西部的帝号，而是望向东部皇帝以求承认。西部帝位，作为一个独立的宫廷，不再有人充任。这是意大利治理的一次真实改变。当它被要求去终结罗马文明、罗马人民或罗马国家时，它就成了一个惯例。

朱利乌斯·尼波斯死于公元480年。他曾在东部得到承认，并且在废黜之后又活了4年。惯例偏爱意大利的那次废黜，因为它是半岛上更清楚的一道断裂。年表把两个年份都锁定，好让这个选择保持可见。

东部的帝国从公元330年的首都继续运转，自公元380年起是官方基督教的，并拥有罗马的法律、税收与军队。奥多亚塞的政变没有把它作废。后来的几个世纪称那个国家为拜占庭的。[[after-rome/byzantium]]解释这个名称。把"拜占庭的"当作一个生于公元476年的新物种，就是让这个惯例把罗马性定义为任何在西部死去的东西。

在西部，法律、地产、拉丁语、城市、教会与地方精英，在一些常常想要那台财政机器的国王治下延续。[[after-rome/successor-kingdoms]]讲述那段历史。希瑟的书坚持西部的军事崩坏是真实的。它不是针对那些强调延续的史家的一道判决。你可以认为中央政府失败了，同时仍然拒绝"罗马文明在公元476年终结"。

:::theorem 公元476年是一个惯例，不是罗马生活或罗马国家的终结 {#thm-476}
公元476年奥多亚塞废黜罗慕路斯·奥古斯都鲁斯，是西部帝位的惯例性终结。它不是罗马国家的终结，因为东部的帝国仍在继续；也不是西部罗马生活的终结。朱利乌斯·尼波斯死于公元480年，说明一项西部的宣称在废黜之后仍然活着。
:::
:::proof
年表把惯例与限度一并陈述。公元410年的洗劫与公元330年的首都，使476年成不了孤零零的高潮。希瑟的书表明，一份为西部真实崩坏而立的严肃论证是存在的，而且它是一种讲述。会构成对这条论断之反驳的，是一个在公元476年终结的东部的帝国，或者西部的法律、城市与土地占有在这一年作为一个整体停止。它们没有。会构成对那个较窄内容的反驳的，是罗慕路斯不曾被废黜的证据，或是一个延续的西部宫廷不顾一切地维持下去的证据。废黜成立。全盘式的终结不成立。
:::

:::example 四年与一位宣称者 {#ex-four}
计算从公元476年到公元480年的已过计数，以及从公元410年到公元476年的已过计数。一条时间线只印出476年，并把它注作"罗马的覆亡"。它删掉了什么？
:::solution
从476年到480年，已过计数是4年。从410年到476年是66年。这条时间线删掉了阿拉里克的洗劫与朱利乌斯·尼波斯之死，而且没有给一个不停下来的东部的帝国留下位置。这条图注把意大利的一次废黜变成了罗马这个名字的终结。[[#thm-476]]保留了这次废黜。洗劫在公元410年8月24日。尼波斯死于公元480年。东部仍在继续。
:::
:::

:::example 一个原因，东部也共享 {#ex-shared-cause}
这些句子不是史料。"西部覆亡，是因为输水管里的铅。""西部覆亡，是因为它成了基督教的。""西部覆亡，是因为腐化堕落。"用东部的帝国的延续，用公元380年与公元476年这两个年份，说明为什么它们都不能是东部与西部之间的那个分别。
:::solution
西部帝位终结的一个原因，必须是东部所没有的，或者必须在这两半之间有所不同，而且你说得出不同的理由。铅、基督教与精英的奢侈，都曾对整个罗马世界被提出过。东部是罗马的，自公元380年起是官方基督教的，并且在公元476年之后延续。一个共享的特征，单凭自己挑不出西部。从380年到476年的已过计数是96年，所以基督教也不是那道敕令的即时效果。不要用另一个单一名词替换这三个句子。军事压力、财政失败与同军队的交易，是一团史家——包括希瑟——争论不休的东西。它们不是一句格言。
:::
:::

把年份移动，直到476年坐在410年与480年之间。那条线就是[[#thm-476]]。然后注意，313年与380年不是邻居。这张图没有铅、腐化堕落或信仰清点的点。窗口宽十二年，是为了让476年与480年能成对地被看见。

:::warning 不是一句话，也不是一种文明的终结
铅、基督教与腐化堕落，每一个都是被要求去解释一场并不单一的事件的变化的那句话，而且在通常的讲述里，每一个都是与一个在公元476年没有失去自己帝位的东部的帝国共享的。这里的基督教是一串行为：313年的宽容，325年的公会议，380年的官方宗教，391年对公共多神教崇拜的限制。这些行为只是开启了基督教化。腐化堕落是一句骂名，不是一个可检验的原因。铅是一个本份年表没有锁定的物质故事。

废黜是真实的。西部的罗马生活没有因它而熄灭，东部的国家也没有因它而熄灭。尼波斯死于公元480年。希瑟关于西部崩坏的讲述，属于这个分别，站在它旁边。它并不为"当西部宫廷不再有人充任时罗马就终结了"这句话发放许可。
:::

:::history
公元235年到公元284年这段时期，是被称为三世纪危机的打包；戴克里先的统治定年为自公元284年起。阿拉里克的西哥特人在公元410年8月24日洗劫了罗马。公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。东部的帝国仍在继续，而朱利乌斯·尼波斯死于公元480年。476年这个年份是一个惯例，不是罗马生活的终结。
:::

## 通向何处

西部帝位是一个带日期的惯例。延续下去的是一系列社会、教会，和一个东部的罗马国家。[[after-rome/christianisation]]把313、325、380、391与公元451年的公会议讲到超出开端的更远处。[[after-rome/successor-kingdoms]]接管西部宫廷失灵之后治理罗马行省的那些王国。[[after-rome/byzantium]]接管那个没有停下来的国家。把东部和尼波斯之死保持在论断之内，是与[[sources/argument]]同一种纪律。

:::summary
- 从公元235年到公元284年是49年。三世纪危机是史家的一个打包，不是单一事件。戴克里先自公元284年起重建统治，没有终结罗马历史。
- 按通常的定年，公元312年10月28日君士坦丁在米尔维安桥击败马克森提乌斯。公元313年，他与李锡尼商定宽容，后来被称为《米兰敕令》。这个名字是后来的。宽容不是一个官方教会。
- 公元325年的尼西亚划下一条教义的界线。君士坦丁堡传统的落成日期是公元330年5月11日。一座东部的首都，就是为什么公元476年不能终结罗马国家。
- 公元380年的《帖撒罗尼迦敕令》把基督教定为官方宗教。执行不是一次信仰的清点。公元391年针对公共多神教崇拜的措施是又一个行为。这些行为只是开启了基督教化。
- 阿拉里克在公元410年8月24日洗劫罗马。奥多亚塞在公元476年废黜了罗慕路斯·奥古斯都鲁斯。朱利乌斯·尼波斯死于公元480年。史家对西部崩坏的范围意见不一。
- 东部的帝国仍在继续。西部的法律、城市、土地与教会没有停止。希瑟的书是关于一次真实的军事与政治损失的一种讲述，不是神谕。
- 铅、基督教与腐化堕落作为一句话的原因都不成立。一个与东部共享的原因无法区分这两半。
:::

## 练习

:::exercise 这个打包的长度 {level=1 check="49"}
计算从公元235年到公元284年的已过计数。（请输入年数。）
:::solution
两个年份都是公元。已过计数是284减235，即49年。这段跨度是三世纪危机的括号，对一个下午来说太长了。

49
:::
:::

:::exercise 从废黜到宣称者之死 {level=1 check="4"}
计算从公元476年到公元480年的已过计数。（请输入年数。）
:::solution
已过计数是480减476，即4年。朱利乌斯·尼波斯死于罗慕路斯·奥古斯都鲁斯被废黜的四年之后。

4
:::
:::

:::exercise 从宽容到官方宗教 {level=1 check="67"}
计算从公元313年到公元380年的已过计数。（请输入年数。）
:::solution
已过计数是380减313，即67年。313年这一年是宽容。380年这一年是官方宗教。它们不是同一个行为的两个名字。

67
:::
:::

:::exercise 为什么这个标签不是一个事件 {level=2}
解释三世纪危机，使它不致被误当作一场战役，也使公元284年的戴克里先不致成为那个终结了罗马麻烦的人。
:::solution
这个标签覆盖公元235年到公元284年，已过计数49年。在它之内，不需要额外的数字，统治者暴烈地更替，几条边疆被进逼，一些地区有一段时间脱离出去，税收陷入紧张。史家对这场变化的深度意见不一。戴克里先开启一次重建：共享的帝位、一个更重的财政国家、一套更公然属于君主制的宫廷。帝位宣称者之间的内战，在有日期的记载中于公元312年在米尔维安桥重演。这个计数描述的是长度。它不是原因。
:::
:::

:::exercise 后来的名字 {level=2}
一条图注把公元313年称作"《米兰敕令》，君士坦丁在此把基督教定为国教"。请纠正这个名称、行为者与法律效果，并说出这条图注偷运进来的年份。
:::solution
君士坦丁与李锡尼在公元313年商定宽容。"《米兰敕令》"是后来的名字。基督教的崇拜得到允许。官方宗教是公元380年的《帖撒罗尼迦敕令》，按已过计数晚67年。这条图注偷运进380年，删掉李锡尼，还把一个绰号当作皇帝的头衔。公元325年的尼西亚是一份信经，不是这项协议。[[#def-toleration]]把许可与设立国教分开。
:::
:::

:::exercise 洗劫对废黜 {level=2}
比较公元410年8月24日与公元476年。对每一个，说出什么改变了，什么不得被推断出来。让东部的帝国留在你的答案里。
:::solution
公元410年8月24日，阿拉里克的西哥特人洗劫了那座城市。改变的是城市的安全。西部帝位没有终结，东部的帝国未受触动。公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。按惯例的说法，意大利的西部帝位不再有人充任。罗马文明没有终结，罗马国家也没有终结：东部仍在继续，尼波斯死于公元480年，西部的法律、城市与教会仍在延续。这两个年份之间的已过计数是66年。
:::
:::

:::exercise 拒绝那句话 {level=3}
用四句话改写这个结尾："公元476年，罗马文明终结了，因为铅、基督教与腐化堕落使帝国衰弱了。"保留废黜、东部、尼波斯，以及对一句话原因的拒绝。不要发明一句替代的格言。
:::hint
说出这个惯例标记什么——西部帝位——以及它不标记什么。一个共享的原因无法把东部与西部分开。希瑟是关于一次真实的西部崩坏的一种讲述，不是那个缺席的单词原因。
:::
:::solution
公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯，这是意大利西部帝位的惯例性终结。它不是罗马文明或罗马国家的终结：东部的帝国仍在继续，而朱利乌斯·尼波斯直到公元480年才死去。铅、基督教与腐化堕落解释不了那个分别，因为在它们通常的形态里，它们是与东部共享的。希瑟的讲述把西部崩坏当作真实的，但它仍然是一种讲述，不是投进空格里的那个名词。

一个新的单词原因只会重复这个错误。被允许的正面陈述是一团东西：对西部军队的压力、财政与政治的失败，以及与武装集团的交易——在延续问题上意见不一的史家对这些东西的权衡各不相同。
:::
:::

:::exercise 这个窗口是用来做什么的 {level=3}
这张图除了476年之外还包括313年、380年与480年。一位设计者想把那三个删掉，"以便聚焦于覆亡"。为保留每一个提出论证，并说出这次删除会产出什么故事。
:::hint
宽容不是官方宗教。官方宗教不是476年的原因，而且东部与它共享。尼波斯之死使476年成为一种标记的选择。"覆亡"是那个惯例以设计任务书的形式到场。
:::
:::solution
保留公元313年，因为它是披着一个后来的名字的宽容。从米尔维安桥跳到一次洗劫，会让一场战役看起来像一次归信。保留公元380年，因为官方宗教是整个帝国的一部法律，在宽容之后67年，而且被一个仍在延续的东部共享。没有它，基督教就作为一个造成了废黜的情绪飘在那里。保留公元480年，因为尼波斯死在那一年。没有它，那四年的计数就消失了，476年看起来就像西部最后一件事实。

这次删除就是教科书的惯例：危机、基督教的战役、洗劫、覆亡。公开的窗口之所以存在，是为了让476年坐在480年旁边。废黜可以留下。需要限定的词是"覆亡"：西部帝位的惯例性终结，不比它更大。
:::
:::
