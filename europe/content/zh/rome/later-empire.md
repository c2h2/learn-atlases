为什么说476年是一个惯例？

公元476年，奥多亚塞（Odoacer）废黜了罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）。教科书往往以这次废黜为罗马帝国画上句号。这个句号是一种惯例：它既不是罗马生活的终结，也不是罗马国家的终结，更不是一个道德教训。东部帝国依然延续。另一位帝位宣称者朱利乌斯·尼波斯（Julius Nepos）死于公元480年，即4年之后。一个需要西部在某一时刻应声而亡的故事，必须忽略尼波斯，忽略东部，也忽略这一年份前后更漫长的变化：公元410年的洗劫，几代人之久的军事和政治崩坏，以及一个仍在运用罗马法、土地所有制、城市和基督教制度的社会。

本章挪动了这个终点。它从被历史学家统称为“三世纪危机”的公元235年至公元284年讲起，然后是公元284年起的戴克里先（Diocletian），公元312年10月28日的米尔维安桥（Milvian Bridge）之战，公元313年的宽容政策，公元325年的公会议，以及公元330年5月11日君士坦丁堡的落成。至于基督教成为官方宗教，本章只讲到公元380年和公元391年的开端，后续由[[after-rome/christianisation]]继续。铅中毒、基督教和腐化堕落，都被拒绝作为对公元476年的解释。彼得·希瑟（Peter Heather）的《罗马帝国的陨落》（*The Fall of the Roman Empire*）认为西部的军事失败是真实的。这是一种论述，而不是神谕。其他历史学家强调相互适应以及延续下来的东西。历史学家们看法不一。西部政府的真实崩溃与一个惯例性的年份，可以同时成立。

## 五十年的标签，而不是一个事件

从公元235年到公元284年，经过的年数是49年。“三世纪危机”是历史学家的一个统称，而不是一场战役、一个统治时期或一个下午。在这一起讫之内，无须补充年份就可以说：皇帝频繁地被拥立又被推翻，许多人死于暴力；莱茵河、多瑙河和东方的边疆在相互交叠的几代人中承受压力；有一段时间，一些地区与中央分离；货币和税收陷入困境，城市越来越难以维持旧日的公共开支。年表锁定了235年和284年，也锁定了用这个标签将其统称起来的判断。它没有在这一起讫之内锁定任何内战年份，所以我们也不杜撰一个。

对于“危机”一词的分量，历史学家看法不一。有些人看到的是元首制与其后时期之间的一次断裂；另一些人看到的是一连串惨烈的战争，使一些地区受到的损害远远大于另一些地区，而精英、语言和土地占有则延续了下来。能够推翻使用这个标签本身的，是公元235年至公元284年间政府、军队和税收的正常延续。但这几十年并非如此。能够推翻把这个标签说成单一事件的，是它的长度：49年间各不相同的战争，构成的是一个时期。

:::definition 三世纪危机 {#def-crisis}
**三世纪危机**是历史学家给公元235年至公元284年这一时期贴的标签。它统称了频繁而暴力的统治者更替、多条边疆所受的压力、财政困境以及地区分离事件。它不是一个单一事件，也不是罗马国家的灭亡。下一个世纪的帝国依然是罗马的，是在这一时期之后重建起来的。
:::

:::theorem 危机是一个统称，戴克里先的统治不是它的最后一个下午 {#thm-bundle}
公元235–284年是历史学家对一系列危机的统称，而不是一个单一事件。戴克里先从公元284年开始的统治，标志着这些危机之后统治的重建，而不是一场早已完成的崩溃的终结。
:::
:::proof
年表同时给出了这一起讫和戴克里先的年份。战争、篡位者和地区的多样性，正是“统称”一词恰当的原因。他的统治开启了一种经过重组的君主制：几位同僚分享皇帝的地位；行省和财政区划更加细密；宫廷比元首制那件共和外衣更加公开地具有君主色彩。能够推翻这条论断的，是证明235–284年只是一场战役，或证明公元284年什么也没有改变的证据。而分享统治和财政重建，正是那种改变。同样能够推翻它的，是把某一个单一原因说成全部49年的意义。但年表没有锁定任何这样的原因。
:::

这次重建恢复了征税和统率军队的能力，也恢复了把统治者呈现为不只是一个拒绝王号的官员的能力。[[rome/end-of-the-republic]]已经把至高权力的变化定在公元前27年，而那时形式被保留了下来。戴克里先的宫廷使这种至高权力更不容易被误认。本图谱没有锁定每一位同僚受任的年份，所以分享统治没有时间表。分享帝位覆盖了几条边疆，却没有终结内战。接下来有确切年代的事实，是公元312年罗马帝位宣称者之间的一场战役，以及公元313年的一项协议。分享统治是一种手段，而不是和平。

:::example 四十九年，以及“一个下午”的错误 {#ex-forty-nine}
计算从公元235年到公元284年经过的年数。一份概述说，这场危机“只持续了片刻，直到戴克里先终结了罗马的麻烦”。这个计算结果对这句话意味着什么？
:::solution
经过的年数是284减235，即49年。片刻不会持续49年。公元284年结束的是历史学家所划定的起讫，并没有结束罗马的麻烦，也没有结束内战：米尔维安桥之战还在后面，在公元312年。[[#thm-bundle]]把一次重建与“麻烦已经结束”的幻想区分开来。
:::
:::

## 从米尔维安桥到一座新都城

按照通常的定年，公元312年10月28日，君士坦丁（Constantine）在米尔维安桥击败了马克森提乌斯（Maxentius）。这场战役是一场争夺哪位罗马帝位宣称者占有西部的内战。它没有决定帝国的宗教，也没有建立教会。后来的基督教作家说，君士坦丁是在一个基督教标记下作战的。我们不引用这一说法，也不把那次异象当作事实。“通常的定年”意味着我们讲授这一天，而不提供另一个日期。

公元313年，君士坦丁与李锡尼（Licinius）商定了一项宽容政策，后来被称为《米兰敕令》，这个名称是后起的。转述（而非引用他们的原话）：这项政策允许基督教崇拜与其他崇拜并存，作为两人共同的政策终止了对基督徒的迫害，并归还了迫害中被夺走的财产。宽容并不等于确立国教。从公元313年到公元325年的公会议，经过的年数是12年；从公元313年到公元380年的敕令，是67年。两人的合作本身没有维持下去。本图谱没有锁定君士坦丁与李锡尼后来交战的年份，所以我们不杜撰它。这项政策与这对政治搭档，是两个不同的事实。

公元325年的尼西亚（Nicaea）公会议是另一种性质的行为。君士坦丁召集了主教们。他们在与阿里乌（Arius）相关的那场争论中，就圣子与圣父的关系展开辩论，并通过了一份信经。转述而不引用：公会议认定圣子与圣父同样具有完全的神性，并否定了阿里乌的教导。界定正统，也就界定了谁在正统之外。皇帝出现在确定教义的场合，而基督教此时还不是官方宗教。争论并没有在公元325年停止。公元451年的卡尔西顿（Chalcedon）公会议是后来的一次教义分裂，属于[[after-rome/christianisation]]的内容。在这里提到它，只是为了提醒不要把尼西亚当作基督教内部分歧的终点。

按照传统的日期，公元330年5月11日，君士坦丁为君士坦丁堡举行了落成典礼。这座城市原是古希腊城市拜占庭（Byzantium），被重建为帝国的都城。我们讲授这一标志，而不假装亲眼见过那场典礼。这次落成并没有在一天之内创造出一种新文明，也没有因为换了名称就终结东部的罗马国家。它给了这个国家一座比西部帝位存在得更久的都城，这正是公元476年不能作为罗马国家终结的原因。从公元330年到公元476年，经过的年数是146年：这是一座都城的生命，而不是一段序幕。后来的历史由[[after-rome/byzantium]]讲述。

:::definition 宽容不等于确立国教 {#def-toleration}
公元313年的协议，后来被称为《米兰敕令》，是一项**宽容**政策，这个名称是后起的。这项政策允许基督教崇拜，却没有把基督教定为官方宗教，也没有描述每一个居民的信仰。本图谱把官方宗教的确立定于公元380年。
:::

:::theorem 312年、313年、325年和330年是不同性质的行为 {#thm-kinds}
米尔维安桥之战、宽容政策、尼西亚公会议和君士坦丁堡的落成，并不构成一次皈依。一场战役、一项许可、一条教义界线和一座都城，是四种不同的行为。
:::
:::proof
年表把它们区分开来：先是312年10月28日，然后是313年，然后是325年，然后是330年5月11日。从312年到313年经过一年，从313年到325年经过十二年，从325年到330年经过五年。一个对手被击败，一场迫害被停止，一份信经被通过，一座城市举行了落成典礼。能够推翻这条论断的，是一份公元312年的文献，其中同时包含了宽容政策、信经和落成。但并不存在这样的文献。桥边那个标记的故事，把这场战役拉向一次皈依，而这些各自分开的年份抵制着这种拉扯。把公元313年说成确立了国教，也会推翻这条论断。[[#def-toleration]]把这项许可与公元380年区分开来。
:::

:::example 从许可到官方宗教 {#ex-sixty-seven}
计算从公元313年到公元380年、从公元380年到公元391年各自经过的年数。每个计算结果各自排除了什么？
:::solution
从313年到380年，经过的年数是67年；从380年到391年，是11年。前者排除了把宽容和官方宗教当作同一步；后者排除了把公元391年的措施与公元380年的敕令当作同一个行为。那些措施限制的是公开的多神教祭祀，而不是对信仰的统计。
:::
:::

:::quiz
公元313年的协议是什么？
- [ ] 基督教成为官方宗教的时刻
- [ ] 一次通过了尼西亚信经的公会议
- [x] 一项宽容政策，后来被称为《米兰敕令》，这个名称是后起的
- [ ] 罗慕路斯·奥古斯都鲁斯被废黜
:::solution
[[#def-toleration]]与年表相符。官方宗教在公元380年，尼西亚公会议在公元325年，废黜在公元476年。公元313年的协议是一项冠以后起名称的宽容政策。公元312年的战役也不是这项协议。
:::
:::

## 官方宗教：只是一个开端

公元380年，《帖撒罗尼迦敕令》把基督教定为帝国的官方宗教。要把这句话当作法律来读：皇帝们的信经成为国家的信经，其他基督教立场可以被视为异端。执行是一个过程，而不是一个开关。主教、法庭和习俗并不同步变化，公元380年也不是一次信仰普查。没有锁定任何遵从比例，所以这里不给出百分比。

公元391年，与狄奥多西（Theodosius）相关的一些措施限制了公开的多神教祭祀。禁止公开献祭，并不能证明每一种私人或乡村的宗教实践都在那一年停止了。从380年到391年的这11年，把官方地位与对公开祭祀的禁令区分开来。

这两个行为只是基督教化的开端，[[after-rome/christianisation]]接着讲述它们，包括那些没有改变的东西：罗马法、土地所有制和税收。基督教化不是一种欧洲精神的降临，也不是多神教理性的退场。这里没有任何东西导致了公元476年。东部成为官方信奉基督教的帝国，并延续了下来；西部帝位按照惯例的定年，是在一个基督教帝国之中终结的。一个为延续下来的那一半所共有的原因，不可能是东西两部的差别所在。从公元380年到公元476年，经过的年数是96年。

## 洗劫、废黜与帝位宣称者

公元410年8月24日，阿拉里克（Alaric）率领的西哥特人（Visigoths）洗劫了罗马。这次洗劫震动了一座已经很久没有被外族军队攻陷过的城市，但它并不是西部帝位的终结。宫廷此时已不再等同于这座城市。我们不给宫廷的迁移定年，因为那一年没有锁定。洗劫之后，帝位依然存在，其惯例性的终结是在66年之后的公元476年。阿拉里克没有扶立奥多亚塞，也没有触及公元330年落成的那座都城。

从410年到476年，主要从罗马人称为“蛮族”的那些民族中招募的军队，与西部的皇帝们讨价还价，有时还废黜他们。“蛮族”是罗马人的一种蔑称，后来成了一个时代名称，而不是一种解释。哥特人和其他民族早已身处军事体制之中。本章不逐一讲述每个皇帝的统治。列出没有锁定的篡位事件，就是在三世纪危机中已经拒绝过的那种虚假精确。

公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。这个名字令人想起一个没有确切年代的建城传说，因此这次废黜成了一个工整的结尾。被废黜的人是意大利的一位少年皇帝，而不是一位缔造者。按照通常的叙述，奥多亚塞没有采用西部皇帝的称号，而是寻求东部皇帝的承认。作为一个独立宫廷的西部帝位从此无人继任。这是意大利统治的一次真实变化。但当人们要求它代表罗马文明、罗马人民或罗马国家的终结时，它就成了一种惯例。

朱利乌斯·尼波斯死于公元480年。他曾得到东部的承认，并在那次废黜之后又活了4年。惯例偏爱意大利的那次废黜，因为它是半岛上更清晰的断裂。年表把两个年份都锁定了下来，好让这种选择始终清晰可见。

东部帝国从公元330年的都城继续运转，自公元380年起正式信奉基督教，拥有罗马的法律、税收和军队。奥多亚塞的政变并没有使它失效。后来的几个世纪把这个国家称为“拜占庭帝国”，[[after-rome/byzantium]]解释了这一名称。把“拜占庭”当作公元476年诞生的一个新物种，就等于让这个惯例把“罗马性”界定为在西部消亡的那些东西。

在西部，法律、土地所有制、拉丁语、城市、教会和地方精英，在往往希望保留那套财政机器的国王们的统治下延续了下来，这段历史由[[after-rome/successor-kingdoms]]讲述。希瑟的书坚持认为，西部的军事崩溃是真实的，但这并不是对那些强调延续性的历史学家的裁决。你可以认为中央政府失败了，同时仍然拒绝“罗马文明终结于476年”的说法。

:::theorem 公元476年是一个惯例，而不是罗马生活或罗马国家的终结 {#thm-476}
公元476年奥多亚塞废黜罗慕路斯·奥古斯都鲁斯，是西部帝位的惯例性终结。它不是罗马国家的终结，因为东部帝国依然延续；也不是西部罗马生活的终结。朱利乌斯·尼波斯于公元480年去世，表明西部的一项帝位主张比这次废黜存在得更久。
:::
:::proof
年表把这一惯例及其限度放在一起陈述。公元410年的洗劫和公元330年的都城，使476年无法成为一个孤立的高潮。希瑟的书表明，关于西部真实崩溃的严肃论证是存在的，而它是一种论述。能够推翻这条论断的，是东部帝国在公元476年终结，或者西部的法律、城市和土地占有在那一年整体停止。但事实并非如此。能够推翻其中较窄内容的，是罗慕路斯并未被废黜的证据，或者一个连续的西部宫廷照旧存在下去的证据。废黜是成立的，全面终结则不成立。
:::

:::example 四年与一位帝位宣称者 {#ex-four}
计算从公元476年到公元480年、从公元410年到公元476年各自经过的年数。一条时间线只标出476年，并注明“罗马的陨落”。它删掉了什么？
:::solution
从476年到480年，经过的年数是4年；从410年到476年，是66年。这条时间线删掉了阿拉里克的洗劫和朱利乌斯·尼波斯之死，也没有为一个并未终止的东部帝国留下位置。这则图注把意大利的一次废黜变成了罗马之名的终结。[[#thm-476]]保留了这次废黜。洗劫发生在公元410年8月24日，尼波斯死于公元480年，东部依然延续。
:::
:::

:::example 一个东部同样具有的原因 {#ex-shared-cause}
下面这些句子不是史料。“西部灭亡是因为水管里的铅。”“西部灭亡是因为它皈依了基督教。”“西部灭亡是因为腐化堕落。”请利用东部帝国的延续以及公元380年和公元476年这两个年代，说明为什么其中任何一个都不能成为东西两部的差别所在。
:::solution
西部帝位终结的原因，必须是东部所没有的，或者在两部之间有所不同，而且你能说出不同的理由。铅、基督教和精英的奢靡，都曾被用来解释整个罗马世界。东部是罗马的，自公元380年起正式信奉基督教，并在公元476年之后延续下来。一个共有的特征，本身无法把西部挑选出来。从380年到476年经过了96年，所以基督教也不是那道敕令的直接后果。不要用另一个单一名词来替换这三句话。军事压力、财政失败以及与军队的交易，是一组历史学家（包括希瑟在内）争论不休的因素，而不是一句格言。
:::
:::

废黜确实发生了，它是西部帝位的惯例性终结。东部帝国没有终结。尼波斯死于公元480年，废黜不是他所为。[[#thm-476]]保留了这两个方面。“惯例”并不意味着“虚构”。
:::

:::warning 不是一句话，也不是一种文明的终结
铅、基督教和腐化堕落，都是被要求用来解释一场并非单一事件的变化的一句话；而且按照通常的说法，每一个都同样适用于一个在公元476年并没有失去帝位的东部帝国。这里的基督教是一系列行为：313年的宽容，325年的公会议，380年的官方宗教，391年对公开多神教祭祀的限制。这些行为只是基督教化的开端。腐化堕落是一种骂名，而不是可以检验的原因。铅是一个本年表没有锁定的物质层面的故事。

废黜是真实的，但西部的罗马生活并没有因此熄灭，东部的国家也没有因此熄灭。尼波斯死于公元480年。希瑟关于西部崩溃的论述，应当与这一区分放在一起，它并不能为“西部宫廷无人继任时罗马就终结了”这句话提供依据。
:::

:::history
公元235年至公元284年这一时期，被统称为“三世纪危机”；戴克里先的统治从公元284年算起。公元410年8月24日，阿拉里克率领的西哥特人洗劫了罗马。公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。东部帝国依然延续，朱利乌斯·尼波斯死于公元480年。476年是一个惯例，而不是罗马生活的终结。
:::

## 通向何处

西部帝位是一个有确切年代的惯例。延续下来的，是一系列社会、教会和一个东部的罗马国家。[[after-rome/christianisation]]把313年、325年、380年、391年以及公元451年的公会议讲得比开端更远。[[after-rome/successor-kingdoms]]讲述西部宫廷失效之后统治罗马行省的那些王国。[[after-rome/byzantium]]讲述那个没有终止的国家。把东部和尼波斯之死保留在论断之中，与[[sources/argument]]要求的是同一种纪律。

:::summary
- 从公元235年到公元284年是49年。“三世纪危机”是历史学家的统称，而不是一个单一事件。戴克里先从公元284年起重建了统治，并没有终结罗马历史。
- 按照通常的定年，公元312年10月28日，君士坦丁在米尔维安桥击败马克森提乌斯。公元313年，他与李锡尼商定了宽容政策，后来被称为《米兰敕令》，这个名称是后起的。宽容并不是确立官方教会。
- 公元325年的尼西亚公会议划出了一条教义界线。按照传统的日期，君士坦丁堡于公元330年5月11日落成。正是这座东部都城，使公元476年不能作为罗马国家的终结。
- 公元380年的《帖撒罗尼迦敕令》把基督教定为官方宗教。执行并不是信仰普查。公元391年针对公开多神教祭祀的措施是又一个行为。这些行为只是基督教化的开端。
- 阿拉里克于公元410年8月24日洗劫罗马。奥多亚塞于公元476年废黜罗慕路斯·奥古斯都鲁斯。朱利乌斯·尼波斯死于公元480年。对于西部崩溃的范围，历史学家看法不一。
- 东部帝国依然延续。西部的法律、城市、土地和教会都没有停止。希瑟的书是对一场真实的军事和政治失败的一种论述，而不是神谕。
- 铅、基督教和腐化堕落，作为一句话的原因都站不住脚。一个东部同样具有的原因，无法区分东西两部。
:::

:::exercise 这个标签为什么不是一个事件 {level=2}
请解释三世纪危机，使它不会被误认为是一场战役，也使公元284年的戴克里先不会被当作终结了罗马麻烦的人。
:::solution
这个标签涵盖公元235年至公元284年，经过的年数是49年。在这一时期内，无须补充年份就可以说：统治者暴力更替，多条边疆受到压迫，一些地区一度分离，税收陷入困境。历史学家对这一变化的深度看法不一。戴克里先开启了一次重建：分享的帝位，更沉重的财政国家，更加公开的君主制宫廷。在有确切年代的记录中，帝位宣称者之间的内战在公元312年的米尔维安桥再次出现。这个计算结果描述的是时长，而不是原因。

:::exercise 后起的名称 {level=2}
一则图注把公元313年称为“《米兰敕令》，君士坦丁借此把基督教定为国教”。请纠正其中的名称、行为者和法律效果，并指出这则图注偷运进来的年份。
:::solution
公元313年，君士坦丁与李锡尼商定了宽容政策。“《米兰敕令》”是后起的名称。这项政策允许基督教崇拜。确立官方宗教的是公元380年的《帖撒罗尼迦敕令》，按经过的年数算晚了67年。这则图注偷运进了380年，删掉了李锡尼，还把一个俗称当作了皇帝的正式名称。公元325年的尼西亚公会议通过的是一份信经，而不是这项协议。[[#def-toleration]]把许可与确立国教区分开来。
:::

:::exercise 洗劫与废黜 {level=2}
比较公元410年8月24日与公元476年。分别说明各自改变了什么，又不能由此得出什么结论。在回答中要保留东部帝国。
:::solution
公元410年8月24日，阿拉里克率领的西哥特人洗劫了这座城市。改变的是城市的安全。西部帝位没有终结，东部帝国也未受触动。公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。按照惯例的说法，意大利的西部帝位从此无人继任。但罗马文明没有终结，罗马国家也没有终结：东部依然延续，尼波斯死于公元480年，西部的法律、城市和教会仍在延续。这两个年份之间经过的年数是66年。
:::
:::

:::exercise 拒绝那句话 {level=3}
用四句话改写这个结尾：“公元476年，罗马文明终结了，因为铅、基督教和腐化堕落削弱了帝国。”保留废黜、东部、尼波斯，以及对一句话原因的拒绝。不要杜撰一句替代的格言。
:::hint
说明这个惯例标志着什么——西部帝位——以及它不标志什么。一个东西两部共有的原因无法区分两者。希瑟的书是对西部真实崩溃的一种论述，而不是那个缺失的单一原因。
:::
:::solution
公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯，这是意大利西部帝位的惯例性终结。它不是罗马文明或罗马国家的终结：东部帝国依然延续，朱利乌斯·尼波斯直到公元480年才去世。铅、基督教和腐化堕落解释不了这种差别，因为按照通常的说法，东部同样具有这些因素。希瑟的论述认为西部的崩溃是真实的，但它依然只是一种论述，而不是一个可以填进空白的名词。

一个新的单一原因只会重复这个错误。可以作出的正面陈述是一组因素：西部军队所受的压力，财政和政治的失败，以及与武装集团的交易；而在延续性问题上看法不一的历史学家，对这些因素的权衡各不相同。
:::
:::

:::exercise 这个窗口的用途 {level=3}
这张图除了476年之外，还包括313年、380年和480年。一位设计者想删掉这三个年份，“以便聚焦于陨落”。请分别论证为什么要保留它们，并说明删除之后会形成什么样的故事。
:::hint
宽容不是官方宗教。官方宗教不是476年的原因，而且东部同样具有它。尼波斯之死使476年成为对一个标志的选择。“陨落”是这一惯例以设计要求的形式出现了。
:::
:::solution
保留公元313年，因为它是冠以后起名称的宽容政策。从米尔维安桥直接跳到一次洗劫，会让一场战役看起来像一次皈依。保留公元380年，因为官方宗教是一部适用于整个帝国的法律，晚于宽容政策67年，而且一个延续下来的东部同样具有它。没有它，基督教就会作为一种导致了废黜的氛围飘浮在那里。保留公元480年，因为尼波斯死于那一年。没有它，那四年的计算就消失了，476年看起来就像是西部的最后一个事实。

删除之后，就成了教科书的惯例：危机、基督教的战役、洗劫、陨落。这个公开的窗口之所以存在，就是为了让476年位于480年旁边。废黜可以保留。需要加以限定的是“陨落”一词：它指西部帝位的惯例性终结，仅此而已。
:::
