撇开诞生的故事，共和国究竟是什么？

后来的罗马人讲了一个干净利落的故事：这座城市曾由国王统治，最后一位国王被逐，于是“公共之事”，即 *res publica*，开始了。他们把这一变化定在公元前509年。这是一个传统年代，既不是从当年某次会议中能读到的记录，也不是一个现代共和国的诞生。我们能够研究的是一套制度：任期短暂的高级官员；由担任过这些官职的人组成的元老院；以及公民大会。围绕这些官职的，是一个大得多、却不能分享它们的人口群体。女性公民没有投票权，奴隶不是公民，意大利的大多数自由人是同盟者或其他身份的属民，而不是罗马的投票者。

从这个传统的诞辰到与迦太基（Carthage）的第一场战争，是一段漫长的意大利扩张时期。从公元前509年到公元前264年，经过的年数是245年。一个诞辰无法解释一个已经花了这么长时间作战、建立定居点、以条约约束各共同体的体系。本章所说的共和国，是由这些官职构成、并已是意大利强权的共和国。与迦太基的战争从[[rome/slavery-and-conquest]]开始讲起，但它们并不是罗马征服的起点。

一座选举指挥官的城市，并不因此就是全体成年人的民主制。公元前451年公民权法之后的雅典，已经显示出一个狭窄的公民团体：父母双方都是公民的成年男子，[[greece/athenian-democracy]]对此有所阐述。罗马不是换了名字的雅典，也不是民族国家，正如[[greece/poleis]]中的城邦不是民族国家一样。我们不从公元前509年推导出现代共和国，而是追问：这些官职是什么，把谁排除在外，以及它们在意大利已经是一种什么样的权力。

## 一个属于传统的年代

这个传统的开端是建城传说的一部分。几个世纪之后写作的作家，把王政的终结描绘为自由的开端。仅作转述：国王变成了暴君，显要人物将他驱逐，两名官员取代了一位终身统治者。我们不引用这些作家的原文。对一个道德故事的转述，不是它声称所描述的那一年留下的文献。正如[[greece/poleis]]所说，首届奥林匹亚赛会被后来的传统定于公元前776年，梭伦（Solon）的执政官任期也被后来的传统定于公元前594年。传统年代可以讲授，但重复并不能使它变成同时代的记录。

那为什么还要锁定公元前509年？因为这一传统是关于罗马人记忆的一个事实。后来的罗马人这样编排自己的过去，让自由有了一个年份。这种编排是关于他们的证据，而不是那一年颁布了一部政制的证据。[[sources/time-and-names]]把日期当作一种论断而不是中性的标签来处理。“共和国始于公元前509年”这句话，把一个真实的对比——历史上的罗马不是旧式的王政——与一种早期证据所不支持的精确性捆绑在一起。

最初几代人的年度最高官员名单本身就是后来编成的，名单上的一个名字并不是选举的记录。等到记录丰富起来，一种熟悉的格局便出现了：两名高级官员，若干职责明确的低级官员，一个元老院，以及几种公民大会。我们按照可以证实的情形来描述共和国的这一格局，而不假装它在公元前509年就被拍下了照片。直到公元前264年的这段时期，是意大利强权形成的时期，也是后来所讲的“等级斗争”的时期，我们不用统计数字来装点它。

:::definition 共和国 {#def-republic}
本章所说的**共和国**，是罗马由有限任期的官职、元老院和公民大会构成的体制，与国王统治相对。拉丁语 *res publica* 意为“公共之事”。它不是指全体成年人的民主制，也不是指后来那种拥有广泛选举权和成文宪法的现代共和国。英语的“republic”一词是一个译名，并不意味着后来的共和国都是照搬这一个的。
:::

:::theorem 公元前509年是一个传统，而不是有文献证实的建立 {#thm-tradition}
公元前509年是共和国开端的传统年代，它记录的是后来的罗马人如何安放王政的终结。它不是政制变更的同时代文献，也没有建立任何现代共和国。
:::
:::proof
这个年份来自后来的罗马历史著作，而不是来自当时形成的记录。那些作家所关心的对比，在一种较弱的意义上是真实的：在我们能够证实的时期，罗马通过官员、元老院和公民大会进行治理，而罗马人把这种安排与王政区分开来。能够推翻这条论断的，是一份同时代的记录，表明这些官职是在公元前509年作为一部我们今天仍能读到的政制而设立的。我们没有这样的记录。同样能够推翻它的，是在本年表中把这一年用作某个现代共和国的法律渊源。本年表并没有这样用。这一年依然是记忆的标记。
:::

:::example 从传统开端到第一次迦太基战争经过的年数 {#ex-elapsed-509}
传统开端是公元前509年，第一次布匿战争始于公元前264年。求两个公元前年份之间经过的年数：用较早的年份数减去较晚的年份数，不要为了把首尾都算进去而加一年。经过的年数是多少？
:::solution
从公元前509年到公元前264年，经过的年数是509减264，即245年。把首尾所经历的年份逐一计入，是另一个问题。年表自己的例子，从公元800年到公元843年，是43年，这是一个差值，而不是首尾都算的计数。这245年说明了诞辰与战争为什么相隔遥远。填满这段时间的是制度，而不是诞辰。
:::
:::

:::example 一句虚构的编年史 {#ex-invented}
下面这句话是虚构的，不是译文。“公元前509年，元老院写下一部人人平等投票的政制，国王们之所以离去，是因为这份文本被当众宣读了。”

要把这句话提升为证据，需要什么？在它仍被标明为虚构的情况下，它可以用来做什么？
:::solution
要提升为证据，需要一条形成时间足够接近事件、可以确认其来源、并且确实这样说的史料。即便如此，我们仍要追问这条史料能够知道什么、想要什么。这句虚构的话通不过这些检验。它还偷运了本章所否定的两个主张：公元前509年是一个有文献证实的立法时刻；共和国是全体成年人的民主制。在标明为虚构的情况下，它只是一个坏习惯的标本：一个诞生故事会长出传统并未授权的附加内容——一部成文政制、平等的投票、一次公开宣读。它不是关于罗马人看法的证据。
:::
:::

## 官员、元老院与公民大会

制度才是主题。对于共和国中后期，我们可以从罗马人如何诉讼、投票、指挥以及争论合法性，大致了解这些制度；但无法把它们当作一部定于公元前509年的单一法令来了解。

**高级官员**是担任官职的人。地位最高的一对是执政官：两人经选举产生，共同掌权一年，每人都可以行事，每人也都是对另一人的制约。一个人的指挥权受到任期和同僚的限制。此外还有其他官职：裁判官通常负责司法和指挥，财务官负责钱财，市政官负责城市设施和市场，监察官负责公民名册和元老院成员名单。职责会有变化，我们不会把某一张图表固定下来，称之为原初的政制。权力被分割为临时性的官职，而担任过官职，就标志着一个人属于政治阶层。少数富有家族一再出任执政官，指挥权也可以在任期届满后延长。官职的理念是限权，实践却是少数人的仕途。

:::definition 高级官员 {#def-magistrate}
**高级官员**（magistrate）是罗马的任职者，选任期有限，通常为一年，往往有一位拥有同类权力的同僚。执政官是地位最高的一对。高级官员不是国王，一组高级官员也不是现代的权力分立。严格说来，这个词不包括平民保民官。保民官是平民组织的官职，其权力足以阻止一名高级官员。
:::

:::definition 元老院 {#def-senate}
**元老院**（senate）是一个议事机构，主要由担任过高级官职的人组成。在我们能够证实的时期，它在战争、和平、财政和指挥权方面的建议主导着共和国。它不是由全体成年人选出的议会。进入元老院标志着进入了官职生涯，监察官可以修订成员名单。我们不假装后来的元老院在公元前509年就已经以同样的惯例开会。
:::

公民大会是“民主”一词最常被偷运进来的地方。公民集会选举官员、通过法律、决定战争与和平。但他们并不是以一群人的方式集会，由每个人平等投票、逐人计票。他们分组投票，而各组并不平等。在选举执政官的大会中，分组依据财富，因此由较富裕公民组成的各组决定结果。一个贫穷的公民可以是投票者，却是一个分量很轻的投票者。公民大会在罗马召开，远离罗马的公民无法行使一项他够不着的权利。我们不会杜撰有多少人留在家中的数字。公民大会不止一种。一个由公民按不平等的组别投票的大会，不是全体成年人的统治，也不是意大利全体自由人的统治。

“等级斗争”是后来的罗马人讲述一场更早冲突的方式。在这种讲述中，公民分为两部分：贵族（patricians），一个世袭群体，声称拥有高级官职和某些祭司职位；以及平民，即其余的人。平民中有穷人，随着故事的推进，也有仍被排斥在贵族之外的富有家族。后来的作家描述了平民撤离城市、设立能够否决高级官员的保民官、把法律写成文字，以及最终向平民家族开放执政官职位。按照他们的说法，由此产生了一个凭官职形成的显贵阶层：担任过高级官职、并打算继续把持这些官职的家族，无论是贵族还是平民。

我们不会把这些妥协重述为有文献证实的社会史。对于早期冲突，我们既没有财富或投票的统计数字，本图谱也没有锁定任何年份，所以这两样我们都不杜撰。我们也不引用《十二表法》。后来的罗马人认为，一部早期的成文法典，对那些曾受制于自己无法读到的法律的人来说是一项收获。我们所取的仅此而已。一句冒充其中某条条文的现代句子，就会是一句杜撰的引文。

我们延续下去的是制度层面的内容。平民保民官可以阻止一名高级官员。公元前133年，提比略·格拉古（Tiberius Gracchus）在一场土地与帝国的危机中运用了这一官职，这属于[[rome/slavery-and-conquest]]的内容。我们所能看到的政治阶层，是一个凭官职形成的显贵阶层，既不是封闭的贵族集团，也不是全体成年人的民主制。妇女、奴隶和非公民并不是这些妥协的当事方。

:::theorem 官职共和国不是全体成年人的民主制 {#thm-not-democracy}
由公民大会选举官员，并不能使共和国成为全体成年人的民主制。投票者是男性公民，其分组方式使财富在执政官选举中分量极重，而且他们必须身在罗马。妇女、奴隶和意大利的非公民人口都在这些官职之外。
:::
:::proof
公民大会、任职资格，以及妇女、奴隶和意大利同盟者的法律地位，都是证据，这些可以从有文献证实的共和国时期的罗马公法中得知。雅典提供了一个对照：公元前451年以后，雅典民主制中的公民是父母双方都是公民的成年男子。罗马划出了自己的界线，同时还使公民的选票分量不等。能够推翻这条论断的，是成年妇女、奴隶或整个同盟者人口曾经投票并担任执政官的证据。这样的证据并不存在。同样能够推翻它的，是一部在本年表中有年代、确立成年人平等选举权的罗马法律。这里没有记载这样的法律。
:::

:::example 迦太基战争之前，一个家户中的三个人 {#ex-household}
这个案例是一张示意图，而不是一份传记。设想在公元前264年之前的那一代人中，意大利的一个家户。

- 马库斯（Marcus）是一名成年男性罗马公民，登记在较富裕的等级中，能够前往罗马。
- 他的姐妹卢西娅（Lucia）是生而自由的罗马公民。她不能支配这个家户的选票。
- 家中一名被奴役的女子，是在一场意大利战争中被俘的。

按照[[#thm-not-democracy]]，谁作为投票者和潜在的高级官员处在官职共和国之内？这种归类没有告诉你什么？
:::solution
马库斯处在潜在投票者的圈子之内，如果财产条件允许，也处在潜在候选人的圈子之内。他在执政官选举中的一票，是偏向财富的组别投票。卢西娅是公民，但既不是投票者，也不是官员。那名被奴役的女子不是公民。战争中被俘已经是沦为奴隶的途径之一，这是下一章的主题。

这种归类没有告诉我们他们中任何人的想法。公共记录中的沉默，显示的是谁被邀请发言，而不是某个人没有头脑。三个虚构的人物是一条规则的示意图，而不是样本，也不是对这类家户的统计。
:::
:::

## 与迦太基开战之前的意大利

在意大利的扩张发生在布匿战争之前。忽略这一事实，罗马的征服看起来就像一场突如其来的海外意外。从公元前509年到公元前264年是245年。到这段时间结束时，罗马已经是意大利半岛的头号强权。从公元前264年到公元前241年的第一次布匿战争，是这一强权接下来越海所做的事。

手段是战争、定居点和条约，这里的描述不杜撰战役年份。战败的共同体失去土地。罗马人和拉丁人建立定居点，即与罗马有法律联系的新共同体，有时由完全公民组成，有时具有拉丁人身份。这种定居点不是行省，也不是近代的海外殖民地。行省属于下一章。拉丁人身份处于中间：既不是完全的罗马公民权，也不是外邦人。同盟共同体，即 *socii*，保留各自的城市，并有义务提供兵员。有些共同体获得了没有投票权的罗马公民权。公民权是一束权利——通婚、贸易、上诉，以及对拥有投票权的成年男子而言的公民大会——罗马可以部分地授予它。

同盟者参加罗马的战争。一位执政官的军队，是罗马本城的兵力加上经罗马组织起来的意大利兵力。当罗马在公元前264年投入一场持续到公元前241年的战争时，这个同盟就是战争机器。我们在这里不叙述那场战争。这台机器并不是那场战争造就的。

在那场战争之前，亚历山大（Alexander）之后希腊世界的一位国王曾在意大利南部作战。本图谱没有为他的战役锁定年份，所以我们不杜撰一个。[[greece/alexander]]以公元前323年死于巴比伦（Babylon）以及若干希腊化王国作结，而不是以一个留存下来的帝国作结。罗马是作为那个世界中的一个意大利强权，进入那些有确切年代的战争的。后来所讲的等级斗争，与意大利的那些战争处在同一段没有年代的时期。国内的自由与对外的征服，并不在两只不同的钟上走。将俘虏卖为奴隶已经是罗马的做法。我们不会给这些俘虏编出数字，也不会假装奴隶制到公元前264年才出现。下一章的论断是：在迦太基战争之后，奴隶制成为结构性的。

:::proposition 在意大利的霸权先于布匿战争 {#thm-italy}
到公元前264年，罗马已经在主导一个通过战争、定居点和条约建立起来的意大利共同体同盟。第一次布匿战争并不是罗马征服的开端。
:::
:::proof
年表把传统开端放在公元前509年，把与迦太基的第一场战争放在公元前264年，而没有给出任何更早的、锁定的战役年份来说明意大利的那些战争。当那场战争开始时，这个同盟已清晰可见：拉丁定居点和公民定居点，有义务提供兵员的同盟者，以及不具备完全投票权的各级身份。没有这套体系，罗马就无法打下一章所描述的那场战争。能够推翻这条论断的，是这样的证据：公元前264年的罗马仍然只是众多拉丁城市中平等的一员，既没有同盟者的等级，也没有重新分配的土地。但随后开始的那场战争，并不是这样一座城市的战争。海外行省是新的，征服却不是。
:::

:::example 公元前323年在两个罗马年代之间的位置 {#ex-323}
亚历山大于公元前323年死于巴比伦。用公元前年份经过的年数计算：公元前509年与公元前323年之间、公元前323年与公元前264年之间，各相隔多少年？这两个数字显示了什么，又没有显示什么？
:::solution
从公元前509年到公元前323年，经过的年数是509减323，即186年。从公元前323年到公元前264年，是323减264，即59年。罗马的传统诞辰远在亚历山大之死以前，与迦太基的第一场战争则在其后。罗马即将在其中作战的地中海世界，已经经历了他的征服分裂为若干王国的过程。这两个数字并没有为那位后来的希腊国王在意大利南部的战役定年，也没有把公元前323年变成罗马的事件。它们阻止的是这样一种故事：罗马的一个诞辰既解释了制度，又解释了后来的帝国。
:::
:::

移动年份。空白的时段是拒绝杜撰战役年份，而不是说这段历史空无一物。如果第一个点诱使你去叙述一部政制的生效，[[#thm-tradition]]就是纠正。

:::warning 不是现代自由的诞辰
一个常见的故事把公元前509年当作共和自由的开端，并画出一条通向现代共和国的线，仿佛后来的选举权和后来的成文宪法早已存在于罗马的官职之中。这个年份是后来的传统，而不是文献。这些官职把大多数成年人排除在外，让拥有选票的人的票分量不等，而且属于一座已经在通过战争和同盟在意大利建立权力的城市。玛丽·比尔德（Mary Beard）的罗马通史，正是针对“罗马为后来的欧洲提供了单一教训”这种说法而写的。这种拒绝就从这里、从诞辰开始。
:::

传统并不是一种没有对象的虚构。在有文献证实的时期，罗马是通过官职来治理的，而罗马人把王政视为他们已经抛弃的东西。有些历史学家认为，确实发生过一次脱离君主制的真实变化，尽管其年份和英雄细节是后来塑造的。这种可能性并不损害[[#thm-tradition]]。这条论断并不是说王政一直延续到某个秘密的年份，而是说公元前509年不是一次有文献证实的建立，也不是现代共和国的源头。一份把这些官职固定在那一年的同时代文本，才能推翻这条论断，而我们没有这样的文本。与王政的对比可以成立，无须一个诞辰，无须等级斗争的统计数字，也无须引用《十二表法》。

:::history
后来的传统把共和国的开端定于公元前509年。第一次布匿战争始于公元前264年。本章所描述的官职，填满了从一个诞生故事到一场迦太基战争之间的这段时期，而它们并不是全体成年人的民主制。
:::

## 通向何处

意大利同盟是下一场战争所使用的机器。[[rome/slavery-and-conquest]]把它带入与迦太基的战争，然后带入行省与奴隶制，再带入公元前133年提比略·格拉古的保民官任期。那些战争所遭遇的世界，是[[greece/alexander]]留下的世界。让“民主”一词保持诚实的对照，是[[greece/athenian-democracy]]。传统年代与有文献证实的年代有何不同，由[[sources/time-and-names]]来处理。

:::summary
- 公元前509年是共和国的传统开端。它是后来的传统，不是同时代的文献，也不是现代共和国的源头。
- 我们能够描述的共和国，由有限任期的官职、由卸任官员组成的元老院，以及按不平等组别投票的公民大会构成。
- 等级斗争是后人对一场更早冲突的讲述。它不是有统计数字的社会史，也没有以全体成年人的民主制告终。
- 投票者是身在罗马的成年男子，在执政官选举大会中财富分量很重。妇女、奴隶和意大利的大多数自由人在官职之外。
- 到公元前264年，罗马已经主导着一个通过战争、定居点和条约建立起来的意大利同盟。征服并不是从第一次布匿战争开始的。
- 从公元前509年到公元前264年，经过的年数是245年。公元前323年亚历山大之死就在这段时期之内。
- 归功于等级斗争的保民官制度，在下一章的公元前133年再次出现，成为在一场土地与帝国危机中被运用的官职。
:::

:::exercise 等级斗争为什么不是一组统计数字 {level=2}
后来的罗马人描述了贵族与平民之间的一场冲突，这场冲突产生了保民官，最终也使平民得以担任高级官职。一本教科书想要人群规模、财富份额，并为每一项成果配上一部有年代的法令。本章为什么拒绝这些补充？我们保留了什么制度上的结果？
:::solution
等级斗争是后人的讲述，而不是一份同时代的统计档案。本图谱没有为平民撤离锁定年份，所以一份有年代的清单会是杜撰的；也没有锁定任何财富份额，所以百分比同样会是杜撰的。引用《十二表法》则会杜撰一段文本。保留下来的是保民官制度——一个能够阻止高级官员的官职——以及一个以担任官职而不单以贵族出身来界定的政治阶层。这些制度并没有把妇女、奴隶或意大利同盟者带进公民大会。拒绝统计数字，并不等于主张平民的地位毫无变化。
:::
:::

:::exercise 再读那句虚构的话 {level=2}
一位读者评论[[#ex-invented]]中的那句话说：“即使它是现代人写的，它也抓住了公元前509年的精神，所以可以替代缺失的史料。”“精神”做不到什么？
:::solution
“精神”是一种诠释。它不能替代缺失的史料，也无法用史料来检验。那句虚构的话添加了一部成文政制和成年人的平等投票权。把这些称为“精神”，就是在为这些添加洗白。这句话只能作为一个标明了的标本存在。能把一句话提升为证据的，是一条真实的、足够接近事件以回答问题的史料——而本章已经拒绝了杜撰的引文，包括来自《十二表法》的引文。
:::
:::

:::exercise 意大利同盟为什么改变了战争史的第一页 {level=2}
一种叙述把罗马征服的起点定在公元前264年，并把此前的一切都当作国内政治。请运用[[#thm-italy]]说明，这种叙述遗漏了什么。
:::solution
到公元前264年，罗马已经主导着一个通过战争、定居点和条约建立起来的同盟：公民定居点和拉丁定居点，有义务提供兵员的同盟城市，以及不具备完全投票权的各种身份。把征服的起点定在公元前264年，会让海外战争看起来像是帝国的开端。而意大利体系本身已经是征服，也已经是统治：土地已被夺取并重新分配；同盟者身在军中，却在选举权之外。下一章因此可以把布匿战争当作规模的变化，而不是罗马战争的发明。
:::
:::

:::exercise 不要从传统年份推导出现代共和国 {level=3}
一名学生写道：“因为罗马在公元前509年驱逐了国王，并把结果称为共和国（republic），所以现代共和国是那个决定的延续，批评罗马的选举权就是攻击共和国这一理念本身。”请把传统年代、罗马的官职和现代制度区分开来，并说明什么能够推翻[[#thm-tradition]]，什么不能。
:::hint
这名学生把本章所否认的三个环节串在了一起：公元前509年是一个有文献证实的决定；罗马的这个词就是现代的制度；对罗马选举权的限制，限制了这个词后来的一切用法。与王政的真实对比可以保留。
:::
:::solution
公元前509年是后来的传统，而不是我们所拥有的文本。一个现代共和国，并不因为英语用同一个词称呼两者就成了罗马的。罗马的官职是有限任期的官职、元老院和不平等的男性公民大会。批评这种限制，是在描述共和国，而不是在攻击后来每一次对王政的拒绝。

能够推翻[[#thm-tradition]]的，是一份那一年建立共和国的同时代记录，或者本年表中某个现代共和国以那个日期为其宪法来源的证据。这两样都不存在。不能推翻它的，是那个真实而较弱的说法：有文献证实的罗马不是旧式的王政。
:::
:::

:::exercise 沉默与身份 {level=3}
回到[[#ex-household]]。一位评论者写道：“卢西娅和那名被奴役的女子没有出现在公民大会中，所以她们没有政治判断力。只凭马库斯就可以描述共和国。”请利用法律身份与头脑之间的区别来回答，并指出这张示意图无法证明的一件事。
:::hint
谁被允许投票是一条规则，而不是一次访谈。这个家户是为了给身份分类而虚构的。一个虚构的家户不是意大利的样本。
:::
:::solution
不出席公民大会，是一条关于性别的规则，对那名被奴役的女子来说，还是一条关于自由身份的规则。它显示的是谁被准许担任官职，而不是谁头脑空空。没有人请她们投票，所以没有选票可读。马库斯可以说明投票者是什么样子，却无法说明整个家户，也无法说明一个公民家庭所依赖的劳动。

这张示意图无法证明一个数字：这样的女子有多少，或者公元前264年之前意大利的劳动中有多大比例是奴隶劳动。这些数量都没有被锁定。一条规则的示意图，不是记录卢西娅想要什么的日记。
:::
:::
