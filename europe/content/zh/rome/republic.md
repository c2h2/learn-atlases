如果把诞生故事放到一边，共和国究竟是什么？

后来的罗马人讲了一个干净的故事。王曾经统治这座城。最后一位王被赶了出去，于是 res publica（公共事务）开始了。他们把这次变更定在公元前509年。这个年份是一个传统年代。它不是一次举行过的会议留下的当场记录，也不是一个现代共和国的诞生。我们能够研究的是一组制度：任期短暂的长官、由担任过这些官职的人组成的元老院，以及公民的集会。围绕这些官职的，还有远为众多并不分享它们的人口。女性公民没有投票权。奴隶不是公民。意大利的大多数自由人属于别的身份——同盟者或臣属——不是在罗马的投票人。

从这个传统诞辰到第一场与迦太基（Carthage）的战争，是一段漫长的意大利扩张。从公元前509年到公元前264年的已过跨度是245年。一个诞辰解释不了一个已经花去这么久时间开战、建立移居点、以条约把共同体绑定在一起的体系。这里所使用的意义上的共和国，是那些官职与那股意大利权力的共和国。与迦太基的战争在 [[rome/slavery-and-conquest]] 里开始。它们不是罗马征服的起点。

一座选举军事长官的城，并不因此就是全体成年人的民主制。雅典在公元前451年的公民法之后，已经显示出一个小得多的公民团体：双亲皆为公民的成年男子，[[greece/athenian-democracy]] 对此有专门论述。罗马不是换了一个名字的雅典，也不是民族国家，正如 [[greece/poleis]] 里的城邦之于民族国家。我们不是从公元前509年推导出现代共和国。我们问的是：这些官职是什么，它们把谁关在外面，而在意大利它们已经是一种什么样的权力。

## 一个作为传统的年代

这个传统起点是一个奠基传说的一部分。后世的写作者在他们之后许多世纪着手写作，把王权的终结呈现为自由的开端。仅止于转述：王变成了僭主，显要人物把他驱逐，两名长官取代了一名终身统治者。我们不引用那些写作者。对一个道德故事的转述，不是它所声称描述的那一年留下来的文书。首届奥林匹克竞技会被后世传统定在公元前776年，梭伦（Solon）任执政官被后世传统定在公元前594年，正如 [[greece/poleis]] 所述。传统年代可以教。重复不会使它变成当世的记录。

为什么要锁定公元前509年？因为这个传统是关于罗马人记忆的一个事实。后来的罗马人这样组织他们的过去，使自由有了一年。这种组织是关于他们的证据，不是那一年颁布了一部政制的证据。[[sources/time-and-names]] 正是把一个年代当作一条论断而不是一个中性标签来处理的地方。「共和国始于公元前509年」这句话捆绑了一个真实的对比——历史上的罗马不是旧式王政的王室统治——与一种早期证据并不支持的精确性。

最早几代人的年度最高长官名单本身就是后来的。名单上的一个名字不是那次选举的会议记录。等到记录更厚了，一个熟悉的形态出现了：两名资深长官、职责较为有限的下级长官、一个元老院，以及若干集会。我们按能够证实的样子描述共和国的这个形态。我们并不假装它在公元前509年被拍了下来。下到公元前264年的这一段是意大利的权力，它也是等级斗争那个较晚的故事，我们不会用统计数字去装点它。

:::definition 共和国 {#def-republic}
本章所说的**共和国**，是罗马的限任长官、元老院与公民集会的体系，相对于王之治。拉丁语 *res publica* 意为公共事务。它不意味着全体成年人的民主制，也不意味着带有后来的那种广泛选举权和成文政制的现代共和国。英语的 republic 一词是一个翻译，不是一个后来的共和国都抄自这一个的主张。
:::

:::theorem 公元前509年是一个传统，不是一部有佐证的奠基 {#thm-tradition}
公元前509年是共和国开端的传统年代。它记录的是后来的罗马人如何安置王权的终结。它不是一份当世的政制变更文书，也不为任何现代共和国提供奠基。
:::
:::proof
这个年份出自后来的罗马历史写作，不是出自当时制作的记录。那些写作者看重的对比在一个较弱的意义上是真实的：在我们能够证实的时期，罗马通过长官、元老院和集会来治理，罗马人把这种安排与王权区分开来。能够构成对这条论断的反证的，是一份当世记录，表明这些官职是在公元前509年作为一部我们今天仍然读得到的政制设立起来的。我们没有这样的记录。同样能够构成反证的，是在本时间线内部把这一年用作一个现代共和国的法源。它没有被这样使用。这一年仍然是记忆的标记。
:::

:::example 从传统到第一场布匿战争的已过跨度 {#ex-elapsed-509}
传统起点是公元前509年。第一次布匿战争始于公元前264年。求两个公元前年份之间的已过跨度：用较早的数字减去较晚的数字。不要为了把跨度做成闭区间而加一年。已过跨度是多少年？
:::solution
从公元前509年到公元前264年，已过跨度是509减264，等于245年。逐年点数的官名年则是一个不同的问题。年表自己的例子，从公元800年到公元843年，是43年，是一个差值，不是一个闭区间的点数。这245年正是诞辰与战争相去遥远的原因。填满这一段的是制度，不是诞辰。
:::
:::

:::example 一句编造的编年史句子 {#ex-invented}
下面这句话是编造的。它不是翻译。「公元前509年，元老院为每一个成年人写下一部平等投票的政制，诸王离去，因为这份文书被当众宣读。」

要把这句话提升为证据需要什么？在它保持标明为编造的时候，它能用来做什么？
:::solution
提升需要一条与事件相距足够近而制作的史料，能够确认就是那条史料，并且确实说了这句话。我们仍然要问这条史料能够知道什么、想要什么。这句编造的句子通不过这些检验。它还偷偷夹带了本章拒绝的两个主张：公元前509年是一个有佐证的立法时刻，共和国是全体成年人的民主制。让它保持标明为编造，它只是一个坏习惯的标本。诞辰故事会长出传统不允许的额外子句——一部成文政制、平等的投票、一次公开宣读。它不是关于罗马人意见的证据。
:::
:::

- [x] 共和国开端的传统年代，由后世传下

## 长官、元老院与集会

制度是正题。就共和国的中后期而言，从罗马人诉讼、投票、指挥和争论合法律性的方式来看，它们大体可知。它们不是一部定年为公元前509年的单独法律。

**长官**是担任官职的人。资深的一对是执政官：两人，由选举产生，共同掌权一年，每人都能行事，每人都是对另一人的牵制。一人的指挥权受时间和同僚的限制。他们之外还有其他官职。裁判官常常处理法律与指挥，财务官处理钱财，市政官管理城市的营造与市场，监察官掌管公民名册和元老院的名单。职责会变动。我们不会冻结一张表把它叫作原始政制。权力被切割成临时性的官职，担任过官职便使一个人被认作政治阶层的一员。少数富裕家族一再供给执政官。一项指挥权可以在一年任期之后延长。官职的理念是限权。实践是少数人的仕途。

:::definition 长官 {#def-magistrate}
**长官**（magistrate）是经限定任期——通常为一年——选出的罗马任职者，常常另有一名持有同种权力的同僚。执政官是资深的一对。长官不是王，一组长官也不是现代的三权分立。这个词在严格的意义上不涵盖平民保民官。保民官是平民组织的官职，其权力足以阻挠一名长官。
:::

:::definition 元老院 {#def-senate}
**元老院**（senate）是一个议事会，其成员主要是担任过长官的人。在我们能够证实的时期，它关于战争、和平、财政与指挥权的咨议指导着共和国。它不是全体成年人选出的议会。名列其中标志着进入官职生涯，监察官可以修订这份名单。我们并不假装后来的元老院在公元前509年已经带着同样的习惯开会。
:::

集会是最常把 democracy 这个词混进来的地方。公民集会，是为了选举长官、通过法律、决定战争与和平。他们不是以人人投出等量一票并逐人计点的人群来集会的。他们分组投票，各组并不平等。在选举执政官的集会里，分组依财富而定，较富公民的组使决定成立。一个穷公民可以是一个投票人，仍然是一个分量轻的投票人。集会必须在罗马开会。一个远离罗马的公民无法使用一个他够不着的权利。我们不会编造一个数字说多少人留在了家里。集会不止一种。公民按不平等的各组投票的集会，不是全体成年人的统治，也不是意大利全体自由人的统治。

等级斗争是后来的罗马人讲述一场更早冲突的方式。在那个讲述里，公民分裂为 patricians——一个宣称拥有资深官职和若干祭司职位的世袭团体——和平民，即其余的人。平民包括穷人，而随着故事推进，也包括仍然被排斥在贵族团体之外的富裕家族。后世写作者描述了撤出罗马城的行动、设立能够否决一名长官的保民官、把法律写下来，以及最后向平民家族开放执政官。据此种讲述，由此产生了一个凭官职形成的显贵：担任过资深长官并打算继续把它们留在手里的家族，无论贵族还是平民。

我们不会把那些妥协重述为一部有佐证的社会史。早期冲突没有留给我们财富或投票的统计，本图谱也不为它锁定任何年份，所以我们两样都不编造。我们不引用《十二表法》。后来的罗马人把一部早期成文法典当作曾受制于读不懂之法律的人的一项收获。我们就取这么多。一句现代的话装作其中一条条文，就会是一句编造的引文。

我们带走的是制度方面的东西。平民保民官可以阻止一名长官。公元前133年，提比略·格拉古（Tiberius Gracchus）在土地与帝国的危机中使用那个官职，那属于 [[rome/slavery-and-conquest]]。我们看得见的政治阶层是一个凭官职形成的显贵，不是封闭的贵族团体，也不是全体成年人的民主制。妇女、奴隶和非公民不是这些妥协的当事方。

:::theorem 一个官职的共和国不是全体成年人的民主制 {#thm-not-democracy}
由公民集会选举长官，并不使共和国成为全体成年人的民主制。投票人是男性公民，其分组使财富在执政官选举中占有重权重，而且他们必须身在罗马。妇女、奴隶和意大利的非公民人口都在这些官职之外。
:::
:::proof
集会、任官资格，以及妇女、奴隶和意大利同盟者的法律身份，就是证据，可从有佐证的共和国时期的罗马公法得知。雅典提供一个对照：公元前451年之后，民主制中的雅典公民是双亲皆为公民的成年男子。罗马画出自己的线，并且同样使公民的投票分量不平等。能够构成对这条论断的反证的，是成年妇女、奴隶或同盟人口作为一个整体投过票并担任过执政官的证据。没有这样的证据。同样能够构成反证的，是一部在本时间线内定年、确立全体成年人平等选举权的罗马法律。这里没有这样一部法律见诸记载。
:::

:::example 布匿战争之前，三个人，一个家户 {#ex-household}
这个案例是一个示意图，不是传记。设想公元前264年之前那一代意大利的一个家户。

- 马库斯（Marcus）是一名成年男性罗马公民，登记在较富的等级里，能够到罗马去。
- 他的姐姐露琪亚（Lucia）是出生自由的罗马公民。她不能支配这个家户的投票。
- 家中一名女奴隶是在一场意大利战争中被掳的。

按 [[#thm-not-democracy]]，谁作为一个投票人和一个可能的长官在官职的共和国之内？这次分拣没有告诉你什么？
:::solution
马库斯在潜在投票人的圈子里，并且按财产条件也在潜在候选人的圈子里。他的执政官票是一个偏向财富的组票。露琪亚是公民，但不是投票人，也不是长官。那名女奴隶不是公民。在战争中被掳已经是进入奴隶身份的一条通道，那是下一章的主题。

这次分拣没有告诉我们他们各自怎么想。公共记录里的沉默显示的是谁被要求发言，不是一个人没有头脑。三个编造的人是一条规则的示意图，不是一个样本，也不是这类家户的清点。
:::
:::

## 与迦太基开战之前的意大利

在意大利的扩张在布匿战争之前。跳过这个事实，罗马的征服就会显得像一场突如其来的海外意外。从公元前509年到公元前264年是245年。在这个跨度之末，罗马已经是意大利半岛的首要强权。第一次布匿战争，公元前264年到公元前241年，是这股权力接下来在海对面所做的事。

手段是战争、移居点与条约，这里描述它们而不编造战斗年份。战败的共同体失去土地。罗马人和拉丁人建立移居点：与罗马有法律纽带的新共同体，有时是全权公民，有时是拉丁籍。这种移居点不是行省，也不是近代的海外殖民地。行省属于下一章。拉丁籍是中间的：不是全权罗马公民权，也不是外邦。被称为 *socii*（同盟者）的诸共同体保留自己的城市，并承担出兵义务。有些共同体得到了不带投票权的罗马公民权。公民权是一束东西——婚姻、贸易、申诉，以及对有投票权的成年男子而言的集会——罗马可以部分授予。

同盟者在罗马的战争中作战。一名执政官的军队是本城的武力加上罗马按其方式组织起来的意大利的武力。当罗马在公元前264年投入一场持续到公元前241年的战争时，这台机器就是这个同盟。我们不在此讲述那场战争。这台机器不是由它建成的。

亚历山大（Alexander）之后希腊世界的一位王曾在那场战争之前在意大利南部作战。本图谱不为他的战役锁定年份，所以我们不编一个。[[greece/alexander]] 终于公元前323年死在巴比伦（Babylon），终于希腊化诸王国，而不是终于一个幸存的帝国。罗马作为一个意大利强权进入那个世界的有年代的战争。较晚讲述的等级斗争，与意大利诸战争坐在同一段没有年代的区间里。内部自由与征服不在两只钟上。把战俘掳为奴隶已经是罗马的惯例。我们不会给那些俘虏编数字，也不会假装奴隶制到公元前264年才到来。下一章的论断是：布匿战争之后，它是结构性的。

:::proposition 意大利领导权在布匿战争之前 {#thm-italy}
到公元前264年，罗马已经指挥着一个由战争、移居点与条约建成的意大利诸共同体同盟。第一次布匿战争不是罗马征服的开端。
:::
:::proof
年表把传统起点放在公元前509年，把第一场与迦太基的战争放在公元前264年，并且没有给出更早的、能够替意大利诸战争完成工作的锁定战斗年份。在那场战争开始的时候，同盟是可见的：拉丁与公民移居点、欠负军队的同盟者、不到全权投票权的身份层级。没有这套体系，罗马打不成下一章所描述的那场战争。能够构成对这条论断的反证的，是公元前264年罗马仍然是拉丁城市中的平等一员、没有同盟者的层级、也没有重新分配的土地的证据。随后开始的那场战争不是那样一座城市的战争。海外的行省是新的。征服不是。
:::

:::example 公元前323年落在两个罗马年代之间的哪里 {#ex-323}
公元前323年，亚历山大死在巴比伦。用公元前年份的已过跨度计算：公元前509年到公元前323年相隔多少年，公元前323年到公元前264年相隔多少年？这一对数字显示了什么，又没有显示什么？
:::solution
从公元前509年到公元前323年，已过跨度是509减323，等于186年。从公元前323年到公元前264年是323减264，等于59年。传统的罗马诞辰远在亚历山大之死以前。第一场与迦太基的战争在其后。罗马即将在其中作战的地中海世界，已经经历了他的征服分裂为诸王国。这两个跨度不给那位较晚的希腊王在意大利南部的战役定年，也不把公元前323年变成一次罗马事件。它们拦住的，是这样一种故事：罗马的一个诞辰同时解释了制度和后来的帝国。
:::
:::

:::warning 不是现代自由的诞辰
一个常见的故事把公元前509年当作共和自由的起点，并画一条线通向现代诸共和国，仿佛后来的选举权和后来的成文政制已经包含在罗马的官职里。这个年代是后世传统，不是文书。这些官职把多数成年人排斥在外，使握有投票者的票分量不等，而且它们属于一座已经在用战争和同盟在意大利建设权力的城市。玛丽·比尔德（Mary Beard）对罗马的通史是逆着罗马对后来的欧洲只有一课的说法写的。这种拒绝从诞辰开始，就在这里。
:::

传统不是没有对象的虚构。在有佐证的时期，罗马通过官职治理，而罗马人把王权当作他们已经否弃的东西。有些史家认为，一场脱离君主制的真实变更确曾发生，即便这个年份和英雄细节是后世的形塑。这个可能性不损害 [[#thm-tradition]]。论断不是说王权持续到某个秘密的年份。论断是说公元前509年不是一部有佐证的奠基，不是现代诸共和国的来源。一部当世文本如果把官职固定在那一年，就会构成对论断的反证。我们没有这样的文本。与王权的对比不需要诞辰就可以成立，不需要等级斗争的统计，也不需要一条来自《十二表法》的引文。

:::history
后世传统把共和国的开端放在公元前509年。第一次布匿战争始于公元前264年。本章所描述的官职，填满了诞辰故事与迦太基之战之间的这一段，而它们不是全体成年人的民主制。
:::

## 通向何处

意大利同盟是下一场战争使用的机器。[[rome/slavery-and-conquest]] 把它带入与迦太基的战争，然后是行省与奴隶制，然后是公元前133年提比略·格拉古的保民官任期。那些战争遭遇的世界，是 [[greece/alexander]] 留下的那个世界。使 democracy 一词保持诚实的对照是 [[greece/athenian-democracy]]。一个传统年代如何不同于一个有佐证的年代，是 [[sources/time-and-names]] 的工作。

:::summary
- 公元前509年是共和国的传统开端。它是后世传统，不是当世文书，也不是现代诸共和国的起源。
- 我们能够描述的共和国，是限任长官、由卸任长官组成的元老院，以及按不平等的各组投票的公民集会。
- 等级斗争是一场更早冲突的后世讲述。它不是带统计数字的社会史，也不以全体成年人的民主制收尾。
- 投票人是成年男子，必须在罗马，财富在执政官集会中占有分量。妇女、奴隶和意大利的大多数自由人在官职之外。
- 到公元前264年，罗马指挥着一个由战争、移居点与条约建成的意大利同盟。征服不是从第一次布匿战争开始的。
- 从公元前509年到公元前264年的已过跨度是245年。公元前323年亚历山大之死落在这段区间之内。
- 等级斗争传说中设立的保民官，在下一章的公元前133年重新出现，作为一个在土地与帝国的危机中被使用的官职。
:::

已过跨度是509减264，等于245年。加一会数成触及的官名年，那是另一个问题。年表的公元800年到公元843年的43年，是同一种差值。

:::exercise 为什么等级斗争不是一组统计数字 {level=2}
后来的罗马人描述过贵族与平民之间的一场冲突，它产生了保民官，并最终产生了通向资深官职的权利。一本教科书想要群众人数、财富份额，以及为每一项收获配一部有年代的法律。本章为什么拒绝这些添加？我们留下了什么制度结果？
:::solution
等级斗争是后世的讲述，不是当世清点的一个卷宗。本图谱不为那些撤离行动锁定年份，所以一份有年代的名单会是编造的；也不锁定任何财富份额，所以百分比也会是编造的。引用《十二表法》会编造一部文本。留下来的东西是保民官制度——一个能够阻挠一名长官的官职——以及一个以担任官职而非单凭贵族出身来定义的统治阶层。这些制度没有把妇女、奴隶或意大利同盟者带进集会。拒绝统计数字不是主张平民的身份什么都没有变。
:::
:::

:::exercise 再读一遍那句编造的句子 {level=2}
有读者这样评价 [[#ex-invented]] 里的句子：「即便它是现代的，它抓住了公元前509年的精神，所以它可以代替缺失的史料。」精神不能做什么？
:::solution
精神是一种解释。它不能代替一条缺失的史料，也不能对照一条史料来检验。那句编造的句子添加了一部成文政制和平等的成年投票权。把这称为「精神」，就是把添加洗白。这句话只能作为标明过的标本存在。能把一句话提升为证据的是一条真实的史料，近得足以回答——而本章已经拒绝过编造的引文，包括来自《十二表法》的。
:::
:::

:::exercise 为什么意大利同盟改变了战争的第一页 {level=2}
一个叙事把罗马征服定在公元前264年，并把此前的一切当作内部政治。用 [[#thm-italy]] 说明那个叙事丢掉了什么。
:::solution
到公元前264年，罗马指挥着一个由战争、移居点与条约建成的同盟：公民与拉丁移居点、欠负军队的盟邦、不到全权投票权的身份。把征服定在公元前264年，海外的战争就显得是帝国的开端。意大利体系已经是征服，也已经是治理。土地已被夺取并被重新安置。同盟者在军队之内，在选举权之外。下一章可以把布匿战争当作一次规模的变化，而不是罗马战争的发明确立来处理。
:::
:::

:::exercise 不要从传统年份推导一个现代共和国 {level=3}
一名学生写道：「因为罗马在公元前509年驱逐了诸王，并把结果称为 republic，现代的共和国就是那个决定的延续，而批评罗马的选举权就是在攻击 republic 这个观念本身。」把传统年代、罗马官职与现代制度分开。说出什么会构成对 [[#thm-tradition]] 的反证，什么不会。
:::hint
这个学生捆住了本章否认的三个环节：公元前509年是一个有佐证的决定；罗马的词语就是现代的制度；对罗马选举权的限制限制了这个词后来的一切使用。与王权的真实对比可以保留。
:::
:::solution
公元前509年是后世传统，不是我们手里的一部文本。一个现代共和国不会因为英语用一个词称呼两者就变成罗马的。罗马的官职是限任长官、元老院，以及男性公民的不平等集会。批评那个限度是在描述共和国。它不是在攻击后来对王权的每一次否弃。

会构成对 [[#thm-tradition]] 反证的，是一份那一年的奠基的当世记录，或本时间线内某个现代共和国从那个日期取得其政制的证据。两样都没有人拿得出来。不会构成反证的，是那个真实的、较弱的说法：有佐证的罗马不是旧式王政的王室统治。
:::
:::

:::exercise 一种沉默与一种身份 {level=3}
回到 [[#ex-household]]。一位评论者写道：「露琪亚和那名女奴隶没有出现在集会里，所以她们没有政治判断。共和国可以只从马库斯一个人来描述。」用法律身份与头脑的差别来回答，并说出这个示意图不能证明的一件事。
:::hint
谁被允许投票是一条规则，不是一次访谈。这个家户是为了分拣身份而编造的。一个编造的家户不是意大利的样本。
:::
:::solution
缺席于集会，是关于性别的一条规则，而对那名女奴隶，还是关于自由身份的一条规则。它显示谁被准入官职。它不显示一颗空空的头脑。没有人向她们要过票，所以那里没有票可读。马库斯可以说明一个投票人。他不能说明一个家户，也不能说明一个公民的家所能依靠的劳动。

这个示意图不能证明一个数字：这样的妇女有多少，或者公元前264年之前意大利劳动中有多大份额是奴隶劳动。那些量没有被锁定。一条规则的示意图不是露琪亚想要什么的日记。
:::
:::
