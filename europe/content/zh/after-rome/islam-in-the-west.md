伊斯兰政治史为什么属于一门欧洲课程？

它属于，是因为地图，不是因为道德记分。伊比利亚在欧洲之内。从公元711年一支由塔里克·伊本·齐亚德（Tariq ibn Ziyad）率领的部队渡海进入半岛起，它的大部分政治史就是穆斯林统治者、穆斯林法律以及生活在他们治下之人的历史。一门课程若在拉丁基督教的诸王重返每一座城市之前都保持沉默，那就是对地理动了手脚。[[sources/naming-europe]]把安达卢斯（al-Andalus）放进地图之内、拒绝把它写成一次中断，它命名的正是这一类的选择。

这个政治体不是从海峡起步的。希吉拉（Hijra）在公元622年，是伊斯兰历纪年的起点。穆罕默德（Muhammad）卒于公元632年。雅尔穆克（Yarmouk）一役，按通常的定年，在公元636年，那是一次东罗马军队的失败，有助于说明一个新国家如何能守住叙利亚。这些都不是伊比利亚的事件。它们是公元711年之所以可以理解的原因。图尔（Tours）战役，或称普瓦捷（Poitiers）战役，是一场有三个候选年份的战役：按传统定年是公元732年10月，而遵循《754年编年史》（Chronicle of 754）的学者主张公元733年或734年。这场战役没有拯救欧洲。查理·马特（Charles Martel）不是国王。袭扰仍在继续。科尔多瓦倭马亚埃米尔国建立于公元756年，在战役的每一个候选日期之后，而一个哈里发称号在公元929年随之而来。把这场战役当作终点的传说，经不起它自己年表的检验。

## 一个新的政治体，在伊比利亚之前

:::definition 希吉拉 {#def-hijra}
**希吉拉**是公元622年的那次迁徙，伊斯兰历的纪年后来正是从它起算。它是一个发生在阿拉伯的日期。它不是伊比利亚的事件，而那个历法里的一年，与本图谱为自身日期所用的儒略历年并不等长。本章不在这两种纪年之间随意换算。它使用年表已经锁定的那些公元纪年的年份。
:::

:::definition 安达卢斯 {#def-andalus}
**安达卢斯**是伊比利亚的穆斯林政治体，从公元711年的渡海，经过公元756年的科尔多瓦埃米尔国和公元929年宣告的哈里发国，在这些称号之后仍继续存在，只要半岛上的穆斯林统治还在，它就还在。它是一部统治者、赋税、军队和城市的政治史。它不是宽容的象征，也不是威胁的象征。
:::

从公元622年到公元632年，年份的数字相差10。这十年是迁徙之后、在穆罕默德领导下的共同体存续的岁月，而本章不是一部传记。已锁定的事实，是那次开启历法的迁徙和那次死亡。死亡之后，新共同体内部的权威是一个政治问题。本图谱没有锁定早期诸哈里发的年份列表，因此这里不会补上任何一个。下一个被锁定的战役是雅尔穆克，在公元636年，按通常的定年：是死亡之后的第四个年份数字，因为636减632是4。这里的“通常”，其含义与[[after-rome/successor-kingdoms]]中伦巴第人的条目相同。这个年份是应当教授的通行定年，但它仍然是一个定年，不是我们抄录下来的一纸特许状。

雅尔穆克是一次东罗马的失败。叙利亚在此后的余波中脱离罗马的控制。罗马国家本身，即[[after-rome/byzantium]]的主题，并没有在公元636年终结。一场战役可以消灭一支野战军和一个地区，却不消灭一个帝国。这场战役对本章的作用是解释性的。还在任何人渡海进入伊比利亚之前的几十年，一个新的政治体就已经庞大，就已经战胜君士坦丁堡的皇帝。从公元636年到公元711年，年份的数字相差75。从希吉拉到渡海相差89，因为711减622是89。伊比利亚是一段早已开始的历史之更晚的西部边疆。像它从图尔才开始那样讲述伊斯兰政治，是一门欧洲课程丢掉解释、只留下惊恐的方式。

:::theorem 711年之后的伊比利亚属于本课程 {#thm-inside}
从公元711年起，伊比利亚的政治史就不只是一部拉丁的历史。一门欧洲课程若略去穆斯林诸政治体，那是选择了一幅地图，而不是跟随史料；而公元622年、632年和636年的那些事件解释了这个政治体，却还不是伊比利亚的事件。
:::
:::proof
证据是地理的，也是有日期的。塔里克·伊本·齐亚德的部队于公元711年渡海进入伊比利亚。半岛在本图谱称作欧洲的地理之内。其后的事情——公元756年的埃米尔国和公元929年的哈里发国——是那半岛上的统治，不是停泊在近海的一段外来插曲。希吉拉、穆罕默德之死和雅尔穆克，按通常的定年，更早，也在别处。它们解释一个新国家。它们不发生在伊比利亚；正因如此，一章若从科尔多瓦讲起，会与一章若从图尔讲起同样误导人。能够反驳[[#thm-inside]]的，是对以下一点的论证：公元711年并未把穆斯林统治置于伊比利亚之内；或者本图谱中的“欧洲”早已被定义为排除半岛的穆斯林诸世纪。[[sources/naming-europe]]拒绝了那个定义。不算数的，是读者对统治者的厌恶，或后来一次拉丁人的征服。格拉纳达在公元1492年的投降——[[crises/year-1492]]将讲到的事件——是另一件事件。它不会伸手回到过去，把公元711年变成一条脚注。
:::

## 711年，然后是科尔多瓦

公元711年的渡海可以用一句话讲完，而这已经是年表所锁定的一切，也是本章将使用的一切。一支由塔里克·伊本·齐亚德率领的部队渡海进入伊比利亚。这里没有船只数目，没有岩石上的演说，也没有战役叙事。添加它们就是编造。课程记录里的那句话就是这条论断：这一年之后，半岛的政治史不只是一部拉丁的历史。

公元750年，阿拔斯革命推翻了东方的倭马亚哈里发国。公元756年，倭马亚家族成员阿卜杜勒·拉赫曼一世（Abd al-Rahman I）在科尔多瓦建立一个埃米尔国。这两个年份的数字相差6。本章不会用一段无法定年的旅行记去填满这六年。政治结果已经足够。安达卢斯成为一个自成一体的倭马亚政治体，而不是新任阿拔斯哈里发治下一个效忠的行省。埃米尔是军事统帅，也是亲王。他还没有索取哈里发这个最高称号。课程参考文献中列出的布赖恩·卡特洛斯（Brian Catlos）的史著，恰恰在这里有用：主题是政治，不是宽容的象征，也不是威胁的象征。

公元929年，阿卜杜勒·拉赫曼三世（Abd al-Rahman III）取哈里发称号。从公元756年到公元929年，年份的数字相差173。称号的改变是一个关于合法性的主张——科尔多瓦的统治者不是任何人的副手——而这个主张提出时，东方的阿拔斯哈里发依然存在。这是政治语言上的一个事实。它不是那一年有多少人改变了礼拜方式的清点，它也与公元800年在罗马取得的罗马皇帝称号不是同一个制度。形式上的平行仅止于此：一个最高的新主张被安置在一个更古老的主张旁边。职务不同，宗教不同，而[[after-rome/carolingians]]绝不能被并入科尔多瓦，反过来也一样。

本图谱没有为科尔多瓦哈里发国的终结锁定年份。公元929年取得的称号不是半岛永恒的定格画面。公元1492年的格拉纳达晚好几个世纪，它不是公元711年的含义。在这两个极端之间，诚实的那句话是政治性的。统治者、赋税、军队和科尔多瓦城就是主题。穆斯林、基督徒和犹太人生活在随统治时期而变化的规则之下。犹太人和基督徒的受保护地位仍然是一种法律上较低的地位：保护不是平等，而附加于其上的赋税也不是我们能为它定价的细节，因为没有任何数字被锁定。包括书籍在内的文化交流同样真实。这两个事实都不是故事的全部，也都不是给现代争论记分的东西。

:::quiz
为什么公元711年会出现在一门欧洲课程里？
- [ ] 因为图尔已经拯救了这块大陆，而公元711年只是续集
- [x] 因为一支由塔里克·伊本·齐亚德率领的部队渡海进入了伊比利亚，那一年之后半岛的政治不再只是拉丁的
- [ ] 因为公元622年的希吉拉发生在伊比利亚
- [ ] 因为希吉拉那一年科尔多瓦已经是一个哈里发国
:::solution
希吉拉是公元622年在阿拉伯的日期，而科尔多瓦的哈里发称号在公元929年，不是公元622年。图尔晚于公元711年，也没有终结穆斯林统治。那次渡海才是一门欧洲的地理无法把伊比利亚讲成一段不间断的拉丁故事的原因。[[#thm-inside]]就是这条主张，而更早的日期被留在半岛之外。
:::
:::

## 一场不是终点的战役

图尔与普瓦捷是一场战役的两个名字，不是两场战役。传统日期是公元732年10月。一些学者依据《754年编年史》主张公元733年或734年。三个年份都必须教。本图谱不会沉默地替读者挑选，正如它不曾为克洛维挑过一个单独的年份。下面的图把传统年份和一个替代年份——公元733年——画在一起。它没有标出公元734年。缺失的那个圆点不是针对那一年的决定。它是这幅图的限度，而正文必须承担第三个候选年份。

查理·马特指挥法兰克军队。他是宫相，是王国中居首的军事强人，而他不是国王。他不是公元800年12月25日受冕的那个人。查理曼（Charlemagne）是同一个家族中较晚的成员，马特的孙子，而那个帝国日期在[[after-rome/carolingians]]。把两个人混为一体，就是让一场战役去干一场加冕的工作。无论你采用哪个图尔年份，它与公元800年的距离仍然是几十年的事：800减732是68，800减733是67，800减734是66。一个730年代的宫相不是公元800年的一位皇帝。

这场战役没有拯救欧洲。那个传说是一个后来的故事：最初引以为傲时它是法兰克人的，在现代的形态里它是欧洲列国的。它想要的是某一个下午，在那一下午“欧洲”击败了“伊斯兰”。而这三个日期中的任何一个下午，都是一次法兰克人对一支袭扰军队的击败。战略结果是有限的。袭扰仍在继续。年表说明了这种延续，而没有为此后的某次袭扰锁定年份，因此本章不会发明一个。它能锁定的是战役之后的政治。公元756年，科尔多瓦埃米尔国建立。从公元732年10月到公元756年，年份的数字相差24；从公元733年算，相差23；从公元734年算，相差22。无论采哪种读法，科尔多瓦都在其后。一个把这场战役当作终点的传说，必须解释一个在终点之后建立的政府。它解释不了。

:::theorem 图尔没有终结穆斯林统治，也没有拯救欧洲 {#thm-tours}
被称为图尔战役或普瓦捷战役的那一战，传统定年为公元732年10月，一些学者则定年为公元733或734年，它没有拯救欧洲，也没有终结伊斯兰在西方的政治权力。查理·马特不是国王，袭扰仍在继续，而科尔多瓦埃米尔国建于公元756年。
:::
:::proof
证据是有争议的日期，加上后来已经锁定的政治。三个候选年份意味着，就连这个传说的“何时”也没有定论。《754年编年史》正是公元733年和734年仍然成立的原因，而不是因为本章有什么私人偏好。马特握有的是宫相之职，不是王冠；他的孙子的帝国加冕在公元800年12月25日。年表写明袭扰仍在继续。它把科尔多瓦埃米尔国定在公元756年，把哈里发国定在公元929年，两者都在战役之后。能够反驳[[#thm-tours]]的，是穆斯林诸政治体在730年代离开了伊比利亚的证据，或不再有袭扰的证据，或马特当时已经是国王的证据。这些都不是记录。这场战役能支撑的东西更窄，但仍然值得拥有：在三个候选年份中的某一年，一支法兰克军队在一位不是国王的统帅之下，击败了一支袭扰军队。有限不等于不存在。
:::

:::quiz

- [ ] 学者们唯一使用的日期是公元732年10月
- [x] 传统日期是公元732年10月，一些学者主张公元733年或734年，这场战役没有拯救欧洲，而查理·马特不是国王

:::

## 论证与反驳

一种反对意见说，把安达卢斯放进一门欧洲课程是一种姿态，一种示好的方式，而真正的欧洲是法兰克人在图尔所保卫的那个拉丁基督教的欧洲。按照这个观点，公元711年是一次来自科目之外的入侵，而本章是在为例外辩解。日期不用布道就回答了这一反对。[[#thm-inside]]并不要求任何人喜欢那些统治者。它问的是半岛在哪里，以及谁在统治它。一门课程当然仍可以只研究拉丁基督教世界，但它应当说明自己做了选择。它不应当说那些被略去的世纪发生在欧洲以外的地方。雅尔穆克从另一岸说明同一个道理。新的政治体在公元636年已经是一个地中海强权。公元711年的伊比利亚是那权力的又一次延伸，不是一个只为威胁法兰克人而存在的话题的突然出现。

相反的反对意见同样把历史压平。如果一块大陆获救的传说是假的，那么安达卢斯必定是一个宽容的黄金时代，而说不是就是威胁叙事的回潮。[[#def-andalus]]把两个象征都挡住。犹太人和基督徒的法律不平等是真实的。一个以阿拉伯语为载体的学术文化也是真实的，后来的拉丁学者曾从中汲取养分——其方式[[christendom/towns-and-learning]]可以承接，而不需要本图谱并未锁定的奠基年份。卡特洛斯的观点在这里被当作一条规则来使用，而不是一句引文：一部政治史在这两张海报之间都活得下来。要让宽容海报作为对整个时期的描述成立，需要单一的法律上的平等秩序，而受保护并纳税的地位并不是它。要让威胁海报作为对图尔的描述成立，需要穆斯林统治在730年代终结，而公元756年和公元929年与之矛盾。

第三种压力是要把公元711年讲得“有船、有岩石、有演说”般的完整。这种压力感觉像是完整性。它是编造。年表给出了一位统帅和一次渡海。[[sources/evidence]]就是这种拒绝的一般形式：不要把一句生动的句子提升为史料。一个虚构的细节会被标上虚构，而它仍然不是证据。

:::example 从希吉拉到伊比利亚 {#ex-span}
希吉拉在公元622年。塔里克的部队于公元711年渡海进入伊比利亚。两个年份的数字相差多少，而这个数字不被允许是什么意思？
:::solution
711减622是89。这个跨度是89年。

它不是一场战争的时长，也不是说这中间什么都没有发生。穆罕默德卒于公元632年。雅尔穆克按通常的定年在公元636年。两者都落在这个跨度之内，而两者都不在伊比利亚。这个数字只是否定那种把公元711年当作伊斯兰政治史开端的说法。
:::
:::

:::example 三个年份，然后是一个埃米尔国 {#ex-tours-years}
把公元732年10月、公元733年和公元734年摆在公元756年旁边。无论对战役的年份作何选择，什么仍然为真？
:::solution
无论怎么选择，查理·马特都不是国王，这场战役都不是公元800年的那次加冕，袭扰也没有被说成停止。科尔多瓦埃米尔国建于公元756年，在战役之后：756减732是24，756减733是23，756减734是22。

因此，《754年编年史》被采信也好，传统定年被采信也罢，把这场战役当作终点的传说在哪一个年份下都失败。本章的图只画了732年和733年。公元734年仍然是一个候选，而算术不需要一个圆点也能成立。
:::
:::

:::example 一句虚构的编年史句子 {#ex-invented}
下面这句话是虚构的。它不是史料。

“732年，查理王在图尔拯救了欧洲，西方再无穆斯林统治者。”

列出其中不成立的各个分句，以及逐一击破它们的已锁定事实。
:::solution
“国王”不成立，因为查理·马特不是国王。他是宫相。“拯救欧洲”不成立，因为那是后来的传说，而战役的结果是有限的。把“在732年”当作唯一年份不成立，因为公元733年和734年同样有学者主张——依据的是《754年编年史》——尽管公元732年10月仍是传统日期。“再无穆斯林统治者”不成立，因为阿卜杜勒·拉赫曼一世在公元756年建立科尔多瓦埃米尔国，阿卜杜勒·拉赫曼三世在公元929年取哈里发称号。

袭扰仍在继续，而本章没有为此后的某次袭扰发明年份。这句话是一个传说被压成的一行。要把它提升为证据，需要这份年表明确不予提供的东西。
:::
:::

:::example 雅尔穆克不是伊比利亚 {#ex-yarmouk}
为什么雅尔穆克——按通常的定年在公元636年——必须在本章讲授，又为什么不能把它讲成一次伊比利亚的战役？用它到公元711年的距离来回答。
:::solution
雅尔穆克解释了这个新政治体。一支东罗马野战军被击败，罗马对叙利亚的控制在其后的余波中瓦解，而以君士坦丁堡为中心的罗马国家继续存在。没有那个背景，公元711年看起来就像从空无一物的天上落下的一击，而图尔的传说正喜欢那样开始它的故事。

它不是伊比利亚的。711减636是75，而两地不同。把雅尔穆克称为西班牙的战役，或把公元711年称为第二次雅尔穆克，就是把一次叙利亚的战事与一次进入伊比利亚的渡海混为一体。[[#thm-inside]]需要把这两个事实都留住，且分开保持：一个早已存在的政治体，和一次更晚进入一个欧洲半岛。
:::
:::

移动年份。图注里的两个图尔日期就是这幅图所画的两个圆点，它们彼此相邻。公元734年——同样是某些《754年编年史》读者的选择——是没有圆点的第三个候选。公元756年的科尔多瓦，以及公元929年的哈里发国，出现在战役之后。公元622年的希吉拉不是伊比利亚的圆点。不要让这条线变成一个在730年代收尾的拯救故事。

:::warning 一次拯救，或一个黄金时代
常见的迷思说图尔拯救了欧洲，它还常常把查理·马特与查理曼混为一体，让一位宫相在讲述中变成一位皇帝。这场战役没有拯救欧洲。马特不是国王，年份在公元732、733和734年之间有争议，袭扰仍在继续，而科尔多瓦的埃米尔国建于其后。相反的迷思——一个没有法律不平等的宽容黄金时代——同样是一张海报。犹太人和基督徒的受保护地位是一种较低的地位。政治、赋税和军队才是历史。威胁与宽容都是口号，而[[#def-andalus]]不会驮起它们中的任何一个。
:::

:::history
希吉拉在公元622年，是伊斯兰历纪年的起点，而穆罕默德卒于公元632年。公元711年，一支由塔里克·伊本·齐亚德率领的部队渡海进入伊比利亚，那一年之后半岛的政治史不再只是一部拉丁的历史。科尔多瓦埃米尔国随后建于公元756年，在图尔战役各个有争议日期之后。
:::

## 通向何处

查理·马特的家族，以及绝不可与他的战役混为一谈的、公元800年12月25日的那个帝国主张，在[[after-rome/carolingians]]。在雅尔穆克战败却依然存在的罗马国家在[[after-rome/byzantium]]。公元1492年的格拉纳达是[[crises/year-1492]]，不是对公元711年的一句注解。后来使用阿拉伯语书籍的拉丁学术——这里没有发明奠基年份——在[[christendom/towns-and-learning]]承接。把安达卢斯留在欧洲之内的地图在[[sources/naming-europe]]。

:::summary
- 希吉拉在公元622年。穆罕默德卒于公元632年。雅尔穆克按通常的定年在公元636年。这些解释了一个新政治体。它们还不是伊比利亚的事件。
- 公元711年，一支由塔里克·伊本·齐亚德率领的部队渡海进入伊比利亚。那一年之后，半岛的政治史不再只是拉丁的。本章不添加船只、演说和战役叙事。
- 公元750年，阿拔斯人推翻东方的倭马亚哈里发国。公元756年，阿卜杜勒·拉赫曼一世建立科尔多瓦倭马亚埃米尔国。公元929年，阿卜杜勒·拉赫曼三世取哈里发称号。
- 图尔，或称普瓦捷，传统日期是公元732年10月。一些学者依据《754年编年史》主张公元733年或734年。这场战役没有拯救欧洲。查理·马特不是国王。袭扰仍在继续。
- 科尔多瓦的埃米尔国出现在这场战役每一个候选日期之后。一个终点的传说活不过公元756年，更不用说公元929年。
- 安达卢斯是一部政治史。它不是宽容的象征，也不是威胁的象征。
:::

## 习题

:::exercise 从希吉拉到渡海 {level=1 check="89"}
希吉拉在公元622年。塔里克·伊本·齐亚德的部队于公元711年渡海进入伊比利亚。按本图谱的规则，这个跨度是多少年？（请输入年数。）
:::solution
711减622是89。年数是89。穆罕默德卒于公元632年和雅尔穆克在公元636年，都落在这个跨度之内，而两者都不是伊比利亚的事件。这个数字是一段距离，不是伊斯兰政治史始于那次渡海的主张。
:::
:::

:::exercise 只有传统年份 {level=1 check="732"}
图尔战役，或称普瓦捷战役，的传统年份是哪一年？（请输入年份。）
:::solution
传统日期是公元732年10月。年份是732。它不是学者们争论的唯一年份。一些人依据《754年编年史》主张公元733年或734年。输入732记录的是传统日期，不是断定其他年份不可能，也不是说这场战役拯救了欧洲。
:::
:::

:::exercise 不是国王 {level=1}
用三四句话说清楚：查理·马特在图尔时是什么人，不是什么人，以及为什么公元800年的加冕不能移回到他的战役上。
:::solution
他是宫相，是居首的法兰克军事统帅。他不是国王。他不是查理曼，尽管查理曼是他的孙子，并在公元800年12月25日被加冕为帝。

无论取战役的哪个年份——公元732、733或734年——加冕都在几十年之后。对一支袭扰军队的一次胜利——此后袭扰仍在继续——既不是一个帝国称号，也不是穆斯林统治在伊比利亚的终结。
:::
:::

:::exercise 雅尔穆克为何在本章 {level=2}
解释雅尔穆克——按通常的定年，公元636年——让你对公元711年理解了什么，又没让你对伊比利亚、或对罗马国家的终结说什么。
:::solution
雅尔穆克是一次东罗马军队的失败，此后罗马对叙利亚的控制瓦解。它表明，在公元622年的希吉拉和穆罕默德逝世的公元632年之后建立的那个政治体，已经是一个地中海强权。公元711年的渡海于是是那权力的一次更晚的西部延伸，既不是一次无来由的袭扰，也不是伊斯兰历史的开端。

它不发生在伊比利亚：711减636是75。它没有终结君士坦丁堡的罗马国家——那个国家继续存在，正如[[after-rome/byzantium]]所论证的，在一场战败和一个地区的丧失之后还延续了许多世纪。所谓“通常的定年”是通行的年份，不是本书复制出来的一纸文书。
:::
:::

:::exercise 传说之后的科尔多瓦 {level=2}
一幅图注写道：“732年：穆斯林对欧洲的扩张结束。”用733年、734年、756年和929年，把图注改写成一个可核查的主张，并说出它的限度。
:::solution
一个可核查的替代是：一支由查理·马特——他不是国王——率领的法兰克军队在图尔或普瓦捷击败了一支袭扰军队，传统上在公元732年10月，尽管公元733年和734年也有学者主张，而袭扰仍在继续。

限度在其后的政治。科尔多瓦倭马亚埃米尔国建于公元756年，哈里发称号取于公元929年。扩张、统治和袭扰不是同一个词。把“穆斯林对欧洲的扩张”终结在公元732年，就是抹去一个被年表安置在战役之后的政府。改写后的图注没有把一块大陆的拯救判给这场战役。
:::
:::

:::exercise 两张海报 {level=2}
为什么在拒绝了图尔拯救欧洲的说法之后，把安达卢斯称为宽容的黄金时代仍然不够？用法律地位来回答，不要发明赋税数字或人口数字。
:::solution
拒绝一张海报并不证明它的反面。[[#thm-tours]]说这场战役是有限的、日期是有争议的、统帅不是国王、科尔多瓦还在后头。这些没有一条是安达卢斯内部日常法律的描述。

犹太人和基督徒可以既受保护又在法律上不平等。带赋税的保护不是平等，而赋税的数额没有任何一个被锁定，因此这里不会给出。阿拉伯语的学术与文化交流是真实的，却不是一份平等身份的特许状。[[#def-andalus]]把主题保持在统治者、赋税、军队和城市的范围。卡特洛斯的规则——政治，而不是象征——同时禁止威胁海报与宽容海报。黄金时代是一种情绪。它不是史料。
:::
:::

:::exercise 完整的拒绝 {level=3}
一部纪录片说：“732年，法兰克人的国王查理·马特在图尔拯救了欧洲。伊斯兰在西方的统治结束了。”写出这部影片所使用的论证，然后逐点驳斥。包括日期争议、他的职务、袭扰，以及科尔多瓦。
:::hint
把这些句子拆开：年份、“国王”这个称号、“拯救”这个动词，以及统治终结的主张。每一条都有一个不同的已锁定事实对它不利。公元756年在战役的每个候选年份之后。不要添加对公元711年那次渡海的描述。
:::
:::solution
影片的论证是：一场战役是一块大陆的拯救，由一位国王打的一场有已知年份的战役，带来一个永久的结果。它把伊斯兰政治史当作一个外部威胁，被一次法兰克的胜利关上了。

年份不是单一的。公元732年10月是传统的；一些学者依据《754年编年史》主张公元733年或734年。马特是宫相，不是国王，也不是公元800年加冕的那位皇帝。这场战役没有拯救欧洲：那句话是后来的传说，而能陈述的结果是对一支袭扰军队的击败。袭扰仍在继续，而本章不为它们发明年份。统治没有终结。阿卜杜勒·拉赫曼一世在公元756年建立科尔多瓦埃米尔国，在732、733和734年每一个之后；阿卜杜勒·拉赫曼三世在公元929年取哈里发称号。[[#thm-tours]]就是简短的形式。这部影片在每个分句上都失败。
:::
:::

:::exercise 沉默的代价 {level=3}
一份教学大纲教授到罗马时期为止的伊比利亚，然后在拉丁基督教的诸王占统治地位时重新开讲，并把中间的缺口称为“算不上真正的欧洲”。这份大纲主张了什么？来自711、756和929年的什么史料对它不利？另外说出本章仍然拒绝把安达卢斯变成什么。
:::hint
这个主张关乎地图，不关乎你是否钦佩那些统治者。[[sources/naming-europe]]是一般形式。不要用宽容故事或威胁故事来回答。公元1492年的格拉纳达是一件较晚的事件，不是跳过较早诸世纪的理由。
:::
:::solution
这份大纲主张伊比利亚的穆斯林统治落在欧洲历史之外，于是从那次渡海到后来拉丁人推进之间的诸年份是一段外来中断，而不是半岛自己的政治。这是一个地图的选择，却被当作关于这个地方的事实来出售。

对它不利的证据是：公元711年，塔里克的部队渡海进入伊比利亚，这在地理之内；公元756年，在公元750年的阿拔斯革命之后，一个倭马亚埃米尔国在科尔多瓦建立；公元929年，统治者取哈里发称号。这些都是半岛上的政府。略去它们不会使它们成为欧洲之外的东西。它只会让这份大纲比年表更沉默。[[#thm-inside]]就是那个拒绝。

本章仍然拒绝的是那对象征。安达卢斯并不因此就是宽容的典范，也不是一个以图尔为含义的永久威胁。它是一部政治史。格拉纳达在公元1492年的投降，在[[crises/year-1492]]，既不许可这种跳过，也不能总结其间的诸世纪。
:::
