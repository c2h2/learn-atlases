公元800年12月25日的加冕主张了什么，843年的《凡尔登条约》又分割了什么？

那次加冕在西方主张了一个帝国。教皇利奥三世（Leo III）在罗马为查理曼（Charlemagne）加冕为帝。君士坦丁堡已有一位皇帝，而它对新的帝号提出异议。那一下午没有任何事情终结东部的罗马国家、创建一个民族，或让一个人成为全欧洲的皇帝。按年份的数字之差，四十三年之后，凡尔登（Verdun）把一份法兰克人的遗产分割给三个孙子：洛泰尔一世（Lothar I）、日耳曼人路易（Louis the German）和秃头查理（Charles the Bald）。它没有创建法国和德国。一次较晚的加冕——奥托一世（Otto I）在公元962年的那次——是另一个帝国主张，不是同一场典礼。公元988年在基辅的一次传统受洗是一个标记，不是人口普查。1054年的相互绝罚是诸教会之间一场长期争论中的一个标记，不是两个民族的出生证明，也不是一天之内办完的离婚。

这个家族在成为帝国性的之前就有实权。查理·马特（Charles Martel）是查理曼的祖父，是宫相，不是国王；与他相关联的那场战役，是[[after-rome/islam-in-the-west]]中有争议的图尔之战：传统上是公元732年10月，公元733年和734年也有学者主张。本图谱没有锁定一位加洛林家族成员首次取王号的年份。它锁定的是那个帝国日期。把马特、王权和皇帝分开保持，那次加冕才不会从一项主张变成传说的最后一幕。

## 一个帝号，遭到争辩

:::definition 西方帝国主张 {#def-claim}
**西方帝国主张**是查理曼在公元800年12月25日由利奥三世在罗马加冕为帝时所取的皇帝称号，以及君士坦丁堡对它的异议。它不是一次东罗马官职的移交，不是一个空缺被填补，也不是说这位皇帝统治欧洲每一个民族的声明。
:::

:::definition 遗产分割 {#def-division}
**遗产分割**是在一个家族的诸继承人之间对土地、权利和称号的分派。公元843年的《凡尔登条约》就是这样一次分割。它不是一个民族国家的创建法令，也没有创建法国和德国的现代边界或现代人民。
:::

公元800年12月25日，教皇与法兰克国王做成了一件公开的事实。利奥三世奉上帝国冠冕。查理曼承担起这个称号。后来的一部拉丁传记把这一天讲成适合宫廷的形状，而本图谱没有为那部传记锁定年份。我们不会把它当作一份笔录来对待，也不会把一个国王大吃一惊的故事当作事实重复。我们同样不会发明任何誓词的文本。可核查的那句话是[[#def-claim]]。那个圣诞节之后，有了一位西方的皇帝。东方的宫廷并不把这个帝号当作自己的。

异议之所以要紧：君士坦丁堡的罗马国家——[[after-rome/byzantium]]所教授的——仍然在那里。查士丁尼（Justinian）的法典书已是几个世纪以前的事，而这个国家并没有变成一具化石。罗马城里的一次加冕在西方是一个挑战，一件新事。它不是一把空宝座的拯救。本章不会给公元800年的东方统治者定年，因为那些年份没有锁定；也不会用一个空缺来解释这场争论。存在两个主张。一个是古老的、东方的。一个是新生的、西方的。把第二个称为“那个”帝国，仿佛第一个已经辞职，就是让一场法兰克人的典礼做它做不了的活。

利奥三世不是一个中性的典礼司仪。他是一个政治行动者，在罗马有敌人，并且有理由想要一个保护者。他的危机之年在这里没有锁定，因此不会被补上。锁定的日期就是加冕本身。保护与合法性双向流动：一位国王得到一个教皇在罗马能够给予的称号，一位教皇得到一柄法兰克人的剑。这是政治。它还不是[[christendom/popes-and-kings]]的叙任权之争，那一场有它自己的日期。这已经足以阻止一幅王冠单单从神学降临的图景。

:::theorem 800年的加冕是一次新的主张，不是一次移交 {#thm-claim}
公元800年12月25日，利奥三世为查理曼加冕，创设了一个君士坦丁堡提出异议的西方帝号。它没有终结东罗马帝国，也没有让查理曼成为全欧洲的皇帝。
:::
:::proof
证据是典礼的地点，以及年表所记录的东方回应。冠冕在罗马戴出，给一位法兰克国王，由一位教皇出手。一位皇帝已经在君士坦丁堡在位，就是那个没有在公元476年终结的罗马国家。异议正是一个活着的竞争主张的样子。如果东方的帝职已经断绝，异议就没有必要。能够反驳[[#thm-claim]]的，是君士坦丁堡把这个帝号承认为它自己那被移交的官职的证据，或东方的帝系已经停止的证据。一个西方的空缺故事不是那个证据，而本章不会为它定年。那次加冕能支撑的，是新帝号、教皇的角色和那场争执。它不能支撑一幅每个地区之上有一位皇帝的欧洲地图，也不能支撑[[after-rome/byzantium]]中那个国家的终结。
:::

## 43年之后实际分割了什么

从公元800年到公元843年是43年。年表有意如此陈述这个数字：843减800，不是44。公元843年，《凡尔登条约》分割法兰克人的遗产。洛泰尔一世、日耳曼人路易和秃头查理是公元800年那位受冕者的孙子。年长的洛泰尔保留一个帝国称号和土地与权利的中份。路易取东份。查理取西份。这些份额是一捆捆的统治权，不是民族国家。其中的人是诸王之下的法兰克人和邻人。他们不是现代法兰西或德意志共和国的公民，条约也没有说他们是。

:::theorem 凡尔登分割了一份遗产，没有创建两个民族 {#thm-verdun}
公元843年的《凡尔登条约》把一份法兰克人的遗产分割给洛泰尔一世、日耳曼人路易和秃头查理。它没有创建法国和德国。
:::
:::proof
证据是行为的种类与当事各方。三个孙子分割土地、权利，以及一个由其中一人保留的帝国称号。[[#def-division]]就是这类文书所属的类别。两个民族的创建会属于另一个类别：一个人民、一个连续的法律人格，以及与后来国家吻合的边界。凡尔登没有提供其中任何一样。中份不对应任何一个现代国家，这本身就是一条线索：这份条约做的不是替那两个国家划界的工作。家族内部的后来分割随之而来；本图谱没有锁定它们的年份，也不会为了让一个民族国家的故事更顺而发明它们。能够反驳[[#thm-verdun]]的，是一段以现代国名和现代边界创建国家的843年文本。不存在这样的文本。不算数的，是一本需要一个诞辰的后来教科书，或一位史家能够追溯的西方与东方的国王世系。世系不是创建。一个西方王国可以另有后来的继承人，而凡尔登并不是他们的出生证明。
:::

谁从诞辰中受益？想要法国和德国始于一个学生能够记诵的日期的课程设置。这个日期对一个民族国家的故事有用，作为对公元843年的描述无用。[[sources/time-and-names]]就是那个一般性的警告：一个绰号和一套国王在位年的排法都是主张，而当主张被当作不再需要证据的标签时，就有人受益。这里的受益是一幅简单的地图。代价是中份、那个不是民族的帝号，以及那三位兄弟——他们是一家人，不是两个民族的代表。

奥托一世在公元962年加冕为帝。那是另一个帝国主张，不是与公元800年同一场典礼的延续，也不是对凡尔登的一份补遗。从公元800年到公元962年，年份的数字相差162。从公元843年到公元962年相差119。本图谱没有锁定凡尔登与奥托之间的诸王，所以不会填入他们的在位年份。可比的是行为的种类。一个人被加冕为帝。他不是查理曼，这一年也不是公元800年。奥托的圆点是这幅图上的最后一个事件。传统的公元988年受洗和1054年的绝罚落在它之外，而它们必须在正文里讲授，否则就会被遗忘。

:::quiz
公元800年12月25日的加冕主张了什么？
- [ ] 东罗马帝国已经终结，帝号移进了西方的一个空缺
- [ ] 法国和德国在那一天被创建
- [x] 一个西方的帝号，君士坦丁堡对它提出异议
- [ ] 查理·马特成了皇帝
:::solution
利奥三世加冕的是查理曼，不是马特，而马特从不是国王。东方帝国继续存在并对这个帝号提出异议，所以这不是一把空椅子等着人坐。法国和德国是附着在公元843年上的迷思，不是附着在加冕上的，而且在那里它们也是迷思。[[#thm-claim]]是合适的分量。
:::
:::

## 一次不是人口普查的受洗，一场不是一天的分裂

公元988年，按传统的定年，基辅的弗拉基米尔（Vladimir）受洗。年表要求把这个年份当作罗斯（Rus'）皈依的传统标记来对待，不是当作信仰的人口普查。“传统”弱于一纸特许状，却强于一通猜测：它是传统交给我们的日期，而我们不假装本书里存有一部登记册。公开的行为是一位统治者采纳东方基督教。它是政治性的，也是教会性的。它没有说基辅的每一个人在公元988年信仰什么，也不去盘问一部编年史不曾询问的人。同一个限度曾管着[[after-rome/christianisation]]里公元380年的法令，也管着[[after-rome/successor-kingdoms]]里有争议的克洛维受洗。克洛维有两个被提出的年份。弗拉基米尔有一个传统年份。两者都不是灵魂的清点。

关于1054年，一段话就够了，这里就是那一段话。相互绝罚涉及洪贝尔（Humbert），一位教皇特使，和米海尔·凯鲁拉里乌斯（Michael Cerularius），君士坦丁堡的牧首。这些行为是真实的，它们坐落在一段关于权威、礼仪与教义的更长争论之内。它们不是拉丁教会与希腊教会变成两个隔绝世界的那一天，也不是诸民族的创建。争论与接触在此之前与之后都存在。诸教皇与王室职分的拉丁故事在[[christendom/popes-and-kings]]继续。东罗马国家仍然是[[after-rome/byzantium]]的那个国家：在查士丁尼之后若干世纪，在1204年4月13日的洗劫与1453年5月29日的陷落之前若干世纪。标记不是离婚判决书。

:::quiz
凡尔登在公元843年做了什么？
- [ ] 它创建了法国和德国两个民族
- [ ] 它以同一位皇帝重复了公元800年12月25日的典礼
- [x] 它把一份法兰克人的遗产分割给三个孙子
- [ ] 它是基辅的弗拉基米尔的传统受洗
:::solution
三个孙子是洛泰尔一世、日耳曼人路易和秃头查理。他们分割土地、权利，而对洛泰尔，还有一个帝国称号。查理曼已在公元800年受冕，他不是条约中人。弗拉基米尔的传统受洗在公元988年。创建两个现代民族，是[[#thm-verdun]]所拒绝的读法。中份是这一读法失败的原因之一：它不对应后来任何一个民族。
:::
:::

## 论证与反驳

对民族国家读法的辩护是说，名字和王国必须始于某处，而凡尔登正是西方份额与东方份额分道扬镳的地方。后来的法国和后来的德国不是十九世纪毫无根基的发明。说条约“没有创建”它们，听起来像是在否定有任何连续的东西随后而来。这个辩护配得上它所应得的区分。

某种连续性是真实的。有一个西方份额和一个东方份额，后来的政治可以从它们往后讲述。[[#thm-verdun]]不禁止那种讲述。它禁止的是特定的一句话：条约创建了现代国家，像一个出生证明创建法律人格那样。当事各方是兄弟，不是民族。边界不是现代边界。中份没有单一的现代继承者，能让这份条约成为一台恰好生产两个国家的机器。要让那句民族国家的话成立，需要我们没有的那段文本。让一种谦抑的连续性为真的，是一条统治与名号的链条，后来的章节可以研究它，而不必把护照的日期提前。

第二个反对意见说，如果君士坦丁堡对这个帝号提出异议，那次加冕就是一场失败，应当作为教皇的一场幻想来教。异议不是失败。[[#thm-claim]]说这个帝号是新的、有争议的，而当另一位皇帝存在时，一个真实的主张看起来就是这样。一个无人理睬的幻想不会遭到异议。东方的异议是证据，表明两个宫廷都明白这个帝号重要。它不是查理曼实际上仍是国王、教皇自说自话的证据。查理曼承担着这个西方称号。对方拒绝把它当作自己的。

奥托的加冕是对照。如果公元800年创建的“那个”西方帝国是一场单一的连续典礼，那么公元962年就该是一场纪念。那是另一个人在162个年份数字之后重取这个称号。这段间隔——我们不用未锁定的在位年份去填它——证明这一时期的帝国主张是一个个行为，被重复，且彼此竞争，不是一簇不曾间断传递的火焰。

:::example 四十三年 {#ex-forty-three}
加冕在公元800年12月25日。凡尔登在公元843年。这个跨度是多少年，本图谱为什么拒绝44？
:::solution
843减800是43。这个跨度是43年。年表直接给出了这个计数。把两端都算进去会得到44，而那不是规则。同样的年份数字之差，曾在[[after-rome/christianisation]]里从公元313年用到公元380年。

这个数字是一次加冕与一次遗产分割之间的距离。它不是一个民族的时长，也不会让那三个孙子成为与公元800年那位皇帝同一个人。
:::
:::

:::example 两次加冕 {#ex-two-crowns}
把公元800年12月25日与公元962年并置。它们共享哪种行为，而第二个不能称之为什么？
:::solution
每一次都是一次帝国加冕：查理曼的那次出自利奥三世之手，奥托一世的那次在公元962年。它们共享一种主张的类型。年份的数字相差162，因为962减800是162。从公元843年的凡尔登到奥托，相差119。

你不能把奥托的加冕称为同一场典礼的延续、一场周年纪念，或法国和德国开始的时刻。本章的图画了这两个圆点和凡尔登。它没有画中间的那些国王，因为本图谱没有锁定他们，而坐标轴本身的边缘不是一个事件。
:::
:::

:::example 一句虚构的编年史句子 {#ex-invented}
下面这句话是虚构的。它不是史料。

“843年，诸王在凡尔登创建了法国和德国，他们的誓词宣告诸民族诞生。”

这两个半句各错在哪里，而为什么不能靠写下那段誓词来修补后半句？
:::solution
前半句把一次遗产分割变成了两个现代民族的创建。当事各方是洛泰尔一世、日耳曼人路易和秃头查理——分割土地与权利的孙子们。[[#thm-verdun]]就是纠正。中份在那句话里没有成为一个民族，这是这句话失败的种种方式之一。

后半句发明了一段誓词，又发明了它的内容。本章不提供任何誓词的文本，哪怕是为了反驳一段誓词。修补就是第二次编造。这句话可以在没有替代演说的情况下被拒绝：史料中没有那样的宣告，而一个民族的诞生不是这份条约所做的事。
:::
:::

:::example 一次传统的受洗 {#ex-vladimir}
基辅的弗拉基米尔按传统日期在公元988年受洗。你可以推论什么，而这个限度与克洛维的限度有什么不同？
:::solution
你可以推论一个传统的标记：一位统治者公开采纳东方基督教，并与罗斯作为政治和教会故事的皈依相连。你不能推论基辅信仰的人口普查，也不能把这个年份当作本书复制出来的一纸特许状。“传统”就是这个日期的强度。

克洛维在[[after-rome/successor-kingdoms]]里有两个被主张的年份，约公元496年与约公元508年，没有沉默的挑选。弗拉基米尔有一个传统年份，不是一对。两个限度都拒绝灵魂的清点。区别只在于历法争议被塑成什么形状，而不是准许去读出公元988年人心中的想法。
:::
:::

移动年份。15年的窗口装不下公元800年和843年：距离是43年，而窗口不到它的一半。公元962年的奥托更远，在凡尔登之后119个年份数字。传统的公元988年受洗和1054年的绝罚没有圆点，因为它们落在坐标轴之外。不在图上，不等于不在历史里。不要让三个圆点变成一场单一的帝国典礼，也不要让凡尔登的圆点变成一个民族国家的诞辰。

:::warning 两个民族的诞生
常见的说法是凡尔登创建了法国和德国。它没有。三个孙子在公元843年分割了一份法兰克人的遗产。这些份额不是现代国家，中份不是那两个民族之一，其中的人也不是那两个民族的公民。一个后来的王国可以从一个份额衍生，而不需要条约是出生证明。同样的过度解读把查理·马特——一位不是国王的宫相——塞进查理曼的帝冠，又把公元800年的加冕放进一把空缺的东方宝座。每一句话都比它的日期大。
:::

## 通向何处

继承这些王国的拉丁世界中的领主权、地租与不自由身份的诸种形态，在[[christendom/lords-and-peasants]]。诸教皇与诸王关于职分的争执——它与利奥三世的加冕不是同一场争执——在[[christendom/popes-and-kings]]。在公元800年之后继续存在并对这个帝号提出异议的东方帝国，在[[after-rome/byzantium]]。那个“大陆获救”的传说想在查理曼受冕之前就送终的伊比利亚政治体，在[[after-rome/islam-in-the-west]]。

:::summary
- 公元800年12月25日，利奥三世在罗马为查理曼加冕为帝。这个主张是一个新的西方帝号。君士坦丁堡对它提出异议。东方的帝国没有终结。
- 查理·马特不是那位皇帝，也不是国王。本图谱没有锁定一位加洛林家族成员首次取王号的年份。锁定的帝国日期是公元800年。
- 从公元800年到公元843年是43年。凡尔登把一份法兰克人的遗产分割给洛泰尔一世、日耳曼人路易和秃头查理。它没有创建法国和德国。
- 奥托一世在公元962年加冕为帝。那是另一个主张，不是与公元800年同一场典礼，也不是对凡尔登的补遗。
- 公元988年是基辅的弗拉基米尔受洗的传统日期。标记不是信仰的人口普查。
- 1054年，洪贝尔与米海尔·凯鲁拉里乌斯的相互绝罚，是一场更长分裂中的一个标记，不是一天之内办完的离婚，也不是一次民族创建。
:::

## 习题

:::exercise 标准跨度 {level=1 check="43"}
加冕在公元800年，《凡尔登条约》在公元843年。这个跨度是多少年？（请输入年数。）
:::solution
843减800是43。年数是43。年表给出了这个计数，它是年份的数字之差，不是44。这个跨度分开了一次帝国主张与一次遗产分割。它不度量一个民族的寿命。
:::
:::

:::exercise 从凡尔登到奥托 {level=1 check="119"}
凡尔登在公元843年。奥托一世在公元962年加冕为帝。这两个年份数字之间有多少年？（请输入年数。）
:::solution
962减843是119。年数是119。奥托的加冕是一次后来的帝国主张，不是公元800年那场典礼的延续，也不是条约的一个条款。两个日期之间的诸王在本图谱中没有锁定，因此这个数字不得用他们的在位年份去填。
:::
:::

:::exercise 圣诞节那天谁做了什么 {level=1}
用三四句话说清楚：公元800年12月25日谁为谁加了冕，称号是什么，谁对它提出异议。不要把东方的宝座说成空缺。
:::solution
教皇利奥三世在罗马为查理曼加冕为帝。这个称号是西方帝国主张，在那个场合是新的，不是东罗马官职的移交。君士坦丁堡提出异议，因为一位东方的皇帝已经存在。

异议是证据，表明这个帝号对两个宫廷都重要。它不是东方国家已在公元476年或公元800年终结的证据。查理·马特不是冠冕之下的那个人。
:::
:::

:::exercise 这个主张能承受什么 {level=2}
列出公元800年的加冕能支撑的东西，以及三件它常被要求支撑、却支撑不了的东西。用上君士坦丁堡和地图的限度。
:::solution
它能支撑公元800年12月25日的一个公开行为，一位教皇和一位法兰克国王，一个西方的皇帝称号，以及来自君士坦丁堡的异议。[[#thm-claim]]就是那张清单。

它不能支撑东方帝国的终结、一把空缺的宝座，或全欧洲的皇帝。君士坦丁堡的罗马国家继续存在，并质疑这件新事。那次加冕也不是凡尔登，不是法国或德国的创建。后来的一部宫廷传记不是那一天的笔录，而任何誓词文本都不应出现在答案里。
:::
:::

:::exercise 重写诞辰 {level=2}
一块牌子上写着：“843年：法国和德国的诞生。”把它换成一句可核查的话，点出三位继承人和行为的种类。然后用两句话说清，中份为什么是这块牌子的麻烦。
:::solution
一个替代是：公元843年，《凡尔登条约》把一份法兰克人的遗产分割给洛泰尔一世、日耳曼人路易和秃头查理，帝国称号在洛泰尔的份额里。这个行为是遗产分割，不是民族国家的创建。

中份不对应任何一个现代国家。一份真正恰好是两个民族诞生的条约，必须交代第三捆既不属于这方也不属于那方的土地与权利。[[#thm-verdun]]正是用这个错位，连同当事各方的家族性质，来对付这块牌子。
:::
:::

:::exercise 标记，不是普查 {level=2}
公元988年应当如何陈述？基辅的弗拉基米尔的传统受洗，为什么不是关于基辅每一个居民人数的证据？把这个限度与公元380年简短地比较一下。
:::solution
把它陈述为弗拉基米尔受洗的传统日期，和罗斯皈依的一个标记——不是特许状，也不是人口普查。公开的事实是一位统治者采纳东方基督教。政治与教会层面的后果在这个尺度上可以是真实的。

它们没有记录每一个人的信仰。公元380年的法令把基督教定为帝国的国教，它仍然不是一次良心的清点。平行的是限度，不是制度：一位统治者的公共宗教不是一份调查。克洛维案的不同在历法上——两个被主张的年份，而不是一个传统年份——相同的是对统计数字的拒绝。
:::
:::

:::exercise 想要一个诞辰的博物馆 {level=3}
一段展说写道，凡尔登是“法兰西与德意志诸民族登台的时刻”，并补充说诸王发过一段誓词，展馆随后引用了它的现代法语和现代德语译文。这个历史主张错在哪里，靠自己撰写誓词来修补它又错在哪里？给出一个单句的替代标签。
:::hint
把关于民族的时代错置与誓词的编造分开。本章禁止提供誓词的文本。三个名字加上遗产一词，足够写出替代标签。不要为任何后来的家族条约定年。
:::
:::solution
这个历史主张把现代民族提前塞进一次家族析产。当事各方是孙子们——洛泰尔一世、日耳曼人路易和秃头查理——在公元843年分割土地与权利。这些份额不是现代国家，而中份是对一个只生产两个民族的故事的常设异议。诸王国后来的连续不是出生证明。[[#thm-verdun]]就是纠正。

誓词是第二重错误。没有任何文本被锁定，而写一段出来——哪怕作为怀疑的戏仿——也是在替诸王编造话语。展馆的现代法语和现代德语正是一条线索，表明那段演说是我们自己的。拒绝它。不要用一个更好的虚构去替换它。

一个装得下的标签是：843年，《凡尔登条约》把一份法兰克人的遗产分割给三个孙子，没有创建法国和德国。
:::
:::

:::exercise 为什么1054年只有一段 {level=3}
一位读者想要一部拉丁教会与希腊教会分裂的完整历史，从1054年的相互绝罚讲起，也讲到它为止。解释为什么在本章里一段话才是合适的长度，那些行为能支撑什么，又不能支撑什么。指出拉丁的故事接下来走向哪里，而不要讲述它。
:::hint
点出洪贝尔与米海尔·凯鲁拉里乌斯，并保留标记一词。东方国家在这个年份的两侧都还存在，而1204年和1453年远在本章的讲述之外。[[christendom/popes-and-kings]]是拉丁的延续，它不是对1054年的重述。
:::
:::solution
洪贝尔，一位教皇特使，和米海尔·凯鲁拉里乌斯，君士坦丁堡的牧首，在1054年卷入相互绝罚。这些行为是真实的，它们属于一段关于权威、礼仪与教义的更长争论。一个标记记录的是行为。一道离婚判决书则会宣称两个教会在某一天变成了隔绝的世界，而那段更长的争论容不下这种说法。争论与接触在此之前与之后都存在。

本章的主题是公元800年的法兰克主张和公元843年的分割，而奥托、弗拉基米尔和这个标记是其后的限度。一部完整的教会史会淹没它们，也会讲述不属于本题的年份。东罗马国家仍然在那里，在查士丁尼之后若干世纪，在1204年4月13日和1453年5月29日之前若干世纪，所以1054年也不是那个国家的终结。

诸教皇与诸王的拉丁故事在[[christendom/popes-and-kings]]继续。点出章节名就是指针。在这里讲述卡诺莎（Canossa），或任何后来的争执，都会打破一段话的规则，并偷走一门有它自己史料的课程。
:::
