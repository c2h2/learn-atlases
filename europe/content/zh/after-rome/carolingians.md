公元800年12月25日的加冕主张了什么？公元843年的《凡尔登条约》又分割了什么？

这次加冕在西方提出了一个帝国主张：教皇利奥三世（Leo III）在罗马为查理曼（Charlemagne）加冕称帝。君士坦丁堡当时已有皇帝，并对这个新帝号提出异议。那天下午发生的一切，既没有终结东罗马国家，也没有缔造一个民族，更没有让一个人成为全欧洲的皇帝。按年份数字之差计算，四十三年后，凡尔登（Verdun）把法兰克人的遗产分给了三个孙子：洛泰尔一世（Lothar I）、日耳曼人路易（Louis the German）和秃头查理（Charles the Bald）。它并没有缔造法国和德国。后来公元962年奥托一世（Otto I）的加冕，是另一次帝国主张，而不是同一场典礼。公元988年基辅的那次受洗按传统定年，是一个标志，而不是人口普查。1054年的相互绝罚是教会之间长期争论中的一个标志，既不是两个民族的出生证明，也不是一天之内办完的离婚。

这个家族在称帝之前就已大权在握。查理曼的祖父查理·马特（Charles Martel）是宫相，不是国王；与他相关的战役，就是[[after-rome/islam-in-the-west]]中有争议的图尔之战：传统定年为公元732年10月，公元733年和734年也有人主张。本图谱没有确定加洛林家族成员首次称王的年份，已确定的是称帝的日期。把马特、王位和帝位区分开来，加冕才仍然是一项主张，而不会变成某个传说的最后一幕。

## 一个遭到异议的帝号

:::definition 西方帝位主张 {#def-claim}
**西方帝位主张**指公元800年12月25日利奥三世在罗马为查理曼加冕时，查理曼所获得的皇帝称号；君士坦丁堡对此提出了异议。它不是东罗马帝位的移交，不是填补空缺，也不表示这位皇帝统治着欧洲的每一个民族。
:::

:::definition 遗产分割 {#def-division}
**遗产分割**指一个家族的继承人之间对土地、权利和称号的分配。公元843年的《凡尔登条约》就是这样一次分割。它不是民族国家的建国法令，也没有创造法国和德国的现代边界或现代民族。
:::

公元800年12月25日，教皇与法兰克国王共同造就了一个公开的事实：利奥三世戴上帝冠，查理曼接受帝号。后来的一部拉丁文传记以适合宫廷的方式讲述了这一天，本图谱没有为这部传记确定成书年份。我们不会把它当作现场记录，也不会把“国王事先毫不知情”的故事当作事实复述，更不会杜撰任何誓词的文本。可以检验的论断是[[#def-claim]]：那个圣诞节之后，西方有了一位皇帝，而东方宫廷并不承认这个帝号属于自己。

异议之所以重要，是因为君士坦丁堡的罗马国家（见[[after-rome/byzantium]]）依然存在。查士丁尼（Justinian）的法律书已是几个世纪前的事，而这个国家并没有变成化石。在罗马举行的加冕在西方是一个挑战，也是一件新事，而不是拯救一个空悬的宝座。本章不会为公元800年东方的统治者定年，因为那些年份没有确定；也不会用“帝位空缺”来解释这场争议。当时存在两个主张：一个古老，在东方；一个新兴，在西方。把后者称为“唯一的”帝国，仿佛前者已经退位，就是让一场法兰克典礼承担了它承担不起的意义。

利奥三世并不是一位中立的典礼司仪。他是一个政治人物，在罗马有敌人，也有理由想要一个保护者。他陷入危机的年份这里没有确定，因此不予补出。已确定的日期就是加冕本身。保护与合法性是双向的：国王得到了只有教皇能在罗马授予的称号，教皇得到了法兰克人的刀剑。这是政治，但还不是[[christendom/popes-and-kings]]中的叙任权之争，那场争端有它自己的年代。这一点已足以打破“皇冠纯粹从神学中降临”的图景。

:::theorem 800年的加冕是新的主张，而不是移交 {#thm-claim}
公元800年12月25日，利奥三世为查理曼加冕，创立了一个遭到君士坦丁堡异议的西方帝号。它没有终结东罗马帝国，也没有使查理曼成为全欧洲的皇帝。
:::
:::proof
证据在于典礼的地点，以及年表所记载的东方反应。帝冠在罗马授予，授予者是教皇，接受者是法兰克国王。而君士坦丁堡已有一位在位的皇帝，那是一个并未在公元476年终结的罗马国家。提出异议，正是一个仍然存在的竞争性主张的表现；倘若东方帝位已经中断，异议就无从谈起。能够推翻[[#thm-claim]]的，是君士坦丁堡承认这个帝号就是它自己被移交的帝位的证据，或者东方帝系早已断绝的证据。西方关于帝位空缺的说法并不是这样的证据，本章也不会为这种说法定年。这次加冕能够支持的是新帝号、教皇的角色和由此引发的争执；它不能支持一幅由一位皇帝统辖所有地区的欧洲地图，也不能支持[[after-rome/byzantium]]中那个国家的终结。
:::

## 43年后实际分割了什么

从公元800年到公元843年是43年。年表有意这样计数：843减800，而不是44。公元843年，《凡尔登条约》分割了法兰克人的遗产。洛泰尔一世、日耳曼人路易和秃头查理是公元800年受冕者的孙子。长子洛泰尔保留了帝号以及土地与权利的中部份额，路易取得东部份额，查理取得西部份额。这些份额是一组组统治权，而不是民族国家。生活在其中的人，是各位国王治下的法兰克人及其邻族，而不是现代法兰西共和国或德意志共和国的公民，条约也没有这样说。

:::theorem 凡尔登分割了一份遗产，并没有缔造两个民族 {#thm-verdun}
公元843年的《凡尔登条约》把法兰克人的遗产分给了洛泰尔一世、日耳曼人路易和秃头查理。它并没有缔造法国和德国。
:::
:::proof
证据在于这一行为的性质和当事人。三个孙子分割了土地、权利，以及由其中一人保留的帝号。[[#def-division]]就是这类文书的类型。缔造两个民族则属于另一类行为：需要一个民族、一个延续不断的法律人格，以及与后来国家相吻合的边界。凡尔登一样也没有提供。中部份额并不对应任何一个现代国家，这本身就表明，这份条约并不是在为那两个国家划界。此后家族内部又有过多次分割；本图谱没有确定它们的年份，也不会为了让民族叙事更顺畅而杜撰。能够推翻[[#thm-verdun]]的，是一份公元843年以现代国名、按现代边界建国的文本，而这样的文本并不存在。一本需要“诞辰”的后世教科书，或者史家能够追溯的西部和东部王系，都不能推翻这一论断。世系不等于建国。一个西部王国可以有后来的继承者，而凡尔登并不因此就是他们的出生证明。
:::

这个“诞辰”对谁有利？对那些希望法国和德国始于一个学生能够背诵的日期的课程有利。这个日期对民族叙事有用，作为对公元843年的描述却毫无用处。[[sources/time-and-names]]给出了一般性的警示：绰号和王位安排都是主张，一旦主张被当作无需证据的标签，就有人从中得利。在这里，得到的是一幅简单的地图；付出的代价，则是那个中部份额、那个并非民族的帝号，以及那三兄弟——他们是一家人，而不是两个民族的代表。

奥托一世于公元962年加冕称帝。这是另一次帝位主张，既不是公元800年同一场典礼的延续，也不是凡尔登条约的附录。从公元800年到公元962年，年份数字相差162；从公元843年到公元962年，相差119。本图谱没有确定凡尔登与奥托之间的诸位国王，因此不会补出他们的在位年代。可以比较的是行为的类型：一个人加冕称帝，但他不是查理曼，那一年也不是公元800年。奥托的圆点是图上最后一个事件。按传统定于公元988年的受洗和1054年的绝罚都在图外，必须在正文中讲授，否则就会被遗忘。

:::quiz
公元800年12月25日的加冕主张了什么？
- [ ] 东罗马帝国已经终结，帝号西移，填补了空缺
- [ ] 法国和德国在那一天诞生
- [x] 一个西方帝号，君士坦丁堡对此提出了异议
- [ ] 查理·马特成了皇帝
:::solution
利奥三世加冕的是查理曼，而不是马特，马特也从未称王。东方帝国依然存在，并对这个帝号提出异议，所以那并不是一把等人来坐的空椅子。“法国和德国的诞生”是附会在公元843年上的迷思，与加冕无关，而且即便放在公元843年也同样是迷思。[[#thm-claim]]才是大小合适的论断。
:::
:::

## 受洗不是人口普查，分裂不是一天之事

按传统定年，基辅的弗拉基米尔（Vladimir）于公元988年受洗。年表要求把这一年份看作罗斯（Rus'）皈依的传统标志，而不是信仰普查。“传统”的分量弱于一份特许状，又强于一个猜测：它是传统所提供的日期，我们也不假装本书保存着一本登记册。这一公开行为是一位统治者接受东方基督教，它具有政治和教会的性质。它没有说明公元988年基辅每个人信仰什么，也无法替编年史从未询问过的人作答。同样的限度也适用于[[after-rome/christianisation]]中公元380年的敕令，以及[[after-rome/successor-kingdoms]]中有争议的克洛维受洗。克洛维的受洗有两个候选年份，弗拉基米尔的受洗有一个传统年份，两者都不是对人心的统计。

关于1054年，一段话就够了，这里就是这一段。相互绝罚的当事人是教皇特使洪贝尔（Humbert）和君士坦丁堡牧首米海尔·凯鲁拉里乌斯（Michael Cerularius）。这些行为是真实的，但它们处在一场有关权威、礼仪和教义的更长期的争论之中。那一天并不是拉丁教会与希腊教会变成两个隔绝世界的日子，也不是任何民族的诞生。争论与交往在此前和此后都一直存在。教皇与王权的拉丁故事在[[christendom/popes-and-kings]]中继续。东罗马国家仍是[[after-rome/byzantium]]中的那个国家：距查士丁尼已有几个世纪，距1204年4月13日的洗劫和1453年5月29日的陷落也还有几个世纪。标志不是离婚判决书。

:::quiz
凡尔登在公元843年做了什么？
- [ ] 缔造了法兰西和德意志两个民族
- [ ] 由同一位皇帝重演了公元800年12月25日的典礼
- [x] 把法兰克人的遗产分给了三个孙子
- [ ] 它就是基辅弗拉基米尔的传统受洗
:::solution
三个孙子是洛泰尔一世、日耳曼人路易和秃头查理。他们分割了土地和权利，洛泰尔还得到了帝号。查理曼在公元800年受冕，并不是条约的当事人。弗拉基米尔的传统受洗在公元988年。“缔造两个现代民族”正是[[#thm-verdun]]所拒绝的读法；中部份额就是这种读法站不住的原因之一，因为它与后来任何一个民族都不对应。
:::
:::

## 论证与反论

为民族化读法辩护的人说：名称和王国总得有个起点，而凡尔登正是西法兰克与东法兰克两部分分道扬镳之处。后来的法国和德国并不是十九世纪凭空发明、毫无根基的东西。说条约“没有缔造”它们，听上去像是在否认此后存在任何连续性。这一辩护理应得到应有的区分。

某种连续性确实存在。有一个西部份额和一个东部份额，后来的政治可以从它们出发往下讲。[[#thm-verdun]]并不禁止这种叙述，它禁止的是一句特定的话：这份条约像出生证明确立一个法律人格那样，缔造了现代国家。当事人是兄弟，不是民族；边界不是现代边界；中部份额也没有一个单一的现代继承者，可以让这份条约成为一台恰好生产出两个国家的机器。要使那句民族化的话成立，需要一份我们并不拥有的文本。能够支持一种有限连续性的，则是一条统治与名号的链条，后续章节可以研究它，而不必把“护照”的签发日期往前挪。

第二种反驳认为，既然君士坦丁堡对这个帝号提出异议，这次加冕就是失败的，应当作为教皇的一厢情愿来讲授。但异议不等于失败。[[#thm-claim]]说这个帝号是新的、有争议的，而在另有一位皇帝存在时，一个真实的主张正应如此。一个无人理会的幻想，根本不会招致异议。东方的反对恰恰证明两个宫廷都认为这个帝号举足轻重，而不能证明查理曼实际上仍只是国王、教皇在唱独角戏。查理曼确实拥有这个西方帝号，只是东方拒绝承认它属于自己。

奥托的加冕是一个对照。如果公元800年是以一场连续不断的典礼缔造了“唯一的”西方帝国，那么公元962年就只是一个周年纪念。事实上，那是另一个人在162个年份数字之后重新取得这一称号。这段间隔——我们不会用未确定的在位年代去填补——证明这一时期的帝位主张是一次次的行为，反复出现而且相互竞争，而不是一簇不间断传递的火焰。

:::example 四十三年 {#ex-forty-three}
加冕在公元800年12月25日，凡尔登在公元843年。这段跨度是多少年？本图谱为什么不接受44？
:::solution
843减800是43，跨度是43年。年表直接给出了这个数字。若把两端都计入，就会得到44，而这不符合规则。[[after-rome/christianisation]]中从公元313年到公元380年的计算，用的也是同样的年份数字之差。

这个数字是一次加冕与一次遗产分割之间的距离。它不是某个民族存在的时长，也不会让那三个孙子变成公元800年的那位皇帝。
:::
:::

:::example 两次加冕 {#ex-two-crowns}
把公元800年12月25日与公元962年对照。两者属于哪一类行为？第二次加冕不能被称为什么？
:::solution
两者都是帝位加冕：查理曼由利奥三世加冕，奥托一世则在公元962年加冕。它们属于同一类主张。两者的年份数字相差162，因为962减800是162；从公元843年的凡尔登到奥托，相差119。

不能把奥托的加冕称为同一场典礼的延续、一个周年纪念，或法国和德国的开端。本章的图标出了这两次加冕和凡尔登，但没有标出其间的国王，因为本图谱没有确定他们的年代；而坐标轴的边缘本身也不是一个事件。
:::
:::

:::example 一句虚构的编年史 {#ex-invented}
下面这句话为示例而虚构。它不是史料。

“843年，诸王在凡尔登缔造了法国和德国，他们的誓词宣告了两个民族的诞生。”

这句话的前后两半各错在哪里？为什么不能通过写出那段誓词来修补后半句？
:::solution
前半句把一次遗产分割说成了两个现代民族的诞生。当事人是洛泰尔一世、日耳曼人路易和秃头查理，是分割土地与权利的三个孙子。[[#thm-verdun]]就是对此的纠正。在这句话里，中部份额并没有成为一个民族，这正是它站不住的原因之一。

后半句先杜撰了一段誓词，又杜撰了誓词的内容。本章不提供任何誓词的文本，即使是为了驳斥也不提供。修补就等于第二次杜撰。拒绝这句话，并不需要用另一段演说来代替：证据中没有这样的宣告，而宣告民族诞生也不是这份条约所做的事。
:::
:::

:::example 按传统定年的受洗 {#ex-vladimir}
按传统日期，基辅的弗拉基米尔于公元988年受洗。你可以推出什么？这一限度与克洛维案的限度有何不同？
:::solution
你可以推出一个传统标志：一位统治者公开接受了东方基督教，这与作为政治和教会故事的罗斯皈依相联系。你不能推出基辅的信仰普查，也不能把这个年份当作本书复制的特许状。“传统”二字表明的正是这个日期的可靠程度。

[[after-rome/successor-kingdoms]]中的克洛维受洗有两个有人论证的年份，即约公元496年和约公元508年，而且不能默默择一。弗拉基米尔则只有一个传统年份，而不是两个。两种限度都拒绝统计人心；区别只在于年代争议的形态不同，这并不意味着可以读出公元988年人们心中所想。
:::
:::

移动年份。15年的窗口无法同时容纳公元800年和843年：两者相距43年，窗口还不到它的一半。公元962年的奥托更远，在凡尔登之后119个年份数字。公元988年的传统受洗和1054年的绝罚没有圆点，因为它们在坐标轴之外。不在图上，并不意味着不在历史中。不要让三个圆点变成一场单一的帝国典礼，也不要让凡尔登的圆点变成一个民族的诞辰。

:::warning 两个民族的诞生
常见的说法是，凡尔登缔造了法国和德国。事实并非如此。公元843年，三个孙子分割了法兰克人的遗产。这些份额不是现代国家，中部份额不属于那两个民族中的任何一个，生活在其中的人也不是那两个民族的公民。一个后来的王国可以由某一份额演变而来，而条约并不因此成为出生证明。同样的过度解读，还把并非国王的宫相查理·马特安到了查理曼的帝冠之下，又把公元800年的加冕安到了一个空悬的东方宝座之上。每一句这样的话，都比它所依据的日期说得更多。
:::

## 通向何处

继承这些王国的拉丁世界中的领主制、地租和各种形式的不自由身份，见[[christendom/lords-and-peasants]]。教皇与国王围绕职位的争执——它与利奥三世的加冕并非同一场争执——见[[christendom/popes-and-kings]]。在公元800年之后继续存在、并对这一帝号提出异议的东方帝国，见[[after-rome/byzantium]]。那个“大陆获救”的传说想在查理曼加冕之前就为之画上句号的伊比利亚政权，见[[after-rome/islam-in-the-west]]。

:::summary
- 公元800年12月25日，利奥三世在罗马为查理曼加冕称帝。这一主张是一个新的西方帝号，君士坦丁堡对此提出异议。东方帝国并没有终结。
- 查理·马特不是那位皇帝，也不是国王。本图谱没有确定加洛林家族成员首次称王的年份，已确定的称帝日期是公元800年。
- 从公元800年到公元843年是43年。凡尔登把法兰克人的遗产分给了洛泰尔一世、日耳曼人路易和秃头查理，并没有缔造法国和德国。
- 奥托一世于公元962年加冕称帝。这是另一项主张，既不是公元800年的同一场典礼，也不是凡尔登条约的附录。
- 公元988年是基辅的弗拉基米尔受洗的传统日期。标志不等于信仰普查。
- 1054年洪贝尔与米海尔·凯鲁拉里乌斯的相互绝罚，是一场更长期分裂中的一个标志，既不是一天之内办完的离婚，也不是一次民族的诞生。
:::

## 习题

:::exercise 标准跨度 {level=1 check="43"}
加冕在公元800年，《凡尔登条约》在公元843年。这段跨度是多少年？（请输入年数。）
:::solution
843减800是43，年数是43。年表给出的正是这个数字，它是年份数字之差，而不是44。这段跨度把一次帝位主张与一次遗产分割隔开，并不衡量一个民族的寿命。
:::
:::

:::exercise 从凡尔登到奥托 {level=1 check="119"}
凡尔登在公元843年，奥托一世于公元962年加冕称帝。这两个年份数字之间相隔多少年？（请输入年数。）
:::solution
962减843是119，年数是119。奥托的加冕是后来的又一次帝位主张，既不是公元800年那场典礼的延续，也不是条约中的条款。本图谱没有确定这两个日期之间的诸位国王，因此不能用他们的在位年代来填充这个数字。
:::
:::

:::exercise 圣诞节那天谁做了什么 {level=1}
用三四句话说明：公元800年12月25日谁为谁加冕，获得的是什么称号，谁对它提出了异议。不要把东方的宝座说成空悬。
:::solution
教皇利奥三世在罗马为查理曼加冕称帝。这个称号是西方的帝位主张，在当时的情境下是新事物，而不是东罗马帝位的移交。君士坦丁堡之所以提出异议，是因为东方已经有一位皇帝。

这一异议证明，这个帝号对两个宫廷都很重要；它并不证明东方国家已在公元476年或公元800年终结。查理·马特也不是戴上帝冠的那个人。
:::
:::

:::exercise 这一主张能支撑多少 {level=2}
列出公元800年的加冕能够支持的内容，以及常被要求支持、它却无法支持的三件事。请利用君士坦丁堡和地图的限度来回答。
:::solution
它能够支持的是：公元800年12月25日的一次公开行为，一位教皇和一位法兰克国王，一个西方的皇帝称号，以及来自君士坦丁堡的异议。[[#thm-claim]]就是这份清单。

它不能支持东方帝国的终结、空悬的宝座或全欧洲的皇帝。君士坦丁堡的罗马国家依然存在，并对这一新事物提出异议。加冕也不是凡尔登，不是法国或德国的诞生。后来的宫廷传记不是当天的现场记录，答案中也不应出现任何誓词文本。
:::
:::

:::exercise 改写“诞辰” {level=2}
一块牌匾上写着：“843年：法国和德国的诞生。”请把它换成一句可以检验的话，写明三位继承人和这一行为的性质；再用两句话说明，为什么中部份额会给这块牌匾带来麻烦。
:::solution
可以这样替换：公元843年，《凡尔登条约》把法兰克人的遗产分给了洛泰尔一世、日耳曼人路易和秃头查理，帝号归洛泰尔所得的那一份。这一行为是遗产分割，而不是民族国家的建立。

中部份额并不对应任何一个现代国家。一份真正恰好催生两个民族的条约，就必须解释为什么还有第三组既不属于这方、也不属于那方的土地和权利。[[#thm-verdun]]正是利用这种错位，再加上当事人的家族性质，来反驳这块牌匾。
:::
:::

:::exercise 是标志，不是普查 {level=2}
应当如何表述公元988年？为什么基辅弗拉基米尔的传统受洗不能作为关于基辅每一个居民的证据？请简要地把这一限度与公元380年作比较。
:::solution
应当把它表述为弗拉基米尔受洗的传统日期，以及罗斯皈依的一个标志，而不是特许状，也不是普查。公开的事实是一位统治者接受了东方基督教。在这一层面上，政治和教会方面的后果可以是真实的。

这些后果并没有记录每个人的信仰。公元380年的敕令把基督教定为帝国的官方宗教，但仍然不是对人心的统计。两者相似的是限度，而不是制度：统治者的公共宗教不等于一项调查。克洛维案在年代上有所不同——有两个有人论证的年份，而不是一个传统年份——但在拒绝统计数字这一点上是一致的。
:::
:::

:::exercise 想要“诞辰”的博物馆 {level=3}
一段展厅说明写道，凡尔登是“法兰西民族和德意志民族登上历史舞台的时刻”，还说诸王立下了一段誓词，并用现代法语和德语引用了这段誓词。这一历史论断错在哪里？自己撰写誓词来修补它又错在哪里？请给出一句话的替代说明。
:::hint
把关于民族的时代错置与对演说的杜撰分开。本章禁止提供誓词的文本。三个名字加上“遗产”一词，就足以写出替代说明。不要为后来的任何家族条约定年。
:::
:::solution
这一历史论断把现代民族提前安到了一次家族析产之上。当事人是三个孙子——洛泰尔一世、日耳曼人路易和秃头查理——他们在公元843年分割了土地与权利。这些份额不是现代国家，中部份额则始终是对“恰好产生两个民族”这一说法的反驳。王国后来的延续并不是出生证明。[[#thm-verdun]]就是对此的纠正。

誓词是第二个错误。没有任何文本得到确定，而写出一段誓词——即使是作为怀疑性的戏仿——也是在替诸王编造言辞。展厅使用现代法语和德语，恰恰透露出这段演说出自我们自己之手。应当拒绝它，而不是用一段更高明的虚构来代替。

合适的说明是：公元843年，《凡尔登条约》把法兰克人的遗产分给了三个孙子，并没有缔造法国和德国。
:::
:::

:::exercise 为什么1054年只写一段 {level=3}
一位读者希望看到一部完整的拉丁教会与希腊教会分裂史，并且从1054年的相互绝罚开始、也在那里结束。请说明为什么在本章中只写一段是合适的篇幅，这些行为能支持什么、不能支持什么，并指出拉丁故事接下来的去向，但不要展开叙述。
:::hint
写出洪贝尔和米海尔·凯鲁拉里乌斯的名字，并保留“标志”一词。在这一年份的前后，东方国家都依然存在，而1204年和1453年远在本章的叙述范围之外。[[christendom/popes-and-kings]]是拉丁故事的延续，而不是对1054年的重述。
:::
:::solution
1054年，教皇特使洪贝尔与君士坦丁堡牧首米海尔·凯鲁拉里乌斯卷入了相互绝罚。这些行为是真实的，它们属于一场有关权威、礼仪和教义的更长期的争论。标志记录的是这些行为；离婚判决书则会宣称两个教会在那一天变成了互相隔绝的世界，而那场更长期的争论不允许这种说法。争论与交往在此前和此后都一直存在。

本章的主题是公元800年的法兰克帝位主张和公元843年的分割，奥托、弗拉基米尔和这个标志则是后来的界限。一部完整的教会史会把这些内容淹没，还会叙述不在本章任务范围内的年代。东罗马国家依然存在，距查士丁尼已有几个世纪，距1204年4月13日和1453年5月29日也还有几个世纪，所以1054年也不是这个国家的终结。

教皇与国王的拉丁故事在[[christendom/popes-and-kings]]中继续。点出这一章，就是指明方向。如果在这里讲述卡诺莎（Canossa）或任何后来的争执，就会打破“只写一段”的规则，也会侵占一门有自己证据的课程。
:::
