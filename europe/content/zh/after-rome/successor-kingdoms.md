为什么说“蛮族入侵”不足以概括西部帝国之后的各个王国？

这一说法把所有军队、所有定居和所有新国王都放到同一条斜线上：从外来者到空无一人的罗马西部。可日期并不落在这条线上。公元476年，奥多亚塞（Odoacer）废黜罗慕路斯·奥古斯都鲁斯（Romulus Augustulus），而东部帝国依然存在；朱利乌斯·尼波斯（Julius Nepos）死于公元480年。哥特人与法兰克人在罗马行省之内、在罗马的土地上建立王国，沿用罗马的税收，也常常任用罗马的行政人员。一位法兰克国王的受洗年份有争议：约公元496年和约公元508年两说都必须讲授。伦巴第人（Lombards）进入意大利通常定于公元568年，在查士丁尼（Justinian）公元527年至565年的统治之后，与五世纪的定居并非同一事件。把这一切概括为一次入侵，答案就已经预先选定了。

这一说法还夹带了两样东西，本章都不接受。一是种族替换，即一个新民族把一个行省清空；二是一种道德上的黑暗，本章不会把它当作自己的论断。战争与剥夺仍然属于政治史，但它们不会把罗马人的一句蔑称变成一个种族，也不会把公元476年变成一页空白。

## 从蔑称到时代名称

拉丁语 *barbari* 把某些人划在罗马人心目中文明言谈与举止的范围之外。它是蔑称，也是一个范畴；它不是一个民族的名称，也不是后世任何生物学意义上的种族。哥特人与法兰克人并不是顶着同一个名字的同一血统。罗马作家之所以用同一个轻蔑的词，是因为它能让持有武装的邻人显得不合法。很久以后，民族史学又拾起了这个蔑称：有人想要蛮族祖先作为开国者，有人想要蛮族毁灭者，好让纯粹的罗马死去，再让纯粹的民族随后诞生。两种用法都把这个蔑称当成了一份族群普查。

:::definition 蛮族 {#def-barbarian}
**蛮族**在本章中指罗马人对其文明自我形象之外各族群的蔑称。一旦被用作时代名称——“蛮族入侵”——它就把许多王国说成一股种族浪潮。它并不指称任何有史料记载的民族，本身也无法说明那些王国如何征税、如何审判。
:::

:::definition 继承王国 {#def-successor}
**继承王国**是在罗马行省内建立的君主国，依靠罗马的土地、罗马的税收，并常常依靠受过罗马训练的行政人员；其国王的权力并非仅仅来自旧有的帝位继承。它既不是一个已消失帝国的郡县，也不能证明行省人口已被替换。
:::

罗马作者从这一时代名称中得益，因为这个词把新国王们排除在罗马人唯一承认的合法性之外。教科书也从中得益，因为一个短语就能盖住一个世纪，省去洗劫、废黜、受洗与后来进入意大利之间的区别。可以检验的历史是政治史：许多武装集团本已身处帝国境内或边缘，它们为土地、地位和收入作战、讨价还价，然后用行省居民熟悉的手段统治他们。

[[#def-barbarian]]并不是说没有人越过边界。人在迁移，军队也在移动。我们反对的，是附加在迁移之上的一整套说法：一个种族、一个被清空的西部、罗马制度的中断。去掉这一套，剩下的是一句更朴素的话：武装集团在罗马行省之内夺取并分享权力，往往借助战争，然后通过罗马的手段征税和审判。

## 哥特人、法兰克人与罗马的统治机器

公元410年8月24日，阿拉里克（Alaric）率领的哥特军队攻入并洗劫罗马城。[[rome/later-empire]]和[[after-rome/christianisation]]从另一角度讲述了这一事件。它还不是一幅王国分布图。哥特人的各个集团后来确实在高卢、伊比利亚和意大利的罗马行省中进行统治。本图谱没有为这些王国分别确定建国年份，这里也不会杜撰。已经确定的，是[[#def-successor]]所指出的模式，以及框定这一模式的意大利政治日期：公元476年的废黜、公元480年尼波斯之死，以及很久之后、通常定于公元568年的伦巴第人进入意大利。

在公元476年与公元568年之间，哥特人在意大利的王权是政治史的一部分，本图谱没有为其起止确定年份。史料支持的是这一模式，而不是某段统治的年数：一位国王置身于罗马的地理环境之中，任用能够撰写罗马法律、用罗马式文书处理土地与税务的人。由受过罗马训练的官员为国王起草文书，与“林中民族凭空发明政府”的图景恰恰相反。这就是继承——正如列于课程参考文献中的克里斯·威克姆（Chris Wickham）的比较史为后罗马时代的西部所论证的那样：新统治者治下延续着旧有的财政与法律习惯。一本书不能代替一份特许状，但它提供了一个理由，让我们不必从零讲起。

法兰克人是另一个日期确实站得住的例子。他们在高卢的势力是克洛维（Clovis）登场的背景，也是他受洗皈依尼西亚派基督教的背景——自公元380年起，这一派就是帝国的官方宗教，详见[[after-rome/christianisation]]。许多哥特国王早已是基督徒，但其信仰形式与公元325年尼西亚会议划定的界线不符。因此，一位法兰克国王接受官方定义，是在政治上与尼西亚派主教以及广大的高卢-罗马民众结盟，而不是“日耳曼人”第一次接触宗教。它同样不是对每个法兰克人信仰的统计。挡住公元380年归信统计的那条限度，在这里同样适用。

:::quiz
为什么“蛮族入侵”不足以概括这些王国？
- [ ] 因为没有军队移动，也没有人被剥夺
- [x] 因为罗马人的一句蔑称被说成了一股种族浪潮，掩盖了那些利用罗马土地、税收并常常任用罗马行政人员的王国
- [ ] 因为公元476年在西部恢复了罗马共和国
- [ ] 因为在法律上，哥特人与法兰克人是同一个民族的两个名称
:::solution
军队和剥夺都是真实的，所以第一个选项不对。这个说法之所以不妥，另有原因：它把不同的王国捆成一个外来种族，略去了这些王国所使用的罗马统治机器。哥特人与法兰克人不是同一个民族；公元476年是一次废黜，而不是共和国的恢复。东部帝国在那一年之后继续存在。
:::
:::

## 两个候选年份，不可默默择一

史家手中没有一份同时代的登记册记载克洛维在哪一年受洗。主要的拉丁文叙事出自后来的图尔的格里高利（Gregory of Tours）。本图谱没有为他的史书确定成书年份。这部史书不是洗礼登记册，这里也不会把其中任何内容当作引文呈现。格里高利排列的是历次战争与这次受洗的相对先后。重新排列这些战争的史家，对具体年份看法不一：一种排法得出约公元496年；另一种得出约公元508年，那时克洛维在高卢的势力更大，他与南方主教的交往也属于这一时期。两说都有人论证过。在教科书里只取一说、隐去另一说，是本图谱不会做的。

争议在于年份。按照这份年表要求我们讲授的论证，争议并不在于法兰克国王是否与尼西亚派基督教结盟。要确定年份，需要一份载有该年份的同时代文书；要否定这次受洗作为事件的真实性，则需要证明后来的叙事连这次结盟本身都是杜撰的。在任何一项检验得到满足之前，我们能检验的只是那句较窄的话：一位法兰克国王曾公开接受尼西亚派洗礼，而年份尚无定论。从约公元496年到约公元508年，年份数字相差12。十二年足以推翻任何把这次受洗说成某场战役之确切起因的叙述，因为战役与受洗的先后无法确定。我们可以把这次受洗当作一次公开的宗教结盟来使用，却不能把它当作秒表。

:::theorem 克洛维的受洗没有确定的单一年份 {#thm-clovis}
克洛维受洗的年份有约公元496年和约公元508年两说。两者都不能作为确切日期来讲授，而这次受洗也不是对法兰克人信仰的统计。
:::
:::proof
证据在于论证的现状——年表把它标为有争议——以及史料的类型。叙事是后来写成的，不是载有年份的特许状。学者们重建书中所述各次战争的先后，得出了两个候选年份；本图谱没有确定那些战争的年份，因此也不会私下引入第三个日期来打破僵局。公开受洗皈依官方的尼西亚派基督教，符合公元380年之后主教与高卢-罗马城市的政治格局，但它并没有记录王国中每个人的想法。能够推翻[[#thm-clovis]]的，是一份确定某一年份的同时代文书，或者学界公认两种重建之一通不过另一种能通过的检验。在教科书中流行并不是这样的检验。能够推翻更宽论断——即这次结盟确曾发生——的，是证明后来的史书杜撰了这次受洗的证据。对年份的分歧并不是这样的证据。
:::

想要一个确定年份的读者，往往是在寻找一个原因。如果受洗在“早”，就可以讲成他崛起的秘诀；如果在“晚”，就可以讲成对既得胜利的点缀。这两种讲法都只有在假装年份已知时才说得通。[[#thm-clovis]]拒绝这种假装。无论取哪一年都成立的政治事实，是与官方教会的结盟；而必须依赖某个特定年份的军事叙事则站不住。

## 476年并没有使西部空无一人

公元476年奥多亚塞废黜罗慕路斯·奥古斯都鲁斯，是意大利统治者的一次真实更替。很久以后，它成了惯常所说的“西罗马帝国灭亡”。惯例并不等于事件本身。东部帝国依然存在。尼波斯死于公元480年，可见一个与之对立的西部帝位主张比那个著名的下午存续得更久：480减476是4。这两个年份都没有描述乡村被清空、人口被替换或税收终止。[[rome/later-empire]]和[[sources/argument]]有意把公元476年与东部的延续放在一起讲；本章再加上各个王国。此后几代人的政治史并不是“灭亡”的脚注，它就是历史本身。

:::theorem 476年的废黜没有使西部各行省空无一人 {#thm-empty}
公元476年奥多亚塞废黜罗慕路斯·奥古斯都鲁斯，并没有使西部失去罗马人、税收或政治生活。继承王国正是这种政治生活，而东部帝国依然存在。
:::
:::proof
证据在于废黜之后发生了什么，以及废黜本身是什么。它是在意大利除掉一位帝位主张者，而不是有记载的行省撤离。尼波斯直到公元480年才去世。哥特人和法兰克人在罗马的土地上继续统治，沿用罗马的财政与法律习惯。东部仍有皇帝，因此公元800年的西部加冕将受到君士坦丁堡的质疑，这一后来的事实见[[after-rome/carolingians]]。能够推翻[[#thm-empty]]的证据，应当表明各行省人口在公元476年作为民族被替换，或者罗马税收与法律实践普遍止于这次废黜。被焚的城市、被没收的地产、惊恐的编年史，是暴力的证据，而不是大陆空无一人的证据。地区差异很大。本图谱没有为罗马政府在不列颠的终结确定年份，而公元410年8月24日罗马遭洗劫也不是那个年份。不列颠不是意大利。这条论断针对的是已确定日期所支持的模式，而不是每一处山谷。
:::

伦巴第人进入意大利是一个较晚的例子，它使人无法把五世纪的情形照搬到六世纪。查士丁尼在位于公元527年至565年。无论他在西部的战争取得了什么成果——他的法律与都城属于[[after-rome/byzantium]]——他的统治都在公元565年结束。伦巴第人进入意大利的通常日期是公元568年。“通常”与有两个候选年份并存的受洗之争不同：它的意思是，学术惯例已足够稳定，可以作为标准日期讲授，但它仍是一种惯例，而不是我们手中的特许状。这并不允许把公元568年当作废黜罗慕路斯的同一股浪潮。两者的年份数字相差92，因为568减476是92；其间横亘着一段东罗马的统治。一种名为“蛮族入侵”、把公元476年到公元568年当作同一事件一路讲下来的概括，忽略了这段间隔。

:::quiz
哪一种说法与关于克洛维的证据相符？
- [ ] 他在公元496年受洗，另一说是抄写者的错误
- [ ] 他在公元508年受洗，较早的一说已被驳倒
- [x] 约公元496年和约公元508年都有人论证过，本图谱不作选择
- [ ] 一份同时代的登记册载明了年份，因此并无争议
:::solution
年表把这次受洗标为有争议，并列出两个年份。本章所用的证据中没有同时代的登记册，图尔的格里高利是后来的叙事者，他的书也不是特许状。只讲一个年份，正是本章要防止的默默择一。这里讲授的争议关乎一次尼西亚派洗礼的年份，并不否认法兰克王权曾与官方教会结盟。
:::
:::

## 论证与反论

对本章最有力的反驳认为，“入侵”才是诚实的说法：军队确实进入了罗马行省，确实有人被杀、被剥夺。一套讲定居与转型的温和词汇，把血迹藏到了文书的案头后面。如果非要在种族史诗与一个无人受伤的故事之间选择，史诗至少承认了战争。

这一反驳在战争问题上是对的，在种族问题上是错的。拒绝用“蛮族入侵”作概括，并不是说这些夺权都是和平的，也不是说每个行省家庭都保住了土地。[[#thm-empty]]说的是西部没有被清空，罗马的财政生活并没有普遍中断；它并没有说，身处反复争夺地区的农民是安全的。更好的说法把暴力保留在政治史之内：武装集团往往通过战争夺取权力，然后运转罗马的统治机器。要使种族化的概括成立，需要证明人口作为一个民族被替换；要使“空无一人的西部”成立，需要证明税收、耕作与法律在公元476年中断。恐惧的编年史提供不了这两样证据。它们提供的是恐惧，而我们不应把恐惧删去。

第二种反驳认为，有争议的受洗应该干脆略去。这未免太过省事。[[#thm-clovis]]把这次结盟保持在史料能够支撑的大小，并拒绝虚假的年份；略去它，就会掩盖我们本可以讲授的宗教政治。在两个候选年份之间另造一个年份，则是第三种杜撰，而不是史料。

彼得·布朗（Peter Brown）主张的漫长转型说列于课程参考文献中，它驳斥的是“某一年骤然陷入黑暗”的说法，却不允许把历次战争一笔抹平。这份日期档案依然参差不齐：一次废黜，一次受洗的两个候选年份，一次较晚的进入意大利。

:::example 相差十二年，没有定论 {#ex-twelve}
克洛维受洗有约公元496年和约公元508年两说。两者的年份数字相差多少？你仍然不能得出什么结论？（按本图谱计算跨度的规则。）
:::solution
508减496是12，相差12年。这不是把两端各加一的计数。

这个数字并不决定年份，它只表明两说相距多远。凡是需要让受洗引发某一特定战役的叙述都无法成立，因为十二年足以颠倒战役与洗礼的先后。这个数字也不是对法兰克人信仰的统计。
:::
:::

:::example 476年与568年的对照 {#ex-pair}
把罗慕路斯·奥古斯都鲁斯被废黜与伦巴第人进入意大利放在一起。哪些内容可以写进同一句话，哪些不可以？
:::solution
公元476年，奥多亚塞在意大利废黜罗慕路斯·奥古斯都鲁斯，而东部帝国依然存在。伦巴第人进入意大利通常定于公元568年，在查士丁尼公元527年至565年的统治之后。两者的年份数字相差92。

这两件事可以作为两次政治断裂并列，但不能当作同一次入侵。不能成立的说法是：公元568年是公元476年的最后余波，或者其中任何一年使行省空无一人。伦巴第人的通常定年比克洛维之争更为确定，但它仍然不是我们手中的特许状。两个日期之间哥特人在意大利的统治是真实的，本图谱没有确定其起止，因此这些起止不写进句子。
:::
:::

:::example 一句虚构的编年史 {#ex-invented}
下面这句话为示例而虚构。它不是史料。

“公元476年，蛮族各种族取代了罗马人，税收停止，黑暗时代开始了。”

要把其中任何一个分句提升为证据需要什么？哪些已确定的事实已经与它相抵触？
:::solution
每个分句各需不同类型的史料。人口替换需要关于民族的证据，而不是一份国王名单；税收终止需要中断的财政记录，而不是一则道德训诫；“黑暗时代”需要一个定义，而本章不把它当作自己的论断。这句虚构的话背后没有任何一种这样的史料。

与之相抵触的是：东部帝国在公元476年之后依然存在，尼波斯死于公元480年。继承王国利用罗马的土地和税收，也常常任用罗马的行政人员。法兰克人的受洗有约公元496年和约公元508年两说，这属于宗教政治，而不是一片空无的黑暗。通常定于公元568年的伦巴第人进入意大利是一次较晚的断裂，而不是某个下午在意大利开始的黑暗的序幕。
:::
:::

:::example 一位行政人员能说明什么 {#ex-admin}
意大利的一位国王任用受过罗马训练的人，撰写有关土地与税务的法律和文书。这能支持什么，不能支持什么？不要为这位国王杜撰在位年份。
:::solution
它支持[[#def-successor]]：一个位于罗马行省之内、沿用罗马法律与财政习惯的王国。这些人证明的是统治机器的延续，而不只是一桩奇闻。威克姆式的比较论断，即这些王国继承了罗马的做法，在这里有了具体的形态。

它不支持本图谱尚未确定的年份。奥多亚塞之后哥特人在意大利的王权是真实的，但本章没有给出它的年代。它也不支持种族替换，不能表明每个行省农民都表示认可。一封书吏的文书是政府存在的证据，而不是忠诚度的统计，也不能证明无人遭到剥夺。
:::
:::

:::warning 替换与黑暗时代
两个迷思常常被写进同一句话。第一个说蛮族各种族取代了罗马人；第二个说，黑暗时代随之开始，仿佛灯光随着罗慕路斯一同熄灭。“蛮族”是蔑称，不是种族。在罗马土地上建立、沿用罗马税收并常常任用罗马行政人员的王国，既不是人口的替换，也不是一片空旷的大陆。某些地区记载参差，对史家而言确是一个真实的难题，但这并不是道德上的黑暗，本章也不会把“黑暗时代”当作自己的论断。战争与剥夺留在叙述之中，种族地图则不留。
:::

:::history
公元476年，奥多亚塞废黜了罗慕路斯·奥古斯都鲁斯。与之对立的帝位主张者朱利乌斯·尼波斯死于公元480年，东部帝国依然存在。克洛维的受洗是另一类日期：约公元496年和约公元508年两说都有人论证过；伦巴第人进入意大利则通常定于公元568年。
:::

## 通向何处

在公元476年并未终止的罗马国家，是[[after-rome/byzantium]]的主题：查士丁尼的法律、尼卡暴动、圣索菲亚大教堂，以及一场本图谱不给出死亡总数的瘟疫。这些国王所继承的官方宗教，以及“公共仪式不等于人口统计”这一限度，见[[after-rome/christianisation]]。后来一个法兰克家族将把王权变为帝位主张，见[[after-rome/carolingians]]。至于这次废黜本身为何只是一个惯例，而不是罗马生活的终结，[[rome/later-empire]]中有论证。

:::summary
- “蛮族”是罗马人的蔑称，后来成了时代名称。它并不指称某一个种族，“蛮族入侵”掩盖了各不相同的政治史。
- 哥特人与法兰克人在罗马行省之内、在罗马土地上建立王国，沿用罗马的税收，并常常任用罗马的行政人员。这不是种族替换，也不意味着夺权过程是和平的。
- 克洛维的受洗年份有争议，约公元496年和约公元508年两说都有人论证过。不要默默择一，也不要把任何一年当作信仰统计。
- 公元476年罗慕路斯·奥古斯都鲁斯被废黜，但西部并没有因此空无一人。东部帝国依然存在，朱利乌斯·尼波斯死于公元480年。
- 伦巴第人进入意大利通常定于公元568年，在查士丁尼的统治之后。这是较晚的一例，与五世纪的定居不是同一事件。
- 本章不把“黑暗时代”当作自己的论断。证据参差并不是道德上的黑夜。
:::

## 习题

:::exercise 两说相距多远 {level=1 check="12"}
克洛维受洗有约公元496年和约公元508年两说。按本图谱的规则，这两个年份数字之间相隔多少年？（请输入年数。）
:::solution
用年份数字之差。508减496是12，年数是12。这个差值不能决定哪一说正确，也不是受洗的人数。
:::
:::

:::exercise 从废黜到伦巴第人 {level=1 check="92"}
罗慕路斯·奥古斯都鲁斯于公元476年被废黜，伦巴第人进入意大利通常定于公元568年。这段跨度是多少年？（请输入年数。）
:::solution
568减476是92，年数是92。跨度如此之大，正是不能把两件事当作同一次入侵的理由之一。查士丁尼公元527年至565年的统治就在其中。
:::
:::

:::exercise 这一蔑称起什么作用 {level=1}
用三四句话说明罗马人所说的“蛮族”指什么，以及这个词变成时代名称之后无法做到什么。
:::solution
罗马人用这个词指罗马人心目中文明言谈与举止范围之外的各族群。它是蔑称，也是一个范畴，而不是对血统的统计，也不是某个民族的名称。作为时代名称，“蛮族入侵”把哥特人、法兰克人以及后来的伦巴第人说成终结罗马生活的单一种族浪潮。

这个词无法描述这些王国所沿用的税收、土地和受过罗马训练的行政人员，也无法判断某次夺权是战斗、交易还是二者兼有。[[#def-barbarian]]让这一蔑称保持其本来面目，而不是把它提升为族群事实。
:::
:::

:::exercise 只印一个年份的教科书 {level=2}
一本教科书写道，克洛维于公元496年受洗，却不提公元508年。它对证据做了什么？应当用怎样的表述取代那个确定的年份？
:::solution
它把对一部后来叙事的一种重建，当成了登记册。图尔的格里高利排列了历次战争与一次受洗的先后，却没有给出同时代的年份，本图谱也没有为他的书确定成书年份。约公元496年和约公元508年两说都有人论证过。只印前者，正是[[#thm-clovis]]所禁止的默默择一。它还会引出一种因果叙述——把受洗说成某场战争的动力——而十二年的间隔无法支撑这种叙述。

可以这样替换：一位法兰克国王受洗皈依了尼西亚派基督教，即自公元380年起的官方形式；其年份有约公元496年和约公元508年两说，尚有争议。这句话不作选择，也不声称每个法兰克人都在那一天改变了信仰。
:::
:::

:::exercise 为什么568年不是又一个476年 {level=2}
请说明，为什么通常定于公元568年的伦巴第人进入意大利，不能讲成公元476年那次废黜的最后阶段。请利用查士丁尼的在位年代，但不要叙述他在西部的战役。
:::solution
两者的年份数字相差92。在这段跨度之内，查士丁尼在位于公元527年至565年；也就是说，在伦巴第人进入意大利之前，东罗马政府经历了一段漫长的统治，其中包括本章不叙述的西部征战。通常日期公元568年比公元565年晚3个年份数字。五世纪的一次废黜与六世纪后期的一次进入，是不同的政治时刻，涉及的军队也不同。

称公元568年为“通常”日期，本身就已是一种限定：它是标准日期，不是第二个克洛维之争，但它仍然不是摆在桌上的特许状。[[#thm-empty]]允许这两件事都伴有暴力，却不把它们说成以同一名称两度清空意大利的种族浪潮。
:::
:::

:::exercise “入侵”是不是诚实的说法 {level=2}
一位读者说：“既然有人被杀、土地被夺，就该叫入侵。你们那些温和的说法掩盖了暴力。”请在不否认暴力的前提下回应这一反驳，并说明什么证据能使种族化的概括成立。
:::solution
战争与剥夺属于这段历史。一个行省家庭可能失去土地；如果“定居”意味着无人受害，那它就是糟糕的概括。

种族化的概括额外断言：新来者是一个种族，他们替换了原有人口，罗马的税收与法律中断了。而证据是政治性的：这些王国建立在罗马土地上，沿用罗马的财政手段，并常常任用罗马的行政人员；与此同时，东部帝国依然存在，尼波斯活到公元480年。编年史中的恐惧证明的是恐惧。只有当民族——而不只是国王——取代了其他民族，才谈得上替换；只有当税收与法律普遍中断，才谈得上空无一人的西部。事实上它们并没有中断。
:::
:::

:::exercise 不列颠不是意大利 {level=3}
有人说：既然公元476年没有使意大利空无一人，它也就不可能改变不列颠的任何事情，因此那里的罗马政府未受触动。请只用本章已确定的内容回应这两个半句，不要为不列颠杜撰年份。
:::hint
把关于意大利的否定性论断（废黜并没有普遍清空各行省）与关于不列颠的肯定性论断分开；后者需要一个本图谱尚未确定的日期。公元410年8月24日的洗劫是对罗马的洗劫，不是一份不列颠的特许状。
:::
:::solution
[[#thm-empty]]说的是：这次废黜并没有普遍清空西部各行省，罗马的财政生活也没有因为罗慕路斯被除去而处处中断。这是一个关于模式的论断，意大利以及法兰克和哥特王国是我们能够定年的例子。它并不是说每个地区都未受触动，也不是说不列颠与意大利共用同一个政治时钟。

后半句之所以不成立，是因为本图谱没有为罗马政府在不列颠的终结确定年份，公元410年8月24日罗马遭洗劫也不能拿来充当这个年份。[[#thm-empty]]的论证中专门写明了地区差异，正是为了不让意大利白白充当不列颠的例证。要为不列颠的变化定年，需要一个已确定的年份。在此之前，对年份保持沉默，既不能证明什么都没有改变，也不能证明公元476年可以解释这座岛屿的历史。
:::
:::

:::exercise 折中的年份 {level=3}
一位同学提议“各让一步”，把克洛维的受洗定在约公元496年与约公元508年之间的中点，好让考试有一个确定的数字。请说明为什么这不是出路，再说明一个好的回答应当如何处理这两种说法以及法兰克人的信仰。
:::hint
想一想，中点年份会是哪一类事实：是史料，还是你自己算出的平均数？记住，这一争议使受洗无法被用作某场战役的原因。信仰是与年代不同的另一条限度。
:::
:::solution
中点年份是第三种杜撰。两说都不是可以取平均的测量值，本图谱也不会为了让减法更好看而制造年份。没有同时代的登记册可以依据，格里高利后来的叙事也不会因为被折中就成为登记册。十二年的间隔正是这场争议的历史事实；用编造的中点把它填平，等于假装秒表管用。

好的回答会同时列出约公元496年和约公元508年两说，拒绝选择，并保留那个无需选择的政治要点：一位法兰克国王与尼西亚派的官方基督教结盟。接着，它拒绝把受洗当作人口统计：这次受洗无法说明每个法兰克人信仰什么，正如公元380年的敕令无法说明帝国每个居民信仰什么。至于那种非得依赖两个年份中某一特定年份的战役叙述，仍然无法证实。
:::
