476年的废黜之后，罗马帝国在什么意义上延续了下去？

它作为一个国家延续了下去。君士坦丁堡的皇帝们没有把奥多亚塞（Odoacer）除去罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）当作罗马帝国的终结，那一年也没有让他们辞职。朱利乌斯·尼波斯（Julius Nepos）死于公元480年，仍在西部，而东部只是继续存在。现代的书把那个国家称为拜占庭（Byzantium），名字来自那座城市的更古老的名字。这个词是一个书架标签。它不是那个国家对自己使用的名字，也不是罗马已经悄悄变成别的东西的证据。在查士丁尼（Justinian）治下——他的统治为公元527年到565年——这个书架标签罩住一部拉丁文的罗马法、一座说希腊语的首都、一座于公元537年12月27日落成奉献的教堂、一场公元532年的暴动，以及一场在541年抵达的瘟疫。这些属于同一个统治。它们不是一个原因，也不是法兰克人的一个脚注。

"延续"这个说法不能意味着的东西是：什么都没有变；或者宫廷是一枚化石；或者宫廷八卦就是宪法。语言移动了。边疆移动了。一场瘟疫损害了征税与募兵的能力，其规模本图谱不以数字给出。这个论断是制度性的。仍然有一位皇帝，仍然有罗马法，仍然有一个财政与军事的国家，仍然有一座皇帝视为自己事务的教会。[[after-rome/successor-kingdoms]]是罗马土地上诸王国的西部模式。本章是那些国王没有替换掉的那个国家。

## 一个罗马的名字，一座希腊的首都

:::definition 拜占庭的 {#def-byzantine}
**拜占庭的**是现代对那个从君士坦丁堡统治的罗马国家使用的名字。它不是这个国家自己的法律名称——那个仍然是罗马的——也不是一个判定，说这个国家是相对于拉丁原本的一个希腊偏离。希腊语是首都的语言，并且日益也是政府的语言。它不是一份离开罗马的辞呈。
:::

:::definition 查士丁尼的编纂 {#def-codex}
**查士丁尼的编纂**是在查士丁尼治下颁布的那套法律书：公元529年的第一部《法典》（Codex），公元533年的《学说汇编》（Digest）与《法学阶梯》（Institutes），以及公元534年的第二部《法典》。《法典》收集皇帝的敕令；《学说汇编》摘录诸法学家，并给那些摘录以权威；《法学阶梯》是一部给学生的书。这套书是收集起来的罗马法学，不是一部新的宗教，也不是一部法兰克人的法典。
:::

到查士丁尼的统治时期，君士坦丁堡的街道以及宫廷的大部都说希腊语。那些大部头的法律书仍然以拉丁文颁布。那个组合正是[[#def-byzantine]]所要保护的政治事实。一个只遇见法兰克人的西部读者，可能以为"罗马性"已经搬去了高卢，而东部是一个说着错误语言的剩余。那些法律书说的不是这样。它们是一位罗马皇帝的工具，他能够命令诸法学家把一个庞大的传统归档进学生与法官能够使用的书。朱迪思·赫林（Judith Herrin）的讲述——在课程参考文献里点名——把同一个意思表述为一段漫长的生命，而不是一阵序曲：这个国家没有在等待成为别人历史里的一章。

把罗马这个名字拿走，谁受益？公元800年12月25日之后，一位教皇将在罗马为一位法兰克国王加冕为帝，而君士坦丁堡将争夺那个宣称。那次加冕是[[after-rome/carolingians]]。如果东部的帝国已经被改名改出了罗马，把它讲述成对一个空置头衔的补救就更容易。那个改名是后来的方便。在529年，宫廷里没有人需要它。这位皇帝正在制定罗马的法律，在那座罗马的首都——按传统的落成日期，自公元330年5月11日起，它就是君士坦丁（Constantine）的城市。

宫廷叙事不是体制。在宫廷附近的写作者们，普罗科匹乌斯（Procopius）就在其中，描述着诸派系、恐惧与皇帝的选择。它们是识文断字的观察者选择了写什么的证据。它们不是宪法。宪法，在本章将使用的唯一意义上，是那套比谣言活得更长的制度：税收、军队、法律，以及作为公共制度的教会。把一次统治化约为阴谋，就是下面的警告所点名的错误。一场暴动能显示首都有能力威胁一位皇帝。它显示不了八卦就是政府。

## 一次统治，按次序

次序就是论证。529年，第一部《法典》出现。532年，尼卡暴动（Nika riot）在君士坦丁堡爆发。533年，《学说汇编》与《法学阶梯》出现。534年，第二部《法典》修订那个汇编。537年12月27日，圣索菲亚大教堂（Hagia Sophia）落成奉献。541年，查士丁尼瘟疫抵达埃及并蔓延。565年，查士丁尼仍在位。谁把瘟疫说成暴动的原因，或者把那座教堂说成对瘟疫的赎罪，谁就把年份写反了。

尼卡暴动是首都的一场政治危机，不是肥皂剧的一集。赛马场的诸派系——它们的呼喊是这场暴动名字的由来——把一场抗议变成对查士丁尼的挑战。城市的一大片被烧毁，包括先前立在那座位置上的那座大教堂。皇帝的人马恢复控制时，许多人被杀。本图谱不给死亡总数，因为没有任何总数被锁定，而一个猜出来的人群是虚假的精确。叙事史料描述了一个皇帝对城市的掌控存有疑问的时刻，然后是暴力的恢复。我们不会把一位宫廷作者的戏剧当作政治体制。我们要说的是这场暴动显示的东西：首都能够吓到一位皇帝，而被恢复的政权有重建的资源。法律工程没有为灰烬停下。《学说汇编》与《法学阶梯》在533年跟进，第二部《法典》在534年。

圣索菲亚大教堂，于537年12月27日落成奉献，就是那座重建的教堂。537年与532年的年份数字之差是5。一座那样规模的建筑是劳动、材料与皇帝宗教政策的证据。它不是每一个居民都虔诚的证据，也不是西部已经陷入黑暗的一个象征。法兰克人不是那座穹顶被建造出来要羞辱的观众。观众是那座罗马的首都。

:::theorem 东部国家仍然是罗马的 {#thm-roman}
476年之后，帝国作为君士坦丁堡的一个罗马国家延续下去：一位皇帝，罗马法，税收，一座公共的教会。说希腊语没有使它成为一枚非罗马的化石，它也不是法兰克人的一个附属。
:::
:::proof
证据是制度的，并且有日期。查士丁尼在位为527年到565年，并在529年、533年与534年以拉丁文颁布[[#def-codex]]的编纂。首都是那座按传统日期于公元330年5月11日落成的城市。这个国家自称为罗马。一个现代的标签，拜占庭的，记录的是我们的书架，不是他们的退位。[[after-rome/successor-kingdoms]]里的西部诸王国是罗马土地上的继承者；它们不是这座首都的政府。会构成对[[#thm-roman]]之反驳的，是476年东部帝职的一个正式终结，或者一个新国家抛弃罗马法、改用另一种权威。那套编纂是指向反方向的证据。不构成反驳的，是说希腊语这件事，或者一位西部作家偏爱把这些罗马人叫作希腊人。那种偏爱是一场论战。它是竞争的证据——尤其当第二个帝位宣称在800年出现之后——它不是一个界定。
:::

:::theorem 法律、暴动、教堂与瘟疫不是一个原因 {#thm-order}
529年的第一部《法典》、532年的尼卡暴动、533年的《学说汇编》与《法学阶梯》、534年的第二部《法典》、537年12月27日圣索菲亚大教堂的落成奉献，以及541年的瘟疫，属于同一个统治。它们之中没有一个是他者的原因，而这场统治没有结束于541年。
:::
:::proof
证据是被锁定年份的次序。第一部法律书先于暴动。《学说汇编》、《法学阶梯》与第二部《法典》跟在暴动之后，所以法律工程穿过危机进行，没有被它中断，也不是由它引起。537年的落成奉献跟在先前那座教堂的被焚之后；年份数字之差是5，而暴动没有被锁定的月份，所以我们不假装计算天数。瘟疫在541年抵达，在落成奉献之后，而查士丁尼继续统治到565年；从瘟疫的抵达再到统治的终结，年份数字之差是24。会构成对[[#thm-order]]之反驳的，是一条把瘟疫定年在暴动之前的史料，或者一条在541年终结帝职的史料。一篇把灾难归咎于城市之罪的布道不是那条史料。年份之线拒绝的是单一原因。
:::

:::quiz
476年之后，罗马帝国在什么意义上延续了下去？
- [ ] 只作为一枚希腊的化石，没有法律也没有税收，直到法兰克人把它继承过去
- [x] 作为君士坦丁堡的一个国家，它保持罗马的名字，在查士丁尼治下颁布罗马法，并且在476年之后又活了几百年
- [ ] 它在537年12月27日落成奉献圣索菲亚大教堂时终结
- [ ] 它随奥多亚塞搬去了意大利，不再有一个东部的宫廷
:::solution
奥多亚塞的废黜没有关闭东部的宫廷，尼波斯之死在480年，也仍然是一个西部的故事。查士丁尼的拉丁文法律书，从529年到534年，是一个活着的国家里的罗马法学。圣索菲亚大教堂的落成奉献是一座建筑，不是灭绝。"化石"与"法兰克人的脚注"，正是[[#thm-roman]]拒绝的两种读法。
:::
:::

## 一场没有总数的瘟疫

541年，查士丁尼瘟疫抵达埃及，并蔓延过帝国以及更远处。你可以说那是一场灾难，可以说许多地方的劳动与税收变得更难维持。你不可以说死了多少人。没有任何总数被锁定，而世界的一个比例，或者帝国的一个比例，都会是发明。在[[after-rome/christianisation]]里挡住一个归信统计数字的同一条规则，在这里挡住一个死亡计数。"许多"是允许的。一个精确的死亡数字是不允许的。

这场统治提供了关于因果的限度。查士丁尼作为统治的终结死于565年，不是541年。到了800年，当一次西部的加冕必须从君士坦丁堡遭到争夺时，那个国家仍然在场，可供争论。它继续存在，直到别的课程教授的日期——本章对它不再多讲。说瘟疫终结了帝国的论断，被那些更晚的年份驳为假。说瘟疫什么也没有改变的论断也同样过头：募兵、收入与安置明显并非未受影响，而史家就规模争论，恰恰因为证据不支持一个数字。我们停在抵达、蔓延，与总数的缺席上。[[#thm-order]]已经禁止把541年变成532年的解释。

## 两句后来的话，仅此而已

君士坦丁堡的那个罗马国家在476年之后延续了几百年。1204年4月13日，一支十字军军队洗劫了君士坦丁堡，一座基督教城市；这是[[christendom/crusades]]教授的更晚的断裂，不是罗马帝位宣称的终结。1453年5月29日，城市陷落于奥斯曼苏丹穆罕默德二世（Mehmed II）之手，东罗马国家终结；[[crises/city-states]]承接这一点，而那不是在476年就已经完成的一场安静灭绝。

那两句话就是本章获准的全部后来的叙事。1204年的洗劫对这座城市的治理是一次真实的打击。它不是查士丁尼的危机，也不是一枚化石终于开裂。1453年的陷落是一个有日期、有暴力的终结，不是那个在五世纪就已经合上的故事的最后一页。从1204年到1453年，年份数字之差是249。从565年，查士丁尼统治的终结，到1204年，相差639。这些距离正是一门六世纪的课不可把这两个年份中的任何一个吸收进尼卡、法律诸书或瘟疫的理由。

:::quiz
关于查士丁尼瘟疫，你可以说什么？
- [ ] 541年的死亡总数正是引发尼卡暴动的东西
- [ ] 年表里有一个写明的死亡总数，课文应当引用它
- [x] 它在541年抵达并蔓延，而本图谱不给死亡总数
- [ ] 在它抵达的那一年终结了东罗马国家
:::solution
瘟疫在541年抵达埃及并蔓延。年表禁止死亡总数，所以任何一个分数都会是发明。尼卡暴动在532年，在瘟疫之前，而查士丁尼统治到565年。这个国家的终结，按本图谱使用的定年，是1453年5月29日，不是541年。
:::
:::

## 论证与反论

对[[#thm-roman]]最尖锐的反对是语言上的。如果宫廷说希腊语，如果后来的写作者说拜占庭的，那么把这个国家叫作罗马就是怀旧，是现代史家中喜爱延续之人支付的一句恭维。按照这个反对，真正的断裂是文化的。一座希腊语的宫廷是另一种文明，而罗马的正当继承者是法兰克人，或者教皇制。

这个反对把一种语言与一部宪法混为一谈。[[#def-byzantine]]正是为了把两者分开。529年到534年的拉丁文法律不是怀旧。那是一个政府在首都说着希腊语的同时，归档它自己的法律传统。这个国家对自己的名字仍然是罗马。偏爱说"希腊人"的西部写作者，常常是在为一个竞争的宣称辩护，尤其是800年之后。他们的形容词是一条关于竞争的史料。它对六世纪的国家不是一个好的界定。会使这个反对站得住的，是东部的帝职已经终结的证据，或者查士丁尼的法律书把自己呈现为一个新的非罗马民族的法律的证据。它们没有。

第二个反对朝另一个方向运行。如果国家延续，那么暴动、瘟疫与1204年的洗劫就是细节，延续就是一条从君士坦丁直到1453年的平滑丝带。[[#thm-order]]是统治之内的回答：丝带是不同种类事件的序列，图形上的线没有把它们变成一个原因。那两句后来的话是统治之外的回答。罗马宣称的延续，与一座被焚的首都、一场我们无法计数的瘟疫、一次十字军的洗劫和一个最后的征服，是可以兼容的。平滑不是"国家延续"的意思。

:::example 一次统治，按次序 {#ex-order}
把这些按时间先后排好，并说出这个次序禁止哪一种因果句子：第一部《法典》；尼卡暴动；《学说汇编》与《法学阶梯》；第二部《法典》；圣索菲亚大教堂的落成奉献；瘟疫。使用529、532、533、534、537与541年。
:::solution
次序是：529年的第一部《法典》，532年的尼卡暴动，533年的《学说汇编》与《法学阶梯》，534年的第二部《法典》，537年12月27日圣索菲亚大教堂的落成奉献，以及541年的瘟疫。

这个次序禁止"瘟疫引发了暴动"与"新教堂是对瘟疫的赎罪"。它也禁止把法律当作一部在某个平静年份颁布的单一的书。那个工程从529年延伸到534年，中间有一场暴动，而教堂跟在暴动之后，因为先前的那座教堂被烧毁了。一次统治，不是一个原因。
:::
:::

:::example 统治有多长 {#ex-reign}
查士丁尼在位为527年到565年。年份数字之差是多少？532年与541年落在那个跨度的什么位置？
:::solution
565减527是38。跨度是38年，按年份数字之差，不是把两端都算在内的计数。

532减527是5，所以尼卡暴动落在统治开始之后5个年份数字处。541减527是14，565减541是24，所以瘟疫在统治内部相当早处抵达，而统治在它之后继续。这两个事件都不是统治的边缘，哪一个也不可以被讲述为它的界定。
:::
:::

:::example 一句虚构的编年史句子 {#ex-invented}
下面这句话是虚构的。它不是史料。

"476年之后，罗马帝国只作为一枚希腊的化石存活，与欧洲无关，而查士丁尼的瘟疫、暴动与新教堂是一次单一的惩罚。"

哪些句子失败？哪些锁定的事实使它们失败？
:::solution
"只作为一枚希腊的化石"失败，因为这个国家在529年、533年与534年以拉丁文颁布罗马法，并且仍然自称罗马。"与欧洲无关"失败，因为地理包括这座首都，还因为800年的一个西部帝位宣称不得不从它那里遭到争夺。说希腊语不是一份离开罗马的辞呈。

"一次单一的惩罚"在[[#thm-order]]的次序面前失败。暴动在532年，落成奉献在537年12月27日，瘟疫在541年。一次惩罚不能引起先于它的事件。也没有任何死亡总数可供给这句话添加厚度，也不应添加一个。
:::
:::

:::example 两句不可扩写的句子 {#ex-later}
为什么本章对1204年与1453年各只允许一句话？如果对其中任何一个年份再加第三句话，它多半会在哪里做错？
:::solution
两个年份都是更晚的断裂，在别的课程里教授：1204年4月13日的十字军洗劫在[[christendom/crusades]]，1453年5月29日的奥斯曼征服在[[crises/city-states]]。本章的任务书是查士丁尼的国家，它在476年之后延续很久，并不由那些后来的打击来界定。各记一句话，是记录那些打击是真实的，也是记录它们不是这场统治。

第三句话会启动一段本章没有锁定细节的叙事：洗劫之后这座城市的治理，或者1453年的诸场战役。它还会招致一种教训——化石，或者拯救——而[[#thm-roman]]的存在就是为了挡住它。单是那些距离，1204减565，以及1453减1204，就足以把这两个年份留在查士丁尼的线之外。
:::
:::

移动年份。圆点是不同种类的事件，而一个高亮不是一个原因。《学说汇编》在图上；《法学阶梯》与同在533年颁布，却没有第二个圆点，而534年的第二部《法典》根本不在那条线上。这幅图是一场统治的样本，不是一份完整的清单。瘟疫坐在教堂之后。不要把次序倒过来读。

:::warning 化石，或者一部宫廷连续剧
讲述这个国家的两种习惯都错过了制度。一种叫它化石，一个相对于西部的希腊偏离，在476年之后精神已死，只有作为一件将被法兰克人或突厥人取代的遗物才有趣。另一种把这场统治讲述为宫廷阴谋，一部低语连续剧，其中法律诸书与税收是布景。查士丁尼的编纂、军队、财政体系与圣索菲亚大教堂才是内容。一场暴动显示首都有能力威胁一位皇帝。它显示不了八卦就是宪法。希腊语是首都的语言，不是从罗马的一跌。
:::

:::history
查士丁尼在位为527年到565年。他的第一部《法典》是529年，《学说汇编》与《法学阶梯》是533年，第二部《法典》是534年。圣索菲亚大教堂于537年12月27日落成奉献，在532年的尼卡暴动之后，而查士丁尼瘟疫在541年抵达。死亡总数不是那份记录的一部分。
:::

## 通向何处

东部的一次罗马人的失败——按通常的定年，是636年的雅尔穆克（Yarmouk）——是一个新政治体如何抵达地中海、后来又抵达伊比利亚的那段经过的一部分。那个问题在[[after-rome/islam-in-the-west]]。公元800年12月25日的西部帝号——这座首都对它加以争夺的那个——是[[after-rome/carolingians]]。1204年4月13日的洗劫在[[christendom/crusades]]。1453年5月29日这个国家的终结在[[crises/city-states]]。这些章节都没有把查士丁尼变成一个序曲。

:::summary
- 476年之后，罗马帝国作为君士坦丁堡的一个国家延续。"拜占庭的"是我们的名字，不是他们的名字。说希腊语不取消罗马的宣称。
- 查士丁尼在位为527年到565年。第一部《法典》是529年，《学说汇编》与《法学阶梯》是533年，第二部《法典》是534年。这是罗马法，不是法兰克人的一个脚注。
- 532年的尼卡暴动是首都的一场危机。许多人死了，而本图谱不写任何死亡总数。圣索菲亚大教堂于537年12月27日落成奉献。法律、暴动与教堂不是一个原因。
- 瘟疫在541年抵达并蔓延。没有死亡总数。在那一年之后，统治延续，国家也延续。
- 1204年4月13日，一支十字军军队洗劫了这座城市；1453年5月29日，国家在穆罕默德二世治下终结。每个事实在这里各记一句话。两者都不是476年一枚化石的安静死亡。
- 宫廷阴谋不是政治体制。税收、军队、法律与那座公共的教会才是。
:::

## 习题

:::exercise 统治的长度 {level=1 check="38"}
查士丁尼在位为527年到565年。按本图谱的规则，那个跨度是多少年？（请输入年数。）
:::solution
565减527是38。年数是38。这个计数是年份数字之差，不是把两端都算在内的总数，那会是39。这个跨度包含法律诸书、暴动、教堂与瘟疫，而它不被其中任何一个界定。
:::
:::

:::exercise 从暴动到落成奉献 {level=1 check="5"}
尼卡暴动在532年。圣索菲亚大教堂在537年落成奉献。那两个年份数字之间隔着多少年？（请输入年数。）
:::solution
537减532是5。年数是5。暴动没有被锁定的月份，而落成奉献在537年12月27日，所以数字5是一个年份之差，不是天数的计数。教堂跟在火灾之后。它不是暴动的原因。
:::
:::

:::exercise 他们的名字，与我们的名字 {level=1}
用三四句话说出那个国家自称什么，"拜占庭的"是用来干什么的，以及为什么说希腊语不是身份的改变。
:::solution
那个国家自称罗马，而它的皇帝们没有把476年当作自己的辞职。"拜占庭的"取自那座城市的更古老的名字，是现代的书架标签，用来让读者不把这个国家与那座更古老的城市罗马，或者与更晚的西部的帝位宣称混为一谈。

到查士丁尼的统治时期，希腊语是首都与政府大部分事务的语言。529年到534年的那些大部头的法律书仍然是拉丁文的。一种语言不是一部新的宪法，也不是对"西部"的一个偏离。[[#def-byzantine]]就是那个区分。
:::
:::

:::exercise 拉丁的书，希腊的街道 {level=2}
一位读者说，如果宫廷说希腊语，那些法律书就不可能是罗马的。请从编纂的各个日期出发回答，并说出什么会使这位读者是对的。
:::solution
529年的第一部《法典》、533年的《学说汇编》与《法学阶梯》、534年的第二部《法典》，在一位罗马皇帝之下收集罗马的敕令与罗马的法学家。这些书的语言是拉丁语。街道上的语言可以同时是希腊语。[[#thm-roman]]把那一对当作这个国家的正常形状，不是矛盾。

如果那些书抛弃了罗马的法律范畴、改用另一种权威，或者东部的帝职早已终结，这位读者就是对的。仅仅说希腊语，两样都不是。西部把罗马人叫作"希腊人"的一种习惯，是关于竞争的证据——尤其800年之后——不是对533年的一个描述。
:::
:::

:::exercise 541年没有总数 {level=2}
为什么本章拒绝给541年的瘟疫一个死亡总数？关于它在那场统治中的位置，仍然可以说什么？
:::solution
年表没有锁定任何总数。一个数字，或者帝国的一个分数，都会是发明，与一个归信统计数字是同一种虚假的精确。"许多"与"一场灾难"留在证据之内。对这种疾病的一份临床描述则不留在证据之内。

能够从年份说出的，是位置，不是死亡数字。瘟疫在537年的落成奉献之后、565年统治终结之前抵达。它不引起532年的暴动，也不终结这个国家。史家就规模争论，因为史料交不出一个数字。这场争论是一个停下来的理由，不是一个要填的空隙。
:::
:::

:::exercise 不是一个原因 {level=2}
只用529、532、533、534、537与541年的次序，反驳这句话："查士丁尼建造圣索菲亚大教堂，是为了赎那场引发了尼卡暴动的瘟疫的罪。"
:::solution
暴动在532年。落成奉献在537年12月27日，晚5个年份数字，在一场火灾之后。瘟疫在541年，在两者之后。一场瘟疫不能引发一场已经发生的暴动，而一座在瘟疫之前就落成奉献的教堂，不可能是对它的赎罪。法律诸书从另一边说明同一点：第一部《法典》在529年，在暴动之前，而《学说汇编》、《法学阶梯》与第二部《法典》跟在暴动之后，所以法律工作不是任一灾难造成的一种情绪。

[[#thm-order]]是这个回答的一般形式。一次统治装得下法律、一场暴动、一座教堂与一场瘟疫，而它们之中没有一个是他者的原因。
:::
:::

:::exercise 化石 {level=3}
一块博物馆图注写道："拜占庭：罗马的化石，一个对476年之后的欧洲无关紧要的希腊偏离。"写出这条图注所倚仗的论证，然后写出从法律、名字与更晚的帝国政治出发的反论。说出什么证据会迫使你接受"化石"。
:::hint
把现代的"拜占庭的"这个词与这个国家自己的名字分开。那套编纂有年份。800年的一次西部加冕从君士坦丁堡遭到争夺，这对一枚化石而言是一种奇怪的做法。不要把宫廷八卦当作回答。
:::
:::solution
这条图注的论证是：476年终结了真正的罗马；说希腊语标记着另一种较低级的文明；而凡是在君士坦丁堡留下来的东西，一个以拉丁西部为中心的欧洲故事都可以忽略。"化石"另外加上：这个残余不再行动。

反论就是[[#thm-roman]]。这个国家保有罗马的名字。查士丁尼529年、533年与534年的书，是一个活着的政府颁布的罗马法，不是陈列柜里的一件遗物。希腊语是首都的语言，不是离开罗马。800年，君士坦丁堡争夺一个新的西部帝号，这是一个仍然认为那个名号属于它自己的国家的行为。法兰克人是在[[after-rome/successor-kingdoms]]里的一段平行的历史，不是这座首都的主人。

只有当东部的帝职已经终结，或者那个政府已经停止征税、立法与作战，你才应当接受"化石"。口语的一种改变，以及一位现代史家的绰号，都不是那个证据。对宫廷故事的爱好也不是。
:::
:::

:::exercise 后来的年份能做什么 {level=3}
各用一句话、不再多加叙事，说明1204年4月13日与1453年5月29日对查士丁尼的国家"延续"这一论断做了什么。然后说出这两个年份都不被允许对476年或对541年意味着什么。
:::hint
这个论断是说那个罗马国家在476年之后又活了几百年，不是说它从不遭受断裂。一句话是一次对一座基督教城市的洗劫；另一句话是这个国家的终结。把查士丁尼的统治——结束于565年——与这两个年份隔开。
:::
:::solution
1204年4月13日，一支十字军军队洗劫了君士坦丁堡，一座基督教城市；这是对这个同样的罗马国家的一次更晚的打击，不是它的宣称的终结。1453年5月29日，穆罕默德二世夺取这座城市，东罗马国家终结。

这两个年份都不可以被挪回476年，那没有终结东部的帝国，也不可以被挪到541年，那是查士丁尼统治内部的一场瘟疫，不是这座城市的陷落。"国家延续"意味着罗马的宣称与那些制度延续过五世纪、延续过瘟疫。它不意味着历史是平滑的，也不为在本章内部讲述1204年或1453年的叙事发放许可证。那些叙事住在[[christendom/crusades]]与[[crises/city-states]]里。
:::
