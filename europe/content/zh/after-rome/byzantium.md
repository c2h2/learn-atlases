公元476年的废黜之后，罗马帝国在什么意义上延续了下来？

它作为一个国家延续了下来。君士坦丁堡的皇帝们并不认为奥多亚塞（Odoacer）除掉罗慕路斯·奥古斯都鲁斯（Romulus Augustulus）意味着罗马帝国的终结，这一年也没有使他们退位。朱利乌斯·尼波斯（Julius Nepos）于公元480年死去，那时他仍在西部，而东部照常延续。现代著作称这个国家为拜占庭（Byzantium），得名于这座城市更古老的名称。这个词只是一个图书分类标签，不是这个国家的自称，也不能证明罗马已经悄然变成了别的东西。在查士丁尼（Justinian）治下（公元527年至565年在位），这个标签之下有一部拉丁文的罗马法、一座说希腊语的首都、一座于公元537年12月27日落成祝圣的教堂、一场公元532年的暴动，以及一场公元541年传来的瘟疫。这些同属一朝，却并非出于同一原因，也不是法兰克人历史的脚注。

“延续”不能理解为一切照旧，不能理解为宫廷是一块化石，也不能理解为宫廷流言就是国家体制。语言变了，边界变了。一场瘟疫削弱了征税和募兵的能力，其规模本图谱不以数字给出。我们的论断是制度层面的：皇帝依然存在，罗马法依然存在，财政与军事国家依然存在，皇帝视为己任的教会也依然存在。[[after-rome/successor-kingdoms]]讲的是国王们在罗马土地上建国的西部模式；本章讲的则是这些国王并未取代的那个国家。

## 罗马的名号，希腊语的首都

:::definition 拜占庭 {#def-byzantine}
**拜占庭**是现代人对以君士坦丁堡为中心的罗马国家的称呼。它不是这个国家的正式法律名称——那仍然是“罗马”——也不意味着这个国家是对拉丁正统的一种希腊式偏离。希腊语是首都的语言，也日益成为政府的语言，但这并不意味着与罗马决裂。
:::

:::definition 查士丁尼法典编纂 {#def-codex}
**查士丁尼法典编纂**指查士丁尼治下颁布的一系列法律书：公元529年的第一部《法典》（Codex），公元533年的《学说汇编》（Digest）和《法学阶梯》（Institutes），以及公元534年的第二部《法典》。《法典》汇集皇帝敕令；《学说汇编》摘录历代法学家的论述，并赋予这些摘录以法律效力；《法学阶梯》是供学生使用的教科书。这套书是对罗马法学的汇编，既不是一种新宗教，也不是一部法兰克法典。
:::

到查士丁尼时代，君士坦丁堡的街头和宫廷的大部分人都说希腊语，而那几部重要的法律书仍以拉丁文颁布。这一组合正是[[#def-byzantine]]所要强调的政治事实。只了解法兰克人的西方读者可能会以为，“罗马”已经迁到了高卢，东部只是一个说着“错误”语言的残余。这些法律书表明情况并非如此：它们是一位罗马皇帝的工具，他能够命令法学家们把庞大的传统整理成学生和法官可以使用的书。课程参考文献中列出的朱迪思·赫林（Judith Herrin）的论述也表达了同样的观点：这是一段漫长的生命，而不是一段序曲；这个国家并不是在等待成为别人历史中的一章。

剥夺“罗马”之名，对谁有利？公元800年12月25日，一位教皇将在罗马为一位法兰克国王加冕称帝，而君士坦丁堡将对这一主张提出异议。这次加冕见[[after-rome/carolingians]]。如果东部帝国已经先被改名、从“罗马”中剔除，这次加冕就更容易被讲成是填补一个空缺的头衔。这种改名是后世图方便的做法，公元529年的宫廷里没有人需要它。当时，皇帝正在罗马的首都制定罗马法；按传统的落成日期，自公元330年5月11日起，这座城市就是君士坦丁（Constantine）之城。

宫廷叙事不等于国家体制。普罗科匹乌斯（Procopius）等接近宫廷的作者描述了派系、恐惧和皇帝的抉择。这些记述证明的是一位有学识的观察者选择写些什么，而不是国家的宪制。本章所说的宪制只有一种含义：比流言更持久的那套制度——税收、军队、法律，以及作为公共制度的教会。把这一朝化约为阴谋，正是下文警示所指出的错误。一场暴动可以表明首都有能力威胁皇帝，却不能表明流言就是政府。

## 一朝之事，依次排列

先后次序本身就是论证。公元529年，第一部《法典》问世；公元532年，尼卡暴动（Nika riot）在君士坦丁堡爆发；公元533年，《学说汇编》和《法学阶梯》问世；公元534年，第二部《法典》修订了这部汇编；公元537年12月27日，圣索菲亚大教堂（Hagia Sophia）落成祝圣；公元541年，查士丁尼瘟疫传到埃及并蔓延开来；公元565年，查士丁尼仍在位。谁把瘟疫说成暴动的原因，或把这座教堂说成对瘟疫的赎罪，谁就把年份弄颠倒了。

尼卡暴动是首都的一场政治危机，而不是一集肥皂剧。竞技场的派系——暴动之名即来自他们的呼喊——把一场抗议变成了对查士丁尼的挑战。城市大片被焚，包括原先矗立在那里的大教堂。皇帝的军队恢复秩序时，许多人被杀。本图谱不给出死亡总数，因为没有确定的数字，而猜测的人数只是虚假的精确。叙事史料描述了皇帝对城市的控制一度岌岌可危，随后以暴力恢复秩序的过程。我们不会把一位宫廷作家的戏剧化叙述当作政治体制，而只说明这场暴动所显示的事实：首都能够让皇帝感到恐惧，而恢复后的政权拥有重建的资源。法律工程并没有因灰烬而中断：《学说汇编》和《法学阶梯》于公元533年随即问世，第二部《法典》于公元534年问世。

公元537年12月27日落成祝圣的圣索菲亚大教堂，就是重建的那座教堂。公元537年与公元532年的年份数字相差5。如此规模的建筑证明了劳力、物料和皇帝的宗教政策，却不能证明每个居民都很虔诚，也不象征西部已陷入黑暗。这座穹顶并不是为了让法兰克人自惭形秽而建的，它的观众是这座罗马首都。

:::theorem 东部国家仍是罗马国家 {#thm-roman}
公元476年之后，帝国以君士坦丁堡为中心作为罗马国家延续下来：有皇帝，有罗马法，有税收，有公共教会。说希腊语并没有使它变成一块非罗马的化石，它也不是法兰克人的附庸。
:::
:::proof
证据是制度性的，而且有日期可考。查士丁尼于公元527年至565年在位，并于公元529年、533年和534年以拉丁文颁布了[[#def-codex]]中的法律书。首都就是按传统日期于公元330年5月11日落成的那座城市。这个国家自称罗马。“拜占庭”这一现代标签记录的是我们的分类方式，而不是他们的退位。[[after-rome/successor-kingdoms]]中的西部王国是罗马土地上的继承者，而不是这座首都的政府。能够推翻[[#thm-roman]]的，是东部的帝位在公元476年被正式废除，或者出现一个抛弃罗马法、改用另一种权威的新国家。法典编纂恰恰是相反方向的证据。说希腊语，或者西方作家喜欢把这些罗马人称为“希腊人”，都不能推翻这一论断。这种偏好是论战性的；它是竞争关系的证据——尤其是在公元800年出现第二个帝位主张之后——而不是一个定义。
:::

:::theorem 法律、暴动、教堂与瘟疫并非出于同一原因 {#thm-order}
公元529年的第一部《法典》、公元532年的尼卡暴动、公元533年的《学说汇编》与《法学阶梯》、公元534年的第二部《法典》、公元537年12月27日圣索菲亚大教堂的落成祝圣，以及公元541年的瘟疫，都属于同一朝代。其中任何一件都不是其他各件的原因，而这一朝也并没有在公元541年结束。
:::
:::proof
证据就是这些确定年份的先后次序。第一部法律书早于暴动；《学说汇编》、《法学阶梯》和第二部《法典》都在暴动之后，可见法律工程贯穿了这场危机，既没有因它而中止，也不是由它引起的。公元537年的落成祝圣在旧教堂被焚之后，两者的年份数字相差5；暴动的月份无法确定，所以我们不假装能算出天数。瘟疫于公元541年传来，在落成祝圣之后；查士丁尼则一直在位到公元565年，从瘟疫传来到这一朝结束，年份数字相差24。能够推翻[[#thm-order]]的，是一份把瘟疫定在暴动之前的史料，或者一份记载帝位在公元541年终结的史料。一篇把灾难归咎于城中罪孽的布道并不是这样的史料。这条年份之线所拒绝的，正是单一原因。
:::

:::quiz
公元476年之后，罗马帝国在什么意义上延续了下来？
- [ ] 仅作为一块希腊化石存在，没有法律，也没有税收，直到被法兰克人继承
- [x] 作为以君士坦丁堡为中心的国家，它保留了罗马之名，在查士丁尼治下颁布罗马法，并在公元476年之后又存续了几个世纪
- [ ] 它在公元537年12月27日圣索菲亚大教堂落成祝圣时终结
- [ ] 它随奥多亚塞迁到了意大利，不再有东部宫廷
:::solution
奥多亚塞的废黜并没有终结东部宫廷，公元480年尼波斯之死也仍属西部的故事。查士丁尼在公元529年至534年间颁布的拉丁文法律书，是一个仍然运转的国家中的罗马法学。圣索菲亚大教堂的落成祝圣是一座建筑的完工，而不是一次灭亡。“化石”和“法兰克人的脚注”正是[[#thm-roman]]所拒绝的两种读法。
:::
:::

## 没有死亡总数的瘟疫

公元541年，查士丁尼瘟疫传到埃及，并蔓延至整个帝国乃至更远的地方。你可以说这是一场灾难，也可以说许多地方的劳动力和税收变得更难维持；但你不能说死了多少人。没有确定的总数，无论说占世界人口还是帝国人口的多少比例，都是杜撰。在[[after-rome/christianisation]]中挡住归信统计的那条规则，在这里同样挡住死亡统计。可以说“许多”，不可以给出精确的死亡人数。

这一朝的年代为因果推断划定了界限。查士丁尼的统治结束于公元565年，而不是公元541年。到公元800年，当君士坦丁堡必须对西部的一次加冕提出异议时，这个国家依然存在，依然是争论的一方。它一直延续到其他课程所讲的年代，本章不再展开叙述。“瘟疫终结了帝国”这一论断，被那些更晚的年份证伪。“瘟疫什么都没改变”的论断同样过头：募兵、财政收入和人口分布显然并非不受影响，史家之所以争论其规模，正是因为证据无法支持一个确定的数字。我们只讲瘟疫的传入、蔓延，以及死亡总数的缺失。[[#thm-order]]已经禁止用公元541年来解释公元532年。

## 后来的事，只说两句

君士坦丁堡的罗马国家在公元476年之后又延续了几个世纪。1204年4月13日，一支十字军洗劫了君士坦丁堡这座基督教城市；这是后来的一次断裂，见[[christendom/crusades]]，但它并不是罗马帝位主张的终结。1453年5月29日，这座城市被奥斯曼苏丹穆罕默德二世（Mehmed II）攻陷，东罗马国家灭亡，详见[[crises/city-states]]；这并不是一场早在公元476年就已悄然完成的消亡。

这两句话就是本章所允许的全部后续叙述。1204年的洗劫对这座城市的统治是一次实实在在的打击，但它不是查士丁尼时代的危机，也不是一块化石终于碎裂。1453年的陷落是一个有确切日期、伴随暴力的终结，而不是一个早在五世纪就已结束的故事的最后一页。从1204年到1453年，年份数字相差249；从查士丁尼统治结束的公元565年到1204年，相差639。正是这些距离，使一堂讲六世纪的课不能把这两个年份中的任何一个并入尼卡暴动、法律书或瘟疫之中。

:::quiz
关于查士丁尼瘟疫，你可以说什么？
- [ ] 公元541年的死亡总数引发了尼卡暴动
- [ ] 年表载有它的死亡总数，课文应当引用
- [x] 它于公元541年传来并蔓延，本图谱不给出死亡总数
- [ ] 它在传来的当年就终结了东罗马国家
:::solution
瘟疫于公元541年传到埃及并蔓延开来。年表不允许给出死亡总数，因此任何比例都是杜撰。尼卡暴动发生在公元532年，早于瘟疫；查士丁尼则在位到公元565年。按本图谱采用的定年，这个国家的终结在1453年5月29日，而不是公元541年。
:::
:::

## 论证与反论

对[[#thm-roman]]最尖锐的反驳来自语言：既然宫廷说希腊语，后来的作者又称之为“拜占庭”，那么把这个国家叫作罗马，就只是怀旧，是喜欢延续性的现代史家的一句恭维。按照这种反驳，真正的断裂在文化上：说希腊语的宫廷属于另一种文明，罗马真正的继承者是法兰克人，或是教廷。

这一反驳把语言与宪制混为一谈。[[#def-byzantine]]正是要把二者区分开来。公元529年至534年的拉丁文法律并不是怀旧，而是一个政府在首都通行希腊语的同时，整理它自己的法律传统。这个国家的自称始终是罗马。喜欢称之为“希腊人”的西方作者，往往是在为一个与之竞争的主张辩护，尤其是在公元800年之后。他们使用的形容词是研究这种竞争的史料，却不是对六世纪这个国家的恰当定义。要使这一反驳站得住，需要证明东部帝位已经终结，或者查士丁尼的法律书自称是某个新的非罗马民族的法律。事实并非如此。

第二种反驳来自相反的方向：如果国家一直延续，那么暴动、瘟疫和1204年的洗劫就只是细枝末节，延续性就是一条从君士坦丁一直延伸到1453年的平滑丝带。在这一朝之内，[[#thm-order]]就是回答：这条丝带由不同类型的事件依次构成，图上的连线并没有把它们变成同一个原因。在这一朝之外，那两句后续叙述就是回答：罗马帝位主张的延续，与首都被焚、一场无法统计的瘟疫、十字军的洗劫和最终的征服完全可以并存。“国家延续”的意思并不是一帆风顺。

:::example 一朝之事，依次排列 {#ex-order}
把下列事项按时间先后排列，并指出这一次序排除了哪种因果说法：第一部《法典》；尼卡暴动；《学说汇编》与《法学阶梯》；第二部《法典》；圣索菲亚大教堂落成祝圣；瘟疫。请使用公元529年、532年、533年、534年、537年和541年这些年份。
:::solution
次序是：公元529年的第一部《法典》，公元532年的尼卡暴动，公元533年的《学说汇编》和《法学阶梯》，公元534年的第二部《法典》，公元537年12月27日圣索菲亚大教堂落成祝圣，以及公元541年的瘟疫。

这一次序排除了“瘟疫引发了暴动”和“新教堂是为瘟疫赎罪”的说法，也排除了把法律当作某个太平年份颁布的单独一本书的看法。这项工程从公元529年持续到公元534年，中间夹着一场暴动；教堂之所以在暴动之后，是因为旧教堂被烧毁了。同属一朝，并非同出一因。
:::
:::

:::example 这一朝有多长 {#ex-reign}
查士丁尼于公元527年至565年在位。年份数字之差是多少？公元532年和公元541年落在这段跨度中的什么位置？
:::solution
565减527是38。按年份数字之差计算，这段跨度是38年，而不是把两端都计入的计数。

532减527是5，所以尼卡暴动发生在这一朝开始后的第5个年份数字处。541减527是14，565减541是24，所以瘟疫是在这一朝中段传来的，此后统治仍在继续。这两件事都不在这一朝的起止边缘，也都不能被当作这一朝的定义。
:::
:::

:::example 一句虚构的编年史 {#ex-invented}
下面这句话为示例而虚构。它不是史料。

“476年之后，罗马帝国只作为一块希腊化石残存下来，与欧洲毫不相干；查士丁尼时代的瘟疫、暴动和新教堂是同一场天谴。”

哪些分句站不住？是哪些已确定的事实使它们站不住？
:::solution
“只作为一块希腊化石”站不住，因为这个国家在公元529年、533年和534年以拉丁文颁布罗马法，并且仍然自称罗马。“与欧洲毫不相干”站不住，因为这一地理范围本身就包括这座首都，而且公元800年西部的帝位主张还必须面对来自这里的异议。说希腊语并不意味着与罗马决裂。

“同一场天谴”违背了[[#thm-order]]中的次序。暴动在公元532年，落成祝圣在公元537年12月27日，瘟疫在公元541年。惩罚不可能引起发生在它之前的事件。没有任何死亡总数可以为这句话增添分量，也不应添加。
:::
:::

:::example 不可扩写的两句话 {#ex-later}
为什么本章对1204年和1453年各只允许写一句话？如果再为其中任何一年添上第三句，最可能犯什么错误？
:::solution
这两个年份都是后来的断裂，在其他课程中讲授：1204年4月13日十字军的洗劫见[[christendom/crusades]]，1453年5月29日奥斯曼的征服见[[crises/city-states]]。本章的任务是讲查士丁尼的国家；它在公元476年之后又延续了很久，并不由这些后来的打击来定义。各写一句，是为了记录这些打击确有其事，同时表明它们不属于这一朝。

第三句话就会开启一段本章并未确定细节的叙述：洗劫之后这座城市的统治，或者1453年的各次战役。它还容易引出一种道德寓意——“化石”或“拯救”——而[[#thm-roman]]正是为了阻止这种寓意。仅凭两段距离，即1204减565和1453减1204，就足以让这两个年份不落在查士丁尼的时间线上。
:::
:::

:::warning 化石，还是宫廷连续剧
讲述这个国家的两种惯常方式都忽略了制度。一种称之为化石，是相对于西方的一种希腊式偏离，公元476年之后精神上已经死亡，只有作为将被法兰克人或突厥人取代的遗物才有意思。另一种把这一朝讲成宫廷阴谋，一部窃窃私语的连续剧，法律书和税收只是布景。其实，查士丁尼的法典编纂、军队、财政体系和圣索菲亚大教堂才是内容本身。一场暴动表明首都有能力威胁皇帝，却不表明流言就是宪制。希腊语是首都的语言，并不意味着从罗马跌落。
:::

:::history
查士丁尼于公元527年至565年在位。他的第一部《法典》在公元529年，《学说汇编》和《法学阶梯》在公元533年，第二部《法典》在公元534年。圣索菲亚大教堂于公元537年12月27日落成祝圣，在公元532年的尼卡暴动之后；查士丁尼瘟疫于公元541年传来。这份记录中没有死亡总数。
:::

## 通向何处

东部的一次罗马战败——按通常的定年，是公元636年的雅尔穆克（Yarmouk）之战——是一个新政权到达地中海、后来又到达伊比利亚的过程的一部分。这一问题见[[after-rome/islam-in-the-west]]。公元800年12月25日的西部帝号——这座首都对此提出异议——见[[after-rome/carolingians]]。1204年4月13日的洗劫见[[christendom/crusades]]。1453年5月29日这个国家的终结见[[crises/city-states]]。这些章节都没有把查士丁尼当作序曲。

:::summary
- 公元476年之后，罗马帝国作为以君士坦丁堡为中心的国家延续下来。“拜占庭”是我们的叫法，不是他们的自称。说希腊语并不取消罗马的名分。
- 查士丁尼于公元527年至565年在位。第一部《法典》在公元529年，《学说汇编》和《法学阶梯》在公元533年，第二部《法典》在公元534年。这是罗马法，不是法兰克人历史的脚注。
- 公元532年的尼卡暴动是首都的一场危机。许多人死去，本图谱不给出死亡总数。圣索菲亚大教堂于公元537年12月27日落成祝圣。法律、暴动与教堂并非出于同一原因。
- 瘟疫于公元541年传来并蔓延，没有死亡总数。这一年之后，这一朝和这个国家都在继续。
- 1204年4月13日，十字军洗劫了这座城市；1453年5月29日，国家在穆罕默德二世手中灭亡。这里对每件事只写一句。两者都不是一块化石在公元476年的悄然死亡。
- 宫廷阴谋不是政治体制。税收、军队、法律和公共教会才是。
:::

## 习题

:::exercise 这一朝的长度 {level=1 check="38"}
查士丁尼于公元527年至565年在位。按本图谱的规则，这段跨度是多少年？（请输入年数。）
:::solution
565减527是38，年数是38。这一计数是年份数字之差，而不是把两端都计入的总数（那样会是39）。这段跨度包含了法律书、暴动、教堂和瘟疫，但不由其中任何一件来定义。
:::
:::

:::exercise 从暴动到落成祝圣 {level=1 check="5"}
尼卡暴动在公元532年，圣索菲亚大教堂于公元537年落成祝圣。这两个年份数字之间相隔多少年？（请输入年数。）
:::solution
537减532是5，年数是5。暴动的月份无法确定，而落成祝圣在公元537年12月27日，所以5是年份之差，而不是天数。教堂建于大火之后，不是暴动的原因。
:::
:::

:::exercise 他们的自称与我们的叫法 {level=1}
用三四句话说明这个国家如何自称，“拜占庭”这个叫法有什么用，以及为什么说希腊语并不意味着身份的改变。
:::solution
这个国家自称罗马，它的皇帝们也不认为公元476年意味着自己退位。“拜占庭”取自这座城市更古老的名称，是一个现代的分类标签，用来让读者不把这个国家与更古老的罗马城或后来西部的帝位主张相混淆。

到查士丁尼时代，希腊语已是首都和大部分政务所用的语言，但公元529年至534年间那几部重要的法律书仍用拉丁文写成。语言不等于新的宪制，也不是对“西方”的偏离。[[#def-byzantine]]讲的正是这一区分。
:::
:::

:::exercise 拉丁文的书，希腊语的街道 {level=2}
一位读者说，既然宫廷说希腊语，这些法律书就不可能是罗马的。请根据法典编纂的年代作答，并说明在什么情况下这位读者是对的。
:::solution
公元529年的第一部《法典》、公元533年的《学说汇编》和《法学阶梯》，以及公元534年的第二部《法典》，都是在一位罗马皇帝主持下汇编罗马敕令和罗马法学家的论述。这些书用的是拉丁文，而街头的语言同时可以是希腊语。[[#thm-roman]]把这两者并存视为这个国家的常态，而不是矛盾。

如果这些书抛弃了罗马的法律范畴而改用另一种权威，或者东部的帝位早已终结，这位读者就是对的。仅仅说希腊语，并不会导致其中任何一种情况。西方习惯把这些罗马人称为“希腊人”，这是竞争关系的证据——尤其是在公元800年之后——而不是对公元533年的描述。
:::
:::

:::exercise 公元541年没有总数 {level=2}
为什么本章拒绝给出公元541年瘟疫的死亡总数？关于它在这一朝中的位置，仍然可以说些什么？
:::solution
年表没有确定任何总数。给出一个数字，或者占帝国人口的某个比例，都是杜撰，与归信统计一样是虚假的精确。“许多”和“一场灾难”都在证据范围之内；对这种疾病的临床描述则不在。

从年份中能说的是位置，而不是死亡人数。瘟疫在公元537年落成祝圣之后、公元565年这一朝结束之前传来。它没有引起公元532年的暴动，也没有终结这个国家。史家之所以争论其规模，是因为史料给不出一个确定的数字。这一争论提醒我们就此止步，而不是留下一个有待填补的空白。
:::
:::

:::exercise 并非同出一因 {level=2}
仅根据公元529年、532年、533年、534年、537年和541年的先后次序，反驳这句话：“查士丁尼建造圣索菲亚大教堂，是为了替引发尼卡暴动的那场瘟疫赎罪。”
:::solution
暴动在公元532年。落成祝圣在公元537年12月27日，晚了5个年份数字，是在一场大火之后。瘟疫在公元541年，晚于前两者。瘟疫不可能引发一场早已发生的暴动，一座在瘟疫之前就已落成祝圣的教堂也不可能是为瘟疫赎罪。法律书从另一方面说明了同一点：第一部《法典》在公元529年，早于暴动；《学说汇编》、《法学阶梯》和第二部《法典》都在暴动之后，所以法律工作并不是这两场灾难中任何一场所激起的一时情绪。

[[#thm-order]]是这一回答的一般形式。同一朝代可以容纳法律、暴动、教堂和瘟疫，而其中任何一件都不是其他各件的原因。
:::
:::

:::exercise 化石之说 {level=3}
一块博物馆展板写道：“拜占庭：罗马的化石，一种希腊式的偏离，对476年之后的欧洲无足轻重。”请写出这块展板所依赖的论证，再从法律、名号和后来的帝国政治出发写出反论，并说明什么证据会迫使你接受“化石”之说。
:::hint
把现代的“拜占庭”一词与这个国家的自称区分开来。法典编纂有确切年份。公元800年西部的一次加冕遭到君士坦丁堡的异议——对一块化石来说，这可是件怪事。不要拿宫廷流言当作回答。
:::
:::solution
展板的论证是：公元476年终结了真正的罗马；说希腊语标志着另一种、而且较为低级的文明；一部以拉丁西方为中心的欧洲史，可以无视君士坦丁堡残存下来的一切。“化石”一词还额外暗示：这一残余已不再有所作为。

反论就是[[#thm-roman]]。这个国家保留着罗马之名。查士丁尼在公元529年、533年和534年颁布的法律书，是一个仍在运转的政府所颁布的罗马法，而不是陈列柜里的遗物。希腊语是首都的语言，而不是与罗马的决裂。公元800年，君士坦丁堡对一个新的西部帝号提出异议，这正是一个仍然认为这一名号属于自己的国家的做法。法兰克人是[[after-rome/successor-kingdoms]]中的一段平行历史，而不是这座首都的主人。

只有当东部帝位已经终结，或者这个政府已经不再征税、立法和作战时，你才应接受“化石”之说。口语的变化和现代史家起的绰号都不是这样的证据，对宫廷故事的偏爱更不是。
:::
:::

:::exercise 后来的年份能说明什么 {level=3}
请各用一句话、不再展开叙述，说明1204年4月13日和1453年5月29日对“查士丁尼的国家得以延续”这一论断意味着什么，然后说明这两个日期都不能被理解为对公元476年或公元541年意味着什么。
:::hint
这一论断说的是，这个罗马国家在公元476年之后又延续了几个世纪，而不是说它从未遭受断裂。一句是对一座基督教城市的洗劫，另一句是这个国家的终结。查士丁尼的统治结束于公元565年，不要把它与这两个日期扯在一起。
:::
:::solution
1204年4月13日，一支十字军洗劫了君士坦丁堡这座基督教城市，这是对同一个罗马国家后来的一次打击，而不是其帝位主张的终结。1453年5月29日，穆罕默德二世攻占这座城市，东罗马国家灭亡。

这两个日期都不能挪回公元476年——那一年并没有终结东部帝国；也不能挪到公元541年——那是查士丁尼一朝中的一场瘟疫，而不是这座城市的陷落。“国家延续”指的是罗马的名分和各项制度延续到五世纪之后、瘟疫之后。它并不意味着历史一帆风顺，也不允许在本章中展开对1204年或1453年的叙述。那些叙述属于[[christendom/crusades]]和[[crises/city-states]]。
:::
