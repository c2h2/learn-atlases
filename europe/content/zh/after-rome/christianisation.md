基督教成为罗马帝国的官方宗教时，哪些东西改变了，哪些没有改变？

最省事的回答是一种情绪：先是多神教的光明，后是基督教的黑暗；或者先是多神教的混乱，后是基督教的黎明。两种幕布都对不上日期。宽容、信经、官方宗教、对公共崇拜的限制，以及造成教会分裂的公会议，是性质不同的行为。它们改变的是国家在公开场合尊崇什么、惩罚什么，并不描述每个人的良心，也没有让罗马法、罗马的土地占有和罗马的税收就此停摆。

法律是史料。断言当时人人相信什么，则是推论，而且是大得多的推论。两者的区别正是[[sources/evidence]]的主题。本章的史料是有日期的公共法令。我们拒绝的推论，是一个无人统计过的归信比例，以及一种谁也无从记录在案的“欧洲精神”。

## 宽容不是设立国教

公元312年10月28日（按通常的定年），君士坦丁（Constantine）在米尔维安桥（Milvian Bridge）获胜。这场战役见[[rome/later-empire]]。战役本身并不是对教会的安排。次年，君士坦丁与李锡尼（Licinius）商定宽容政策，后世称之为《米兰敕令》。这个名称是后起的；这项政策也还不等于设立国教。基督徒可以公开奉行信仰而不再受旧日的刑罚，被没收的集会场所应予发还。传统崇拜并未在同一法令中被废除。政府停止迫害某种崇拜，并不等于已把它定为帝国的宗教。

后世的叙述常让公元312年的战役去承担公元380年那道法律的作用。我们不这样做。公元312年与公元313年的年份数字相差1，公元313年与公元380年相差67。本图谱计算时间跨度的规则是取年份数字之差——同样按这条规则，从公元800年到公元843年算作43年。若把两端都算进去，67会变成68，43会变成44。我们不这样算。

:::definition 官方宗教 {#def-official}
**官方宗教**是一种公开的法律地位：皇帝们宣布为帝国自身之宗教的崇拜，并由此在任职、财产和公开礼拜的权利上产生后果。它并不报告每个居民信仰什么，也不意味着较古老的仪式在法令颁布当天就消失了。
:::

:::definition 异端 {#def-heresy}
**异端**在本章中指公会议或法律把某种基督教教导界定在正统之外时所产生的范畴。这个词既不是指“现代读者不喜欢的任何东西”，也不是指从未进过法庭的私人疑虑。正统与异端是同时界定的，有其一，必有其二。
:::

## 公会议决定什么

公元325年，尼西亚（Nicaea）公会议在皇帝主持下召开。主教们争论圣子与圣父的关系，写下一项后世奉为标准的定义；与阿里乌（Arius）相关的教导被排除在这一标准之外。用我们自己的话转述，而非照录信经：公会议认定圣子与圣父同质，并将相反的教导判为不可接受。这句话描述的是一项决定，既不是引文，也不是对各城基督徒原有看法的调查。

皇帝主持下的公会议是一种新的公共事实。尼西亚会议此时并未把基督教定为官方宗教，而是在基督教内部划出一条界线，使自称基督徒的人可能被告知：他们信的是错误的基督教。[[#def-heresy]]作为一个实用范畴，由此开始。后来的拉丁法律正是在这类范畴之上建立起一套排斥机制；那属于[[christendom/exclusion]]，这里暂不展开。

尼西亚会议无法支撑的是一幅信仰地图。会上无人清点过帝国人口，本图谱也不会杜撰尼西亚派与非尼西亚派基督徒的比例。我们的论断很窄：公会议划定的是一条界线，而不是一次普查。能够推翻它的，只能是一份对各行省私人宗教实践进行系统调查的记录。我们手中有的，是主教们在皇帝支持下达成的一项定义。这已非同小可，但它不是对人心的调查。

:::quiz
公元313年的协议起了什么作用？
- [ ] 使基督教成为官方宗教，并关闭了神庙
- [x] 确立了宽容；后来的“《米兰敕令》”之名与设立国教不是一回事
- [ ] 它就是尼西亚公会议，只是提前了十二年召开
- [ ] 因帝国已皈依基督教而废除了土地税
:::solution
公元313年君士坦丁与李锡尼的协议是一项宽容政策。人们熟悉的名称是后起的，年表也明确指出这还不是设立国教。官方宗教始于公元380年的《帖撒罗尼迦敕令》。公元325年的尼西亚是一次公会议。这三件事之后，土地税依然存在。
:::
:::

## 先定官方宗教，再限制公共崇拜

公元380年，与狄奥多西一世（Theodosius I）相关的《帖撒罗尼迦敕令》把基督教定为帝国的官方宗教。以下是转述，并非法律原文：皇帝们采纳一种基督教定义——即他们与罗马和亚历山大里亚（Alexandria）两大主教座相联系的那种定义——作为公共宗教，并把其他基督教定义视为非法。转述只是帮助理解其法律效果；敕令原文是专家要读拉丁文的史料。我们的论断依据的是年表所载的效果：基督教成为官方宗教。执行是一个过程，不是一拨开关就完成的事。

一道法令可以改变公共生活的风险，而家庭与旧节庆只受到部分触动。主教们获得了在迫害性政府之下从未有过的地位。持非尼西亚派神学的人，或仍奉行传统城市崇拜的人，面对的是一个已经选边站的国家。这两点都不是人口统计。[[#def-official]]才是大小合适的论断；“帝国在公元380年从内心皈依了基督教”则言过其实。

公元391年与公元380年的年份数字相差11。公元391年，狄奥多西的一系列措施限制了公共的多神教崇拜，即献祭和旧有的城市礼仪；这并不是那道敕令的翻版。前一项行为确立官方基督教，并剥夺其他基督教教导的合法性；后一项行为则限制传统崇拜的公开举行。若把两者合并为一道禁令，就容易进一步犯错，把法律当成窥探私人信念的窗口。人们会服从、抵制、重新诠释，也会置之不理。法律显示的是当权者下了什么命令，却显示不出谁出于信仰而服从、谁出于审慎而服从。

:::theorem 官方宗教不是信仰普查 {#thm-census}
公元380年的敕令与公元391年的措施是公开的法律事实。它们并不描述帝国每个居民的信仰，从中也读不出任何归信比例。
:::
:::proof
证据在于史料的类型。敕令指定一种公共宗教，并规定相应的法律后果；针对公共崇拜的措施限制的是公开的礼仪。两类文书都没有清点人心，年表也明确指出执行是一个过程，不是一拨开关就完成的事。从公元380年到公元391年的间隔，本身就是不能合并这两项行为的理由：假如公元380年已经终结了旧有的公共崇拜，公元391年便没有什么公共崇拜可限制了。能够推翻[[#thm-census]]的，是一份同时代的信仰统计，或者能证明公共多神教崇拜作为寻常城市实践在公元391年之前已在各地绝迹的证据。一座关闭的神庙不是这样的统计；一项残存的地方礼仪也不能抹掉法律。两者都不是百分比。
:::

## 什么没有停止

公元380年以后的罗马政府依然是一个征税、行法、以土地为根基的国家。基督教化改变的是公共宗教和主教的地位；它既不是另一个世界的降临，也不是“欧洲精神”的降临。颁布这些法律的帝国是一个地中海帝国，它的公会议在东部召开：公元325年在尼西亚，公元451年在卡尔西顿（Chalcedon）。北非和亚洲同在一个帝国教会之内。所谓“欧洲精神”，若理解为后世一个拥有统一价值观的大陆，乃是一种向过去投射的观念。这一投射在[[sources/naming-europe]]中有专门剖析。这里只需指出：公元380年奠定的并不是一个信奉拉丁基督教的西欧。

土地占有没有停止。大地产仍是地方权力的支柱，教会也随之成为大地主。这改变了部分土地的持有者，却没有改变土地占有这一事实；我们也不会杜撰教会掌握了多少比例的土地。税收没有停止，国家仍需土地税来供养军队。公共崇拜的改变并不是财政改革。

法律没有停止。查士丁尼（Justinian）的《法典》（Codex）、《学说汇编》（Digest）和《法学阶梯》（Institutes）见[[after-rome/byzantium]]，分别定年于公元529年、公元533年和公元534年。它们汇编的是罗马法学，而不是以一部新的基督教法典取而代之。奴役也没有停止。[[rome/imperial-society]]讲过公元212年的公民权授予，它并未改变被奴役者的处境，官方基督教同样没有扭转这一点。被奴役人口没有可用的数字，本书也不会杜撰。一种公共宗教可以颂扬仁慈，而让这一法律范畴原封不动。

:::theorem 法律、土地与税收比公共宗教的改变更持久 {#thm-continuity}
基督教化改变了官方崇拜和主教的公共角色，但没有废除罗马法、土地占有或税收，也没有终结奴役。
:::
:::proof
在公元380年和公元391年之后，土地税和私人财产法依然是国家与精英运作的方式。查士丁尼后来的法典编纂是汇集罗马法学，而不是抛弃它。被奴役者仍然存在于法律之中，一如公元212年之后。主教们在城中获得审判权和话语权，是地方权力的真实变化，但这一变化发生在原有的财政与法律秩序之内。能够推翻[[#thm-continuity]]的证据，应当显示征税评估因公共崇拜改变而中止，或者公元380年或公元391年的某项法律整体解放了被奴役者这一阶层。一篇谴责贪婪的布道不是这样的证据；一次释奴也不意味着这一制度的终结。
:::

公元410年8月24日罗马遭洗劫，是一个反向检验。阿拉里克（Alaric）率领的西哥特人（Visigoths）洗劫罗马城时，基督教早已是官方宗教：410减380是30。洗劫没有摧毁教会，教会此前也没有摧毁罗马法。许多哥特人本身就是基督徒，只是不属于尼西亚派的定义。这次进攻是一个官方基督教帝国内部的军事冲击，既不是官方宗教的开端，也不能证明这一宗教作为法律已经失败。

## 卡尔西顿的分裂

公元451年的卡尔西顿公会议既是一次定义，也是一次分裂。以下是我们的描述，并非引文：公会议宣告基督是一个位格而具神、人二性，二性不相混淆。不接受这一信条的教会，尤其是埃及和叙利亚的教会，与帝国正统分道扬镳。由于皇帝的教会支持这次公会议，这一分裂既是教义上的，也是政治上的。后世给各方起的名称只是标签，本章不逐一叙述后来的各个教会。公会议可以在界定正统的同时，造成一场持久的分裂。

从公元325年到公元451年，年份数字相差126。尼西亚在圣子与圣父的关系上划了界线，卡尔西顿则在位格与本性的问题上划了界线。公元380年的官方宗教已经选定了尼西亚的标准，却没有终结争论。[[#thm-census]]不仅适用于教会的边界，也适用于教会内部：一部指定某种基督教的法律，并不能造就统一的信仰。

:::quiz
公元451年的卡尔西顿公会议可以用来说明什么？
- [ ] 从那年起，帝国内的每个基督徒都接受了同一种教义
- [ ] 公共的多神教崇拜首次受到限制
- [x] 公会议可以在界定教义的同时造成教会分裂
- [ ] 罗马的税收和土地占有走到了尽头
:::solution
卡尔西顿是一项教义定义，一些大教会——尤其是埃及和叙利亚的教会——没有接受。对公共多神教崇拜的限制在公元391年，早了60个年份数字，因为451减391是60。法律、土地和税收照旧延续。公会议证明的是一项决定和一次分裂，而不是普遍的认同，也不是一种新的经济。
:::
:::

## 一组完整的推演

请把这五个日期读作各自允许推出什么，而不是一条上升的斜线。从公元313年可以推出法律风险的变化，推不出官方宗教；从公元325年可以推出正统与异端之间的界线，推不出各行省的民意；从公元380年可以推出狄奥多西一世治下的一种法律地位，推不出归信率；从公元391年可以推出传统城市崇拜仍是一个公共问题；从公元451年可以推出一次分裂，推不出敕令的作废。持异议者是在敕令已经重塑的世界里争论何为正确的基督教。

在这份材料旁边放一个人作为限度，并把她标为一种类型，而非有名有姓的史料：公元451年之后的一位埃及城市居民，处在罗马的税收和罗马的土地占有之下，属于一个拒绝卡尔西顿的基督教会。这一类型打破了两句口号：她既不能证明罗马已经覆亡，也不能证明帝国此时已信仰一致。只有当某份史料记载了她，她才能成为证据。在此之前，她只是一个提醒：作为类型是虚构的，作为统计毫无用处。

君士坦丁堡的时间线还能挡住另一句口号，即官方宗教缔造了这座基督教首都。传统的落成日期是公元330年5月11日。380减330是50，可见首都早于敕令而存在，敕令并没有缔造这座城市。同一个地方可以容纳宫殿、税务机构，以及与信经并不相符的人群。

## 论证与反论

对[[#thm-census]]最有力的反驳来自实际层面：如果皇帝们限制公共多神教崇拜，扶持某一种基督教，把主教置于城市生活的中心，并惩处与之竞争的基督教教导，那么在实际意义上帝国已经基督教化了。坚持区分法律与信仰，看起来不过是咬文嚼字。人总是追随权力，一代人之后，公共宗教与私人习惯便会趋于一致。这一反驳值得正面回答。

公共层面的趋同是真实的，但这并不是反驳的全部。神庙关闭、城市节庆取消、主教成为城市的庇护者、异端成为法律风险，这些正是那些法律要造成的变化。可是这一反驳随即滑向第二个论断：内心信仰也随之一致地改变了，而且可以用一个数字来表述。这个论断需要别的证据。抱怨教化尚未完成的布道也不是统计，不过它们确实表明，教士们并不认为大功已经告成。我们拒绝的是虚假的精确，而不是公共变化的方向。

第二种反驳来自相反的方向。以彼得·布朗（Peter Brown）为代表、列于本课程参考文献中的那种“转型”论，可能把强制从历史叙述中打磨掉。如果什么都没有“覆亡”，公元391年似乎就只是一次温和的风尚转变。这种读法同样站不住。限制公共崇拜是权力行为，把基督徒定为异端也是权力行为。转型论证的正确用法，是驳斥“某一年骤然陷入黑暗”的说法，而不是否认那些有日期的法律的效力。说公元380年是一场灾变，或说公元380年前后一派温和延续，两种说法都过于平滑。这份行为档案本来就是参差不齐的。

要证实那条被我们拒绝的论断——敕令描述了每个人的信仰——需要一份我们并不拥有的统计。要动摇那条法律论断，则需要证据表明敕令从未颁布，或者并未把基督教定为公共宗教。法律论断成立，普查论断不成立。

:::example 从宽容到官方宗教的跨度 {#ex-span}
宽容协议在公元313年，《帖撒罗尼迦敕令》在公元380年。按本图谱的规则，这段跨度是多少年？再用一句话说明这个数字不能被理解为什么。（用年份数字之差计算。）
:::solution
将年份数字相减：380减313是67。这段跨度是67年，与843减800得43的算法相同；若把两端都计入，则会得到68。

67这个数字衡量的是宽容政策与官方宗教法律之间的距离。它衡量的不是归信，也不意味着其间没有发生任何重要的宗教事件。公元325年的尼西亚会议就落在这段跨度之内，而那是另一种性质的行为。
:::
:::

:::example 两次公会议的对照 {#ex-councils}
把公元325年与公元451年对照。它们有什么共同点？又有什么不可混为一谈？
:::solution
两者都界定了教义，也因此把另一种教导排除在外。尼西亚争论的是圣子与圣父的关系；卡尔西顿争论的是一个位格与两种本性，而埃及和叙利亚的教会拒绝了它。

不要把它们混为一句“教会作出了决定”。两者的年份数字相差126，因为451减325是126。公元380年的官方宗教介于两者之间。一项定义是那项决定的证据，而不是后世普遍认同的证据。
:::
:::

:::example 一句虚构的编年史 {#ex-invented}
下面这句话为示例而虚构。它不是史料。

“皇帝们把基督教定为官方宗教的那一年，帝国的每个居民都抛弃了旧有的崇拜，接受了信经。”

要把这句话提升为证据需要什么？哪些有日期的行为已经与它相抵触？
:::solution
这需要一份同时代、覆盖全帝国的宗教崇拜统计。敕令显示的只是一道命令；要说“每个居民”，就需要一份礼仪普查，而我们没有，也不会杜撰。

公元391年的措施仍在限制公共多神教崇拜，391减380是11；倘若人人早已抛弃那种崇拜，这些措施就毫无意义。公元451年的卡尔西顿表明基督徒在教义上存在分歧：451减380是71。这句虚构的话把一项法律行为变成了一场普遍的人心转变。
:::
:::

一位读者说：“公元391年是多神教终结之年。”请把这条论断改写到证据能够支撑的大小，并指出这个日期做不到的一件事。
:::solution
合适的说法是：公元391年，狄奥多西的措施限制了公共多神教崇拜。这是一项公开的法律行为，针对的是城市礼仪、献祭和旧有的公共礼拜。它与公元380年的官方宗教属于同一系列，但并非同一项行为。两者的年份数字相差11。

如果“多神教”指一切旧习俗、私人记忆或地方实践，这个日期就无法终结它，也推不出它在人口中所占的份额。这个日期也不能挪回公元313年——那一年是宽容；也不能往后挪，仿佛卡尔西顿讨论的是同一主题。公共崇拜不等于一般意义上的信仰，限制也不是普查。
:::
:::

:::warning 黑暗还是黎明
常见的迷思有两个方向，而两个方向都站不住。一种说法是，官方教会熄灭了宽容的多神教理性之光；另一种说法是，基督教点亮了一个道德的欧洲。传统城市崇拜并不是一种自由主义的安排，而那些敕令既不是纯粹强制的黑夜，也不是自由的日出。它们是有关公共宗教的法律，是既界定正统也界定异端的公会议，是一个继续征税、继续蓄奴的国家。“欧洲精神”不在这些圆点之中，归信比例也不在。
:::

:::history
公元380年，狄奥多西一世颁布《帖撒罗尼迦敕令》，把基督教定为帝国的官方宗教。实际奉行与执行所需的时间，远比一道法令长。公元313年的协议是宽容政策，后世称为《米兰敕令》；公元391年针对公共多神教崇拜的措施是又一项行为，而不是那道敕令的同义词。
:::

## 通向何处

已奉行这一官方宗教的西部各行省，构成了[[after-rome/successor-kingdoms]]中各王国的舞台。法兰克国王的受洗将提出与公元380年同样的问题——一项公共行为并不等于人口统计，而且连年份本身都有争议。颁布这些敕令的国家，并没有因为西部一个篡位者被废黜而消失：[[after-rome/byzantium]]将沿着查士丁尼的法律继续追踪这个罗马政府及其后来的历史。为什么公元476年只是一个惯例，而不是罗马生活的终结，[[rome/later-empire]]对此有论证；[[sources/argument]]则把它作为一堂反证课来讲。

:::summary
- 公元313年的协议是宽容。“《米兰敕令》”之名是后起的。它不是设立国教，公元312年的米尔维安桥之战也不能代替它。
- 公元325年的尼西亚会议界定了教义，也由此界定了异端。公会议不是信仰普查，这段历史里没有归信率的位置。
- 公元380年的《帖撒罗尼迦敕令》把基督教定为官方宗教。执行是一个过程。公元391年的措施限制公共多神教崇拜，是另一项行为。
- 官方宗教是狄奥多西一世治下的一项公开法律事实，并不说明每个居民信仰什么。
- 公元451年的卡尔西顿会议界定了教义，也造成了教会分裂，尤其是在埃及和叙利亚。它没有终结罗马法、土地占有、税收或奴役。
- 基督教化不是“欧洲精神”，不是黑暗的幕布，也不是黎明。公元410年8月24日罗马遭洗劫，既没有开启也没有废止官方宗教。
:::

## 习题

:::exercise 从敕令到限制 {level=1 check="11"}
《帖撒罗尼迦敕令》在公元380年，狄奥多西针对公共多神教崇拜的措施在公元391年。按本图谱的规则，这两个年份数字之间相隔多少年？（请输入年数。）
:::solution
用年份数字之差，而不是把两端都计入。391减380是11，年数是11。正因为相隔这段时间，两项行为不能当作一道法令来讲。这个数字不是信仰统计。
:::
:::

:::exercise 造成分裂的公会议在哪一年 {level=1 check="451"}
卡尔西顿公会议在哪一年召开？本章把这次会议既视为一项定义，也视为一次教义分裂。（请输入年份。）
:::solution
卡尔西顿在公元451年。尼西亚在公元325年，是另一次公会议。确立官方宗教的敕令在公元380年。答案是451。
:::
:::

:::exercise 宽容，以及后起的名称 {level=1}
用三四句话说明君士坦丁与李锡尼在公元313年商定了什么，为什么“《米兰敕令》”这个名称是个陷阱，以及这项协议不是什么。
:::solution
他们商定了一项宽容政策。基督徒可以集会、追回财产，但这项协议并不等于确立了帝国的官方宗教。人们熟悉的“《米兰敕令》”之名是后起的；如果用它来暗示当事人曾以这个标题颁布过一部现代式的法令，就夸大了这份文书，也误读了它的法律效果。这项协议不是设立国教，不是尼西亚会议，也不是公元391年的各项限制。官方宗教要到公元380年才出现。
:::
:::

:::exercise 说得过大的一句话 {level=2}
一块博物馆展板上写着：“公元380年：欧洲成为基督教的欧洲。”请保留这个日期中站得住的部分，把其余部分换成一条可以检验的论断，并在同一回答中指出限度。
:::solution
站得住的核心是：公元380年，与狄奥多西一世相关的《帖撒罗尼迦敕令》把基督教定为罗马帝国的官方宗教。一条可检验的替代说法是：公元380年，皇帝们把尼西亚派基督教定为帝国的公共宗教，而执行是一个过程，不是一拨开关就完成的事。

“欧洲成为基督教的欧洲”之所以不成立，一是因为单位是帝国，而不是后世的“欧洲”观念；二是因为这一变化是法律上的，而不是人口普查。其他基督教教导被排除在官方定义之外。公元451年的卡尔西顿表明，官方地位并不等于教义统一。展板上不该出现任何百分比。
:::
:::

:::exercise 关于罗马遭洗劫的两种说法 {level=2}
一位读者说，公元410年8月24日罗马遭洗劫，证明官方宗教已经取代了罗马国家；另一位读者说，这次洗劫证明官方宗教已经失败。请回应这两种说法，只依据日期的先后，不要诉诸任何“欧洲精神”。
:::solution
两种读法都让一次进攻承担了过多的意义。官方宗教始于公元380年，针对公共多神教崇拜的措施始于公元391年。洗劫发生在此之后：410减380是30。它既没有开启这一法律地位，也没有废除它。法律、税收和土地占有没有因哥特军队的进入而被废除，此前也没有因那道敕令而被废除。

第二种读法把一次军事事件当作对教义的裁决。许多哥特人是非尼西亚派的基督徒，所以这次进攻既不是多神教的复辟，也不是对某一信经真伪的检验。[[#thm-continuity]]经得起这两种反驳：宗教崇拜与法律各按各的时钟运行。
:::
:::

:::exercise 主教与税收 {level=2}
请解释：主教们在城市治理中的作用如何能够增强，而[[#thm-continuity]]依然成立？不要使用任何人口数字或土地比例。
:::solution
主教可以获得审判权、建筑，以及在城市纷争中的发言权。这是地方权力由谁来调解的真实变化，也是基督教化带来的变化之一。但这一变化发生在一个仍然评估土地、承认财产、区分自由人与被奴役者的世界里。教会地产改变了部分土地的持有者，并没有终结土地占有。

如果主教们用捐献取代了税收，或者法庭上只有信经才算数，[[#thm-continuity]]就不成立了。布道与征税评估并存。在城市中地位上升，并不等于废除了财政国家。
:::
:::

:::exercise 怎样才算“所有人” {level=3}
一位朋友承认公元380年是一道敕令，接着说：“公元391年以后公共崇拜受到限制，所以多神教终结了。要求拿出统计数字，不过是在回避显而易见的事实。”请写出论证与反论，并说明什么证据会证明你的朋友是对的，什么证据会使你放弃那条法律论断。
:::hint
把朋友粘在一起的两条论断拆开：一条是关于公开礼仪的命令，一条是关于每个人宗教归属的结果。然后问：每条论断各需要哪种史料？公元391年不是公元380年。
:::
:::solution
朋友的论证是：限制公共崇拜就终结了“多神教”，而要求拿出数字是一种回避。其中务实的一半有说服力：惩处公开献祭会改变城市广场的面貌，公共习惯也可能随之改变。史家应当承认这一点。

反论是：“终结”是一个全称词。公共崇拜不等于私人习惯，也不包括法律看不到的每一项礼仪。公元380年与公元391年的两项行为相隔11个年份数字，针对的目标也不同，两者都没有清点人数。拒绝一个杜撰的百分比，并不是拒绝描述强制。

如果证据表明，凡法律声称所及之处公共多神教崇拜都已消失，并且那句话被改写到这一公共范围之内，那么朋友就是对的。如果公元391年的措施从未颁布，或者并不针对公共崇拜，就应放弃那条法律论断。只有出现一份同时代的普查，才应放弃[[#thm-census]]。在此之前，法律论断成立，全称论断不成立。
:::
:::

:::exercise 卡尔西顿与“统一”的口号 {level=3}
一段简述写道：“到公元451年，基督教帝国已在教义上统一，各次公会议已经完成了它们的使命。”请用尼西亚、公元380年的敕令和卡尔西顿说明这句话为什么不成立，再给出一句公允的替代表述。不要逐一叙述后来的各个教会。
:::hint
想一想公会议能证明什么：是接受者共同认可的一份文本，还是拒绝者的认同？埃及和叙利亚就是本章实际点出的限度，你不需要了解它们后来的历史。
:::
:::solution
公元325年的尼西亚表明，一项定义会划出一条边界。公元380年的敕令把其中一方采纳为官方宗教，但这并不证明那条边界没有争议。公元451年的卡尔西顿就位格与本性作出进一步定义，而尤其是埃及和叙利亚的教会拒绝了它。一次遭持异议者拒绝的公会议，正是分裂的证据。两者的年份数字相差126，可见这两次公会议并非一个下午的事。

一句公允的替代表述是：公元451年，卡尔西顿界定的教义成为帝国正统，却遭到一些重要教会的拒绝，因此官方基督教在法律上仍是国教，在教义上却已分裂。这句话无需巡览后来的各个教会，也无需任何百分比。
:::
