当基督教成为罗马帝国的官方宗教时，什么改变了，什么没有改变？

诱人的回答是一种情绪：多神教的光明，然后是基督教的黑暗；或者多神教的混乱，然后是基督教的黎明。这两种幕布都不符合那些日期。宽容、一份信经、一个官方宗教、一项对公共崇拜的限制、一次分裂诸教会的公会议，是不同的行为。它们改变国家在公开场合尊崇什么、惩罚什么。它们不描述每一颗良心，也关不掉罗马法、罗马的地产与罗马的税收。

一条法律是一条史料。一句关于所有人当时相信什么的句子是一条推论，而且是一条大得多的推论。这一分别是[[sources/evidence]]的主题。这里的史料是有日期的公共法令。我们拒绝的那个推论，是一个没有人统计过的归信统计数字，是一种谁也不可能记下会议纪要的欧洲精神。

## 宽容不是设立国教

公元312年10月28日，按通常的定年，君士坦丁（Constantine）在米尔维安桥（Milvian Bridge）获胜。那场战役在[[rome/later-empire]]里讲述。它本身并不是一项教会安排。次年，君士坦丁与李锡尼（Licinius）商定了一项宽容政策，后来被称为《米兰敕令》。这个名字是后来的。这项政策还不是一个国教。基督徒可以公开实践信仰而不受旧日的刑罚；被没收的集会场所将予发还。传统的崇拜没有在同一道法令中被废除。一个停止迫害某种崇拜的政府，还没有把那种崇拜变成帝国的宗教。

后来的故事让公元312年的那场战役去干公元380年那道法律的活。我们不这样干。从公元312年到公元313年，年份数字之差是1，从公元313年到公元380年，它们相差67。本图谱对一段跨度的内部规则——也就是本图谱把公元800年到公元843年算作43年所用的同一条规则——就是年份数字之差。把两端都加进去会把67变成68，把43变成44。我们不那样做。

:::definition 官方宗教 {#def-official}
**官方宗教**是一种公开的法律身份：皇帝们点名为帝国自己的崇拜，连带着任职、财产与公开崇拜之权上的后果。它不是对每一个居民相信什么的报告，也不是说更古老的仪式在法令颁布的那一天消失了。
:::

:::definition 异端 {#def-heresy}
**异端**，在本章中，是一条公会议或一条法律在把一种基督教的教导界定为正统之外时所造出的范畴。这个词不意味着"现代读者不喜欢的任何东西"，也不意味着某座法庭从未听过的私人疑虑。正统与异端是被一起界定的。有了其中一个，就离不开另一个。
:::

## 公会议决定什么

公元325年，尼西亚（Nicaea）公会议在一位皇帝之下召开。主教们争论圣子与圣父的关系，写下一个后来各代人当作标准的界定。与阿里乌（Arius）相联的教导被置于那个标准之外。用我们的话，不是粘贴一份信经：公会议主张圣子与圣父同具本体，并把相反的教导标记为不可接受。那句话是一个决定的描述。它不是一句引文，也不是对各城市基督徒已经怎么想的一份调查。

一位皇帝之下的公会议是一种新的公共事实。尼西亚此时还没有把基督教变成官方宗教。它在基督教内部划下一条线，以致自称基督徒的人可能被告知，他们的基督教是错的那一种。[[#def-heresy]]从这里开始作为一个可用的范畴。后来的拉丁法律在这类范畴之上建造一架排斥的机器；那属于[[christendom/exclusion]]，我们现在不讲述它。

尼西亚无法承载的是一张信仰的地图。公会议上没有人清点过帝国，本图谱也不会发明一个尼西亚派与非尼西亚派基督徒的比例。会构成对那条窄论断之反驳的——公会议界定的是一条线，不是一次清点——是一份对各行省私人实践的系统查勘的纪要。我们拥有的，是一份由皇帝支持、经主教们一致同意的界定。这已经很大。它不是对人心的一次调查。

:::quiz
公元313年的协议做了什么？
- [ ] 它使基督教成为官方宗教，并关闭了神庙
- [x] 它规定了宽容，而后来的名字《米兰敕令》与设立国教不是一回事
- [ ] 它就是尼西亚公会议，提前十二年召开
- [ ] 它废除了土地税，因为帝国已经变成基督教的
:::solution
君士坦丁与李锡尼在公元313年的协议是一项宽容政策。人们熟悉的名字是后来的，而年表明确说明这还不是一个国教。官方宗教是公元380年的《帖撒罗尼迦敕令》。尼西亚在公元325年，是一次公会议。土地税在这三件事之后仍然存在。
:::
:::

## 官方宗教，然后是对公共崇拜的限制

公元380年，与狄奥多西一世（Theodosius I）相联的《帖撒罗尼迦敕令》把基督教定为帝国的官方宗教。用转述，不作为对法律的引用：皇帝们采取一种基督教的界定，他们与罗马和亚历山大里亚（Alexandria）两座教座相联的那份界定，把它作为公共宗教，并把基督教的其余界定视为非法。转述只是对法律效果的一个指引。敕令的字句是一条专家用拉丁文阅读的史料。我们的论断使用的是年表陈述的效果。基督教成为官方宗教。执行是一个过程，不是开关。

一道法令可以改变公共生活的风险，而家户与旧日节庆仍然只被部分触及。主教们获得了一种在迫害他们的政府之下不曾有过的地位。持有非尼西亚派神学的人，或者持守一种传统城市崇拜的人，面对的是一个已经选边的国家。这两个事实都不是清点。[[#def-official]]是恰当的论断尺寸。"帝国在公元380年从内心变成了基督教的"是错误的尺寸。

公元391年与公元380年的年份数字之差是11。公元391年，与狄奥多西一世相联的措施限制了公共的多神教崇拜：献祭与旧日的城市礼仪，不是那道敕令的第二份抄本。一个行为选择了一种官方基督教，并使其他基督教的教导失效。另一个行为在公开场合限制传统崇拜。把它们并成一道禁令，会招来进一步的错误，即把一条法律当作通往私人信念的窗口。人们服从、抵抗、重新解释、无视。一条法律显示的是权力命令了什么。它不显示谁因信念而服从、谁因审慎而服从。

:::theorem 官方宗教不是一次信仰的清点 {#thm-census}
公元380年的敕令与公元391年的措施是公开的法律事实。它们不描述帝国的每一个居民相信什么，从它们之中读不出任何归信统计数字。
:::
:::proof
证据是史料的种类。一道敕令点名一种公共宗教，并附上法律后果。针对公共崇拜的措施限制的是公开场合的礼仪。两份文书都没有清点良心，而年表明确说明执行是一个过程，不是开关。从公元380年到公元391年的间隔，本身就是不把这两个行为合并的理由：如果公元380年已经终结了旧的公共崇拜，那么公元391年就再也没有公共的东西可供限制。会构成对[[#thm-census]]之反驳的，是一次同时代的信仰清点，或者是这样的证据：公共的多神教崇拜在公元391年之前，作为寻常的城市实践已经在各处停止。一座关闭的神庙不是那次清点。一场存留的地方礼仪也不废除法律。两者都不是百分比。
:::

## 没有停止的东西

公元380年之后的罗马政府仍然是一个征税、用法、立足于土地的国家。基督教化是公共宗教的改变，也是主教地位的改变。它不是另一种世界的到来，也不是一种欧洲精神的到来。颁布这些法律的帝国是地中海的。它的公会议在东边召开，公元325年在尼西亚，公元451年在卡尔西顿（Chalcedon）。北非与亚细亚在同一座帝国教会之内。一种欧洲精神，如果理解为一个后来的大陆持有一套价值，就是一个向后投射的观念。拆解那个投射的地方是[[sources/naming-europe]]。这里只需要说：一个拉丁基督教的西欧，不是公元380年所奠定的。

地产没有停止。大地产仍然是地方权力的骨干，而教会轮到自己也成为一个大地主。这改变了一些占有者。它没有终结占有土地这个事实，我们也不会发明一份处于教会之手的大地比例。税收没有停止。国家仍然需要土地税来支付士兵。公共崇拜的改变不是一次财政改革。

法律没有停止。查士丁尼（Justinian）的《法典》（Codex）、《学说汇编》（Digest）与《法学阶梯》（Institutes）——[[after-rome/byzantium]]讲述它们——定年为公元529年、公元533年与公元534年。它们收集的是罗马法学。它们没有用一部新的基督教法典取代它。奴役也没有停止。公元212年的公民身份授予，在[[rome/imperial-society]]里讲授过——让被奴役者依然是被奴役者，而官方基督教并不扭转这一点。奴隶人口没有任何数字可用，也不会被发明。一种公共宗教可以赞美仁慈，同时把那个法律范畴留在原地。

:::theorem 法律、土地与税收比公共宗教的改变更长寿 {#thm-continuity}
基督教化改变了官方崇拜与主教的公共角色。它没有废除罗马法、地产或税收，也没有终结奴役。
:::
:::proof
土地税与私人财产法，在公元380年之后和公元391年之后，仍然是国家与精英运转的方式。查士丁尼更晚的编纂收集的是罗马法学，而不是抛弃它。被奴役者仍然在法律之中，正如他们在公元212年之后仍然在其中。主教们在城中获得法庭与发言权，是地方权力的一次真实改变，而它坐落在那个财政与法律秩序之内。会构成对[[#thm-continuity]]之反驳的，是这样的证据：征税评定因为公共崇拜的改变而停止了，或者公元380年或公元391年的某条法律作为一个阶级释放了被奴役者。一篇反对贪婪的布道不是那个证据。一次释放不构成那个制度的终结。
:::

公元410年8月24日对罗马的洗劫是一个否定性检验。基督教已经官方化之后，阿拉里克（Alaric）的西哥特人（Visigoths）洗劫了那座城市：410减380是30。洗劫没有拆掉教会，教会也没有拆掉罗马法。许多哥特人自己就是基督徒，虽然不是尼西亚派界定中的那一种。这次攻击是一个官方基督教帝国内部的军事冲击，不是官方宗教的开端，也不是那个宗教作为法律已经失败的证明。

## 卡尔西顿分裂

公元451年，卡尔西顿公会议既是一个界定，也是一次分裂。用我们的描述，不作为引文：公会议教导一个基督，两个本性，神性与人性，不相混淆。不接受那个公式的诸教会，特别是在埃及与叙利亚的，与帝国这一系分了手。这个分裂是教义的，也是政治的，因为皇帝的教会支持公会议。各方的后来名字是标签。本章不会逐一讲述每个后来的教会。一次公会议可以界定正统，并在同一件工作里造出一个持久的分裂。

从公元325年到公元451年，年份数字之差是126。尼西亚在圣子与圣父之间划了一条线。卡尔西顿在位格与本性的问题上划了一条线。公元380年的官方宗教已经选定了一个尼西亚参照，而没有终结争论。[[#thm-census]]既适用于教会的边缘，也适用在教会内部。一道点名一种基督教的法律，产生不出一种信念。

:::quiz
公元451年的卡尔西顿公会议可以用来显示什么？
- [ ] 从那一年的那一天起，帝国里每一个基督徒都接受了一个教义
- [ ] 公共的多神教崇拜在那时第一次受到限制
- [x] 一次公会议可以在界定教义的行为之中分裂诸教会
- [ ] 罗马的税收与地产走到了尽头
:::solution
卡尔西顿是一个教义界定，而大教会们，特别是在埃及与叙利亚的，没有接受它。对公共多神教崇拜的限制在公元391年，早60个年份数字，因为451减391是60。法律、土地与税收延续。一次公会议是一个决定与一次分裂的证据，不是普遍同意的证据，也不是一种新经济的证据。
:::
:::

## 一个完整的序列

把这五个日期读作许可，而不是一条斜率。从公元313年推出法律风险的改变，不是官方宗教。从公元325年推出正统与异端之间的一条线，不是对各行省的一次访谈。从公元380年推出狄奥多西一世治下的一个法律身份，不是一个归信率。从公元391年推出传统城市崇拜仍然是一个公共问题。从公元451年推出一次分裂，不是那道敕令的作废。持异议者在敕令已经重新塑造的世界里，争论何为正确的基督教。

在卷宗旁边放一个人作为限度，把她标记为一个类型，而不是一个具名史料：一位公元451年之后的埃及城中居民，在罗马税收之下，挨着罗马的地产，并且在一个拒绝卡尔西顿的教会里做基督徒。这个类型打破两句口号。她不是罗马已经覆亡的证据，也不是帝国如今信仰一体的证据。只有当某条史料记载了她，她才会成为证据。在那之前她是一个提醒，作为一个类型被发明，作为一个统计数字毫无用处。

君士坦丁堡的时钟挡住另一句口号，即官方宗教创建了这座基督教首都。传统的落成日期是公元330年5月11日。由于380减330是50，首都先于那道敕令而存在，而敕令没有创建那座城市。一个地方容纳得下一座宫殿、一个税务署，以及一群与信经不相称的人。

## 论证与反论

对[[#thm-census]]最有力的反对意见是务实的。如果皇帝们限制公共的多神教崇拜，优待一种基督教，把主教放进城市生活的中心，并惩罚与之竞争的基督教教导，那么就实际而言帝国已经变成基督教的。坚持法律与信念之间有一道缺口，看起来像迂腐。人跟随权力。过一代人，公共宗教与私人习惯相互趋近。这个反对值得一个直截了当的回答。

公开场合的趋同是真实的，而它不是这个反对意见的全部。关闭的神庙、取消的城市节庆、作为城市庇护者的主教，以及作为法律风险的异端，都是那些法律被制定出来所要造成的改变。这个反对接着滑向第二句话：内在的信念跟上了，一致地跟上了，而且可以用一个数字来陈述。这句话需要别的证据。抱怨工作没有做完的诸布道也不是清点。它们确实显示，教士们并不认为大功已经告成。我们拒绝的是虚假的精确，不是公共变化的方向。

第二个反对来自另一面。关于转型的谈论——与彼得·布朗（Peter Brown）相联、在课程参考文献里点名的那一类——可以把故事里的强制磨掉。如果没有任何东西"覆亡"，那么公元391年就是一次温和的趣味变化。这种读法也失败。对公共崇拜的限制是一个权力行为。把基督徒归类为异端是一个权力行为。转型论证的正确用法，是挡住一个黑暗的年份，而不是否认那些有日期的法律的效力。公元380年的灾变，以及跨过公元380年的温和延续，两种说法都太平滑了。行为的卷宗有意就是不平的。

能够了结那条被拒绝的论断——敕令描述了每个人的信念——的，是一次我们并没有的清点。会动摇那条法律论断的，是这样的证据：敕令不曾颁布，或者不曾点名基督教为公共宗教。法律论断成立。清点论断不成立。

:::example 从宽容到官方宗教的跨度 {#ex-span}
宽容协议在公元313年。《帖撒罗尼迦敕令》在公元380年。按本图谱的规则，这个跨度是多少年？然后用一句话说出这个数字不被允许意味着什么。（用年份数字之差。）
:::solution
用年份数字相减：380减313是67。这个跨度是67年，与843减800得43是同一种计数，不是把两端都算在内的计数，那会给出68。

数字67度量的是一项宽容政策与一道官方宗教法律之间的距离。它不度量一次归信，也不意味着期间没有发生任何宗教上重要的事。尼西亚在公元325年，落在这个跨度之内，是另一种行为。
:::
:::

:::example 两次公会议，并排放置 {#ex-councils}
把公元325年放在公元451年旁边。你能说出它们共同之处是什么，又有什么是你不可压平的？
:::solution
每一个都界定教义，并由此把另一种教导标记为在其之外。尼西亚争论的是圣子与圣父。卡尔西顿争论的是一个位格与两个本性，而埃及与叙利亚的诸教会拒绝了它。

不要把它们压平为"教会作了决定"。年份数字之差是126，因为451减325是126。公元380年的官方宗教落在它们两者之间。一个界定是关于那个决定的证据，不是关于后来一切同意的证据。
:::
:::

:::example 一句虚构的编年史句子 {#ex-invented}
下面这句话是虚构的。它不是史料。

"在皇帝们把基督教定为官方宗教的那一年，帝国里每一个居民都抛弃了旧日的崇拜，接受了信经。"

要把这句话提升为证据需要什么？哪些有日期的行为已经对它不利？
:::solution
提升需要一次遍及帝国的、同时代的崇拜清点。一道敕令显示的是一道命令。"每一个居民"需要的是一次诸礼仪的清点，而那个我们没有，也不会发明。

公元391年的措施仍然在限制公共的多神教崇拜，而391减380是11；如果每个人早已抛弃那种崇拜，这就毫无意义。卡尔西顿在公元451年显示基督徒在教义上分裂：451减380是71。这句虚构的话把一个法律行为变成了一次普遍的改心。
:::
:::

一位读者说："公元391年是多神教终结的一年。"请把这条论断改写到证据所能承载的尺寸，并说出一件这个日期做不到的事。
:::solution
合适的尺寸是：公元391年，与狄奥多西一世相联的措施限制了公共的多神教崇拜。那是一个法律与公共的行为，指向城市礼仪、献祭与旧日的公共崇拜。它属于公元380年的官方宗教那一组，但不是同一个行为。年份数字之差是11。

这个日期终结不了"多神教"，如果这个词指的是每一种旧习惯、私人记忆或地方实践；它也产不出人口的份额。它也不能被挪回公元313年，那一年是宽容；或者被向前挪，仿佛卡尔西顿讲的是同一个主题。公共崇拜不是泛泛的信念，一项限制不是一次清点。
:::

移动年份，并拒绝一条斜率。一个10年的窗口不会让公元313年和公元451年成为邻居：年份数字之差是138，因为451减313是138。这条线上没有任何东西度量信念。一条不断上升的"基督教化"数量曲线将是你加进去的，不是这幅图加进去的。

:::warning 黑暗，或黎明
常见的迷思朝两个方向运行，而且在两个方向上都失败。一个版本说，一个官方教会吹熄了一种宽容的多神教理性。另一个版本说，基督教点亮了一个有道德的欧洲。传统的城市崇拜不是一个自由的安排，而诸敕令既不是一夜纯粹的强制，也不是自由的日出。它们是关于公共宗教的法律，是既界定异端也界定正统的诸公会议，是一个继续征税、继续把人蓄为奴隶的国家。一种欧洲精神不是这些圆点之一。一个归信统计数字也不是。
:::

:::history
公元380年，狄奥多西一世治下的《帖撒罗尼迦敕令》把基督教定为帝国的官方宗教。实践与执行花的时间比一道法令长。公元313年的协议曾是宽容，后来被称为《米兰敕令》；而公元391年针对公共多神教崇拜的措施是一个进一步的行为，不是那道敕令的同义词。
:::

## 通向何处

已经在这一官方宗教之下的西部诸行省，是[[after-rome/successor-kingdoms]]里诸王国的舞台。一位法兰克国王的受洗会提出与公元380年相同的问题：一个不是清点的公共行为；外加一个问题，就是那个年份本身有争议。颁布诸敕令的国家不会在一个西部篡位者被废黜时消失：[[after-rome/byzantium]]沿着查士丁尼的法律以及更远处，追踪那个罗马政府。公元476年为什么是一个惯例而不是罗马生活的终结，在[[rome/later-empire]]里有论证；作为反证据的一课，则在[[sources/argument]]。

:::summary
- 公元313年的协议是宽容。《米兰敕令》这个名字是后来的。它不是一个国教，而公元312年的米尔维安桥不能替代它。
- 尼西亚在公元325年界定了一个教义，并由此界定了异端。一次公会议不是一次信仰的清点，而这个故事里没有任何归信率的位置。
- 《帖撒罗尼迦敕令》在公元380年把基督教定为官方宗教。执行是一个过程。公元391年的措施限制公共的多神教崇拜，是另一个行为。
- 官方宗教是狄奥多西一世治下的一个法律与公共事实。它没有说出每一个居民相信什么。
- 卡尔西顿在公元451年界定教义并分裂诸教会，特别是在埃及与叙利亚的。它没有终结罗马法、地产、税收或奴役。
- 基督教化不是一种欧洲精神，不是黑暗的幕布，也不是黎明。公元410年8月24日对罗马的洗劫既不开始也不作废那个官方宗教。
:::

## 习题

:::exercise 从敕令到限制 {level=1 check="11"}
《帖撒罗尼迦敕令》在公元380年。针对公共多神教崇拜的狄奥多西措施在公元391年。按本图谱的规则，那两个年份数字之间隔着多少年？（请输入年数。）
:::solution
用年份数字之差，不是把两端都算在内的计数。391减380是11。年数是11。那段距离正是这两个行为不可当作一道法令来讲述的理由。它不是信仰的统计数字。
:::
:::

:::exercise 分裂的那次公会议是哪一年 {level=1 check="451"}
卡尔西顿公会议是哪一年，即那个本章既当作教义分裂又当作界定的会议？（请输入年份。）
:::solution
卡尔西顿在公元451年。尼西亚在公元325年，是另一次公会议。官方宗教的敕令在公元380年。年份是451。
:::
:::

:::exercise 宽容，名字是后来的 {level=1}
用三四句话说出君士坦丁与李锡尼在公元313年商定了什么，为什么"《米兰敕令》"这个名字是一个陷阱，以及那个协议不是什么。
:::solution
他们商定了一项宽容政策。基督徒可以集会、追回财产，而这个协议并不构成一个官方的帝国宗教。人们熟悉的名字《米兰敕令》是后来的，所以使用它时如果把参与各方写成曾以那个标题颁布过一部现代法令，就是夸大这份文书，也误读了法律结果。这个协议不是设立国教，不是尼西亚，也不是公元391年的诸限制。官方宗教要等到公元380年。
:::
:::

:::exercise 一条过大的句子 {level=2}
一块博物馆图注说："公元380年：欧洲变成基督教的。"请保留这个日期里站得住的东西，并用一条你能检验的论断替换其余部分。在同一个回答里说出限度。
:::solution
站得住的内核是《帖撒罗尼迦敕令》在公元380年，与狄奥多西一世相联，把基督教定为罗马帝国的官方宗教。一条可检验的替换是：公元380年，皇帝们点名一种尼西亚派基督教为帝国的公共宗教，而执行是一个过程，不是开关。

"欧洲变成基督教的"之所以失败，是因为单位是帝国，不是后来关于欧洲的观念；也因为变化是法律的，不是一次清点。其他基督教的教导被置于官方界定之外。卡尔西顿在公元451年显示，官方身份不是教义统一。图注上放不进任何百分比。
:::
:::

:::exercise 针对洗劫的两个反对 {level=2}
一位读者说，公元410年8月24日对罗马的洗劫证明官方宗教已经取代了罗马国家。另一位说洗劫证明官方宗教已经失败。请两个都回答，只使用那些日期的次序，不使用任何关于欧洲精神的东西。
:::solution
两种读法都让一次攻击负载过多。官方宗教定年起于公元380年，针对公共多神教崇拜的措施起于公元391年。洗劫在其后：410减380是30。它没有开始那个法律身份，也没有把它废除。法律、税收与地产没有被一支哥特军队的开进所废除，也没有被那道敕令所废除。

第二种读法把一个军事事件当作对教义的判决。许多哥特人是非尼西亚派的基督徒，所以这次攻击不是一场多神教复辟，也不是对一个信经是否为真的检验。[[#thm-continuity]]在这两个反对意见之下存活：崇拜与法律按不同的时钟运行。
:::
:::

:::exercise 主教与税收 {level=2}
请解释主教们怎么能在城市治理中变得更重要，而[[#thm-continuity]]仍然为真。不要使用任何人口数字，也不要使用任何土地比例。
:::solution
一位主教可以获得一个法庭、一栋建筑，以及对城市纷争的发言权。这是由谁来调解地方权力的真实改变，也是基督教化所改变的事情之一。它发生在这样一个世界：那里仍然评定土地、承认财产，并区分自由人与被奴役者。教会地产改变某些土地的占有者。它们没有终结地产。

如果主教们用捐赠取代税收，或者如果只有信经在法庭上重要，[[#thm-continuity]]就会失败。布道与评定并存。在城市中的重要，不是财政国家的废除。
:::
:::

:::exercise 什么才算所有人 {level=3}
一位朋友承认公元380年是一道敕令，然后说："公元391年之后，公共崇拜受到限制，所以多神教终结了。索要一次清点，是回避明摆着的东西。"请写出论证与反论。说明什么证据会使你的朋友正确，什么证据会使你放弃那条法律论断。
:::hint
把朋友粘在一起的两条论断分开：一条关于公开礼仪的命令，和一个关于每一个人宗教的结果。然后问每条论断需要哪一种史料。公元391年不是公元380年。
:::
:::solution
朋友的论证是：限制公共崇拜就终结了"多神教"，而索要数字的要求是一种回避。务实的那一半有力量。惩罚公开献祭会改变城市的广场，公共习惯会移动。史家应当承认这一点。

反论是："终结了"是一个全称词。公共崇拜不是私人习惯，也不是一条法律没有看到的每一场礼仪。公元380年与公元391年的两个行为相隔11个年份数字，目标也不同。两者都不数人头。拒绝一个发明的百分比，不是拒绝描述强制。

如果证据显示公共的多神教崇拜在法律声称所及之处都已消失，并且那句话被改写到那个公共范围，那么朋友是对的。如果公元391年的措施不曾颁布，或不针对公共崇拜，就放弃法律论断。只有当一次同时代的清点出现时，才放弃[[#thm-census]]。在那之前，法律成立，全称句子不成立。
:::
:::

:::exercise 卡尔西顿与统一的口号 {level=3}
一段简短的概述说："到公元451年，基督教的帝国已经在教义上联合起来；诸公会议已经完成了它们的工作。"请用尼西亚、公元380年的敕令与卡尔西顿，解释这句话为什么失败。然后说出一句公平的一句话替换会是什么。不要逐一讲述后来的诸教会。
:::hint
问一问一次公会议是什么的证据：一份由接受它的人一致同意的文本，还是拒绝它的人的同意。埃及与叙利亚就是本章真正点名的限度。你不需要它们后来的历史。
:::
:::solution
尼西亚在公元325年显示，一个界定会划出一道边界。公元380年的敕令采纳一方作为官方宗教，却没有证明那条边界没有争议。卡尔西顿在公元451年写下进一步的界定，关于位格与本性，而特别是埃及与叙利亚的诸教会拒绝了它。一次被持异议者拒绝的公会议，是一次分裂的证据。年份数字之差是126，所以两次公会议不是同一个下午。

一句公平的替换是：公元451年，卡尔西顿界定了一个成为帝国这一系、却被重要教会拒绝的教义，所以官方基督教在法律上仍是国教，在教义上仍是分裂的。这句话不需要对后来诸教会的巡礼，也不需要百分比。
:::
