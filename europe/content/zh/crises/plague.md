证据无法支持单一数字时，死亡人数应当如何表述？

十四世纪给我们留下了两场灾难，篇幅短小的章节总喜欢把它们粘在同一张幻灯片上。大饥荒始于1315年。1347年10月，墨西拿（Messina）报告出现鼠疫；1348年和1349年，鼠疫已遍及西欧大部分地区。此后还有数波疫情，本图谱不为它们定年。两场灾难都没有附带一份死者普查。诱惑在于借用某个地区估计区间的上限，宣布欧洲死了一半人。这句话不是本课程要讲授的事实，而正是这些年份要防止的错误。

死亡人数是关于人的论断。它需要灾前人口、灾后人口，以及相信这两个数字的理由。这些年里的欧洲，这三样都不是作为单一对象存在的。存在的是一个个地区：其中一些已借助税册、遗嘱、庄园账目和叙事记载得到研究，还有许多没有以同样的方式研究过。[[sources/evidence]]已经把1347年的鼠疫报告当作灾难的见证，而不是人口普查。本章坚持这条规则，并追问这条规则仍然允许怎样的句子。允许的句子是一个区间，与证据已得到研究的地方相联系，而在其他地方则公开承认尚无定论。

## 两个年份，相隔一代人

以1315年作为大饥荒的开端。年表把这次饥荒定为1315–1317年，范围是北欧大部分地区。它不是某一个歉收的下午，而是一连串坏收成，伴随着人畜之间的饥饿与疾病，持续了不止一个冬天。有人死去。死了多少，本图谱没有数字，因此一个也不列出。在这里，“许多”是诚实的用词。虚假的精确将是第二场饥荒——一场证据的饥荒。

饥荒不是鼠疫。从1315年到1347年经过了32年，因为本图谱把从A年到B年的跨度算作B减A，正如它把800年到843年算作43年。三十二年是一代人。在第一个饥荒年出生的孩子，到西西里港口报告鼠疫时可能已经成年；1347年的老人也可能还记得1315年。记忆并不会把两个事件变成一个事件。读者若把“十四世纪危机”说得仿佛是同一个季节，就是为了省一个短语而抹去了这一代人。

饥荒确实改变的，是解读后来各种损失的背景。一个已经遭受饥饿打击的人口，与寻常年份里的人口并不相同。这句话是一个提醒，而不是一个总和。我们不能用1348年无名的死者减去1315–1317年无名的死者，再把差额称为结果。减法需要整数，而我们没有这些整数。诚实的联系是定性的：在鼠疫被报告之前，匮乏已经是一个政治和宗教问题，领主权也早已靠地租和劳役维持。[[christendom/lords-and-peasants]]那一章说明了庄园是什么，本章只是借用这个术语。**庄园**是领主权与地租的单位，而不是由千人一面的农民构成的欧洲制度。不自由因地区和世纪而异，饥荒并没有使它整齐划一。

## 报告不是普查

:::definition 报告与地区估计 {#def-report}
本章所说的**报告**，是一份注明日期、证明鼠疫已经出现的见证，而不是死者计数。**地区估计**是史家针对证据已得到研究的地方，就其人口下降幅度给出的区间。它不是欧洲的总数，也不能描述未经研究的地方。
:::

1347年10月，墨西拿报告出现鼠疫。请留意这个动词。“报告”的意思是，史料提供给我们的是灾难的消息，地点是一个港口，时间是那个月。这并不意味着墨西拿是生物学意义上的源头，也不意味着有一位书记员走遍全岛、记下了每一例死亡。更早的阶段——沿着商路、在黑海世界——在学界仍有争论。本图谱没有为墨西拿之前的阶段确定任何年份或地点，因此本课一个也不给出。这里确定的1346年属于下一章的克雷西（Crécy）之战，不能悄悄挪用为鼠疫的年份。你可以视为确定的第一个鼠疫年份是1347年，而且只是作为报告。

1348年和1349年，鼠疫已遍及西欧大部分地区。从1347年到1349年经过了2年。这个跨度反映的是史料中的传播，而不是死亡率。一种疾病可以沿着道路和海路传遍广大地区，而它在所接触的人群中造成的死亡比例却可能相差悬殊。人口密度和商路很重要，所以[[christendom/towns-and-learning]]已经把城镇和贸易与本课程中的瘟疫联系起来，却没有提出它无法给出出处的统计论断。正因为有港口、河港城镇和集市，墨西拿的报告才在1348年和1349年成为别处的消息。“很快”指的就是这两年，并不是说每个村庄都在同一个星期遭到打击。

此后还有数波疫情。这句话属于已确定的年表，但没有附带年份。你会在其他书里看到后来几次暴发的日期，不要把它们引进来。一波年份未确定的疫情，不能用来凑总数，也不能被叙述成按时清除了一个已知的比例。后来的几波疫情，是不信任任何把1348年当作这个世纪全部人口史的句子的理由，也是不为显得完整而杜撰缺失日期的理由。

本图谱中已经有一场更早的鼠疫。公元541年，鼠疫传入埃及并扩散开来，那一段文字同样拒绝给出死亡总数。这种拒绝是一条关于证据的规则，而不是对十四世纪特有的避讳。[[after-rome/byzantium]]离那次更早的暴发更近。两份报告共同具有的，是一个谨慎句子的结构：传入、扩散、没有全大陆的整数。

:::theorem 没有单一的欧洲死亡总数 {#thm-no-total}
1347年10月在墨西拿报告、1348年和1349年遍及西欧大部分地区的鼠疫，依据本图谱所用的证据，无法给出单一的欧洲死亡总数。在证据已得到研究的许多地区，估计值在人口的约三分之一到约二分之一之间，也有一些地方与此不同。
:::
:::proof
年表确定了鼠疫的传入、传播的两年以及区间的形态，而禁止给出单一的欧洲总数。这就是这一论断所能依靠的证据。区间背后是一些不完整的记录：略去免税者的税额评定，只记录领主愿意列出的佃户的法庭卷宗，只记录有遗产可留之人的遗嘱，只记录作者觉得可怕之事的叙事报告。每一种都是真实的痕迹，但没有一种是欧洲。史家对全大陆的数字意见不一，本课在正文而不是脚注中说明这一点，因为这种分歧本身就是结论。能够推翻[[#thm-no-total]]的，是一次同时代的欧洲人口普查，在鼠疫前后各进行一次，覆盖范围已知，并有已知的方法把鼠疫死亡与其他死亡区分开来。我们没有这样的普查。一项结果落在三分之一到二分之一之外的新的地区研究，本身并不能推翻这一论断：论断已经说明有些地方与此不同，而且说的是“许多”，而不是“所有”。真正会动摇它的，是许多已研究地区都落在这一区间之外的证据，或者任何能诚实地得出单一欧洲整数的途径。在这种途径出现之前，“欧洲死了一半人”就不是概括，而是把一个地区区间的上限拔高为整个大陆。
:::

请慢慢读这些量词。“许多”不是“每一个”，“已研究的”不是“有人居住的”。“约三分之一”和“约二分之一”是一个区间的两端，而不是对同一个对象的两次测量。“有些地方与此不同”是论断内部的一个分句，而不是事后的客气致歉。最佳估计接近三分之一的地方、接近二分之一的地方，以及两者之外的地方，都与这句话相容；但它们与一个装扮成研究发现的欧洲平均值并不相容。对区间两端取平均，得出十二分之五，这是任何史料都未曾记录的精确，而这个分数仍然冒充整个欧洲。它比任何一端都更糟，因为它看起来像是计算的结果。

“黑死病”（Black Death）是后来的名称，是一个标签。它告诉现代读者指的是哪一场灾难，却并不增加任何数字，也不会把地区估计变成全大陆的估计。陈述报告内容时，宁可用“鼠疫”；并把这个后来的名称视为[[sources/argument]]意义上的标签：你若放任它，它就会把论断掩藏起来。

## 什么改变了，死亡又解释不了什么

在人口下降的地方，劳动力可能变得更加稀缺，按旧条件收取地租也可能更加困难。这是一个值得陈述的后果，但它不是工资率。本图谱没有确定任何价格、日工资或工资上涨的百分比。在史家能够研究的许多地方，趋势是：出卖劳动力的人有了更大的议价空间，而靠租税为生的人不得不让步、施压，或另找佃户。他们采取了哪种做法，因地而异。一项法令可以试图冻结工资，但它的通过本身并不能证明冻结奏效，也不能替一个我们尚未读过其卷宗的王国说话。

在英格兰，瘟疫年间的一道法令试图压低工资。后来的一项制定法在英格兰的法律记忆中颇为有名，其年份这里没有确定，因此不予给出。要点在于这种企图：统治者面对人口下降，回应的是一种关于谁的议价才算正当的主张。这证明的是上层的焦虑，而不是每个劳动者都服从了。1381年的英格兰起义（English Rising），也称农民起义（Peasants' Revolt），参与者并不只是农民。从1349年到1381年又是32年。它属于[[crises/war-and-schism]]的内容，是一场关于赋税和领主权的危机，而不是鼠疫引发起义的证明。“之后”不等于“因为”。

:::theorem 地方性的议价不等于后来的革命 {#thm-not-later}
在鼠疫使人口减少的地方，劳动和地租可能被重新议定，宗教回应也增多了。这些后果并不使鼠疫成为宗教改革或文艺复兴的原因，也没有让庄园作为一个欧洲事实就此消失。
:::
:::proof
论断的肯定部分，依据的是庄园账目和城市工资纠纷真正能够显示的证据：租税所受的压力、强制劳动的企图，以及充满誓愿、游行和归咎的公共宗教生活。否定部分依据的是年份。按惯例，百年战争（Hundred Years' War）始于1337年，克雷西之战在1346年，两者都早于墨西拿的报告。一场已经开始的战争，不可能是一场尚未被报告的瘟疫的结果。按照[[crises/city-states]]将给出的定义，人文主义是一种关于拉丁语、教育和文书院的实践，而不是死亡造成的一种情绪；年表也不允许用鼠疫来解释它。论纲的日期是1517年10月31日。从1349年到1517年经过了168年。这么长的间隔可以容纳种种影响，却不能用“导致了”这样一个动词一跃而过。能够推翻[[#thm-not-later]]的，是证明劳动的重新议定从西西里到苏格兰采取了同一种法律形式，或者证明不把欧洲死亡总数作为原因插进去，1517年就无法理解。这两种证明都不存在。同样能推翻它的，是证明人口一下降，不自由就随之终结。但在一些地区，证据指向相反的方向：领主重新加征了租税。本图谱没有为这些后来的加征确定年份，因此不予给出。[[sources/scale]]中的尺度原则才是恰当的检验：一个真实的地方性议价，并不能推出全国性的结论，更不能推出全大陆的结论。
:::

宗教回应也需要同样的约束。人们举行游行、布道、许愿，并寻找可以归咎的人。在一些城镇，犹太社区在瘟疫年间遭到攻击。归咎不是关于疾病的发现。迫害在其发生之处，是一个关于权力和邻里的事实，而不是受害者造成了死亡的证据。[[christendom/exclusion]]已经表明，拉丁基督教的法律如何能把犹太人和穆斯林标记为局外人。瘟疫年间并没有发明这种模式，只是给了它一场可以借势的恐慌。本图谱没有确定任何城镇名单、具体日期或遇害人数，因此一个也不列出。也不要描述症状。临床细节弥补不了缺失的普查，只会转移话题。

这一反驳值得直接回应。一位读者说：这个区间涵盖了许多已研究的地区，其中包括一些大王国，所以欧洲的损失必定落在这个区间之内。但“包括”不等于“穷尽”，区间也不是一个点。一个研究充分的郡，可能位于一个所知甚少的王国之中。把郡拔高为王国，再把王国拔高为大陆，正是[[sources/scale]]所要防范的尺度错误。拒绝给出总数，并不会让这场灾难显得更小。“在许多已研究的地方约三分之一到约二分之一，其他地方则有所不同”，本身就已经是一句骇人的话。添上一个全大陆的整数并不能告慰死者，只会假装已经清点过他们。

## 一个标明虚构的算例

这里要求有一个算术算例，以免区间的两端被无意中叠加起来。设想一座有600人的虚构城镇。它不是墨西拿，不是记录中的某个教区，也不是欧洲；每次用到它，都要说明它是虚构的。如果这座城镇失去三分之一的人口，就有200人死亡、400人存活，因为600的三分之一是200。如果它接着又失去剩余人口的一半，那么400人中有200人死亡，剩下200人。第一次损失后的结果是400，第二次之后是200，两者不同。最初600人的一半应是300，既不是400，也不是200。“先失去三分之一，再失去剩余的一半”是两个不同运算的先后序列，而不是“约三分之一到约二分之一”的另一种说法。

历史上的区间描述的是不同的已研究地区，有的接近三分之一，有的接近二分之一。它描述的不是一座先遭低估计打击、再遭高估计打击的城镇。余数200只是这座虚构城镇的答案。谁把200或400带进关于欧洲的句子，谁就忘记了“虚构”这个标注。如果把顺序颠倒过来，600的一半剩下300，300的三分之一再剩下200。结果相同是代数使然，而不是关于先后几波疫情的事实。把步骤展示出来，然后把它们留在这个玩具模型里。

:::example 从饥荒到报告的间隔 {#ex-gap}
大饥荒始于1315年，墨西拿于1347年报告出现鼠疫。从1315年到1347年经过了多少年？你不能从中得出什么结论？
:::solution
经过的年数是1347减1315，即32。你可以得出结论：饥荒与这份报告相隔一代人，所以它们不是同一个季节，也不能用同一个名称概括。你不能得出结论说：死去的是同一批人，或者一件事引起了另一件事，或者32是死亡人数。饥荒本身有确定年份的跨度是1315年到1317年，经过2年，而这个2同样不是死者人数。
:::
:::

:::example 分两步计算的虚构城镇 {#ex-town}
一座虚构的城镇有600人，它不是真实存在的地方。它先失去三分之一的人口，然后又失去剩余人口的一半。每一步之后还剩多少人？为什么两次结果不同？
:::solution
600的三分之一是200，所以第一步之后剩下400人。400的一半是200，所以第二步之后剩下200人。结果不同，因为400不是200。最初600人的一半应是300，又是第三个数字。400、300和200都不是欧洲的总数。历史上“约三分之一到约二分之一”的说法，是跨越各个已研究地区的区间，并不允许你把两个比率先后套用到一座城镇上，再套用到整个大陆上。
:::
:::

:::example 一句虚构的编年史 {#ex-sentence}
下面这句话是虚构的。请把它当作一件专门写来让人识破的伪作。“1348年，欧洲死了一半人；从那天起，每个领主都失去了他的农民，新时代开始了。”你可以保留什么？必须拒绝什么？
:::solution
你可以保留1348年，这是真实的年份，鼠疫在这一年已遍及西欧大部分地区。你必须拒绝“欧洲死了一半人”，因为它把一个地区区间的一端拔高为整个大陆。你必须拒绝“每个领主”，因为庄园是地方性的，不自由也没有在某一天消失。你必须拒绝“新时代开始了”，因为[[#thm-not-later]]不允许把鼠疫当作文艺复兴或宗教改革的原因。编年史的道德训诫不是人口普查。要把这句虚构的话提升为证据，需要一份有名可查的史料、一位已知的作者，以及相信其数字的理由。这句话一样都没有，而它被标明虚构，正是为了让你不必去寻找这些东西。
:::
:::

:::example 两个真实事件的对照 {#ex-pair}
把1315年与1347年10月对照。前者是北欧大部分地区大饥荒的开端，后者是墨西拿关于鼠疫的报告。两者之中，哪一个是死亡人数——如果有的话？
:::solution
都不是。1315年标定的是一场饥荒的开端，饥荒跨度为1315–1317年，没有确定的死亡数字。1347年10月标定的是一个港口的报告，这是灾难的见证，而不是人口普查。把两者对照，显示的是32年的间隔和性质上的差异：饥荒是跨越数季收成的匮乏，报告是鼠疫的消息。把两者混为“十四世纪的死亡人数”，就是在回答一个从未以史料能够回答的方式向史料提出的问题。
:::
:::

- [x] 否。两者相隔一代人，本图谱不把其中一个当作另一个的原因。
- [ ] 否，因为饥荒的年代在墨西拿报告之后。
:::solution
饥荒始于1315年，报告则在1347年10月，相隔32年。同处一个世纪并不构成因果。饥荒的年代并不在墨西拿报告之后。1348年和1349年之后还有数波疫情，但它们的年份没有确定，而且它们也不是饥荒。
:::
:::

移动年份，看看哪些圆点同时出现在窗口中。1315年的饥荒与1347年的报告相隔32年，所以四年宽的窗口无法同时容纳它们。1347年、1348年和1349年的圆点表示传入与传播，而不是三个死亡总数。后来的几波疫情没有圆点，因为它们的年份没有确定。一段空白是拒绝杜撰日期，而不是断言什么都没有发生。

:::warning 欧洲的一半
人们常重复的一句话是：欧洲死了一半人。这句话站不住，因为“约二分之一”是许多已研究地区估计区间的上限，而不是对整个大陆的测量，况且还有一些地方与此不同。重复这句话并不会让缺失的普查出现，只会让一个谨慎的区间听起来像是某个大胆真相的怯懦版本。而那个大胆的版本，恰恰是证据承载不了的。
:::

:::history
1347年10月，墨西拿报告出现鼠疫。1348年和1349年，鼠疫已遍及西欧大部分地区。史家针对许多已研究地区发表的估计，在人口的约三分之一到约二分之一之间，这些估计并不构成单一的欧洲死亡总数。
:::

在这些分数前保留“约”字，并且不要让欧洲进入那座虚构的城镇。史料汇编所能收集到的那类见证，告诉你的是人们说自己看到了什么，它们加起来也凑不出谚语所要的那个整数。一个落在区间之外的地方，[[#thm-no-total]]本来就允许。只有当许多已研究地区都落在区间之外，或者一次真正的普查取代了这一区间时，这一论断才需要改写。为了保住一个流畅的句子而隐瞒差异，那才是回避；援用“有些地方与此不同”这一分句，则不是。

## 通向何处

下一章[[crises/war-and-schism]]讨论一场战争和一次教会分裂：墨西拿报告鼠疫时，这场战争按惯例已在1337年开始；教会分裂则始于1378年。这些是权威和赋税的危机，而不是死亡人数造成的情绪。[[crises/city-states]]将拒绝“大规模死亡造就了人文主义”这一进一步的主张。1517年属于[[reformations/luther]]，它不是你可以从一个分数中读出的结果。如果你需要再次运用这一方法，[[sources/scale]]告诉你如何防止一个真实的地方事实变成一个虚假的大陆事实，[[sources/evidence]]则告诉你如何让报告始终只是报告。

:::summary
- 大饥荒始于1315年，在北欧大部分地区持续到1317年，没有确定的死亡总数。
- 从1315年到1347年10月墨西拿的报告是32年，两场灾难相隔一代人。
- 1348年和1349年是鼠疫传遍西欧大部分地区的年份。此后还有数波疫情，本图谱不为它们杜撰年份。
- 在许多已研究的地区，估计值在约三分之一到约二分之一之间，也有一些地方与此不同。不存在欧洲总数。
- “欧洲死了一半人”把这一区间的上限拔高为整个大陆，本章正是为了阻止这句话而写。
- 劳动、地租和宗教归咎——包括对一些犹太社区的攻击——都是后果。它们不是宗教改革或文艺复兴，也不是一种全欧洲统一的议价。
- 可以用一座虚构的城镇来区分三分之一与二分之一，但不能把它的余数当作全大陆的结果带出去。
:::

## 习题

:::exercise 年份间隔 {level=1 check="32"}
饥荒始于1315年，墨西拿于1347年报告出现鼠疫。从1315年到1347年经过了多少年？（请输入年数。）
:::solution
本图谱把从A年到B年的跨度算作B减A。1347减1315是32，经过了32年。这个32是一场饥荒与一份报告之间的间隔，既不是死亡人数，也不是原因。
:::
:::

:::exercise 报告的年份 {level=1 check="1347"}
墨西拿在哪一年报告出现鼠疫？（请输入年份。）
:::solution
报告的时间是1347年10月，年份是1347年。“10月”确定了这一年中的月份，却不会把报告变成普查，也不能为后来的几波疫情定年。
:::
:::

:::exercise 传播不等于比率 {level=1 check="2"}
从1347年到1349年经过了多少年？（请输入年数。）
:::solution
1349减1347是2，经过了2年。本图谱就是用这两年，包括其间的1348年，来标定鼠疫在西欧大部分地区的传播。2年的跨度不是人口的某个比例。
:::
:::

:::exercise 失去三分之一之后 {level=2 check="400"}
一座虚构的城镇有600人，失去了三分之一。还剩多少人？（请输入人数。）
:::solution
这座城镇是虚构的，所以600是教学用的数字，而不是史料。600的三分之一是200，600减200是400，剩下的人数是400。不要把200称为欧洲死亡总数，也不要把400当作欧洲。
:::
:::

:::exercise 再失去剩余的一半 {level=2 check="200"}
同一座虚构城镇在上一题的损失之后剩下400人。现在它又失去剩余人口的一半。还剩多少人？（请输入人数。）
:::solution
400的一半是200，400减200是200，剩下的人数是200。这个200与第一步之后剩下的400不同，两个结果的差异正是本题的要点。但它们仍然不是历史上的区间：那是一个跨越各地区的区间，而不是对一座虚构城镇的两次打击。
:::
:::

:::exercise 识破伪造的句子 {level=2}
这句话是虚构的：“1349年，欧洲死了一半人，这引发了宗教改革。”请把它改写成本图谱可以接受的句子。你不需要任何单一数字。
:::solution
可以接受的句子要限定在已确定的事实之内。1347年10月墨西拿报告之后，1349年鼠疫已遍及西欧大部分地区，1348年也是如此。在许多已研究的地区，估计值在人口的约三分之一到约二分之一之间，也有一些地方与此不同。不存在欧洲总数，所以“欧洲死了一半人”必须拒绝。论纲的日期是1517年10月31日，距1349年168年，[[#thm-not-later]]不允许把鼠疫当作它的原因。一种可用的改写是：“1349年，鼠疫已遍及西欧大部分地区；地区估计多在约三分之一到约二分之一之间，也有一些地方与此不同，而这并不是宗教改革的原因。”
:::
:::

:::exercise 对区间取平均 {level=3}
一位作者说：三分之一是一端，二分之一是另一端，所以欧洲损失了约十二分之五，即两个分数的平均值。请解释为什么这个平均值并不比“一半”的迷思更好。什么才真正能推翻[[#thm-no-total]]？
:::hint
想一想这两个分数是不是对同一人口的两次测量。再想一想，“许多”一词以及“有些地方与此不同”这一分句，本来已经允许了什么。
:::
:::solution
三分之一是4/12，二分之一是6/12，平均值是5/12，即约十二分之五。这看上去很审慎，但它仍然是一个欧洲总数。这两个分数不是对整个大陆的两次读数，而是针对许多已研究地区所报告的区间的两端。对两端取平均，杜撰了一种任何普查都未曾记录的精确，还抹去了“有些地方与此不同”这一分句。这只是给单一数字的迷思换了一身更整洁的衣服。能够推翻[[#thm-no-total]]的，是一次真正的、在鼠疫前后进行的欧洲人口普查，或者是许多已研究地区都落在区间之外的证据。一个落在区间之外的地方，论断本已考虑在内。平均值不是这样的证据，它只是对措辞所做的算术。
:::
:::

:::exercise 与众不同的地方 {level=3}
假设有一天，一个真实的地区——而不是虚构的城镇——被证明损失了约十分之一的人口，另一个地区则损失了约三分之二。一位批评者说[[#thm-no-total]]站不住了。真的如此吗？请说明什么样的进一步结果会迫使你改写这一论断。
:::hint
注意量词“许多”，以及“有些地方与此不同”这几个字。然后把论断本已允许的差异，与会推翻它的差异区分开来。
:::
:::solution
仅凭这两个地区，论断并没有站不住。[[#thm-no-total]]说的是：在许多已研究的地区，估计值在约三分之一到约二分之一之间，也有一些地方与此不同。十分之一和三分之二正是第二个分句所说的那种差异。只有当它们被证明具有代表性，也就是许多已研究地区都落在区间之外，或者有人得出了一个真正可以取代这一区间的欧洲总数时，它们才会成为改写论断的理由。在此之前，举出一个损失惨重的地方和一个损失较轻的地方，是在运用这一论断，而不是推翻它。虚构的城镇连这一点都做不到：一个虚构的十分之一不是一项研究。批评者的错误，在于把一个明确附有例外的区间当成了一个普遍适用的比例。
:::
:::
