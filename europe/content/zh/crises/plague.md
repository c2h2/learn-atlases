当证据不支持一个数字时，一个死亡人数应当如何陈述？

十四世纪交给我们两场灾变，而一个短章节喜欢把它们粘到一页幻灯片上。大饥荒始于1315年。鼠疫于1347年10月在墨西拿（Messina）被报告，而它在1348年与1349年已在西欧的大部分地区。其后又有数波，而本图谱不为这些波次定年。两场灾变都不是带着一次死者的人口普查到来的。诱惑在于借来一个地区区间的上端，并宣布半个欧洲死了。那句话不是这门课程将要教授的事实。它正是这些年份在这里要阻止的错误。

死亡人数是一条关于人的论断。它需要之前的人口、之后的人口，以及一个信任这两个数字的理由。这些年里的欧洲，并不把这三样中的任何一样作为单一的对象拥有。它有一些地区，其中一些经由税收名册、遗嘱、庄园账目与叙事记述得到过研究，而其中许多没有以同样的方式得到研究。[[sources/evidence]]已经把1347年的瘟疫报告当作一场灾变的见证，而不是一次人口普查。本章守着那条规则，并问那条规则仍然允许哪一种句子。被允许的句子是一个区间，系在证据已经被加工过的地方，而在别处公开地未完成。

## 两个年份，一代人

用1315年作为大饥荒的开端。年表把饥荒锁定为1315–1317年，在北欧的大部分地区。它不是一个歉收的下午。它是一连串坏收成，伴随着人与牲畜之间的饥饿和疾病，跨越不止一个冬天。人死了。死了多少不是本图谱持有的一个数字，所以一个也不印。"许多"在这里是一个诚实的词。一个虚假的精确将是一场第二次饥荒，这一次的饥荒关于证据。

饥荒不是瘟疫。从1315年到1347年，已过计数是32年，因为本图谱把从A年到B年的跨度算作B减A，正如它把800年到843年算作43年。32年是一代人。一个出生在第一个饥年里的孩子，可能在一座西西里港口报告鼠疫时已经成年，而一个1347年的老人可能记得1315年。记忆不把两个事件变成一个事件。一个读者说出"十四世纪的危机"，仿佛那是同一个季节，他就是为了让一个短语省事而抹去了那一代人。

饥荒确实改变了的东西，是后来那些损失赖以被阅读的背景。一个已经被饥饿打击过的人口，不同于一个平常年份里的人口。那句话是一条告诫，不是一个和。我们不能把1348年的无名死者减去1315–1317年的无名死者，然后把余数叫作一个结果。减法需要整数。我们没有那些整数。诚实的联结是定性的：在瘟疫被报告之前，稀缺已经是一个政治与宗教问题，而领主权已经靠地租与劳役为生。[[christendom/lords-and-peasants]]是说出庄园是什么的那一章。这一章只是借用那个词。一个**庄园**是一个领主制度与租金的单位，不是一套由彼此相同的农民构成的欧洲制度。不自由因地域而异，因世纪而异。饥荒没有把它标准化。

## 报告不是普查

:::definition 报告与地区估计 {#def-report}
本章所说的**报告**，是一条有日期的见证，见证鼠疫在场，不是一次死者计数。**地区估计**是史家对一个证据得到过研究的地方的人数下降所给出的区间。它不是一个欧洲总数，也不描述一个未经研究的地方。
:::

1347年10月，鼠疫在墨西拿被报告。按住这个动词。被报告意味着史料给我们的是一场灾变的消息，在一个港口，在那一个月。它不意味着墨西拿是生物学的起源，也不意味着有一位书记员走遍那座岛，写下了每一次死亡。更早的阶段，沿着贸易路线，在黑海世界，在学术之中是有争论的。本图谱不为它们在墨西拿之前锁定年份或地方，所以本课一个也不给。1346年在这里是为克雷西（Crécy）锁定的，在下一章，而且不得被悄悄当作一个瘟疫年份重新使用。你可以当作确定来处理的第一年瘟疫年份是1347年，而且只是作为一条报告。

1348年与1349年，瘟疫已在西欧的大部分地区。从1347年到1349年的已过计数是2年。那个宽度是史料里的一次蔓延，不是一个死亡率。一场疾病可以沿着道路与海路走过大片土地，而杀死与它相遇的人口中比例迥异的部分。密度与路线是要紧的，这就是为什么[[christendom/towns-and-learning]]已经把城市与贸易和本课程的瘟疫连接起来，却没有作出一个它无法给出来源的统计论断。港口、河上城镇与集市，就是为什么一条在墨西拿的报告在1348年与1349年会成为别处的新闻。"不久"就是那两个年份，不是一个说每个村庄都在同一个星期被击中的论断。

其后又有数波。那句话是锁定的年表的一部分，而它没有系着年份。你会在其他书里遇到后来暴发的日期。不要把那些日期引进来。一个年份没有被锁定的波次不能为一个总数凑数，也不能被叙述为按日程清除的一个已知比例。后来的波次，让人不信任任何把1348年当作这个世纪全部人口历史的句子，也让人不为了显得完整而发明缺失的日期。

一场更早的瘟疫已经在图谱里。公元541年，鼠疫抵达埃及并蔓延，而那段文字同样拒绝一个死亡总数。这个拒绝是一条关于证据的规则。它不是对十四世纪的一种特别的拘谨。[[after-rome/byzantium]]坐得离那次更早的暴发更近。两条报告共同拥有的，是一条谨慎句子的形状：抵达、蔓延、没有大陆整数。

:::theorem 没有单一的欧洲死亡总数 {#thm-no-total}
1347年10月在墨西拿被报告、并在1348年与1349年存在于西欧大部分地区的瘟疫，从本图谱使用的证据出发，给不出一个欧洲死亡总数。在证据得到过研究的许多地区里，估计落在大约三分之一与大约二分之一之间，而有些地方另有不同。
:::
:::proof
年表锁定了抵达、蔓延的那两个年份、以及区间的形状，而它禁止一个单一的欧洲总数。这就是那条论断被允许依靠的证据。区间背后坐着的是部分的记录：略去免税者的税收评估，记录下领主愿意列出的是哪些佃户的法庭卷册，记录下那些有东西可以遗赠的人的遗嘱，记录下一位写作者认为可怕之事的叙事记述。每一条都是真实的存迹。它们之中没有一条是欧洲。史家对一个大陆数字意见不一，而这一课把这一点说在散文里，不是说在一条脚注里，因为这个分歧就是结果。会构成对[[#thm-no-total]]之反驳的，是一次同时代的、关于瘟疫之前与之后欧洲人口的人口普查，具有已知的覆盖范围，以及一种把瘟疫死亡与其他死亡区分开来的已知方法。我们没有那次人口普查。一项落在三分之一到二分之一之外的新的地区研究，单凭自身并不反驳这条论断：这条论断已经说了有些地方另有不同，而且说的是"许多"，不是"所有"。会使它吃紧的，是许多经过研究的地区落在那条带之外的证据，或者是任何通向一个欧洲整数的诚实路径。在那条路径存在之前，"半个欧洲死了"不是一个概述。它是把一个地区区间的上端提升为一块大陆。
:::

慢慢读这些量词。"许多"不是"每一处"。"经过研究的"不是"有人居住的"。"大约三分之一"与"大约二分之一"是一条带的两端，不是对一个身体的两次测量。"有些地方另有不同"是论断内部的一个从句，不是它之后的一个客套道歉。一个最佳估计靠近三分之一的地方，一个最佳估计靠近二分之一的地方，以及一个两者都在其外的地方，都与那句话相容。它们与一个装扮成发现的欧洲平均值不相容。对一条带的两端取平均会产出十二分之五，一个没有任何史料记录过的精确，而那个分数仍然假装自己是欧洲。它比任何一端都糟，因为它看起来像一次计算。

后来的名字黑死病（Black Death）是一个标签。它告诉一个现代读者说的是哪场灾变。它不添上一个计数，也不把地区估计变成一个大陆估计。当你在陈述那些报告说了什么时，宁可说"瘟疫"，并把那个后来的名字当作[[sources/argument]]意义上的一个标签：一个如果你纵容它、它就把论断藏起来的打包。

## 什么改变了，而死亡解释不了什么

在人数下降之处，劳动可能变得更稀缺，地租按旧条件可能更难收取。这是一个值得陈述的后果，而它不是一个工资率。本图谱不锁定任何价格、日工钱或工资上涨的百分比。在史家能够研究过的许多地方，方向是：出卖劳动的人有更多讨价还价的空间，而靠租税为生的人必须让步、强制，或寻找新的佃户。他们做到了其中哪一样，是地方性的。一项制定法可以尝试冻结工资。它不能因为被通过，就证明冻结奏了效，也不能替一个其卷册我们不曾读过的王国说话。

在英格兰，瘟疫年头的一道法令试图压低工资。一项后来的制定法在英格兰的法律记忆中很有名。它的年份在这里没有被锁定，所以不予给出。企图才是要点：统治者用一个关于谁的讨价还价是合法的的论断，来回应人数的下降。那是上层焦虑的证据，不是每个劳动者都服从了的证据。1381年的英格兰起义（English Rising），亦称农民起义（Peasants' Revolt），不只有农民参加。从1349年到1381年又是32年。它属于[[crises/war-and-schism]]，作为一场税收与领主主权的危机，而不是瘟疫引起反抗的证明。"之后"不是"因为"。

:::theorem 地方议价不是后来的革命 {#thm-not-later}
在瘟疫削减了人数之处，劳动与地租可能重新议价，而宗教回应可能增多。这些后果并不使瘟疫成为宗教改革或文艺复兴的原因，它们也不消灭庄园作为一个欧洲事实。
:::
:::proof
肯定的那一半依靠庄园账目与城市工资争端真正能够显示的那类证据：对租税的压力、强制劳动的企图、以及一种充满宣誓、游行与归咎的公共宗教生活。否定的那一半依靠年份。百年战争（Hundred Years' War）惯例性的开端是1337年，而克雷西是1346年，两者都在墨西拿之前。一场已经开始的战争不是一场尚未被报告的瘟疫的结果。人文主义，如[[crises/city-states]]将要定义它的，是一种拉丁语、教育与文书署的实践，不是一种由死亡产生的情绪，而年表拒绝让瘟疫解释它。那些论纲定年为1517年10月31日。从1349年到1517年，已过计数是168年。那样大的一段空隙装得下影响。它不能被"导致了"这样一个动词跳过去。会构成对[[#thm-not-later]]之反驳的，是一个证明劳动的重新议价从西西里到苏格兰采取了同一种法律形式的论证，或者一个证明除非把一个欧洲死亡总数作为其原因插进去、否则1517年就无法理解的论证。两种论证都不存在。同样会构成对它的反驳的，是人数一降、不自由就简单地终结了的证据。有些地区的证据走的是反方向：领主们重新加上了租税。本图谱不为那些后来的加派锁定年份，所以一个也不给。[[sources/scale]]里的尺度课就是正确的检验。一条为真的地方协议不许可一个全国性的句子，也不许可一个大陆性的句子。
:::

宗教回应需要同样的纪律。人们举行游行、布道、许愿，并寻找归咎的对象。在一些城市，犹太社区在瘟疫年头里遭到攻击。归咎不是关于疾病的一个发现。一场迫害，在其发生之处，是一个关于权力与关于邻居的事实。它不是受害者造成了那些死亡的证据。[[christendom/exclusion]]已经表明了拉丁基督教的法律如何能够把犹太人与穆斯林标记为局外人。瘟疫年头没有发明那个模式。它们只是给了它一种可以活动的恐慌。本图谱不锁定任何城市清单、任何一日或任何被杀者的计数，所以一个也不印。也不要描述症状。临床细节修不好那次缺失的人口普查。它只会改变话题。

反论值得一句直接的回应。一个读者说：区间覆盖了多个经过研究的地区，那些地区包括大王国，所以欧洲所失的就在带里面。"包含"不是"穷尽"，而一条带不是一个点。一个研究充分的郡可以坐在一个知之甚差的王国里面。把郡提升为王国，再把王国提升为大陆，就是[[sources/scale]]所要对付的那个尺度错误。拒绝一个总数不会让灾难变小。"在许多经过研究的地方大约三分之一到大约二分之一，而在别处不同"已经是一句可怕的句子。添上一个大陆整数不会告慰死者。它只会假装数过了他们。

## 一个算例，标为虚构

任务书要求一个算术算例，好让区间的两端不能被偶然地叠在一起。取一座虚构的、有600人的城镇。它不是墨西拿，不是记录里的一个教区，也不是欧洲。每次使用它，都说它是虚构的。如果这座城镇失去它三分之一的人，200人死亡，400人留下，因为600的三分之一是200。如果它接着失去余数的一半，那400人里有200人死亡，200人留下。第一次损失之后的结果是400。第二次之后的结果是200。它们不同。最初600人的一半会是300，而300既不是400也不是200。"三分之一，然后是余数的一半"这个短语是两个不同运算的一个序列。它不是"大约三分之一到大约二分之一"的翻译。

历史上的那个区间描述的是不同的经过研究的地区，一些靠近三分之一，一些靠近二分之一。它不描述一座先被低估计打击、然后又被高估计打击的城镇。余数200只是对这座虚构城镇的一个答案。任何一个把200或400带进一个欧洲句子的人，都忘记了那个标签。如果你把顺序倒过来，600的一半留下300，而300的三分之一留下200。同样的终点是代数，不是关于相继几波的一个事实。展示这些步骤，然后把它们留在这个玩具里。

:::example 从饥荒到报告的间隔 {#ex-gap}
大饥荒始于1315年。鼠疫于1347年在墨西拿被报告。从1315年到1347年的已过计数是多少年，而你不得从中推出什么？
:::solution
已过计数是1347减1315，即32。你可以得出：饥荒与这条报告相隔一代人，所以它们不是一个季节，也不是一个名字。你不得得出：死去的是同一批人，或者一个引起了另一个，或者32是一个死亡人数。饥荒自己被定年的跨度，从1315年到1317年，是2年的已过计数，而那个2同样不是死者的计数。
:::
:::

:::example 一座虚构的城镇，分两步 {#ex-town}
一座虚构的城镇有600人。它不是一个真实的地方。它失去三分之一，然后失去余数的一半。每一步之后留下多少人，结果为什么不同？
:::solution
600的三分之一是200，所以第一步之后留下400。400的一半是200，所以第二步之后留下200。结果不同，因为400不是200。最初的600的一半会是300，又是第三个数字。400、300、200，没有一个是一个欧洲总数。历史上的那个短语"大约三分之一到大约二分之一"是一个跨经过研究的地区的区间，不是一道许可证，允许把两个比率先后应用到一座城镇身上，然后再应用到一个大陆身上。
:::
:::

:::example 一句虚构的编年史句子 {#ex-sentence}
下面这句话是虚构的。把它当作一件为被识破而写下的伪造品来对待。"1348年，半个欧洲死了，而从那一天起，每个领主都失去了他的农民，新时代开始了。"你能留下什么，必须拒绝什么？
:::solution
你可以把1348年作为一个真实的年份留下，在这一年瘟疫已在西欧的大部分地区。你必须拒绝"半个欧洲死了"，因为它把一个地区区间的一端提升为一块大陆。你必须拒绝"每个领主"，因为庄园是地方性的，而不自由没有在某一天消失。你必须拒绝"新时代开始了"，因为[[#thm-not-later]]把瘟疫当作文艺复兴或宗教改革的原因这件事挡了回去。一部编年史的教训不是一次人口普查。要把这句虚构的话提升为证据，将需要一个具名的史料、一个已知的作者，以及一个信任那个计数的理由。这句话一样也没有，而它被标为虚构，正是为了防止你去找它们。
:::
:::

:::example 两个真实的事件，并排放着 {#ex-pair}
把1315年与1347年10月并排。一个是北欧大部分地区大饥荒的开端。另一个是墨西拿对鼠疫的一条报告。它们之中，哪一个是一个死亡人数——如果有一个是的话？
:::solution
都不是。1315年为饥荒的开端定年，其跨度是1315–1317年，没有一个被锁定的死亡数字。1347年10月为一座港口的报告定年，那是一场灾变的见证，不是一次人口普查。把它们并排放，显示的是32年的间隔与种类的差别。饥荒是跨歉收的匮乏。这条报告是瘟疫的消息。把两者折叠进"十四世纪的死亡人数"，是在史料能够回答的形式里，回答一个不曾向史料提出的问题。
:::
:::

- [x] 不。它们相隔一代人，而本图谱不把其中一个当作另一个的原因
- [ ] 不，因为饥荒被定年在墨西拿之后
:::solution
饥荒始于1315年，而报告是1347年10月。已过计数是32年。共享一个世纪不是一个原因。饥荒没有被定年在墨西拿之后。更晚的瘟疫波次跟在1348年与1349年之后，但它们的年份没有被锁定，而它们也不是饥荒。
:::
:::

移动年份，看哪些点共享这个窗口。1315年的饥荒与1347年的报告相隔32年，所以一个宽四年的窗口装不下它们两个。1347年、1348年与1349年的点是一次抵达与一次蔓延，不是三个死亡总数。更晚的几波没有点，因为它们的年份没有被锁定。一段空白是拒绝发明一个日期，不是一个什么都没有发生的论断。

:::warning 半个欧洲
人们重复的那句话是半个欧洲死了。它之所以失败，是因为"大约二分之一"是许多经过研究的地区的一个区间的上端，不是对那块大陆的一次测量，而且因为有些地方另有不同。重复那句话不会让缺失的人口普查出现。它只会让一个谨慎的区间听起来像一个大胆真相的怯懦版本。大胆的那个版本，正是证据承载不动的那个。
:::

:::history
1347年10月，鼠疫在墨西拿被报告。1348年与1349年，它已在西欧的大部分地区。史家为许多经过研究的地区发表的估计，落在人口的约三分之一与约二分之一之间，而它们不是一个单一的欧洲死亡总数。
:::

把"大约"这个词留在那些分数上，并把欧洲留在虚构城镇之外。见证人——史料汇编所能聚集的那类——告诉你人们说自己看见了什么。他们相加，凑不成谚语想要的那个整数。一个与那条带不同的地方，[[#thm-no-total]]本来就是允许的。只有当许多经过研究的地区坐在带外，或者一次真的人口普查取代了它，这条论断才需要被改写。为了保一句顺溜的句子而藏起一个差别，那才是回避。使用有些地方另有不同的那个从句，则不是。

## 通向何处

下一章，[[crises/war-and-schism]]，接过的是一场战争——当墨西拿报告瘟疫时，它1337年惯例性的开端已经过去——以及一次始于1378年的教皇分裂。那些是权威与税收的危机。它们不是由一个死亡人数引起的情绪。[[crises/city-states]]将拒绝大规模死亡产生了人文主义这一进一步的论断。[[reformations/luther]]是1517年的去处，而它不是你可以从一个分数上读出来的结果。如果你需要重新用这个方法，[[sources/scale]]是那里的一个为真的地方事实被阻止变成一个虚假的大陆事实的地方，而[[sources/evidence]]是报告保持为报告的地方。

:::summary
- 大饥荒始于1315年，在北欧的大部分地区延续到1317年。它没有一个被锁定的死亡总数。
- 从1315年到1347年10月的墨西拿报告是32年。两场灾变相隔一代人。
- 1348年与1349年是蔓延过西欧大部分地区的那些年份。其后又有数波，本图谱不为它们发明年份。
- 在许多经过研究的地区，估计落在大约三分之一与大约二分之一之间，而有些地方另有不同。没有一个欧洲总数。
- "半个欧洲死了"把那个区间的顶端提升为一块大陆。它正是本章为阻止它而存在的那句话。
- 劳动、地租与宗教归咎——包括对某些犹太社区的攻击——是后果。它们不是宗教改革或文艺复兴，也不是一个欧洲议价。
- 一座虚构的城镇可以用来把三分之一与二分之一区分开。它的余数不得被带出去当作一个大陆结果。
:::

## 习题

:::exercise 年份的间隔 {level=1 check="32"}
饥荒始于1315年。鼠疫于1347年在墨西拿被报告。从1315年到1347年的已过计数是多少年？（请输入年数。）
:::solution
本图谱把从A年到B年算作B减A。1347减1315是32。年数是32。那个32是一场饥荒与一条报告之间的间隔。它不是一个死亡人数，也不是一个原因。
:::
:::

:::exercise 报告的年份 {level=1 check="1347"}
鼠疫在哪一年在墨西拿被报告？（请输入年份。）
:::solution
报告是1347年10月。年份是1347。十月定住了那一年里面的月份。它没有把报告变成人口普查，也没有为更晚的诸波定年。
:::
:::

:::exercise 蔓延不是比率 {level=1 check="2"}
从1347年到1349年的已过计数是多少年？（请输入年数。）
:::solution
1349减1347是2。年数是2。那两个年份就是本图谱为穿过西欧大部分地区的蔓延定年的方式，包括中间的1348年。2年宽不是人口的一个分数。
:::
:::

:::exercise 失去三分之一之后 {level=2 check="400"}
一座虚构的城镇有600人。它失去三分之一。留下多少人？（请输入人数。）
:::solution
那座城镇是虚构的，所以600是一个教学数字，不是史料。600的三分之一是200。600减200是400。留下的人数是400。不要把200叫作欧洲死亡总数。不要把400叫作欧洲。
:::
:::

:::exercise 然后是余数的一半 {level=2 check="200"}
同一座虚构的城镇，在前一道习题的损失之后，剩下400人。它现在失去余数的一半。留下多少人？（请输入人数。）
:::solution
400的一半是200。400减200是200。留下的人数是200。这个200不同于第一步之后留下的400。两个结果才是这道习题的要点。它们仍然不是历史上的那个区间，区间是一条跨地区的带，不是对一座虚构城镇的两击。
:::
:::

:::exercise 抓住那句伪造的话 {level=2}
这句话是虚构的。"1349年，半个欧洲死了，这引起了宗教改革。"把它改写成一句本图谱会接受的句子。你不需要一个单独的数字。
:::solution
一句可接受的句子留在锁定的事实之内。1349年，瘟疫在西欧的大部分地区，正如在1348年，在1347年10月的墨西拿报告之后。在许多经过研究的地区，估计落在人口的约三分之一与约二分之一之间，而有些地方另有不同。没有一个欧洲总数，所以"半个欧洲死了"被拒绝。那些论纲定年为1517年10月31日，距1349年已过计数168年，而[[#thm-not-later]]拒绝瘟疫作为它们的原因。一个可用的改写是："1349年，瘟疫在西欧的大部分地区；地区估计常常落在大约三分之一与大约二分之一之间，有些地方另有不同，而这不是宗教改革的原因。"
:::
:::

:::exercise 对那条带取平均 {level=3}
一个作者说：三分之一是一端，二分之一是另一端，所以欧洲失去了约十二分之五，那两个分数的平均。解释为什么这个平均并不是对二分之一那个迷息的改进。什么会真正构成对[[#thm-no-total]]的反驳？
:::hint
问那两个分数是不是对一个人口的两次测量。然后问"许多"这个词，以及关于有些地方另有不同的那个从句，本来已经允许什么。
:::
:::solution
三分之一是4/12，二分之一是6/12。它们的平均是5/12，约十二分之五。那看起来像是谨慎，而它仍然是一个欧洲总数。那两个分数不是对一块大陆的两次读数。它们是为许多经过研究的地区报告的一条带的两端。对两端取平均发明了一个没有任何普查记录过的精确，而且它抹去了有些地方另有不同的那个从句。它是单个数字的迷思换了一身干净衣服。会构成对[[#thm-no-total]]之反驳的，是一次真正的瘟疫前与瘟疫后的欧洲普查，或者是许多经过研究的地区落在那条带之外的证据。一个落在带外的地方是本来已经料到的。一个平均不是那个证据。它是对措辞做的算术。
:::
:::

:::exercise 一个另有不同的地方 {level=3}
假设一个真实的地区——不是虚构的城镇——有一天被证明失去了约十分之一，而另一个失去了约三分之二。一个批评者说[[#thm-no-total]]失败了。它失败了吗？说出什么进一步的结果会迫使你改写这条论断。
:::hint
看量词"许多"，以及"有些地方另有不同"这几个字。然后分开这条论断本来就允许的差别与会打破它的差别。
:::
:::solution
单凭那两个地区，它没有失败。[[#thm-no-total]]说的是：在许多经过研究的地区，估计落在大约三分之一与大约二分之一之间，而且有些地方另有不同。十分之一与三分之二是第二个从句所说的那类差别。它们只有在证明自己是典型时才会成为改写这条论断的理由，也就是说，如果许多经过研究的地区坐在带外，或者如果有人产出了一个能取代那个区间的真正的欧洲总数。在那之前，举出一个损失陡峭的地方和一个较缓的地方，是使用这条论断的方式，不是打破它的方式。虚构的城镇连这点都做不到：一个虚构的十分之一不是一项研究。批评者的错误，是把一条带有明文例外的区间当作一个普适的分数。
:::
:::
