印刷术改变了什么，又没有引起什么？

它改变了书籍的制造。一种必须用手抄写的文本，一旦活字排定，就能在一台印刷机上成倍复制，在集市上出售，而最终仍然由一只手添上首字母与色彩来完工。它单凭自身，没有引起宗教改革。古腾堡（Gutenberg）印制的《圣经》通常定年为约1454–1455年。没有哪一天。论纲定年为1517年10月31日，而那场争吵属于[[reformations/luther]]。从1454年到1517年，已过的跨度是63年；从1455年到1517年，是62年。两种读法都是大约两代人，而在一个五年的窗口里，两者谁也不是对方的邻居。新行当印刷的东西，大多数不是新哲学。要紧的是赎罪券与课本。手抄本文化继续存在。一项技术可以改变速度与价格，却仍然不是后来一种学说的作者。

上一章把印刷机留在君士坦丁堡的陷落旁边，并拒绝把两者变成一个原因。本章保留这份拒绝，并改变问题。[[crises/city-states]]把人文主义定义为一种拉丁语、学校教育与文书署的实践，早在1453年5月29日之前它就已经在进行。印刷机可以用同一副螺丝，把一部人文主义语法书和一部礼仪书成倍复制。成倍复制对于文本是否新颖无动于衷。正是这种无动于衷，是那些关于公众舆论的迷思无法存活的那个事实。

## 一部没有确定一天的《圣经》

:::definition 印刷术 {#def-print}
**印刷术**，在本课里，是用活字和一台印刷机制造文本的做法，而在这样一间印刷所里，它还依赖于纸、墨水、校对者与买主。它不是新思想的同义词，也不是某个人一生之中的某一天。
:::

通常定年为约1454–1455年的那部《圣经》是一部拉丁语《圣经》，一种教会已经持有、已经在读的文本。印刷它，并没有向正典添上一部书，而是添上了复制本。通常的定年是一个约两年的区间，不是一则本图谱愿意视为已定的题记。不要发明一天。也不要折中，把1月1日称作一种妥协。一个妥协的日子仍然是一个发明。古腾堡这个名字，是挂在那部《圣经》上的名字。他的生与死在这里没有锁定，所以不给。印刷所才是那个单位：活字、一台印刷机、能够在金属上着墨的墨水，以及在一张纸卖出之前买纸的钱。合伙人与债主属于那个单位。一场诉讼的年份没有锁定，因此绝不能把1455年悄悄挪用作一场法庭争吵的日期。在本课里，1455年只是《圣经》通常区间的末端。

美因茨（Mainz）可以被指认为那项工作所在之城。但指认一座城，并不是主张这项发明有一个生日，也不是主张别的印刷所无足轻重。在年表允许我们讲的任何一个故事里，纸都比这部《圣经》更古老。印刷机没有发明纸张。它只是比一个抄写员填满更多的纸张。那句话就是本章需要的全部技术论断。它不需要一个纸张的清点。年表没有锁定任何书籍的清点，所以一个也不说。从另一本书抄来的一个听起来很大的整数，将是一个与欧洲疫病总数同族的虚假精确。出于同样的理由拒绝它。

:::theorem 成倍复制不是宗教改革 {#thm-not-cause}
印刷术成倍复制文本，改变复制本能够制成的速度，并且能够改变价格。它建造诸行当。它单凭自身，没有引起宗教改革。论纲定年为1517年10月31日，在约1454–1455年的那部《圣经》之后大约两代人。
:::
:::proof
关于印刷术改变什么，证据就是印刷所本身。一旦活字排定，再制一个复制本就是与逐行手写不同的一种劳动。速度随这个差别而来，作为一个方向，而不是作为一份本图谱已经锁定的计时记录。随着复制本增多，价格可以下落，而再次，方向就是论断。没有一笔用里夫尔或英镑记下的钱被锁定，所以一笔也不写。诸行当跟着机器而来：铸字工、印刷工、造纸工、校对者、赶车人、集市上的摊主。反对宗教改革之原因的证据，是那段差距与产出的内容。从《圣经》区间的任何一端到1517年是63年或62年，而那幅图五年的窗口装不下两者。在那几十年里，印刷机成倍复制着一部教会已经在使用的拉丁语《圣经》、为[[#def-print]]并没有发明的拉丁语而设的课本，以及赎罪券。印刷出来的大多数东西不是一种新哲学。能够反驳[[#thm-not-cause]]的，是以下证据：1517年的争吵没有印刷就不可能发生，并且印刷机的平常工作就已经是那场争吵。后半句在赎罪券与课本上站不住。前半句是一个反事实。手抄本文化已经承载文本好几个世纪了——[[christendom/towns-and-learning]]正是摆在那里用来提醒这一点的——而它在1455年之后继续存在。一个后来帮助一种文本流传的条件，单凭自身，并不是那种文本的论证的原因。
:::

反对意见正是一位认真的读者会提出的那一个，它值得一份认真的答复。论纲流传了。一旦活字排定，纸上的流传更容易。于是读者说：印刷术引起了宗教改革。毛病在这个“因此”。一种使复制更快的手段，可以在后来的一场争吵中要紧，却仍然不是那场争吵。如果成倍复制本身就是在改革，那么约1454–1455年的那部《圣经》就已经是与罗马的决裂了。它是一部拉丁语《圣经》。印刷机还成倍复制了赎罪券，正是后来那场争吵所攻击的形式。一台既服务于那个形式、又服务于对那个形式的攻击的机器，不站在某一边。[[reformations/luther]]将给论纲定年，将说出关于教堂门哪些尚未确立，并把赎罪券保留为那场争吵的导因，而不是把它画成一座再无别的生活的教会的漫画。本章绝不能提前讲那个故事，也绝不能把那座门当作事实来讲。那座门没有确立。1517年10月31日这个日期确立了。

## 诸行当实际生产了什么

:::definition 平常的印刷 {#def-ordinary}
**平常的印刷**是印刷所工作的主体：赎罪券、课本、礼仪书、语法书、历书，以及诸机构本来就想要的拉丁语文本。**赎罪券**，在本课里，是一种陈述一项灵性惠益的印刷表格。在本章里，它不是后来那场批评的全部，也不是一摞纸张的清点。
:::

课本是与人文主义之间的铰链。一部古典拉丁语语法书，是[[crises/city-states]]所描述的那种教育的工具：导师、男孩，以及一张文书署的凭证。印刷机能够以使那件工具更便宜地获得的方式——即已经说过的方向上的意义——改变它，而不成为课程的作者。课程是一种模仿的实践。印刷机是一种成倍复制的实践。把它们混为一谈，正是一部技术史吞掉一部教学史的方式。大体被排斥在那种学校教育之外的妇女，不会因为印刷机的存在而被准入其中。一项技术不会纠正一种它并未设计的社会排斥。没有一份女性读者的清点被锁定，所以一个也不给。

赎罪券从另一面显示同一种分裂。在成为一种印刷表格之前，它们是一项牧灵与财政的工具。印刷它们使它们更容易成倍复制。它没有发明那种神学，也没有反驳那种神学。当赎罪券在1517年成为一场公开争吵的导因时，印刷机处在背景之中，作为制造表格的手段，后来又作为制造论证的手段。背景是正确的深度。一位读者如果从《圣经》开始这个故事、到论纲结束它，就跳过了那些平常的十年——在那十年里，印刷机正忙着教会自己的文书。那些十年就是印刷术与改革不是一个事件这一点的证据。

集市与诸行当同列。布匹与其他货物早就在集市上买卖。书籍加入了集市所能出售的行列。本图谱没有为一个书市锁定一个特许年份，所以一个也不给。点名集市的要点是商业的，不是城市的。一个买不起纸的印刷匠不能成倍复制一种文本，无论那种文本的思想多么紧迫。资本先于名声坐在印刷所里。这既是对孤独的发明家这一迷思的约束，也是对突然出现的公众这一迷思的约束。发明家，就一个名字站得住的限度而言，是一间有一部《圣经》可展示的印刷所。公众，在1455年，是那部《圣经》与更卑微的工作的一群买主与读者。它还还不是一个关于教会的、组织起来充当一个原因的意见。

手抄本文化继续存在，而这正是应当让“革命”这个词卡在喉咙里的事实。唱经本、题献本、特许状与行政文书平常的潦草笔迹，不会因为活字存在就停下来。许多印本仍然要由手工收尾。一页可以印好之后再敷彩。两种工艺共用一张书桌。任何在1455年横下一堵墙、一边放手抄本、另一边放印刷品的人，都是把一个定年区间的末端当成了一个文化的末端。能够反驳手抄本继续存在这条论断的，是一个有日期、普遍、此后手抄停止的断点。本图谱没有这样的断点。手抄书籍在《圣经》的区间之后存留是平常之事，它是针对每一句把1455年说成最后一个中世纪年度的话的反证据。

## 一份演练过的清单，与那个窗口

取一份虚构的印刷匠清单。它是虚构的，而且上面没有任何数字，因为一个数字就是年表所拒绝的那种清点。清单如下：一部拉丁语《圣经》，一部语法书，一摞赎罪券表格，一部历书。把这份清单放在“印刷术创造了新哲学”这条论断旁边。《圣经》是旧的。语法书教一门旧语言，无论模仿多么新。赎罪券陈述一项教会本来就提供的惠益。历书给一年排定次序。四项之中，没有一项是第一次出现的思想体系。这份清单是平常印刷的一幅公允图画，而禁止把它提升为美因茨一家具名商号的档案。一份真实的财产清单会有数量和一个日期。这一份是一个教学用具。它没有一个整数，是刻意的。

现在把同一份清单放在1517年旁边。清单上没有一项蕴含那些论纲。一间印刷所可以把清单上的每一项都印出来，而终生遇不到一位改革者。一位改革者可以在两代人之后使用印刷机，包括仍在印赎罪券的印刷机。已过的跨度62与63，是“不是单凭自身”的数量形式。那幅图不用做这道减法也在说同一个意思——如果你把窗口保持在五年，并试图同时看见《圣经》与论纲的话。你做不到。图注说五年的窗口装不下两者。相信图注，然后把这道减法做一遍，使你不至于信任一幅你没有检验过的图。

:::example 窗口装不下的那段差距 {#ex-gap}
《圣经》通常定年为约1454–1455年。论纲定年为1517年。计算从区间两端分别到1517年的已过跨度。一个五年的窗口装得下印刷机与论纲两者吗？
:::solution
1517减1454是63。1517减1455是62。两个跨度都远大于五，所以无论你从《圣经》区间的哪一端出发，五年的窗口都装不下两者。两个跨度相差一年，因为《圣经》的定年是一个区间。那个差别是说出“约”字的理由，不是发明一天的理由——那样一天会让你挑出一个单一整数，把不确定性藏起来。62与63既不是书籍的清点，也不是原因。
:::
:::

:::example 一个发明出来的日子 {#ex-day}
这则题记是虚构的：“于1455年1月1日在美因茨完工，此即印刷术创造公众舆论的那一天。”既然1455年是《圣经》区间里的一个真实年份，它错在哪里？
:::solution
1455年在通常区间之内，这正是伪造诱人的原因。但那一天，1月1日，没有锁定。一个落在真实区间里面的日期，如果那一天本身从未确立，就仍然是一个发明的日子。那个因果子句更糟。印刷术没有在1455年创造公众舆论，而[[#thm-not-cause]]也拒绝把印刷机当作一场宗教改革的原因——那场宗教改革即便从区间的末端算起，也还在62年之外。一则真实的题记，倘若有一则被锁定，会为一部书定年，不会为一种意见定年。那句话被标为虚构，正是为了让真实的年份不至于为虚假的日子洗白。
:::
:::

:::example 平常的工作 {#ex-list}
章中那份虚构的清单点出一部拉丁语《圣经》、一部语法书、赎罪券表格与一部历书，而且没有给出数量。为什么数量的缺席是功课的一部分？读者会错误地把哪一项称为宗教改革？
:::solution
年表没有锁定一份书籍的清点，所以一个发明的数量会教人一种虚假精确。这份清单能够显示工作的种类，而不自命为一份财产清单。诸项之中没有一项是宗教改革。读者会错误地提升的那一项是赎罪券，因为赎罪券是1517年论纲的导因。后来的导因不是此刻的原因。印刷一种陈述灵性惠益的表格，是在成倍复制教会已经有的一项实践。它并没有打开[[reformations/luther]]。
:::
:::

:::example 城市、印刷机、论纲 {#ex-three}
把三个锁定的日期排成次序：1453年5月29日，《圣经》的区间约1454–1455年，以及1517年10月31日。哪几对是邻近的？哪一对正是诸迷思压平的那一对？
:::solution
君士坦丁堡的陷落与《圣经》区间的开端是邻近的：1454年是1453年的下一年。邻近不是原因，这既是上一章的要点，也是本章的要点。《圣经》与论纲并不邻近。已过跨度从1454年算是63年，从1455年算是62年。迷思把印刷机压平进论纲，有时还把那座城压平进印刷机，仿佛一个十年诞生了近代。三个日期的次序就是纠正。一场征服、一部印刷所的《圣经》、一场关于赎罪券的更晚的争吵，是三个事件。手抄本在它们全部之中继续存在。
:::
:::

:::quiz

- [ ] 它只印刷新哲学。
- [x] 它单凭自身没有引起宗教改革，也没有在1455年创造公众舆论。
- [ ] 它对书籍的速度或价格没有影响。
:::solution

:::warning 1455年的公众舆论
要拒绝的那句话是：印刷术在1455年创造了公众舆论。它把一部《圣经》定年区间的末端拿过来，把它变成近代政治的生日。一个在印刷品上就学说争论的公众，是一件更晚而局部的事，而即便到那时也不是每一个人。在1455年，印刷机有着一部拉丁语《圣经》与一系列行当的开端。它没有议会，没有宗教改革，也没有一份读者普查。手抄本继续存在，这就足以挡住那一横这一年的墙。
:::

:::history
古腾堡印制的《圣经》通常定年为约1454–1455年，没有哪一天得到确立。1453年5月29日，穆罕默德二世（Mehmed II）攻取君士坦丁堡，比那个区间的开端早一年。论纲定年为1517年10月31日。印刷机成倍复制文本。它单凭自身没有引起宗教改革。
:::

最后的一个区别，使本章不至于变成一场反对技术的布道。印刷术确实改变了某种真实的东西。一个买得起语法书的学生，一个买得起礼仪书的教区，一个带得动一摞表格的讲道者：其中的每一项都是一种文本可得性的变化。可得不是认同。同一张印页的两位读者，可以停留在后来一场争吵的相反两边，而那张纸并没有造成他们中的任何一边。那份演练过的清单摆在那里，是为了让你感到这个变化多么平常。平常不等于渺小。它是神奇的反面。奇迹故事，是说一台机器会思考的那个故事。印刷所的故事，是人们排字、买纸、校对一张印页、并把它摆在布匹旁边出售的那个故事。留住第二个故事，年份会做完其余的事。

## 通向何处

[[crises/year-1492]]是这幅图压缩成“格拉纳达与大洋”的那个圆点。印刷机不解释那一年，那一年也不解释印刷机。[[reformations/luther]]是1517年10月31日被好好教授的地方，包括哪些尚未确立。[[crises/city-states]]是印刷机能够成倍复制、却没有发明的那种文字实践。[[christendom/towns-and-learning]]是那个不在本课拒绝发明的日子里终结的手抄本世界。[[sources/argument]]是那个方法：一个原因必须是那种本可别样的东西，而一个像“印刷革命”这样的标签，打包了一条关于公众舆论的、[[#thm-not-cause]]不肯签署的论断。

:::summary
- 古腾堡《圣经》通常定年为约1454–1455年。没有哪一天，也没有一份锁定的书籍清点。
- 印刷术用活字与印刷机成倍复制文本，并建造纸、活字、校对与集市诸行当。价格与速度能够变化。没有陈述任何一笔钱。
- 那部《圣经》的文本是一部教会已经持有的拉丁语《圣经》。成倍复制既不是一个新正典，也不是一次翻译。
- 印刷出来的大多数东西是平常的：赎罪券、课本、礼仪书、历书。新哲学不是主体。
- 手抄本文化继续存在。一张印页仍然可以由手工收尾。1455年不是一堵墙。
- 论纲定年为1517年10月31日，从1454年算的已过跨度是63年，从1455年算是62年。印刷机单凭自身没有引起宗教改革。
- 印刷术没有在1455年创造公众舆论。一个更快的复制本不是一种意见。
:::

## 习题

:::exercise 从区间的开端算 {level=1 check="63"}
从1454年到1517年，已过的跨度是多少年？（请输入年数。）
:::solution
1517减1454是63。年数是63。《圣经》的通常定年是一个区间，所以这个跨度是从区间的开端算的，不是从某一天算的。它不是复制本的清点，也不是原因。
:::
:::

:::exercise 从区间的末端算 {level=1 check="62"}
从1455年到1517年，已过的跨度是多少年？（请输入年数。）
:::solution
1517减1455是62。年数是62。把这个跨度与63一起使用，而不是代它而用。相差一年，是“约1454–1455年”这个区间的宽度。拒绝一个单一的日子，就是保住两个跨度。
:::
:::

:::exercise 一个只是区间末端的年份 {level=1 check="1455"}
古腾堡《圣经》通常区间的后一端是哪一年？（请输入年份。）
:::solution
通常区间是约1454–1455年。后一端是1455年。不要给它安上某一天。不要把它变成公众舆论被创造的那一年。不要把它变成一场本图谱没有锁定的诉讼的年份。在本课里，它只是《圣经》区间的末端。
:::
:::

:::exercise 种类，不是册数 {level=2}
说出本课当作平常印刷的四种文本，并说出本课为什么不给出其中任何一种的数量。
:::solution
一部拉丁语《圣经》、课本或语法书、赎罪券，以及历书或礼仪书，就是章中点名的平常种类。本课不给数量，因为年表没有锁定一份书籍的清点。一个看起来精确的总数会是一种虚假精确。种类就足以表明大部分工作不是新哲学，而这正是[[#def-ordinary]]存在所要托住的那条论断。
:::
:::

:::exercise 什么在继续 {level=2}
一位同学在1455年处画一条线，说手抄在那里结束。本课里面的什么证据回答那条线？而对你答案的一次真实反驳必须显示什么？
:::solution
手抄本文化继续存在：特许状、唱经本、题献本，以及印页的手工收尾，包括首字母与色彩。那条线把一个定年区间的末端当成一项技术的末端。一次真实的反驳将是一个有日期的、普遍的停止，此后手抄停止。本图谱没有这样的停止。那位同学的线，正是[[#thm-not-cause]]在说手抄本在1455年之后继续存在时所拒绝的那堵墙。
:::
:::

:::exercise 识破那则题记 {level=2}
那则题记是虚构的：“成于1455年1月1日，近代公众诞生之日。”用四个简短的步骤，把真实的碎片同虚假的碎片分开。
:::solution
第一，1455年是一个真实的年份，《圣经》通常区间的后一端。第二，1月1日不是一个锁定的日子，所以它作为事实是假的，尽管它坐在一个真实的年份里面。第三，“近代公众诞生了”是印刷术在1455年创造了公众舆论这个迷思，而注意块拒绝了它。第四，真实的年份并不证实那一天，也不证实那个诞生。一则真实的题记仍然只会为一部书定年。虚构的那则是这样造的：让一个真实的年份来伪装两处添加。
:::
:::

:::exercise 认真的反对意见 {level=3}
一位读者承认[[#thm-not-cause]]里的每一个日期，仍然说：论纲流传了，印刷使流传成为可能，因此印刷引起了宗教改革。“因此”错在哪里？什么才会真正反驳这条论断？
:::hint
把一个能够帮助一种文本流传的手段，与那种文本所作的论证分开。然后看一看印刷机在过去大约两代人里一直在成倍复制什么，包括赎罪券。
:::
:::solution
毛病在于从一个手段到一个原因的跳跃。印刷机能够使复制更快，更快的复制能够在1517年要紧，而印刷机仍然不是那场争吵的作者。如果成倍复制本身改革了教会，那么约1454–1455年的那部拉丁语《圣经》就已经是决裂了。它不是。同一批行当成倍复制了赎罪券——那个后来受到攻击的形式——而对于一个据说只站在一边的原因，这是一个奇怪的形状。手抄本已经承载论证好几个世纪了。能够反驳[[#thm-not-cause]]的，是以下证据：那场争吵没有印刷就不可能发生，并且印刷机的平常产品就已经是那场争吵。平常的印刷——课本与赎罪券表格——通不过第二个检验。已过62年或63年的跨度，使那种把差距藏进“因此”一词的企图落空。
:::
:::

:::exercise 没有数目的价格 {level=3}
本课说印刷能够改变一部书的价格，而它没有陈述任何一笔钱。为什么这份沉默是必需的？一个方向怎么仍然可以是一条论断？哪一句额外的话，会把那个方向变成公众舆论的迷思？
:::hint
问一问年表关于钱锁定了什么。再问一问：一个买主是什么，同一个分享一种学说的公众相对？
:::
:::solution
没有锁定任何一个价格，无论以里夫尔还是以英镑，所以一个数字将是一个发明。一个方向仍然可以是一条论断：一旦活字排定，更多的复制本就是一种不同于手写的劳动，而一种文本可以变得更容易获得。更容易获得不是免费，也不是普遍。一部语法书的买主不是一种公众舆论。会把那个方向变成迷思的那句额外的话，是任何一个把一种共享的近代政治定年于1455年的句子，或者把一部更便宜的书当作对一种学说的认同的句子。[[#thm-not-cause]]允许价格的变化，而拒绝那种认同。一本锁定的、带着真实数目的账簿，会让未来的某一课说出一个价格。它仍然不会说出一种意见。
:::
:::
