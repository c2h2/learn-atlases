印刷术改变了什么？又没有引发什么？

它改变了书籍的制作方式。原本必须手抄的文本，一旦排好活字，就可以在印刷机上大量复制，拿到集市上出售，而最后仍要由手工添上首字母和色彩来完成。它本身并没有引发宗教改革。古腾堡（Gutenberg）印制的《圣经》通常定于约1454–1455年，没有具体日期。论纲的日期是1517年10月31日，那场争论属于[[reformations/luther]]的内容。从1454年到1517年经过了63年，从1455年到1517年则是62年。无论哪种算法，都相隔大约两代人，在五年宽的窗口里，两者都不可能相邻。新兴行业印刷的东西，大多不是新哲学，重要的是赎罪券和课本。手抄本文化仍在延续。一项技术可以改变速度和价格，却仍然不是后来某种学说的作者。

上一章把印刷机放在君士坦丁堡陷落的旁边，并拒绝把两者当作同一个原因。本章保留这一拒绝，换一个问题。[[crises/city-states]]把人文主义界定为一种关于拉丁语、教育和文书院的实践，它在1453年5月29日之前早已开始。印刷机可以用同样的螺杆复制人文主义的语法书，也可以复制礼仪书。复制对文本新不新毫不在意。正是这种不在意，让那些关于公众舆论的迷思无法成立。

## 一部没有确切日期的《圣经》

:::definition 印刷术 {#def-print}
本课所说的**印刷术**，是用活字和印刷机制作文本，而印刷作坊还依赖纸张、油墨、校对者和买主。它不是新思想的同义词，也不是某个人一生中的某一天。
:::

通常定于约1454–1455年的那部《圣经》是拉丁文《圣经》，是教会早已拥有、早已在读的文本。印刷它并没有给正典增加一卷书，增加的只是副本。通常的年代是一个约两年的区间，而不是一份本图谱愿意视为定论的版本记录（colophon）。不要杜撰具体日期，也不要折中取个1月1日当作妥协。妥协出来的日子仍然是杜撰。古腾堡这个名字与这部《圣经》联系在一起。他的生卒年这里没有确定，因此不予给出。作坊才是基本单位：活字、印刷机、能附着在金属上的油墨，以及在卖出第一张纸之前买纸的资金。合伙人和债主也属于这个单位。某场诉讼的年份没有确定，所以不能悄悄把1455年挪用为法庭纠纷的日期。在本课中，1455年只是这部《圣经》通常年代区间的终点。

美因茨（Mainz）可以作为这项工作所在的城市提及。提到一座城市，并不是主张这项发明有个生日，也不是主张其他作坊无关紧要。在年表允许我们讲述的任何故事里，纸张都比这部《圣经》古老。印刷机没有发明纸张，它只是比抄写员印满更多的纸。这句话就是本章所需的全部技术论断，并不需要统计纸张数量。年表没有确定任何书籍数量，这里也不给出。从别的书里抄来一个听起来很大的整数，将是一种虚假的精确，与欧洲鼠疫死亡总数属于同一类。出于同样的理由，应当拒绝它。

:::theorem 复制不等于宗教改革 {#thm-not-cause}
印刷术大量复制文本，改变了制作副本的速度，也可能改变价格。它造就了新的行业。但它本身并没有引发宗教改革。论纲的日期是1517年10月31日，比约1454–1455年的《圣经》晚了大约两代人。
:::
:::proof
印刷术改变了什么，证据就在作坊本身。活字一旦排好，再印一份副本就是与逐行手抄性质不同的劳动。速度的提高源于这种差异，但这只是一种趋势，而不是本图谱确定的计时记录。随着副本增多，价格可能下降，论断说的同样只是趋势。这里没有确定任何以里弗尔或英镑计的金额，因此一笔也不写。行业随机器而来：铸字工、印刷工、造纸工、校对者、车夫、集市上的摊贩。反对把印刷术视为宗教改革原因的证据，是时间间隔和印刷品的内容。从《圣经》年代区间的两端到1517年，分别是63年和62年，图上五年宽的窗口容纳不下两者。在这几十年里，印刷机复制的是教会早已在用的拉丁文《圣经》，是为拉丁语教学编的课本（拉丁语并不是[[#def-print]]所发明的），还有赎罪券。印出来的东西大多不是新哲学。能够推翻[[#thm-not-cause]]的证据是：没有印刷术，1517年的争论就不可能发生，而且印刷机的日常工作本身就已经是那场争论。后一条在赎罪券和课本面前站不住；前一条则是反事实推断。手抄本文化已经承载文本好几个世纪，[[christendom/towns-and-learning]]正可以提醒我们这一点，而且它在1455年之后仍在延续。一个后来有助于文本传播的条件，本身并不是这一文本论证的原因。
:::

这一反驳正是认真的读者会提出的，因而值得认真回应。论纲流传开来；有了活字，纸上的流传更加容易；读者因此说，印刷术引发了宗教改革。问题出在“因此”上。一种让复制更快的手段，可以在后来的争论中很重要，却仍然不是那场争论本身。如果复制本身就意味着改革，那么约1454–1455年的《圣经》就已经是与罗马的决裂了。但它是一部拉丁文《圣经》。印刷机也大量复制赎罪券，而赎罪券正是后来那场争论所抨击的形式。一台既为这种形式服务、又为抨击这种形式服务的机器，并不站在任何一边。[[reformations/luther]]将为论纲定年，说明关于教堂大门的说法哪些尚无定论，并把赎罪券看作争论的契机，而不是把教会画成除此之外别无生活的漫画。本章不能提前讲这个故事，也不能把教堂大门的情节当作事实来讲。大门的说法并未确立，确立的是1517年10月31日这个日期。

## 这些行业实际印了什么

:::definition 日常印刷 {#def-ordinary}
**日常印刷**是作坊工作的主体：赎罪券、课本、礼仪书、语法书、历书，以及各种机构本来就需要的拉丁文文本。这里的**赎罪券**是一种载明某项属灵恩惠的印刷表格。在本章中，它不是后来那场批判的全部内容，也不是纸张的数量。
:::

课本是印刷术与人文主义之间的枢纽。一部古典拉丁语语法书，是[[crises/city-states]]所描述的那种教育的工具：家庭教师、男孩，以及进入文书院的资历凭证。印刷机可以让人更便宜地得到这种工具（就前面所说的趋势意义而言），却并不因此成为课程的作者。课程是一种模仿的实践，印刷是一种复制的实践。把两者混为一谈，技术史就吞没了教学史。妇女基本上被排斥在这种教育之外，印刷机的存在也没有让她们获准进入。一项技术不会纠正一种并非由它造成的社会排斥。这里没有确定女性读者的人数，因此不予给出。

赎罪券从另一个侧面显示了同样的区分。在成为印刷表格之前，它们就已经是一种牧灵和财政工具。印刷使它们更容易大量复制，却既没有发明这种神学，也没有驳倒它。1517年，赎罪券成为一场公开争论的契机，这时印刷机处在背景之中：它是制作表格的手段，后来也成为制作论证的手段。“背景”才是恰当的位置。如果读者从《圣经》讲起、到论纲结束，就跳过了那些平常的几十年——那时印刷机正忙于印制教会自己的文书。正是这几十年证明，印刷术与宗教改革不是同一件事。

集市也属于这些行业的世界。布匹和其他货物早就在集市上买卖，书籍加入了集市可以出售的商品之列。本图谱没有为任何书市确定特许年份，因此不予给出。提到集市，着眼点在商业而非城市政治。买不起纸的印刷商就无法复制文本，无论文本中的思想多么迫切。在作坊里，资本先于名声。这既约束了“孤独发明家”的迷思，也约束了“公众突然出现”的迷思。如果说可以用一个名字来指称发明者，那么它指的是一个能拿出一部《圣经》的作坊。1455年的“公众”，是这部《圣经》以及其他更寻常印刷品的买主和读者，还不是一种关于教会、并被组织起来成为原因的舆论。

手抄本文化仍在延续，这一事实应当让“革命”一词难以出口。唱诗本、呈献本、特许状和日常行政中潦草的手写文书，并不会因为有了活字就停止。许多印本仍要由手工完成，一页纸可以先印后绘，两种技术共用一张书桌。谁要是在1455年画下一道墙，一边是手抄本，一边是印刷品，就是把一个年代区间的终点当成了一种文化的终结。能够推翻“手抄本仍在延续”这一论断的，是一个有日期、普遍适用的终止点，此后手抄就不再进行。本图谱没有这样的终止点。《圣经》年代区间之后仍有手抄书存世，这是寻常之事，也反驳了一切把1455年说成最后一个中世纪年份的句子。

## 一份推演用的清单，以及时间窗口

设想一份虚构的印刷商清单。它是虚构的，上面也没有任何数字，因为任何数字都是年表所拒绝的那种统计。清单上写着：一部拉丁文《圣经》、一部语法书、一叠赎罪券表格、一部历书。把这份清单与“印刷术创造了新哲学”的论断对照。《圣经》是古老的；语法书教的是一门古老的语言，无论模仿得多么新；赎罪券载明的是教会早已提供的恩惠；历书安排一年的时序。四项中没有一项是首次出现的思想体系。这份清单公允地呈现了日常印刷，但不能被拔高为美因茨某家有名有姓的作坊的档案。真正的库存清单会有数量和日期，而这一份只是教学道具，它没有任何整数是有意为之的。

现在把同一份清单与1517年对照。清单上没有任何一项必然导向论纲。一个作坊可以印出清单上的每一样东西，却从未遇到一位改革者；而两代人之后，一位改革者也可以使用印刷机，包括仍在印赎罪券的印刷机。经过的年数62和63，就是“它本身并没有”的量化形式。如果把窗口保持在五年，并试图同时看到《圣经》和论纲，那么不做减法，这幅图也在说明同样的道理：你做不到。图注说窗口容纳不下两者。相信图注，然后再做一遍减法，这样你就不是在相信一幅未经检验的图。

:::example 窗口容纳不下的间隔 {#ex-gap}
《圣经》通常定于约1454–1455年，论纲定于1517年。分别计算从这个区间两端到1517年经过的年数。五年宽的窗口能同时容纳印刷机和论纲吗？
:::solution
1517减1454是63，1517减1455是62。两个数都远大于五，所以无论从《圣经》年代区间的哪一端算起，五年宽的窗口都容纳不下两者。两个数相差一年，是因为《圣经》的年代是一个区间。这一差异是说“约”的理由，而不是杜撰一个日期、好让你挑出单一整数并掩盖不确定性的理由。62和63都不是书籍数量，也都不是原因。
:::
:::

:::example 一个杜撰的日子 {#ex-day}
这份版本记录是虚构的：“1455年1月1日完成于美因茨，即印刷术创造公众舆论之日。”既然1455年是《圣经》年代区间中的真实年份，这句话错在哪里？
:::solution
1455年在通常的年代区间之内，这正是这件伪作诱人之处。但1月1日这个日子并没有确定。一个日期即使落在真实的区间之内，如果这一天本身从未确立，就仍然是杜撰的。因果分句更糟。印刷术并没有在1455年创造公众舆论；[[#thm-not-cause]]也拒绝把印刷机当作宗教改革的原因，而即使从区间的终点算起，宗教改革也还在62年之后。一份真实的版本记录，如果有确定的话，会为一本书定年，而不会为一种舆论定年。这句话被标明虚构，就是为了不让真实的年份替虚假的日子洗白。
:::
:::

:::example 日常的工作 {#ex-list}
本章那份虚构的清单列出了一部拉丁文《圣经》、一部语法书、赎罪券表格和一部历书，但没有给出数量。为什么没有数量也是本课内容的一部分？读者会错把哪一项当作宗教改革？
:::solution
年表没有确定任何书籍数量，所以杜撰一个数量就是在传授虚假的精确。这份清单可以展示工作的种类，而不必冒充库存清单。其中没有一项是宗教改革。读者最容易错误拔高的是赎罪券，因为赎罪券是1517年论纲的契机。但后来的契机不是当时的原因。印刷一种载明属灵恩惠的表格，是在复制教会早已有之的一种实践，并没有开启[[reformations/luther]]的故事。
:::
:::

:::example 城市、印刷机与论纲 {#ex-three}
把三个已确定的日期按顺序排列：1453年5月29日，《圣经》的年代区间约1454–1455年，以及1517年10月31日。哪两者相近？迷思把哪两者混为一谈？
:::solution
君士坦丁堡陷落与《圣经》年代区间的起点相近：1454年是1453年的下一年。但相近不等于原因，这既是上一章的要点，也是本章的要点。《圣经》与论纲并不相近：从1454年算起是63年，从1455年算起是62年。迷思把印刷机与论纲混为一谈，有时还把君士坦丁堡与印刷机也混在一起，仿佛一个十年就诞生了现代。三个日期的先后顺序就是纠正。一次征服、一个作坊印制的《圣经》、一场后来关于赎罪券的争论，是三件不同的事。手抄本在这一切之中始终延续。
:::
:::

:::warning 1455年的公众舆论
要拒绝的说法是：印刷术在1455年创造了公众舆论。这种说法把一部《圣经》年代区间的终点，变成了现代政治的生日。一个借助印刷品争论教义的公众，是更晚出现的、局部的现象，即使到那时也并非人人参与。1455年，印刷机拥有的是一部拉丁文《圣经》和一系列行业的开端，而没有议会，没有宗教改革，也没有读者普查。手抄本仍在延续，这就足以拆掉横亘在这一年的那堵墙。
:::

:::history
古腾堡印制的《圣经》通常定于约1454–1455年，没有确定的具体日期。1453年5月29日，即这个区间开始的前一年，穆罕默德二世（Mehmed II）攻占君士坦丁堡。论纲的日期是1517年10月31日。印刷机大量复制文本，但它本身并没有引发宗教改革。
:::

最后还有一个区分，免得本章变成一篇反对技术的说教。印刷术确实改变了某种真实的东西。一个买得起语法书的学生，一个买得起礼仪书的教区，一个带得动一叠表格的布道者：每一种情形都是文本可得性的变化。但可得不等于认同。同一张印页的两位读者，可以在后来的争论中站在对立的两边，而这张纸并没有造成其中任何一方的立场。那份推演用的清单，是为了让你感受到这种变化有多么平常。平常不等于微小，而是神奇的反面。神奇的故事里，是一台机器在思考；作坊的故事里，是人们排字、买纸、校对印页，再把它摆在布匹旁边出售。留住第二个故事，剩下的就交给日期。

## 通向何处

[[crises/year-1492]]就是图上被压缩为“格拉纳达与大洋”的那个圆点。印刷机解释不了那一年，那一年也解释不了印刷机。[[reformations/luther]]会恰当地讲授1517年10月31日，包括哪些说法尚未确立。[[crises/city-states]]讲的是印刷机能够复制却并未发明的文字实践。[[christendom/towns-and-learning]]讲的是手抄本世界，它并没有在本课拒绝杜撰的那一天终结。[[sources/argument]]提供了方法：一个原因必须是本可能不发生的那类事情；而“印刷革命”这样的标签，捆绑了一个关于公众舆论的论断，[[#thm-not-cause]]不会为它背书。

:::summary
- 古腾堡《圣经》通常定于约1454–1455年，没有具体日期，也没有确定的书籍数量。
- 印刷术用活字和印刷机大量复制文本，造就了造纸、铸字、校对和集市贸易等行业。价格和速度可能发生变化，但这里不给出任何金额。
- 这部《圣经》的文本是教会早已拥有的拉丁文《圣经》。大量复制既不是新的正典，也不是翻译。
- 印出来的东西大多是日常印刷品：赎罪券、课本、礼仪书、历书。新哲学并不是主体。
- 手抄本文化仍在延续。印页仍可由手工完成。1455年不是一堵墙。
- 论纲的日期是1517年10月31日，从1454年算起经过63年，从1455年算起经过62年。印刷机本身并没有引发宗教改革。
- 印刷术并没有在1455年创造公众舆论。复制得更快，不等于形成了一种舆论。
:::

## 习题

:::exercise 从区间起点算起 {level=1 check="63"}
从1454年到1517年经过了多少年？（请输入年数。）
:::solution
1517减1454是63，经过了63年。《圣经》通常的年代是一个区间，所以这个数是从区间起点算起的，而不是从某一天算起。它不是副本数量，也不是原因。
:::
:::

:::exercise 从区间终点算起 {level=1 check="62"}
从1455年到1517年经过了多少年？（请输入年数。）
:::solution
1517减1455是62，经过了62年。要把这个数与63一起使用，而不是用它取代63。相差的一年，就是“约1454–1455年”这个区间的宽度。拒绝单一日期，就意味着保留两个数。
:::
:::

:::exercise 只是区间终点的年份 {level=1 check="1455"}
古腾堡《圣经》通常年代区间的较晚一端是哪一年？（请输入年份。）
:::solution
通常的年代区间是约1454–1455年，较晚的一端是1455年。不要给它加上具体日期，不要把它说成公众舆论诞生的年份，也不要把它当作本图谱未确定的某场诉讼的年份。在本课中，它只是这部《圣经》年代区间的终点。
:::
:::

:::exercise 是种类，不是册数 {level=2}
说出本课视为日常印刷的四种文本，并说明本课为什么不给出其中任何一种的数量。
:::solution
本章提到的日常种类有：拉丁文《圣经》、课本或语法书、赎罪券，以及历书或礼仪书。本课不给出数量，因为年表没有确定任何书籍数量，一个看似精确的总数将是虚假的精确。种类就足以说明大部分工作并不是新哲学，而这正是[[#def-ordinary]]所要支撑的论断。
:::
:::

:::exercise 什么在延续 {level=2}
一位同学在1455年画了一条线，说手抄到此为止。本课中的什么证据可以回应这条线？真正推翻你的回答，需要证明什么？
:::solution
手抄本文化仍在延续：特许状、唱诗本、呈献本，以及对印页的手工收尾，包括首字母和色彩。那条线把一个年代区间的终点当成了一种技术的终结。真正的反驳，需要一个有日期、普遍适用的终止点，此后手抄不再进行。本图谱没有这样的终止点。这位同学画的线，正是[[#thm-not-cause]]在指出手抄本在1455年后仍在延续时所拒绝的那堵墙。
:::
:::

:::exercise 识破这份版本记录 {level=2}
这份版本记录是虚构的：“成于1455年1月1日，近代公众诞生之日。”请分四个简短的步骤，把其中真实的部分与虚假的部分区分开来。
:::solution
第一，1455年是真实的年份，是《圣经》通常年代区间的较晚一端。第二，1月1日不是已确定的日子，所以即使它落在一个真实的年份之内，作为事实它也是假的。第三，“近代公众诞生”正是“印刷术在1455年创造了公众舆论”的迷思，警示已经拒绝了它。第四，真实的年份既不能证实那个日子，也不能证实那次诞生。一份真实的版本记录也只能为一本书定年。这份虚构的版本记录，就是要用一个真实的年份来掩饰两处添加。
:::
:::

:::exercise 认真的反驳 {level=3}
一位读者接受[[#thm-not-cause]]中的每一个日期，却仍然说：论纲流传开来，印刷术使流传成为可能，因此印刷术引发了宗教改革。这个“因此”错在哪里？什么才真正能推翻这一论断？
:::hint
把一种有助于文本传播的手段，与文本本身提出的论证区分开来。再看看大约两代人的时间里，印刷机一直在复制什么，包括赎罪券。
:::
:::solution
错误在于从手段跳到了原因。印刷机可以让复制更快，更快的复制也可以在1517年很重要，但印刷机仍然不是那场争论的作者。如果复制本身就能改革教会，那么约1454–1455年的拉丁文《圣经》就已经是决裂了，而事实并非如此。同样的行业也大量复制赎罪券——正是后来遭到抨击的那种形式——对于一个据说只站在一边的原因来说，这是很奇怪的。手抄本承载论证已有好几个世纪。能够推翻[[#thm-not-cause]]的证据是：没有印刷术，那场争论就不可能发生，而且印刷机的日常产品本身就已经是那场争论。日常印刷——课本和赎罪券表格——通不过第二项检验。62年或63年的间隔，则让把这段距离藏进“因此”一词的企图落了空。
:::
:::

:::exercise 没有金额的价格 {level=3}
本课说印刷术可能改变书价，却没有给出任何金额。为什么必须保持沉默？一种趋势为什么仍然可以是一个论断？再加上哪一句话，就会把这种趋势变成公众舆论的迷思？
:::hint
想一想年表在金钱方面确定了什么。再想一想，买主与一个共享某种教义的公众有何不同。
:::
:::solution
这里没有确定任何价格，无论以里弗尔还是英镑计，所以任何数字都是杜撰。一种趋势仍然可以是论断：活字一旦排好，再印副本就是不同于手抄的劳动，文本也可能变得更容易得到。更容易得到不等于免费，也不等于人人可得。一部语法书的买主并不是公众舆论。会把这种趋势变成迷思的那句额外的话，就是任何把一种共享的现代政治定年于1455年的句子，或者把更便宜的书当作对某种教义之认同的句子。[[#thm-not-cause]]允许价格变化，却拒绝这种认同。一本已确定的、载有真实金额的账簿，可以让将来某一课给出价格，但它仍然不会给出一种舆论。
:::
:::
