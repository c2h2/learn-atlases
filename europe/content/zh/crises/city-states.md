如果文艺复兴是一个标签，人文主义者做了什么？

他们研习并模仿古典拉丁语，把那种拉丁语教给将来需要它的男孩，他们书写共和国与君主的文书，并为写作追求声名。那是一种实践。它不是一种叫作现代性的个性，也不是一盏对着中世纪黑暗打开的灯。本世纪的意大利城市国家是有派系、放逐与雇佣兵的共和国与君主国。它们雇用这种实践，因为政府需要散文。公元1453年5月29日君士坦丁堡的陷落把希腊书籍与希腊学者带向西方，这是一个真实的联系，而不是那个原因。人文主义已经在进行之中。常与为佩脱拉克（Petrarch）加冕的桂冠联系在一起的年份，在本图谱中没有被锁定，所以不被使用。没有那个年份，他的名字照样可以使用。

同一年还装着另一个终结。公元1453年7月17日，卡斯蒂永（Castillon）合上了百年战争（Hundred Years' War）的惯例括号。[[crises/war-and-schism]]讲授那场战役，也把贞德（Joan of Arc）——于公元1431年5月30日在鲁昂（Rouen）被处以火刑——作为战争中的一个人而非一个民族的奠基者来讲授。她在本章的图上，好让一个世纪的意大利文字不能变成整个十五世纪。从1431年到1453年是22年。从那座城的陷落到公元1492年格拉纳达的投降是39年。那些间隔就是本章对抗单一的重生的第一道防御。

## 共和国、君主、派系

:::definition 城市国家 {#def-city}
本章所说的意大利**城市国家**（city-state），是一个统治一座城市与一片领土的共和国或君主国，有派系、放逐，常常还有雇佣兵。**派系**是在城市内部为职位而斗争的团体。**放逐**是一种政治判决，不是一个隐喻。**雇佣兵**是一名被雇用的士兵。城市国家不是民族国家，不是古代的城邦（polis），而本课不给它任何奠基年份。
:::

可以举出佛罗伦萨、威尼斯与米兰，也可以举出教廷与那不勒斯，作为这种政治被生活过的地方。举出它们不是给它们的诞生定年。如果一本书提供威尼斯的奠基年份，或佛罗伦萨的共同体生日，本课仍然不使用它。年表没有锁定那些节庆。一个城市国家以它如何被治理而被认识，不是以一个奠基故事。威尼斯被说成一个共和国。这个时期的米兰被说成一个君主国。佛罗伦萨是一个共和国，同时也是一个派系政体，在它自己的公民之间不止一次易手。那些易手的年份在这里没有被锁定，所以不被列出。共和国不是和平的证明。一位君主不是"国家"在后来意义上已经到来的证明。

古代的类比是人文主义者自己享受的一种诱惑。**城邦**，如[[greece/poleis]]所定义的，是一个公民共同体与一片领土，不是民族国家，而且不曾存在过一个希腊国家。一座意大利城市不是那个城邦。它有基督教的制度、一位主教、呢绒与信贷的商业，以及雇佣士兵的习惯。共用的古典阅读不取消这个差别。用西塞罗（Cicero）的拉丁语来赞美一个共和国的自由，可以是真诚的，也可以是交给一位秘书的任务书。真诚与任务书是相容的。两者都不奠基现代的自由。

放逐是一个派系除掉对手而不必杀死他们的方式。它也是一座城市失去那些此后从别处写文章反对它的人的方式。放逐的文学是这种实践的一部分，它是冲突的证据，不是一个黄金共识的证据。雇佣兵是一座城市在不愿只依靠自己的人民时打仗的方式。雇用一位队长，就把武装力量放在一份契约上。契约可以被打破，而队长本人可以成为一个政治问题。这一切都不是暴君对抗自由人的漫画。共和国雇用队长。君主们书写拉丁语。这些事实的分布是地方性的，而本课不会发明一张关于它们的表。

## 这种实践是什么

:::definition 人文主义 {#def-humanism}
**人文主义**，在本课，是一种实践：对古典拉丁语——有些作者还有希腊语——的研习与模仿；建立在这种研习之上的教育；在文书署中的工作；以及通过写作追求声名。它不是一种叫作现代性的个性，也不是对基督教信仰的拒绝。
:::

文书署是为一个政府书写文书的机构。外交的散文、被写成体面拉丁语的法律、一场使团的演说：这些是职务。一种人文主义的拉丁语，比经院学校的专门拉丁语更贴近古代的散文，是秘书们的资历。文书署里不是每一个人都是人文主义者，而也不是每一个人文主义者都靠薪水生活。声名是另一半。书信、史书与抨击文在能够评判它们的人中间流通，而声望是一种资本。庇护与声名一起运作。一个作者可以既想被人知道，又同时由一位君主付酬。现代的习惯是把这些动机当作对立面，自由的个人对抗廷臣。这种实践不需要那个对立。

教育正是资历被制造的地方。家庭教师与学校教师训练学生，大多是男孩，模仿古典散文并当众演说。女性不是通常的学生。有几个人照样写作。本课不会发明她们的一句话，也不会发明一个关于她们的人数。这种排除是这种实践的社会形状的一部分。它不是把这种实践称为抽象意义上"人"的解放的理由。[[sources/scale]]是恰当的告诫：一座城市里一位杰出的秘书，不是欧洲的心灵。

佩脱拉克是最常被放在拉丁语复兴开端附近的名字。用这个名字，然后停下。他的桂冠的年份没有被锁定。添上它，就会假装本图谱已经议定了一个它有意留下的日期。你不需要那个缺失的年份来拒绝一个更坏的日期。那座城在公元1453年的陷落，不是一种早就把他包括在内的实践的开端。语文学也可以被转向一份文献。洛伦佐·瓦拉（Lorenzo Valla）是这样一个论证的通常的名字：一份被用来支持教皇世俗权力的文献，并不是它自称的那种东西。那个论证的年份没有被锁定，所以不予给出。要点是工作的种类：拉丁语的比较，不是一种新的主权学说。[[christendom/popes-and-kings]]正是讲授教皇宣称本身的地方。瓦拉没有替换那一章。

:::theorem 文艺复兴是一个标签，而1453年不是它的原因 {#thm-label}
"文艺复兴"命名的是文字、艺术与治国术中一束实践。把它用作现代人之到来的一个标签，它便藏起了它本该陈述的那条论断。人文主义，如[[#def-humanism]]所定义的，在公元1453年5月29日之前已经是一种实践。君士坦丁堡的陷落，以及随之而来的希腊书籍与学者的移动，是一个真实的联系。它不是这种实践的起源。
:::
:::proof
联系的证据是那个日期与那个流通。公元1453年5月29日，奥斯曼苏丹穆罕默德二世（Mehmed II）攻取君士坦丁堡。东罗马国家终结。书籍与受过教育的希腊人在那次征服前后的几年里向西移动，而想要希腊语的西方读者得到了更充足的供应。这句话是被允许的。反对把它变成原因的证据，是这种实践自身的形状。文书署的拉丁语，模仿的教育，对文学声名的追求，不在那座城陷落的早晨开始。佩脱拉克的名字，不带年份地携带着，已经坐在这种实践之中。会构成对[[#thm-label]]之反驳的是证据，证明这种拉丁语的实践在公元1453年5月29日之前不存在，而由于流亡者才开始；或者证据，证明"文艺复兴"在公元1453年的史料中已经意味着一种现代人格的诞生。第二种是一个标签的后来的用法。第一种正是本章所否认的。艺术与建筑是这个标签流行的部分原因。本章的论断是关于文字与职务的实践的。一幅在别的某本书里定过年的一幅画，不是本图谱锁定过的一个奠基年份，所以它不会被引进来装饰这条论断。
:::

希腊语是一项增添，而增添是要紧的。一个热爱希腊语的读者会说真正的变化是那种语言，所以原因终究是那座城的陷落。回答是把这种实践拆开。拉丁语的人文主义不等待公元1453年。希腊语的人文主义因陷落之后书籍与人口的移动而被加强，而那种加强就是年表所允许的联系。加强不是开始。那座城里、以及巴尔干各地的奥斯曼统治，不是那里历史的终结。那是一次主权的改变。离开的人和留下的人，不是一场你可以把它变成欧洲之重生的单一的出走。本课不给出这两组人的任何数字。

## 对抗黑暗，与一个算例

:::warning 一个黑暗时代与一道突然的光
常见的迷思把一个黑暗的中世纪与一道文艺复兴之光对立起来。它失败，因为拉丁基督教世界已经有了大学、法律，以及同亚里士多德（Aristotle）的一场长久的论辩。托马斯·阿奎那（Thomas Aquinas）卒于公元1274年，处在一个论证的实践之内，[[christendom/towns-and-learning]]讲授他，不是作为中世纪的心灵，而是作为一生。人文主义者批评过那种实践的拉丁语。一次批评不是一次无知的普查。这个迷思对后来的标签有用，因为重生需要一场先于它的死亡。[[#thm-label]]保留诸实践，丢掉那场死亡。
:::

反论应当被公正地陈述。人文主义者说过，在他们与古人之间的那些世纪是笨拙的。他们用他们所钦佩的那种拉丁语说这话，而他们这么说是为了被雇用、被钦佩。他们的辱骂是关于其品味的史料。它不是大教堂、评注与自治市之缺席的史料。把一部有党派的风格的歷史当作整个社会的歷史，就又是那个尺度错误。会构成对这种拒绝之反驳的，是一个证明：在人文主义者之前，拉丁欧洲没有学校，也没有受过训练的论证。阿奎那在公元1274年的死，就足以挡住那个证明。它没有使阿奎那成为人文主义者。它使那片黑暗成为虚构。

5月29日与7月17日，同一年终结了两个不同政体的故事，东罗马国家与惯例上的英法战争。从5月29日到7月17日是49天。公开地数：从5月29日到6月29日是31天，从6月29日到7月17日是18天，而31加18是49。那个间隔既不是一个军事秘密，也不是一个原因。它是一种看法的方式：标签"1453年"藏着两个日期。这两个日期都不是印刷机的发明。图里的下一个点大约在1454年，是古腾堡（Gutenberg）《圣经》通常被安放的那个范围的起点，而[[crises/print]]解释为什么一个范围不是一天，又为什么一台印刷机不是宗教改革的原因。那座城与那台印刷机相近。相近不是一个原因。公元1492年的格拉纳达更远，距公元1453年39年，而不是一座佛罗伦萨文书署的文化回报。

:::example 一个年份里的两个日期 {#ex-forty-nine}
君士坦丁堡陷落于公元1453年5月29日。卡斯蒂永打于公元1453年7月17日。按从5月29日到6月29日为31天、从6月29日到7月17日为18天的计法，这两个日期之间隔着多少天？你不得推出什么？
:::solution
31加18是49。天数是49。你可以得出：一个年份的名字盖着两个终结，一个东罗马国家，一场西部的王朝战争。你不得得出：两个终结互为原因，或它们引起了人文主义，或49是流亡者的人数或死者的人数。没有任何这样的数字被锁定。
:::
:::

:::example 一道虚构的文书署命令 {#ex-chancery}
这道命令是虚构的。一座城市的政府命令它的秘书用古典拉丁语写给另一座城市，赞美共和国的自由，并请求一位队长和他的部属。这道命令说明了哪些实践，而"虚构"这个标签禁止你对它做什么？
:::solution
它说明文书署的人文主义、被用作政治任务书的共和语言，以及雇佣兵的雇用。它不说明一种叫作现代性的个性，也不显示这座城市没有派系。放逐在这篇具体的虚构里缺席，这是一个提醒：一道虚构的命令不是一部宪法。你不得把它提升为关于佛罗伦萨、威尼斯或米兰的证据。提升它将需要一封真实的信、一份真实的档案、一个真实的日期。这道命令被标为虚构，正是为了让你不去寻找它们。没有奠基年份被暗示，因为一个也没有被说出。
:::
:::

:::example 一句把重生开始得太晚的话 {#ex-fled}
这句话是虚构的。"公元1453年5月29日，文艺复兴开始了，因为希腊学者逃出君士坦丁堡，教会欧洲思考。"哪一从句是一个真实的日期，而[[#thm-label]]划掉哪些从句？
:::solution
公元1453年5月29日这个日期，以及穆罕默德二世取那座城的事实，可以站立。希腊书籍与学者确实移动，而如果那个联系不被叫作一个开端，它也可以站立。划掉"文艺复兴开始了"，那是标签在做原因的工作。划掉"教会欧洲思考"，那是黑暗到光明的迷思，外加一个尺度错误：欧洲不是一个教室里的学生。作为拉丁语、教学、文书署与声名的人文主义，已经是一种实践。那场逃亡没有奠基它。这句话用一个真实的日子，做一个虚假起源的诱饵。
:::
:::

:::example 从那座城到格拉纳达 {#ex-granada-gap}
那张图从公元1453年君士坦丁堡的陷落跑到公元1492年的格拉纳达。已过计数是多少年，而格拉纳达为什么不是人文主义散文的结果？
:::solution
1492减1453是39。已过计数是39年。格拉纳达的投降，在[[crises/year-1492]]中讲授，是公元1492年1月2日在伊比利亚的一次征服。一座意大利城市的文书署可以欣赏古典拉丁语整整一代人，而在那次投降中没有任何份额。共享一个世纪，共享一张图，不是一个原因。《圣经》在约公元1454年的点，比格拉纳达更靠近公元1453年，而它仍然不是同一个原因。下一章将用自己的证据拒绝那种等同。
:::
:::

- [ ] 卡斯蒂永之战打响的那一天

把年份移到1453年，然后移到1454年。两个点挨在一起，而说明禁止你把它们变成一个原因。《圣经》的标记是"约1454年"，一个范围的起点，不是一个日子，这就是下一章存在的原因。1431年贞德的点更早，是另一场战争里的一次死亡。1492年格拉纳达的点是一次征服，不是一首诗。一个宽十年的窗口不会把1431与1492当作邻居拉进同一个视野：从1431年到1492年的已过计数是61年。这张图的差事，是在散文把各种实践保持分开的同时，让那些距离保持可见。空白的年份并不是政治的空无。它们是事件没有被本图谱锁定的年份，包括城市内部的派系易手。把它们留空，是不发明一个生日的另一个办法。

:::history
公元1453年5月29日，穆罕默德二世攻取君士坦丁堡，东罗马国家终结。奥斯曼的统治不是巴尔干历史的终结。同年的7月17日，卡斯蒂永结束了惯例上的百年战争。希腊书籍与学者向西移动。人文主义，一种拉丁语、教学与文书署的实践，已经在进行之中，而那场移动不是它的原因。
:::

算过例的那道命令与那句虚构的起源句，是同一个试验朝两个方向运行。一份虚构的文献能够教你一个文书署是做什么用的，只要你保留那个标签。一个真实的日期能够教给你一个虚假的起源，如果你让那个日期给粘在它上面的口号作证。[[sources/argument]]把那种口号叫作系在一条论断上的标签。这里的标签是文艺复兴，而它内部的那条论断，一旦拆开，是：一种新型的人出现了，而公元1453年解释了这次出现。[[#thm-label]]把它拆开，只保留日期所承载得起的东西：一种已经在进行的实践，一次在东方的征服，一个书籍与人口的流通，一场在同一个夏天、在法兰西的战役。

## 通向何处

[[crises/print]]问道：当约公元1454–1455年的《圣经》增殖了人文主义者在乎的文本和许多他们并不在乎的文本之后，印刷机改变了什么。[[crises/year-1492]]把格拉纳达从这张图上拿走，并拒绝让它成为近代世界的出生。[[crises/war-and-schism]]就是那座城陷落时正在卡斯蒂永结束的那场战争。[[christendom/towns-and-learning]]是大学与阿奎那在公元1274年的死，是反对一个黑暗时代的证据。[[greece/poleis]]是古代的城，而这座城不是它。[[reformations/luther]]还很远，而一种文书署的文风不引起它。

:::summary
- 这里的一个意大利城市国家，是一个有派系、放逐与雇佣兵的共和国或君主国。它在本图谱没有奠基年份，也不是民族国家或城邦。
- 人文主义是一种古典拉丁语、教育、文书署写作与声名的实践，有些人还有希腊语。它不是一种现代的个性，也不是基督教信仰的失落。
- 佩脱拉克可以被举名。他的桂冠的年份没有被锁定，也不被使用。瓦拉的语文学论证在这里同样没有定年。
- 公元1453年5月29日，穆罕默德二世攻取君士坦丁堡。希腊书籍与学者移动。那是一个真实的联系，不是已经在进行的人文主义的原因。
- 卡斯蒂永，在公元1453年7月17日，晚49天，是另一个终结。印刷机约在公元1454年，靠近那座城的陷落，而不是同一个原因。
- 黑暗时代的迷思挡不住大学，也挡不住卒于公元1274年的阿奎那。人文主义者的辱骂是一种品味，不是一次普查。
- 公元1492年的格拉纳达在陷落之后39年。共享一个世纪，不会把一次征服变成一种散文的一个结果。
:::

## 习题

:::exercise 陷落的日子 {level=1 check="1453"}
穆罕默德二世在哪一年攻取君士坦丁堡？（请输入年份。）
:::solution
那座城陷落于公元1453年5月29日。年份是1453。同年还有7月17日的卡斯蒂永。不要把这两个日期合并成一个事件，也不要把它们中的任何一个变为人文主义的出生。
:::
:::

:::exercise 两个终结之间的天数 {level=1 check="49"}
按从5月29日到6月29日为31天、从6月29日到7月17日为18天的计法，君士坦丁堡的陷落与公元1453年的卡斯蒂永之间隔着多少天？（请输入天数。）
:::solution
31加18是49。天数是49。这个计数是一个年份之内的一个历法间隔。它不是流亡者的人数，不是死者的人数，也不是一个从一个事件跑到另一个事件的原因。
:::
:::

:::exercise 从那座城到格拉纳达的年数 {level=1 check="39"}
从公元1453年到公元1492年的已过计数是多少年？（请输入年数。）
:::solution
1492减1453是39。年数是39。格拉纳达于公元1492年1月2日投降，是本课程最后一章讲授的一次征服。那段间隔，是不把那次投降当作君士坦丁堡的陷落或一种文书署文风之结果的一个理由。
:::
:::

:::exercise 那道命令被允许说明什么 {level=2}
用[[#ex-chancery]]里那道虚构的文书署命令，说出它被允许说明的三种真实的工作，并说出一个关于一座真实的城市的、它被禁止支持的结论。
:::solution
它可以说明文书署的拉丁语、共和语言的政治使用，以及一位雇佣兵队长的雇用。它不得支持一个关于佛罗伦萨、威尼斯、米兰或任何其他一座真实的城市的结论，因为那道命令是虚构的，并且一座也没有提名。它也不得被用作一个奠基年份，或一座城市没有派系的证明。一份真实档案里的一封真实的信会是另一个对象。这一道是这种实践的一个模型，标着虚构，好让你不去提升它。
:::
:::

:::exercise 桂冠之年为什么缺席 {level=2}
一个读者索要佩脱拉克受桂冠的那一年，并提出从另一本书补上它。你如何回答，而关于他你仍然可以说什么？
:::solution
你拒绝那个年份。本图谱没有锁定它，而一个从外面抄进来的年份，在本课内部会是一种发明的确定性。你仍然可以把佩脱拉克命名为一位与古典拉丁语复兴相联的作者，也仍然可以说人文主义在公元1453年5月29日之前已经是一种实践。那个缺失的年份不是一个缺失的原因。那座城的陷落不会因为一个著名的日期被有意省去，就变成了那种实践的起源。
:::
:::

:::exercise 品味不是一次普查 {level=2}
一位人文主义者用你不会发明的话写道，他之前的那些世纪是笨拙的。那个判断为什么不是拉丁基督教世界是一个黑暗时代的证据？
:::solution
它是关于他的品味的证据，也是关于他为了让自己的拉丁语看起来像一次收复而需要的那个反差的证据。它不是关于学校、法律、大教堂或自治市的一次调查。阿奎那卒于公元1274年，处在一个论证的实践之内，这就足以挡住"在人文主义者之前没有任何智识的东西"那个论断。对经院拉丁语的批评，作为风格问题可以是有理的，而如果把它当作对一个社会的描述，就仍然是一个尺度错误。[[#thm-label]]保留实践，丢掉那个标签想要的黑暗。
:::
:::

:::exercise 那些书会反驳这条论断吗 {level=3}
假设一批真实的希腊书籍在公元1453年5月29日之后抵达意大利，而一位真实的学者在那里教授希腊语。一个批评者说[[#thm-label]]已经失败，因为文艺复兴现在明显地开始了。它失败了吗？什么样的发现才会真正构成对这条论断的反驳？
:::hint
把拉丁语的人文主义与希腊语研习之被加强分开。然后问"已经是一种实践"需要什么才会倒塌。
:::
:::solution
它没有失败。那批书与那位教师，正是[[#thm-label]]已经承认的那个联系：书籍与学者在那座城陷落之后移动。希腊语研习可以被那场移动加强，而拉丁语的文书署人文主义并不必在5月29日开始。一项增添不是一个起源。这条论断会失败，如果拉丁语的实践、教学与文书署被证明在陷落之前不存在、而由于流亡者才开始，或者如果公元1453年的史料自己用"文艺复兴"来意味着一个现代人的诞生。一箱书两样都不显示。它显示一个流通，而这就是本课所称呼的一个真实的联系。
:::
:::

:::exercise 共和国，自由，队长 {level=3}
一个读者说，一个意大利共和国是近代自由的出生，因为它用古典拉丁语赞美自由，并打自己的战争。用派系、放逐与雇佣兵，给出反驳。什么样的东西会构成对你的回答的反驳？
:::hint
问一问对自由的赞美是否就是同一部宪法，以及当一位队长被雇用时是谁在打仗。
:::
:::solution
[[#def-city]]里的一个共和国，是一个同时放逐对手、并常常雇用雇佣兵的城市政府。放逐是公民体内部的一件武器，不是职位开放而和平的证明。一位被雇用的队长打仗，是因为那座城不愿或不能只依靠自己的人民，所以"打自己的战争"已经太光滑了。对自由的古典赞美可以是一个秘书被交给的任务书。任务书不是现代自由的一部宪法，而没有任何奠基年份被锁定，能把那座城变成一个民族国家。你的回答会失败，如果一个被锁定的日期显示了一个没有派系也没有放逐、统治着一个民族国家、并且只靠公民征召打仗的共和国，并且那个日期是后来那个观念的起源。本图谱没有那个日期。人文主义者自己同古代城邦的类比还有另一个失败的理由：[[greece/poleis]]是另一种城，而不曾存在过一个可以重生的希腊国家。
:::
:::
