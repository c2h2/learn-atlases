如果“文艺复兴”只是一个标签，那么人文主义者究竟做了什么？

他们研习并模仿古典拉丁语，把这种拉丁语传授给日后需要它的男孩，为共和国和君主撰写公文，并借写作追求声名。这是一种实践，而不是一种名为“现代性”的人格，也不是在中世纪的黑暗中突然打开的一盏灯。这个世纪的意大利城市国家，是充斥着派系、放逐和雇佣兵的共和国与君主国。它们雇用这种实践，因为政府需要文章。1453年5月29日君士坦丁堡陷落，把希腊书籍和希腊学者带到了西方，这是真实的联系，却不是原因：人文主义早已开始。人们常把某个年份与佩脱拉克（Petrarch）的桂冠加冕联系在一起，但本图谱没有确定这个年份，因此不予使用。不提年份，照样可以提到他的名字。

同一年还有另一个终结。1453年7月17日的卡斯蒂永（Castillon）之战，按惯例为百年战争（Hundred Years' War）画上了句号。[[crises/war-and-schism]]讲授这场战役，也讲授1431年5月30日在鲁昂（Rouen）被处以火刑的贞德（Joan of Arc），把她当作战争中的一个人，而不是民族的缔造者。她出现在本章的图上，是为了不让一个世纪的意大利文学变成整个十五世纪。从1431年到1453年是22年；从君士坦丁堡陷落到1492年格拉纳达投降是39年。这些间隔是本章抵御“单一重生”之说的第一道防线。

## 共和国、君主、派系

:::definition 城市国家 {#def-city}
本章所说的意大利**城市国家**（city-state），是统治一座城市及其周边领土的共和国或君主国，有派系、放逐，往往还有雇佣兵。**派系**是在城内争夺职位的团体。**放逐**是一种政治判决，而不是比喻。**雇佣兵**是受雇的士兵。城市国家不是民族国家，也不是古代城邦（polis），本课也不为它给出任何创立年份。
:::

佛罗伦萨、威尼斯和米兰都可以提及，教廷和那不勒斯也可以，它们都是这种政治实际展开的地方。提及它们并不等于为它们的诞生定年。如果某本书给出威尼斯的建城年份或佛罗伦萨公社的诞生日，本课仍然不用。年表没有确定这些纪念日。认识一个城市国家，要看它如何治理，而不是看它的建城传说。威尼斯被称为共和国；这一时期的米兰被称为君主国；佛罗伦萨是共和国，同时也是派系政权，政权不止一次在其公民之间易手。这些易手的年份这里没有确定，因此不予列出。共和国不能证明和平；君主也不能证明后来意义上的“国家”已经到来。

古代类比是人文主义者自己也乐于沉溺的诱惑。按照[[greece/poleis]]的定义，**城邦**是一个公民共同体及其领土，不是民族国家，而且从来没有一个统一的希腊国家。意大利城市不是那种城邦。它有基督教的制度、主教、呢绒与信贷的商业，还有雇用士兵的习惯。共同的古典阅读并不能抹去这一差别。用西塞罗（Cicero）的拉丁语赞美共和国的自由，可以出于真诚，也可以是交给秘书的一项差事。真诚与差事并不矛盾，两者都不是现代自由的源头。

放逐是一个派系不必杀死对手就能除掉他们的办法。城市也因此失去一些人，而这些人随后在别处写文章攻击它。放逐文学是这种实践的一部分，它证明的是冲突，而不是黄金般的共识。城市不愿只依靠本城的人打仗时，就雇用雇佣兵。雇用一位雇佣军首领，就是把武装力量交给一纸契约。契约可能被撕毁，首领本人也可能成为一个政治难题。这一切都不是暴君对抗自由人的漫画。共和国也雇用雇佣军首领，君主也写拉丁文。这些事实如何分布是地方性的问题，本课不会为此杜撰一张表。

## 这种实践是什么

:::definition 人文主义 {#def-humanism}
本课所说的**人文主义**是一种实践：研习和模仿古典拉丁语，有些作者还研习希腊语；以这种研习为基础的教育；在文书院（chancery）中的工作；以及通过写作追求声名。它不是一种名为“现代性”的人格类型，也不是对基督教信仰的拒斥。
:::

文书院是为政府撰写公文的机构。外交文书、用得体的拉丁语写成的法令、出使时的演说词：这些都是差事。一种比经院学校的专业拉丁语更接近古代文章的人文主义拉丁语，成了秘书的资历凭证。文书院里并非人人都是人文主义者，人文主义者也并非都靠薪俸为生。声名是另一半。书信、史书和抨击文在有鉴赏能力的人之间流传，声望是一种资本。庇护与声名相辅相成。一位作者可以既想扬名，又受君主供养。现代人习惯把这些动机视为对立，即自由的个人对抗廷臣，但这种实践并不要求这种对立。

资历凭证是在教育中造就的。家庭教师和学校教师训练学生——大多是男孩——模仿古典文章并公开演说。女性通常不是学生，但仍有少数女性写作。本课不会杜撰她们的话，也不会杜撰她们的人数。这种排斥是这一实践社会形态的一部分，不能据此把这一实践称为抽象的“人”的解放。[[sources/scale]]给出了恰当的提醒：某座城市里一位出色的秘书，并不是欧洲的心灵。

佩脱拉克是最常被放在拉丁语复兴开端的名字。提到这个名字就够了。他获得桂冠的年份没有确定，添上它，就等于假装本图谱已经认定了一个有意略去的日期。拒绝一个更糟的日期，并不需要那个缺失的年份：1453年君士坦丁堡陷落，不可能是一种早已包括他在内的实践的开端。语文学也可以用来审视一份文献。洛伦佐·瓦拉（Lorenzo Valla）通常与这样一个论证联系在一起：一份被用来支持教皇世俗权力的文献，并不是它所自称的那样。这一论证的年份没有确定，因此不予给出。要点在于工作的性质：这是拉丁语的比较，而不是一种新的主权学说。教皇的主张本身在[[christendom/popes-and-kings]]中讲授，瓦拉并不取代那一章。

:::theorem 文艺复兴是一个标签，而1453年不是它的原因 {#thm-label}
“文艺复兴”指称的是文学、艺术和治国术中的一组实践。如果用它来标示现代人的到来，它就掩盖了本应明确陈述的论断。按照[[#def-humanism]]的定义，人文主义在1453年5月29日之前就已经是一种实践。君士坦丁堡的陷落，以及随后希腊书籍和学者的迁移，是真实的联系，但不是这一实践的起源。
:::
:::proof
这一联系的证据是日期和流动。1453年5月29日，奥斯曼苏丹穆罕默德二世（Mehmed II）攻占君士坦丁堡，东罗马国家灭亡。在这次征服前后的几年里，书籍和受过教育的希腊人向西迁移，想学希腊语的西方读者得到了更充足的资源。这句话是可以说的。反对把它当作原因的证据，是这一实践本身的形态。文书院的拉丁语、以模仿为本的教育、对文学声名的追求，都不是在城破那天早晨开始的。不带年份的佩脱拉克之名，本就已经处在这一实践之中。能够推翻[[#thm-label]]的证据是：这种拉丁语实践在1453年5月29日之前并不存在，而是因流亡者才开始的；或者，1453年的史料中“文艺复兴”一词已经意指现代人格的诞生。后者是这个标签后来的用法；前者正是本章所否认的。艺术和建筑是这个标签广受欢迎的部分原因，但本章的论断针对的是文字和职务的实践。别的书里为某幅画给出的年代，并不是本图谱确定的创立年份，因此不会被引进来装点这一论断。
:::

希腊语是一种增添，而增添很重要。热爱希腊语的读者会说，真正的变化在于语言，所以原因终究还是城破。回答是把这一实践拆开来看。拉丁语人文主义并不等待1453年；希腊语人文主义则因城破后书籍和人员的迁移而得到加强，这种加强正是年表所允许的联系。加强不等于开端。奥斯曼对这座城市以及巴尔干的统治，并不是那里历史的终结，而是一次主权的更替。离开的人和留下的人，并不是一场可以被你说成欧洲重生的单一出走。本课不给出这两类人的任何数字。

## 反对“黑暗时代”，以及一个算例

:::warning 黑暗时代与突然的光明
常见的迷思把黑暗的中世纪与文艺复兴的光明对立起来。这种说法站不住，因为拉丁基督教世界早已有了大学、法律，以及与亚里士多德（Aristotle）的长期论辩。托马斯·阿奎那（Thomas Aquinas）于1274年在论辩的实践中去世，[[christendom/towns-and-learning]]讲授他时，不是把他当作“中世纪心灵”，而是当作一个人的一生。人文主义者批评过那种实践的拉丁语，但批评不是对无知的普查。这一迷思对后来的标签很有用，因为重生需要先有一次死亡。[[#thm-label]]保留这些实践，舍弃那次死亡。
:::

反论应当公平地陈述。人文主义者说，他们与古人之间的那些世纪是拙劣的。他们是用自己推崇的拉丁语说这番话的，说这番话也是为了受雇和受推崇。他们的贬斥是关于他们自身品味的史料，而不是证明大教堂、评注和城市公社不存在的史料。把一部带有党派立场的文风史当作整个社会的历史，又是那种尺度错误。能够推翻这一拒绝的，是证明在人文主义者之前，拉丁欧洲既没有学校，也没有经过训练的论辩。阿奎那1274年去世，就足以阻断这种证明。这并不使阿奎那成为人文主义者，而是使那片黑暗成为虚构。

5月29日和7月17日，同一年里两个不同政治体的故事分别画上了句号：东罗马国家，以及按惯例划定的英法战争。从5月29日到7月17日是49天。不妨公开地数一遍：从5月29日到6月29日是31天，从6月29日到7月17日是18天，31加18是49。这段间隔既不是军事秘密，也不是原因，它只是让人看到，“1453年”这个标签掩盖了两个日期。这两个日期都不是印刷机的发明。图上的下一个圆点约在1454年，这是古腾堡（Gutenberg）《圣经》通常所处年代范围的起点；[[crises/print]]解释为什么一个范围不是某一天，以及为什么印刷机不是宗教改革的原因。城破与印刷机在时间上很近，但很近不等于同一个原因。1492年的格拉纳达则更远，距1453年39年，它也不是佛罗伦萨文书院的文化回报。

:::example 同一年中的两个日期 {#ex-forty-nine}
君士坦丁堡于1453年5月29日陷落，卡斯蒂永之战发生于1453年7月17日。按从5月29日到6月29日为31天、从6月29日到7月17日为18天计算，两个日期之间相隔多少天？你不能得出什么结论？
:::solution
31加18是49，相隔49天。你可以得出结论：一个年份之下有两个终结，一个是东罗马国家，一个是西方的王朝战争。你不能得出结论说：这两个终结互为因果，或者它们引发了人文主义，或者49是流亡者或死者的人数。这里没有确定任何这样的数字。
:::
:::

:::example 一道虚构的文书院命令 {#ex-chancery}
这道命令是虚构的：某城政府命令其秘书用古典拉丁语致函另一座城市，赞美共和国的自由，并请求派一位雇佣军首领及其部队前来。这道命令说明了哪些实践？“虚构”这一标注又禁止你拿它做什么？
:::solution
它说明了文书院的人文主义、作为政治差事的共和话语，以及对雇佣兵的雇用。它不能说明一种名为“现代性”的人格，也不能表明这座城市没有派系。这则虚构中恰好没有放逐，这提醒我们：一道虚构的命令不是一部宪法。你不能把它提升为关于佛罗伦萨、威尼斯或米兰的证据；要提升它，需要一封真实的信、一份真实的档案和一个真实的日期。这道命令标明是虚构的，正是为了让你不必去找这些东西。它也不暗示任何创立年份，因为根本没有给出。
:::
:::

:::example 一句把重生定得太晚的话 {#ex-fled}
这句话是虚构的：“1453年5月29日，文艺复兴开始了，因为希腊学者逃离君士坦丁堡，教会了欧洲思考。”哪一部分是真实的日期？[[#thm-label]]要删去哪些部分？
:::solution
1453年5月29日这个日期，以及穆罕默德二世攻占这座城市的事实，都可以成立。希腊书籍和学者确实发生了迁移，只要不把这一联系称为开端，它也可以成立。“文艺复兴开始了”要删去，因为那是让标签充当原因。“教会了欧洲思考”也要删去，因为那是从黑暗到光明的迷思，外加一个尺度错误：欧洲不是一间教室里的学生。由拉丁语、教育、文书院和声名构成的人文主义早已是一种实践，那次出逃并没有创立它。这句话是用一个真实的日子作诱饵，引出一个虚假的起源。
:::
:::

:::example 从君士坦丁堡到格拉纳达 {#ex-granada-gap}
这幅图从1453年君士坦丁堡陷落延伸到1492年的格拉纳达。其间经过了多少年？为什么格拉纳达不是人文主义文章的结果？
:::solution
1492减1453是39，经过了39年。格拉纳达投降在[[crises/year-1492]]中讲授，是1492年1月2日发生在伊比利亚的一次征服。一座意大利城市的文书院可以推崇古典拉丁语整整一代人之久，却与那次投降毫无关系。同处一个世纪、同在一幅图上，都不构成原因。约1454年《圣经》的圆点离1453年比格拉纳达更近，但它同样不是同一个原因。下一章会依据自己的证据拒绝这种等同。
:::
:::

把年份移到1453年，再移到1454年。两个圆点紧挨着，而图注禁止你把它们说成同一个原因。《圣经》的标记是“约1454年”，是一个范围的起点而不是某一天，这正是下一章存在的理由。1431年贞德的圆点更早，是另一场战争中的一次死亡。1492年格拉纳达的圆点是一次征服，而不是一首诗。十年宽的窗口不会把1431年和1492年当作邻居拉进同一个视野：从1431年到1492年经过了61年。这幅图的任务是让这些距离始终可见，而文字则让各种实践保持区分。空白的年份并非没有政治，而是本图谱没有确定其中事件的年份，包括城市内部派系的更替。让它们空着，是杜撰生日之外的另一种选择。

:::history
1453年5月29日，穆罕默德二世攻占君士坦丁堡，东罗马国家灭亡。奥斯曼的统治并不是巴尔干历史的终结。同年7月17日，卡斯蒂永之战按惯例结束了百年战争。希腊书籍和学者向西迁移。人文主义作为一种关于拉丁语、教育和文书院的实践早已开始，这次迁移不是它的原因。
:::

前面推演过的那道命令和那句虚构的起源说，是从两个方向进行的同一种检验。一份虚构的文献，只要你记住它是虚构的，就能教你明白文书院是做什么的；一个真实的日期，如果你让它为粘在上面的口号作保，就会教给你一个虚假的起源。[[sources/argument]]把这种口号称为附着在某个论断上的标签。这里的标签是“文艺复兴”，而其中的论断一经拆开，就是：一种新型的人出现了，而1453年解释了这一出现。[[#thm-label]]把它拆开，只保留日期能够承载的内容：一种早已在进行的实践，一次东方的征服，一股书籍与人员的流动，以及同一个夏天在法兰西进行的一场战役。

## 通向何处

[[crises/print]]追问：约1454–1455年的《圣经》问世后，印刷机大量复制了人文主义者关心的文本，也复制了许多他们并不关心的文本，那么它究竟改变了什么。[[crises/year-1492]]把格拉纳达从这幅图上拿开，并拒绝把它当作近代世界的诞生。[[crises/war-and-schism]]讲的就是君士坦丁堡陷落时正在卡斯蒂永结束的那场战争。[[christendom/towns-and-learning]]讲大学和1274年阿奎那的去世，这是反驳“黑暗时代”的证据。[[greece/poleis]]讲古代城邦，而这里的城市并不是城邦。[[reformations/luther]]还很遥远，一种文书院文风也不会引发它。

:::summary
- 这里的意大利城市国家，是有派系、放逐和雇佣兵的共和国或君主国。本图谱不为它给出创立年份，它既不是民族国家，也不是城邦。
- 人文主义是一种关于古典拉丁语、教育、文书院写作和声名的实践，一些人还研习希腊语。它不是现代人格，也不是基督教信仰的丧失。
- 佩脱拉克可以提及，但他获得桂冠的年份没有确定，也不使用。瓦拉的语文学论证在这里同样不定年。
- 1453年5月29日，穆罕默德二世攻占君士坦丁堡，希腊书籍和学者随之迁移。这是真实的联系，但不是人文主义的原因，人文主义早已是一种实践。
- 1453年7月17日的卡斯蒂永之战晚了49天，是另一个终结。约1454年的印刷机与城破时间相近，但不是同一个原因。
- 面对大学和1274年去世的阿奎那，“黑暗时代”的迷思站不住。人文主义者的贬斥反映的是品味，而不是普查。
- 1492年的格拉纳达在城破之后39年。同处一个世纪，并不会把一次征服变成文章的结果。
:::

## 习题

:::exercise 城破之日 {level=1 check="1453"}
穆罕默德二世在哪一年攻占君士坦丁堡？（请输入年份。）
:::solution
君士坦丁堡于1453年5月29日陷落，年份是1453年。同一年还有7月17日的卡斯蒂永之战。不要把这两个日期合并成一个事件，也不要把其中任何一个当作人文主义的诞生。
:::
:::

:::exercise 两个终结之间的天数 {level=1 check="49"}
按从5月29日到6月29日为31天、从6月29日到7月17日为18天计算，1453年君士坦丁堡陷落与卡斯蒂永之战相隔多少天？（请输入天数。）
:::solution
31加18是49，相隔49天。这是同一年之内的一段日历间隔，不是流亡者的人数，不是死者的人数，也不是从一件事通向另一件事的因果。
:::
:::

:::exercise 从君士坦丁堡到格拉纳达的年数 {level=1 check="39"}
从1453年到1492年经过了多少年？（请输入年数。）
:::solution
1492减1453是39，经过了39年。格拉纳达于1492年1月2日投降，这次征服在本课程最后一章讲授。这段间隔正是不应把那次投降当作君士坦丁堡陷落或某种文书院文风之结果的理由之一。
:::
:::

:::exercise 这道命令可以说明什么 {level=2}
根据[[#ex-chancery]]中那道虚构的文书院命令，说出它可以说明的三种真实工作，并说出一个它不能支持的、关于某座真实城市的结论。
:::solution
它可以说明文书院的拉丁语、共和话语的政治用途，以及对雇佣军首领的雇用。它不能支持关于佛罗伦萨、威尼斯、米兰或任何其他真实城市的结论，因为这道命令是虚构的，也没有提到其中任何一座城市。它也不能被当作创立年份，或者当作这座城市没有派系的证明。真实档案中的一封真实信件是另一回事。这道命令只是这种实践的一个模型，标明虚构，就是为了让你不去拔高它。
:::
:::

:::exercise 为什么没有桂冠之年 {level=2}
一位读者问佩脱拉克在哪一年获得桂冠，并提出从另一本书里补上这个年份。你如何回答？关于他，你仍然可以说什么？
:::solution
你拒绝这个年份。本图谱没有确定它，从外面抄进来的年份，在本课中就是一种杜撰的确定性。你仍然可以说佩脱拉克是与古典拉丁语复兴相关的作家，也仍然可以说人文主义在1453年5月29日之前就已经是一种实践。缺失的年份不是缺失的原因。一个著名的日期被有意略去，并不会让城破变成这一实践的起源。
:::
:::

:::exercise 品味不是普查 {level=2}
一位人文主义者写道——具体措辞你不要杜撰——在他之前的那些世纪是拙劣的。为什么这一评判不能证明拉丁基督教世界是一个黑暗时代？
:::solution
它证明的是他的品味，以及他为了让自己的拉丁语显得像一次复兴而需要的那种反差。它不是对学校、法律、大教堂或城市公社的调查。阿奎那于1274年在论辩的实践中去世，这就足以驳倒“人文主义者之前没有任何智识活动”的论断。对经院拉丁语的批评，作为文风问题可能言之成理；但如果把它当作对一个社会的描述，仍然是尺度错误。[[#thm-label]]保留这一实践，舍弃这个标签想要的那片黑暗。
:::
:::

:::exercise 这些书能推翻这一论断吗？ {level=3}
假设一批真实的希腊书籍在1453年5月29日之后运抵意大利，一位真实的学者在那里教授希腊语。一位批评者说[[#thm-label]]已经站不住了，因为文艺复兴此时显然已经开始。它真的站不住了吗？什么样的发现才真正能推翻这一论断？
:::hint
把拉丁语人文主义与希腊语研究的加强区分开来，然后想一想，“早已是一种实践”需要什么条件才会被推翻。
:::
:::solution
它没有站不住。这批书和这位教师，正是[[#thm-label]]已经承认的那种联系：城破之后，书籍和学者发生了迁移。希腊语研究可以因这种迁移而加强，但拉丁语的文书院人文主义并不是从5月29日才开始的。增添不等于起源。只有证明拉丁语实践——教育和文书院——在城破之前并不存在，而是因流亡者才开始的；或者1453年的史料本身就用“文艺复兴”来指现代人的诞生，这一论断才会站不住。一箱书两者都证明不了，它显示的只是一股流动，也就是本课所说的真实联系。
:::
:::

:::exercise 共和国、自由与雇佣军首领 {level=3}
一位读者说，意大利共和国是近代自由的诞生，因为它用古典拉丁语赞美自由，并且自己打仗。请从派系、放逐和雇佣兵出发提出反驳。什么能够推翻你的回答？
:::hint
想一想：对自由的赞美是否等于一部宪法？雇用了雇佣军首领之后，究竟是谁在打仗？
:::
:::solution
按[[#def-city]]，共和国是一种城市政府，它同时放逐对手，并常常雇用雇佣兵。放逐是公民内部的武器，不能证明职位开放、政治和平。雇来的首领之所以打仗，是因为城市不愿或不能只依靠本城的人，所以“自己打仗”的说法已经过于圆滑。对自由的古典式赞美，可能只是交给秘书的一项差事；差事不是现代自由的宪法，而且也没有任何已确定的创立年份可以把这座城市变成民族国家。如果有一个已确定的日期显示，某个共和国没有派系、没有放逐，统治着一个民族国家，只靠公民征召作战，而且这个日期就是后来那种观念的起源，你的回答才会站不住。本图谱没有这样的日期。人文主义者自己把城市与古代城邦相比，也有另一层站不住的理由：[[greece/poleis]]讲的是另一种城市，而且从来没有一个统一的希腊国家可供重生。
:::
:::
