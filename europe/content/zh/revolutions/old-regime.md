一场财政危机为什么还不是一场革命？

一个付不出钱的王权处在政治危险之中。仅凭这一事实，它并不处在一场革命之中。在这里，一场革命是这样一个变化：谁可以为法律授权。法国有一场偿付危机：以债务融资的诸场战争，以及一种使一项一般税难以通过的特权。那场危机只有在被召来补救它的那个团体拒绝按旧的方式开会时，才变成一场代表权危机。三级会议于公元1789年5月5日开幕。6月17日，第三等级取用了国民议会这个名称。这两个日期就是那道铰链。一座被攻占的监狱、一个共和国、一位死去的国王、恐怖统治：各自属于后来的一课。

两条近路总是有人兜售。一条说，一个已知的赤字必然把这个政权掀翻。另一条说，一个宫廷，尤其是一位王后，把一个王国挥霍到崩溃。两者都没有办法对照诸制度来检验。没有任何赤字数字被锁定，因此一个也不会被发明。旧制度不会被讲成一个家户。特权、官职与债务才是那些政治事实。一份公布出来的短缺不会投票。

## 一个复合物，不是一幅漫画

:::definition 旧制度 {#def-old-regime}
**旧制度**（ancien régime）这个取自法语的名字，指的是一场革命宣称已经结束的那个秩序。在本章，它指的是法国的那个复合物——特权、可买卖的官职、行省法律与王室债务——就它在三级会议于公元1789年开幕时所存在的样子而言。它不意味着“近代以前的法国”，也不意味着一台宫廷喜剧。它的很大一部分是近来的战争财政，坐落在更古老的权利之上。
:::

法国是一个复合君主制（composite monarchy），取[[states/composite-monarchy]]的意义：一个国王，许多法律。诸行省保持着不同的契约。一些行省在自己的等级会议里表决税收。另一些由王室官员治理。一座城镇、一个同业公会或一位领主，可以持有一项免税特权、一桩垄断的行业、若干捐税，或一座邻人所没有的法庭。把那个叫作专制主义，就掩盖了讨价还价。路易十四（Louis XIV）的政府，在[[states/fiscal-military]]里，宣扬能力，而没有废除它绕着征税的那些特权。

三个等级组织了三级会议：教士、贵族，以及选举能够看见的所有其他人。那第三不是“人民”。女性不是代表。殖民地中被奴役的人站在那个分类之外。公元1685年的《黑人法典》（Code Noir）在[[states/atlantic]]。把种植园奴隶制撕开的那次起义在[[revolutions/from-1789]]。公元1789年的第三等级诸人，在很大程度上是律师、持职者与有产者。“民族”是一条论断，不是一次人口普查。

:::definition 特权 {#def-privilege}
**特权**是附着于一个等级、一个行省、一个法人团体、一座城镇或一个官职的法律优势。它涵盖免税、领主捐税、特别法庭，以及做某一件特定事情排他的权利。它不是势利的同义词。一项特权可以被书写、被申辩、被继承，并且仍然是这样一条理由：一项一般税为什么失败。
:::

官职属于特权一侧。许多司法与行政职位是财产，是被买来的，并且在实践之中能够传给一名继承人。一个高级法院职位的占有者，常常因为那项占有而为贵族。他靠费用与身份过活，而他有一个理由去抵抗这样一项改革：它会终结官职的买卖，或是对一项免税特权征税。“贵族”是一个太顺滑的词。廷臣、贫穷的行省乡绅与法官并不共享同一份收入。他们确实共享一个理由，去希望一项新税落在别处。

高等法院（parlements）是注册法律的王室法庭，不是一个不列颠议会，也不是一座现代最高法院。它们可以拖延注册并且抗议。当大臣们试图让特权者纳税时，这些法庭谈论根本法。那套语言是一种真实的约束，而不是一部民众的宪法。捍卫免税豁免的法官是一个反对派，不是等待中的民主。那种反对是一个宪制传统还是一个地位的防卫，史家意见不一。两种读法都有证据。哪一种都没有把一份谏书变成一场革命。

:::quiz
三级会议开幕那一天，哪一个描述符合旧制度？
- [ ] 一架名为专制主义的单一机器，在其中特权只是一件戏装
- [x] 一个由特权、官职与债务构成的复合物，其中一项一般税在政治上很难
- [ ] 一个只差名号的共和国，等待一份赤字被公布
- [ ] 一个宫廷家户，它的支出是我们能够引用的、经过测量的原因
:::solution
[[#def-old-regime]]与[[#def-privilege]]就是本章使用的描述：诸等级、诸行省、可买卖的官职，以及一个充满免税特权的税制。作为一架单一机器的专制主义是一个标签，不是一架你能指着的机器。没有任何赤字数字被锁定，所以一个家户的支出不能被提供为那个经过测量的原因。公元1789年5月5日，这个国家仍然是一个正在召集自己三级会议的君主制，不是一个共和国。
:::
:::

那位王后属于一则警告，不属于定义。一位外国公主与一桩项链丑闻是一幅漫画的材料，而一句关于面包的话没有被确立为出自她口，所以我们不会复述它。一幅关于一个女人的漫画喂养一个厌女的故事。它不解释为什么一项税更容易宣布、而不是从免税者手里征起，也不解释为什么一位法官能够阻挡一位大臣。我们不使用任何以里夫尔计的款额。人格不是一笔预算。

税名显示出同一个结构，而不带一个岁入。*taille*落在没有特权的人身上。*gabelle*是一桩盐税，被痛恨而且不均衡。一项*vingtième*，就其名称而言是二十分之一，仍然遇到免税特权与抵抗。说出这些税的名字就够了。一张我们所没有的收据会是一种虚假的精确。要点在于谁能够逃脱。

## 没有新授权的战争财政

我们能够定年的那场战争是七年战争，1756至1763年，在欧洲、北美、加勒比、西非与印度打的。法国失去了领土，并且大量花费。1763减1756是7。1789减1756是33。一个财政问题可以搁置一代人。那段跨度已经是一条反对如下观念的论证：一场战争的账单本身就是一场革命。

公元1776年之后的进一步诸场战争添加进了债务。那一年美国的《独立宣言》只是背景，正如[[states/enlightenment]]所坚持的，而本图谱没有为法国王冠卷入那场冲突锁定一个年份，所以我们不发明一个。有日期的背景是战争财政，包括1756至1763年的那场全球战争。一个在1780年代需要信用的大臣遇到的是一个结构：为战争缔结的债务，以及不会安静地变成一个统一税基的诸特权。

:::theorem 一个赤字还不是一个关于谁为法律授权的变化 {#thm-not-yet}
一场财政危机只有当为税收与债务授权的诸手段本身被拒绝、被替换时，才变成一场革命。对一个短缺的知晓不是那个拒绝。公元1789年的法国旧制度是一个由特权、官职与债务构成的复合物，而债务是真实的。革命不以大臣们知晓他们短缺的那一刻定年。债务是一个条件。它不是一个充足的原因，也没有使六月诸事件成为必然。
:::
:::proof
证据是制度的与比较的。1756至1763年的战争财政留下了一个需要税收与信用的王权。特权，如[[#def-privilege]]，让诸等级与持职者抵抗一项一般税。诸高等法院可以拖延法律。大臣们可以倒台，而君主制的形式不变。不列颠通过一个议会为债务提供资金，有公元1694年的英格兰银行，以及在公元1688年的登陆之后公元1689年的《权利法案》。那个解决方案不是一场民主革命，而“光荣革命”这个名字是党派性的，正如[[states/fiscal-military]]所说。带有一个行得通的授权的债务是一个财政国家。带有一个被堵塞的授权的债务是一场政治危机。只有拒绝旧的授权，才是这条论断意义上的革命。

什么会构成对这条论断的反证？一个有日期的行为，在公元1789年6月17日之前，凭它一个短缺本身就已经移动了立法权威，而三级会议的开会方式没有变化。或者一个欧洲，其中每一个负债沉重的君主制都产生了同一个断裂。这两样我们都没有。一个被锁定的赤字数字也没有帮助：一个数字不是一个议会，而本图谱没有这样一个数字。
:::

那条反对意见值得同样的篇幅。它说，启蒙公众已经撤回了正当性，所以财政危机只是点燃了一条已经铺好的引信。《百科全书》（Encyclopédie）始于公元1751年。《社会契约论》（Social Contract）与《爱弥儿》（Emile）是公元1762年。贝卡里亚（Beccaria）论犯罪与刑罚是公元1764年。亚当·斯密（Adam Smith）的《国富论》（Wealth of Nations）与美国的《独立宣言》是公元1776年。[[states/enlightenment]]拒绝了启蒙运动导致法国大革命那句话，而本章把那个拒绝当作一个前提。一套权利的语言能够为一个国王治下的一项税作辩护，能够为一份谏书作辩护，也能够为第三等级是民族这个宣称作辩护。可得性不是一个目的地。一个原因，在[[sources/argument]]里，必须是一个本可以不同的东西。三级会议本来仍然能够按等级表决一项税，然后回家。它们没有这样做，是公元1789年的一个事件，不是从公元1762年得出的一次推演。

关于各种权重，史家意见不一：债务、诸高等法院、权利的语言、面包的压力。这个分歧关乎分量，不关乎日期。我们不会发明一个价格或一个收获年份。面包解释压力。它不会签署国民议会这个名称。

公元1772年对波兰-立陶宛的瓜分，是同一条轴上的一个不同事件。俄罗斯、普鲁士与奥地利切入了一个拥有议会的联邦。经由公元1793年与公元1795年的那个序列在[[states/east]]。一个议会没有使一个国家安全，一场财政危机也没有把一个国家注定交给革命。法国在公元1789年没有被瓜分。这个对照拦住了一个范畴错误。

:::example 同一条轴上的两段跨度 {#ex-span}
七年战争始于公元1756年。波兰-立陶宛的第一次瓜分在公元1772年。三级会议在公元1789年开幕。计算从1756年到1789年、以及从1772年到1789年的年份之差。然后说出一个定在1789年的三年窗口，对更早的那些圆点做了什么。
:::solution
1789减1756是33，而1789减1772是17。那场战争自己的括号，1756至1763年，相差7，所以这33年中的大部分是余波。一个半宽为3年的窗口显示1789的一个邻域，而够不到1772年或1756年。把窗口留在那里，就藏起了财政背景。这就是你要移动年份的原因。1789年的那一个单独圆点也不能显示5月5日与七月更晚的一天是不同的行为。
:::
:::

:::example 从开幕到新名称的天数 {#ex-days}
三级会议于公元1789年5月5日开幕。国民议会于公元1789年6月17日被宣告。6月17日在5月5日之后多少天？五月有31天。数较晚的那个日期，而不是把两个端点都包含在内的总数。
:::solution
从5月5日之后到5月31日的天数：31减5是26。从五月底到6月17日是17天。26加17是43，所以6月17日在5月5日之后43天。这个间隔不是一种突然性的心绪。一个团体可以在43天里改变它的宣称，而仍然是作为旧的三级会议开幕的。这段跨度长到一个计策够用，又短到禁止“1789年是一团模糊”这个故事。
:::
:::

## 从一个赤字到三级会议

召集三级会议是一个王室决定。王权需要钱与信用，而平常的诸条路径——敕令、诸法庭、一次显贵会议——没有产生一个总体的解决方案。我们不给显贵会议定年。那一年没有被锁定，而逻辑也不需要它。当平常的诸团体不愿为一项税提供正当性时，一个国王伸手去取那个团体，按旧的语言，那个团体能够替王国发言。他召集三级会议是为了拯救这个财政君主制，不是为了废除他自己。意图不是结果。它是一个证据，证明六月没有被预先写好。

三级会议将如何投票，是危机之中的危机。按等级投票让教士与贵族能够在票数上压过第三等级，即便它的代表团与其他两级的总和相当。公元1789年的规则确实给予了第三等级那个扩大的代表团。我们陈述规则而不陈述一个人数清点，因为没有任何清点被锁定。数字只有在按人头投票时才有分量。特权诸等级与国王偏爱旧的形式。第三等级的代表们有理由拒绝它。一条有争议的规则，把一个财政问题变成了一个代表权问题。那个转换就是本章的心脏。它不是堡垒前的人群，也不是一个共和国。

公元1789年5月5日，三级会议开幕。把那个上午仍然当作国王的会议。大厅、演辞、资格审查：那些都还不是一个国民议会。信任状应当共同查验还是按等级查验的争执，占据了随后的诸周。程序就是政治。一个想在五月第一周要一场暴动的读者，是在把一个更晚的日子倒着读。

:::proposition 那道铰链是6月17日，不是开幕本身 {#prop-hinge}
公元1789年6月17日，第三等级，在部分教士加入之下，宣告自己为国民议会，并且主张对税收的权威。那个宣告，而不是5月5日的开幕，才是那道铰链，一场财政危机在它上面变成一场代表权危机。限度是这条论断的一部分。6月17日没有废黜国王，没有撰写八月的法令，也没有攻占巴士底狱。它改变了谁主张授权。它没有完成一个新政权的。
:::
:::proof
5月5日，三级会议开幕。6月17日，命名国民议会。中间的日子花在资格审查上，亦即旧的形式能否存活。那个宣告把税收系于议会的同意。一个按三个等级召集的团体，已经以一个民族作答。那就是[[#thm-not-yet]]所要求的新授权，在它之前，革命这个词才能被使用而不作弊。

什么会构成对这条命题的反证？这样一个证据：5月5日就已经移转了立法权力，以至于6月17日是一个手续；或者6月17日在税收上法律上什么都没有触动。那场典礼就是旧制度，以它自己的诸形式。代表们的论点是：税收现在需要他们宣称自己是的那个议会。他们能否使那个宣称站住，在[[revolutions/from-1789]]，不是一个把那道铰链挪回5月5日的理由。
:::

我们有意停在铰链那里。6月20日，代表们将约束自己不解散，直到一部宪法存在。7月14日，一群巴黎人将攻占巴士底狱。8月4日到11日的诸法令将攻击封建权利。8月26日，《人权与公民权宣言》将被定年。10月5日到6日，一次行军将把国王从凡尔赛（Versailles）带向巴黎。每个都是一个不同的行为。在这里叙述它们，会把那道铰链变成整个夏天，并且夹带进6月17日没有产生的结果。这些日期存在，是为了不让一个命名被误认为终结。那个命名不是那次强攻。

一份公元1789年的小册子，西哀士（Sieyès）论第三等级，属于这道铰链，不属于后来的一个共和国。我们不会引用它。转述起来，它宣称第三等级已经是民族，而特权诸等级不是政治社会的一个必要部分。一次转述不是一个史料文本。要紧的是方向：在那个关于选举的争执的同一个季节里，民族是对着特权被定义的。这份小册子没有开幕三级会议，也没有通过一项法令。印刷品与6月17日的投票相关，而不是同一回事。把它们合拢，就让那条关于1762年的反对意见重新进来。

:::quiz
公元1789年6月17日傍晚，什么是真的？
- [ ] 共和国已经被宣告，国王已经被处死
- [ ] 巴士底狱已经陷落，八月的法令已经废除封建捐税
- [x] 一个国民议会已经被宣告，而共和国、国王的死与恐怖统治都还在未来
- [ ] 公布赤字已经完成了革命
:::solution
[[#prop-hinge]]把那道铰链放在6月17日。共和国是公元1792年9月21日到22日。国王死于公元1793年1月21日。恐怖统治，作为一个被命名的时段，从公元1793年9月持续到公元1794年7月27日。巴士底狱是公元1789年7月14日，八月的法令是8月4日到11日，两者都在更晚，两者都在下一课教授。一个赤字本身不是一场革命，这就是[[#thm-not-yet]]。
:::
:::

## 一份陈情能够支持什么

陈情书（cahiers）是为选举起草的那些陈情清单。它们是史料，不是一个民族的心灵。一份堂区清单与一份贵族清单是不同的文书。一次沉默是关于谁被要求书写的证据，那个区分在[[sources/evidence]]，不是一个空的心灵的证明。许多清单要求定期开会、税收改革与某些弊病的终结，用的是关于国王的效忠语言。一个公式里的效忠不是被测量过的感情，也不是一个共和派的宣言。一项对共和国的要求必须在文本中找到。

那条限度反过来也成立。一个降低一项税的请求是一个诉苦，而一捆诉苦还不是国民议会，因为一个村庄不宣告一个民族。尺度，正如[[sources/scale]]所坚持的，不是免费的。代表们在6月17日的行为是一个国家行为。一份堂区文本是一个地方行为。它们可以指向同一个方向，而仍然是不同的证据。

:::example 一句虚构的陈情书句子 {#ex-invented}
下面这句话为示例而虚构。它不是史料。它不是任何一份陈情书的引文。“圣安旺泰（Saint-Inventé）村只请求降低盐税，颂赞国王，而且对共和国一字不提。”这个村庄是虚构的。如果一份真的陈情书曾这样说，这句话能够支持什么，又不能支持什么？
:::solution
它能够支持一个地方的财政诉苦，以及那个文体的效忠语言，不是一个王国的意志。它不要求一个共和国。一个降低一项税的请求是一个诉苦，所以它不能显示满足，而一个村庄不是法国。它没有陈述任何赤字。一个民族的要求将需要许多份陈情书，与贵族及教士的诸清单并置。你仍然不会拥有6月17日的傍晚，一个代表们的行为。那个虚构的村庄是一个尺度陷阱。
:::
:::

:::example 一笔没有改称立法机关的债务 {#ex-britain}
把两个有日期的制度并排放置。公元1694年，英格兰银行创建。公元1789年5月5日，法国三级会议开幕。这个对照被允许证明什么，什么又是超出一步？
:::solution
这个对照可以显示，公共债务与政治断裂不是同一个事件。不列颠带着一个自公元1694年起的银行、一个在公元1688年之后由公元1689年的《权利法案》重述的议会，打了这个世纪的诸场战争。法国在公元1789年开幕三级会议，是因为税收与信用被一套不同的特权堵塞。它不可以显示不列颠是平静的或一个模范。公元1688年的解决方案不是一场民主革命，而它的绰号是党派性的。1789减1694是95。那个间隙就是要点，而它是支持[[#thm-not-yet]]的证据，不是一个名为近代国家兴起的故事。
:::
:::

:::widget timeline
start: 1750
end: 1790
window: 3
events: 1756,七年战争; 1772,第一次瓜分; 1789,三级会议
caption: 移动年份。一场战争、一次瓜分，以及三级会议的开幕。最后一个圆点是公元1789年5月5日，不是7月14日。
:::

把年份移到1789年，把窗口留在3。你看见三级会议，不是1756年，也不是1772年。往回滑，三级会议消失。在两者之间的那次瓜分摧毁了一个有议会的联邦。它不是一个法国的赤字。1789年的一个圆点不能既是5月5日又是7月14日。本章把它读作5月5日，也读作6月17日的那道铰链，后者共享这一年，而它本身不是一个圆点。下一章把七月、八月与十月读作它们自己的行为。

:::warning 把赤字，或者那位王后，当作命运
人们重复说，旧制度倒台是因为赤字为人所知，或者因为一位王后轻浮。第一种把一个财政危机与一个谁为法律授权的变化相混淆，那就是[[#thm-not-yet]]，并且把六月当作写好的。大臣们召集三级会议是为了拯救一个君主制。第二种把一个女人放在一个税制的位置上。一桩丑闻不是一笔预算，而没有任何赤字被锁定、可以用来同一个家户相比。当你问谁能够阻挡一项税、以及6月17日改变了什么时，那幅漫画就失败了。
:::

:::history
公元1789年5月5日，三级会议在路易十六（Louis XVI）治下开幕，召集它是因为王权需要钱，以及一种以别的方式得不到的同意。6月17日，第三等级宣告了一个国民议会。那个夏天有更晚的行为，而它们不是这条注记的内容。共和国不在它们之中，也不在这两个日期之中。
:::

路易十六在6月17日仍然是国王。他召集了三级会议，并将设法对付他所召集的东西。他还没有在一个公会面前受审。把他叙述为已经死了，就是把公元1793年1月21日读进一个五月的早晨。把他叙述为唯一的原因，就回到那幅漫画。堵塞的是那些制度。改名的是那些代表。债务让这次召集，在内阁看来，像一条出路。

## 通向何处

[[revolutions/from-1789]]从5月5日与6月17日重新开始，然后做本章拒绝做的工作：那次宣誓、巴士底狱、八月的法令、《人权与公民权宣言》、十月诸日，以及公元1791年与公元1792年不同的诸政权，包括圣多明戈（Saint-Domingue）的起义。使一笔有资金支撑的债务变得可想象的那个财政国家在[[states/fiscal-military]]。那些没有迫使六月发生的诸公众在[[states/enlightenment]]。在公元1772年被瓜分的那个联邦在[[states/east]]。一个标签如何不同于一个原因，在[[sources/argument]]。

:::summary
- 旧制度是一个由特权、官职、行省法律与债务构成的复合物，不是一幅宫廷漫画，也不是一架名为专制主义的机器。
- 特权是一个法律优势。它使一项一般税难以通过。那是一个政治事实，不是一个关于礼数的故事。
- 七年战争，1756至1763年，是背景里那个有日期的战争财政。从1756年到1789年，年份数字相差33。
- 没有任何赤字数字被锁定。我们不发明一个，我们也不让一位王后顶替一个。
- 公元1751年、公元1762年与公元1764年的那些书是一个公众，不是一个充足的原因。一个原因必须是一个本可以不同的东西。
- 公元1789年5月5日，三级会议在旧君主制内部开幕。6月17日，国民议会被宣告。那道铰链是一个为税收授权的新宣称。它不是巴士底狱，也不是一个共和国。
- 公元1688年之后的不列颠，有公元1689年的《权利法案》与公元1694年的英格兰银行，显示公共债务不必改称一个立法机关。这个对照限制了法国的论断。它不是一个道德排名。
:::

## 习题

:::exercise 背景的长度 {level=1 check="33"}
七年战争始于公元1756年。三级会议于公元1789年开幕。年份之差是多少？（请输入年数。）
:::solution
用较晚的年份减去较早的年份。1789减1756是33。差是33年。它不是一个中间什么都没有发生的论断，也不是一次把同一个减法变成34的包含两端的计数。这个算术与[[#ex-span]]里的相同。
:::
:::

:::exercise 从瓜分到三级会议 {level=1 check="17"}
波兰-立陶宛的第一次瓜分在公元1772年。三级会议于公元1789年开幕。年份之差是多少？（请输入年数。）
:::solution
1789减1772是17。那次瓜分与那次开幕相隔17年。它们共享一个世纪，而它们不是一个事件。一个切开一个联邦。另一个开幕一个法国议会。
:::
:::

:::exercise 到铰链的天数 {level=1 check="43"}
开幕是公元1789年5月5日。国民议会是公元1789年6月17日。6月17日在5月5日之后多少天？五月有31天。不要为包含两个端点而加一。（请输入天数。）
:::solution
5月5日之后到5月31日的天数：31减5是26。从五月底到6月17日是17天。然后26加17是43。6月17日在5月5日之后43天。
:::
:::

:::exercise 替换一个标签 {level=2}
一部教科书写道：“专制主义在1789年崩溃了。”使用[[#def-old-regime]]以及特权与诸高等法院的诸制度，重写这句话，使一个读者能够检验它。不要发明一个赤字数字。
:::solution
公元1789年的法国是一个由特权、可买卖的官职与王室债务构成的复合物，而大臣们无法使一项一般税通过它。三级会议于5月5日开幕。6月17日，第三等级宣告了一个国民议会，并且主张对税收的权威。那改变了谁主张为法律授权。那不是一架机器的崩溃，也还不是一个共和国。诸高等法院是捍卫地位的持职者。两个日期与特权的法律含义能够被检验。“专制主义崩溃了”不能。
:::
:::

:::exercise 六月本可以走另一条路吗？ {level=2}
假设三个等级在公元1789年六月初达成一致，按旧的形式表决一项税，然后回家。公元1751年、1762年与1764年的那些书仍然会被印行。[[#thm-not-yet]]仍然站得住吗？这个假设对“那些书使一场革命成为必需”这个观念做了什么？
:::solution
这个假设就是一个原因所需要的那个“本可以不同”。一项按等级表决的税，加上一次解散，本来会是旧授权内部的一个补救，6月17日将没有一个国民议会。公元1751年、1762年与1764年的那些书仍然会存在，所以它们是不充足的。代表们没有解散。这个假设检验必然性。它不描述六月。[[#thm-not-yet]]站得住：那个拒绝就是那个新授权，不是印刷，也不是光那个债务。那些公众使那套语言更容易理解。那不等于注定发生。
:::
:::

:::exercise 6月17日没有做什么 {level=2}
说出革命序列中四个有日期的行为，它们在公元1789年6月17日尚未成真。然后说出一个停在5月5日、没有6月17日的章节，为什么会停得太早。
:::solution
那次宣誓是公元1789年6月20日，巴士底狱是公元1789年7月14日，《人权与公民权宣言》是公元1789年8月26日，共和国是公元1792年9月21日到22日。没有一样在6月17日的傍晚成真。国王在公元1793年1月21日的死，以及恐怖统治在公元1793年9月的惯例开端，都更远。停在5月5日，将留下一个正在召集自己三级会议的财政君主制。[[#prop-hinge]]把那道铰链放在一个新授权被宣称的那一天。没有它，你有一个会议，而不是让这门课程能够说出革命的那个拒绝。
:::
:::

:::exercise 什么会击败这条论断？ {level=3}
:::hint
寻找一个在任何对旧形式的拒绝之前定年的行为，并且问一问：债务本身是否移动了立法的权威。另一个负债的国家，只在你不把这个对照变成劝告时，才算数。
:::
[[#thm-not-yet]]说一场财政危机还不是一场革命。描述一条会使你放弃这条论断的证据，以及一条只会使你收窄它的证据。不要使用任何发明出来的赤字，也不要把一篇发明出来的演说当作证据。
:::solution
如果你放弃这条论断，那会是因为：在公元1789年6月17日之前，在任何关于三级会议如何开会的争执之前，一个短缺本身就已经移动了立法权威。一个仍然在要钱的典礼不是那个行为。如果负债的诸君主制在没有任何政治选择的情况下，经常产生同一个断裂，你也会放弃它。它们没有。

你只会收窄它，如果一个被锁定的账目显示，一场战争的债务在召集三级会议的决定中压过了特权。那改变一个分量。它没有把这次召集变成6月17日。不列颠已经在收窄这条论断：当授权行得通时，债务能够被承载。一篇发明出来的大臣演说既不会收窄它，也不会击败它。
:::
:::

:::exercise 那位王后，以及一个原因的尺度 {level=3}
:::hint
把一个文化事实，例如一份小册子或一则谣言，同一个财政制度分开，例如一项免税特权或一个可买卖的官职。问一问：单单一个家户仍然没能解释什么。
:::
一位读者说：“特权与6月17日是不必要的。宫廷挥霍无度，王后被人憎恨，而那份憎恨就是革命。”分三步作答。说出一份敌意的小册子能够显示什么。在一个赤字数字都没有被锁定的前提下，说出它不能显示什么。说出即使一位未来的历史学家锁定一个庞大的家户总数，6月17日将仍然坐落哪里。
:::solution
一份敌意的小册子能够显示印刷品攻击过那位王后，以及名声能够触到信用，因为放贷者有意见。那就是那个论点的最强版本。

它不能显示一个家户导致了那场财政危机。没有任何赤字被锁定，所以一个也不可以被发明。一桩丑闻不废除一项特权或一个可买卖的官职。一种心绪不是一个三级会议。

即使有一个未来的家户总数，6月17日将仍然是那道铰链。一张庞大的账单解释召集三级会议的压力。它没有强迫代表们拒绝旧的开会方式。那位读者的句子跳过了那个日期。
:::
