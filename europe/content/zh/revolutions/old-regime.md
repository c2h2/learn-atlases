为什么财政危机还不是革命？

一个无力偿付的王权处于政治危险之中，但仅凭这一点，它并不处于革命之中。这里所说的革命，是指由谁授权立法发生了改变。法国面临的是一场偿付危机：靠举债支撑的战争，以及使普遍税难以通过的特权。只有当被召来解决危机的机构拒绝按旧方式开会时，这场危机才变成代表权危机。三级会议于1789年5月5日开幕；6月17日，第三等级自称国民议会。这两个日期就是转折的枢纽。攻占监狱、共和国、国王之死、恐怖统治，都分属后面的课。

有两条捷径总是唾手可得。一条说，一旦赤字为人所知，这个政权就必然垮台；另一条说，宫廷，尤其是一位王后，把王国挥霍到了崩溃。两者都无法对照制度加以检验。年表没有锁定任何赤字数字，因此这里一个也不编造。旧制度不会被讲成一户人家的家务事。特权、官职与债务才是政治事实。一份公布出来的亏空并不会投票。

## 是复合体，而非漫画

:::definition 旧制度 {#def-old-regime}
**旧制度**一词取自法语 *ancien régime*，指一场革命宣称已经终结的那种秩序。在本章中，它指1789年三级会议开幕时法国由特权、可买卖的官职、各省法律与王室债务构成的复合体。它既不意味着“现代以前的法国”，也不意味着一出宫廷喜剧。其中很大一部分，是建立在更古老权利之上的晚近战争财政。
:::

按[[states/composite-monarchy]]的意义，法国是一个复合君主国（composite monarchy）：一位国王，多种法律。各省保留着不同的约定，有的在本省三级会议中表决税收，有的由王室官员治理。一座城镇、一个行会或一位领主，可以享有邻人所没有的免税权、行业垄断、捐税或法庭。把这称为专制主义，就掩盖了其中的讨价还价。[[states/fiscal-military]]所讲的路易十四（Louis XIV）政府宣扬自己的能力，却并没有废除那些它只能绕开征税的特权。

三级会议由三个等级组成：教士、贵族，以及选举所能看见的其余所有人。第三等级并不等于“人民”。女性不能当代表，殖民地的被奴役者则在这一分类之外。1685年的《黑人法典》（Code Noir）见[[states/atlantic]]，撕开种植园奴隶制的那场起义见[[revolutions/from-1789]]。1789年的第三等级代表，大多是律师、官职持有者与有产者。“民族”是一项主张，而不是一次人口普查。

:::definition 特权 {#def-privilege}
**特权**是附属于某一等级、省份、团体、城镇或官职的法律上的优势，包括免税权、领主捐税、特别法庭，以及做某件事的专有权利。它不是势利的同义词。特权可以写成文字、在法庭上申辩、世代继承，并且正是普遍税难以推行的原因。
:::

官职与特权密不可分。许多司法与行政职位是财产，可以买卖，实际上还能传给继承人。高等法院职位的持有者，往往凭借这一职位而成为贵族。他靠规费与身份生活，因而有理由抵制废除卖官或对免税权征税的改革。“贵族”这个词过于笼统：廷臣、贫穷的外省乡绅与法官的收入各不相同，但他们都有理由希望新税落在别人头上。

高等法院（parlements）是负责登记法律的王室法院，既不是不列颠式的议会，也不是现代的最高法院。它们可以拖延登记并提出抗议。当大臣们试图让特权者纳税时，这些法院就援引根本法。这套语言是真实的约束，却不是一部人民的宪法。捍卫免税权的法官是一种反对派，而不是蓄势待发的民主。这种反对究竟是一种宪政传统，还是对身份地位的维护，史家意见不一，两种解读都有证据，但哪一种都不能把一份谏诤书变成一场革命。

:::quiz
三级会议开幕那天，哪一项描述符合旧制度？
- [ ] 一台名为专制主义的单一机器，特权在其中只是装饰
- [x] 一个由特权、官职与债务构成的复合体，普遍税在其中很难在政治上推行
- [ ] 一个只差名号的共和国，只等赤字公之于众
- [ ] 一个宫廷家户，其开支是我们可以援引的、经过测算的原因
:::solution
本章采用的描述是[[#def-old-regime]]与[[#def-privilege]]：等级、省份、可买卖的官职，以及充斥免税权的税制。作为单一机器的专制主义只是一个标签，不是一台你能指认的机器。年表没有锁定任何赤字数字，所以不能把一户人家的开支当作经过测算的原因。1789年5月5日，这个国家仍是一个正在召集三级会议的君主国，而不是共和国。
:::
:::

那位王后只属于警示，而不属于定义。一位外国公主与一桩项链丑闻，是漫画的素材；那句关于面包的话并未确证出自她口，因此这里不予重复。把一个女人画成漫画，助长的是厌女的故事，却解释不了为什么一项税宣布起来容易、向免税者征收却很难，也解释不了为什么一位法官能够阻挡一位大臣。本课不使用任何以里弗尔计的金额。个性不是预算。

税种的名称不需要岁入数字，也能显示同样的结构。*taille*（军役税）落在没有特权的人身上；*gabelle*（盐税）令人痛恨，且负担不均；*vingtième*（廿一税），顾名思义是二十分之一，却仍然遭遇免税与抵制。说出这些税的名称就够了，引用一张我们并没有的收据，只是虚假的精确。要点在于谁能够逃税。

## 没有新授权的战争财政

我们能够定年的战争是1756年至1763年的七年战争，战场遍及欧洲、北美、加勒比、西非与印度。法国丧失了领土，花费巨大。1763减1756等于7，1789减1756等于33。一个财政问题可以拖延一代人之久。这段跨度本身就已反驳了“战争的账单就等于革命”的想法。

1776年以后的战争进一步加重了债务。正如[[states/enlightenment]]所坚持的，同年美国的《独立宣言》只作为背景；本图谱没有锁定法国王室参与那场冲突的年份，因此这里也不编造。有日期可考的背景是战争财政，包括1756年至1763年的那场全球战争。1780年代需要借贷的大臣，所面对的是一种结构：为战争而举的债，以及不会悄然变成统一税基的种种特权。

:::theorem 赤字还不等于立法授权者的改变 {#thm-not-yet}
只有当授权征税与举债的方式本身遭到拒绝并被取代时，财政危机才成为革命。知道财政亏空，并不是这种拒绝。1789年的法国旧制度是由特权、官职与债务构成的复合体，债务是真实的；但革命并不从大臣们得知亏空的那一刻算起。债务是一个条件，而不是充分原因，也没有使六月的事件成为必然。
:::
:::proof
证据既来自制度，也来自比较。1756年至1763年的战争财政，留下了一个需要税收与借贷的王权。[[#def-privilege]]所说的特权，使各等级与官职持有者得以抵制普遍税。高等法院可以拖延法律。大臣可以下台，而君主制的形式不变。不列颠则通过议会为债务提供资金：1694年有了英格兰银行，1688年登陆之后有了1689年的《权利法案》。正如[[states/fiscal-military]]所说，那一安排并不是民主革命，“光荣革命”这个名称带有党派色彩。授权渠道畅通时，债务造就的是财政国家；授权渠道受阻时，债务造成的是政治危机。只有拒绝旧的授权，才是这一论断意义上的革命。

什么能推翻这一论断？一项在1789年6月17日之前、单凭财政亏空就已转移了立法权的有日期的行为，而三级会议的开会方式却没有任何改变；或者一个所有负债累累的君主国都发生了同样断裂的欧洲。这两样我们都没有。即使有一个锁定的赤字数字也无济于事：数字不是议会，何况本图谱并没有这样的数字。
:::

反对意见也应得到同样的篇幅。它认为，启蒙公众早已撤回了对政权的认可，财政危机只是点燃了一条早已铺好的导火索。《百科全书》（Encyclopédie）始于1751年；《社会契约论》（Social Contract）与《爱弥儿》（Emile）在1762年；贝卡里亚（Beccaria）论犯罪与刑罚在1764年；亚当·斯密（Adam Smith）的《国富论》（Wealth of Nations）与美国《独立宣言》在1776年。[[states/enlightenment]]拒绝了“启蒙运动导致法国大革命”这句话，本章把这一拒绝作为前提。权利的语言既可以为君主治下的一项税辩护，也可以为一份谏诤书辩护，还可以为第三等级自称民族的主张辩护。可以利用，不等于必然走向某个终点。按照[[sources/argument]]的说法，原因必须是本来可能不同的东西。三级会议本来仍可以按等级表决一项税，然后各自回家。它们没有这样做，这是1789年发生的事件，而不是从1762年推导出来的结论。

对于各因素的分量，即债务、高等法院、权利语言与面包的压力，史家意见不一。分歧在于分量，而不在于日期。本课不编造任何价格或歉收年份。面包解释的是压力，它并不会签下“国民议会”这个名称。

1772年对波兰-立陶宛的瓜分，是同一时间轴上的另一个事件：俄罗斯、普鲁士与奥地利瓜分了一个有议会的联邦，1793年与1795年的后续见[[states/east]]。有议会并没有使一个国家安全，财政危机也没有注定使一个国家走向革命。1789年的法国并没有被瓜分。这一对照防止了一种范畴错误。

:::example 同一时间轴上的两段跨度 {#ex-span}
七年战争始于1756年，波兰-立陶宛的第一次瓜分在1772年，三级会议于1789年开幕。请分别计算从1756年到1789年、从1772年到1789年的年份之差，然后说明一个以1789年为中心、半宽三年的窗口，对更早的那些点意味着什么。
:::solution
1789减1756等于33，1789减1772等于17。战争本身的起止年份1756年至1763年相差7，所以这33年中大部分是战后余波。半宽3年的窗口只显示1789年附近的年份，够不到1772年或1756年。把窗口停在那里，就掩盖了财政背景，所以你需要移动年份。1789年这一个点，也无法显示5月5日与七月的某一天是不同的行为。
:::
:::

:::example 从开幕到改名的天数 {#ex-days}
三级会议于1789年5月5日开幕，国民议会于1789年6月17日宣告成立。6月17日在5月5日之后多少天？五月有31天。只计算到较晚的日期，不要把两端都算进去。
:::solution
5月5日之后到5月31日：31减5等于26天。从五月底到6月17日是17天。26加17等于43，所以6月17日在5月5日之后43天。这段间隔并不是一种突如其来的情绪。一个机构可以在43天里改变自己的主张，而开幕时仍是旧式的三级会议。这段时间足以施展策略，又短到足以否定“1789年是一团模糊”的说法。
:::
:::

## 从赤字到三级会议

召集三级会议是国王的决定。王室需要金钱与信贷，而通常的途径，即敕令、法院和显贵会议，都没能带来全面的解决。这里不为显贵会议定年：那个年份没有锁定，论证也不需要它。当通常的机构不肯为一项税提供正当性时，国王就会求助于那个按古老说法能够代表全国说话的机构。他召集三级会议是为了挽救财政君主制，而不是为了废黜自己。意图不等于结果，但它证明六月的事并不是事先注定的。

三级会议如何投票，是危机中的危机。按等级投票，即使第三等级的代表人数与其他两个等级之和相当，教士与贵族仍能在票数上压倒它。1789年的规则确实给予第三等级加倍的代表名额。这里只陈述规则，不给出人数，因为年表没有锁定人数。只有按人头投票，人数才有意义。特权等级与国王倾向于旧形式，第三等级的代表则有理由拒绝。一条有争议的规则，把财政问题变成了代表权问题。这一转变正是本章的核心。它既不是要塞前的人群，也不是共和国。

1789年5月5日，三级会议开幕。不妨把那个上午仍然看作国王的会议：会场、演说、资格审查，都还不是国民议会。资格审查应当合议进行还是按等级分别进行的争执，占据了随后的几个星期。程序就是政治。想在五月第一周看到暴动的读者，是把后来某一天的事倒读回来。

:::proposition 枢纽是6月17日，而不是开幕本身 {#prop-hinge}
1789年6月17日，第三等级在部分教士的加入下，宣布自己为国民议会，并主张对税收的权力。正是这一宣布，而不是5月5日的开幕，使财政危机转变为代表权危机。这一论断的限度也是论断的一部分：6月17日没有废黜国王，没有制定八月法令，也没有攻占巴士底狱。它改变的是由谁主张授权，并没有建成一个新政权。
:::
:::proof
5月5日，三级会议开幕；6月17日，国民议会得名。其间的日子用于资格审查，也就是旧形式能否存续的问题。这一宣布把税收与议会的同意联系起来：一个按三个等级召集的机构，以一个民族的名义作出了回答。这就是[[#thm-not-yet]]所要求的新授权，有了它，“革命”一词才能被正当地使用。

什么能推翻这一命题？证明5月5日就已经转移了立法权，使6月17日只是一道手续；或者证明6月17日在法律上丝毫没有触动税收。开幕典礼是旧制度按其自身形式举行的。代表们的要点在于：征税从此需要得到他们所自称的那个议会的同意。他们能否让这一主张站稳脚跟，见[[revolutions/from-1789]]，这并不是把枢纽挪回5月5日的理由。
:::

我们有意停在这个枢纽上。6月20日，代表们将宣誓，在制定宪法之前决不解散；7月14日，巴黎民众将攻占巴士底狱；8月4日至11日的法令将冲击封建权利；8月26日是《人权与公民权宣言》的日期；10月5日至6日，一次进军将把国王从凡尔赛（Versailles）带往巴黎。每一件都是不同的行为。在这里叙述它们，就会把这个枢纽扩展成整个夏天，并夹带进6月17日并未产生的结果。列出这些日期，是为了不让一次命名被误认为终点。命名不是攻占。

1789年西耶斯（Sieyès）论第三等级的小册子，属于这个枢纽，而不属于后来的共和国。这里不引用它。转述其意，它主张第三等级已经就是民族，特权等级并不是政治社会的必要组成部分。转述不是史料原文。要紧的是方向：在关于选举的争执的同一季节里，民族正被界定为特权的对立面。这本小册子既没有让三级会议开幕，也没有通过任何法令。印刷品与6月17日的投票相互关联，却不是同一回事。把两者混为一谈，就又给关于1762年的那种反对意见开了门。

:::quiz
1789年6月17日傍晚，哪一项是事实？
- [ ] 共和国已经宣告成立，国王已被处死
- [ ] 巴士底狱已经陷落，八月法令已经废除了封建捐税
- [x] 国民议会已经宣告成立，而共和国、国王之死与恐怖统治都还在后面
- [ ] 公布赤字已经完成了革命
:::solution
[[#prop-hinge]]把枢纽定在6月17日。共和国在1792年9月21日至22日，国王死于1793年1月21日；作为一个有名称的时期，恐怖统治从1793年9月持续到1794年7月27日。巴士底狱在1789年7月14日，八月法令在8月4日至11日，两者都更晚，都在下一课讲授。赤字本身不是革命，这就是[[#thm-not-yet]]。
:::

## 陈情书能支持什么

陈情书（cahiers）是为选举起草的申诉清单。它们是史料，而不是民族的心声。堂区的陈情书与贵族的陈情书是不同的文献。沉默是关于谁被请来书写的证据，这是[[sources/evidence]]所作的区分，而不能证明人们心中空无一物。许多陈情书用效忠国王的语言，要求定期开会、改革税收、革除某些弊端。程式化的效忠并不是经过测量的感情，也不是共和派宣言。对共和国的要求，必须在文本中找到。

这一限度反过来同样成立。请求减税是申诉，一堆申诉还不等于国民议会，因为村庄不会宣告成立一个民族。正如[[sources/scale]]所坚持的，尺度不能随意切换。代表们6月17日的行为是国家层面的行为，堂区文本则是地方层面的行为。两者可以指向同一方向，却仍是不同的证据。

:::example 一句虚构的陈情书 {#ex-invented}
下面这句话为示例而虚构。它不是史料。它也不引自任何一份陈情书。“圣安旺泰（Saint-Inventé）村只请求降低盐税，为国王祝福，对共和国只字未提。”这个村庄是虚构的。如果一份真实的陈情书这样说，这句话能支持什么，又不能支持什么？
:::solution
它能支持的是一个地方的财政申诉，以及这类文体的效忠语言，而不是一个王国的意志。它没有要求共和国。请求减税本身是申诉，所以不能证明人们心满意足；一个村庄也不等于法国。它没有给出任何赤字。要提出全国性的论断，需要许多份陈情书，并与贵族和教士的陈情书对照。即便如此，你仍然得不到6月17日傍晚，那是代表们的行为。这个虚构的村庄是一个尺度陷阱。
:::
:::

:::example 未曾改换立法机构名称的债务 {#ex-britain}
把两个有日期的制度并置：1694年，英格兰银行创立；1789年5月5日，法国三级会议开幕。这一对照可以证明什么？哪一步走得太远了？
:::solution
这一对照可以表明，公共债务与政治断裂不是同一回事。不列颠依靠1694年起的银行，以及1688年之后由1689年《权利法案》重申地位的议会，打了这个世纪的历次战争；法国在1789年召开三级会议，则是因为税收与信贷被另一套特权堵塞了。但它不能证明不列颠风平浪静或堪为楷模。1688年的安排不是民主革命，其别称也带有党派色彩。1789减1694等于95。这段间隔正是要点所在，它是支持[[#thm-not-yet]]的证据，而不是一个名为“现代国家兴起”的统一故事。
:::
:::

:::widget timeline
start: 1750
end: 1790
window: 3
events: 1756,七年战争; 1772,第一次瓜分; 1789,三级会议
caption: 移动年份。一场战争、一次瓜分与三级会议的开幕。最后一个点是1789年5月5日，而不是7月14日。
:::

把年份移到1789年，窗口保持为3。你会看到三级会议，却看不到1756年和1772年。往回拖动，三级会议就消失了。位于两者之间的那次瓜分，消灭了一个有议会的联邦，它并不是法国的赤字。1789年这一个点，不能同时代表5月5日与7月14日。本章把它读作5月5日，并读作6月17日这个枢纽；后者与它同年，却没有单独的点。下一章则把七月、八月与十月当作各自独立的行为来读。

:::warning 把赤字或王后当作命运
人们常说，旧制度垮台是因为赤字为人所知，或者因为一位王后轻佻。第一种说法混淆了财政危机与立法授权者的改变（即[[#thm-not-yet]]），并把六月看作照本宣科；而大臣们召集三级会议，本是为了挽救君主制。第二种说法把一个女人放在了税制的位置上。丑闻不是预算，而且年表没有锁定任何可与一户人家的开支相比较的赤字。只要问一问谁能阻挡一项税、6月17日改变了什么，这幅漫画就站不住了。
:::

:::history
1789年5月5日，三级会议在路易十六（Louis XVI）治下开幕。召集它，是因为王室需要金钱，以及一种别无他途可得的同意。6月17日，第三等级宣告成立国民议会。那个夏天还有更晚的行为，但不在这条注记之内。共和国不在其中，也不在这两个日期之中。
:::

6月17日，路易十六仍是国王。是他召集了三级会议，他也将设法驾驭自己召来的这个机构。他还没有在国民公会面前受审。把他讲成已死之人，就是把1793年1月21日读进一个五月的早晨；把他讲成唯一的原因，又回到了那幅漫画。造成阻塞的是制度，改换名称的是代表，而债务使召集三级会议在大臣们看来像是一条出路。

## 通向何处

[[revolutions/from-1789]]从5月5日与6月17日重新开始，然后完成本章拒绝去做的工作：宣誓、巴士底狱、八月法令、《人权与公民权宣言》、十月事件，以及1791年与1792年的不同政权，包括圣多明戈（Saint-Domingue）的起义。使有资金保障的债务成为可能的财政国家，见[[states/fiscal-military]]。没有迫使六月发生的那些公众，见[[states/enlightenment]]。1772年遭瓜分的联邦，见[[states/east]]。标签与原因有何不同，见[[sources/argument]]。

:::summary
- 旧制度是由特权、官职、各省法律与债务构成的复合体，既不是宫廷漫画，也不是一台名为专制主义的机器。
- 特权是法律上的优势，它使普遍税难以通过。这是政治事实，而不是关于礼仪风俗的故事。
- 1756年至1763年的七年战争，是背景中有日期可考的战争财政。从1756年到1789年，年份之差是33。
- 年表没有锁定任何赤字数字。本课不编造，也不让一位王后来顶替它。
- 1751年、1762年与1764年的书构成一个公众，而不是充分原因。原因必须是本来可能不同的东西。
- 1789年5月5日，三级会议在旧君主制之内开幕；6月17日，国民议会宣告成立。这个枢纽是对征税授权的新主张，它不是巴士底狱，也不是共和国。
- 1688年以后的不列颠，有1689年的《权利法案》与1694年的英格兰银行，表明公共债务不必导致立法机构改换名称。这一对照限定了关于法国的论断，而不是道德排名。
:::

## 习题

:::exercise 背景的长度 {level=1 check="33"}
七年战争始于1756年，三级会议于1789年开幕。年份之差是多少？（请输入年数。）
:::solution
用较晚的年份减去较早的年份：1789减1756等于33，差是33年。这并不是说其间什么也没有发生，也不是把同一减法变成34的首尾都算的计数。算法与[[#ex-span]]相同。
:::
:::

:::exercise 从瓜分到三级会议 {level=1 check="17"}
波兰-立陶宛的第一次瓜分在1772年，三级会议于1789年开幕。年份之差是多少？（请输入年数。）
:::solution
1789减1772等于17，瓜分与开幕相隔17年。两者同在一个世纪，却不是同一个事件：一个是瓜分一个联邦，一个是召开法国的议会。
:::
:::

:::exercise 到枢纽的天数 {level=1 check="43"}
开幕在1789年5月5日，国民议会在1789年6月17日。6月17日在5月5日之后多少天？五月有31天。不要为了把两端都算进去而加一。（请输入天数。）
:::solution
5月5日之后到5月31日：31减5等于26天。从五月底到6月17日是17天。26加17等于43。6月17日在5月5日之后43天。
:::
:::

:::exercise 替换一个标签 {level=2}
一本教科书写道：“专制主义在1789年崩溃了。”请运用[[#def-old-regime]]以及特权和高等法院等制度，改写这句话，使读者能够加以检验。不要编造赤字数字。
:::solution
1789年的法国是一个由特权、可买卖的官职与王室债务构成的复合体，大臣们无法在其中推行普遍税。三级会议于5月5日开幕；6月17日，第三等级宣告成立国民议会，并主张对税收的权力。这改变了由谁主张授权立法。这不是一台机器的崩溃，也还不是共和国。高等法院是捍卫自身地位的官职持有者。两个日期与特权的法律含义都可以检验，“专制主义崩溃了”则不能。
:::
:::

:::exercise 六月本可以走另一条路吗？ {level=2}
假设三个等级在1789年六月初达成一致，按旧形式表决一项税，然后各自回家。1751年、1762年与1764年的书仍然会出版。[[#thm-not-yet]]还能成立吗？这一假设对“那些书使革命成为必然”的观念意味着什么？
:::solution
这个假设正是原因所需要的“本来可能不同”。按等级表决一项税、然后解散，本来会是在旧授权之内的补救，6月17日也就不会有国民议会。1751年、1762年与1764年的书仍会存在，所以它们并不充分。代表们没有解散。这个假设检验的是必然性，而不是在描述六月。[[#thm-not-yet]]依然成立：新的授权在于那次拒绝，而不在于出版物，也不在于债务本身。那些公众使那套语言更容易理解，但这不等于注定发生。
:::
:::

:::exercise 6月17日没有做到什么 {level=2}
请举出革命进程中四个有日期的行为，它们在1789年6月17日还没有发生。然后说明，一章如果停在5月5日而没有6月17日，为什么就停得太早了。
:::solution
宣誓在1789年6月20日，巴士底狱在1789年7月14日，《人权与公民权宣言》在1789年8月26日，共和国在1792年9月21日至22日。这些在6月17日傍晚都还没有发生。国王1793年1月21日之死，以及按惯例始于1793年9月的恐怖统治，就更远了。停在5月5日，留下的只是一个正在召集三级会议的财政君主国。[[#prop-hinge]]把枢纽定在新授权被提出的那一天。没有它，你得到的只是一次会议，而不是使本课程得以称之为革命的那次拒绝。
:::
:::

:::exercise 什么能推翻这一论断？ {level=3}
:::hint
寻找一个早于任何对旧形式的拒绝的有日期行为，并追问是否单凭债务就转移了立法权。另一个负债国家可以作为比较，但前提是你不把这一比较变成说教。
:::
[[#thm-not-yet]]认为，财政危机还不是革命。请描述一条会使你放弃这一论断的证据，以及一条只会使你收窄它的证据。不要使用编造的赤字，也不要把编造的演说当作证据。
:::solution
如果在1789年6月17日之前，在任何关于三级会议如何开会的争执之前，单凭财政亏空就已转移了立法权，你就应当放弃这一论断。一个仍在要钱的典礼并不是这样的行为。如果负债的君主国在没有任何政治选择的情况下经常发生同样的断裂，你也应当放弃它，但事实并非如此。

如果一份锁定的账目表明，在召集三级会议的决定中，某一场战争的债务比特权更重要，你只需收窄这一论断。这改变的是分量，并不会把召集三级会议变成6月17日。不列颠的例子已经在收窄这一论断：授权渠道畅通时，债务是可以承受的。一篇编造的大臣演说，既不能收窄它，也不能推翻它。
:::
:::

:::exercise 王后与原因的尺度 {level=3}
:::hint
把文化事实（如一本小册子或一则谣言）与财政制度（如一项免税权或一个可买卖的官职）区分开来。问一问：单凭一户人家，仍然有什么解释不了？
:::
一位读者说：“特权与6月17日都无关紧要。宫廷挥霍无度，王后遭人憎恨，这种憎恨就是革命。”请分三步作答：说明一本敌视王后的小册子能证明什么；在没有锁定任何赤字数字的前提下，说明它不能证明什么；再说明即使将来有史家锁定了一笔巨大的王室开支总额，6月17日仍然处于什么位置。
:::solution
一本敌视王后的小册子可以证明，印刷品曾攻击王后，而且名声可能影响信贷，因为放贷者也有看法。这是这一论点最有力的版本。

它不能证明一户人家导致了财政危机。年表没有锁定任何赤字，因此不得编造。丑闻不会废除任何特权或可买卖的官职。一种情绪也不是三级会议。

即使将来有了王室开支的总额，6月17日仍然是枢纽。一笔巨大的账单可以解释召集三级会议的压力，却不能迫使代表们拒绝旧的开会方式。那位读者的说法跳过了这个日期。
:::
