到1789年夏末，革命做成了什么，又还没有做成什么？

到1789年10月初，国民议会正在立法，巴士底狱已经陷落，一系列法令冲击了封建形式，一份权利宣言已经有了日期，国王正被从凡尔赛（Versailles）带往巴黎。这已经很多了，但这还不是共和国。国王没有被处死，恐怖统治没有开始，殖民地奴隶制没有被废除，女性也没有投票权。把7月14日称为现代民主的开端，就是把一个由不同行为构成的夏天压扁，并借用了一个法国当时尚不具备的政体。

这个夏天并不能回答1791年或1792年的问题。国王接受的宪法、一次出逃、一场在他仍为国王时宣布的战争、一次王权中止，然后是共和国：这些都是后来的政体。[[revolutions/old-regime]]停在6月17日。本章从那项主张出发，拒绝让七月吞没其后的一切。

## 一个夏天，多个行为

:::definition 革命行为 {#def-act}
在本章中，**革命行为**是指一个有日期的公开行为，它改变了某种特定的法律关系或军事关系：谁开会，谁控制要塞，哪些捐税受到冲击，宣布了哪些权利，国王住在哪里，国王是否还在。它不是一种名为“革命”的情绪，也不是把后来的政体倒读进更早的某一天。同一个夏天里的几个行为，不会因为同在一年就变成一个行为。
:::

这个序列短得足以记住，又清晰得足以争论。1789年5月5日，三级会议开幕；6月17日，国民议会宣告成立；三天之后的6月20日，代表们发现惯常的会场被关闭，便在一座网球场集会，宣誓在制定宪法之前决不解散。这里不引用誓词。其政治内容在于这项主张：议会的存续，并不取决于国王当天是否允许使用那个房间。关闭会场是一种策略，宣誓是对它的回应。但路易十六（Louis XVI）仍然在位。

7月14日，巴黎民众与该市新组建民兵中的一些人，攻占了巴士底狱。它是一座要塞、一座监狱、一处武器库，也是王权武力的象征。要塞司令被杀。这里不描述他如何被杀，也不给出囚犯人数，因为没有锁定任何数字。改变的是巴黎的指挥权：一支市民民兵，即不久后的国民自卫军，掌握了宫廷无法随意授予又收回的武器。大臣们下台，国王来到巴黎，承认了他无法撤销的局面。这一切既不是全国选举，也不是权利文本。一座首都可以决定内阁的去留，却仍然不是成年人的民主。

乡村早已行动起来。整个夏天，关于匪徒的谣言与拒交捐税的风潮在许多地区蔓延，这一浪潮后来被称为“大恐慌”。领主的宅邸遭到袭击。并不是每个村庄都起来了，本课也不会编造被焚宅邸的数目。凡尔赛的议会既在回应巴黎人，也在回应农民。这就是八月第一周的背景，也是关于尺度的警示：7月14日的巴黎不是法国，起来反抗捐税的法国也不是某一个农民。

:::theorem 到十月，君主制已被约束，未被取代 {#thm-summer}
到1789年夏末，即以10月5日至6日的进军作为这个夏天的最后一个行为，法国有了一个着手制定宪法的国民议会，有了一个攻占了王室要塞的巴黎，有了冲击封建法律形式的法令，还有一份日期为8月26日的权利宣言。国王在巴黎，仍然是国王。共和国尚未宣告，国王尚未被处死，恐怖统治尚未开始，殖民地奴隶制尚未废除。限度就是这份清单本身：每一项都是[[#def-act]]意义上的行为，而后来那些尚未发生的事，也都不是荣耀底下的附注小字。
:::
:::proof
证据是日期的先后。6月17日产生了国民议会；6月20日使它与宪法绑定；7月14日改变了巴黎的武力格局；8月4日至11日的八月法令冲击了封建捐税与人身依附：一些权利被废除，许多金钱性权利被宣布为可赎买，所以一夜的演说并不等于财产转移已经完成。8月26日是《人权与公民权宣言》的日期，这里不引用它。宣言可以树立一个标准，却仍然没有确定选民范围、殖民地或女性的地位。10月5日至6日，国王被带往巴黎，巴黎妇女在进军中十分醒目。有卫兵被杀，这里既不描述，也不统计死者。结果是位置的变化：国王与议会都到了攻占巴士底狱的那座城市。王权并没有终结。

什么能推翻这一论断？一项在1789年10月6日或之前宣告共和国、处死国王、废除殖民地奴隶制，或把投票权赋予女性和无产者的法令。并没有这样的法令。国王仍在，1791年还将有一部宪法交给他接受。把共和国藏进1789年8月的比喻，在那次后来的签署面前就站不住了。
:::

从8月4日到8月11日是一段时间，而不是一闪而过。8月11日在8月4日之后7天。代表们在演说的热潮中放弃了特权，此后的法令还得说明这股热潮究竟意味着什么。人身依附被直接废除；而按照议会的分类，许多土地上的缴纳只能赎买，而不是取消。听说封建制度一夜终结的农民并不愚蠢，坚持赎买的律师也没有凭空捏造条文。那一夜与那些附注小字，共同构成了这一行为。后来某个村庄围绕某项捐税的争执，显示了法令与田地之间的距离，但这并不使法令变得一文不值。

《人权与公民权宣言》不是宪法，宪法到1791年9月3日才完成；它也不是一份关于谁享有标题中那些权利的普查。不符合后来纳税资格的男子、女性以及被奴役者，并没有因为这个日期就获得政治权利。但这个文本仍然给了批评者一把尺子。1791年，奥兰普·德古热（Olympe de Gouges）发表了关于女性权利的著作。这里不引用她的话。这个夏天的标题，已经被人作为一种排斥来回应。她于1793年被处死，正处在下一章所界定的时期。她的死并没有使她的文本成为1789年的法律，也不是略过这种排斥的理由。

:::example 从要塞到宣言 {#ex-july-august}
巴士底狱于1789年7月14日被攻占，《人权与公民权宣言》的日期是1789年8月26日。8月26日在7月14日之后多少天？七月有31天。只计算到较晚的日期，不要把两端都算进去。然后说明这两个行为中，哪一个是权利文本，哪一个是巴黎武力格局的改变。
:::solution
从7月14日到8月14日是31天，即七月的天数；从8月14日到8月26日是12天。31加12等于43，所以8月26日在7月14日之后43天。前一个日期是武力格局的改变；后一个是权利宣言，这里不引用它，它也还不是宪法。这43天里还包含8月4日至11日的法令，它们既不是攻占巴士底狱，也不是宣言。
:::
:::

:::quiz
关于1789年10月第一周结束时的法国，哪一种说法是正确的？
- [ ] 共和国已经取代国王，殖民地奴隶制已被废除
- [x] 在经历了从巴士底狱到宣言这一系列不同行为的夏天之后，国王在巴黎，仍然是国王
- [ ] 恐怖统治正在进行，国王已被处死
- [ ] 7月14日已经把投票权给了成年女性和被奴役者
:::solution
[[#thm-summer]]列出了这个夏天做了什么、没有做什么。10月5日至6日的进军改变了国王的所在，但没有废黜他。共和国始于1792年9月21日至22日，处决在1793年1月21日，作为法国法令的殖民地废奴在1794年2月4日。1789年七月与八月发生的事，没有一件给予女性选举权或终结奴隶制。巴士底狱只是那个夏天里的一个行为，而不是现代民主的诞辰。
:::
:::

## 宪法与出逃

从十月到出逃之间，本图谱没有为下一阶段的逐日政治锁定年份，这里也不编造。能够谈的是制度：地方政府得到重建，节日庆典宣扬团结。一项要求宣誓的法律把教会置于国家之下，许多教士拒绝宣誓，堂区由此分裂。在国王试图出走之前，一场改组教会的革命已经在税收与封建捐税之外开辟了第二条战线。

1791年6月，国王一家乔装离开巴黎，在瓦雷纳（Varennes）被截住。一位逃往边境的国王，并不认同他名义上仍在领导的方向。他被带了回来，却没有被废黜。那年夏天，军队向巴黎要求更彻底决裂的请愿者开枪。这里不统计死者，也不描述那次齐射。立宪君主制在还没有共和国之前，就已经在用武力对付共和派。宪法于1791年9月3日完成，9月14日被接受，相隔11天。出逃并没有阻止签署。信任受损与宪法签署都是事实。希望瓦雷纳终结君主制的读者，早了一年。

:::example 先出逃，后签署 {#ex-varennes}
出逃瓦雷纳在1791年6月。宪法于1791年9月3日完成，国王于1791年9月14日接受。从这个顺序中，你可以推出什么，不能推出什么？六月之内没有锁定具体日期，所以不要编造。
:::solution
你可以推出：立宪君主制挺过了国王的出走企图。9月3日的完成与9月14日的接受，都是一个仍有国王的政体的行为。这十一天，即14减3，是一段程序上的间隔，而不是一场新的革命。信任受到了损害，因为出逃是公开表示的不情愿。你不能推出共和国或恐怖统治已经开始，不能推出国王是热情接受的，不能把出逃定在六月的某一天，也不能把1793年1月21日国王之死挪回瓦雷纳。一次失败的出逃、一次没有伤亡数字的开枪与一部签署了的宪法，可以同在一年，却不是同一个事件。
:::
:::

1791年宪法保留了国王与一院制立法机构。它把选民与宣言中更宽泛的“公民”之名区分开来，标准是纳税，而具体数额没有锁定，这里不予说明。宣言与选举制度是不同的工具，选举制度要窄得多。女性不是选民，被奴役者也没有获得自由。不顾这些限制就把这一安排称为民主，就是把巴士底狱神话延伸到了1791年。新的立法议会于当年秋天开会。次年春天的战争是这个君主国宣布的，而不是共和国宣布的。

## 同一年的殖民地

:::proposition 圣多明戈属于1791年 {#prop-colony}
始于1791年8月的圣多明戈（Saint-Domingue）被奴役者起义，是1791年历史的一部分，而不是殖民地附录。1791年9月3日完成的宪法并没有废除奴隶制。本土的政治安排与殖民地的战争同处一年，但不能不加论证地相互说明。
:::
:::proof
年表把起义定在1791年8月，即瓦雷纳出逃与宪法的那一年。圣多明戈是法国主要的种植园殖民地，由1685年的《黑人法典》（Code Noir）以及[[states/atlantic]]所讲的贸易所塑造。起义使奴隶制变成了战争。宪法没有解放任何人，这就是与战争并存的本土事实。什么能推翻这一命题？1791年9月3日或1789年8月26日的某项条款废除了奴隶制，并在那年八月于该殖民地生效。并没有这样的条款。国民公会（Convention）的废奴在1794年2月4日，见[[revolutions/republic-and-terror]]；1802年恢复奴隶制与1804年1月1日海地宣告独立，属于[[revolutions/napoleon]]。没有复辟、也没有新国家诞生的解放，并不是这里的序列。

另一种同样能推翻我们的说法，是认为宣言导致了起义。被奴役者不需要一份巴黎的文本才能有自己的目的，而宣言也没有解放他们。谣言与消息或许曾经传播，但起义由巴黎的某项法令所发动，这一点没有得到证实，本课也不会为一个本图谱不引用的文本编造引文。
:::

这里不把起义中的暴力当作过程来描述，也不给出死亡人数。政治范畴就已足够：一个种植园社会正在与它所奴役的人交战。有色自由人对公民身份有自己的诉求，早在八月以前就已发生争执；即使两场战争相互交织，这些诉求也不同于被奴役者的起义。在同一个殖民地中，两种排斥可以同时成立。1789年夏天的巴黎，没有做任何事来解决其中任何一种。

## 先有战争，后有共和国

1792年4月20日，法国向“波希米亚与匈牙利国王”宣战。这是宣战文书中的头衔，指的是年表中也称为奥地利的那位哈布斯堡（Habsburg）君主。这个措辞很重要：这是一份针对一位国王的宣战书，发出时法国自己仍有国王。一些代表希望借战争揭露敌人、凝聚全国；宫廷中的一些人则希望战败能够恢复王权。我们不需要某一个动机就构成全部原因。这次宣战是1791年宪法之下的一个选择，而不是1789年7月14日的条件反射。外国威胁与贵族流亡是背景，这里不为它们单独锁定日期。

:::theorem 1789年、1791年与1792年是不同的政体 {#thm-regimes}
1789年夏天留下的是一个正在被革命改造的君主国。1791年9月14日被接受的宪法，建立的是一个有成文安排、选举权受限的君主国。从1792年9月21日至22日起，法国是一个处于战争中的共和国。这不是同一政体的三个名称。战争在1792年4月20日宣布，那时共和国还不存在。限度在于：“不同”并不意味着毫无关联。每个政体都继承了前一阶段的危机，但继承不等于同一。
:::
:::proof
证据是先后顺序。到1789年10月6日为止，路易十六受到约束，却没有被取代，这就是[[#thm-summer]]。1791年有六月的出逃、9月3日的宪法与9月14日的接受。1792年有4月20日的宣战、8月10日的王权中止、九月的屠杀囚犯、9月20日的瓦尔密（Valmy）战役，以及9月21日至22日的共和国。共和国是在战争开始之后才出现的。国王在8月10日被停权，但并没有在那天被杀。他死于1793年1月21日，那属于下一章，也不是共和国的诞生。共和国是国民公会在八月紧急状态下经选举产生后投票决定的。

什么能推翻这一定理？一份1789年夏天就已废除君主制的文本，一次日期晚于1792年9月22日的宣战，或者一个在瓦雷纳宣告成立的共和国。这些都不符合年表。8月10日的王权中止与9月21日的宣告相隔数周，其间有九月屠杀与瓦尔密战役。把它们合为一体，本章就失败了。
:::

从4月20日到8月10日是112天，长得足以否定那种认为战争与国王倒台发生在同一个下午的说法。计算步骤见[[#ex-one-twelve]]：30，然后31，然后30，然后21。8月10日，巴黎起义中止了君主制。国王成了新局势下的囚徒，国民公会随之召集。这已不再是他1791年9月接受的那部宪法，但也还不是死刑判决。

九月，巴黎的囚犯在九月屠杀中遇害。对于指挥链，史家意见不一：谁鼓动了杀戮，谁纵容了杀戮，巴黎当局在多大程度上是主使者。这种分歧本身就是事件的一部分。我们接受杀戮这一事实，但不给出死亡人数，因为没有锁定任何数字，也不描述杀戮的方式。九月屠杀不是恐怖统治，后者按惯例从1793年9月持续到1794年7月27日。两个九月相隔一年。把其中一个当作另一个，就丢掉了下一章所要讲授的时间界限。

1792年9月20日，瓦尔密战役遏制了入侵法国的军队的直接推进。这里不给出双方的兵力。9月21日至22日，国民公会废除君主制，宣告成立共和国。瓦尔密战役比21日早一天。相邻不等于因果。战役是军事结果，共和国是一次制宪性的投票。它们可以同在一周，这一周也可能很要紧，但大炮并没有投票。

:::example 一句关于瓦尔密的虚构句子 {#ex-valmy}
下面这句话为示例而虚构。它不是史料。它既不是战报，也不是法令。“瓦尔密创造了共和国。”请利用1792年9月20日与9月21日至22日这两个日期，说明这个动词错在哪里，严谨的句子又该怎么说。
:::solution
瓦尔密战役在9月20日，共和国在9月21日至22日。战役早一天，但它并不是法令的制定者。“创造了”把一次军事上的遏制变成了一部宪法。严谨的句子会说：这场战役遏制了一次入侵，随后国民公会废除了君主制。代表们有意愿，并不等于战役创造了共和国。如果共和国在战役之前就已宣告，或者是由指挥官作为命令宣告的，那么严谨的句子就不成立。这句虚构的话分不清战役与政体，而[[#thm-regimes]]正是要防止这一点。
:::
:::

:::example 宣战与中止王权不在同一天 {#ex-one-twelve}
1792年4月20日，法国向波希米亚与匈牙利国王宣战；1792年8月10日，君主制被中止。8月10日在4月20日之后多少天？请按四月30天、五月31天、六月30天计算，并停在8月10日，而不是8月20日。然后说明宣战的是哪一种政体。
:::solution
从4月20日到5月20日是30天，从5月20日到6月20日是31天，从6月20日到7月20日是30天。从7月20日到8月10日，是七月20日之后剩下的11天（31减20），加上八月的10天，共21天。合计30加31加30加21，等于112。所以8月10日在4月20日之后112天。宣战的是1791年的立宪君主国，路易十六仍是国王，共和国尚不存在。把共和国的开端放在四月，或把八月当作同一个早晨，就丢掉了112天和一次政体更迭。
:::
:::

反对意见认为，1789年夏天已经包含了后来的一切，因为民众杀过人、进过军，所以恐怖统治已经在萌芽中存在。那个夏天并不温和：十月有卫兵丧生，七月有要塞司令被杀，大恐慌也让靠捐税为生的人心惊胆战。但“萌芽”只是比喻。按照下一章的定义，恐怖统治是一个处于战争中的政府，从1793年9月到1794年7月27日动用特别法庭。1789年的民众不是那个政府。正是这一区分，使你能够追问究竟发生了什么变化。

第二种反对意见认为，殖民地分散了对真正革命即巴黎的注意力。[[#prop-colony]]就是回答。1791年8月与宪法同在一年。记下了瓦雷纳却漏掉圣多明戈，就是事先认定欧洲首都是唯一的尺度。起义不能解释网球场宣誓，网球场宣誓也不能解释起义。同处一个时代，并不意味着可以不顾日期地用其中一个来说明另一个。

:::widget timeline
start: 1789
end: 1792
window: 0
events: 1789,行为之夏; 1791,瓦雷纳与宪法; 1792,战争与共和国
caption: 把窗口设为0并移动年份。1789年、1791年与1792年是不同的政体。零窗口显示出单独一年所能容纳的东西有多少。
:::

把窗口设为0，在三个点之间移动。零窗口不会让1789年借用1792年。在1789年之内，这个点仍然要同时代表五月、六月、七月、八月与十月，所以本课要计算天数。在1791年之内，瓦雷纳、向请愿者开枪、宪法与圣多明戈共用一个点。在1792年之内，宣战、王权中止、屠杀、瓦尔密与共和国共用一个点。只记住这些点，就失去了本章。

:::warning 把巴士底狱当作诞辰
人们常说，攻占巴士底狱开启了现代民主。1789年7月14日改变的是巴黎的武力格局。无论是那天傍晚、那年十月，还是在1791年9月14日接受的宪法之下，法国都没有成年人的民主。女性没有投票权，选举权以纳税为资格，圣多明戈的被奴役者没有获得自由，到1791年8月，他们已在作战。共和国在1792年9月21日至22日。诞辰的故事只保留了一座要塞，却丢掉了那些本可以检验它的日期。
:::

:::history
三级会议于1789年5月5日开幕，召集它的路易十六当时仍是国王。巴士底狱于7月14日被攻占，《人权与公民权宣言》的日期是8月26日。共和国不在这些行为之列，它是后来的政体，属于更晚的年份。
:::

## 通向何处

[[revolutions/republic-and-terror]]从本章停下的地方开始：国王于1793年1月21日被处死，随后是1793年8月的全民征兵令，而恐怖统治的时间界限并不包括1789年。[[revolutions/napoleon]]接着讲殖民地奴隶制的恢复与海地的独立宣告；如果略去1791年8月，这两件事都无法理解。奴隶贸易与《黑人法典》见[[states/atlantic]]。旧制度的财政危机见[[revolutions/old-regime]]，到了这个夏天，它已不仅仅是财政危机了。

:::summary
- 革命行为是对某种特定关系的有日期的改变，不是一种情绪，也不是被压缩进7月14日的整个政体。
- 到1789年10月6日，法国有了国民议会，攻占了巴士底狱，颁布了八月法令与8月26日的宣言，国王也被带到了巴黎。他仍然是国王。
- 八月法令是从8月4日到11日的一段时间。一些捐税被废除，许多被宣布为可赎买。一夜的演说并不是一幅已经完成的财产地图。
- 这里不引用宣言。它不是宪法，不是女性选举权，也不是奴隶制的废除。宪法于1791年9月3日完成，9月14日被接受。
- 1791年6月的瓦雷纳出逃损害了君主制，却没有阻止宪法被接受。1791年8月，圣多明戈起义爆发，它是这一年的一部分。
- 1792年4月20日，在君主制之下，法国向波希米亚与匈牙利国王宣战。君主制于8月10日被中止。共和国始于9月21日至22日，比瓦尔密战役晚一天，但与瓦尔密并非一回事。
- 1792年的九月屠杀不是1793年9月的恐怖统治。到本章结束时，国王还没有被处决。
:::

## 习题

:::exercise 七月与八月两个日期之间的天数 {level=1 check="43"}
巴士底狱于1789年7月14日被攻占，宣言的日期是1789年8月26日。8月26日在7月14日之后多少天？七月有31天。不要把两端都算进去而多加一天。（请输入天数。）
:::solution
从7月14日到8月14日是31天，即七月的天数；从8月14日到8月26日是12天。31加12等于43。8月26日在7月14日之后43天。
:::
:::

:::exercise 八月法令的时长 {level=1 check="7"}
八月法令从1789年8月4日持续到8月11日。8月11日在8月4日之后多少天？（请输入天数。）
:::solution
11减4等于7。8月11日在8月4日之后7天。在这个意义上，这些法令跨越了一周，而不是一个晚上，尽管8月4日的演说是其中最著名的部分。
:::
:::

:::exercise 共和国的一年 {level=1 check="1792"}
共和国于9月21日至22日宣告成立，这是哪一年？（请输入年份。）
:::solution
宣告在1792年，在1792年4月20日宣战之后，也在1792年8月10日君主制被中止之后。不是1789年。
:::
:::

:::exercise 这个夏天不是什么 {level=2}
一位朋友说：“巴士底狱一陷落，法国就成了民主共和国，殖民地也自由了。”请只用本章的日期写出四条纠正，每一条都需要一个日期，或一个有日期可证的“尚未发生”。
:::solution
第一，1789年7月14日攻占的是一座要塞，并没有宣告共和国，共和国的宣告在1792年9月21日至22日。第二，国王在1791年9月14日接受了一部宪法，所以巴士底狱之后的政体仍是君主国。第三，那部宪法以纳税资格限制选举权，女性没有投票权，所以即使到1791年，成年人的民主也不成立。第四，奴隶制在1789年和1791年9月3日都没有被废除；圣多明戈起义始于1791年8月，废奴法令在1794年2月4日。这位朋友只保留了一天，却虚构了一个政体。
:::
:::

:::exercise 1792年之内的先后 {level=2}
把以下事件按时间顺序排列，并说明哪一个是共和国的开端：向波希米亚与匈牙利国王宣战、瓦尔密战役、君主制被中止、九月屠杀、宣告共和国。请为每一项注明日期。
:::solution
宣战在1792年4月20日。君主制于1792年8月10日被中止。随后是九月屠杀，发生在九月、战役之前。瓦尔密战役在1792年9月20日。共和国于1792年9月21日至22日宣告成立。其中只有最后一项是共和国的开端。宣战更早，而且是由君主国宣布的。屠杀是杀害囚犯，而不是立宪建国。瓦尔密是宣告前一天的一场战役，并不是宣告本身。
:::
:::

:::exercise 相邻与原因 {level=2}
为什么“瓦尔密创造了共和国”比“瓦尔密战役打响的次日，共和国宣告成立”更糟？请运用[[#ex-valmy]]与[[#def-act]]作答。不要编造将军的话。
:::solution
[[#def-act]]把军事结果与国家形态的改变区分开来。1792年9月20日的瓦尔密战役遏制了一次入侵；9月21日至22日的共和国是国民公会的行为。第二句话保留了先后与类别，第一句话却给战役安上了一个只属于法令的动词。恰恰是在这一天之差上，故事最容易夹带因果。关于士气的论证是允许的，只要它是作为论证提出来的，但不能用大炮取代国民公会。不应编造任何指挥官的话。
:::
:::

:::exercise 宣言能解决殖民地问题吗？ {level=3}
:::hint
你不得引用宣言。你可以使用1789年8月26日、1791年8月、1791年9月3日与1794年2月4日这几个日期。追问一下：一份巴黎的文本本来必须包含什么？起义又说明了等待那份文本意味着什么？
:::
一位作者说：“1789年的宣言使圣多明戈起义成为多余，因为自由已经宣布过了。”请解释这句话为什么站不住，以及什么样的证据才能使它成立。请时刻参照[[#prop-colony]]。
:::solution
这句话站不住，因为一份我们不认为废除了奴隶制的文件，不可能使一场反抗奴隶制的起义成为多余。起义始于1791年8月，1791年9月3日的宪法仍然没有解放任何人。法国在法律上废奴是1794年2月4日，而且甚至这一废奴也在1802年被推翻。作者的“已经”一词，承担的是一句我们不会编造的引文的作用，以及一种被后来的日期所否定的法律效力。

只有当一项自1789年8月26日起在圣多明戈生效的条款已经终结了奴隶制，并且1791年8月发生的并不是一场反抗奴役的起义时，这句话才能成立。关于权利的传闻仍然可以是殖民地政治的一部分，但政治的一部分并不等于已经完成的解放。[[#prop-colony]]把宪法与起义放在同一年，而不让任何一方抵消另一方。
:::
:::

:::exercise 三个政体，一种阅读习惯 {level=3}
:::hint
认真对待图表上的零窗口。一种阅读习惯可能把三个点合并起来，也可能把一个点之内的几个行为合并起来。你的反例应当用日期同时处理这两种情况。
:::
有人说：“我只需要‘革命’这个词。1789年、1791年与1792年之间的区别不过是咬文嚼字。”请为每两个年份各给出一个带日期的区别，并说明如果抹去这些区别，哪个政治问题就无从追问了。
:::solution
1789年与1791年之间：1789年10月6日时还没有完成的宪法；1791年9月14日，国王在六月出逃之后接受了一部宪法。1791年与1792年之间：被接受的宪法建立的是君主国，而1792年9月21日至22日宣告的是共和国，此时1792年4月20日宣布的战争已经进行了几个月。1789年与1792年之间的差别，就是这整条弧线。一位受约束的国王，并不是一个处于战争中的共和国。

抹去这些区别，你就无法追问：战争是否先于共和国？一位国王在企图出逃之后，怎么还能签署宪法？这个夏天在圣多明戈留下了什么没有解决？这些问题就是[[#thm-summer]]与[[#thm-regimes]]。图表上的零窗口不会让你站在某一年，假装能看见其他年份。
:::
