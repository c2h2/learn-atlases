到公元1789年夏天末尾，革命已经做了什么，还没有做什么？

到公元1789年10月初，一个国民议会正在立法，巴士底狱已经陷落，诸法令打击过封建形式，一份关于权利的宣言已经被定年，而国王正被从凡尔赛（Versailles）带来巴黎。这已经是很多。这不是一个共和国。国王还没有被处死。恐怖统治还没有开始。殖民地奴隶制还没有被废除。女性没有投票。把7月14日称作现代民主的开端，是把一个由不同行为组成的夏天压平，并且借用一个法国尚且没有的政权。

那个夏天不是公元1791年或公元1792年的答案。一部国王接受的宪法，一次出逃，一场在他仍然是国王时宣战的战争，一次中止，然后是一个共和国：这些是后来的诸政权。[[revolutions/old-regime]]停在6月17日。本章从那条论断出发，并且拒绝让七月吞掉随后的东西。

## 一个夏天，数个行为

:::definition 革命行为 {#def-act}
在本章，一个**革命行为**是一个有日期的公共行为，它改变一个指定的法律或军事关系：谁开会，谁据有一座堡垒，哪些捐税被攻击，哪些权利被宣告，国王睡在哪里，一个国王是否还在。它不是一种名为革命的心绪，也不是一个后来的政权被倒着读进更早的一天。一个夏天里的若干行为，不会因为共享一年而变成一个行为。
:::

那个序列短到可以记住，也锋利到可以与之争论。公元1789年5月5日，三级会议开幕。6月17日，国民议会被宣告。6月20日，三天之后，代表们发现他们惯常的大厅关闭了，在一座网球场会合，并且约束自己不解散，直到一部宪法存在。我们不会引用那次宣誓。政治内容是那个宣称：这个议会的存续，不取决于国王对那一天那个房间的许可。一次锁门是一个计策。那次宣誓是一个回应。它仍然让路易十六（Louis XVI）留在王位上。

7月14日，巴黎的一群人，连同这座城市新民兵中的人，攻占了巴士底狱，一座堡垒、一座监狱、一个武器储备，以及王室武力的一座象征。守将被杀了。我们不会描述如何被杀，也不给出一个囚犯数目，因为没有任何数目被锁定。改变的是巴黎的指挥权。一支市民民兵，很快成为国民自卫军，持有宫廷不能随意发放又收回的武器。大臣们倒台了。国王来到这座城市，并且承认了他不能撤销的东西。那些都不是一个全国选举或一份权利文本。一个首都能够决定一个内阁，而仍然不是一个成年人的民主。

乡村已经在动。整个夏天，关于匪徒的谣言与对捐税的拒绝在许多地区蔓延，一波后来被称为大恐惧的风潮。领主们的房屋被攻击。不是每一个村庄都起事，而我们不会发明一个被烧房屋数。凡尔赛的议会在回应农民，也在回应巴黎人。那就是八月第一周的背景，而它是一个关于尺度的警告。7月14日的巴黎不是法国。起来反抗捐税的法国不是一个农民。

:::theorem 到十月，君主制已被约束，未被取代 {#thm-summer}
到公元1789年夏天末尾，把10月5日到6日的行军当作那个夏天的最后一个行为，法国有一个着手制定一部宪法的国民议会，有一个攻占了一座王室堡垒的巴黎，有攻击封建法律形式的诸法令，以及一份定年为8月26日的权利宣言。国王在巴黎，而且仍然是国王。共和国还没有被宣告。国王还没有被处死。恐怖统治还没有开始。殖民地奴隶制还没有被废除。限度就是那张清单本身：每一项都是[[#def-act]]意义上的一个行为，而后来的每一个缺席，都不是一条荣耀之下的小字。
:::
:::proof
证据是日期的顺序。6月17日创造国民议会。6月20日把它系于一部宪法。7月14日改变巴黎的武力。八月的法令，8月4日到11日，攻击封建捐税与人身依附：一些权利被废除，许多金钱上的权利被宣告可以赎回，所以一晚上的演辞不是一次完成了的财产转移。8月26日定年《人权与公民权宣言》。我们不会引用它。一份宣言能够设定一个标准，而仍然不固定选举人的范围、诸殖民地或女性的地位。10月5日到6日，国王被带来巴黎，这座城市的女性在行军中很显眼。卫兵被杀了。我们既不描述那件事，也不数死者。结果是位置。国王与议会都在那座攻占了巴士底狱的城市里。王权没有终结。

什么会构成对这条论断的反证？一项在公元1789年10月6日当日或之前，宣告一个共和国、处死国王、废除殖民地奴隶制，或把投票权给女性和无财产者的法令。没有这样一项法令。国王仍在，而在公元1791年，一部宪法将被提供给他。一个把共和国藏进公元1789年8月之内的隐喻，在那个后来的签署面前失败。
:::

从8月4日到8月11日是一段跨度，不是一闪。8月11日在8月4日之后7天。代表们在一片演辞的热潮中放弃了特权，而后来的诸法令必须说出那股热潮是什么意思。人身依附被直接攻击。许多对土地的支付，在议会的类别里，是要被买断，而不是被勾销。听到封建制在一夜之间终结的农民不是傻瓜，而坚持赎回的律师也没有发明那个文本。那一晚和那些小字都是那个行为。后来一场围绕一项捐税的村庄之争，显示一项法令与一块田地之间的间隙。它没有让那项法令变成零。

《人权与公民权宣言》不是宪法，宪法直到公元1791年9月3日才完成，而它也不是一份关于谁拥有标题里那些权利的人口清点。没有后来那个纳税资格的男子、女性、以及被奴役的人，没有被那个日期单独带入政治权利。那个文本仍然给了批评者一个尺度。公元1791年，奥兰普·德古热（Olympe de Gouges）发表了关于女性权利的著述。我们不会引用她。那个夏天的标题，已经在被当作一种排斥而遭到回应。她在公元1793年被处死，在下一章定年的那个时段里。那次死亡没有把她的文本变成公元1789年的法律，也不是一个跳过那种排斥的理由。

:::example 从堡垒到宣言 {#ex-july-august}
巴士底狱在公元1789年7月14日被攻占。《人权与公民权宣言》定年为公元1789年8月26日。8月26日在7月14日之后多少天？七月有31天。数较晚的那个日期，不是两个端点。然后说出这两个行为中哪一个是权利的一个文本，哪一个是巴黎武力的改变。
:::solution
从7月14日到8月14日是31天，七月的长度。从8月14日到8月26日是12天。31加12是43，所以8月26日在7月14日之后43天。第一个日期是一个武力的改变。第二个是一个权利的宣言，我们不引用它，而它还不是一部宪法。这43天还装着8月4日到11日的诸法令，它们既不是那次强攻，也不是宣言。
:::
:::

:::quiz
公元1789年10月第一周结束时，关于法国的哪一个说法是真的？
- [ ] 一个共和国已经取代了国王，殖民地奴隶制已经被废除
- [x] 国王在巴黎而且仍然是国王，在一个从巴士底狱到宣言的、由不同行为组成的夏天之后
- [ ] 恐怖统治正在进行，国王已经被处死
- [ ] 7月14日已经把投票权给了成年女性与被奴役的人
:::solution
[[#thm-summer]]列出了那个夏天做了什么，以及没有做什么。10月5日到6日的行军移动了国王。它没有废黜他。共和国从公元1792年9月21日到22日定年。处决是公元1793年1月21日。作为一道法国法令的殖民地废奴是公元1794年2月4日。公元1789年的七月或八月里没有任何东西给女性选举权或终结奴隶制。巴士底狱是那个夏天里的一个行为，不是一个近代民主的生日。
:::
:::

## 一部宪法，一次出逃

在十月与那次出逃之间，本图谱没有为下一季逐日的政治锁定一个年份数字，而我们不发明一个。能够说的东西是制度的。地方政府被重建。节庆宣扬一体。教会通过一项要求宣誓的法律被置于国家之下，而许多教士拒绝，把诸堂区分裂了。一场重新组织一座教会的革命，已经在税收与封建捐税之旁开辟了一个第二战场，在国王试图离开之前。

公元1791年6月，国王和他的家人乔装离开巴黎，在瓦雷纳（Varennes）被拦下。一个朝着边界逃跑的国王，不接受他仍然在名义上带领的方向。他被带回来了，而没有废黜。那年夏天，军队向巴黎中要求更彻底断裂的请愿者开火。我们不数死者，也不描写那次齐射。立宪君主制在拥有一个共和国之前，就已经在使用武力对付共和派。宪法在公元1791年9月3日完成，在9月14日被接受，11天之后。那次出逃没有阻止那次签署。信任的损伤与一部签署了的宪法都是真的。想要瓦雷纳终结君主制的读者，早了一年。

:::example 出逃，然后是一次签署 {#ex-varennes}
出逃瓦雷纳在公元1791年6月。宪法在公元1791年9月3日完成，在公元1791年9月14日被国王接受。从那个顺序你可以推论什么，不能推论什么？六月之内没有一天被锁定，所以不要发明一天。
:::solution
你可以推论：立宪君主制在它国王的出走企图之下存活了下来。9月3日的完成与9月14日的接受，是一个仍然有一个国王的政权的行为。那十一天，14减3，是一个形式的间隔，不是一场新革命。信任被损伤了，因为一次出逃是公开的不情愿。你不能推论：共和国或恐怖统治已经开始，或接受是热情的，或把那次出逃定年到六月的某一天，或把国王在公元1793年1月21日的死挪回瓦雷纳。一次失败的出逃、一次没有附带数目的开火，与一部签署了的宪法，可以共享一年，而不是一个事件。
:::
:::

公元1791年的宪法保留了一个国王与一个单一的立法机关。它把投票者与宣言里更宽的名称“公民”区分开。标准是一项纳税支付，而那个数额没有被锁定，所以我们不说出它。一份宣言与一个选举制度是不同的工具，而选举制度更窄。女性不是投票者。被奴役的人没有被解放。在缺少那些限度的情况之下把这桩解决方案称作民主，就把巴士底狱的迷思延伸进了公元1791年。新的立法机关在那个秋天开会。接下来那个春天的战争是由这个君主制宣战的，不是由共和国。

## 同一年里的殖民地

:::proposition 圣多明戈属于公元1791年 {#prop-colony}
圣多明戈（Saint-Domingue）的被奴役者的起义，始于公元1791年8月，是公元1791年历史的一部分，不是一个殖民地的附录。在公元1791年9月3日完成的宪法不废除奴隶制。一个本土的解决方案与一场殖民地的战争占据同一年，而不会免费地互相举例。
:::
:::proof
年表把那次起义放在公元1791年8月，瓦雷纳与宪法的那一年。圣多明戈，主要的法国种植园殖民地，由公元1685年的《黑人法典》（Code Noir）与[[states/atlantic]]里的那桩贸易组织。那次起义使奴隶制变成一场战争。那部宪法没有解放任何人。这就是那场战争旁边的本土事实。什么会构成对这条命题的反证？一条在公元1791年9月3日，或在公元1789年8月26日，废除了奴隶制、并且在那年八月于那个殖民地有效力的条款。没有这样一条。国民公会（Convention）的废奴是公元1794年2月4日，在[[revolutions/republic-and-terror]]。公元1802年的恢复与海地在公元1804年1月1日的宣告，属于[[revolutions/napoleon]]。一场没有恢复、也没有新国家的解放，不是这个序列。

同样会构成对我们的反证的，是那个说宣言导致了那次起义的论断。被奴役的人不需要一个巴黎的文本就能有他们的目的，而那份宣言没有解放他们。谣言与消息可能传播过。由一道巴黎法令所开创，这一点没有被确立，而我们不会从一个本图谱不曾引用的文本发明一条引文。
:::

我们不会把那次起义的暴力描述为一个程序，也不给出一个死亡数字。那个政治范畴就够了。一个种植园社会正在同它所奴役的人交战。有色自由人他们自己对公民身份提出要求，早在八月之前就在争执之中，而那些要求与被奴役者的起义不是一回事，即便诸场战争互相重叠。在一个殖民地里，两种排斥可以同时为真。巴黎的公元1789年夏天没有做成任何了结这两者中任何一个的事。

## 战争，然后是共和国

公元1792年4月20日，法国向波希米亚与匈牙利国王宣战，那是那项法令里的头衔，年表也称作奥地利的那位哈布斯堡（Habsburg）君主。那个公式要紧。这是一道对着一个国王的宣战，在法国仍然有一个国王时发出。一些代表想要一场战争来暴露敌人、团结国家。宫廷中的一些人希望一次失败会恢复王室权威。我们不需要任何一个动机就是全部的原因。那次宣战是公元1791年的宪法之下的一个选择，不是公元1789年7月14日的一个反射。外国的威胁与贵族流亡是背景。我们不替它们锁定一个单独的日子。

:::theorem 公元1789年、公元1791年与公元1792年是不同的政权 {#thm-regimes}
公元1789年的夏天留下一个正在革命的君主制。公元1791年9月14日被接受的宪法，是一个带有一个书面解决方案与一个受限制的选举制度的君主制。从公元1792年9月21日到22日起，法国是一个开战的共和国。这些不是一个政权的三个名字。战争在公元1792年4月20日宣战，在共和国存在之前。限度：“不同”不意味着不相关。每个政权继承前一个危机。继承不是同一。
:::
:::proof
证据是那个顺序。到公元1789年10月6日为止，路易十六被约束，未被取代，那就是[[#thm-summer]]。公元1791年记录一次六月出逃，一部在9月3日的宪法，一次在9月14日的接受。公元1792年记录4月20日的战争，8月10日的中止，九月囚犯被杀害，9月20日的瓦尔密（Valmy），以及9月21日到22日的共和国。共和国在战争已经开始之后到来。国王在8月10日被中止，而没有在那一天被杀。他的死在公元1793年1月21日，下一章，而它不是共和国的诞生。共和国是国民公会在八月紧急状态之下选举之后的一次投票。

什么会构成对这条定理的反证？一个在公元1789年夏天、已经废除君主制的文本，一次在公元1792年9月22日之后定年的宣战，或一个在瓦雷纳宣告的共和国。这些都不是年表。8月10日的中止与9月21日的宣告相隔数周，而那些周里有九月屠杀与瓦尔密。把它们合拢，就是这个章节失败的方式。
:::

从4月20日到8月10日是112天，长到足以阻止这样一个故事：战争与国王的倾覆是同一个下午。那些台阶在[[#ex-one-twelve]]里：先是30，然后是31，然后是30，然后是21。8月10日，一次巴黎起义中止了君主制。国王成为新局面的一名囚徒，而国民公会被召集。这不再是他于公元1791年9月接受的那部宪法。这还不是一道死刑判决。

九月，巴黎的囚犯在九月屠杀中被杀。对于指挥链，史家意见不一：谁催促了那些杀戮，谁容忍了它们，这座城市的当局在多大程度上是主使者。这个分歧是事件的一部分。我们接受那些杀戮的事实，并且拒绝给出一个死者数目，因为没有任何数目被锁定，而我们拒绝描述那个方法。那些屠杀不是恐怖统治，后者按惯例从公元1793年9月持续到公元1794年7月27日。一年隔开这两个九月。任何一个用一个来顶替另一个的人，已经丢掉了下一章存在来教授的那道括号。

公元1792年9月20日，瓦尔密战役遏止了入侵法国的军队的即时推进。我们不给出任何一方的军队规模。9月21日到22日，国民公会废除君主制，宣告共和国。瓦尔密在21日之前一天。相邻不是因果。一场战役是一个军事结果。一个共和国是一个宪法性的投票。它们可以共享一周，那一周可以重要，而大炮并没有投票。

:::example 一句关于瓦尔密的虚构句子 {#ex-valmy}
下面这句话为示例而虚构。它不是史料。它不是一份军报，也不是一项法令。“瓦尔密创造了共和国。”使用公元1792年9月20日与9月21日到22日，说出那个动词错在哪里，以及一个谨慎的句子会改说什么。
:::solution
瓦尔密是9月20日。共和国是9月21日到22日。那场战役早一天，不是一道法令的作者。“创造了”把一个军事上的遏止变成了一部宪法。一个谨慎的句子会说，这场战役遏止了一场入侵，而国民公会随后废除了君主制。代表中间的意愿不是创造。如果共和国曾在战役之前被宣告，或由指挥官们作为一道命令宣告，那个谨慎的句子就会失败。那句虚构的句子无法分辨一场战役与一个政权，而这正是[[#thm-regimes]]要拦下的东西。
:::
:::

:::example 战争与中止不是一个日期 {#ex-one-twelve}
法国在公元1792年4月20日向波希米亚与匈牙利国王宣战。君主制在公元1792年8月10日被中止。8月10日在4月20日之后多少天？使用各月长度：四月30天，五月31天，六月30天，并且停在8月10日，而不是8月20日。然后说出是哪种政权宣战。
:::solution
从4月20日到5月20日是30天。从5月20日到6月20日是31天。从6月20日到7月20日是30天。从7月20日到8月10日，是20日之后七月剩下的11天（31减20），加上八月的10天，即21。总数是30加31加30加21，即112。所以8月10日在4月20日之后112天。战争是由公元1791年的立宪君主制宣战的，路易十六仍然是国王。共和国尚不存在。把共和国开在四月，或把八月当作同一个早晨，会丢掉112天与一次政权更替。
:::
:::

那条反对意见说，公元1789年的夏天已经包含了后来的一切，因为人群杀戮过、行军过，所以恐怖统治以胚芽形式在场。那个夏天并不温和。卫兵在十月死了。守将在七月被杀。大恐惧恐吓了靠捐税过活的人。胚芽是一个隐喻。恐怖统治，按下一章对它的定义，是一个开战的政府自公元1793年9月至公元1794年7月27日使用特别法庭。一群人在公元1789年不是那个政府。这个区分正是使你能够追问什么改变了的东西。

第二条反对意见说，殖民地是对真正革命即巴黎的分心。[[#prop-colony]]就是回答。公元1791年8月与宪法坐在同一年。记下瓦雷纳而漏掉圣多明戈，就是预先决定一座欧洲的首都是唯一的尺度。那次起义不解释网球场宣誓，那次宣誓也不解释那次起义。共享一个时代，不是一张不加日期地用一个举例说明另一个的许可证。

:::widget timeline
start: 1789
end: 1792
window: 0
events: 1789,行为之夏; 1791,瓦雷纳与宪法; 1792,战争与共和国
caption: 把窗口设为0并移动年份。公元1789年、公元1791年与公元1792年是不同的政权。一个为零的窗口显示单一年份包含多么少。
:::

把窗口设为0，在三个圆点上移动。一个为零的窗口不会让公元1789年借用公元1792年。在公元1789年之内，那个圆点仍然必须同时代表五月、六月、七月、八月与十月，这就是本课要数一天的原因。在公元1791年之内，瓦雷纳、向请愿者开火、宪法与圣多明戈是一个圆点。在公元1792年之内，战争、中止、屠杀、瓦尔密与共和国是一个圆点。只记住那个圆点，就丢掉了这个章节。

:::warning 作为生日的巴士底狱
人们重复说，巴士底狱开启了现代民主。公元1789年7月14日改变的是巴黎的武力。成年人的民主不是法国在那个傍晚、在十月、或在公元1791年9月14日接受的宪法之下所拥有的东西。女性没有投票。选举权以纳税为资格。圣多明戈的被奴役者没有被解放，而在公元1791年8月，他们在作战。共和国是公元1792年9月21日到22日。一个生日故事留下一座堡垒，扔掉那些本来能够检验它的日期。
:::

:::history
三级会议于公元1789年5月5日开幕，当时路易十六仍然是召集了它们的国王。巴士底狱在7月14日被攻占。《人权与公民权宣言》定年为8月26日。共和国不是这些行为中的一个。它是一个后来的政权，在更晚的一年。
:::

## 通向何处

[[revolutions/republic-and-terror]]从本课停止的地方开始：国王在公元1793年1月21日被处死，公元1793年8月的总动员令随之而来，而恐怖统治有一道不覆盖公元1789年的括号。[[revolutions/napoleon]]接过殖民地奴隶制的恢复与海地的宣告，这两件事在漏掉公元1791年8月的情况下是不可理解的。那桩贸易与《黑人法典》在[[states/atlantic]]。旧制度的那场财政危机，而这个夏天已经不再只是一场财政危机，在[[revolutions/old-regime]]。

:::summary
- 一个革命行为是一个对指定关系的有日期的改变，不是一种心绪，也不是一个被挤进7月14日的完整政权。
- 到公元1789年10月6日，法国有一个国民议会，有攻占的巴士底狱，有八月的法令，有8月26日的宣言，还有一个被带来巴黎的国王。他仍然是国王。
- 八月的法令是8月4日到11日的一段跨度。一些捐税被废除，许多被宣告可以赎回。一晚上的演辞不是一幅完成了的财产地图。
- 宣言在这里没有被引用，它不是一部宪法，不是女性选举权，也不是奴隶制的废除。宪法在公元1791年9月3日完成，在9月14日被接受。
- 公元1791年6月的出逃瓦雷纳损伤了君主制，而没有阻止那次接受。公元1791年8月，圣多明戈的起义开始。它是这一年的一部分。
- 战争在公元1792年4月20日对着波希米亚与匈牙利国王宣战，是在一个君主制之下。君主制在8月10日被中止。共和国从9月21日到22日定年，在瓦尔密之后一天，与瓦尔密不是一回事。
- 公元1792年的九月屠杀不是公元1793年9月的恐怖统治。到本课结束为止，国王的处决还没有发生。
:::

## 习题

:::exercise 两个七月与八月日期之间的天数 {level=1 check="43"}
巴士底狱在公元1789年7月14日被攻占。宣言定年为公元1789年8月26日。8月26日在7月14日之后多少天？七月有31天。不要把两个端点都算作额外的一天。（请输入天数。）
:::solution
从7月14日到8月14日是31天，七月的长度。从8月14日到8月26日是12天。31加12是43。8月26日在7月14日之后43天。
:::
:::

:::exercise 诸法令的长度 {level=1 check="7"}
八月的法令从公元1789年8月4日持续到8月11日。8月11日在8月4日之后多少天？（请输入天数。）
:::solution
11减4是7。8月11日在8月4日之后7天。这些法令在那个意义上是一周的跨度，不是一个单独的晚上，尽管8月4日的演辞是有名的那一部分。
:::
:::

:::exercise 共和国的一年 {level=1 check="1792"}
共和国在哪一年被宣告，在9月21日到22日？（请输入年份。）
:::solution
宣告在公元1792年，在公元1792年4月20日宣战之后，在公元1792年8月10日君主制被中止之后。不是公元1789年。
:::
:::

:::exercise 那个夏天不是什么 {level=2}
一位朋友说：“巴士底狱一陷落，法国就是一个民主共和国，殖民地也自由了。”只使用本课的日期，写出四条纠正。每条纠正需要一个日期或一个有日期的缺席。
:::solution
第一，公元1789年7月14日攻占一座堡垒。它没有宣告一个共和国。那个宣告是公元1792年9月21日到22日。第二，国王在公元1791年9月14日接受一部宪法，所以巴士底狱之后的政权仍然是一个君主制。第三，那部宪法以一项纳税资格限制选举权，而女性没有投票，所以成年人的民主连公元1791年都不成立。第四，奴隶制在公元1789年没有废除，在公元1791年9月3日也没有。圣多明戈的起义始于公元1791年8月，而废奴的法令是公元1794年2月4日。这位朋友留下了一个日子，发明了一个政权。
:::
:::

:::exercise 公元1792年内部的顺序 {level=2}
把这些按年代顺序排好，并说出哪一个是共和国的开端：对波希米亚与匈牙利国王宣战、瓦尔密、君主制的中止、九月屠杀、共和国的宣告。给每一个一个日期。
:::solution
战争在公元1792年4月20日宣战。君主制在公元1792年8月10日被中止。九月屠杀随之而来，在九月，在战役之前。瓦尔密是公元1792年9月20日。共和国在公元1792年9月21日到22日被宣告。只有最后这一个是共和国的开端。战争更早，而且是由一个君主制宣战的。屠杀是对囚犯的杀害，不是一个国家的立宪开端。瓦尔密是一场在宣告之前一天的战役，不是那个宣告。
:::
:::

:::exercise 相邻与原因 {level=2}
为什么“瓦尔密创造了共和国”是一个比“瓦尔密战役开打的那一天之后，共和国才被宣告”更糟的句子？使用[[#ex-valmy]]与[[#def-act]]。不要发明一位将军的话。
:::solution
[[#def-act]]把一个军事结果与一个国家形态的改变分开。瓦尔密，在公元1792年9月20日，遏止了一场入侵。共和国，在9月21日到22日，是国民公会的一个行为。第二个句子保住了顺序与种类。第一个句子给一场战役配了一个属于一道法令的动词。一天正是故事夹带因果的地方。一个关于士气的论证是允许的，只要它是作为一个论证被提出的。它不能用一门大炮取代国民公会。任何指挥官的话都不应被发明。
:::
:::

:::exercise 宣言会安置好殖民地吗？ {level=3}
:::hint
你不得引用宣言。你可以使用公元1789年8月26日、公元1791年8月、公元1791年9月3日与公元1794年2月4日。问一问：一个巴黎的文本本来必须包含什么，以及那次起义对于等待那个文本显示出什么。
:::
一位作者说：“公元1789年的宣言使圣多明戈的起义成为多余，因为自由已经被陈述过了。”解释为什么那句话失败，以及什么样的证据会使它成功。让[[#prop-colony]]留在视野里。
:::solution
那句话失败，是因为一份我们并不当作已经废除了奴隶制的文件，不可能使一场反抗奴隶制的起义成为多余。那次起义始于公元1791年8月。公元1791年9月3日的宪法仍然没有解放任何人。法国的法律废奴是公元1794年2月4日，而那甚至还在公元1802年被逆转。这位作者的“已经”，替一句我们不会发明的引文、以及一个后来的日期所反驳的法律效果，干了活。

那句话只会成功，如果一条自公元1789年8月26日起在圣多明戈有效力的条款曾经终结了奴隶制，并且如果公元1791年8月不是一场反抗奴役的起义。关于权利的谣言仍然可以成为那个殖民地的政治的一部分。政治的一部分不是一场完成了的解放。[[#prop-colony]]把宪法与起义保持在同一年，而不让任何一个取消另一个。
:::
:::

:::exercise 三个政权，一种阅读习惯 {level=3}
:::hint
把图形上那个为零的窗口当真。一种阅读习惯能够合拢三个圆点，也能够合拢一个圆点之内的数个行为。你的反例应当用日期同时干这两件事。
:::
有人说：“我只需要革命这个词。公元1789年、公元1791年与公元1792年之间的区别是迂腐。”给出每一对年份之间一个带日期的区别，并解释如果丢掉那些区别，哪一个政治问题会变得无法追问。
:::solution
在公元1789年与公元1791年之间：在公元1789年10月6日，没有一部完成的宪法；在公元1791年9月14日，国王接受一部，在六月出逃之后。在公元1791年与公元1792年之间：那部被接受的宪法是一个君主制，而在公元1792年9月21日到22日，一个共和国被宣告，而在公元1792年4月20日宣战的战争已经过去数月。在公元1789年与公元1792年之间，那个间隙是整条弧线。一个被约束的国王不是一个开战的共和国。

丢掉那些区别，你就无法追问战争是否在共和国之先，一个国王在试图逃跑之后如何能够签署一部宪法，或那个夏天在圣多明戈没有了结什么。那些问题就是[[#thm-summer]]与[[#thm-regimes]]。图形上那个为零的窗口不会让你站在一年上、假装能看见另外几年。
:::
