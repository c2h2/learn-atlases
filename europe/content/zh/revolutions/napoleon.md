拿破仑的哪些行为是法律，哪些是皇冠，哪些是战争？

这个名字把一次政变、一部民法典、一次对殖民地奴隶制的恢复、一次加冕、一场海战的失败、一场陆战的胜利、一次入侵、两次退位，以及一场在一份和平安排已经签署之后才打的战役，聚拢在一起来。被聚拢的名字感觉像是诸项成就。日期并不是。一部关于财产与家庭的法律不是一顶皇冠，一顶皇冠不是一场战役，而这三者都不是海地离开殖民体系时的那道宣告。本章按种类给诸行为分类。它拒绝给出一支军队的规模，并且在入侵确曾发生、撤退随之而来这一事实之外，拒绝给出撤退中苦难的一幅肖像。

[[revolutions/republic-and-terror]]结束于热月9日之后仍然存续的一个共和国，它在1795年被改组。1799年11月9日，那个后来的共和国被推翻。接管行政权的那个人还不是皇帝。从政变到皇冠的距离是论断的一部分。同样如此，是在1804年这一个单独的年份之内，从一道独立的宣告到一部法典、再到一次加冕的距离。

## 政变不是皇冠

:::definition 行为的诸种类 {#def-kinds}
在本章，一条**法律**是一个改变民事身份、财产或殖民地奴隶制的文本。一顶**皇冠**是造就一个君主这件事。一场**战争**是一次战役或一场战斗。一次创建一个执政府的政变，在一个进一步的行为接续它之前，不是这三者中的任何一种。把若干种类放进同一年，或放进同一个姓氏之下，并不把它们合并。
:::

1799年11月9日，共和历的雾月18日，督政府（Directory）被推翻，一个执政府被建立，拿破仑（Napoleon）是居支配地位的执政官。那个行为是一个共和国国内部的政变，这个共和国在一段时间里保留了共和国的语言与一个集中起来的行政权。它不是《民法典》，它还不存在。它不是一次加冕。它不是渡过涅曼河（Niemen）。称雾月为“帝国”开始的那一刻，是后来的荣耀编辑日历的方式。执政府是它自己的一个政权。它制造和平、法律与治安，并且在预备一顶它还不曾戴上的皇冠。

1801年，法国国家同教廷经由《教务专约》（Concordat）达成和解，那是在教会曾被分裂、曾被攻击的十年之后的一场宗教和平。我们不引用它，也不假装本图谱把《教务专约》锁定为一桩普查事件。1801年是可用的，而那个解决方案属于它。它的种类既不是一部民法典，也不是一顶皇冠，也不是一场战斗。它是一场关于公开礼拜与由国家付薪的教士的讨价。一个能够同罗马签约、而下一年又恢复殖民地奴隶制的政权，必须被一个一个行为地阅读。

1802年至少有三种东西不应当被合拢。于1794年2月4日被废除的殖民地奴隶制被恢复了。杜桑·卢维杜尔（Toussaint Louverture）被俘。拿破仑取走了终身执政官之位，一种不足于世袭皇冠的个人权力。一次公民投票被安排过。没有任何票数被锁定，所以我们不发明一个。一次公民投票不是一个民族的自由的描述。终身执政官之位是朝向1804年那顶皇冠的一步，而不是那顶皇冠。恢复奴隶制是一部关于殖民地身份的法律，一次把种植园秩序放回去的尝试，不是朝向海地独立的一步。在法国武力能够执行它的地方，那次尝试是要紧的。在圣多明戈（Saint-Domingue），它遇到的是一个自1791年8月起就在作战的社会，而它失败了。

杜桑在1803年死于法国的羁押之中。他没有活到看见独立的宣告。任何让他于1804年1月1日宣布海地的句子，都搞错了人，也搞错了年份。让-雅克·德萨林（Jean-Jacques Dessalines），在本课程的记录里，是附在那个新国家上的名字。1803年的那个死，是关于一名囚犯的一个事实。我们不描述那次羁押。我们把它用作一个日期，它阻止两位领袖塌缩为一则传奇。

:::theorem 《法典》、皇冠与诸战争不是一个成就 {#thm-not-one}
于1804年3月21日公布的《民法典》、1804年12月2日的加冕，以及从特拉法尔加（Trafalgar）与奥斯特里茨（Austerlitz）经由涅曼河直到滑铁卢（Waterloo）的诸战役，是不同的行为种类。一个姓氏和一个年份并不把它们变成一个成就。限度：它们可以服务于一个政府，而仍然是不同的器具。对一个政府的服务不是种类的同一。
:::
:::proof
证据是那些器具。《法典》是民事法律：财产、契约、法律等级作为身份的一种形式的终结、父权与夫权，以及对1792年的共和国曾经准入的离婚的收窄。它不是一部政治自由的宪制，也不是一道给一个军团的命令。那次教皇在场的加冕，把一个执政官变成一个皇帝。一场典礼不是一部关于抵押的制定法。特拉法尔加，1805年10月21日，是一场海上的失败。奥斯特里茨，1805年12月2日，是四十二天之后的一场陆上的胜利，所以甚至早在俄国之前，“诸战争”就不是一个结果。涅曼河在1812年6月24日被渡过，那是一次入侵，随后是撤退与失败。《法典》里没有任何东西告诉你渡过一条河。奥斯特里茨里没有任何东西是一条关于已婚妇女的契约的规则。

什么会构成对这条论断的反证？一个同时是民事法律、加冕与一道战役命令的文本，或者一个其中每一个有日期的行为都属于同一种类的年份。1804年拒绝了这种诱惑：海地在1月1日，《法典》在3月21日，皇冠在12月2日。1805年以另一种方式拒绝它：海上的失败与陆地上的胜利。同时代人能够把一部制定法与一场战斗区分开。后来的把一个成就来谈论的这种习惯是我们的，而这正是本章存在所要打破的习惯。
:::

那条反对意见说，这种拆分是迂腐，因为诸行为构成一个事业：给内地的法律，一顶使它世袭的皇冠，以及诸场把它强加给欧洲的战争。一个事业可以是真实的，而仍然不是一个成就。如果《法典》与诸战争是一个成就，那么特拉法尔加就会是与奥斯特里茨同一种成功的一个花招，而1812年之后的撤退就会是《法典》的一条未能适用的条款。把诸失败与诸法律称为一件珠宝，是一部传记谄媚一个政权的方式。[[#def-kinds]]就是解药。你可以说执政府与帝国在内追求秩序、在外追求支配。你不可以停在单独一个名词上。

“一条法律”不是恭维。《法典》给了男性一种不再按旧的法律等级分拣的民事身份，并且确认了一种宽大的父权。已婚妇女失去了她们一直在赢得的东西。离婚，在1792年被准入，被收窄了。我们不引用条文。一条稳定财产并使妻子从属的法律，是一个社会解决方案。它不是1789年的《宣言》，不是恐怖统治，也不是一份使一场战役正当化的礼物。一些财产规则比承载它们的帝国活得更长。存续是关于法律实践的后来的事实，不是把奥斯特里茨称为法学的理由。

:::example 闰年里的八十天 {#ex-leap}
1804年是闰年，所以二月有29天。海地在1804年1月1日宣布独立。《民法典》于1804年3月21日公布。3月21日在1月1日之后多少天？然后说明那段间隔对[[#thm-not-one]]为什么要紧。
:::solution
1月1日是第1天。3月21日是31天的一月，加上29天的二月，加上21，即第81天。81减1是80，所以3月21日在1月1日之后80天。那段间隔要紧，是因为一道独立的宣告与一部民法典是不同的种类。“在1804年，拿破仑制作了现代国家”丢掉了海地，丢掉了《法典》的日期，也丢掉了12月2日的加冕。八十天，足够一条法律成为一条法律、一个国家成为一个国家。
:::
:::

## 海地不是《法典》的一条

:::proposition 海地的宣告既不是《法典》也不是皇冠 {#prop-haiti}
在1804年1月1日，海地宣布独立。那个行为不是3月21日的《民法典》，也不是12月2日的加冕。它是一场始于1791年8月的革命的政治成功，针对的正是1802年奴隶制的恢复。杜桑，在1802年被俘、在1803年死去，不是宣告它的那个人。
:::
:::proof
证据是人与法的次序。那次起义始于1791年8月。国民公会于1794年2月4日废除殖民地奴隶制。1802年，执政府恢复奴隶制并且俘虏了杜桑。1803年，他死于羁押。1804年1月1日，德萨林的国家宣布独立，在《法典》之前，在皇冠之前。1802年的恢复试图在法国权力能够到达之处逆转1794年。在圣多明戈，它输了。在别处，在恢复了的法律能够被执行的地方，奴隶制回来了。我们不描述那次执行，也不数死者。什么会构成对这条命题的反证？一份被写成《法典》的一条的海地宣告，或者一份由杜桑在1804年签署的宣告。宣告是1月1日，《法典》是3月21日，而杜桑已经死了。[[states/atlantic]]承载着那桩贸易与两次法国废奴，第二次在1848年。本章的职责，是不让1月1日消失在3月21日与12月2日之中。
:::

那条反对意见说，海地是法国大革命的一个结果，因而是一个拿破仑式的细节。继承不是作者身份。那次起义比雾月更老。1794年的废奴比《法典》更老。1802年的恢复是拿破仑的政策，而在圣多明戈，独立所击败的正是这个政策。德萨林不是一次加冕的脚注。如果那道宣告曾是一道在巴黎宣告的帝国法令，这个回答就会失败。它是对着那个殖民主张被宣告的。1804年的同几个月，显示一个人成为皇帝，而一个加勒比国家离开他的法律射程。[[#thm-not-one]]讲的既是那个分岔，也是一部制定法与一场战斗。

:::quiz
谁宣布海地独立，以及在何时，相对于《民法典》？
- [ ] 杜桑·卢维杜尔，在1802年，作为恢复奴隶制的一条
- [x] 海地在1804年1月1日宣布独立，在德萨林之下，早于3月21日的《法典》
- [ ] 拿破仑，在加冕的那一天，1804年12月2日
- [ ] 国民公会，在1794年2月4日，而那与独立是同一个行为
:::solution
[[#prop-haiti]]把人与诸日期分开。杜桑在1802年被俘，在1803年死去。国民公会1794年的废奴是一部自由的法国法律，不是一个新国家的宣告。加冕是1804年12月2日，在宣告与《法典》之后。独立是1804年1月1日，而德萨林是本课程附在那个国家上的名字。
:::
:::

## 诸战争是第三种种类

帝国作战，而这些战斗并不共享一个结果。1805年10月21日，特拉法尔加是一场海上的失败，其战略后果是不列颠对海洋的控制。我们不给出任何一个舰船数目。1805年12月2日，奥斯特里茨是一场陆上的胜利，对手是奥地利皇帝与俄国皇帝的军队。与加冕同一个日历日期、一年之后的那一天，是一场战斗，这是一个有用的警告。1804年12月2日与1805年12月2日恰好相隔一年，而不是一个事件。一个记住了“十二月二日”而不带年份的头脑，会把一顶皇冠与一门大炮混在一起。

:::example 四十二天，两种结果 {#ex-forty-two}
特拉法尔加打于1805年10月21日。奥斯特里茨打于1805年12月2日。十月有31天，十一月有30天。12月2日在10月21日之后多少天？这一对对“1805年的胜利”这个短语做了什么？
:::solution
从10月21日到11月21日是31天。从11月21日到12月2日是11天。31加11是42，所以奥斯特里茨在特拉法尔加之后42天。“1805年的胜利”抹掉了六周之前的一场海上的失败。[[#def-kinds]]把两者都称为战争，而[[#thm-not-one]]禁止把它们加成一个成就。法国可以在同一个季节输掉海洋而赢下一片战场。《法典》不在这一对里。它是在上一年公布的。
:::
:::

1807年，不列颠通过一部针对奴隶贸易的法令，打击的是贸易而不是奴隶制本身，正如[[states/atlantic]]所作的区分。同一年还见到拿破仑与俄国之间一场未能持久的和平。一部不列颠制定法与一场欧陆和平，不是一场拿破仑式的战斗，也不是《法典》。它们阻止一个年份自动成为他的荣耀的一章。那场和平作为一个解决方案失败了。对本图谱而言，证据是1812年6月24日，*Grande Armée*（大军团）渡过涅曼河，入侵俄罗斯帝国。

我们不给出那支军队的规模。年表说出了那次渡河，而拒绝那个数字。入侵发生了，撤退发生了，而战役失败了。进一步的诸战役坐落在撤退与第一次退位之间，而它们的年份在这里没有被锁定，所以我们不把它们插进来。被锁定的是第一次帝制的政治终结：1814年4月6日的退位。一次失败的入侵，其本身并不是那个签字。我们停在入侵、撤退与失败。天气、饥饿与一条道路的样子不是本课。那次渡河是一场战争，而它不是《法典》。

第一次退位没有终结诸战争。拿破仑在1815年回来。我们没有锁定他登陆的那一天，所以我们不发明它。那次回来，就理解六月而言已经足够。1815年6月18日，滑铁卢是一次失败。6月22日，他第二次退位，在4天之后。一场战斗与一次退位很近，而不是同一个行为。威灵顿（Wellington）与布吕歇尔（Blücher）赢下了一场战斗。他们没有撰写最后法案。那份法案已经签署。

:::example 一封虚构的军报 {#ex-dispatch}
下面这句话为示例而虚构。它不是史料。它给出一个本图谱禁止给出的规模，所以这个规模连在这里也不会被印出。“大军团，它的规模我们拒绝陈述，把《民法典》带过了涅曼河，因此《法典》与入侵是一个成就。”除了那个缺失的数字，这句话错在哪里？
:::solution
即使在数字被删掉之后，这句话也是把一部民法典变成了一次入侵的货物，并且把两种种类称为一个成就。《法典》是1804年3月21日。涅曼河是1812年6月24日。它们是不同的器具，这就是[[#thm-not-one]]。一条关于财产的法律可以随军队行进，而仍然不是这条河被渡过的那个理由。对一个被禁止的规模打手势，仍然是在使用它。这句话本来只会是真的，如果1812年6月24日的一道战役命令与《法典》同一，并且如果一个兵力规模在年表里被锁定。两者都不是。
:::
:::

## 滑铁卢之前的维也纳

那场会议自1814年起就在开会。它的最后法案是1815年6月9日。滑铁卢是1815年6月18日。第二次退位是6月22日。记住了一个叫作“先失败、后解决”的序列的人，把六月的诸日期记反了。那个解决方案被签署时，拿破仑已经回来，而在那场再一次把他挪开的战斗之前。[[revolutions/restoration-and-1848]]教授那个解决方案包含了什么。本节只教那个次序，因为那个次序在记忆中被不断地颠倒。

:::theorem 最后法案早于滑铁卢 {#thm-order}
维也纳会议最后法案的日期是1815年6月9日，早于1815年6月18日的滑铁卢九天。那场战斗没有产生那份条约。那份条约没有产生那场战斗。那场会议自1814年起就在开会。限度：外交官们本来可以预期进一步的战争。预期不是起草。一个动机不移动一个日期。
:::
:::proof
证据是那一对日期，以及那已经在1814年、即第一次退位于4月6日的那一年开会的会议。从6月9日到6月18日是9天。从6月18日到6月22日是4天。第二次退位跟随那场战斗。最后法案先于它。什么会构成对这条论断的反证？一条定年在6月18日之后、而仍然是6月9日那份法案的一部分的条款，或者一个日期被错标到滑铁卢之后一天的最后法案。我们两样都没有。诸协约国在6月18日之前不让拿破仑统治的意图，可以为真，而仍然让日历保持为：最后法案，然后战斗，然后退位。下一章可以评判那个解决方案。它不可以把6月9日挪到战斗的那天晚上。
:::

如果诸大国已经决定了那张地图，滑铁卢就看上去像是扫尾，而九天就看上去像一个戏法。扫尾仍然不是起草。一场条约之后的战争，没有使条约成为那个战争的孩子。1815年的那次回来威胁了那个解决方案，并且解释了一场战斗为什么仍然可以打。它没有重写那个签字。[[#thm-order]]是有意狭窄的。一个读者能够用一份文献击败它。一个宽泛的论断，例如“维也纳创造了十九世纪”，才是一个绰号藏起来的东西。

:::example 九天，然后四天 {#ex-june}
最后法案是1815年6月9日。滑铁卢是1815年6月18日。第二次退位是1815年6月22日。6月18日在6月9日之后多少天，而6月22日在6月18日之后多少天？每一段间隔各自禁止哪一句政治的句子？
:::solution
18减9是9，所以滑铁卢在最后法案之后9天。22减18是4，所以第二次退位在滑铁卢之后4天。第一段间隔禁止“滑铁卢产生了最后法案”。第二段禁止把一场战斗与一次退位当作一个签字。[[#thm-order]]使用第一段。第二段阻止1815年6月塌缩为滑铁卢这一个词，正如如果你忘了[[#ex-leap]]，1804年就塌缩为拿破仑。
:::
:::

[[#thm-order]]与[[#ex-june]]把最后法案放在1815年6月9日，滑铁卢放在6月18日，第二次退位放在6月22日。第一次退位是1814年4月6日，不是一个六月的事件。《法典》是1804年3月21日。涅曼河是1812年6月24日。四个选项里只有这一个保住了六月的次序与正确的诸年份。
:::
:::

在窗口为1的情况下移到1804年。那个圆点无法显示1月1日、3月21日与12月2日。你可以。1802年的圆点说的是奴隶制被恢复，而漏掉了杜桑的被俘与终身执政官之位。1805年的圆点装着一场失败与一场胜利。1815年的圆点说的是滑铁卢，而无法显示6月9日先来。从雾月到第二个帝制的序列就是那份纪律。凡本课已经按种类拆开的一切，都是那种压缩。

:::warning 一个成就，以及一支军队的一个规模
人们重复说《民法典》与诸胜利是一个成就，而他们常常给渡过涅曼河的那支军队附上一个规模。《法典》是1804年3月21日。奥斯特里茨是1805年12月2日。涅曼河是1812年6月24日。[[#thm-not-one]]拒绝这个单数。那个规模没有被教授，因为它没有被锁定，而一个数字也不会把一次入侵变成一部制定法。海地在1804年1月1日，是一个荣耀的故事最容易放错位置的事实。它既不是他的法典，也不是他的皇冠。
:::

:::history
《民法典》于1804年3月21日公布，而拿破仑在12月2日加冕。那一年的1月1日，海地已经宣布了独立，而让-雅克·德萨林是附在那个新国家上的名字。一部法典、一顶皇冠与一道宣告共享一个年份，而不共享一个种类。
:::

## 通向何处

[[revolutions/restoration-and-1848]]把最后法案读作一个解决的事业，而不是滑铁卢的一个事后想法，然后追随1830年与1848年。执政府曾经倒转的那个废奴在[[revolutions/republic-and-terror]]。帝国在圣多明戈没能重新塞回奴隶制的那场起义始于[[revolutions/from-1789]]。那桩贸易、1685年的《黑人法典》、1807年的不列颠法令，以及1848年法国的第二次废奴，在[[states/atlantic]]。

:::summary
- 雾月18日，1799年11月9日，是一次创建一个执政府的政变。它还不是一顶皇冠，还不是一部《民法典》，也还不是一场俄国战役。
- 在1802年，殖民地奴隶制被恢复，杜桑被俘，而终身执政官之位被取走。这是三个行为。杜桑死于羁押，在1803年，而他没有宣布独立。
- 海地的宣告是1804年1月1日，早于3月21日的《法典》八十天，而远在12月2日的加冕之前。附在那道宣告上的，是德萨林，不是杜桑，也不是拿破仑。
- 《法典》是一部关于财产、父权与一个被收窄的离婚的民事法律。加冕是一顶皇冠。1805年10月21日的特拉法尔加与1805年12月2日的奥斯特里茨，是一场失败与一场胜利，相隔四十二天。
- 涅曼河在1812年6月24日被渡过。那次入侵与那次撤退失败了。任何一个军队规模都没有被说出，而撤退中的苦难也没有被叙述。第一次退位是1814年4月6日。
- 维也纳的最后法案是1815年6月9日，在6月18日的滑铁卢之前，而第二次退位是6月22日。那场会议自1814年起就在开会。那场战斗没有撰写那份条约。
- 一个治理的事业可以把法律、皇冠与战争一起使用。一起使用它们，与一个成就并不相同。
:::

## 习题

:::exercise 《法典》的一天 {level=1 check="21"}
《民法典》于1804年三月的哪一天公布？（请输入那个月的日期数字。）
:::solution
《法典》于1804年3月21日公布。那一天是21。加冕不在三月。它是1804年12月2日。
:::
:::

:::exercise 从条约到战斗的天数 {level=1 check="9"}
最后法案定年为1815年6月9日。滑铁卢是1815年6月18日。滑铁卢在最后法案之后多少天？（请输入天数。）
:::solution
18减9是9。滑铁卢在最后法案之后9天。那场战斗跟随那个签字。它不在那个签字之前。
:::
:::

:::exercise 独立在《法典》之前 {level=1 check="80"}
1804年是闰年，所以二月有29天。海地宣布独立在1月1日。《民法典》公布在3月21日。3月21日在1月1日之后多少天？（请输入天数。）
:::solution
3月21日是那一年之中的第31加29加21天，即第81天。1月1日是第1天。81减1是80。3月21日在1月1日之后80天。
:::
:::

:::exercise 按种类给1804年归类 {level=2}
把1月1日、3月21日与12月2日的1804年排成顺序。说出每一个日期上的那个行为，并说出它是[[#def-kinds]]中的哪一种种类，同时指出其中一个是一个定义没有交给拿破仑的种类。
:::solution
在1月1日，海地宣布独立。那是一个国家的创建，不是拿破仑的法律，也不是他的皇冠。在3月21日，《民法典》公布。那是一条法律。在12月2日，拿破仑加冕。那是一顶皇冠。次序是宣告、法律、皇冠。[[#prop-haiti]]存在，是为了这第一个不被归档在第二个或第三个之下。[[#thm-not-one]]在这单独的一年之内已经是真的，早在1805年的任何一场战斗被添加进来之前。
:::
:::

:::exercise 一个日历日，两个年份 {level=2}
1804年12月2日与1805年12月2日共享一个月与一个日子。在每一个上发生了什么，而为什么“十二月二日”是一种危险的记忆方式？
:::solution
在1804年12月2日，拿破仑加冕。在1805年12月2日，奥斯特里茨开打，恰好一年之后，而种类从皇冠变成战争。一个保留了日子而丢掉了年份的记忆，会把一场典礼与一场战斗混在一起，并且还会丢掉特拉法尔加，1805年10月21日，在奥斯特里茨之前四十二天。一个周年纪念日不是一种同一。
:::
:::

:::exercise 雾月不是什么 {level=2}
一条图形说明写着：“1799年，帝国开始。”使用1799年11月9日、1804年12月2日与1804年3月21日，重写那条说明，使诸种类保持分明。
:::solution
在1799年11月9日，雾月18日，督政府被推翻，执政府开始。那是一次政变，不是一次加冕，不是一部民法典。《法典》于1804年3月21日公布。皇冠是1804年12月2日。一条重写的说明会说“1799年，雾月，执政府”，并且会把帝国与《法典》留在它们自己的日期上。那条坏说明用一个词，帝国，来称呼一个执政官，从而省下四年与一次种类的改变。[[#def-kinds]]不允许这种节省。
:::
:::

:::exercise 一部文本会反驳这个拆分吗？ {level=3}
:::hint
[[#thm-not-one]]说出了什么会构成对它的反证：一个同时是法律、皇冠与一道战役命令的文本，或者一个只有单一一种种类的年份。把1804年与1805年用作检验最难的年份，而不要引入一支军队的规模。
:::
想象你正试图诚实地击败[[#thm-not-one]]。你需要找到什么样的一份文献，而海地在1804年的一月，以及特拉法尔加与奥斯特里茨这一对，为什么使那次搜寻更难，而不是更容易？
:::solution
你会需要一个同时干着《法典》、加冕与一道战役命令的工作的文本，或者一个其中每一个有日期的行为都属于单一一种种类的年份。一句自夸不会足够，而我们不会发明一句。那次搜寻更难，是因为1804年已经装着三种种类：海地在1月1日，那不是他的器具；《法典》在3月21日；皇冠在12月2日。一个包含着一个对着他的殖民主张的行为的年份，不可能是“仅仅那个成就”。在1805年，10月21日的特拉法尔加是一场失败，而12月2日的奥斯特里茨是一场胜利，在42天之后。1812年的涅曼河只会添加又一场战争，仍然不是一部制定法。这条论断屹立不动，直到那一个单独的文献出现为止。它没有。
:::
:::

:::exercise 动机不是一个日期 {level=3}
:::hint
保留1814年4月6日、自1814年起开会的会议、1815年6月9日、1815年6月18日与1815年6月22日。诸协约国想把拿破仑排除在外的愿望可以为真。决定那个愿望是否把最后法案挪到滑铁卢之后的那一天。
:::
一位读者说：“那些大国本意是要把欧洲解决到对着拿破仑的方向，所以滑铁卢在逻辑上先于最后法案，即使日历不同意。逻辑打败一个日期。”使用[[#thm-order]]回答。什么会使那位读者的“逻辑上先于”变成一个历史上的先于？
:::solution
意图不移动一个签字。那场会议自1814年起开会，那一年是第一次退位于4月6日的那一年。最后法案是1815年6月9日。滑铁卢是6月18日，而第二次退位是6月22日。那些大国本来可能有意阻止拿破仑的回来变成一个复辟的帝国。那解释了为什么1815年是一场危机。它没有使6月18日早于6月9日。“逻辑上先于”是一个关于诸目的的故事。[[#thm-order]]是一条关于诸文献的陈述。

那位读者的版本会变成历史上的先于，如果最后法案被定年在滑铁卢之后，或者如果一条在6月18日之后写成的条款是6月9日那份法案的一部分。到那时我们会纠正这一课。在那之前，那个句子是那个平淡的句子：那个解决方案被签署，那场战斗被开打，那次退位跟随而来。[[revolutions/restoration-and-1848]]可以争论那个解决方案做了什么。它不可以假装那场战斗起草了它。
:::
:::
