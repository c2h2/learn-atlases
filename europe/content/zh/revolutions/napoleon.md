拿破仑的行为中，哪些是法律，哪些是皇冠，哪些是战争？

“拿破仑”这个名字聚拢了一次政变、一部民法典、殖民地奴隶制的恢复、一次加冕、一场海战失败、一场陆战胜利、一次入侵、两次退位，以及一场在和平安排签署之后才打的战役。聚拢在一个名字下的东西，看起来像是一项项成就；日期却不这样显示。一部关于财产与家庭的法律不是皇冠，皇冠不是战役，三者也都不是海地借以脱离殖民体系的那份宣言。本章按种类为这些行为分类。本章不给出军队的规模；除了入侵确曾发生、随后是撤退这一事实之外，也不描绘撤退途中的苦难。

[[revolutions/republic-and-terror]]结束时，共和国在热月9日之后依然存在，并于1795年改组。1799年11月9日，这个后来的共和国被推翻。掌握行政权的那个人还不是皇帝。从政变到皇冠的距离，是论证的一部分；在1804年这同一年里，从独立宣言到法典、再到加冕的距离，也是论证的一部分。

## 政变不是皇冠

:::definition 行为的种类 {#def-kinds}
在本章中，**法律**是指改变民事身份、财产或殖民地奴隶制的文本；**皇冠**是指造就一位君主；**战争**是指一场战役或一次战斗。一次建立执政府的政变，在有后续行为之前，不属于这三种中的任何一种。把几种行为放在同一年，或放在同一个姓氏之下，并不会使它们合而为一。
:::

1799年11月9日，即共和历雾月18日，督政府（Directory）被推翻，执政府建立，拿破仑（Napoleon）成为掌握实权的执政。这一行为是共和国内部的政变，而这个共和国在一段时间内仍保留着共和的话语，以及一个高度集中的行政权。它不是《民法典》，那时《民法典》还不存在；它不是加冕；它也不是渡过涅曼河（Niemen）。把雾月称为“帝国”开始的时刻，是后来的荣耀对日历的改写。执政府是一个独立的政体。它缔造和平，制定法律，建立治安，并在为一顶尚未戴上的皇冠作准备。

1801年，在教会经历了十年分裂与打击之后，法国国家与教廷签订《教务专约》（Concordat），达成宗教上的和解。这里不引用它，也不假装本图谱把《教务专约》锁定为一个可以统计的事件。1801年这个年份是可用的，这一安排属于这一年。它的种类既不是民法典，也不是皇冠，也不是战斗，而是一项关于公开礼拜和由国家支薪的教士的交易。一个能与罗马签约、次年又恢复殖民地奴隶制的政体，必须逐一按行为来解读。

1802年至少有三件事不应混为一谈。1794年2月4日被废除的殖民地奴隶制得到恢复；杜桑·卢维杜尔（Toussaint Louverture）被俘；拿破仑就任终身执政，获得了仅次于世袭皇冠的个人权力。当时组织了一次公民投票，但票数没有锁定，这里也不编造。公民投票并不是人民的自由表达。终身执政是通向1804年皇冠的一步，却不是那顶皇冠。恢复奴隶制是一部关于殖民地身份的法律，是恢复种植园秩序的企图，而不是走向海地独立的一步。在法国武力能够强制推行的地方，这一企图产生了实际后果；在圣多明戈（Saint-Domingue），它遇到的是一个自1791年8月起就处于战争中的社会，最终失败了。

杜桑于1803年死于法国的囚禁之中，没能活着看到独立宣言。任何让他在1804年1月1日宣布海地独立的句子，都弄错了人，也弄错了年份。在本课程的记录中，与这个新国家相联系的名字是让-雅克·德萨林（Jean-Jacques Dessalines）。1803年之死，是关于一名囚徒的事实。这里不描述他的囚禁，只把它当作一个日期，防止两位领袖被糅合成同一个传说。

:::theorem 法典、皇冠与战争并不是同一项成就 {#thm-not-one}
1804年3月21日颁布的《民法典》、1804年12月2日的加冕，以及从特拉法尔加（Trafalgar）、奥斯特里茨（Austerlitz）经涅曼河直到滑铁卢（Waterloo）的历次战役，是不同种类的行为。一个姓氏、一个年份，并不能使它们成为同一项成就。限度在于：它们可以为同一个政府服务，却仍然是不同的工具。为同一个政府服务，并不等于种类相同。
:::
:::proof
证据在于工具本身。《法典》是民法：财产、契约、法律等级作为身份形式的终结、父权与夫权，以及对1792年共和国所允许的离婚的限制。它既不是一部政治自由的宪法，也不是给某个团的命令。教皇在场的加冕把一位执政变成了皇帝；一场典礼不是一部关于抵押的法规。1805年10月21日的特拉法尔加是一场海上失败；四十二天之后，1805年12月2日的奥斯特里茨是一场陆上胜利，所以即使在俄国之前，“那些战争”也不是同一种结果。1812年6月24日渡过涅曼河是一次入侵，随后是撤退与失败。《法典》中没有任何内容让你渡河，奥斯特里茨中也没有任何内容是关于已婚妇女订立契约的规则。

什么能推翻这一定理？一份同时是民法、加冕与战役命令的文本，或者一个所有有日期的行为都属于同一种类的年份。1804年拒绝了这种诱惑：1月1日是海地，3月21日是《法典》，12月2日是皇冠。1805年以另一种方式拒绝了它：海上失败，陆上胜利。同时代的人分得清法规与战斗。把它们视为同一项成就，是后来才有的、属于我们的习惯，而本章正是要打破这种习惯。
:::

反对意见认为，这种拆分是吹毛求疵，因为这些行为构成了同一项事业：对内立法，以皇冠使之世袭，以战争把它强加给欧洲。一项事业可以是真实的，却仍然不是同一项成就。如果《法典》与战争是同一项成就，特拉法尔加就会成为与奥斯特里茨同一场胜利的点缀，1812年之后的撤退也会成为《法典》中未能实施的某个条款。把失败与法律称作同一件珍宝，是传记吹捧政体的手法。[[#def-kinds]]就是解药。你可以说执政府与帝国对内追求秩序、对外追求支配，但不能停留在一个单一的名词上。

“法律”并不是一句恭维。《法典》赋予男子一种不再按旧法律等级划分的民事身份，同时确认了广泛的父权。已婚妇女失去了她们此前逐渐获得的行为能力。1792年获准的离婚受到了限制。这里不引用条文。一部稳定财产、使妻子处于从属地位的法律，是一种社会安排。它不是1789年的《宣言》，不是恐怖统治，也不是一件可以为战役辩护的礼物。有些财产规则比承载它们的帝国存在得更久。但这种延续是关于法律实践的后来的事实，而不是把奥斯特里茨称为法学的理由。

:::example 闰年中的八十天 {#ex-leap}
1804年是闰年，所以二月有29天。海地于1804年1月1日宣布独立，《民法典》于1804年3月21日颁布。3月21日在1月1日之后多少天？然后说明这段间隔对[[#thm-not-one]]为什么重要。
:::solution
1月1日是第1天。3月21日是一月的31天加二月的29天再加21天，即第81天。81减1等于80，所以3月21日在1月1日之后80天。这段间隔之所以重要，是因为独立宣言与民法典属于不同的种类。“1804年，拿破仑缔造了现代国家”这种说法，丢掉了海地，丢掉了《法典》的日期，也丢掉了12月2日的加冕。八十天，足以让法律是法律，国家是国家。
:::
:::

## 海地不是《法典》的一个条款

:::proposition 海地的宣言既不是《法典》，也不是皇冠 {#prop-haiti}
1804年1月1日，海地宣布独立。这一行为不是3月21日的《民法典》，也不是12月2日的加冕，而是一场始于1791年8月、反抗1802年恢复奴隶制的革命在政治上的成功。1802年被俘、1803年去世的杜桑，不是宣布独立的那个人。
:::
:::proof
证据在于人物与法律的先后顺序。起义始于1791年8月。国民公会于1794年2月4日废除殖民地奴隶制。1802年，执政府恢复奴隶制，并俘获了杜桑。1803年，他死于囚禁。1804年1月1日，德萨林领导的国家宣布独立，这早于《法典》，也早于加冕。1802年的恢复，企图在法国权力所及之处推翻1794年的废奴。在圣多明戈，它失败了；在别处，凡是恢复奴隶制的法律能够强制执行的地方，奴隶制都回来了。这里不描述强制执行的过程，也不统计死者。什么能推翻这一命题？一份被写成《法典》条款的海地宣言，或者一份由杜桑在1804年签署的宣言。但宣言在1月1日，《法典》在3月21日，而杜桑已经去世。奴隶贸易以及法国的两次废奴（第二次在1848年）见[[states/atlantic]]。本章的任务，是不让1月1日消失在3月21日与12月2日之中。
:::

反对意见认为，海地是法国大革命的一个后果，因而只是拿破仑时代的一个细节。但继承不等于创造。起义早于雾月，1794年的废奴早于《法典》。1802年的恢复是拿破仑的政策，而在圣多明戈，被独立所击败的正是这项政策。德萨林不是加冕的注脚。只有当这份宣言是一部在巴黎颁布的帝国法令时，这一回应才不成立；而它恰恰是针对那种殖民主张而宣布的。在1804年的同几个月里，一个人成为皇帝，而一个加勒比国家脱离了他的法律管辖。[[#thm-not-one]]所讲的，既是法规与战斗之别，也是这种分道扬镳。

:::quiz
谁宣布了海地独立？与《民法典》相比，是在什么时候？
- [ ] 杜桑·卢维杜尔，在1802年，作为恢复奴隶制法律的一个条款
- [x] 海地在德萨林领导下于1804年1月1日宣布独立，早于3月21日的《法典》
- [ ] 拿破仑，在加冕当天，即1804年12月2日
- [ ] 国民公会，在1794年2月4日，这与独立是同一个行为
:::solution
[[#prop-haiti]]把人物与日期区分开来。杜桑于1802年被俘，1803年去世。国民公会1794年的废奴是法国的一部自由法律，而不是一个新国家的宣言。加冕在1804年12月2日，晚于宣言与《法典》。独立在1804年1月1日，本课程把德萨林的名字与这个国家联系在一起。
:::
:::

## 战争是第三种行为

帝国在作战，而这些战斗的结果各不相同。1805年10月21日的特拉法尔加是一场海上失败，其战略后果是不列颠掌握了制海权。这里不给出舰船数目。1805年12月2日的奥斯特里茨，是对奥地利皇帝与俄国皇帝军队的一场陆上胜利。它与加冕是同月同日，只是晚了一年，却是一场战斗，这是一个有用的警示。1804年12月2日与1805年12月2日恰好相隔一年，并不是同一个事件。只记得“12月2日”而不记年份的人，会把皇冠与大炮混为一谈。

:::example 四十二天，两种结局 {#ex-forty-two}
特拉法尔加海战发生在1805年10月21日，奥斯特里茨战役发生在1805年12月2日。十月有31天，十一月有30天。12月2日在10月21日之后多少天？这两场战斗对“1805年的胜利”这一说法意味着什么？
:::solution
从10月21日到11月21日是31天，从11月21日到12月2日是11天。31加11等于42，所以奥斯特里茨在特拉法尔加之后42天。“1805年的胜利”抹去了六周之前的一场海上失败。[[#def-kinds]]把两者都称为战争，而[[#thm-not-one]]禁止把它们加成同一项成就。法国可以在同一季节里失去海洋、赢得战场。《法典》不在这两者之列，它在前一年就已颁布。
:::
:::

1807年，不列颠通过了一部反对奴隶贸易的法令。正如[[states/atlantic]]所区分的，它针对的是贸易，而不是奴隶制本身。同一年，拿破仑与俄国之间还达成了一项未能持久的和约。一部不列颠法规与一项欧陆和约，既不是拿破仑的战斗，也不是《法典》；它们使这一年不会自动成为他荣耀史中的一章。这项和约作为一种安排失败了。对本图谱而言，证据是1812年6月24日：*Grande Armée*（大军团）渡过涅曼河，入侵俄罗斯帝国。

这里不给出这支军队的规模。年表写明了渡河，却拒绝给出数字。入侵发生了，撤退发生了，战役失败了。在撤退与第一次退位之间还有其他战役，但它们的年份在这里没有锁定，所以不予插入。锁定了的是第一次统治在政治上的终结：1814年4月6日的退位。一次失败的入侵本身并不等于那次签字退位。我们止步于入侵、撤退与失败。天气、饥饿与道路的景象，不属于本课。渡河是战争，而不是《法典》。

第一次退位并没有结束战争。拿破仑于1815年归来。他登陆的日期没有锁定，这里也不编造。知道他归来，就足以理解六月发生的事了。1815年6月18日，滑铁卢是一场失败；4天之后的6月22日，他第二次退位。一场战斗与一次退位时间相近，却不是同一个行为。威灵顿（Wellington）与布吕歇尔（Blücher）赢得了一场战斗，但他们并没有起草《最后议定书》。那份文件早已签署。

:::example 一份虚构的战报 {#ex-dispatch}
下面这句话为示例而虚构。它不是史料。原句给出了一个本图谱禁止给出的规模，所以即使在这里也不印出这个规模。“大军团以我们拒绝说明的规模，把《民法典》带过了涅曼河，因此《法典》与入侵是同一项成就。”除了缺少的数字之外，这句话还错在哪里？
:::solution
即使删去了数字，这句话仍把一部民法典变成了入侵的货物，并把两种行为称为同一项成就。《法典》在1804年3月21日，渡过涅曼河在1812年6月24日。它们是不同的工具，这就是[[#thm-not-one]]。一部关于财产的法律可以随军队传播，却仍然不是渡过这条河的理由。对一个被禁止的规模含糊其辞，仍然是在使用它。只有当1812年6月24日的某项战役命令与《法典》完全等同，并且年表锁定了兵力时，这句话才能成立。但两者都不是事实。
:::
:::

## 滑铁卢之前的维也纳

维也纳会议自1814年起就在开会。它的《最后议定书》签署于1815年6月9日，滑铁卢战役在1815年6月18日，第二次退位在6月22日。记得“先战败、后议和”这一顺序的人，把六月的日期记反了。和约签署时，拿破仑已经归来，而那场使他再次下台的战斗还没有发生。和约的内容在[[revolutions/restoration-and-1848]]中讲授。本节只讲先后顺序，因为这一顺序在记忆中常常被颠倒。

:::theorem 《最后议定书》早于滑铁卢 {#thm-order}
维也纳会议《最后议定书》的日期是1815年6月9日，比1815年6月18日的滑铁卢战役早九天。战斗并没有产生条约，条约也没有引发战斗。会议自1814年起就在进行。限度在于：外交官们或许曾经预料还会有战争，但预料不等于起草。动机并不能挪动日期。
:::
:::proof
证据是这两个日期，以及早在1814年、即4月6日第一次退位的那一年就已开始工作的会议。从6月9日到6月18日是9天，从6月18日到6月22日是4天。第二次退位在战斗之后，《最后议定书》则在战斗之前。什么能推翻这一定理？一项日期晚于6月18日、却仍属于6月9日文件的条款，或者一份日期其实应在滑铁卢之后的《最后议定书》。这两样我们都没有。在6月18日之前，盟国确实可能有意阻止拿破仑重新统治，但日历的顺序依然是：《最后议定书》，然后是战斗，然后是退位。下一章可以评判这一安排，却不能把6月9日挪到战斗当天的晚上。
:::

如果列强早已决定了版图，滑铁卢看起来就像扫尾，九天之差看起来就像障眼法。但扫尾仍然不是起草。条约之后的战争，并不会使条约成为这场战争的产物。1815年的归来威胁了这一安排，也解释了为什么还会打这一仗，但它并没有改写签字。[[#thm-order]]是有意限定得很窄的，读者可以用一份文献推翻它。“维也纳创造了十九世纪”这样宽泛的论断，才是绰号所掩盖的东西。

:::example 九天，然后四天 {#ex-june}
《最后议定书》在1815年6月9日，滑铁卢在1815年6月18日，第二次退位在1815年6月22日。6月18日在6月9日之后多少天？6月22日又在6月18日之后多少天？每一段间隔分别排除了哪一种政治说法？
:::solution
18减9等于9，所以滑铁卢在《最后议定书》之后9天。22减18等于4，所以第二次退位在滑铁卢之后4天。第一段间隔排除了“滑铁卢产生了《最后议定书》”的说法；第二段间隔排除了把战斗与退位当作同一次签字的说法。[[#thm-order]]用的是第一段。第二段使1815年6月不至于被压缩成“滑铁卢”这一个词，正如你如果忘了[[#ex-leap]]，1804年就会被压缩成“拿破仑”。
:::
:::

[[#thm-order]]与[[#ex-june]]把《最后议定书》定在1815年6月9日，滑铁卢定在6月18日，第二次退位定在6月22日。第一次退位在1814年4月6日，不是六月的事件。《法典》在1804年3月21日，渡过涅曼河在1812年6月24日。四个选项中，只有这一项既保持了六月的先后顺序，又给出了正确的年份。
:::

把窗口设为1，移到1804年。这个点无法显示1月1日、3月21日与12月2日，但你可以。1802年的点只写着恢复奴隶制，漏掉了杜桑被俘与终身执政。1805年的点同时容纳了一场失败与一场胜利。1815年的点写着滑铁卢，却无法显示6月9日在先。从雾月到第二次统治的序列，是需要遵守的规矩；本课按种类拆分开的一切，则是被压缩掉的内容。

:::warning 同一项成就，以及军队的规模
人们常说，《民法典》与历次胜利是同一项成就，还常常给渡过涅曼河的军队附上一个规模。《法典》在1804年3月21日，奥斯特里茨在1805年12月2日，渡过涅曼河在1812年6月24日。[[#thm-not-one]]拒绝这种单数说法。这里不讲授军队规模，因为它没有锁定，而且一个数字也不能把入侵变成法规。1804年1月1日的海地，是荣耀叙事最容易放错位置的事实。它既不是他的法典，也不是他的皇冠。
:::

:::history
《民法典》于1804年3月21日颁布，拿破仑于12月2日加冕。而在这一年的1月1日，海地已经宣布独立，与这个新国家相联系的名字是让-雅克·德萨林。一部法典、一顶皇冠与一份宣言同在一年，却不属于同一种类。
:::

## 通向何处

[[revolutions/restoration-and-1848]]把《最后议定书》当作一项缔造秩序的事业，而不是滑铁卢之后的补笔，然后讲述1830年与1848年。被执政府推翻的那次废奴，见[[revolutions/republic-and-terror]]。帝国在圣多明戈无法重新压回奴隶制的那场起义，始于[[revolutions/from-1789]]。奴隶贸易、1685年的《黑人法典》、1807年的不列颠法令，以及1848年法国的第二次废奴，见[[states/atlantic]]。

:::summary
- 雾月18日，即1799年11月9日，是一次建立执政府的政变。它还不是皇冠，还不是《民法典》，也还不是对俄战争。
- 1802年，殖民地奴隶制得到恢复，杜桑被俘，拿破仑就任终身执政。这是三个行为。杜桑于1803年死于囚禁，并没有宣布独立。
- 海地的宣言在1804年1月1日，比3月21日的《法典》早八十天，更远早于12月2日的加冕。与这份宣言联系在一起的是德萨林，而不是杜桑，也不是拿破仑。
- 《法典》是一部关于财产、父权与限制离婚的民法。加冕是皇冠。1805年10月21日的特拉法尔加与1805年12月2日的奥斯特里茨，是相隔四十二天的一场失败与一场胜利。
- 1812年6月24日渡过涅曼河。入侵与撤退都失败了。本课不给出军队规模，也不叙述撤退中的苦难。第一次退位在1814年4月6日。
- 维也纳《最后议定书》在1815年6月9日，早于6月18日的滑铁卢，第二次退位在6月22日。会议自1814年起就在进行。战斗并没有起草条约。
- 一项治理事业可以同时运用法律、皇冠与战争，但同时运用并不等于同一项成就。
:::

## 习题

:::exercise 《法典》的日期 {level=1 check="21"}
《民法典》于1804年3月的哪一天颁布？（请输入日期。）
:::solution
《法典》于1804年3月21日颁布，日期是21日。加冕不在三月，而在1804年12月2日。
:::
:::

:::exercise 从条约到战斗的天数 {level=1 check="9"}
《最后议定书》的日期是1815年6月9日，滑铁卢战役在1815年6月18日。滑铁卢在《最后议定书》之后多少天？（请输入天数。）
:::solution
18减9等于9。滑铁卢在《最后议定书》之后9天。战斗在签字之后，而不是之前。
:::
:::

:::exercise 独立早于《法典》 {level=1 check="80"}
1804年是闰年，所以二月有29天。海地于1月1日宣布独立，《民法典》于3月21日颁布。3月21日在1月1日之后多少天？（请输入天数。）
:::solution
3月21日是这一年的第31加29加21天，即第81天。1月1日是第1天。81减1等于80。3月21日在1月1日之后80天。
:::
:::

:::exercise 按种类整理1804年 {level=2}
请把1804年的1月1日、3月21日与12月2日按先后排列，说出每个日期上的行为，并指出它属于[[#def-kinds]]中的哪一种；同时指出，其中有一种行为是定义没有归于拿破仑的。
:::solution
1月1日，海地宣布独立。这是一个国家的建立，既不是拿破仑的法律，也不是他的皇冠。3月21日，《民法典》颁布，这是法律。12月2日，拿破仑加冕，这是皇冠。顺序是宣言、法律、皇冠。[[#prop-haiti]]的作用，就是不让第一项被归入第二项或第三项之下。即使还没有加入1805年的任何战斗，[[#thm-not-one]]在这同一年之内就已经成立了。
:::
:::

:::exercise 同一个日子，两个年份 {level=2}
1804年12月2日与1805年12月2日同月同日。这两天各发生了什么？为什么用“12月2日”来记忆它们是危险的？
:::solution
1804年12月2日，拿破仑加冕。恰好一年之后的1805年12月2日，奥斯特里茨战役打响，种类从皇冠变成了战争。只记日子、不记年份的记忆，会把一场典礼与一场战斗混为一谈，还会丢掉比奥斯特里茨早四十二天的1805年10月21日特拉法尔加海战。周年并不等于同一。
:::
:::

:::exercise 雾月不是什么 {level=2}
一条图表说明写着：“1799年，帝国开始。”请利用1799年11月9日、1804年12月2日与1804年3月21日改写这条说明，使各种行为保持分明。
:::solution
1799年11月9日，即雾月18日，督政府被推翻，执政府开始。这是一次政变，既不是加冕，也不是民法典。《法典》于1804年3月21日颁布，皇冠在1804年12月2日。改写后的说明应当是“1799年，雾月政变，执政府”，并把帝国与《法典》留给它们各自的日期。那条错误的说明用“帝国”一个词来称呼一位执政，从而省掉了四年时间与一次种类的转变。[[#def-kinds]]不允许这样省略。
:::
:::

:::exercise 一份文本能推翻这种拆分吗？ {level=3}
:::hint
[[#thm-not-one]]已经说明了什么能推翻它：一份同时是法律、皇冠与战役命令的文本，或者一个只有一种行为的年份。请把1804年与1805年作为检验最困难的年份，并且不要引入军队规模。
:::
假设你要诚实地推翻[[#thm-not-one]]。你需要找到什么样的文献？为什么1804年1月的海地，以及特拉法尔加与奥斯特里茨这两场战斗，使这一搜寻变得更难而不是更容易？
:::solution
你需要找到一份同时承担《法典》、加冕与战役命令功能的文本，或者一个所有有日期的行为都属于同一种类的年份。一句自夸是不够的，本课也不会编造一句。搜寻之所以更难，是因为1804年已经包含了三种行为：1月1日的海地，那不是他的工具；3月21日的《法典》；12月2日的皇冠。一个包含了反对他殖民主张的行为的年份，不可能“只有那一项成就”。1805年，10月21日的特拉法尔加是一场失败，42天之后12月2日的奥斯特里茨是一场胜利。1812年的涅曼河只会再添一场战争，仍然不是法规。在那份唯一的文本出现之前，这一定理始终成立，而它并没有出现。
:::
:::

:::exercise 动机不是日期 {level=3}
:::hint
请记住1814年4月6日、自1814年起召开的会议、1815年6月9日、1815年6月18日与1815年6月22日。盟国想把拿破仑排除在外的愿望可能是真实的。请判断这一愿望能否把《最后议定书》挪到滑铁卢之后。
:::
一位读者说：“列强本来就打算以反对拿破仑为前提来安排欧洲，所以即使日历不是这样，滑铁卢在逻辑上也先于《最后议定书》。逻辑胜过日期。”请运用[[#thm-order]]作答。什么能使这位读者所说的“逻辑上在先”变成历史上的在先？
:::solution
意图不能挪动签字。会议自1814年起召开，那一年4月6日发生了第一次退位。《最后议定书》在1815年6月9日，滑铁卢在6月18日，第二次退位在6月22日。列强或许有意阻止拿破仑的归来演变为帝国的复辟，这解释了1815年为什么是一场危机，却并不能使6月18日早于6月9日。“逻辑上在先”是一个关于目的的故事，[[#thm-order]]则是一个关于文献的陈述。

如果《最后议定书》的日期晚于滑铁卢，或者6月18日之后写成的某个条款属于6月9日的文件，读者的说法就会变成历史上的在先，到那时我们会修正本章。在此之前，结论只能是那句平淡的话：和约签署了，战斗打响了，随后是退位。[[revolutions/restoration-and-1848]]可以争论这一安排做了什么，却不能假装是那场战斗起草了它。
:::
