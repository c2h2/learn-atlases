1848年解决了什么，而它仅仅尝试了什么？

一个年份可以震动许多座首都，而仍然没有一个单一的结果。在1848年，革命的政权在整座欧洲兴起。它们大多数被击败了。哈布斯堡的农奴制被废除了，而那次废除存续了下来。同一年的一个瑞士的解决方案存续了下来。奥尔良王朝没有回来。法国的殖民地奴隶制第二次被废除，而那次废除站住了。一个德意志议会开了会，而没有成为一个国家。一份在二月于伦敦出版的小册子没有成为一个政府。说那一年失败了，是保住了那些街垒而丢掉了那些法律。说它创建了作为国家的社会主义，是保住了那本小册子而丢掉了那些在当权的政府。

通往那一年的道路，穿过一个并不是返回的解决方案，并且穿过政治没有等待1848年就在运动的二十年。维也纳的最后法案是1815年6月9日，早于6月18日的滑铁卢。复辟是一个事业。1830年改变了一个法国的王朝，并且开创了一个比利时的国家。1832年的不列颠改革法案扩大了一个保持狭窄的选举权。《谷物法》在1846年被一个议会废除，而不是被一座街垒废除。这些之中没有一个，是“1848年”的另一个名字。它们就是为什么1848年不能被叙述成一块冻结的大陆上的第一道裂缝，或者一种唯一的变迁形式。

## 一个先被签署的解决方案

:::definition 复辟 {#def-restoration}
**复辟**是拿破仑第一次退位之后，把诸国王放回去、并且画一张将阻断法国帝制的支配回来的地图的那个事业。它不是回到1789年5月5日的旧制度，也不是一个在滑铁卢那天晚上写成的条约。这个名字听起来像一次时间的倒转。那些行为是选择：哪一个王朝，哪些边界，对过去的哪些债要兑付，哪些要忽略。
:::

[[revolutions/napoleon]]确立了那个次序，然后停下。那场会议自1814年起就在开会。1814年4月6日，拿破仑第一次退位。最后法案是1815年6月9日。滑铁卢是6月18日，在九天之后，而第二次退位是6月22日。一个从那场战斗赶来的读者，错过了那个签字。对皇帝回来的恐惧，解释了六月为什么危险。它没有让那场战斗起草那份法案。[[#def-restoration]]接着问：那个事业试图恢复什么。

不是1789年5月5日的那个早晨。1814年，法国领受了一部钦定宪章：路易十八（Louis XVIII），一个议会，不是按等级表决的三个等级。我们不引用那部宪章。《民法典》仍然是民事法律。法律等级没有作为国家的骨架回来。那个事业要王座与祭坛在公共生活里，而*émigrés*（流亡者）在荣誉上、在力所能及之处也在财产上得到补偿。想要，不是把一代人的出售、法律与死亡倒回去。一个复辟的波旁，是一个革命与一个帝国之后的波旁。他不是等级会议前夜的路易十六。路易十六自1793年1月21日起已经死了。

这张地图是一张大国之图，不是诸民族之图。一个德意志邦联是一个松散的框架，不是一个民族国家。荷兰王国把北方诸省同南方诸省连接起来，而后者不会留下不走。那个在1772年、1793年与1795年被抹去的波兰-立陶宛联邦，没有被恢复。一个被系缚在俄国皇帝身上的王国不是独立。意大利保持为若干分离的国家，奥地利在北方有影响，而别处是复辟的统治者。诸大国所解决的是领土，以及对一个单一的法兰西帝国的禁绝，不是对每一种语言的正义。[[states/east]]有那些瓜分。[[nations/unifications]]有更晚的那些国家，而这个解决方案并没有把它们预先写好。

:::proposition 维也纳是一个事业，不是附笔，也不是倒带 {#prop-vienna}
1815年6月9日的最后法案，是诸大国选择的一个解决方案，在滑铁卢之前签署，目标是在不重造1789年的三级会议的情况下，防止拿破仑式的支配回来。复辟命名的就是那个事业。它命名的，不是对民事法律中每一场革命性改变的一次成功的撤销。限度：一个事业可以是强制的，而仍然是一个事业，而不是一种命运。后来的诸革命没有“反驳”那个签字。它们显示那个签字没有把政治冻住。
:::
:::proof
证据是[[revolutions/napoleon]]里已经固定的那一对次序：6月9日，然后6月18日。被安装的：一个在1814年宪章之下的一个波旁，一个德意志邦联，一个联合的荷兰，被重画的诸意大利国家，没有一个完整的波兰-立陶宛联邦。没有被安装的：三个等级，《民法典》的废除，德意志人、意大利人或波兰人的一个民族国家。什么会构成对这条命题的反证？一个定年在滑铁卢之后的最后法案，或者一部像1789年5月5日那样恢复按等级投票、并且在财产法之前废除了民事平等的1814年的宪制。我们没有那些文献。那个解决方案并不温和。诸边界是被强加的，而在第二次复辟之后，那些报复是暴力的、党派的，有时被戏称为白色恐怖。那个绰号不是1793年9月到1794年7月27日的恐怖统治。没有一个死亡数目，没有一个程序。一个事业与一场镇压可以共享一个季节。
:::

那条反对意见说，《法典》与一个议会是一层表面，而旧精英们回来了，所以“不是倒带”是律师们的安慰。精英们的确回到了土地、教会与官职那里，只要他们能够。我们没有说复辟在社会上与共和国同一。授权的形式不是1789年的那个开幕的早晨。一部宪章与一部民法典不是三级会议。一个贵族在那些形式之内收买影响，是拿着旧名字玩一场新游戏。[[#prop-vienna]]能够容纳社会性的复辟，而仍然禁止那个旧早晨已经回来这句话。如果三个等级与那个官职可买卖的高等法院不是这部宪制，旧制度就没有回来。

## 1830年，以及一场狭窄的改革

那个事业没有停在原地。1830年7月，曾试图越过那部宪章而治的夏尔十世（Charles X）被推翻。奥尔良支系的路易-菲利普（Louis-Philippe）成了法国人的国王。那个头衔是一个宣称，是一个民族的国王而不是旧式的一片国土的国王，不是一份社会描述。1830年改变了一个王朝，而保留了一个君主制。它没有创建一个共和国，也没有恢复夏尔十世。七月王朝在1848年2月倒下。那是一个后来的事实，不是1830年已知的一条规律。

同一年，一场革命在荷兰王国的南方诸省开始。一个比利时的国家从中产生。本图谱没有锁定一个后来的承认条约的日子，所以我们不发明一个。存续下来的东西，是一个同荷兰王冠分离的政治体，而维也纳曾把那些省份置于那个王冠之下。那张地图在那个解决方案的有生之年被修订过。那次修订不是1848年，也不是1815年的每一个条款的失败。诸边界可以在一个德意志邦联仍然存在的同时移动。

不是1830年的每一场起事都创建了一个国家。一场反抗俄国统治的波兰起义始于1830年，而被击败了。我们没有锁定它结束的那一年，所以我们不给它编号。波兰人没有从这个季节得到一个国家，而这是[[nations/unifications]]仍将面对的一个事实。1830年已经是一个复数：法国改变王朝，比利时开始，波兰的起事失败。“1830年的革命”这个单数，已经挑选了巴黎。

:::example 一年里的三种结果 {#ex-1830}
只用1830年，说出一个改变王朝而不终结君主制的结果，一个创建了一个国家的结果，以及一个被击败的起事。为什么“1830年成功了”以与“1848年失败了”相同的方式失败？
:::solution
七月革命用路易-菲利普替换了夏尔十世，而保留了一个君主制。比利时革命从维也纳曾并入荷兰王冠的那些省份当中开创出一个国家。1830年的波兰起义被击败，而没有创建一个国家。“1830年成功了”之所以失败，是因为波兰是一场失败，也是因为法国的结果是一个王朝，而不是一种你不说出为了谁就不能命名的成功。“1848年失败了”因镜像的理由而失败。一个只带一个成功或失败的动词的年份标签，已经把那个复数扔掉了。图形印的是“七月与比利时”，而没有提波兰。图形在压缩。本课不应当照抄它。
:::
:::

:::example 两部不列颠制定法 {#ex-statutes}
改革法案是1832年。《谷物法》在1846年被废除。两个年份的差是什么，而为什么这两部制定法都不是1848年那种革命？
:::solution
1846减1832是14。两部都是一个不曾倒台的议会的制定法。一部扩大了一个保持狭窄、并且把女性排除在外的选举权。另一部废除了一项谷物保护，而本课不陈述任何关税。这个对照就是那一章的问题所需要的那个：维也纳与1848年之间的变迁，不是街垒的同义词。十四年的制定法不是一份1848年二月的脚本。
:::
:::

不列颠没有经历那个七月。1832年，改革法案重新分配议席，并且在财产之内扩大选举权。成年男子作为一个阶级没有被授予选举权。女性也没有。那部法案是一个存活下来的议会的制定法，属于1689年的《权利法案》与1694年的英格兰银行的那个世界，不是巴黎的一次王朝改变。后来的改革法案，在1867年与1884年，仍然把女性排除在外。它们属于[[nations/mass-politics]]。说出它们，是对“1832年完成了民主”这个故事的警告。没有任何百分比被锁定，所以一个也不陈述。[[#ex-statutes]]把这部制定法放在1846年的废除旁边。

1846年，议会废除了《谷物法》，即对谷物的保护性关税。罗伯特·皮尔（Robert Peel）的政府主持了那次废除，承受着来自制造商的、以及来自想要更便宜的面包的人们的压力。那个十年也是爱尔兰的饥荒的十年。[[nations/industry]]比较1841年与1851年，并且不陈述一个死亡总数。本章既不发明那个总数，也不发明一个本图谱没有锁定的起始年份。那次废除是一部制定法，不是一场革命。一个议会能够不经一座街垒而撤销一项重大的保护，正当其他诸首都即将建造街垒的那个时代。那次废除本身没有喂饱爱尔兰。它显示，维也纳与1848年之间的变迁，不是革命的同义词。

1833年的针对帝国大部分地区奴隶制的不列颠法令，带着延续到1838年的学徒身份，是同一个对照，并且在[[states/atlantic]]里作为法律被教授。它不是1848年，也不是一种文明的道德教训。一部自由的劳动法，被学徒身份围着护栏，是另一种器具。我们不描述种植园劳动，也不数人。

:::quiz
关于1832年的不列颠改革法案，什么是真的？
- [ ] 它把投票权给了所有成年人，并且完成了民主
- [ ] 它是1792年的法兰西共和国的一个翻版
- [x] 它扩大了一个保持狭窄的选举权，而没有把女性包括进来
- [ ] 它废除了《谷物法》，而那其实发生在1846年
:::solution
1832年的法案重新分配了一些议席，并且在财产之内扩大了选举人团。它没有把选举权给女性，也没有把选举权给作为阶级的成年男子。《谷物法》倒在1846年，那是另一部制定法。1792年9月21日到22日的法兰西共和国，是一个不同的国家与一种不同种类的事件。狭窄是年表锁定的事实，而它正是一个“民主的胜利”的故事不能使用的那个事实。
:::
:::

## 许多场革命

1848年2月，巴黎的一场革命揭开了这一年。路易-菲利普倒台，而一个共和国被宣告。成年男子被一种宽泛的普选权吸了进来，而女性没有。国家工场作为一种社会的应急办法被开设，随后被关闭。六月，共和国同巴黎工人的一场起事作战，并且镇压了它。我们不陈述任何死亡数目。到那一年年底，路易-拿破仑·波拿巴已经被选为总统。春天的那个社会共和国没有统治冬天。七月王朝也没有回来。十二月里的法国不是二月里的法国，而且它也不是六月的那些战斗者想要的那个共和国。

同一年，法国诸殖民地再一次废除了奴隶制。第一次废奴是1794年2月4日。殖民地奴隶制的恢复是1802年。第二次废奴，在1848年，站住了。它是这个革命之年的一个法律结果，不依赖于六月起义的取胜，而它也没有把第二共和国变成一个恒久的政权。[[states/atlantic]]把这三个日期放进更长的大西洋序列，放在1807年针对贸易的不列颠法令与1833年的法令旁边。在这里，这一点是就地针对那个问题的。废奴比通过它的那个革命政府活得更长。那是一个年份能够在其诸政权被击败的同时解决某件事的一种方式。

:::theorem 1848年没有在所有地方失败 {#thm-not-everywhere}
1848年的革命政权大多数被击败了。那一年没有在所有地方失败。哈布斯堡帝国里的农奴制在1848年被废除，而那次废除存续了下来。1848年的瑞士解决方案存续了下来。其他的结果，包括奥尔良王朝的终结与法国对殖民地奴隶制的第二次废除，也活过了那些街垒。限度：存续的法律，同获胜的革命政府，不是一回事。两个句子都是真的，而第二个不取消第一个。
:::
:::proof
证据是政权与法律之间的分裂。维也纳、匈牙利、波希米亚与诸意大利省份的革命，撼动了哈布斯堡君主国。匈牙利的革命政府被击败了，而有俄国军队被用来对付它。我们不为那场军事行动锁定一个单独的年份，也不给出一个伤亡数字。革命者想要的那种形式的独立的匈牙利的那个事业，没有存续下来。农奴制的废除存续了下来。法律上的不自由在那个帝国于1848年结束，并且在将军们获胜之后保持结束。一个1848年的瑞士联邦解决方案存续了下来。意大利的革命与一场对奥地利的战争，没有产出一个统一的意大利，那是一个更晚的创造，在[[nations/unifications]]里教授。法兰克福开了会，而没有成为一个国家。巴黎看着它的二月共和国击败它的六月起义。被击败的诸政权的清单很长。存续的诸改变的清单不是空的。“在所有地方都失败了”需要一个空的清单。

什么会构成对这条论断的反证？哈布斯堡农奴制的回来，瑞士解决方案的一次迅速的撤销，路易-菲利普的回来，以及1848年在法国诸殖民地获得自由的人们的重新为奴。一个逆转会收窄这条论断。它们全部会击败它。那个说大多数革命政府输了的真实句子，已经在论断之内。错误是让它冒充那一年。
:::

那条反对意见说，那些存续的结果是由获胜的诸政府授予的，所以它们不是革命性的。一部法律可以在革命的压力之下诞生，并且被那个随后粉碎革命者的权威所确认。作者身份与存续是不同的问题。哈布斯堡的农奴制，终结在那个击败匈牙利政府的帝国里。史家意见不一，争论哪一道法令应当得到强调。你不可以得出一座倒下的街垒让农民的法律处境没有改变的结论。瑞士的解决方案是那一年自己的宪制结果，而它存续了下来。一个无视瑞士与农民们的反对意见，是挑选了它的例子。

法兰克福是那个不曾解决的尝试里最清楚的一个。一个德意志议会辩论了一部宪制，一个没有奥地利的小德意志，还是一个带着哈布斯堡诸地的大德意志，而它没有成为一个国家。我们没有锁定一顶皇冠被拒绝的那一天，所以我们不给它定年。一个国家之缺席就够了。1871年宣告的那个帝国是另一个事业，在[[nations/unifications]]里教授，不是这个被延宕的议会。在1848年输了的意大利人，并不因此就被排定了在1861年要赢。后来的成功是一个不同的章节。

不列颠的1848年，是一场没有变成一个政权的动员。宪章派为一种更宽的民主请了愿。政府留了下来。我们不给出任何人群规模。一场爱尔兰的起事在同一年被击败，在饥荒的那个十年之内，而同样没有一个死亡数目被陈述。一个把一场不列颠的非革命与一场爱尔兰的失败包括进来的年份，不是一个从西向东滚动的机制。1846年的废除没有引起巴黎。它让那些种类保持着分明。

:::example 一个只在一个方向失败的句子 {#ex-fail}
下面这句话为示例而虚构。它不是史料。它不是一编编年史，也不是一部法律。“1848年在所有地方都失败了，所以到下一个季节，那一年没有任何东西留下来。”这句话抹去了哪些被锁定的结果，而你可以添加哪一句真实的子句，而不把那一年变成一个成功的故事？
:::solution
这句话抹去了哈布斯堡农奴制的废除、1848年的瑞士解决方案、法国对殖民地奴隶制的第二次废除，以及路易-菲利普没有回来这个事实。[[#thm-not-everywhere]]就是修补。你可以添加的一句真实的子句是：革命政权大多数被击败了，包括匈牙利政府、诸意大利的事业、六月起义，以及那个未能成为国家的法兰克福。那个子句保住了那些失败，而没有把“在所有地方”放回去。一个全称的动词遇到的，是一个曾经是一组的年份。修补是一份清单。
:::
:::

## 一份文件不是一个政府

:::corollary 《宣言》不是一个国家 {#cor-manifesto}
《共产党宣言》（Communist Manifesto），由卡尔·马克思（Karl Marx）与弗里德里希·恩格斯（Friedrich Engels）写作，于1848年2月在伦敦出版，是那个月的一份文献。它不是一份巴黎、维也纳、法兰克福或任何别的地方的政府，而1848年不是作为国家的社会主义的诞生。我们不引用那本书，也不叙述作者们的生平。
:::
:::proof
一份伦敦的小册子可以为一场革命作论证。论证不是官职。巴黎在二月推倒了一个国王。它后来的那些治理者不是那些作者，也不是那个在当权的纲领。法兰克福是一个自由主义的与民族的议会，不是这份文本。六月没有把那本小册子安装为一部宪制。1848年没有任何国家是由《宣言》创建的社会主义国家。如果一个内阁曾把那份小册子采纳为它的宪制、并且依据它进行统治，这条推论就会失败。在本课程使用的记录里，没有一个内阁这样做过。那本书作为一份有日期的文献仍然要紧。要紧不是统治。作为国家的社会主义是一个后来的宣称。
:::

一句细到足以成为引文的转述就是一句引文，所以我们不重建那个论证。两位作者巴黎起事的那个月，在伦敦出版了一份纲领，而那份纲领不是随后那个政府。社会主义的言说比这本小册子更老。我们不给那些词语锁定一个生日。1848年开始社会主义的那个迷思，从这本书滑向一个国家。[[#cor-manifesto]]拦住那个滑动。本章不会报告一句它不曾得到的话，或者一段生平。印刷了结一场论证。它不了结一部宪制。

:::example 印在同一个月 {#ex-february}
揭开1848年的巴黎革命在二月。《共产党宣言》于1848年2月在伦敦出版。从共享的那个月你可以推论什么，而[[#cor-manifesto]]禁止你推论什么？
:::solution
你可以推论：一场革命的爆发与一份社会主义的纲领是同时代的。同时代不是因果，也不是同一。你不可以推论：《宣言》引起了巴黎，巴黎把它制定了出来，或者它的作者们进行了统治。你不可以引用它，也不可以用一段生平去填补那个空缺。共享的那个月，同1792年9月瓦尔密与共和国之间的那一天，是同一种诱惑：一段短的间隔邀请“创造了”这个动词。那个动词仍然是错的。一个谨慎的句子会说，在1848年2月，一个政权在巴黎倒下，而一份小册子在伦敦出现。[[#thm-not-everywhere]]说的是哪些结果存续了下来。那本小册子是论证上的一次尝试，不是那些解决方案中的一个。
:::
:::

:::quiz
哪一个说法符合1848年？
- [ ] 那一年在所有地方都失败了，包括哈布斯堡帝国里农民们的法律处境
- [ ] 《共产党宣言》成了法兰西与那个德意志议会的宪制
- [x] 革命政权大多数被击败了，而一些结果，包括哈布斯堡农奴制的终结与瑞士的解决方案，存续了下来
- [ ] 维也纳的最后法案是在滑铁卢之后签署的，为了回应1848年的诸革命
:::solution
[[#thm-not-everywhere]]把那些失败与那些存续的结果保持在一条论断里。《宣言》是二月的一份伦敦出版物，不是一部宪制，这就是[[#cor-manifesto]]。最后法案是1815年6月9日，在滑铁卢之前，也在1848年之前数十年。这些错误选项，每一个都塌缩了一个复数的年份、一份文献，或者一个年表。
:::
:::

:::widget timeline
start: 1814
end: 1850

events: 1815,维也纳与滑铁卢; 1830,七月与比利时; 1832,改革法案; 1846,谷物法; 1848,革命与宣言
caption: 移动年份。维也纳与滑铁卢共享1815年，而在圆点上它们的先后并非如此。1848年是若干场革命，不是一个结果。
:::

1815年的圆点说不出哪一样先来。你可以：6月9日，然后6月18日。1830年的圆点把七月接上比利时，而漏掉了波兰的失败，那就是[[#ex-1830]]存在的原因。1832年与1846年是不列颠的诸制定法，不是诸革命，那就是[[#ex-statutes]]。最后那个圆点是若干场革命加一份宣言。一个为2年的窗口显示的是邻居。邻居不是原因。一项谷物关税的废除不解释法兰克福，而法兰克福也不解释那次废除。

:::warning 作为一次单独的失败的这一年
人们重复说1848年失败了，有时还说一份宣言吓坏了体面人，或者它是那一年真正的宪制。[[#thm-not-everywhere]]回答第一个习惯。诸政权大多数被击败了，而那一年仍然终结了哈布斯堡的农奴制，留下了一个瑞士的解决方案，终结了奥尔良王朝，并且第二次废除了法国的殖民地奴隶制。[[#cor-manifesto]]回答第二个。一本二月的伦敦的书不是一个国家。完全的失败，对一个想要诸民族国家看起来像真实结果的后来的故事是有用的。有用不是关于这一年的证据。
:::

:::history
在1848年2月，巴黎的一场革命揭开一个革命之年，遍及许多座城市。《共产党宣言》在同一个月于伦敦出现，出自卡尔·马克思与弗里德里希·恩格斯之手，而它是一份文献，不是一个政府。一些结果活过了那些街垒的失败，其中包括哈布斯堡帝国里农奴制的终结。
:::

## 通向何处

[[nations/unifications]]接走1848年尝试过而不曾创建的那些德意志与意大利的国家，以及仍然不曾得到一个国家的波兰人与别的人们。[[nations/mass-politics]]接走后来的不列颠诸改革法案，以及1832年留下的那个狭窄的选举权。[[nations/industry]]接走那些普查数字，包括1841年与1851年的爱尔兰，并且拒绝一个饥荒的死亡总数，本章也拒绝过它。维也纳与滑铁卢的那个次序，这里假定它，是在[[revolutions/napoleon]]里论证的。复辟不曾恢复的那个旧制度在[[revolutions/old-regime]]。

:::summary
- 复辟是1814年与1815年的一个事业，不是对1789年5月5日的一次倒带，也不是一份在滑铁卢之后写成的文献。最后法案是1815年6月9日，在6月18日的那场战斗之前。
- 那个解决方案建起一张大国之图：一个宪章之下的一个波旁君主制，一个德意志邦联，一个荷兰王国，一个没有被恢复的波兰联邦。《民法典》没有被当作那个国王回来的代价而废除。
- 1830年改变了法国的王朝，并且开创了一个比利时的国家。一次1830年的波兰起事被击败。那一年已经是一个复数。
- 1832年的改革法案扩大了一个狭窄的选举权，而没有包括女性。《谷物法》在1846年被一部制定法废除。这两部法案都不是1848年那种革命。
- 1848年是若干场革命。革命政权大多数被击败了。那一年没有在所有地方失败：哈布斯堡的农奴制终结了，瑞士的解决方案存续了下来，奥尔良的国王没有回来，而法国的殖民地奴隶制被再一次废除。
- 法兰克福开了会，而没有创建一个德意志国家。意大利的统一没有在这一年达成。匈牙利的革命政府被击败了。
- 《共产党宣言》于1848年2月在伦敦出版。它在这里没有被引用，它不是它的作者们的一部生平，也不是作为国家的社会主义的诞生。
:::

## 习题

:::exercise 六月的哪一天？ {level=1 check="9"}
维也纳会议最后法案在1815年六月的哪一天被签署？（请输入那个月的日期数字。）
:::solution
最后法案是1815年6月9日。滑铁卢是6月18日。那个签字的月份的日子是9。
:::
:::

:::exercise 一场狭窄的改革 {level=1 check="1832"}
扩大选举权同时让它保持狭窄的那部不列颠改革法案，在哪一年？（请输入年份。）
:::solution
那部法案是1832年。它不是1846年，《谷物法》废除的那一年，也不是1848年。
:::
:::

:::exercise 从最后法案到革命之年 {level=1 check="33"}
最后法案在1815年。本章作为一个欧洲整体讨论的那些革命在1848年。两个年份之差是多少？（请输入年数。）
:::solution
1848减1815是33。差是33年。它与[[revolutions/old-regime]]里从1756年到1789年的是同一段算术上的间隔，而它们不是同一段历史。相等的间隔不是相等的原因。这个数字只是阻止你把维也纳与1848年当作相邻的两种心绪。
:::
:::

:::exercise 一个存续的结果，一次失败 {level=2}
说出1848年的一个存续的结果，以及1848年的一个被击败的革命事业。把两者都定年到那一年，并说出这一对为什么是“那一年解决了什么？”的答案。
:::solution
一个存续的结果是1848年哈布斯堡农奴制的废除，或者那一年的瑞士解决方案。一个被击败的事业是法兰克福成为德意志国家的那次尝试，或者匈牙利政府，或者六月起义，或者意大利的统一。[[#thm-not-everywhere]]把那一年定义为一组。解决，是在法律里留下来的东西。尝试，是被击败的诸政权曾经想要成为的东西。一个动词不能覆盖两者。
:::
:::

:::exercise 复辟不是被倒转的1789年 {level=2}
使用1814年的宪章与《民法典》的存续，解释为什么[[#def-restoration]]禁止“维也纳把法国放回1789年5月5日的那个早晨”这句话。不要发明那部宪章的任何条文。
:::solution
在1789年5月5日，法国以三个等级开幕了三级会议，以特权与可买卖的官职为中心，正如[[revolutions/old-regime]]所定义的。在1814年，路易十八有一部宪章与一个议会，而《法典》仍然是法律。那不是按等级投票，也不是1789年以来每一场改变的撤销。[[#prop-vienna]]允许诸精英回来，而仍然要求那个制度的检验。那个句子通不过它。它还搅混了文献：宪章是法国的、1814年的，最后法案是欧洲的、1815年6月9日的，而滑铁卢还要更晚。
:::
:::

:::exercise 邻居不是原因 {level=2}
1846年废除《谷物法》。1848年见到诸革命与《宣言》。一位学生说，那次废除引起了1848年，因为图形的那个为2年的窗口能够同时显示两者。那个推论有什么错，而那两个圆点更好的用法是什么？
:::solution
一个窗口显示的是一个邻域，不是一个原因。那次废除是一部关于谷物的不列颠制定法。1848年的诸革命大多在不列颠之外，而《宣言》是一份伦敦的小册子。不列颠在1848年不改变政权。更好的用法是种类的对照，那也正是[[#ex-statutes]]。1846年是不带街垒的变迁。1848年是许多座街垒与一组混合的结果。[[#thm-not-everywhere]]阻止你把第二个圆点称为一次失败。那条说明说1848年是若干场革命，不是一个结果。它没有说《谷物法》产生了它们。
:::
:::

:::exercise 修补那个全称动词 {level=3}
:::hint
把“革命政权大多数被击败了”保留为一句真实的子句。加上哈布斯堡的与瑞士的结果，并决定第二次法国废奴是否属于存续的那一边。不要把那一年称为一次成功，也不要引用《宣言》。
:::
把“1848年在所有地方都失败了”重写成一个读者能够对照[[#thm-not-everywhere]]检验的句子。然后说出，如果有人添上“而《宣言》是那一年真正的宪制”，那个句子会多造成什么损害。
:::solution
一个可检验的句子会说：在1848年，革命政权大多数被击败了，包括匈牙利、那个未能成为国家的法兰克福、诸意大利的事业与六月起义，而那一年仍然终结了哈布斯堡的农奴制，留下了一个瑞士的解决方案，没有恢复路易-菲利普，并且第二次废除了殖民地奴隶制。那些失败使它不成一个成功的故事。那些存续的结果使“在所有地方”不成。

添上《宣言》是真正的宪制，会造成进一步的损害。它用一份二月的伦敦小册子代替了诸政府与诸法律，这是[[#cor-manifesto]]所禁止的，并且它邀请一句我们不会发明的引文。修补后的句子不需要那本书。一个不同的句子可以说，一场论证在同一个月出现于伦敦。那个句子不可以把一个印刷品的产品变成一个国家。
:::
:::

:::exercise 什么会击败这条论断？ {level=3}
:::hint
[[#thm-not-everywhere]]已经说了哪些逆转会击败它，以及哪一个单独的逆转只会收窄它。把一个被击败的政府同一条被撤销的法律分开。波兰1830年的个案是一个有用的类比，不是1848年的替身。
:::
假设一位史家证明，哈布斯堡农奴制在短时间内就在法律上被恢复了，而瑞士解决方案与第二次法国废奴站稳了。你会放弃[[#thm-not-everywhere]]，还是收窄它？什么样的发现会使你放弃它？只把波兰1830年的起事当作一个已经复数的年份的类比。
:::solution
你会收窄这条论断，而不是放弃它。一个被逆转的结果仍然留下瑞士解决方案与第二次废奴，所以“在所有地方”仍然是假的。[[#thm-not-everywhere]]的论证已经说过，一个逆转收窄，全部击败。你会放弃它，如果农奴制回来，瑞士解决方案被撤销，路易-菲利普回来，而殖民地奴隶制在1848年之后被恢复，或者如果诸政权其实不曾大多数被击败。一个空的存续清单会使“在所有地方都失败了”变得公平。那不是记录。

波兰1830年的起事是一个类比，不是1848年的证据。一场起事失败了，而一个王朝改变了，一个比利时的国家开始了。[[#ex-1830]]已经禁掉了单个的动词。这条论断依据1848年的内容、而不只是依据这个比较，为1848年拒绝那个动词。
:::
:::
