1848年解决了什么，又只是尝试了什么？

一个年份可以震动许多首都，却仍然没有单一的结果。1848年，革命政权在欧洲各地兴起，其中大多数被击败了。哈布斯堡的农奴制被废除，而且这一废除延续了下来。同一年瑞士的宪制安排延续了下来。奥尔良王朝没有复辟。法国殖民地奴隶制第二次被废除，这次废除站住了。一个德意志议会召开了，却没有成为一个国家。二月在伦敦出版的一本小册子，也没有成为一个政府。说这一年失败了，就是保留了街垒而丢掉了法律；说它创建了作为国家的社会主义，就是保留了小册子而丢掉了实际执政的那些政府。

通向这一年的道路，经过一项并非倒退的和平安排，也经过二十年里不等1848年到来就已在变化的政治。维也纳《最后议定书》签署于1815年6月9日，早于6月18日的滑铁卢。复辟是一项事业。1830年，法国更换了王朝，比利时开始建国。1832年的不列颠《改革法案》扩大了选举权，但选举权依然狭窄。1846年，《谷物法》是由议会而不是由街垒废除的。这些都不是换了名称的“1848年”。正因为有它们，1848年才不能被讲成冰封大陆上的第一道裂缝，也不能被讲成变革的唯一形式。

## 先签署的和平安排

:::definition 复辟 {#def-restoration}
**复辟**是指拿破仑第一次退位之后，让国王们重新登位，并划定一张足以阻止法国帝国支配卷土重来的地图的那项事业。它不是回到1789年5月5日的旧制度，也不是在滑铁卢当晚写成的条约。这个名称听起来像是时间倒流，但其中的行为都是选择：哪个王朝，哪些边界，对过去的哪些旧账要兑现，哪些要置之不理。
:::

[[revolutions/napoleon]]确立了先后顺序，就此打住。会议自1814年起就在召开。1814年4月6日，拿破仑第一次退位。《最后议定书》签署于1815年6月9日；九天之后的6月18日是滑铁卢，6月22日是第二次退位。从那场战斗入手的读者，会错过签字这一环。对皇帝归来的恐惧，解释了六月为什么危险，却不能让战斗来起草这份文件。[[#def-restoration]]接下来要问：这项事业试图恢复的是什么。

不是1789年5月5日的那个早晨。1814年，法国得到了一部宪章：国王路易十八（Louis XVIII），一个议会，而不是按等级投票的三级会议。这里不引用宪章原文。《民法典》仍然是民法，法律上的等级也没有作为国家的骨架回来。这项事业希望王座与祭坛重返公共生活，并在荣誉上、在可能的地方也在财产上补偿*émigrés*（流亡贵族）。但希望并不能把一代人的财产买卖、法律与死亡倒转回去。复辟的波旁君主，是经历了一场革命与一个帝国之后的波旁君主，而不是三级会议召开前夜的路易十六。路易十六早在1793年1月21日就已被处死。

这张地图是大国的地图，而不是民族的地图。德意志邦联是一个松散的框架，而不是民族国家。尼德兰王国把北方各省与南方各省合在一起，而南方各省并不会长久留下。在1772年、1793年与1795年被抹去的波兰-立陶宛联邦，没有得到恢复；一个与俄国皇帝绑在一起的王国并不是独立。意大利依然是若干分立的国家，北部受奥地利影响，其他地方则由复位的君主统治。列强解决的是领土问题，以及禁止出现单一的法兰西帝国，而不是对每一种语言的公正。瓜分见[[states/east]]，后来的国家见[[nations/unifications]]，而这一安排并没有预先写定它们。

:::proposition 维也纳是一项事业，既不是附笔，也不是倒带 {#prop-vienna}
1815年6月9日的《最后议定书》，是列强选定的一项安排，在滑铁卢之前签署，目的是阻止拿破仑式的支配卷土重来，而不是重建1789年的三级会议。“复辟”指的就是这项事业，而不是成功撤销了民法中的每一项革命性变化。限度在于：一项事业可以是强制性的，却仍然是一项事业，而不是命运。后来的革命并没有“驳倒”这次签字，它们表明的是，签字并没有冻结政治。
:::
:::proof
证据是[[revolutions/napoleon]]中已经确定的先后顺序：先是6月9日，然后是6月18日。被确立的有：1814年宪章之下的波旁王朝、德意志邦联、统一的尼德兰、重新划定的意大利各邦，而没有完整的波兰-立陶宛联邦。没有被确立的有：三个等级、对《民法典》的废除、德意志人、意大利人或波兰人的民族国家。什么能推翻这一命题？一份日期晚于滑铁卢的《最后议定书》，或者一部像1789年5月5日那样恢复按等级投票、并在财产法面前废除了民事平等的1814年宪法。我们没有这样的文献。这一安排并不温和：边界是强加的；第二次复辟之后，报复行动既暴力又带有党派性，有时被称为“白色恐怖”。这个绰号不是1793年9月至1794年7月27日的恐怖统治。这里不给死亡人数，也不描述过程。一项事业与一场镇压可以同在一个季节。
:::

反对意见认为，《法典》与议会只是表面文章，旧精英回来了，所以“不是倒带”不过是法学家的自我安慰。精英们确实在可能的地方重新掌握了土地、教会与官职。我们并没有说复辟在社会层面与共和国相同。但授权的形式已不是1789年开幕那天早晨的形式。宪章与民法典不是三级会议。一位贵族在这些形式之内谋取影响，是在用旧名号玩新游戏。[[#prop-vienna]]可以容纳社会层面的复辟，同时仍然否定“旧日的早晨已经回来”这句话。只要三个等级与可以买卖官职的高等法院不构成宪制，旧制度就没有回来。

## 1830年与有限的改革

这项事业并没有静止不动。1830年7月，曾试图越过宪章进行统治的查理十世（Charles X）被推翻。奥尔良支系的路易-菲利普（Louis-Philippe）成为“法国人的国王”。这个头衔是一种主张，即他是一国人民的国王，而不是旧式的一片王国领土之王；它并不是一种社会描述。1830年更换了王朝，保留了君主制，既没有建立共和国，也没有让查理十世复位。七月王朝在1848年2月垮台，但那是后来的事实，而不是1830年时就已知道的规律。

同一年，尼德兰王国南部各省爆发了革命，比利时国家由此产生。本图谱没有锁定后来承认其独立的条约日期，这里也不编造。延续下来的是一个脱离了荷兰王室的政治体，而维也纳曾把这些省份置于荷兰王室之下。这张地图在这一安排存续期间就被修改了。这次修改不是1848年，也不意味着1815年的每一项条款都失败了。德意志邦联依然存在的同时，边界也可以移动。

1830年的起义并不都建立了国家。一场反抗俄国统治的波兰起义始于1830年，最终被镇压。它结束的年份没有锁定，所以这里不给出。波兰人没有在这个时期得到国家，[[nations/unifications]]仍将面对这一事实。1830年本身就已经是复数：法国更换王朝，比利时开始建国，波兰起义失败。用单数说“1830年革命”，就已经选择了巴黎。

:::example 一年中的三种结果 {#ex-1830}
请只用1830年，分别说出一个更换了王朝而没有终结君主制的结果、一个建立了国家的结果，以及一次被镇压的起义。为什么“1830年成功了”与“1848年失败了”错在同一个地方？
:::solution
七月革命以路易-菲利普取代了查理十世，并保留了君主制。比利时革命从维也纳曾划归荷兰王室的那些省份中开创了一个国家。1830年的波兰起义被镇压，没有建立国家。“1830年成功了”之所以不成立，是因为波兰是一次失败，也因为法国的结果是更换王朝，而不是一种不必说明对谁而言就能称之为成功的东西。“1848年失败了”不成立，理由与此恰好相反。一个只配上“成功”或“失败”一个动词的年份标签，已经丢掉了复数。图表上印着“七月与比利时”，却没有提到波兰。图表在压缩，本课不应照搬。
:::
:::

:::example 两部不列颠法规 {#ex-statutes}
《改革法案》在1832年，《谷物法》在1846年被废除。两个年份相差多少？为什么这两部法规都不是1848年那种革命？
:::solution
1846减1832等于14。两者都是一个并未垮台的议会制定的法规。一部扩大了选举权，但选举权依然狭窄，并且把女性排除在外；另一部废除了对谷物的保护，本章不给出任何关税数字。这一对照正是本章问题所需要的：维也纳与1848年之间的变化，并不等于街垒。十四年间的法规，也不是1848年2月的剧本。
:::
:::

不列颠没有经历那样的七月。1832年，《改革法案》重新分配了议席，并在财产资格之内扩大了选举权。成年男子作为一个整体没有获得选举权，女性也没有。这部法案是一个存续下来的议会所制定的法规，属于1689年《权利法案》与1694年英格兰银行所在的那个世界，而不是巴黎式的王朝更替。后来1867年与1884年的《改革法案》仍然把女性排除在外，它们属于[[nations/mass-politics]]。提到它们，是为了提防“1832年完成了民主”的说法。年表没有锁定任何百分比，这里也不给出。[[#ex-statutes]]把这部法规与1846年的废除放在一起。

1846年，议会废除了《谷物法》，即对谷物征收的保护性关税。罗伯特·皮尔（Robert Peel）政府在制造商以及希望面包更便宜的人们的压力下推动了这次废除。这十年也是爱尔兰饥荒的十年。[[nations/industry]]比较了1841年与1851年，但不给出死亡总数。本章既不编造这个总数，也不编造本图谱没有锁定的起始年份。这次废除是一部法规，而不是一场革命。在其他首都即将筑起街垒的时代，一个议会无需街垒就能取消一项重大的保护政策。这次废除本身并没有让爱尔兰吃饱，但它表明，维也纳与1848年之间的变化并不等于革命。

1833年不列颠废除帝国大部分地区奴隶制的法令，附有持续到1838年的学徒制，体现的是同样的对照，并在[[states/atlantic]]中作为法律讲授。它不是1848年，也不是某种文明的道德寓意。一部受学徒制限制的自由劳动法，是另一种工具。这里不描述种植园劳动，也不统计人数。

:::quiz
关于1832年的不列颠《改革法案》，哪一项是正确的？
- [ ] 它把投票权给了所有成年人，完成了民主
- [ ] 它是仿照1792年法兰西共和国建立的共和国
- [x] 它扩大了选举权，但选举权依然狭窄，也不包括女性
- [ ] 它废除了《谷物法》，而这其实发生在1846年
:::solution
1832年的法案重新分配了部分议席，在财产资格之内扩大了选民范围。它没有给女性选举权，也没有给成年男子本身选举权。《谷物法》在1846年被废除，那是另一部法规。1792年9月21日至22日的法兰西共和国，是另一个国家、另一种事件。狭窄是年表所锁定的事实，也正是“民主的胜利”这种故事无法利用的事实。
:::
:::

## 许多场革命

1848年2月，巴黎的一场革命揭开了这一年的序幕。路易-菲利普倒台，共和国宣告成立。宽泛的选举权把成年男子纳入了政治，女性却没有。作为社会应急措施的国家工场开办了，随后又被关闭。六月，共和国与巴黎工人的起义交战，并镇压了这次起义。这里不给出死亡人数。到年底，路易-拿破仑·波拿巴（Louis-Napoleon Bonaparte）当选为总统。春天的社会共和国并没有统治到冬天，七月王朝也没有复辟。十二月的法国不是一月的法国，也不是六月起义者想要的那个共和国。

同一年，法国殖民地再次废除了奴隶制。第一次废奴是在1794年2月4日，殖民地奴隶制的恢复是在1802年。1848年的第二次废奴站住了。它是这个革命之年的一项法律成果，并不取决于六月起义的成败，也没有使第二共和国成为一个持久的政体。[[states/atlantic]]把这三个日期放在更长的大西洋序列中，与1807年不列颠禁止奴隶贸易的法令以及1833年的法令并列。在这里，要点只关乎本章的问题：废奴比通过它的革命政府存在得更久。一个年份可以在其政权被击败的同时解决某些问题，这就是方式之一。

:::theorem 1848年没有在所有地方失败 {#thm-not-everywhere}
1848年的革命政权大多被击败了，但这一年并非处处失败。哈布斯堡帝国的农奴制在1848年被废除，而且废除延续了下来。1848年瑞士的宪制安排延续了下来。其他结果，包括奥尔良王朝的终结与法国对殖民地奴隶制的第二次废除，也比街垒存在得更久。限度在于：延续下来的法律，并不等于获胜的革命政府。两句话都是真的，后一句并不抵消前一句。
:::
:::proof
证据在于政权与法律的分化。维也纳、匈牙利、波希米亚与意大利各省的革命，震撼了哈布斯堡君主国。匈牙利革命政府被击败，镇压它时动用了俄国军队。这里不为那场战役单独锁定年份，也不给出伤亡数字。革命者所要的那种独立匈牙利的事业没有延续下来，农奴制的废除却延续了下来。在这个帝国中，法律上的不自由于1848年终结，而且在将军们获胜之后也没有恢复。1848年瑞士的联邦安排延续了下来。意大利的革命与对奥地利的战争，并没有造就统一的意大利，那是后来的创造，见[[nations/unifications]]。法兰克福议会召开了，却没有成为一个国家。巴黎的二月共和国镇压了六月起义。被击败的政权名单很长，但延续下来的变化名单并不是空的。“处处失败”需要一份空名单。

什么能推翻这一定理？哈布斯堡农奴制的恢复、瑞士安排的迅速瓦解、路易-菲利普的复辟，以及1848年在法国殖民地获得自由的人重新沦为奴隶。其中一项逆转会收窄这一定理，全部发生则会推翻它。“大多数革命政府失败了”这句真话，已经包含在定理之中。错误在于让这句话冒充整个年份。
:::

反对意见认为，那些延续下来的成果是由获胜的政府授予的，所以不算革命性的。一部法律可以在革命压力下诞生，再由随后镇压革命者的当局加以确认。谁是作者与能否延续，是两个不同的问题。哈布斯堡的农奴制，正是在击败了匈牙利政府的那个帝国里终结的。史家对于应当强调哪一道法令有争论，但你不能得出结论说，街垒倒下之后，农民的法律处境毫无改变。瑞士的安排是这一年自身的宪制成果，而且延续了下来。一个无视瑞士和农民的反对意见，是挑选过例子的。

法兰克福是最明显的一次未能达成解决的尝试。一个德意志议会讨论了宪法，在不含奥地利的小德意志与包含哈布斯堡领地的大德意志之间争论，却没有成为一个国家。拒绝皇冠的日期没有锁定，这里不予定年。没有建成国家这一点就足够了。1871年宣告成立的帝国是另一项事业，见[[nations/unifications]]，而不是这个议会的延期。1848年失败的意大利人，并没有因此被安排好在1861年胜利。后来的成功属于另一章。

不列颠的1848年是一场没有变成政权的动员。宪章派请愿要求更广泛的民主，政府却依然在位。这里不给出人群规模。同一年，在饥荒的十年之中，一场爱尔兰起义被镇压，同样不给出死亡人数。一个既包括不列颠的“非革命”、又包括爱尔兰的失败的年份，并不是某种由西向东滚动的单一机制。1846年的废除并没有引发巴黎的革命，它让这些种类保持了区分。

:::example 只朝一个方向出错的句子 {#ex-fail}
下面这句话为示例而虚构。它不是史料。它既不是编年史，也不是法律。“1848年处处失败，所以到下一个季节，这一年什么都没有留下。”这句话抹去了哪些已锁定的结果？你可以加上哪一个真实的分句，而又不把这一年变成一个成功故事？
:::solution
这句话抹去了哈布斯堡农奴制的废除、1848年瑞士的宪制安排、法国对殖民地奴隶制的第二次废除，以及路易-菲利普没有复辟这一事实。[[#thm-not-everywhere]]就是修正。你可以加上的真实分句是：大多数革命政权被击败了，包括匈牙利政府、意大利的各项事业、六月起义，以及想要成为国家的法兰克福议会。这个分句保留了失败，又没有恢复“处处”。一个全称动词，遇上的是一个由多种结果构成的年份。修正的办法是列出清单。
:::
:::

## 文献不是政府

:::corollary 《宣言》不是国家 {#cor-manifesto}
由卡尔·马克思（Karl Marx）与弗里德里希·恩格斯（Friedrich Engels）撰写、1848年2月在伦敦出版的《共产党宣言》（Communist Manifesto），是那个月的一份文献。它不是巴黎、维也纳、法兰克福或任何其他地方的政府，1848年也不是作为国家的社会主义的诞生。这里不引用这本书，也不叙述作者的生平。
:::
:::proof
伦敦的一本小册子可以为革命进行论证，但论证不是执政。巴黎在二月推翻了一位国王，后来的执政者并不是这本书的作者，执政的也不是这个纲领。法兰克福是一个自由主义的、民族主义的议会，而不是这份文本。六月并没有把这本小册子确立为宪法。1848年没有哪个国家是由《宣言》建立的社会主义国家。如果某个内阁把这本小册子采纳为宪法并据此统治，这一推论就不成立。在本课程所依据的记录中，没有任何内阁这样做过。作为一份有日期的文献，这本书仍然重要。但重要不等于统治。作为国家的社会主义，是后来才有的主张。
:::

细致到足以成为引文的转述，就是引文，所以这里不重构其论证。两位作者在巴黎起义的那个月，于伦敦出版了一份纲领，而这份纲领并不是随后的政府。社会主义的言论比这本小册子更早，我们不为这些词语锁定一个诞辰。“1848年开启了社会主义”的神话，是从这本书滑向一个国家。[[#cor-manifesto]]阻止了这种滑动。本章不会转述它没有得到的句子，也不会讲述生平。印刷品可以完成一个论证，却不能完成一部宪法。

:::example 同月出版 {#ex-february}
揭开1848年序幕的巴黎革命在二月，《共产党宣言》于1848年2月在伦敦出版。从同在一个月这一点上，你可以推出什么？[[#cor-manifesto]]又禁止你推出什么？
:::solution
你可以推出：一次革命爆发与一份社会主义纲领是同时代的。但同时代既不是因果，也不是同一。你不能推出《宣言》引发了巴黎革命，不能推出巴黎实施了它，也不能推出它的作者执掌了政权。你不能引用它，也不能用作者生平来填补空白。同在一个月所带来的诱惑，与1792年9月瓦尔密战役和共和国之间相差一天所带来的诱惑一样：短暂的间隔会引出“创造了”这个动词，而这个动词仍然是错的。严谨的句子会说：1848年2月，一个政权在巴黎倒台，一本小册子在伦敦问世。[[#thm-not-everywhere]]说明了哪些结果延续了下来。这本小册子是论证层面的一次尝试，而不是那些安排之一。
:::
:::

:::quiz
哪一种说法符合1848年？
- [ ] 这一年处处失败，包括哈布斯堡帝国农民的法律处境
- [ ] 《共产党宣言》成了法国与德意志议会的宪法
- [x] 大多数革命政权被击败了，而一些结果延续了下来，包括哈布斯堡农奴制的终结与瑞士的宪制安排
- [ ] 维也纳《最后议定书》是在滑铁卢之后签署的，目的是回应1848年的革命
:::solution
[[#thm-not-everywhere]]把失败与延续下来的结果放在同一个论断之中。《宣言》是二月在伦敦出版的读物，而不是宪法，这就是[[#cor-manifesto]]。《最后议定书》在1815年6月9日，早于滑铁卢，也比1848年早了几十年。每个错误选项，分别压缩了一个复数的年份、一份文献或一个年表。
:::
:::

1815年的点无法说明哪一件在先，但你可以：先是6月9日，然后是6月18日。1830年的点把七月革命与比利时连在一起，却漏掉了波兰的失败，所以才有[[#ex-1830]]。1832年与1846年是不列颠的法规，而不是革命，这就是[[#ex-statutes]]。最后一个点是许多场革命加一份宣言。2年的窗口显示的是相邻的年份，而相邻不等于原因。谷物关税的废除不能解释法兰克福，法兰克福也不能解释这次废除。

:::warning 把这一年当作单一的失败
人们常说1848年失败了，有时还说一份宣言吓坏了体面人，或者说它才是这一年真正的宪法。[[#thm-not-everywhere]]回应了第一种习惯：大多数政权被击败了，但这一年仍然终结了哈布斯堡的农奴制，留下了瑞士的宪制安排，终结了奥尔良王朝，并第二次废除了法国殖民地奴隶制。[[#cor-manifesto]]回应了第二种：二月在伦敦出版的一本书不是国家。“彻底失败”的说法，对后来某个想让民族国家显得才是真正结果的故事很有用。但有用并不是关于这一年的证据。
:::

:::history
1848年2月，巴黎的一场革命揭开了一个革命之年，革命遍及许多城市。同月，卡尔·马克思与弗里德里希·恩格斯合著的《共产党宣言》在伦敦问世；它是一份文献，而不是一个政府。一些结果比街垒的失败延续得更久，哈布斯堡帝国农奴制的终结就是其中之一。
:::

## 通向何处

1848年尝试建立而未能建成的德意志国家与意大利国家，以及仍然没有得到国家的波兰人和其他民族，见[[nations/unifications]]。后来的不列颠改革法案，以及1832年留下的狭窄选举权，见[[nations/mass-politics]]。人口普查数字，包括1841年与1851年的爱尔兰，见[[nations/industry]]；那里同样拒绝给出本章也拒绝给出的饥荒死亡总数。本章所假定的维也纳与滑铁卢的先后顺序，论证见[[revolutions/napoleon]]。复辟没有恢复的旧制度，见[[revolutions/old-regime]]。

:::summary
- 复辟是1814年与1815年的一项事业，既不是倒带回1789年5月5日，也不是滑铁卢之后写成的文本。《最后议定书》签署于1815年6月9日，早于6月18日的战斗。
- 这一安排构建了一张大国地图：受宪章约束的波旁君主国、德意志邦联、尼德兰王国，没有恢复的波兰联邦。《民法典》并没有作为国王复位的代价而被废除。
- 1830年，法国更换了王朝，比利时开始建国，1830年的一场波兰起义被镇压。这一年本身就已是复数。
- 1832年的《改革法案》扩大了狭窄的选举权，但不包括女性。《谷物法》在1846年通过立法被废除。两者都不是1848年那种革命。
- 1848年是许多场革命。大多数革命政权被击败了，但这一年并非处处失败：哈布斯堡的农奴制终结了，瑞士的宪制安排延续了下来，奥尔良国王没有复位，法国殖民地奴隶制再次被废除。
- 法兰克福议会召开了，却没有建立德意志国家。意大利的统一没有在这一年实现。匈牙利革命政府被击败。
- 《共产党宣言》于1848年2月在伦敦出版。这里不引用它，不讲述作者生平，它也不是作为国家的社会主义的诞生。
:::

## 习题

:::exercise 六月的哪一天？ {level=1 check="9"}
维也纳会议《最后议定书》签署于1815年6月的哪一天？（请输入日期。）
:::solution
《最后议定书》在1815年6月9日，滑铁卢在6月18日。签字的日期是9日。
:::
:::

:::exercise 有限的改革 {level=1 check="1832"}
扩大了选举权、却仍使其保持狭窄的不列颠《改革法案》是在哪一年？（请输入年份。）
:::solution
这部法案在1832年。不是废除《谷物法》的1846年，也不是1848年。
:::
:::

:::exercise 从《最后议定书》到革命之年 {level=1 check="33"}
《最后议定书》在1815年，本章作为一个欧洲整体讨论的那些革命在1848年。两个年份相差多少？（请输入年数。）
:::solution
1848减1815等于33，相差33年。这与[[revolutions/old-regime]]中从1756年到1789年的算术间隔相同，却不是同一段历史。间隔相等不等于原因相等。这个数字只是防止你把维也纳与1848年当作相邻的两种情绪。
:::
:::

:::exercise 一个延续的结果，一次失败 {level=2}
请说出1848年一个延续下来的结果，以及1848年一项被击败的革命事业。把两者都定年到这一年，并说明为什么这一对就是“这一年解决了什么？”的答案。
:::solution
延续下来的结果，可以是1848年哈布斯堡农奴制的废除，或者这一年瑞士的宪制安排。被击败的事业，可以是法兰克福建立德意志国家的尝试，或者匈牙利政府，或者六月起义，或者意大利统一。[[#thm-not-everywhere]]把这一年界定为一个集合。“解决”的，是留在法律中的东西；“尝试”的，是那些被击败的政权曾想成为的东西。一个动词无法同时涵盖两者。
:::
:::

:::exercise 复辟不是倒转的1789年 {level=2}
请运用1814年的宪章与《民法典》的延续，说明为什么[[#def-restoration]]不允许说“维也纳把法国带回了1789年5月5日的早晨”。不要编造宪章的条文。
:::solution
正如[[revolutions/old-regime]]所界定的，1789年5月5日，法国以三个等级的形式召开三级会议，其核心是特权与可买卖的官职。1814年，路易十八有宪章与议会，《法典》也依然有效。这不是按等级投票，也不是撤销1789年以来的每一项变化。[[#prop-vienna]]允许精英回归，但仍然要求接受制度上的检验，而这句话通不过检验。它还混淆了文献：宪章是法国的、1814年的；《最后议定书》是欧洲的、1815年6月9日的；滑铁卢则更晚。
:::
:::

:::exercise 相邻不是原因 {level=2}
1846年废除了《谷物法》，1848年发生了革命并出版了《宣言》。一位学生说，因为图表上2年的窗口能同时显示两者，所以废除导致了1848年。这一推论错在哪里？对这两个点更好的用法是什么？
:::solution
窗口显示的是相邻的年份，而不是原因。这次废除是一部关于谷物的不列颠法规；1848年的革命大多发生在不列颠以外，《宣言》则是伦敦的一本小册子。不列颠在1848年并没有更换政体。更好的用法是对比种类，这也就是[[#ex-statutes]]：1846年是没有街垒的变化，1848年是许多街垒和一组混合的结果。[[#thm-not-everywhere]]防止你把第二个点称为失败。说明文字说1848年是许多场革命，而不是一个结果；它并没有说是《谷物法》引发了这些革命。
:::
:::

:::exercise 修正全称动词 {level=3}
:::hint
把“大多数革命政权被击败了”保留为一个真实的分句。加上哈布斯堡与瑞士的结果，并判断法国的第二次废奴是否属于延续的一方。不要把这一年称为成功，也不要引用《宣言》。
:::
请把“1848年处处失败”改写成读者可以对照[[#thm-not-everywhere]]加以检验的句子。然后说明，如果有人再加上“而《宣言》才是这一年真正的宪法”，这句话会造成什么额外的损害。
:::solution
一个可以检验的句子会说：1848年，大多数革命政权被击败了，包括匈牙利、想要成为国家的法兰克福议会、意大利的各项事业与六月起义；但这一年仍然终结了哈布斯堡的农奴制，留下了瑞士的宪制安排，没有让路易-菲利普复位，并第二次废除了殖民地奴隶制。那些失败使它不成其为成功故事，那些延续的结果则使“处处”不能成立。

再加上“《宣言》才是真正的宪法”，会造成更多的损害。它用二月伦敦的一本小册子取代了政府与法律，而这是[[#cor-manifesto]]所禁止的；它还会引出一句我们不会编造的引文。修正后的句子并不需要这本书。另一个句子可以说，同一个月在伦敦出现了一种论证，但这个句子不能把印刷品变成国家。
:::
:::

:::exercise 什么能推翻这一定理？ {level=3}
:::hint
[[#thm-not-everywhere]]已经说明了哪些逆转会推翻它，哪一项单独的逆转只会收窄它。请把被击败的政府与被撤销的法律区分开来。1830年的波兰个案是一个有用的比较，但不能替代1848年。
:::
假设一位史家证明，哈布斯堡农奴制在短时间内就在法律上恢复了，而瑞士的安排与法国的第二次废奴依然有效。你会放弃[[#thm-not-everywhere]]，还是收窄它？什么样的发现会使你放弃它？请只把1830年的波兰起义当作“一年本身就是复数”的类比。
:::solution
你会收窄这一定理，而不是放弃它。一个结果被逆转了，仍然留下瑞士的安排与第二次废奴，所以“处处”依然不成立。[[#thm-not-everywhere]]的论证已经说过，一项逆转只会收窄它，全部逆转才会推翻它。如果农奴制恢复、瑞士的安排被撤销、路易-菲利普复位、殖民地奴隶制在1848年之后又被恢复，或者大多数政权其实并没有被击败，你才会放弃它。只有延续清单空空如也，“处处失败”才说得过去。但记录并非如此。

1830年的波兰起义是一个类比，而不是1848年的证据：一场起义失败了，与此同时一个王朝更替了，一个比利时国家开始了。[[#ex-1830]]已经排除了单一动词。这一定理拒绝为1848年使用那个动词，依据的是1848年本身的内容，而不只是这个比较。
:::
:::
