在民主制的雅典，谁是公民，谁不是？

这个问题是本章的核心，而不是在颂扬之后补上的一句歉意。雅典民主制是一套真实的制度，而且范围狭窄。克里斯提尼（Cleisthenes）的改革通常定于公元前508/507年，我们采用公元前508年。伯里克利（Pericles）的公民权法通常定于公元前451/450年，我们采用公元前451年。这项法律颁布之后，参加投票、审判和担任抽签公职的，是父母双方都是公民的成年男子；妇女、奴隶和外侨（metic）都不在此列。公民大会、议事会、法庭和抽签的运用都是真实的，但它们不是成文宪法，不是现代议会，也不是西方自由的诞生。本章不给出阿提卡（Attica）的人口数字：年表没有提供这一数字，而法庭演说也不是人口普查。

## 这些制度是什么

:::definition 雅典民主制 {#def-democracy}
**雅典民主制**是雅典成年男性公民通过集会进行的统治，其方式包括群众大会、议事会、大型法庭，以及主要以抽签产生的公职。与克里斯提尼相联系的形态，通常定于公元前508/507年；按出身加以收紧的形态，则以通常定于公元前451/450年的公民权法为标志。它不是一份奠定现代国家的文件，也不是对所有居住在阿提卡之人的称呼。
:::

这些改革发生在庇西特拉图家族（Peisistratid）的僭主统治之后，也发生在一场有斯巴达插手的显贵家族之争之后。我们不给僭主倒台定年，因为年表中没有这个年份。按照通常的定年，公元前508年标志着公民团体的重新组织。地方区划即德莫（deme），成为确认一个人公民身份的单位。新设的部落打破了沿海、内陆和城区的旧有地域派系，使依托某一地区的势力更难聚集。从这些部落中抽签产生的议事会，为公民大会准备议程。陶片放逐法——以陶片投票，将某人放逐若干固定年限——也属于同一个政治世界：这是一种无须刑事审判就能除掉有权势公民的手段。我们不计算所需的票数。这种手段的意义在于，它是男性公民彼此之间握有的一种权力。

公元前508年之后的几十年里，较早的议事机构战神山议事会（Areopagus）的权力逐渐让位于公民大会和法庭。这一转变的某些环节有确切年份，但本年表没有列出，所以这里一概不给。方向已经足够说明问题：民主制更加充分地成为到场者及从他们中间抽选的陪审团的统治。这一发展并不是从公元前594年梭伦的传统执政官任期延伸而来的一条直线——[[greece/poleis]]已经拒绝把那个年份当作民族政制。从公元前594年到公元前508年是一段漫长的间隔，其间有一段僭主统治；从公元前508年到公元前451年是另一段间隔，隔开的是另一项法律。

公民大会就是当天到场的男性公民。他们以多数作出决定。他们不是被派来替家庭、妇女或外侨发言的代表；待在家里的人没有代理人。普通男性公民只要到场，他在一项动议上的一票就与富人的一票相等。阿提卡的大多数居民不在会场之中。

大多数公职以抽签产生，任期很短，卸任时须接受审查。在公民团体内部，统治并不专属于专家或某些家族。将军由选举产生并可连任，因为城邦想自己挑选领兵出征的人；选举是例外。公职津贴和出席津贴使较贫穷的男性公民也能任职。我们不给出具体金额。津贴补偿的是已在团体之内的人，与被法律挡在门外的人无关。

雅典有法律，其中许多刻在石碑上。也有程序可以控告某位发言者提出了违法的议案。这是民主制内部的一种制约，但它不是依据唯一一份建国文献进行裁决的最高法院，而这些法律也不是现代意义上的成文宪法。公民大会的决议就是城邦的政治行为。一块石碑是证据，而不是一部等待后世议会照抄的宪法。

:::theorem 这些制度不是现代议会，也不是西方自由的诞生 {#thm-not-parliament}
公民大会、议事会、法庭和抽签构成了一种真实的成年男性公民的民主制，却没有构成代议制议会、成文宪法或西方自由的起源。这条论断两次自我限定：这些制度不是迷思；而后世给予它们的现代赞誉，也不是对公元前508年或公元前451年的描述。
:::
:::proof
证据就是这些制度本身，即亚里士多德（Aristotle）名下的《雅典政制》（*Constitution of the Athenians*）、存世的法令和法庭实践所能让我们重构的样子。亲自到场、抽签、短任期和大型陪审团，与在一部更高的宪法文本之下立法的民选代表议院，是两套截然不同的机制。后来的欧洲人仰慕雅典，却是通过别的途径建立起议会的。仰慕是关于那些欧洲人的事实，并不能把他们的制度挪回公元前5世纪。

“西方自由”之说站不住脚，还有另一个原因。“西方”是一种现代的地理—道德概念，正是[[sources/naming-europe]]拒绝视为古代行动者的那一类。在希波战争的口号中，自由意味着不受波斯国王统治；在雅典内部，它意味着一个限定的男性群体的政治生活，而这种生活依托于对其他城邦的帝国统治，[[greece/persian-wars]]对此有所描述。这个说法偷换了话题。

能够推翻这条论断的，是一份当时的文本，表明雅典的公职由全体成年居民——包括妇女和外侨——的代表担任，并且有一份这些居民可以援引来对抗公民大会的统一宪法文件。法令、陪审津贴和抽签，不会因为令人印象深刻就变成这样的文本。能够推翻这一民主制之真实性的，则是表明公民大会和法庭实际上并不作决定的证据。精英的影响是真实的，但这并不等于这些制度不存在。
:::

## 公元前451年的法律

:::definition 公元前451年之后的参与者 {#def-citizen}
在通常定于公元前451/450年的公民权法之后，雅典民主制的**参与者**是父母双方都是公民的成年男子。这是一条关于出身和性别的规则，而不是人数统计。公民家庭的妇女可能为这条规则所必需——因为儿子的身份取决于母亲——却依然没有投票权。奴隶和外侨，无论是否成年、是否为男性，都在参与团体之外。
:::

按照通常的说法，在这项法律之前，主要的出身标准是父亲为雅典人，与其他城邦的女子通婚也是可能的。这项法律把标准收紧为父母双方都是公民。关于其动机，历史学家看法不一：是这类婚姻，是一座帝国城市的特权，还是伯里克利政治生涯中的某个时刻？效果比动机清楚，而图示显示的正是效果。我们不杜撰某个单一的私人理由，再把它说成就是这项法律。

**外侨**（metic）是自由的外来居民，常常来自其他希腊城邦。他们在雅典登记，须缴纳一种我们不标价的税，通常还需要一位公民担保人。外侨可以很富有，他们从事商业和手工业；按照通常的说法，他们也在战时服役。但他们不能以外侨身份出席公民大会。授予某位具名外邦人公民身份需要一项法令，而这恰恰确认了边界：如果这种身份平常可得，城邦就不必专门授予。奴隶不是外侨。奴隶在法律上是财产，他们在家户、农庄、作坊和阿提卡的银矿中劳作。我们不描述这种劳作，也不给出他们的数字。即便获得自由，也不等于获得公民身份；被释放的人并不因此成为父母双方都是公民的男子。

公民家庭的妇女是最棘手的情形，也是颂扬式叙事最想用一条注脚打发的地方。她们并没有被挡在一切公共活动之外：女祭司担任宗教职务，节庆需要男性公民的女儿和妻子参加。公元前451年之后，母亲是公民成为儿子是公民的条件。这是关于她的身体和出身的政治事实，却没有给她投票权、抽签公职或陪审员席位。有些历史学家把“公民”一词保留给这种出身身份，再补充说政治权利属于男性。这套词汇是一场真实的争论，但它并不能把她移入图中的阴影区域。本课用“参与者”指称那些政治行为，用[[#def-citizen]]指称那条规则。宗教职务是公共的，但它不是民主制。

这项法律深入到家户之中，因此并非一项无关紧要的选举技术细节。法庭演说一再追究某人的母亲是不是雅典人。这一文体是控告，而不是能从中读出阿提卡人口的登记簿。在数字上的沉默，并不是在规则上的沉默：规则写在法律里，数字则不在我们的年表里。

按顺序读这三个标签：成年、父母都是公民、男性，三者俱备才能参与，缺一不可。公民妇女成年，父母都是公民，但她不是男性，所以在阴影之外。男性外侨成年且为男性，却缺少公民父母；一名男奴可能与他同处那个没有阴影的角落。这幅图无法区分这两个人，因为两人在规则的同一项条件上不合格。这一局限恰恰是优点：这幅图从来不是一份身份普查。公民父母所生的子女，在登记之前不符合“成年”。我们不把成年年龄杜撰为一个数字。在德莫登记是城邦自己设立的门槛，而这道门槛是为儿子设的。

:::example 五十七年的变化 {#ex-span}
克里斯提尼的改革通常定于公元前508年，公民权法通常定于公元前451年。两者相隔多少年？这段间隔禁止你对“那个”雅典公民作出什么样的表述？
:::solution
两个年代都在公元前，所以直接相减：508减451等于57。核对：451加57等于508。508/507和451/450这样的双重年份，是古代年份常见的写法，我们仍按本年表的做法采用508和451。这段间隔排除了任何单一的诞生日。公元前451年之后的参与者必须满足一条出身规则，而这条规则与公元前508年的部落改革并不相同。五十七年，足以让僭主统治的余波演变成一个帝国城市的民主制，也足以让城邦决定：守护特权的是父母双方，而不是一方。
:::
:::

:::example 三个虚构的人物 {#ex-three}
以下三个人物为示例而虚构，不是人口普查。第一，公元前451年之后的一名成年男子，已在德莫登记，父亲和母亲都是雅典人。第二，他的成年姐妹，父母相同。第三，一名在雅典居住多年、城邦征召时就去服役的成年外侨。谁在图中的阴影交集之内？谁又在哪个圆之外？
:::solution
只有第一个人在交集之内：成年，父母都是公民，男性。他的姐妹成年，父母都是公民，却不符合标为“男性”的那项条件。她的身份对法律很重要，因为她的儿子可以通过她获得参与资格，但她本人仍然不能参与。外侨成年且为男性，却不符合“公民双亲”。服役并不能使他越过这道边界。如果后来有一项法令授予他公民身份，那也是他尚未加入的那个团体所给予的例外。这三个人物都不是人口统计，这次归类只是对[[#def-citizen]]的一种解读。
:::
:::

:::example 并列的两项法律 {#ex-pair}
把公元前508年与公元前451年并列。前一个年代与德莫、部落和抽签产生的议事会相联系，后一个则是一项关于出身的公民权法。它们是同一次改革吗？其中任何一个是西方自由的奠基吗？
:::solution
它们是雅典的两次改革，相隔57年，回答的是不同的问题。按通常定年，克里斯提尼改组了已有的公民团体，使地域和家族势力不那么容易发挥作用；伯里克利则决定了下一代谁可以进入这个团体。把两者当作同一次奠基，就是把部落改革和出身标准混为一谈；把其中任何一个当作西方自由的诞生，则是添上了一幅现代地图和一套石碑上并不存在的权利话语。两个年代并列，显示的是一个会修改自身边界的民主制。一个能够收紧自身边界的民主制，不是一种超越时间的理念，而是一座城市在运用它的公民大会。
:::
:::

## 排斥就是设计

先讲公民大会，再把排斥当作憾事补在后面，这样讲很诱人。但这种顺序正是“荣耀加注脚”的迷思。公元前451年的法律关乎的恰恰是公民大会由谁组成。帝国使这个问题更尖锐，而不是更温和。[[greece/persian-wars]]中描述的盟邦贡赋，支撑着这座城市的政治津贴和公共建筑。谁来分享一座如此富有的城市，是一场政治斗争，收紧出身规则正是男性公民进行这场斗争的方式之一。你可以欣赏抽签制度，同时看到：抽签从未向缴税的外侨开放，从未向儿子身份受法律审查的那位妇女开放，也从未向银矿中的奴隶劳工开放。如果欣赏需要把这些人模糊掉才能成立，那么所欣赏的就不是这座城市，而是另一座城市。

法庭是同一设计的组成部分。由男性公民组成的大型陪审团审理的案件，可以毁掉一个政治人物，也可以处死一名被告。公元前399年，这些法庭将判处苏格拉底（Socrates）有罪。[[greece/peloponnesian-war]]把这场审判当作战败之后雅典的一个事件来处理，而不是当作希腊思想的意义所在。它在本章中只作为一种限度出现：一个男性公民的民主制可以毁掉它自己的一员。这一事实并不能概括这一制度，也不能把这一制度扩大到那些不能坐上陪审席的人。

:::theorem 排斥构成了公民团体本身，而不是注脚 {#thm-exclusion}
公元前451年之后，妇女、奴隶和外侨被排除在参与之外，这是由公民团体的界定方式决定的，而不是一个本应普遍的民主制旁边的偶然现象。去掉这些排斥，你所描述的就是一座法律并未描述的城市。
:::
:::proof
法律本身就是证据：父母双方都须是公民；公民大会、议事会、陪审团和抽签公职都由男子担任的政治实践。以授予公民身份来表彰某个外邦人的法令，从另一侧显示了同一条边界。妇女担任的宗教职务，显示的是一种系统性地止步于投票权之前的公共角色。奴隶制是合法而寻常的，存在于家户之中，也存在于白银产业之中，这意味着公民政治的闲暇和财源建立在不自由的劳动之上。这一切都不是仅凭沉默作出的推论。史料沉默的地方，沉默的是数字和被排斥者的言语，而不是规则。[[sources/evidence]]指出，沉默不是某人没有头脑的证据，而是关于询问了谁的证据。被排斥的人有头脑，只是没有这种参政权。

能够推翻这条论断的，是一项法令或一份可信的叙述，表明公元前451年之后，妇女作为一个群体、外侨作为一个群体或奴隶，曾出席公民大会或担任陪审员。一位女祭司不算，舰队中的一名外侨不算，授予某一具名男子的公民身份也不算一个群体。如果出现了这种以群体为单位的接纳，[[#def-citizen]]就必须改写。但它没有出现。能够推翻这条论断的一个粗糙版本——即妇女在社会上完全不可见——的，是宗教方面的记录。我们并不提出这种粗糙的主张。被排除在民主制之外，与在祭祀中现身，两者都是真的。
:::

:::example 一次虚构的奠基 {#ex-invented}
下面这句话是虚构的，不是史料。“公元前508年，雅典把权力交给阿提卡的人民，从而发明了西方自由。”其中有什么年代用对了？又添加了什么？
:::solution
公元前508年是我们为克里斯提尼改革所采用的通常年代，常写作508/507年，这是这句话与年表相合的部分。“发明了西方自由”添加了一种现代地理观和一种现代道德观。“阿提卡的人民”则把那些不是参与者的居民也加了进来：妇女、外侨、奴隶，以及公元前451年之后任何不符合双亲规则的人。即便在公元前508年，新部落组织的也是公民，而不是全体居民。这句话保留了一个真实的年份，却用一个后来的理念替换了公民团体。修补后的说法是：公元前508年，雅典男性公民被重新组织成一个民主制，这个民主制后来在公元前451年以父母双方都是公民来界定他们。
:::
:::

## 反驳与实例

来自词汇的反驳需要认真对待。如果雅典的希腊语可以把父母都是公民的女子称为城邦的一员，那么一幅标着“男性”的图示，看起来就像是把一种现代的贬低倒投到过去。回答在于行为，而不在于拒绝听这个词。出身身份和投票权是两回事。[[#def-citizen]]指出，她可以对儿子的身份至关重要，同时在公民大会中缺席。用“参与者”来指后一个事实，恰恰能让前一个事实保持可见。把她画进阴影的图示才是时代错置，因为那等于授予她一张法庭和法令都没有记录的选票。

第二条反驳说，抽签和津贴使男性公民之间极为平等，排斥只是一种与其他城邦共有的古代小习惯，因而不值得放在本课的中心。与其他城邦共有，并不等于无足轻重。雅典在自己的政治言辞中宣称拥有一种特殊的自由，本课的中心正是这一宣称与享有这种自由的群体之间的落差。其他城邦同样狭窄，但这并不会让这个城邦变得宽广。而且，这种习惯也不只是与民主制并存的古代风俗：公元前451年的法律，是男性公民在他们早已掌控的公民大会上作出的、进一步收紧这个团体的民主决定。

实例。下面三句话是虚构的，被拟作这幅图的说明文字。“阴影区域就是雅典人民。阴影之外的每个人都差不多是公民。这幅图统计的是公元前451年之后阿提卡的人口。”

阴影区域是一条规则——成年、父母都是公民、男性——而不是现代意义上的“人民”，也不是泛指居民的那种“人民”。阴影之外的人并不是“差不多是公民”。外侨的接近是社会和经济意义上的，法律依然把他排除在外。奴隶也不是“差不多是参与者”。公民妇女以另一种方式——通过出身——与之接近，但她依然在参与之外。这幅图没有统计任何人。任何以人口数字作结的说明文字，都已经离开了证据。修补的办法就是图上原有的说明：这是一条规则，而不是一次统计。

:::warning 不是西方自由的诞生
常见的迷思说雅典发明了西方自由，被追问时再补充说，妇女和奴隶当然被排除在外——仿佛排斥只是一句真话下面的注脚。但这句话并不是真的。摆脱波斯国王统治的自由，在上一章的战争中是真实的口号；男性公民之间的民主制度也是真实的。但无论口号还是制度，都没有包括阿提卡的居民，也都没有在公元前508年或公元前451年奠定一个西方政治传统。一条为荣耀致歉的注脚，已经事先选择了荣耀。本章选择的是法律所规定的边界。
:::

:::history 一次改革，然后是一条更严的规则
克里斯提尼的改革通常定于公元前508/507年。这些改革把雅典男性公民重新组织到德莫和部落之中，为公民大会、议事会和抽签制度开辟了道路。伯里克利的公民权法通常定于公元前451/450年。此后，参与须以父母双方都是公民为条件，并由成年男子行使。妇女、奴隶和外侨始终被排除在这种实践之外。
:::

## 通向何处

这里所界定的男性公民，就是那些掌握着一个帝国、随后又与其他希腊国家进行一场漫长战争的雅典人。[[greece/peloponnesian-war]]始于公元前431年，以公元前404年的投降告终。它不是对“希腊心智”的裁决，而苏格拉底在公元前399年的死，只是这些法庭的一次运用，而不是对它们的概括。[[greece/persian-wars]]讲述的是那场胜利和那个同盟，正是它们使分享特权的问题变得紧迫。史料与你从中得出的推论有何不同——尤其当史料是一篇法庭演说时——见[[sources/evidence]]。

:::summary
- 雅典民主制是成年男性公民之间的公民大会、议事会、法庭和抽签。它不是议会，也不是成文宪法。
- 克里斯提尼的改革通常定于公元前508/507年，我们采用公元前508年。这些改革重组的是男性公民，并没有赋予整个阿提卡参政权。
- 从公元前508年到公民权法颁布是57年。这项法律通常定于公元前451/450年，这里采用公元前451年，它要求父母双方都是公民。
- 这项法律之后，参与者是父母都是公民的成年男子。关于动机，历史学家看法不一；效果就是这条规则。
- 公民家庭的妇女可以传递身份、担任宗教职务，却不投票。外侨可以是自由人、纳税、持有武器，却不投票。奴隶在法律上是财产。
- 维恩图表示的是这条规则，而不是人口。这里不给出阿提卡的人口，因为没有确定的数字。
- 这些制度不是西方自由的诞生。排斥是公民团体的设计，而不是注脚。
:::

## 习题

:::exercise 两次改革之间的年数 {level=1 check="57"}
这里把克里斯提尼的改革定于公元前508年，把公民权法定于公元前451年。两者相隔多少年？（请输入年数。）
:::solution
508减451等于57。核对：451加57等于508。两个年代都在公元前。答案是57。
:::
:::

:::exercise 父母中要几位是公民 {level=1 check="2"}
公元前451年的公民权法之后，这条规则要求几位公民父母？（请输入数字。）
:::solution
[[#def-citizen]]把这条规则表述为父母双方都是公民。只要父亲是雅典人即可，是更早、更宽松的说法，而不是公元前451年之后的法律。答案是2。
:::
:::

:::exercise 哪个标签不符合 {level=1 check="Man"}
公元前451年之后，一位虚构的成年女子，母亲和父亲都是雅典人。图上有三个标签：成年（Adult）、公民双亲（Citizen parents）和男性（Man）。她不符合哪一个？（请输入该标签。）
:::solution
她已成年，父母都是公民，但她不是男性，所以在阴影交集之外。她不符合的标签是Man。
:::
:::

:::exercise 不是议会 {level=2}
一位读者说，雅典的公民大会就是议会，因为人民在那里辩论和投票。请运用[[#thm-not-parliament]]说明，关键的区别是什么？
:::solution
后来意义上的议会是一个代表机构，通常由选举产生，代表更广泛的公众发言，而且往往处于一部高于任何单次会议的成文宪法之下。雅典的公民大会则是到场的男性公民。他们不是被派来代表妇女、外侨或奴隶的，也不在任何一份建国文献之下开会。大多数公职是抽签而不是选举产生的。两者相似之处在于都集会、都投票；区别在于谁在会场之中，以及这一票属于一套什么样的机制。把它称为议会，是借来一份现代的荣誉，却用在了错误的对象上。
:::
:::

:::exercise 舰队中的外侨 {level=2}
一位虚构的外侨在雅典舰队中服役，缴纳外侨税，终生未获授予公民身份。一位评论者说，他的服役“使他实际上成了公民”。请用公元前451年的法律和这幅图来回答。
:::solution
服役和纳税是城邦可以加在一个自由外来者身上的义务，它们既不是双亲规则，也不是作为男性公民的登记。在图上，他可以成年、是男性，却仍然落在“公民双亲”之外。“实际上”一词正是症结所在：它把社会上的用处当成了参政权。一项法令本可以使他成为公民，而这个虚构的情形说明并没有这样的法令。他依然是外侨，这就是从外侧看到的[[#def-citizen]]。
:::
:::

:::exercise 为什么没有人口数字 {level=2}
有人请你给出伯里克利时代阿提卡的人口。提供给你的史料是一项公民权法、关于出身的法庭演说和若干法令。本章为什么拒绝给出一个数字？
:::solution
年表没有给出人口，而列出的史料也都不是人口普查。法律陈述的是一条规则；演说控告的是某些具体的人不符合这条规则；法令则把身份授予具名的个人。它们没有一份统计居民人数。给出一个数字会是虚假的精确，还会诱使读者把维恩图的阴影当作人头数。[[sources/evidence]]把存迹与推论分开。允许作出的推论是公民团体的形状，不允许作出的推论是阿提卡的人数。
:::
:::

:::exercise 西方自由 {level=3}
一张讲课幻灯片写着：“公元前508年：雅典奠定西方自由。排斥妇女和奴隶是时代的细节，而不是成就的细节。”请用一段简短的论证回应，并保留公元前508年真实的部分。
:::hint
把一次有确切年代的男性公民改革与一个现代说法分开。然后问：一项后来写进法律的排斥——公元前451年——能否只是成就中的一个细节？
:::
:::solution
真实的是一次通常定于公元前508/507年的改革：它把雅典男性公民重新组织到德莫和部落之中，并为公民大会、议事会和抽签制度提供了支撑。这是早期形态的雅典民主制，[[#thm-not-parliament]]承认它是真实的。但“西方自由”并不在这次改革之中。“西方”是后来的名称，而作为普遍主张的自由，描述不了一个公民团体。对妇女、外侨和奴隶的排斥，正是这个团体的界定方式，而不是藏在它下面的一个细节。公元前451年，城邦又按出身进一步收紧了这一界定，这就是[[#thm-exclusion]]。所谓时代的细节，应当是成就本身并不需要的东西；而这项成就——如果成就指的是民主制——恰恰需要一条规定谁在会场之中的规则。这张幻灯片保留了一个年份，却用一句口号替换了会场。
:::
:::

:::exercise 一位母亲与一张选票 {level=3}
公元前451年之后，一位虚构的公民妇女是一个确实参与政治的虚构儿子的母亲。一位作者说：“因此她是完全的公民，图示不给她涂上阴影是错的。”你可以承认什么？这位作者又在哪里越出了证据？
:::hint
承认法律本身造成的那个出身事实。然后问：这种承认把她放进了哪些行为之中——公民大会、议事会、法庭还是抽签？
:::
:::solution
可以承认的部分是真实的。法律把父母双方都是公民定为儿子参与的条件，所以她的身份对儿子而言具有政治上的决定性。有些历史学家甚至对处于这种地位的妇女使用一个表示公民身份的词。这是一场词汇上的争论，不应嗤之以鼻，但它并不会使她在这幅图上被涂上阴影。阴影代表的是参与：身在公民大会、议事会、陪审团和抽签公职之中。这一承认中没有任何东西把她放进这些场合。她也许担任的宗教职务是另一种公共角色，依然不是投票权。只有当记录显示妇女作为一个群体身在这些制度之中时，这幅图才是错的。这位作者把“对他人的公民身份必不可少”当成了“享有同样的公民行为”。[[#def-citizen]]有意把两者分开。
:::
:::
