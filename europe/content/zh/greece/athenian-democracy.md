在民主制的雅典，谁是公民，谁不是？

这个问题是本章的中心，不是光环之后补上的一句道歉。雅典民主制是一套真实的制度，而它很狭隘。克利斯提尼（Cleisthenes）的改革常被定在公元前508/507年。我们采用公元前508年。伯里克利（Pericles）的公民法常被定在公元前451/450年。我们采用公元前451年。这部法律之后，投票、审判和担任抽签之职的人，是双亲皆为公民的成年男子。妇女、奴隶和侨居者（metic）不在其内。公民大会、议事会、法庭和抽签的使用都是真实的。它们不是成文宪法，不是现代议会，也不是西方自由的诞生。我们不给阿提卡（Attica）任何人口数字。年表没有给出，法庭的演说也不是人口普查。

## 这些制度是什么

:::definition 雅典民主制 {#def-democracy}
**雅典民主制**是雅典公民成年男子的集会统治：通过群众大会、议事会、庞大的法庭，以及大多以抽签充任的公职。在与克利斯提尼相联系的形式中，它常被定在公元前508/507年。在按出身收紧了的形式中，它以常被定在公元前451/450年的公民法为标志。它不是一部奠基现代国家的文书，也不是所有居住在阿提卡的人的总称。
:::

这些改革坐落在一场僭主政治——庇西特拉图家族（Peisistratid）——之后，也坐落在一场大家族之间、斯巴达曾插手干预的斗争之后。我们不给僭主倒台定年。年表里没有它。按通常的年代，公元前508年标记的是公民团体的重新组织。基层单位村社（deme）成为识别一个人为公民的单位。新部落横切沿海、内陆、城区这些旧的地域派系，使依托一地的势力更难聚合。一个从各部落抽签选出的议事会为公民大会准备议程。陶片放逐法——用碎陶片投票、把一个人放逐固定年限——也属于同一个政治世界：一种不经刑事审判而去除有权势公民的手段。我们不去统计它所需的票数。这种手段之所以重要，在于它是公民男子相互握有的一种权力。

公元前508年之后的几十年里，旧的议事会战神山议事会（Areopagus）在公民大会和法庭面前节节退让。这场变化的某些环节有本表不列的年份，所以一个也不给。方向已经足够。民主制更充分地成为到场者的统治——以及从到场者中抽出的陪审法庭的统治。这一发展不是从公元前594年梭伦执政官任期的传统连成的一条直线；[[greece/poleis]] 已经拒绝把那个年份当作民族政制。从公元前594年到公元前508年是一段漫长的间隔，中间有一次僭主政治。从公元前508年到公元前451年是另一段间隔，隔着另一部法律。

公民大会就是当天在场的公民男子。他们以多数做决定。他们不是受派遣为家庭、妇女或侨居者代言的代表。留在家里的人没有代理票。普通公民男子只要到场，在一项动议上的票就与富人的一票等价。阿提卡的绝大多数居民不在那个会场里。

绝大多数公职由抽签充任，任期短，任满要受审查。在公民团体内部，统治不为专家或家族所垄断。将军由选举产生并可连任，因为城邦想选择谁来领军。选举是例外。公职津贴和出席津贴使较穷的公民男子得以任职。我们不写出任何数额。津贴补偿的是已经在团体之内的人。它不理会法律挡在外面的人。

有法律，许多还刻在石碑上。也有程序可以控告一名发言人提出了违反法律的建议。这是民主制内部的一道约束。它不是最高法院宣读一份建国文献，法律也不是现代意义上的成文宪法。公民大会的决议就是城邦的政治行为。一块石头是证据。它不是一部等着被后世议会照抄的宪法。

:::theorem 这些制度不是现代议会，也不是西方自由的诞生 {#thm-not-parliament}
公民大会、议事会、法庭和抽签造就了一个成年公民男子的真实民主制。它们没有造就代表制议会，没有造就成文宪法，也没有造就西方自由的起源。这条论断两次限定自己：这些制度不是迷思；后世献给它们的现代荣誉，不是对公元前508年或公元前451年的描述。
:::
:::proof
证据就是这些制度本身——就亚里士多德（Aristotle）名下的《雅典政制》（Constitution of the Athenians）、存世的法令和法庭实践允许我们重构而言。到场、抽签、短任期、庞大的陪审团，是一部与民选议院在一部高于自身的宪制文本之下立法完全不同的机器。后来的欧洲人仰慕雅典，并经由别的路线建立了议会。仰慕是关于那些欧洲人的事实。它没有把他们的制度搬回公元前五世纪。

“西方自由”还有一个失败的理由。“西方”是一种现代的地理道德判断，正是 [[sources/naming-europe]] 拒绝当作古代行动者的那种。自由，在希波战争的口号里，意思是不受波斯国王统治。在雅典内部，它的意思是一个确定的男性团体的政治生活，其凭借是对其他城邦的帝国，如 [[greece/persian-wars]] 所述。这个短语偷换了主题。

会构成对这条论断的反证的，是一部当时的文本：其中雅典的公职由所有成年居民的代表充任，妇女和侨居者也在其内，而且在一份这些居民可以用来对抗公民大会的统一宪法文献之下。法令、陪审津贴和抽签不会因为壮观就变成那部文本。会构成对民主制真实性的反证的，是公民大会和法庭实际上并不做决定的证据。精英的影响是真实的。它不等于这些制度的缺席。
:::

## 公元前451年的法律

:::definition 公元前451年之后的参与者 {#def-citizen}
在常被定在公元前451/450年的公民法之后，雅典民主制的**参与者**是双亲皆为公民的成年男子。这是一条出身与性别的规则。它不是人数清点。公民家庭的女性可能因这条规则而被需要——儿子的身份取决于母亲——却仍然没有投票权。奴隶和侨居者在参与团体之外，无论他们是否成年、是否为男性。
:::

这部法律之前，通常的说法是雅典父亲为主要出身标准，与外邦妇女通婚是可能的。法律把标准收紧为双亲皆为公民。对动机，史家意见不一：是这些婚姻，是一座帝国城市的特权，还是伯里克利生涯中的一个时刻。效果比动机清楚，而效果正是那张图示显示的东西。我们不编造一个私人的理由，然后把它称为法律。

**侨居者**（metic）是自由的外来居民，多来自其他希腊城邦：在雅典登记，负有我们不标价的一种赋税，通常需要一名公民保人。侨居者可以很富有。他们经商、做工。按通常的说法，他们战时服役。他们不以侨居者身份出席公民大会。授予某个具名外邦人以公民身份是一项法令，而它恰恰确认了边界：如果这种身份稀松平常，城邦就不必去授予它。奴隶不是侨居者。奴隶在法律上是财产。他们在家庭、农场、工场和阿提卡的银矿里劳作。我们不去描述那种劳动，也不去给他们定数字。自由即使到来，也不是公民身份。获得解放的人并不会因此成为双亲皆为公民的人。

公民家庭的女性是最难的案例，也是光环故事最想加一条注脚的地方。她们并没有被挡在一切公共行为之外。女司祭执掌宗教职务。节庆需要公民男子的女儿和妻子。公元前451年之后，公民母亲是公民儿子的条件。这是关于她的身体和她的出身的政治事实，却不给她投票权、抽签之职或陪审席位。有些史家把“公民”一词留给那种出身身份，然后再补一句：政治权利属于男性。这套词汇是一场真实的争论。它并没有把她移进图上着色的区域。这一课用“参与者”指那些行为，用 [[#def-citizen]] 指那条规则。宗教职务是公共的。它不是民主制。

这部法律伸入家庭内部，这正是它不是一处小小的选举技术细节的原因。法庭演说反复触及某人的母亲是否为雅典人。这种文体的功能是控告，不是一份可以从中读出阿提卡人口的名录。数字上的沉默不是规则上的沉默。规则在法律里。数字不在我们的年表里。

按顺序读这三个标签。成年、公民双亲、男性：三条全满足，否则没有参与。公民妇女是成年公民双亲之女，但不是男性，所以在着色之外。侨居者成年而男性，但没有公民双亲。一名奴隶也许与他在同一片未着色的角落里。图形分不开这两个人，因为他们倒在规则的同一条条件上。这个限度是一种优点。这张图从来不是身份的人口普查。公民双亲之子女在登记之前不符合“成年”。我们不把成年年龄编造为一个数字。村社登记是城邦自己的关口，而它是为儿子设的关口。

:::example 五十七年的变迁 {#ex-span}
克利斯提尼的改革常被定在公元前508年。公民法常被定在公元前451年。它们相隔多少年？这段间隔禁止你对“那个”雅典公民说什么？
:::solution
两个年代都是公元前，所以相减：508减451等于57。核对：451加57等于508。双年份508/507和451/450是古代年份对常见的写法。我们仍像本年表要求的那样采用508和451。这段间隔禁止给出一个单一的诞生日。公元前451年之后参与的人，必须满足一条出身规则，而它与公元前508年的部落改革并不相同。五十七年，足够让一场僭主政治的余波变成一座帝国的民主制，也足够让城邦做出决定：守护特权的是双亲，而不是单亲。
:::
:::

:::example 三个编造的人物 {#ex-three}
这三个人物是为这个例子编造的。他们不是人口普查。第一，公元前451年之后，一名已在村社登记的成年男子，父亲是雅典人，母亲也是雅典人。第二，他的成年姐姐，双亲相同。第三，一名在雅典居住多年、城邦征召时便服役的成年侨居者。谁在图上着色的交集之内？谁在哪个圈之外？
:::solution
只有第一个在交集之内：成年、双亲皆为公民、男性。姐姐成年且出身公民双亲。她不符合标注为“男性”的那个条件。她的身份对法律很重要，因为她的儿子可以经由她承继参与资格，而她自己仍然不参与。侨居者成年而且是男性。他不符合公民双亲。服役不能使他移进另一侧。如果某项法令后来封他为公民，那项法令是由他尚未属于的那个团体批准的例外。三个人物没有一个人口统计的意义。这次分类是对 [[#def-citizen]] 的一种阅读。
:::
:::

:::example 两部法律并排 {#ex-pair}
把公元前508年与公元前451年并排。一个年代与村社、部落和抽签选出的议事会相联系。另一个是一部关于出身的公民法。它们是同一场改革吗？其中任何一个是西方自由的奠基吗？
:::solution
它们是两次雅典改革，相隔57年，回答的是不同的问题。克利斯提尼的通常年代改组的是既存公民团体，使地域和家族势力不那么好用。伯里克利的通常年代决定下一代谁可以进入这个团体。把两者当作一次奠基，就是把部落改革与出身标准混为一谈。把其中任何一个当作西方自由的诞生，就是添加了一幅现代地图和一套石头并不承载的权利语言。并排来看，这两个年代显示的是一种修改自身边界的民主制。一个能够收紧边界的民主制不是一个超时间的理念。它是一座城邦在使用自己的公民大会。
:::
:::

## 排除就是设计

先讲公民大会、再把排除当作憾事补在后面，这种讲法很诱人。那个顺序就是“光环加注脚”的迷思。公元前451年的法律讲的就是公民大会是谁。帝国让这个问题更尖锐，而不是更温和。[[greece/persian-wars]] 描述的盟邦贡金，供养了这座城邦的政治津贴与公共营建。分享如此富有的一座城邦，是一场政治之争。收紧出身规则，是公民男子进行这场斗争的一种方式。你可以赞赏抽签，同时看到：抽签从未提供给纳税的侨居者、孩子被法律盘问的那个妇女、矿里的奴隶劳动者。需要把这些人模糊掉才能成立的赞赏，赞赏的不是这座城邦。那是另一座城邦。

法庭是同一设计的一部分。由公民男子组成的庞大陪审团审理的案件，可以让一个政治家身败名裂，也可以判处被告死刑。公元前399年，这些法庭将判处苏格拉底（Socrates）有罪。[[greece/peloponnesian-war]] 把那场审判当作一次战败之后的雅典事件来处理，而不是当作希腊思想的意义。它在本章只作为一个限度出现。一个公民男子的民主制能够毁灭自己的一个人。这个事实既不能概括这个制度，也不会因为这个事实，这个制度就扩展到那些不能坐上陪审席位的人。

:::theorem 排除就是公民团体本身，不是注脚 {#thm-exclusion}
妇女、奴隶和侨居者在公元前451年之后不在参与之列，是由团体的界定方式决定的，不是又一个否则就普遍参与的民主制旁边的意外。把排除拿掉，你描述的就是一部法律没有描述的城邦。
:::
:::proof
法律就是证据：双亲皆为公民；以及公民大会、议事会、陪审法庭和抽签之职都由男性运作的政治实践。以授予公民身份来褒奖某个外邦个人的法令，从另一面显示了同一条边界。女性担任的宗教职务显示的是一种止步于投票之外的公共角色。奴隶制合法而平常，在家户中如此，在白银产业中也如此——这意味着公民政治的余裕与收入建立在不自由劳动之上。这一切都不是仅凭沉默做出的推论。史料沉默之处，沉默的是数字和被排除者的声音，不是规则。[[sources/evidence]] 说：沉默不是一个人没有头脑的证据。它是关于谁被征求意见的证据。被排除者有头脑。他们没有这项选举权。

会构成对这条论断的反证的，是一项法令或一份可信的叙事：其中妇女作为一个阶级、或侨居者作为一个阶级、或奴隶，在公元前451年之后出席公民大会或担任陪审员。一位女司祭不算。舰队里的一名侨居者不算。授予一个人的特权不算一个阶级。若真有这样按阶级的纳入出现，[[#def-citizen]] 就得重写。它没有出现。还会构成对这条论断的一个粗糙版本的反证的——那个粗糙版本说妇女在社会上不可见——是宗教记录。我们不做那个粗糙版本的主张。被民主制排除和在祭祀中在场，两者皆为真。
:::

:::quiz
对公元前451年的法律，哪一种描述是准确的？
- [ ] 它把投票权给了阿提卡的每一个成年人
- [ ] 它是西方自由的成文宪法
- [x] 它要求双亲皆为公民，而参与仍属于成年男子
- [ ] 它废除了银矿里的奴隶制
:::solution
法律收紧的是出身。它没有向妇女、侨居者或奴隶开放公民大会，也没有触动奴隶制的合法性。[[#thm-not-parliament]] 挡住了宪法式读法和“西方”式读法。第三个选项就是 [[#def-citizen]] 里的规则。
:::
:::

:::example 一个编造的奠基 {#ex-invented}
这句话是编造的。它不是史料。“公元前508年，雅典发明了西方自由，把权力交给了阿提卡的人民。”什么——如果有的话——年代用对了？什么是添加进去的？
:::solution
公元前508年是我们用于克利斯提尼改革的通常年代，常写作508/507。这是这句话触碰年表的部分。“发明了西方自由”添加了现代的地理观和现代的道德观。“阿提卡的人民”添加了那些不是参与公民男子的居民：妇女、侨居者、奴隶，以及公元前451年之后任何不符合双亲规则的人。即便在公元前508年，新部落组织的也是公民，不是全部居民。这句话留下了一个真实的年份，却把公民团体换成了一个后来的理念。修补后的说法是：公元前508年，雅典公民男子被重新组织进一个民主制；这个民主制后来在公元前451年把他们定义为双亲皆为公民的人。
:::
:::

## 反对意见与一个案例

来自词汇的反对意见是需要认真对待的那一条。如果雅典希腊语能够把出身公民家庭的女性称为城邦的一员，那么一张以“男性”为标签的图，看起来就像一种倒投射的现代侮辱。回答在那些行为里，不在拒绝倾听这个词。出身身份和投票权是两回事。[[#def-citizen]] 说：她可以对儿子的身份至关重要，同时缺席于公民大会。用“参与者”去指第二类事实，正好让第一类事实保持可见。把她着上进图里的画法才是时代错位，因为那等于授予她一票——法庭和法令都没有记录过她的一票。

第二条反对意见说：抽签和津贴使公民男子之间如此平等，以致排除不过是一种古代的小习惯，其他城邦也一样，因此不值得放在一课的中心。与其他城邦共有不等于小。雅典在自己的政治言辞中宣称一种特殊的自由。本课的中心，就是那个主张与享有它的那个团体之间的落差。其他城邦也狭隘。那并不会让这个城邦变宽。而且这种习惯不只是坐在民主制旁边的古代风俗。公元前451年的法律是一项民主的决策，由公民男子已经掌控的公民大会做出，决定把团体进一步收紧。

案例。三句话，编造的，被提议作为那张图的图注。“着色区域就是雅典人民。它之外的每个人都几乎是公民。这张图清点的是公元前451年之后阿提卡的人口。”

着色区域是一条规则：成年、双亲皆为公民、男性。它不是现代意义上的“人民”，也不是居民的那个宽泛意义。它之外的人不是几乎公民。侨居者的接近是社会的和经济的，法律仍然把他挡在外面。奴隶不是几乎参与者。公民妇女以另一种方式接近——经由出身——她仍然在参与之外。这张图谁也没有清点。任何以人口做结的图注都已经离开了证据。修补就是图上那条图注：一条规则，不是一次清点。

:::warning 不是西方自由的诞生
常见的迷思说雅典发明了西方自由，被逼问时再补一句：妇女和奴隶当然被排除在外——仿佛排除只是一句真话底下的注脚。这句话不真。摆脱波斯国王的自由，是上一章各场战争中真实的口号。公民男子中间的民主制度是真实的。口号和制度都没有把阿提卡的居民包括在内，两者也都没有在公元前508年或公元前451年奠定一个西方政治传统。一句为光环道歉的注脚，已经选边选了光环。本章选择的是法律陈述的那条边界。
:::

:::history 一场改革，然后一条更紧的规则
克利斯提尼的改革常被定在公元前508/507年。它们把雅典公民男子重新组织进作为基层单位的村社和各部落，并为公民大会、议事会和抽签开辟了道路。伯里克利的公民法常被定在公元前451/450年。此后，参与要求双亲皆为公民，并由成年男子实行。妇女、奴隶和侨居者仍然站在这个实践之外。
:::

## 通向何处

这里界定的公民男子，就是先握有一个帝国、随后与其他希腊诸国打一场漫长战争的那些雅典人。[[greece/peloponnesian-war]] 始于公元前431年，终于公元前404年的投降。它不是对“希腊心灵”的判决，苏格拉底公元前399年的死是这些法庭的一种运用，不是它们的全貌。[[greece/persian-wars]] 是那场胜利和那个同盟，它们使分享特权的问题变得紧迫。一份史料与你的推论有何分别——尤其是当史料是一场法庭演说时——见 [[sources/evidence]]。

:::summary
- 雅典民主制是成年公民男子之间的公民大会、议事会、法庭和抽签。它不是议会，也不是成文宪法。
- 克利斯提尼的改革常被定在公元前508/507年。我们采用公元前508年。它们改组的是公民男子。它们没有给阿提卡选举权。
- 从公元前508年到公民法是57年。公民法常被定在公元前451/450年，这里采用公元前451年，要求双亲皆为公民。
- 那部法律之后，参与者是双亲皆为公民的成年男子。动机，史家意见不一。效果就是规则。
- 公民家庭的女性可以传递身份、担任宗教职务，而她们不投票。侨居者可以自由、纳税、武装，而他们不投票。奴隶在法律上是财产。
- 那个韦恩图是那条规则，不是人口。不给阿提卡人口数字，因为这里没有任何数字是确定的。
- 这些制度不是西方自由的诞生。排除是公民团体的设计，不是注脚。
:::

## 练习

:::exercise 两场改革之间的年数 {level=1 check="57"}
克利斯提尼的改革在这里定为公元前508年。公民法在这里定为公元前451年。它们之间相隔多少年？（输入年数。）
:::solution
508减451等于57。核对：451加57等于508。两个年代都是公元前。答案是57。
:::
:::

:::exercise 需要几个双亲 {level=1 check="2"}
公元前451年的公民法之后，规则要求几个公民双亲？（输入数字。）
:::solution
[[#def-citizen]] 把规则表述为双亲皆为公民。只认一位雅典父亲是更早、更宽的说法，不是公元前451年之后的法律。答案是2。
:::
:::

:::exercise 哪个标签不合格 {level=1 check="Man"}
公元前451年之后，一个编造的成年女性，母亲是雅典人，父亲也是雅典人。图上三个标签——成年（Adult）、公民双亲（Citizen parents）、男性（Man）——她不符合哪一个？（输入那个标签。）
:::solution
她成年，双亲皆为公民。她不是男性，所以在着色的交集之外。她不符合的标签是 Man。
:::
:::

:::exercise 不是议会 {level=2}
一位读者说，雅典公民大会就是一个议会，因为人民在其中辩论和投票。用 [[#thm-not-parliament]] 说明：要紧的分别是什么？
:::solution
后来意义上的议会是一个代表团体，通常由选举产生，为更广泛的公众发言，常常在一份高于单独一次会议的成文宪法之下议事。雅典公民大会是在场的公民男子。他们不是受派来代表妇女、侨居者或奴隶的，他们也不在一份建国文献之下开会。绝大多数公职是抽出来的，不是选出来的。相似之处是两者都集会、都投票。分别是：谁在会场里，以及那票属于一台什么样的机器。把它叫作议会，是借来一份现代的荣誉，把它花在了错误的对象上。
:::
:::

:::exercise 舰队里的侨居者 {level=2}
一个编造的侨居者在雅典舰队服役，缴纳侨居者税，终其一生没有得到公民身份的授予。一位评论者说，他的服役“让他事实上成了公民”。用公元前451年的法律和那张图来回答。
:::solution
服役和纳税是城邦可以对自由外来人施加的义务。它们不是双亲规则，也不是作为公民男子的登记。在图上，他可以成年、男性，仍然落在公民双亲之外。“事实上”是惹祸的地方：它把社会有用性当成了选举权。某项法令本可以让他成为公民。这个编造的案例说法令没有这样做。他仍然是侨居者——这是从外面看的 [[#def-citizen]]。
:::
:::

:::exercise 为什么没有人口数字 {level=2}
有人问你伯里克利时代阿提卡的人口。提供给你的史料是一部公民法、关于出身的法庭演说、以及一些法令。为什么本章拒绝给出数字？
:::solution
年表没有给出人口，而列出的史料都不是人口普查。法律陈述一条规则。演说控告某些具体的人不符合规则。法令授予具名个人身份。它们谁也不清点居民。一个数字会是虚假的精确，还会引诱读者把韦恩图的着色当作人头数。[[sources/evidence]] 把存迹与推论分开。被允许的推论是公民团体的形状。被禁止的推论是阿提卡的人数。
:::
:::

:::exercise 西方自由 {level=3}
一张讲义幻灯片写着：“公元前508年：雅典奠基西方自由。妇女和奴隶被排除，是时代的细节，不是成就的细节。”用一段简短的论证回应。保留公元前508年真实的东西。
:::hint
把一场有年代的公民男子改革与一个现代短语分开。然后问：写进后来法律的排除——公元前451年——能否只是成就的一个细节。
:::
:::solution
真实的是常定于公元前508/507年的一场改革：它把雅典公民男子重新组织进村社和部落，并支撑起公民大会、议事会和抽签。那是早期形态的雅典民主制，[[#thm-not-parliament]] 说它是真实的。“西方自由”不在那场改革里。西方是一个后来的名字，而作为普遍主张的自由也不描述一个公民团体。对妇女、侨居者和奴隶的排除就是这个团体的界定方式，不是它底下的一个细节。公元前451年，城邦按出身进一步收紧这个定义，这就是 [[#thm-exclusion]]。时代的细节应该是成就用不着的东西。而这个成就——如果这个成就是指民主制——需要一条规则来规定谁在会场里。这张幻灯片留下了一个年份，把会场换成了一个口号。
:::
:::

:::exercise 一位母亲和一张选票 {level=3}
公元前451年之后，一个编造的公民妇女是一个编造的儿子之母，而这个儿子确实参与政治。一位作者说：“因此她是完全的公民，而图画没有给她着色是错的。”你可以让步什么？这位作者在哪里越过了证据？
:::hint
让步法律本身造成的那个出身事实。然后问：这一让步把她在哪些行为上放进会场——公民大会、议事会、法庭、抽签？
:::
:::solution
可以让步的是真实的。法律把双亲皆为公民定为儿子参与的条件，所以她的身份对他有政治上的决定意义。有些史家甚至对处于这种位置的妇女使用一个公民身份的称呼。这是一场词汇之争，不应嗤之以鼻。但它不会在这张图上给她着色。着色指的是参与：在公民大会、议事会、陪审法庭和抽签之职之中。这一让步没有任何一点把她放进那些会场。她也许同时担任的宗教职务是另一种公共角色，仍然不是投票权。如果妇女作为一个阶级在这些制度里被记录下来，图画就错了。这位作者把“对别人的公民身份是必要的”当成了“持有同样的公民身份行为”。[[#def-citizen]] 正是有意把两者分开。
:::
:::
