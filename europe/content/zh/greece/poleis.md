城邦如果不是一个希腊民族，那它是什么？

后世的欧洲地图喜欢这样开篇：一个民族万事俱备，只差一纸文书。古风时代的希腊语诸共同体并不符合这幅图景。它们是许多政治体，而不是一个等待被命名的政治体。它们跨海建立新的共同体，彼此攻战，并与一个全然不是希腊的强权比邻而居：波斯帝国在本图谱所记任何一场战役之前，就已经是爱琴海对岸的大国了。

本章的问题是：怎样称呼这些共同体中的一个，而不把“民族”偷偷夹带进来。共同的语言、共同的神明、共同的竞技会，都是证据的一部分。它们不是政制。殖民城邦、同盟和僭主政治都属于这幅图景。统一的希腊国家则不属于。可以当作标记的数字有两个，而且都必须当作传统来处理：公元前776年对应奥林匹克竞技会，公元前594年对应梭伦（Solon）任执政官。两个数字都不是出生证明。

公开的时间线把这些相同的负年份印作 BC。这里的标签是 BCE。两个标记都处在公元之前，所以它们之间的间隔就是一道普通的减法，下文会算出来。

## 公民与一块土地

:::definition 城邦 {#def-polis}
**城邦**（polis，复数 poleis）是公民共同体连同其领土。后起的说法 city-state 指向的也是这个单位。nation-state 则不是。城邦的领土通常包括一座城镇和一片乡野。生活劳作在这片领土上的许多人并不是公民：公民家庭的女性与担任公职的男性地位不同，外邦人、依附劳动者和奴隶也不属于公民团体。

城邦不是“希腊”，也不是通往现代国家途中的一个阶段。它可以小可以大，可以在海边可以在内陆，可以实行民主制、寡头制，也可以处在僭主之下。大小和政制的风格并不是构成这个单位的东西。构成它的是公民共同体和领土。
:::

公民身份是地方性的、靠出身承继的。在一个城邦是公民的人，到了邻邦就是外邦人。不存在一份所有希腊语城邦都同意遵守的文书。公民通常共有而外人没有的，是一束随城邦而异的东西：对土地的要求、在祭祀中的位置、进入法庭的资格，以及凡政制允许有份额之处分享决策。寡头制不是失败的城邦。它是公民团体可以采取的形态之一。

乡野让这幅图景不至于收缩成几座神庙。公民、外邦人和奴隶都在土地、家户和工场里劳作。城镇里有行政长官、集会场所和神龛。这一切都不是希伦人（Hellenes）的首都。根本不存在这样的首都。雅典、斯巴达、科林斯和底比斯是四个城邦，不是一出戏的布景，其中两个替其余的站一站就行。

史家对城邦类型可以推广多远意见不一。有些希腊语共同体是以更松散的地区方式组织的；上一章以一个王国面貌遇到的马其顿，并不是雅典的翻版。这场争论关乎一个类别的边缘。它并不会把一个希腊国家放到正中间。

:::definition 殖民城邦 {#def-colony}
**殖民城邦**（colony）在这里指从一个旧城邦建立起来的新城邦，不是一个希腊王国的一个县。旧城邦是母城。移居者成为新共同体的公民团体。他们可能保留创始者的祭祀、一段起源传说和一层宗教义务。他们制定自己的法律，也结下自己的仇敌。他们不是一个行政辖区，因为根本不存在一个让他们当辖区的希腊国家。
:::

移民的足迹延伸到西西里和意大利南部、黑海、北非，以及埃及的商站。当地的邻居往往不说希腊语，新城邦便以贸易、联姻、剥削或战争与他们打交道。殖民城邦也可能与自己的母城交战。县不会这样做之后还继续当县。我们不给这些建城定年：年表没有列出它们。叙拉古（Syracuse）可以作为西西里的一个城邦被提及，而不需要一个建城年份。另一本书给出的确切年份，在达到 [[sources/evidence]] 的标准之前仍然只是传统——那里把存迹与推论分开。

**僭主**（tyrant）在古风时代的用法中，指在一个城邦里攫取个人权力的人。这个词标记一条上台的路线。它还不是后来那种恶魔的漫画形象，也不是一种常规的年度官职。有些僭主以兴建和节庆被记住，有些以对政敌的暴力被记住。两种记忆都可能出于党派，而后世作者偏爱那种以合法政府收尾的道德剧。我们可以使用这个范畴而不要那出戏。僭主倒台之后，公民共同体还在。他的生平不是一个民族的经历。

斯巴达显示出这个定义有多宽。它是一个城邦，有两位世袭国王、一个长老会议、一年一任的监察官（ephors），还有一个公民大会。它还凌驾于希洛人（helots）之上——一群不自由的人口，被束缚在拉科尼亚和麦西尼亚的土地上。他们是结构的一部分，不是一个理想底下的注脚：一个靠不自由劳动为生的公民少数，常常提防那些会让家乡无人看管的出征。斯巴达不是民主制，也不是“多利安民族”。我们不去给希洛人或全权公民定数字。年表没有确定这样的数字，而一个生动的数字只会伪造精确。

在这里，雅典是另一个作为案例来处理的城邦，不是古风时代的归宿。梭伦任执政官的传统年代是公元前594年。传统把解除债务记在他名下，也把按财产给政治权利分等记在他名下，后来的雅典人则把这件事讲成本邦守法的起点。一座城邦讲述自己的立法者的故事，是记忆与冲突的证据。它不是一次会议的记录，也不是全希腊的大会。年份为什么能够承载一条论断，见 [[sources/time-and-names]]。这个年份承载的是“梭伦当时担任雅典的官职”，而连这句话也是传统。

与克利斯提尼（Cleisthenes）相联系的民主制是另一件事，常被定在公元前508/507年，它是 [[greece/athenian-democracy]] 的主题。这里提到它，只是为了打断一条情节线。梭伦的传统年份不会因为时间流逝，就长成一部希腊人的民主政制。在传统记载的执政官任期与后来对雅典部落的改革之间，隔着世代更替，中间还有一次僭主政治，而仍然没有一个希腊国家。

## 什么不是国家

:::definition 民族国家 {#def-nation}
**民族国家**（nation-state），本图谱使用这个说法时，是一种现代主张：一个民族与一个国家相重合，即单一的公民身份，加上一个为该民族发言的政府。这个说法是我们的，不是古风时代的称号。我们把它当作一道检验。城邦通不过这道检验，因为它的公民团体只是希腊语世界的一个片段。希腊语世界也通不过，因为它没有统一的政府。
:::

人们确实有一个更大的称呼。他们自称希伦人，竞技会也可以拒绝不算希腊人的参赛者。在一个圣所里，这是真实的边界，是一场节庆的民族与宗教考试。谁算数，有时也有争议。一场关于资格的争吵不是人口普查，也不是一个政府衙门。

:::theorem 希腊国家并不存在 {#thm-no-state}
共同的语言、祭祀和竞技会没有构成一个希腊民族国家。没有统一的公民身份，没有统一的长官体系，也没有统一的平时军队。为某一场的特定战争结成的同盟不是那个缺席的国家。这条论断不是说希腊语者没有共同之处。他们共有之物甚多。共同的文化不是政制。
:::
:::proof
证据是政治地图——就考古、铭刻和后世叙事允许我们绘制而言。各城邦以各自的名义相互开战、议和。科林斯公民并不因此就是底比斯公民。斯巴达和雅典在同样的几十年里运行着不同的制度。殖民城邦以独立国家行动，对待母城也不例外。当许多城邦共同行动时——它们将来对付波斯时就会如此——靠的是同盟：有人缺席，指挥权还得协商。这是同盟，不是国家。

希腊语是一族方言，不是一部法律。一座圣所可以吸引许多城邦的来访者，因为它不是任何人的首都。会构成对 [[#thm-no-state]] 的反证的，是一条与事件相近同时代的存迹：其中某些长官的命令在平时就约束希腊语共同体本身，并且有一个金库、一种这些共同体服从的公民身份。一场节庆、一首英雄诗歌、一张涂成同色的现代地图都不算。那样的政府若出现过，这条论断就得放弃。它没有出现过。
:::

:::quiz
下面哪一项会是一个希腊国家的证据，而不仅仅是共同文化的证据？
- [ ] 奥林匹亚（Olympia）举办的、许多城邦都参加的竞技会
- [ ] 环爱琴海通行的希腊语方言群
- [x] 长官的命令在平时以单一公民身份约束各城邦本身
- [ ] 一则希腊英雄并肩作战的神话
:::solution
按 [[#def-nation]] 的检验，国家需要政府和公民身份，而不只是相似。竞技会、方言和英雄神话，正是 [[#thm-no-state]] 说是真实而不充分的那些东西。第三个选项，正是论证说缺失的那类存迹。若那条存迹出现，论断就不成立。
:::
:::

民族这条反对意见是认真的，但仍然是不充分的。希伦人可以自称其名，也可以把外人挡在竞技会之外。那条边界是真实的，但它是圣所的规矩，不是政府衙门。你可以是希伦人，同时是邻邦的外邦人，没有投票权，也没有土地。把一句关于节庆的真话升格成一句关于国家的假话——[[sources/scale]] 就是对这种升格的警告。

:::theorem 同盟仍然不是民族 {#thm-league}
城邦同盟是诸国之间的协议，不是把它们熔铸成一个民族。斯巴达的伯罗奔尼撒同盟就是这一类。后来雅典领导的同盟也一样。成员保留各自的公民身份。它们可以尝试退出，也可能被迫留下。强迫显示的是权力。它不能说明有一个民族已经悄然生成。
:::
:::proof
这里的同盟由誓词、战时领导权和贡赋建成。它们有一个领衔的城邦，没有共同的公民名册。一个人不会因为他的城邦跟随斯巴达就不再是科林斯人。离盟之争是按同盟与恐惧来议论的，不是按背叛民族来议论的。强迫（凡有发生之处）是一个强邦压迫弱邦。帝国可以由这种关系长出来。民族不是同一种生长。

会构成对这条论断的反证的，是一个取消了成员公民身份、撤换其长官的同盟，各城邦因此不再是政治共同体。共同的铸币、共同的神庙、一场战争由一位统帅，都不够。如果后面某一章显示雅典在挤压盟邦，那是希腊语世界内部的一个帝国，不是一个正在苏醒的民族。
:::

## 两个传统与一段漫长的间隔

年表允许两个早期数字，并告诉我们如何读它们。公元前776年是首届奥林匹克竞技会的传统年代，那是后世的传统，不是一份有记录的希腊民族的诞生。公元前594年是梭伦任执政官的传统年代。“传统”的意思是：这是希腊人后来一致讲述的一个年份，出自本身就是编纂而成的表录。它不意味着我们拿到了会议记录。

:::example 两个传统之间的间隔 {#ex-gap}
竞技会的传统年代是公元前776年。梭伦任执政官的传统年代是公元前594年。它们之间相隔多少年？两个年代都是公元前。（把推理写进笔记；结果是一个年数。）
:::solution
两个年份都在公元之前，所以这不是一个公元前到公元的跨度。跨越纪元界限时要用的那步额外调整在这里不适用。没有一个第0年需要插入或去掉。用较早的年份数减去较晚的年份数：776减594等于182。用加法核对：594加182等于776。两个传统相隔182年。
:::
:::

这182年的间隔正是这张图的意义所在。其中没有任何东西能用一个民族填满这些年。殖民城邦、僭主政治、邻居之间的战争，以及已经坐落在东方诸城之侧的波斯帝国，全都落在圆点没有讲述的那段间隔里。两个标记不等于主张只发生过两件事。

:::example 一句编造的编年史句子 {#ex-invented}
下面这句话是为这一课编造的。它不是史料。“公元前776年，希腊民族举行了首届竞技会；公元前594年，梭伦为这个民族写下了政制。”对照两个年代的限度来读这句话。什么——如果有的话——能从中抢救出来？什么是惹祸的部分？
:::solution
能抢救的只有那两个数字，而它们是传统年代。公元前776年标记的是奥林匹亚的竞技会，不是民族的诞生。公元前594年标记的是雅典的一个执政官任期，不是全希腊的政制。梭伦不是所有希腊语者的长官。这句话留下了真实的年份，却换了主语。要把它当真，需要一条近世同时代的存迹说过这些话，而 [[sources/evidence]] 仍然会把那条存迹与推论分开。后世编年史的自豪感是一种教训，不是它目击的事实。我们没有那条存迹。这句话仍然是编造的。
:::
:::

:::example 两个城邦并排 {#ex-pair}
把古风时代的斯巴达与雅典并排。斯巴达有国王、监察官和希洛人。雅典的传统里有公元前594年梭伦的执政官任期。两者都是城邦。这是否意味着它们有共同的政制，或一个希腊国家？
:::solution
这意味着它们是同一种单位——有领土的公民共同体——但不是同一个共同体。它们的制度不同。梭伦的年份是雅典的传统，不是斯巴达的传统，也不是民族的传统。共用“城邦”这个标签，就像共用 city-state 这个标签。它不会合并公民身份。从“两者都是城邦”走到“因此存在一个希腊国家”的读者改变了尺度，这正是 [[#thm-no-state]] 拦住的错误。
:::
:::

## 波斯就在隔壁

一部把自身关在封闭的“希腊世界”里、只在开战时让波斯以怪物形象登场的城邦史，已经预先认定希腊政治是自足封闭的。事实并非如此。阿契美尼德（Achaemenid）帝国——下一章的国王大流士（Darius）和薛西斯（Xerxes）所属的波斯王权——就是爱琴海东岸的大国。在我们定年的第一场战役之前，爱奥尼亚（Ionia）的希腊语城邦就已经必须以臣民、邻居或反叛者的身份与它打交道。

我们不去编造臣服始于哪一年。年表里没有它，本章也不需要替代的数字。我们需要的是一条在先的在场：公元前490年的马拉松（Marathon）之战，是与一个早有自己的政治的帝国交锋——它有国王、总督（satrap）、贡金、驻军，也有希腊臣民。它不是一个成型民族与一个无形东方之间的初次相遇。战争由 [[greece/persian-wars]] 来讲。我们在这里的任务只是拒绝把这个帝国留作反衬。

同一种拒绝也改变了殖民城邦的位置。殖民城邦不是插进虚空的一块欧洲。它是这片拥挤地景中的新城邦：东边有一个帝国，西边和北边还有别的民族，它们不会因为希腊语者到来就变成了序幕。城邦是对那片地景的地方性回答，不是一个大陆的胚胎。从一个现代名字里倒推出一种文明——反对这种做法的长篇论证见 [[sources/naming-europe]]。

:::example 给三个对象分类 {#ex-sort}
把这三样东西归入本章的范畴。第一，叙拉古，西西里的一个希腊人移居点。第二，奥林匹亚，竞技会的圣所，其传统开端是公元前776年。第三，爱琴海亚洲一侧的波斯帝国的一个总督辖区。其中哪些——如果有的话——是城邦？哪个是圣所而不是首都？哪个是非希腊帝国的一个单位？
:::solution
叙拉古是一个殖民城邦，因此就是一个新的城邦，有自己的公民，不是一个希腊民族的县，也不是母城的县。奥林匹亚是一座圣所和一场节庆，其“共有”的意义只是许多城邦前往那里。它不是首都，传统年代也没有使它成为首都。波斯总督辖区是阿契美尼德帝国的一个单位，一个有自己的指挥链的真实国家。它不是城邦，也不是作为一种情绪的“东方”。若把叙拉古称为行省、把奥林匹亚称为首都、把总督辖区在希腊军队到来之前称为历史之外的空白，这次分类就失败了。
:::
:::

:::quiz
教科书说：“各城邦是希腊民族的县，而在开战之前波斯不在故事之中。”哪一种纠正与本章相符？
- [ ] 两半都对，因为共同的语言就是国家，而波斯是一个遥远的符号
- [ ] 城邦确实是县，但波斯早已是近旁的大国
- [x] 城邦是有领土的公民共同体；殖民城邦是新的城邦；波斯早已是邻国的帝国
- [ ] 根本没有什么城邦，只有波斯帝国和它的希腊仆从
:::solution
教科书那句话在本章的两道检验上都不合格。[[#def-polis]] 和 [[#def-colony]] 拒绝县的类比，[[#thm-no-state]] 拒绝民族的说法。波斯帝国在下一章各场战役之前就已经是爱琴海旁的大国，并且拥有希腊臣民。第四个选项矫枉过正：城邦是真实的。它们只是不是县。
:::
:::

## 反对意见与一个案例

共同行动比民族称呼是更有力的一条反对意见。希腊语者确实曾在共同的旗帜下作战、请示过神谕、称其他民族为野蛮人。批评者说：若这都不算民族性，那没有哪个古代民族通得过检验，这条检验便只是现代的陷阱。

这条检验就是故意现代的。我们没有说古风时代的希腊人拒绝过 nation-state 这个词。我们说：把希伦人圈进一个国家的现代画法，用的是一个后来的物件，而证据撑不起它。共同的战事是同盟。神谕可以被每个城邦各自听从或无视。“野蛮人”标记的是言语和习俗。它不任命内阁。时代的错位在于责怪他们没通过一场现代的考试。不让这场考试被倒写在他们身上，正是 [[#def-nation]] 的作用。

斯巴达的领导权持续不止一个夏天，是另一条反对意见。持久是一个领衔城邦可以拥有的权力。只有当跟随者不再各自是公民共同体时，它才成为一个民族。它们没有停止。后来对雅典的战争是城邦之间的战争，也就是 [[#thm-league]] 所说的那种，不是同一个疆域内部的内战。

案例。这段是编造的，不是史料。“竞技会自公元前776年举办之后，希腊人作为一个民族走向成熟。公元前594年，梭伦赋予这个民族以政制形态。殖民城邦是它海外的各县，僭主则是对民族性格的偏离。波斯可以等着。”

每一句都在不同的检验上失败。竞技会是节庆传统，“走向成熟”是一条情节。梭伦的年份属于雅典。按 [[#def-colony]]，殖民城邦是新的城邦。“偏离”预先假定了它需要的民族性格。波斯就在故事旁边。修补它要换主语，而不是换数字：一场节庆，一个雅典传统，若干新的公民共同体，若干本地发生的夺权，一个邻国的帝国。只有当一条同时代铭文把这些殖民城邦称为一个希腊当局的辖区时，[[#thm-no-state]] 才需要重新讨论。一张学校地图做不到这一点。

:::warning 从荷马到民主制的兴起
常见的迷思是一条单一的情节线：先有诗歌，然后竞技会，然后立法者，然后民族，最后民主制作为全篇的归宿。它同时坏在三个地方。诗歌在本年表中没有年代，我们也不替它编一个年份；即便能定年，诗歌也不是政制。我们确实拥有的年代——公元前776年和公元前594年——是关于一场节庆和一个雅典官职的传统，不是同一个民族生命史的章节。民主制是一个城邦后来的一部政制，其狭隘程度将由 [[greece/athenian-democracy]] 写明；它不是斯巴达的目的，不是一个从未采用它的殖民城邦的目的，也不是隔壁波斯帝国的目的。一条需要让此前每个世纪都成为通往雅典的台阶的情节，是先选定了雅典，再布置证据。
:::

:::history 是传统，不是生日
公元前776年是首届奥林匹克竞技会的传统年代，那是后世传统，不是一份有记录的希腊民族的诞生。公元前594年是梭伦任执政官的传统年代，在后世的讲述中那是雅典的一个官职。这两个传统之间漫长的间隔里满是城邦、殖民城邦、僭主政治和一个已经就位的波斯帝国。它不是一个国家的童年。
:::

## 通向何处

与那个帝国的战争就在后面。[[greece/persian-wars]] 让各城邦保持为城邦，并追问：一旦把波斯当作一个有自己的政治的国家来对待，公元前490年和公元前480年会发生什么。这里的方法就是 [[sources/evidence]]、[[sources/time-and-names]] 和 [[sources/scale]] 的方法：传统不是证人，一个年份可以承载一条论断，一句关于节庆的真话不是一句关于大陆的真话。这一章没有生出任何一种文明。

:::summary
- 城邦是公民共同体加上一块领土，不是民族国家，也不是“希腊”。
- 领土之内许多人不是公民，一个城邦的公民身份到不了邻邦。
- 殖民城邦是新的城邦，不是母城或希腊王国的县。
- 僭主政治和同盟都坐落在这个城邦世界里；两者都不是一个正在生成的民族。
- 公元前776年和公元前594年是传统，相隔182年，哪一个都不建立国家。
- 共同的语言、祭祀和竞技会是真实的，但它们不是政府。
- 波斯已经是爱琴海旁的大国，不是为下一章攒下的一个符号。
:::

## 练习

:::exercise 从梭伦到克利斯提尼 {level=1 check="86"}
梭伦任执政官的传统年代是公元前594年。克利斯提尼的改革常被定在公元前508年。这两个公元前年代之间相隔多少年？不要插入一个第0年。（输入年数。）
:::solution
两个年代都是公元前，所以直接相减：594减508等于86。用加法核对：508加86等于594。这段跨度没有进入公元纪元，没有第0年需要调整。答案是86。
:::
:::

:::exercise 给移居点定名 {level=1 check="polis"}
一个母城把移居者送往海外。他们立法、选举或任命自己的长官，后来还与母城交战。用本章的词汇说，这个移居点是县（county）、行省（province），还是城邦（polis）？（输入一个词：county、province 或 polis。）
:::solution
[[#def-colony]] 说，殖民城邦是一个新的城邦。与母城交战是一个独立公民共同体的行为，不是一个县或一个希腊国家的行省的行为。根本不存在一个能让它当行省的希腊国家。答案是 polis。
:::
:::

:::exercise 这是哪一类年代 {level=1 check="tradition"}
年表称公元前776年是首届奥林匹克竞技会的传统年代，并说这是后世传统，不是一份有记录的希腊民族的诞生。用一个词说，我们在这里是把公元前776年当作传统（tradition）还是当作奠基（foundation）？（输入 tradition 或 foundation。）
:::solution
本课遵循年表。这个数字被印出来，是因为传统作为传统是真实的。它不是作为一个民族的奠基年份被印出来的。答案是 tradition。
:::
:::

:::exercise 奥林匹亚不是首都 {level=2}
有人说：“奥林匹亚是希腊的首都，因为竞技会于公元前776年在那里开办，所有希腊人都来了。”用 [[#def-polis]] 和 [[#thm-no-state]] 说明：奥林匹亚是什么？传统年代没有证明什么？
:::solution
奥林匹亚是一座有节庆的圣所。许多城邦与它有往来，一条准入规则可以标记谁在竞技会的意义上算希腊人。首都应当是各城邦之上的某个政府的驻地。这样的政府并不存在。公元前776年是这场节庆的传统年代，不是一个国家开门办公的记录。赴会的规模属于圣所。首都的规模属于国家。那句话把前者升格成了后者。
:::
:::

:::exercise 斯巴达的国王 {level=2}
斯巴达有世袭国王、长老会议、监察官、公民大会和庞大的不自由人口。有读者由此推论：斯巴达就是希腊民族，其他城邦是它在同一疆域之下依附于它的属从。这个推论在哪里断裂？
:::solution
斯巴达是一个城邦：一个有领土的公民共同体，以及一套建立在希洛人之上的严苛秩序。那里的王权是斯巴达的制度，不是希伦人的冠冕。其他城邦保留自己的公民身份和自己的长官。盟邦可以在战争中追随斯巴达而仍然是城邦，这正是 [[#thm-league]] 里的区分。仍然是政治共同体的属从，是同盟者或承压的臣民，不是一个民族的县。这个推论断裂的地方，是把一座城邦的政制当成一个大陆的国家。
:::
:::

:::exercise 交战的殖民城邦 {level=2}
两个母城建立了殖民城邦。一代人之后，这些殖民城邦相互开战，其中一个还与自己的母城开战。一篇概述仍称这些殖民城邦为“希腊人海外的各县”。这些战事显示了什么？这篇概述在让“县”这个词变得准确之前还需要什么？
:::solution
战事显示的是各自独立的政治意志。一个县不会像外国那样向首都开战，一个国家的两个县也不会像国家那样开战。每个殖民城邦都符合 [[#def-colony]]：一个新的公民团体。这篇概述需要这样的证据：存在一个希腊当局向它们征税、任命它们的长官、把它们之间的战争当作一个司法辖区内部的叛乱来处理。我们手里有的反而是各城邦以自己的名义使用武力。“县”这个词加入了证据中并不存在的一个国家。
:::
:::

:::exercise 民族的童年 {level=3}
一位作者接受了你的减法，同意公元前776年与公元前594年之间相隔182年，但仍然说：“这段间隔就是希腊民族的童年。共同的竞技会证明共同的国家，梭伦是这个民族的立法者，年代稍晚。”用一段简短的论证回应。把真实的东西和情节分开。
:::hint
不需要新的年份数字。问一问：一场节庆能授权什么，一个雅典传统能授权什么，什么证据才能让“民族”这个词用得不亏。
:::
:::solution
算术可以为真，情节可以为假。公元前776年授权的是一场节庆的传统年代。公元前594年授权的是一个雅典执政官任期的传统。182年的间隔不授权任何关于“成熟”的说法，因为“童年”已经预设了那个民族，才声称能量度它的成长。共同的竞技会证明共同的实践和一座许多城邦使用的圣所。它们不证明长官、金库或公民身份——那正是 [[#thm-no-state]] 要求而没有找到的东西。梭伦是一座城邦记忆中的人物。称他为民族的立法者，就是把他从雅典搬进一个并不存在的国家。真实的余数是：一个节庆传统，一个后起的雅典传统，以及一段由许多城邦构成的漫长时期。能挽救这位作者的证据，是在这两个年代之间有一个有佐证的希伦人平时政府。关于竞技会和梭伦的传统不是那个政府。
:::
:::

:::exercise 停放波斯 {level=3}
一部古风城邦简史结尾说：“外交始于公元前490年波斯登场那年。”作者说这样很整洁，因为有年代的战役正从那时开始。为什么这种整洁是关于各城邦的错误——尽管公元前490年是一个真实的年份，下一章你会用到它？
:::hint
把第一场有年代的战役与第一段政治关系分开。然后问：爱琴海旁边已经坐着一种什么样的权力——不必为它的到来编造年份。
:::
:::solution
公元前490年的马拉松是一场有年代的真实战役，它属于 [[greece/persian-wars]]。把它当作“外交”的起点，是把我们早期年份表上的空白变成世界史上的空白。早在那场战役之前，爱奥尼亚的希腊城邦就已经是波斯帝国的臣民、邻居或反叛者。我们不编造臣服开始的年份，因为年表里没有它。我们也不需要那个年份来拒绝那张封闭的地图。波斯是一个有总督和贡金的王国，不是幕外待命的符号。一部把它停放至公元前490年的历史，会让各城邦显得自足，然后把这些战争误读为一个民族与一个外人之间的初次相撞。各城邦从来不是它们自己那片海上仅有的国家。
:::
:::
