如果城邦不是希腊民族，那么它是什么？

后世的欧洲地图喜欢以这样一个民族开篇：万事俱备，只差一纸文书。古风时代说希腊语的各个共同体却不合这幅图景。它们是许多政治体，而不是一个等待命名的政治体。它们跨海建立新的共同体，彼此攻战，并与一个根本不是希腊的强权为邻：早在本图谱所定年的任何一场战役之前，波斯帝国就已是爱琴海对岸的大国。

本章的问题是：如何称呼这些共同体中的一个，而不偷偷塞进“民族”的概念。共同的语言、共同的神祇和共同的赛会都是证据的一部分，但它们不是政制。殖民城邦、同盟和僭主政治属于这幅图景，统一的希腊国家则不属于。可以用作标记的数字有两个，都必须当作传统来对待：公元前776年对应奥林匹克赛会，公元前594年对应梭伦（Solon）任执政官。两个数字都不是出生证明。

公开的时间线把同样的负年份印作BC，这里的标注则是BCE。两个标记都在公元之前，所以它们之间的间隔只需做一道普通的减法，下文将给出算式。

## 公民与领土

:::definition 城邦 {#def-polis}
**城邦**（polis，复数poleis）是公民共同体及其领土。后来所说的city-state（城市国家）指的是同一种单位，nation-state（民族国家）则不是。城邦的领土通常包括一座城镇和一片乡村。许多在这片领土上生活和劳作的人并不是公民：公民家庭的妇女与担任公职的男子地位不同，外邦人、依附劳动者和奴隶也都不属于公民团体。

城邦不是“希腊”，也不是通往现代国家途中的一个阶段。它可大可小，可以濒海也可以在内陆，可以实行民主制、寡头制，也可以处于僭主统治之下。决定这一单位的不是规模，也不是政制的色彩，而是公民共同体和领土。
:::

公民身份是地方性的，并且世代相承。一个人在本邦是公民，到了邻邦就是外邦人。不存在一份所有说希腊语的城市都同意遵守的文书。公民通常共享而外人没有的，是一组因城邦而异的权利：对土地的权利、在祭祀中的位置、诉诸法庭的资格，以及在政制允许分享的范围内参与决策。寡头制不是失败的城邦，而是公民团体可能采取的形式之一。

乡村使这幅图景不至于缩小为几座神庙。公民、外邦人和奴隶都在田地、家户和作坊中劳作。城镇里有官员、集会场所和神殿，但这一切都不是希腊人（Hellenes）的首都——根本没有这样的首都。雅典、斯巴达、科林斯和底比斯是四个城邦，而不是一个舞台布景，由其中两个代表其余所有城邦。

城邦这一类型可以推广到什么程度，历史学家看法不一。有些说希腊语的共同体以较松散的地区方式组织起来；本课程最后一章所讲的马其顿是一个王国，并不是雅典的翻版。这场争论关乎一个类别的边缘，并不会在中心放进一个希腊国家。

:::definition 殖民城邦 {#def-colony}
这里所说的**殖民城邦**（colony），是由一个旧城邦建立的新城邦，而不是希腊王国的一个郡县。旧城邦称为母邦，移民则成为新共同体的公民团体。他们可能保留对创建者的崇拜、一段起源传说和一份宗教上的纽带，但他们自己立法，也自己结仇。他们不是行政区划，因为根本没有一个可供他们充当辖区的希腊国家。
:::

移民的足迹远及西西里和意大利南部、黑海、北非，以及埃及的商站。当地的邻人往往不说希腊语，新城邦以贸易、通婚、剥削或战争与之打交道。殖民城邦也可能与自己的母邦交战，而郡县这样做之后是不会仍然是郡县的。我们不给这些城邦的建立定年，因为年表没有列出这些年份。叙拉古（Syracuse）可以作为西西里的一个城邦被提及，而无须给出建城年份。别的书中给出的精确年份，在达到[[sources/evidence]]的标准——存迹与推论分开——之前，仍然只是传统。

古风时代所说的**僭主**（tyrant），是在城邦中夺取个人权力的人。这个词标示的是获取权力的途径，还不是后来那种怪物式的漫画形象，也不是每年例行的官职。有些僭主因营建和节庆而为人铭记，有些则因对政敌施暴而为人铭记。两种记忆都可能出于党派立场，而后世作者偏爱以合法政府收场的道德剧。我们可以使用这个范畴，而不接受那出戏。僭主倒台之后，公民共同体依然存在；他的生平不是一个民族的传记。

斯巴达显示了这一定义的宽度。它是一个城邦，有两位世袭国王、一个长老会议、每年选任的监察官（ephors）和一个公民大会。它还凌驾于黑劳士（helots）之上——这是一群被束缚在拉科尼亚和美塞尼亚土地上的不自由人口。他们是这一结构的组成部分，而不是某种理想下的注脚：少数公民依靠不自由的劳动为生，因而常常对会让本土无人看管的远征心存顾虑。斯巴达不是民主制，也不是“多利安民族”。我们不给出黑劳士或全权公民的数字。年表没有确定这样的数字，而一个生动的数字只会伪造精确。

在这里，雅典是另一个作为实例的城邦，而不是古风时代的归宿。梭伦任执政官的传统年代是公元前594年。传统把免除债务、按财产划分政治权利等级归功于他，后来的雅典人则把这件事讲成本邦法治的开端。一座城市关于其立法者的故事，是记忆与冲突的证据，而不是会议记录，也不是全希腊的大会。日期为何能承载论断，见[[sources/time-and-names]]。这个日期承载的是“梭伦当时担任了雅典的官职”，而即便这句话也来自传统。

与克里斯提尼（Cleisthenes）相联系的民主制是另一件事，通常定于公元前508/507年，是[[greece/athenian-democracy]]的主题。这里提到它，只是为了打断一条情节线：梭伦的传统年代不会仅仅因为时间流逝，就长成一部希腊人的民主政制。从传统所记的执政官任期到后来对雅典部落的改革，其间隔着一代人的更替，中间还夹着一段僭主统治，而且依然没有希腊国家。

## 什么不是国家

:::definition 民族国家 {#def-nation}
本图谱所说的**民族国家**（nation-state），是一种现代主张：一个民族与一个国家相重合，即只有一种公民身份，并有一个代表这个民族的政府。这个说法是我们的，不是古风时代的称号；我们把它当作一项检验。城邦通不过这项检验，因为它的公民团体只是希腊语世界的一个片段；希腊语世界也通不过，因为它没有统一的政府。
:::

人们确实有一个更大的称呼。他们可以自称希腊人，赛会也可以拒绝不被视为希腊人的参赛者。这在圣所中是一条真实的边界，是一场节庆的族群和宗教资格审查。谁算希腊人，有时也有争议。但关于参赛资格的争执不是人口普查，也不是政府部门。

:::theorem 不存在希腊国家 {#thm-no-state}
共同的语言、祭祀和赛会并没有构成一个希腊民族国家。没有统一的公民身份，没有统一的官员体系，也没有统一的常备军队。为某一场战争结成的同盟，并不是那个缺失的国家。这条论断并不是说说希腊语的人毫无共同之处——他们的共同之处很多。但共同的文化不是政制。
:::
:::proof
证据就是考古、铭文和后世叙事所能让我们绘出的政治地图。各城邦以自己的名义相互开战，也以自己的名义议和。科林斯的公民并不因此就是底比斯的公民。在同样的几十年里，斯巴达和雅典运行着各不相同的制度。殖民城邦作为独立的国家行事，对母邦也不例外。许多城邦共同行动时——它们在对抗波斯时就会如此——靠的是结盟，有的城邦缺席，指挥权也要经过协商。这是同盟，不是国家。

希腊语是一族方言，而不是一部法令。一座圣所之所以能吸引许多城市的来访者，正因为它不是任何一方的首都。能够推翻[[#thm-no-state]]的，是一条近乎同时代的存迹，显示有一批官员，其命令在和平时期约束着作为整体的各希腊语共同体，并且有一座金库、一种这些共同体都服从的公民身份。一场节庆、一首英雄史诗或一幅涂成同一种颜色的现代地图，都不算数。如果这样的政府出现了，这条论断就必须放弃。但它没有出现。
:::

:::quiz
下列哪一项会是希腊国家的证据，而不只是共同文化的证据？
- [ ] 许多城市都参加的奥林匹亚（Olympia）节庆
- [ ] 爱琴海周围通行的一族希腊语方言
- [x] 一批官员，其命令在和平时期以统一的公民身份约束作为整体的各城邦
- [ ] 一则希腊英雄并肩作战的神话
:::solution
按照[[#def-nation]]的检验，国家需要政府和公民身份，而不仅仅是相似性。赛会、方言和英雄神话，正是[[#thm-no-state]]所说的那些真实却不充分的东西。第三个选项正是论证所说缺失的那类存迹；如果这样的存迹出现，论断就不能成立。
:::
:::

族群方面的反驳是认真的，但仍不充分。希腊人可以自称希腊人，也可以把别人挡在赛会之外。这条边界是真实的，但它是圣所的规则，而不是政府部门。你可以是一个希腊人，同时在邻邦是没有投票权、也没有土地的外邦人。[[sources/scale]]所警告的，正是把一句关于节庆的真话升格为一句关于国家的假话。

:::theorem 同盟仍然不是民族 {#thm-league}
城邦同盟是国家之间的协议，而不是把它们熔铸为一个民族。斯巴达的伯罗奔尼撒同盟属于这一类，后来由雅典领导的同盟也是如此。成员保留各自的公民身份。它们可以试图退出，也可能被迫留下。强迫显示的是权力，并不表明一个民族已悄然形成。
:::
:::proof
这里的同盟由誓约、战时的领导权和缴纳的贡赋构成。它们有一个领导城邦，却没有共同的公民名册。一个人不会因为自己的城邦追随斯巴达，就不再是科林斯人。关于退盟的争论，是按照同盟关系和恐惧来展开的，而不是按照背叛民族来展开的。发生强迫时，那是强邦对弱邦施压。帝国可以由此生长出来，但民族不是同一种生长。

能够推翻这条论断的，是一个废除成员公民身份、撤换其官员的同盟，以致各城邦不再是政治共同体。共同的钱币、共同的圣所，或一场战争中的统一指挥，都不足以说明问题。如果后面某一章显示雅典在压榨盟邦，那是希腊语世界内部的一个帝国，而不是一个正在苏醒的民族。
:::

## 两个传统与一段漫长的间隔

年表允许使用两个早期数字，并说明了应当如何解读它们。公元前776年是首届奥林匹克赛会的传统年代，这是后世的传统，而不是希腊民族诞生的文献记录。公元前594年是梭伦任执政官的传统年代。所谓“传统”，是指希腊人后来一致讲述的年份，依据的是本身也经过编纂的名录，而不是说我们掌握了会议记录。

:::example 两个传统之间的间隔 {#ex-gap}
奥林匹克赛会的传统年代是公元前776年，梭伦任执政官的传统年代是公元前594年。两者相隔多少年？两个年代都在公元前，这段跨度中不涉及公元0年的问题。（把推理过程写在笔记里，结果是一个年数。）
:::solution
两个年份都在公元之前，所以这不是从公元前某年到公元某年的跨度，跨越纪元分界时所需的额外调整在这里不适用，也没有公元0年需要插入或去掉。用较早年份的数字减去较晚年份的数字：776减594等于182。用加法核对：594加182等于776。两个传统相隔182年。
:::
:::

这182年的间隔正是下图的要点。其中没有任何东西用一个民族来填满这些年。殖民城邦、僭主政治、邻邦之间的战争，以及早已与东方诸城相邻的波斯帝国，都处在这两个点没有讲述的间隔之中。两个标记并不意味着只发生过两件事。

:::example 一句虚构的编年史文字 {#ex-invented}
下面这句话为本课而虚构。它不是史料。“公元前776年，希腊民族举办了首届赛会；公元前594年，梭伦为这个民族制定了政制。”请对照这两个年代的限度来阅读这句话。其中有什么可以挽救？造成破坏的又是什么？
:::solution
能挽救的只有这两个数字，而它们是传统年代。公元前776年标记的是奥林匹亚的赛会，而不是一个民族的诞生；公元前594年标记的是雅典的一个执政官任期，而不是全希腊的政制。梭伦并不是所有说希腊语之人的官员。这句话保留了真实的年份，却偷换了话题。要把它升格为证据，需要一条近乎同时代、确实说过这些话的存迹，而即便如此，[[sources/evidence]]仍会把存迹与推论分开。后世编年史的自豪是一种教训，而不是它亲眼目睹的事实。我们没有这样的存迹，这句话依然是虚构的。
:::
:::

:::example 并列的两个城邦 {#ex-pair}
把古风时代的斯巴达与雅典并列。斯巴达有国王、监察官和黑劳士；雅典的传统中有公元前594年梭伦的执政官任期。两者都是城邦。这是否意味着它们共有一部政制，或同属一个希腊国家？
:::solution
这意味着它们是同一种单位——有领土的公民共同体——而不是同一个共同体。它们的制度各不相同。梭伦的年代是雅典的传统，不是斯巴达的传统，更不是民族的传统。共用“城邦”这个标签，就像共用city-state这个标签一样，并不会使公民身份合而为一。从“两者都是城邦”推到“因此存在一个希腊国家”的读者，改变了尺度，这正是[[#thm-no-state]]所拦阻的错误。
:::
:::

## 波斯早已近在咫尺

一部把城邦关在封闭的“希腊世界”里、直到战争爆发才让波斯以怪物形象登场的城邦史，已经预先认定希腊政治是自成一体的。事实并非如此。阿契美尼德（Achaemenid）帝国——下一章中大流士（Darius）和薛西斯（Xerxes）作为国王统治的波斯王权——是爱琴海东岸的大国。在我们所定年的第一场战役之前，爱奥尼亚（Ionia）说希腊语的城市就已经必须以臣属、邻邦或叛乱者的身份与它打交道。

我们不杜撰这种臣属开始的年份。年表中没有这个年份，本章也不需要一个替代的数字。我们需要的事实是：波斯早已在场。公元前490年的马拉松（Marathon）之战，是与一个早有自身政治的帝国的交锋——它有国王、总督、贡赋、驻军，也有希腊臣民。这并不是一个成形的民族与一个面目模糊的东方之间的初次相遇。战争由[[greece/persian-wars]]讲述，我们在这里的任务只是拒绝把这个帝国留作陪衬。

同样的拒绝也改变了对殖民城邦的看法。殖民城邦不是栽进一片虚空的一块欧洲，而是一个拥挤环境中的新城邦：东边有一个帝国，西边和北边还有其他民族，他们不会因为说希腊语的人到来就变成序幕。城邦是对这一环境的地方性回应，而不是一块大陆的种子。反对从一个现代名称中倒推出一种文明的更完整论证，见[[sources/naming-europe]]。

:::example 为三个对象归类 {#ex-sort}
按照本章的范畴为以下三者归类。第一，叙拉古，希腊人在西西里建立的城市。第二，奥林匹亚，传统上始于公元前776年的赛会所在的圣所。第三，波斯帝国在爱琴海亚洲一侧的一个行省（satrapy）。其中哪一个——如果有的话——是城邦？哪一个是圣所而不是首都？哪一个是非希腊帝国的一个单位？
:::solution
叙拉古是殖民城邦，因而是一个拥有自己公民的新城邦，既不是希腊民族的郡县，也不是其母邦的郡县。奥林匹亚是一座圣所和一场节庆，所谓共享，只是许多城市都来到这里；它不是首都，传统年代也不会使它成为首都。波斯行省是阿契美尼德帝国的一个单位，这个帝国是一个拥有自己指挥体系的真实国家。行省不是城邦，也不是作为一种情绪的“东方”。如果把叙拉古称为行省，把奥林匹亚称为首都，或者把波斯行省说成在希腊军队到来之前处于历史之外的空白，这次归类就失败了。
:::
:::

一本教科书说：“各城邦是希腊民族的郡县，而在战争爆发之前，波斯不在故事之中。”哪一种纠正符合本章？

- [x] 城邦是有领土的公民共同体；殖民城邦是新的城邦；波斯早已是邻近的帝国
- [ ] 根本没有城邦，只有波斯帝国和它的希腊仆从
:::solution
教科书的这句话两项检验都通不过。[[#def-polis]]和[[#def-colony]]拒绝郡县的类比，[[#thm-no-state]]拒绝民族的说法。在下一章的战争之前，波斯帝国就已经是爱琴海旁的大国，并拥有希腊臣民。第四个选项则矫枉过正：城邦是真实存在的，只不过不是郡县。
:::
:::

## 反驳与实例

共同行动是比族群称呼更有力的反驳。说希腊语的人确实曾在共同的旗帜下作战，求问神谕，并把其他民族称为蛮族。批评者会说：如果这都不算民族，那么任何古代民族都通不过这项检验，可见这项检验只是一个现代的陷阱。

这项检验有意采用现代标准。我们并不是说古风时代的希腊人拒绝过“民族国家”这个说法，而是说：现代人围绕希腊人画出一个国家，用的是一个后来才有的对象，而证据支撑不了它。共同的战役是同盟。神谕可以由各城邦分别遵从或置之不理。“蛮族”标示的是语言和习俗，它并不组建内阁。真正的时代错置，是责怪他们没有通过一场现代的考试。[[#def-nation]]的作用，就是不让这场考试被倒过来强加在他们身上。

另一条反驳是，斯巴达的领导地位持续了不止一个夏天。持久是领导城邦可能拥有的一种权力；只有当追随者不再是各自的公民共同体时，它才会成为一个民族。而它们并没有不再是公民共同体。后来针对雅典的战争是城邦之间的战争，即[[#thm-league]]所说的情形，而不是同一个国度内部的内战。

实例。下面这段文字是虚构的，不是史料。“公元前776年赛会开始之后，希腊人逐渐成熟为一个民族。公元前594年，梭伦赋予这个民族以政制形式。殖民城邦是它在海外的郡县，僭主则是对民族性格的偏离。波斯可以以后再说。”

每一个分句都通不过不同的检验。赛会是节庆传统，“逐渐成熟”是一条情节线。梭伦的年代属于雅典。按照[[#def-colony]]，殖民城邦是新的城邦。“偏离”预设了它所需要的民族性格。波斯早已在故事旁边。修补的办法是更换主语，而不是更换数字：一场节庆，一个雅典的传统，若干新的公民共同体，若干地方性的夺权，一个邻近的帝国。只有当一条同时代的铭文把这些殖民城邦称为某个希腊权力机构的辖区时，[[#thm-no-state]]才需要重新讨论。一幅教学地图做不到这一点。

:::warning 从荷马到民主制的上升
常见的迷思是一条单一的情节线：先有诗歌，再有赛会，再有立法者，再有民族，最后是作为全部归宿的民主制。它同时在三处站不住脚。诗歌在本年表中没有定年，我们也不会为它们杜撰年份；即便能定年，一首诗也不是政制。我们确实拥有的年代，即公元前776年和公元前594年，是关于一场节庆和一个雅典官职的传统，而不是同一个民族生命史中的章节。民主制是某一个城邦后来的一种政制，其局限之处[[greece/athenian-democracy]]将会说明；它不是斯巴达的目的，不是某个从未采用它的殖民城邦的目的，也不是邻近的波斯帝国的目的。一条需要让此前每个世纪都成为通往雅典之台阶的情节线，是先选定了雅典，再去安排证据。
:::

:::history 是传统，不是诞辰
公元前776年是首届奥林匹克赛会的传统年代，这是后世的传统，而不是希腊民族诞生的文献记录。公元前594年是梭伦任执政官的传统年代，在后世的讲述中，那是雅典的一个官职。这两个传统之间的漫长间隔里，充满了城邦、殖民城邦、僭主政治和一个早已存在的波斯帝国。它不是一个国家的童年。
:::

## 通向何处

接下来是与这个帝国的战争。[[greece/persian-wars]]让城邦始终作为城邦出现，并追问：一旦把波斯当作一个有自身政治的国家，公元前490年和公元前480年发生了什么？这里的方法，就是[[sources/evidence]]、[[sources/time-and-names]]和[[sources/scale]]的方法：传统不是证人，日期可以承载论断，一句关于节庆的真话也不是一句关于大陆的真话。本章并没有造就任何一种文明。

:::summary
- 城邦是公民共同体加上领土，不是民族国家，也不是“希腊”。
- 领土之内的许多人不是公民，一个城邦的公民身份也不能带到邻邦。
- 殖民城邦是新的城邦，不是母邦或某个希腊王国的郡县。
- 僭主政治和同盟都处于这个城邦世界之中，两者都不是一个正在形成的民族。
- 公元前776年和公元前594年都是传统年代，相隔182年，两者都没有建立国家。
- 共同的语言、祭祀和赛会是真实的，但它们不是政府。
- 波斯早已是爱琴海旁的大国，而不是留给下一章的一个符号。
:::

## 习题

:::exercise 从梭伦到克里斯提尼 {level=1 check="86"}
梭伦任执政官的传统年代是公元前594年，克里斯提尼的改革通常定于公元前508年。这两个公元前年代之间相隔多少年？不要插入公元0年。（请输入年数。）
:::solution
两个年代都在公元前，所以直接相减：594减508等于86。用加法核对：508加86等于594。这段跨度没有进入公元纪年，所以无须为公元0年作调整。答案是86。
:::
:::

:::exercise 为移民城市定名 {level=1 check="polis"}
一个母邦向海外派出移民。他们自己立法，选举或任命自己的官员，后来还与母邦交战。用本章的词汇来说，这个移民城市是郡县（county）、行省（province），还是城邦（polis）？（请输入一个词：county、province或polis。）
:::solution
[[#def-colony]]指出，殖民城邦是一个新的城邦。与母邦交战是一个独立公民共同体的行为，而不是某个希腊国家的郡县或行省的行为——根本不存在一个可以让它充当行省的希腊国家。答案是polis。
:::
:::

:::exercise 哪一类年代 {level=1 check="tradition"}
年表称公元前776年为首届奥林匹克赛会的传统年代，并指出这是后世的传统，而不是希腊民族诞生的文献记录。用一个词回答：我们在这里把公元前776年当作传统（tradition），还是当作奠基（foundation）？（请输入tradition或foundation。）
:::solution
本课遵循年表。这个数字之所以印出来，是因为这个传统作为传统是真实的；它并不是作为一个民族的奠基年份而印出来的。答案是tradition。
:::
:::

:::exercise 奥林匹亚不是首都 {level=2}
有人说：“奥林匹亚是希腊的首都，因为赛会公元前776年在那里开始，所有希腊人都来了。”请运用[[#def-polis]]和[[#thm-no-state]]，说明奥林匹亚是什么，以及这个传统年代不能证明什么。
:::solution
奥林匹亚是一座举办节庆的圣所。许多城邦与它有往来，一条准入规则可以标示谁在赛会上算作希腊人。首都则应当是统辖各城邦的某个政府的所在地，而这样的政府并不存在。公元前776年是这场节庆的传统年代，而不是一个国家开始运转的记录。参加赛会属于圣所的尺度，首都属于国家的尺度。这句话把前者升格成了后者。
:::
:::

:::exercise 斯巴达的国王 {level=2}
斯巴达有世袭国王、长老会议、监察官、公民大会和大量不自由人口。一位读者由此推断，斯巴达就是希腊民族，其他城市则是它在同一国度中的附属。这个推论在哪里断裂？
:::solution
斯巴达是一个城邦：一个有领土的公民共同体，以及一套建立在黑劳士之上的严酷秩序。那里的王权是斯巴达的制度，而不是全体希腊人的王冠。其他城邦保留着自己的公民身份和自己的官员。盟邦可以在战争中追随斯巴达，同时仍是城邦，这正是[[#thm-league]]中的区分。仍然作为政治共同体存在的附属者，是盟友或承受压力的臣属，而不是一个民族的郡县。这个推论的断裂之处，在于把一个城市的政制当成了覆盖整块大陆的国家。
:::
:::

:::exercise 交战的殖民城邦 {level=2}
两个母邦各自建立了殖民城邦。一代人之后，这些殖民城邦相互交战，其中一个还与自己的母邦交战。一篇概述仍称这些殖民城邦为“希腊人的海外郡县”。这些战事表明了什么？这篇概述还需要什么，“郡县”一词才会准确？
:::solution
这些战事表明存在各自独立的政治意志。郡县不会像外国那样向首都开战，同一国家的两个郡县也不会像国家那样彼此交战。每个殖民城邦都符合[[#def-colony]]：一个新的公民团体。这篇概述需要的证据是：有一个统一的希腊权力机构向它们征税、任命它们的官员，并把它们之间的战争当作同一管辖范围内的叛乱来处理。而我们实际掌握的，是各城邦以自己的名义使用武力。“郡县”一词添加了一个证据中并不存在的国家。
:::
:::

:::exercise 民族的童年 {level=3}
一位作者接受了你的减法，同意公元前776年与公元前594年相隔182年，却依然说：“这段间隔就是希腊民族的童年。共同的赛会证明了共同的国家，而梭伦是这个民族的立法者，年代稍晚一些。”请用一段简短的论证回应，把真实的部分与情节分开。
:::hint
你不需要新的年份数字。问一问：一场节庆能支持什么，一个雅典的传统能支持什么，什么样的证据才能让“民族”成为恰当的名词。
:::
:::solution
算术可以是对的，情节却可以是错的。公元前776年支持的是一场节庆的传统年代，公元前594年支持的是雅典一个执政官任期的传统年代。182年的间隔并不支持任何关于“成熟”的说法，因为“童年”一词预设了它声称要衡量其成长的那个民族。共同的赛会证明的是一种共同的做法，以及一座许多城市都使用的圣所；它们不能证明存在官员、金库或公民身份，而这些正是[[#thm-no-state]]所要求、却没有找到的东西。梭伦是某一座城市记忆中的人物，称他为民族的立法者，就是把他从雅典搬进一个并不存在的国家。真实的剩余部分是：一个节庆的传统，一个较晚的雅典传统，以及一段由众多城邦构成的漫长时期。能为这位作者挽回论点的证据，是在这两个年代之间有据可查的一个希腊人的平时政府。关于赛会和梭伦的传统，并不是这样的政府。
:::
:::

:::exercise 把波斯搁在一边 {level=3}
一部古风时代城邦简史这样结尾：“对外关系始于公元前490年，那一年波斯登场。”作者说这样很整齐，因为有确切年代的战役正是从那时开始的。尽管公元前490年是一个真实的年份，下一章也会用到它，为什么这种整齐是对城邦的误解？
:::hint
把第一场有年代可考的战役与第一段政治关系区分开来。然后问：爱琴海旁早已存在的是一种什么样的权力？不必为它的到来杜撰年份。
:::
:::solution
公元前490年的马拉松之战是一场有确切年代的真实战役，属于[[greece/persian-wars]]。把它当作“对外关系”的开端，就是把我们早期年份表上的空白，变成了世界上的空白。在这场战役之前，爱奥尼亚的希腊城邦就已经是波斯帝国的臣属、邻邦或叛乱者。我们不杜撰臣属开始的年份，因为年表中没有它；而要拒绝那幅封闭的地图，我们也并不需要这个年份。波斯是一个有总督和贡赋的王国，而不是一个在幕后待命的符号。一部把它搁置到公元前490年的历史，会让城邦显得自成一体，进而把这些战争误读为一个民族与一个外来者的初次碰撞。城邦从来不是它们自己那片海上仅有的国家。
:::
:::
