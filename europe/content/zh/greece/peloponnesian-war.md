伯罗奔尼撒战争（Peloponnesian War）是一场什么样的战争？

这是一场希腊国家之间的战争。它始于公元前431年，以公元前404年雅典投降告终。一方是雅典及其在爱琴海拥有的帝国，也就是[[greece/persian-wars]]中那个已经变成一种强权的同盟；另一方是斯巴达及其盟邦，其中包括科林斯和底比斯。波斯也卷入其中，主要是在后期，主要是出钱，但它并不是这场战争的意义所在。在雅典投票的男性公民，就是[[greece/athenian-democracy]]所界定的那个群体。他们的失败没有废除城邦，也没有揭示什么“希腊人的人生观”。苏格拉底（Socrates）在公元前399年受审并被处死，距投降已有五年。那是雅典的一个事件，而不是这场战争的意义。

## 希腊人之间

:::definition 伯罗奔尼撒战争 {#def-war}
按照通常的定年，**伯罗奔尼撒战争**（Peloponnesian War）是公元前431年雅典、斯巴达及各自盟邦之间爆发的战争，以公元前404年雅典投降告终。这个名称是后人为一系列战事取的便利称呼，它既不是一场战役，也不是某个希腊民族内部的内战——当时并不存在这样一个可以发生内战的民族。
:::

:::definition 雅典帝国 {#def-empire}
在这场战争中，**雅典帝国**（Athenian empire）指雅典凌驾于爱琴海其他城邦之上的权力：贡赋、被迫的效忠，以及加害盟邦和中立者的能力。它不是雅典城邦之外的另一个国家，也不是后来罗马那样的行省体系。盟邦仍然是城邦，只是处在压力之下的城邦。
:::

修昔底德（Thucydides）是雅典人，亲历了这场战争的一部分，并写下了它的历史。他把公开争论的纠纷与他所认为的更真实的原因区分开来：雅典势力的增长，以及由此在斯巴达引起的恐惧。这是他的论证，而且相当有力，因为帝国是真实的，斯巴达也确实选择了战争。但这并不是一条结果必然随之而来的定律。科林斯心怀不满，盟邦想要退出，雅典选择了作战而不是解散帝国。按照[[sources/argument]]的用法，原因必须是本来可能不同的那类事情，而这里有好几件事本来都可能不同。我们不引用修昔底德的原文。他在开篇借伯里克利（Pericles）之口发表的一篇演说，是他希望说出的话的证据，而不是公民大会的记录。在战争爆发时的事件进程中，伯里克利被提到了名字，但他没有活到雅典投降。我们不给他的去世定年，因为年表中没有这个年份。

战争期间，一场瘟疫袭击了雅典。许多人死去，其中包括叙述中视为显要的人物。我们不给出总数：年表没有提供，而一个虚假的总数只会给灾难添加装饰。当时的人求助于宗教解释。但一场疾病并不是对一种政制的裁决。斯巴达不是民主制，却也没有因为有国王和监察官（ephors）而免于战争的其他残酷。瘟疫可以解释城邦内部的苦难和政治紧张，却不能解释希腊国家为什么相互交战。

战争期间，雅典对抵抗或保持中立的希腊城邦动用武力。小城邦米洛斯（Melos）被毁灭。修昔底德在那里安排了一场对话。我们不引用这场对话，也不给这次毁灭定年，因为年表中没有这个年份。这一事件是一个城邦对另一个城邦施加帝国暴力的证据，而不是希腊伦理的概括。其他希腊人，包括在别的事件中的斯巴达，获胜时也曾屠杀和奴役。把这种做法归因于民主制本身，是一种解读，而不是这片废墟所允许的唯一解读。

:::theorem 这是一场希腊国家之间的战争 {#thm-greek}
伯罗奔尼撒战争是在希腊城邦之间进行的，一方是雅典帝国，另一方是斯巴达同盟。波斯的援助，尤其是后期的援助，是真实的，但它并没有使这场战争成为希腊与波斯之间的冲突，也没有使它成为一场文明冲突的预演。公元前404年的失败，是一个帝国及一个城市的战争政策的失败，而不是城邦的终结。
:::
:::proof
公元前431年的交战双方就是证据。雅典及其领导或胁迫的城邦，与斯巴达及其同盟中的城邦作战。后来的叙拉古（Syracuse）是西西里的一个希腊城邦。修昔底德放在开篇的争端，包括科西拉（Corcyra）和波提狄亚（Potidaea），都是希腊国家之间的争端。当斯巴达需要一支舰队、而波斯帝国愿意提供支持时，波斯的作用才增大。一位总督和一位波斯王子各自谋求自身利益，这是寻常的帝国政治。他们没有改变开战各方军队的身份，也没有在另一方造就一个统一的希腊国家。

能够推翻这条论断的，是这样一场战争：从公元前431年直到投降，主力军队一方是波斯人，另一方是统一的希腊。那是上一章的格局，而不是本章的。能够推翻最后一句话的，是雅典作为一个政治共同体在公元前404年消失。按照通常所说的和约条款，雅典投降，失去帝国，交出舰队，拆除城墙。随后，一个由斯巴达扶植、后世称为三十僭主（the Thirty）的寡头政权，在一段时间内杀害政敌，包括公民和外侨（metic）。我们不统计死者人数。这个寡头政权没有成为这座城市的永久形态，民主制得到了恢复。我们不给恢复的时间定年。恢复这一事实本身就足以表明，公元前404年终结的是一场战争和一个帝国，而不是城邦。
:::

## 西西里，不标年份

战争进行中，雅典决定派遣一支远征军前往西西里，进攻叙拉古。与这次远征相联系的将领包括亚西比德（Alcibiades）和尼西阿斯（Nicias）。远征失败了，人员和战船都有损失，这一损失削弱了这个帝国城市。我们不给出兵力数字，因为年表没有给出；我们也不给出年份——别处有时印出的那个年份不在本年表中，所以这里不印。这次失败很重要，但它没有结束战争。战斗一直持续到公元前404年雅典投降。一个从西西里直接跳到雅典陷落的故事，跳过了一段战争，而这段战争的起点我们同样无法定年。诚实的说法要简短得多：雅典对另一个希腊城邦的一次大规模行动失败了，希腊国家之间的战争仍在继续。

需要把握的正是最后这一事实。西西里并不因为是一个岛屿，就成了一个不再属于希腊的旁支插曲。叙拉古是一个城邦。这次远征是希腊人的力量被用来对付希腊人的力量，而这正是[[#thm-greek]]对整场战争的论断。省去年份并不是为模糊而模糊，而是遵循一条规则：一个数字必须是我们可以视为确定的数字。

:::example 二十七年 {#ex-span}
战争始于公元前431年，雅典于公元前404年投降。这段跨度有多少年？为什么在任何实质意义上，投降都不是“爆发之后的下一件事”？
:::solution
431减404等于27。核对：404加27等于431。两个年代都在公元前。这二十七年里有一场瘟疫、帝国暴力、一次我们不定年的失败的西西里远征、波斯对斯巴达舰队的支持，以及不止一个阶段的战事。这两个数字是[[#def-war]]的起讫。它们并不是说两者之间的一切都不可讨论，而是说我们讨论中间这段时，不杜撰年表没有列出的年份。答案是27年。
:::
:::

:::example 关于西西里可以说什么 {#ex-sicily}
写出本章所允许的、关于西西里远征的最有力的一句话。然后写出两种被禁止的补充，一个是年份，一个是士兵人数，并说明各自为什么被禁止。
:::solution
允许的句子是：伯罗奔尼撒战争期间，雅典派遣远征军进攻西西里的希腊城邦叙拉古；远征失败，人员和战船都有损失；战争继续进行，直到公元前404年雅典投降。年份被禁止，是因为年表没有给这次远征定年，本课不得自行补上一个。士兵人数被禁止，是因为年表中没有确定的数字，而一个精确的总数会是虚假的精确。政治上的要点——在一场以公元前404年告终的战争中，希腊人对希腊人——不需要这两种补充中的任何一种。
:::
:::

后来击败雅典的舰队是斯巴达的舰队，它是在波斯的支持下建立起来的。接着是一次我们不定年的海上失败，然后是公元前404年的投降。其中的讽刺是政治上的，而不是文学上的：提洛同盟（Delian League）当初为对抗而建立的那个帝国，帮助斯巴达打败了领导这个同盟的城市。波斯依然是一个有自身利益的国家，而不是一个在公元前479年就退出舞台的符号。斯巴达赢得了战争，但也没有因此成为一个希腊民族。它扶植了一个亲己的寡头政权，随后便像历来的霸主一样发现：赢得战争并不等于统治一个城邦的世界。

:::example 先是投降，然后是审判 {#ex-pair}
把公元前404年与公元前399年并列。前一年雅典投降；后一年苏格拉底受审并被处死。两者各是什么性质的事件？这五年的间隔使你不能说什么？
:::solution
404减399等于5。投降是雅典帝国和这场战争在军事上和政治上的终结。审判则是一个仍然设有法庭的城邦内部的司法事件，发生在寡头政权上台又倒台、民主制已经恢复之后。这段间隔排除了“苏格拉底随战争一同逝去”的说法，也排除了“审判是雅典陷落的原因”的说法。陷落在前，审判在后。它们发生在同一座城市，意义却并不相同。五年足以让政体不止一次地改变，仅此一点，就是不把公元前399年当作公元前431年的道德教训的理由。
:::
:::

## 不是这场战争的意义

苏格拉底案，是在恢复后的民主制下，一个由男性公民组成的雅典陪审法庭对一名公民作出的判决。通常所说的罪名是不敬神和腐蚀青年。我们不引用柏拉图（Plato）后来写的申辩，也不引用色诺芬（Xenophon）后来写的那一篇。这些文本各有立场，而不是庭审记录。陪审法庭运用的是[[greece/athenian-democracy]]中的那些制度：男性公民、法庭、投票。哲学不是这座城市的政策，大多数雅典人也不是哲学家，其他希腊城市也没有举行这场审判。这次处死关乎一个城邦在战败之后的法律、宗教和政治。它不是希腊人的人生观，因为并不存在一种单一的希腊人的观念，等着与他一同被处决。

:::theorem 这场审判不是这场战争的意义 {#thm-socrates}
苏格拉底在公元前399年受审和被处死，是雅典的一个事件，发生在公元前404年投降之后五年。它们既不是伯罗奔尼撒战争的意义，也不是希腊思想的概括。如果说本章为这场战争主张某种意义，那么这种意义是政治的：一个由城邦组成的帝国，在与其他城邦的战争中失败了。
:::
:::proof
年代是第一重证据。公元前399年的审判不可能是公元前404年投降的原因，也不可能是公元前431年开始的那些战事的内容。制度是第二重证据。判他有罪的法庭，是一个由男性公民组成的民主法庭，而不是全体希腊人（Hellenes）的大会，也不是三十僭主——这个寡头政权的杀戮属于投降之后紧接着的余波，是另一种罪行。柏拉图和色诺芬是事后写作的，他们写的是一场围绕一个人和一座城市的争论。这场争论是雅典思想史的一部分。把它当作战争本身，就是重犯[[sources/scale]]所说的尺度错误：一句关于一场审判的真话，变成了一句关于整整一代人战事的假话。

能够推翻这条论断的证据是：希腊国家是为苏格拉底而打这场战争的；或者他的死是由一个全希腊的共同权威决定的；或者投降与审判是同一个行为。那五年的间隔、政权的更替，以及战争通常的主题——帝国与同盟——就是反证。能够推翻另一种错误——即认为这场审判没有发生过、或在雅典无足轻重——的，是公元前399年这一事实本身。我们并没有犯那种错误。这场审判是真实的，也是地方性的。
:::

一种颇有影响的修昔底德读法，把这部书看作一个警告：民主制的雅典因过度而自取灭亡——过于冒进，伯里克利之后缺乏节制，人民无法坚持一贯的政策。你可以把这当作对他叙述的一种解读来介绍，却不能当作这场战争本身的事实来陈述。公民大会确实作出过灾难性的选择，西西里远征就是其中之一，修昔底德对后来的领导人也很严厉。但斯巴达同样选择了一场长期战争，波斯的出资者选择了资助一支舰队，盟邦选择了反叛。一出关于民主制过度的悲剧，是一种把这些选择编排成道德教训的论证。[[#thm-greek]]才是可以检验的那句话。它不需要这个道德教训，而这个道德教训也不是它的升级版。

失败并没有终结希腊的政治生活。雅典城邦延续了下来，其他城邦也是如此。公元前404年之后，希腊国家依然相互作战，依然结成同盟，依然争论政制。从投降到公元前338年马其顿在喀罗尼亚（Chaeronea）击败一个希腊同盟，相隔66年。这些年并不是一片贴着“衰落”标签的空白，而是政治生活。[[greece/alexander]]的起点是公元前338年获胜的那个王国，而不是城邦的尸体。哲学在同样的几十年里也在继续，包括在一座处死过一位哲学家的城市里。那次处决没有让哲学成为这座城市的外交政策，也没有终结哲学或政策中的任何一个。

:::example 一个虚构的道德教训 {#ex-invented}
下面这段话是虚构的，不是史料。“伯罗奔尼撒战争（公元前431年至公元前404年）是民主制的悲剧性过度，而公元前399年苏格拉底之死就是它的道德教训。西西里远征——年份不必核对——因为人民是自由的而毁灭了这座城市。”请把修昔底德式的论证与你真正能够定年的事实区分开来。
:::solution
公元前431年和公元前404年这两个起讫是真实的，公元前399年也确有一场审判。“民主制的悲剧性过度”是对修昔底德的解读，或者是对修昔底德读者的解读，并不是与投降处于同一层面的事实。斯巴达、波斯和盟邦也都有所作为。西西里远征并没有单独毁灭这座城市，远征失败之后战争仍在继续，我们也不为它补上年份。“因为人民是自由的”忘记了：这个民主制是一个由成年男性公民组成的群体，而这种意义上的自由包括了一个帝国。苏格拉底之死在投降之后五年，发生在恢复后的民主制之下，因此不可能是解释战败的那个道德教训。可以定年的事实是：一场希腊国家之间的战争，以及后来的一场审判。悲剧只是一种可选的情节。
:::
:::

## 反驳与实例

来自目击者的反驳最为有力。修昔底德亲历了这场战争，而且态度严肃。如果他认为雅典的权力和民主制的失控是这段历史的核心，那么拒绝这个道德教训的后世读者似乎就显得傲慢。回答并不是说他是一个糟糕的证人，而是说：一个证人可以加工演说、挑选事件，同时仍然是我们所拥有的最好的连贯记述。他关于斯巴达恐惧的判断，在帝国确实令人恐惧的范围内，是一个我们可以接受的论证。但他对公民大会的刻画，并不能证明民主制作为一种政体类型导致了战争。寡头制的斯巴达也必须表决开战，不论斯巴达以何种方式表决。一部书既是关于一场战争的证据，也是关于一位作者的证据。[[sources/evidence]]不允许用后者取代前者。

第二条反驳说，让西西里远征不标年份，会使本课比印出年份的教科书更弱。真正的弱，是假装这次远征没有发生过。印出一个年表没有列出的年份，则是另一种弱，一种借来的精确。没有数字，你也可以讲授一场灾难；但你不能讲授一个你无权为之担保的数字。

实例。一句虚构的编年史式句子写道：“公元前404年，希腊民族向斯巴达投降，哲学随苏格拉底而死，城邦就此终结。”每个分句都含有一个真实的片段和一个错误的主语。公元前404年投降的是雅典，而不是希腊民族。苏格拉底死于公元前399年，而不是在投降之时，哲学也没有随他而死。城邦延续了下来，包括雅典在内，经历了此后一系列战争，直到公元前338年的喀罗尼亚之战，并在那之后依然存在。修补几乎完全是在替换名词。把年份放回正确的分句之后，它们已经完成了很大一部分工作。

:::warning 不是民主制的悲剧，也不是文明的冲突
两种迷思在这场战争中交汇。一种把它变成后来某场文明冲突的预演，让波斯或“东方”充当真正的敌人；但公元前431年的交战方是希腊国家。另一种把它变成一出悲剧，并把民主制的过度当作事实。那是对修昔底德的一种解读，应当标明是他的论证或后人关于他的论证，而不是事件本身。雅典是一部分男子的民主制，它作出过可怕的选择；斯巴达不是那样的民主制，却同样把战争拖得很长。要说清谁在作战、谁投降、谁在五年后受审，两种迷思都用不上。
:::

:::history 起讫年代，然后是一场审判
伯罗奔尼撒战争始于公元前431年，战争爆发时被提到名字的雅典领导人中有伯里克利；战争以公元前404年雅典投降告终。苏格拉底在公元前399年受审并被处死。这场审判是雅典的一个事件，发生在投降之后五年，并不是这场战争的意义。
:::

## 通向何处

城邦在投降之后延续下来，随后一个并非城邦的王国击败了它们的同盟。[[greece/alexander]]从公元前338年的喀罗尼亚之战讲起，追问亚历山大（Alexander）在公元前323年去世终结了什么。[[greece/athenian-democracy]]讲的是在雅典一方作战的公民群体，包括其中的排斥。[[greece/poleis]]说明了为什么这些群体之间的战争不是一场民族内战。如何不让一位历史学家的道德教训变成标签，见[[sources/argument]]。

:::summary
- 战争始于公元前431年，雅典于公元前404年投降，跨度为27年。这是一场希腊国家之间的战争。
- 雅典作为一个拥有帝国的城邦作战，斯巴达与盟邦一起作战。有些希腊城邦抵抗雅典而被毁灭。叙拉古是西西里的一个希腊敌手。
- 西西里远征是这场战争的一部分。本章不给出它的年份和兵力数字。这次失败本身并没有结束战争。
- 波斯的支持在后期帮助了斯巴达，但这并没有使这场战争成为波斯战争或文明冲突。
- 战争期间，一场瘟疫袭击了雅典。这里不给出死亡总数。一场疾病不是对民主制的裁决。
- 苏格拉底于公元前399年在恢复后的民主制下受审并被处死，距投降五年。这场审判既不是这场战争的意义，也不是希腊人的人生观。
- 失败没有终结城邦或希腊的政治生活。从公元前404年到公元前338年的喀罗尼亚之战，这种政治生活又持续了66年。
:::

## 习题

:::exercise 战争的长度 {level=1 check="27"}
战争始于公元前431年，雅典于公元前404年投降。这两个年代相隔多少年？（请输入年数。）
:::solution
431减404等于27。核对：404加27等于431。两个年份都在公元前。答案是27。
:::
:::

:::exercise 从投降到审判 {level=1 check="5"}
雅典于公元前404年投降，苏格拉底于公元前399年被处死。投降与审判相隔多少年？（请输入年数。）
:::solution
404减399等于5。审判在后，不可能是投降的原因。答案是5。
:::
:::

:::exercise 投降之后 {level=1 check="66"}
雅典于公元前404年投降，马其顿于公元前338年在喀罗尼亚击败一个希腊同盟。这两个年代相隔多少年？（请输入年数。）
:::solution
404减338等于66。核对：338加66等于404。这段间隔是城邦之间的政治生活，而不是一片空洞的衰落。答案是66。
:::
:::

:::exercise 一句话说西西里 {level=2}
用一句话说明西西里远征发生了什么，不用年份，也不用人数。然后说明，这句话仍然足以证明这是一场什么样的战争。
:::solution
雅典派军进攻西西里的希腊城邦叙拉古，这支军队被歼灭，但这并没有结束那场一直持续到公元前404年的战争。这足以证明[[#thm-greek]]的一部分：战事是希腊人对希腊人；其中的一场灾难既不是对波斯的战争，也不是公元前431年的一场战役。缺失的年份和人数限制的是精确程度，而不是敌人的身份。
:::
:::

:::exercise 波斯的金钱 {level=2}
斯巴达在波斯的支持下建立了一支舰队，随后击败了雅典。一位读者由此得出结论：伯罗奔尼撒战争因而是一场波斯战争，就像公元前480年的那场战争一样。这个结论在哪里站不住脚？
:::solution
它在谁在作战、何时作战这一点上站不住脚。公元前480年，是一位波斯国王出兵攻打一个城邦同盟。而在这场战争中，公元前431年开启冲突的陆军和海军都是希腊人的，公元前404年的投降是雅典向斯巴达投降。波斯的支持是一个国家选择出资帮助希腊的一方对抗另一方。这表明阿契美尼德（Achaemenid）帝国仍有自己的利益，却没有改变交战方的名义。[[#thm-greek]]承认这种援助，但拒绝这种改名。
:::
:::

:::exercise 不是希腊人的人生观 {level=2}
苏格拉底于公元前399年在雅典被处死。为什么把这次处死称为希腊人的人生观，或称为公元前431年开始的那场战争的意义，是一个错误？
:::solution
这次处死是一个城邦中一个由雅典男性公民组成的陪审法庭，以不敬神和腐蚀青年的罪名作出的判决，发生在这个城邦投降五年之后。其他希腊城市没有参与这场审判的投票。大多数雅典人不是哲学家，哲学也不是这座城市的政策。柏拉图和色诺芬后来写的申辩，我们不引用，它们也不是庭审记录。一种为“希腊人”所共有的人生观，正是[[greece/poleis]]已经否定的那种民族对象。从公元前431年到公元前404年，这场战争的政治内容是帝国与同盟。一场在战争结束之后举行的审判，不可能是这一内容。
:::
:::

:::exercise 解读不是事实 {level=3}
一位教师说：“修昔底德表明，这场战争是民主制过度的悲剧。把它当作事实来教，因为他是同时代人。”请回应。你可以给他的论证留出位置，但必须说明：如果读者拒绝他的道德教训，仍然成立的事实是什么。
:::hint
把帝国、斯巴达的恐惧和公民大会的灾难性决策保留为可以讨论的内容。然后指出那些无法仅仅纳入“民主制过度”的交战方和选择。
:::
:::solution
修昔底德的论证可以作为他的论证来教。雅典的权力是真实的，斯巴达畏惧这种权力，雅典公民大会也作出了一些被他描述为背离早先节制的选择，西西里远征就是其中之一。这是对一部书的严肃解读，但它本身并不是事实，因为同时代人可以加工演说，却仍然不能把一个道德教训变成原因。斯巴达并不是那样的民主制，却选择了一场长期战争；波斯当局选择资助一支舰队；盟邦选择反叛。这些选择本来都可能不同。如果读者拒绝这个悲剧性的道德教训，依然成立的事实是[[#thm-greek]]：从公元前431年到公元前404年，一场希腊国家之间的战争，一方是一个帝国，最后是投降，以及一个延续下来的城邦。道德教训是可选的，起讫年代却不是。
:::
:::

:::exercise 城邦没有终结 {level=3}
有人把公元前404年当作希腊政治生活的终结，把公元前399年当作它的葬礼。请用公元前404年、公元前399年和公元前338年这三个年份，说明什么延续了下来，以及什么样的证据会使“终结”之说成立。
:::hint
先把三个年份排序。然后问：一个延续着的城邦会是什么样子，而一次真正的终结必须消除什么。
:::
:::solution
顺序是：公元前404年投降；公元前399年，在一座仍有生机的城市里举行了一场审判；后来是公元前338年的喀罗尼亚之战，马其顿在这场战役中击败了一个城邦同盟——这些城邦仍然存在，才谈得上被击败。从公元前404年到公元前338年是66年。在三十僭主的寡头统治之后，民主制在雅典得到恢复，尽管我们不给恢复的时间定年。希腊国家之间的同盟和战争仍在继续。苏格拉底之死是恢复后的民主制所做的事，而这只有在政治生活依然存在时才有可能。只有当公元前404年把城邦作为共同体彻底废除，以致公元前338年已没有这样的对手可打，并且公元前399年是思想的葬礼而不是一场审判时，“终结”之说才能成立。年份所显示的恰恰相反。公元前404年终结的是雅典的帝国和它的战争，而不是希腊人从事政治的习惯。
:::
:::
