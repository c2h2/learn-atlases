伯罗奔尼撒战争（Peloponnesian War）是一场什么样的战争？

它是一场希腊诸国之间的战争。它始于公元前431年，终于公元前404年雅典的投降。一边是雅典，以及它在爱琴海握有的帝国——[[greece/persian-wars]] 里的那个同盟，在那个同盟变成一种权力之后。另一边是斯巴达和她的盟邦，其中有科林斯和底比斯。波斯插手了，主要在后期，主要用金钱，而它不是这场战争的意义。在雅典投票的公民男子，就是 [[greece/athenian-democracy]] 里定义的那个团体。他们的失败没有废除城邦，也没有揭示什么“希腊的生活方式”。苏格拉底（Socrates）在公元前399年被审判并处死，在投降之后五年。那是一次雅典事件。它不是这场战争的意义所在。

## 希腊人之间

:::definition 伯罗奔尼撒战争 {#def-war}
**伯罗奔尼撒战争**（Peloponnesian War）按通常的纪年，是公元前431年在雅典与斯巴达及其盟邦之间开始的那场战争，终于公元前404年雅典投降。这个名字是后来为方便起见给一系列战事加的称呼，不是一场战役，也不是一个希腊民族内部的内战。并没有这样一个民族可供它打内战。
:::

:::definition 雅典帝国 {#def-empire}
**雅典帝国**（Athenian empire）在这场战争中，指雅典对爱琴海其他城邦握有的权力：贡金、被强制的忠诚，以及加害盟邦与中立者的能力。它不是脱离雅典城邦之外的另一个国家，也不是后世罗马式的那种行省体系。盟邦们仍然是城邦。它们是在压力之下的城邦。
:::

修昔底德（Thucydides）是一个雅典人，战争中他在场参与了一部分，后来写下了它的历史。他区分两样东西：在公开场合被争论的纠纷，和他自己呈现的更真实的原因——雅典势力的增长，以及它在斯巴达引起的恐惧。那是他的论证，而且是一个强有力的论证，因为帝国是真实的，斯巴达也确实选择了战争。但结果必然随之而来，并不是一条规律。科林斯有积怨。盟邦想退出。雅典选择了开战，而不是解散帝国。原因，正如 [[sources/argument]] 使用这个词时所要求的，必须是本可以不同的那类东西。这几桩里的好几桩，本可以不同。我们不会引用修昔底德原文。他在战争之初放进伯里克利（Pericles）嘴里的一篇演说，证据的是他想让人说出的话，不是公民大会的会议记录。在事态的叙述中，战争爆发时点到了伯里克利的名字。他没有活到投降那一天。我们不给他之死定年。那一年不在年表里。

一场瘟疫在战争期间袭击雅典。许多人死去，其中包括叙事视为重要人物的人。我们不给出总数。年表没有给出，而一个虚假的总数只会为一场灾难添加装饰。同时代的人转向宗教解释。一场疾病不是对一部政制的判决。斯巴达不是民主制，却也没有因为有国王和监察官（ephors）而免于战争的其他残酷。瘟疫解释的是城邦内部的苦难与政治紧张。它不解释希腊诸国为什么在互相攻打。

战争期间，雅典对抵抗的或置身事外的希腊城邦使用武力。米洛斯（Melos），一座小城邦，被摧毁了。修昔底德在那里安排了一场对话。我们不引用那场对话，也不给毁灭定年，因为那一年不在年表里。这个事件是一个城邦对另一个城邦使用帝国暴力的证据。它不是希腊伦理的概要。其他希腊人，包括在其他事件中的斯巴达人，在获胜时也使用过屠杀和奴役。把这种习性归因于民主制本身，是一种解读。它不是残骸所能允许的唯一种解读。

:::theorem 这是一场希腊诸国之间的战争 {#thm-greek}
伯罗奔尼撒战争是在希腊诸城邦之间打的：一边是雅典的帝国，另一边是斯巴达的同盟。波斯的援助——尤其在后期的——是真实的，但它没有把这场战争变成希腊与波斯之间的冲突，也没有把它变成一场文明冲突的预演。公元前404年的失败，是一个帝国和一座城市的战争政策的失败，不是城邦的终结。
:::
:::proof
证据就是公元前431年的交战双方。雅典和它领导或胁迫的城邦，作战对象是斯巴达和她同盟中的城邦。后来的叙拉古（Syracuse）是西西里的一个希腊城邦。修昔底德放在开头的争端，包括科基拉（Corcyra）和波提狄亚（Potidaea），是希腊诸国之间的争端。波斯的角色在斯巴达需要舰队、而帝国愿意提供资助时增长起来。一位总督和一位波斯王子各自追逐自己的利益，那是寻常的帝国政治。他们没有改变开战诸军的身份，也没有在另一边造成一个统一的希腊国家。

会构成对这条论断的反证的，是这样一场战争：从公元前431年到投降，一边的主力军队是波斯人，另一边是统一的希腊。那是上一章的形状，不是本章的。会构成对最后一句话的反证的，是雅典作为一个政治共同体在公元前404年消失。雅典投降，失去帝国，并按通常的媾和条款交出舰队和城墙。一个由斯巴达背书、后世称为三十僭主（the Thirty）的寡头政体，随后一时之间杀害政治敌人——公民和侨居者（metic）。我们不计算死者人数。这个寡头政体没有变成这座城市的永久形态。民主制回来了。我们不给回归定年。回归本身就足以表明，公元前404年终结的是一场战争和一个帝国，不是城邦。
:::

## 西西里，不带年份

雅典在战争期间决定派遣一支远征队前往西西里，进攻叙拉古。与之相联系的将领包括亚西比德（Alcibiades）和尼基阿斯（Nicias）。远征失败了。人员与战船损失殆尽，这场失败削弱了那座帝国城市。我们不陈述兵力数字，因为年表没有陈述。我们不陈述年份。别的书里有时会印出的那个年份不在本年表里，所以这里也不印。失败是重要的，而它没有终结战争。战斗一直继续，直到公元前404年的投降。一个从西西里直接跳到城破的故事，跳过了一段战争，而这段战争我们也拒绝从一个缺失的开始去定年。诚实的句子更短。雅典对另一个希腊城邦的一次大规模行动失败了，希腊诸国之间的战争继续进行。

最后这个事实才是要拿住的。西西里不是一个因为是一座岛就不再是希腊的插曲。叙拉古是一个城邦。这支远征是希腊权力对希腊权力的使用，而这正是 [[#thm-greek]] 关于整场战争所说的。把年份省掉不是为模糊而模糊。那是一条规则：一个数字必须是我们被允许当作定论来对待的数字。

:::example 二十七年 {#ex-span}
战争始于公元前431年。雅典在公元前404年投降。这段跨度是多少年？为什么投降在任何实在的意义上都不是“爆发之后的下一件事”？
:::solution
431减404等于27。核对：404加27等于431。两个年代都是公元前。二十七年里装着一场瘟疫、帝国暴力、一次我们不定年的对西西里的失败的远征、波斯对一个斯巴达舰队的支持，以及不止一个阶段的战事。这两个数字是 [[#def-war]] 里的括号。它们不是说两者之间的任何东西都不可讨论。它们说的是：我们讨论中段，而不发明年表没有列出的年份。答案是27年。
:::
:::

:::example 关于西西里你能说什么 {#ex-sicily}
写出本章所允许的最强的一句关于西西里远征的话。然后写两个被禁止的补充，一个是年份，一个是士兵数目，并说明每一个为什么被禁止。
:::solution
被允许的句子：在伯罗奔尼撒战争期间，雅典派遣了一支远征队进攻叙拉古，西西里的一个希腊城邦；远征失败了，损失了人员与战船；战争继续，直到公元前404年雅典投降。年份被禁止，是因为年表没有为这支远征定年，而本课不得补上一个。士兵数目被禁止，是因为没有任何这样的数字在年表里成为定论，而一个精确的总数将是虚假的精确。政治上的要点——希腊人对希腊人，在一场结束于公元前404年的战争之内——不需要这两个补充中的任何一个。
:::
:::

后来击败雅典的那支舰队是斯巴达的，它是靠波斯的支持建起来的。然后是一次我们不定年的海战失败，然后是公元前404年的投降。这层讽刺是政治的，不是文学的。提洛同盟（Delian League）当初为抗击而建立的那个帝国，帮助斯巴达打败了领导同盟的那座城市。波斯仍然是一个有自己的利益的国家。它不是一个在公元前479年就下台的符号。斯巴达赢得了战争，也没有变成一个希腊民族。它扶植一个有利的寡头政体，然后发现——霸主们都会发现——打赢与统治一个城邦的世界不是一回事。

:::example 投降，然后是一场审判 {#ex-pair}
把公元前404年和公元前399年并排。前一年雅典投降。后一年，苏格拉底受审并被处死。每一个是什么类型的事件？五年的间隔阻止你说什么？

404减399等于5。投降是雅典帝国和这场战争的军事与政治终结。审判是一个仍然有法庭的城邦内部的司法事件，发生在一个寡头政体来过又走、民主制已经恢复之后。这段间隔阻止“苏格拉底随战争一同死去”这个句子，也阻止“审判是雅典陷落的原因”这个句子。陷落在前，审判在后。它们共享一座城市，不共享一个意义。五年足够政体形态改变不止一次，这已经是不把公元前399年当作公元前431年之道德教训的一个理由。
:::

## 不是这场战争的意义

苏格拉底的审判是一个雅典的陪审法庭——由公民男子组成——在恢复了的民主制下判决一个公民。通常的指控是不敬神明和败坏青年。我们不引用柏拉图（Plato）后来写的辩护词，也不引用色诺芬（Xenophon）后来写的那一篇。那些文本各有立场。它们不是会议记录。陪审法庭使用的是 [[greece/athenian-democracy]] 的那些制度：公民男子，一个法庭，一次表决。哲学不是这座城市的政策。大多数雅典人不是哲学家。其他希腊城市没有举行过这场审判。这次死刑关乎的是法律、宗教与政治，地点是一座战败之后的城邦。它不是希腊的生活方式，因为并不存在一个单一的希腊观点，等着与他一同被处决。

:::theorem 审判不是这场战争的意义 {#thm-socrates}
苏格拉底公元前399年的审判与死亡是一次雅典事件，在公元前404年投降之后五年。它们不是伯罗奔尼撒战争的意义，也不是希腊思想的概要。这场战争的意义——就本章主张一个而言——是政治的：一个城邦组成的帝国输掉了与其他城邦的战争。
:::
:::proof
年代是第一重证据。公元前399年的审判不可能是公元前404年投降的原因，也不可能是公元前431年开始的那些战事的内容。制度证据是第二重。定他罪的那个法庭是一个公民男子的民主法庭，不是希伦人（Hellenes）的大会，也不是三十僭主——那个寡头的杀戮属于投降之后紧接的余波，是另一种罪行。柏拉图和色诺芬事后执笔，写的是一场关于一个人和一座城的争吵。他们的争吵是雅典思想史的一部分。把它当作战争本身，就是在重复 [[sources/scale]] 点名的尺度错误：一句关于一次审判的真话，变成一句关于一代人战事的假话。

会构成对这条论断的反证的，是这样的证据：希腊诸国为了苏格拉底打这场战争；或者他的死是由一个共同的希腊权威裁定的；或者投降和审判是同一个行为。那五年、政体的更迭、以及战争平常的主题——帝国与同盟——就是反证。会构成对另一个不同错误的反证的——那个错误是说审判没有发生过、或者在雅典不要紧——是公元前399年这个事实本身。我们犯的不是那个错误。审判是真实的，也是地方性的。
:::

一种有影响的读法把修昔底德的书当作一种警告：民主制的雅典因过度而自我毁灭——过大胆，太少节制，伯里克利之后尤甚，一个无法坚持一贯政策的人民。你可以把它报告为对修昔底德叙事的一种解读。你不能把它报告为这场战争本身的事实。公民大会确实做出过灾难性的选择，其中有西西里，而修昔底德对后来的领袖们很严厉。斯巴达也选择了长期战争。波斯的出资者们也选择了一支舰队。盟邦们也选择了反叛。一部关于民主制过度的悲剧，是一个如何把这些选择安排成道德教训的论证。[[#thm-greek]] 才是那句可核对的话。它不需要那个道德教训，而那个道德教训也不是它的升级。

失败没有终结希腊的政治生活。雅典城邦延续下去，其余的也是。公元前404年之后的岁月里，希腊诸国仍然在开战，仍然在结盟，仍然在争论政制。从公元前404年的投降，到公元前338年的喀罗尼亚（Chaeronea）之战——马其顿在那里击败了一个希腊同盟——是66年。那些年不是一个贴了“衰落”标签的空白。它们是政治生活，而 [[greece/alexander]] 正是从公元前338年得胜的那个王国开始的，不是从城邦的一具尸体开始的。哲学也在同样的几十年里延续，包括在一座处死过一位哲学家的城市里。那次处决没有任命哲学为这座城市的对外政策，也没有终结哲学，也没有终结政策。

:::example 一个编造的道德教训 {#ex-invented}
这一段是编造的。它不是史料。“伯罗奔尼撒战争，公元前431年至公元前404年，是民主制的悲剧性过度，而苏格拉底公元前399年的死是它的道德教训。西西里，在一个我们不必核对的年份，因为人民是自由的，就毁灭了这座城市。”把修昔底德那种论证，与你真正能够定年的事实分开。
:::solution
公元前431年和公元前404年这两个括号是真实的，公元前399年是一场真实的审判。“民主制的悲剧性过度”是对修昔底德的解读，或是对修昔底德诸读者的解读，不是与投降处在同一层面的事实。斯巴达、波斯和盟邦们也都有行动。西西里没有单凭自己毁灭城市，远征失败之后战争还在继续。我们不为它添加年份。“因为人民是自由的”忘了一件事：民主制是一个由成年公民男子构成的团体，而且自由在那个意义上包含一个帝国。苏格拉底之死在投降之后五年，在恢复了的民主制之下，所以它不能是那个解释战败的道德教训。可以定年的事实是一场希腊诸国之间的战争和一次较晚的审判。悲剧是一套可选的情节。
:::

## 反对意见与一个案例

来自目击者的反对意见是最强的一条。修昔底德亲眼见过这场战争，而且他是认真的。如果他认为雅典的权力和民主制的无法无天是故事的核心，那么拒绝这个道德教训的后世读者就显得傲慢。回答不是说他是一个糟糕的证人。回答是：一个证人可以塑造演说、挑选事件，同时仍然是我们拥有的最好的连续记述。他关于斯巴达之恐惧的判断，是一个我们就帝国确实令人恐惧的范围而言可以接受的论证。他对公民大会的刻画，并不能证明民主制作为一种类型造成了这场战争。寡头的斯巴达也不得不投票选择它——无论斯巴达怎样投票。一部书是关于一场战争的证据，也是关于一位作者的信息。[[sources/evidence]] 不会让后一样东西取代前一样。

第二条反对意见说：让西西里不带年份，使这一课比印出一个年份的教科书更弱。弱化会是假装那次远征没有发生。印出一个年表没有列出的年份，则是另一种弱化，一种借来的精确。你可以不靠一个数字讲授一场灾难。但你不能教授一个你自己都不被允许为之背书的数字。

案例。一段编造的编年史句子说：“公元前404年，希腊民族向斯巴达投降，哲学随苏格拉底死去，城邦们就此终结。”每一从句都有一段真实的碎片和一个错误的主语。公元前404年投降的是雅典，不是希腊民族。苏格拉底死于公元前399年，不是在投降之时，而哲学也没有随他死去。城邦们延续着，包括雅典，经过进一步的战争，一直打到公元前338年的喀罗尼亚，并且在那之后仍然存在。修补几乎完全是一次名词的更换。年份一旦放回正确的从句里，已经完成了很大一部分工作。

:::warning 不是民主制的悲剧，也不是文明的冲突
两种迷思在这场战争里相遇。一种把它变成后来一场文明冲突的预演，让波斯或“东方”充当真正的敌人。公元前431年的交战方是希腊诸国。另一种把它变成一出悲剧，而它的事实是民主制的过度。那是对修昔底德的解读，应当标明是他的论证，或是后世关于他的论证，而不是当作事件本身。雅典是一部分男子的民主制，而它做出过可怕的选择。斯巴达不是那个民主制，却照样把战争打长。不需要任何一种迷思，就能说出谁作战、谁投降、谁在五年后受审。
:::

:::history 括号，然后是一场审判
伯罗奔尼撒战争始于公元前431年，战争爆发时点到的雅典领袖中有伯里克利，终于公元前404年雅典的投降。苏格拉底在公元前399年被审判处死。那次审判是一次雅典事件，在投降之后五年。它不是这场战争的意义。
:::

## 通向何处

城邦比投降更长命，随后一个不是城邦的王国击败了它们的同盟。[[greece/alexander]] 从公元前338年的喀罗尼亚开始，追问公元前323年亚历山大（Alexander）之死终结了什么。[[greece/athenian-democracy]] 是在雅典一方作战的公民团体，包括那些被排除在外的人。[[greece/poleis]] 讲的是为什么这些团体之间的战争不是一场民族内战。怎样不让一位史家的道德教训变成一个标签，见 [[sources/argument]]。

:::summary
- 战争始于公元前431年，雅典在公元前404年投降。跨度是27年。它是一场希腊诸国之间的战争。
- 雅典以一个握有帝国的城邦的身份作战。斯巴达与盟邦一起作战。有些希腊城邦抵抗雅典，并被摧毁。叙拉古是西西里的一个希腊敌人。
- 西西里远征是这场战争的一部分。本章不给它年份，也不给兵力数字。这次失败本身没有终结战争。
- 波斯的援助在后来帮助了斯巴达。它没有把战争变成一场波斯战争，也没有变成文明的冲突。
- 一场瘟疫在战争期间袭击雅典。不给出死亡总数。一场疾病不是对民主制的判决。
- 苏格拉底在公元前399年受审而死，在投降之后五年，在恢复了的民主制之下。那次审判不是这场战争的意义，也不是希腊的生活方式。
- 失败没有终结城邦，也没有终结希腊的政治生活。从公元前404年到公元前338年的喀罗尼亚，是它的66年。
:::

## 练习

:::exercise 战争的长度 {level=1 check="27"}
战争始于公元前431年。雅典在公元前404年投降。这两个年代相隔多少年？（输入年数。）
:::solution
431减404等于27。核对：404加27等于431。两个年份都是公元前。答案是27。
:::
:::

:::exercise 从投降到审判 {level=1 check="5"}
雅典在公元前404年投降。苏格拉底在公元前399年被处死。投降与审判相隔多少年？（输入年数。）
:::solution
404减399等于5。审判在后。它不可能是投降的原因。答案是5。
:::
:::

:::exercise 投降之后 {level=1 check="66"}
雅典在公元前404年投降。马其顿在公元前338年的喀罗尼亚击败了一个希腊同盟。这两个年代相隔多少年？（输入年数。）
:::solution
404减338等于66。核对：338加66等于404。这段间隔是城邦之间的政治生活，不是空洞的衰落。答案是66。
:::
:::

:::exercise 西西里，一句话 {level=2}
用一句话说明西西里远征发生了什么，不使用年份，不使用人数。然后说明，这句话仍然足以证明这场战争是哪种战争。
:::solution
雅典派遣一支军队进攻叙拉古，西西里的一个希腊城邦，这支军队被全歼，却没有终结那场一直打到公元前404年的战争。这就足以证明 [[#thm-greek]] 的一部分：战事是希腊人对希腊人；其中一场灾难不是一场对波斯的战争，也不是公元前431年的一场战役。缺失的年份和缺失的人数是对精确的限制，不是对敌人身份的限制。
:::
:::

:::exercise 波斯的金钱 {level=2}
斯巴达靠着波斯的支持建起一支舰队，然后击败了雅典。一位读者由此得出结论：伯罗奔尼撒战争因此是一场波斯人的战争，就像公元前480年的那场战争。这个结论在哪里断裂？
:::solution
它在谁在作战、在什么时候作战这两点上断裂。公元前480年，是一位波斯国王对城邦联盟作战。在这场战争里，公元前431年开启战端的陆军和海军是希腊人，公元前404年的投降是雅典向斯巴达投降。波斯的支持是一个国家选择出钱帮一个希腊一方打另一方。它显示阿契美尼德（Achaemenid）帝国仍然有自己的利益。它没有为交战方改名。[[#thm-greek]] 保留了那份援助，拒绝了那次改名。
:::
:::

:::exercise 不是希腊的生活方式 {level=2}
苏格拉底在公元前399年的雅典被处死。为什么把它称为希腊的生活方式，或称为公元前431年开始的那场战争的意义，是一个错误？
:::solution
那次处死是一个陪审法庭、一次不敬神明与败坏青年的指控，由雅典公民男子在投降之后五年，在一座城邦里作出的。其他希腊城市没有为这场审判投票。大多数雅典人不是哲学家，而哲学不是这座城市的政策。柏拉图和色诺芬写下的是后来的辩护词，我们不引用，它们也不是会议记录。所谓“希腊人”共有的生活方式，正是 [[greece/poleis]] 已经拒绝过的民族对象。战争的政治内容，是帝国与同盟，从公元前431年到公元前404年。一场在结束之后发生的审判不可能是那个内容。
:::
:::

:::exercise 一种解读不是事实 {level=3}
一位老师说：“修昔底德表明这场战争是民主制过度的悲剧。把它作为事实来教，因为他是同时代人。”请回应。你可以为他的论证安排一个位置。你必须说出：如果一位读者拒绝他的道德教训，仍然剩下的事实是什么。
:::hint
把帝国、斯巴达的恐惧，以及公民大会那些灾难性的决策保留为可讨论的东西。然后点名那些装不进单独的“民主制过度”里的交战方与选择。
:::
:::solution
修昔底德的论证可以作为他的来教。雅典的权力是真实的，斯巴达畏惧它，而雅典公民大会做出过——其中有西西里——被他呈现为对早先节制的背离的选择。那是对一部书的认真解读。它本身不是事实，因为一个同时代人可以塑造演说，仍然不能把道德教训变成原因。斯巴达选择了打一场长期战争，而它并不是那个民主制。波斯的当局们选择资助一支舰队。盟邦们选择反叛。这些选择本可以不同。如果一位读者拒绝那个悲剧性的道德教训，剩下的事实是 [[#thm-greek]]：公元前431年到公元前404年一场希腊诸国之间的战争，一边是一个帝国，然后是投降，然后是一个延续下来的城邦。道德教训是可选项。括号不是。
:::
:::

:::exercise 城邦没有终结 {level=3}
有人把公元前404年当作希腊政治生活的终结，把公元前399年当作葬礼。用公元前404年、公元前399年和公元前338年这三个年份，说明什么在延续，以及什么样的证据会使那句“终结”成为真话。
:::hint
先把三个年份排序。然后问：一个延续着的城邦会是什么样子，而一次真正的终结又必须移除掉什么。
:::
:::solution
次序是：公元前404年的投降；公元前399年，一座还活着的城市里的审判；然后是更晚的一场战役——公元前338年的喀罗尼亚——马其顿在那里击败了一个仍然存在、因而可供击败的城邦同盟。从公元前404年到公元前338年是66年。民主制在三十僭主的寡头之后回到雅典，虽然我们不给回归定年。希腊诸国之间的同盟与战争在继续。苏格拉底之死是恢复了的民主制做的一件事——只有当政治生活还在场时，这才可能。那句“终结”要成为真话，就需要公元前404年把城邦作为共同体一并废除，以致公元前338年已没有那一类人可战；还需要公元前399年是一场思想的葬礼而不是一场审判。年份显示的是反面。公元前404年终结的是雅典的帝国和她的战争，不是希腊人搞政治的习性。
:::
:::
