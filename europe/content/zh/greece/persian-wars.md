一旦把波斯当作一个帝国来对待，公元前490年和公元前480年究竟发生了什么？

这个问题拒绝这样一幅图景：一个成型的希腊民族遭遇一个无形的东方，并且靠胜利拯救了欧洲。[[greece/poleis]] 里的那些城邦仍然是城邦。大流士一世（Darius I）及其后的薛西斯一世（Xerxes I）治下的波斯，是一个拥有国王、总督（satrap）、贡金和希腊语臣民的庞大帝国。战役是真实的。马拉松（Marathon）是公元前490年。温泉关（Thermopylae）和萨拉米斯（Salamis）落在公元前480年同一个作战季节，而且不是同一个结果。普拉提亚（Plataea）是公元前479年。提洛同盟（Delian League）通常的起始是公元前478年，即公元前478/477年冬天。希腊一方在大陆上的胜利是真实的。它不是一个大陆的诞生，也不是一堂一方代表自由、另一方代表奴隶制的课。

## 一个有政治的国家

:::definition 阿契美尼德帝国 {#def-achaemenid}
**阿契美尼德帝国**（Achaemenid empire）是这一时期的波斯王国：由国王统治，分设各行省总督。它辖有众多民族和语言，其中也包括希腊人；它向臣属征收贡金、征发士兵。它不是一种叫“东方”的气氛，也不是与“自由希腊”相对的一群奴隶。身处其中的希腊城邦有自己的政治，包括选择反叛、顺从，或在某场战争中站在国王一边。
:::

大流士一世治下，一支波斯远征军在马拉松被击败——他就是当时的国王。通常的叙事不把他放在战场上。他派遣将领。这就是帝国的样子：中枢决策，代理人把战事带到遥远的海岸。在马拉松与大军入侵之间，王位由大流士传给薛西斯一世。我们不给他的死定年。年表里没有它，政治上的论点也不需要替代年份。薛西斯继承的这个帝国，已经与希腊诸城邦交过手，并且与它们之间还有未了的事。

那些城邦并不是一个统一的敌人。爱奥尼亚（Ionia）的希腊语城邦早已在帝国的轨道之内——有些是反叛过又被拉回来的臣民，有些是不得不选边站的邻居。我们不给那场反叛定年。在大陆上，当入侵来临时，有些城邦与国王作战，有些试图置身事外，有些投向了国王。希腊语里对这种选择的通常说法“附敌”（medising）本身，就是反对“全体希腊人对全体波斯人的战争”这种说法的证据。附敌的城邦仍然是城邦。它做的是一个关于权力的盘算，不是背叛一个并不存在的民族。

帝国自身的政治并不是一片空白。总督们相互竞争，也服从。王位继承是要事。包括希腊人在内的属从民族在王国军队中服役。我们所见的王室铭刻，说的是国王的土地与秩序之语。它们不叙述马拉松，我们也不假装它们叙述。希罗多德（Herodotus）写作时代较晚，身处海这边的希腊一侧，他才是我们实际拥有的关于这些战事的叙事。他是史料，不是镜子。[[sources/evidence]] 讲的是把存迹与推论分开。他偏爱自由人面对国王的故事，这种偏好是希腊政治语言的证据。它不是帝国的人口调查，也不是把波斯人叫作奴隶的凭据。

:::theorem 胜利是真实的，但它不是对欧洲的拯救 {#thm-europe}
希腊诸城邦的联盟在公元前490年、公元前480年和公元前479年的战事中挡住了波斯在大陆上的目标。那场胜利是真实的。它没有拯救欧洲，因为欧洲不是交战方，帝国没有崩溃，而且许多希腊城邦根本不在联盟之内。“自由对抗奴隶制”是希腊人讲述中的一句口号。它不是对波斯社会的描述，也不是对各城邦的描述——各城邦蓄有奴隶，斯巴达还有希洛人。
:::
:::proof
有年代的战役是胜利的证据，连同那些没有跟在战役后面的事态。公元前490年的马拉松击败了一支远征军，战争没有结束。公元前480年，一支希腊军队在温泉关口战败，一支希腊舰队在萨拉米斯获胜。公元前479年，一场陆战在普拉提亚击败了留在希腊的那支军队。在此之后，国王夺取大陆诸城邦的计划就结束了。本年表中没有后来任何一次有年代的行军，把波斯军队重新放回那个计划。胜利就是那个计划的失败。

同样这些证据承载不了的，是一个“被拯救的大洲”。联盟是一个城邦组成的联军，指挥权靠协商，而且有人缺席。有些希腊国家为国王作战。阿契美尼德帝国在普拉提亚之后继续存在，仍有总督和岁入。这些战役中没有任何一场建立了一个欧洲国家，甚至没有一个希腊国家。“欧洲”曾是几张不同的地图，不是一个在公元前480年等着被拯救的行动者——这个论证见 [[sources/naming-europe]]。

会构成对“胜利”的反证的，是一条与事件接近的史料：其中大陆战事以联盟诸城邦臣服于国王告终。会构成对论断后半部分（“不是拯救欧洲”）的反证的，是一份同时代的文本：其中那个联盟自称为欧洲，而帝国确实在公元前479年瓦解了。一句现代教科书的话做不了这个工作。希罗多德赞美希腊式的自由也做不了。赞美是一种主张。帝国的延续，是“崩溃说”的反证；希腊的奴隶制和希洛人制度，是“自由社会写真”的反证。
:::

:::quiz
下面哪句话符合公元前490年到公元前479年的各次战事？
- [ ] 波斯帝国灭亡了，欧洲成为一个国家
- [ ] 全体希腊人作战到底，对抗全体天生为奴的波斯人
- [x] 一个城邦联盟在大陆上挡住了一个王室的计划，而帝国延续了下去

:::

## 一个季节不是一个结果

年表把温泉关和萨拉米斯放在公元前480年同一个作战季节。这个成对关系，正是粗心的概述会删掉的事实。在温泉关，一支希腊军队扼守一个隘口而被击败。同一个季节，在优卑亚（Euboea）近海也有海战。那个季节决定性的海战胜利——年表点名的那一场——是萨拉米斯：希腊舰队在那里击败了波斯舰队。地米斯托克利（Themistocles）是与选择在那里作战相联系的雅典人。国王是薛西斯一世。战前，许多雅典人已经离开了雅典。我们不引用神谕，也不给战船或士兵定数字。年表没有给出这样的数字，政治上的结果也不需要它们。

陆上的战争没有在萨拉米斯结束。通常的记述是国王撤走，留下一名指挥官马尔多纽斯（Mardonius）带一支军队留在希腊。公元前479年的普拉提亚，就是击败这支军队的陆战。在那里，斯巴达在希腊一方很突出，正如雅典在海上很突出。联盟仍然是联盟。说“公元前480年希腊人获胜了”的一句话，删掉了温泉关。说“公元前480年希腊人战败了”的一句话，删掉了萨拉米斯。这一年是一个季节、两个结果，而战争的陆上裁决在下一年。

:::example 十年，不是一场战役 {#ex-ten}
马拉松是公元前490年。萨拉米斯是公元前480年。它们相隔多少年？对一个把“波斯战争”当作一个下午来处理的句子，这个间隔为什么重要？两个年代都是公元前。（结果是一个年数。）
:::solution
相减：490减480等于10。用加法核对：480加10等于490。两个年份都是公元前，所以没有第0年需要插入。间隔之所以重要，是因为大流士的远征和薛西斯的战役是两个不同的季节，中间隔着一次我们不在此定年的王位更替，先是一次击败，然后是一场大得多的战争。十年足够让“一个下午”的故事停摆。答案是10年，而战争在萨拉米斯时还没有结束。
:::
:::

:::example 公元前480年的两个结果 {#ex-season}
把温泉关与萨拉米斯并排。两者都属于公元前480年。一个是希腊军队在一个隘口的失败。另一个是希腊舰队的胜利。一份概述说：“公元前480年是希腊赢得自由的一年。”这份概述删掉了什么，又添加了什么？
:::solution
它删掉了温泉关——同一个季节里的一场失败，也删掉了普拉提亚这个陆上裁决是在公元前479年这个事实。它添加了“希腊”，仿佛联盟是一个民族；添加了“自由”，仿佛那句口号是对整个社会的描述。诚实的一对是：一年，两个结果，一个城邦联盟，无军队数字，一场延续到下一年的战争。萨拉米斯是一场真实的海战胜利：在希腊一方，它与地米斯托克利相联系，另一边对阵的是薛西斯的舰队。它不是对一个大陆的拯救。
:::
:::

:::example 十一年，然后是另一种东西 {#ex-eleven}
计算从马拉松（公元前490年）到普拉提亚（公元前479年）的年数。然后说一说：按通常的年代，在公元前478年、公元前478/477年冬天开始的是什么类型的东西，为什么不能把它叫作胜利的另一个名字。
:::solution
490减479等于11。核对：479加11等于490。普拉提亚在马拉松之后十一年，在萨拉米斯之后一年。公元前478年、公元前478/477年之冬，通常的教科书年代把提洛同盟的起始放在这里。那是一个有金库、有贡赋的同盟，很快就变成雅典权力的工具。胜利是一个季节里的结果。同盟是一个延续并变化的结构。把同盟叫作“胜利本身”，就是把 [[#def-league]] 塌进各场战役里。数字11属于从马拉松到普拉提亚的战争，不属于同盟。
:::
:::

## 同盟不是胜利

:::definition 提洛同盟 {#def-league}
**提洛同盟**（Delian League）是通常定年起于公元前478年、公元前478/477年冬天的同盟：各次胜利之后，雅典与其他城邦为对付波斯而组织起来。它早期的贡赋中心与提洛（Delos）相联系。成员应提供战船或金钱。它不是希腊民族，也不是萨拉米斯或普拉提亚的别名。它后来变成了雅典权力的结构。
:::

同盟早期的目标仍然与国王有关：守卫爱琴海，把战事推向波斯的据点。盟邦加入是为了保护和复仇，也因为雅典拥有舰队。一座领衔的城邦、贡赋、誓词——[[greece/poleis]] 说同盟不是民族时已经点名了这些工具。在这里，这些工具硬化了。试图退出的盟邦被强行拉回。我们不给每一次叛离定年。格局本身就是证据：成员身份不再是每年一次自由选择。起初作为军费的贡金，变成雅典维持权力、营建公共建筑、并为自己的公民的政治生活付酬的手段。后来收紧谁可分享这种生活的公民法，在 [[greece/athenian-democracy]] 里讲，不在这里。此刻的论点只有一条：同盟的实际含义已经改变。

对波斯的公开战争是否在公元前五世纪中叶由一场正式和约结束，史家意见不一。任何为这场和约提出的年份都不在本年表之内，所以我们一个也不印。这场争论不会把同盟放回到公元前479年。有无条约，那套机器都留着，并且服务于雅典。这一转向预备了下一场大战——公元前431年雅典与斯巴达及各自盟邦之间开战的那场。它由 [[greece/peloponnesian-war]] 来讲。不由我们讲。属于这里的是恐惧的起因：一个在爱琴海的雅典帝国，以抗击波斯的名义建成，靠武力与自愿共同维系，并令其他从未入盟的城邦感到警觉。

波斯并没有下台去当一个符号。帝国仍是大国。在雅典那场战争的后期，它甚至还会资助斯巴达，这是帝国政治的一个事实，不是一个需要抹平的悖论。一个在希腊受挫的国家，一代人之后仍然可以有钱、有船、有利益。对帝国来说这是常态。而它足以置“公元前479年是东方的终结”那种故事于死地。

:::theorem 同盟后来的形态不是胜利 {#thm-league}
提洛同盟以对波斯的同盟开始，变成雅典的强权。这第二件事预备了一场希腊诸国之间的战争。它不是马拉松、萨拉米斯或普拉提亚所决定过的内容，也不是各场胜利并不真实的证据。
:::
:::proof
时序就是证据。各场战役在公元前490年、公元前480年和公元前479年。同盟通常的起始在公元前478年、公元前478/477年之冬，在陆上胜利之后。强迫昔日盟邦的制度是同盟生命内部的又一次变化，不是萨拉米斯的一个秘密内容。雅典动用盟邦资源，有同盟实际运行方式作证：贡赋、镇压企图退出者、以及一个雅典足以威胁其他城邦的爱琴海。斯巴达及其盟友最终把这种权力视为不可容忍。公元前431年的战争，是同盟的转变具有重要意义这一点的后来证明。它不是普拉提亚是迷思的证明。

会构成对这条论断的反证的，是一条记录：同盟直到公元前431年都仍然保持自愿、平等的联合，没有强制，雅典也不控制公共资源。会构成对另一半（各场胜利的真实性）的反证的，是 [[#thm-europe]] 已经点名的反证。后来成为帝国，不能回头取消一场战役。但它确实意味着：“希腊的自由”不能充当整个序列的道德教训，因为领衔的自由城邦正是利用这场胜利去支配其他希腊城邦。
:::

下面哪一项是对提洛同盟最好的描述？
- [ ] 萨拉米斯胜利的另一个名字
- [ ] 欧洲的奠基性政制
- [x] 一个通常定年起于公元前478年、后来变成雅典强权的同盟

:::solution
[[#def-league]] 和 [[#thm-league]] 把这个制度与各场战役分开。通常的年代是公元前478年，公元前478/477年之冬。萨拉米斯是公元前480年。欧洲不在那里建国。同盟是处于雅典日益加强的指挥之下的希腊诸城邦，不是一个总督辖区。第三个答案既尊重那个年份，也尊重后来的变化。
:::

:::example 一个编造的道德教训 {#ex-invented}
这句话是编造的。它不是史料。“公元前480年，自由的西方在萨拉米斯击败了奴隶的东方，从而把欧洲从波斯手中救了出来。”只用本章的年代和区分，把这句话拆开。
:::solution
公元前480年里既有萨拉米斯，一场真实的海战胜利，也有温泉关，一场失败。陆上的裁决是公元前479年的普拉提亚。“自由的西方”和“奴隶的东方”不是对两个社会的描述：城邦蓄有奴隶，斯巴达依赖希洛人，波斯帝国是一个有臣民的国家，不是一团奴隶。“欧洲”不是那个联盟，也没有被拯救，因为它不是这场战争中的政治行动者。能抢救出来的东西要狭窄得多。公元前480年，一支希腊舰队在萨拉米斯打败了波斯舰队。编造的那句话留下一场真实的战役，再把它裹进本章的存在理由正是要拦住的迷思里。
:::
:::

## 反对意见与一个案例

认真的反对意见是说我们在训斥史料。作战的希腊人说过，他们作战是为了不被国王统治，他们把那种处境叫作自由。希罗多德保存了这种语言。如果本课接着说胜利与自由无关，就似乎是宁要现代的顾虑，也不要当事人。

回答是：我们在给口号评分，不是在禁止它。拒绝生活在波斯王权之下，是联盟真实的政治目标，而且可以理解。但由此推不出波斯臣民在法律上是奴隶，也推不出联盟是一个自由社会——以任何把妇女、侨居者（metic）、奴隶和希洛人都包含在内的意义。也推不出这个目标一直是同盟此后三十年的意义。战争的原因和对胜利的使用，是两句不同的话。[[sources/argument]] 把论断与标签分开。“自由”在这里接近一个标签。可以核对的论断在 [[#thm-europe]] 里：一个计划被挡住了；一个大洲没有被创造出来；一个帝国延续着。

第二条反对意见说：没有军队数字，各场战役就模糊得无法讲授。流传的数字不在年表之内，在研究文献中也不稳定到本图谱可以印出的程度。稳定的是：谁作战，谁获胜，产生了什么政治对象、没有产生什么政治对象。对沙滩上人数的虚假精确，只会让本章听起来更精确，而对 [[#thm-europe]] 毫无增益。

案例。这段是编造的。“公元前490年，大流士把奴隶的东方帝国带到马拉松，被希腊民族击败。公元前480年薛西斯卷土重来，在温泉关一天之内输掉了战争，欧洲从此安全。雅典随后领导了一个平等的同盟，而同盟就是胜利本身。”

远征军是大流士的，并不需要他本人站在马拉松；那个帝国也不是奴隶帝国。获胜的是雅典及其盟邦，不是希腊民族。薛西斯的战役在公元前480年，但温泉关是那个季节里希腊一方的失败，不是战争一天输掉的地方。萨拉米斯才是舰队获胜；公元前479年的普拉提亚是陆上的裁决。欧洲是弄错了的对象。公元前478年起的同盟不是胜利，也没有停留在平等者的同盟上——这就是 [[#thm-league]]。修补的办法是留下四个年代，换掉每一个在替迷思出力的名词。

:::warning 不是东方，也不是一堂自由的课
常见的迷思有两副面孔。一副把波斯人叫作东方、奴隶、或一面衬托希腊光辉的黑暗。另一副把各场胜利称为欧洲的拯救和西方自由的诞生。两副都不符合证据。波斯是一个有自己的政治的帝国。获胜者是一个城邦联盟：成员不全、好争吵、自己蓄奴。其后建立的同盟，变成雅典对其他希腊人的强权。一个需要国王充当符号而不是统治者的故事，用的不是这些战役，而是后来的一种对比——[[sources/naming-europe]] 拆解的正是那一类。
:::

:::history 四个年代，不是一场奠基
公元前490年，大流士一世治下派出的一支波斯远征军在马拉松被雅典及其盟邦击败。战争没有结束。公元前480年，同一个作战季节里，一支希腊军队在温泉关战败，一支希腊舰队在萨拉米斯获胜；当时的国王是薛西斯一世，雅典方面的计划与地米斯托克利相联系。公元前479年的普拉提亚是陆上的胜利。这一切中没有哪一场是欧洲的奠基。
:::

## 通向何处

同盟转向雅典强权，就是那座桥。[[greece/athenian-democracy]] 要问的是：在这座帝国城市里面，谁算参与者，谁被挡在口号所称的自由之外。[[greece/peloponnesian-war]] 是同盟的成功使其趋于可能的、希腊诸国之间的那场战争，这里不讲它。[[greece/poleis]] 仍然是那个理由：几个城市加在一起的胜利不是一个民族的胜利。把战役与标签分开的方法见 [[sources/argument]]。

:::summary
- 大流士一世和薛西斯一世治下的阿契美尼德帝国，是一个有总督、贡金和希腊臣民的国家，不是东方的符号。
- 马拉松是公元前490年，它没有结束战争。温泉关和萨拉米斯共享公元前480年，结果相反。普拉提亚是公元前479年。
- 从马拉松到普拉提亚是十一年。这段间隔是战争不是一个下午的理由。
- 希腊一方在大陆上的胜利是真实的。它没有拯救欧洲，没有瓦解帝国，也没有把各城邦描述成一个自由社会。
- 有些希腊城邦附敌了。战争不是全体希腊人对全体波斯人。
- 提洛同盟通常起始于公元前478年，即公元前478/477年冬天。它变成雅典的强权，而这个转向与胜利不是一回事。
- 那个强权是后来希腊诸国之战的背景，不是那场战争本身的叙事。
:::

## 练习

:::exercise 从马拉松到萨拉米斯 {level=1 check="10"}
马拉松是公元前490年。萨拉米斯是公元前480年。它们相隔多少年？两个年代都是公元前，不要插入一个第0年。（输入年数。）
:::solution
490减480等于10。核对：480加10等于490。这段跨度不进入公元纪元。答案是10。
:::
:::

:::exercise 从马拉松到普拉提亚 {level=1 check="11"}
马拉松是公元前490年。普拉提亚是公元前479年。它们相隔多少年？（输入年数。）
:::solution
490减479等于11。核对：479加11等于490。两个年份都是公元前，直接相减年份数即可。答案是11。
:::
:::

:::exercise 普拉提亚的次年 {level=1 check="1"}
普拉提亚是公元前479年。提洛同盟通常的起始是公元前478年。这两个年代相隔多少年？（输入年数。）
:::solution
479减478等于1。同盟通常的教科书年份是陆上胜利的次年，不是胜利本身。答案是1。
:::
:::

:::exercise 不要压扁一个季节 {level=2}
一份图注写着“公元前480年，希腊人的胜利”。用温泉关、萨拉米斯和普拉提亚说明，这句图注抹掉了什么。不需要新的数字。
:::solution
温泉关和萨拉米斯共享公元前480年，却不共享一个结果。隘口之战是希腊军队的失败。萨拉米斯是海战的胜利。针对留在希腊的那支军队的陆上裁决——普拉提亚——在公元前479年，是另一个年份。这句图注留下了那个著名的年份，删掉了年份内部的失败，还把下一年的战役拖了回来。可用的图注应当说：一个季节，两个结果，陆上的胜利还没有到来。
:::
:::

:::exercise 附敌 {level=2}
有些城邦没有加入联盟，而是投向了薛西斯。一位读者说，那些城市“不再算希腊人”，这样战争仍然可以作为希腊人对波斯人的战争来讲。附敌实际显示了什么？
:::solution
它显示的是：城邦在威胁之下各自做出了选择。投向国王并没有取消那些城市的希腊语言、祭祀和公民身份。它取消的是“这场战争是全体希腊人的民族战争”这个说法。联盟是一个联军，有人缺席，也有反对者——而反对者本身就是希腊国家。[[greece/poleis]] 已经说过，不存在一个可供效忠的希腊国家。附敌，就是这个事实承受帝国压力时的样子。
:::
:::

:::exercise 不是萨拉米斯的别名 {level=2}
一个学生写道：“提洛同盟，公元前480年，就是萨拉米斯胜利的政治名称。”用 [[#def-league]] 和 [[#thm-league]] 纠正这个年份和这个同一判断。
:::solution
萨拉米斯是公元前480年。同盟通常的起始是公元前478年、公元前478/477年之冬，在公元前479年普拉提亚之后。即便年份改对，同盟也不会成为“胜利的政治名称”。胜利是一次战事的结果。同盟是一个后来强迫成员、服务于雅典权力的联盟。[[#thm-league]] 说，后来的形态是真实的，而且不是萨拉米斯所决定的东西。这个句子把两个年代和两类对象熔在了一起。
:::
:::

:::exercise 被拯救的欧洲 {level=3}
一本书总结说：“因为联盟获胜，欧洲在公元前479年得救，而这场胜利的意义，就是自由人击败了奴隶。”写一段回应：保留胜利，拒绝结论。说出什么样的证据会迫使你接受这本书的说法。
:::hint
把普拉提亚保留为真实的陆上胜利。然后问：“欧洲”和“奴隶”是不是证据承载得起的名称？战役之后，帝国和各城邦实际是什么样子？
:::
:::solution
公元前479年的普拉提亚，是对留在希腊的那支波斯军队的真实击败；它与马拉松、萨拉米斯一道，构成王室在大陆上的计划的失败。这是应当保留的胜利。“欧洲得救了”添加了一个不在战场上的交战方。联盟没有自称为一个欧洲国家，也没有产生这样一个国家。“自由人击败了奴隶”把一句希腊口号当作描述来使用。城邦蓄有奴隶，斯巴达蓄有希洛人，阿契美尼德帝国是一个由臣民和总督构成的王国，它在公元前479年之后继续存在。会迫使我们接受这本书版本的证据是：联盟是一个欧洲政体；帝国在普拉提亚瓦解了；波斯社会在口号所需要的意义上，法律上是一个奴隶社会。各场战役本身，和希罗多德对摆脱国王的自豪，不是这种证据。
:::
:::

:::exercise 预备一场你不讲的战争 {level=3}
解释提洛同盟如何预备了公元前431年开始的那场战争，同时不讲那场战争。你被允许说什么，哪些必须留给 [[greece/peloponnesian-war]]？
:::hint
留在公元前431年这一边。允许的事实是贡赋、对盟邦的强制，以及爱琴海出现雅典强权可能引起的恐惧。不要讲战事，也不要编造一个和约年份。
:::
:::solution
被允许的是 [[#thm-league]] 里的那个转变。公元前478年之后，一个对付波斯的同盟变成雅典使用的结构：贡赋、强拉的忠诚、对其他希腊城邦的权力。其他国家，包括斯巴达，有理由畏惧这种权力。对波斯的正式和约，史家意见不一，我们不给任何年份。公元前431年开始的那场战争，是这些事实有助于解释的后来冲突。必须留下的是战争本身：它如何详细地爆发，每个阶段发生了什么，雅典最后如何投降。说出背景不是讲那场战争。把同盟收进“起因”这个单一标签里，同样走得太远。起因必须是本可以不同的东西。爱琴海的帝国使一场希腊战争变得可能。它没有让后来的每一个选择沦为走形式。
:::
:::
