如果把波斯当作一个帝国来看待，公元前490年和公元前480年发生了什么？

这个问题拒绝这样一幅图景：一个成形的希腊民族遭遇一个面目模糊的东方，并以胜利拯救了欧洲。[[greece/poleis]]中的城邦依然是城邦。大流士一世（Darius I）及其后薛西斯一世（Xerxes I）治下的波斯，是一个有国王、总督（satrap）、贡赋和希腊语臣民的大帝国。这些战役都是真实的。马拉松（Marathon）之战在公元前490年。温泉关（Thermopylae）之战和萨拉米斯（Salamis）之战同在公元前480年的一个作战季节，结果却不相同。普拉提亚（Plataea）之战在公元前479年。提洛同盟（Delian League）通常定于公元前478年，即公元前478/477年冬季成立。希腊人在本土的胜利是真实的，但它不是一块大陆的诞生，也不是一堂一方代表自由、另一方代表奴役的课。

## 一个有自身政治的国家

:::definition 阿契美尼德帝国 {#def-achaemenid}
**阿契美尼德帝国**（Achaemenid empire）是这一时期的波斯王国，由国王统治，划分为若干由总督治理的行省。它统辖着众多民族和语言，其中包括希腊人，并向臣民征收贡赋、征发兵员。它不是一种名为“东方”的情绪，也不是与自由的希腊相对立的一群奴隶。帝国境内的希腊城市有自己的政治，包括选择反叛、顺从，或在战争中站在国王一边。
:::

在马拉松被击败的那支波斯远征军，是在大流士一世在位时派出的。通常的叙述并不让他亲临战场，而是由他派遣将领。帝国的运作正是如此：中枢作出决策，由代理人把战事推进到遥远的海岸。从马拉松之战到大规模入侵之间，王位由大流士传给了薛西斯一世。我们不给大流士的去世定年，因为年表中没有这个年份，而这里的政治论点也不需要一个替代年份。薛西斯继承的帝国，已经与希腊城邦交过手，而且与它们之间还有未了之事。

这些城邦并不是一个统一的敌人。爱奥尼亚（Ionia）说希腊语的城市早已处在帝国的势力范围之内，有的是反叛后又被收服的臣民，有的是不得不作出选择的邻邦。我们不给那次反叛定年。在希腊本土，入侵到来时，有些城邦与国王作战，有些试图置身事外，有些则投向了国王。希腊人用来称呼这种选择的常用词“亲波斯”（medising），本身就是反驳“全体希腊人对全体波斯人”之战说法的证据。一个亲波斯的城邦依然是城邦；它所作的是一次权力上的权衡，而不是背叛了一个并不存在的民族。

帝国自身的政治也不是一片空白。总督们既相互竞争，也服从命令；王位继承至关重要；包括希腊人在内的臣属民族在王室军队中服役。在我们所掌握的王室铭文中，国王用的是关于疆土与秩序的语言。这些铭文并不叙述马拉松之战，我们也不假装它们有所叙述。我们对这几场战事实际拥有的叙述，出自希罗多德（Herodotus）之手——他写作的时代较晚，立场在爱琴海的希腊一侧。他是史料，而不是一面镜子。[[sources/evidence]]要求把存迹与推论分开。他偏爱自由人对抗国王的故事，这是希腊政治语言的证据，而不是帝国的人口普查，也不是把波斯人称作奴隶的依据。

:::theorem 胜利是真实的，但它不是对欧洲的拯救 {#thm-europe}
在公元前490年、公元前480年和公元前479年的战事中，希腊城邦的同盟挫败了波斯在希腊本土的图谋。这场胜利是真实的。但它没有拯救欧洲，因为欧洲不是交战的一方，帝国没有崩溃，而且许多希腊城邦从未加入这个同盟。“自由对抗奴役”是希腊人讲述中的一句口号，它既不是对波斯社会的描述，也不是对希腊城邦的描述——这些城邦拥有奴隶，斯巴达还有黑劳士。
:::
:::proof
有确切年代的战役，连同战役之后没有发生的事情，就是这场胜利的证据。公元前490年的马拉松之战击败了一支远征军，但战争并未结束。公元前480年，一支希腊军队在温泉关失守，一支希腊舰队在萨拉米斯获胜。公元前479年，普拉提亚的一场陆战击败了留在希腊的波斯军队。此后，国王夺取希腊本土城邦的图谋宣告结束；本年表中再没有任何有确切年代的战役让波斯军队重新执行这一图谋。胜利就是这一图谋的失败。

同样的证据却承载不了一块获救的大陆。这个同盟是城邦的联合，指挥权要经过协商，也有城邦缺席。有些希腊国家为国王而战。普拉提亚之战以后，阿契美尼德帝国依然存在，依然有总督和税收。这些战役中没有任何一场建立了一个欧洲国家，甚至没有建立一个希腊国家。[[sources/naming-europe]]论证了“欧洲”曾是好几幅不同的地图，而不是一个在公元前480年等待被拯救的行动者。

能够推翻“胜利”这一点的，是一条接近事件的史料，表明本土战事以同盟城邦臣服于国王而告终。能够推翻论断后半部分的，是一份同时代的文本，其中这个同盟自称为欧洲，而且帝国确实在公元前479年解体。一句现代教科书中的话做不到这一点，希罗多德对希腊式自由的赞美也做不到——赞美是一种主张。帝国的延续是对“崩溃”之说的反证，希腊的奴隶制和黑劳士制则是对“自由社会”这幅画像的反证。
:::

- [ ] 波斯帝国灭亡，欧洲成为一个国家
- [ ] 全体希腊人与全体波斯人作战，而波斯人天生是奴隶
- [x] 一个城邦同盟挫败了国王在希腊本土的图谋，而帝国继续存在

:::solution

:::
:::

## 一个季节，两种结果

年表把温泉关之战和萨拉米斯之战放在公元前480年的同一个作战季节。草率的概述恰恰会删掉这一并列的事实。在温泉关，一支希腊军队扼守山口，最终战败。同一季节，在优卑亚（Euboea）附近海域也发生了海战。而这一季节决定性的海上胜利——年表点名标出的那一场——是萨拉米斯之战：希腊舰队在那里击败了波斯舰队。与选择在那里作战相联系的雅典人是地米斯托克利（Themistocles），国王则是薛西斯一世。战前，许多雅典人已经撤离了雅典。我们不引用神谕，也不给出战船或士兵的数字。年表没有提供这类数字，政治上的结果也不需要它们。

陆上战争并没有在萨拉米斯结束。按照通常的叙述，国王撤离，留下一名指挥官马铎尼斯（Mardonius）率军驻在希腊。公元前479年的普拉提亚之战，就是击败这支军队的陆战。在那里，斯巴达在希腊一方的作用突出，正如雅典在海上的作用突出。同盟依然是同盟。说“公元前480年希腊人获胜了”，就删掉了温泉关；说“公元前480年希腊人战败了”，就删掉了萨拉米斯。这一年是一个季节、两种结果，而陆上的决战在下一年。

:::example 十年，而不是一场战役 {#ex-ten}
马拉松之战在公元前490年，萨拉米斯之战在公元前480年。两者相隔多少年？对于一句把“波斯战争”当作一个下午的话来说，这段间隔为什么重要？两个年代都在公元前。（结果是一个年数。）
:::solution
相减：490减480等于10。用加法核对：480加10等于490。两个年份都在公元前，所以无须插入公元0年。这段间隔之所以重要，是因为大流士的远征和薛西斯的战役是两个不同的季节，其间有一次我们在这里不定年的王位更替，先是一次失败，然后是一场规模大得多的战争。十年足以打破“一个下午”的故事。答案是10年，而到萨拉米斯之战时，战争仍未结束。
:::
:::

:::example 公元前480年的两种结果 {#ex-season}
把温泉关之战与萨拉米斯之战并列。两者都在公元前480年。一个是希腊军队在山口的失败，另一个是希腊舰队的胜利。一份概述写道：“公元前480年是希腊赢得自由的一年。”这份概述删掉了什么？又添加了什么？
:::solution
它删掉了温泉关——同一季节中的一次失败，也删掉了陆上决战普拉提亚之战发生在公元前479年这一事实。它添加了“希腊”，仿佛同盟是一个民族；又添加了“自由”，仿佛这句口号是对整个社会的描述。诚实的表述是：一年，两种结果，一个城邦同盟，没有军队人数，一场延续到下一年的战争。萨拉米斯之战是一场真实的海上胜利，在希腊一方与地米斯托克利相联系，对阵的是薛西斯的舰队。它不是对一块大陆的拯救。
:::
:::

:::example 十一年，然后是另一种对象 {#ex-eleven}
计算从马拉松之战（公元前490年）到普拉提亚之战（公元前479年）的年数。然后说明，按照通常的定年，公元前478年即公元前478/477年冬季开始的是一种什么样的东西，以及为什么不能把它当作胜利的另一个名称。
:::solution
490减479等于11。核对：479加11等于490。普拉提亚之战在马拉松之战后十一年，在萨拉米斯之战后一年。通常的教科书年代把提洛同盟的开端定于公元前478年，即公元前478/477年冬季。这是一个有金库、有贡赋的同盟，不久便成为雅典权力的工具。胜利是一个季节中的结果，同盟则是一个延续并不断变化的结构。把同盟称作“胜利”，就是把[[#def-league]]混同于那几场战役。数字11属于从马拉松到普拉提亚的那场战争，而不属于同盟。
:::
:::

## 同盟不是胜利

:::definition 提洛同盟 {#def-league}
**提洛同盟**（Delian League）是在几次胜利之后，雅典与其他城邦为对抗波斯而组织起来的同盟，通常定于公元前478年即公元前478/477年冬季成立。其早期的贡赋中心与提洛岛（Delos）相联系。成员须提供战船或金钱。它不是一个希腊民族，也不是萨拉米斯之战或普拉提亚之战的别名。它后来变成了雅典权力的结构。
:::

早期同盟的目标仍然与国王有关：守卫爱琴海，把战火推向波斯的据点。盟邦加入，是为了获得保护和复仇，也因为雅典拥有舰队。领导城邦、贡赋和誓约，正是[[greece/poleis]]在指出同盟不是民族时已经提到的那些手段。在这里，这些手段变得强硬起来：试图退出的盟邦被强行拉回。我们不给每一次叛离定年，这一模式本身就是证据：成员资格不再是每年一次的自由选择。起初作为军费的贡赋，变成了雅典维持权力、兴建工程、为本邦公民的政治生活支付报酬的手段。后来收紧谁可以分享这种生活的公民权法，在[[greece/athenian-democracy]]中讲授，不在这里。此刻要说明的只是：同盟的实际含义已经改变。

与波斯的公开战争是否在公元前5世纪中叶以一项正式和约结束，历史学家看法不一。为这项和约提出的任何年份都不在本年表中，所以我们一个也不列出。这一分歧并不会把同盟放回公元前479年。无论有没有条约，这套机制都保留了下来，并为雅典服务。这一转变为下一场大战埋下了伏笔，即公元前431年雅典、斯巴达及各自盟邦之间爆发的战争。那场战争由[[greece/peloponnesian-war]]讲述，我们这里不讲。属于这里的是恐惧的来由：一个在爱琴海的雅典帝国，以抗击波斯之名建立，靠强力和认同共同维系，令那些从未加入同盟的城邦感到警惕。

波斯并没有退出舞台、变成一个符号。帝国依然是一个强国。在雅典那场战争的后期，它甚至会资助斯巴达——这是帝国政治中的一个事实，而不是一个需要抹平的悖论。一个在希腊受挫的国家，一代人之后依然可以拥有金钱、战船和利益，这对帝国来说再平常不过。而对于那种把公元前479年说成“东方”终结的故事，这一点是致命的。

:::theorem 同盟后来的形态不是胜利 {#thm-league}
提洛同盟起初是对抗波斯的同盟，后来变成了雅典的强权。这后一事实为希腊国家之间的一场战争埋下了伏笔。它不是马拉松、萨拉米斯或普拉提亚之战所决定的东西，也不能证明那些胜利是虚假的。
:::
:::proof
时间顺序就是证据。几场战役发生在公元前490年、公元前480年和公元前479年；同盟通常的起始是公元前478年即公元前478/477年冬季，在陆上胜利之后。强迫昔日盟友的种种制度，是同盟存续过程中的又一次变化，而不是萨拉米斯之战中隐藏的内容。雅典利用盟邦资源，可以从同盟的实际运作中得到证明：贡赋、镇压退盟企图，以及一个雅典足以威胁其他城邦的爱琴海。斯巴达及其盟邦最终认为这种权力无法容忍。公元前431年的战争，后来证明了同盟的转变有多么重要；但它并不能证明普拉提亚之战是一个迷思。

能够推翻这条论断的，是一份记录，表明直到公元前431年，同盟始终是自愿而平等的联合，既没有强迫，雅典也不控制共同的资源。能够推翻另一半——胜利的真实性——的，是[[#thm-europe]]中已经指出的那些反证。后来成为帝国，并不能回溯过去，抹掉一场战役。但这确实意味着，“希腊的自由”不能作为整个过程的道德教训，因为领头的那个自由城邦正是利用这场胜利去支配其他希腊城邦。
:::

- [ ] 欧洲的奠基政制
- [x] 一个通常定于公元前478年成立、后来变成雅典强权的同盟

[[#def-league]]和[[#thm-league]]把这一机构与那几场战役区分开来。它通常定于公元前478年即公元前478/477年冬季成立，而萨拉米斯之战在公元前480年。欧洲并不是在那里奠基的。同盟是在雅典日益加强的主导之下的希腊城邦，而不是一个行省。第三个答案既尊重了这个年份，也尊重了后来的变化。

:::example 一个虚构的道德教训 {#ex-invented}
下面这句话是虚构的，不是史料。“公元前480年，自由的西方在萨拉米斯击败了奴役的东方，从而把欧洲从波斯手中拯救出来。”只用本章的年代和区分，把这句话拆开。
:::solution
公元前480年既有一场真实的海上胜利萨拉米斯之战，也有一次失败温泉关之战，而陆上决战是公元前479年的普拉提亚之战。“自由的西方”和“奴役的东方”都不是对这两个社会的描述：希腊城邦奴役他人，斯巴达依赖黑劳士，波斯帝国则是一个有臣民的国家，而不是一群奴隶。“欧洲”不是这个同盟，也没有被拯救，因为它不是这场战争中的政治行动者。能挽救的内容要窄得多：公元前480年，一支希腊舰队在萨拉米斯击败了一支波斯舰队。这句虚构的话保留了一场真实的战役，却把它包裹在本章正要制止的那个迷思之中。
:::
:::

## 反驳与实例

认真的反驳是：我们在苛责史料。参战的希腊人说，他们作战是为了不受国王统治，并把这称为自由，希罗多德保留了这种语言。如果本课接着说这场胜利与自由无关，似乎就是以现代人的顾虑取代了当事人的看法。

回答是：我们是在评估这句口号，而不是禁止它。拒绝生活在波斯王权之下，是这个同盟真实的政治目标，而且可以理解。但由此推不出波斯臣民在法律上是奴隶，也推不出这个同盟在任何包括妇女、外侨（metic）、奴隶和黑劳士在内的意义上是一个自由社会，更推不出这一目标在此后三十年里始终是同盟的意义所在。战争的原因与胜利的用途是两句不同的话。[[sources/argument]]把论断与标签区分开来，而“自由”在这里接近于一个标签。可以检验的论断是[[#thm-europe]]中的那一条：一项图谋被挫败了；一块大陆并没有被创造出来；一个帝国继续存在。

第二条反驳说，没有军队人数，这些战役就太模糊，无法讲授。流传的那些数字不在年表中，在学术研究中也没有稳定到本图谱愿意印出的程度。稳定的是：谁参战，谁获胜，以及产生了或没有产生什么样的政治实体。对海滩上人数的虚假精确，只会让本章听起来更精确，却不会给[[#thm-europe]]增添任何内容。

实例。下面这段话是虚构的。“公元前490年，大流士把东方的奴隶帝国带到马拉松，被希腊民族击败。公元前480年，薛西斯卷土重来，在温泉关一天之内输掉了战争，欧洲从此安全。随后雅典领导了一个平等者的同盟，这与那场胜利是一回事。”

远征是大流士的远征，并不需要他亲临马拉松；那个帝国也不是奴隶帝国。获胜的是雅典及其盟邦，而不是希腊民族。薛西斯的战役在公元前480年，但温泉关是那个季节中希腊一方的失败，而不是一天之内输掉战争的地方。萨拉米斯是舰队的胜利，公元前479年的普拉提亚才是陆上决战。“欧洲”是用错了的对象。公元前478年起的同盟不是胜利，也没有一直是平等者的同盟，这就是[[#thm-league]]。修补的办法是保留四个年代，替换每一个在为迷思出力的名词。

:::warning 不是东方，也不是一堂自由课
常见的迷思有两副面孔。一副把波斯人称作东方、奴隶，或衬托希腊光辉的黑暗；另一副把这些胜利称作欧洲的得救和西方自由的诞生。两者都经不起证据的检验。波斯是一个有自身政治的帝国。获胜者是一个城邦同盟，并不完整，内部争吵不断，而且本身就蓄奴。随后建立的同盟变成了雅典凌驾于其他希腊人之上的强权。一个需要国王充当符号、而不是统治者的故事，用的并不是这些战役，而是后来的一种对比——[[sources/naming-europe]]所拆解的正是这一类对比。
:::

:::history 四个年代，不是一次奠基
公元前490年，大流士一世在位时派出的一支波斯远征军在马拉松被雅典及其盟邦击败，战争并未结束。公元前480年，在同一个作战季节里，一支希腊军队在温泉关战败，一支希腊舰队在萨拉米斯获胜；当时的国王是薛西斯一世，雅典的作战方案与地米斯托克利相联系。公元前479年的普拉提亚之战是陆上的胜利。这些都不是欧洲的奠基。
:::

## 通向何处

同盟向雅典强权的转变是一座桥梁。[[greece/athenian-democracy]]追问：在这个帝国城市内部，谁算作参与者，谁被挡在口号所说的自由之外。[[greece/peloponnesian-war]]讲的是同盟的成功使之更有可能发生的那场希腊国家之间的战争，这里不讲。[[greece/poleis]]始终说明了为什么几个城市的胜利不是一个民族的胜利。把战役与标签区分开来的方法，见[[sources/argument]]。

:::summary
- 大流士一世和薛西斯一世治下的阿契美尼德帝国，是一个有总督、贡赋和希腊臣民的国家，而不是东方的符号。
- 马拉松之战在公元前490年，它没有结束战争。温泉关之战和萨拉米斯之战同在公元前480年，结果相反。普拉提亚之战在公元前479年。
- 从马拉松之战到普拉提亚之战是十一年。这段间隔说明了战争为什么不是一个下午的事。
- 希腊人在本土的胜利是真实的。它没有拯救欧洲，没有瓦解帝国，也没有把希腊城邦描绘成一个自由社会。
- 有些希腊城邦亲附波斯。这场战争不是全体希腊人对全体波斯人。
- 提洛同盟通常定于公元前478年即公元前478/477年冬季成立。它变成了雅典的强权，而这一转变与胜利不是一回事。
- 这种强权是后来希腊国家之间那场战争的背景，而不是那场战争的叙述本身。
:::

## 习题

:::exercise 从马拉松到萨拉米斯 {level=1 check="10"}
马拉松之战在公元前490年，萨拉米斯之战在公元前480年。两者相隔多少年？两个年代都在公元前，不要插入公元0年。（请输入年数。）
:::solution
490减480等于10。核对：480加10等于490。这段跨度没有进入公元纪年。答案是10。
:::
:::

:::exercise 从马拉松到普拉提亚 {level=1 check="11"}
马拉松之战在公元前490年，普拉提亚之战在公元前479年。两者相隔多少年？（请输入年数。）
:::solution
490减479等于11。核对：479加11等于490。两个年份都在公元前，所以直接用年份数字相减。答案是11。
:::
:::

:::exercise 普拉提亚之后的一年 {level=1 check="1"}
普拉提亚之战在公元前479年，提洛同盟通常的起始年份是公元前478年。这两个年代相隔多少年？（请输入年数。）
:::solution
479减478等于1。教科书通常给同盟的年份是陆上胜利的次年，而不是胜利本身。答案是1。
:::
:::

:::exercise 不要把一个季节压缩 {level=2}
一则图注写着“公元前480年，希腊的胜利”。请用温泉关、萨拉米斯和普拉提亚三场战役说明，这则图注抹掉了什么。你不需要新的数字。
:::solution
温泉关之战和萨拉米斯之战同在公元前480年，结果却不相同：山口之战是希腊军队的失败，萨拉米斯之战是海上的胜利。普拉提亚之战——针对留驻希腊的波斯军队的陆上决战——在公元前479年，是另一年。这则图注保留了那个著名的年份，删掉了其中的失败，又把下一年的战役拉了回来。可用的图注应当是：一个季节，两种结果，陆上的胜利还在后面。
:::
:::

:::exercise 亲附波斯 {level=2}
有几个城邦没有加入同盟，而是投向了薛西斯。一位读者说，这些城市“不再算希腊人”，因此仍然可以把这场战争讲成希腊人对波斯人。亲附波斯实际上表明了什么？
:::solution
它表明城邦在威胁之下各自作出了选择。投向国王并没有取消这些城市的希腊语言、祭祀或公民身份，它取消的是“这是一场全体希腊人的民族战争”这一说法。同盟是一个联合，有缺席者，也有对手，而这些对手本身就是希腊国家。[[greece/poleis]]已经指出，不存在一个可以效忠的希腊国家。亲附波斯，就是这一事实在帝国压力下的表现。
:::
:::

:::exercise 不是萨拉米斯的别名 {level=2}
一名学生写道：“提洛同盟，公元前480年，是萨拉米斯胜利的政治名称。”请运用[[#def-league]]和[[#thm-league]]，纠正其中的年份和等同关系。
:::solution
萨拉米斯之战在公元前480年。同盟通常的起始是公元前478年即公元前478/477年冬季，在公元前479年的普拉提亚之战之后。即便改正了年份，同盟也不会因此成为“胜利的政治名称”。胜利是一次战事的结果；同盟则是一个后来强迫成员、服务于雅典权力的联盟。[[#thm-league]]指出，这种后来的形态是真实的，但不是萨拉米斯之战所决定的。这名学生的句子把两个年代和两类对象混为一谈。
:::
:::

:::exercise 欧洲得救了 {level=3}
一本书的结论是：“由于同盟获胜，欧洲在公元前479年得救了，而这场胜利的意义在于自由人击败了奴隶。”请写一段回应，保留胜利，拒绝这一结论，并说明什么样的证据会迫使你接受这本书的说法。
:::hint
把普拉提亚之战保留为一场真实的陆上胜利。然后问：“欧洲”和“奴隶”是证据能够承载的名称吗？战役之后，帝国和希腊城邦实际上是什么样子？
:::
:::solution
公元前479年的普拉提亚之战，真实地击败了留驻希腊的波斯军队；它与马拉松之战、萨拉米斯之战一起，构成了国王在希腊本土图谋的失败。这是应当保留的胜利。“欧洲得救了”添加了一个并不在战场上的交战方：同盟没有自称为一个欧洲国家，也没有产生任何欧洲国家。“自由人击败了奴隶”则把一句希腊口号当作了描述。希腊城邦拥有奴隶，斯巴达拥有黑劳士，而阿契美尼德帝国是一个由臣民和总督构成的王国，在公元前479年以后依然存在。只有以下证据才会迫使我们接受这本书的说法：同盟是一个欧洲政治体；帝国在普拉提亚之战后解体；波斯社会在这句口号所需要的意义上，在法律上是一个奴隶社会。那几场战役本身，以及希罗多德对摆脱国王统治的自豪，都不是这样的证据。
:::
:::

:::exercise 为一场不讲的战争铺垫 {level=3}
不叙述那场战争本身，说明提洛同盟如何为公元前431年开始的战争埋下伏笔。你可以说什么？又必须把什么留给[[greece/peloponnesian-war]]？
:::hint
停留在公元前431年之前。允许使用的事实是贡赋、对盟邦的强迫，以及爱琴海上的雅典强权可能引起的恐惧。不要讲述战役，也不要杜撰和约的年份。
:::
:::solution
可以说的是[[#thm-league]]中的那一转变：公元前478年以后，一个对抗波斯的同盟变成了雅典利用的一种结构——贡赋、被迫的效忠，以及凌驾于其他希腊城邦之上的权力。其他国家，包括斯巴达，有理由畏惧这种权力。关于与波斯是否订立过正式和约，历史学家看法不一，我们不给任何年份。公元前431年开始的战争，是这些事实有助于解释的后来冲突。必须留下的是战争本身：它具体如何爆发，各个阶段发生了什么，雅典最终如何投降。说出背景并不等于讲述战争。而把同盟压缩为“原因”这样一个单一标签，同样走得太远：原因必须是本来可能不同的东西。爱琴海上的帝国使一场希腊人之间的战争更有可能发生，却并没有让此后的每一个选择都沦为形式。
:::
:::
