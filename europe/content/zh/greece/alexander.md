公元前323年终结了什么，什么没有终结？

马其顿的亚历山大（Alexander）于公元前323年死于巴比伦（Babylon）。随他终结的是一生命，以及他征服的那个帝国作为一个王国传递下去的机会。没有终结的是希腊人的政治生活、诸城邦，以及他所夺取的那些土地上的诸民族。他没有统一欧洲。他没有把文明带给那些本已有国家、文字和国王的社会。马其顿是一个王国。它不是雅典，也不是作为国家的“希腊人”。这次死亡的政治结果，是一组希腊化诸王国（Hellenistic kingdoms），也就是 [[rome/republic]] 日后将要遭遇的那个世界。那次相遇不在这里讲。

## 一个王国，不是一个城邦

:::definition 马其顿 {#def-macedon}
**马其顿**（Macedon）在本章是一个坐落在旧日诸城邦北部边缘、由一个王室统治的王国。它不是一个成年公民男子的民主制，也不是把希腊人称为一个国家的名称。它的国王可以率领希腊盟邦，同时仍与希腊城邦交战。王位是继承来的、争夺来的，也会遇刺终结。它不是抽签来的。
:::

腓力二世（Philip II）是那个在公元前338年于喀罗尼亚（Chaeronea）击败希腊城邦同盟的国王。按通常的说法，雅典和底比斯都在那个同盟里。这场战役是一个王国对公民军队的胜利，不是一个民族的再统一。德摩斯梯尼（Demosthenes）是那个与抵抗腓力相联系的雅典演说家。我们不引用他。胜利之后，腓力在自己领导下组织了一个希腊诸国的同盟，一种领导权。我们不把那个同盟与喀罗尼亚分开定年。成员们仍然是城邦。领导权正是 [[greece/poleis]] 已经与民族区分开来的那种权力：追随者们没有停止做它们自己的共同体。有些希腊人曾与之为敌。有些人将来会为他儿子效力。这场战役底下没有一个一致对外的希腊计划在暗处。

公元前336年，腓力遇刺身亡。亚历山大成为国王，因为他是那个王室的继承人，而不是因为雅典公民大会选举了他。在位早期，底比斯反叛，被摧毁。按通常的说法，它的许多人被奴役。我们不给这场毁灭定年，也不给死者或被奴者定数字。事实已经足够。一个马其顿国王对一座有名的城邦使用恐怖。这不是一个被“希腊人”热爱的统一者的行为，也不是一个该留给宽宏传说去保存的细节。这是他权力的开端，早在他渡海之前。

:::theorem 喀罗尼亚不是一个希腊民族行动 {#thm-chaeronea}
公元前338年在喀罗尼亚击败一个希腊同盟，使马其顿成为诸城邦之间的头号强国。它没有使马其顿成为“希腊人”，也没有把诸城邦变成一顶民族王冠之下的一个国家。盟邦与敌邦仍然界限分明。
:::
:::proof
证据是这场战役自己的两方。一个王国作战的对象是一个同盟。同盟之所以存在，是因为各方仍然各自分立，这正是 [[greece/poleis]] 里同盟不是民族的同一个理由。胜利之后，领导权是通过存续下来的诸城邦组织起来的，不是通过废除它们。底比斯后来的毁灭显示的是同意之反面：一个城邦仍然可以选择反叛，而国王的回答是这座城市的终结。后来在亚洲战事里的希腊士兵，是一个马其顿国王的募兵和盟邦部队，与马其顿人并肩，不是希伦（Hellas）的民族征召军。

会构成对这条论断的反证的，是在喀罗尼亚颁行的一份统一公民身份，或是一条史料：其中被击败的城市自称为一个希腊民族的辖区，而不是战败于一个国王之下的失败者。一句写着“希腊统一了”的现代图注不是那条史料。腓力死于公元前336年，这本身又是一条反证——反对一顶稳定的民族王冠：这个领导权个人化到这种程度，以致刺杀就是一场政治危机，而新国王不得不重新迫使诸城邦服从。
:::

## 战事，只在被允许之处定年

公元前334年，亚历山大渡海进入亚洲。敌人是阿契美尼德（Achaemenid）帝国，同一条帝国传统，在公元前479年的普拉提亚（Plataea）之后仍然是一个大国。这场战争是一个马其顿国王对这个帝国的入侵，他身后有希腊盟邦，也有希腊敌人，不是欧洲的十字军。在渡海与本年表所定年的那场战役之间，按通常的叙事还有进一步的战事与战役，沿着海岸，直至埃及。我们不为它们逐一地定年。我们印出的数字，是公元前334年的渡海和公元前331年的高加米拉（Gaugamela）。

高加米拉是对波斯国王的一次战场上的决定性击败。此后，帝国的中心门户洞开。巴比伦被攻取。按通常的说法，波斯波利斯（Persepolis）的宫殿中心被焚，而我们不给这场火定年。波斯国王没有保住他的王位。他在崩溃的过程中被杀，我们也不给那次杀害定年。大流士（Darius）一脉，作为帝国中枢的统治王室，作为一个统治王室终结了。这些土地上的诸民族没有终结。在任何马其顿人到来之前，埃及和巴比伦尼亚（Babylonia）早已是古老的国家与文字的中心。伊朗诸地本就是帝国自己的腹地。征服不是一份历史的礼物，送给本来没有历史的人。

战事继续，穿过伊朗高原，远达印度河地区。按通常的说法，军队最终拒绝再往前，而他折返。我们不引用那次拒绝，也不给军队定人数。年表没有确定一个规模，而下面的 [[#thm-death]] 并不需要它。他于公元前323年死在巴比伦。史料对死因意见不一。发烧是寻常的报告。毒杀是一则传闻。政治上的事实不等候诊断。他没有留下一个撑得住他所征服之物的继承人。

:::example 十五年 {#ex-fifteen}
喀罗尼亚是公元前338年。亚历山大在公元前323年死于巴比伦。使马其顿在希腊诸城邦中称尊的那场战役，与把被征服的帝国砸进继业危机的那次死亡，相隔多少年？
:::solution
338减323等于15。核对：323加15等于338。两个年代都是公元前，所以没有第0年需要插入。十五年里装着一场公元前336年的刺杀、一次公元前334年进入亚洲的渡海、公元前331年的高加米拉，以及那次死亡。这段跨度在帝国的尺度上是短的，又长到足够装下一个领导权和一个征服。它不是一个民族的完成。答案是15年。
:::
:::

:::example 一场胜利与一次死亡 {#ex-pair}
把高加米拉，公元前331年，与巴比伦的那次死亡，公元前323年，并排。一个是波斯国王的失败。另一个是亚历山大生命的终结。为什么前者不是一个完成的定局，尽管它是一场真实的胜利？
:::solution
331减323等于8。高加米拉赢下一场会战，打开了帝国的中心。它没有为一个单一继承国写出宪法，也没有让国王活着。八年后，征服者死去，没有留下一个能统治全境的继承人。一场胜利是一个季节里的结果。一个定局得是一份守得住的遗产。[[#thm-death]] 说的是这份继承没有发生。把两个年代并排放下，阻止的是把最大的一场战役当作故事结尾的习惯。政治上的结尾，是那次死亡。
:::
:::

## 那次死亡打破了什么

:::definition 希腊化诸王国 {#def-hellenistic}
**希腊化诸王国**（Hellenistic kingdoms）是公元前323年亚历山大死后，由将领们的战争产生的那些各自为政的君主国。这个词是后世给那个政治世界贴的标签，不是一个希腊民族，也不是换了新希腊贴纸的阿契美尼德帝国。后世最常点名的几块大拼图，是一个在埃及的王国、一个在亚洲的王国、一个在马其顿的王国。边界移动过。城邦在这些王国旁边和内部延续下去。
:::

公元前323年，那张整洁的地图还没有画出来。有一场危机。将领们——继业者（the successors）——为总督辖区、军队和王室残余成员争斗。在此后几十年里，这些争斗产生了那个标签所命名的诸王国。托勒密（Ptolemy）家族统治埃及。塞琉古（Seleucus）家族统治一片广大而多变的亚洲疆域。安提柯（Antigonid）家族成为与马其顿相联系的王室。这些没有一个是在葬礼上宣读的一份遗嘱。点它们的名，是一种看清结果的方式，不是一种假装结果是即时发生的方式。即时发生的是那个否定性的事实。被征服的帝国没有保持为一个王国。

希腊语成为广大地域里政府与城市的一种语言。新的城市被建立。埃及的亚历山大里亚（Alexandria）成为其中最著名的一座，我们不把它的建城与战事分开定年。一种统治的语言不是一个政体。[[greece/poleis]] 已经拒绝把共同的语言变成一个国家。同一个拒绝在放大一级的尺度上同样适用。马其顿的诸王朝统治着混居的人口——埃及的、巴比伦的、伊朗的以及其他——而他们需要这些人口的收成、祭司和书吏。那是帝国。它不是把人熔成一个民族的融合，也不是城邦的终结——其中许多城邦在国王们之下、国王们旁边保持着它们的公民形态。城邦的联邦同盟也在延续。我们不给它们后来的显要定年。它们的存在本身就是要点。

:::theorem 那次死亡终结了一生命与一份单一继承，不是终结一个世界 {#thm-death}
亚历山大公元前323年在巴比伦的死亡，终结了他的统治，也终结了被征服的阿契美尼德诸地作为一个王国传递下去的前景。它没有终结诸城邦，没有终结希腊语者的政治生活，也没有终结那些本已被征服的社会。结果是多个并立的希腊化王国，不是一个完成的希腊民族。
:::
:::proof
断裂的证据是将领们的战争。那些做过他部将的人各自统治不同的地区，并且彼此攻战。没有一个继承人通过一代人的时间把这些总督辖区当作一套行政体系控制起来。巴比伦的编年史材料把征服和那次死亡记载为那座城市的政治时间里的记事。它是对一个纯粹英雄化的希腊故事的校验，我们不引用它。希腊与罗马的叙事——写得更晚、充满传说——在政治轮廓上仍然一致：一次巴比伦的死亡，然后是分裂。皮埃尔·布里安（Pierre Briant）那种读法——把征服对照于它所推翻的阿契美尼德帝国、对照于传说——是我们要跟随的现代告诫。不需要他的书页，我们也看得见：埃及和巴比伦尼亚在渡海之前并不空洞。

会构成对这条论断的反证的，是一位继业者真的从巴比伦或从佩拉（Pella）把整个帝国握在一起、其余将领一律服从，以致公元前323年是一场葬礼而不是一场危机。事情不是这样发生的。会构成对后一半——那个世界没有终结——的反证的，是死亡之后诸城邦的消失，以及非希腊制度随之消失。公民生活、庙宇和地方精英延续着。一个需要埃及财富的埃及王国不是对埃及的废除。多个并立，就是 [[#def-hellenistic]] 所命名的那个结果。
:::

:::theorem 他不是欧洲的统一者，也不是文明的带来者 {#thm-not-europe}
从公元前334年到公元前323年死亡的那场战事，是一个马其顿国王对阿契美尼德帝国的征服。它没有统一欧洲，也没有把文明带给被征服者。那些说法称颂的是一个传说。它们不描述那些对手、那条路线或那个结果。
:::
:::proof
欧洲是一张错误的地图。路线穿过安纳托利亚（Anatolia）、黎凡特（Levant）、埃及、美索不达米亚（Mesopotamia）、伊朗，再指向印度河方向。那些是帝国的土地和它的邻地，不是一个正被收进一个国家的欧洲半岛。[[sources/naming-europe]] 的论证是：欧洲曾经是好几个后来的观念。它们没有一个是亚历山大的军队。文明一旦被用作一份礼物，就预设被征服者本来没有政治秩序。埃及与巴比伦尼亚诸国家、以及阿契美尼德王权本身的证据，就是反证。他推翻了一个统治王室。他没有引入历史。

喀罗尼亚是对“希腊的统一者”的反证，而且它就在希腊语世界内部，不在欧洲整体。他在率领一些希腊人之前先击败了希腊人。底比斯被摧毁了。一个以砸毁一座城邦开头的统一者，名字被叫错了。会构成对这一拒绝的反证的，是这样的定局：被征服的土地在公元前334年之前没有国家，或者在他死后有一个欧洲政体建立起来、并且存续下来。希腊化诸王国是好几个，而且它们不是欧洲。

不算数的，是后世那个称号“大王”（the Great），或一张把帝国涂成一色的课堂地图——仿佛它仍然是那个家族的一个国家。称号是传说的一部分。那种涂色是把 [[#thm-death]] 画错了。
:::

:::example 一个编造的完成 {#ex-invented}
这句话是编造的。它不是史料。“公元前323年，亚历山大完成了希腊与欧洲的统一，并把一个王国留给了他的人民。”哪些词可以接到真实的年份上，哪些词发明了一个结果？
:::solution
公元前323年是他死于巴比伦之年。它可以接到他的生命的终点上，也可以接到一场继业危机的起点上。“完成”用给一次死亡是个错的动词。“希腊的统一”与喀罗尼亚矛盾——在那里，一个王国击败了希腊诸城邦；也与那些城邦的存续矛盾。“欧洲”不是那个战场，也不是那个结果。“一个王国”正是诸将领没能守住的东西。“他的人民”假装存在一个可供继承的民族。修补用的是本课自己的那句话：他死在巴比伦，被征服的帝国在他的将领们之间瓜分了，而不是作为一个希腊国家被继承。

马其顿是那个王国，自公元前336年由亚历山大统治，它就是公元前334年的入侵者。雅典是一个城邦，一个它的一部分男子的民主制，公元前338年与其他城邦一道在喀罗尼亚战败，而仍然是一个城邦。阿契美尼德中枢是那个被攻击的帝国，一个有自己的国王的国家，不是一张空白，也不是一个欧洲边疆。如果马其顿被称为雅典类型的城邦，如果雅典被称为民族，如果那个帝国被称为等着被带来的文明，这次分类就失败了。

## 反对意见与一个案例

认真的反对意见是个人之治。有几年时间，一个国王在广大的距离上得到承认。反对意见说，若这都算不是一个帝国，那就没有什么算帝国了。回答是把征服与继承分开。那种幅度的个人之治是真实的，而且恰恰是随他死去的东西。一个不能在国王死后不分裂而存续的国家，还没有变成一个持久的单一王国。将领们的战争不是一个完成了的计划底下的小节。它们是那个计划的政治结果。[[#thm-death]] 就是按这个意思写的。会重新打开它的，是服从，不是进一步的征服：一位继承人，在全体总督辖区被服从。传说偏爱的是征服。

第二条反对意见说：拒绝给出军队规模，拒绝为公元前334年到公元前331年之间的每场战役给出年份，让这场战事太单薄，不像一次征服。单薄是一条证据规则的结果，不是对征服是否发生的怀疑。高加米拉是有年代的。帝国的中心脱离了阿契美尼德家族之手。死亡是有年代的。流传的规模数字不在年表里，而好几场有名的战役有着本图谱不会印出的年份。你可以把一次征服当作一次统治者的更替来讲，不用人数，也不用逐日的行军路线。加上任何一样，听起来会更精确，诚实会更少。

案例。一段编造的学校课文说：“腓力在公元前338年的喀罗尼亚统一了希腊。亚历山大，一个文明的带来者，在公元前334年渡海，在公元前331年的高加米拉赢得了世界，并在公元前323年把那个世界作为一个王国留下。罗马后来接收了他造就的那个民族。”

腓力击败的是一个同盟。他没有统一一个民族。渡海与高加米拉是真实的，年代也是按年表的，而它们是对一个帝国的征服——那个帝国已经拥有文明，在这个词唯一不带侮辱意味的意义上拥有，也就是它自有其国家、文字与诸神。公元前323年的那次死亡是断裂，不是把一个王国作为遗产交出去。罗马没有接收一个希腊民族。[[rome/republic]] 开始的是另一段制度史，后来的战争将要遭遇的世界是希腊化的多元格局。那段课文的年代多半就是年表的年代。它的名词是传说。把名词修好吧。

:::warning 不是统一者，也不是一份文明的礼物
常见的迷思给同一个人两个称号。一个称他为希腊的、或欧洲的统一者。喀罗尼亚是一个外邦王国的国王对希腊诸城邦的击败，而这场战事的路线是阿契美尼德帝国，不是一个欧洲联盟。另一个称他为文明的带来者。埃及、巴比伦尼亚和波斯没有在黑暗中等待一个马其顿人来开始它们的历史。两个称号还掩盖了图所示出的那个结果。公元前323年的那次死亡是一道政治断裂。它不是一个完成了的计划，而其后的诸王国是好几个。
:::

:::history 一段短促的王统
腓力二世在公元前338年于喀罗尼亚击败一个希腊同盟，并在公元前336年遇刺身亡。马其顿的亚历山大在公元前334年渡海进入亚洲，在公元前331年的高加米拉击败波斯国王，并于公元前323年死于巴比伦。被征服的帝国在他的将领们之间瓜分了，而不是作为一个希腊国家被继承。
:::

## 通向何处

罗马遭遇的是这个世界——诸王国与诸城邦——不是在巴比伦遗下一个完工的希腊民族。[[rome/republic]] 讲的是共和国自己的官职与它自己的传统开端。它不应被倒着读成亚历山大渡海的原因，也不在本章讲述。在他身后，[[greece/peloponnesian-war]] 的那场战争早已显示希腊诸国彼此攻战，而 [[greece/poleis]] 讲的是为什么腓力和亚历山大都不可能是那个缺席的民族。那种把一场征服变成一个文明故事的习惯，正是 [[sources/naming-europe]] 和 [[sources/argument]] 要设法放慢的那种习惯。

:::summary
- 马其顿是一个王国。它不是雅典，也不是作为国家的希腊人。公元前338年的喀罗尼亚是对一个希腊同盟的击败，不是民族的统一。
- 腓力二世在公元前336年遇刺。亚历山大作为继承人成为国王。底比斯在位早期被摧毁，这里不印年份，也不定死亡数字。
- 他在公元前334年渡海进入亚洲。公元前331年的高加米拉击败了波斯国王。这场战事的其他战役，我们不给出年表未列的年份。不给出军队规模。
- 从喀罗尼亚到那次死亡是15年。从渡海到那次死亡是11年。战事是短的。一场短的战事不是一个完成了的计划。
- 他于公元前323年死在巴比伦。死因有争议，而它不决定政治。没有一个继承人把那个征服保持为一个王国。
- 希腊化诸王国——在埃及、在亚洲、在马其顿——是政治上的结果。诸城邦与地方社会延续下去。希腊语作为统治语言，不是一个希腊民族。
- 他不是欧洲的统一者，也不是文明的带来者。[[rome/republic]] 是罗马自己那段历史的起点。它后来才与这个多元世界相遇。
:::

## 习题

:::exercise 从喀罗尼亚到巴比伦 {level=1 check="15"}
喀罗尼亚是公元前338年。亚历山大在公元前323年死于巴比伦。它们相隔多少年？（输入年数。）
:::solution
338减323等于15。核对：323加15等于338。两个年代都是公元前。答案是15。
:::
:::

:::exercise 亚洲战事的长度 {level=1 check="11"}
亚历山大在公元前334年渡海进入亚洲。他在公元前323年死于巴比伦。渡海与那次死亡相隔多少年？（输入年数。）
:::solution
334减323等于11。按这个纪年，亚洲战事历时十一年，而以一场继业危机告终，不是以一个安定的单一王国告终。答案是11。
:::
:::

:::exercise 从遇刺到渡海 {level=1 check="2"}
腓力二世在公元前336年遇刺。亚历山大在公元前334年渡海进入亚洲。这两个年代相隔多少年？（输入年数。）
:::solution
336减334等于2。新国王在渡海之前重新迫服希腊，其中包括摧毁底比斯，我们不为此定年。答案是2。
:::
:::

:::exercise 不是雅典 {level=2}
一位读者说：“马其顿是一个像雅典一样的城邦，只是更大，所以亚历山大作为它的民主派当选，使他成了希腊人的代言人。”用 [[#def-macedon]] 和公元前336年这个年份，纠正这个政制上的类比。
:::solution
马其顿是一个有王室的王国。亚历山大在公元前336年成为国王，是因为腓力遇刺、他是继承人，不是因为一个雅典式的公民大会选举了他。雅典是一个它的一部分男子的民主制。公元前338年的喀罗尼亚，是那一类同盟与那个王国之间的一场战役。更大，不会把王权变成抽签的民主制，而一个马其顿国王也不是他所击败的那些城邦的代言人。这位读者先把一个君主国改名为城邦，再把诸城邦改名为民族。
:::
:::

:::exercise 没有终结的东西 {level=2}
列出两样在公元前323年终结了的东西和两样没有终结的东西。把被征服的诸民族和诸城邦放在这条线的正确一边。
:::solution
终结的是亚历山大的生命，以及他征服的阿契美尼德诸地被作为一个王国继承的前景。没有终结的是诸城邦——它们在国王们之下、国王们旁边延续——以及被征服诸地的社会——在他之前它们是国家和人口，而任何想要它们岁入的国王仍然少不了它们。[[#thm-death]] 就是这道分线。一份把“希腊人”或“埃及”放进终结一侧的清单，重复的是传说。
:::
:::

:::exercise 没有军队规模 {level=2}
一本书给出高加米拉的一个精确的士兵数字，并把这个数字当作这场战役之所以要紧的原因。本章为什么拒绝这个数字？关于公元前331年，你仍然能说什么？
:::solution
年表没有确定军队规模，而取自传说传统的数字是虚假的精确。政治上的结果不需要它。公元前331年，波斯国王在战场上被击败，帝国的中心此后脱离他的家族的控制。这就足以让征服是真实的。这不足以让征服成为一个单一的持久王国——那是在公元前323年的死亡处决定的，不是由一条战线的规模决定的。拒绝这个数字，保住的是 [[#thm-death]] 的诚实。
:::
:::

:::exercise 欧洲的统一者 {level=3}
一幅肖像下面写着：“亚历山大，欧洲的统一者与文明的带来者，公元前334—前323年。”如果这些年代用得正确就接受它们，并拒绝那些称号。说出什么样的证据会使这些称号成为真话。
:::hint
问一问：公元前334年到公元前323年之间军队实际去了哪里，谁本来就住在那里，死亡之后存在着什么政治形态。欧洲和文明是要检验的词，不是那些数字。
:::
:::solution
这些年代可以标记一段真实的跨度：公元前334年的渡海和公元前323年的死亡，十一年的战事。它们不能标记一个欧洲联盟或一项开化使命。路线是阿契美尼德帝国及其邻近地区，包括埃及和巴比伦尼亚——它们是古老的国家与文字的中心——以及作为帝国腹地的伊朗诸地。文明作为一份礼物，在这些证据上站不住。欧洲作为被统一之物也站不住，因为欧洲不是战场，也没有产生一个欧洲国家。公元前323年之后，继承裂成希腊化诸王国。这些称号要成为真话，需要被征服的土地在公元前334年之前没有政治秩序，还需要一次死亡之后剩下一个欧洲政体屹立不倒。肖像的年代是一段生涯。图注的名词是一首后来的颂诗。[[#thm-not-europe]] 就是那个拒绝。
:::
:::

:::exercise 罗马将遭遇什么 {level=3}
不讲罗马的历史，说出后来的罗马共和国将会遭遇的是一个什么样的希腊与马其顿世界，不会遭遇的是哪一个。把公元前323年当作那道门轴。
:::hint
留在那次死亡的结果上：一个王国还是几个，一个民族还是国王们旁边的诸城邦。指名 [[rome/republic]] 为讲授罗马制度的地方，不要引进那座城市的战事。
:::
:::solution
公元前323年之后，被征服的帝国没有保持为一个王国。从将领们的战争中沉淀出来的世界，是希腊化的多元格局：在埃及、在亚洲、在马其顿的诸王国，城邦与同盟仍然存在，非希腊的社会在国王统治下原地不动。后来的罗马共和国遭遇的就是那个世界。它不会遭遇一个亚历山大完工的希腊民族，也不会继承一个欧洲国家。[[rome/republic]] 是讲授罗马自己的官职与传统开端的课。本章不叙述那些。门轴是那次死亡。在此之前，是一个国王的征服。在此之后，是几个君主国。谁把罗马讲成一个统一的希腊的继承人，谁就跳过了 [[#thm-death]]。
:::
:::
