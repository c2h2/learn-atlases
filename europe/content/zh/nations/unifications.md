哪些民族得到了一个国家，哪些没有？

民族国家是一个政治工程：国家应当与一个民族相匹配，这一论断由战争、谈判、学校、地图与排除来执行。它不是一个人的醒来，也不是自然的完成。在公元1861年3月17日意大利王国的宣告与公元1871年1月18日德意志帝国的宣告之间，两个这样的工程按它们的制造者设定的条件成功了。波兰没有得到一个国家。爱尔兰也没有。捷克人也没有。公元1905年，瑞典与挪威的联盟解体了，那是另一种性质的一个民族结果。这一课就是那份清单：谁在一座首都之内被包括进来，谁被拒绝给一座首都。

普查那一章，[[nations/industry]]，已经拒绝把一个人口总数当作一个民族。爱尔兰被清点的下降不是一次为建立一个国家投出的票，而英格兰与威尔士增长到32,527,843也不是一部宪法。下面接着讲的是那些数字所不包含的政治史。

## 一个工程，不是一次觉醒

:::definition 民族国家 {#def-nation}
在本课里，**民族国家**是这样一种政治工程：它主张国家的边界与民族的成员资格应当是同一个东西。它由可指认的行为造成：宣告、战争、条约、加冕、拒绝。它不是一个生物学上的人，也不是对一个本来就已经是国家的民族的发现。
:::

语言、教会与记忆可以比下面任何一个日期更古老。古老不是问题所在。问题是哪些工程在这些年份得到了一个国家，凭借哪些行为，以及哪些工程没有得到。一个沉睡与觉醒的隐喻回答不了它，因为隐喻不会失败。一个行为会。

:::theorem 统一是战争与谈判，不是自然的完成 {#thm-project}
意大利王国与德意志帝国由带着日期的战争与谈判的行为造成。它们不是一个意大利人或一个德意志人的自然完成，而本课不把它们当作任何说那种语言的人的命运。
:::
:::proof
锁定的行为是这些。意大利王国于公元1861年3月17日宣告成立。威尼斯（Venice）的转让属于公元1866年的一部分——那一年7月3日打了柯尼希格雷茨（Königgrätz）——而本图谱没有为威尼斯锁定一个单独的条约日，所以一个也不发明。意大利军队于公元1870年9月20日夺取罗马。在德意志一方，柯尼希格雷茨是普鲁士对奥地利的一次胜利。公元1870年9月1日与2日的色当（Sedan），是法国帝国军队的一次失败。德意志帝国于公元1871年1月18日在凡尔赛（Versailles）的镜厅宣告成立，而法国的那场战争还没有结束。《法兰克福和约》在公元1871年5月10日，是那一场和平。每一项都是一个决定，或一场战事的一个结局，不是一朵花开。会构成对这条论断的反证的，是表明这两个国家中的任何一个在没有战争、没有谈判的情况下到来的证据，仿佛那是对某一个已经与后来的边界相吻合的单一意志的承认。边界本身就构成对那幅图景的反证。在公元1861年3月17日，威尼斯与罗马不在新王国的手中。在1871年，奥地利的德语者在刚刚宣告的那个帝国之外。一个自行完成的自然，不会把那些人留在那个行为的错误一边。
:::

较早的那个德意志议会属于这个对照。公元1848年，一个法兰克福议会开会了，而那一年革命的大多数政权被击败了。公元1871年的帝国不是那个议会重新开会。它是一个在柯尼希格雷茨与色当之后宣告的、由普鲁士领导的联邦。记住1848——[[revolutions/restoration-and-1848]]讲授它——要点在于：一个民族议会可以开会，而仍然不是后来佩戴着民族名称的那个国家。如果民族只是醒来，那么法兰克福与凡尔赛就不会是两种不同的房间。

本图谱没有为公元1861年3月17日之前、在北方或南方的那些战事锁定日子，所以本课不发明它们。说出加里波第（Garibaldi）的远征，或加富尔（Cavour）的外交，而不带年份，是允许的。给它们定年则不是。年表确实锁定的东西，对这条论断已经足够：一次宣告，1866年之内的对威尼斯的一次较晚转让，以及公元1870年9月20日的罗马。那个王国并非完整地诞生。完整是觉醒故事所需要的，而年份把它扣住不给。

:::example 按标签相隔十年 {#ex-decade}
意大利王国于公元1861年3月17日宣告成立。德意志帝国于公元1871年1月18日宣告成立。年份标签之间的差距是多少，而两个日子之间的跨度为什么比那个差距略短一点？
:::solution
年份标签相差1871减1861，即10。从公元1861年3月17日起的十个整年，会结束于公元1871年3月17日。德意志的宣告落在公元1871年1月18日，在那个周年之前，所以日之间的跨度不足十年。那个图形的“十年”是标签之间的差距。它不是说两次宣告是一个事件，也不是说第二次完成了第一次。
:::
:::

:::quiz
哪一句关于公元1861年3月17日的读法是[[#thm-project]]所允许的？
- [ ] 意大利民族醒来了，而国家是那个人的完成
- [ ] 王国已经握有威尼斯与罗马，所以那次宣告完成了地图
- [x] 那次宣告是一个政治行为，而威尼斯与罗马还没有在新王国的手中

:::solution
威尼斯的转让属于1866年的一部分，而罗马于公元1870年9月20日被夺取。德意志帝国于公元1871年1月18日宣告成立，那是另一个行为，按年份标签晚了十年。那个意大利的日期是一个在某一刻的工程，不是一个已经完成的人，也不是德意志帝国。
:::
:::

## 1866、1867与一个二元制君主国

柯尼希格雷茨，又称萨多瓦（Sadowa），是公元1866年7月3日。它是普鲁士与奥地利之间的一场会战。本课不给出伤亡总数。这场会战在论证中做的事情是政治性的。普鲁士接着可以去建造一个把奥地利排除在外的德意志。战败的奥地利在自己帝国内部进行谈判。威尼斯转手给意大利，是同一年份的一部分。任何为威尼斯添加一个条约日的人，都是在发明一个年表没有锁定的日期。“属于1866年的一部分”就是被允许的句子的全部。

:::definition 折衷方案 {#def-ausgleich}
**1867年折衷方案**（Ausgleich）是那次把哈布斯堡帝国变成奥匈——即一个二元制君主国——的妥协。弗朗茨·约瑟夫（Franz Joseph）于公元1867年6月8日加冕为匈牙利国王。这个安排承认了一个在皇帝之下的匈牙利王国。它不是这个王朝所统治的每一个人民的民族国家，也不是同一年的英国改革法案。
:::

:::theorem 折衷方案承认匈牙利，而拒绝给捷克人一个对等物 {#thm-dual}
公元1867年的妥协与公元1867年6月8日的加冕，是有利于一个匈牙利王国的行为。它们没有给捷克人一个相匹配的国家。一个二元制君主国是一个王朝与一个王国之间的交易，不是它的一切民族的觉醒。
:::
:::proof
年表锁定了折衷方案的年份与加冕的日子，而对于波希米亚没有任何平行的锁定。在这些年份里，捷克民族政治要求一种与匈牙利的相当的地位，而没有得到它。会构成对这条论断的反证的，是一个1867年的——或加冕那个季节的——按匈牙利模式建立一个捷克王国的锁定行为。本图谱里没有。同样会构成对它的反证的，是表明这个二元结构只是仪式性的、而哈布斯堡的每一个人民都已经拥有与匈牙利相同的公共地位的证据。需要一个特殊的妥协、需要一个单独的加冕，本身就是匈牙利的地位正在被造成、而不仅仅是被描述的证据。1867年的英国改革法案——[[nations/mass-politics]]里讲授——共享这个年份，而不共享这个行为。英国的一项选举权法令不是布达（Buda）的一场加冕。
:::

柯尼希格雷茨的失败改变了维也纳能够谈判的东西。它单凭自身并不撰写折衷方案。一个军事结果约束一座朝廷。朝廷与匈牙利的政治家们仍然达成了一个妥协，而不是另一种安排——其中包括捷克人想要的那个安排。约束不是选择的缺席。那个区分将在[[nations/toward-1914]]里更尖锐地回来。

:::example 一年，两种行为 {#ex-1867}
折衷方案定年为1867年，而弗朗茨·约瑟夫于公元1867年6月8日加冕为匈牙利国王。柯尼希格雷茨在公元1866年7月3日。关于这些日期的关系，你可以说什么，而不能添加哪一个条约日？
:::solution
年份标签相差1867减1866，即1。加冕落在7月3日的周年之前，所以日之间的跨度不足一年。你可以说失败在妥协之先，并改变了这场交易。你不可以说柯尼希格雷茨就是折衷方案，也不可以为1866年之内的一个威尼斯条约发明一天。威尼斯的转让属于1866年的一部分，在本图谱没有单独的条约日。加冕是折衷方案那一年之内一个有日期的行为。它单凭自身，不是一次给捷克人的授予。
:::
:::

## 罗马、色当、凡尔赛、法兰克福

公元1870年承载着两个容易被粘在一起、却不应当被粘在一起的标记。色当是9月1日与2日：一支法国帝国军队被击败，而第二个法兰西帝国没能在这场失败之后作为一个继续作战的政府存续下来。本课不为随后继续作战的那个共和国给出一个日子，因为年表没有锁定一个。罗马是9月20日：意大利军队夺取这座城市。公元1861年宣告的那个王国还没有握有它所声称的首都。夺取这座城市终结了教皇对罗马的统治。按本处年表，它并没有了结与教廷的争执，而本课不发明一个更晚的条约日来把故事讲完。

色当与罗马共享一个年份。罗马的日期落在色当的日期之后。那个次序是真实的。它不是一条单一原因句子的许可证，在那种句子里，一场战役是另一场战役的含义。法国在罗马的权力曾是那个意大利王国等待的部分原因。等待结束于一场法国正在输掉的战争。意大利政府仍然需要决定夺取这座城市。一个变得更容易的决定仍然是一个决定。

:::example 公元1870年9月的两个日期 {#ex-1870}
把公元1870年9月1–2日放到公元1870年9月20日旁边。每个日期锁定什么，而什么会是过度解读？
:::solution
色当锁定9月头两天里法国帝国军队的一次失败。罗马锁定9月20日意大利军队夺取这座城市。那个月历法里的差距从9月2日延伸到9月20日。过度解读会把色当与罗马做成一个事件，会为两者中任何一个发明一个伤亡总数，或者把夺取罗马当作一个民族的完成，而不是当作对一个公元1861年的王国尚未握有的城市的一次夺取。公元1861年3月17日的宣告仍然是一幅较早的、不完整的地图。
:::
:::

德意志帝国于公元1871年1月18日在镜厅宣告成立。威廉一世（Wilhelm I）采取皇帝称号。俾斯麦（Bismarck）是那位把普鲁士的道路造成了帝国的道路的大臣。本课程自己对那一天的注记所说的，正是那个房间没有取消的东西：巴黎仍在作战，而公社还没有开始。公社是公元1871年3月至5月，在[[nations/mass-politics]]里讲授。一座被夺取的宫殿里的一次宣告，不是城外那座城市的同意，也还不是和平。

《法兰克福和约》是公元1871年5月10日。那一天落在公社的诸月之内。一项和约与一座起义的城市可以共享一个季节，而不是同一个事实。和约结束了新帝国与法兰西国家之间的战争。它割让阿尔萨斯（Alsace）与洛林（Lorraine）的一部分。本课不陈述任何赔款。没有锁定任何款项，而一个猜出的总数只会显得精确。1月18日的宣告与5月10日的条约是两个行为。任何写下“德国在1月18日统一了，所以战争结束了”的人，都把两者折叠在了一起。

## 谁被拒绝了

:::theorem 波兰人、爱尔兰人与捷克人在这些年份没有得到国家 {#thm-refused}
公元1861年与1871年的成功不是一条普遍规则。波兰联邦已经由公元1772年、1793年与1795年的瓜分作为一个国家被抹除了。1861年或1871年都没有恢复一个波兰国家。爱尔兰在这些年份没有得到国家。捷克人没有得到公元1867年匈牙利安排的一个对等物。
:::
:::proof
诸次瓜分是锁定的：三个行为，而联邦作为一个国家消失了。它曾是一个庞大的欧洲政治体，不是地图上的空档。诸统一日期中没有一样把它放回去。波兰的政治生活延续在普鲁士之下、然后是德意志帝国之下、在俄国之下、以及在奥匈之下。延续不是一座首都。爱尔兰，在联合王国内部，有一个民族政治，而由[[nations/industry]]知道，它有一部普查史。它在本章锁定的任何日期上都没有一个单独的国家。捷克个案就是折衷方案本身，从它没有包括的那一面来读，正如[[#thm-dual]]所论证的。会构成对这条论断的反证的，是在这段年份里一个建立波兰、爱尔兰或捷克国家的宣告、条约或加冕。年表里没有任何一个。同样会构成对它的反证的，是一个证明，证明这里的“国家”意味着某种如此微弱的东西，以至于一个被拒绝的议会与一个被拒绝的王国仍然算作成功。它们不算。一个工程可以是真实的，而仍然被拒绝。
:::

拒绝不是关于心灵的沉默。华沙、都柏林与布拉格的人们争论、组织并且记忆。一个缺席的国家是关于谁掌握主权的证据，不是没有人想要一个国家的证据。那与[[sources/evidence]]里关于沉默的是同一条规则：档案记录的是谁被要求签署一项条约，不是一种愿望的缺席。

也不是每一个成功的工程都包括了它所称名的每一个人。公元1871年的德意志帝国是一个没有奥地利的德意志。公元1861年的意大利王国是一个没有罗马直到1870年、没有威尼斯直到1866年的意大利。包括与拒绝是同一种政治技艺。觉醒故事把两者都藏起来，因为一个醒来的人不去谈判一条边界。

:::example 一次发明出来的觉醒 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“公元1861年，意大利民族醒来了；公元1867年，哈布斯堡的每一个民族都得到了它的王国；公元1871年，德意志民族醒来了，所以到1871年，欧洲的每一个民族都有了它的国家。”把锁定的日期与添加的东西分开。
:::solution
公元1861年3月17日、1867年的折衷方案、以及公元1871年1月18日，是真实的行为，而它们不是觉醒。折衷方案没有给哈布斯堡的每一个民族一个王国：匈牙利在公元1867年6月8日加冕，而捷克人没有。“欧洲的每一个民族都有了它的国家”通不过[[#thm-refused]]。自公元1772年、1793年与1795年的瓜分以来，波兰没有了它自己的国家，而1871年没有恢复一个。爱尔兰没有得到任何一个。那句虚构的句子把三座首都提升为一条普遍规则。普遍规则才是那个将需要证据的部分，而那些拒绝就是反对它的证据。
:::
:::

## 公元1905年的一次分离

公元1905年，瑞典与挪威的联盟解体了。那是一个民族结果，而它不是一次统一。两个曾共享一个联盟的国家分开了。本课里没有人需要假装每一种民族情感都终结在一个更大的国家里，或者一个联盟一旦造成就是自然。年表锁定了那次解体，而没有为联盟的开端锁定一个日子，所以开端在这里不被给一个年份。要紧的是行为的种类。公元1861与1871在战争之后用宣告建造国家。1905终结了一个联盟。把它们放进一份叫作“诸民族的兴起”的清单里，那份清单就已经撒了谎。

那次解体也挡住了一幅整洁的世纪地图，在那幅地图里，1871是最后的话。晚于镜厅，一个欧洲的联盟散开了，而不是作为意大利或德意志的故事。民族政治不止一种形状。这些形状是有日期的。它们不是一架梯子。

:::quiz
瑞典与挪威联盟在公元1905年的解体，最好被描述为下面哪一个？
- [ ] 与德意志帝国的宣告同一种类的行为
- [ ] 波兰联邦的恢复
- [x] 一个把两个国家分开的民族结果，不是一次统一
- [ ] 爱尔兰与捷克诸地得到王国的那个时刻
:::solution
公元1905年解体的是一个联盟。它没有宣告一个帝国，没有恢复波兰，也没有给爱尔兰或捷克人一个国家。[[#def-nation]]允许不同的行为是民族的，而不把它们塞进一次觉醒的单一情节。
:::
:::

## 一个完整的案例：一座宫殿与一个缺席的首都

把公元1871年1月18日当作一个完整的案例来读，把5月10日放在它旁边，并且故意把华沙留在地图之外。

1月18日，帝国在镜厅宣告成立。房间里面的人是德意志诸邦的诸王公与大臣，在一位采取帝号的普鲁士国王之下。奥地利不在他们中间。法国的那场战争还没有结束。公社仍然在未来。典礼之中没有一样是对德语者的一次普查，而其中也没有一样是一个波兰的制宪议会。那个房间的光彩不是一条论证。论证是一份清单：谁在场，以及哪一个法律行为已经完成、哪一个还没有完成。

5月10日，《法兰克福和约》完成一个不同的行为：和平，以及阿尔萨斯与洛林一部分的割让。从1月18日到5月10日在一个季节之内。它足够长，长到宣告与条约是两样东西。一个只记得“1871”的学生，已经辜负了这个图形，因为这个图形给那一年不止一个事件。同样的纪律用到1870年上，会把色当与罗马保持分开。

现在把这份清单用到一个没有圆点的城市上。公元1871年1月的华沙处在俄国的统治之下。一个波兰国家没有在镜厅被宣告，也没有在法兰克福被创建。公元1772年、1793年与1795年的诸次瓜分，仍然是这份年表就波兰的国家地位所允许的最后的话。如果这个案例在起它的作用，1月18日看上去就应当比那个迷思更小，而不是更大。它是一个大国行为。它不是诸民族作为民族终于得到自身的那一年。

:::warning 觉醒，以及自然的完成
通常的故事说，意大利与德意志是一些等待站起来的民族，而公元1861与1871是它们站起来的时刻。这个故事看不见公元1861年缺失的威尼斯、直到公元1870年9月20日都缺失的罗马、德意志帝国里缺失的奥地利，以及折衷方案里缺失的布拉格。它看不见波兰人与爱尔兰人根本没有得到任何国家。一个工程可以成功，可以部分成功，可以被拒绝。自然不会在另一座首都仍在作战时，在一座宫殿里宣告一个帝国；也不会在公元1867年为一个王国加冕，同时把同一顶王冠扣住不给另一个民族。柯尼希格雷茨或色当的伤亡总数也修不好这个故事。这里一个也不给出。
:::

:::history
公元1871年1月18日，德意志帝国在凡尔赛的镜厅宣告成立。巴黎仍在作战，而公社还没有开始。《法兰克福和约》随后在公元1871年5月10日。那次宣告是一场战争之中的建国行为，不是一个德意志人的觉醒，也不是一个给波兰人的国家。
:::

## 通向何处

那些不得被要求做本章工作的数字在[[nations/industry]]。公元1848年的那个没有变成帝国的议会在[[revolutions/restoration-and-1848]]。谁能够在这里建成的诸国家之内投票，而谁仍然在选举权之外，在[[nations/mass-politics]]。这些国家后来向海外扩展的诸帝国在[[nations/empires]]。折衷方案建造的那个二元制君主国，仍然是在[[nations/toward-1914]]里面对七月危机的奥匈。更晚的诸边界，包括本处年表没有定年的任何一个波兰国家，属于[[wars/interwar]]，而不属于1871年。

:::summary
- 民族国家是由行为造成的一个政治工程，不是一个正在醒来的人，也不是自然的完成。
- 意大利王国于公元1861年3月17日宣告成立。威尼斯的转让属于1866年，没有单独的条约日。意大利军队于公元1870年9月20日夺取罗马。
- 柯尼希格雷茨是公元1866年7月3日。折衷方案是1867年，而弗朗茨·约瑟夫于公元1867年6月8日加冕为匈牙利国王。捷克人没有得到那个安排。
- 色当是公元1870年9月1–2日。德意志帝国于公元1871年1月18日在镜厅宣告成立。《法兰克福和约》是公元1871年5月10日。没有给出伤亡总数。
- 波兰人、爱尔兰人与捷克人在这些年份没有得到国家。公元1772年、1793年与1795年的诸次瓜分已经作为一个国家抹除了波兰联邦。
- 公元1905年，瑞典与挪威的联盟解体。那是一次分离，不是另一次统一。公元1861与1871的年份标签相差10，而1870与1871各自装着不止一个事件。
:::

## 习题

:::exercise 标签之间的差距 {level=1 check="10"}
意大利王国的年份标签与德意志帝国的年份标签之间隔着多少年？（请输入年数。）
:::solution
1871减1861是10。从公元1861年3月17日到公元1871年1月18日的日之间的跨度，比十个整年略短一点，因为1月18日在3月17日之前。被要求的数字是标签之间的差距。
:::
:::

:::exercise 妥协的年份 {level=1 check="1867"}
折衷方案，即创建奥匈的那次妥协，在哪一年？（请输入年份。）
:::solution
折衷方案是1867年。弗朗茨·约瑟夫在那一年6月8日加冕为匈牙利国王。公元1867年的英国改革法案是同一年里的另一个行为。
:::
:::

:::exercise 柯尼希格雷茨 {level=1 check="1866"}
柯尼希格雷茨战役，又称萨多瓦，在哪一年？（请输入年份。）
:::solution
柯尼希格雷茨是公元1866年7月3日。威尼斯的转让属于同一年。答案里不应当有任何伤亡数字，也没有锁定的单独的威尼斯条约日。
:::
:::

:::exercise 宣告与条约 {level=2}
解释为什么“德国在公元1871年1月18日统一了”与“对法国的战争在公元1871年5月10日结束了”不是同一个论断。
:::solution
公元1871年1月18日是帝国在镜厅的宣告，而巴黎仍在作战，也在3月至5月的公社之前。公元1871年5月10日是《法兰克福和约》，是和平，包括阿尔萨斯与洛林一部分的割让。宣告不是条约。图形给公元1871年不止一个事件，正是这个原因。两个日期都没有恢复一个波兰国家，也没有把奥地利包括进新帝国。
:::
:::

:::exercise 妥协留下的那一面 {level=2}
为什么捷克个案是对折衷方案的一个检验，而不是对匈牙利成功的一条脚注？
:::solution
折衷方案与公元1867年6月8日的加冕，在弗朗茨·约瑟夫之下造成了一个匈牙利王国。捷克政治要求一种相当的地位，而在这些年份没有得到它。如果妥协是帝国“诸民族”的觉醒，捷克的被拒绝就不可理解。一旦折衷方案是与一个王国的交易，它就是可理解的。[[#thm-dual]]就是那个读法。匈牙利的成功与捷克人的被拒绝，是同一个安排从两面看。
:::
:::

:::exercise 公元1905年放在1871年旁边 {level=2}
为什么瑞典与挪威联盟在公元1905年的解体，不是“公元1871年已经揭示了一个民族的正常形态”的证据？
:::solution
公元1905年终结的是一个联盟。它没有通过宣告建造一个更大的民族国家，也没有遵循公元1861或1871的模式。一次更晚的分离显示，民族的结果不止一种形状。年表锁定了那次解体，而没有锁定联盟的第一个日子，所以答案不发明一个。“正常形态”正是[[#def-nation]]所拒绝的东西：行为，而不是一个由自然去填满的样板。
:::
:::

:::exercise 发明出来的普遍性 {level=3}
下面这句话为示例而虚构。它不是史料。“公元1861年意大利醒来之后，波兰、爱尔兰与捷克诸地在1871年之前注定会得到国家，因为一个民族不可能被拒绝。”要相信它，你得忽略年表里的什么？而哪一些锁定的拒绝杀死了它？
:::hint
把波兰的诸次瓜分列出来，然后问公元1861、1867与1871实际创建了什么。那句话里的“不可能”在做一条规律的工作。
:::
:::solution
相信它，意味着忽略波兰联邦在公元1772年、1793年与1795年作为一个国家被抹除、而在1861年或1871年没有被恢复；忽略爱尔兰在这些年份没有得到国家；并且忽略公元1867年加冕的是匈牙利，不是一个捷克王国。它还误读公元1861年本身：那个王国宣告成立时没有威尼斯——威尼斯只是作为1866年的一部分被转让——也没有罗马，罗马在公元1870年9月20日被夺取。“不可能被拒绝”正是本章否认的那条规律。诸工程被拒绝过。这句话是虚构的，而在日期面前仍然失败。
:::
:::

:::exercise 语言不是国家 {level=3}
一个反方论证说：意大利语、德语、波兰语、捷克语与爱尔兰语在这一切宣告之前就被使用，所以诸民族本来就在，而诸国家只是承认了它们。你可以承认什么？而那个反方论证仍然必须解释什么？
:::hint
承认语言的古老年代。然后把威尼斯、罗马、奥地利与布拉格放回那些日期里。问一问一条语言单独画不出哪一条边界。
:::
:::solution
承认语言与记忆可以比公元1861与1871更古老。[[#def-nation]]从未说一个工程发明说话。那个反方论证仍然必须解释：承认，如果它只是承认，为什么把威尼斯留在外面直到1866年，把罗马留在外面直到公元1870年9月20日，把奥地利留在德意志帝国之外，把捷克人留在匈牙利的交易之外；以及为什么波兰语与爱尔兰语的说话者根本没有在这些年份产出国家。一条把国家所称名的那种语言的使用者排除在外的边界，是一个政治决定。会支持那个反方论证的，是一个国家的边界与语言一道到来、而没有战争、谈判或拒绝。锁定的行为是战争、谈判与拒绝。诸语言可以古老。诸国家是有日期的。
:::
:::
