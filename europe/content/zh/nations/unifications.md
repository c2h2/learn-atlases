哪些民族得到了国家，哪些没有？

民族国家是一项政治工程：它主张国家应当与一个民族相吻合，并通过战争、谈判、学校、地图与排斥来实现这一主张。它不是某个人从沉睡中醒来，也不是自然的圆满。从1861年3月17日意大利王国宣告成立，到1871年1月18日德意志帝国宣告成立，有两项这样的工程按其缔造者设定的条件取得了成功。波兰没有得到国家，爱尔兰没有，捷克人也没有。1905年，瑞典与挪威的联合解体，这是另一种性质的民族结果。本课就是这样一份清单：谁被纳入了某个首都之下，谁又被拒于首都之外。

普查一章（[[nations/industry]]）已经拒绝把人口总数当作民族。爱尔兰清点人数的下降不是为建国投下的一票，英格兰与威尔士的人口增至32,527,843也不等于一部宪法。下文讲述的，是这些数字所不包含的政治史。

## 是工程，不是觉醒

:::definition 民族国家 {#def-nation}
在本课中，**民族国家**指这样一项政治工程：它主张国家的疆界与民族的成员资格应当一致。它由可以指认的行为造成：宣告、战争、条约、加冕与拒绝。它不是生物意义上的人，也不是发现了一个本已是国家的民族。
:::

语言、教会与记忆可能比下文任何日期都古老。问题不在于古老与否，而在于：在这些年份里，哪些工程得到了国家，凭借的是哪些行为，又有哪些工程没有得到。沉睡与觉醒的隐喻回答不了这个问题，因为隐喻不可能失败，而行为可能失败。

:::theorem 统一是战争与谈判，不是自然的圆满 {#thm-project}
意大利王国与德意志帝国是由有确切日期的战争行为与讨价还价造成的。它们不是意大利人或德意志人的自然圆满，本课也不把它们当作所有说这种语言的人的宿命。
:::
:::proof
锁定的行为如下。意大利王国于1861年3月17日宣告成立。威尼斯（Venice）的移交属于1866年的事件——这一年的7月3日发生了柯尼希格雷茨（Königgrätz）战役——本图谱没有为威尼斯锁定单独的条约日期，因此不编造。意大利军队于1870年9月20日攻占罗马。在德意志方面，柯尼希格雷茨战役是普鲁士对奥地利的胜利。1870年9月1日至2日的色当（Sedan）战役，是法国帝国军队的失败。德意志帝国于1871年1月18日在凡尔赛（Versailles）宫镜厅宣告成立，其时对法战争尚未结束。1871年5月10日的《法兰克福和约》才带来和平。每一项都是一个决定或一场战役的结局，而不是花开。能够推翻这一论断的，是表明两国之中任何一国的诞生既无战争也无讨价还价、仿佛只是承认一个早已与后来疆界相吻合的单一意志的证据。疆界本身就与这幅图景相抵触。1861年3月17日，威尼斯与罗马都不在新王国手中；1871年，奥地利的德语居民处在刚刚宣告成立的帝国之外。自行圆满的自然，不会把这些人留在这一行为的另一边。
:::

更早的德意志议会可以作为对照。1848年，法兰克福议会召开，而那一年的革命政权大多遭到失败。1871年的帝国并不是那个议会的重开，而是在柯尼希格雷茨与色当之后宣告成立、由普鲁士主导的联邦。记住1848年（见[[revolutions/restoration-and-1848]]）的意义在于：民族议会可以召开，却仍然不是后来冠以民族之名的国家。如果民族只是醒来，法兰克福与凡尔赛就不会是两种截然不同的会场。

本图谱没有为1861年3月17日之前北方或南方的历次战役锁定日期，所以本课不编造日期。可以提及加里波第（Garibaldi）的远征或加富尔（Cavour）的外交，但不标年份，更不能为它们定年。年表锁定的内容已足以支撑这一论断：一次宣告，1866年间稍后对威尼斯的移交，以及1870年9月20日的罗马。这个王国诞生时并不完整。觉醒叙事需要的是完整，而日期恰恰不给。

:::example 年份标签相隔十年 {#ex-decade}
意大利王国于1861年3月17日宣告成立，德意志帝国于1871年1月18日宣告成立。两个年份标签相差多少？为什么两个日期之间的跨度比这个差距略短？
:::solution
年份标签相差1871减1861，即10。从1861年3月17日起算的十个整年，应止于1871年3月17日。德意志帝国的宣告在1871年1月18日，早于这个周年日，所以两个日期之间的跨度不足十年。图示中的“十年”是标签之间的差距，并不是说两次宣告是同一事件，也不是说后者完成了前者。
:::
:::

:::quiz
对1861年3月17日的哪一种解读是[[#thm-project]]所允许的？
- [ ] 意大利民族醒来了，国家是这个人的圆满
- [ ] 王国已经掌握威尼斯与罗马，所以这次宣告完成了版图
- [x] 这次宣告是一个政治行为，当时威尼斯与罗马尚不在王国手中
- [ ] 这个日期与镜厅中的德意志宣告是同一个行为
:::solution
威尼斯的移交属于1866年的事件，罗马于1870年9月20日被攻占。德意志帝国于1871年1月18日宣告成立，那是另一个行为，按年份标签晚了十年。意大利的这个日期是某一时刻的一项工程，既不是一个已经圆满的人，也不是德意志帝国。
:::
:::

## 1866年、1867年与二元君主国

柯尼希格雷茨战役，又称萨多瓦（Sadowa）战役，发生在1866年7月3日，是普鲁士与奥地利之间的一场会战。本课不给出伤亡总数。这场战役在论证中的作用是政治性的：普鲁士此后得以建立一个排除奥地利的德意志；战败的奥地利则在自己的帝国内部讨价还价。威尼斯转归意大利，也属于同一年的事件。凡是为威尼斯添加条约日期的人，都是在编造年表没有锁定的日期。“属于1866年的事件”就是所允许的全部说法。

:::definition 奥匈折衷方案 {#def-ausgleich}
**1867年折衷方案**（Ausgleich）是把哈布斯堡帝国改组为奥匈帝国这一二元君主国的妥协。弗朗茨·约瑟夫（Franz Joseph）于1867年6月8日加冕为匈牙利国王。这一安排承认了皇帝之下的匈牙利王国。它不是该王朝治下每个民族的民族国家，也不是同年的英国改革法案。
:::

:::theorem 折衷方案承认了匈牙利，却拒绝给予捷克人对等地位 {#thm-dual}
1867年的妥协与1867年6月8日的加冕，是有利于匈牙利王国的行为。它们没有给予捷克人与之相当的国家。二元君主国是一个王朝与一个王国之间的交易，而不是其治下所有民族的觉醒。
:::
:::proof
年表锁定了折衷方案的年份与加冕的日期，却没有为波希米亚锁定任何对应的事件。这些年间，捷克民族政治要求获得与匈牙利相当的地位，却没有得到。能够推翻这一论断的，是1867年或加冕前后锁定的某一行为，按照匈牙利模式建立了捷克王国。本图谱中没有这样的行为。同样能够推翻它的，是表明二元结构只具礼仪性质、哈布斯堡治下各民族早已与匈牙利享有同等公共地位的证据。正因为需要一项特别的妥协、一场单独的加冕，可见匈牙利的地位是被创造出来的，而不仅仅是被描述出来的。1867年的英国改革法案（见[[nations/mass-politics]]）与之同年，却不是同一行为。英国的一项选举权法令不是在布达（Buda）举行的加冕。
:::

柯尼希格雷茨的失败改变了维也纳的谈判筹码，但它本身并没有写出折衷方案。军事结果约束朝廷；朝廷与匈牙利政治家仍然选择了这一妥协，而不是别的安排，包括捷克人想要的那种安排。受到约束并不等于没有选择。这一区分将在[[nations/toward-1914]]中更尖锐地再次出现。

:::example 同一年，两类行为 {#ex-1867}
折衷方案定年为1867年，弗朗茨·约瑟夫于1867年6月8日加冕为匈牙利国王，柯尼希格雷茨战役发生在1866年7月3日。关于这些日期之间的关系，你可以说什么？又不能添加哪个条约日期？
:::solution
年份标签相差1867减1866，即1。加冕在7月3日的周年日之前，所以两个日期的跨度不足一年。你可以说，战败在妥协之前，并改变了交易的条件。你不能说柯尼希格雷茨战役就是折衷方案，也不能为1866年间的威尼斯条约编造日期。威尼斯的移交属于1866年的事件，本图谱中没有单独的条约日期。加冕是折衷方案那一年中有确切日期的行为，其本身并不是对捷克人的授予。
:::
:::

## 罗马、色当、凡尔赛与法兰克福

1870年有两个标志性事件，容易被混为一谈，却不应如此。色当战役在9月1日至2日：一支法国帝国军队战败，法兰西第二帝国没能在此后作为战时政府存续下去。随后继续作战的共和国，本课不给出其日期，因为年表没有锁定。罗马在9月20日：意大利军队攻占该城。1861年宣告成立的王国此前一直没有掌握它所主张的首都。攻占罗马终结了教皇对罗马的统治，但按本处年表，并没有了结与教廷的争端，本课也不编造后来的条约日期来为故事收尾。

色当与罗马同在一年，罗马的日期在色当之后。这一先后顺序是真实的，但它不允许写出单一原因的句子，仿佛一场战役就是另一事件的全部意义。法国在罗马的力量，曾是意大利王国按兵不动的部分原因；这种等待结束于一场法国正在输掉的战争。意大利政府仍须作出攻占罗马的决定。一个变得容易的决定，仍然是决定。

:::example 1870年9月的两个日期 {#ex-1870}
把1870年9月1日至2日与1870年9月20日放在一起。每个日期锁定了什么？什么样的解读属于过度解读？
:::solution
色当锁定的是9月头两天法国帝国军队的战败；罗马锁定的是9月20日意大利军队攻占该城。这个月里两者之间的间隔是从9月2日到9月20日。过度解读包括：把色当与罗马当作同一事件；为两者任一编造伤亡总数；或者把攻占罗马当作一个民族的圆满，而不是攻占一座1861年的王国尚未掌握的城市。1861年3月17日的宣告仍然是一幅更早的、不完整的地图。
:::
:::

德意志帝国于1871年1月18日在镜厅宣告成立，威廉一世（Wilhelm I）接受皇帝称号。俾斯麦（Bismarck）是使普鲁士道路成为帝国道路的大臣。本课程自身对这一天的注记，说明了这个大厅抹不掉的事实：巴黎仍在作战，公社尚未开始。巴黎公社存在于1871年3月至5月，见[[nations/mass-politics]]。在一座被占领的宫殿里宣告建国，既不代表城外那座城市的同意，也还不是和平。

《法兰克福和约》签订于1871年5月10日，正值公社存在的几个月之中。一项和约与一座起义的城市可以同处一季，却不是同一事实。和约结束了新帝国与法兰西国家之间的战争，割让了阿尔萨斯（Alsace）和洛林（Lorraine）的一部分。本课不提赔款，因为没有锁定任何金额，猜测的数字只会显得精确。1月18日的宣告与5月10日的和约是两个行为。凡是写下“德国在1月18日统一，所以战争结束了”的人，都把两者混为一谈了。

## 谁遭到了拒绝

:::theorem 波兰人、爱尔兰人与捷克人在这些年份没有得到国家 {#thm-refused}
1861年与1871年的成功并非普遍规律。波兰联邦早已因1772年、1793年与1795年的三次瓜分而作为国家被抹去，1861年和1871年都没有恢复波兰国家。爱尔兰在这些年份没有得到国家。捷克人也没有得到与1867年匈牙利安排相当的待遇。
:::
:::proof
历次瓜分是锁定的：三个行为之后，联邦作为国家不复存在。它曾是欧洲的一个大型政治体，而不是地图上的空白。统一时期的任何日期都没有使它复国。波兰的政治生活在普鲁士（后为德意志帝国）、俄国与奥匈的统治下延续，但延续不等于拥有首都。爱尔兰在联合王国内部有其民族政治，从[[nations/industry]]也可知它有一部普查史，但在本章锁定的任何日期上，它都没有单独的国家。捷克的情形就是折衷方案本身，只是从它未曾包括的一面来看，正如[[#thm-dual]]所论证的。能够推翻这一论断的，是这些年间建立波兰、爱尔兰或捷克国家的某次宣告、某项条约或某场加冕。年表中没有这样的事件。同样能够推翻它的，是证明这里的“国家”含义如此薄弱，以至于被拒绝的议会和被拒绝的王国仍可算作成功。它们不算。一项工程可以是真实的，却仍然遭到拒绝。
:::

这种拒绝并不意味着人们心中毫无想法。华沙、都柏林与布拉格的人们争论、组织、记忆。国家的缺席是关于谁掌握主权的证据，而不是无人想要国家的证据。这与[[sources/evidence]]中关于沉默的规则相同：档案记录的是谁受邀签署条约，而不是愿望的缺席。

成功的工程也并未把它所称名的人全都包括进来。1871年的德意志帝国是没有奥地利的德意志；1861年的意大利王国，在1870年之前没有罗马，在1866年之前没有威尼斯。纳入与拒绝是同一种政治技艺。觉醒叙事把两者都掩盖了，因为醒来的人不会去谈判疆界。

:::example 编造的觉醒 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1861年意大利民族醒来，1867年哈布斯堡的每个民族都得到了自己的王国，1871年德意志民族醒来，所以到1871年，欧洲每个民族都有了自己的国家。”请把锁定的日期与添加的内容区分开来。
:::solution
1861年3月17日、1867年的折衷方案与1871年1月18日都是真实的行为，但都不是觉醒。折衷方案并没有给哈布斯堡的每个民族一个王国：1867年6月8日加冕的是匈牙利，捷克人则没有。“欧洲每个民族都有了自己的国家”通不过[[#thm-refused]]的检验。自1772年、1793年与1795年的瓜分以来，波兰就没有自己的国家，1871年也没有恢复。爱尔兰也没有得到国家。这句虚构的话把三个首都上升为一条普遍规律。需要证据的正是这条普遍规律，而那些拒绝就是反对它的证据。
:::
:::

## 1905年的分离

1905年，瑞典与挪威的联合解体。这是一项民族结果，但不是统一：两个曾经结成联合的国家分道扬镳。本课不需要假装每一种民族情感都终结于一个更大的国家，也不需要假装联合一旦形成就是天然的。年表锁定了这次解体，却没有锁定联合开始的日期，所以这里不为其开端标注年份。要紧的是行为的种类：1861年与1871年是战后以宣告建立国家，1905年则是终结一个联合。把它们列入一份名为“民族的兴起”的清单，这份清单从一开始就是假的。

这次解体也打破了一幅以1871年为定论的整齐的世纪地图。在镜厅宣告之后，欧洲又有一个联合解体，而这并不是意大利或德意志的故事。民族政治不止一种形态。这些形态各有日期，但并不构成一架阶梯。

:::quiz
1905年瑞典—挪威联合的解体，最恰当的描述是下列哪一项？
- [ ] 与德意志帝国宣告成立属于同一类行为
- [ ] 波兰联邦的复国
- [x] 使两个国家分离的民族结果，而不是统一
- [ ] 爱尔兰与捷克地区得到王国的时刻
:::solution
1905年解体的是一个联合。它没有宣告帝国，没有恢复波兰，也没有给爱尔兰人或捷克人一个国家。[[#def-nation]]允许不同的行为都具有民族性，而不必把它们塞进单一的觉醒情节。
:::
:::

## 完整案例：一座宫殿与一个缺席的首都

把1871年1月18日作为完整案例来解读，把5月10日放在旁边，并有意把华沙留在地图之外。

1月18日，帝国在镜厅宣告成立。在场的是德意志各邦的王公与大臣，簇拥着一位接受皇帝称号的普鲁士国王。奥地利不在其中。对法战争尚未结束，公社也尚未到来。典礼中没有任何内容是对德语居民的普查，也没有任何内容是波兰的制宪会议。大厅的辉煌不是论证。论证是一份清单：谁在场，哪些法律行为已经完成，哪些尚未完成。

5月10日，《法兰克福和约》完成了另一个行为：缔结和平，割让阿尔萨斯和洛林的一部分。从1月18日到5月10日不过一季，但已足以使宣告与和约成为两件不同的事。只记得“1871年”的学生，就没有读懂这张图，因为图上这一年有不止一个事件。用同样的纪律处理1870年，也能把色当与罗马分开。

现在把这份清单用到一座图上没有数据点的城市。1871年1月的华沙处在俄国统治之下。波兰国家既没有在镜厅宣告成立，也没有在法兰克福诞生。就波兰的国家地位而言，1772年、1793年与1795年的历次瓜分仍是这份年表所允许的最后结论。如果这个案例发挥了作用，1月18日看上去就应当比那个迷思更小，而不是更大。它是一次大国行为，而不是各民族本身终于各得其所的一年。

:::warning 觉醒与自然的圆满
通常的说法是：意大利与德意志是等待崛起的民族，1861年与1871年是它们崛起的时刻。这种说法看不见1861年缺了威尼斯，直到1870年9月20日还缺着罗马，德意志帝国中缺了奥地利，折衷方案中缺了布拉格；也看不见波兰人与爱尔兰人根本没有得到任何国家。一项工程可以成功，可以部分成功，也可以遭到拒绝。自然不会在另一座首都仍在作战时在宫殿里宣告帝国，也不会在1867年为一个王国加冕、同时拒绝把同样的王冠给予另一个民族。柯尼希格雷茨或色当的伤亡总数也补救不了这种说法，这里一个也不给出。
:::

:::history
1871年1月18日，德意志帝国在凡尔赛宫镜厅宣告成立。其时巴黎仍在作战，公社尚未开始。随后，《法兰克福和约》于1871年5月10日签订。这次宣告是战争期间的建国行为，既不是德意志人的觉醒，也没有给波兰人一个国家。
:::

## 通向何处

不应被要求承担本章任务的那些数字，见[[nations/industry]]。没有演变为帝国的1848年议会，见[[revolutions/restoration-and-1848]]。在这里建立的国家之内谁能投票、谁仍被排除在选举权之外，见[[nations/mass-politics]]。这些国家随后向海外扩张的帝国，见[[nations/empires]]。折衷方案所建立的二元君主国，也就是在[[nations/toward-1914]]中面对七月危机的奥匈帝国。更晚的疆界，包括本处年表未予定年的任何波兰国家，属于[[wars/interwar]]，而不属于1871年。

:::summary
- 民族国家是由行为造成的政治工程，不是正在醒来的人，也不是自然的圆满。
- 意大利王国于1861年3月17日宣告成立。威尼斯的移交属于1866年的事件，没有单独的条约日期。意大利军队于1870年9月20日攻占罗马。
- 柯尼希格雷茨战役在1866年7月3日。折衷方案在1867年，弗朗茨·约瑟夫于1867年6月8日加冕为匈牙利国王。捷克人没有得到这样的安排。
- 色当战役在1870年9月1日至2日。德意志帝国于1871年1月18日在镜厅宣告成立。《法兰克福和约》签订于1871年5月10日。本课不给出伤亡总数。
- 波兰人、爱尔兰人与捷克人在这些年份没有得到国家。1772年、1793年与1795年的历次瓜分早已把波兰联邦作为国家抹去。
- 1905年，瑞典—挪威联合解体。这是分离，而不是又一次统一。1861年与1871年的年份标签相差10，1870年与1871年各有不止一个事件。
:::

## 习题

:::exercise 标签之间的差距 {level=1 check="10"}
意大利王国与德意志帝国的年份标签之间相隔多少年？（请输入年数。）
:::solution
1871减1861得10。从1861年3月17日到1871年1月18日的实际跨度略短于十个整年，因为1月18日早于3月17日。题目所问的是年份标签之间的差距。
:::
:::

:::exercise 妥协的年份 {level=1 check="1867"}
建立奥匈帝国的那项妥协，即折衷方案，是在哪一年？（请输入年份。）
:::solution
折衷方案在1867年。弗朗茨·约瑟夫于同年6月8日加冕为匈牙利国王。1867年的英国改革法案是同一年中的另一个行为。
:::
:::

:::exercise 柯尼希格雷茨 {level=1 check="1866"}
柯尼希格雷茨战役，又称萨多瓦战役，发生在哪一年？（请输入年份。）
:::solution
柯尼希格雷茨战役发生在1866年7月3日，威尼斯的移交也属于这一年的事件。答案中不应出现伤亡数字，也没有锁定单独的威尼斯条约日期。
:::
:::

:::exercise 宣告与和约 {level=2}
请解释为什么“德国在1871年1月18日统一”与“对法战争在1871年5月10日结束”不是同一个论断。
:::solution
1871年1月18日是帝国在镜厅宣告成立，当时巴黎仍在作战，也早于3月至5月的巴黎公社。1871年5月10日是《法兰克福和约》，即和平，其中包括割让阿尔萨斯和洛林的一部分。宣告不是和约，图上1871年有不止一个事件，原因正在于此。两个日期都没有恢复波兰国家，也没有把奥地利纳入新帝国。
:::
:::

:::exercise 妥协所遗漏的一面 {level=2}
为什么说捷克的情形是对折衷方案的检验，而不是匈牙利成功的一个脚注？
:::solution
折衷方案与1867年6月8日的加冕，在弗朗茨·约瑟夫之下造就了匈牙利王国。捷克政治要求获得相当的地位，在这些年份却没有得到。如果这一妥协是帝国内“各民族”的觉醒，捷克人遭到拒绝就无法理解；而一旦把折衷方案理解为与一个王国的交易，就完全可以理解。[[#thm-dual]]正是这样解读的。匈牙利的成功与捷克人遭到拒绝，是从两面看到的同一个安排。
:::
:::

:::exercise 把1905年放在1871年旁边 {level=2}
为什么1905年瑞典—挪威联合的解体，不能证明1871年已经揭示了民族的正常形态？
:::solution
1905年终结的是一个联合。它没有通过战争宣告建立一个更大的民族国家，也不遵循1861年或1871年的模式。较晚的这次分离表明，民族结果不止一种形态。年表锁定了这次解体，却没有锁定联合开始的日期，所以答案也不编造。“正常形态”恰恰是[[#def-nation]]所拒绝的：只有行为，没有一个等待自然去填满的模板。
:::
:::

:::exercise 编造的普遍性 {level=3}
下面这句话为示例而虚构。它不是史料。“1861年意大利一旦醒来，波兰、爱尔兰与捷克地区在1871年之前就注定会得到国家，因为一个民族不可能被拒绝。”要相信这句话，你必须忽略年表中的什么？哪些锁定的拒绝推翻了它？
:::hint
列出波兰的历次瓜分，再想一想1861年、1867年与1871年实际创立了什么。这句话中的“不可能”承担的是一条规律的作用。
:::
:::solution
相信这句话，就要忽略：波兰联邦在1772年、1793年与1795年作为国家被抹去，1861年或1871年都没有复国；爱尔兰在这些年份没有得到国家；1867年加冕的是匈牙利，而不是捷克王国。它还误读了1861年本身：王国宣告成立时既没有威尼斯（直到1866年的事件中才移交），也没有罗马（1870年9月20日才被攻占）。“不可能被拒绝”正是本章所否认的规律。工程确曾遭到拒绝。这句话是虚构的，在日期面前也站不住脚。
:::
:::

:::exercise 语言不等于国家 {level=3}
有一种反驳说：意大利语、德语、波兰语、捷克语与爱尔兰语早在这些宣告之前就有人使用，所以民族本来就存在，国家只是承认了它们。你可以承认什么？这种反驳仍须解释什么？
:::hint
承认语言的古老。然后把威尼斯、罗马、奥地利与布拉格放回这些日期之中。想一想有哪些疆界是语言本身划不出来的。
:::
:::solution
可以承认，语言与记忆可能比1861年与1871年更古老；[[#def-nation]]从未说过工程发明了语言。这种反驳仍须解释：如果只是承认，为什么威尼斯直到1866年、罗马直到1870年9月20日都被排除在外，奥地利被排除在德意志帝国之外，捷克人被排除在匈牙利的交易之外；又为什么说波兰语和爱尔兰语的人在这些年份根本没有建立国家。一条把国家所主张之语言的使用者排除在外的疆界，是一项政治决定。能够支持这种反驳的，是这样一个国家：其疆界随语言而来，无须战争、讨价还价或拒绝。而锁定的行为恰恰是战争、讨价还价与拒绝。语言可以古老，国家却有日期。
:::
:::
