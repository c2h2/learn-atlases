柏林会议做了什么，又没有做什么？

柏林会议的会期是公元1884年11月15日到1885年2月26日，它规范的是欧洲诸国家将如何相互承认彼此在非洲的诸主张。它并没有在一次会议里送掉一块大陆。征服比这场会议更长，而且它是暴力的。法国对阿尔及尔的入侵在1830年已经开始了。印度起义在1857年，而你所使用的对它的称呼本身就已经是一个论断。利奥波德二世（Leopold II）的刚果自由邦是他的私人统治，从1885年到1908年，此后是比属刚果。凯斯门特（Casement）的报告在1904年。同一年，10月2日，冯·特罗塔（von Trotha）针对赫雷罗人（Herero）发布了一道歼灭令。史家们把针对赫雷罗人与纳马人（Nama）、延续到1908年的那场战事归为灭绝种族罪。南非战争是1899至1902年。这些句子中没有一句包含一个死亡总数。本课也不会添加一个。

另一次不同的会议，1878年的柏林大会，是关于巴尔干半岛的。它不是这场会议。两个柏林容易混淆，而且不是同一个行为。

## 主张不是一块大陆

:::definition 柏林会议 {#def-conference}
**柏林会议**是公元1884年11月15日到1885年2月26日的那场会议，它规范的是欧洲在非洲的诸主张。它不是1878年的柏林大会。它不是一场在一个下午交出非洲主权的典礼，也不是对生活在那些主张之下的人们的一次清点。
:::

外交家们能够写下关于通知的规则，写下关于这样一个观念的规则——纸面上的主张需要有在场来支撑——以及关于刚果河与尼日尔河航行的规则。史家们用这些措辞来概括这场会议。这份概括是对一个外交行为的概括。它不是一次在1885年2月26日完成的、把内陆的治理从诸非洲政治体转到欧洲诸首都的移交。一条关于主张者应当如何行事的规则，不是那个行事本身。有效占领——常常用来指那条在场规则的措辞——是给诸帝国的一道指令。它本身并不是一次占领。

:::theorem 会议规范诸主张，而没有送掉一块大陆 {#thm-regulates}
柏林会议规范欧洲的诸主张。它没有在一次会议里移交非洲的主权。征服比1884年11月15日到1885年2月26日这段时日更长，而且它是暴力的。一个签字不是内陆的历史。
:::
:::proof
那些日期就是这场会议。年表在同一口气里说出了那个限度：会议没有把大陆送掉，而征服更长，而且是暴力的。会构成对这条论断的反证的是这样的证据：在1885年2月26日，内陆的诸政治体确实只凭这场会议就换了主权者，而此后没有再发生战争。这里采用的较晚的记录是对那幅图景的反证。利奥波德的私人统治从1885年延续到1908年。南非战争还在未来，1899至1902年。歼灭令在1904年10月2日。一场已经把征服完成的会议，是不会给那些年份留下任何工作的。同样会构成对一个较温和版本的反证的——在那个版本里，这场会议只是空谈，而暴力是别人的题目——是规范诸主张这件事的用意本身。外交家们正在组织一场他们预期诸国家会去追求的竞争。追求并不等同于那份《总约书》（General Act）。句子的两半都得在句子里。
:::

这些日期圈住的是一个季节，不是一个时刻，也不是一个十年。把两端都算在内来数日历日。11月，从15日到30日，是16天。12月有31天。1月有31天。2月，从1日到26日，是26天。于是16加31是47，加31是78，加26是104。这场会议的日期圈住了104个日历日。这个计数不是说有人在每一天都开了会。从11月15日到2月26日的已过时间，不把两端作为额外计入，是103天。无论哪种算法，这场会议都是一个外交的季节。它不是一个下午，也不是帝国的全部。

:::example 一百零四天 {#ex-days}
会议在公元1884年11月15日开幕，在1885年2月26日闭幕。如果两端都算在内，这些日期圈住了多少个日历日，而这个数字不意味着什么？
:::solution
11月贡献16天，从15日到30日。12月贡献31天，1月31天。2月贡献26天。总和是16加31加31加26，即104。这个数字圈住的是那段跨度。它不是说代表们每日开会，也不是说非洲的主权在这些日子的最后一天完成了转移。[[#thm-regulates]]就是那道算术不得被要求去膨胀的那条论断。
:::
:::

这场会议也没有把每一个非洲政治体都变成殖民地。有些国家不是被柏林的一个签字征服的，而征服在1885年2月之后仍在继续。本课不为那些较晚的胜利与失败发明年表没有锁定的年份。它说出的是那个明显的否定。一场规范诸主张的会议，并没有因此完成一幅地图。

:::quiz
1884至1885年的柏林会议做了下面哪一件事？
- [ ] 它在一次会议里把非洲大陆移交给了欧洲统治者
- [ ] 它就是柏林大会，解决了巴尔干问题
- [x] 它规范了欧洲的在非洲的诸主张将如何被承认，而把征服留在了有待完成之处
- [ ] 它发布了一个本图谱所依据的刚果死亡总数
:::solution
[[#def-conference]]与[[#thm-regulates]]把对诸主张的一份规范与一次主权的移交分开了。柏林大会是1878年，是另一次会议。本图谱没有说出任何刚果的死亡总数，所以这场会议不可能发布过一个我们随后拿来使用的总数。
:::
:::

## 柏林之前，以及另一个柏林

这个世纪里的帝国不是在会议开幕时开始的。1830年，法国对阿尔及尔的入侵开始了。法国的七月革命也在1830年。年表没有为两者锁定一个日子，所以本课不说哪个在先，也不把其中一个说成另一个的原因。共享一个年份不是共享一个事件。那次入侵是北非一场长久征服的开端，其中有垦殖者、士兵和本来就在那里的人们。没有给出伤亡总数。1830年在论证中做的事情是年代学上的：一个欧洲帝国正在靠入侵扩张，这在1884年11月15日之前五十多年。两个年份标签相隔五十四年，1884减1830。“瓜分”是一场晚到的加剧的标签。它不是帝国的出生。

:::example 1830年的两个事件 {#ex-1830}
七月革命与法国对阿尔及尔入侵的开端共享1830。你可以得出什么结论，又不可以得出什么？
:::solution
你可以得出：两者在本图谱中都定于那个年份；在巴黎的一场革命与对阿尔及尔的一次入侵是不同种类的事件。你不可以得出其中一个引起了另一个，因为没有一天被锁定，也没有给出任何机制。你不可以描述战事，也不可以添加伤亡总数。这一章使用那个年份，是为了把征服放在柏林会议之前，而不是完整地叙述1830年。那场革命同时也是[[revolutions/restoration-and-1848]]的一部分。
:::
:::

印度起义在1857年。年表对它的名称是起义。另有两个名称在使用之中，而每一个都是一个论断。“兵变”把事件置于英国军法之内，以东印度公司军队的士兵为中心。“第一次独立战争”把它置于一个后来的民族故事之内，以一场为了一个国家的战争为中心。两个名称都不中立，这就是本课偏爱年表的那个词、然后再说另两个名称在做什么的原因。这场起义是公司的统治在南亚次大陆大片地区上的一场危机。它不只是一群士兵的密谋，也不只是一个后来民族的起源迷思。本图谱没有为公司政府的终结锁定年份，所以那个年份不予给出。一场危机可以在没有后续法令的情况下讲授。

柏林大会的会期是1878年6月13日到7月13日。它是一份巴尔干的安排，处在年表没有单独定年的一场俄土冲突之后，而且它不是一场关于非洲诸海岸的会议。我们把它数出来，好让这场混淆有一个可以撞上的数字。6月，从13日到30日，是18天。7月，从1日到13日，是13天。总和是两端都算在内的31个日历日。一个月的巴尔干外交不是三个月的非洲主张制造，而1878年不是1884年。奥匈对波斯尼亚-黑塞哥维那的占领属于这次大会的安排。1908年的兼并危机——在[[nations/toward-1914]]里讲授——是一个后来的政府拿那次占领做的事。一段话足以阻止两个柏林变成同一个词。它不足以——也无意——叙述奥斯曼帝国的这个世纪。

:::example 两次会议，两段跨度 {#ex-berlins}
把1878年6月13日到7月13日的柏林大会，与公元1884年11月15日到1885年2月26日的柏林会议作个比较。每一次是为了什么，而它们圈住的天数有何不同？
:::solution
那次大会是一份巴尔干的安排。两端都算在内时，它圈住6月的18天加7月的13天，即31天。这场会议规范非洲的诸主张，圈住104个日历日，正如[[#ex-days]]里那样。两个年份标签相差1884减1878，即6，而会议一直开到1885年。两段跨度中哪一段都不是死亡总数，不是完成的征服，也不是一张把“柏林”当作一个词来用、仿佛两次会议是一次会议的许可证。
:::
:::

## 刚果，没有一个总数

:::definition 刚果自由邦 {#def-congo}
**刚果自由邦**是利奥波德二世的私人统治，从1885年到1908年。它还不是比属刚果——比属刚果是1908年之后的那个政制。它不是通常意义上的殖民地——并非布鲁塞尔的一个议会从一开始就统治着它。私人统治之下的暴行是有文献记录的。没有给出死亡总数。
:::

这场会议是一个刚果主张变得在国际上可被承认的一部分方式。承认不是那个政制。从1885年到1908年，统治者就是利奥波德本人。榨取橡胶的那种强制是一套统治，不是1885年2月26日表决通过、随后被遗忘的一项条款。罗杰·凯斯门特1904年的报告记录了暴行。本图谱拒绝那些作为死亡总数流传的大而整的数字。它们没有被确定到可以印出的地步。拒绝不是宣告无罪。一项罪行可以由一份报告、由强迫劳动的结构、由最终批评了它的那套外交来记录，而不需要一个本书不肯担保的数字。

会构成对那个拒绝的反证的，是一个年表本身接受了的总数。不曾有过。会构成对这种软化的反证的——把“暴行是有文献记录的”软化为“有人提出了指控”——是年表给予那份报告的地位：那是记录，不是一个本课可以自由地平衡掉的谣言。1908年，比利时国家把那片领地接过来，成为比属刚果。主权者变了。记录没有变。一次兼并不是对它之前那些年的清洗。

:::theorem 有文献记录的暴力不等一个死亡总数 {#thm-novictims}
在利奥波德的刚果发生的暴行，以及针对赫雷罗人与纳马人的那场战事，都是这段历史的一部分。史家们把1904至1908年的那场战事归为灭绝种族罪。两个案例都不是带着一个死亡总数来教授的，而一个确定的总数之缺席，并不是一项无罪的认定。
:::
:::proof
凯斯门特的报告在1904年。冯·特罗塔针对赫雷罗人的歼灭令在1904年10月2日。针对赫雷罗人与纳马人的那场战事延续到1908年。年表说出史家们把那场战事归为灭绝种族罪，并且同时禁止为那场战事和为刚果给出死亡总数。灭绝种族这个词晚于那道命令：拉斐尔·莱姆金（Raphael Lemkin）1944年的著作使用了它，而《防止及惩治灭绝种族罪公约》于1948年12月9日通过。把一个后来的法律范畴应用于较早的一场战事，是一位史家的判断，本图谱跟随这个判断。它不是说那道命令使用了那个后来的词。那道命令是一道歼灭的命令。那是意图的证据。会构成对这个归类的反证的是这样的证据：那道命令没有被执行，而那场战事是一场只针对战斗人员的有限战争。年表的归类站在那个读法的对面。会构成对不带一个数字来教授这两个案例这一做法的反证的，是一种相信只有一个总数才使暴力成为真实的观念。那些报告、那道命令与那个归类就是证据。一个借来的整数将是一个不同的、更弱的东西。
:::

1904年的两份文件不得合并。凯斯门特写的是刚果，在利奥波德的私人统治之下。冯·特罗塔的命令是德国的，在德属西南非洲，而它点的是赫雷罗人。纳马人是那场延续到1908年的战事的一部分。同一个年份，两个帝国，两种罪行。这个图形把它们放在同一个圆点上，因为那个年份同时承载两者，而图注说那个圆点不包含一个死亡总数。一个一定要为1904年拿出一个非洲故事的读者，已经拒绝了那个地理。

那道命令、那份报告、那些日期与那个归类就是内容。一套杀戮的程序不是。说出罪行的名称不需要它，而本课不提供一套。

## 一场不是会议的战争

南非战争从1899年打到1902年。交战的一方是大英帝国，另一方是两个布尔人共和国。它不是柏林会议的一场会期，会议自1885年2月26日就已经结束，按年份标签在1899年之前十四年，1899减1885。它是作为战争的帝国，发生在关于诸主张的规则已经被写下之后。非洲的居民并不是给那些共和国命名的那套外交的当事方，而且他们无论如何都生活在战争之中。没有给出死亡总数。把这场战争包括进来的用意，就是把阿尔及尔和1857年包括进来的用意：这场会议是诸多手段中的一种手段，而不是1830年到1908年之间欧洲帝国的全部。

废奴也不是那个帝国的终结。公元1807年的英国法令针对的是奴隶贸易，而不是奴隶制。公元1833年的法令在大部分大英帝国废除奴隶制，而学徒身份延续到1838年。大西洋贸易的登船估计——1501至1866年间12,521,354人——在[[states/atlantic]]里。它不是一份对刚果自由邦的描述，也不是一份对德属西南非洲的描述。领土帝国在英国的贸易成为非法之后继续存在，在英国的殖民地奴隶制被废除之后继续存在。任何把1833年当作帝国故事之终结的人，都解释不了1884年，也解释不了1904年。

有一个反方论证试图用这场会议关于奴隶贸易的措辞来拯救它。外交家们确实讨论过针对贸易的种种承诺。一场讨论不是一个人道主义的公约，而一项条款并不管辖刚果。会支持一个人道主义读法的，是一场其规则止住了随之而来的暴力的会议。随之而来的包括利奥波德的私人统治、凯斯门特的报告，以及一道歼灭令。那个条款赢不了那个检验。[[nations/industry]]已经把纤维、金融与帝国分成了关于英国工业化的诸论断。在这里，帝国不是关于棉花的一个论断。它是统治、主张与战争。

:::example 一次发明出来的移交 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1885年2月26日，刚果的人民成了比利时人，而会议的人道主义诸条款意味着此后没有任何暴力。”这句话在主权者、日期与后续上各错了什么？
:::solution
1885年2月26日是会议的闭幕，不是比利时统治的开端。1885至1908年的刚果自由邦是利奥波德二世的私人统治。比属刚果开始于1908年，主权者在那一年改变，而暴行的记录没有改变。凯斯门特的报告在1904年，在私人统治之内。关于奴隶贸易的人道主义讨论，无论外交家们写下了什么，都没有阻止那个统治，也没有阻止1904年10月2日那道在另一个殖民地里的歼灭令。那句发明出来的句子把一份对诸主张的规范变成了一个国籍的改变和一个和平的承诺。[[#thm-regulates]]与[[#thm-novictims]]就是纠正。没有添加任何死亡总数来让纠正显得更重。
:::
:::

## 一个完整的案例：会议的最后一日

把1885年2月26日当作一个完整的案例。它是会议闭幕的那一天。一位外交家可以带着一条关于诸主张的规则离开柏林。刚果盆地的一位统治者不会因为那位外交家离开就成了比利时臣民。利奥波德的私人统治定年起于1885年，也就是闭幕的同一年，而且那是他的统治。一个年份标签可以既容纳一个签字，又容纳一个私人的主权者，而不把它们变成一个政府。

问一问：在你把一个地方故事当作会议本身来讲之前，你需要什么。你会需要一份来自一个地方的史料，说出会议之后第二天是谁在治理，凭借什么武力，遭到什么抵抗。会议自己的那些文书不提供那份史料。[[sources/scale]]就是方法：一句关于外交家的真句子，常常是一句关于一个村庄的假句子。[[#ex-invented]]里那个发明出来的移交就是那句假句子。这个完整的案例是同一个检验，只是没有发明。会议闭幕，私人统治开始，暴行到1904年才有记录，比利时兼并到1908年才发生。四拍。它们之中没有一拍是死亡总数，也没有一拍是无罪开释。

把1904年10月2日放在那个案例旁边，尺度就又变了。一道歼灭令不是一场会议。它是一场针对赫雷罗人的战争中的一道命令，处在那场也针对纳马人、一直打到1908年的战事之内。史家们称那场战事为灭绝种族。那个后来的词——莱姆金的那个在1944年，而公约的那个在1948年12月9日——并没有使那道命令变得客气，也不要求你发明死了多少人。意图在那道命令里。持续在这些日期里。归类是年表告诉你应当跟随的史家们的判断。一个没有数字就不肯称那场战事为灭绝种族的学生，添加了一个证据并不需要的条件。一个发明那个数字的学生打破了另一条规则。两个学生都离开了这个案例。

:::warning 一个下午，以及一个能够把它了结的数字
两个迷思会拆掉这一章。第一个说柏林会议在一个下午就把非洲送掉了，所以1885年2月26日就是瓜分本身。这场会议延续到104个圈住的日子，它规范诸主张，而让征服处于未完成状态。1830年的阿尔及尔与1857年的起义是会议之前的帝国。南非战争与1904年那道命令是会议之后的帝国。第二个迷思说，没有一个人人同意的死亡总数，刚果就没有发生什么严重的事，赫雷罗人与纳马人就没有遭遇什么严重的事。凯斯门特的报告记录了暴行。那道命令是一道歼灭令。史家们把延续到1908年的那场战事归为灭绝种族罪。流传的那些总数没有被确定，所以不予印出。一个缺席的总数不是一道无罪开释。
:::

:::history
柏林会议的会期是公元1884年11月15日到1885年2月26日。它规范欧洲在非洲的诸主张。征服是比这场会议更长、更暴力的一个过程。1878年的柏林大会是另一个行为，关于巴尔干半岛，不得折叠进这一场里。
:::

## 通向何处

被奴役者的贸易——它不是本章的刚果，也不是本章的那个德属殖民地——在[[states/atlantic]]。帝国是英国工业化的一个条件——这个论断不是一场会议的同一条论断——在[[nations/industry]]。那些宣称了诸帝国的欧洲国家之内的诸公众在[[nations/mass-politics]]。1878年那次大会之后的巴尔干半岛，作为1908年的兼并危机与1914年7月的诸决定，在[[nations/toward-1914]]里回来。灭绝种族这个后来的法律范畴——史家们已经把它应用于1904至1908年的那场战事——在[[wars/genocide]]里为1940年代的那桩罪行而展开。在这里使用那个范畴，并不会把两场战事变成一个事件。

:::summary
- 法国对阿尔及尔的入侵始于1830年，与七月革命同一年，而不是同一个事件。印度起义在1857年。“兵变”与“第一次独立战争”都是一个论断。年表的名称是起义。
- 柏林大会，1878年6月13日到7月13日，是一份巴尔干的安排。它不是柏林会议。
- 会议从公元1884年11月15日开到1885年2月26日，两端都算在内共104个日历日。它规范诸主张。它没有在一次会议里送掉一块大陆。征服更长，而且是暴力的。
- 刚果自由邦是利奥波德二世从1885年到1908年的私人统治，此后是比属刚果。凯斯门特1904年的报告记录了暴行。没有给出死亡总数。
- 1904年10月2日，冯·特罗塔针对赫雷罗人发布了一道歼灭令。针对赫雷罗人与纳马人的战事延续到1908年。史家们把它归为灭绝种族罪。没有给出死亡总数。
- 南非战争是1899至1902年。1807年对英国奴隶贸易的废除，与1833年在大部分大英帝国对奴隶制的废除，都没有终结帝国。
:::

## 习题

:::exercise 圈住的跨度 {level=1 check="104"}
如果1884年11月15日与1885年2月26日都算在内，柏林会议圈住了多少个日历日？（请输入数字。）
:::solution
11月贡献16天，12月31天，1月31天，2月26天。16加31是47，加31是78，加26是104。这个计数是对诸日期的一次圈住，不是一份每日开会的登记，也不是一次主权的移交。
:::
:::

:::exercise 那次大会的跨度 {level=1 check="31"}
柏林大会圈住了多少个日历日，1878年6月13日与7月13日都算在内？（请输入数字。）
:::solution
6月从13日到30日是18天。7月从1日到13日是13天。总和是31。那些日子是一份巴尔干的安排。它们不是1884至1885年的那场非洲会议。
:::
:::

:::exercise 那道命令的年份 {level=1 check="1904"}
冯·特罗塔在哪一年针对赫雷罗人发布歼灭令，而凯斯门特关于刚果的报告出现在哪一年？（请输入那个共享的年份。）
:::solution
两者都是1904年。那道命令的日期是10月2日。那份报告是那一年的另一份文件，写的是利奥波德的刚果，不是德属西南非洲。针对赫雷罗人与纳马人的战事延续到1908年。死亡总数不是答案的一部分。
:::
:::

:::exercise 1857年的诸名称 {level=2}
对于1857年的诸事件，本课为什么拒绝在“兵变”与“第一次独立战争”之间默默择一？
:::solution
每一个名称都是一个论断。“兵变”以士兵与英国军法为中心。“第一次独立战争”以一个后来的民族宣称为中心。年表把两者都记录为在使用的名称，并且告诉本课说名称是一个论断。本图谱自己的词是起义。默默地选取另两个中的一个，会藏起那个词服务于谁的故事。这场起义是公司的统治的一场危机，不只是一场兵变，也不只是一个民族的诞生，而为了收尾它，不得发明一个后来法令的年份。
:::
:::

:::exercise 私人统治与兼并 {level=2}
就刚果而言，解释1885年、1904年与1908年之间的区别。为什么1908年没有终结暴行的问题？
:::solution
1885年是利奥波德二世的私人统治——刚果自由邦——的开端，那与会议闭幕是同一年，但不是会议的同义词。1904年是凯斯门特的报告，它记录了那场私人统治之中的暴行。1908年是主权者改变为比属刚果。一个新的主权者不会重写私人统治的那些年份，也不会提供本图谱所拒绝的那个死亡总数。[[#def-congo]]把诸政制分开。[[#thm-novictims]]既保住记录，又拒绝那个数字。
:::
:::

:::exercise 会议与战争 {level=2}
柏林会议在1885年2月26日闭幕。南非战争始于1899年。这场战争不是会议的一场会期，那它为什么是一场关于会议的章节的一部分？
:::solution
这一章的论断是：会议规范诸主张，而没有穷尽帝国。一场从1899年打到1902年、在大英帝国与两个布尔人共和国之间的战争，是诸规则被写下之后的帝国。从1885年到1899年，年份标签相差14。非洲的居民不是那些外交当事方，而无论如何都在战争之内。没有给出死亡总数。这场战争阻止读者把故事停在1885年2月26日。1830年的阿尔及尔与1904年那道命令也是如此。
:::
:::

:::exercise 人道主义的拯救 {level=3}
一个反方论证说，会议是一个人道主义的行为，因为它讨论过奴隶贸易，所以此后的暴力不能归咎于它。你可以让步什么，而哪一个比较击败了这个拯救？
:::hint
让步外交家们讨论过针对贸易的承诺。然后把凯斯门特1904年的报告与1904年10月2日那道命令，放在“那场讨论管辖了随后之事”这个论断旁边。问一问一场人道主义的会议本来必须阻止住什么。
:::
:::solution
让步那场讨论。一项关于奴隶贸易的条款可以是真的，而仍然不管辖刚果或德属西南非洲。如果“人道主义的”意味着这场会议阻止了它所规范的那些主张的暴力，那么这个拯救就失败了。它没有阻止。1885至1908年利奥波德的私人统治包括了凯斯门特在1904年记录的那些暴行。针对赫雷罗人的歼灭令在同一年，在另一个帝国里，而延续到1908年的那场战事被归为灭绝种族罪。一场没有阻止住那些结局的讨论，不是对诸主张之政治的一道无罪开释。看见这道缺口不需要任何死亡总数，也不发明任何一个。公元1807年与1833年的英国法令确实处理了贸易与奴隶制，它们同样没有终结领土帝国。那个比较是同一个形状的论证。
:::
:::

:::exercise 村庄与《总约书》 {level=3}
下面这句话为示例而虚构。它不是史料。“内陆诸河流上的每一个村庄都在1884年11月15日——会议开幕的那个早晨——换了它的主权者，这就是1904年不需要任何报告的原因。”这句话犯了什么尺度错误，而哪一个锁定的后续与“不需要报告”那半句相矛盾？
:::hint
一场会议是外交家们的一次聚会。一个村庄不是一个代表团。然后问一问：如果开幕的那个早晨已经把问题终结，凯斯门特的报告又是为了什么。
:::
:::solution
这句话拿一个外交的开幕，假装它是一次地方的主权移交，这正是[[sources/scale]]点名的那个尺度错误：一个国家的故事不是一个地方的事实。1884年11月15日开幕的是一场规范诸主张的会议。它没有描述任何一个具名的村庄，而本图谱没有锁定这样一份描述。后续与“不需要报告”相矛盾。凯斯门特1904年的报告记录了利奥波德私人统治之下的暴行，那个统治从1885年延续到1908年，在开幕之后，也在1885年2月26日的闭幕之后。如果那个早晨已经把内陆安排成了和平，那份报告就会有一个不同的题目。这句话是虚构的，而年表的日期不需要一个死亡总数就足以把它打破。
:::
:::
