柏林会议做了什么，又没有做什么？

柏林会议从1884年11月15日开到1885年2月26日，规定欧洲各国将如何相互承认彼此在非洲的主张。它并没有在一次会议上把一块大陆拱手送出。征服的过程比这次会议长得多，而且充满暴力。法国早在1830年就已开始入侵阿尔及尔。印度起义发生在1857年，而你用什么名称称呼它，本身就已是一种论证。利奥波德二世（Leopold II）的刚果自由邦是他从1885年到1908年的私人统治，此后成为比属刚果。凯斯门特（Casement）的报告发表于1904年。同年10月2日，冯·特罗塔（von Trotha）对赫雷罗人（Herero）发布了灭绝令。史家们把针对赫雷罗人与纳马人（Nama）、持续到1908年的那场战事归为种族灭绝。南非战争发生在1899年至1902年。以上各句都不含死亡总数，本课也不会添加。

另一次会议，即1878年的柏林大会（Congress of Berlin），讨论的是巴尔干问题，与本次会议不是一回事。两个“柏林”容易混淆，却不是同一个行为。

## 主张不等于一块大陆

:::definition 柏林会议 {#def-conference}
**柏林会议**指1884年11月15日至1885年2月26日规范欧洲在非洲之主张的那次会议。它不是1878年的柏林大会，不是在一个下午移交非洲主权的典礼，也不是对生活在这些主张之下的人们的清点。
:::

外交官们可以就通知程序制定规则，就纸面主张须以实际存在为后盾这一观念制定规则，也可以就刚果河与尼日尔河的航行制定规则。史家们正是用这些措辞来概括这次会议。但这只是对一项外交行为的概括，而不是说内陆的治理权在1885年2月26日已经从非洲各政治体转移到了欧洲各国首都。关于主张者应当如何行事的规则，并不是行事本身。“有效占领”这一常被用来指称“存在”规则的说法，是给各帝国的指令，本身并不是占领。

:::theorem 会议规范了主张，没有送出一块大陆 {#thm-regulates}
柏林会议规范了欧洲的主张，但并没有在一次会议上移交非洲的主权。征服所用的时间远远超出1884年11月15日至1885年2月26日这段日子，而且充满暴力。签字并不是内陆的历史。
:::
:::proof
这些日期就是会议本身。年表在同一处就说明了其限度：会议没有把大陆送出，征服更为漫长且充满暴力。能够推翻这一论断的，是这样的证据：1885年2月26日，内陆各政治体确实仅凭这次会议就更换了主权者，此后再无战争。这里所用的后续记录否定了这幅图景。利奥波德的私人统治从1885年延续到1908年；南非战争尚在未来，即1899年至1902年；灭绝令发布于1904年10月2日。倘若会议已经完成了征服，这些年份就无事可做了。另有一种较温和的说法，认为会议不过是空谈，暴力是另一个话题；能够反驳这种说法的，正是规范主张这件事的用意本身。外交官们是在组织一场他们预料各国会去争夺的竞争。争夺并不等同于《总议定书》（General Act）。这句话的前后两半都不可缺少。
:::

这些日期圈定的是一个季节，既不是一个时刻，也不是十年。把首尾两天都算在内来数日历天数：11月从15日到30日为16天，12月31天，1月31天，2月从1日到26日为26天。于是16加31得47，再加31得78，再加26得104。会议的日期圈定了104个日历日。这一计数并不是说每天都有人开会。如果不额外计入首尾，从11月15日到2月26日实际经过的时间是103天。无论哪种算法，这次会议都是一个外交季节，既不是一个下午，也不是帝国的全部。

:::example 一百零四天 {#ex-days}
会议于1884年11月15日开幕，1885年2月26日闭幕。如果首尾两天都算在内，这些日期共圈定多少个日历日？这个数字不意味着什么？
:::solution
11月从15日到30日计16天，12月31天，1月31天，2月26天。总和为16加31加31加26，即104。这个数字圈定的是时间跨度，并不表示代表们每天开会，也不表示非洲的主权在最后一天完成了转移。[[#thm-regulates]]就是这道算术不得用来夸大的那个论断。
:::
:::

会议也没有使每一个非洲政治体都沦为殖民地。有些国家并不是因柏林的一纸签字而被征服的，1885年2月之后征服仍在继续。除年表锁定的年份之外，本课不为那些后来的胜败编造年份，只陈述一个显而易见的否定：一次规范主张的会议，并没有因此完成一幅地图。

:::quiz
1884年至1885年的柏林会议做了下列哪件事？
- [ ] 在一次会议上把非洲大陆移交给欧洲统治者
- [ ] 它就是解决巴尔干问题的柏林大会
- [x] 规定了欧洲在非洲的主张将如何得到承认，征服仍有待进行
- [ ] 公布了本图谱所依据的刚果死亡总数
:::solution
[[#def-conference]]与[[#thm-regulates]]把对主张的规范与主权的移交区分开来。柏林大会是1878年，是另一次会议。本图谱没有给出任何刚果死亡总数，因此这次会议不可能公布过一个供我们引用的总数。
:::
:::

## 柏林会议之前，以及另一个柏林

十九世纪的帝国并不是从会议开幕时才开始的。1830年，法国开始入侵阿尔及尔；法国七月革命也发生在1830年。年表没有为两者锁定具体日期，因此本课不说孰先孰后，也不把其中一个说成另一个的原因。同在一年不等于同一事件。这次入侵是北非一场漫长征服的开端，牵涉定居者、士兵以及原本就生活在那里的人们。本课不给出伤亡总数。1830年在论证中的作用是年代上的：早在1884年11月15日之前五十多年，一个欧洲帝国就已通过入侵向外扩张。两个年份标签相隔五十四年，即1884减1830。“瓜分”是对后期加剧阶段的称呼，并不是帝国的诞生。

:::example 1830年的两个事件 {#ex-1830}
七月革命与法国开始入侵阿尔及尔同在1830年。你可以得出什么结论？又不能得出什么结论？
:::solution
你可以得出：两者在本图谱中都定于这一年；巴黎的革命与对阿尔及尔的入侵是不同种类的事件。你不能得出其中一个导致了另一个，因为没有锁定具体日期，也没有给出任何机制。你不能描述战斗经过，也不能添加伤亡总数。本章使用这个年份，是为了把征服置于柏林会议之前，而不是完整叙述1830年。那场革命同时也属于[[revolutions/restoration-and-1848]]。
:::
:::

印度起义发生在1857年。年表对它的称呼是“起义”。另有两个名称也在使用，各自都是一种论证。“兵变”把事件置于英国军法的框架内，以东印度公司军队的士兵为中心；“第一次独立战争”把它置于后来的民族叙事之中，以争取建国的战争为中心。两个名称都不中立，因此本课采用年表的用词，再说明另外两个名称各自在做什么。这场起义是东印度公司统治在南亚次大陆大片地区的一场危机，既不只是士兵的密谋，也不只是后来某个民族的起源神话。本图谱没有锁定公司政府终结的年份，因此不予提供。一场危机可以不借助后来的法令来讲授。

柏林大会于1878年6月13日至7月13日举行。它是一场俄土冲突（本年表未单独定年）之后的巴尔干安排，并不是讨论非洲海岸的会议。数一数它的天数，好让这种混淆撞上一个数字：6月从13日到30日为18天，7月从1日到13日为13天，首尾都算在内共31个日历日。一个月的巴尔干外交不是三个月的非洲主张划分，1878年也不是1884年。奥匈帝国对波斯尼亚和黑塞哥维那的占领属于这次会议的安排；1908年的吞并危机（见[[nations/toward-1914]]）则是后来的政府对这一占领的处置。一段话足以防止两个“柏林”变成一个词，却不足以、也无意叙述奥斯曼帝国的这个世纪。

:::example 两次会议，两段跨度 {#ex-berlins}
把1878年6月13日至7月13日的柏林大会，与1884年11月15日至1885年2月26日的柏林会议加以比较。两者各为何事？圈定的天数有何不同？
:::solution
柏林大会是巴尔干安排。首尾都算在内，它圈定6月的18天加7月的13天，共31天。柏林会议规范非洲的主张，圈定104个日历日，见[[#ex-days]]。两个年份标签相差1884减1878，即6，而柏林会议一直开到1885年。两段跨度都不是死亡总数，不是已完成的征服，也不能据此把“柏林”当作一个词来用，仿佛两次会议是同一次。
:::
:::

## 刚果：不给出总数

:::definition 刚果自由邦 {#def-congo}
**刚果自由邦**是利奥波德二世从1885年到1908年的私人统治。它还不是比属刚果，后者是1908年之后的政权。它也不是通常意义上的殖民地，即并非从一开始就由布鲁塞尔的议会统治。私人统治下的暴行有文献记录。本课不给出死亡总数。
:::

这次会议是刚果主张获得国际承认的途径之一，但承认不等于政权。从1885年到1908年，统治者就是利奥波德本人。榨取橡胶的强制手段是一套统治体系，而不是1885年2月26日表决通过、随后被人遗忘的某项条款。罗杰·凯斯门特1904年的报告记录了暴行。本图谱拒绝采用那些作为死亡总数流传的庞大整数，因为它们还没有可靠到可以印出的程度。拒绝不等于无罪开释。一项罪行可以由一份报告、由强迫劳动的结构、由最终对它提出批评的外交来记录，而无须一个本书不愿为之担保的数字。

能够推翻这一拒绝的，是年表本身接受的某个总数，而年表从未接受过。能够反驳把“暴行有文献记录”淡化为“有人提出了指控”的，是年表赋予这份报告的地位：它是文献记录，而不是本课可以随意“平衡”掉的传闻。1908年，比利时国家接管这片领土，改为比属刚果。主权者变了，记录没有变。吞并并不能洗白此前的岁月。

:::theorem 有文献记录的暴力无须等待死亡总数 {#thm-novictims}
利奥波德治下刚果的暴行，以及针对赫雷罗人与纳马人的战事，都是这段历史的组成部分。史家们把1904年至1908年的那场战事归为种族灭绝。两个案例都不附带死亡总数来讲授；没有公认的总数，并不等于认定无罪。
:::
:::proof
凯斯门特的报告在1904年。冯·特罗塔针对赫雷罗人的灭绝令在1904年10月2日。针对赫雷罗人与纳马人的战事持续到1908年。年表说明史家们把这场战事归为种族灭绝，同时禁止为这场战事和刚果给出死亡总数。“种族灭绝”一词晚于那道命令：拉斐尔·莱姆金（Raphael Lemkin）1944年的著作使用了这个词，《防止及惩治灭绝种族罪公约》于1948年12月9日通过。把后来的法律范畴用于更早的战事，是史家的判断，本图谱遵循这一判断；这并不是说那道命令使用了后来的这个词。那道命令是一道灭绝的命令，这是意图的证据。能够推翻这一归类的，是表明这道命令没有得到执行、这场战事只是针对战斗人员的有限战争的证据。年表的归类与这种解读相对立。能够反驳不附带数字讲授这两个案例的，是那种认为只有总数才能使暴力成为真实的观念。报告、命令与归类就是证据。一个借来的整数会是另一种更弱的东西。
:::

1904年的两份文件不得合并。凯斯门特写的是利奥波德私人统治下的刚果。冯·特罗塔的命令是德国的，发布于德属西南非洲，点名针对赫雷罗人；纳马人则是持续到1908年的那场战事的对象之一。同一年份，两个帝国，两项罪行。图示把它们放在同一个数据点上，是因为这一年同时承载两者；图注也说明，这个数据点不包含死亡总数。想为1904年只讲一个非洲故事的读者，已经无视了地理。

内容是命令、报告、日期与归类，而不是杀戮的具体过程。指明这项罪行并不需要描述这一过程，本课也不提供。

## 不是会议的战争

南非战争从1899年打到1902年，交战双方是大英帝国和两个布尔人共和国。它不是柏林会议的某次会期——会议早在1885年2月26日就已结束，按年份标签比1899年早十四年，即1899减1885。它是关于主张的规则写成之后、以战争形式出现的帝国。非洲居民并不是那场为这两个共和国定名的外交的当事方，却无论如何都身处战争之中。本课不给出死亡总数。纳入这场战争的用意，与纳入阿尔及尔和1857年的用意相同：会议只是诸多手段之一，而不是1830年至1908年间欧洲帝国的全部。

废奴也不是这个帝国的终结。英国1807年的法令针对的是奴隶贸易，而不是奴隶制。1833年的法令在大英帝国大部分地区废除了奴隶制，学徒制延续到1838年。大西洋贸易的登船估计——1501年至1866年间12,521,354人——见[[states/atlantic]]。它描述的既不是刚果自由邦，也不是德属西南非洲。在英国的奴隶贸易成为非法、英国的殖民地奴隶制被废除之后，领土帝国依然延续。凡是把1833年当作帝国故事终点的人，都无法解释1884年，也无法解释1904年。

有一种反驳试图借会议中关于奴隶贸易的措辞为它开脱。外交官们确实讨论过反对奴隶贸易的承诺。但讨论不是人道主义公约，一项条款也管辖不了刚果。能够支持人道主义解读的，是一次以其规则制止了随后暴力的会议。而随后发生的，包括利奥波德的私人统治、凯斯门特的报告以及一道灭绝令。这项条款通不过这一检验。[[nations/industry]]已经把纤维、金融与帝国区分为关于英国工业化的不同论证。在这里，帝国不是关于棉花的论证，而是统治、主张与战争。

:::example 编造的移交 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1885年2月26日，刚果人民成了比利时人，会议的人道主义条款意味着此后再无暴力。”这句话在主权者、日期与后续发展上各错在哪里？
:::solution
1885年2月26日是会议闭幕之日，而不是比利时统治的开始。1885年至1908年的刚果自由邦是利奥波德二世的私人统治。比属刚果始于1908年，那一年主权者变了，暴行的记录却没有变。凯斯门特的报告在1904年，处于私人统治时期。关于奴隶贸易的人道主义讨论，无论外交官们写下什么，都没有阻止这一统治，也没有阻止1904年10月2日在另一块殖民地发布的灭绝令。这句编造的话把对主张的规范变成了国籍的改变与和平的承诺。[[#thm-regulates]]与[[#thm-novictims]]就是纠正。本课没有为了让纠正显得更有分量而添加任何死亡总数。
:::
:::

## 完整案例：会议的最后一天

把1885年2月26日作为完整案例。这是会议闭幕的日子。外交官可以带着一条关于主张的规则离开柏林，但刚果盆地的一位统治者并不会因为外交官离开就成为比利时臣民。利奥波德的私人统治从1885年算起，与闭幕同年，而这统治是他个人的。一个年份标签可以同时容纳一次签字和一个私人主权者，而不会使它们合为一个政府。

问一问：在把一个地方故事当作会议本身来讲述之前，你需要什么？你需要一份来自某个地方的史料，说明会议次日由谁统治、凭借什么武力、遭遇了什么抵抗。会议本身的文件提供不了这样的史料。[[sources/scale]]就是方法：关于外交官的真实陈述，往往是关于一个村庄的虚假陈述。[[#ex-invented]]中编造的移交就是这样的虚假陈述。这个完整案例是同样的检验，只是没有编造：会议闭幕，私人统治开始，暴行直到1904年才有记录，比利时直到1908年才吞并。四个节点，没有一个是死亡总数，也没有一个是无罪开释。

把1904年10月2日放在这个案例旁边，尺度又变了。灭绝令不是一次会议，而是针对赫雷罗人的战争中的一道命令，那场战事也针对纳马人，一直持续到1908年。史家们称这场战事为种族灭绝。这个后来的词——莱姆金在1944年使用，公约在1948年12月9日采用——既不会使那道命令显得温和，也不要求你编造死了多少人。意图在命令之中，持续时间在日期之中，归类则是年表告诉你应当遵循的史家判断。没有数字就不肯称这场战事为种族灭绝的学生，添加了证据并不需要的条件；编造数字的学生则违反了另一条规则。两人都偏离了这个案例。

:::warning 一个下午，以及一个能够了结问题的数字
有两种迷思会瓦解本章。第一种说，柏林会议在一个下午就把非洲送了出去，因此1885年2月26日就是瓜分本身。实际上，会议历时104个日历日，规范的是主张，征服则尚未完成。1830年的阿尔及尔与1857年的起义是会议之前的帝国；南非战争与1904年的命令是会议之后的帝国。第二种迷思说，没有公认的死亡总数，刚果就没有发生什么严重的事，赫雷罗人与纳马人也没有遭遇什么严重的事。凯斯门特的报告记录了暴行。那道命令是灭绝令。史家们把持续到1908年的那场战事归为种族灭绝。流传的那些总数并不可靠，因此不予印出。缺少总数不等于无罪开释。
:::

:::history
柏林会议从1884年11月15日开到1885年2月26日，规范欧洲在非洲的主张。征服是一个比这次会议更长、也更暴力的过程。1878年的柏林大会是另一个行为，讨论的是巴尔干问题，不得与本次会议混为一谈。
:::

## 通向何处

奴隶贸易——它既不是本章的刚果，也不是本章的德国殖民地——见[[states/atlantic]]。帝国是英国工业化条件之一这一论证，与关于会议的论断不是一回事，见[[nations/industry]]。主张帝国的欧洲国家内部的公众，见[[nations/mass-politics]]。1878年柏林大会之后的巴尔干，将以1908年吞并危机与1914年7月各项决定的形式在[[nations/toward-1914]]中再次出现。种族灭绝这一后来的法律范畴，史家们已将其用于1904年至1908年的那场战事；它在[[wars/genocide]]中就1940年代的罪行展开讨论。在这里使用这一范畴，并不会使两场战事成为同一事件。

:::summary
- 法国于1830年开始入侵阿尔及尔，与七月革命同年，但不是同一事件。印度起义发生在1857年。“兵变”与“第一次独立战争”都是论证，年表的称呼是“起义”。
- 柏林大会（1878年6月13日至7月13日）是巴尔干安排，不是柏林会议。
- 会议从1884年11月15日开到1885年2月26日，首尾都算在内共104个日历日。它规范了主张，没有在一次会议上送出一块大陆。征服更为漫长，且充满暴力。
- 刚果自由邦是利奥波德二世从1885年到1908年的私人统治，此后为比属刚果。凯斯门特1904年的报告记录了暴行。本课不给出死亡总数。
- 1904年10月2日，冯·特罗塔对赫雷罗人发布灭绝令。针对赫雷罗人与纳马人的战事持续到1908年，史家们将其归为种族灭绝。本课不给出死亡总数。
- 南非战争发生在1899年至1902年。1807年废除英国奴隶贸易、1833年在大英帝国大部分地区废除奴隶制，都没有终结帝国。
:::

## 习题

:::exercise 圈定的跨度 {level=1 check="104"}
如果把1884年11月15日与1885年2月26日都算在内，柏林会议共圈定多少个日历日？（请输入数字。）
:::solution
11月计16天，12月31天，1月31天，2月26天。16加31得47，再加31得78，再加26得104。这一计数是对日期的圈定，既不是每日开会的记录，也不是主权的移交。
:::
:::

:::exercise 柏林大会的跨度 {level=1 check="31"}
把1878年6月13日与7月13日都算在内，柏林大会共圈定多少个日历日？（请输入数字。）
:::solution
6月从13日到30日为18天，7月从1日到13日为13天，合计31天。这些日子属于巴尔干安排，而不是1884年至1885年那次关于非洲的会议。
:::

:::exercise 命令的年份 {level=1 check="1904"}
冯·特罗塔在哪一年对赫雷罗人发布灭绝令？凯斯门特关于刚果的报告又发表于哪一年？（请输入两者共同的年份。）
:::solution
两者都在1904年。命令的日期是10月2日。报告是这一年的另一份文件，写的是利奥波德治下的刚果，而不是德属西南非洲。针对赫雷罗人与纳马人的战事一直持续到1908年。答案中不包括任何死亡总数。
:::
:::

:::exercise 1857年的名称 {level=2}
对于1857年的事件，本课为什么拒绝在“兵变”与“第一次独立战争”之间默默择一？
:::solution
每个名称都是一种论证。“兵变”以士兵和英国军法为中心，“第一次独立战争”以后来的民族主张为中心。年表把两者都记作通行的名称，并要求本课指出名称本身就是论证。本图谱自己的用词是“起义”。默默选用另外两个名称之一，就会掩盖这个词在为谁的叙事服务。这场起义是东印度公司统治的危机，既不只是兵变，也不只是一个民族的诞生，也不得为了给它收尾而编造后来某项法令的年份。
:::
:::

:::exercise 私人统治与吞并 {level=2}
就刚果而言，请解释1885年、1904年与1908年的区别。为什么1908年并没有了结暴行问题？
:::solution
1885年是利奥波德二世私人统治即刚果自由邦的开始，与会议闭幕同年，但并不是会议的同义词。1904年是凯斯门特的报告，它记录了私人统治期间的暴行。1908年是主权者变更为比属刚果。新的主权者既不会改写私人统治的岁月，也不会提供本图谱所拒绝的死亡总数。[[#def-congo]]把不同政权区分开来，[[#thm-novictims]]保留了文献记录，同时拒绝那个数字。
:::
:::

:::exercise 会议与战争 {level=2}
柏林会议于1885年2月26日闭幕，南非战争始于1899年。既然这场战争不是会议的某次会期，为什么它属于一章关于会议的内容？
:::solution
本章的论断是：会议规范了主张，却没有穷尽帝国。1899年至1902年大英帝国与两个布尔人共和国之间的战争，是规则写成之后的帝国。从1885年到1899年，年份标签相差14。非洲居民不是外交当事方，却无论如何都身处战争之中。本课不给出死亡总数。这场战争使读者不能把故事停在1885年2月26日；1830年的阿尔及尔与1904年的命令也起同样的作用。
:::
:::

:::exercise 人道主义的开脱 {level=3}
有一种反驳说，会议讨论过奴隶贸易，因而是一项人道主义行为，此后的暴力不能归咎于它。你可以承认什么？哪一项比较推翻了这种开脱？
:::hint
承认外交官们讨论过反对奴隶贸易的承诺。然后把凯斯门特1904年的报告与1904年10月2日的命令，放在“这场讨论支配了随后之事”的论断旁边。想一想，一次人道主义的会议本该阻止什么。
:::
:::solution
可以承认这场讨论。一项关于奴隶贸易的条款可以是真实的，却仍然管辖不了刚果或德属西南非洲。如果“人道主义”是指会议阻止了它所规范的那些主张所带来的暴力，这种开脱就站不住脚，因为它并没有阻止。利奥波德1885年至1908年的私人统治，包括了凯斯门特在1904年记录的暴行。针对赫雷罗人的灭绝令发布于同一年，在另一个帝国，持续到1908年的那场战事被归为种族灭绝。一场没能阻止这些结果的讨论，不能为主张政治开脱罪责。看出这一缺口不需要任何死亡总数，本课也不编造。英国1807年与1833年的法令确实处理了奴隶贸易与奴隶制，它们同样没有终结领土帝国。这一比较是同一形式的论证。
:::
:::

:::exercise 村庄与《总议定书》 {level=3}
下面这句话为示例而虚构。它不是史料。“内陆河流沿岸的每一个村庄都在1884年11月15日，即会议开幕的那个早晨，更换了主权者，所以1904年根本不需要什么报告。”这句话犯了什么尺度错误？哪一项锁定的后续事件与“不需要报告”这半句相矛盾？
:::hint
会议是外交官的聚会，村庄不是代表团。再想一想：如果开幕那个早晨就已了结问题，凯斯门特的报告又是为了什么？
:::
:::solution
这句话把一次外交会议的开幕冒充为地方的主权移交，这正是[[sources/scale]]所指明的尺度错误：国家层面的叙事不等于地方的事实。1884年11月15日开幕的是一次规范主张的会议，它没有描述任何具名的村庄，本图谱也没有锁定这样的描述。后续事件与“不需要报告”相矛盾：凯斯门特1904年的报告记录了利奥波德私人统治下的暴行，这一统治从1885年延续到1908年，既在开幕之后，也在1885年2月26日闭幕之后。倘若那个早晨已使内陆归于和平，这份报告的主题就会截然不同。这句话是虚构的，年表的日期无须死亡总数就足以将它驳倒。
:::
