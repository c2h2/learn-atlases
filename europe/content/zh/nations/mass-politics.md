当政治变成大众政治的时候，谁被包括了进来？

大众政治的意思是：大批的人被当作一个公众来诉求，凭借的是选举权、政党、教会、报刊或联盟，无论他们能不能投票。它不是说民主已经实现。到1914年还没有。英国的第二次与第三次改革法案，在1867年与1884年，扩大了一个男性选举权，而把女性留在了外面。1871年3月至5月的巴黎公社是一个城市政府，而它被摧毁了。反犹主义在这些年代里是一场政治运动，而德雷福斯事件是那个个案，不是1933年的起源。1905年1月22日（新历），圣彼得堡的一份请愿遭到的是暴力。1906年，在芬兰大公国，女性获得了议会投票权与被选举权。那是欧洲议会史上的第一次。它不是世界范围内最早的女性选举权，也不是英国那些法案做过的事。

在[[nations/unifications]]里建成的那些国家，是其中一部分事情的容器。一次宣告不是一个选举人团体。[[nations/industry]]里的普查数的是在场，不是一张选票。

## “被包括”不得被允许意味着什么

:::definition 大众政治 {#def-mass}
**大众政治**是把大批的人当作一个能够被登记、被诉求或被挡在门外的公众来对待的实践。它的手段包括选举权、政党、教会、报刊与联盟。这个说法不是说每一个成年人都选择了政府，也不是说包括是大众政治所做的唯一的事情。
:::

一个公众可以被诉求，为的是给它选举权。一个公众也可以被诉求，为的是归咎于它。同样这些年代里装着改革法案，也装着反犹联盟。任何把这段时期定义为人民之到来的人，已经删掉了半个档案。对每一个有日期的行为来说，检验是：谁在规则之内，谁在规则之外。

:::definition 政治反犹主义 {#def-antisemitism}
**政治反犹主义**，作为这些年代里的一场政治运动，是这样一种有组织的论断：犹太人是民族的一个集体敌人；它由报刊、联盟与选举政治承载。它不只是一种私人的厌恶，而在本课里，它也不是1933年1月30日希特勒（Hitler）被任命为总理这件事的起源。
:::

:::theorem 英国的改革法案扩大了一个男性选举权，而没有包括女性 {#thm-reform}
1832年的法案是第一次扩大，而它仍然狭窄。1867年的法案与1884年的法案进一步扩大了男性选举权，先在自治市，然后在各郡。三个法案都没有包括女性。一个更大的男性选举人团体不是民主，也不是1906年的芬兰选举权。
:::
:::proof
年表给出那三项制定法，并说女性没有被包括在1867年或1884年。1832年已经在[[revolutions/restoration-and-1848]]里作为一种狭窄的选举权讲授。选民规模的任何数字都没有锁定，所以一个也不发明。那些法案显示的是一个方向：更多的男性，在一条财产或住户资格的规则之下，而不是女性。会构成对这条论断的反证的，是1867年或1884年的一项生效的条款，把议会投票权给予女性。没有这样的条款。同样会构成把这些法案当作民主来对待的反证的，是芬兰1906年的制定法，它确实把议会投票权与被选举权给予女性，而英国没有效仿它。这个对照就在锁定的年份之内。它不需要一个关于多少男性仍然不能投票的猜测，尽管住户资格的规则本身就在说明这次扩大并非普遍。
:::

从1867年到1884年是1884减1867，即17年。十七年的进一步改革，而在它们尽头，对女性的排除完好如初。1867年也是折衷方案的那一年。[[nations/unifications]]用它来指匈牙利的加冕。本章用它来指一项英国制定法。同一年，两次包括，两者都不是女性的选举权，两者也都不是一个捷克的王国。一个日期不是一个同义词。

第三个法案把一种住户资格的选举权延伸进各郡。在这里锁定的任何日期上，它都没有废除复票制，也没有把投票权给予女性。世纪后叶的那个法兰西共和国建立在一个宽广的男性选举权之上，它的革命性的扩大属于1848年，而它同样把女性留在外面。在德意志帝国，帝国议会的选举权与普鲁士的选举权不是同一个机制。普鲁士的票是被加权的。本课不发明那些权重。一个男人可以处在一个德国选举人团体之内，而不以同等资格处在另一个之内，而这两个规则都不是芬兰的那一个——这就够了。

:::example 十七年，以及同一个排除 {#ex-seventeen}
第二次改革法案是1867年，第三次是1884年。英国议会选举权在这两者中都没有让女性进入。年份标签之间的差距有多长，而那个差距不软化什么？
:::solution
1884减1867是17。那个差距不是包括之前的暂停。在较晚的日期，那个排除仍然成立。芬兰给女性的议会选举权，包括被选举权在内，是1906年，即1906减1884，在英国第三个法案之后22年，而它是另一个国家的规则。英国17年的差距是没有女性的改革的证据，不是改革与包括是同一个词的证据。
:::
:::

:::quiz
哪一个关于英国改革法案的说法与年表相符？
- [ ] 到1884年，女性已经有了议会投票权，因为男性选举权自1832年以来已经扩大过两次
- [ ] 1867年把投票权给了联合王国的每一个成年人
- [x] 1867年与1884年扩大了一个男性选举权，而女性没有被包括

:::solution
1832年是一次狭窄的扩大。1867年与1884年在男性之间走得更远，而没有包括女性。[[#thm-reform]]就是那句话。民主是一个不同的论断，而[[#thm-notyet]]对1914年拒绝它。
:::
:::

## 一座城市，一个政党，一座教会

巴黎公社从1871年3月持续到5月。它是在那场战争的余波之中的一个城市政府；那场战争，[[nations/unifications]]在法国一侧以5月10日的《法兰克福和约》结束。和约的日子落在公社的诸月之内。德意志帝国已经于1月18日宣告成立，在公社开始之前。三个事实共享一个季节，而不共享一个含义：一个帝国被宣告，一项和平被签署，一次城市革命被粉碎。

公社像一个城市政府那样行事，并通过了社会措施。本课不发明一份纲领的文本。女性参与了这座城市的政治生活。那种参与不是一个持久的全国性选举权，也没有在公社的失败之后存续。那次失败是暴力的。没有给出死亡总数，因为没有总数被锁定，而一个猜出的总数将是错误种类的精确。公社不是社会主义必须采取一座武装的城市的形式的证明，也不是一桩只是为了使一种学说难堪而讲述的罪案故事。它是一段有日期的大众政治的插曲，其中一个公众占据了一座城市，然后被挡在了城市之外。

社会主义诸政党属于同样的年代，而它们也不是选举权。《共产党宣言》于1848年2月在伦敦出版。声称代表劳工发言的诸政党更晚组织起来，坐在若干议会里，并出版纲领。本课不引用那些纲领。一个政党可以庞大，却同时受到打压、被排除在行政权之外，或者受到一种加权选举权的抵制。组织是一种意义上的包括，即[[#def-mass]]的那个意义。它不是芬兰在1906年改变谁可以投票、谁可以参选时的那个意义。

教会是大众规模的制度，用的是同样平实的意义。它们登记、教育、出版，并且在法律允许之处举行选举。天主教与新教的社团是政治生活的一部分，不是政治变得现代之后剩下的残渣。在新的德意志帝国，国家与天主教会的冲突本身就是政治。本课不为那场冲突的个别制定法定年，因为那些日子没有锁定。它说这场冲突是公开的。信仰与一个内阁的政策不是同一回事——[[sources/evidence]]会这样坚持。一座能够坐满会堂的大厅的教会，是一个关于组织的事实。它不是一次灵魂的普查。

## 德雷福斯：作为个案，而不是作为起源

:::theorem 德雷福斯事件是政治反犹主义的一个个案，不是1933年的起源 {#thm-dreyfus}
德雷福斯（Dreyfus）于1894年被捕，左拉（Zola）那篇题为《我控诉》（J'Accuse）的文章于1898年1月13日发表，而德雷福斯于1906年获得平反。这个事件显示了一种由报刊与联盟组成的、针对一名犹太人军官的大众政治。它没有引起、也不是1933年1月30日希特勒被任命为总理这件事的起源。
:::
:::proof
三个日期是锁定的，而那个标题可以被说出。文章的句子不得被发明，所以一句也不给出。单是标题本身所做的事情，就足以说明这个行为的公共性质：一个第一人称的指控，登在一份报纸上，面向读者。1906年的平反意味着那个定罪没有站住。按标签的十二年，1906减1894，把逮捕与平反分开。那篇文章没有宣判他的无罪。它是一次介入，按标签在平反之前八年，1906减1898。会构成把这称为一场政治运动的反证的，是这个事件停留在私人的厌恶、没有报刊、没有联盟、对公共职位没有影响的证据。那篇有日期的文章构成对那种安静读法的反证。会构成对拒绝与1933年建立联系的反对的，是一条在证据之中的、从这个法兰西个案通向那个德意志任命的链条。一种共有的偏见不是一条链条。那个任命属于[[wars/interwar]]。把1894年当作它的起源，会把一桩冤案变成一个后来的政权的作者，而日期没有这样说。
:::

德雷福斯是法兰西军队里的一名犹太人军官，因一项输送机密的指控被捕并定罪。本课不重建那份案卷。它记下那个定罪后来被撤销，而撤销它一直延续到1906年。在中间的诸年里，这个事件分裂了法国的公共生活。反犹主义按照[[#def-antisemitism]]的描述运转：一种政治，而不只是一次冷遇。诸联盟与诸报刊把一个犹太人当作一个集体敌人的替身。那就是这个完整的案例。它是大众政治行为不端的一个案例，这就是“群众”不得被预先赞扬的原因。

:::example 从逮捕到平反 {#ex-dreyfus}
德雷福斯于1894年被捕。《我控诉》于1898年1月13日发表。平反是1906年。计算两个年份标签之间的差距，并说出关于那篇文章你不得添加什么。
:::solution
1906减1894是12。1906减1898是8。文章的标题可以被说出，它的日期可以被使用。它的句子不得凭记忆写出，也不得凭一个假装是文本的转述写出。那个标题是一个面向公众的指控。它不是一个判决。平反是一个后来的法律行为，不是那篇文章自动产生的一个后果。两个差距中的任何一个，都不是把这个事件称为1933年1月30日的起源的理由。
:::
:::

没有要你钦佩这十二年，也没有要你去挖掘一条关于耐心的道德教训。要你把一个法律结果、一份报纸与一个后来的德意志任命放在不同的格子里。把格子塌缩成一个，是一个1894年之后的法兰西个案被讲述得仿佛它解释了1933年的一个总理职位的方式。它没有解释。

## 1905与1906，相隔恰好够远

:::theorem 到1914年民主还没有被实现 {#thm-notyet}
到1914年，锁定的那些不包括在一起不构成民主。英国改革了一个男性选举权，而把女性留在外面。俄国在血腥星期日以暴力对待一份请愿。芬兰在1906年显示了一条英国没有采纳的议会规则。一个欧洲的第一次不是一条欧洲的规范。
:::
:::proof
证据是已经定年的那组行为。1867年与1884年排除女性。1905年1月22日（新历），是圣彼得堡的血腥星期日，它同时也是1905年1月9日（旧历）：一个事件，一个以暴力而不是以投票相待的公众。没有给出死亡总数。1906年给予芬兰大公国的女性议会投票权与被选举权。年表把那个称为欧洲议会史上的第一次，而禁止把它称为世界范围内最早的女性选举权。因此本课不点出任何更早的外国年份。会构成对这条论断的反证的，是一条锁定的普遍规则，到1914年在本课程一路追踪的诸国家之内生效，依据它，成年的女性与男性选择她们的政府。英国的诸法案、俄国的那个早晨与芬兰的例外，都不是那条规则。芬兰是对自满的反例，同时是那条更宽广的规则并不普遍的证据。两种用法都公平。
:::

两种历法就是把[[sources/time-and-names]]的方法应用在一个政治的日子上。俄国还没有进行1918年的那次切换，在那次切换中，1月31日之后跟着2月14日。在1905年，旧历的日期与新历的日期指称同一个早晨。两个数字相差13：9加13是22。任何人把这个故事讲两遍，仿佛那份请愿分散在两天里，都是把一个历法误当成了一个序列。十月革命的双重日期更晚，在[[wars/revolutions-1917]]。本章停在那个一月的日子。

1905年装着比那个早晨更多的东西。本图谱锁定血腥星期日，而没有为那一年更晚的让步与起义锁定日子，所以那些日子不被发明。一场革命可以是真实的，而在某一课里仍然只有一个有日期的门槛。这里的门槛是对请愿者提供的暴力。选举权恰恰是那个早晨所不是的东西。

芬兰在1906年是另一个门槛。那个大公国，在俄国皇帝之下，得到了一个把女性包括为投票者与候选人的议会选举权。“被选举权”不是一个点缀。没有被选举权的投票是一种更薄的包括，而芬兰的规则两者都有。英国1884年的规则对女性两样都没有。图形有意把1905与1906并排放。一个三年的窗口仅仅刚好把它们分开。一个是街头的一次拒绝。一个是关于谁可以进入议会的制定法。把两者都称为“群众的兴起”，在你说出是哪个公众、是哪项权利之前，教不了任何东西。

:::example 一个早晨，两个数字 {#ex-sunday}
血腥星期日是1905年1月22日新历，也是1905年1月9日旧历。证明两个数字相差13，并说出那个差别不是什么。
:::solution
22减9是13，而9加13是22。那个差别是俄国历法与同一天的格里高利历日期之间的差距。它不是一份第二次的请愿，也不是一个死亡总数。本课使用新历的日期作为标记，并把旧历的日期保留在它旁边。两者指称同一个事件。
:::
:::

:::example 一句发明出来的关于1884年的判决 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1884年，英国人民终于进入了政治，因为公社在1871年指明了道路，而民主赶上了1905年，就此完成。”把它借用的日期与它添加的论断分开。
:::solution
1884年、1871年3月至5月与1905年是真实的。“英国人民”不是第三个改革法案的选举人团体，第三个改革法案是更宽广的男性选举权，而不是女性。公社没有为进入那个法案“指明道路”：它是一个法兰西的城市政府，被粉碎了，按标签在1884年之前十三年，1884减1871。民主在1884年没有完成，而1905年的圣彼得堡是血腥星期日，不是一个完成了的民主。本来会构成有趣对照的芬兰选举权，在那句发明出来的句子里是缺席的，而它是1906年。那句话用真实的年份，走私一个已经完成了的民族。
:::

## 反方论证必须面对什么

反方论证说，1867年与1884年是民主的到来，也许缓慢，而缓慢的到来仍然是一个到来。它指向真实的制定法。在每一项之后，能够投票的男性都比之前更多。社会主义诸政党与诸教会建造了更早的精英政治所不知道的组织。那些是事实，而它们属于[[#def-mass]]。它们达不到[[#thm-notyet]]。

会支持反方论证的，是一条规则——到1914年在英国，或作为一条欧洲的规范——依据它，本章点名的那些排除已经失效。女性会在英国的议会选举权之内。俄国首都的一次请愿，不会是一个公众如何遇见国家的画面。芬兰会是典型的，而不是第一次。这些都不是锁定的记录。反方论证能够保留的东西更谦逊，也更诚实：选举人团体增长了，诸政党与诸教会组织了，而有些国家在1906年比在1832年更开放。那种增长是大众政治。它不是民主的同义词，而本章不会签署那个同义词。

还有第二个反方论证，关于那个事件。它说德雷福斯是一桩冤案，不幸的，个人的，而通常意义上的政治在别处进行。一名被告可以是一个人，同时仍然是一场运动的机缘。检验不是被告的人数。检验是报刊、诸联盟与公共职位是否把这个案件当作一个关于犹太人的民族问题来接受。它们这样做了。1906年的平反结束了针对他的法律案件。它没有把那场运动倒回成一种私人的冷遇，也没有把这个案件向前投射成1933年的原因。两种夸大——“只是个人的”与“后来一切事情的起源”——在同样的日期面前失败。

:::warning 1914年前的民主，以及1933年的一个法兰西起源
两个迷思使用了本章的日期，而错过了它们。第一个说民主到1914年已经实现，因为改革法案已经通过，而诸政党已经存在。女性在1867年与1884年的英国法案之外。血腥星期日是一个以暴力相待的公众。芬兰1906年的选举权是一次第一次，不是一条规范。第二个迷思把德雷福斯事件当作1933年的起源。这个事件从1894年的一次逮捕，走到一篇1898年1月13日的文章《我控诉》，走到1906年的一次平反。总理职位是一个后来的德意志行为。大众政治包括改革，它也包括一场针对一个少数群体的运动。这两个事实都不是一个幸福的结局。
:::

:::history
巴黎公社从1871年3月守住这座城市直到5月，在德意志帝国已经于1月18日宣告成立之后，而5月10日的《法兰克福和约》落在公社的诸月之内。公社是一个政府，而它被摧毁了。它不是1871年的帝国的含义，对于参与其中的女性，它也不是一项选举权。
:::

## 通向何处

选举权成为问题的那些国家，是在[[nations/unifications]]里建成、并被拒绝的。一份普查能够看见、而还不是投票者的人们，在[[nations/industry]]。狭窄的1832年法案与1848年2月的《宣言》，在[[revolutions/restoration-and-1848]]。诸历法，包括为什么1月9日与1月22日可以是同一天，在[[sources/time-and-names]]。同样这些国家的海外诸帝国在[[nations/empires]]。显示1914年的政治多么未完成的那场战争，在[[wars/first-world-war]]；而这个本章拒绝从德雷福斯推演出来的1933年的德意志任命，在[[wars/interwar]]。

:::summary
- 大众政治通过选举权、诸政党、诸教会、诸报刊与诸联盟诉求大型公众。它不是民主，而到1914年民主还没有被实现。
- 1832年的改革法案是一次狭窄的扩大。1867年与1884年的法案扩大了一个男性选举权。女性没有被包括。年份标签相差17年。
- 巴黎公社从1871年3月持续到5月。它是一个城市政府，被摧毁了，没有给出死亡总数。它不是1月18日的德意志宣告，也不是5月10日的《法兰克福和约》，尽管那项和约落在它的诸月之内。
- 德雷福斯于1894年被捕。左拉的文章，其标题为《我控诉》，出现在1898年1月13日。它的文本不在这里被发明。平反是1906年。这个事件是政治反犹主义，不是1933年1月30日的起源。
- 血腥星期日是1905年1月22日新历，与1月9日旧历，一个事件。两个数字相差13。没有给出死亡总数。
- 在1906年，芬兰大公国的女性获得议会投票权与被选举权。那是欧洲议会史上的第一次，不是世界的第一次，也不是英国的改革。
:::

## 习题

:::exercise 英国的差距 {level=1 check="17"}
英国第二次与第三次改革法案的年份标签之间隔着多少年？（请输入年数。）
:::solution
1884减1867是17。两个法案中女性都在议会选举权之外。这个数字是一个男性选举人团体的两次扩大之间的差距，不是一个已经完成的民主的度量。
:::
:::

:::exercise 平反的年份 {level=1 check="1906"}
德雷福斯在哪一年获得平反？（请输入年份。）
:::solution
平反是1906年。逮捕是1894年，按标签早十二年。《我控诉》是1898年1月13日，按标签在平反之前八年。文章的标题可以被说出。它的句子不得被给出。
:::
:::

:::exercise 历法的差距 {level=1 check="13"}
血腥星期日的新历与旧历数字相差多少天？（请输入数字。）
:::solution
1月22日减1月9日是13。两个数字指称一个事件，不是两个早晨。新历是本课使用的标记。旧历是俄国历法对同一天的名字。
:::
:::

:::exercise 一个季节里的三个事实 {level=2}
1871年1月18日、1871年5月10日，与1871年3月至5月，很容易被一起记成“1871”。给每一个一个自己的描述，并说出哪一个是公社。
:::solution
1月18日是德意志帝国在镜厅的宣告，当时巴黎仍在作战，也在公社之前。5月10日是《法兰克福和约》。3月至5月是巴黎公社，一个随后被摧毁的城市政府。和约的日子落在公社的诸月之内，这就是季节被共享而事实不被共享的原因。答案里不应当有死亡总数。
:::
:::

:::exercise 为什么那些法案不是民主 {level=2}
一名读者说，1867年与1884年之后，英国是一个民主国家，而芬兰在1906年只是重复了这个教训。回答这两个从句。
:::solution
英国的法案扩大了一个男性选举权，而没有包括女性。一条住户资格的规则不是普遍的成人选举权，而这里没有发明任何选举人总数来装饰它。芬兰在1906年给予女性议会投票权与被选举权。那是欧洲议会史上的第一次，不是对英国法案的摹写，也不是世界范围内最早的女性选举权。[[#thm-reform]]与[[#thm-notyet]]就是那名读者颠倒的两个从句。
:::
:::

:::exercise 诸政党、诸教会与投票权 {level=2}
社会主义诸政党与诸教会都在这些年代里组织了大型公众。为什么那个事实不是与芬兰1906年的选举权同一个事实，而你为什么不得引用一个政党纲领来论证这一点？
:::solution
组织是[[#def-mass]]那个意义上的大众政治：人们被登记、被诉求。选举权是一条关于谁投票、谁可以参选的法律规则。芬兰1906年的规则是第二种，而它包括女性。一个政党或一座教会可以极其庞大，而与此同时女性、或者大多数男性仍然不能投票，而一个政府仍然以暴力回应一份请愿，正如血腥星期日。纲领存在过。它们的文本没有锁定，所以不得被发明。1848年2月的《宣言》是一个不同的、更早的时刻的出版物。它不是对一个后来的政党的党纲的引用。
:::
:::

:::exercise 不是起源 {level=3}
解释德雷福斯事件如何能够是政治反犹主义的一个核心个案，同时仍然不是1933年1月30日的起源。在你颠倒后半句之前，你需要什么证据？
:::hint
把法兰西的诸日期（1894年、1898年1月13日、1906年）放在一个清单里，把那个德意志任命放在另一个里。问一问一个“原因”必须联结什么。
:::
:::solution
这个事件之所以是核心的，是因为一次逮捕、一份题为《我控诉》的报纸指控、诸联盟与一场公开的争吵，使犹太人成为法兰西政治中的一个民族问题，那就是[[#def-antisemitism]]。1906年的平反结束了针对德雷福斯的法律案件，而没有抹去那场运动。希特勒在1933年1月30日的任命，是一个属于更晚一代的德意志行为，在[[wars/interwar]]里讲授。一个共有的反犹主义主题不是一条原因之链。颠倒后半句，将需要表明这个法兰西个案产生了那个任命的证据，而不只是两者都是反犹主义的政治。年表没有提供那条链，而本课拒绝它。那篇文章的文本对于这个区分并不是必需的，而且不得为了加强这个区分而被发明。
:::
:::

:::exercise 一个发明出来的人民 {level=3}
下面这句话为示例而虚构。它不是史料。“1月9日的血腥星期日和1月22日的血腥星期日教会了沙皇去授予英国在1884年已经授予的东西，而到1906年，欧洲有了一种民主的选举权。”找出三个分开的错误。
:::hint
从历法开始。然后问1884年授予了什么，授予了谁。然后问芬兰的规则是不是英国的规则，或一条欧洲的规范。
:::
:::solution
第一，1月9日与1月22日1905年是同一个事件的旧历与新历，不是给一个政府上的两堂课。两个数字相差13。第二，1884年扩大了一个英国的男性选举权，而没有包括女性，所以它不是一个民主的欧洲会抄写的“那个东西”。第三，1906年是芬兰的议会选举权，是包括女性为投票者与候选人的欧洲第一次，不是一条单一的欧洲规则，也不是一项英国的授予。这句话是虚构的，而它的三个论断每一个都在一个锁定的日期面前失败。没有任何死亡总数可供那个早晨用来使故事更生动，也不需要任何死亡总数来看见这些错误。
:::
:::
