政治成为大众政治时，谁被纳入了其中？

大众政治是指：大批民众通过选举权、政党、教会、报刊或联盟被当作公众来动员和诉求，无论他们是否有投票权。它并不意味着民主已经实现——到1914年，民主还没有实现。英国1867年的第二次和1884年的第三次改革法案扩大了男性选举权，却把女性排除在外。1871年3月至5月的巴黎公社是一个城市政府，最终被摧毁。这几十年间，反犹主义是一场政治运动；德雷福斯事件是它的典型案例，而不是1933年的起源。1905年1月22日（新历），圣彼得堡的一次请愿遭到暴力镇压。1906年，芬兰大公国的女性获得了议会选举权和被选举权。这在欧洲议会史上尚属首次，但既不是世界上最早的女性选举权，也不是英国那几项法案所做到的事。

[[nations/unifications]]中建立的国家，承载了其中的一部分。宣告建国并不产生选民群体。[[nations/industry]]中的普查统计的是在场的人，而不是选票。

## “纳入”不能被理解成什么

:::definition 大众政治 {#def-mass}
**大众政治**是把大批民众当作可以登记、诉求或排斥的公众来对待的做法。它的手段包括选举权、政党、教会、报刊与联盟。这个说法并不意味着每个成年人都参与了选择政府，也不意味着纳入是大众政治所做的唯一的事。
:::

诉求公众，可以是为了赋予其选举权，也可以是为了归罪于它。同样这几十年里，既有改革法案，也有反犹联盟。凡是把这一时期定义为“人民登场”的人，已经删掉了一半档案。对每一个有日期的行为，检验标准都是：谁在规则之内，谁在规则之外。

:::definition 政治反犹主义 {#def-antisemitism}
**政治反犹主义**作为这几十年间的一场政治运动，是一种有组织的论断，认为犹太人是民族的集体敌人，并借助报刊、联盟与选举政治来传播。它不只是私人的厌恶；在本课中，它也不是1933年1月30日希特勒（Hitler）被任命为总理的起源。
:::

:::theorem 英国的改革法案扩大了男性选举权，却没有纳入女性 {#thm-reform}
1832年的法案是第一次扩大，但范围仍然狭窄。1867年和1884年的法案进一步扩大了男性选举权，先及于自治市，后及于各郡。三项法案都没有纳入女性。男性选民群体扩大不等于民主，也不同于1906年芬兰的选举权。
:::
:::proof
年表列出了这三项法令，并说明1867年与1884年都没有纳入女性。1832年的法案已在[[revolutions/restoration-and-1848]]中作为一种狭窄的选举权讲授过。没有锁定任何关于选民规模的数字，因此不编造。这几项法案显示的是一个方向：在财产或户主资格的规则下，更多的男性获得选举权，而女性没有。能够推翻这一论断的，是1867年或1884年某项已生效、赋予女性议会选举权的条款。这样的条款并不存在。同样能够反驳把这几项法案视为民主的，是芬兰1906年的法令：它确实赋予了女性议会选举权和被选举权，而英国并未仿效。这一对照就在锁定的年份之内，无须猜测还有多少男性没有投票权，尽管户主资格的规则本身已表明这次扩大并不普遍。
:::

从1867年到1884年，是1884减1867，即17年。十七年间改革不断，而到这段时期结束时，对女性的排斥依然如故。1867年也是折衷方案之年：[[nations/unifications]]用它指匈牙利的加冕，本章用它指英国的一项法令。同一年份，两次纳入，都不是女性选举权，也都不是捷克王国。日期不是同义词。

第三次改革法案把户主选举权扩展到各郡。在这里锁定的任何日期上，它都没有废除复数投票制，也没有赋予女性投票权。十九世纪后期的法兰西共和国建立在广泛的男性选举权之上，这一选举权的革命性扩大属于1848年，而它同样把女性排除在外。在德意志帝国，帝国议会的选举权与普鲁士的选举权并不是同一种制度：普鲁士的选票是加权计算的。本课不编造具体的权重。只需指出：一个男子可以在一个德国选民群体中享有平等地位，在另一个中却不然；而这两种规则都不是芬兰的规则。

:::example 十七年与同样的排斥 {#ex-seventeen}
第二次改革法案在1867年，第三次在1884年，两者都没有让女性进入英国的议会选举权。两个年份标签相隔多久？这段间隔并没有缓和什么？
:::solution
1884减1867得17。这段间隔并不是纳入女性之前的停顿：到了较晚的日期，排斥依然存在。芬兰赋予女性议会选举权（包括被选举权）是在1906年，即1906减1884，比英国第三次法案晚22年，而且那是另一个国家的规则。英国这17年的间隔证明的是没有女性参与的改革，而不是说改革与纳入是同义词。
:::
:::

关于英国改革法案，下列哪一种说法与年表相符？

- [ ] 1867年赋予了联合王国每个成年人投票权
- [x] 1867年与1884年扩大了男性选举权，女性没有被纳入

:::solution
1832年是一次狭窄的扩大。1867年与1884年在男性中进一步扩大，却没有纳入女性。[[#thm-reform]]说的正是这一点。民主是另一个论断，[[#thm-notyet]]否认1914年已经实现了民主。
:::

## 一座城市、一个政党、一座教会

巴黎公社从1871年3月持续到5月。它是一场战争余波中的城市政府；就法国一方而言，这场战争以5月10日的《法兰克福和约》告终（见[[nations/unifications]]）。和约签订之日正处在公社存在的几个月之中。德意志帝国则早在公社开始之前的1月18日就已宣告成立。三个事实同处一季，含义却各不相同：一个帝国宣告成立，一项和约签订，一场城市革命被镇压。

公社以城市政府的身份行事，通过了若干社会措施。本课不编造任何纲领文本。女性参与了这座城市的政治生活，但这种参与并不是持久的全国性选举权，也没有在公社失败后延续下来。这场失败伴随着暴力。本课不给出死亡总数，因为没有锁定任何总数，猜测的总数只会是错误类型的精确。公社既不证明社会主义必须采取武装城市的形式，也不只是一个用来让某种学说难堪的犯罪故事。它是大众政治中一段有日期的插曲：一个公众掌握了一座城市，随后又被排斥在外。

社会主义政党同属这几十年，它们也不等于选举权。《共产党宣言》于1848年2月在伦敦出版。自称代表劳工的政党组建得更晚，它们进入了一些国家的议会，并发表纲领。本课不引用这些纲领。一个政党可以规模庞大，却仍遭受骚扰、被排除在行政权之外，或受到加权选举制的压制。组织是一种意义上的纳入，即[[#def-mass]]所说的意义；它不是芬兰在1906年改变谁可以投票、谁可以参选时的那种意义。

在同样朴素的意义上，教会也是大众性的机构。它们登记教友、施行教育、出版书刊，并在法律允许的地方举行选举。天主教与新教的社团是政治生活的组成部分，而不是政治现代化之后遗留的残余。在新成立的德意志帝国，国家与天主教会的冲突本身就是政治。本课不为这场冲突中的各项法令定年，因为这些日期没有锁定；只指出这场冲突是公开的。正如[[sources/evidence]]所坚持的，信仰并不等同于某个部的政策。一座能坐满会堂的教会，是关于组织的事实，而不是对灵魂的普查。

## 德雷福斯：是案例，不是起源

:::theorem 德雷福斯事件是政治反犹主义的案例，不是1933年的起源 {#thm-dreyfus}
德雷福斯（Dreyfus）于1894年被捕；左拉（Zola）题为《我控诉》（J'Accuse）的文章于1898年1月13日发表；德雷福斯于1906年获得平反。这一事件显示了报刊与联盟针对一名犹太军官所发动的大众政治。它没有导致1933年1月30日希特勒被任命为总理，也不是这一任命的起源。
:::
:::proof
三个日期是锁定的，文章标题可以提及。文章的语句不得编造，因此这里不予提供。仅标题本身所起的作用，就足以说明这一行为的公共性质：在报纸上、面向读者的第一人称控诉。1906年的平反意味着原判没有成立。按年份标签，从被捕到平反相隔十二年，即1906减1894。这篇文章并没有宣告他无罪；它是一次介入，按年份标签比平反早八年，即1906减1898。能够反驳把这称为政治运动的，是表明这一事件始终只是私人厌恶、既无报刊参与也无联盟活动、对公职毫无影响的证据。这篇有日期的文章恰恰否定了这种低调的解读。能够反驳拒绝与1933年相联系的，须是有证据支持的、从这一法国案例通向德国那次任命的链条。共同的偏见不构成链条。那次任命属于[[wars/interwar]]。把1894年当作它的起源，就是让一桩冤案成为一个后来政权的缔造者，而日期并没有这样说。
:::

德雷福斯是法国军队中的一名犹太军官，被控泄露机密而遭逮捕并定罪。本课不重建案卷，只记录：这一判决后来被撤销，而撤销一直拖到1906年。在此期间，这一事件使法国公共生活陷入分裂。反犹主义的运作正如[[#def-antisemitism]]所描述的：它是一种政治，而不只是冷眼相待。联盟与报纸把一个犹太人当作集体敌人的替身。这就是本章的完整案例。它是大众政治表现恶劣的案例，正因如此，不能预先赞美“大众”。

:::example 从被捕到平反 {#ex-dreyfus}
德雷福斯于1894年被捕，《我控诉》于1898年1月13日发表，平反在1906年。计算两个年份标签之间的差距，并说明关于这篇文章你不得添加什么。
:::solution
1906减1894得12，1906减1898得8。可以提及文章的标题，也可以使用它的日期；但不得凭记忆写出它的语句，也不得用冒充原文的转述代替。标题是面向公众的控诉，而不是判决。平反是后来的法律行为，并不是这篇文章自动产生的结果。两个差距都不能作为把这一事件称为1933年1月30日之起源的理由。
:::
:::

这里并不要求你赞叹这十二年，也不要求你从中提炼关于耐心的道德教训，而是要求你把一个法律结果、一份报纸与后来德国的一次任命分装在不同的格子里。一旦把格子合而为一，1894年之后的一桩法国案例就会被讲得好像它解释了1933年的总理职位。它并没有。

## 1905年与1906年，恰好分开

:::theorem 到1914年，民主尚未实现 {#thm-notyet}
到1914年，锁定的各项纳入合起来也不构成民主。英国改革了男性选举权，却把女性排除在外；俄国在血腥星期日以暴力对待请愿；芬兰在1906年展示了一条英国尚未采纳的议会规则。欧洲的首例并不是欧洲的常规。
:::
:::proof
证据就是已经定年的这组行为。1867年与1884年排斥女性。1905年1月22日（新历）是圣彼得堡的血腥星期日，也就是1905年1月9日（旧历）：同一个事件，一个公众遭到的是暴力而不是选票。本课不给出死亡总数。1906年，芬兰大公国的女性获得议会选举权和被选举权。年表称之为欧洲议会史上的首例，并禁止称之为世界上最早的女性选举权，因此本课不提任何更早的外国年份。能够推翻这一论断的，是一条锁定的普遍规则：到1914年，在本课程一路追踪的各国中生效，成年男女据此选择自己的政府。英国的法案、俄国的那一天与芬兰的例外，都不是这样的规则。芬兰既是对自满的反例，也证明了更广泛的规则并不普遍。两种用法都是正当的。
:::

两种历法正是把[[sources/time-and-names]]的方法应用于一个政治日期。俄国尚未进行1918年的历法切换，那次切换中，1月31日之后紧接着2月14日。在1905年，旧历日期与新历日期指的是同一个早晨，两个数字相差13：9加13得22。凡是把这个故事讲成两遍、仿佛请愿者在两天里分别遭到驱散的人，都把历法误当成了先后顺序。十月革命的双重日期在更晚的[[wars/revolutions-1917]]中讨论，本章止于这个一月的日子。

1905年发生的远不止那个早晨。本图谱锁定了血腥星期日，却没有为当年稍后的让步与起义锁定日期，因此不编造这些日期。一场革命可以是真实的，而在某一课中仍只有一个有日期的门槛。这里的门槛是请愿者遭受的暴力。那个早晨恰恰不是选举权。

1906年的芬兰是另一个门槛。在俄国皇帝统治下的这个大公国，获得了把女性同时作为选民与候选人纳入的议会选举权。“被选举权”并不是点缀：没有被选举权的投票权是较为单薄的纳入，而芬兰的规则两者兼具。英国1884年的规则对女性则两者皆无。图示有意把1905年与1906年并排摆放，三年的窗口才勉强把两者分开。一个是街头的拒绝，一个是关于谁可以进入议会的法令。把两者都称为“大众的兴起”，在你说明是哪一个公众、哪一项权利之前，什么也说明不了。

:::example 一个早晨，两个数字 {#ex-sunday}
血腥星期日是新历1905年1月22日，也是旧历1905年1月9日。请证明两个数字相差13，并说明这一差别不是什么。
:::solution
22减9得13，9加13得22。这一差别是同一天在俄国历法与格里高利历中的日期之差。它既不是第二次请愿，也不是死亡总数。本课以新历日期为标记，并把旧历日期附在旁边。两者指的是同一个事件。
:::
:::

:::example 对1884年的一个编造的论断 {#ex-invented}

:::solution
1884年、1871年3月至5月与1905年都是真实的。“英国人民”并不是第三次改革法案所规定的选民群体，那次法案扩大的是男性选举权，并不包括女性。公社也没有为这项法案“指明道路”：它是一个遭到镇压的法国城市政府，按年份标签比1884年早十三年，即1884减1871。民主在1884年并未完成；1905年的圣彼得堡发生的是血腥星期日，而不是已经完成的民主。本可作为有意义对照的芬兰选举权，在这句编造的话里缺席了，而它在1906年。这句话借真实的年份，偷运了一个已经完成的“人民”。
:::

## 反驳必须面对什么

有一种反驳说，1867年与1884年代表民主的到来，或许缓慢，但缓慢的到来仍是到来。它指向真实的法令：每一项法令之后，能投票的男性都比以前多；社会主义政党与教会建立了旧式精英政治所不知道的组织。这些都是事实，属于[[#def-mass]]的范围，却达不到[[#thm-notyet]]。

能够支持这种反驳的，是这样一条规则：到1914年，无论在英国还是作为欧洲的常规，本章列举的各种排斥都已失效。那样的话，女性会在英国的议会选举权之内；俄国首都的一次请愿，就不会成为公众与国家相遇的写照；芬兰也会是常态而非首例。这些都不是锁定的记录。这种反驳能够保留的，是更为谦逊也更为诚实的说法：选民群体扩大了，政党与教会组织起来了，有些国家在1906年比在1832年更加开放。这样的增长就是大众政治。它不是民主的同义词，本章也不会认可这种同义。

关于德雷福斯事件，还有第二种反驳。它说，德雷福斯只是一桩冤案，不幸而属个人遭遇，通常意义上的政治在别处照常进行。一名被告可以只是一个人，却仍成为一场运动的契机。检验标准不在于被告的人数，而在于报刊、联盟与公职机构是否把这一案件当作关于犹太人的全国性问题来对待。它们确实如此。1906年的平反结束了针对他的法律案件，但既没有把那场运动倒退回私人的冷眼相待，也没有把这一案件向后投射为1933年的原因。“只是个人遭遇”与“后来一切的起源”这两种夸大，在同样的日期面前都站不住脚。

:::warning 1914年前的民主，以及1933年的法国起源
有两种迷思借用了本章的日期，却错读了它们。第一种说，到1914年民主已经实现，因为改革法案已经通过，政党已经存在。然而，女性被排除在英国1867年与1884年的法案之外；血腥星期日是一个公众遭到暴力对待；芬兰1906年的选举权是首例，而不是常规。第二种迷思把德雷福斯事件当作1933年的起源。这一事件从1894年的逮捕，经1898年1月13日的文章《我控诉》，到1906年的平反；总理职位则是后来德国的行为。大众政治包括改革，也包括针对少数群体的运动。两者都不是圆满的结局。
:::

:::history
巴黎公社从1871年3月到5月控制着这座城市。此前，德意志帝国已于1月18日宣告成立；而5月10日的《法兰克福和约》正签订于公社存在的几个月之中。公社是一个政府，最终被摧毁。它不是1871年帝国的含义，对于参与其中的女性来说，它也不是选举权。
:::

## 通向何处

选举权成为问题的那些国家，是在[[nations/unifications]]中建立或遭到拒绝的。普查能够看见、却尚未成为选民的人，见[[nations/industry]]。范围狭窄的1832年法案与1848年2月的《宣言》，见[[revolutions/restoration-and-1848]]。历法问题，包括为什么1月9日与1月22日可以是同一天，见[[sources/time-and-names]]。这些国家的海外帝国，见[[nations/empires]]。显示1914年的政治多么未完成的那场战争，见[[wars/first-world-war]]；本章拒绝从德雷福斯推导出来的1933年德国那次任命，见[[wars/interwar]]。

:::summary
- 大众政治通过选举权、政党、教会、报刊与联盟诉求广大公众。它不是民主，到1914年民主尚未实现。
- 1832年的改革法案是一次狭窄的扩大。1867年与1884年的法案扩大了男性选举权，女性没有被纳入。两个年份标签相隔17年。
- 巴黎公社从1871年3月持续到5月。它是一个城市政府，最终被摧毁，本课不给出死亡总数。它既不是1月18日德意志帝国的宣告，也不是5月10日的《法兰克福和约》，尽管和约签订于公社存在期间。
- 德雷福斯于1894年被捕。左拉题为《我控诉》的文章发表于1898年1月13日，本课不编造其文本。平反在1906年。这一事件属于政治反犹主义，而不是1933年1月30日的起源。
- 血腥星期日是新历1905年1月22日，即旧历1月9日，是同一个事件。两个数字相差13。本课不给出死亡总数。
- 1906年，芬兰大公国的女性获得议会选举权和被选举权。这是欧洲议会史上的首例，不是世界首例，也不是英国的改革。
:::

## 习题

:::exercise 英国的间隔 {level=1 check="17"}
英国第二次与第三次改革法案的年份标签之间相隔多少年？（请输入年数。）
:::solution
1884减1867得17。两项法案都把女性排除在议会选举权之外。这个数字是男性选民群体两次扩大之间的间隔，而不是衡量民主完成程度的尺度。
:::
:::

:::exercise 平反的年份 {level=1 check="1906"}
德雷福斯在哪一年获得平反？（请输入年份。）
:::solution
平反在1906年。逮捕在1894年，按年份标签早十二年。《我控诉》发表于1898年1月13日，按年份标签比平反早八年。可以提及文章标题，但不得提供其中的语句。
:::
:::

:::exercise 历法之差 {level=1 check="13"}
血腥星期日的新历与旧历日期相差多少天？（请输入数字。）
:::solution
1月22日减1月9日得13。两个数字指的是同一个事件，而不是两个早晨。新历是本课使用的标记，旧历是俄国历法对同一天的称呼。
:::
:::

:::exercise 同一季的三个事实 {level=2}
1871年1月18日、1871年5月10日与1871年3月至5月，很容易被一并记作“1871年”。请分别描述每一个，并指出哪一个是公社。
:::solution
1月18日是德意志帝国在镜厅宣告成立，当时巴黎仍在作战，公社也尚未开始。5月10日是《法兰克福和约》。3月至5月是巴黎公社，一个随后被摧毁的城市政府。和约签订之日正处在公社存在的几个月之中，这正是季节相同而事实不同的原因。答案中不应出现死亡总数。
:::
:::

:::exercise 为什么这些法案不是民主 {level=2}
一位读者说，1867年和1884年之后英国已是民主国家，而1906年的芬兰只是重复了这一经验。请回应这两个分句。
:::solution
英国的法案扩大了男性选举权，却没有纳入女性。户主资格规则不是普遍的成人选举权，这里也不编造任何选民总数来加以粉饰。1906年的芬兰赋予女性议会选举权和被选举权。这是欧洲议会史上的首例，既不是对英国法案的仿效，也不是世界上最早的女性选举权。[[#thm-reform]]与[[#thm-notyet]]正是这位读者颠倒了的两个分句。
:::
:::

:::exercise 政党、教会与选举权 {level=2}
这几十年间，社会主义政党与教会都组织起了广大公众。为什么这一事实与1906年芬兰的选举权不是同一个事实？为什么你不得引用政党纲领来说明这一点？
:::solution
组织是[[#def-mass]]意义上的大众政治：人们被登记、被诉求。选举权则是关于谁可以投票、谁可以参选的法律规则。芬兰1906年的规则属于后者，而且纳入了女性。一个政党或一座教会可以规模极大，而与此同时女性乃至大多数男性仍然不能投票，政府仍以暴力回应请愿，正如血腥星期日那样。这些纲领确实存在，但其文本没有锁定，因此不得编造。1848年2月的《宣言》是另一个更早时刻出版的文本，而不是对后来某个政党党纲的引用。
:::
:::

:::exercise 不是起源 {level=3}
请解释：德雷福斯事件为何能够是政治反犹主义的核心案例，却仍不是1933年1月30日的起源？在推翻后半句之前，你需要什么证据？
:::hint
把法国的日期（1894年、1898年1月13日、1906年）列在一份清单里，把德国的那次任命列在另一份里。想一想，所谓“原因”必须把什么联系起来。
:::
:::solution
这一事件之所以是核心案例，是因为逮捕、题为《我控诉》的报纸控诉、联盟与公开的争吵，使犹太人成为法国政治中的全国性问题，这正是[[#def-antisemitism]]所说的。1906年的平反结束了针对德雷福斯的法律案件，却没有抹去那场运动。1933年1月30日希特勒的任命是后一代人的德国行为，在[[wars/interwar]]中讲授。共同的反犹主题不构成因果链条。要推翻后半句，需要证明这一法国案例造成了那次任命，而不仅仅是两者都属于反犹政治。年表没有提供这样的链条，本课拒绝这种联系。作出这一区分并不需要文章的原文，也不得为了加强这一区分而编造原文。
:::
:::

:::exercise 编造的“人民” {level=3}
下面这句话为示例而虚构。它不是史料。“1月9日的血腥星期日和1月22日的血腥星期日教会了沙皇给予英国在1884年已经给予的东西，到1906年，欧洲有了统一的民主选举权。”请找出三个各不相同的错误。
:::hint
从历法入手。再想一想1884年给予了什么、给予了谁。最后想一想芬兰的规则是不是英国的规则，或者是不是欧洲的常规。
:::
:::solution
第一，1905年的1月9日与1月22日是同一事件的旧历与新历日期，而不是给政府上的两堂课；两个数字相差13。第二，1884年扩大的是英国的男性选举权，并没有纳入女性，因此它不是一个民主的欧洲会仿效的“东西”。第三，1906年是芬兰的议会选举权，是欧洲首次把女性作为选民与候选人纳入，既不是统一的欧洲规则，也不是英国的授予。这句话是虚构的，它的三个论断都在锁定的日期面前站不住脚。既没有关于那个早晨的死亡总数可以用来渲染故事，看出这些错误也不需要任何死亡总数。
:::
:::
