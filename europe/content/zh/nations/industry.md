普查的数字显示了什么，而“英国居先”又主张了什么？

普查是替一个国家做的一次清点：在国家选择的一个时刻，清点调查员受命记录的那些人。它可以被印行、修订与比较。它单凭自身说不出谁过得好，也说不出哪一种经济必须先增长。公元1801年的英国普查给英格兰与威尔士留下了两个官方数字，而不是一个。关于工业的经典论断又是一种不同种类的句子：英国在棉花、煤与铁上的机械化增长，按欧洲的标准是早的。那个论断是有争论余地的。它不是一条规律，而两个印出的总数也都不是它的替代品。

本课程接手的这段时期，以公元1815年的安排开始：6月9日的维也纳会议最后法案，与6月18日的滑铁卢。那些日期关闭了一场战争。它们没有开动一台机器。本章读那些被印行过的数字，并拒绝那些没有被印行的。

## 一年的两份印本

:::definition 清点 {#def-enumeration}
一次**清点**是：在一条说明的规则之下、在一个说明的时刻，对在场者进行的计数。奉命于公元1801年12月21日付印的《普查摘要》（Enumeration Abstract），就是这样一次对英格兰、威尔士与苏格兰的计数。它不是后来一位史家的估计，也不是对收入、健康或选举权的一种测量。
:::

这份摘要印出了本课要用的三行。英格兰是8,331,434。威尔士是541,546。苏格兰是1,599,068。由那两行相加，英格兰与威尔士是8,872,980。苏格兰保持单独一行。我们不把它折进下面的英格兰与威尔士数列，我们也不把三行当作对整个不列颠的一份经过修订的单一总数。爱尔兰根本不在这份摘要里。它是另一张表，它在本章更晚的地方出现。

:::definition 后来的数列 {#def-series}
**后来的数列**是公元1901年的普查报告在比较这个世纪时所使用的那一串英格兰与威尔士的总数，也是公元1911年的回溯表所同样刊载的那一串。在那个数列里，公元1801年的英格兰与威尔士是8,892,536。这个数字是官方的。它不是摘要的加总之和，也不是第二个国家。
:::

:::theorem 这道差距是一次修订，不是第二份人口 {#thm-gap}
后来的数列超出摘要的英格兰与威尔士之和19,556。这道差距是对那个印出的总数的一次修订。两个数字，单拿哪一个出来，都不是丢弃了另一个之后的那个真人口。
:::
:::proof
算术由两份印本钉住。摘要的英格兰，8,331,434，加威尔士，541,546，是8,872,980。后来的数列为同一对被命名的国家、在同一个被命名的年份，印出8,892,536。相减给出19,556。本图谱的年表把这道差异称为一次修订，不是两个不同的国家。会构成对这一读法的反证的，是表明8,892,536所描述的领土、日期或人的类别不同于摘要的那对英格兰与威尔士、并且公元1901年的报告曾沉默地比较这些不相类之物的证据。这里所采用的记录中没有任何这样的断裂。会把任何一份印本单独当作人口来对待，同样会构成反证的，恰恰是另一份印本的存在。两份都存世。
:::

:::example 把英格兰与威尔士相加 {#ex-sum}
摘要给出英格兰8,331,434，威尔士541,546。把它们加起来。（如果你要用这个结果核对后面的一道习题，请输入不带逗号的和。）
:::solution
把541,546拆成500,000、41,000与546。于是8,331,434加500,000是8,831,434。加41,000给出8,872,434。加546给出8,872,980。那就是摘要的英格兰与威尔士之和。它不是后来的数列，也不包括苏格兰的1,599,068。
:::
:::

:::example 19,556这道差距 {#ex-gap}
就公元1801年，从后来的数列中减去摘要的英格兰与威尔士之和。
:::solution
后来的数列是8,892,536。摘要的和是8,872,980。差额是8,892,536减8,872,980，即19,556。较晚的印本是较大的那一个。这道差距就是本图谱关于这次修订要说的全部内容。我们不把19,556拆成漏计的教区、士兵或水手。那些部分这里没有给出，而一个编造的拆分将会是一次虚假的精确。
:::
:::

:::quiz
关于公元1801年英格兰与威尔士的两个数字，哪一句话是本课将要捍卫的？
- [ ] 8,872,980是真人口，而8,892,536是一个应当忽略的错误
- [ ] 8,892,536是真人口，而摘要可以扔掉
- [x] 两个数字相差一次19,556的修订，而其中任何一个都不是丢弃了另一个的那个真人口

:::solution
摘要的和与后来的数列都是英格兰与威尔士的官方印本。它们的差额是19,556，这里读作一次修订，不是第二个国家，也不是一个爱尔兰的总数。爱尔兰的数字是另一次比较，在公元1841年与1851年之间。
:::
:::

想要一个数字来画一张图的读者仍然得做出选择。本课的那个图形为公元1801年选择了后来的数列，而图注说明了这一点。选择一个圆点不等同于删除摘要。每当本章说“8,892,536”，它指的是后来的数列。每当它说“8,872,980”，它指的是公元1801年12月21日那份摘要的英格兰加威尔士。

## 后来的圆点填不上什么

同一个数列为公元1851年印出英格兰与威尔士17,927,609，为公元1901年印出32,527,843。公元1901年的总数是对活在公元1901年3月31日午夜的那些人的一次清点。那个钟点要紧。那天早晨更晚出生的一个孩子不在这个总数里。一个在午夜之前死去的人也不在里面。那条规则是一条关于在场的规则，不是关于一条生命的价值的规则。

标签1801、1851与1901相隔五十年，然后又相隔五十年：1851减1801是50，而1901减1851是50。从年份标签1801到年份标签1901是100年。公元1901年3月31日的午夜不是公元1801年12月21日的周年纪念日，所以这些时刻之间的跨度并不是为中间的日子发明一个人口的理由。三个圆点是三个总数。它们不是一份公元1830年的普查，也不是为一条图线恰好穿过的任何年份的普查。

:::example 一道差额不是人口的流动 {#ex-diff}
使用后来的数列，用公元1851年的总数减去英格兰与威尔士的公元1801年总数，再用公元1901年的总数减去公元1851年的总数。说出每一道差额不是什么。
:::solution
17,927,609减8,892,536是9,035,073。然后32,527,843减17,927,609是14,600,234。每一个结果都是一个印出的总数超出一个较早总数的部分。它不是对出生、对迁居者、或对由工业增添的人的一次计数。1851年的人并不是1801年的人外加一个批次。把任何一道超出称为一个人口，将发明一个报告里并没有的普查。
:::
:::

:::widget series
points: 1801,8892536; 1851,17927609; 1901,32527843
ylabel: 英格兰与威尔士的人数
caption: 移动年份。三个圆点是本课中经过清点或经过修订的总数。它们之间的那条线不是它所穿过的诸年份的人口。1801年的圆点是8,892,536，即后来的数列，不是摘要的8,872,980。
:::

摘要的苏格兰那一行，1,599,068，不是第四个圆点。爱尔兰也不在这个图形上。一条英格兰与威尔士的上升线，与同一个国家内部别处的一条下降线，是相容的。那就是下一节。

## 爱尔兰不是一份死亡名册

公元1901年的报告所使用的比较表给出公元1841年的爱尔兰为8,175,124，公元1851年的爱尔兰为6,552,385。清点的总数下降了。下降的幅度是这张表的算术的一部分。下降的含义不是写在数字下面的一个单一的原因。

:::theorem 爱尔兰的下降不是饥荒死亡计数 {#thm-ireland}
从公元1841年到1851年，爱尔兰被清点的人口下降了1,622,739。那个整数混合了死亡、迁出与出生减少。它不是对饥荒死亡的一次计数，而本课将不会给出一个死亡总数。
:::
:::proof
8,175,124减6,552,385是1,622,739。年表说这个差额混合了死亡、迁出与出生减少，而它禁止把这个整数读作一个饥荒死亡计数。一个死亡总数将是一种不同的统计。这里没有印出任何一个，所以一个也不给出。会构成对这条论断的反证的，是一份被本图谱接纳的、把这三个过程分开并且显示整个差额都是死亡的史料。这样的拆分是得不到的。一次清点的下降也会随人们离开与孩子们没有出生而变化，这就是这个整数不能只凭它的形状重新命名的原因。
:::

下降两侧的年份是普查年份，不是枯萎病的一段叙述。本图谱没有为马铃薯歉收的开始锁定一个年份，所以本课不发明一个。它锁定这一对清点，以及那条禁止对它们的差额重新命名的禁令。公元1846年《谷物法》的废除，是一件关于谷物与贸易的英国事实。它不是一份爱尔兰的普查，也不是一份死亡名册。“废除解释了1,622,739”将需要本章没有的证据，而且仍然不会把这个整数变成死亡。

:::example 计算爱尔兰的下降 {#ex-ireland}
检查那两个爱尔兰总数的减法，并说出这个差额被允许混合的三个过程。
:::solution
8,175,124减6,552,385。首先，6,552,385加1,600,000是8,152,385。到8,175,124还剩下的距离是22,739。所以差额是1,600,000加22,739，即1,622,739。反过来检查：6,552,385加1,622,739返回8,175,124。这个差额混合了死亡、迁出与出生减少。它没有说出一个死亡的人数。
:::
:::

把爱尔兰那一对放到英格兰与威尔士数列旁边，尺度就改变了主意。在公元1801年与1851年之间，后来的数列上升，从8,892,536到17,927,609。在公元1841年与1851年之间，爱尔兰的清点下降。在一张表上的一次真实上升，与在另一张表上的一次真实下降，可以共享一个国家，却不共享一种命运。那就是[[sources/scale]]的纪律：一个尺度上的一个事实，不是在另一个尺度上说一句句子的许可证。

- [ ] 公元1801年两份英格兰与威尔士印本之间的差距
- [x] 从公元1841年的爱尔兰清点下降到公元1851年的爱尔兰清点，混合了死亡、迁出与出生减少

:::solution
摘要的苏格兰那一行是1,599,068。公元1801年的差距是19,556。爱尔兰的下降是8,175,124减6,552,385，即1,622,739，而本图谱拒绝把那个差额称为死亡计数。

## 专利、铁路、法令

人口总数是一份档案。机械与法律是另一份。它们在经典论断里相遇，而它们不会自动相遇。

公元1769年，瓦特（Watt）为分离式冷凝器取得了一项专利。这项专利是一项法律事实，关于一台比那种在汽缸内部冷凝蒸汽的机器更有效率地使用蒸汽的机器。它不是一份工厂的普查，也没有说明制造了多少台机器。从1769年到斯托克顿—达灵顿铁路的通车，是1825减1769，即56年。那次跨度开端的一项专利与末端的一条铁路，是两件带着日期的制品。它们中间的诸年份不是一条马力的图线。

:::example 两次通车，按标签相隔五年 {#ex-span}
斯托克顿—达灵顿铁路于公元1825年9月27日通车。利物浦—曼彻斯特铁路于公元1830年9月15日通车。年份标签之间隔着多少年，而通车日之间的跨度为什么不那么整长？
:::solution
年份标签相差1830减1825，即5。通车日之间不足五个整年，因为9月15日在9月27日之前。本课使用那个年份跨度，而不把它换算成旅客。两次通车都不是一个人口。利物浦—曼彻斯特常常被视为进入城际运输的一次更清楚的断裂。斯托克顿—达灵顿仍然是较早的那个日期。
:::
:::

英国的工厂法是公元1833年。它管制工厂劳动，特别是纺织工场里的童工，并且它创设了监察。本课不提供年龄或工时：那些数量不在锁定的年表里。一项法令显示，公共权威已经开始把工厂当作一个它可以管制的地方。它没有显示规则被遵守了，也没有显示普查因为这项法令而上升。从公元1830年的利物浦—曼彻斯特通车到那项法令，按标签是三年。一条铁路与一项法令可以都为真，而不需要其中一个引起另一个。

公元1832年的改革法案属于国家活动的同一代，并且已经在[[revolutions/restoration-and-1848]]里讲授。它所扩大的选举权仍然是狭窄的。在公元1801年、1851年与1901年被清点的人，不是那些能够投票的人。一份增长的普查与一个保持狭窄的选举权是相容的。把它们混淆，是一个人口总数被误读为一个民主事实的方式。那个误读在[[nations/mass-politics]]里处理。这里，把两份档案分开就够了：午夜在场不是一票。

## 英国居先的论断

:::definition 经典论断 {#def-classic}
本图谱所使用的经典论断里，**工业化**指的是公元十八世纪末与十九世纪初英国在棉花、煤与铁上的机械化增长，按欧洲的标准是早的。它不是说每一名工人都站在一台机器旁，不是说没有别的地区机械化，也不是说英国必须是第一个。
:::

:::theorem “英国居先”不是一条规律 {#thm-not-law}
经典论断是一次比较，向关于时机、完成程度、煤、工资、奴隶制与帝国的证据保持开放。英国必须先工业化，它不是一条规律，而一份普查的上升单凭自身并不能证明这个论断。
:::
:::proof
在别处、用同样的度量、在更晚更大的一次棉花、煤与铁的机械化，将构成对“早”的反证。表明作坊、农场与家庭生产吞并了那些部门、而不是坐在它们旁边的证据，将构成对任何听上去像一次彻底转变的措辞的反证。一次上升的清点救不了那个措辞。英格兰与威尔士可以从8,892,536增长到17,927,609，再到32,527,843，与此同时爱尔兰在下降，与此同时许多工人仍然在工厂之外。史家们就那些条件争论，而那场争论是这个论断的一部分。会击败整个比较的，是一个证明，证明那些部门的变化按主张者愿意说出的任何度量都不是早的。做不到这一点，这句话就作为一条有对手的论断站着。
:::

这些对手必须被分开，否则这场争论就坍缩成一句口号。

当史家们拒绝一个只由发明家构成的故事时，煤是他们伸手去拿的那个条件。瓦特1769年的专利属于那段历史：热与机械功取自煤，而不是仅仅取自木材与肌肉。这是转述，而且它是一次转述：转用煤移除了一个限制。支持它的证据，是早期工厂与锻炉对煤的依赖，而这种依赖是同时代的其他生产者所没有的。反对它的证据，是一条没有那种燃料的早期机械化道路。地下的煤还不是一个经济。专利是一项社会事实，不是一种矿物。

工资是第二个条件，而它们很容易被错当成一个幸福的结局。一种论证说，英国的劳动相对于能源是昂贵的，所以一台机器是划算的。那是一个关于雇主激励的论断。它不是清点测量舒适度的论断，也不是公元1833年的工厂法毫无必要的论断。会构成对它的反证的，是机器最先在工资低的地方传播的证据。本图谱不给出任何工资数列，也不会发明一个。

奴隶制与帝国分裂成两个不得熔铸在一起的论断。大西洋贸易——在奴隶贸易航行数据库覆盖1501至1866年的登船地区表上——是登船者12,521,354人的一个估计。那是那个项目的估计，不是当时做的一次人头点数，也不是世界历史上每一场奴隶贸易的一个总数。下船的人少于登船的人，因为有人在航程中死了。本课不为那次横渡给出死亡总数、国别份额或利润总和。公元1807年的英国法令针对的是贸易，而不是奴隶制。公元1833年的法令在大部分大英帝国废除奴隶制，而学徒身份延续到公元1838年。这两个日期都没有终结帝国，也都没有终结英国管辖之外、由被奴役者种植出的纤维的供应。那个供应就是纤维论断：兰开夏的棉花依赖于奴隶种植出的纤维。它可以在两项法令之后继续存在，因为那些法令并不管辖每一座种植棉花的种植园。

第二个关于奴隶制的论断关乎金融：贸易与奴隶殖民地的利润为机械化付了账。史家们意见不一。有些人把那些利润当作早期工厂的一个条件。另一些人则论证，国内需求、煤与工资做了更多的工作。本图谱没有一个可以引用的已定的百分比，而它不会发明一个。会支持那个金融论断的，是一笔大到足以改变时机的资金流。会构成对它的反证的，是一个融资的故事，其中工厂由国内的来源建成，而纤维论断仍然为真。你可以接受一个论断而悬置另一个。作为征服的帝国在[[nations/empires]]里回来。那桩贸易本身在[[states/atlantic]]。公元1804年1月1日的海地独立，以及法国对殖民地奴隶制的废除与恢复，属于[[revolutions/napoleon]]，也属于公元1848年法国的第二次废除。它们不是那张英格兰与威尔士图上的一条线。

完成程度是措辞内部的那个限度。远在公元1825年与1833年之后，许多工作仍然是农业的、家庭的，或者是在小作坊里的熟练手艺。比利时与德意志诸邦的一些地区也实行了机械化。本课不为那些道路定年，因为年表没有为它们锁定一个年份。“居先”是一次关于时机与规模的比较，而史家们争论英国的个案有多早、有多彻底。一次比较可以在棉花机械上赢，而在劳动力中的份额上输。在那个度量被说出之前，“英国居先”就是[[sources/argument]]所警告的那一类标签。

普查无法裁判这些对手。公元1901年比1801年更大的总数，与煤起了作用相容，与煤没有起足够的作用相容，与奴隶种植的棉花喂养了工厂相容，与奴隶贸易的利润没有为它们提供资金也相容。从32,527,843走到一条规律，是在改变话题。

## 一个完整的案例

设想一句地方编年史也许曾想要的句子。下面这句话为示例而虚构。它不是史料。“公元1830年9月15日，英格兰的每一座城镇都加倍了，因为利物浦—曼彻斯特铁路通车了，而1801年奉命进行的普查早已证明工业是一条规律。”

:::example 读一句虚构的句子 {#ex-invented}
上一段里的那句话是虚构的。把它借用的有日期的事实与它添加的论断分开，并说出要把任何一个添加的论断提升为证据需要什么。
:::solution
两处借用是真实的：公元1830年9月15日的利物浦—曼彻斯特通车，与奉命于公元1801年12月21日付印的那份摘要。“英格兰的每一座城镇都加倍了”不在摘要里，不在后来的数列里，也不在那次通车里。摘要的英格兰是8,331,434，不是一份加倍了的城镇的清单。“证明工业是一条规律”通不过[[#thm-not-law]]：经典论断是一次比较，而一次普查不是那个比较。把加倍提升起来，将需要若干座具名城镇的清点、一条计数规则，以及一个把那个变化与铁路联结起来的理由。把那条规律提升起来，将需要[[#def-classic]]里的那些度量，以及一个本来可能失败的检验。那句虚构的句子两样都不提供。
:::
:::

:::warning 一个真人口，以及一份死亡名册
三种习惯造成本章之所以存在要阻止的损害。第一种从8,872,980与8,892,536中挑出一个，称之为公元1801年的真人口。19,556这道差距就是它失败的原因。第二种把1,622,739读作一个饥荒死亡计数。那次下降混合了死亡、迁出与出生减少，而这里没有给出死亡总数。第三种把经典论断当作一条英国必须是第一个的规律，并把一份上升的普查当作证明。
:::

:::history
《普查摘要》奉命于公元1801年12月21日付印。它给出英格兰8,331,434、威尔士541,546，而它们的和是8,872,980。一个较晚的官方数列——公元1901年的报告在比较这个世纪时所使用的那一个——给出英格兰与威尔士8,892,536。两个数字都是这个数字的历史的一部分。
:::

这些记录中的每一份承载一种事实：一条规则之下的一个总数、一项专利、一个通车日、一项法令，或者一次仍然有对手的比较。一句需要一个死亡总数、一个利润份额、或圆点之间某一年的人口的句子，不是本章将要签署的句子。一份英格兰与威尔士的普查也不会决定爱尔兰是否是一个民族。在公元1841年与1851年之间，它只决定爱尔兰的各个总数照它们所是的样子变动了。

## 通向何处

[[sources/evidence]]与[[sources/scale]]是那道算术底下的方法：一条史料不是那个推论，而一个尺度上为真的一个总数，在另一个尺度上可以是一个假句子。[[states/atlantic]]保存着这里使用的登船估计，而[[revolutions/napoleon]]与[[revolutions/restoration-and-1848]]保存着革命的诸日期、狭窄的公元1832年改革法案、以及1848年。普查之后被建成与被拒绝的民族国家在[[nations/unifications]]。选举权——这些总数没有描述它——在[[nations/mass-politics]]。作为征服的帝国——而不是作为经典论断之下被争论的一个条件——在[[nations/empires]]。

:::summary
- 奉命于公元1801年12月21日付印的《普查摘要》，给出英格兰8,331,434、威尔士541,546与苏格兰1,599,068。英格兰加威尔士是8,872,980。
- 公元1901年的报告所使用的后来的数列，给出公元1801年的英格兰与威尔士8,892,536。19,556这道差距是一次修订，不是第二个国家，而单独看，两个印本中哪一个都不是人口。
- 英格兰与威尔士在公元1851年是17,927,609，在公元1901年3月31日午夜是32,527,843。圆点之间的那条线不是它所穿过的诸年份的一次普查，而两个总数之间的差额不是人口的流动。
- 爱尔兰在公元1841年是8,175,124，在1851年是6,552,385。1,622,739的下降混合了死亡、迁出与出生减少。它不是一个饥荒死亡计数。
- 瓦特的专利是1769年。斯托克顿—达灵顿于公元1825年9月27日通车。利物浦—曼彻斯特于公元1830年9月15日通车。工厂法是1833年。这些都不是一个人口。
- 经典论断是棉花、煤与铁的早期机械化增长。史家们就时机、完成程度、煤、工资、奴隶制与帝国争论。它不是一条英国必须是第一个的规律，而纤维论断不是金融论断。
:::

## 习题

:::exercise 摘要的和 {level=1 check="8872980"}
把摘要为英格兰与威尔士给出的两个数字加起来，8,331,434与541,546。（请输入这个数字，不带逗号。）
:::solution
8,331,434加541,546是8,872,980。一条路径：加500,000到8,831,434，再加41,000到8,872,434，再加546到8,872,980。
:::
:::

:::exercise 那次修订 {level=1 check="19556"}
公元1801年英格兰与威尔士的后来数列超出摘要的和多少人？（请输入这个数字，不带逗号。）
:::solution
8,892,536减8,872,980是19,556。那个超出是对印出的总数的一次修订，不是第二个国家，也不是一个爱尔兰的数字。
:::
:::

:::exercise 苏格兰的那一行 {level=1 check="1599068"}
《普查摘要》为苏格兰印出什么数字？（请输入这个数字，不带逗号。）
:::solution
苏格兰印为1,599,068。那一行不是本课图形上的一个圆点。那些圆点只是英格兰与威尔士，而1801年的圆点是后来的数列，8,892,536，不是一个包括苏格兰的和。
:::
:::

:::exercise 一次上升的两种描述 {level=2}
后来的数列从公元1801年的8,892,536移动到公元1851年的17,927,609。一名学生既说“总数增长了9,035,073”，又说“工业增添了9,035,073人”。接受一句话，拒绝另一句。
:::solution
接受第一句。17,927,609减8,892,536是9,035,073，是一个印出的总数超出另一个的部分。拒绝第二句。那个超出不是对由工业、由迁移、或由出生增添的人的一次计数。两次清点追踪的不是同一些个人，而关于机械化增长的经典论断与这道减法不是一条算术恒等式。在同一段时期的一部分上爱尔兰的下降，是不把一道超出变成一条民族规律的一个进一步的理由。
:::
:::

:::exercise 铁路与法令 {level=2}
斯托克顿—达灵顿于公元1825年9月27日通车，利物浦—曼彻斯特于公元1830年9月15日通车，而工厂法定年为公元1833年。这三个日期放在一起能显示什么，而不能显示哪一个原因？
:::solution
它们一起显示两次运输通车，以及一项管制工厂劳动、带有监察的法令，包括纺织工场里的童工。从1825到1830，年份标签相差5，而1833在1830之后三年。它们没有显示铁路引起了那项法令，没有显示任何一次通车引起了普查的上升，也没有显示年龄与工时可以从这份年表里引用。瓦特1769年的专利是一项较早的法律事实，按标签在1825年之前56年，不是从那项法令里倒读出来的一个原因。
:::
:::

:::exercise 说出经典论断及它的限度 {level=2}
用两三句话，说出关于英国工业化的经典论断，以及一个使它成为不了规律的限度。不要把一个人口数字当作证明。
:::solution
经典论断是：公元十八世纪末与十九世纪初英国在棉花、煤与铁上的机械化增长，按欧洲的标准是早的。限度是：史家们争论它有多早、有多彻底、煤、工资、奴隶制与帝国在多大程度上是条件，而且别的地区也实行了机械化。一条规律会说英国必须是第一个。那个论断没有这样说。一份普查总数补不上这个缺口：[[#thm-not-law]]把比较与清点放在不同的句子里。
:::
:::

:::exercise 纤维与金融 {level=3}
把英国棉花使用了奴隶种植的纤维这一论断，与奴隶贸易的利润为工厂提供了资金这一论断分开。哪一个公元1807年或1833年的事实可以支持其中一个论断而让另一个悬着？什么会构成对金融论断的反证，而不触碰纤维论断？
:::hint
公元1807年的法令与公元1833年的法令改变了英国的法律。问一问它们不管辖哪一种生产，以及它们不测量哪一种资金流。
:::
:::solution
纤维论断关乎供应：在英国纺出的棉花是由被奴役的劳动种出来的，其中包括英国的法令没有解放的劳动。金融论断关乎资本：贸易与奴隶殖民地的利润为工厂付了账。公元1807年的法令禁止英国的贸易，而没有废除奴隶制。公元1833年的法令在大部分大英帝国废除奴隶制，学徒身份延续到1838年。两者都可以让纤维论断站着。两者都不测量利润，所以哪一个也不证明金融论断。工厂由国内的来源获得资金的证据，将构成对金融论断的反证，而不触碰纤维论断。本图谱两个方向都不给出百分比。史家们意见不一，而这个分歧属于答案的一部分。
:::
:::

:::exercise 一个教区与一个王国 {level=3}
下面这句话为示例而虚构。它不是史料。“诺斯福德的教区登记簿，在铁路测量员到访与下一次收获之间加倍了，所以英格兰与威尔士加倍了，而爱尔兰也必定加倍了。”只使用锁定的总数，解释那两个尺度错误。
:::hint
把公元1841年到1851年爱尔兰各总数的方向，与公元1801年到1851年英格兰与威尔士数列的方向比较。然后问一问一份教区登记簿不是什么。
:::
:::solution
第一个错误把一个虚构的教区提升为英格兰与威尔士。一份登记簿不是普查，而一个教区不是8,892,536或17,927,609。后来的数列确实在那些年份之间上升，上升了9,035,073，但那个事实不是从诺斯福德推演出来的。第二个错误把英格兰与威尔士的方向硬拖过爱尔兰。爱尔兰从公元1841年的8,175,124移动到1851年的6,552,385，下降了1,622,739，不是加倍。这句话作为证据失败，因为它是虚构的；作为算术也失败，因为那对爱尔兰的数字指向相反的方向。一个地方的真相仍然不会是那个国家的故事。
:::
:::
