普查数字显示了什么？“英国居先”又主张了什么？

普查是为国家所做的清点：在国家选定的时刻，清点调查员按指示登记的那些人。普查结果可以印行、修订与比较，但单凭自身，它说不出谁过得好，也说不出哪一个经济必须率先增长。1801年的英国普查为英格兰与威尔士留下了两个官方数字，而不是一个。关于工业的经典论断则属于另一类陈述：英国棉纺、煤炭与钢铁业的机械化增长，按欧洲标准来看起步较早。这一论断可以争论；它不是规律，两个印出的总数也都不能代替它。

本课程所接续的时期始于1815年的安排，即6月9日的维也纳会议最后议定书和6月18日的滑铁卢战役。这些日期结束了一场战争，却没有开动任何机器。本章解读确曾印行的数字，拒绝未曾印行的数字。

## 同一年的两种印本

:::definition 清点 {#def-enumeration}
**清点**是按照明确的规则、在明确的时刻，对在场者进行的计数。1801年12月21日奉命付印的《普查摘要》（Enumeration Abstract）就是对英格兰、威尔士与苏格兰的这样一次计数。它不是后世史家的估计，也不是对收入、健康或选举权的测量。
:::

本课要用到摘要印出的三行数字：英格兰8,331,434，威尔士541,546，苏格兰1,599,068。前两行相加，英格兰与威尔士合计8,872,980。苏格兰单列一行。我们不把它并入下文的英格兰与威尔士数列，也不把三行数字当作全不列颠经修订的单一总数。爱尔兰根本不在这份摘要中；它属于另一张表，在本章稍后出现。

:::definition 后来的数列 {#def-series}
**后来的数列**指1901年普查报告在作百年比较时所用的英格兰与威尔士历次总数，1911年的回溯表也载有这一数列。在该数列中，1801年英格兰与威尔士的人口为8,892,536。这个数字是官方数字；它既不是摘要两行之和，也不代表另一个国家。
:::

:::theorem 这一差距是修订，不是另一份人口 {#thm-gap}
后来的数列比摘要中英格兰与威尔士之和多出19,556。这一差距是对印出总数的修订。两个数字中任何一个单独拿出来，都不是舍弃另一个之后的真实人口。
:::
:::proof
算术由两种印本确定。摘要中英格兰8,331,434，加上威尔士541,546，得8,872,980。后来的数列对同样两个国家、同一年份印出8,892,536。两数相减得19,556。本图谱的年表把这一差额称为修订，而不是两个不同的国家。能够推翻这一解读的证据，须表明8,892,536所描述的领土、日期或人员类别与摘要中的英格兰与威尔士不同，而1901年的报告默不作声地比较了这些不可比之物。这里所用的记录中没有这样的断裂。至于把任何一种印本单独当作人口，反驳它的恰恰是另一种印本的存在。两者都保存了下来。
:::

:::example 英格兰与威尔士相加 {#ex-sum}
摘要给出英格兰8,331,434、威尔士541,546。请把两者相加。（如果你要用这一结果核对后面的习题，请输入不带逗号的和。）
:::solution
把541,546拆成500,000、41,000与546。8,331,434加500,000得8,831,434，再加41,000得8,872,434，再加546得8,872,980。这就是摘要中英格兰与威尔士之和。它不是后来的数列，也不包括苏格兰的1,599,068。
:::
:::

:::example 19,556的差距 {#ex-gap}
就1801年而言，用后来的数列减去摘要中英格兰与威尔士之和。
:::solution
后来的数列为8,892,536，摘要之和为8,872,980。差额为8,892,536减8,872,980，即19,556。较晚的印本数字较大。关于这次修订，本图谱要说的仅此而已。我们不把19,556拆分为漏计的教区、士兵或水手。这里没有给出这些组成部分，编造的拆分只会是虚假的精确。
:::
:::

:::quiz
关于1801年英格兰与威尔士的两个数字，本课要捍卫的是哪一种说法？
- [ ] 8,872,980是真实人口，8,892,536是应当忽略的错误
- [ ] 8,892,536是真实人口，摘要可以弃置
- [x] 两个数字因一次19,556的修订而不同，舍弃其中一个、以另一个为真实人口都不成立
- [ ] 19,556的差距是从爱尔兰迁来的人数
:::solution
摘要之和与后来的数列都是英格兰与威尔士的官方印本。两者相差19,556，这里解读为修订，既不是另一个国家，也不是爱尔兰的总数。爱尔兰的数字属于另一项比较，即1841年与1851年之间的比较。
:::
:::

想为图表取一个数字的读者仍须作出选择。本课的图形在1801年选用了后来的数列，图注也说明了这一点。选定一个数据点并不等于删除摘要。本章凡说“8,892,536”，指的都是后来的数列；凡说“8,872,980”，指的都是1801年12月21日摘要中英格兰与威尔士之和。

## 后来的数据点填补不了什么

同一数列印出1851年英格兰与威尔士为17,927,609，1901年为32,527,843。1901年的总数清点的是1901年3月31日午夜时在世的人。这个钟点很要紧：当天凌晨稍后出生的孩子不在总数之内，午夜之前去世的人也不在其中。这条规则关乎是否在场，而不关乎生命的价值。

年份标签1801、1851与1901两两相隔五十年：1851减1801为50，1901减1851也是50。从年份标签1801到1901为100年。1901年3月31日午夜并不是1801年12月21日的周年日，因此，不能借这些时刻之间的跨度为中间的日子编造人口。三个数据点就是三个总数，而不是1830年的普查，也不是图线恰好经过的任何年份的普查。

:::example 差额不是人口流动 {#ex-diff}
使用后来的数列，用1851年的总数减去1801年英格兰与威尔士的总数，再用1901年的总数减去1851年的总数。说明每一个差额不是什么。
:::solution
17,927,609减8,892,536为9,035,073；32,527,843减17,927,609为14,600,234。每个结果都只是一个印出的总数超过较早总数的部分，而不是出生人数、移民人数或工业所增添人口的计数。1851年的人口并不是1801年的人口外加一批新人。把任何一个超出部分称为一份人口，就是编造报告中并不存在的普查。
:::
:::

:::widget series
points: 1801,8892536; 1851,17927609; 1901,32527843
ylabel: 英格兰与威尔士的人数
caption: 移动年份。三个数据点是本课中经清点或经修订的总数。点与点之间的连线并不代表其所经年份的人口。1801年的数据点是后来数列的8,892,536，而不是摘要中的8,872,980。
:::

摘要中苏格兰那一行的1,599,068不是第四个数据点，爱尔兰也不在图上。英格兰与威尔士的上升曲线，与同一国家内部别处的下降曲线，可以并存。这就是下一节的内容。

## 爱尔兰的数字不是死亡名册

1901年报告所用的比较表给出爱尔兰1841年为8,175,124，1851年为6,552,385。清点总数下降了。下降的幅度属于这张表的算术；下降的含义，却不是写在数字下面的某个单一原因。

:::theorem 爱尔兰的人口下降不是饥荒死亡人数 {#thm-ireland}
1841年至1851年间，爱尔兰清点所得的人口减少了1,622,739。这个整数混合了死亡、移出与出生减少，不是饥荒死亡人数，本课也不会给出死亡总数。
:::
:::proof
8,175,124减6,552,385为1,622,739。年表说明，这一差额混合了死亡、移出与出生减少，并禁止把这个整数读作饥荒死亡人数。死亡总数是另一种统计。这里没有印出任何死亡总数，因此也不提供。能够推翻这一论断的，须是本图谱所采信的、将这三个过程分开并表明全部差额都是死亡的史料。这样的拆分并不存在。清点人数的下降也会因人们离开、孩子未出生而变化，正因如此，不能仅凭数字的形态给这个整数换个名目。
:::

下降前后的年份是普查年份，而不是马铃薯枯萎病的叙事。本图谱没有锁定马铃薯歉收开始的年份，所以本课也不编造一个。它锁定的是这两次清点，以及禁止为两者之差改换名目的规定。1846年废除《谷物法》，是关于谷物与贸易的英国史实，既不是爱尔兰普查，也不是死亡名册。“废除谷物法解释了1,622,739”这种说法需要本章所没有的证据，而且即便有了证据，也不能把这个整数变成死亡人数。

:::example 计算爱尔兰的人口下降 {#ex-ireland}
验算爱尔兰两个总数的减法，并说出这一差额可以混合的三个过程。
:::solution
8,175,124减6,552,385。先算6,552,385加1,600,000得8,152,385，距8,175,124还差22,739。所以差额是1,600,000加22,739，即1,622,739。反向验算：6,552,385加1,622,739得8,175,124。这一差额混合了死亡、移出与出生减少，并没有给出死亡人数。
:::
:::

把爱尔兰的这对数字与英格兰与威尔士的数列并置，尺度一变，结论也随之改变。1801年至1851年间，后来的数列从8,892,536升至17,927,609；1841年至1851年间，爱尔兰的清点人数却在下降。一张表上真实的上升与另一张表上真实的下降，可以同属一个国家，却未必同一命运。这正是[[sources/scale]]的纪律：一个尺度上的事实，不能当作在另一个尺度上下断语的许可。

:::quiz
数字1,622,739是下列哪一项？
- [ ] 爱尔兰的饥荒死亡人数
- [ ] 1801年英格兰与威尔士两种印本之间的差距
- [x] 爱尔兰清点人数从1841年到1851年的下降，混合了死亡、移出与出生减少
- [ ] 《普查摘要》中苏格兰那一行
:::solution
摘要中苏格兰那一行是1,599,068，1801年的差距是19,556。爱尔兰的人口下降是8,175,124减6,552,385，即1,622,739，本图谱拒绝把这一差额称为死亡人数。
:::
:::

## 专利、铁路与法令

人口总数是一类档案，机械与法律是另一类。两者在经典论断中交汇，但并不会自动交汇。

1769年，瓦特（Watt）取得分离式冷凝器的专利。这项专利是一项法律事实，涉及一种比在工作汽缸内冷凝蒸汽的机器更有效利用蒸汽的机器。它不是工厂普查，也没有说明造出了多少台机器。从1769年到斯托克顿—达灵顿铁路通车，是1825减1769，即56年。这段跨度起点的专利与终点的铁路，是两件有确切日期的人工制品；两者之间的年份并不是一条马力曲线。

:::example 两次通车，按年份标签相隔五年 {#ex-span}
斯托克顿—达灵顿铁路于1825年9月27日通车，利物浦—曼彻斯特铁路于1830年9月15日通车。两个年份标签相隔几年？为什么两个通车日之间的跨度不足这么长？
:::solution
年份标签相差1830减1825，即5年。两个通车日之间不足五个整年，因为9月15日早于9月27日。本课使用这一年份跨度，但不把它换算成旅客人数。两次通车都不是人口。利物浦—曼彻斯特铁路常被视为迈向城际运输的更明确的转折，斯托克顿—达灵顿铁路的日期则仍在其前。
:::
:::

英国的工厂法颁行于1833年。它管制工厂劳动，尤其是纺织厂中的童工，并设立了监察制度。本课不提供年龄或工时的数字，因为这些数量不在锁定的年表之内。一项法令表明，公共权力已开始把工厂视为可以管制的场所；它并不表明规则得到了遵守，也不表明普查数字因这项法令而上升。从1830年利物浦—曼彻斯特铁路通车到这项法令，按年份标签相隔三年。铁路与法令可以都是真实的，而无须一方导致另一方。

1832年的改革法案属于同一代国家活动，已在[[revolutions/restoration-and-1848]]中讲授。它所扩大的选举权仍然狭窄。1801年、1851年与1901年清点的人，并不是有权投票的人。普查人数增长与选举权依旧狭窄可以并存。把两者混为一谈，人口总数就会被误读为民主的事实。这一误读留待[[nations/mass-politics]]处理。在此只需把两类档案分开：午夜在场并不等于一张选票。

## 英国居先的论断

:::definition 经典论断 {#def-classic}
在本图谱所用的经典论断中，**工业化**指十八世纪末至十九世纪初英国棉纺、煤炭与钢铁业的机械化增长，按欧洲标准起步较早。它并不是说每个工人都站在机器旁，不是说其他地区没有机械化，也不是说英国必然领先。
:::

:::theorem “英国居先”不是规律 {#thm-not-law}
经典论断是一种比较，须接受有关时机、完成程度、煤炭、工资、奴隶制与帝国的证据的检验。它并不是说英国必然率先工业化的规律；普查数字的上升本身也不能证明这一论断。
:::
:::proof
如果别处在同样的衡量标准下出现了更晚而规模更大的棉纺、煤炭与钢铁业机械化，就能推翻“较早”之说。如果有证据表明作坊、农场与家庭生产吞没了这些部门，而不是与之并存，就能推翻任何听来像是彻底转变的措辞。清点人数的上升挽救不了这种措辞：英格兰与威尔士的人口可以从8,892,536增至17,927,609，再增至32,527,843，与此同时爱尔兰人口在下降，许多工人也仍在工厂之外。史家们就这些条件争论不休，而这场争论本身就是这一论断的组成部分。能够推翻整个比较的，是证明这些部门的变化按主张者所提出的任何衡量标准都不算早。在做到这一点之前，这一陈述作为一个有竞争对手的论断成立。
:::

这些竞争的解释必须分开处理，否则争论就会沦为口号。

史家们在拒绝只由发明家构成的叙事时，首先诉诸的条件是煤炭。瓦特1769年的专利属于这段历史：热能与机械功取自煤炭，而不再仅仅取自木材与人畜之力。概括地说——这只是概括——转向煤炭解除了一项限制。支持这一点的证据，是早期工厂与锻造厂对煤炭的依赖，而同期的其他生产者并无这种依赖；反驳这一点的证据，则是一条不依赖这种燃料的早期机械化道路。地下的煤炭尚不构成经济，专利是社会事实，而不是矿物。

工资是第二个条件，它很容易被误认为圆满的结局。有一种论证说，英国的劳动力相对于能源较为昂贵，因此使用机器合算。这是关于雇主激励的论断，而不是说清点能够衡量生活舒适程度，也不是说1833年的工厂法多此一举。能够反驳它的，是机器首先在低工资地区推广的证据。本图谱不提供任何工资数列，也不会编造一个。

奴隶制与帝国分成两个不可混为一谈的论断。根据“奴隶航程”数据库（Slave Voyages）1501年至1866年的登船地区表，大西洋贸易的登船人数估计为12,521,354人。这是该项目的估计，不是当时的人头清点，也不是世界上所有奴隶贸易的总数。下船人数少于登船人数，因为有人死于航程之中。本课不给出横渡途中的死亡总数、各国所占份额或利润总额。英国1807年的法令针对的是奴隶贸易，而不是奴隶制。1833年的法令在大英帝国大部分地区废除了奴隶制，学徒制则延续到1838年。这两个日期都没有终结帝国，也都没有切断英国管辖范围之外由被奴役者种植的纤维的供应。这种供应就是纤维论断：兰开夏的棉纺业依赖奴隶种植的纤维。这一论断在两项法令之后依然可以成立，因为这些法令并不管辖每一个种植棉花的种植园。

第二个与奴隶制有关的论断关乎金融：奴隶贸易与奴隶殖民地的利润为机械化提供了资金。史家们对此意见不一。有人把这些利润视为早期工厂的条件之一；另一些人则认为，国内需求、煤炭与工资的作用更大。本图谱没有公认的百分比可以引用，也不会编造一个。支持金融论断的，会是一笔大到足以改变时机的资金流；反驳它的，会是这样一种融资叙事：工厂依靠国内资金建成，而纤维论断依然成立。你可以接受一个论断而暂不判断另一个。作为征服的帝国将在[[nations/empires]]中再次出现，奴隶贸易本身见[[states/atlantic]]。1804年1月1日海地独立，以及法国废除又恢复殖民地奴隶制，属于[[revolutions/napoleon]]，也与1848年法国第二次废除奴隶制相关。它们不是英格兰与威尔士图表上的一条线。

完成程度是措辞内部的限度。在1825年与1833年之后很久，许多劳动仍是农业的、家庭的，或是小作坊里的熟练手艺。比利时和德意志诸邦的一些地区也实现了机械化。本课不为这些道路定年，因为年表没有为它们锁定年份。“居先”是对时机与规模的比较，史家们争论英国的情形究竟有多早、有多彻底。一项比较可以在棉纺机械上胜出，却在劳动力占比上落败。在说明衡量标准之前，“英国居先”就是[[sources/argument]]所警示的那类标签。

普查无法在这些竞争的解释之间作出裁决。1901年的总数大于1801年，这一事实与煤炭起了作用相容，与煤炭的作用不够大相容，与奴隶种植的棉花供给了工厂相容，也与奴隶贸易的利润并未为工厂提供资金相容。从32,527,843推出一条规律，就是偷换了话题。

## 完整案例

设想一句地方编年史或许乐于写下的话。下面这句话为示例而虚构。它不是史料。“1830年9月15日，英格兰每一座城镇的人口都翻了一番，因为利物浦—曼彻斯特铁路通车了，而1801年奉命进行的普查早已证明工业是一条规律。”

:::example 解读虚构的句子 {#ex-invented}
上一段中的句子是虚构的。请把它借用的有日期的事实与它添加的论断区分开来，并说明要把任何添加的论断提升为证据需要什么。
:::solution
有两处借用是真实的：1830年9月15日利物浦—曼彻斯特铁路通车，以及1801年12月21日奉命付印的摘要。“英格兰每一座城镇的人口都翻了一番”既不见于摘要，也不见于后来的数列，与通车更无关系。摘要中英格兰的数字是8,331,434，而不是一份人口翻番的城镇清单。“证明工业是一条规律”通不过[[#thm-not-law]]的检验：经典论断是一种比较，而普查并不是这种比较。要证实人口翻番，需要若干具名城镇的清点数字、一条计数规则，以及把这一变化与铁路联系起来的理由；要证实那条规律，需要[[#def-classic]]中的衡量标准，以及一项有可能失败的检验。这句虚构的话两者都没有提供。
:::
:::

:::warning 唯一的真实人口，以及死亡名册
有三种习惯会造成本章所要防止的损害。第一种是在8,872,980与8,892,536中任选其一，称之为1801年的真实人口；19,556的差距正说明这行不通。第二种是把1,622,739读作饥荒死亡人数；这次下降混合了死亡、移出与出生减少，这里也没有给出死亡总数。第三种是把经典论断当作英国必然领先的规律，并把普查数字的上升当作证明。
:::

:::history
《普查摘要》于1801年12月21日奉命付印。它给出英格兰8,331,434、威尔士541,546，两者之和为8,872,980。后来的官方数列，即1901年报告作百年比较时所用的数列，给出英格兰与威尔士8,892,536。两个数字都是这一数字的历史的组成部分。
:::

这些记录各自承载一类事实：某条规则下的总数、一项专利、一个通车日、一项法令，或一项仍有竞争解释的比较。凡是需要死亡总数、利润份额或数据点之间某一年人口的陈述，本章都不会认可。英格兰与威尔士的普查也不能决定爱尔兰是否是一个民族。就1841年至1851年而言，它只能确定爱尔兰的总数如实发生了变化。

## 通向何处

[[sources/evidence]]与[[sources/scale]]是这些算术背后的方法：史料不等于推论，在一个尺度上为真的总数，放到全国层面可能成为错误的陈述。[[states/atlantic]]载有这里所用的登船估计，[[revolutions/napoleon]]与[[revolutions/restoration-and-1848]]载有革命时期的日期、范围狭窄的1832年改革法案以及1848年。普查之后建成与遭到拒绝的民族国家，见[[nations/unifications]]。这些总数并未描述的选举权，见[[nations/mass-politics]]。作为征服的帝国——而不是作为经典论断之下争论的条件——见[[nations/empires]]。

:::summary
- 1801年12月21日奉命付印的《普查摘要》给出英格兰8,331,434、威尔士541,546、苏格兰1,599,068。英格兰与威尔士合计8,872,980。
- 1901年报告所用的后来的数列，给出1801年英格兰与威尔士8,892,536。19,556的差距是修订，不是另一个国家；两种印本都不能单独代表人口。
- 英格兰与威尔士1851年为17,927,609，1901年3月31日午夜为32,527,843。数据点之间的连线不是其所经年份的普查，总数之差也不是人口流动。
- 爱尔兰1841年为8,175,124，1851年为6,552,385。1,622,739的下降混合了死亡、移出与出生减少，不是饥荒死亡人数。
- 瓦特的专利在1769年。斯托克顿—达灵顿铁路于1825年9月27日通车，利物浦—曼彻斯特铁路于1830年9月15日通车。工厂法在1833年。这些都不是人口。
- 经典论断是棉纺、煤炭与钢铁业较早的机械化增长。史家们就时机、完成程度、煤炭、工资、奴隶制与帝国展开争论。它不是英国必然领先的规律，纤维论断也不同于金融论断。
:::

## 习题

:::exercise 摘要之和 {level=1 check="8872980"}
把摘要中英格兰与威尔士的两个数字8,331,434与541,546相加。（请输入数字，不带逗号。）
:::solution
8,331,434加541,546得8,872,980。一种算法：先加500,000得8,831,434，再加41,000得8,872,434，再加546得8,872,980。
:::
:::

:::exercise 修订 {level=1 check="19556"}
1801年英格兰与威尔士的后来数列比摘要之和多出多少人？（请输入数字，不带逗号。）
:::solution
8,892,536减8,872,980得19,556。这一超出部分是对印出总数的修订，既不是另一个国家，也不是爱尔兰的数字。
:::
:::

:::exercise 苏格兰那一行 {level=1 check="1599068"}
《普查摘要》为苏格兰印出的数字是多少？（请输入数字，不带逗号。）
:::solution
苏格兰印为1,599,068。这一行不是本课图形上的数据点。数据点只涉及英格兰与威尔士，1801年的数据点是后来数列的8,892,536，而不是包括苏格兰在内的和。
:::
:::

:::exercise 对同一次上升的两种描述 {level=2}
后来的数列从1801年的8,892,536升至1851年的17,927,609。一名学生既说“总数增加了9,035,073”，又说“工业增添了9,035,073人”。请接受其中一句，拒绝另一句。
:::solution
接受第一句。17,927,609减8,892,536得9,035,073，这是一个印出的总数超过另一个的部分。拒绝第二句。这一超出部分并不是工业、移民或出生所增添人口的计数。两次清点追踪的并不是同一批个人，关于机械化增长的经典论断与这道减法也不构成算术恒等式。爱尔兰在同一时段的部分年份中人口下降，进一步说明不能把一个超出部分变成全国性的规律。
:::
:::

:::exercise 铁路与法令 {level=2}
斯托克顿—达灵顿铁路于1825年9月27日通车，利物浦—曼彻斯特铁路于1830年9月15日通车，工厂法定年为1833年。这三个日期合在一起能显示什么？又不能显示哪种因果关系？
:::solution
它们合在一起显示了两次运输线路的开通，以及一项管制工厂劳动（包括纺织厂童工）并设有监察的法令。年份标签从1825到1830相差5年，1833年在1830年之后三年。它们并不表明铁路导致了这项法令，不表明任何一次通车导致普查数字上升，也不表明可以从这份年表中引用年龄与工时。瓦特1769年的专利是更早的法律事实，按年份标签比1825年早56年，而不是从这项法令倒推出来的原因。
:::
:::

:::exercise 陈述经典论断及其限度 {level=2}
用两三句话陈述关于英国工业化的经典论断，以及使它不能成为规律的一项限度。不要用人口数字作为证明。
:::solution
经典论断是：十八世纪末至十九世纪初英国棉纺、煤炭与钢铁业的机械化增长，按欧洲标准起步较早。其限度在于：史家们争论它究竟有多早、有多彻底，煤炭、工资、奴隶制与帝国在多大程度上构成条件，而且其他地区也实现了机械化。规律会说英国必然领先，这一论断并没有这样说。普查总数弥补不了这一缺口：[[#thm-not-law]]把比较与清点放在不同的陈述之中。
:::
:::

:::exercise 纤维与金融 {level=3}
请把“英国棉纺业使用了奴隶种植的纤维”这一论断，与“奴隶贸易的利润为工厂提供了资金”这一论断区分开来。1807年或1833年的哪一项事实可以支持其中一个论断，而让另一个悬而未决？什么能够反驳金融论断而不触及纤维论断？
:::hint
1807年的法令与1833年的法令改变了英国的法律。想一想它们不管辖哪一类生产，又不衡量哪一种资金流。
:::
:::solution
纤维论断关乎供应：在英国纺制的棉花由被奴役的劳动力种植，其中包括英国法令并未解放的劳动力。金融论断关乎资本：奴隶贸易与奴隶殖民地的利润为工厂提供了资金。1807年的法令禁止英国的奴隶贸易，但没有废除奴隶制；1833年的法令在大英帝国大部分地区废除了奴隶制，学徒制延续到1838年。两者都可以让纤维论断继续成立；两者都不衡量利润，因此都不能证明金融论断。工厂依靠国内资金建成的证据，可以反驳金融论断，而不触及纤维论断。本图谱在两个方向上都不给出百分比。史家们意见不一，这一分歧本身就应写进答案。
:::
:::

:::exercise 一个教区与一个王国 {level=3}
下面这句话为示例而虚构。它不是史料。“诺斯福德的教区登记簿在铁路测量员到访到下一次收获之间翻了一番，所以英格兰与威尔士翻了一番，爱尔兰也必定翻了一番。”请仅使用锁定的总数，解释其中的两个尺度错误。
:::hint
比较1841年至1851年爱尔兰总数的变化方向，与1801年至1851年英格兰与威尔士数列的变化方向。再想一想教区登记簿不是什么。
:::
:::solution
第一个错误把一个虚构的教区上升为英格兰与威尔士。登记簿不是普查，一个教区也不是8,892,536或17,927,609。后来的数列在这些年份之间确实上升了9,035,073，但这一事实并非从诺斯福德推导而来。第二个错误把英格兰与威尔士的变化方向硬套到爱尔兰身上。爱尔兰从1841年的8,175,124降至1851年的6,552,385，减少了1,622,739，而不是翻了一番。这句话作为证据不成立，因为它是虚构的；作为算术也不成立，因为爱尔兰的两个数字指向相反的方向。即便是真实的地方情况，也不会就是国家的历史。
:::
:::
