1914年7月还剩下哪些选择？

1914年6月28日，弗朗茨·斐迪南（Franz Ferdinand）在萨拉热窝遇刺。7月28日，奥匈对塞尔维亚宣战。8月1日德国对俄国宣战，8月3日对法国宣战。8月4日，德国入侵比利时，英国对德国宣战。这些都是标有日期的选择。1879年、1894年、1904年与1907年的各项盟约，并不是一台替各国政府作出选择的机器。与施里芬（Schlieffen）之名相连、又经毛奇（Moltke）修订的德国动员计划，约束了一份时间表；但约束并不等于没有选择。一个常被重复的论断是：1879年之后，或者在后来被称为“空白支票”的支持承诺之后，战争就不可避免了。这个论断是某些人的论证，日期对它作出了回答。本课不叙述随后到来的那场战争，它见[[wars/first-world-war]]。

7月28日宣战的二元君主国，就是折衷方案（Ausgleich）所造就的奥匈帝国，见[[nations/unifications]]。一个王朝与一个匈牙利王国一同走向战争，它们并不是一个醒来奔赴宿命的民族。

## 四项协定，不是一台机器

:::definition 同盟与协约 {#def-alliance}
这里的**同盟**，指具名国家之间有日期的协定，解读它是为了看清它约束什么、不约束什么。**协约**（entente）也是有日期的协定，但它与德奥同盟并不是同一种文书。两个词都不意味着一台能够自行宣战的机器。意大利在1914年是欧洲大国，却不是下图所示任何一项协定的一端。
:::

1879年的德奥同盟把德国与奥匈联结在一起。它不联结英国，也没有把意大利放在这条边上。法俄同盟缔结于1894年；这一年也是德雷福斯被捕之年，而[[nations/mass-politics]]把那件事作为另一事件看待：一桩法国的案件不是一项军事协定。英法协约（Entente Cordiale）于1904年4月8日在法国与英国之间缔结，它解决了悬而未决的殖民地争端，但本身并不是承诺在后来某年的8月4日参战。英俄协约在1907年，是又一项协定，而不是把英国与俄国融合成一个矛头指向柏林的单一意志。四个日期，四份文书，其中三条边涉及英国、法国或俄国，一条边联结德国与奥匈。把它们算作两大集团，本身就已是一种解读。这种解读必须经得起一个事实的检验：这些文书彼此并不相同。

:::theorem 各项协定并没有取消选择 {#thm-agreements}
1879年的德奥同盟、1894年的法俄同盟、1904年4月8日的英法协约与1907年的英俄协约，并不是一台机器。它们提高了某些选择的代价，却没有使战争在1879年之后变得不可避免，也不能代替1914年的各次宣战。
:::
:::proof
四份文书的当事方与年份各不相同。意大利不在本课所画的任何一条边上，也不在7月28日至8月4日这一系列宣战的国家之列。如果这些协定是一台机器，它在每一次危机中都应呈现同样的形态，而事实并非如此。1908年的波斯尼亚吞并危机没有演变成全欧战争，1912年与1913年的巴尔干战争也没有。能够推翻这一论断的，是这样的证据：1879年之后，任何政府都不可能采取与1914年不同的做法，因为1879年、1894年、1904年与1907年的文本早已穷尽了一切替代方案。那几次平息下来的危机否定了这种证据。一项解决殖民地争端的协约与德奥之间的同盟之间的差别，同样否定了它。代价是真实的，但代价不等于不可能。“不可避免”一词属于本段所拒绝的那个论断，而不属于年表。
:::

## 半途而止的危机

1908年，奥匈吞并了波斯尼亚和黑塞哥维那。1878年的柏林大会——与那次关于非洲的柏林会议不是同一次会议——曾把这些土地交由奥匈占领。吞并是地位的改变，也是一场危机：塞尔维亚与俄国表示反对。但它不是1914年7月28日，全欧战争并没有爆发。德奥同盟可以在一场巴尔干争端中发挥作用，而其他国家政府仍停留在本章所列的各次宣战之外。如果真有那台机器，它是不会容许这种情况的。

1912年与1913年的巴尔干战争发生在奥斯曼帝国的欧洲领土上，先是巴尔干诸国与奥斯曼帝国交战，随后又围绕战后安排而战。本课不叙述这些战役，也不给出伤亡总数，只使用年表给出的时间范围。一场巴尔干战争，即使规模很大，也还不是1914年的欧洲战争。如果把1908年与1912年至1913年都算上，东南欧的危机已有两次没能演变为7月末8月初的那一系列事件。这种“没能”本身就是证据。它并不使1914年成为不可能，而是使1914年成为又一组决定——在此前的危机都被平安度过的情况下作出的决定。

:::example 两场不是8月的危机 {#ex-crises}
把1908年的波斯尼亚吞并危机与1912年至1913年的巴尔干战争放在一起。关于1879年的德奥同盟，它们显示了什么？关于1914年，它们又没有显示什么？
:::solution
两者都是1879年之后的巴尔干危机，都没有演变为全欧战争。它们否定了这样一种论断：德奥同盟早已使这样一场战争成为唯一可行的行为。它们既没有表明1914年是不可能的，也没有表明7月28日、8月1日、8月3日与8月4日的决定与1908年是同一个决定。巴尔干战争的伤亡总数不属于答案。1908年被吞并的那片占领地，源于1878年的柏林大会，[[nations/empires]]已把它与关于非洲的柏林会议区分开来。
:::
:::

奥匈与俄国在巴尔干的对抗在多大程度上束缚了后来的选择，史家们意见不一。这一分歧是正文的组成部分，而不是可以跳过的脚注。对抗是一种条件；所谓条件，就是本来可以不同的东西，而这正是[[sources/argument]]为原因设定的检验标准。俄国可以在1908年表示反对，而不与奥匈开战；巴尔干国家可以在1912年与1913年交战，而各大国仍停留在8月的宣战之外。对抗解释了这一地区为何危险，却没有选定那一天。

## 时间表不是命运

:::definition 动员计划 {#def-plan}
**动员计划**是按照预先拟定的时间表征召预备役、调动军队的参谋方案。与施里芬之名相连、又经毛奇修订的德国计划，把两线作战的首要重心放在西线，因而也就放在穿越比利时的行动上。这一计划约束着下令执行它的政府，但它不是地理规律，也不能证明不可能写出别的命令。
:::

:::theorem 约束不等于没有选择 {#thm-choice}
德国的动员计划一旦成为现行计划，就约束了一份时间表。但无论在1914年7月还是更早，它都没有取消选择。各次宣战与那次入侵仍是各国政府有日期的行为。克里斯托弗·克拉克（Christopher Clark）的《梦游者》（Sleepwalkers）是对这些行为的一种解读，而不是判决。
:::
:::proof
这一计划是一份时间表：铁路、预备役，以及若按计划的条件进行两线作战，就须穿越比利时向西推进。一旦某国政府下令按此动员，随后的每一个小时都被压缩。这种压力就是约束。它是参谋军官与大臣们造成的，毛奇也修订过它，所以它不是自然。修订本身就证明这一方案本可以不同——它确实曾经不同。能够推翻这一约束的，是这样的证据：在最后几天里，柏林本可以局部动员、停止动员或只面向东方，而且政府既这样认为，也这样做了。这些替代方案在多大程度上真正可行，史家们意见不一，这一分歧在此保持开放。能够反驳“别无选择”的，是一份清单：在任何支持承诺之后仍须付诸实施的那些行为——7月23日的最后通牒，7月28日对塞尔维亚宣战，8月1日对俄国宣战，8月3日对法国宣战，入侵比利时，以及8月4日英国宣战。奥匈对塞尔维亚的战争本身，并没有把德国军队送进比利时；那次调动是有人下令的。克拉克的著作把这场危机解读为一连串局部可以理解、合起来却酿成灾难的步骤。“梦游者”是他的意象，而不是一项“无人清醒”的发现。另一些史家则认为，德国领导人利用这场危机谋求一场他们想要的战争。那是关于目标的论断。目标可以是真实的，却仍然留下某一天，那一天本可以下达不同的命令。本课的论断比两部著作都更窄：在那些锁定的日期上，选择依然存在。
:::

柏林对维也纳的支持承诺，常被称为“空白支票”，发生在7月，早于7月23日的最后通牒。本图谱没有为这一承诺锁定日期，因此不编造日期，也不提供承诺的任何文本。一张支票，哪怕是空白支票，也只是一国政府给出的担保，还不是宣战。主张“担保一经给出，选择便告终结”的论断，必须解释此后的种种行为。这些行为各有日期，并不是那项担保的自我重复。

最后通牒在7月23日。本课不编造其文本。它是向塞尔维亚提出的、附有短促期限的要求。期限有几个小时没有锁定，因此不予说明。各国政府随后就塞尔维亚的答复是否足够发生分歧。宣战在7月28日接踵而至。从23日到28日，日历上的五天足以容纳一次判断，而判断就是选择。你没有看到条款原文，也无须看到，就能明白宣战是又一个行为。

:::example 二十五天，然后五天 {#ex-span}
弗朗茨·斐迪南于1914年6月28日遇刺，最后通牒在7月23日，对塞尔维亚宣战在7月28日。遇刺与最后通牒之间相隔多少天？最后通牒与宣战之间又相隔多少天？
:::solution
从6月28日到7月23日为25天。7月23日比7月28日早五天，因为28减23得5。这25天是一段政治间隔：谋杀已经发生，欧洲战争尚未宣布。这五天是又一段间隔，处在一项本课不编造其文本的要求之后。两段间隔都不空洞到可以称为“自动”。本课有意不为空白支票标注日期，它落在7月之内、最后通牒之前，既没有吞没那25天，也没有吞没那五天。
:::
:::

## 完整案例：四个日期

请把这个案例当作一份清单来读，而不是当作一张幻灯片。

6月28日，哈布斯堡皇储在萨拉热窝遇害。本课不描述凶器，也不编造演说。刺杀皇储是一个政治事实，但在那一天，它既不是奥匈与塞尔维亚之间的战争，也不是德国与俄国之间的战争。凡是把战争的开端定在6月28日的人，都跳过了作出种种选择的那一个月。

7月23日，最后通牒送达。7月28日，奥匈对塞尔维亚宣战。这个二元君主国选择把刺杀事件当作开战的理由，也选定了日期。此时俄国尚未被宣战，德国也还没有入侵比利时。1908年与1912年至1913年的巴尔干先例表明，这一地区的争端可以始终只是争端。作出别的选择是可以理解的，但它仍然是一种选择。

8月1日，德国对俄国宣战；8月3日，德国对法国宣战。从7月28日到8月1日是四天，从8月1日到8月3日是两天。每一次宣战都多卷入一个国家。动员计划使向西推进成为参谋部为两线作战所选定的首选顺序。首选的、预先拟定的、经过修订的，并不等于不可能是别的样子。柏林还剩下多少回旋余地，史家们意见不一。本课既不以宣布计划就是命运来终结他们的分歧，也不以宣布计划只是毫无约束力的借口来终结它。约束力就是那种约束，宣战就是那些选择。

8月4日，德国入侵比利时，英国对德国宣战。一天之内有两个行为。如果计划被贯彻到比利时，入侵就是修订后的计划向西推进所要求的。英国的宣战则是伦敦作出的决定，与比利时和两项协约相关，而不是1879年写下的某项条款。英法协约不会宣战，宣战的是内阁。从8月3日到8月4日只有一天，但一天已足以把入侵与宣战区分开来，而这正是年表所要求的全部。

:::example 从萨拉热窝到英国宣战 {#ex-thirty-seven}
1914年6月28日与1914年8月4日之间相隔多少天？请把25、5、4、2与1这几步相加来验算。
:::solution
从6月28日到8月4日为37天。各步首尾相接：6月28日到7月23日25天，7月23日到7月28日5天，7月28日到8月1日4天，8月1日到8月3日2天，8月3日到8月4日1天。25加5得30，加4得34，加2得36，加1得37。这是三十七天的政治时间，而不是一次引爆。这个总和中不包含死亡总数，不包含最后通牒的文本，也不包含任何一步是唯一可能步骤的主张。
:::
:::

:::example 编造的机器 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1879年德奥同盟一经签订，空白支票一经发出，此后的每一个行为都是唯一剩下的行为，所以7月28日与8月4日是同一个决定。”这句话抹掉了什么？
:::solution
它抹掉了1908年与1912年至1913年那几次没有演变为这场战争的危机。它抹掉了空白支票缺失的日期（本图谱不会编造），还把这项担保当作了宣战本身。它抹掉了7月28日、8月1日、8月3日与8月4日之间的区别：先是塞尔维亚，然后是俄国，然后是法国，然后是比利时与英国。它抹掉了毛奇的修订，而这次修订表明，这一计划是有人改动过的计划。[[#thm-agreements]]与[[#thm-choice]]就是回答。克拉克的《梦游者》与“德国领导人谋求战争”的论证，都是对目标与混乱的解读，两者都不允许把这些有日期的行为称为一个行为。这句话是虚构的，仅凭年表就足以将它驳倒。
:::
:::

:::quiz
1914年7月28日奥匈对塞尔维亚宣战，证明了下列哪一项？
- [ ] 德国当时已在入侵比利时
- [ ] 英法协约已经宣战
- [x] 一国政府已选择对塞尔维亚开战，此后仍有标有日期的进一步选择
- [ ] 自1879年德奥同盟以来，战争就已不可避免
:::solution
7月28日是对塞尔维亚宣战。入侵比利时与英国宣战在8月4日。德国对俄国与对法国宣战分别在8月1日与8月3日。协约本身不会宣布任何事。“自1879年以来不可避免”正是[[#thm-agreements]]所拒绝的论断，它把1908年与1912年至1913年作为拒绝理由的一部分。
:::
:::

这一狭窄的论断很容易被一带而过，因此值得撇开叙事再说一遍：7月与8月初，各国政府能够采取年表所列的那些步骤，也本可以不采取其中某些步骤。不采取会有代价，其中包括同盟的代价与时间表的代价。代价是一种理由，却不能证明替代方案不存在。强调德国目标的史家与强调共同失败的史家，争论的是如何分配这些理由。你可以偏向某一种分配，同时仍然拒绝“不可避免”。这一拒绝是本章的立场，它既不是为任何一国首都辩护，也不是对后来任何一场战争的建议。

:::warning 1879年之后不可避免，或支票之后不可避免
这种迷思说，战争早已在等待——或是从1879年的德奥同盟起，或是从1914年7月的空白支票起——日期只是记录了一台机器的启动。这种迷思是一个论断，而且站不住脚。1908年与1912年至1913年的巴尔干战争都没有启动它。最后通牒、从7月28日到8月4日的四个节点、经毛奇修订的计划，都是一台真正的机器无须决定的东西。在克拉克的论证中，《梦游者》是对选择的一种解读，而不是“选择不存在”的判决。参谋部的时间表约束了德国，却没有取消那份清单。
:::

:::history
1914年6月28日，弗朗茨·斐迪南在萨拉热窝遇害。7月28日，奥匈对塞尔维亚宣战。到8月4日，德国已入侵比利时，英国已对德国宣战。在此期间，德国还于8月1日对俄国宣战，于8月3日对法国宣战。这一系列事件是约束之下的一组选择，而不是十九世纪早已定好的约会。
:::

## 通向何处

原因与时间表有何不同，[[sources/argument]]已预告将在本章讨论。宣战的奥匈帝国，就是[[nations/unifications]]中的二元君主国。1878年的柏林大会（不是那次关于非洲的会议）见[[nations/empires]]，规范主张与进行战争之间的区别也在那里。这些政府所面对的公众（当时尚非民主政体）见[[nations/mass-politics]]。本课不叙述的战事本身，见[[wars/first-world-war]]。

:::summary
- 德奥同盟在1879年，法俄同盟在1894年，英法协约在1904年4月8日，英俄协约在1907年。它们不是一台机器。意大利不在任何一条边上。
- 波斯尼亚吞并危机在1908年，巴尔干战争在1912年至1913年。两者都没有演变为全欧战争，都否定了“1879年之后战争不可避免”的说法。
- 弗朗茨·斐迪南于1914年6月28日遇刺。最后通牒在7月23日，本课不编造其文本。奥匈于7月28日对塞尔维亚宣战。
- 德国于8月1日对俄国宣战，8月3日对法国宣战。8月4日，德国入侵比利时，英国对德国宣战。从6月28日到8月4日为37天。
- 被称为“空白支票”的支持承诺在这里没有锁定日期，因此不编造日期。它并没有终结选择。
- 与施里芬之名相连、经毛奇修订的动员计划约束了德国的时间表。还剩下多少回旋余地，史家们意见不一。约束不等于没有选择。克拉克的《梦游者》是一种解读，而不是判决。
:::

## 习题

:::exercise 最后通牒之前的天数 {level=1 check="25"}
1914年6月28日遇刺与1914年7月23日最后通牒之间相隔多少天？（请输入天数。）
:::solution
从6月28日到7月23日为25天。谋杀已经发生，宣战尚未发生。这段间隔是“6月28日还不是战争”这一论证的组成部分。
:::
:::

:::exercise 总天数 {level=1 check="37"}
1914年6月28日与1914年8月4日之间相隔多少天？（请输入天数。）
:::solution
跨度为37天。验算：到7月23日25天，到7月28日再加5天，到8月1日再加4天，到8月3日再加2天，到8月4日再加1天。25加5加4加2加1得37。
:::
:::

:::exercise 德奥同盟的年份 {level=1 check="1879"}
德国与奥匈的德奥同盟缔结于哪一年？（请输入年份。）
:::solution
德奥同盟缔结于1879年。它联结这两个国家，不包括意大利、英国、法国或俄国，也没有宣布1914年的各场战争。
:::
:::

:::exercise 谁不在边上 {level=2}
意大利出现在图上，却没有任何边。请解释这对1914年7月意味着什么，又不意味着什么。
:::solution
这意味着意大利不是图中各条边的当事方，即1879年的德奥同盟、1894年的法俄同盟、1904年4月8日的英法协约与1907年的英俄协约。这并不意味着意大利与欧洲政治无关，也不意味着意大利参与了止于8月4日的那一系列宣战。年表没有锁定更多的条约年份，因此不予添加。这些协定的图不是命运图，图注说的正是这一点。
:::
:::

:::exercise 1908年否定那台机器 {level=2}
1908年的波斯尼亚吞并危机如何否定“德奥同盟之后战争不可避免”的论断？
:::solution
1908年，奥匈吞并了根据1878年柏林大会的安排而占领的波斯尼亚和黑塞哥维那。这次吞并是一场危机，却没有演变成全欧战争。如果1879年之后已别无选择，这样一场巴尔干危机就早该是1914年的那场战争了，而事实并非如此。1912年至1913年的巴尔干战争再次说明了这一点，但它们不是同一事件。答案中使用“不可避免”一词，仅仅是为了称呼被拒绝的那个论断。
:::
:::

:::exercise 计划与入侵 {level=2}
德国的动员计划约束了什么？为什么奥匈7月28日的宣战还不等于8月4日对比利时的入侵？
:::solution
与施里芬之名相连、经毛奇修订的计划，约束的是德国为两线作战进行动员的时间表，这场战争的首要重心在西线，要穿越比利时。这一约束在计划被下令执行时才起作用。7月28日是奥匈对塞尔维亚宣战；比利时则在七天之后的8月4日遭到入侵，那是德国的行为。一个盟国对塞尔维亚的战争，并不是另一个盟国的入侵。毛奇的修订表明这一方案已被改动过一次，所以它不是地理。最后几天还剩多少回旋余地，史家们意见不一。[[#thm-choice]]同时保留了约束与分歧。
:::
:::

:::exercise 目标与混乱 {level=3}
一些史家认为德国领导人谋求战争。克拉克的《梦游者》则描绘了另一幅图景：多国首都相继采取的步骤。本课可以从两者各吸取什么？又仍须拒绝什么？
:::hint
让本课的论断比两部著作都更窄。想一想，真实的目标或真实的混乱，是否能抹去7月23日至8月4日之间那些有日期的行为。
:::
:::solution
从关于目标的论证中，可以吸取这种可能性：德国的政策想要一场战争，并利用了这场危机。这是关于目的的论断，它可以成立，却不会使此后的每一个小时都变成自动的。从克拉克那里，可以吸取这一坚持：多国政府选择了局部可以理解、合起来却酿成灾难的步骤；同时把“梦游者”这一意象当作他的解读，而不是判决。史家们意见不一，这一分歧本身就应写进答案。两种解读都必须保留[[#thm-choice]]：最后通牒、各次宣战与入侵是有日期的行为。两部著作都不允许说战争在1879年之后或在空白支票之后已不可避免。空白支票没有锁定的日期，也没有编造的文本。
:::
:::

:::exercise 一个决定还是五个 {level=3}
下面这句话为示例而虚构。它不是史料。“萨拉热窝、空白支票、最后通牒、对塞尔维亚宣战与入侵比利时是同一个决定，作出于1879年。”这句话抹平了多少个锁定的日期？为什么1879年对它们来说是错误的年份？
:::hint
列出6月28日、7月23日、7月28日与8月4日，并注意空白支票没有日期。再想一想1879年实际签订的是什么。
:::
:::solution
这句话至少抹平了四个锁定的日期：6月28日、7月23日、7月28日与8月4日。在后两个日期之间，它还跳过了8月1日与8月3日，因此，从遇刺到英国宣战，更完整的锁定节点计数是六个有日期的行为，而不是一个。空白支票不是第七个锁定日期。1879年签订的是德国与奥匈的德奥同盟，是两国之间的协定，而不是刺杀皇储或入侵比利时的决定。1908年与1912年至1913年表明，同盟可以存在而不出现这一系列事件。这句话是虚构的，它正是[[#thm-agreements]]所拒绝的那种迷思。
:::
:::
