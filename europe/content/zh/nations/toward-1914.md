1914年7月还剩下哪些选择？

弗朗茨·斐迪南（Franz Ferdinand）在萨拉热窝遇刺，日期是1914年6月28日。奥匈在7月28日对塞尔维亚宣战。德国在8月1日对俄国宣战，在8月3日对法国宣战。8月4日，德国入侵比利时，英国对德国宣战。那些是带着日期的选择。1879年、1894年、1904年与1907年的那些协定，并不是一台替诸政府做出选择的机器。一个德国的动员计划，与施里芬（Schlieffen）联系在一起、又经毛奇（Moltke）修订，约束了一个时间表。一个约束不是选择的缺席。一个常被重复的论断是：战争在1879年之后是不可避免的，或者在那个后来被称为空头支票的支持承诺之后是不可避免的。那个论断是某个人的论断。那些日期回答了它。本课不叙述随后到来的那场战争。那场战争在[[wars/first-world-war]]。

在7月28日宣战的那个二元制君主国，是折衷方案（Ausgleich）造就的那个奥匈，在[[nations/unifications]]里讲授。一个王朝与一个匈牙利王国一起走进战争。它们不是一个正在醒来投入命运的民族。

## 四份协定，不是一台机器

:::definition 同盟与协约 {#def-alliance}
这里的**同盟**，是具名国家之间一项有日期的协定，读它是为了看它约束什么、不约束什么。**协约**（entente）也是一项有日期的协定，而它不是一纸与德奥同盟相同的东西。这两个词都不意味着一台北自身就会宣战的机器。意大利在1914年是一个欧洲大国，而不是下面所画的那些协定的一个端点。
:::

1879年的德奥同盟把德国与奥匈连接起来。它不连接英国，也不把意大利放到那条边上。法俄同盟在1894年。那一年也是德雷福斯被捕的那一年，而[[nations/mass-politics]]把它当作一个不同的事件来保住：一桩法国的案件不是一纸军事协定。英法协约（Entente Cordiale）在1904年4月8日，在法国与英国之间。它解决了未决的殖民地争端。它本身不是在一个后来的8月的第四日参战的承诺。英俄协定在1907年，是又一项协定，不是把英国与俄国融合为一个指向柏林的单一意志。四个日期，四份文书，三条触及英国或法国或俄国的边，以及一条把德国与奥匈连接的边。把它们数成两大集团已经是一种解读。这个解读必须在诸文书并不相像这个事实面前活下来。

:::theorem 那些协定没有取消选择 {#thm-agreements}
1879年的德奥同盟、1894年的法俄同盟、1904年4月8日的英法协约与1907年的英俄协定不是一台机器。它们抬高了某些选择的代价。它们没有使战争在1879年之后成为不可避免，也没有代替1914年的那些宣战行事。
:::
:::proof
四份文书各有不同的当事方与不同的年份。意大利不在本课所画的任何一条边里，而意大利也不在7月28日到8月4日那个序列中宣战的国家之列。如果那些协定是一台机器，这台机器在每一次危机中都应当是同一个形状。它不是。1908年的波斯尼亚兼并危机没有变成一场全欧战争。1912年与1913年的巴尔干战争也没有变成一场。会构成对这条论断的反证的是这样的证据：1879年之后，没有哪个政府本来能够有别于它在1914年的作为，因为1879年、1894年、1904年与1907年的那些文本已经穷尽了诸替代项。那些平静的危机是对那个证据的反证。一项解决殖民地争论的协约与一个德国和奥匈之间的同盟之间的差距，也是对它的反证。代价是真实的。代价不是不可能。“不可避免”这个词属于这一段所拒绝的那个论断，而不属于年表。
:::

拖动意大利。没有任何东西跟着它。那片空无就是本课的图式，不是一个坏掉的图形。一张诸条约的图形是四份协定的一张图像。它不是一幅8月的图像，而在你移动一个节点时，它不会移动诸军队。

:::example 意大利在诸边之外 {#ex-italy}
只使用1879年、1894年、1904年4月8日与1907年的那些协定，说出这个图形关于意大利主张了什么，而读者不可以添加什么。
:::solution
意大利不是德奥同盟的当事方，不是法俄同盟的当事方，也不是与英国的任何一项协定的当事方。所以这个图形没有给意大利任何一条边。你不可以添加一个年表没有锁定的条约年份，也不可以推断意大利在7月28日到8月4日的那个序列中宣战。它没有出现在那个序列里。不在这些边里，不是不在欧洲政治里。它是不在这台特定的机器里。
:::
:::

德奥同盟、法俄同盟与那两项协约是不同的文书。意大利没有边。1908年与1912至1913年的危机没有变成一场全欧战争。7月末与8月初的那些宣战是进一步的行为。“不可避免”正是那条论断所拒绝的读法。
:::
:::

## 中途止住的诸危机

1908年，奥匈兼并了波斯尼亚-黑塞哥维那。1878年的那次大会——一次与那场非洲会议不同的柏林会议——曾把那些土地置于奥匈的占领之下。兼并是一次地位的改变，而且它是一场危机：塞尔维亚与俄国表示反对。它不是1914年7月28日。一场全欧战争没有开始。德奥同盟可以在一场巴尔干的争吵之内运转，而仍然让其他政府停在这一章所列的那些宣战之外。如果那台机器当真存在，它是不会容许这一点的。

1912年与1913年的巴尔干战争，是在欧洲的奥斯曼领土上打的战争，先是在巴尔干诸国与奥斯曼帝国之间打，随后又围绕那份安排打。本课不叙述那些战事，也不给出伤亡总数。它使用的是年表给的那对方括号。一场巴尔干战争，即使是一场大的，也还不是1914年的那场欧洲战争。两次——如果把1908年和1912至1913年都算上——一场东南欧的危机没能变成7月末与8月初的那个序列。这个没能是证据。它没有使1914年成为不可能。它使1914年成为又一套决定，是在较早的危机原来都熬得过去的情况下做出的。

:::example 两场不是8月的危机 {#ex-crises}
把1908年的波斯尼亚兼并危机放在1912至1913年的巴尔干战争旁边。它们关于1879年的德奥同盟显示了什么，而关于1914年它们没有显示什么？
:::solution
两者都是1879年之后的巴尔干危机，而两者都没有变成一场全欧战争。它们是对这条论断的反证：德奥同盟本来已经把这样一场战争变成了唯一可用的行为。它们没有显示1914年是不可能的，也没有显示7月28日、8月1日、8月3日与8月4日的诸决定是与1908年同一个决定。巴尔干战争的伤亡总数不是答案的一部分。1908年兼并的是那次占领，那次占领属于1878年的大会，而[[nations/empires]]把它与那场非洲会议分开放着。
:::
:::

史家们意见不一：奥匈与俄国在巴尔干的对抗在多大程度上束缚了后来的那些选择。这场分歧是正文的一部分，不是一条你可以跳过的脚注。对抗是一个条件。条件是一种本来可以不一样的东西，而这正是[[sources/argument]]给予一个原因的检验。俄国可以在1908年表示反对，而没有与奥匈处于战争状态。巴尔干诸国可以在1912年与1913年打仗，而各大国仍然停在8月那些宣战之外。对抗解释了这片地区为什么危险。它没有选择那一天。

## 一个时间表不是一个命运

:::definition 一个动员计划 {#def-plan}
**动员计划**是一套参谋方案，按照一份预先准备好的时间表征召预备役并调动军队。与施里芬联系在一起、又经毛奇修订的那个德国计划，把一场两线战争的第一个重心放在西线，因而也就是放在一次穿过比利时的移动上。这个计划约束一个下达它的政府。它不是一条地理的规律，也不是一个不可能写出别的命令的证明。
:::

:::theorem 一个约束不是选择的缺席 {#thm-choice}
德国的动员计划，在它成为生效中的那个计划之后，约束了一个时间表。它没有废除选择，无论是在1914年7月，还是在更早。那些宣战与那次入侵仍然是诸政府带着日期的行为。克里斯托弗·克拉克（Christopher Clark）的《梦游者》（Sleepwalkers）是对那些行为的一种解读，不是一个判决。
:::
:::proof
这个计划是一个时间表：铁路、预备役，以及在一场按这个计划的条款来打的两线战争中一次穿过比利时的西线移动。一旦一个政府下令进行那次动员，接下来的那些小时就被压紧。那个压力就是那个约束。它是参谋军官与部长们制造的，而毛奇修订过它，所以它不是自然。一次修订本身就是这个方案本来可以不一样的证据。它本来已经是不一样的了。会构成对这个约束的反证的是这样的证据：在最后那些天里，柏林本可以部分动员，本可以停下来，本可以只面对东方，而且那个政府既这样相信过又这样做过。史家们就那些替代项有多敞开而意见不一。这场分歧在这里保持敞开。会构成对“没有选择”的反证的是那个清单：在任何一种支持承诺之后，仍然必须被执行的那些行为——7月23日的最后通牒，7月28日对塞尔维亚的宣战，8月1日对俄国的宣战，8月3日对法国的宣战，对比利时的入侵，以及8月4日英国的宣战。奥匈对塞尔维亚的战争，单拿它本身出来，并没有把德国军队放进比利时。是有人下令了那次移动。克拉克的那本书把这场危机解读为一串在局部可以理解、而合起来是灾难性的步骤。梦游者是他的意象，不是一个关于没有人醒着的发现。另一些史家则论证，德国的领导人们利用这场危机去谋求一场他们想要的战争。那是一个关于目标的论断。目标可以是真实的，而仍然留下这样的一天：在那一天，一道不同的命令本来可以被下达。本课的论断比那两本书中的任何一本都更窄。在那些被锁定的日期上，选择留存了下来。
:::

从柏林给维也纳的那个支持承诺，常常被叫作空头支票，它属于7月，在7月23日的最后通牒之前。本图谱没有为那个承诺锁定一个日子，所以一个日子也不发明，那个承诺的任何文本也不提供。一张支票，哪怕是一张空白的支票，是一个政府给出的一项担保。它还不是一纸宣战。那个“选择在那个担保给出时就终结了”的论断，必须解释它之后的那些行为。那些行为有日期。它们不是那个担保在自我重复。

最后通牒是7月23日。它的文本不在这里被发明。它是对塞尔维亚的一个带有短促期限的要求。那个期限以小时计的长度没有锁定，所以不予给出。诸政府随后争执塞尔维亚的答复是否够了。宣战在7月28日跟上来。日历上的五天，从23日到28日，足以容纳一次判断。一次判断是一个选择。那些条款没有给到你，而你不需要它们，就能看出一次宣战是一个进一步的行为。

:::example 二十五天，然后五天 {#ex-span}
弗朗茨·斐迪南在1914年6月28日遇刺。最后通牒是7月23日。对塞尔维亚的宣战是7月28日。遇刺与最后通牒之间隔着多少天，而最后通牒与宣战之间又有多少天？
:::solution
从6月28日到7月23日是25天。7月23日在7月28日之前五天，因为28减23是5。那25天是一个政治的间隔：一桩谋杀已经发生，而一场欧洲战争还没有被宣战。那五天是一个进一步的间隔，在一个本课不发明其文本的要求之后。两个间隔都不空洞到可以被叫作自动。那张空头支票在这里有意不带日期，它落在7月之内、最后通牒之前。它没有吞掉那25天，也没有吞掉那五天。
:::
:::

## 一个完整的案例：四个日期

把这个案例当作一个清单来读，而不是当作一幅幻灯片。

6月28日，哈布斯堡的皇储在萨拉热窝被杀死。本课不描述凶器，也不发明一篇演说。杀害一位皇储是一个政治事实。在那一天，它还不是奥匈与塞尔维亚之间的战争，也不是德国与俄国之间的战争。任何一个把战争开在6月28日的人，都跳过了做出那些选择的那个月。

7月23日，最后通牒送达。7月28日，奥匈对塞尔维亚宣战。那个二元制君主国选择把那次刺杀当作战争的理由，并选择了那一天。俄国还没有被宣战。德国还没有入侵比利时。1908年和1912至1913年的巴尔干先例显示，这片地区里的一场争吵可以仍然只是一场争吵。选择不同样是能够理解的。它仍然是一个选择。

8月1日，德国对俄国宣战。8月3日，德国对法国宣战。从7月28日到8月1日是四天。从8月1日到8月3日是两天。每一次宣战添加一个国家。动员计划使一次西线的移动成为参谋们为一场两线战争首选的序列。首选的、预先准备好的、修订过的，并不等于不能是别的。史家们就柏林还剩下多少余地意见不一。本课不靠宣布那个计划就是命运来终结他们的分歧，也不靠宣布那个计划只是一个没有抓手的借口来终结它。那个抓手就是那个约束。那些宣战就是那些选择。

8月4日，德国入侵比利时，英国对德国宣战。一天装着两个行为。那次入侵，如果那个计划被贯彻进比利时，就是修订过的计划的西线移动所要求的。英国的宣战是伦敦的一个决定，它与比利时、与那两项协约有关联，而不是1879年写下的一个条款。英法协约不宣战。一个内阁宣战。从8月3日到8月4日是一天。一天足够长，长到一次入侵与一次宣战可以被区分开，而这就是年表所要求的全部。

:::example 从萨拉热窝到英国的宣战 {#ex-thirty-seven}
1914年6月28日与1914年8月4日之间隔着多少天？把25、5、4、2与1这些步骤相加来检查结果。
:::solution
从6月28日到8月4日是37天。那些步骤是接续的：从6月28日到7月23日25天，从7月23日到7月28日5天，从7月28日到8月1日4天，从8月1日到8月3日2天，从8月3日到8月4日1天。25加5是30，加4是34，加2是36，加1是37。三十七天的政治时间，不是一次引爆。这个和里面没有一个死亡总数，没有最后通牒的文本，也没有任何一个步骤本来是唯一可能被采取的步骤的主张。
:::
:::

:::example 一台发明出来的机器 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“德奥同盟在1879年签署之后，以及那张空头支票发出之后，每一个后来的行为都是唯一剩下的行为，所以7月28日与8月4日是同一个决定。”这句话擦掉了什么？
:::solution
它擦掉了1908年与1912至1913年的诸危机，它们没有变成这场战争。它擦掉了那张空头支票缺失的日子——本图谱不会发明它——而它把那项担保当作那些宣战本身。它擦掉了7月28日、8月1日、8月3日与8月4日之间的区别：先是塞尔维亚，然后是俄国，然后是法国，然后是比利时与英国。它擦掉了毛奇的修订，那次修订显示这个计划是一个有人改动过的计划。[[#thm-agreements]]与[[#thm-choice]]就是回答。克拉克的《梦游者》与德国领导人寻求一场战争的论证，都是关于目标与混乱的解读。两者都不是一张把带着日期的诸行为叫作一个行为的许可证。这句话是虚构的，而年表足以把它打破。
:::
:::

:::quiz
奥匈在1914年7月28日对塞尔维亚的宣战证明了下面哪一项？
- [ ] 那时德国已经在入侵比利时
- [ ] 英法协约已经宣了战
- [x] 一个政府已经选择了对塞尔维亚的战争，而在此之后仍有带日期的进一步选择
- [ ] 战争自1879年的德奥同盟以来就是不可避免的
:::solution
7月28日是对塞尔维亚的一次宣战。对比利时的入侵与英国的宣战在8月4日。德国对俄国与法国的宣战在8月1日与8月3日。那些协约单凭自身不宣布任何事。自1879年以来的不可避免，正是[[#thm-agreements]]所拒绝的论断，它把1908年与1912至1913年用作拒绝的一部分。
:::
:::

那条狭窄的论断很容易被滑过去，所以值得不带叙述地再说一遍。诸政府在7月与8月初能够采取年表所列的那些步骤，而它们本来也可以不做某些特定的步骤。不做本来会有代价，同盟的代价与时间表的代价都在其中。代价是一个理由。它不是替代项缺席的证明。强调德国目标的史家与强调共同失败的史家，正在争论如何分配那些理由。你可以偏爱一种分配，而仍然拒绝“不可避免”。这个拒绝是这一章的。它不是为任何一座首都的辩护，也不是对任何一场后来的战争的建议。

:::warning 1879年之后不可避免，或者支票之后不可避免
这个迷思说，战争是在等着的，或者从1879年的德奥同盟起，或者从1914年7月的那张空头支票起，而那些日期记录的只是一台机器的击发。这个迷思是一个论断，而且它失败了。1908年与1912至1913年的巴尔干战争没有把它击发。最后通牒、从7月28日到8月4日的四个节拍、以及一个毛奇修订过的计划，全都是机器如果当真存在就不需要去决定的东西。《梦游者》在克拉克的论证里，是对诸选择的一种解读，不是一个关于选择不存在的判决。一张参谋的时间表约束了德国。它没有废除那个清单。
:::

:::history
弗朗茨·斐迪南在1914年6月28日于萨拉热窝被杀死。奥匈在7月28日对塞尔维亚宣战。到8月4日，德国已经入侵比利时，英国已经对德国宣战。在这些日期之间，德国还已经对俄国宣战，在8月1日，对法国宣战，在8月3日。这个序列是约束之下的诸选择的集合，不是一个十九世纪早已保住的预约。
:::

## 通向何处

一个原因如何不同于一个时间表，曾从[[sources/argument]]指向这一章。宣战的那个奥匈是[[nations/unifications]]里的那个二元制君主国。1878年的那次大会——它不是那场非洲会议——在[[nations/empires]]里，对一项主张的规范与一场战争的作战之间的区别也在那里。那些政府所面对的诸公众——它们还不是诸民主政体——在[[nations/mass-politics]]里。作战本身，本课不叙述，在[[wars/first-world-war]]。

:::summary
- 德奥同盟是1879年，法俄同盟是1894年，英法协约是1904年4月8日，英俄协定是1907年。它们不是一台机器。意大利不在那些边中的任何一条上。
- 波斯尼亚兼并危机是1908年。巴尔干战争是1912至1913年。两者都没有变成一场全欧战争。两者都对“1879年之后战争不可避免”构成反证。
- 弗朗茨·斐迪南在1914年6月28日遇刺。最后通牒是7月23日。它的文本没有被发明。奥匈在7月28日对塞尔维亚宣战。
- 德国在8月1日对俄国宣战，在8月3日对法国宣战。8月4日，德国入侵比利时，英国对德国宣战。从6月28日到8月4日是37天。
- 被叫作空头支票的那个支持承诺，在这里没有锁定的日子，所以一个也不发明。它没有终结选择。
- 与施里芬联系在一起、又经毛奇修订的动员计划约束了德国的一个时间表。史家们就还剩下多少余地意见不一。一个约束不是选择的缺席。克拉克的《梦游者》是一种解读，不是一个判决。
:::

## 习题

:::exercise 通牒之前的天数 {level=1 check="25"}
1914年6月28日的遇刺与1914年7月23日的最后通牒之间隔着多少天？（请输入天数。）
:::solution
从6月28日到7月23日是25天。一桩谋杀已经发生。一次宣战还没有。这个间隔是“6月28日还不是那场战争”这个论证的一部分。
:::
:::

:::exercise 总共的天数 {level=1 check="37"}
1914年6月28日与1914年8月4日之间隔着多少天？（请输入天数。）
:::solution
那段跨度是37天。核对：25天到7月23日，加5天到7月28日，加4天到8月1日，加2天到8月3日，加1天到8月4日。25加5加4加2加1是37。
:::
:::

:::exercise 德奥同盟的年份 {level=1 check="1879"}
德国与奥匈的德奥同盟在哪一年？（请输入年份。）
:::solution
德奥同盟是1879年。它连接那两个国家。它不包括意大利、英国、法国或俄国，也没有宣布1914年的那些战争。
:::
:::

:::exercise 谁在诸边之外 {level=2}
意大利出现在图形上，却没有边。解释这对1914年7月意味着什么，又不意味着什么。
:::solution
它的意思是：意大利不是所画的这些边的当事方——1879年的德奥同盟、1894年的法俄同盟、1904年4月8日的英法协约、1907年的英俄协定。它的意思不是意大利与欧洲政治无关，也不是意大利在终于8月4日的那个序列中宣战。没有更多的条约年份被锁定，所以一个也不添加。这些协定的一张图形不是一张命运的图形，图注说的就是这个。
:::
:::

:::exercise 1908年反对那台机器 {level=2}
1908年的波斯尼亚兼并危机如何构成对“德奥同盟之后战争不可避免”这一论断的反证？
:::solution
1908年，奥匈兼并了波斯尼亚-黑塞哥维那，那片土地是在1878年柏林大会的安排之下被占领的。兼并是一场危机，而没有变成一场全欧战争。如果1879年本来没有留下任何选择，一场这样的巴尔干危机就会已经是1914年的那场战争了。它不是。1912至1913年的巴尔干战争重复了这个道理，却不是同一个事件。答案使用“不可避免”，仅仅作为被拒绝的那个论断的名称。
:::
:::

:::exercise 计划与入侵 {level=2}
德国的动员计划约束了什么，而奥匈在7月28日的宣战为什么还不等于8月4日对比利时的入侵？
:::solution
与施里芬联系在一起、又经毛奇修订的那个计划，约束的是德国为一场两线战争动员的时间表，这场战争的第一个重心在西方，穿过比利时。那个约束在这个计划被下令时咬合。7月28日是奥匈对塞尔维亚的宣战。比利时在七天之后、作为德国的一个行为、在8月4日被入侵。一个盟友对塞尔维亚的战争不是另一个盟友的入侵。毛奇的修订显示这个方案本来已经被改变过一次，所以它不是地理。史家们就最后那些天里还剩多少余地意见不一。[[#thm-choice]]把约束与分歧同时保住。
:::
:::

:::exercise 目标与混乱 {level=3}
一些史家论证德国的领导人寻求一场战争。克拉克的《梦游者》给出了另一幅图景：若干座首都里被采取的诸步骤。本课可以从每一种取什么，而它仍然必须拒绝什么？
:::hint
让本课的论断比那两本书中的任何一本都更窄。问一问一个真实的目标，或一场真实的混乱，是否把7月23日到8月4日的那些带日期的行为拿掉了。
:::
:::solution
从关于目标的论证里，取这种可能性：德国的政策想要一场战争，并利用了这场危机。那是一个关于目的的论断，它可以为真，而不使后来的每一个钟点成为自动。从克拉克那里，取这份坚持：若干政府选择了在局部可以理解、而合起来是灾难性的步骤，并把梦游者的意象当作他的解读，而不是当作一个判决。史家们意见不一，而这场分歧属于答案的一部分。两种读法都仍然必须让它站得住的，是[[#thm-choice]]：最后通牒、那些宣战与那次入侵是带日期的行为。两本书都不是一张说战争在1879年之后、或在空头支票之后不可避免的许可证。那张支票没有锁定的日子，也没有发明的文本。
:::
:::

:::exercise 一个决定还是五个 {level=3}
下面这句话为示例而虚构。它不是史料。“萨拉热窝、那张空头支票、最后通牒、对塞尔维亚的宣战与对比利时的入侵是同一个决定，做出于1879年。”这句话压平了多少个锁定的日期，而1879年对它们为什么是错的年份？
:::hint
把6月28日、7月23日、7月28日与8月4日列出来，然后注意那张支票没有一个日子。然后问一问1879年实际签下了什么。
:::
:::solution
这句话至少压平了四个锁定的日期：6月28日、7月23日、7月28日与8月4日。在后两个日期之间，它还跳过了8月1日与8月3日，所以一个更完备的、从遇刺到英国宣战的锁定节拍的计数，是六个带日期的行为，不是一个。那张空头支票不是第七个锁定的日子。1879年是德国与奥匈的德奥同盟，是两个国家之间的一项协定，不是一个杀害一位皇储或入侵比利时的决定。1908年与1912至1913年显示，那个同盟可以存在而没有这个序列。这句话是虚构的。它就是[[#thm-agreements]]所拒绝的那个迷思。
:::
:::
