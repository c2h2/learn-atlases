关于犹太人遭到屠杀，证据是什么？一堂课在处理这些证据时又绝不能做什么？证据包括文献、证词与实物，它们证明了德国政权及其合作者在战争期间犯下的一项罪行：屠杀欧洲的犹太人。史家们以及纪念机构亚德·瓦谢姆（Yad Vashem）与美国大屠杀纪念博物馆（United States Holocaust Memorial Museum）所用的数字，是约六百万犹太人遇害。这个数字是估计，既不是凶手们完成的名单，也不能借此为其他任何人编造第二个总数。一堂课绝不能做的事，与日期一样，都是历史学科纪律的组成部分。它不能描述杀戮的程序、武器或营地的运作方式；不能编造受害者或凶手的引语；不能就某个当代国家展开争论；也不能把屠杀的开端挪到一次只是协调一项早已在进行之罪行的会议上。

“大屠杀”（Holocaust）是这场屠杀的通用名称，“浩劫”（Shoah）是另一个名称。两个名称都不能代替日期。法律上的排斥早于大规模杀戮。1935年9月15日，《纽伦堡法》（Nuremberg Laws）在法律上界定了犹太人，并禁止犹太人与法律认定为德意志血统的人之间通婚和发生性关系。这是以法令进行的迫害。它还不是约六百万这一估计所指的罪行，但与后来的罪行相比，它也绝非小事。1938年11月9日至10日，“十一月大迫害”（pogrom）袭击了德国境内的犹太人生活，我们不为它给出死亡总数。这场大迫害不是入侵苏联之后发生的系统性屠杀；如果问题是大规模屠杀，那么从这两个日期中任何一个开始讲述的读者，起点都仍然不对。就杀戮而言，正确的起点是1941年夏天，在1941年6月22日入侵之后被占领的苏联境内。1942年1月20日的一次会议，挪不动那个夏天。

由于这个数字是估计，有些人便把这项罪行当作可疑之事。只有当文献、证词与遗址彼此不相吻合时，怀疑才站得住脚。而它们恰恰吻合于这样一场屠杀：其规模经上述机构公布为约六百万犹太人。对估计范围内精确整数的分歧并不是否认。缺少一份由凶手完成的单一名单，正是使用“约”字的原因，而不是抛弃这种吻合的理由。

## 万湖之前，以及万湖会议

对被占领苏联境内犹太平民的大规模枪杀始于1941年夏天。年表用的就是这些字眼，本课也只用这些字眼，到此为止，不描述武器、部队或任何具体行动的经过。1941年夏天在6月22日之后、1942年1月之前。这一顺序足以表明：在官员们后来坐下来进行协调时，杀戮早已是东线战争中的事实。切尔姆诺（Chełmno）于1941年12月开始杀戮。切尔姆诺是一处屠杀之地，我们把它作为一个地方提及，而不说那里的杀戮是如何进行的。1941年12月仍在1942年1月20日之前。

1942年1月20日，包括莱因哈德·海德里希（Reinhard Heydrich）在内的一批官员在万湖（Wannsee）开会，协调驱逐与屠杀。会议记录是一份行政文件。协调不是开端。只知道会议日期的读者，掌握的只是一个目录词——“万湖”，也就是稍后图示中排在若干更早数据点之后的那一个。那些更早的数据点是《纽伦堡法》、十一月大迫害以及大规模枪杀的开始。这次会议之所以载入历史，是因为它表明一个国家在各部门之间组织一项罪行，而不是因为它是这项罪行的诞生。驱逐是被协调的内容之一。提及驱逐，并不需要、本课也不会提供对某次押运或某个地方之机器运作的描述。

其他杀戮中心也是屠杀之地，奥斯维辛（Auschwitz）是其中之一。1945年1月27日，红军解放了奥斯维辛。解放日是一处屠杀之地脱离该政权之手的日子，而不是对这个地方的描述，本课也不提供描述。史家们还列举了其他杀戮中心，其中有贝尔泽克（Bełżec）、索比布尔（Sobibór）与特雷布林卡（Treblinka）。它们在这里只作为地方被提及。年表没有为它们标注年份，所以不予编造；任何一个中心如何运作，也一字不提。地名证明屠杀有其地理分布；程序则是另一类陈述，本课拒绝提供。

:::definition 估计数字 {#def-estimate}
本章的**估计数字**，是史家们以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用的约六百万犹太人遇害这一数字。它不是凶手们结清的账簿，不是对这场战争中每一位受害者的清点，也不是一个可以凭想象再添加另一群体总数的数字。
:::

:::definition 种族灭绝：词语与公约 {#def-genocide}
**种族灭绝**是拉斐尔·莱姆金（Raphael Lemkin）在1944年出版的*Axis Rule in Occupied Europe*中使用的词语。1948年12月9日，联合国大会通过《防止及惩治灭绝种族罪公约》。这个词语与这项公约，一个是新造的词，一个是法律工具。它们不是对犹太人屠杀的开端——那在1941年就已在进行——也不等同于这个词后来的每一种用法。
:::

:::theorem 万湖不是开端 {#thm-wannsee}
1942年1月20日的万湖会议，协调的是早已开始的驱逐与屠杀。对被占领苏联境内的大规模枪杀始于1941年夏天，切尔姆诺于1941年12月开始杀戮。这次会议不是对犹太人屠杀的开端。
:::
:::proof
证据是年表锁定的顺序。入侵苏联在1941年6月22日。大规模枪杀始于随后的夏天，早于1942年1月。切尔姆诺始于1941年12月，同样早于1942年1月20日。按照年表的表述，会议的目的是协调一场早已在进行的屠杀。能够推翻这一论断的，是表明大规模枪杀与切尔姆诺的杀戮始于1942年1月20日当天或之后的证据，而年表所记录的并非如此。不能使万湖重新成为开端的，是这次会议的重要性。一次协调性的会议可以在历史上意义重大，却仍然是晚到的。1935年9月15日的《纽伦堡法》与1938年11月9日至10日的十一月大迫害更早，但它们也不是大规模屠杀。[[#thm-wannsee]]不把迫害、大迫害与系统性屠杀压缩成一个数据点，也拒绝相反方向的压缩，即在官员们开会之前一切都不算数。
:::

:::theorem 无须描述程序即可陈述证据 {#thm-evidence}
对犹太人的屠杀有文献、证词与实物证据支持，也有[[#def-estimate]]中的估计数字支持。一堂课可以讲授这一论断，而无须描述杀戮的程序、武器或营地的运作。拒绝这些描述并不会削弱这一论断；编造这些描述则会违反本课程的规则，却不会增加任何锁定的事实。
:::
:::proof
文献——命令、名单、行政文书、万湖会议记录——显示了各部门写下了什么，合起来读，则显示了政策是什么。它们不能取代个人的经历，本章也不编造任何人的话。证词可以确证一个地点、一个时间与一种命运。一个人的声音不是整个欧洲大陆的总数，但它在本质上并不比文书弱。遗址、物品与遗存表明某些地方曾被用于屠杀，但它们并不是邀请人们去重建某种方法。估计数字把这些记录，包括人口比较，汇集为公布的数字。能够推翻这一论断的，是三类证据共同表明被驱逐者在文书所列地点仍然活着。记录并非如此。拒绝描述程序，并不构成反证。弗里德兰德（Friedländer）的史著把受害者的声音视为证据的一部分。我们引述这一宗旨，而不伪造任何声音。
:::

:::quiz
下列哪一项与年表的顺序相符？
- [ ] 对犹太人的屠杀始于1942年1月20日的万湖，更早的日期只是没有杀戮的背景。
- [ ] 1935年的《纽伦堡法》就已是约六百万这一估计所指的罪行。
- [x] 大规模枪杀始于1941年夏天，切尔姆诺始于1941年12月。1942年1月20日的万湖会议协调的是一场早已在进行的屠杀。
- [ ] 1948年的《防止及惩治灭绝种族罪公约》是这项罪行的开端。
:::solution
第三项就是[[#thm-wannsee]]。1935年9月15日的法令是法律上的排斥，而不是战时的估计数字。1948年12月9日的公约是投降之后的法律工具，而不是屠杀的开端。万湖会议真实存在，但为时已晚。把此前的每一个日期都称为“单纯的背景”，正是把这次会议误教为诞生时刻的方式。
:::
:::

## 估计数字是什么，又不是什么

“约六百万”是一句带着“约”字的话，这个字是论断的组成部分。为了让数字听起来更硬而删掉它，并不会使它更准确。凶手们并没有交给史家们一份与某种计数方法相符的、完整的单一名单。史家们依据驱逐名单、人口比较以及其他记录进行重建，[[#def-estimate]]中提到的机构把结果公布为约六百万犹太人遇害。一堂印出精确整数、并称之为凶手们自己的总数的课，编造了一本已经结清的账簿；一堂因为估计数字不是这样一本账簿就将其抛弃的课，则把审慎与否认混为一谈。

估计数字是关于犹太人的数字。它不是该政权所杀害的每一个人的数字，也不是战争中每一例死亡的数字。本章不给出战争死亡总数。把两者混在一起是一种常见的混淆，也是编造数字的一种方式。波兰犹太人包括在约六百万犹太人的估计之内，非犹太裔波兰人则不在其中，他们在下文被提及，但不附总数。添加第二个数字，哪怕是另一本书中真诚给出的数字，在这里也是禁止的，因为年表没有锁定它。其他估计可以公开获得，并不意味着可以把它们引进来。本图谱的规则，与[[wars/first-world-war]]和[[wars/second-world-war]]中处理战场总数的规则相同：未锁定的数量，不由我们转述。

罗姆人遭到屠杀。残疾人也在所谓的“安乐死”计划中遭到屠杀；这个名称掩盖了对病人的屠杀，并不意味着他们选择了死亡。该计划没有锁定的开始日期，本课也不描述任何方法。许多非犹太裔波兰人遭到屠杀，苏联战俘以及其他人也是如此。可以说“许多”，但不能给出第二个总数。这一空缺是证据规则，而不是认为这些屠杀规模很小的判断。列出这些群体，同时拒绝伪造的整数，两者都是义务。

:::example 一次会议之前的三个日期 {#ex-order}
请按时间顺序排列以下各项，并指出哪一项不是大规模杀戮的开端：1935年9月15日的《纽伦堡法》；始于1941年夏天的大规模枪杀；1941年12月的切尔姆诺；1942年1月20日的万湖。
:::solution
法令最早，在1935年，它们是法律上的迫害，而不是大规模杀戮。大规模枪杀始于1941年夏天，在1941年6月22日入侵之后、万湖会议之前。切尔姆诺始于1941年12月，同样在会议之前。万湖是四者中最晚的，在1942年1月20日，它协调的是一场早已在进行的屠杀。法令不是换了名称的“大规模杀戮的开端”，会议也不是开端。1941年夏天与1941年12月，是年表为早已在进行的杀戮所作的标记。我们仍然不描述杀戮本身。
:::
:::

:::example 从苏联的投降纪念日到公约 {#ex-convention-span}
苏联以1945年5月9日为德国投降的纪念日。《防止及惩治灭绝种族罪公约》于1948年12月9日通过。按照两个日期相同的“日”，两者相隔几年几个月？为什么1948减1945是另一个更小的结果？
:::solution
从1945年5月9日到1948年5月9日是三年，从5月9日到12月9日是七个月，跨度为三年零七个月。两个日期都落在9日，所以周年计算法不受1948年的闰日是否在跨度之内的影响。把年份相减，1948 − 1945 = 3，只保留了年份，丢掉了七个月。公约在投降之后，它不是罪行本身，也不在投降的那个月份。莱姆金使用“种族灭绝”一词的那本书出版于1944年，处于战争期间，早于投降，也早于公约。一个1944年才造出的词，不可能是年表已置于1941年的一场屠杀的原因。
:::
:::

:::example 编造的开端与编造的账簿 {#ex-invented-start}
下面这句话为示例而虚构。它不是史料。“对犹太人的屠杀始于1942年1月20日的万湖，凶手们自己完成的名单显示，所有群体加起来恰好六百万人。”请把其中的错误分别指出。
:::solution
这句话是虚构的。它把万湖当作开端，违背了[[#thm-wannsee]]：大规模枪杀始于1941年夏天，切尔姆诺始于1941年12月。它把约六百万犹太人的估计变成了一本精确的账簿，而[[#def-estimate]]禁止这样做。它把数字从犹太人扩展到“所有群体”，既编造了年表未锁定的总数，又抹去了犹太人估计数字与其他遇害群体之间的区别，后者只被提及而不附数字。一句经得起检验的改写是：约六百万犹太人遇害；这一数字是估计，为史家们以及两个具名的纪念机构所使用；万湖会议协调的是一场早已开始的屠杀。改写后的句子平淡无奇，而这正是检验。编造的那句话在日期、精确程度与范围上都是错误的。
:::
:::

:::example 一份名单、一个声音、一处遗址各能证明什么 {#ex-three-sources}
在不编造引语或程序的前提下，说明一份驱逐名单、一位幸存者的证词与一处杀戮中心的遗址各自能够支持什么，又各自不能单独支持什么。
:::solution
驱逐名单属于文献。它可以支持关于某部门对被押送者之记录的论断，与其他文书合起来，还可以支持关于某项政策的论断。它本身不能证明名单上的每个人都遇害了，也不能单独得出约六百万的估计。幸存者的证词可以在任何证人都有的局限之内，支持关于某个地点、某个时间与某种命运的论断。它是证据，但不是整个大陆的总数，本练习也不得编造证人的话。遗址是某地曾被用于屠杀的实物证据。1945年1月27日解放的奥斯维辛，以及1941年12月开始杀戮的切尔姆诺，就是这样的地方。遗址并不授权描述杀戮中心如何运作，[[#thm-evidence]]拒绝这样做。估计数字是把这几类证据合起来读时才能得出的，而不是其中任何一类单独所能给出的。要把一句编造的证词提升为证据，你需要真实的证词，正如[[sources/evidence]]所要求的。本例题不提供任何证词。
:::
:::

莱姆金1944年的著作，为一项早已在进行的罪行创造了一个术语。1948年12月9日的公约，即1945年5月9日之后三年零七个月，要求各国防止并惩治灭绝种族罪。这是对其职能的转述，而不是对其条款的引用。一部1948年的法律不可能导致一场定于1941年的屠杀；一门从公约出发、一路倒推直至万湖看起来像起源的课程，重复的是[[wars/interwar]]中的走廊错误。公约并没有开启这场种族灭绝。

还有一项更早的归类，使这个词不至于看起来只适用于一项罪行、只适用于1948年之后。1904年10月2日，德属西南非洲发布了针对赫雷罗人（Herero）的灭绝令。史家们把针对赫雷罗人与纳马人（Nama）、持续到1908年的那场战事归为种族灭绝。年表禁止为那场战事给出死亡总数，本课也不给出。这一归类是历史判断。莱姆金造词在1944年，公约在1948年。这是三项操作，而不是一项：一个后来的法律词语，一本书，以及一场史家们如今用这一范畴加以归类的战事。本章的中心仍是对犹太人的屠杀。在这里提及赫雷罗人与纳马人的案例，是为了不让这一范畴被困在单一的日期之中，而不是为了比较总数：我们已经拒绝了第二个总数，年表也没有为1904年给出第一个总数。

:::quiz
“约六百万”具有什么地位？
- [ ] 它是凶手们对全部受害者完成的名单，“约”字可以删去。
- [ ] 它是一个没有文献、证词或实物支持的猜测，所以这项罪行值得怀疑。
- [x] 它是史家们以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用的犹太遇害者估计数字，既不是结清的账簿，也不是其他群体的总数。
- [ ] 它是苏联战俘的数字，犹太人的总数尚无定论。
:::solution
第三项就是[[#def-estimate]]。删掉“约”字，就编造了这些机构并未主张的精确。把这个数字称为毫无根据的猜测，就无视了[[#thm-evidence]]中的证据。苏联战俘遭到屠杀，罗姆人、在所谓的“安乐死”计划中遇害的残疾人、许多非犹太裔波兰人以及其他人也是如此。这些群体在这里都不附第二个总数。犹太人的数字不转移给他们，他们的数字也不转移给犹太人。
:::
:::

合作与救援都曾发生。不止一个国家的官员参与了驱逐。有些人藏匿了犹太人。有些人在不同的月份里两者都做过。两种模式都不是一个民族的性格。德国的权力组织了这项罪行，其他地方的合作者加入了进来。救援者存在于不止一个社会之中，包括德国境内。能够推翻这一拒绝的，是这样一份记录：一个国家的每一个人在整个屠杀过程中都只属于一个类别。档案并没有显示这一点。它们显示的是一个个决定，这正是[[wars/second-world-war]]中关于占领已经指出的。

移动年份。第一个数据点是1935年的《纽伦堡法》，而不是1942年。接着是1938年的大迫害、1941年大规模枪杀的开始、1942年的会议。如果你的目光把万湖当作起源，那些更早的数据点就是纠正。1944年是莱姆金的著作，1945年是1月27日奥斯维辛的解放，1948年是公约。从1945年到1948年，年份标签相差三。从1945年5月9日到1948年12月9日的跨度是三年零七个月。图上不附任何死亡总数。“约六百万”留在[[#def-estimate]]之中，而不放在数据点上。

:::warning 万湖作为开端，以及“要么是账簿，要么什么都不是”
有四种混乱造成危害。第一种把1942年1月20日当作开端，抹去了1941年夏天与切尔姆诺的十二月。第二种把约六百万当作凶手们完成的全部受害者名单，否则就当作一个使罪行变得可疑的模糊猜测。实际上，它是犹太遇害者的估计数字，其依据见[[#thm-evidence]]。第三种按本质把各民族归为救援者或合作者。合作与救援都曾发生，两者都不是民族性格。第四种说，如果我们不肯为罗姆人、在所谓的“安乐死”计划中遇害的残疾人、非犹太裔波兰人或苏联战俘编造总数，就等于认定这些屠杀无关紧要。我们所认定的，是不伪造数字。这些群体被一一提及，第二个总数则不予给出。这些混乱都不能靠描述武器或营地的运作来弥补。这种描述被拒绝，而拒绝并不是证据中的缺口。
:::

:::history
1942年1月20日，包括海德里希（Heydrich）在内的一批官员在万湖开会，协调驱逐与屠杀。对被占领苏联境内的大规模枪杀已于1941年夏天开始，切尔姆诺已于1941年12月开始杀戮。史家们与纪念机构所用的数字是约六百万犹太人遇害。它是估计，而不是凶手们完成的名单。
:::

这则历史注记不引用会议记录，也不描述任何地方。在图示上，万湖不是最左边的数据点。能够推翻这则注记的，是基于同类证据作出的修订，以之取代这一估计数字，或把大规模枪杀移到1942年。要求描述程序、提供第二个总数或一篇演说，则不能推翻它。罪行从1941年起有日期，词语在1944年，公约在1948年。用公约来怀疑罪行，就是颠倒了这一顺序；拿罪行作为讲述某种方法的理由，就是颠倒了本课的目的。一份名单、一份证词与估计数字仍然是不同的尺度，正如[[#ex-three-sources]]所说：其中任何一个都不包含另一个。

## 通向何处

实施这场屠杀的那场战争，包括在不同意义上定于1945年5月7日、8日、9日的投降，见[[wars/second-world-war]]。1935年的法令与1938年的大迫害处在[[wars/interwar]]的岁月之中，那些岁月不是通向一个人的走廊，也还不是这项罪行。投降之后欧洲的分裂，从[[postwar/division]]开始。史料与推论有何不同，以及编造的句子为何还不是证据，见[[sources/evidence]]。

:::summary
- 约六百万犹太人遇害。这一数字是估计，为史家们以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用。它不是凶手们完成的名单，也不是该政权或这场战争全部受害者的总数。
- 《纽伦堡法》在1935年9月15日。十一月大迫害在1938年11月9日至10日。两者都不是大规模屠杀，也都不是可以跳过的无足轻重的序幕。
- 对被占领苏联境内的大规模枪杀始于1941年夏天。屠杀之地切尔姆诺于1941年12月开始杀戮。1942年1月20日的万湖会议协调的是一项早已在进行的罪行，它不是开端。
- 1945年1月27日由红军解放的奥斯维辛以及其他杀戮中心，都只作为地方被提及。本课不描述程序、武器或营地如何运作。
- 罗姆人、在所谓的“安乐死”计划中遇害的残疾人、许多非犹太裔波兰人、苏联战俘以及其他人，也遭到了屠杀。本课不给出第二个总数。这一拒绝并不意味着这些屠杀规模很小。
- 莱姆金的*Axis Rule in Occupied Europe*（1944年）使用了“种族灭绝”一词。《防止及惩治灭绝种族罪公约》于1948年12月9日通过，在1945年5月9日之后三年零七个月。这个词与这部法律都不是罪行的原因。
- 证据包括文献、证词与实物。合作与救援都曾发生，两者都不是一个民族的性格。史家们把从1904年10月2日的命令到1908年针对赫雷罗人与纳马人的战事归为种族灭绝，这里不给出死亡总数。
:::

## 习题

:::exercise 不是第一个数据点 {level=1 check="1941"}
对被占领苏联境内的大规模枪杀始于哪一年？（请输入四位数年份。）
:::solution
大规模枪杀始于1941年夏天，年份是1941。万湖在1942年，不是开端。使被占领苏联陷入这场枪杀的那次入侵，发生在1941年6月22日。
:::
:::

:::exercise 会议的月份 {level=1 check="January"}
万湖会议在1942年的哪个月举行？（请输入月份。）
:::solution
会议在1942年1月20日，月份是1月。切尔姆诺开始杀戮的1941年12月，是上一个月，也是上一年。答案是1月。
:::
:::

:::exercise 公约的年份 {level=1 check="1948"}
联合国大会在哪一年通过了《防止及惩治灭绝种族罪公约》？（请输入四位数年份。）
:::solution
公约于1948年12月9日通过，年份是1948。莱姆金的著作在1944年，投降在1945年。公约不是屠杀的开端。
:::
:::

:::exercise “约”字的作用 {level=2}
为什么“约”字必须留在六百万犹太人这一数字之中？为什么不得把这个数字扩展到“所有群体”？
:::solution
年表与[[#def-estimate]]都把这个数字称为估计，为史家们以及具名的纪念机构所使用，而不是凶手们完成的名单。删掉“约”字，就编造了一种已经结清的精确。把数字扩展到所有群体，就编造了第二个总数，并把包括在犹太人估计之内的波兰犹太人，与只被提及而不附数字的非犹太裔波兰人以及罗姆人、残疾人、苏联战俘和其他人混在了一起。这项罪行并不会因为整数是估计的就变得可疑；只有当[[#thm-evidence]]中的证据失效时，它才会变得可疑。而这些证据并没有失效。
:::
:::

:::exercise 地点不是方法 {level=2}
切尔姆诺于1941年12月开始杀戮，奥斯维辛于1945年1月27日获得解放。关于这两个名称，你可以说什么？又绝不能说什么？
:::solution
你可以说两者都是屠杀之地，切尔姆诺的杀戮早于万湖会议，红军在一个确定的日子解放了奥斯维辛。你可以说，关于这些地方的证据包括文献、证词与实物。你绝不能描述杀戮的程序、武器或营地如何运作。[[#thm-evidence]]把这一拒绝视为负责任的教学的组成部分，而不是论断中的漏洞。你也不能编造这两个地方中任何人的引语。
:::
:::

:::exercise 词语、罪行、法律 {level=2}
按大规模枪杀、莱姆金的著作与《防止及惩治灭绝种族罪公约》的顺序排列1941年、1944年与1948年。为什么那本书与那项公约都不可能是枪杀的原因？
:::solution
大规模枪杀始于1941年夏天。莱姆金的*Axis Rule in Occupied Europe*在1944年使用了“种族灭绝”一词。公约于1948年12月9日通过。一本1944年的书不可能导致一项年表已置于1941年的罪行，一项1948年的公约也不可能。从1945年5月9日到1948年12月9日的跨度是三年零七个月，所以这部法律也在投降之后。在[[sources/argument]]所说的意义上，原因必须早于结果。这个词是为了能够指称这项罪行而提出的范畴，而不是罪行的起源。
:::
:::

:::exercise 修正编造的句子 {level=3}
改写[[#ex-invented-start]]中那句编造的话，使万湖、估计数字与其他受害群体各得其所。不要添加第二个总数或任何程序。
:::hint
让1941年夏天与1941年12月早于1942年1月20日。让“约六百万”与犹太人以及“估计”一词连在一起。提及其他群体而不附整数。在描述任何方法之前停下。
:::
:::solution
一种改写是：大规模枪杀始于1941年夏天，切尔姆诺于1941年12月开始杀戮；1942年1月20日，万湖会议协调了这场屠杀，而不是开启了它；约六百万犹太人遇害，这是估计，而不是完整的名单；罗姆人、在所谓的“安乐死”计划中遇害的残疾人、许多非犹太裔波兰人、苏联战俘以及其他人也遭到了屠杀，这里不给出第二个总数。这一改写不包含任何程序，也不包含伪造的引语。如果把万湖移到最前面，删掉“约”字，或者给第二个群体附上数字，它就会重新变成错误。这些正是原句的错误，被拆分开来以便逐一检验。
:::
:::

:::exercise 什么能够推翻估计数字 {level=3}
[[#thm-evidence]]说明了什么能够推翻“屠杀以这种规模发生过”这一论断。请用你自己的话陈述这种反面证据。然后说明：为什么缺少凶手的账簿并不是这种反面证据，要求描述营地也不是。
:::hint
想一想文献、证词与遗址指向同一方向的情形。某一类名单中的缺口，不同于一份表明被驱逐者仍然活着的记录。程序并不是本课程接受的任何一种证明。
:::
:::solution
能够推翻这一论断的，是文献、证词与实物记录共同表明被驱逐者在文书所列地点仍然活着。记录所显示的并非如此。缺少一本单一的账簿，正是这个数字只是约六百万的估计、而不是结清的行政总数的原因。史家们与具名机构仍然公布这一估计，因为其他记录相互吻合。这一缺口是使用“约”字的原因，而不是抛弃这种吻合的理由。要求描述营地如何运作，要的是[[#thm-evidence]]所拒绝的东西。拒绝它，去掉的只是一本手册，并没有去掉文献、证词或遗址。编造的引语填补不了其中任何一个角色，它只会是又一份虚假的文献。
:::
:::
