对犹太人的谋杀，证据是什么，而一课对它必须不做什么？证据是文献的、证词的与实物的，它支持一桩由德国政权及其合作者在战争期间实施的罪行：对欧洲犹太人的谋杀。史家们使用的、以及亚德·瓦谢姆（Yad Vashem）与美国大屠杀纪念博物馆（United States Holocaust Memorial Museum）使用的数字，是约六百万犹太人遭灭绝。那个数字是一个估计。它不是凶手们完成的一份清单，也不是为任何别的人发明第二个总数的许可证。一课必须不做的事，与那些日期一样，是历史纪律的一部分。它必须不描述一套杀戮的程序、一件武器，或一座营地的运作方式。它必须不发明一句出自受害者或凶手的引语。它必须不就一个当代的国家展开争论。它必须不把一个谋杀的开端挪到一次协调了一桩已经在进行的罪行的会议上。

大屠杀（Holocaust）是这场谋杀通用的名称，浩劫（Shoah）是另一个名称。两个名称都不是日期的替代品。法律的排斥比大规模杀戮更早开始。1935年9月15日，纽伦堡诸法令（Nuremberg Laws）为了法律的目的界定犹太人，并禁止犹太人与法律算作德意志血统的人之间的婚姻与性关系。那是法令里的迫害。它还不是约六百万的那个估计，而放在后来那桩罪行旁边，它也不是一件小事。1938年11月9–10日，十一月大迫害（pogrom）攻击德国之内的犹太生活。我们不为它给出死亡总数。那场大迫害不是对苏联的入侵之后跟随的系统性谋杀，而如果问题是大规模谋杀，那么一个从这两个日期中任何一个开始讲故事的读者，仍然没有在正确的位置开始。就杀戮而言，正确的位置是1941年的夏天，在被占领的苏联，在1941年6月22日的入侵之后。1942年1月20日的一次会议挪不动那个夏天。

因为那个数字是一个估计，一些人把这桩罪行当作可疑的。怀疑只会在这些文献、证词与遗址并不吻合的时候才跟得上来。它们吻合在一场达到那些机构公布为约六百万犹太人被杀的规模的谋杀上。对估计之内那个精确整数的分歧不是一项否认。缺少一份单一的、由凶手完成的清单，正是“约”这个字的理由，而不是丢弃那个吻合的理由。

## 万湖之前，以及在万湖

对被占领的苏联境内犹太平民的大规模枪杀，始于1941年的夏天。年表用的就是这些话。本课用这些话，并且停在这里。它不描述武器、部队，或任何一次具体行动的经过。1941年的夏天在6月22日之后、在1942年1月之前。那个次序就足够显示：当官员们后来坐下来协调它的时候，杀戮已经是东方战争的一个事实。切尔姆诺（Chełmno）在1941年12月开始杀戮。切尔姆诺是一个谋杀之地。我们把它作为一个地方来点名。我们不说那里的杀戮是怎样做的。1941年12月仍然在1942年1月20日之前。

1942年1月20日，官员们在万湖（Wannsee）开会，莱因哈德·海德里希（Reinhard Heydrich）在其中，以协调驱逐与谋杀。记录是一份行政文书。协调不是一个开端。一个只有会议日期的读者，只有一个目录词，“万湖”，一种稍后的图形会作为早先诸圆点中的一个来显示的那个词。早先的那些圆点是纽伦堡诸法令、十一月大迫害，以及大规模枪杀的开始。那次会议属于历史，是因为它显示一个国家在诸官署之间组织一桩罪行，而不是因为它是那桩罪行的出生。驱逐是被协调的内容的一部分。点名驱逐不需要、也不会得到一段对一次行程或一座地方的机器的记述。

别的杀戮中心也是谋杀之地。奥斯维辛（Auschwitz）是其中之一。红军在1945年1月27日解放奥斯维辛。解放是一个谋杀之地脱离那个政权之手的日子。它不是对这个地方的描述，而本课不给一个描述。史家们也点名别的杀戮中心，其中有贝尔泽克（Bełżec）、索比布尔（Sobibór）与特雷布林卡（Treblinka）。它们在这里是作为地方被点名的。年表没有把任何年份附在它们身上，所以没有一个被发明，而任何一座中心如何运作，也一字不提。一个地名是谋杀曾有一个地理的证据。一套程序将是一种不同种类的句子，而它被拒绝。

:::definition 估计数字 {#def-estimate}
本章的**估计数字**，是约六百万犹太人遭灭绝这个数字，为史家们，以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用。它不是凶手们做完了的一本账，不是对这场战争的每一个受害者的一次清点，也不是一个可以把另一个团体的总数凭想象加进去的数字。
:::

:::definition 种族灭绝，这个词语与公约 {#def-genocide}
**种族灭绝**是拉斐尔·莱姆金（Raphael Lemkin）在*Axis Rule in Occupied Europe*中使用的词语，该书出版于1944年。1948年12月9日，联合国大会通过《防止及惩治灭绝种族罪公约》。这个词语与这份公约是一个新造的词与一件法律工具。它们不是对犹太人谋杀的开始——那在1941年已经在进行——它们也与这个词语后来的一切用法不相同。
:::

:::theorem 万湖不是开端 {#thm-wannsee}
1942年1月20日的万湖会议，协调的是已经开始了的驱逐与谋杀。对被占领的苏联的大规模枪杀始于1941年的夏天。切尔姆诺在1941年12月开始杀戮。那次会议不是对犹太人谋杀的开端。
:::
:::proof
证据是年表锁定的次序。对苏联的入侵是1941年6月22日。大规模枪杀始于随后的那个夏天，那在1942年1月之前。切尔姆诺始于1941年12月，那也在1942年1月20日之前。会议的目的，如年表所述，是协调一场已经在进行的谋杀。会构成对这条论断的反证的，是这样的证据：大规模枪杀与切尔姆诺的杀戮开始于1942年1月20日当日或之后。那个证据不是年表所记录的。不会把万湖挽救成一个开端的，是那次会议的重要性。一次协调的会议可以在历史上是严重的，而仍然是晚的。1935年9月15日的纽伦堡诸法令与1938年11月9–10日的十一月大迫害又更早，而它们也还不是那场大规模谋杀。[[#thm-wannsee]]不把迫害、大迫害与系统性谋杀坍进一个圆点。它也拒绝相反的坍缩，在那个坍缩里，在官员们开会之前什么都不算。
:::

:::theorem 证据可以在没有一套程序的情况下讲出 {#thm-evidence}
对犹太人的谋杀得到文献的、证词的与实物的证据的支持，并得到[[#def-estimate]]里的估计数字的支持。一课能够讲授那条论断，而不描述一套杀戮的程序、一件武器、或一座营地的运作。拒绝那些描述不削弱那条论断。发明它们会打破本课程的规则，而不会添加一个锁定的事实。
:::
:::proof
文献——命令、清单、行政文书、万湖的记录——显示出各个官署写下了什么，而放在一起读，那项政策是什么。它们不替代一个人的经历，而本章不发明任何人的句子。证词能够确立一个地方、一个时间与一个命运。一个声音不是大陆性的总数，而它按本性不比文书弱。遗址、物品与遗存显示出有些地方曾被用于谋杀。它们不是一份去重建一套方法的邀请。估计数字把这些记录——包括人口比较——收进公布的数字。会构成对这条论断的反证的，是三类证据一起显示被驱逐的人在文书点名的地方活着。那不是记录。拒绝一套程序不构成反证。弗里德兰德（Friedländer）的史著把受害者的声音当作证据的一部分。我们引用那个宗旨，而不伪造任何声音。
:::

:::quiz
哪一个论断与年表的次序相符？
- [ ] 对犹太人的谋杀始于1942年1月20日的万湖，而较早的日期只是没有杀戮的背景。
- [ ] 1935年的纽伦堡诸法令就已经是约六百万的那个估计。
- [x] 大规模枪杀始于1941年的夏天，而切尔姆诺始于1941年12月。1942年1月20日的万湖，协调的是一场已经在进行的谋杀。
- [ ] 1948年的《灭绝种族罪公约》是那桩罪行的开端。
:::solution
第三个论断是[[#thm-wannsee]]。1935年9月15日的诸法令是法律的排斥，不是战时的估计。1948年12月9日的公约是投降之后的一件法律工具，不是谋杀的开端。万湖是一次真实的会议，而是一次晚的会议。把每一个较早的日期叫作“单纯的背景”，就是那次会议被错教成一个出生的方式。
:::
:::

## 估计数字是什么，又不是什么

约六百万是一个带着“约”这个字的句子。这个字是那条论断的一部分。把它删掉好让数字听起来更硬，并没有让它更准确。凶手们不曾交给史家们一份单一的、完成的、与一种计数方法相匹配的清单。史家们从驱逐清单、从人口比较、从别的记录中重建。[[#def-estimate]]里点名的那些机构，把结果公布为约六百万犹太人遭灭绝。一课如果印出一个精确的整数、并把它叫作凶手们自己的总数，就发明了一本完成的账。一课如果因为那个估计不是那本账就把它扔掉，就是把审慎与否认混为一谈。

估计数字是一个关于犹太人的数字。它不是关于那个政权谋杀的每一个人的数字，也不是关于战争之中每一个死亡者的数字。本课不陈述战争死亡总数。把两者混在一起是一种常见的混淆，也是一种发明一个数字的方式。波兰的犹太人在约六百万犹太人的估计之内。非犹太人的波兰人不在。他们在下文被点名，没有一个总数。添加第二个数字，即使是从另一本书里拿来的一个真诚的数字，在这里也是被禁止的，因为年表没有锁定它。别的估计可以公开获得，这不是把它们引进来的许可。本图谱的规则，与[[wars/first-world-war]]和[[wars/second-world-war]]里对战场总数所使用的同一条：一个未锁定的量，不是我们来复述的。

罗姆人遭谋杀。残疾人也在所谓的“安乐死”计划里遭谋杀，那是一个掩盖了对病人的谋杀、而且并不意味着他们选择了去死的名称。那个计划没有锁定一个开始的日子，而一种方法也不被描述。许多非犹太人的波兰人遭谋杀，苏联战俘也是，还有别的人。“许多”是被允许的。第二个总数不是。这道空档是证据的一条规则，不是一个那些谋杀是轻微的论断。点名诸团体，与拒绝一个伪造的整数，都是义务。

:::example 一次会议之前的三个日期 {#ex-order}
把这些按时间排好，并说出哪一个不是大规模杀戮的开端：1935年9月15日的纽伦堡诸法令；始于1941年的夏天的大规模枪杀；1941年12月的切尔姆诺；1942年1月20日的万湖。
:::solution
诸法令在最前，在1935年，而它们是法律的迫害，不是大规模的杀戮。大规模枪杀始于1941年的夏天，在1941年6月22日的入侵之后、在万湖之前。切尔姆诺始于1941年12月，仍然在会议之前。万湖是四者中最晚的，在1942年1月20日，而它协调的是一场已经在进行的谋杀。诸法令不是换了名字的“大规模杀戮的开端”。那次会议也不是开端。1941年的夏天与1941年12月是年表对一场已在进行的杀戮的标记。我们仍然不描述那场杀戮。
:::
:::

:::example 从投降的苏联纪念到公约 {#ex-convention-span}
苏联把德国的投降作为1945年5月9日来纪念。《防止及惩治灭绝种族罪公约》在1948年12月9日通过。用共享的那一个月中的日子，这两个日期之间隔着多少年多少个月？为什么1948减1945是一个不同的、更小的结果？
:::solution
从1945年5月9日到1948年5月9日是三年。从5月9日到12月9日是七个月。跨度是三年又七个月。两个日期都落在一个9日，所以周年的方法不依赖于1948年的闰日是否在跨度之内。减去年份数字，1948 − 1945 = 3，只留下年份而丢掉了七个月。公约在投降之后。它不是那桩罪行，也不在与投降相同的月份里。莱姆金的那本使用了种族灭绝这个词的书，是1944年，在战争之中，在投降与公约两者之前。一个1944年造出的词不可能是年表已经放在1941年的一场谋杀的原因。
:::
:::

:::example 一个发明出来的开端与一本发明出来的账 {#ex-invented-start}
下面这句话为示例而虚构。它不是史料。“对犹太人的谋杀始于1942年1月20日的万湖，而凶手们自己完成的清单显示出整整六百万人，包括所有团体。”把错误分开。
:::solution
这句话是虚构的。它把万湖变成开端，违反了[[#thm-wannsee]]：大规模枪杀始于1941年的夏天，而切尔姆诺在1941年12月。它把一个约六百万犹太人的估计变成一本精确的账。[[#def-estimate]]禁止那个。它把数字从犹太人扩展到“所有团体”，这发明了一个年表没有锁定的总数，并且抹掉犹太人的估计与别的遭谋杀的团体之间的分别——那些团体是被点名而没有数字的。一句能够存活下来的改写句子是：约六百万犹太人遭灭绝；那个数字是一个估计，为史家们与两个点名的纪念机构所使用；万湖协调的是一场已经开始的谋杀。改写的句子是乏味的。那就是检验。发明的那句在它的日期、它的精确、它的边界上都是假的。
:::
:::

:::example 一份清单、一个声音、一处遗址，各自能做什么 {#ex-three-sources}
不发明一句引语或一套程序，说一说一份驱逐清单、一名幸存者的证词、一座杀戮中心的遗址各自能够支持什么，而各自不能单独支持什么。
:::solution
一份驱逐清单是文献。它能够支持一个关于某个官署对所送人员的记录的论断，并且，与其他文书放在一起，支持一个关于一项政策的论断。它本身不能显示每一个被点名的人遭了谋杀，它本身也得不出约六百万的那个估计。一名幸存者的证词能够支持一个关于一个地方、一个时间与一个命运的论断，在任何一个证人的限度之内。它是证据。它不是一个大陆性的总数，而本练习不得发明那个证人的话。一处遗址是一个地方曾被用于谋杀的实物证据。奥斯维辛，在1945年1月27日被解放，以及切尔姆诺，杀戮始于1941年12月，就是这样的地方。那处遗址不授权一段对一个中心如何运作的描述，[[#thm-evidence]]拒绝那个。估计数字是当这些种类的证据放在一起读的时候变得可用的东西，不是它们之中任何一个单独印出的东西。要把一句发明出来的证词提升为证据，你会需要真实的证词，如[[sources/evidence]]所要求的。这个例子不提供一句。
:::
:::

莱姆金1944年的书为一个已经在进行的罪行造出一个词语。1948年12月9日的公约，在1945年5月9日之后三年又七个月，要求各国防止并惩治灭绝种族罪。那是对它的职务的一句转述，不是对它的条款的一句引文。一部1948年的法律不能引发一场被放在1941年的谋杀，而一门从公约出发、向后走回，直到万湖看起来像一个起源的课程，重复了[[wars/interwar]]的走廊的错误。公约没有开启这桩灭绝种族罪。

有一个更早的归类，使这个词语不至于看起来好像它只能适用于一桩罪行、而且只能在1948年之后。1904年10月2日，一道针对德属西南非洲的赫雷罗人（Herero）的歼灭令被发布。史家们把针对赫雷罗人与纳马人（Nama）、延续到1908年的那场战事归为灭绝种族罪。年表禁止为那场战事给出一个死亡总数，而本课不给出一个。这个归类是一个历史的论断。莱姆金的造词是1944年。公约是1948年。三个操作，不是一个：一个较晚的法律词语、一本书，以及一场史家们如今用这个范畴来归类的战事。本章的中心仍然是对犹太人的谋杀。赫雷罗人与纳马人的案例在这里，是为了这个范畴不被困在一个单一的日期之内。它在这里不是作为诸总数的比较，因为我们已经拒绝了第二个总数，而年表对1904年也没有给出一个第一个总数。

:::quiz
“约六百万”是什么地位？
- [ ] 它是凶手们对他们的全部受害者完成的清单，而“约”这个字可以删掉。
- [ ] 它是一个没有文献、证词或实物支持的猜测，所以这桩罪行是可疑的。
- [x] 它是史家们以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用的、对遭灭绝的犹太人的估计，不是一本完成了的账，也不是一个别的团体的总数。
- [ ] 它是关于苏联战俘的数字，而犹太人的总数留空未定。
:::solution
第三个论断是[[#def-estimate]]。删掉“约”发明了一种那些机构并不声称的精确。把那个数字叫作一个无根据的猜测，无视了[[#thm-evidence]]里的证据。苏联战俘遭谋杀，罗姆人也是，在所谓的“安乐死”计划里遭谋杀的残疾人也是，许多非犹太人的波兰人也是，还有别的人。这些团体之中没有一个在这里得到第二个总数。犹太人的数字不转嫁给它们，它们的也不转嫁给犹太人的。
:::
:::

合作与拯救都发生过。不止一个国家的官员参与了驱逐。有些人藏匿了犹太人。有些生命两样都做了，在不同的月份。两种样式都不是一种民族的性格。德国的权力组织了这桩罪行。别处的合作者加入了它。拯救者在不止一个社会里存在，包括德国之内。会构成对那个拒绝的反证的，是一份记录，显示一个国家里的每一个人在这场谋杀的整个过程之中都站在一个类别之内。档案不显示那个。它们显示的是决定，这正是已经在[[wars/second-world-war]]里为占领说过的。

移动年份。第一个圆点是1935年，纽伦堡诸法令，不是1942年。然后1938年是大迫害，1941年是大规模枪杀的开始，1942年是那次会议。如果你的眼睛把万湖当作起源，那些早先的圆点就是纠正。1944年是莱姆金的书籍，1945年是1月27日奥斯维辛的解放，1948年是公约。从1945年到1948年的年份标签相差三。从1945年5月9日到1948年12月9日的跨度是三年又七个月。这幅图形不承载死亡总数。约六百万留在[[#def-estimate]]里，不在那些圆点上。

:::warning 作为一个开端的万湖，以及一本账，否则什么也不是
四团混乱造成损害。第一团把1942年1月20日变成开端，这抹掉了1941年的夏天与切尔姆诺的十二月。第二团把约六百万当作一份完成了的、关于全部受害者的凶手清单，否则就当作一个让罪行可疑的含糊猜测。它是一个对遭灭绝的犹太人的估计，其支持在[[#thm-evidence]]里点名。第三团按本质把民族归类成拯救者或合作者。合作与拯救都发生过，而两者都不是民族性格。第四团说，我们如果不肯为罗姆人、为在所谓的“安乐死”计划里遭谋杀的残疾人、为非犹太人的波兰人、或为苏联战俘发明一个总数，我们就是已经判定那些谋杀是轻微的。我们决定的是不去伪造一个数字。诸团体被点名了。第二个总数没有。这些混乱之中，没有一团能靠描述一件武器或一座营地的运作来修补。那个描述被拒绝，而这个拒绝不是证据里的一个缺口。
:::

:::history
1942年1月20日，官员们在万湖开会，海德里希（Heydrich）在其中，以协调驱逐与谋杀。对被占领的苏联的大规模枪杀已经在1941年的夏天开始了，而切尔姆诺已经在1941年12月开始杀戮。史家们与纪念机构使用的数字是约六百万犹太人遭灭绝。它是一个估计，不是凶手们完成的一份清单。
:::

历史注记不引那份记录书，也不描述一个地方。在图形上，万湖不是左手边的圆点。会构成对这条注记的反证的，是一个在同样这些种类的证据之上做出的修订，取代那个估计数字，或把大规模枪杀挪到1942年。一个对一套程序、第二个总数或一场演说的要求则不会。那桩罪行自1941年起有日期。那个词语是1944年。公约是1948年。用公约去怀疑那桩罪行，把这个次序颠倒过来。用那桩罪行去作讲述一套方法的理由，把这一课的目的颠倒过来。一份清单、一个证词与那个估计数字仍然是不同的尺度，如[[#ex-three-sources]]所说：它们之中没有一个包含另一个。

## 通向何处

实施这场谋杀的那场战争，包括一场以不同的含义定在1945年5月7、8、9日的投降，在[[wars/second-world-war]]。1935年的诸法令与1938年的大迫害坐在[[wars/interwar]]的年头里，那些年头不是一条通往一个人的走廊，而它们也还不是这桩罪行。投降之后的欧洲的分裂从[[postwar/division]]开始。一份史料如何不同于一个推断，以及一句发明出来的句子为何还不是证据，在[[sources/evidence]]。

:::summary
- 约六百万犹太人遭灭绝。那个数字是一个估计，为史家们以及亚德·瓦谢姆与美国大屠杀纪念博物馆所使用。它不是一份凶手们完成的清单，也不是那个政权的或那场战争的每一个受害者的总数。
- 纽伦堡诸法令是1935年9月15日。十一月大迫害是1938年11月9–10日。两者都不是那场大规模谋杀，而两者都不是你可以跳过的一篇轻微的序言。
- 对被占领的苏联的大规模枪杀始于1941年的夏天。切尔姆诺，一个谋杀之地，在1941年12月开始杀戮。万湖，在1942年1月20日，协调的是一桩已经在进行的罪行。它不是开端。
- 奥斯维辛，由红军在1945年1月27日解放，以及别的杀戮中心，是作为地方被点名的。本课不描述一套程序、一件武器，或一座营地如何运作。
- 罗姆人、在所谓的“安乐死”计划里遭谋杀的残疾人、许多非犹太人的波兰人、苏联战俘，以及别的人，也遭谋杀。没有第二个总数被陈述。那个拒绝不是一个那些谋杀是轻微的论断。
- 莱姆金的*Axis Rule in Occupied Europe*（1944年）使用了种族灭绝这个词。《防止及惩治灭绝种族罪公约》于1948年12月9日通过，在1945年5月9日之后三年又七个月。那个词语与那部法律不是那桩罪行的原因。
- 证据是文献的、证词的与实物的。合作与拯救都发生过。两者都不是一种民族的性格。史家们把针对赫雷罗人与纳马人的那场战事——从1904年10月2日那道命令到1908年——归为灭绝种族罪，这里没有一个死亡总数。
:::

## 习题

:::exercise 不是第一个圆点 {level=1 check="1941"}
对被占领的苏联的大规模枪杀在哪一年开始？（请输入四位数的年份。）
:::solution
大规模枪杀始于1941年的夏天。年份是1941。万湖是1942年，而不是开端。那一次把被占领的苏联向那场枪杀敞开的入侵，是1941年6月22日。
:::
:::

:::exercise 会议的月份 {level=1 check="January"}
万湖会议在1942年的哪个月？（请输入月份。）
:::solution
会议在1942年1月20日。月份是1月。1941年12月，切尔姆诺开始的时候，是上一个月，也是上一年。答案是1月。
:::
:::

:::exercise 公约的年份 {level=1 check="1948"}
联合国大会在哪一年通过《防止及惩治灭绝种族罪公约》？（请输入四位数的年份。）
:::solution
公约于1948年12月9日通过。年份是1948。莱姆金的书籍是1944年。投降是1945年。公约不是谋杀的开端。
:::
:::

:::exercise 这个“约”字在做什么 {level=2}
为什么“约”这个字必须留在六百万犹太人这个数字之内，而为什么这个数字不得扩展到“所有团体”？
:::solution
年表与[[#def-estimate]]把那个数字称为一个估计，为史家们与点名的纪念机构所使用，不是一份凶手们完成的清单。删掉“约”发明了一种完成了的精确。把数字扩展到所有团体，发明了第二个总数，并把波兰的犹太人——他们在犹太人的估计之内——与非犹太人的波兰人，以及罗姆人、残疾人、苏联战俘和别的人混淆起来，他们是被点名而没有数字的。那桩罪行不会因为一个整数是估计的就变得可疑。只有当[[#thm-evidence]]里的证据失灵时，它才会变得可疑。它没有失灵。
:::
:::

:::exercise 一个地方不是一套方法 {level=2}
切尔姆诺在1941年12月开始杀戮，而奥斯维辛在1945年1月27日被解放。关于这两个名字你可以说什么，而又必须不说什么？
:::solution
你可以说两者都是谋杀之地，说杀戮在切尔姆诺的开始早于万湖，而说红军在一个说出的日子解放奥斯维辛。你可以说，关于这样一些地方的证据是文献的、证词的与实物的。你必须不描述一套杀戮的程序、一件武器，或一座营地如何运作。[[#thm-evidence]]把那个拒绝当作负责任的讲授的一部分，而不是那条论断里的一个洞。你还必须不发明一句出自这两个地方中的任何一个人的引语。
:::
:::

:::exercise 词语、罪行、法律 {level=2}
把1941、1944与1948按大规模枪杀、莱姆金的书籍与《灭绝种族罪公约》的次序排好。为什么那本书与那份公约都不能是那场枪杀的原因？
:::solution
大规模枪杀始于1941年的夏天。莱姆金的*Axis Rule in Occupied Europe*在1944年使用了种族灭绝这个词。公约于1948年12月9日通过。一本1944年的书不能引发一场年表已经放在1941年的罪行。一部1948年的公约也不能。从1945年5月9日到1948年12月9日的跨度是三年又七个月，所以那部法律也在投降之后。原因必须早于它们的结果，在[[sources/argument]]给予一条原因的那个意义上。那个词语是一个被提出的范畴，为的是那桩罪行能够被命名。它不是那桩罪行的起源。
:::
:::

:::exercise 修复那句发明的句子 {level=3}
改写[[#ex-invented-start]]里那句发明出来的句子，使万湖、那个估计数字与别的受害者团体各自处于各自的位置。不要添加第二个总数或一套程序。
:::hint
让1941年的夏天与1941年12月早于1942年1月20日。让“约六百万”连着犹太人与估计这个词。点名别的团体而不带整数。在任何一套方法的描述之前停下。
:::
:::solution
一个改写是：大规模枪杀始于1941年的夏天，而切尔姆诺在1941年12月开始杀戮；1942年1月20日，万湖协调那场谋杀而没有开启它；约六百万犹太人遭灭绝，一个估计，而不是一份完成了的清单；罗姆人、在所谓的“安乐死”计划里遭谋杀的残疾人、许多非犹太人的波兰人、苏联战俘与别的人也遭谋杀，这里没有第二个总数被陈述。这个改写不包含一套程序，也不包含一句伪造的引语。如果把万湖移到最前，如果“约”被删掉，或者如果对一个第二团体附上一个数字，它就再次变假。那些就是原来那句的、被拆开以便逐一检验的错误。
:::
:::

:::exercise 什么会构成对那个估计数字的反证 {level=3}
[[#thm-evidence]]说出了什么会构成对“谋杀以这个规模发生过”那条论断的反证。用你自己的话陈述那个反面的证据。然后说一说，为什么一本缺失的凶手账目不是那个反面的证据，以及对一座营地的描述的要求为什么也不是。
:::hint
想想文献、证词与遗址指向同一个方向。一种清单里的一处缺口，不同于一条显示被驱逐的人活着的记录。一套程序不是本课程接受的任何一种证明。
:::
:::solution
会构成对那条论断的反证的，是一份文献的、证词的与实物的记录，它们一起显示被驱逐的人在文书点名的地方活着。记录显示的不是那个。一本单独的账目的缺失，正是那个数字是一个约六百万的估计、而不是一笔结清了了的行政总数的理由。史家们与点名的机构仍然公布那个估计，因为别的记录相吻合。这道缺口是“约”这个字的理由，不是丢弃那个吻合的理由。一个去描述一座营地如何运作的要求，要的是[[#thm-evidence]]拒绝的东西。拒绝它移走的是一本手册。它没有移走那些文献、那些证词或那些遗址。一句发明出来的引语填不上这些角色中的任何一个。它将是一份额外的假文献。
:::
:::
