欧洲战争是如何扩大的，德国又是在何时投降的？它扩大于一系列带着日期的抉择，而不是一场单凭自身分量展开的单独战斗；它终结于一次投降，而这次投降以不同的含义承载着五月的三个日期。德国在1939年9月1日入侵波兰。英国与法国在1939年9月3日宣战。西线的大规模攻势不在那一周。它是1940年5月10日，而法国的停战是1940年6月22日。德国在1941年6月22日入侵苏联，不早不晚，恰好一年之后的同一日。美国是被1941年12月11日的一纸宣战拉进对德战争的，那在12月7日的珍珠港（Pearl Harbor）之后四天。这些句子中没有一句是一种作战技术，也没有一句带着一个伤亡总数。年表没有锁定一个。本章不会发明一个。

投降同样容易被压平，而压平它同样错。1945年5月7日，在兰斯（Reims）签署了一份文书。1945年5月8日，在卡尔斯霍斯特（Karlshorst）签署了一份文书。苏联因为时差而把5月9日作为投降的日子。同时讲授5月8日与5月9日是要求。把5月7日也教出来，才使第一份签字不消失在关于另外两个的争论里。5月9日不是取消5月8日的第三次签署，而5月8日也不是取消5月9日的一次更正。它们是一次失败的几种不同含义。前一章止于1939年8月23日的协定，在那次入侵之前九天。本章从那次入侵开始，停在五月的这些日期上。灭绝种族罪在[[wars/genocide]]。大规模谋杀曾是东方战争的一部分。估计数字与证据在那里讲授，不在这里以一套程序预先给出。

## 一个序列，不是一套技术

1939年9月3日的诸次宣战是真实的，而它们不是西线攻势。从9月1日到9月3日是两天。从1939年9月3日到1940年5月10日是一段长得多的间隔，下文把它算作250天。在那段间隔里，战争不是一片空白，也还不是那一场产出法国停战的战事。波兰被入侵并被占领。8月23日的莫洛托夫-里宾特洛甫（Molotov–Ribbentrop）协定是最直接的政治背景。在9月1日之后的几个星期里，苏联占领了波兰东部的领土。我们不为那次占领锁定一个日子，因为年表没有锁定，所以我们不发明一个。占领已经是1939年的一个事实，在法国签下任何东西之前。

1940年5月10日，德国的西线攻势开始。1940年6月22日，法国签署停战。从5月10日到6月22日是43天：五月有31天，所以10日之后余21天，而6月22日加上22天，但更清楚的数法是5月10日到6月10日为31天，再到6月22日再加十二天，即43。我们说出结果与跨度。我们不把那场战事描述成一套方法。本课程没有任何一课是一份关于一支军队如何击碎另一支军队的手册。1940年6月22日的停战开启了一段时期，其间一个法国政权与之合作，而法国的人们也抵抗。两样对同一个社会都是真的。两样都不是法国的性格。同一个拒绝适用于每一个被占领的国家，也适用于德国自身。

1941年6月22日，德国入侵苏联。这个日期与法国停战共享它的日与月，而不共享它的年。从1940年6月22日到1941年6月22日是365天，不是366。1940年的闰日落在二月，在停战之前，而1941年不是闰年，所以它不落在这十二个月之内。一名读者因为“1940年是闰年”而加上一天，就把二月放错了地方。这次入侵开启了东方的战争。对平民的大规模谋杀是那场战争的一部分。我们这样说一次，而我们把证据与估计数字交给下一课，不在这里描述一套程序。苏联，曾在1939年占领波兰东部，现在是被入侵的国家。1939年8月的协定不是一次永久的结好。它是一次抉择，被另一个抉择在一个说出的日子打破。

战争在1941年12月再次扩大。珍珠港是12月7日。12月11日，德国对美国宣战。这四天是一次太平洋进攻与一个欧洲联盟之间的连接。本章不成为一部太平洋的历史。它记录下那纸使美国成为对德交战国的宣战，而它拒绝把那纸宣战当作欧洲战争的开始。开始，在本课程里，是1939年9月1日。美国在那场更早的战争中的参战是1917年4月，在[[wars/first-world-war]]里讲授。“美国进来了”的押韵不是日期的同一。

:::definition 扩大 {#def-widening}
**扩大**，在本章中，意味着一个新的国家或一条新的战线在一个锁定的日期进入欧洲战争：1940年的西线攻势与法国停战、1941年对苏联的入侵，以及德国于1941年12月11日对美国的宣战。扩大不是一场场战斗变得血流成河的隐喻，也不是陈述一个伤亡总数的许可证。
:::

:::definition 占领 {#def-occupation}
**占领**是对被击败或被入侵的领土的一套统治。它与同一个社会之内、有时是同一条生命之内的合作与抵抗并存。它不是一个民族可以被归入其中的道德类型，也不是一套作战的技术。
:::

:::theorem 战争因带着日期的抉择而扩大 {#thm-widen}
欧洲战争从1939年9月1日的入侵波兰，经由1940年5月10日的西线攻势、1941年6月22日对苏联的入侵，以及德国于1941年12月11日对美国的宣战而扩大。这些是带着日期的抉择。它们不是一场战斗，也不是一份手册。
:::
:::proof
证据是这些锁定日期的顺序，与它们之间的间隔。英国与法国在1939年9月3日宣战，在入侵之后两天，而西线攻势等到1940年5月10日。法国的停战是1940年6月22日。对苏联的入侵是1941年6月22日，365天之后。珍珠港是1941年12月7日，而德国的宣战是12月11日，四天之后。会构成对这条论断的反证的，是这样一份史料：这些是一个中间没有决定的连续行动，或者西线攻势在1939年9月第一周有一个锁定的开始。年表把它们分开。不会构成对它的反证的，是一份详细记述某支部队在其中一天如何作战的记述。这样的记述可以在它自己的尺度上为真，而仍然不是那个扩大。[[sources/scale]]适用。我们也拒绝伤亡总数。一个总数不是这些日期中的一个，而发明它不能证明这个顺序。
:::

:::theorem 以不同的含义讲授5月7日、8日与9日 {#thm-may}
德国的投降于1945年5月7日在兰斯签署，于1945年5月8日在卡尔斯霍斯特签署。苏联因为时差而把5月9日作为投降的日子。5月8日与5月9日都应当讲授。5月9日不是第三次签署，而两个公开日期都不把另一个纠正到不存在。
:::
:::proof
年表区分这些行为。兰斯是一份签字，在5月7日。卡尔斯霍斯特是另一份，在5月8日。苏联的纪念落在5月9日，因为相对于签字，莫斯科的历日已经是第二天。我们不发明钟点。时差是锁定的原因，而它够了。会构成对这条论断的反证的，是这样的证据：这些日期中只有一个发生过，或者5月9日是一场与卡尔斯霍斯特文书相矛盾的单独仪式，而不是它的历法后果。同样会构成对一个马虎版本的反证的，是任何一个说5月7日是迷思的论断。它是兰斯的签字。不会判定这条论断的，是只纪念其中一个日子的民族习惯。习惯是事后记忆的证据。那些文书才是投降的证据。把一个纪念纠正到不存在，是隔了一层地重复本课程在[[wars/revolutions-1917]]里对1917年的两种历法所拒绝的那个错误：一个真实的第二标签不是一个错误。
:::

:::quiz
哪一句话让五月的日期保持在它们的不同的含义里？
- [ ] 德国在5月8日投降，所以5月9日是一个错误，而5月7日不曾发生。
- [ ] 有三场互不相干的投降，在5月7、8、9日，对三个不同的敌人。
- [x] 兰斯是1945年5月7日，卡尔斯霍斯特是1945年5月8日，而苏联因为时差而把5月9日作为投降的日子。
- [ ] 唯一要紧的投降是1940年6月22日的法国停战。
:::solution
第三句话是[[#thm-may]]。第一句删掉了两个锁定的日期，其中一个是签字，另一个是带着一个已说明的原因的纪念。第二句发明了三个互不相干的投降。签字有两份，第三个历法标签是时钟造成的。法国的停战是1940年6月22日，在扩大的早期，不是德国的失败。
:::
:::

## 可以重算的间隔

扩大是一组跨度。每一段跨度都拦住一个把战争熔成一个星期或一套方法的故事。

:::example 两天，然后是二百五十天 {#ex-two-gaps}
德国在1939年9月1日入侵波兰。英国与法国在1939年9月3日宣战。西线攻势在1940年5月10日开始。从9月1日到9月3日隔着多少天？从1939年9月3日到1940年5月10日隔着多少天？1940年是闰年。1939年不是。
:::solution
从9月1日到9月3日是2天。对较长的间隔，1939年9月3日是一个非闰年的第246天：一月到八月有243天，加上3。从9月4日到12月31日的天数是365 − 246 = 119。在闰年1940年，5月10日是第131天：一月31、二月29、三月31、四月30，再加10，给出31 + 29 + 31 + 30 + 10 = 131。于是119 + 131 = 250。攻势在英国与法国的诸次宣战之后250天，而那些宣战在对波兰的入侵之后2天。这250天的间隔不是一段虚假的空无。它是一纸宣战与一次较晚的攻势之间的距离。我们不用一个伤亡总数来填充它。
:::
:::

:::example 同一天同一个月，一年之后 {#ex-june-pair}
法国的停战是1940年6月22日。德国在1941年6月22日入侵苏联。它们之间隔着多少天？为什么1940年的闰日没有让答案成为366？
:::solution
闰日是1940年2月29日，它在1940年6月22日之前，所以不在跨度之内。下一个闰日在1944年。因此从1940年6月22日到1941年6月22日是一个平年，365天。两个日期共享一个日与一个月，而不得被合并。一个是停战，它使法国退出战斗，作为一个1940年签字者的那种交战国。另一个是对苏联的战争的开端。一个只记得“6月22日”的读者，已经弄丢了扩大。
:::
:::

:::example 斯大林格勒的两个日期，华沙的跨度 {#ex-two-ends}
年表把德国的投降定在斯大林格勒的1943年1月31日与1943年2月2日。2月2日在1月31日之后多少天？华沙（Warsaw）起义从1944年8月1日打到1944年10月2日。10月2日在8月1日之后多少天，而如果两端都数，你会得到什么不同的数？
:::solution
从1月31日到2月2日是2天。两个日期都属于斯大林格勒的投降。只保留其中一个是不完整的，而我们不给任何一天指派超出年表所说的东西，年表说的就是投降本身。我们也不陈述一个死亡总数。从8月1日到10月2日：八月有31天，所以8月1日之后余30天，九月有30天，而10月2日加上2天。30 + 30 + 2 = 62。所以10月2日在8月1日之后62天。把两端都算在内的计数是63。年表的措辞是一个从-到区间，而这些日期之差是62。起义是一座被占领的城市里的一次暴动。它不是波兰的性格，也不是一份巷战手册。它在10月2日结束，而没有成为那座城市的解放。红军后来的推进是一个不同的事实。我们不在这段区间之外发明一个城市解放的日子。
:::
:::

:::example 一句发明出来的单一胜利日 {#ex-invented-may}
下面这句话为示例而虚构。它不是史料。“德国投降过一次，在1945年5月8日，这使5月7日成为一个传言、5月9日成为一个政治虚构，而那场失败是一场西面登陆的结果。”什么被删掉了？那次登陆的真实日期必须先做过什么，才能驮得起那个结论？
:::solution
这句话是虚构的。它删掉了5月7日的兰斯签字与5月9日的苏联纪念，违反了[[#thm-may]]。它还把1944年6月6日的诺曼底（Normandy）登陆变成了那场失败的唯一原因，而那场失败还包括东方的战争、1943年初的斯大林格勒（Stalingrad），以及1944年7月20日那次失败的密谋。从6月6日到7月20日是44天：六月有30天，所以6日之后余24天，而7月20日加上20天，或者从6月6日到7月6日是30天，再加14天，即44。密谋失败。它的失败不是证明德国没有人反对那个政权，而它的存在也不是证明那个政权即将垮台。登陆是1944年6月6日，不是1945年5月的投降，也不是一套技术。要驮起那个发明出来的结论，诺曼底必须是1943年之后仍在战斗的唯一战线。它不是。苏联战线继续着。雅尔塔（Yalta），在1945年2月，是投降之前盟国之间的一次会议，不是投降。
:::
:::

从斯大林格勒到五月的这些日期之间，战争不会为了照顾一幅图形而暂停。斯大林格勒的投降是1943年1月31日与2月2日。诺曼底登陆是1944年6月6日。一场针对希特勒（Hitler）的密谋在1944年7月20日失败。华沙起义从1944年8月1日打到10月2日。雅尔塔在1945年2月开会。奥斯维辛（Auschwitz）由红军在1945年1月27日解放。最后这个日期记在这里，只是作为东方推进的一个日期。那个地方是什么，以及对被谋杀者的估计是什么，属于[[wars/genocide]]。我们不描述那个地方。五月的那些投降文书在希特勒死后签署。年表没有锁定那个死的日子，所以我们不发明一个。本课程里德国战争的锁定终点，是兰斯、卡尔斯霍斯特，以及苏联的纪念。

占领是坐落在这些日期之下的体制，也是道德归类造成最大伤害的地方。一个国家可以被占领，而其中仍然有与之合作的官员、藏匿被迫害者的邻居，以及告发他们的邻居。有时一条生命做了其中不止一样。这些类别是史家们的标签，而在战后，也是法律的标签。它们不是民族性格。1940年6月22日之后的法国是那个做过功课的案例，不是因为法国独一无二地混杂，而是因为停战、一个合作的政权、与抵抗都有文献记录，而它们之中没有一个取消其余的。被占领下的波兰产出了华沙起义，也产出了起义所不尽涵盖的一切别的行止。德国产出了那个政权、7月20日那次失败的密谋，以及既不归于密谋也不归于领导层的行止。苏联在1941年被入侵，此前它在1939年占领了波兰东部。英国在1939年9月3日宣战，而它并不因此就清白于帝国。本课程不把民族归类成有罪的与无辜的。会构成对那个拒绝的反证的，是一份记录，显示一个国家里的每一个人整场战争都落在一个类别里。法庭卷宗、行政文书与回忆录不显示那个。一份回忆录仍然不是一次普查。[[sources/evidence]]限定了单条生命能够证明什么，这就是为什么[[#def-occupation]]说的是一套体制与一个社会，不是一个民族的灵魂。

:::quiz
把6月22日称为法国停战的日期与入侵苏联的日期、而不带年份，有什么错？
- [ ] 什么也没有。这两个事件是同一个扩大。
- [x] 停战是1940年6月22日，而入侵是1941年6月22日，365天之后。共享的日与月，在年份被丢掉时藏起了两个事件。
- [ ] 两个事件都在1939年，在诸次宣战之前。
- [ ] 1941年6月22日是卡尔斯霍斯特的签署。
:::solution
年份就是分别。[[#ex-june-pair]]显示一段365天的跨度，并解释了为什么1940年二月的闰日不落进它之内。卡尔斯霍斯特是1945年5月8日。英国与法国对德国的宣战在1939年9月3日。丢掉年份，就是一份目录页的习惯抹掉[[#thm-widen]]为之而存在的扩大的方式。
:::
:::

把窗口设为零，移动年份。每个圆点是一个目录词。1939年的“波兰”显示不出直到英国与法国的诸次宣战的那两天，也显示不出直到西线攻势的那250天。1940年的“法国”显示不出5月10日与6月22日相隔43天，也显示不出占领、合作与抵抗此后如何共存。1941年的“苏联”显示不出6月22日相对于12月7日与11日。1943年的“斯大林格勒”显示不出两个投降日期，1月31日与2月2日。1944年的“诺曼底与华沙”显示不出6月6日、7月20日、8月1日与10月2日作为一个次序。1945年的“投降”显示不出5月7、8、9日。这幅图形是本课拒绝成为一场单独战斗的决心的地图。如果你要五月的这些含义，你必须离开圆点，使用[[#thm-may]]。

:::warning 一个胜利日，以及每个民族一种道德类型
两个迷思互相加固。第一个挑出1945年5月的一个日子，并把其余日期叫作错误。5月7日的兰斯与5月8日的卡尔斯霍斯特是签字。5月9日的苏联纪念是时差，不是一个虚构，也不是一场第三战争。第二个迷思把每个民族归进有罪的或无辜的：一个抵抗者的民族，一个合作者的民族，一个其军队就是它的全部行止的民族。占领是一套统治的体制。合作与抵抗都发生过，包括在一个社会之内。1944年7月20日那次失败的密谋不为德国宣告无罪，而它确实证明反对不是想象出来的。华沙起义不穷尽波兰。在本章里没有可用的伤亡总数来颁给道德的奖品。即使一个总数曾被锁定，它也不曾做过那样的工作。
:::

德国在1939年9月1日入侵波兰。英国与法国在9月3日宣战。西线攻势在1940年5月10日开始，而法国的停战是1940年6月22日。德国在1941年6月22日入侵苏联。德国的投降于1945年5月7日在兰斯签署，于1945年5月8日在卡尔斯霍斯特签署。苏联因为时差而把5月9日作为投降的日子。
:::

历史注记是一个次序，而次序就是论证。把它与图形对照着读，间隔就打开了。从入侵到西面的诸次宣战是两天。从那些宣战到1940年5月10日是二百五十天。到法国的停战是四十三天。到对苏联的入侵是三百六十五天。然后是斯大林格勒在1943年的两个日期、1944年的诺曼底与一次失败的密谋与华沙、1945年2月的雅尔塔，以及五月的签字。会构成对[[#thm-widen]]的反证的，是一个把西线攻势放在1939年9月第一周的锁定日期，或者一个把美国宣战放在珍珠港之前的锁定日期。会构成对[[#thm-may]]的反证的，是一份既是唯一签字、又是唯一纪念的单独文书。不会构成对任何一条论断的反证的，是一部只展示一场登陆与一面旗帜的电影。电影是一种尺度。日期是另一种。

东方战争的大规模谋杀，是本章不会推开的那道枢轴。我们说过，它是1941年6月22日之后那场战争的一部分；也说过下一课保存着对被谋杀的犹太人的估计、万湖（Wannsee）不是一个开端的理由，以及反对第二个发明总数的规则。以一套程序预先给出那一课，会打破它的头一条规则。在读者想着别的事情的时候塞进一个士兵的伤亡总数，也会。“死了许多人”仍然是可以说的。一个精确的整数不是。

## 通向何处

估计数字、证据与种族灭绝这个词，在[[wars/genocide]]。投降之后的政治分裂，包括1945年7月与8月的波茨坦（Potsdam），在[[postwar/division]]。那次入侵之前的协定与任命，在[[wars/interwar]]。1917年的双重纪日，本章把它当作1945年5月之事的平行案例，在[[wars/revolutions-1917]]。

:::summary
- 德国在1939年9月1日入侵波兰。英国与法国在9月3日宣战，两天之后。西线攻势是1940年5月10日，在那些宣战之后250天，而法国的停战是1940年6月22日，在攻势之后43天。
- 苏联在1939年9月1日之后的几个星期里占领波兰东部。那一步没有锁定一个日子。德国在1941年6月22日入侵苏联，在法国的停战之后365天。1940年的闰日不落在那一年之内。
- 珍珠港是1941年12月7日。德国在12月11日对美国宣战。那扩大了联盟。它没有开启欧洲战争。
- 斯大林格勒的投降定在1943年1月31日与2月2日。诺曼底是1944年6月6日。一场针对希特勒的密谋在1944年7月20日失败，在登陆之后44天。华沙起义从1944年8月1日打到10月2日。
- 占领、合作与抵抗共存于单个社会之中。本课程不把任何一个民族归类成一种道德类型，也不陈述任何伤亡总数。
- 投降：1945年5月7日的兰斯，1945年5月8日的卡尔斯霍斯特，苏联因为时差在5月9日作为投降的日子纪念。5月8日与5月9日都要教。东方的大规模谋杀在这里被承认，而在下一课讲授。
:::

## 习题

:::exercise 入侵的年份 {level=1 check="1939"}
德国在哪一年入侵波兰？（请输入四位数的年份。）
:::solution
入侵是1939年9月1日。年份是1939。法国的停战是1940年，对苏联的入侵是1941年。
:::
:::

:::exercise 两纸宣战 {level=1 check="2"}
英国与法国在1939年9月1日之后多少天宣战？（请输入天数。）
:::solution
他们在1939年9月3日宣战。从9月1日到9月3日是2天。西线攻势不在这些日子中的第二天。它是1940年5月10日。
:::
:::

:::exercise 入侵苏联的年份 {level=1 check="1941"}
德国在哪一年入侵苏联？（请输入四位数的年份。）
:::solution
入侵是1941年6月22日。年份是1941。法国的停战同样在一个6月22日，是1940年。珍珠港与德国对美国的宣战也在1941年，在十二月，而它们不是这次入侵。
:::
:::

:::exercise 5月9日是什么 {level=2}
说出1945年5月7日、8日与9日发生了什么，并说出三者之中哪一个不是签署。
:::solution
1945年5月7日，在兰斯签署了一份投降文书。1945年5月8日，在卡尔斯霍斯特签署了另一份。苏联因为时差而把5月9日作为投降的日子。5月9日的纪念不是第三次签署。[[#thm-may]]要求5月8日与5月9日都被讲授，而5月7日不被当作传言丢掉。发明签字的钟点是不必要的。年表给出原因，即时差，而扣住钟面。
:::
:::

:::exercise 占领不是一种性格 {level=2}
使用1940年6月22日之后的法国，解释[[#def-occupation]]，使你的讲法同时拦住“一个合作者的民族”与“一个抵抗者的民族”。
:::solution
1940年6月22日的停战之后是占领，是一个合作的政权，也是抵抗。两者在一个社会之内都有文献记录。把法国叫作合作者的民族，抹掉了抵抗。把法国叫作抵抗者的民族，抹掉了合作。同一个拦截适用于别处：华沙起义不穷尽波兰，1944年7月20日那次失败的密谋不穷尽德国。[[#def-occupation]]是一条关于一套统治体制与混杂行止的论断。它不是对灵魂的普查，而一份回忆录也变不成一次普查。
:::
:::

:::exercise 那段365天的跨度拒绝了什么 {level=2}
以1940年是闰年为理由，给1940年6月22日与1941年6月22日之间的那一年加上一天，为什么是错误？这个错误助长什么历史的合并？
:::solution
1940年2月29日落在1940年6月22日之前，所以它在跨度之外。1941年不是闰年。跨度是365天，如[[#ex-june-pair]]。加一天会把二月放错地方。历史的合并，是把“6月22日”当作一个事件。停战与对苏联的入侵相隔一年，在[[#thm-widen]]里做不同的工作。1939年的协定曾使德国与苏联结好。入侵打破了那个抉择。一个闰日的错误是小的。它搭载着的那个合并不是。
:::
:::

:::exercise 两端都算，还是日期之差 {level=3}
华沙起义定在1944年8月1日到1944年10月2日。一名读者报告63天。另一名报告62。两名读者各自回答了什么问题？哪个数是这些日期之差？
:::hint
数从8月1日之后、直到你抵达10月2日的天数，这排除了起始日。然后问一问：如果8月1日与10月2日都包括在一次对触及的历日的清点里，什么会改变。
:::
:::solution
这些日期之差是62。八月贡献8月1日之后的30天，九月贡献30天，而10月2日贡献2天：30 + 30 + 2 = 62。说62的读者回答了“10月2日在8月1日之后多少天？”说63的读者把两端都算了进来，数了这段区间触及的每一个历日。两种算术习惯都是真实的。年表的从-到措辞是一个区间，而本章对差值使用62，如[[#ex-two-ends]]。两个数都不是死亡总数，也都不把起义变成波兰的性格。暴动在1944年10月2日结束。它不是1945年5月的德国投降。
:::
:::

:::exercise 一个被归类的民族 {level=3}
下面这句话为示例而虚构。它不是史料。“因为英国与法国的部队在1944年6月6日在诺曼底登陆，所以法国作为一个民族进行了抵抗，波兰作为一个民族进行了抵抗，而德国作为一个民族没有，因此每一个人民对于整场战争都有一种道德类型。”要让这个归类存活下来，记录必须怎么样？哪些锁定的日期已经在阻碍它？
:::hint
使用1940年6月22日的停战、1944年7月20日的密谋，以及华沙的那些日期。问一问一场登陆能否给三个人民指派一种性格。[[#def-occupation]]是要检验的定义，不是一份战斗的叙事。
:::
:::solution
这句话是虚构的。要让它存活下来，记录必须显示每个国家里的每一个人整场战争都在一个类别之内。它们不显示那个。1940年6月22日停战之后的法国有一个合作的政权，也有抵抗，所以一次1944年的登陆不能追溯地给法国一种类型。1944年8月1日到10月2日的华沙起义是真实的，而它不穷尽波兰人在占领下的行止。1944年7月20日的密谋失败了，它显示了德国人的反对，而既不为那个政权宣告无罪，也不界定每一个德国人。诺曼底在那次密谋之前44天，而不是一次道德的普查。[[#def-occupation]]拦住了这个归类。本课程把民族分成有罪的与无辜者的那个拒绝也拦住了它。年表里没有任何伤亡总数在等着代做这个归类。
:::
:::
