欧洲战争是如何扩大的？德国又是何时投降的？战争是通过一系列有日期的抉择扩大的，而不是由一场战役凭自身的分量展开；它终结于一次投降，而这次投降在不同意义上对应着五月的三个日期。1939年9月1日，德国入侵波兰。1939年9月3日，英国与法国宣战。西线的大规模攻势并不在那一周，而是在1940年5月10日；法国的停战则在1940年6月22日。1941年6月22日，德国入侵苏联，恰好是一年后的同一天。1941年12月11日的一纸宣战，把美国拉进了对德战争，那是在12月7日珍珠港（Pearl Harbor）事件之后四天。这些句子都不涉及作战技术，也都不附带伤亡总数。年表没有锁定这样的总数，本章也不会编造。

投降同样容易被压平，而压平它同样是错误的。1945年5月7日，一份文件在兰斯（Reims）签署；1945年5月8日，一份文件在卡尔斯霍斯特（Karlshorst）签署。由于时差，苏联以5月9日为投降之日。5月8日与5月9日都必须讲授；同时讲授5月7日，才能使第一次签字不至于消失在关于另外两个日期的争论之中。5月9日不是取消5月8日的第三次签署，5月8日也不是取消5月9日的更正。它们是同一次失败的不同意义。上一章止于1939年8月23日的条约，即入侵前九天；本章从那次入侵开始，止于五月的这几个日期。种族灭绝见[[wars/genocide]]。大规模屠杀是东线战争的组成部分；估计数字与证据在那里讲授，这里不以某种程序加以预告。

## 是一系列事件，而不是一套技术

1939年9月3日的宣战是真实的，但它们不是西线攻势。从9月1日到9月3日是两天。从1939年9月3日到1940年5月10日则是长得多的间隔，下文算出是250天。在这段间隔里，战争并非一片空白，但也还不是导致法国停战的那场战役。波兰遭到入侵并被占领。8月23日的《莫洛托夫-里宾特洛甫（Molotov–Ribbentrop）条约》是最直接的政治背景。9月1日之后的几周里，苏联占领了波兰东部的领土。年表没有为这次占领锁定日期，因此我们不予编造。在法国签署任何文件之前，占领在1939年就已是事实。

1940年5月10日，德国在西线发动攻势。1940年6月22日，法国签署停战协定。从5月10日到6月22日是43天：五月有31天，10日之后还剩21天，6月22日再加22天；更清楚的算法是5月10日到6月10日为31天，再到6月22日加十二天，得43天。我们说明结果与跨度，但不把这场战役描述为一种方法。本课程没有任何一课是讲一支军队如何击溃另一支军队的手册。1940年6月22日的停战开启了一个时期：一个法国政权与德国合作，法国境内的人们也进行了抵抗。两者对同一个社会都成立，两者都不是法国的民族性格。同样的拒绝适用于每一个被占领的国家，也适用于德国本身。

1941年6月22日，德国入侵苏联。这个日期与法国停战同月同日，却不同年。从1940年6月22日到1941年6月22日是365天，而不是366天。1940年的闰日在二月，早于停战，而1941年不是闰年，所以这十二个月中没有闰日。以“1940年是闰年”为由加上一天的读者，是把二月放错了位置。这次入侵开启了东线战争。对平民的大规模屠杀是这场战争的组成部分。我们在此只说一次，把证据与估计数字留给下一章，而不在这里描述某种程序。1939年曾占领波兰东部的苏联，如今成了被入侵的国家。1939年8月的条约并不是永久的结盟，而是一个选择，在一个明确的日子被另一个选择打破。

1941年12月，战争再度扩大。珍珠港事件发生在12月7日；12月11日，德国对美国宣战。这四天把太平洋上的一次进攻与欧洲的联盟连接了起来。本章不会变成一部太平洋史，只记录使美国成为对德交战国的那纸宣战，并拒绝把这纸宣战当作欧洲战争的开端。在本课程中，开端是1939年9月1日。美国在上一场战争中的参战是1917年4月，见[[wars/first-world-war]]。“美国参战了”的相似说法，并不意味着日期相同。

:::definition 扩大 {#def-widening}
本章所说的**扩大**，指一个新的国家或一条新的战线在锁定的日期加入欧洲战争：1940年的西线攻势与法国停战，1941年对苏联的入侵，以及1941年12月11日德国对美国宣战。扩大不是战斗愈加血腥的隐喻，也不是给出伤亡总数的许可。
:::

:::definition 占领 {#def-occupation}
**占领**是对战败或被入侵领土的一种统治体制。在同一个社会中，有时甚至在同一个人身上，它与合作和抵抗并存。它不是可以用来给一个民族归类的道德类型，也不是一种作战技术。
:::

:::theorem 战争因有日期的抉择而扩大 {#thm-widen}
欧洲战争从1939年9月1日入侵波兰开始，经由1940年5月10日的西线攻势、1941年6月22日对苏联的入侵以及1941年12月11日德国对美国宣战而扩大。这些都是有日期的抉择，既不是一场战役，也不是一本手册。
:::
:::proof
证据在于这些锁定日期的顺序以及它们之间的间隔。英国与法国在入侵两天后的1939年9月3日宣战，西线攻势则一直等到1940年5月10日。法国停战在1940年6月22日。入侵苏联在1941年6月22日，即365天之后。珍珠港事件在1941年12月7日，德国宣战在四天之后的12月11日。能够推翻这一论断的，是这样一份史料：它表明这些是一个中间没有任何决定的连续行动，或者西线攻势在1939年9月第一周就有锁定的开始日期。年表把它们区分开来。不能推翻这一论断的，是对某支部队在其中某一天如何作战的详细记述。这样的记述在它自己的尺度上可能为真，却仍然不是战争的扩大。[[sources/scale]]在此适用。我们也拒绝伤亡总数。总数不是这些日期之一，编造它也不能证明这一顺序。
:::

:::theorem 在不同意义上讲授5月7日、8日与9日 {#thm-may}
德国的投降书于1945年5月7日在兰斯签署，于1945年5月8日在卡尔斯霍斯特签署。由于时差，苏联以5月9日为投降之日。5月8日与5月9日都应讲授。5月9日不是第三次签署，两个公开的日期也都不能把对方“纠正”掉。
:::
:::proof
年表把这些行为区分开来。兰斯是一次签字，在5月7日；卡尔斯霍斯特是另一次，在5月8日。苏联的纪念日落在5月9日，因为相对于签字时刻，莫斯科的日期已是第二天。我们不编造具体钟点。时差是锁定的原因，这就足够了。能够推翻这一论断的，是这样的证据：这些日期中只有一个确有其事；或者5月9日是一场与卡尔斯霍斯特文件相矛盾的单独仪式，而不是其历法上的结果。同样能够驳斥一种草率说法的，是任何声称5月7日是迷思的论断——它就是兰斯的签字。不能裁决这一论断的，是某国只纪念其中一天的习惯。习惯是事后记忆的证据，文件才是投降的证据。把一个纪念日“纠正”掉，就是以间接的形式重复本课程在[[wars/revolutions-1917]]中针对1917年两种历法所拒绝的错误：一个真实的第二标签并不是错误。
:::

:::quiz
下列哪一种说法使五月的日期各自保持其不同的意义？
- [ ] 德国在5月8日投降，所以5月9日是错误，5月7日根本没有发生。
- [ ] 5月7日、8日、9日有三次互不相关的投降，对象是三个不同的敌人。
- [x] 兰斯是1945年5月7日，卡尔斯霍斯特是1945年5月8日，苏联由于时差以5月9日为投降之日。
- [ ] 唯一有意义的投降是1940年6月22日的法国停战。
:::solution
第三种说法就是[[#thm-may]]。第一种删掉了两个锁定的日期，其中一个是签字，另一个是有明确原因的纪念日。第二种编造了三次互不相关的投降：签字只有两次，第三个历法标签是时钟造成的。法国停战在1940年6月22日，处于战争扩大的早期，并不是德国的失败。
:::
:::

## 可以重新计算的间隔

战争的扩大是一组跨度。每一段跨度都能挡住一种把战争熔铸为一周或一种方法的叙事。

:::example 两天，然后是二百五十天 {#ex-two-gaps}
德国于1939年9月1日入侵波兰，英国与法国于1939年9月3日宣战，西线攻势始于1940年5月10日。9月1日与9月3日相隔多少天？1939年9月3日与1940年5月10日相隔多少天？1940年是闰年，1939年不是。
:::solution
从9月1日到9月3日是2天。至于较长的间隔，1939年9月3日是非闰年的第246天：一月至八月共243天，再加3。从9月4日到12月31日共365 − 246 = 119天。在闰年1940年，5月10日是第131天：一月31天、二月29天、三月31天、四月30天，再加10天，即31 + 29 + 31 + 30 + 10 = 131。于是119 + 131 = 250。攻势在英法宣战之后250天，而英法宣战在入侵波兰之后2天。这250天的间隔并不是一段虚假的空白，而是一纸宣战与一次后来的攻势之间的距离。我们不用伤亡总数去填充它。
:::
:::

:::example 同月同日，相隔一年 {#ex-june-pair}
法国停战在1940年6月22日，德国于1941年6月22日入侵苏联。两者相隔多少天？为什么1940年的闰日不会使答案成为366？
:::solution
闰日是1940年2月29日，早于1940年6月22日，所以不在这段跨度之内。下一个闰日在1944年。因此，从1940年6月22日到1941年6月22日是一个平年，即365天。两个日期同月同日，却不得合并：一个是停战，使法国作为1940年签字的那种交战国退出了战斗；另一个是对苏战争的开端。只记得“6月22日”的读者，就弄丢了战争的扩大。
:::
:::

:::example 斯大林格勒的两个日期与华沙的跨度 {#ex-two-ends}
年表把德军在斯大林格勒的投降定于1943年1月31日与1943年2月2日。2月2日在1月31日之后多少天？华沙（Warsaw）起义从1944年8月1日持续到1944年10月2日。10月2日在8月1日之后多少天？如果把首尾都算在内，你会得到什么不同的数字？
:::solution
从1月31日到2月2日是2天。两个日期都属于斯大林格勒的投降，只保留其中一个是不完整的。除了年表所说的投降本身，我们不为任何一天指定更多内容，也不给出死亡总数。从8月1日到10月2日：八月有31天，8月1日之后还剩30天；九月有30天；10月2日再加2天。30 + 30 + 2 = 62。所以10月2日在8月1日之后62天。如果把首尾都算在内，是63天。年表的表述是一个“从……到……”的区间，两个日期之差是62。这次起义是一座被占领城市中的起事，既不是波兰的民族性格，也不是巷战手册。它在10月2日结束，并没有使这座城市获得解放。红军后来的推进是另一回事。我们不在这一区间之外编造这座城市的解放日期。
:::
:::

:::example 编造的唯一胜利日 {#ex-invented-may}
下面这句话为示例而虚构。它不是史料。“德国只投降过一次，就是在1945年5月8日，所以5月7日只是传言，5月9日是政治虚构，而这次失败是西线一次登陆的结果。”这句话删掉了什么？这次登陆的真实日期必须先满足什么条件，才能撑得起那个结论？
:::solution
这句话是虚构的。它删掉了5月7日的兰斯签字与5月9日的苏联纪念日，违背了[[#thm-may]]。它还把1944年6月6日的诺曼底（Normandy）登陆当作这次失败的唯一原因，而这次失败还包括东线战争、1943年初的斯大林格勒（Stalingrad），以及1944年7月20日失败的密谋。从6月6日到7月20日是44天：六月有30天，6日之后还剩24天，7月20日再加20天；或者6月6日到7月6日为30天，再加14天，得44天。密谋失败了。它的失败并不能证明德国无人反对这一政权，它的存在也不能证明这一政权即将垮台。登陆是在1944年6月6日，而不是1945年5月的投降，也不是一种技术。要撑得起那个编造的结论，诺曼底就必须是1943年之后唯一仍在作战的战线，而事实并非如此：苏联战线仍在继续。1945年2月的雅尔塔（Yalta）会议是投降之前盟国之间的会议，而不是投降。
:::
:::

在斯大林格勒与五月的那几个日期之间，战争并不会为了迁就一张图而暂停。斯大林格勒的投降在1943年1月31日与2月2日。诺曼底登陆在1944年6月6日。一次针对希特勒（Hitler）的密谋于1944年7月20日失败。华沙起义从1944年8月1日持续到10月2日。雅尔塔会议在1945年2月举行。奥斯维辛（Auschwitz）于1945年1月27日由红军解放。最后这个日期在这里只作为东线推进的日期记录下来；那个地方是什么，被害者的估计数字是多少，属于[[wars/genocide]]。我们不描述那个地方。五月的投降文件签署于希特勒死后。年表没有锁定他的死亡日期，因此我们不予编造。在本课程中，德国战争锁定的终点是兰斯、卡尔斯霍斯特以及苏联的纪念日。

占领是位于这些日期之下的体制，也是道德归类危害最大的地方。一个国家可以被占领，其中仍有与占领者合作的官员、藏匿受迫害者的邻居，以及告发他们的邻居。有时，同一个人做了不止其中一件事。这些类别是史家的标签，战后也成了法律的标签，而不是民族性格。1940年6月22日之后的法国是本章的完整案例，并不是因为法国格外混杂，而是因为停战、一个合作的政权与抵抗都有文献记录，而且没有一个能抵消其余。被占领的波兰既产生了华沙起义，也产生了起义所不能涵盖的其他种种行为。德国既产生了这一政权、7月20日失败的密谋，也产生了既不属于密谋、也不属于领导层的种种行为。苏联在1939年占领了波兰东部，又在1941年遭到入侵。英国于1939年9月3日宣战，却并不因此就在帝国问题上清白无辜。本课程不把各民族分为有罪与无辜两类。能够推翻这一拒绝的，是这样一份记录：一个国家的每一个人在整场战争中都只属于一个类别。法庭卷宗、行政文书与回忆录都没有显示这一点。一部回忆录仍然不是普查。[[sources/evidence]]限定了一个人的生平能够证明什么，因此[[#def-occupation]]谈论的是一种体制与一个社会，而不是一个民族的灵魂。

:::quiz
不标年份地把6月22日称为法国停战与入侵苏联的日期，错在哪里？
- [ ] 没有错。两个事件是同一次扩大。
- [x] 停战是1940年6月22日，入侵是1941年6月22日，相隔365天。去掉年份，相同的月日就会掩盖两个事件。
- [ ] 两个事件都发生在1939年，早于宣战。
- [ ] 1941年6月22日是卡尔斯霍斯特签字之日。
:::solution
区别就在年份。[[#ex-june-pair]]展示了一段365天的跨度，并解释了为什么1940年二月的闰日不在其中。卡尔斯霍斯特签字在1945年5月8日。英国与法国对德宣战在1939年9月3日。丢掉年份，就是以目录式的习惯抹去[[#thm-widen]]所要守护的那种扩大。
:::

把窗口设为零，然后移动年份。每个数据点都只是一个目录词。1939年的“波兰”显示不出到英法宣战的那两天，也显示不出到西线攻势的那250天。1940年的“法国”显示不出5月10日与6月22日相隔43天，也显示不出此后占领、合作与抵抗如何并存。1941年的“苏联”显示不出6月22日与12月7日、11日的对照。1943年的“斯大林格勒”显示不出1月31日与2月2日这两个投降日期。1944年的“诺曼底与华沙”显示不出6月6日、7月20日、8月1日与10月2日的先后顺序。1945年的“投降”显示不出5月7日、8日、9日。这张图标示的是本章拒绝成为单一战役的立场。如果你要了解五月的各种意义，就必须离开数据点，使用[[#thm-may]]。

:::warning 唯一的胜利日，以及每个民族一种道德类型
有两种迷思相互强化。第一种从1945年5月挑出一天，把其余日期称为错误。然而，5月7日的兰斯与5月8日的卡尔斯霍斯特都是签字；5月9日的苏联纪念日源于时差，既不是虚构，也不是第三场战争。第二种迷思把每个民族归入有罪或无辜：一个抵抗者的民族，一个合作者的民族，一个其军队就代表其全部行为的民族。占领是一种统治体制。合作与抵抗都发生过，包括在同一个社会之中。1944年7月20日失败的密谋并不能为德国开脱，却确实证明反对并非虚构。华沙起义也不能涵盖整个波兰。本章没有任何伤亡总数可以用来颁发道德奖项；即使锁定了总数，它也起不到这样的作用。
:::

1939年9月1日，德国入侵波兰。9月3日，英国与法国宣战。西线攻势始于1940年5月10日，法国停战在1940年6月22日。1941年6月22日，德国入侵苏联。德国的投降书于1945年5月7日在兰斯签署，于1945年5月8日在卡尔斯霍斯特签署。由于时差，苏联以5月9日为投降之日。
:::

这则历史注记是一个顺序，而顺序就是论证。把它与图示对照着读，间隔就显现出来：从入侵到英法宣战是两天；从宣战到1940年5月10日是二百五十天；到法国停战是四十三天；到入侵苏联是三百六十五天；然后是1943年斯大林格勒的两个日期，1944年的诺曼底、一次失败的密谋与华沙，1945年2月的雅尔塔，以及五月的签字。能够推翻[[#thm-widen]]的，是一个把西线攻势放在1939年9月第一周的锁定日期，或者一个把美国宣战放在珍珠港事件之前的锁定日期。能够推翻[[#thm-may]]的，是一份既是唯一签字、又是唯一纪念的单一文件。不能推翻任何一项论断的，是一部只展示一次登陆和一面旗帜的电影。电影是一种尺度，日期是另一种尺度。

东线战争中的大规模屠杀，是本章不会推开的那道门轴。我们已经说过，它是1941年6月22日之后那场战争的组成部分；也说过，下一章会讲授被害犹太人的估计数字、万湖（Wannsee）为何不是开端，以及禁止编造第二个总数的规则。以某种程序预告那一课，会违反它的首要规则；趁读者想着别的事时塞进一个士兵伤亡总数，同样如此。“死者众多”仍然可以说，精确的整数则不行。

## 通向何处

估计数字、证据以及“种族灭绝”一词，见[[wars/genocide]]。投降之后的政治分裂，包括1945年7月至8月的波茨坦（Potsdam）会议，见[[postwar/division]]。入侵之前的条约与任命，见[[wars/interwar]]。本章用作1945年5月之参照的1917年双重纪日，见[[wars/revolutions-1917]]。

:::summary
- 1939年9月1日，德国入侵波兰。英国与法国于两天后的9月3日宣战。西线攻势在1940年5月10日，即宣战之后250天；法国停战在1940年6月22日，即攻势开始之后43天。
- 1939年9月1日之后的几周里，苏联占领了波兰东部，这一步没有锁定日期。1941年6月22日，德国入侵苏联，在法国停战之后365天。1940年的闰日不在这一年之内。
- 珍珠港事件在1941年12月7日。12月11日，德国对美国宣战。这扩大了联盟，却并没有开启欧洲战争。
- 斯大林格勒的投降定于1943年1月31日与2月2日。诺曼底登陆在1944年6月6日。一次针对希特勒的密谋于1944年7月20日失败，在登陆之后44天。华沙起义从1944年8月1日持续到10月2日。
- 占领、合作与抵抗在同一个社会中并存。本课程不把任何民族归为单一的道德类型，也不给出任何伤亡总数。
- 投降：1945年5月7日在兰斯，1945年5月8日在卡尔斯霍斯特；由于时差，苏联以5月9日为纪念日。5月8日与5月9日都要讲授。东线的大规模屠杀在此予以承认，并在下一章讲授。
:::

## 习题

:::exercise 入侵的年份 {level=1 check="1939"}
德国在哪一年入侵波兰？（请输入四位数年份。）
:::solution
入侵在1939年9月1日，年份是1939。法国停战在1940年，入侵苏联在1941年。
:::
:::

:::exercise 两国宣战 {level=1 check="2"}
英国与法国在1939年9月1日之后多少天宣战？（请输入天数。）
:::solution
两国于1939年9月3日宣战。从9月1日到9月3日是2天。西线攻势并不在其中的第二天，而是在1940年5月10日。
:::
:::

:::exercise 入侵苏联的年份 {level=1 check="1941"}
德国在哪一年入侵苏联？（请输入四位数年份。）
:::solution
入侵在1941年6月22日，年份是1941。同样在6月22日的法国停战是在1940年。珍珠港事件与德国对美宣战也在1941年，但在十二月，与这次入侵不是一回事。
:::
:::

:::exercise 5月9日是什么 {level=2}
说明1945年5月7日、8日与9日分别发生了什么，并指出三者中哪一个不是签署。
:::solution
1945年5月7日，一份投降文件在兰斯签署。1945年5月8日，另一份在卡尔斯霍斯特签署。由于时差，苏联以5月9日为投降之日。5月9日的纪念不是第三次签署。[[#thm-may]]要求5月8日与5月9日都予讲授，也不得把5月7日当作传言丢掉。编造签字的钟点没有必要：年表给出了原因，即时差，而不提供具体时刻。
:::
:::

:::exercise 占领不是民族性格 {level=2}
以1940年6月22日之后的法国为例，解释[[#def-occupation]]，使你的说法同时挡住“合作者的民族”与“抵抗者的民族”两种说法。
:::solution
1940年6月22日的停战之后，是占领与一个合作的政权，也有抵抗。两者在同一个社会中都有文献记录。把法国称为合作者的民族，就抹去了抵抗；把法国称为抵抗者的民族，就抹去了合作。同样的拒绝也适用于别处：华沙起义不能涵盖整个波兰，1944年7月20日失败的密谋也不能涵盖整个德国。[[#def-occupation]]是关于一种统治体制与混杂行为的论断，而不是对灵魂的普查，回忆录也不会因此变成普查。
:::
:::

:::exercise 365天的跨度拒绝了什么 {level=2}
以1940年是闰年为由，给1940年6月22日至1941年6月22日这一年加上一天，为什么是错误的？这个错误助长了怎样的历史合并？
:::solution
1940年2月29日在1940年6月22日之前，所以不在这段跨度之内。1941年不是闰年。跨度是365天，见[[#ex-june-pair]]。加一天就是把二月放错了位置。由此助长的历史合并，是把“6月22日”当作同一个事件。停战与入侵苏联相隔一年，在[[#thm-widen]]中起着不同的作用。1939年的条约曾使德国与苏联结盟，入侵则打破了这一选择。闰日的错误很小，与之相伴的合并却不小。
:::
:::

:::exercise 首尾都算，还是日期之差 {level=3}
华沙起义定于1944年8月1日至1944年10月2日。一位读者报告63天，另一位报告62天。两位读者各自回答的是什么问题？哪个数字是两个日期之差？
:::hint
从8月1日之后开始数，一直数到10月2日，这样就不包括起始日。然后想一想：如果在统计所涉及的日期时把8月1日与10月2日都算进去，会有什么变化？
:::
:::solution
两个日期之差是62。八月贡献8月1日之后的30天，九月贡献30天，10月2日贡献2天：30 + 30 + 2 = 62。说62的读者回答的是“10月2日在8月1日之后多少天？”说63的读者把首尾都算了进去，统计的是这一区间涉及的每一个日历日。两种算法都是真实存在的习惯。年表的“从……到……”表述是一个区间，本章用62表示日期之差，见[[#ex-two-ends]]。两个数字都不是死亡总数，也都不能使起义成为波兰的民族性格。起义于1944年10月2日结束，它不是1945年5月德国的投降。
:::
:::

:::exercise 被归类的民族 {level=3}
下面这句话为示例而虚构。它不是史料。“由于英法军队于1944年6月6日在诺曼底登陆，法国作为一个民族进行了抵抗，波兰作为一个民族进行了抵抗，而德国作为一个民族没有，所以每个民族在整场战争中都只有一种道德类型。”要使这种归类成立，记录必须呈现什么？哪些锁定的日期已经与它相抵触？
:::hint
使用1940年6月22日的停战、1944年7月20日的密谋以及华沙的日期。想一想，一次登陆能否为三个民族指定一种性格。要检验的是[[#def-occupation]]这一定义，而不是一段战斗叙事。
:::
:::solution
这句话是虚构的。要使它成立，记录就必须表明每个国家的每一个人在整场战争中都只属于一个类别，而记录并非如此。1940年6月22日停战之后的法国，既有一个合作的政权，也有抵抗，所以1944年的一次登陆不能追溯性地赋予法国单一的类型。1944年8月1日至10月2日的华沙起义是真实的，却不能涵盖波兰人在占领下的全部行为。1944年7月20日的密谋失败了，它表明德国人中存在反对，却既不能为这一政权开脱，也不能界定每一个德国人。诺曼底登陆在这次密谋之前44天，而不是一次道德普查。[[#def-occupation]]挡住了这种归类；本课程拒绝把各民族分为有罪与无辜，同样挡住了它。年表中也没有任何伤亡总数等着替人完成这种归类。
:::
:::
