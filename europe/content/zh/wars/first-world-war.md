从1914年到停战（armistice），打的是一场什么样的战争？这个问题针对的是战争本身。它既不是请人把七月危机的单一原因偷运回来，也不是索要死亡总数。到1914年8月4日，德国已经入侵比利时，英国已经对德国宣战。奥匈已于7月28日对塞尔维亚宣战，德国已于8月1日对俄国宣战、于8月3日对法国宣战。这两周之内的种种选择，是[[nations/toward-1914]]的主题。本章从上一章止步之处开始，从那次入侵一直讲到1918年11月11日的停战，追问的是：填满其间岁月的是一场什么样的战斗——有哪些战线，谁在劳动，谁在作战，以及在没有本图谱未锁定之数字的情况下，哪些陈述仍可核对。

一场战争可以就其首都而言是欧洲的，就其军队而言又是帝国的。宣战的决定是在维也纳、柏林、圣彼得堡、巴黎与伦敦作出的。随后作战与劳动的人，既有这些国家的应征者与志愿兵，也有在殖民地与自治领征募的士兵与劳工。后方（home front）并不是站在真实战争背后的隐喻；配给、审查、战时工业与哀悼，都是这场战争得以持续的方式。一部只保留法国与比利时一条堑壕的历史，是选定了一个尺度，却把它称为全部。[[sources/scale]]正是对这种做法的警告。一个真实的地方故事，哪怕是可怕的故事，也还不是这场战争的故事。

也不能靠反复讲述七月危机、直到它变成宿命来解释这场战争。1914年，动员计划约束了德国的时间表，但约束并不等于此后再无选择。战争打响之后，各国政府仍要决定：是否开辟新的战线，是否谋求单独媾和，是否实行征兵，是否收紧封锁，以及是否停战。停战就是其中一项决定，日期为1918年11月11日。它不是1919年6月28日的《凡尔赛（Versailles）和约》，也不是对七月哪一项选择“真正”导致了其余一切的判决。我们在此拒绝这种判决，一是因为前一门课程已经拒绝过它，二是因为1916年、1917年与1918年的日期所证明的，是一场持续、扩大并最终停止的战争，而不是一份预先写好的剧本。

## 不止一条战线

西线是真实的，但它不是这场战争的全貌。对奥匈的作战在东方与巴尔干继续进行。奥斯曼帝国是交战国，因此这场战争的地理范围也包括奥斯曼的各条战线，其中之一是达达尼尔（Dardanelles）的战事。年表没有为这次战役锁定年份，所以本课不予编造。一场真实的战役可以提及名称，却仍不给出数字。在[[nations/toward-1914]]那张标出1879年、1894年、1904年与1907年各条边的同盟图上，意大利不在任何一条边上，但它确实参加了这场战争。年表没有锁定意大利参战的日期，所以我们不说。参战是又一个选择，而不是德奥同盟早已画好的一条线。

在欧洲之外，各帝国同样相互交战。非洲与太平洋的战役不是后人出于道德趣味添加的脚注，而是源于交战各方都是帝国国家这一事实。同一事实也把殖民地军队带上了欧洲战场。法国的军队取自北非、西非与印度支那；英国的军队取自印度、各自治领、加勒比地区与非洲殖民地。在亚洲招募的劳工在英法战线后方劳作。对这些人，我们一概不给出人数：年表没有锁定，而从教科书上抄来的整数只会是虚假的精确。我们确实提出的论断是绝对的：一场其军队中有这些士兵的战争，就是一场帝国战争，即使征募他们的是欧洲的首都。

这一论断有其限度，而这一限度正是[[#thm-imperial]]的要点：在场不等于同意。身穿宗主国军服的殖民地臣民，既不能证明殖民地选择了这场战争，也不能证明这场战争是为了该殖民地的自由而打的。有些士兵自己的动机记录甚少。档案中的沉默，证明的是谁被要求发言，而不是这个人没有思想。这条规则已在[[sources/evidence]]中讲授，在这里尤其适用。帝国的公报不是士兵的传记。

后方属于同一论证。交战各国调配劳动力、审查新闻、举借债务、配给食物。在不止一个国家，妇女大批进入工业劳动——我们说“大批”，是因为我们不会编造百分比。若干国家征召了并未志愿入伍的男子。法国与德国参战时，征兵制早已是其制度的一部分；英国则在战争期间从志愿招募转向了征兵制。年表没有锁定英国这一转变的日期，所以我们不予提供。粮食短缺是一个政治事实，在封锁切断进口的地方最为严峻。我们不给出饥饿造成的死亡总数。政府部门的海报证明的是政府希望人们相信什么，而不是人们确实相信了。一个在记录中没有留下抗议的村庄，既不能因此证明未受触动，也不能证明满怀热情。

兵变、逃亡与罢工都曾发生，因此这场战争并不只有一种顺从牺牲的情绪。本章不描述武器或伤口。称这场战争为工业化战争，是关于规模与补给的论断，而不是一本手册。

## 1916年的两场战役，不给出死亡总数

凡尔登战役始于1916年2月21日，索姆河（Somme）战役始于1916年7月1日。两者都在西线，都是漫长的战役而非一日之战，也都常常借伤亡数字来讲授。本图谱禁止使用这种数字。这项禁令并不暗示这些战役规模很小，而是一条关于什么可以视为定论的规则。不在年表中的数字，既不能用来强调，也不能用来比较，更不能用作段落的高潮。

这两个日期表明，1916年并不是战争爆发与美国参战之间的空白；它们也使我们能在[[#ex-verdun-somme]]中计算一段跨度，而无须清点尸体。同一年里，其他战线与后方仍在继续。后面的图示把1916年压缩为一个数据点，图注说明这个数据点包含两场战役。它是一份目录，而不是一张地图。

:::definition 停战 {#def-armistice}
**停战**是停止作战的协定，而不是和约。它本身不划定新的版图，不确定赔款数额，也不建立新的国家。本章所说的停战，是1918年11月11日的那一次。
:::

:::definition 后方 {#def-home}
**后方**指交战社会内部对劳动力、粮食、法律、信贷与信息的动员。它是战争的组成部分。它不是和平时期平民生活的委婉说法，也不能证明每个家庭经历的是同一场战争。
:::

:::definition 帝国的士兵 {#def-empire-soldiers}
本章所说的**帝国的士兵**，指在殖民地与自治领征募、用于一场由欧洲帝国国家宣战的战争的军队与军事劳工。这个说法是一个征募类别，而不是关于忠诚、同意或共同政治目标的论断。
:::

:::theorem 这场战争既是欧洲的，也是帝国的 {#thm-imperial}
从1914年到停战，这场战争由欧洲各国及其帝国的士兵与劳工共同进行，战场既在欧洲，也在欧洲之外。后方是这场战争的组成部分。这一论断并不主张每个殖民地都以同样的方式经历了这场战争，也不包括人数。
:::
:::proof
1914年7月末与8月初的各次宣战，是早已统治着帝国的欧洲国家的行为，这些帝国为战争征募了士兵与劳工，其中也包括在欧洲各战线上作战的人。奥斯曼帝国参战、达达尼尔战事以及欧洲以外的各次战役，使战斗超出了法国与比利时的范围，即便我们拒绝给出年表未锁定的年份也是如此。征兵、配给、审查与战时工业表明，后方在承担战争工作。能够推翻这一论断的，是这样一种记录：1914年至1918年的军队仅由单一战线上的宗主国志愿兵组成，既无帝国征募，也无生产动员。而记录并非如此。不能推翻它的，是某个殖民地只派出了很少的士兵，或某个士兵并不认同其军官的政治立场。这一论断针对的是战争的性质，而不是整齐划一的经历。单个村庄既不能否定它，也不能证明一种全民情绪。这就是[[sources/scale]]中的尺度规则。
:::

:::theorem 停战不等于和约 {#thm-not-peace}
1918年11月11日的停战按照商定的条件停止了作战，却没有写出和平解决方案。《凡尔赛和约》是更晚的文件，签订于1919年6月28日。无论为这两场战役还是为停战定年，都不需要凡尔登或索姆河的死亡总数，这里也不给出。
:::
:::proof
按照[[#def-armistice]]的规定，停战是停止作战。凡尔赛和约签订于镜厅，德意志帝国曾于1871年1月18日在这座大厅宣告成立。两个年份相差48，因为1919减1871得48。年表把凡尔登定于1916年2月21日开始，把索姆河定于1916年7月1日开始，并拒绝给出死亡总数。能够推翻这一论断的，是一项日期为1918年11月11日、涉及边界与赔款的和约，或是1916年任一战役已锁定的伤亡总数。两者都不存在。停止作战并没有使政治冻结：一些政府倒台了，边界也已出现争议。这一论断只是说，停火与解决方案是不同的文件。1918年3月3日的《布列斯特-立托夫斯克（Brest-Litovsk）和约》是第三份文件，是西线停战之前的东线和约，在[[wars/revolutions-1917]]中讲授。它进一步说明，不能把11月11日当作每一条战线的终点。
:::

:::quiz
下列哪一项与本章锁定的日期相符？
- [ ] 1918年11月11日的停战就是《凡尔赛和约》。
- [ ] 凡尔登与索姆河只有附上死亡总数才能讲授。
- [x] 凡尔登始于1916年2月21日，索姆河始于1916年7月1日，停战在1918年11月11日，两场战役都不附死亡总数。
- [ ] 美国与德国入侵比利时在同一周参战。
:::solution
第一项混淆了两份文件，凡尔赛和约签订于1919年6月28日。第二项正是本章所要纠正的习惯：年表禁止为任何一场战役给出死亡总数。第四项把战争压缩了：入侵比利时在1914年8月4日，美国在1917年4月参战。第三项是锁定的顺序，它足以辨认这两场战役与停战，而无须编造死者人数。
:::
:::

## 一段可以核对的跨度

只有当读者能够重新计算时，日期才算发挥了作用。下面的例题只使用锁定的日期，没有一道会得出伤亡数字，也没有一道需要伤亡数字。

:::example 从凡尔登第一天到索姆河第一天 {#ex-verdun-somme}
凡尔登战役始于1916年2月21日，索姆河战役始于1916年7月1日。7月1日在2月21日之后多少天？1916年是闰年，二月有29天。请给出两个日期之差，而不是首尾都算在内的计数。
:::solution
以2月21日为第0天往后数。闰年二月有29天，所以2月21日之后仍在二月的日子是22日至29日，共八天。三月31天，四月30天，五月31天，六月30天，再加上7月1日这一天。总和为8 + 31 + 30 + 31 + 30 + 1 = 131。所以1916年7月1日在1916年2月21日之后131天。用一年中的序数日也能得出同样的结果：2月21日是闰年的第52天（一月31天加21），7月1日是第183天（31 + 29 + 31 + 30 + 31 + 30 + 1）。于是183 − 52 = 131。如果把2月21日到7月1日的每个日历日都算在内，结果是132，但那是另一个问题。这里问的是两个日期之差。
:::
:::

:::example 停战之年内部的一段 {#ex-span-war}
德国于1914年8月4日入侵比利时，停战在1918年11月11日。在非闰年中，11月11日在8月4日之后多少天？1918年不是闰年。请给出两个日期之差，而不是首尾都算在内的计数。另请说明1914年8月4日至1918年8月4日之间有几个闰日。
:::solution
非闰年中一月至七月共有31 + 28 + 31 + 30 + 31 + 30 + 31 = 212天，所以8月4日是第216天。一月至十月共有212 + 31 + 30 + 31 = 304天，所以11月11日是第315天。于是315 − 216 = 99。在1918年，11月11日在8月4日之后99天。1914年8月4日至1918年8月4日之间唯一的闰日是1916年2月29日。我们在这两项核对处停下，而不把它们合成一个可能被误读为年数的总数。停战仍是1918年11月11日。整数99是这一年内部的一段，而不是死者人数。
:::
:::

:::example 把一句编造的话一分为二 {#ex-invented-somme}
下面这句话为示例而虚构。它不是史料。请说明哪一个分句可以保留。“1916年7月1日索姆河战役开始，到黄昏时一个确定的死亡总数已为人所知，本图谱理应把它印出来。”
:::solution
这句话是虚构的，使用之前必须先标明。第一个分句陈述了一个锁定的日期：索姆河战役始于1916年7月1日。这个分句与年表相符，可以保留。第二个分句编造了一个死亡总数，又假装图谱有义务转述它。年表的说法恰恰相反：不要为索姆河或凡尔登给出死亡总数。要把第二个分句提升为证据，你需要一个年表已经锁定、并附有警示说明的数量。这样的数量并不存在。一个生动的整数并不会因为精确就成为史料。同样的检验也排除了任何被偷运进关于1916年2月21日或7月1日之陈述的其他总数。日期站得住，数字站不住。
:::
:::

:::example 情绪相同、日期不同的两份文件 {#ex-armistice-treaty}
下面这句话为示例而虚构。它不是史料。一位读者在教科书页边写下这样一条笔记：“1918年11月11日，凡尔赛签字，战争的意义就此定局。”请指出其中的每一个错误，并用一句只使用锁定日期的话替换这条笔记。
:::solution
这条笔记是虚构的，犯了三个错误：它把停战说成凡尔赛和约的签字；它把凡尔赛和约放在1918年，而不是1919年6月28日；它把一种意义当作一个日期来对待。一种不越出年表的替换是：1918年11月11日的停战停止了作战；《凡尔赛和约》于1919年6月28日在镜厅签订，德意志帝国曾于1871年1月18日在同一座大厅宣告成立。从1871年到1919年相差48年。这些陈述都不需要伤亡总数，也都没有说和约是停战不可避免的结果。两个日期之间是政治，包括下一章讲授的各场革命。
:::
:::

## 战争的扩大，以及只作为日期提及的东线和约

1917年4月，美国参战。月份是锁定的，单一的动机则不是。史家们指出了海上战争、财政、先前的同情与紧迫的危机，但他们对这些理由的排序并不一致。本章锁定参战的时间，拒绝排序。1917年4月不是停战。从1917年4月到1918年11月是一年零七个月：十二个月到1918年4月，五月至十一月再加七个月。美国参战改变了联盟，却没有在参战当天停止战斗。一个在四月才出现的原因，不可能解释早在前一年二月和七月就已开始的战役。凡尔登与索姆河都在1916年。美国参战证明的是战争如何扩大，而不是战争为何开始。这正是[[sources/argument]]对任何原因提出的同一纪律：它必须是本可以不同的那类事物，而且必须在时间中定位。

1918年3月3日，《布列斯特-立托夫斯克和约》使俄国退出了战争。完整的论证，包括1917年的两种历法，属于[[wars/revolutions-1917]]。在这里，这项和约只有一个作用：它是西线停战之前的东线和约。从3月3日到1918年11月11日是253天。在此期间，德国已不再与自1914年8月1日起与之交战的俄国国家作战。停战仍落在11月11日，而且不是德国的胜利。因此，不能把东线和约叙述为决定战争胜负的一步。它是战线的真实变化，却不是剧本的最后一行。我们不把1918年的战斗描述为一种战术，也不编造某次攻势的发起日期。年表锁定了布列斯特-立托夫斯克与停战，这两个日期已足以驳斥这样一种想法：退出东线战争就等于赢得西线战争。

:::quiz
在一章以停战为问题终点的内容里，布列斯特-立托夫斯克起什么作用？
- [ ] 它取代了停战，因为战争实际上是在东线结束的。
- [x] 它是1918年3月3日的东线和约，提及它是为了不让11月11日的停战被误认为每一条战线的终点。各场革命属于下一章。
- [ ] 它就是1919年6月28日在镜厅签订的和约。
- [ ] 它是换了名称的索姆河死亡总数。
:::solution
布列斯特-立托夫斯克和约的日期是1918年3月3日，革命中的俄国借此退出了战争。西线的停战仍在1918年11月11日，晚了253天，而且不是德国的胜利。凡尔赛和约是1919年6月28日的另一项和约。这个名称下面并没有藏着任何伤亡总数。下一章将把各场革命、历法与这项和约作为自己的主题。
:::
:::

年表拒绝给出死亡总数，这本身就是关于方法的证据。它告诉你本课程不会假装知道什么；它既没有告诉你死者很少，也没有告诉你数字在历史中总是不正当的。图谱其他地方的普查数字之所以锁定，是因为一个附有警示说明的计数是可以核对的。一个史家们仍以互不相容的方式重建的战场总数，在这里不享有这种地位。如果你在别的书里看到一个精确的索姆河总数，你看到的是那本书的选择，而不是一个可以悄悄引入的数字。

把窗口设为零，然后移动年份。窗口为零时，高亮的年份只是一个整数，旁边的标签也很简短。1914年的标签“战争扩大”，代表本章视为已经讲过的开端的那一系列日期：7月28日、8月1日、8月3日、8月4日。1916年，一个数据点代表两场开始时间相隔131天的战役，也代表这一年里数据点无法显示的其他一切。1917年的数据点标记美国参战，却无法显示俄国的革命；1918年的数据点标记停战，却无法显示三月的布列斯特-立托夫斯克。这张图之所以有用，正因为它单薄。一份单薄的目录能防止你把标签误当作死者名册。

:::warning 单一的堑壕与借来的总数
一幅常见的画面展示一条泥泞的堑壕，称之为战争，再给凡尔登或索姆河钉上一个庞大的整数死亡总数。这两部分都站不住。这场战争在不止一条战线上进行，参战的既有宗主国军队，也有各帝国的士兵，而且依靠后方支撑。年表没有为任何一场战役锁定死亡总数，所以借来的整数不是本课程的事实。拒绝这个整数，并不是说这些战役无关紧要，而是关于证据的论断。这种迷思的另一个版本说，停战“就是凡尔赛”，或者战争的意义在1918年11月11日就已签定。和约在1919年6月28日。停火不是解决方案，解决方案也不是可以一路倒推、直到七月再无选择余地的原因。
:::

:::history
1916年2月21日，凡尔登战役开始；1916年7月1日，索姆河战役开始。1917年4月，美国参战。停战日期为1918年11月11日。1918年3月3日的《布列斯特-立托夫斯克和约》是这次停战之前的东线和约。这些日期都不是死亡总数。
:::

如果一句关于1916年的话离开死亡总数就说不出口，那它依赖的是本课程拒绝给出的数字。如果一句关于1918年的话分不清11月11日与1919年6月28日，那它就把两份文件混为一谈了。能够推翻本章框架的，是表明既无帝国征募、也无后方动员的证据，或者是一项日期为1918年11月11日的和平解决条约。一部关于某条堑壕的回忆录则不能，它是个人尺度上的证据。[[#thm-imperial]]的成立与否，取决于征募、其他战线与各政府部门。

一座只刻着一个村庄名字的战争纪念碑，证明的是谁的名字被刻在石头上，而不是作战序列。本章不给出任何国家的死亡总数，也不给出1914年至1918年欧洲的总数。“死者众多”是一个未锁定的数量所能允许的最大限度。没有这个整数，这场战争的性质依然可以描述：一场帝国联盟之间的战争，不止一条战线，各国后方，凡尔登，索姆河，美国参战，作为此前东线和约的布列斯特-立托夫斯克，以及停战。

## 通向何处

停战时，俄国早已借一项本章只给出日期的和约退出了战争。[[wars/revolutions-1917]]将讨论1917年的两种历法、退位、十月，以及作为退出（而不只是一笔带过）的布列斯特-立托夫斯克。各项和约，以及“1918年之后的岁月是通向一个人的走廊”这一论断，见[[wars/interwar]]。七月危机仍见[[nations/toward-1914]]。日期与标签有何不同，见[[sources/time-and-names]]；原因与标签有何不同，见[[sources/argument]]。

:::summary
- 从1914年8月4日入侵比利时到1918年11月11日停战，这场战争是帝国之间的多战线战争，既不是单一的堑壕，也不是从七月延续下来的单一原因。
- 殖民地与自治领的士兵和劳工是这场战争的组成部分。他们的在场不等于同意，本章不给出人数。
- 后方——劳动、粮食、审查、征兵——承担着战争工作。海报不是信念，沉默也不是情绪。
- 凡尔登战役始于1916年2月21日，索姆河战役始于1916年7月1日，晚131天。两场战役都不给出死亡总数。
- 美国于1917年4月参战。这扩大了联盟，却既没有开启战争，也没有结束战争。
- 1918年3月3日的布列斯特-立托夫斯克和约是停战之前的东线和约。各场革命属于下一章。退出东线不是德国的胜利：停战仍在1918年11月11日。
- 停战停止了作战。1919年6月28日的凡尔赛和约是更晚的和约，签订于德意志帝国1871年1月18日宣告成立的那座大厅。
:::

## 习题

:::exercise 停战的年份 {level=1 check="1918"}
本章中结束作战的停战在哪一年？（请输入四位数年份。）
:::solution
停战在1918年11月11日，年份是1918。《凡尔赛和约》在1919年，不是答案。
:::
:::

:::exercise 美国参战 {level=1 check="1917"}
美国在哪一年参战？（请输入四位数年份。）
:::solution
美国于1917年4月参战，年份是1917。入侵比利时在1914年，停战在1918年。
:::
:::

:::exercise 年份之差 {level=1 check="4"}
用停战的年份减去入侵比利时的年份。（请输入年数。）
:::solution
入侵比利时在1914年，停战在1918年，于是1918 − 1914 = 4。这是年份标签之差。停战之年内部从8月4日到11月11日的那一段是99天，已在[[#ex-span-war]]中算过。那一段不是四年之差，两个整数也都不是死亡总数。
:::
:::

:::exercise 索姆河的日期承载不了什么 {level=2}
一位同学说：“没有死亡总数，1916年7月1日根本没法讲。”请从这个日期确实支持什么、年表又拒绝给出什么这两方面作答。
:::solution
这个日期支持一个有定位的论断：索姆河战役始于1916年7月1日，比始于1916年2月21日的凡尔登战役晚131天，发生在西线，处在一场同时还有其他战线与后方的战争之中。年表拒绝给出死亡总数，并禁止编造。拒绝给出总数，防止的是虚假的精确；它既没有抹去这场战役，也没有暗示这场战役规模很小。凭记忆抄来的教科书整数弥补不了这一缺口，只会把它掩盖起来。
:::
:::

:::exercise 停战与和约 {level=2}
说出停战的日期与《凡尔赛和约》的日期，并说明一门把两者混为一谈的课程为什么通不过[[#thm-not-peace]]的检验。
:::solution
停战在1918年11月11日。凡尔赛和约于1919年6月28日在镜厅签订。[[#thm-not-peace]]指出，前者停止了作战，后者是更晚的和平。把两者混为一谈，就会把两份文件变成一个事件，让1918年去做1919年的工作。1871年1月18日德意志帝国在同一座大厅宣告成立，是第三个事件，并不能证明后来的和约早已在那里写就。
:::
:::

:::exercise 什么能够推翻帝国论断 {level=2}
[[#thm-imperial]]说这场战争既是欧洲的，也是帝国的。请举出一个能够推翻它的发现，以及一个不能推翻它的发现。
:::solution
能够推翻它的发现是：有证据表明1914年至1918年各交战国的军队与劳役既没有在殖民地与自治领征募，也没有在单一欧洲战线之外作战。不能推翻它的发现是：一部回忆录或一个编造的村庄中，有一个士兵对帝国毫不在意。这样的证据是在个人尺度上说话，而这一论断针对的是征募、战线与后方。殖民地人员的在场仍然不能证明同意；即使论断成立，论证的限度依然存在。
:::
:::

:::exercise 编造的黄昏 {level=3}
下面这句话为示例而虚构。它不是史料。“因为1916年7月1日是索姆河战役的第一天，所以当晚的死亡总数是这个日期的一部分，可以说出来。”日期与总数有什么区别？这句话的哪一半站得住？
:::hint
把与年表相符的分句和编造数量的分句分开。想一想，要把这个数量提升为锁定的数字，需要什么。
:::
:::solution
这句话是虚构的。日期站得住：索姆河战役始于1916年7月1日。总数站不住。日期定位的是年表已经指名的事件；总数统计的是人，而这份年表拒绝为索姆河给出这一计数。把总数称为“日期的一部分”是修辞上的偷换，而不是证据规则。要引入任何这样的总数，年表必须说明它并附上警示，而年表并没有这样做。同样的偷换用在1916年2月21日的凡尔登上也行不通。你可以算出索姆河的开战比凡尔登晚131天，却不能用编造的死者填满这些日子。
:::
:::

:::exercise 四年跨度中的闰日 {level=3 check="1"}
一位读者计算1914年8月4日至1918年8月4日这一段时，用四乘以365，再加上从8月4日到11月11日的99天，却始终没有加上闰日。这位读者漏掉了几个闰日？（请输入数字。）
:::hint
检查这两个八月日期之间哪些年份是闰年。从八月到十一月那一段已在1918年内部算过，而这一年不是闰年，所以那一段并没有藏着缺失的那一天。
:::
:::solution
这位读者漏掉了一个闰日。从1914年8月4日到1918年8月4日，唯一的闰日是1916年2月29日；1914年与1918年都不是闰年。从8月4日到11月11日那99天的一段在1918年之内，不包含那个二月。修正后的跨度是读者的数字加一天。看出这个错误并不需要一个四位数的总数。结果仍是一段时间长度，而不是伤亡总数。漏掉的闰日数为1。
:::
:::
