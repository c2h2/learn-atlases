从1914年到停战（armistice），打的是一场什么样的战争？这个问题问的是战争本身。它不是一封邀请，请我们把七月的单一原因偷运回来；它也不是一个对死亡总数的请求。到1914年8月4日，德国已经入侵比利时，英国已经对德国宣战。奥匈已经在7月28日对塞尔维亚宣战。德国已经在8月1日对俄国宣战，在8月3日对法国宣战。那个双周之内的诸选择，是[[nations/toward-1914]]的题目。本章从上一章停下的地方开始。它从那次入侵一直走到1918年11月11日的停战，它要问的是：填充中间那些年的是一场什么样的战事——哪几条战线，谁的劳动，谁的士兵，以及，在没有一个本图谱没有锁定的数字的情况下，哪些句子仍然可以被核对。

一场战争可以同时在其诸首都上是欧洲的、在其诸军队上是帝国的。那些宣战的决定是在维也纳、柏林、圣彼得堡、巴黎与伦敦做出的。随后作战与劳动的人们包括了来自那些国家的被征召者与志愿者，也包括在殖民地与自治领征募的士兵与劳工。后方（home front）不是站在一场真实战争背后的一个隐喻。配给、审查、战争工业与哀悼，是这场战争如何被继续进行的一部分。一段只保留法国与比利时的一条堑壕的历史，是选择了一个尺度，并把它叫作全部。[[sources/scale]]就是针对那个动作的警告。一个真实的地方故事，即使是一个可怕的故事，也还不是这场战争的故事。

这场战争也不能靠把七月危机重复到它变成一个命运来解释。一个动员计划在1914年约束了德国的一个时间表。一个约束不是后来的选择的缺席。战争一旦进行起来，诸政府仍然要决定：是否再开一条战线，是否寻求一项单独和平，是否征兵，是否收紧一次封锁，以及是否停下。停战是那些决定之一，定在1918年11月11日。它不是《凡尔赛（Versailles）和约》，那是1919年6月28日，它也不是关于七月的哪一个选择“真正”造成了其余的一切的一个判决。我们在这里拒绝那个判决，因为前面的课程已经拒绝过它，也因为1916年、1917年与1918年的那些日期是一场战争曾经继续、扩大、并且终于停下的证据，不是一份预先写就的剧本的证据。

## 不止一条战线

西线是真实的。它不是这场战争的轮廓。对奥匈的作战继续在东方与巴尔干进行。奥斯曼帝国是一个交战国，所以这场战争的地理包括了奥斯曼的诸条战线。其中一条是达达尼尔（Dardanelles）的战事。年表没有为那次战役锁定一个年份，所以本课不发明一个。一场真实的战役可以被点名，却仍然被拒绝给一个数字。意大利——[[nations/toward-1914]]里那张为1879年、1894年、1904年与1907年画边的同盟图形把它留在了边之外的意大利——确实在这场战争中打过仗。年表没有锁定意大利参战的那一天，所以我们不说出一个。参与是一个进一步的选择。它不是一条已经由德奥同盟画好的线。

在欧洲之外，诸帝国也同样彼此交战。在非洲与太平洋的诸战役，不是由后来的道德趣味添加的一条脚注。它们源自交战各方是帝国国家这个事实。同一个事实把殖民地军队带到了欧洲的战场。法国的军队取用于北非、西非与印度支那。英国的军队取用于印度、诸自治领、加勒比与非洲诸殖民地。在亚洲招募的劳工在英国与法国的战线后方做工。我们不给这些人中的任何一批一个计数。年表没有锁定一个，而从一本教科书抄来的一个凑整数字将是一种虚假精确。我们确实做出的那条论断是无条件的。一支其军队包括了那些士兵的战争是一场帝国的战争，即使征募他们的那座首都是欧洲的。

那条论断有一个限度，而这个限度正是[[#thm-imperial]]的要点。在场不是同意。一个穿着宗主国军装的殖民地臣民，不是那个殖民地选择了这场战争的证据，也不是这场战争是为那个殖民地的自由而打的证据。一些士兵自己的动机，记录得很差。档案里的一段沉默，是关于谁被要求发言的证据，不是这个人没有头脑的证据。那条规则在[[sources/evidence]]里讲授。它在这里以特别的力度适用。帝国的公报不是那名士兵的传记。

后方属于同一个论证。交战诸国指挥劳动、审查新闻、举债并配给食物。不止一个国家里，妇女大批进入工业劳动。我们说“大批”，因为我们不会发明一个百分比。若干个国家征召了本来没有志愿入伍的男子。法国与德国参战时，征兵制已经在它们的制度之中。英国在战争期间从志愿招募转向了征兵制。年表没有锁定那次英国变更的那一天，所以我们不提供一个。食物短缺是一个政治事实，在一次封锁切断进口之处最为尖锐。我们不给出饥饿的死亡总数。一张政府部的海报是一个政府想要什么东西被相信的证据。它不是人们相信了它的证据。一个在记录里不留下一次抗议的村庄，并不因此就被证明未曾被动过，也不被证明是热情的。

兵变、逃亡与罢工曾经发生，所以这场战争不是一种顺从的牺牲的情绪。本章不描述武器或伤口。把这场战争命名为工业的，是一条关于尺度与补给的论断，不是一本手册。

## 1916年的两场战役，与一个也不给出的死亡总数

凡尔登在1916年2月21日开始。索姆河（Somme）在1916年7月1日开始。两者都在西线。两者都是漫长的战役，而不是单日的一场遭遇，而两者都常常是通过一个伤亡数字来教授的。本图谱禁止那个数字。这项禁令不是这些战役很小的暗示。它是一条关于什么可以被当作确定之物的规则。一个不在年表里的数字，不可用于强调，不可用于比较，也不可用于一段话的高潮。

那两个日期显示，1916年不是爆发与美国参战之间的一片空白，而它们让我们在[[#ex-verdun-somme]]里计算一段跨度，而不需要一个死亡计数。其他的战线与后方在同一年里继续。那幅图后来把1916年压缩成一个圆点。图注说这个圆点装着两场战役。它是一页目录，不是一幅地图。

:::definition 停战 {#def-armistice}
**停战**是一项停止作战的协定。它不是一份和约。它本身不绘制一幅新地图，不确定一笔赔款数额，也不建立一个新国家。本章的这次停战，是定在1918年11月11日的那一次。
:::

:::definition 后方 {#def-home}
**后方**是交战社会内部对劳动、食物、法律、信贷与信息的动员。它是这场战争的一部分。它不是和平时期平民生活的一个更软的同义词，它也不是每一户人家都经历了同一场战争的证据。
:::

:::definition 帝国的士兵 {#def-empire-soldiers}
**帝国的士兵**，在本章中，指的是在殖民地与自治领征募、并被用于一场其宣战书由欧洲帝国国家发布的战争的军队与军事劳工。这个短语是一个征募的类别。它不是关于忠诚、同意或一个共享的政治目标的论断。
:::

:::theorem 这场战争既是欧洲的，也是帝国的 {#thm-imperial}
从1914年到停战，这场战争是由欧洲诸国打的，也是由它们的诸帝国的士兵与劳工打的，是在欧洲的战线上打的，也是在欧洲之外打的。后方是这场战争的一部分。这条论断没有主张每一个殖民地都以同一种方式经历了这场战争，它也不包括一个人数计数。
:::
:::proof
1914年7月末与8月初的那些宣战，是已经统治着诸帝国的欧洲诸国的行为，而那些帝国为这场战争征募了士兵与劳工，包括在欧洲的各条战线上。奥斯曼的交战状态、达达尼尔，以及在欧洲之外的诸战役，把战事放到了法国与比利时之外，即使在我们拒绝给出一个年表没有锁定的年份之处也是如此。征兵、配给、审查与战争工业，显示后方在做战争的工作。会构成对这条论断的反证的，是这样的记录：1914–1918年的诸军队只是一条战线上的宗主国志愿兵，没有帝国的征募，也没有生产的动员。记录不是这样的。不能构成反证的，是一个派出很少士兵的殖民地，或一名不与他的军官们共享政治的士兵。这条论断说的是这场战争的种类，不是一种整齐划一的经历。一个单独的村庄取消不了它，也证明不了一种国民情绪。那就是[[sources/scale]]里的尺度规则。
:::

:::theorem 停战不是和约 {#thm-not-peace}
1918年11月11日的停战在商定的条款之下停止了作战。它没有写出和平处置。《凡尔赛和约》是一份更晚的文书，签署于1919年6月28日。无论是为这两场战役还是为这次停战定年，都不需要一个凡尔登或索姆河的死亡总数，这里也没有说出一个。
:::
:::proof
停战，如[[#def-armistice]]所规定的，停止作战。凡尔赛是一份在镜厅签署的和约，德意志帝国曾在1871年1月18日在那座大厅宣告成立。年份数字相差48，因为1919减1871是48。年表把凡尔登定从1916年2月21日起，把索姆河定从1916年7月1日起，并且扣住一个死亡总数不给。会构成对这条论断的反证的，是一份定在1918年11月11日的关于边界与赔款的和约，或是一个锁定的1916年任一战役的伤亡总数。两者都没有。停止作战没有把政治冻住：诸政府倒台了，而边界已经在争议之中。这条论断只是说，那次停止与那份处置是不同的文书。布列斯特-立托夫斯克（Brest-Litovsk），在1918年3月3日，是第三份文书，是西线停战之前的一份东线和平，在[[wars/revolutions-1917]]里讲授。它是不要把11月11日当作每一条战线的终点的又一个理由。
:::

## 一段你可以核对的跨度

当读者能够重新计算日期时，日期就挣得了它们的位置。下面的例子只使用锁定的日子。它们之中没有一个产出一个伤亡数字，也没有一个需要一个。

:::example 从凡尔登的第一天到索姆河的第一天 {#ex-verdun-somme}
凡尔登在1916年2月21日开始。索姆河在1916年7月1日开始。2月21日之后多少天是7月1日？1916年是闰年，所以二月有29天。给出两个日期的差，不是把两端都算在内的计数。
:::solution
把2月21日当作第0天，向前数。在闰年，二月有29天，所以2月21日之后仍在二月之内的日子是22日到29日：八天。三月有31天，四月30天，五月31天，六月30天。然后7月1日再加一天。总和是8 + 31 + 30 + 31 + 30 + 1 = 131。所以1916年7月1日在1916年2月21日之后131天。同样的结果可以从一年之内的日数得到：2月21日是闰年的第52天（一月的31天加21），而7月1日是第183天（31 + 29 + 31 + 30 + 31 + 30 + 1）。于是183 − 52 = 131。从2月21日到7月1日把每一个历日都算在内的计数会是132。那是另一个问题。这里问的是差。
:::
:::

:::example 停战之年的内部一步 {#ex-span-war}
德国在1914年8月4日入侵比利时。停战是1918年11月11日。在一个非闰年，8月4日之后多少天是11月11日？1918年不是闰年。给出两个日期的差，不是把两端都算在内的计数。另外说出，在1914年8月4日与1918年8月4日之间落入多少个闰日。
:::solution
在非闰年，一月到七月有31 + 28 + 31 + 30 + 31 + 30 + 31 = 212天，所以8月4日是第216天。一月到十月有212 + 31 + 30 + 31 = 304天，所以11月11日是第315天。于是315 − 216 = 99。在1918年，11月11日在8月4日之后99天。在1914年8月4日与1918年8月4日之间，唯一的闰日是1916年2月29日。我们在这两个核对处停下，而不是把它们压成一个可能被误读为一年的总计数。停战仍然是1918年11月11日。整数99是那一年内部的一步。它不是死者的人数。
:::
:::

:::example 一句发明出来的句子，拦腰切开 {#ex-invented-somme}
下面这句话为示例而虚构。它不是史料。并说出哪个子句可以保留。“1916年7月1日索姆河开始，而到黄昏为止，一个确定的死亡总数已经为人所知，本图谱应当把它印出来。”
:::solution
这句话是虚构的，而在使用它之前必须把它标明为虚构。第一个子句说出一个锁定的日期：索姆河在1916年7月1日开始。那个子句可以保留，因为它与年表相符。第二个子句发明了一个死亡总数，然后假装图谱有义务复述它。年表说的是反面：不要为索姆河或凡尔登说出一个死亡总数。要把第二个子句提升为证据，你需要一个年表已经锁定的数量，连同印在它旁边的警告。没有这样的数量。一个生动的整数不会因为精确就成为一条史料。同样的检验拒绝任何其他被偷运进一个关于2月21日或1916年7月1日的句子里的总数。日期站得住。数字不站得住。
:::
:::

:::example 两份共享一种情绪而不共享一个日期的文书 {#ex-armistice-treaty}
下面这句话为示例而虚构。它不是史料。一位读者把它写成一条写在教科书页边的笔记：“1918年11月11日，凡尔赛签字，战争的意义就此定局。”指出每一个错误，并用一句只使用锁定日期的句子替换这条笔记。
:::solution
这条笔记是虚构的。它犯了三个错误。它把停战叫作凡尔赛的签字。它把凡尔赛放在1918年，而不是1919年6月28日。而它对待一个意义，仿佛它是一个日期。一个待在年表之内的替换是：1918年11月11日的停战停止了作战；凡尔赛和约于1919年6月28日签署在镜厅，即德意志帝国曾于1871年1月18日被宣告成立的那座大厅。从1871年到1919年的年份差是48。这些句子没有一个需要一个伤亡总数，也没有一个说那个和约是停战的不可避免的结果。在这两个日期之间躺着政治，包括在下一章讲授的诸革命。
:::
:::

## 扩大，以及一份只作为一个日期被提及的东线和平

1917年4月，美国参战。这个月份是锁定的。一个单独的动机不是。史家们指出海上的战争、财政、先前的同情与迫近的危机，而他们并不都把那些理由按同一个顺序排名。本章锁定参战而拒绝那个排名。1917年4月不是停战。从1917年4月到1918年11月是一年零七个月：十二个月把计数带到1918年4月，而五月到十一月再加七个月。美国的参战改变了联盟。在它发生的那一天，它没有停止作战。一条在四月到来的原因，不可能是前一年二月与七月已经开打的各场战役的解释。凡尔登与索姆河是1916年。美国参战是关于这场战争如何扩大的证据，不是关于它为什么开始的证据。那正是[[sources/argument]]对任何一条原因所要求的同一种纪律：它必须是本可以不一样的那种东西，而它必须在时间中被安放。

1918年3月3日，《布列斯特-立托夫斯克和约》把俄国带出这场战争。完整的论证，包括1917年的两种历法，属于[[wars/revolutions-1917]]。在这里，这份和约只有一件事要做。它是西线停战之前的那份东线和平。从3月3日到1918年11月11日是253天。在那一段里，德国不再与那个自1914年8月1日起与之交战的俄国国家作战。停战仍然落在11月11日，而不是一场德国的胜利。所以那份东线和平不能被叙述为决定了这场战争的那一步。它是一次真实的战线变化。它不是剧本的最后一行。我们不把1918年的战事描述为一种战术，也不发明一次攻势的发起日。年表锁定布列斯特-立托夫斯克与停战。那两个日期已经反驳了这样的想法：退出东方的战争与赢得西线的战争是同一件事。

:::quiz
在一个其问题止步于停战的一章里，布列斯特-立托夫斯克在做什么？
- [ ] 它取代停战，因为这场战争真的是在东端结束的。
- [x] 它是1918年3月3日的东线和平，提到它是为了不让11月11日的停战被错当成每一条战线的终结。诸革命是下一章。
- [ ] 它是1919年6月28日在镜厅签署的那份和约。
- [ ] 它是换了名字的索姆河的死亡总数。
:::solution
布列斯特-立托夫斯克的日期是1918年3月3日。它是革命中的俄国退出这场战争的方式。西线的停战仍然是1918年11月11日，晚253天，而不是一场德国的胜利。凡尔赛是1919年6月28日的另一份和约。这个名字底下没有藏着任何伤亡总数。下一章把诸革命、诸历法与这份和约当作它自己的题目。
:::
:::

年表对死亡总数的拒绝，本身就是关于方法的一则证据。它告诉你这门课程不会假装知道什么。它没有告诉你死者寥寥，也没有告诉你数字在历史中永远不正当。图谱别处的普查数字是锁定的，因为一个被陈述的计数连同它的警告可以被核对。一个史家们仍然以互不相容的方式重建的战场总数，在这里不被给予那种地位。如果你在另一本书里遇到一个精确的索姆河总数，你遇到的是那本书的选择。你没有遇到一个你可以悄悄引进的数字。

把窗口设为零，移动年份。在窗口为零时，被高亮的年份是一个单独的整数，而它旁边的标签是短的。1914年，标签“战争扩大”代替了一个本章已经当作教过的开场来对待的序列：7月28日、8月1日、8月3日、8月4日。1916年，一个圆点代表两场战役——它们的开端彼此相隔131天——也代表那一年里这个圆点无法显示的其他一切。1917年，圆点标记美国参战，无法显示俄国的诸革命。1918年，它标记停战，无法显示三月里的布列斯特-立托夫斯克。这幅图有用，正因为它薄。一页薄的目录页能阻止你把一个标签错当成一份死者名册。

:::warning 单一的堑壕与借来的总数
一幅熟悉的画面显示出一条泥泞的堑壕，把它叫作战争，并且把一个大的、凑整的死亡总数钉在凡尔登或索姆河上。两个部分都不成立。这场战争是在不止一条战线上打的，是由诸帝国的士兵打的，也是由宗主国的军队打的，而且它是由诸后方支撑起来的。年表没有锁定任何一场战役的死亡总数，所以一个借来的整数不是本课程的一个事实。拒绝这个整数，不是主张这些战役是次要的。这是一条关于证据的论断。这个迷思的第二个版本说，停战“就是凡尔赛”，或者战争的意义在1918年11月11日被签署了。和约是1919年6月28日。一次停止作战不是一份处置，而处置也不是一条你可以一路倒着跑到七月、使七月不再有余下的选择的因。
:::

:::history
1916年2月21日，凡尔登战役开始，而1916年7月1日，索姆河战役开始。1917年4月，美国参战。停战的日期是1918年11月11日。布列斯特-立托夫斯克和约，1918年3月3日，是那次停战之前的东线和平。这些日期没有一个是一个死亡总数。
:::

如果一个关于1916年的句子非要有死亡总数才能说出口，那么它就是依赖于一个本课程扣住不给的数字。如果一个关于1918年的句子分不清11月11日与1919年6月28日，那么它已经把两份文书合并了。会构成对这一章的形状的反证的，是这样的证据：没有帝国的征募，没有后方的动员，或者一份定在1918年11月11日的处置和约。一部单一堑壕的回忆录不会。它是在一个人的尺度上的证据。[[#thm-imperial]]立于或倒于征募、其他战线与诸部。

一座只点名一个村庄的战争纪念碑，是谁被刻在石头上的证据，不是战斗序列。本章不给出任何国家的死亡总数，也不给出1914–1918年的欧洲总数。“死者众多”是一个未锁定的数量所允许走到的远处。这场战争的种类在没有那个整数的情况下仍然是可描述的：一场诸帝国的联盟战争，不止一条战线，诸后方，凡尔登，索姆河，美国参战，作为较早的东线和平的布列斯特-立托夫斯克，以及停战。

## 通向何处

停战把俄国已经留在场外了，靠的是一份本章只给了日期的和约。[[wars/revolutions-1917]]接过1917年的两种历法、退位、十月，以及作为一次退出而不只是一次提及的布列斯特-立托夫斯克。那些和约，以及1918年之后的岁月是一条通往一个人的走廊这条论断，在[[wars/interwar]]。七月危机仍然在[[nations/toward-1914]]。一个日期如何不同于一个标签在[[sources/time-and-names]]，一条原因如何不同于一个标签在[[sources/argument]]。

:::summary
- 从1914年8月4日入侵比利时到1918年11月11日停战的这场战争，是一场诸帝国的多战线战争，不是一条单一的堑壕，也不是一个从七月带过来的单一原因。
- 殖民地与自治领的士兵与劳工是这场战争的一部分。他们的在场不是同意，而本章不给出人数。
- 后方——劳动、食物、审查、征兵——是战争工作。一张海报不是一个信念，而一段沉默不是一种情绪。
- 凡尔登在1916年2月21日开始，索姆河在1916年7月1日开始，晚131天。两场战役都不附带死亡总数。
- 美国在1917年4月参战。那扩大了联盟。它没有开始这场战争，也没有结束它。
- 布列斯特-立托夫斯克在1918年3月3日，是停战之前的东线和平。诸革命是下一章。东方的退出不是一场德国的胜利：停战仍然是1918年11月11日。
- 停战停止了作战。凡尔赛，1919年6月28日，是一份更晚的和约，签署在那座德意志帝国于1871年1月18日被宣告成立的大厅里。
:::

## 习题

:::exercise 停战的年份 {level=1 check="1918"}
本章中结束作战的这次停战在哪一年？（请输入四位数的年份。）
:::solution
停战是1918年11月11日。年份是1918。《凡尔赛和约》是1919年，不是答案。
:::
:::

:::exercise 美国参战 {level=1 check="1917"}
美国在哪一年参战？（请输入四位数的年份。）
:::solution
美国在1917年4月参战。年份是1917。入侵比利时是1914年，而停战是1918年。
:::
:::

:::exercise 年份之差 {level=1 check="4"}
用停战的年份数字减去入侵比利时的年份数字。（请输入年数。）
:::solution
入侵比利时在1914年，停战在1918年。于是1918 − 1914 = 4。这是年份标签之间的差。在停战之年内部，从8月4日到11月11日的一步是99天，在[[#ex-span-war]]里做过。那一步不是四年的差，而这两个整数都不是死亡总数。
:::
:::

:::exercise 索姆河的日期承载不了什么 {level=2}
一位同学说：“没有死亡总数，1916年7月1日就根本没法教。”请用这个日期确实支持什么、而年表扣住不给什么来回答。
:::solution
这个日期支持的是一条安置好的论断：索姆河在1916年7月1日开始，在凡尔登于1916年2月21日开始之后131天，在西线，在一场同时还有别的战线与后方的战争里。年表扣住一个死亡总数不给，并禁止发明一个。扣住总数挡住的是虚假精确。它没有抹去这场战役，也没有暗示这场战役是小的。从记忆里抄来的一个教科书整数修不好这个缺口。它会隐藏它。
:::
:::

:::exercise 停战对和约 {level=2}
说出停战的日期与凡尔赛和约的日期，并说一门把它们混在一起的课程为什么会通不过[[#thm-not-peace]]。
:::solution
停战是1918年11月11日。凡尔赛是1919年6月28日，签署于镜厅。[[#thm-not-peace]]说前者停止了作战，而后者是更晚的和平。把它们混在一起会把两份文书变成一个事件，并让1918去做1919的工作。德意志帝国在同一座大厅于1871年1月18日的宣告成立是第三个事件，不是一份更晚的和约早已在那里写就的证明。
:::
:::

:::exercise 什么会反驳帝国的论断 {level=2}
[[#thm-imperial]]说这场战争既是欧洲的，也是帝国的。给出一个会构成反证的发现，与一个不会构成反证的发现。
:::solution
会构成反证的一个发现是：1914–1918年交战诸国的军队与劳役没有在殖民地与自治领征募、也没有在一条欧洲战线之外作战的证据。不会构成反证的一个发现是一部回忆录，或一个发明出来的村庄，其中一名士兵对帝国毫不关心。那份证据是在一个人的尺度上说话的。那条论断说的是征募、战线与后方。殖民地的在场仍然不会证明同意。即使那条论断成立，论证的限度仍然存在。
:::
:::

:::exercise 发明出来的黄昏 {level=3}
下面这句话为示例而虚构。它不是史料。“1916年7月1日是索姆河的第一天，所以当晚的死亡总数是这个日期的一部分，可以被说出来。”日期与总数之间的差别是什么，而这句话的哪一半存活下来？
:::hint
与年表相符的那个子句，同一个发明出数量的子句，要分开。问一问：要把那个数量提升为一个锁定的数字，需要什么。
:::
:::solution
这句话是虚构的。日期存活下来：索姆河在1916年7月1日开始。总数没有。一个日期安置的是一个年表已经点名的事件。一个总数数的是人，而这个年表对索姆河拒绝了那个计数。把总数叫作“日期的一部分”是一种修辞上的滑移，不是一条证据的规则。要把任何这样的总数提升进来，年表必须说出它，并附上它的警告。它没有。同样的滑移在凡尔登、在1916年2月21日那里也行不通。你可以算出索姆河的开端晚131天。你不可以用发明出来的死者填满那些天。
:::
:::

:::exercise 四年跨度之内的闰日 {level=3 check="1"}
一名读者为1914年8月4日到1918年8月4日这一段用四乘365，然后加上从8月4日到11月11日的99天，而始终没有加上一个闰日。这名读者漏掉了多少个闰日？（请输入数字。）
:::hint
检查这两个八月日期之间的哪些年份是闰年。从八月到十一月的那一步已经在1918年内部走过了，而它不是闰年，所以它没有藏住那个缺失的日子。
:::
:::solution
这名读者漏掉了一个闰日。从1914年8月4日到1918年8月4日，唯一的闰日是1916年2月29日。1914年与1918年不是闰年。从8月4日到11月11日的99天的一步坐在1918年之内，不包含那个二月。纠正后的跨度是读者的数字加一天。我们不需要一个四位数的总计数就能看出这个错误。结果仍然是一段时长，不是一份伤亡总数。漏掉的闰日数是1。
:::
:::
