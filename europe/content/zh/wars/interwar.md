为什么1918年至1939年不是一条通向一个人的走廊？因为这些年里有不止一个政权、不止一项和约、不止一场危机，还因为通常叙事中的那个人在这段时期开始时并不在位。停战（armistice）在1918年11月11日。希特勒（Hitler）于1933年1月30日被任命为总理。德国入侵波兰在1939年9月1日。这些日期之间，有巴黎各项和约、一次失败的暴动（putsch）、一次向罗马进军、苏联的成立、一场与欧洲各国萧条并不同日发生的金融崩溃、一场西班牙内战，以及若干并非德国的威权政府。走廊叙事从《凡尔赛（Versailles）和约》画一条直线到一次任命，再到一场战争，其余一切都被当作布景。除非把这些日期抹掉，否则它们不会安分地待在这条线上。

本章拒绝这种抹除，也拒绝给出赔款数额、选票总数与死亡总数。凡尔赛和约究竟有多苛刻，史家们意见不一；这一分歧是正文的组成部分，而不是脚注。年表锁定的是签字的日期、其他各项和约的名称以及后来的政治日期。德国人感受到的屈辱可以是真实的，但屈辱并不是一份任命总理的时间表。前面各章已经拒绝了1914年的单一原因和1917年的宿命。同样的纪律也适用于这里，否则两次大战之间的岁月就会塌缩成一篇序言。它们并不是序言。在这些年里，若干种不同类型的国家被建立起来；其中德国的一段进程短促而暴烈，仍须按它自己的那几个星期来讲述。

## 多项和约，而非一次签字

1919年6月28日，凡尔赛和约在镜厅签订。德意志帝国曾于1871年1月18日在这座大厅宣告成立。两个年份相差48，因为1919减1871得48。同一个大厅，两个行为。后者并不是前者机械导致的报复，前者也不是后者的草稿。凡尔赛和约是对德和约。它规定了领土损失、军事限制与赔款，并包含一项确定战争责任归属的条款。我们不给出赔款金额、军队规模，也不给出关于和约的表决结果。这些整数没有锁定，编造它们只会让虚假的精确看起来像是解释。

凡尔赛和约只是巴黎和会各项安排之一，而不是和平的全部。1919年还缔结了圣日耳曼（Saint-Germain）和约与纳伊（Neuilly）和约，前者对奥地利，后者对保加利亚。1920年6月4日，《特里亚农（Trianon）和约》与匈牙利签订。1920年，《塞夫尔（Sèvres）和约》被强加给奥斯曼帝国，后来又经修订。年表没有锁定修订的年份，所以我们不予编造。凡是说“凡尔赛”而指整个欧洲版图重划的人，已经遗漏了特里亚农、圣日耳曼、纳伊与塞夫尔。哈布斯堡帝国并不是仅凭对德和约就告终结的，匈牙利的损失是特里亚农和约的内容。混淆这些文件，就会让德国的一种屈辱代表每一条新边界。

新的版图中，包括了一些在1914年还不是主权国家的国家。波兰是最清楚的例子，其背景锁定得更早：1772年、1793年与1795年的历次瓜分曾把波兰联邦作为国家抹去，而在战后安排中，波兰国家得以重建。我们不指定其宣告成立的日期，因为年表没有锁定。捷克斯洛伐克、一个南部斯拉夫人的王国、波罗的海国家，以及分立的奥地利共和国与匈牙利共和国，也适用同样的谨慎：说出政治结果，不要用未锁定的纪念日加以点缀。就本章而言，这些和约的要点在于：它们是复数的，是有日期的，而且早于各个独裁政权足够多年，足以堵住那条走廊。

:::definition 巴黎和会各项和约 {#def-paris}
**巴黎和会各项和约**指与战败国缔结、结束1914年至1918年战争的各项和约：1919年6月28日对德国的凡尔赛和约；1919年对奥地利的圣日耳曼和约与对保加利亚的纳伊和约；1920年6月4日对匈牙利的特里亚农和约；1920年对奥斯曼帝国的塞夫尔和约，后来在本图谱未锁定的日期经过修订。凡尔赛和约是其中之一，而不是它们的总称。
:::

:::definition 走廊叙事 {#def-corridor}
关于这些年的**走廊叙事**，是这样一种说法：1918年至1939年只是从凡尔赛通向希特勒的道路，其他每个政权不是他的预演，就是一段插曲。这种叙事是[[sources/argument]]意义上的标签，它掩盖了种种选择、失败以及不合其框架的国家。
:::

:::theorem 这些年并不是那条走廊 {#thm-not-corridor}
1918年至1939年的政治，不能化约为一条从凡尔赛和约通向德国一次任命的道路。意大利的向罗马进军、苏联的成立、慕尼黑暴动的失败、西班牙内战以及其他地方的威权政权，都各有日期或各有名称。即使对凡尔赛和约作最苛刻的解读（史家们对此意见不一），也不能单凭它恢复那条走廊。
:::
:::proof
证据在于日期的分布。向罗马进军在1922年10月28日，早于希特勒的任命，也早于华尔街崩盘。苏联成立于1922年12月30日，是另一种类型的一党制国家，而不是德国的翻版。1923年11月8日至9日的慕尼黑暴动失败了，所以后来被任命的那个人，在1923年是一个夺权企图已遭挫败的人。西班牙内战从1936年7月17日至18日持续到1939年4月1日，尽管有其他国家干预，它也不是德国的内部事件。葡萄牙以及东欧和南欧若干国家的威权统治，是这一时期的事实。我们不给出各次政变的日期，因为编造一份政变清单会伪造年表所拒绝提供的精确。被纳入战后秩序的英国与法国，也没有变成那种德国政权。能够支持走廊叙事的，是证明这些替代道路全是幻象，或者证明1933年1月30日的任命已由1919年的文本确定、无须再作任何决定。然而这些替代道路并非幻象，任命也是一项决定。不能挽救走廊叙事的，是凡尔赛和约在德国普遍遭到怨恨这一真实情况。怨恨可以是真实的，史家们也仍可对和约的分量意见不一，但怨恨并不因此成为充分原因。原因必须是本可以不同的那类事物，而那次失败的暴动正是“不同”的证明。
:::

:::theorem 这次任命是数周之内的一系列行为，而非选票总数 {#thm-sequence}
希特勒于1933年1月30日被任命为总理。国会（Reichstag）纵火案发生在1933年2月27日。《授权法》（Enabling Act）在1933年3月23日。这是一系列政治行为，而不是选票总数（本章不会编造），也不是1919年的事件。
:::
:::proof
计算1933年内部的间隔，这一年不是闰年。1月30日是第30天。2月27日是第58天，因为一月有31天，31 + 27 = 58。纵火案在任命之后58 − 30 = 28天。3月23日是第82天，因为一月与二月共31 + 28 = 59天，59 + 23 = 82。《授权法》在纵火案之后82 − 58 = 24天，在任命之后82 − 30 = 52天。年表锁定这三个日期，却没有锁定任何议会计票。能够推翻这一论断的，是一个锁定的选票总数，表明总理职位是在1月30日经某次具体表决授予的；或者是一份把《授权法》放在1919年的史料。这里没有这样的总数，而《授权法》在1933年3月23日。不能推翻它的，是这一政权后来的历史。这一系列行为解释的是：总理职位如何变成一个能够越过通常议会限制而立法的政府。它不能解释西班牙的战争、苏维埃国家，也不能解释意大利君主在1922年10月28日所起的作用。这些都在那五十二天之外。
:::

:::quiz
哪一份清单列的是不同的和约，而不是凡尔赛和约的五个别名？
- [ ] 凡尔赛、镜厅、战争罪责条款、赔款与波兰边界。
- [x] 对德国的凡尔赛和约、对奥地利的圣日耳曼和约、对保加利亚的纳伊和约、对匈牙利的特里亚农和约，以及对奥斯曼帝国的塞夫尔和约。
- [ ] 向罗马进军、苏联、暴动、《授权法》与条约。
- [ ] 凡尔登、索姆河、布列斯特-立托夫斯克、停战与十月。
:::solution
第二份清单就是[[#def-paris]]。第一份清单是对德和约内部或与之相关的一组话题，而不是巴黎的其他和约。第三份清单是后来的政治，而不是和平文件。第四份清单属于战争与革命。塞夫尔和约后来经过修订，而修订的年份没有锁定，这是对第五个名称的限定，而不是把它并入凡尔赛的理由。
:::
:::

## 拒绝直线的日期

走廊是一幅关于时间的图像。破坏它的办法，就是把日期放回去，包括那些来得太早的日期和那些以失败告终的日期。

:::example 排不成一条线的年份标签 {#ex-year-gaps}
只使用年份数字，计算1923减1919、1933减1923与1939减1933，并说明每个间隔分开了什么。
:::solution
1923 − 1919 = 4。四个年份标签把凡尔赛和约与失败的慕尼黑暴动分开。1933 − 1923 = 10。十个年份标签把这次失败与1933年1月30日的任命分开。1939 − 1933 = 6。六个年份标签把任命与《莫洛托夫-里宾特洛甫（Molotov–Ribbentrop）条约》以及入侵波兰分开，后两者都在1939年。这些间隔都不是天数，也都不是表决。合在一起，它们与“1919年已经就是1933年”的叙事不相容。暴动有时间失败，任命也有时间不发生。但它还是发生了，经由[[#thm-sequence]]中的那一系列行为；那是1933年之内的选择，而不是和约的成熟。
:::
:::

:::example 五十二天 {#ex-fifty-two}
不借助选票总数，重新计算从1933年1月30日到1933年3月23日的天数。《授权法》在任命之后多少天？国会纵火案的28天与随后的24天如何衔接？
:::solution
如[[#thm-sequence]]的论证所示：纵火案在1月30日之后28天，《授权法》在2月27日之后24天。28 + 24 = 52。《授权法》在任命之后52天。这五十二天里有一场火和一部法律，却没有任何计票数字，因为没有锁定。它们也不能回溯到1919年6月28日。把《授权法》称为“凡尔赛的结果”的读者，既跳过了失败的暴动，也跳过了这几个星期。这几个星期很短，而短正是要点所在。这一政权的法律断裂是一个可以计数的过程，而不是笼罩十四年的一团迷雾。十四是1933减1919，是另一个年份标签间隔，与52不是同一回事。
:::
:::

:::example 九天，以及西班牙的另一场战争 {#ex-nine-and-spain}
《莫洛托夫-里宾特洛甫条约》签订于1939年8月23日，德国于1939年9月1日入侵波兰。两个日期之间相隔多少天？另外，西班牙内战于1939年4月1日结束，9月1日在内战结束之后多少天？请把两段跨度分开。
:::solution
从8月23日到9月1日是九天，入侵在条约签订九天之后。这种紧邻是真实的，它属于本章末尾与下一章开头讲授的直接序幕，而不是1919年的缩影。从4月1日到9月1日：四月有30天，4月1日之后还剩29天，然后是五月31天、六月30天、七月31天、八月31天，再加9月1日。29 + 31 + 30 + 31 + 31 + 1 = 153。所以9月1日在西班牙战争结束之后153天。西班牙的战争在入侵波兰之前就已结束，两者不是同一场战争。把西班牙的1936年至1939年当作带有地方色彩的德国走廊，在这一计算面前站不住脚。
:::
:::

:::example 编造的走廊句 {#ex-invented-corridor}
下面这句话为示例而虚构。它不是史料。“1919年，德国人民在凡尔赛和约之下投票让希特勒上台，所以1923年的暴动不可能失败，1933年的任命只是走个形式。”请列出其中的错误。
:::solution
这句话是虚构的。它在1919年安插了一次年表并未记录的投票，而本章在任何年份都不得编造选票总数。它把和约与任命当作同一事件。它否认了1923年11月8日至9日那次失败的暴动，而年表锁定的恰恰是这次失败。它把1933年1月30日称为走形式，这与[[#thm-sequence]]相抵触，后者为随后几周中的一场火和一部《授权法》定了年。一句经得起检验的改写有意平淡：凡尔赛和约于1919年6月28日签订；一次暴动于1923年11月失败；希特勒于1933年1月30日被任命，52天后是3月23日的《授权法》。平淡就是检验。编造的那句话之所以令人激动，是因为它删掉了[[#ex-year-gaps]]中的那些间隔。
:::
:::

华尔街崩盘有意标注了两个日期：1929年10月24日是“黑色星期四”，1929年10月29日是“黑色星期二”。欧洲各国的萧条与这场危机相关联，却不是同一天发生的同一事件。英国的劳动力市场、德国的银行危机与法国的贸易格局，不会随纽约某个下午的钟声同时改变。我们说它们相互关联，但不给出失业率，因为没有锁定任何百分比，而借来的百分比会假装一个数字可以描述若干个国家。这场崩盘之所以构成反驳走廊叙事的论证，还有另一个原因：它发生在向罗马进军和苏联成立之后，那些政权并不是从这场恐慌中诞生的。德国的任命则在恐慌之后的1933年，这是认真对待经济危机的理由，而不是把它说成和约之化身的理由。

意大利是最干净的早期反例。1922年10月28日，向罗马进军把墨索里尼（Mussolini）的法西斯分子带到了权力边缘，国王请他组阁。这在多大程度上是一场以暴动相威胁的行动、又在多大程度上是一次谈判达成的权力移交，史家们争论不休。我们报告这一争论，而不编造国王的言辞。无论哪种解读，都堵住了走廊。意大利的法西斯政府早在1933年1月30日之前数年就已存在。它不是德国的事件，也不能证明凡尔赛和约造成了它。意大利与和约的关系也不同于德国。

1922年12月30日成立的苏联，是另一个德国人物传记无法吞并的早期国家。它是意识形态不同的一党专政，建立于1917年的革命与布列斯特-立托夫斯克的退出之后。本章不为后来的集体化或恐怖等内部运动定年，因为这些日期没有锁定，也不给出死亡总数。成立的日期已足以支撑[[#thm-not-corridor]]中的论断。一幅既有1922年10月的罗马、又有1922年12月的苏维埃联盟的欧洲地图，就已经不是通向一个人的走廊。再加上在这几十年间由威权政权统治的葡萄牙，以及东欧和南欧若干国家的威权政府，也能说明同一点，而无须一份伪造的政变年表。不给出这些政变日期，是一条证据规则，而不是说这些政权温和，或者说它们不曾存在。

:::quiz
1923年11月8日至9日的失败对走廊叙事有何影响？
- [ ] 它表明希特勒当时已是总理，所以后来的任命只是重复。
- [ ] 它表明凡尔赛和约已被废除。
- [x] 它表明一次夺权企图失败了，那是在1933年1月30日之前数年，所以1919年并没有把他送上权位。
- [ ] 它就是换了名称的西班牙内战。
:::solution
暴动失败了，而失败正是年表特意锁定的事实。任命在1933年1月30日，从1923年到1933年的年份标签之差为10，见[[#ex-year-gaps]]。凡尔赛和约在1923年并未被废除。西班牙的战争始于1936年。一个认为和约使总理职位不可避免的叙事，要么必须抹去一次有日期的失败，要么必须假装这次失败无关紧要。这次失败之所以要紧，是因为它证明政治本可以走向另一条路。后来走上了这条路，是又一系列行为的结果，并不能证明另一条路本不可能。
:::
:::

纽伦堡与“十一月大迫害”属于本章，因为它们发生在任命之后、1939年战争之前，也因为后面各章不得被讲述成仿佛迫害始于万湖（Wannsee）。1935年9月15日，《纽伦堡法》在法律上界定了谁算犹太人，并禁止犹太人与法律认定为德意志血统的人之间通婚和发生性关系。这是对这种法律排斥的转述，不是引文，也不是[[wars/genocide]]中讲授的屠杀。1938年11月9日至10日，“十一月大迫害”（pogrom），年表中又称“水晶之夜”（Kristallnacht），袭击了德国境内的犹太人生活：会堂、商店、逮捕。我们不给出死亡总数。“碎玻璃”之名突出的是财产，“十一月大迫害”则把针对人的暴力保留在句子之中。无论《纽伦堡法》还是这场迫害，都不是选票总数，也都不是凡尔赛和约。

关于西班牙的战争，还需要再作一项区分。它始于1936年7月17日至18日，于1939年4月1日以佛朗哥（Franco）一方的胜利告终。德国、意大利与苏联都进行了干预。我们不给出兵力数字。干预表明这场战争国际化了，却并没有使西班牙成为德国故事的一个省份，也没有使每个西班牙人都成为某一道德类型的战斗者。从这场战争结束到入侵波兰相隔153天。邻近不等于同一。

移动年份。窗口为一时，你看到的是相邻的点，而不是熔为一体的线。1922年的数据点必须同时承载向罗马进军与苏联成立，这两个政权正是走廊叙事宁愿归档为预备动作的。1929年的数据点是美国股市崩盘，而课文已经拒绝把它当作欧洲萧条的唯一日期。1933年的数据点是一次任命，而不是和约。1938年是慕尼黑，它既不是德国扩张的全部，也不是同年发生却不在图上的十一月大迫害。1939年是那项条约，在入侵前九天，图到此为止。图注要你看到的，是从1933年到1939年的六个年份标签，即1939减1933得6。如果这条线看起来像走廊，本课就失败了。这些数据点之所以在那里，是为了让你能够拒绝那条线。

结尾的这一系列事件开启了下一章，却不能取代本章。1938年3月，德奥合并（Anschluss）把奥地利并入德国。1938年9月30日，《慕尼黑协定》满足了德国对捷克斯洛伐克苏台德（Sudeten）地区的要求。我们不引用当时宣称该协定已经保障和平的言论。从1938年9月30日到1939年9月1日为336天：非闰年有365天，365减29得336，因为9月1日比9月30日的周年日早29天。这一协定距入侵不到一年，但它不是入侵。1939年8月23日，《莫洛托夫-里宾特洛甫条约》以一项公开的互不侵犯协定把纳粹德国与苏联绑在一起。史家们还把一份后来发现的秘密议定书解读为划分了东欧的势力范围。我们不编造议定书的条款。九天之后，德国入侵波兰。这项条约是那次入侵的直接政治背景的一部分，它不是凡尔赛的缩影，也没有使苏联沦为德国的附庸。1941年6月，德国将入侵苏联。这个日期属于下一章，在此提及，是为了防止读者在1939年收尾时以为这项条约是永久的。它是一个有日期的选择，后来被另一个选择打破。

:::warning 和约使总理职位不可避免的迷思
这种迷思说，凡尔赛和约使希特勒不可避免。还没等它作为一种因果理论失败，它就已经在日期面前失败了。和约在1919年6月28日。暴动于1923年11月8日至9日失败。任命在1933年1月30日，随后是一场火，然后是《授权法》，都在52天之内，本课程不给出任何选票总数。自1922年向罗马进军起，意大利就有了法西斯政府。苏联自1922年12月30日起作为联盟存在。西班牙的战争从1936年持续到1939年4月1日。其他威权政权也都存在，我们无须编造它们的政变日期。凡尔赛和约究竟有多苛刻，史家们意见不一，我们也不锁定任何可以终结这场争论的赔款数额。沉重的屈辱并不是充分原因。能够支持这种迷思的，是一条既无替代道路、也无失败暴动的链条，而替代道路与那次失败恰恰就是记录。不要通过把1933年称为走形式，让这种迷思卷土重来。
:::

:::history
凡尔赛和约于1919年6月28日在镜厅签订，德意志帝国曾于1871年1月18日在那里宣告成立。它是巴黎和会各项安排之一，而不是和平的全部。希特勒于1933年1月30日被任命为总理。国会纵火案发生在1933年2月27日，随后是3月23日的《授权法》。
:::

能够推翻[[#thm-not-corridor]]的，是这样一份史料：它表明向罗马进军、苏联的成立、西班牙的战争以及其他威权政权，都是1919年为成就某一个人的生涯而创造的德国工具。事实并非如此。在演说中谴责和约，是政治的证据，而不是日历的证据。完整的案例仍是[[#ex-invented-corridor]]。把1919年6月28日、1923年11月失败的暴动与1933年1月30日的任命分开，也别把罗马与苏联放到那条线上。

## 通向何处

1939年8月23日的条约与9月1日的入侵，是转入[[wars/second-world-war]]的枢纽。缔造了签署该条约之国家的那些革命，以及1917年的历法，见[[wars/revolutions-1917]]。对犹太人的屠杀——《纽伦堡法》与十一月大迫害还远非其全部——见[[wars/genocide]]。“走廊”这样的标签与原因有何不同，见[[sources/argument]]。

:::summary
- 巴黎和会各项和约是复数的：凡尔赛和约在1919年6月28日，圣日耳曼和约与纳伊和约在1919年，特里亚农和约在1920年6月4日，塞夫尔和约在1920年，后来在未锁定的日期经过修订。同一座大厅也见证了1871年1月18日的宣告。
- 凡尔赛和约究竟有多苛刻，史家们意见不一。赔款数额与选票总数都没有锁定。屈辱并不是充分原因。
- 向罗马进军在1922年10月28日。苏联成立于1922年12月30日。1923年11月8日至9日的慕尼黑暴动失败。这些日期都不是德国故事的布景。
- 华尔街崩盘在1929年10月24日与29日。欧洲各国的萧条与之相关，却不在那一天，这里也不给出百分比。
- 希特勒于1933年1月30日被任命。国会纵火案在28天之后。《授权法》在纵火案之后24天，即任命之后52天。
- 《纽伦堡法》在1935年9月15日。十一月大迫害在1938年11月9日至10日。西班牙的战争从1936年7月17日至18日持续到1939年4月1日。其他威权政权也曾存在，我们不编造它们的政变日期。
- 德奥合并在1938年3月。慕尼黑在1938年9月30日，比1939年9月1日早336天。苏德条约在1939年8月23日，比入侵早九天。这一切都不能把1919年变成1939年。
:::

## 习题

:::exercise 和约的年份 {level=1 check="1919"}
凡尔赛和约签订于哪一年？（请输入四位数年份。）
:::solution
凡尔赛和约签订于1919年6月28日，年份是1919。希特勒的任命在1933年，不是答案。特里亚农和约在1920年。
:::
:::

:::exercise 六个年份标签 {level=1 check="6"}
用《莫洛托夫-里宾特洛甫条约》的年份减去希特勒被任命的年份。（请输入年份标签的个数。）
:::solution
任命在1933年，条约在1939年。于是1939 − 1933 = 6。图示的图注正是建立在这个间隔之上。这并不是说两者之间什么也没有发生，它也不是天数。
:::
:::

:::exercise 从条约到入侵 {level=1 check="9"}
1939年9月1日在1939年8月23日之后多少天？（请输入天数。）
:::solution
从8月23日到9月1日是9天。入侵波兰在条约签订9天之后。这段距离不是与凡尔赛的距离，也不是从1939年4月1日西班牙战争结束算起的153天。
:::
:::

:::exercise 说出和约的名称 {level=2}
一名学生说，特里亚农和约是在镜厅与德国签订的和约。请纠正凡尔赛、特里亚农与塞夫尔三项和约的对应关系，并说明塞夫尔和约的限定。
:::solution
1919年6月28日在镜厅签订的凡尔赛和约是对德和约。1920年6月4日的特里亚农和约是对匈牙利和约。1920年的塞夫尔和约是对奥斯曼帝国和约，后来经过修订。年表没有锁定修订的年份，所以纠正后的答案到此为止，不予编造。圣日耳曼和约与纳伊和约都在1919年，分别对奥地利与保加利亚。[[#def-paris]]列出了全部。
:::
:::

:::exercise 为什么1922年对走廊叙事是致命的 {level=2}
仅使用1922年10月28日与1922年12月30日两个日期，解释为什么一个始于凡尔赛、终于希特勒的叙事，在1929年之前就已失败。
:::solution
1922年10月28日，向罗马进军使意大利出现了法西斯政府，比德国那次任命早数年，也早于华尔街崩盘。1922年12月30日，苏联成立，这是另一种专政，同样早于那次崩盘，也早于1933年1月30日。[[#thm-not-corridor]]把这两个日期作为走廊叙事必须抹去的替代道路。它们不是德国的事件，也不是预演。对凡尔赛的怨恨，即使史家们判定和约苛刻，也造不出罗马或苏联。
:::
:::

:::exercise 没有数额的分歧 {level=2}
凡尔赛和约究竟有多苛刻，史家们意见不一。你可以说什么？又仍须拒绝哪些整数？这一分歧与[[#thm-not-corridor]]有什么关系？
:::solution
你可以说，这项和约规定了领土损失、军事限制、赔款以及一项责任条款，而史家们对这一安排的分量意见不一。你必须拒绝赔款数额、军队规模与选票总数，因为它们都没有锁定。这一分歧并不能恢复走廊叙事。无论和约被判定苛刻与否，[[#thm-not-corridor]]都成立，因为1919年的一份文件并不是1933年的任命、失败的暴动或其他政权。即使有了一个数额，也不能使怨恨成为充分原因。
:::
:::

:::exercise 修正编造的句子 {level=3}
改写[[#ex-invented-corridor]]中那句编造的话，使每个日期都成立，且不出现任何表决。然后说明，哪一个单独的改动会使你的改写重新变成错误。
:::hint
保留三个锁定的日期：和约、失败的暴动、任命。不要引入投票。如果把这三者压进同一年，或者把暴动描述为成功，改写就会再次失效。
:::
:::solution
一种改写是：凡尔赛和约于1919年6月28日签订；慕尼黑暴动于1923年11月8日至9日失败；希特勒于1933年1月30日被任命为总理，随后是3月23日的《授权法》，在任命之后52天。其中没有出现选票总数。如果把暴动说成成功，或把任命移到1919年，或插入一个计票数字，这一改写就会变成错误。这些正是编造的原句所叠加的错误。可以加上西班牙的战争、向罗马进军与苏联，但它们并不能挽救原句；它们是[[#thm-not-corridor]]的进一步证据，而不是装饰。
:::
:::

:::exercise 慕尼黑不是9月1日 {level=3}
请证明1938年9月30日与1939年9月1日相隔336天，并解释为什么只把年份相减、得出1的学生回答的是另一个问题。这段336天的跨度不能证明关于苏德条约的什么？
:::hint
在非闰年中，从9月30日到下一个9月30日是365天。9月1日比这个周年日早29天。苏德条约在1939年8月23日，这是第三个日期。
:::
:::solution
1939年不是闰年。从1938年9月30日到1939年9月30日是365天。9月1日比9月30日早29天，365 − 29 = 336。入侵在慕尼黑之后336天。把年份相减，1939 − 1938 = 1，只说明两个年份标签相差一，却丢掉了月份。这段336天的跨度表明，慕尼黑没有阻止入侵，而且慕尼黑不是入侵。它既不能为苏德条约定年（条约在1939年8月23日，比9月1日早九天），也不引用任何人在慕尼黑说过的话，更不能使凡尔赛成为原因。走廊叙事在这里失败，正如它在1922年与1923年失败一样：有日期的行为太多，却没有一条穿过某一个人的充分直线。
:::
:::
