1918–1939年为什么不是一条通往一个人的走廊？因为这些年头装着不止一个政权、不止一份和约与不止一场危机，而且因为通常故事里的那个人在它们的开端并不在位。停战（armistice）是1918年11月11日。希特勒（Hitler）在1933年1月30日被任命为总理。德国入侵波兰是1939年9月1日。在这些日期之间躺着巴黎诸和约、一次失败的暴动（putsch）、一次向罗马的进军、苏联的成立、一场与欧洲的每一场萧条都不在同一天的金融大崩溃、一场西班牙内战，以及若干不是德国的威权政府。一个走廊故事从凡尔赛（Versailles）和约画一条直线到一次任命，再到一场战争，并把其余一切都当作布景。那些日期不会肯待在那条线上，除非我们把它们擦掉。

本章拒绝这种擦除。它也拒绝一个赔款数额、一个票数总和与一个死亡总数。史家们就凡尔赛有多沉重意见不一。这场分歧是正文的一部分，不是一条脚注。年表锁定的，是签字的那一天、另外那些和约的名字与后来的那些政治日期。在德国被感受到的一次冤屈可以是真的。一次冤屈不是一个任命总理的时间表。前面的各章已经拒绝过1914年的单条原因与1917年的命运。同样的纪律适用于这里，否则战间期的那些年就会坍缩成一篇序言。它们不是一篇序言。它们是若干种不同的国家被制造出来的年头，而在其中，一个德国的序列，短促而暴力，仍然必须在它自己的几个星期里被讲述。

## 若干份和约，不是一次签字

1919年6月28日，凡尔赛和约签署在镜厅。德意志帝国曾于1871年1月18日在那座大厅宣告成立。年份数字之差是48，因为1919减1871是48。同一间屋子，两个行为。第二个不是第一个机械地蕴含的复仇，而第一个不是第二个的草稿。凡尔赛是与德国的和约。它强加了领土损失、军事限制与赔款，并且它包含一条裁定战争责任归属的条款。我们不给出一个钱的数额、一支军队的规模，或一次对该和约的表决。那些整数是未锁定的。发明它们会让一种虚假精确看起来像一个解释。

凡尔赛是巴黎诸和约中的一个，不是全部的和约。1919年，《圣日耳曼（Saint-Germain）和约》与《纳伊（Neuilly）和约》也缔结了：圣日耳曼是与奥地利，纳伊是与保加利亚。1920年6月4日，《特里亚农（Trianon）和约》与匈牙利签署。1920年，《塞夫尔（Sèvres）和约》被强加于奥斯曼帝国，而它后来被修订。年表没有锁定那次修订的年份，所以我们不发明一个。任何说出“凡尔赛”而意指欧洲的全部重新划分的人，已经弄丢了特里亚农、圣日耳曼、纳伊与塞夫尔。哈布斯堡帝国不是只凭与德国的那份和约就终结的。匈牙利的损失是特里亚农的题目。混淆这些文书，就是使一次德国的冤屈去代表每一条新边界的做法。

新地图包括了在1914年还不是主权国家的诸国。波兰是有着更长锁定的最清楚的例子：1772年、1793年与1795年的瓜分曾把那个联邦作为一个国家抹去。一个波兰国家在处置之中重新存在。我们不指定一个宣告成立的日子，因为年表没有锁定一个。捷克斯洛伐克、一个南部斯拉夫王国、波罗的海诸国，以及分开的奥地利与匈牙利诸共和国，都属于同一条小心。说出那个政治结果。不要用一场未锁定的周年纪念来装饰它。对这些和约来说，本章的要点是：它们是复数的，是有日期的，而且比诸独裁政权早足够的年头，足以挡住一条走廊。

:::definition 巴黎诸和约 {#def-paris}
**巴黎诸和约**是1914–1918年的战争中与诸战败国缔结的那些和约：凡尔赛是与德国，1919年6月28日；圣日耳曼是与奥地利，纳伊是与保加利亚，1919年；特里亚农是与匈牙利，1920年6月4日；塞夫尔是与奥斯曼帝国，1920年，后来在一个本图谱没有锁定的日期被修订。凡尔赛是它们中的一个。它不是它们的名字。
:::

:::definition 一个走廊故事 {#def-corridor}
关于这些年的一个**走廊故事**是这样一个说法：1918–1939年只是从凡尔赛到希特勒的道路，而每一个别的政权要么是他的预演，要么是一次中断。这个故事是[[sources/argument]]意义上的一个标签。它藏起选择、失败与那些不相合的国家。
:::

:::theorem 这些年头不是那条走廊 {#thm-not-corridor}
1918–1939年的政治不能被化约为一条从凡尔赛和约到一次德国任命的道路。意大利的向罗马进军、苏联的成立、慕尼黑暴动的失败、西班牙内战，以及别处的威权政权，是各自有日期或各自有名的。一个关于凡尔赛的严苛解读——史家们对它意见不一——单凭自身不能恢复那条走廊。
:::
:::proof
证据是那些日期的分布。向罗马进军是1922年10月28日，在希特勒的任命之前，也在华尔街崩盘之前。苏联成立于1922年12月30日，是一种不同种类的一党国家，不是德国的翻版。1923年11月8–9日的慕尼黑暴动失败了，所以那个后来被任命的人，在1923年，是一个夺权的尝试已经被拦下的人。西班牙内战从1936年7月17–18日一直打到1939年4月1日，而不是一场德国的内部事件，尽管别的国家干预。葡萄牙的威权统治，以及东部与南部的若干欧洲国家的威权统治，是那个时期的一条事实。我们不给出政变的日期，因为发明一份它们的清单会伪造一种年表扣住不给的精确。被绑进战后秩序里的英国与法国，没有变成那个德国政权。会支持那条走廊的，是一个证明，表明这些替代项每一个都是虚幻的，或者表明1933年1月30日的任命是被1919年的文本在没有任何进一步决定的情况下定好的。这些替代项不是虚幻的，而任命是一个决定。不能挽救那条走廊的，是凡尔赛在德国被广泛怨恨这个真实的事实。怨恨可以是真的，而史家们仍然可以就那个和约的分量意见不一，怨恨并不因此就是一条充足的原因。一条原因必须是本可以不一样的那种东西。那次失败的暴动就是那个别样。
:::

:::theorem 那次任命是一个数周的序列，不是一个票数总和 {#thm-sequence}
希特勒在1933年1月30日被任命为总理。帝国议会（Reichstag）的纵火案在1933年2月27日。《授权法》（Enabling Act）在1933年3月23日。这是一个政治行为的序列。它不是一个票数总和，本章不会发明一个，而它也不是1919年的一个事件。
:::
:::proof
数一数1933年内部的间隔，它不是闰年。1月30日是第30天。2月27日是第58天，因为一月有31天，而31 + 27 = 58。纵火案在任命之后58 − 30 = 28天。3月23日是第82天，因为一月与二月有31 + 28 = 59天，而59 + 23 = 82。《授权法》在纵火案之后82 − 58 = 24天，在任命之后82 − 30 = 52天。年表锁定这三个日期，而不锁定任何议会票数。会构成对这条论断的反证的，是一个锁定的票数总和，显示总理的职位在1月30日由一次具名的投票授予，或者一份把《授权法》放在1919年的史料。这里没有这样的总数，而那个法令是1933年3月23日。不会构成反证的，是那个政权的后来历史。这个序列解释了一个总理职位如何变成一个能够越过通常的议会限制来立法的政府。它不解释西班牙的战争、苏维埃国家，或意大利的君主制在1922年10月28日的角色。那些都留在那五十二天之外。
:::

:::quiz
哪一份清单是不同和约的清单，而不是凡尔赛的五个名字？
- [ ] 凡尔赛、镜厅、战争罪责条款、赔款与波兰边界。
- [x] 凡尔赛是与德国，圣日耳曼是与奥地利，纳伊是与保加利亚，特里亚农是与匈牙利，塞夫尔是与奥斯曼帝国。
- [ ] 向罗马进军、苏联、暴动、《授权法》与协定。
- [ ] 凡尔登、索姆河、布列斯特-立托夫斯克、停战与十月。
:::solution
第二份清单就是[[#def-paris]]。第一份清单是与德国的那份和约之内或之旁的一组话题，不是另外的巴黎诸和约。第三份清单是后来的政治，不是和平的文书。第四份清单属于战争与诸革命。塞夫尔后来被修订，而修订的年份没有被锁定，这是第五个名字的一个限度，不是一个把它折进凡尔赛的理由。
:::
:::

## 拒绝直线的日期

走廊是一幅时间的图像。损害它的办法是把日期放回去，包括那些来得太早的日期和那些失败的日期。

:::example 排列不齐的年份标签 {#ex-year-gaps}
只使用年份数字，计算1923减1919、1933减1923与1939减1933。说出每个间隔把什么分开。
:::solution
1923 − 1919 = 4。四个年份标签把凡尔赛和约与那次失败的慕尼黑暴动分开。1933 − 1923 = 10。十个年份标签把那次失败与1933年1月30日的任命分开。1939 − 1933 = 6。六个年份标签把任命与莫洛托夫-里宾特洛甫（Molotov–Ribbentrop）协定、也与入侵波兰分开，两者都在1939年。这些间隔没有一个是一个天数，也没有一个是一个表决。它们合在一起，与一个1919年已经就是1933年的故事不相容。暴动有时间失败。任命有时间不发生。它还是发生了，通过[[#thm-sequence]]里的那个序列，那是1933年内部的一个选择，不是那个和约的成熟。
:::
:::

:::example 五十二天 {#ex-fifty-two}
不用票数总和，重复从1933年1月30日到1933年3月23日的计数。《授权法》在任命之后多少天，而帝国议会纵火案的28天与随后的24天如何衔接？
:::solution
如[[#thm-sequence]]的论证：纵火案在1月30日之后28天，《授权法》在2月27日之后24天。28 + 24 = 52。《授权法》在任命之后52天。那五十二天包括一场火与一部法律。它们不包括一个投票数字，因为一个也没有锁定。它们也不回溯到1919年6月28日。一个把《授权法》叫作“凡尔赛的结果”的读者，跳过了那次失败的暴动与这几个星期。这几个星期是短的。它们的短就是要点。那个政权的法律断裂是一个你可以数的序列，不是一团盖住十四年的雾。十四是1933减1919，另一个年份标签的间隔，而它不是与52同一个对象。
:::
:::

:::example 九天，然后是西班牙的一场不同的战争 {#ex-nine-and-spain}
莫洛托夫-里宾特洛甫协定是1939年8月23日。德国在1939年9月1日入侵波兰。这两个日期之间隔着多少天？分别地，西班牙内战在1939年4月1日结束。那个结束之后多少天，9月1日才到来？把两段跨度保持分开。
:::solution
从8月23日到9月1日是九天。入侵在协定之后9天跟随。那个邻近是真实的，而它属于本章末尾与下一章开头讲授的直接序曲。它不是一份1919年的摘要。从4月1日到9月1日：四月有30天，所以4月1日之后余29天，然后五月31、六月30、七月31、八月31，以及9月1日。29 + 31 + 30 + 31 + 31 + 1 = 153。所以9月1日在西班牙的战争结束之后153天。西班牙的战争在入侵波兰之前已经结束。它不是同一场战争。把西班牙的1936–1939年当作一条带上地方色彩的德国走廊，在这个计算上通不过。
:::
:::

:::example 一句发明出来的走廊句子 {#ex-invented-corridor}
下面这句话为示例而虚构。它不是史料。“1919年，德意志民族在凡尔赛和约之下把希特勒投票选上了台，所以1923年的暴动不可能失败，而1933年的任命只不过是一道手续。”列出错误。
:::solution
这句话是虚构的。它在1919年放进了一个年表不曾记录的表决，而本章被禁止在任何一年发明票数总和。它把那个和约与那次任命变成了同一个事件。它否认1923年11月8–9日那次失败的暴动，而它被锁定的恰恰是一次失败。而它把1933年1月30日叫作一道手续，违反了[[#thm-sequence]]，后者在接下来的几个星期里为一次火与一部《授权法》定年。一个存活下来的改写句子有意是乏味的：凡尔赛在1919年6月28日签署；一次暴动在1923年11月失败；希特勒在1933年1月30日被任命，52天后是3月23日的《授权法》。乏味就是检验。那句发明出来的句子令人兴奋，因为它擦掉了[[#ex-year-gaps]]里的间隔。
:::
:::

华尔街的崩盘被有意定了两次年。1929年10月24日是黑色星期四。1929年10月29日是黑色星期二。欧洲的诸场萧条与那场危机相连，但不是同一天的同一个事件。英国的劳动力市场、德国的银行危机与法国的贸易模式，不会在纽约一个下午的钟声里改变。我们说它们相连。我们不给出一个失业的百分比，因为一个也没有锁定，而一个借来的百分比会假装一个数字描述了若干个国家。崩盘出于又一个理由，是反对走廊的论证的一部分。它在向罗马进军之后、在苏联成立之后到来。那些政权不是从这场恐慌中出生的。德国的任命在恐慌之后到来，在1933年，这是一个认真对待那场经济危机的理由，不是一个把它叫作换了名字的凡尔赛的理由。

意大利是最早的、最干净的反例。1922年10月28日，向罗马进军把墨索里尼（Mussolini）的法西斯分子带到权力的边缘，而国王请他组织政府。史家们争论那里有多大程度上是一次被威胁的暴动、多大程度上是一次谈妥的移交。我们报道那场争论，而不发明国王的词句。两种读法中的任何一种都挡住走廊。一个法西斯政府在意大利的存在，早于1933年1月30日数年。它不是一个德国的事件，也不是凡尔赛导致了它的证据。意大利与那份和平的关系不是德国的关系。

苏联，成立于1922年12月30日，是另一个一部德国的传记无法吞掉的早期国家。它是一个意识形态不同的一党独裁，建立在1917年革命与布列斯特-立托夫斯克的退出之后。本章不给集体化或恐怖的那些后来的内部行动定年，因为那些日期没有被锁定，而它不给出一个死亡总数。成立的那个日期，对于[[#thm-not-corridor]]里的论断就够了。一幅在1922年10月装着罗马、又在1922年12月装着苏维埃联盟的欧洲地图，已经不是一条通往一个人的走廊。加上葡萄牙——威权政权在这几十年里统治着它——再加上东部与南部若干欧洲国家的威权政府，就给出了同一个要点，而不需要一份假冒的政变年表。那些政变日期的缺席，是一条证据的规则。它不是那些政权温和的论断，也不是它们不曾存在的论断。

:::quiz
1923年11月8–9日的失败对一个走廊故事做了什么？
- [ ] 它显示希特勒已经是总理，所以后来的任命是一次重复。
- [ ] 它显示凡尔赛已经被废除。
- [x] 它显示一次夺权的尝试失败了，早于1933年1月30日数年，所以1919年并没有已经把他放进职权。
- [ ] 它是换了名字的西班牙内战。
:::solution
暴动失败了。失败是年表费心去锁定的事实。任命是1933年1月30日，而从1923年到1933年的年份标签之差是10，如同[[#ex-year-gaps]]。凡尔赛没有在1923年被废除。西班牙的战争在1936年开始。一个和约使总理职位不可避免的故事，必须擦掉一次带日期的失败，或者假装那次失败无关紧要。那次失败要紧，因为它是政治本来可以走向另一条路的证据。它后来走了这条路，是一个进一步的序列，不是另一条路曾经不可能的证明。
:::
:::

纽伦堡（Nuremberg）与十一月大迫害属于本章，因为它们在任命之后、在1939年的战争之前，也因为后来的各章不得被叙述成仿佛迫害从万湖（Wannsee）才开始。1935年9月15日，纽伦堡诸法令为了法律的目的界定了谁算作犹太人，并禁止犹太人与法律算作德意志血统的人之间的婚姻与性关系。那是对那种法律排斥的转述，不是一句引文，也不是[[wars/genocide]]里讲授的谋杀。1938年11月9–10日，十一月大迫害（pogrom），在年表里也被称为水晶之夜（Kristallnacht），攻击德国之内的犹太生活：会堂、店铺、逮捕。我们不给出死亡总数。那个谈论碎玻璃的名字把财产放在中心。“十一月大迫害”把针对人的暴力保持在句子里。无论那些法令还是那场迫害，都不是一个票数总和，也都不是凡尔赛。

西班牙的战争还需要一个区分。它在1936年7月17–18日开始，在1939年4月1日以佛朗哥（Franco）一方的胜利结束。德国、意大利与苏维埃联盟出兵干预。我们不给出一个军队人数。干预显示这场战争被国际化了。它没有使西班牙成为德国故事的一个省份，也没有使每一个西班牙人成为一种道德类型的战斗者。从那场战争的结束到入侵波兰是153天。邻近不是同一。

:::

移动年份。当窗口为一时，你看到的是邻居，不是一条熔成的线。1922年，那个圆点必须同时装下向罗马进军与苏联的成立，两个走廊宁愿归档为预备动作的政权。1929年，那个圆点是一场美国市场的崩盘，而课文已经拒绝把它当作欧洲萧条的独一无二的那一天。1933年，那个圆点是一次任命，不是一份和约。1938年，它是慕尼黑，不是德国扩张的全部，也不是十一月大迫害——它共享那一年，却不在图形上。1939年，它是那个协定，在入侵之前九天，而图形就停了。从1933年到1939年的六个年份标签，就是图注要你去看的。六是1939减1933。如果那条线看起来像一条走廊，本课就失败了。圆点在那里，是为了让你能够拒绝那条线。

结尾的序列打开下一章，而不取代本章。1938年3月，德奥合并（Anschluss）把奥地利并入德国。1938年9月30日，慕尼黑协定让予德国对捷克斯洛伐克的苏台德（Sudeten）地区的要求。我们不引用当时那些宣称那个协定已经保障了和平的说法。从1938年9月30日到1939年9月1日是336天。一个非闰年有365天，而365减29是336，因为9月1日落在9月30日那个周年之前29天。那个协定距入侵不足一年，而它不是入侵。1939年8月23日，莫洛托夫-里宾特洛甫协定把纳粹德国与苏维埃联盟绑进一项公开的互不侵犯协定。史家们也把一份后来被找回来的秘密议定书读作安排了东部欧洲的诸势力范围。我们不发明那份议定书的条款。九天之后，德国入侵波兰。那个协定是那场入侵的直接原因的政治设置的一部分。它不是一份凡尔赛的摘要，也没有把苏维埃联盟变成德国的卫星国。1941年6月，德国将入侵苏维埃联盟。那个日期是下一章的。在这里提及它，是为了防止读者把1939年当作那个协定是永久的那样结束。它是一个选择，带着日期，后来被另一个选择打破。

:::warning 那个和约使总理不可避免的迷思
那个迷思说，凡尔赛使希特勒不可避免。即使在它作为一条原因的学说失败之前，它已经在日期上失败。那个和约是1919年6月28日。暴动在1923年11月8–9日失败。任命是1933年1月30日，然后是一场火，然后是《授权法》，在五十二天之内，本课程不陈述任何票数总和。意大利自1922年的向罗马进军起就有一个法西斯政府。苏维埃联盟自1922年12月30日起作为一个联盟而存在。西班牙的战争从1936年一直打到1939年4月1日。别的威权政权存在，而我们不发明它们的政变日子。史家们就凡尔赛有多沉重意见不一，而我们不锁定一个会终结那场争吵的赔款数额。一次沉重的冤屈不是一条充足的原因。会支持那个迷思的，是一条没有替代项、也没有失败暴动的链条。替代项与那次失败就是记录。不要把1933年叫作一道手续，从而把那个迷思放回来。
:::

:::history
凡尔赛和约于1919年6月28日签署在镜厅，德意志帝国曾于1871年1月18日在那里宣告成立。它是巴黎诸和约中的一个，不是全部的和约。希特勒于1933年1月30日被任命为总理。帝国议会的纵火案在1933年2月27日，而《授权法》接在3月23日。
:::

会构成对[[#thm-not-corridor]]的反证的，是一份显示向罗马进军、苏联的成立、西班牙的战争与别的那些威权政权是为了一个仕途而在1919年创造的德国工具、而它们就是那样的史料。它们不是。在一篇演说里对那个和约的责备，是政治的证据，不是日历的证据。做过的工作的案例仍然是[[#ex-invented-corridor]]。把1919年6月28日、1923年11月那次失败的暴动与1933年1月30日的任命分开放着，并把罗马与苏维埃联盟放离那条线。

## 通向何处

1939年8月23日的协定与9月1日的入侵，是通往[[wars/second-world-war]]的枢轴。缔造了签署那个协定的国家的那些革命，以及1917年的诸历法，在[[wars/revolutions-1917]]。对犹太人的谋杀——纽伦堡诸法令与十一月大迫害还不是它的全部——在[[wars/genocide]]。“走廊”这样一个标签如何不同于一条原因，在[[sources/argument]]。

:::summary
- 巴黎诸和约是复数的：凡尔赛在1919年6月28日，圣日耳曼与纳伊在1919年，特里亚农在1920年6月4日，塞夫尔在1920年、后来在一个未锁定的日期被修订。同一座大厅也装着1871年1月18日的宣告。
- 史家们就凡尔赛有多沉重意见不一。没有赔款数额与票数总和被锁定。一次冤屈不是一条充足的原因。
- 向罗马进军是1922年10月28日。苏联成立于1922年12月30日。1923年11月8–9日的慕尼黑暴动失败。这些日期不是德国的布景。
- 华尔街的崩盘是1929年10月24日与29日。欧洲的诸场萧条与之相连，但不是那一日，而这里没有关于它们的百分比。
- 希特勒在1933年1月30日被任命。帝国议会的纵火案在28天之后。《授权法》在那场火之后24天，在任命之后52天。
- 纽伦堡诸法令是1935年9月15日。十一月大迫害是1938年11月9–10日。西班牙的战争从1936年7月17–18日打到1939年4月1日。别的威权政权存在过。我们不发明它们的政变日子。
- 德奥合并是1938年3月。慕尼黑是1938年9月30日，早于1939年9月1日336天。协定是1939年8月23日，早于入侵九天。这一切都不会把1919年变成1939年。
:::

## 习题

:::exercise 和约的年份 {level=1 check="1919"}
凡尔赛和约在哪一年签署？（请输入四位数的年份。）
:::solution
凡尔赛签署于1919年6月28日。年份是1919。希特勒的任命是1933年，不是答案。特里亚农是1920年。
:::
:::

:::exercise 六个年份标签 {level=1 check="6"}
用莫洛托夫-里宾特洛甫协定的年份减去希特勒被任命的年份。（请输入年份标签的个数。）
:::solution
任命是1933年，协定是1939年。于是1939 − 1933 = 6。那个图形的图注建立在这个间隔上。它不是一个这两者之间什么也没有发生的论断，也不是一个天数。
:::
:::

:::exercise 从协定到入侵 {level=1 check="9"}
1939年9月1日在1939年8月23日之后多少天？（请输入天数。）
:::solution
从8月23日到9月1日是9天。对波兰的入侵在协定之后9天跟随。那段距离不是从凡尔赛来的距离，也不是从1939年4月1日西班牙的战争结束起的153天。
:::
:::

:::exercise 说出和约的名字 {level=2}
一名学生说，特里亚农是在镜厅与德国缔结的和约。纠正凡尔赛、特里亚农与塞夫赛的配对，并说出塞夫赛的限度。
:::solution
凡尔赛，1919年6月28日，在镜厅，是与德国的和约。特里亚农，1920年6月4日，是与匈牙利的和约。塞夫尔，1920年，是与奥斯曼帝国的和约，后来被修订。年表没有锁定修订的年份，所以一个纠正后的答案停在那里，不发明一个。圣日耳曼与纳伊，两者都是1919年，是奥地利与保加利亚。[[#def-paris]]是全部的一套。
:::
:::

:::exercise 为什么1922年对走廊是致命的 {level=2}
只使用1922年10月28日与1922年12月30日，解释为什么一个从凡尔赛开始、在希特勒结束的故事，在1929年之前就已经失败了。
:::solution
1922年10月28日，向罗马进军把一个法西斯政府带进意大利的执政，早于那次德国的任命数年，也早于华尔街的崩盘。1922年12月30日，苏联成立，一个不同的独裁，也早于那场崩盘，早于1933年1月30日。[[#thm-not-corridor]]把这两个日期当作走廊必须擦掉的替代项。它们不是德国的事件，也不是预演。对凡尔赛的怨恨，即使史家们判定那个和约沉重，也不会制造罗马或苏维埃联盟。
:::
:::

:::exercise 没有数额的分歧 {level=2}
史家们就凡尔赛有多沉重意见不一。你可以说什么，而你必须仍然拒绝哪个整数？那场分歧与[[#thm-not-corridor]]有什么关系？
:::solution
你可以说，那个和约强加了领土损失、军事限制、赔款与一条责任条款，而史家们就那份处置的分量意见不一。你必须拒绝一个赔款数额、一支军队的规模与一个票数总和，因为一个也没有锁定。那场分歧不恢复走廊。[[#thm-not-corridor]]在那个和约被判定沉重与否之上都站立，因为一份1919年的文书不是1933年的任命、那次失败的暴动，或别的政权。一个数额也不曾把怨恨变成一条充足的原因。
:::
:::

:::exercise 修复那句发明的句子 {level=3}
改写[[#ex-invented-corridor]]的那句发明出来的句子，使每一个日期都是可能的，并且不出现任何表决。然后说出，哪一个单独的改变会使你的改写重新变假。
:::hint
保住三个锁定的日期：那个和约、那次失败的暴动、那次任命。不要引进一次投票。如果那三个被坍进一个年份，或者那次暴动被描述为成功，改写就重新失效。
:::
:::solution
一个改写是：凡尔赛和约于1919年6月28日签署；慕尼黑暴动在1923年11月8–9日失败；希特勒于1933年1月30日被任命为总理，而《授权法》接在3月23日，即任命之后52天。没有出现票数总和。那次暴动被叫作成功时，或者任命被移到1919年时，或者一个投票数字被插入时，改写就会变假。那些就是发明出来的原文堆叠在一起的错误。西班牙的战争、向罗马进军与苏联可以被添加，而不帮助原来的句子。它们是[[#thm-not-corridor]]的进一步证据，不是装饰。
:::
:::

:::exercise 慕尼黑不是9月1日 {level=3}
说明1938年9月30日与1939年9月1日相隔336天，并解释为什么一个只相减年份数字、得到1的学生，回答的是另一个问题。那段336天的跨度关于那个协定没有证明什么？
:::hint
一个从9月30日到下一个9月30日的非闰年跨度是365天。9月1日在那个周年之前29天到来。那个协定是1939年8月23日，第三个日期。
:::
:::solution
1939年不是闰年。从1938年9月30日到1939年9月30日是365天。9月1日比9月30日早29天，而365 − 29 = 336。入侵在慕尼黑之后336天。把年份相减，1939 − 1938 = 1，只说两个年份标签相差一。它丢掉了月份。那段336天的跨度显示慕尼黑没有阻止入侵，而慕尼黑不是入侵。它不给那个协定定年——那个协定是1939年8月23日，早于9月1日九天——也不引用任何人在慕尼黑的说法。它也不使凡尔赛成为原因。走廊在这里失败，如同它在1922年与1923年失败：带日期的行为太多，而没有一条穿过一个人的充足直线。
:::
:::
