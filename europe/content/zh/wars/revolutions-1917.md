1917年为什么有两种历法？因为在二月革命与十月革命发生的时候，俄国仍在按儒略历给它的民事生活标注日期，而巴黎、伦敦与1582年的格里高利改革早已站在另一个计数上。不列颠在1752年完成了它自己的切换。俄国直到第二年才切换：儒略历1918年1月31日之后的那一天，是格里高利历1918年2月14日。在那个清晨之前，同一个事件的一个俄国日期与一个法国日期并不戴着同一个日与月。十月革命是旧历1917年10月25日，也是新历1917年11月7日。两个名称是一个事件。把其中任何一个当作错误，正是一个真双重日期被“纠正”到消失的办法。

本章关乎那个事实，也关乎诸革命对[[wars/first-world-war]]里定年的那场战争做了什么。尼古拉二世（Nicholas II）退位于新历1917年3月15日，即旧历3月2日。1918年3月3日，《布列斯特-立托夫斯克（Brest-Litovsk）和约》把俄国带出这场战争。1918年11月11日的停战（armistice）仍然是西线的停止。这些日期没有一个是俄罗斯民族的命运，也没有一个是标语。一部历法解释一个夜晚为什么有两个标签。它不解释一个政府为什么倒台，也不使第二场革命成为第一场必不可少的续集。在退位与十月之间躺着数月，其间另一个政权在统治。那数月是对任何这样的故事的反证：十月在动荡的第一天就已经写好。

方法是[[sources/time-and-names]]里的那一个。一次历法改革之前标注的日期不是错误。它是按当时通行的历法标注的日期。这个论证里没有公元0年，而我们也不需要它。我们在二十世纪之内，比较两个相差固定天数的计数，不是从公元前跨入公元。

## 两种历式，两场革命

**旧历（Old Style）**指俄国仍在使用的儒略历民事历。**新历（New Style）**指已经采纳了改革的诸国已经在使用的格里高利历。在二十世纪，一个给定日子的格里高利日期比儒略历日期晚十三天。那个十三不是第三种历法。它是使10月25日与11月7日成为同一天、使2月23日与3月8日成为同一天的换算。我们要把它算一遍，我们也要展示1918年那次切换里的陷阱，在那里，两个标签相减给出的是十四而不是十三。那个陷阱是一个关于被省略日期的差一错。它不是怀疑这个换算的理由。

俄国人叫作二月的那场革命，按旧历定从1917年2月23日到3月3日。按新历日历，那些端点是1917年3月8日与3月16日。所以“二月革命”这个名字是一个旧历名称。在巴黎与伦敦，同一场动荡是一件三月的事件。说这一边或那一边错了，就是混淆一个名字与一个错误。退位坐在区间之内：旧历3月2日是新历3月15日，而3月15日落在3月8日与3月16日之间，正如3月2日落在2月23日与3月3日之间。一次退位，一场革命之内，两个标签。一本教科书如果只印“二月”与只印“3月15日”，它就混用了两种历式而没有说明。你应当能够指出那种混用。

叫作十月的那场革命更晚。它不是二月的第二个标签。两场革命是两个事件。两种历法是每一个事件的两个名称。同时守住这两个区分，就是全部的本领。从新历3月15日的退位到新历11月7日的十月夺权，是237天。非闰年里3月15日的一年之内的日数：一月与二月有31 + 28 = 59天，加15，即74。11月7日的日数：一月到十月有304天，加7，即311。于是311 − 74 = 237。在那237天里，一个临时政府继退位而执政，而被称为苏维埃（soviet）的工人与士兵的委员会也宣称一份发言权。布尔什维克（Bolshevik），由列宁（Lenin）领导，是那场争吵之内的一个党。他们不是三月的政府。十月是带日期的夺权，凭它他们成为了政府。一个跳过那237天的读者，把一个序列变成了一次爆发，并把临时的数月弄得像一篇序言，而不是一个政权。

:::definition 旧历与新历 {#def-styles}
**旧历**是1918年1月31日为止在俄国仍然有效的儒略历民事纪年。**新历**是格里高利纪年。在1917年，一个日子的新历日期比旧历日期晚十三天。在切换之前写下的日期，不是它所使用的那种历式里的错误。
:::

:::definition 二月的名字 {#def-february-name}
**二月革命**是定从旧历1917年2月23日到3月3日、即新历1917年3月8日到16日的动荡与政权变更，包括尼古拉二世于旧历3月2日、即新历3月15日的退位。二月这个词记录的是俄国的历法。它没有记录那一周在巴黎使用的月名。
:::

:::definition 苏维埃，在1917年 {#def-soviet}
1917年的**苏维埃**是一个委员会，特别是工人与士兵代表的委员会。这个词还不是1922年12月30日成立的那个联盟国家的名称。那个更晚的国家在[[wars/interwar]]里讲授。给委员会和联盟使用同一个词，正是把一幅更晚的地图回画到1917年春天上的办法。
:::

:::theorem 十月的两个日期是一个事件 {#thm-one-event}
旧历1917年10月25日与新历1917年11月7日命名同一次夺权，不是两场革命。二月革命是另一个事件，在同一年更早，而它也是一对标签，不是两次爆发。两个对都不是俄国人民的命运。
:::
:::proof
给10月25日加上十三天。十月有31天，所以25日之后余下六天，而另外的七天落在十一月里：7日。年表为一场革命说出两个标签，并把历法切换放在第二年，所以俄国的十月还没有移入新历。因此俄国的同时纪年与外国纪相距于这个换算而分岔，而不是分岔于第二次起义。二月更早：旧历2月23日换算为新历3月8日，而退位从3月2日换算为3月15日。会构成对这条论断的反证的，是两次不同的夺权的证据，一次在儒略历的10月25日，另一次在十三天后、格里高利历的11月7日。史料不显示那个。它们显示的是一个夜晚在两种历法里的描述。同样会构成对一个粗心读法的反证的，是任何把二月坍进十月的做法。退位与十月夺权之间的237天足以把它们分开。不能为这条论断做决断的，是一场关于革命这个词的争吵。一些史家强调一个党的政变，另一些强调更广的社会崩溃。那场争吵是关于一个标签的，在[[sources/argument]]的意义上。它不把那个夜晚拆成两个日期。命运是一个进一步的标签，而且是一个更糟的。一个命运按构造没有反证。临时政府就是那个反证：它存在过，随后被推翻了。推翻是一个历史行为。它不是一个必须在十一月到来的天命。
:::

:::theorem 布列斯特-立托夫斯克是一次退出，而它有一种历法 {#thm-exit}
布列斯特-立托夫斯克和约，1918年3月3日，以苛刻的条款把俄国带出这场战争。它落在民事历已经切换之后，所以年表不给它一个旧历双胞胎。它早于1918年11月11日的停战，而它不是巴黎处置。
:::
:::proof
这次切换是明文的。儒略历1918年1月31日之后的一天是格里高利历1918年2月14日。和约的1918年3月3日在2月14日之后，按新的民事计数。与1917年10月不同，它不需要第二个日与月。这份和约结束了俄国的对德战争，那场战争自德国于1914年8月1日宣战起已经开始。从3月3日到1918年11月11日是253天，所以西线的停战不是这份和约，也不是东方的退出买来的一场德国胜利。那些条款分离出旧帝国西缘的大片领土。我们不给那些损失说出一个人口或一个面积。会构成对这条论断的反证的，是一个为1918年3月3日锁定的旧历双胞胎，像10月25日被锁定在11月7日旁边那样锁定在它旁边，或者停战当日那个俄国国家仍在按这份和约与德国正式交战。年表做的是反面：和约一个日期，停战更晚。不能构成反证的，是那些领土条款后来的崩溃。它们没有成为最终的地图。最终的地图是[[wars/interwar]]里巴黎诸和约的工作。一份和约可以是一次真实的退出而仍然没能持久。持久不是退出是否发生过的检验。
:::

:::quiz
哪一对命名的是同一个事件？
- [ ] 旧历1917年2月23日与旧历1917年10月25日，因为两者都是革命。
- [ ] 1917年3月8日与1917年3月15日，因为两者都落在二月革命的新历区间之内，因而必定是同一个瞬间。
- [x] 旧历1917年10月25日与新历1917年11月7日。
- [ ] 1918年3月3日与1918年11月11日，因为两者都结束一场战争。
:::solution
十月那对是一次夺权在两种历法之下，那正是[[#thm-one-event]]。二月与十月是不同的事件，即使两者都写作旧历。在二月区间之内，3月8日是新历的开端，而3月15日是退位，不是同一个瞬间。布列斯特-立托夫斯克与停战是不同的文书，相隔253天。这个小测验考的是两个标签与两个事件是否被保持了区分。
:::
:::

## 演算这个换算

算术是短的，而它是一个读者不用档案就能核对的部分。十月与三月不像二月那样行事，因为只有二月是短的，而1917年不是闰年。

:::example 从10月25日到11月7日 {#ex-october-convert}
给旧历1917年10月25日加上十三天来换算。你到达哪个新历日期，而月份为什么改变？
:::solution
十月有31天。25日之后，十月之内还余六天，26日到31日。十三减六是七，所以计数跑进十一月七天，落在11月7日。月份改变，是因为这个加法越过了十月的最后一天，不是因为发生了第二个事件。年表的那一对——旧历10月25日与新历11月7日——就是这个换算。俄国还没有切换它的民事历。切换是在第二年。
:::
:::

:::example 二月的名字，与坐在它里面的退位 {#ex-february-convert}
1917年不是闰年，所以二月有28天。给旧历的2月23日与3月2日加上十三天来换算。说出这些结果如何坐在3月8日到16日这个新历区间之内。
:::solution
2月23日之后，二月之内还余五天，24日到28日。十三减五是八，所以日期是3月8日。给3月2日加十三天不跨入四月：2 + 13 = 15，所以日期是3月15日。年表的二月革命新历窗口是3月8日到16日。两个结果都坐在它里面：3月8日是开端，而3月15日，即退位，在16日这个终点之前。旧历的退位，3月2日，同样坐在旧历3月3日这个终点之前。二月这个名字只属于第一个标签。
:::
:::

:::example 十三个被省略的标签，不是十四个 {#ex-switch-trap}
儒略历1918年1月31日之后的一天是格里高利历1918年2月14日。一名读者把两个标签相减，报告说被丢掉的是十四天，因为在不曾断裂的日历上，2月14日在1月31日之后十四天。在俄国，有多少个日期标签没有过民事日，而十四为什么是那些标签的错误计数？
:::solution
在一部不曾断裂的格里高利历上，2月14日在1月31日之后十四天。那个十四数的是实际过去的那一天，也数了被跳过的标签。被跳过的标签是2月1日到2月13日：十三个日子。俄国在1月31日就寝，在2月14日醒来。过去的是一个夜晚。十三个日子的名称从未被使用。年表的那个句子就是证据：1月31日之后的一天是2月14日。如果被跳过的是十四个标签，那么第二天清晨本会被叫作2月15日。它没有。那个差一错，与在问题要求一个差的时候把两端都算进去，是同一种错误。这里的问题是有多少个标签被省略了。答案是13。
:::
:::

:::example 一场发明出来的双重革命 {#ex-invented-twice}
下面这句话为示例而虚构。它不是史料。“十月革命发生了两次：俄国人在10月25日做了它，然后，因为他们迟到了，又在11月7日做了一次，这就是1917年有两种历法的原因。”这句话混淆了什么，而一个真实的第二个事件在史料里本会是什么样子？
:::solution
这句话是发明的，而它是假的。它把一个换算变成了一次第二次起义，而它把一个儒略历日期当作迟到，而不是当作俄国正在使用的民事日期。[[#def-styles]]禁止那个。一个真实的第二个事件会是一次单独的夺权，有自己的行动者与自己地点，在第一次之后十三天发生，并在换算被应用之后，在一个俄国的卷宗与一个外国的卷宗里都按此定日。加上了那十三天之后，卷宗所支持的，是一个夜晚。这句话还偷运进一个原因，“因为他们迟到了”，那不是历法事实。两种历法是关于诸国在不同时间采纳格里高利改革的事实，罗马在1582年，不列颠在1752年。它们不是关于俄国迟钝的事实。
:::
:::

同样的检验适用于一个发明出来的标题。假设有这样一幅标明为发明的情景：一张彼得格勒（Petrograd）报纸写着“10月25日”，一张伦敦报纸写着“11月7日”，而一名学生得出结论：伦敦报纸是在纠正一个错印。那个结论通不过。当且仅当换算成立、而且所描述的事件相符时，两张报纸才是同一个夜晚的候选。要把任何一个发明出来的标题提升为证据，你需要的是那张实际的报纸，不是一句为练习造出来的句子。这条规则来自[[sources/evidence]]。一句发明出来的句子可以演练这个检验。它通不过这个检验。

:::quiz
在俄国切换之后，关于1918年3月3日，哪一句陈述是真的？
- [ ] 它仍然需要一个旧历双胞胎，正如1917年10月25日需要的那样。
- [x] 它落在1918年1月31日之后的那一天之后，所以民事日期已经是格里高利历，而年表给它一个标签。
- [ ] 它是停战。
- [ ] 它是儒略历被恢复的那一天。
:::solution
1918年1月31日之后的一天是1918年2月14日。1918年3月3日的和约晚于那个清晨，所以它是按新的民事历标注的。1917年10月早于切换，因而保留两个标签。停战是1918年11月11日。年表里没有任何东西在切换之后恢复儒略历民事历。
:::
:::

把窗口保持在零，移动年份。1917年的圆点可以说“两场的革命”，而它仍然不能把2月23日与3月8日、或10月25日与11月7日印成分开的数字。一幅时间线图形每年只存一个整数。双重日期是一个关于历法的事实，而这幅图形是它的错误仪器。那个限度是有用的。如果这幅图只能显示11月7日，一个读者也许会以为10月25日已被反驳。如果它只能显示10月25日，国外的读者会去错误的一周里找一个事件。本课把两者都带着。1918年的圆点还要更挤：历法切换、3月3日的布列斯特-立托夫斯克、以及11月11日的停战，是三个不同的行为。标签可以点名它们。它不能给它们排序。你已经能够了。切换在先，在1月31日到2月14日的过渡里。和约在3月3日。停战在11月11日，那不是一个俄国的历法故事。它是这场战争在西线的终结，在前一章讲授，而在这里只被定了年。

:::warning 十月不是一个命运，而旧历不是一个错印
三个糊涂账结伴而行。第一个说，“十月”必定意味着格里高利历上的十月，所以11月7日是一个后来的错误。那个换算，以及定在第二年的那次切换，反驳它。第二个说，旧历日期是错误，因为它们不是我们的。一次改革之前的日期，是在当时生效的历法中的日期。第三个说，十月是俄国人民的命运，仿佛临时政府曾是一部剧本里的一次停顿。从3月15日到11月7日新历的那237天，是一段曾是一个政权的停顿。它被推翻了。推翻是一场冲突的证据，不是一场天命的证据。我们不发明一个标语来使这场冲突听起来不可避免，而我们也不需要它。这些日期足以把二月、十月、切换与和约保持在顺序里。
:::

:::history
十月革命在儒略历上是1917年10月25日，在格里高利历上是1917年11月7日。尼古拉二世退位于新历1917年3月15日，即旧历3月2日。列宁是十月夺权的一位布尔什维克领袖。俄国在第二年移动了它的民事历：1918年1月31日之后的一天是1918年2月14日。
:::

那个历史注记只使用锁定的等值。它不引用列宁，因为这门课程不发明演说。转述是被允许的，而我们使用的转述是平的。布尔什维克寻求结束俄国的战争，并把土地当作一个政治问题来处理。那是对一个纲领的诸议题的描述，不是一面三个词的旗子。任何一个把旗子当作引文递给你的人，递给你的是本图谱没有锁定的词。要求史料。不要让一句标语的节奏去做一个日期的工作。

在1918年11月11日停战前后的那些日子里，德国的帝制政权崩溃，一个共和国接踵而至。1919年1月，一次与斯巴达克派（Spartacist）相关的起义被击败。那次起义不是在柏林重演的十月，它也没有使德国成为一个苏维埃共和国。我们不给它比1919年1月更细的日期，因为年表没有锁定一天。德国的故事有意只有一个段落。俄国的双重日期，以及在布列斯特-立托夫斯克的退出，才是本章。

什么会构成对这一章整体的反证？一条锁定的史料，显示俄国在1917年十月之前已经采纳了格里高利历民事历，或者1918年3月3日在这个国家自己的纪年里仍是儒略历，或者两种历式都写下来之后，退位落在了二月区间之外。这些没有一个在年表里。不会构成反证的，是一部只记得两个月名之一的回忆录。记忆常常保住它被教会的那个名称。检验是算术，不是记忆。给10月25日加上十三天到达11月7日。给3月2日加上十三天到达3月15日。从1918年2月1日到2月13日，十三个标签从未被活过。那三个结果就是这一章的缩影。

一个进一步的警告属于尺度。临时政府、诸苏维埃与布尔什维克的夺权，是彼得格勒的与国家这两个尺度上的政治事实。它们单凭自身，不描述每一个村庄、前线的每一名士兵、或旧帝国内部的每一个民族。一句关于10月25日那个夜晚的真句子，还不是一句关于芬兰、乌克兰或中亚的句子。[[sources/scale]]适用。我们不发明地方编年史来填补那个空隙，也不假装那个空隙是对夺权发生过的一种否认。布列斯特-立托夫斯克是国家从这场战争中的退出。它不是谁想要那次退出的人口普查。

## 通向何处

取代那份和约的苛刻边缘的地图，不在这里绘制。[[wars/interwar]]接过凡尔赛、其他巴黎诸和约，以及那些年头是一条通往一个人的走廊这条论断。被诸革命打断的那场战争是[[wars/first-world-war]]。这里使用的历法规则，包括1582年与1752年以及没有公元0年，在[[sources/time-and-names]]。“命运”这样一个标签如何不同于一条原因，在[[sources/argument]]。

:::summary
- 1917年，俄国仍在使用儒略历。新历日期比旧历日期晚十三天。民事切换在第二年：1918年1月31日之后的一天是1918年2月14日。
- 二月革命是旧历1917年2月23日到3月3日，或新历3月8日到16日。二月这个名字是俄国的名称，不是巴黎的月份。
- 尼古拉二世退位于旧历3月2日，即新历3月15日，在那个区间之内。从那次退位到新历11月7日，是237天的临时政府，不是一片空白。
- 十月革命是一个事件：旧历1917年10月25日与新历1917年11月7日。它不是俄国的命运，也不是二月的第二次复制。
- 十三个日期标签，1918年2月1日到2月13日，被跳过了。一个报告十四的减法，把实际过去的那一天也数了进去。
- 布列斯特-立托夫斯克在1918年3月3日，在切换之后，所以它有一种历法。它是俄国从这场战争中的退出，早于停战253天，不是巴黎的和平。
- 1919年1月一次被击败的斯巴达克派起义，不是在德国重演的十月。新的诸国与诸和约属于下一章。
:::

## 习题

:::exercise 被省略的标签 {level=1 check="13"}
当1918年1月31日之后的一天被叫作1918年2月14日时，在俄国有多少个日期标签没有过民事日？（请输入数字。）
:::solution
被省略的标签是2月1日到2月13日。那是13个日子。十四天的缺口，在不曾断裂的日历上，包含了确实到来的那个清晨。被跳过的标签数是13。
:::
:::

:::exercise 十一月的日子 {level=1 check="7"}
给10月25日加上十三天。你落在十一月的哪一天，按新历？（请输入月内日。）
:::solution
25日之后，十月之内还余六天。十三减六是7。新历日期是1917年11月7日。月内日是7。
:::
:::

:::exercise 切换的年份 {level=1 check="1918"}
俄国的民事历切换在哪一年，即1月31日之后接2月14日的那个变更？（请输入四位数的年份。）
:::solution
切换是从1918年1月31日到1918年2月14日。年份是1918。以两种历式定年的诸革命是1917年，在切换之前。
:::
:::

:::exercise 哪个名字是二月？ {level=2}
解释一份1917年3月的巴黎报纸为什么可以在报道二月革命而月份并没有错。使用换算后的端点。
:::solution
旧历的跨度是1917年2月23日到3月3日。加上十三天，并记住1917年不是闰年，得到3月8日到3月16日。一份日期落在那个三月窗口之内的巴黎报纸，可以正是在描述同一场动荡。二月是俄国的民事名称。三月是格里高利名称。两者都不是错印。退位，新历3月15日，坐在巴黎的窗口之内，而它仍然是二月革命的一部分。
:::
:::

:::exercise 一份和约，一种历式 {level=2}
当[[#thm-one-event]]坚持1917年10月25日要有一个双胞胎时，[[#thm-exit]]为什么拒绝给1918年3月3日一个旧历双胞胎？
:::solution
1917年10月在切换之前，所以俄国的民事纪年与格里高利纪年仍然不同，而年表锁定两个标签。1918年3月3日在1918年2月14日之后，即1月31日之后的第一个格里高利民事日。国家自己的历法已经移动了。发明一个儒略历双胞胎，就是假装切换没有发生。这份和约仍然是从这场战争中的退出，早于1918年11月11日的停战253天，而它不是凡尔赛。
:::
:::

:::exercise 什么会拆散那个夜晚 {level=2}
什么发现会构成对[[#thm-one-event]]的反证，而一个关于“革命”这个词的什么发现不会？
:::solution
会构成反证的一个发现是两次夺权，相隔十三天，在两种历法对齐之后，每一次都被记录为它自己的事件。一场关于该把夺权叫作政变还是革命的争吵，不会拆散那个夜晚。那场争吵改变一个标签。它不使10月25日离开11月7日。一部只记得一个月名的回忆录也不会。检验是那个十三天的换算，不是回忆录的习惯。
:::
:::

:::exercise 十四天的错误 {level=3}
一位同学说：“2月14日减1月31日是十四天，所以十四个日期被废除了，而十月的换算应当加十四，使革命成为11月8日。”找出两个错误。
:::hint
把1918年2月实际过去的那一天与被跳过的标签分开。然后把十三天的规则，而不是十四天的错误，应用到10月25日上。
:::
:::solution
第一个错误是[[#ex-switch-trap]]里的差一错。在不曾断裂的日历上，从1月31日到2月14日的十四天，把2月14日清晨本身也包括了进去。从未出现的标签是十三个：2月1日到2月13日。第二个错误，是把那个错误的十四用到十月。年表的换算是十三天，而10月25日加十三是11月7日，不是11月8日。加上十四会发明一个史料不使用的日期。1918年的切换不能被用来改写1917年的一个夜晚。诸革命发生在切换之前，这正是它们有两个标签、而1918年3月3日的和约只有一个的原因。
:::
:::

:::exercise 一个发明出来的迟到 {level=3}
[[#ex-invented-twice]]里那句发明出来的话说，俄国人“因为他们迟到了”，在10月25日行动，又在11月7日行动一次。改写这句话，使两个日期都保留，而去掉第二个事件与发明出来的原因。说出史料仍然必须显示什么。
:::hint
从[[#def-styles]]开始。一个夜晚，两个标签，十三天，没有任何关于迟到的判断。然后说出，要把一句报纸的话从一次练习提升为证据，需要什么。
:::
:::solution
一个改写后的句子，仍然不是任何人的引文，是这样的：在俄国定日为1917年10月25日的那次夺权，就是在格里高利历国家里定日为1917年11月7日的那次夺权，因为两个民事历相差十三天。没有过第二次夺权，而迟到不是一条原因。要把一份具体的报纸提升为证据，你需要那份报纸，不是这道练习。改写后的句子与[[#thm-one-event]]相符。发明的那句不相符。一条显示十三天后另有一场起义的史料，会构成对这条论断的反证。这样的史料在这里没有锁定。
:::
:::
