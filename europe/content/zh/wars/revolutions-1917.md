1917年为什么有两种历法？因为二月革命与十月革命发生时，俄国国家的民事生活仍以儒略历纪日，而巴黎、伦敦早已采用1582年格里高利改革后的另一种计法。英国在1752年完成了自己的历法切换，俄国则直到第二年才切换：儒略历1918年1月31日的次日，是格里高利历1918年2月14日。在那天早晨之前，同一事件的俄国日期与法国日期并不落在同一月同一日。十月革命是旧历1917年10月25日，也是新历1917年11月7日。两个名称指的是同一个事件。把其中任何一个当作错误，就是把一个真实的双重日期“纠正”得无影无踪。

本章讨论这一事实，也讨论这些革命对[[wars/first-world-war]]中定年的那场战争产生了什么影响。尼古拉二世（Nicholas II）于新历1917年3月15日退位，即旧历3月2日。1918年3月3日，《布列斯特-立托夫斯克（Brest-Litovsk）和约》使俄国退出了战争。1918年11月11日的停战（armistice）仍是西线战事的终止。这些日期都不是俄罗斯民族的宿命，也都不是口号。历法能够解释为什么同一个夜晚有两个标签，却不能解释一个政府为何倒台，也不能使第二场革命成为第一场的必然续篇。在退位与十月之间，是另一个政权执政的几个月。这几个月本身就否定了任何认为十月在动荡第一天就已注定的叙事。

方法与[[sources/time-and-names]]相同。历法改革之前标注的日期不是错误，而是按当时通行历法标注的日期。这里的论证不涉及公元0年，也不需要它：我们身处二十世纪之内，比较的是两种相差固定天数的计日法，并不是从公元前跨入公元。

## 两种历式，两场革命

**旧历（Old Style）**指俄国仍在使用的儒略历民用历法。**新历（New Style）**指已采纳改革的各国所使用的格里高利历。在二十世纪，同一天的格里高利历日期比儒略历日期晚十三天。这个“十三”不是第三种历法，而是一种换算：正是它使10月25日与11月7日成为同一天，使2月23日与3月8日成为同一天。我们将演算这一换算，也将指出1918年切换中的陷阱：在那里，两个标签相减得出的是十四而不是十三。这个陷阱是关于被省略日期的“差一”错误，并不是怀疑这一换算的理由。

俄国人称为“二月”的那场革命，按旧历定于1917年2月23日至3月3日；按新历，起止日期是1917年3月8日与3月16日。所以，“二月革命”这一名称是旧历名称。在巴黎和伦敦，同一场动荡是三月的事件。说其中一方弄错了，就是把名称与错误混为一谈。退位落在这一区间之内：旧历3月2日即新历3月15日，3月15日落在3月8日与3月16日之间，正如3月2日落在2月23日与3月3日之间。一次退位，处于一场革命之中，有两个标签。如果一本教科书只印“二月”和“3月15日”，它就是在不加说明地混用两种历式。你应当能够指出这种混用。

称为“十月”的那场革命发生得更晚，它不是二月革命的另一个标签。两场革命是两个事件，两种历法则是每个事件的两个名称。同时把握这两种区分，就是全部的本领。从新历3月15日退位到新历11月7日十月夺权，共237天。在非闰年中，3月15日的年内序数：一月与二月共31 + 28 = 59天，加15，得74。11月7日的年内序数：一月至十月共304天，加7，得311。于是311 − 74 = 237。在这237天里，退位后由临时政府执政，而称为苏维埃（soviet）的工人与士兵委员会也要求发言权。列宁（Lenin）领导的布尔什维克（Bolshevik）只是这场争执中的一个政党，并不是三月的政府。十月是他们借以成为政府的、有日期的夺权。跳过这237天的读者，就把一个过程变成了一次爆发，也把临时政府的几个月弄得像是一篇序言，而不是一个政权。

:::definition 旧历与新历 {#def-styles}
**旧历**是俄国一直沿用到1918年1月31日的儒略历民用纪日。**新历**是格里高利历纪日。1917年，同一天的新历日期比旧历日期晚十三天。切换之前写下的日期，在其所用历式中并不是错误。
:::

:::definition “二月”这一名称 {#def-february-name}
**二月革命**指旧历1917年2月23日至3月3日（即新历1917年3月8日至16日）的动荡与政权更迭，包括尼古拉二世于旧历3月2日（即新历3月15日）退位。“二月”一词记录的是俄国的历法，而不是当周巴黎所用的月份名称。
:::

:::definition 1917年的苏维埃 {#def-soviet}
1917年的**苏维埃**是一种委员会，尤其指工人与士兵代表委员会。这个词那时还不是1922年12月30日成立的联盟国家的名称，后者在[[wars/interwar]]中讲授。用同一个词称呼委员会与联盟，就会把后来的地图倒画到1917年的春天上。
:::

:::theorem 十月的两个日期是同一事件 {#thm-one-event}
旧历1917年10月25日与新历1917年11月7日指的是同一次夺权，而不是两场革命。二月革命是另一个事件，发生在同年较早的时候；它同样是一对标签，而不是两次爆发。两对标签都不是俄国人民的宿命。
:::
:::proof
给10月25日加上十三天。十月有31天，25日之后还剩六天，其余七天落在十一月，即7日。年表为同一场革命给出两个标签，并把历法切换放在第二年，所以俄国在十月时尚未改用新历。因此，俄国当时的纪日与外国纪日之所以不同，在于这一换算，而不在于第二次起义。二月更早：旧历2月23日换算为新历3月8日，退位则从3月2日换算为3月15日。能够推翻这一论断的，是两次不同夺权的证据：一次在儒略历10月25日，另一次在十三天后的格里高利历11月7日。史料并没有显示这一点，它们显示的是用两种历法描述的同一个夜晚。同样能够反驳粗心解读的，是任何把二月并入十月的做法：退位与十月夺权之间的237天足以把两者分开。不能裁决这一论断的，是关于“革命”一词的争论。有些史家强调一个政党发动的政变，另一些则强调更广泛的社会崩溃。这一争论关乎标签，即[[sources/argument]]所说的意义上的标签，并不会把那个夜晚拆成两个日期。“宿命”是又一个标签，而且更糟：宿命按其构造就没有反证。临时政府正是反证：它曾经存在，后来被推翻。推翻是一个历史行为，而不是一种必然在十一月降临的命运。
:::

:::theorem 布列斯特-立托夫斯克是一次退出，只有一种历法 {#thm-exit}
1918年3月3日的《布列斯特-立托夫斯克和约》以苛刻的条件使俄国退出了战争。它签订于民用历法切换之后，因此年表不为它配旧历日期。它早于1918年11月11日的停战，也不是巴黎和会的安排。
:::
:::proof
切换有明文规定：儒略历1918年1月31日的次日是格里高利历1918年2月14日。和约的1918年3月3日在2月14日之后，按的是新的民用计日。与1917年10月不同，它不需要第二个月日。这项和约结束了俄国对德国的战争，这场战争始于1914年8月1日德国宣战。从3月3日到1918年11月11日为253天，因此西线停战不是这项和约，也不是用东线退出换来的德国胜利。和约条款割走了旧帝国西部边缘的大片领土。我们不为这些损失给出人口或面积。能够推翻这一论断的，是为1918年3月3日锁定的旧历对应日期（就像10月25日与11月7日并列锁定那样），或者是停战当天俄国国家仍按这项和约与德国处于正式交战状态。年表恰恰相反：和约只有一个日期，停战在其后。不能推翻这一论断的，是这些领土条款后来的瓦解，它们没有成为最终的版图。最终的版图是[[wars/interwar]]中巴黎各项和约的工作。一项和约可以是真实的退出，却仍未能持久。是否持久，并不是检验退出是否发生的标准。
:::

:::quiz
下列哪一对日期指的是同一个事件？
- [ ] 旧历1917年2月23日与旧历1917年10月25日，因为两者都是革命。
- [ ] 1917年3月8日与1917年3月15日，因为两者都落在二月革命的新历区间内，所以必定是同一时刻。
- [x] 旧历1917年10月25日与新历1917年11月7日。
- [ ] 1918年3月3日与1918年11月11日，因为两者都结束了一场战争。
:::solution
十月的这对日期是用两种历法表示的同一次夺权，这正是[[#thm-one-event]]所说的。二月与十月是不同的事件，即使两者都用旧历书写。在二月区间内，3月8日是新历的起点，3月15日是退位，并不是同一时刻。布列斯特-立托夫斯克和约与停战是不同的文件，相隔253天。这道小测验检验的是能否把两个标签与两个事件区分开来。
:::
:::

## 演算换算

算术很简单，而且是读者不查档案就能核对的部分。十月与三月的情形不同于二月，因为只有二月是小月，而1917年不是闰年。

:::example 从10月25日到11月7日 {#ex-october-convert}
给旧历1917年10月25日加上十三天进行换算。你得到的新历日期是哪一天？为什么月份变了？
:::solution
十月有31天。25日之后，十月还剩六天，即26日至31日。十三减六得七，所以计数进入十一月七天，落在11月7日。月份变了，是因为加法越过了十月的最后一天，而不是因为发生了第二个事件。年表中的那一对日期——旧历10月25日与新历11月7日——就是这一换算。俄国当时尚未切换民用历法，切换在第二年。
:::
:::

:::example “二月”之名与其中的退位 {#ex-february-convert}
1917年不是闰年，二月有28天。给旧历2月23日与3月2日各加十三天进行换算，并说明结果如何落在新历3月8日至16日的区间之内。
:::solution
2月23日之后，二月还剩五天，即24日至28日。十三减五得八，所以日期是3月8日。给3月2日加十三天不会跨入四月：2 + 13 = 15，所以日期是3月15日。年表中二月革命的新历区间是3月8日至16日，两个结果都落在其中：3月8日是起点，3月15日的退位早于16日的终点。旧历的退位日3月2日，同样早于旧历终点3月3日。“二月”这一名称只属于第一个标签。
:::
:::

:::example 被省略的标签是十三个，不是十四个 {#ex-switch-trap}
儒略历1918年1月31日的次日是格里高利历1918年2月14日。一位读者把两个标签相减，报告说丢掉了十四天，因为在不间断的日历上，2月14日在1月31日之后十四天。在俄国，有多少个日期标签没有对应的民用日？为什么十四是这些标签的错误计数？
:::solution
在不间断的格里高利历上，2月14日在1月31日之后十四天。这个“十四”既算了实际过去的那一天，也算了被跳过的标签。被跳过的标签是2月1日至2月13日，共十三个日期。俄国人在1月31日入睡，在2月14日醒来，中间只过了一夜，十三个日子的名称从未使用过。年表中的那句话就是证据：1月31日的次日是2月14日。如果跳过了十四个标签，第二天早晨就会叫作2月15日，而事实并非如此。这个“差一”错误，与题目问差值时却把首尾都算进去属于同一类错误。这里问的是省略了多少个标签，答案是13。
:::
:::

:::example 编造的“两次革命” {#ex-invented-twice}
下面这句话为示例而虚构。它不是史料。“十月革命发生了两次：俄国人在10月25日干了一次，后来因为迟到，又在11月7日干了一次，所以1917年才有两种历法。”这句话混淆了什么？真正的第二个事件在史料中会是什么样子？
:::solution
这句话是编造的，而且是错的。它把一次换算变成了第二次起义，又把儒略历日期当作迟到，而不是俄国当时使用的民用日期。[[#def-styles]]禁止这样做。真正的第二个事件，会是一次单独的夺权，有自己的行动者和地点，发生在第一次之后十三天，并且在应用换算之后，俄国与外国的卷宗都会如此记载其日期。加上十三天之后，卷宗所支持的只是同一个夜晚。这句话还偷运进一个原因——“因为迟到”——而这并不是历法事实。两种历法反映的是各国在不同时间采纳格里高利改革这一事实，如罗马在1582年、英国在1752年；它们并不反映俄国的迟缓。
:::
:::

同样的检验也适用于编造的报纸标题。假设（明确标为虚构）一份彼得格勒（Petrograd）的报纸写着“10月25日”，一份伦敦的报纸写着“11月7日”，一名学生由此断定伦敦报纸是在更正印刷错误。这个结论站不住。只有在换算成立、所描述的事件也相符的情况下，两份报纸才可能报道的是同一个夜晚。要把任何一个编造的标题提升为证据，你需要的是真实的报纸，而不是为练习而造的句子。这条规则来自[[sources/evidence]]。编造的句子可以用来练习检验，却不可能通过检验。

:::quiz
俄国切换历法之后，关于1918年3月3日，下列哪一项是正确的？
- [ ] 它仍然需要一个旧历对应日期，就像1917年10月25日那样。
- [x] 它在1918年1月31日的次日之后，所以民用日期已是格里高利历，年表只给它一个标签。
- [ ] 它就是停战日。
- [ ] 它是恢复儒略历的那一天。
:::solution
1918年1月31日的次日是1918年2月14日。1918年3月3日的和约晚于那天早晨，所以按新的民用历法标注日期。1917年10月早于切换，因此保留两个标签。停战在1918年11月11日。年表中没有任何内容表明切换之后恢复了儒略历民用历法。
:::
:::

把窗口保持为零，然后移动年份。1917年的数据点可以写“两场革命”，却仍无法把2月23日与3月8日、10月25日与11月7日作为不同的数字印出来。时间线图示每年只存储一个整数。双重日期是关于历法的事实，而这张图并不是处理它的合适工具。这一局限反而有用：如果图示只能显示11月7日，读者也许会以为10月25日已被推翻；如果只能显示10月25日，国外的读者就会到错误的那一周里去找这个事件。本课两者兼顾。1918年的数据点更加拥挤：历法切换、3月3日的布列斯特-立托夫斯克和约与11月11日的停战，是三个不同的行为。标签可以列出它们的名称，却无法为它们排序。而你已经能够排序：切换在先，即从1月31日到2月14日的过渡；和约在3月3日；停战在11月11日，那不是俄国的历法故事，而是战争在西线的结束，已在上一章讲授，这里只标出日期。

:::warning 十月不是宿命，旧历也不是印刷错误
有三种糊涂认识常常结伴而行。第一种说，“十月”必定指格里高利历的十月，所以11月7日是后来的错误。换算以及定于第二年的切换驳斥了这一点。第二种说，旧历日期之所以是错误，是因为它们不是我们的日期。改革之前的日期，是按当时有效的历法标注的日期。第三种说，十月是俄国人民的宿命，仿佛临时政府只是剧本中的一次停顿。从新历3月15日到11月7日的237天，是一段作为政府存在过的“停顿”，它后来被推翻了。推翻证明的是冲突，而不是命运。我们不编造口号来使这场冲突听起来不可避免，也不需要这样做。这些日期足以使二月、十月、历法切换与和约各就其位。
:::

:::history
十月革命按儒略历是1917年10月25日，按格里高利历是1917年11月7日。尼古拉二世于新历1917年3月15日退位，即旧历3月2日。列宁是十月夺权的布尔什维克领导人之一。俄国在第二年改换了民用历法：1918年1月31日的次日是1918年2月14日。
:::

这则历史注记只使用锁定的日期对应关系。它不引用列宁的话，因为本课程不编造演说。转述是允许的，我们所用的转述也很朴素：布尔什维克谋求结束俄国的战争，并把土地作为政治问题来处理。这是对一个纲领所涉议题的描述，而不是一面写着三个词的旗帜。凡是把这面旗帜当作引文递给你的人，递给你的都是本图谱没有锁定的言辞。请索要史料。不要让口号的节奏去承担日期的工作。

在1918年11月11日停战前后的那些日子里，德国的帝制政权崩溃，随后成立了共和国。1919年1月，一场与斯巴达克派（Spartacist）有关的起义遭到镇压。这场起义并不是在柏林重演的十月，也没有使德国成为苏维埃共和国。我们不把它的日期定得比1919年1月更细，因为年表没有锁定具体日期。德国的故事有意只用一段话。本章的主题，是俄国的双重日期以及布列斯特-立托夫斯克的退出。

什么能够推翻本章的整体论证？一份锁定的史料，表明俄国在1917年十月之前就已采用格里高利历民用历法；或者表明1918年3月3日在该国自己的纪日中仍是儒略历；或者表明在写出两种历式之后，退位落在了二月区间之外。年表中没有这样的内容。不能推翻它的，是一部只记得两个月份名称之一的回忆录。记忆往往保留它被教给的名称。检验靠的是算术，而不是记忆：10月25日加十三天是11月7日；3月2日加十三天是3月15日；1918年2月1日至2月13日的十三个标签从未被经历过。这三个结果就是本章的缩影。

还有一项关于尺度的提醒。临时政府、苏维埃与布尔什维克的夺权，是彼得格勒和国家层面的政治事实。它们本身并不描述每一个村庄、前线的每一名士兵或旧帝国境内的每一个民族。一句关于10月25日夜晚的真实陈述，还不是关于芬兰、乌克兰或中亚的陈述。[[sources/scale]]在此适用。我们不编造地方编年史来填补这一空缺，也不假装这一空缺是在否认夺权的发生。布列斯特-立托夫斯克是国家退出战争，而不是一次关于谁想要退出的人口普查。

## 通向何处

取代这项和约苛刻边界的那张地图，不在这里绘制。[[wars/interwar]]将讨论凡尔赛和约、巴黎的其他各项和约，以及“那些年是通向一个人的走廊”这一论断。被这些革命打断的那场战争，见[[wars/first-world-war]]。这里所用的历法规则，包括1582年、1752年以及没有公元0年，见[[sources/time-and-names]]。“宿命”这样的标签与原因有何不同，见[[sources/argument]]。

:::summary
- 1917年，俄国仍在使用儒略历。新历日期比旧历日期晚十三天。民用历法的切换在第二年：1918年1月31日的次日是1918年2月14日。
- 二月革命是旧历1917年2月23日至3月3日，即新历3月8日至16日。“二月”是俄国的名称，而不是巴黎的月份。
- 尼古拉二世于旧历3月2日即新历3月15日退位，落在这一区间之内。从退位到新历11月7日，是临时政府执政的237天，而不是一片空白。
- 十月革命是一个事件：旧历1917年10月25日，即新历1917年11月7日。它既不是俄国的宿命，也不是二月革命的翻版。
- 1918年2月1日至2月13日这十三个日期标签被跳过了。得出十四的减法，把实际过去的那一天也和被省略的标签一起算了进去。
- 1918年3月3日的布列斯特-立托夫斯克和约签订于切换之后，所以只有一种历法。它是俄国退出战争，比停战早253天，而不是巴黎的和平。
- 1919年1月遭到镇压的斯巴达克派起义，不是在德国重演的十月。新的国家与各项和约属于下一章。
:::

## 习题

:::exercise 被省略的标签 {level=1 check="13"}
1918年1月31日的次日被称为1918年2月14日时，俄国有多少个日期标签没有对应的民用日？（请输入数字。）
:::solution
被省略的标签是2月1日至2月13日，共13个日期。在不间断的日历上，十四天的间隔包括了确实到来的那个早晨。被跳过的标签数为13。
:::
:::

:::exercise 十一月的那一天 {level=1 check="7"}
给10月25日加上十三天，按新历会落在十一月的哪一天？（请输入日期中的日。）
:::solution
25日之后，十月还剩六天。十三减六得7。新历日期是1917年11月7日，日为7。
:::
:::

:::exercise 切换的年份 {level=1 check="1918"}
俄国民用历法切换（即1月31日之后接2月14日的那次变更）发生在哪一年？（请输入四位数年份。）
:::solution
切换是从1918年1月31日到1918年2月14日，年份是1918。用两种历式定年的两场革命都在1917年，早于切换。
:::
:::

:::exercise 哪个名称是“二月”？ {level=2}
请解释：为什么一份1917年3月的巴黎报纸可以在报道二月革命，而月份并没有写错？请使用换算后的起止日期。
:::solution
旧历跨度是1917年2月23日至3月3日。加上十三天，并记住1917年不是闰年，得到3月8日至3月16日。一份日期落在这个三月区间内的巴黎报纸，完全可能是在报道同一场动荡。“二月”是俄国的民用名称，“三月”是格里高利历的名称，两者都不是印刷错误。新历3月15日的退位落在巴黎的这一区间之内，仍属于二月革命。
:::
:::

:::exercise 一项和约，一种历式 {level=2}
为什么[[#thm-exit]]拒绝为1918年3月3日配旧历日期，而[[#thm-one-event]]却坚持1917年10月25日须有对应日期？
:::solution
1917年10月在切换之前，俄国民用纪日与格里高利纪日仍然不同，所以年表锁定两个标签。1918年3月3日在1918年2月14日之后，后者是1月31日之后的第一个格里高利民用日。国家自己的历法已经改变，编造一个儒略历对应日期，就是假装切换没有发生。这项和约仍是退出战争，比1918年11月11日的停战早253天，而且不是凡尔赛和约。
:::
:::

:::exercise 什么能把那个夜晚拆开 {level=2}
什么发现能够推翻[[#thm-one-event]]？关于“革命”一词的什么发现则不能？
:::solution
能够推翻它的发现是：在两种历法对齐之后，有两次相隔十三天的夺权，各自被记录为独立的事件。至于该把这次夺权称为政变还是革命的争论，则不能把那个夜晚拆开。这种争论改变的是标签，并不会使10月25日离开11月7日。一部只记得一个月份名称的回忆录也不能。检验靠的是十三天的换算，而不是回忆录的习惯。
:::
:::

:::exercise 十四天的错误 {level=3}
一位同学说：“2月14日减1月31日是十四天，所以有十四个日期被废除了，十月的换算也应该加十四天，那么革命就是11月8日。”请找出两个错误。
:::hint
把1918年2月实际过去的那一天与被跳过的标签分开。然后把十三天的规则（而不是十四天的错误）用到10月25日上。
:::
:::solution
第一个错误是[[#ex-switch-trap]]中的“差一”错误。在不间断的日历上，从1月31日到2月14日的十四天包括了2月14日那天早晨本身。从未出现的标签是十三个：2月1日至2月13日。第二个错误是把这个错误的“十四”用到了十月。年表的换算是十三天，10月25日加十三天是11月7日，而不是11月8日。加十四天就会编造出一个史料并不使用的日期。不能用1918年的切换去改写1917年的一个夜晚。革命发生在切换之前，正因如此，它们有两个标签，而1918年3月3日的和约只有一个。
:::
:::

:::exercise 编造的“迟到” {level=3}
[[#ex-invented-twice]]中那句编造的话说，俄国人在10月25日行动，又“因为迟到”在11月7日再行动一次。请改写这句话，保留两个日期，去掉第二个事件和编造的原因，并说明史料仍须证明什么。
:::hint
从[[#def-styles]]出发：一个夜晚，两个标签，十三天，不作任何关于迟到的判断。然后说明，要把一句报纸上的话从练习提升为证据，需要什么。
:::
:::solution
改写后的句子（仍然不是任何人的原话）可以是：俄国定为1917年10月25日的那次夺权，就是格里高利历国家定为1917年11月7日的那次夺权，因为两种民用历法相差十三天。并没有第二次夺权，迟到也不是原因。要把某一份具体的报纸提升为证据，你需要的是那份报纸，而不是这道练习。改写后的句子与[[#thm-one-event]]相符，编造的那句则不符。一份表明十三天后另有一次起义的史料，能够推翻这一论断，但这里没有锁定这样的史料。
:::
:::
