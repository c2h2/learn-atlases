欧洲联盟成为了什么，而什么仍然不是一个已经闭合的过去？

1957年3月25日的经济共同体是一份小的成员名单，不是一块大陆。欧洲联盟（European Union）是一个更晚的条约，1992年2月7日在马斯特里赫特（Maastricht）签署，1993年11月1日生效。它以两个步骤获得一种货币：账面货币（book money）在1999年1月1日，纸币与硬币在2002年1月1日。它以更多的步骤获得成员：1995年1月1日三个国家，2004年5月1日十个国家，2007年保加利亚与罗马尼亚，2013年7月1日克罗地亚；而它失去一个成员：联合王国在2016年6月23日表决离开，在2020年1月31日离开，并在2020年12月31日结束一场过渡。在同样的那些年之间，围绕科索沃（Kosovo）进行着一场军事战役，一场在美国的破产与希腊的贷款项目不是同一天，俄罗斯在2014年占领并吞并克里米亚（Crimea），而2022年2月24日，俄罗斯开始对乌克兰的全面入侵。截至2026年，那场战争还没有结束。本课把那次入侵陈述为一次入侵。它不给出伤亡总数，不推荐任何政策，也不告诉你们该支持谁。欧洲联盟不是本图谱的幸福结局。一份时增时减的成员名单，坐在一场仍然敞开的战争旁边，正是一个结局的反面。

## 从诸共同体到一个联盟

通往马斯特里赫特的路是三个不同的行为，不是单独一次诞生。1975年8月1日，《赫尔辛基最后文件》（Helsinki Final Act）签署，一份来自分裂两侧的诸国家的安全文件，不是一个市场。1979年，欧洲议会第一次被直接选举。一个当选的议会不是一个主权者，而一次选举不是一种货币。1986年，《单一欧洲法令》（Single European Act）朝向一个单一市场（single market）修订诸条约。它不是欧洲联盟的创立文书。马斯特里赫特才是。

:::definition 欧洲联盟 {#def-union}
这里的**欧洲联盟**，指的是《马斯特里赫特条约》（Maastricht Treaty）于1993年11月1日生效时建立的条约组织，带着一份后来会改变的成员名单。它不是一个文明，不是那块大陆的同义词，也不是欧洲历史的幸福结局。
:::

那个条约在1992年2月7日签署，在1993年11月1日生效。签字不是生效。从1992年2月7日到1993年2月7日是366天，因为1992年是闰年，而1992年2月29日落在那一年2月7日之后、那个跨度之内。从1993年2月7日到1993年11月1日是267天。总和是633天。在那633天里，那个条约是一份已经签署、却还没有把一个生效的联盟约束其成员的文件。把那两个日期合拢，会让一场谈判看起来像一个开关。

那个条约所做的，用本课所需要的狭义说，是给欧洲联盟它的法律名称，并规定一条包含一种单一货币的路线。它没有在签署的那一天把纸币放进谁的口袋。欧元（euro）作为账面货币在1999年1月1日开始。纸币与硬币在2002年1月1日开始。从那些日子中的第一个到第二个是三年，而一个2月29日落在那个跨度之内，所以那个跨度是三年加一天，不是整三年。我们不把那一年的2月当作一个单独的历史事件，也不需要它的年份作为一个政治日期。那三个日期就是那条论断。

不是每一个成员国都采用了那些纸币与硬币。联合王国没有。其他国家也待在那种现金之外。一个说“欧洲在2002年换了它的钱”的读者，是把一份名单重命名为一块大陆，而[[sources/naming-europe]]已经为1957年禁止过这件事，并且擦除了那些保留自己纸币的国家。[[#def-union]]是同一道禁令，应用在一个更晚的条约上。

:::theorem 三个日期，不是一个完成的行为 {#thm-three}
1992年2月7日的《马斯特里赫特条约》签字、1993年11月1日的生效、1999年1月1日作为账面货币的欧元、以及2002年1月1日的纸币与硬币，是不同的日期。把它们合拢，会让欧洲联盟看起来像一个单独的完成的行为。
:::
:::proof
证据是诸日期之间的间隔，以及每个日期所做的事情的差别。签字产生一份文本。生效使欧洲联盟对其成员成为一个法律事实。账面货币是一个记账单位。纸币与硬币是另一个日子，在账面货币之后三年又一天，而并非每个成员都采用它们。这些日子没有一个是2004年5月1日的扩大，也没有一个是2020年1月31日的离开。

会构成对这条论断的反证的，是一份单一的文书，在某一天被签署、生效、发行纸币，并且把每一个欧洲国家都装在里面。没有这样的文书。不会构成反证的，是那个政治希望——在许多签署者之间是真实的——即一个联盟与一种货币是朝向一个更安定的大陆的诸步骤。一个希望不是一个日期。[[postwar/from-1989]]已经拒绝让1989年成为一个终结。这条论断拒绝让马斯特里赫特成为第二个披着一个条约名字的终结。
:::

那个反方论证说，就实际目的而言，欧洲联盟“发生在”马斯特里赫特，而更晚的日期是行政。实际目的恰恰住在行政里。一家还不能用纸币支付的商行，一个已经签署却还没有被约束的国家，一个从不采用那种现金的成员：如果你只保留1992年2月7日，这些每一个都是不可见的。从签字到生效的那633天是最简单的检验。如果行政不要紧，那些日子就不会存在。

:::quiz
哪一个序列与那种货币和那个条约相符？
- [ ] 纸币与硬币在1992年2月7日、马斯特里赫特被签署的那一天开始，在每一个欧洲国家。
- [ ] 作为账面货币的欧元与纸币都是1999年1月1日，而英国两者都采用。
- [x] 马斯特里赫特在1992年2月7日签署，在1993年11月1日生效，在1999年1月1日成为账面货币，在2002年1月1日成为纸币与硬币，且并非在每一个成员国。
- [ ] 1986年的《单一欧洲法令》就是纸币发行的那一天。
:::solution
[[#thm-three]]把四个日期分开。联合王国不采用那些纸币与硬币。《单一欧洲法令》是1986年，一次市场的修订，不是那种现金，也不是欧洲联盟的生效。1975年的赫尔辛基与1979年的直接选举更早，而且又是不同的东西。
:::
:::

:::example 签字不是生效 {#ex-maastricht}
求从1992年2月7日到1993年11月1日的日期差，并说出那两个日期各做什么。
:::solution
从1992年2月7日到1993年2月7日是366天，包括1992年2月29日。从1993年2月7日到1993年11月7日，逐月为28加31加30加31加30加31加31加30加31，即273天，落在11月7日。11月1日早6天，所以273减6是267。于是366加267是633。那个条约在第一个日期签署，在第二个日期生效。在633天里，它还不是一个生效的欧洲联盟。[[#thm-three]]从那个间隔出发，然后拒绝把那些货币日期也折进来。
:::
:::

## 一份名单是精确的

:::definition 一次精确的扩大 {#def-ten}
一次**精确的扩大**是一份带日期的、加入诸国家的名单，既不是一个地区，也不是一种情绪。2004年5月1日的扩大恰好是十个国家：塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。添加或删去一个名字，就改变那个事实。
:::

在那十个之前，三个国家在1995年1月1日加入：奥地利、芬兰与瑞典。它们不是一场2004年的预演，也不是“东方”。瑞典的加入是一个条约事实，关于一个曾经待在《罗马条约》之外的国家。它不会把1957年变成对欧洲的定义。

2004年5月1日，那十个加入。请一边读[[#def-ten]]一边数它们，因为那个数目就是检验。马耳他与塞浦路斯在那十个之内，而它们不是东方集团的前共产主义国家。捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、波兰与斯洛伐克经由不同的诸条路走出那个世界，而斯洛文尼亚的路既穿过一个南斯拉夫共和国的终结，也穿过加入。本课不需要那些路来看守那份名单。它需要你不要说“东欧加入了”，仿佛那个短语就是那十个。一个绰号不是一份名单。保加利亚与罗马尼亚在2007年加入。它们不是那十个的一部分。克罗地亚在2013年7月1日加入。第三个日期不是第一个日期的一个脚注。一个把克罗地亚添加进2004年名单的人，或者添加保加利亚、然后删掉马耳他以求保住十这个数字的人，是为了救一个故事而改变了那个事实。

同样的纪律适用于一场共享欧元第一年的战争。1999年1月1日，欧元作为账面货币开始。1999年3月24日，北约（NATO）围绕科索沃开始一场军事战役。它延续到1999年6月10日。从3月24日到6月10日是78天。从1月1日到3月24日是82天。一种货币与一场战役共享一个年份，不共享一种行为。那场战役是年表的事实。各政府与各史家关于它的法律基础与它的结果意见不一。本课记录那些日期与那场论辩的存在。它不裁决那场论辩，也不给出死亡总数。裁决会是一项政策。本图谱不提供任何政策。

:::example 一场战役旁边的账面货币 {#ex-kosovo}
把1999年1月1日与1999年3月24日、1999年6月10日并置。一个1999年的单独圆点可能藏起什么？
:::solution
从1999年1月1日到3月24日是82天：1月有31天，而1999年不是闰年，所以1月1日到3月1日是31加28，即59，而3月1日到3月24日是23天。那场战役随后从3月24日延续到6月10日，即78天：3月24日到6月24日是31加30加31，即92，而6月10日早14天，所以92减14是78。一个标为1999年的圆点可以藏起一种货币、一场78天的军事战役，以及这两者不是同一项政策这个事实。[[#thm-three]]已经把那种货币与马斯特里赫特分开了。这个例子把那种货币与那场战役分开。关于那场战役合法性的论辩是真实的。本课不裁决它。
:::
:::

:::example 一个编造的完成 {#ex-happy}
下面这句话为示例而虚构。它不是史料。“一旦那十个在2004年加入，欧洲联盟就完成了1989年的工作，可以合上这本图谱了。”这句话对那份名单做了什么，而它必须假装看不见哪些更晚的日期？
:::solution
2004年5月1日的那十个，恰好是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。“1989年的工作”把一份成员名单当作历史的终结，而[[postwar/from-1989]]已经拒绝过那个，并且它把马耳他与塞浦路斯藏进了一个关于旧东方集团的故事里。这句话看不见2007年，保加利亚与罗马尼亚在那一年加入；也看不见2013年7月1日，克罗地亚在那一天加入；也看不见2016年6月23日，联合王国在那一天表决离开；也看不见2020年1月31日，它在那一天离开。它还看不见2014年，俄罗斯在那一年占领并吞并克里米亚；也看不见2022年2月24日，俄罗斯在那一天开始对乌克兰的全面入侵，而那场入侵截至2026年还没有结束。一句编造的完成句是假的，因为那份名单是精确的，也因为那份名单之后的诸年份不是空的。
:::
:::

## 危机、离开、入侵

2008年9月15日，雷曼兄弟（Lehman Brothers）申请破产。那是一个美国事件。随之而来的欧洲债务危机不是同一天。希腊的贷款项目在2010年开始。我们不给出任何数额，以任何货币，因为年表没有给出任何数额，而一个数字只会看起来像精确。那场危机考验了一种共享的货币，其成员却并没有共享一个年纪相同的财政国家。那是对一种安排的一种描述，不是对那种安排应当被保持、打破或改革的推荐。若干国家被卷入。年表为那些项目的开始点名的是希腊。我们不为其他项目发明日子。那些日期确实支持的，是那个分离：2008年9月15日不是2010年。一次破产不是一个贷款项目。一节把欧洲危机起于美国那个申请日的课程，跳过了那份记录给出的唯一开始。

联合王国的离开是三个日期，而那三个正是全部要点。2016年6月23日，联合王国表决离开欧洲联盟。年表没有给出多数的规模，所以我们不发明一个百分比。那个结果是一次离开的决定。它不是离开。2020年1月31日，联合王国离开。2020年12月31日，过渡结束。从表决到离开是1317天。没有一个2月29日落在那个跨度之内：2016年2月29日在2016年6月23日之前，而2020年2月29日在2020年1月31日之后。从2016年6月23日算起三年是1095天，三乘365。从那个周年纪念到2020年1月31日是222天，而1095加222是1317。那场过渡，从2020年1月31日到2020年12月31日，是335天，不是334天，因为2020年是闰年，而2月29日落在那几个月之内。一个说“英国在2016年离开了”的人，得到了表决，却错过了那两个更晚的日期。一个说“英国在1月31日离开，所以那就是法律的终点”的人，错过了一场335天的过渡。我们不说那次表决是否明智。明智会是一个立场。那些日期就是本课。

:::theorem 不是一个闭合的过去 {#thm-open}
欧洲联盟的诸条约、货币、诸次扩大与联合王国的离开，同俄罗斯2014年对克里米亚的占领与吞并、同2022年2月24日开始的俄罗斯对乌克兰的全面入侵，在同一条时间线上。它们不是一个带着幸福结局的故事。截至2026年，那次入侵还没有结束，而它不是一个闭合的过去。
:::
:::proof
证据是那些确定事实的顺序，以及年表自己的限度。多数国家不承认对克里米亚的吞并。那种不承认是那个事实的一部分，不是一场为一项政策的演说。那场全面入侵在2022年2月24日开始。它是一次入侵。回避那个词的语言，或者把2014年与2022年当作同一个行为的语言，通不过那些日期：对克里米亚的占领与吞并不是那场全面入侵，而那次入侵也不是一种委婉语的“危机”或“行动”。年表陈述：截至2026年，那场战争还没有结束。它不陈述任何伤亡总数。本课照搬那个限度，而对于读者应当支持谁，不添加任何东西。

会构成对这条论断的反证的，是一份在这份年表里定年的、结束了那场战争的和平，或者一个表明欧洲联盟的制度史在2014年之前就已停止、因而不可能坐在同一条时间线上的论证。两者都不是记录。扩大、一次离开、一种货币、一次入侵，全部有日期。不会构成对这条论断的反证的，是那份真实的制度所得清单：一个自1979年起直选的议会，一个自1993年起生效的联盟，一种自1999年与2002年起的货币，一份自1995年、2004年、2007年与2013年起更大的成员名单。把那些所得每一样都让步给你。它们没有一样是一个终结，因为成员名单在2020年1月31日也会缩小，也因为一场全面入侵在2026年正在进行。一项所得不是那块落幕的幕布。
:::

那个反方论证说，一部制度教科书应当停在制度那里，而一场正在进行的战争会让那一页变得过时，并把它拖进一场争吵。回答是年表本身，它不停在入侵之前，而且它禁止那场争吵。提前停下，会把欧洲联盟变成那条论断所否认的幸福结局。继续走进建议、一个伤亡数字、或者一个立场，会把本课变成一场演说。[[#thm-open]]是那些失败之间的那条窄路。你可以说，一场论辩是存在的，在各国家之间、在各公民之间，关于承认，关于援助，关于谈判。那场论辩的存在是一个事实。本课不加入它。

2014年的克里米亚与2022年2月24日的入侵，也显示了为什么一份成员名单不是一项被讲述为命运的安全保证。欧洲联盟的名单经由条约改变。一条边界的承认是另一种类的事实：多数国家不承认那次吞并。我们不把那个句子变成一场关于那场战争如何结束的预言。那份记录里没有一个终结。那个图形停在2022年，是因为年表停在一个事实，而不是停在一个结果。一个继续跑到它所没有的一个和平那里去的图形，将会是一个虚构。

:::example 一次离开的三个日期 {#ex-brexit}
分开2016年6月23日、2020年1月31日与2020年12月31日。给出从表决到离开的日期差，以及从离开到过渡结束的日期差。
:::solution
离开的表决是2016年6月23日。联合王国在2020年1月31日离开。过渡在2020年12月31日结束。从2016年6月23日算起三年是1095天，而没有一个2月29日落在直到2020年1月31日的整个跨度之内，因为2016年的闰日在6月23日已经过去了，而2020年的闰日在1月31日还没有到来。从那个周年纪念到2020年1月31日是222天：从6月23日起的逐月步子为30、31、31、30、31、30与31，到达1月23日，再八天到达1月31日。于是1095加222是1317，即从表决到离开的差。从2020年1月31日到2020年12月31日是335天，因为2020年是闰年，而2月29日落在里面。那次表决不是离开。离开不是过渡的结束。没有任何百分比被说出，也不应当发明任何百分比。
:::
:::

:::

:::warning 一个幸福结局，与一个更软的词
两个习惯会毁掉本章。第一个把欧洲联盟当作本图谱的幸福结局：1989年完成了，2004年完成了，没有什么剩下需要定年的。它在联合王国的离开上失败，在2010年的那些债务项目上失败，在一场2026年仍然敞开的战争上失败。第二个习惯把2022年2月24日软化为一场危机、一场冲突或一次行动，或者把它折进2014年的吞并里。年表的词是入侵，而那场全面入侵有它自己的日子。第三个习惯更小、却持续存在，它编辑2004年5月1日的那十个，添加克罗地亚或保加利亚，或者删掉马耳他与塞浦路斯，因为它们败坏了一个地区的绰号。那份名单是精确的。那个过去没有闭合。
:::

:::history
2022年2月24日，俄罗斯开始对乌克兰的全面入侵。截至2026年，那场战争还没有结束。本图谱陈述那个事实，不提供伤亡总数，也不提供政策。欧洲联盟自己的那些日期，从1992年2月7日《马斯特里赫特条约》的签字到2020年1月31日联合王国的离开，坐在同一条时间线上，并没有把它闭合。
:::

:::widget timeline

end: 2022

:::

那个图形就是画成圆点的警告。1999年同时装着账面货币的欧元与科索沃战役。2004年是十个国家，不是一个地区。2008年是一场破产，不是2010年的那些希腊项目——它们甚至不是一个圆点。2016年是一次表决，不是离开，而2020年是离开，不是那一年之内的过渡的结束。2022年是一次入侵的开始。它之后没有任何东西被画出来，因为它之后没有任何东西是这份年表所掌握的结果。如果你想让那条线结束，你就是在向那个图形要一个它所没有的和平。

## 通向何处

这本图谱里没有更晚的课程。那个敞开的论断就是[[sources/argument]]的方法：一次带日期的入侵，对一个伤亡总数的拒绝，对一个立场的拒绝。欧洲联盟之所以仍然是一份成员名单，而不是那块大陆，是[[sources/naming-europe]]的道理。1989年没有完成的东西，在[[postwar/from-1989]]。那些并非永久的分裂制度，包括民主德国在内，在[[postwar/division]]。本图谱对1939年9月1日在[[wars/second-world-war]]里、对2022年2月24日在这里，都使用入侵这个词，因为年表说的就是那个词。那些战争不是同一场战争，而那个共享的词也不是关于任何人该做什么的建议。

:::summary
- 马斯特里赫特在1992年2月7日签署，在1993年11月1日生效，相隔633天。1975年的赫尔辛基、1979年的直选与1986年的《单一欧洲法令》更早，而且不同。
- 欧元在1999年1月1日是账面货币，在2002年1月1日是纸币与硬币。不是每个成员国都采用那种现金。联合王国没有。
- 奥地利、芬兰与瑞典在1995年1月1日加入。2004年5月1日的那十个是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。
- 保加利亚与罗马尼亚在2007年加入。克罗地亚在2013年7月1日加入。更晚加入者不是那十个。
- 北约围绕科索沃的战役从1999年3月24日延续到6月10日。本课记录关于它的论辩，不裁决它。
- 雷曼兄弟在2008年9月15日申请破产。希腊的贷款项目在2010年开始。那些不是同一天。
- 联合王国在2016年6月23日表决离开，在2020年1月31日离开，在2020年12月31日结束过渡。
- 2014年，俄罗斯占领并吞并克里米亚。多数国家不承认。2022年2月24日，俄罗斯开始对乌克兰的全面入侵。截至2026年，那场战争还没有结束。不说出伤亡总数，也不说出政策。
:::

## 习题

:::exercise 多少个国家 {#exr-ten level=1 check="10"}
多少个国家在2004年5月1日加入欧洲联盟？（请输入数目。）
:::solution
名单是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。那是10。保加利亚、罗马尼亚与克罗地亚更晚，不在计数之内。奥地利、芬兰与瑞典在1995年1月1日加入。

10
:::

:::exercise 项目，不是破产 {#exr-loans level=1 check="2010"}
希腊的贷款项目在哪一年开始？（请输入年份。）
:::solution
希腊的贷款项目在2010年开始。雷曼兄弟在2008年9月15日申请破产。债务危机不是那一天。年表点名的那些项目的年份是2010年。

2010

:::exercise 二月的日子 {#exr-invasion level=1 check="24"}
俄罗斯在2022年2月的哪一天开始对乌克兰的全面入侵？（请输入日子。）
:::solution
那场全面入侵在2022年2月24日开始。它是一次入侵。截至2026年，它还没有结束。克里米亚是2014年，不是这一天。伤亡总数不是答案的一部分。

24

:::exercise 战役的长度 {#exr-kosovo level=2 check="78"}
求从1999年3月24日到1999年6月10日的日期差。（请输入天数。）
:::solution
从3月24日到6月24日是92天：3月有31天，所以3月24日到4月24日是31天；4月有30天，所以4月24日到5月24日是30天；5月有31天，所以5月24日到6月24日是31天。总和是92。6月10日在6月24日之前14天，所以92减14是78。那场战役是一场78天的军事战役。它不是欧元，欧元在同一年1月1日作为账面货币开始。本课不评判那场战役的合法性，也不给出死亡总数。

78
:::
:::

:::exercise 表决、离开、过渡 {#exr-three level=2}
说出联合王国离开的三个日期，说出每个日期是什么，并说出年表关于那次表决扣住了什么事实。
:::solution
2016年6月23日，联合王国表决离开。2020年1月31日，它离开。2020年12月31日，过渡结束。表决不是离开，离开也不是过渡的结束。年表不给出多数的规模，所以不得发明任何百分比。它也不给出表决是否明智的任何评判。[[#thm-open]]允许那些日期，拒绝一个立场。从表决到离开的日期差是1317天，过渡持续335天，但问题要的是那三个日期与那个未给出的数字，不是那些计数。
:::
:::

:::exercise 不是同一天 {#exr-lehman level=2}
解释为什么2008年9月15日没有开启希腊的贷款项目。如果你为两个事件中的任何一个给出一个钱的数额，你添加了什么？
:::solution
雷曼兄弟，一家美国公司，在2008年9月15日申请破产。希腊的贷款项目在2010年开始。年表把它们分开，并说欧洲债务危机不是破产的那一天。把那些项目起于2008年，就是把一个事实搬到错误的年份上。一个钱的数额，以任何货币，都不在年表里。添加一个会是一种虚假的精确，与发明一个伤亡总数是同一种过错。那种承压的安排可以被描述，一种没有同年财政国家的共享货币，而不推荐保持或废弃它。
:::
:::

:::exercise 一部完成的图谱 {#exr-complete level=3}
下面这句话为示例而虚构。它不是史料。“到2004年5月1日，欧洲联盟已经吸收了东方，治愈了1989年，并完成了欧洲历史。”修复那份名单，并说出这句话无法幸存的两类更晚的事实。什么样的发现会使你的修复成为不必要？
:::hint
[[#def-ten]]是那精确的十个，包括马耳他与塞浦路斯，排除保加利亚、罗马尼亚与克罗地亚。[[#thm-open]]提供那些更晚的事实：一次离开，一次不被承认的吞并，以及一场2026年尚未结束的入侵。一个发现必须改变那些日期，而不仅仅是赞美欧洲联盟。
:::
:::solution
2004年5月1日的诸国家是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。马耳他与塞浦路斯不是作为一个单独集团的“东方”，而斯洛文尼亚也不能与其他国家互相替换。保加利亚与罗马尼亚在2007年加入。克罗地亚在2013年7月1日加入。“治愈了1989年”就是那个历史的终结的论断，由于诸场南斯拉夫战争，它在1990年代之内已经是假的。那句话无法幸存的两类更晚的事实，是联合王国的离开——在2016年6月23日表决、在2020年1月31日生效——与俄罗斯对乌克兰的全面入侵，始于2022年2月24日，截至2026年尚未结束。2014年对克里米亚的占领与吞并——多数国家不承认它——是第三类。一个会使修复成为不必要的发现，将是一份真的是作为一个国家的“东方”的2004年名单，加上一份其后既没有离开也没有入侵的年表。那不是记录。那个句子是编造的，而它完成的是那些日期留为敞开的历史。
:::
:::

:::exercise 编辑那十个 {#exr-edit level=3}
一位同学的2004年5月1日名单添加了保加利亚与克罗地亚，删掉了马耳他，而保留了“东部扩大”这个短语。写出精确的名单，说出每处编辑做了什么，并说出为什么单凭一个正确的十的数目也救不了那份被编辑的名单。
:::hint
把那位同学的名字与[[#def-ten]]比较。保加利亚的年份是2007年。克罗地亚的日子是2013年7月1日。马耳他正是那十个之一。数目可以停在十，而名字却是错的。
:::
:::solution
精确的名单是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。添加保加利亚，是把一个2007年的加入搬到2004年。添加克罗地亚，是把2013年7月1日搬到2004年。删掉马耳他，是删去一个确实加入过的国家，而它常常被删掉，是因为马耳他败坏了一个把那十个当作一个东部地区的故事。塞浦路斯会败坏同一个故事，却在真实名单上。如果那位同学添加两个名字、删掉一个，数目可以仍然是十。一个正确的数目救不了错误的名字。[[#def-ten]]是一份名单，不单单是一个数目，而“东部扩大”是一个绰号，不是那些名字的替代品。
:::
:::
