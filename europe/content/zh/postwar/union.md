欧洲联盟变成了什么？又有什么仍然不是已经结束的过去？

1957年3月25日的经济共同体是一份很短的成员名单，而不是一片大陆。欧洲联盟（European Union）出自后来的一项条约：该条约于1992年2月7日在马斯特里赫特（Maastricht）签署，1993年11月1日生效。联盟分两步获得了货币：1999年1月1日启用账面货币（book money），2002年1月1日发行纸币与硬币。它又分几步吸收了成员：1995年1月1日三国加入，2004年5月1日十国加入，2007年保加利亚与罗马尼亚加入，2013年7月1日克罗地亚加入；它也失去了一个成员：联合王国于2016年6月23日投票决定退出，2020年1月31日退出，2020年12月31日结束过渡期。在这些年里，围绕科索沃（Kosovo）进行了一场军事行动；美国的一次破产与希腊的贷款计划不在同一天；2014年，俄罗斯占领并吞并克里米亚（Crimea）；2022年2月24日，俄罗斯开始全面入侵乌克兰。截至2026年，这场战争尚未结束。本课把这次入侵称为入侵，不给出伤亡总数，不推荐任何政策，也不告诉你应当支持谁。欧洲联盟不是本图谱的圆满结局。一份时增时减的成员名单，与一场仍未结束的战争并存，恰恰是结局的反面。

## 从共同体到联盟

通往马斯特里赫特的道路是三项不同的行为，而不是一次诞生。1975年8月1日，《赫尔辛基最后文件》（Helsinki Final Act）签署，这是分裂两侧国家共同签署的安全文件，而不是一个市场。1979年，欧洲议会首次实行直接选举。民选议会不是主权者，选举也不是货币。1986年，《单一欧洲法令》（Single European Act）修订了各项条约，朝单一市场（single market）推进。它不是欧洲联盟的创立文件，马斯特里赫特条约才是。

:::definition 欧洲联盟 {#def-union}
这里的**欧洲联盟**，指《马斯特里赫特条约》（Maastricht Treaty）于1993年11月1日生效时建立的条约组织，其成员名单此后有所变化。它不是一种文明，不是这片大陆的同义词，也不是欧洲历史的圆满结局。
:::

该条约于1992年2月7日签署，1993年11月1日生效。签署不等于生效。从1992年2月7日到1993年2月7日是366天，因为1992年是闰年，1992年2月29日在当年2月7日之后，落在这段跨度之内。从1993年2月7日到1993年11月1日是267天，合计633天。在这633天里，条约是一份已经签署、却尚未作为生效的联盟约束其成员的文本。把这两个日期合而为一，会让一场谈判看起来像拨动一个开关。

就本课所需的狭义而言，该条约的作用是赋予欧洲联盟法定名称，并规划了一条包括单一货币在内的道路。签署当天，它并没有把纸币放进任何人的口袋。欧元（euro）作为账面货币始于1999年1月1日，纸币与硬币始于2002年1月1日。从前一个日子到后一个日子是三年，其间有一个2月29日，所以这段跨度是三年零一天，而不是整三年。我们不把那个二月当作单独的历史事件，也不需要把它所在的年份当作政治日期。这三个日期就是论断本身。

并非每个成员国都采用了欧元纸币与硬币。联合王国没有采用，另一些国家也没有使用这种现金。说“欧洲在2002年换了货币”的读者，是把一份名单改称为一片大陆，而[[sources/naming-europe]]早已就1957年禁止这样做；这种说法还抹去了那些保留本国纸币的国家。[[#def-union]]是同一项禁令，只是适用于后来的一项条约。

:::theorem 三个日期，而不是一项完成的行为 {#thm-three}
1992年2月7日《马斯特里赫特条约》的签署、1993年11月1日的生效、1999年1月1日作为账面货币的欧元，以及2002年1月1日的纸币与硬币，是不同的日期。把它们合而为一，会使欧洲联盟看起来像一项已经完成的单一行为。
:::
:::proof
证据在于这些日期之间的间隔，以及每个日期所起作用的不同。签署产生文本。生效使欧洲联盟对其成员成为法律事实。账面货币是记账单位。纸币与硬币是另一个日子，比账面货币晚三年零一天，而且并非每个成员都采用。这些日子中没有一个是2004年5月1日的扩大，也没有一个是2020年1月31日的退出。

能够推翻这一论断的，是一份在同一天签署、生效并发行纸币，且囊括每一个欧洲国家的单一文件。不存在这样的文件。不能推翻这一论断的，是许多签署国真诚抱有的政治希望，即联盟与货币是迈向更安定大陆的步骤。希望不是日期。[[postwar/from-1989]]已经拒绝让1989年成为终点，这一论断则拒绝让马斯特里赫特成为披着条约名称的第二个终点。
:::

反方论证说，就实际而言，欧洲联盟“发生于”马斯特里赫特，后来的日期只是行政事务。然而实际意义恰恰存在于行政事务之中。一家还不能用欧元纸币付款的企业，一个已经签署却尚未受约束的国家，一个从不采用这种现金的成员：如果只保留1992年2月7日，这些都看不见了。从签署到生效的633天是最简单的检验。如果行政事务无关紧要，这些日子就不会存在。

:::quiz
下列哪一个顺序与货币和条约的情况相符？
- [ ] 纸币与硬币始于1992年2月7日，即马斯特里赫特条约签署当天，并通行于每一个欧洲国家。
- [ ] 作为账面货币的欧元与纸币都始于1999年1月1日，英国两者都采用了。
- [x] 马斯特里赫特条约于1992年2月7日签署，1993年11月1日生效；欧元于1999年1月1日成为账面货币，2002年1月1日发行纸币与硬币，但并非在每个成员国通行。
- [ ] 1986年的《单一欧洲法令》就是发行纸币的那一天。
:::solution
[[#thm-three]]把四个日期区分开来。联合王国没有采用欧元纸币与硬币。《单一欧洲法令》在1986年，是对市场的修订，既不是现金，也不是欧洲联盟的生效。1975年的赫尔辛基与1979年的直接选举更早，性质也不同。
:::
:::

:::example 签署不等于生效 {#ex-maastricht}
求从1992年2月7日到1993年11月1日的日期差，并说明这两个日期各起什么作用。
:::solution
从1992年2月7日到1993年2月7日是366天，其中包括1992年2月29日。从1993年2月7日到1993年11月7日，逐月计算为28加31加30加31加30加31加31加30加31，即273天，落在11月7日。11月1日比它早6天，273减6得267。于是366加267得633。条约在前一个日期签署，在后一个日期生效。在这633天里，它还不是生效的欧洲联盟。[[#thm-three]]从这段间隔出发，并拒绝把货币的日期也并入其中。
:::
:::

## 名单是精确的

:::definition 精确的扩大 {#def-ten}
**精确的扩大**是一份有日期的加入国名单，既不是一个地区，也不是一种情绪。2004年5月1日的扩大恰好是十个国家：塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。增加或删去一个国名，事实就改变了。
:::

在这十国之前，1995年1月1日有三国加入：奥地利、芬兰与瑞典。它们不是2004年的预演，也不是“东方”。瑞典的加入是一个条约事实，涉及一个曾处于《罗马条约》之外的国家。它不会使1957年成为欧洲的定义。

2004年5月1日，这十国加入。请一边读[[#def-ten]]，一边数一数它们，因为数目就是检验。马耳他与塞浦路斯在这十国之中，但它们并不是东方集团的前共产主义国家。捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、波兰与斯洛伐克经由不同的道路走出了那个世界；斯洛文尼亚的道路既经过一个南斯拉夫加盟共和国的终结，也经过入盟。本课无须借助这些道路来核查名单，只需要你不说“东欧加入了”，仿佛这个短语就等于这十国。绰号不是名单。保加利亚与罗马尼亚于2007年加入，不属于这十国。克罗地亚于2013年7月1日加入。第三个日期不是第一个日期的脚注。把克罗地亚加进2004年名单的人，或者加进保加利亚、再删去马耳他以凑满十这个数目的人，是为了保全一个故事而改变了事实。

同样的纪律也适用于与欧元同年开始的一场战事。1999年1月1日，欧元作为账面货币启用。1999年3月24日，北约（NATO）围绕科索沃发起军事行动，持续到1999年6月10日。从3月24日到6月10日是78天，从1月1日到3月24日是82天。货币与军事行动同在一年，却不是同一类行为。这场军事行动是年表中的事实。各国政府与史家对其法律依据和后果看法不一。本课记录这些日期以及这场争论的存在，但不裁决这场争论，也不给出死亡总数。裁决就成了一项政策，而本图谱不提供政策。

:::example 账面货币与军事行动并置 {#ex-kosovo}
把1999年1月1日与1999年3月24日、1999年6月10日并排放置。一个单独的1999年数据点可能掩盖什么？
:::solution
从1999年1月1日到3月24日是82天：一月有31天，1999年不是闰年，所以1月1日到3月1日是31加28，即59天；3月1日到3月24日是23天。军事行动随后从3月24日持续到6月10日，共78天：3月24日到6月24日是31加30加31，即92天；6月10日比它早14天，92减14得78。一个标着1999年的数据点，可能掩盖一种货币、一场78天的军事行动，以及两者并非同一项政策这一事实。[[#thm-three]]已经把货币与马斯特里赫特区分开来，本例则把货币与军事行动区分开来。关于这场军事行动合法性的争论是真实存在的，本课不作裁决。
:::
:::

:::example 编造的“大功告成” {#ex-happy}
下面这句话为示例而虚构。它不是史料。“2004年十国一加入，欧洲联盟就完成了1989年的事业，这部图谱也可以合上了。”这句话对名单做了什么？它必须假装看不见哪些后来的日期？
:::solution
2004年5月1日的十国恰好是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。“1989年的事业”把一份成员名单当作历史的终结，而[[postwar/from-1989]]早已拒绝这种说法；它还把马耳他与塞浦路斯藏进了一个关于旧东方集团的故事。这句话看不见2007年保加利亚与罗马尼亚的加入，看不见2013年7月1日克罗地亚的加入，看不见2016年6月23日联合王国投票决定退出，也看不见2020年1月31日联合王国的退出。它同样看不见2014年俄罗斯占领并吞并克里米亚，看不见2022年2月24日俄罗斯开始全面入侵乌克兰，而这场入侵截至2026年尚未结束。这句编造的“大功告成”之所以错误，是因为名单是精确的，也因为名单之后的岁月并非空白。
:::
:::

## 危机、退出、入侵

2008年9月15日，雷曼兄弟（Lehman Brothers）申请破产。这是美国的事件。随后的欧洲债务危机并不在同一天。希腊的贷款计划始于2010年。我们不给出任何货币的任何金额，因为年表没有给出，而数字只会显得精确。这场危机考验了一种共同货币，而其成员并没有共享一个同样历史的财政国家。这是对一种安排的描述，而不是建议保留、打破或改革这种安排。若干国家被卷入其中，年表为贷款计划的开始所点名的是希腊。我们不为其他计划编造日期。这些日期确实支持的，是区分：2008年9月15日不是2010年。破产不是贷款计划。一堂把欧洲危机的开端定在美国申请破产之日的课，跳过了记录所给出的唯一开端。

联合王国的退出包含三个日期，而这三个日期正是全部要点。2016年6月23日，联合王国投票决定退出欧洲联盟。年表没有给出多数票的幅度，所以我们不编造百分比。投票结果是退出的决定，而不是退出本身。2020年1月31日，联合王国退出。2020年12月31日，过渡期结束。从投票到退出是1317天。这段跨度中没有2月29日：2016年2月29日在2016年6月23日之前，2020年2月29日在2020年1月31日之后。从2016年6月23日起算三年是1095天，即三乘365。从这个周年日到2020年1月31日是222天，1095加222得1317。过渡期从2020年1月31日到2020年12月31日，共335天而不是334天，因为2020年是闰年，2月29日在这几个月之内。说“英国在2016年退出了”的人，抓住了投票，却漏掉了后来的两个日期。说“英国1月31日退出，法律关系就此终结”的人，则漏掉了335天的过渡期。我们不评说这次投票是否明智，评说明智与否就是选边站。这些日期才是本课的内容。

:::theorem 不是已经结束的过去 {#thm-open}
欧洲联盟的条约、货币、历次扩大与联合王国的退出，与俄罗斯2014年对克里米亚的占领和吞并、与俄罗斯2022年2月24日开始的对乌克兰的全面入侵，处在同一条时间线上。它们不是一个有着圆满结局的故事。截至2026年，这场入侵尚未结束，它不是已经结束的过去。
:::
:::proof
证据在于已确定事实的顺序，以及年表本身的限度。大多数国家不承认对克里米亚的吞并。这种不承认是事实的一部分，而不是为某项政策所作的宣讲。全面入侵始于2022年2月24日，它是入侵。回避这个词的说法，或者把2014年与2022年当作同一项行为的说法，都经不起日期的检验：对克里米亚的占领与吞并不是全面入侵，而这次入侵也不是委婉语所说的“危机”或“行动”。年表指出，截至2026年，这场战争尚未结束。年表没有给出伤亡总数。本课照搬这一限度，对读者应当支持谁不作任何补充。

能够推翻这一论断的，是本年表中定有日期、结束了这场战争的和约，或者证明欧洲联盟的制度史在2014年之前就已停止，因而不可能与之处在同一条时间线上。两者都不符合记录。扩大、退出、货币与入侵都有日期。不能推翻这一论断的，是那份真实的制度成就清单：自1979年起直接选举的议会，自1993年起生效的联盟，自1999年与2002年起的货币，以及自1995年、2004年、2007年与2013年起不断扩大的成员名单。这些成就可以逐一承认，但没有一项是终点，因为成员名单在2020年1月31日也会缩小，而一场全面入侵在2026年仍在进行。成就不是落下的帷幕。
:::

反方论证说，一部讲制度的教材应当止于制度，而一场正在进行的战争会使这一页很快过时，并把它卷入争吵。回答就是年表本身：它并不止于入侵之前，同时又禁止卷入争吵。提早停下，会使欧洲联盟成为这一论断所否认的圆满结局；进一步给出建议、伤亡数字或立场，又会使本课变成宣讲。[[#thm-open]]是这两种失败之间的窄路。你可以说，在各国之间、在公民之间，存在着关于承认、援助和谈判的争论。争论的存在是事实，本课不参与其中。

2014年的克里米亚与2022年2月24日的入侵还表明，为什么成员名单不是被讲成命运的安全保障。欧洲联盟的名单通过条约改变。对边界的承认则是另一类事实：大多数国家不承认这次吞并。我们不把这句话变成对战争如何结束的预言。记录中没有结局。图示止于2022年，是因为年表止于一个事实，而不是止于一个结果。一张延伸到它并不掌握的和平的图，就成了虚构。

:::example 一次退出的三个日期 {#ex-brexit}
请区分2016年6月23日、2020年1月31日与2020年12月31日。给出从投票到退出的日期差，以及从退出到过渡期结束的日期差。
:::solution
投票决定退出是在2016年6月23日。联合王国于2020年1月31日退出。过渡期于2020年12月31日结束。从2016年6月23日起算三年是1095天；而在直到2020年1月31日的整个跨度中没有2月29日，因为2016年的闰日在6月23日已经过去，2020年的闰日在1月31日还没有到来。从这个周年日到2020年1月31日是222天：从6月23日起逐月为30、31、31、30、31、30与31天，到达1月23日，再过八天到达1月31日。于是1095加222得1317，即从投票到退出的日期差。从2020年1月31日到2020年12月31日是335天，因为2020年是闰年，2月29日在其中。投票不是退出，退出也不是过渡期的结束。这里没有给出任何百分比，也不应编造。
:::
:::

:::warning 圆满结局，以及更柔和的字眼
有两种习惯会毁掉这一章。第一种把欧洲联盟当作本图谱的圆满结局：1989年完成了，2004年完成了，再也没有需要标注日期的事情。它在联合王国的退出、2010年的债务计划以及一场2026年仍未结束的战争面前都站不住。第二种习惯把2022年2月24日软化为危机、冲突或行动，或者把它并入2014年的吞并。年表使用的词是入侵，而全面入侵有它自己的日子。第三种习惯较小却始终存在：篡改2004年5月1日的十国名单，加上克罗地亚或保加利亚，或者因为马耳他与塞浦路斯破坏了某个地区绰号而把它们删去。名单是精确的，过去并没有结束。
:::

这张图就是画成数据点的警示。1999年同时容纳了作为账面货币的欧元与科索沃军事行动。2004年是十个国家，而不是一个地区。2008年是一次破产，而不是2010年的希腊贷款计划，后者甚至没有成为一个数据点。2016年是投票，而不是退出；2020年是退出，而不是同年稍后的过渡期结束。2022年是入侵的开始。此后什么也没有画出，因为此后没有任何东西是这份年表所掌握的结果。如果你想让这条线有个终点，你就是在向这张图索要一个它并不拥有的和平。

## 通向何处

本图谱中没有更晚的课程。这一开放的论断，正是[[sources/argument]]的方法：一次有日期的入侵，拒绝给出伤亡总数，拒绝选边站。欧洲联盟为何仍是一份成员名单而不是这片大陆，见[[sources/naming-europe]]。1989年没有完成的事情，见[[postwar/from-1989]]。那些并非永久的分裂制度，包括民主德国在内，见[[postwar/division]]。本图谱在[[wars/second-world-war]]中对1939年9月1日、在这里对2022年2月24日都使用“入侵”一词，因为年表就是这样说的。这两场战争不是同一场战争，共用的词也不是对任何人该做什么的建议。

:::summary
- 马斯特里赫特条约于1992年2月7日签署，1993年11月1日生效，相隔633天。1975年的赫尔辛基、1979年的直接选举与1986年的《单一欧洲法令》更早，性质也不同。
- 欧元于1999年1月1日成为账面货币，2002年1月1日发行纸币与硬币。并非每个成员国都采用这种现金，联合王国就没有采用。
- 奥地利、芬兰与瑞典于1995年1月1日加入。2004年5月1日的十国是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。
- 保加利亚与罗马尼亚于2007年加入，克罗地亚于2013年7月1日加入。后来的加入国不属于这十国。
- 北约围绕科索沃的军事行动从1999年3月24日持续到6月10日。本课记录有关争论，但不作裁决。
- 雷曼兄弟于2008年9月15日申请破产，希腊的贷款计划始于2010年，两者不在同一天。
- 联合王国于2016年6月23日投票决定退出，2020年1月31日退出，2020年12月31日结束过渡期。
- 2014年，俄罗斯占领并吞并克里米亚，大多数国家不予承认。2022年2月24日，俄罗斯开始全面入侵乌克兰。截至2026年，这场战争尚未结束。本课不给出伤亡总数，也不给出政策。
:::

## 习题

:::exercise 多少个国家 {#exr-ten level=1 check="10"}
2004年5月1日有多少个国家加入欧洲联盟？（请输入数目。）

10

:::exercise 二月的那一天 {#exr-invasion level=1 check="24"}

全面入侵始于2022年2月24日。它是入侵。截至2026年，它尚未结束。克里米亚是2014年，而不是这一天。伤亡总数不属于答案的一部分。

:::exercise 军事行动的时长 {#exr-kosovo level=2 check="78"}
求从1999年3月24日到1999年6月10日的日期差。（请输入天数。）
:::solution
从3月24日到6月24日是92天：三月有31天，所以3月24日到4月24日是31天；四月有30天，所以4月24日到5月24日是30天；五月有31天，所以5月24日到6月24日是31天。合计92。6月10日比6月24日早14天，92减14得78。这是一场持续78天的军事行动。它不是欧元，欧元在同年1月1日作为账面货币启用。本课不评判这场军事行动的合法性，也不给出死亡总数。

78
:::

:::exercise 投票、退出、过渡期 {#exr-three level=2}
说出联合王国退出的三个日期及其各自的含义，并说明年表在投票问题上没有提供什么事实。
:::solution
2016年6月23日，联合王国投票决定退出。2020年1月31日，它退出。2020年12月31日，过渡期结束。投票不是退出，退出也不是过渡期的结束。年表没有给出多数票的幅度，所以不得编造任何百分比。它也没有对投票是否明智作出任何评判。[[#thm-open]]允许陈述日期，拒绝选边站。从投票到退出的日期差是1317天，过渡期为335天，但本题要的是三个日期和那个未提供的数字，而不是这些计数。
:::
:::

:::exercise 不是同一天 {#exr-lehman level=2}
解释为什么2008年9月15日并没有开启希腊的贷款计划。如果你为其中任何一件事给出金额，你添加了什么？
:::solution
美国公司雷曼兄弟于2008年9月15日申请破产，希腊的贷款计划始于2010年。年表把两者区分开来，并指出欧洲债务危机不在破产那一天。把贷款计划的开始定在2008年，就是把一个事实挪到了错误的年份。任何货币的金额都不在年表中。添加金额是一种虚假的精确，与编造伤亡总数属于同一类错误。可以描述这种承受压力的安排，即一种没有同样历史的统一财政国家作支撑的共同货币，而无须建议保留或放弃它。
:::
:::

:::exercise 大功告成的图谱 {#exr-complete level=3}
下面这句话为示例而虚构。它不是史料。“到2004年5月1日，欧洲联盟已经吸纳了东方，弥合了1989年，并完成了欧洲历史。”请修正名单，并举出这句话经不起检验的两类后来的事实。什么样的发现会使你的修正变得不必要？
:::hint
[[#def-ten]]给出了精确的十国，包括马耳他与塞浦路斯，不包括保加利亚、罗马尼亚与克罗地亚。[[#thm-open]]提供了后来的事实：一次退出，一次未获承认的吞并，以及一场到2026年仍未结束的入侵。一项发现必须改变这些日期，而不只是赞美欧洲联盟。
:::
:::solution
2004年5月1日加入的国家是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。马耳他与塞浦路斯不属于作为单一集团的“东方”，斯洛文尼亚也不能与其他国家互换。保加利亚与罗马尼亚于2007年加入，克罗地亚于2013年7月1日加入。“弥合了1989年”就是历史终结论，由于南斯拉夫的历次战争，它在1990年代就已经不成立。这句话经不起检验的两类后来事实，一是联合王国的退出，于2016年6月23日投票决定、2020年1月31日生效；二是俄罗斯对乌克兰的全面入侵，始于2022年2月24日，截至2026年尚未结束。2014年对克里米亚的占领与吞并，大多数国家不予承认，这是第三类。能使修正变得不必要的发现，是一份真正作为单一国家的“东方”的2004年名单，再加上一份其后既无退出也无入侵的年表。记录并非如此。这句话是编造的，它把日期所敞开的历史说成已经完成。
:::
:::

:::exercise 篡改十国名单 {#exr-edit level=3}
一位同学列出的2004年5月1日名单加入了保加利亚与克罗地亚，删去了马耳他，并保留了“东扩”这一说法。请写出精确的名单，说明每处改动造成了什么，并说明为什么仅凭数目正确为十，也挽救不了这份被改动的名单。
:::hint
把这位同学的国名与[[#def-ten]]对照。保加利亚的年份是2007年，克罗地亚的日子是2013年7月1日，马耳他正是十国之一。数目可以仍是十，国名却是错的。
:::
:::solution
精确的名单是塞浦路斯、捷克、爱沙尼亚、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、斯洛伐克和斯洛文尼亚。加入保加利亚，是把2007年的加入挪到了2004年。加入克罗地亚，是把2013年7月1日挪到了2004年。删去马耳他，是删掉了一个确实加入的国家；它之所以常被删去，是因为马耳他破坏了把十国视为一个东部地区的故事。塞浦路斯同样会破坏这个故事，却仍在真实名单上。如果这位同学加了两个国名、删了一个，数目仍可能是十。数目正确救不了错误的国名。[[#def-ten]]是一份名单，而不只是一个数目；“东扩”是绰号，不能代替这些国名。
:::
:::
