1989年发生了什么，而什么没有随那堵墙终结？

一个流行的图景是柏林的一个夜晚，此后历史已经完成，欧洲已经完整。年表不支持这个图景。1989年有一个序列：波兰的圆桌会议（Round Table），这里不为它锁定单独的一天；5月，匈牙利开始开放它的边界；11月9日，柏林墙被开放；11月，捷克斯洛伐克的天鹅绒革命（Velvet Revolution）；12月，尼古拉·齐奥塞斯库（Nicolae Ceaușescu）倒台；1989年12月25日，他被处决。德国统一是更晚的一天，1990年10月3日。苏联于1991年12月26日正式解体，在米哈伊尔·戈尔巴乔夫（Mikhail Gorbachev）辞职的次日，而不是在墙被开放的那个夜晚。在那次解体的同一年，战争在南斯拉夫开始。波斯尼亚战争从1992年4月延续到代顿协议（Dayton agreement），后者于1995年11月草签，并于1995年12月14日签署。斯雷布雷尼察（Srebrenica）是1995年7月。我们对那场屠杀或对波斯尼亚战争都不说出一个死亡总数。1989年不是历史的终结。诸场战争就是那十年之内的证据。

铺垫不是那一年。1980年8月，格但斯克（Gdańsk）协议承认团结工会（Solidarity）。1985年3月，戈尔巴乔夫成为总书记。这些事实解释了一道裂缝如何成为可能。它们不是11月9日，也不是1991年12月26日。

## 铺垫不是那一年

:::definition 铺垫 {#def-runup}
本课里，1989年的**铺垫**是那两个先于那一年、却不是那一年的带日期的事实：1980年8月的格但斯克协议，以及戈尔巴乔夫1985年3月到任总书记。一次铺垫可以让一个更晚的序列变得可理解。它不能被用来替换那个序列。
:::

团结工会是波兰的一个工人运动，它在1980年8月的格但斯克赢得了一种国家后来试图收回的承认。年表没有为那次更晚的镇压定日，所以我们不为它发明一个年份。我们可以说的是，那个运动在戈尔巴乔夫之前被迫转入地下，而它仍然是那份记录所命名的铺垫。1980年的波兰还不是圆桌会议。年份标签上的距离，从1980年到1989年，是9。九不是一个稳步前进的故事。它是一个空隙，在其中一个工会被承认、然后被推出公众生活，而在其中一位新的总书记，从1985年3月起，从苏联党的顶层开始一场改革。

那场改革是铺垫的后半。我们在转述一项政策，而且我们说出这一点：戈尔巴乔夫试图修复的是那个联盟，不是为它的葬礼公布一份时间表。重建（perestroika）与公开性（glasnost）是那次尝试的通常名称。它们是一项政策的名称，不是引文，也不是一部宪法。会构成对那个转述的反证的，是一份1985年3月的、把那个联盟的解体排定在1991年12月的纲领。这份记录里没有这样的纲领。解体有它自己的日子，而那些日子是晚的。一个原因得是这样一类东西：它本来可能是别的样子的。诸改革可能被拒绝，而那个联盟可能在没有它们的情况下破裂。我们并不主张1985年3月是1989年11月9日的充足原因。[[sources/argument]]就是那个区分。在这里我们只是拒绝让铺垫吃掉那一年。

:::theorem 1989年是一个序列，不是一个夜晚 {#thm-sequence}
1989年的诸事件是不同国家里诸不同政治行为的一个序列。11月9日对柏林墙的开放是那个序列之内的一个日期。它不是那一年，也不是苏联的终结。
:::
:::proof
证据是年表实际给出的那个顺序，包括精确度上的那些限度。波兰圆桌会议定年到1989年而不定日到某一天。匈牙利在5月开始开放它的边界，在11月之前。墙在11月9日被开放。捷克斯洛伐克的天鹅绒革命也是11月，一个不同的国家，一种不同的形态，一场公民的反抗使一个党的领导层下台。齐奥塞斯库在12月倒台，而他在1989年12月25日被处决。一个单独的夜晚装不下一个春天的边境开放、一场11月在布拉格的反抗、以及12月在罗马尼亚的一场处决。人们早在11月9日之前就已经可以通过匈牙利离开民主德国。那次开放不是第一道裂缝。

会构成对这条论断的反证的，是表明波兰、匈牙利、捷克斯洛伐克与罗马尼亚没有它们自己的诸事件，或者表明那些事件是与墙的开放同一个行为。事实不是那样。同样会构成反证的，是一份在1989年11月9日解散苏联的文件。正式解体是1991年12月26日。不会构成对这条论断的反证的，是这个真实的情况：那次开放是令人震惊的，或者电视让一座城市看起来像整整一年。一幅图景可以对一个夜晚是真的，而对一年是假的。
:::

一个反方论证说，墙才是记忆所系的东西，而其他日期是专家的细节。记忆不是年表。只能说出11月9日的读者，说不出为什么匈牙利的5月要紧，也说不出为什么罗马尼亚的12月拦住了一个没有流血的那一年的迷思。我们不在处决上流连，也不描述一种方法。我们记录一个独裁者倒台了、被处决了，好让1989年不能被讲述成一种单一的温和。通俗的动词是“倒塌”。年表的动词是“开放”。“倒塌”藏起了一个已经开始的序列，和一个还没有终结的联盟。

:::quiz
哪一个顺序与1989年的年表相符？

- [x] 圆桌会议是1989年而没有锁定的日子，匈牙利在5月开始开放它的边界，墙在11月9日被开放，天鹅绒革命在11月，而齐奥塞斯库在12月25日被处决。
- [ ] 天鹅绒革命就是苏联的解体，定日为11月9日。

:::solution
[[#thm-sequence]]把圆桌会议、匈牙利的5月、11月9日、天鹅绒革命与1989年12月25日保持为不同的事实。团结工会的确定日期是1980年8月，是铺垫，不是墙被开放的那个夜晚。苏联的解体是1991年12月26日。那场处决与那次辞职不可以被允许共用一个句子，仅仅因为它们都落在一个12月25日。
:::

:::example 什么有某一天，什么没有 {#ex-precision}
列出1989年的序列，标出哪些条目有某一天，哪些只有月份，哪些只有年份。这个精确度的差别为什么要紧？
:::solution
波兰圆桌会议有年份1989年，而在这份年表里没有锁定的日子。匈牙利的边境开放有1989年5月而没有某一天。墙有某一天，1989年11月9日。天鹅绒革命有1989年11月而没有某一天。齐奥塞斯库的倒台有1989年12月，而他的处决有某一天，1989年12月25日。这个差别要紧，因为一种虚假的精确会发明记录没有给出的日子，而一种虚假的含混会把11月9日与12月25日变成“那一年的某个时候”。[[#def-runup]]已经把1980年8月与1985年3月挡在名单之外。精确是这条论断的一部分，不是它之后的装饰。
:::
:::

## 那次开放没有做到的事

:::definition 正式解体 {#def-dissolve}
本课里，苏联的**正式解体**是1991年12月26日的行为，那一天苏联最高苏维埃（Supreme Soviet）解散那个联盟。它不是戈尔巴乔夫1991年12月25日的辞职，不是1991年12月8日的别洛韦日协议（Belavezha accords），不是1991年8月19日至21日那场未成功的政变，也不是1989年11月9日墙的开放。
:::

德国统一是1990年10月3日。从1989年11月9日到1990年10月3日是328天，这个计数我们马上就做。民主德国作为一个单独的国家终结。联邦共和国继续存在。那是制度事实。前民主德国的有些人把那次统一体验为一场并吞，一种一个国家的丧失，而不是对等者的加入。那种体验是一场关于1990年的政治的真实论辩。它不是第二个日期。我们并不以党派立场告诉你们该偏好哪一种描述。我们说的是，《基本法》的那个共和国——在[[postwar/division]]里定日为1949年5月23日——是那个继续存在的国家，而1990年10月3日不是1989年11月9日。一堵墙的开放不是一个国家的终结。十一个月，按那328天的粗略尺度，坐在它们之间。

那个联盟用得更久，而且走一条不同的路。1991年8月19日至21日，一场在莫斯科的政变试图夺取政府而未成功。1991年12月8日，诸共和国之间议定了别洛韦日协议。我们在转述，而且我们说出这一点：那些协议把那个联盟当作已经终结，先于那个正式的行为。戈尔巴乔夫在1991年12月25日辞职。1991年12月26日，最高苏维埃正式解散那个联盟。辞职不是解体。这两个行为相隔一天，而它们在日历上是在另一个12月25日之后的两年。齐奥塞斯库在1989年12月25日被处决。从那一天到戈尔巴乔夫1991年12月25日的辞职是730天，恰好两年，跨度之内没有一个2月29日。日历日子上的巧合是一个陷阱。一个日子是罗马尼亚的一场处决。另一个是莫斯科的一次辞职。两者都不是1991年12月26日。

:::theorem 联盟活得比墙久 {#thm-union}
苏联并不在墙被开放时终结。作为一个正式的联盟，它在1991年12月26日终结，在一场未成功的政变、别洛韦日协议与一次辞职之后。1989年不是历史的终结：诸场南斯拉夫战争就在同一个十年之内。
:::
:::proof
第一句话的证据是那一对十二月的日子，以及任何一个定年到1989年的解体的缺席。政变在1991年8月19日至21日失败。那些协议是12月8日。辞职是12月25日。解体是12月26日。从1989年11月9日到1991年12月26日，那个联盟仍然有一个年表所能指向的正式存在。第二句话的证据是南斯拉夫。斯洛文尼亚的十日战争（Ten-Day War）是1991年6月。克罗地亚战争在1991年开始。波斯尼亚战争定年为从1992年4月到代顿，代顿于1995年11月草签，于1995年12月14日签署。斯雷布雷尼察是1995年7月，在那场战争之内，不是在一个幸福结局之后。一个包含着历史的终结的年份，不会在那十年之内被这些战争接在身后。

会构成对那条正式论断的反证的，是一道定年到1989年的解体法令，或者一个表明1991年12月25日与26日是同一个行为的论证。它们相继而不同。会构成对“历史的终结”之拒绝的反证的，是一个在11月9日之后、没有为前南斯拉夫境内的任何战争定年的和平的十年。年表为诸战争定了年。不会构成对任何一半的反证的，是这个真实的评说：到1991年末，权力已经从那个联盟流走了，或者11月9日对在场者来说感觉像一种终结。感觉不是最高苏维埃的行为。流失不是把12月26日搬回1989年的许可证。
:::

那个关于权力的反方论证，是一个认真的读者会提出的论证，所以它应当在满强度下被回答。到政变之时，诸共和国已经在行动，仿佛那个中心已经无法指挥它们。12月8日的那些协议，按我们正在使用的那个转述，把那个联盟当作已经完结。如果那个转述是公允的，那么12月26日看起来就像一名文书的最后一个签字。把那些政治让步给你。[[#thm-union]]里的论断说的是年表定年的那个正式终结，不是那种那个联盟在1989年已经是一个鬼魂的感觉。一个鬼怪故事正是那句历史的终结被写出来的方式：如果真正的终结是柏林的那个夜晚，那么此后的一切都是尾声，而一场在1991年6月开始的战争也是一个尾声。尾声是错误的卷宗。1991年6月与解体是同一个年份，而它不是同一个事件。那个图形把“苏联与南斯拉夫”放进1991年的一个圆点。本课劈开那个圆点，正如关于1968年的那一课劈开了它自己的那个圆点。

从1991年8月19日到1991年12月8日是111天。8月有31天，所以8月19日到12月19日是31加30加31加30，即122天，而12月8日早11天，所以122减11是111。那场政变与那些协议相隔一个季节。从12月8日到12月25日是17天。从12月25日到12月26日是1天。任何一个说“联盟在8月终结”或者“联盟在圣诞节终结”的人，得到的是一个月份，却失去了那些区分。[[#def-dissolve]]的存在，就是为了让那些说法必须点名一个行为。

:::example 统一不是那次开放 {#ex-unify}
求从1989年11月9日到1990年10月3日的日期差。说出这个计数禁止你合拢什么。
:::solution
从1989年11月9日到1990年11月9日是365天。1990年不是闰年，所以那个跨度之内没有一个2月29日。从10月3日到11月9日是37天：10月有31天，所以10月3日到11月3日是31天，而11月3日到11月9日是6天。于是365减37是328。墙在1989年11月9日被开放。德国统一是1990年10月3日，晚328天。那次开放没有统一德国。民主德国作为一个单独的国家终结是更晚的日期，而联邦共和国是那个继续存在的国家。一种并吞的感觉——前民主德国的有些人持有这种感觉——是一场关于那种政治的论辩。它不是一个对立的日期。
:::
:::

:::example 两个圣诞节 {#ex-christmas}
1989年12月25日与1991年12月25日很容易混淆，而1991年12月26日很容易被丢掉。分开那三个日期，并给出从第一个到第二个的日期差。
:::solution
1989年12月25日，齐奥塞斯库被处决。那是罗马尼亚的一个独裁者的终结，在[[#thm-sequence]]的序列之内。它不是苏联的终结。1991年12月25日，戈尔巴乔夫辞职。1991年12月26日，最高苏维埃正式解散那个联盟。辞职与解体相隔一天，却不是同一个行为，这就是[[#def-dissolve]]。从1989年12月25日到1991年12月25日是两年。跨度之内没有一个2月29日落下，所以差是2乘365，即730天。共享的日历日子是记忆的一个陷阱。那些行为是一场处决、一次辞职、一场解体。
:::
:::

## 那个十年的另一场战争

南斯拉夫不是苏联解体的一份迟到的副本，而那些战争也不是一个预先定好的命运。斯洛文尼亚的十日战争在1991年6月，是旧联邦边缘上的一场短促战争，在苏联最后一个夏天的同一个月窗口之内，不是同一种政治。克罗地亚战争在1991年开始，不是十日战争换了另一个名字。波斯尼亚战争定年为从1992年4月起。我们不在4月里发明某一天。从1992年4月到1995年4月是三年，而代顿协议在1995年12月14日签署，晚于那个第三个4月，所以那场定年的战争比三年长。它比从1992年4月起的四年短，因为那个签字仍然在1995年之内。这是一个没有定日的4月所能允许的精确限度。1995年11月的草签不是12月14日的签署。同一个季节，不同的行为。一个只被草签的和平，还不是年表当作已签署来对待的那个和平。

斯雷布雷尼察在1995年7月，是波斯尼亚塞族武装对波斯尼亚穆斯林的一场屠杀，在波斯尼亚战争之内、在代顿签字之前。国际法庭后来认定那场屠杀是灭绝种族。我们不为那些判决定日，因为那些日子不在这份年表里，而我们也不说出一个死亡总数。我们不描述一种方法。说出那项罪行、那个月份与那个法律认定而不给出一个数字，就是那份记录设定的限度。同一个限度约束整个波斯尼亚战争。没有死亡总数。那个缺席不是那场战争很小的暗示，也不是从一份报纸借一个数字的许可证。这是本图谱的一条规则。

这就是针对历史的终结的那个工作过的案例。取一份编造的、定日为那次开放次日清晨的报道。它可以知道1989年11月9日。它还不可能知道1990年10月3日，还不可能知道1991年12月25日的一次辞职，还不可能知道1995年7月的一场屠杀或1995年12月14日的一个签字。如果一种哲学告诉你说那份报道已经包含着意识形态冲突的终结，那就是在要那份报道看穿一个十年。[[#thm-union]]就是那个拒绝。一个1989年的著名论辩——我们转述它而不引用它——把自由民主当作意识形态斗争的终结。那个转述对那个论辩也许是公允的。那个论辩对那个十年并不公允。诸场南斯拉夫战争是坐在那个十年之内的反证，不是一个在论断完成之后才被钉上去的更晚的辩解。

1975年8月1日的《赫尔辛基最后文件》（Helsinki Final Act）有时被征用为1989年的原因，因为持不同政见者使用过它关于权利的语言。那份文件是真实的，而它不是1989年11月9日的充足原因。一项约束不是一个夜晚。同样的谨慎适用于戈尔巴乔夫：把铺垫包括进来，而不要让它变成那一年。1986年的《单一欧洲法令》（Single European Act）与1979年的直接选举，属于通往马斯特里赫特（Maastricht）的路，在[[postwar/union]]里讲授。它们不是那堵墙的意思。

:::example 一份编造的报道 {#ex-dispatch}
下面这句话为示例而虚构。它不是史料。在这项虚构之内，它被定日为1989年11月10日。“昨夜历史终结了，德国问题关闭了，而苏联离开了地图。”这个虚构的日期能够看见什么，而它被禁止知道什么？
:::solution
1989年11月10日，墙已经被开放了一天。圆桌会议、匈牙利的5月与天鹅绒革命已经在那一年或那一年的11月之内。齐奥塞斯库还没有倒台。那是12月，而处决是1989年12月25日。德国统一是1990年10月3日，在11月9日之后328天，所以“德国问题关闭了”按[[#ex-unify]]里的计数来得早。那个联盟在1991年12月26日正式解体，在1991年12月25日的辞职之后。斯洛文尼亚的十日战争是1991年6月，克罗地亚战争在1991年开始，而波斯尼亚战争延续到1995年12月14日的一个签字，其中有1995年7月的斯雷布雷尼察，没有说出任何死亡总数。那份编造的报道知道一次开放。仅仅凭盖在它上面的那个日期，它就被禁止知道其余的一切。把它提升为史料所需要的，是更晚的史料。一句编造的句子没有任何史料。
:::
:::

- [x] 1991年12月26日，最高苏维埃解散那个联盟之时。
:::solution
[[#def-dissolve]]把那四个日期分开。那次开放是1989年之内的一个事件。那场处决是罗马尼亚的。那次辞职是解体之前的那一天，不是解体。那个正式的行为是1991年12月26日。诸场南斯拉夫战争就是[[#thm-union]]同时也拒绝把1989年称为历史的终结的理由。
:::
:::

:::warning 历史的终结
本章的存在所要拦住的迷思，是1989年终结了历史，通常经由柏林的一个夜晚。那个夜晚是真实的：墙在11月9日被开放。那个终结不是。波兰、匈牙利、捷克斯洛伐克与罗马尼亚在那个序列之中有它们自己的位置。德国在1990年10月3日统一，不是在夜晚。那个联盟在1991年12月26日解体，在一次辞职的次日，在一次共享同一个日历日子、此外什么都不共享的处决之后的两年。南斯拉夫的诸场战争贯穿同一个十年，到一个1995年12月14日的签字。第二个迷思更安静、同样昂贵，它把1989年12月25日与1991年12月25日当作同一个圣诞节。它们相隔730天，而它们是不同的行为。
:::

:::history
1989年11月9日，柏林墙被开放。它是那一年之内的一个事件，那一年还包括波兰圆桌会议与齐奥塞斯库的倒台，而他在1989年12月25日被处决。那次开放不是苏联的正式终结，后者出现在1991年12月26日，戈尔巴乔夫辞职的次日。
:::

在窗口0，每一年是一个圆点，这就是1989年如何变成“墙”、1991年如何变成一个终结。团结工会是1980年，戈尔巴乔夫是1985年，那些铺垫，坐在与1995年的代顿同一条线上。那个图形停在一扇窗口，而不是停在一个结果。1995年是一个签字，不是墙之后的那个十年是和平的证据。斯雷布雷尼察是同一年之内的那个7月，而它没有被画出来。你必须说出它，而你必须不带死亡总数地说出它。

## 通向何处

在解体之后数周、于1992年2月7日签署的那个条约，是[[postwar/union]]的开端：马斯特里赫特、欧元（euro）、诸次扩大、一次离开，以及一场截至2026年还没有结束的全面入侵。1989年之内的任何东西都没有合上那一页。1961年8月13日那堵墙的关闭——本章只是把它打开——定年在[[postwar/decolonisation-and-1968]]里。一个像“历史的终结”这样的标签如何隐藏一个论断，而一次铺垫如何作为充足原因而失败，是[[sources/argument]]。统一把两个德国国家带到一个制度终结，而那两个国家建于[[postwar/division]]。

:::summary
- 1980年8月的团结工会与格但斯克协议，以及1985年3月的戈尔巴乔夫，是铺垫。它们不是1989年那一年。
- 1989年是一个序列：圆桌会议，匈牙利5月的边境，11月9日开放的墙，11月的天鹅绒革命，12月齐奥塞斯库的倒台，他在12月25日的处决。
- 那次开放不是德国统一。那是1990年10月3日，晚328天。联邦共和国继续存在。
- 一场政变在1991年8月19日至21日失败。别洛韦日协议是12月8日。戈尔巴乔夫在1991年12月25日辞职。那个联盟在1991年12月26日正式解体。
- 1989年12月25日与1991年12月25日相隔730天。它们是一场处决与一次辞职，不是同一个圣诞节。
- 斯洛文尼亚的十日战争是1991年6月。克罗地亚战争在1991年开始。波斯尼亚从1992年4月延续到1995年12月14日的代顿签字。
- 斯雷布雷尼察是1995年7月，一场后来被法庭认定为灭绝种族的屠杀。对它或波斯尼亚战争都不说出死亡总数。
- 1989年不是历史的终结。诸场战争就是那十年之内的证据。
:::

:::exercise 从协议到辞职 {#exr-seventeen level=2 check="17"}

两个日期都在1991年12月。差是25减8，即17天。12月26日的解体在辞职之后一天，所以它在协议之后18天，但问题止步于辞职。8月19日至21日的政变在当年的更早，不在这个计数里。

:::exercise 把那一年排成顺序 {#exr-order level=2}
按年表所支持的顺序写出1989年的序列。标出哪些条目有某一天，哪些只有月份，哪些只有年份。不要把铺垫搬进那一年。
:::solution
铺垫留在外面：1980年8月与1985年3月。在1989年之内，顺序是波兰圆桌会议，然后是匈牙利在5月开始开放它的边界，然后是11月9日墙的开放，然后是11月的天鹅绒革命，然后是12月齐奥塞斯库的倒台，然后是他在12月25日的处决。圆桌会议有年份而没有某一天。匈牙利有5月而没有某一天。天鹅绒革命有11月而没有某一天。齐奥塞斯库的倒台有12月，而在处决——12月25日——之外没有一个单独的日子。那次开放有某一天。不要发明那些缺失的日子。[[#thm-sequence]]就是那个名单不是单独的“11月9日”的理由。
:::

:::exercise 草签不是签署 {#exr-dayton level=2}
波斯尼亚战争被定年到代顿协议。把草签与签署分开，把斯雷布雷尼察与它们并置，并说出本课不会量化什么。
:::solution
那场战争定年为从1992年4月起。代顿在1995年11月草签，在1995年12月14日签署。草签与签署是同一个季节，却不是同一个行为。斯雷布雷尼察是1995年7月，在两者之前，是战争期间波斯尼亚塞族武装对波斯尼亚穆斯林的一场屠杀。法庭后来认定它是灭绝种族。本课对那场屠杀不说出死亡总数，对那场战争也不说出，而且不描述一种方法。那个签字不是1989年11月9日，也不是钉在那堵墙上的一个幸福结局。
:::
:::

:::exercise 一份知道得太多的报道 {#exr-dispatch level=3}
下面这句话为示例而虚构。它不是史料。在这项虚构之内，它被盖上1989年11月10日的印记。“历史终结了，德国统一了，而联盟消失了。”只使用那个印记之后的日期，指出这句话还不可能知道什么。要什么才能让那天早晨的一份真实史料能够说出其中任何一点？
:::hint
那个印记在1989年11月9日之后一天。统一、辞职、解体与诸场南斯拉夫战争全在更晚。[[#thm-union]]就是那个检验。一本真实的日记可以记录一种情绪。它不能记录一个还没有发生的日期。
:::
:::solution
1989年11月10日，墙已经被开放了一天。德国统一是1990年10月3日。戈尔巴乔夫在1991年12月25日辞职，而那个联盟在1991年12月26日正式解体。斯洛文尼亚的十日战争是1991年6月，克罗地亚战争在1991年开始，而波斯尼亚战争延续到1995年12月14日的一个签字，其中有1995年7月的斯雷布雷尼察，没有死亡总数。那些事实没有一个对一个盖着1989年11月10日的句子是可用的。那天早晨的一封真实信件可以记录狂喜、恐惧或一个预言。一个预言不是对1990年10月3日或对1991年12月26日的知识。要把那些更晚的事实当作事实说出来，那份史料必须比它们更晚。那句编造的句子根本不是什么史料。
:::
:::

:::exercise 一个日期的两次处决 {#exr-trap level=3}
解释记住不带年份的“12月25日”里的陷阱。给出你必须分开的那两个12月25日之间的日期差，说出每个行为是什么，并说出12月26日添加了什么。会构成对你的区分的反证的，会是什么？
:::hint
一个12月25日是1989年，一个是1991年。如果没有一个闰日落在跨度之内，差是730天。[[#def-dissolve]]不会让辞职顶替解体。拦住“历史的终结”的，是诸场战争，不是那道算术。
:::
:::solution
1989年12月25日，齐奥塞斯库被处决。1991年12月25日，戈尔巴乔夫辞职。从第一个到第二个是两年，跨度之内没有一个2月29日，所以差是730天。它们共享一个日历日子，不共享一个行为：罗马尼亚的一场处决，莫斯科的一次辞职。1991年12月26日，最高苏维埃正式解散那个联盟。那在辞职之后一天，而不是辞职。会构成对这条区分的反证的，是这样的证据：那场处决与那次辞职是同一个行为，或者那个联盟在1989年12月25日被正式解体。年表两者都不支持。从1991年6月贯穿到一个1995年12月14日的签字的诸场南斯拉夫战争，是不把任何一个圣诞节当作历史的终结的更进一层的理由。
:::
:::
