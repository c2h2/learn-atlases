1989年发生了什么？又有什么没有随柏林墙一同终结？

一种流行的图景是：柏林的一个夜晚之后，历史宣告完结，欧洲重归完整。年表并不支持这种图景。1989年是一个序列：波兰的圆桌会议（Round Table），这里不为它锁定具体日期；5月，匈牙利开始开放边境；11月9日，柏林墙开放；11月，捷克斯洛伐克发生天鹅绒革命（Velvet Revolution）；12月，尼古拉·齐奥塞斯库（Nicolae Ceaușescu）倒台；1989年12月25日，他被处决。德国统一是更晚的日子，即1990年10月3日。苏联于1991年12月26日正式解体，是在米哈伊尔·戈尔巴乔夫（Mikhail Gorbachev）辞职的次日，而不是在柏林墙开放的那个夜晚。就在苏联解体的同一年，南斯拉夫爆发了战争。波斯尼亚战争从1992年4月持续到代顿协议（Dayton agreement），该协议于1995年11月草签，1995年12月14日正式签署。斯雷布雷尼察（Srebrenica）事件发生在1995年7月。对这场屠杀和波斯尼亚战争，我们都不给出死亡总数。1989年不是历史的终结，这十年间的历次战争就是证据。

前奏不等于这一年。1980年8月，格但斯克（Gdańsk）协议承认了团结工会（Solidarity）。1985年3月，戈尔巴乔夫出任总书记。这些事实解释了裂缝如何成为可能，但它们既不是11月9日，也不是1991年12月26日。

## 前奏不等于这一年

:::definition 前奏 {#def-runup}
本课所说的1989年的**前奏**，是两项先于这一年、却不属于这一年的有日期的事实：1980年8月的格但斯克协议，以及1985年3月戈尔巴乔夫出任总书记。前奏可以使后来的序列变得可以理解，却不能代替这一序列。
:::

团结工会是波兰的工人运动，它于1980年8月在格但斯克赢得了承认，而国家后来又试图收回这一承认。年表没有为后来的镇压标注日期，所以我们不为它编造年份。我们可以说的是，这一运动在戈尔巴乔夫上台之前就被迫转入地下，而它仍然是记录所指明的前奏。1980年的波兰还不是圆桌会议。从1980年到1989年，年份标签相差9。这个9并不是稳步前进的故事，而是一段间隔：其间一个工会先获承认、后被逐出公共生活，一位新任总书记又从1985年3月起，自苏联共产党的高层发起改革。

这场改革是前奏的后一半。我们是在转述一项政策，并明说这一点：戈尔巴乔夫试图修复苏联，而不是为它的葬礼公布时间表。“改革”（perestroika）与“公开性”（glasnost）是这一尝试的通常名称。它们是政策的名称，不是引文，也不是宪法。能够推翻这一转述的，是一份1985年3月制定、把苏联解体排定在1991年12月的纲领。记录中没有这样的纲领。解体有它自己的日子，而且来得很晚。原因必须是本来可能不同的那类事情：这些改革本可以被拒绝，苏联也可能在没有这些改革的情况下解体。我们并不主张1985年3月是1989年11月9日的充分原因，这一区分见[[sources/argument]]。在这里，我们只是拒绝让前奏吞没这一年。

:::theorem 1989年是一个序列，而不是一个夜晚 {#thm-sequence}
1989年的事件，是不同国家中各不相同的政治行为所构成的序列。11月9日柏林墙的开放只是这一序列中的一个日期，它不是这一整年，也不是苏联的终结。
:::
:::proof
证据是年表实际给出的顺序，包括它在精确度上的限度。波兰圆桌会议定于1989年，但没有具体日期。匈牙利于5月开始开放边境，早于11月。柏林墙于11月9日开放。捷克斯洛伐克的天鹅绒革命也在11月，但那是另一个国家、另一种形式：一场使党的领导层下台的公民反抗。齐奥塞斯库于12月倒台，并于1989年12月25日被处决。一个夜晚装不下春天的边境开放、11月布拉格的反抗和12月罗马尼亚的处决。早在11月9日之前，人们就已经可以经由匈牙利离开民主德国。柏林墙的开放并不是第一道裂缝。

能够推翻这一论断的，是证明波兰、匈牙利、捷克斯洛伐克与罗马尼亚没有各自的事件，或者证明这些事件与柏林墙开放是同一项行为。事实并非如此。同样能够推翻它的，是一份在1989年11月9日解散苏联的文件。苏联的正式解体在1991年12月26日。不能推翻这一论断的，是这样的事实：柏林墙的开放令人震惊，或者电视让一座城市看起来就是这一整年。一幅画面可以对一个夜晚为真，对一整年却为假。
:::

有一种反方论证说，柏林墙才是记忆所系，其他日期只是专家的细节。但记忆不是年表。只说得出11月9日的读者，说不出匈牙利的5月为何重要，也说不出罗马尼亚的12月为何打破了“不流血的一年”这一神话。我们不在处决上停留，也不描述方式。我们只记录一位独裁者倒台并被处决，使1989年不能被讲成单一的温和类型。通俗的说法是“倒塌”，年表的用词是“开放”。“倒塌”掩盖了一个早已开始的序列，也掩盖了一个尚未终结的联盟。

下列哪一种顺序与1989年的年表相符？

- [x] 圆桌会议在1989年，没有锁定的日期；匈牙利于5月开始开放边境；柏林墙于11月9日开放；天鹅绒革命在11月；齐奥塞斯库于12月25日被处决。

:::example 哪些有具体日期，哪些没有 {#ex-precision}
列出1989年的序列，标出哪些条目有具体日期，哪些只有月份，哪些只有年份。精确度的差别为什么重要？
:::solution
波兰圆桌会议有年份1989年，但这份年表没有锁定其具体日期。匈牙利开放边境有1989年5月，没有具体日期。柏林墙有具体日期，即1989年11月9日。天鹅绒革命有1989年11月，没有具体日期。齐奥塞斯库倒台在1989年12月，他的处决则有具体日期，即1989年12月25日。这一差别之所以重要，是因为虚假的精确会编造记录没有给出的日子，而虚假的模糊又会把11月9日与12月25日变成“那年的某个时候”。[[#def-runup]]已经把1980年8月与1985年3月排除在这份清单之外。精确是论断的一部分，而不是事后的点缀。
:::
:::

## 柏林墙的开放没有做到的事

:::definition 正式解体 {#def-dissolve}
本课所说的苏联**正式解体**，是指1991年12月26日苏联最高苏维埃（Supreme Soviet）解散联盟的行为。它不是1991年12月25日戈尔巴乔夫的辞职，不是1991年12月8日的别洛韦日协议（Belavezha accords），不是1991年8月19日至21日失败的政变，也不是1989年11月9日柏林墙的开放。
:::

德国统一在1990年10月3日。从1989年11月9日到1990年10月3日是328天，这一计算稍后就做。民主德国作为单独的国家不复存在，联邦德国则延续下来。这是制度上的事实。前民主德国的一些人把统一体验为吞并，是一个国家的丧失，而不是平等者的联合。这种体验是关于1990年政治的一场真实争论，但它不是第二个日期。我们不以党派立场告诉你应当偏向哪一种描述。我们要说的是，在[[postwar/division]]中以1949年5月23日为日期的《基本法》共和国，是延续下来的那个国家；而1990年10月3日不是1989年11月9日。一堵墙的开放不等于一个国家的终结。按328天粗略计算，两者之间隔着十一个月。

苏联存续得更久，走的也是另一条路。1991年8月19日至21日，莫斯科的一场政变企图夺取政权，以失败告终。1991年12月8日，各加盟共和国之间达成了别洛韦日协议。我们是在转述，并明说这一点：这些协议在正式行为之前，就已把苏联视为终结。戈尔巴乔夫于1991年12月25日辞职。1991年12月26日，最高苏维埃正式解散苏联。辞职不是解体。这两项行为相隔一天，而在日历上，它们距另一个12月25日恰好两年。齐奥塞斯库于1989年12月25日被处决。从那一天到1991年12月25日戈尔巴乔夫辞职是730天，恰好两年，其间没有2月29日。日历日子的巧合是一个陷阱：一个是罗马尼亚的处决，另一个是莫斯科的辞职，两者都不是1991年12月26日。

:::theorem 苏联比柏林墙存续得更久 {#thm-union}
苏联并没有在柏林墙开放时终结。作为正式的联盟，它在经历了一场失败的政变、别洛韦日协议和一次辞职之后，于1991年12月26日终结。1989年不是历史的终结：南斯拉夫的历次战争就发生在同一个十年之内。
:::
:::proof
第一句话的证据，是十二月的那两个日子，以及不存在任何定于1989年的解体。政变于1991年8月19日至21日失败，协议在12月8日，辞职在12月25日，解体在12月26日。从1989年11月9日到1991年12月26日，苏联仍有年表能够指认的正式存在。第二句话的证据是南斯拉夫。斯洛文尼亚的十日战争（Ten-Day War）在1991年6月。克罗地亚战争始于1991年。波斯尼亚战争的时间是从1992年4月到代顿协议，后者于1995年11月草签，1995年12月14日签署。斯雷布雷尼察事件发生在1995年7月，处于这场战争之中，而不是在某个圆满结局之后。一个包含历史终结的年份，不会在同一个十年里接连出现这些战争。

能够推翻这一正式论断的，是一道定于1989年的解体法令，或者证明1991年12月25日与26日是同一项行为。两者先后相继，彼此不同。能够推翻对“历史终结”之拒绝的，是11月9日之后的一个和平的十年，其中前南斯拉夫境内没有任何有日期的战争。年表为这些战争标注了日期。不能推翻这两半论断中任何一半的，是这样的真实说法：到1991年末，权力早已从联盟中流失；或者，对亲历者而言，11月9日感觉像是终结。感觉不是最高苏维埃的行为，权力流失也不能成为把12月26日挪回1989年的许可。
:::

关于权力的反方论证，是认真的读者一定会提出的，因此应当以最有力的形式回答。到政变发生时，各加盟共和国已经表现得仿佛中央无法再指挥它们。按照我们所用的转述，12月8日的协议已经把苏联视为终结。如果这一转述公允，12月26日看起来就像是书记员的最后一个签名。这一政治判断可以承认。但[[#thm-union]]的论断，讲的是年表所标注的正式终结，而不是苏联在1989年已成幽灵的感觉。“幽灵故事”正是“历史终结”之说的写法：如果真正的终结是柏林的那个夜晚，此后的一切都是尾声，连1991年6月爆发的战争也成了尾声。尾声是归错了卷宗。1991年6月与苏联解体同年，却不是同一事件。图示把“苏联与南斯拉夫”放在1991年的同一个数据点上，本课则把这个数据点拆开，正如关于1968年的那一课拆开了它自己的数据点。

从1991年8月19日到1991年12月8日是111天。八月有31天，所以8月19日到12月19日是31加30加31加30，即122天；12月8日比它早11天，122减11得111。政变与协议相隔一个季节。从12月8日到12月25日是17天，从12月25日到12月26日是1天。说“苏联在8月终结”或“苏联在圣诞节终结”的人，抓住了一个月份，却失去了这些区分。[[#def-dissolve]]的作用，就是迫使这些说法指明一项具体行为。

:::example 统一不等于柏林墙的开放 {#ex-unify}
求从1989年11月9日到1990年10月3日的日期差，并说明这一计算禁止你把什么合而为一。
:::solution
从1989年11月9日到1990年11月9日是365天。1990年不是闰年，这段跨度中没有2月29日。从10月3日到11月9日是37天：十月有31天，所以10月3日到11月3日是31天，11月3日到11月9日是6天。于是365减37得328。柏林墙于1989年11月9日开放，德国统一在1990年10月3日，晚328天。柏林墙的开放并没有统一德国。民主德国作为单独国家的终结是更晚的日期，而联邦德国是延续下来的国家。前民主德国一些人所持的“被吞并”之感，是关于那段政治的争论，而不是另一个与之竞争的日期。
:::
:::

:::example 两个圣诞节 {#ex-christmas}
1989年12月25日与1991年12月25日很容易混淆，1991年12月26日又很容易被遗漏。请区分这三个日期，并给出从第一个到第二个的日期差。
:::solution
1989年12月25日，齐奥塞斯库被处决。这是罗马尼亚一位独裁者的终结，属于[[#thm-sequence]]所说的序列，而不是苏联的终结。1991年12月25日，戈尔巴乔夫辞职。1991年12月26日，最高苏维埃正式解散苏联。辞职与解体相隔一天，却不是同一项行为，这正是[[#def-dissolve]]的内容。从1989年12月25日到1991年12月25日是两年。这段跨度中没有2月29日，所以日期差是2乘365，即730天。相同的日历日子是记忆的陷阱，三项行为分别是处决、辞职与解体。
:::
:::

## 这十年里的另一场战争

南斯拉夫并不是苏联解体迟来的翻版，那些战争也不是预先注定的命运。1991年6月斯洛文尼亚的十日战争，是旧联邦边缘的一场短暂战争，与苏联的最后一个夏天处在同一时段，却不是同一种政治。克罗地亚战争始于1991年，并不是换了名称的十日战争。波斯尼亚战争从1992年4月算起。我们不为这个4月编造具体日期。从1992年4月到1995年4月是三年，代顿协议于1995年12月14日签署，晚于第三个4月，所以有日期可考的这场战争长于三年；又因为签署仍在1995年之内，它短于从1992年4月起算的四年。这已是一个没有具体日期的4月所能允许的精确程度。1995年11月的草签不是12月14日的签署：同一季节，不同的行为。只经草签的和平，还不是年表视为已签署的和平。

1995年7月的斯雷布雷尼察事件，是波斯尼亚塞族武装对波斯尼亚穆斯林的屠杀，发生在波斯尼亚战争期间、代顿协议签署之前。国际法庭后来认定这场屠杀构成种族灭绝。我们不为这些判决标注日期，因为这些日子不在这份年表中；我们也不给出死亡总数，不描述屠杀方式。指明罪行、月份与法律认定而不给出数字，是记录所设定的限度。同样的限度也适用于整个波斯尼亚战争：不给出死亡总数。没有数字并不暗示这场战争规模很小，也不允许从报纸上借用一个数字。这是本图谱的规则。

这就是反驳“历史终结”的完整案例。设想一篇编造的报道，日期是柏林墙开放的次日清晨。它可以知道1989年11月9日，却还不可能知道1990年10月3日，不可能知道1991年12月25日的辞职，也不可能知道1995年7月的屠杀或1995年12月14日的签署。如果某种哲学告诉你，这篇报道已经包含了意识形态冲突的终结，那就是要求它看穿整整十年。[[#thm-union]]就是对此的拒绝。1989年有一个著名的论点，我们只转述而不引用：它把自由民主视为意识形态斗争的终点。这一转述对该论点或许公允，但该论点对这十年并不公允。南斯拉夫的历次战争正是这十年之中的反证，而不是在论断完成之后再补上去的辩解。

1975年8月1日的《赫尔辛基最后文件》（Helsinki Final Act）有时被拿来充当1989年的原因，因为持不同政见者曾援用其中关于权利的措辞。这份文件是真实的，但它不是1989年11月9日的充分原因。约束不是一个夜晚。对戈尔巴乔夫也应同样谨慎：把前奏纳入叙述，但不要让它变成这一年。1986年的《单一欧洲法令》（Single European Act）与1979年的直接选举，属于通往马斯特里赫特（Maastricht）的道路，在[[postwar/union]]中讲授，它们不是柏林墙的意义所在。

:::example 一篇编造的报道 {#ex-dispatch}
下面这句话为示例而虚构。它不是史料。在虚构中，它的日期是1989年11月10日。“昨夜历史终结了，德国问题解决了，苏联也从地图上消失了。”这个虚构的日期能看到什么？又被禁止知道什么？
:::solution
1989年11月10日，柏林墙已经开放了一天。圆桌会议、匈牙利的5月与天鹅绒革命，已经发生在这一年或这一年的11月。齐奥塞斯库尚未倒台，那是12月的事，处决则在1989年12月25日。德国统一在1990年10月3日，比11月9日晚328天，所以按[[#ex-unify]]中的计算，“德国问题解决了”说得太早。苏联在1991年12月25日的辞职之后，于1991年12月26日正式解体。斯洛文尼亚的十日战争在1991年6月，克罗地亚战争始于1991年，波斯尼亚战争则持续到1995年12月14日的签署，其间有1995年7月的斯雷布雷尼察事件，这里不给出死亡总数。这篇编造的报道只知道一次开放。仅凭它所标注的日期，它就无从知道其余的一切。要使它升格为证据，就需要更晚的史料，而编造的句子没有任何史料。
:::
:::

- [x] 1991年12月26日，最高苏维埃解散苏联之时。
:::solution
[[#def-dissolve]]把这四个日期区分开来。柏林墙的开放是1989年中的一个事件。处决是罗马尼亚的事。辞职是解体的前一天，而不是解体。正式行为在1991年12月26日。南斯拉夫的历次战争，则是[[#thm-union]]同时拒绝把1989年称为历史终结的理由。
:::
:::

:::warning 历史的终结
本章要阻止的神话是：1989年终结了历史，而且通常是借柏林的一个夜晚终结的。那个夜晚是真实的：柏林墙于11月9日开放。终结却不是。波兰、匈牙利、捷克斯洛伐克与罗马尼亚在这一序列中各有位置。德国于1990年10月3日统一，而不是在那个夜晚。苏联于1991年12月26日解体，在一次辞职的次日，距一次与它同一日历日子、此外毫无共同之处的处决两年。南斯拉夫的历次战争贯穿同一个十年，直到1995年12月14日的签署。第二个神话较为隐蔽，代价却同样高昂：它把1989年12月25日与1991年12月25日当作同一个圣诞节。两者相隔730天，是不同的行为。
:::

:::history
1989年11月9日，柏林墙开放。这是那一年中的一个事件，那一年还包括波兰圆桌会议以及齐奥塞斯库的倒台，他于1989年12月25日被处决。柏林墙的开放不是苏联的正式终结，后者在1991年12月26日，即戈尔巴乔夫辞职的次日。
:::

窗口为0时，每一年都只是一个数据点，1989年就这样变成了“柏林墙”，1991年也变成了单一的终结。团结工会在1980年，戈尔巴乔夫在1985年，这些前奏与1995年的代顿处在同一条线上。图示止于一个窗口，而不是止于一个结果。1995年是一次签署，而不是证明柏林墙之后的十年是和平的。斯雷布雷尼察事件就在同一年的7月，却没有画出来。你必须把它说出来，而且必须在不附死亡总数的情况下说出来。

## 通向何处

苏联解体数周之后，于1992年2月7日签署的那项条约，是[[postwar/union]]的开端：马斯特里赫特、欧元（euro）、历次扩大、一次退出，以及一场截至2026年尚未结束的全面入侵。1989年的任何事情都没有合上这一页。本章只是提到其开放的柏林墙，其1961年8月13日的封闭在[[postwar/decolonisation-and-1968]]中标注日期。“历史的终结”这类标签如何掩盖论断，前奏为何不足以充当充分原因，见[[sources/argument]]。统一使两个德意志国家在制度上归于一，而这两个国家的建立见[[postwar/division]]。

:::summary
- 1980年8月的团结工会与格但斯克协议，以及1985年3月的戈尔巴乔夫，是前奏，不属于1989年这一年。
- 1989年是一个序列：圆桌会议，5月匈牙利开放边境，11月9日柏林墙开放，11月的天鹅绒革命，12月齐奥塞斯库倒台，以及他于12月25日被处决。
- 柏林墙的开放不是德国统一。德国统一在1990年10月3日，晚328天。联邦德国延续下来。
- 1991年8月19日至21日，一场政变失败。别洛韦日协议在12月8日。戈尔巴乔夫于1991年12月25日辞职。苏联于1991年12月26日正式解体。
- 1989年12月25日与1991年12月25日相隔730天，分别是处决与辞职，而不是同一个圣诞节。
- 斯洛文尼亚的十日战争在1991年6月。克罗地亚战争始于1991年。波斯尼亚战争从1992年4月持续到1995年12月14日代顿协议签署。
- 斯雷布雷尼察事件在1995年7月，这场屠杀后来被法庭认定为种族灭绝。对它和波斯尼亚战争都不给出死亡总数。
- 1989年不是历史的终结，这十年间的历次战争就是证据。
:::

:::exercise 解体的那一天 {#exr-twenty-six level=1 check="26"}
最高苏维埃于1991年12月的哪一天正式解散苏联？（请输入日期中的“日”。）

正式解体在1991年12月26日。戈尔巴乔夫于前一天，即1991年12月25日辞职。齐奥塞斯库于1989年12月25日被处决，那是另一年。[[#def-dissolve]]把辞职与解体区分开来。

德国在哪一年统一？（请输入年份。）
:::solution
德国统一在1990年10月3日。柏林墙于1989年开放，苏联于1991年解体。统一的年份是1990年。

:::exercise 从协议到辞职 {#exr-seventeen level=2 check="17"}
求从1991年12月8日到1991年12月25日的日期差。（请输入天数。）
:::solution
两个日期都在1991年12月。日期差是25减8，即17天。12月26日的解体比辞职晚一天，所以比协议晚18天，但本题只问到辞职为止。8月19日至21日的政变在当年更早，不在这一计算之内。

:::exercise 为这一年排序 {#exr-order level=2}
按年表所支持的顺序写出1989年的序列。标出哪些条目有具体日期，哪些只有月份，哪些只有年份。不要把前奏挪进这一年。
:::solution
前奏留在外面：1980年8月与1985年3月。1989年之内的顺序是：波兰圆桌会议；5月，匈牙利开始开放边境；11月9日，柏林墙开放；11月，天鹅绒革命；12月，齐奥塞斯库倒台；12月25日，他被处决。圆桌会议只有年份，没有具体日期。匈牙利只有5月，没有具体日期。天鹅绒革命只有11月，没有具体日期。齐奥塞斯库倒台在12月，除了处决的12月25日之外，没有单独的日子。柏林墙的开放有具体日期。不要编造缺失的日子。[[#thm-sequence]]正是这份清单不能只剩“11月9日”的原因。
:::
:::

:::exercise 草签不等于签署 {#exr-dayton level=2}
波斯尼亚战争以代顿协议为终点。请区分草签与签署，把斯雷布雷尼察事件与两者对照，并说明本课不会给出哪些数量。
:::solution
这场战争从1992年4月算起。代顿协议于1995年11月草签，1995年12月14日签署。草签与签署在同一季节，却不是同一项行为。斯雷布雷尼察事件发生在1995年7月，早于两者，是战争期间波斯尼亚塞族武装对波斯尼亚穆斯林的屠杀。法庭后来认定它构成种族灭绝。本课既不给出这场屠杀的死亡总数，也不给出整场战争的死亡总数，而且不描述屠杀方式。这次签署不是1989年11月9日，也不是附加在柏林墙上的圆满结局。
:::
:::

:::exercise 知道得太多的报道 {#exr-dispatch level=3}
下面这句话为示例而虚构。它不是史料。在虚构中，它标注的日期是1989年11月10日。“历史终结了，德国统一了，苏联消失了。”请只用这个日期之后的日期，指出这句话还不可能知道什么。那天早晨的真实史料要怎样才能说出其中任何一点？
:::hint
这个日期是1989年11月9日的次日。统一、辞职、解体与南斯拉夫的历次战争都在更晚。[[#thm-union]]就是检验标准。真实的日记可以记录情绪，却不能记录尚未发生的日期。
:::
:::solution
1989年11月10日，柏林墙已经开放了一天。德国统一在1990年10月3日。戈尔巴乔夫于1991年12月25日辞职，苏联于1991年12月26日正式解体。斯洛文尼亚的十日战争在1991年6月，克罗地亚战争始于1991年，波斯尼亚战争则持续到1995年12月14日的签署，其间有1995年7月的斯雷布雷尼察事件，这里不给出死亡总数。对一句标注为1989年11月10日的话来说，这些事实都无从得知。那天早晨一封真实的信件，可以记录狂喜、恐惧或预言，但预言不是对1990年10月3日或1991年12月26日的知识。要把这些后来的事实当作事实说出来，史料本身必须晚于它们。这句编造的话根本不是史料。
:::
:::

:::exercise 同一日期的两种用途 {#exr-trap level=3}
解释只记“12月25日”而不记年份的陷阱。给出你必须区分的两个12月25日之间的日期差，说明每一项行为是什么，以及12月26日又添加了什么。什么能够推翻你的区分？
:::hint
一个12月25日在1989年，另一个在1991年。如果其间没有闰日，日期差就是730天。[[#def-dissolve]]不允许用辞职代替解体。挡住“历史终结”之说的是历次战争，而不是这道算术。
:::
:::solution
1989年12月25日，齐奥塞斯库被处决。1991年12月25日，戈尔巴乔夫辞职。从前者到后者是两年，其间没有2月29日，所以日期差是730天。两者只是同一个日历日子，并不是同一项行为：一个是罗马尼亚的处决，一个是莫斯科的辞职。1991年12月26日，最高苏维埃正式解散苏联，这比辞职晚一天，而不是辞职本身。能够推翻这一区分的，是证明处决与辞职是同一项行为，或者证明苏联于1989年12月25日正式解体。年表对两者都不支持。从1991年6月一直持续到1995年12月14日签署的南斯拉夫历次战争，是不把任何一个圣诞节当作历史终结的又一个理由。
:::
:::
