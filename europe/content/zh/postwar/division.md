投降之后的欧洲是如何分裂的？凭的是哪些日期？

德国的投降于1945年5月7日在兰斯（Reims）签署，1945年5月8日在卡尔斯霍斯特（Karlshorst）签署。苏联因为时差而把5月9日作为投降的日子。[[wars/second-world-war]]同时保留5月8日与5月9日，而不是把其中的一个纠正到不存在。这些年历事实终结了一场战争。它们没有创建两个共和国，也没有签署一项同盟。如果你把1945年5月当作“分裂”，你就略过了分裂实际上唯一能够被核对的那些日期。

可以被核对的是一份短清单。波茨坦会议（Potsdam）在1945年7月与8月开会。1947年3月12日，一场在华盛顿发表的、后来被称为杜鲁门主义（Truman Doctrine）的演说，为美国的支持提出了一个框架。1947年6月5日，乔治·马歇尔（George Marshall）在哈佛发表演说，为复兴提供援助。欧洲复兴计划（European Recovery Programme）是1948年的一个计划，不是演说中的一个句子。从1948年6月24日到1949年5月12日，柏林的西占分区处于封锁之下。在1949年之内跟着三个更晚的行为，而它们不是同一个行为：4月4日的《北大西洋公约》（North Atlantic Treaty），5月23日的联邦共和国《基本法》（Basic Law），以及10月7日的德意志民主共和国（German Democratic Republic）的建立。本课把这些日期保持在那个顺序里。一张只画着一条线的地图做不到这一点。

我们不会把这段故事讲成一场有一方无辜的道德对决。两套军事体系都胁迫过人。两者都讲述着一个把对方说成全部解释的故事。美国的权力是真实的，而它不是欧洲之选择的一份充足的历史。苏联的权力是真实的，而它不是一种德国人、法国人、英国人以及其他国家的政府只能袖手旁观的命运。我们能够捍卫的这条论断比一份判决更窄。分裂是一组有着日期的制度。它不只是一条线，也不只是一个美国的决定。

## 占领还不是一部宪法

:::definition 占领 {#def-occupation}
**占领**在这里指的是胜利者的军队与行政机构对一个战败国家的管理。它是关于谁在发号施令、征税与治安的一个事实。它还不是一部新共和国的宪法，也还不是胜利者之间的一项战时同盟。
:::

雅尔塔（Yalta）在1945年2月，是一场战时会议。波茨坦在1945年7月与8月开会，那是在投降之后。两者都是胜利者的会议。两者都不是《基本法》——《基本法》定日为1949年5月23日——也不是德意志民主共和国的建立，后者定日为1949年10月7日。如果你减去年份标签，1949减1945是4。那个4是标签之差。它不是一个周年纪念。这份年表没有为波茨坦给出一个确定的日子，只有7月至8月这段跨度，所以你无法诚实地从“波茨坦”数天数到5月23日。你可以说出更有用的东西。一场1945年夏天的会议可以约束德国政治家后来能够做什么。一种约束不是一部法条。法条有自己的日子。

要紧的那个地理平平常常，而且容易被抹糊。德国被分区占领。处在苏联区之内的柏林，本身又被分为若干分区。环绕一个区的线与环绕一个分区的线不是同一条线。对西占分区的封锁是对进入一座城市的一种使用。它本身不是任何一部宪法的起草。我们不为那些区发明一个议定书的日子。年表锁定了雅尔塔、波茨坦与封锁，我们停在这些上面。

另一个法律日期落在同几个月之内，不得被征用为分裂的同义词。1948年12月9日，联合国大会通过《防止及惩治灭绝种族罪公约》。种族灭绝这个词已经出现在拉斐尔·莱姆金（Raphael Lemkin）1944年的书里。约六百万犹太人遭灭绝这件事是[[wars/genocide]]的题目，不是本课的题目。公约是一份关于一项罪行的法律文本。封锁——从1948年6月24日到1949年5月12日——是对公路与铁路的一次政治使用。它们在时间上重叠。它们不解释彼此。把两者都折进“1948年，新秩序”的读者已经把两者都弄丢了。

作为对被占领社会的一次道德分拣，占领同样失灵。合作与抵抗都曾经是真实的，有时在同一个人的一生里，[[wars/second-world-war]]就坚持过这一点，而事情的后续没有变成一个单一的民族性格。非纳粹化发生了，职业上的延续也发生了。本图谱对两者都没有一个确定的份额，所以我们不发明一个百分比。一个数字的缺席是关于我们可以说出什么的限度。它不是一个暗示，叫你去猜。

## 演说是语境

:::definition 语境 {#def-context}
**语境**在这里指的是一种有日期的事实：它属于解释之内，却仍然不足以构成解释。一场演说可以改变各国政府认为可能的事情。它不能替代那些政府后来签署或拒绝的诸条约与诸宪法。
:::

1947年3月12日，杜鲁门主义演说把美国的支持框定为对处于压力之下——至少是被如此描述——的各国政府的帮助。希腊与土耳其是通常被系在那场演说上的两个案例。我们在转述一项政策，不是在引用一篇咨文。1947年6月5日，马歇尔在哈佛的演说提出：如果欧洲各国政府组织起复兴，美国就提供援助。欧洲复兴计划是1948年的事。在哈佛演说与那个计划之间，有一段欧洲各部委回应、讨价还价、并且在某些情况下拒绝的间隔。把演说说成语境，全部意思就在那段间隔里。

:::theorem 演说与一个计划不是一段充足的历史 {#thm-context}
1947年3月12日的杜鲁门主义演说、1947年6月5日马歇尔的演说与1948年的欧洲复兴计划，都属于对分裂的任何诚实叙述，而它们不是一段关于欧洲之选择的充足历史。
:::
:::proof
把包括它们在内的证据就是年表本身。两场演说与一个计划坐在波茨坦与封锁之间，而各国政府必须回应一个援助的提议。反对充足性的证据是那些演说并不包含的行为清单。《北大西洋公约》在1949年4月4日由不是德国的国家签署。《基本法》是一部定日为1949年5月23日的德国宪法文本。德意志民主共和国在1949年10月7日、在苏联占领之下建立。这些都不是1947年发表的一场演说里的一段。

会构成对这条论断的反证的，是表明《基本法》、民主德国的建立与《北大西洋公约》其实是美国的法条，没有欧洲的作者，也没有各自的日期。记录不是那样说的。同样会构成反证的，是表明那些演说无关紧要，比如表明没有任何政府在其后改过方向，而复兴计划从未运作过。那个计划定年为1948年，所以无关紧要也说不通。这条论断是中间那个窄的。把演说包括进来。不要停在那里。
:::

这个反方论证值得以全强度说出来。美国军队还在欧洲。美国的钱，无论那个数目是多少，大到拒绝它是一次战略选择，而接受它也是一次战略选择。本课不给出数目，因为年表没有给出，而一个假的数字只会让那个权力显得比我们使用的这些史料更精确。一个没有数字的权力仍然是权力。联邦共和国后来的繁荣不是一个日期，也不是哈佛的一场演说创建了一部德国宪法的证明。苏联的权力是同一个错误的镜像。处在莫斯科掌握之中的各国政府没有加入复兴计划。那次拒绝是政治的，而且有武力在背后支撑。它仍然没有写出《基本法》——《基本法》不是一部苏联文本——它也不等同于民主德国的建立，后者有自己的日子。

从1947年3月12日到6月5日是85天。3月有31天，所以3月12日到6月12日是31加30加31，即92天，而6月5日早7天，所以92减7是85。同一个季节里的两场演说很容易被粘成一个“美国的决定”。这个计数把它们分开，而那个计划的年份——1948年——把那个制度与两场演说都分开。

:::quiz
哪一个说法与演说和复兴计划的日期相符？
- [ ] 欧洲复兴计划就是马歇尔在1947年6月5日宣读的那个文本。
- [x] 那个计划是1948年的事，而1947年的那两场演说对于欧洲之选择来说是语境，不是充足的历史。
- [ ] 杜鲁门主义演说就是联邦共和国的《基本法》。
- [ ] 1945年7月与8月的波茨坦与哈佛演说是同一个行为。
:::solution
马歇尔的演说在1947年6月5日。欧洲复兴计划是1948年的一个计划。[[#thm-context]]把两者都包括进来，也把《基本法》包括进来，却仍然称那些演说不足，因为诸宪法与那个同盟有更晚的日期与别的作者。波茨坦是一场1945年的会议，不是一场1947年的演说。
:::
:::

:::example 年份标签与一场夏天的会议 {#ex-labels}
波茨坦定年为1945年7月至8月。《基本法》定年为1949年5月23日。有人说“宪法在波茨坦之后四年到来”。那个4是什么，又不是什么？
:::solution
减去年份数字：1949减1945是4。那是标签之差，而波茨坦的定日只支持得起这一道减法。那场会议没有确定的日子，只有7月至8月，所以从波茨坦到5月23日不存在诚实的天数计算。从1945年8月起的4年会落在1949年8月，那在1949年5月23日之后。所以《基本法》早于那场会议闭幕的四年周年。“四年之后”那句话是一个标签。它不是一段已经过去的时间。
:::
:::

## 封锁是一只时钟

柏林封锁从1948年6月24日延续到1949年5月12日。进入西占分区的陆路通道被关闭了。在那段间隔里，各分区靠空运获得补给。我们不给出吨位，也不给出飞行次数。年表没有给出，而一个英雄主义的总数不是那条论断。论断是这两天在其他日子之中的位置。

德国货币的一场纷争属于1948年，与复兴计划和封锁的开始同一年。我们不为一个货币法令添加一个法令日。年表没有列出这样一个法令日。它列出的是封锁的两个端点。一场关于钱的分歧可以解释通道为什么被关闭。它不能被拿来替换关闭的日期，它也不是《基本法》。

把封锁对着1949年来读，而不是对着一个传说来读。《北大西洋公约》于1949年4月4日签署，而封锁仍在生效。从4月4日到5月12日是38天。封锁在5月12日结束。《基本法》定日为5月23日，即11天之后。德意志民主共和国在10月7日建立，即在5月23日之后137天。所以封锁的结束坐在诸政治行为的序列中间。它不是最后一个行为，也不是第一个。任何说“空运拯救了城市，于是分裂被解决了”的人，都把时钟早停了11天，而且根本没有去看十月。

:::example 封锁的长度 {#ex-blockade}
求从1948年6月24日到1949年5月12日的日期差。使用日期之差，不要把两个端点都算进去。
:::solution
从1948年6月24日到1949年6月24日是365天。1948年的闰日落在2月，在6月24日之前，而1949年不是闰年，所以这段跨度里的那一年不含2月29日。从5月12日往回上到6月24日是43天：5月有31天，所以5月12日到6月12日是31天，而6月12日到6月24日是12天。于是365减43是322。如果把两个端点都算进去会是323。我们使用322，也就是必须加在1948年6月24日之上才能达到1949年5月12日的天数。
:::
:::

:::example 纸面上相隔一年的两个日期 {#ex-side}
把1947年6月5日放在1948年6月24日旁边。日期差是多少，而你为什么不可以把它们称为一个决定？
:::solution
从1947年6月5日到1948年6月5日是366天，因为1948年2月29日落在那段跨度之内。从1948年6月5日到1948年6月24日是19天。差是366加19，即385天。一个日期是一场提供援助的演说。另一个是对柏林西占分区的一次封锁的开始。它们既不共享一座城市，也不共享一种行为的种类。这385天就是[[#def-context]]坚持要守住的那段间隔。
:::
:::

## 三个行为，不是一条线

:::definition 分裂 {#def-division}
**分裂**在本课指的是那组制度：它们在占领、一个复兴计划与一次封锁之上，给了欧洲两个德意志国家与一个有着1949年之日期的战时同盟。它不意味着在地图上被画了一次的单独一条线，也不意味着一种被称为冷战的情绪。
:::

冷战（Cold War）是一个标签。像[[sources/argument]]里的其他标签一样，它打包一个论断，而且常常把它藏起来。用得好时，它命名的是武装同盟之间的一场对抗，带着附庸国家、间谍，以及关于自由的两种说法。用得坏时，它变成一场道德对决：一方是无辜的，另一方是唯一的主体。我们将用日期来代替那场对决。在标签与日期不一致的地方，日期获胜。

:::theorem 1949年的三个日期，不是一条线 {#thm-three}
能够对1949年作出日期确定的那个分裂是三个行为：4月4日的《北大西洋公约》、5月23日的《基本法》、以及10月7日的德意志民主共和国的建立。它不是在地图上被画了一次的单独一条线，也不是一个仅仅属于美国的决定。
:::
:::proof
证据是那些日子的顺序。4月4日，两个建国日期一个都还没有到，所以两个德意志国家都没有在那一天签署那个条约。那个同盟不是任何一部宪法的一个条款。5月23日，《基本法》为联邦共和国定日。10月7日，第二个国家被建立。从4月4日到5月23日是49天。从5月23日到10月7日是137天。单独一条线不可能先是49天长，然后是137天长。

那张地图并非空无，而论证应当这样说。区界与分区界约束过移动。封锁表明进入是可以被关断的。那张地图所不包含的，是一个《基本法》的作者、一份回应马歇尔提议的各国政府的名录，或者四月、五月与十月之间的区分。会构成对这条论断的反证的，是一件单独的文件，定日于一天，既创建了两个国家又签署了那个同盟，而且诸史料之中没有欧洲文本。这份年表里没有这样一件文件。同样会构成反证的，是这样的证据：欧洲各国政府既没有起草也没有拒绝任何东西，而美国的各个官署把《基本法》与民主德国的建国法当作纯粹美国的法条公布出去。那两个日期的记录方式都不是那样。
:::

康拉德·阿登纳（Konrad Adenauer）是这门课程系于1949年的政治人物。他领导了早期的联邦共和国。我们不替他发明一场演说，我们也不假装一位总理就是宪法。《基本法》是一个议会共和国的文本。民主德国是一个另外的国家，在苏联占领之下建立，并由一个垄断政权的党统治。它们不是镜像，两者都不无辜。联邦共和国把旧行政机构的碎片带进了新机构，而它也建立了选举与一个宪法法院。民主德国则提供了一个竞争的宣称，称它自己才是德国，带着苏联军队与一个党的垄断。同时把两种描述都拿住，才是那场道德对决的替代物。

有一个反方论证说这是在吹毛求疵，因为每个人都能在地图上看见那条线，而那条线就是分裂。回答是那只封锁的时钟。如果那条线就是全部故事，那么1949年5月12日结束封锁就会终结分裂。它没有。11天之后，《基本法》定日。十月，第二个国家被建立。另一个反方论证说，只有美国的政策重要，所以欧洲的日期是装饰。那么苏联政府拒绝复兴计划、德国人起草《基本法》、以及民主德国单独的建国日，就都是无法解释的多余之物。它们就在记录里。装饰不会创建一个国家。

同一只时钟挡住了第三种捷径。人们有时谈起柏林墙，仿佛它就是那个分裂。那堵墙是对分区界的一次更晚的关闭，定日为1961年8月13日，在[[postwar/decolonisation-and-1968]]里教授。它在1989年11月9日的开放在[[postwar/from-1989]]里教授。1948年和1949年的封锁不是这两个日期中的任何一个。一个符号被要求去做三个不同的决定的工作。

:::example 一个编造的编年句子 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1949年，美国瓜分了德国，而欧洲人接受了那条线。”把它对着那些日期来读。在它算作史料之前，你会需要什么？
:::solution
这句话把三个行为塌缩为一个主体与一个客体。1949年4月4日，《北大西洋公约》签署，而两个德国的建国日期一个都还没有到。5月23日，《基本法》为一部德国宪法定日，不是一部美国法条。10月7日，民主德国建立。“那条线”压根没有一个日子。在这句话能够算作史料之前，你会需要史料：一份《基本法》文本、一份谁签署那个条约的记录、一份民主德国之建立的记录，以及某份“欧洲”接受一条线的文件。即使如此，这句话仍然会越界宣称，因为[[#thm-three]]讲的是三个行为。一个编造的句子命名的是情绪。它不会因为听起来像编年史就变成一份史料。
:::
:::

:::quiz
在1949年4月4日，下面哪一项已经为真？
- [ ] 《基本法》已经定日，所以联邦共和国在那一天签署了《北大西洋公约》。
- [ ] 德意志民主共和国已经建立，而封锁已经结束好几个月了。
- [x] 两个德国的建国日期一个都没有到，而柏林封锁仍在生效。
- [ ] 波茨坦在那同年的7月与8月开会。
:::solution
《基本法》在1949年5月23日，在4月4日之后。民主德国在1949年10月7日建立。封锁延续到1949年5月12日，所以在4月4日仍在生效。波茨坦是1945年7月至8月，不是1949年。那个条约、那两部宪法与封锁是四个不同的事实，这正是[[#thm-three]]要求你守住的东西。
:::
:::

:::warning 道德对决
一个常见的图景把1945年之后的那些年变成一场无辜者的对决：一个阵营是自由，另一个是暴政，而欧洲人是观众。这个图景在日期上与在行为上都失败。日期同样属于欧洲，不只属于美国与苏联：一部《基本法》、第二个德意志国家、对一个援助提议的回应、一项在两个德意志国家存在之前就已签署的条约。行为也同样无法分拣进一个无辜方。下一章的日期已经显示了东方阵营内部的胁迫，包括1953年6月17日的起义。西方诸国家仍然拥有诸帝国，而[[postwar/decolonisation-and-1968]]对它们进行日期确定，而不是辩解。一场对决需要一个干净的英雄。这份年表没有提供一个。
:::

:::history
1949年4月4日，《北大西洋公约》签署。联邦共和国的《基本法》定日为1949年5月23日，德意志民主共和国建于1949年10月7日。康拉德·阿登纳是这门课程系于那个有两个共和国与一个同盟之年份的人物。这三个日期不是一个行为，而它们之中没有一个就是1945年7月与8月的那场波茨坦会议。
:::

这个图形是对本课的一场检验，不是它的替代物。在窗口0处，1949年是一个圆点。这就是一条年表在若干行为共享一个年份时误导人的方式。四月、五月与十月仍然必须用语言说出来。1945年、1947年与1948年是不同种类的圆点：一场会议、两场演说、一次封锁与一个计划。如果你只凭那些圆点向别人讲述这个故事，你就已经犯了[[#def-division]]所命名的那个错误。

## 通向何处

在这里被定日的这些制度，是[[postwar/welfare-and-treaties]]之下的地面。福利不是单一的一种欧洲安排，而巴黎与罗马的诸条约是成员名单，不是这块大陆的名称。1953年6月17日的起义与1956年的匈牙利起义坐在那更晚的一页上，因为一个建国日不是同意。投降的那些日期留在[[wars/second-world-war]]里，而1948年12月9日的《防止及惩治灭绝种族罪公约》留在[[wars/genocide]]旁边，作为一项法律事实，不是封锁的同义词。一个像冷战这样的标签如何藏起一个论断，是[[sources/argument]]的方法。

:::summary
- 1945年5月7日、8日与9日的投降终结了一场战争。它们没有创建任何一个德意志国家。
- 波茨坦在1945年7月与8月开会。1949减1945给出的是标签之差，不是一个周年。
- 杜鲁门演说在1947年3月12日，马歇尔的演说在1947年6月5日，而欧洲复兴计划是1948年。它们是语境，不是充足的历史。
- 柏林封锁从1948年6月24日延续到1949年5月12日，日期差为322天。结束它并没有结束分裂。
- 1949年的顺序是4月4日，然后5月23日，然后10月7日：同盟、《基本法》、德意志民主共和国。
- 在4月4日，两个德国的建国日期一个都没有到，而封锁仍在生效。
- 分裂是一组制度。它不只是地图上的一条线，也不只是一个美国的决定。
- 一场有一方无辜的道德对决，与日期和行为都不相符。
:::

## 习题

:::exercise 十月的那一天 {#exr-october level=1 check="7"}
德意志民主共和国在1949年10月的哪一天建立？（请输入日子。）
:::solution
年表把建立定日为1949年10月7日。《基本法》在5月23日，不是一个十月的日子，而《北大西洋公约》在4月4日。

7
:::

:::exercise 封锁之后 {#exr-eleven level=1 check="11"}
柏林封锁结束之后多少天，《基本法》定日？使用日期之差。（请输入天数。）
:::solution
封锁在1949年5月12日结束。《基本法》定日为1949年5月23日。差是23减12，即11天。这个计数不需要十月。

11
:::

:::exercise 会议的年份 {#exr-potsdam level=1 check="1945"}
波茨坦会议在哪一年开会？（请输入年份。）
:::solution
波茨坦在1945年7月与8月开会。雅尔塔也在1945年2月，但问题问的是波茨坦。《基本法》是1949年，不是那次会议。

1945
:::
:::

:::exercise 从条约到《基本法》 {#exr-forty-nine level=2 check="49"}
求从1949年4月4日到1949年5月23日的日期差。（请输入天数。）
:::solution
4月有30天，所以4月4日到5月4日是30天。从5月4日到5月23日是19天。总和是30加19，即49天。这就是[[#thm-three]]用来隔开同盟与《基本法》的那段间隔。它不是从《基本法》到10月7日的那段间隔，那是一个更晚的练习，不是这个计数。

49
:::
:::

:::exercise 演说为什么不够 {#exr-sufficient level=2}
用一小段话说明[[#thm-context]]包括什么，以及什么会构成对它的反证。使用演说、那个计划、《基本法》与民主德国之建立的日期。
:::solution
那条论断包括1947年3月12日的杜鲁门演说、1947年6月5日马歇尔的演说与1948年的欧洲复兴计划，并且否认它们就足够。一段充足的历史仍然必须够得着1949年5月23日的《基本法》与1949年10月7日的民主德国的建立，而它们不是那些演说的文本。会构成对这条论断的反证的，是这样的证据：那些建国行为是纯粹美国的法条，没有各自的日期；或者这样的证据：1948年的那个计划从未存在，也没有任何政府回应过那个提议。这两者都不是记录。美国的权力可以被十足地承认，而那些演说仍然是语境。
:::
:::

:::exercise 演说与法条并排 {#exr-beside level=2}
把杜鲁门主义演说与《基本法》并排放置。为各自说出日期与行为的种类，并说出前者无法解释后者的哪一点。
:::solution
杜鲁门主义演说在1947年3月12日。它是一场美国的政策演说，这里以转述的方式把它说成一个对处于压力之下——至少是被如此描述——的各国政府的支持承诺。《基本法》在1949年5月23日。它是联邦共和国的宪法文本。那场演说无法解释《基本法》的日子、它的德国起草，也无法解释为什么第二个德意志国家在更晚的1949年10月7日建立。这两个日期是1947年与1949年。语境不是一部宪法，这正是[[#def-context]]所说的。
:::
:::

:::exercise 又一个编造的句子 {#exr-mood level=3}
下面这句话为示例而虚构。它不是史料。“封锁一结束，德国就重新成为一个国家，因为美国人赢下了那场对决。”这句话在1949年的5月12日、5月23日与10月7日上各错了什么？在它的任何部分能够成为超越一种情绪的东西之前，你会要求什么样的史料？
:::hint
先把那三天排成顺序。然后问一问，“一个国家”与“赢下那场对决”是否有一段你可以不编造就引用的文本。[[#thm-three]]与那条关于道德对决的注意事项就是检验。
:::
:::solution
封锁在1949年5月12日结束。《基本法》定日为5月23日，即11天之后，它开创的是联邦共和国的宪政道路，不是一个把东方包括进来的、恢复了统一的德国。民主德国建于1949年10月7日。结束封锁没有拆除分裂，也没有阻止第二个国家。“美国人赢下了那场对决”就是本课拒绝的那幅道德图景：它命名一个主体，它宣告一场被十月的日期所反驳的胜利，而它没有引用任何人。在它的任何部分能够算作史料之前，你会需要那些文件本身，不是一句被写来显得古老的句子。即使是一份1949年5月的真日记，如果不包含那些行为，也只是一个人的情绪。一个编造的句子什么行为都不包含。
:::
:::

:::exercise 什么会击败三个行为 {#exr-defeat level=3}
假设一位史家宣称[[#thm-three]]是假的。给出两项会构成对它的反证的发现，并说出每一项发现为什么迫使你重写这条论断，而不仅仅是添加一条脚注。
:::hint
那条论证已经点明了各种反证的种类。你的工作是说出每一项会对“三个行为”与“不只是一个美国的决定”这些语做什么。对美国的权力的一次空泛的诉求还不是一项发现。
:::
:::solution
第一，一件单独的定日于一天的文件，创建两个德意志国家、构成那个同盟，并且不具任何德国起草与任何欧洲对复兴计划的拒绝或接受，会使“三个行为”为假。你将不得不以一条关于那一件文件的论断来替换这条论断。各自的日期才使得那个数目成为三。第二，这样的档案证据——《基本法》与民主德国的建立被当作纯粹美国的法条公布出去，没有德国起草，也没有欧洲对复兴计划的拒绝或接受——会使“不只是一个美国的决定”为假。你将不得不丢弃那条论断的这一半。不会迫使重写的，是一句真实的陈述：美国的权力是庞大的。[[#thm-context]]已经把那个权力包括进来，却仍然称它不足。一条脚注可以记录权力。它无法把四月、五月与十月变成一支美国的笔。
:::
:::
