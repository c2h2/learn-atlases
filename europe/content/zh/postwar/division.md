投降之后，欧洲是如何分裂的？依据的是哪些日期？

德国的投降书于1945年5月7日在兰斯（Reims）签署，于1945年5月8日在卡尔斯霍斯特（Karlshorst）签署。由于时差，苏联以5月9日为投降之日。[[wars/second-world-war]]同时保留5月8日与5月9日，而不是把其中一个“纠正”掉。这些历日事实结束了一场战争，却没有建立两个共和国，也没有签订同盟。如果把1945年5月当作“分裂”，就跳过了唯一能够实际核对分裂的那些日期。

能够核对的是一份简短的清单。波茨坦会议（Potsdam）于1945年7月至8月举行。1947年3月12日，后来被称为“杜鲁门主义”（Truman Doctrine）的一篇华盛顿演说，为美国的支持提出了框架。1947年6月5日，乔治·马歇尔（George Marshall）在哈佛发表演说，提出为复兴提供援助。欧洲复兴计划（European Recovery Programme）是1948年的计划，而不是演说中的一句话。从1948年6月24日到1949年5月12日，柏林西占区处于封锁之下。1949年之内又接连发生了三项行为，它们并不是同一项行为：4月4日的《北大西洋公约》（North Atlantic Treaty），5月23日联邦德国的《基本法》（Basic Law），以及10月7日德意志民主共和国（German Democratic Republic）的建立。本课按这一顺序保留这些日期，而一张只画着一条线的地图做不到这一点。

我们不会把这段历史讲成一方无辜的道德对决。两大军事体系都曾胁迫民众，双方都讲述着把对方当作全部解释的故事。美国的权力是真实的，但它不足以构成欧洲各种选择的历史。苏联的权力也是真实的，但它并不是一种德国、法国、英国及其他国家政府只能旁观的命运。我们能够捍卫的论断，比一纸判决更窄：分裂是一组有日期的制度，它不只是一条线，也不只是美国的决定。

## 占领还不是宪法

:::definition 占领 {#def-occupation}
**占领**在这里指战胜国的军队与行政机构对战败国的治理。它关乎谁在发号施令、征税和维持治安。它还不是新共和国的宪法，也还不是战胜国之间的和平时期同盟。
:::

1945年2月的雅尔塔（Yalta）会议是一次战时会议。1945年7月至8月的波茨坦会议则在投降之后举行。两者都是战胜国的会议，但都不是定于1949年5月23日的《基本法》，也都不是定于1949年10月7日的德意志民主共和国的建立。如果把年份标签相减，1949减1945等于4。这个4是标签之差，而不是周年。在这份年表中，波茨坦没有确定的日子，只有7月至8月这一跨度，因此无法诚实地从“波茨坦”数天数到5月23日。但可以说出更有用的东西：1945年夏天的一次会议，可以约束德国政治家后来能够做什么。约束不等于法令，法令有它自己的日子。

要紧的地理事实很平常，却容易被模糊掉。德国被划分为若干占领区。位于苏占区之内的柏林，本身又被划分为若干分区。占领区的边界与分区的边界不是同一条线。封锁西占区，是对进入一座城市之通道的利用，它本身并不是在起草任何一部宪法。我们不为各占领区编造议定书的日期。年表锁定了雅尔塔、波茨坦与封锁，我们就以此为限。

还有一个法律日期落在同一段月份之内，不得被拿来充当分裂的同义词。1948年12月9日，联合国大会通过《防止及惩治灭绝种族罪公约》。“种族灭绝”一词此前已见于拉斐尔·莱姆金（Raphael Lemkin）1944年的著作。约六百万犹太人遇害，是[[wars/genocide]]的主题，而不是本课的主题。公约是关于一项罪行的法律文本；从1948年6月24日持续到1949年5月12日的封锁，则是对公路与铁路的政治利用。两者在时间上重叠，却并不相互解释。把两者都塞进“1948年，新秩序”的读者，两者都弄丢了。

把占领当作对被占领社会的道德分类，同样行不通。正如[[wars/second-world-war]]所坚持的，合作与抵抗都曾真实存在，有时就在同一个人的一生之中，而战后的局面也没有变成某种单一的民族性格。非纳粹化发生了，职业生涯的延续也发生了。本图谱对两者都没有确定的比例，所以我们不编造百分比。没有数字，是对我们能说什么的限制，而不是暗示你去猜。

## 演说是背景

:::definition 背景 {#def-context}
**背景**在这里指一种有日期的事实：它属于解释的一部分，但仍不足以构成解释。一篇演说可以改变各国政府对可能性的判断，却不能代替这些政府后来签署或拒绝的条约与宪法。
:::

1947年3月12日的杜鲁门主义演说，把美国的支持表述为对那些被描述为处于压力之下的政府的援助。通常与这篇演说联系在一起的案例是希腊与土耳其。我们是在转述一项政策，而不是引用一篇讲话。1947年6月5日，马歇尔在哈佛的演说提出：如果欧洲各国政府组织复兴，美国将提供援助。欧洲复兴计划是1948年的事。从哈佛演说到这一计划之间有一段间隔，其间欧洲各国的部委作出回应、讨价还价，有的则予以拒绝。称演说为背景，全部意义就在这段间隔之中。

:::theorem 演说与计划不足以构成历史 {#thm-context}
1947年3月12日的杜鲁门主义演说、1947年6月5日马歇尔的演说以及1948年的欧洲复兴计划，都属于对分裂的任何诚实叙述，但它们不足以构成欧洲各种选择的历史。
:::
:::proof
把它们纳入叙述的证据就是年表本身。两篇演说与一项计划处在波茨坦与封锁之间，各国政府必须对援助提议作出回应。反对“足以构成历史”的证据，则是这些演说所不包含的一系列行为。《北大西洋公约》于1949年4月4日由德国以外的国家签署。《基本法》是定于1949年5月23日的德国宪法文本。德意志民主共和国于1949年10月7日在苏联占领下建立。这些都不是1947年某篇演说中的段落。

能够推翻这一论断的，是证明《基本法》、民主德国的建立与《北大西洋公约》都是美国的法令，既没有欧洲的起草者，也没有各自的日期。记录并非如此。同样能够推翻它的，是证明这些演说无关紧要，例如证明此后没有任何政府改变方针，复兴计划也从未运作。这一计划定于1948年，所以“无关紧要”的说法也站不住。这一论断是居中的窄论断：把演说纳入叙述，但不要止步于此。
:::

反方论证值得以其最有力的形式陈述。美国军队仍驻在欧洲。美国的资金，无论数额多少，都大到拒绝它是一种战略选择，接受它也是一种战略选择。本课不给出数额，因为年表没有给出，虚假的数字只会让这种权力显得比我们所用的史料更精确。没有数字的权力仍然是权力。联邦德国后来的繁荣不是一个日期，也不能证明哈佛的一篇演说缔造了一部德国宪法。苏联的权力则是同一错误的镜像。处于莫斯科势力范围内的各国政府没有加入复兴计划。这一拒绝是政治性的，并有武力作后盾。但它仍然没有写出《基本法》，《基本法》也不是苏联的文本；它也不等同于民主德国的建立，后者有自己的日子。

从1947年3月12日到6月5日是85天。三月有31天，所以3月12日到6月12日是31加30加31，即92天；6月5日比它早7天，92减7得85。同一季节里的两篇演说，很容易被粘成一个“美国的决定”。这一计数把两者分开，而计划所在的年份1948年，又把这项制度与两篇演说都区分开来。

:::quiz
下列哪一种说法与演说及复兴计划的日期相符？
- [ ] 欧洲复兴计划就是马歇尔在1947年6月5日宣读的文本。
- [x] 该计划属于1948年，1947年的两篇演说是欧洲各种选择的背景，而不足以构成其历史。
- [ ] 杜鲁门主义演说就是联邦德国的《基本法》。
- [ ] 1945年7月至8月的波茨坦会议与哈佛演说是同一项行为。
:::solution
马歇尔的演说在1947年6月5日，欧洲复兴计划是1948年的计划。[[#thm-context]]把两者以及《基本法》都纳入叙述，却仍然认为演说并不充分，因为宪法与同盟的日期更晚，起草者也不同。波茨坦是1945年的会议，而不是1947年的演说。
:::
:::

:::example 年份标签与夏季会议 {#ex-labels}
波茨坦会议定于1945年7月至8月，《基本法》定于1949年5月23日。有人说“宪法是在波茨坦会议四年之后出现的”。这个4是什么？又不是什么？
:::solution
把年份数字相减：1949减1945得4。这是标签之差，也是波茨坦会议的定年唯一能支持的减法。会议没有确定的日子，只有7月至8月，所以从波茨坦到5月23日不存在诚实的天数计算。从1945年8月起算四年，会落在1949年8月，晚于1949年5月23日。因此，《基本法》早于会议结束的四周年。“四年之后”这句话只是标签，而不是经过的时间。
:::
:::

## 封锁是一座时钟

柏林封锁从1948年6月24日持续到1949年5月12日。通往西占区的陆路通道被切断，在此期间各分区依靠空运获得补给。我们不给出吨数，也不给出飞行架次。年表没有给出这些数字，而英雄式的总数并不是论证所在。论证在于这两个日子在其他日子之中的位置。

德国的一场货币冲突属于1948年，与复兴计划和封锁的开始在同一年。我们不为某项货币法令添加颁布日期，因为年表没有列出。它列出的是封锁的起止日期。关于货币的争执可以解释通道为何被切断，却不能代替封锁的日期，它也不是《基本法》。

要对照1949年来读封锁，而不是对照某个传说来读。《北大西洋公约》于1949年4月4日签署，当时封锁仍在持续。从4月4日到5月12日是38天。封锁于5月12日结束。《基本法》定于5月23日，即11天之后。德意志民主共和国于10月7日建立，在5月23日之后137天。所以，封锁的结束处在这一系列政治行为的中间，既不是最后一项，也不是第一项。谁要是说“空运拯救了这座城市，分裂问题也就此解决”，就是把时钟提早了十一天停下，而且根本没有去看十月。

:::example 封锁的长度 {#ex-blockade}
求从1948年6月24日到1949年5月12日的日期差。请用两个日期之差，不要把首尾两天都算进去。
:::solution
从1948年6月24日到1949年6月24日是365天。1948年的闰日在二月，早于6月24日，而1949年不是闰年，所以这段一年的跨度中没有2月29日。从5月12日往后到6月24日是43天：五月有31天，所以5月12日到6月12日是31天，6月12日到6月24日是12天。于是365减43得322。如果把首尾两天都算进去，是323天。我们用322，即在1948年6月24日上加多少天才能到达1949年5月12日。
:::
:::

:::example 纸面上相隔一年的两个日期 {#ex-side}
把1947年6月5日与1948年6月24日并排放置。两者的日期差是多少？为什么不能把它们称为同一个决定？
:::solution
从1947年6月5日到1948年6月5日是366天，因为1948年2月29日在这段跨度之内。从1948年6月5日到1948年6月24日是19天。日期差是366加19，即385天。一个日期是提供援助的演说，另一个是对柏林西占区封锁的开始。两者既不属于同一座城市，也不属于同一类行为。这385天，正是[[#def-context]]坚持要保留的那段间隔。
:::
:::

## 三项行为，而不是一条线

:::definition 分裂 {#def-division}
本课所说的**分裂**，是指在占领、复兴计划与封锁的基础上，使欧洲出现两个德意志国家和一个和平时期同盟、并在1949年留下日期的那一组制度。它不是指在地图上一次画定的单独一条线，也不是指一种名叫“冷战”的情绪。
:::

“冷战”（Cold War）是一个标签。与[[sources/argument]]中的其他标签一样，它把一个论断打包起来，而且常常把它藏起来。用得好，它指的是武装同盟之间的对抗，伴随着附庸国、间谍以及关于自由的两种叙事。用得不好，它就变成一场道德对决：一方无辜，另一方是唯一的行动者。我们将用日期代替这场对决。标签与日期不一致时，以日期为准。

:::theorem 1949年的三个日期，而不是一条线 {#thm-three}
可以定于1949年的分裂，是三项行为：4月4日的《北大西洋公约》、5月23日的《基本法》，以及10月7日德意志民主共和国的建立。它不是在地图上一次画定的一条线，也不只是美国的决定。
:::
:::proof
证据是这些日子的顺序。4月4日，两个建国日期都尚未到来，所以两个德意志国家都没有在那天签署这项条约。这一同盟也不是任何一部宪法中的条款。5月23日，《基本法》确立了联邦德国的日期。10月7日，第二个国家建立。从4月4日到5月23日是49天，从5月23日到10月7日是137天。单独一条线不可能先有49天长，再有137天长。

地图并非毫无意义，论证也应当承认这一点。占领区与分区的边界约束着人员的流动，封锁则表明通道可以被切断。地图所不包含的，是《基本法》的起草者、回应马歇尔提议的各国政府名单，以及四月、五月与十月之间的区别。能够推翻这一论断的，是某一份定于同一天的单一文件，它既建立了两个国家，又缔结了同盟，而且史料中没有任何欧洲文本。这份年表中没有这样的文件。同样能够推翻它的，是这样的证据：欧洲各国政府既没有起草也没有拒绝任何东西，美国各机构把《基本法》与民主德国的建国法当作纯粹的美国法令颁布。这两个日期的记录方式都并非如此。
:::

康拉德·阿登纳（Konrad Adenauer）是本课程与1949年联系在一起的政治人物。他领导了早期的联邦德国。我们不为他编造演说，也不假装一位总理就等于宪法。《基本法》是议会制共和国的文本。民主德国则是另一个国家，在苏联占领下建立，实行一党统治。两者并非镜像，也都不无辜。联邦德国把旧行政机构的一些部分带进了新机构，同时也建立了选举制度与宪法法院。民主德国则在苏联驻军与一党垄断之下，提出了自己才代表德国的对立主张。同时把握这两种描述，才是道德对决之外的另一种选择。

有一种反方论证说，这是在吹毛求疵，因为谁都能看见地图上的那条线，那条线就是分裂。回答就是封锁这座时钟。如果那条线就是全部故事，那么1949年5月12日封锁结束，分裂也就该结束了。事实并非如此。十一天后，《基本法》确定了日期；十月，第二个国家建立。另一种反方论证说，只有美国的政策才重要，欧洲的日期只是点缀。那么，苏联政府拒绝复兴计划、德国人起草《基本法》以及民主德国单独的建国日，就都成了无法解释的多余之物。可它们都在记录之中。点缀不会建立一个国家。

同一座时钟还能挡住第三条捷径。人们有时说起柏林墙，仿佛它就是分裂本身。柏林墙是后来对分区边界的封闭，定于1961年8月13日，在[[postwar/decolonisation-and-1968]]中讲授；它在1989年11月9日的开放，在[[postwar/from-1989]]中讲授。1948年至1949年的封锁不是这两个日期中的任何一个。一个符号被要求承担三个不同决定的分量。

:::example 编造的编年句 {#ex-invented}
下面这句话为示例而虚构。它不是史料。“1949年，美国分裂了德国，欧洲人接受了那条线。”请对照日期来读这句话。在它能算作证据之前，你需要什么？
:::solution
这句话把三项行为压缩成了一个行动者和一个对象。1949年4月4日，《北大西洋公约》签署，两个德国的建国日期都尚未到来。5月23日，《基本法》确立了一部德国宪法的日期，而不是一项美国法令。10月7日，民主德国建立。“那条线”则根本没有日子。在这句话能算作证据之前，你需要史料：《基本法》的文本、谁签署了条约的记录、民主德国建立的记录，以及某份“欧洲”接受一条线的文件。即便如此，这句话仍然言过其实，因为[[#thm-three]]讲的是三项行为。编造的句子标示的是一种情绪，并不会因为听起来像编年史就变成史料。
:::
:::

:::quiz
1949年4月4日，下列哪一项已经成立？
- [ ] 《基本法》已经确定日期，所以联邦德国在当天签署了《北大西洋公约》。
- [ ] 德意志民主共和国已经建立，封锁也已结束好几个月了。
- [x] 两个德国的建国日期都尚未到来，柏林封锁仍在持续。
- [ ] 波茨坦会议正于同一年的7月至8月举行。
:::solution
《基本法》在1949年5月23日，晚于4月4日。民主德国于1949年10月7日建立。封锁持续到1949年5月12日，所以4月4日时仍在持续。波茨坦会议是1945年7月至8月，而不是1949年。条约、两部宪法与封锁是四个不同的事实，这正是[[#thm-three]]要求你区分清楚的。
:::
:::

:::warning 道德对决
一种常见的图景把1945年之后的岁月变成一场关于无辜的对决：一方代表自由，另一方代表暴政，欧洲人则是观众。这一图景在日期上和行为上都站不住。日期不只属于美国和苏联，也属于欧洲：一部《基本法》，第二个德意志国家，对援助提议的回应，一项在两个德意志国家都还不存在时就已签署的条约。行为也无法归入一个无辜的阵营。下一章的日期已经显示了东方阵营内部的胁迫，包括1953年6月17日的起义。西方国家仍然拥有帝国，[[postwar/decolonisation-and-1968]]为之标注日期，而不是为之开脱。对决需要一个清白的英雄，而这份年表提供不了。
:::

:::history
1949年4月4日，《北大西洋公约》签署。联邦德国的《基本法》定于1949年5月23日，德意志民主共和国于1949年10月7日建立。康拉德·阿登纳是本课程与这一出现两个共和国和一个同盟的年份联系在一起的人物。这三个日期不是同一项行为，其中任何一个也都不是1945年7月至8月的波茨坦会议。
:::

这张图是对本课的检验，而不是本课的替代品。窗口为0时，1949年只是一个数据点。当几项行为同在一年时，时间轴就是这样误导人的。四月、五月与十月仍然必须用文字说出来。1945年、1947年与1948年是不同类型的数据点：一次会议、两篇演说、一次封锁和一项计划。如果你只凭这些数据点向别人讲述这段历史，你就已经犯了[[#def-division]]所指出的错误。

## 通向何处

这里标注日期的各项制度，是[[postwar/welfare-and-treaties]]的基础。福利并不是单一的欧洲安排，巴黎与罗马的条约是成员名单，而不是这片大陆的名称。1953年6月17日的起义与1956年的匈牙利起义放在后面那一章，因为建国日并不等于同意。投降的日期留在[[wars/second-world-war]]中；1948年12月9日的《防止及惩治灭绝种族罪公约》作为法律事实留在[[wars/genocide]]旁边，而不是封锁的同义词。像“冷战”这样的标签如何藏起一个论断，属于[[sources/argument]]的方法。

:::summary
- 1945年5月7日、8日与9日的投降结束了一场战争，却没有建立任何一个德意志国家。
- 波茨坦会议于1945年7月至8月举行。1949减1945得出的是标签之差，而不是周年。
- 杜鲁门的演说在1947年3月12日，马歇尔的演说在1947年6月5日，欧洲复兴计划在1948年。它们是背景，但不足以构成历史。
- 柏林封锁从1948年6月24日持续到1949年5月12日，日期差为322天。封锁的结束并没有结束分裂。
- 1949年的顺序是4月4日、5月23日、10月7日：同盟、《基本法》、德意志民主共和国。
- 4月4日时，两个德国的建国日期都尚未到来，封锁仍在持续。
- 分裂是一组制度，不只是地图上的一条线，也不只是美国的决定。
- 一方无辜的道德对决，与日期和行为都不相符。
:::

## 习题

:::exercise 十月的那一天 {#exr-october level=1 check="7"}
德意志民主共和国于1949年10月的哪一天建立？（请输入日期中的“日”。）
:::solution
年表把建国日期定于1949年10月7日。《基本法》在5月23日，不在十月；《北大西洋公约》在4月4日。

7
:::

:::exercise 封锁之后 {#exr-eleven level=1 check="11"}
柏林封锁结束多少天后，《基本法》确定了日期？请用两个日期之差。（请输入天数。）
:::solution
封锁于1949年5月12日结束，《基本法》定于1949年5月23日。日期差是23减12，即11天。这一计数用不到十月。

11
:::
:::

:::exercise 会议的年份 {#exr-potsdam level=1 check="1945"}
波茨坦会议在哪一年举行？（请输入年份。）
:::solution
波茨坦会议于1945年7月至8月举行。雅尔塔会议也在1945年，在2月，但问题问的是波茨坦。《基本法》是1949年，而不是这次会议。

1945
:::
:::

:::exercise 从条约到《基本法》 {#exr-forty-nine level=2 check="49"}
求从1949年4月4日到1949年5月23日的日期差。（请输入天数。）
:::solution
四月有30天，所以4月4日到5月4日是30天。从5月4日到5月23日是19天。合计30加19，即49天。这就是[[#thm-three]]用来区分同盟与《基本法》的间隔。它不是从《基本法》到10月7日的间隔，那属于后面的阅读练习，而不是这里的计数。

49
:::
:::

:::exercise 演说为何不够 {#exr-sufficient level=2}
用一小段话说明[[#thm-context]]包括什么，以及什么能够推翻它。请使用演说、计划、《基本法》与民主德国建立的日期。
:::solution
这一论断包括1947年3月12日杜鲁门的演说、1947年6月5日马歇尔的演说以及1948年的欧洲复兴计划，并否认它们已经足够。足以构成历史的叙述，仍然必须写到1949年5月23日的《基本法》与1949年10月7日民主德国的建立，而它们都不是这些演说的文本。能够推翻这一论断的，是证明这些建国行为纯属美国法令、没有各自的日期，或者证明1948年的计划从未存在、也没有任何政府回应过援助提议。两者都不符合记录。即使完全承认美国的权力，演说也仍然只是背景。
:::
:::

:::exercise 演说与法令并置 {#exr-beside level=2}
把杜鲁门主义演说与《基本法》并排放置。分别说出两者的日期与行为类型，并指出前者无法解释后者的一点。
:::solution
杜鲁门主义演说在1947年3月12日。它是美国的政策演说，这里转述为对那些被描述为处于压力之下的政府提供支持的承诺。《基本法》在1949年5月23日，是联邦德国的宪法文本。这篇演说解释不了《基本法》的日子、它由德国人起草，也解释不了为什么第二个德意志国家在更晚的1949年10月7日建立。两个日期分别是1947年与1949年。背景不是宪法，这正是[[#def-context]]所说的。
:::
:::

:::exercise 又一句编造的话 {#exr-mood level=3}
下面这句话为示例而虚构。它不是史料。“封锁一结束，德国就重新成为一个国家，因为美国人赢得了这场对决。”这句话在1949年5月12日、5月23日与10月7日这三个日期上各错在哪里？在其中任何部分能够超出一种情绪之前，你会要求什么样的史料？
:::hint
先把这三天排好顺序。然后问一问，“一个国家”与“赢得了这场对决”是否有一份你无须编造就能引用的文本。[[#thm-three]]与关于道德对决的警示就是检验标准。
:::
:::solution
封锁于1949年5月12日结束。《基本法》定于5月23日，即十一天之后，它开启的是联邦德国的宪政道路，而不是一个包括东部在内、重归统一的德国。民主德国于1949年10月7日建立。封锁的结束既没有消除分裂，也没有阻止第二个国家的出现。“美国人赢得了这场对决”正是本课所拒绝的道德图景：它只认定一个行动者，宣告了一场为十月的日期所反驳的胜利，而且没有引用任何人。在其中任何部分能算作证据之前，你需要的是那些文件本身，而不是一句故意写得像旧文献的话。即使是一本1949年5月的真实日记，如果其中不包含这些行为，也只是一个人的情绪。编造的句子则什么行为都不包含。
:::
:::

:::exercise 什么能推翻三项行为 {#exr-defeat level=3}
假设一位史家声称[[#thm-three]]是错的。请给出两项能够推翻它的发现，并说明为什么每一项都会迫使你重写这一论断，而不仅仅是加一条脚注。
:::hint
论证已经指出了反面证据的类型。你的任务是说明每一项会对“三项行为”与“不只是美国的决定”这些字眼产生什么影响。泛泛地诉诸美国的权力，还算不上一项发现。
:::
:::solution
第一，一份定于同一天、既建立了两个德意志国家又构成了同盟的单一文件，会使“三项行为”不成立。你将不得不用关于这一份文件的论断来代替原论断。正是各自不同的日子，才使数目成为三。第二，档案证据如果证明《基本法》与民主德国的建立是作为美国法令颁布的，既没有德国人起草，也没有欧洲对复兴计划的拒绝或接受，就会使“不只是美国的决定”不成立。你将不得不放弃论断的这一半。不会迫使你重写的，是“美国的权力很大”这一真实陈述。[[#thm-context]]已经把这种权力纳入其中，却仍然认为它并不充分。脚注可以记录权力，却不能把四月、五月与十月变成同一支美国的笔。
:::
:::
