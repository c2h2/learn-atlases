苏黎世（Zurich）与日内瓦（Geneva）何以不是维滕贝格（Wittenberg）？维滕贝格是一座选帝侯治下的大学城池，而1521年之后，那位选帝侯的庇护就是路德公开生涯的条件。苏黎世与日内瓦由议会治理。它们更换了一套礼仪，建立了一套纪律，而且没有等候《奥格斯堡和约》后来向路德宗与天主教诸侯提供的那类诸侯性解决方案。教义的标界比任何一座城市完成其秩序都更早。1529年在马尔堡（Marburg），路德与茨温利（Zwingli）没有在圣餐上达成一致。改革宗与路德宗不是带两种口音的一个新教。它们是一道分裂。

本章讲的是制度。本章不叙述加尔文（Calvin）的个性，也不描述日内瓦的刑事刑罚。一个施行劝诫的宗教法庭（consistory），一部治理的议会，就是事实。恐惧、名声与刑台，替代不了那些法令。

## 议会不是选帝侯

**城市改革**是一座城市的自身政府决定的公共崇拜之变更：一次议会，常常在一次辩论会之后，产出一套礼仪与一套纪律。它不是后来那桩领土诸侯为其领地选定路德宗或天主教的帝国交易。苏黎世有一个议会，也有一片属从的乡村，所以“城市”并不意味着每一个农民都投了票。日内瓦是一个小共和国，它已经甩脱了自己的主教与萨伏依公爵（duke of Savoy），并倚靠着伯尔尼（Bern）。两座城市都不是帝国的选帝侯国。两座都不是维滕贝格。

:::definition 城市改革 {#def-city}
**城市改革**是议会对崇拜的改革：一次公开辩论会或一场同类的听审，一套方言礼仪，以及一套与平信徒职员共同施行的、关于道德与教义的纪律。它不是诸侯在《奥格斯堡和约》之下的解决方案，也不是各家各户的私人选择。
:::

:::definition 改革宗 {#def-reformed}
**改革宗**命名的是站在茨温利一边、后来又站在加尔文一边、位于马尔堡分歧之另一侧的那些教会：它们不传授路德在饼与酒中的身体临在，并且通过牧师与长老而非仅仅通过一位诸侯的法庭来安排教会。这个词不是新教的同义词。新教出自1529年的施派尔（Speyer），是一个政治的名称。改革宗是一个教义与建制的名称。
:::

这道分裂可以在不假装茨温利与加尔文写过同一个句子的前提下讲出来。茨温利强调圣餐是一种表征、一次感恩、一份共同体的保证。加尔文在《基督教要义》（Institutes）与日内瓦的礼仪中教导：基督借着圣灵真实地给予信心，而饼仍然是饼。两人都拒绝了基督的身体在空间意义上在于饼酒之内的主张，而那正是路德不肯跟随他们的地方。马尔堡是针对路德的标界。它不是一个改革宗内部统一的断言。

## 苏黎世：一个议会，一套礼仪，一个战场

茨温利是格罗斯教堂（Grossmünster）的人民神父。苏黎世的变更在议会之前辩论，并由议会颁布。圣像的移除是在城市管控之下进行的，而不是作为任何人群的固有权利。1525年，正是农民战争在帝国境内进行并被谴责的那一年，苏黎世以改革的圣餐礼取代了弥撒。同一年属于两套宪法。在帝国，福音的语言迎头撞上领主并被镇压，[[reformations/luther]]对此有叙述。在苏黎世，一个议会废除了旧教会的核心礼典，另设了一个处理婚姻与道德的法庭。年份的巧合不是共同的原因。它是对一条单一的“宗教改革”时间线的警告。

苏黎世州的乡村并非一致同意。苏黎世统治着属从的共同体。一场城市改革可以是中心的城市化的、边缘的强加式的。当同一座城市试图把自己的改革推入与天主教诸州共享的地域时，这个限度就要紧起来。瑞士邦联是一个联盟，不是一个诸侯国，也不是一个缩小的帝国。天主教诸州保持了天主教。来自苏黎世的压力产生了战争。

:::theorem 马尔堡把路德宗与改革宗分开 {#thm-marburg-split}
1529年的马尔堡会谈，是路德与改革宗之间的教义标界。他们没有在圣餐上达成一致。对教皇的共同拒绝，或使用新教一词的共同习惯，都修复不了那个分歧。
:::
:::proof
[[reformations/luther]]讲过这次会面：黑森的菲利普想要一个同盟，而圣餐拦住了它。路德持有一种真实的身体临在。茨温利不。加尔文不在马尔堡。他后来的教导仍然属于那道鸿沟的茨温利一侧，而不属于路德一侧，即使加尔文的句子比茨温利的更丰满。证据是失败的协议，不是一种情绪。能够构成对[[#thm-marburg-split]]的反证的，是一段路德接受一种仅仅具有表征意义的圣餐的文字，或是一段茨温利接受路德之临在说的文字，或是一部把马尔堡条款视为已按路德的方向了结的改革宗信条。茨温利的继任者海因里希·布林格（Heinrich Bullinger）治下的苏黎世教会没有变成路德宗。分裂比那场会谈活得长。
:::

1531年，茨温利在卡佩尔（Kappel）阵亡。他是随苏黎世的军队一同前往的。那次战败结束了以战争把改革强加于其他诸州的尝试。天主教崇拜留在了邦联之内。一位宣讲者的死没有解散这座城市的教会。布林格接续他，并维持了苏黎世的秩序长达一段我们在这里不定年的任期。幸存的是制度，不是人格。卡佩尔也是对城市改革之浪漫化读法的回答：一个议会可能打败一场仗，而礼仪保不住随军牧师。

:::example 同一年，两种政体 {#ex-1525}
1525年，苏黎世议会取代了弥撒。1525年，农民战争正在德意志诸邦进行之中，路德谴责了叛乱者。把1525年称为“宗教改革之年”，为什么是个错误？
:::solution
年份是共享的，宪法却不是。苏黎世之举是一个议会改变一座城市的礼典，其中包括一片并非全都要求变更的属从乡村。农民战争是一场对领主的起义，被击败，并被路德否认。一个标签会把一套礼仪、一场社会战争与一次谴责藏进一句口号。从1517年的论纲到这一年，年份数字之差是8。这八年里有沃尔姆斯、有起义、有苏黎世的圣餐。它们里面没有一个单独的事件。
:::
:::

## 1536年的书与1541年的回归

:::example 从马尔堡到卡佩尔的两年 {#ex-kappel-span}
马尔堡是1529年。茨温利于1531年在卡佩尔阵亡。年份数字之差是多少年，这段短暂的间隔为什么要紧？
:::solution
1531减1529是2。教义分裂与军事败亡，不是同一个瑞士故事的什么长期成熟。苏黎世早已在1525年取代了弥撒，比马尔堡早四年。那次死亡既不奠基改革，也不在苏黎世恢复弥撒。布林格的领导，就是制度熬过了那位随军牧师的证据。年数是2。
:::
:::

加尔文《基督教要义》的第一版出现于1536年。它是一本书：一册简短的拉丁文教义纲要，带有一篇致法兰西国王的献词，为福音事业辩护。我们转述那个目的。我们不引用那篇序言。这本书不是一座城市。日内瓦有自己的与主教的决裂，那在加尔文被劝挽留并工作时已经完成。议会后来把他驱逐。1541年，这座城市把他召回。从1536年到1541年，年份数字之差是5。书在流传，而这位牧师不在任。这段间隔，正是一本文本与一项制度之间最干净的区分。

他回归之后，这座城市通过了教会法令。四个职分组织教会：牧师，宣讲并施行圣事；教师，教导；长老，出自民事议会；执事，照管穷人。宗教法庭由牧师与长老共同组成。它开会查核教义与道德。它自身的手段是劝诫与停止领圣餐。城市视为犯罪的案件交还议会，议会仍然是政府。本章停在那条线上。它不描述刑事刑罚。任何认为改革宗的宗教改革是一张刑罚清单的人，都是拿一场景观顶替了一个职分。

:::proposition 议会、礼仪、纪律 {#prop-institutions}
苏黎世式或日内瓦式的城市改革就是这三样东西：一部作出决定的议会，一套取代弥撒的礼仪，以及一套在牧师与平信徒长老之间分享的纪律。它不是一位牧师取代长官的统治，也不是奥格斯堡的诸侯规则。
:::
:::proof
苏黎世显示出议会决定礼典，在1525年，也显示出议会开战，在1531年，宣讲者死在议会的军队里。日内瓦显示出1541年的法令，把出自议会的长老安置进宗教法庭，并把民事裁判权留在议会。加尔文希望圣餐比议会肯给的更常举行。那次拒绝，就是牧师没有掌管日历的证据。能够构成对[[#prop-institutions]]的反证的，是一本牧师征税、定罪刑事案件、没有议会便宣布战争的会议记录。那不是日内瓦或苏黎世的记载。同样能够构成反证的，是一座采纳了加尔文的书、却让弥撒、圣像与旧教士原封不动的城市。礼仪是定义的一部分，不是一种可选的风格。
:::

牧师团考核牧师并差遣他们出去，包括去法兰西。日内瓦由此成为一批改革宗教会的苗圃，而那些教会自身并不是城市共和国。正是这次输出，使[[reformations/religious-war]]里的法兰西战争是改革宗的战争，而不是路德宗的战争。1559年，这座城市开办了一所学院来训练那份牧职。同一年，英格兰伊丽莎白的议会通过了两部宪法全然不同的法令，这在[[reformations/england]]里有讲授。共享的年份不是共享的教会秩序。《基督教要义》的长定本同样属于1559年。我们仍然取1536年为初版，1541年为回归。一本书在生长，不是政权的更替。

:::example 从初版《基督教要义》到回归 {#ex-span-geneva}
《基督教要义》的第一版是1536年。加尔文于1541年回到日内瓦。差是多少年，这段间隔关于书与城市显示了什么？（要保留的数字就是这个差。）
:::solution
1541减1536是5。在那些年岁里，书已经存在，而改革者不在任，因为曾任用他的议会也曾把他驱逐。1541年的回归是一座城市的决定，随后是法令。五年，足够把一部出版物与一个政府分开。年数是5。
:::
:::

## 奥格斯堡是对照，不是样板

1555年9月25日，《奥格斯堡和约》让帝国内的路德宗与天主教诸侯解决各自领地的公共宗教。公式 *cuius regio, eius religio* ——谁的领地，谁的宗教——就是那种诸侯抉择的简写。它不是现代的宽容。它不把加尔文派包括在内。苏黎世与日内瓦不是那个和约的诸侯，改革宗教会也不是它的一方。一个市议会于1541年采纳一套纪律，与一位选帝侯于1555年在路德宗与天主教之间作选择，是两个不同的法律对象。

遗漏不是一纸理论上的狡辩。1563年，正是特兰托（Trent）公会议结束之年，一部为普法尔茨（Palatinate）、帝国内的一个公国颁行的改革宗要理问答出版了。从1555年到1563年是8年。一部改革宗信条可以在帝国法律命名它之前，就存在于帝国之内。最终接纳加尔文派的和约是1648年，不是1555年。那次接纳是[[reformations/religious-war]]的工作。奥格斯堡在这里只用来拦住一个错误的概括：不要把苏黎世或日内瓦说成诸侯宗教的早期草样。

:::corollary 在诸侯的交易之外 {#cor-augsburg}
《奥格斯堡和约》不能被用作苏黎世或日内瓦的样式。它点名的是路德宗与天主教的诸侯。它没有点名这些议会，也没有点名改革宗。
:::
:::proof
这个推论就是年表本身画出的对照。奥格斯堡的公式是给路德宗与天主教诸侯的。加尔文派不在其中。苏黎世的改革由一个瑞士议会颁布，并在1531年卡佩尔的战败处受限，比那个和约早二十四年。日内瓦的法令在1541年，比它早十四年。能够构成对这个推论的反证的，是1555年和约中批准城市宗教法庭的条款，或是把改革宗点名列出的条款。没有这样的条款。后来把每一座非罗马的教会都归入单一新教类型的读者，是在用一个施派尔的词，抹去一个比他们本人更精确的和约。
:::

:::example 一次虚构的合并 {#ex-invented-merger}
下面这句话是虚构的，不是史料。“马尔堡之后，路德与加尔文签署了一部统一的新教信条，《奥格斯堡和约》把它为每一座城市颁布施行。”哪些分句经不起推敲，各自对哪些日期？
:::solution
马尔堡是1529年，它在圣餐上失败了。加尔文不是当事方。第一部《基督教要义》是1536年，回归日内瓦是1541年，所以“马尔堡之后”不可能是一场与路德共同签署一部包含日内瓦秩序的信条。奥格斯堡是1555年9月25日，它颁布的只是路德宗与天主教之间的诸侯抉择。它不颁布一座城市的纪律，也不包括改革宗。那句虚构句子的每一个分句，都在拼接日期们拒绝合并的东西。
:::
:::

## 一个完整的案例：一座城里的两种权威

设想一位1541年之后的日内瓦市民。名字没有必要，任何关于某个具体罪人的轶事都会是发明，所以我们让案例保持在制度层面。他可能被宗教法庭传唤，因为他不出席宣讲，因为一次公开的争吵，或者因为轻慢圣餐。宗教法庭劝诫他。它可以把他挡在圣餐之外，直到他向教会作出交代。如果这件事同时是城市法律下的犯罪，它就移交议会。两份记录，两种权威。牧师不是主权者。他身旁的那位长老，是议会派来的一位平信徒。他被控疏于参加的那套礼仪，正是议会设立来取代弥撒的公共崇拜。

这个案例不会做的，是跟着他走进刑事法庭并描述一种刑罚。这种拒绝是本章程的规则，不是档案的空白。刑事司法存在过。描述它会把一堂关于职分的课变成一堂关于痛苦的课，还会让一座城市的严苛充当每一座改革宗教会。苏黎世的道德法庭与日内瓦的宗教法庭，细节并非处处相同。天主教国王治下、由日内瓦供给牧师的法兰西会众，根本不可能成为日内瓦式的共和国。可输出的部分，是长老职、纪律与圣餐教义。绞架不可输出，因为它们是那座城市的。

什么能打破这个案例？证明停止领圣餐不过是一种没有公共崇拜可被排除在外的私人冷遇，或者证明宗教法庭是一个没有议会长老的牧师委员会。1541年回归时的法令恰恰相反地拟定：公共礼仪，混合的宗教法庭，保留的民政。卡佩尔是这同一课业的苏黎世版本。议会制造了战争。神学家死在了里面。

## 反对意见

第一个反对意见说出“新教”然后住口。施派尔在1529年给了这个词一个政治的出身，同一年的马尔堡则显示出，本来可能共享它的那些人并不共享一场圣餐。1555年的奥格斯堡随后只在路德宗与天主教周围画了一个法律圈。一位回答“新教如何得胜？”的讲师，提的是本章拒绝的问题。哪一种新教，在哪套宪法里，被哪部法律承认？

第二个反对意见说日内瓦是一个神权政体，意思是加尔文就是国家。这个词省去了读者学习法令的工夫。牧师们不执刑事之剑。他们与出自议会的长老同席。他们在圣餐举行的频次上输了辩论。加尔文被驱逐过一次，又被召回过一次，那是一种奇怪的主权。他的人格力量可以承认，而不必叙述。人格通不过一部法律。会让神权政体之说为真的，是一座牧师身旁没有议会的城市。日内瓦是相反的布置：一部雇佣他、罢免他、又再雇佣他的议会。

第三个反对意见把茨温利的死当作改革宗实验的终结，或者当作城市改革不过是一场个人冒险的证明。卡佩尔在1531年杀死了那个人，限制了苏黎世的战争。它没有在苏黎世恢复弥撒。布林格的长期领导是反证，日内瓦自1541年、即卡佩尔十年之后的独立路径也是反证。从1531年到1541年是10年。城市改革是一种类型，不是一部传记。

:::warning 一个新教，以及作为故事的刑台
改革宗与路德宗不是一座恰好为一种仪式争吵的教会。1529年的马尔堡是那道分界。1555年的奥格斯堡把改革宗留在帝国和约之外。另一个错误是用刑罚来定义日内瓦。本章不会描述它们。那些职分是宗教法庭、牧师团、礼仪与诸议会。一份刑罚清单不是一部教会秩序。
:::

:::solution
奥格斯堡是1555年9月25日。它是给路德宗与天主教等级的一份诸侯和平，不包括加尔文派。苏黎世议会早在1525年就已取代弥撒，并已在1531年卡佩尔战失了茨温利。这座城市，宪法不对，年份不对，教义也不对，归不进那个和约。
:::
:::

:::quiz
加尔文1541年回到日内瓦，确立的是什么？
- [ ] 一部后来被称作 *cuius regio, eius religio* 的规则之下的诸侯选举
- [ ] 《基督教要义》的第一版，它此前并不存在
- [x] 一座城市对一位牧师的召回，随之而来的法令把牧师与长老结合在一起，并把民政留在议会手中
- [ ] 与路德在圣餐中基督身体临在问题上的一致
:::solution
第一部《基督教要义》是1536年，不是1541年。回归是议会的行为。法令使长老与牧师同席，并没有把城市的刑事裁判权给牧师。与路德在圣餐上的一致，正是马尔堡在1529年已经未能产出的东西。加尔文站在那次失败之改革宗的一侧。
:::
:::

:::history
1529年，路德与茨温利在马尔堡没有就圣餐达成一致。茨温利于1531年在卡佩尔阵亡。加尔文《基督教要义》的第一版出现于1536年，加尔文于1541年回到日内瓦。
:::

## 通向何处

天主教改革是本世纪的另一半，而且它不仅仅是对这些城市的答复：[[reformations/catholic-reform]]。那个在1555年把加尔文派留在门外的帝国和平，以及与日内瓦有联系的诸会众卷起的法兰西战争，是[[reformations/religious-war]]。英格兰的法令是结合王冠与教会的第三种方式，在[[reformations/england]]。这些城市不是的那个维滕贝格的故事，是[[reformations/luther]]。一位心里装着马尔堡与宗教法庭的读者，再也不能把“新教”听成一件东西。

:::summary
- 苏黎世与日内瓦是议会的改革：一套礼仪，一套纪律，一个民政政府。它们不是选帝侯治下的维滕贝格。
- 1525年，苏黎世取代了弥撒。同一年是帝国境内的农民战争。一个年份不是一场宗教改革。
- 1529年的马尔堡，是路德与茨温利之间的圣餐分裂。改革宗不是路德宗的同义词，也不是新教的同义词。
- 茨温利于1531年在卡佩尔阵亡。这座城市的教会在布林格之下延续。一个人格不是制度。
- 第一部《基督教要义》在1536年。加尔文于1541年回到日内瓦。书与圣职相隔五年。
- 日内瓦的宗教法庭劝诫，并能把人挡在圣餐之外。诸议会保留了民事裁判权。本章不描述刑罚。
- 1555年9月25日的《奥格斯堡和约》是一个对照。它涵盖路德宗与天主教的诸侯，把改革宗排除在外。
:::

## 习题

:::exercise 卡佩尔的年份 {level=1 check="1531"}
茨温利在哪一年于卡佩尔阵亡？（请输入年份。）
:::solution
苏黎世的败亡与茨温利的死，锁定在同一年。年份是1531。
:::
:::

:::exercise 书的间隔 {level=1 check="5"}
《基督教要义》的第一版与加尔文回到日内瓦之间，按年份数字之差计，隔着多少年？（请输入年数。）
:::solution
第一版是1536年。回归是1541年。1541减1536是5。年数是5。
:::
:::

:::exercise 法令所属之年的年份 {level=1 check="1541"}
加尔文在哪一年回到日内瓦，城市的教会法令正属于那次回归？（请输入年份。）
:::solution
年表锁定的是回归，不是法令单独的一天。回归的年份是1541。
:::
:::

:::exercise 不是一个新教 {level=2}
只用马尔堡与奥格斯堡，解释为什么一座改革宗教会与一座路德宗教会不是一个新教。
:::solution
1529年在马尔堡，路德与茨温利没有在圣餐上达成一致。新教一词，出自同一年的施派尔，记录的是一次政治抗议，不是圣餐的解决方案。1555年9月25日，《奥格斯堡和约》承认的是路德宗与天主教之间的诸侯抉择，并把加尔文派留在外面。教义与帝国法都拒绝合并。对罗马的共同敌意，不是一场共同的圣事，也不是一种共同的法律身份。
:::
:::

:::exercise 两份记录 {level=2}
日内瓦的宗教法庭能做什么，又不持有什么？这个回答为什么对“牧师就是国家”的主张要紧？
:::solution
宗教法庭，牧师与长老同席，施行劝诫，并能把一个人停止领圣餐。长老来自议会。包括刑事司法在内的民事裁判权，留在那些议会手中。这个回答之所以要紧，因为“牧师就是国家”抹掉了长老们，抹掉了那个驱逐并召回加尔文的议会，也抹掉了教会惩戒与长官之间的那条线。本章说出那条线，并不接着去描述刑罚。
:::
:::

:::exercise 普法尔茨的八年 {level=2}
一部为普法尔茨颁行的改革宗要理问答出版于1563年。《奥格斯堡和约》是1555年。这八年的间隔，关于信条与帝国法显示了什么？
:::solution
1555年是那份让路德宗与天主教诸侯解决公共宗教、却不把改革宗包括进来的和约。1563年既是特兰托的终点，也是帝国内一部改革宗要理问答的年份。八，是1563减1555。一部信条可以在帝国和约命名它之前就被传授。法律与教义不是同一座钟。加尔文派获接纳，要等到1648年的和约。
:::
:::

:::exercise 神权政体的反对意见 {level=3}
反对意见：日内瓦是一个神权政体，所以那些制度不过是个人统治的伪装。公平地陈述这条反对意见，然后说出什么证据使那些法令成不了伪装。
:::hint
用上驱逐与回归、出自议会的长老的在场，以及议会对圣餐举行频次的掌控。不要用一份刑罚清单作答。
:::
:::solution
公平的陈述是：加尔文的个人权威是真实的，日内瓦以严苛闻名，而一位强势的牧师能够在名义上仍设议会的纸面上主宰一座小城。如果会议记录只是一身戏服，“神权政体”就是诚实的简称。

法令让这个词成不了全部的真相。长老与牧师同席，并且出自诸议会。宗教法庭的教会惩戒不是刑事法庭。议会驱逐过加尔文，又在1541年把他召回，那是雇主的行为，不是臣民的行为。议会还拒绝了他想要的领圣餐频次。会让这条反对意见获胜的，是一位牧师在没有议会陪同的情况下立法、征税、审判犯罪的证据。1541年的记载是相反的布置。严苛，无论其程度如何，既是牧师的，也是那座城市的，本课不描述它。
:::
:::

:::exercise 一个句子，三个错误 {level=3}
一句虚构的教科书句子说：“1531年加尔文死于马尔堡，而1541年的《基督教要义》随后成为奥格斯堡的路德宗信条。”逐一指认每个错误，并用本图谱真正锁定的日期替换这个句子。
:::hint
把卡佩尔、马尔堡、《基督教要义》的两个日期，以及奥格斯堡包括了什么，分开。替换的句子不需要任何年表之外的年份。
:::
:::solution
在1531年被杀的是茨温利，不是加尔文，地点是卡佩尔，不是马尔堡。马尔堡是1529年，它是一场分歧，不是一场死亡。第一部《基督教要义》是1536年。1541年是回归日内瓦，不是书的诞生，也不是路德宗信条。1555年9月25日的奥格斯堡承认的是路德宗与天主教的诸侯，不包括改革宗。日期担当得起的一个句子是：茨温利于1531年在卡佩尔阵亡；加尔文的《基督教要义》初版于1536年，他于1541年回到日内瓦；1555年的《奥格斯堡和约》仍然略去改革宗。
:::
:::
