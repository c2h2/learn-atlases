苏黎世（Zurich）与日内瓦（Geneva）为何不同于维滕贝格（Wittenberg）？维滕贝格是选帝侯治下的大学城，1521年以后，选帝侯的庇护是路德得以公开活动的前提。苏黎世与日内瓦则由市议会治理。它们改换礼仪、建立纪律，并没有等待《奥格斯堡和约》后来向路德宗与天主教诸侯提供的那种由诸侯决定的宗教安排。教义上的分界早于任何一座城市完成其教会秩序：1529年在马尔堡（Marburg），路德与茨温利（Zwingli）未能在圣餐问题上达成一致。改革宗与路德宗不是同一个新教的两种口音，而是一次分裂。

本章讲的是制度，不叙述加尔文（Calvin）的个性，也不描述日内瓦的刑罚。施行劝诫的宗教法庭（consistory）与执掌治权的市议会，才是事实。恐惧、名声与刑台都不能代替这些法令。

## 市议会不是选帝侯

**城市宗教改革**是由城市自身的政府决定的公共礼拜变革：市议会往往在一场公开辩论之后，确立新的礼仪与纪律。它不同于后来帝国的那项交易，即由领地诸侯为其领地选定路德宗或天主教。苏黎世既有市议会，也有一片隶属的乡村，所以“城市”并不意味着每个农民都投了票。日内瓦是一个小共和国，已摆脱了本城主教与萨伏依公爵（duke of Savoy），并依靠伯尔尼（Bern）。两座城市都不是帝国的选帝侯国，都不是维滕贝格。

:::definition 城市改革 {#def-city}
**城市宗教改革**是由市议会推行的礼拜改革：一场公开辩论或类似的听证，一套用本地语言举行的礼仪，以及一套与平信徒职员共同施行的道德与教义纪律。它既不是诸侯依《奥格斯堡和约》作出的宗教安排，也不是各家各户的私人选择。
:::

:::definition 改革宗 {#def-reformed}
**改革宗**指的是在马尔堡分歧中站在另一侧、先追随茨温利、后追随加尔文的那些教会：它们不教导路德所说的基督身体在饼与酒中的临在，并且通过牧师与长老、而不只是通过诸侯的法庭来治理教会。这个词不是“新教”的同义词。“新教”源于1529年的施派尔（Speyer），是一个政治名称；改革宗则是教义与教会体制的名称。
:::

讲述这次分裂，无须假装茨温利与加尔文说过同样的话。茨温利强调圣餐是一种象征、一次感恩、共同体的一项凭证。加尔文在《基督教要义》（Institutes）和日内瓦的礼仪中教导：基督借着圣灵真实地把自己赐给信心，而饼仍然是饼。两人都拒绝基督身体在空间意义上存于饼酒之内的主张，而路德恰恰在这一点上不肯随从他们。马尔堡是与路德之间的分界，并不表明改革宗内部已经统一。

## 苏黎世：市议会、礼仪与战场

茨温利是格罗斯大教堂（Grossmünster）的民众神父。苏黎世的变革先在市议会面前辩论，再由市议会颁行。圣像在城市当局的控制下移除，而不是作为任何人群固有的权利。1525年，正当帝国境内进行农民战争、起义者遭到谴责之时，苏黎世以改革后的圣餐礼取代了弥撒。同一年分属两种宪制。在帝国，福音的语言与领主迎头相撞并遭镇压，见[[reformations/luther]]；在苏黎世，市议会废除了旧教会的核心礼仪，并另设一个处理婚姻与道德的法庭。年份的巧合并非共同的原因，而是对单一“宗教改革”时间线的警示。

苏黎世辖区的乡村并非一致赞同。苏黎世统治着隶属的共同体，城市宗教改革可能在中心是自发的，在边缘却是强加的。当这座城市试图把改革推行到与天主教各州共管的地区时，这一限度就显得关键了。瑞士邦联是一个同盟，既不是诸侯国，也不是缩小的帝国。天主教各州保持了天主教，苏黎世施加的压力引发了战争。

:::theorem 马尔堡把路德宗与改革宗分开 {#thm-marburg-split}
1529年的马尔堡会谈，是路德与改革宗之间的教义分界。双方未能在圣餐问题上达成一致。共同拒斥教皇，或共同使用“新教”一词，都弥合不了这一分歧。
:::
:::proof
[[reformations/luther]]讲过这次会谈：黑森的菲利普希望结成同盟，而圣餐问题阻碍了它。路德坚持基督身体的真实临在，茨温利则不然。加尔文没有出席马尔堡会谈；他后来的教导虽比茨温利的表述更为丰满，仍属于这道鸿沟的茨温利一侧，而非路德一侧。证据是协议的失败，而不是某种情绪。能够推翻[[#thm-marburg-split]]的，是一段路德接受纯象征性圣餐的文字，或一段茨温利接受路德临在说的文字，或一部认为马尔堡的条款已按路德的方向了结的改革宗信条。茨温利的继任者海因里希·布林格（Heinrich Bullinger）领导下的苏黎世教会并没有变成路德宗。这次分裂比那场会谈持久得多。
:::

1531年，茨温利随苏黎世军队出征，在卡佩尔（Kappel）阵亡。这次战败终结了以战争把改革强加于其他各州的尝试，天主教礼拜在邦联内保留了下来。一位宣讲者的死没有瓦解这座城市的教会。布林格继任，并在一段这里不作定年的任期内维持了苏黎世的教会秩序。延续下来的是制度，而不是个人。卡佩尔也回应了对城市宗教改革的浪漫化解读：市议会可能打败仗，礼仪也保不住随军牧师。

:::example 同一年，两种政体 {#ex-1525}
1525年，苏黎世市议会取代了弥撒；同在1525年，德意志各邦正进行农民战争，路德谴责了起义者。为什么把1525年称为“宗教改革之年”是错误的？
:::solution
年份相同，宪制却不同。苏黎世之举是市议会改变一座城市的礼仪，其中包括一片并非都要求变革的隶属乡村。农民战争是反抗领主的起义，以失败告终，并遭到路德否认。一个标签会把礼仪变革、社会战争与一次谴责一并藏进一句口号。从1517年的论纲到这一年，年份数字之差是8。这八年里有沃尔姆斯、有起义、有苏黎世的圣餐礼，其中没有哪一件是单独的“那个事件”。
:::
:::

## 1536年的书与1541年的回归

:::example 从马尔堡到卡佩尔的两年 {#ex-kappel-span}
马尔堡会谈在1529年，茨温利于1531年在卡佩尔阵亡。年份数字之差是多少年？这段短暂的间隔为什么重要？
:::solution
1531减1529等于2。教义分裂与军事失败，并不是同一个瑞士故事的长期酝酿。苏黎世早在1525年就已取代弥撒，比马尔堡早四年。茨温利之死既没有奠定改革，也没有使苏黎世恢复弥撒。布林格的领导，证明了制度在随军牧师死后依然延续。年数是2。
:::
:::

加尔文《基督教要义》第一版问世于1536年。那是一本书：一部简短的拉丁文教义纲要，附有一篇致法国国王、为福音事业辩护的献词。这里转述其目的，不引用那篇序言。书不等于城市。日内瓦与本城主教的决裂另有其过程，在加尔文受劝留下工作时已经完成。市议会后来驱逐了他，1541年又召他回来。从1536年到1541年，年份数字之差是5。这期间书在流传，而这位牧师并不在任。这段间隔最清楚地区分了文本与制度。

他回来以后，日内瓦通过了《教会法令》。教会按四种职分组织：牧师负责讲道与施行圣事；教师负责教导；长老选自市政议会；执事负责照管穷人。宗教法庭由牧师与长老共同组成，开会审查教义与道德，其自身的手段是劝诫和暂停领圣餐。城市视为犯罪的案件交回市议会处理，市议会仍是政府。本章止于这条界线，不描述刑罚。认为改革宗的宗教改革只是一张刑罚清单的人，是拿一场景观顶替了一种职分。

:::proposition 议会、礼仪、纪律 {#prop-institutions}
苏黎世式或日内瓦式的城市宗教改革由三者构成：作出决定的市议会，取代弥撒的礼仪，以及由牧师与平信徒长老共同施行的纪律。它既不是牧师取代官员的统治，也不是奥格斯堡的诸侯规则。
:::
:::proof
苏黎世表明，市议会决定礼仪（1525年），也由市议会开战（1531年），宣讲者死于市议会的军队之中。日内瓦1541年的法令把选自市议会的长老安置在宗教法庭中，并把民事司法权留给市议会。加尔文希望圣餐举行得比市议会所同意的更频繁，这次被拒，就证明牧师并不掌控礼仪日程。能够推翻[[#prop-institutions]]的，是一份会议记录，显示牧师征税、审判刑事案件、无须市议会即可宣战；日内瓦与苏黎世的记载都不是这样。同样能够推翻它的，是一座采纳了加尔文的书、却对弥撒、圣像与旧神职人员原封不动的城市。礼仪是定义的一部分，而不是可有可无的风格。
:::

牧师团考核牧师并把他们派往各地，包括法国。日内瓦由此成为一批改革宗教会的培育地，而这些教会本身并非城市共和国。正是这种输出，使[[reformations/religious-war]]中的法国战争成为改革宗的战争，而非路德宗的战争。1559年，日内瓦开办学院以培养牧师。同一年，伊丽莎白治下的英格兰议会通过了两项宪制截然不同的法令，见[[reformations/england]]。同一年份并不意味着同一种教会秩序。《基督教要义》的最终定本同样出版于1559年；我们仍以1536年为初版，以1541年为回归。这是一本书的增订，而不是政权的更替。

:::example 从初版《基督教要义》到回归 {#ex-span-geneva}
《基督教要义》第一版在1536年，加尔文于1541年回到日内瓦。两者相差多少年？这段间隔就书与城市的关系说明了什么？（要保留的数字就是这个差。）
:::solution
1541减1536等于5。在这几年里，书已存在，改革者却不在任，因为曾聘用他的市议会也驱逐了他。1541年的回归是城市的决定，随后才有法令。五年足以把一部出版物与一个政府区分开来。年数是5。
:::
:::

## 奥格斯堡是对照，而非样板

1555年9月25日的《奥格斯堡和约》，让帝国内的路德宗与天主教诸侯决定各自领地的公共宗教。*cuius regio, eius religio*（“谁的领地，谁的宗教”）这一公式，就是对这种诸侯抉择的简称。它不是现代意义上的宽容，也不包括加尔文派。苏黎世与日内瓦不是该和约所涉的诸侯，改革宗教会也不是和约的一方。1541年一个市议会采纳一套纪律，与1555年一位选帝侯在路德宗与天主教之间作出选择，是两种不同的法律对象。

这一遗漏并非纸面上的诡辩。1563年，即特兰托（Trent）公会议闭幕的那一年，一部为帝国内的普法尔茨（Palatinate）颁行的改革宗要理问答出版。从1555年到1563年是8年。一种改革宗信条可以在帝国法律承认它之前就存在于帝国之内。最终接纳加尔文派的是1648年的和约，而不是1555年的和约，这一点见[[reformations/religious-war]]。这里援引奥格斯堡，只是为了防止一种错误的概括：不要把苏黎世或日内瓦说成诸侯定教的早期雏形。

:::corollary 诸侯交易之外 {#cor-augsburg}
《奥格斯堡和约》不能用作苏黎世或日内瓦的模式。它点名的是路德宗与天主教诸侯，既没有提到这些市议会，也没有提到改革宗。
:::
:::proof
这一推论就是年表本身所呈现的对照。奥格斯堡的公式适用于路德宗与天主教诸侯，加尔文派不在其中。苏黎世的改革由一个瑞士市议会颁行，并在1531年卡佩尔战败时受挫，比该和约早二十四年；日内瓦的法令在1541年，比它早十四年。能够推翻这一推论的，是1555年和约中批准城市宗教法庭或点名改革宗的条款，而这样的条款并不存在。后世读者若把一切非罗马教会都归入单一的新教类型，就是在用一个出自施派尔的词，抹去一项比他们自己更精确的和约。
:::

:::example 一次虚构的合并 {#ex-invented-merger}
下面这句话为示例而虚构。它不是史料。“马尔堡会谈之后，路德与加尔文签署了一部统一的新教信条，《奥格斯堡和约》又把它颁行于每一座城市。”哪些分句经不起推敲？各自与哪些日期相抵触？
:::solution
马尔堡会谈在1529年，在圣餐问题上失败了，加尔文也不是当事人。第一版《基督教要义》在1536年，回到日内瓦在1541年，因此“马尔堡会谈之后”不可能有一次与路德共同签署、并包含日内瓦秩序的信条。奥格斯堡在1555年9月25日，它所颁定的只是诸侯在路德宗与天主教之间的选择，既不颁行城市的纪律，也不包括改革宗。这句虚构的话，每一个分句都在拼合年代所不容合并的东西。
:::
:::

## 一个完整的案例：一城之中的两种权威

设想一位1541年以后的日内瓦市民。名字不必给出，任何关于某个具体罪人的轶事都会是编造，因此这个案例只停留在制度层面。他可能因为不去听道、因为一次当众争吵、或因为轻慢圣餐而被宗教法庭传唤。宗教法庭对他进行劝诫，并可禁止他领圣餐，直到他向教会作出交代。如果此事同时触犯城市法律，就移交市议会。两份记录，两种权威。牧师不是主权者；他身旁的长老，是市议会派来的平信徒。他被指责疏于参加的礼仪，正是市议会为取代弥撒而设立的公共礼拜。

这个案例不会跟随他进入刑事法庭去描述刑罚。这是本章的规则，并非档案的空白。刑事司法确曾存在，但描述它会把一堂讲职分的课变成一堂讲痛苦的课，还会让一座城市的严苛代表所有改革宗教会。苏黎世的道德法庭与日内瓦的宗教法庭，细节并不处处相同。天主教国王治下、由日内瓦提供牧师的法国会众，根本不可能成为日内瓦式的共和国。能够输出的是长老职、纪律与圣餐教义；绞刑架无法输出，因为它属于那座城市。

什么能推翻这个案例？证明暂停领圣餐只是一种私下的冷落，背后并无可被排除在外的公共礼拜；或者证明宗教法庭是一个没有市议会长老的牧师委员会。1541年回归时的法令恰恰作了相反的规定：公共礼仪、混合组成的宗教法庭、由市政保留的民事权力。卡佩尔是同一课题的苏黎世版本：市议会发动战争，神学家死于其中。

## 反对意见

第一种反对意见说出“新教”二字便就此打住。1529年的施派尔赋予这个词政治上的出身，同年的马尔堡则表明，本可共用这个词的人并不共享同一种圣餐。随后，1555年的奥格斯堡只为路德宗与天主教划定了法律范围。一位讲授“新教如何取胜？”的讲师，提出的正是本章拒绝的问题。是哪一种新教，在哪一种宪制之中，被哪一部法律承认？

第二种反对意见说日内瓦是神权政体，意思是加尔文就是国家。这个词让读者省去了研读法令的功夫。牧师不执掌刑事之剑；他们与选自市议会的长老同席；在圣餐举行频次的争论中，他们输了。加尔文被驱逐过一次，又被召回过一次，这样的主权未免奇怪。他个人的影响力可以承认，而不必在此叙述；个人魅力通过不了一部法律。要使神权政体之说成立，需要一座牧师身旁没有市议会的城市。日内瓦的安排恰好相反：市议会聘用他、罢免他、又再聘用他。

第三种反对意见把茨温利之死当作改革宗实验的终结，或当作城市宗教改革只是个人冒险的证明。1531年的卡佩尔之战夺去了他的生命，也限制了苏黎世的战争，却没有使苏黎世恢复弥撒。布林格的长期领导是反证，日内瓦自1541年起、即卡佩尔之战十年之后所走的独立道路也是反证。从1531年到1541年是10年。城市宗教改革是一种类型，而不是一部传记。

:::warning 单一的新教，与作为故事的刑台
改革宗与路德宗并不是恰好为某项仪式争执的同一个教会。1529年的马尔堡是分界线，1555年的奥格斯堡把改革宗排除在帝国和约之外。另一个错误是用刑罚来定义日内瓦，本章不会描述那些刑罚。真正的职分是宗教法庭、牧师团、礼仪与市议会。刑罚清单不等于教会秩序。
:::

- [ ] 因为城市宗教改革是不带公共礼仪的私人意见
:::solution
奥格斯堡在1555年9月25日，是为路德宗与天主教等级订立的诸侯和约，不包括加尔文派。苏黎世市议会早在1525年就已取代弥撒，1531年在卡佩尔失去了茨温利。无论宪制、年份还是教义，这座城市都归不进那项和约。
:::
:::

:::quiz
加尔文1541年回到日内瓦，确立的是什么？
- [ ] 一次依照后来所谓 *cuius regio, eius religio* 规则进行的诸侯选择
- [ ] 此前尚不存在的《基督教要义》第一版
- [x] 一座城市召回一位牧师，随后的法令把牧师与长老结合起来，并把民事权力留在市议会手中
- [ ] 与路德就基督身体在圣餐中的临在达成一致
:::solution
第一版《基督教要义》在1536年，不在1541年。回归是市议会的决定。法令让长老与牧师同席，并没有把城市的刑事司法权交给牧师。与路德在圣餐问题上达成一致，恰恰是马尔堡在1529年未能做到的。加尔文站在那次失败中改革宗的一侧。
:::
:::

:::history
1529年，路德与茨温利在马尔堡未能就圣餐达成一致。茨温利于1531年在卡佩尔阵亡。加尔文《基督教要义》第一版问世于1536年，加尔文于1541年回到日内瓦。
:::

## 通向何处

天主教改革是这个世纪的另一半，而且不仅仅是对这些城市的回应，见[[reformations/catholic-reform]]。1555年把加尔文派拒之门外的帝国和约，以及与日内瓦有联系的会众所卷入的法国战争，见[[reformations/religious-war]]。英格兰的法令是把王权与教会结合起来的第三种方式，见[[reformations/england]]。与这些城市形成对照的维滕贝格的故事，见[[reformations/luther]]。读者一旦记住马尔堡与宗教法庭，就再也不会把“新教”听成单一的东西。

:::summary
- 苏黎世与日内瓦是市议会推行的改革：礼仪、纪律与民事政府。它们不是选帝侯治下的维滕贝格。
- 1525年，苏黎世取代了弥撒；同一年，帝国境内发生农民战争。同一个年份并不等于同一场宗教改革。
- 1529年的马尔堡会谈，是路德与茨温利之间的圣餐分裂。改革宗既不是路德宗的同义词，也不是新教的同义词。
- 茨温利于1531年在卡佩尔阵亡，苏黎世的教会在布林格领导下延续。个人不等于制度。
- 第一版《基督教要义》在1536年，加尔文于1541年回到日内瓦。书与牧职相隔五年。
- 日内瓦的宗教法庭施行劝诫，并可禁止领圣餐；民事司法权保留在市议会手中。本章不描述刑罚。
- 1555年9月25日的《奥格斯堡和约》是一个对照：它涵盖路德宗与天主教诸侯，而把改革宗排除在外。
:::

## 习题

:::exercise 卡佩尔的年份 {level=1 check="1531"}
茨温利在哪一年于卡佩尔阵亡？（请输入年份。）
:::solution
苏黎世的战败与茨温利之死锁定在同一年。年份是1531。
:::
:::

:::exercise 书的间隔 {level=1 check="5"}
按年份数字之差计算，《基督教要义》第一版与加尔文回到日内瓦相隔多少年？（请输入年数。）
:::solution
第一版在1536年，回归在1541年。1541减1536等于5。年数是5。
:::
:::

:::exercise 法令之年 {level=1 check="1541"}
加尔文在哪一年回到日内瓦？日内瓦的《教会法令》正是随这次回归而来。（请输入年份。）
:::solution
年表锁定的是回归，而不是法令颁布的具体日期。回归的年份是1541。
:::

:::exercise 并非同一个新教 {level=2}
只用马尔堡与奥格斯堡，说明为什么改革宗教会与路德宗教会不是同一个新教。
:::solution
1529年在马尔堡，路德与茨温利未能在圣餐问题上达成一致。同年出自施派尔的“新教”一词，记录的是一次政治抗议，而不是圣餐问题的解决。1555年9月25日，《奥格斯堡和约》承认的是诸侯在路德宗与天主教之间的选择，而把加尔文派排除在外。教义与帝国法律都不容二者合并。共同敌视罗马，既不意味着共同的圣事，也不意味着共同的法律身份。
:::
:::

:::exercise 两份记录 {level=2}
日内瓦的宗教法庭能做什么，又不掌握什么？这个回答对于“牧师就是国家”的说法为什么重要？
:::solution
宗教法庭由牧师与长老同席组成，施行劝诫，并可暂停某人领圣餐。长老来自市议会。包括刑事司法在内的民事司法权留在市议会手中。这个回答之所以重要，是因为“牧师就是国家”一说抹去了长老，抹去了驱逐又召回加尔文的市议会，也抹去了教会惩戒与世俗官员之间的界线。本章指出这条界线，但不进而描述刑罚。
:::
:::

:::exercise 普法尔茨的八年 {level=2}
一部为普法尔茨颁行的改革宗要理问答出版于1563年，《奥格斯堡和约》在1555年。这八年的间隔，就信条与帝国法律的关系说明了什么？
:::solution
1555年的和约让路德宗与天主教诸侯决定公共宗教，却不包括改革宗。1563年既是特兰托公会议闭幕之年，也是帝国内一部改革宗要理问答问世之年。八，是1563减1555之差。一种信条可以在帝国和约承认它之前就被传授。法律与教义并不按同一个钟走。加尔文派获得接纳，要等到1648年的和约。
:::
:::

:::exercise 神权政体之说 {level=3}
反对意见：日内瓦是神权政体，因此那些制度不过是个人统治的伪装。请公平地陈述这一反对意见，再指出哪些证据表明那些法令并非伪装。
:::hint
运用驱逐与回归、选自市议会的长老的在场，以及市议会对圣餐频次的掌控。不要用刑罚清单作答。
:::
:::solution
公平的陈述是：加尔文的个人权威是真实的，日内瓦以严苛著称，一位强势的牧师完全可能主宰一座小城，而纸面上依然保留着市议会。如果会议记录只是一身戏装，“神权政体”就是诚实的简称。

法令表明，这个词不是全部真相。长老与牧师同席，且选自市议会。宗教法庭的教会惩戒不是刑事审判。市议会驱逐过加尔文，又在1541年把他召回，这是雇主的行为，而不是臣民的行为。市议会还拒绝了他所希望的领圣餐频次。要使这一反对意见成立，需要证据表明某位牧师在没有市议会参与的情况下立法、征税、审判罪案。1541年的记载显示的恰恰是相反的安排。至于严苛，无论程度如何，既属于牧师，也属于那座城市，本课不作描述。
:::
:::

:::exercise 一个句子，三个错误 {level=3}
一句虚构的教科书句子写道：“1531年加尔文死于马尔堡，随后1541年的《基督教要义》成为奥格斯堡的路德宗信条。”请逐一指出其中的错误，并用本图谱确实锁定的日期改写这句话。
:::hint
把卡佩尔、马尔堡、《基督教要义》的两个日期以及奥格斯堡所涵盖的范围区分开来。改写后的句子不需要年表之外的任何年份。
:::
:::solution
1531年阵亡的是茨温利，不是加尔文，地点是卡佩尔，不是马尔堡。马尔堡在1529年，那是一次分歧，而不是一次死亡。第一版《基督教要义》在1536年；1541年是回到日内瓦，既不是这本书的问世，也不是路德宗信条。1555年9月25日的奥格斯堡承认的是路德宗与天主教诸侯，不包括改革宗。日期能够支撑的句子是：茨温利于1531年在卡佩尔阵亡；加尔文的《基督教要义》初版于1536年，他于1541年回到日内瓦；1555年的《奥格斯堡和约》仍然没有包括改革宗。
:::
:::
