关于1517年10月31日，什么是确立的，什么不是？《九十五条论纲》带着那个日期。它们是一份真实的文本，而且流传了。至于马丁·路德（Martin Luther）把它们钉在维滕贝格（Wittenberg）城堡教堂门上的故事，则出自后来人菲利普·梅兰希顿（Philip Melanchthon），并未确立。一组学术命题上的一个日期，与一个带铁锤的场面，不是一回事。本章只讲能够定年的东西：论纲、沃尔姆斯（Worms）帝国会议、农民战争、罗马之劫，以及马尔堡（Marburg）的分裂。

单数的“宗教改革”这个名字，对这些年头来说已经很不合身。路德拒绝撤回，并没有产生一种教义、一座教会，或一种宣讲者与诸侯之间的关系。到1529年，他与茨温利（Huldrych Zwingli）在圣餐上没有达成一致。新教（Protestant）一词同年诞生，它命名的是帝国政治中的一次抗议，不是一个单一的信条。下一章讲那些不是维滕贝格的城市改革。天主教改革，它不仅仅是对路德的答复，是再下一章。

## 一个日期、一份文本，与一个后来的故事

维滕贝格是萨克森选帝侯国的一座大学小城。路德是一名奥斯定会修士，也是神学教授。论纲以辩论会的形式写成：为学术争论而设的、用拉丁语写成的编号命题，不是面向人群的讲道，也不是新建教会的章程。那个日期确立的是作者身份与流传。抄本以印刷和手抄两种形式流出了大学。印刷是放大器。它本身不是原因。德文《圣经》早已存在，而一部印刷的拉丁文《圣经》通常定年为约1454–1455年，比论纲早两代人。[[crises/print]]是那项技术的所在。一台印刷机能传播一场已经在进行的争吵。它不能决定这场争吵的含义。

:::definition 《九十五条论纲》 {#def-theses}
**《九十五条论纲》**是为一场辩论会提出的命题，定年为1517年10月31日。作为一份流传了的文本，它们是确立的。作为钉在维滕贝格教堂门上的纸张，它们并未确立。门前的场面是梅兰希顿后来的故事。即使大学真有张贴论纲的惯例，它仍然不是这一天的证人。
:::

论纲的导因是赎罪券（indulgence）的宣讲。它们实质上问的是：教皇的赎罪券能否触及炼狱中的一个灵魂，一笔金钱能否代替悔改，以及教皇如果真有宣讲者所宣称的那种权能，为何不白白清空炼狱。我们是在转述这条论证的思路，不是引用台词。这些命题仍然身处拉丁教会之内：它们争论的是忏悔、教皇与牧灵之责。它们还不是对每一件圣事的否定，也不是德意志诸侯的政治纲领。决裂是在其后的争论中扩大的：路德被人从一项做法，一路推到教皇与公会议的权威问题上。

那次扩大回溯到一道康斯坦茨（Constance）公会议以为已经愈合的伤口。那次公会议从1414年开到1418年。扬·胡斯（Jan Hus）于1415年被处以火刑。始于1378年的西方大分裂，随马丁五世（Martin V）在1417年的当选而终结。在论纲之后的争论里，路德被逼到说出教皇与公会议都会犯错。一个被公会议烧死的人由此成了一个先例，而不是一个已结的案子。[[crises/war-and-schism]]按其自身的条件处理康斯坦茨。这里的论点更窄：论纲是一场公开争吵的开端，不是路德后来教导的全部，也不是各地的宗教改革的全部。

:::theorem 1517年10月31日确立什么 {#thm-door}
这一天确立的是一份有日期且流传了的文本。它没有确立路德把论纲钉在教堂门上。门的故事出得晚，来自梅兰希顿，而且不是对那个行动的同时代记载。
:::
:::proof
支持文本的证据，是论纲本身以及它们流传了这个事实。反对门那个场面的证据，是这个故事的形状：它讲述得晚，出自一个并没有在1517年10月31日写日记的人。张贴论纲的惯例会让那个场面显得可信。可信不是证词。能够构成对[[#thm-door]]的反证的，是一位独立于梅兰希顿、记载了当天钉上的动作的同时代证人。这样的证人并未确立。能够构成对前一半的反证的，是论纲未曾流传的证据。流传正是确立的那一半。门前的一幅图画，增添了一个我们拿不出来的行动，又遮住了印刷、大学与诸侯。
:::

:::quiz
关于1517年10月31日，什么是确立的？
- [ ] 路德把《九十五条论纲》钉在城堡教堂的门上，铁锤之声开启了宗教改革
- [x] 论纲定年为那一天，而且它们流传了。钉上门是后来的故事，并未确立
- [ ] 关于论纲一无所知。那个日期是十九世纪编造的
- [ ] 论纲是一篇德文讲道，在那天下午废除了教皇制
:::solution
文本与它的流传是既定的事实。梅兰希顿的门前场面出得晚，并未确立。论纲是为一场辩论会写的拉丁语命题，不是一天之内创立一座教会的讲道，也不是一张任由后来几个世纪凭空填写的空白。
:::
:::

## 赎罪券是导因，不是整座教会

在拉丁教会的教导中，赎罪券是对罪的暂罚（temporal penalty）的赦免。它不是犯罪的许可证，而按照那个教导，它也不是把罪咎的赦免拿出来出售。罪咎属于痛悔与忏悔圣事。暂罚是留下来的东西，包括与炼狱相连的暂罚。宣讲者把赎罪券与对虔诚事业的捐赠捆绑在一起宣讲。罗马圣彼得大教堂的重建就是这样一项事业。特策尔（Johann Tetzel）在美因茨的阿尔布雷希特（Albert of Mainz）的教省里宣讲它，此人是美因茨大主教兼马格德堡大主教。那次推销正是论纲的导因。我们不给出具体的钱数。弊端在宣讲的结构里，不在一个本图谱没有锁定的数字上。

:::definition 赎罪券 {#def-indulgence}
**赎罪券**是凭借教皇所宣称的那种权威，对罪的暂罚的赦免。它不是犯罪的许可证，也不是对中世纪晚期宗教的完整描述。在1517年，它是路德公开争吵的导因。它不是他后来全部批判的内容，也不是一座再无别的生活的教会的漫画像。
:::

那幅漫画正是要拒绝的错误。这几十年里，拉丁基督教的生活也包括堂区弥撒、宗教善会、朝圣、慈善与为亡者祈祷。一场告诉买者他已买出一个炼狱灵魂的推销，尽可攻击，而不必假装每一座祭坛都是一间店铺。迪菲（Duffy）在[[reformations/england]]里关于英格兰的警告同样走得远：对一项做法的批评，不是一座死教会的照片。[[reformations/catholic-reform]]里的天主教改革，如果旧教会内部没有任何东西值得改革、除非作为对新教的答复，那就不可理解了。

论纲本身并不停在钱箱上。它们把宣讲与悔改、与教皇权力的限度、与一种使恩典听起来很廉价的赦免所引发的丑闻系在一起。争论一旦关乎权威，就不能再是对一位宣讲者的地方性抱怨。为赎罪券辩护的人回答说，路德误解了一套合法的神学，还侮辱了教皇。在沃尔姆斯之前的几年里，他的回答是不断扩大阵地：先以《圣经》反对宣讲者，再以《圣经》反对教皇或公会议不能犯错的主张。我们不给这些步骤指派年表没有锁定的年份。要紧的是方向。到他在沃尔姆斯站出来的时候，他已被处以绝罚。帝国会议不是争吵的第一天。它是争吵与皇帝相遇的那一天。

:::example 关于门的一句虚构的话 {#ex-invented-door}
读一读这句话，它是虚构的，不是史料。“1517年10月31日，路德把《九十五条论纲》钉在教堂门上，并对人群说，他宁可相信自己的良心，也不相信教皇。”这句话里有什么——如果有什么的话——是确立的？要把其余的部分提升为证据，需要什么？
:::solution
只有论纲的日期，以及存在一份该日期的文本可供谈论这个事实，沾到了确立的事实。钉上门是后来的故事，不是我们可以当作事实来讲的事。对人群讲话是虚构的。路德的话轮不到我们来补写，无论在门前还是在沃尔姆斯。要把钉上门提升为证据，史家需要一位独立于梅兰希顿后来记述的同时代证人。要把那次讲话提升为证据，需要的是一句话说过的记录，而不是一句为了让场面戏剧化而写下的句子。论纲的流传可以由抄本来显示。人群、铁锤和一句格言则不能。
:::
:::

## 沃尔姆斯：一次拒绝，不是一台戏

1521年4月，路德出现在沃尔姆斯帝国会议上，查理五世（Charles V）在座主持。他被要求撤回。他拒绝了。这次拒绝就是本图谱要陈述的结果。后来挂在那一幕上的著名句子，不是我们能引用的台词，本章也不会发明它们。一纸安全通行证把他带到会前，又准许他离开。1521年5月的《沃尔姆斯诏书》宣布他为帝国法外之徒。法外地位是一个法律事实。在萨克森，它不是一次逮捕。

诏书与逮捕之间的落差，是这第一代人的政治事实。萨克森选帝侯弗里德里希（Frederick）庇护了他大学里的教授。1521年，路德被带入那种庇护之下，在瓦尔特堡（Wartburg）。他利用这段隐匿把《新约》译成德文。把《圣经》译成德文，他不是第一人。译本之所以要紧，是因为他此时已经是谁，也是因为印刷能够成倍复制它。我们不把这部译本的出版定在年表没有锁定的年份。一个已宣布他为法外之徒的帝国，不能或不愿把他从一位诸侯手里带走。查理五世同时也是一叠王国的统治者，这在[[states/composite-monarchy]]里有讲授。他在1556年的退位远在前方。在沃尔姆斯，他无法对每一位选帝侯强行推行同一部宗教法律。

:::example 从论纲到沃尔姆斯 {#ex-span-worms}
论纲的日期是1517年10月31日。帝国会议在1521年4月。年份数字之差是多少年，为什么它与从十月到四月的跨度不是一回事？（请输入年份数字之差。）
:::solution
对于两个公元年份，本图谱把从A年到B年的已过计数取作B减A。从1517年到1521年，这个计数是4。从1517年10月31日到1521年4月的某一天，是三年零大约六个月，因为十月到四月走不满第四个年头。一句“四年之后，在沃尔姆斯”用的是年份数字之差，把一个十月的日期向前拉伸到四月的一个日期。只要你说出问的是哪个问题，两个数字都可以是对的。年份数字计数里的年数是4。
:::
:::

沃尔姆斯之后，争吵不再是一个修士的案子。宣讲者、议会与一些诸侯开始改变崇拜。萨克森的庇护使一种公开生涯成为可能。它并没有把路德变成帝国的主教。苏黎世（Zurich）的茨温利早已在另一条路上。分裂在1529年的马尔堡变得确凿无疑。

## 农民战争是故事的一部分

1524年和1525年，一场大起义席卷德意志诸邦。它被称为农民战争。它不只有农民，正如1381年的英格兰起义不只有农民。平民、乡村居民与一些市民起来反对领主。怨愤里混杂着地租、农奴身份、林地与公地的使用权，以及选立牧师之权。1525年，一份被广为抄传的文告《十二条款》，把其中一些怨愤用福音的语言写了出来：领主要用《圣经》来检验，负担要减轻，共同体要获准自选其牧师。我们是在转述这类要求的种类。我们并不假装这些条款是某一支军队的某一份宣言。起义是许多场起义。

路德谴责了叛乱者。他曾在沃尔姆斯拒绝教皇与皇帝。他并不为拿起武器反对领主的臣民辩护。他实质上划出的区分，一面是一种并不需要重造法律的基督徒的自由，另一面是一个臣民不可奉福音之名推翻的世俗秩序。诸侯扑灭了起义。镇压是凶残的。本图谱不给出死亡总数。托马斯·闵采尔（Thomas Müntzer），一位站在暴动一边的宣讲者，在1525年弗兰肯豪森（Frankenhausen）战败之后被杀。我们不描述处死的方式。我们保留的事实是那种对齐：福音的语言可供叛乱者使用，而路德把它用尽来对付他们。

:::proposition 沃尔姆斯不是臣民的特许状 {#prop-peasants}
路德在1521年4月的拒绝撤回，并不蕴含臣民以武力强加福音的权利。他在1524–1525年农民战争中对叛乱者的谴责就是证据，它与沃尔姆斯属于同一个人的生平。
:::
:::proof
证据是年表锁定的顺序：在沃尔姆斯的一次拒绝，随后是对起义的谴责。在沃尔姆斯，一个被传唤的神学家拒绝收回他的教导。1525年，臣民进攻领主，而他站在领主一边。能够构成对[[#prop-peasants]]的反证的，是他在起义的那几年里的一篇文字，把武装叛乱辩护为他拒绝撤回的那个福音的必然结果。他发表的不是这个。跳过战争，自由的画像就被删改过。只把谴责当作唯一的事实，你就无法解释一个法外之徒为何值得庇护。两个事实都成立。
:::

萨克森的弗里德里希死于1525年，就在战争期间。选帝侯国的庇护没有随他而死。一场王朝的死亡、一场社会战争、一项神学谴责，可以共享一个年份，却不是同一个事件。

:::example 沃尔姆斯与农民战争并置 {#ex-side}
把1521年4月与1524–1525年并置。一部标明为虚构的编年史说：“路德在沃尔姆斯与一切权威决裂，便带领农民反对他们的领主。”真实日期的并置，对那句话做了什么？
:::solution
真实的日期把一次拒绝与一次谴责放进同一个人的生平，相隔数年。从1521年到1525年，年份数字之差是4。虚构的句子把它们坍缩成一种姿态，“反对一切权威”，然后又发明了一种路德并未行使过的领导。他拒绝在皇帝面前撤回。当叛乱者与领主作战时，他谴责了他们。并置就是更正。只知沃尔姆斯的读者会误读1525年。只知谴责的读者会误读沃尔姆斯。图谱两者都保留。
:::
:::

## 罗马、施派尔与马尔堡

1527年，帝国军队洗劫了罗马。教皇克雷芒七世（Clement VII）曾在意大利反对查理五世。那支军队是皇帝的军队，欠着军饷，成分混杂，其中包含听过福音派宣讲的德意志士兵。洗劫使教皇蒙羞。它没有确立路德的教义，查理也没有把它作为一次神学示威来下令。他仍是一位天主教诸侯。在沃尔姆斯被宣布法外的那个人不是统帅。皇帝与教皇可以在一同拒绝路德的同时彼此开战。英格兰的后果属于[[reformations/england]]：一个被皇帝重创的教皇，在宣告皇帝姑母的婚姻无效这件事上，处境极为不利。

:::theorem 已然不止一场宗教改革 {#thm-marburg}
到1529年，福音派运动在圣餐上已经不止一种教义。马尔堡会谈是标志：路德与茨温利没有达成一致。新教一词出自同年施派尔（Speyer）的抗议，并不能取消那道分裂。
:::
:::proof
1529年，施派尔的一次帝国会议着手执行《沃尔姆斯诏书》。福音派的诸侯与城市提出抗议。新教这个名称就出自那次抗议。它是帝国法律里的一个词。同年，黑森的菲利普（Philip of Hesse）把路德与茨温利带到马尔堡。他们能在许多事情上达成一致。他们无法在圣餐上达成一致。路德主张，基督的身体与血在饼与酒中真实地给予。茨温利不。我们陈述分歧，不补写对话。会谈的失败就是[[#thm-marburg]]的证据。能够构成反证的，是一份两人陈述同一教义的协议记录，或者一个并不需要这项一致的同盟。会谈之所以召开，正是因为一致缺席。同盟没有跟来。新教这个名称并不能告诉你，一个人对圣餐相信什么。
:::

:::corollary 名称不是教义 {#cor-protestant}
1529年之后称一位诸侯、一座城市或一位宣讲者为新教，标明的是帝国争吵中的一方。它标明的不是一种圣餐教义，也不是一座日内瓦式的改革宗教会。
:::
:::proof
施派尔的抗议反对的是一项会议决议。它不是一部为圣餐定论而起草的信条。路德与茨温利可以都站在抗议一边，却仍然在马尔堡分裂。能够构成对这个推论的反证的，是一部在1529年被施派尔接受、为每一个抗议等级确定圣餐的统一信条。这样的信条并不存在。1555年9月25日的《奥格斯堡和约》仍然还得说出帝国将承认哪些教义。那个和约在[[reformations/religious-war]]里讲授。一个1529年铸造出来的词，干不了一部教会秩序的活。
:::

:::example 同一年，两个事实 {#ex-1529}
施派尔与马尔堡都落在1529年。从1517年的论纲到那一年，年份数字之差是12。把1529年当作“新教”获得一套神学的年份，为什么是个错误？
:::solution
十二年，就是1529减1517之差。第十二年里面坐着两个彼此拉脱的事实。施派尔给了抗议一项帝国会议决议的诸侯与城市一个政治的名称，新教。马尔堡显示出，那些诸侯本可以与之结盟的神学家们，无法就圣餐说出同一句话。一套神学需要第二次会谈成功。它失败了。年份是共享的。结果却不是可以互换的。再加上苏黎世后来的历史，以及茨温利1531年在卡佩尔（Kappel）的战死，复数本身就已经是[[reformations/reformed-cities]]的故事。
:::

## 一个完整的案例：一个未被逮捕的法外之徒

把萨克森选帝侯当作案例来看，不当作圣徒来看。1521年5月之后，路德是一个法外之徒。在一个帝国法律描述世界的故事里，他要么被逮捕，要么逃亡。实际发生的却是领土性的庇护。他于1521年被藏了起来，随后回到萨克森重操一种公开生涯。诏书仍是诏书。这还不是《奥格斯堡和约》。1521年，没有人拥有为一块诸侯领地选择宗教的法律权利。选帝侯与诸侯能够阻挠与庇护。1356年的金玺诏书（Golden Bull）已经把选帝侯变成拣选皇帝的人。沃尔姆斯显出那部宪法的另一副面孔：他们选出的皇帝，并不能总是把他们当作警察来用。

这个案例同时也限制路德。他之所以有自由去谴责农民，是因为有一位领主庇护他。这种吻合并不证明纯粹的自利。但它确实禁止一种读法，即把沃尔姆斯当作抵抗权的诞生。同一片土地既产出一场受庇护的改革，也产出一场被粉碎的起义。

能够打破这个案例的，是《沃尔姆斯诏书》曾被一体执行的证据，或者农民曾赢得某种路德宣讲过的自由的证据。两者都不是记载。这个案例立在两个传说之间：门前的铁锤，与叛乱的天使。

## 反对意见

门之所以长存，是因为铁锤比流传好记。好记不是证据。梅兰希顿后来的故事不是那一天的日记。论纲需要读者、一所大学、一台印刷机和一位诸侯，这就是[[#thm-door]]。

下一个反对意见是那座全然败坏的教会。赎罪券的宣讲确实人人得而攻之。寻常的宗教也是真实的。钱箱不是整座教会，虔敬也不是无视钱箱的理由。从未成为路德宗的人，仍然要求驻任的主教与受过训练的神父。这个要求比1517年更古老。

第三个反对意见把沃尔姆斯变成宗教自由的诞生。它是在一纸安全通行证之下一个人对撤回的拒绝。它不是一条任何良心皆可随意出版的规则。对叛乱者的谴责，就是他自己著作中的反证。1555年的《奥格斯堡和约》仍然只是诸侯在路德宗与天主教之间的抉择，不是一项私人权利，而且它把改革宗排除在外。那个和约没有藏在论纲里面。

:::warning 门，与那座漫画式的教会
钉在维滕贝格门上的那件事是后来的故事。不要把它当作开篇的事实来讲。另一幅常见的图画，一座腐败透顶、没有堂区生活的教会，朝相反的方向失败。赎罪券是论纲的导因。它们不是路德批判的全部，也不是他所批评的那个拉丁教会的全部。一节课还需要铁锤或漫画的话，就根本还没有开工。
:::

:::quiz
在1529年的马尔堡，什么失败了？
- [ ] 路德与茨温利在圣餐上达成一致，建立了一座统一的新教教会
- [ ] 施派尔的帝国会议在全帝国废除了教皇制
- [x] 路德与茨温利没有在圣餐上达成一致，因此一个福音派同盟缺少一种共享的圣事教义
- [ ] 茨温利说服路德撤回了论纲
:::solution
施派尔与马尔堡都在1529年，它们不是同一个事件。施派尔提供了新教这个词，出自一次政治抗议。马尔堡则是那场圣餐使路德与茨温利分裂的会谈。在其他条款上的一致，没有弥合那道分裂。撤回论纲不是他们任何一人此行要做的事。
:::

:::history
《九十五条论纲》定年为1517年10月31日。它们流传了。它们被钉在维滕贝格教堂门上的故事出自梅兰希顿，并未确立。1521年4月，路德出席沃尔姆斯帝国会议并拒绝撤回。《沃尔姆斯诏书》随后发布于1521年5月。
:::

## 通向何处

苏黎世与日内瓦不是萨克森。茨温利1531年在卡佩尔的死，开启[[reformations/reformed-cities]]。那场答复路德、却不只是追赶路德的公会议，是[[reformations/catholic-reform]]。英格兰的法令是第三套宪法，在[[reformations/england]]。新教这个词挡不住的战争，以及后来读者读得过满的1648年和约，是[[reformations/religious-war]]。论纲的背后坐着[[crises/print]]，那个烧死胡斯的公会议在[[crises/war-and-schism]]，教皇的诸宣称在[[christendom/popes-and-kings]]。那些章节里没有任何一条是必然终结于1517年的道路。沃尔姆斯本可以以撤回收尾。马尔堡本可以以一致收尾。两者都没有。

:::summary
- 《九十五条论纲》定年为1517年10月31日，而且流传了。钉上教堂门是梅兰希顿后来的故事，并未确立。
- 赎罪券是暂罚的赦免，不是犯罪的许可证。它是争吵的导因，不是整个拉丁教会的画像。
- 1521年4月，路德在沃尔姆斯拒绝撤回。《沃尔姆斯诏书》在1521年5月。本图谱不发明他的话。
- 诸侯的庇护，而非诏书的执行，才是一个法外之徒得以继续著述的原因。这是一个关于帝国的事实，还不是抵抗权。
- 1524–1525年的农民战争属于这个故事。路德谴责了叛乱者。不给出死亡总数。
- 帝国军队于1527年洗劫罗马。洗劫是哈布斯堡与教皇的政治，不是路德的胜利。
- 1529年，新教是施派尔抗议带来的名称，而马尔堡是与茨温利的圣餐分裂。宗教改革已然复数。
:::

## 习题

:::exercise 年份数字计数 {level=1 check="4"}
从1517年到1521年，年份数字之差是多少年？（请输入年数。）
:::solution
本图谱对两个公元年份的规则是相减。1521减1517是4。这不是从十月三十一日到四月的月数，那个更短。年数是4。
:::
:::

:::exercise 共享的年份 {level=1 check="1529"}
提供了新教一词的抗议与马尔堡的会谈，都落在哪一年？（请输入年份。）
:::solution
两者都锁定在1529年。施派尔是抗议。马尔堡是圣餐上的分歧。年份是1529。
:::
:::

:::exercise 诏书的月份 {level=1 check="May"}
路德于1521年4月出席沃尔姆斯。《沃尔姆斯诏书》在1521年的哪个月份？（请输入月份。）
:::solution
帝国会议在1521年4月。宣布他为法外之徒的诏书在随后的那个月。月份是五月。
:::

:::exercise 导因与漫画 {level=2}
用几句话解释，一场赎罪券推销何以能是论纲的导因，而不构成拉丁教会的充分画像。
:::solution
就其自身含义而言，赎罪券赦免暂罚。它不出售犯罪的许可证，也不取代忏悔圣事。1517年那场与虔诚工程和诸侯收入相绑的宣讲，是真实的弊端，也是路德那些命题真实的导因。堂区、弥撒、善会与朝圣，环绕着那场推销继续存在。一份恶劣的赦免的证据，是关于赦免的证据。它没有显示教会再无别的宗教生活。本世纪晚些时候的天主教改革是实际的检验：留在旧教会里的人仍然认为它值得改革。
:::
:::

:::exercise 沃尔姆斯没有台词 {level=2}
一部教科书在沃尔姆斯帝国会议上给路德安上一句抗辩的句子。你可以改说什么，为什么那个结果已经足够？
:::solution
你可以说，1521年4月他被要求撤回而遭到拒绝，《沃尔姆斯诏书》于五月随之而来。这个结果是本图谱锁定的历史事实。人们喜爱的那些句子不在年表里，发明它们会把一场帝国会议变成一台戏。拒绝解释了为什么需要一道诏书。后来传说里的话，解释不了任何拒绝尚未解释的东西，而且无法对照本课的史料加以核对。
:::
:::

:::exercise 福音语言的两种使用 {level=2}
《十二条款》与路德对叛乱者的谴责，在1525年怎么能够都是“福音的”？这对那个词的单一含义做了什么？
:::solution
那些条款用福音的语言来检验地租、农奴身份与选立牧师之权。路德用《圣经》和他关于世俗秩序的教义谴责拿武器的臣民。同一套宗教词汇，一场起义用得，它的对手也用得。那一年，福音的并不命名某一个社会纲领。它命名的是一次有争议的诉诸福音。农民战争正是证据，表明这次诉诸已经超出那位教授的掌控，而他试图把它拉回来。
:::
:::

:::exercise 诸侯作为原因 {level=3}
反对意见：德意志宗教改革不过是诸侯的夺产，论纲只是一块幌子。把这条反对意见论证到它能被论证的最强程度，然后说出什么证据使它成不了全部的原因。
:::hint
把沃尔姆斯、各城市与农民战争保持在同一个回答里。幌子理论必须解释，谁真的相信那场宣讲，又有谁因为拿它对付领主而被碾碎。
:::
:::solution
强版本是真实的。诸侯与贵族后来夺取了修道院地产，而萨克森对路德的庇护自始就是政治的。一位能增加诸侯脱离罗马之独立性的神学，是有用的。从1555年的《奥格斯堡和约》倒读，夺产看起来就像剧情。

它不是全部的原因。1521年4月，路德是一个法外之徒，不是没收行动的执掌者。各城市在议会之下改变崇拜，那里的奖品不是选帝侯的新产业。1525年的农民把福音语言用来反对领主，路德谴责了他们。纯粹的夺产解释不了那次谴责，也解释不了马尔堡的圣餐分裂，那里茨温利一方是一座城市，而不是选帝侯的库藏。诸侯利益是一个原因。它不是文本的替代品。这条反对意见只有在枢密衙门之外没有人认真对待那些宗教论辩时，才会成为全部的原因。马尔堡之所以召开，正是因为他们认真对待了。
:::
:::

:::exercise 提升一件史料，或者拒绝它 {level=3}
有人递给你一张无日期、出自十九世纪某人之手的纸条，上面只说：“门，正如梅兰希顿所讲的那个版本。”一位同学想援引它作为钉门的佐证。你怎么回答？什么样的发现才真的能移动[[#thm-door]]？
:::hint
把梅兰希顿故事的后来复述，与1517年10月31日的证人分开。然后说出，同时代的、独立的、可核对的各是什么意思。
:::
:::solution
那张纸条只能佐证门的故事为一位后来作者所知，而它指向梅兰希顿，那正是这个故事已经起始的地方。十九世纪的手迹不可能看见1517年。[[#thm-door]]只会为这样一份记录而移动：同时代的、不衍生自梅兰希顿的、报告了钉门之举、并且能够对照流传文本加以核对的记录。在此之前，确立的那句话保持简短：论纲定年为1517年10月31日，而且它们流传了。那位同学的引文属于传说的历史。
:::
