关于1517年10月31日，哪些是确立的，哪些不是？《九十五条论纲》的落款日期正是这一天；论纲是真实的文本，而且流传开来。至于马丁·路德（Martin Luther）把论纲钉在维滕贝格（Wittenberg）城堡教堂门上的故事，则是后来由菲利普·梅兰希顿（Philip Melanchthon）讲述的，并未确立。一组学术命题所署的日期，与一幅手持铁锤的场景，不可混为一谈。本章只讲能够定年的事：论纲、沃尔姆斯（Worms）帝国会议、农民战争、罗马之劫，以及马尔堡（Marburg）的分裂。

用单数的“宗教改革”来称呼这些年代，已很不贴切。路德拒绝撤回主张，并没有产生单一的教义、单一的教会，或宣讲者与诸侯之间单一的关系。到1529年，他与茨温利（Huldrych Zwingli）仍未能在圣餐问题上达成一致。“新教”（Protestant）一词也出现在同一年，它指的是帝国政治中的一次抗议，而非某一种信条。下一章讲维滕贝格以外的城市宗教改革；再下一章讲天主教改革，它并不仅仅是对路德的回应。

## 一个日期、一份文本与一个后来的故事

维滕贝格是萨克森选帝侯国的一座大学小城，路德是奥斯定会修士，也是神学教授。论纲采用学术论辩的形式：用拉丁文写成、供学者争辩的编号命题，既不是面向民众的讲道，也不是新教会的章程。这个日期所确立的是作者身份与流传情况。抄本以印刷和手抄两种形式流出大学。印刷起了放大作用，本身却不是原因。德文《圣经》早已有之，而印刷本拉丁文《圣经》一般定年于约1454–1455年，比论纲早两代人。这项技术见[[crises/print]]。印刷机能够传播一场已在进行的争论，却不能决定这场争论的意义。

:::definition 《九十五条论纲》 {#def-theses}
**《九十五条论纲》**是为一场学术论辩提出的命题，落款日期为1517年10月31日。作为流传开来的文本，它是确立的；作为钉在维滕贝格教堂门上的告示，它并未确立。门前一幕是梅兰希顿后来讲的故事。即便大学确有张贴论纲的惯例，这一惯例也不能为当天作证。
:::

论纲的起因是赎罪券（indulgence）的宣讲。其要旨在于追问：教皇的赎罪券能否惠及炼狱中的灵魂，金钱能否代替悔罪，以及教皇若真有宣讲者所称的权能，为何不无偿清空炼狱。这里转述的是论证的思路，而非原文。这些命题仍处在拉丁教会之内，争论的是告解、教皇与牧灵职责；它们尚未否定全部圣事，也不是德意志诸侯的政治纲领。决裂是在此后的论争中扩大的：路德被一步步从一项具体做法推向教皇与公会议的权威问题。

这一扩大触及康斯坦茨（Constance）公会议自以为已经弥合的旧伤。该公会议从1414年开到1418年；扬·胡斯（Jan Hus）于1415年被处以火刑；始于1378年的西方教会大分裂，以1417年马丁五世（Martin V）当选而告终。在论纲引发的论争中，路德被逼到承认教皇与公会议都可能犯错。于是，一个被公会议烧死的人成了先例，而不再是已结之案。康斯坦茨公会议本身见[[crises/war-and-schism]]。这里的论点更窄：论纲是一场公开论争的开端，既不是路德后来教导的全部，也不是各地宗教改革的全部。

:::theorem 1517年10月31日确立了什么 {#thm-door}
这一天确立的是一份有日期并流传开来的文本，而没有确立路德把论纲钉在教堂门上。钉门的故事出现得晚，来自梅兰希顿，并非对此举的同时代记载。
:::
:::proof
支持文本的证据，是论纲本身及其流传。反对钉门一幕的证据，在于这个故事的形态：它讲得晚，讲述者并没有在1517年10月31日记下日记。张贴论纲的惯例使这一幕显得可信，但可信并非证词。能够推翻[[#thm-door]]的，是一位独立于梅兰希顿、记录当天钉门之举的同时代证人；这样的证人并未确立。能够推翻前半句的，是论纲从未流传的证据，而流传恰恰是已经确立的那一半。门前的一幅图画，凭空添上一个我们拿不出证据的行为，又遮蔽了印刷、大学与诸侯。
:::

:::quiz
关于1517年10月31日，哪一项是确立的？
- [ ] 路德把《九十五条论纲》钉在城堡教堂门上，锤声开启了宗教改革
- [x] 论纲的落款日期是这一天，而且流传开来；钉门是后来的故事，并未确立
- [ ] 关于论纲一无所知，这个日期是十九世纪编造的
- [ ] 论纲是一篇德文讲道，当天下午就废除了教皇制
:::solution
文本及其流传是既定事实。梅兰希顿讲的钉门一幕出现得晚，并未确立。论纲是为学术论辩写的拉丁文命题，既不是一天之内创立教会的讲道，也不是一张任凭后世随意填写的白纸。
:::
:::

## 赎罪券是起因，而非整个教会

按照拉丁教会的教导，赎罪券是对罪之暂罚（temporal penalty）的赦免。它不是犯罪的许可证；按此教导，它也不是出售罪咎的赦免，罪咎的赦免属于痛悔与告解圣事。暂罚是此后仍然留存的部分，其中包括与炼狱相关的暂罚。宣讲者把赎罪券与为虔诚事业捐献捆绑在一起宣讲，罗马圣彼得大教堂的重建就是这样一项事业。特策尔（Johann Tetzel）在美因茨的阿尔布雷希特（Albert of Mainz）的教省内宣讲赎罪券，阿尔布雷希特身兼美因茨大主教与马格德堡大主教。正是这次推销引出了论纲。这里不给出具体钱数：弊端在于宣讲的结构，而不在某个本图谱未能锁定的数字。

:::definition 赎罪券 {#def-indulgence}
**赎罪券**是凭借教皇所宣称的权威，对罪之暂罚的赦免。它不是犯罪的许可证，也不能完整描述中世纪晚期的宗教。1517年，它是路德公开论争的起因，而不是他后来全部批判的内容，更不能据此把教会描绘成别无宗教生活的漫画。
:::

这种漫画正是本章要拒绝的错误。在这几十年里，拉丁基督教的生活还包括堂区弥撒、宗教善会、朝圣、慈善与为亡者祈祷。一场声称买者已为炼狱中的灵魂赎得解脱的推销，尽可加以攻击，而无须假装每座祭坛都是店铺。[[reformations/england]]中迪菲（Duffy）对英格兰的提醒同样适用于此：批评一种做法，不等于给一座死去的教会拍照。[[reformations/catholic-reform]]所讲的天主教改革，如果旧教会内部除了回应新教之外别无值得改革之处，就无从理解。

论纲本身并不止于钱箱。它们把宣讲与悔罪、与教皇权力的界限、与一种让恩典显得廉价的赦免所造成的丑闻联系起来。论争一旦涉及权威，就不再只是对某位宣讲者的地方性抱怨。为赎罪券辩护的人反驳说，路德误解了一套正当的神学，并且侮辱了教皇。在沃尔姆斯之前的几年里，路德的回应是不断扩大阵地：先以《圣经》反对宣讲者，再以《圣经》反对教皇或公会议不会犯错之说。本章不为这些步骤指定年表未锁定的年份，要紧的是方向。到他出现在沃尔姆斯时，他已被处以绝罚。帝国会议不是论争的第一天，而是论争与皇帝正面相遇的那一天。

:::example 关于钉门的一句虚构的话 {#ex-invented-door}
请读下面这句话，它是虚构的，不是史料：“1517年10月31日，路德把《九十五条论纲》钉在教堂门上，并对人群说，他宁可相信自己的良心，也不相信教皇。”这句话里有哪些内容（如果有的话）是确立的？要把其余部分提升为证据，需要什么？
:::solution
只有论纲的日期，以及当时确有一份署此日期的文本可供谈论，触及确立的事实。钉门是后来的故事，不能当作事实来讲。对人群讲话是虚构的。路德说过什么，无论在门前还是在沃尔姆斯，都轮不到我们代为补写。要把钉门提升为证据，史家需要一位独立于梅兰希顿后来记述的同时代证人；要把那番话提升为证据，需要的是确有其言的记录，而不是为渲染场面而写下的句子。论纲的流传可以由抄本证明，人群、铁锤与格言则不能。
:::
:::

## 沃尔姆斯：一次拒绝，而非一出戏

1521年4月，路德出席沃尔姆斯帝国会议，由查理五世（Charles V）亲自主持。他被要求撤回主张，他拒绝了。这次拒绝就是本图谱要陈述的结果。后人附会在这一幕上的名句，不是我们能够引用的原话，本章也不会编造。一纸安全通行证保证他到会，也准许他离开。1521年5月的《沃尔姆斯敕令》宣布他为帝国的法外之徒。法外地位是一个法律事实，但在萨克森，它并不等于逮捕。

敕令与逮捕之间的落差，是第一代人的政治现实。萨克森选帝侯弗里德里希（Frederick）庇护了本国大学的这位教授。1521年，路德被安置在瓦尔特堡（Wartburg），置于这种庇护之下。他利用这段隐居把《新约》译成德文。他并不是第一个把《圣经》译成德文的人；这部译本之所以重要，是因为他此时已有的身份，也因为印刷能够大量复制它。本章不把这部译本的出版定在年表未锁定的年份。一个已宣布他为法外之徒的帝国，不能或不愿把他从一位诸侯手中带走。查理五世同时统治着一连串王国，这一点见[[states/composite-monarchy]]；他1556年的退位还在遥远的将来。在沃尔姆斯，他无法迫使每一位选帝侯接受同一部宗教法律。

:::example 从论纲到沃尔姆斯 {#ex-span-worms}
论纲的落款日期是1517年10月31日，帝国会议在1521年4月。两者的年份数字相差多少年？为什么这与从十月到四月的跨度不是一回事？（请输入年份数字之差。）
:::solution
对于两个公元年份，本图谱把从A年到B年经过的年数取作B减A。从1517年到1521年，这个数是4。从1517年10月31日到1521年4月的某一天，则是三年又约六个月，因为从十月到四月不满第四年。“四年之后，在沃尔姆斯”这样的说法，用的是年份数字之差，把十月的日期拉长到了四月的日期。只要说明问的是哪个问题，两个数字都可以是对的。按年份数字计算，年数是4。
:::
:::

沃尔姆斯之后，论争不再只是一个修士的案子。宣讲者、市议会与部分诸侯开始改变礼拜。萨克森的庇护使路德得以继续公开活动，却没有使他成为帝国的主教。苏黎世（Zurich）的茨温利早已走上另一条路。1529年在马尔堡，分裂已确凿无疑。

## 农民战争是这段历史的一部分

1524年至1525年，一场大规模起义席卷德意志各邦，史称农民战争。参加者并不只有农民，正如1381年的英格兰起义也不只有农民。平民、乡村居民与部分市民起来反抗领主，怨愤交织着地租、农奴身份、林地与公地的使用权以及选立牧师之权。1525年广为传抄的《十二条款》，用福音的语言表达了其中一些诉求：以《圣经》检验领主，减轻负担，准许共同体自选牧师。这里转述的是这类要求的种类，并不假定这些条款是某一支队伍的某一份宣言。这场起义实为许多场起义。

路德谴责了起义者。他曾在沃尔姆斯拒绝教皇与皇帝，却不为拿起武器反抗领主的臣民辩护。他所作的区分大致是：一边是无须改造法律的基督徒自由，一边是臣民不得以福音之名推翻的世俗秩序。诸侯镇压了起义，镇压十分残酷。本图谱不给出死亡总数。站在起义一方的宣讲者托马斯·闵采尔（Thomas Müntzer），在1525年弗兰肯豪森（Frankenhausen）战败后被处死，这里不描述处死的方式。我们保留的是两相对照的事实：起义者可以借用福音的语言，而路德用尽这套语言来反对他们。

:::proposition 沃尔姆斯并非臣民的特许状 {#prop-peasants}
路德1521年4月拒绝撤回主张，并不意味着臣民有权以武力推行福音。他在1524–1525年农民战争中对起义者的谴责就是证据，它与沃尔姆斯同属一个人的生平。
:::
:::proof
证据是年表锁定的先后顺序：先是在沃尔姆斯的拒绝，后是对起义的谴责。在沃尔姆斯，一位被传召的神学家拒绝收回自己的教导；1525年，臣民攻击领主，而他站在领主一边。能够推翻[[#prop-peasants]]的，是他在起义那几年写下的、把武装起义辩护为他所坚持的福音之必然结果的文字。他发表的并非这样的文字。略过这场战争，关于自由的画像就经过了删改；若只把谴责当作唯一的事实，又无法解释一个法外之徒为何值得庇护。两个事实同时成立。
:::

萨克森的弗里德里希死于1525年，正值战争期间，但选帝侯国的庇护并未随他而终。一位诸侯的去世、一场社会战争与一项神学谴责可以同在一年，却不是同一个事件。

:::example 沃尔姆斯与农民战争的并置 {#ex-side}
把1521年4月与1524–1525年并置。一部标明为虚构的编年史写道：“路德在沃尔姆斯与一切权威决裂，随即率领农民反抗领主。”真实日期的并置，对这句话意味着什么？
:::solution
真实的日期把一次拒绝与一次谴责放进同一个人的生平，相隔数年；从1521年到1525年，年份数字之差为4。虚构的句子把两者压缩成“反对一切权威”这一种姿态，又编造出路德从未担当的领导角色。他拒绝在皇帝面前撤回主张；当起义者与领主交战时，他谴责了他们。并置本身就是更正。只知沃尔姆斯的读者会误读1525年，只知谴责的读者会误读沃尔姆斯。本图谱两者兼存。
:::
:::

## 罗马、施派尔与马尔堡

1527年，帝国军队洗劫了罗马。教皇克雷芒七世（Clement VII）此前在意大利与查理五世为敌。这支军队属于皇帝，欠饷已久，成分混杂，其中有听过福音派宣讲的德意志士兵。洗劫使教皇蒙羞，却没有确立路德的教义，查理也没有把它当作神学示威来下令。他仍是一位天主教君主，而在沃尔姆斯被宣布为法外之徒的那个人也不是统帅。皇帝与教皇可以一面共同拒斥路德，一面彼此交战。英格兰方面的后果见[[reformations/england]]：一位遭皇帝重创的教皇，很难宣告皇帝姑母的婚姻无效。

:::theorem 已然不止一场宗教改革 {#thm-marburg}
到1529年，福音派运动在圣餐问题上已有不止一种教义，马尔堡会谈就是标志：路德与茨温利未能达成一致。同年施派尔（Speyer）的抗议产生了“新教”一词，但这个名称并不能抹去这道裂痕。
:::
:::proof
1529年，施派尔帝国会议着手执行《沃尔姆斯敕令》，福音派诸侯与城市提出抗议，“新教”之名即由此而来，它是帝国法律中的一个词。同年，黑森的菲利普（Philip of Hesse）把路德与茨温利请到马尔堡。两人在许多问题上能够一致，在圣餐问题上却不能。路德主张，基督的身体与血真实地在饼和酒中赐下；茨温利不这样认为。这里陈述分歧，不补写对话。会谈的失败就是[[#thm-marburg]]的证据。能够推翻它的，是一份记载两人陈述同一教义的协议，或是一个无须这种一致的同盟。会谈之所以召开，正是因为缺少一致；同盟也没有随之而来。“新教”这个名称并不能告诉你，一个人对圣餐持何种信仰。
:::

:::corollary 名称不等于教义 {#cor-protestant}
1529年以后称某位诸侯、某座城市或某位宣讲者为新教徒，标明的是他在帝国论争中的立场，而不是某种圣餐教义，也不是日内瓦式的改革宗教会。
:::
:::proof
施派尔的抗议针对的是一项会议决议，而不是为圣餐问题定论而起草的信条。路德与茨温利可以同在抗议一方，却仍在马尔堡分道扬镳。能够推翻这一推论的，是施派尔在1529年接受的、为每个抗议等级统一规定圣餐教义的信条，而这样的信条并不存在。1555年9月25日的《奥格斯堡和约》仍须写明帝国承认哪些教义，该和约见[[reformations/religious-war]]。一个1529年诞生的词，承担不了教会规章的职能。
:::

:::example 同一年的两个事实 {#ex-1529}
施派尔与马尔堡都发生在1529年。从1517年的论纲到这一年，年份数字之差是12。为什么把1529年当作“新教”获得一套神学的年份是错误的？
:::solution
十二年，即1529减1517之差。这第十二年里有两个相互背离的事实。施派尔为抗议帝国会议决议的诸侯与城市提供了一个政治名称：新教。马尔堡则表明，这些诸侯本可与之结盟的神学家们，在圣餐问题上说不出同样的话。要有一套统一的神学，第二次会谈就必须成功，而它失败了。年份相同，结果却不能互换。再加上苏黎世此后的历史，以及茨温利1531年在卡佩尔（Kappel）战死，宗教改革的复数形态已是[[reformations/reformed-cities]]的内容。
:::

## 一个完整的案例：未被逮捕的法外之徒

把萨克森选帝侯当作一个案例，而不是一位圣徒来看。1521年5月以后，路德是法外之徒。假如帝国法律就是现实，他要么被捕，要么出逃。实际发生的却是领地的庇护：他在1521年被藏匿起来，随后回到萨克森继续公开活动。敕令依然有效。这时还没有《奥格斯堡和约》，1521年没有人享有为一块诸侯领地选择宗教的法定权利；选帝侯与诸侯能做的是阻挠和庇护。1356年的《金玺诏书》（Golden Bull）已使选帝侯成为选举皇帝的人。沃尔姆斯显示了这部宪制的另一面：他们选出的皇帝，未必总能把他们当作警察来驱使。

这个案例同时也限定了对路德的理解。他之所以能自由地谴责农民，是因为有一位领主庇护他。这种契合并不证明他纯出私利，却足以排除一种读法，即把沃尔姆斯视为抵抗权的诞生。同一片土地上，既有一场受到庇护的宗教改革，也有一场被镇压的起义。

能够推翻这个案例的，是《沃尔姆斯敕令》曾被一体执行的证据，或是农民争得了路德所宣讲的某种自由的证据。史料中两者皆无。这个案例处在两个传说之间：门前的铁锤，与起义的天使。

## 反对意见

钉门的故事之所以经久不衰，是因为铁锤比流传更容易记住。容易记住不等于证据。梅兰希顿后来讲的故事不是当天的日记。论纲需要读者、大学、印刷机和诸侯，这就是[[#thm-door]]。

另一种反对意见认为教会已彻底腐败。赎罪券的宣讲确实招致普遍攻击，但日常的宗教生活同样真实。钱箱不是整个教会，虔诚也不是对钱箱视而不见的理由。从未改宗路德宗的人，同样要求主教驻守教区、神父受过训练，而这一要求早于1517年。

第三种反对意见把沃尔姆斯说成宗教自由的诞生。实际上，那是一个人在安全通行证保护下拒绝撤回主张，而不是任何良心都可随意出版的规则。他对起义者的谴责，就是其本人著作中的反证。1555年的《奥格斯堡和约》仍只是让诸侯在路德宗与天主教之间选择，并非个人权利，而且把改革宗排除在外。这项和约并不潜藏在论纲之中。

:::warning 钉门与漫画式的教会
把论纲钉在维滕贝格教堂门上，是后来的故事，不要把它当作开篇的事实来讲。另一幅常见的图画，即一座腐败透顶、毫无堂区生活的教会，则从相反方向失误。赎罪券是论纲的起因，但既不是路德批判的全部，也不是他所批评的拉丁教会的全部。一堂课若还离不开铁锤或漫画，就根本还没有开始。
:::

- [x] 路德与茨温利未能在圣餐问题上达成一致，因此福音派同盟缺少共同的圣事教义

施派尔与马尔堡都在1529年，但不是同一事件。施派尔的政治抗议提供了“新教”一词；马尔堡则是路德与茨温利因圣餐而分裂的会谈。在其他条款上的一致，没有弥合这道裂痕。撤回论纲也不是两人赴会的目的。

:::history
《九十五条论纲》的落款日期为1517年10月31日，并且流传开来。论纲被钉在维滕贝格教堂门上的故事出自梅兰希顿，并未确立。1521年4月，路德出席沃尔姆斯帝国会议并拒绝撤回主张，随后于1521年5月颁布了《沃尔姆斯敕令》。

## 通向何处

苏黎世与日内瓦不同于萨克森。茨温利1531年在卡佩尔战死，开启了[[reformations/reformed-cities]]。那次回应路德而又不只是追随路德议程的公会议，见[[reformations/catholic-reform]]。英格兰的议会法令构成第三种宪制，见[[reformations/england]]。“新教”一词未能阻止的战争，以及后世读者解读过度的1648年和约，见[[reformations/religious-war]]。论纲的背景是[[crises/print]]；烧死胡斯的公会议见[[crises/war-and-schism]]；教皇的种种主张见[[christendom/popes-and-kings]]。这些章节都不是注定通向1517年的道路。沃尔姆斯本可能以撤回告终，马尔堡本可能以一致告终，两者都没有发生。

:::summary
- 《九十五条论纲》的落款日期为1517年10月31日，并且流传开来。钉门是梅兰希顿后来的故事，并未确立。
- 赎罪券是对暂罚的赦免，而不是犯罪的许可证。它是论争的起因，而不是整个拉丁教会的写照。
- 1521年4月，路德在沃尔姆斯拒绝撤回主张；《沃尔姆斯敕令》颁布于1521年5月。本图谱不编造他的话。
- 一个法外之徒之所以能继续著述，靠的是诸侯的庇护，而不是敕令的执行。这是关于帝国的事实，还谈不上抵抗权。
- 1524–1525年的农民战争是这段历史的一部分。路德谴责了起义者。本图谱不给出死亡总数。
- 1527年，帝国军队洗劫罗马。这是哈布斯堡与教皇之间的政治，而不是路德的胜利。
- 1529年，“新教”之名来自施派尔的抗议，马尔堡则是与茨温利在圣餐问题上的分裂。宗教改革此时已是复数。
:::

:::exercise 起因与漫画 {level=2}
用几句话说明：为什么一场赎罪券推销可以是论纲的起因，却不足以充当拉丁教会的完整写照。
:::solution
按其本义，赎罪券赦免的是暂罚，既不出售犯罪的许可证，也不取代告解圣事。1517年那场与虔诚工程和诸侯收入捆绑在一起的宣讲，是真实的弊端，也是路德提出那些命题的真实起因。堂区、弥撒、善会与朝圣，在这场推销周围照常存在。一项恶劣赦免的证据，只是关于这项赦免的证据，并不表明教会别无宗教生活。本世纪稍后的天主教改革就是实际的检验：留在旧教会中的人仍然认为它值得改革。
:::
:::

:::exercise 沃尔姆斯没有台词 {level=2}
一本教科书在沃尔姆斯帝国会议上给路德安排了一句抗辩名言。你可以改用什么说法？为什么这个结果已经足够？
:::solution
可以说：1521年4月，他被要求撤回主张而予以拒绝，五月随即颁布了《沃尔姆斯敕令》。这个结果是本图谱锁定的历史事实。人们喜爱的那些名句不在年表之中，编造它们会把一次帝国会议变成一出戏。拒绝本身就解释了为何需要一道敕令；后来传说中的话，解释不了拒绝未曾解释的任何东西，也无法用本课的史料核对。
:::
:::

:::exercise 福音语言的两种用法 {level=2}
1525年，《十二条款》与路德对起义者的谴责怎么可能都是“福音的”？这对该词的单一含义意味着什么？
:::solution
《十二条款》用福音的语言来检验地租、农奴身份与选立牧师之权；路德则依据《圣经》和他关于世俗秩序的教义谴责拿起武器的臣民。同一套宗教词汇，起义者可用，其反对者也可用。在那一年，“福音的”并不指向某一种社会纲领，而是指一种有争议的对福音的援引。农民战争正好证明，这种援引已经超出那位教授的掌控，而他试图把它收回。
:::
:::

:::exercise 诸侯作为原因 {level=3}
反对意见：德意志宗教改革不过是诸侯的夺产，论纲只是幌子。请把这一反对意见论证到最有力的程度，再指出哪些证据使它不能成为全部的原因。
:::hint
在同一个回答里兼顾沃尔姆斯、各城市与农民战争。幌子论必须解释：谁真正相信那些宣讲，谁又因为用它反抗领主而遭到镇压。
:::
:::solution
最有力的版本确有其实。诸侯与贵族后来夺取了修道院地产，萨克森对路德的庇护从一开始就带有政治性。一种能增强诸侯对罗马的独立性的神学，自然有用。从1555年的《奥格斯堡和约》倒推回去，夺产看起来就像整个剧情。

但它不是全部的原因。1521年4月，路德是法外之徒，而不是主持没收的人。各城市在市议会主持下改变礼拜，那里的收获并不是选帝侯的新产业。1525年，农民用福音的语言反抗领主，路德谴责了他们。单纯的夺产说既解释不了这一谴责，也解释不了马尔堡的圣餐分裂，而在马尔堡，茨温利一方是一座城市，不是选帝侯的府库。诸侯利益是原因之一，却不能取代文本。只有在宫廷枢密院之外无人认真对待那些宗教论辩时，这一反对意见才能成为全部的原因。马尔堡会谈之所以召开，恰恰因为他们认真对待了。
:::
:::

:::exercise 提升一件史料，或者拒绝它 {level=3}
有人递给你一张没有日期、出自十九世纪某人之手的纸条，上面只写着：“钉门，按梅兰希顿所讲的版本。”一位同学想引用它来佐证钉门之事。你如何回应？什么样的发现才真正能动摇[[#thm-door]]？
:::hint
把对梅兰希顿故事的后来复述，与1517年10月31日的证人区分开来，再说明“同时代的”“独立的”“可核对的”各指什么。
:::
:::solution
这张纸条最多只能证明，某位后来的作者知道钉门的故事，而它所指向的梅兰希顿，正是这个故事的源头。十九世纪的手迹不可能见证1517年。只有这样一份记录才能动摇[[#thm-door]]：它是同时代的，不源自梅兰希顿，记载了钉门之举，并且能与流传的文本相互核对。在此之前，确立的说法仍然简短：论纲的落款日期为1517年10月31日，并且流传开来。那位同学的引文属于传说的历史。
:::
