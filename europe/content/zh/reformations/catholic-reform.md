反宗教改革（Counter-Reformation）这个名字掩盖了什么？它掩盖了天主教改革中不是对新教答复的那一半，保留了是答复的那一半。两半都为真。旧的标签只保留第二种。从1545年到1563年，一次在特兰托（Trent）的公会议定义教义、改革实践，中间有一段长期的休会，它没有开会。新的修会，包括耶稣会（Society of Jesus）在内，属于同样的年份。本图谱不给那些修会一个创立年份。1555年9月25日，帝国缔结了一个公会议不会称之为真理的和平。一个和平与一次公会议，回答的是不同的问题。

拉丁教会内部的改革比1517年更古老。克吕尼（Cluny）的通常年代是公元910年。西多（Cîteaux），西多会的起点，是1098年。康斯坦茨（Constance）公会议从1414年开到1418年，并于1415年烧死胡斯，那是被用作统一工具的公会议，不是新教的发明。对驻任主教与识字教士的要求，不是作为对路德的答复开始的。作为答复开始的，是针对论纲以来已经传播的那些教导画出教义界线。一个诚实的名字给两句话都留了位置。反宗教改革只给一句留了位置。

## 一次中间有间隔的公会议

特兰托于1545年开幕，于1563年闭会。年份数字之差是18。十八不是十八年的连续辩论。本图谱的年表把那次中断称为会期之间的长期休会，本课不得用一个它没有锁定年份的清单来替代那段休会。主教们难以集齐。皇帝与教皇想要的不是同一个公会议。查理五世（Charles V）想要教廷的改革，以及一条让帝国等级回来的路。教廷想要教义被定义，并且在教皇的主持下被定义，而不是被一个可能重演康斯坦茨凌驾教皇之宣称的公会议重新打开。大君主国之间的战争，以及选择一个双方都受得了的城市，造成了其余的部分。查理于1556年退位，在公会议结束之前。前一年的和平在帝国已经生效。特兰托在一个不同的教皇与一个不同的皇帝治下闭会，而非当年开启那场争论的那些人。

:::definition 天主教改革 {#def-catholic-reform}
**天主教改革**是在拉丁教会内部、尤其贯穿1545年到1563那些年岁的努力：定义教义，改变主教与教士的生活，创立或更新修会。它包括对新教教导的回应。它不只是那种回应。这个名字不意味着“一切答复了路德的东西”，也不意味一座新教会。
:::

:::definition 反宗教改革 {#def-counter}
**反宗教改革**是后来史家给那场努力中回应性一半贴的标签：论战、审查，以及从新教教会手中收复领土与人。用作整体的名字时，它掩盖了驻任、修院、旧修会的改革，以及面向从未当过新教徒之人的传教。耶丁（Hubert Jedin）的公式，天主教改革与反宗教改革，是提醒：两半需要两个词。
:::

公会议所决定的东西可以被转述，而且不得假装成引文。论《圣经》，它认定福音经书写成的书籍与保存在天主教会中的口传传统一同传递，并把古老的拉丁文《武加大译本》（Vulgate）奉为公共教导的权威文本。这是对“唯独圣经”的拒绝，按新教徒们后来使用它的方式。论称义，它教导罪人因上帝的恩典、为基督的缘故被称为义，信心是救恩的开端，同时拒绝这样的主张：唯独信心，若无望德、爱德与各圣事，便是全部的说法。在那道法令里，称义者的善工不是附带议题。论圣事，它保留七件，并教导它们赋予恩典。论圣餐，它肯定体变说（transubstantiation）。那排除了纯粹象征主义的读法。它也拒绝把路德宗的真实临在（real presence）当作充分，而路德宗的立场本身已经拒绝体变说。改革宗的教导，自1529年马尔堡以来已经自成一格，离特兰托的公式更远。参看[[reformations/luther]]与[[reformations/reformed-cities]]。

实践的改革是另一堆法令，它不是第一堆的掩护故事。主教们要驻任、宣讲、巡视。一人同时持有多个圣俸（benefice）受到限制。每个教区要在一座修院（seminary）里培训教士。一项婚姻，若要有效，须在堂区神父与证人之前缔结，以对付旧日的秘密婚约问题。这些规则没有一条需要一位新教邻居才能被理解。一个念不成弥撒的教士，一个从不巡视自己教区的主教，是中世纪的抱怨。特兰托重复它们时，它们仍是天主教改革。

:::theorem 标签只保留了回应 {#thm-label}
天主教改革是对新教教导的回应，而且它不只是回应。反宗教改革这个名字保留前半，掩盖后半。两半对于特兰托与新的修会都是必需的。
:::
:::proof
回应的一半，见于刚才转述的教义法令。它们针对唯独信心称义、针对《圣经》作为福音的唯一渠道、针对任何不肯说体变说的圣餐，画出界线。那些界线有对手，对手就是1517年以来这几十年间的诸教会。另一半见于驻任、修院、婚姻法，也见于那些在无新教可反之处照样传教的修会。能够构成对[[#thm-label]]的反证的，是一次只定罪、从不改革教士的公会议，或是一次只重复十五世纪忠告、从不点名新教义的公会议。特兰托两样都做。同样能够构成反证的，是一种已经把修院与传教不遮不掩地包括进来的“反宗教改革”用法。寻常的用法不是这样。它的意思是“天主教的答复”，而答复只是记载的一半。
:::

:::example 十八年，不是十八个会期 {#ex-span-trent}
特兰托于1545年开会，于1563年结束。差是多少年，为什么不得把公会议当作在这全部年份里都在忙碌？
:::solution
1563减1545是18。年表把那次中断称为会期之间的长期休会。这十八年里，有些是开会的年份，有些是停止、战争，以及一位不想让集会待在原地的教皇或皇帝的年份。查理五世于1556年退位，在跨度之内、结局之前。1555年9月25日的《奥格斯堡和约》也落在其中。连续的公会议不会有一段需要解释的间隔，也不需要缺席的政治。年数是18。
:::
:::

## 没有创立年份的新修会

耶稣会士、嘉布遣会士（Capuchins）、乌尔苏拉会（Ursulines）、改革了的加尔默罗会（Carmelites），以及腓力·内里（Philip Neri）的祈祷所（Oratory），不是一个项目穿五身制服。与依纳爵·罗耀拉（Ignatius of Loyola）相联系的耶稣会，把其会士在传教事务上对教皇的特殊服从作为约束，办学院，并以一套结构化的退省、即《神操》（Spiritual Exercises），作为一种有章法的操练。方济各·沙勿略（Francis Xavier）这个名字，使该会成不了只剩一桩欧洲警务：他的传教沿伊比利亚海路向外，面向的不是走了歧路的路德宗徒。嘉布遣会是方济各会在宣讲与神贫上的改革。乌尔苏拉会以女子教育为职事，这一点足以拦住一个把天主教改革只讲成牧师故事的说法。加尔默罗会更新了一个旧修会。祈祷所把在俗教士聚集起来过共同生活。它们合在一起与特兰托同时代。这就是本图谱允许的年份主张。

:::proposition 同时代，且不再进一步定年 {#prop-orders}
新的修会，包括耶稣会士在内，是天主教改革的一部分，与1545年到1563年的公会议同时代。创立年份没有在年表里锁定。印出一个创立年份的教科书，添加了一个本课不会使用的数字。
:::
:::proof
正面的证据是工作本身，摆在公会议的年份旁边：学院、传教、宣讲与教士培养，就是天主教改革在不是法令之时的模样。负面的证据是本图谱的规则。年表没有锁定年份的地方，本课不发明替代品。能够构成对[[#prop-orders]]的反证的，是一条为耶稣会定年、并授权那个数字的年表条目。没有这样的条目。能够构成对第一句的反证的，是这些修会只是反新教的队伍、没有学校、在基督教欧洲之外没有传教、也没有修会生活之改革的证据。沙勿略的传教、乌尔苏拉会的学校、嘉布遣会回到方济各会实践的回归，正是相反的东西。它们也在德意志、法兰西与帝国，是一种回应。这条论断说的是同时代、是天主教改革的一部分。它没有说“未受路德触动”。
:::

:::example 页面上不得提供的那个日期 {#ex-no-year}
一道虚构的考题写着：“给出耶稣会的创立年份，并引用特兰托答复它的那道法令。”为什么本图谱拒绝这个问题的两半？
:::solution
创立年份没有锁定。给出一个，哪怕是有名的一个，就是发明一个数字。正确的句子是：新修会与特兰托同时代，且这里不给出创立年份。法令是陷阱的另一半。特兰托的决定可以被转述：《圣经》与传统并列，称义不唯独靠信心，七件圣事，体变说，驻任主教，修院，在堂区神父与证人之前缔结婚姻。转述不是引用，本课不会把一份摘要装扮成公会议的措辞。这道虚构的考题两次不及格：一次因为一个缺失的年份，一次因为一份假文献。
:::
:::

## 公会议不会称之为真的和平

1555年9月25日，《奥格斯堡和约》让帝国内的路德宗与天主教诸侯解决各自领地的公共宗教。公式 *cuius regio, eius religio* 就是那种抉择的简写。加尔文派没有被包括在内。臣民没有被授予随心信仰的私人权利。这个和约不是现代的宽容，也不是一种教义。特兰托没有把它接受为信仰的真理。公会议说出教会教导什么。帝国会议说出诸侯可以维持哪种公共崇拜而不致在帝国内重燃战争。一位诸侯的抉择不会使一种教义为真。一道法令，就其本身而言，不会重写等级的法律。查理五世1556年的退位，让他的继任者生活在一个他并不想要成神学解决方案的和平之上。帝国与公会议，在公会议自身跨度之内的一个十年里已经分道扬镳。

:::theorem 两个问题，两种回答 {#thm-two-questions}
特兰托与《奥格斯堡和约》回答不同的问题。公会议定义天主教的教义与教士实践。和约在路德宗与天主教诸侯之间分配公共宗教。任何一个结果都不是另一个的伪装，而公会议不接受和约为真理。
:::
:::proof
证据是各别行为的内容，不是关于“教会与国家”的理论。奥格斯堡点名两种被允许的公共宗教，把改革宗略去。特兰托论圣餐与称义的法令，不会接受路德宗的教导为天主教的真理，而它们也丝毫说不出任何能把一种诸侯选项变成圣事的话。日期彼此咬合而不合并：1555年落在1545–1563之内，开幕后十年，闭会前八年。能够构成对[[#thm-two-questions]]的反证的，是一道批准 *cuius regio, eius religio* 的特兰托法令，或是一条声称要定义称义的奥格斯堡条款。两份文献都没有干对方的活。把奥格斯堡叫作“特兰托对德意志的政策”的读者，是把一个和平与一次公会议搞混了。
:::

:::example 在一个跨度之内 {#ex-inside}
只用1545、1555与1563，说出奥格斯堡相对特兰托的位置，以及一个学生不得从这种嵌套里得出什么结论。
:::solution
从1545年到1555年是10年。从1555年到1563年是8年。奥格斯堡在公会议的跨度之内，不在任何一端。嵌套诱导出这样的结论：和约是公会议的一个会期，或者公会议曾为颁布它而暂停。特兰托的间隔是真实的，但和约是一项帝国法律，不是一道法令。特兰托不接受诸侯的抉择为教义的真理。共享一部日历，不是共享一位作者。
:::
:::

:::example 三个机构，三个日期 {#ex-three-courts}
把1231、1478年11月1日与1545–1563年的公会议并置。一句虚构的话说：“宗教裁判所（Inquisition）一经创立，便在特兰托开会，并把《禁书目录》作为它唯一的书发表。”你必须把什么分开？
:::solution
1231年是格列高利九世（Gregory IX）的教皇程序，而年表说它还不是西班牙宗教裁判所。1478年是西克斯图斯四世（Sixtus IV）对那个西班牙法庭的授权，一个王室机构。特兰托是一次定义教义、改革实践的公会议。公会议那些年岁里罗马的裁判法庭是又一个机构，而本课不用一个年表没有锁定的数字为它的改组定年。《禁书目录》是同样几十年的一个工具，不是唯一的书，也不是公会议。那句虚构的句子把四样东西坍进一个绰号。分开，就是全部的回答。
:::
:::

## 《禁书目录》是一个工具，不是教会的心智

查禁书籍的名录，是教廷治理印刷的一种方式。它们属于回应的一半：一种曾经使论纲成倍增殖的技术，正如[[crises/print]]所解释的，也能使一种答复成倍增殖，而且它可能被审查。审查是真实的。它不是天主教智识生活的全部。大学仍在辩论。新的学院在授课。法学家在做注释。公会议命令对礼仪书籍进行改革，那是一项编辑的劳作，不是一堆篝火。圣经学与教父学的学问，在颁布名录的教会内部延续。一部停在《禁书目录》的历史，描述的是一项警务措施，却把它叫作一种文化。

对“宗教裁判”（inquisition）一词也需要同样的细心。1231年，格列高利九世的程序是教皇的宗教裁判。它还不是西班牙宗教裁判所。1478年11月1日，西克斯图斯四世批准了西班牙宗教裁判所，卡斯蒂利亚与阿拉贡的一个王室机构，作为[[crises/year-1492]]的一部分讲授。在特兰托的年份里，教廷还在罗马改组了裁判权。那个罗马法庭是第三样东西。本课不描述它们任何一方的程序。要看清一个教义法庭、一个西班牙王室法庭与一次公会议的法令不是同一个机构挂三个绰号，并不需要一套程序。

:::corollary 审查不是文化 {#cor-index}
《禁书目录》是天主教改革回应性一半的一部分。它对同年岁的天主教思想、学术与教育，不是充分的描述。
:::
:::proof
这个推论跟着上述别种机构的存在而来：修院、学院、礼仪的改革、新修会的教学，以及公会议自身那一大宗教义与实践的文本。一部目录是一份清单。一份清单不可能是它试图限制的那个活动。能够构成对这个推论的反证的，是一个证明天主教出版、大学辩论与教育恰好在名录开始之处停止了的证明。它们没有停止。同样能够构成反证的，是一种说名录无关紧要的主张。它们并非无关紧要。推论说的是“不充分”，不是“不重要”。
:::

## 一个完整的案例：两道法令，一次公会议

把修院与称义法令当作一个案例的两个行为来看。修院回应的是牧灵的失败：教士没有受训，主教不在任，堂区由那些只享有圣俸之名而不负牧灵之实的人照管。一位十五世纪的改革者本可以写出这份控诉。这里面没有一样东西需要维滕贝格。称义法令回应的是十六世纪的争论。它拒绝让唯独信心，在新教的意义上，成为罪人如何在上帝面前站立的答案，并把恩典、各圣事与善工保持在一个教导之内。一位路德宗的谈判代表无法签署它而仍然是路德宗。一位天主教主教能够在一生的同一年里既落实修院又宣讲法令。

这个案例就是名字的检验。只把公会议叫作反宗教改革，修院就成了定罪的烟幕。只把它叫作一次内部整修，定罪就成了一桩需要跳过的尴尬。那件完整论证过的事，就是[[#thm-label]]里的那个连词。会打破这个案例的证据：一道事实上只批准了用于论战的学院、对寻常教士绝口不提的修院法令，或者一道事实上提供了查理五世为帝国等级所想要的那种妥协的称义法令。可转述的内容朝着相反的方向。一边是日常的培养，一边是教义的墙，一次公会议。

## 反对意见

最尖锐的反对意见说，回应的一半才是真实的一半，因为法令定罪新教立场，而耶稣会士成了新教地区最显眼的天主教力量。这条反对意见对了一半，这就是[[#thm-label]]不肯丢掉回应的理由。它删去其余时才变成谎言。欧洲以外的传教不是在反驳一篇德意志讲道。一条关于秘密婚姻的规定不是在反驳茨温利。驻任不是一本小册子。这条反对意见只有在那些行为能被证明是幌子时才获胜。它们后来被用于反对新教徒，不能证明它们没有别的对象。

相反的反对意见说，天主教改革只是延续，“反”是新教的侮辱。延续是真实的，一直回到1098年，回到任何一次教务会议对无知教士的抱怨。它不是全部。1517年之前，没有一次公会议必须答复1536年的《基督教要义》或1525年的苏黎世圣餐。在那些文本之后，沉默是一个选择，而特兰托没有选择沉默。一个只有“改革”而没有“反”的标签，掩盖了那道墙。耶丁的那对词，才是这条反对意见应有的尺寸。

:::warning 三种偷换
不要让反宗教改革充当整体的名字。它保留了回应，掩盖了实践的改革与新修会更宽广的工作。不要让《禁书目录》充当天主教的智识生活。也不要让1545年到1563年充当一次不间断的开会。间隔是公会议的一部分。1555年的一个和平与一个终结于1563年的公会议，是时间线上的邻居，不是一项单一的政策。
:::

- [x] 天主教改革中不只是回应的那一半：驻任、修院、更新了的修会，以及不针对新教徒的传教
- [ ] 《奥格斯堡和约》，它本是公会议的一道法令
- [ ] 1517年之后的任何天主教活动，因为这个名字是公会议自己的称号
:::solution
回应的一半是真实的，而提到它的那个错误选项，出的不是关于特兰托教义的错误，而是关于问题的错误，问题问的是这个名字漏掉了什么。这个名字漏掉了不只是答复的改革。奥格斯堡不是公会议的法令，而反宗教改革是后来的标签，不是特兰托对自己的称号。
:::

:::quiz
关于耶稣会士，在本图谱里你可以说哪句话？
- [ ] 他们创立于年表印出的一个年份，而那个年份解释了特兰托
- [ ] 他们只是一支对抗土耳其人的军事修会
- [x] 他们是天主教改革的一部分，与特兰托同时代，而本课不给他们创立年份
- [ ] 他们作为特兰托公会议的表决多数开了会
:::solution
年表没有锁定创立年份，所以本课不得发明一个。耶稣会的学院、传教，以及传教事务上对教皇的服从，都是公会议那些年代里天主教改革的一部分。他们不是特兰托的表决团体，也不只是一支十字军。与公会议同时代，才是那个句子。一个数字不是。
:::
:::

:::history
特兰托公会议开会，会期之间有一段长期休会，自1545年至1563年。1555年9月25日，《奥格斯堡和约》让帝国内的路德宗与天主教诸侯解决公共宗教。公会议没有接受那个和约为教义的真理。
:::

## 通向何处

英格兰的天主教复辟是一位女王与一个议会，不是特兰托的一个会期：[[reformations/england]]。一个诸侯和平与一次公会议都未能阻止的战争，是[[reformations/religious-war]]。它们是在答复与不是答复的那些论纲，在[[reformations/luther]]。特兰托拒绝了其圣餐的那些城市教会，在[[reformations/reformed-cities]]。1478年的西班牙宗教裁判所是另一个机构，在[[crises/year-1492]]。一个能把[[#thm-label]]的两半都说出来的读者，不会惊讶于1563年之后的欧洲仍然不止一座教会，也不止一种做天主教徒的方式。

:::summary
- 反宗教改革命名天主教改革的回应性一半，掩盖其余。两半都为真。
- 特兰托自1545年到1563年，十八年带一段长期休会，不是连续的开会。查理五世于1556年退位，在它结束之前。
- 教义，以转述而非假引文：《圣经》与传统，称义不唯独靠信心，七件圣事，体变说，以及对主教、修院与婚姻的真实改革。
- 新的修会，耶稣会士包括在内，与公会议同时代。不给出创立年份。
- 1555年9月25日，奥格斯堡让路德宗与天主教的诸侯解决公共宗教。特兰托没有接受那个和约为真理。
- 《禁书目录》是一个管控的工具。它不是天主教学术、教育或崇拜的全部。
- 1231年的教皇裁判、1478年的西班牙宗教裁判所，与特兰托年份里的罗马法庭，是三个机构。它们的程序不在此描述。
:::

## 习题

:::exercise 跨度 {level=1 check="18"}
特兰托公会议的开幕与闭会之间，年份数字之差是多少年？（请输入年数。）
:::solution
特兰托于1545年开幕，于1563年结束。1563减1545是18。休会意味着你不得把18读作十八年的连续开会。年数是18。
:::
:::

:::exercise 跨度之内的和平 {level=1 check="1555"}
特兰托跨度之内的哪一年，是《奥格斯堡和约》？（请输入年份。）
:::solution
和约是1555年9月25日。它落在1545年之后、1563年之前。年份是1555。
:::
:::

:::exercise 不是引用 {level=1 check="paraphrase"}
当本课报告特兰托的一道法令时，哪个词命名了这样做的方式：引用还是转述？（请输入那个词。）
:::solution
年表禁止一部被发明的法令的措辞。所以本课报告其含义，并说明自己正在这样做。那个词是转述。
:::
:::

:::exercise 两半 {level=2}
给出一件作为对新教教导之回应的特兰托行为，再给出一件即使路德从未写作也仍然讲得通的行为。为什么这一对，而不是其中任何单独一件，才对得上关于反宗教改革这个名字的论断？
:::solution
称义法令是回应：它拒绝唯独信心，并把恩典、各圣事与善工保持在同一套天主教教导之内。修院，或主教必须驻任的规定，是另一件：无知的教士与不在任的主教，是比1517年更古老的抱怨。反宗教改革，用作整体的名字时，保留第一件，掩盖第二件。这一对，正是这个名字只有半个名字的原因。任何单独一件，都会让那两个更简单的故事中的一个成为真的。
:::
:::

:::exercise 三个宗教裁判所 {level=2}
把1231、1478与特兰托年份里的罗马法庭当作一个宗教裁判所，为什么是个错误？
:::solution
1231年，教皇的宗教裁判是教皇治下的一个程序。它还不是西班牙的法庭。1478年，西克斯图斯四世批准了西班牙宗教裁判所，半岛上的一名王室机构，其后来的历史在[[crises/year-1492]]里。罗马的改组属于特兰托的年代，是第三个机构。共享的议题，教义，造不出共享的宪法。本课也拒绝描述三者中任何一个的程序。这个区分是建制的，不是操作的。
:::
:::

:::exercise 奥格斯堡没有解决的东西 {level=2}
一位同学说，《奥格斯堡和约》“把特兰托在帝国付诸实施”。用两份文献的问题，解释为什么那个句子不成立。
:::solution
特兰托问的是天主教会教导什么、它的教士应当如何生活。奥格斯堡问的是帝国的一位诸侯可以设立哪些公共宗教，路德宗或天主教。和约略去加尔文派，不定义称义，也不定义圣事。公会议不批准一种诸侯的抉择为真理。1555年只是作为一个日期坐在1545–1563之内。时间线上的邻居，不是作者与实施。那个句子把公会议的任务给了和约，又把和约的政治给了公会议。
:::
:::

:::exercise 一个和平与一道墙 {level=3}
就这个主张论证两面：“奥格斯堡一经达成和平，特兰托的教义之墙就没有必要了。”然后说出证据偏向哪一面，什么能翻转这个判断。
:::hint
把问题保持分开。问和约约束谁，公会议约束谁，一个德意志的休战能否为拉丁教会裁定一种教义。
:::
:::solution
说墙没有必要的一面主张：帝国的战争风险才是真实的问题，1555年为路德宗与天主教的诸侯解决了它，而进一步的定罪只会硬化和约已同意与之共处的身份。按那种看法，特兰托后来的会期错过了一次批准休战的机会。

另一面主张：诸侯之间的休战不是教义。它不约束法兰西、西班牙或全球各地的传教。它不告诉一位主教一种圣事是什么。它略去改革宗。而且它并非作为教会的教导被提出。特兰托的墙回答的，是奥格斯堡无权了结的一个问题。作为对这两个行为是什么的描述，证据偏向这第二面，那便是[[#thm-two-questions]]。它不要求你喜欢那道墙。这个判断会翻转，如果奥格斯堡载有一句天主教与路德宗神学家都接受为信仰的教义公式，或者如果特兰托的法令明确把诸侯的和平采纳为天主教的真理。两份文本都没有做到。
:::
:::

:::exercise 缺失的数字 {level=3}
你在编辑一段话，它说耶稣会创立于某一个特定年份，因而导致了特兰托的后一半。那个年份是本图谱没有锁定的。重写那个因果句，不带任何创立年份，并说出那个因果主张仍然需要什么种类的证据。
:::hint
“与……同时代”不是“由……引起”。在改写里保留学院、传教与公会议自己的主教们。不要塞进一个不同的数字作为替代。
:::
:::solution
改写如下：耶稣会士是天主教改革的一部分，与1545年到1563年的特兰托同时代。他们的学院与传教，属于与公会议法令相同的年代。不陈述创立年份。同时代并不显示该会导致了公会议的后一半。主教们在特兰托投票。耶稣会不是公会议。那个因果主张将需要这样的证据：耶稣会的建议或人力决定了具体的法令，并且由这份年表实际包含的史料定年。一个创立的数字，无论锁定与否，仍然不会是那个证据。替换进一个恰好被锁定的邻近年份，比如1541或1545，将是另一种发明。
:::
:::
