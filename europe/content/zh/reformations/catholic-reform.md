“反宗教改革”（Counter-Reformation）这个名称掩盖了什么？它掩盖了天主教改革中并非回应新教的那一半，只保留了作为回应的那一半。两半都是真实的，而旧标签只保留后者。从1545年到1563年，特兰托（Trent）公会议界定教义、改革实践，其间有一段很长的休会期。包括耶稣会（Society of Jesus）在内的新修会也属于这些年代，本图谱不给出这些修会的创立年份。1555年9月25日，帝国缔结了一项公会议不会承认为真理的和约。和约与公会议回答的是不同的问题。

拉丁教会内部的改革早于1517年。克吕尼（Cluny）修院通常定年于公元910年；西多会的发源地西多（Cîteaux）修院建于1098年。康斯坦茨（Constance）公会议从1414年开到1418年，并于1415年烧死胡斯，那是一次被用作统一工具的公会议，而不是新教的发明。要求主教驻守教区、神职人员识字，并不是作为对路德的回应才开始的；作为回应而开始的，是针对论纲以来传播开来的教导划定教义界线。一个诚实的名称应当为这两句话都留出位置，“反宗教改革”只容得下一句。

## 中间有间隔的公会议

特兰托公会议于1545年开幕，1563年闭幕，年份数字之差是18。这十八年并不是连续不断的辩论。本图谱的年表把这段中断称为会期之间的长期休会，本课不得用年表未锁定的年份清单来替代它。主教难以召集齐全，皇帝与教皇想要的公会议也不一样。查理五世（Charles V）希望改革教廷，并为德意志各等级重返教会开辟道路；教廷则希望在教皇主持下界定教义，而不是让一次可能重提康斯坦茨“公会议高于教皇”之说的会议重新讨论教义。列强之间的战争，以及寻找一座双方都能接受的城市，造成了其余的困难。查理于1556年退位，当时公会议尚未结束，而前一年的和约已在帝国生效。特兰托闭幕时，教皇与皇帝都已不是当初开启这场争论的人。

:::definition 天主教改革 {#def-catholic-reform}
**天主教改革**是拉丁教会内部、尤其贯穿1545年至1563年的种种努力：界定教义，改变主教与神职人员的生活，创立或更新修会。它包括对新教教导的回应，但不止于此。这个名称既不意味着“一切回应路德的事物”，也不意味着一个新的教会。
:::

:::definition 反宗教改革 {#def-counter}
**反宗教改革**是后来的史家给这场努力中回应性的一半所贴的标签：论战、审查，以及从新教教会手中夺回领土与人心。用它来称呼整体，就会掩盖主教驻守、修道院、旧修会的改革，以及面向从未信过新教之人的传教。耶丁（Hubert Jedin）提出的“天主教改革与反宗教改革”这一表述提醒我们：两半需要两个词。
:::

公会议的决定可以转述，但不得冒充引文。关于《圣经》，公会议认定福音通过成文的书卷与保存在天主教会中的口传传统一同传承，并把古老的拉丁文《武加大译本》（Vulgate）定为公开教导的权威文本。这是对新教徒后来所用意义上的“唯独圣经”的拒绝。关于称义，公会议教导罪人因上帝的恩典、为基督的缘故而称义，信是得救的开端；同时拒绝这样的主张：唯独信心，离开望德、爱德与圣事，就足以涵盖一切。在这道法令中，称义之人的善工并非枝节问题。关于圣事，公会议保留七件圣事，并教导圣事赋予恩典。关于圣餐，公会议肯定“变体说”（transubstantiation），这就排除了纯象征性的解读；它也不认为路德宗的“真实临在”（real presence）已经足够，而路德宗本身是拒绝变体说的。改革宗的教导自1529年马尔堡会谈以来已自成一派，与特兰托的表述相距更远。参见[[reformations/luther]]与[[reformations/reformed-cities]]。

实践方面的改革是另一组法令，并不是前一组的掩饰。主教须驻守教区、讲道、巡视；限制一人兼领多份圣俸（benefice）；每个教区须设修院（seminary）培养神职人员；婚姻须在堂区神父与证人面前缔结方为有效，以应对由来已久的秘密婚约问题。这些规定没有一条需要借助新教邻居才能理解。不会做弥撒的神父、从不巡视教区的主教，本是中世纪的老问题。特兰托重申这些要求时，它们依然是天主教改革。

:::theorem 标签只保留了回应 {#thm-label}
天主教改革是对新教教导的回应，但不止于回应。“反宗教改革”这个名称保留了前一半，掩盖了后一半，而理解特兰托与新修会，两半缺一不可。
:::
:::proof
回应的一半，见于上文转述的教义法令：它们针对唯独信心称义、针对以《圣经》为福音唯一渠道、针对一切不承认变体说的圣餐观划定了界线。这些界线有其对手，即1517年以来几十年间形成的各个教会。另一半则见于主教驻守、修院与婚姻法，也见于那些在没有新教可反的地方照样传教的修会。能够推翻[[#thm-label]]的，是一次只谴责异端、从不改革神职人员的公会议，或一次只重复十五世纪的告诫、从不点名新教义的公会议；特兰托两者都做了。同样能够推翻它的，是一种已经明确把修院与传教包括在内的“反宗教改革”用法，而通常的用法并非如此。它的意思是“天主教的回应”，而回应只是史料所载的一半。
:::

:::example 十八年，而非十八个会期 {#ex-span-trent}
特兰托公会议于1545年开幕，1563年结束。两者相差多少年？为什么不能认为公会议在这些年里一直在开会？
:::solution
1563减1545等于18。年表把这段中断称为会期之间的长期休会。这十八年中，有些年份在开会，有些年份则是停会、战争，或教皇、皇帝不愿会议留在原地的年份。查理五世于1556年退位，在这段跨度之内、会议结束之前；1555年9月25日的《奥格斯堡和约》也落在其中。一次连续的公会议，既不会有需要解释的间隔，也不需要讲缺席背后的政治。年数是18。
:::
:::

## 不给创立年份的新修会

耶稣会、嘉布遣会（Capuchins）、乌尔苏拉会（Ursulines）、经过改革的加尔默罗会（Carmelites），以及腓力·内里（Philip Neri）的祈祷会（Oratory），并不是同一个计划换了五身制服。与依纳爵·罗耀拉（Ignatius of Loyola）相联系的耶稣会，要求会士在传教事务上对教皇特别服从，兴办学院，并以一套结构化的避静，即《神操》（Spiritual Exercises），作为有章法的灵修操练。方济各·沙勿略（Francis Xavier）的名字说明，耶稣会不只是在欧洲执行治安：他沿着伊比利亚的海路向外传教，面对的不是误入歧途的路德宗信徒。嘉布遣会是方济各会在讲道与守贫方面的改革。乌尔苏拉会以女子教育为使命，仅此一点，就足以驳倒把天主教改革只讲成神职人员故事的说法。加尔默罗会更新了一个古老的修会；祈祷会则把在俗神职人员聚集起来过共同生活。它们都与特兰托公会议同时代，这就是本图谱允许作出的关于年份的论断。

:::proposition 同时代，不再进一步定年 {#prop-orders}
包括耶稣会在内的新修会是天主教改革的一部分，与1545年至1563年的公会议同时代。年表没有锁定它们的创立年份。印出创立年份的教科书，添加了一个本课不会使用的数字。
:::
:::proof
正面的证据是这些修会的工作本身，与公会议的年份并列：学院、传教、讲道与神职人员的培养，就是天主教改革在法令之外的样貌。反面的证据是本图谱的规则：年表没有锁定年份的地方，本课不编造替代。能够推翻[[#prop-orders]]的，是一条为耶稣会定年并认可这个数字的年表条目，而这样的条目并不存在。能够推翻第一句的，是证明这些修会只是反新教的队伍、既无学校、也不在基督教欧洲以外传教、更没有改革修会生活的证据。沙勿略的传教、乌尔苏拉会的学校、嘉布遣会向方济各会传统做法的回归，恰恰证明了相反的情形。它们在德意志、法国与帝国境内也确实是一种回应。这一论断说的是“同时代”和“天主教改革的一部分”，并没有说“未受路德影响”。
:::

:::example 不得写在页面上的日期 {#ex-no-year}
一道虚构的考题写道：“请给出耶稣会的创立年份，并引用特兰托公会议回应它的那道法令。”为什么本图谱拒绝这道题的两个部分？
:::solution
创立年份没有锁定，给出一个，哪怕是广为人知的那个，也是在编造数字。正确的说法是：新修会与特兰托公会议同时代，这里不给出创立年份。法令是这个陷阱的另一半。特兰托的决定可以转述：《圣经》与传统并列，称义不唯独靠信心，七件圣事，变体说，主教驻守，修院，婚姻须在堂区神父与证人面前缔结。转述不是引用，本课不会把一份概要装扮成公会议的原文。这道虚构的考题错了两次：一次是缺失的年份，一次是虚假的文献。
:::
:::

## 公会议不会承认为真理的和约

1555年9月25日的《奥格斯堡和约》，让帝国内的路德宗与天主教诸侯决定各自领地的公共宗教。*cuius regio, eius religio* 这一公式就是对这种选择的简称。加尔文派不包括在内，臣民也没有获得随己意信仰的个人权利。这项和约既不是现代意义上的宽容，也不是一种教义，特兰托没有把它接受为信仰的真理。公会议规定的是教会教导什么；帝国会议规定的是，诸侯可以维持哪种公共礼拜而不致在帝国内重燃战火。诸侯的选择不能使一种教义成为真理；一道公会议法令本身，也不能改写帝国等级的法律。查理五世1556年退位后，他的继任者只能接受这样一项和约，而他本人并不希望它成为一种神学上的解决。在公会议自身跨度中的十年之内，帝国与公会议已经分道扬镳。

:::theorem 两个问题，两种回答 {#thm-two-questions}
特兰托公会议与《奥格斯堡和约》回答的是不同的问题。公会议界定天主教的教义与神职实践；和约则在路德宗与天主教诸侯之间分配公共宗教。两者都不是对方的伪装，公会议也不承认和约为真理。
:::
:::proof
证据在于两项行为各自的内容，而不在于某种关于“教会与国家”的理论。奥格斯堡点名两种获准的公共宗教，而把改革宗排除在外。特兰托关于圣餐与称义的法令不会承认路德宗的教导为天主教真理，也根本没有任何能把诸侯的选项变成圣事的说法。两个日期相互交错而不重合：1555年落在1545–1563年之内，在开幕后十年、闭幕前八年。能够推翻[[#thm-two-questions]]的，是一道批准 *cuius regio, eius religio* 的特兰托法令，或一条宣称界定称义的奥格斯堡条款。两份文献都没有越俎代庖。把奥格斯堡称为“特兰托的德意志政策”的读者，混淆了和约与公会议。
:::

:::example 处在跨度之内 {#ex-inside}
只用1545、1555与1563三个年份，说明奥格斯堡相对于特兰托的位置，以及学生不应从这种嵌套关系中得出什么结论。
:::solution
从1545年到1555年是10年，从1555年到1563年是8年。奥格斯堡处在公会议的跨度之内，而不在任何一端。这种嵌套容易诱使人得出结论：和约是公会议的一个会期，或者公会议曾为颁布和约而休会。特兰托的休会确有其事，但和约是帝国法律，而不是公会议法令。特兰托不承认诸侯的选择为教义真理。同用一本日历，并不等于出自同一位作者。
:::
:::

:::example 三个机构，三个日期 {#ex-three-courts}
把1231年、1478年11月1日与1545–1563年的公会议并置。一句虚构的话写道：“宗教裁判所（Inquisition）一经创立，就在特兰托开会，并发布了《禁书目录》作为它唯一的书。”你必须把哪些东西区分开来？
:::solution
1231年是格列高利九世（Gregory IX）确立的教皇审判程序，年表说明它还不是西班牙宗教裁判所。1478年是西克斯图斯四世（Sixtus IV）批准设立那个西班牙法庭，它是一个王室机构。特兰托是一次界定教义、改革实践的公会议。公会议期间罗马的宗教裁判法庭是另一个机构，本课不用年表未锁定的数字为它的改组定年。《禁书目录》是同一时期的一种工具，既不是唯一的书，也不是公会议。这句虚构的话把四样东西压进了一个绰号。把它们区分开来，就是全部的答案。
:::
:::

## 《禁书目录》是工具，而非教会的全部思想

开列禁书名录，是教廷管理印刷品的一种方式，属于回应的那一半：正如[[crises/print]]所说，曾使论纲大量复制的技术，同样可以使回应大量复制，也可能受到审查。审查确有其事，但它不是天主教思想生活的全部。大学照常辩论，新的学院照常授课，法学家照常注释。公会议下令改革礼仪书籍，那是编订文字的工作，而不是焚书的篝火。圣经学与教父学研究，在颁布禁书目录的教会内部继续进行。一部止步于《禁书目录》的历史，描述的是一项管控措施，却把它称为一种文化。

对“宗教裁判”（inquisition）一词也需同样谨慎。1231年格列高利九世的程序是教皇的宗教裁判，还不是西班牙宗教裁判所。1478年11月1日，西克斯图斯四世批准设立西班牙宗教裁判所，它是卡斯蒂利亚与阿拉贡的王室机构，作为[[crises/year-1492]]的一部分讲授。在特兰托公会议期间，教廷又在罗马改组了宗教裁判机构，这个罗马法庭是第三种机构。本课不描述其中任何一个的审判程序。要看清教义法庭、西班牙王室法庭与公会议法令并不是同一机构的三个绰号，并不需要了解这些程序。

:::corollary 审查不是文化 {#cor-index}
《禁书目录》属于天主教改革中回应性的一半，并不足以描述同一时期天主教的思想、学术与教育。
:::
:::proof
这一推论源于上述其他机构的存在：修院、学院、礼仪改革、新修会的教学，以及公会议本身大量关于教义与实践的文本。目录只是一份清单，清单不可能等同于它试图限制的活动。能够推翻这一推论的，是证明天主教出版、大学辩论与教育恰恰在禁书目录开始之处停止的证据，而它们并没有停止。同样能够推翻它的，是“禁书目录无关紧要”的主张，而它们并非无关紧要。这一推论说的是“不充分”，而不是“不重要”。
:::

## 一个完整的案例：两道法令，一次公会议

把修院法令与称义法令当作同一案例中的两项行为来看。修院法令回应的是牧灵上的失职：神职人员未受训练，主教不驻教区，堂区由只挂圣俸之名而不尽牧灵之责的人照管。一位十五世纪的改革者也完全可能写出这份控诉，其中没有一样需要维滕贝格。称义法令回应的则是十六世纪的论争：它拒绝让新教意义上的“唯独信心”成为罪人如何在上帝面前称义的答案，并把恩典、圣事与善工维系在同一种教导之中。路德宗的谈判代表若签署它，就不再是路德宗。天主教主教却能在同一年里既兴办修院，又宣讲这道法令。

这个案例检验的是名称。只把公会议称为反宗教改革，修院就成了谴责异端的烟幕；只把它称为内部整顿，谴责异端就成了需要略过的尴尬。完整论证过的，正是[[#thm-label]]中的那个“而且”。能够推翻这个案例的证据是：一道实际上只批准用于论战的学院、对普通神职人员只字不提的修院法令，或一道实际上提供了查理五世想为帝国各等级争取的那种妥协的称义法令。可以转述的内容所指的方向恰恰相反：一边是日常的培养，一边是教义的高墙，同出一次公会议。

## 反对意见

最尖锐的反对意见认为，回应的一半才是真实的一半，因为法令谴责了新教立场，而耶稣会成为新教地区最显眼的天主教力量。这一反对意见对了一半，这也正是[[#thm-label]]不肯舍弃回应的原因；只有当它删去其余部分时，才变成谎言。欧洲以外的传教并不是在反驳一篇德意志讲道，关于秘密婚姻的规定并不是在反驳茨温利，主教驻守也不是一本论战小册子。只有证明这些行为都是幌子，这一反对意见才能成立。它们后来被用于对付新教徒，并不能证明它们没有别的目标。

相反的反对意见认为，天主教改革只是延续，“反”字是新教的侮辱。延续确有其事，可以一直追溯到1098年，追溯到历次教务会议对无知神职人员的抱怨，但这不是全部。1517年以前，没有哪次公会议需要回应1536年的《基督教要义》或1525年苏黎世的圣餐礼。有了这些文本之后，沉默是一种选择，而特兰托没有选择沉默。一个只有“改革”而没有“反”的标签，掩盖了那道高墙。耶丁的那对词，才是这一反对意见应有的分寸。

:::warning 三种偷换
不要让“反宗教改革”充当整体的名称：它保留了回应，掩盖了实践的改革与新修会更广泛的工作。不要让《禁书目录》充当天主教的思想生活。也不要把1545年至1563年当作一次不间断的会议：休会是公会议的一部分。1555年的和约与1563年结束的公会议，是时间线上的邻居，而不是同一项政策。
:::

:::history
特兰托公会议自1545年至1563年召开，会期之间有一段长期休会。1555年9月25日，《奥格斯堡和约》让帝国内的路德宗与天主教诸侯决定公共宗教。公会议没有把这项和约接受为教义真理。
:::

## 通向何处

英格兰的天主教复辟出自一位女王与一个议会，而不是特兰托的某个会期，见[[reformations/england]]。诸侯和约与公会议都未能阻止的战争，见[[reformations/religious-war]]。天主教改革所回应、又不仅仅回应的论纲，见[[reformations/luther]]。圣餐观被特兰托拒绝的那些城市教会，见[[reformations/reformed-cities]]。1478年的西班牙宗教裁判所是另一个机构，见[[crises/year-1492]]。能够说出[[#thm-label]]两半的读者，不会惊讶于1563年以后的欧洲依然不止一个教会，作天主教徒的方式也不止一种。

:::summary
- “反宗教改革”指天主教改革中回应性的一半，掩盖了其余部分。两半都是真实的。
- 特兰托公会议从1545年到1563年，历时十八年，其间有长期休会，并非连续开会。查理五世于1556年退位，当时会议尚未结束。
- 教义以转述而非伪造引文的方式呈现：《圣经》与传统，称义不唯独靠信心，七件圣事，变体说，以及对主教、修院与婚姻的实际改革。
- 包括耶稣会在内的新修会与公会议同时代。本课不给出创立年份。
- 1555年9月25日，奥格斯堡让路德宗与天主教诸侯决定公共宗教。特兰托没有承认这项和约为真理。
- 《禁书目录》是一种管控工具，并非天主教学术、教育或礼拜的全部。
- 1231年的教皇宗教裁判、1478年的西班牙宗教裁判所与特兰托时期的罗马法庭，是三个不同的机构。本章不描述它们的审判程序。
:::

## 习题

:::exercise 跨度 {level=1 check="18"}
特兰托公会议的开幕与闭幕之间，年份数字相差多少年？（请输入年数。）
:::solution
特兰托公会议于1545年开幕，1563年结束。1563减1545等于18。由于有休会，不能把18理解为连续开会十八年。年数是18。
:::
:::

:::exercise 跨度之内的和约 {level=1 check="1555"}
特兰托公会议跨度之内的哪一年签订了《奥格斯堡和约》？（请输入年份。）
:::solution
和约签订于1555年9月25日，在1545年之后、1563年之前。年份是1555。
:::

:::exercise 不是引用 {level=1 check="paraphrase"}
本课报告特兰托的某道法令时，用的是哪种方式：引用还是转述？（请输入这个词。）
:::solution
年表禁止编造法令的原文措辞，所以本课报告其含义，并说明自己是在转述。答案是转述。
:::

:::exercise 两半 {level=2}
举出特兰托公会议回应新教教导的一项行为，再举出一项即使路德从未著述也同样说得通的行为。为什么是这一对，而不是其中任何一项单独，才符合关于“反宗教改革”这一名称的论断？
:::solution
称义法令是回应：它拒绝唯独信心，并把恩典、圣事与善工维系在同一套天主教教导之中。修院，或主教必须驻守教区的规定，属于另一类：神职人员无知、主教不驻教区，都是早于1517年的老问题。用“反宗教改革”称呼整体，保留了前者，掩盖了后者。这一对说明了为什么这个名称只道出了一半。单举其中任何一项，都会使两种更简单的说法之一显得成立。
:::
:::

:::exercise 三种宗教裁判 {level=2}
为什么把1231年的程序、1478年的机构与特兰托时期的罗马法庭视为同一个宗教裁判所，是错误的？
:::solution
1231年的教皇宗教裁判是教皇治下的一种程序，还不是西班牙的法庭。1478年，西克斯图斯四世批准设立西班牙宗教裁判所，这是半岛上的王室机构，其后来的历史见[[crises/year-1492]]。罗马的改组属于特兰托时期，是第三种机构。议题同为教义，并不意味着体制相同。本课也不描述三者中任何一个的审判程序。这里的区分是制度上的，而不是操作上的。
:::
:::

:::exercise 奥格斯堡没有解决的问题 {level=2}
一位同学说，《奥格斯堡和约》“在帝国实施了特兰托的决定”。请从两份文献各自回答的问题出发，说明这句话为什么不成立。
:::solution
特兰托回答的是天主教会教导什么、神职人员应当如何生活；奥格斯堡回答的是帝国诸侯可以确立哪种公共宗教，路德宗或天主教。和约把加尔文派排除在外，既不界定称义，也不界定圣事；公会议也不承认诸侯的选择为真理。1555年只是作为一个日期落在1545–1563年之内。时间线上的邻居，并不构成“制定与实施”的关系。这句话把公会议的任务交给了和约，又把和约的政治交给了公会议。
:::
:::

:::exercise 和约与高墙 {level=3}
请就以下主张正反两面论证：“奥格斯堡一旦带来和平，特兰托的教义高墙就没有必要了。”然后说明证据更支持哪一方，什么情况会推翻这一判断。
:::hint
把两个问题分开。问一问：和约约束谁？公会议约束谁？德意志的一次休战能否为拉丁教会裁定教义？
:::
:::solution
认为高墙没有必要的一方主张：帝国的战争风险才是真正的问题，1555年已为路德宗与天主教诸侯解决了它，进一步的谴责只会使和约同意共存的双方身份更加僵化。按照这种看法，特兰托后来的会期错过了认可休战的机会。

另一方主张：诸侯之间的休战不是教义。它约束不了法国、西班牙或世界各地的传教，不会告诉主教圣事是什么，把改革宗排除在外，也并不是作为教会教导而提出的。特兰托的高墙回答的，是奥格斯堡无权解决的问题。就描述这两项行为是什么而言，证据更支持后一方，这就是[[#thm-two-questions]]。这并不要求你赞同那道高墙。如果奥格斯堡载有一条天主教与路德宗神学家都接受为信仰的教义表述，或者特兰托的法令明确把诸侯和约采纳为天主教真理，这一判断就会被推翻。两份文本都没有这样做。
:::
:::

:::exercise 缺失的数字 {level=3}
你在编辑一段文字，其中说耶稣会创立于某个特定年份，因而导致了特兰托公会议的后半段，而这个年份本图谱并未锁定。请不用任何创立年份改写这个因果句，并说明这一因果论断仍然需要哪类证据。
:::hint
“与……同时代”不等于“由……引起”。改写时保留学院、传教与公会议自己的主教。不要换上另一个数字来顶替。
:::
:::solution
改写如下：耶稣会是天主教改革的一部分，与1545年至1563年的特兰托公会议同时代；他们的学院与传教，与公会议的法令属于同一时期。不说明创立年份。同时代并不表明该修会引起了公会议的后半段：在特兰托投票的是主教，耶稣会不是公会议。这一因果论断需要的证据是：耶稣会的建议或人力决定了具体的法令，而且这些证据可以用本年表实际收录的史料来定年。一个创立年份，无论是否锁定，都不会是这样的证据。换上一个恰好已锁定的邻近年份，比如1541年或1545年，则是另一种编造。
:::
:::
