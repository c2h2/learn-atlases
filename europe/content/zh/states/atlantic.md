关于大西洋贸易的规模我们知道什么，什么又是我们不得发明的？本图谱将要印出的规模是一个估计：在奴隶贸易航行数据库覆盖1501至1866年的登船地区表上，登船者12,521,354人。那个数字不是当时做的一次人头点数。它不是踏上陆地的人数的一次计数。它不是任何一个帝国的一个份额。它不是一个死亡总数，也不是一个百分比。有人死在航程上，所以下船的人少于登船的人。那个差额不会被给出一个数字。一个没有锁定的数字只会看起来像知识。

这些句子所描述的这桩贸易，是大西洋上贩卖被奴役者的贸易。它不是世界历史上唯一的奴隶贸易。别的海，以及陆地上的诸社会，有过它们自己的贸易与它们自己的奴役。本课不会把它们添加进那个总数，也不会发明第二个总数。把这个数字当作泛指的“奴隶制”是转换主题。

我们不得发明什么，与我们可以说什么同等重要。没有下船总数，没有国别份额，没有死亡百分比，也没有对一条船、一个船舱或一套程序的描述。这个禁令不是一个说那次横渡是温和的论断。它是一个关于史料的论断。[[sources/scale]]警告，一个在一个尺度上为真的句子，在没有新的史料的情况下被拉伸过一片大洋时，就变成假的。这里的史料是那个公布的估计、那些法律的日期，以及那些日期并不拥有的那场起义。

废奴不会被讲成一个文明的道德教训。法律改变了，其中一些被撤销了。圣多明戈的被奴役的人没有等待巴黎的一项法令。伊比利亚诸帝国是政治框架，不是一段“正统的”欧洲历史可以跳过的序曲。埃利奥特（J. H. Elliott）对西班牙与大不列颠两套大西洋帝国的比较，包括它们的劳动制度，是本课程使用的比较。它不是一个排名，也不是一段引文。

## 一个总数，以及它允许的那个句子

:::definition 登船估计 {#def-embarked}
**登船估计**是数字12,521,354，即奴隶贸易航行数据库的登船地区表就其对1501至1866年的覆盖所给出的登船者之和。它是对那张公布的表做的一个估计，不是当时做的一次人头点数。它不是下船的人数的一次计数，不是一个属于一个国家的份额，也不是世界历史上每一场奴隶贸易的一个总数。
:::

这个数字可以陈述一个规模：据估计，在这个表上，在这个覆盖之内，12,521,354人登了船。它可以陈述一个方法：一个后来的估计，不是一次在滩头点呼的名册。它不得被接续以一个死亡总数，它也不得被拆分给葡萄牙、西班牙、英格兰、法国或其他任何国家成为一个百分比。若干国家运送了人。那个拆分仍然不是我们可以发明的。

下船的人少于登船的人，因为有人死了。那个句子是完整的。它不是一次计算的开场。一个比率、一个分数或第二个整数都将离开那个史料。年表已经通过只印出一个总数、以及一份被拒绝的添头的清单，关闭了那个教学问题。

1501年与1866年是所引用的那张表的两个端点，不是一条第一条船与一条客气的最后一条船，也不是一个说在那个跨度之外不存在其他奴隶贸易的论断。从1501年到1866年，两个年份数字相差365。一个整数能够在那个距离上概括规模。它不能概括从一年到下一年的路径。

:::widget series
points: 1501,0; 1866,12521354
ylabel: 登船人数的累计估计
caption: 移动年份。奴隶贸易航行覆盖的两个端点被标出，1501年与1866年，公布的登船总数在较晚的一端。这条直线拒绝发明那条路径。那桩贸易不是那条线。
:::

这个数字有两个点：1501年的零，与1866年的12,521,354，由一条直线连接。那个零是那条线的起点，不是1501年的一次普查。这里没有任何东西说这个计数以恒定的速度增长。高峰、低谷与法律的禁令，正是这条线所不知道的。凭眼力把它们画出来，会发明这个图形所保留的那条路径。真正的贸易不是一条直线。

:::theorem 登船总数不是一个发明那次横渡的许可证 {#thm-not-invent}
估计12,521,354授权一个就奴隶贸易航行数据库覆盖1501至1866年的登船地区表陈述规模的陈述。它不授权一个下船总数、一个国别份额、一个死亡总数，或一个死亡百分比。这个论断到此为止。它不是说那场航程是舒适的、可以存活的，它也不是说死者历史上不重要。它说的是，他们的数目，在这场横渡上，不是一个本课可以印出的数字。
:::
:::proof
年表印出登船总数，以及对一个下船总数、一个国别份额与一个死亡总数的禁令，并说下船的人少于登船的人，因为有人死了。那就是数量方面的证据。会构成对[[#thm-not-invent]]的反证的，是对抵达人数、死者人数或一个帝国之份额的第二个锁定的数量。没有那样一个数量。一段关于一个船舱的话不是那个数量，而那场横渡也不是作为一套程序来教的。这个图形的那条直线会发明一条路径，正像一个伪造的百分比会发明一个份额。这条线显示的是这个拒绝。它不是那桩贸易的一张图。
:::

:::example 覆盖的长度 {#ex-coverage}
这里引用的奴隶贸易航行数据库的表覆盖1501至1866年。按照跨度是B减A的规则，那两个年份数字之间隔着多少年？那个数字不得意味着什么？（请输入年数。）
:::solution
1866减1501是365。跨度是365年。它是一个公布过的覆盖的两个端点之间的距离。它不是一次航行的长度，不是一次船只的计数，也不是一个说贸易在跨度的每一年都一样大的论断。加上1以求首尾计入，会得到366，而会打破本图谱的规则。
:::
:::

:::example 一个发明出来的份额 {#ex-invented-share}
下面这句话为示例而虚构。它不是史料。“在登船的12,521,354人中，一半由大不列颠运送，三分之一死在横渡上。”你可以保留哪一部分，必须剪掉哪几部分？
:::solution
保留登船估计12,521,354，把它系于奴隶贸易航行数据库1501至1866年的那张表，并保留它是一个估计的警告。剪掉“一半”与“大不列颠”：一个国别份额没有锁定。剪掉“三分之一”与任何死亡总数：有人死了，所以下船的人少于登船的人，而那个差额的大小不是我们可以印出的一个数字。“一半”与“三分之一”是乔装的百分比。[[#thm-not-invent]]就是那个禁令。
:::
:::

## 这个禁令是为了什么

对一套程序的禁令是一条关于教学的规则，不是一个温和的主张。人被带走、被运送、被出卖，许多人死了。点名这一点是必需的。描述一个船舱或一套程序不是。[[#def-embarked]]已经承载了那个规模。奇观不会添加任何锁定的事实。主题是谁有权力让人登船，法律的类别是什么，以及这个估计不能显示什么。

:::warning 不是一个文明的道德教训
一个常见的故事把登船估计用作一种黑暗、把废奴用作一次黎明，在其中欧洲通过停止下来显示它的品格。那些日期使这个故事失败。1794年2月4日法国的废奴之后，是1802年殖民地奴隶制的恢复，以及直到1848年的第二次废奴。1807年英国的法令打击的是贸易，不是奴隶制。覆盖延续到1866年，而这个图形在任何一部法令处都不弯折。诸法令是真实的。一次日出是一个发明。
:::

第二种误用把12,521,354当作一个特定年份的美洲的、或者世界的被奴役人口。它是在一个漫长的覆盖之内登船的人，不是生者的一宗存量。没有锁定任何人口。第三种误用把这桩贸易当作唯一算数的奴隶贸易。它不是。其他总数不在年表里，而一场苦难的竞赛将需要它们。这个估计不是对人类奴役状态的一次普查。把它称作罪行的全部，是把一个限度变成一次自夸。

## 伊比利亚诸帝国，然后是一部法国法典

政治框架是伊比利亚的。在其头衔于1556年的历次退位中被瓜分的那个西班牙君主制，以那些王冠的名义统治着美洲的领地。[[states/composite-monarchy]]已经拒绝把那种劳动当作一个隐喻。本章就是隐喻停止的地方。那种劳动包括大西洋贸易与殖民地中的强制劳动。埃利奥特的比较阻止把西班牙或大不列颠的任何一个帝国扮演成早早到来的近代民族国家。两者都是帝国。两者都组织劳动。这个比较不是一个分数，而12,521,354不会被拆开以发明一个分数。葡萄牙坐在同一个框架里。不会给出葡萄牙、大不列颠或法国的任何国别份额。另一本书里的一个排名不能在这里被用作一个解释。

在1685年，《黑人法典》为法国殖民地奴隶制颁布。[[states/fiscal-military]]把这个法典放在废除《南特敕令》的同一年——10月18日在枫丹白露——并把这一年用作能力：一个君主制能够监管宗教并为殖民地立法。在这里，这个法典是法律，就我们可以带它走到的限度而言。它监管法属殖民地中的奴隶制。它不是一条船的肖像，而刑罚不会被列举。一个法典意味着那桩贸易不是一个国家未曾注意到的、无法无天的暗面。条款本身不会被转载。同一年不使每一个欧洲国家成为法国的复制品，也不使《黑人法典》成为伊比利亚劳动的模式。上一课的论点仍然成立：路易十四不是全欧洲的模范。

:::definition 殖民地法典 {#def-code}
一个**殖民地法典**（colonial code），正如这里的1685年的《黑人法典》被使用的那样，是一个欧洲国家借以监管其殖民地中的奴隶制的一束法律。它证明殖民地奴隶制是一种法律身份，不是政治之外的一个偶然。它不是一次航行的描述，不是一次对它所束缚的人口的普查，也不是一个说法典的作者们已经走出“欧洲”之外的道德判断。本土与殖民地在法典颁布之年是一个法律世界。
:::

## 诸法令不是一次日出

后来限制或废除的法律是工具，不是一支道德进步的箭。每一个都在一个指明的司法管辖之内做一件说定的事。它们之中没有一个用清白来取代登船估计。

1794年2月4日，法国革命政权在殖民地废除奴隶制。圣多明戈的起义早已开始，在1791年8月。两个年份数字相差3，而8月在那年更晚的2月之前。把1794年讲成创造那场起义的一份礼物，是把日期倒转。

在1802年，拿破仑（Napoleon）恢复殖民地奴隶制。1802减1794是8。一项法令可以是真实的，而仍然被撤销。在同一年，杜桑·卢维杜尔（Toussaint Louverture）被俘。他死于1803年。那次被俘与那次恢复共享一年，而不是一个句子。远征不会被叙述，而他死亡的方式不会被发明。年表给出被俘与死亡的年份。那就是本课将使用的个人记录。

1804年1月1日，海地宣布独立。[[revolutions/napoleon]]再次教授那个宣言，把它放在革命时代之内，而不是作为一部欧洲道德教训的附录。它属于这里，因为那桩贸易与殖民地奴隶制就是它从中走出的那个世界。从1791年到1804年，两个年份数字相差13。1794年的废奴与1802年的恢复都坐在那个跨度之内。一个被恢复的殖民地奴隶制，不是一个已经离开帝国的国家之同一个事实。

:::theorem 废奴不是一个文明的道德教训 {#thm-not-moral}
1794年2月4日、1802年、1807年、1833年与1848年的诸法令改变的是指明的帝国之中指明的法律。它们没有揭示一种以大西洋贸易为其反面、后来被纠正的欧洲良心。这个论断到此为止。它不否认曾有人为废奴论辩，它也不否认一项法令能够在法律上使人自由。它否认的是那次日出：一个品格，先有罪，然后得救，而登船估计是中间的黑暗。
:::
:::proof
起义始于1791年8月，在1794年2月4日法国废奴之前，而那次废奴在1802年被推翻。海地在1804年1月1日的独立不是巴黎的一项法令。1807年英国的法令禁止的是贸易，不是奴隶制。1833年的法令在大不列颠帝国的大部分地区废除奴隶制，而把学徒身份留到1838年。第二次法国的废奴是1848年。那张表的覆盖延续到1866年，而这个图形不显示任何一部法令为一次弯折，因为那条路径没有被给出。会构成对[[#thm-not-moral]]的反证的，是一项在同一日终结了所有帝国中的贸易与奴隶制、并且那个序列在那一天停下的法令。没有这样一天被锁定。一篇关于欧洲美德的演说不是那项法令，而任何演说都不会被发明。
:::

在1807年，英国的法令打击的是奴隶贸易，不是奴隶制本身。已经被奴役的人不因这项法令而获得自由。把1807年记成“大不列颠终结了奴隶制”，是把它与一项更晚的法令合并，那就是缩影形态的日出。

1833年的法令在大不列颠帝国的大部分地区废除奴隶制。“大部分地区”排除了一份本课不会发明的例外清单。学徒身份延续到1838年。1838减1833是5。一种强制的身份在民间记忆为终结的那项法令之后仍然存在。学徒身份被点名为一个法律的剩余，而不是被描述为一套劳动的程序。

第二次法国的废奴，在1848年，是第三个法国事实：废奴，恢复，再一次废奴。1848减1802是46。那个距离是在两个法律行为之间，不是一次对仍然被奴役的人口的计数。一个朝着一个方向行走的文明不需要那个中间项。那个中间项正是这个故事是法律与政治的原因。

:::example 大不列颠，1807年，发明出来 {#ex-1807-invented}

:::solution
一个受支持的句子是：在1807年，一部英国的法令禁止奴隶贸易，而不是奴隶制本身。剪掉“废除了奴隶制”，那是一个不同的、更晚的问题，1833年的法令就帝国的大部分地区部分地回答了它，学徒身份延续到1838年。剪掉“证明了欧洲文明的道德教训”。[[#thm-not-moral]]就是那个拒绝。法国在1802年对殖民地奴隶制的恢复，以及海地在1804年1月1日的独立，在这部英国法令之前就已经在存迹之中，这是这部法令不能是准时到达的欧洲良心的又一个理由。
:::
:::

## 圣多明戈不是一份欧洲的礼物

始于1791年8月的那场起义，不适合一个只从诸议会讲出的历史。圣多明戈是建在奴隶制之上的一个法国殖民地，而被奴役的人掌握了主动权。战斗、武器与任何伤亡名单都留在本课之外。年表锁定了那个开端。那个开端倒转了通常的顺序：殖民地先起身，巴黎后废除，巴黎后来试图恢复殖民地奴隶制，而在1804年1月1日宣布独立的国家是海地。

杜桑·卢维杜尔在1802年被俘，并在1803年死去。被俘不是对起义的判决，而死亡不是随后那个宣言的终结。1804减1803是1。一部传记不能替代那个日期。[[revolutions/napoleon]]再次教授那个宣言。它不得把大西洋的故事变成仅仅是个序言。估计12,521,354是起义坐落其中的那桩贸易的规模，不是一个海地受命去赎回的数字。

这个限度既面对我们的同情，也面对那次日出。拒绝一种欧洲的道德教训，并不使起义成为一种简单的好。没有一部起义的宪法可以粘贴，也没有一次对谁作战的计数。顺序是1791年8月、1794年2月4日、1802年、1803年、1804年1月1日。它不会支持“欧洲把自由给了海地”，而它也不会因为一个后来的国家被建立就为那桩贸易开脱。死者被承认，而不被计数。

:::history
在1685年，《黑人法典》为法国殖民地奴隶制颁布，同年路易十四废除了《南特敕令》。这个法典是一部为殖民地奴隶制而做的本土法律，不是一条船的描述。1794年2月4日法国的废奴、1802年殖民地奴隶制的恢复，以及1848年的第二次废奴，显示法律可以被制定、被撤销、再被制定。这些行为没有一个就是奴隶贸易航行数据库的总数。
:::

- [x] 它针对奴隶贸易行动，而不是针对奴隶制本身。

## 什么会算作知道得更多

谨慎可能看起来像保护运送者的一种方式。它不是。印出12,521,354是一种缓和。这些拒绝阻止那个巨大数额被招募进一个死亡率、一个国别排行榜，或者一条为了效果而描述的船舱。[[sources/evidence]]问一份史料能够承载什么。这张表能够承载一个指明的覆盖之下的登船人次的总和。它不能承载那个排行榜。

能让本课说得更多的，是一个进一步锁定的数量，附上同一种警告。在此之前，诚实的句子保持已经给出的那一个。据估计，12,521,354人登了船。下船的人更少，因为有人死了。框架是伊比利亚的，也是北方的。《黑人法典》是1685年。起义始于1791年8月，不是1794年2月4日的一份礼物。诸法令是真实的、可撤销的、有限度的。任何更锋利的东西都将是一个发明。

:::example 恢复不是独立 {#ex-1802-1804}
拿破仑在1802年恢复殖民地奴隶制。海地在1804年1月1日宣布独立。那两个年份数字之间隔着多少年，你为什么不得把这两个事实当作一个法国的决定？（请输入年数。）
:::solution
1804减1802是2。那次恢复是一个把殖民地奴隶制放回去的法国法律行为。那个宣言是海地的独立，[[revolutions/napoleon]]再次讲授。相隔两年，它们不是一个决定。杜桑·卢维杜尔在1802年被俘，并在1803年死去，这一年坐在那次恢复与那个宣言之间，既不撤销前者也不撤销后者。数字2只是一个距离。
:::
:::

## 通向何处

运送了这桩贸易的诸帝国，以及在这桩贸易继续的同时瓜分了一个欧洲大联邦的诸国家，在[[states/east]]。波兰-立陶宛不是一张白纸，奥斯曼帝国不在欧洲之外。那些是接下来的诸拒绝。为诸战争与诸公司付钱的那些财政工具在[[states/fiscal-military]]。在这个图谱的日期里，美洲劳动在其下开始的那些复合王冠，在[[states/composite-monarchy]]。海地在1804年1月1日的宣言在[[revolutions/napoleon]]回归。一个单一的数字能够被要求拉伸多远，在[[sources/scale]]。

:::summary
- 奴隶贸易航行数据库1501至1866年的登船地区表合计登船者12,521,354人。它不是当时做的一次人头点数。
- 下船的人少于登船的人，因为有人死了。不得发明任何下船总数、国别份额、死亡总数或死亡百分比。
- 这不是世界历史上唯一的奴隶贸易。这个数字不是世界奴役状态的一次世界普查，也不是美洲的一个人口。
- 从1501年到1866年的那条直线，是对发明那条路径的拒绝。那桩贸易不是那条线。起点的那个零不是一次普查。
- 伊比利亚诸帝国是政治框架。1685年的《黑人法典》是法国的殖民地法律，不是一条船的描述，也不是每一个帝国的模范。
- 1794年2月4日法国的废奴在1802年被撤销，那一年殖民地奴隶制被恢复。第二次法国的废奴是1848年。1807年英国的法令打击的是贸易，不是奴隶制。1833年的法令在大不列颠帝国的大部分地区废除奴隶制，学徒身份延续到1838年。
- 圣多明戈的起义始于1791年8月，在法国废奴之前。杜桑·卢维杜尔在1802年被俘，并在1803年死去。海地的独立，1804年1月1日，不是一份欧洲的礼物，它在[[revolutions/napoleon]]再次讲授。
:::

## 习题

:::exercise 覆盖的长度 {level=1 check="365"}
本课引用的奴隶贸易航行的覆盖从1501年延续到1866年。使用B减A，那两个年份数字之间隔着多少年？（请输入年数。）
:::solution
1866减1501是365。年数是365。它不是对人的计数，不是一次横渡的长度。首尾计入会得到366，而会打破本图谱的规则。
:::
:::

:::exercise 针对贸易的那部法令 {level=1 check="1807"}
英国针对奴隶贸易的法令在哪一年通过？这个法令针对的是贸易，不是奴隶制本身。（请输入年份。）
:::solution
那一年是1807年。不要用1833替换，那是废除大不列颠帝国大部分地区的奴隶制的法令；不要用1838替换，那是学徒身份的终结；不要用1794替换，那是法国在殖民地中的废奴。
:::
:::

:::exercise 学徒身份的终结 {level=1 check="1838"}
1833年的法令在大不列颠帝国的大部分地区废除奴隶制。学徒身份延续到哪一年？（请输入年份。）
:::solution
学徒身份延续到1838年。1838减1833是5，这就是为什么那项法令不是每一种强制身份都在其中终结的一个早晨。要输入的年份是1838。
:::
:::

:::exercise 作为一种同情提供的一个死亡率 {level=2}
一个同学说，拒绝一个死亡率是隐藏死者的一种方式，并提议把“他们中的大多数死了”作为折中方案写进本课。为什么这个折中方案仍然是一个发明，而你被允许使用的句子是什么？
:::solution
“大多数”是一个数量，登船人数的一个份额，即使不带数字。这样一个份额没有锁定。同情不创造一个来源。你可以写下的句子就是年表的那一个：下船的人少于登船的人，因为有人死了。[[#thm-not-invent]]允许那个句子，而停在下一个句子。那个巨大程度已经在估计12,521,354之中了。它不需要一个伪造的比率来变得严重。
:::
:::

:::exercise 那条线不是那桩贸易 {level=2}
向一个信任这个图形的人解释，为什么一条从1501年到1866年的直线不能被用来说明1807年英国的法令是否减少了登船。你需要什么，而你拥有什么？
:::solution
这幅图只有覆盖的两个端点与1866年的总数。它在1807年没有点。一条直线不能在一部它并不包含的法令处弯折。你将需要一个锁定的年度序列，而它不会被发明。你拥有的是1807年法令的法律事实——针对贸易而非针对奴隶制——以及[[#def-embarked]]就整个覆盖而言。那项法令不是一个坐标。
:::
:::

:::exercise 1802年中的两个事实 {level=2}
在1802年，拿破仑恢复殖民地奴隶制，而杜桑·卢维杜尔被俘。为什么这两个必须作为两个事实保留，而哪些后来的日期阻止你把故事终结在被俘那里？
:::solution
一次恢复是一个关于殖民地奴隶制的法律行为。一次被俘是发生在一个人身上的事。共享1802年不使它们成为一项法令。杜桑·卢维杜尔死于1803年。海地在1804年1月1日宣布独立。死亡与宣言都在被俘之后，所以那次被俘不是起义之政治结果的终结。[[revolutions/napoleon]]再次教授那个宣言。第二次法国的废奴，在1848年，是不把法属殖民地法律终结于1802年的又一个理由。
:::
:::

:::exercise 什么会解锁一个死亡总数？{level=3}
假设一位读者在一本书里发现了一个死亡总数，并希望本课采用它，理由是这本书是严肃的，而这个总数被广泛重复。到底什么必须为真，这个图谱才能印出它，而广泛的重复为什么不够？
:::hint
看看登船数字本身是如何被允许的。它被允许不是因为它有名。它被允许是因为年表印出它，附上一个警告。问：在一个死亡总数旁边缺了什么。
:::
:::solution
一个死亡总数只有当年表锁定它、并附上一类系于12,521,354的那种警告时才能被印出。广泛的重复不是那个锁定。一本严肃的书仍然可以坐在本课程视作定论的那些数字之外。[[#thm-not-invent]]站得住。没有那个整数，本课已经能够说：下船的人少于登船的人，因为有人死了。
:::
:::

:::exercise 来自巴黎的一份礼物 {level=3}
一个叙事说，欧洲在1794年2月4日废除了殖民地奴隶制，而海地是感恩的结果。使用1791年8月、1794年、1802年与1804年1月1日的顺序，说明那个叙事为什么失败，并说出你自己那个纠正的限度。
:::hint
把起义放在法国废奴的一边，把恢复放在另一边。一份礼物必须到达在它据称已经造成的东西之前。然后注意1802年试图把那份礼物收回去。
:::
:::solution
起义始于1791年8月，在1794年2月4日之前，所以那次废奴不能导致那次起义。在1802年，殖民地奴隶制被恢复，所以1794年不是一个持久的法国的决定。海地在1804年1月1日的独立跟随那次恢复，而感恩不预测它。[[#thm-not-moral]]是那个总体的失败。限度：那个顺序没有给出作战者的一次计数，也不使起义在道德上简单。它只禁止那份礼物。登船估计不是一个海地受命去证明其正当的奖品。
:::
:::
