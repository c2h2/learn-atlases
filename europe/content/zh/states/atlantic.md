关于大西洋贸易的规模，我们知道什么？又有什么不得编造？本图谱给出的规模只有一个估计值：在“奴隶贸易航程”（Slave Voyages）数据库涵盖1501年至1866年的登船地区表中，登船人数为12,521,354人。这个数字不是当时清点的人头，不是上岸人数，不是任何一个帝国所占的份额，不是死亡总数，也不是百分比。有人死于航程之中，所以下船的人少于登船的人。这个差额不给出数字。一个没有锁定的数字，只会看上去像知识。

这里所说的贸易，是大西洋上的奴隶贸易。它不是世界历史上唯一的奴隶贸易：其他海域，以及陆地上的各个社会，都有过各自的奴隶贸易与奴役。本课不把它们计入这个总数，也不编造第二个总数。把这个数字当作泛指的“奴隶制”，就是偷换了主题。

不得编造的东西，与可以说的东西同样重要：没有上岸总数，没有国别份额，没有死亡率，也不描述船只、船舱或任何操作过程。这一禁令并不是说横渡是温和的，而是一项关于证据的主张。[[sources/scale]]提醒我们，一句在某一尺度上为真的话，若没有新的史料就被延伸到整片大洋，便会变成假话。这里的史料是已发表的估计、法律上的日期，以及一场不由这些日期主宰的起义。

废奴不会被讲成某种文明的道德寓言。法律变了，有些又被推翻。圣多明戈的被奴役者并没有等待巴黎的法令。伊比利亚诸帝国是政治框架，而不是“正统”欧洲史可以略过的序曲。本课程采用的是埃利奥特（J. H. Elliott）对西班牙与不列颠大西洋帝国（包括其劳动制度）的比较，它既不是排名，也不是引文。

## 一个总数，以及它所允许的那句话

:::definition 登船估计 {#def-embarked}
**登船估计**是指数字12,521,354，即“奴隶贸易航程”数据库登船地区表在1501年至1866年覆盖范围内所列登船人数的总和。它是根据这张已发表的表得出的估计，而不是当时的人头清点。它既不是上岸人数，也不是某个国家所占的份额，更不是世界历史上所有奴隶贸易的总数。
:::

这个数字可以表明规模：根据这张表，在其覆盖范围内，估计有12,521,354人被押上船。它也可以表明方法：这是后来的估计，而不是在海滩上点名的花名册。但它后面不能接着一个死亡总数，也不能拆分成葡萄牙、西班牙、英格兰、法国或其他任何国家所占的百分比。运送人口的国家不止一个，但这种拆分仍然轮不到我们来编造。

下船的人少于登船的人，因为有人死了。这句话已经完整，并不是一次计算的开头。比率、分数或第二个整数，都会脱离证据。年表只给出一个总数，并列出一份应予拒绝的附加内容清单，已经了结了这个教学问题。

1501年与1866年是所引数据表的两端，既不是第一艘船和体面的最后一艘船，也不意味着这一跨度之外不存在其他奴隶贸易。从1501年到1866年，年份数字相差365。一个整数可以概括这段距离内的规模，却不能概括逐年的变化轨迹。

这幅图只有两个点：1501年的零与1866年的12,521,354，中间以直线相连。这个零是这条线的起点，而不是1501年的普查。图中没有任何内容表明数字以恒定速度增长。高峰、低谷与法律禁令，正是这条线所不知道的。凭目测把它们画出来，就是在编造图表有意不给的轨迹。真实的贸易并不是一条直线。

:::theorem 登船总数不是编造横渡的许可 {#thm-not-invent}
12,521,354这一估计，允许就“奴隶贸易航程”数据库涵盖1501年至1866年的登船地区表陈述规模；它不允许给出上岸总数、国别份额、死亡总数或死亡率。论断仅止于此：它并不是说航程舒适、易于生还，也不是说死者在历史上无关紧要，而是说，这次横渡中死者的人数，不是本课可以给出的数字。
:::
:::proof
年表给出了登船总数，禁止给出上岸总数、国别份额与死亡总数，并说明下船的人少于登船的人，因为有人死了。这就是数量方面的证据。能够推翻[[#thm-not-invent]]的，是关于抵达人数、死亡人数或某一帝国份额的第二个锁定数字，而这样的数字并不存在。一段描写船舱的文字不是这样的数字，横渡也不作为一套操作过程来讲授。这幅图如果画出轨迹，就和伪造百分比来编造份额一样，是在编造。这条直线表达的是拒绝，而不是贸易的图表。
:::

这里引用的“奴隶贸易航程”数据表覆盖1501年至1866年。按照跨度为B减A的规则，两个年份数字相差多少年？这个数字不能表示什么？（请输入年数。）

:::
:::

:::example 一个编造的份额 {#ex-invented-share}
下面这句话为示例而虚构。它不是史料。“在登船的12,521,354人中，一半由不列颠运送，三分之一死于横渡途中。”哪一部分可以保留？哪些部分必须删去？
:::solution
保留登船估计12,521,354，注明它出自“奴隶贸易航程”数据库1501年至1866年的数据表，并保留它只是估计的说明。删去“一半”与“不列颠”：国别份额没有锁定。删去“三分之一”以及任何死亡总数：有人死了，所以下船的人少于登船的人，但这个差额有多大，不是我们可以给出的数字。“一半”和“三分之一”都是改头换面的百分比。[[#thm-not-invent]]就是这一禁令。
:::
:::

## 这一禁令的用意

不描述操作过程，是一条教学规则，而不是说情形温和。人们被掳走、被运送、被出卖，许多人死去。这一点必须说明，描写船舱或操作过程则不必。[[#def-embarked]]已经承载了规模，猎奇的场面不会增添任何锁定的事实。真正的主题是：谁有权力把人押上船，法律上有哪些类别，以及这个估计无法显示什么。

:::warning 并非一种文明的道德寓言
一个常见的故事把登船估计当作黑暗，把废奴当作黎明，欧洲通过停止这一贸易展现了自己的品格。这些日期否定了这个故事：1794年2月4日法国废奴之后，1802年殖民地奴隶制又被恢复，直到1848年才第二次废奴。1807年的英国法令打击的是奴隶贸易，而不是奴隶制。数据覆盖一直延续到1866年，图上的线也不在任何一项法令处转折。法律是真实的，日出却是编造的。
:::

第二种误用把12,521,354当作某一年美洲或全世界的被奴役人口。它是一段漫长时期内被押上船的人数，而不是在世者的存量。年表没有锁定任何人口数字。第三种误用把这当作唯一值得计算的奴隶贸易，事实并非如此。其他总数不在年表之中，而比较苦难需要这些数字。这个估计不是人类奴役状况的普查。把它称为罪行的全部，就把一种限度变成了一种夸耀。

## 先是伊比利亚诸帝国，后是一部法国法典

政治框架是伊比利亚的。那个在1556年退位时被分割了头衔的西班牙君主国，以这些王冠的名义统治着美洲领地。[[states/composite-monarchy]]已经拒绝把那里的劳动当作比喻，本章就是比喻止步的地方。这种劳动包括大西洋贸易与殖民地的强迫劳动。埃利奥特的比较，使西班牙帝国和不列颠帝国都不能被塑造成提前到来的现代民族：两者都是帝国，都组织劳动。这一比较不是计分，也不会为了编出一个分数而拆分12,521,354。葡萄牙也在同一框架之内。本课不给出葡萄牙、不列颠或法国的国别份额。别的书中的排名，不能在这里充当解释。

1685年，法国为其殖民地奴隶制颁布了《黑人法典》。[[states/fiscal-military]]把这部法典与同年10月18日在枫丹白露废除《南特敕令》放在一起，并把这一年当作国家能力的例证：同一个君主国既能监管宗教，又能为殖民地立法。在这里，这部法典就是法律，以我们所能说明的程度为限：它规范法国殖民地的奴隶制。它不是对船只的描绘，本课也不列举其中的刑罚。法典的存在说明，这种贸易并不是国家未曾察觉的法外暗角。法典条文本身不予转载。同一个年份并不使每个欧洲国家都成为法国的翻版，也不使《黑人法典》成为伊比利亚劳动的模式。上一课的论点依然成立：路易十四不是全欧洲的模板。

:::definition 殖民地法典 {#def-code}
本课所说的**殖民地法典**（colonial code），以1685年的《黑人法典》为例，是欧洲国家借以规范其殖民地奴隶制的一套法律。它证明殖民地奴隶制是一种法律身份，而不是政治之外的偶然现象。它既不是对航程的描述，也不是对受其约束者的人口普查，更不是一种道德评判，认为法典的制定者已经走出了“欧洲”。在法典颁布的那一年，本土与殖民地是同一个法律世界。
:::

## 法令不是日出

后来限制或废除奴隶贸易与奴隶制的法律，都是工具，而不是道德进步的箭头。每一项法律都在特定的司法管辖范围内做特定的事，没有一项能用清白来取代登船估计。

1794年2月4日，法国革命政权在殖民地废除了奴隶制，而圣多明戈的起义早在1791年8月就已开始。两个年份数字相差3，而且8月在后来的那个2月之前。把1794年说成造就这场起义的恩赐，就是把日期颠倒了。

1802年，拿破仑（Napoleon）恢复了殖民地奴隶制。1802减1794等于8。一项法令可以是真实的，却仍然被撤销。同一年，杜桑·卢维杜尔（Toussaint Louverture）被俘，次年即1803年去世。被俘与恢复奴隶制同在一年，却不是同一句话能说完的事。本课不叙述那次远征，也不编造他的死因。年表给出了被俘与去世的年份，这就是本课使用的个人记录。

1804年1月1日，海地宣布独立。[[revolutions/napoleon]]会在革命时代的框架内再次讲授这一宣言，而不是把它当作欧洲道德寓言的附录。它之所以属于这里，是因为奴隶贸易与殖民地奴隶制正是它所由产生的世界。从1791年到1804年，年份数字相差13，1794年的废奴与1802年的恢复都落在这段跨度之内。被恢复的殖民地奴隶制，与一个已经脱离帝国的国家，并不是同一个事实。

:::theorem 废奴不是一种文明的道德寓言 {#thm-not-moral}
1794年2月4日、1802年、1807年、1833年与1848年的法令，改变的是特定帝国中的特定法律。它们并没有揭示一种以大西洋贸易为反面、后来又得到纠正的欧洲良知。论断仅止于此：它不否认曾有人为废奴而论争，也不否认一项法令能使人在法律上获得自由。它否认的是那种日出叙事：一种品格，先是有罪，后来得救，而登船估计就是其间的黑暗。
:::
:::proof
起义始于1791年8月，早于1794年2月4日的法国废奴，而这次废奴在1802年被推翻。海地1804年1月1日的独立并不是巴黎的法令。1807年的英国法令禁止的是奴隶贸易，而不是奴隶制。1833年的法令在不列颠帝国的大部分地区废除了奴隶制，但学徒制一直保留到1838年。法国第二次废奴是在1848年。数据表的覆盖延续到1866年，图上的线也没有在任何法令处转折，因为年表没有给出变化轨迹。能够推翻[[#thm-not-moral]]的，是一项在同一天终结所有帝国的奴隶贸易与奴隶制、并使数据序列在当天中止的法令。年表没有锁定这样的一天。一篇颂扬欧洲美德的演说不是这样的法令，本课也不编造任何演说。
:::

1807年，英国的法令打击的是奴隶贸易，而不是奴隶制本身，已被奴役的人并没有因这项法令获得自由。把1807年记成“不列颠终结了奴隶制”，就是把它与后来的一项法令混为一谈，这正是日出叙事的缩影。

1833年的法令在不列颠帝国的大部分地区废除了奴隶制。“大部分”意味着存在例外，本课不编造例外的清单。学徒制延续到1838年，1838减1833等于5。在这项被普遍记作终点的法令之后，一种强制身份依然存在。这里只把学徒制作为法律上的残余点出，而不描述其劳动过程。

1848年的法国第二次废奴，是法国的第三个事实：废除，恢复，再废除。1848减1802等于46。这段距离位于两项法律行为之间，而不是对仍被奴役者人数的统计。一个朝单一方向前进的文明，不需要这个中间环节；恰恰是这个中间环节，说明这个故事属于法律与政治。

## 圣多明戈不是欧洲的恩赐

始于1791年8月的起义，无法纳入一部只从议会讲起的历史。圣多明戈是一个建立在奴隶制之上的法国殖民地，被奴役者掌握了主动。战斗、武器与任何伤亡名单都不在本课之内。年表锁定了起义的开端，而这个开端颠倒了通常的顺序：殖民地先起事，巴黎后废奴；巴黎后来又试图恢复殖民地奴隶制；1804年1月1日宣布独立的国家，是海地。

杜桑·卢维杜尔于1802年被俘，1803年去世。被俘不是对起义的裁决，他的死也不是随后那份宣言的终结。1804减1803等于1。一部传记不能代替那个日期。[[revolutions/napoleon]]会再次讲授这一宣言，但不得把大西洋的故事变成区区一篇序言。12,521,354这一估计是这场起义所处的那个贸易的规模，而不是海地建国所要赎回的数字。

这一限度既针对日出叙事，也针对我们自己的同情。拒绝欧洲的道德寓言，并不使起义成为简单的善。没有一部起义的宪法可供照搬，也没有参战人数的统计。顺序是1791年8月、1794年2月4日、1802年、1803年、1804年1月1日。这一顺序既不支持“欧洲把自由给了海地”，也不会因为后来建立了一个国家就为奴隶贸易开脱。死者得到承认，但不予计数。

:::history
1685年，法国为其殖民地奴隶制颁布了《黑人法典》，同年路易十四废除了《南特敕令》。这部法典是本土为殖民地奴隶制制定的法律，而不是对船只的描述。1794年2月4日的法国废奴、1802年殖民地奴隶制的恢复与1848年的第二次废奴表明，法律可以制定、撤销、再制定。这些行为都不是“奴隶贸易航程”的总数。
:::

## 怎样才算知道得更多

谨慎看起来可能像是在为运送者开脱，其实不然。给出12,521,354并不是淡化。这些拒绝，是为了防止把这样巨大的数字拉去充当死亡率、国别排行榜，或为渲染效果而描写的船舱。[[sources/evidence]]追问一件史料能承载什么。这张数据表能承载的，是特定覆盖范围内登船人次的总和，而不能承载排行榜。

要让本课说得更多，需要另一个锁定的数字，并附有同类的说明。在此之前，诚实的说法仍是已经给出的那些：估计有12,521,354人被押上船；下船的人更少，因为有人死了；框架既是伊比利亚的，也是北方的；《黑人法典》在1685年；起义始于1791年8月，而不是1794年2月4日的恩赐；法令是真实的、可撤销的、有限的。任何更尖锐的说法都是编造。

:::example 恢复不等于独立 {#ex-1802-1804}
拿破仑于1802年恢复殖民地奴隶制，海地于1804年1月1日宣布独立。两个年份数字相差多少年？为什么不能把这两个事实当作法国的同一个决定？（请输入年数。）
:::solution
1804减1802等于2。恢复奴隶制是法国的一项法律行为，使殖民地奴隶制卷土重来；宣言则是海地的独立，[[revolutions/napoleon]]会再次讲授。两者相隔两年，并不是同一个决定。杜桑·卢维杜尔于1802年被俘，1803年去世，这一年位于恢复与宣言之间，两者都没有因此撤销。数字2只是一段距离。
:::
:::

## 通向何处

运送这些人口的帝国，以及在这一贸易持续期间瓜分了一个欧洲大联邦的国家，见[[states/east]]。波兰-立陶宛不是一片空白，奥斯曼帝国也不在欧洲之外，这些是接下来要拒绝的说法。为战争与公司提供资金的财政工具，见[[states/fiscal-military]]。按本图谱的日期，美洲劳动开始于其下的复合王冠，见[[states/composite-monarchy]]。海地1804年1月1日的宣言，将在[[revolutions/napoleon]]中再次出现。一个数字能被延伸到多远，见[[sources/scale]]。

:::summary
- “奴隶贸易航程”数据库1501年至1866年的登船地区表，合计估计登船人数为12,521,354人。这不是当时的人头清点。
- 下船的人少于登船的人，因为有人死了。不得编造上岸总数、国别份额、死亡总数或死亡率。
- 这不是世界历史上唯一的奴隶贸易。这个数字既不是全世界奴役状况的普查，也不是美洲的人口。
- 从1501年到1866年的直线，是对编造轨迹的拒绝。真实的贸易不是这条线，起点的零也不是普查。
- 伊比利亚诸帝国是政治框架。1685年的《黑人法典》是法国的殖民地法律，既不是对船只的描述，也不是所有帝国的模板。
- 1794年2月4日的法国废奴在1802年被推翻，殖民地奴隶制得到恢复；法国第二次废奴在1848年。1807年的英国法令打击的是奴隶贸易，而不是奴隶制。1833年的法令在不列颠帝国大部分地区废除了奴隶制，学徒制延续到1838年。
- 圣多明戈的起义始于1791年8月，早于法国废奴。杜桑·卢维杜尔于1802年被俘，1803年去世。海地1804年1月1日的独立不是欧洲的恩赐，[[revolutions/napoleon]]会再次讲授。
:::

## 习题

:::exercise 覆盖范围的跨度 {level=1 check="365"}
本课引用的“奴隶贸易航程”数据覆盖1501年至1866年。按B减A计算，两个年份数字相差多少年？（请输入年数。）
:::solution
1866减1501等于365，年数是365。这既不是人数，也不是一次横渡的时长。首尾都算会得到366，从而违背本图谱的规则。
:::

:::exercise 针对奴隶贸易的法令 {level=1 check="1807"}
英国针对奴隶贸易的法令在哪一年通过？这项法令针对的是贸易，而不是奴隶制本身。（请输入年份。）
:::solution
年份是1807。不要换成1833年，那是在不列颠帝国大部分地区废除奴隶制的法令；也不要换成学徒制结束的1838年，或法国在殖民地废奴的1794年。
:::
:::

:::exercise 学徒制的结束 {level=1 check="1838"}
1833年的法令在不列颠帝国大部分地区废除了奴隶制。学徒制延续到哪一年？（请输入年份。）
:::solution
学徒制延续到1838年。1838减1833等于5，这说明该法令并不是一切强制身份同时终结的某个早晨。应输入的年份是1838。
:::
:::

:::exercise 以同情为名的死亡率 {level=2}
一位同学说，拒绝给出死亡率是在掩盖死者，并提议作为折中，在课文中写上“其中大多数人死了”。为什么这种折中仍然是编造？你可以改用什么句子？
:::solution
“大多数”即使不带数字，也是一个数量，即登船人数中的一个份额，而这样的份额并没有锁定。同情不能创造史料。你可以写的是年表中的那句话：下船的人少于登船的人，因为有人死了。[[#thm-not-invent]]允许这句话，并止步于下一句。12,521,354这一估计已经显示了事态的巨大，它不需要伪造的比率来显得严重。
:::
:::

:::exercise 这条线不是贸易本身 {level=2}
有人信赖这幅图，请向他说明：为什么不能用1501年至1866年的直线来判断1807年的英国法令是否减少了登船人数？你需要什么？你手头又有什么？
:::solution
这幅图只有覆盖范围的两端与1866年的总数，在1807年没有数据点。一条直线不可能在它并不包含的法令处转折。你需要的是一个锁定的逐年序列，而本课不会编造它。你手头有的是1807年法令的法律事实（针对奴隶贸易而非奴隶制），以及覆盖整个范围的[[#def-embarked]]。这项法令不是一个坐标。
:::
:::

:::exercise 1802年的两个事实 {level=2}
1802年，拿破仑恢复了殖民地奴隶制，杜桑·卢维杜尔被俘。为什么必须把这两件事作为两个事实分开？哪些后来的日期使你不能把故事停在被俘那一刻？
:::solution
恢复奴隶制是关于殖民地奴隶制的法律行为，被俘则是发生在一个人身上的事。同在1802年，并不使它们成为同一道法令。卢维杜尔于1803年去世，海地于1804年1月1日宣布独立。他的死与独立宣言都在被俘之后，所以被俘并不是起义政治结果的终点。[[revolutions/napoleon]]会再次讲授这一宣言。1848年的法国第二次废奴，则是不能让法国殖民地法律止于1802年的又一个理由。
:::
:::

:::exercise 怎样才能解锁死亡总数？{level=3}
假设一位读者在一本书中看到一个死亡总数，希望本课采用，理由是这本书很严肃，这个数字也被广泛引用。究竟要满足什么条件，本图谱才能给出它？为什么广泛引用还不够？
:::hint
看看登船数字本身是凭什么被采纳的。它被采纳不是因为它有名，而是因为年表给出了它，并附有说明。问一问：死亡总数旁边缺了什么？
:::
:::solution
只有当年表锁定了死亡总数，并附有与12,521,354同类的说明时，它才能被给出。广泛引用并不等于锁定。一本严肃的书，仍然可能不在本课程视为确定的数字之列。[[#thm-not-invent]]依然成立。即使没有这个整数，本课也已经可以说：下船的人少于登船的人，因为有人死了。
:::
:::

:::exercise 来自巴黎的恩赐 {level=3}
有一种叙事说，欧洲在1794年2月4日废除了殖民地奴隶制，海地是心怀感激的结果。请用1791年8月、1794年、1802年与1804年1月1日的顺序说明这种叙事为何不成立，并说明你自己这一纠正的限度。
:::hint
把起义放在法国废奴的一侧，把恢复奴隶制放在另一侧。恩赐必须先于它据说造成的结果。然后注意，1802年试图把这份恩赐收回。
:::
:::solution
起义始于1791年8月，早于1794年2月4日，所以废奴不可能引发起义。1802年殖民地奴隶制得到恢复，所以1794年并不是欧洲的永久决定。海地1804年1月1日的独立发生在这次恢复之后，而“感激”无法预示这一点。[[#thm-not-moral]]说明的是普遍的失败。限度在于：这一顺序没有给出参战人数，也不使起义在道德上变得简单，它只是排除了“恩赐”之说。登船估计也不是海地建国所要证明其正当的奖品。
:::
:::
