启蒙时代的公众是什么？谁被排除在外？这个问题本身就拒绝了“心智”之说。这些日期中，并没有一个名叫“启蒙运动”的人醒来，决定走向现代。有的只是印刷品、沙龙、学院与审查官，以及零散的一批书，各有各的年份。1687年，牛顿（Newton）的《自然哲学的数学原理》（Principia）出版；1751年，《百科全书》（Encyclopédie）第一卷问世；1762年，卢梭（Rousseau）的《社会契约论》（Social Contract）与《爱弥儿》（Emile）问世；1764年，贝卡里亚（Beccaria）的《论犯罪与刑罚》（On Crimes and Punishments）问世。这些并不是同一个纲领。1687年的一部科学论著不是沙龙，沙龙也不是已经向所有人敞开大门的学院。

谁被排除在外，本身就是定义的一部分。女性主持沙龙、从事写作，却被大多数学院拒之门外。许多作者接受帝国。大西洋奴隶贸易与这些书同时存在：“奴隶贸易航程”数据库涵盖1501年至1866年的数据表估计，登船人数为12,521,354人。本课不为这个数字编造变化轨迹、上岸总数、国别份额、死亡总数或死亡率。下船的人少于登船的人，因为有人死了。1756年至1763年的七年战争正处在这些日期中间，战场遍及欧洲、北美、加勒比、西非与印度。1685年10月18日，《南特敕令》在枫丹白露（Fontainebleau）被废除；同一年，《黑人法典》（Code Noir）颁布。废除敕令与这部法典，和这些书处在同一条时间线上。

这一切都不是法国大革命的原因。下一门课程见[[revolutions/old-regime]]，它从一场财政危机讲起，而不是从一本书讲起。三级会议于1789年5月5日开幕，那是下一门课程的开端，而不是本章的情节。本课不编造任何赤字。对1776年的《国富论》（Wealth of Nations），一句话就够了；美国《独立宣言》只作为背景。

## 是多种公众，而非一个心智

:::definition 启蒙公众 {#def-public}
**启蒙公众**（Enlightenment public）是论辩得以流通、同时又受到约束的一组实践：印刷、沙龙、学院与审查官。它不是单一的纲领，不是单一的心智，也不是囊括所有人的成员资格。作者之间意见分歧，其中许多人接受帝国。女性可以主持沙龙、从事写作，却仍被大多数学院拒之门外。审查官是这个公众的一部分，而不是从历史之外打断它的力量。
:::

在相信那个大写的“启蒙”之前，先把定义拿到具体日期上去检验。一本书有它的年份。沙龙是在众人面前交谈，往往在一位女性主持的宅邸中进行，本课不编造其中的谈话。学院有成员，而大多数学院把女性排除在外；“大多数”并不是百分比。审查官可以准许、拖延或禁止出版，所以这个公众并不是一片自由的天地。能够废除宗教宽容的国家，也能够查禁一本书。这种能力见[[states/fiscal-military]]，在这里，它构成了公众的边界。“时代心智”是一种拟人化：把若干实践赋予同一个意志，再让这个意志导致此后发生的一切。[[#def-public]]挡住了这个意志。实践是不会醒来的。

:::theorem 《原理》与《百科全书》不属于同一个公众 {#thm-two-publics}
1687年出版的牛顿《原理》，属于一个早于沙龙与《百科全书》的科学公众；1751年的《百科全书》第一卷，属于一个后来的集体出版的公众。两者既不是同一事件，也不是同一纲领。论断仅止于此：它并不把自然哲学逐出后来的书籍，也不是说1751年没有人读过牛顿，而是说不能把这些日期熔成一次单一的觉醒。
:::
:::proof
年份就是证据。1751减1687等于64。一部科学著作与一部集体编纂的百科全书的第一卷，相隔六十四年，并不是同一次出版。时间线把两者放在同一条线上，却仍要求你拒绝把它们等同。能够推翻[[#thm-two-publics]]的，是证明《原理》与那第一卷产生于同一个公众、同一年，或证明科学与沙龙只是同一种制度、同一批成员的两个名称。事实并非如此。1751年的读者知道《原理》，说明的是传播，而传播不等于同一。这里没有任何内容是物理学史，那段间隔也不能成为把这两本书统称为“欧洲开始思考之时”的理由。
:::

1685年10月18日，路易十四（Louis XIV）在枫丹白露废除了《南特敕令》，该敕令给予胡格诺派的是有限的宽容，而非平等。同一年，法国为其殖民地奴隶制颁布了《黑人法典》。[[states/fiscal-military]]把这两件事当作作战与监管宗教的国家能力；[[states/atlantic]]把这部法典当作法律，而不是船只、船舱或操作过程。1687减1685等于2。一部数学著作与一部奴隶法典在时间上相邻，却不是同一文本；后来的《百科全书》也并不从它们那里继承一片道德空白。

## 彼此并不一致的书

1762年，两本书问世：《社会契约论》与《爱弥儿》。一部政治论著与一本论教育的书，即使出自同一作者，也不是同一个纲领。本课不引用它们，也不把它们压缩成一句口号。从1751年《百科全书》第一卷算起，年份数字相差11。读者相同，仍然可以争论；“不是同一个纲领”的意思正在于此。

1764年，贝卡里亚的《论犯罪与刑罚》是又一本书，讨论刑法。1764减1762等于2，相近不等于相同。一部关于犯罪的印刷论著，不是每个国家的政策，也没有废除审查官。本课不会编造某项法令，来证明某个政府照搬了这本书。一本书表明某种论点被印了出来，并不表明这种论点主导了统治。

:::definition 并非同一纲领 {#def-programme}
**并非同一纲领**（not one programme）是指：被后人归在同一个名称下的书籍与制度，并没有共同的一套目标。1751年的《百科全书》、1762年的《社会契约论》与《爱弥儿》、1764年的《论犯罪与刑罚》，可以在同一个十年里被阅读，却仍然相互矛盾。这个说法并不是说这些书无足轻重，而是说读者不能挑出自己喜欢的那句话，称之为“启蒙运动”，再把其他的话当作对某个心智的背叛。
:::

有影响力的印刷公众，正是有人试图加以管控的公众。[[#def-public]]之所以把审查官包括在内，是因为不受约束的流通只是后世的幻想。这里没有禁书名录可供照抄，本课也不会编写一份。

:::example 两个书名，同一年 {#ex-1762}
1762年，《社会契约论》与《爱弥儿》都出版了。为什么把它们当作同一个纲领是错误的？为了让它们开口说话，哪些东西是不允许添加的？
:::solution
它们是同一年出版的两本书：一部政治论著和一本论教育的书，出自同一位作者。[[#def-programme]]指出，日期相同不等于目标相同。你不得编造引文、沙龙谈话，或把两个书名合而为一的口号。《百科全书》第一卷在1751年，相减可知早十一年；贝卡里亚的书在1764年。两者都不属于这一对。这个年份支持的是出版，而不是单一的意志。
:::
:::

## 谁在外面，谁有条件地在里面

女性主持沙龙、从事写作，所以她们处在[[#def-public]]所说的实践之内；她们也被大多数学院拒之门外。主持沙龙不等于拥有席位。两方面缺一不可，但都不必写成场景。本课不会编写任何谈话来证明机智或粗鲁。“大多数学院”就是我们所掌握的证据，具体哪些门、在哪些年份关闭，这里没有锁定。

许多作者接受帝国，所以不能把这个公众定义为帝国的反面。根据“奴隶贸易航程”数据库1501年至1866年的数据表，登船估计为12,521,354人。1866减1501等于365，这是数据覆盖的跨度，而不是任何一年的普查。[[states/atlantic]]禁止给出上岸总数、国别份额、死亡总数和死亡率，本课沿用这一禁令。在《百科全书》开始编纂、贝卡里亚印行他关于刑罚的论著的同时，人们正被押上奴隶船。下船的人少于登船的人，因为有人死了。接受帝国的作者，仍然可以身处公众之内。被排除在外的，包括受《黑人法典》约束的人、被大多数学院拒之门外的女性，以及任何被审查官切断了出版渠道的人。这不是世界历史上唯一的奴隶贸易，本课也不会为了给苦难排名而编造其他贸易的总数。

瓜分也是同一类并存。[[states/east]]把波兰-立陶宛（一个有议会的联邦，而非空白）的覆灭定在1772年、1793年与1795年。从1764年贝卡里亚的书到第一次瓜分是8年。一本论刑罚的书并没有导致这次夺取，议会也不是它的原因。在讨论法律的书籍流通之际，普鲁士、奥地利与俄罗斯消灭了一个国家。论断就是两者并存，而不是一则道德寓言：书籍代表良知，瓜分则代表次一等的欧洲。

:::warning 一个曾经醒来的心智
通常的迷思赋予这些实践同一张面孔、同一个清晨：启蒙运动醒来了，编撰《百科全书》，减轻刑罚，解放思想，然后，既然已经醒来，就导致了法国大革命。这个迷思经不起时间线的检验。1685年的废除敕令与《黑人法典》就在线上；1687年的《原理》不是1751年的《百科全书》；七年战争处在中间；女性主持沙龙，却被拒之门外；奴隶贸易的估计贯穿这些年份。一个心智容纳不下这一切。如果你需要这个迷思，就得删掉那些令它难堪的点，而那些点恰恰就是本课的内容。
:::

:::example 一次虚构的觉醒 {#ex-awoke}
下面这句话为示例而虚构。它不是史料。“1751年，启蒙运动觉醒了，它拒斥帝国，并推动了法国大革命。”哪些可以保留？哪些必须删去？
:::solution
保留1751年，作为《百科全书》第一卷的年份。删去“启蒙运动觉醒了”：那是拟人化，而不是日期。删去“它拒斥帝国”：许多作者接受帝国，《黑人法典》早在1685年就已颁布，而1501年至1866年的登船估计为12,521,354人，与这本书同时代。删去“推动了法国大革命”：三级会议于1789年5月5日开幕，[[revolutions/old-regime]]是从财政危机而不是从这一卷书讲起的。[[#thm-two-publics]]也使1751年与1687年的《原理》保持区分。
:::
:::

## 处在中间的战争

1756年至1763年的七年战争，是处在这些书中间的全球战争，战场遍及欧洲、北美、加勒比、西非与印度。本章不复述战役，也不添加伤亡总数或军队规模。1756减1751等于5，1763减1762等于1，所以《社会契约论》与《爱弥儿》出现在战事的尾声。印刷公众并不是和平中的公众。这场战争，就是“接受帝国”被标上日期之后的样子。

腓特烈二世于1740年入侵西里西亚。这次入侵见[[states/east]]，这里不再重述，只说明这场战争的欧洲一方，包括后来参与瓜分的那个王国。老威廉·皮特（William Pitt the Elder）是本课程的历史注记系于1756年的那位英国大臣。这两人都不是沙龙，也都不是需要讲两遍的战役。

## 并非一场革命的原因

1776年，亚当·斯密（Adam Smith）的《国富论》出版。这是一本讨论帝国世界中的财富与国家权力的书，既不是沙龙纲领，也不是革命的原因。关于这本书，这里就只说这一句。美国《独立宣言》也发表于同一年，它只作为背景：大西洋世界中的一次政治决裂，既不是本章的情节，也不是法国的危机。本课不叙述任何战役。

单一原因需要一条从某个文本通向国家危机的路径，并且证明其他原因都是多余的。我们没有这样的路径。[[revolutions/old-regime]]从财政危机讲起，并追问为什么危机还不等于革命。本课不编造任何赤字。

:::theorem 这些公众不是法国大革命的原因 {#thm-not-cause}
《百科全书》、1762年与1764年的那些书，以及1776年的《国富论》，都不是法国大革命的单一原因。论断仅止于此：它并不是说书籍在政治上无所作为，也不是说1789年没有人读过它们，而是说印刷公众并非充分的原因；本章也不讲述大革命的情节。
:::
:::proof
这些书各有年份。三级会议于1789年5月5日开幕，在这里只作为下一门课程的开端提及。1776年与1789年之间，年份数字相差13；1751年与1789年之间相差38。“这些书催生了那次会议”的说法，填补不了这段间隔。能够推翻[[#thm-not-cause]]的，是一条从其中某本书通向那次开幕的锁定因果链，并证明财政危机是多余的。这样的因果链并不存在。1685年的《黑人法典》与登船估计，是不能把这些书讲成一个告别暴力的心智的又一层理由。读者中或许有人反对奴隶贸易，但反对不等于单一的意志，而且许多作者接受帝国。
:::

1789年5月5日，三级会议开幕。记住这一天，然后就此打住。国民议会、那次宣誓、巴士底狱与八月法令，都不会被借来给本课制造高潮。[[#def-public]]既有实践，也有相邻的事物：一场战争、一部法典、一项贸易、一次瓜分、一位审查官。通向大革命的门是[[revolutions/old-regime]]。走这扇门并不使这些书无所作为，而是拒绝让它们把其他一切事实都变成点缀。

:::example 关于1776年的一句话 {#ex-1776}
1776年，《国富论》出版，美国《独立宣言》也在同年发表。请写出本课允许的关于这本书的那一句话，并说明《独立宣言》在这里可以充当什么。哪些内容不允许添加？
:::solution
这句话是：1776年，亚当·斯密的《国富论》出版，这是一本讨论贸易与帝国世界中的财富与国家权力的书，既不是沙龙纲领，也不是革命的原因。《独立宣言》只作为背景，是同一年大西洋世界中的一次政治行为，既不是本章的情节，也不是法国的危机。你不得叙述战役，不得编造斯密的引文，也不得把这两个文本中的任何一个当作[[#thm-not-cause]]所说的那个原因。三级会议于1789年5月5日开幕，按年份数字相减，是在十三年之后。
:::
:::

:::history
1687年，牛顿的《原理》出版，距1685年《南特敕令》的废除与《黑人法典》的颁布两年。1751年，《百科全书》第一卷问世。1756年至1763年的七年战争，发生在这一卷与1762年那些书之间，战场遍及欧洲、北美、加勒比、西非与印度。这些是同一个世界中的日期，而不是一个正在觉醒的心智。

## 反方论证需要什么

认真的反方论证会说，拒绝因果关系，就让思想沦为点缀。书籍可以有影响，而不必是革命的单一原因：它们可以塑造读者、与审查官周旋，同时仍让财政危机成为[[revolutions/old-regime]]所开启的那扇门。能够扩大书籍作用的，是像这些年份一样锁定的证据，表明某一本具体的书导致了某一项具体的政治行为。我们没有这样的证据。[[sources/argument]]把论断与标签区分开来：论断必须说明是哪一种实践、哪一条边界、哪一年。

:::example 一场编好台词的沙龙 {#ex-salon}
有人编了一段设定在1762年的对话，一位女主人与一位审查官在其中讨论《社会契约论》。即使每句话听起来都很可信，为什么你也必须拒绝它？
:::solution
这段对话是虚构的谈话，而本课不编造沙龙谈话。可信不等于史料。1762年支持的是《社会契约论》与《爱弥儿》的出版，而不是一个场景。审查官作为一种制度属于[[#def-public]]；女主人属于其中，凭的是这样一个事实：女性主持沙龙、从事写作，却被大多数学院拒之门外。这段台词还可能把两本书变成同一个纲领，而这是[[#def-programme]]所禁止的。保留年份与边界即可。
:::
:::

## 通向何处

尚未成为革命的财政危机，见[[revolutions/old-regime]]。三级会议于1789年5月5日在那里开幕，那门课程的情节不在这里讲完。这些书流通期间被抹去的联邦，见[[states/east]]。登船估计所衡量的贸易，以及本章拒绝当作道德寓言的那些废奴法令，见[[states/atlantic]]。作为国家能力、而非作为公众的废除敕令与《黑人法典》，见[[states/fiscal-military]]。标签与原因有何不同，见[[sources/argument]]。

:::summary
- 启蒙公众由印刷、沙龙、学院与审查官构成。它不是单一的纲领，不是一个曾经醒来的心智，也不是囊括所有人的成员资格。
- 《原理》在1687年，《百科全书》第一卷在1751年，两者相隔64年，不属于同一个公众。《社会契约论》与《爱弥儿》在1762年，贝卡里亚的《论犯罪与刑罚》在1764年。
- 1685年10月18日，《南特敕令》在枫丹白露被废除，《黑人法典》也在同年颁布。这些行为与那些书处在同一条线上。
- 女性主持沙龙、从事写作，却被大多数学院拒之门外。本课不编造任何沙龙谈话。
- 许多作者接受帝国。“奴隶贸易航程”数据库1501年至1866年的估计是登船12,521,354人。下船的人少于登船的人，因为有人死了。本课不添加其他总数。
- 1756年至1763年的七年战争是处在中间的全球战争，战场遍及欧洲、北美、加勒比、西非与印度。
- 1776年的《国富论》只用一句话，美国《独立宣言》只作为背景。这些公众不是法国大革命的原因。三级会议于1789年5月5日开幕，作为下一门课程的开端。本课不给出任何赤字。
:::

## 习题

:::exercise 第一卷的年份 {level=1 check="1751"}
《百科全书》第一卷在哪一年问世？（请输入年份。）
:::solution
年份是1751。不要换成《原理》的1687年、《社会契约论》与《爱弥儿》的1762年，或贝卡里亚的1764年。
:::
:::

:::exercise 贝卡里亚的年份 {level=1 check="1764"}
《论犯罪与刑罚》出版于哪一年？（请输入年份。）
:::solution
年份是1764。《社会契约论》与《爱弥儿》在1762年，《百科全书》第一卷在1751年。《国富论》在1776年，那是另一本书，本课只允许用一句话。
:::
:::

:::exercise 从《原理》到《百科全书》 {level=1 check="64"}
《原理》在1687年，《百科全书》第一卷在1751年。按B减A计算，两个年份数字相差多少年？（请输入年数。）
:::solution
1751减1687等于64，年数是64。这不是读者人数，也不会使两本书属于同一个公众。首尾都算会得到65，从而违背本图谱的规则。
:::
:::

:::exercise 主持不等于席位 {level=2}
一本教科书说，女性是启蒙公众的正式成员，因为她们主持沙龙、从事写作。这句话中哪些是真的？它丢掉了哪条边界？
:::solution
女性主持沙龙、从事写作，所以她们处在[[#def-public]]之内。这句话丢掉的是大多数学院紧闭的大门。主持不等于席位。年表没有锁定任何百分比。不要用虚构的沙龙谈话来填补这个缺口。
:::
:::

:::exercise 同一条线上的法典 {level=2}
为什么时间线把1685年的废除敕令与《黑人法典》，放在一条同样标有《原理》《百科全书》与贝卡里亚的线上？哪个故事因此变得更难讲了？
:::solution
1685年有10月18日枫丹白露的废除敕令与《黑人法典》，比《原理》早两年。它与1751年、1764年处在同一条线上，挡住了一个被清洗干净的世纪，以及一场告别残酷的觉醒。[[states/atlantic]]拒绝为这部法典给出死亡总数，[[states/fiscal-military]]把这一年解读为国家能力。1501年至1866年登船12,521,354人的估计，在贝卡里亚之后还延续了很久。
:::
:::

:::exercise 背景不是情节 {level=2}
为什么1776年的美国《独立宣言》只能作为背景？如果你把它当作本章的中心，那是在做什么？
:::solution
1776年的那一句话属于《国富论》。《独立宣言》与它同年，只作为背景，是大西洋世界中的一次政治决裂，既不是法国的危机，也不是[[#thm-not-cause]]所拒绝的那个原因。把它当作中心，就会编造出一场战役。1789年5月5日的三级会议是下一门课程的开端，而不是这里的情节。
:::
:::

:::exercise 怎样才能证明单一原因？{level=3}
有人说，《百科全书》导致了法国大革命，财政危机只是分散注意力的枝节。什么证据能使这一因果论断成为本图谱可以讲授的内容？我们实际掌握的又是什么？
:::hint
单一原因必须使其他原因成为多余。下一门课程从财政危机讲起，而你不得编造任何金额。然后看看从1751年到1789年5月5日的间隔。
:::
:::solution
年表必须锁定一条从《百科全书》通向1789年5月5日三级会议的因果链，并证明财政危机是多余的。它既没有锁定这条链，也没有锁定任何赤字。1789减1751等于38。[[#thm-not-cause]]成立。[[revolutions/old-regime]]从财政危机讲起。1685年的《黑人法典》与同时进行的奴隶贸易，否定了心智早已告别暴力的图景。
:::
:::

:::exercise 划定边界 {level=3}
请运用[[#def-public]]中的实践、奴隶贸易以及1756年至1763年的战争，说明谁处在启蒙公众之外，谁只是有条件地处在其中。什么证据能推翻你划定的边界？
:::hint
“在外面”不是道德等级。接受帝国的作者可以身处公众之内；主持沙龙的女性仍可能被学院拒之门外。登船估计不是一份成员名单。
:::
:::solution
印刷商、作者、沙龙主人、学院成员与审查官都处在这些实践之内，包括接受帝国的作者。主持沙龙、从事写作的女性处在这些实践之内，却在大多数学院之外。在奴隶贸易中被押上船的人不是成员；1501年至1866年12,521,354人的估计也不是一份名单。1756年至1763年的战争表明，同样的年份在欧洲、北美、加勒比、西非与印度发生着作用。能够推翻这条边界的证据是：大多数学院接纳了女性，或者受《黑人法典》约束的人被算作这个公众的一员，或者那场战争与奴隶贸易落在这些书的年份之外。年表中没有这样的证据。
:::
:::
