一个启蒙公众是什么，谁在它之外？这个问题拒绝一个心灵。在这些日期里，没有任何东西是一个叫做启蒙运动的人正在醒来，并且决定变得近代。有的却是印刷、沙龙、科学院与审查官，以及散开着的一批书，各有它们自己的年份。1687年，牛顿（Newton）的《自然哲学的数学原理》（Principia）出版。1751年，《百科全书》（Encyclopédie）第一卷出现。1762年，卢梭（Rousseau）的《社会契约论》（Social Contract）与《爱弥儿》（Emile）出现。1764年，贝卡里亚（Beccaria）的《论犯罪与刑罚》（On Crimes and Punishments）出现。这些不是一个纲领。一部1687年的科学论著不是一个沙龙，一个沙龙也不是一个已经把所有人都放进来的科学院。

谁在它之外，是定义的一部分。女性主持并且写作，却被大多数科学院关在门外。许多写作者接受帝国。那桩贸易与这些书同时发生：在奴隶贸易航行数据库覆盖1501至1866年的表上，估计登船者12,521,354人。本课不会为那个数字发明一条航线、一个下船总数、一个国别份额、一个死亡总数，或一个死亡率。下船的人少于登船的人，因为有人死了。七年战争，1756至1763年，坐在这些日期的中间，是在欧洲、北美、加勒比、西非与印度打的。1685年10月18日，《南特敕令》在枫丹白露（Fontainebleau）被废除，而同一年《黑人法典》（Code Noir）颁布。那次废除与那个法典和这些书处在同一条线上。

这一切都不导致法国大革命。下一门课程从一场财政危机开启，在[[revolutions/old-regime]]，而不是从一本书。三级会议于1789年5月5日开幕。那个日期是下一门课程的开场。它不是本章的情节。不会发明任何赤字。1776年，一句话就够《国富论》（Wealth of Nations）用了，而美国的《独立宣言》只是背景。

## 诸公众，不是一个心灵

:::definition 启蒙公众 {#def-public}
一个**启蒙公众**（Enlightenment public）是这样一组实践：论辩借它流通，并且受到约束——印刷、沙龙、科学院与审查官。它不是一个纲领，不是一个心灵，也不是一个人人包括在内的成员资格。写作者们互相争执。他们许多人接受帝国。女性可以主持、可以写作，却仍然被大多数科学院关在门外。审查官是这个公众的一部分，而不是历史从外部对它的一次打断。
:::

在你相信那个大写字母之前，先把定义带到一个日期那里去。一本书有一个年份。一个沙龙是在人前说话，常常在一所由女性主持的宅子里，而本课不会发明那些谈话。一个科学院有成员，而大多数科学院把女性关在门外。“大多数”不是一个百分比。审查官准许、拖延或阻止印刷，所以这个公众不是一片自由的场地。一个能够废除一种宗教宽容的国家，也能够管制一本书。那种能力就是[[states/fiscal-military]]。在这里它是一个公众的边缘。时代的心灵是一种拟人化：若干实践被给予一个意志，这个意志随后导致随后到来的一切。[[#def-public]]挡住那个意志。实践不会醒来。

:::theorem 《原理》与《百科全书》不是一个公众 {#thm-two-publics}
牛顿的《原理》，1687年出版，属于一个比沙龙与《百科全书》更早的科学公众。《百科全书》的第一卷，1751年，属于一个后来的集体印刷的公众。它们不是一个事件，也不是一个纲领。论断到此为止。它没有把自然哲学从后来的那些书里流放出去，也没有说1751年没有人读过牛顿。它是说这些日期不得被熔化进一次单一的觉醒。
:::
:::proof
年份就是证据。1751减1687是64。一部科学书与一部集体百科全书的第一卷，相隔六十四年，不是一次出版。这个图形把两者放在同一条线上，仍然要求你拒绝那个等同。会构成对[[#thm-two-publics]]的反证的，是证明《原理》与那第一卷是在同一个公众、同一个年份里产生的，或者证明科学与沙龙是同一个拥有同一个成员的制度的两个名字。它们不是。一个在1751年知道《原理》的读者显示的是传播。传播不是同一性。这里没有任何东西是物理学史，而那个间隙也不是把这两本书一起称为欧洲开始思想的那个时刻的许可证。
:::

1685年10月18日，在枫丹白露，路易十四（Louis XIV）废除了《南特敕令》——它是对胡格诺派的一种有限宽容，不是平等。同一年，《黑人法典》为法国殖民地奴隶制颁布。[[states/fiscal-military]]把这一对用作作战与管制宗教的能力。[[states/atlantic]]把这个法典用作法律，而不是一条船、一个船舱或一套程序。1687减1685是2。一部数学书与一个奴隶法典是邻居，不是同一个文本，而更晚的《百科全书》不从它们继承一个道德空白。

沙龙没有圆点，因为沙龙不是一个供发明谈话的年份。《国富论》与三级会议以散文讲授。七年战争坐在《百科全书》与《社会契约论》之间。一个六年的窗口不会把1685与1764变成一个下午。这条线是一组日期，不是一种觉醒的情绪。

:::example 六十四年，两本书 {#ex-principia-encyclopedie}
《原理》出版于1687年。《百科全书》的第一卷是1751年。这两个年份数字之间隔着多少年，你为什么不得称这一对为一个事件？（请输入年数。）
:::solution
1751减1687是64。跨度是64年。一部科学书与一部集体百科全书的开卷不是一次出版，也不是一个公众。[[#thm-two-publics]]就是那个论断。这个数字不是读者的计数，也不是一个心灵醒来的时刻。加上1以求首尾计入，会给出65，并且会打破本图谱的规则。
:::

## 并不一致的诸书

1762年，两本书出现：《社会契约论》与《爱弥儿》。一部政治论著与一本关于教育的书，即便在同一个写作者的名字之下，也不是一个纲领。本课不会引用它们，也不会把它们合并成一句口号。从《百科全书》第一卷的1751年算起，年份数字相差11。共享的读者仍然可以争吵。争吵就是“不是一个纲领”的意思。

1764年，贝卡里亚的《论犯罪与刑罚》是又一部书，关于刑事法律。1764减1762是2。近不是同一。一部关于犯罪的印刷论辩不是每一个国家的政策，也没有废除审查官。不会发明一部制定法来显示某个政府抄了那本书。一本书显示一个论辩被印行了。它没有显示那个论辩起了统治作用。

:::definition 不是一个纲领 {#def-programme}
**不是一个纲领**（not one programme）的意思是：被收集在一个后来的名字之下的那些书与制度，并未共享一整套目标。1751年的《百科全书》、1762年的《社会契约论》与《爱弥儿》、1764年的《论犯罪与刑罚》，可以在同一个十年里被阅读，并且仍然互相矛盾。这个短语不是说这些书无足轻重。它说读者不得挑选她喜欢的那个句子，把它称为启蒙运动，并把别的句子当作一个心灵的背叛。
:::

起了作用的印刷公众，是有人试图管制的公众。[[#def-public]]把审查官包括进来，是因为没有约束的流通是后来的幻想。没有一份被查禁书目的登记可以抄录，这里也不会写出一份。

:::example 两个书名，同一年 {#ex-1762}
1762年，《社会契约论》与《爱弥儿》都出版了。把它们当作一个纲领为什么是一个错误？为了让它们说话，你被禁止添什么？
:::solution
它们是同一年里的两本书：一部政治论著与一本关于教育的书，在一个写作者的名字之下。[[#def-programme]]说共享的日期不是共享的目标。你被禁止发明一句引文、一场沙龙谈话，或一句把两个书名合并的口号。《百科全书》的第一卷是1751年，按相减早十一年，而贝卡里亚的书是1764年。两者都不是这一对。这个年份支持的是出版。它不支持一个单一的意志。
:::
:::

## 谁在外面，谁以某种条件在里面

女性主持沙龙并且女性写作，所以她们在[[#def-public]]的实践之内。她们也被大多数科学院关在门外。主持不是一个席位。两半都是必需的，两半都不是场景。不会编写任何一场谈话来证明聪明或无礼。“大多数科学院”是我们拥有的证据。具体的门，带着具体的年份，在这里没有被锁定。

许多写作者接受帝国，所以这个公众不能被定义为帝国的反面。登船估计是12,521,354人，在奴隶贸易航行数据库1501至1866年的表上。1866减1501是365，那是那个覆盖的跨度，不是任何一个单独年份的一次普查。[[states/atlantic]]禁止一个下船总数、一个国别份额、一个死亡总数与一个死亡率。本课继承这个禁令。人们登船的时候，《百科全书》正在开始，贝卡里亚正在印行一场关于刑罚的论辩。下船的人少于登船的人，因为有人死了。一个接受帝国的写作者仍然可以是在公众之内的。谁在外面，包括被《黑人法典》的法律束缚的人、被大多数科学院拒之门外的人，以及任何被审查官切断了印刷的人。这不是世界历史上唯一的奴隶贸易。不会为了给苦难排名而发明另一桩贸易的总数。

历次瓜分是同一种并存。[[states/east]]把对波兰-立陶宛——一个有议会、不是白纸的联邦——的抹除，定在1772年、1793年与1795年。从贝卡里亚的1764年到第一次瓜分是8年。一本关于刑罚的书不导致那次夺取，议会也不是那次夺取的原因。普鲁士、奥地利与俄罗斯在关于法律的诸书流通之时移除了一个国家。并存就是那个论断。它不是一个道德，在其中这些书是一个良心，而历次瓜分是一个次等的欧洲。

:::warning 一个曾经醒来的心灵
通常的迷思给这些实践一张脸和一个早晨。启蒙运动醒来了，撰写《百科全书》，宽缓刑罚，解放思想，然后，因为已经醒着，导致了法国大革命。这个迷思活不过那条线。那次废除与《黑人法典》就在线上，在1685年。《原理》，1687年，不是《百科全书》，1751年。七年战争在中间。女性主持，而被关在门外。那桩贸易的估计贯穿这些年。一个心灵装不下这一切。如果你需要这个迷思，你就得删掉使它尴尬的那些圆点。那些圆点就是本课。
:::

:::example 一次发明出来的觉醒 {#ex-awoke}
下面这句话为示例而虚构。它不是史料。“1751年，启蒙运动醒来了，拒绝了帝国，并使法国大革命开始转动。”你可以保留什么，必须剪掉什么？
:::solution
保留1751，作为《百科全书》第一卷的年份。剪掉“启蒙运动醒来了”：那是一个拟人化，不是一个日期。剪掉“拒绝了帝国”：许多写作者接受帝国，《黑人法典》在1685年就已经存在，而1501至1866年的登船估计是12,521,354，与这本书同时。剪掉“使法国大革命开始转动”。三级会议于1789年5月5日开幕，而[[revolutions/old-regime]]从一场财政危机开始，不是从这一卷。[[#thm-two-publics]]也使1751与1687年的《原理》保持分开。
:::
:::

## 中间的那场战争

七年战争，1756至1763年，是这些书中间的那场全球战争，是在欧洲、北美、加勒比、西非与印度打的。本章不复述那些战役，也不添加伤亡总数或军队规模。1756减1751是5，1763减1762是1，所以《社会契约论》与《爱弥儿》坐在战事的末端。一个印刷的公众不是一个和平的公众。这场战争就是“接受帝国”在被定上年份之后的样子。

腓特烈二世在1740年入侵了西里西亚。那次入侵在[[states/east]]讲授，这里不重打一次。它只标示：这场战争的欧洲一侧包括那个后来分享历次瓜分的王国。老威廉·皮特（William Pitt the Elder）是本课程的历史注记把他系于1756年的那位英国大臣。这两个人都不是沙龙，也都不是要讲述两遍的战役。

:::quiz
哪一个描述适用于1687年与1751年？
- [ ] 它们是同一个事件，一个单一的启蒙心灵的一次觉醒。
- [ ] 它们是《南特敕令》的废除与《黑人法典》。
- [x] 它们是两部出版物，《原理》与《百科全书》的第一卷，而且不是一个公众。
- [ ] 它们是七年战争的开始与结束之年。
:::solution
1687年是牛顿的《原理》。1751年是《百科全书》的第一卷。1751减1687是64。[[#thm-two-publics]]拒绝把它们熔化。那次废除与《黑人法典》是1685年。七年战争是1756至1763年。一次觉醒不是一个日期。
:::

## 不是一场革命的起因

1776年，亚当·斯密（Adam Smith）的《国富论》出版，一本关于财富与诸国家的权力在一个帝国世界里的书，不是一个沙龙纲领，也不是一场革命的起因。那一句就是这里关于这本书的全部。美国的《独立宣言》在同一年，而它只是背景：大西洋世界里的一个政治断裂，不是这里的情节，也不是法国的危机。不会叙述任何一场战役。

一个单一的原因将需要一条从一个文本通往一个国家的危机的路径，并且表明别的原因是多余的。我们没有那条路径。[[revolutions/old-regime]]从一场财政危机开始，并且追问一场危机为什么还不是一场革命。不会发明任何赤字。

:::theorem 这些公众不导致法国大革命 {#thm-not-cause}
《百科全书》、1762年与1764年的那些书，以及1776年的《国富论》，并不作为一个单一的原因导致法国大革命。论断到此为止。它不是说这些书在政治上无所作为，也没有说1789年没有人读过它们。它是说一个印刷的公众不是一个充足的原因，而本章不会讲述大革命的情节。
:::
:::proof
这些书有它们的年份。三级会议于1789年5月5日开幕，在这里是作为下一门课程的开场而点名的。在1776与1789之间，年份数字相差13，在1751与1789之间相差38。那个间隙不会被“这些书产生了那个会议”填上。会构成对[[#thm-not-cause]]的反证的，是一条锁定的因果链，从这些书名中的一个通向那个开幕，并且表明财政危机是多余的。没有这样一条链。1685年的《黑人法典》与那个登船估计，是进一步的理由，使我们不能把这些书讲成一个把暴力留在身后的心灵。读者们可能反对过那桩贸易。反对不是一个单一的意志，而许多写作者接受帝国。
:::

1789年5月5日，三级会议开幕。记住那一天，然后停下来。国民议会、那次宣誓、巴士底狱与八月的法令，不会被借来给本课一个高潮。[[#def-public]]有实践，也有邻居：一场战争，一个法典，一桩贸易，一次瓜分，一个审查官。通往大革命的那扇门是[[revolutions/old-regime]]。用那扇门不会使这些书无所作为。它拒绝让这些书把每一个别的事实变得只有装饰作用。

:::example 1776年的一句话 {#ex-1776}
1776年，《国富论》出版，同一年还有美国的《独立宣言》。写出本课就这本书允许的那一句话，并说出《独立宣言》被允许是什么。你不被允许添什么？
:::solution
那句话是：1776年，亚当·斯密的《国富论》出版，一本在一个贸易与帝国的世界里关于财富与诸国家的权力的书，不是一个沙龙纲领，也不是一场革命的起因。《独立宣言》只是背景，是同一年大西洋世界里的一个政治行为，不是本章的情节，也不是法国的危机。你不得叙述一场战役，不得发明一句斯密的引文，也不得把这两个文本中的任何一个当作[[#thm-not-cause]]里被点名的那个原因。三级会议于1789年5月5日开幕，按年份数字相减是十三年之后。
:::
:::

:::history
1687年，牛顿的《原理》出版，在1685年《南特敕令》的废除与《黑人法典》的两年之后。1751年，《百科全书》的第一卷出现。七年战争，1756至1763年，是在那一卷与1762年的诸书之间的间隙里打的，在欧洲、北美、加勒比、西非与印度。这些是一个世界里的日期。它们不是一个正在觉醒的心灵。
:::

## 一个反方论证需要什么

一个认真的反方论证会说，拒绝因果关系使这些思想只有装饰作用。书可以起作用，而不必是一场革命的单一原因。它们可以塑造读者、与审查官争吵，并且仍然把一场财政危机留作[[revolutions/old-regime]]打开的那扇门。会扩大它们的作用的，是一份证据——像这些年被锁定一样被锁定的、表明一本点名的书产生了某个点名的政治行为的证据。我们没有它。[[sources/argument]]把一条论断与一个标签分开。论断必须说出哪一个实践、哪一条界线、哪一个年份。

:::example 一场写好了台词的沙龙 {#ex-salon}
为什么你必须拒绝一段发明出来的对话，设在1762年，一位女主人和一个审查官在里面讨论《社会契约论》，即便每一句话听上去都很可信？
:::solution
那段对话是一场发明出来的谈话，而本课不发明沙龙谈话。可信不是一份史料。1762年支持的是《社会契约论》与《爱弥儿》的出版，不是一个场景。审查官作为制度在[[#def-public]]之内。女主人则作为这样一个事实而在内：女性主持、写作，并且被大多数科学院关在门外。那段台词还会冒把两本书变成一个纲领的危险，而[[#def-programme]]禁止这样。保留年份与界线。
:::
:::

## 通向何处

还不是革命的那场财政危机在[[revolutions/old-regime]]。三级会议在那里开幕，在1789年5月5日，而那门课程的情节不在这里讲完。这些书流通之时被抹除的那个联邦在[[states/east]]。那个估计所测量的那桩贸易，以及本章拒绝当作道德来使用的那些废奴法令，在[[states/atlantic]]。那次废除与《黑人法典》，作为能力而不是作为公众，在[[states/fiscal-military]]。一个标签如何不同于一个原因，在[[sources/argument]]。

:::summary
- 一个启蒙公众是印刷、沙龙、科学院与审查官。它不是一个纲领，不是一个曾经醒来的心灵，不是一个人人的成员资格。
- 《原理》是1687年。《百科全书》的第一卷是1751年。它们相隔64年，不是一个公众。《社会契约论》与《爱弥儿》是1762年。贝卡里亚的《论犯罪与刑罚》是1764年。
- 1685年10月18日，《南特敕令》在枫丹白露被废除，《黑人法典》颁布。那些行为与这些书处在同一条线上。
- 女性主持并且写作，而被大多数科学院关在门外。没有发明任何一场沙龙谈话。
- 许多写作者接受帝国。奴隶贸易航行数据库1501至1866年的估计是登船者12,521,354人。下船的人少于登船的人，因为有人死了。不添加任何别的总数。
- 七年战争，1756至1763年，是中间的那场全球战争，是在欧洲、北美、加勒比、西非与印度打的。
- 1776年，《国富论》得到一句话，而美国的《独立宣言》只是背景。这些公众不导致法国大革命。三级会议于1789年5月5日开幕，作为下一门课程的开端。没有陈述任何赤字。
:::

## 习题

:::exercise 第一卷的年份 {level=1 check="1751"}
《百科全书》的第一卷在哪一年出现？（请输入年份。）
:::solution
年份是1751。不要用1687替换，那是《原理》；不要用1762替换，那是《社会契约论》与《爱弥儿》；不要用1764替换，那是贝卡里亚。
:::
:::

:::exercise 贝卡里亚的年份 {level=1 check="1764"}
《论犯罪与刑罚》在哪一年出版？（请输入年份。）
:::solution
年份是1764。《社会契约论》与《爱弥儿》是1762年。《百科全书》的第一卷是1751年。《国富论》是1776年，它是另一部书，在本课只被允许一句话。
:::
:::

:::exercise 从《原理》到《百科全书》 {level=1 check="64"}
《原理》是1687年。《百科全书》的第一卷是1751年。使用B减A，这两个年份数字之间隔着多少年？（请输入年数。）
:::solution
1751减1687是64。年数是64。它不是读者的计数，也没有使这两本书成为一个公众。首尾计入会给出65，并且会打破本图谱的规则。
:::
:::

:::exercise 主持不是席位 {level=2}
一本教科书说，女性是启蒙公众的完全成员，因为她们主持沙龙并且写作。那个句子里有什么是真的，它丢掉了哪条界线？
:::solution
女性主持并且写作，所以她们在[[#def-public]]之内。那个句子丢掉了大多数科学院的那扇关着的门。主持不是席位。没有任何百分比被锁定。不要用一场发明出来的沙龙谈话来修补那个缺口。
:::
:::

:::exercise 同一条线上的那个法典 {level=2}
为什么这个图形把1685年的那次废除与《黑人法典》放在一条也承载着《原理》、《百科全书》与贝卡里亚的线上？哪一个故事因此变得更难讲了？
:::solution
1685年是10月18日在枫丹白露的废除与《黑人法典》，在《原理》之前两年。与1751年和1764年处在同一条线上，它挡住的是一个打扫干净的世纪，以及一场把残酷留在身后的觉醒。[[states/atlantic]]拒绝为那个法典给出一个死亡总数。[[states/fiscal-military]]把这个年份读作能力。登船者12,521,354人的估计，1501至1866年，在贝卡里亚之后还延续了很久。
:::
:::

:::exercise 背景不是情节 {level=2}
为什么1776年的美国《独立宣言》只被允许作为背景，而如果你把它做成这一章的中心，你是在做什么？
:::solution
1776年的那句话属于《国富论》。《独立宣言》作为背景共享那一年，大西洋世界里的一个政治断裂，不是法国的危机，也不是[[#thm-not-cause]]里被拒绝的那个原因。把它做成中心将是发明一场战役。1789年5月5日的三级会议是下一门课程的开场，不是这里的情节。
:::
:::

:::exercise 什么会显示一个单一的原因？{level=3}
有人说《百科全书》导致了法国大革命，而财政危机只是一个岔题。什么样的证据会使那个因果论断成为本图谱能够教授的东西？而我们拥有的又是什么？
:::hint
一个单一的原因必须使另一个原因成为多余的。下一门课程从一场财政危机开始，而你不得发明一笔钱。然后看一看从1751年到1789年5月5日的间隙。
:::
:::solution
年表将不得不锁定一条从《百科全书》到1789年5月5日三级会议的链，并且表明财政危机是多余的。它既不锁定那条链，也不锁定任何赤字。1789减1751是38。[[#thm-not-cause]]站得住。[[revolutions/old-regime]]从财政危机开始。1685年的《黑人法典》与同时的那桩贸易，挡住了这幅心灵已经离开暴力的图景。
:::
:::

:::exercise 画出那条界线 {level=3}
使用[[#def-public]]里的那些实践、那桩贸易，以及1756至1763年的那场战争，说出谁在一个启蒙公众之外，谁只是在某种条件之下在里面。什么样的证据会构成对你那条界线的反证？
:::hint
在外面不是一种道德等级。一个接受帝国的写作者可以在公众之内。一个主持的女性仍然可以在一个科学院之外。登船估计不是一份成员名单。
:::
:::solution
印刷商、写作者、沙龙主人、科学院成员与审查官在诸实践之内，包括接受帝国的写作者。主持并且写作的女性在那些实践之内，而在大多数科学院之外。在那桩贸易里登船的人不是成员。估计12,521,354人，1501至1866年，不是一份名字的清单。1756至1763年的那场战争显示同样的那些年份在欧洲、北美、加勒比、西非与印度起作用。会构成对那条界线的反证的，是大多数科学院给女性席位，或者《黑人法典》辖下的人被算进这个公众之内，或者那场战争与那桩贸易落在这些书的年份之外。那份证据不在年表里。
:::
:::
