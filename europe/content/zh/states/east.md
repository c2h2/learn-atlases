历次瓜分所消灭的，是一个怎样的政治体？一幅在波罗的海与黑海之间几近空白的地图，已经给出了回答，而且答错了。波兰-立陶宛是一个欧洲大联邦，有国王，也有议会。它不是夹在真正国家之间的空隙，等着懂得治理的邻国来填色。1772年、1793年与1795年，这些邻国把它肢解了；到第三次瓜分，这个联邦作为国家已被抹去。问题在于被消灭的是怎样的政治体，答案不是“一个错误”。

通常叙事中的错误在于那个议会。一个设有议会的联邦，被放在从后世地图看来更为稳固的君主国旁边，被当作宪制上的失败；然后，这种失败又被拿来解释它的覆灭，仿佛邻国是在纠正一个错误。本课拒绝这种道德寓言。夺取领土的是普鲁士、奥地利与俄罗斯，议会这一原因不能取代这些夺取者。本课也不提供人口数字，好让损失显得可以衡量。年表没有锁定这个联邦的任何人口数字，年表允许使用的词是“大”。伪造的人口普查，只会假装规模是一个我们已经掌握的数字。

另有两项拒绝，使这幅地图保持诚实。奥斯曼帝国是巴尔干与黑海地区的一个欧洲强国，而不是局外者。1683年9月12日的维也纳解围属于另一条边疆，与瓜分不是同一个事件。凭借这些瓜分，俄罗斯已经是一个欧洲帝国，不必等到后来的某场革命才算进欧洲史。1701年的普鲁士王冠与1740年腓特烈二世（Frederick II）入侵西里西亚，则是同一故事另一侧的那个崛起中的强国。1756年至1763年的七年战争只占一段，因为它由[[states/enlightenment]]承接。只写一段是一种纪律，而不是轻视。

## 是联邦，而非空白

:::definition 联邦 {#def-commonwealth}
本课所说的**波兰-立陶宛**，是一个欧洲大联邦：一个有议会、有国王的政治体，而不是地图上夹在“算数”的国家之间的空白。“联邦”指的就是这一政治事实。它并不意味着议会明智、平等或有效，也不意味着这个国家是[[states/composite-monarchy]]所说的后世意义上的民族国家。它意味着，确实存在一个可供消灭的国家。
:::

这个定义可以拿到地图上去检验。如果你眼中唯一的波兰，是瓜分之后作为记忆或冤屈出现的那个波兰，那么你就是从覆灭出发，却把它称为地理。1772年以前，这个联邦就在那里，它的议会是其中的一部分，王冠也是。第一次瓜分时，国王是斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基（Stanisław August Poniatowski）。提到他的名字，既不是写传记，也不是引用，而是为了阻止这样一幅图景：一片群龙无首的混乱，有待正规的王国来收拾。国王加议会，是近代早期一种寻常的安排。荷兰共和国有议会而无国王，不列颠既有王冠又有议会，这些事实都没有使那些国家变得不真实，也不会使这个国家变得不真实。

“不是民族国家”不等于“不是国家”。[[states/composite-monarchy]]已经拒绝了更强的那种论断。瓜分消灭的是一个国家，而不是填补一片空白；要让人相信这一点，也不需要人口数字，而年表也没有锁定任何人口数字。

:::theorem 议会不是覆灭所需的原因 {#thm-not-parliament}
波兰-立陶宛有议会。这一事实并不使瓜分成为这个联邦咎由自取，也不能把它的覆灭解释为对一项宪制错误的纠正。论断仅止于此：它不赞美这个议会，也不否认史家对其运作方式仍有争论。它否认的是这样一种道德寓言：手握军队的邻国是医治议会的良方。
:::
:::proof
1772年，普鲁士、奥地利与俄罗斯夺取了领土；1793年与1795年的进一步瓜分抹去了这个联邦。这些才是行为本身。能够推翻[[#thm-not-parliament]]的，是议会在没有外来夺取者的情况下自行解散了国家，或者呈现出这样一种规律：凡有议会的国家都遭瓜分，凡没有议会的国家都得以保全。不列颠的议会就没有被瓜分。对议事程序的严厉评判，并不能取代邻国成为行为者，本课也不会为了归咎而编造这些程序。议会是真实的，归咎才是编造的。
:::

:::example 一片虚构的空白 {#ex-invented-blank}
下面这句话为示例而虚构。它不是史料。“1772年，波兰这片因议会而衰弱的空白，终于被真正的国家填补了。”哪些词可以保留，哪些必须删去？
:::solution
1772这个年份可以保留，即第一次瓜分，普鲁士、奥地利与俄罗斯在这一年夺取了领土。删去“空白”：[[#def-commonwealth]]所说的恰恰相反。删去“因议会而衰弱”和“终于”：两者都把夺取者变成良方，把议会变成过错，而这是[[#thm-not-parliament]]所禁止的。删去“填补”和“真正的国家”，因为它们预设这个联邦原本还不是国家。有依据的句子只是：1772年，领土被夺取了。这既不是对一部宪制的评判，也不是故事的结局，此后还有进一步的瓜分。
:::
:::

## 三个日期，一次覆灭

:::definition 瓜分 {#def-partition}
本章所说的**瓜分**，是邻国从波兰-立陶宛夺取领土的行为。三个日期是1772年、1793年与1795年，它们合起来把这个联邦作为国家抹去了。瓜分不是对受害者议会的裁决，不是人口普查，也与1683年的维也纳解围不是同一个事件。
:::

要把这三个年份读作一系列行为，而不是一声叹息。1772年，夺取开始：普鲁士、奥地利与俄罗斯。国家继续存在，只是缩小了。1793年，第二次瓜分接踵而至；1795年，第三次瓜分，这个联邦作为国家不复存在。从1772年到1795年，年份数字相差23。二十三年足够长，足以否定“它在一个下午就消失了”的说法；也足够短，足以否定“它衰微了几个世纪，直到地图才注意到”的说法。衰微是那片空白所讲的故事；这些日期讲的，则是能够夺取并占有土地的强国的故事。本课不给出三次瓜分中任何一次被夺走的面积，也不给出更换了统治者的人数。两者都是数量，而都没有锁定。

对于1772年，夺取者是有名有姓的：普鲁士、奥地利与俄罗斯。对于1793年与1795年，记录是进一步的瓜分，以及最后的覆灭。这里不另列每一项后续行为的签署者名单，编造这样的名单，就如同编造人口数字。1795年以后，地图上再也没有可以作为国家标出的这个联邦了。被消灭的政治体就是[[#def-commonwealth]]：有国王，有议会，是一个大国，而不是一片空白。

:::example 从第一次瓜分到抹除 {#ex-span-partitions}
第一次瓜分在1772年，第三次在1795年，这个联邦随之作为国家被抹去。两个年份数字相差多少年？这段距离说明了什么？又不能被拿来充当什么？（请输入年数。）
:::solution
1795减1772等于23。按本图谱的规则，跨度是23年，而不是首尾都算的24年。它说明覆灭是一个过程，既不是一个下午的事，也不是没有行为者的缓慢衰微。它不能被拿来充当人口数字、面积，或议会导致这一损失的证据。[[#def-partition]]是邻国的夺取。数字23只是第一次夺取与最终覆灭之间的距离。
:::
:::

在把这些点连成一场战争之前，先移动窗口。1683年的维也纳离第一次瓜分还很远：1772减1683等于89。正因为相隔八十九年，山上的一支援军才不是对波兰-立陶宛的瓜分。1701年的普鲁士王冠与1740年入侵西里西亚，位于这些点之间；七年战争始于1756年，仍早于任何一次瓜分。这条线是一组不同的行为，最后三个点才是覆灭。它们既不是换了名字的维也纳，也不是西里西亚的简单重演。五年的窗口不会让1683年与1795年成为邻居；如果图上看起来如此，那就是窗口太窄，你讲的故事也太顺了。

## 另一条边疆

1683年9月12日，维也纳之围在卡伦贝格（Kahlenberg）被解除。[[states/fiscal-military]]已经拒绝把这次解围称为“欧洲对抗亚洲”，这一拒绝依然有效。本课为同一日期增添另一种用法：奥斯曼帝国并没有因为一次围城失败就退出欧洲政治，它仍是巴尔干与黑海地区的一个强国。这些都是欧洲的地方，一个在那里作战并占有领土的强国，就是欧洲强国。这个说法既不是恭维，也不是同属一种宗教的证明，而是一种政治描述。把这个帝国当作局外者，就是地图把巴尔干推出课程边缘、又对它们的重新出现故作惊讶的做法。

:::definition 欧洲强国 {#def-european}
本课所说的**欧洲强国**，是在欧洲内部（包括巴尔干与黑海沿岸）作战并获取领土的国家，或是与其他这类国家一起处置一个欧洲联邦的国家。奥斯曼帝国符合第一项标准；在瓜分中与普鲁士、奥地利一道行动的俄罗斯，符合第二项。这个说法并不意味着“文明”，也不意味着“亚洲的反面”。
:::

维也纳是前面已经讲过的标志；如果要它代表后来与奥斯曼帝国的一切关系，它就是一个错误的标志。1683年解除的一次围城，不是1772年的一次瓜分。卡伦贝格的那些强国，并不是抹去波兰-立陶宛的那些强国，即使其中有王朝相同。哈布斯堡君主国可以在维也纳出现，后来也可以出现在参与瓜分的宫廷之中。名字相同，不等于事件相同。[[#def-partition]]使这些日期保持分开；只要你让窗口显示出其间的空隙而不是把它藏起来，这幅图也会如此。

这里的限度，与财政一课不编造伤亡数字的限度相同。奥斯曼帝国的欧洲地位，既不由维也纳的死亡人数来证明，也不因那次解围而被否定。年表没有为这次围城、也没有为本章不叙述的任何后来的奥斯曼战争锁定军队规模。本课也不添加年表在这一课里没有给出的条约年份。巴尔干与黑海本身就是论断所在，它们不需要第二场战役才能成立；一场日期出于编造的第二场战役，只会使论断显得更弱，而不是更强。

:::quiz
在本课中，1683年的维也纳解围是什么？
- [ ] 换了个名字的第一次瓜分波兰-立陶宛。
- [ ] 奥斯曼帝国退出欧洲、成为局外者的时刻。
- [x] 另一条边疆：在卡伦贝格解除的一次围城，既不是联邦的覆灭，也不是“欧洲对抗亚洲”。
- [ ] 七年战争的开端。
:::solution
解围发生在1683年9月12日，第一次瓜分在1772年。1772减1683等于89，所以两个事件在性质和时间上都不相同。奥斯曼帝国仍是巴尔干与黑海地区的欧洲强国，[[#def-european]]就是这一描述。七年战争始于1756年。[[states/fiscal-military]]已经拒绝把维也纳变成一种文明本质。
:::
:::

## 普鲁士、西里西亚与一场全球战争

1701年，勃兰登堡选帝侯在普鲁士加冕称王。[[states/fiscal-military]]已经把这次加冕与同年英格兰的《王位继承法》区分开来。这个王号是一个崛起中的强国获得的新法律表述，还不是入侵，也还不是瓜分。从1701年到1740年，年份数字相差39。1740年，腓特烈二世入侵西里西亚，以武力夺取了一个省份。本课不给出军队规模，也不给出该省的收入。财政一课止步于这次入侵，以免1701年只被记成英格兰一项法令的年份。本课接过这条线索，是因为同一个王国后来位列瓜分波兰-立陶宛的强国之中。崛起的强国与瓜分的强国可以是同一个王朝，但瓜分并不因此成为西里西亚的“目的”。西里西亚是一次夺取；联邦则是另一个国家，后来被不止一个夺取者消灭。

人们容易把普鲁士当作成年的国家，把这个联邦当作孩子。这其实是披上普鲁士外衣的“议会有罪论”，[[#thm-not-parliament]]不允许这样做。一次入侵表明一个新王国诉诸战争，并不表明失败者咎由自取，也不表明在一次成功的夺取面前，议会就是缺陷。

七年战争定年为1756年至1763年，战场遍及欧洲、北美、加勒比、西非与印度，并不只是一场宫廷战争。1756减1740等于16，所以这场战争并不是入侵西里西亚，尽管腓特烈二世两次都在场。这一段就是全部叙述：没有战役，没有舰队，没有伤亡总数。这场战争由[[states/enlightenment]]承接，在这里它只是西里西亚与第一次瓜分之间的一个点。1772减1756等于16。瓜分并不是这场于1763年结束的战争中的一段插曲。

:::example 西里西亚不是那场全球战争 {#ex-silesia-seven}
腓特烈二世于1740年入侵西里西亚，七年战争始于1756年，持续到1763年。入侵与开战之间相隔多少年？哪些东西你仍然不能混为一谈？（请输入年数。）
:::solution
1756减1740等于16，入侵与开战相隔16年。你不能把两者混成一场战争，也不能把七年战争缩成宫廷之间的争执：它的战场遍及欧洲、北美、加勒比、西非与印度。你不能给出军队规模。1772年的第一次瓜分还要更晚，它也不是这场于1763年结束的战争中的插曲。
:::
:::

:::warning 空白，以及好用的议会
通常的迷思分两步。第一步，把波兰-立陶宛画成空白，使瓜分看起来像是政治秩序的到来；第二步，发现了议会并归咎于它，于是这片空白就成了咎由自取。两步都在保护夺取者，使他们不必成为句子的主语。一个有议会的大联邦，在1772年、1793年与1795年间被普鲁士、奥地利与俄罗斯消灭了。议会不是那块橡皮擦，空白也不是橡皮擦到来之前那里原有的东西。不要用人口数字来修补这个迷思，年表没有锁定任何人口数字。
:::

## 俄罗斯早已在故事之中

俄罗斯是作为瓜分者进入本图谱的，而不是作为后来某场革命的遥远序幕。1772年，它与普鲁士和奥地利一起夺取领土；1793年与1795年，这个联邦被抹去时，它仍在故事之中。一个能够与另外两个欧洲君主国合伙做到这一点的国家，就是欧洲帝国。[[#def-european]]正是为了包括这一标准而写的。若把俄罗斯留给本课程尚未讲到的一场革命，就等于把瓜分当作普鲁士与奥地利的行为来讲，而在东边留下一片空白。这片空白是假的，东边的夺取者正是覆灭的一部分。

:::theorem 凭借瓜分，俄罗斯已是欧洲帝国 {#thm-russia}
在1772年、1793年与1795年的瓜分中，俄罗斯与其他欧洲强国一起夺取并最终抹去了一个欧洲联邦。因此，俄罗斯在这一时期已经是一个欧洲帝国。论断仅止于此：它不描述俄罗斯的社会、农奴制或教会，也不要求读者赞赏这种夺取，只是拒绝把俄罗斯推迟到后来的某场危机。
:::
:::proof
证据是参与。第一次瓜分点名了俄罗斯，与普鲁士、奥地利并列；后来的瓜分完成了俄罗斯参与开启的覆灭。按照[[#def-european]]，欧洲帝国包括参与处置一个欧洲联邦的国家。能够推翻[[#thm-russia]]的，是证明俄罗斯没有参与瓜分，或证明这个联邦不是欧洲国家，从而夺取它是欧洲之外的行为。[[#def-commonwealth]]堵住了第二条退路；第一条按年表是不成立的。只愿从一场革命讲起俄国史的偏好，并不能证明它缺席；那是一种把参与其事的帝国从句子中删去的选择。限度在于：这里没有任何内容是关于俄罗斯内部治理的历史。但这一限度并不是把这个帝国从1772年删去的理由。
:::

一种“局外者”叙事在维也纳之后把奥斯曼人推出地图，另一种则把俄罗斯推出地图，直到后来的一场革命。两者都把“欧洲”局限为西方的几个宫廷，而瓜分与黑海都与此不符。[[states/atlantic]]拒绝为奴隶贸易编一则欧洲的道德寓言；本课拒绝的，是关于哪些帝国真正在场的另一则寓言。

:::history
1772年，普鲁士、奥地利与俄罗斯从波兰-立陶宛夺取了领土。波兰-立陶宛是一个有议会的大联邦，而不是地图上的空白，当时的国王是斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基。1793年与1795年的进一步瓜分把这个联邦作为国家抹去了。议会不是那块橡皮擦，这一损失也不附带任何人口数字。
:::

:::quiz
1772年、1793年与1795年的瓜分消灭了什么？
- [ ] 一片从来不是国家的空白，后来由真正的君主国填上了颜色。
- [ ] 奥斯曼帝国，它于1683年在维也纳被逐出欧洲。
- [x] 一个有议会和国王的欧洲大联邦，被邻国作为国家抹去了。
- [ ] 1701年的普鲁士王冠，瓜分使它被废除。
:::solution
[[#def-commonwealth]]就是那个政治体，[[#def-partition]]是抹去它的过程。第一次瓜分时的国王是斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基。维也纳是另一条边疆。1701年的普鲁士王冠并没有被瓜分废除。俄罗斯是1772年的夺取者之一，因此[[#thm-russia]]不肯推迟这个帝国的出场。
:::
:::

## 反方论证需要什么

一个无力保卫国家的议会，或许应当出现在更完整的解释之中。这里不这样说，并不是出于客气，而是要区分描述与取代行为者的归咎。议会的程序没有锁定，所以本课不会编造一种机制，再称之为原因。锁定的是夺取。一个删掉普鲁士、奥地利与俄罗斯的原因，即使议会确实是一件拙劣的工具，也已经不成立。能够推翻[[#thm-not-parliament]]的，是议会在邻国缺席的情况下投票使国家不复存在。我们面前没有这样的记录，也没有人口数字。[[sources/argument]]把标签与论断区分开来。“空白”是标签；我们能够检验的论断，是这个联邦在三个日期上被邻国抹去。

:::example 从维也纳到第一次瓜分的距离 {#ex-vienna-gap}
维也纳解围在1683年，第一次瓜分在1772年。请计算两个年份数字之间的年数，并说明为什么不能用这幅图的窗口来掩盖其间的空隙。（请输入年数。）
:::solution
1772减1683等于89，空隙是89年。如果忘了追问其间有什么，五年的窗口会让相距遥远的点显得彼此相关：1701年的普鲁士王冠，1740年的西里西亚，1756年至1763年的七年战争。正是这段空隙，使维也纳成为另一条边疆，而不是一次瓜分。这个数字也不是卡伦贝格的死亡人数。
:::
:::

## 通向何处

印刷、沙龙与审查官所构成的公众，以及处在其中的那场全球战争，见[[states/enlightenment]]。那一章接过1756年至1763年的七年战争，不能被讲成某种心智在这些帝国之外觉醒，而本课刚刚拒绝把这些帝国推出地图。这些帝国同样组织了的奴隶贸易，见[[states/atlantic]]。普鲁士王冠与英格兰银行的财政工具，见[[states/fiscal-military]]。“空白”这类标签与论断有何不同，见[[sources/argument]]。

:::summary
- 波兰-立陶宛是一个有议会和国王的大联邦，既不是地图上的空白，也不因为有了一个名称就成为民族国家。
- 1772年、1793年与1795年的瓜分把它作为国家抹去了。1772年的夺取者是普鲁士、奥地利与俄罗斯。议会不是能够取代这些夺取者的原因，本课也不给出人口数字。
- 奥斯曼帝国是巴尔干与黑海地区的欧洲强国。1683年9月12日的维也纳解围属于另一条边疆，既不是瓜分，也不是“欧洲对抗亚洲”。
- 凭借瓜分，俄罗斯已是欧洲帝国，不必推迟到后来的某场革命。
- 1701年，勃兰登堡选帝侯在普鲁士加冕称王；1740年，腓特烈二世入侵西里西亚。本课不给出军队规模。
- 1756年至1763年的七年战争，战场遍及欧洲、北美、加勒比、西非与印度。这里只用一段，由[[states/enlightenment]]承接。
- 从1683年到1772年是89年，从1772年到1795年是23年。这些距离使一次围城、一次入侵、一场全球战争与一次覆灭不至于混为一个事件。
:::

## 习题

:::exercise 覆灭的年数 {level=1 check="23"}
第一次瓜分在1772年，把联邦作为国家抹去的第三次瓜分在1795年。按B减A计算，两个年份数字相差多少年？（请输入年数。）
:::solution
1795减1772等于23，年数是23。首尾都算会得到24，从而违背本图谱的规则。这个数字不是联邦的人口。
:::
:::

:::exercise 夺取开始的那一年 {level=1 check="1772"}
在瓜分中，普鲁士、奥地利与俄罗斯第一次从波兰-立陶宛夺取领土是在哪一年？（请输入年份。）
:::solution
年份是1772。不要换成后来瓜分的1793年或1795年，也不要换成维也纳解围的1683年，或普鲁士王冠的1701年。
:::
:::

:::exercise 全球战争的结束 {level=1 check="1763"}
七年战争始于1756年，在哪一年结束？（请输入年份。）
:::solution
这场战争在1756年至1763年，所以年份是1763。战场遍及欧洲、北美、加勒比、西非与印度。不要换成入侵西里西亚的1740年，或第一次瓜分的1772年。
:::
:::

:::exercise 日常用语中的归咎 {level=2}
一位同学说，瓜分固然可悲，却也可以理解，因为议会使这个联邦无法成为真正的国家。请改写这一说法，使每个分句都有依据，并说明你必须拒绝什么。
:::solution
有依据的说法是：1772年，普鲁士、奥地利与俄罗斯从一个有议会的大联邦夺取了领土，1793年与1795年的瓜分又把它作为国家抹去。应当拒绝把“可以理解”作为道德判断，也应当拒绝“议会使它不真实”的想法。[[#thm-not-parliament]]使夺取者留在句子之中，[[#def-commonwealth]]保证这个国家在他们动手之前是真实的。本课不添加人口数字，好让悲哀显得可以量化。
:::
:::

:::exercise 围城不是瓜分 {level=2}
为什么不能把1683年9月12日的维也纳解围当作瓜分的开篇？请给出以年份数字计算的距离，以及性质上的差别。
:::solution
1772减1683等于89。那次解围是在卡伦贝格解除了奥斯曼人的围城，而[[states/fiscal-military]]已经拒绝把它解释为“欧洲对抗亚洲”。瓜分则是邻国从波兰-立陶宛夺取领土。解围之后，奥斯曼帝国仍是巴尔干与黑海地区的欧洲强国。无论从性质还是距离看，两者都不能等同。图上的窄窗口也不能抹去这89年。
:::
:::

:::exercise 一段文字，五个战场 {level=2}
本课的写作要求只允许用一段文字写七年战争。这一段必须包含什么？必须拒绝什么？哪一章负责进一步讲述这场战争？
:::solution
它必须把战争定年为1756年至1763年，并列出各个战场：欧洲、北美、加勒比、西非与印度；必须说明这场战争不只是宫廷战争；必须拒绝叙述战役，拒绝给出伤亡总数与军队规模，因为这些都没有锁定；也不能吞并1740年入侵西里西亚或1772年的第一次瓜分。[[states/enlightenment]]会进一步讲述这场战争，把它作为印刷与论辩所构成的公众之中的一个事实，而不是某种心智的觉醒。
:::
:::

:::exercise 什么能使地图成为空白？{level=3}
假设有人主张，这个联邦确实是一片空白，“大”只是客气的形容词。什么证据能支持这一主张？我们掌握的哪些证据反驳它？
:::hint
空白没有议会，没有国王，也没有需要订约才能夺取它的邻国。看看1772年的记录费心记下了什么：夺取者，以及被夺取的那个国家。
:::
:::solution
支持“空白”说的证据，应当是国家的缺席：没有议会，没有王冠，1772年以前没有任何政治行为，只有一片后来由君主国组织起来的空地。我们掌握的恰恰相反。[[#def-commonwealth]]记录了一个有议会的大政治体。第一次瓜分时，国王是斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基。1772年，普鲁士、奥地利与俄罗斯夺取领土，这是针对一个国家而不是针对虚空的行为。后来的瓜分抹去了这个国家，而不是因为注意到它才创造了它。这一论证不需要人口数字，本课也不会为了加强论证而编造。[[#thm-not-parliament]]依然阻止从“它有议会”推到“所以这片空白是咎由自取”。
:::
:::

:::exercise 推迟俄罗斯的出场 {level=3}
一份教学大纲把俄罗斯放进一个标着“留待后来某场革命”的格子里，讲1772年、1793年与1795年时不提它。这份大纲必须否认什么？把俄罗斯放回来又有什么限度？
:::hint
核对第一次瓜分点名的夺取者。然后问：“欧洲帝国”是否被定义成了一种恭维？并没有。
:::
:::solution
这份大纲必须否认俄罗斯在1772年与普鲁士、奥地利一起参与了瓜分，或者否认波兰-立陶宛是欧洲国家，以便让这次夺取不算欧洲政治。两种否认都不成立。[[#thm-russia]]凭借瓜分本身，把这个帝国放进了这个时期。放回来的限度在于：本课不描述俄罗斯的社会、农奴制或教会，也不赞赏这种夺取。但这一限度不是把它的名字从夺取者名单中删去的借口。本课不使用任何后来的革命年份，因为瓜分并不需要它。
:::
:::
