诸次瓜分移除的是哪一种政体？一幅在波罗的海与黑海之间大体空白的地图已经作出了回答，而且它答错了。波兰-立陶宛是一个欧洲大联邦。它有一个国王和一个议会。它不是一个介于真正的诸国家之间、等着被那些懂得如何治理的邻国填色的空隙。公元1772年、公元1793年与公元1795年，这些邻国把它拆开了。到第三次瓜分，联邦作为一个国家被抹除了。被移除的是哪一种政体，这就是那个问题。答案不是“一个错误”。

通常故事里的错误是那个议会。一个有会议的联邦，在那些从后来的地图上看去更结实的君主制旁边，被当作一种宪制上的失败。然后这个失败被要求去解释那次抹除，仿佛邻国们一直是在纠正一个错误。本课拒绝这个道德。普鲁士、奥地利与俄罗斯夺取领土。一个议会不是一个能够取代那些夺取者的原因。同样也不会提供一个人口来让这份损失显得可以被度量。联邦的任何一个人人口数字都没有被锁定。“大”是年表允许的那个词。一份伪造的人口普查只会假装规模是一个我们已经挣得的数字。

另外两个拒绝让这幅地图保持诚实。奥斯曼帝国是巴尔干与黑海的一个欧洲强国，不是一个局外者。公元1683年9月12日的维也纳解围是一条不同的边界，不是与一次瓜分同一个事件。俄罗斯凭借这些瓜分已经是一个欧洲帝国。它不需要先被留待一场后来的革命，才算作欧洲历史。公元1701年的普鲁士王冠与腓特烈二世（Frederick II）公元1740年对西里西亚的入侵，是同一个故事另一侧的那个崛起强国。七年战争，1756至1763年，只得到一段话，因为[[states/enlightenment]]承接它。一段话是一种纪律，不是轻慢。

## 一个联邦，不是一张白纸

:::definition 联邦 {#def-commonwealth}
**波兰-立陶宛**，就本课使用这个名称而言，是一个欧洲大联邦：一个有议会与国王的政体，不是在有分量的诸国家之间的一幅地图上的空白。“联邦”命名的是那个政治事实。它不是说议会是明智的、平等的或有效的。它不是说这个国家是[[states/composite-monarchy]]后来意义上的民族国家。它的意思是，存在一个可供移除的国家。
:::

这个定义是一个你可以带到地图那里去检验的东西。如果你能看见的唯一的波兰，是诸次瓜分之后出现的那个波兰，作为一段记忆或一笔冤屈，你就是从那次抹除出发，并且把它称作了地理。联邦在公元1772年之前就在那里。它的议会是曾经在那里的一部分。王冠也是。斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基（Stanisław August Poniatowski）在第一次瓜分之时是国王。说出他的名字不是立传，也不是引用。它阻止这样一幅图景：一场没有首领的混乱，有待诸正经的王国来收拾。一个国王加一个议会是一种平常的近代早期安排。荷兰共和国有会议而没有国王。大不列颠既有王冠也有议会。这两个事实中的任何一个都没有使那些国家不真实。它也不会使这个国家不真实。

“不是一部民族国家”不是“不是一个国家”。[[states/composite-monarchy]]已经拒绝了那个更强的论断。诸次瓜分移除的是一个国家。它们没有填一张空白，也不需要一个人来令人相信。一个也没有被锁定。

:::theorem 议会不是那次抹除所需要的起因 {#thm-not-parliament}
波兰-立陶宛有一个议会。这个事实没有使诸次瓜分成为这个联邦自己的过错，也没有把那次抹除解释为对一个宪制错误的纠正。论断到此为止。它不赞扬那个会议，也不否认史家们正在争论它如何运作。它否认的是这样一个道德：有军队的邻国是一个会议的解药。
:::
:::proof
公元1772年，普鲁士、奥地利与俄罗斯夺取领土。公元1793年与公元1795年的进一步瓜分抹除了这个联邦。这些才是那些行为。会构成对[[#thm-not-parliament]]的反证的，是那个会议在没有外部夺取者的情况下解散了这个国家，或者这样一种模式：每一个有议会的国家都被瓜分了，而每一个没有议会的国家都被饶过了。大不列颠的议会没有被瓜分。一个关于程序的严苛裁断不会取代邻国们成为施动者，本课也不会为了归罪而发明那个程序。议会是真实的。罪名才是发明。
:::

:::example 一张发明出来的白纸 {#ex-invented-blank}
下面这句话为示例而虚构。它不是史料。“公元1772年，波兰，一个因其议会而变得软弱的空白，终于被真正的诸国家填上了。”哪些词可以站住，哪些必须剪掉？
:::solution
年份1772可以站住，作为第一次瓜分，普鲁士、奥地利与俄罗斯在其中夺取领土。剪掉“一个空白”：[[#def-commonwealth]]正相反。剪掉“因其议会而变得软弱”与“终于”：两者都把夺取者变成了解药，把一个会议变成了过错，而[[#thm-not-parliament]]禁止这样。剪掉“填上了”与“真正的诸国家”，它们预设了联邦还不是一个国家。受支持的句子只是：领土在公元1772年被夺取了。它不是一个关于宪法的裁断，也不是故事的结尾。进一步的瓜分随后至。
:::
:::

## 三个日期，一次抹除

:::definition 瓜分 {#def-partition}
在本章，一次**瓜分**是邻国们从波兰-立陶宛夺取领土的一个行为。三个日期是公元1772年、公元1793年与公元1795年。它们一起把这个联邦作为一个国家抹除了。一次瓜分不是对受害者的议会的一个判决，不是一次人口普查，也不是与1683年的维也纳解围同一个事件。
:::

把这三个年份读作一组行为的序列，而不是一声长叹。公元1772年，夺取开始：普鲁士、奥地利与俄罗斯。国家延续，只是缩小了。公元1793年，第二次瓜分随之而来。公元1795年，第三次，联邦作为一个国家消失了。从1772年到1795年，年份数字相差23。二十三年足够长，禁止“它在某一个下午消失了”这句话；也足够短，禁止“它淡退了若干世纪，直到地图注意到”这句话。淡退是那张白纸讲的故事。这些日期是能够夺取土地并且守住土地的诸强权讲的故事。我们不会给出这三次中任何一次被夺取的面积，也不会给出转换了统治者的人数。两者都会是数量。两者都没有被锁定。

对于公元1772年，夺取者被点名：普鲁士、奥地利与俄罗斯。对于1793年与1795年，记录是进一步的诸次瓜分，以及最后的那次抹除。谁签署了每一个后来的行为，这样一份单独的名单这里不会印出，发明一份名单会像发明一个人。1795年之后，不再有可以作为一个国家放上地图的联邦。被移除的政体就是[[#def-commonwealth]]：一个国王，一个议会，一个大国家。不是一张白纸。

:::example 从第一次瓜分到抹除 {#ex-span-partitions}
第一次瓜分是公元1772年。第三次是公元1795年，联邦随之作为一个国家被抹除。这两个年份数字之间隔着多少年？这段距离显示了什么，又不得被用作什么？（请输入年数。）
:::solution
1795减1772是23。跨度是23年，按本图谱的规则，不是首尾计入的24。它显示那次抹除是一个序列，不是某一个下午，也不是一场没有施动者的缓慢淡退。它不得被用作一个人口、一个面积，或者一个说议会导致了这份损失的证明。[[#def-partition]]是一次来自邻国的夺取。数字23只是第一次夺取与那次抹除之间的距离。
:::
:::

在你让那些圆点变成一场战争之前，先把窗口移动一遍。1683年的维也纳与第一次瓜分隔着一段距离。1772减1683是89。八十九年，正是一座山头上的解围之师不是对波兰-立陶宛的一次瓜分的理由。1701年的普鲁士王冠与1740年的对西里西亚的入侵坐在这些圆点之间，而七年战争始于1756年，仍在任何一次瓜分之前。这条线是一组不同的行为。最后三个圆点是那次抹除。它们不是另一个名字下的维也纳，也不是简单重复的西里西亚。一个五年的窗口不会使1683与1795成为邻居。如果这个图形看起来做到了，那窗口太窄，而你在讲的故事太顺滑。

## 一条不同的边界

公元1683年9月12日，维也纳之围在卡伦贝格（Kahlenberg）被解除。[[states/fiscal-military]]已经拒绝把那次解围称作“欧洲对抗亚洲”。那个拒绝仍然成立。本课添上的是同一个日期的另一种用法。奥斯曼帝国不会因为一次围困失败就离开欧洲政治。它仍然是巴尔干与黑海的一个强权。那些是欧洲的地方。一个在那里作战并且持有领土的强权是一个欧洲强国。这个短语不是恭维，也不是共同宗教的证书。它是一个政治描述。把这个帝国当作一个局外者，正是一幅地图把巴尔干推出课程的边缘、然后对它们的返回装作惊讶的做法。

:::definition 欧洲强国 {#def-european}
一个**欧洲强国**，在这里，是一个在欧洲内部作战并取得领土的国家，包括巴尔干与黑海海岸；或者与别的此类国家联合起来处置一个欧洲联邦的国家。奥斯曼帝国满足第一个检验。俄罗斯在诸次瓜分中与普鲁士、奥地利一起，满足第二个。这个短语不意味着“文明”，也不意味着“亚洲的反面”。
:::

维也纳是已经教过的那个标记，而如果要求它代表后来与奥斯曼帝国的每一段关系，它就是一个错误的标记。1683年被解除的一次围困不是1772年的一次瓜分。卡伦贝格的诸强权不是抹除波兰-立陶宛的诸强权，即便有一个王朝重叠。哈布斯堡君主制可以身在维也纳，也可以在后来到场于瓜分的诸宫廷之中。名字的重叠不是事件的同一。[[#def-partition]]使这些日期保持分开。这个图形也是如此，只要你让窗口显示那个间隙，而不是把它藏起来。

这里的限度，就是当初让财政一课不发明伤亡的那个限度。奥斯曼帝国的欧洲身份不是由维也纳的一个死亡数目证明的，也不是由那次解围否证的。没有为那次围困、或为本章不会叙述的任何后来的奥斯曼战争锁定任何军队规模。我们不会添加年表在这一课没有交给我们的条约年份。巴尔干与黑海就是论断。它们不需要第二场战斗来为真，而一场带着发明日期的第二场战斗会让它们显得更弱，不是更强。

:::quiz
在本课之内，1683年的维也纳解围是什么？
- [ ] 对波兰-立陶宛的第一次瓜分，用了另一个名字。
- [ ] 奥斯曼帝国离开欧洲、变成一个局外者的那个时刻。
- [x] 一条不同的边界：一次在卡伦贝格被解除的围困，不是联邦之被抹除，也不是“欧洲对抗亚洲”。
- [ ] 七年战争的开始。
:::solution
解围是公元1683年9月12日。第一次瓜分是公元1772年。1772减1683是89，所以这两个事件在种类上与时间上都不同。奥斯曼帝国仍然是巴尔干与黑海的一个欧洲强国。[[#def-european]]就是那个描述。七年战争始于公元1756年。[[states/fiscal-military]]已经拒绝把维也纳变成一个文明本质。
:::
:::

## 普鲁士、西里西亚，与一场全球战争

公元1701年，勃兰登堡选帝侯在普鲁士加冕为王。[[states/fiscal-military]]已经把那次加冕与同年英格兰的《王位继承法令》分开了。这个头衔是一个崛起强国的一个新法律句子。它还不是一次入侵，也还不是一次瓜分。从1701年到1740年，年份数字相差39。公元1740年，腓特烈二世入侵西里西亚。一个行省被武装力量夺取。不会给出任何军队规模，也不会给出那个行省的任何收入。财政一课在那次入侵处停下来，是为了让1701年不被仅仅记住为一部英格兰的制定法。本课把这条线接起来，因为同一个王国后来在瓜分波兰-立陶宛的诸强权之列。一个崛起强国和一个瓜分强国可以是同一个王朝，而不使那次瓜分成为西里西亚的“要点”。西里西亚是一次夺取。联邦是另一个国家，在更晚的时候，被不止一个夺取者移除。

诱惑在于把普鲁士做成成年的国家，把这个联邦做成孩子。那是穿了一件普鲁士外衣的议会归罪。[[#thm-not-parliament]]不允许这样。一次入侵显示一个新王国使用战争。它没有显示失败者活该，也没有显示在一个成功的夺取旁边，一个议会是一种缺陷。

七年战争定年为1756至1763年。它是在欧洲、北美、加勒比、西非与印度打的。它不只是一场内阁战争。1756减1740是16，所以这场战争不是对西里西亚的入侵，尽管腓特烈二世在两件事里都有份。这一段话就是全部的叙述。没有战役，没有舰队，没有伤亡总数。[[states/enlightenment]]承接这场战争。在这里它是西里西亚与第一次瓜分之间的一个圆点。1772减1756是16。那次瓜分不是这场在1763年结束的战争的一个插曲。

:::example 西里西亚不是那场世界大战 {#ex-silesia-seven}
腓特烈二世在公元1740年入侵西里西亚。七年战争始于1756年，打到1763年。那次入侵与那次爆发之间隔着多少年？有什么是你仍然不得合并的？（请输入年数。）
:::solution
1756减1740是16。那次入侵与那次爆发相隔16年。你不得把它们合并为一场战争，也不得把七年战争合并为一场内阁的争吵：它是在欧洲、北美、加勒比、西非与印度打的。你不许给一支军队一个规模。第一次瓜分在公元1772年，更晚，而它不是这场在1763年结束的战争的一个插曲。
:::
:::

:::warning 那张白纸，以及那个有用的议会
通常的迷思有两笔。第一笔，它把波兰-立陶宛留成空白，使诸次瓜分看上去像政治秩序的到来。然后它发现了那个议会并且归罪于它，于是那张空白便是活该。这两笔都护住了夺取者，使他们不成为句子的主语。一个有议会的大联邦被普鲁士、奥地利与俄罗斯在公元1772年、公元1793年与公元1795年这些年间移除了。议会不是那块橡皮。那张白纸也不是橡皮到来之前在那里存在的东西。不要用一个人来修补这个迷思。一个也没有被锁定。
:::

## 俄罗斯已经在故事之中

俄罗斯进入本图谱，是作为一个瓜分强国，而不是作为通向后来某场革命的一个遥远序章。公元1772年，它与普鲁士和奥地利一起夺取领土。在公元1793年和公元1795年它仍然在故事之中，那时联邦被抹除了。一个能与另外两个欧洲君主制合伙做到这一点的国家，就是一个欧洲帝国。[[#def-european]]当初写下，就是为了包含那个检验。把俄罗斯留待一场本课还没有到达的革命，就会是把诸次瓜分当作普鲁士与奥地利的行为来教，并且在东边留下一张白纸。那张白纸会是假的。东部的那个夺取者是那次抹除的一部分。

:::theorem 俄罗斯凭借诸次瓜分已经是一个欧洲帝国 {#thm-russia}
在公元1772年、公元1793年与公元1795年的诸次瓜分中，俄罗斯与其他欧洲强权一起行动去夺取，并且最终抹除一个欧洲联邦。因此俄罗斯在这一时期已经是一个欧洲帝国。论断到此为止。它不描述俄罗斯社会、农奴制或教会，也不要求读者去赞美这次夺取。它只是拒绝把俄罗斯推迟到某个后来的危机。
:::
:::proof
证据是参与。第一次瓜分点名的俄罗斯与普鲁士、奥地利在一起。后来的瓜分完成了俄罗斯帮助开始的一次抹除。按[[#def-european]]，一个欧洲帝国包括一个参与处置一个欧洲联邦的国家。会构成对[[#thm-russia]]的反证的，是证明俄罗斯在诸次瓜分中缺席，或者证明这个联邦不是一个欧洲国家，以致夺取它是欧洲之外的一个行为。[[#def-commonwealth]]堵住了第二个出口。第一个在年表上是假的。一种只从一场革命讲起俄国历史的偏好，不是一种缺席的证明。那会是一种把参与其中的帝国从句子里省去的决定。限度：这里没有任何东西是俄罗斯内部治理的历史。这个限度不是把这个帝国从1772年删去的理由。
:::

一种外部者的故事在维也纳之后把奥斯曼人推出地图。另一种把俄罗斯推出地图，直到一场后来的革命。两者都把“欧洲”保持为几个西方的宫廷。诸次瓜分与黑海不肯就范。[[states/atlantic]]为那桩贸易拒绝了一个欧洲的道德。本课拒绝的是那一个关于哪些帝国真正在场的道德。

:::history
公元1772年，普鲁士、奥地利与俄罗斯从波兰-立陶宛夺取领土，那是一个有议会的大联邦，不是地图上的一个空白。斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基是国王。进一步的瓜分在公元1793年与公元1795年把这个联邦作为一个国家抹除。议会不是那块橡皮，也没有任何人把一个人附于那份损失。
:::

- [ ] 公元1701年的普鲁士王冠，诸次瓜分把它废除了。
:::solution
[[#def-commonwealth]]是那个政体。[[#def-partition]]是抹除它的那个序列。第一次瓜分时的国王是斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基。维也纳是一条不同的边界。公元1701年的普鲁士王冠没有被诸次瓜分废除。俄罗斯是1772年的夺取者之一，这就是[[#thm-russia]]不肯推迟这个帝国的原因。
:::
:::

## 反方论证需要什么

一个不能保卫国家的议会，也许属于一个更充分的解释。在这里拒绝这么说不是客气。这是一种描述与一种取代了施动者的归罪之间的区别。会议的诸程序没有被锁定，所以不会发明一个机制，然后把它叫作原因。被锁定的是夺取。一个删除了普鲁士、奥地利与俄罗斯的原因，即便那个议会是一件糟糕的工具，也已经是失败的。会构成对[[#thm-not-parliament]]的反证的，是那个会议在邻国们缺席之时投票使这个国家不复存在。那份记录不在我们面前，一个人也不在。[[sources/argument]]把一个标签与一条论断分开。“空白”是一个标签。我们能够检验的论断是这个联邦之被邻国们在三个日期上抹除。

:::example 从维也纳到第一次瓜分的距离 {#ex-vienna-gap}
维也纳解围是公元1683年。第一次瓜分是公元1772年。计算这两个年份数字之间的年数，并说出这个图形的窗口为什么不得被用来隐藏那个间隙。（请输入年数。）
:::solution
1772减1683是89。间隙是89年。一个五年的窗口能够使遥远的圆点显得相关，如果你忘了问它们之间坐着什么：1701年的普鲁士王冠，1740年的西里西亚，1756至1763年的七年战争。这个间隙正是维也纳是一条不同的边界、而不是一次瓜分的原因。这个数字不是从卡伦贝格来的一个死亡数目。
:::
:::

## 通向何处

印刷、沙龙与审查官的诸公众，以及坐在它们中间的那场全球战争，在[[states/enlightenment]]。那一章继承七年战争，1756至1763年，而且不得被讲述成一个心灵在本课刚刚拒绝把诸帝国推下地图的那些帝国的外面苏醒。那些帝国也组织了的那桩贸易，在[[states/atlantic]]。普鲁士王冠与英格兰银行的财政工具，在[[states/fiscal-military]]。一个像“空白”这样的标签如何不同于一条论断，在[[sources/argument]]。

:::summary
- 波兰-立陶宛是一个有议会与国王的大联邦，不是地图上的一个空白，也不是仅仅因为有一个名字便成的一部民族国家。
- 公元1772年、公元1793年与公元1795年的诸次瓜分把它作为一个国家抹除。在1772年，夺取者是普鲁士、奥地利与俄罗斯。议会不是取代那些夺取者的起因，也没有陈述任何人口。
- 奥斯曼帝国是巴尔干与黑海的一个欧洲强国。公元1683年9月12日的维也纳解围是一条不同的边界，不是一次瓜分，也不是“欧洲对抗亚洲”。
- 俄罗斯凭借诸次瓜分已经是一个欧洲帝国。它没有被推迟到一场后来的革命。
- 勃兰登堡选帝侯在公元1701年在普鲁士加冕为王。腓特烈二世在公元1740年入侵西里西亚。没有给出任何军队规模。
- 七年战争，1756至1763年，是在欧洲、北美、加勒比、西非与印度打的。在这里它是一段话。[[states/enlightenment]]承接它。
- 从1683年到1772年是89年，从1772年到1795年是23年。这些距离使一次围困、一次入侵、一场全球战争与一次抹除不成成为一个事件。
:::

## 习题

:::exercise 抹除的年份 {level=1 check="23"}
第一次瓜分是公元1772年。第三次把联邦作为一个国家抹除，是公元1795年。使用B减A，这两个年份数字之间隔着多少年？（请输入年数。）
:::solution
1795减1772是23。年数是23。首尾计入会给出24，并且会打破本图谱的规则。这个数字不是联邦的一个人口。
:::
:::

:::exercise 夺取开始的那一年 {level=1 check="1772"}
普鲁士、奥地利与俄罗斯在诸次瓜分中第一次从波兰-立陶宛夺取领土是在哪一年？（请输入年份。）
:::solution
年份是1772。不要用1793或1795替换，那是后来的诸次瓜分；不要用1683替换，那是维也纳解围；不要用1701替换，那是普鲁士王冠。
:::
:::

:::exercise 那场全球战争的终结 {level=1 check="1763"}
七年战争始于公元1756年。它在哪个年份结束？（请输入年份。）
:::solution
这场战争是1756至1763年，所以年份是1763。它是在欧洲、北美、加勒比、西非与印度打的。不要用1740替换，那是对西里西亚的入侵；不要用1772替换，那是第一次瓜分。
:::
:::

:::exercise 日常言语中的归罪 {level=2}
一个同学说诸次瓜分令人悲哀但可以理解，因为一个议会使这个联邦无法成为一个真正的国家。重写那个论断，使每一个子句都受到支持，并说出你不得不拒绝什么。
:::solution
受支持的：公元1772年，普鲁士、奥地利与俄罗斯从一个有议会的大联邦夺取领土，而公元1793年与公元1795年的诸次瓜分把它作为一个国家抹除。把“可以理解”作为一个道德拒绝掉，把那个议会使它不成真的想法拒绝掉。[[#thm-not-parliament]]把夺取者留在句子里。[[#def-commonwealth]]在他们行动之前保持这个国家是真实的。没有添加任何人口来让那份悲哀显得有数量。
:::
:::

:::exercise 一次围困不是一次瓜分 {level=2}
为什么公元1683年9月12日的维也纳解围不能被用作诸次瓜分的开篇章？给出以年份数字计的距离与种类上的区别。
:::solution
1772减1683是89。那次解围是一次在卡伦贝格被解除的奥斯曼围困，而[[states/fiscal-military]]已经拒绝“欧洲对抗亚洲”作为它的含义。一次瓜分是邻国们从波兰-立陶宛夺取领土。解围之后，奥斯曼帝国仍然是巴尔干与黑海的一个欧洲强国。种类与距离都使这种等同失败。这个图形的窄窗口不会取消那89年。
:::
:::

:::exercise 一段话，五个战场 {level=2}
简报允许就七年战争写一段话。那一段话必须包含什么，必须拒绝什么，而哪一章被要求承接这场战争？
:::solution
它必须把战争定年为1756至1763年，并且点名诸战场：欧洲、北美、加勒比、西非与印度。它必须说这场战争不只是一场内阁战争。它必须拒绝战役、伤亡总数与军队规模，这些一个也没有被锁定。它不得吞并对西里西亚的入侵（1740年）或第一次瓜分（1772年）。[[states/enlightenment]]更远处承接这场战争，把它当作一个印刷与论辩的公众内部的一个事实，而不是一个心灵的苏醒。
:::
:::

:::exercise 什么会使地图变成白纸？{level=3}
假设有人论断说这个联邦真的是一张白纸，而“大”只是一个客气的形容词。什么样的证据会算作支持那个论断，而我们拥有的什么证据反对它？
:::hint
一张白纸没有议会，没有国王，也没有需要一项条约来夺取它的邻国。看看公元1772年费心记录了什么：夺取者，以及他们从中夺取的那个国家。
:::
:::solution
支持白纸说的证据将是一个国家的缺席：没有议会，没有王冠，公元1772年之前没有任何政治行为，只有空地，诸君主制随后加以组织。我们拥有的是反面。[[#def-commonwealth]]记录了一个有议会的大政体。斯坦尼斯瓦夫·奥古斯特·波尼亚托夫斯基在第一次瓜分之时是国王。普鲁士、奥地利与俄罗斯在公元1772年夺取领土，这是指向一个国家的行为，不是指向一个虚空。后来的诸次瓜分抹除了那个国家。它们没有通过注意它来创造它。这个论证不需要一个人，也不会为了加强它而发明一个。[[#thm-not-parliament]]仍然阻止从“它有一个议会”移动到“所以那张白纸是活该”。
:::
:::

:::exercise 推迟俄罗斯 {level=3}
一个教学大纲把俄罗斯放进一个标着留待后来某场革命的格子里，教公元1772年、公元1793年与公元1795年而不带它。那个教学大纲必须否认什么？把俄罗斯放回有什么限度？
:::hint
检查第一次瓜分点名的夺取者。然后问：“欧洲帝国”是否曾被定义成一种恭维。并没有。
:::
:::solution
那个教学大纲必须否认俄罗斯在1772年与普鲁士、奥地利的参与，或者否认波兰-立陶宛是一个欧洲国家，以致这次夺取不算欧洲政治。两种否认都失败。[[#thm-russia]]凭诸次瓜分本身把这个帝国放进这个时期。把它放回的限度：本课不描述俄罗斯社会、农奴制或教会，也不赞美这次夺取。这个限度不是把这个名字从夺取者的名单上略去的借口。没有使用任何后来的革命年份，因为诸次瓜分不需要一个。
:::
:::
