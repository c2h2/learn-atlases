战争、税收与债务如何造就一个国家？一幅着色的地图回答得太快。它想给法国一种填色、给英格兰一种填色、给一个共和国一种填色，然后配一段说明文字，在其中一个强大的国王是这三者的成年形态。下面的日期不是那架阶梯上的台阶。它们是工具：一份特许状、一次停战、一次处决、一项航海法令、一次复辟、一次登陆、一项权利法案、一家银行、一项继承法令、一个国王头衔、一次联合、一个和平、一次入侵。战争是它们所服务的。税收是臣民被令出钱的方式。债务是一个国家花费它尚不具备的收入的方式。三者都不是道德情绪，也没有哪一个把每一个欧洲政体强行纳入一部宪法。

“造就一个国家”，在这里，不是奠基一个民族。[[states/composite-monarchy]]已经拒绝了对于1556年、1579年、1581年与1707年5月1日的那种读法。这里，一个国家是一个能够再次作战的政体，因为它能够征税与借贷。这种能力可以坐在一个共和国里，坐在一个自我宣扬的君主制里，或者坐在一个杀死一位国王、恢复一位国王、后来又创建一家银行的王国里。本图谱不会印出一个军队规模、一个利率、一个认购额、一个贸易份额或一个难民总数。“许多”是被允许的。一个伪造的数字不被允许。

荷兰共和国在第一个台阶上就拦住了那架阶梯。它富有，它武装，而它不是君主制。这句话就是把那个时期称作专制主义的反对意见，也是把路易十四当作全欧洲的模范的做法的反对意见。他是一个解决方案，大声宣扬过的，而不是那个共和国、英格兰的诸序列与普鲁士头衔的模式。1683年的维也纳解围也不是那个模式。一次在一座城市之上被解除的围困是一个军事日期，不是一个叫做欧洲对抗亚洲的持久事实。

## 一个征税并作战的共和国

在这些财政日期之前，这个共和国已经是一个国家。1579年的乌得勒支同盟使正在与它们的国王作战的诸省结盟。1581年的《废位诏书》免掉了他，并没有安上持久的替代者。西班牙在1648年1月于明斯特承认这个共和国。《威斯特伐利亚和约》——明斯特与奥斯纳布吕克加在一起——是1648年10月24日。教授那个和约的是[[reformations/religious-war]]，以及那个警告：一个完成形态的主权理论是一种后来的读法。承认并没有创造出征税与作战的能力。

荷兰东印度公司（VOC）的特许状是1602年。这个共和国授权一家公司。公司不是共和国，共和国也不是一个伪装起来的国王。没有锁定任何资本、任何船队与任何利润，所以什么也不会被发明。那一年所支持的已经足够：一个非君主制能够在与西班牙的战争尚未结束之时委派武装贸易。从1602年到1648年，两个年份数字相差46。特许状比承认更古老。一个共和国要等到西班牙签字才成为真实的说法，必须解释那个间隙。

:::definition 财政—军事国家 {#def-fiscal}
一个**财政—军事国家**（fiscal-military state）是这样一种政体：它通过征税并组织债务来保持作战的能力，以至于武装力量不限于箱中已有的钱币或单独一场战役。这个短语点名一种压力与一组工具。它不点名一部宪法。它不要求一个君主。它不是说荷兰共和国、法国与英格兰在不同旗帜之下拥有同样的官职。
:::

把这个定义用作检验。如果一个行为为武装力量付钱、决定谁可以贸易、或者停止一场战争，它就属于这里，无论有没有国王。对西里西亚的入侵在1740年属于一次对一块可征税行省的夺取，而不是一个关于聪明的故事。检验是行为的种类，不是一次人数统计。

十二年停战始于1609年，持续到1621年。从年份A到年份B，跨度是B减A。加上1会打破那条规则。1621减1609是12。一次停战是一次暂停，不是退役，也不是荷兰东印度公司已把共和国带出战争的证据。1621年，它结束。不会提供任何战役与船队。

:::theorem 一个财政—军事国家不必是一个君主制 {#thm-not-monarchy}
荷兰共和国在1602年特许荷兰东印度公司、在1609年进入十二年停战，是一个富有的武装国家而不是君主制。因此，财政—军事压力不选择单一的宪制类型。这个论断到此为止。它不是说共和国是民主的、温和的，或者没有寡头制，它也不说一份特许状与一个在省区会议中投票通过的税是同一个文书。
:::
:::proof
1581年之后，诸省没有在一个持久的国王之下安定，而它们仍然作战。它们在1602年特许一家公司，并在1609年缔结一次持续到1621年的停战。西班牙在1648年1月承认那个共和国。会构成对[[#thm-not-monarchy]]的反证的，是这样一个论证：那份特许状与那次停战是一位国王的行为，或者那个共和国不能征税、不能作战。对国王的偏爱不是那个论证，“专制主义”这个标签也不是。一个富有的武装共和国是这个时期的一部分，而不是一个为了救标签而归档的例外。限度：这里没有任何东西使这个共和国成为民主的或温和的。
:::

:::example 特许状先于停战 {#ex-voc-truce}
荷兰东印度公司于1602年获得特许状。十二年停战始于1609年。那两个年份数字之间隔着多少年，而那个顺序禁止你说什么？（请输入年数。）
:::solution
1609减1602是7。特许状在前。停战没有创造公司，公司也没有把共和国带出战争。数字7是一个距离，不是船只的计数，也不是利润。
:::
:::

:::example 一次发明出来的退役 {#ex-invented-voc}
下面这句话为示例而虚构。它不是史料。“1602年，荷兰民族缔造了一个现代经济，并把战争抛在身后。”那一年支持哪些子句，哪些子句是被添加的？
:::solution
那一年支持1602年荷兰东印度公司的特许状——来自那个在1581年弃绝了它的国王的共和国。剪掉“荷兰民族”“现代经济”“把战争抛在身后”。1609年的停战是一次暂停，而它在1621年结束。一份特许状不是对战争的辞职。
:::
:::

## 一个宫廷，大声宣扬

路易十四（Louis XIV）回应同一种压力。他不是每一个别的回应的模子。一个统治仍然被要求代表整个大陆，因为那个宫廷把自己宣扬得那么好。这些日期显示一个君主制能够监管宗教，并且在同一年为殖民地奴隶制立法。它们没有把荷兰共和国、英格兰银行或维也纳之围变成那个宫廷的复制品。

《南特敕令》曾是对胡格诺派的一种有限宽容，不是平等。1685年10月18日，在枫丹白露（Fontainebleau），路易十四废除了它。这个行为不是税收，而它仍然属于这里。王冠能够决定谁可以礼拜，并且能够惩罚这个决定。统一性是国家权力的一种使用。人们离去。没有锁定任何难民人数，而一个人数不会被发明。

在同一年，《黑人法典》（Code Noir）为法国殖民地奴隶制颁布。[[states/atlantic]]承接这个法典、那桩贸易，以及不发明一个死亡总数的拒绝。这里的要点是能力，不是一条船的船舱。一个君主制在1685年能够废除一种有限宽容，并颁布一个殖民地奴隶法典。这两个行为不是一个主题，也不是两个世纪。把宗教归档在欧洲名下、把法典归档在“帝国，以后再说”名下，就打破了一个年表保持完整的年份。

:::theorem 一个宣扬过的解决方案不是这个时期的模范 {#thm-not-model}
路易十四的君主制在1685年10月18日废除《南特敕令》、并在同一年颁布《黑人法典》，是把王权接上宗教监管与殖民地法律的一种方式。它不是全欧洲的模范。这个论断到此为止。它不否认那种能力，也不把这次废除与另一个国家的工具放在一个我们并不拥有的量表上排名。
:::
:::proof
荷兰共和国富有而武装，而不必是这个君主制。下面的英格兰诸行为不模仿枫丹白露。1701年的普鲁士王冠是一个新头衔，不是向北派送的一部法国宪法。1683年的维也纳解围是一场奥斯曼战争，不是一次宫廷仪式。会构成对[[#thm-not-model]]的反证的，是这样一个论证：那些政体分享了路易的官职、他的宗教解决方案与他的殖民地法典。一个共同的赢得战争的愿望不是那个论证。把那个时期称为专制主义，就掩盖了这个区别，而[[states/composite-monarchy]]已经把它拒绝为一个时期之名。
:::

:::warning 专制主义，以及一个国王的模范
这个迷思把这个时代称为专制主义，仿佛每一个严肃的国家都是一个没有刹车的国王，然后把路易十四作为完成形态的范例端出来。一个共和国、一个议会与一个奥斯曼帝国就都成了偏差。这个迷思在1602年的荷兰东印度公司特许状面前，或者在一次废除与一个奴隶法典被保持在同一年面前，都存活不下来。能力是真实的。单一的模范不是。不要用军队规模来修补它。没有一个被锁定。
:::

## 一次解围不是一个文明

1683年9月12日，维也纳之围在卡伦贝格（Kahlenberg）被解除。一支奥斯曼军队在城市之前。一支解围的部队打破了围困。这就是处于战争中的诸国家：一座哈布斯堡的城市，奥斯曼帝国，以及山上的诸王公。它不是两个大陆亲自出面。“欧洲对抗亚洲”把一次解围变成一种本质，然后把其余一切纷争都吞进去。年表禁止那个做法。

我们没有那张账单，伤亡也不会被发明。双方都能在那里放上一支军队。奥斯曼帝国是巴尔干的一个欧洲强国，不是来自历史之外的天气。[[states/east]]带着黑海与历次瓜分回到那个问题。从1683年到1685年，两个年份数字相差2。那次废除是一个邻居，不是同一个行为，也不是一次基督教世界的危机。

:::quiz
1683年9月12日的维也纳解围是什么的证据？
- [ ] 一场欧洲对抗亚洲的持久冲突，此后奥斯曼帝国站在欧洲政治之外。
- [ ] 路易十四成为每一个欧洲国家的模范的那一刻。
- [x] 一次在卡伦贝格被解除的围困：处于战争中的诸国家，不是一种文明本质。
- [ ] 英格兰银行的创建，它支付了这次解围。
:::solution
解围是1683年9月12日，而它不是作为持久事实的“欧洲对抗亚洲”。英格兰银行是1694年，按相减是十一年之后，而它没有为卡伦贝格付过钱。枫丹白露是1685年10月18日。[[#thm-not-model]]使这次围困不被归档在路易的宫廷名下。
:::
:::

## 工具，不是一次道德进步

英格兰的日期是一个序列，不是一支箭。一次处决不导致一家银行，一家银行不赎回一次处决，一次复辟不取消一项法令。一个自由成长起来的故事不在这些日期里。

1649年1月30日，查理一世（Charles I）被处死。国家继续存在。弑君不是税收，也不是一次民主革命。战争保持未讲，不给任何军队一个规模。[[states/composite-monarchy]]已经拒绝把那次断裂，或者那次复辟，变成一个民族国家。一次处决决定了谁可以统治。它不奠基公共信用。

1651年，《航海条例》把航运与殖民地贸易系于英格兰的权力。没有锁定任何份额，所以不会发明任何百分比。1651减1649是2。运输与杀死一位国王是同时进行的工具，不是一个道德序列。[[states/atlantic]]不会把那片大洋变成一个隐喻。

1660年，复辟送回一位国王。从1649年到1660年，两个年份数字相差11。这次返回打破了任何从弑君通向一个没有国王的未来的箭。没有英格兰君主制的十一年，使一个只能想象国王的时期之名尴尬。它们不是民主，它们也不是荷兰共和国。

:::definition 党派性的名称 {#def-partisan}
一个**党派性的名称**（partisan name）是一个后来的标签，它赞扬一个解决方案的一方，并偷偷带入那个解决方案并不具备的一个结果。“光荣革命”是奥兰治的威廉（William of Orange）在1688年的登陆、以及重申议会地位的在1689年的《权利法案》的一个党派性的名称。这个标签说荣耀。那些日期说一位天主教国王被取代，并且议会的地位被重述。它们没有说一次民主已经开始。
:::

1688年，奥兰治的威廉登陆。1689年，《权利法案》重述议会的地位。一位天主教国王被取代，王冠继续存在，而议会不再是一位客人。一笔必须经过一个议会批准的拨款，是一种与一个宣扬索取权的国王不同的工具。这不是一次民主：不会发明任何选民，而《权利法案》也不会被引用。[[#def-partisan]]里的那个绰号添上了荣耀与一个新纪元的气息。1689减1688是1。银行还在前面，而[[revolutions/old-regime]]不是这次登陆的后来讲述。

:::definition 公共信用 {#def-credit}
**公共信用**是一个国家通过一个放贷者能够识别的制度、而不是只以已经征收到的财富作抵，针对未来的收入借贷的能力。1694年的英格兰银行是有日期的英格兰案例。这个定义不固定一个利率、一个数额，或者一个债务是明智的判断。债务能够支撑一场战争。债务也能够毁掉一个政府。它做到哪一个，不由一家银行的创建来决定。
:::

1694年，这家银行使债务成为一个官署。放贷者面对的是一个制度，不只是一个王子的承诺，而国家能够为又一场战争借贷。没有锁定任何数额。1694减1689是5。银行没有撰写《权利法案》。不要从这次创建发明一个法国赤字：没有锁定，而[[revolutions/old-regime]]正是把一场财政危机与一场革命分开讲授的地方。把1694年放在1602年的特许状与1685年的废除旁边。三个工具，三个政体。那个对照就是[[#thm-not-model]]。

1701年，《王位继承法令》为英格兰王冠固定一个新教的王位继承——在汉诺威一系之中——并为之附加条件。同一年，勃兰登堡选帝侯在普鲁士加冕为王。一年，两个制度。[[states/east]]沿着这个普鲁士头衔跟进西里西亚与历次瓜分。一个新王冠不是那家银行，而1701年不是一个英格兰的私人周年。

1707年5月1日，《联合法案》在安妮女王之下联合英格兰与苏格兰。上一课有那个宪制论点：一项法令，不是诸民族的一次自然合并，爱尔兰在外面。在这里，贸易与王位继承被联合起来，而交易中没有锁定任何数额。这个联合是图上的一个工具，不是一个自1649年以来成熟起来的民族。

1713年，《乌得勒支和约》结束一场战争。1713减1694是19，所以这家银行已经年老。这个和平不废除《航海条例》，也不把1688年变成一次民主革命。年表里缺席的条款保持不写。乌得勒支是这些工具之间的和平。

为什么从1649年到1713年的英格兰序列不是一次道德进步？
- [ ] 因为英格兰银行在1694年失败了，而公共信用被证明是不可能的。
- [ ] 因为1651年的《航海条例》恢复了查理一世，并把处决撤销了。
- [x] 因为这些日期是不同的工具，而1660年的复辟把一位国王放回去，所以这条线不是一支通向民主的箭。
- [ ] 因为1713年的乌得勒支废除了议会，并模仿了对南特的废除。
:::solution
[[#def-fiscal]]收集税收、债务与武装力量，不收集美德。一位国王在1660年返回，处在1649年的处决与1694年的银行之间，所以这条线不是一支箭。1713年的乌得勒支没有制定1685年的那次废除，也没有任何我们说过的、银行可能在其中失败的数额。
:::
:::

## 反方论证需要什么

一个认真的反方论证不会重复战争是昂贵的。它会说这些工具是一件戏服，穿在一个到处同时到来的现代国家身上。压力是相似的：作战的国家寻找金钱。压力的相似不是官职的相同。[[#thm-not-monarchy]]与[[#thm-not-model]]是那种相同性的两次失败。一个非君主制就在这个集合里，而声音最大的君主制不是其余诸国的模式。

[[sources/argument]]把一条论断与一个标签分开。专制主义、“欧洲对抗亚洲”与“光荣革命”是标签。它们只有靠一次官职的真实匹配才能获救：荷兰东印度公司作为一家王室公司，《权利法案》作为一部民主宪法，乌得勒支作为枫丹白露的复制品，维也纳作为一场诸大陆的战争。赞美显示一次宣扬。[[#def-fiscal]]本身只有当每一个行为通过税收、债务、武装力量或一次停止战争的决定而赢得这个名字时，并且当那个缺失的数字保持缺失时，才是安全的。

## 通向何处

与那次废除同一年的《黑人法典》，打开了[[states/atlantic]]：大西洋贸易的尺度允许我们说什么，以及什么我们不可以发明。1701年的王冠与1740年的入侵在[[states/east]]回归，奥斯曼帝国作为一个欧洲强国，而波兰-立陶宛是被瓜分移除的，不是因为拥有一个议会被责备。标签与论断在[[sources/argument]]。一家银行不是一块大陆：[[sources/scale]]。1648年10月24日的和平仍然是[[reformations/religious-war]]。

:::summary
- 一个财政—军事国家通过税收与有组织的债务来支撑武装力量。这个短语不点名一部宪法，也不要求一个国王。
- 荷兰共和国富有、武装，而不是君主制。荷兰东印度公司于1602年获得特许状。十二年停战始于1609年，持续到1621年。西班牙在1648年1月的承认不创造那种能力。
- 路易十四是一个解决方案，不是全欧洲的模范。1685年10月18日，他在枫丹白露废除《南特敕令》。《黑人法典》在同一年，[[states/atlantic]]承接它。
- 1683年9月12日，维也纳之围在卡伦贝格被解除。那不是作为持久事实的“欧洲对抗亚洲”。
- 英格兰的日期是工具，不是道德进步：1649年1月30日处死查理一世，1651年的《航海条例》，1660年的复辟，威廉在1688年的登陆，1689年的《权利法案》，1694年的英格兰银行。
- “光荣革命”是一个党派性的名称。一位天主教国王被取代，议会的地位被重述。它不是一次民主革命。
- 1701年，《王位继承法令》与普鲁士王冠是两个事件。1707年5月1日的联合与1713年的《乌得勒支和约》是更多的工具。1740年，腓特烈二世入侵西里西亚。没有说出任何军队规模。
:::

## 习题

:::exercise 停战的长度 {level=1 check="12"}
十二年停战始于1609年，持续到1621年。使用B减A，那两个年份数字之间隔着多少年？（请输入年数。）
:::solution
1621减1609是12。停战的名字与本图谱的规则相合。加上1以求首尾计入，会得到13，而会打破那条规则。结果是12年，而它不是士兵的计数。
:::
:::

:::exercise 银行的年份 {level=1 check="1694"}
英格兰银行创建于哪一年？（请输入年份。）
:::solution
英格兰银行创建于1694年。《权利法案》是1689年。《乌得勒支和约》是1713年。不要用那两者替换，也不要用1688替换，那是奥兰治的威廉登陆的年份。
:::
:::

:::exercise 从权利法案到银行 {level=1 check="5"}
《权利法案》是1689年。英格兰银行是1694年。那两个年份数字之间隔着多少年？（请输入年数。）
:::solution
1694减1689是5。议会的地位先被重述。公共信用作为一个制度，随后到来。数字5不把《权利法案》变成一家银行，也不把一家银行变成一次民主。
:::
:::

:::exercise 日常言语中的一个党派性的名称 {level=2}
一个同学说“光荣革命”，仿佛它是一个民主奠基的平常名字。使用1688年与1689年，改写那个说法，使每一个子句都受支持，并说出哪个词在做党派性的工作。
:::solution
受支持的说法是：1688年威廉登陆，1689年《权利法案》重述议会的地位。一位天主教国王被取代。“光荣”在做党派性的工作，而“革命”暗示一个新时代。[[#def-partisan]]抓住了这一点。1694年的银行不是这个事件，而那个结果不是一次民主。
:::
:::

:::exercise 《航海条例》不是一种情绪 {level=2}
为什么把1651年的《航海条例》当作1649年1月30日处死查理一世的和平续篇是一个错误？为了让这个法令显得有效，你被禁止发明什么数量？
:::solution
1651减1649是2。一个行为免掉一位国王。另一个把航运与殖民地贸易系于英格兰的权力。那不是一种和平的情绪。1660年的复辟显示这个序列不是一支离开诸国王的箭。不要发明一个贸易百分比。没有一个被锁定。
:::
:::

:::exercise 同一年，两个主题 {level=2}
1685年10月18日，《南特敕令》在枫丹白露被废除。在1685年，《黑人法典》颁布。为什么本课必须同时提到两者，又为什么必须拒绝解释这个法典的内容？
:::solution
一年装着一场宗教的废除与一个殖民地奴隶法典，所以它们不是两个世纪。要点是能力。[[#thm-not-model]]阻止那种能力变成全欧洲的模式。这个法典的内容，以及任何一条船的船舱，属于[[states/atlantic]]，那里同样禁止一个伪造的死亡总数。
:::
:::

:::exercise 什么会使这个共和国成为一个君主制？{level=3}
假设有人接受荷兰人作战与贸易，但坚持说财政—军事国家按定义是一个君主制，所以这个共和国只是一个名誉上的例外。什么样的证据会支持那种坚持，而我们实际拥有的什么证据反对它？
:::hint
按顺序看看弃绝、特许状与承认。一个你必须不断为之道歉的例外，通常就是打破定义的那个案例。
:::
:::solution
那种坚持将需要一位在1581年之后持久的国王，而1602年的特许状与1609年的停战是他的行为。弃绝没有安上任何这样的国王。西班牙在1648年1月承认一个共和国，而1648减1602是46。[[#thm-not-monarchy]]站得住。限度：这个共和国可以是寡头的、武装的。它仍然不是一次民主。
:::
:::

:::exercise 什么会使维也纳成为一场诸大陆的战争？{level=3}
一个叙事说，1683年9月12日是欧洲击败亚洲的一天，并且每一场别的奥斯曼战争都是同一场战争。什么样的证据会支持那个论断，而你必须说什么作为替代——包括你自己的论点的限度？
:::hint
一种持久的本质需要的不止是一座城市的一次解围。问：要显示奥斯曼帝国是在欧洲政治之外，而不是参与一次围城的一方，需要什么。
:::
:::solution
那个论断将需要奥斯曼帝国在欧洲诸战争之外，而卡伦贝格作为诸文明的相遇。我们拥有的是在1683年9月12日被解除的一次围困。那个持久的公式被拒绝。[[states/east]]把那个帝国当作巴尔干与黑海的一个欧洲强国来处理。拒绝这个口号不使这次围困显得小，也不允许一个伤亡总数或一个军队规模。1685年10月18日的枫丹白露，是一个不同的主题。
:::
:::
