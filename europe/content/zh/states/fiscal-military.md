战争、税收与债务如何造就国家？着色地图回答得太快了。它想给法国、英格兰和一个共和国各涂一种颜色，再配上一段说明，把强势的国王说成三者共同的成熟形态。下面的日期并不是这架阶梯上的台阶，而是一件件工具：一份特许状、一次停战、一次处决、一项航海法令、一次复辟、一次登陆、一项法案、一家银行、一项王位继承法、一个王号、一次合并、一项和约、一次入侵。它们为战争服务。税收是迫使臣民出钱的方式，债务是国家花费尚未到手之收入的方式。三者都不是道德情绪，也没有哪一项迫使所有欧洲政治体都纳入同一种宪制。

这里所说的“造就国家”，并不是缔造民族。[[states/composite-monarchy]]已经拒绝了对1556年、1579年、1581年与1707年5月1日的那种解读。这里的国家，是因为能够征税和借贷、所以能够一再作战的政治体。这种能力可以存在于共和国中，存在于大肆自我宣扬的君主国中，也可以存在于一个处死国王、复立国王、后来又创办银行的王国中。本图谱不会给出军队规模、利率、认购金额、贸易份额或难民总数。可以说“许多”，但不能伪造数字。

荷兰共和国在第一级台阶就挡住了这架阶梯：它富庶，有武装，却不是君主国。这句话既是反对把这个时期称为专制主义的理由，也是反对把路易十四当作全欧洲模板的理由。他只是一种大肆宣扬的解决方式，而不是共和国、英格兰的事件序列与普鲁士王号的模式。1683年的维也纳解围也不是这种模式。一座城市的围困被解除，是一个军事日期，而不是一种名为“欧洲对抗亚洲”的永恒事实。

## 一个征税并作战的共和国

在这些财政日期之前，这个共和国已经是一个国家。1579年的乌得勒支同盟把正在与国王作战的各省联合起来；1581年的《誓绝法案》废黜了国王，却没有另立持久的继任者。1648年1月，西班牙在明斯特承认了这个共和国；由明斯特和约与奥斯纳布吕克和约共同构成的威斯特伐利亚和约，签订于1648年10月24日。这项和约见[[reformations/religious-war]]，那里也提醒：成熟的主权理论是后来的解读。征税与作战的能力并不是承认所创造的。

荷兰东印度公司（VOC）的特许状颁发于1602年。共和国授权一家公司；公司不是共和国，共和国也不是乔装的国王。资本、船队和利润都没有锁定，因此一概不予编造。这个年份所能支持的已经足够：一个非君主制的国家，可以在对西班牙的战争尚未结束时，把武装贸易委托出去。从1602年到1648年，年份数字相差46。特许状早于承认。认为共和国要等西班牙签字才算真正存在的说法，必须解释这段间隔。

:::definition 财政—军事国家 {#def-fiscal}
**财政—军事国家**（fiscal-military state）是通过征税和组织债务来维持作战能力的政治体，其武装力量因此不受金库中现有钱币或单次战役的限制。这个术语指的是一种压力和一组工具，而不是某一种宪制。它不要求君主，也不意味着荷兰共和国、法国与英格兰在不同旗帜下拥有相同的官职。
:::

不妨把这个定义当作检验：一项行为，只要是为武装力量付钱、决定谁可以经商或终止一场战争，无论有没有国王，都属于这里。1740年入侵西里西亚之所以属于这里，是因为它夺取了一个可以征税的省份，而不是因为它讲的是谋略高明。检验看的是行为的类型，而不是人数统计。

十二年停战从1609年开始，持续到1621年。从A年到B年的跨度是B减A，加1就违背了这条规则。1621减1609等于12。停战是暂停，而不是退出，也不能证明荷兰东印度公司已经带着共和国走出了战争。1621年停战结束。这里不补充任何战役或船队。

:::theorem 财政—军事国家不必是君主国 {#thm-not-monarchy}
1602年特许荷兰东印度公司、1609年进入十二年停战的荷兰共和国，是一个富庶而武装的国家，却不是君主国。因此，财政—军事压力并不只选择一种宪制类型。论断仅止于此：它不说共和国是民主的、温和的或没有寡头统治，也不说特许状与省议会投票通过的税收是同一种工具。
:::
:::proof
1581年以后，各省没有在某位持久的国王治下安定下来，却依然在作战。它们在1602年特许了一家公司，1609年订立了持续到1621年的停战。1648年1月，西班牙承认了这个共和国。能够推翻[[#thm-not-monarchy]]的，是证明特许状与停战出自某位国王，或证明这个共和国既不能征税、也不能作战。偏爱国王不是这样的证明，“专制主义”这个标签也不是。一个富庶而武装的共和国是这个时期的一部分，而不是为保住标签而另册登记的例外。限度在于：这里没有任何内容表明这个共和国是民主的或温和的。
:::

:::example 特许状早于停战 {#ex-voc-truce}
荷兰东印度公司于1602年获得特许状，十二年停战始于1609年。两个年份数字相差多少年？这个先后顺序不允许你说什么？（请输入年数。）
:::solution
1609减1602等于7。特许状在先。停战没有创造这家公司，公司也没有带着共和国走出战争。数字7是一段距离，既不是船只的数量，也不是利润。
:::
:::

:::example 一次虚构的退出 {#ex-invented-voc}
下面这句话为示例而虚构。它不是史料。“1602年，荷兰民族创建了现代经济，从此告别战争。”这个年份支持哪些分句？哪些分句是添加的？
:::solution
这个年份支持的是1602年荷兰东印度公司的特许状，颁发者是1581年弃绝了国王的共和国。应当删去“荷兰民族”“现代经济”和“从此告别战争”。1609年的停战只是暂停，并在1621年结束。特许状并不意味着退出战争。
:::
:::

## 一个大肆宣扬的宫廷

路易十四（Louis XIV）回应的是同一种压力，但他并不是其他一切回应的模子。人们仍然要用这一朝来代表整个大陆，只因这个宫廷太善于自我宣扬。这些日期显示，一个君主国能够监管宗教，并在同一年为殖民地奴隶制立法；它们并没有使荷兰共和国、英格兰银行或维也纳之围成为这个宫廷的翻版。

《南特敕令》曾给予胡格诺派有限的宽容，而非平等。1685年10月18日，路易十四在枫丹白露（Fontainebleau）废除了它。这一行为不是税收，却仍属于这里：王权能够决定谁可以礼拜，并能惩罚违抗者。宗教统一是国家权力的一种运用。人们出走了。难民人数没有锁定，这里也不编造。

同一年，法国为其殖民地奴隶制颁布了《黑人法典》（Code Noir）。这部法典、奴隶贸易，以及拒绝编造死亡总数的原则，见[[states/atlantic]]。这里的要点是国家能力，而不是船舱。1685年，同一个君主国既能废除有限的宽容，又能颁布殖民地奴隶法典。这两项行为不是同一个主题，也不属于两个世纪。把宗教归入“欧洲”，把法典归入“帝国，以后再讲”，就把年表完整保留的一个年份拆散了。

:::theorem 一种大肆宣扬的解决方式并非时代的模板 {#thm-not-model}
路易十四的君主国在1685年10月18日废除《南特敕令》，并在同一年颁布《黑人法典》，这是把王权与宗教监管和殖民地法律结合起来的一种方式，而不是全欧洲的模板。论断仅止于此：它不否认这种能力，也不把这次废除与其他国家的工具放在一把我们并不具备的标尺上排序。
:::
:::proof
荷兰共和国富庶而武装，却不是这样的君主国。下文英格兰的种种法令并没有仿效枫丹白露。1701年的普鲁士王冠是一个新的王号，而不是一部输往北方的法国宪法。1683年的维也纳解围是一场奥斯曼战争，而不是宫廷礼仪。能够推翻[[#thm-not-model]]的，是证明这些政治体共享路易的官职、他的宗教安排和他的殖民地法典。共同希望赢得战争，并不是这样的证明。把这个时期称为专制主义，就掩盖了其间的差别，而[[states/composite-monarchy]]已经拒绝把专制主义当作时期名称。
:::

:::warning 专制主义，以及以一王为模板
这个迷思把这个时代称为专制主义，仿佛每个像样的国家都是没有刹车的国王，然后把路易十四当作完美范例端出来。于是，共和国、议会和奥斯曼帝国都成了偏离。这个迷思经不起1602年荷兰东印度公司特许状的检验，也经不起同一年里既有废除敕令又有奴隶法典的检验。能力是真实的，单一的模板却不是。不要用军队规模来修补它，年表并没有锁定任何军队规模。
:::

## 一次解围并不代表一种文明

1683年9月12日，维也纳之围在卡伦贝格（Kahlenberg）被解除。一支奥斯曼军队兵临城下，一支援军打破了包围。这是国家之间的战争：一座哈布斯堡城市、奥斯曼帝国，以及山上的诸侯。这并不是两个大洲亲自上阵。“欧洲对抗亚洲”把一次解围变成一种本质，进而吞没了其他一切纷争。年表不允许这样做。

我们没有这场战争的账单，也不编造伤亡人数。双方都能在那里部署一支军队。奥斯曼帝国是巴尔干地区的一个欧洲强国，而不是来自历史之外的天灾。[[states/east]]会结合黑海与历次瓜分再谈这一点。从1683年到1685年，年份数字相差2。那次废除敕令与它相邻，却不是同一项行为，也不构成基督教世界的同一场危机。

:::quiz
1683年9月12日的维也纳解围，是什么的证据？
- [ ] 欧洲对抗亚洲的永恒冲突，此后奥斯曼帝国置身于欧洲政治之外。
- [ ] 路易十四成为每个欧洲国家模板的时刻。
- [x] 在卡伦贝格解除的一次围困：国家之间的战争，而不是一种文明本质。
- [ ] 英格兰银行的创建，它为这次解围出了钱。
:::solution
解围发生在1683年9月12日，并不是作为永恒事实的“欧洲对抗亚洲”。英格兰银行创建于1694年，相减可知晚了十一年，它并没有为卡伦贝格出钱。枫丹白露敕令在1685年10月18日。[[#thm-not-model]]防止把这次围困归入路易的宫廷名下。
:::
:::

## 是工具，而非道德进步

英格兰的这些日期是一个序列，而不是一支箭头。处死国王并不导致银行的出现，银行并不为处死国王赎罪，复辟也不取消一项法令。一个关于自由逐渐成长的故事，并不在这些日期之中。

1649年1月30日，查理一世（Charles I）被处死，国家依然存在。弑君既不是税收，也不是民主革命。这里不叙述战争，也不给出任何军队的规模。[[states/composite-monarchy]]已经拒绝把这次断裂或后来的复辟说成民族国家的形成。处死国王解决的是由谁统治的问题，并没有奠定公共信用。

1651年，《航海条例》把航运与殖民地贸易同英格兰的国家权力绑在一起。年表没有锁定任何份额，因此不编造任何百分比。1651减1649等于2。海运与弑君是同时并用的工具，而不是一个道德序列。[[states/atlantic]]不会把大洋变成比喻。

1660年，王政复辟使国王归来。从1649年到1660年，年份数字相差11。国王的归来打断了任何从弑君指向无君未来的箭头。英格兰没有君主的十一年，令一个只能想象国王的时期名称陷于尴尬；但这些年既不是民主，也不是荷兰共和国。

:::definition 党派性名称 {#def-partisan}
**党派性名称**（partisan name）是后来的标签，它褒扬某项安排中的一方，并偷偷塞进该安排本身并不具有的结果。“光荣革命”就是对1688年奥兰治的威廉（William of Orange）登陆、以及1689年重申议会地位的《权利法案》的党派性名称。标签说的是荣耀；日期说的是一位天主教国王被取代，议会的地位得到重申，并没有说民主就此开始。
:::

1688年，奥兰治的威廉登陆；1689年，《权利法案》重申了议会的地位。一位天主教国王被取代，王权延续下来，议会则不再是客人。必须经议会通过的拨款，与一位宣扬自己有权索取的国王，是两种不同的工具。但这不是民主：这里不编造选民，也不引用《权利法案》的原文。[[#def-partisan]]中的那个称号，添上了荣耀和新时代的暗示。1689减1688等于1。银行还在后面，而[[revolutions/old-regime]]讲的也不是这次登陆的后续。

:::definition 公共信用 {#def-credit}
**公共信用**是国家通过放贷者认可的机构、以未来收入为担保借款的能力，而不只是以已征收的财富为担保。1694年的英格兰银行是英格兰有确切日期的案例。这个定义不确定利率或金额，也不判断举债是否明智。债务可以支撑一场战争，也可以拖垮一个政府；究竟如何，并不由一家银行的创建来决定。
:::

1694年，这家银行使债务成为一项制度。放贷者面对的是一个机构，而不只是君主的承诺，国家也因此能为下一场战争借款。年表没有锁定任何金额。1694减1689等于5。《权利法案》并不是银行写的。不要从银行的创建推想出一个法国赤字：年表没有锁定这样的数字，而把财政危机与革命区分开来，正是[[revolutions/old-regime]]的任务。把1694年与1602年的特许状、1685年的废除敕令并置：三种工具，三个政治体。这一对照就是[[#thm-not-model]]。

1701年，《王位继承法》为英格兰王位确定了汉诺威一系的新教继承顺序，并附加了条件。同一年，勃兰登堡选帝侯在普鲁士加冕称王。同一年，两项制度。[[states/east]]会沿着这个普鲁士王号追踪到西里西亚与历次瓜分。新的王冠不是那家银行，1701年也不是英格兰独有的纪念日。

1707年5月1日，《联合法案》在安妮女王治下合并了英格兰与苏格兰。宪制上的要点见上一课：这是一项法令，而不是民族的自然融合，爱尔兰不在其内。在这里，贸易与王位继承得到统一，交易中的金额没有锁定。这次合并是图上的一件工具，而不是自1649年以来逐渐成熟的一个民族。

1713年，《乌得勒支和约》结束了一场战争。1713减1694等于19，可见银行已经运作多年。这项和约既没有废除《航海条例》，也没有把1688年变成民主革命。年表中没有的条款，这里一概不写。乌得勒支是这些工具中的那项和约。

为什么从1649年到1713年的英格兰事件序列不是一种道德进步？
- [ ] 因为英格兰银行在1694年失败了，公共信用被证明行不通。
- [ ] 因为1651年的《航海条例》让查理一世复位，撤销了对他的处决。
- [x] 因为这些日期是不同的工具，而1660年的复辟让国王重新登位，所以这条线不是指向民主的箭头。
- [ ] 因为1713年的乌得勒支和约废除了议会，并仿效了南特敕令的废除。
:::solution
[[#def-fiscal]]汇集的是税收、债务与武装力量，而不是美德。国王在1660年回来了，介于1649年的处决与1694年的银行之间，所以这条线不是箭头。1713年的乌得勒支和约并没有颁行1685年的废除敕令，本课也没有给出任何可以用来说明银行失败的金额。
:::
:::

## 反方论证需要什么

认真的反方论证不会只是重复战争花费巨大。它会说，这些工具只是同一个现代国家在各地同时出现时所穿的戏装。压力的确相似：要打仗的国家都在找钱。但压力相似不等于官职相同。[[#thm-not-monarchy]]与[[#thm-not-model]]正是这种“相同”的两处破绽：这个集合里有一个非君主国，而宣扬得最响的君主国也不是其他国家的模式。

[[sources/argument]]把论断与标签区分开来。专制主义、“欧洲对抗亚洲”与“光荣革命”都是标签。只有官职真正吻合，它们才能得到挽救：荷兰东印度公司是王室公司，《权利法案》是民主宪法，乌得勒支和约是枫丹白露的翻版，维也纳是大洲之间的战争。赞美只证明了宣传。[[#def-fiscal]]本身也只有在每一项行为都凭借税收、债务、武装力量或终止战争的决定而名副其实，并且缺失的数字始终保持缺失时，才是可靠的。

## 通向何处

与废除敕令同年的《黑人法典》开启了[[states/atlantic]]：大西洋贸易的规模允许我们说什么，又有什么不得编造。1701年的王冠与1740年的入侵将在[[states/east]]中再次出现；在那里，奥斯曼帝国是一个欧洲强国，波兰-立陶宛则是被瓜分而消失的，而不是因为拥有议会而受到指责。标签与论断见[[sources/argument]]。一家银行并不代表整个大陆，见[[sources/scale]]。1648年10月24日的和约仍见[[reformations/religious-war]]。

:::summary
- 财政—军事国家依靠税收与有组织的债务维持武装力量。这个术语不指某一种宪制，也不要求国王。
- 荷兰共和国富庶、武装，却不是君主国。荷兰东印度公司于1602年获得特许状。十二年停战从1609年持续到1621年。西班牙1648年1月的承认并没有创造这种能力。
- 路易十四只是一种解决方式，而不是全欧洲的模板。1685年10月18日，他在枫丹白露废除了《南特敕令》。《黑人法典》颁布于同一年，见[[states/atlantic]]。
- 1683年9月12日，维也纳之围在卡伦贝格被解除。这并不是作为永恒事实的“欧洲对抗亚洲”。
- 英格兰的这些日期是工具，而不是道德进步：1649年1月30日处死查理一世，1651年的《航海条例》，1660年的王政复辟，1688年威廉登陆，1689年的《权利法案》，1694年的英格兰银行。
- “光荣革命”是党派性名称。一位天主教国王被取代，议会的地位得到重申。这不是民主革命。
- 1701年的《王位继承法》与普鲁士王冠是两个事件。1707年5月1日的合并与1713年的《乌得勒支和约》是又一批工具。1740年，腓特烈二世入侵西里西亚。本课不给出军队规模。
:::

## 习题

:::exercise 停战的时长 {level=1 check="12"}
十二年停战从1609年持续到1621年。按B减A计算，两个年份数字相差多少年？（请输入年数。）
:::solution
1621减1609等于12。停战的名称与本图谱的规则一致。为了首尾都算而加1，会得到13，从而违背规则。结果是12年，这也不是士兵的人数。
:::
:::

:::exercise 银行的年份 {level=1 check="1694"}
英格兰银行创建于哪一年？（请输入年份。）
:::solution
英格兰银行创建于1694年。《权利法案》在1689年，《乌得勒支和约》在1713年。不要换成这两个年份，也不要换成奥兰治的威廉登陆的1688年。
:::
:::

:::exercise 从《权利法案》到银行 {level=1 check="5"}
《权利法案》在1689年，英格兰银行在1694年。两个年份数字相差多少年？（请输入年数。）
:::solution
1694减1689等于5。先是议会的地位得到重申，然后公共信用作为一项制度出现。数字5既不会把《权利法案》变成银行，也不会把银行变成民主。
:::
:::

:::exercise 日常用语中的党派性名称 {level=2}
一位同学说起“光荣革命”，仿佛这是民主奠基的寻常名称。请用1688年与1689年改写这一说法，使每个分句都有依据，并指出哪个词在起党派作用。
:::solution
有依据的说法是：1688年威廉登陆，1689年《权利法案》重申了议会的地位，一位天主教国王被取代。“光荣”一词在起党派作用，“革命”则暗示了一个新时代。[[#def-partisan]]指出的正是这一点。1694年的银行不是这个事件，其结果也不是民主。
:::
:::

:::exercise 《航海条例》不是一种情绪 {level=2}
为什么把1651年的《航海条例》当作1649年1月30日处死查理一世之后的和平续篇是错误的？为了让这项法令显得卓有成效，你不得编造什么数量？
:::solution
1651减1649等于2。一项行为除掉了一位国王，另一项把航运与殖民地贸易同英格兰的国家权力绑在一起，这谈不上什么和平情绪。1660年的复辟表明，这个序列并不是离国王越来越远的箭头。不要编造贸易百分比，年表没有锁定任何百分比。
:::
:::

:::exercise 同一年，两个主题 {level=2}
1685年10月18日，《南特敕令》在枫丹白露被废除；同在1685年，《黑人法典》颁布。为什么本课必须同时提到两者？又为什么必须拒绝解释法典的内容？
:::solution
同一年里既有宗教上的废除敕令，又有殖民地奴隶法典，所以两者并不属于两个世纪。要点在于国家能力，而[[#thm-not-model]]防止这种能力被说成全欧洲的模式。法典的内容，以及任何船舱里的情形，属于[[states/atlantic]]，那一课同样禁止伪造死亡总数。
:::
:::

:::exercise 什么能使这个共和国成为君主国？{level=3}
假设有人承认荷兰人确实作战、经商，却坚持认为财政—军事国家按定义就是君主国，所以这个共和国只是名义上的例外。什么证据能支持这种坚持？我们实际掌握的哪些证据反驳它？
:::hint
按顺序看誓绝、特许状与承认。一个需要不断为之辩解的例外，往往正是打破定义的那个案例。
:::
:::solution
这种坚持需要1581年以后存在一位持久的国王，而1602年的特许状与1609年的停战都是他的行为。誓绝之后并没有另立这样的国王。西班牙在1648年1月承认的是一个共和国，1648减1602等于46。[[#thm-not-monarchy]]成立。限度在于：这个共和国可以是寡头的、武装的，但它仍然不是民主。
:::
:::

:::exercise 什么能使维也纳成为大洲之间的战争？{level=3}
有一种叙事说，1683年9月12日是欧洲击败亚洲的日子，其他所有奥斯曼战争都是同一场战争。什么证据能支持这一论断？你必须改用什么说法，包括你自己论点的限度？
:::hint
永恒的本质所需要的，远不止一座城市的一次解围。问一问：要证明奥斯曼帝国处在欧洲政治之外，而不是一场围城中的一方，需要什么？
:::
:::solution
这一论断需要证明奥斯曼帝国置身于欧洲战争之外，卡伦贝格是文明之间的相遇。我们掌握的是1683年9月12日一次围困的解除。那种永恒的公式应予拒绝。[[states/east]]把这个帝国当作巴尔干与黑海地区的欧洲强国来讨论。拒绝这个口号并不会使这次围困显得微不足道，也不允许给出伤亡总数或军队规模。1685年10月18日的枫丹白露敕令是另一个主题。
:::
:::
