静电平衡下的导体是一个等势体。多余电荷都分布在它的表面上，而导电材料内部的电场为零。给一个孤立导体放上电荷 $Q$，整个导体就升到同一个电势 $V$，这个 $V$ 从你选定的零点量起。把 $Q$ 加倍，由于静电方程是线性的，每一个电势也随之加倍。于是电荷与电势之比是形状、周围环境和间隙中材料的属性，与你恰好加了多少电荷无关。这个比值就是**电容**。

同样的想法适用于带等量异号电荷的一对导体。此时要紧的量是**电势差**，而电容器就是一种把这一比值做得大、做得稳、做得有用的装置。本章对球与平行板计算它，组合电容器，并求出储存在场中的能量。线性电介质把这个比值改变一个常数因子。除特别指明电介质外，全程在真空中工作，并且

$$
\varepsilon_0 = 8.854187817\times 10^{-12}\,\mathrm{F/m}, \qquad
\frac{1}{4\pi\varepsilon_0} = 8.9875517923\times 10^{9}\,\mathrm{N\cdot m^2/C^2}.
$$

电势差是 [[electrostatics/potential]] 中的曲线积分，

$$
\Delta V = V(b) - V(a) = -\int_a^b \mathbf{E}\cdot\dd\mathbf{l},
$$

而高度对称的电荷分布的电场，就是 [[electrostatics/gauss-law]] 里高斯定律提供的那一个。我们需要用到的简短论证会重新陈述一遍，让推导独立成立。

## 电容

::: definition 孤立导体的电容 {#def-isolated}
设孤立导体带电荷 $Q$，$V$ 是它相对所选零点的电势，当导体独自留在空间中时零点通常取无穷远。导体的**电容**为

$$
C = \frac{Q}{V}.
$$ {#eq-cap-isolated}

SI 单位是法拉：$1\,\mathrm{F} = 1\,\mathrm{C/V}$。
:::

一法拉是极大的电容。实验台上的电容器以皮法拉到毫法拉计。[[#eq-cap-isolated]] 中的比值在线性介质中不依赖 $Q$：电场正比于电荷，而电势是电场的积分，也正比于电荷。零点在无穷远时，正的 $Q$ 给出正的 $V$，所以 $C$ 为正。

孤立导体是一种理想化。它的意思是其他一切导体都足够远，可以把它们因静电感应将要获得的电荷忽略掉。真实的电容器是一对，定义要为这一对重写。

::: definition 一对导体的电容 {#def-pair}
设两导体分别带电荷 $+Q$ 与 $-Q$，$V$ 为正导体的电势减去导航体的电势。这一对导体的电容为

$$
C = \frac{Q}{V}.
$$ {#eq-cap-pair}

$Q$ 是一个导体上的电荷，不是两个导体电荷之和。两者之和为零。
:::

彼此靠近的几个导体要用一个系数矩阵来描述，而不是单个 $C$。本章只处理一个导体，或一对导体。[[#eq-cap-pair]] 中的符号 $V$ 是一个差。零点选定之前，确定的只有电势差——这正是一对导体不需要向无穷远求助的原因。

::: proposition 孤立导体球的电容 {#prop-sphere}
真空中半径 $R$ 的孤立导体球，其电容为

$$
C = 4\pi\varepsilon_0 R.
$$ {#eq-sphere}
:::

::: proof
多余电荷驻在表面上。由高斯定律，球外的电场是点电荷场，导电材料内部的电场为零。$r \ge R$ 时，

$$
E(r) = \frac{1}{4\pi\varepsilon_0}\frac{Q}{r^2},
$$

$Q > 0$ 时方向朝外。导体内电势处处相同，所以球的电势等于其表面的电势。零点取在无穷远，

$$
\begin{aligned}
V(R) - V(\infty)
&= -\int_{\infty}^{R} E\,\dd r
= \int_{R}^{\infty} \frac{1}{4\pi\varepsilon_0}\frac{Q}{r^2}\,\dd r
= \frac{1}{4\pi\varepsilon_0}\frac{Q}{R}.
\end{aligned}
$$

从无穷远向内的路径，把 $\Delta V$ 定义里的那个负号变成对一个正的 $E$ 与向外写的正的 $\dd r$ 的普通积分。于是

$$
C = \frac{Q}{V} = 4\pi\varepsilon_0 R = \frac{R}{k},
$$

其中 $k = 1/(4\pi\varepsilon_0)$。半径是唯一可用的几何长度，$C$ 与它成正比。
:::

::: example 半径十厘米的球 {#ex-sphere}
求半径 $R = 0.100\,\mathrm{m}$ 的孤立导体球的电容。若把球相对无穷远升到 $1.00\times 10^{3}\,\mathrm{V}$，求它带的电荷。
::: solution
[[#eq-sphere]] 给出

$$
C = 4\pi\varepsilon_0 R = \frac{R}{k} = \frac{0.100}{8.9875517923\times 10^{9}} = 1.11265\times 10^{-11}\,\mathrm{F},
$$

保留三位有效数字是 $11.1\,\mathrm{pF}$。在 $V = 1.00\times 10^{3}\,\mathrm{V}$ 下，

$$
Q = CV = (1.11265\times 10^{-11})(1.00\times 10^{3}) = 1.11265\times 10^{-8}\,\mathrm{C} = 11.1\,\mathrm{nC}.
$$

一个小甜瓜那么大的球充到一千伏，只携带大约十个纳库仑。电容在人的尺度上就是小，除非导体很大，或者导体之间的间隙很窄。这就是平行板的理由。
:::
:::

::: intuition 电容就是大小
$C = Q/V$ 问的是产生一伏特需要多少电荷。一个大的导体，或两个紧紧压近在一起的导体，会把同样的电荷铺开在一种几何上，其电场沿着确定 $V$ 的那条路径更弱，于是同样的伏特需要更多电荷。球把这笔账数得明明白白：$C$ 是一个长度乘以 $4\pi\varepsilon_0$。
:::

## 平行板电容器

两块面积为 $A$、相距 $d$ 的平行导体板构成标准的电容器。一块板带 $+Q$，另一块带 $-Q$。我们假设 $d$ 远小于板的横向尺寸，于是间隙中的电场是匀强的，边缘的边缘场只占整体的一小部分。

正极板上的面电荷密度大小为 $\sigma = Q/A$。金属内部电场为零。把一个底面在金属内、另一个底面在间隙中的扁圆柱形高斯面放进去，它包围电荷 $\sigma A_{\mathrm{box}}$，而电通量只穿过位于间隙中的那个底面，所以间隙中电场的大小为

$$
E = \frac{\sigma}{\varepsilon_0} = \frac{Q}{\varepsilon_0 A},
$$ {#eq-gap-field}

方向由正极板指向负极板。这是单个无限大平面板电场 $\sigma/(2\varepsilon_0)$（每侧各一个）的两倍。第二块板提供了另一半，而在这对板的外部，两部分的贡献相互抵消。有限大板在边缘附近添加的边缘效应被我们忽略。

从正极板到负极板的电势差是匀强场横穿间隙的积分，

$$
V = Ed = \frac{Q d}{\varepsilon_0 A}.
$$

::: theorem 平行板电容 {#thm-parallel-plate}
真空中平行板电容器，板面积 $A$，间距 $d$，忽略边缘效应，则

$$
C = \frac{\varepsilon_0 A}{d}.
$$ {#eq-plate}
:::

::: proof
由[[#def-pair]]和刚算出的电势，

$$
\begin{aligned}
C &= \frac{Q}{V} = \frac{Q}{Ed} = \frac{Q}{(Q/(\varepsilon_0 A))\, d} = \frac{\varepsilon_0 A}{d}.
\end{aligned}
$$

等价地，$V = \sigma d/\varepsilon_0$ 且 $Q = \sigma A$，所以电荷密度被约掉，$C$ 只依赖几何形状和 $\varepsilon_0$。假定的条件是：板间为真空；导体足够厚，使金属内电场为零；间距足够小，可以省去边缘效应。在这些假设下，$E$ 垂直于板面且处处相同，这正是 $V = Ed$ 成立的原因。
:::

这个公式说：大面积、小间隙产生大电容。介电常数 $\varepsilon_0$ 的单位是 $\mathrm{F/m}$，正是[[#eq-plate]]所需要的。由于固定电荷下 $V = Qd/(\varepsilon_0 A)$，电压正比于间距。而电容是 $Q/V$，于是它按 $1/d$ 下降。

有一点容易被误读。固定电荷时，[[#eq-gap-field]] 不含 $d$。把理想电容器的两块板拉开并不会削弱电场。它拉长的只是路径，所以电势差增大，能量也随之增大。人们预期的那种削弱是边缘效应，或者是接了一个保持 $V$ 固定、任 $Q$ 随 $d$ 增大而减少的电池的效果。

::: widget plot
f: 1/x
x: 0.5, 5
caption: 固定电荷时，平行板的电压正比于间距，所以 C 按 1/d 下降。曲线的形状是 1/x，其中比例常数取为 1。把横轴上的值加倍，高度就减半。
:::

::: example 面积 0.0200 平方米的板 {#ex-plate}
一平行板电容器面积 $A = 0.0200\,\mathrm{m^2}$，间距 $d = 1.00\,\mathrm{mm} = 1.00\times 10^{-3}\,\mathrm{m}$。忽略边缘效应。求 $C$。然后把它充到 $V = 100\,\mathrm{V}$，求 $Q$ 与储存的能量 $U = \tfrac12 CV^2$。
::: solution
把 $\varepsilon_0$ 的给定值代入[[#eq-plate]]，

$$
\begin{aligned}
C &= \frac{\varepsilon_0 A}{d} = \frac{(8.854187817\times 10^{-12})(0.0200)}{1.00\times 10^{-3}} \\
&= 1.7708375634\times 10^{-10}\,\mathrm{F} = 177.08375634\,\mathrm{pF}.
\end{aligned}
$$

数据 $A$ 与 $d$ 都给出三位有效数字，所以

$$
C = 177\,\mathrm{pF}.
$$

在 $100\,\mathrm{V}$ 下，使用未四舍五入的电容值，

$$
Q = CV = (1.7708375634\times 10^{-10})(100) = 1.7708375634\times 10^{-8}\,\mathrm{C} = 17.708\,\mathrm{nC},
$$

保留三位有效数字是 $17.7\,\mathrm{nC}$。下面在[[#thm-energy]]中推导出的储存能量为

$$
U = \tfrac12 C V^2 = \tfrac12 (1.7708375634\times 10^{-10})(100)^2 = 8.854187817\times 10^{-7}\,\mathrm{J}.
$$

保留三位有效数字，$U = 8.85\times 10^{-7}\,\mathrm{J}$。同一个数也是 $\tfrac12 QV$ 与 $Q^2/(2C)$。把四舍五入后的 $177\,\mathrm{pF}$ 直接代入，可以复现 $Q = 17.7\,\mathrm{nC}$ 与 $U = 8.85\times 10^{-7}\,\mathrm{J}$，因为 $177\times 10^{-12}\times 100 = 1.77\times 10^{-8}$，而 $\tfrac12\times 177\times 10^{-12}\times 10^{4} = 8.85\times 10^{-7}$。

若板是正方形，边长为 $\sqrt{0.0200} = 0.141\,\mathrm{m}$，约为间隙的 $141$ 倍。边缘效应占据一条宽度约为 $d$ 的边界带，此时它只占面积的一小部分，[[#eq-plate]] 是很好的近似。
:::
:::

::: quiz
固定电荷时，把理想平行板电容器的间距加倍，仍忽略边缘效应。会发生什么？
- [ ] 间隙中的电场减半，电压保持不变
- [ ] 电容加倍，因为板离边缘效应区域更远了
- [x] 间隙中的电场不变，电压加倍，电容减半
- [ ] 每块板上的电荷减半，因为电容减半了
::: solution
[[#eq-gap-field]] 依赖的是 $\sigma = Q/A$，而不是 $d$，所以 $Q$ 与 $A$ 固定时 $E$ 不变。电势差是 $V = Ed$，于是它加倍。[[#eq-plate]] 说 $C$ 减半。电荷不可能改变：板是孤立的，$Q$ 固定。那个让电场减半的选项描述的是单个点电荷，或者一块允许电荷离开的板。
:::
:::

## 电容器的组合

两个电容器的正极板接在一起、负极板也接在一起，使两者承受相同的电势差，这时它们是**并联**的。一个电容器的负极板只与另一个电容器的正极板相连，自由端作为组合的两个端子，这时它们是**串联**的。稳态下，两者之间的节点处不积累电荷。

::: proposition 电容器串联 {#prop-series}
串联的两个电容器 $C_1$ 与 $C_2$ 等效于单个电容 $C$，满足

$$
\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}.
$$ {#eq-series}

等效电容小于其中任何一个电容。
:::

::: proof
把 $C_1$ 的自由端接到一个源上，使外板带上电荷 $+Q$。两个电容器之间的节点与源是隔离的。$C_1$ 外板上的 $+Q$ 在其内板感应出 $-Q$，而这些 $-Q$ 只能从 $C_2$ 的内板离开而来。于是 $C_2$ 的外板留下 $+Q$。两个电容器带相同的电荷 $Q$。它们的电势差相加，因为从一个自由端子到另一个自由端子的路径穿过两个间隙：

$$
V = V_1 + V_2 = \frac{Q}{C_1} + \frac{Q}{C_2} = Q\left(\frac{1}{C_1} + \frac{1}{C_2}\right).
$$

由[[#def-pair]]，$C = Q/V$，所以 $1/C = 1/C_1 + 1/C_2$。由于 $1/C_1 > 0$ 且 $1/C_2 > 0$，有 $1/C > 1/C_1$ 且 $1/C > 1/C_2$，故 $C < C_1$ 且 $C < C_2$。再串联一个电容并不会增大电容。同样的倒数相加，通过两个一组地归并，可推广到任意多个串联的电容器。
:::

串联的一对中，较大的那个电容分到的电压份额较小。因为 $Q$ 相同，$V_1/V_2 = C_2/C_1$。

::: proposition 电容器并联 {#prop-parallel}
并联的两个电容器 $C_1$ 与 $C_2$ 等效于

$$
C = C_1 + C_2.
$$ {#eq-parallel}
:::

::: proof
两个电容器接在同样的两个节点之间，所以它们有相同的电势差 $V$。源必须同时提供两份电荷：

$$
Q = Q_1 + Q_2 = C_1 V + C_2 V = (C_1 + C_2)V.
$$

于是 $C = Q/V = C_1 + C_2$。电荷与电容成正比，$Q_1/Q_2 = C_1/C_2$。同样的相加方式可推广到任意多个并联的电容器。
:::

并联组合增大了给定电压下可放置电荷的面积，所以电容相加。串联组合增大了等效间距，所以电容变小。串联的倒数法则与电阻并联的代数相同，但其物理是 $C = \varepsilon_0 A/d$ 的几何，而不是把电容器等同于电阻。

::: example 两板串联 {#ex-series}
取两个电容器，都与[[#ex-plate]]中的电容相同，即各有 $C_1 = 1.7708375634\times 10^{-10}\,\mathrm{F}$。求串联与并联的等效电容。
::: solution
串联时，[[#eq-series]] 在 $C_1 = C_2$ 下给出 $C = C_1/2$：

$$
C_{\mathrm{series}} = 8.854187817\times 10^{-11}\,\mathrm{F} = 88.54187817\,\mathrm{pF},
$$

保留三位有效数字是 $88.5\,\mathrm{pF}$。它小于其中任何一个电容，正如[[#prop-series]]所要求。并联时，[[#eq-parallel]] 给出

$$
C_{\mathrm{parallel}} = 2C_1 = 3.5416751268\times 10^{-10}\,\mathrm{F} = 354.167513\,\mathrm{pF},
$$

保留三位有效数字是 $354\,\mathrm{pF}$。

若把这副串联对接到 $100\,\mathrm{V}$ 上，每个电容器上的电荷为

$$
Q = C_{\mathrm{series}}\times 100 = 8.854187817\times 10^{-9}\,\mathrm{C} = 8.854\,\mathrm{nC},
$$

由于两者相等，每个电容器两端各是 $50.0\,\mathrm{V}$。计算其中一个的能量公式时要用的电压是 $50.0\,\mathrm{V}$，而不是电源的 $100\,\mathrm{V}$。这一区别正是下面警告的主题。
:::
:::

::: warning 串联取倒数，以及用哪个电压
串联法则相加的是倒数，不是电容本身。两个相同的电容串联，其电容是单个的一半，而不是两倍。第二个相关的错误出现在电荷移动之后。能量 $\tfrac12 C V^2$ 用的是那个特定电容器两端的电势差。一旦串联对——或一对已共享过电荷的电容——达到稳态，这个差既不是给系统充电所用电池的读数，也不是某个电容在与其他电容相连之前的原始电压。
:::

## 电容器储存的能量

给电容器充电，就是把电荷从一块板搬到另一块板，逆着已有电荷建立起来的电场做功。搬运者做的功被储存下来。我们把充电过程视为准静态的：电荷移动得足够慢，以至于磁效应与辐射可以忽略，而我们储存的也不是载流子的动能。这个功不是[[mechanics/work-energy]]中的 $W_{\mathrm{net}} = \Delta K$，也不是热机的热力学功。它是最终那个构型的静电能。

::: theorem 电容器的能量 {#thm-energy}
电容为 $C$、带电 $Q$、电势差为 $V = Q/C$ 的电容器所储存的静电能为

$$
U = \frac{Q^2}{2C} = \tfrac12 C V^2 = \tfrac12 Q V.
$$ {#eq-energy}
:::

::: proof
从 $q = 0$ 开始，再把一份电荷 $\dd q$ 从负极板搬到正极板。此时电势差为 $v = q/C$（[[#def-pair]]），而线性电容器的 $C$ 是常数。搬运者施加的力恰好平衡电场力，所以它对 $\dd q$ 做的功为

$$
\dd W_{\mathrm{agent}} = v\,\dd q = \frac{q}{C}\,\dd q.
$$

从不带电状态积分到最终电荷 $Q$：

$$
\begin{aligned}
U &= \int_0^{Q} \frac{q}{C}\,\dd q = \frac{1}{C}\left[\tfrac12 q^2\right]_0^{Q} = \frac{Q^2}{2C}.
\end{aligned}
$$

代入 $Q = CV$ 得 $\tfrac12 C V^2$。代入 $C = Q/V$ 得 $\tfrac12 QV$。三个表达式相等，仅当 $V$ 与 $Q$ 属于同一时刻的同一个电容器。因子 $\tfrac12$ 是 $v$ 的平均值，它从 $0$ 线性上升到 $V$：搬运者把全部电荷 $Q$ 通过了平均电势差 $V/2$。
:::

::: corollary 平行板间的能量密度 {#cor-energy-density}
忽略边缘效应，真空平行板电容器储存的能量以均匀密度分布在间隙中，

$$
u = \tfrac12 \varepsilon_0 E^2.
$$ {#eq-energy-density}
:::

::: proof
由[[#thm-energy]]与[[#eq-plate]]，并注意 $V = Ed$，

$$
\begin{aligned}
U &= \tfrac12 C V^2 = \tfrac12\left(\frac{\varepsilon_0 A}{d}\right)(Ed)^2 = \tfrac12 \varepsilon_0 E^2\,(Ad).
\end{aligned}
$$

间隙的体积是 $Ad$。相除即得[[#eq-energy-density]]。这一推导用的是限制在该体积内的匀强场，所以它是平行板版本的结论。同样的密度也是一般静电场中真空的局域表达式；一般的论证要把 $\tfrac12\varepsilon_0 E^2$ 对全空间积分，这里不需要。
:::

在[[#ex-plate]]中，$E = V/d = 100/(1.00\times 10^{-3}) = 1.00\times 10^{5}\,\mathrm{V/m}$，于是

$$
u = \tfrac12\varepsilon_0 E^2 = \tfrac12(8.854187817\times 10^{-12})(1.00\times 10^{10}) = 4.4270939085\times 10^{-2}\,\mathrm{J/m^3}.
$$

乘以体积 $Ad = 0.0200\times 1.00\times 10^{-3} = 2.00\times 10^{-5}\,\mathrm{m^3}$，返回 $U = 8.854187817\times 10^{-7}\,\mathrm{J}$，即前面已求出的能量。

若固定电荷，把该电容器的板距拉开到 $d = 2.00\,\mathrm{mm}$，则 $C$ 减半，$E$ 不变，$V$ 加倍到 $200\,\mathrm{V}$。储存的能量加倍到 $1.7708375634\times 10^{-6}\,\mathrm{J}$。多出的能量就是你逆着两板间的吸引力把它们拉开时所做的功。用电池保持 $V$ 固定则是另一种操作：那时 $Q$ 随 $d$ 增大而减少，$U = \tfrac12 C V^2$ 随之下降。

电池通过电阻给电容器充电时，它做的功比电容器储存的多。

::: proposition 恒压电池充电时的能量分配 {#prop-battery}
初始不带电的电容器 $C$，经一个电阻从电动势恒为 $\mathcal{E}$ 的电池充电。电流降到零时，电容器储存 $\tfrac12 C\mathcal{E}^2$。电池已提供 $C\mathcal{E}^2$。差额——又一个 $\tfrac12 C\mathcal{E}^2$——已在电阻中耗散。
:::

::: proof
每一时刻电容器上的电势差为 $v = q/C$，回路定律在电场仍是保守场时成立，写作 $\mathcal{E} = v + iR$。乘以 $\dd q = i\,\dd t$：

$$
\mathcal{E}\,\dd q = v\,\dd q + i^2 R\,\dd t.
$$

从 $q = 0$ 积分到最终电荷 $q = C\mathcal{E}$，此时 $i = 0$。左边是 $\mathcal{E}(C\mathcal{E}) = C\mathcal{E}^2$。右边第一项是[[#thm-energy]]证明中的那个积分，等于 $Q^2/(2C) = \tfrac12 C\mathcal{E}^2$。剩下的 $\int i^2 R\,\dd t$ 是电阻中耗散的能量，它等于 $\tfrac12 C\mathcal{E}^2$。这一结果不依赖 $R$ 的数值，只要 $R > 0$，从而最终稳态存在。$i$ 随时间的变化是[[electrostatics/dc-circuits]]的主题，这里只用到积分后的分配。
:::

::: example 两个电容器共享电荷 {#ex-sharing}
电容器 $C_1 = 2.00\,\mu\mathrm{F}$ 充到 $100\,\mathrm{V}$ 后断开。再把它与不带电的电容器 $C_2 = 3.00\,\mu\mathrm{F}$ 并联。求最终的共同电势差、最终储存的能量，以及离开电场的能量。
::: solution
初始电荷与能量为

$$
\begin{aligned}
Q &= C_1 V_i = (2.00\times 10^{-6})(100) = 2.00\times 10^{-4}\,\mathrm{C}, \\
U_i &= \tfrac12 C_1 V_i^2 = \tfrac12(2.00\times 10^{-6})(100)^2 = 1.00\times 10^{-2}\,\mathrm{J}.
\end{aligned}
$$

接通后两个电容器并联，由[[#eq-parallel]]，等效电容为 $C_1 + C_2 = 5.00\,\mu\mathrm{F}$。连接导线与任何电池隔离，所以电荷 $Q$ 守恒。共同的电势差为

$$
V_f = \frac{Q}{C_1 + C_2} = \frac{2.00\times 10^{-4}}{5.00\times 10^{-6}} = 40.0\,\mathrm{V}.
$$

最终储存的能量为

$$
U_f = \tfrac12 (C_1 + C_2) V_f^2 = \tfrac12(5.00\times 10^{-6})(40.0)^2 = 4.00\times 10^{-3}\,\mathrm{J}.
$$

电场损失了

$$
U_i - U_f = 6.00\times 10^{-3}\,\mathrm{J}.
$$

这些能量以火花或连接路径电阻中的热与辐射耗散掉了。它与[[#prop-battery]]中的损失是同一类，不是能量定理失灵。接通之后再套用 $\tfrac12 C_1 (100)^2$ 或 $\tfrac12(C_1+C_2)(100)^2$，就是把[[#eq-energy]]用在了那些板上已不存在的电压上。
:::
:::

圆柱形电容器是同一个想法换一种对称性，它正是同轴电缆的几何。

::: proposition 同轴电容器 {#prop-coax}
两个同心导体圆柱面，半径 $a < b$，长度 $L$，其间为真空，其电容为

$$
C = \frac{2\pi\varepsilon_0 L}{\ln(b/a)},
$$ {#eq-coax}

忽略端部效应。
:::

::: proof
设内圆柱带电荷 $+Q$，外圆柱带 $-Q$，并写 $\lambda = Q/L$。取一个半径为 $r$（$a < r < b$）、长度为 $L$ 的圆柱形高斯面。由对称性，电场沿径向。通量为 $E\cdot 2\pi r L$，包围的电荷为 $\lambda L$，所以高斯定律给出

$$
E(r) = \frac{\lambda}{2\pi\varepsilon_0 r}.
$$

内圆柱相对外圆柱的电势为

$$
\begin{aligned}
V &= -\int_b^{a} E\,\dd r = \int_a^{b} \frac{\lambda}{2\pi\varepsilon_0 r}\,\dd r = \frac{\lambda}{2\pi\varepsilon_0}\ln\frac{b}{a}.
\end{aligned}
$$

于是

$$
C = \frac{Q}{V} = \frac{\lambda L}{(\lambda/(2\pi\varepsilon_0))\ln(b/a)} = \frac{2\pi\varepsilon_0 L}{\ln(b/a)}.
$$

假设 $L \gg b$，才能忽略两端并把 $E$ 当作纯径向。若电荷分布无休无止地延伸下去，电势零点就无法放在无穷远；这里外圆柱是一个有限的参考，不存在这种麻烦。
:::

::: example 一段短同轴线 {#ex-coax}
取 $a = 1.00\,\mathrm{mm}$，$b = 2.00\,\mathrm{mm}$，$L = 0.200\,\mathrm{m}$。求 $C$。若内导体带 $Q = 5.00\,\mathrm{nC}$，求 $V$ 与 $U$。
::: solution
这里 $b/a = 2$，$\ln 2 = 0.693147$。[[#eq-coax]] 给出

$$
\begin{aligned}
C &= \frac{2\pi(8.854187817\times 10^{-12})(0.200)}{\ln 2} \\
&= 1.605214718\times 10^{-11}\,\mathrm{F} = 16.052\,\mathrm{pF},
\end{aligned}
$$

保留三位有效数字是 $16.1\,\mathrm{pF}$。在 $Q = 5.00\times 10^{-9}\,\mathrm{C}$ 下，

$$
\begin{aligned}
V &= \frac{Q}{C} = \frac{5.00\times 10^{-9}}{1.605214718\times 10^{-11}} = 311.485\,\mathrm{V}, \\
U &= \frac{Q^2}{2C} = \frac{(5.00\times 10^{-9})^2}{2\times 1.605214718\times 10^{-11}} = 7.787\times 10^{-7}\,\mathrm{J}.
\end{aligned}
$$

保留三位有效数字，$V = 311\,\mathrm{V}$，$U = 7.79\times 10^{-7}\,\mathrm{J}$。[[#ex-plate]]中那个窄间隙只加 $100\,\mathrm{V}$ 就储存了相近的能量，因为它的电容大了约十倍。区别在于几何，而不是定律不同。
:::
:::

## 线性电介质

法拉第发现，两板之间的绝缘材料会增大电容。增大的倍数是材料本身的属性。

::: definition 线性电介质 {#def-dielectric}
**线性电介质**是这样一种材料，其中的极化正比于宏观电场。无量纲因子 $\kappa$（也写作 $\varepsilon_r$）称为介电常数或相对介电常数，它的定义方式是：一块完全填满电容器间隙的电介质板，把真空电容乘以 $\kappa$。真空的 $\kappa = 1$。我们取 $\kappa$ 与场强无关。
:::

极化的意思是材料内部的束缚电荷发生了微小的位移。对于填满间隙的电介质板，这种位移在其两个表面上留下密度为 $\sigma_b$ 的束缚面电荷。我们把线性关系写成 $\sigma_b = \varepsilon_0(\kappa - 1)E$，其中 $E$ 是电介质中的净电场。这正是上面那个定义的内容，只是换成了便于用高斯论证求 $E$ 的形式。

::: proposition 填满平行板间隙的电介质 {#prop-dielectric}
设介电常数为 $\kappa$ 的线性电介质完全填满平行板电容器的间隙，仍忽略边缘效应。若板上自由电荷密度为 $\sigma_f$，则电介质中的电场为

$$
E = \frac{\sigma_f}{\kappa\varepsilon_0},
$$ {#eq-diel-field}

电容为

$$
C = \kappa\frac{\varepsilon_0 A}{d} = \kappa C_0,
$$ {#eq-kappa}

其中 $C_0 = \varepsilon_0 A/d$ 是真空电容。给定自由电荷时，$E$ 与 $V$ 都比真空值小一个因子 $\kappa$。
:::

::: proof
间隙中的净电场是自由电荷的电场减去束缚电荷的反向电场。两者都是导体型的无限大平面电场，因为几何形状仍是一块平行的板：

$$
E = \frac{\sigma_f}{\varepsilon_0} - \frac{\sigma_b}{\varepsilon_0}.
$$

代入 $\sigma_b = \varepsilon_0(\kappa - 1)E$：

$$
E = \frac{\sigma_f}{\varepsilon_0} - (\kappa - 1)E.
$$

合并含 $E$ 的项：

$$
E + (\kappa - 1)E = \kappa E = \frac{\sigma_f}{\varepsilon_0}, \qquad E = \frac{\sigma_f}{\kappa\varepsilon_0}.
$$

电势差为 $V = Ed = \sigma_f d/(\kappa\varepsilon_0) = Qd/(\kappa\varepsilon_0 A)$。因此

$$
C = \frac{Q}{V} = \kappa\frac{\varepsilon_0 A}{d}.
$$

固定自由电荷时，$E$ 与 $V$ 都是真空结果除以 $\kappa$，而 $U = Q^2/(2C)$ 是真空能量除以 $\kappa$。束缚电荷是导线取用不到的；[[#eq-cap-pair]] 中的 $Q$ 是板上的自由电荷。
:::

插入电介质有两种方式，必须区分开，因为它们各自固定的量不同。

电容器先充电再断开，$Q$ 固定。插入电介质把 $C$ 乘以 $\kappa$，把 $V$、$E$、$U$ 都除以 $\kappa$。

电容器始终保持与电池相连，$V$ 固定。自由电荷按因子 $\kappa$ 增大，因为 $Q = CV$ 而 $C$ 变大了。场强 $E = V/d$ 并不下降：电介质本来会造成的那次削减，被电池补上的额外自由电荷抵消了。储存的能量 $U = \tfrac12 C V^2$ 按因子 $\kappa$ 上升。这些额外能量的来源是电池。

关于受力，大纲里只说这一点。一块可以自由滑入间隙的电介质板会被吸进去，无论固定的是 $Q$ 还是 $V$。固定 $Q$ 时，板进入过程中储存的能量下降，这个下降与电场对板做机械功是自洽的。固定 $V$ 时，储存的能量上升，电池同时提供多出的场能和机械功。力的规律本身是后面的计算，我们不在这里推导。

::: example 介电常数为 4 的电介质 {#ex-dielectric}
[[#ex-plate]]中的电容器在真空中充到 $100\,\mathrm{V}$。然后用 $\kappa = 4.00$ 的线性电介质填满间隙。求新的电容、电荷、电压与储存的能量，分两种情况：(a) 电池保持连接；(b) 插入电介质之前断开电池。
::: solution
由[[#ex-plate]]，真空值为 $C_0 = 1.7708375634\times 10^{-10}\,\mathrm{F}$，$Q_0 = 1.7708375634\times 10^{-8}\,\mathrm{C}$，$U_0 = 8.854187817\times 10^{-7}\,\mathrm{J}$。[[#eq-kappa]] 在两种情况下都把电容乘以 $4$：

$$
C = 4C_0 = 7.0833502536\times 10^{-10}\,\mathrm{F} = 708.335\,\mathrm{pF}.
$$

(a) 电池维持 $V = 100\,\mathrm{V}$。于是

$$
\begin{aligned}
Q &= CV = 4Q_0 = 7.0833502536\times 10^{-8}\,\mathrm{C} = 70.8335\,\mathrm{nC}, \\
U &= \tfrac12 C V^2 = 4U_0 = 3.5416751268\times 10^{-6}\,\mathrm{J}.
\end{aligned}
$$

电场保持 $E = V/d = 1.00\times 10^{5}\,\mathrm{V/m}$。自由电荷增大到 $4$ 倍，而束缚电荷抵消掉这些新自由电荷单独存在时本会产生的场的四分之三，剩下的正是原来的场。

(b) 自由电荷保持 $Q_0$。于是

$$
\begin{aligned}
V &= \frac{Q_0}{C} = \frac{100}{4.00} = 25.0\,\mathrm{V}, \\
U &= \frac{Q_0^2}{2C} = \frac{U_0}{4} = 2.213546954\times 10^{-7}\,\mathrm{J},
\end{aligned}
$$

且 $E = V/d = 2.50\times 10^{4}\,\mathrm{V/m}$，即真空电场除以 $\kappa$，与[[#eq-diel-field]]一致。断开电池之后还在 $\tfrac12 CV^2$ 里代入 $100\,\mathrm{V}$，就是警告里点名的那个错误。
:::
:::

::: quiz
一电容器由电池充电并始终保持连接。插入一块 $\kappa > 1$ 的电介质板，恰好填满间隙。哪句话正确？
- [x] 自由电荷按因子 $\kappa$ 增大，储存的能量也按因子 $\kappa$ 增大
- [ ] 自由电荷不变，储存的能量按因子 $\kappa$ 下降
- [ ] 电势差按因子 $\kappa$ 增大，因为电介质被极化了
- [ ] 电容不变，因为板间距没有变
::: solution
电池维持电势差不变，所以第三句是错的，而第二句描述的是断开连接的电容器。[[#eq-kappa]] 说电容变为 $\kappa C_0$。固定 $V$ 时，自由电荷 $Q = CV$ 与能量 $\tfrac12 CV^2$ 都上升 $\kappa$ 倍。间距没有变，但间隙中的材料变了，所以 $C$ 改变。
:::
:::

::: application 作为短时储能元件的电容器
一只 $100\,\mu\mathrm{F}$ 的电容器充到 $300\,\mathrm{V}$，储存

$$
U = \tfrac12 C V^2 = \tfrac12(1.00\times 10^{-4})(300)^2 = 4.50\,\mathrm{J}.
$$

这是不多的能量，但它可以在极短时间内通过灯管或闪光管释放，这就是相机闪光用电容器、而不是从小电池直接抽取整个脉冲的原因。若在 $1.00\,\mathrm{ms}$ 内均匀放电，功率可达 $4.50\times 10^{3}\,\mathrm{W}$。两次闪光之间，电池慢慢给电容器重新充电。这里的计算只用到[[#eq-energy]]，与电池的化学物质无关。
:::

::: remark 本章没有做的事
部分插入的板所受的力、多个导体的电容矩阵、以及非线性电介质的能量，都放在一边。充电过程中的暂态电流也是如此，除了[[#prop-battery]]中积分后的能量分配。[[#eq-plate]]的边缘修正是边值问题，不是 $C$ 的定义有变。
:::

## 后续内容

[[#eq-energy]]中的能量与[[#eq-energy-density]]中的密度，是场能的静电部分。运动的电荷——也就是下一章的电流——在电阻中耗散能量，其速率在[[electrostatics/current]]中处理。既能储存电荷又让电荷流过的电路，是[[electrostatics/dc-circuits]]中的 $RC$ 电路：时间常数是乘积 $RC$，充电曲线趋于这里证明过的能量分配。介电常数会在电磁波于介质中传播时重新出现，因为波速依赖 $\varepsilon$ 与 $\mu$。后文的这些发展不会改变[[#eq-plate]]或[[#eq-series]]。

::: history 法拉第与法拉
1837 年，迈克尔·法拉第（Michael Faraday）在《电的实验研究》（*Experimental Researches in Electricity*）第十一期中证明：在两个导体之间放置绝缘物质，会增大它们在给定电势差下所携带的电荷。他把这个倍数称为该物质的感电系数（specific inductive capacity）。[[#def-dielectric]]中的数 $\kappa$ 正是这个倍数。电容的 SI 单位法拉，是很久以后以他命名的。一法拉远远大于法拉第测到过的任何东西：[[#ex-plate]]中的平行板电容器只有 $177\,\mathrm{pF}$，比一法拉低了十一个数量级。
:::

::: summary
- 孤立导体的电容是 $C = Q/V$；一对导体的电容是一个导体上的 $Q$ 除以电势差。线性介质中 $C$ 不依赖 $Q$。单位是法拉。
- 半径 $R$ 的孤立导体球有 $C = 4\pi\varepsilon_0 R$。半径 $0.100\,\mathrm{m}$ 的球有 $C = 11.1\,\mathrm{pF}$。
- 忽略边缘效应时，真空平行板电容器有 $C = \varepsilon_0 A/d$，因为 $E = \sigma/\varepsilon_0$ 且 $V = Ed$。固定电荷时，$E$ 不依赖 $d$。
- 串联时 $1/C = 1/C_1 + 1/C_2$，等效电容小于其中任何一个。并联时 $C = C_1 + C_2$。两个 $177\,\mathrm{pF}$ 串联得 $88.5\,\mathrm{pF}$。
- 储存的能量是 $U = Q^2/(2C) = \tfrac12 CV^2 = \tfrac12 QV$，由充电过程中对 $v\,\dd q$ 积分得到。真空平行板之间的密度是 $\tfrac12\varepsilon_0 E^2$。
- 恒压电池从零开始给电容器充电时提供 $C\mathcal{E}^2$，其中一半耗散在路径的电阻里。电荷重新分布之后，$\tfrac12 CV^2$ 必须用新的电压。
- 填满间隙的线性电介质把 $C$ 乘以 $\kappa$。给定自由电荷时，$E$ 按 $\kappa$ 下降。若改由电池维持 $V$ 固定，自由电荷与储存的能量都上升 $\kappa$ 倍。
- 同轴对忽略端部效应时有 $C = 2\pi\varepsilon_0 L/\ln(b/a)$。电介质板所受的力留给后文处理；板会被吸进间隙。
:::

## 习题

::: exercise 由电荷与电压求电容 {#exr-ratio level=1 check="40"}
一导体相对所选零点的电势为 $150\,\mathrm{V}$ 时带电荷 $Q = 6.00\,\mu\mathrm{C}$。求它的电容，以纳法为单位。
::: solution
由[[#eq-cap-isolated]]，

$$
C = \frac{Q}{V} = \frac{6.00\times 10^{-6}}{150} = 4.00\times 10^{-8}\,\mathrm{F} = 40.0\,\mathrm{nF}.
$$

答案是 $40.0\,\mathrm{nF}$。这里说的"相对所选零点的电势为 $150\,\mathrm{V}$"，零点必须是给出 $V$ 时所用的那一个；换一个零点数值就会改变，而测量结果说的不是那个意思。
:::
:::

::: exercise 二微法拉电容器的能量 {#exr-stored level=1 check="0.0025"}
电容为 $2.00\,\mu\mathrm{F}$ 的电容器充到 $50.0\,\mathrm{V}$。求储存的能量，以焦耳为单位。
::: solution
用[[#eq-energy]]的中间那个形式：

$$
U = \tfrac12 C V^2 = \tfrac12(2.00\times 10^{-6})(50.0)^2 = (1.00\times 10^{-6})(2500) = 2.50\times 10^{-3}\,\mathrm{J}.
$$

电荷为 $Q = CV = 1.00\times 10^{-4}\,\mathrm{C}$，而 $\tfrac12 QV = \tfrac12(1.00\times 10^{-4})(50.0) = 2.50\times 10^{-3}\,\mathrm{J}$，两者一致。答案是 $2.50\times 10^{-3}\,\mathrm{J}$。
:::
:::

::: exercise 两个电容器并联 {#exr-parallel-uf level=1 check="16"}
$4.00\,\mu\mathrm{F}$ 与 $12.0\,\mu\mathrm{F}$ 的电容器并联。求等效电容，以微法为单位。
::: solution
[[#eq-parallel]]把电容相加：

$$
C = 4.00 + 12.0 = 16.0\,\mu\mathrm{F}.
$$

答案是 $16.0\,\mu\mathrm{F}$。这两个电容器若改为串联，得到的就不是这个和；那是下一道题。
:::
:::

::: exercise 两个电容器串联 {#exr-series-uf level=2 check="3"}
上一题的两个电容器 $4.00\,\mu\mathrm{F}$ 与 $12.0\,\mu\mathrm{F}$ 改为串联。求等效电容，以微法为单位。
::: solution
由[[#eq-series]]，

$$
\frac{1}{C} = \frac{1}{4.00} + \frac{1}{12.0} = 0.250 + 0.08333 = 0.33333\,\mu\mathrm{F}^{-1},
$$

所以 $C = 3.00\,\mu\mathrm{F}$。精确地算，

$$
\frac{1}{C} = \frac{1}{4} + \frac{1}{12} = \frac{3}{12} + \frac{1}{12} = \frac{1}{3},
$$

于是 $C = 3$，单位是微法。结果小于两者中较小的 $4.00\,\mu\mathrm{F}$，这正是[[#prop-series]]里的那个不等式。
:::
:::

::: exercise 混合网络 {#exr-network level=2 check="18"}
一个 $2.00\,\mu\mathrm{F}$ 的电容器，与"$3.00\,\mu\mathrm{F}$ 和 $6.00\,\mu\mathrm{F}$ 并联后的组合"串联。整个网络接到 $11.0\,\mathrm{V}$ 的电池上。求电池提供的电荷，以微库仑为单位。
::: hint
先把并联对替换成一个电容，再用串联法则。你要求的电荷就是等效电容上的电荷，也正好是 $2.00\,\mu\mathrm{F}$ 电容器上的电荷。
:::
::: solution
由[[#eq-parallel]]，并联对是 $3.00 + 6.00 = 9.00\,\mu\mathrm{F}$。再与 $2.00\,\mu\mathrm{F}$ 串联，

$$
\frac{1}{C} = \frac{1}{2.00} + \frac{1}{9.00} = \frac{9}{18} + \frac{2}{18} = \frac{11}{18},
$$

所以 $C = 18/11\,\mu\mathrm{F} = 1.63636\,\mu\mathrm{F}$。接在 $11.0\,\mathrm{V}$ 上，

$$
Q = CV = \left(\frac{18}{11}\times 10^{-6}\right)(11.0) = 18.0\times 10^{-6}\,\mathrm{C} = 18.0\,\mu\mathrm{C}.
$$

答案是 $18.0\,\mu\mathrm{C}$。作为检验：这份电荷在 $2.00\,\mu\mathrm{F}$ 电容器上产生 $18.0/2.00 = 9.00\,\mathrm{V}$ 的分压，在 $9.00\,\mu\mathrm{F}$ 的并联对上产生 $18.0/9.00 = 2.00\,\mathrm{V}$ 的分压。两处分压相加为 $11.0\,\mathrm{V}$。
:::
:::

::: exercise 电荷不变时插入电介质 {#exr-kappa-v level=2 check="200/7"}
[[#ex-plate]]中的平行板电容器，$C_0 = 1.7708375634\times 10^{-10}\,\mathrm{F}$，充到 $100\,\mathrm{V}$ 后断开。然后用 $\kappa = 3.50$ 的线性电介质完全填满间隙。求新的电势差，以伏特为单位。
::: solution
断开连接固定了自由电荷。[[#prop-dielectric]]说 $C = \kappa C_0$，电势差按 $\kappa$ 下降：

$$
V = \frac{100}{3.50} = \frac{200}{7} = 28.5714\,\mathrm{V}.
$$

保留三位有效数字答案是 $28.6\,\mathrm{V}$；按题给的 $\kappa = 3.50$，精确值是 $200/7$ 伏特。储存的能量按同一因子下降。此时仍取 $V = 100\,\mathrm{V}$ 是错的，那是电池保持连接的情形。
:::
:::

::: exercise 搭出能量积分 {#exr-energy-proof level=3}
电容 $C$ 为常数的电容器，由一个准静态的外在代理把电荷从 $0$ 搬到 $Q$。证明代理做的功为 $Q^2/(2C)$，并说明假设条件。然后证明同一功等于 $\tfrac12 QV$，其中 $V = Q/C$，并用一句话解释为什么电压为 $V$ 的恒压电池做的不是这么多功。
::: hint
写出电荷为 $q$ 时的电势差，乘以 $\dd q$，再积分。关于电池的说明见[[#prop-battery]]。
:::
::: solution
假设条件是：$C$ 为常数，即电容器是线性的且几何形状固定；充电是准静态的，因此载流子的动能不算在储存的能量之内，磁辐射也被忽略；电荷为 $q$ 时的电势差是 $v = q/C$，即[[#def-pair]]。

代理对又一份电荷 $\dd q$ 做的功是 $v\,\dd q = (q/C)\,\dd q$。因此

$$
W = \int_0^{Q} \frac{q}{C}\,\dd q = \frac{Q^2}{2C}.
$$

由 $V = Q/C$ 得 $Q = CV$，所以

$$
\frac{Q^2}{2C} = \frac{(CV)^2}{2C} = \tfrac12 C V^2 = \tfrac12 Q V.
$$

电势差为 $V$ 的恒压电池把全部电荷 $Q$ 推过恒定的电势差 $V$，所以它提供 $QV$，是储存能量的两倍。另一半耗散在充电路径的电阻里，正如[[#prop-battery]]所证明。
:::
:::

::: exercise 相同电容器共享电荷时损失的能量 {#exr-share level=3 check="0.0025"}
一只 $4.00\,\mu\mathrm{F}$ 的电容器充到 $50.0\,\mathrm{V}$ 后与源断开。再把它与另一只不带电的 $4.00\,\mu\mathrm{F}$ 电容器并联。求接通过程中耗散的能量，以焦耳为单位。
::: hint
电荷守恒。最终电容是两者之和。用每个阶段实际具有的电压，分别计算前后两个 $U$。
:::
::: solution
初始电荷与能量为

$$
\begin{aligned}
Q &= (4.00\times 10^{-6})(50.0) = 2.00\times 10^{-4}\,\mathrm{C}, \\
U_i &= \tfrac12(4.00\times 10^{-6})(50.0)^2 = 5.00\times 10^{-3}\,\mathrm{J}.
\end{aligned}
$$

电荷守恒，最终电容为 $8.00\,\mu\mathrm{F}$，所以

$$
V_f = \frac{2.00\times 10^{-4}}{8.00\times 10^{-6}} = 25.0\,\mathrm{V}.
$$

最终储存的能量为

$$
U_f = \tfrac12(8.00\times 10^{-6})(25.0)^2 = 2.50\times 10^{-3}\,\mathrm{J}.
$$

耗散的能量为

$$
U_i - U_f = 2.50\times 10^{-3}\,\mathrm{J}.
$$

场能的一半离开了电容器。在最终能量里使用 $50.0\,\mathrm{V}$，等于凭空造出一个早已断开的电池。两只相同的电容器最终停在原来电压的一半，因为它们均分电荷；换成一般的第二只电容，能量下降的不是恰好一半，[[#ex-sharing]]已经演示过这一点。
:::
:::
