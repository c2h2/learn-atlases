用丝绸摩擦过的玻璃棒，与第二根玻璃棒会互相推开。同一根玻璃棒与一块用毛皮摩擦过的琥珀却彼此吸引。万有引力做不到这一点：重量永远是吸引力，而且对你拿得住的物体而言它实在太小，绝不会被感觉成两者之间的一推。对这个“推”作出响应的物质的新性质，就是**电荷**。

[[mechanics/newton-laws]] 中的牛顿第二定律把一个已知的力变成一个加速度。本章讲的就是静止电荷之间的那个力——电荷小到可以当成质点处理，并且处于真空中。一根带电的棒不是质点：附近一只轻小通草球受到的力，是由点电荷规律拼出来的一个积分。[[electrostatics/electric-field]] 与 [[electrostatics/gauss-law]] 把同一条规律重新组织，而不是取而代之。

## 电荷

电荷有两种符号，它是守恒的，而且一个自由粒子的电荷是元电荷的整数倍。这三条事实独立于力的规律，而正是它们决定了力的规律长成现在的样子。

摩擦并不是凭空创造电荷，而是把电荷从一个物体搬到另一个物体。只要这一对物体与其余一切隔绝，玻璃棒带多少正电，丝绸就带多少等量的负电。本杰明·富兰克林（Franklin）作出的指认——今天沿用的仍然是它——把玻璃规定为正，把琥珀（或橡胶）规定为负。名字只是约定。电荷有两种，而且同种相斥、异种相吸——这一点不是约定。

::: definition 电荷 {#def-charge}
**电荷**是静电力所依赖的物质的标量属性。它可以是正的，也可以是负的。同号电荷彼此排斥；异号电荷彼此吸引。在一个孤立系统中，电荷的代数和保持不变：电荷是**守恒的**。电荷的 SI 单位是库仑，缩写为 $\mathrm{C}$。
:::

守恒是计入符号的。正负对的产生与湮灭会改变正电荷的多少，却不改变代数的总和。在本课程涉及的过程——摩擦、接触、电流——中，电荷只是从一个地方挪到另一个地方。库仑对静电实验来说是个很大的单位：日常遇到的电荷是纳库仑或微库仑量级，而一安培的电流在一秒内就让一个库仑通过某一点。

::: definition 元电荷 {#def-elementary}
任何自由粒子的电荷都是**元电荷**的整数倍

$$
e = 1.602176634\times 10^{-19}\,\mathrm{C}.
$$ {#eq-elementary}

电子带 $-e$，质子带 $+e$。在 SI 中这个 $e$ 的值是精确的：库仑的定义方式就使元电荷恰好取这几个数字。电荷是**量子化的**。
:::

一微库仑已经包含约 $10^{13}$ 个元电荷，所以下面的力律可以把 $q$ 当作连续量。对束缚在单个质子旁边的单个电子来说，这个模型是错的；对本章每一个宏观电荷来说，它是对的。

::: example 一微库仑里的电子数 {#ex-count}
要从中性物体上移走多少个电子，才能使它带 $+1.00\,\mu\mathrm{C}$ 的电荷？一摩尔元电荷是多少库仑？
::: solution
每移走一个电子，物体就带上 $+e$。需要移走的个数为

$$
N = \frac{1.00\times 10^{-6}}{e} = \frac{1.00\times 10^{-6}}{1.602176634\times 10^{-19}} = 6.241509074\times 10^{12}.
$$

保留三位有效数字——与电荷里的 $1.00$ 相匹配——$N = 6.24\times 10^{12}$。

一摩尔是 $N_{\mathrm{A}} = 6.02214076\times 10^{23}$ 个粒子，这又是一个精确的 SI 常量。一摩尔元电荷的电荷量为

$$
N_{\mathrm{A}} e = 96485.332\,\mathrm{C}.
$$

这个乘积就是法拉第常量。一摩尔元电荷不是能抹到棒上去的静电荷，它是一安培的电流大约一天输送的电荷量。
:::
:::

带 $1.00\,\mu\mathrm{C}$ 的物体得到或失去了 $6.24\times 10^{12}$ 个电子。把这笔账与一克普通物质里的原子数放在一起，份额小得可怜，而 [[#ex-gravity]] 会说明为什么力却不小。多余的电荷是否留在你放下的地方，取决于材料。

::: definition 导体与绝缘体 {#def-conductor}
在**导体**中，有些电荷可以在材料里自由地移动实验室尺度那样的距离。金属是导体，因为其中一些电子不束缚在某个特定的原子上。在**绝缘体**中，电荷束缚在原子或分子上，不会穿过样品移动。**静电平衡**指每一个自由电荷都已经停止移动，此时每个自由电荷受到的合力都为零。
:::

玻璃、橡胶、干燥空气和大多数塑料在这里都是良绝缘体。金属是良导体。纯水导电很差；自来水因溶有离子，导电好到足以让摩擦过的棒放电。本章只使用这两个极端。

三种起电方式由定义就能得出，不需要力律。摩擦在两个绝缘体之间分离电荷，电荷就停在发生接触的地方。与导体接触可以让自由电荷流动：两个相同的孤立金属球均分电荷，而对形状的依赖是 [[electrostatics/potential]] 的问题。感应起电从不让棒碰到你要充电的物体。一根带负电的棒靠近中性导体时，会把自由电子驱赶到远侧；把远侧接地，这些电子就流走；先断开地线，再移走棒，导体就留下正电。换成带正电的棒，它就留下负电。棒自身的电荷没有变。把接走电荷的大地也算进来，代数总和依然守恒。

静电平衡意味着每个自由电荷受到的合力为零。导体材料内部电场为零、多余电荷分布在表面上，这两条都要到 [[electrostatics/gauss-law]] 里成为定理，前提是先用 [[electrostatics/electric-field]] 把“每单位电荷受到的力”变成一个场。

::: intuition “中性”究竟意味着什么
一个中性的金属球并不是球里没有电荷，而是球里电子的负电荷与原子核的正电荷相互抵消，精确度远超一个微库仑。给球充电加入的只是一个小小的失衡。本章所有的力，都是失衡与失衡之间的力。
:::

## 库仑定律

两个静止的带电小物体之间的力，依赖两个电荷，也依赖它们之间的距离。库仑（Coulomb）在 1785 年测定了这种依赖。对点电荷而言，其结果就是以他命名的定律。

::: theorem 库仑定律 {#thm-coulomb}
两个点电荷都静止在真空中、彼此距离 $r$ 为正时，点电荷 $q_2$ 由于点电荷 $q_1$ 所受的静电力是

$$
\mathbf{F}_{21} = \frac{1}{4\pi\varepsilon_0}\,\frac{q_1 q_2}{r^{2}}\,\hat{\mathbf{r}}_{21}.
$$ {#eq-coulomb}

单位向量 $\hat{\mathbf{r}}_{21}$ 由 $q_1$ 的位置指向 $q_2$ 的位置。当 $q_1 q_2 > 0$ 时力是斥力，当 $q_1 q_2 < 0$ 时力是引力。以 $\mathbf{r}_1$、$\mathbf{r}_2$ 为两个电荷的位置，

$$
r = \abs{\mathbf{r}_2 - \mathbf{r}_1}, \qquad \hat{\mathbf{r}}_{21} = \frac{\mathbf{r}_2 - \mathbf{r}_1}{r}.
$$ {#eq-rhat}
:::

::: proof
库仑定律是一条实验定律。本章不会从更基本的动力学原理推出平方反比。实验定下来、[[#eq-coulomb]] 记录下来的，是三件事：力分别正比于每一个电荷，力随间距的平方反比衰减，力沿着两电荷的连线。这里的证明，是从这条向量表述里推导出日常的使用规则。

$\hat{\mathbf{r}}_{21}$ 的大小是 $1$，所以

$$
\abs{\mathbf{F}_{21}} = \frac{1}{4\pi\varepsilon_0}\,\frac{\abs{q_1 q_2}}{r^{2}}.
$$ {#eq-coulomb-mag}

乘积 $q_1 q_2$ 的符号没有放进绝对值里，它决定沿连线的指向。乘积为正时，$\mathbf{F}_{21}$ 与 $\hat{\mathbf{r}}_{21}$ 同向，于是 $q_2$ 被推离 $q_1$。乘积为负时，$\mathbf{F}_{21}$ 与 $\hat{\mathbf{r}}_{21}$ 反向，于是 $q_2$ 被拉向 $q_1$。

$q_2$ 施加给 $q_1$ 的力是同一个公式交换标签。间距是同一个数，$r_{12} = r_{21}$。单位向量反号，$\hat{\mathbf{r}}_{12} = -\hat{\mathbf{r}}_{21}$，因为 $\mathbf{r}_1 - \mathbf{r}_2 = -(\mathbf{r}_2 - \mathbf{r}_1)$。乘积 $q_2 q_1$ 等于 $q_1 q_2$。因此

$$
\mathbf{F}_{12} = \frac{1}{4\pi\varepsilon_0}\,\frac{q_2 q_1}{r^{2}}\,\hat{\mathbf{r}}_{12} = -\mathbf{F}_{21}.
$$ {#eq-third}

这两个力大小相等、方向相反，且作用在不同的物体上。按 [[mechanics/newton-laws]] 的意义，它们是一对第三定律的静电力。某个电荷受到的力是它们之一，不是它们的和。它们的和是这一对电荷整体的合力，等于零。
:::

电荷前面那个常量，由库仑的 SI 定义和对力的测量共同确定。我们用两种写法之一来表示它。

$$
k = \frac{1}{4\pi\varepsilon_0} = 8.9875517923\times 10^{9}\,\mathrm{N\cdot m^{2}/C^{2}},
$$ {#eq-k}

$$
\varepsilon_0 = 8.854187817\times 10^{-12}\,\mathrm{C^{2}/(N\cdot m^{2})}.
$$ {#eq-eps0}

这里 $k$ 是库仑常量，$\varepsilon_0$ 是真空介电常数。按 [[#eq-k]] 与 [[#eq-eps0]] 中的数字，$4\pi\varepsilon_0 k$ 与 $1$ 的差在 $10^{10}$ 分之一量级的几倍以内，比下文任何保留的位数都精细，所以数值计算直接用给定的 $k$。把 $4\pi$ 放进分母，是为了让后面登场的高斯定律里不必再出现它。电荷的平方除以长度的平方，再乘这个 $k$，单位应是牛顿。算不出牛顿的公式就是错误的公式。

::: warning 点电荷、静止、一次只数一个力
[[#eq-coulomb]] 适用于真空中静止的点电荷。电荷分布在体积或表面上的物体不是点。它附近一个点电荷 $q_0$ 受到的力，是把 [[#eq-coulomb]] 对分布作积分，

$$
\mathbf{F} = \frac{1}{4\pi\varepsilon_0}\, q_0 \int \frac{\mathrm{d}q}{r^{2}}\,\hat{\mathbf{r}},
$$

其中 $r$ 与 $\hat{\mathbf{r}}$ 都从电荷元 $\mathrm{d}q$ 取到 $q_0$。把总电荷塞进 [[#eq-coulomb-mag]]、距离取到中心，是另一种、而且通常是错误的计算。运动的电荷会引入磁力，那不在这条定律之内；磁力从 [[magnetism]] 开始。而且某个电荷受到的力是 $\mathbf{F}_{21}$ 或 $\mathbf{F}_{12}$，不是 $2\abs{\mathbf{F}_{21}}$。第三定律的另一半作用在另一个物体上；一旦你说明了自己在画哪个物体的受力图，它就已经被数过一次了。
:::

相距一米、各带一个库仑的两个电荷，会以 $k = 8.9875517923\times 10^{9}\,\mathrm{N}$ 的力互相排斥。在地球附近，这相当于质量为 $k/g$ 的物体的重量。取 $g = 9.80\,\mathrm{m/s^{2}}$，

$$
\frac{k}{g} = \frac{8.9875517923\times 10^{9}}{9.80} = 9.171\times 10^{8}\,\mathrm{kg}.
$$

一库仑是荒唐的静电荷量。实验室的可用尺度是微库仑配上厘米到几十厘米的距离：力从零点几牛顿到几牛顿，大到可以测量，又小到搭得起来。

::: example 两个微库仑电荷 {#ex-pair}
电荷 $q_1 = +2.00\,\mu\mathrm{C}$ 与电荷 $q_2 = -3.00\,\mu\mathrm{C}$ 相距 $0.200\,\mathrm{m}$，静止于真空。求每个电荷受到的力。
::: solution
乘积 $q_1 q_2$ 为负，所以力是引力。大小由 [[#eq-coulomb-mag]] 给出，$k$ 取 [[#eq-k]]：

$$
\abs{\mathbf{F}} = \frac{k\,\abs{q_1 q_2}}{r^{2}} = \frac{(8.9875517923\times 10^{9})\,(2.00\times 10^{-6})\,(3.00\times 10^{-6})}{(0.200)^{2}}.
$$

分子中不含 $k$ 的部分是 $6.00\times 10^{-12}$，$r^{2} = 0.0400$，两者之比为 $1.50\times 10^{-10}$。乘上 $k$ 得

$$
\abs{\mathbf{F}} = 1.348\,\mathrm{N}.
$$

不四舍五入的乘积是 $1.34813\,\mathrm{N}$。$q_2$ 受到的力指向 $q_1$，$q_1$ 受到的力指向 $q_2$。它们就是 [[#eq-third]] 的那一对。谁的大小都不是 $2.696\,\mathrm{N}$。
:::
:::

::: quiz
两个点电荷的间距加倍，其中某一个电荷也加倍。静电力的大小变为
- [ ] 原来的四倍
- [ ] 原来的两倍
- [x] 原来的一半
- [ ] 原来的四分之一
::: solution
大小正比于两个电荷的乘积，正比于 $1/r^{2}$。一个电荷加倍使乘积乘 $2$；间距加倍使 $1/r^{2}$ 乘 $1/4$。力乘 $2/4 = 1/2$。
:::
:::

::: corollary 缩放 {#cor-scaling}
若 $q_1$ 乘因子 $\alpha$，$q_2$ 乘因子 $\beta$，间距乘因子 $\gamma > 0$，库仑力就乘 $\alpha\beta/\gamma^{2}$。特别地，两个电荷都乘 $-1$ 不改变力；间距加倍则力变为四分之一。
:::

::: proof
把 $\alpha q_1$、$\beta q_2$ 与 $\gamma r$ 代入 [[#eq-coulomb]]。只要两个电荷在连线上的前后次序不变，沿线的单位向量就不变，它前面的标量因子变化 $\alpha\beta/\gamma^{2}$。两个电荷同时变号使乘积乘 $(+1)$，所以力向量不变。把 $r$ 换成 $2r$，力除以 $4$。
:::

## 叠加原理

库仑定律说的是“一对”。第三个电荷不会迫使这一对停止施加那个力。多出来的电荷施加自己的力，两个力按向量相加。这是一条进一步的实验事实，不是 [[#eq-coulomb]] 的代数推论。

::: axiom 叠加原理 {#ax-superposition}
一簇其他点电荷都静止在真空中时，它们作用在一个点电荷上的静电力，是这些电荷各自单独作用时施加的库仑力的向量之和。这些力互不改变对方。
:::

把所有源电荷加倍，试探电荷上的合力也加倍。实验室的强度下，真空是线性的，叠加原理在本课程中是精确的。大多数错误答案来自漏掉流程中的某一步。

::: algorithm 净库仑力 {#alg-super}
从一开始就用 SI 单位：米和库仑，而不是没换算的厘米和微库仑。选定你要算哪个电荷的力，只画它受到的力。对每一个别的电荷，算出 $k\abs{q_i q}/r_i^{2}$，再由 $q_i q$ 的符号定指向：乘积为正就背离 $q_i$，为负就指向 $q_i$。把这些力沿固定的坐标轴分解成分量。分量相加。只有当各力平行时才能把大小相加。不要计入某个电荷对自己施加的力。第三定律的另一半作用在别的电荷上，不是这个求和里的额外项。
:::

::: example 中点处的第三个电荷 {#ex-mid}
[[#ex-pair]] 的两个电荷保持不动：$x = 0$ 处是 $+2.00\,\mu\mathrm{C}$，$x = 0.200\,\mathrm{m}$ 处是 $-3.00\,\mu\mathrm{C}$。在中点 $x = 0.100\,\mathrm{m}$ 处放下第三个电荷 $q_3 = +1.00\,\mu\mathrm{C}$。求 $q_3$ 受到的合力。
::: solution
中点与两个电荷都是 $0.100\,\mathrm{m}$，所以两个力的 $r^{2}$ 都是 $0.0100\,\mathrm{m^{2}}$。

$q_3$ 与原点处电荷的乘积为正，那个力是斥力；从 $x = 0.100\,\mathrm{m}$ 处说“背离原点”，就是 $x$ 轴正向。其大小为

$$
F_{1} = \frac{k\,(2.00\times 10^{-6})\,(1.00\times 10^{-6})}{0.0100} = 1.7975\,\mathrm{N}.
$$

$q_3$ 与 $x = 0.200\,\mathrm{m}$ 处电荷的乘积为负，那个力是引力，指向负电荷，那也是 $x$ 轴正向。其大小为

$$
F_{2} = \frac{k\,(3.00\times 10^{-6})\,(1.00\times 10^{-6})}{0.0100} = 2.6963\,\mathrm{N}.
$$

两个力平行。叠加原理说要把它们加起来，不是相减：

$$
F_{\mathrm{net}} = 1.7975 + 2.6963 = 4.4938\,\mathrm{N},
$$

方向沿 $x$ 轴正向，指向负电荷。保留三位有效数字是 $4.49\,\mathrm{N}$。相减回答的是两个力指向相反的问题。它们并不相反：试探电荷被正电荷推开，同时被负电荷拉过去。
:::
:::

当力不平行时，下一步是取分量，而不是把大小求和。

::: example 三个电荷，不在一条线上 {#ex-triangle}
电荷 $q_1 = +5.00\,\mu\mathrm{C}$ 在原点，电荷 $q_2 = +3.00\,\mu\mathrm{C}$ 在 $(0.300\,\mathrm{m},\, 0)$。求 $q_3 = +2.00\,\mu\mathrm{C}$ 在 $(0.300\,\mathrm{m},\, 0.400\,\mathrm{m})$ 处受到的合力。
::: solution
$q_1$ 到 $q_3$ 的距离是 $\sqrt{0.300^{2} + 0.400^{2}} = 0.500\,\mathrm{m}$，一个放大 $0.100\,\mathrm{m}$ 的 $3$-$4$-$5$ 三角形。$q_2$ 到 $q_3$ 的距离是 $0.400\,\mathrm{m}$。三个电荷乘积都是正的，所以 $q_3$ 受到的两个力都是斥力。

$$
F_{1} = \frac{k\,(5.00\times 10^{-6})\,(2.00\times 10^{-6})}{(0.500)^{2}} = 0.35950\,\mathrm{N},
$$

方向由原点指向 $q_3$，沿单位向量 $(0.600,\, 0.800)$。

$$
F_{2} = \frac{k\,(3.00\times 10^{-6})\,(2.00\times 10^{-6})}{(0.400)^{2}} = 0.33703\,\mathrm{N},
$$

方向竖直向上，背离 $q_2$，沿 $(0,\, 1)$。

合力的分量为

$$
\begin{aligned}
F_x &= 0.35950\times 0.600 = 0.21570\,\mathrm{N}, \\
F_y &= 0.35950\times 0.800 + 0.33703 = 0.28760 + 0.33703 = 0.62463\,\mathrm{N}.
\end{aligned}
$$

大小与相对 $x$ 轴正向的方向角为

$$
\abs{\mathbf{F}} = \sqrt{0.21570^{2} + 0.62463^{2}} = 0.66083\,\mathrm{N}, \qquad \theta = \tan^{-1}\frac{0.62463}{0.21570} = 70.95^{\circ}.
$$

两个力相差 $53.13^{\circ}$，所以大小之和不是和的大小。
:::
:::

叠加原理还指出第三个电荷可以坐在哪里，使它受到的合力消失。位置完全由源电荷决定。

::: proposition 两个同号电荷之间的零点 {#prop-null}
在 $x = 0$ 固定电荷 $Q \neq 0$，在 $x = L > 0$ 固定电荷 $\alpha Q$，其中 $\alpha > 0$。第三个电荷 $q \neq 0$ 放在两者之间的开线段上时，恰在一个点上受到的净库仑力为零：

$$
x = \frac{L}{1 + \sqrt{\alpha}}.
$$ {#eq-null}

这个坐标不依赖 $q$，也不依赖 $Q$ 的符号。若两个固定电荷异号，线段上就没有这样的点。若 $q$ 与 $Q$ 同号，沿线方向的小位移会被合力拉回，而离开直线的小位移则不会。若 $q$ 与 $Q$ 异号，沿线方向的小位移才是那个会跑掉的。
:::

::: proof
设 $q$ 在坐标 $x$ 处，$0 < x < L$。它到 $Q$ 的距离是 $x$，到 $\alpha Q$ 的距离是 $L - x$。

先设 $Q$ 与 $q$ 同号，于是 $C = k Q q > 0$。$Q$ 的斥力把 $q$ 推向 $x$ 轴正向，$\alpha Q$ 的斥力把 $q$ 推向 $x$ 轴负向。合力为

$$
F_x = C\left(\frac{1}{x^{2}} - \frac{\alpha}{(L - x)^{2}}\right).
$$

当 $(L - x)/x = \sqrt{\alpha}$ 时它为零，取正根是因为两个距离都是正的。于是 $L - x = x\sqrt{\alpha}$，即 $x(1 + \sqrt{\alpha}) = L$，就是 [[#eq-null]]。平方根的负值会把某个距离放到零的错误一侧，舍去。若 $q$ 与 $Q$ 异号，两个力同时反向，$C$ 变号，同一个括号仍在同一个 $x$ 处为零。因此只要 $\alpha > 0$——即两个固定电荷同号——位置就与 $q$ 以及 $Q$ 的符号无关。

若两个固定电荷异号，取 $\alpha < 0$。在线段上，正的试探电荷被正的固定电荷排斥、被负的固定电荷吸引，这两个方向重合。负的试探电荷两个力都反过来，它们依然彼此重合。$F_x$ 的两个贡献在整个开线段上处处同号，所以 $F_x$ 在那里没有零点。

对于 $\alpha > 0$ 的稳定性，把同号情形的表达式求导：

$$
\deriv{F_x}{x} = C\left(-\frac{2}{x^{3}} - \frac{2\alpha}{(L - x)^{3}}\right).
$$

括号对线段内的每个 $x$ 都是负的。若 $C > 0$，导数为负：把 $q$ 右移使 $F_x$ 变负，朝零点回去；把 $q$ 左移使 $F_x$ 变正，又朝零点回去。若 $C < 0$，导数为正，沿线方向的零点不稳定。

侧向呢，零点并非对每种符号都是极小。若 $Q > 0$ 且 $q > 0$，每个斥力都有把电荷推得离轴更远的分量，横向位移会跑掉。若 $q$ 为负，横向分量是恢复性的，而沿线方向——本来就不稳定——正是跑掉的那个方向。两种情形下，零点都不是对所有小位移都稳定。恩肖（Earnshaw）在 1842 年证明这是一般的：只靠静电力，无法把一个电荷在空区域里维持稳定平衡。上面的求导只是对这一种布置的检验，不是那条定理。
:::

::: example 一个电荷与四倍它的电荷之间的零点 {#ex-null}
$Q = +2.00\,\mu\mathrm{C}$ 固定在 $x = 0$，$4Q = +8.00\,\mu\mathrm{C}$ 固定在 $x = 0.300\,\mathrm{m}$。电荷 $q = +1.00\,\mathrm{nC}$ 在哪里不受净力？那里两个分力的大小各是多少？
::: solution
这里 $\alpha = 4$，$\sqrt{\alpha} = 2$，所以 [[#eq-null]] 给出 $x = L/3 = 0.100\,\mathrm{m}$，即距较小的电荷 $0.100\,\mathrm{m}$、距较大的电荷 $0.200\,\mathrm{m}$。试探电荷离较小的源更近。规律就是这样：零点总是靠近数值较小的那个电荷，让较弱的源靠更近来抵消较强的那个。

每个力的大小都是

$$
F = \frac{k\,(2.00\times 10^{-6})\,(1.00\times 10^{-9})}{(0.100)^{2}} = 1.7975\times 10^{-3}\,\mathrm{N}.
$$

来自 $4Q$ 的力是

$$
\frac{k\,(8.00\times 10^{-6})\,(1.00\times 10^{-9})}{(0.200)^{2}} = \frac{k\,(8.00\times 10^{-15})}{0.0400} = 1.7975\times 10^{-3}\,\mathrm{N},
$$

数值相同，方向相反。合力为零。由于 $q$ 与 $Q$ 都是正的，这个平衡沿线方向能恢复、沿线外不能。穿在一根光滑绝缘细线上的小珠会停在原地；平面里的一个自由电荷则会滑走。
:::
:::

- [ ] 方向相反，大小大的那个赢
- [x] 方向相同，都指向负电荷，所以要相加

## 这个力有多大

平方反比也是 [[mechanics/gravitation]] 中万有引力定律的形状。这个比较值得算出一个数，因为它解释了为什么一个几乎中性的物体仍然能施加一个你感觉到的力，也解释了为什么主宰行星运动的是引力而不是电力。

::: example 电力对抗引力 {#ex-gravity}
比较两个质子之间的静电斥力与它们的万有引力，再比较一个电子和一个质子之间的静电引力与它们的万有引力。质子取 $m_p = 1.673\times 10^{-27}\,\mathrm{kg}$，电子取 $m_e = 9.109\times 10^{-31}\,\mathrm{kg}$，$G = 6.67430\times 10^{-11}\,\mathrm{N\cdot m^{2}/kg^{2}}$。距离会约掉；不要擅自假设一个。
::: solution
两个力都是平方反比，所以比值与 $r$ 无关。两个质子之间，静电力是斥力，万有引力是吸引力：

$$
\frac{F_e}{F_g} = \frac{k e^{2}/r^{2}}{G m_p^{2}/r^{2}} = \frac{k e^{2}}{G m_p^{2}}.
$$

代入 [[#eq-k]]、[[#eq-elementary]] 和上面的质量，

$$
\frac{k e^{2}}{G m_p^{2}} = 1.235\times 10^{36}.
$$

电子与质子之间，静电力像引力一样是吸引力，而比值更大，因为电子更轻：

$$
\frac{k e^{2}}{G m_e m_p} = 2.268\times 10^{39}.
$$

普通物质必须中性到荒唐的精度，否则电力会把重量碾过去。行星轨道无视电荷，不是因为静电力弱，而是因为行星中性到那种精度。
:::
:::

对于空气中相距几厘米的通草球，[[#eq-coulomb]] 就是可用的定律。分布源要用 warning 里的那个积分，而不是把总电荷摆在中心——除非某个定理替你担保。均匀球壳的外部就是那个定理，在 [[electrostatics/gauss-law]] 中证明。

::: history 扭秤，以及此前的一次零结果
1767 年，普里斯特利（Priestley）在《电的历史与现状》（*The History and Present State of Electricity*）中论证，电力应当随距离的平方反比衰减。他使用的证据是一次零结果：放在带电空心导体内部的电荷不受力。牛顿已经证明，一层均匀球壳对其内部质点的万有引力为零，而且证明用到了平方反比。普里斯特利把电学上的零结果读成同一条定理换了个力。卡文迪什（Cavendish）在 1773 年前后，用同心球检验那个指数，精度比当时任何直接测力都高得多。他没有发表。麦克斯韦（Maxwell）在 1879 年发表了卡文迪什的电学研究。

库仑自己的测量发表于 1785 年，用的是扭秤：一只带电通草球挂在细纤维吊着的杆上，被第二只带电的球排斥。纤维的扭转量度力的大小。改变间距与电荷，就得到了平方反比律以及力分别正比于每个电荷的结论。[[#eq-coulomb]] 就是这个结果，用 SI 单位表述，适用于真空中静止的电荷。
:::

## 后续内容

选定的电荷受到的力，正是牛顿第二定律需要的东西。[[#ax-superposition]] 给出合力，剩下的交给 $m\mathbf{a} = \mathbf{F}_{\mathrm{net}}$。如果源电荷也可以自由运动，那么位置一变，每个力都跟着变。本章固定源的问题，就是那个多体耦合问题在源质量取无穷大时的特例。

把力除以受力那个电荷，就把那个电荷从描述中删掉了。剩下的就是 [[electrostatics/electric-field]] 的电场。[[electrostatics/potential]] 里的电势把向量问题变回标量问题。这两步都不改变真空中静止两点电荷之间的 [[#eq-coulomb]]。

::: summary
- 电荷有两种符号，同号相斥，异号相吸。孤立系统中电荷的代数和守恒，自由粒子带的电荷是精确元电荷 $e = 1.602176634\times 10^{-19}\,\mathrm{C}$ 的整数倍。
- 导体中有些电荷可以自由移动，绝缘体中不能。静电平衡指每个自由电荷受到的合力为零。摩擦、接触与感应挪动电荷，不从无中造出净电荷。
- 库仑定律给出 $q_1$ 作用在 $q_2$ 上的力为 $k q_1 q_2 \hat{\mathbf{r}}_{21}/r^{2}$，其中 $k = 1/(4\pi\varepsilon_0) = 8.9875517923\times 10^{9}\,\mathrm{N\cdot m^{2}/C^{2}}$。电荷乘积为正时力是斥力。它是真空中静止点电荷的定律。
- 一对库仑力等大反向，作用在不同的物体上。某个物体受到的力不是 [[#eq-coulomb-mag]] 那个大小的两倍。
- 叠加原理：合力是各个库仑力的向量和。先分量，后大小。只有当各力平行、且方向已经确认一致时，才能把大小相加。
- 两个同号的固定电荷之间，第三个电荷在 $x = L/(1+\sqrt{\alpha})$ 处所受合力为零，零点靠近较小的电荷。零点不是各个方向都稳定。
- 分布电荷是库仑定律的积分。把总电荷放到中心代替不了那个积分。运动电荷受到的磁力不在本章之内。
:::

## 习题

::: exercise 两个小电荷的排斥 {#exr-pair level=1}
$+3.00\,\mu\mathrm{C}$ 与 $+6.00\,\mu\mathrm{C}$ 两个电荷在真空中静止，相距 $0.120\,\mathrm{m}$。求每个电荷受力的大小，并指出是引力还是斥力。
::: solution
电荷的乘积为正，所以每个力都是斥力。由 [[#eq-third]]，两者的大小相同：

$$
\abs{\mathbf{F}} = \frac{k\,(3.00\times 10^{-6})\,(6.00\times 10^{-6})}{(0.120)^{2}} = \frac{k\,(1.80\times 10^{-11})}{0.0144} = k\,(1.25\times 10^{-9}).
$$

代入 [[#eq-k]]，

$$
\abs{\mathbf{F}} = 11.234\,\mathrm{N},
$$

保留四位有效数字是 $11.23\,\mathrm{N}$。每个力都背离另一个电荷。把这个大小乘二，就是那个重复计数的错误。
:::
:::

::: exercise 与元电荷分享一个微库仑 {#exr-count level=1}
一个中性绝缘小球通过接触带上了 $-1.00\,\mathrm{nC}$ 的电荷。这相当于多少个多余的电子？用精确的元电荷值。
::: solution
$-1.00\times 10^{-9}\,\mathrm{C}$ 是电子过剩，不是缺少。个数为

$$
N = \frac{1.00\times 10^{-9}}{e} = \frac{1.00\times 10^{-9}}{1.602176634\times 10^{-19}} = 6.241509074\times 10^{9}.
$$

保留三位有效数字是 $6.24\times 10^{9}$ 个电子。同一个计数在微库仑尺度上是 [[#ex-count]]，大一千倍；而这两个数与 $1$ 相比都大得没边。
:::
:::

::: exercise 电荷加倍、间距变三倍 {#exr-scale level=1 check="2/9"}
两个静止的点电荷之间的库仑力大小为 $F$。把一个电荷加倍，另一个保持不变，再把间距变成三倍。新的大小为 $f F$，求数 $f$。
::: solution
[[#cor-scaling]] 给出力乘 $\alpha\beta/\gamma^{2}$。这里 $\alpha = 2$、$\beta = 1$、$\gamma = 3$，所以

$$
f = \frac{2\times 1}{3^{2}} = \frac{2}{9}.
$$

距离变三倍把力除以九，加倍的那个电荷补不回来。
:::
:::

::: exercise 不在中点处 {#exr-off level=2}
$+5.00\,\mu\mathrm{C}$ 固定在 $x = 0$，$-2.00\,\mu\mathrm{C}$ 固定在 $x = 0.500\,\mathrm{m}$。在 $x = 0.200\,\mathrm{m}$ 处放一个 $+1.00\,\mu\mathrm{C}$ 的电荷。求它受到的合力，方向相对 $x$ 轴正向给出。
::: solution
试探电荷距正源 $0.200\,\mathrm{m}$，距负源 $0.300\,\mathrm{m}$。

$+5.00\,\mu\mathrm{C}$ 施加的力是斥力。在 $x = 0.200\,\mathrm{m}$ 处，那个方向是 $+x$。其大小为

$$
F_{+} = \frac{k\,(5.00\times 10^{-6})\,(1.00\times 10^{-6})}{(0.200)^{2}} = 1.1234\,\mathrm{N}.
$$

$-2.00\,\mu\mathrm{C}$ 施加的力是引力，指向 $x = 0.500\,\mathrm{m}$，也是 $+x$。其大小为

$$
F_{-} = \frac{k\,(2.00\times 10^{-6})\,(1.00\times 10^{-6})}{(0.300)^{2}} = 0.19972\,\mathrm{N}.
$$

两个力平行，所以

$$
F_{\mathrm{net}} = 1.1234 + 0.19972 = 1.3232\,\mathrm{N}
$$

方向沿 $x$ 轴正向，指向负电荷。保留四位有效数字是 $1.323\,\mathrm{N}$。方向一致，是因为试探电荷位于异号电荷之间，正如 [[#ex-mid]]。若是同号就会相互对抗，那是 [[#prop-null]]。
:::
:::

::: exercise 连线之上的电荷 {#exr-components level=2}
$+2.00\,\mu\mathrm{C}$ 在原点，$-5.00\,\mu\mathrm{C}$ 在 $(0.800\,\mathrm{m},\, 0)$。求放在 $(0.800\,\mathrm{m},\, 0.600\,\mathrm{m})$ 的 $+1.00\,\mu\mathrm{C}$ 受到的合力。
::: solution
原点到试探电荷的距离是 $\sqrt{0.800^{2} + 0.600^{2}} = 1.000\,\mathrm{m}$。负电荷到试探电荷的距离是 $0.600\,\mathrm{m}$。

$+2.00\,\mu\mathrm{C}$ 的力是斥力，沿单位向量 $(0.800,\, 0.600)$：

$$
F_{1} = \frac{k\,(2.00\times 10^{-6})\,(1.00\times 10^{-6})}{(1.000)^{2}} = 1.7975\times 10^{-2}\,\mathrm{N}.
$$

$-5.00\,\mu\mathrm{C}$ 的力是引力。负电荷恰在试探电荷正下方，所以“指向它”就是 $y$ 轴负向：

$$
F_{2} = \frac{k\,(5.00\times 10^{-6})\,(1.00\times 10^{-6})}{(0.600)^{2}} = 0.12483\,\mathrm{N}.
$$

分量，取 $+x$ 向右、$+y$ 向上：

$$
\begin{aligned}
F_x &= (1.7975\times 10^{-2})\times 0.800 = 1.4380\times 10^{-2}\,\mathrm{N}, \\
F_y &= (1.7975\times 10^{-2})\times 0.600 - 0.12483 = 1.0785\times 10^{-2} - 0.12483 = -0.11404\,\mathrm{N}.
\end{aligned}
$$

$$
\abs{\mathbf{F}} = \sqrt{(1.4380\times 10^{-2})^{2} + (0.11404)^{2}} = 0.1149\,\mathrm{N}.
$$

方向在 $x$ 轴正向以下，

$$
\theta = \tan^{-1}\frac{-0.11404}{1.4380\times 10^{-2}} = -82.81^{\circ}.
$$

占大头的是把电荷拉向较近那个负电荷的向下的吸引力。远处斥力贡献了 $F_x$ 的全部，丢掉它就成了另一个问题。
:::
:::

::: exercise 三个相等的电荷 {#exr-equilateral level=2 check="sqrt(3)"}
三个相等的电荷 $q$ 位于边长 $a$ 的等边三角形的三个顶点。每个电荷受到的合力大小为 $f\, k q^{2}/a^{2}$，求 $f$。设 $q \neq 0$、$a > 0$，并假设三个电荷被固定住。
::: hint
选定电荷受到的两个力大小相等，夹角就是三角形的内角。用和的余弦定理算大小，或者沿角平分线取分量，都可以。
:::
::: solution
每个邻近的电荷都施加大小为 $F = k q^{2}/a^{2}$ 的力。若 $q > 0$，两个乘积都是正的，两个力都是斥力，方向背离各自的邻居，即沿两条边向外。若 $q < 0$，两个力都是引力，沿两条边向内。两种情形下，选定电荷上的两个力向量都有相同的大小，而它们的作用线之间的夹角是 $60^{\circ}$，即等边三角形的内角。

两个长度同为 $F$、夹角 $60^{\circ}$ 的向量，其和的大小满足

$$
\abs{\mathbf{F}_{\mathrm{net}}}^{2} = F^{2} + F^{2} + 2 F F \cos 60^{\circ} = 2F^{2} + 2F^{2}\cdot\tfrac{1}{2} = 3F^{2}.
$$

所以 $\abs{\mathbf{F}_{\mathrm{net}}} = F\sqrt{3}$，即 $f = \sqrt{3}$。沿角平分线取分量给出同样的因子：每个力贡献 $F\cos 30^{\circ}$，横向的部分相互抵消，而 $q$ 的符号让两个力同时反向，$f$ 不变。
:::
:::

::: exercise 一对异号电荷之外 {#exr-opposite level=3 check="1/2"}
$+Q$ 固定在 $x = 0$，$-9Q$ 固定在 $x = L > 0$，其中 $Q \neq 0$。一个正试探电荷在 $x$ 轴上的 $x = -d$ 处平衡，$d > 0$。求数 $d/L$。
::: hint
在 $x = -d$ 处，$+Q$ 的斥力与指向 $-9Q$ 的吸引力方向相反。令两者大小相等。再检查 $x > L$ 的区域与开线段，足以看出这是唯一的零点。
:::
::: solution
把试探电荷 $q > 0$ 放在 $x = -d$。$+Q$ 排斥它，朝 $x$ 轴负向，大小 $k Q q/d^{2}$。$-9Q$ 吸引它，朝 $x$ 轴正向，大小 $k\,(9Q)\,q/(L + d)^{2}$。这两个方向相反，所以零点有可能存在。令大小相等，

$$
\frac{1}{d^{2}} = \frac{9}{(L + d)^{2}}.
$$

两个距离都是正的，所以 $L + d = 3d$，于是 $L = 2d$，$d/L = 1/2$。负根 $L + d = -3d$ 要求一个负距离，舍去。零点位于线段之外、靠近数值较小的那个电荷，也就是 $Q$ 而不是 $9Q$。

在开线段 $0 < x < L$ 上，正的试探电荷被 $+Q$ 向右排斥，被 $-9Q$ 向右吸引，两个力平行。源电荷之间没有零点。

在远侧，$x = L + s$、$s > 0$，来自 $+Q$ 的斥力向右，对 $-9Q$ 的吸引力向左，所以几何上零点有可能存在。大小给出 $Q/(L + s)^{2} = 9Q/s^{2}$，对 $1/9$ 取正平方根后得 $(L + s)/s = 1/3$。于是 $L + s = s/3$，迫使 $L < 0$，与 $L > 0$ 矛盾。较大的电荷之外没有零点。轴上唯一的平衡点就在 $d = L/2$。

沿线方向这个零点不稳定：靠近 $+Q$ 会加强斥力，把试探电荷推得离零点更远。异号电荷翻转了 [[#prop-null]] 中关于恢复的结论。
:::
:::

::: exercise 正方形上的四个电荷 {#exr-square level=3 check="sqrt(2)+1/2"}
四个相等的电荷 $q$ 固定在边长 $a > 0$ 的正方形的四个顶点上。每个电荷受到的合力大小为 $f\, k q^{2}/a^{2}$，求 $f$。
::: hint
其中两个力大小相等且互相垂直，它们的合力沿对角线。来自对角顶点的第三个力也在这条对角线上。到对角顶点的距离是 $a\sqrt{2}$。
:::
::: solution
把正方形记作 $ABCD$，计算 $A$ 处电荷受到的力。两个相邻顶点 $B$、$D$ 处的电荷各施加大小为

$$
F_{\mathrm{adj}} = \frac{k q^{2}}{a^{2}}
$$

的力。这两个力互相垂直。$q > 0$ 时它们沿两条边向外，其合力大小为

$$
\sqrt{F_{\mathrm{adj}}^{2} + F_{\mathrm{adj}}^{2}} = F_{\mathrm{adj}}\sqrt{2} = \sqrt{2}\,\frac{k q^{2}}{a^{2}},
$$

沿对角线向外。若 $q < 0$，合力反向而大小不变。对角顶点 $C$ 在距离 $a\sqrt{2}$ 处，施加

$$
F_{\mathrm{diag}} = \frac{k q^{2}}{(a\sqrt{2})^{2}} = \frac{k q^{2}}{2a^{2}},
$$

沿同一条对角线。无论 $q$ 是什么符号，这个力都与两个相邻力的合力平行：三个力或者全是斥力，或者全是引力，而几何位置把它们放在同一条线上。

于是合力的大小是

$$
\left(\sqrt{2} + \frac{1}{2}\right)\frac{k q^{2}}{a^{2}}.
$$

所求的数是 $f = \sqrt{2} + 1/2$，等价地写成 $(2\sqrt{2} + 1)/2$。作为算术检验，取 $q = 2.00\,\mu\mathrm{C}$、$a = 0.100\,\mathrm{m}$，得 $k q^{2}/a^{2} = 3.5950\,\mathrm{N}$，合力为 $6.8816\,\mathrm{N}$。因子 $f$ 本身不依赖这两个数值。
