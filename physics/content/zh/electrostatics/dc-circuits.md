一盏灯接一个电池，欧姆定律一行就说完了。但加上第二盏灯、第二个电池，或者一个电容器，问题就变了。电流不再是一个能从电势差和电阻直接读出的数。电流稳恒时电荷不会在节点堆积，而沿任何闭合路径绕行一周，静电势必定回到出发时的值。这两条事实就是基尔霍夫定律。本章把它们变成一套方法：可以化简的电阻网络、无法这样化简的网络、会加热自己内部的电池，以及电容器的缓慢充电。

电流、电阻与欧姆定律取自[[electrostatics/current]]。电容以及电容器储存的能量取自[[electrostatics/capacitance]]。电势是静电场的曲线积分，见[[electrostatics/potential]]。下面的电功率是对电荷做功的速率。它不是[[mechanics/work-energy]]中的力学动能定理；电池贡献的符号必须从电流的方向读出，而不是从电动势的大小去猜。

全程中，理想连接导线的电阻为零。在模型里它上面没有电势降落。欧姆定律产生的每一处降落，都落在电阻里，或者落在有内阻的电池内部。

## 电阻的串联与并联

两个网络对外等价，是指同一个电势差在两者中各自驱动同样的总电流——外部电路分不出它们。

::: definition 等效电阻 {#def-equivalent}
设一个电阻网络有两个端子，两个端子之间的电势差 $V$ 驱动总电流 $I$ 从一个端子流入、从另一个端子流出。网络在这两个端子之间的**等效电阻**为

$$
R_{\mathrm{eq}} = \frac{V}{I},
$$ {#eq-equivalent}

其中要求 $I \neq 0$。在任何更大的电路中，该网络都可以用一个电阻 $R_{\mathrm{eq}}$ 代替。
:::

这一定义用的是真正流入网络的稳恒电流，还没有说电阻怎么连接。串联与并联是 $R_{\mathrm{eq}}$ 可以直接写出的两种接法。

::: theorem 电阻的串联 {#thm-series}
若电阻 $R_1, R_2, \ldots, R_n$ 通过相同的电流 $I$，且整条链两端的电势差 $V$ 等于各个电阻两端电势差之和，则

$$
R_{\mathrm{eq}} = R_1 + R_2 + \cdots + R_n.
$$ {#eq-series}
:::

::: proof
对第 $k$ 个电阻用欧姆定律得 $V_k = I R_k$。只存在一个电流，因为串联链上没有能让电荷离开的节点。把电势差相加，

$$
V = V_1 + \cdots + V_n = I(R_1 + \cdots + R_n).
$$

由[[#def-equivalent]]便得 $R_{\mathrm{eq}} = V/I = R_1 + \cdots + R_n$。
:::

串联电阻相加，正是同一种金属的细长线比粗短线电阻更大的原因：导线是一段段的链，各段电阻相加。串联同时也是一个分压器。第 $k$ 个电阻分得总电势差的份额 $R_k/R_{\mathrm{eq}}$，因为 $V_k/V = (IR_k)/(IR_{\mathrm{eq}})$。

::: theorem 电阻的并联 {#thm-parallel}
若电阻 $R_1, R_2, \ldots, R_n$ 接在同样的两个节点之间，因而每个电阻承受相同的电势差 $V$，则

$$
\frac{1}{R_{\mathrm{eq}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}.
$$ {#eq-parallel}
:::

::: proof
由欧姆定律，第 $k$ 条支路的电流为 $I_k = V/R_k$。在支路汇合的节点处电流相加：从电源到达的总电流为 $I = I_1 + \cdots + I_n$，因为稳态下电荷不在节点上积聚。于是

$$
I = V\left(\frac{1}{R_1} + \cdots + \frac{1}{R_n}\right).
$$

由[[#def-equivalent]]得 $1/R_{\mathrm{eq}} = I/V$，这正是[[#eq-parallel]]。
:::

对两个电阻，公式写作"乘积除以和"：$R_{\mathrm{eq}} = R_1 R_2/(R_1 + R_2)$。并联总是降低电阻：多一条路径不会让电荷更难通过。最小的电阻分走最大份额的电流，并主导 $R_{\mathrm{eq}}$。

::: example 两个等值电阻并联 {#ex-parallel}
两个 $8.00\,\Omega$ 的电阻并联，接在 $12.0\,\mathrm{V}$ 的理想电池两端。求等效电阻、每个电阻中的电流，以及电池输出的功率。
::: solution
把两个相等电阻代入[[#eq-parallel]]得 $1/R_{\mathrm{eq}} = 1/8.00 + 1/8.00 = 1/4.00$，所以 $R_{\mathrm{eq}} = 4.00\,\Omega$。电池随之供给

$$
I = \frac{12.0}{4.00} = 3.00\,\mathrm{A}.
$$

每个电阻两端都是完整的 $12.0\,\mathrm{V}$，故各通过 $12.0/8.00 = 1.50\,\mathrm{A}$。两条支路电流之和等于电池电流。一个电阻消耗的功率为 $(1.50)^2 \times 8.00 = 18.0\,\mathrm{W}$，两个共耗散 $36.0\,\mathrm{W}$。电池交付的功率为 $\mathcal{E} I = 12.0 \times 3.00 = 36.0\,\mathrm{W}$。两笔账相符。
:::
:::

::: intuition 增加阻碍，还是增加路径
串联让电荷依次通过每一个电阻，所以阻碍相加、电流相同。并联在同样的两个电势之间提供多条路径，所以电导 $1/R_k$ 相加、电势差相同。若从一个画出的网络分不清该用这两句话中的哪一句，就不要硬套：那个网络需要的是下一节的定律。
:::

混合网络从内部开始化简。把每一条纯串联链和每一组纯并联群各自归并成一个等效电阻，然后重复。顺序无关紧要；两个端子之间最终的 $R_{\mathrm{eq}}$ 是唯一的。

::: example 串联电阻馈电给并联对 {#ex-ladder}
$10.0\,\mathrm{V}$ 的理想电池接一个 $4.00\,\Omega$ 电阻，该电阻与"$6.00\,\Omega$ 和 $3.00\,\Omega$ 的并联组合"串联。求电池电流以及每个电阻中的电流。
::: solution
并联对有

$$
R_{\parallel} = \frac{6.00 \times 3.00}{6.00 + 3.00} = 2.00\,\Omega.
$$

与 $4.00\,\Omega$ 串联后整条链为 $R_{\mathrm{eq}} = 6.00\,\Omega$，所以电池电流为

$$
I = \frac{10.0}{6.00} = \frac{5}{3}\,\mathrm{A} = 1.67\,\mathrm{A}.
$$

并联对两端的电势差为 $I R_{\parallel} = (5/3)\times 2.00 = 3.33\,\mathrm{V}$。于是 $6.00\,\Omega$ 支路通过 $0.556\,\mathrm{A}$，$3.00\,\Omega$ 支路通过 $1.11\,\mathrm{A}$。支路电流之和等于电池电流，三个电阻的功率之和为 $\mathcal{E} I = 16.7\,\mathrm{W}$。 
:::
:::

当一个电阻横跨两个回路，既不属于纯串联链，也不属于纯并联群时，化简到此为止。电桥中的那条桥接跨线就是最常见的情形。电流依然存在，节点定律与回路定律能把它们求出来。

## 基尔霍夫定律

这两条定律适用于**集总**电路：网络的几何尺度远小于光在我们关心的任一时间间隔内走过的距离，忽略辐射，并且穿过回路的磁通要么恒定，要么被局限在我们尚未用到的元件之中。在这个模型里，静电势只是位置的函数，导线中的电流是一个数——沿整条支路处处相同。

::: definition 稳态与支路 {#def-steady}
当每个电流都不随时间变化、任何节点上都不积累电荷时，电路处于**稳态**。**支路**是连接两个节点的一条路径，其上电流取同一个值。**节点**（junction，汇接点）是三条或更多支路相交之点。**回路**是沿支行进的闭合路径。
:::

::: theorem 节点定律 {#thm-junction}
稳态下，任一节点处各电流的代数和为零。约定流入节点的电流为正、流出的为负，则

$$
\sum_k I_k = 0.
$$ {#eq-junction}
:::

::: proof
设 $Q(t)$ 为积在节点上的电荷。流出节点的电流就是这份电荷减少的速率，所以 $\mathrm{d}Q/\mathrm{d}t$ 等于流入电流的代数和。稳态下 $Q$ 恒定，这个和为零。同一陈述也就是对包围节点的一小块闭曲面积分的连续性方程：若曲面内 $\partial \rho/\partial t = 0$，则电流密度穿过曲面的通量为零。
:::

这些方程并不独立：从一个节点流出的每个电流都流进另一个节点，所以把所有节点方程相加得到 $0 = 0$。对 $N$ 个节点，最多只写 $N - 1$ 个节点方程。

::: theorem 回路定律 {#thm-loop}
稳态下，在没有变化磁通量的集总模型中，沿任何闭合回路各电势变化之和为零：

$$
\sum \Delta V = 0.
$$ {#eq-loop}
:::

::: proof
静电场是保守场，两点间的电势差与路径无关，从一点出发再回到该点的电势差为零。明确地写：若 $V$ 是静电势，则沿任何闭曲线 $C$

$$
\oint_C \mathbf{E}\cdot\dd\mathbf{l} = 0,
$$

这正是"沿 $C$ 的各电势降落之和为零"的表述。在集总模型中，这个和的每一项贡献都定域在一个电路元件上。理想导线不贡献。电阻贡献欧姆压降。电池贡献它的电动势——即电池内部非静电力对单位电荷做的功——在电势账目里记作一次跃变。把这些贡献相加便得[[#eq-loop]]。
:::

回路定律是说：沿闭合路径走一圈，回到同一个电势。对平面电路，网孔——内部不含其他回路的回路——构成一组独立方程：任何其他回路方程都是网孔方程之和。

符号必须在写出方程之前定好，然后保持不变。负的答案也是信息：它表示电流与所设的箭头反向。

::: proposition 回路的符号法则 {#prop-signs}
沿选定的方向绕行回路。经过电阻：若绕行方向与所设电流同向，电势变化为 $\Delta V = -IR$；若逆着电流，则 $\Delta V = +IR$。经过理想电池：若从负极走向正极，$\Delta V = +\mathcal{E}$；若从正极走向负极，$\Delta V = -\mathcal{E}$。
:::

::: proof
欧姆定律说，电阻中的电流从高电势流向低电势，差值大小为 $IR$。所以顺着电流走是下台阶，逆着电流走是上台阶。在理想电池内部，化学作用把正电荷从负极搬到正极时抬高它的电势，每库仑抬高 $\mathcal{E}$ 焦耳，无论是否有电流流过。回路定律记录的电势变化就是这一抬升，其符号由回路穿过电池的方向决定。上面两条都只是电势差的定义用在单个元件上；[[#thm-loop]]接着说这些带符号的变化相加为零。
:::

画出电路，用箭头标出每条支路的电流。写出 $N - 1$ 个节点方程，并用[[#prop-signs]]写出足够多的回路方程，使方程数与未知数相符。负的电流意味着电荷的实际流向与你画的箭头相反。检验解答的办法，是让电池提供的功率与电阻耗散的功率相平衡。

::: example 两个电池共用中间电阻 {#ex-twoloop}
三条支路连接上下两个节点。左支路是理想电池 $\mathcal{E}_1 = 12.0\,\mathrm{V}$（正极在上）与 $R_1 = 2.00\,\Omega$ 串联。中间支路只有 $R_2 = 8.00\,\Omega$。右支路是理想电池 $\mathcal{E}_2 = 6.00\,\mathrm{V}$（正极在上）与 $R_3 = 2.00\,\Omega$ 串联。求每条支路的电流，并检验功率。
::: solution
两个电池彼此对着：换作单独一个，它都会从自己位于上方的正极把电流推出去，向下流过中间电阻。设左支路电流 $I_1$ 向上，右支路电流 $I_2$ 向下，中间电流 $I_{\mathrm{m}}$ 向下。上节点处，由[[#thm-junction]]得

$$
I_1 = I_{\mathrm{m}} + I_2.
$$ {#eq-node-ex}

沿左回路顺时针绕行：沿左支路上行，再沿中间支路下行。[[#prop-signs]]给出电池贡献 $+\mathcal{E}_1$，左侧电阻贡献 $-I_1 R_1$，中间电阻贡献 $-I_{\mathrm{m}} R_2$：

$$
12.0 - 2.00\, I_1 - 8.00\, I_{\mathrm{m}} = 0.
$$ {#eq-left-ex}

沿右回路顺时针绕行：沿中间支路上行，再沿右支路下行。向上穿过中间支路是逆着 $I_{\mathrm{m}}$，所以中间电阻贡献 $+I_{\mathrm{m}} R_2$。沿右支路下行时顺着 $I_2$ 经过 $R_3$，并从正极到负极经过 $\mathcal{E}_2$：

$$
8.00\, I_{\mathrm{m}} - 2.00\, I_2 - 6.00 = 0.
$$ {#eq-right-ex}

把 $I_1 = I_{\mathrm{m}} + I_2$ 代入[[#eq-left-ex]]：

$$
12.0 - 2.00(I_{\mathrm{m}} + I_2) - 8.00\, I_{\mathrm{m}} = 0,
$$

即 $10.0\, I_{\mathrm{m}} + 2.00\, I_2 = 12.0$，或 $5.00\, I_{\mathrm{m}} + I_2 = 6.00$。右端方程为 $4.00\, I_{\mathrm{m}} - I_2 = 3.00$。把这两个化简后的方程相加可消去 $I_2$，得 $9.00\, I_{\mathrm{m}} = 9.00$，所以 $I_{\mathrm{m}} = 1.00\,\mathrm{A}$。于是 $I_2 = 6.00 - 5.00 \times 1.00 = 1.00\,\mathrm{A}$，$I_1 = 2.00\,\mathrm{A}$。

三个电流都是正的，说明每个箭头都画在了真实方向上。电流从 $12.0\,\mathrm{V}$ 电池的正极流出：该电池正在放电，其化学功率为 $\mathcal{E}_1 I_1 = 24.0\,\mathrm{W}$。电流流入 $6.00\,\mathrm{V}$ 电池的正极：该电池正在被充电，吸收 $\mathcal{E}_2 I_2 = 6.00\,\mathrm{W}$。电阻耗散的功率为

$$
I_1^2 R_1 + I_{\mathrm{m}}^2 R_2 + I_2^2 R_3 = (2.00)^2(2.00) + (1.00)^2(8.00) + (1.00)^2(2.00) = 18.0\,\mathrm{W}.
$$

放电电池输出的功率，等于充电电池吸收的功率加上电阻耗散的功率：$24.0 = 6.00 + 18.0$。若 $I_2$ 算出来是负的，右边的电池就也在放电，并且要先反画那条支路的箭头，再给功率定符号。
:::
:::

::: warning 回路定律与变化的磁通
[[#thm-loop]]用到的是保守电场。若穿过回路的磁通在变化，就会产生非保守电场，静电势变化之和就不再是全部情况。必须把[[magnetism/faraday]]的感应电动势加进回路方程。节点定律在这种推广下依然成立，因为它是电荷守恒，不关心电场是否保守。不要把本章陈述的回路定律用在磁通变化的回路上。
:::

同一条警告也界定了集总模型的实用边界。若电流变化快得让电路相对于一个波长不再显得小，或者电路里有一个线圈、其磁通不可忽略，电路就已经走出了[[#thm-loop]]的假设。电感在[[magnetism/inductance]]中处理，回路定律在那里的扩充形式下重新成立。

## 端电压与电功率

真实电池不是一处理想的电势跃变。它的电极与电解液都有电阻，而这部分电阻通过与外电路相同的电流。

::: definition 内阻与端电压 {#def-terminal}
真实电池建模为一个理想电动势 $\mathcal{E}$ 与一个**内阻** $r$ 串联。**端电压**是这一组合两个端子之间的电势差。当电池放电、电流 $I$ 从正极流出时，

$$
V_{\mathrm{t}} = \mathcal{E} - Ir.
$$ {#eq-terminal}
:::

$Ir$ 这一项是电池内部的欧姆压降，按[[#prop-signs]]写出。若电池正在被充电，电流流入正极，电池内部从负极走向正极的绕行方向逆着 $r$ 中的电流，端电压便是 $V_{\mathrm{t}} = \mathcal{E} + Ir$。放电时的端电压低于电动势；充电时的端电压高于电动势。开路时 $I = 0$，所以用电压表测量空载电池读出的是 $\mathcal{E}$，而不是带载时的 $V_{\mathrm{t}}$。

::: proposition 电池的功率平衡 {#prop-power}
电动势为 $\mathcal{E}$、内阻为 $r$ 的电池经外电路放电、电流 $I$ 从正极流出时，化学功率、内部发热与端子输出功率之间有关系

$$
\mathcal{E} I = I^2 r + I V_{\mathrm{t}}.
$$ {#eq-power-balance}

化学作用提供 $\mathcal{E} I$；其中 $I^2 r$ 加热电池内部，$I V_{\mathrm{t}}$ 交给外电路。
:::

::: proof
把[[#eq-terminal]]乘以正的放电电流 $I$。左边是 $I V_{\mathrm{t}}$，右边是 $\mathcal{E} I - I^2 r$。整理即得[[#eq-power-balance]]。每一项都是功率。$\mathcal{E} I$ 是非静电力对穿过电池的电荷单位时间做的功，因为每库仑电荷获得能量 $\mathcal{E}$。项 $I^2 r$ 是内阻中的欧姆发热，与电阻产生的那个 $I^2 R$ 相同。两者之差就是端子上剩下的部分。
:::

单回路电路中的外电阻 $R$ 因而满足 $V_{\mathrm{t}} = IR$ 且 $I = \mathcal{E}/(R + r)$。化学功率中到达负载的份额为 $R/(R + r)$，其余消耗在电池内部。

::: example 带内阻的电池 {#ex-battery}
电动势 $12.0\,\mathrm{V}$、内阻 $0.50\,\Omega$ 的电池接在 $5.50\,\Omega$ 的外电阻上。求电流、端电压，以及[[#prop-power]]功率平衡中的三个功率。
::: solution
两个电阻串联，所以

$$
I = \frac{12.0}{0.50 + 5.50} = \frac{12.0}{6.00} = 2.00\,\mathrm{A}.
$$

端电压为 $V_{\mathrm{t}} = 12.0 - (2.00)(0.50) = 11.0\,\mathrm{V}$，它也是 $I \times 5.50 = 11.0\,\mathrm{V}$。化学功率为 $\mathcal{E} I = 12.0 \times 2.00 = 24.0\,\mathrm{W}$。内阻耗散 $I^2 r = (2.00)^2(0.50) = 2.0\,\mathrm{W}$。外电阻耗散 $I^2 R = (2.00)^2(5.50) = 22.0\,\mathrm{W}$。于是 $24.0 = 2.0 + 22.0$，与[[#eq-power-balance]]一致。化学功率中到达负载的份额为 $22.0/24.0 = 11/12 = 0.917$。
:::
:::

取用功率最大的负载，并不是最有效地使用电池的负载。固定 $r$ 与 $\mathcal{E}$，让外电阻为变量 $R$。电流为 $I = \mathcal{E}/(R + r)$，外电路功率为

$$
P(R) = I^2 R = \mathcal{E}^2 \frac{R}{(R + r)^2}.
$$ {#eq-pr}

对 $R$ 求导。除去正因子 $\mathcal{E}^2$，$P'(R)$ 的分子为 $(R + r)^2 - R \cdot 2(R + r) = (R + r)(r - R)$。所以 $R < r$ 时 $P'(R)$ 为正，$R = r$ 时为零，$R > r$ 时为负。最大值在 $R = r$ 处取得，其值为

$$
P_{\max} = \frac{\mathcal{E}^2}{4r}.
$$ {#eq-pmax}

此时效率 $R/(R + r)$ 只有一半：负载与内部各消耗一半。对[[#ex-battery]]中的电池，$P_{\max} = (12.0)^2/(4 \times 0.50) = 72.0\,\mathrm{W}$，此时 $R = 0.50\,\Omega$。$5.50\,\Omega$ 的负载只取用 $22.0\,\mathrm{W}$，并且不必让内部以同样的速率发热。这种匹配电阻下的最大功率传输适合微弱信号，却不是驱动电池的好办法。

## 电容器的充电与放电

电容器与电阻、电池串联，一旦电容器上的电压升到电动势，就不再取用电流。有意思的是趋近这一状态的过程。此时电流不稳恒，所以[[#def-steady]]不适用于电容器的极板：电荷恰恰是要在那里积累。它确实适用于连接导线的一切普通节点。在单一串联回路中，导线电流只有一个值，而这个值等于正极板上电荷的变化率。

我们继续使用[[#thm-loop]]，也就是继续忽略变化的磁通。真实的充电脉冲确实会产生很小的磁场。集总 $RC$ 模型是这样一种近似：该脉冲感生的电场与电池和欧姆压降相比可以忽略。本章的警告划出的正是这一近似的边界。

::: definition 时间常数 {#def-tau}
电阻 $R$ 与电容 $C$ 串联组合的**时间常数**为

$$
\tau = RC.
$$ {#eq-tau}

其 SI 单位是秒：欧姆是伏特每安培，法拉是库仑每伏特，所以 $RC$ 的单位是 $\mathrm{C/A} = \mathrm{s}$。
:::

::: theorem 电容器的充电 {#thm-charge}
串联电路包含电动势为 $\mathcal{E}$ 的理想电池、电阻 $R$ 与初始不带电的电容器 $C$。正极板上的电荷与充电电流为

$$
Q(t) = C\mathcal{E}\left(1 - e^{-t/(RC)}\right), \qquad I(t) = \frac{\mathcal{E}}{R}\, e^{-t/(RC)},
$$ {#eq-charge}

其中 $t \ge 0$，电流取使 $Q$ 增大的方向。
:::

::: proof
从负极出发绕回路一周：经过电池，经过电阻，抵达正极板。由[[#prop-signs]]和电容关系 $V_C = Q/C$ 得

$$
\mathcal{E} - IR - \frac{Q}{C} = 0.
$$ {#eq-rc-loop}

在这个串联回路中，通过电阻的电流就是到达正极板的电流，所以 $I = \mathrm{d}Q/\mathrm{d}t$。把它代入[[#eq-rc-loop]]并整理：

$$
R\frac{\mathrm{d}Q}{\mathrm{d}t} = \mathcal{E} - \frac{Q}{C} = \frac{C\mathcal{E} - Q}{C},
$$

于是

$$
\frac{\mathrm{d}Q}{C\mathcal{E} - Q} = \frac{\mathrm{d}t}{RC}.
$$

从 $t = 0$ 时的电荷 $0$ 积分到 $t$ 时刻的电荷 $Q$。左边为 $-\ln(C\mathcal{E} - Q) + \ln(C\mathcal{E})$，所以

$$
\ln\frac{C\mathcal{E}}{C\mathcal{E} - Q} = \frac{t}{RC}.
$$

两边取指数并解出 $Q$：

$$
Q(t) = C\mathcal{E}\left(1 - e^{-t/(RC)}\right).
$$

利用 $I = \mathrm{d}Q/\mathrm{d}t$ 求导，即得[[#eq-charge]]中的电流。$t = 0$ 时电荷为零且 $I = \mathcal{E}/R$。当 $t \to \infty$，电荷趋于 $C\mathcal{E}$、电流趋于零；这正是把电容器一开始就当开路处理、由节点定律与回路定律本来就会给出的稳态。
:::

时间常数是假想电流保持初始值 $\mathcal{E}/R$ 不降时，电荷达到 $C\mathcal{E}$ 所需的时间。电流确实在下降，所以到 $t = \tau$，电荷只达到终值的份额 $1 - e^{-1}$，约 $0.632$。到目标差距的剩余份额始终是 $e^{-t/\tau}$，因此此后每经过一个长度为 $\tau$ 的时间段，差距就乘以 $1/e$。

::: corollary 电容器的放电 {#cor-discharge}
若撤去电池，让 $t = 0$ 时带电 $Q_0$ 的电容器只经电阻 $R$ 接成回路，则

$$
Q(t) = Q_0 e^{-t/(RC)}, \qquad I_{\mathrm{dis}}(t) = \frac{Q_0}{RC}\, e^{-t/(RC)},
$$ {#eq-discharge}

其中 $I_{\mathrm{dis}}$ 是从正极板流出的正电流。
:::

::: proof
电池不在时，若取 $I_{\mathrm{dis}}$ 沿使 $Q$ 减小的方向为正，[[#eq-rc-loop]]化为 $0 = I_{\mathrm{dis}} R - Q/C$。于是 $I_{\mathrm{dis}} = Q/(RC)$ 且 $\mathrm{d}Q/\mathrm{d}t = -Q/(RC)$。分离变量：$\mathrm{d}Q/Q = -\mathrm{d}t/(RC)$。从 $t = 0$ 时的 $Q_0$ 积分到 $t$ 时刻的 $Q$，得 $\ln(Q/Q_0) = -t/(RC)$，这就是[[#eq-discharge]]中的电荷。电流为 $Q/(RC)$。
:::

放电与充电电流只差一个常数因子，是同一个指数函数。电荷经过一个时间常数衰减到 $Q_0/e$，经过 $t_{1/2} = \tau \ln 2 \approx 0.693\,\tau$ 衰减到 $Q_0/2$。这两个时间都不依赖 $Q_0$。电容更大或电阻更大，都会使两个过程按比例变慢——这正是 $\tau = RC$ 所说的。

::: example 缓慢充电的一个时间常数 {#ex-rc}
电阻 $R = 2.00 \times 10^{5}\,\Omega$ 与电容 $C = 5.00\,\mu\mathrm{F}$ 串联，接在电动势 $10.0\,\mathrm{V}$ 的理想电池上。$t = 0$ 时电容器不带电。求时间常数、$t = 1.00\,\mathrm{s}$ 时的电荷与电流，以及足够长时间后储存的能量。
::: solution
时间常数为 $\tau = RC = (2.00 \times 10^{5})(5.00 \times 10^{-6}) = 1.00\,\mathrm{s}$。终态电荷为 $Q_{\mathrm{f}} = C\mathcal{E} = (5.00 \times 10^{-6})(10.0) = 5.00 \times 10^{-5}\,\mathrm{C} = 50.0\,\mu\mathrm{C}$。在 $t = \tau$ 时，

$$
\frac{Q}{Q_{\mathrm{f}}} = 1 - e^{-1} = 0.63212\ldots = 0.632
$$

保留三位有效数字，所以 $Q(1.00\,\mathrm{s}) = 0.632 \times 50.0\,\mu\mathrm{C} = 31.6\,\mu\mathrm{C}$。初始电流为 $\mathcal{E}/R = 10.0/(2.00 \times 10^{5}) = 5.00 \times 10^{-5}\,\mathrm{A} = 50.0\,\mu\mathrm{A}$。到 $t = \tau$，电流按因子 $e^{-1} = 0.36788\ldots$ 下降，所以 $I = 18.4\,\mu\mathrm{A}$。足够长时间后储存的能量为

$$
U_{\mathrm{f}} = \tfrac12 C\mathcal{E}^2 = \tfrac12 (5.00 \times 10^{-6})(10.0)^2 = 2.50 \times 10^{-4}\,\mathrm{J}.
$$

在 $t = \tau$ 时，能量是 $U_{\mathrm{f}}$ 的份额 $(1 - e^{-1})^2 = 0.3996$，即 $9.99 \times 10^{-5}\,\mathrm{J}$。电荷已经越过终值的一半，但能量对电荷是二次的，还不到终值的五分之二。
:::
:::

整个充电过程中，电池把总电荷 $Q_{\mathrm{f}} = C\mathcal{E}$ 推送过电势差 $\mathcal{E}$，因此提供能量 $C\mathcal{E}^2$。其中只有一半到达电容器，另一半加热电阻，而这个分配不依赖 $R$。较大的 $R$ 使充电更慢、电流更小，这两个变化在积分后的热量里正好相消。

::: proposition 充电过程中的能量分配 {#prop-energy}
在[[#thm-charge]]的电路中，电池从 $t = 0$ 到 $t = \infty$ 提供的能量为 $C\mathcal{E}^2$。其中一半储存在电容器上，一半耗散在电阻里。分配与 $R$ 无关。
:::

::: proof
把回路方程[[#eq-rc-loop]]乘以电流 $I$：

$$
\mathcal{E} I = I^2 R + \frac{Q}{C} I.
$$

左边是电池的瞬时功率。右边第一项是电阻的瞬时发热。第二项是输入电容器的功率，因为 $I = \mathrm{d}Q/\mathrm{d}t$，而电容器储存能量 $\tfrac12 Q^2/C$ 的导数正是 $(Q/C)\,\mathrm{d}Q/\mathrm{d}t$。从 $t = 0$ 积分到 $t = \infty$。电池贡献 $\mathcal{E}$ 乘以通过的总电荷，即 $\mathcal{E} \cdot C\mathcal{E} = C\mathcal{E}^2$。电容器贡献

$$
\int_0^{Q_{\mathrm{f}}} \frac{Q}{C}\,\mathrm{d}Q = \frac{Q_{\mathrm{f}}^2}{2C} = \tfrac12 C\mathcal{E}^2.
$$

电阻得到剩下的 $\tfrac12 C\mathcal{E}^2$。回路方程乘以 $I$、积分进行到底之后，$R$ 已被消去，所以这些总量不依赖 $R$。这一相消的前提是电荷最终确实达到 $C\mathcal{E}$，对每个有限的 $R > 0$ 它都会达到。
:::

放电时电池已经不在。能量 $\tfrac12 Q_0^2/C$ 离开电容器，按同样的回路方程乘电流的论证，它将全部耗散在电阻里。它没有第二个去处。

::: quiz
电容器经电阻由电池充电。合上开关很长时间后，电阻中的电流
- [ ] 为 $\mathcal{E}/R$，因为欧姆定律对电阻仍然适用
- [ ] 为 $\mathcal{E}/(2R)$，因为一半能量耗散在电阻中
- [x] 基本为零，因为电容器电压已升到电池电动势，回路定律没有给电阻留下压降
- [ ] 反向，因为充过电的电容器总是把电流倒着推回电池
::: solution
指数函数在衰减，所以[[#eq-charge]]使 $I(t)$ 随 $t$ 增大而趋于零。回路方程 $\mathcal{E} - IR - Q/C = 0$ 只有在 $I = 0$ 时才能达到 $Q = C\mathcal{E}$。欧姆定律仍然联系着电流与电阻两端的压降；是那个压降本身消失了。[[#prop-energy]]里的那个二分之一说的是积分后的能量，不是稳恒电流。经单一电阻充电时电流不会反向：$I(t)$ 保持非负。
:::
:::

::: intuition 剩下的多少决定变化的快慢
充电时，电流正比于尚待填满的差距 $C\mathcal{E} - Q$；放电时，电流正比于尚存的电荷。两种情形说的都是：变化率正比于到平衡位置的距离，比例常数为 $1/\tau$。指数函数恰是具有这一性质的函数。于是对 $t/\tau$ 作图的曲线是通用的：每个串联 $RC$ 电路都是同一条曲线，只是读在一个以自己的时间常数为单位、走时不同的钟上。
:::

## 后续内容

电感会给回路定律添上一项电势差 $L\,\mathrm{d}I/\mathrm{d}t$。节点定律照旧，电路进入[[magnetism/inductance]]的 $RL$ 与 $LC$ 暂态。在振荡电源的驱动下，同样这两条定律就是[[magnetism/ac-circuits]]的电路定律，只不过现在用在幅度与相位上，而不是用在常数上。穿过回路的磁通一旦随时间变化，本章写下的[[#thm-loop]]就不再完整，缺的那一项正是[[magnetism/faraday]]的感应电动势。

::: history 基尔霍夫的两条定律
古斯塔夫·基尔霍夫（Gustav Kirchhoff）1845 年还是柯尼斯堡大学的学生时发表了节点定律与回路定律，把欧姆定律从单根导体推广到网络。节点定律是节点处的电荷守恒；回路定律是静电势单值这一事实。直到今天，两者仍是分析直流电路的组织方法。本章警告记录的那条限制——变化的磁通会添入非保守电场——并不属于 1845 年的那个理论；它属于法拉第的电磁感应。
:::

::: summary
- 串联链的等效电阻是各电阻之和；并联电阻按倒数相加。
- 由纯串联与纯并联组构成的混合网络可以从内向外化简；电桥的桥接跨线不能，需要节点定律与回路定律。
- 稳态下节点处电流的代数和为零，其中有一个节点方程是多余的。
- 沿闭合回路，只要电场是保守场，电势变化的带符号总和为零。顺着电流经过电阻，$\Delta V = -IR$；从负极到正极经过理想电池，$\Delta V = +\mathcal{E}$。
- 解出负电流意味着电流与所设箭头反向。功率平衡是检验。
- 放电电池的端电压为 $\mathcal{E} - Ir$。化学功率 $\mathcal{E} I$ 分成内部发热 $I^2 r$ 与送到外部的功率 $IV_{\mathrm{t}}$。$R = r$ 时输出功率最大，此时效率只有一半。
- 串联 $RC$ 电路按 $Q = C\mathcal{E}(1 - e^{-t/\tau})$ 充电、按 $Q = Q_0 e^{-t/\tau}$ 放电，$\tau = RC$。电池提供的能量一半储存、一半耗散，与 $R$ 无关。
:::

## 习题

::: exercise 一条串联链 {#exr-series level=1 check="1"}
三个 $4.00\,\Omega$、$5.00\,\Omega$、$6.00\,\Omega$ 的电阻串联，接在 $15.0\,\mathrm{V}$ 的理想电池上。求链中的电流，以安培为单位。
::: solution
由[[#thm-series]]，$R_{\mathrm{eq}} = 4.00 + 5.00 + 6.00 = 15.0\,\Omega$。电流为 $I = 15.0/15.0 = 1.00\,\mathrm{A}$。三个电阻两端的电势差分别为 $4.00\,\mathrm{V}$、$5.00\,\mathrm{V}$、$6.00\,\mathrm{V}$，功率分别为 $4.00\,\mathrm{W}$、$5.00\,\mathrm{W}$、$6.00\,\mathrm{W}$，相加等于电池的功率 $15.0\,\mathrm{W}$。
:::
:::

::: exercise 三个电阻并联 {#exr-parallel level=1 check="2"}
三个 $4.00\,\Omega$、$6.00\,\Omega$、$12.0\,\Omega$ 的电阻并联。求等效电阻，以欧姆为单位。
::: solution
由[[#eq-parallel]]得

$$
\frac{1}{R_{\mathrm{eq}}} = \frac{1}{4.00} + \frac{1}{6.00} + \frac{1}{12.0} = 0.250 + 0.1667 + 0.0833 = 0.500\,\Omega^{-1}.
$$

于是 $R_{\mathrm{eq}} = 2.00\,\Omega$。$4.00\,\Omega$ 是三者中最小的，它的电导恰为 $0.500\,\Omega^{-1}$ 的一半，所以无论组合取用多大的总电流，它都分走其中的一半。
:::
:::

::: exercise 带载时的端电压 {#exr-terminal level=1 check="14"}
电动势 $18.0\,\mathrm{V}$、内阻 $2.00\,\Omega$ 的电池接在 $7.00\,\Omega$ 的外电阻上。求端电压，以伏特为单位。
::: solution
电流为 $I = 18.0/(2.00 + 7.00) = 18.0/9.00 = 2.00\,\mathrm{A}$。由[[#eq-terminal]]得 $V_{\mathrm{t}} = 18.0 - (2.00)(2.00) = 14.0\,\mathrm{V}$。同一个数也是 $I \times 7.00 = 14.0\,\mathrm{V}$。化学功率为 $36.0\,\mathrm{W}$，内部耗散 $8.00\,\mathrm{W}$，负载得到 $28.0\,\mathrm{W}$。
:::
:::

::: exercise 串联电阻中的功率 {#exr-split level=2 check="24"}
$24.0\,\mathrm{V}$ 的理想电池接在一个 $6.00\,\Omega$ 电阻上，该电阻与"两个 $12.0\,\Omega$ 电阻的并联对"串联。求 $6.00\,\Omega$ 电阻耗散的功率，以瓦特为单位。
::: solution
并联对有 $R_{\parallel} = 12.0/2 = 6.00\,\Omega$。与另一个 $6.00\,\Omega$ 串联后总电阻为 $12.0\,\Omega$，所以电池电流为 $I = 24.0/12.0 = 2.00\,\mathrm{A}$。这整个电流都通过串联电阻，它耗散 $I^2 R = (2.00)^2(6.00) = 24.0\,\mathrm{W}$。每个并联电阻两端为 $I R_{\parallel} = 12.0\,\mathrm{V}$，通过 $1.00\,\mathrm{A}$，各耗散 $12.0\,\mathrm{W}$。三个功率之和为 $48.0\,\mathrm{W}$，等于 $\mathcal{E} I$。
:::
:::

::: exercise 又一个双回路电路 {#exr-twoloop level=2 check="1"}
三条支路连接上下两个节点。左支路是理想电池 $10.0\,\mathrm{V}$（正极在上）与 $2.00\,\Omega$ 串联。中间支路是 $6.00\,\Omega$。右支路是理想电池 $4.00\,\mathrm{V}$（正极在上）与 $2.00\,\Omega$ 串联。取左支路电流向上、右支路电流向下、中间电流向下。求中间电流，以安培为单位。
::: hint
先写出上节点的方程，再用[[#prop-signs]]对每个网孔各写一条顺时针方程。代入节点方程之后，把两条回路方程相加，就能消去一个未知量。
:::
::: solution
设左支路电流 $I_1$ 向上，右支路电流 $I_2$ 向下，中间电流 $I_{\mathrm{m}}$ 向下。节点方程为 $I_1 = I_{\mathrm{m}} + I_2$。左回路顺时针得 $10.0 - 2.00\, I_1 - 6.00\, I_{\mathrm{m}} = 0$。右回路顺时针得 $6.00\, I_{\mathrm{m}} - 2.00\, I_2 - 4.00 = 0$。把节点方程代入左端方程：$10.0 - 2.00(I_{\mathrm{m}} + I_2) - 6.00\, I_{\mathrm{m}} = 0$，即 $8.00\, I_{\mathrm{m}} + 2.00\, I_2 = 10.0$。右端方程为 $6.00\, I_{\mathrm{m}} - 2.00\, I_2 = 4.00$。两式相加：$14.0\, I_{\mathrm{m}} = 14.0$，所以 $I_{\mathrm{m}} = 1.00\,\mathrm{A}$。于是 $6.00 - 2.00\, I_2 = 4.00$，得 $I_2 = 1.00\,\mathrm{A}$，$I_1 = 2.00\,\mathrm{A}$。

$10.0\,\mathrm{V}$ 电池放电，提供 $20.0\,\mathrm{W}$。$4.00\,\mathrm{V}$ 电池被充电，吸收 $4.00\,\mathrm{W}$。电阻耗散 $(2.00)^2(2.00) + (1.00)^2(6.00) + (1.00)^2(2.00) = 16.0\,\mathrm{W}$。于是 $20.0 = 4.00 + 16.0$。
:::
:::

::: exercise 电容器作为开路 {#exr-open level=2 check="8"}
$12.0\,\mathrm{V}$ 的理想电池接在一个 $3.00\,\Omega$ 电阻上，该电阻与"$6.00\,\Omega$ 电阻和电容器的并联组合"串联。电路已合上很长时间。求电容器两端的电势差，以伏特为单位。
::: solution
很长时间后充电电流已经消失。把[[#thm-charge]]的结论推广到这个网络：电容器支路不载稳恒电流，电容器表现为开路。电池、$3.00\,\Omega$ 电阻与 $6.00\,\Omega$ 电阻构成单一串联回路，电流为 $12.0/(3.00 + 6.00) = 1.333\ldots\,\mathrm{A}$。$6.00\,\Omega$ 电阻两端的电势差为 $(12.0/9.00) \times 6.00 = 8.00\,\mathrm{V}$。电容器与该电阻并联，所以它两端的电势差是 $8.00\,\mathrm{V}$，不是电池的全部电动势。其余 $4.00\,\mathrm{V}$ 落在 $3.00\,\Omega$ 电阻上。
:::
:::

::: exercise 充电能量去了哪里 {#exr-energy level=3}
含电动势 $\mathcal{E}$ 理想电池的串联 $RC$ 电路从 $Q = 0$ 充电到 $Q = C\mathcal{E}$。证明电阻耗散的能量等于电容器储存的能量，并且两者都不依赖 $R$。
::: hint
从回路方程 $\mathcal{E} - IR - Q/C = 0$ 出发，两边乘以 $I$，再从充电开始积分到充电完成。使用 $I\,\mathrm{d}t = \mathrm{d}Q$。
:::
::: solution
回路定律给出每一时刻 $\mathcal{E} = IR + Q/C$，其中 $I = \mathrm{d}Q/\mathrm{d}t$。两边乘以 $I$：

$$
\mathcal{E} I = I^2 R + \frac{Q}{C}\frac{\mathrm{d}Q}{\mathrm{d}t}.
$$

对时间从 $0$ 积分到 $\infty$。左边是 $\mathcal{E}$ 乘以输送的总电荷，$\mathcal{E} \cdot C\mathcal{E} = C\mathcal{E}^2$。右边第二项为

$$
\int_0^{C\mathcal{E}} \frac{Q}{C}\,\mathrm{d}Q = \tfrac12 C\mathcal{E}^2,
$$

这就是电容器储存的能量。于是 $I^2 R$ 的积分是两者的差，$\tfrac12 C\mathcal{E}^2$。两个总量里都不出现 $R$ 的数值。$R$ 影响过程持续多久、每一时刻电流多大，但积完之后的总量只由初末状态决定。上限确实是 $t = \infty$、$Q = C\mathcal{E}$ 这一假设，用到了 $R$ 有限且为正，从而[[#eq-charge]]中的指数确实完成衰减。
:::
:::

::: exercise 取用功率最大的负载 {#exr-pmax level=3 check="72"}
电池电动势为 $\mathcal{E}$、内阻为 $r$，驱动单一外电阻 $R$。证明 $R$ 中的功率在 $R = r$ 时最大，并求 $\mathcal{E} = 12.0\,\mathrm{V}$、$r = 0.50\,\Omega$ 时的最大功率，以瓦特为单位。
::: hint
写出 $P(R) = \mathcal{E}^2 R/(R + r)^2$ 并求导。$P'(R)$ 在 $R = r$ 两侧的符号决定驻点是否为最大值。
:::
::: solution
电流为 $I = \mathcal{E}/(R + r)$，所以外电路功率为 $P(R) = \mathcal{E}^2 R/(R + r)^2$，即[[#eq-pr]]。按商法则求导。除去正因子 $\mathcal{E}^2$，导数的分子为 $(R + r)^2 - 2R(R + r) = (R + r)(r - R)$，分母为正。因此 $R < r$ 时 $P'(R) > 0$，$R = r$ 时 $P'(R) = 0$，$R > r$ 时 $P'(R) < 0$。驻点是最大值。代入 $R = r$ 得 $P_{\max} = \mathcal{E}^2/(4r)$。对题给电池，

$$
P_{\max} = \frac{(12.0)^2}{4 \times 0.50} = \frac{144}{2.00} = 72.0\,\mathrm{W}.
$$

在该负载下电流为 $\mathcal{E}/(2r) = 12.0\,\mathrm{A}$，内部发热 $I^2 r$ 也是 $72.0\,\mathrm{W}$。化学功率的一半留在了电池内部。
:::
:::
