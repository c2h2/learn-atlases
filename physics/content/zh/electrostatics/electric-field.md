[[electrostatics/coulomb]] 中的库仑定律给出两个点电荷之间的力，并把它们捆在一起。把你观察的那个电荷加倍，力就加倍，不管源在做什么。把那个电荷分离出来、只留一个刻画源的向量是大有用处的。这个向量就是**电场**。一旦知道了某一点的电场，放在那里的电荷 $q$ 受到的力就是 $q$ 乘以场，不必再过问源是怎样拼起来的。

这个拆分不是一条新的力律。它是 [[electrostatics/coulomb#thm-coulomb]] 的重新排列：你去计算的对象变成了源，受力的电荷稍后再补上。同一个重新排列把力的叠加变成场的叠加，把对分布的积分变成一个向量的积分。电场线是这个向量的一幅图像，不是积分的替身。匀强电场中的运动随后就是 [[mechanics/motion-1d]] 里普通的匀加速运动学。

## 点电荷的电场

试探电荷是你放在某一点上用来感受力的电荷。它是一个探针，不属于产生力的那套装置。

::: definition 电场 {#def-field}
某一点的**电场** $\mathbf{E}$ 是试探电荷 $q_0$ 在该点将受到的静电力 $\mathbf{F}$ 除以 $q_0$：

$$
\mathbf{E} = \frac{\mathbf{F}}{q_0}.
$$ {#eq-def-E}

$\mathbf{E}$ 的方向是*正*试探电荷受力的方向。SI 单位是牛顿每库仑，$\mathrm{N/C}$。若源固定不动，$\mathbf{F}$ 正比于 $q_0$，这个商不依赖你选了哪个试探电荷。若源可以被重新安排——导体中的自由电荷就可以——那么 $q_0$ 必须足够小，小到挪不动它们。理想的说法是让 $q_0 \to 0$，但取的值仍然是许多个元电荷。
:::

单位 $\mathrm{N/C}$ 也叫伏特每米。伏特要用 [[electrostatics/potential]] 里的电势来定义，两个名字是同一种单位。本章一律使用 $\mathrm{N/C}$。

对固定的点源不需要这个极限，因为 [[electrostatics/coulomb#ax-superposition]] 已经保证力严格正比于 $q_0$。这个极限的价值体现在导体上：一个太肥的试探电荷会把你正要测量的那个分布本身挪走。下面各题的源都是固定的，所以任何顺手的 $q_0$ 都给出同一个 $\mathbf{E}$。

::: theorem 点电荷的电场 {#thm-point}
真空中静止的点电荷 $q$，在它自身以外位移 $\mathbf{r}$ 处（$r = \abs{\mathbf{r}} > 0$）产生的电场是

$$
\mathbf{E} = \frac{1}{4\pi\varepsilon_0}\,\frac{q}{r^{2}}\,\hat{\mathbf{r}},
$$ {#eq-point}

其中 $\hat{\mathbf{r}} = \mathbf{r}/r$ 由源电荷指向场点。$q > 0$ 时电场背离 $q$，$q < 0$ 时指向 $q$。取 $k = 1/(4\pi\varepsilon_0) = 8.9875517923\times 10^{9}\,\mathrm{N\cdot m^{2}/C^{2}}$，大小为 $k\abs{q}/r^{2}$。
:::

::: proof
在场点放一个试探电荷 $q_0$。[[electrostatics/coulomb#thm-coulomb]] 说它受到的力是

$$
\mathbf{F} = \frac{1}{4\pi\varepsilon_0}\,\frac{q q_0}{r^{2}}\,\hat{\mathbf{r}},
$$

其中 $\hat{\mathbf{r}}$ 由源指向试探电荷，也就是指向场点。除以 $q_0$。只要 $q_0 \neq 0$，试探电荷就约掉，所得的商就是 [[#eq-point]]。$\mathbf{E}$ 与 $\hat{\mathbf{r}}$ 同向还是反向，只由 $q$ 的符号决定。常量 $k$ 与 [[electrostatics/coulomb#eq-k]] 中的是同一个常量，同样的话也适用：$k$ 与 $\varepsilon_0 = 8.854187817\times 10^{-12}\,\mathrm{C^{2}/(N\cdot m^{2})}$ 所给的数字在 $10^{10}$ 分之一量级的几倍内一致，数值计算使用 $k$。
:::

::: example 纳库仑电荷外半厘米处的电场 {#ex-nanoc}
求点电荷 $-3.00\,\mathrm{nC}$ 外 $5.00\,\mathrm{cm}$ 处的电场。
::: solution
大小为

$$
E = \frac{k\,\abs{q}}{r^{2}} = \frac{(8.9875517923\times 10^{9})\,(3.00\times 10^{-9})}{(0.0500)^{2}} = 1.0785\times 10^{4}\,\mathrm{N/C}.
$$

保留四位有效数字，$E = 1.079\times 10^{4}\,\mathrm{N/C}$。源是负的，所以 $\mathbf{E}$ 指向它。正试探电荷会被吸引；负试探电荷会被排斥，方向与 $\mathbf{E}$ 相反，受力大小为 $\abs{q_0} E$。
:::
:::

::: quiz
源固定不动，用试探电荷测量某固定点的 $\mathbf{E}$，然后把试探电荷加倍。会发生什么？
- [ ] $\mathbf{E}$ 加倍，力保持不变
- [ ] $\mathbf{E}$ 反向，因为试探电荷变了
- [x] 力加倍，$\mathbf{E}$ 不变
- [ ] 力和 $\mathbf{E}$ 都不变，因为源是固定的
::: solution
[[#eq-def-E]] 把力除以 $q_0$。源固定时力正比于 $q_0$，所以商 $\mathbf{E}$ 是源与该点的性质。$q_0$ 加倍使 $\mathbf{F}$ 加倍，而 $\mathbf{E}$ 纹丝不动。第三个选项只有当“力”不是测量的一部分时才成立。它就是。
:::
:::

## 叠加原理

力按 [[electrostatics/coulomb#ax-superposition]] 相加。场是单位试探电荷的力，所以也以同样的方式相加。

::: proposition 场的叠加 {#prop-super-E}
一簇固定点电荷的电场，是每个电荷单独产生的电场的向量之和。在与任何源都不重合的一点，

$$
\mathbf{E} = \frac{1}{4\pi\varepsilon_0}\sum_i \frac{q_i}{r_i^{2}}\,\hat{\mathbf{r}}_i,
$$ {#eq-super-E}

其中 $\mathbf{r}_i$ 由电荷 $i$ 指向场点。
:::

::: proof
场点处试探电荷 $q_0$ 受到的力是各库仑力之和。把这个和除以 $q_0$。除以非零标量可以进有限和的内部，每一项变成一个源产生的电场。同一个恒等式就是把 [[#eq-def-E]] 用于合力。坐在场点上的源被排除在外，因为 [[#eq-point]] 在 $r = 0$ 处没有定义：点电荷模型在那里已经失效。
:::

这些算术就是 [[electrostatics/coulomb#alg-super]] 的算术，只有一处读法不同。你现在分解的不再是某个具名第三电荷上的力，而是 $\mathbf{E}$；之后再想要力，最后乘一个 $q$ 就行。试探电荷上合力的零点就是 $\mathbf{E}$ 的零点，所以 [[electrostatics/coulomb#prop-null]] 里那个位置是场的一个零点——它不依赖试探电荷，理由与那条公式里不含 $q$ 相同。

::: example 两个等量电荷，在中垂线上 {#ex-bisector}
$(0,\, 0)$ 与 $(0.600\,\mathrm{m},\, 0)$ 处各放 $+5.00\,\mathrm{nC}$。求 $(0.300\,\mathrm{m},\, 0.400\,\mathrm{m})$ 处的 $\mathbf{E}$。
::: solution
场点与两个电荷都是 $0.500\,\mathrm{m}$，又一个 $3$-$4$-$5$ 三角形。每个源都是正的，所以每个场都背离自己的源。任一贡献的大小是

$$
E_1 = \frac{k\,(5.00\times 10^{-9})}{(0.500)^{2}} = 179.75\,\mathrm{N/C}.
$$

从原点到场点的单位向量是 $(0.600,\, 0.800)$。从 $(0.600\,\mathrm{m},\, 0)$ 到场点的单位向量是 $(-0.600,\, 0.800)$。逐分量相加，

$$
\begin{aligned}
E_x &= 179.75\times 0.600 + 179.75\times(-0.600) = 0, \\
E_y &= 179.75\times 0.800 + 179.75\times 0.800 = 287.60\,\mathrm{N/C}.
\end{aligned}
$$

水平分量由对称性抵消，也必须如此：该点位于两个等量电荷的中垂线上。电场是 $287.6\,\mathrm{N/C}$，竖直向上。保留四位，单个电荷的大小是 $179.8\,\mathrm{N/C}$，和是 $287.6\,\mathrm{N/C}$。在那儿放一个正试探电荷，它会被推向 $+y$ 方向；力是 $q E_y$，不是从头再来一次库仑定律。
:::
:::

::: intuition 箭头是干什么用的
在某一点画的箭头就是该点的 $\mathbf{E}$，是这个位置本身的性质。它不是力，除非你乘上放在那里的电荷；它也不是从某个电荷指向另一个电荷，除非源恰好是一个点电荷。叠加原理会把箭头从每一条连线上扳开。
:::

## 连续分布

带电细棒不是点，也不是有限多个点。叠加原理以积分的形式存活下来。

::: definition 电荷密度 {#def-density}
当电荷分布在一条曲线、一片表面或一个体积上时，**线**、**面**、**体**电荷密度是

$$
\lambda = \deriv{q}{\ell}, \qquad \sigma = \deriv{q}{A}, \qquad \rho = \deriv{q}{V},
$$

于是 $\mathrm{d}q = \lambda\,\mathrm{d}\ell = \sigma\,\mathrm{d}A = \rho\,\mathrm{d}V$。均匀密度是常数，等于总电荷除以长度、面积或体积。密度可以为正，也可以为负。
:::

连续分布在其电荷以外的点产生的电场，是 [[#eq-point]] 的积分：

$$
\mathbf{E} = \frac{1}{4\pi\varepsilon_0}\int \frac{\mathrm{d}q}{r^{2}}\,\hat{\mathbf{r}},
$$ {#eq-integral}

其中 $r$ 与 $\hat{\mathbf{r}}$ 从电荷元 $\mathrm{d}q$ 取到场点。这个积分是向量积分。往往还没动手求原函数，就有一个分量已由对称性消失，那个相消才是最值得先看清的部分。

::: theorem 带电圆环轴线上的电场 {#thm-ring}
半径 $R > 0$ 的圆环，总电荷 $Q$ 均匀分布在环周上。在圆环的轴线上、距中心 $z$ 处，

$$
E_z = \frac{1}{4\pi\varepsilon_0}\,\frac{Q z}{(R^{2} + z^{2})^{3/2}},
$$ {#eq-ring}

而垂直于轴线的场分量为零。$Q > 0$、$z > 0$ 时，$E_z$ 沿轴线背离中心。
:::

::: proof
每个电荷元 $\mathrm{d}q$ 到场点的距离都是 $s = \sqrt{R^{2} + z^{2}}$。它的贡献大小为 $\mathrm{d}E = k\,\mathrm{d}q/s^{2}$。把 $\mathrm{d}\mathbf{E}$ 分解成沿轴线的分量与在环面内的分量。环面垂直于轴线，而圆环在绕轴线的转动下不变，所以横向分量成对抵消：每个电荷元都有一个对面的电荷元，其横向场正好反向。只有轴向分量存活。

从电荷元到场点的连线与轴线的夹角 $\alpha$ 满足 $\cos\alpha = z/s$。因此

$$
\mathrm{d}E_z = \mathrm{d}E\cos\alpha = \frac{1}{4\pi\varepsilon_0}\,\frac{\mathrm{d}q\, z}{s^{3}}.
$$

因子 $z/s^{3}$ 对每个电荷元都相同。对 $\mathrm{d}q$ 沿整个环积分，就是把它换成 $Q$，得到 [[#eq-ring]]。若 $z > 0$ 且 $Q > 0$，则 $E_z > 0$：电场背离环心。在 $z = 0$ 处，即环面中心的平面上，公式给出零，那正是横向抵消之后轴向一无所剩。
:::

$\abs{z}$ 很大时圆环看起来像一个点。对 $\abs{z} \gg R$ 展开 [[#eq-ring]] 得 $E_z \approx k Q/z^{2}$，因为 $(R^{2} + z^{2})^{3/2} \approx \abs{z}^{3}$，剩下的 $z/\abs{z}^{3}$ 就是带上 $z$ 的符号的 $1/z^{2}$。靠近圆环时，点电荷公式高估了场：电荷在轴线之外，只有轴向投影算数。

::: example 半径高度的圆环轴上 {#ex-ring}
半径 $R = 0.100\,\mathrm{m}$ 的圆环带 $Q = +5.00\,\mathrm{nC}$。求轴线上 $z = 0.100\,\mathrm{m}$ 处的 $E_z$，并与同一点处点电荷 $Q$ 的电场比较。
::: solution
这里 $R = z$，所以 $R^{2} + z^{2} = 2R^{2}$，

$$
E_z = \frac{k Q R}{(2R^{2})^{3/2}} = \frac{k Q}{2\sqrt{2}\, R^{2}} = \frac{k\,(5.00\times 10^{-9})}{2\sqrt{2}\,(0.0100)} = 1.5888\times 10^{3}\,\mathrm{N/C}.
$$

保留四位是 $1.589\times 10^{3}\,\mathrm{N/C}$，方向背离中心。同样距离处的点电荷 $Q$ 会产生

$$
\frac{k Q}{z^{2}} = 4.4938\times 10^{3}\,\mathrm{N/C}.
$$

比值是 $1/(2\sqrt{2}) = \sqrt{2}/4 = 0.3536$。大约三分之一的点电荷场存活下来，这就是 $\cos\alpha$ 在这一几何下的取值，再加上 $s$ 是 $\sqrt{2}$ 倍的 $z$ 而不是 $z$。对这个尺寸的圆环轴线使用 $kQ/z^{2}$，不是小修正，而是用错了模型。
:::
:::

直棒是另一个基本积分。中垂线是对称性替你做完一半工作的直线。

::: theorem 均匀带电直棒的电场（中垂线上） {#thm-rod}
长 $L > 0$ 的直棒均匀带电 $Q$，即 $\lambda = Q/L$。在中垂线上、距中心 $x > 0$ 处，

$$
E = \frac{1}{4\pi\varepsilon_0}\,\frac{Q}{x\sqrt{x^{2} + (L/2)^{2}}},
$$ {#eq-rod}

$Q > 0$ 时方向背离直棒，$Q < 0$ 时指向直棒。平行于棒的分量为零。
:::

::: proof
把棒放在 $z$ 轴上，从 $-L/2$ 到 $L/2$，场点取 $(x, 0)$，在垂直于棒的平面内，$x > 0$。坐标 $z$ 处的电荷元 $\lambda\,\mathrm{d}z$ 距离 $r = \sqrt{x^{2} + z^{2}}$。它的场有一个沿棒的分量和一个沿中垂线的分量。$+z$ 与 $-z$ 处沿棒的分量等大反向，所以这个分量对对称棒积分是零。

$\mathrm{d}\mathbf{E}$ 的中垂线分量是 $\mathrm{d}E$ 乘 $x/r$：

$$
\mathrm{d}E_x = \frac{1}{4\pi\varepsilon_0}\,\frac{\lambda\,\mathrm{d}z}{r^{2}}\cdot\frac{x}{r} = \frac{1}{4\pi\varepsilon_0}\,\lambda x\,(x^{2} + z^{2})^{-3/2}\,\mathrm{d}z.
$$

原函数由 $z = x\tan\theta$ 得出，于是 $\mathrm{d}z = x\sec^{2}\theta\,\mathrm{d}\theta$，$x^{2} + z^{2} = x^{2}\sec^{2}\theta$。被积函数塌缩成 $\cos\theta\,\mathrm{d}\theta/x^{2}$，积分是 $\sin\theta/x^{2}$。由于 $\sin\theta = z/r$，

$$
\int (x^{2} + z^{2})^{-3/2}\,\mathrm{d}z = \frac{z}{x^{2}\sqrt{x^{2} + z^{2}}}.
$$

从 $-L/2$ 到 $L/2$ 求值，两端贡献相同：

$$
\int_{-L/2}^{L/2} (x^{2} + z^{2})^{-3/2}\,\mathrm{d}z = \frac{L}{x^{2}\sqrt{x^{2} + (L/2)^{2}}}.
$$

乘上 $k\lambda x$。$x$ 约掉一次，而 $\lambda L = Q$，就是 [[#eq-rod]]。
:::

有两个极限值得走一遍，因为它们是对公式的检验。若 $x \gg L$，根式近似为 $x$，$E \approx k Q/x^{2}$：远处直棒看起来像一个点，正如圆环那样。反之若在固定 $\lambda$ 下把棒变得很长，使 $L/2 \gg x$，则 $\sqrt{x^{2} + (L/2)^{2}} \approx L/2$，于是

$$
E \approx \frac{1}{4\pi\varepsilon_0}\,\frac{\lambda L}{x\cdot(L/2)} = \frac{1}{4\pi\varepsilon_0}\,\frac{2\lambda}{x} = \frac{\lambda}{2\pi\varepsilon_0 x}.
$$

::: corollary 无限长直线的电场 {#cor-line}
均匀带电线密度 $\lambda$ 的无限长直线产生的电场，大小为

$$
E = \frac{\lambda}{2\pi\varepsilon_0 r} = \frac{2k\lambda}{r},
$$ {#eq-line}

其中 $r$ 是到直线的垂直距离。电场在垂直于直线的平面内沿径向，$\lambda > 0$ 时向外。它不依赖沿直线的任何坐标。
:::

::: proof
刚取的那个极限就是 [[#eq-line]]，只是把垂直距离 $x$ 写成了 $r$。两个式子一致，因为 $k = 1/(4\pi\varepsilon_0)$，所以 $2k\lambda/r = \lambda/(2\pi\varepsilon_0 r)$。无限长直线没有端点也没有中心，所以场不可能偏爱沿直线的某个方向，而且只能依赖垂直距离。[[electrostatics/gauss-law]] 由那个对称性直接得到同样结果，不必对有限棒取极限。上面的积分是这个结果成立的原因；高斯定律是它如此简短的原因。
:::

::: example 半米长的棒 {#ex-rod}
长 $L = 0.500\,\mathrm{m}$ 的棒均匀带 $Q = +10.0\,\mathrm{nC}$。求中垂线上 $x = 0.200\,\mathrm{m}$ 处的电场。把它与同一点处同样 $Q$ 的点电荷电场比较，再与同样 $\lambda$ 的无限长直线电场比较。
::: solution
[[#eq-rod]] 给出

$$
E = \frac{k\,(1.00\times 10^{-8})}{0.200\,\sqrt{0.200^{2} + 0.250^{2}}} = \frac{k\,(1.00\times 10^{-8})}{0.200\,\sqrt{0.1025}} = 1.4036\times 10^{3}\,\mathrm{N/C},
$$

保留四位是 $1.404\times 10^{3}\,\mathrm{N/C}$，方向背离直棒。与点电荷的对比是 $k Q/x^{2} = 2.2469\times 10^{3}\,\mathrm{N/C}$。棒的电场是那个点电荷场的分数

$$
\frac{x}{\sqrt{x^{2} + (L/2)^{2}}} = \frac{0.200}{\sqrt{0.1025}} = \frac{4}{\sqrt{41}} = 0.6247
$$

倍。电荷铺在棒上，所以一部分电荷离现场点比 $x$ 更远，而且平行分量已经抵消。

线密度是 $\lambda = Q/L = 2.00\times 10^{-8}\,\mathrm{C/m}$。[[#eq-line]] 在 $r = 0.200\,\mathrm{m}$ 处给出 $2k\lambda/r = 1.7975\times 10^{3}\,\mathrm{N/C}$，比有限长棒大，因为无限长直线在远处还有更多电荷，而且它们全都贡献一份向外的场。有限长棒落在点与无限长直线之间：$1.404\times 10^{3}$，对面是 $2.247\times 10^{3}$ 与 $1.798\times 10^{3}$，单位都是 $\mathrm{N/C}$。
:::
:::

## 电偶极子

一对相距很近的等量异号电荷，是整体中性却仍能产生场的标准源。电场比点电荷的场衰减得更快，因为领先的 $1/r^{2}$ 部分相互抵消了。

::: definition 电偶极子 {#def-dipole}
**电偶极子**是电荷 $+q$ 与 $-q$ 相距一个长度 $d > 0$ 的向量 $\mathbf{d}$ 构成的一对，$\mathbf{d}$ 由负电荷画向正电荷。**电偶极矩**是

$$
\mathbf{p} = q\mathbf{d}.
$$ {#eq-dipole}

偶极矩由负指向正。SI 单位是库仑米。
:::

把 $+q$ 放在 $z = +d/2$，$-q$ 放在 $z = -d/2$，于是 $\mathbf{p}$ 沿 $z$ 轴正向。在轴线上、正电荷之外，$+q$ 的场沿 $+z$ 方向，$-q$ 的场沿 $-z$ 方向，指向负电荷。两个场相互对抗，较近的电荷占上风。

::: theorem 偶极子轴线上的电场 {#thm-axial}
在刚定义的偶极子的轴线上、坐标 $z$ 处（$\abs{z} > d/2$），

$$
E_z = \frac{1}{4\pi\varepsilon_0}\,\frac{2 p z}{\bigl(z^{2} - (d/2)^{2}\bigr)^{2}},
$$ {#eq-axial-exact}

其中 $p = qd$。$z > d/2$ 时电场沿 $\mathbf{p}$ 方向。远离偶极子处，$\abs{z} \gg d$，主导项是

$$
E_z \approx \frac{1}{4\pi\varepsilon_0}\,\frac{2p}{z^{3}},
$$ {#eq-axial-far}

当 $p > 0$ 时其符号即 $z$ 的符号，所以在正半轴上 $\mathbf{E}$ 与 $\mathbf{p}$ 平行。
:::

::: proof
精确的场是两个点电荷场之差：

$$
E_z = \frac{1}{4\pi\varepsilon_0}\, q\left(\frac{1}{(z - d/2)^{2}} - \frac{1}{(z + d/2)^{2}}\right).
$$

公分母是 $\bigl(z^{2} - (d/2)^{2}\bigr)^{2}$。两个平方距离之差的分子是

$$
(z + d/2)^{2} - (z - d/2)^{2} = 2zd.
$$

于是 $E_z = k q (2zd) / \bigl(z^{2} - (d/2)^{2}\bigr)^{2}$。因为 $p = qd$，这就是 [[#eq-axial-exact]]。$z > d/2$ 时，$q > 0$ 的每个因子都是正的，所以 $E_z > 0$，与 $\mathbf{p}$ 平行。

远场部分令 $u = d/(2z)$，$\abs{u} < 1$ 恰好当 $\abs{z} > d/2$；现在取 $z > 0$，于是 $u > 0$。则

$$
(z \pm d/2)^{-2} = z^{-2}(1 \pm u)^{-2}.
$$

二项展开 $(1 - u)^{-2} = 1 + 2u + 3u^{2} + 4u^{3} + \cdots$ 与 $(1 + u)^{-2} = 1 - 2u + 3u^{2} - 4u^{3} + \cdots$ 相减得

$$
(1 - u)^{-2} - (1 + u)^{-2} = 4u + 8u^{3} + \cdots.
$$

偶次幂相消。乘上 $k q/z^{2}$ 并用 $4u = 2d/z$：

$$
E_z = \frac{1}{4\pi\varepsilon_0}\, q\left(\frac{2d}{z^{3}} + \frac{d^{3}}{z^{5}} + \cdots\right) = \frac{1}{4\pi\varepsilon_0}\left(\frac{2p}{z^{3}} + \frac{p d^{2}}{z^{5}} + \cdots\right).
$$

第一项就是 [[#eq-axial-far]]。下一项比第一项小一个 $(d/z)^{2}$ 量级的因子，这正是 $\abs{z} \gg d$ 的内容。$z^{-5}$ 的系数留作再展开一阶的练习；$u^{2}$ 的相消正是把误差推到 $1/z^{5}$ 而不是 $1/z^{4}$ 的原因。
:::

在中垂面上相消的情形不同，留下的场与 $\mathbf{p}$ 反向。

::: proposition 中垂面上的电场 {#prop-bisector}
在同一偶极子中心外距离 $r$ 处，在过中心且垂直于 $\mathbf{p}$ 的平面内，

$$
\mathbf{E} = -\frac{1}{4\pi\varepsilon_0}\,\frac{\mathbf{p}}{\bigl(r^{2} + (d/2)^{2}\bigr)^{3/2}}.
$$ {#eq-bisector-exact}

远处 $r \gg d$，

$$
\mathbf{E} \approx -\frac{1}{4\pi\varepsilon_0}\,\frac{\mathbf{p}}{r^{3}}.
$$ {#eq-bisector-far}

中垂面上的场与电偶极矩反向。在相等的大距离处，轴上场的大小是中垂面上场的两倍，且与 $\mathbf{p}$ 的相对取向相反。
:::

::: proof
把场点放在 $(r, 0, 0)$，$r > 0$。每个电荷到该点的距离都是 $R = \sqrt{r^{2} + (d/2)^{2}}$。

从 $(0, 0, d/2)$ 处的 $+q$ 指向场点的向量是 $(r, 0, -d/2)$。$+q$ 的场沿那个向量：

$$
\mathbf{E}_{+} = \frac{1}{4\pi\varepsilon_0}\,\frac{q}{R^{3}}\,(r,\, 0,\, -d/2).
$$

$-q$ 的场指向 $-q$，与从 $-q$ 到场点的向量相反。那个向量是 $(r, 0, d/2)$，所以

$$
\mathbf{E}_{-} = \frac{1}{4\pi\varepsilon_0}\,\frac{q}{R^{3}}\,(-r,\, 0,\, -d/2).
$$

相加。$x$ 分量相消，$z$ 分量一致：

$$
\mathbf{E} = \frac{1}{4\pi\varepsilon_0}\,\frac{q}{R^{3}}\,(0,\, 0,\, -d) = -\frac{1}{4\pi\varepsilon_0}\,\frac{q d}{R^{3}}\,\hat{\mathbf{z}},
$$

就是 [[#eq-bisector-exact]]。$r \gg d$ 时分母是 $r^{3}$，即 [[#eq-bisector-far]]。在同样大的距离上与 [[#eq-axial-far]] 比较：轴上的大小是中垂面大小的两倍，而且轴上场在正半轴与 $\mathbf{p}$ 平行，中垂面上的场则与 $\mathbf{p}$ 反向。
:::

::: example 两毫米的偶极子 {#ex-dipole}
取 $q = 2.00\,\mathrm{nC}$、$d = 2.00\,\mathrm{mm}$，于是 $p = 4.00\times 10^{-12}\,\mathrm{C\cdot m}$。在距中心 $20.0\,\mathrm{mm}$ 处，把精确的轴上场与中垂面场同远场公式比较。
::: solution
这里 $d/(2z) = 0.0500$，小到远场项应有千分之几的精度，又不至于小到看不见比较。

轴线上，[[#eq-axial-exact]] 在 $z = 0.0200\,\mathrm{m}$ 处给出

$$
E_z = \frac{k\,(2.00\times 10^{-9})\,(2\times 0.0200\times 0.00200)}{\bigl(0.0200^{2} - 0.00100^{2}\bigr)^{2}} = 9.0327\times 10^{3}\,\mathrm{N/C}.
$$

远场主导项是 $k(2p)/z^{3} = 8.9876\times 10^{3}\,\mathrm{N/C}$。近似值偏低 $0.499\%$。两者都沿 $\mathbf{p}$ 方向。

同一点的中垂面上，[[#eq-bisector-exact]] 给出 $4.4770\times 10^{3}\,\mathrm{N/C}$，与 $\mathbf{p}$ 反向。远场大小 $kp/r^{3} = 4.4938\times 10^{3}\,\mathrm{N/C}$ 偏高 $0.375\%$。轴向远场大小恰是中垂面远场大小的两倍，$8.9876\times 10^{3}$ 对 $4.4938\times 10^{3}$，这就是 [[#prop-bisector]] 里的那个因子二。精确场之比不是二，因为 $20.0\,\mathrm{mm}$ 只是十个间距，不是无穷大：$9032.7/4477.0 = 2.018$。
:::
:::

## 电场线

积分与求和算出 $\mathbf{E}$。一张图不能取而代之，但它可以记录方向，并能在算术开始之前拦住一个符号错误。

::: definition 电场线 {#def-line}
**电场线**是一条曲线，它在每一点的切线都平行于该点的 $\mathbf{E}$。沿曲线的指向就是 $\mathbf{E}$ 的指向。画线时从正电荷出发，到负电荷终止；若源的总电荷不为零，则伸向无穷远。$\mathbf{E} = \mathbf{0}$ 的点不画线穿过，因为那里的切线没有定义。
:::

由定义与 [[#prop-super-E]] 可推出两条规则，两条都不是装饰。

线不能相交。在交点处，两条切线会要求 $\mathbf{E}$ 有两个方向，而 [[#eq-super-E]] 只给出一个向量。$\mathbf{E}$ 的零点不是交点：场在那里没有方向，趋近它的线就停在那里。

线的密度是 $\abs{\mathbf{E}}$ 的图像，不是它的证明。如果约定按源电荷的多少成正比例地起线，那么单个点电荷的线铺满一个球面，单位面积的条数按 $1/r^{2}$ 衰减，与 [[#eq-point]] 吻合。这个吻合就是约定值得保留的原因。它算不出棒或偶极子的场，算场的是积分。线密的地方，$\abs{\mathbf{E}}$ 比线疏的地方大，而这个比较的可信度只到画图的诚实程度为止。

::: warning 电场线不是运动轨迹
粒子只在一种特殊情形下沿电场线运动：线是直的，且粒子从静止释放。力、从而加速度，沿线的切向。从静止出发，速度沿同一条直线增长，永远不会获得离开它的分量。若线是弯的，粒子仍然沿切线起步，但它已获得的速度指着旧切线方向，而 $\mathbf{E}$ 已经转过去了。电力中没有任何东西能抵消把粒子带离曲线的惯性。若线是直的但粒子横向被抛出，运动就是带着沿场的恒定加速度的抛体运动，轨迹是抛物线，不是那条线。依赖速度的磁力不在本章。它们从 [[magnetism]] 开始。
:::

::: widget charges
charges: 1, 0, 0.5; -1, 0, -0.5
caption: 一个偶极子：$+1$ 在原点上方，$-1$ 在下方，所以电偶极矩朝上。水平中垂面上箭头朝下，与偶极矩相反。正电荷之外的轴线上箭头朝上，沿偶极矩。每支箭头都画成同样长：长度不是 $\abs{\mathbf{E}}$，这张固定网格上箭头的疏密也不是电场线的密度约定。
:::

::: quiz
一个电子在匀强电场中从静止释放，电场线是直的、平行的。它的轨迹
- [ ] 是弯的，因为匀强电场的电场线在纸面上画成曲线
- [ ] 垂直于 $\mathbf{E}$，因为电子带负电
- [x] 是一条与 $\mathbf{E}$ 反向的直线
- [ ] 只有给电子一个横向的初速度时，才沿电场线
::: solution
线是直的，电子从静止出发，所以 warning 里的特殊情形适用。电子受力与 $\mathbf{E}$ 反向，于是这条直线轨迹逆着场延伸，仍然沿一条电场线，只是逆着箭头行进。一个横向的初速度会把它带离那条线，哪怕线是直的。
:::
:::

::: history 电力线
法拉第（Faraday）的《电的实验研究》（*Experimental Researches in Electricity*）从 1831 年开始陆续发表。整个十九世纪三十年代，他发展了电力线的图像：磁体或带电体周围空间里的图案，在他看来就是值得画下来的对象本身，不是超距作用的速记。这些图是定性的。把场变成首要的数学对象——有自己的微分方程、能量储存在空间里——这一步是麦克斯韦（Maxwell）迈出的，从十九世纪六十年代的论文直到《电磁学通论》（*A Treatise on Electricity and Magnetism*，1873）。[[#def-field]] 中的向量 $\mathbf{E}$ 就是那个后来的对象。法拉第的线仍是它的方向的正确速写。
:::

## 匀强电场中的运动

匀强场在所关心的区域内大小和方向都保持不变。它是大块平行带电平面之间电场的理想化，其成立由 [[electrostatics/gauss-law]] 保证；而当一道题直接说“$\mathbf{E}$ 是均匀的”，你要写下的就是它。

::: proposition 匀强场中的匀加速运动 {#prop-uniform}
在 $\mathbf{E}$ 为常量的区域里，电荷为 $q$、质量 $m > 0$ 恒定的粒子具有恒定加速度

$$
\mathbf{a} = \frac{q\mathbf{E}}{m}.
$$ {#eq-a}

若粒子从静止出发，则经过时间 $t$，速率为 $\abs{q E/m}\, t$，走过的距离为 $\tfrac{1}{2}\abs{q E/m}\, t^{2}$，两者都沿 $q\mathbf{E}$ 的方向。
:::

::: proof
把 [[#eq-def-E]] 移项，力就是 $\mathbf{F} = q\mathbf{E}$。[[mechanics/newton-laws]] 中质量恒定的牛顿第二定律是 $\mathbf{F} = m\mathbf{a}$。除以 $m$ 得 [[#eq-a]]。场恒定使 $\mathbf{a}$ 恒定。[[mechanics/motion-1d]] 的匀加速结果在初速度为零时，沿 $\mathbf{a}$ 的方向给出 $v = at$ 与 $s = \tfrac{1}{2}at^{2}$。那个方向就是 $q\mathbf{E}$ 的方向：$q > 0$ 时沿 $\mathbf{E}$，$q < 0$ 时与 $\mathbf{E}$ 反向。
:::

横向的初速度不改变 $\mathbf{a}$。此时的运动就是 [[mechanics/motion-2d]] 的抛体运动，只是把“下”换成 $q\mathbf{E}$ 的方向。轨迹是一条抛物线。它不是电场线，这正是上面 warning 的后半句。

::: example 水平场中的电子 {#ex-electron}
电子在大小 $E = 2000\,\mathrm{N/C}$、水平指向的匀强电场中从静止释放。取 $m_e = 9.109\times 10^{-31}\,\mathrm{kg}$ 和精确元电荷。求加速度，以及 $10.0\,\mathrm{ns}$ 后的速率与走过的距离。与 $c = 2.99792458\times 10^{8}\,\mathrm{m/s}$ 比较。
::: solution
电子的电荷是 $-e$，所以 $\mathbf{a}$ 与 $\mathbf{E}$ 反向，大小为

$$
a = \frac{e E}{m_e} = \frac{(1.602176634\times 10^{-19})\,(2000)}{9.109\times 10^{-31}} = 3.5178\times 10^{14}\,\mathrm{m/s^{2}}.
$$

由 $m_e$ 决定有效数字，保留四位是 $3.518\times 10^{14}\,\mathrm{m/s^{2}}$。在 $t = 1.00\times 10^{-8}\,\mathrm{s}$ 内，

$$
v = at = 3.5178\times 10^{6}\,\mathrm{m/s}, \qquad s = \tfrac{1}{2}at^{2} = 1.7589\times 10^{-2}\,\mathrm{m},
$$

保留四位是 $3.518\times 10^{6}\,\mathrm{m/s}$ 与 $1.759\times 10^{-2}\,\mathrm{m}$。两者都与场反向。

速率之比 $v/c = 0.01173$。用 $\tfrac{1}{2}m v^{2}$ 代替相对论性动能的相对误差在 $(v/c)^{2} \approx 1.4\times 10^{-4}$ 量级，小于四位有效数字质量的精度，所以非相对论运动学与给出的数值是自洽的。动能本身是 $\tfrac{1}{2}m_e v^{2} = 5.636\times 10^{-18}\,\mathrm{J}$，若一个电子伏特定义为 $e$ 焦耳，它就是 $35.18$ 电子伏特。这个单位属于势能，在 [[electrostatics/potential]] 里。加速度大得惊人，是因为质量不大；十个纳秒之后的能量并不惊人。
:::
:::

同样的公式把电子换成质子，就是另一个尺度。质子重 $m_p/m_e$ 倍，其中 $m_p = 1.673\times 10^{-27}\,\mathrm{kg}$，约 $1837$ 倍，它在同一场中的加速度就小这个倍数，而且方向相反，因为质子的电荷是 $+e$。两个都要的题目是 [[#eq-a]] 的两次使用，不是一条新定律。

## 后续内容

[[electrostatics/gauss-law]] 中的高斯定律把 [[#eq-point]] 改写为一条关于通量的陈述。当对称性使 [[#eq-integral]] 的积分变得多余时，它就能算出场；无限长直线、无限大平面和球对称电荷分布的电场，作为简短的论证而不再是极限，都归它管。电势把 $\mathbf{E}$ 变成一个标量，其梯度的负值把场送回来。电容器是一个带有了可测电势差的匀强场。这都不会改变 [[#eq-def-E]] 给出的定义。

运动的电荷感受到的不只是 $q\mathbf{E}$。一旦它有了速度，磁场就施加一个垂直于速度的力。本章的轨迹只受电力。一旦允许依赖速度的力，关于电场线的 warning 就变成另一条定理，而它不在这里证明。

::: summary
- 电场是 $\mathbf{E} = \mathbf{F}/q_0$，单位 $\mathrm{N/C}$，方向为正试探电荷受力的方向。源固定时，它不依赖 $q_0$。
- 点电荷产生 $\mathbf{E} = (1/(4\pi\varepsilon_0))\, q\hat{\mathbf{r}}/r^{2}$，背离正电荷、指向负电荷。几个电荷的场按向量相加。
- 连续分布就是同一条定律的积分。均匀圆环轴线上，$E_z = (1/(4\pi\varepsilon_0))\, Qz/(R^{2}+z^{2})^{3/2}$。均匀直棒中垂线上，$E = (1/(4\pi\varepsilon_0))\, Q/\bigl(x\sqrt{x^{2}+(L/2)^{2}}\bigr)$。无限长直线是长棒极限 $E = \lambda/(2\pi\varepsilon_0 r)$。
- 偶极子 $\mathbf{p} = q\mathbf{d}$ 由负电荷指向正电荷。远处轴线上，$\mathbf{E} \approx (1/(4\pi\varepsilon_0))\, 2\mathbf{p}/z^{3}$。中垂面上，$\mathbf{E} \approx -(1/(4\pi\varepsilon_0))\, \mathbf{p}/r^{3}$。
- 电场线沿 $\mathbf{E}$，始于正电荷、止于负电荷，且不相交。线的密度是 $\abs{\mathbf{E}}$ 的图像，不是计算。只有当线是直的且电荷从静止释放时，线才是轨迹。
- 匀强场中 $\mathbf{a} = q\mathbf{E}/m$。从静止释放的电子逆着 $\mathbf{E}$ 加速。磁力不在本章之内。
:::

## 习题

::: exercise 小负电荷的电场 {#exr-point level=1}
点电荷 $-3.00\,\mathrm{nC}$ 固定在真空中。求距它 $5.00\,\mathrm{cm}$ 处 $\mathbf{E}$ 的大小与方向。
::: solution
这就是 [[#ex-nanoc]]，把算术从 [[#eq-point]] 再走一遍：

$$
E = \frac{k\,(3.00\times 10^{-9})}{(0.0500)^{2}} = 1.0785\times 10^{4}\,\mathrm{N/C},
$$

保留四位是 $1.079\times 10^{4}\,\mathrm{N/C}$，方向指向电荷。方向是答案的一部分。只报大小不报方向，描述的是同样强度的正源，那是另一个场。
:::
:::

::: exercise 带电微粒的加速度 {#exr-grain level=1 check="20"}
质量 $3.00\times 10^{-6}\,\mathrm{kg}$ 的微粒带电荷 $1.50\times 10^{-8}\,\mathrm{C}$。把它放入大小 $4.00\times 10^{3}\,\mathrm{N/C}$ 的匀强电场。求加速度大小。忽略重力。
::: solution
[[#eq-a]] 给出

$$
a = \frac{qE}{m} = \frac{(1.50\times 10^{-8})\,(4.00\times 10^{3})}{3.00\times 10^{-6}} = 20.0\,\mathrm{m/s^{2}}.
$$

电荷为正，所以 $\mathbf{a}$ 与 $\mathbf{E}$ 平行。题目排除了重力；它是 $g = 9.80\,\mathrm{m/s^{2}}$，竖直向下，与这个加速度同一量级，若问的是地球引力中的净加速度就不能忽略。
:::
:::

::: exercise 让带电小珠静止在空中 {#exr-levitate level=1 check="9800"}
质量 $1.00\times 10^{-3}\,\mathrm{kg}$ 的小珠带电荷 $+1.00\times 10^{-6}\,\mathrm{C}$。在地球附近，要多大的匀强电场（单位 $\mathrm{N/C}$）才能平衡它的重力？取 $g = 9.80\,\mathrm{m/s^{2}}$，给出大小。
::: solution
平衡即 $qE = mg$，$\mathbf{E}$ 必须向上，使正电荷受力向上：

$$
E = \frac{mg}{q} = \frac{(1.00\times 10^{-3})\,(9.80)}{1.00\times 10^{-6}} = 9800\,\mathrm{N/C}.
$$

电场是 $9800\,\mathrm{N/C}$，方向向上。电荷反号，所需电场也反向。丢掉 $g$，或者用 $9.8$ 而不用数据允许的带末位零的 $9.80$，是三位数字下的同一个值；题目要的数是 $9800$。
:::
:::

::: exercise 两个电荷之外的场 {#exr-vector level=2}
$+6.00\,\mathrm{nC}$ 在原点，$-8.00\,\mathrm{nC}$ 在 $(0.300\,\mathrm{m},\, 0)$。求 $(0.300\,\mathrm{m},\, 0.400\,\mathrm{m})$ 处的电场。给出大小与相对 $x$ 轴正向向下的角度。
::: solution
原点到场点的距离是 $0.500\,\mathrm{m}$。负电荷到场点的距离是 $0.400\,\mathrm{m}$，而且那个源恰在场点正下方。

正电荷产生的场背离原点，沿 $(0.600,\, 0.800)$，大小为

$$
E_{+} = \frac{k\,(6.00\times 10^{-9})}{(0.500)^{2}} = 215.70\,\mathrm{N/C}.
$$

负电荷产生的场指向自身，竖直向下，大小为

$$
E_{-} = \frac{k\,(8.00\times 10^{-9})}{(0.400)^{2}} = 449.38\,\mathrm{N/C}.
$$

分量，$+y$ 向上：

$$
\begin{aligned}
E_x &= 215.70\times 0.600 = 129.42\,\mathrm{N/C}, \\
E_y &= 215.70\times 0.800 - 449.38 = 172.56 - 449.38 = -276.82\,\mathrm{N/C}.
\end{aligned}
$$

$$
\abs{\mathbf{E}} = \sqrt{129.42^{2} + 276.82^{2}} = 305.6\,\mathrm{N/C},
$$

$$
\theta = \tan^{-1}\frac{-276.82}{129.42} = -64.94^{\circ},
$$

即在 $x$ 轴正向以下 $64.94^{\circ}$。向下的那块来自较近的那个负电荷。丢掉正电荷会剩下一个纯竖直的 $449.4\,\mathrm{N/C}$ 的场，而且会丢掉一个几乎占 $\mathbf{E}$ 的大小之半的 $x$ 分量。
:::
:::

::: exercise 匀强场中的质子 {#exr-proton level=2}
质子在大小 $500\,\mathrm{N/C}$ 的匀强电场中从静止释放。取 $m_p = 1.673\times 10^{-27}\,\mathrm{kg}$。求 $1.00\,\mu\mathrm{s}$ 后的速率与走过的距离，以及相对 $\mathbf{E}$ 的方向。
::: solution
质子的电荷是 $+e$，所以 $\mathbf{a}$ 与 $\mathbf{E}$ 平行。大小为

$$
a = \frac{e E}{m_p} = \frac{(1.602176634\times 10^{-19})\,(500)}{1.673\times 10^{-27}} = 4.7883\times 10^{10}\,\mathrm{m/s^{2}}.
$$

在 $t = 1.00\times 10^{-6}\,\mathrm{s}$ 后，

$$
v = at = 4.788\times 10^{4}\,\mathrm{m/s}, \qquad s = \tfrac{1}{2}at^{2} = 2.394\times 10^{-2}\,\mathrm{m},
$$

两者都沿 $\mathbf{E}$ 方向。与 [[#ex-electron]] 相比，场更弱、时间更长、质量大了约 $1837$ 倍。速率远低于 $c$：$v/c \approx 1.6\times 10^{-4}$。非相对论公式是对的。

::: exercise 棒的电场保留了点电荷场的几成 {#exr-fraction level=2 check="4/sqrt(41)"}
一根均匀带电棒的长 $L = 0.500\,\mathrm{m}$。在中垂线上 $x = 0.200\,\mathrm{m}$ 处，电场大小是“把棒的总电荷集中成点电荷在同一距离处产生的电场”的分数 $f$。求 $f$。总电荷应当约掉。
::: hint
用 [[#eq-rod]] 除以 $k Q/x^{2}$。然后写出 $x^{2} + (L/2)^{2} = 0.1025 = 41/400$。
:::
::: solution
由 [[#eq-rod]] 与点电荷大小 $k Q/x^{2}$，

$$
f = \frac{x}{\sqrt{x^{2} + (L/2)^{2}}}.
$$

电荷 $Q$ 与常量 $k$ 都约掉，这就是 $f$ 不需要它们的原因。代入 $x = 0.200$ 与 $L/2 = 0.250$：

$$
x^{2} + (L/2)^{2} = 0.0400 + 0.0625 = 0.1025 = \frac{41}{400}.
$$

$$
f = \frac{0.200}{\sqrt{41}/20} = \frac{4}{\sqrt{41}}.
$$

数值上 $f = 0.6247$。这就是 [[#ex-rod]] 中已对一个特定的 $Q$ 算过的比较。这个分数是几何，不是电荷。
:::
:::

::: exercise 偶极子轴线上的下一项 {#exr-series level=3}
在 [[#thm-axial]] 的二项论证中，$u^{3}$ 项没有化简。证明它给正半轴上的 $E_z$ 贡献

$$
\frac{1}{4\pi\varepsilon_0}\,\frac{p d^{2}}{z^{5}},
$$

并对 [[#ex-dipole]] 的偶极子在 $z = 20.0\,\mathrm{mm}$ 处求这个修正项的值。
::: hint
由证明，两个二项级数之差以 $4u + 8u^{3}$ 开头。乘上 $k q/z^{2}$，取 $u = d/(2z)$。$4u$ 部分是已经写出的主导项。留下 $8u^{3}$。
:::
::: solution
取 $z > 0$、$u = d/(2z)$，

$$
E_z = \frac{k q}{z^{2}}\bigl(4u + 8u^{3} + \cdots\bigr).
$$

第二块是

$$
\frac{k q}{z^{2}}\cdot 8\cdot\frac{d^{3}}{8 z^{3}} = \frac{k q d^{3}}{z^{5}} = \frac{1}{4\pi\varepsilon_0}\,\frac{p d^{2}}{z^{5}},
$$

因为 $8/8 = 1$ 且 $p = qd$。对 [[#ex-dipole]]，$p = 4.00\times 10^{-12}\,\mathrm{C\cdot m}$、$d = 2.00\times 10^{-3}\,\mathrm{m}$、$z = 2.00\times 10^{-2}\,\mathrm{m}$：

$$
\frac{k p d^{2}}{z^{5}} = 44.94\,\mathrm{N/C}.
$$

加到主导项 $8.9876\times 10^{3}\,\mathrm{N/C}$ 上，两项近似为 $9.0325\times 10^{3}\,\mathrm{N/C}$。[[#eq-axial-exact]] 的精确值是 $9.0327\times 10^{3}\,\mathrm{N/C}$。剩下约 $0.2\,\mathrm{N/C}$ 的差是下一个奇次幂，量级 $1/z^{7}$。在这个距离上，$44.94\,\mathrm{N/C}$ 的修正是 $0.5\%$ 的误差与 $0.002\%$ 的误差之间的差别。
:::
:::

::: exercise 电场线为何不相交 {#exr-cross level=3}
证明两条电场线不能在 $\mathbf{E} \neq \mathbf{0}$ 的点相交。然后从 [[#prop-uniform]] 说明：为什么在匀强电场中从静止释放的电子沿一条电场线运动，而同一电场中横向射入的电子却不。
::: hint
电场线的切线是 $\mathbf{E}$。若在交点处，就会有两条切线。对运动，分别写出两种情形下的初速度与 $\mathbf{a}$ 的方向。
:::
::: solution
设两条电场线在 $\mathbf{E}(P) \neq \mathbf{0}$ 的点 $P$ 相交。由 [[#def-line]]，每条曲线都切于 $\mathbf{E}(P)$。一个确定的非零向量只确定过 $P$ 的一条直线，所以两条曲线共享那条切线。它们可以相切并作为同一条曲线继续走；它们不能成角度地相交。成角度相交需要 $P$ 处 $\mathbf{E}$ 的两个方向，而 [[#eq-super-E]] 只给出一个。$\mathbf{E} = \mathbf{0}$ 的点不是反例：没有电场线在那里有切线，定义拒绝画线穿过它。

匀强电场的线是平行的直线。[[#prop-uniform]] 说加速度恒定：正电荷时与 $\mathbf{E}$ 平行，电子时反平行。从静止释放，电子的速度生在 $\mathbf{a}$ 上并留在 $\mathbf{a}$ 上。路径就是那条直的电场线，逆着箭头行进。

垂直于 $\mathbf{E}$ 射入时，电子有一个 $\mathbf{a}$ 永远改变不了的初速度分量，因为 $\mathbf{a}$ 垂直于那个分量。路径是抛物线，即 [[mechanics/motion-2d]] 的抛体运动，带着与场反向的恒定加速度 $eE/m_e$。抛物线不是直线，所以不是这个场的电场线。正文里 warning 说的就是这两句话，不多不少：线要是直的，而且要从静止释放。
:::
