门捷列夫（Mendeleev）在 1869 年按化学性质把元素排成了表，他发现这张表以 $2, 8, 8, 18, 18, 32, 32$ 为周期重复。稀有气体收尾每一个周期，碱金属开启下一个，电离能沿每一行升高，到下一行开头又塌落下去。氢的光谱里没有任何东西暗示这些数字。它们来自我们现在已经具备的三种原料：[[quantum-1/hydrogen]] 的类氢轨道、[[quantum-2/identical-particles]] 的泡利原理，以及多电子原子中每个电子都在被其余所有电子*屏蔽*过的核场中运动这一事实——后者我们在 [[quantum-2/stationary-perturbation]] 的氦计算里已经遇过。

核电荷为 $Ze$、含 $Z$ 个电子的原子，忽略核的运动和一切相对论效应的哈密顿量是

$$
\hat H = \sum_{i=1}^{Z}\left[-\frac{\hbar^2}{2m}\nabla_i^2 - \frac{Ze^2}{4\pi\varepsilon_0r_i}\right] + \sum_{i<j}\frac{e^2}{4\pi\varepsilon_0\lvert\mathbf r_i - \mathbf r_j\rvert}.
$$ {#eq-atom}

它连氦都解不出来。电子–电子排斥并不小（对氦它是核吸引力的三分之一），按它做微扰论很差。本章改走标准策略。先把排斥换成一个平均的中心势，于是每个电子有自己的轨道，原子由一个**组态**来描述，如 $1s^22s^22p^6$。再把漏掉的部分——排斥的非中心部分与自旋–轨道耦合——当作微扰处理，它们把每个组态劈成**谱项**与**能级**，其标记正是化学家与光谱学家使用的谱项符号。洪特（Hund）定则随后指出哪个能级是基态。同样内容的化学家版本见化学图谱[多电子原子](/learn/chemistry/lesson.php?c=quantum-chemistry&l=many-electron-atoms)一课。

## 中心力场近似 {#central-field}

考虑原子中的一个电子。在核附近、所有其他电子的内部，它感受到全部核电荷 $Ze$。在所有电子之外，它感受到被其余 $Z - 1$ 个电子屏蔽的核：净电荷 $+e$。两者之间，有效电荷从 $Z$ 平滑地降到 $1$。若其他电子的电荷云平均起来球对称，这个电子就运动在一个中心势中。

::: definition 中心力场近似 {#def-central-field}
在**中心力场近似**下，哈密顿量 [[#eq-atom]] 被替换为

$$
\hat H_{\mathrm c} = \sum_{i=1}^{Z}\left[-\frac{\hbar^2}{2m}\nabla_i^2 + U(r_i)\right],
$$

其中 $U(r)$ 是单一的中心势，满足 $r \to 0$ 时 $U(r) \to -Ze^2/4\pi\varepsilon_0r$，$r \to \infty$ 时 $U(r) \to -e^2/4\pi\varepsilon_0r$。余项 $\hat H - \hat H_{\mathrm c}$ 称为**剩余静电相互作用**。**轨道**是单电子哈密顿量 $-\frac{\hbar^2}{2m}\nabla^2 + U(r)$ 的本征态 $\phi_{nlm_lm_s} = R_{nl}(r)Y_l^{m_l}(\theta, \varphi)\chi_{m_s}$，能量为 $\varepsilon_{nl}$。
:::

因为 $U$ 是中心的，轨道的角向部分就是 [[quantum-1/angular-momentum]] 的球谐函数，我们沿用标签 $n$ 与 $l$，其中 $n \ge l + 1$，并按 $n - l - 1$ 计数径向节点，正如氢原子那样。改变的是能量：氢在同一 $n$ 下不同 $l$ 之间的简并是纯 $1/r$ 势特有的，在屏蔽势中 $\varepsilon_{nl}$ 同时依赖 $n$ 和 $l$。对每一对 $(n, l)$ 有 $2(2l+1)$ 个轨道（$m_l$ 与 $m_s$），在中心场中全部简并。它们构成一个**子壳层**。

由于 $\hat H_{\mathrm c}$ 是相同单电子哈密顿量之和，它的本征态就是轨道的斯莱特行列式（[[quantum-2/identical-particles#def-slater]]），能量为被占据轨道的 $\sum\varepsilon_{nl}$。说明每个子壳层上有几个电子，就得到了**组态**。

### 能量为何依赖 $l$：穿透

::: proposition 穿透为子壳层排序 {#prop-penetration}
对满足 $-Ze^2/4\pi\varepsilon_0r \le U(r) \le -e^2/4\pi\varepsilon_0r$ 的屏蔽势 $U(r)$，类氢的排序被修正为：同一 $n$ 下 $l$ 越小的轨道能量越低：$\varepsilon_{ns} < \varepsilon_{np} < \varepsilon_{nd} < \cdots$。
:::

::: proof
这是一个证明概要：完整的证明需要径向方程的比较定理。这里给出本质所在的一阶论证。写 $U = -e^2/4\pi\varepsilon_0r + \delta U(r)$，其中 $\delta U \le 0$ 是未被完全屏蔽的核带来的附加吸引，且 $\delta U$ 集中在小 $r$ 处（它在原子实之外消失）。一阶地，$\varepsilon_{nl} = E_n + \langle nl\vert\delta U\vert nl\rangle$，$E_n$ 是氢的能量。原点附近氢的径向函数行为为 $R_{nl} \propto r^l$，所以出现在核附近小半径 $r_0$ 以内的概率按 $r_0^{2l+3}$ 伸缩。低 $l$ 轨道把更多概率放进原子实内部，感受到的负 $\delta U$ 更多，于是能量被压低得更多。把高 $l$ 轨道挡在外面的是离心势垒 $\hbar^2l(l+1)/2mr^2$。
:::

:::

碱金属把穿透显示得最干净。一个价电子在电荷 $+e$ 的闭合原子实之外运动，所以它的能级在大 $r$ 处是类氢的，原子实的效应被一个**量子数亏损** $\delta_l$ 收编：能级拟合

$$
\varepsilon_{nl} = -\frac{13.606\,\mathrm{eV}}{(n - \delta_l)^2},
$$ {#eq-defect}

其中 $\delta_l$ 几乎不依赖 $n$，且随 $l$ 快速减小。

::: example 钠的量子数亏损 {#ex-sodium}
钠的电离能为 $5.139\,\mathrm{eV}$，来自基态 $3s$；$589.6\,\mathrm{nm}$ 的黄色 D 线来自 $3p_{1/2}\to3s$。求量子数亏损 $\delta_s$ 与 $\delta_p$，并预言 $4s$ 的结合能（实测：$1.948\,\mathrm{eV}$）。
::: solution
对 $3s$，[[#eq-defect]] 给出 $n - \delta_s = \sqrt{13.606/5.139} = 1.627$，所以 $\delta_s = 3 - 1.627 = 1.373$。D 线的光子能量为 $hc/\lambda = 1239.84\,\mathrm{eV\,nm}/589.59\,\mathrm{nm} = 2.103\,\mathrm{eV}$，所以 $3p$ 束缚 $5.139 - 2.103 = 3.036\,\mathrm{eV}$，得 $n - \delta_p = \sqrt{13.606/3.036} = 2.117$，$\delta_p = 0.883$。

若 $\delta_s$ 不依赖 $n$，$4s$ 能级有 $n - \delta_s = 4 - 1.373 = 2.627$，于是

$$
\varepsilon_{4s} = -\frac{13.606}{2.627^2}\,\mathrm{eV} = -1.97\,\mathrm{eV},
$$

与实测值相差在 $0.03\,\mathrm{eV}$ 以内。$s$ 电子对 $1s^22s^22p^6$ 原子实的穿透如此严重，它的结合比氢的 $n = 3$（$1.51\,\mathrm{eV}$）大一倍多。对 $3d$，$\delta_d \approx 0.01$：钠中的 $d$ 电子几乎精确地是类氢的。
:::
:::

### 自洽场：哈特里与哈特里–福克

$U(r)$ 从何而来？道格拉斯·哈特里（Douglas Hartree）的回答（1928）是让它**自洽**：每个电子在核加上所有其他电子的平均电荷所产生的场中运动，而这个平均电荷由它们自己的轨道算出。这就定出了轨道，轨道定出场，场再定出轨道，计算如此迭代直到不再改变。

::: theorem 哈特里方程 {#thm-hartree}
在轨道归一化的乘积试探函数 $\Psi = \phi_1(\mathbf r_1)\phi_2(\mathbf r_2)\cdots\phi_N(\mathbf r_N)$ 中，[[#eq-atom]] 的期望值取驻值当且仅当每个轨道满足

$$
\left[-\frac{\hbar^2}{2m}\nabla^2 - \frac{Ze^2}{4\pi\varepsilon_0r} + \sum_{j\ne i}\int\frac{e^2\lvert\phi_j(\mathbf r')\rvert^2}{4\pi\varepsilon_0\lvert\mathbf r - \mathbf r'\rvert}\,\dd^3r'\right]\phi_i(\mathbf r) = \varepsilon_i\,\phi_i(\mathbf r).
$$ {#eq-hartree}
:::

::: proof
对乘积态，记 $\hat h = -\frac{\hbar^2}{2m}\nabla^2 - Ze^2/4\pi\varepsilon_0r$，

$$
\langle H\rangle = \sum_i\langle\phi_i\vert\hat h\vert\phi_i\rangle + \sum_{i<j}\int\!\!\int\frac{e^2\lvert\phi_i(\mathbf r)\rvert^2\lvert\phi_j(\mathbf r')\rvert^2}{4\pi\varepsilon_0\lvert\mathbf r - \mathbf r'\rvert}\,\dd^3r\,\dd^3r'.
$$

给 $\phi_i^*$ 一个任意的微小变分 $\delta\phi_i^*$，把 $\phi_i$ 与 $\phi_i^*$ 当作独立变量（复函数问题的标准手法），并用拉格朗日乘子 $\varepsilon_i$ 处理约束 $\langle\phi_i\vert\phi_i\rangle = 1$。$\langle H\rangle - \sum_k\varepsilon_k\langle\phi_k\vert\phi_k\rangle$ 的变分为

$$
\int\delta\phi_i^*(\mathbf r)\left[\hat h\phi_i(\mathbf r) + \sum_{j\ne i}\int\frac{e^2\lvert\phi_j(\mathbf r')\rvert^2}{4\pi\varepsilon_0\lvert\mathbf r - \mathbf r'\rvert}\,\dd^3r'\,\phi_i(\mathbf r) - \varepsilon_i\phi_i(\mathbf r)\right]\dd^3r.
$$

它对一切 $\delta\phi_i^*$ 消失当且仅当方括号为零，这就是 [[#eq-hartree]]。
:::

哈特里乘积不是反对称的。弗拉基米尔·福克（Vladimir Fock）与约翰·斯莱特（John Slater）（1930）对斯莱特行列式重做了这一变分。所得的**哈特里–福克方程**多出一项**交换**项，它是 [[quantum-2/identical-particles#thm-exchange]] 中交换积分 $K$ 的多电子版本，只作用于自旋相同的轨道之间。它同时消去了若求和包含 $j = i$ 时哈特里势中本会出现的非物理自排斥。哈特里–福克总能量通常与精确的非相对论值相差约百分之一（对氦为 $-77.87\,\mathrm{eV}$ 对 $-79.0\,\mathrm{eV}$；比较单参数变分结果 $-77.5\,\mathrm{eV}$）。剩下的误差称为**关联能**，来自电子彼此避开的方式超过平均场允许的程度，它是现代量子化学大部分工作瞄准的目标。

::: remark 库普曼斯（Koopmans）定理
在哈特里–福克理论中，若不允其余轨道弛豫，轨道能量 $\varepsilon_i$ 近似等于从轨道 $i$ 移走一个电子所需能量的负值（Tjalling Koopmans，1934）。这给出了计算出的轨道能量与实测电离能之间的直接联系，光电子谱在每个子壳层的轨道能量处出现峰。
:::

## 壳层与元素周期表 {#periodic-table}

按能量递增依次填满子壳层，每个轨道放自旋相反的两个电子，每个子壳层 $2(2l+1)$ 个：这就是**构造原理**（aufbau，"搭建"）。中性原子中子壳层的实际填充顺序是

$$
1s,\ 2s,\ 2p,\ 3s,\ 3p,\ 4s,\ 3d,\ 4p,\ 5s,\ 4d,\ 5p,\ 6s,\ 4f,\ 5d,\ 6p,\ 7s,\ 5f,\ 6d,\ 7p.
$$

一条助记的**马德隆（Madelung）规则**按 $n + l$ 排序，$n + l$ 相等时按 $n$ 排。它是经验总结而非定理，且有例外。穿透解释了它的主要特征：$4s$（$n + l = 4$）穿透氩的原子实，落到几乎不穿透的 $3d$（$n + l = 5$）之下。

现在来数数。表的每个**周期**从一个新的 $s$ 子壳层开始，到随后的 $p$ 子壳层填满时结束：

| 周期 | 填入的子壳层 | 电子数 | 止于 |
|---|---|---|---|
| 1 | $1s$ | $2$ | He |
| 2 | $2s, 2p$ | $2 + 6 = 8$ | Ne |
| 3 | $3s, 3p$ | $8$ | Ar |
| 4 | $4s, 3d, 4p$ | $2 + 10 + 6 = 18$ | Kr |
| 5 | $5s, 4d, 5p$ | $18$ | Xe |
| 6 | $6s, 4f, 5d, 6p$ | $2 + 14 + 10 + 6 = 32$ | Rn |
| 7 | $7s, 5f, 6d, 7p$ | $32$ | Og |

表的区块就是正在填充的子壳层：两列 $s$、六列 $p$、十列 $d$（过渡金属）、十四列 $f$（镧系与锕系）。一个元素的化学性质主要由其最外层的、未填满的子壳层决定，因为只有那些电子束缚得足够弱，能够参与成键。这就是同一列元素行为相似的原因。

::: example 锂为何活泼 {#ex-lithium}
锂（$Z = 3$）的组态是 $1s^22s$。它的第一电离能为 $5.392\,\mathrm{eV}$，而氦的是 $24.587\,\mathrm{eV}$。用类氢公式 $E = -13.606\,\mathrm{eV}\,Z_{\mathrm{eff}}^2/n^2$ 中的有效电荷 $Z_{\mathrm{eff}}$ 解释这两个数。
::: solution
锂的第三个电子不能与头两个一起进 $1s$（泡利原理），只好进 $n = 2$ 的 $2s$。令 $13.606\,Z_{\mathrm{eff}}^2/4 = 5.392$ 得

$$
Z_{\mathrm{eff}} = 2\sqrt{\frac{5.392}{13.606}} = 1.26.
$$

两个 $1s$ 电子若完全屏蔽会给出 $Z_{\mathrm{eff}} = 1$；多出的 $0.26$ 是 $2s$ 轨道对 $1s$ 原子实的穿透。对氦，每个 $1s$ 电子只被另一个部分屏蔽，$13.606\,Z_{\mathrm{eff}}^2 = 24.587$ 给出被移走电子的 $Z_{\mathrm{eff}} = 1.34$。电离能从氦到锂的大幅跌落——因子 $4.6$——主要来自不相容原理强迫的从 $n = 1$ 到 $n = 2$ 的跳跃：这就是第一壳层的闭合。
:::
:::

::: warning 填充顺序的例外
填充顺序是向导不是法律。铬是 $[\mathrm{Ar}]\,3d^54s^1$ 而非 $3d^44s^2$，铜是 $[\mathrm{Ar}]\,3d^{10}4s^1$ 而非 $3d^94s^2$：$3d$ 与 $4s$ 能量如此接近，以致总能量账目——其中交换能偏爱半满与全满的子壳层——把天平掀了过去。更糟的是，*移走*电子的顺序并非加入顺序的逆：铁是 $[\mathrm{Ar}]\,3d^64s^2$，而 $\mathrm{Fe}^{2+}$ 是 $[\mathrm{Ar}]\,3d^6$，不是 $3d^44s^2$。核一旦屏蔽减弱，$3d$ 就落到 $4s$ 之下。轨道能量依赖于它所从属的组态。
:::

::: quiz
钾（$Z = 19$）是 $[\mathrm{Ar}]\,4s^1$ 而非 $[\mathrm{Ar}]\,3d^1$。哪个解释正确？
- [ ] $4s$ 轨道的平均半径比 $3d$ 小。
- [x] $4s$ 轨道穿透氩的原子实，感受到屏蔽较弱的核，其效果超过它较大的 $n$。
- [ ] 泡利原理禁止在 $4s$ 空着时让电子处于 $3d$。
- [ ] $3d$ 轨道在 $Z = 21$ 之前并不存在。
::: solution
$4s$ 轨道的平均半径其实比 $3d$ 大，但它有很小的内瓣能伸到屏蔽很弱的近核区域。$3d$ 轨道被离心势垒挡在外面，看到的几乎精确地是电荷 $+e$，因而近乎类氢，结合能接近 $13.6/9 = 1.5\,\mathrm{eV}$。泡利原理允许占据任何空的轨道。
:::
:::

## 谱项、能级与洪特定则 {#terms}

中心力场近似下，含未满子壳层的组态是简并的：碳的 $1s^22s^22p^2$ 有 $\binom62 = 15$ 种把两个电子放进六个 $2p$ 自旋轨道的方式。有两个微扰把它劈开。

1. **剩余静电相互作用** $\hat H - \hat H_{\mathrm c}$，对价电子典型值为几个 eV。它与总轨道角动量 $\hat{\mathbf L} = \sum_i\hat{\mathbf L}_i$ 和总自旋 $\hat{\mathbf S} = \sum_i\hat{\mathbf S}_i$ 对易（它是标量且不含自旋），所以由 [[quantum-2/stationary-perturbation#lem-good]]，具有确定 $L$ 与 $S$ 的态是好态，组态劈成具有确定 $L$ 与 $S$ 的**谱项**。
2. **自旋–轨道耦合** $\sum_i\xi(r_i)\hat{\mathbf L}_i\cdot\hat{\mathbf S}_i$，在轻原子中更小（meV 到十分之几个 eV）。在一个谱项内它作用如 $A\,\hat{\mathbf L}\cdot\hat{\mathbf S}$，把谱项劈成具有确定总 $J$ 的**能级**，其中 $\hat{\mathbf J} = \hat{\mathbf L} + \hat{\mathbf S}$。

这个次序——剩余静电在前、自旋–轨道在后——称为 **$LS$ 耦合**或**拉塞尔–桑德斯（Russell–Saunders）耦合**。它对轻原子是好的。在重原子中，内层电子的自旋–轨道耦合大约按 $Z^4$ 增长，可能占主导，此时先把每个电子的 $\mathbf l_i$ 与 $\mathbf s_i$ 耦合成 $\mathbf j_i$：称为 **$jj$ 耦合**。

::: definition 谱项符号 {#def-term}
$LS$ 耦合下的能级用**谱项符号**

$$
{}^{2S+1}L_J,
$$

标记，其中 $L = 0, 1, 2, 3, \dots$ 写作 $S, P, D, F, \dots$（整个原子用大写字母），上标 $2S+1$ 是**多重度**，$J$ 从 $\lvert L - S\rvert$ 取到 $L + S$。每个能级 ${}^{2S+1}L_J$ 含 $2J + 1$ 个态（$M_J = -J, \dots, J$），一个谱项 ${}^{2S+1}L$ 总共含 $(2S+1)(2L+1)$ 个态。
:::

满子壳层有 $L = 0$ 与 $S = 0$（[[#exr-closed]]），所以闭合壳层对角动量没有贡献。只需数未满子壳层里的电子。稀有气体，以及所有只有满子壳层的原子（He、Be、Ne、Mg、……）的基态都是 ${}^1S_0$。

::: example $p^2$ 组态的谱项 {#ex-p2}
求两个等价 $p$ 电子（同一 $n$）的谱项，如碳的基组态。
::: solution
两个 $p$ 电子本可给出 $L = 0, 1, 2$ 与 $S = 0, 1$：六个候选谱项共 $36$ 个态，远多于可用的 $15$ 个。泡利原理删去多余的部分。按 $M_L = m_{l1} + m_{l2}$ 与 $M_S = m_{s1} + m_{s2}$ 的取值逐一数态，只列出不同自旋轨道的允许组合。

最大的 $M_L$ 是 $2$，只有两个电子都在 $m_l = 1$ 才能达到。此时它们自旋必须相反，故 $M_S = 0$。所以 $L = 2$ 的谱项必须有 $S = 0$：一个 ${}^1D$，占 $5$ 个态（$M_L = -2, \dots, 2$，$M_S = 0$）。

接下来看 $M_L = 1$ 且 $M_S = 1$：两个自旋都向上，$m_l = (1, 0)$。这样的态有一个，于是存在 $L = 1$、$S = 1$ 的谱项：一个 ${}^3P$，有 $3\times3 = 9$ 个态。

目前共 $5 + 9 = 14$ 个，总数 $15$ 个。剩下的那个态是 $M_L = 0$、$M_S = 0$：一个 ${}^1S$。所以 $p^2$ 给出 ${}^1S$、${}^3P$ 与 ${}^1D$。"缺失"的谱项 ${}^3S$、${}^1P$、${}^3D$ 正是那些需要对称空间态配对称自旋态的。计入自旋–轨道后，${}^3P$ 劈成 ${}^3P_0$、${}^3P_1$、${}^3P_2$；其余的 $S = 0$，给出 ${}^1S_0$ 与 ${}^1D_2$。
:::
:::

哪个谱项最低？弗里德里希·洪特（Friedrich Hund）在 1925–27 年从光谱中提取出了答案。

::: proposition 洪特定则 {#prop-hund}
对 $LS$ 耦合下、只有一个未满子壳层的原子的基组态：

1. 总自旋 $S$ 最大的谱项最低。
2. 在该 $S$ 的谱项中，$L$ 最大的最低。
3. 若未满子壳层不到半满，$J = \lvert L - S\rvert$ 最小的能级最低；若超过半满，则 $J = L + S$ 最大的最低。

这些是关于基态的经验定则，物理解释如下。(1) 更大的 $S$ 意味着更对称的自旋态，从而更反对称的空间态，使电子彼此远离、降低排斥：即 [[quantum-2/identical-particles#thm-exchange]] 的交换效应。(2) 更大的 $L$ 意味着电子沿同一方向绕行，这同样使它们保持距离。(3) 一个谱项的自旋–轨道常数 $A$ 对不到半满的壳层为正，对超过半满的壳层为负——后者行为像一个带正电荷的空穴构成的壳层。
:::

实际操作中，求基态谱项的办法是：从最大的 $m_l$ 开始把电子放进未满子壳层的各 $m_l$，每个轨道先放一个自旋向上的电子，配对了再说（定则 1）；然后 $S = \sum m_s$，$L = \lvert\sum m_l\rvert$（定则 2），$J$ 由定则 3 选定。

::: example 碳、氮、氧、铁的基态谱项 {#ex-hund}
求 C（$2p^2$）、N（$2p^3$）、O（$2p^4$）与 Fe（$3d^6$）的基态能级。
::: solution
**碳**，$2p^2$：$m_l = 1$ 与 $m_l = 0$ 各放一个自旋向上的电子。于是 $S = 1$，$L = 1$，是 ${}^3P$ 谱项（与 [[#ex-p2]] 一致，那里其余谱项都是单态）。壳层不到半满，所以 $J = \lvert L - S\rvert = 0$：基态能级 ${}^3P_0$。

**氮**，$2p^3$：$m_l = 1, 0, -1$ 各放一个自旋向上的电子。$S = \frac32$，$L = 0$：${}^4S_{3/2}$，$J$ 只有这一个可能。

**氧**，$2p^4$：$m_l = 1, 0, -1$ 放三个自旋向上的，第四个自旋向下的放 $m_l = 1$。$S = 1$，$L = 1$：${}^3P$。壳层超过半满，所以 $J = L + S = 2$：基态能级 ${}^3P_2$。

**铁**，$3d^6$（$4s^2$ 已满）：五个自旋向上填满 $m_l = 2, \dots, -2$，贡献 $\sum m_l = 0$，第六个自旋向下进 $m_l = 2$。$S = 5\times\frac12 - \frac12 = 2$，$L = 2$：${}^5D$。超过半满，所以 $J = 4$：基态能级 ${}^5D_4$。四个未配对自旋正是铁原子带有大磁矩的原因。

四个结果全部与实测基态能级相符。
:::
:::

::: quiz
氟 $2p^5$ 的基态能级是什么？
- [ ] ${}^2P_{1/2}$
- [x] ${}^2P_{3/2}$
- [ ] ${}^1S_0$
- [ ] ${}^2S_{1/2}$

五个 $p$ 电子距满壳层差一个，行为像一个空穴：$S = \frac12$，$L = 1$，是 ${}^2P$ 谱项。壳层超过半满，所以 $J = L + S = \frac32$。卤素的基态都是 ${}^2P_{3/2}$；而闭合壳层外只有一个电子的碱金属则都是 ${}^2S_{1/2}$。

### $LS$ 耦合下的精细结构

在一个谱项内部，自旋–轨道相互作用作用如 $A\,\hat{\mathbf L}\cdot\hat{\mathbf S}$，$A$ 是该谱项的常数。由于 $\hat{\mathbf L}\cdot\hat{\mathbf S} = \frac12(\hat J^2 - \hat L^2 - \hat S^2)$，能级能量为

$$
E_J = E_{\mathrm{term}} + \frac A2\bigl[J(J+1) - L(L+1) - S(S+1)\bigr]\hbar^2,
$$

相邻能级的间隔为

$$
E_J - E_{J-1} = A\hbar^2J.
$$ {#eq-interval}

这就是**朗德间隔定则**：相邻能级之差正比于较大的 $J$。

::: example 钠 D 双线 {#ex-sodium-d}
钠 D 双线的两条线位于 $588.995\,\mathrm{nm}$（$3p_{3/2}\to3s_{1/2}$）与 $589.592\,\mathrm{nm}$（$3p_{1/2}\to3s_{1/2}$）。求钠 $3p$ 谱项的精细结构分裂，并与氢 $n = 2$ 的分裂比较。
::: solution
分裂就是两个光子能量之差：

$$
\Delta E = hc\left(\frac{1}{588.995\,\mathrm{nm}} - \frac{1}{589.592\,\mathrm{nm}}\right) = 1239.84\,\mathrm{eV\,nm}\times1.719\times10^{-6}\,\mathrm{nm^{-1}} = 2.13\times10^{-3}\,\mathrm{eV}.
$$

氢 $2p$ 的分裂在 [[quantum-2/stationary-perturbation#ex-fine-n2]] 中为 $4.53\times10^{-5}\,\mathrm{eV}$，小了将近五十倍。钠的 $3p$ 电子穿透原子实，在核附近感受到很强的、未屏蔽的场 $-\nabla U$，而自旋–轨道耦合经 $(1/r)\,\dd U/\dd r$ 依赖这个场。对单个电子，间隔定则 [[#eq-interval]] 平凡地成立（只有一个间隔），$A\hbar^2 = \Delta E/J = 2.13\,\mathrm{meV}/\frac32 = 1.42\,\mathrm{meV}$。
:::
:::

::: history 从门捷列夫到哈特里–福克
德米特里·门捷列夫（Dmitri Mendeleev）1869 年发表了他的元素周期表，并为尚未发现的元素留下空位。亨利·莫塞莱（Henry Moseley）的 X 射线测量（1913 年）表明排序依据是核电荷 $Z$ 而非原子量。尼尔斯·玻尔（Niels Bohr）的构造原理（*Aufbauprinzip*，1921–22）在量子力学建立之前，依据光谱学证据从电子壳层搭建出这张表；沃尔夫冈·泡利（Wolfgang Pauli）的不相容原理（1925 年）解释了壳层为何闭合。亨利·诺里斯·拉塞尔（Henry Norris Russell）与弗雷德里克·桑德斯（Frederick Saunders）1925 年描述了碱土金属光谱中的 $LS$ 耦合；弗里德里希·洪特（Friedrich Hund）1925 年提出他的定则，并写进他 1927 年关于原子与分子光谱的专著。道格拉斯·哈特里（Douglas Hartree）1928 年引入自洽场；弗拉基米尔·福克（Vladimir Fock）与约翰·斯莱特（John Slater）在 1930 年将它反对称化。埃尔温·马德隆（Erwin Madelung）的 $n + l$ 规则出现于 1936 年；夏洛特·摩尔（Charlotte Moore）在美国国家标准局编纂的原子能级表（1949 年起）提供了检验这一切的数据。
:::

## 后续内容 {#leads}

哈特里–福克理论及其后继者是计算化学的起点，而这里的谱项符号标记着原子钟、激光与天文光谱所用到的那些态。同一套方案换一个中心势，就得到 [[particles/nuclear-structure]] 的核壳层模型，其"幻数"是稀有气体的核版本。把洪特第一定则用于晶体的原子，就得到 [[condensed-matter/magnetism-superconductivity]] 中定域的磁矩。下一章 [[quantum-2/scattering]] 我们将从束缚态转向连续谱：一个电子不被原子束缚、而是被原子偏转时会发生什么。

::: summary
- 中心力场近似把电子–电子排斥换成平均中心势 $U(r)$，核附近为 $-Ze^2/4\pi\varepsilon_0r$，远处为 $-e^2/4\pi\varepsilon_0r$。轨道保留标签 $n, l, m_l, m_s$，但 $\varepsilon_{nl}$ 依赖 $l$。
- 低 $l$ 轨道穿透原子实、束缚更强；碱金属能级拟合 $-13.606\,\mathrm{eV}/(n - \delta_l)^2$，$\delta_l$ 是量子数亏损。
- 哈特里的自洽场来自乘积态的变分原理；哈特里–福克加上反对称与交换。剩下的误差是关联。
- 子壳层按 $1s, 2s, 2p, 3s, 3p, 4s, 3d, \dots$ 的顺序填入，每个容纳 $2(2l+1)$ 个电子，得到 $2, 8, 8, 18, 18, 32, 32$ 的周期。
- 剩余排斥把组态劈成谱项 ${}^{2S+1}L$；自旋–轨道耦合把谱项劈成能级 $J$。满子壳层有 $L = S = 0$。
- 洪特定则：先 $S$ 极大，再 $L$ 极大，然后不到半满的壳层取 $J$ 极小、超过半满的取 $J$ 极大。C 是 ${}^3P_0$，N 是 ${}^4S_{3/2}$，O 是 ${}^3P_2$，Fe 是 ${}^5D_4$。
- 自旋–轨道分裂服从间隔定则 $E_J - E_{J-1} = AJ$（$LS$ 耦合），并随 $Z$ 迅速增大。
:::

## 习题 {#exercises}

::: exercise 壳层的容量 {level=1 check="32"}
壳层 $n = 4$ 算上它的全部子壳层能容纳多少个电子？
::: solution
子壳层为 $l = 0, 1, 2, 3$，每个容纳 $2(2l+1)$ 个电子：$2 + 6 + 10 + 14 = 32$。一般地 $\sum_{l=0}^{n-1}2(2l+1) = 2n^2$。
:::

::: exercise 一个谱项中的状态数 {level=1 check="9"}
${}^3P$ 谱项包含多少个态？它们在各能级间如何分布？
::: solution
$(2S+1)(2L+1) = 3\times3 = 9$。能级为 $J = 0, 1, 2$，各有 $2J+1 = 1, 3, 5$ 个态，且 $1 + 3 + 5 = 9$。
:::

::: exercise 钠的有效电荷 {level=1 check="1.84"}
钠的 $3s$ 电子束缚能为 $5.139\,\mathrm{eV}$。求一个类氢的 $n = 3$ 轨道要具有这一结合能所需要的有效核电荷。
::: solution
$13.606\,Z_{\mathrm{eff}}^2/9 = 5.139$ 给出 $Z_{\mathrm{eff}} = 3\sqrt{5.139/13.606} = 1.84$。十个原子实电子把十一个质子屏蔽不到 $1$，因为 $3s$ 轨道穿透了原子实。[[#ex-sodium]] 的量子数亏损描述包含同样的信息：$Z_{\mathrm{eff}}/n = 1/(n - \delta)$。
:::
:::

::: exercise 用洪特定则求基态能级 {level=2 check="4"}
求钛（$3d^24s^2$）、钴（$3d^74s^2$）与镍（$3d^84s^2$）的基态能级，并给出镍的 $J$ 值。
::: solution
**Ti**，$3d^2$：$m_l = 2, 1$ 各放自旋向上的电子。$S = 1$，$L = 3$：${}^3F$，不到半满，$J = L - S = 2$：${}^3F_2$。

**Co**，$3d^7$：五个自旋向上，$\sum m_l = 0$，再放两个自旋向下的进 $m_l = 2, 1$。$S = \frac52 - 1 = \frac32$，$L = 3$：${}^4F$，超过半满，$J = L + S = \frac92$：${}^4F_{9/2}$。

**Ni**，$3d^8$：两个空穴，与 $d^2$ 类似。$S = 1$，$L = 3$：${}^3F$，超过半满，$J = 4$：${}^3F_4$。三者的预测都与实验一致。
:::
:::

::: exercise 碳的间隔定则 {level=2 check="2"}
碳的 ${}^3P$ 能级位于基态能级 ${}^3P_0$ 之上 $0$、$16.40$ 与 $43.40\,\mathrm{cm^{-1}}$ 处。朗德间隔定则预言的比值 $(E_2 - E_1)/(E_1 - E_0)$ 是多少？符合得如何？
::: solution
由 [[#eq-interval]]，$E_J - E_{J-1} \propto J$，所以比值为 $2/1 = 2$。实测比值为 $(43.40 - 16.40)/16.40 = 1.65$。偏离意味着 ${}^3P$ 能级不是纯 $LS$ 态：自旋–轨道耦合把 ${}^3P_2$ 与 ${}^1D_2$、${}^3P_0$ 与 ${}^1S_0$——$J$ 相同的能级——混合起来，这是二阶效应。能级次序（正序，$J = 0$ 最低）符合洪特第三定则。
:::
:::

::: exercise 钠双线的分裂 {level=2 check="2.13"}
用 [[#ex-sodium-d]] 中的波长，求钠 $3p$ 精细结构分裂（以 meV 计），并用波数（$\mathrm{cm^{-1}}$）表示。
::: solution
$\Delta E = 1239.84\,\mathrm{eV\,nm}\times(1/588.995 - 1/589.592)\,\mathrm{nm^{-1}} = 2.13\,\mathrm{meV}$。用波数表示，$1/\lambda_1 - 1/\lambda_2 = 1.719\times10^{-6}\,\mathrm{nm^{-1}} = 17.2\,\mathrm{cm^{-1}}$（因为 $1\,\mathrm{nm^{-1}} = 10^{7}\,\mathrm{cm^{-1}}$）。
:::
:::

::: exercise 满壳层不携带角动量 {#exr-closed level=3}
证明满子壳层 $nl^{2(2l+1)}$ 有 $L = 0$ 与 $S = 0$。
::: solution
满子壳层中每个自旋轨道 $(m_l, m_s)$ 都被占据，所以恰有一个斯莱特行列式：子壳层是一个单一态。其中 $M_L = \sum m_l = 2\sum_{m=-l}^{l}m = 0$，$M_S = (2l+1)(\frac12 - \frac12) = 0$。这个态具有确定的 $L$ 与 $S$，因为它是该组态的唯一态，而总角动量算符把组态的态映到组态自身之内，所以它必是 $\hat L^2$ 与 $\hat S^2$ 的本征态。若 $L > 0$，它将属于 $M_L$ 不同、共 $2L+1 > 1$ 个态构成的多重态，且都在同一组态内；但并没有别的态。故 $L = 0$，同理 $S = 0$。
:::
:::

::: exercise $d^2$ 的谱项 {level=3}
求两个等价 $d$ 电子的谱项，并验证它们恰给出全部 $\binom{10}{2}$ 个态。
::: hint
照 [[#ex-p2]] 的做法：把每个 $(M_L, M_S)$（$M_L, M_S \ge 0$）的允许态数列表，从最大的 $M_L$ 开始逐个剥离谱项。
:::
::: solution
最大的 $M_L$ 是 $4$，两个电子都在 $m_l = 2$，自旋相反：一个 ${}^1G$（$9$ 个态）。$M_S = 1$ 时最大的 $M_L$ 是 $3$（$m_l = 2, 1$，自旋向上）：一个 ${}^3F$（$7\times3 = 21$ 个态）。数 $M_S = 0$ 时各 $M_L$ 的态：两个电子在不同 $(m_l, m_s)$ 上且 $m_{s1} + m_{s2} = 0$。$M_L = 2$ 时 $m_l$ 的组合是 $(2,0)$ 与 $(1,1)$；$(2,0)$ 给出两种自旋排布，$(1,1)$ 给出一种，共 $3$ 个态。它们被 ${}^1G$（一个）、${}^3F$（一个，它的 $M_S = 0$ 成员）以及一个新谱项 $L = 2$、$S = 0$：${}^1D$ 用掉。$M_S = 1$、$M_L = 1$：组合 $(2,-1)$ 与 $(1,0)$，两个态，一个归 ${}^3F$，另一个给出新的 ${}^3P$。$M_S = 0$、$M_L = 0$：组合 $(2,-2)$、$(1,-1)$ 各两种自旋排布，$(0,0)$ 一种，共 $5$ 个态，被 ${}^1G$、${}^3F$、${}^1D$、${}^3P$ 和最后一个 ${}^1S$ 用掉。

谱项是 ${}^1S$、${}^1D$、${}^1G$、${}^3P$、${}^3F$，共 $1 + 5 + 9 + 9 + 21 = 45 = \binom{10}{2}$ 个态。由洪特定则 ${}^3F$ 最低，与钛的情形一致。
:::
:::

::: exercise 哈特里轨道能量的变分含义 {level=3}
由 [[#thm-hartree]] 证明哈特里总能量不是轨道能量之和：$\langle H\rangle = \sum_i\varepsilon_i - \sum_{i<j}J_{ij}$，其中 $J_{ij}$ 是轨道 $i$ 与 $j$ 之间的库仑积分。解释其物理原因。
::: solution
用 $\phi_i^*$ 乘 [[#eq-hartree]] 并积分：$\varepsilon_i = \langle\phi_i\vert\hat h\vert\phi_i\rangle + \sum_{j\ne i}J_{ij}$，其中 $J_{ij} = \int\!\!\int\lvert\phi_i\rvert^2\lvert\phi_j\rvert^2e^2/4\pi\varepsilon_0r_{12}$。对 $i$ 求和，

$$
\sum_i\varepsilon_i = \sum_i\langle\phi_i\vert\hat h\vert\phi_i\rangle + \sum_i\sum_{j\ne i}J_{ij} = \sum_i\langle\phi_i\vert\hat h\vert\phi_i\rangle + 2\sum_{i<j}J_{ij}.
$$

[[#thm-hartree]] 证明中的期望值里每对排斥只出现一次：$\langle H\rangle = \sum_i\langle\phi_i\vert\hat h\vert\phi_i\rangle + \sum_{i<j}J_{ij}$。两式相减得 $\langle H\rangle = \sum_i\varepsilon_i - \sum_{i<j}J_{ij}$。每个轨道能量都包含该电子与所有其他电子的排斥，所以把轨道能量相加会把每一对数两遍。
:::
:::
