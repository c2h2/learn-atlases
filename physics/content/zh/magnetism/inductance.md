线圈不仅产生磁场。它自己的电流变化时，那个场也随之变化，而法拉第定律会在产生这个场的线圈里送回一份电动势。这一效应叫做自感。继电器里的电流按自己的节拍上升而不是跳到 $\mathcal{E}/R$，断开电感性电路的开关会迸出火花，磁场是一个可以储存能量的地方——原因都在这里。

对线性线圈，度量这一效应的数值是自感 $L$。互感是同一个概念在两个电路之间的情形：一个电路里变化的电流在另一个电路里感应出电动势。两个系数都是几何的——绕组的形状与介质一旦固定，它们也就固定；进入电路方程时，两者都作为正比于 $\dd I/\dd t$ 的电压出现。

本章定义这些系数，计算长螺线管的 $L$，并由建立电流必须输入的功率导出储能 $U = \tfrac{1}{2} L I^2$。然后我们将说明：对理想螺线管，同一份能量正是 $B^2/(2\mu_0)$ 在内部的积分。串联 $RL$ 电路由回路定律求解；理想 $LC$ 电路的解则是通向交流电的桥。法拉第定律本身见 [[magnetism/faraday]]。螺线管的场 $B = \mu_0 n I$ 取自 [[magnetism/biot-savart]]。回路定律就是 [[electrostatics/dc-circuits]] 中使用的那条；电场能 $Q^2/(2C)$ 则是 [[electrostatics/capacitance]] 里 $\tfrac{1}{2} L I^2$ 的搭档。

全章沿用同一个符号约定。沿电路正方向的感应电动势为 $-\dd\Lambda/\dd t$，其中 $\Lambda$ 是按右手定则确定正负的磁链。恒定电感上，沿正电流方向的电势降落是 $L\,\dd I/\dd t$。这两句话说的是同一件事。若在回路方程里放一个负号，又把降落取成 $-L\,\dd I/\dd t$，楞次定律就被算了两次。

## 自感 {#self}

给线圈选一个正绕行方向，并用右手定则取每一匝的正法向。设 $\Phi_1$ 为 $\mathbf{B}$ 穿过一匝的磁通量。若线圈有 $N$ 匝，且每匝穿过的磁通量基本相同，**磁链**就是 $\Lambda = N\Phi_1$。各匝不等价时，就把磁通量逐匝相加；符号 $\Lambda$ 仍指那个总和。磁链的单位是韦伯，与单个磁通量相同。它不是一类新的物理量，只是串联绕组的一种记账方式。

::: definition 自感 {#def-self}
设线圈沿正方向载有电流 $I$，介质是线性的，且没有永磁体。则 $\Lambda$ 正比于 $I$。**自感** $L$ 就是那个比例系数，

$$
L = \frac{\Lambda}{I},
$$ {#eq-L}

于是 $\Lambda = L I$。SI 单位是亨利：$1\,\mathrm{H} = 1\,\mathrm{Wb/A} = 1\,\mathrm{V\,s/A}$。
:::

线性正是让 $L$ 不依赖 $I$ 的那条假设。绕在铁芯上的线圈，若驱动到铁芯饱和的程度，就不止有一个电感值：$\Lambda/I$ 随 $I$ 改变。套住永磁体磁场的线圈在 $I = 0$ 时就有磁链，比值 $\Lambda/I$ 根本就不是合适的对象。这两处失效在能量计算之后的那条 warning 里会重新提起。在此之前，本章每一个 $L$ 都是常量。

定义本身并没有说端钮上出现什么电压。这一点来自法拉第定律，一匝一匝地算。

::: theorem 自感电动势 {#thm-emf}
若自感 $L$ 恒定，沿线圈正方向的感应电动势为

$$
\mathcal{E} = -\frac{\dd\Lambda}{\dd t} = -L\deriv{I}{t}.
$$ {#eq-emf}

在无源符号约定下，沿正电流方向的电势降落为 $v_L = L\,\dd I/\dd t$。
:::

::: proof
按 [[magnetism/faraday]] 中固定的符号，法拉第定律说沿一匝绕行、取正方向的电动势是 $-\dd\Phi_1/\dd t$。$N$ 匝是串联的，所以各匝电动势相加：

$$
\mathcal{E} = -N\deriv{\Phi_1}{t} = -\deriv{\Lambda}{t}.
$$

由[[#def-self]]，$\Lambda = L I$ 且 $L$ 恒定，乘积法则中 $\dd L/\dd t$ 一项不贡献。因此 $\mathcal{E} = -L\,\dd I/\dd t$。

$\mathcal{E}$ 为正时，感应电场沿正方向推电流。沿同一方向测量端电压——顺着电流，从进入的一端量到离开的一端——它是该电动势的负值：电流增大时，电感是负载而不是电源。于是 $v_L = -\mathcal{E} = L\,\dd I/\dd t$。
:::

把[[#eq-emf]]读作关于变化的陈述，而不是关于电流的陈述。稳恒电流无论多大，都有 $\dd I/\dd t = 0$，没有自感电动势。减小的电流有 $\dd I/\dd t < 0$，于是 $\mathcal{E}$ 沿电流方向为正：感应电动势试图维持电流。这就是把楞次定律用到电路自己的场上。正电流的场沿正法向，所以增大的正电流产生增大的正磁通，感应电动势必须为负，才能反抗这一增大。

::: intuition 电流的惯性
磁链扮演的角色相当于动量之于粒子，$L$ 扮演的角色相当于质量。关系式 $v_L = L\,\dd I/\dd t$ 就是用电学符号写出的牛顿第二定律：改变电流需要电压，正如改变速度需要力。下面导出的能量 $\tfrac{1}{2} L I^2$ 是 $\tfrac{1}{2} m v^2$ 的搭档。类比到能量的载体为止。粒子的动能随粒子一起走。磁能在场里，铺展在 $\mathbf{B}$ 不为零的区域，而那片区域未必在导线内部。
:::

电路图里的集总电感，就是把这个对象忘掉内部几何之后的样子：两个端钮，一个数 $L$，外加法则 $v_L = L\,\dd I/\dd t$。当场被束缚在绕组处、所用频率下匝间电容可以忽略、电阻已画成单独的电阻器时，把真实线圈这样建模是合法的。长直导线也有小电感，它不是零。本章的电路里，刻意绕制的线圈占主导，我们就把 $L$ 当作画在图上的那个电感。

## 长螺线管 {#solenoid}

长直螺线管是能用我们已经知道的场把 $L$ 算出来的那个几何。设每米 $n$ 匝、均匀缠绕，长度 $\ell$ 远大于直径，横截面积为 $A$，置于真空中或磁导率为 $\mu_0$ 的线性介质中。把安培定律用于一条矩形安培环路——它在螺线管内部行进、到外部闭合——得

$$
B = \mu_0 n I
$$

内部的场沿轴向、平行于轴线，外部的场被忽略。方向由右手定则给出：四指沿电流，拇指沿 $\mathbf{B}$。这个场的推导见 [[magnetism/biot-savart]]。这里新东西是磁通量，以及由磁通量得到的电感。

::: theorem 长螺线管的电感 {#thm-solenoid}
在刚才陈述的假设下，

$$
L = \mu_0 n^2 A \ell.
$$ {#eq-solenoid}
:::

::: proof
内部的场是均匀的，且垂直于横截面，所以穿过一匝的磁通量是 $\Phi_1 = B A = \mu_0 n I A$。总匝数为 $N = n\ell$，并且因为端部修正已被忽略，每一匝都被赋予同一个磁通量。磁链为

$$
\Lambda = N\Phi_1 = n\ell \cdot \mu_0 n I A = \mu_0 n^2 A \ell\, I.
$$

[[#def-self]]接着除以 $I$。电流约掉了——这正是我们把 $B$ 写成正比于 $I$ 时所假定的线性——于是 $L = \mu_0 n^2 A \ell$。
:::

这个公式对匝数的奖励超过对长度的奖励。长度与面积固定时把 $n$ 加倍，$L$ 变为四倍：匝数加倍，每一匝穿过的场也加倍。$n$ 固定时把 $\ell$ 加倍，$L$ 只加倍，因为新加的长度增加了匝数却不增强 $B$。面积加倍则 $L$ 加倍，因为每一匝收到两倍的磁通，而理想螺线管内部的场不依赖半径。

证明里看得见这个理想化。实验室的螺线管在端部附近场会散开，外部还有一点小场。对长度是直径很多倍的线圈，[[#eq-solenoid]] 是主导项。我们不附加修正因子。需要数值时，理想公式才是与假设匹配的那个，而假设应与数值写在同一句话里。

::: example 螺线管：能量与时间常数 {#ex-solenoid}
一长螺线管 $n = 2000\,\mathrm{m^{-1}}$，横截面积 $A = 4.00\times 10^{-4}\,\mathrm{m^2}$，长度 $\ell = 0.300\,\mathrm{m}$。求 $L$。绕组接着载有 $I = 2.00\,\mathrm{A}$，求储存的能量。把线圈接到电阻 $R = 10.0\,\Omega$ 上，回路中没有其他电阻，求电感时间常数。
::: solution
[[#eq-solenoid]] 配上 $\mu_0 = 4\pi\times 10^{-7}\,\mathrm{H/m}$ 给出

$$
\begin{aligned}
L &= (4\pi\times 10^{-7})(2000)^2(4.00\times 10^{-4})(0.300) \\
&= 1.920\pi\times 10^{-4} \\
&= 6.03186\times 10^{-4}\,\mathrm{H}.
\end{aligned}
$$

保留三位有效数字，$L = 6.03\times 10^{-4}\,\mathrm{H}$。输入量 $A$、$\ell$ 以及下面的电流都以三位有效数字给出；$n = 2000\,\mathrm{m^{-1}}$ 同样作此理解。乘积先不舍入，留待下一步使用，以免能量被舍入两次。

该面积对应直径 $2.26\,\mathrm{cm}$，长度是 $13.3$ 个直径。这足够长，在这道题里理想公式就是正确的模型；又不够长，不能在精密实验中假装端部修正是零。我们报告理想的 $L$。

在 $I = 2.00\,\mathrm{A}$ 下，下面[[#thm-energy]]给出的能量是

$$
U = \frac{1}{2} L I^2 = \frac{1}{2}(6.03186\times 10^{-4})(2.00)^2 = 1.20637\times 10^{-3}\,\mathrm{J},
$$

保留三位有效数字为 $1.21\times 10^{-3}\,\mathrm{J}$。同样的算术也给出磁链：$N = n\ell = 600$ 匝，$B = \mu_0 n I = 5.02655\times 10^{-3}\,\mathrm{T}$，$\Lambda = N B A = 1.20637\times 10^{-3}\,\mathrm{Wb}$。于是 $L = \Lambda/I$ 重新给出 $6.03186\times 10^{-4}\,\mathrm{H}$。这里没有引入任何新假设，只是校核磁通与能量用的是同一个 $L$。

取 $R = 10.0\,\Omega$，[[#eq-tau]]的时间常数为

$$
\tau = \frac{L}{R} = \frac{6.03186\times 10^{-4}}{10.0} = 6.03186\times 10^{-5}\,\mathrm{s},
$$

保留三位有效数字即 $6.03\times 10^{-5}\,\mathrm{s}$。这个回路里的电流按约 $60\,\mu\mathrm{s}$ 的时间尺度增长或衰减，这就是该数字的内容。它还不是某一时刻的电流；那需要[[#rl]]里的解。
:::
:::

## 磁场的能量 {#energy}

在电感中建立电流要做功。做功的施力者是任何维持端电压的东西：电池、充过电的电容器，或者电路的其余部分。磁场把花掉的存在那里，电流下降时再归还。

::: theorem 电感的储能 {#thm-energy}
设 $L$ 恒定，电流从 $0$ 增长到末值 $I$，慢到辐射可以忽略。储存的能量为

$$
U = \frac{1}{2} L I^2.
$$ {#eq-energy}

若之后电流在同一恒定 $L$ 下从 $I_1$ 走到 $I_2$，储能的变化是 $\tfrac{1}{2} L I_2^2 - \tfrac{1}{2} L I_1^2$。
:::

::: proof
当电流为 $I'$、变化率为 $\dd I'/\dd t$ 时，由[[#thm-emf]]，沿电流方向的电势降落是 $v_L = L\,\dd I'/\dd t$。把电流推过这一降落的施力者输入电感的功率为

$$
P = v_L I' = L I'\deriv{I'}{t}.
$$

在时间 $\dd t$ 内输入的能量是 $P\,\dd t = L I'\,\dd I'$。从零电流的起点积分到末电流 $I$：

$$
U = \int_0^{I} L I'\,\dd I' = \frac{1}{2} L I^2,
$$

其中把 $L$ 提到积分号外这一步，在 $L$ 依赖电流时会失效。同样的积分取在 $I_1$ 与 $I_2$ 之间，就是 $\tfrac{1}{2} L I^2$ 两个值之差。准静态假设正是让我们得以忽略电流变化时电磁波带走能量的依据。对本章的电路，变化相对于光走过线圈的时间是慢的，储能就是全部故事。
:::

因子 $\tfrac{1}{2}$ 与 $\tfrac{1}{2} Q^2/C$ 里的因子 $\tfrac{1}{2}$ 同源。过程早期电流还小，功率 $L I\,\dd I/\dd t$ 也小。若自始至终按末值电流充电，代价会是 $L I^2$，恰为真实代价的两倍。斜坡的积分就是三角形的面积。

[[#eq-energy]]是一个电路表达式，只通过 $L$ 知道场的存在。另有一个场的表达式：真空中单位体积 $B^2/(2\mu_0)$。两者都能计算的时候是一致的。对理想螺线管两个都能算。下面那条 warning 所说的正是：在把两个公式当成一个之前，必须真把这个积分做一遍。

::: proposition 螺线管能量与场的积分 {#prop-density}
对[[#thm-solenoid]]的理想长螺线管，真空磁导率为 $\mu_0$，

$$
\int \frac{B^2}{2\mu_0}\,\dd V = \frac{1}{2} L I^2,
$$ {#eq-density}

其中积分遍及内部体积 $A\ell$，外部的贡献已连同外部的场一起忽略。
:::

::: proof
内部 $B = \mu_0 n I$ 是均匀的，所以

$$
\frac{B^2}{2\mu_0} = \frac{\mu_0^2 n^2 I^2}{2\mu_0} = \frac{1}{2}\mu_0 n^2 I^2.
$$

内部体积是 $A\ell$。乘过去，

$$
\int \frac{B^2}{2\mu_0}\,\dd V = \frac{1}{2}\mu_0 n^2 I^2 \cdot A\ell = \frac{1}{2}\bigl(\mu_0 n^2 A\ell\bigr) I^2 = \frac{1}{2} L I^2,
$$

最后一步用了[[#eq-solenoid]]。对[[#ex-solenoid]]的数据，$B = 5.02655\times 10^{-3}\,\mathrm{T}$，$B^2/(2\mu_0) = 10.053\,\mathrm{J/m^3}$。体积为 $A\ell = 1.20\times 10^{-4}\,\mathrm{m^3}$，乘积是 $1.20637\times 10^{-3}\,\mathrm{J}$，与 $\tfrac{1}{2} L I^2$ 同一个值。
:::

这一结论是校核，不是从无到有地导出密度公式。我们假定了 $B^2/(2\mu_0)$，再证明它的积分在这一个几何里重新给出电路能量。在自由空间，对稳恒电流的一般线性分布，同一密度对单个电路确实积分为 $\tfrac{1}{2} L I^2$，对两个电路则积分为下一节的互能表达式。一般论证把场能改写为 $\tfrac{1}{2}\int \mathbf{J}\cdot\mathbf{A}\,\dd V$ 再读出 $L$；那是向量势的内容，不属于本章的电路理论。场的定律要到 [[magnetism/maxwell]] 才组装齐；一般能量恒等式的证明在后面的电动力学课。在那个证明给出之前，$\tfrac{1}{2} L I^2$ 与 $\int B^2/(2\mu_0)\,\dd V$ 只是两个我们已证在理想螺线管相等、而对没有积分过的形状绝不默认相等的量。

::: warning 线性、永磁体与能量积分
$L = \Lambda/I$ 假定了线性介质且没有永磁体。若有磁体穿过线圈，零电流时 $\Lambda$ 就不为零，比值 $\Lambda/I$ 在 $I$ 趋于 $0$ 时发散——尽管线圈是完完全全普通的一个绕组。这时好用的对象是增量电感 $\dd\Lambda/\dd I$，而能量是 $\int I\,\dd\Lambda$，不是 $\tfrac{1}{2}(\Lambda/I) I^2$。

另外，在两者被证一致之前，$\tfrac{1}{2} L I^2$ 并不就是 $B^2/(2\mu_0)$ 的积分。[[#prop-density]]就是对理想螺线管做的那次演示。不重新做一次积分、也不把 $\mu_0$ 换成恰当磁导率，就把密度公式照搬到螺绕环、短线圈或带铁芯的电路上，那是另一回事。铁既在磁化了的材料里存能，也在场里存能；而电路表达式 $\int I\,\dd\Lambda$ 仍然是从端电压直接推出的那一个。
:::

::: quiz
一个电感恒定的线圈载有稳恒正电流，随后电流开始减小。关于自感电动势，哪条说法是对的？
- [ ] 电动势为零，因为电动势需要电流，而电流仍然为正。
- [ ] 电动势反抗电流，所以只要电流为正，它沿电流方向就为负。
- [x] 电动势反抗的是变化。电流在减小时，电动势沿电流方向为正，试图维持电流。
- [ ] 电动势等于 $L I$，符号随电流。
::: solution
[[#eq-emf]]依赖 $\dd I/\dd t$，不依赖 $I$。稳恒电流没有自感电动势。电流减小时 $\dd I/\dd t$ 为负，于是 $-L\,\dd I/\dd t$ 沿电流方向为正。楞次定律反抗的是磁通的变化。它并不针对电流本身，也不偏爱 $I$ 的某种符号。$L I$ 是一个磁链，不是电动势。电动势的单位是伏特；$L I$ 的单位是韦伯。
:::
:::

## 互感 {#mutual}

只要一个电路的磁通穿过另一个，两个电路就共享同一现象。变压器、点火线圈，以及 1831 年 8 月 29 日法拉第那只铁环上的一对绕组，都是互感元件。这个系数有一个从电路图并不显然的对称性：单位 $\dd I_2/\dd t$ 在电路 1 里引起的电动势，等于单位 $\dd I_1/\dd t$ 在电路 2 里引起的电动势。

::: definition 互感 {#def-mutual}
在两个电路上各固定一个正方向。设 $\Lambda_1$ 是电路 1 的磁链、$\Lambda_2$ 是电路 2 的磁链，各沿自己的正方向。在没有永磁体的线性介质中，两个磁链是关于两个电流的齐次线性函数。我们写

$$
\Lambda_1 = L_1 I_1 + M I_2, \qquad \Lambda_2 = M I_1 + L_2 I_2.
$$ {#eq-linkages}

$L_1$ 与 $L_2$ 是自感。公共系数 $M$ 就是**互感**。沿各自正方向的感应电动势为 $\mathcal{E}_1 = -\dd\Lambda_1/\dd t$ 与 $\mathcal{E}_2 = -\dd\Lambda_2/\dd t$。特别地，若 $I_1$ 保持不变，

$$
\mathcal{E}_1 = -M\deriv{I_2}{t},
$$ {#eq-mutual-emf}

若 $I_2$ 保持不变，则 $\mathcal{E}_2 = -M\,\dd I_1/\dd t$。
:::

$M$ 的符号不只是导线本身的属性。它记录的是：电路 2 的正方向与电路 1 中正电流产生的场是否一致。把图上一个箭头调过来，$M$ 就变号。大小是几何的。一个方便的取法是：把两个正方向都取成使磁通相加时 $M > 0$，并在本题余下部分保持这一选择。

[[#def-mutual]]在两个磁链里写了同一个 $M$。那是一条定理，不是两个独立系数的定义。不预先假定结论的做法是：由 $\Lambda_1 = L_1 I_1 + M_{12} I_2$ 引入 $M_{12}$，由 $\Lambda_2 = L_2 I_2 + M_{21} I_1$ 引入 $M_{21}$。下一条结论的内容就是 $M_{12} = M_{21}$。

::: theorem 互感的互易性 {#thm-reciprocity}
对线性介质中的两个电路，没有永磁体，且变化慢到磁能只是瞬时电流的函数，

$$
M_{12} = M_{21}.
$$

取公共值 $M$ 后的储能为

$$
U = \frac{1}{2} L_1 I_1^2 + \frac{1}{2} L_2 I_2^2 + M I_1 I_2.
$$ {#eq-mutual-energy}
:::

::: proof
最终能量绝不能依赖于两个电流建立的先后次序，因为在这些假设下，静磁能由最终的电流固定。

先把 $I_1$ 从 $0$ 升到末值，同时把 $I_2$ 保持在 $0$。电路 2 不载电流，其中感应的电动势不做功。对电路 1 做的功就是[[#thm-energy]]的自感积分，等于 $\tfrac{1}{2} L_1 I_1^2$。

然后保持 $I_1$ 不变，把 $I_2$ 从 $0$ 升到末值。驱动电路 2 的施力者反抗自感降落做功 $\tfrac{1}{2} L_2 I_2^2$。与此同时电路 1 感受到 $\mathcal{E}_1 = -M_{12}\,\dd I_2/\dd t$。要保持 $I_1$ 不变，就得用一个电源电压 $+M_{12}\,\dd I_2/\dd t$ 把那个电动势抵消掉。从那个电源取用的功率是 $I_1 M_{12}\,\dd I_2/\dd t$，$I_2$ 上升期间取用的能量是

$$
\int_0^{I_2} M_{12} I_1\,\dd I_2' = M_{12} I_1 I_2.
$$

按这一先后次序完成后，总能量为 $\tfrac{1}{2} L_1 I_1^2 + \tfrac{1}{2} L_2 I_2^2 + M_{12} I_1 I_2$。

换另一次序重复一遍。交叉项变成 $M_{21} I_2 I_1$，自感项相同。两个总数对每一对末值电流都相等，当且仅当 $M_{12} = M_{21}$。把公共值记作 $M$，能量就是[[#eq-mutual-energy]]。
:::

交叉项可以为负。若 $M$ 为负，或 $M$ 为正而两电流反号，两场部分抵消，能量小于两份自能之和。对一对无源线圈，它不可能变成负的。二次型 $\tfrac{1}{2} L_1 I_1^2 + \tfrac{1}{2} L_2 I_2^2 + M I_1 I_2$ 对一切实电流非负，当且仅当 $L_1 \ge 0$、$L_2 \ge 0$ 且 $M^2 \le L_1 L_2$。最后这个不等式就是耦合的上限。章末的习题要求从能量出发给出那段短论证。比值 $k = M/\sqrt{L_1 L_2}$ 是**耦合系数**，上限即 $\abs{k} \le 1$。完全耦合 $\abs{k} = 1$ 是理想变压器的极限：一个绕组的每条场线都穿过另一个。绕在共用铁芯上的真实线圈接近这一点。相距很远的两个回路 $\abs{k}$ 接近零，$M$ 也随之接近零。

一长螺线管、其中段外面绕一个短次级，是 $M$ 与 $L$ 一样好算的几何。

::: example 短次级线圈的互感 {#ex-mutual}
长初级螺线管 $n_1 = 1000\,\mathrm{m^{-1}}$。次级 $N_2 = 400$ 匝绕在它的中部，缠得足够紧，以致每一匝次级都占有初级的内部面积 $A = 5.00\times 10^{-4}\,\mathrm{m^2}$。次级相对初级很短，所以穿过它的场就是均匀的内部场。求 $M$。若初级电流以 $25.0\,\mathrm{A/s}$ 增大而次级开路，求次级中的电动势。
::: solution
初级的场是 $B_1 = \mu_0 n_1 I_1$。每匝次级收到磁通 $B_1 A$，由初级引起的次级磁链为 $\Lambda_2 = N_2 B_1 A = \mu_0 n_1 N_2 A\, I_1$。这一项里没有 $I_2$。与[[#eq-linkages]]比较，

$$
M = \mu_0 n_1 N_2 A = (4\pi\times 10^{-7})(1000)(400)(5.00\times 10^{-4}) = 8\pi\times 10^{-5}\,\mathrm{H} = 2.513\times 10^{-4}\,\mathrm{H}.
$$

保留三位有效数字，$M = 2.51\times 10^{-4}\,\mathrm{H}$。若愿意用匝密度 $n_2$ 描述长度 $\ell_2$、$N_2 = n_2 \ell_2$ 的次级，同一公式就是 $\mu_0 n_1 n_2 A \ell_2$。

次级开路，所以 $I_2 = 0$ 而且保持为零。[[#eq-mutual-emf]]并不是我们要的次级电动势；那条方程说的是电路 1 的电动势。开路次级上的电动势是

$$
\mathcal{E}_2 = -M\deriv{I_1}{t}.
$$

取 $\dd I_1/\dd t = 25.0\,\mathrm{A/s}$，

$$
\abs{\mathcal{E}_2} = (2.513\times 10^{-4})(25.0) = 6.283\times 10^{-3}\,\mathrm{V},
$$

保留三位有效数字即 $6.28\,\mathrm{mV}$。一旦画出正方向，符号就定了。大小正是开路电压表读出的数。互易性说：若反过来让次级载变化的电流而初级开路，初级电动势对单位 $\dd I_2/\dd t$ 的比值仍是这同一个 $M$。初级匝数多得多、自感也不同，但这些都动摇不了两个互感系数相等。
:::
:::

::: application 断开开关时的火花
历史注记里将要讨论的亨利（Henry）的观察，说的就是电流被切断那一刻的巨大 $\dd I/\dd t$。触点分开的过程中，电流被在短时间内压向零，$\dd I/\dd t$ 大而负，$\mathcal{E} = -L\,\dd I/\dd t$ 便是一个试图维持电流方向的巨大电动势。电压出现在张开的间隙两端，足以维持一道电弧。理想方程 $v_L = L\,\dd I/\dd t$ 本身并不预言电弧电压，因为中断持续的时间由间隙中的等离子体决定，而不是由 $L$ 决定。电感确实定住的是对时间的积分：$\int v_L\,\dd t = -L\,\Delta I$。把电流 $I$ 熄灭就抹掉了磁链 $L I$，开关两端的伏秒面积必须把它计入。在线圈两端并一只二极管或一只电容器，就给这个积分找了一条不是电弧的路径。
:::

## 串联 RL 电路 {#rl}

把一个电阻 $R$、一个电感 $L$ 和一个恒定电源 $\mathcal{E}$ 放进同一个回路，$t = 0$ 时在电流仍为零的情况下合上开关。电流不能跃变。跃变会使 $\dd I/\dd t$ 无穷大，而由[[#thm-emf]]，那需要无穷大的电压，有限的电源提供不了。电流沿 $L/R$ 的时间尺度上升，趋向电阻单独存在时本应允许的值。

::: theorem RL 电路充电时的电流 {#thm-rl}
在恒定 $\mathcal{E}$、$R$ 与 $L$ 构成的串联回路中，若 $I(0) = 0$，

$$
I(t) = \frac{\mathcal{E}}{R}\left(1 - e^{-(R/L) t}\right), \qquad t \ge 0.
$$ {#eq-rl}

**时间常数**为

$$
\tau = \frac{L}{R}.
$$ {#eq-tau}

等价地，$I(t) = I_\infty\bigl(1 - e^{-t/\tau}\bigr)$，其中 $I_\infty = \mathcal{E}/R$。
:::

::: proof
沿正方向绕行回路，也就是我们即将求出的电流的方向。电源贡献一个升高 $\mathcal{E}$。电阻贡献一个降落 $I R$。电感贡献一个降落 $L\,\dd I/\dd t$。回路定律说升高等于降落：

$$
\mathcal{E} = I R + L\deriv{I}{t}.
$$ {#eq-rl-ode}

整理成标准线性方程

$$
\deriv{I}{t} + \frac{R}{L} I = \frac{\mathcal{E}}{L}.
$$

积分因子是 $e^{(R/L) t}$。全式乘以它，

$$
\deriv{}{t}\left(I\, e^{(R/L) t}\right) = \frac{\mathcal{E}}{L}\, e^{(R/L) t}.
$$

从 $0$ 积到 $t$。初始条件 $I(0) = 0$ 消掉了左边的下限，于是

$$
I(t)\, e^{(R/L) t} - 0 = \frac{\mathcal{E}}{R}\left(e^{(R/L) t} - 1\right).
$$

除以积分因子：

$$
I(t) = \frac{\mathcal{E}}{R}\left(1 - e^{-(R/L) t}\right).
$$

组合 $L/R$ 就是指数里那个常量 $\tau$，因为 $(R/L) t = t/\tau$。$t\to\infty$ 时指数项消失，$I\to \mathcal{E}/R$，即电阻接在恒定电源上的稳恒电流。对稳恒电流，电感已经变成了一根完美导体，这与[[#eq-emf]]中的 $\dd I/\dd t = 0$ 相吻合。
:::

在 $t = \tau$，因子 $1 - e^{-1}$ 等于 $0.632$，电流到达末值的约 $63\%$。在 $t = 5\tau$，它到达 $1 - e^{-5} = 0.993$；凡不需要抠掉最后那一个百分点的场合，这就是末值。电阻两端电压是 $I R$，随电流一起上升。电感两端电压是剩下的部分，

$$
v_L = L\deriv{I}{t} = \mathcal{E}\, e^{-t/\tau},
$$

在合闸瞬间最大，此时 $v_L(0) = \mathcal{E}$ 而 $I$ 还是零；到稳恒态它就没了。两个电压在每一时刻相加都得 $\mathcal{E}$，这就是[[#eq-rl-ode]]的变形。这个和是做算术时一个有用的校核。

::: corollary 经电阻放电 {#cor-decay}
若在电流为 $I_0$ 的瞬时把电源撤去，只留电感与 $R$ 串联，则从该瞬时起算的 $t \ge 0$ 内

$$
I(t) = I_0\, e^{-(R/L) t} = I_0\, e^{-t/\tau}.
$$ {#eq-decay}
:::

::: proof
回路定律就是[[#eq-rl-ode]]取 $\mathcal{E} = 0$，于是 $\dd I/\dd t = -(R/L) I$。解是指数函数。条件 $I(0) = I_0$ 定出系数，给出[[#eq-decay]]。储能 $\tfrac{1}{2} L I_0^2$ 离场而去，在电阻中耗散掉。再也没有剩下的电源来供给稳恒电流了。
:::

::: widget plot
f: 1-exp(-x)
x: 0, 5
caption: 串联 RL 电路在开关闭合后的电流，时间以时间常数为单位。纵轴是 I/I∞ = 1 − exp(−t/τ)，横轴是 t/τ。曲线在合闸瞬间过 0，在一个时间常数处过 1 − 1/e ≈ 0.63。到 x = 5 时，它与末值的差距已不到百分之一。这里没有滑条：一旦时间以 τ = L/R 为单位来度量，任何 R 与 L 的形状都相同。
:::

坐标轴一经缩放，图就是[[#eq-rl]]的全部内涵。改变 $R$ 或 $L$ 会改变 $\tau$、改变 $I_\infty$，但在这些单位下不改变图像本身。$\tau$ 过后很久仍接近零、或在 $t = 0$ 发生跃变的实测电流，就不是这个电路。

能量账是平的。把[[#eq-rl-ode]]乘以 $I$：

$$
\mathcal{E} I = I^2 R + L I\deriv{I}{t} = I^2 R + \deriv{}{t}\left(\frac{1}{2} L I^2\right).
$$

电源的功率在每一时刻拆成两份：电阻里的热，与场能的生长。从合闸积到任一稍后时刻 $t$，

$$
\int_0^{t} \mathcal{E} I\,\dd t' = \int_0^{t} I^2 R\,\dd t' + \frac{1}{2} L I(t)^2,
$$ {#eq-balance}

因为 $I(0) = 0$。这个恒等式里没有一处需要显式解。解只是让我们能把三项算出来。

::: example 按已知时间常数上升的电流 {#ex-rl}
串联电路有 $\mathcal{E} = 12.0\,\mathrm{V}$、$R = 30.0\,\Omega$、$L = 0.150\,\mathrm{H}$。$t = 0$ 时合闸，$I = 0$。求 $\tau$、末值电流、$t = \tau$ 时的电流与两个电压，以及到该时刻为止电阻与电感之间能量的分配。
::: solution
时间常数与末值电流为

$$
\tau = \frac{L}{R} = \frac{0.150}{30.0} = 5.00\times 10^{-3}\,\mathrm{s}, \qquad I_\infty = \frac{12.0}{30.0} = 0.400\,\mathrm{A}.
$$

在 $t = \tau$，由[[#eq-rl]]得

$$
I(\tau) = 0.400\bigl(1 - e^{-1}\bigr) = 0.400\times 0.632121 = 0.2528\,\mathrm{A}.
$$

电阻电压为 $I R = 7.585\,\mathrm{V}$。电感电压为 $\mathcal{E}\, e^{-1} = 4.415\,\mathrm{V}$。两者相加得 $12.00\,\mathrm{V}$，正是电源。保留三位有效数字，电流为 $0.253\,\mathrm{A}$，两个电压为 $7.59\,\mathrm{V}$ 与 $4.41\,\mathrm{V}$；这里多留一位，是为了让与 $12.0\,\mathrm{V}$ 的校核不被舍入破坏。

该时刻的场能为

$$
U(\tau) = \frac{1}{2}(0.150)(0.2528)^2 = 4.795\times 10^{-3}\,\mathrm{J}.
$$

许多个时间常数之后，末值场能为 $\tfrac{1}{2}(0.150)(0.400)^2 = 1.20\times 10^{-2}\,\mathrm{J}$。一个时间常数处，场持有其末值的 $(1 - e^{-1})^2 = 0.3996$，约 $40\%$，而不是 $63\%$。能量跟着 $I^2$ 走，而 $0.632^2$ 不等于 $0.632$。

至于热量，取标度 $u = t/\tau$。于是

$$
\int_0^{\tau} I^2 R\,\dd t = R I_\infty^2 \tau \int_0^{1} \bigl(1 - e^{-u}\bigr)^2\,\dd u.
$$

该定积分等于 $2e^{-1} - \tfrac{1}{2}e^{-2} - \tfrac{1}{2} = 0.16809$。前置因子是 $30.0\times(0.400)^2\times 5.00\times 10^{-3} = 2.40\times 10^{-2}\,\mathrm{J}$。热量为 $4.034\times 10^{-3}\,\mathrm{J}$。电源已供给

$$
\int_0^{\tau} \mathcal{E} I\,\dd t = \mathcal{E} I_\infty \tau \int_0^{1}\bigl(1 - e^{-u}\bigr)\,\dd u = (2.40\times 10^{-2})\, e^{-1} = 8.829\times 10^{-3}\,\mathrm{J}.
$$

热加场能为 $4.034\times 10^{-3} + 4.795\times 10^{-3} = 8.829\times 10^{-3}\,\mathrm{J}$，与电源一致。[[#eq-balance]]对这一组数值分配成立，而不只是作为形式恒等式成立。到一整个时间常数为止，从电池取出的能量有一半略多一点在场里，其余的已经加热了电阻。等到无穷久则另当别论，因为此后电池还将永远供给 $I_\infty^2 R$，而场能停在 $1.20\times 10^{-2}\,\mathrm{J}$ 不动。
:::
:::

## LC 电路 {#lc}

把电阻和电池换成一个电容器。回路里就只剩 $L$ 和 $C$。电流给电容器充电，电容器电压顶回来，电流反向，能量从磁场搬到电场，再搬回来。没有电阻，能量就无处可去。这一运动就是弹簧上挂质量块的电学副本。

::: theorem 理想 LC 振荡 {#thm-lc}
设电容 $C$ 与电感 $L$ 都恒定，组成一个电阻可忽略的回路。设 $Q$ 是正极性电流流向的那块极板上的电荷，于是 $I = \dd Q/\dd t$。则

$$
\deriv{^2 Q}{t^2} + \frac{1}{LC} Q = 0.
$$ {#eq-lc}

通解为 $Q(t) = A\cos\omega t + B\sin\omega t$，其中

$$
\omega = \frac{1}{\sqrt{LC}}.
$$ {#eq-omega-lc}

量

$$
U = \frac{1}{2} L I^2 + \frac{Q^2}{2C}
$$

守恒。
:::

::: proof
沿 $I$ 方向电感的降落是 $L\,\dd I/\dd t$。同一方向电容器的降落是 $Q/C$，因为 $Q$ 定义为电流流去的那块极板上的电荷，$Q > 0$ 时那正是电势较高的极板。没有电源，也没有电阻。回路定律是

$$
L\deriv{I}{t} + \frac{Q}{C} = 0.
$$

代入 $I = \dd Q/\dd t$：

$$
L\deriv{^2 Q}{t^2} + \frac{Q}{C} = 0,
$$

这就是[[#eq-lc]]。这是简谐方程。二阶导数是自身的负常数倍的函数，就是 $\omega t$ 的正弦与余弦，其中 $\omega^2 = 1/(LC)$，$\omega$ 取正值，即[[#eq-omega-lc]]。两个常数 $A$ 与 $B$ 由初始电荷和初始电流定出。

对所设能量求导。由 $I = \dd Q/\dd t$，

$$
\deriv{U}{t} = L I\deriv{I}{t} + \frac{Q}{C}\deriv{Q}{t} = I\left(L\deriv{I}{t} + \frac{Q}{C}\right) = 0,
$$

最后一步用了回路定律。恒等于零的导数就是一个运动常数。电流为零的时刻，能量全在电容器里；电荷为零的时刻，能量全在电感里。振荡以角频率 $\omega$ 在两者之间交换。
:::

周期是 $T = 2\pi\sqrt{LC}$。电阻非零时，回路定律多出 $R\,\dd Q/\dd t$ 一项，振荡随之衰减。那个阻尼电路再配上交变电源的驱动，就是 [[magnetism/ac-circuits]] 的主题。角频率[[#eq-omega-lc]]在那里作为共振频率保留下来。

::: example 能量在 L 与 C 之间往返 {#ex-lc}
电感 $L = 80.0\,\mathrm{mH}$ 接在电容 $C = 2.00\,\mu\mathrm{F}$ 的两端。$t = 0$ 时电容器电荷为 $Q_0 = 50.0\,\mu\mathrm{C}$，电流为零。求角频率、以赫兹计的频率、周期、守恒的能量以及最大电流。
::: solution
由[[#eq-omega-lc]]得

$$
\omega = \frac{1}{\sqrt{(0.0800)(2.00\times 10^{-6})}} = \frac{1}{\sqrt{1.60\times 10^{-7}}} = 2.50\times 10^{3}\,\mathrm{rad/s},
$$

因为 $(4.00\times 10^{-4})^2 = 1.60\times 10^{-7}$。频率与周期为

$$
f = \frac{\omega}{2\pi} = 397.9\,\mathrm{Hz}, \qquad T = \frac{2\pi}{\omega} = 2.513\times 10^{-3}\,\mathrm{s}.
$$

保留三位有效数字，$f = 398\,\mathrm{Hz}$，$T = 2.51\,\mathrm{ms}$。

初始电流为零，所以[[#thm-lc]]给出 $Q(t) = Q_0\cos\omega t$。$t = 0$ 时能量全是电的：

$$
U = \frac{Q_0^2}{2C} = \frac{(5.00\times 10^{-5})^2}{2\times 2.00\times 10^{-6}} = 6.25\times 10^{-4}\,\mathrm{J}.
$$

它就停在这个值上。当 $Q = 0$ 时整个 $U$ 都是 $\tfrac{1}{2} L I_{\max}^2$，于是

$$
I_{\max} = \sqrt{\frac{2U}{L}} = \sqrt{\frac{1.25\times 10^{-3}}{0.0800}} = \sqrt{0.015625} = 0.125\,\mathrm{A}.
$$

对电荷求导给出同一个数：$I = \dd Q/\dd t = -\omega Q_0\sin\omega t$，而 $\omega Q_0 = (2.50\times 10^{3})(5.00\times 10^{-5}) = 0.125\,\mathrm{A}$。负号是说正的初始电荷开始减少，所以在使 $Q$ 增大的方向上初始电流为负。最大的大小为 $0.125\,\mathrm{A}$。
:::
:::

## 后续内容 {#leads}

[[magnetism/ac-circuits]] 用交变电源驱动 $R$、$L$、$C$ 的串联组合。[[#eq-omega-lc]]的 $LC$ 共振成为电流最大的频率，而[[#eq-rl]]的 $RL$ 暂态变成解中短命的部分，在稳态振荡成为全部之前就已经死去。当每个电压都是正弦的时候，阻抗就是把 $L\,\dd I/\dd t$ 与电容器电压加到 $IR$ 上所用的语言。

[[magnetism/maxwell]] 问的是导线周围的空间里正在发生什么。[[#prop-density]]中的恒等式是第一点暗示：记在 $L$ 名下的能量其实在场里。位移电流与波动方程，正是这一暗示长大后变成的样子。一个变压器若认真处理，就是两个 $\abs{k}$ 很大的耦合电感，而不是一条新的定律。

机械类比仍然有用，也仍然不完整。质量像 $L$，劲度系数像 $1/C$，摩擦像 $R$。[[oscillations/simple-harmonic]] 与 [[oscillations/resonance]] 是换了名词的同一组微分方程。它们不包含的，是互感的符号，以及 $M^2$ 不能超过 $L_1 L_2$ 的要求。

::: history 亨利、法拉第与系数之名
1831 年 8 月 29 日，法拉第（Faraday）借助一只铁环上的两个绕组发现：一个电路中变化的电流会在另一个电路中感应出电流。这就是互感。定律陈述于 [[magnetism/faraday]]。自感是同一条定律由同一个电路分饰两角的情形。

约瑟夫·亨利（Joseph Henry）于 1832 年在《美国科学杂志》（*American Journal of Science*）上发表了自感效应，论文标题是《论由磁产生电流与电火花》（"On the Production of Currents and Sparks of Electricity from Magnetism"）。一根长线圈导体载着电池提供的电流，在电路断开的一瞬间产生火花；同样条件下短导线则不能。他把火花归因于长导线对自身的反作用。电感的 SI 单位就因这项工作得名。这里不引用他论文中的任何一句话。

麦克斯韦（Maxwell）的《电磁通论》（*A Treatise on Electricity and Magnetism*，1873 年）把自感系数安置进场论之中，使它成为电路系统描述的一部分。inductance 一词本身出现得更晚。赫维赛德（Heaviside）在 19 世纪 80 年代引入它作为那个系数的名字，与电容（capacitance）、阻抗（impedance）并列。亨利发现了现象。麦克斯韦把它建成理论的一部分。赫维赛德给出了本章使用的名字。上面的电路公式是这一发展的本科形态，不是三人中任何一篇论文的转录。
:::

::: summary
- 对没有永磁体的线性线圈，磁链为 $\Lambda = L I$，$L$ 是以亨利计的自感。
- 沿正方向的感应电动势为 $\mathcal{E} = -L\,\dd I/\dd t$。沿电流方向的电势降落为 $v_L = L\,\dd I/\dd t$。不要同时写入两个负号。
- 真空中的长螺线管有 $L = \mu_0 n^2 A \ell$。把匝密度加倍，$L$ 变为四倍。
- 从零建立电流储存 $U = \tfrac{1}{2} L I^2$。对理想螺线管，这等于 $B^2/(2\mu_0)$ 在内部的积分，而这一一致必须证明，不能默认。
- 互感满足 $\mathcal{E}_1 = -M\,\dd I_2/\dd t$ 且 $M_{12} = M_{21}$。能量为 $\tfrac{1}{2} L_1 I_1^2 + \tfrac{1}{2} L_2 I_2^2 + M I_1 I_2$，且 $\abs{M} \le \sqrt{L_1 L_2}$。
- 串联 $RL$ 电路在 $I = 0$ 时接到恒定电源上，按 $I = (\mathcal{E}/R)(1 - e^{-t/\tau})$ 上升，其中 $\tau = L/R$。从 $I_0$ 放电为 $I_0 e^{-t/\tau}$。
- 每一时刻都有 $\mathcal{E} I = I^2 R + \dd(\tfrac{1}{2} L I^2)/\dd t$。电源为热和场付账。
- 理想 $LC$ 回路以 $\omega = 1/\sqrt{LC}$ 振荡，$\tfrac{1}{2} L I^2 + Q^2/(2C)$ 守恒。电阻与交变电源是下一章的内容。
:::

## 习题 {#exercises}

::: exercise 较长螺线管的电感 {level=1 check="4*pi*1e-7*1500^2*2.5e-4*0.8"}
一长螺线管 $n = 1500\,\mathrm{m^{-1}}$，横截面积 $A = 2.50\times 10^{-4}\,\mathrm{m^2}$，长度 $\ell = 0.800\,\mathrm{m}$。求以亨利计的 $L$。接受精确表达式。
::: solution
[[#eq-solenoid]]可直接应用。介质就是公式所指的真空，而题目已声明螺线管是长的。

$$
L = \mu_0 n^2 A \ell = (4\pi\times 10^{-7})(1500)^2(2.50\times 10^{-4})(0.800).
$$

先算 $1500^2 = 2.25\times 10^{6}$。接着 $2.25\times 10^{6}\times 2.50\times 10^{-4} = 562.5$，而 $562.5\times 0.800 = 450$。最后

$$
L = 450\times 4\pi\times 10^{-7} = 1.80\pi\times 10^{-4} = 5.655\times 10^{-4}\,\mathrm{H}.
$$

保留三位有效数字，$L = 5.65\times 10^{-4}\,\mathrm{H}$。精确值就是第一行写出的乘积。电流没有出场。在线性假设下，自感是绕组与介质的属性，而不是恰好流过的电流的属性。
:::
:::

::: exercise 已知电感中的能量 {level=1 check="0.5*0.25*0.8^2"}
电感 $L = 0.250\,\mathrm{H}$ 载有稳恒电流 $I = 0.800\,\mathrm{A}$。求以焦耳计的储能。
::: solution
[[#eq-energy]]取 $L$ 恒定，得

$$
U = \frac{1}{2} L I^2 = \frac{1}{2}(0.250)(0.800)^2 = \frac{1}{2}(0.250)(0.640) = 0.0800\,\mathrm{J}.
$$

电流是稳恒的，所以自感电动势为零，没有功率进入电感。能量是在电流建立期间存进去的，并随电流一起在场中留存。把电流切断——按[[#cor-decay]]的放电或任何别的路径——就把那 $0.0800\,\mathrm{J}$ 交还给电路。
:::
:::

::: exercise 时间常数 {level=1 check="0.15/30"}
串联 $RL$ 电路有 $L = 0.150\,\mathrm{H}$、$R = 30.0\,\Omega$。求以秒计的时间常数 $\tau$。
::: solution
[[#eq-tau]]就是出现在[[#eq-rl]]与[[#eq-decay]]指数里的那个比值：

$$
\tau = \frac{L}{R} = \frac{0.150}{30.0} = 5.00\times 10^{-3}\,\mathrm{s}.
$$

不需要电源电压。尽管末值电流 $\mathcal{E}/R$ 未知，时间常数已由 $L$ 与 $R$ 固定。一个充电电流经过一个时间常数达到其末值的 $1 - e^{-1}$，一个放电电流衰减到其初值的 $e^{-1}$。两条说的都是同一个 $\tau$。
:::
:::

::: exercise 达到末值电流一半所需的时间 {level=2 check="0.005*ln(2)"}
上一题的电路在 $t = 0$ 接到恒定电源上，$I(0) = 0$。时间常数为 $5.00\,\mathrm{ms}$。求电流达到末值一半的时刻，以秒计。
::: hint
:::
令 $1 - e^{-t/\tau} = 1/2$ 并解出 $t$。电源电压在比值 $I/I_\infty$ 中被约掉。
::: solution
由[[#thm-rl]]，

$$
\frac{I(t)}{I_\infty} = 1 - e^{-t/\tau}.
$$

末值电流的一半意味着左边等于 $1/2$：

$$
e^{-t/\tau} = \frac{1}{2}, \qquad \frac{t}{\tau} = \ln 2, \qquad t = \tau\ln 2.
$$

取 $\tau = 5.00\times 10^{-3}\,\mathrm{s}$，

$$
t = (5.00\times 10^{-3})\ln 2 = 3.466\times 10^{-3}\,\mathrm{s}.
$$

保留三位有效数字，$t = 3.47\,\mathrm{ms}$。结果比一个时间常数略短，因为 $1 - e^{-1} = 0.632$ 已经过半。电源电压与末值电流的数值从不进场。给定的 $\tau$ 之下，任何恒定的 $\mathcal{E}$ 都给出同一个 $t$。
:::
:::

::: exercise 电流被截断期间的平均电动势 {level=2 check="0.004*3/0.002"}
电感 $L = 4.00\,\mathrm{mH}$ 载有 $3.00\,\mathrm{A}$。电流在 $2.00\,\mathrm{ms}$ 内均匀降到零。求该期间感应电动势的平均大小，以伏特计。
::: solution
每一时刻的[[#eq-emf]]为 $\mathcal{E} = -L\,\dd I/\dd t$。在有限区间上 $\dd I/\dd t$ 的平均值是 $\Delta I/\Delta t$，所以平均电动势是 $-L\,\Delta I/\Delta t$。这里 $\Delta I = 0 - 3.00 = -3.00\,\mathrm{A}$，$\Delta t = 2.00\times 10^{-3}\,\mathrm{s}$：

$$
\abs{\mathcal{E}_{\mathrm{avg}}} = L\frac{\abs{\Delta I}}{\Delta t} = (4.00\times 10^{-3})\frac{3.00}{2.00\times 10^{-3}} = 6.00\,\mathrm{V}.
$$

用变化量之比代替导数的平均值时，用到了均匀下降。一个在 $3.00\,\mathrm{A}$ 附近徘徊、到最后一刻才崩塌的电流，会有同样的 $\Delta I$ 与同样的平均电动势，但峰值大得多。平均值只固定伏秒面积 $L\abs{\Delta I} = 1.20\times 10^{-2}\,\mathrm{V\,s}$。初始储能是另一个量，$\tfrac{1}{2}(4.00\times 10^{-3})(3.00)^2 = 1.80\times 10^{-2}\,\mathrm{J}$，求电动势并不需要它。
:::
:::

::: exercise 开路次级中的电动势 {level=2 check="4*pi*1e-7*1000*400*5e-4*25"}
使用[[#ex-mutual]]的线圈：$n_1 = 1000\,\mathrm{m^{-1}}$，$N_2 = 400$，$A = 5.00\times 10^{-4}\,\mathrm{m^2}$。初级电流以恒定 $25.0\,\mathrm{A/s}$ 上升，次级开路。求次级电动势的大小，以伏特计。
::: solution
由那个已解例题，或用同样一行论证，

$$
M = \mu_0 n_1 N_2 A = (4\pi\times 10^{-7})(1000)(400)(5.00\times 10^{-4}) = 2.513\times 10^{-4}\,\mathrm{H}.
$$

次级电流为零，所以次级上没有自感贡献。互感电动势的大小为

$$
\abs{\mathcal{E}_2} = M\left\lvert\deriv{I_1}{t}\right\rvert = (2.513\times 10^{-4})(25.0) = 6.283\times 10^{-3}\,\mathrm{V}.
$$

精确值是 $M$ 乘以 $25.0$，其中 $M = \mu_0 n_1 N_2 A$。三位有效数字给出 $6.28\times 10^{-3}\,\mathrm{V}$。次级开路正是这一测量成为纯互感测量的原因：闭合的次级会载感应电流，而那电流会贡献它自己的磁通。
:::
:::

::: exercise 耦合上限 {level=3}
假设 $L_1 > 0$、$L_2 > 0$，并假设储能

$$
U = \frac{1}{2} L_1 I_1^2 + \frac{1}{2} L_2 I_2^2 + M I_1 I_2
$$

对每一对实数 $(I_1, I_2)$ 非负。证明 $M^2 \le L_1 L_2$。定义耦合系数 $k = M/\sqrt{L_1 L_2}$ 并推出 $\abs{k} \le 1$。
::: hint
:::
能量是两个电流的二次型。对 $I_1$ 配方，或要求把 $U$ 看作比值 $I_1/I_2$ 的二次函数时，判别式取使 $U$ 不越过零号的符号。一个巧妙选定的比值就够了。
::: solution
固定任意的电流 $I_2$，把 $U$ 看作 $I_1$ 的二次函数。若 $I_2 = 0$，则对每个 $I_1$ 有 $U = \tfrac{1}{2} L_1 I_1^2 \ge 0$，这已经由 $L_1 > 0$ 保证。现在取 $I_2 \ne 0$，令 $x = I_1/I_2$。则

$$
U = I_2^2\left(\frac{1}{2} L_1 x^2 + M x + \frac{1}{2} L_2\right).
$$

因子 $I_2^2$ 为正，所以关于 $x$ 的二次式必须对一切实数 $x$ 非负。首项系数为正的二次式 $\tfrac{1}{2} L_1 x^2 + M x + \tfrac{1}{2} L_2$ 对一切 $x$ 保持非负，当且仅当其判别式非正：

$$
M^2 - 4\cdot\frac{1}{2} L_1\cdot\frac{1}{2} L_2 \le 0,
$$

即 $M^2 - L_1 L_2 \le 0$，或 $M^2 \le L_1 L_2$。除以正数 $L_1 L_2$ 得 $k^2 \le 1$，故 $\abs{k} \le 1$。

等号可以取到。若 $M = \sqrt{L_1 L_2}$，取 $x = -M/L_1$ 使二次式为零，于是存在一个电流比值使两场储存的能量为零。那是反向串联意义下的完全耦合。反之，若 $\abs{M}$ 超过 $\sqrt{L_1 L_2}$，同样的代数会对某些电流给出负的 $U$，而一对无源线性线圈做不到这一点。上限是尖锐的，它是对几何的限制，不是额外的电路元件。
:::
:::

::: exercise 同轴电缆的电感 {level=3 check="(4*pi*1e-7)*5/(2*pi)*ln(4)"}
同轴电缆作如下理想化。内导体是半径 $a$ 的薄圆柱壳，电流 $I$ 沿其圆周均匀分布。回程电流 $-I$ 在半径 $b > a$ 的薄圆柱壳上。壳层之间是真空，外导体之外场为零。用安培定律导出长度 $\ell$ 的 $L$。再证明 $\int B^2/(2\mu_0)\,\dd V$ 在两壳之间的区域上等于 $\tfrac{1}{2} L I^2$。对 $a = 2.00\,\mathrm{mm}$、$b = 8.00\,\mathrm{mm}$、$\ell = 5.00\,\mathrm{m}$，求以亨利计的 $L$。
::: hint
:::
对 $a < r < b$，被包围的电流是 $I$，所以 $B = \mu_0 I/(2\pi r)$。穿过两壳之间一块长 $\ell$ 的纵向矩形的磁通量，就是去—回这个单回路的磁链。内自感不存在，因为电流已被放在导体表面上。
::: solution
对以轴线为中心、半径 $r$ 的圆用安培定律，得 $B\cdot 2\pi r = \mu_0 I_{\mathrm{enc}}$。$r < a$ 时圆不包围电流，所以 $B = 0$。$a < r < b$ 时圆包围 $I$，所以

$$
B = \frac{\mu_0 I}{2\pi r},
$$

沿方位角方向，转向按内电流的右手定则。$r > b$ 时被包围的电流是 $I - I = 0$，所以 $B = 0$。

长度 $\ell$ 的磁链，是这一 $\mathbf{B}$ 穿过一张从 $r = a$ 到 $r = b$、沿电缆长 $\ell$ 的矩形面的磁通量。$\mathbf{B}$ 垂直于该矩形。因此

$$
\Lambda = \int_a^{b} B\,\ell\,\dd r = \frac{\mu_0 I \ell}{2\pi}\int_a^{b}\frac{\dd r}{r} = \frac{\mu_0 I \ell}{2\pi}\ln\frac{b}{a}.
$$

去—回是一个单回路，所以这一磁通量就是全部磁链。[[#def-self]]给出

$$
L = \frac{\Lambda}{I} = \frac{\mu_0 \ell}{2\pi}\ln\frac{b}{a}.
$$

能量积分中只有 $a < r < b$ 有贡献。半径 $r$、厚度 $\dd r$、长 $\ell$ 的圆柱壳体积是 $2\pi r\,\ell\,\dd r$，于是

$$
\int \frac{B^2}{2\mu_0}\,\dd V = \int_a^{b} \frac{1}{2\mu_0}\left(\frac{\mu_0 I}{2\pi r}\right)^2 2\pi r \ell\,\dd r = \int_a^{b} \frac{\mu_0 I^2 \ell}{4\pi r}\,\dd r = \frac{\mu_0 I^2 \ell}{4\pi}\ln\frac{b}{a}.
$$

右边正是把刚得到的 $L$ 代入的 $\tfrac{1}{2} L I^2$。这一几何的电路能量与场积分相符，正如[[#prop-density]]里螺线管的情形——靠的是直接计算，而不是援引一般定理。

取 $b/a = 4$、$\ell = 5.00\,\mathrm{m}$，

$$
L = \frac{(4\pi\times 10^{-7})(5.00)}{2\pi}\ln 4 = (1.00\times 10^{-6})\ln 4 = 1.386\times 10^{-6}\,\mathrm{H}.
$$

保留三位有效数字，$L = 1.39\times 10^{-6}\,\mathrm{H}$。若是实心内导线、电流铺满其截面，还会添上内自感 $\mu_0 \ell/(8\pi)$，而这一表面电流理想化把它略去了。题目求的是外电感，上面的数值就是。
:::
