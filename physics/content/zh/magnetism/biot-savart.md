在指南针附近把电流接通，磁针就会转动。磁针不是像电荷被另一个电荷吸引那样被拉向导线的；它是被扭动，而电流反向时扭动也反向。[[magnetism/magnetic-force]]把这个扭动写成磁场 $\vec{B}$ 作用在一个运动电荷上、或作用在另一股电流上。本章要由产生 $\vec{B}$ 的那些电流把 $\vec{B}$ 建造出来。

干活的是两条定律。毕奥–萨伐尔定律是一小段电流元的平方反比律：它对稳恒电流总是适用，用它就意味着做积分。安培定律是关于 $\vec{B}$ 绕闭曲线环量的陈述。它是 [[electrostatics/gauss-law]] 中高斯定律的磁学伙伴。与高斯定律一样，它在自己的假设之下永远为真，但只有当对称性已经把方向和随位置的依赖都定死时，它才把场以封闭形式交给你。我们用第一条定律导出圆环与直导线的场，用第二条重新得到直导线的场，并处理螺线管与螺绕环。

全章电流都是稳恒的，导线静止，区域是真空。随时间变化的电流，以及磁性材料内部的场，都是后面的事。我们使用的常量是

$$
\mu_0 = 4\pi\times 10^{-7}\,\mathrm{T\,m/A}.
$$ {#eq-mu0}

这个常量是真空磁导率。有两个组合出现得太过频繁，值得记住。因为 $\mu_0$ 含有因子 $4\pi$，

$$
\frac{\mu_0}{4\pi} = 1.00\times 10^{-7}\,\mathrm{T\,m/A}, \qquad \frac{\mu_0}{2\pi} = 2.00\times 10^{-7}\,\mathrm{T\,m/A}.
$$

其中第二个就是长直导线磁场公式里的全部常量。特斯拉这个单位早已被力律固定：一特斯拉的磁场，对一根垂直于场、载有一安培电流的一米长导线，施加一牛顿的力。

## 毕奥–萨伐尔定律

电流有方向，所以磁学定律里的源不是标量的电荷块，而是一小段有方向的电流。设细导线载有稳恒电流 $I$。在导线上的一点，$\dd\vec{l}$ 是沿导线、沿电流方向的无限小位移，$\vec{r}$ 是由那一小段电流画向所求场点的向量。记 $r = \abs{\vec{r}}$、$\hat{r} = \vec{r}/r$。

::: definition 毕奥–萨伐尔定律 {#def-biot}
电流元 $I\,\dd\vec{l}$ 在 $\vec{r}$ 的尖端处产生的磁场为

$$
\dd\vec{B} = \frac{\mu_0}{4\pi}\frac{I\,\dd\vec{l}\times\hat{r}}{r^2}.
$$ {#eq-biot}

整个回路产生的场，是[[#eq-biot]]沿回路的向量积分。对于稳恒电流密度 $\vec{J}$ 的体分布，把 $I\,\dd\vec{l}$ 换成 $\vec{J}\,\dd V$，积分对整个体积进行。
:::

这个叉积就是本定律与库仑定律在形状上的全部差别。[[electrostatics/coulomb]]里，一个标量电荷向外发出沿径向的场。这里 $\dd\vec{l}\times\hat{r}$ 同时垂直于电流和由电流元指向场点的连线，所以 $\dd\vec{B}$ 从不沿 $\vec{r}$。电流产生的磁场线没有起点也没有终点。它们闭合，或者在下面这些理想化的问题里延伸到无穷远。

$\dd\vec{l}\times\hat{r}$ 的方向就是叉积的右手定则，它是与我们如何给坐标轴定向绑在一起的约定，不是一条第二物理定律。右手四指沿 $\dd\vec{l}$，扫向 $\hat{r}$，拇指给出 $\dd\vec{B}$。对长直导线，同样的定则收缩成一个握法：拇指沿电流，四指弯曲的方向就是 $\vec{B}$。我们始终使用同一个定则。电流反向，$\vec{B}$ 也反向。

叠加原理已经包含在积分里。几个回路产生的总场是各场的向量叠加。[[#eq-biot]]里没有对电流的二次项，所以把所有电流加倍就把 $\vec{B}$ 加倍。

这一定律——按我们的用法——要求稳恒电流。沿一根细导线，稳恒意味着电荷不在任何地方堆积，所以同一根导线每个横截面上的 $I$ 都相同。若电流随时间变化，远处一点的场无法立刻响应，还必须加上辐射场。那个范围在本章之外。稳恒定律是磁静力学的极限，安培定律写成下面这个形式也正是这个极限。

::: intuition 必须闭合的磁场线
为一个电流元画出 $\dd\vec{B}$，你得到绕 $\dd\vec{l}$ 的一圈小小的方向。对一根直导线，这些小小的圈彼此一致，磁场线就是以导线为心的圆。这些线没有可以安放磁荷的端头。绕导线走一圈，你总是顺着场走或者总是逆着场走，这就是环量定律恰好是[[#eq-biot]]的天然搭档的原因。点电荷的电场则正相反：绕电荷走一圈什么也得不到，因为场沿径向，它的天然搭档是通量定律。
:::

## 圆环轴线上的磁场

我们执行的第一个积分是圆形回路，而且只在轴线上。离开轴线，这个积分不能化成初等函数。在轴线上，对称性除了沿轴线的分量外把其余分量全部消掉，大小则是距离的有理函数。

::: theorem 圆电流轴线上的磁场 {#thm-loop}
半径 $R$ 的圆形回路载有稳恒电流 $I$。把回路放在 $xy$ 平面内，圆心在原点，电流的环绕方向，从正 $z$ 轴看过去是逆时针。在点 $(0,0,z)$，磁场沿 $z$ 轴，且

$$
B_z = \frac{\mu_0 I R^2}{2\left(R^2 + z^2\right)^{3/2}}.
$$ {#eq-loop}

正号意味着 $\vec{B}$ 在圆环两侧都指向 $+z$ 方向。在圆心处，

$$
B = \frac{\mu_0 I}{2R}.
$$ {#eq-centre}

若 $N$ 匝缠绕得足够紧，可以当作一个半径为 $R$ 的单匝圆环处理，两个表达式都乘以 $N$。
:::

::: proof
考察圆环上的一个电流元。每个电流元到轴上点 $P$ 的距离都是同一个 $r = \sqrt{R^2 + z^2}$。由电流元指向 $P$ 的向量有一个沿轴的分量 $z$，还有一个从电流元指向圆环中心、长度 $R$ 的分量，所以它与切向 $\dd\vec{l}$ 垂直。[[#eq-biot]]的大小因此为

$$
\dd B = \frac{\mu_0}{4\pi}\frac{I\,\dd l}{r^2},
$$

没有额外的正弦因子：$\dd\vec{l}$ 与 $\hat{r}$ 之间的夹角是直角。

那个向量 $\dd\vec{B}$ 垂直于由电流元到 $P$ 的连线。把它分解为沿轴方向与垂直轴方向。由半径、轴线和到 $P$ 的连线组成的直角三角形中，视线与轴线夹角的对边是 $R$，斜边是 $r$。沿轴的一块占 $\dd B$ 的 $R/r$，横向的一块占 $\abs{z}/r$。写出来即

$$
\dd B_z = \frac{\mu_0}{4\pi}\frac{I\,\dd l}{r^2}\cdot\frac{R}{r} = \frac{\mu_0}{4\pi}\frac{I R\,\dd l}{r^3}.
$$

横向的各个分量对每个电流元都直直地指离轴线。绕整圈来看，它们两两成对抵消。沿轴的各块都指向同一个方向。按本结论所述的电流方向，无论 $z$ 是正是负，叉积 $\dd\vec{l}\times\hat{r}$ 的 $z$ 分量都是正的：轴上的场按右手握法指定的方向穿过圆环，而且你从环的一侧穿到另一侧时它不反转。

剩下的积分只是导线的长度，$\int\dd l = 2\pi R$。于是

$$
B_z = \frac{\mu_0}{4\pi}\frac{I R}{r^3}\cdot 2\pi R = \frac{\mu_0 I R^2}{2 r^3} = \frac{\mu_0 I R^2}{2\left(R^2 + z^2\right)^{3/2}}.
$$

在 $z = 0$ 处有 $r = R$，[[#eq-centre]]立刻成立。$N$ 匝重合的线圈就是同一个积分的 $N$ 份，把场乘以 $N$。假设是这束导线整体上远小于 $R$，也远小于使用该公式时离线圈的距离。松松绕成的螺旋线不是这个线圈。
:::

两个极限值得在任何算术之前从[[#eq-loop]]直接读出来。在圆心处，分母是 $2R^3$，$R^2$ 约掉，剩下[[#eq-centre]]。沿轴很远时，$\abs{z}\gg R$，可以把 $R^2 + z^2$ 换成 $z^2$，于是

$$
B_z \approx \frac{\mu_0 I R^2}{2\abs{z}^3}.
$$

电流乘以环的面积是 $I\pi R^2$。把这个组合代进去就能看出，远处的轴向场正是这个小环的标准偶极场。靠近圆环时偶极公式是错的，该用的是[[#eq-loop]]。场在圆心处最强，随 $\abs{z}$ 增大单调下降。

方向由右手握法直接定下，不需要再算。四指沿电流，拇指穿过中心：那根拇指就是轴上的 $\vec{B}$。如果你看着圆环而电流是逆时针的，$\vec{B}$ 就穿过中心指向你。

::: example 圆心处的二十匝 {#ex-loop}
一个 $N = 20$ 匝紧密缠绕的圆形线圈，半径 $R = 0.050\,\mathrm{m}$，载有 $I = 3.00\,\mathrm{A}$。求圆心处的磁场。
::: solution
各匝视为重合，所以[[#eq-centre]]乘以 $N$：

$$
B = \frac{N\mu_0 I}{2R} = \frac{20\times\left(4\pi\times 10^{-7}\right)\times 3.00}{2\times 0.050}.
$$

分母是 $0.100\,\mathrm{m}$。分子是 $20\times 3.00\times 4\pi\times 10^{-7} = 2.40\pi\times 10^{-5}$，除以 $0.100$ 把十的幂挪了一位：

$$
B = 2.40\pi\times 10^{-4}\,\mathrm{T}.
$$

取 $\pi = 3.1416$，乘积 $2.40\pi\times 10^{-4}$ 等于 $7.5398\times 10^{-4}\,\mathrm{T}$，舍入为 $7.54\times 10^{-4}\,\mathrm{T}$。方向沿轴线，由电流的右手握法给出。这样尺寸、几安培电流的线圈产生毫特斯拉量级的场，是地磁场水平分量的好几倍，又远低于带铁芯的实验室磁体的场。真空公式不包含铁。
:::
:::

::: example 轴上偏离圆心之处 {#ex-axis}
单匝圆环半径 $R = 0.0800\,\mathrm{m}$，载有 $I = 4.00\,\mathrm{A}$。求轴上 $z = 0.0600\,\mathrm{m}$ 处的 $B$。
::: solution
直接使用[[#eq-loop]]。先算长度的平方：

$$
R^2 = (0.0800)^2 = 0.00640\,\mathrm{m^2}, \qquad z^2 = (0.0600)^2 = 0.00360\,\mathrm{m^2}.
$$

它们的和恰为 $0.0100\,\mathrm{m^2}$，且

$$
\left(R^2 + z^2\right)^{3/2} = (0.0100)^{3/2} = 1.00\times 10^{-3}\,\mathrm{m^3}.
$$

前置因子为

$$
\frac{\mu_0 I R^2}{2\left(R^2 + z^2\right)^{3/2}} = \frac{\left(4\pi\times 10^{-7}\right)\times 4.00\times 0.00640}{2\times 1.00\times 10^{-3}} = \left(4\pi\times 10^{-7}\right)\times 12.8.
$$

由于 $12.8\times 4 = 51.2$，

$$
B = 5.12\pi\times 10^{-6}\,\mathrm{T} = 1.6085\times 10^{-5}\,\mathrm{T},
$$

舍入为 $1.61\times 10^{-5}\,\mathrm{T}$。作为对照，同一圆环圆心处的场是 $\mu_0 I/(2R) = 3.14\times 10^{-5}\,\mathrm{T}$。沿轴走到四分之三个半径处，轴向场大约减半。$z$ 分量仍按右手握法的方向穿过圆环；它没有反转。
:::
:::

## 直导线的磁场

直导线段是后文每个应用都会引用的另一个积分。几何由一个长度和两个角固定。设 $P$ 是场点，$O$ 是从 $P$ 到导线所在直线（必要时延长）所作垂线的垂足。记 $a = \abs{OP}$。在 $P$ 处量一个角 $\theta$：从垂线 $PO$ 出发转向导线，并取电流流向那一侧的角为正。若垂足 $O$ 落在线段上，则一端对应负角，另一端对应正角。

::: proposition 有限长直导线的磁场 {#prop-finite}
直导线载有稳恒电流 $I$。按刚才记下的记号，$P$ 处磁场的大小为

$$
B = \frac{\mu_0 I}{4\pi a}\left(\sin\theta_2 - \sin\theta_1\right),
$$ {#eq-finite}

其中 $\theta_1$ 与 $\theta_2$ 是由 $P$ 望两个端点的角，且 $\theta_2 > \theta_1$。方向垂直于包含导线与点 $P$ 的那个平面，由电流的右手握法给出。直导线的每个电流元产生的 $\dd\vec{B}$ 都在同一个方向上，所以各贡献像标量一样相加。
:::

::: proof
把导线放在一条直线上，$s$ 是沿电流方向的坐标，垂足 $O$ 处 $s = 0$。坐标 $s$ 处的电流元到 $P$ 的距离为 $r = \sqrt{a^2 + s^2}$。由电流元指向 $P$ 的向量有一个沿导线回指的分量 $-s$ 和一个沿垂线的分量 $a$，所以它与 $\dd\vec{l} = \dd s\,\hat{s}$ 的叉积大小为 $a\,\dd s$。除以 $r$ 得到单位向量，

$$
\dd B = \frac{\mu_0}{4\pi}\frac{I a\,\dd s}{r^3}.
$$

方向在每个 $s$ 处都相同，即 $\hat{s}\times\hat{n}$，指向平面外。现在把变量换成上面定义的角 $\theta$。则 $s = a\tan\theta$，$r = a/\cos\theta$，且

$$
\dd s = a\sec^2\theta\,\dd\theta = \frac{a\,\dd\theta}{\cos^2\theta}.
$$

代入 $r^3 = a^3/\cos^3\theta$：

$$
\frac{a\,\dd s}{r^3} = a\cdot\frac{a\,\dd\theta}{\cos^2\theta}\cdot\frac{\cos^3\theta}{a^3} = \frac{\cos\theta\,\dd\theta}{a}.
$$

于是

$$
\dd B = \frac{\mu_0 I}{4\pi a}\cos\theta\,\dd\theta.
$$

这就是推导中点名的那个积分。从上游端点的角积分到下游端点的角，得

$$
B = \frac{\mu_0 I}{4\pi a}\int_{\theta_1}^{\theta_2}\cos\theta\,\dd\theta = \frac{\mu_0 I}{4\pi a}\left(\sin\theta_2 - \sin\theta_1\right),
$$

即[[#eq-finite]]。若垂足落在线段之外，两个角同号，正弦之差更小，但代数不变。
:::

无限长导线是两个端点从垂线两侧看都成直角的极限。

::: corollary 无限长直导线 {#cor-wire}
载有电流 $I$ 的长直导线在垂直距离 $a$ 处的磁场大小为

$$
B = \frac{\mu_0 I}{2\pi a},
$$ {#eq-wire}

并按右手握法绕着导线转圈。当问题里只有一个距离时，同样的公式把 $a$ 写作 $r$。
:::

::: proof
对无限长导线，$\theta_1 = -\pi/2$、$\theta_2 = \pi/2$。于是 $\sin\theta_2 - \sin\theta_1 = 1 - (-1) = 2$，[[#eq-finite]]化为

$$
B = \frac{\mu_0 I}{4\pi a}\cdot 2 = \frac{\mu_0 I}{2\pi a}.
$$

利用 $\mu_0/(2\pi) = 2.00\times 10^{-7}\,\mathrm{T\,m/A}$，当 $I$ 以安培、$a$ 以米为单位时，也可以写 $B = \left(2.00\times 10^{-7}\,I/a\right)\,\mathrm{T}$。在这个理想化下，$a = 0$ 处场没有定义：零粗细的导线不是真实电缆内部的诚实模型。对半径有限的长直电缆，只要电流均匀铺开或集中在其内部，[[#eq-wire]]在外部仍然成立，$a$ 是到轴线的距离——理由就是下一节的安培论证。
:::

按 $1/a$ 的下降比点电荷的 $1/r^2$ 慢，而且它有一个几何原因。磁场线是圆。半径为 $a$ 的圆周长度是 $2\pi a$，而安培定律将说明 $B$ 乘这个长度是常量 $\mu_0 I$。你站得越远，同一股电流就被摊到越长的回路上，所以 $B$ 只按 $1/a$ 下降。[[electrostatics/gauss-law]]里无限长均匀带电直线的电场按 $1/r$ 下降，正是对通量说了同样的话。点电荷的电场降得更快，因为通量摊在球面上，而不是圆周上。

::: example 八安电流，两厘米之外 {#ex-wire}
长直导线载有 $I = 8.00\,\mathrm{A}$。求垂直距离 $r = 0.0200\,\mathrm{m}$ 处的 $B$。
::: solution
由[[#eq-wire]]与约化常量得

$$
B = \frac{\mu_0 I}{2\pi r} = \left(2.00\times 10^{-7}\right)\frac{8.00}{0.0200} = \left(2.00\times 10^{-7}\right)\times 400 = 8.00\times 10^{-5}\,\mathrm{T}.
$$

算术是精确的：$8.00/0.0200 = 400$，而 $2.00\times 10^{-7}\times 400 = 8.00\times 10^{-5}$。若拇指沿电流方向，这一处的四指就弯向 $\vec{B}$ 的方向。大小 $80.0\,\mu\mathrm{T}$ 与地球表面磁场同一量级，这就是为什么几安培电流的课堂导线在几厘米外就能让指南针偏转，也为什么必须把导线仔细对准方向，否则地磁场会主宰磁针的指向。
:::
:::

::: example 从四十五度张角看到的有限长导线 {#ex-finite}
一段直导线载有 $I = 10.0\,\mathrm{A}$。场点位于线段中点处垂线上、距中点 $a = 0.0500\,\mathrm{m}$，两个端点对该垂线的张角都是 $45^\circ$。求 $B$，并与同距离处无限长导线的场比较。
::: solution
两个角是 $\theta_1 = -45^\circ$、$\theta_2 = +45^\circ$。于是

$$
\sin\theta_2 - \sin\theta_1 = \sin 45^\circ - \sin(-45^\circ) = \frac{\sqrt{2}}{2} - \left(-\frac{\sqrt{2}}{2}\right) = \sqrt{2}.
$$

[[#eq-finite]]的前置因子为

$$
\frac{\mu_0 I}{4\pi a} = \left(1.00\times 10^{-7}\right)\frac{10.0}{0.0500} = 2.00\times 10^{-5}\,\mathrm{T}.
$$

乘以 $\sqrt{2} = 1.41421$ 得

$$
B = 2.8284\times 10^{-5}\,\mathrm{T},
$$

舍入为 $2.83\times 10^{-5}\,\mathrm{T}$。因为 $\tan 45^\circ = 1$，导线的每一半长都是 $a$，所以整段长 $0.100\,\mathrm{m}$。它不是一根长导线。

同样的 $a$ 与 $I$，无限长导线公式给出

$$
B_\infty = \frac{\mu_0 I}{2\pi a} = \left(2.00\times 10^{-7}\right)\frac{10.0}{0.0500} = 4.00\times 10^{-5}\,\mathrm{T}.
$$

两个结果的精确之比是 $\sin 45^\circ = 1/\sqrt{2} = 0.707$。把导线剪短到对场点只张一个直角——从 $-45^\circ$ 到 $+45^\circ$——保留了无限长导线磁场的大约七成。剪掉的两段尾巴在渐近线附近，仍贡献剩下的三成，因为被积函数里的 $\cos\theta$ 衰减得很慢。
:::
:::

## 安培定律

刚才做的那个积分，对具有对称性的导线来说是绕远路。安培定律把同样的内容包装成一个环量。

::: theorem 安培定律 {#thm-ampere}
设 $C$ 是真空中的闭曲线，电流分布稳恒。则

$$
\oint_C \vec{B}\cdot\dd\vec{l} = \mu_0 I_{\mathrm{encl}},
$$ {#eq-ampere}

其中 $I_{\mathrm{encl}}$ 是通过以 $C$ 为边界的任一曲面的总电流。正负号由右手定则固定：四指沿线积分方向弯曲，拇指给出的就是电流的正方向。反向穿过曲面的回流为负。
:::

::: proof
我们对无限长直导线证明[[#eq-ampere]]——这是本章确定这一定律用法的情形——并记录采纳一般陈述时所依据的假设。

由[[#cor-wire]]，导线外距离 $a$ 处的 $\vec{B}$ 沿方位角方向，大小为 $\mu_0 I/(2\pi a)$。在以导线为心、半径为 $a$ 的圆上，$\vec{B}$ 沿切向且大小恒定，而圆周长为 $2\pi a$，所以

$$
\oint\vec{B}\cdot\dd\vec{l} = B\cdot 2\pi a = \mu_0 I.
$$

$a$ 的这种相消对不是圆的曲线同样成立。在垂直于导线的平面内，$B_\varphi\,\dd l_\varphi = \left(\mu_0 I/(2\pi a)\right)\,a\,\dd\varphi = \left(\mu_0 I/(2\pi)\right)\dd\varphi$。积分等于 $\mu_0 I$ 乘以曲线绕导线的净圈数。不包围导线的曲线给出零。这就是对每条链接无限长直导线的曲线的[[#eq-ampere]]。

一般的稳恒分布这里不积分。从[[#eq-biot]]走到[[#eq-ampere]]是磁静力学的一条标准定理，并且本质地用到电流的稳恒性：穿过以 $C$ 为边界的一个曲面的电流必须等于穿过任何其他这种曲面的电流，否则 $I_{\mathrm{encl}}$ 就会依赖一个任意的选择。稳恒性——电荷不在累积——这句话，正是让那两个曲面一致的东西。我们在这条假设下、在真空中、无磁性材料存在时，使用这一定律的一般形式。
:::

正在充电的电容器是假设失效的标志性情形。绕着给电容器极板供电的导线画一条安培环路，它可以被一块平面曲面张住——传导电流穿过这块面；也可以被一块鼓出来、从两极板之间穿过的曲面张住——没有传导电流穿过那块面。$I_{\mathrm{encl}}$ 的两个值不一致。补救的办法是位移电流，在 [[magnetism/maxwell]] 中处理。在那一项被补回来之前，[[#eq-ampere]]只是对稳恒电流成立的定律。

用这一定律去求 $\vec{B}$——而不是去求一个本来就懂的环量——需要对称性。步骤与高斯定律的论证同形。

1. 用电流的对称性决定 $\vec{B}$ 的方向以及它可能依赖的坐标。
2. 选一条闭曲线，使 $\vec{B}$ 在其上或沿切向且大小恒定，或垂直于曲线，或已知为零。
3. 环量于是塌缩成 $B$ 乘一个长度，或两个这种项之差。
4. 以正确的右手符号计算 $I_{\mathrm{encl}}$，只计入穿过以该曲线为边界的曲面的电流。
5. 解出 $B$。

若对称性不存在，第 3 步就无从下手。定律仍然为真，仍然约束环量，但它不把 $\vec{B}$ 在某一点的值交还给你。正方形导线回路找不到一条能让这种提取奏效的安培环路。那就只好回到[[#eq-biot]]。

::: warning 稳恒电流与对称性
[[#eq-ampere]]形式的安培定律——不含位移电流——对充电中的电容器是错的。那项修正见 [[magnetism/maxwell]]。这里你只能把[[#eq-ampere]]用于稳恒电流。要从积分中提取 $\vec{B}$ 需要对称性，正如从高斯定律中提取 $\vec{E}$ 需要对称性。把 $\mu_0 I_{\mathrm{encl}}$ 除以一条任意曲线的长度，并不能产生那条曲线上的场。
:::

## 长螺线管

螺线管就是绕在圆柱上一圈挨一圈的导线。让场变简单的理想化是一个无限长的螺旋绕组，或者在离两端很多倍半径处观察的有限绕组，且匝与匝靠得足够近，可以把整个绕组当作一堆圆形线圈的叠放。设 $n$ 为单位长度的匝数，每匝载电流 $I$。

::: proposition 理想螺线管的磁场 {#prop-solenoid}
理想无限长螺线管内部的磁场是均匀的，平行于轴线，大小为

$$
B = \mu_0 n I.
$$ {#eq-solenoid}

外部，理想化的场为零。内部的转向是右手握法：四指顺着各匝中的电流弯曲，拇指沿 $\vec{B}$。
:::

::: proof
给出两个论证。第一个用[[#thm-ampere]]，并把理想化说得老老实实。第二个对[[#eq-loop]]积分，直接算出轴向场，而不对外部单独作任何断言。

先说对称性。无限长螺线管在沿自身轴线的平移和绕轴的转动下不变，所以在叠环理想化下 $\vec{B}$ 只能依赖到轴的垂直距离 $s$。径向分量会使净通量穿出同轴圆柱面。对由[[#eq-biot]]搭建的场，穿过任何闭曲面的磁通量都为零，因为没有供磁场线终止的磁荷；这里就使用这条性质，并在 [[magnetism/maxwell]] 中以 $\divg\vec{B} = 0$ 的面目与它重逢。圆柱的弯曲侧壁就得承担全部通量，这迫使径向分量为零。方位角分量在叠环模型里不存在：每匝的场都在子午面内，而真实的螺旋绕组只产生与绕组缓慢推进相伴的一个弱方位角场，理想化把它丢掉了。

现在取一条沿轴线、长 $L$ 的矩形安培环路，两条长边都在绕组之外，位于两个不同的半径处。它不包围任何电流。矩形的两条短边垂直于轴向场，不贡献什么，于是 $\left(B(s_1) - B(s_2)\right)L = 0$。外部的场因此与半径无关。我们把它设为零，作为无限长螺线管理想化的一部分：有限长螺线管的回流磁通摊在整个外部空间，在无限长极限下这个摊开的场被视为零。实际的表述对一只长线圈是实用的：外部 $B \approx 0$。

第二条矩形环路的内侧长边在绕组内、任何小于绕组半径的半径 $s$ 处，外侧长边在绕组外。内侧的边贡献 $B_{\mathrm{in}} L$，外侧的边不贡献，两条短边也不贡献。环路包围 $n L$ 匝，只要环路的走向与右手定则一致，就有 $I_{\mathrm{encl}} = n L I$。[[#eq-ampere]]给出 $B_{\mathrm{in}} L = \mu_0 n L I$，于是 $B_{\mathrm{in}} = \mu_0 n I$，与 $s$ 无关。内部的场是均匀的。

第二个论证用积分复核轴向的值。螺线管在 $z$ 与 $z + \dd z$ 之间的一片是一个载有电流 $\dd I = n I\,\dd z$ 的圆环。在原点处，[[#eq-loop]]贡献

$$
\dd B_z = \frac{\mu_0 (n I\,\dd z)\, R^2}{2\left(R^2 + z^2\right)^{3/2}}.
$$

对无限长螺线管，$z$ 从 $-\infty$ 跑到 $\infty$。代换 $z = R\tan\theta$，于是 $\dd z = R\sec^2\theta\,\dd\theta$，$\theta$ 从 $-\pi/2$ 跑到 $\pi/2$，把有理因子化成 $\cos\theta$：

$$
\int_{-\infty}^{\infty}\frac{R^2\,\dd z}{\left(R^2 + z^2\right)^{3/2}} = \int_{-\pi/2}^{\pi/2}\cos\theta\,\dd\theta = 2.
$$

因此 $B_z = \left(\mu_0 n I / 2\right)\cdot 2 = \mu_0 n I$，与[[#eq-solenoid]]一致。同一个积分从 $\theta_1$ 到 $\theta_2$，对只占据 $z$ 的有限区间的螺线管，给出

$$
B_z = \frac{\mu_0 n I}{2}\left(\sin\theta_2 - \sin\theta_1\right),
$$ {#eq-solenoid-finite}

其中 $\tan\theta = z/R$，从场点量到绕组的两端。对长 $L$、半径 $R$ 的螺线管的中心，这是 $\mu_0 n I$ 乘以 $(L/2)/\sqrt{(L/2)^2 + R^2}$，小于 $\mu_0 n I$，只在 $L\gg R$ 时才趋于它。在半无限长螺线管的管口，$\theta$ 从 $0$ 跑到 $\pi/2$，正弦之差为 $1$，$B = \mu_0 n I/2$。
:::

真实螺线管的端口不是引用[[#eq-solenoid]]的地方。在一根长度数倍于直径的线圈内部、离端部好几个半径处，无限长公式就是可用的公式，而筒身外的场只是内部场的一小部分。靠近任一端管口，轴向场大约只有一半，而且向外散开。

::: example 两安培的长螺线管 {#ex-solenoid}
一只理想长螺线管有 $n = 1000$ 匝每米，载有 $I = 2.00\,\mathrm{A}$。求管内远离两端处的 $B$。
::: solution
由[[#eq-solenoid]]得

$$
B = \mu_0 n I = \left(4\pi\times 10^{-7}\right)\times 1000\times 2.00 = 8\pi\times 10^{-4}\,\mathrm{T}.
$$

小数形式为 $2.5133\times 10^{-3}\,\mathrm{T}$，舍入为 $2.51\times 10^{-3}\,\mathrm{T}$。方向沿轴线，按绕组的右手握法伸出拇指。理想绕组之外场取为零。这样绕密的一只有限线圈，在离端口几个直径处，就很接近这个值；在端口本身上，轴向场约为其一半，这正是[[#eq-solenoid-finite]]的半无限极限。
:::
:::

## 螺绕环

把一根长螺线管弯到两端相接，直螺线管原本铺满整个外部空间的回流磁通就被关在了甜甜圈里面。螺绕环就是这样的绕组：环上绕 $N$ 匝导线，每匝载电流 $I$。理想化是紧密缠绕，使得横截面里能看到的电流只有内缘上的电流和外缘上的电流，两者等量反向，各为 $NI$。

::: proposition 螺绕环的磁场 {#prop-toroid}
设 $r$ 是到螺绕环对称轴——穿过甜甜圈中心孔的那条轴——的距离。在紧密缠绕的理想极限下，$\vec{B}$ 沿方位角方向。在绕组内外半径之间的磁芯内部，

$$
B = \frac{\mu_0 N I}{2\pi r}.
$$ {#eq-toroid}

在中心孔里，以及绕组之外的一切地方，$B = 0$。
:::

::: proof
绕甜甜圈轴的转动对称迫使 $\vec{B}$——若它不为零——沿方位角方向，且只依赖 $r$。取以该轴为心、半径为 $r$ 的圆作为安培环路。

若圆落在磁芯内部，以它为边界的曲面被绕组的内侧线束每匝穿过一次，$I_{\mathrm{encl}} = NI$。在圆上，$\vec{B}$ 由对称性沿切向且大小恒定，环量为 $B\cdot 2\pi r$。[[#eq-ampere]]给出 $B\cdot 2\pi r = \mu_0 N I$，即[[#eq-toroid]]。

若圆落在中心孔里，没有导线穿过以它为边界的曲面，所以 $I_{\mathrm{encl}} = 0$、$B = 0$。若圆落在整个螺绕环之外，曲面被内侧线束朝一个方向穿过、被外侧线束朝另一个方向穿过。两股电流等量，$I_{\mathrm{encl}} = 0$，$B = 0$。场被关在磁芯里。

对细螺绕环，$r$ 在磁芯横截面内几乎不变。把沿平均周长单位长度的匝数记作 $n = N/(2\pi r)$，[[#eq-toroid]]就化成 $B = \mu_0 n I$，即螺线管的结果。粗磁芯的螺绕环保留 $1/r$ 的变化：内缘上的场比外缘上的强，强弱之比恰是两个半径的反比。
:::

被关住这一点正是实用之处。螺绕环几乎不把场送进周围的房间，这就是杂散场惹麻烦时电感器和变压器常绕成这种形状的原因。代价是粗磁芯截面上那个 $1/r$ 的不均匀。

::: example 半径八厘米上的四百匝 {#ex-toroid}
一只紧密缠绕的螺绕环有 $N = 400$ 匝，载有 $I = 1.20\,\mathrm{A}$。求磁芯内部、到对称轴距离 $r = 0.0800\,\mathrm{m}$ 处的 $B$。该点位于绕组的内外半径之间。
::: solution
由[[#eq-toroid]]与 $\mu_0/(2\pi) = 2.00\times 10^{-7}\,\mathrm{T\,m/A}$ 得

$$
B = \left(2.00\times 10^{-7}\right)\frac{N I}{r} = \left(2.00\times 10^{-7}\right)\frac{400\times 1.20}{0.0800}.
$$

电流的因子是 $480$，而 $2.00\times 10^{-7}\times 480 = 9.60\times 10^{-5}$。除以 $0.0800$ 得 $B = 1.20\times 10^{-3}\,\mathrm{T}$，精确如此。在同一磁芯内更大的半径处场更小，与 $r$ 成反比。除非磁芯细到这一区别无关紧要，它不等于平均半径处的值。
:::
:::

## 多根长直导线的叠加

几根长直导线的总场，是一系列[[#eq-wire]]形状的项的向量和。各大小只在方向一致时才直接相加。方向相反、大小相等的地方则相互抵消。

搭一张可以反复使用的图。导线垂直于纸面。点表示电流出纸面朝向你；叉表示电流入纸面。对点，右手握法是逆时针：导线右侧的 $\vec{B}$ 沿纸面向上，导线左侧的 $\vec{B}$ 沿纸面向下。对叉，握法是顺时针，这两个方向随之反转。

::: example 等量反向的电流 {#ex-two-wires}
两根长直平行导线相距 $0.100\,\mathrm{m}$，各载 $5.00\,\mathrm{A}$，电流方向相反。求两者中点处的 $\vec{B}$。
::: solution
每根导线到中点的距离都是 $r = 0.0500\,\mathrm{m}$，所以每根贡献

$$
B_1 = \frac{\mu_0 I}{2\pi r} = \left(2.00\times 10^{-7}\right)\frac{5.00}{0.0500} = 2.00\times 10^{-5}\,\mathrm{T}.
$$

把左边的导线画成点，右边的画成叉。在中点——它在点的右侧——那根点的导线产生的场沿纸面向上。中点在叉的左侧，而顺时针的场在导线左侧也沿纸面向上。两个场平行。总场为

$$
B = 4.00\times 10^{-5}\,\mathrm{T},
$$

按这一对手性选择，沿纸面向上。把两股电流同时反转，$\vec{B}$ 反向而大小不变。若两股电流同向，中点处两个贡献会相反，总场就为零。那种抵消是等量电流特有的。同向而不等量的电流仍有一条场为零的线，只是它挪到靠较弱导线更近的地方，这是一道后面的习题。

任一根导线受到的力可由另一根的磁场求出，正如 [[magnetism/magnetic-force]] 中那样。反向电流相互排斥。这里的场计算只是叠加；力是 $I$ 乘以长度再乘以邻线在那里的场，而不是中点处的总场。
:::
:::

## 场随距离的衰减

本章三个常用公式按三种不同的方式衰减。长直导线是 $1/r$。圆环，远离到轴线上，是 $1/\abs{z}^3$。螺线管，在内部且远离两端，根本不衰减：直到绕组尽头场都保持均匀。你手里拿的是哪个公式，是一个关于几何的决定，在任何算术之前做出。

::: widget plot
f: 1/x
x: 0.2, 5
caption: 长直导线的场按 $1/r$ 衰减，比点电荷的 $1/r^2$ 慢。这条曲线就是那个 $1/r$ 形状。什么都没有滑动：比较从 $0.2$ 到 $1$ 的下落与从 $1$ 到 $5$ 的下落。
:::

从 $r = 1$ 到 $r = 5$，导线的场缩小五倍。同样一段距离上，点电荷的场会缩小二十五倍。缓慢的长尾解释了为什么一根回流引线哪怕绕着敏感仪器远处走过，仍会贡献一个场；也解释了为什么螺绕环——它把回流电流带回家从而取消那条长尾——是与单根导线不同种类的东西。

::: history 毕奥、萨伐尔与安培
1820 年，毕奥（Jean-Baptiste Biot）与萨伐尔（Félix Savart）宣布了他们把一个磁极放在长直导线附近时受到的力。这个力与垂直距离成反比。他们测到的其实就是磁场[[#eq-wire]]，读数是磁极受到的力矩。同样的几年，1820 到 1827 年，安培（André-Marie Ampère）建立了两股电流之间的力，并把永磁体当作电流的集合而不是一对磁极来处理。环路定律[[#eq-ampere]]——用 $\vec{B}$ 沿闭曲线积分表述的现代形式——要等到场的向量分析就位之后才清晰起来。电流元定律[[#eq-biot]]是局域陈述，直导线的场、圆环的场，以及在稳恒假设下的环路定律，都从它推出。
:::

::: summary
- 毕奥–萨伐尔定律给出 $\dd\vec{B} = (\mu_0/4\pi)\, I\,\dd\vec{l}\times\hat{r}/r^2$，其中 $\vec{r}$ 由电流元画向场点。我们取 $\mu_0 = 4\pi\times 10^{-7}\,\mathrm{T\,m/A}$。
- 圆电流轴线上，$B = \mu_0 I R^2 / \bigl(2(R^2 + z^2)^{3/2}\bigr)$；圆心处 $B = \mu_0 I/(2R)$。$N$ 匝密绕线圈把这两个值乘以 $N$。
- 有限长直导线给出 $B = (\mu_0 I/(4\pi a))(\sin\theta_2 - \sin\theta_1)$。无限长是 $\theta = \pm\pi/2$ 的极限，$B = \mu_0 I/(2\pi r)$，按右手握法绕导线转圈。
- 安培定律 $\oint\vec{B}\cdot\dd\vec{l} = \mu_0 I_{\mathrm{encl}}$ 对真空中的稳恒电流成立。提取 $\vec{B}$ 需要对称性。不含位移电流时，它对充电中的电容器不成立。
- 理想长螺线管内部 $B = \mu_0 n I$，理想化的外部场为零。半无限长螺线管管口的轴向场是其一半。
- 螺绕环磁芯内部 $B = \mu_0 N I/(2\pi r)$，中心孔里和绕组之外场为零。
- 几个电流的场按向量相加。平行的贡献相加；反平行的贡献在大小相等的地方抵消。
- 导线的场按 $1/r$ 衰减，比点电荷的场慢，因为环量 $\mu_0 I$ 摊在长度 $2\pi r$ 的圆周上。
:::

## 习题

::: exercise 再往外两厘米的场 {#exr-wire level=1 check="6e-5"}
长直导线载有 $I = 15.0\,\mathrm{A}$。求垂直距离 $r = 0.0500\,\mathrm{m}$ 处 $\vec{B}$ 的大小。
::: solution
由[[#eq-wire]]与 $\mu_0/(2\pi) = 2.00\times 10^{-7}\,\mathrm{T\,m/A}$ 得

$$
B = \left(2.00\times 10^{-7}\right)\frac{15.0}{0.0500} = \left(2.00\times 10^{-7}\right)\times 300 = 6.00\times 10^{-5}\,\mathrm{T}.
$$

方向绕导线沿方位角方向。大小比[[#ex-wire]]的 $8.00\times 10^{-5}\,\mathrm{T}$ 小，因为在那个比较里，较大的距离与不同的电流都已被比值 $I/r$ 一个量算进去了。
:::
:::

::: exercise 单匝圆环的中心 {#exr-centre level=1 check="pi*10^(-5)"}
单匝圆形回路半径 $R = 0.100\,\mathrm{m}$，载有 $I = 5.00\,\mathrm{A}$。求圆心处 $\vec{B}$ 的大小。
::: solution
由[[#eq-centre]]得

$$
B = \frac{\mu_0 I}{2R} = \frac{\left(4\pi\times 10^{-7}\right)\times 5.00}{2\times 0.100} = \left(4\pi\times 10^{-7}\right)\times 25.0 = \pi\times 10^{-5}\,\mathrm{T}.
$$

小数形式为 $3.14\times 10^{-5}\,\mathrm{T}$。验证所要求的精确值是 $\pi\times 10^{-5}$。方向垂直于圆环平面。

::: exercise 螺线管的绕密 {#exr-solenoid level=1 check="8*pi*10^(-4)"}
一只理想长螺线管有 $n = 500$ 匝每米，载有 $I = 4.00\,\mathrm{A}$。求管内远离两端处的 $B$。
::: solution
由[[#eq-solenoid]]得

$$
B = \mu_0 n I = \left(4\pi\times 10^{-7}\right)\times 500\times 4.00 = 8\pi\times 10^{-4}\,\mathrm{T}.
$$

数值上为 $2.51\times 10^{-3}\,\mathrm{T}$。理想绕组之外场取为零，所以这组数据并不描述螺线管旁边的一个点。
:::
:::

::: exercise 沿轴走到半个位置 {#exr-ratio level=2 check="1/(2*sqrt(2))"}
一个圆形回路载有稳恒电流。设 $B_0$ 为圆心处的场，$B(R)$ 为轴上距圆心 $R$ 处的轴向场，$R$ 是圆环半径。求比值 $B(R)/B_0$。
::: solution
由[[#eq-loop]]与[[#eq-centre]]，

$$
\frac{B(z)}{B_0} = \frac{R^3}{\left(R^2 + z^2\right)^{3/2}} = \left(\frac{R}{\sqrt{R^2 + z^2}}\right)^3.
$$

在 $z = R$ 处，

$$
\frac{R}{\sqrt{R^2 + R^2}} = \frac{1}{\sqrt{2}}, \qquad \frac{B(R)}{B_0} = \left(\frac{1}{\sqrt{2}}\right)^3 = \frac{1}{2\sqrt{2}}.
$$

小数形式为 $0.354$。轴上向外走一个半径处的场，比中心场略大过三分之一。$N$ 匝密绕线圈的同一比值不变，因为 $N$ 约掉了。
:::
:::

::: exercise 五厘米处的螺绕环 {#exr-toroid level=2 check="2.4*10^(-3)"}
$N = 200$ 匝的螺绕环载有 $I = 3.00\,\mathrm{A}$。求磁芯内部、到对称轴距离 $r = 0.0500\,\mathrm{m}$ 处的 $B$。
::: solution
由[[#eq-toroid]]得

$$
B = \left(2.00\times 10^{-7}\right)\frac{200\times 3.00}{0.0500} = \left(2.00\times 10^{-7}\right)\times 1.20\times 10^{4} = 2.40\times 10^{-3}\,\mathrm{T}.
$$

中间一步是 $NI/r = 600/0.0500 = 1.20\times 10^{4}\,\mathrm{A/m}$。在理想绕组下，半径更小的孔中的点会有 $B = 0$，而不是同一公式更大的值。该公式只适用于磁芯内外半径之间。
:::
:::

::: exercise 两根导线的抵消线 {#exr-null level=2 check="0.1"}
两根长直平行导线相距 $0.300\,\mathrm{m}$，载有同向电流 $4.00\,\mathrm{A}$ 与 $8.00\,\mathrm{A}$。两线之间有一条与两者平行的线，其上 $\vec{B} = \vec{0}$。求这条线到 $4.00\,\mathrm{A}$ 那根导线的距离。
::: hint
在两线之间的区域，两个场反平行。令大小相等。
:::
::: solution
设 $x$ 是到 $4.00\,\mathrm{A}$ 导线的距离，$0.300 - x$ 是到 $8.00\,\mathrm{A}$ 导线的距离。两线之间，两只右手握法把 $\vec{B}$ 送到相反的方向，如[[#ex-two-wires]]的讨论。大小相等的条件是

$$
\frac{\mu_0}{2\pi}\frac{4.00}{x} = \frac{\mu_0}{2\pi}\frac{8.00}{0.300 - x}.
$$

约去公共因子：

$$
\frac{4.00}{x} = \frac{8.00}{0.300 - x} \implies 0.300 - x = 2x \implies x = 0.100\,\mathrm{m}.
$$

零点靠较弱的电流更近。在这一对导线的两侧之外，两个场同向，所以不可能抵消。结果 $0.100\,\mathrm{m}$ 纯粹来自两电流之比 $1:2$；$\mu_0$ 约掉了。
:::
:::

::: exercise 轴向场降到八分之一之处 {#exr-eighth level=3 check="0.05*sqrt(3)"}
圆形回路半径 $R = 0.0500\,\mathrm{m}$。在轴线上 $z > 0$ 的一侧，场随 $\abs{z}$ 增大而下降。求 $B_z$ 降到中心值八分之一处的距离 $z$。
::: hint
比值 $B(z)/B_0$ 是 $\bigl(R/\sqrt{R^2 + z^2}\bigr)^3$。令它等于 $1/8$，先开立方再平方。
:::
::: solution
由[[#exr-ratio]]用过的比值，

$$
\left(\frac{R}{\sqrt{R^2 + z^2}}\right)^3 = \frac{1}{8} = \left(\frac{1}{2}\right)^3.
$$

括号里的量都是正的，所以

$$
\frac{R}{\sqrt{R^2 + z^2}} = \frac{1}{2}.
$$

于是 $\sqrt{R^2 + z^2} = 2R$，两边平方得 $R^2 + z^2 = 4R^2$，故 $z^2 = 3R^2$，

$$
z = R\sqrt{3} = 0.0500\sqrt{3} = 8.66\times 10^{-2}\,\mathrm{m}.
$$

负根是圆环另一侧的镜像点，那里场大小相同，而且对给定的电流方向，方向也相同。中心场的八分之一在略大于一倍半半径处达到。偶极近似 $B\propto 1/\abs{z}^3$ 会把这一点放在别处，因为 $z = R\sqrt{3}$ 还没有进入 $\abs{z}\gg R$ 的范围。
:::
:::

::: exercise 螺线管的开口端 {#exr-mouth level=3 check="4*pi*10^(-4)"}
一只理想化螺线管占据其轴线从原点出发到无穷的半直线，$n = 1000$ 匝每米，$I = 2.00\,\mathrm{A}$。绕组就从场点处开始。证明那一点的轴向场是深处内部值的一半，并求其大小。
::: hint
对从场点开始、延伸到无穷的绕组，把[[#eq-solenoid-finite]]配上相应的角度。
:::
::: solution
从场点处的径向平面量起 $\theta$，使 $\tan\theta = z/R$ 量到螺线管的一片。绕组占据 $\theta$ 从 $0$ 到 $\pi/2$。[[#eq-solenoid-finite]]给出

$$
B = \frac{\mu_0 n I}{2}\left(\sin\frac{\pi}{2} - \sin 0\right) = \frac{\mu_0 n I}{2}.
$$

无限长螺线管深处内部的值是 $\mu_0 n I$，所以半无限长螺线管的管口带着其中的一半。数值上

$$
B = \frac{1}{2}\left(4\pi\times 10^{-7}\right)\times 1000\times 2.00 = 4\pi\times 10^{-4}\,\mathrm{T},
$$

即 $1.26\times 10^{-3}\,\mathrm{T}$。这正是理想化末端处的轴向场。在长实验室螺线管里退回一小段距离，场已经从这个半值爬上了通往 $\mu_0 n I$ 的大部分路程；向外一小段，场已跌到半值以下，正在散开。
:::

::: quiz
长直导线载有稳恒电流。你想求导线旁一点处 $\vec{B}$ 的大小。哪些说法是合法的？
- [x] 把毕奥–萨伐尔定律沿导线积分，或对以导线为心的圆使用安培定律。两者都给出 $\mu_0 I/(2\pi r)$。
- [x] 对任何绕导线一圈的曲线，同样的安培环量都等于 $\mu_0 I$；选以导线为心的圆，是因为对称性使 $B$ 在其上恒定。
- [ ] 对以导线为中心的正方形使用安培定律，就给出 $B$ 等于 $\mu_0 I$ 除以正方形的周长。
- [ ] 充电中电容器的两极板之间传导电流为零，所以本章使用的形式的安培定律说：在绕着给电容器供电的导线的回路上 $\vec{B}$ 为零。
::: solution
前两条说法就是[[#cor-wire]]与[[#thm-ampere]]证明的内容。绕着包围导线的正方形的环量仍是 $\mu_0 I$，但 $B$ 既不在正方形上恒定，也不处处与其相切到让你能除以周长的地步。关于电容器的那条说法，是没有位移电流的[[#eq-ampere]]的标志性失效：两极板之间的曲面不被任何传导电流穿过，而切断供电导线的曲面被 $I$ 穿过，两者不一致。那种情形在 [[magnetism/maxwell]] 之前都被排除在外。
:::
