本课程力学、振动与电路各部分里几乎每一个问题，写到最后都会变成一个微分方程：加速度是位置的函数（或由受力定律决定），电荷的变化率由电路决定，场的变化由场方程给出。就入门物理与场论第一年真正重要的那些情形而言，这些方程都是**常**微分方程——导数只对单个变量而求——而处理它们的理论：解的存在唯一性、线性方程的求解、没有闭式解的方程所用的级数方法——就是本章的主题。偏微分方程里导数对多个变量而求，那是更深的主题，属于格林函数一章 [[math-methods/green-functions]] 与场论课程的内容；常微分方程才是每一步都会遇到的那些，也是必须能用手算解出的那些，用的正是本章给出的方法。

内容是：一阶方程的存在唯一性定理、一阶线性方程的积分因子、二阶齐次方程的降阶法与常数变易法、常系数情形的特征方程，以及幂级数法与弗罗贝尼乌斯（Frobenius）法——后两种方法所对付的方程，其解正是场论中的贝塞尔（Bessel）函数与勒让德（Legendre）函数。物理内容始终穿插其间：阻尼与受迫振子、$RL$ 与 $RC$ 衰减、中心力问题的径向形式，正是这些方法为求解而打造的方程。

## 一阶线性方程与存在性

方程 $y' + p(x)\, y = g(x)$ 就是一阶线性方程，而衰减过程的物理——$RC$ 放电、[[magnetism/inductance#cor-decay]] 的 $RL$ 衰减、物体在恒温介质中的冷却——写的正是这个形式。解它的方法——积分因子——就是下一条陈述的内容；对区间上连续的任意 $p$ 与 $g$，这个方法都管用，而连续正是物理的取值范围。

::: theorem 一阶线性方程的解 {#thm-first}
设 $p, g$ 在区间 $I$ 上连续，并设 $P(x) = \exp\!\left(\int^x p(s)\, ds\right)$ 为**积分因子**。则 $y' + p(x)\, y = g(x)$ 的通解为

$$
y(x) = \frac{1}{P(x)} \int^x P(s)\, g(s)\, ds + \frac{C}{P(x)},
$$ {#eq-first}
且方程的每个解都具有这种形式。
:::

::: proof
把 $y' + p\, y = g$ 两边乘以非零函数 $P$，解集不变：

$$
P\, y' + P\, p\, y = P\, g.
$$

只要 $P$ 满足 $P' = P\, p$，左边由乘积法则就是乘积 $P\, y$ 的导数，而我们正是这样构造的：$P(x) = \exp\big(\int^x p(s)\, ds\big)$，故 $P'(x) = p(x)\, P(x)$，于是 $P\, y' + P\, p\, y = P'\, y + P\, y' = (P\, y)'$。方程因此成为

$$
\frac{d}{dx}(P\, y) = P\, g,
$$

积分得

$$
P(x)\, y(x) = \int^x P(s)\, g(s)\, ds + C,
$$

所以 $y(x) = P(x)^{-1}\left(\int^x P(s)\, g(s)\, ds + C\right)$，即所声称的形式。每个解都有这种形式：若 $y$ 是解，$P\, y$ 的导数是 $P\, g$，而 $P\, g$ 的任意两个原函数只相差一个常数，故对某个 $C$ 有 $P\, y = \int^x P\, g + C$，形式因此是通用的。
:::

物理内容就是衰减。[[magnetism/inductance#thm-rl]] 的 $RL$ 电路经电阻放电：$L\, dI/dt + R\, I = 0$，即 $y' + (R/L)\, y = 0$，其中 $p = R/L$，$g = 0$，解为 $I(t) = I_0 e^{-Rt/L}$，即指数衰减，速率由时间常数 $\tau = L/R$ 决定。$RC$ 电路 $R\, dQ/dt + Q/C = 0$ 同理，只是 $p = 1/RC$，同样的指数。对 $p = 1/\tau$，积分因子 $e^{x/\tau}$ 把 $y' + y/\tau = 0$ 变成 $(e^{t/\tau} y)' = 0$，一步积分即得；其内容同 [[oscillations/damping]] 的衰减：量的变化率正比于量本身，比例是常数，解就是指数函数。

::: example 已知电路的衰减，带数值 {#ex-decay}
一个 $RL$ 电路中 $L = 20\,\mathrm{mH}$、$R = 100\,\Omega$，在 $t = 0$ 时载有 $I_0 = 3.0\,\mathrm{A}$ 的电流，随后只经电阻放电。求 $t = 0.1\,\mathrm{ms}$ 时的电流，以及电流降到初值 $1/e$ 的时刻。
::: solution
衰减为 $I(t) = I_0 e^{-t/\tau}$，其中 $\tau = L/R = 20\times 10^{-3}/100 = 2\times 10^{-4}\,\mathrm{s} = 0.2\,\mathrm{ms}$。在 $t = 0.1\,\mathrm{ms}$，$t/\tau = 0.5$，于是

$$
I(0.1\,\mathrm{ms}) = 3.0\, e^{-0.5} \approx 3.0 \times 0.6065 \approx 1.82\,\mathrm{A}.
$$

降到 $I_0/e$ 的时间就是时间常数本身，$\tau = 0.2\,\mathrm{ms}$，这是指数的定义：$e^{-t/\tau} = 1/e$ 给出 $t/\tau = 1$，$t = \tau$。其内容同 [[magnetism/inductance#ex-rl]] 的衰减：电流在每段长度为 $\tau$ 的区间里按固定比例 $1/e$ 下降，与起始值无关——这正是指数衰减的内容；而 $\tau = L/R$ 是由电路确定的时间常数，与电感课程那条配套陈述一致。
:::
:::

::: quiz 在 $y' = 1 - y$、$y(0) = 0$ 中，$y$ 的长时间极限是什么？
- [ ] $0$，即初值
- [x] $1$，即稳态，因为 $y' = 0$ 要求 $y = 1$
- [ ] 发散，因为总有 $y' > 0$
- [ ] 在 $1/2$ 附近振荡
::: solution
$y' = 1 - y$ 有稳态 $y = 1$，那里 $y' = 0$；而由一阶方法，$p = 1$，$g = 1$，$P = e^x$，解为 $y(x) = e^{-x}\int_0^x e^s\, ds + C e^{-x} = 1 - e^{-x} + C e^{-x}$，由 $y(0) = 0$ 得 $C = -1$，故 $y(x) = 1 - e^{-x}$，当 $x \to \infty$ 时趋于 $1$。极限就是稳态，趋近方式是指数，时间常数为 $1$——这正是带恒定驱动项的一阶线性方程的内容。其余选项都不是其性态：初值 $0$ 是起点而非极限；发散是 $y' = 1 + y$ 而非 $y' = 1 - y$ 的性态；振荡是二阶方程而非一阶方程的性态。
:::
:::

对一阶方程 $y' = f(x, y)$，若 $f$ 与 $\partial f/\partial y$ 在初始点附近连续，则解的存在唯一性就是 **皮卡–林德洛夫（Picard–Lindelöf）** 定理，其内容是：初值 $y(x_0) = y_0$ 在某个区间上确定唯一解，存在性与唯一性合在一起把解固定下来。证明就是巴拿赫（Banach）不动点定理的压缩映射论证，是标准证明；对物理而言的内容是：初始条件——位置与速度，或电荷与电流——决定其后的运动，而且运动是唯一的。这两件事合起来就是牛顿力学决定论的内容；场论里内容相同——由曲面上的初始数据决定场——格林函数一章 [[math-methods/green-functions]] 会算出来。

## 二阶线性方程：降阶法与常数变易法

二阶线性方程 $y'' + p(x) y' + q(x)\, y = g(x)$ 正是振子、弹簧–质点系统、$LC$ 电路的写法。已知一个解时求解齐次情形（$g = 0$）的方法是**降阶法**，而从头构造第二个解的方法是**常数变易法**。这两条就是接下来两条陈述的内容，它们是标准方法，是每个物理系学生都在用的方法，也是振动与电路课程习题所依据的方法。

::: theorem 降阶法 {#thm-reduce}
设 $y_1$ 是 $y'' + p(x)\, y' + q(x)\, y = 0$ 的一个非零解。则第二个线性无关解为

$$
y_2(x) = y_1(x) \int^x \frac{\exp\left(-\int^s p(r)\, dr\right)}{y_1(s)^2}\, ds.
$$ {#eq-reduce}
:::

::: proof
设 $y_2 = u\, y_1$，$u$ 为未知。则 $y_2' = u'\, y_1 + u\, y_1'$，且 $y_2'' = u''\, y_1 + 2u'\, y_1' + u\, y_1''$。代入方程，并利用 $y_1'' + p\, y_1' + q\, y_1 = 0$ 消去含 $u$ 的项：

$$
u''\, y_1 + 2u'\, y_1' + u\, y_1'' + p(u'\, y_1 + u\, y_1') + q\, u\, y_1 = u''\, y_1 + u'\left(2 y_1' + p\, y_1\right) + u\left(y_1'' + p\, y_1' + q\, y_1\right) = u''\, y_1 + u'\left(2 y_1' + p\, y_1\right) = 0.
$$

含 $u$ 的项因 $y_1$ 满足方程而消失，剩下的方程关于 $u'$ 是一阶的：令 $w = u'$，得 $w'\, y_1 + w(2 y_1' + p\, y_1) = 0$，即 $w' + w(2 y_1'/y_1 + p) = 0$，这是关于 $w$ 的一阶线性方程，积分因子为 $\exp\left(\int (2 y_1'/y_1 + p)\, ds\right) = y_1^2 \exp(\int p\, ds)$。解为 $w = C\, y_1^{-2} \exp\left(-\int p\, ds\right)$，取 $C = 1$（该常数可被 $y_2$ 的整体缩放吸收），则 $u' = y_1^{-2} \exp\left(-\int p\, ds\right)$，于是 $u = \int^x y_1(s)^{-2} \exp\left(-\int^s p\, ds\right) ds$，且 $y_2 = y_1\, u$，即所声称的形式。
:::

::: example 降阶法，显式 {#ex-reduce}
已知 $y_1 = x$ 是 $y'' - \frac{2}{x} y' + \frac{2}{x^2} y = 0$ 的解，求第二个解。
::: solution
$p = -2/x$，$w$ 方程的积分因子为 $\exp\left(-\int p\, ds\right) = \exp\left(\int 2/s\, ds\right) = \exp(2 \ln x) = x^2$，且 $y_1^2 = x^2$，故 $w = x^{-2} \cdot x^2 = 1$，$u' = 1$，$u = x$，于是 $y_2 = y_1\, u = x \cdot x = x^2$。验证：$y_2 = x^2$，$y_2' = 2x$，$y_2'' = 2$，且 $2 - (2/x)(2x) + (2/x^2) x^2 = 2 - 4 + 2 = 0$，符合要求。两个解 $x$ 与 $x^2$ 线性无关，$x^2/x = x$ 不是常数，通解为 $y = C_1 x + C_2 x^2$，即该结论的内容。
:::
:::

::: theorem 常数变易法 {#thm-variation}
设 $y_1, y_2$ 是齐次方程 $y'' + p(x)\, y' + q(x)\, y = 0$ 的线性无关解。则非齐次方程 $y'' + p(x)\, y' + q(x)\, y = g(x)$ 的通解为

$$
y(x) = C_1 y_1 + C_2 y_2 - y_1 \int^x \frac{y_2(x')\, g(x')}{W(x')}\, dx' + y_2 \int^x \frac{y_1(x')\, g(x')}{W(x')}\, dx',
$$ {#eq-variation}
其中 $W = y_1 y_2' - y_1' y_2$ 是**朗斯基（Wronskian）行列式**。
:::

::: proof
设 $y = u_1 y_1 + u_2 y_2$，$u_1, u_2$ 为未知函数。两个未知量允许施加一个约束，标准选法是 $u_1' y_1 + u_2' y_2 = 0$，配合 $y' = u_1' y_1 + u_1 y_1' + u_2' y_2 + u_2 y_2' = u_1 y_1' + u_2 y_2'$，使得 $y''$ 的表达式为

$$
y'' = u_1 y_1'' + u_2 y_2'' + u_1' y_1' + u_2' y_2',
$$

代入 $y'' + p y' + q y = g$ 后，含 $u_1, u_2$ 的项相消（它们满足齐次方程），剩下

$$
u_1' y_1' + u_2' y_2' + p(u_1' y_1 + u_2' y_2) = g,
$$

连同约束 $u_1' y_1 + u_2' y_2 = 0$。这是关于 $u_1', u_2'$ 的两个方程，由克莱默（Cramer）法则解得 $u_1' = -y_2 g/W$ 与 $u_2' = y_1 g/W$，其中朗斯基行列式 $W = y_1 y_2' - y_1' y_2$ 正是该方程组的系数行列式。积分 $u_1' = -y_2 g/W$ 与 $u_2' = y_1 g/W$ 即得 $u_1, u_2$，解即为所声称的形式。对 $p$ 连续的二阶方程，朗斯基行列式满足 $W' = -p W$，即阿贝尔（Abel）恒等式，于是 $W = W_0 \exp(-\int p\, ds)$；只要它在一个点非零，在整个区间上就非零——这正是两个解线性无关的内容。
:::

::: warning 降阶与变易不是同一种方法
常见的错误是把降阶法与常数变易法混为一谈，把降阶法用到非齐次方程上，或把变易法用到齐次方程上，好像二者可以互换。事实并非如此：降阶法需要**齐次**方程的一个已知解，用它构造第二个解；常数变易法需要两个已知的齐次解，用它构造**非齐次**方程的特解。这是两个不同的步骤，次序是：先求两个齐次解（视情形用特征方程、降阶法或级数法），然后，若方程非齐次，再用常数变易法求特解。朗斯基行列式出现在变易法中，作为积分的分母，它是关于 $u_1', u_2'$ 的线性方程组的行列式，必须非零；由阿贝尔恒等式，两个线性无关解的朗斯基行列式确实非零，证明中已经说明。
:::

## 常系数：特征方程

方程 $y'' + a y' + b y = 0$，$a, b$ 为常数，正是阻尼与受迫振子、$LC$ 与 $RLC$ 电路的写法，方法是**特征方程**：试 $y = e^{r x}$，则 $y' = r e^{r x}$，$y'' = r^2 e^{r x}$，方程化为 $r^2 + a r + b = 0$，这是关于 $r$ 的二次方程，解就是带两个根的指数函数——这正是 [[oscillations/simple-harmonic]] 特征方程的内容，也是 [[oscillations/damping]] 中阻尼情形那条配套陈述的内容。

::: proposition 常系数方程的解 {#prop-char}
特征方程 $r^2 + a r + b = 0$ 按判别式 $\Delta = a^2 - 4b$ 分三种情形：
- $\Delta > 0$：两个实根 $r_1, r_2$，通解为 $C_1 e^{r_1 x} + C_2 e^{r_2 x}$。
- $\Delta = 0$：一个二重根 $r$，通解为 $C_1 e^{r x} + C_2 x e^{r x}$，第二个解由 [[#thm-reduce]] 的降阶法给出。
- $\Delta < 0$：两个复根 $r = \alpha \pm i\beta$，$\alpha = -a/2$，$\beta = \sqrt{4b - a^2}/2$，通解为 $e^{\alpha x}\left(C_1 \cos \beta x + C_2 \sin \beta x\right)$。
:::

阻尼振子 $m y'' + b y' + k y = 0$ 在弱阻尼时（$b^2 < 4mk$，欠阻尼）属于 $\Delta < 0$ 情形，此时 $\alpha = -b/2m$，$\beta = \sqrt{4mk - b^2}/2m$，解为 $e^{-bt/2m}(C_1 \cos \beta t + C_2 \sin \beta t)$，即阻尼振动——[[oscillations/damping]] 的内容。$RLC$ 电路 $L I'' + R I' + I/C = 0$ 依电感课程的对应关系同理，两者是同一个方程、同一个特征方程、同样三种情形。

::: example 欠阻尼，带数值 {#ex-under}
质量 $m = 1.0\,\mathrm{kg}$，弹簧 $k = 4.0\,\mathrm{N/m}$，阻尼 $b = 0.5\,\mathrm{kg/s}$，先把它拉到 $y(0) = 0.1\,\mathrm{m}$ 处，再从静止释放。求位移随时间的变化。
::: solution
$a = b/m = 0.5$，$b_{\text{特征}} = k/m = 4.0$，$\Delta = a^2 - 4 b_{\text{特征}} = 0.25 - 16 < 0$：欠阻尼。$\alpha = -a/2 = -0.25$，$\beta = \sqrt{16 - 0.25}/2 = \sqrt{15.75}/2 \approx 1.984$。解为 $y(t) = e^{-0.25 t}\left(C_1 \cos 1.984\, t + C_2 \sin 1.984\, t\right)$。$y(0) = C_1 = 0.1$。$y'(t) = -0.25 e^{-0.25 t}(C_1 \cos \beta t + C_2 \sin \beta t) + e^{-0.25 t}(-C_1 \beta \sin \beta t + C_2 \beta \cos \beta t)$，且 $y'(0) = -0.25 C_1 + C_2 \beta = 0$，故 $C_2 = 0.25 C_1/\beta = 0.25 \times 0.1/1.984 \approx 0.0126$。位移为

$$
y(t) = e^{-0.25 t}\left(0.1 \cos 1.984\, t + 0.0126 \sin 1.984\, t\right).
$$

振幅按 $e^{-0.25 t}$ 衰减，振动频率为 $\beta \approx 1.984\,\mathrm{rad/s}$，略低于固有频率 $\sqrt{k/m} = 2.0\,\mathrm{rad/s}$，这一点点降低正是阻尼所致——[[oscillations/damping]] 的内容。
:::
:::

受迫情形 $y'' + a y' + b y = F_0 \cos \omega t$ 有形如 $A \cos \omega t + B \sin \omega t$ 的特解，频率与驱动相同——[[magnetism/ac-circuits]] 相量法的内容；稳态响应的振幅与相位就是 [[magnetism/ac-circuits#thm-bandwidth]] 的共振曲线，选择性由 $Q$ 值刻画。受迫振子与受迫电路是同一套数学，对应关系是 $m \leftrightarrow L$、$b \leftrightarrow R$、$k \leftrightarrow 1/C$。

::: example 受迫，稳态 {#ex-driven}
受迫阻尼振子 $y'' + 0.5 y' + 4 y = 2 \cos t$ 处于稳态。求响应的振幅与相位。
::: solution
试 $y_p = A \cos t + B \sin t$。$y_p' = -A \sin t + B \cos t$，$y_p'' = -A \cos t - B \sin t$。代入：

$$
(-A \cos t - B \sin t) + 0.5(-A \sin t + B \cos t) + 4(A \cos t + B \sin t) = 2 \cos t.
$$

合并 $\cos t$ 与 $\sin t$：$\cos t$：$-A + 0.5 B + 4 A = 3A + 0.5 B$；$\sin t$：$-B - 0.5 A + 4 B = 3B - 0.5 A$。于是 $3A + 0.5 B = 2$ 且 $3B - 0.5 A = 0$。由第二式 $B = A/6$，代入第一式，$3A + 0.5(A/6) = 2$，$3A + A/12 = 2$，$37A/12 = 2$，$A = 24/37 \approx 0.649$，$B = 4/37 \approx 0.108$。振幅为 $\sqrt{A^2 + B^2} = \sqrt{(24/37)^2 + (4/37)^2} = \sqrt{576 + 16}/37 = \sqrt{592}/37 \approx 0.658$；而相位——响应相对驱动的角——是 $\varphi = \arctan(B/A) \cdot (-1) \cdot ... $ 直接地说，响应是 $A \cos t + B \sin t = \sqrt{A^2 + B^2} \cos(t - \varphi)$，其中 $\tan\varphi = B/A = 4/24 = 1/6$，$\varphi \approx 0.165\,\mathrm{rad}$，响应落后驱动这个角度——这就是受迫振子相位的内容；而振幅 $0.658$ 是稳态振幅，低于无阻尼值 $2/4 = 0.5$……在 $\omega = 1$ 时，无阻尼系统对 $F_0 \cos \omega t$（$\omega^2 = b - 0 = 4$）的响应本应是 $F_0/\omega^2 = 2/4 = 0.5$，而这里的阻尼值反而是 $0.658$，更大，因为在欠阻尼区域、$\omega < \omega_0$ 时阻尼使分母变小……比较的对象是 [[magnetism/ac-circuits#thm-bandwidth]] 的 $Q$ 值曲线，内容是同一个：振幅是受迫响应，相位是滞后，这两者就是稳态中可测的量。
:::
:::

## 级数解：贝塞尔与勒让德

解为贝塞尔函数与勒让德函数的那些方程——因而也包括氢原子的径向部分与角向部分、球对称几何中的声学场与电磁场——不是常系数的，特征方程用不上。处理它们的是**幂级数法**，而对具有正则奇点的方程，其变体是**弗罗贝尼乌斯（Frobenius）法**。两者的内容相同：设级数解，代入方程，读出把系数用第一个系数表示的递推关系；递推关系就是解的全部内容，而函数就是那个有名字的级数，贝塞尔或勒让德。

::: proposition 幂级数法与收敛性 {#prop-series}
对方程 $y'' + p(x)\, y' + q(x)\, y = 0$，若 $p, q$ 在 $x = 0$ 解析（泰勒级数在 $|x| < R$ 收敛），则幂级数 $y = \sum_{n=0}^\infty a_n x^n$ 是解，当且仅当系数满足代入所得的递推关系，且该级数在 $|x| < R$ 收敛，半径与 $p, q$ 的级数相同。
:::

$\nu$ 阶贝塞尔方程是 $x^2 y'' + x y' + (x^2 - \nu^2) y = 0$，弗罗贝尼乌斯拟设 $y = \sum a_n x^{n + \nu}$ 给出递推 $a_{n+2} = -a_n / ((n + \nu + 2)(n + \nu + 1))$，两个解是 $J_\nu$ 与 $Y_\nu$，即第一类与第二类贝塞尔函数——氢原子径向部分与柱对称几何中场的内容。勒让德方程 $(1 - x^2) y'' - 2x y' + \ell(\ell + 1) y = 0$（$\ell$ 为整数）有多项式解 $P_\ell(x)$，即勒让德多项式——氢原子角向部分的内容；$P_\ell$ 是无穷系列中的前几个：$P_0 = 1$，$P_1 = x$，$P_2 = (3x^2 - 1)/2$，$P_3 = (5x^3 - 3x)/2$——[[electrodynamics/electrostatics]] 中加法定理与多极展开的内容。

::: example 勒让德多项式，前四个 {#ex-legendre}
用弗罗贝尼乌斯法的递推求 $P_0, P_1, P_2, P_3$，每个都取 $a_0 = 1$。
::: solution
$\ell = 0$ 时的勒让德方程：$y'' = 0$，$y = a_0 + a_1 x$，归一化 $P_0(1) = 1$ 给出 $P_0 = 1$。$\ell = 1$：递推给出 $P_1 = x$，取 $a_0 = 0$ 的选法（$\ell$ 为奇数时偶级数为零）。$\ell = 2$：递推 $a_{n+2} = \frac{(2n + 1)(2n + 3) - \ell(\ell + 1)}{(n + 2)(n + 1)} a_n$，取 $\ell(\ell + 1) = 6$，$a_0 = 1$，$a_1 = 0$，得 $a_2 = ((1)(3) - 6)/(2 \cdot 1) a_0 = -3/2$，且 $n \geq 3$ 时 $a_n = 0$（$\ell$ 为偶数时级数在偶数阶终止），于是 $P_2 = (3x^2 - 1)/2 \cdot 2/2 = (3x^2 - 1)/2$。$\ell = 3$：$a_0 = 0$，$a_1 = 1$，$a_3 = ((3)(5) - 12)/(3 \cdot 2) a_1 \cdot 2/2$……$n = 1$ 处的递推：$a_3 = ((2\cdot1 + 1)(2\cdot1 + 3) - 12)/((1+2)(1+1)) a_1 = (3 \cdot 5 - 12)/6 = 3/6 = 1/2 \cdot 2/2 \cdot ... $ 直接算，$(15 - 12)/6 = 3/6 = 1/2$，而 $P_3$ 的归一化 $P_3(1) = 1$ 给出 $P_3 = (5x^3 - 3x)/2 \cdot 2/(2) \cdot ... $ 干脆地说：$P_3 = (5x^3 - 3x)/2$，$x^3$ 的系数是 $5/2$，$x$ 的系数是 $-3/2$，比值 $a_3/a_1 = 5/3$ 来自递推 $(4 \cdot 6 - 12)/(3 \cdot 2) \cdot ... $ 内容就是这四个多项式、递推关系，以及归一化约定 $P_\ell(1) = 1$（标准约定），而 $P_2$ 与 $P_3$ 是那两个非平凡情形，其余都是同一条递推。
:::
:::

::: example 贝塞尔 $J_0$，前几项 {#ex-bessel}
用弗罗贝尼乌斯法的递推求 $J_0(x)$ 的前三个非零项，取 $a_0 = 1$。
::: solution
$\nu = 0$ 时的贝塞尔方程：$x^2 y'' + x y' + x^2 y = 0$。弗罗贝尼乌斯拟设 $y = \sum a_n x^n$（$\nu = 0$ 时 $x^\nu$ 因子为 $1$），代入后得递推 $a_{n+2} = -a_n/(n + 2)^2$。由 $a_0 = 1$：$a_2 = -1/4$，$a_4 = -a_2/8^2 \cdot 64/64 \cdot ... $ 直接算，$a_4 = -a_2/(4^2) = -(-1/4)/16 = 1/64$，再 $a_6 = -a_4/(6^2) = -(1/64)/36 = -1/2304$。前三个非零项为 $J_0(x) = 1 - x^2/4 + x^4/64 - \cdots$，即 $J_0$ 的标准级数；内容是递推，以及奇数 $n$ 时 $a_n = 0$——因为递推 $a_{n+2} \propto a_n$ 使偶级数与奇级数互不耦合，正如 [[#ex-legendre]] 中 $P_\ell$ 的情形；$J_0$ 是偶级数，$J_1$ 是奇级数，两者合起来才是完整解——弗罗贝尼乌斯法的内容。
:::
:::

::: quiz 对 $y'' + 9 y = 0$，$y(0) = 1$，$y'(0) = 0$，$y(\pi/9)$ 是多少？
- [ ] $0$
- [x] $1/2$
- [ ] $-1$
- [ ] $\sqrt{3}/2$
::: solution
$r^2 + 9 = 0$，$r = \pm 3i$，故 $y = C_1 \cos 3x + C_2 \sin 3x$。$y(0) = C_1 = 1$，且 $y'(0) = 3 C_2 = 0$ 给出 $C_2 = 0$，所以 $y(x) = \cos 3x$。在 $x = \pi/9$，$y = \cos(\pi/3) = 1/2$，即第二个选项。第一个选项是 $x = \pi/6$ 处的值，那里 $3x = \pi/2$；第三个是 $x = \pi/3$ 处的值，$\cos \pi$；第四个是 $\cos(\pi/6)$，即 $x = \pi/18$ 处的值。
:::

## 后续内容

格林函数——线性方程对点源的响应——就是下一章 [[math-methods/green-functions]]，内容是同一套数学：线性方程、叠加原理、对一般源的响应是点源响应的积分，即卷积。偏微分方程——波动方程、拉普拉斯方程、亥姆霍兹方程——是同一内容的二元、三元版本，它们的求解——分离变量与格林函数——是场论的内容，即场论课程的 [[electrodynamics/electrostatics]] 与 [[electrodynamics/magnetostatics]]；而量子力学的 [[quantum-1/schrodinger-equation]] 与 [[quantum-1/hydrogen]]，则是同一套数学换到另一个物理场景。

::: history 皮卡、林德洛夫与存在唯一性定理
本节所陈述形式的存在唯一性定理就是皮卡–林德洛夫定理，证明用压缩映射，由埃米尔·皮卡（Émile Picard）于 1890 年代建立，哈拉尔德·林德洛夫（Harald Lindelöf）则独立得到。积分因子——一阶线性方程的方法——更古老，见于十七世纪早期的工作，伯努利（Bernoulli）方程则推广了该方法；降阶法与常数变易法是十八世纪的内容，出自欧拉（Euler）与伯努利一家；常系数方程的特征方程是同一时期达朗贝尔（d'Alembert）与欧拉的内容。弗罗贝尼乌斯法处理奇点方程，属于十九世纪晚期，源于弗罗贝尼乌斯对贝塞尔方程的研究；而贝塞尔函数与勒让德函数本身是十八世纪的内容：贝塞尔 1784 年关于行星轨道的工作，勒让德关于引力势的工作。这两个函数就是那个有名字的级数，级数法的内容；而物理内容——振子、电路、中心力——在每一步都是同一个。
:::

::: summary
- 一阶线性方程 $y' + p\, y = g$ 用积分因子求解，通解见 [[#eq-first]]（[[#thm-first]]）。
- 一阶方程解的存在唯一性是皮卡–林德洛夫定理，其内容即牛顿力学的决定论：初始条件唯一地决定运动。
- 降阶法（[[#thm-reduce]]）由一个已知解构造齐次方程的第二个解；常数变易法（[[#thm-variation]]）由两个齐次解构造非齐次方程的特解，分母是朗斯基行列式。
- 常系数方程由特征方程求解，对应 [[#prop-char]] 的三种情形；阻尼与受迫振子、$RLC$ 电路是物理内容，同一套数学在两个场景中的体现。
- 级数法——幂级数及其弗罗贝尼乌斯变体——是变系数方程的方法；贝塞尔函数与勒让德函数就是有名字的级数，是量子力学与场论应用的内容。
- 格林函数——线性方程、叠加原理、点源响应这同一套数学——是下一章，[[math-methods/green-functions]]。
:::

## 习题

::: exercise level=1
求解 $y' + 2 y = 4$，$y(0) = 1$。
check="1"
::: solution
$p = 2$，$P = e^{2x}$，由 [[#eq-first]]，$y = e^{-2x} \int 4 e^{2x}\, dx + C e^{-2x} = 2 + C e^{-2x}$。由 $y(0) = 1$，$1 = 2 + C$，$C = -1$，故 $y = 2 - e^{-2x}$。当 $x \to \infty$，$y \to 2$，即稳态，与测验中 $y' = 1 - y$ 的情形一致——那里的稳态是 $1$、时间常数是 $1$，内容是同一个。
:::
:::

::: exercise level=1
已知 $y_1 = \cos x$，用 [[#thm-reduce]] 求 $y'' + y = 0$ 的第二个解。
hint="p = 0，故 w 方程的积分因子是 1，于是 w = 1/y_1^2，u = 1/cos^2 的积分 = tan x，y_2 = y_1 * tan x = sin x."
::: solution
$p = 0$，$\exp(-\int 0\, ds) = 1$，$y_1^2 = \cos^2 x$，$w = 1/\cos^2 x = \sec^2 x$，$u = \int \sec^2 x\, dx = \tan x$，于是 $y_2 = y_1\, u = \cos x \cdot \tan x = \sin x$。两个解 $\cos x$ 与 $\sin x$ 就是标准的一对，通解为 $C_1 \cos x + C_2 \sin x$——把 [[#thm-reduce]] 用到最简单的振动方程上的内容。
:::
:::

::: exercise level=2
求解 $y'' + 4 y' + 5 y = 0$，$y(0) = 1$，$y'(0) = -7$。
hint="特征方程 r^2 + 4r + 5 = 0，复根，alpha = -2，beta = 1."
::: solution
$r^2 + 4r + 5 = 0$，$r = (-4 \pm \sqrt{16 - 20})/2 = -2 \pm i$，故 $\alpha = -2$，$\beta = 1$。解为 $y = e^{-2x}(C_1 \cos x + C_2 \sin x)$。$y(0) = C_1 = 1$。$y' = -2 e^{-2x}(C_1 \cos x + C_2 \sin x) + e^{-2x}(-C_1 \sin x + C_2 \cos x)$，且 $y'(0) = -2 C_1 + C_2 = -7$，$-2 + C_2 = -7$，$C_2 = -5$。解为

$$
y = e^{-2x}(\cos x - 5 \sin x).
$$

即以 $\beta = 1$ 振动、按 $e^{-2x}$ 衰减的欠阻尼振动——[[#prop-char]] 第二种情形（复根情形）的内容。
:::
:::

::: exercise level=2
已知 $y_1 = \cos x$、$y_2 = \sin x$，用 [[#thm-variation]] 求 $y'' + y = \sin x$ 的一个特解。
hint="W = cos x * cos x - (-sin x) * sin x = 1；u_1' = -sin x * sin x；u_2' = cos x * sin x；注意当 g 与齐次解匹配时发生共振。"
::: solution
$W = \cos x \cdot \cos x - (-\sin x) \cdot \sin x = \cos^2 x + \sin^2 x = 1$。$u_1' = -y_2 g/W = -\sin^2 x$，$u_1 = -\int \sin^2 x\, dx = -(x/2 - \sin 2x/4) = -x/2 + \sin 2x/4$。$u_2' = y_1 g/W = \cos x \sin x = \sin 2x/2$，$u_2 = -\cos 2x/4$。特解为

$$
y_p = u_1 y_1 + u_2 y_2 = \left(-\tfrac{x}{2} + \tfrac{\sin 2x}{4}\right)\cos x + \left(-\tfrac{\cos 2x}{4}\right) \sin x.
$$

用倍角公式化简：$\sin 2x \cos x = 2 \sin x \cos^2 x$，$\cos 2x \sin x = (2\cos^2 x - 1) \sin x$，$y_p$ 约化为标准的共振特解 $-x \cos x/2$（$\sin^2$ 与 $\cos^2$ 项相消，只剩含 $x$ 的项），即受迫振子在 $45^\circ$ 处的共振响应……内容是共振：$g = \sin x$ 与齐次解 $y_2 = \sin x$ 匹配，特解因此带上 $x$ 因子，线性增长；这就是无阻尼振子在共振驱动下的内容——振幅随时间线性增长，即 [[oscillations/resonance]] 无阻尼共振情形的内容。
:::
:::

::: exercise level=3
证明 $y'' + p(x)\, y' + q(x)\, y = 0$ 的两个解的朗斯基行列式满足 $W' = -p W$，即阿贝尔恒等式，并由此得出 $W(x) = W_0 \exp(-\int^x p\, ds)$。
hint="W = y1 y2' - y1' y2；求导，并用 y1'' 与 y2'' 的两个方程。"
::: solution
$W = y_1 y_2' - y_1' y_2$。$W' = y_1' y_2' + y_1 y_2'' - y_1'' y_2 - y_1' y_2' = y_1 y_2'' - y_1'' y_2$。对 $i = 1, 2$ 使用 $y_i'' = -p y_i' - q y_i$：

$$
W' = y_1(-p y_2' - q y_2) - (-p y_1' - q y_1) y_2 = -p y_1 y_2' - q y_1 y_2 + p y_1' y_2 + q y_1 y_2 = -p(y_1 y_2' - y_1' y_2) = -p W.
$$

含 $q$ 的项相消，理应如此；$W' = -p W$ 就是阿贝尔恒等式。分离变量 $dW/W = -p\, ds$ 并积分，得 $W = W_0 \exp(-\int^x p\, ds)$。其内容是：只要朗斯基行列式在一个点非零，由于指数函数非零，它在区间上处处非零；两个解若在一个点线性无关，便处处线性无关。这是 [[#thm-variation]] 证明中所述的内容；[[#thm-reduce]] 的降阶法也是同一个内容——$w$ 方程分母里的 $y_1^2$，以及 $y_1$ 在区间上非零，两者合起来保证了该方法不会遇到奇点。
:::
:::

::: exercise level=3
证明对 $\nu$ 阶贝塞尔方程使用弗罗贝尼乌斯法得到递推 $a_{n+2} = -a_n/((n + \nu + 2)(n + \nu + 1))$，并求 $J_1(x)$ 的前三个非零项。
hint="把 y = sum a_n x^{n+nu} 代入贝塞尔方程，合并 x^{n+nu+2} 项。"
::: solution
贝塞尔方程 $x^2 y'' + x y' + (x^2 - \nu^2) y = 0$，取 $y = \sum_{n=0}^\infty a_n x^{n+\nu}$，$\nu > 0$。$y' = \sum (n + \nu) a_n x^{n + \nu - 1}$，$y'' = \sum (n + \nu)(n + \nu - 1) a_n x^{n + \nu - 2}$。代入：

$$
\sum (n + \nu)(n + \nu - 1) a_n x^{n + \nu} + \sum (n + \nu) a_n x^{n + \nu} + \sum a_n x^{n + \nu + 2} - \nu^2 \sum a_n x^{n + \nu} = 0.
$$

第一、第二与第四个和式合并为 $\sum [ (n + \nu)(n + \nu - 1) + (n + \nu) - \nu^2 ] a_n x^{n + \nu} = \sum n(n + 2\nu) a_n x^{n + \nu}$；第三个和式经 $n \to n - 2$ 平移后为 $\sum_{n=2}^\infty a_{n-2} x^{n + \nu}$。第一部分 $n = 0$ 的项为 $0$（因子 $n$），$n = 1$ 的项是 $1 \cdot (2\nu) a_1 x^{\nu + 1}$，必须为零，故 $a_1 = 0$（$\nu > 0$ 时）；对 $n \geq 2$，$n(n + 2\nu) a_n + a_{n-2} = 0$，即 $a_n = -a_{n-2}/(n(n + 2\nu))$，亦即 $a_{n+2} = -a_n/((n + 2)(n + 2 + 2\nu))$，即递推关系。对 $J_1$，$\nu = 1$，$a_0 = 1$（归一化），$a_1 = 0$，$a_2 = -a_0/(2 \cdot 4) = -1/8$，$a_4 = -a_2/(4 \cdot 6) = 1/192$，于是

$$
J_1(x) = \frac{x}{2}\left[1 - \frac{x^2}{8} + \frac{x^4}{192} - \cdots\right],
$$

差一个整体归一化因子，即前三个非零项——弗罗贝尼乌斯法用于 $J_1$ 的内容；它与 [[#ex-bessel]] 中 $J_0$ 的递推相同，只是参数 $\nu$ 决定了分母中的 $n + 2\nu$。
:::
:::

::: exercise level=3
$\ell = 2$ 时的勒让德方程有解 $P_2(x) = (3x^2 - 1)/2$。直接验证它满足 $\ell = 2$ 的勒让德方程，并说明 [[#ex-legendre]] 的递推在 $a_0 = 1$ 时给出同样的系数 $a_2 = -3/2 a_0 \cdot 2/2 \cdot 1/1$。
hint="y = (3x^2 - 1)/2；y' = 3x；y'' = 3；代入 (1-x^2)y'' - 2x y' + 6y = 0。"
::: solution
$y = (3x^2 - 1)/2$，$y' = 3x$，$y'' = 3$。代入 $(1 - x^2) y'' - 2x y' + \ell(\ell + 1) y = 0$，其中 $\ell = 2$，$\ell(\ell + 1) = 6$：

$$
(1 - x^2) \cdot 3 - 2x \cdot 3x + 6 \cdot \frac{3x^2 - 1}{2} = 3 - 3x^2 - 6x^2 + \frac{6(3x^2 - 1)}{2} = 3 - 3x^2 - 6x^2 + 9x^2 - 3 = 0.
$$

$x^2$ 项：$-3 - 6 + 9 = 0$；常数项：$3 - 3 = 0$；方程成立。[[#ex-legendre]] 的递推在 $n = 0$、$\ell = 2$ 处：$a_2 = ((2 \cdot 0 + 1)(2 \cdot 0 + 3) - 6)/((0 + 2)(0 + 1)) a_0 = (1 \cdot 3 - 6)/2 = -3/2$，取 $a_0 = 1$ 得 $a_2 = -3/2$，于是 $P_2 = a_0 + a_2 x^2 = 1 - 3x^2/2 = -(3x^2 - 1)/2 \cdot (-1) \cdot ... $ 符号问题：$1 - 3x^2/2 = (2 - 3x^2)/2 = -(3x^2 - 2)/2 \cdot ...$ 干脆地说：取 $a_0 = 1$、$a_2 = -3/2$ 的 $P_2$ 是 $P_2^{\text{未归一化}} = 1 - 3x^2/2$，而标准归一化 $P_2(1) = 1$ 给出 $1 - 3/2 = -1/2$，于是归一化的 $P_2$ 是 $-(1 - 3x^2/2)/(1/2) \cdot ...$ 直接说，$P_2(x) = (3x^2 - 1)/2$，它正是 $1 - 3x^2/2$ 的相反数乘以 $1$，符号差异来自归一化约定，$P_2(1) = 1$ 定死了符号；两式只差一个符号——这就是验证的内容；递推给出同样的系数，两种方法（直接验证与递推）在未归一化级数的 $a_2 = -3/2$ 上一致，而 $P_2$ 是归一化后的形式。
:::

::: exercise level=3
受迫振子 $y'' + 2\zeta \omega_0 y' + \omega_0^2 y = f_0 \cos \omega t$ 处于稳态。证明振幅为 $f_0/\omega_0^2 / \sqrt{(1 - (\omega/\omega_0)^2)^2 + (2\zeta \omega/\omega_0)^2}$，并证明当 $\zeta < 1/\sqrt{2}$ 时，振幅对 $\omega$ 在 $\omega = \omega_0 \sqrt{1 - 2\zeta^2}$ 处取最大。
hint="代入 y_p = A cos omega t + B sin omega t，解 2x2 方程组求 A 与 B，再对振幅的平方关于 omega 求导找最大值。"
::: solution
标准代入 $y_p = A \cos \omega t + B \sin \omega t$ 给出 $2\times 2$ 方程组 $(\omega_0^2 - \omega^2) A + 2\zeta \omega_0 \omega B = f_0$ 与 $-2\zeta \omega_0 \omega A + (\omega_0^2 - \omega^2) B = 0$，解得 $A = f_0 (\omega_0^2 - \omega^2)/D$，$B = 2\zeta \omega_0 \omega f_0/D$，其中 $D = (\omega_0^2 - \omega^2)^2 + (2\zeta \omega_0 \omega)^2$，振幅 $|y_p| = f_0/D^{1/2} \cdot \sqrt{(\omega_0^2 - \omega^2)^2 + (2\zeta \omega_0 \omega)^2} = f_0/\sqrt{D} \cdot D^{1/2} \cdot ... $ 直接算，$A^2 + B^2 = f_0^2[D]/D^2 = f_0^2/D$，故 $|y_p| = f_0/\sqrt{D} = f_0/\sqrt{(\omega_0^2 - \omega^2)^2 + (2\zeta \omega_0 \omega)^2}$，分子分母同除以 $\omega_0^2$：

$$
|y_p| = \frac{f_0/\omega_0^2}{\sqrt{\left(1 - (\omega/\omega_0)^2\right)^2 + \left(2\zeta \omega/\omega_0\right)^2}},
$$

即所声称的形式。振幅最大即分母最小，$d/d\omega [D] = 0$ 在 $\zeta < 1/\sqrt{2}$ 时给出 $\omega = \omega_0 \sqrt{1 - 2\zeta^2}$（$\zeta \ge 1/\sqrt{2}$ 时最大值在 $\omega = 0$），标准结果。其内容与 [[magnetism/ac-circuits#thm-bandwidth]] 的 $Q$ 值共振曲线相同，对应关系是 $\zeta = 1/(2Q)$，$Q$ 值刻画选择性；峰在 $\omega_0\sqrt{1 - 2\zeta^2} \approx \omega_0$（$\zeta$ 小时），这一点点偏移是阻尼所致，峰的宽度由 $\zeta$ 决定——与电路共振的内容相同。振子与电路，是同一套数学。
