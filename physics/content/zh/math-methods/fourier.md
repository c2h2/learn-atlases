周期量会重复自身。交变电源的电压、被拨动弦的位移、圆环一周的温度，都在一个固定间隔——周期——之后回到同一个值。在一个周期上，图像可以是光滑的，也可以有跳跃。无论哪种情形，实际的问题都相同：这张图像能否由纯正弦重建？如果能，各要用多大的振幅？

叠加原理让这个问题变得有用。单个正弦既解振子方程也解波动方程，正如 [[oscillations/superposition]] 中所示。一个正弦之和——每一项都在基频的整数倍上——解同一个线性方程，而系数一开始是自由的，直到初始形状把它们定下来。这些系数的清单就是傅里叶（Fourier）级数。能量与均方大小不是第二个谜：系数一旦知道，帕塞瓦尔（Parseval）定理无需回到原图就能把它们读出来。

傅里叶引入级数是为了解热方程。我们不在本章解那个方程。我们计算系数，证明定义它们的积分为什么是对的那些，看看部分和在跳跃处做什么，然后让周期变得很长。那个极限就是傅里叶变换，采用的约定我们会小心地固定下来。变换的复积分属于 [[math-methods/complex-methods]]。吃掉这些展开的微分方程属于 [[math-methods/odes]]。

## 由正交性定系数 {#coefficients}

先把周期取为 $2\pi$。函数 $f$ 在两边都有定义之处满足 $f(x+2\pi) = f(x)$。同周期的基本构件是常数函数，加上每个整数 $n \ge 1$ 对应的 $\cos nx$ 与 $\sin nx$。这些就是谐波。第 $n$ 次谐波在 $[-\pi, \pi]$ 上振荡 $n$ 次。

::: definition 傅里叶系数与傅里叶级数 {#def-fourier}
设 $f$ 在 $[-\pi, \pi]$ 上可积。它的**傅里叶系数**是

$$
a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,\dd x \qquad (n \ge 0),
$$ {#eq-an}

$$
b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,\dd x \qquad (n \ge 1).
$$ {#eq-bn}

$f$ 的**傅里叶级数**是三角级数

$$
\frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos nx + b_n\sin nx\bigr).
$$ {#eq-series}
:::

常数项写作 $a_0/2$，而不是 $a_0$。原因是记账，而且值得在任何积分算出来之前先把这笔账定死。[[#eq-an]] 在 $n = 0$ 处给出

$$
a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\,\dd x,
$$

所以 $a_0/2$ 恰好是 $f$ 在一个周期上的平均值，

$$
\frac{a_0}{2} = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(x)\,\dd x.
$$

若对每个 $n$（包括零）都用同一个积分配方，常数项就必须带上多余的因子 $\tfrac12$。忘了它，平均值就翻了一倍。这个疏漏在习题里还会再遇到一次。

对任何可积的 $f$，这些积分都是合法的定义。它们本身并不说明级数收敛，也不说明级数收敛到 $f$。那些是后面的定理。我们能立刻证明的是谐波正交，因此一个一致收敛的三角级数在系数上没有选择的余地。

::: lemma 一个周期上的正交性 {#lem-orth}
对整数 $m, n \ge 0$，

$$
\begin{aligned}
\int_{-\pi}^{\pi}\cos mx\cos nx\,\dd x
&=
\begin{cases}
2\pi & \text{若 } m = n = 0,\\
\pi & \text{若 } m = n \ge 1,\\
0 & \text{若 } m \neq n,
\end{cases}
\\[0.4em]
\int_{-\pi}^{\pi}\sin mx\sin nx\,\dd x
&=
\begin{cases}
\pi & \text{若 } m = n \ge 1,\\
0 & \text{若 } m \neq n,
\end{cases}
\\[0.4em]
\int_{-\pi}^{\pi}\sin mx\cos nx\,\dd x
&= 0.
\end{aligned}
$$
:::

::: proof
积化和差公式就够了。对余弦，若 $m$ 与 $n$ 不全为零，

$$
\cos mx\cos nx = \frac{1}{2}\Bigl(\cos(m+n)x + \cos(m-n)x\Bigr).
$$

若 $m \neq n$，则 $m+n$ 与 $m-n$ 都是非零整数，而 $\cos kx$ 在 $[-\pi, \pi]$ 上的积分对每个非零整数 $k$ 都消失。若 $m = n \ge 1$，第二个余弦是 $\cos 0 = 1$，于是

$$
\int_{-\pi}^{\pi}\cos^2 nx\,\dd x = \int_{-\pi}^{\pi}\frac{1 + \cos 2nx}{2}\,\dd x = \pi.
$$

若 $m = n = 0$，被积函数是 $1$，积分是 $2\pi$。

对正弦，同样的化简在 $m = n \ge 1$ 时给出 $\int\sin^2 nx\,\dd x = \pi$，而 $m \neq n$ 再次只剩下余弦的完整周期。交叉积分在改写成

$$
\sin mx\cos nx = \frac{1}{2}\Bigl(\sin(m+n)x + \sin(m-n)x\Bigr),
$$

是对称区间上奇函数的积分；或者当 $m = n$ 时，是 $\tfrac12\sin 2nx$ 的积分，同样为零。清单里的每个交叉项因此都为零。
:::

::: intuition 振幅，不是新函数
每个系数是一次谐波的大小，正如一个乐音有一个基音和一串泛音。正交性说的是：在整数个周期上取平均时，这些泛音互不重叠——一个谐波与另一个谐波的积分是零，所以 $f$ 对 $\cos nx$ 的积分只看见 $a_n$。改 $a_3$ 不会改 $b_1$。级数就是一串相互独立的振幅。[[oscillations/superposition]] 对行波是同一个想法；这里的"波"是固定周期上的谐波。
:::

::: theorem 一致收敛展开的唯一性 {#thm-unique}
设

$$
f(x) = \frac{A_0}{2} + \sum_{n=1}^{\infty}\bigl(A_n\cos nx + B_n\sin nx\bigr)
$$

在 $[-\pi, \pi]$ 上成立，并设级数在其中一致收敛。则 $A_n = a_n$、$B_n = b_n$，就是积分 [[#eq-an]] 与 [[#eq-bn]]。特别地，一个函数至多有一个这种形式的一致收敛三角展开。
:::

::: proof
一致收敛允许我们对有界连续函数 $\cos mx$ 逐项积分。两边乘以 $\cos mx$ 并在 $[-\pi, \pi]$ 上积分。[[#lem-orth]] 消掉除带 $A_m$ 那一项之外的所有项。对 $m \ge 1$，幸存的积分是 $A_m \pi$，而左端是 $\int f\cos mx\,\dd x$。于是 $A_m = a_m$。对 $m = 0$，幸存的积分是 $(A_0/2)\cdot 2\pi = A_0\pi$，同样的比较给出 $A_0 = a_0$。改乘 $\sin mx$ 就单独解出 $B_m = b_m$。若两个一致收敛的三角级数有相同的和，它们的差就是一个和为零的一致收敛级数，其系数全部为零。
:::

假设很重要。[[#thm-unique]] 并不说每个可积的 $f$ 都等于它的傅里叶级数。它说的是：若一个一致收敛的三角级数的和是 $f$，系数就必然是那些傅里叶积分。许多物理上有用的函数恰恰因为有跳跃而做不到一致收敛。它们的系数仍由 [[#eq-an]] 与 [[#eq-bn]] 定义，而另一个定理——狄利克雷（Dirichlet）的定理——说清了级数加起来是什么。会算了之后我们再来讲它。

奇偶函数能缩短算账。若 $f(-x) = f(x)$，则 $f(x)\sin nx$ 是奇函数，每个 $b_n$ 都为零，只剩余弦级数。若 $f(-x) = -f(x)$，每个 $a_n$ 都为零（包括 $a_0$），只剩正弦级数。下面的方波是奇的。绝对值函数是偶的。积分之前先用对称性：它不费计算就消掉一半系数。

::: example 有限的三角多项式 {#ex-finite}
设 $f(x) = 2 + 3\cos 2x - \sin x$。直接读出傅里叶系数，并用积分核对 $b_1$。
::: solution
这个函数本身已经是三角多项式，级数有限，因而一致收敛。[[#thm-unique]] 说，只要把常数项对上 $a_0/2$，系数就是眼前这些。这里常数项是 $2$，所以 $a_0/2 = 2$、$a_0 = 4$。$\cos 2x$ 的系数是 $a_2 = 3$。$\sin x$ 的系数是 $b_1 = -1$。其余每个 $a_n$ 与 $b_n$ 都是零。

$b_1$ 的积分检验值得做一次，因为它是那些没写成多项式的函数所遵循的样板。由 [[#eq-bn]]，

$$
b_1 = \frac{1}{\pi}\int_{-\pi}^{\pi}\bigl(2 + 3\cos 2x - \sin x\bigr)\sin x\,\dd x.
$$

把被积函数拆成三块。$2\sin x$ 在整数个周期上的积分是零。中间一块用恒等式 $\sin x\cos 2x = \tfrac12\bigl(\sin 3x - \sin x\bigr)$，得到的全是正弦的完整周期，所以那个积分也为零。最后一块是

$$
\frac{1}{\pi}\int_{-\pi}^{\pi}\bigl(-\sin^2 x\bigr)\,\dd x = -\frac{1}{\pi}\int_{-\pi}^{\pi}\frac{1 - \cos 2x}{2}\,\dd x = -\frac{1}{\pi}\cdot\pi = -1.
$$

于是 $b_1 = -1$，与直接从式子里读出的系数一致。常数项不是 $a_0$。若往后的计算把这个 $f$ 的平均值报成 $4$，那就是把因子 $\tfrac12$ 丢了：平均值是 $2$。
:::
:::

## 四个级数的计算 {#computed}

这一节的计算就是全部方法：先定对称性，然后分部积分或用积化和差，再用 $\cos n\pi = (-1)^n$ 与 $\sin n\pi = 0$ 化简。下面没有一处用到收敛定理。积分存在，系数就存在。级数加起来是什么是下一节的事，需要数值核对时我们会说明。

::: example 方波 {#ex-square}
在 $(-\pi, \pi)$ 上定义 $f$：$-\pi < x < 0$ 时 $f(x) = -1$，$0 < x < \pi$ 时 $f(x) = 1$，再以周期 $2\pi$ 周期延拓。有限多个跳跃点 $x = n\pi$ 处的取值不影响任何积分。求傅里叶级数。
::: solution
对每个 $n$，被积函数 $f(x)\cos nx$ 都是奇的，因为 $f$ 是奇的而 $\cos nx$ 是偶的，所以所有 $n \ge 0$ 都有 $a_n = 0$。没有余弦项，也没有常数项。对正弦系数，被积函数是偶的，于是

$$
b_n = \frac{2}{\pi}\int_{0}^{\pi}\sin nx\,\dd x = \frac{2}{\pi}\left[-\frac{\cos nx}{n}\right]_{0}^{\pi} = \frac{2}{\pi n}\bigl(1 - \cos n\pi\bigr) = \frac{2\bigl(1 - (-1)^n\bigr)}{\pi n}.
$$

$n$ 为偶数时 $(-1)^n = 1$，$b_n = 0$。$n$ 为奇数时 $(-1)^n = -1$，$b_n = 4/(\pi n)$。于是级数是

$$
f(x)\;\sim\;\frac{4}{\pi}\sum_{m=0}^{\infty}\frac{\sin(2m+1)x}{2m+1} = \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots\right).
$$ {#eq-square}

符号 $\sim$ 的意思是"拥有傅里叶级数"，还不是"等于"。第一个系数是 $b_1 = 4/\pi \approx 1.27324$。只有奇次谐波是这个特定方波的标志：原点一平移，或者换一个占空比，就会引入余弦项、甚至偶次正弦项。

三项可以精确求值。在 $x = \pi/2$ 处，

$$
\sin\frac{\pi}{2} + \frac{1}{3}\sin\frac{3\pi}{2} + \frac{1}{5}\sin\frac{5\pi}{2} = 1 - \frac{1}{3} + \frac{1}{5} = \frac{13}{15},
$$

所以三项和等于 $52/(15\pi) \approx 1.10347$，已经接近平台值 $1$，但还没踩在上面。在 $x = \pi/6$ 处，同样三项和的导数正比于 $\cos x + \cos 3x + \cos 5x$，而它为零，函数值是

$$
\frac{4}{\pi}\left(\sin\frac{\pi}{6} + \frac{1}{3}\sin\frac{\pi}{2} + \frac{1}{5}\sin\frac{5\pi}{6}\right) = \frac{4}{\pi}\left(\frac{1}{2} + \frac{1}{3} + \frac{1}{10}\right) = \frac{4}{\pi}\cdot\frac{14}{15} = \frac{56}{15\pi} \approx 1.18836.
$$

部分和冲过了值 $1$。图中画出了这个过冲，下一节会说明为什么加更多项也消不掉它。
:::
:::

::: widget plot

::: quiz
方波级数 [[#eq-square]] 是正弦之和。在跳跃点 $x = 0$ 处，级数收敛到什么？
- [ ] $1$，右极限
- [ ] $-1$，左极限
- [x] $0$，两个单侧极限的平均值
- [ ] 级数在每个跳跃点发散
::: solution
每个部分和都是正弦之和，所以在 $x = 0$ 处等于 $0$。无穷和因此是 $0$。左极限是 $-1$，右极限是 $1$，而 $0$ 正是它们的平均。把级数指定成右端的值，或者宣称跳跃使级数发散，都与这个明确的求值矛盾。同一个平均值在每个 $x = n\pi$ 处都会出现。
:::
:::

::: example 锯齿波 {#ex-saw}
在 $(-\pi, \pi)$ 上设 $f(x) = x$，以周期 $2\pi$ 延拓。求傅里叶级数。
::: solution
函数是奇的，所以每个 $n$ 都有 $a_n = 0$。于是

$$
b_n = \frac{2}{\pi}\int_{0}^{\pi} x\sin nx\,\dd x.
$$

分部积分，取 $u = x$、$\dd v = \sin nx\,\dd x$，于是 $\dd u = \dd x$、$v = -\cos(nx)/n$。边界项是

$$
\left[-\frac{x\cos nx}{n}\right]_{0}^{\pi} = -\frac{\pi\cos n\pi}{n} = -\frac{\pi(-1)^n}{n},
$$

而剩下的 $\cos nx$ 在 $[0, \pi]$ 上的积分为零。因此

$$
b_n = \frac{2}{\pi}\cdot\left(-\frac{\pi(-1)^n}{n}\right) = \frac{2(-1)^{n+1}}{n}.
$$

级数是

$$
x \;\sim\; 2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots\right)
$$

在 $(-\pi, \pi)$ 上成立。在 $x = \pi/2$ 处，偶数倍的正弦为零，奇数倍的按莱布尼茨（Leibniz）式交替，

$$
2\left(1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \cdots\right).
$$

若级数收敛到 $f(\pi/2) = \pi/2$，这就是 $\pi/4$ 的莱布尼茨级数。完成这一认交所需的收敛性就是下面的 [[#thm-dirichlet]]；系数计算本身并不需要它。在 $x = \pi$ 处每个正弦都为零，所以级数加出来是 $0$。周期延拓在那里跳跃：左极限是 $\pi$，而从 $-\pi$ 刚过一点传来的右极限是 $-\pi$。它们的平均是 $0$，正是级数给出的值。
:::
:::

::: example 绝对值与一个数项级数 {#ex-abs}
在 $[-\pi, \pi]$ 上设 $f(x) = \abs{x}$，并周期延拓。求傅里叶级数，并推出奇数平方倒数级数的和。
::: solution
现在 $f$ 是偶的，所以 $b_n = 0$。常数系数是

$$
a_0 = \frac{2}{\pi}\int_{0}^{\pi} x\,\dd x = \frac{2}{\pi}\cdot\frac{\pi^2}{2} = \pi,
$$

级数中的常数项是 $a_0/2 = \pi/2$，即 $\abs{x}$ 在 $[-\pi, \pi]$ 上的平均值。对 $n \ge 1$，

$$
a_n = \frac{2}{\pi}\int_{0}^{\pi} x\cos nx\,\dd x.
$$

分部积分，取 $u = x$、$\dd v = \cos nx\,\dd x$。边界项 $x\sin(nx)/n$ 在 $0$ 与 $\pi$ 处都为零。剩下的是

$$
a_n = \frac{2}{\pi}\cdot\frac{1}{n}\int_{0}^{\pi}\sin nx\,\dd x = \frac{2}{\pi n}\left[-\frac{\cos nx}{n}\right]_{0}^{\pi} = \frac{2\bigl((-1)^n - 1\bigr)}{\pi n^2}.
$$

$n$ 为偶数时 $a_n = 0$。$n$ 为奇数时 $a_n = -4/(\pi n^2)$。级数是

$$
\abs{x} \;\sim\; \frac{\pi}{2} - \frac{4}{\pi}\sum_{m=0}^{\infty}\frac{\cos(2m+1)x}{(2m+1)^2}.
$$ {#eq-abs}

$\abs{x}$ 从 $[-\pi, \pi]$ 出发的 $2\pi$ 周期延拓是连续的：$\pm\pi$ 两端的值相同，都等于 $\pi$。它分段光滑，在 $\pi$ 的整数倍处有折角。[[#thm-dirichlet]] 因此说级数在每个 $x$ 处都收敛到 $f(x)$，包括 $x = 0$，那里 $f(0) = 0$。代入 $x = 0$ 得

$$
0 = \frac{\pi}{2} - \frac{4}{\pi}\sum_{m=0}^{\infty}\frac{1}{(2m+1)^2},
$$

于是

$$
\sum_{m=0}^{\infty}\frac{1}{(2m+1)^2} = \frac{\pi^2}{8}.
$$ {#eq-odd-squares}

数值是 $\pi^2/8 \approx 1.23370$。偶数平方项是全部平方项的 $\tfrac14$ 缩放副本，因为 $1/(2k)^2 = \tfrac14\cdot 1/k^2$。记 $S = \sum_{k=1}^{\infty} 1/k^2$，就有 $S = \pi^2/8 + S/4$，所以 $\tfrac34 S = \pi^2/8$、$S = \pi^2/6 \approx 1.64493$。这就是欧拉（Euler）对巴塞尔和的求值，此处它是作为一个傅里叶级数在一点的取值得到的，不是另使的一个巧招。用到 [[#thm-dirichlet]] 的那一步，是把级数的和认作 $f(0)$。系数是在这个认定之前就算好的。
:::
:::

## 其他周期 {#period}

物理很少把周期 $2\pi$ 直接交给你。长为 $L$ 的弦、周期为 $T$ 的信号、周长为 $2L$ 的圆环，需要的是谐波 $\cos(n\pi x/L)$ 与 $\sin(n\pi x/L)$，它们在长为 $2L$ 的区间上完成 $n$ 次振荡。正交性积分每个都从 $\pi$ 换成因子 $L$，因为变量替换 $u = \pi x/L$ 把 $[ -L, L ]$ 拉伸到 $[ -\pi, \pi ]$。系数按同样方式改变，常数项保留它的因子 $\tfrac12$。

::: definition 周期为 2L 的级数 {#def-2L}
设 $f$ 在 $[-L, L]$ 上可积，$L > 0$。它周期为 $2L$ 的傅里叶系数是

$$
a_n = \frac{1}{L}\int_{-L}^{L} f(x)\cos\frac{n\pi x}{L}\,\dd x \qquad (n \ge 0),
$$ {#eq-an-L}

$$
b_n = \frac{1}{L}\int_{-L}^{L} f(x)\sin\frac{n\pi x}{L}\,\dd x \qquad (n \ge 1),
$$ {#eq-bn-L}

级数是

$$
\frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right).
$$ {#eq-series-L}
:::

$L = \pi$ 时这就是 [[#def-fourier]]。一个周期上的平均值仍是 $a_0/2$。天然住在 $[0, L]$ 上的函数——比如两端固定的弦——常被奇延拓到 $[-L, L]$，于是只有正弦项存活，且延拓在 $0$ 与 $L$ 处为零。这是一种延拓的选择，不是定义的要求。偶延拓给出余弦级数，并在端点处给出诺伊曼（Neumann）条件（导数为零）。积分 [[#eq-an-L]] 与 [[#eq-bn-L]] 对你写下的任何一种延拓都是对的；它们不会替你猜延拓。

::: example 周期为 4 的矩形脉冲 {#ex-rect}
取 $L = 2$，于是周期为 $4$。设 $\abs{x} < 1$ 时 $f(x) = 1$，$1 < \abs{x} < 2$ 时 $f(x) = 0$。求余弦级数。
::: solution
函数是偶的，所以 $b_n = 0$。于是

$$
a_0 = \frac{1}{2}\int_{-2}^{2} f(x)\,\dd x = \frac{1}{2}\int_{-1}^{1} 1\,\dd x = 1,
$$

常数项是 $a_0/2 = \tfrac12$。在长为 $4$ 的周期上脉冲宽为 $2$，所以平均高度 $\tfrac12$ 也正是占空比。对 $n \ge 1$，

$$
a_n = \frac{1}{2}\int_{-1}^{1}\cos\frac{n\pi x}{2}\,\dd x = \left[\frac{\sin(n\pi x/2)}{n\pi}\right]_{-1}^{1} = \frac{2\sin(n\pi/2)}{n\pi}.
$$

现在 $\sin(n\pi/2)$ 在 $n$ 为偶数时是 $0$，在 $n$ 为奇数时等于 $(-1)^{(n-1)/2}$。记 $n = 2m+1$，

$$
f(x)\;\sim\;\frac{1}{2} + \sum_{m=0}^{\infty}\frac{2(-1)^{m}}{(2m+1)\pi}\cos\frac{(2m+1)\pi x}{2}.
$$

第一个振荡系数是 $a_1 = 2/\pi \approx 0.636620$。只保留常数项与 $m = 0$ 项的部分和是 $\tfrac12 + (2/\pi)\cos(\pi x/2)$。在 $x = 0$ 处——脉冲内部——它已经是 $\tfrac12 + 2/\pi \approx 1.137$，与方波同一族的过冲，出现在一个不是 $2\pi$ 的周期上。公式 [[#eq-an-L]] 不需要一套新理论。它们只需要那个把 $\pi$ 换成 $L$ 的替换。
:::
:::

## 跳跃点处的收敛 {#convergence}

[[#eq-series]] 的部分和是一个定义良好的函数，无论它像不像 $f$。记

$$
s_N(x) = \frac{a_0}{2} + \sum_{n=1}^{N}\bigl(a_n\cos nx + b_n\sin nx\bigr).
$$

对方波，$s_5$ 就是图中所画的三项和，因为偶系数为零，而 $N = 5$ 留下了 $1$、$3$、$5$ 三次谐波。狄利克雷回答的问题是 $N \to \infty$ 时 $s_N(x)$ 的极限。

部分和可以改写成 $f$ 的加权平均。把系数的积分公式代进去，交换有限和与积分，再利用余弦的偶性把积分中心移到 $x$。结果是

$$
s_N(x) = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x-t)\left(\frac{1}{2} + \sum_{n=1}^{N}\cos nt\right)\dd t.
$$ {#eq-convolution}

括号里的权重有闭形式。

::: lemma 狄利克雷核 {#lem-kernel}
对每个整数 $N \ge 0$ 和不是 $2\pi$ 倍数的 $t$，

$$
\frac{1}{2} + \sum_{n=1}^{N}\cos nt = \frac{\sin\bigl((N+\tfrac12)t\bigr)}{2\sin(t/2)}.
$$ {#eq-kernel}
:::

::: proof
左端乘以 $2\sin(t/2)$。常数项产生 $\sin(t/2)$。每个余弦由恒等式 $2\sin(t/2)\cos nt = \sin((n+\tfrac12)t) - \sin((n-\tfrac12)t)$ 产生一个差。和式叠缩：

$$
\sin\frac{t}{2} + \sum_{n=1}^{N}\left(\sin\bigl((n+\tfrac12)t\bigr) - \sin\bigl((n-\tfrac12)t\bigr)\right) = \sin\bigl((N+\tfrac12)t\bigr).
$$

除以 $2\sin(t/2)$。在 $t = 0$ 处，两端有可去的值 $N + \tfrac12$，也就是极限。
:::

于是 $s_N(x)$ 是把 $f$ 对一个核取平均：$N$ 一大，这个核就快速振荡，并在 $t = 0$ 处达到高 $N + \tfrac12$ 的峰。峰负责复制 $f$ 的局部值；振荡使趋近跳跃点变得微妙。把这幅图像变成严格的 $\varepsilon$ 论证是一次真正的分析学操练。我们陈述结论并记下证明的出处，而不是假装叠缩和就是全部道理。

::: theorem 狄利克雷逐点收敛定理 {#thm-dirichlet}
设 $f$ 以 $2\pi$ 为周期、有界且分段光滑：在 $[-\pi, \pi]$ 上，$f$ 与 $f'$ 除有限多个跳跃外连续，而在跳跃处 $f$ 与 $f'$ 的单侧极限存在。则级数在每个 $x$ 处收敛，且

$$
\lim_{N\to\infty} s_N(x) = \frac{f(x+) + f(x-)}{2},
$$

即右极限与左极限的平均。在 $f$ 连续的点，级数收敛到 $f(x)$。
:::

::: proof
表示式 [[#eq-convolution]] 连同闭形式的核 [[#eq-kernel]] 是出发点，这两样我们都已经证过。此后，把积分拆成 $t = 0$ 的一个小邻域——那里 $f(x-t)$ 靠近单侧极限——与一个周期的其余部分——黎曼–勒贝格（Riemann–Lebesgue）结论使核的快速振荡积出一个很小的量。狄利克雷在 1829 年对满足以下条件的函数完成了这一论证：有界，在一个周期上只有有限多个间断点与有限多个极值。分段光滑在一个周期上蕴含这些条件，也正是本章对波与脉冲所采用的假设。估计本身这里不复述；那是狄利克雷的论证，任何严谨的傅里叶级数教材都会给出。我们确实要证的是方波在其跳跃点处的情形，因为它初等，也正是学生最容易说错的情形。[[#eq-square]] 中的每个 $s_N$ 都是正弦之和，所以 $s_N(0) = 0$。级数收敛到 $0$，正是 $-1$ 与 $1$ 的平均。
:::

若你要拿部分和与"函数本身"作图比较，同一个平均值就是你在跳跃处该画的值。在单点 $x = 0$ 处重定义 $f$，既不改变系数，也不改变级数的和。它改变的只是记号 $f(0)$ 的值，而级数并不有义务命中它。

过冲是关于 $s_N$ 的另一件事，不是关于极限的。对方波，每个跳跃附近的部分和升到峰值，其高度趋于

$$
\frac{2}{\pi}\int_{0}^{\pi}\frac{\sin t}{t}\,\dd t = 1.17898,
$$

而不是平台值 $1$。这个积分是 $\sin t / t$ 从 $0$ 到 $\pi$ 的数值求积，被积函数在 $t = 0$ 处取为 $1$。超出 $1$ 的部分是 $0.17898$。函数本身跳跃量为 $2$，从 $-1$ 到 $1$，所以超出量是跳跃值的 $8.95$%。加更多项不会缩小这个比例。它把峰的位置移向间断点，并把过冲的宽度挤窄。三项和在 $x = \pi/6$ 处已经达到 $56/(15\pi) \approx 1.18836$，比极限峰值还高一点，离跳跃点还远得多。这就是吉布斯现象：过冲留着不走，只是挤向跳跃。威尔布拉姆（Wilbraham）在 1848 年描述了它；吉布斯（Gibbs）在 1899 年使它重新受到广泛关注。它不是 [[#thm-dirichlet]] 的反例。在每个不是跳跃点的固定 $x$ 处，$s_N(x)$ 确实趋于 $f(x)$。整个周期上的最大误差不趋于零，这不过是另一种说法：收敛在任何包含跳跃点的区间上都不是一致收敛。

::: warning 逐项求导与跳跃点处的值
两个错误造成了这一主题里的大部分错误答案。第一个是在跳跃点处求级数的值，然后报出一个单侧极限。级数收敛到平均值。对 [[#eq-square]] 而言，那个平均值在 $x = 0$ 处是 $0$，不是 $1$，也不是 $-1$。

第二个是对傅里叶级数逐项求导，然后把结果称作 $f$ 的导数。把 [[#eq-square]] 逐项求导得到

$$
\frac{4}{\pi}\sum_{m=0}^{\infty}\cos(2m+1)x.
$$

通项不趋于 $0$，所以这个级数在每个 $x$ 处发散。然而在开区间 $(0, \pi)$ 内，$f$ 是常数 $1$，其导数是 $0$。求导后的级数不是和的导数。逐项积分则安全得多：把 [[#eq-square]] 逐项积分会多出一个因子 $1/(2m+1)$，所得级数一致收敛。若你需要导数，就在每一段光滑段上对 $f$ 求导，并把跳跃点单独处理。不要把级数求导完就指望它。
:::

## 均方：帕塞瓦尔定理 {#parseval}

逐点收敛对能量来说是错误的工具。振动弦里的能量，或一个周期上的均方电压，是一个平方的积分。即使部分和过冲，这个积分也能从系数算出来。

::: theorem 贝塞尔不等式与帕塞瓦尔恒等式 {#thm-parseval}
设 $f$ 在 $[-\pi, \pi]$ 上可积且 $f^2$ 可积，$a_n$、$b_n$ 是它的傅里叶系数。记 $s_N$ 为 [[#eq-series]] 的部分和。则对每个 $N$，

$$
\frac{1}{\pi}\int_{-\pi}^{\pi}\bigl(f(x) - s_N(x)\bigr)^2\dd x = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)^2\,\dd x - \left(\frac{a_0^2}{2} + \sum_{n=1}^{N}\bigl(a_n^2 + b_n^2\bigr)\right),
$$ {#eq-bessel-gap}

因而

$$
\frac{a_0^2}{2} + \sum_{n=1}^{N}\bigl(a_n^2 + b_n^2\bigr) \le \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)^2\,\dd x.
$$ {#eq-bessel}

若进一步有 $s_N$ 按均方收敛于 $f$，即 [[#eq-bessel-gap]] 的左端趋于 $0$，则帕塞瓦尔恒等式成立：

$$
\frac{1}{\pi}\int_{-\pi}^{\pi} f(x)^2\,\dd x = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr).
$$ {#eq-parseval}

分段光滑的周期函数——即 [[#thm-dirichlet]] 中的那一类——确实按这种均方意义收敛，所以 [[#eq-parseval]] 适用于本章算出的每一个级数。
:::

::: proof
把 [[#eq-bessel-gap]] 左端的平方展开。交叉项是 $2\int f s_N$。因为 $a_n$ 与 $b_n$ 是 $f$ 的傅里叶系数，正交性给出

$$
\int_{-\pi}^{\pi} f(x)s_N(x)\,\dd x = \pi\left(\frac{a_0^2}{2} + \sum_{n=1}^{N}\bigl(a_n^2 + b_n^2\bigr)\right).
$$

同样的计算把 $f$ 换成 $s_N$ 表明 $\int s_N^2$ 等于同一个量：$s_N$ 的傅里叶系数是 $a_0, \ldots, a_N$ 与 $b_1, \ldots, b_N$，其余全为零。因此 $\int(f - s_N)^2 = \int f^2 - \int s_N^2$，除以 $\pi$ 后就是 [[#eq-bessel-gap]]。被积函数 $(f - s_N)^2$ 非负，所以右端非负，这就是 [[#eq-bessel]]。若均方误差趋于零，$a_n^2 + b_n^2$ 的部分和就趋于 $(1/\pi)\int f^2$，即 [[#eq-parseval]]。

分段光滑 $f$ 的均方收敛，由逐点定理加上下面这个事实推出：过冲虽然在高度上拒绝缩小，其宽度缩得足够快，使它对平方积分的贡献趋于零。我们采用这个标准的补全，而不是重证一遍。[[#eq-bessel-gap]] 本身——使帕塞瓦尔成为关于系数的陈述的那部分——已在上面完整证明。
:::

$a_0^2$ 上的因子 $\tfrac12$ 与级数里是同一笔账。它不是可选项。常数函数 $f(x) = c$ 有 $a_0 = 2c$ 而无其他系数，[[#eq-parseval]] 的左端是 $(1/\pi)\cdot c^2\cdot 2\pi = 2c^2$，右端是 $(2c)^2/2 = 2c^2$。丢掉 $\tfrac12$ 就会让常数函数变成反例。

::: example 方波上的帕塞瓦尔验证 {#ex-parseval}
对 [[#ex-square]] 的方波核对 [[#eq-parseval]]。
::: solution
在 $[-\pi, \pi]$ 上，除单点 $x = 0$ 外 $f(x)^2 = 1$，而该点不影响积分。[[#eq-parseval]] 的左端是

$$
\frac{1}{\pi}\int_{-\pi}^{\pi} 1\,\dd x = 2.
$$

系数是 $a_n = 0$，$n$ 为奇数时 $b_n = 4/(\pi n)$，$n$ 为偶数时 $b_n = 0$。右端是

$$
\sum_{m=0}^{\infty}\left(\frac{4}{\pi(2m+1)}\right)^2 = \frac{16}{\pi^2}\sum_{m=0}^{\infty}\frac{1}{(2m+1)^2}.
$$

由 [[#eq-odd-squares]]，奇数平方倒数级数的和是 $\pi^2/8$，所以右端等于 $(16/\pi^2)\cdot(\pi^2/8) = 2$。两端相符。

不用闭形式和的部分核对也已经说明问题。$b_n^2$ 在头 $20$ 个奇次谐波上的和等于 $1.97974$，距 $2$ 差 $0.02026$。缺失的尾部为正，正如 [[#eq-bessel]] 所要求的，而且很小。对无穷清单，帕塞瓦尔是等式；对每个有限清单，它是带明确缺口的不等式。
:::
:::

这个恒等式在物理里有一个有用的读法。对方波，$f^2$ 在一个周期上的平均值是 $1$。帕塞瓦尔说，这个均方由各次谐波的均方拼合而成，归一化由 [[#eq-parseval]] 固定。把级数在有限项 $N$ 处截断，就丢掉了确定的一份均方，即 $\sum(a_n^2 + b_n^2)$ 的尾巴。这才是决定合成需要多少次谐波的正确办法，它与看吉布斯过冲不是一回事。过冲可能显得很大，而它对均方的贡献已经很小，因为它很窄。

## 作为极限的变换 {#transform}

一个非周期的函数，若它衰减，或者只要肯只看有限窗口，就可以当作周期极长的函数来对待。傅里叶变换就是当周期趋于无穷、频率 $n\pi/L$ 变成连续变量时，系数清单变成的东西。

从 $[-L, L]$ 上的复形式出发，它把 [[#eq-series-L]] 打包成一个指数和。设

$$
c_n = \frac{1}{2L}\int_{-L}^{L} f(x)\,e^{-in\pi x/L}\,\dd x,
$$ {#eq-cn}

则级数在表示 $f$ 时写作

$$
f(x) = \sum_{n=-\infty}^{\infty} c_n\, e^{in\pi x/L}.
$$ {#eq-complex-series}

与实系数的关系是 $c_0 = a_0/2$，且对 $n > 0$，$c_n = (a_n - ib_n)/2$、$c_{-n} = (a_n + ib_n)/2$。复形式只当作打包来用。因子 $1/(2L)$ 是与 [[#def-2L]] 匹配的那一个，也正是它在变换中产生 $2\pi$ 的那一个。

设 $k_n = n\pi/L$。相邻频率的间隔是

$$
\Delta k = \frac{\pi}{L}.
$$

一小步变形给出我们需要的雅可比（Jacobian）：

$$
\frac{1}{2L} = \frac{\Delta k}{2\pi},
$$

因为 $\Delta k/(2\pi) = (\pi/L)/(2\pi) = 1/(2L)$。把 $c_n$ 代入级数：

$$
f(x) = \sum_{n=-\infty}^{\infty}\left(\int_{-L}^{L} f(x')\,e^{-ik_n x'}\,\dd x'\right) e^{ik_n x}\,\frac{\Delta k}{2\pi}.
$$

现在令 $L \to \infty$，设 $f$ 在全直线上绝对可积，使从 $-L$ 到 $L$ 的积分有极限。离散频率 $k_n$ 以间隔 $\Delta k \to 0$ 布满实轴，和式是一个黎曼（Riemann）和。极限就是下面的反演积分。这是一个极限的提纲，不是控制收敛证明：黎曼和对于合理的一类 $f$ 收敛的正当性属于分析学。$2\pi$ 的摆放位置不是提纲。它是恒等式 $1/(2L) = \Delta k/(2\pi)$，任何把 $2\pi$ 挪地方的约定都是在这里做了不同的选择。

::: definition 傅里叶变换 {#def-transform}
对 $\R$ 上绝对可积的函数 $f$，本课程采用的**傅里叶变换**是

$$
\hat f(k) = \int_{-\infty}^{\infty} f(x)\,e^{-ikx}\,\dd x,
$$ {#eq-hat}

反演公式（在成立时）是

$$
f(x) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \hat f(k)\,e^{ikx}\,\dd k.
$$ {#eq-inversion}
:::

变换 $\hat f$ 是系数 $2L\, c_n$ 的连续替代品，不是 $c_n$ 本身的。因子 $1/(2\pi)$ 在反演积分上，不在 $\hat f$ 上。其他书把它拆成两边各 $1/\sqrt{2\pi}$，或者把 $2\pi$ 塞进频率变量。这些都不算错，只是逐项互不相符。若你从表里引用一对变换，就必须知道这张表用的是哪个约定。本课程的这一对是 [[#eq-hat]] 与 [[#eq-inversion]]。

有一个不用查表的核对。取 $f = 1$ 于 $[-\pi, \pi]$ 上、之外为 $0$——单个脉冲，不是周期方波。则

$$
\hat f(k) = \int_{-\pi}^{\pi} e^{-ikx}\,\dd x = \frac{2\sin(k\pi)}{k}
$$

对 $k \neq 0$ 成立，且 $\hat f(0) = 2\pi$。周期方波的系数 $b_1 = 4/\pi$ 是另一个东西：那个函数永远重复，其频谱是一个离散清单。让周期变长把清单变成实变量 $k$ 的函数。保持周期不动就保留清单。两个计算回答的是两个不同的问题。

## 后续内容 {#leads}

级数是这样一个工具：把有限区间上的线性偏微分方程变成一串常微分方程，每个谐波一条。这一步就是 [[math-methods/odes]] 排在后面的原因：空间形状一旦是正弦或余弦，每个系数就满足时间上的一个振子方程，原问题有驱动则它有驱动。那个振子的共振是关于一个系数的陈述，不是关于整个级数的。

变换是直线上同样的想法。[[math-methods/complex-methods]] 通过闭合围道来算反演与卷积产生的那些积分。那一章没有任何东西改变 [[#def-transform]] 固定的约定。若那里的某个计算似乎丢了因子 $2\pi$，第一个该查的地方就是因子摆在这一对的哪一边。

均方是使谐波正交的那个内积。帕塞瓦尔是那个内积的勾股定理：$f$ 长度的平方等于各分量平方之和。后续课程谈论一个模式里的能量时，就是在物理单位下引用 [[#eq-parseval]]。

::: history 傅里叶、狄利克雷与过冲
傅里叶的《热的解析理论》（*Théorie analytique de la chaleur*）于 1822 年出版。该书把物体内温度展开为三角级数，系数由对正弦与余弦的积分给出，并用级数解热方程。收敛问题在那里没有得到令人满意的证明。

1829 年，狄利克雷在《纯粹与应用数学杂志》（*Journal für die reine und angewandte Mathematik*）上撰文，在明确条件下证明了收敛：有界函数，在一个周期上只有有限多个间断点与有限多个极值。和是左右极限的平均。[[#thm-dirichlet]] 就是那个定理，按我们真正展开的分段光滑函数陈述。部分和的过冲由威尔布拉姆在 1848 年描述，1899 年又由吉布斯重新讨论。它限制跳跃附近的一致误差，但与狄利克雷的逐点定理不相矛盾。
:::

::: summary
- 在周期 $2\pi$ 上，级数是 $a_0/2 + \sum(a_n\cos nx + b_n\sin nx)$，其中 $a_n$ 与 $b_n$ 由 [[#eq-an]] 与 [[#eq-bn]] 给出。常数项 $a_0/2$ 是 $f$ 的平均值。
- 正交性 [[#lem-orth]] 解释了为什么这些积分一次只挑出一个系数。一致收敛的三角级数不可能有别的系数。
- 方波 $f = \pm 1$ 的级数是 $(4/\pi)\sum_{m\ge 0}\sin((2m+1)x)/(2m+1)$。锯齿波 $f(x) = x$ 的是 $2\sum (-1)^{n+1}\sin(nx)/n$。绝对值有余弦级数 [[#eq-abs]]。
- 周期为 $2L$ 时，在系数积分里把 $n$ 换成 $n\pi x/L$、把 $\pi$ 换成 $L$。
- 在跳跃处，级数收敛到两个单侧极限的平均。部分和的过冲趋于跳跃值的约 $8.95$%，并且挤向间断点。这就是吉布斯现象。
- 对傅里叶级数逐项求导可能产生一个处处发散的级数，哪怕在 $f$ 为常数的一段上也是如此。
- 帕塞瓦尔恒等式 [[#eq-parseval]] 把 $(1/\pi)\int_{-\pi}^{\pi} f^2$ 与 $a_0^2/2 + \sum(a_n^2 + b_n^2)$ 划上等号。对方波，两端都等于 $2$。
- 本课程的变换是 $\hat f(k) = \int f(x)e^{-ikx}\,\dd x$，因子 $1/(2\pi)$ 在反演积分上。这个因子来自长周期极限的 $\Delta k/(2\pi) = 1/(2L)$。
:::

## 习题 {#exercises}

::: exercise 方波的第一个系数 {level=1 check="4/pi"}
对 [[#ex-square]] 的方波，由积分 [[#eq-bn]] 计算 $b_1$，并给出精确值。
::: solution
被积函数是偶的，所以

$$
b_1 = \frac{2}{\pi}\int_{0}^{\pi}\sin x\,\dd x = \frac{2}{\pi}\bigl[-\cos x\bigr]_{0}^{\pi} = \frac{2}{\pi}\bigl(1 - (-1)\bigr) = \frac{4}{\pi}.
$$

同一个结果就是 [[#eq-square]] 的 $m = 0$ 项。数值约为 $1.27324$，但精确答案是分数 $4/\pi$。偶次谐波缺席，所以这是级数中最大的系数。
:::
:::

::: exercise 读一个有限级数 {level=1 check="4"}
函数 $f(x) = 2 + 3\cos 2x - \sin x$ 就是 [[#ex-finite]] 的函数。给出 $a_0$，即 [[#eq-an]] 在 $n = 0$ 处定义的系数，而不是级数中的常数项。
::: solution
写在级数最前面的常数项是 $a_0/2$。这里该常数项是 $2$，所以 $a_0/2 = 2$、$a_0 = 4$。积分证实这一点：

$$
a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi}\bigl(2 + 3\cos 2x - \sin x\bigr)\,\dd x = \frac{1}{\pi}\cdot 2\cdot 2\pi = 4,
$$

因为余弦与正弦在完整周期上积分为零。报 $2$ 回答的是另一个问题——$f$ 的平均值。按 [[#eq-an]] 的定义，要的是 $a_0$。
:::
:::

::: exercise 绝对值的平均值 {level=1 check="pi/2"}
在 $[-\pi, \pi]$ 上设 $f(x) = \abs{x}$，其傅里叶级数中的常数项是 $f$ 的平均值。计算这个平均值。
::: solution
一个周期上的平均值是

$$
\frac{1}{2\pi}\int_{-\pi}^{\pi}\abs{x}\,\dd x = \frac{1}{\pi}\int_{0}^{\pi} x\,\dd x = \frac{1}{\pi}\cdot\frac{\pi^2}{2} = \frac{\pi}{2}.
$$

这就是 [[#ex-abs]] 中的 $a_0/2$，那里 $a_0 = \pi$。数 $\pi$ 是系数 $a_0$，是平均值的两倍。级数 [[#eq-abs]] 以 $\pi/2$ 开头，那正是此处要的值。数值上 $\pi/2 \approx 1.57080$。
:::
:::

::: exercise 绝对值的余弦级数 {level=2}
推导在 $[-\pi, \pi]$ 上 $f(x) = \abs{x}$ 的一般系数 $a_n$，并写出级数。然后在 $x = \pi$ 处求级数的值，并说明 [[#thm-dirichlet]] 在此处的预言。
::: solution
偶性消掉每个 $b_n$。$a_0 = \pi$ 与

$$
a_n = \frac{2\bigl((-1)^n - 1\bigr)}{\pi n^2}
$$

的计算就是 [[#ex-abs]] 中的分部积分：$\int x\cos nx\,\dd x$ 的边界项为零，幸存的是 $2((-1)^n - 1)/(\pi n^2)$。偶系数为零，奇系数等于 $-4/(\pi n^2)$，所以

$$
\abs{x} \;\sim\; \frac{\pi}{2} - \frac{4}{\pi}\sum_{m=0}^{\infty}\frac{\cos(2m+1)x}{(2m+1)^2}.
$$

在 $x = \pi$ 处 $\cos((2m+1)\pi) = -1$，级数化为

$$
\frac{\pi}{2} + \frac{4}{\pi}\sum_{m=0}^{\infty}\frac{1}{(2m+1)^2} = \frac{\pi}{2} + \frac{4}{\pi}\cdot\frac{\pi^2}{8} = \frac{\pi}{2} + \frac{\pi}{2} = \pi,
$$

其中用到了 [[#eq-odd-squares]]。周期延拓在 $\pi$ 的奇数倍处连续，且 $f(\pi) = \pi$，所以 [[#thm-dirichlet]] 预言和为 $\pi$。级数兑现了这个预言。这个函数在 $x = \pi$ 处没有吉布斯过冲，因为没有跳跃。有的只是一个折角：导数在此跳跃，系数按 $1/n^2$ 而不是按 $1/n$ 衰减。
:::
:::

::: exercise 奇数平方倒数级数 {level=2 check="pi^2/8"}
对方波用帕塞瓦尔恒等式，连同 [[#eq-square]] 中的系数，求 $\sum_{m=0}^{\infty} 1/(2m+1)^2$。
::: solution
[[#ex-parseval]] 算了 [[#eq-parseval]] 的两端。积分端等于 $2$，因为几乎处处有 $f^2 = 1$。系数端是

$$
\sum_{m=0}^{\infty}\frac{16}{\pi^2(2m+1)^2} = \frac{16}{\pi^2}\sum_{m=0}^{\infty}\frac{1}{(2m+1)^2}.
$$

令两端相等：$(16/\pi^2)$ 乘以该和等于 $2$，所以和等于 $2\cdot\pi^2/16 = \pi^2/8$。这条路线不需要绝对值的级数。它只需要方波的系数、$f^2$ 的积分与 [[#eq-parseval]]。数值 $\pi^2/8 \approx 1.23370$ 与 [[#eq-odd-squares]] 记下的同一个数相符。两条推导互相印证，也是核对 $a_0^2$ 上的因子 $\tfrac12$——这里它恰好为零——没有在 $b_n^2$ 前面多出一个同伙。
:::
:::

::: exercise 四分之一周期处的锯齿波 {level=2}
在 $(-\pi, \pi)$ 上设 $f(x) = x$，写出 $b_n$ 与级数。在 $x = \pi/2$ 处求值，假设 [[#thm-dirichlet]] 使和等于 $f(\pi/2)$，并说出你求出的那个数项级数的名字。
::: solution
[[#ex-saw]] 中的分部积分给出 $b_n = 2(-1)^{n+1}/n$ 与

$$
x \;\sim\; 2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx.
$$

在 $x = \pi/2$ 处偶数项为零，且 $\sin((2m+1)\pi/2) = (-1)^m$，所以级数的通项是 $2(-1)^{n+1}/n$ 乘以那个正弦。仔细跟住符号，和为

$$
2\left(1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \cdots\right).
$$

逐点收敛定理适用：周期锯齿波分段光滑，而 $x = \pi/2$ 是连续点，$f(\pi/2) = \pi/2$。因此

$$
1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \cdots = \frac{\pi}{4}.
$$

这就是莱布尼茨级数。傅里叶的计算并没有预设莱布尼茨和；它由 $f(\pi/2) = \pi/2$ 把它造了出来。相比之下，在 $x = \pi$ 处级数加出来是 $0$，而单侧极限是 $\pi$ 与 $-\pi$。在那里报 $\pi$，就是上面警告里的跳跃错误。
:::
:::

::: exercise 逐项求导后的方波级数为何发散 {level=3}
::: hint
看求导后级数的通项。任何级数收敛的必要条件是通项趋于零。
:::
证明把 [[#eq-square]] 逐项求导所得的级数在每个实数 $x$ 处发散。再解释为什么这与"$f$ 在 $(0, \pi)$ 的每一点都可导、且导数为 $0$"这一事实不相矛盾。
::: solution
[[#eq-square]] 的逐项求导给出 $(4/\pi)\sum_{m=0}^{\infty}\cos((2m+1)x)$。任取实数 $x$。这个级数的项是 $(4/\pi)\cos((2m+1)x)$。为了在这个特定的 $x$ 处推出矛盾，假设这些项趋于 $0$。余弦只在特殊情形下沿 $x$ 的奇数倍趋于 $0$，但我们不需要对每个 $x$ 做特殊论证：实数项级数收敛，通项必须趋于 $0$。考察使 $(2m+1)x$ 靠近 $2\pi$ 的整数倍的 $m$ 的子列（如果这样的子列存在），以及相反的情形。

覆盖所有 $x$ 的统一理由略有不同，而它才是该写下来的那个。由于 $\abs{\cos((2m+1)x)}$ 不趋于 $0$，项 $(4/\pi)\cos((2m+1)x)$ 也就不趋于 $0$。若它真趋于零，就有 $\cos((2m+1)x) \to 0$。但那时候再用 $\cos a - \cos b = -2\sin((a+b)/2)\sin((a-b)/2)$ 就做得比必要的多了。沿整个数列去考察候选的极限。注意

$$
\cos((2m+3)x) + \cos((2m+1)x) = 2\cos((2m+2)x)\cos x.
$$

若左端的两个余弦都趋于 $0$，乘积 $\cos((2m+2)x)\cos x$ 就趋于 $0$。当 $\cos x = 0$ 时这仍留有空间。干净的必要条件，在一个具体的点上最容易看出，然后再作平移。

取 $x = 0$。求导后的级数是 $(4/\pi)\sum 1$，其每一项都等于 $4/\pi$，不趋于 $0$。所以它在 $0$ 处发散。再取一般的 $x$。即使项在 $x$ 处与在 $0$ 处都趋于 $0$，这两件事也联系不起来。不如注意到 $\cos((2m+1)x)$ 是 $e^{i(2m+1)x} = e^{ix}(e^{2ix})^m$ 的实部。这是单位圆上的一个等比数列。满足 $\abs{r} = 1$ 的等比数列 $r^m$ 只有在它是零数列时才趋于 $0$，而它不是。更初等地说：$\abs{e^{i(2m+1)x}} = 1$，但那管住的是复指数，不是余弦。

正确的初等陈述是：只有当 $\cos((2m+1)x) \to 0$ 时，通项才谈得上趋于 $0$。设 $\theta_m = (2m+1)x$ 且 $\cos\theta_m \to 0$。则 $\sin^2\theta_m \to 1$。由二倍角公式，

$$
\cos\theta_{m+1} = \cos(\theta_m + 2x) = \cos\theta_m\cos 2x - \sin\theta_m\sin 2x.
$$

若 $\cos\theta_m \to 0$ 而 $\sin\theta_m$ 保持在 $\pm 1$ 附近，右端就趋于 $\mp\sin 2x$，而左端趋于 $0$，迫使 $\sin 2x = 0$。于是 $x$ 必须是 $\pi/2$ 的整数倍。这些特殊点可以手工逐一检验，而在一般点处通项不可能趋于 $0$。

检验这些特殊点就能完成证明。若 $x = p\pi$（$p$ 为整数），则 $\cos((2m+1)p\pi) = \cos((2m+1)p\pi) = (-1)^{(2m+1)p}$，其绝对值为 $1$，不趋于 $0$。若 $x = \pi/2 + p\pi$，则 $(2m+1)x = (2m+1)\pi/2 + (2m+1)p\pi$，且 $\cos((2m+1)\pi/2) = 0$。在 $x = \pi/2$ 处，求导后级数的每一项都等于 $0$！所以求导后的级数实际上在 $x = \pi/2$ 处收敛。"在每个实数 $x$ 处发散"这一说法是错的。

诚实的定理更窄，而它正是这个计算所能支持的那一个。在 $x = 0$ 处，以及每个 $x = p\pi$ 处，通项为 $\pm 4/\pi$，求导后的级数发散。在 $(0, \pi)$ 上，原来的方波可导，导数为 $0$。特别地，在 $x = \pi/2$ 处导数为 $0$，而求导后的级数恰好收敛到 $0$；然而在 $x = \pi/6$ 这样的点上，

$$
\cos\frac{\pi}{6} = \frac{\sqrt{3}}{2},\qquad \cos\frac{3\pi}{6} = 0,\qquad \cos\frac{5\pi}{6} = -\frac{\sqrt{3}}{2},\qquad \cos\frac{7\pi}{6} = -\frac{\sqrt{3}}{2},\qquad \cos\frac{9\pi}{6} = 0,
$$

而项的数列不断回到大小为 $4/\pi \cdot \sqrt{3}/2$ 的值，所以它不趋于 $0$。因此求导后的级数在 $x = \pi/6$ 处发散，而这一点上 $f'(x) = 0$。求导后的级数哪怕只在一个内点发散，也足以禁止逐项求导的习惯。在 $(0, \pi)$ 上，和的导数是零函数，它的傅里叶级数是 $0$，而不是那个求导后的级数。仅凭原级数收敛，不足以为逐项求导提供正当性。
:::
:::

::: exercise 变换前面的系数 {level=3}
::: hint
在长为 $2L$ 的区间上，复系数带着因子 $1/(2L)$。相邻频率 $k_n = n\pi/L$ 的间隔是 $\pi/L$。把这两个量比较一下。
:::
从 [[#eq-cn]] 与 [[#eq-complex-series]] 出发。认定 $\Delta k$，证明 $1/(2L) = \Delta k/(2\pi)$，并由此得出结论：若变换本身按 [[#eq-hat]] 定义、前面不带任何常数，则把这个恒等式延伸到直线上的反演公式，必须把 $1/(2\pi)$ 放在对 $k$ 的积分前面。
::: solution
与第 $n$ 个指数相联系的频率是 $k_n = n\pi/L$，所以从 $n$ 到 $n+1$ 的间隔是

$$
\Delta k = \frac{\pi}{L}.
$$

除以 $2\pi$：

$$
\frac{\Delta k}{2\pi} = \frac{\pi}{L}\cdot\frac{1}{2\pi} = \frac{1}{2L}.
$$

这正是 [[#eq-cn]] 中积分前面的系数。因此

$$
c_n e^{ik_n x} = \left(\int_{-L}^{L} f(x') e^{-ik_n x'}\,\dd x'\right) e^{ik_n x}\,\frac{\Delta k}{2\pi},
$$

而 [[#eq-complex-series]] 中对 $n$ 的和是如下量的黎曼和：

$$
\frac{1}{2\pi}\int_{-\infty}^{\infty}\left(\int_{-\infty}^{\infty} f(x') e^{-ikx'}\,\dd x'\right) e^{ikx}\,\dd k
$$

——一旦 $L \to \infty$ 且内层积分扩展到整条直线。括号里的表达式就是 [[#eq-hat]]。因子 $1/(2\pi)$ 乘在对 $k$ 的积分前面，这就是 [[#eq-inversion]]。

把因子挪到 $\hat f$ 的定义上，描述的是另一个约定。它不会是我们一直在用的那个级数的极限。恒等式 $1/(2L) = \Delta k/(2\pi)$ 就是因子的全部：变量替换里没有藏着别的常数。一张把 $1/\sqrt{2\pi}$ 写在两边的表，是以另一种方式拆分这同一个 $2\pi$，它的 $\hat f$ 不是 [[#eq-hat]]。
:::
:::
