一个原子的直径约为 $10^{-10}\,\mathrm{m}$，而它几乎全部的质量都集中在一个小十万倍的区域里。这个区域就是原子核，由质子和中子组成：把它们束缚在一起的力，强到足以克服质子之间的静电排斥，程却又短到超出几飞米（femtometre）便无影无踪。本章要问三个具体的问题。原子核有多大，我们是怎么知道的？是什么能量把它束缚在一起，为什么几乎每一种核的每个核子的结合能都接近 $8\,\mathrm{MeV}$？为什么有些质子数与中子数——2、8、20、28、50、82 和 126——被大自然特别选中，异乎寻常地稳定？

答案来自两个看起来互不相容的模型。**液滴模型**（liquid-drop model）把核看作一滴不可压缩的带电流体，解释的是平滑的趋势：密度恒定、结合能正比于核子数、稳定核所在的谷。**壳层模型**（shell model）把每个核子看作在平均势中独立运动的粒子，像原子中的电子，解释的是例外：幻数、基态的自旋与宇称。两者都是对一个至今未能从第一性原理解出的多体问题的近似；实际工作的核物理学家会按问题的需要选用其中任何一个。

你需要 [[quantum-1/piecewise-potentials]] 的方势阱与 [[quantum-1/angular-momentum]] 的角动量代数、[[quantum-1/spin]] 的自旋，以及 [[relativity/velocity-energy]] 中能量、动量与质量的关系。这门学科的常用单位是飞米，$1\,\mathrm{fm} = 10^{-15}\,\mathrm{m}$，以及兆电子伏，$1\,\mathrm{MeV} = 1.602\times10^{-13}\,\mathrm{J}$。大部分算术靠两个组合完成：

$$
\hbar c = 197.327\,\mathrm{MeV\,fm}, \qquad \frac{e^2}{4\pi\varepsilon_0} = \alpha\hbar c = 1.43996\,\mathrm{MeV\,fm},
$$ {#eq-units}

其中精细结构常量 $\alpha = 1/137.036$。质量以 MeV$/c^2$ 或统一原子质量单位计，$1\,\mathrm{u} = 931.494\,\mathrm{MeV}/c^2$（CODATA 2022）。本章的原子质量取自 2020 年原子质量评估（Atomic Mass Evaluation，AME2020）。

## 组成与记号 {#notation}

原子核包含 $Z$ 个质子与 $N$ 个中子。质子与中子统称为**核子**（nucleon）。它们的静能为

$$
m_p c^2 = 938.272\,\mathrm{MeV}, \qquad m_n c^2 = 939.565\,\mathrm{MeV},
$$

于是中子比质子重 $1.293\,\mathrm{MeV}$，比电子的静能 $m_e c^2 = 0.511\,\mathrm{MeV}$ 的两倍还多。正是这一点小差别使自由中子能够衰变，这一事实在 [[particles/decay]] 中将会用到。两种核子的自旋都是 $\tfrac12$，因此都是费米子，服从泡利不相容原理。

::: definition 核素、同位素、同量异位素、同中子异位素 {#def-nuclide}
具有确定质子数 $Z$ 与中子数 $N$ 的一类原子核称为**核素**（nuclide）。它的**质量数**为 $A = Z + N$，记作 ${}^{A}_{Z}\mathrm{X}_N$，或简单地记作 ${}^{A}\mathrm{X}$，因为化学符号 $\mathrm{X}$ 已经定死了 $Z$。$Z$ 相同的核素互称**同位素**（isotope），$A$ 相同的互称**同量异位素**（isobar），$N$ 相同的互称**同中子异位素**（isotone）。
:::

于是 ${}^{12}\mathrm{C}$ 与 ${}^{14}\mathrm{C}$ 是碳的同位素，${}^{14}\mathrm{C}$ 与 ${}^{14}\mathrm{N}$ 是同量异位素，${}^{13}\mathrm{C}$ 与 ${}^{14}\mathrm{N}$ 是 $N = 7$ 的同中子异位素。稳定的核素有 250 个左右，此外还有 3,000 多个已被制造并测量过。把稳定的核素画在以 $N$ 为一轴、$Z$ 为另一轴的图上，它们构成一条窄带，即**稳定谷**（valley of stability）：轻核沿 $N = Z$ 起步，重核则向 $N > Z$ 一侧弯过去——${}^{208}\mathrm{Pb}$ 的 $Z = 82$、$N = 126$。解释这条弯折正是 [[#semf]] 的成功之处之一。

表中列出的是**原子**质量，即包含 $Z$ 个电子的中性原子的质量，因为质谱仪测得的正是它。我们将全程使用原子质量，让电子自行相消。电子自身的结合能量级为 $10\,\mathrm{eV}$ 到 $100\,\mathrm{keV}$，在 MeV 精度下可以忽略，我们略去不计。

::: remark 能量尺度
有三个数能让这门学科的量级保持正确。原子结合能的量级是 eV。核结合能的量级是每个核子几 MeV，大一百万倍——这就是核反应释放的能量约为化学反应一百万倍的原因。核子静能约为 $939\,\mathrm{MeV}$，所以一个核比它的各个组分分开时只轻了约 $1\%$。核物理是非相对论的——动能相比静能很小——但质量亏损（mass defect）大到足以轻易测出。
:::

## 核的大小 {#size}

卢瑟福 1911 年对 α 粒子在金上散射的分析表明，原子的正电荷集中在小于约 $10^{-14}\,\mathrm{m}$ 的区域内：直到当时所能测得的最大角度，散射都服从点电荷公式。这给出的是上限，不是大小。要测量大小，我们需要一种波长短于核、且只感受一种已知力的探针。电子是理想的选择：它们不感受强力，与核电荷的相互作用是纯粹的电磁作用，可以精确计算。

### 需要多大的能量

对高度相对论性的电子，$E \approx pc$，它的约化德布罗意波长为

$$
\bar{\lambda} = \frac{\hbar}{p} = \frac{\hbar c}{pc}.
$$

当 $pc = 200\,\mathrm{MeV}$ 时，$\bar{\lambda} = 197.327/200 = 0.987\,\mathrm{fm}$。因此，要分辨几飞米尺度上的结构，就需要几百 MeV 的电子能量。这正是决定性的实验必须等到 1950 年代的直线加速器才做得成的原因。

### 形状因子

当靶是点电荷时，相对论性电子弹性散射的截面是**莫特（Mott）截面** $(\dd\sigma/\dd\Omega)_\mathrm{Mott}$，即在卢瑟福公式上修正了电子的自旋与相对论性运动的结果。伸展的电荷分布在大角度上散射得更少，因为从分布的不同部分散射出的波相干相消。这一修正只是动量转移的一个函数。

::: definition 形状因子 {#def-form-factor}
设核的电荷密度为 $Ze\,\rho(\mathbf{r})$，归一化为 $\int \rho\,\dd^3 r = 1$。对动量转移为 $\hbar\mathbf{q} = \mathbf{p} - \mathbf{p}'$ 的弹性散射，归一化电荷分布的傅里叶变换称为**形状因子**（form factor），

$$
F(\mathbf{q}) = \int \rho(\mathbf{r})\, e^{i\mathbf{q}\cdot\mathbf{r}}\,\dd^3 r,
$$

而测得的截面为

$$
\frac{\dd\sigma}{\dd\Omega} = \left(\frac{\dd\sigma}{\dd\Omega}\right)_{\mathrm{Mott}} \lvert F(\mathbf{q})\rvert^2 .
$$ {#eq-ff}

动量为 $p$ 的电子（忽略反冲）被弹性散射到角度 $\theta$ 时，$q = 2p\sin(\theta/2)/\hbar$。
:::

关系式 [[#eq-ff]] 就是 [[quantum-2/scattering]] 中的一阶玻恩近似：对一组源散射的振幅等于各源振幅之和，每个源带上由其位置决定的相位 $e^{i\mathbf{q}\cdot\mathbf{r}}$。由此立刻看出两件事。$q = 0$ 时形状因子 $F = 1$，这正是归一化：长波长探针只看得见总电荷。而对球对称分布，$F$ 只依赖 $q = \lvert\mathbf{q}\rvert$。把角向积分做出来，

$$
F(q) = \int_0^\infty \rho(r)\,\frac{\sin qr}{qr}\,4\pi r^2\,\dd r .
$$ {#eq-ff-radial}

::: theorem 均匀球体的形状因子 {#thm-uniform-ff}
半径为 $R$ 的均匀电荷分布，$r < R$ 内 $\rho = 3/(4\pi R^3)$、球外为 $0$，其形状因子为

$$
F(q) = \frac{3\,(\sin qR - qR\cos qR)}{(qR)^3}.
$$ {#eq-ff-sphere}

它的第一个零点在 $qR = 4.4934$，即 $\tan x = x$ 的最小正根。对任何球对称分布，小 $q$ 时都有 $F(q) = 1 - \tfrac16 q^2 \langle r^2\rangle + O(q^4)$；对均匀球体，$\langle r^2\rangle = \tfrac35 R^2$。
:::

::: proof
把均匀密度代入 [[#eq-ff-radial]]：

$$
F(q) = \frac{3}{4\pi R^3}\cdot\frac{4\pi}{q}\int_0^R r\sin qr\,\dd r .
$$

分部积分：$\int_0^R r\sin qr\,\dd r = \bigl[-r\cos qr/q\bigr]_0^R + \int_0^R \cos qr\,\dd r/q = -R\cos qR/q + \sin qR/q^2$。于是

$$
F(q) = \frac{3}{R^3 q}\left(\frac{\sin qR}{q^2} - \frac{R\cos qR}{q}\right) = \frac{3(\sin qR - qR\cos qR)}{(qR)^3}.
$$

$q \neq 0$ 时它在 $\sin x = x\cos x$（$x = qR$）处为零，即 $\tan x = x$，其第一个正根为 $x = 4.4934$（数值求得）。小 $q$ 展开则在 [[#eq-ff-radial]] 中使用 $\sin(qr)/(qr) = 1 - \tfrac16 q^2 r^2 + O(q^4 r^4)$：

$$
F(q) = \int \rho\,\dd^3 r - \frac{q^2}{6}\int r^2 \rho\,\dd^3 r + \dots = 1 - \frac{q^2}{6}\langle r^2\rangle + \dots
$$

均匀球体的 $\langle r^2\rangle = \frac{3}{4\pi R^3}\int_0^R r^2\,4\pi r^2\,\dd r = \frac{3}{R^3}\cdot\frac{R^5}{5} = \frac35 R^2$。
:::

小 $q$ 的结果与模型无关。无论什么形状，$F$ 在小 $q^2$ 处的斜率都度量**均方根电荷半径**（root-mean-square charge radius）$r_\mathrm{rms} = \langle r^2\rangle^{1/2}$。更大的 $q$ 处的衍射极小则携带边缘形状的信息。

::: example 由衍射极小求半径 {#ex-diffraction}
能量 $400\,\mathrm{MeV}$ 的电子在 ${}^{40}\mathrm{Ca}$ 上弹性散射。设截面与莫特截面之比在 $\theta = 28.6^\circ$ 处出现第一个极小。把核当作均匀球，求它的半径以及 $R = R_0 A^{1/3}$ 中 $R_0$ 的值。
::: solution
电子静能可以忽略，所以 $pc = 400\,\mathrm{MeV}$，$p/\hbar = 400/197.327 = 2.027\,\mathrm{fm}^{-1}$。质量为 $37\,\mathrm{GeV}/c^2$ 的核反冲很小，于是

$$
q = \frac{2p}{\hbar}\sin\frac{\theta}{2} = 2(2.027)\sin 14.3^\circ = 4.054 \times 0.2470 = 1.001\,\mathrm{fm}^{-1}.
$$

[[#eq-ff-sphere]] 的第一个零点在 $qR = 4.4934$，所以

$$
R = \frac{4.4934}{1.001\,\mathrm{fm}^{-1}} = 4.49\,\mathrm{fm}.
$$

由 $A^{1/3} = 40^{1/3} = 3.420$，得 $R_0 = 4.49/3.420 = 1.31\,\mathrm{fm}$。${}^{40}\mathrm{Ca}$ 实测的均方根电荷半径为 $3.48\,\mathrm{fm}$，而 $\sqrt{5/3}\times 3.48 = 4.49\,\mathrm{fm}$，两者一致。这里 $R_0$ 比常为重核引用的 $1.2\,\mathrm{fm}$ 大，是因为轻核的表面相对太厚；对 ${}^{208}\mathrm{Pb}$ 用同样的做法得 $R_0 = 1.20\,\mathrm{fm}$。
:::
:::

### 实验的结论

1950 年代，斯坦福的罗伯特·霍夫施塔特（Robert Hofstadter）及其研究组测量了电子在许多核上的散射。它们的电荷分布用**费米**分布（又称 Woods–Saxon 分布）描述得很好

$$
\rho(r) = \frac{\rho_0}{1 + e^{(r - c)/a}},
$$ {#eq-fermi}

其中半密度半径 $c \approx 1.07 A^{1/3}\,\mathrm{fm}$、弥散度（diffuseness）$a \approx 0.54\,\mathrm{fm}$。密度从中心值的 $90\%$ 降到 $10\%$ 所跨的皮层厚度 $t = 4a\ln 3 \approx 2.4\,\mathrm{fm}$，对所有核都相同。除最轻的核外，中心密度 $\rho_0$ 对所有核也几乎相同。用等价尖锐球来表述，

$$
R = R_0 A^{1/3}, \qquad R_0 \approx 1.2\,\mathrm{fm}.
$$ {#eq-radius}

:::

规律 $R \propto A^{1/3}$ 说的是体积正比于核子数，因而密度恒定。核子像液体里的分子那样堆积，而不像原子里的电子——原子的尺寸几乎不随 $Z$ 变。取 $R_0 = 1.2\,\mathrm{fm}$，核子密度为

$$
n_0 = \frac{A}{\frac43\pi R_0^3 A} = \frac{3}{4\pi (1.2\,\mathrm{fm})^3} = 0.138\,\mathrm{fm}^{-3},
$$

而费米分布的平台接近 $0.16\,\mathrm{fm}^{-3}$。乘以核子质量得约 $2.3\times10^{17}\,\mathrm{kg/m^3}$，正是中子星的密度。密度恒定是**饱和性**（saturation）的第一个迹象：每个核子只与它的近邻相互作用，所以增加核子只是增加体积，而不是把原有的核子压紧。

其他探针的结论一致。μ 子（muon）原子中，μ 子的轨道比电子近 $207$ 倍，其能级因核的有限大小而移动。感受强力的 α 粒子与中子的散射测量的是核**物质**而非电荷的范围，给出的同型 $A^{1/3}$ 半径稍大一些。镜核（mirror nuclei）之间的库仑能差提供第三种估计，习题里会让你算出来。

::: warning 半径不是一个单一的数
"原子核的半径"在不同公式里含义不同。均方根半径 $r_\mathrm{rms}$、半密度半径 $c$ 与等价尖锐半径 $R = \sqrt{5/3}\,r_\mathrm{rms}$ 相差可达 $30\%$。使用 $R = R_0 A^{1/3}$ 时，要用与你的计算相配的那个 $R_0$：均匀带电球用约 $1.2\,\mathrm{fm}$，反应中两核开始接触的距离用约 $1.4\,\mathrm{fm}$。写明你用的是哪一个。
:::

## 结合能 {#binding}

一个核比把它拆开后各就各位的核子要轻。缺失的那部分质量乘以 $c^2$，正是把核拆开所需供给的能量。

::: definition 结合能 {#def-binding}
核素 ${}^{A}_{Z}\mathrm{X}_N$ 的**结合能**（binding energy）为

$$
B(Z, A) = \bigl[Z\, m({}^1\mathrm{H}) + N m_n - m({}^{A}\mathrm{X})\bigr]c^2 ,
$$ {#eq-binding}

其中 $m({}^{A}\mathrm{X})$ 与 $m({}^1\mathrm{H}) = 1.007825\,\mathrm{u}$ 是原子质量，$m_n = 1.008665\,\mathrm{u}$ 是中子质量。**每个核子的结合能**为 $B/A$。
:::

用氢原子质量而不是质子质量，可让 $Z$ 个电子自动相消：${}^{A}\mathrm{X}$ 原子含 $Z$ 个电子，$Z$ 个氢原子也含 $Z$ 个电子。**中子分离能** $S_n = B(Z, A) - B(Z, A-1)$ 与**质子分离能** $S_p = B(Z, A) - B(Z-1, A-1)$ 是移走最后一个中子或质子所需的能量，扮演的正是原子物理中电离能的角色。

::: example 氦-4 与铁-56 {#ex-binding}
用 $m({}^4\mathrm{He}) = 4.002603\,\mathrm{u}$ 与 $m({}^{56}\mathrm{Fe}) = 55.934936\,\mathrm{u}$，求各自的 $B$ 与 $B/A$。
::: solution
对 ${}^4\mathrm{He}$，$Z = N = 2$：

$$
\begin{aligned}
Z m({}^1\mathrm{H}) + N m_n &= 2(1.007825) + 2(1.008665) = 4.032980\,\mathrm{u}, \\
\Delta m &= 4.032980 - 4.002603 = 0.030377\,\mathrm{u}, \\
B &= 0.030377 \times 931.494\,\mathrm{MeV} = 28.30\,\mathrm{MeV}.
\end{aligned}
$$

于是 $B/A = 7.07\,\mathrm{MeV}$。对 ${}^{56}\mathrm{Fe}$，$Z = 26$、$N = 30$：

$$
\begin{aligned}
26(1.007825) + 30(1.008665) &= 26.203451 + 30.259947 = 56.463398\,\mathrm{u}, \\
\Delta m &= 56.463398 - 55.934936 = 0.528462\,\mathrm{u}, \\
B &= 0.528462 \times 931.494 = 492.3\,\mathrm{MeV},
\end{aligned}
$$

于是 $B/A = 8.79\,\mathrm{MeV}$。铁的质量亏损几乎达到其质量的 $1\%$。注意质量需要多少位数字：结合能是两个大数之差的小头，这就是核质量必须测到优于 $10^8$ 分之一的精度的原因。
:::
:::

把稳定核素的 $B/A$ 对 $A$ 作图，有三个特征十分醒目。它在轻核区急剧上升，并在 ${}^4\mathrm{He}$、${}^{12}\mathrm{C}$ 与 ${}^{16}\mathrm{O}$ 处出现尖峰。它在铁与镍附近达到约 $8.8\,\mathrm{MeV}$ 的宽极大；最大值属于 ${}^{62}\mathrm{Ni}$（$8.795\,\mathrm{MeV}$），略微领先于 ${}^{58}\mathrm{Fe}$ 与 ${}^{56}\mathrm{Fe}$（$8.790\,\mathrm{MeV}$）。之后它缓慢下降，到铀约为 $7.6\,\mathrm{MeV}$。在表中的大部分区域，$B/A$ 都在 $8\,\mathrm{MeV}$ 的 $10\%$ 以内。

这种近乎恒定是饱和性的第二个迹象。若每个核子吸引所有其他核子，结合能就会像对数 $A(A-1)/2$ 那样增长，$B/A$ 会像 $A$ 一样增长。事实并非如此。核子只被它的近邻束缚，能量正比于核子数，强力的短程就写在曲线上。曲线的形状还告诉你能量可以在哪里释放：两个轻核并合是沿曲线向上（聚变），一个重核裂成两个中等核也是如此（裂变）。[[particles/reactions]] 会把这一定量化。

::: quiz
${}^{238}\mathrm{U}$ 的每个核子的结合能约为 $7.6\,\mathrm{MeV}$，$A \approx 119$ 的核约为 $8.5\,\mathrm{MeV}$。若 ${}^{238}\mathrm{U}$ 裂成两个 $A = 119$ 的核，大约释放多少能量？
- [ ] 约 $0.9\,\mathrm{MeV}$
- [ ] 约 $8\,\mathrm{MeV}$
- [x] 约 $200\,\mathrm{MeV}$
- [ ] 约 $2\,\mathrm{GeV}$
::: solution
238 个核子中的每一个最终都比原来多束缚约 $0.9\,\mathrm{MeV}$，所以释放的能量约为 $238 \times 0.9 \approx 210\,\mathrm{MeV}$。第一个选项忘了乘 $A$。最后一个把结合能与总静能混为一谈——后者约 $220\,\mathrm{GeV}$，且几乎全部留在碎片里。
:::
:::

## 半经验质量公式 {#semf}

1935 年，卡尔·弗里德里希·冯·魏茨泽克（Carl Friedrich von Weizsäcker）把结合能写成一个和式，每一项都出于一个物理图像，系数由实测质量拟合。汉斯·贝特（Hans Bethe）与罗伯特·巴彻（Robert Bacher）在 1936 年对它做了改进。称之为**半**经验公式，是因为每一项的形式都是推出来的，只有系数是拟合的。

::: definition 半经验质量公式 {#def-semf}
**半经验质量公式**（贝特–魏茨泽克公式）把质子数为 $Z$、质量数为 $A$ 的核素的结合能近似为

$$
B(Z, A) = a_V A - a_S A^{2/3} - a_C\,\frac{Z(Z-1)}{A^{1/3}} - a_\mathrm{sym}\,\frac{(A - 2Z)^2}{A} + \delta(Z, A),
$$ {#eq-semf}

其中配对项 $\delta$ 对偶 $Z$ 偶 $N$ 取 $+a_P A^{-3/4}$，对奇 $Z$ 奇 $N$ 取 $-a_P A^{-3/4}$，对奇 $A$ 取 $\delta = 0$。我们采用克拉尼（Krane）《Introductory Nuclear Physics》（1988，§3.3）引用的拟合：

$$
a_V = 15.5, \quad a_S = 16.8, \quad a_C = 0.72, \quad a_\mathrm{sym} = 23, \quad a_P = 34 \qquad (\text{单位均为 MeV}).
$$ {#eq-coeffs}
:::

其他拟合采用的形式略有不同，例如用 $Z^2$ 代替 $Z(Z-1)$，或让配对项正比于 $A^{-1/2}$，系数也相应不同；脱离它所拟合的公式，一组系数毫无意义。下面说明每一项的来源。

**体积项。** 饱和性意味着每个核子被它的近邻以大致相同的能量束缚，所以首项正比于 $A$。

**表面项。** 表面的核子近邻较少，束缚较松。表面核子数正比于面积 $4\pi R^2 \propto A^{2/3}$，所以体积项多算了 $a_S A^{2/3}$。这是表面张力的核类比，也正是以表面为主的轻核 $B/A$ 偏小的原因。

**库仑项。** 质子彼此排斥。它们的静电能是均匀带电球体的能量，下一步就来计算。

**对称项。** 固定 $A$ 时，核倾向于 $N = Z$，原因是一个量子效应，下面解释。代价关于不对称度 $N - Z = A - 2Z$ 是二次的。

**配对项。** 同一轨道中角动量相反的两个全同核子额外地紧。偶–偶核受益，奇–奇核受损。稳定核素中约 150 个是偶–偶的，只有四个（${}^2\mathrm{H}$、${}^6\mathrm{Li}$、${}^{10}\mathrm{B}$、${}^{14}\mathrm{N}$）是奇–奇的。

::: theorem 均匀带电球体的库仑能 {#thm-coulomb}
电荷 $Q$ 均匀分布于半径 $R$ 的球内的静电能为

$$
U = \frac35\,\frac{Q^2}{4\pi\varepsilon_0 R}.
$$ {#eq-coulomb-energy}
:::

::: proof
一层一层地组装这个球。当球半径为 $r$ 时带电 $q(r) = Q r^3/R^3$，由高斯定理，其表面的电势像点电荷一样是 $q(r)/(4\pi\varepsilon_0 r)$。从无穷远运来一层厚 $\dd r$、带电 $\dd q = 3Q r^2\,\dd r/R^3$ 的球壳，需要

$$
\dd U = \frac{q(r)\,\dd q}{4\pi\varepsilon_0 r} = \frac{1}{4\pi\varepsilon_0}\,\frac{Q r^3}{R^3}\cdot\frac{3Q r^2}{R^3 r}\,\dd r = \frac{3Q^2}{4\pi\varepsilon_0 R^6}\,r^4\,\dd r .
$$

从 $0$ 积到 $R$ 得 $U = \frac{3Q^2}{4\pi\varepsilon_0 R^6}\cdot\frac{R^5}{5} = \frac35\,\frac{Q^2}{4\pi\varepsilon_0 R}$。
:::

取 $Q = Ze$、$R = R_0 A^{1/3}$，上式即 $\tfrac35 Z^2 (e^2/4\pi\varepsilon_0 R_0) A^{-1/3}$。单个质子不会与自己排斥，所以数对数时把 $Z^2$ 换成 $Z(Z-1)$，这就是 [[#eq-semf]] 中的形式。利用 [[#eq-units]]，预言的系数为

$$
a_C = \frac35\,\frac{1.440\,\mathrm{MeV\,fm}}{1.2\,\mathrm{fm}} = 0.72\,\mathrm{MeV},
$$

恰好等于拟合值。库仑项是整个公式中系数出于预言而非拟合的唯一一项，这个相符是对核半径的一个检验。

::: proposition 费米气体的对称能 {#prop-symmetry}
把核建模为同一体积 $V$ 中两份独立的理想费米气体：$N$ 个中子与 $Z$ 个质子。固定 $A$，并把不对称度 $\varepsilon = (N - Z)/A$ 展开到二阶，总动能为

$$
E_\mathrm{kin} = \frac35 E_F A\left(1 + \frac59\varepsilon^2\right),
$$

其中 $E_F$ 为 $N = Z$ 时任一气体的费米能。对称系数中来自动能的贡献因此是 $E_F/3$。
:::

::: proof
体积 $V$ 中 $n$ 个质量为 $m$、自旋 $\tfrac12$ 的费米子，费米波数为 $k_F = (3\pi^2 n/V)^{1/3}$，总动能为 $\tfrac35 n\,\hbar^2 k_F^2/2m$，所以固定 $V$ 时它正比于 $n^{5/3}$（见 [[statistical-mechanics/quantum-statistics]]）。写成 $E_\mathrm{kin} = C(N^{5/3} + Z^{5/3})$，$C$ 由体积固定。令 $N = \tfrac{A}{2}(1 + \varepsilon)$、$Z = \tfrac{A}{2}(1 - \varepsilon)$。展开 $(1 \pm \varepsilon)^{5/3} = 1 \pm \tfrac53\varepsilon + \tfrac59\varepsilon^2 + O(\varepsilon^3)$，求和时奇次项相消，得

$$
E_\mathrm{kin} = C\left(\frac{A}{2}\right)^{5/3}\left(2 + \frac{10}{9}\varepsilon^2\right) = 2C\left(\frac{A}{2}\right)^{5/3}\left(1 + \frac59\varepsilon^2\right).
$$

$\varepsilon = 0$ 时上式即 $\tfrac35 E_F A$，这就固定了前置因子。增加量为 $\tfrac35\cdot\tfrac59 E_F A\varepsilon^2 = \tfrac13 E_F (N - Z)^2/A$，正是 $a_\mathrm{sym}(A - 2Z)^2/A$ 的形式，其中 $a_\mathrm{sym} = E_F/3$。
:::

核子密度取 $0.16\,\mathrm{fm}^{-3}$ 时，每种气体的密度为 $0.08\,\mathrm{fm}^{-3}$，于是 $k_F = (3\pi^2 \times 0.08)^{1/3} = 1.33\,\mathrm{fm}^{-1}$，

$$
E_F = \frac{(\hbar c\,k_F)^2}{2 m c^2} = \frac{(197.3 \times 1.333)^2}{2 \times 939}\,\mathrm{MeV} = 37\,\mathrm{MeV}.
$$

动能给出的对称能约 $12\,\mathrm{MeV}$，只有拟合值 $23\,\mathrm{MeV}$ 的一半。其余来自核力本身：中子–质子间的吸引强于中子–中子或质子–质子间的吸引。物理要点在近似之后依然成立：不相容原理使把全部多余核子塞进同一片费米海（Fermi sea）的代价不菲。

::: example 铀-238 的各项 {#ex-u238}
对 ${}^{238}\mathrm{U}$（$Z = 92$）逐项计算 [[#eq-semf]]，并把总和与实测的 $1801.7\,\mathrm{MeV}$ 比较。
::: solution
需要 $A^{2/3} = 38.405$、$A^{1/3} = 6.1972$ 及 $A - 2Z = 54$。于是

$$
\begin{aligned}
a_V A &= 15.5 \times 238 = 3689.0\,\mathrm{MeV}, \\
a_S A^{2/3} &= 16.8 \times 38.405 = 645.2\,\mathrm{MeV}, \\
a_C Z(Z-1)/A^{1/3} &= 0.72 \times 8372 / 6.1972 = 972.7\,\mathrm{MeV}, \\
a_\mathrm{sym}(A-2Z)^2/A &= 23 \times 2916/238 = 281.8\,\mathrm{MeV}, \\
\delta &= +34 \times 238^{-3/4} = +0.56\,\mathrm{MeV}.
\end{aligned}
$$

配对项为正，因为 $Z = 92$ 与 $N = 146$ 皆为偶数。总和为

$$
B = 3689.0 - 645.2 - 972.7 - 281.8 + 0.6 = 1789.9\,\mathrm{MeV},
$$

与实测值相差在 $0.7\%$ 以内，于是 $B/A = 7.52\,\mathrm{MeV}$，实测为 $7.57\,\mathrm{MeV}$。重核中库仑项是最大的修正，超过体积项的 $25\%$。这就是重核不如铁束缚得紧、并能靠裂变或放出 α 粒子释放能量的原因。
:::
:::

同一公式能以约 $1\%$ 的精度重述几乎所有 $A \gtrsim 20$ 的核的实测结合能。它对最轻的核失效——那里"表面"和"体积"已失去意义；对 ${}^4\mathrm{He}$ 它给 $30.8\,\mathrm{MeV}$，而实际为 $28.3\,\mathrm{MeV}$；对氘核（deuteron）它给负值。它还把 ${}^{208}\mathrm{Pb}$ 低估了 $23\,\mathrm{MeV}$（$1613.6$ 对 $1636.4\,\mathrm{MeV}$）。这偏差不是噪声：${}^{208}\mathrm{Pb}$ 的 $Z = 82$、$N = 126$，双双为幻数，那份额外束缚是任何光滑公式都抓不住的壳层效应。

### 稳定谷

固定 $A$ 时，质量公式是 $Z$ 的抛物线。最稳定的同量异位素就是结合能最大——更确切地说原子质量最小——的那一个。

::: theorem 最稳定的同量异位素 {#thm-valley}
略去配对项与中子–氢质量差。固定 $A$ 时，结合能 [[#eq-semf]] 在

$$
Z_0(A) = \frac{4a_\mathrm{sym} + a_C A^{-1/3}}{8a_\mathrm{sym}/A + 2a_C A^{-1/3}} \approx \frac{A}{2}\,\frac{1}{1 + \frac{a_C}{4a_\mathrm{sym}} A^{2/3}} .
$$ {#eq-valley}
处取极大。
:::

::: proof
把 $Z$ 当作连续变量。固定 $A$ 时只有库仑项与对称项依赖 $Z$，且

$$
\pdv{B}{Z} = -a_C\,\frac{2Z - 1}{A^{1/3}} + 4a_\mathrm{sym}\,\frac{A - 2Z}{A}.
$$

二阶导数 $-2a_C A^{-1/3} - 8a_\mathrm{sym}/A$ 为负，所以驻点是极大。令一阶导数为零并把含 $Z$ 的项归并，

$$
Z\left(\frac{2a_C}{A^{1/3}} + \frac{8a_\mathrm{sym}}{A}\right) = \frac{a_C}{A^{1/3}} + 4a_\mathrm{sym},
$$

这就是第一个形式。近似形式则略去分子中的小项 $a_C A^{-1/3}$，再把分子分母同除以 $8a_\mathrm{sym}/A$。
:::

用克拉尼系数，$a_C/4a_\mathrm{sym} = 0.0078$。$A = 56$ 时，[[#eq-valley]] 给 $Z_0 = 25.2$，稳定同量异位素是铁，$Z = 26$。$A = 238$ 时它给 $Z_0 = 91.6$，长寿命同量异位素是铀，$Z = 92$。若在*质量*的最小化中计入质量差 $(m_n - m_\mathrm{H})c^2 = 0.782\,\mathrm{MeV}$，$Z_0$ 会再上移约 $0.2$ 到 $0.8$。稳定谷向中子过剩一侧弯过去，是对称项与库仑项之争：前者要 $N = Z$，后者的代价按 $Z^2/A^{1/3}$ 增长，终究使多余的核子当中子比当质子便宜。

不在谷底附近的核可以通过 β 衰变滚下去——β 衰变固定 $A$ 而把 $Z$ 改变一个单位。奇 $A$ 只有一条抛物线，通常也只有一个稳定同量异位素。偶 $A$ 时配对项把点分成两条抛物线，偶–偶的在下面、奇–奇的在上面；偶–偶的同量异位素可以有两个甚至三个是稳定的，因为夹在它们中间的奇–奇核比两边都重。这就是 [[particles/decay]] 的内容。

## 壳层模型 {#shell}

液滴模型把核子当作流体。然而核内的核子的平均自由程与核本身一样大，因为不相容原理挡住了绝大多数碰撞：被散射的核子所需要的终态早已被占据。于是，把每个核子想象成在所有其他核子产生的平均势中独立运动，是合理的。这就是**独立粒子模型**，又称**壳层模型**。

### 壳层存在的证据

质子数或中子数为某些特定值的核素异乎寻常地稳定：

$$
2, \; 8, \; 20, \; 28, \; 50, \; 82, \; 126 .
$$

这些就是**幻数**（magic number）（126 只对中子而言，因为没有已知元素有那么多质子）。证据是多方面的。一过幻数，分离能陡然下降，正像稀有气体之后电离能那样：从 ${}^{209}\mathrm{Pb}$ 移走第 127 个中子花 $3.9\,\mathrm{MeV}$，从 ${}^{208}\mathrm{Pb}$ 移走第 126 个却要 $7.4\,\mathrm{MeV}$。锡的 $Z = 50$，稳定同位素有十种，比任何其他元素都多。双幻核 ${}^4\mathrm{He}$、${}^{16}\mathrm{O}$、${}^{40}\mathrm{Ca}$ 与 ${}^{208}\mathrm{Pb}$ 比质量公式预言的束缚得更紧，它们的第一激发态也异常地高。

### 从谐振子到自旋–轨道力

平均势跟着密度走，所以一个合理的形状是像 [[#eq-fermi]] 那样边缘圆化的势阱。它的能级被两个可解情形夹在中间：方势阱与三维谐振子。各向同性谐振子的能级为 $E = (\mathcal{N} + \tfrac32)\hbar\omega$，壳层 $\mathcal{N}$ 能容纳同一种核子 $(\mathcal{N}+1)(\mathcal{N}+2)$ 个（已计入两个自旋态）。累计总数为

$$
2,\; 8,\; 20,\; 40,\; 70,\; 112,\; 168 .
$$

前三个与幻数相符。此后谐振子便失灵。更接近实际的平底势阱把每个谐振子壳层按轨道角动量 $\ell$ 分裂，把高 $\ell$ 态压低，但单靠任何中心势都复现不出 28、50、82 与 126。

关键在 1949 年由玛丽亚·格佩特–梅耶（Maria Goeppert Mayer）以及奥托·哈克塞尔（Otto Haxel）、J. 汉斯·D. 延森（J. Hans D. Jensen）与汉斯·休斯（Hans Suess）各自独立找到：单粒子势中有一个很强的**自旋–轨道**（spin–orbit）项

$$
V_{\ell s}(r)\,\mathbf{L}\cdot\mathbf{S}
$$

且 $V_{\ell s} < 0$。由于 $\mathbf{J} = \mathbf{L} + \mathbf{S}$，算符 $\mathbf{L}\cdot\mathbf{S} = \tfrac12(J^2 - L^2 - S^2)$ 在 $j$ 确定的态下是对角的，本征值为

$$
\langle\mathbf{L}\cdot\mathbf{S}\rangle = \frac{\hbar^2}{2}\bigl[j(j+1) - \ell(\ell+1) - \tfrac34\bigr] = \begin{cases} \tfrac12\ell\hbar^2, & j = \ell + \tfrac12, \\ -\tfrac12(\ell+1)\hbar^2, & j = \ell - \tfrac12. \end{cases}
$$ {#eq-ls}

两能级间的劈裂正比于 $2\ell + 1$，随 $\ell$ 增大。$V_{\ell s}$ 为负时，$j = \ell + \tfrac12$ 的能级被压低，与原子精细结构的次序相反；$\ell$ 很大时，它被一路压进下面的壳层。$n$、$\ell$、$j$ 确定的每个能级容纳 $2j + 1$ 个核子。

::: definition 壳层模型轨道 {#def-orbitals}
单核子轨道记作 $n\ell_j$：$n = 1, 2, \dots$ 按能量次序数同一 $\ell$ 的各个轨道，$\ell = 0, 1, 2, 3, 4, 5, 6$ 依次写作 $s, p, d, f, g, h, i$，$j = \ell \pm \tfrac12$。轨道可容纳 $2j + 1$ 个质子或 $2j + 1$ 个中子，宇称为 $(-1)^\ell$。
:::

由此得到的能级次序由质子和中子分别填充（组内的次序因核而异，略有不同）：

| 壳层 | 轨道 | 容量 | 累计 |
|---|---|---|---|
| 1 | $1s_{1/2}$ | 2 | 2 |
| 2 | $1p_{3/2},\ 1p_{1/2}$ | 4, 2 | 8 |
| 3 | $1d_{5/2},\ 2s_{1/2},\ 1d_{3/2}$ | 6, 2, 4 | 20 |
| 4 | $1f_{7/2}$ | 8 | 28 |
| 5 | $2p_{3/2},\ 1f_{5/2},\ 2p_{1/2},\ 1g_{9/2}$ | 4, 6, 2, 10 | 50 |
| 6 | $1g_{7/2},\ 2d_{5/2},\ 2d_{3/2},\ 3s_{1/2},\ 1h_{11/2}$ | 8, 6, 4, 2, 12 | 82 |
| 7 | $1h_{9/2},\ 2f_{7/2},\ 2f_{5/2},\ 3p_{3/2},\ 3p_{1/2},\ 1i_{13/2}$ | 10, 8, 6, 4, 2, 14 | 126 |

闯入者清晰可见：$1f_{7/2}$ 从 $\mathcal{N} = 3$ 的谐振子壳层被劈下来，自成一壳，造出 28；$1g_{9/2}$ 并入下面一层，在 50 处把它封上；$1h_{11/2}$ 造出 82；$1i_{13/2}$ 造出 126。梅耶与延森因这套方案分享 1963 年诺贝尔物理学奖的一半。

::: quiz
${}^{101}\mathrm{Mo}$（$N = 59$）中，超出 $N = 50$ 的九个中子填在哪些轨道里？
- [ ] $1g_{9/2}$，因为它能装 10 个，而壳层到 60 才满
- [x] 第六壳层的 $1g_{7/2},\ 2d_{5/2}, \dots$ 组
- [ ] $1f_{5/2}$，因为 $f$ 轨道排在 $g$ 轨道之后
- [ ] $1h_{11/2}$，那个在 82 处封锁壳层的闯入者
::: solution
$1g_{9/2}$ 轨道在 $N = 50$ 处已经填满；它是被自旋–轨道力压进第五壳层的，这正是 50 成为幻数的原因。第 51 个起的中子进入第六壳层最低的轨道，实际上是彼此靠得很近的 $2d_{5/2}$ 与 $1g_{7/2}$。$1h_{11/2}$ 闯入者也属于第六壳层，只是位于接近壳层顶部处。
:::
:::

### 基态自旋与宇称

模型最锐利的预言关于奇 $A$ 核。同种核子在同一轨道中两两配对，总角动量为零；这正是 [[#eq-semf]] 中出现的配对。偶–偶核的基态因此是 $0^+$，至今没有已知的例外。奇 $A$ 核的基态自旋与宇称，就是那个单个未配对核子——或已满轨道中那个空穴（hole）——的自旋与宇称。

::: example 预言 $J^\pi$ {#ex-spin-parity}
预言 ${}^{17}\mathrm{O}$、${}^{15}\mathrm{O}$ 与 ${}^{209}\mathrm{Bi}$ 的基态自旋与宇称。
::: solution
${}^{17}\mathrm{O}$ 的 $Z = 8$、$N = 9$。八个质子与前八个中子填满到幻数 8，贡献 $0^+$。第九个中子进入下一个轨道 $1d_{5/2}$，$\ell = 2$、$j = \tfrac52$。宇称 $(-1)^2 = +$，所以预言为 $\tfrac52^+$，与实测一致。

${}^{15}\mathrm{O}$ 的 $Z = 8$、$N = 7$：比满壳层差一个中子。已满轨道缺一个核子时，其角动量与宇称就是那个缺席核子的角动量与宇称。缺的中子在 $1p_{1/2}$，$\ell = 1$，所以预言为 $\tfrac12^-$，与实测一致。

${}^{209}\mathrm{Bi}$ 的 $Z = 83$、$N = 126$。中子构成满壳层。八十二个质子填到幻数，第 83 个进入 $1h_{9/2}$，$\ell = 5$：预言为 $\tfrac92^-$，与实测一致。同样的逻辑给出 ${}^{41}\mathrm{Ca}$ 为 $\tfrac72^-$（$1f_{7/2}$ 中子），${}^{207}\mathrm{Pb}$ 为 $\tfrac12^-$（$3p_{1/2}$ 空穴）。
:::
:::

对靠近满壳层的几乎一切奇 $A$ 核，这些预言都成立。远离满壳层时，价核子之间的残余相互作用与核的永久形变会破坏它们；那里的核做集体运动，整体转动、振动，正如液滴模型所提示的。用同一图像（施密特值）预言的磁偶极矩落在壳层模型上下限之间而不落在其上，这是独立粒子图像只是一种近似的又一个迹象。

::: intuition 为什么两个模型可以都对
液滴模型对所有核子求和，只看平均值：体积、表面、电荷、不对称。壳层模型看最后几个核子，看它们占据的量子能级。$1800\,\mathrm{MeV}$ 的总结合能由平均值主导，壳层效应把它移动几个 MeV——对 $B$ 是小修正，对最后一个核子的性质却是大影响。现代核模型把两者合起来：在液滴能量上加上壳修正。
:::

::: history 从卢瑟福的核到壳层模型
欧内斯特·卢瑟福（Ernest Rutherford）在解释汉斯·盖革（Hans Geiger）与欧内斯特·马斯登（Ernest Marsden）的 α 散射实验的基础上，1911 年提出原子的核模型。詹姆斯·查德威克（James Chadwick）1932 年从 α 粒子轰击铍产生的贯穿辐射中辨认出中子；几个月之内，沃纳·海森堡（Werner Heisenberg）等人就把核描述为质子与中子的组合。魏茨泽克 1935 年发表质量公式，贝特与巴彻 1936 年写出影响深远的核物理综述；尼尔斯·玻尔（Niels Bohr）1936 年的复合核（compound nucleus）图像为液滴图像画上圆满的句号。霍夫施塔特在斯坦福的电子散射测量始于 1953 年，给出第一批细致的电荷分布，他也因此分享 1961 年诺贝尔物理学奖。瓦尔特·埃尔萨瑟（Walter Elsasser）1933 年就注意到一些特殊的数，但壳层模型真正令人信服，是在 1949 年玛丽亚·格佩特–梅耶以及各自独立的哈克塞尔、延森与休斯提出自旋–轨道耦合之后。
:::

## 后续内容 {#leads}

质量公式与它的稳定谷统辖着后面两章。在 [[particles/decay]] 里，不在谷底的核经 β 衰变向谷底靠拢，而位于稳定谷高端附近的重核放出 α 粒子，因为库仑项已使这在能量上有利。在 [[particles/reactions]] 里，结合能曲线决定裂变与聚变释放的能量。壳层模型将在 γ 衰变中重新登场：能级的自旋与宇称决定了哪些跃迁快。放射性同位素的化学及其应用见化学图谱的课程[核化学](/learn/chemistry/lesson.php?c=general-chemistry-2&l=nuclear-chemistry)。

两个模型都不解释的是核力本身。它的短程、它的饱和性、它对自旋的依赖，都是夸克之间强相互作用的残余，将在 [[particles/standard-model]] 中处理。多体工具——费米气体与平均场——来自 [[quantum-2/identical-particles]] 与 [[statistical-mechanics/quantum-statistics]]。

::: summary
- 原子核由 $Z$ 个质子与 $N$ 个中子组成，$A = Z + N$。能量用 MeV，长度用 fm；$\hbar c = 197.3\,\mathrm{MeV\,fm}$，$e^2/4\pi\varepsilon_0 = 1.440\,\mathrm{MeV\,fm}$。
- 电子散射通过形状因子——密度的傅里叶变换——测量电荷分布。它在小 $q^2$ 处的斜率给出 $\langle r^2\rangle$；衍射极小给出大小。
- 核密度几乎恒定，约 $0.16\,\mathrm{fm}^{-3}$，于是 $R = R_0 A^{1/3}$，$R_0 \approx 1.2\,\mathrm{fm}$，表面厚约 $2.4\,\mathrm{fm}$。
- 结合能为 $B = [Z m({}^1\mathrm{H}) + N m_n - m(\text{原子})]c^2$。多数核的 $B/A$ 在 $8\,\mathrm{MeV}$ 上下，在铁与镍附近达到 $8.8\,\mathrm{MeV}$ 的极大：核力是饱和的。
- 半经验质量公式有体积项、表面项、库仑项、对称项与配对项。库仑系数 $a_C = \tfrac35 e^2/(4\pi\varepsilon_0 R_0) = 0.72\,\mathrm{MeV}$ 是预言的；其余是拟合的。
- 固定 $A$ 时，$B$ 是 $Z$ 的抛物线，极大在 $Z_0 \approx (A/2)/(1 + 0.0078A^{2/3})$ 处，稳定谷因此弯向 $N > Z$。
- 幻数 2、8、20、28、50、82、126 来自平均势中独立的核子，其中的强自旋–轨道项压低 $j = \ell + \tfrac12$。
- 偶–偶核的 $J^\pi = 0^+$；满壳层附近的奇 $A$ 核取最后一个核子或空穴的 $j$ 与宇称 $(-1)^\ell$。
:::

## 习题 {#exercises}

::: exercise 铅核的半径 {level=1 check="7.11"}
用 $R = R_0 A^{1/3}$ 与 $R_0 = 1.2\,\mathrm{fm}$，求 ${}^{208}\mathrm{Pb}$ 的半径，以飞米计。
::: solution
$208^{1/3} = 5.925$，所以 $R = 1.2 \times 5.925 = 7.11\,\mathrm{fm}$。实测均方根电荷半径为 $5.50\,\mathrm{fm}$，而 $\sqrt{5/3}\times 5.50 = 7.10\,\mathrm{fm}$：对重核而言，等价均匀球与 $R_0 = 1.2\,\mathrm{fm}$ 符合得很好。
:::
:::

::: exercise 氘核 {level=1 check="2.225"}
${}^2\mathrm{H}$ 的原子质量为 $2.01410178\,\mathrm{u}$。用 $m({}^1\mathrm{H}) = 1.00782503\,\mathrm{u}$、$m_n = 1.00866492\,\mathrm{u}$ 与 $1\,\mathrm{u} = 931.494\,\mathrm{MeV}/c^2$，求氘核的结合能，以 MeV 计，保留三位小数。
::: solution
由 [[#eq-binding]]，$m({}^1\mathrm{H}) + m_n - m({}^2\mathrm{H}) = 1.00782503 + 1.00866492 - 2.01410178 = 0.00238817\,\mathrm{u}$，于是 $B = 0.00238817 \times 931.494 = 2.2246\,\mathrm{MeV}$，即 $2.225\,\mathrm{MeV}$（保留三位小数）。若质量只舍入到小数点后六位，差值为 $0.002388\,\mathrm{u}$，$B$ 的第三位小数就已不确定：结合能是大数之差的小头。氘核的 $B/A = 1.11\,\mathrm{MeV}$，远低于较重核典型的 $8\,\mathrm{MeV}$：它没有内层核子，全都是表面。它的结合能可由 $n + p \to d + \gamma$ 放出的光子直接测得。
:::
:::

::: exercise 半径之比 {level=1 check="2.71"}
按 [[#eq-radius]]，${}^{238}\mathrm{U}$ 的半径是 ${}^{12}\mathrm{C}$ 的多少倍？
::: solution
比值为 $(238/12)^{1/3} = (19.83)^{1/3} = 2.71$。铀核的体积约为碳核的二十倍，半径却不到三倍。（实测均方根半径 $5.86$ 与 $2.47\,\mathrm{fm}$ 之比为 $2.37$，因为碳的表面相对太厚，使它比 $R_0 A^{1/3}$ 的估计更大。）
:::
:::

::: exercise 由质量公式算钙-40 {level=2 check="8.64"}
用 [[#eq-semf]] 与系数 [[#eq-coeffs]] 估算 ${}^{40}\mathrm{Ca}$ 的 $B/A$，以 MeV 计。与实测值 $8.551\,\mathrm{MeV}$ 比较。
::: solution
$A = 40$、$Z = 20$：$A^{1/3} = 3.420$，$A^{2/3} = 11.696$，$A - 2Z = 0$，且核为偶–偶。各项为

$$
\begin{aligned}
a_V A &= 620.0\,\mathrm{MeV}, & a_S A^{2/3} &= 196.5\,\mathrm{MeV}, \\
a_C Z(Z-1)A^{-1/3} &= 0.72 \times 380/3.420 = 80.0\,\mathrm{MeV}, & a_\mathrm{sym}(A-2Z)^2/A &= 0, \\
\delta &= 34 \times 40^{-3/4} = 2.14\,\mathrm{MeV}.
\end{aligned}
$$

于是 $B = 620.0 - 196.5 - 80.0 + 2.1 = 345.6\,\mathrm{MeV}$，$B/A = 8.64\,\mathrm{MeV}$，比实测的 $8.55\,\mathrm{MeV}$ 高约 $1\%$。即便对双幻核，公式在这里也偏高，因为对轻核而言，用单一系数的表面项太粗糙了。
:::
:::

::: exercise A = 125 的稳定同量异位素 {level=2 check="52.35"}
用 [[#eq-valley]]（精确的第一形式，克拉尼系数）求 $A = 125$ 的 $Z_0$，保留两位小数。哪个元素是稳定同量异位素？
::: solution
$A = 125$ 时 $A^{1/3} = 5$ 恰为整数，所以 $a_C A^{-1/3} = 0.144\,\mathrm{MeV}$，$8a_\mathrm{sym}/A = 184/125 = 1.472\,\mathrm{MeV}$。于是

$$
Z_0 = \frac{92 + 0.144}{1.472 + 0.288} = \frac{92.144}{1.760} = 52.35.
$$

最接近的整数是 $52$，碲；${}^{125}\mathrm{Te}$ 正是 $A = 125$ 的稳定同量异位素。相邻的 ${}^{125}\mathrm{Sb}$（$Z = 51$）与 ${}^{125}\mathrm{I}$（$Z = 53$）都向它 β 衰变。若把 $0.78\,\mathrm{MeV}$ 的中子–氢质量差计入，质量极小移到 $52.8$，结论不变。
:::
:::

::: exercise 镜核的半径 {level=2 check="1.39"}
**镜核**（mirror nuclei）${}^{15}\mathrm{O}$（$Z = 8$、$N = 7$）与 ${}^{15}\mathrm{N}$（$Z = 7$、$N = 8$）只差把一个质子与一个中子互换。设核力对两者相同（电荷对称性），于是它们的结合能只差在库仑能 $\tfrac35 Z(Z-1)\,e^2/(4\pi\varepsilon_0 R)$，$R$ 相同。原子质量为 $15.003066\,\mathrm{u}$ 与 $15.000109\,\mathrm{u}$。求 $R$，再以 fm 计 $R_0 = R/A^{1/3}$。
::: hint
先用 [[#eq-binding]] 把质量差化为结合能差：把一个 $n$ 换成一个 ${}^1\mathrm{H}$ 原子要花 $(m_n - m_\mathrm{H})c^2 = 0.782\,\mathrm{MeV}$。
:::
::: solution
由 [[#eq-binding]]，$B({}^{15}\mathrm{N}) - B({}^{15}\mathrm{O}) = [m({}^{15}\mathrm{O}) - m({}^{15}\mathrm{N})]c^2 + (m_n - m_\mathrm{H})c^2$，因为 ${}^{15}\mathrm{N}$ 多一个中子、少一个氢原子。数值上，

$$
\Delta B = (0.002957)(931.494) + 0.782 = 2.754 + 0.782 = 3.537\,\mathrm{MeV}.
$$

按假设，这就是库仑能之差，其中氧的 $Z(Z-1) = 56$、氮的 $Z(Z-1) = 42$：

$$
3.537\,\mathrm{MeV} = \frac35\,\frac{1.440\,\mathrm{MeV\,fm} \times 14}{R} \quad\Longrightarrow\quad R = \frac{12.10}{3.537}\,\mathrm{fm} = 3.42\,\mathrm{fm}.
$$

由 $15^{1/3} = 2.466$，$R_0 = 3.42/2.466 = 1.39\,\mathrm{fm}$。这比电子散射给出的值大，因为这一简单公式忽略了库仑能中的交换项与奇质子伸展的电荷；把这两者计入、并对多对镜核作分析，得到 $R_0 \approx 1.2\,\mathrm{fm}$——对 [[#eq-radius]] 的第三个独立印证。
:::
:::

::: exercise 自旋与宇称 {level=2}
用壳层模型预言 ${}^{13}\mathrm{C}$、${}^{39}\mathrm{K}$、${}^{57}\mathrm{Ni}$ 与 ${}^{90}\mathrm{Zr}$ 的基态 $J^\pi$。
::: solution
${}^{13}\mathrm{C}$：$Z = 6$（偶数，已配对），$N = 7$。中子填满 $1s_{1/2}$（2 个）、$1p_{3/2}$（4 个），第七个进入 $1p_{1/2}$：$\tfrac12^-$。

${}^{39}\mathrm{K}$：$Z = 19$，$N = 20$（幻数）。质子比 20 差一个，是 $1d_{3/2}$（$\ell = 2$）中的空穴：$\tfrac32^+$。

${}^{57}\mathrm{Ni}$：$Z = 28$（幻数），$N = 29$。第 29 个中子是 28 之上的第一个，在 $2p_{3/2}$：$\tfrac32^-$。

${}^{90}\mathrm{Zr}$：$Z = 40$、$N = 50$，皆为偶数：$0^+$。

四个都与实验一致。注意宇称来自 $\ell$ 而非 $j$：$1p_{1/2}$ 与 $2p_{3/2}$ 都是奇的。
:::
:::

::: exercise 有相互作用的对称能 {level=3}
(a) 证明：若固定 $A$ 时的结合能为 $B(Z) = B_0 - \beta (Z - Z_0)^2$，则质子数为 $Z_0 + k$ 的核 β 衰变到 $Z_0 + k - 1$ 时释放的能量随 $k$ 线性增长。(b) 用 [[#prop-symmetry]] 的费米气体结果并取 $E_F = 37\,\mathrm{MeV}$，证明仅动能就给出 $a_\mathrm{sym}$ 的约一半，并用一两句话说明这对核子–核子力意味着什么。
::: hint
对 (a)，忽略中子–氢质量差，于是释放的能量就是结合能的增量 $B(Z_0 + k - 1) - B(Z_0 + k)$。
:::
::: solution
(a) 增量为

$$
B(Z_0 + k - 1) - B(Z_0 + k) = -\beta\bigl[(k-1)^2 - k^2\bigr] = \beta(2k - 1),
$$

随 $k$ 线性增长：离谷底越远的核每步释放的能量越多，因而衰变得越快（衰变速率随能量急剧上升，[[particles/decay]] 会说明这一点）。与 [[#eq-semf]] 对照，把 $(A - 2Z)^2$ 与 $Z(Z-1)$ 在 $Z_0$ 附近展开后 $\beta = 2a_C A^{-1/3} + 8 a_\mathrm{sym}/A$。

(b) [[#prop-symmetry]] 给出 $a_\mathrm{sym}^\mathrm{kin} = E_F/3 = 37/3 = 12.3\,\mathrm{MeV}$，约为拟合值 $23\,\mathrm{MeV}$ 的 $54\%$。其余的 $11\,\mathrm{MeV}$ 必须来自势能，所以异种核子（中子–质子）之间的吸引平均而言必须强于同种核子之间的吸引。这与氘核的情况一致：$np$ 对氘核是唯一束缚的双核子系统——$nn$ 与 $pp$ 都不束缚。
:::
:::

::: exercise 均方根半径与小 $q$ 展开 {level=3}
(a) 证明：对任何球对称的归一化密度，$F(q) = 1 - \tfrac16 q^2\langle r^2\rangle + \tfrac{1}{120}q^4\langle r^4\rangle - \dots$。(b) 对均匀球证明 $\langle r^4\rangle = \tfrac37 R^4$，并验证 [[#eq-ff-sphere]] 的展开到 $q^4$ 阶相符。(c) 解释为什么只出现 $q$ 的偶次幂。
::: hint
在 [[#eq-ff-radial]] 内展开 $\sin(x)/x = 1 - x^2/6 + x^4/120 - \dots$，并把 $\sin x - x\cos x$ 展开到 $x^7$ 阶。
:::
::: solution
(a) 把 $\sin(qr)/(qr) = \sum_{k\ge 0} (-1)^k (qr)^{2k}/(2k+1)!$ 代入 [[#eq-ff-radial]] 并逐项积分（矩有限时这是合法的，对快速衰减的密度确实如此）得 $F(q) = \sum_k (-1)^k q^{2k}\langle r^{2k}\rangle/(2k+1)!$，其前几项即 $1 - q^2\langle r^2\rangle/6 + q^4\langle r^4\rangle/120$。

(b) $\langle r^4\rangle = \frac{3}{R^3}\int_0^R r^6\,\dd r = \frac{3}{7}R^4$。另一边，令 $x = qR$，

$$
\sin x - x\cos x = \Bigl(x - \frac{x^3}{6} + \frac{x^5}{120} - \frac{x^7}{5040}\Bigr) - \Bigl(x - \frac{x^3}{2} + \frac{x^5}{24} - \frac{x^7}{720}\Bigr) + \dots = \frac{x^3}{3} - \frac{x^5}{30} + \frac{x^7}{840} - \dots
$$

于是 $3(\sin x - x\cos x)/x^3 = 1 - x^2/10 + x^4/280 - \dots$。由 (a) 的级数得 $1 - \tfrac16 \cdot \tfrac35 x^2 + \tfrac{1}{120}\cdot\tfrac37 x^4 = 1 - x^2/10 + x^4/280$，两者相符。

(c) $F$ 对 $\mathbf{q}$ 的依赖只通过 $\mathbf{q}\cdot\mathbf{r}$ 对 $\mathbf{r}$ 的各方向积分出现，所以对球对称密度 $F(\mathbf{q}) = F(-\mathbf{q})$，这使 $F(q)$ 是 $q$ 的偶函数。等价地说，$\sin(qr)/(qr)$ 是 $q$ 的偶函数。
:::
