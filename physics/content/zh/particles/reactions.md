1919 年，欧内斯特·卢瑟福（Ernest Rutherford）让放射源的 α 粒子穿过氮气，看到了一些射程远比 α 粒子为远的粒子产生的闪烁：那是质子。他把氮嬗变成了氧——第一次有意为之的核反应。此后核物理的每一个问题，从原子核的结构到恒星的能量，都是靠把入射粒子与靶撞在一起、再追问两件事得到回答的：反应为能量守恒所允许吗？它发生的概率有多大？

第一个问题由 **Q 值**（Q-value）回答，即释放的静能，它直接来自 [[particles/nuclear-structure]] 的结合能记账。第二个问题由**截面**（cross-section）回答——一个把全部动力学编码在内的等效靶面积：把带正电的核彼此隔开的库仑势垒、复合核的共振、根本没有势垒的慢中子俘获，尽在其中。本章把两者都建立起来，然后用到大规模释放核能的两种反应上：重核的裂变与轻核的聚变。我们在能量学的层面处理它们，足以看清为什么每次裂变约释放 $200\,\mathrm{MeV}$，以及太阳为什么能发光一百亿年。

我们用到 [[particles/decay]] 的衰变 Q 值与隧穿因子、[[relativity/velocity-energy]] 与 [[relativity/four-vectors]] 的相对论能量–动量关系，以及 [[thermodynamics/kinetic-theory]] 的麦克斯韦–玻尔兹曼分布。质量取 AME2020 的原子质量，并使用 $1\,\mathrm{u} = 931.494\,\mathrm{MeV}/c^2$ 与 $e^2/4\pi\varepsilon_0 = 1.440\,\mathrm{MeV\,fm}$。

## Q 值与阈能 {#qvalue}

两体反应写作

$$
a + X \to Y + b \qquad\text{或}\qquad X(a, b)Y ,
$$

其中 $a$ 是入射粒子，$X$ 是靶（在实验室系中通常静止），$Y$ 是剩余核，$b$ 是较轻的出射粒子。卢瑟福的反应是 ${}^{14}\mathrm{N}(\alpha, p){}^{17}\mathrm{O}$。在这些能量下，每个核反应都电荷守恒、核子数守恒，所以上下标必须配平。

::: definition 反应 Q 值 {#def-qreaction}
$X(a, b)Y$ 的 **Q 值**（Q-value）为

$$
Q = \bigl[m_a + m_X - m_Y - m_b\bigr]c^2 = K_Y + K_b - K_a - K_X ,
$$ {#eq-q}

即初始静能超出末态静能的部分，由能量守恒知它等于动能的增量。$Q > 0$ 时反应**放能**（exothermic），$Q < 0$ 时**吸能**（endothermic）。由于电荷配平时电子也随之配平，可以用原子质量计算。
:::

就能量而言，放能反应即使在入射粒子静止时也能进行（它实际会不会进行，那是势垒与截面的问题）。吸能反应则要求入射粒子的动能至少为 $\lvert Q\rvert$，而且实际上要更多，因为动量守恒禁止产物在实验室系中全静止：入射粒子的能量必须有一部分拿去做质心运动。

::: theorem 阈能 {#thm-threshold}
对静止靶上的吸能反应 $a + X \to$（总质量为 $M_f$ 的产物），反应可能进行的最小入射粒子动能为

$$
K_\mathrm{th} = \frac{(M_f^2 - (m_a + m_X)^2)c^2}{2m_X} = -Q\,\frac{m_a + m_X + M_f}{2m_X}.
$$ {#eq-threshold}

当 $\lvert Q\rvert \ll m_X c^2$ 时，这就是 $K_\mathrm{th} \approx -Q\,(1 + m_a/m_X)$。
:::

::: proof
初态的不变质量平方 $s = (E_\mathrm{tot}^2 - p_\mathrm{tot}^2c^2)$ 在各参考系中相同（[[relativity/four-vectors]]）。在实验室系中，入射粒子能量为 $E_a = K_a + m_ac^2$、靶静止，

$$
s = (E_a + m_Xc^2)^2 - p_a^2c^2 = m_a^2c^4 + m_X^2c^4 + 2E_am_Xc^2 .
$$

在质心系中，产物最好也只能全部静止，所以末态 $s$ 的最小可能值为 $M_f^2c^4$。当且仅当 $s \ge M_f^2c^4$ 时反应才可能。在阈能处，$2E_am_Xc^2 = (M_f^2 - m_a^2 - m_X^2)c^4$，于是

$$
K_\mathrm{th} = E_a - m_ac^2 = \frac{(M_f^2 - m_a^2 - m_X^2 - 2m_am_X)c^2}{2m_X} = \frac{(M_f^2 - (m_a + m_X)^2)c^2}{2m_X} .
$$

把平方差因式分解，并注意到 $-Q = (M_f - m_a - m_X)c^2$，即得第二个形式；当 $M_f \approx m_a + m_X$ 时，因子 $(m_a + m_X + M_f)/2m_X \approx (m_a + m_X)/m_X$。
:::

同一条公式也支配加速器上的粒子产生，那里 $\lvert Q\rvert$ 与质量相比不再是小量；[[particles/accelerators]] 用它来比较固定靶机器与对撞机。

::: example 卢瑟福的嬗变 {#ex-rutherford}
求 ${}^{14}\mathrm{N}(\alpha, p){}^{17}\mathrm{O}$ 的 Q 值与阈能。原子质量：${}^{14}\mathrm{N}$ $14.003074$、${}^4\mathrm{He}$ $4.002603$、${}^{17}\mathrm{O}$ $16.999132$、${}^1\mathrm{H}$ $1.007825\,\mathrm{u}$。
::: solution
由 [[#eq-q]]，

$$
Q = (14.003074 + 4.002603 - 16.999132 - 1.007825)(931.494)\,\mathrm{MeV} = (-0.001280)(931.494) = -1.192\,\mathrm{MeV}.
$$

反应是吸能的。[[#eq-threshold]] 的非相对论形式给出

$$
K_\mathrm{th} = 1.192 \times \left(1 + \frac{4.0026}{14.0031}\right) = 1.192 \times 1.2858 = 1.533\,\mathrm{MeV},
$$

精确形式与它相符到四位数字。卢瑟福所用的 ${}^{214}\mathrm{Po}$ 的 α 粒子有 $7.7\,\mathrm{MeV}$，稳稳地在阈能之上。起限制作用的不是能量而是库仑势垒——按 [[#eq-barrier]]，$\alpha + {}^{14}\mathrm{N}$ 的约为 $4\,\mathrm{MeV}$——还有那微小的截面：大约每一百万个 α 粒子才有一个产生质子。
:::
:::

## 截面 {#cross-sections}

能量守恒说反应能不能发生。截面说它多久发生一次。

::: definition 截面 {#def-sigma}
每秒 $\dot N_a$ 个粒子的束流均匀铺在比靶大的面积上，打在薄靶上，靶的面密度为 $n_t$（表面单位面积内的靶核数）。若每秒发生 $\dot N_R$ 个反应，则**截面**（cross-section）为

$$
\sigma = \frac{\dot N_R}{\dot N_a\, n_t}.
$$ {#eq-sigma}

它有面积的量纲。核物理的单位是**靶恩**（barn），$1\,\mathrm{b} = 10^{-28}\,\mathrm{m}^2 = 100\,\mathrm{fm}^2$。若改为把靶浸在均匀通量 $\Phi$（单位时间单位面积的粒子数）中，则每个靶核以速率 $\sigma\Phi$ 发生反应。
:::

这幅图像是：靶核向束流呈现一块面积 $\sigma$，进入这块面积的入射粒子就发生反应，没进入的就不发生。"薄"指各核互不遮蔽，$n_t\sigma \ll 1$。一个靶恩大致是一个重核的几何面积 $\pi(7\,\mathrm{fm})^2 = 1.5\,\mathrm{b}$，1942 年美国物理学家因此得名：as big as a barn（"像谷仓一样大"）。实测截面从几千靶恩（某些核的慢中子俘获）一直跨到 $10^{-20}\,\mathrm{b}$（中微子相互作用），所以几何图像只是个便于记忆的类比。

厚靶会衰减束流。在核数密度为 $n$（单位体积内的核数）的介质中，已深入 $x$ 的束流在下一层损失 $\dd I = -I n\sigma\,\dd x$，于是

$$
I(x) = I_0 e^{-n\sigma x}, \qquad \ell = \frac{1}{n\sigma},
$$ {#eq-attenuation}

其中 $\ell$ 是**平均自由程**。这与衰变定律是同一个指数，只是把时间换成了深度。

**微分截面** $\dd\sigma/\dd\Omega$ 只数沿给定方向进入小立体角 $\dd\Omega$ 的出射粒子；对整个立体角积分就得到 $\sigma$。带电粒子的卢瑟福散射是经典例子，它由 [[analytical-mechanics/central-forces]] 中的库仑轨道导出：

$$
\frac{\dd\sigma}{\dd\Omega} = \left(\frac{zZe^2}{4\pi\varepsilon_0\,4K}\right)^2 \frac{1}{\sin^4(\theta/2)} .
$$

它的总截面是无穷大，因为库仑力力程无穷；有意义的只有微分形式。

::: example 金的中子活化 {#ex-activation}
一片质量 $1.00\,\mathrm{mg}$ 的金箔放在热中子通量 $\Phi = 1.0\times10^{16}\,\mathrm{m^{-2}\,s^{-1}}$ 中。${}^{197}\mathrm{Au}$ 对热中子的俘获截面为 $98.7\,\mathrm{b}$，产物 ${}^{198}\mathrm{Au}$ 的 $t_{1/2} = 2.694\,\mathrm{d}$。求生成速率与辐照一天后的活度。
::: solution
金箔含 $N = (1.00\times10^{-3}/196.97)\times 6.022\times10^{23} = 3.057\times10^{18}$ 个核。每个核的俘获速率为 $\sigma\Phi = 98.7\times10^{-28} \times 1.0\times10^{16} = 9.87\times10^{-11}\,\mathrm{s}^{-1}$，所以生成速率为

$$
R = N\sigma\Phi = 3.02\times10^{8}\,\mathrm{s}^{-1}.
$$

（金箔对中子是薄的：$N\sigma\Phi$ 每秒只占 $N$ 的极小部分，燃耗可以忽略。）${}^{198}\mathrm{Au}$ 的核数服从 $\dot N_{198} = R - \lambda N_{198}$，这是带恒定源的衰变链，所以 $N_{198} = (R/\lambda)(1 - e^{-\lambda t})$，活度为

$$
\mathcal{A}(t) = R\left(1 - e^{-\lambda t}\right).
$$

由 $\lambda t = \ln 2 \times 1/2.694 = 0.2573$、$1 - e^{-0.2573} = 0.2269$，得 $\mathcal{A} = 6.8\times10^7\,\mathrm{Bq}$。无限期辐照至多给出**饱和活度** $R = 3.0\times10^8\,\mathrm{Bq}$；辐照超过几个半衰期就是浪费。活化分析把这套计算倒过来做：由测得的活度推出样品里有多少金原子。
:::
:::

### 势垒、共振与慢中子

三个特征决定了核截面随能量的变化。

**库仑势垒。** 电荷为 $Z_1e$ 与 $Z_2e$ 的两个核，在两表面相切、相距 $R_1 + R_2$ 时开始感受到强力。该处的静电能为

$$
V_C = \frac{Z_1Z_2e^2}{4\pi\varepsilon_0(R_1 + R_2)}, \qquad R_i = R_0A_i^{1/3},
$$ {#eq-barrier}

为此目的 $R_0$ 取 $1.2$ 到 $1.4\,\mathrm{fm}$。对 $\alpha + {}^{14}\mathrm{N}$，取 $R_0 = 1.2\,\mathrm{fm}$ 得 $2 \times 7 \times 1.440/(1.2(1.587 + 2.410)) = 4.2\,\mathrm{MeV}$；对 $\alpha + {}^{197}\mathrm{Au}$ 得 $26\,\mathrm{MeV}$——这就是盖革与马斯登的 $5$–$8\,\mathrm{MeV}$ α 粒子在金上的散射与点电荷的散射完全一样的原因。势垒以下，带电粒子反应只能靠隧穿，带着 [[particles/decay]] 的伽莫夫因子，截面随能量下降而指数跌落。

**共振。** 许多反应经由**复合核**（compound nucleus）进行，这是玻尔（Niels Bohr）1936 年提出的图像：入射粒子被吸收，它的能量分配到所有核子之间，系统活得足够久，在衰变之前已经"忘了"自己是怎样形成的。当入射粒子能量对上复合核的一个准束缚能级时，截面出现尖峰，由**布莱特–维格纳**（Breit–Wigner）公式描述（格雷戈里·布莱特与尤金·维格纳，1936 年）：

$$
\sigma(E) = \frac{\pi}{k^2}\, g\, \frac{\Gamma_a\Gamma_b}{(E - E_R)^2 + \Gamma^2/4},
$$ {#eq-bw}

其中 $k$ 是相对运动的波数，$g$ 是自旋统计因子，$E_R$ 是共振能量，$\Gamma$ 是能级的总宽度（其寿命为 $\hbar/\Gamma$），$\Gamma_a$、$\Gamma_b$ 是入射道与出射道的部分宽度。峰在半高处的全宽度为 $\Gamma$。同一条公式也描述 [[particles/standard-model]] 中的粒子共振，例如 $Z$ 玻色子。

::: widget plot
f: (G^2/4)/((x - E)^2 + G^2/4)
x: 0, 10
y: 0, 1.1
sliders: E=5:1:9:0.1; G=0.5:0.05:3:0.05
labels: 布莱特–维格纳线型，峰处归一化为 1
caption: [[#eq-bw]] 的能量依赖，$\pi g\Gamma_a\Gamma_b/k^2$ 取固定值、峰高缩放为 1；横轴为能量（任意单位）。图打开时 $E_R = 5$、$\Gamma = 0.5$。把 $\Gamma$ 缩小，线形变得又高又窄，那是长寿命态的特征；把它放宽，峰便化入背景。注意半高之点总在 $E_R \pm \Gamma/2$ 处，所以宽度可以从曲线上直接读出，再用 $\tau = \hbar/\Gamma$ 换算成寿命。
:::

**慢中子。** 中子感受不到库仑势垒，所以无论多慢都可能被俘获。在低能、远离共振处，俘获截面按 $1/v$ 变化：中子在核附近停留的时间正比于 $1/v$，而 [[#eq-bw]] 中的因子 $\pi/k^2 \propto 1/v^2$ 乘上一个入射道宽度 $\Gamma_a \propto v$。因此，用水或石墨这类**慢化剂**（moderator）中的碰撞把中子放慢，能使俘获与中子致裂变容易得多。费米在罗马的小组 1934 年发现了这一点：他们发现源四周包上石蜡，感生放射性会增大一百倍。

::: quiz
为什么质子引起的重核反应需要几 MeV 的束流，而同一批核上的中子引起的反应常常在低于 $1\,\mathrm{eV}$ 时概率最大？
- [ ] 质子比中子重。
- [x] 质子必须越过或隧穿库仑势垒，中子则完全遇不到势垒，而且慢中子的俘获截面按 $1/v$ 增长。
- [ ] 中子只被弱相互作用吸收，而弱相互作用在低能最强。
- [ ] 质子引起的反应的 Q 值总是负的。
::: solution
质子与中子的质量只差 $0.14\%$，与本题无关。质子带电荷，在重核上面对的势垒在 $10\,\mathrm{MeV}$ 量级，低于它时截面被伽莫夫因子压低。中子靠强力被俘获，没有势垒，而 $1/v$ 定律使越慢的中子越容易反应。Q 值与入射粒子的电荷毫无关系。
:::
:::

## 裂变 {#fission}

1938 年岁末，柏林的奥托·哈恩（Otto Hahn）与弗里茨·施特拉斯曼（Fritz Strassmann）在中子轰击铀的产物中发现了钡。钡的 $Z = 56$，大约是铀 92 的一半。那年夏天已离开德国的丽泽·迈特纳（Lise Meitner）与她的外甥奥托·弗里施（Otto Frisch）在 1938 年圣诞节期间解释了这一结果，并于 1939 年 2 月发表：铀核裂成了两半，像一个拉长而分裂的液滴，释放约 $200\,\mathrm{MeV}$。弗里施把它称为**裂变**（fission）。

### 重核为什么会分裂

结合能曲线已经回答了能量问题。$A = 236$ 的核 $B/A \approx 7.6\,\mathrm{MeV}$；两个 $A \approx 118$ 的碎片 $B/A \approx 8.5\,\mathrm{MeV}$。每个核子约获得 $0.9\,\mathrm{MeV}$，$236 \times 0.9 \approx 210\,\mathrm{MeV}$ 释放出来。

::: example 一条裂变道 {#ex-fission}
${}^{235}\mathrm{U}$ 吸收一个慢中子之后的裂变方式有很多，其中一种是

$$
n + {}^{235}\mathrm{U} \to {}^{141}\mathrm{Ba} + {}^{92}\mathrm{Kr} + 3n .
$$

用原子质量 ${}^{235}\mathrm{U}$ $235.043930$、${}^{141}\mathrm{Ba}$ $140.914403$、${}^{92}\mathrm{Kr}$ $91.926173$ 与 $m_n = 1.008665\,\mathrm{u}$，求 $Q$。把它与两碎片作为相切球时的库仑能作比较。
::: solution
初始质量为 $235.043930 + 1.008665 = 236.052595\,\mathrm{u}$；末态质量为 $140.914403 + 91.926173 + 3(1.008665) = 235.866571\,\mathrm{u}$。于是

$$
Q = 0.186024 \times 931.494 = 173.3\,\mathrm{MeV}.
$$

电子配平：两边各 $92$ 个。若碎片作为 $R_0 = 1.2\,\mathrm{fm}$ 的相切球出发，两球心相距 $1.2(141^{1/3} + 92^{1/3}) = 1.2(5.205 + 4.514) = 11.66\,\mathrm{fm}$，库仑能为

$$
V_C = \frac{56 \times 36 \times 1.440}{11.66}\,\mathrm{MeV} = 249\,\mathrm{MeV}.
$$

这比可用的能量还多，所以碎片实际上不可能作为相切球出发：断裂（scission）时它们是拉长的、分得更开。但这一比较指出了能量的去向。碎片被彼此的斥力推开，释放的能量大部分成为它们的动能，约 $170\,\mathrm{MeV}$。碎片还远离稳定谷（${}^{141}\mathrm{Ba}$ 的 $N/Z = 1.52$，而稳定钡同位素至多 $1.46$），所以它们随后 β 衰变，在几秒到几年里再释放一些能量。
:::
:::

${}^{235}\mathrm{U}$ 的热中子裂变在所有反应道上的平均总释放约 $200\,\mathrm{MeV}$，大致分配如下：约 $170\,\mathrm{MeV}$ 为碎片动能，$5\,\mathrm{MeV}$ 由平均 $2.4$ 个瞬发中子带走，$7\,\mathrm{MeV}$ 为瞬发 γ 射线；碎片其后的 β 衰变再给出约 $8\,\mathrm{MeV}$ 电子能量、$7\,\mathrm{MeV}$ γ 射线与 $10\,\mathrm{MeV}$ 反中微子（后者逃逸）。一千克 ${}^{235}\mathrm{U}$ 含 $2.56\times10^{24}$ 个核，完全裂变将释放

$$
2.56\times10^{24} \times 200\,\mathrm{MeV} \times 1.602\times10^{-13}\,\mathrm{J/MeV} = 8.2\times10^{13}\,\mathrm{J},
$$

约为一千克煤化学能（$\approx 3\times10^7\,\mathrm{J}$）的三百万倍。这个倍数体现了 [[particles/nuclear-structure]] 中 MeV 与 eV 两个能量尺度的比值。

### 裂变势垒

重核分裂明明有如此大的收获，${}^{238}\mathrm{U}$ 为什么还能存活几十亿年？和 α 衰变一样，因为有一道势垒拦路。球形液滴形变时，表面积增大要付出能量，质子彼此远离则释放库仑能。小形变下表面项获胜。

::: proposition 液滴对裂变的稳定性 {#prop-fissility}
把一体积固定、均匀带电的液滴形变为半轴 $R(1 + \varepsilon)$ 与 $R(1 + \varepsilon)^{-1/2}$ 的旋转椭球。到 $\varepsilon$ 的二阶，表面能与库仑能变为

$$
E_S = E_S^{(0)}\left(1 + \tfrac25\varepsilon^2\right), \qquad E_C = E_C^{(0)}\left(1 - \tfrac15\varepsilon^2\right).
$$

于是球对小板形变的稳定当且仅当 $E_C^{(0)} < 2E_S^{(0)}$，用质量公式的项写出即

$$
\frac{Z^2}{A} < \frac{2a_S}{a_C} \approx 47 .
$$ {#eq-fissility}
:::

::: proof
这两个展开是椭球几何的标准结果，由玻尔与惠勒（Wheeler，1939）导出；计算可看克拉尼 §13.2。承认它们之后，能量变化为

$$
\Delta E = \frac{\varepsilon^2}{5}\left(2E_S^{(0)} - E_C^{(0)}\right),
$$

它为正——即球恰在能量极小处——当且仅当 $2E_S^{(0)} > E_C^{(0)}$。代入 $E_S^{(0)} = a_SA^{2/3}$ 与 $E_C^{(0)} \approx a_CZ^2A^{-1/3}$，条件 $a_CZ^2A^{-1/3} < 2a_SA^{2/3}$ 即 $Z^2/A < 2a_S/a_C = 2 \times 16.8/0.72 = 46.7$。
:::

对 ${}^{238}\mathrm{U}$，$Z^2/A = 35.6$，远低于 47。核坐在一个浅极小里，一道约 $6\,\mathrm{MeV}$ 的势垒把它与断裂组态隔开。自发裂变只能靠穿过这道势垒的隧穿，而且极为罕见：${}^{238}\mathrm{U}$ 的自发裂变分支约占衰变的 $5\times10^{-7}$。$Z^2/A$ 越大势垒越矮，这是最重的元素寿命如此之短的原因之一。

感生裂变的办法是把复合核抬到势垒之上。${}^{235}\mathrm{U}$ 吸收一个动能可忽略的中子时，生成的复合核 ${}^{236}\mathrm{U}$ 的激发能等于 ${}^{236}\mathrm{U}$ 的中子分离能 $6.55\,\mathrm{MeV}$，高于其约 $6\,\mathrm{MeV}$ 的裂变势垒，于是轻易分裂。${}^{238}\mathrm{U}$ 吸收一个慢中子时，生成的 ${}^{239}\mathrm{U}$ 只有 $4.81\,\mathrm{MeV}$，低于势垒，通常只放出一个 γ 射线。这 $1.7\,\mathrm{MeV}$ 之差来自质量公式的对偶项：${}^{236}\mathrm{U}$ 是偶–偶核，最后一个中子束缚得格外紧；${}^{239}\mathrm{U}$ 是偶–奇核，没有这份加强。${}^{233}\mathrm{U}$、${}^{235}\mathrm{U}$、${}^{239}\mathrm{Pu}$ 这类能被慢中子裂变的核素称为**易裂变**（fissile）核素。

::: remark 链式反应
每次裂变平均放出两个以上中子，所以一次裂变能引发更多裂变。核反应堆维持一条稳定的链：平均而言，每次裂变恰有一个中子再造成一次裂变；时间尺度由一小部分（${}^{235}\mathrm{U}$ 约 $0.65\%$）由裂变碎片延迟数秒放出的中子控制。第一条这样的自持链式反应由费米的小组于 1942 年 12 月 2 日在芝加哥实现。反应堆的工程属于核工程课程，超出本章范围。
:::

## 聚变 {#fusion}

在结合能曲线的另一端，把轻核接起来是沿陡坡上行，释放能量。对实验室最重要的反应是

$$
{}^2\mathrm{H} + {}^3\mathrm{H} \to {}^4\mathrm{He} + n, \qquad Q = 17.59\,\mathrm{MeV},
$$

它在可达能量下的截面是轻核反应中最大的，在约 $64\,\mathrm{keV}$ 的质心能量处达到峰，约 $5\,\mathrm{b}$。问题在于库仑势垒：按 [[#eq-barrier]]，$d + t$ 约为 $0.4\,\mathrm{MeV}$。只有核热得让热分布的高能尾巴能以有用的速率穿过这道势垒，聚变才发生。

### 伽莫夫峰

温度为 $T$ 的气体中，相对能量在 $E$ 附近的粒子对占比正比于 $e^{-E/kT}$，随 $E$ 下降；而隧穿概率 $e^{-2G}$ 随 $E$ 陡升。对远低于势垒的能量，[[particles/decay]] 中伽莫夫因子的厚势垒形式给出 $2G \approx \sqrt{E_G/E}$，其中的**伽莫夫能**（Gamow energy）为

$$
E_G = 2\mu c^2\left(\pi\alpha Z_1Z_2\right)^2 .
$$ {#eq-gamow-energy}

反应速率正比于乘积 $e^{-E/kT}e^{-\sqrt{E_G/E}}$（再乘一个缓变因子）的积分，而这个乘积是尖锐成峰的。

::: proposition 伽莫夫峰 {#prop-gamow-peak}
函数 $f(E) = \exp\bigl(-E/kT - \sqrt{E_G/E}\bigr)$ 只有一个极大，位于

$$
E_0 = \left(\frac{E_G (kT)^2}{4}\right)^{1/3},
$$ {#eq-gamow-peak}

该处的函数值为 $e^{-3E_0/kT}$。
:::

::: proof
对指数 $g(E) = -E/kT - E_G^{1/2}E^{-1/2}$ 求极大。其导数 $g'(E) = -1/kT + \tfrac12 E_G^{1/2}E^{-3/2}$ 在小 $E$ 时为正、大 $E$ 时为负，且全程单调下降，所以只有一个零点，那里 $E^{3/2} = \tfrac12 E_G^{1/2}kT$；平方即得 $E_0^3 = E_G(kT)^2/4$。在该点，由 $E_0^{3/2} = \tfrac12 E_G^{1/2}kT$ 得 $\sqrt{E_G/E_0} = 2E_0/kT$，所以 $g(E_0) = -E_0/kT - 2E_0/kT = -3E_0/kT$。
:::

:::

::: quiz
把等离子体的温度加倍，伽莫夫峰的能量 $E_0$ 如何变化？峰高又发生了什么？
- [ ] $E_0$ 加倍，峰高不变。
- [x] $E_0$ 增大为 $2^{2/3} \approx 1.59$ 倍，峰高 $e^{-3E_0/kT}$ 陡升，因为 $E_0/kT$ 缩小为 $2^{-1/3}$。
- [ ] $E_0$ 由库仑势垒决定，不变。
- [ ] $E_0$ 下降，因为粒子越快隧穿越少。
::: solution
由 [[#eq-gamow-peak]]，$E_0 \propto T^{2/3}$，$T$ 加倍使它乘 $2^{2/3} = 1.587$。比值 $E_0/kT \propto T^{-1/3}$ 缩小为 $2^{-1/3} = 0.794$；对太阳中的 pp 反应，$3E_0/kT$ 约为 13.5，所以峰高 $e^{-3E_0/kT}$ 增大约 $e^{2.8} \approx 16$ 倍。这正是恒星核心恒温性能好的原因：轻微加热使反应速率大增，核心便膨胀冷却。
:::
:::

### 太阳的能量收支

汉斯·贝特（Hans Bethe）1939 年说明了太阳如何把氢变成氦。在太阳质量的恒星里，主要路线是**质子–质子链**（proton–proton chain），其主支（pp I）为

$$
\begin{aligned}
p + p &\to {}^2\mathrm{H} + e^+ + \nu_e \quad (\text{两次}), \\
{}^2\mathrm{H} + p &\to {}^3\mathrm{He} + \gamma \quad (\text{两次}), \\
{}^3\mathrm{He} + {}^3\mathrm{He} &\to {}^4\mathrm{He} + 2p .
\end{aligned}
$$

净效果是 $4p + 2e^- \to {}^4\mathrm{He} + 2\nu_e$，两个正电子已与电子湮灭。用原子质量写就是 $4\,m({}^1\mathrm{H}) \to m({}^4\mathrm{He})$，于是

$$
Q = \bigl[4(1.007825) - 4.002603\bigr](931.494)\,\mathrm{MeV} = 26.73\,\mathrm{MeV}.
$$

这一支的两个中微子平均带走约 $0.53\,\mathrm{MeV}$，所以约 $26.2\,\mathrm{MeV}$ 给太阳加热。第一步把质子变成中子，因此是弱相互作用。它的截面小到太阳中心的一个质子平均要等上 $10^{10}$ 年才轮得上参加一次；正是这份缓慢，太阳才活得如此之久。在质量更大的恒星里，**CNO 循环**占主导，碳、氮、氧充当催化剂；贝特在同一篇 1939 年的论文里提出了它。

::: example 太阳的中微子 {#ex-sun}
太阳的辐射功率为 $L_\odot = 3.828\times10^{26}\,\mathrm{W}$（IAU 名义值）。假定它全部来自 pp 链、每个氦核沉积 $26.2\,\mathrm{MeV}$，求每秒生成的氦核数、氢的消耗速率，以及距太阳 $1.496\times10^{11}\,\mathrm{m}$ 处地球处的太阳中微子通量。
::: solution
每次转化沉积 $26.2 \times 1.602\times10^{-13} = 4.20\times10^{-12}\,\mathrm{J}$，所以速率为

$$
\dot N_\mathrm{He} = \frac{3.828\times10^{26}}{4.20\times10^{-12}} = 9.1\times10^{37}\,\mathrm{s}^{-1}.
$$

每次用去四个氢原子，$4 \times 1.674\times10^{-27}\,\mathrm{kg}$，所以太阳每秒烧掉 $6.1\times10^{11}\,\mathrm{kg}$ 氢。每个氦核放出两个中微子，共 $1.82\times10^{38}\,\mathrm{s}^{-1}$，铺在半径 $1\,\mathrm{AU}$ 的球面上：

$$
\Phi_\nu = \frac{1.82\times10^{38}}{4\pi(1.496\times10^{11})^2}\,\mathrm{m^{-2}\,s^{-1}} = 6.5\times10^{14}\,\mathrm{m^{-2}\,s^{-1}}.
$$

每秒钟约有 $6.5\times10^{10}$ 个太阳中微子穿过地球的每平方厘米。雷蒙德·戴维斯（Raymond Davis）的氯实验从 1960 年代后期开始，只测到侧支高能中微子预期通量的三分之一左右；"太阳中微子问题"最终由中微子振荡（[[particles/standard-model]]）解决，并经萨德伯里中微子观测台在 2001–02 年证实。
:::
:::

燃料够用吗？太阳质量约 $10\%$——核心的氢——在主序阶段被烧掉，而烧掉的质量有 $0.7\%$ 转化为能量。于是寿命为

$$
t \approx \frac{0.1 \times 0.007 \times M_\odot c^2}{L_\odot} = \frac{0.1 \times 0.007 \times 1.99\times10^{30} \times 9.0\times10^{16}}{3.83\times10^{26}}\,\mathrm{s} \approx 3\times10^{17}\,\mathrm{s} \approx 10^{10}\,\mathrm{yr},
$$

与太阳现在 $4.6\times10^9\,\mathrm{yr}$ 的年龄相符，而且远远超过单靠引力收缩所能供应的 $3\times10^7\,\mathrm{yr}$。太阳与其他恒星的结构见 [[gravitation/stars]]。

### 受控聚变与劳森判据

在地球上，恒星核心那样的压强是不可得的，所以聚变等离子体必须热得多，$kT \approx 10$ 到 $20\,\mathrm{keV}$（超过 $10^8\,\mathrm{K}$），还必须被约束住——靠磁场，在托卡马克里；或者靠自身惯性，在激光内爆的靶丸里。等离子体以特征性的**能量约束时间**（energy confinement time）$\tau_E$ 损失能量。约翰·劳森（John Lawson）1955 年证明（1957 年发表）：要获得净能量增益，离子密度 $n$ 与 $\tau_E$ 的乘积必须超过一个依赖温度的阈值。对 D–T 等离子体点火——其中全靠 α 粒子维持等离子体的高温——现代的"三乘积"形式为

$$
n\,T\,\tau_E \gtrsim 3\times10^{21}\,\mathrm{keV\,s\,m^{-3}},
$$ {#eq-lawson}

最优处在 $kT \approx 15\,\mathrm{keV}$ 附近。那一温度下 $n\tau_E \gtrsim 2\times10^{20}\,\mathrm{s\,m^{-3}}$。托卡马克以 $n \approx 10^{20}\,\mathrm{m^{-3}}$、维持几秒达到它；惯性约束靶丸以 $n \approx 10^{31}\,\mathrm{m^{-3}}$，但维持时间远不到一纳秒。2022 年 12 月 5 日，加利福尼亚州的国家点火装置（National Ignition Facility）在一次实验中由打到靶上的 $2.05\,\mathrm{MJ}$ 激光产生 $3.15\,\mathrm{MJ}$ 聚变能，是第一个释放能量超过吸收能量的实验室聚变实验，尽管这仍远少于激光器消耗的电能。

::: warning Q 值不等于你能用的能量
D–T 聚变的 $17.59\,\mathrm{MeV}$ 由动量守恒按质量反比分配给 α 粒子（$3.5\,\mathrm{MeV}$）与中子（$14.1\,\mathrm{MeV}$）。只有 α 粒子能加热磁约束等离子体；中子会逃逸。类似地，每次裂变的 $200\,\mathrm{MeV}$ 里约 $10\,\mathrm{MeV}$ 随反中微子离开，太阳每个氦核的 $26.7\,\mathrm{MeV}$ 中有 $0.5\,\mathrm{MeV}$ 随中微子离开。引用能量产出之前，先问每个产物把能量沉积在哪里。
:::

::: history 从嬗变到裂变与聚变
卢瑟福 1919 年报告了氮的嬗变；帕特里克·布莱克特（Patrick Blackett）1925 年在云室里拍到了这条反应，显示 α 粒子被吸收。约翰·科克罗夫特（John Cockcroft）与欧内斯特·沃尔顿（Ernest Walton）1932 年用加速质子分裂锂，这是第一条由人工加速粒子引起的反应，也是 $E = mc^2$ 的一次早期检验。查德威克的中子（1932 年）给物理学家一个不带电的入射粒子，费米的罗马小组（1934 年）表明慢中子特别有效。哈恩与施特拉斯曼 1938 年 12 月从铀中认出钡，迈特纳与弗里施 1939 年初把它解释为裂变；玻尔与约翰·惠勒（John Wheeler）同年发表了裂变的液滴理论。爱丁顿（Arthur Eddington）早在 1920 年就论证太阳的能量可能来自把氢变成氦；贝特在 1938–39 年与查尔斯·克里奇菲尔德（Charles Critchfield）合作算出了质子–质子链，并提出 CNO 循环。
:::

## 后续内容 {#leads}

产生入射粒子、探测反应产物的仪器是 [[particles/accelerators]] 的主题，阈能公式 [[#eq-threshold]] 在那里以固定靶机器与对撞机之比较的面目重现。截面、共振与宽度是粒子物理的基本语言：$Z$ 玻色子的布莱特–维格纳线型在那里量出中微子的种类数（[[particles/standard-model]]）。氦以外的恒星核合成与恒星的终局见 [[gravitation/stars]]。化学图谱的课程[核化学](/learn/chemistry/lesson.php?c=general-chemistry-2&l=nuclear-chemistry)从化学家的角度讲核方程与应用。

::: summary
- $X(a,b)Y$ 的 Q 值为 $[m_a + m_X - m_Y - m_b]c^2$，用原子质量计算。吸能反应有阈能 $K_\mathrm{th} = (M_f^2 - (m_a + m_X)^2)c^2/2m_X \approx -Q(1 + m_a/m_X)$。
- 截面 $\sigma$ 是每个入射粒子打在每个单位面积靶核上的反应数。$1\,\mathrm{b} = 10^{-28}\,\mathrm{m}^2$。束流按 $e^{-n\sigma x}$ 衰减。
- 带电粒子面对库仑势垒 $Z_1Z_2e^2/4\pi\varepsilon_0(R_1 + R_2)$；势垒以下只能靠隧穿反应。中子没有势垒，慢中子俘获遵循 $\sigma \propto 1/v$。
- 复合核共振呈布莱特–维格纳线型，全宽度 $\Gamma = \hbar/\tau$。
- ${}^{235}\mathrm{U}$ 裂变释放约 $200\,\mathrm{MeV}$，大部分是碎片动能。液滴对小板形变稳定当 $Z^2/A < 2a_S/a_C \approx 47$；${}^{235}\mathrm{U}$ 能被慢中子裂变，是因为复合核生成时就在其势垒之上。
- 等离子体中的聚变速率由伽莫夫峰 $E_0 = (E_G(kT)^2/4)^{1/3}$ 决定，它是 $kT$ 的几倍。
- pp 链把 $4p$ 变成 ${}^4\mathrm{He}$，$Q = 26.73\,\mathrm{MeV}$；太阳辐射功率要求每秒 $9\times10^{37}$ 次转化，并向地球送来每平方米每秒 $6.5\times10^{14}$ 个中微子。
- 受控 D–T 聚变需要 $kT \approx 10$–$20\,\mathrm{keV}$，点火则需 $nT\tau_E \gtrsim 3\times10^{21}\,\mathrm{keV\,s\,m^{-3}}$（劳森判据）。
:::

## 习题 {#exercises}

::: exercise 氘–氚反应 {level=1 check="17.59"}
用原子质量 ${}^2\mathrm{H}$ $2.0141018$、${}^3\mathrm{H}$ $3.0160493$、${}^4\mathrm{He}$ $4.0026033$ 与 $m_n = 1.0086649\,\mathrm{u}$，求 ${}^2\mathrm{H} + {}^3\mathrm{H} \to {}^4\mathrm{He} + n$ 的 $Q$，以 MeV 计。
::: solution
$Q = (2.0141018 + 3.0160493 - 4.0026033 - 1.0086649)(931.494) = 0.0188829 \times 931.494 = 17.59\,\mathrm{MeV}$。电子配平：两边各两个，中子不带电子，氦有两个。
:::
:::

::: exercise α 粒子打金 {level=1 check="25.6"}
取 $R_0 = 1.2\,\mathrm{fm}$，按 [[#eq-barrier]] 求 α 粒子与 ${}^{197}\mathrm{Au}$ 核的库仑势垒，以 MeV 计。
::: solution
$R_1 + R_2 = 1.2(4^{1/3} + 197^{1/3}) = 1.2(1.587 + 5.819) = 8.887\,\mathrm{fm}$，且 $V_C = 2 \times 79 \times 1.440/8.887 = 25.6\,\mathrm{MeV}$。天然放射源的 α 粒子只有 $4$ 到 $9\,\mathrm{MeV}$，永远到不了能感受到金核强力的距离，这就是盖革与马斯登看到纯粹卢瑟福散射的原因。
:::
:::

::: exercise 太阳的质量损失 {level=1 check="4.26e9"}
太阳以辐射损失 $L_\odot = 3.828\times10^{26}\,\mathrm{W}$，它以多大速率损失静质量，以千克每秒计？（忽略中微子与太阳风。）
::: solution
$\dot m = L_\odot/c^2 = 3.828\times10^{26}/(2.998\times10^8)^2 = 4.26\times10^9\,\mathrm{kg/s}$，约每秒四百万吨。$4.6\times10^9\,\mathrm{yr}$ 下来是 $6\times10^{26}\,\mathrm{kg}$，占太阳质量的 $0.03\%$。
:::
:::

::: exercise 束流打薄靶 {level=2 check="0.30"}
$1.00\,\mu\mathrm{A}$ 的质子束打在一个面密度为 $2.0\times10^{22}$ 个靶核每平方米的薄靶上。某一条反应道的产物之一被全部探测到，计数率为 $3.74\times10^{6}$ 每秒。求截面，以靶恩计。
::: solution
束流每秒打出 $\dot N_a = 1.00\times10^{-6}\,\mathrm{C/s}/1.602\times10^{-19}\,\mathrm{C} = 6.24\times10^{12}$ 个质子。由 [[#eq-sigma]]，

$$
\sigma = \frac{3.74\times10^{6}}{6.24\times10^{12} \times 2.0\times10^{22}}\,\mathrm{m}^2 = 3.0\times10^{-29}\,\mathrm{m}^2 = 0.30\,\mathrm{b}.
$$

靶在要求的意义上是薄的：$n_t\sigma = 2.0\times10^{22} \times 3.0\times10^{-29} = 6\times10^{-7}$，所以约每两百万个质子才有一个反应，各核互不遮蔽。
:::
:::

::: exercise 光生 π 介子的阈能 {level=2 check="144.7"}
求静止质子上 $\gamma + p \to p + \pi^0$ 的最小光子能量，以 MeV 计，取 $m_pc^2 = 938.272\,\mathrm{MeV}$ 与 $m_{\pi^0}c^2 = 134.977\,\mathrm{MeV}$（PDG 2024）。
::: solution
把 [[#thm-threshold]] 用于 $m_a = 0$、$m_X = m_p$、$M_f = m_p + m_\pi$：

$$
E_\mathrm{th} = \frac{(m_p + m_\pi)^2 - m_p^2}{2m_p}c^2 = \frac{m_\pi(m_\pi + 2m_p)}{2m_p}c^2 = \frac{134.977 \times 2011.521}{1876.544}\,\mathrm{MeV} = 144.7\,\mathrm{MeV}.
$$

这比 π 介子的静能多出 $10\,\mathrm{MeV}$，正是阈能处质心的动能。非相对论近似 $-Q(1 + m_a/m_X) = m_\pi c^2 = 135.0\,\mathrm{MeV}$ 失效，因为 $\lvert Q\rvert/m_Xc^2 = 0.14$ 不算小量。
:::

::: exercise 太阳中微子 {level=2 check="6.4e14"}
重做 [[#ex-sun]] 的中微子通量计算，但假定每个氦核的全部 $Q = 26.73\,\mathrm{MeV}$ 都沉积在太阳内。地球处的通量是多少，以 $\mathrm{m^{-2}\,s^{-1}}$ 计、保留两位有效数字？答案为什么几乎不变？
::: solution
$\dot N_\mathrm{He} = 3.828\times10^{26}/(26.73 \times 1.602\times10^{-13}) = 8.94\times10^{37}\,\mathrm{s}^{-1}$，给出每秒 $1.79\times10^{38}$ 个中微子，通量为

$$
\Phi_\nu = \frac{1.79\times10^{38}}{4\pi(1.496\times10^{11})^2}\,\mathrm{m^{-2}\,s^{-1}} = 6.4\times10^{14}\,\mathrm{m^{-2}\,s^{-1}},
$$

与 [[#ex-sun]] 的 $6.5\times10^{14}$ 相比几乎没变。中微子只带走 $2\%$ 的能量，所以这一假定只使答案改变 $2\%$。通量由辐射功率除以每次转化的能量决定，而链的每一支都是每个氦核两个中微子，对细节并不敏感。
:::

::: exercise 液滴的裂变参数 {level=3}
从 [[#prop-fissility]] 中的两个展开出发，证明形变液滴的能量为 $E(\varepsilon) = E(0) + \tfrac15\varepsilon^2(2E_S^{(0)} - E_C^{(0)})$。然后用克拉尼的系数、库仑能用 $Z(Z-1)$，对 ${}^{238}\mathrm{U}$ 与假想核 $Z = 114$、$A = 298$ 计算 $x = E_C^{(0)}/2E_S^{(0)}$（**裂变参数**，fissility parameter）。讨论 $x \to 1$ 时发生什么。
::: hint
$E_S^{(0)} = a_SA^{2/3}$、$E_C^{(0)} = a_CZ(Z-1)A^{-1/3}$，所以 $x = a_CZ(Z-1)/(2a_SA)$。
:::
::: solution
把两个展开相加，

$$
E_S + E_C = E_S^{(0)} + E_C^{(0)} + \frac{2}{5}\varepsilon^2 E_S^{(0)} - \frac{1}{5}\varepsilon^2E_C^{(0)} = E(0) + \frac{\varepsilon^2}{5}\left(2E_S^{(0)} - E_C^{(0)}\right),
$$

因为质量公式的其余各项在体积固定时都与形状无关。曲率为正当且仅当 $x < 1$。

对 ${}^{238}\mathrm{U}$：$x = 0.72 \times 92 \times 91/(2 \times 16.8 \times 238) = 6027.8/7996.8 = 0.754$。对 $Z = 114$、$A = 298$：$x = 0.72 \times 114 \times 113/(2 \times 16.8 \times 298) = 9275.0/10012.8 = 0.926$。

$x \to 1$ 时回复曲率消失，液滴的裂变势垒缩到零；$x > 1$ 之后液滴不稳定，会瞬间裂变。$Z = 114$ 附近的超重核之所以存在（半衰期以秒计），全凭壳层效应（液滴模型里没有）添上了几 MeV 的势垒。
:::

::: exercise 太阳中的伽莫夫峰 {level=3}
(a) 对 $p + p$ 反应，用 $\mu = m_p/2$ 计算 [[#eq-gamow-energy]]，证明 $E_G = 493\,\mathrm{keV}$。(b) 在太阳中心温度 $1.57\times10^7\,\mathrm{K}$ 下求 $kT$ 与 $E_0$。(c) 证明峰的近似高斯形在 $1/e$ 处的全宽度为 $\Delta = 4\sqrt{E_0kT/3}$，并求其值。
::: hint
对 (c)，把 [[#prop-gamow-peak]] 的指数 $g(E)$ 在 $E_0$ 附近展开到二阶，证明 $g''(E_0) = -3/(2E_0kT)$。
:::
::: solution
(a) 取 $\mu c^2 = 938.272/2 = 469.136\,\mathrm{MeV}$、$Z_1 = Z_2 = 1$，$E_G = 2 \times 469.136 \times (\pi/137.036)^2\,\mathrm{MeV} = 938.272 \times 5.2557\times10^{-4}\,\mathrm{MeV} = 0.4931\,\mathrm{MeV} = 493\,\mathrm{keV}$。

(b) $kT = 8.617\times10^{-5}\,\mathrm{eV/K} \times 1.57\times10^7\,\mathrm{K} = 1.353\,\mathrm{keV}$。于是 $E_0 = (493.1 \times 1.353^2/4)^{1/3}\,\mathrm{keV} = (225.7)^{1/3}\,\mathrm{keV} = 6.09\,\mathrm{keV}$。

(c) $g'(E) = -1/kT + \tfrac12E_G^{1/2}E^{-3/2}$，所以 $g''(E) = -\tfrac34E_G^{1/2}E^{-5/2}$。在 $E_0$ 处，$E_G^{1/2} = 2E_0^{3/2}/kT$，于是 $g''(E_0) = -\tfrac34 \cdot 2E_0^{3/2}E_0^{-5/2}/kT = -3/(2E_0kT)$。这样 $f \approx f(E_0)\exp[-\tfrac{3}{4E_0kT}(E - E_0)^2]$，它在 $\lvert E - E_0\rvert = \sqrt{4E_0kT/3}$ 处降到峰的 $1/e$，全宽度 $\Delta = 2\sqrt{4E_0kT/3} = 4\sqrt{E_0kT/3}$。数值上 $\Delta = 4\sqrt{6.09 \times 1.353/3} = 4 \times 1.657 = 6.6\,\mathrm{keV}$。太阳核心的反应发生在约 $3$ 到 $10\,\mathrm{keV}$ 的能量窗口里，全都远低于势垒。
:::
