我们对核与粒子的一切认识，都来自两类仪器：一类是机器，它给粒子足够的能量，去探测或创造我们想要研究的对象；另一类是探测器，它把一个看不见粒子的通过变成能够记录的信号。两者都不是黑箱。回旋加速器之所以能工作，是因为带电粒子在磁场中的周期与它的速率无关——直到相对论改变了这一点。对撞机之所以胜过固定靶机器，靠的是狭义相对论的一个不变量。硅探测器能测量能量，是因为产生一个电子–空穴对只需 $3.6\,\mathrm{eV}$；径迹室能测量动量，是因为带电粒子在磁场中沿螺旋线运动，其半径为 $p/qB$。

本章把这些原理一一道来。我们先从为什么需要高能量讲起，然后把加速器从静电机器一路搭建到同步加速器与对撞机，其中的两个品质因数是质心能量与亮度。后半部分转向辐射与物质的相互作用——每一台探测器利用的正是它——并以一台现代对撞机探测器如何鉴别从碰撞中出来的粒子作结。

你需要 [[relativity/velocity-energy]] 与 [[relativity/four-vectors]] 中的相对论运动学、[[magnetism/magnetic-force]] 中电荷在磁场里的运动，以及 [[electrodynamics/radiation]] 中加速电荷的辐射。[[particles/reactions]] 的阈能公式贯穿全章。本章中，把动量以 $\mathrm{GeV}/c$、质量以 $\mathrm{GeV}/c^2$ 来度量比较方便；这样一来，单位电荷的粒子在磁场 $B$ 中，曲率半径 $\rho$ 就满足

$$
p\,[\mathrm{GeV}/c] = 0.2998\,B\,[\mathrm{T}]\,\rho\,[\mathrm{m}].
$$ {#eq-rigidity}

这就是 $p = eB\rho$，其中 $e\,c = 0.2998\,\mathrm{GeV\,T^{-1}\,m^{-1}}$；乘积 $B\rho$ 称为**磁刚度**。

## 为什么需要高能量 {#why}

加速粒子有两个理由，它们恰好对应本课程的上下两半。

第一个理由是**分辨本领**。动量为 $p$ 的探针，能分辨小至其约化德布罗意波长 $\hbar/p$ 的结构。由 $\hbar c = 0.1973\,\mathrm{GeV\,fm}$，$1\,\mathrm{GeV}$ 的探针能分辨 $0.2\,\mathrm{fm}$，即质子半径的五分之一；1968 年 SLAC 的电子–质子实验正是在这一尺度上看见了质子内部的类点组分。$1\,\mathrm{TeV}$ 的探针能分辨 $2\times10^{-4}\,\mathrm{fm}$。

第二个理由是**产生**。要造出一个质量为 $M$ 的粒子，碰撞必须在质心系中至少提供 $Mc^2$，再加上守恒定律所要求的一切。$W$ 与 $Z$ 玻色子（$80$ 与 $91\,\mathrm{GeV}/c^2$）、顶夸克（$173\,\mathrm{GeV}/c^2$）与希格斯玻色子（$125\,\mathrm{GeV}/c^2$），每一个都在等一台能够达到所需能量的机器，而且要有足够多的碰撞，把它们产生到可测量的数目。

可用于产生的能量不是束流能量，而是碰撞体系的**不变质量** $\sqrt{s}$，其中

$$
s\,c^4 = \Bigl(\sum E\Bigr)^2 - \Bigl\lvert\sum \mathbf{p}\Bigr\rvert^2 c^2 ,
$$

也就是质心系总能量之平方。对不同类型的机器，我们要计算的正是这个量。

## 加速电荷 {#accelerating}

只有电场能改变粒子的能量；磁场力垂直于速度，不做功。各类加速器的区别在于如何施加电场，以及是否用磁铁把粒子送回来再过一遍。

**静电加速器**只施加一个高电压。约翰·科克罗夫特（John Cockcroft）与欧内斯特·沃尔顿（Ernest Walton）造了一台 $700\,\mathrm{kV}$ 的电压倍增器，并在 1932 年用它以质子分裂了锂。罗伯特·范德格拉夫（Robert Van de Graaff）的皮带起电机（1931 年起）在加压舱中能达到约 $25\,\mathrm{MV}$；其极限是电气击穿。电荷为 $q$ 的粒子落下电势差 $V$ 获得 $qV$，所以 $1\,\mathrm{MV}$ 给质子 $1\,\mathrm{MeV}$。

**直线加速器**靠把一个交变场反复使用多次来避开击穿极限。在罗尔夫·维德罗（Rolf Widerøe）1928 年的设计中，粒子穿过一列漂移管，它们交替接到射频电源的两端；管中粒子被屏蔽，而它每次穿过间隙时，那里的电场恰好指向正确的方向。现代直线加速器使用射频腔的行波或驻波。斯坦福直线加速器长 $3.2\,\mathrm{km}$，从 1966 年起把电子加速到 $20\,\mathrm{GeV}$，后来又达到 $50\,\mathrm{GeV}$。直线加速器没有弯曲磁铁，这对电子很重要，我们马上就会看到。

### 回旋加速器

欧内斯特·劳伦斯（Ernest Lawrence）1929–30 年的想法，是用磁场把粒子弯回来，让一个不大的射频电压能够反复使用。

::: theorem 回旋频率 {#thm-cyclotron}
电荷为 $q$、质量为 $m$、速率 $v \ll c$ 的粒子垂直于均匀磁场 $B$ 运动时，沿半径为 $r = mv/qB$ 的圆周运动，角频率为

$$
\omega_c = \frac{qB}{m},
$$ {#eq-cyclotron}

与其速率和半径无关。相对论性地，半径为 $r = p/qB$，角频率为 $\omega = qB/\gamma m$。
:::

::: proof
磁力 $q\mathbf{v}\times\mathbf{B}$ 垂直于 $\mathbf{v}$，所以不做功，速率恒定。当 $\mathbf{v} \perp \mathbf{B}$ 时，其大小 $qvB$ 恒定且总与速度垂直，这正是向心加速度为 $v^2/r$ 的匀速圆周运动。牛顿第二定律给出 $qvB = mv^2/r$，于是 $r = mv/qB$，且 $\omega = v/r = qB/m$。

相对论地，$\deriv{\mathbf{p}}{t} = q\mathbf{v}\times\mathbf{B}$，其中 $\mathbf{p} = \gamma m\mathbf{v}$。力仍然不做功，故 $\gamma$ 恒定，且 $\gamma m\,\deriv{\mathbf{v}}{t} = q\mathbf{v}\times\mathbf{B}$。这正是把 $m$ 换成 $\gamma m$ 的非相对论方程，于是 $r = \gamma mv/qB = p/qB$，$\omega = qB/\gamma m$。
:::

在回旋加速器中，两个中空的 D 形电极（"dees"）放在磁铁的两极之间，间隙上加频率为 $\omega_c/2\pi$ 的射频电压。粒子每转一圈过间隙两次，每次都被加速；它的半径随速率增大，但周期不变，于是始终与射频同步。它一路向外螺旋，在边缘半径 $R$ 处引出，此时

$$
K_\mathrm{max} = \frac{p_\mathrm{max}^2}{2m} = \frac{(qBR)^2}{2m}.
$$ {#eq-cyclotron-k}

劳伦斯与 M. 斯坦利·利文斯顿（M. Stanley Livingston）1931 年的回旋加速器直径 $11\,\mathrm{cm}$，给质子 $80\,\mathrm{keV}$；几年之内，回旋加速器就达到了 $10$ 到 $20\,\mathrm{MeV}$。

::: example 一台医用回旋加速器 {#ex-cyclotron}
一台生产医用放射性核素的回旋加速器在 $1.50\,\mathrm{T}$ 的磁场中把质子加速到 $10.0\,\mathrm{MeV}$。求射频频率与引出半径，并估算到末尾质子偏离同步有多远。
::: solution
由 [[#eq-cyclotron]]，$f = qB/2\pi m = (1.602\times10^{-19})(1.50)/(2\pi \times 1.673\times10^{-27})\,\mathrm{Hz} = 22.9\,\mathrm{MHz}$，这是一个射频。

末动量为 $pc = \sqrt{2mc^2K} = \sqrt{2 \times 938.27 \times 10.0}\,\mathrm{MeV} = 137.0\,\mathrm{MeV}$，即 $0.137\,\mathrm{GeV}/c$，所以由 [[#eq-rigidity]]

$$
R = \frac{0.1370}{0.2998 \times 1.50}\,\mathrm{m} = 0.305\,\mathrm{m}.
$$

（相对论动量 $pc = \sqrt{K^2 + 2Kmc^2}$ 为 $137.3\,\mathrm{MeV}$，它把 $R$ 改变 $0.3\%$。）在 $10\,\mathrm{MeV}$ 处，$\gamma = 1 + K/mc^2 = 1.0107$，所以由 [[#thm-cyclotron]] 的相对论形式，轨道频率已经下降了 $1.1\%$。在达到满能量所需的几百圈中，$1\%$ 的滑相会积累成很大的相位误差。这就是经典回旋加速器止步于质子约 $20\,\mathrm{MeV}$ 的原因，也是现代"等时性"回旋加速器把磁场按半径增长整形、使之正比于 $\gamma$ 的原因。
:::
:::

### 同步加速器

要远远越过回旋加速器的极限，就得让磁场与射频频率都跟着粒子的能量同步变化，并把粒子保持在固定的圆上。这就是**同步加速器**（synchrotron）。它的可能性建立在**相位稳定**（phase stability）之上，弗拉基米尔·韦克斯勒（Vladimir Veksler，1944）与埃德温·麦克米兰（Edwin McMillan，1945）各自独立发现了这一点：稍微晚到加速腔的粒子得到的推力略有不同，恰好把它拉回同步相位，于是束团中的粒子在被加速的同时围绕设计轨道稳定地振荡。恩斯特·库朗特（Ernest Courant）、M. 斯坦利·利文斯顿与哈特兰·斯奈德（Hartland Snyder）1952 年发明的四极磁铁强聚焦（交替梯度聚焦）使束流的横向尺寸保持很小，从而允许围绕大环使用小磁铁。

对固定的环，[[#eq-rigidity]] 说最大动量由弯曲磁场与半径决定。这就是高能质子机器又大、又用超导磁体的原因。

::: example 大型强子对撞机的环 {#ex-lhc-ring}
CERN 的大型强子对撞机（LHC）占有一条周长 $26.7\,\mathrm{km}$ 的隧道，其中的二极磁铁使束流沿半径 $\rho = 2804\,\mathrm{m}$ 的圆弧弯曲。它的超导二极磁铁按 $8.33\,\mathrm{T}$ 设计。求设计束流动量，以及第 3 轮运行所用 $6.8\,\mathrm{TeV}$ 束流所需的磁场。
::: solution
由 [[#eq-rigidity]]，$p = 0.2998 \times 8.33 \times 2804\,\mathrm{GeV}/c = 7.00\times10^3\,\mathrm{GeV}/c$，即设计的 $7\,\mathrm{TeV}$。对 $6.8\,\mathrm{TeV}$（此时 $pc \approx E$，因为 $\gamma = 6800/0.938 = 7250$），$B = 6800/(0.2998 \times 2804) = 8.09\,\mathrm{T}$。只有大约三分之二的周长排着弯曲磁铁（$2\pi \times 2804\,\mathrm{m} = 17.6\,\mathrm{km}$）；其余部分是放置射频腔、聚焦磁铁与实验装置的直线节。
:::
:::

### 同步辐射

沿圆周运动的电荷在加速，它要辐射。对电子而言，这为圆形机器的能量定了上限。

::: proposition 每圈能量损失 {#prop-synchrotron}
电荷为 $e$、能量为 $E = \gamma mc^2$（$\beta \approx 1$）的粒子沿半径 $\rho$ 的圆运动，每圈辐射的能量为

$$
U_0 = \frac{4\pi}{3}\,\frac{e^2}{4\pi\varepsilon_0}\,\frac{\gamma^4}{\rho} .
$$

对电子，这就是 $U_0\,[\mathrm{keV}] = 88.5\,E^4\,[\mathrm{GeV}^4]/\rho\,[\mathrm{m}]$。
:::

::: proof
[[electrodynamics/radiation]] 中加速度垂直于速度的相对论拉莫尔公式给出辐射功率 $P = \frac{2}{3}\frac{e^2}{4\pi\varepsilon_0}\frac{\gamma^4 a^2}{c^3}$，其中 $a = v^2/\rho \approx c^2/\rho$。于是 $P = \frac{2}{3}\frac{e^2}{4\pi\varepsilon_0}\frac{c\gamma^4}{\rho^2}$。一圈历时 $2\pi\rho/c$，所以 $U_0 = P\cdot 2\pi\rho/c = \frac{4\pi}{3}\frac{e^2}{4\pi\varepsilon_0}\frac{\gamma^4}{\rho}$。

对 $1\,\mathrm{GeV}$ 的电子，$\gamma = 1000/0.51100 = 1957.0$，$\gamma^4 = 1.467\times10^{13}$。取 $e^2/4\pi\varepsilon_0 = 1.440\times10^{-15}\,\mathrm{MeV\,m}$、$\rho = 1\,\mathrm{m}$，得 $U_0 = 4.189 \times 1.440\times10^{-15} \times 1.467\times10^{13}\,\mathrm{MeV} = 0.0885\,\mathrm{MeV}$。
:::

$\gamma^4$ 是决定性的。在同样能量下，质子的 $\gamma$ 小 $m_p/m_e = 1836$ 倍，辐射少 $1836^4 \approx 10^{13}$ 倍。大型电子–正电子对撞机（LEP）1989 到 2000 年间占用了 LHC 的隧道，每束达到 $104.5\,\mathrm{GeV}$；在弯曲半径约 $3.1\,\mathrm{km}$ 下，每个电子每圈损失

$$
U_0 \approx 88.5 \times 104.5^4/3100\,\mathrm{keV} = 3.4\times10^6\,\mathrm{keV} = 3.4\,\mathrm{GeV}
$$

超过其能量的 $3\%$，而全部都要由射频腔补回来。这就是正在设计的下一代电子–正电子对撞机要么是直线、要么是大得多的环的原因。同样的辐射集中在半角约 $1/\gamma$ 的前向细锥里发出，是强烈的 X 射线源，专门的同步辐射光源就是为产生它而建造的。

## 固定靶与对撞机 {#cm-energy}

::: theorem 质心能量 {#thm-sqrt-s}
质量为 $m_1$、能量为 $E_1$ 的束流粒子打在质量为 $m_2$ 的静止粒子上，

$$
s\,c^4 = m_1^2c^4 + m_2^2c^4 + 2E_1m_2c^2 .
$$ {#eq-s-fixed}

对能量为 $E_1$、$E_2$，动量为 $p_1$、$p_2$ 的两束迎头碰撞，

$$
s\,c^4 = (E_1 + E_2)^2 - (p_1 - p_2)^2c^2 \approx 4E_1E_2 \quad (E_i \gg m_ic^2).
$$ {#eq-s-collider}
:::

::: proof
对固定靶，总四维动量的能量为 $E_1 + m_2c^2$、动量为 $\mathbf{p}_1$，所以 $sc^4 = (E_1 + m_2c^2)^2 - p_1^2c^2 = (E_1^2 - p_1^2c^2) + 2E_1m_2c^2 + m_2^2c^4$，而 $E_1^2 - p_1^2c^2 = m_1^2c^4$。

对头对头的碰撞，动量方向相反，所以总动量的大小为 $\lvert p_1 - p_2\rvert$。展开得 $sc^4 = m_1^2c^4 + m_2^2c^4 + 2(E_1E_2 + p_1p_2c^2)$。对极端相对论粒子，$p_ic \approx E_i$，质量可以忽略，留下 $4E_1E_2$。
:::

后果是鲜明的。在高能下，固定靶机器给出 $\sqrt{s} \approx \sqrt{2E_1m_2c^2}$，只按束流能量的平方根增长，因为大部分能量拿去做质心运动了。对称对撞机给出 $\sqrt{s} = 2E$，全部可用。这正是维德罗与唐纳德·柯斯特（Donald Kerst）及其同事在 1950 年代主张对撞束流的理由。其代价是两束粒子远不如一块实体靶那样密集，所以碰撞稀少得多；下文的亮度就是这一代价的度量。

::: example 产生反质子，以及 LHC 改作固定靶需要什么 {#ex-sqrt-s}
(a) 伯克利的 Bevatron 的设计目标是用 $p + p \to p + p + p + \bar p$ 产生反质子，质子束打在氢靶上。求阈束流能量。(b) LHC 以 $\sqrt{s} = 13.6\,\mathrm{TeV}$ 对撞质子。固定靶机器要达到同样的 $\sqrt{s}$，需要多大的束流能量？
::: solution
(a) 重子数守恒禁止产生单独一个反质子，所以最小的末态是三个质子加一个反质子，$M_f = 4m_p$。取 $m_1 = m_2 = m_p$，[[#eq-s-fixed]] 在阈处写成 $(4m_pc^2)^2 = 2m_p^2c^4 + 2E_1m_pc^2$，于是 $E_1 = 7m_pc^2$，动能为

$$
K_\mathrm{th} = 6m_pc^2 = 6 \times 0.938\,\mathrm{GeV} = 5.63\,\mathrm{GeV}.
$$

对撞机每束只需 $m_pc^2$ 的动能。Bevatron 的质子最高 $6.2\,\mathrm{GeV}$，于 1955 年产生了第一批反质子（欧文·张伯伦（Owen Chamberlain）、埃米利奥·塞格雷（Emilio Segrè）、克莱德·维甘德（Clyde Wiegand）与托马斯·伊普西兰蒂斯（Thomas Ypsilantis））。

(b) 由 [[#eq-s-fixed]]，在 $c = 1$ 的单位制中 $E_1 = (s - 2m_p^2)/2m_p$：

$$
E_1 = \frac{(13\,600)^2 - 2(0.938)^2}{2 \times 0.938}\,\mathrm{GeV} = 9.86\times10^{7}\,\mathrm{GeV} \approx 10^{17}\,\mathrm{eV}.
$$

这约为 LHC 束流能量的 $14\,000$ 倍。如此能量的宇宙线确实会击中大气，但每平方公里每年只有几个；反过来说，LHC 束流打在固定靶上只给出 $\sqrt{s} = \sqrt{2 \times 6800 \times 0.938}\,\mathrm{GeV} = 113\,\mathrm{GeV}$。
:::
:::

::: quiz
一项固定靶实验把束流能量从 $400\,\mathrm{GeV}$ 加倍到 $800\,\mathrm{GeV}$（质子打质子）。$\sqrt{s}$ 大约增大几倍？
- [ ] 2
- [x] $\sqrt{2} \approx 1.41$
- [ ] 4
- [ ] 不变，因为靶是静止的。
::: solution
对 $E_1 \gg m_pc^2$，[[#eq-s-fixed]] 给出 $s \approx 2E_1m_pc^2$，所以 $\sqrt{s} \propto \sqrt{E_1}$：束流能量加倍使 $\sqrt{s}$ 乘以 $\sqrt{2}$，从 $27.4$ 到 $38.8\,\mathrm{GeV}$。在对称对撞机中，两束能量都加倍会使 $\sqrt{s}$ 加倍。
:::
:::

### 亮度

截面为 $\sigma$ 的过程，其速率是截面乘上一个只由机器本身决定的量。

::: definition 亮度 {#def-luminosity}
对撞机的**亮度**（luminosity）$\mathcal{L}$ 由

$$
\dot N = \mathcal{L}\,\sigma
$$ {#eq-luminosity}

对任一截面为 $\sigma$ 的过程的事例率 $\dot N$ 定义。对每束 $n_b$ 个束团、各含 $N_1$ 与 $N_2$ 个粒子、以回旋频率 $f$ 迎头对撞、在碰撞点有横向均方根宽度为 $\sigma_x$、$\sigma_y$ 的高斯分布的情况，

$$
\mathcal{L} = \frac{f\,n_b\,N_1N_2}{4\pi\sigma_x\sigma_y} .
$$ {#eq-lumi-gauss}

**积分亮度** $\int\mathcal{L}\,\dd t$ 以靶恩的倒数计；$1\,\mathrm{fb}^{-1}$（一个飞靶恩的倒数）$= 10^{39}\,\mathrm{cm}^{-2}$，对截面为 $1\,\mathrm{fb}$ 的过程恰好给出一个事例。
:::

公式 [[#eq-lumi-gauss]] 在习题中证明。亮度通常以 $\mathrm{cm^{-2}\,s^{-1}}$ 报告。要把它做大，加速器物理学家把两束在相互作用点挤压到微米大小，并往环里填入机器所能容忍的最多、最强的束团。

::: example LHC 的亮度与堆积 {#ex-lumi}
LHC 设计为 $f = 11.245\,\mathrm{kHz}$、$n_b = 2808$ 个束团、每个含 $1.15\times10^{11}$ 个质子，在 ATLAS 与 CMS 的相互作用点上是均方根尺寸 $16.7\,\mu\mathrm{m}$ 的圆束。(a) 由 [[#eq-lumi-gauss]] 计算 $\mathcal{L}$。(b) 第 3 轮运行中，实验以约 $\mathcal{L} = 2\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}$、约 $2400$ 个对撞束团运行。非弹性质子–质子截面为 $80\,\mathrm{mb}$，求碰撞率以及每个束团交叉中同时发生的碰撞的平均数目。
::: solution
(a) 以厘米计，$\sigma_x = \sigma_y = 1.67\times10^{-3}\,\mathrm{cm}$，于是

$$
\mathcal{L} = \frac{11\,245 \times 2808 \times (1.15\times10^{11})^2}{4\pi(1.67\times10^{-3})^2}\,\mathrm{cm^{-2}\,s^{-1}} = 1.2\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}.
$$

两束以一个小的交叉角对撞以避免寄生碰撞，这使上式乘以一个约 $0.84$ 的几何因子，得到设计值 $1.0\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}$。

(b) $80\,\mathrm{mb} = 8.0\times10^{-26}\,\mathrm{cm}^2$，所以 $\dot N = 2\times10^{34} \times 8.0\times10^{-26} = 1.6\times10^9$ 次碰撞每秒。束团每秒交叉 $11\,245 \times 2400 = 2.7\times10^7$ 次，所以每次交叉平均有 $\mu = 1.6\times10^9/2.7\times10^7 \approx 60$ 次质子–质子碰撞，称为**堆积**（pile-up）。探测器必须把它们一一解开。相比之下，在这一能量下希格斯玻色子的产生截面约 $60\,\mathrm{pb}$，$1\,\mathrm{fb}^{-1}$ 的数据中包含约 $60\,000$ 个希格斯玻色子：每 $10^{10}$ 次碰撞一个。
:::
:::

::: application 截至 2026 年的 LHC
LHC 于 2008 年 9 月 10 日首次实现两束循环，2010 年以 $\sqrt{s} = 7\,\mathrm{TeV}$ 开始物理运行，2012 年为 $8\,\mathrm{TeV}$——正是发现希格斯玻色子的那一年。第 2 轮运行（2015–18）以 $13\,\mathrm{TeV}$ 运行，向 ATLAS 与 CMS 各交付了约 $140\,\mathrm{fb}^{-1}$ 的物理质量数据。第 3 轮运行于 2022 年 7 月以 $13.6\,\mathrm{TeV}$ 开始，亮度稳在约 $2\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}$ 附近。截至 2026 年，CERN 的计划安排第 3 轮到 2026 年年中结束，然后开始为高亮度 LHC 进行长期停机；高亮度 LHC 计划于 2030 年前后开始运行，稳定亮度为 $5$ 到 $7.5\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}$，寿命期内每台实验装置积累约 $3000\,\mathrm{fb}^{-1}$ 或更多的积分亮度。环中有 1232 台超导二极磁铁，以超流氦冷却到 $1.9\,\mathrm{K}$。
:::

## 辐射与物质 {#matter}

每台探测器的工作方式，都是让粒子沉积一些能量，再把这部分能量变成电的或光的信号。粒子如何沉积能量，取决于它是谁。

### 带电粒子：电离

穿过物质的带电粒子与原子的电子碰撞，使原子电离或激发。每次碰撞只取走能量的一小部分，所以损失几乎是连续的。其平均速率由汉斯·贝特（Hans Bethe，1930、1932）与费利克斯·布洛赫（Felix Bloch，1933）算出。电荷为 $ze$、速率为 $\beta c$、质量远大于电子的粒子，按 PDG 表列的形式为

$$
-\left\langle\deriv{E}{x}\right\rangle = K z^2\frac{Z}{A}\frac{1}{\beta^2}\left[\ln\frac{2m_ec^2\beta^2\gamma^2}{I} - \beta^2 - \frac{\delta}{2}\right],
$$ {#eq-bethe}

其中 $K = 0.307\,\mathrm{MeV\,cm^2/mol}$，$Z$ 与 $A$ 是介质的原子序数与原子量（所以 $A$ 以 $\mathrm{g/mol}$ 计时，$K Z/A$ 的单位是 $\mathrm{MeV\,cm^2/g}$），$I$ 是平均激发能（约 $16Z^{0.9}\,\mathrm{eV}$；水为 $75\,\mathrm{eV}$），$\delta$ 是在极高能量下才重要的密度修正。这里 $\dd x$ 以 $\mathrm{g/cm^2}$ 计，即穿过的单位面积质量，这使公式几乎与材料无关。

实际要紧的特征有三个。损失取决于粒子的速率而非质量，所以动量相同时重的粒子慢、损失多：这就是**以 $\dd E/\dd x$ 鉴别粒子**。低速时 $1/\beta^2$ 因子使损失陡升，所以一个停下来的粒子在径迹末端把大部分能量沉积在那里，即**布拉格峰**（Bragg peak）；这就是癌症治疗用质子束的原因——把剂量沉积在肿瘤处，同时保护肿瘤前面的组织。而在 $\beta\gamma \approx 3$ 到 $4$ 处，损失有一个宽极小，多数材料中约为 $1$ 到 $2\,\mathrm{MeV\,cm^2/g}$；处在这个极小附近的粒子称为**最小电离粒子**（minimum-ionising particle），宇宙线 μ 子与多数高能带电径迹都是这种情形。

:::

电子与正电子也靠电离损失能量，但因为它们轻，被核偏转时还强烈辐射：**轫致辐射**（bremsstrahlung）。在多数材料中，超过几十 MeV 量级的**临界能量**之后，辐射占主导，电子能量按 $e^{-x/X_0}$ 衰减，其中 $X_0$ 是**辐射长度**（水 $36\,\mathrm{cm}$，铅 $0.56\,\mathrm{cm}$）。

**切伦科夫辐射**（Cherenkov radiation）在带电粒子穿过介质比那里的光速还快时发出，即 $\beta > 1/n$。波前拼成一个锥，像船的艏波，锥角为

$$
\cos\theta_C = \frac{1}{n\beta}.
$$ {#eq-cherenkov}

这样损失的能量极少，但光有方向性且有尖锐的阈值，这使它成为鉴别粒子、以及像超级神冈（Super-Kamiokande）那样在大水池中探测中微子的有力工具。

:::

### 光子

光子不逐渐损失能量。它一路飞行直到发生相互作用，然后在一次事件中整份地被吸收或散射，所以一束光按指数衰减，$I = I_0e^{-\mu x}$，如 [[particles/reactions]] 中那样。三个过程相互竞争。**光电效应**中，光子被原子吸收并打出一个电子；它在低能、重元素中占主导（大致按 $Z^4$ 到 $Z^5$）。**康普顿散射**在 $1\,\mathrm{MeV}$ 附近占主导，光子从电子上散射，把一部分能量交给它。**电子对产生**在核的场中要求 $2m_ec^2 = 1.022\,\mathrm{MeV}$ 以上，光子变成一个电子–正电子对；它在约 $10\,\mathrm{MeV}$ 以上占主导，平均自由程为 $\tfrac97 X_0$。

### 中性强子与中微子

中子不带电荷，无视原子的电子。它只能通过一个产生带电粒子的核反应被探测：在富氢闪烁体上弹性散射质子，或慢中子的俘获反应，如 $n + {}^{10}\mathrm{B} \to {}^7\mathrm{Li} + \alpha$ 或 $n + {}^3\mathrm{He} \to p + {}^3\mathrm{H}$。中微子只参与弱相互作用，$1\,\mathrm{GeV}$ 时对核子的截面约 $10^{-38}\,\mathrm{cm}^2$；探测它们需要千吨级的靶。在对撞机探测器中它们根本不被探测到，而是由横向动量的不平衡推断出来。

## 探测器 {#detectors}

探测器把沉积的能量变成信号。主要的几类是：

**闪烁体。** 某些晶体（碘化钠、碘化铯、锗酸铋）与塑料被电离时发光。光电倍增管或硅光探测器把光变成正比于沉积能量的电脉冲。闪烁体很快（塑料中以纳秒计），用于定时与触发，晶体形态则用于测量光子能量。

**气体探测器。** 气体中的电离产生电子–离子对，在电场中漂移。低场时只是把它们收集起来（电离室）；场强高一些时，在细阳极丝附近电子雪崩倍增（正比计数器）；场再高时，放电沿整条丝蔓延（1928 年的盖革–缪勒计数器，只计数、不能测能量）。乔治·沙帕克（Georges Charpak）1968 年的多丝正比室把许多这样的丝放在一个平面里，使高能率的电子学径迹记录成为可能。

**半导体探测器。** 在硅中，一个带电粒子每沉积 $3.6\,\mathrm{eV}$ 产生一个电子–空穴对，产生一对所需的电子伏比气体少约十倍，所以信号更大、统计涨落更小。硅条与硅像素探测器的特征尺寸为几十微米，构成对撞机实验的内径迹室，为短寿命粒子定位衰变顶点。锗冷却到液氮温度，对 γ 射线给出最好的能量分辨，$1\,\mathrm{MeV}$ 处约 $0.1\%$。

**量能器。** 量能器在致密的块体中吸收一个粒子的全部能量并加以测量。电子或光子发起一场**电磁簇射**（electromagnetic shower），轫致辐射与电子对产生交替进行，直到能量降到临界能量以下，约在 $20X_0$ 内被容纳。强子发起一场由核反应组成的**强子簇射**（hadronic shower），更长也更不规则。量能器的分辨随能量改善，大致 $\sigma_E/E \propto 1/\sqrt{E}$，因为簇射中的粒子数随 $E$ 增长。

### 磁场中的径迹测量

螺线磁场 $B$ 中的带电粒子沿螺旋线运动。它在垂直于场的平面上的投影是半径为 $\rho$ 的圆，由 [[#eq-rigidity]] 给出横向动量 $p_T = 0.2998B\rho$。在长度 $L$ 的一段径迹上，圆偏离直线的**矢高**（sagitta）为 $s \approx L^2/8\rho$。高动量下矢高很小，要用几次微米精度的位置测量来测定，所以动量分辨随 $p$ 线性变坏：径迹测量在低动量最准，量能器在高能量最准。

::: example CMS 中的一条径迹 {#ex-track}
CMS 探测器的螺线管磁场为 $3.8\,\mathrm{T}$。一条带电径迹的横向曲率半径为 $2.00\,\mathrm{m}$。求 $p_T$。对 $p_T = 100\,\mathrm{GeV}/c$ 的径迹，求 $L = 1.0\,\mathrm{m}$ 探测器段上的矢高。
::: solution
由 [[#eq-rigidity]]，$p_T = 0.2998 \times 3.8 \times 2.00 = 2.28\,\mathrm{GeV}/c$。

对 $p_T = 100\,\mathrm{GeV}/c$，$\rho = 100/(0.2998 \times 3.8) = 87.8\,\mathrm{m}$，于是

$$
s \approx \frac{L^2}{8\rho} = \frac{(1.0\,\mathrm{m})^2}{8 \times 87.8\,\mathrm{m}} = 1.42\,\mathrm{mm}.
$$

要把这个动量测到 $1\%$，矢高要测到约 $14\,\mu\mathrm{m}$，这就是硅径迹室精度之所以要紧、CMS 之所以选强磁场的原因：在固定精度下，动量分辨正比于 $BL^2$ 改善。
:::
:::

### 粒子鉴别

一台通用对撞机探测器围绕碰撞点分层建造，每一层擅长一件事，一个粒子由它留下的信号图案来鉴别。

| 粒子 | 内径迹室 | 电磁量能器 | 强子量能器 | μ 子室 |
|---|---|---|---|---|
| 电子 | 弯曲径迹 | 完全簇射 | — | — |
| 光子 | — | 完全簇射 | — | — |
| 带电强子（$\pi^\pm$、$K^\pm$、$p$） | 弯曲径迹 | 小沉积 | 簇射 | — |
| 中性强子（$n$、$K^0_L$） | — | 小沉积 | 簇射 | — |
| μ 子 | 弯曲径迹 | 最小电离 | 最小电离 | 径迹 |
| 中微子 | — | — | — | —（缺失 $p_T$） |

μ 子之所以能被鉴别，是因为它们是穿过几米铁后唯一幸存的带电粒子：它们太重，辐射不了多少，又不感受强力。中微子表现为**缺失横向动量**：垂直于束流方向的动量之和必须为零，所以不平衡意味着有什么东西没有被看见。要把带电强子彼此分开，探测器再加上比电离、飞行时间与切伦科夫测量，这些测的都是速率，与动量合在一起就给出质量。

::: quiz
一个事例显示内径迹室中一条弯曲径迹，电磁量能器中一场与径迹动量相匹配的大簇射，强子量能器中什么也没有，μ 子室中也什么也没有。粒子是什么？
- [x] 电子或正电子
- [ ] 光子
- [ ] μ 子
- [ ] 带电 π 介子
::: solution
径迹意味着粒子带电，排除光子。能量等于径迹动量的完全电磁簇射、加上没有强子簇射，正是电子的签名。μ 子只会留下最小电离的沉积，并到达 μ 子室；带电 π 介子会把大部分能量沉积在强子量能器里。弯曲的方向区分 $e^-$ 与 $e^+$。
:::
:::

::: warning 探测器测量的是动量与速率，不是质量
径迹室给 $p$；飞行时间或切伦科夫测量给 $\beta$。质量只能由二者合并得出，$m = p\sqrt{1 - \beta^2}/\beta c$，而且随着两种粒子都逼近 $\beta = 1$，这种区分逐渐消失。在 $10\,\mathrm{GeV}/c$ 处，π 介子与 K 介子的 $\beta$ 只差 $0.1\%$。只凭动量引用一个"测得的质量"，或者比较相同能量而非相同动量的粒子，都是常见的错误。
:::

::: history 从云室到 LHC
查尔斯·威尔逊（Charles Wilson）的云室（1911）使带电粒子的径迹成为可见——在过饱和蒸气中留下一串串小液滴；卡尔·安德森（Carl Anderson）1932 年在云室中发现了正电子，并与塞思·内德迈尔（Seth Neddermeyer）一起在 1936 年发现了 μ 子。汉斯·盖革与瓦尔特·缪勒（Walther Müller）的计数器始于 1928 年。科克罗夫特与沃尔顿的电压倍增器和劳伦斯的回旋加速器都在 1932 年做出了各自第一批核物理成果。韦克斯勒与麦克米兰 1944–45 年发现相位稳定，为 Bevatron 一类的同步加速器开辟了道路，反质子就是在 Bevatron 上于 1955 年找到的。唐纳德·格拉泽（Donald Glaser）1952 年发明气泡室，它的照片主导了 1950 与 60 年代强子共振的发现。沙帕克的多丝正比室（1968）开启了电子学时代。第一台强子对撞机——CERN 的交叉储存环——1971 年起运行；CERN 的质子–反质子对撞机于 1983 年发现 $W$ 与 $Z$ 玻色子，费米实验室的 Tevatron 于 1995 年发现顶夸克，LHC 于 2012 年发现希格斯玻色子。
:::

## 后续内容 {#leads}

这些仪器揭示出的粒子以及它们之间的相互作用，是 [[particles/standard-model]] 的主题；历史注记里列出的那些发现将在其中得到解释。精密测量所检验的那些对称性，例如 β 衰变中的宇称破坏，在 [[particles/symmetries]]。加速器设计与同步辐射背后的电磁理论在 [[electrodynamics/radiation]] 与 [[electrodynamics/relativistic-fields]]。

::: summary
- 分辨需要短波长 $\hbar/p$；产生需要质心能量 $\sqrt{s}$ 超过要造粒子的质量。
- 磁场中的电荷以 $\omega = qB/\gamma m$ 回旋、半径 $p/qB$；$p\,[\mathrm{GeV}/c] = 0.2998\,B\,[\mathrm{T}]\,\rho\,[\mathrm{m}]$。回旋加速器在 $\gamma \approx 1$ 时有效。
- 同步加速器在固定轨道上让 $B$ 与射频同步爬升，依靠相位稳定与强聚焦。每圈同步辐射损失 $U_0 = \frac{4\pi}{3}\frac{e^2}{4\pi\varepsilon_0}\frac{\gamma^4}{\rho}$，这限制了圆形电子机器。
- 固定靶：$s = m_1^2 + m_2^2 + 2E_1m_2$（取 $c = 1$），所以 $\sqrt{s}$ 按 $\sqrt{E_1}$ 增长。对撞机：$s \approx 4E_1E_2$。
- 事例率 $= \mathcal{L}\sigma$，高斯束下 $\mathcal{L} = fn_bN_1N_2/4\pi\sigma_x\sigma_y$。LHC 在约 $2\times10^{34}\,\mathrm{cm^{-2}\,s^{-1}}$ 附近运行，每个交叉约 60 次碰撞。
- 重带电粒子靠电离损失能量（贝特公式），极小在 $\beta\gamma \approx 3$ 附近，射程末端有布拉格峰。电子会辐射；光子靠光电吸收、康普顿散射与电子对产生转化为其他东西。
- 探测器把沉积的能量变成信号：闪烁体、气体室、硅、量能器。磁场中的径迹测量给动量；测速率给质量；分层探测器按签名鉴别每种粒子，中微子则由缺失横向动量发现。
:::

## 习题 {#exercises}

::: exercise 回旋频率 {level=1 check="22.9"}
求质子在 $1.50\,\mathrm{T}$ 磁场中的回旋频率 $f = \omega_c/2\pi$，以 MHz 计。（$m_p = 1.673\times10^{-27}\,\mathrm{kg}$。）
::: solution
$f = eB/2\pi m_p = (1.602\times10^{-19} \times 1.50)/(2\pi \times 1.673\times10^{-27})\,\mathrm{Hz} = 2.29\times10^7\,\mathrm{Hz} = 22.9\,\mathrm{MHz}$。氘核质量加倍、电荷相同，在同一磁场中将以这个频率的一半回旋。
:::
:::

::: exercise 电子–质子对撞机 {level=1 check="318"}
DESY 的 HERA 对撞机（1992–2007）使 $27.5\,\mathrm{GeV}$ 的电子或正电子与 $920\,\mathrm{GeV}$ 的质子迎头对撞。求 $\sqrt{s}$，以 GeV 计。
::: solution
两种粒子都是极端相对论的，所以由 [[#eq-s-collider]]，$\sqrt{s} = 2\sqrt{E_1E_2} = 2\sqrt{27.5 \times 920}\,\mathrm{GeV} = 2\sqrt{25\,300} = 318\,\mathrm{GeV}$。质心系沿质子方向运动，所以探测器建成不对称的，质子一侧装了更多的仪器。
:::
:::

::: exercise 由曲率求动量 {level=1 check="0.30"}
$2.00\,\mathrm{T}$ 磁场中一条带电径迹的横向曲率半径为 $0.500\,\mathrm{m}$。求 $p_T$，以 $\mathrm{GeV}/c$ 计。
::: solution
由 [[#eq-rigidity]]，$p_T = 0.2998 \times 2.00 \times 0.500 = 0.300\,\mathrm{GeV}/c$。磁场只给出垂直于它的动量分量；纵向分量来自螺旋线的螺距。
:::

::: exercise 反质子阈能 {level=2 check="5.63"}
证明静止质子上 $p + p \to p + p + p + \bar p$ 的阈动能为 $6m_pc^2$，并用 $m_pc^2 = 0.93827\,\mathrm{GeV}$ 算出以 GeV 计的值。
::: solution
对 $m_a = m_X = m_p$、$M_f = 4m_p$ 用 [[particles/reactions#thm-threshold]]：$K_\mathrm{th} = (16m_p^2 - 4m_p^2)c^2/2m_p = 6m_pc^2 = 5.63\,\mathrm{GeV}$。等价地，由 [[#eq-s-fixed]]，$E_1 = 7m_pc^2$。非相对论估计 $-Q(1 + m_a/m_X) = 2m_pc^2 \times 2 = 4m_pc^2$ 在这里错得离谱。
:::

::: exercise LEP 的辐射账单 {level=2 check="3.40"}
用 [[#prop-synchrotron]] 求 $104.5\,\mathrm{GeV}$ 电子在 $3100\,\mathrm{m}$ 弯曲半径上每圈损失的能量，以 GeV 计。同样能量的质子损失多少？
::: solution
$U_0 = 88.5\,\mathrm{keV} \times 104.5^4/3100 = 88.5 \times 1.1925\times10^8/3100\,\mathrm{keV} = 3.40\times10^6\,\mathrm{keV} = 3.40\,\mathrm{GeV}$。对质子，$\gamma$ 小 $1836.15$ 倍，所以损失小 $1836.15^4 = 1.14\times10^{13}$ 倍：每圈约 $3\times10^{-4}\,\mathrm{eV}$。（在 LHC 的 $6.8\,\mathrm{TeV}$ 处，质子每圈损失约 $6\,\mathrm{keV}$，虽小但足以让低温系统在意。）
:::

::: exercise π 介子的切伦科夫阈值 {level=2 check="159"}
求带电 π 介子（$m_\pi c^2 = 139.57\,\mathrm{MeV}$）在水中（$n = 1.33$）发出切伦科夫光的最小动量，以 $\mathrm{MeV}/c$ 计。K 介子（$493.68\,\mathrm{MeV}/c^2$）的阈值是多少？
::: solution
阈值在 $\beta = 1/n$。此时 $\beta\gamma = \beta/\sqrt{1 - \beta^2} = 1/\sqrt{n^2 - 1}$，而 $p = m\beta\gamma c$，所以

$$
p_\mathrm{th} = \frac{mc}{\sqrt{n^2 - 1}} = \frac{139.57}{\sqrt{0.7689}}\,\mathrm{MeV}/c = 159\,\mathrm{MeV}/c.
$$

对 K 介子，$493.68/0.8769 = 563\,\mathrm{MeV}/c$。在 $159$ 到 $563\,\mathrm{MeV}/c$ 之间，水切伦科夫计数器对 π 介子发信号而不为 K 介子发信号。
:::

::: exercise 飞行时间 {level=2 check="1.06"}
动量 $1.00\,\mathrm{GeV}/c$ 的 π 介子与 K 介子各飞行 $3.00\,\mathrm{m}$。求二者飞行时间之差，以纳秒计。
::: solution
飞行时间为 $t = L/\beta c$，其中 $1/\beta = E/pc = \sqrt{1 + (mc/p)^2}$。对 π 介子，$\sqrt{1 + 0.13957^2} = 1.00969$；对 K 介子，$\sqrt{1 + 0.49368^2} = 1.11522$。由 $L/c = 3.00/2.998\times10^8\,\mathrm{s} = 10.007\,\mathrm{ns}$，时间差为

$$
\Delta t = 10.007 \times (1.11522 - 1.00969)\,\mathrm{ns} = 1.06\,\mathrm{ns}.
$$

约 $100\,\mathrm{ps}$ 的闪烁体定时可以宽宽地把它们分开。在 $5\,\mathrm{GeV}/c$ 处，差降到约 $0.04\,\mathrm{ns}$，因为它按 $1/p^2$ 缩小。
:::

::: exercise 高斯束的亮度 {level=3}
两个束团迎头对撞。它们在横向平面内的粒子数密度为 $N_i\,g(x, y)$，其中 $g(x, y) = \exp(-x^2/2\sigma_x^2 - y^2/2\sigma_y^2)/(2\pi\sigma_x\sigma_y)$ 对两者是同一个归一化高斯。证明截面为 $\sigma$ 的过程每个交叉的事例数为 $\sigma N_1N_2/(4\pi\sigma_x\sigma_y)$，并推出 [[#eq-lumi-gauss]]。
::: hint
位于 $(x, y)$ 的束 1 中的一个粒子，看到的束 2 粒子面密度为 $N_2\,g(x, y)$，并以概率 $\sigma N_2 g(x, y)$ 发生反应。对束 1 积分。你需要 $\int_{-\infty}^{\infty} e^{-x^2/\sigma^2}\,\dd x = \sqrt{\pi}\sigma$。
:::
::: solution
由提示，每个交叉的事例数期望值为

$$
n = \sigma N_1N_2\int g(x, y)^2\,\dd x\,\dd y = \frac{\sigma N_1N_2}{(2\pi\sigma_x\sigma_y)^2}\int e^{-x^2/\sigma_x^2}\,\dd x\int e^{-y^2/\sigma_y^2}\,\dd y .
$$

两个积分分别为 $\sqrt{\pi}\sigma_x$ 与 $\sqrt{\pi}\sigma_y$，所以 $n = \sigma N_1N_2\,\pi\sigma_x\sigma_y/(4\pi^2\sigma_x^2\sigma_y^2) = \sigma N_1N_2/(4\pi\sigma_x\sigma_y)$。交叉每秒发生 $f n_b$ 次，所以事例率为 $\sigma\,fn_bN_1N_2/(4\pi\sigma_x\sigma_y)$，与 [[#eq-luminosity]] 比较即得 [[#eq-lumi-gauss]]。这是两个宽度各为 $\sigma$ 的高斯的交叠，这就是系数为 $4\pi$、而不是单个高斯归一化的 $2\pi$ 的原因。
:::

::: exercise 非对称碰撞与洛伦兹提升 {level=3}
(a) 对能量为 $E_1$ 与 $E_2$ 的两个无质量粒子迎头碰撞，证明质心系沿粒子 1 的方向以快度 $y = \tfrac12\ln(E_1/E_2)$ 运动。(b) 证明能量为 $E_1 \gg m$ 的束流打在质量为 $m$ 的静止靶上时，质心系的洛伦兹因子为 $\gamma_\mathrm{cm} = (E_1 + mc^2)/\sqrt{s}c^2 \approx \sqrt{E_1/2mc^2}$。对 LHC 束流打静止质子算出它的值。
::: hint
快度由 $\tanh y = \beta$ 定义，所以 $e^{2y} = (1 + \beta)/(1 - \beta)$。质心速度为 $\beta_\mathrm{cm} = \sum pc/\sum E$。
:::
::: solution
(a) 总动量为 $(E_1 - E_2)/c$，总能量为 $E_1 + E_2$，所以 $\beta_\mathrm{cm} = (E_1 - E_2)/(E_1 + E_2)$。于是 $(1 + \beta)/(1 - \beta) = 2E_1/2E_2 = E_1/E_2$，且 $y = \tfrac12\ln(E_1/E_2)$。对 HERA，$y = \tfrac12\ln(920/27.5) = 1.75$，沿质子方向。

(b) 该参考系的洛伦兹因子等于总能量除以不变质量，$\gamma_\mathrm{cm} = (E_1 + mc^2)/(\sqrt{s}c^2)$。当 $E_1 \gg mc^2$ 时 $sc^4 \approx 2E_1mc^2$，于是 $\gamma_\mathrm{cm} \approx E_1/\sqrt{2E_1mc^2} = \sqrt{E_1/2mc^2}$。取 $E_1 = 6800\,\mathrm{GeV}$、$mc^2 = 0.938\,\mathrm{GeV}$，$\gamma_\mathrm{cm} = \sqrt{3625} = 60$：产物将以锥角约 $1/60$ 弧度的前向细锥喷出，而且只有 $\sqrt{s} = 113\,\mathrm{GeV}$ 可用于产生新粒子。
:::
