我们关于粒子相互作用的大部分认识，是在人们还不会拿它们做计算之前，靠着追问它们守恒什么而学到的。如果一个反应尽管能量允许却从不发生，那一定是某个量禁止了它；如果两个反应以固定的速率比发生，那一定是某种对称性把它们联系在一起。对称性论证是粒子物理最稳健的工具，因为它们在我们对动力学一无所知时依然成立。它们也造出了这门学科最大的两次意外：1957 年发现弱相互作用区分左右，以及 1964 年发现它极其轻微地区分物质与反物质。

本章先讲对称性与守恒律的联系，然后处理三个分立对称性：宇称 P、电荷共轭 C 与时间反演 T，以及表明哪些相互作用尊重它们的那些实验。接着转向强相互作用近似的内部对称性：同位旋，以及把它推广到 SU(3) 味——正是这些对称性把强子谱组织成盖尔曼的八重道，并引出了夸克。最后是一种**局域**或**规范**对称性的思想——[[particles/standard-model]] 中的各种相互作用都由它导出。

你需要 [[quantum-1/angular-momentum]] 与 [[quantum-1/spin]] 中的角动量及其合成，[[quantum-2/identical-particles]] 的全同粒子，以及标准模型的粒子内容。粒子数据取自 PDG 的《Review of Particle Physics》（2024）。

## 对称性与守恒律 {#noether}

一个物理系统的**对称性**是使其规律保持不变的变换。量子力学中，对称性由一个与哈密顿量对易的幺正算符 $U$ 表示，$[U, H] = 0$。于是若 $\psi$ 是薛定谔方程的解，$U\psi$ 也是。

::: theorem 对称性意味着守恒 {#thm-noether}
设 $U$ 是满足 $[U, H] = 0$ 的幺正算符，$Q$ 是与 $H$ 对易的厄米算符。则在任何态中 $Q$ 的期望值都不随时间改变。特别地，若 $U(\theta) = e^{-i\theta Q}$ 是一个连续对称性族，它的生成元 $Q$ 守恒；而若 $U$ 本身既厄米又幺正（于是 $U^2 = 1$），它的本征值 $\pm1$ 守恒。
:::

::: proof
对任何态，$\deriv{}{t}\langle Q\rangle = \frac{i}{\hbar}\langle[H, Q]\rangle$（埃伦费斯特定理，[[quantum-1/formalism]]），当 $[H, Q] = 0$ 时它为零。对连续族，把 $[e^{-i\theta Q}, H] = 0$ 在 $\theta = 0$ 处对 $\theta$ 求导，得 $-i[Q, H] = 0$。对既厄米又幺正的 $U$，这个算符本身就是一个满足 $U^2 = 1$ 的可观测量，所以它的本征值为 $\pm1$，而 $[U, H] = 0$ 意味着 $U$ 的本征态随时间演化成同一本征值的本征态。
:::

这就是艾米·诺特（Emmy Noether）定理（1918）的量子形式。空间平移给出动量守恒，时间平移给出能量守恒，转动给出角动量守恒。带电场的相位旋转 $\psi \to e^{iq\theta}\psi$ 给出电荷守恒。连续对称性给出**相加性**守恒量：一个系统的电荷是它各部分电荷之和。宇称这样的分立对称性给出**乘积性**守恒量：一个系统的宇称是它各部分宇称之积，再乘上一个来自它们相对运动的因子。

每种相互作用守恒什么的这张表，是给过程分类的钥匙。

| 量 | 强 | 电磁 | 弱 |
|---|---|---|---|
| 能量、动量、角动量、电荷 | 是 | 是 | 是 |
| 重子数 $B$、轻子数 $L$ | 是 | 是 | 是 |
| 夸克味（奇异数 $S$、粲、……） | 是 | 是 | 否 |
| 同位旋 $I$ | 是（近似） | 否 | 否 |
| 宇称 P、电荷共轭 C | 是 | 是 | 否 |
| CP | 是 | 是 | 否（在 $\sim10^{-3}$ 量级上被破坏） |
| CPT | 是 | 是 | 是 |

被所有守恒律放过的过程一定会发生，速率由能产生它的最强相互作用决定。强衰变如 $\Delta^{++} \to p\pi^+$ 约需 $10^{-23}\,\mathrm{s}$；电磁衰变如 $\pi^0 \to \gamma\gamma$ 约需 $10^{-16}\,\mathrm{s}$；弱衰变则从 $10^{-13}\,\mathrm{s}$ 到几分钟都有。当一个本可以强衰变的粒子却活了 $10^{-10}\,\mathrm{s}$——$\Lambda$ 就是这样——那必定是强相互作用的某个守恒律（这里是奇异数）禁止了那条更快的路。

::: example Λ 为什么寿命长 {#ex-lambda}
$\Lambda$（$uds$，质量 $1115.7\,\mathrm{MeV}$）以 $\Lambda \to p\pi^-$ 衰变，寿命 $2.6\times10^{-10}\,\mathrm{s}$。证明这个衰变在能量上是允许的、并且守恒电荷与重子数，指出它破坏了强相互作用的哪个守恒量，并解释这个寿命。
::: solution
产物总质量 $938.3 + 139.6 = 1077.8\,\mathrm{MeV}$，小于 $1115.7\,\mathrm{MeV}$，所以 $Q = 37.9\,\mathrm{MeV} > 0$。电荷：$0 \to +1 - 1 = 0$。重子数：$1 \to 1 + 0$。$\Lambda$ 含有一个 $s$ 夸克，奇异数 $S = -1$；质子（$uud$）与 $\pi^-$（$d\bar u$）的 $S = 0$。这个衰变的奇异数改变一个单位，强与电磁相互作用都禁止它，所以它必须经弱相互作用发生：$s$ 夸克发出一个 $W^-$ 变成 $u$ 夸克，后者再做成一个 $d\bar u$ 对。弱过程很慢，所以 $\Lambda$ 的寿命约比一次强衰变该花的时间长 $10^{13}$ 倍。这正是盖尔曼与西岛和彦（Kazuhiko Nishijima）1953–55 年引入奇异数时所说的"奇异"行为：强产生时成对出现，衰变却靠弱作用。
:::
:::

## 宇称 {#parity}

::: definition 宇称 {#def-parity}
**宇称算符** P 反射全部空间坐标，$P\psi(\mathbf{r}) = \psi(-\mathbf{r})$。它把动量反转，$\mathbf{p} \to -\mathbf{p}$，而把角动量（$\mathbf{L} = \mathbf{r}\times\mathbf{p}$ 与自旋这样的轴向量）保持不变。因为 $P^2 = 1$，它的本征值为 $\pm1$。一个静止的粒子有一个**内禀宇称** $\eta = \pm1$；轨道角动量为 $\ell$ 的态有轨道宇称 $(-1)^\ell$，因为 $Y_\ell^m(-\hat{\mathbf{r}}) = (-1)^\ell Y_\ell^m(\hat{\mathbf{r}})$。
:::

按惯例，质子与中子的宇称为 $+1$，夸克也是。一个费米子与它的反粒子内禀宇称相反（狄拉克方程的一个推论），所以轨道角动量为 $\ell$ 的 $q\bar q$ 介子有 $P = (-1)^{\ell+1}$：π 介子、K 介子等赝标介子，$\ell = 0$、自旋反平行，$J^P = 0^-$；$\rho$、$\omega$ 与 $J/\psi$，$\ell = 0$、自旋平行，$J^P = 1^-$。玻色子与它的反粒子宇称相同。光子的 $P = -1$，这是一个矢量场的宇称。

π 介子宇称为负，是由一个只用角动量、泡利原理与宇称守恒的论证在实验上确立的。

::: proposition π 介子的宇称 {#prop-pion-parity}
被 $\pi^-$ 俘获进 π 介子氘原子最低（$1s$）轨道的 $\pi^-$，被反应 $\pi^- + d \to n + n$ 吸收。已知氘核的 $J^P = 1^+$、π 介子自旋为 $0$，并且宇称与角动量守恒，则 π 介子的内禀宇称为 $-1$。
:::

::: proof
初态中 π 介子与氘核的轨道角动量 $\ell = 0$，所以总角动量就是氘核的 $J = 1$，宇称为 $\eta_\pi\eta_d(-1)^0 = \eta_\pi$。两个中子的末态，每个内禀宇称 $+1$，其宇称为 $(-1)^L$，$L$ 是它们的相对轨道角动量；它还必须有 $J = 1$。两个中子是全同费米子，所以态在交换下必须反对称。交换给空间部分一个因子 $(-1)^L$，给自旋部分 $S = 1$ 时 $+1$、$S = 0$ 时 $-1$，所以反对称要求 $L + S$ 为偶。具有 $J = 1$ 的态有 ${}^3S_1$、${}^1P_1$、${}^3P_1$ 与 ${}^3D_1$（记号为 ${}^{2S+1}L_J$）。其中只有 ${}^3P_1$ 满足 $L + S$ 为偶。于是末态 $L = 1$、宇称 $-1$，宇称守恒给出 $\eta_\pi = -1$。
:::

### 宇称的倾覆

尤金·维格纳（Eugene Wigner）表明宇称如何用于原子态之后的三十年里，人人都假定一切相互作用守恒宇称。第一道裂缝是 1950 年代初的 **θ–τ 疑难**：两种奇异介子，$\theta^+$ 与 $\tau^+$，质量和寿命相同，但一个衰变为两个 π 介子，另一个衰变为三个。自旋为 $0$ 的粒子，两 π 介子末态的宇称为 $+1$；三 π 介子末态——习题里会让你证明——宇称为 $-1$。若宇称守恒，它们就必须是两种粒子。1956 年，李政道（Tsung-Dao Lee）与杨振宁（Chen-Ning Yang）指出，弱相互作用中的宇称从来没有被任何实验检验过，并提出了几个检验方案。（$\theta$ 与 $\tau$ 都是我们今天称为 $K^+$ 的那个粒子。）

吴健雄（Chien-Shiung Wu）与她在国家标准局的同事们完成了第一个检验，1957 年 2 月发表。他们把 ${}^{60}\mathrm{Co}$ 核在磁场中冷却到约 $0.01\,\mathrm{K}$，使核自旋排列起来，然后沿核自旋方向及其反方向计数 β 衰变放出的电子。在宇称下，自旋作为轴向量不变，而电子动量反转。宇称不变的定律因此必须对沿自旋方向与反方向给出相同的速率。吴健雄发现电子优先朝核自旋的*反方向*发射，并且磁场反转时不对称性也随之反转。角分布为

$$
W(\theta) \propto 1 + a\,P\,\frac{v}{c}\cos\theta ,
$$ {#eq-wu}

其中 $\theta$ 是电子动量与核自旋的夹角，$P$ 是核极化度，而这个纯伽莫夫–泰勒跃迁的 $a = -1$。几天之内，哥伦比亚大学的理查德·加文（Richard Garwin）、利昂·莱德曼（Leon Lederman）与马塞尔·韦恩赖希（Marcel Weinrich），以及芝加哥大学的杰罗姆·弗里德曼（Jerome Friedman）与瓦伦丁·特莱格迪（Valentine Telegdi），在衰变链 $\pi \to \mu \to e$ 中看到了同样的破坏。李政道与杨振宁获 1957 年诺贝尔奖。

### 螺旋度与弱相互作用的手性

说清弱相互作用干了什么，最干净的语言是**螺旋度**（helicity）：自旋沿运动方向的分量，$h = \mathbf{S}\cdot\hat{\mathbf{p}}/\lvert\mathbf{S}\rvert$。宇称下 $\mathbf{p}$ 反转而 $\mathbf{S}$ 不变，所以 P 把螺旋度为 $+1$（"右手"）的态变成螺旋度为 $-1$（"左手"）的态。莫里斯·戈德哈贝尔（Maurice Goldhaber）、利·格罗德津斯（Lee Grodzins）与安德鲁·苏尼亚尔（Andrew Sunyar）1958 年从 ${}^{152}\mathrm{Eu}$ 电子俘获后放出的光子的极化测出了中微子的螺旋度，发现它是左手的。观测到的每一个中微子都是左手的，每一个反中微子都是右手的。带电流弱相互作用只与左手费米子和右手反费米子耦合——在零质量极限下——它最大程度地破坏宇称。

::: example π 介子衰变的螺旋度压低 {#ex-helicity}
$\pi^+$（自旋 $0$）几乎总是衰变为 $\mu^+\nu_\mu$，只有很少的时候衰变为 $e^+\nu_e$，尽管电子道有大得多的相空间。解释这一点，并用标准结果

$$
R = \left(\frac{m_e}{m_\mu}\right)^2\left(\frac{m_\pi^2 - m_e^2}{m_\pi^2 - m_\mu^2}\right)^2 .
$$
计算比值 $R = \Gamma(\pi \to e\nu)/\Gamma(\pi \to \mu\nu)$。
::: solution
在 π 介子静止系中，带电轻子与中微子背对背飞出。π 介子自旋为 $0$，所以它们的自旋必须相反，而由于动量也相反，它们的螺旋度相同。中微子是左手的，所以带正电的反轻子也必须是左手的。可是弱相互作用产生的反轻子是右手的；之所以还存在左手反轻子，只因为它有质量，而振幅正比于 $m/E$。电子比 μ 子轻 $200$ 倍，所以它的衰变被强烈压低。这就是因子 $(m_e/m_\mu)^2$ 的由来；第二个因子是相空间之比。

取 $m_e = 0.511$、$m_\mu = 105.658$、$m_\pi = 139.570\,\mathrm{MeV}$：

$$
\left(\frac{m_e}{m_\mu}\right)^2 = 2.339\times10^{-5}, \qquad \frac{m_\pi^2 - m_e^2}{m_\pi^2 - m_\mu^2} = \frac{19479.8}{8316.3} = 2.342 ,
$$

所以 $R = 2.339\times10^{-5} \times 2.342^2 = 1.283\times10^{-4}$。实测值为 $1.233\times10^{-4}$；那 $4\%$ 之差是一个理解得很清楚的辐射修正。倘若相互作用对两种螺旋度同等耦合，电子道将占优约 $5$ 倍。这种压低于 1958 年在 CERN 被观察到，证实了左手结构。
:::
:::

::: quiz
设想某个实验产生了一个右手中微子。把哪个对称性变换作用于熟悉的左手中微子，会得到这个态？
- [x] 宇称
- [ ] 电荷共轭
- [ ] CP
- [ ] 时间反演
::: solution
宇称反转动量而不反转自旋，所以它翻转螺旋度、并使粒子仍是粒子：P 把左手中微子变成右手中微子，而弱相互作用不产生这样的态。C 把它变成左手反中微子，那也不被产生。CP 给出右手反中微子，而这正是弱相互作用产生的东西，这就是 CP 在宇称倾覆之后幸存的原因。时间反演同时反转动量与自旋，螺旋度不变。
:::
:::

## 电荷共轭与 CP {#cp}

::: definition 电荷共轭 {#def-c}
算符 **C** 把每个粒子换成它的反粒子，位置、动量与自旋保持不变。一个本身就是自己反粒子的系统——如 $\gamma$、$\pi^0$ 或一个粒子–反粒子对——可以是 C 的本征态，本征值 $C = \pm1$，称为它的 **C 宇称**。光子的 $C = -1$，因为电荷变号时电磁场也变号。轨道角动量为 $L$、总自旋为 $S$ 的费米子–反费米子对有 $C = (-1)^{L+S}$。
:::

强与电磁相互作用守恒 C。$\pi^0$ 衰变为 $\gamma\gamma$，所以 $C(\pi^0) = (-1)^2 = +1$，与 $q\bar q$ 态的 $L = S = 0$ 相合；衰变 $\pi^0 \to 3\gamma$ 需要 $C = -1$，从未被看到（分支比低于 $3\times10^{-8}$）。正电子素的两个基态的区别恰在于此：单态 ${}^1S_0$ 的 $C = +1$，以 $0.125\,\mathrm{ns}$ 的寿命衰变为两个光子；三重态 ${}^3S_1$ 的 $C = -1$，必须放出三个光子，寿命 $142\,\mathrm{ns}$。

弱相互作用破坏 C 的程度与 P 不相上下：C 把左手中微子变成左手反中微子，而它不参与相互作用。但联合变换 **CP** 把左手中微子变成右手反中微子，而它参与相互作用。1957 年，列夫·朗道（Lev Landau）等人提出 CP 才是自然的真正对称性：镜射的同时把物质与反物质互换。

### 中性 K 介子与 1964 年的发现

中性 K 介子提供了一个灵敏的检验。$K^0$（$d\bar s$）与 $\bar K^0$（$s\bar d$）是两种不同的粒子，奇异数分别为 $+1$ 与 $-1$，但改变奇异数的弱相互作用可以通过二阶过程把一个变成另一个。因此具有确定寿命的态是两者的混合。取相位约定 $CP\lvert K^0\rangle = \lvert\bar K^0\rangle$，CP 本征态为

$$
\lvert K_1\rangle = \frac{\lvert K^0\rangle + \lvert\bar K^0\rangle}{\sqrt2} \;(CP = +1), \qquad \lvert K_2\rangle = \frac{\lvert K^0\rangle - \lvert\bar K^0\rangle}{\sqrt2} \;(CP = -1).
$$ {#eq-k1k2}

自旋为 $0$ 的粒子，两 π 介子末态的 $CP = +1$，三 π 介子末态的 $CP = -1$。若 CP 守恒，$K_1$ 将衰变为 $\pi\pi$——相空间大，所以很快——而 $K_2$ 只衰变为 $\pi\pi\pi$，很慢。实验看到的几乎正是如此：短寿命 $K_S$ 的寿命为 $0.895\times10^{-10}\,\mathrm{s}$，长寿命 $K_L$ 的为 $5.12\times10^{-8}\,\mathrm{s}$，长 $571$ 倍。默里·盖尔曼与亚伯拉罕·帕伊斯（Abraham Pais）1955 年预言了长寿命中性 K 介子，1956 年它就被找到了。

1964 年，布鲁克海文的詹姆斯·克里斯蒂（James Christenson）、詹姆斯·克罗宁（James Cronin）、瓦尔·菲奇（Val Fitch）与勒内·图尔莱（René Turlay）把探测器放得离靶足够远，让所有 $K_S$ 都已衰变殆尽，然后发现每一千个 $K_L$ 衰变中约有两个是 $\pi^+\pi^-$。一个 $CP = -1$ 的态在衰变成一个 $CP = +1$ 的态：**CP 被破坏了**。$K_L$ 主要是 $K_2$，掺有一小份 $\varepsilon \approx 2.2\times10^{-3}$ 的 $K_1$。克罗宁与菲奇获 1980 年诺贝尔奖。

此后 CP 破坏在 $B$ 介子的衰变中被测到，最早是 SLAC 的 BaBar 实验与 KEK 的 Belle 实验在 2001 年测到的，其中一些不对称性很大，达 $70\%$ 量级；$D$ 介子中也有（LHCb，2019 年）。夸克部分的全部结果都与 [[particles/standard-model]] 中 CKM 矩阵的那个单一复相位相洽。小林诚与益川敏英因证明这样的相位至少需要三代，而分享了 2008 年诺贝尔奖。

::: application 为什么存在物质
宇宙中每一个宇宙微波背景光子对应约 $6\times10^{-10}$ 个重子，而几乎没有反重子。安德烈·萨哈罗夫（Andrei Sakharov）1967 年证明，从一个对称的起点产生这样的不对称需要三个条件：破坏重子数的过程，C 与 CP 同时被破坏，以及脱离热平衡。标准模型原则上三者兼备，但它的 CKM 相位产生的不对称小了不知多少个数量级。因此需要 CP 破坏的某个额外来源，也许就在中微子部分——长基线实验正在那里测量它。
:::

### CPT

格哈特·吕德斯（Gerhart Lüders）与沃尔夫冈·泡利在 1954–57 年间证明，任何洛伦兹不变的定域量子场论在 CPT 联合变换下（无论以什么次序）都是不变的。它的推论——粒子与反粒子具有精确相等的静止质量与寿命、以及大小相等方向相反的磁矩——已被检验到惊人的精度：$K^0$ 与 $\bar K^0$ 的质量相符到优于 $10^{18}$ 分之一。有了 CPT，CP 破坏就意味着 **T 破坏**，即一个过程与其时间反演过程之间的差别；BaBar 于 2012 年在 $B$ 介子跃迁中直接观测到了它。

::: warning 被破坏的对称性并非没有用处
"P 被破坏"并不意味着宇称可以忽略不管。它被强与电磁相互作用精确守恒，这就是原子态与核态具有确定宇称、[[particles/decay]] 中的选择定则成立的原因；宇称破坏在核物理与原子物理中，只表现为弱相互作用带来的 $10^{-7}$ 量级的微小混杂。同样，下文的同位旋被电磁作用与 $u$–$d$ 质量差破坏，却近似到约 $1\%$。在抛弃一个对称性之前，先弄清楚是哪个相互作用、以多大力度破坏它。
:::

## 同位旋 {#isospin}

质子与中子的质量几乎相等（相差 $0.14\%$），而且除了质子的电荷之外，它们通过强力的相互作用完全相同：同一量子态下的 $pp$、$nn$ 与 $np$ 的力是一样的，这一性质称为**电荷无关性**。维尔纳·海森堡（Werner Heisenberg）1932 年建议把它们看作同一个粒子——**核子**——的两个态，由一个内部量子数区分。其数学就是自旋 $\tfrac12$ 的数学。

::: definition 同位旋 {#def-isospin}
**同位旋**是一个具有角动量代数的内部量子数。核子是一个同位旋二重态，$I = \tfrac12$，$\lvert p\rangle = \lvert\tfrac12, +\tfrac12\rangle$、$\lvert n\rangle = \lvert\tfrac12, -\tfrac12\rangle$。π 介子构成三重态，$I = 1$，$\lvert\pi^+\rangle = \lvert 1, +1\rangle$、$\lvert\pi^0\rangle = \lvert 1, 0\rangle$、$\lvert\pi^-\rangle = \lvert 1, -1\rangle$。强相互作用在同位旋空间转动下不变，所以总同位旋 $I$ 及其第三分量 $I_3$ 守恒，一个多重态内的各态质量相同，至电磁与夸克质量修正而止。对轻夸克的强子，$Q = I_3 + \tfrac12(B + S)$（**盖尔曼–西岛关系**）。
:::

在夸克模型中，同位旋就是交换 $u$ 与 $d$ 的对称性：$u$ 的 $I_3 = +\tfrac12$，$d$ 的 $I_3 = -\tfrac12$。它之所以是一个好对称性，不是因为两个夸克的质量相等，而是因为它们都只有几 MeV，与几百 MeV 的强子尺度相比微不足道。

同位旋守恒预言截面之比，用的正是 [[quantum-1/angular-momentum]] 中合成角动量的那些克莱布希–戈登系数。

::: theorem 同位旋与 π 介子产生之比 {#thm-isospin-ratio}
若强相互作用守恒同位旋，则在同一能量附近有

$$
\frac{\sigma(p + p \to d + \pi^+)}{\sigma(n + p \to d + \pi^0)} = 2 .
$$
:::

::: proof
氘核的 $I = 0$（它是唯一束缚的双核子态，而它 $I = 1$ 的伙伴——束缚的 $pp$ 或 $nn$——并不存在）。所以 $d + \pi$ 的 $I = 1$，末态为 $\lvert d\pi^+\rangle = \lvert 1, 1\rangle$ 与 $\lvert d\pi^0\rangle = \lvert 1, 0\rangle$。

对初态，把两个同位旋 $\tfrac12$ 的核子合成：$\lvert pp\rangle = \lvert 1, 1\rangle$，而 $\lvert np\rangle = \tfrac{1}{\sqrt2}\bigl(\lvert 1, 0\rangle - \lvert 0, 0\rangle\bigr)$（单态的符号约定除外）。同位旋守恒意味着振幅只联系相同 $I$ 的态，并且由维格纳–埃卡特定理，它在多重态内对每个 $I_3$ 都相同：记作 $\mathcal{M}_1$。于是

$$
\mathcal{M}(pp \to d\pi^+) = \mathcal{M}_1, \qquad \mathcal{M}(np \to d\pi^0) = \tfrac{1}{\sqrt2}\mathcal{M}_1 ,
$$

$np$ 中 $I = 0$ 的部分没有贡献。截面正比于振幅的平方，而除微小质量差外相空间相同，所以比值为 $1/(1/2) = 2$。实验同意。
:::

::: example Δ 共振 {#ex-delta}
在 $1232\,\mathrm{MeV}$ 附近，π–核子散射的截面由 $\Delta$ 共振主导，它的 $I = \tfrac32$。用 $\lvert\pi^+p\rangle = \lvert\tfrac32, \tfrac32\rangle$ 与 $\lvert\pi^-p\rangle = \sqrt{\tfrac13}\lvert\tfrac32, -\tfrac12\rangle - \sqrt{\tfrac23}\lvert\tfrac12, -\tfrac12\rangle$，预言峰处弹性截面之比 $\sigma(\pi^+p \to \pi^+p) : \sigma(\pi^-p \to \pi^-p) : \sigma(\pi^-p \to \pi^0n)$。
::: solution
共振处只有 $I = \tfrac32$ 的振幅 $\mathcal{M}_{3/2}$ 要紧；令 $\mathcal{M}_{1/2} = 0$。把 $\tfrac32$ 多重态内的各态联系起来的同位旋转动不改变振幅，所以

$$
\mathcal{M}(\pi^+p \to \pi^+p) = \mathcal{M}_{3/2}, \qquad \mathcal{M}(\pi^-p \to \pi^-p) = \tfrac13\mathcal{M}_{3/2},
$$

第二个式子之所以成立，是因为初末态各自带着其 $I = \tfrac32$ 成分的系数 $\sqrt{1/3}$。对电荷交换，末态是 $\lvert\pi^0n\rangle = \sqrt{\tfrac23}\lvert\tfrac32, -\tfrac12\rangle + \sqrt{\tfrac13}\lvert\tfrac12, -\tfrac12\rangle$，所以 $\mathcal{M}(\pi^-p \to \pi^0n) = \sqrt{\tfrac13}\sqrt{\tfrac23}\mathcal{M}_{3/2} = \tfrac{\sqrt2}{3}\mathcal{M}_{3/2}$。取平方，截面之比为

$$
1 : \tfrac19 : \tfrac29 = 9 : 1 : 2 .
$$

$\pi^-p$ 的总截面是 $\pi^+p$ 的 $\tfrac19 + \tfrac29 = \tfrac13$，实测峰约 $200\,\mathrm{mb}$ 与 $70\,\mathrm{mb}$，与此相合。费米在芝加哥的小组于 1951–52 年测出这些截面，那是 $\Delta$ 的第一个证据。
:::
:::

## SU(3) 味与八重道 {#su3}

随着奇异粒子的到来，出现了一个更大也更粗糙的对称性。把奇异数 $S$ 加到 $I_3$ 上，默里·盖尔曼与独立地尤瓦尔·内埃曼（Yuval Ne'eman）1961 年注意到，轻强子排成有八个或十个成员的花样，正是群 SU(3) 的表示。盖尔曼称之为**八重道**（Eightfold Way）。

以 $I_3$ 为横轴、奇异数（或超荷 $Y = B + S$）为纵轴作图，质量最低的八个自旋 $\tfrac12$ 重子构成一个中心有两个态的六角形：

| $S$ | 成员（$I_3$ 从左到右） | 质量（MeV） |
|---|---|---|
| $0$ | $n$、$p$ | 939.6、938.3 |
| $-1$ | $\Sigma^-$、$\Sigma^0$ 与 $\Lambda$、$\Sigma^+$ | 1197.4、1192.6 与 1115.7、1189.4 |
| $-2$ | $\Xi^-$、$\Xi^0$ | 1321.7、1314.9 |

八个赝标介子 $\pi^{\pm,0}$、$K^{+,0}$、$\bar K^{0}$、$K^-$ 与 $\eta$ 构成同样的花样，而自旋 $\tfrac32$ 重子构成一个十个成员的三角形，即**十重态**（decuplet）：

| $S$ | 成员 | 质量（MeV） |
|---|---|---|
| $0$ | $\Delta^-$、$\Delta^0$、$\Delta^+$、$\Delta^{++}$ | 1232 |
| $-1$ | $\Sigma^{*-}$、$\Sigma^{*0}$、$\Sigma^{*+}$ | 1385 |
| $-2$ | $\Xi^{*-}$、$\Xi^{*0}$ | 1533 |
| $-3$ | $\Omega^-$ | ?（1962 年时） |

若 SU(3) 精确，一个多重态的所有成员质量都相同。它是破缺的，主要因为 $s$ 夸克重于 $u$ 与 $d$，所以质量随奇异数的减少而增大。对破缺取一阶，盖尔曼与奥库波（Susumu Okubo）导出了质量关系；对十重态，他们预言各行之间**等间距**。

::: example 预言 Ω 粒子 {#ex-omega}
1962 年的 CERN 会议上，十重态只知九个成员。用等间距预言第十个的质量、奇异数与电荷，并说明它必须如何衰变。
::: solution
表中相邻行的间距为 $1385 - 1232 = 153$ 与 $1533 - 1385 = 148\,\mathrm{MeV}$，平均约 $150\,\mathrm{MeV}$。于是第四行约在 $1533 + 150 \approx 1680\,\mathrm{MeV}$。这个粒子位于顶角，$I = 0$、$S = -3$；由盖尔曼–西岛关系，$Q = 0 + \tfrac12(1 - 3) = -1$。在夸克模型中它是 $sss$。

它的衰变是妙处所在。$B = 1$ 且 $S = -3$ 的最轻状态是 $\Xi + \bar K$，约 $1315 + 494 = 1809\,\mathrm{MeV}$，比 $\Omega^-$ 的质量还大。所以不存在守恒奇异数的强衰变，$\Omega^-$ 必须弱衰变，使 $S$ 改变一个单位：$\Omega^- \to \Xi^0\pi^-$ 或 $\Lambda K^-$，寿命为 $10^{-10}\,\mathrm{s}$ 量级，长到能留下一条可见的径迹。1964 年它在布鲁克海文的一张气泡室照片中被找到（尼古拉斯·萨米奥斯（Nicholas Samios）与合作者们），质量 $1672\,\mathrm{MeV}$，寿命 $0.82\times10^{-10}\,\mathrm{s}$。
:::
:::

这些花样急切地要求一个解释，1964 年盖尔曼与茨威格给出了它：多重态就是把三个基础对象——构成 SU(3) 基本三重态的 $u$、$d$、$s$——组合起来所得到的东西。一对 $q\bar q$ 给出 $3 \otimes \bar 3 = 8 \oplus 1$，即介子八重态加一个单态；三个夸克给出 $3 \otimes 3 \otimes 3 = 10 \oplus 8 \oplus 8 \oplus 1$，其中含十重态与八重态。十重态是味的完全对称组合，它与对称的自旋相乘，正是当初引入色的缘由（[[particles/standard-model]]）。八重道的味 SU(3) 是轻夸克质量的一个近似的、偶然的对称性；QCD 的色 SU(3) 则是精确的，而且是规范对称性。

::: quiz
$\Xi^{*0}$（十重态 $S = -2$、$I_3 = +\tfrac12$ 那一行）有什么样的夸克成分与电荷？
- [x] $uss$，电荷 $0$
- [ ] $dss$，电荷 $-1$
- [ ] $uds$，电荷 $0$
- [ ] $sss$，电荷 $-1$
::: solution
奇异数 $-2$ 意味着两个 $s$ 夸克。第三个夸克的 $I_3 = +\tfrac12$，所以它是 $u$。电荷：$\tfrac23 - \tfrac13 - \tfrac13 = 0$，与 $Q = I_3 + \tfrac12(B + S) = \tfrac12 + \tfrac12(1 - 2) = 0$ 相合。$dss$ 态是 $\Xi^{*-}$，$uds$ 属于 $S = -1$ 那一行，$sss$ 是 $\Omega^-$。
:::
:::

## 规范对称性 {#gauge}

对称性在粒子物理中最深刻的应用，是决定相互作用本身。电荷守恒来自在**全局**相位变换 $\psi \to e^{iq\theta}\psi$——每一点都相同——下的不变性。假如我们转而要求在**局域**变换 $\psi \to e^{iq\chi(\mathbf{r}, t)/\hbar}\psi$ 下的不变性，$\chi$ 为任意函数。自由薛定谔方程就不再保持不变，因为其中出现了 $\chi$ 的导数。要恢复不变性，唯一的办法是引入一个以补偿方式改变的场，而这个场原来就是电磁学。

::: proposition 局域相位不变性要求规范场 {#prop-gauge}
电荷为 $q$、处于势 $\phi$ 与 $\mathbf{A}$ 中的粒子的薛定谔方程

$$
i\hbar\pdv{\psi}{t} = \left[\frac{1}{2m}\bigl(-i\hbar\nabla - q\mathbf{A}\bigr)^2 + q\phi\right]\psi ,
$$

在如下同时变换下保持形式不变

$$
\psi \to \psi' = e^{iq\chi/\hbar}\psi, \qquad \mathbf{A} \to \mathbf{A}' = \mathbf{A} + \nabla\chi, \qquad \phi \to \phi' = \phi - \pdv{\chi}{t},
$$

对任意可微函数 $\chi(\mathbf{r}, t)$。场 $\mathbf{E} = -\nabla\phi - \partial_t\mathbf{A}$ 与 $\mathbf{B} = \nabla\times\mathbf{A}$ 保持不变。
:::

::: proof
记 $\mathbf{D} = \nabla - iq\mathbf{A}/\hbar$，则动能算符为 $-\hbar^2\mathbf{D}^2/2m$。于是

$$
\mathbf{D}'\psi' = \Bigl(\nabla - \frac{iq}{\hbar}\mathbf{A} - \frac{iq}{\hbar}\nabla\chi\Bigr)\bigl(e^{iq\chi/\hbar}\psi\bigr) = e^{iq\chi/\hbar}\Bigl(\nabla\psi + \frac{iq}{\hbar}\nabla\chi\,\psi - \frac{iq}{\hbar}\mathbf{A}\psi - \frac{iq}{\hbar}\nabla\chi\,\psi\Bigr) = e^{iq\chi/\hbar}\mathbf{D}\psi .
$$

对同一恒等式再作用一次（作用于 $\mathbf{D}\psi$，它带着同样的相位变换），得 $\mathbf{D}'^2\psi' = e^{iq\chi/\hbar}\mathbf{D}^2\psi$。对时间导数，$(i\hbar\partial_t - q\phi')\psi' = e^{iq\chi/\hbar}\bigl(i\hbar\partial_t\psi - q\partial_t\chi\,\psi - q\phi\psi + q\partial_t\chi\,\psi\bigr) = e^{iq\chi/\hbar}(i\hbar\partial_t - q\phi)\psi$。所以 $\psi'$ 的方程两边都是 $\psi$ 的方程对应两边的 $e^{iq\chi/\hbar}$ 倍，一方成立当且仅当另一方成立。最后，$\nabla\times\nabla\chi = 0$ 使 $\mathbf{B}$ 不变，而 $-\nabla(-\partial_t\chi) - \partial_t\nabla\chi = 0$ 使 $\mathbf{E}$ 不变。
:::

倒过来读，这个命题说的是：若物理定律要在带电场的局域相位变换下不变，就必须存在一个矢量场 $(\phi, \mathbf{A})$，以恰恰这样的方式与电荷耦合。光子就是这个场的量子，而且它必须无质量，因为质量项不是规范不变的。杨振宁与罗伯特·米尔斯（Robert Mills）1954 年把这一思想推广到变换不可交换的对称性，如 SU(2) 与 SU(3)。那时规范场自身就带荷、彼此相互作用：这就是 QCD 的胶子，以及电弱理论的 $W$ 与 $Z$——它们的质量来自希格斯机制。[[particles/standard-model]] 的全部结构，都来自选定规范群 $\mathrm{SU}(3)\times\mathrm{SU}(2)\times\mathrm{U}(1)$ 与费米子的表示。

::: history 粒子物理中的对称性
海森堡 1932 年引入同位旋，维格纳自 1920 年代末起发展了对称群在量子力学中的应用。杨振宁与米尔斯 1954 年提出非阿贝尔规范理论。李政道与杨振宁 1956 年 6 月对宇称守恒提出质疑；吴健雄的钴 60 实验——与欧内斯特·安布勒（Ernest Ambler）、雷蒙德·海沃德（Raymond Hayward）、戴尔·霍普斯（Dale Hoppes）、拉尔夫·哈德森（Ralph Hudson）合作——于 1957 年 1 月完成，与加文、莱德曼、韦恩赖希以及弗里德曼、特莱格迪的 μ 子衰变实验同时。戈德哈贝尔、格罗德津斯与苏尼亚尔 1958 年测出中微子螺旋度。盖尔曼与内埃曼 1961 年提出八重道，$\Omega^-$ 于 1964 年被发现，同年克里斯蒂、克罗宁、菲奇与图尔莱发现了 CP 破坏。萨哈罗夫 1967 年提出了他对物质–反物质不对称的条件。小林诚与益川敏英 1973 年用三代夸克解释了 CP 破坏，$B$ 介子中的大 CP 破坏于 2001 年被观测到。
:::

## 后续内容 {#leads}

[[#prop-gauge]] 的规范原理是量子场论课程的出发点，标准模型的拉氏量就由它建构。规范对称性的自发破缺，即 [[particles/standard-model]] 的希格斯机制，在超导中有一个类比（[[condensed-matter/magnetism-superconductivity]]），光子在超导体内实际上获得了质量。味对称性及其破缺仍是一个活跃的领域：CKM 幺正性的精确检验、中微子振荡中 CP 破坏的寻找，以及中子与电子电偶极矩的搜索——后者同时破坏 P 与 T。CP 破坏的宇宙学后果在 [[gravitation/cosmology]]。

::: summary
- 由与 $H$ 对易的幺正算符表示的对称性给出一个守恒律：连续对称性给出相加性量子数（动量、电荷），分立对称性给出乘积性量子数（宇称、C 宇称）。
- 强与电磁相互作用守恒 P、C、T 与夸克味；弱相互作用最大程度地破坏 P 与 C，轻微地破坏 CP，并改变味。一切相互作用都守恒 CPT。
- 宇称：$P = \eta(-1)^\ell$；由 $\pi^-d \to nn$ 知 π 介子的 $P = -1$。$q\bar q$ 介子有 $P = (-1)^{\ell+1}$ 与 $C = (-1)^{\ell+S}$。
- 吴健雄的 ${}^{60}\mathrm{Co}$ 实验（1957）发现 β 电子优先逆着核自旋发射：宇称破坏。中微子是左手的；螺旋度压低使 $\pi \to e\nu$ 比 $\pi \to \mu\nu$ 少到 $1.3\times10^{-4}$。
- 中性 K 介子混合；CP 本征态为 $K_{1,2} = (K^0 \pm \bar K^0)/\sqrt2$。衰变 $K_L \to \pi\pi$（1964）表明 CP 破坏，$\varepsilon \approx 2.2\times10^{-3}$，由 CKM 相位解释；物质占优还需要更多。
- 同位旋是强相互作用的 $u$–$d$ 对称性，它把强子分组成多重态，并预言 $\sigma(pp \to d\pi^+)/\sigma(np \to d\pi^0) = 2$ 以及 $\Delta$ 峰处的 $9:1:2$ 等比值。
- SU(3) 味（八重道）把强子组织成八重态与十重态，预言了 $\Omega^-$（1964 年找到），并引出了夸克。
- 局域（规范）不变性要求一个规范场：U(1) 给出电磁学，SU(3) 与 SU(2)×U(1) 给出 QCD 与电弱理论。
:::

(a) 允许，电磁：电荷、C（$+1 \to (-1)^2$）及其他一切守恒。(b) 禁止：它破坏轻子数（$0 \to 1$）与角动量（一个自旋 $\tfrac12$ 的粒子不可能变成两个总角动量为整数的自旋 $\tfrac12$ 粒子）；真实的衰变包含 $\bar\nu_e$。(c) 允许，弱：奇异数由 $+1$ 变为 $0$。(d) 禁止：它破坏重子数（$1 \to 0$）与轻子数；这一模式下的质子寿命超过 $10^{34}$ 年（超级神冈）。(e) 允许，强：电荷、重子数、奇异数与同位旋（$\tfrac32 \to \tfrac12 \otimes 1$）全部守恒；历时约 $5\times10^{-24}\,\mathrm{s}$。

::: exercise 短寿命 K 介子能飞多远？ {level=2 check="53.9"}

::: exercise 用数字看 CP 破坏 {level=2 check="1.97e-3"}
振幅比 $\eta_{+-} = A(K_L \to \pi^+\pi^-)/A(K_S \to \pi^+\pi^-)$ 的大小为 $2.232\times10^{-3}$。已知 $\tau_L = 5.116\times10^{-8}\,\mathrm{s}$、$\tau_S = 0.8954\times10^{-10}\,\mathrm{s}$、$B(K_S \to \pi^+\pi^-) = 0.692$，求分支比 $B(K_L \to \pi^+\pi^-)$。
::: hint
部分宽度正比于振幅的平方：$\Gamma(K_L \to \pi^+\pi^-) = \lvert\eta_{+-}\rvert^2\,\Gamma(K_S \to \pi^+\pi^-)$。分支比是部分宽度乘以寿命。
:::
::: solution

::: exercise θ–τ 疑难 {level=3}
一个自旋 $0$ 的粒子 (a) 衰变为两个 π 介子，(b) 衰变为三个 π 介子。证明若宇称守恒，(a) 的末态宇称为 $+1$；而 (b) 中若所有相对轨道角动量都为零，宇称为 $-1$。更一般地证明：对三个 π 介子，π 1 与 π 2 之间的角动量为 $\ell_{12}$、它们的质心与 π 3 之间为 $\ell_3$，则总 $J = 0$ 要求 $\ell_{12} = \ell_3$，从而无论 $\ell$ 是多少宇称都是 $-1$。据此得出结论：若宇称守恒，$\theta^+ \to \pi^+\pi^0$ 与 $\tau^+ \to \pi^+\pi^+\pi^-$ 不可能来自同一种粒子。
::: hint
自旋为零的 π 介子不自带自旋，所以总角动量完全来自轨道。两个角动量 $\ell_{12}$ 与 $\ell_3$ 能合成为零，只有当它们相等。
:::
::: solution
(a) 两个 π 介子，各自内禀宇称 $-1$，处于相对轨道角动量 $\ell$ 的态，宇称为 $(-1)^2(-1)^\ell = (-1)^\ell$。母粒子自旋为 $0$ 而 π 介子没有自旋，所以角动量守恒要求 $\ell = 0$，宇称为 $+1$。

(b) 三个 π 介子的内禀宇称为 $(-1)^3 = -1$，再乘轨道因子 $(-1)^{\ell_{12}}(-1)^{\ell_3}$，因为每个相对坐标都被 P 反转。总角动量为 $\boldsymbol{\ell}_{12} + \boldsymbol{\ell}_3$，它为零只可能 $\ell_{12} = \ell_3$（三角条件 $\lvert\ell_{12} - \ell_3\rvert \le J$ 取 $J = 0$）。于是轨道因子为 $(-1)^{2\ell_3} = +1$，宇称为 $-1$，对一切允许的组态都如此，特别地，对所有 $\ell = 0$ 都如此。

两 π 介子态的母粒子宇称为 $+1$，三 π 介子态的母粒子宇称为 $-1$。若衰变中宇称守恒，母粒子的宇称就必须等于末态的宇称，所以一个自旋 $0$ 的粒子不可能两者都干。既然 $\theta^+$ 与 $\tau^+$ 的质量和寿命相同，李政道与杨振宁的结论是：更省事的假定是一种粒子，$K^+$，以及一个不守恒宇称的弱相互作用。
:::

::: exercise 概率流的规范不变性 {level=3}
对带势的薛定谔方程，概率流为 $\mathbf{j} = \frac{1}{m}\mathrm{Re}\bigl[\psi^*(-i\hbar\nabla - q\mathbf{A})\psi\bigr]$。(a) 证明 $\mathbf{j}$ 与 $\rho = \lvert\psi\rvert^2$ 在 [[#prop-gauge]] 的规范变换下不变。(b) 证明"朴素的"流 $\frac{1}{m}\mathrm{Re}[\psi^*(-i\hbar\nabla)\psi]$ 不是规范不变的，并说明为什么这意味着存在矢量势时它不能是一个物理可观测量。
::: hint
用 [[#prop-gauge]] 证明中的 $\mathbf{D}'\psi' = e^{iq\chi/\hbar}\mathbf{D}\psi$，以及 $(-i\hbar\nabla - q\mathbf{A}) = -i\hbar\mathbf{D}$。
:::
::: solution
(a) $\rho' = \lvert e^{iq\chi/\hbar}\psi\rvert^2 = \lvert\psi\rvert^2$。对电流，$(-i\hbar\nabla - q\mathbf{A}')\psi' = -i\hbar\mathbf{D}'\psi' = e^{iq\chi/\hbar}(-i\hbar\mathbf{D}\psi)$，而 $\psi'^* = e^{-iq\chi/\hbar}\psi^*$，所以相位在 $\psi'^*(-i\hbar\mathbf{D}'\psi') = \psi^*(-i\hbar\mathbf{D}\psi)$ 中互相抵消。于是 $\mathbf{j}' = \mathbf{j}$。

(b) $\psi'^*(-i\hbar\nabla)\psi' = \psi^*(-i\hbar\nabla)\psi + q\nabla\chi\,\lvert\psi\rvert^2$，所以朴素的流改变 $q\lvert\psi\rvert^2\nabla\chi/m$，一个任意的量，因为 $\chi$ 是任意的。两个描述完全相同的电场与磁场的规范会给出不同的预言，所以这个量不可测量。物理的速度是 $(\mathbf{p} - q\mathbf{A})/m$，即"动能"动量，而不是 $\mathbf{p}/m$。同样的逻辑，把相位换成矩阵，就决定了夸克在 QCD 中如何与胶子耦合。
:::
