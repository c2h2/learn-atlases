在行驶的火车车厢里向前抛出的球，相对车厢有一个速度，相对站台又有另一个速度。两个数都正确。它们说的是不同的参考系，背后并不存在第三个不依附于任何参考系的速率在等着我们。牛顿力学对此毫不在意。[[mechanics/newton-laws]] 中的定律写在惯性系中，而匀速运动的车厢和站台一样是好的惯性系。

牛顿力学额外提供的、也就是本讲要用坐标写出来的，是从一个惯性系过渡到另一个惯性系的明确规则。时间只有一个，所有参考系共用。在同一时刻量得的长度在每个参考系中都有同样的值。于是速度相减。加速度却不：同一个自由质点在每个惯性系中有同样的加速度，这正是只依赖物体间距离的力律能在一切惯性系中采取同一形式的原因。

这一整套东西就是伽利略变换。它是 1632 年船舱论证背后的运动学，是由空速和风速算出地速的每一次计算背后的运动学，也是车厢里松开手、球落回你脚边这一事实背后的运动学。它同样是一个规则，而本图谱接下来就要拒绝把它交给光。按 [[magnetism/electromagnetic-waves]] 的证据，光波在真空中以由真空常量决定的速率传播，而不是以相对某个可以被追上的介质量出的速率传播。最后一节将用直接代入说明：伽利略换系并不保持这列波。如何修补，是 [[relativity]] 的主题。

在本讲通篇，一个**事件**是发生在某个地点某个时刻的事情——一次闪光、一次碰撞、一个质点经过一个标记。不同参考系对同一事件给出不同的坐标，但对它是哪个事件并无分歧。

## 惯性系 {#inertial}

[[mechanics/newton-laws]] 中的第一定律是参考系的挑选规则。我们把它改写成本课程要一直使用的形式，因为后面的一切都是惯性系彼此之间的比较。

::: definition 惯性系 {#def-inertial}
**自由质点**是所受合力为零的质点。若在一个参考系中，每个自由质点都做匀速运动——沿直线以恒定速率运动，或保持静止——则称该参考系为**惯性系**。相对惯性系匀速运动的参考系本身也是惯性系。相对惯性系加速或转动的参考系则不是。
:::

对本讲的力学而言，地面是足够好的惯性系。地球自转的微小影响略去不计，这与 [[mechanics/newton-laws]] 中的处理一致。正在刹车的车厢、正在加速的电梯和旋转转盘都不是惯性系。在那些参考系中自由质点不做匀速运动，于是同样的力律按 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 去写时，其中的 $\mathbf{a}$ 若是在那些系中测得的，方程就不成立。

在直轨道上以恒定速率行驶的车厢是惯性系。站台也是。伽利略变换的全部内容，就是这两个参考系赋予同一个事件的坐标之间的关系。变换中没有哪一处说这两个系中哪一个才是“真正”静止的。我们正在准备的原理是说：在封闭车厢内部做的任何力学实验都无法裁决这个问题。

::: intuition 检验在代数之前
若拿不准一个参考系是否可用，别管公式，去看自由质点在做什么。匀速运动意味着该系是惯性系，第二定律可以照写照用。任何其他表现意味着该系相对某个惯性系加速或转动，而减去一个速度修不好它。下面的伽利略变换只联系惯性系与惯性系。它不是拿去处理刹车汽车的配方。
:::

## 事件与标准配置 {#events}

写变换之前，先把坐标轴的摆法定下来。物理不依赖这个选择。凌乱的摆法产出凌乱的代数，产出的事件却是同一批。

::: definition 事件与标准配置 {#def-standard}
一个**事件**在参考系 $S$ 中有坐标 $(t, x, y, z)$：一个时刻和一个位置。第二个惯性系 $S'$ 与 $S$ 处于**标准配置**，当且仅当三条都成立。$S'$ 的坐标轴与 $S$ 的坐标轴平行。$S'$ 的原点沿 $S$ 的正 $x$ 轴以恒定速率 $v$ 运动，$v$ 可正可负，但必须恒定。两原点在 $t = 0$ 重合，且那一刻两只钟读数相同：事件“两原点重合”在两个系中都是 $(0,0,0,0)$。
:::

任何一对惯性系都可以通过挑选原点、时间零点和 $x$ 轴的方向被安置成标准配置。我们每次计算前都先这样做。$S'$ 相对 $S$ 的速度 $\mathbf{v}$ 于是有分量 $(v, 0, 0)$。$S$ 相对 $S'$ 的速度是 $(-v, 0, 0)$：车厢朝你的右方运动，站台就朝乘客的左方运动，速率相同。

坐标是我们贴在事件上的标签，不是质点随身搬运的物件。换参考系改变的是标签，不改变质点，也不改变哪一对事件是“出手”和“接住”。

## 伽利略变换 {#transformation}

牛顿力学里标签之间的关系现在短到可以写在一行里。我们把它陈述为定义，因为在本讲内部它就是假设。下一讲会替换它。从它能推出什么，我们就推出什么。

::: definition 伽利略变换 {#def-galilean}
设 $S'$ 与 $S$ 处于标准配置，沿共享的 $x$ 轴以恒定速度 $v$ 运动。把一个事件在 $S$ 中的坐标变到它在 $S'$ 中坐标的**伽利略变换**是

$$
x' = x - v t, \qquad y' = y, \qquad z' = z, \qquad t' = t.
$$ {#eq-galilean}

其逆变换，从 $S'$ 回到 $S$，是

$$
x = x' + v t', \qquad y = y', \qquad z = z', \qquad t = t'.
$$ {#eq-galilean-inverse}
:::

[[#eq-galilean]] 里压着两条假设，而它们后来对光都被抛弃。第一条是 $t' = t$：每个参考系共用一个时间。按这一规则，在原点对齐的两只钟在任何地方都保持同步，无论它们的运动如何。第二条是：一把沿 $x$ 放置、相对 $S$ 静止的尺，在 $S'$ 中有同样的长度。若它的两端在同一个公共时刻 $t$ 位于 $x_1$ 和 $x_2$，则

$$
x'_2 - x'_1 = (x_2 - v t) - (x_1 - v t) = x_2 - x_1.
$$

$v t$ 项之所以相消，是因为两端记录于同一个 $t$，也是因为 $t'$ 与 $t$ 没有差别。横向长度因同样的原因纹丝不动：$y' = y$，$z' = z$。在伽利略变换下，同时事件之间的距离是不变量，时间间隔是不变量。速度不是。

公式 $x' = x - v t$ 说的就是：$S'$ 的原点——动点 $x = v t$——带着标签 $x' = 0$。$x$ 轴上其余每一点都从那个原点量起，用的是与 $S$ 的米一致的米。

::: example 一个事件，两个标签 {#ex-event}
一个事件在 $S$ 中的坐标是 $x = 30.0\,\mathrm{m}$、$t = 2.00\,\mathrm{s}$。参考系 $S'$ 与 $S$ 处于标准配置，速率 $v = 10.0\,\mathrm{m/s}$。求同一事件在 $S'$ 中的坐标。
::: solution
直接使用 [[#eq-galilean]]。时间是共享的：

$$
t' = t = 2.00\,\mathrm{s}.
$$

沿相对运动方向的空间标签是

$$
x' = 30.0 - (10.0)(2.00) = 10.0\,\mathrm{m},
$$

而 $y' = y$，$z' = z$。事件并不因为 $10.0 \neq 30.0$ 就成了另一个事件。它还是同一次闪光，只是由一个在 $t = 2.00\,\mathrm{s}$ 时已沿 $x$ 移走 $20.0\,\mathrm{m}$ 的原点记录下来。逆变换校验：$x = x' + v t' = 10.0 + (10.0)(2.00) = 30.0\,\mathrm{m}$。

若第二个事件发生在同一个 $t$、位于 $x = 34.0\,\mathrm{m}$，它的 $x'$ 是 $14.0\,\mathrm{m}$。两个事件的间距在两个系中都是 $4.00\,\mathrm{m}$。这个相消就是本讲的长度规则，而且它本质地用到了 $t' = t$。
:::
:::

## 速度与加速度 {#velocity}

质点是事件的曲线，在 $S$ 中是 $x(t)$。同一条曲线在 $S'$ 中有描述 $x'(t')$。对变换求导得到速度之间的关系，再求导一次得到加速度之间的关系。第一个关系是相减，第二个是恒等。

::: theorem 伽利略速度相加 {#thm-velocity}
设 $S'$ 与 $S$ 处于标准配置、相对 $S$ 以恒定速度 $v$ 运动，一个质点在 $S$ 中速度的 $x$ 分量为 $u = \deriv{x}{t}$。在 $S'$ 中该分量为

$$
u' = u - v.
$$ {#eq-u-gal}

横向分量不变：若 $u_y = \deriv{y}{t}$、$u_z = \deriv{z}{t}$，则 $u'_y = u_y$，$u'_z = u_z$。向量形式，若 $\mathbf{v}_{\mathrm{frame}}$ 是 $S'$ 相对 $S$ 的速度，则

$$
\mathbf{u}' = \mathbf{u} - \mathbf{v}_{\mathrm{frame}}.
$$ {#eq-u-gal-vec}
:::

::: proof
对 [[#eq-galilean]] 关于时间求导。因为 $t' = t$，对 $t'$ 求导与对 $t$ 求导是同一个操作。参考系速度 $v$ 恒定，所以

$$
u' = \deriv{x'}{t'} = \deriv{}{t}(x - v t) = \deriv{x}{t} - v = u - v.
$$

横向坐标由 $y' = y$ 得 $u'_y = u_y$，$z$ 同理。向量方程就是这三个分量写在一起。逆变换为 $u = u' + v$：它是 [[#eq-galilean-inverse]] 的求导形式，也是 [[#eq-u-gal]] 解出 $u$ 的形式。
:::

“相加”这个名字对 [[#eq-u-gal]] 略有误导，因为当你要求的是 $u'$ 时它其实做的是相减。规则是从逆变换那里挣来这个名字的：相对站台的速度等于相对车厢的速度加上车厢的速度。两个方向都会出现在下面的算例里。方程从未说的是：质点只有一个速度。它在每个参考系中各有一个速度，而这两个数相差 $v$。

::: proposition 加速度的不变性 {#prop-accel}
在 [[#thm-velocity]] 的前提下，质点的加速度在 $S$ 与 $S'$ 中相同。若 $\mathbf{a} = \deriv{\mathbf{u}}{t}$、$\mathbf{a}' = \deriv{\mathbf{u}'}{t'}$，则

$$
\mathbf{a}' = \mathbf{a}.
$$ {#eq-a-inv}
:::

::: proof
对 [[#eq-u-gal-vec]] 关于时间求导。参考系速度恒定，它的导数为零，且 $t' = t$，所以

$$
\mathbf{a}' = \deriv{\mathbf{u}'}{t} = \deriv{}{t}\bigl(\mathbf{u} - \mathbf{v}_{\mathrm{frame}}\bigr) = \deriv{\mathbf{u}}{t} = \mathbf{a}.
$$

逐分量看，$a'_x = \deriv{}{t}(u - v) = a_x$，$a'_y = a_y$，$a'_z = a_z$。若 $v$ 不恒定，这一步就失效：正在刹车的车厢不是惯性系，[[#eq-galilean]] 也不是该用的变换。
:::

::: corollary 相对速度 {#cor-relative}
设两个质点在惯性系 $S$ 中的速度为 $\mathbf{u}_1$ 和 $\mathbf{u}_2$。它们的相对速度 $\mathbf{u}_1 - \mathbf{u}_2$ 在每个与 $S$ 成伽利略变换关系的惯性系中有相同的值。
:::

::: proof
在 $S'$ 中，[[#eq-u-gal-vec]] 给出 $\mathbf{u}'_1 = \mathbf{u}_1 - \mathbf{v}_{\mathrm{frame}}$、$\mathbf{u}'_2 = \mathbf{u}_2 - \mathbf{v}_{\mathrm{frame}}$。相减：

$$
\mathbf{u}'_1 - \mathbf{u}'_2 = \mathbf{u}_1 - \mathbf{u}_2.
$$

参考系速度相消。两物体的接近速率、以及一个物体相对另一个的速度，都是伽利略不变量。而任一物体相对站台的速度不是。
:::

::: example 车厢里的球 {#ex-train}
车厢相对站台以 $20.0\,\mathrm{m/s}$ 运动，处于标准配置，于是 $v = 20.0\,\mathrm{m/s}$。一名乘客相对车厢沿 $x$ 方向向前以 $15.0\,\mathrm{m/s}$ 抛出一个球。求球相对站台的速度。再把题目改成相对车厢向后以 $15.0\,\mathrm{m/s}$ 抛出，重做一遍。
::: solution
把 $S$ 取作站台、$S'$ 取作车厢。投掷这个动作在车厢里描述得最直接，所以已知的数是 $u'$，而 [[#eq-u-gal]] 解出 $u$ 的形式就是站台速度：

$$
u = u' + v.
$$

向前：$u' = +15.0\,\mathrm{m/s}$，于是

$$
u = 15.0 + 20.0 = 35.0\,\mathrm{m/s}.
$$

向后：$u' = -15.0\,\mathrm{m/s}$，负号记录的是与车厢速度相反的投向，于是

$$
u = -15.0 + 20.0 = 5.00\,\mathrm{m/s}.
$$

两个结果都是站台速度。“速率是 $35.0\,\mathrm{m/s}$”与“速率是 $15.0\,\mathrm{m/s}$”可以同时为真，因为它们说的是不同的参考系。两个数都不是球单独拥有的属性。

球离手之后、忽略空气阻力期间，站台系中唯一的加速度是竖直的 $-g$，其中 $g = 9.80\,\mathrm{m/s^2}$。由 [[#prop-accel]]，车厢中的加速度与之相同。速度的水平分量在两个系中各自恒定，而这两个常数相差 $20.0\,\mathrm{m/s}$。
:::
:::

竖直上抛在二维里说明同一点，而且它就是缩成一只球的船舱论证。设乘客相对车厢把球竖直向上以 $15.0\,\mathrm{m/s}$ 抛出，并在同一高度接住。取向上为正。飞行时间是从 $u_y = 15.0\,\mathrm{m/s}$ 到 $u_y = -15.0\,\mathrm{m/s}$、在 $a_y = -9.80\,\mathrm{m/s^2}$ 下的时间，

$$
t = \frac{30.0}{9.80} = 3.06\,\mathrm{s}.
$$

在车厢里球的水平速度为零，所以球回到手中。在站台系中球自始至终有水平速度 $20.0\,\mathrm{m/s}$，在这 $3.06\,\mathrm{s}$ 内它沿站台前进的距离为

$$
(20.0)\left(\frac{30.0}{9.80}\right) = 61.2\,\mathrm{m}
$$

这两种描述都是完整的。落点相对乘客的位置是 [[#cor-relative]] 所说的那种不变量：球和手在每个伽利略参考系中有相同的水平速度，所以它们沿 $x$ 的间距不会拉开。

::: example 打在车窗上的雨 {#ex-rain}
在站台系中，雨以 $8.00\,\mathrm{m/s}$ 竖直下落。车厢沿正 $x$ 方向以 $20.0\,\mathrm{m/s}$ 运动。求雨相对车厢的速度、速率，以及雨与车窗相交时与竖直方向的夹角。
::: solution
取向下为负 $y$ 方向。在站台系中 $u_x = 0$、$u_y = -8.00\,\mathrm{m/s}$。车厢是 $S'$，$v = 20.0\,\mathrm{m/s}$。由 [[#eq-u-gal-vec]] 得

$$
u'_x = 0 - 20.0 = -20.0\,\mathrm{m/s}, \qquad u'_y = -8.00\,\mathrm{m/s}.
$$

雨相对车厢的速率为

$$
\abs{\mathbf{u}'} = \sqrt{(20.0)^2 + (8.00)^2} = \sqrt{464} = 21.5\,\mathrm{m/s}.
$$

与竖直方向的夹角 $\theta$ 满足

$$
\tan\theta = \frac{\abs{u'_x}}{\abs{u'_y}} = \frac{20.0}{8.00} = 2.50, \qquad \theta = 68.2^{\circ}.
$$

车窗上的雨痕向后倾斜。一位把 $8.00\,\mathrm{m/s}$ 说成“雨速”的乘客，说的是站台系的数值，他的伞角会因此撑错。把雨滴当作已经达到终速来对待时，它在两个系中的加速度都为零，与 [[#prop-accel]] 一致。速度不是零，而且两个系中的速度互不相等。
:::
:::

## 两条加法规则分道扬镳之处 {#rules}

[[#thm-velocity]] 就是本讲速度算术的全部。把它应用于光，它说出了某种尖锐的东西。若一列光脉冲在参考系 $S$ 中速度为 $+c$，则在相对 $S$ 以 $+v$ 运动的参考系中，同一脉冲的速度为 $c - v$。朝反方向发出的一列脉冲在 $S$ 中速度为 $-c$，在运动系中为 $-c - v$，所以其速率为 $c + v$。光如果服从伽利略规则，速率就应当是 $c \pm v$。

在日常速率下比值 $v/c$ 很小，这就是这条规则在力学中沿用至今的原因。取 $c = 2.99792458\times 10^{8}\,\mathrm{m/s}$、车厢 $20.0\,\mathrm{m/s}$，

$$
\frac{v}{c} = \frac{20.0}{2.99792458\times 10^{8}} = 6.67\times 10^{-8}.
$$

对一个光速做一次车厢速度大小的伽利略平移，至多使它改变不到千万分之一。对两个普通速度，[[#eq-u-gal]] 与图中所用相对论规则的分歧还要小得多。共线速度 $v$ 与 $u$ 的相对论合成，在 $c = 1$ 的单位下是 $(v+u)/(1+vu)$。把 $c$ 恢复回来，球的站台速度应为

$$
\frac{u' + v}{1 + u' v/c^{2}}
$$

而不是 $u' + v$。对 $15.0\,\mathrm{m/s}$ 和 $20.0\,\mathrm{m/s}$，分母中的修正为

$$
\frac{u' v}{c^{2}} = \frac{300}{c^{2}} = 3.34\times 10^{-15}.
$$

两种规则预言的站台速度相差这一量级的分数。任何球类实验都看不见它。伽利略规则不是我们在车厢里需要道歉的近似；它是下一讲推导的规则的正确低速极限，而在 $20\,\mathrm{m/s}$ 处，出于一切实际目的，这个极限已经到达。

有意思的数字是 $c$ 的分数——上面的图中两条规则在那里分家。算术很短，而这场比较是其后整门课程不断回头来的那一场。

::: example 零点二与零点三的光速 {#ex-tenths}
用伽利略规则把共线的两个速度 $0.200c$ 与 $0.300c$ 相加，再用以 $c$ 为单位的相对论规则 $(v+u)/(1+vu)$ 加一遍。
::: solution
伽利略相加——即 [[#eq-u-gal]] 的逆方向——就是普通算术：

$$
0.200c + 0.300c = 0.500c.
$$

相对论和，以 $c$ 为单位，是

$$
\frac{0.2 + 0.3}{1 + 0.2\times 0.3} = \frac{0.5}{1.06} = 0.471698\ldots,
$$

三位有效数字即 $0.472c$。代数正是表达式 $(0.2+0.3)/(1+0.2\times 0.3)$。相对论和比伽利略和小 $0.0283c$。本讲没有任何东西为相对论公式辩护过；它就是画在那张图上的规则，在下一讲由洛伦兹变换导出，记在这里是为了让分歧的大小成为一个算出来的数，而不是一句口号。在这些速率下分歧是百分之几；在车厢速率下它是 $10^{-15}$。
:::
:::

曾经期望从地球轨道得到的那种大小的以太风，是同一场比较配上更有名的数字。取 $v = 3.00\times 10^{4}\,\mathrm{m/s}$，约 $30\,\mathrm{km/s}$。于是

$$
\frac{v}{c} = 1.00\times 10^{-4}.
$$

伽利略相加会给光两个速率

$$
c - v = 2.99762458\times 10^{8}\,\mathrm{m/s}, \qquad c + v = 2.99822458\times 10^{8}\,\mathrm{m/s}.
$$

在 $3.00\times 10^{8}\,\mathrm{m/s}$ 这个速率上平移了 $30.0\,\mathrm{km/s}$。这正是十九世纪的以太理论要求干涉仪去找的效应的量级。测量本身留到下一讲再谈。此处唯一的主张是运动学的：$c \pm v$ 是 [[#thm-velocity]] 的预言，而 $c \pm v$ 也正是电磁学将来不肯接受的东西。

## 牛顿定律在每个惯性系中 {#newton}

加速度是不变量。第二定律把力与加速度联系起来。要让定律在每个惯性系中有同样的形式，力也必须是不变量，或者以相匹配的方式改变。初等力学的力恰好做到前一种，理由从 [[#eq-galilean]] 一眼就能看出，而一旦有介质掺进来，又很容易把它忘掉。

::: proposition 牛顿相对性 {#prop-newton}
设质点的质量 $m$ 在每个惯性系中都是同一个正数，并设作用在它的一切力都只是相互作用物体的位置差与它们的相对速度的函数。则 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 在一个惯性系中成立，当且仅当在以伽利略变换与它相联系的每个惯性系中、对同样的力也成立。
:::

::: proof
由 [[#prop-accel]]，$\mathbf{a}' = \mathbf{a}$。由关于 $m$ 的假设，乘积 $m\mathbf{a}$ 与 $m\mathbf{a}'$ 因而相同。剩下检查力。对任意两个质点，[[#eq-galilean]] 给出

$$
x'_2 - x'_1 = (x_2 - v t) - (x_1 - v t) = x_2 - x_1,
$$

$y$ 与 $z$ 同理。在共享时刻的每一坐标差都是不变量。由 [[#cor-relative]]，每一个相对速度也是不变量。只依赖这些量的力因而在 $S$ 与 $S'$ 中取相同的值。于是 $\mathbf{F}' = \mathbf{F}$，而 $\mathbf{F} = m\mathbf{a}$ 与 $\mathbf{F}' = m\mathbf{a}'$ 是同一条陈述。
:::

弹簧、牛顿引力、绳中的张力，都落在 [[#prop-newton]] 之内。它们的定律里只出现间距、或间距的变化率，此外一无所有。这就是为什么在一艘匀速航行的船的底舱里做力学实验无法察觉这项运动：力是实验室本来就认识的那些力，加速度也是。

[[#prop-newton]] 中的质量就是 [[mechanics/newton-laws]] 中的惯性质量。不给它配上依赖速率的因子。伽利略理论里没有任何迹象提示这样的因子，本课程其后也不会换个名字把它引进来。当动量和能量被重建时，进入其中的质量 $m$ 仍然是这个不变量。

关于力的假设不是可选项，而阻力是破坏它的标准做法。空气中的阻力依赖物体相对空气的速度，而不只是物体彼此相对的速度。若空气在某个参考系中静止，这个参考系就被力律挑了出来。开着窗的车厢不是封闭的船。下一节把这一观察应用到波上。

## 声音有一个静止系 {#sound}

小振幅声波相对空气以由空气决定的速率传播。在空气的静止系里把这个速率记作 $c_{\mathrm{s}}$。伽利略相加于是对声做它对球做过的事：在相对空气以速度 $v$ 运动的参考系中，沿正 $x$ 方向传播的声波速度为 $c_{\mathrm{s}} - v$，沿负 $x$ 方向传播的波速率为 $c_{\mathrm{s}} + v$。存在一个被偏爱的参考系：两个速率相等的那个系。

这种偏爱正是声的多普勒公式对“波源动”与“观察者动”不对称的原因。[[oscillations/sound]] 中的公式必须说明是谁相对空气在动。相对空气静止的波源与以同样速率相对空气运动的观察者，以及相对空气静止的观察者与运动的波源，即便速率相同，产生的移动也不一样。介质已经选定了一个参考系，剩下的事交给 [[#thm-velocity]]。这里没有任何东西与 [[#prop-newton]] 相抵触：作用在一团空气上的力依赖它周围的空气。波速是一种穿过某种材料的速率，而材料有静止系。

如果光是某种材料的振动——哪怕极其古怪的材料——同样的结构就照样适用。这种材料曾被称为发光以太。在以太的静止系中光向各个方向以 $c$ 传播；在相对以太以速度 $v$ 运动的实验室里，伽利略相加给出上面算过的速率 $c \pm v$。地球的轨道速率约 $30\,\mathrm{km/s}$，除非以太被完全拖着与地球同行，就会有一股同样量级的风掠过仪器。电磁学不服从这个模式。原因不是多普勒代数上的细节，而是真空方程定下了一个速率，却不给世界留下任何可供静止的介质。

## 电磁学为什么装不进去 {#maxwell}

在真空中，麦克斯韦方程组对电场与磁场各自推出波动方程，传播速率为

$$
c = \frac{1}{\sqrt{\mu_0 \eps_0}}.
$$

这里的常量是 $\mu_0 = 4\pi\times 10^{-7}\,\mathrm{N\,A^{-2}}$ 与 $\eps_0 = 8.854187817\times 10^{-12}\,\mathrm{C^{2}\,N^{-1}\,m^{-2}}$。它们的组合是

$$
\frac{1}{\sqrt{\mu_0 \eps_0}} = 2.99792458\times 10^{8}\,\mathrm{m/s},
$$

与定义值 $c = 2.99792458\times 10^{8}\,\mathrm{m/s}$ 一致，精确到所给 $\eps_0$ 能支撑的每一位。原始商比该定义值大约 $0.011\,\mathrm{m/s}$，落在所给 $\eps_0$ 末位一个单位的范围之内。波动方程里的这个速率，不是我们先在某个具名介质中测得一个速度再填进去的，而是由早已站在库仑定律和电流之间磁力里的两个常量拼装起来的。[[magnetism/electromagnetic-waves]] 推导了那列波。本讲要问的是：换一个参考系会对它做什么。

球面光壳是最干净的检验，而且只用代数。

::: proposition 光球面不服从伽利略变换 {#prop-sphere}
设在 $t = 0$ 于公共原点处的一次闪光产生一个球面波前，它在惯性系 $S$ 中是事件的集合

$$
x^{2} + y^{2} + z^{2} = c^{2} t^{2}.
$$ {#eq-sphere}

在 $v \neq 0$ 的伽利略变换 [[#eq-galilean]] 下，这些事件不满足 $x'^{2} + y'^{2} + z'^{2} = c^{2} t'^{2}$。
:::

::: proof
把 $x = x' + v t'$、$y = y'$、$z = z'$、$t = t'$ 代入 [[#eq-sphere]]：

$$
(x' + v t')^{2} + y'^{2} + z'^{2} = c^{2} t'^{2}.
$$

展开平方：

$$
x'^{2} + y'^{2} + z'^{2} + 2 v x' t' + v^{2} t'^{2} = c^{2} t'^{2}.
$$

当 $v \neq 0$ 时，交叉项 $2 v x' t'$ 和项 $v^{2} t'^{2}$ 不在波前的每一点上为零。方程 $x'^{2} + y'^{2} + z'^{2} = c^{2} t'^{2}$ 会要求二者在波前上恒等于零，而它们并不如此。看一个具体的点：事件 $x = c t$、$y = z = 0$ 在 $S$ 中位于波前上。它的像是 $x' = (c - v) t'$、$y' = z' = 0$，而 $(c - v)^{2} t'^{2} = c^{2} t'^{2}$ 强迫 $v = 0$ 或 $v = 2c$。一个速度为普通值 $v$ 的参考系，保不住“波前是以 $S'$ 的原点为中心、半径为 $c t'$ 的球”。
:::

在 $S'$ 中波前被拖着走。若坚持把展开后的方程读成一个球面，它的中心在移动，而半径并非沿每个方向都以同一个速率 $c$ 增长。这又是 $c \pm v$，只不过这一次是一整个球壳而不是一条光线。[[#prop-sphere]] 说的就是：伽利略运动学与普适的光速彼此矛盾，二者必弃其一。经由 [[#prop-newton]]，力学站在伽利略变换一边。真空波动方程站在单一速率 $c$ 一边。

同一种冲突还可以写成微分形式——它在场方程里出现时就是这个样子，而不只是在某一次闪光里。

::: theorem 波动方程不是伽利略不变的 {#thm-wave}
设场分量 $E$ 在 $S$ 中满足一维波动方程

$$
\pdv{^{2} E}{x^{2}} - \frac{1}{c^{2}}\pdv{^{2} E}{t^{2}} = 0,
$$

其中 $c$ 为常量。令 $x' = x - v t$、$t' = t$，$v$ 为非零常数。则作为 $x'$ 与 $t'$ 的函数，$E$ 一般不满足

$$
\pdv{^{2} E}{x'^{2}} - \frac{1}{c^{2}}\pdv{^{2} E}{t'^{2}} = 0.
$$
:::

::: proof
利用 $\partial x'/\partial x = 1$、$\partial t'/\partial x = 0$、$\partial x'/\partial t = -v$、$\partial t'/\partial t = 1$，一阶导数的链式法则为

$$
\pdv{E}{x} = \pdv{E}{x'}, \qquad \pdv{E}{t} = -v\,\pdv{E}{x'} + \pdv{E}{t'}.
$$

再求一次导。空间导数原样通过，

$$
\pdv{^{2} E}{x^{2}} = \pdv{^{2} E}{x'^{2}},
$$

而时间导数相当于把算子 $-v\,\partial/\partial x' + \partial/\partial t'$ 用两遍：

$$
\pdv{^{2} E}{t^{2}} = v^{2}\,\pdv{^{2} E}{x'^{2}} - 2v\,\frac{\partial^{2} E}{\partial x'\,\partial t'} + \pdv{^{2} E}{t'^{2}}.
$$

把这些代回 $S$ 中的波动方程并整理：

$$
\left(1 - \frac{v^{2}}{c^{2}}\right)\pdv{^{2} E}{x'^{2}} + \frac{2v}{c^{2}}\frac{\partial^{2} E}{\partial x'\,\partial t'} - \frac{1}{c^{2}}\pdv{^{2} E}{t'^{2}} = 0.
$$

若 $E$ 同时以同一个 $c$ 满足 $S'$ 中的波动方程，就必须没有混合导数项，且 $\partial^{2} E/\partial x'^{2}$ 的系数必须等于 $1$。当 $v \neq 0$ 时两条都失败。形如 $f(x - c t)$、在 $S$ 中求解的波，在新坐标下成为 $f\bigl(x' - (c - v) t'\bigr)$，速率是 $c - v$ 而不是 $c$。
:::

[[#thm-wave]] 不是说麦克斯韦方程组错了。它是说：如果参考系之间按 [[#eq-galilean]] 相联系，这些方程就不可能在每个惯性系中以同一个 $c$ 成立。必须有东西让步。十九世纪末摆在面前的可能性是这些。其一：方程只在某一个被偏爱的参考系——以太的静止系——中成立，其余参考系看到 $c \pm v$。其二：运动物体发生收缩，或时钟行为异常，恰好把以太风隐藏起来。其三：惯性系之间的变换不是伽利略的，真空方程在每个惯性系中都成立，而 $c$ 在其中每一个系里都是光速。

本课程走第三条路，从下一讲开始。第一条路正是迈克尔逊干涉仪被造出来要检验的。第二条是一个真实出现过的提议，出自菲茨杰拉德（FitzGerald）与洛伦兹（Lorentz），它并不愚蠢：那是在保住以太的同时去迁就零结果的一次尝试。爱因斯坦的做法，是不再把以太当作那个定义坐标的东西。

力律本身还有第二个、更安静的症状。电荷受到的磁力是 $q\,\mathbf{v}\times\mathbf{B}$，而 $\mathbf{v}$ 是速度，所以它依赖参考系。一个静止在载流导线旁的电荷不受磁力；换到某个电荷随其中一股电流的漂移一起运动的参考系里描述同一批物体，它们就不再是“静止的电荷”。在伽利略变换下，电力与磁力的拆分并不会重排成新参考系中的洛伦兹力，而麦克斯韦方程组保不住它们的形式。本讲不对场量做变换。[[#thm-wave]] 已经是一个足够充分的矛盾。只有先把坐标变换本身换掉，场的变换才会变成整齐的那种。

::: warning 速率总属于某个参考系
“球的速率是 $35.0\,\mathrm{m/s}$”是站台的一句话，“球的速率是 $15.0\,\mathrm{m/s}$”是车厢的一句话。不存在脱离参考系的球速，把两个数平均也造不出一个来。由 [[#prop-accel]]，加速度一致；由 [[#thm-velocity]]，速度不一致。如果你还在用本讲的规则，同样的警告对光也成立：一个系里的 $c$ 与另一个系里的 $c - v$，不是对同一个数的两种意见，而是伽利略相加所要求的。下一讲就真空中的光放弃这一要求，并随之把它对一切速度都放弃掉。
:::

::: quiz
车厢相对站台以恒定速度 $20\,\mathrm{m/s}$ 运动。一名乘客相对车厢沿同一直线向前以 $15\,\mathrm{m/s}$ 抛出一个球。球在空中期间忽略空气阻力。下列说法哪个正确？
- [ ] 球只有一个速率 $35\,\mathrm{m/s}$，两个参考系都必须使用这个数。
- [ ] 球只有一个速率 $15\,\mathrm{m/s}$，因为投掷把速率定死了。
- [x] 相对车厢水平速度是 $15\,\mathrm{m/s}$，相对站台是 $35\,\mathrm{m/s}$。两个参考系中加速度相同。
- [ ] 速度不同，所以加速度也不同，于是牛顿第二定律只能在两个参考系中的一个里成立。
::: solution
[[#ex-train]] 就是这个情形。速度相加 [[#eq-u-gal]] 把水平速度平移一个参考系速度，留下两条各自对某个参考系为真的陈述。[[#prop-accel]] 说加速度一致，所以第二定律并不被迫挑选参考系。前两个选项凭空造出一个脱离参考系的速率；第四个把“速度会变”与“速度的变化率也会变”混为一谈。
:::
:::

## 后续内容 {#leads}

[[relativity]] 的下一讲保留“任何惯性系内实验都探测不到匀速运动”这条原理，再加第二条原理：真空中的光速不依赖波源的运动，在每个惯性系中取同样的值。这两句话对一条光线与 [[#eq-u-gal]] 相矛盾。取代 [[#eq-galilean]] 的坐标变换是洛伦兹变换。此后时间间隔与运动尺子的长度都依赖参考系。本讲的结果没有被丢掉：它们是 $v \ll c$ 的极限，在那个极限里 $t' = t$ 够用了，而 $c \pm v$ 与 $c$ 在任何车厢尺度的测量中都分辨不开。

[[mechanics/newton-laws]] 仍是那个极限的力学，[[magnetism/electromagnetic-waves]] 仍是那个不肯接受伽利略平移的波速的来源。改变的，是坐在它们中间的运动学。

::: history 1632 年的船
伽利略（Galileo Galilei）在《关于托勒密和哥白尼两大世界体系的对话》（*Dialogue Concerning the Two Chief World Systems*，1632）第二日的讨论中论证了力学原理。发言者请你和朋友把自己关在甲板下的大船舱里，带上几只小飞虫、一盆游着鱼的清水，以及一个向下滴入容器、缓慢滴漏的瓶子。船停泊时你观察虫子飞、鱼游、水滴落入容器、你起跳、以及把东西抛给同伴。然后让船匀速前进，不摇不晃。船舱内部的这些运动一个都不变：水滴照样落入容器，向船头和向船尾抛掷一样准。船的运动被物体、船舱和舱内的空气共同分享。伽利略指出结论依赖于封闭：到了甲板上，外面的空气不随船同行，烟和飞虫未必跟得上。

他没有写下 [[#eq-galilean]]。代数形式的变换是这一论证后来的坐标版本——前提是先承认单一的时间坐标和一把欧几里得尺。我们用的一直是那条公式，而正是船舱让 [[#prop-newton]] 有了分量。

与光的困难要晚得多。麦克斯韦（Maxwell）1865 年的电磁理论把光认定为电磁波，其速率由电磁常量固定，也就是本讲算出的那个速率。这一陈述如何与伽利略的船舱相处，是下一讲要回答的问题。我们没有引用伽利略的原话，也不需要引用：船舱里的那些实验本身就是论证。
:::

::: summary
- 惯性系是每个自由质点都在其中做匀速运动的参考系。以恒定相对速度相联系的两个参考系，要么都是惯性系，要么都不是。
- 事件用 $(t, x, y, z)$ 标记。标准配置下 $S'$ 沿 $x$ 以恒定 $v$ 运动，坐标轴平行，两原点在 $t = t' = 0$ 重合。
- 伽利略变换是 $x' = x - v t$、$y' = y$、$z' = z$、$t' = t$。它编码了一个共享的时间，以及对同时事件一致的长度。
- 速度相减：$\mathbf{u}' = \mathbf{u} - \mathbf{v}_{\mathrm{frame}}$。在 $20.0\,\mathrm{m/s}$ 的车厢里向前以 $15.0\,\mathrm{m/s}$ 投出的球，对站台是 $35.0\,\mathrm{m/s}$；向后以 $15.0\,\mathrm{m/s}$ 投出，对站台是 $5.00\,\mathrm{m/s}$。
- 加速度是不变量。两个质点的相对速度是不变量。单个质点相对某个参考系的速度不是。
- 若质量不变、力只依赖间距与相对速度，则 $\mathbf{F} = m\mathbf{a}$ 在每个惯性系中形式相同。在某个参考系中静止的介质——比如声之于空气——会挑出一个被偏爱的参考系，破坏这一模式。
- 伽利略相应用于光给出速率 $c \pm v$。球面光波前不会映射成球面波前，速率为 $c$ 的波动方程不保形式。在 $0.200c$ 与 $0.300c$ 处，伽利略和是 $0.500c$，相对论和 $(0.2+0.3)/(1+0.2\times 0.3)$ 是 $0.472c$。
- 日常速率下 $v/c$ 极小（$20.0\,\mathrm{m/s}$ 时为 $6.67\times 10^{-8}$），所以伽利略规则仍是实验室的力学规则。它只是本课程对光放弃掉的那条规则。
:::

## 习题 {#exercises}

::: exercise 船上行走 {level=1 check="9.5"}
船相对码头以 $8.00\,\mathrm{m/s}$ 运动，处于标准配置。一名乘客相对船沿 $x$ 方向以 $1.50\,\mathrm{m/s}$ 向前行走。求乘客相对码头的速度，以 $\mathrm{m/s}$ 计。
::: solution
码头是 $S$，船是 $S'$，$v = 8.00\,\mathrm{m/s}$。行走给在船上，所以 $u' = 1.50\,\mathrm{m/s}$。[[#eq-u-gal]] 的逆变换是

$$
u = u' + v = 1.50 + 8.00 = 9.50\,\mathrm{m/s}.
$$

正号表示乘客相对码头沿正 $x$ 方向运动，比船恰好快出步行速度。匀速行走的加速度在两个参考系中都为零。两个速度 $1.50\,\mathrm{m/s}$ 与 $9.50\,\mathrm{m/s}$ 都正确，而且它们不是对同一个数的两次尝试。
:::
:::

::: exercise 向船尾走 {level=1 check="6.5"}
上一题的船和乘客都不变，只把行走改为乘客相对船以 $1.50\,\mathrm{m/s}$ 向船尾走。求相对码头的速度，以 $\mathrm{m/s}$ 计，取船的速度方向为正。
::: solution
标准配置下船尾方向是负方向，所以 $u' = -1.50\,\mathrm{m/s}$、$v = 8.00\,\mathrm{m/s}$。于是

$$
u = -1.50 + 8.00 = 6.50\,\mathrm{m/s}.
$$

乘客相对码头仍然向前走，因为船比步行快。再报成 $9.50\,\mathrm{m/s}$ 意味着丢掉了行走的方向；报成 $-6.50\,\mathrm{m/s}$ 意味着暗中翻转正方向约定而没有说明。符号约定是答案的一部分。
:::
:::

::: exercise 闪光的坐标 {level=1 check="30"}
一次闪光在 $S$ 中的坐标为 $x = 48.0\,\mathrm{m}$、$t = 3.00\,\mathrm{s}$。参考系 $S'$ 与 $S$ 处于标准配置、$v = 6.00\,\mathrm{m/s}$。求 $x'$，以米计。
::: solution
[[#eq-galilean]] 给出 $t' = 3.00\,\mathrm{s}$，且

$$
x' = 48.0 - (6.00)(3.00) = 48.0 - 18.0 = 30.0\,\mathrm{m}.
$$

那 $18.0\,\mathrm{m}$ 是 $S'$ 的原点到闪光时刻已沿 $x$ 走过的距离，不是某个物体的长度。逆变换 $x = 30.0 + (6.00)(3.00) = 48.0\,\mathrm{m}$，取回原来的标签。另一发生在同一时刻、位于 $x = 50.0\,\mathrm{m}$ 的闪光有 $x' = 32.0\,\mathrm{m}$，两个事件在两个系中的间距都是 $2.00\,\mathrm{m}$。
:::
:::

::: exercise 减去参考系速度 {level=2 check="7"}
在站台系中一个质点速度的 $x$ 分量为 $u = 12.0\,\mathrm{m/s}$。一节车厢相对站台以 $v = 5.00\,\mathrm{m/s}$ 做标准配置运动。求质点相对车厢的速度的 $x$ 分量，以 $\mathrm{m/s}$ 计。
::: solution
这题给的量在 $S$ 中，要的是 $S'$，[[#eq-u-gal]] 照写即用：

$$
u' = u - v = 12.0 - 5.00 = 7.00\,\mathrm{m/s}.
$$

把 $5.00$ 加上去而不是减掉是逆操作，它回答的是另一个问题：多大的站台速度对应车厢系中的 $12.0\,\mathrm{m/s}$？那个数是 $17.0\,\mathrm{m/s}$，不是本题。先画出标准配置，确定自己拿到的是哪个符号，再去动符号位。
:::
:::

::: exercise 雨的倾斜 {level=2 check="5/3"}
在地面系中雨以 $9.00\,\mathrm{m/s}$ 竖直下落。一列火车以 $15.0\,\mathrm{m/s}$ 水平行驶。求 $\tan\theta$，其中 $\theta$ 是雨打在火车上时与竖直方向的夹角。
::: solution
在地面系中 $u_x = 0$，竖直分量大小为 $9.00\,\mathrm{m/s}$。在火车系中，[[#eq-u-gal-vec]] 只平移水平分量：

$$
u'_x = -15.0\,\mathrm{m/s}, \qquad u'_y = -9.00\,\mathrm{m/s}
$$

若取向下为负。与竖直方向的夹角满足

$$
\tan\theta = \frac{15.0}{9.00} = \frac{5}{3}.
$$

相对火车的速率（没有问）是 $\sqrt{15.0^{2} + 9.00^{2}} = \sqrt{306} = 17.5\,\mathrm{m/s}$。这个角是关于火车系的陈述。在地面系中与竖直方向的夹角为零，两种描述都对。这就是换了数字的 [[#ex-rain]]，以及同样的警告：不要把任何一个速率叫作雨“的”速率。
:::
:::

::: exercise 与相对论对照 {level=2 check="(0.2+0.3)/(1+0.2*0.3)"}
两个共线速度为 $0.200c$ 与 $0.300c$。用 $(v+u)/(1+vu)$ 计算它们的相对论和（以 $c$ 为单位），并与伽利略和比较。
::: solution
伽利略和是 $0.200 + 0.300 = 0.500$，以 $c$ 为单位。相对论和是

$$
\frac{0.2 + 0.3}{1 + 0.2\times 0.3} = \frac{0.5}{1.06} = 0.471698\ldots = 0.472
$$

三位有效数字，同样以 $c$ 为单位。值 $0.472c$ 是那个精确商的三位舍入，不是另一个公式。差 $0.0283c$ 就是 boost 图中滑块停在 $0.2$ 与 $0.3$ 时两个点之间的间距。本题把相对论规则当作给定的函数使用；推导是下一讲从洛伦兹变换给出的，而只要 [[#thm-velocity]] 的前提在生效，伽利略值 $0.500c$ 就仍是答案。
:::

::: exercise 证明加速度是不变量 {level=3}
把前提陈述清楚，并证明：若 $S'$ 与 $S$ 由 [[#eq-galilean]] 相联系，则每个质点在两个参考系中有相同的加速度。再指出当参考系之间的相对速度不恒定时失效的那一步。
::: hint
对 $x' = x - v t$ 求两次导，并用 $t' = t$。把 $v$ 移到导数号之外之前，先说清凭什么可以。
:::
::: solution
前提：$S'$ 与惯性系 $S$ 处于标准配置，相对速度 $v$ 恒定，坐标由 $x' = x - v t$、$y' = y$、$z' = z$、$t' = t$ 相联系。设质点在 $S$ 中的坐标为 $x(t)$，它在 $S$ 中的加速度分量为 $a_x = \dd^{2} x/\dd t^{2}$。在 $S'$ 中，

$$
a'_x = \frac{\dd^{2} x'}{\dd t'^{2}}.
$$

因为 $t' = t$，求导就是对 $t$ 的普通求导。因为 $v$ 恒定，

$$
\deriv{x'}{t} = \deriv{x}{t} - v, \qquad \frac{\dd^{2} x'}{\dd t^{2}} = \frac{\dd^{2} x}{\dd t^{2}}.
$$

对 $y' = y$、$z' = z$ 做同样计算得 $a'_y = a_y$、$a'_z = a_z$。所以 $\mathbf{a}' = \mathbf{a}$。

若 $v$ 是时间的函数，一阶导数是 $\deriv{x}{t} - v(t)$，二阶导数就是 $a_x - \deriv{v}{t}$。两个加速度于是相差参考系的加速度。对正在刹车的车厢这是正确的答案，但它越出了前提：[[#eq-galilean]] 是为恒定 $v$ 写的，而 $v$ 变化的参考系不是惯性系。
:::
:::

::: exercise 换系之后的波动方程 {level=3}
一个场只通过组合 $x - c t$ 依赖 $x$ 与 $t$，$c$ 为常量，因此它在 $S$ 中满足一维波动方程。用 $x' = x - v t$、$t' = t$，$v$ 恒定且 $v \neq 0$，把这个场改写为 $x'$ 与 $t'$ 的函数，并读出它在 $S'$ 中的速率。解释为什么那个速率不是 $c$。
::: hint
从变换式把 $x - c t$ 用 $x'$ 与 $t'$ 解出来。波只是一个组合的函数时，不需要一般的链式法则；[[#thm-wave]] 是一般情形。
:::
::: solution
由逆变换 $x = x' + v t'$、$t = t'$，所以

$$
x - c t = x' + v t' - c t' = x' - (c - v)\, t'.
$$

在 $S$ 中是任意函数 $f(x - c t)$ 的场，在 $S'$ 中就是函数 $f\bigl(x' - (c - v)\, t'\bigr)$。这是一列沿正 $x'$ 方向以速率 $c - v$、而不是 $c$ 行进的波。若它在 $S'$ 中以原来的速率 $c$ 满足波动方程，需要的组合是 $x' - c t'$。多出来的 $v$，就是把 [[#thm-velocity]] 的伽利略平移作用在一个在 $S$ 中速率为 $c$ 的信号上的结果。

结论用到了 $v \neq 0$，也用到了 $t' = t$——后者正是下一讲要放弃的假设。若一个理论坚持同一场方程以同一个 $c$ 在每个惯性系中成立，这一计算就表明：惯性系之间不可能用伽利略变换相联系。[[#thm-wave]] 对一般场陈述了这一冲突，这里特化为单向波，让速率一眼就能读出来。
:::
