[[relativity/postulates]] 中的洛伦兹变换告诉你，两个惯性系为同一个事件分别指派什么坐标。紧接着有两个问题。其一：一个质点在 $S$ 中速度为 $\mathbf{u}$，$S'$ 给它指派的速度是多少？伽利略的答案 $u' = u - v$ 曾是力学中最干净利落的定理之一；在这里它不对，而对它的替换牵涉到一切会飞的东西。其二：若 $p = mv$ 与 $T = \tfrac12 mv^2$ 是从给出 $u' = u - v$ 的同一个变换上读出来的，那么动能与动量就不可能同时在每个惯性系中守恒。补救之道不是抛弃守恒——而是重建定义，使*守恒律*成为相对性公设所要求不变的东西，正如伽利略变换过去保证加速度的不变性与牛顿第二定律那样。

本章两件事都做。速度律由洛伦兹变换经过与 [[relativity/postulates#ex-galilean-check]] 中预览过的相同的三行求导得到；多普勒移动是把它用于光的一个推论。能量与动量要多费一点心思，因为要求不是"造一个公式"，而是"造一条形式不因更换惯性系而改变的守恒律"。结果——$p = \gamma m v$、$T = mc^2(\gamma - 1)$、$E = \gamma mc^2$、$E^2 = p^2 c^2 + m^2 c^4$——就是本章的内容，而质能关系 $E_0 = mc^2$ 作为其中的静能项随之而来，并不是一道单独的奇迹。

## 速度变换

::: theorem 速度变换 {#thm-velocity2}
设 $S'$ 相对 $S$ 处于标准配置、沿 $+x$ 方向以速率 $v$ 运动。一个在 $S$ 中速度分量为 $(u_x, u_y, u_z)$ 的质点，在 $S'$ 中有

$$
u'_x = \frac{u_x - v}{1 - \dfrac{v u_x}{c^2}}, \qquad u'_y = \frac{u_y}{\gamma\left(1 - \dfrac{v u_x}{c^2}\right)}, \qquad u'_z = \frac{u_z}{\gamma\left(1 - \dfrac{v u_x}{c^2}\right)}.
$$ {#eq-velocity}
:::

::: proof
速度就是 $d\mathbf{x}'/dt'$：变换后的坐标对变换后的时间求导。这不是可选的——$t'$ 不是 $t$，比值 $dx'/dt'$ 也不是 $dx'/dt$。把 [[relativity/postulates#eq-lorentz2]] 的两个洛伦兹方程都对*未变换的*时间 $t$（质点世界线上的参数）求导：

$$
\frac{dx'}{dt} = \gamma\left(\frac{dx}{dt} - v\right) = \gamma(u_x - v), \qquad \frac{dt'}{dt} = \gamma\left(1 - \frac{v}{c^2}\frac{dx}{dt}\right) = \gamma\left(1 - \frac{v u_x}{c^2}\right).
$$

横向坐标不变，$y' = y$，所以 $dy'/dt = u_y$。现在取比值：

$$
u'_x = \frac{dx'}{dt'} = \frac{\gamma(u_x - v)}{\gamma(1 - vu_x/c^2)} = \frac{u_x - v}{1 - vu_x/c^2},
$$

对横向分量，$dy' = dy$，但分母仍是 $dt'$：

$$
u'_y = \frac{dy'}{dt'} = \frac{dy/dt}{dt'/dt} = \frac{u_y}{\gamma(1 - vu_x/c^2)},
$$

而 $u'_z$ 完全一样。对同一对事件而言，横向速度在运动系中*小于*朴素的值 $u_y$，这是两个效应相乘的结果：分母里的 $\gamma$，以及 $(1 - vu_x/c^2)$ 因子。当 $v/c \to 0$ 时二者都消失，恰好取回 $u' = \mathbf{u} - \mathbf{v}$，正如 [[relativity/galilean#thm-velocity]] 在低速极限下所要求的。逆变换是同一公式，把 $v \to -v$ 并互换带撇与不带撇的量。
:::

共线情形——[[#eq-velocity]] 取 $u_y = u_z = 0$——就是合成规则：

::: corollary 爱因斯坦速度相加 {#cor-addition}
$$
u' = \frac{u - v}{1 - uv/c^2}, \qquad u = \frac{u' + v}{1 + u'v/c^2}.
$$ {#eq-addition}
两个各小于 $c$ 的速率之和小于 $c$；$c$ 与任何亚光速的合成仍是 $c$。
:::

::: proof
第一个方程已经在 [[#eq-velocity]] 里。对第二个，把 $u'(1 - uv/c^2) = u - v$ 解出 $u$：展开得 $u' - u' u v/c^2 = u - v$，于是 $u' + v = u(1 + u' v/c^2)$，再相除，

$$
u = \frac{u' + v}{1 + u'v/c^2}.
$$

关于上界，设 $0 \le u < c$ 且 $0 \le v < c$。于是

$$
u' = \frac{u - v}{1 - uv/c^2}.
$$

若 $u \le v$，分子非正，$u'$ 的符号合乎情理。若 $u > v$，分子与分母都为正，且

$$
c - u' = c - \frac{u - v}{1 - uv/c^2} = \frac{c(1 - uv/c^2) - (u - v)}{1 - uv/c^2} = \frac{c - \frac{cu v}{c^2} - u + v}{1 - uv/c^2} = \frac{(c - u)(1 + v/c)\,c/c}{1 - uv/c^2}\cdot \frac{1}{c}\cdot c.
$$

更干脆一些，把差的分子乘以 $c$：

$$
c(1 - uv/c^2) - (u - v) = c - \frac{uv}{c} - u + v = \left(c - u\right) + \left(v - \frac{uv}{c}\right) = (c - u) + v\left(1 - \frac{u}{c}\right) > 0,
$$

因为 $u < c$ 且 $v \ge 0$。故 $u' < c$。对 $u = c$：$u' = (c - v)/(1 - v/c) = c(c - v)/(c - v) = c$。一条光线与亚光速 boost 合成之后仍是光线，正如 [[relativity/postulates#ax-light]] 所要求。合成是可交换的——其含义是两步的结果不依赖于参考系的次序——因为两参考系间的相对速度就是一个相对速度；固定 $v$ 的映射 $u \mapsto u'$ 在 $v \to -v$ 下恰是自身的逆，第二个公式的证明已经说明了这一点。
:::

::: widget boost
v: 0.5
u: 0.5
caption: 蓝线是伽利略和 u + v，红线是爱因斯坦合成——固定一个粒子的 u、让 v 变化。注意只要 u 与 v 各自小于 1（以 c 为单位），两者就都保持在 1 以下；而在 0.5c 以下二者相差不到 1%——相对论修正并不是只在 0.99c 才出现的小效应；它在每一个 v > 0 处都在，只是被它所修正的那个和大和淹没了。
:::

::: quiz 若一艘飞船相对地球以 $0.9c$ 运动，并沿同一方向相对自身以 $0.9c$ 弹出一枚探测器，探测器相对地球的速率是多少？
- [ ] $1.8c$，探测器跑赢光，相对论被违背
- [x] $\dfrac{0.9c + 0.9c}{1 + 0.9^2} \approx 0.994c$，低于 $c$
- [ ] $0.9c$，因为相对于不同参考系的速度是绝对的
- [ ] 取决于探测器的加速历史
::: solution
用 [[#eq-addition]]，取 $u' = 0.9c$（探测器相对飞船）与 $v = 0.9c$（飞船相对地球）：$u = (1.8c)/(1 + 0.81) = 1.8/1.81 \, c \approx 0.9945c$。低于 $c$，高于 $0.9c$，并且对合成的次序不敏感，因为两参考系间的相对速度就是一个相对速度（[[#cor-addition]]）。第一个选项是伽利略和；第三个否认速度依赖参考系；第四个之错，在于合成只依赖于相对速度，而不依赖于它们是怎样得到的。
:::
:::

::: warning 横向分量：不要把 $\gamma$ 丢掉
[[#eq-velocity]] 的 $x$ 分量看起来像 [[relativity/postulates]] 里的一维公式，于是常有学生把那个公式也照搬到 $y$、$z$ 分量上：$u'_y = u_y - 0$（因为"$y$ 方向没有 boost"）。这就是错误。$S'$ 中的 $y$ 速度是 $dy'/dt'$，而对在 $x$ 上分开的一对事件，$dt'$ *不是* $dt$。正确的因子是 $\gamma(1 - vu_x/c^2)$，不是 $1$。对一个在 $S$ 中纯沿 $y$ 运动的质点（$u_x = 0$），它化为 $u'_y = u_y/\gamma$，这是横向速率实打实的*改变*，不只是换个标签。分母里的 $\gamma$ 与运动长度沿运动方向收缩是同一个道理：它来自 $dt' \ne dt$，而且它出现在速度变换的每一个分量里，不只是被 boost 的那一个。
:::

## 相对论多普勒效应

运动波源发出的光：观察者接收到的频率是多少？答案不是"把伽利略多普勒公式里的 $u_{\text{sound}}$ 换成 $c$"，因为那条公式要用*介质*的参考系来定义波源和观察者的速率，而真空中没有哪个参考系是特殊的。诚实的推导是把洛伦兹变换直接用在波本身上。

::: theorem 相对论多普勒效应（共线） {#thm-doppler}
一个波源在自身静止系中以频率 $f_0$ 发射，相对观察者以速率 $v$ 运动并正在远离。接收到的频率为

$$
f = f_0\,\sqrt{\frac{1 - v/c}{1 + v/c}}.
$$ {#eq-doppler}
若是接近，$v \to -v$：$f = f_0\sqrt{(1 + v/c)/(1 - v/c)} > f_0$。
:::

::: proof
全程在观察者系 $S$ 中工作：波源沿 $+x$ 以速率 $v$ 运动，观察者固定在 $x = L > 0$、位于波源前方，而波源自 $t = 0$ 起于原点。波源在*自己的*系 $S'$ 中以周期 $T_0 = 1/f_0$ 发出自己波的波峰；因此这两个发射事件在 $S'$ 时间中相距 $T_0$，而洛伦兹变换告诉我们对应的 $S$ 坐标。

两个发射事件在 $S'$ 中是 $E_1 = (x', t') = (0, 0)$ 与 $E_2 = (0, T_0)$。变换到观察者系 $S$（其中 $S'$ 以 $v$ 退行）：

$$
t_1 = 0, \qquad x_1 = 0; \qquad t_2 = \gamma T_0, \qquad x_2 = 0.
$$

（波源坐在自己系 $S'$ 的原点，所以两事件都有 $x' = 0$，而逆变换 $x = \gamma(x' + vt')$ 给出 $x_2 = \gamma v T_0$、$t_2 = \gamma T_0$：在 $S$ 中波源在 $\gamma T_0$ 这段时间里前进了 $v\gamma T_0$，速率为 $v$，正如预期。）

第一个波峰在 $E_1$ 发出并以 $c$ 传播：它在 $S$ 中的世界线是 $x = c t$。它将被观察者接收。观察者在 $S$ 中固定——比如说在 $x = 0$——但波峰在 $t = 0$ 于 $x = 0$ 发出、向*外*传播；观察者必定在别处。把观察者放在 $S$ 中的 $x = -L$（退行波源的后方，波源沿 $+x$ 运动）。波峰 1 到达 $x = -L$……它沿 $+x$ 走，与 $x = -L$ 背道而驰。把观察者放在前方 $x = +L$：波峰 1（从 $x = 0$ 沿 $+x$）在 $t_{1,\text{recv}} = L/c$ 到达 $x = L$。

波峰 2 于 $t_2 = \gamma T_0$ 在 $x_2 = v\gamma T_0$ 发出，同样沿 $+x$ 以 $c$ 走：$x = v\gamma T_0 + c(t - \gamma T_0)$。到达 $x = L$ 于 $t_{2,\text{recv}}$：由 $L = v\gamma T_0 + c(t_{2,\text{recv}} - \gamma T_0)$ 得 $t_{2,\text{recv}} = \gamma T_0 + (L - v\gamma T_0)/c = L/c + \gamma T_0(1 - v/c)$。

$S$ 中接收到的周期是二者之差：

$$
T_{\text{recv}} = t_{2,\text{recv}} - t_{1,\text{recv}} = \gamma T_0(1 - v/c) = T_0\,\frac{1 - v/c}{\sqrt{1 - v^2/c^2}} = T_0\,\sqrt{\frac{1 - v/c}{1 + v/c}},
$$

最后一步用到 $1 - v^2/c^2 = (1 - v/c)(1 + v/c)$。接收频率是它的倒数：$f = f_0 \sqrt{(1 + v/c)/(1 - v/c)}$。

注意这里的几何：波源*远离*观察者而去，晚发的波峰出自离观察者更远的一点，因此后发的波峰要多走一段路，才会在波源*后方*的观察者位置被接收。在上面的配置里观察者在前方，用同样的代数、让波源沿 $x$ 减小的方向运动（或者让观察者在后方），$(1 - v/c)$ 因子中的符号就会翻转，得到所陈述的远离波源公式 [[#eq-doppler]]，$f = f_0\sqrt{(1 - v/c)/(1 + v/c)} < f_0$，以及把 $v$ 换成 $-v$ 得到的接近波源公式。这两个效应并非各自独立：$\gamma$ 因子是波源的钟在 $S$ 中的时间膨胀，$(1 \pm v/c)$ 因子是几何的改变——第二个波峰的发射点比第一个离观察者近 $v\gamma T_0$ 或远 $v\gamma T_0$。二者之积才是完整的相对论多普勒因子；缺哪个都不行。
:::

::: example 退行类星体的红移 {#ex-quasar}
一个类星体以 $v = 0.5c$ 退行。在类星体静止系中频率为 $f_0 = 1.0 \times 10^{15}\,\mathrm{Hz}$ 的一条谱线被观测。求观测频率与红移 $z = (f_0 - f)/f$。
::: solution
$\beta = v/c = 0.5$。远离波源公式 [[#eq-doppler]] 给出

$$
f = f_0 \sqrt{\frac{1 - 0.5}{1 + 0.5}} = f_0 \sqrt{\frac{0.5}{1.5}} = f_0 \sqrt{1/3} \approx 0.577\,f_0 = 5.77\times 10^{14}\,\mathrm{Hz}.
$$

红移为 $z = (f_0 - f)/f = f_0/f - 1 = \sqrt{3} - 1 \approx 0.732$。以天文标准看，$0.73$ 是个大红移：在 $z \approx 0.73$ 处，常见的推手是宇宙膨胀而非局部的本征速度，但对一个真正带有 $0.5c$ 本征速度的波源——比如活动星系核中的喷流——*狭义相对论*的多普勒移动公式才是对的那一条。
:::
:::

## 重建动量与能量

相对性公设要求物理定律的*形式*在每个惯性系中相同。动量守恒——一条形如"反应前的总和等于反应后的总和"的定律——就是这些定律之一。若沿用 $p = mv$，而 $v$ 依 [[#eq-velocity]] 而非伽利略减法变换，那么在一个参考系中守恒 $p = mv$ 的碰撞，一般而言在另一个参考系中并不守恒。要求不是动量*必须*守恒——而是动量*应当怎样定义*，才使守恒律具有协变性。

::: theorem 相对论动量 {#def-momentum}
不变质量为 $m$（在质点自身静止系中测得的质量）、以速率 $v$ 运动的质点，其动量为

$$
p = \gamma m v = \frac{m v}{\sqrt{1 - v^2/c^2}}.
$$ {#eq-p-rel}
:::

::: proof
这一论证是关于一次弹性对心碰撞的对称性论证，不是从力律出发的推导。两个质量为 $m$ 的全同质点在碰撞对称的参考系 $S$（初速度等值反向）中以速率 $u$ 相向运动，发生弹性碰撞后对称离开。在 $S$ 中初态总动量为零；守恒（一条写在 $S$ 中的定律）给出末态总动量为零。

现在从相对 $S$ 以速率 $v$ 运动的 $S'$ 看这同一次碰撞。在 $S'$ 中两质点不再有等值反向的速率：把速度变换 [[#thm-velocity2]] 用于 $+u$ 与 $-u$ 得 $u'_1 = (u - v)/(1 - uv/c^2)$ 与 $u'_2 = (-u - v)/(1 + uv/c^2)$，二者互不为相反数。若动量是 $mv$，那么在 $S'$ 中碰撞前后的总量就不会靠当初使它在 $S$ 中相消的同一个对称性相消，而 $S$ 中的守恒也就推不出 $S'$ 中的守恒。使总量在*每个*参考系中都相消的因子，正是出现在时间分量变换里的那个 $\gamma(v)$：定义 $p = \gamma(v) m v$。于是在 $S'$ 中，利用速度变换与恒等式 $\gamma(u') = \gamma(u)\gamma(v)(1 - uv/c^2)$（它由定义直接得出，因为 $\gamma(u)^{-2} = 1 - u^2/c^2$，而 $t$ 分量的变换给出同一个因子），两质点的动量恰好以这种方式变换：它们在 $S'$ 中的总和等于 $S$ 中总和的洛伦兹变换，即为零。守恒律因此是协变的。

具体地说，两质点系统的总四维动量（一个将在 [[relativity/four-vectors]] 中精确化的量）是一个四维矢量，而它的守恒是一条四维的陈述，归约到任何一个单独参考系就是一般的三维动量守恒。那个四维矢量的三维动量分量是 $p = \gamma m v$。由碰撞对称性出发的论证是 $\gamma(v)$ 必须乘在 $mv$ 之上的*物理*理由，不是任意的选择：除一个由 $v \to 0$ 时要求 $p \to mv$ 固定的总体比例之外，没有任何别的 $v$ 的函数能让两个参考系中的守恒彼此相符。
:::

动能由功得到。力 $F$ 作用在质点上做功 $dW = F\,dx$；关于转移能量的动能定理是一条与参考系无关的陈述，它给出 $T = \int F\,dx = \int v\,dp$。

::: theorem 相对论动能与总能量 {#thm-energy}
不变质量为 $m$、速率为 $v$ 的相对论质点，其动能为

$$
T = mc^2(\gamma - 1), \qquad \gamma = \frac{1}{\sqrt{1 - v^2/c^2}}.
$$ {#eq-T}
**总能量**为 $E = T + mc^2 = \gamma mc^2$，其中 $E_0 = mc^2$ 是**静能**。能量与动量之间的不变关系是

$$
E^2 = p^2 c^2 + m^2 c^4.
$$ {#eq-Emass}
:::

::: proof
从 $T = \int_0^v v'\, dp$ 出发，其中 $p = \gamma(v') m v'$，于是

$$
dp = dm\,v' \frac{d\gamma}{dv'} + \gamma m\, dv' = m\,v'\,\frac{d\gamma}{dv'} + \gamma m\, dv',
$$

其中 $\dfrac{d\gamma}{dv'} = \dfrac{v'}{c^2}(1 - v'^2/c^2)^{-3/2} = \dfrac{v'}{c^2}\gamma^3$。于是

$$
T = \int_0^v \left[ m v'^2 \frac{v'}{c^2}\gamma^3 + \gamma m v' \right] dv' = m\int_0^v \left[\gamma v' + \frac{v'^3}{c^2}\gamma^3\right]dv'.
$$

合并公因子：$\gamma v' + (v'^2/c^2)\gamma^3 v' = \gamma v'(1 + v'^2/c^2\,\gamma^2)$。用 $\gamma^2 = 1/(1 - v'^2/c^2)$，得 $1 + v'^2/c^2\,\gamma^2 = 1 + v'^2/c^2 \cdot 1/(1 - v'^2/c^2) = (1 - v'^2/c^2 + v'^2/c^2)/(1 - v'^2/c^2) = \gamma^2$。故被积函数为 $\gamma v'\cdot \gamma^2 = \gamma^3 v'$，于是

$$
T = m\int_0^v \gamma^3 v'\, dv' = m\int_0^v \frac{v'\,dv'}{(1 - v'^2/c^2)^{3/2}}.
$$

作代换 $w = 1 - v'^2/c^2$，$dw = -2v'\,dv'/c^2$，$v'\,dv' = -c^2\,dw/2$；$v' = 0$ 时 $w = 1$；$v' = v$ 时 $w = 1 - v^2/c^2 = 1/\gamma^2$：

$$
T = \frac{mc^2}{2}\int_{1/\gamma^2}^{1} w^{-3/2}\, dw = \frac{mc^2}{2}\left[-2 w^{-1/2}\right]_{1/\gamma^2}^{1} = mc^2\left(\gamma - 1\right).
$$

总能量为 $E = T + mc^2 = \gamma mc^2$。对不变关系，直接计算 $E^2 - p^2 c^2$：

$$
E^2 - p^2 c^2 = \gamma^2 m^2 c^4 - \gamma^2 m^2 v^2 c^2 = \gamma^2 m^2 c^2 (c^2 - v^2).
$$

现在 $\gamma^2 = 1/(1 - v^2/c^2) = c^2/(c^2 - v^2)$，前置因子恰好化简：

$$
\gamma^2 c^2 (c^2 - v^2) = \frac{c^2}{c^2 - v^2} \cdot c^2 (c^2 - v^2) = c^4,
$$

因此 $E^2 - p^2 c^2 = m^2 c^4$，即 [[#eq-Emass]]。公式中的质量 $m$ 是*不变*质量：它在每个参考系中都是同一个数，而根号下的量是一个洛伦兹不变量（用 [[relativity/four-vectors]] 的话说，是四维动量平方的一个分量）。
:::

::: example 以 $0.98c$ 运动的电子：相对论值与非相对论值 {#ex-electron}
一个电子（$mc^2 = 0.511\,\mathrm{MeV}$）被加速到 $v = 0.98c$。求它的总能量、动能与动量。并把动能与非相对论的 $\tfrac12 mv^2$ 作比较。
::: solution
$\beta = 0.98$，$\gamma = 1/\sqrt{1 - 0.98^2} = 1/\sqrt{1 - 0.9604} = 1/\sqrt{0.0396} = 1/0.1990 \approx 5.025$。

$$
E = \gamma m c^2 = 5.025 \times 0.511\,\mathrm{MeV} \approx 2.568\,\mathrm{MeV},
$$

$$
T = E - mc^2 = 2.568 - 0.511 = 2.057\,\mathrm{MeV},
$$

$$
pc = \gamma (mc^2)\beta = 5.025 \times 0.511\times 0.98\,\mathrm{MeV} \approx 2.52\,\mathrm{MeV}, \qquad p \approx 2.52\,\mathrm{MeV}/c.
$$

非相对论估计为 $\tfrac12 m v^2 = \tfrac12 (mc^2)(v^2/c^2) = \tfrac12 \times 0.511 \times 0.9604\,\mathrm{MeV} \approx 0.245\,\mathrm{MeV}$，约为真值 $T = 2.057\,\mathrm{MeV}$ 的 $12\%$。这不是小修正的错误；在这里用 $p = mv$ 会把动量低估 $\gamma \approx 5$ 倍——在磁场中，这正是"电子按这个半径拐弯"与"电子按五倍于斯的半径拐弯"之间的全部差别。
:::
:::

::: example 电子–正电子湮灭 {#ex-annihilation}
一个电子与一个正电子，静能均为 $0.511\,\mathrm{MeV}$，以大小为 $p = 1.00\,\mathrm{MeV}/c$ 的等值反向动量迎头相遇，湮灭为两个光子。求光子的能量与两者之间的夹角。
::: solution
这一对的四维动量总和（不变）：$E_{\text{tot}} = 2 \times \sqrt{(0.511)^2 + 1.00^2}\,\mathrm{MeV} = 2 \times \sqrt{0.261 + 1.00}\,\mathrm{MeV} = 2\times\sqrt{1.261}\,\mathrm{MeV} \approx 2\times 1.123\,\mathrm{MeV} = 2.246\,\mathrm{MeV}$。总动量为零（等值反向）。两个光子的总动量为零，仅当它们的动量等值反向，即一个背靠背地飞出，夹角 $\pi$。每个带走总能量的一半：$E_\gamma = E_{\text{tot}}/2 \approx 1.123\,\mathrm{MeV}$。（对光子 $E = pc$，所以 $p_\gamma = E_\gamma/c \approx 1.123\,\mathrm{MeV}/c$，而 $|\mathbf{p}_1 + \mathbf{p}_2| = 0$ 要求背靠背发射。）静能 $2 \times 0.511 = 1.022\,\mathrm{MeV}$ 只在初动能为零的极限下才解释光子能量；在这里多出的 $2.246 - 1.022 = 1.224\,\mathrm{MeV}$ 是两个有质量粒子的动能，它们全部落进了光子。这就是守恒律的样子：对背靠背的两光子态，$E_{\text{tot}}^2 - p_{\text{tot}}^2 c^2 = E_{\text{tot}}^2$（因为 $p_{\text{tot}} = 0$），所以它的不变质量为 $E_{\text{tot}}/c^2 \approx 2.246\,\mathrm{MeV}/c^2$，等于初态那对粒子的不变质量，而 [[#eq-Emass]] 在碰撞两侧都这样要求。
:::
:::

::: example 动量为 $1.00\,\mathrm{GeV}/c$ 的质子 {#ex-proton}
一个质子（$mc^2 \approx 938\,\mathrm{MeV}$）的动量为 $p = 1.00\,\mathrm{GeV}/c = 1000\,\mathrm{MeV}/c$。求它的速率、总能量与动能。
::: solution
用 [[#eq-Emass]]：$E = \sqrt{p^2 c^2 + m^2 c^4} = \sqrt{1000^2 + 938^2}\,\mathrm{MeV} = \sqrt{1{,}000{,}000 + 879{,}844}\,\mathrm{MeV} = \sqrt{1{,}879{,}844}\,\mathrm{MeV} \approx 1371\,\mathrm{MeV}$。于是 $E \approx 1.371\,\mathrm{GeV}$，$T = E - mc^2 \approx 1371 - 938 = 433\,\mathrm{MeV}$。

关于速率：$\beta = pc/E = 1000/1371 \approx 0.729$，故 $v \approx 0.73c$。校验 $\gamma = E/(mc^2) = 1371/938 \approx 1.462$；于是 $\beta = \sqrt{1 - 1/\gamma^2} = \sqrt{1 - 1/2.137} = \sqrt{1 - 0.468} = \sqrt{0.532} \approx 0.729$。一致。由 $p = mv$ 做非相对论的速率估计会给 $v = p/m = (1000\,\mathrm{MeV}/c)/(938\,\mathrm{MeV}/c^2) \cdot c = 1.066c$，快过光速——这错误并不隐晦，而且它就是 [[#def-momentum]] 的同一个 $\gamma$ 因子朝反方向现形：在 $p$ 中忽略 $\gamma$，会对给定的 $p$ 高估 $v$。
:::
:::

::: example 低速极限：旧公式回来了 {#ex-lowlimit}
对 $v \ll c$ 展开 $T = mc^2(\gamma - 1)$，证明 $E = mc^2 + \tfrac12 mv^2 + \tfrac{3}{8}mv^4/c^2 + \cdots$，并指出其中的牛顿项。
::: solution
把 $\gamma = (1 - \beta^2)^{-1/2}$ 按 $\beta^2$ 的幂展开：

$$
\gamma = 1 + \frac{\beta^2}{2} + \frac{3\beta^4}{8} + O(\beta^6).
$$

于是

$$
T = mc^2(\gamma - 1) = mc^2\left[\frac{\beta^2}{2} + \frac{3\beta^4}{8} + \cdots\right] = \frac{1}{2}mv^2 + \frac{3}{8}\frac{mv^4}{c^2} + \cdots,
$$

且

$$
E = mc^2 + \frac{1}{2}mv^2 + \frac{3}{8}\frac{mv^4}{c^2} + \cdots.
$$

静能 $mc^2$ 是每个参考系中都存在的常数偏移；动能是依赖 $v$ 的那部分，其首项就是牛顿的 $\tfrac12 mv^2$。牛顿公式并非*错*；它是一个级数的第一项，而级数的下一项相对首项为 $O(v^4/c^2)$、是首项的 $v^2/(4c^2)$ 这样一个分数……确切地说，第二项与首项之比为 $(3/8)(v^2/c^2)$，当 $v = 0.1c$ 时它是 $(3/8)(0.01) = 0.00375$，即 $0.4\%$：在非相对论公式于十分之一光速处有大约半个百分点的准确度，而误差按 $v^4/c^2$、不是按 $v/c$ 增长。
:::
:::

::: warning $mc^2$ 是静能，不是总能量
公式 $E = mc^2$ 是总能量 $E = \gamma mc^2$ 的*静止*项，$E_0 = mc^2$。对一个运动质点写"能量是 $mc^2$"就丢掉了 $\gamma$，把能量低估的倍数在静止时是 $1$、在速率 $v$ 处是 $\gamma$。反过来，"动能是 $\gamma mc^2$"又把它高估了一个静能项 $mc^2$——静能项永远在场，但除非质量本身改变（产生、湮灭或改变内部状态的粒子），它并不参与功能记账。这两种错误是同一个错误：忘了 $E = \gamma mc^2$ 的哪一块是"能量"、哪一块是"静能"。把二者分开的那套记账，正是使 $E^2 = p^2c^2 + m^2c^4$ 得以成立的东西：不变的 $m$ 是不变量，而 $E$ 与 $p$ 是依赖参考系的部分。
:::

::: quiz 一个质点的 $\gamma = 2$。它的速率以 $c$ 的分数计是多少？
- [ ] $0.5c$
- [x] $\sqrt{3}/2\,c \approx 0.866c$
- [ ] $0.707c$
- [ ] $2c$，因为 $\gamma = 1/v$
::: solution
由 $\gamma = 1/\sqrt{1 - v^2/c^2} = 2$ 得 $1 - v^2/c^2 = 1/4$，故 $v^2/c^2 = 3/4$，$v = \sqrt{3}/2\, c \approx 0.866c$。第一个选项把关系倒了过来；第三个对应 $\gamma = \sqrt{2}$；第四个把 $\gamma$ 与倒数混为一谈。
:::
:::

::: quiz 用本讲的术语说，光子的速率是多少，它的静质量又是多少？
- [ ] $v = c$ 且 $m > 0$，对 $\gamma \to \infty$ 有 $E = \gamma mc^2$
- [x] $v = c$ 且 $m = 0$，满足 $E = pc$，没有静能项
- [ ] $v = c$ 且 $m = 0$，但对任何非零 $p$ 都有 $E = mc^2 = 0$
- [ ] 永远 $v < c$，因为光子有一个定义良好的静止系
::: solution
对光子 $m = 0$，于是静能 $mc^2 = 0$，而由 [[#eq-Emass]] 取 $m = 0$ 得总能量 $E = pc$。它在每个惯性系中都以 $c$ 运动，正如 [[relativity/postulates#ax-light]] 所要求，并且没有静止系（静止系是使 $v = 0$ 的系，那不是 $c$）。选项 1 对 $m > 0$ 的"$\gamma \to \infty$"需要 $m$ 固定而 $v \to c$，那是趋近光速的有质量质点，不是光子；光子的 $m = 0$ 是精确为零，不是很小。
:::
:::

## 应用算例与常见陷阱

在应用中最吃重的两条公式是 [[#eq-Emass]] 与 [[#eq-addition]]。不变关系让你在$\{E, p, m\}$中已知两个、不用写下 $v$ 就算出剩下的能量或动量；加法规则让你合成相对速度，而不把 $\gamma$ 因子丢在横向分量里。

::: warning 横向速度里的 $\gamma$，再提
一个反复出现的错误，这回在能量语境：对一个在 $S$ 中 $p_y \ne 0$ 而 $p_x = 0$ 的质点，沿 $x$ 运动的参考系 $S'$ 看到的是 $p'_y = p_y / \gamma$，不是 $p_y$。横向*速度* $u'_y = u_y/\gamma$（由 [[#thm-velocity2]]，$u_x = 0$）与横向*动量* $p'_y = \gamma(u') m u'_y$ 各自都缩放，但缩放因子不同，因为 $\gamma(u') \ne \gamma(u)$。不变式 $E^2 - p^2 c^2 = m^2 c^4$ 是检验：它必须在两个参考系中都成立；而它成立仅当 $E$、$p_x$、$p_y$ 作为一个四维矢量一起变换，而不是 $p_y$ 单独变换。四维矢量的结构是 [[relativity/four-vectors]] 的主题；此处的警告是：把三维动量当作三个各自按自己的规则变换的独立标量，正是破坏不变式的错误。
:::

::: application 静能现身之处
核结合能、反应的 $Q$ 值、物质–反物质湮灭释放的能量、太阳发光度的来源：在每一种情形里，相关的量都是初末态之间静能的*差*，$\Delta E_0 = (m_{\text{initial}} - m_{\text{final}})c^2$。每个单个粒子的静能是一个常数偏移，在一个封闭系统中彼此抵消；物理上可取用的是系统不变质量的*变化*。太阳的静质量每秒减少约 $400$ 万吨，即它所辐射的 $3.8\times 10^{26}\,\mathrm{W}$ 的质当量。这条公式说的不是"质量变成了能量"，而是"反应后系统的不变质量比反应前小，其差乘以 $c^2$ 就是产物带走的能量"。
:::

::: history 从 $E = mc^2$ 到湮灭
爱因斯坦 1905 年的论文《物体的惯性同它所含的能量有关吗？》（*Does the Inertia of a Body Depend Upon Its Energy Content?*）导出了 $L = A(\gamma - 1)$（他的 $L$ 是动能，$A$ 是一个只依赖物体与单位制的常量），并论证：若一个物体以辐射形式放出能量 $L$，它的质量就减少 $L/c^2$，与发射的本性无关。静能的正比关系 $E_0 = mc^2$ 随之而来；而把 $mc^2$ 认定为静能、与总能量 $\gamma mc^2$ 区别开来，则是在其后十年间由普朗克（Planck）、哈瑟诺尔（Hasenöhrl）等人的工作定型的。物质–反物质湮灭为光子的第一个直接实验确证，随 1932 年安德森（Anderson）发现正电子而来；而自 1970 年代起，[[#ex-annihilation]] 中背靠背的湮灭光子一直是医学成像（PET 扫描）的标准工具：来自近乎静止的正电子–电子湮灭的两个 $511\,\mathrm{keV}$ 光子，被一圈探测器以符合方式探测，响应线由此钉定了湮灭地点。
:::

## 后续内容

[[#eq-Emass]] 背后的四维矢量结构——不变的质量壳、作为四维陈述的守恒律，以及不必写下某个特定参考系就能干净处理碰撞——在 [[relativity/four-vectors]]。闵可夫斯基图与光锥结构——即本讲一切背后的不变量 $c^2 t^2 - x^2$ 的几何版本——在 [[relativity/spacetime]]。[[#thm-velocity2]] 的速度变换与 [[#thm-doppler]] 的多普勒公式，是任何涉及两个以上参考系与一个光信号的问题中所用的工具。

::: summary
- 速度变换 [[#eq-velocity]] 是把洛伦兹变换用于速度；共线情形是爱因斯坦加法规则 [[#eq-addition]]，其两个亚光速的合成仍为亚光速，与 $c$ 的合成给出 $c$。
- 相对论多普勒效应 [[#eq-doppler]] 不是把 $c$ 代入的伽利略多普勒公式；它是把洛伦兹变换用于相继波前的发射事件与观测事件，单个因子中同时包含时间膨胀与几何的改变。
- 相对论动量 $p = \gamma m v$ 由"动量守恒须在各参考系间协变"的要求逼出；除了 $\gamma(v)$，没有任何别的 $v$ 的函数能使两个全同粒子碰撞的对称论证在每个参考系中闭合。
- 动能 $T = mc^2(\gamma - 1)$ 是以 $p = \gamma mv$ 代入的功积分 $\int v\,dp$；总能量为 $E = \gamma mc^2 = T + mc^2$。
- 不变式 $E^2 = p^2 c^2 + m^2 c^4$ 是能量–动量中与参考系无关的内容；$mc^2$ 是静能，一个常数偏移，除非系统的不变质量改变，它不参与功能记账。
- 在 $v/c \to 0$ 极限下，$p$、$T$ 以及 $E$ 的相加结构三者都精确回到各自的牛顿形式，修正项相对首项为 $v^4/c^2$ 阶（不是 $v^2/c^2$ 阶）。
:::

## 习题

::: exercise level=1
一个 μ 子的 $\gamma = 10$。求它的速率以 $c$ 的分数计；若其静能为 $105.7\,\mathrm{MeV}$，再求总能量。
check="0.995"
::: solution
$\gamma = 10$ 给出 $1 - v^2/c^2 = 1/100 = 0.01$，故 $v^2/c^2 = 0.99$，$v = \sqrt{0.99}\,c \approx 0.995c$。总能量为 $E = \gamma mc^2 = 10 \times 105.7\,\mathrm{MeV} = 1057\,\mathrm{MeV}$。动能为 $T = E - mc^2 = 1057 - 105.7 = 951\,\mathrm{MeV}$。检验值为 $v/c \approx 0.995$。
:::
:::

::: exercise level=1
两枚火箭 $A$ 与 $B$ 在地球系中沿同一方向分别以 $0.6c$ 与 $0.8c$ 运动。求 $B$ 测得的 $A$ 的速率。
::: solution
用 [[#eq-addition]]，取 $u' = 0.6c$（A 相对地球，作为"内层"速度）与 $v = 0.8c$（B 相对地球）：$u = (u' + v)/(1 + u'v/c^2)$ 是……小心：公式给出的是那个物体（A）在把速度"内层"地测出的那个参考系中的速度，以参考系的运动来表示。设 $u' = 0.6c$ 为 A 在地球系中的速率、$v = 0.8c$ 为 B 相对地球的速率；A 相对 B 的速率是 $(u' - v)/(1 - u'v/c^2)$……符号取决于哪一个参考系在动。B 相对地球以 $0.8c$ 运动；A 相对地球以 $0.6c$ 运动，同向。在 B 的参考系中地球以 $-0.8c$ 运动，而 A 在 B 系中的速率是

$$
u_{A|B} = \frac{u_A - u_B}{1 - u_A u_B/c^2} = \frac{0.6c - 0.8c}{1 - 0.6 \times 0.8} = \frac{-0.2c}{1 - 0.48} = \frac{-0.2c}{0.52} \approx -0.385c.
$$

负号表示在 B 看来 A 沿 $-x$ 方向运动（B 在前且更快，所以在 B 系中 A 落在后方、沿 $-x$ 退行）。大小为 $\approx 0.385c$。
:::
:::

::: exercise level=2 {#exr-doppler-app}
一个星系以 $v = 0.12c$ 退行。在星系静止系中频率为 $f_0 = 4.57\times 10^{14}\,\mathrm{Hz}$ 的一条氢线被观测。求观测频率与红移 $z$。
::: solution
$\beta = 0.12$。远离波源公式 [[#eq-doppler]]：

$$
f = f_0 \sqrt{\frac{1 - 0.12}{1 + 0.12}} = f_0 \sqrt{\frac{0.88}{1.12}} = f_0 \sqrt{0.7857} \approx f_0 \times 0.8864 \approx 4.05\times 10^{14}\,\mathrm{Hz}.
$$

红移 $z = (f_0 - f)/f = f_0/f - 1 = 1/\sqrt{0.7857} - 1 \approx 1.128 - 1 = 0.128$。（非相对论多普勒估计在 $0.12c$ 处给 $z \approx 0.12$，接近但不相等；相对论修正在这一速率上是百分之几的量级，并在更高的 $v$ 处迅速增长。）
:::
:::

::: exercise level=2
一个电子经过 $100\,\mathrm{kV}$ 的电势差被加速，获得动能 $T = 100\,\mathrm{keV}$。求它的速率、动量与总能量。并把速率与非相对论估计作比较。
::: solution
电子的静能为 $mc^2 = 0.511\,\mathrm{MeV} = 511\,\mathrm{keV}$。总能量为 $E = T + mc^2 = 100 + 511 = 611\,\mathrm{keV}$。于是 $\gamma = E/(mc^2) = 611/511 \approx 1.196$。进而 $\beta = \sqrt{1 - 1/\gamma^2} = \sqrt{1 - 1/1.430} = \sqrt{1 - 0.699} = \sqrt{0.301} \approx 0.549$，故 $v \approx 0.55c$。

动量：$pc = \gamma (mc^2)\beta = 1.196 \times 511 \times 0.549\,\mathrm{keV} \approx 336\,\mathrm{keV}$，故 $p \approx 0.336\,\mathrm{MeV}/c$。

由 $T = \tfrac12 mv^2$ 做速率的非相对论估计是 $v = \sqrt{2T/m} = \sqrt{2 \times 100/511}\,c = \sqrt{0.391}\,c \approx 0.625c$，把真实速率高估约 $14\%$。这一误差在 $100\,\mathrm{keV}$ 处算不上灾难，但它远高于任何用速率反推飞行时间的测量的精度，并且在任何用 $v$ 反推距离或曲率半径的计算中按二次方累积。
:::
:::

::: exercise level=3 {#exr-four-mom}
直接从 $E = \gamma mc^2$ 与 $p = \gamma mv$ 导出不变关系 $E^2 = p^2c^2 + m^2c^4$，不使用中间关系 $\gamma^2 = 1/(1 - v^2/c^2) \cdot c^2/(c^2-v^2)$。
hint="计算 E^2 - p^2 c^2，提出公因子 gamma^2 m^2，并使用 gamma 的定义，而不是 gamma^2 的某个恒等式。"
::: solution
从定义出发：

$$
E^2 - p^2 c^2 = \gamma^2 m^2 c^4 - \gamma^2 m^2 v^2 c^2 = \gamma^2 m^2 c^2 (c^2 - v^2).
$$

现在直接代入定义 $\gamma = 1/\sqrt{1 - v^2/c^2}$：

$$
\gamma^2 c^2 (c^2 - v^2) = \frac{c^2 (c^2 - v^2)}{1 - v^2/c^2} = \frac{c^2 (c^2 - v^2)}{(c^2 - v^2)/c^2} = \frac{c^2 (c^2 - v^2) \cdot c^2}{c^2 - v^2} = c^4.
$$

相消是精确的：分子中的 $(c^2 - v^2)$ 与分母中的 $(c^2 - v^2)/c^2$（即 $1 - v^2/c^2$）是同一个量，其比为 $c^2$，留下 $c^2 \cdot c^2 = c^4$。于是 $E^2 - p^2 c^2 = m^2 c^4$，即所陈述的关系，除了定义之外没有借助任何 $\gamma^2$ 的恒等式。
:::
:::

::: exercise level=3
两个静质量同为 $m$ 的粒子迎头相向，各有动能 $T$。它们发生非弹性碰撞并粘合，形成一个复合粒子。用 $m$ 与 $T$ 表示复合粒子的静质量 $M$，并证明当 $T > 0$ 时 $M > 2m$。
hint="总动量为零，所以复合粒子在实验室系中静止。它的静能等于初始总能量，即 2(mc^2 + T)。"
::: solution
初态总动量为零（等值反向）。初态总能量为

$$
E_{\text{tot}} = 2(T + mc^2).
$$

复合粒子在实验室系中静止（它的动量是两个等值反向动量之和，为零），所以它的静能等于总能量，于是

$$
Mc^2 = E_{\text{tot}} = 2(T + mc^2), \qquad M = 2m + \frac{2T}{c^2}.
$$

故 $M - 2m = 2T/c^2 > 0$ 对 $T > 0$：复合粒子比它的各部分之和质量更大，而"多出的"静质量 $2T/c^2$ 正是两个入射粒子的动能，如今作为内能（热、形变、激发——凡非弹性机制所提供的一切）锁进了复合粒子。这就是 $E^2 - p^2c^2 = m^2c^4$ 的不变质量内容：系统的不变质量不是其各部分静质量之和；它是质心系（动量中心系）中的总能量除以 $c^2$，其中包含内部的动能。
:::

::: exercise level=3
一个静质量为 $m$ 的粒子静止，衰变为两个静质量分别为 $m_1$ 与 $m_2$ 的粒子（$m > m_1 + m_2$）。在母粒子的静止系中求衰变产物的能量 $E_1$ 与 $E_2$，并进而求它们的动量。
hint="静止的两体衰变：两个产物必然背靠背。用动量守恒联系 E_1 与 E_2，再用能量守恒把它们定下来。"
::: solution
在母粒子的静止系中总动量为零，所以两个产物动量等值反向：$|\mathbf{p}_1| = |\mathbf{p}_2| = p$。总能量为 $mc^2 = E_1 + E_2$。对每一个用 [[#eq-Emass]]：$E_1^2 = p^2 c^2 + m_1^2 c^4$ 与 $E_2^2 = p^2 c^2 + m_2^2 c^4$。

两式相减：$E_1^2 - E_2^2 = (m_1^2 - m_2^2)c^4$，故 $(E_1 - E_2)(E_1 + E_2) = (m_1^2 - m_2^2)c^4$，而 $E_1 + E_2 = mc^2$，于是

$$
E_1 - E_2 = \frac{(m_1^2 - m_2^2)c^4}{mc^2} = \frac{m_1^2 - m_2^2}{m}c^2.
$$

与 $E_1 + E_2 = mc^2$ 联立，解出 $E_1$：

$$
2E_1 = mc^2 + \frac{m_1^2 - m_2^2}{m}c^2 = \frac{m^2 + m_1^2 - m_2^2}{m}c^2, \qquad E_1 = \frac{m^2 + m_1^2 - m_2^2}{2m}c^2.
$$

由对称性，$E_2 = (m^2 + m_2^2 - m_1^2)c^2/(2m)$。任一产物的动量为 $p = \sqrt{E_1^2 - m_1^2 c^4}/c$，把 $E_1$ 代入即得只含 $m, m_1, m_2$ 的表达式。条件 $m > m_1 + m_2$ 保证 $E_1$ 与 $E_2$ 都为正且根号为实：两体衰变只有在母粒子重于两个子粒子静质量之和时运动学上才允许，而"多出的" $mc^2 - (m_1 + m_2)c^2$ 就是两个衰变产物的总动能。
:::

::: exercise level=3
一个在 $S$ 中速率为 $v$ 的粒子，在 $S'$（相对 $S$ 以 $0.6c$ 运动）中的速率 $v'$ 垂直于相对速度，且 $|v'| = 0.4c$。证明粒子在 $S$ 中的速率不是 $\sqrt{v'^2 + (0.6c)^2}$，求出它在 $S$ 中的真实速率，并解释朴素估计中丢掉的因子去了哪里。
hint="使用速度变换的逆变换：用 u'_x = 0.6c（参考系的速度）与 u'_y = 0.4c 表示 S 系中的 u_x 与 u_y，注意 u'_y 的分母中有 gamma 因子。"
::: solution
在 $S'$ 中粒子有 $u'_x = 0$（纯沿 $y'$ 运动，垂直于相对运动方向的 $x'$ 轴）与 $u'_y = 0.4c$。参考系 $S'$ 相对 $S$ 以 $v = 0.6c$ 运动。用逆变换（同形，$v \to -v$）：

$$
u_x = \frac{u'_x + v}{1 + v u'_x/c^2} = \frac{0 + 0.6c}{1 + 0} = 0.6c,
$$

$$
u_y = \frac{u'_y}{\gamma(1 + v u'_x/c^2)} = \frac{0.4c}{\gamma(1 + 0)} = \frac{0.4c}{\gamma}.
$$

由 $\gamma = 1/\sqrt{1 - 0.36} = 1/0.8 = 1.25$，$u_y = 0.4c/1.25 = 0.32c$。$S$ 中的真实速率为

$$
v = \sqrt{u_x^2 + u_y^2} = \sqrt{(0.6c)^2 + (0.32c)^2} = \sqrt{0.36 + 0.1024}\,c = \sqrt{0.4624}\,c \approx 0.680c.
$$

朴素估计 $\sqrt{(0.6c)^2 + (0.4c)^2} = \sqrt{0.36 + 0.16}\,c = \sqrt{0.52}\,c \approx 0.721c$ 把速率高估约 $6\%$。丢掉的因子是 $u_y$ 中的 $1/\gamma$：横向速度在实验室系中小于粒子自身横向参考系中的值，因为在 $x$ 上分开的事件对有 $dt \ne dt'$，这正是产生速度变换 $x$ 分量中 $\gamma$ 的同一个 $dt'/dt$ 因子。两个分量不按"另一个参考系的"值做平方和相加；它们按*变换后的*值做平方和相加，而横向分量的变换带着朴素矢量和所丢掉的 $1/\gamma$。
:::
