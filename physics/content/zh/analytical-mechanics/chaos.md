一个有摩擦的单摆，被一个周期性力矩推着摆动——力学系统再简单也不过如此。它的运动方程有三项，外加一个驱动；每一项都精确已知，而解完全由初始角度与初始角速度决定。然而对某些驱动强度，它的运动从不稳定成一个重复的模式；两次运行从相差一亿分之一弧度的角度出发，三十次摆动之后就完全对不上。没有加入任何随机因素。这种不可预言性是方程自己产生的。

这就是**确定性混沌**：在没有噪声的系统中，有界、非周期的运动却对初始条件有敏感依赖。它不是什么奇闻。它把天气预报限制在两周左右，它主宰小行星带的长期行为，它出现在激光器、化学反应、心脏节律与滴水的水龙头里；它是在分析力学最古老的问题——三个相互引力作用的天体的运动——中被发现的。

前面几章讲的是可解的系统：化归为求积（[[analytical-mechanics/central-forces]]）、用简正模（[[analytical-mechanics/small-oscillations]]），或用作用–角变量（[[analytical-mechanics/hamiltonian]]）。本章讲的是一般的非线性系统取而代之会做什么。我们从不动点的几何开始，解释混沌为什么至少需要三维相空间，用数值跟着受驱摆一路进入混沌，定义并计算**李雅普诺夫（Lyapunov）指数**，然后研究所有混沌系统中最简单的一个——逻辑斯蒂（logistic）映射——它的通往混沌之路连着几个普适常数。第一节要用的相平面技术，数学图谱中的[非线性系统一章](/learn/maths/lesson.php?c=ode&l=nonlinear-systems)讲得更细。

## 不动点与相平面 {#fixed-points}

把一阶方程组写成 $\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x})$，$\mathbf{x}$ 在 $N$ 维相空间中。哈密顿方程是一例，$N = 2n$；阻尼单摆 $\dot\theta = \omega$、$\dot\omega = -\gamma\omega - \omega_0^2\sin\theta$ 是另一例，$N = 2$。

::: definition 不动点及其线性化 {#def-fixed-point}
$\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x})$ 的一个**不动点**是满足 $\mathbf{F}(\mathbf{x}^*) = 0$ 的点 $\mathbf{x}^*$。它的**雅可比**是矩阵 $A_{ab} = \partial F_a/\partial x_b$ 在 $\mathbf{x}^*$ 处的取值，**线性化系统**是位移 $\boldsymbol\xi = \mathbf{x} - \mathbf{x}^*$ 的方程 $\dot{\boldsymbol\xi} = A\boldsymbol\xi$。
:::

在二维中，线性化的行为由 $A$ 的特征值 $\lambda_{1,2}$（即 $\lambda^2 - (\tr A)\lambda + \det A = 0$ 的根）分类：

- $\det A < 0$：符号相反的实特征值，**鞍点**，不稳定；
- $\det A > 0$ 且 $\tr A < 0$：两个特征值的实部都为负，稳定**结点**（实）或**焦点**（复）；
- $\det A > 0$ 且 $\tr A > 0$：不稳定结点或焦点；
- $\det A > 0$ 且 $\tr A = 0$：纯虚特征值，线性化的**中心**。

只要没有特征值的实部为零，哈特曼-格罗布曼（Hartman–Grobman）定理就保证不动点附近的非线性流与它的线性化长得一样。中心是例外：一点小非线性可以把线性中心变成朝任一个方向的缓慢螺线，除非有守恒能量之类的东西禁止它这样做。

::: example 阻尼单摆的不动点 {#ex-damped-fixed}
判定 $\ddot\theta + \gamma\dot\theta + \omega_0^2\sin\theta = 0$ 在 $0 < \gamma < 2\omega_0$ 时各不动点的类型。
::: solution
作为一阶系统，$\mathbf{x} = (\theta, \omega)$，$\mathbf{F} = (\omega, -\gamma\omega - \omega_0^2\sin\theta)$。不动点要求 $\omega = 0$ 且 $\sin\theta = 0$：悬挂位置 $\theta = 0$ 与倒立位置 $\theta = \pi$（以及平移 $2\pi$ 得到的副本）。雅可比矩阵是

$$
A = \begin{pmatrix}0 & 1\\ -\omega_0^2\cos\theta & -\gamma\end{pmatrix}.
$$

在 $\theta = 0$ 处：$\tr A = -\gamma < 0$ 且 $\det A = \omega_0^2 > 0$。特征值为 $\lambda = \frac12\bigl(-\gamma \pm \sqrt{\gamma^2 - 4\omega_0^2}\bigr)$，因 $\gamma < 2\omega_0$ 而为复数，且实部为负：稳定焦点。每条附近的轨道都螺旋卷入——这就是一次衰减摆动在相空间中的图像。

在 $\theta = \pi$ 处：$\det A = -\omega_0^2 < 0$，鞍点，特征值 $\frac12\bigl(-\gamma \pm \sqrt{\gamma^2 + 4\omega_0^2}\bigr)$，一正一负。趋近倒立位置的方向恰好只有一个，而对它的任何偏离都会增长。

若无摩擦，$\gamma = 0$，悬挂位置是线性化的中心，而 [[analytical-mechanics/hamiltonian#ex-pendulum-phase]] 中的守恒能量使它成为真正的中心，被闭合轨道环绕。有摩擦时，迹 $-\gamma$ 就是 $\mathbf{F}$ 的散度，相空间面积按 $e^{-\gamma t}$ 收缩，所以闭合轨道不可能存在，一切能量低于分离线的运动都落在底部。
:::
:::

### 为什么二维不够

在二维自治系统中，轨道不能相交，因为过每一点的解是唯一的。被限制在平面内有界区域中的轨道因此受到很强的限制：它不能以复杂的方式永远游荡，而不终于挤进自己待过的地方。

::: theorem 庞加莱-本迪克松（Poincaré–Bendixson）定理 {#thm-pb}
设 $\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x})$ 是平面上的连续可微系统，并设某条轨道对所有 $t \ge 0$ 留在一个不含不动点的有界闭区域 $D$ 中。则该轨道在 $t \to \infty$ 时趋近一条闭轨道（周期解）。
:::

::: proof {collapsed}
**证明概要。** 在轨道的一个极限点附近取一段与流横截的短线段。轨道相继穿过线段的点沿线段单调排列，因为轨道与线段共同围出一块轨道不能再进入的区域——由约当（Jordan）曲线定理与解的唯一性。线段上的单调数列收敛，其极限是一条轨道为闭曲线的点。完整证明，以及允许 $D$ 中含不动点的版本，见斯特罗加茨（Strogatz）《非线性动力学与混沌》（*Nonlinear Dynamics and Chaos*）§7.3，或赫希（Hirsch）、斯梅尔（Smale）与德瓦尼（Devaney）第 10 章。
:::

于是在平面内，有界运动止于不动点、止于闭轨道，或落在由轨道串接的不动点链上。混沌没有容身之地。自治系统至少需要三维。受*驱*的一自由度系统恰好有三维：$(\theta, \omega)$，再加上驱动的相位 $\psi = \omega_dt$（模 $2\pi$），它可以当作满足 $\dot\psi = \omega_d$ 的第三个变量来处理。这就是受驱摆。

## 受驱阻尼单摆 {#driven}

我们沿用泰勒（Taylor）《经典力学》（*Classical Mechanics*）第 12 章的写法，把运动方程写成

$$
\ddot\phi + 2\beta\dot\phi + \omega_0^2\sin\phi = \gamma\,\omega_0^2\cos\omega t,
$$ {#eq-ddp}

其中 $\gamma$ 是相对于重力度量的驱动强度：$\gamma = 1$ 表示驱动力矩等于重力力矩的最大值。取单位制使驱动周期为 $1$，于是 $\omega = 2\pi$，并取 $\omega_0 = 1.5\omega$、$\beta = \omega_0/4$。$\gamma$ 小时 $\sin\phi \approx \phi$，[[#eq-ddp]] 就是 [[oscillations/resonance]] 的线性受驱振子：瞬态过后，运动稳定在驱动频率上的稳态振荡，对每个初始条件都相同。

::: widget oscillator

k: 4
F: 1
omega: 1.5

v0: 0
caption: 线性受驱振子，即单摆的小振幅极限。播放运动，看从 $x_0 = 1.5$ 处释放的瞬态如何消退为驱动频率上的稳态振荡。改变 $x_0$ 或 $v_0$ 再运行：稳态是同一个，因为线性系统只有这一个。增大 $F$ 只是把稳态振幅按比例缩放。本节其余部分出现的一切行为，在这张图里都不可能发生。
:::

$\phi$ 一旦不再小，单摆就不是线性的。问题是当 $\gamma$ 增大越过 $1$ 时稳态长什么样。运动用四阶龙格-库塔方法数值积分（[数学图谱中的数值常微分方程](/learn/maths/lesson.php?c=numerical-analysis&l=numerical-odes)），每个驱动周期 $1000$ 步，从 $\phi(0) = -\pi/2$、$\dot\phi(0) = 0$ 出发。

### 庞加莱截面

连续地看 $\phi(t)$，很难分辨一个运动是一周期、两周期还是四周期一重复。每个驱动周期只看一次要容易得多。

::: definition 庞加莱截面 {#def-poincare}
对以周期 $T$ 驱动的系统，**庞加莱截面**（或频闪映射）是在驱动的同一相位记录的状态列 $\mathbf{x}(t_0 + kT)$，$k = 0, 1, 2, \dots$。更一般地，对一个自治流，庞加莱截面按单一方向记录对相空间中某张选定曲面的依次穿越。
:::

以驱动周期重复的运动在截面中是一个点。周期为 $2T$ 的运动是轮流造访的两个点，周期 $4T$ 是四个点。混沌运动铺展开一个永不重复的复杂集合。下面的清单记录 $300$ 个周期运行中最后八个整数时刻的 $\phi$（化到 $(-\pi, \pi]$ 内），此时瞬态早已消退；随后估计最大的李雅普诺夫指数——它的定义在下一节。

```python
import math
w = 2*math.pi; w0 = 1.5*w; beta = w0/4      # 驱动周期为 1，同 Taylor 第 12 章

def f(t, y, g):
    phi, om = y
    return (om, -2*beta*om - w0*w0*math.sin(phi) + g*w0*w0*math.cos(w*t))

def rk4(t, y, h, g):
    k1 = f(t, y, g)
    k2 = f(t + h/2, (y[0] + h/2*k1[0], y[1] + h/2*k1[1]), g)
    k3 = f(t + h/2, (y[0] + h/2*k2[0], y[1] + h/2*k2[1]), g)
    k4 = f(t + h, (y[0] + h*k3[0], y[1] + h*k3[1]), g)
    return (y[0] + h/6*(k1[0] + 2*k2[0] + 2*k3[0] + k4[0]),
            y[1] + h/6*(k1[1] + 2*k2[1] + 2*k3[1] + k4[1]))

N = 1000                         # 每个驱动周期的步数，h = 0.001
def wrap(x): return (x + math.pi) % (2*math.pi) - math.pi

def section(g, periods=300, keep=8):
    t, y, out = 0.0, (-math.pi/2, 0.0), []
    for n in range(periods):
        for _ in range(N):
            y = rk4(t, y, 1.0/N, g); t += 1.0/N
        if n >= periods - keep:
            out.append(round(wrap(y[0]), 4))
    return out

def lyapunov(g, periods=400, d0=1e-8):
    t, y = 0.0, (-math.pi/2, 0.0)
    for _ in range(100*N):           # 丢弃 100 个周期的瞬态
        y = rk4(t, y, 1.0/N, g); t += 1.0/N
    z = (y[0] + d0, y[1]); s = 0.0
    for n in range(periods):
        for _ in range(N):
            y = rk4(t, y, 1.0/N, g); z = rk4(t, z, 1.0/N, g); t += 1.0/N
        d = math.hypot(z[0] - y[0], (z[1] - y[1])/w0)
        s += math.log(d/d0)
        z = (y[0] + (z[0] - y[0])*d0/d, y[1] + (z[1] - y[1])*d0/d)   # 重整化
    return s/periods

for g in (0.2, 1.06, 1.07, 1.081, 1.0826, 1.105):
    print("gamma = %.4f  phi mod 2pi at t = 293..300:" % g, section(g))
for g in (1.06, 1.105):
    print("gamma = %.4f  Lyapunov exponent = %.3f per drive period" % (g, lyapunov(g)))
```

::: example 读庞加莱截面 {#ex-sections}
从输出中，指出每种驱动强度下稳态运动的周期，并描述 $\gamma = 1.06$ 到 $\gamma = 1.105$ 之间发生了什么。
::: solution
$\gamma = 0.2$ 时截面是同一个值反复出现：运动以驱动周期运动，是线性图里那种接近正弦的小幅振荡。$\gamma = 1.06$ 时仍是一个值，所以周期仍是 $1$，只是振荡现在很大、远非正弦。

$\gamma = 1.07$ 时两个值交替，$-0.1467$ 与 $-0.3202$：运动要每*两*个驱动周期才重复。相继的摆动略有差别，图案要两个循环才重复一次。这是一次**倍周期分岔**，它发生在 $1.06$ 与 $1.07$ 之间的某处。

$\gamma = 1.081$ 时四个值重复出现：$-0.3539, -0.0856, -0.505, -0.1091$：周期 $4$。$1.07$ 处的两个值各自一分为二。$\gamma = 1.0826$ 时八个值互不相同；更长的运行显示它们随后重复，所以周期是 $8$。相继两次分岔之间的 $\gamma$ 区间收缩得很快，从大于 $0.006$ 到不足 $0.002$。

$\gamma = 1.105$ 时毫无重复。数值散布在整个圆周上，其中包括 $-3.0088$——接近倒立位置：单摆现在有时越过顶点。运动是有界的，方程是周期的，但响应不是。正的李雅普诺夫指数证实这是混沌，而不是一个长周期。
:::
:::

$1 \to 2 \to 4 \to 8 \to \dots$ 的倍周期序列，相邻间隔越来越短，在一个有限的驱动强度处积累，越过它运动便成为混沌——这称为**倍周期级联**。它是通往混沌的标准道路之一，而下面的逻辑斯蒂映射中会出现同样的级联、同样的比值。

::: warning 混沌不是数值伪影，也并非每个不规则输出都是混沌
一个不重复的庞加莱截面，原则上可能来自长瞬态、巨大的周期，或收敛得不好的积分。检验的办法是：跑得更久、丢弃更多瞬态；把步长减半，检查截面作为集合是否不变；以及计算李雅普诺夫指数。对上面的清单，以每周期 $2000$ 步重跑，会把 $\gamma = 1.105$ 处 $\phi$ 的各晚期值完全改变（敏感依赖性保证如此），但不会改变该集合的散布特征，而指数算出来是 $0.712$ 而不是 $0.711$。在 $\gamma = 1.07$ 与 $1.081$ 处，截面数值在打印的全部四位数字内一致。
:::

## 敏感依赖与李雅普诺夫指数 {#lyapunov}

混沌的标志性特征是相邻轨道以指数速率分离。设 $\mathbf{x}(t)$ 是一条轨道，$\mathbf{x}(t) + \boldsymbol\delta(t)$ 是相邻的一条，$\abs{\boldsymbol\delta(0)} = \delta_0$ 非常小。

::: definition 李雅普诺夫指数 {#def-lyapunov}
轨道的**最大李雅普诺夫指数**是

$$
\lambda = \lim_{t\to\infty}\lim_{\delta_0\to 0}\frac1t\ln\frac{\abs{\boldsymbol\delta(t)}}{\delta_0},
$$ {#eq-lyapunov}

只要极限存在。$\lambda > 0$ 的有界运动是**混沌**的。若 $\lambda < 0$，相邻轨道收敛，运动被吸引到一个稳定不动点或周期轨道。
:::

内层极限 $\delta_0 \to 0$ 的意思是 $\boldsymbol\delta$ 沿轨道按线性化方程演化。实际上，指数增长的间距没法跟踪很久，因为它很快就长到与吸引子同样大，不再增长。所以下面的清单采用贝内廷（Benettin）与合作者的标准重整化方法：让第二条轨道从距离 $d_0 = 10^{-8}$ 处出发，两条一起积分一个驱动周期，记录 $\ln(d/d_0)$，把间距沿其当前方向缩回 $d_0$，然后重复。对数取平均就是每个周期的指数。间距按 $\sqrt{\Delta\phi^2 + (\Delta\dot\phi/\omega_0)^2}$ 度量，使两个分量都无量纲；指数不依赖这一选择。

$\gamma = 1.105$ 处的结果是每个驱动周期 $\lambda = 0.711$，即每个循环 $e^{0.711} = 2.04$ 倍。初始不确定度每个周期翻一番。$\gamma = 1.06$ 处 $\lambda = -0.255$：扰动每个循环缩为 $e^{-0.255} = 0.77$，运动返回它的周期吸引子。

::: proposition 可预报期限 {#prop-horizon}
若混沌运动的李雅普诺夫指数为 $\lambda > 0$，初态以精度 $\delta_0$ 已知，则预报误差经过大约

$$
t_{\mathrm{p}} = \frac{1}{\lambda}\ln\frac{\Delta}{\delta_0}.
$$ {#eq-horizon}

达到容差 $\Delta$。
:::

::: proof
$\delta_0$ 小，且只要间距比起吸引子的尺寸还小，由 [[#eq-lyapunov]] 有 $\abs{\boldsymbol\delta(t)} \approx \delta_0e^{\lambda t}$。令它等于 $\Delta$ 并对 $t$ 求解，即得公式。
:::

对数是无情之处。对 $\gamma = 1.105$ 的单摆，初始角度精确到 $10^{-8}\,\mathrm{rad}$，可得精确到 $1\,\mathrm{rad}$ 的预报，维持 $\ln(10^8)/0.711 \approx 26$ 个周期。把测量提高一百万倍、到 $10^{-14}$，预报也只延长到 $45$ 个周期。洛伦兹（Lorenz）对大气的估计——误差加倍时间为几天——正是天气预报无论观测多么好都会在一两周后失去技巧的原因。

::: proposition 李雅普诺夫指数与耗散 {#prop-lyapunov-sum}
对 $N$ 维相空间中的流，一条轨道的 $N$ 个李雅普诺夫指数 $\lambda_1 \ge \dots \ge \lambda_N$ 满足 $\sum_a\lambda_a = \langle\nabla\cdot\mathbf{F}\rangle$，即散度沿轨道的时间平均。对哈密顿系统，这个和为零。对受驱摆 [[#eq-ddp]]，在频闪映射的 $(\phi, \dot\phi)$ 平面中，两个指数之和为单位时间 $-2\beta$。
:::

::: proof {collapsed}
**证明概要。** 指数度量的是初始条件小球的各主方向的平均对数增长率，所以它们的和是其体积的平均对数增长率。按 [[analytical-mechanics/hamiltonian#thm-liouville]] 证明中的计算，体积元按 $\dot J = (\nabla\cdot\mathbf{F})J$ 演化，于是 $\frac1t\ln J(t)$ 是散度的时间平均。哈密顿流的散度为零。对变量 $(\phi, \dot\phi)$ 中的 [[#eq-ddp]]，$\nabla\cdot\mathbf{F} = \partial_\phi\dot\phi + \partial_{\dot\phi}(-2\beta\dot\phi + \cdots) = -2\beta$，是常数。全部 $N$ 个指数的精确定义，以及它们对几乎每条轨道都存在这一事实，是奥谢列茨（Oseledets）的乘性遍历定理；见奥特（Ott）的《Chaos in Dynamical Systems》第 4 章。
:::

于是一个耗散的混沌系统在一个方向拉伸、在另一个方向更强烈地压缩。它被吸引到的那个集合在庞加莱截面中面积为零，但它既不是一条曲线也不是一个点集：它是一个**奇怪吸引子**，一个分形，被反复的拉伸与折叠无限分层。

::: quiz
两个天气模型只在初始温度场的精度上不同：一个精确到 $0.1\,\mathrm{K}$，另一个到 $0.001\,\mathrm{K}$。若误差按指数增长、加倍时间为两天，第二个模型的有效预报大约能长多少？
- [ ] 长一百倍。
- [ ] 大约长一倍。
- [x] 无论原来的预报期限多长，都长约十三天。
- [ ] 不会更长，因为混沌使每个预报立刻变得毫无用处。
::: solution
由 [[#eq-horizon]]，期限是 $(1/\lambda)\ln(\Delta/\delta_0)$。把 $\delta_0$ 缩小 $100$ 倍，加的是 $(1/\lambda)\ln 100$。加倍时间为两天时 $\lambda = \ln 2/(2\,\mathrm{days})$，所以收益是 $2\ln 100/\ln 2 \approx 13.3$ 天。一百倍的改进买到的是一个固定的额外时长，而不是一百倍的预报。
:::
:::

## 逻辑斯蒂映射 {#logistic}

庞加莱截面把连续的流变成了映射：一条规则 $\mathbf{x}_{k+1} = \mathbf{G}(\mathbf{x}_k)$，给出下一个驱动周期的状态。映射比流探索起来快得多，而一个一维映射就已经显示出通往混沌的整条倍周期之路。

::: definition 逻辑斯蒂映射 {#def-logistic}
对参数 $0 \le r \le 4$，**逻辑斯蒂映射**是 $x_{k+1} = f(x_k)$，其中

$$
f(x) = rx(1 - x), \qquad 0 \le x \le 1.
$$ {#eq-logistic}
:::

它作为资源受限的种群模型流行开来：$rx$ 是增长，$(1 - x)$ 是限制增长的拥挤。它对物理学的意义在于：它是最简单的带单个鼓包的光滑映射，而它的许多性质为每一张这样的映射所共享，包括强耗散流的庞加莱映射。

映射的**不动点**是 $f(x^*) = x^*$ 的解。它的稳定性由导数决定。

::: theorem 映射不动点的稳定性 {#thm-map-stability}
设 $f$ 连续可微，$x^*$ 是它的不动点。若 $\abs{f'(x^*)} < 1$，每个足够靠近 $x^*$ 出发的轨道都收敛到它。若 $\abs{f'(x^*)} > 1$，每个靠近（但不在）$x^*$ 出发的轨道终会离开它。
:::

::: proof
设 $\abs{f'(x^*)} < 1$，取 $c$ 使 $\abs{f'(x^*)} < c < 1$。由 $f'$ 连续，存在区间 $I = [x^* - \eps, x^* + \eps]$，在其上 $\abs{f'} \le c$。对 $I$ 中的 $x$，中值定理给出 $\abs{f(x) - x^*} = \abs{f(x) - f(x^*)} \le c\abs{x - x^*}$。于是 $f(x)$ 仍在 $I$ 中，且由归纳法 $\abs{x_k - x^*} \le c^k\abs{x_0 - x^*} \to 0$。反之若 $\abs{f'(x^*)} > 1$，取 $1 < c < \abs{f'(x^*)}$ 和一个使 $\abs{f'} \ge c$ 的区间；只要轨道留在该区间内就有 $\abs{x_k - x^*} \ge c^k\abs{x_0 - x^*}$，它只会增长，所以轨道必须离开。
:::

逻辑斯蒂映射有不动点 $x^* = 0$ 与 $x^* = 1 - 1/r$。因为 $f'(x) = r(1 - 2x)$，$f'(0) = r$，$f'(1 - 1/r) = 2 - r$。$1 < r < 3$ 时非零不动点稳定，$(0, 1)$ 内的每个种群都稳定到它。$r = 3$ 时 $f'(x^*) = -1$，不动点在一次振幅增长的振荡中失去稳定性，振荡落定为一个周期二的圈。

::: example 2 周期圈 {#ex-two-cycle}
对 $r > 3$ 求逻辑斯蒂映射的 2 周期圈，并对 $r = 3.2$ 算出它的两个点。
::: solution
2 周期点满足 $f(f(x)) = x$ 但不是不动点。方程 $f(f(x)) - x = 0$ 是四次方程，而它必然以不动点为根，所以能被 $x(x - 1 + 1/r)$ 整除，也就是被 $f(x) - x = -rx(x - 1 + 1/r)$ 整除。做除法（或注意到 2-圈 $p, q$ 满足 $q = rp(1 - p)$ 与 $p = rq(1 - q)$，将两式相减）剩下二次方程

$$
r^2x^2 - r(r + 1)x + (r + 1) = 0, \qquad x = \frac{(r + 1) \pm\sqrt{(r + 1)(r - 3)}}{2r}.
$$

根仅在 $r \ge 3$ 为实：2-圈恰好在不动点失去稳定性之处诞生。$r = 3.2$ 时，$\sqrt{(4.2)(0.2)} = \sqrt{0.84} = 0.9165$，且

$$
p = \frac{4.2 + 0.9165}{6.4} = 0.7995, \qquad q = \frac{4.2 - 0.9165}{6.4} = 0.5130.
$$

验证：$3.2(0.7995)(0.2005) = 0.5130$ 且 $3.2(0.5130)(0.4870) = 0.7995$。$r = 3.2$ 下逐年迭代的种群最终就在这两个值之间交替。由 [[#exr-two-cycle-stability]]，该圈在 $3 < r < 1 + \sqrt6 = 3.4495$ 内稳定，此后它再度倍周期。
:::
:::

::: widget plot
f: r*x*(1-x); r*(r*x*(1-x))*(1-r*x*(1-x)); x
x: 0, 1
y: 0, 1
sliders: r=2.8:2.5:4:0.01
labels: f(x); f(f(x)); y = x
caption: 逻辑斯蒂映射 $f$、它的二次迭代 $f\circ f$ 与对角线。$f$ 的不动点在第一支曲线与对角线相交之处；2-周期点是第二支曲线的额外交点。$r = 2.8$ 时，二次迭代与对角线只在不动点处相交。把 $r$ 拖过 $3$，看 $f\circ f$ 在不动点处的斜率如何陡过 $1$——随后两侧各出现新的交点：即前面算过的 2-圈。$r = 3.2$ 时它们落在 $0.513$ 与 $0.799$ 附近。$r = 4$ 时 $f$ 的峰顶达到 $1$，映射完全混沌。
:::

$r$ 继续增大，故事重演。2-圈在 $r_2 = 1 + \sqrt6 = 3.449490$ 失去稳定性，被稳定的 4-圈取代；它在 $r_3 = 3.544090$ 让位于 8-圈，接着 $r_4 = 3.564407$ 处 16-圈，$r_5 = 3.568759$ 处 32-圈，依此类推。分岔点积累于 $r_\infty = 3.569946$，超过它，多数 $r$ 值给出混沌轨道，中间夹杂着周期的**窗**，其中最大的是 $r = 3.83$ 附近一个稳定的 3-圈。

::: theorem 费根鲍姆普适性 {#thm-feigenbaum}
对逻辑斯蒂映射，以及对区间上经历倍周期级联的每一族带单个二次极大值的光滑单参数映射族，相继倍周期的参数值 $r_n$ 满足

$$
\lim_{n\to\infty}\frac{r_n - r_{n-1}}{r_{n+1} - r_n} = \delta = 4.669201609\ldots,
$$

对每一族都是同一个常数。第二个普适常数 $\alpha = 2.502907875\ldots$ 给出圈的几何结构相继尺寸的比。
:::

::: proof {collapsed}
这是对一条定理的陈述：费根鲍姆 1978 年从数值实验与一个重整化论证出发把它猜了出来，1982 年由奥斯卡·兰福德（Oscar Lanford）证明，其中重整化算子不动点的存在性由计算机辅助证明。思路是：二次迭代 $f\circ f$ 在极大值附近、按 $-\alpha$ 重标度之后，看起来像一个参数更大的新的单峰映射；反复施行这一操作收敛到一个普适函数，而 $\delta$ 是该操作的不稳定特征值。通俗的介绍见斯特罗加茨（Strogatz）§10.7，数学处理见科莱（Collet）与埃克曼（Eckmann）的《Iterated Maps on the Interval as Dynamical Systems》（1980）。
:::

普适性正是逻辑斯蒂映射在物理上有用的原因。受驱摆级联的分岔比、滴水水龙头的、利布沙贝尔（Libchaber）与毛雷尔（Maurer）1980 年实验里液氦对流的，都趋于同一个 $4.669$——因为在强耗散把它们压平成几乎一维的曲线之后，它们的庞加莱映射都是带单个鼓包的映射。

### 映射的李雅普诺夫指数

对一维映射，相邻轨道的间距每步乘以 $\abs{f'(x_k)}$，所以李雅普诺夫指数是平均

$$
\lambda = \lim_{n\to\infty}\frac1n\sum_{k=0}^{n-1}\ln\abs{f'(x_k)}.
$$ {#eq-lyapunov-map}

$r = 4$ 时可以精确算出：变量代换 $x = \sin^2(\pi y/2)$ 把逻辑斯蒂映射变成**帐篷映射** $y \mapsto 1 - \abs{1 - 2y}$，它把每个区间拉伸 $2$ 倍，结果是 $\lambda = \ln 2$ 精确成立（[[#exr-tent]]）。对一百万次迭代的直接数值平均证实了这一点，并显示指数如何随 $r$ 变化：

```python
import math
def lyap(r, n=10**6, x=0.3):
    s = 0.0
    for _ in range(1000): x = r*x*(1-x)
    for _ in range(n):
        x = r*x*(1-x); s += math.log(abs(r*(1-2*x)))
    return s/n
for r in (2.8, 3.2, 3.5, 3.83, 4.0):
    print(r, round(lyap(r), 4))
print(1+math.sqrt(6), math.log(2))
```

输出：

```
2.8 -0.2231
3.2 -0.9163
3.5 -0.8725
3.83 -0.3697
4.0 0.6931
3.449489742783178 0.6931471805599453
```

::: example 解读逻辑斯蒂指数 {#ex-logistic-lyap}
解释输出中每个指数的符号与数值，并手工核验 $r = 2.8$ 处的值。
::: solution
$r = 2.8$ 时轨道收敛到不动点 $x^* = 1 - 1/2.8 = 0.6429$，所以 [[#eq-lyapunov-map]] 的每一项最终都等于 $\ln\abs{f'(x^*)} = \ln\abs{2 - 2.8} = \ln 0.8 = -0.2231$，正是打印的值。$r = 3.2$ 时轨道是 [[#ex-two-cycle]] 的 2-圈，指数是圈的乘数 $\abs{f'(p)f'(q)} = \abs{-r^2 + 2r + 4} = 0.16$ 的对数之半：$\frac12\ln 0.16 = -0.9163$，与打印一致。$r = 3.5$ 时吸引子是稳定的 4-圈，$\lambda$ 又是负的。$r = 3.83$ 在 $r_\infty$ 之外，指数也是负的：这是 3 周期窗，混沌范围内的秩序孤岛。$r = 4$ 时指数为 $0.6931 = \ln 2$（四位小数），为正：混沌。倒数第二行在数值上确认了 $r_2 = 1 + \sqrt 6$。
:::
:::

## 哈密顿系统中的混沌 {#hamiltonian-chaos}

受驱阻尼单摆是耗散的。哈密顿系统不可能有吸引子（由刘维尔定理），但它们仍然可以是混沌的，而且从历史上说，混沌正是在这样的系统中被发现的。

一个 $n$ 自由度的可积哈密顿系统有 $n$ 个独立的对合守恒量（两两泊松括号为零），它的有界运动旋绕在 $n$ 维**不变环面**上，环面由 [[analytical-mechanics/hamiltonian#ex-action-angle]] 的作用变量标记。对两个自由度，能量面上的庞加莱截面把每个环面显示为一条光滑闭曲线。把哈密顿量稍微扰动一下——非线性地耦合两个振子，或加入第三个引力天体——问环面能否存活。

::: theorem KAM 定理 {#thm-kam}
设 $H = H_0(J) + \eps H_1(J, \varphi)$ 是可积哈密顿量的光滑扰动，其频率 $\partial H_0/\partial J$ 非退化地依赖作用变量。则 $\eps$ 足够小时，$H_0$ 的多数不变环面——即那些频率比离有理数足够远的环面——作为 $H$ 的轻微变形的不变环面存活下来。被破坏集合的测度在 $\eps \to 0$ 时趋于零。
:::

这一定理由柯尔莫哥洛夫（Kolmogorov，1954）、阿诺德（Arnold，1963）与莫瑟（Moser，1962）给出，远远超出本课程的范围；阿诺德的《经典力学的数学方法》（*Mathematical Methods of Classical Mechanics*）附录 8 给出概观。它的信息有两面。弱扰动的系统大体是规则的，这就是太阳系能存活几十亿年的原因。但频率比接近有理数的环面——共振——会碎裂成一串串岛，周围包着薄薄的**混沌层**；$\eps$ 增大时，这些层变宽、合并成混沌海。于是庞加莱截面上同时出现光滑曲线、岛链与散点。埃农（Hénon）与海尔斯（Heiles）1964 年在星系中恒星运动的模型里正好发现了这幅图像，而小行星带中的柯克伍德空隙——位于与木星公转周期成简单整数比的轨道上——正是混沌运动把小行星清扫出去的区域。

::: history 从三体问题到蝴蝶
1887 年，瑞典国王奥斯卡二世悬赏征求 $N$ 体问题的收敛级数解。亨利·庞加莱（Henri Poincaré）得奖，但正当他的论文在《Acta Mathematica》排印时，他发现了一个错误，自费收回了那一版；在修正版（1890）中，他证明三体问题存在"缠绕"得极其复杂的轨道——同宿纠缠——并且除经典积分外没有别的解析积分。他 1908 年写道，初始条件的微小差异可以在最终现象中产生极大的差异，以致预言成为不可能。此后这一主题在物理学中长期沉寂，直到爱德华·洛伦兹（Edward Lorenz）在麻省理工学院（MIT）的一台 Royal McBee 计算机上运行一个十二变量的天气模型：他用印出的数值四舍五入后的数字重启一次运行，发现得到了一个完全不同的预报；他的论文「Deterministic Nonperiodic Flow」（《Journal of the Atmospheric Sciences》，1963）把这一效应化简到三个方程。罗伯特·梅（Robert May）的综述「Simple mathematical models with very complicated dynamics」（《Nature》，1976）让逻辑斯蒂映射广为人知；李天岩（Tien-Yien Li）与詹姆斯·约克（James Yorke）的「Period three implies chaos」（1975）为这门学科定了名；米切尔·费根鲍姆（Mitchell Feigenbaum）1975–78 年在洛斯阿拉莫斯用一台可编程计算器发现了普适常数 $\delta$，1978 年发表在《Journal of Statistical Physics》上。
:::

## 后续内容 {#leads}

一个混沌的哈密顿系统是否均匀地遍历它的整个能量面——这正是 [[statistical-mechanics/microcanonical]] 赖以立足的遍历假设。混沌系统的数值方法，包括在实验中诊断混沌所用的时间序列与谱，在 [[computation/chaos-and-data]]。在 [[quantum-2]] 的量子力学中，轨道的缺失消除了指数敏感，"量子混沌"研究的取而代之是经典混沌系统的能级如何分布。流体中的湍流，[[continuum]]，是无穷多自由度的混沌，仍是经典物理学的重大未解问题之一。

::: summary
- $\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x})$ 的不动点由雅可比矩阵的特征值分类：鞍点、结点、焦点、中心。阻尼单摆底部是稳定焦点，顶部是鞍点。
- 由庞加莱-本迪克松定理，平面自治系统的有界运动止于不动点或闭轨道；混沌需要三维，而受驱的一自由度系统恰好有三维。
- 庞加莱截面每个驱动周期对状态采样一次。对受驱阻尼单摆，它在 $\gamma = 1.06$–$1.083$ 附近显示 $1, 2, 4, 8$ 周期构成的级联，在 $\gamma = 1.105$ 处显示混沌。
- 最大李雅普诺夫指数度量相邻轨道分离的平均指数速率；用重整化算得混沌单摆的它约每个驱动周期 $0.71$。预报在 $(1/\lambda)\ln(\Delta/\delta_0)$ 之后失效。
- 李雅普诺夫指数之和等于相空间散度的平均：哈密顿系统为零，单摆为 $-2\beta$。
- 逻辑斯蒂映射 $x \mapsto rx(1 - x)$ 在 $1 < r < 3$ 有稳定不动点，$3 < r < 1 + \sqrt6$ 有 2-圈，倍周期级联积累于 $r_\infty = 3.5699$，$r = 4$ 处有 $\lambda = \ln 2$ 的混沌。
- 费根鲍姆的 $\delta = 4.6692$ 对带单个鼓包的映射是普适的。在哈密顿系统中，KAM 定理说多数环面经受小扰动而存活，混沌藏在共振附近的薄层里。
:::

## 习题 {#exercises}

::: exercise 逻辑斯蒂映射的一个不动点 {level=1 check="0.6"}
对 $r = 2.50$，求逻辑斯蒂映射的非零不动点，并判定它是否稳定。
::: solution
$x^* = 1 - 1/r = 1 - 0.400 = 0.600$。该处的导数是 $f'(x^*) = 2 - r = -0.500$，$\abs{f'} < 1$，所以由 [[#thm-map-stability]] 它是稳定的。负号意味着相邻轨道从上、下两侧交替逼近它，且每步把距离减半。
:::
:::

::: exercise 加倍映射 {level=1 check="ln(2)"}
加倍映射是 $[0, 1)$ 上的 $x_{k+1} = 2x_k \bmod 1$。求它的李雅普诺夫指数，并解释 $x_0$ 的二进制数码如何使它对初始条件的敏感依赖一目了然。
::: solution
除跳跃点外导数处处为 $2$，所以 [[#eq-lyapunov-map]] 的每一项都是 $\ln 2$，$\lambda = \ln 2 = 0.693$。二进制下，乘以 $2$ 把数码左移一位，而丢掉整数部分就是丢掉最高位数码。于是 $x_k$ 由 $x_0$ 从第 $(k+1)$ 位起的二进制数码给出。前 $50$ 位二进制数码相同的两个初值——大约相差 $10^{-15}$——给出前 $50$ 步一致、此后再不相干的轨道。
:::
:::

::: exercise 预报单摆 {level=1 check="ln(1e8)/0.711"}
对 $\gamma = 1.105$、每驱动周期 $\lambda = 0.711$ 的受驱单摆，估计初始误差 $10^{-8}\,\mathrm{rad}$ 长到 $1\,\mathrm{rad}$ 需要多少个驱动周期。
::: solution
由 [[#eq-horizon]]，$t_{\mathrm{p}} = \ln(1/10^{-8})/0.711 = 18.42/0.711 = 25.9$ 个周期。由于 $\ln(10) = 2.30$，初始精度每多一位十进制数字，只多换来 $2.30/0.711 = 3.2$ 个周期。
:::
:::

::: exercise 阻尼单摆的鞍点 {level=2 check="(-0.5+sqrt(4.25))/2"}
对 $\ddot\theta + 0.500\,\dot\theta + \sin\theta = 0$，求雅可比矩阵在倒立位置 $\theta = \pi$ 处的特征值，给出正的那个。它的物理意义是什么？
::: solution
$\gamma = 0.5$、$\omega_0 = 1$ 时，$\theta = \pi$ 处的雅可比矩阵是 $\begin{pmatrix}0&1\\1&-0.5\end{pmatrix}$，特征方程为 $\lambda^2 + 0.5\lambda - 1 = 0$。根为 $\lambda = \frac12(-0.5 \pm\sqrt{0.25 + 4}) = \frac12(-0.5 \pm\sqrt{4.25})$，即 $0.781$ 与 $-1.281$。正特征值是离开倒立位置的小位移的增长速率：单摆按 $e^{0.781t}$ 从顶点跌落。它的特征向量 $(1, 0.781)$ 是不稳定流形的方向；负特征值的特征向量是唯一的趋近方向——沿它出发、速度恰好合适的单摆会缓缓爬到顶点。
:::

::: exercise 估计费根鲍姆常数 {level=2 check="(3.544090-3.449490)/(3.564407-3.544090)"}
用 $r_2 = 3.449490$、$r_3 = 3.544090$ 与 $r_4 = 3.564407$，由比值 $(r_3 - r_2)/(r_4 - r_3)$ 估计 $\delta$。然后用 $\delta = 4.6692$ 预言 $r_5$，并与 $r_5 = 3.568759$ 比较。
::: solution
$(r_3 - r_2)/(r_4 - r_3) = 0.094600/0.020317 = 4.656$，距 $\delta = 4.6692$ 已在 $0.3\%$ 以内。把下一个区间预言为 $(r_4 - r_3)/\delta = 0.020317/4.6692 = 0.004351$，得 $r_5 \approx 3.564407 + 0.004351 = 3.568758$，与真值符合到六位数字。把剩余区间的几何级数求和可估计积累点：$r_\infty \approx r_4 + (r_4 - r_3)/(\delta - 1) = 3.564407 + 0.005537 = 3.569944$，而真值是 $3.569946$。
:::

::: exercise 混沌单摆中的收缩 {level=2 check="-3*pi/2"}
对 $\omega_0 = 3\pi$、$\beta = \omega_0/4$ 的 [[#eq-ddp]] 单摆，求频闪映射的两个李雅普诺夫指数之和（每个驱动周期，$T = 1$）。已知 $\gamma = 1.105$ 处最大指数为 $0.711$，求另一个指数，以及庞加莱截面中一个小面积每个周期缩小的因子。
::: solution
由 [[#prop-lyapunov-sum]]，和为 $-2\beta T = -2(3\pi/4)(1) = -3\pi/2 = -4.712$ 每周期。第二个指数是 $-4.712 - 0.711 = -5.423$。面积每周期按 $e^{-4.712} = 0.0090$ 收缩：在一个周期内，截面中的一小块在一个方向被拉伸 $e^{0.711} = 2.0$ 倍，在另一个方向被压缩 $e^{-5.42} = 0.0044$ 倍。反复进行，便产生奇怪吸引子的精细分层结构：在任何放大倍率下面积为零，而长度不为零。
:::

::: exercise 2 周期圈的稳定性 {level=3 #exr-two-cycle-stability}
证明映射 $f$ 的一个 2-圈 $\{p, q\}$ 在 $\abs{f'(p)f'(q)} < 1$ 时稳定。对逻辑斯蒂映射，证明 $f'(p)f'(q) = -r^2 + 2r + 4$，并推出 2-圈恰好在 $3 < r < 1 + \sqrt6$ 内稳定。
::: hint
对 $g = f\circ f$ 应用 [[#thm-map-stability]]，它的不动点包括 $p$ 与 $q$。至于乘积，用 [[#ex-two-cycle]] 中那个二次方程的 $p + q$ 与 $pq$。
:::
::: solution
$p$ 与 $q$ 是 $g = f\circ f$ 的不动点。由链式法则，$g'(p) = f'(f(p))f'(p) = f'(q)f'(p)$，在 $q$ 处同理。由用于 $g$ 的 [[#thm-map-stability]]，当 $\abs{f'(p)f'(q)} < 1$ 时圈吸引附近的轨道。

对逻辑斯蒂映射，$f'(x) = r(1 - 2x)$，所以

$$
f'(p)f'(q) = r^2\bigl(1 - 2(p + q) + 4pq\bigr).
$$

由二次方程 $r^2x^2 - r(r + 1)x + (r + 1) = 0$，$p + q = (r + 1)/r$ 且 $pq = (r + 1)/r^2$。于是

$$
f'(p)f'(q) = r^2 - 2r(r + 1) + 4(r + 1) = -r^2 + 2r + 4.
$$

$r = 3$ 时它为 $1$，圈正是在这里从不动点诞生。随 $r$ 增大它递减（其导数 $-2r + 2 < 0$），并在 $r^2 - 2r - 5 = 0$ 即 $r = 1 + \sqrt6 = 3.449$ 处达到 $-1$。在 $3 < r < 1 + \sqrt6$ 内乘积严格介于 $-1$ 与 $1$ 之间，圈稳定；超过它，乘积小于 $-1$，圈失稳，让位于 4-圈。$r = 3.2$ 时乘积为 $0.16$，[[#ex-logistic-lyap]] 中用的正是这个值。
:::
:::

::: exercise 逻辑斯蒂映射在 $r = 4$ {level=3 #exr-tent}
证明代换 $x = \sin^2(\pi y/2)$（$0 \le y \le 1$）把 $r = 4$ 的逻辑斯蒂映射共轭为帐篷映射 $T(y) = 1 - \abs{1 - 2y}$。由此推出 $r = 4$ 的逻辑斯蒂映射几乎每条轨道的李雅普诺夫指数都是 $\ln 2$。
::: hint
用 $4\sin^2\theta\cos^2\theta = \sin^22\theta$。至于指数，比较两个映射对小区间的拉伸，并注意除端点外，变量代换把长度只乘上有界因子。
:::
::: solution
设 $x = h(y) = \sin^2(\pi y/2)$。则 $1 - x = \cos^2(\pi y/2)$，且

$$
4x(1 - x) = 4\sin^2\frac{\pi y}{2}\cos^2\frac{\pi y}{2} = \sin^2(\pi y).
$$

$0 \le y \le \frac12$ 时 $T(y) = 2y$，$h(T(y)) = \sin^2(\pi y)$。$\frac12 \le y \le 1$ 时 $T(y) = 2 - 2y$，$h(T(y)) = \sin^2(\pi - \pi y) = \sin^2(\pi y)$。两种情形都有 $f(h(y)) = h(T(y))$：$r = 4$ 的逻辑斯蒂映射就是换了装束的帐篷映射，$f = h\circ T\circ h^{-1}$。

帐篷映射除 $y = \frac12$ 外处处 $\abs{T'} = 2$，所以避开那一个点的每条轨道的李雅普诺夫指数都是 $\ln 2$。对逻辑斯蒂映射，把共轭关系迭代起来得 $f^n = h\circ T^n\circ h^{-1}$，由链式法则

$$
\ln\abs{(f^n)'(x_0)} = \ln\abs{h'(y_n)} + n\ln 2 - \ln\abs{h'(y_0)}.
$$

除以 $n$ 并令 $n \to \infty$，只要 $\ln\abs{h'(y_n)}$ 不随 $n$ 线性增长，首末两项就没有贡献；这对几乎每条轨道都成立，因为 $h'(y) = \frac\pi2\sin(\pi y)$ 只在端点为零，而典型的帐篷映射轨道均匀分布，很少造访端点的邻域。于是 $\lambda = \ln 2$，与数值 $0.6931$ 一致。
:::
