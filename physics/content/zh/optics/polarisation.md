透过偏振太阳镜看湿路面上的反光，侧一侧头：反光变暗，又回来了。用同一副镜片看与太阳方向成直角的一片晴空，转动镜片：天空暗了。这两种效应对纵波（例如声波）都不可能发生，因为纵波的振动只有一个方向——沿传播方向。除强度、颜色和相位之外，光还有另一个属性：它的电场在垂直于光线的平面内振动的方向。这个属性就是**偏振**。

[[magnetism/electromagnetic-waves]] 中的电磁波，其 $\mathbf{E}$ 与 $\mathbf{B}$ 都垂直于传播方向且互相垂直。[[optics/interference]] 与 [[optics/diffraction]] 中的干涉和衍射把场当作标量处理；当每一列波的偏振都相同时，这就足够了。在这里，向量本性成了主角。本章用两分量的**琼斯（Jones）向量**描述偏振态，用 $2\times 2$ **琼斯矩阵**描述光学元件，推导马吕斯定律，从麦克斯韦（Maxwell）的边界条件得到菲涅耳公式，再由它得到布儒斯特角，并解释双折射晶体、波片与旋光性。

## 偏振态与琼斯向量 {#jones}

考虑一列沿 $z$ 传播的单色平面波。它的电场在 $xy$ 平面内，两个分量各以同一频率振动，各有自己的振幅和相位。我们把场写成复数表达式的实部，

$$
\mathbf{E}(z, t) = \operatorname{Re}\left[\begin{pmatrix} E_x \\ E_y \end{pmatrix} e^{i(kz - \omega t)}\right],
$$ {#eq-field}

其中 $E_x$ 与 $E_y$ 是复常数。它们的模是两个分量的振幅，各自的相位就是该分量的相位。

::: definition 琼斯向量 {#def-jones}
单色平面波的**琼斯向量**是 [[#eq-field]] 中复振幅组成的列 $\mathbf{J} = (E_x, E_y)\T$。它的辐照度正比于 $\lvert E_x\rvert^2 + \lvert E_y\rvert^2$。只差一个整体复数因子的两个琼斯向量描述同一个偏振态。
:::

整体相位不影响偏振态，因此通常作归一化。重要的情形有以下几种。

- 与 $x$ 轴成 $\theta$ 角的**线偏振**：$\mathbf{J} = (\cos\theta, \sin\theta)\T$。两个分量同相，场沿一条固定直线来回振动。
- **圆偏振**：$\mathbf{J} = \tfrac{1}{\sqrt2}(1, \pm i)\T$。两个分量等幅、相位相差四分之一个周期，场向量端点画出一个圆。
- **椭圆偏振**：任何其他 $\mathbf{J}$。场向量的端点描出一个椭圆；线偏振和圆偏振是它的两个退化极限。

要看那个圆，取 $\mathbf{J} = \tfrac{1}{\sqrt2}(1, i)\T$ 并观察 $z = 0$ 处。由于 $\operatorname{Re}(e^{-i\omega t}) = \cos\omega t$，$\operatorname{Re}(ie^{-i\omega t}) = \sin\omega t$，场为 $\tfrac{1}{\sqrt2}(\cos\omega t, \sin\omega t)$。它从 $+x$ 转向 $+y$，对迎面而来的波观察呈逆时针。

::: warning 旋向的约定并不统一
本章在 [[#eq-field]] 的 $e^{-i\omega t}$ 时间约定下，态 $(1, i)\T/\sqrt2$ 对望向波源的观察者呈逆时针旋转。光学界通常的约定（Hecht，Born 与 Wolf）称之为**左旋圆偏振**，而把 $(1, -i)\T/\sqrt2$ 称为右旋。许多工程教材改为沿传播方向观察，于是把同一列波叫作右旋；另一些书用 $e^{+i\omega t}$，这会把每个琼斯向量取复共轭。凡旋向要紧之处，务必先声明约定。
:::

两个态 $\mathbf{J}_1$ 与 $\mathbf{J}_2$ 若满足 $\mathbf{J}_1^\dagger\mathbf{J}_2 = \bar{E}_{1x}E_{2x} + \bar{E}_{1y}E_{2y} = 0$（复共轭加在第一个向量上），就称**正交**。水平与垂直线偏振态正交；两个圆偏振态也正交，因为 $\overline{(1, i)}\cdot(1, -i) = (1)(1) + (-i)(-i) = 1 - 1 = 0$。任何一对正交态都构成一组基：每个偏振态都可以表为水平与垂直的组合，也同样可以表为左旋与右旋的组合。能把两个正交态分开成两束的器件，例如方解石棱镜，会按光在该基下各分量模的平方把光分配到两束之中。

**自然光**（非偏振光），如太阳光或白炽灯的光，不能用任何琼斯向量描述。它的偏振在 [[optics/interference#def-coherence]] 的相干时间尺度上随机变化，快得没有任何探测器跟得上，因此平均而言没有哪个方向更受偏爱。**部分偏振光**是偏振光与自然光的混合。描述它们需要四个斯托克斯（Stokes）参数，或一个 $2\times2$ 相干矩阵（参见 Hecht，§8.12）；就本章而言，只要知道自然光可以当作任意两个正交偏振的非相干等量混合来处理就够了，它们的辐照度相加。

## 偏振片与马吕斯定律 {#malus}

**线偏振片**透过电场沿其**透振轴**的分量，吸收（或反射掉）垂直分量。偏振片（Polaroid）薄膜靠定向排列的长链分子吸收沿分子方向的场分量；线栅靠细密的平行导体；方解石棱镜则把两个分量在空间上分开。

::: definition 琼斯矩阵 {#def-jones-matrix}
把输入琼斯向量 $\mathbf{J}$ 线性地变为输出 $\mathbf{J}' = M\mathbf{J}$ 的光学元件由它的**琼斯矩阵** $M$ 描述。按 $M_1, M_2, \dots, M_k$ 的顺序经过的元件，作用相当于乘积 $M_k\cdots M_2M_1$。透振轴与 $x$ 轴成 $\theta$ 角的线偏振片，其矩阵为

$$
P(\theta) = \begin{pmatrix} \cos^2\theta & \sin\theta\cos\theta \\ \sin\theta\cos\theta & \sin^2\theta \end{pmatrix}.
$$ {#eq-polariser}
:::

这矩阵是向单位向量 $\hat{\mathbf{u}} = (\cos\theta, \sin\theta)\T$ 的投影：$P(\theta) = \hat{\mathbf{u}}\hat{\mathbf{u}}\T$，故 $P\mathbf{J} = (\hat{\mathbf{u}}\cdot\mathbf{J})\,\hat{\mathbf{u}}$。它保留沿轴的分量，抹去垂直于轴的分量。和任何投影一样，它满足 $P^2 = P$：再放一块完全相同的偏振片不改变任何东西。

::: theorem 马吕斯定律 {#thm-malus}
辐照度为 $I_0$ 的线偏振光射在一块理想线偏振片上，其透振轴与偏振方向成 $\theta$ 角。透射辐照度为

$$
I = I_0\cos^2\theta .
$$ {#eq-malus}

辐照度为 $I_0$ 的自然光，不论偏振片如何取向，透射辐照度都是 $I_0/2$。
:::

::: proof
取坐标轴使入射光沿 $x$ 偏振：$\mathbf{J} = (E_0, 0)\T$，$I_0 \propto E_0^2$。由 [[#eq-polariser]]，

$$
P(\theta)\mathbf{J} = E_0\begin{pmatrix} \cos^2\theta \\ \sin\theta\cos\theta \end{pmatrix} = E_0\cos\theta\begin{pmatrix} \cos\theta \\ \sin\theta \end{pmatrix}.
$$

输出是沿透振轴、振幅为 $E_0\cos\theta$ 的线偏振光，其辐照度为 $I_0\cos^2\theta$。

自然光是沿透振轴偏振的光与垂直于它偏振的光的非相干混合，两者辐照度各为 $I_0/2$。前者完全透过，后者完全不透过，非相干光的辐照度相加，故 $I = I_0/2$。等价地，把 $\cos^2\theta$ 对所有角度取平均：$\langle\cos^2\theta\rangle = \tfrac12$。
:::

透振轴正交（$\theta = 90^\circ$）的两块偏振片不透光。在两者*之间*再插一块透振轴处于中间角度的偏振片，光又透过去了。中间那块并不是在添加光，而是在旋转偏振方向，而且要为此付出代价。

::: example 三块偏振片 {#ex-three}
辐照度为 $I_0$ 的自然光透过三块理想偏振片。第一块透振轴竖直，第二块成 $45^\circ$，第三块水平。求透射辐照度。若拿走中间那块会怎样？
::: solution
由 [[#thm-malus]]，经第一块后光是竖直偏振的，辐照度为 $I_0/2$。第二块与它成 $45^\circ$，由 [[#eq-malus]]

$$
I_2 = \frac{I_0}{2}\cos^2 45^\circ = \frac{I_0}{4},
$$

光现在偏振于 $45^\circ$ 方向。第三块与这个新方向成 $45^\circ$，所以

$$
I_3 = \frac{I_0}{4}\cos^2 45^\circ = \frac{I_0}{8}.
$$

透出的光是八分之一。若没有中间那块，竖直偏振的光遇到水平透振轴，$\cos^2 90^\circ = 0$，什么都不透出。用琼斯语言说，$P(0)P(\tfrac{\pi}{4})P(\tfrac{\pi}{2}) \neq 0$ 而 $P(0)P(\tfrac{\pi}{2}) = 0$：偏振片的矩阵不可交换，每个元件的存在与次序都重要。
:::
:::

## 反射：菲涅耳公式与布儒斯特角 {#fresnel}

光射到两种透明介质的界面时，反射多少？[[optics/geometric]] 中的几何光学无法回答。答案来自麦克斯韦方程组，而且依赖偏振。两种情形就够了，因为任何偏振都是它们的组合。**s-偏振**（源自德语 *senkrecht*，垂直）的 $\mathbf{E}$ 垂直于入射面；**p-偏振**（*parallel*，平行）的 $\mathbf{E}$ 位于入射面内。

::: theorem 菲涅耳公式 {#thm-fresnel}
光从折射率为 $n_1$ 的非磁性介质射向折射率为 $n_2$ 的介质，入射角 $\theta_i$ 与折射角 $\theta_t$ 由斯涅尔定律联系。反射场与入射场的振幅比为

$$
r_s = \frac{n_1\cos\theta_i - n_2\cos\theta_t}{n_1\cos\theta_i + n_2\cos\theta_t}, \qquad r_p = \frac{n_2\cos\theta_i - n_1\cos\theta_t}{n_2\cos\theta_i + n_1\cos\theta_t},
$$ {#eq-fresnel}

反射率为 $R_s = r_s^2$ 与 $R_p = r_p^2$。正入射时两者都化为

$$
R = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2 .
$$ {#eq-normal-r}
:::

::: proof
我们给出 s-偏振的证明；p-偏振是同样的论证，只是 $\mathbf{E}$ 与 $\mathbf{B}$ 互换角色（Griffiths，§9.3.3 或 Hecht，§4.6.2）。把界面放在 $z = 0$，入射面取 $xz$ 面，于是对 s-偏振，三个电场都沿 $y$ 方向，振幅为 $E_i$、$E_r$、$E_t$。界面上的相位匹配，如 [[optics/geometric#thm-snell]] 中那样，使三列波有相同的 $x$ 依赖和频率，所以我们只需比较振幅。

界面上没有自由电荷和电流，$\mathbf{E}$ 与 $\mathbf{H} = \mathbf{B}/\mu_0$ 的切向分量连续。这里 $\mathbf{E}$ 的切向分量就是整个场：

$$
E_i + E_r = E_t .
$$

折射率为 $n$ 的介质中，平面波的磁场大小为 $B = nE/c$，方向同时垂直于 $\mathbf{E}$ 与传播方向。对向 $+z$ 传播的入射波与透射波，$\mathbf{B}$ 的切向（$x$）分量为 $-B\cos\theta$；对向 $-z$ 传播的反射波，它为 $+B\cos\theta_i$。切向 $\mathbf{B}$ 连续（两侧都是 $\mu = \mu_0$）给出

$$
-n_1E_i\cos\theta_i + n_1E_r\cos\theta_i = -n_2E_t\cos\theta_t .
$$

代入 $E_t = E_i + E_r$：

$$
n_1\cos\theta_i\,(E_i - E_r) = n_2\cos\theta_t\,(E_i + E_r), \qquad \frac{E_r}{E_i} = \frac{n_1\cos\theta_i - n_2\cos\theta_t}{n_1\cos\theta_i + n_2\cos\theta_t},
$$

即 $r_s$。正入射时 $\cos\theta_i = \cos\theta_t = 1$，$r_s = (n_1 - n_2)/(n_1 + n_2)$；$r_p$ 在那里反号，这只是 p 场方向的约定问题，因此两个反射率都等于 [[#eq-normal-r]]。
:::

$r$ 的符号就是 [[optics/interference#prop-film]] 中用到的反射相位变化：正入射时若 $n_2 > n_1$，则 $r_s < 0$，光在光密介质表面反射时相位变化 $\pi$。空气中射向折射率 $1.50$ 的玻璃，正入射时 $R = (0.50/2.50)^2 = 0.040$：每个表面反射 $4\%$ 的光。钻石（$n = 2.417$）则是 $17\%$，这是它璀璨夺目的部分原因。

随入射角增大，两个反射率的表现大不相同。表中给出光从空气射向折射率 $1.50$ 的玻璃时由 [[#eq-fresnel]] 算出的数值。

| $\theta_i$ | $R_s$ | $R_p$ | 自然光 $\tfrac12(R_s + R_p)$ |
|---|---|---|---|
| $0^\circ$ | $0.0400$ | $0.0400$ | $0.0400$ |
| $30^\circ$ | $0.0578$ | $0.0252$ | $0.0415$ |
| $45^\circ$ | $0.0920$ | $0.0085$ | $0.0502$ |
| $56.3^\circ$ | $0.1479$ | $0$ | $0.0740$ |
| $70^\circ$ | $0.2996$ | $0.0425$ | $0.1710$ |
| $80^\circ$ | $0.5386$ | $0.2368$ | $0.3877$ |
| $89^\circ$ | $0.9395$ | $0.8689$ | $0.9042$ |

$R_s$ 一路上升，在掠入射时到达 $1$。$R_p$ 在一个角度处降为零，然后又上升。接近掠入射时，任何表面都成了不错的镜子，这就是湖面把对岸映得如此清楚的原因。

::: theorem 布儒斯特角 {#thm-brewster}
p-偏振的反射率恰在一个入射角处为零，该角称**布儒斯特（Brewster）角** $\theta_B$，满足

$$
\tan\theta_B = \frac{n_2}{n_1}.
$$ {#eq-brewster}

此时反射光线与折射光线互相垂直：$\theta_B + \theta_t = 90^\circ$。
:::

::: proof
由 [[#eq-fresnel]]，$r_p = 0$ 当且仅当 $n_2\cos\theta_i = n_1\cos\theta_t$。斯涅尔定律给出 $n_1\sin\theta_i = n_2\sin\theta_t$。设 $n_1 \neq n_2$，把两式相乘：

$$
n_1n_2\sin\theta_i\cos\theta_i = n_1n_2\sin\theta_t\cos\theta_t, \qquad \sin 2\theta_i = \sin 2\theta_t .
$$

两角都在 $0$ 与 $90^\circ$ 之间，所以或者 $2\theta_i = 2\theta_t$，或者 $2\theta_i = 180^\circ - 2\theta_t$。第一种情形由斯涅尔定律将要求 $n_1 = n_2$。于是 $\theta_i + \theta_t = 90^\circ$，从而 $\sin\theta_t = \cos\theta_i$。斯涅尔定律化为 $n_1\sin\theta_i = n_2\cos\theta_i$，即 [[#eq-brewster]]。反过来，若 $\tan\theta_i = n_2/n_1$，令 $\theta_t = 90^\circ - \theta_i$；则 $n_1\sin\theta_i = n_2\cos\theta_i = n_2\sin\theta_t$，所以这就是折射角。于是 $n_2\cos\theta_i = n_2\sin\theta_t$，$n_1\cos\theta_t = n_1\sin\theta_i$，由斯涅尔定律二者相等，故 $r_p = 0$。由于 $\tan$ 在 $(0^\circ, 90^\circ)$ 内一一对应，该角唯一。
:::

有一个物理图像。反射波由第二种介质中被折射场驱动的电子辐射。振荡的电偶极子沿自身轴向不辐射任何能量，见 [[electrodynamics/radiation]]。p-偏振的偶极子在入射面内、垂直于折射光线的方向振荡；当反射光线恰与折射光线垂直时，它正落在偶极子的轴向上，于是那个方向没有辐射。

::: example 水面的眩光 {#ex-brewster}
阳光在平静的湖面（$n = 1.333$）上反射。入射角多大时反射光完全偏振？偏振朝哪个方向？该角下 s-偏振光被反射的比例是多少？偏振太阳镜应如何取向？
::: solution
由 [[#eq-brewster]] 取 $n_1 = 1.00$、$n_2 = 1.333$，

$$
\theta_B = \arctan 1.333 = 53.1^\circ ,
$$

即太阳的高度为 $36.9^\circ$。此角下 $R_p = 0$，所以反射光是纯 s-偏振的：其电场垂直于入射面；对水平表面来说，那就是水平方向。

对 s-分量，$\theta_t = 90^\circ - 53.1^\circ = 36.9^\circ$，且

$$
r_s = \frac{\cos 53.1^\circ - 1.333\cos 36.9^\circ}{\cos 53.1^\circ + 1.333\cos 36.9^\circ} = \frac{0.6001 - 1.0664}{0.6001 + 1.0664} = -0.2798, \qquad R_s = 0.0783 .
$$

所以阳光中 s-偏振那一半约有 $7.8\%$ 被反射，占总光的 $3.9\%$。透振轴竖直的太阳镜几乎完全挡住这片水平偏振的眩光，同时把其他物体发出的自然光透过一半。其他角度下眩光只是部分偏振，但仍以水平为主，所以同一取向同样有效。
:::
:::

以布儒斯特角透射的光只是部分偏振，因为 $R_s$ 很小：光透过一块玻璃表面，s-分量减少 $15\%$，p-分量一点不少。**玻片堆**由十来块以布儒斯特角排列的玻璃板组成，能剥掉足够的 s-光，成为可用的偏振器。气体激光器管两端的窗口以布儒斯特角倾斜，使 p-偏振光透过时没有反射损耗；因此激光以 p-偏振起振。

用玻璃在布儒斯特角反射的光来检验一块偏振片的取向。下列说法哪个正确？
- [ ] 反射光是 p-偏振的，其电场位于入射面内
- [x] 反射光是 s-偏振的，其电场垂直于入射面
- [ ] 反射光是自然光，因为偏振被透射光带走了
- [ ] 在布儒斯特角什么光都不反射
::: solution
布儒斯特角下 $r_p = 0$，所以凡被反射的都是 s-偏振的，电场垂直于入射面。反射并非为零：对玻璃，$56.3^\circ$ 处 $R_s = 0.148$。透射光只是部分偏振。辨认没有标记的偏振片的透振轴正是用这个方法：使它对着地板或桌面反光的消光位置，就是透振轴的方向。
:::
:::

## 双折射与波片 {#birefringence}

玻璃的折射率不依赖场的方向。在许多晶体中它依赖，因为电子在某些方向上被束缚得更紧。这样的介质是**双折射**的，也称双重折射。

::: definition 单轴晶体 {#def-uniaxial}
**单轴**晶体只有一个特殊方向，即**光轴**。垂直于光轴偏振的光无论沿哪个方向传播，都以**寻常折射率** $n_o$ 传播。电场有沿光轴分量的光，其折射率介于 $n_o$ 与**非常折射率** $n_e$ 之间；当光垂直于光轴传播且电场沿光轴时，折射率恰为 $n_e$。**双折射**为 $\Delta n = n_e - n_o$。
:::

方解石（冰洲石）的双折射之大是出了名的：在 $589.3\,\mathrm{nm}$ 处，$n_o = 1.6584$，$n_e = 1.4864$，故 $\Delta n = -0.172$。结晶石英弱得多，$n_o = 1.5443$，$n_e = 1.5534$，$\Delta n = +0.0091$。一束自然光斜射入方解石晶体（相对光轴倾斜），会分裂成两条偏振互相垂直的光线；透过方解石菱面体看一个印刷的字，字会重影。尼科尔（Nicol）、格兰–汤姆孙（Glan–Thompson）等方解石棱镜把两条光线完全分开，是纯度最高的线偏振器。

### 波片

沿板面含光轴切割一块厚度 $d$ 的晶片，让光正入射透过。电场沿光轴与垂直光轴的两个分量以不同速度传播。折射率较小的那个轴是**快轴**，另一个是**慢轴**。出射时，慢分量落后的相位为

$$
\Gamma = \frac{2\pi}{\lambda_0}\,\lvert n_e - n_o\rvert\,d ,
$$ {#eq-retardance}

称为**延迟量**。忽略整体相位，快轴沿 $x$ 的波片的琼斯矩阵为

$$
W(\Gamma) = \begin{pmatrix} 1 & 0 \\ 0 & e^{i\Gamma} \end{pmatrix},
$$ {#eq-waveplate}

因为在 $e^{i(kz - \omega t)}$ 约定下，多出的光程表现为慢分量上多出的相位 $e^{+i\Gamma}$。**四分之一波片**满足 $\Gamma = \pi/2$，**半波片**满足 $\Gamma = \pi$（或这些值加上 $2\pi$ 的整数倍）。

::: proposition 四分之一波片与半波片 {#prop-plates}
1. 与四分之一波片的轴成 $45^\circ$ 的线偏振光出射时为圆偏振；反过来，圆偏振光出射时为线偏振。
2. 快轴在 $\phi$ 方向的半波片，把 $\theta$ 方向线偏振的光变为 $2\phi - \theta$ 方向的线偏振：偏振方向关于快轴作镜像反射，等效于旋转了 $2(\phi - \theta)$。
:::

::: proof
对于 (1)，快轴沿 $x$，

$$
W(\tfrac{\pi}{2})\,\frac{1}{\sqrt2}\begin{pmatrix} 1 \\ 1 \end{pmatrix} = \frac{1}{\sqrt2}\begin{pmatrix} 1 \\ i \end{pmatrix},
$$

即圆偏振；输入取 $-45^\circ$ 时输出为 $(1, -i)\T/\sqrt2$，旋向相反。把 $W(\tfrac{\pi}{2})$ 作用在 $(1, \mp i)\T/\sqrt 2$ 上得 $(1, \mp i\cdot i)\T/\sqrt2 = (1, \pm 1)\T/\sqrt2$，即线偏振。

对于 (2)，先取 $\phi = 0$。此时 $W(\pi) = \operatorname{diag}(1, -1)$，

$$
W(\pi)\begin{pmatrix} \cos\theta \\ \sin\theta \end{pmatrix} = \begin{pmatrix} \cos\theta \\ -\sin\theta \end{pmatrix} = \begin{pmatrix} \cos(-\theta) \\ \sin(-\theta) \end{pmatrix},
$$

即 $-\theta$ 方向的线偏振，$\theta$ 关于 $x$ 轴的镜像。对一般的快轴方向 $\phi$，旋转坐标即可：在转过 $\phi$ 的坐标轴中，输入在 $\theta - \phi$，输出在 $-(\theta - \phi)$，再转回原来的轴得 $\phi - (\theta - \phi) = 2\phi - \theta$。
:::

半波片因此是线偏振的旋转器：把波片转过 $\phi$，出射偏振就转过 $2\phi$，且不损失光——这是偏振片做不到的。

::: example 石英四分之一波片 {#ex-qwp}
求对 $589.3\,\mathrm{nm}$ 起四分之一波片作用的最薄石英片。为什么不制作方解石波片？
::: solution
在 [[#eq-retardance]] 中令 $\Gamma = \pi/2$，取 $\lvert\Delta n\rvert = 1.5534 - 1.5443 = 0.0091$：

$$
d = \frac{\lambda_0}{4\lvert\Delta n\rvert} = \frac{589.3\,\mathrm{nm}}{4 \times 0.0091} = 1.62\times10^{4}\,\mathrm{nm} = 16.2\,\mu\mathrm{m}.
$$

这样的"零级"波片很脆弱，所以商品波片常是更厚的"多级"波片，$\Gamma = \pi/2 + 2\pi m$，它们只在一个波长处工作，且随温度漂移；或者把两片波片的快轴正交胶合，使只有厚度差起作用。

对方解石，$d = 589.3/(4 \times 0.172)\,\mathrm{nm} = 857\,\mathrm{nm}$，不足一微米：不可能抛光到所需的精度。方解石的大双折射适合分束，不适合做延迟器。云母和拉伸聚合物薄膜的双折射很小，是另外两种常用的波片材料。
:::
:::

把一块双折射片放在正交偏振片之间，其轴成 $45^\circ$。若 $\Gamma = \pi$，这片把光旋转 $90^\circ$，光完全透过第二块偏振片；若 $\Gamma = 2\pi$，光一点不透。一般地，透射比例为 $\sin^2(\Gamma/2)$，而 $\Gamma$ 依赖波长，于是白光透过时带上颜色。受力的塑料和玻璃会变成双折射的，$\Delta n$ 正比于当地应力，于是机械零件的透明模型放在正交偏振片之间，就会以彩色条纹显示出它的应力图样。这种**光弹性**方法在计算机应力分析出现之前是标准的工程工具，同样的彩色条纹也能透过偏振太阳镜在汽车后窗上看到。

::: example 正交偏振片之间的波片 {#ex-crossed}
一块延迟量为 $\Gamma$、快轴成 $45^\circ$ 的延迟片放在竖直偏振片与水平偏振片之间，入射的是辐照度为 $I_0$ 的自然光。用琼斯矩阵证明透射辐照度为 $\tfrac12 I_0\sin^2(\Gamma/2)$。对一块对 $589.3\,\mathrm{nm}$ 的石英半波片，忽略 $\Delta n$ 的色散，求波长 $486.1\,\mathrm{nm}$ 与 $656.3\,\mathrm{nm}$ 处的值。
::: solution
经竖直偏振片后光为 $\mathbf{J} = (0, 1)\T$，辐照度 $I_0/2$。在转过 $45^\circ$、沿波片快慢轴的坐标中，这个向量的分量是 $\tfrac{1}{\sqrt2}(1, 1)$；波片把慢分量乘以 $e^{i\Gamma}$，得 $\tfrac{1}{\sqrt2}(1, e^{i\Gamma})$。转回原来的坐标轴，水平分量——最后一块偏振片唯一透过的分量——为

$$
E_x = \frac{1}{\sqrt2}\left(\frac{1}{\sqrt2} - \frac{e^{i\Gamma}}{\sqrt2}\right) = \frac{1 - e^{i\Gamma}}{2} = -ie^{i\Gamma/2}\sin\frac{\Gamma}{2}.
$$

于是 $\lvert E_x\rvert^2 = \sin^2(\Gamma/2)$，透射辐照度为 $\tfrac12 I_0\sin^2(\Gamma/2)$。半波片（$\Gamma = \pi$）把 $I_0/2$ 全部透过；全波片一点都不透。

对石英，$589.3\,\mathrm{nm}$ 处的半波厚度为 $d = \lambda_0/(2\lvert\Delta n\rvert) = 589.3/(2 \times 0.0091)\,\mathrm{nm} = 32.4\,\mu\mathrm{m}$。取同样的 $d$ 与 $\Delta n$，由 [[#eq-retardance]] 得 $486.1\,\mathrm{nm}$ 处 $\Gamma = 3.81\,\mathrm{rad}$，$656.3\,\mathrm{nm}$ 处 $\Gamma = 2.82\,\mathrm{rad}$，所以 $\sin^2(\Gamma/2)$ 分别为 $0.893$ 与 $0.975$。蓝光的透过略少于红光，绿光最多；在白光下这片看起来带有极淡的颜色。波片越厚，各种颜色之间的差别增长得越快，这正是光弹性彩色条纹绚丽夺目的由来。
:::
:::

### 菲涅耳菱镜

全反射在 [[optics/geometric#def-critical]] 中见过：它把两种偏振都全部反射，却给它们不同的相移。菲涅耳设计了一种玻璃菱镜，光在其中以约 $54.6^\circ$ 发生两次全反射；对折射率 $1.51$ 的玻璃，每一次都在 p-分量与 s-分量之间引入 $45^\circ$ 的相位差。两次反射共 $90^\circ$，即四分之一的波延迟——它不像晶体波片那样依赖波长。

## 旋光性 {#activity}

某些材料让线偏振的方向随光的通过稳定旋转，不需要任何外加场。这就是**旋光性**，出现在结构具有手性的晶体（如石英）和手性分子的溶液（如糖溶液）中。石英沿光轴每毫米把 $589.3\,\mathrm{nm}$ 光的偏振面旋转 $21.7^\circ$；右形与左形石英晶体的转向相反。

菲涅耳把它解释为**圆双折射**：左旋与右旋圆偏振光以略不同的折射率 $n_L$ 与 $n_R$ 传播。线偏振是两种圆偏振态之和，$(1, 0)\T = \tfrac12[(1, i)\T + (1, -i)\T]$。经过厚度 $d$ 后，两者获得相对相位 $2\pi(n_L - n_R)d/\lambda_0$，重新合并后得到旋转了

$$
\rho\,d = \frac{\pi(n_L - n_R)d}{\lambda_0}.
$$

的线偏振。对石英，$21.7^\circ\,\mathrm{mm}^{-1}$ 对应 $\lvert n_L - n_R\rvert = 7.1\times10^{-5}$，比它的线双折射小一百倍。旋光仪利用这一效应测量糖的浓度：蔗糖溶液每分米光程、每克每毫升旋转 $66.5^\circ$，所以 $2.00\,\mathrm{dm}$ 长的管中 $0.100\,\mathrm{g/mL}$ 的溶液把偏振面旋转 $13.3^\circ$。

沿光束方向加磁场，会在任何材料中诱导出类似的旋转，即**法拉第效应**，由法拉第（Faraday）于 1845 年发现，是光与磁的第一个联系。它与天然旋光性有一个重要区别：把光反射回来再穿过材料，旋转会加倍而不是抵消。法拉第隔离器正是利用这一点阻止反射光回到激光器。

::: application 自然界中的偏振
空气分子对太阳光的瑞利（Rayleigh）散射在离开太阳 $90^\circ$ 的方向上强烈偏振，因为散射偶极子沿自身轴向不辐射；蜜蜂和某些鸟类靠天空的偏振图样导航。液晶显示把一层能旋转偏振的扭曲液晶夹在正交偏振片之间；加上电压就解开扭曲，从而切换每个像素。3D 电影把左、右眼画面以旋向相反的圆偏振送出。无线电与卫星天线按特定偏振设计，宇宙微波背景辐射的偏振则携带着早期宇宙的信息。
:::

::: history 双折射、偏振与横波
巴托林（Bartholin）1669 年描述了冰洲石的双折射，惠更斯（Huygens）在《论光》(*Traité de la lumière*, 1690) 中用球面子波与椭球面子波两种次级波解释了它，却解释不了两条光线为什么在通过第二块晶体时表现不同。1808 年，马吕斯（Malus）透过方解石晶体看巴黎卢森堡宫窗户反射的阳光，发现转动晶体时两个像中的一个消失了。他创造了 *polarisation*（偏振）一词，并给出了 $\cos^2\theta$ 定律。

布儒斯特（Brewster）1815 年发现了定律 $\tan\theta_B = n$。阿拉戈（Arago）1811 年发现石英的旋光性，毕奥（Biot）1815 年在松节油和糖溶液等液体中发现了它。菲涅耳（Fresnel）与阿拉戈（Arago）在 1816–1819 年间证明偏振方向互相垂直的两束光不发生干涉，菲涅耳到 1821 年得出光波纯粹是横波的结论，杨（Young）也曾得出同样的结论；1823 年菲涅耳发表了他关于反射振幅的公式。尼科尔（Nicol）1828 年制成了他的方解石棱镜，法拉第（Faraday）1845 年发现磁光旋转，巴斯德（Pasteur）1848 年把旋光性追溯到分子的手性。兰德（Land）在 1929 年前后发明了薄膜偏振片，琼斯（Jones）1941 年创立了琼斯矩阵方法。
:::

## 后续内容 {#leads}

本章对透明介质导出的菲涅耳公式，把折射率取为复数后，可推广到 [[electrodynamics/waves-in-media]] 中的金属与吸收介质；解释布儒斯特角与天空偏振的振荡电偶极子辐射图样，在 [[electrodynamics/radiation]] 中详细给出。琼斯向量是一个贯穿量子力学的思想的第一次露面：一个由归一化复向量描述的两态系统，线偏振与圆偏振是同一空间的两组基。单光子的偏振正是 [[quantum-1]] 中的两态系统，而偏振光子在量子密钥分发中携带着密钥。

::: summary
- 偏振是 $\mathbf{E}$ 在垂直于传播方向的横向平面内的方向。单色偏振态是一个琼斯向量 $(E_x, E_y)\T$：线偏振取 $(\cos\theta, \sin\theta)\T$，圆偏振取 $(1, \pm i)\T/\sqrt2$。务必说明旋向约定。
- 光学元件是琼斯矩阵，作用顺序从右到左。与 $x$ 轴成 $\theta$ 角的线偏振片是投影 $\hat{\mathbf{u}}\hat{\mathbf{u}}\T$。
- 马吕斯定律：偏振光 $I = I_0\cos^2\theta$；理想偏振片透过自然光的一半。正交偏振片不透光，但在两者之间放一块 $45^\circ$ 的偏振片，能透过最初自然光的 $I_0/8$。
- 菲涅耳公式由切向 $\mathbf{E}$ 与 $\mathbf{H}$ 的连续性得出。正入射时 $R = ((n_1 - n_2)/(n_1 + n_2))^2$，玻璃是 $4\%$。
- $R_p = 0$ 于布儒斯特角 $\tan\theta_B = n_2/n_1$（玻璃 $56.3^\circ$，水 $53.1^\circ$），此时反射光线与折射光线垂直；反射光因而是纯 s-偏振的。
- 双折射晶体有两个折射率（方解石 $n_o = 1.6584$，$n_e = 1.4864$）。延迟量为 $\Gamma = 2\pi\lvert\Delta n\rvert d/\lambda_0$ 的晶片是波片：四分之一波片把 $45^\circ$ 线偏振变为圆偏振，半波片使偏振方向关于其快轴作镜像。
- 旋光性是圆双折射，偏振面的旋转与光程成正比（石英为 $21.7^\circ/\mathrm{mm}$）。
:::

## 习题 {#exercises}

::: exercise 马吕斯定律 {level=1 check="0.25"}
线偏振光透过一块偏振片，其透振轴与偏振方向成 $60^\circ$。透射的辐照度比例是多少？
::: solution
由 [[#eq-malus]]，$I/I_0 = \cos^2 60^\circ = (0.500)^2 = 0.25$。四分之一的光透过，偏振方向沿偏振片的透振轴。
:::
:::

::: exercise 玻璃的布儒斯特角 {level=1 check="56.3"}
光在空气中射向折射率 $1.50$ 的玻璃，求反射的布儒斯特角，以度计，保留三位有效数字。
::: solution
由 [[#eq-brewster]]，$\theta_B = \arctan 1.50 = 56.3^\circ$。折射角随后为 $90^\circ - 56.3^\circ = 33.7^\circ$，且确实 $\sin 56.3^\circ/\sin 33.7^\circ = 0.832/0.555 = 1.50$，与斯涅尔定律一致。
:::
:::

::: exercise 钻石表面的反射 {level=1 check="0.172"}
求空气中钻石表面（$n = 2.417$）正入射时反射光的比例，保留三位有效数字。
::: solution
由 [[#eq-normal-r]]，

$$
R = \left(\frac{2.417 - 1}{2.417 + 1}\right)^2 = \left(\frac{1.417}{3.417}\right)^2 = (0.4147)^2 = 0.172 .
$$

这超过玻璃的 $4\%$ 的四倍，是钻石显得璀璨的原因之一。
:::
:::

::: exercise 中间偏振片成 30° {level=2 check="0.09375"}
辐照度为 $I_0$ 的自然光射向两块正交偏振片，在两者之间插入第三块，其透振轴与第一块成 $30^\circ$。求透射辐照度占 $I_0$ 的比例。
::: solution
第一块后 $I_0/2$。中间一块与它成 $30^\circ$：$I_0/2 \times \cos^2 30^\circ = I_0/2 \times 0.75 = 0.375\,I_0$。最后一块与中间一块成 $90^\circ - 30^\circ = 60^\circ$：$0.375\,I_0 \times \cos^2 60^\circ = 0.375 \times 0.25\,I_0 = 0.09375\,I_0$。这是原始光的 $3/32$，小于中间偏振片在 $45^\circ$ 时得到的 $1/8$。
:::
:::

::: exercise 用半波片旋转偏振 {level=2 check="40"}
竖直偏振的光（相对水平 $x$ 轴在 $90^\circ$ 方向）透过一块半波片，其快轴与 $x$ 轴成 $65^\circ$。出射光的偏振方向与 $x$ 轴成多少度（取 $0$ 到 $180$ 之间）？
::: solution
由 [[#prop-plates]]，输出角为 $2\phi - \theta = 2 \times 65^\circ - 90^\circ = 40^\circ$。偏振面关于快轴作镜像：输入在 $65^\circ$ 一侧 $25^\circ$ 处，输出在另一侧 $25^\circ$ 处。光没有损失——换成透振轴在 $40^\circ$ 的偏振片只透 $\cos^2 50^\circ = 41\%$。
:::
:::

::: exercise 糖溶液 {level=2 check="0.15"}
旋光仪的管长 $2.00\,\mathrm{dm}$，装蔗糖溶液，把偏振面旋转 $19.95^\circ$。用蔗糖的比旋光度 $66.5^\circ$ 每分米每 $\mathrm{g/mL}$，求浓度（以 $\mathrm{g/mL}$ 计）。
::: solution
旋转角 =（比旋光度）×（长度）×（浓度），所以

$$
c = \frac{19.95^\circ}{66.5^\circ\,\mathrm{dm^{-1}\,(g/mL)^{-1}} \times 2.00\,\mathrm{dm}} = \frac{19.95}{133.0}\,\mathrm{g/mL} = 0.150\,\mathrm{g/mL}.
$$

这个测量存在以 $180^\circ$ 为倍数的多值性，因为旋转 $199.95^\circ$ 看起来一模一样；实际中用第二根较短的管来检验。
:::

::: exercise 多块偏振片 {level=3}
正交偏振片挡住所有光。在两者之间再插入 $N - 1$ 块偏振片，透振轴以 $90^\circ/N$ 的等步长逐级旋转，共 $N$ 步。证明沿第一块透振轴偏振的偏振光透过最后一块的比例是 $\cos^{2N}(\pi/2N)$，并证明 $N \to \infty$ 时它趋于 $1$。计算 $N = 10$ 时的值。
::: hint
取对数，对小 $x$ 用 $\ln\cos x = -x^2/2 + O(x^4)$。
:::
::: solution
每一块偏振片与前一块的夹角都是 $\pi/(2N)$。由 [[#eq-malus]]，每一步把辐照度乘以 $\cos^2(\pi/2N)$，共 $N$ 步，所以透射比例为 $T_N = \cos^{2N}(\pi/2N)$。

求极限，令 $x = \pi/(2N)$。则

$$
\ln T_N = 2N\ln\cos x .
$$

$x$ 小时，$\cos x = 1 - x^2/2 + O(x^4)$，$\ln(1 - u) = -u + O(u^2)$，所以 $\ln\cos x = -x^2/2 + O(x^4)$。于是

$$
\ln T_N = 2N\left(-\frac{\pi^2}{8N^2} + O(N^{-4})\right) = -\frac{\pi^2}{4N} + O(N^{-3}) \to 0,
$$

由指数函数的连续性，$T_N \to 1$。$N = 10$ 时，$T_{10} = \cos^{20}(9^\circ) = 0.781$；近似值 $e^{-\pi^2/40} = 0.781$ 与之吻合。极限情形下，偏振片把偏振面旋转 $90^\circ$ 而毫无损失，这正是显示器中扭曲的液晶连续做到的事情。
:::

::: exercise 菲涅耳公式与能量守恒 {level=3}
对 s-偏振，透射振幅比为 $t_s = E_t/E_i = 2n_1\cos\theta_i/(n_1\cos\theta_i + n_2\cos\theta_t)$。透过单位界面面积的功率是辐照度乘以 $\cos\theta$，而折射率 $n$ 的介质中辐照度正比于 $nE^2$。证明

$$
R_s + \frac{n_2\cos\theta_t}{n_1\cos\theta_i}\,t_s^2 = 1,
$$

并解释该结果。
::: solution
先从 [[#thm-fresnel]] 的证明导出 $t_s$：$E_t = E_i + E_r$，故 $t_s = 1 + r_s$，代入 [[#eq-fresnel]] 的 $r_s$，

$$
t_s = \frac{(n_1\cos\theta_i + n_2\cos\theta_t) + (n_1\cos\theta_i - n_2\cos\theta_t)}{n_1\cos\theta_i + n_2\cos\theta_t} = \frac{2n_1\cos\theta_i}{n_1\cos\theta_i + n_2\cos\theta_t}.
$$

记 $a = n_1\cos\theta_i$，$b = n_2\cos\theta_t$。则 $r_s = (a - b)/(a + b)$，$t_s = 2a/(a + b)$，于是

$$
R_s + \frac{b}{a}t_s^2 = \frac{(a - b)^2}{(a + b)^2} + \frac{b}{a}\cdot\frac{4a^2}{(a + b)^2} = \frac{a^2 - 2ab + b^2 + 4ab}{(a + b)^2} = \frac{(a + b)^2}{(a + b)^2} = 1 .
$$

解释：射到界面单位面积上的功率正比于 $n_1E_i^2\cos\theta_i$；反射功率正比于 $n_1E_r^2\cos\theta_i$；透射功率正比于 $n_2E_t^2\cos\theta_t$，其中的 $\cos\theta_t$ 计入折射时光束截面的变化。除以入射功率，反射比例是 $R_s$，透射比例是 $T_s = (b/a)t_s^2$。两者之和为 $1$：无损耗界面上能量守恒，本应如此。注意 $T_s \neq t_s^2$：透射振幅大于入射振幅并不矛盾，因为波进入了折射率与光束宽度都不同的介质。
:::
