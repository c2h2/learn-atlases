一壶沸水和一块冰被关在同一个保温箱里，不会保持原样。冰会融化，热水会变凉，足够长的时间之后，两者成为同一池同一温度的水。[[mechanics/work-energy]] 里那本力学账本记的是合力做的功等于动能的变化，它既说不出这个共同温度的名字，也说不出能量将朝哪个方向流动。焦耳还是焦耳。缺的是一个物理量：两个系统恰好在不再因为一冷一热而交换能量时，这个量相等。这个量就是温度。

本章先把定义做严格，再给出把温度变成可用数字的物态方程：理想气体定律。热容放在最后，作为系统沿指定路径受热时的响应。热与功之间的平衡是下一讲 [[thermodynamics/first-law]]。杆和液体的热膨胀是造家用温度计的实用办法，这里不展开；低压气体是通向绝对温标的更好路径。

全文之中，任何公式 $PV = nRT$ 里的 $T$ 都是以开尔文计的热力学温度。同一个状态，用摄氏温度标出的是另一个数。

## 热平衡

温度要能标记东西，系统本身先要处于安定的状态。当系统的宏观性质——压强、体积、插进去的一支温度计的读数——不随时间改变，且内部不再有物质或能量的流动在衰减时，系统处于**内部平衡**。搅拌已经停息。缓慢的化学反应会使样品不合格：那些留到后续课程再说。

**透热壁**允许两个系统交换能量而不交换物质。实验室里一块薄金属板就算一个像样的实现。**绝热壁**阻断这种交换。这个词在 [[thermodynamics/first-law]] 中会对一个没有热的过程再次出现；这里它说的是墙的属性。真实的保温会漏热。理想之墙仍然是正确的语言，正如无摩擦表面对于一道稍后才把摩擦加回去的力学题仍然是正确的语言。

::: definition 热平衡 {#def-equilibrium}
两个系统被透热壁隔开，且它们的宏观性质不随时间改变，则称二者处于**热平衡**。等价地说，若把二者之间的墙从绝热改为透热而两个系统的任何性质都不改变，它们本来就已经处于热平衡。

这个关系记作 $A \sim B$。它是处于内部平衡的系统之间的关系，不是任意一团正在变化中的物质之间的关系。
:::

力学平衡是另一种要求：压强相匹配，于是活塞不加速。扩散平衡——物质已经停止迁移——是第三种要求，需要化学势，那是后面的内容。两种气体可以在相同温度下处于不同压强。温度被引进来只为命名热平衡。

把一块热铜放进冷水，金属与水之间只有透热边界，两者都会变化。铜块变凉，水变温，变化停止。最终这一对处于热平衡。同一块铜，若包裹起来使边界绝热，它保持自己的温度，水保持另一个温度。决定是否需要平衡的是那堵墙，不是铜的某种私有属性。

## 热力学第零定律

设系统 $A$ 已与参考系统 $C$ 接触足够久，使 $A \sim C$；系统 $B$ 另与同一个 $C$ 接触足够久，使 $B \sim C$。现在把 $A$ 与 $B$ 放在一起，还需要进一步实验吗，还是结果已经注定？

你用过的每一支温度计都在赌第二个答案。液柱也好，气体泡也好，就是 $C$。先把它凑近 $A$，再凑近 $B$，若读数相同，就预期 $A$ 与 $B$ 彼此平衡。这个预期不是力学的定理，而是热物理学的一条定律，由实验发现；正是它使单一温标成为可能。

::: theorem 热力学第零定律 {#thm-zeroth}
热平衡是内部平衡的系统之间的一个等价关系。它是自反的、对称的，而且是传递的：

若 $A \sim C$ 且 $B \sim C$，则 $A \sim B$。

传递性就是**热力学第零定律**。这个名字是事后追认的。这条定律在逻辑上先于温度的指派，但它在已有编号的第一、第二定律之后才被陈述。

::: proof
对称性属于定义的一部分。"$A$ 与 $B$ 在透热接触下不发生变化"这句话没有给这对系统定次序，所以 $A \sim B$ 蕴含 $B \sim A$。

自反性用一次分割。取一个处于内部平衡的系统 $A$，想象一堵透热墙画过它，把它分成 $A_1$ 与 $A_2$。内部平衡意味着这两部分不变化，所以 $A_1 \sim A_2$。我们把这读作 $A \sim A$：处于内部平衡的系统与自身热平衡。如果某个假想的分割产生了变化，原来的系统就不处于内部平衡，本来也不在这个关系所定义的集合里。

传递性就是上面陈述的实验定律。它不是从透热壁的定义推出的。墙告诉你可以交换能量的成对系统有哪些；第零定律告诉你，由此得到的平衡把系统分成了类，而不是某种不那么整齐的关系。

一个等价关系把它的集合分成等价类。记 $[A]$ 为与 $A$ 热平衡的所有系统构成的类。则 $[A] = [B]$ 当且仅当 $A \sim B$，两个不同的类没有公共系统。**温度**是这样的类的一个标记。
:::
:::

::: definition 温度 {#def-temperature}
**温度**是热平衡等价类的一个标记 $\theta$。指派满足

$$
\theta(A) = \theta(B) \quad \text{当且仅当} \quad A \sim B.
$$ {#eq-temperature}

任何合法的 $\theta$ 的严格单调函数都是另一种合法标记。[[#thm-zeroth]] 本身选不出摄氏度、开尔文，也选不出水银柱的高度。那些选择是外加的约定，由一支温度计和一个温标固定。
:::

标记相同，意味着两个系统一旦透热接触就处于平衡。标记不同，意味着两者都会变化。温度不是系统的能量：一大瓶温水可以比一小颗更烫的珠子存储更多内能，而热仍然只按温度流动。

::: intuition 一个类共用一个标记
温度计能用，靠的是传递性。泡与房间达到平衡，而任何能与那只泡达到平衡的东西都在房间的类里。刻度上的数字给这个类命名。用一条单调曲线把它重新标号，命名的是同样的类，却会毁掉一切已经认准某种标记的公式，比如理想气体定律。
:::

::: quiz
系统 $A$ 与温度计 $C$ 热平衡，系统 $B$ 与同一支温度计热平衡且读数相同。在 $A$ 与 $B$ 接触之前，第零定律给出了什么？
- [ ] $A$ 一定比 $B$ 热，因为它先被测过
- [x] $A$ 与 $B$ 彼此热平衡
- [ ] $A$ 与 $B$ 有相同的内能
- [ ] 在 $A$、$B$ 真的接触并被观察之前，什么都给不出
::: solution
[[#thm-zeroth]] 陈述的正是平衡具有传递性，所以 $A \sim C$ 且 $B \sim C$ 已经蕴含 $A \sim B$。对 $C$ 的测试就是实验。$A$ 与 $B$ 再接触一次是对定律的检验，不是缺失的前提。温度相同不蕴含内能相同：两个系统可以大小不同、构成不同。
:::
:::

## 温度计与经验温标

**测温属性**是对某个选定仪器而言、在给定等价类内恒定而在相邻等价类中不同的任一可测量 $X$。液柱的长度、定容气体的压强、金属丝的电阻、热电偶的电压都在使用。**经验温度**是选定为严格递增的标度函数 $\theta = f(X)$，并用有限个固定点锚定 $f$。

摄氏温标把冰点指派为 $0$、汽点指派为 $100$，然后内插。两种液体被同两个点约束之后，中间并不吻合，因为它们的膨胀曲线作为等价类的函数不是同一个函数。在 $T$ 应当只是这个类的性质的公式里，这种不吻合是致命的。

所以经验温标是 [[#def-temperature]] 允许的，但它还不是理想气体定律里的 $T$。补救办法是选一种行为在你能够真正逼近的极限下简化的测温物质，并从那个极限定义温标。物质是气体，极限是零压强。

## 理想气体

玻意耳（Robert Boyle）在《新实验》（*New Experiments*）第二版（1662）中测得：一团密闭空气在他保持条件不变时满足 $PV = \text{常数}$。把这个乘积读作"温度固定时"是后来的事。查理（Jacques Charles），以及盖-吕萨克（Joseph Louis Gay-Lussac）在 1802 年的论文中，发现定压下的气体受热均匀膨胀。阿蒙通（Amontons）更早就看到密闭样品的压强随受热升高。在绝对温标上，这些是同一个方程。

::: definition 理想气体 {#def-ideal}
定量**理想气体**是一种模型流体，其平衡态满足

$$
PV = nRT = N k_B T,
$$ {#eq-ideal}

其中 $P$ 是绝对压强，$V$ 是体积，$n$ 是以摩尔计的物质的量，$N$ 是分子数，$T$ 是以开尔文计的热力学温度。气体常数与玻尔兹曼常数（Boltzmann）为

$$
R = 8.314462618\,\mathrm{J\,mol^{-1}\,K^{-1}}, \qquad k_B = 1.380649\times 10^{-23}\,\mathrm{J\,K^{-1}},
$$

且 $N = n N_A$，其中阿伏加德罗（Avogadro）常数 $N_A = 6.02214076\times 10^{23}\,\mathrm{mol^{-1}}$。自 2019 年起，两个常数 $k_B$ 与 $N_A$ 在 SI 中是精确值。它们的乘积修约后就是上面写出的 $R$。
:::

[[#eq-ideal]] 是一个**物态方程**：对平衡态的约束，不是状态之间路径的故事。对定量的简单气体，$P$、$V$、$T$ 中任两个可自由选择，第三个随之而定。液-汽混合还多一个约束。理想气体没有。

物质的量与质量由摩尔质量 $M$（以千克每摩尔计）联系：$n = m/M$，且 $N = m N_A/M$。方程不在乎你数的是摩尔还是分子。数分子时常数是 $k_B$ 而不是 $R$，而 $k_B T$ 是能量。$T = 300\,\mathrm{K}$ 时，

$$
k_B T = (1.380649\times 10^{-23})\times 300 = 4.142\times 10^{-21}\,\mathrm{J}.
$$

这是分子的能量尺度。乘积 $N k_B T = nRT$ 是能量尺度乘以分子数，而 [[#eq-ideal]] 说它等于 $PV$。气体为什么按这个能量成比例地压墙，是 [[thermodynamics/kinetic-theory]] 的问题。这里 $PV = nRT$ 就是我们使用的定律。

$P$ 与 $T$ 是**强度量**：对同一状态的同种气体考虑更大的样品，它们不变。$V$、$n$、$N$ 和内能是**广延量**：样品加倍时它们加倍。理想气体定律尊重这种划分。把 $n$ 换成 $\lambda n$、$V$ 换成 $\lambda V$，同一 $T$ 下的压强不变，因为 $\lambda$ 消掉了。一条通不过这个检验的定律，不可能让 $P$ 是强度量而 $V$ 同时是广延量。

::: proposition 玻意耳定律 {#prop-boyle}
一定量理想气体在固定的热力学温度下，压强与体积的乘积为常数。两个平衡态之间

$$
P_1 V_1 = P_2 V_2.
$$ {#eq-boyle}

::: proof
[[#eq-ideal]] 给出 $PV = nRT$。$n$ 与 $T$ 相同时，右端在两个状态是同一个数，所以左端也相同。这就是玻意耳原初的关系，只不过"温度固定"这个假设现在用开尔文陈述，而不是留作一句实验室操作说明。它是物态方程的特例，不是第二条定律。
:::
:::

::: proposition 体积定律与压强定律 {#prop-charles}
一定量理想气体，

$$
\frac{V_1}{T_1} = \frac{V_2}{T_2} \quad \text{定压下},
$$ {#eq-charles}

以及

$$
\frac{P_1}{T_1} = \frac{P_2}{T_2} \quad \text{定容下}.
$$ {#eq-isochore}

两个等式用的都是热力学温度。把 $T$ 换成摄氏读数，它们就不成立。

::: proof
$n$、$P$ 固定时，[[#eq-ideal]] 给出 $V/T = nR/P$，右端在两个状态之间不变。$n$、$V$ 固定时，$P/T = nR/V$，这个比值同样为两态所共有。把方程的两份抄本相除就是全部论证。如果有人代进以摄氏度计的 $t$，那么 $V/t = nR/P$ 这一步在 [[#def-ideal]] 中没有依据，这套算术也描述不了气体。
:::
:::

::: example 固定容器中的两摩尔气体 {#ex-two-mole}
两摩尔理想气体被保持在 $T = 300\,\mathrm{K}$、体积 $V = 0.0500\,\mathrm{m^3}$。求压强。然后在同一体积下加热到 $360\,\mathrm{K}$，求新的压强。
::: solution
用 $R = 8.314462618\,\mathrm{J\,mol^{-1}\,K^{-1}}$ 的 [[#eq-ideal]]：

$$
P = \frac{nRT}{V} = \frac{2.00\times 8.314462618\times 300}{0.0500} = 9.977\times 10^{4}\,\mathrm{Pa}.
$$

按题目数据的有效数字取三位，$P = 9.98\times 10^{4}\,\mathrm{Pa}$。校核：$PV = nRT$：

$$
nRT = 2.00\times 8.314462618\times 300 = 4.989\times 10^{3}\,\mathrm{J},
$$

而 $(9.977\times 10^{4})\times 0.0500$ 返回同一个 $4.989\times 10^{3}\,\mathrm{J}$。分子数为 $N = n N_A = 1.204\times 10^{24}$。

定 $V$ 与 $n$ 加热即 [[#eq-isochore]]。压强按热力学温度成比例放大：

$$
\frac{P_2}{P_1} = \frac{360}{300} = 1.200, \qquad P_2 = 1.200\times 9.977\times 10^{4} = 1.197\times 10^{5}\,\mathrm{Pa}.
$$

三位有效数字，$P_2 = 1.20\times 10^{5}\,\mathrm{Pa}$。因子 $1.200$ 对这两个温度是精确的；它不依赖 $R$、$n$，也不依赖 $V$。若加热改在定压而非定容下进行，同样的因子就是 $V_2/V_1$。
:::
:::

::: example 把摄氏读数当开尔文用 {#ex-celsius}
一摩尔理想气体在 $T = 300\,\mathrm{K}$ 即 $26.85^\circ\mathrm{C}$ 下占体积 $0.0240\,\mathrm{m^3}$。有人用 [[#eq-ideal]] 算压强，却把 $300$ 换成了 $27$。求真实压强与错误压强，以及错误压强偏小的倍数。
::: solution
真实压强是

$$
P = \frac{(1.00)\times 8.314462618\times 300}{0.0240} = 1.039\times 10^{5}\,\mathrm{Pa}.
$$

误代 $T = 27$ 得到

$$
P_{\text{错}} = \frac{8.314462618\times 27}{0.0240} = 9.354\times 10^{3}\,\mathrm{Pa}.
$$

两个算式的比是 $27/300 = 0.090$。错误压强是真实值的十一分之一，不是舍入误差。在算完的算式末尾加 $273$ 补不回来，因为 $T$ 从一开始就在分子里。先换算成开尔文，再用 [[#eq-ideal]]。与摄氏温标（按温标自身的定义）匹配的换算式是 $T = t + 273.15$，所以 $26.85^\circ\mathrm{C}$ 恰为 $300.00\,\mathrm{K}$，$27.00^\circ\mathrm{C}$ 是 $300.15\,\mathrm{K}$。代 $27$ 不是换算失败，而是拒绝换算。
:::
:::

::: widget isotherm
T: 300
caption: 理想气体的三条等温线。改变温度：标记的点跟随你设定的温度移动；沿一条曲线，压强与体积的乘积保持常数。
:::

拖动温度，标记的点就移动到你设定的等温线上。沿一条曲线 $PV$ 是常数。这个控件展示的是状态，不是过程。室温附近的真实空气与 [[#eq-ideal]] 足够接近，本章的算术用得起；接近液化时就不行了，而且原始的气体温度计压强也还不是 $T$。

## 绝对温标

把稀薄气体保持定容定量，[[#eq-isochore]] 说 $P$ 正比于 $T$。这就是定容气体温度计。实际做法是测一个压强之比，其中分母是固定点上的压强。按开尔文的旧定义，水的三相点被指派为恰好 $273.16\,\mathrm{K}$，未知温度为

$$
T = 273.16\,\mathrm{K}\times \lim_{P_{\mathrm{tp}}\to 0}\frac{P}{P_{\mathrm{tp}}},
$$

极限在定容下取：同一个球泡里放的气体越来越少。极限是全部要点。两种真实气体在同样不大的压强下，比值 $P/P_{\mathrm{tp}}$ 并不完全相同。压强降低时，比值收拢。理想气体温度就是那个公共极限，不是大气压下满满一泡空气的原始读数。

自 2019 年起，开尔文由把 $k_B$ 固定在 [[#def-ideal]] 中的值来定义，而不再给水的三相点指派一个数值温度。摄氏温标由开尔文经下式定义

$$
T = t + 273.15,
$$ {#eq-celsius}

$t$ 以摄氏度计、$T$ 以开尔文计。偏移量按摄氏度的定义是精确的，一度摄氏的大小就是一开尔文的大小。绝对零度是 $0\,\mathrm{K}$，即 $-273.15^\circ\mathrm{C}$。水的冰点非常接近 $0^\circ\mathrm{C}$，但不再是定义的一部分。

偏移 $273.15$ 来自把定压下的 $V \propto (t + 273.15)$ 外推到 $V = 0$。图中没有一种气体真的达到零体积：它先液化或凝固，理想气体模型早已不再适用。绝对零度并不是说一罐空气能被压到没有。

威廉·汤姆孙（William Thomson）1848 年的温标不是这种气体外推。它由卡诺（Carnot）定理建立，使温差不依赖热机里的工作流体。[[thermodynamics/heat-engines]] 把那个构造定量化。理想气体极限与那个热力学温度一致，这就是 [[#eq-ideal]] 可以使用后来出现在卡诺效率里的同一个 $T$ 的原因。任意的经验 $\theta$ 就不行。

::: warning 是开尔文，不是摄氏，也不是原始气体压强
在 $PV = nRT$ 中，符号 $T$ 是以开尔文计的热力学温度。代入摄氏读数不是那种把厘米换算成米的单位换算。它是等价类的另一个函数，[[#prop-charles]] 会直接失效。气体温度计压强也还不是 $T$——仪器按理想气体极限校准之前不是。在工作压强下，球泡里是真实气体，与 [[#eq-ideal]] 有小偏差，两次充气未必吻合。
:::

::: example 等容线的斜率 {#ex-slope}
回到 [[#ex-two-mole]] 的样品：$n = 2.00\,\mathrm{mol}$ 于 $V = 0.0500\,\mathrm{m^3}$。求 $(\partial P/\partial T)_V$，并用它核对从 $300\,\mathrm{K}$ 到 $360\,\mathrm{K}$ 的压强升高。
::: solution
由 [[#eq-ideal]]，$n$、$V$ 固定时，

$$
\left(\frac{\partial P}{\partial T}\right)_V = \frac{nR}{V} = \frac{2.00\times 8.314462618}{0.0500} = 332.6\,\mathrm{Pa\,K^{-1}}.
$$

在有限的定容升温上斜率是常数，所以

$$
\Delta P = 332.6\times 60.0 = 1.995\times 10^{4}\,\mathrm{Pa}.
$$

[[#ex-two-mole]] 中两个压强是 $9.977\times 10^{4}\,\mathrm{Pa}$ 与 $1.197\times 10^{5}\,\mathrm{Pa}$，其差为 $1.995\times 10^{4}\,\mathrm{Pa}$。吻合不是新事实。对这个物态方程，$P$ 在等容线上恰为 $T$ 的线性函数，所以一点处的导数与两点之间的弦是同一个数。真实气体就未必，有限的升高 $\Delta P/\Delta T$ 只能估计导数。
:::
:::

## 物态曲面上的偏导数

物态方程是一张曲面。曲面上的斜率就是偏导数，它们之间的关系不过是链式法则。这个关系是一般性的；理想气体是能手算的例子。

::: proposition 循环关系 {#prop-cyclic}
设定量流体的平衡压强是连续可微函数 $P = P(V, T)$，所在区域内

$$
\left(\frac{\partial P}{\partial V}\right)_T \neq 0, \qquad \left(\frac{\partial P}{\partial T}\right)_V \neq 0.
$$

则 $V$ 可在 $P$ 固定时取为 $T$ 的函数，$T$ 可在 $V$ 固定时取为 $P$ 的函数，且

$$
\left(\frac{\partial P}{\partial V}\right)_T \left(\frac{\partial V}{\partial T}\right)_P \left(\frac{\partial T}{\partial P}\right)_V = -1.
$$ {#eq-cyclic}

::: proof
$P(V, T)$ 的全微分为

$$
\dd P = \left(\frac{\partial P}{\partial V}\right)_T \dd V + \left(\frac{\partial P}{\partial T}\right)_V \dd T.
$$

保持 $P$ 固定，即 $\dd P = 0$，解出等压线的斜率。假设 $(\partial P/\partial V)_T \neq 0$ 允许我们做除法：

$$
\left(\frac{\partial V}{\partial T}\right)_P = -\frac{(\partial P/\partial T)_V}{(\partial P/\partial V)_T}.
$$

两边乘以 $(\partial P/\partial V)_T$，再乘以 $(\partial T/\partial P)_V$：

$$
\left(\frac{\partial P}{\partial V}\right)_T \left(\frac{\partial V}{\partial T}\right)_P \left(\frac{\partial T}{\partial P}\right)_V = -\left(\frac{\partial P}{\partial T}\right)_V \left(\frac{\partial T}{\partial P}\right)_V.
$$

$V$ 固定时，映射 $T \mapsto P(V, T)$ 可逆，因为它的导数 $(\partial P/\partial T)_V$ 不为零。反函数的导数是其倒数，所以 $(\partial T/\partial P)_V = 1/(\partial P/\partial T)_V$，右端的乘积为 $1$。左端等于 $-1$。
:::
:::

对理想气体三个因子都是初等的，你可以亲眼看着负号出现。$n$ 固定时，

$$
\left(\frac{\partial P}{\partial V}\right)_T = -\frac{nRT}{V^2} = -\frac{P}{V}, \qquad \left(\frac{\partial V}{\partial T}\right)_P = \frac{nR}{P} = \frac{V}{T}, \qquad \left(\frac{\partial T}{\partial P}\right)_V = \frac{V}{nR} = \frac{T}{P}.
$$

乘积为 $(-P/V)(V/T)(T/P) = -1$。负号落在等温线上：温度固定时，压强随体积增大而下降。偏导数的下标是记号的一部分。$(\partial P/\partial T)_V$ 不是"$P$ 固定"的 $(\partial P/\partial T)$——那将是零。

## 热容

热是由于温度差而穿越边界的能量。它不是状态的性质。本章理想气体的一个状态是曲面 [[#eq-ideal]] 上的三元组 $(P, V, T)$，或其中任意两个。那张曲面上没有坐标 $Q$。问"气体里有多少热？"，理论内部没有答案。问"沿这条路进入了多少热？"，有。

用 $\delta Q$ 表示**由**系统吸收的微量热，我们拒绝写 $\dd Q$。不带横线的 $\dd$ 留给态函数的变化，例如 $\dd T$ 与 $\dd V$，它们只依赖一小步的端点。热依赖路径。符号约定与即将到来的第一定律匹配：正的 $Q$ 是系统吸收的热。

::: definition 热容 {#def-heat-capacity}
在指定的路径上，系统的**热容**是

$$
C = \frac{\delta Q}{\dd T},
$$ {#eq-heat-cap}

凡 $\dd T \neq 0$ 处。SI 单位是焦耳每开尔文。同一路径上的**摩尔热容**是 $c = C/n$，**比热容**是 $C/m$。

有两条路径常用到值得给下标。体积不变时，

$$
C_V = \left(\frac{\delta Q}{\dd T}\right)_V, \qquad c_V = \frac{C_V}{n},
$$

压强不变时，

$$
C_P = \left(\frac{\delta Q}{\dd T}\right)_P, \qquad c_P = \frac{C_P}{n}.
$$

若热容沿路径为常数，同一路径上有限一步吸收 $Q = C\,\Delta T$。换一条路径，等式就不成立了。
:::

对理想气体，两个摩尔热容之间有一个关系，

$$
c_P - c_V = R, \qquad \text{等价地} \qquad C_P - C_V = nR.
$$ {#eq-mayer-preview}

这里先把它陈述出来，使记号 $c_P - c_V$ 有一个值，证明放在 [[thermodynamics/first-law]]，那里才有它站得住脚的地方。证明用 $\Delta U = Q + W$，对系统做的功取为正，并用准静态功 $W = -\int P\,\dd V$。本章任何内容都不得读成 $c_P - c_V = -R$，也不得读成不带摩尔质量的每千克热容之差。[[#eq-mayer-preview]] 里的 $R$ 是每摩尔的，与 [[#eq-ideal]] 中的同一个。

$C_P$ 为什么应超过 $C_V$？体积不变时边界不移动，进来的热留在内能里。压强不变时气体膨胀，对气体做的功为负，同样的升温需要更多的热。[[thermodynamics/first-law]] 把这段故事变成 $C_P - C_V = nR$。在那之前，[[#eq-mayer-preview]] 是理想气体的一条陈述性质，不是任何一个热容的定义。

::: example 指定路径上的热 {#ex-capacity}
某样品吸收 $1.80\times 10^{3}\,\mathrm{J}$ 的热，温度升高 $12.0\,\mathrm{K}$，压强保持常数。求 $C_P$。样品含 $n = 3.00\,\mathrm{mol}$，求该路径的摩尔热容。
::: solution
路径已指明，[[#eq-heat-cap]] 以有限形式适用。等压线上热容为常数，给出

$$
C_P = \frac{Q}{\Delta T} = \frac{1.80\times 10^{3}}{12.0} = 150\,\mathrm{J\,K^{-1}}.
$$

摩尔值为

$$
c_P = \frac{C_P}{n} = \frac{150}{3.00} = 50.0\,\mathrm{J\,mol^{-1}\,K^{-1}}.
$$

这个数不是 $c_V$，也不是 $R$。若同一样品在定容下升温 $12.0\,\mathrm{K}$，$Q$ 会不同，$C$ 也会不同。这里给的数据定不出另一条路径的热。它们定的是等压的那条。
:::
:::

::: quiz
一位学生说："这个气体的热容是 $20\,\mathrm{J\,K^{-1}}$，所以任何使温度升高 $5\,\mathrm{K}$ 的过程都吸收 $100\,\mathrm{J}$。"哪里错了？
- [ ] 热容不允许小到 $20\,\mathrm{J\,K^{-1}}$
- [ ] 温升必须先写成摄氏再相乘
- [x] 热容属于某条路径；$Q = C\,\Delta T$ 只对该路径成立
- [ ] 吸收的热是 $C/\Delta T$，不是 $C\,\Delta T$
::: solution
[[#def-heat-capacity]] 把路径写进了它本身。值 $20\,\mathrm{J\,K^{-1}}$ 可能是 $C_V$，可能是 $C_P$，也可能是另一条曲线上的热容。乘以 $5\,\mathrm{K}$ 只对沿同一路径的过程才是那个热。摄氏与开尔文两标度的间隔等长，所以升温 $5\,\mathrm{K}$ 就是升高 $5$ 摄氏度；那部分算术无害。公式 $Q = C\,\Delta T$ 里 $C$ 在分子的位置，不在分母。$20\,\mathrm{J\,K^{-1}}$ 对小样品是可能的热容，不是错误所在。
:::
:::

## 后续内容

理想气体定律定的是平衡态。它没有说能量在状态之间如何改变。那笔平衡在 [[thermodynamics/first-law]]：$\Delta U = Q + W$，其中 $W$ 是对系统做的功，还有 $c_P - c_V = R$ 的证明。[[thermodynamics/kinetic-theory]] 把同一条定律读成关于分子动能的陈述，$k_B$ 是两种语言之间的换算。[[thermodynamics/heat-engines]] 需要绝对温标的原因不同：温度用摄氏时，卡诺效率 $1 - T_c/T_h$ 就是错的。熵稍后要用这同一个 $T$ 去除一个热量。

::: history 玻意耳的空气与汤姆孙的温标
罗伯特·玻意耳（Robert Boyle）《新实验》（*New Experiments*）第二版（1662）报告说，按理查德·汤利（Richard Towneley）与亨利·鲍尔（Henry Power）的建议，一团密闭空气在样品保持条件不变时，压强与体积成反比。把乘积 $PV$ 读作"温度固定时不变"，用到了一个玻意耳还没有温标去表达的区分。气体受热均匀膨胀与查理（Jacques Charles）的名字相联，由约瑟夫·路易·盖-吕萨克（Joseph Louis Gay-Lussac）在 1802 年发表，并注明归功于查理。1848 年威廉·汤姆孙（William Thomson）提出一个建立在卡诺关于热的动力的理论之上的绝对温标，使温差不依赖仪器内的流体。那篇论文是绝对温标的起点。开尔文以他命名。自 2019 年 SI 修订以来，开尔文由把玻尔兹曼常数固定在 $1.380649\times 10^{-23}\,\mathrm{J\,K^{-1}}$ 来定义，而不再宣布水的三相点恰为 $273.16\,\mathrm{K}$。
:::

::: summary
- 热平衡是"透热墙两侧，$A$ 不变 $B$，$B$ 也不变 $A$"这个关系。[[#thm-zeroth]] 陈述该关系是等价关系，温度是等价类的标记。
- 用一种液体的膨胀造出的经验温标是合法的标记，但不是理想气体定律里的 $T$。不同的经验温度计在固定点之外互不吻合。
- 定量理想气体满足 $PV = nRT = N k_B T$，$T$ 以开尔文计。玻意耳定律是等温线 $P_1 V_1 = P_2 V_2$。定压下 $V/T$ 为常数；定容下 $P/T$ 为常数。
- $P$ 与 $T$ 是强度量，$V$ 与 $n$ 是广延量，$PV = nRT$ 与这种划分相容。
- 定容气体温度计测的是压强之比。读数只有在低压极限下才是理想气体温度。自 2019 年起开尔文由固定 $k_B$ 定义。按定义 $T = t + 273.15$。
- 在物态曲面上，$(\partial P/\partial V)_T\,(\partial V/\partial T)_P\,(\partial T/\partial P)_V = -1$，前提是假设中出现的那两个 $P$ 的偏导数不为零。
- 热容是指定路径上的 $C = \delta Q/\dd T$。$Q = C\,\Delta T$ 不能从一条路径搬到另一条。对理想气体，每摩尔 $c_P - c_V = R$；证明在下一讲，用 $\Delta U = Q + W$。
- 绝对零度是 $0\,\mathrm{K}$。它不是某种真实气体被观测到占据零体积的状态。
:::

## 习题

::: exercise 等容线上的压强之比 {#exr-ratio level=1 check="6/5"}
一定量理想气体密封在刚性容器里。热力学温度从 $250\,\mathrm{K}$ 变到 $300\,\mathrm{K}$。求 $P_2/P_1$。
::: solution
体积与物质的量固定，所以 [[#eq-isochore]] 给出

$$
\frac{P_2}{P_1} = \frac{T_2}{T_1} = \frac{300}{250} = \frac{6}{5} = 1.20.
$$

$V$ 的值、$n$ 的值和 $R$ 的值都消掉了。只有当题目要求以帕斯卡给出 $P_2$ 时才用得上它们。温度已经是开尔文。摄氏读数的比，$27/(-23)$ 或任何类似代入，不是这个计算。
:::
:::

::: exercise 摄氏换算成开尔文 {#exr-convert level=1 check="373.15"}
把 $100^\circ\mathrm{C}$ 表示为以开尔文计的热力学温度。
::: solution
[[#eq-celsius]] 就是两标度之间关系的定义：

$$
T = t + 273.15 = 100 + 273.15 = 373.15\,\mathrm{K}.
$$

定义温标不再需要汽点，但这个算术换算是精确的。$100$ 摄氏度的温度*差*是 $100\,\mathrm{K}$，因为偏移在差里消掉了。这道题问的是温度本身，所以偏移保留。
:::
:::

::: exercise 等压线上的体积之比 {#exr-charles level=1 check="0.005"}
理想气体保持压强不变。$T_1 = 280\,\mathrm{K}$ 时体积为 $V_1 = 0.00400\,\mathrm{m^3}$。求 $T_2 = 350\,\mathrm{K}$ 时的体积。
::: solution
[[#prop-charles]] 给出 $V_2 = V_1\, T_2/T_1$：

$$
V_2 = 0.00400\times \frac{350}{280} = 0.00400\times 1.25 = 0.00500\,\mathrm{m^3}.
$$

分数 $350/280$ 约成 $5/4$，所以第四位小数是精确的，不是修约。压强从未进入。若压强也变了，就得在两端各用一次 [[#eq-ideal]]，而这一行缩放是错的。
:::
:::

::: exercise 玻意耳定律，两个体积都给出 {#exr-boyle level=2 check="400000"}
理想气体等温地从 $V_1 = 0.0400\,\mathrm{m^3}$ 压缩到 $V_2 = 0.0150\,\mathrm{m^3}$。初始压强为 $P_1 = 1.50\times 10^{5}\,\mathrm{Pa}$。求 $P_2$。
::: solution
温度与物质的量固定，所以 [[#eq-boyle]] 适用：

$$
P_2 = P_1\frac{V_1}{V_2} = (1.50\times 10^{5})\times \frac{0.0400}{0.0150} = (1.50\times 10^{5})\times \frac{8}{3} = 4.00\times 10^{5}\,\mathrm{Pa}.
$$

体积压缩为 $8/3$ 倍，压强就以同一倍数升高。不需要 $T$ 的值。想要的话，$T = P_1 V_1/(nR)$ 仍需要 $n$，而它没有给出，对 $P_2$ 也用不着。
:::
:::

::: exercise 由测得的热求热容 {#exr-cpath level=2 check="400"}
沿一条指定路径，某样品吸收 $Q = 2.40\times 10^{3}\,\mathrm{J}$，温度升高 $\Delta T = 6.00\,\mathrm{K}$。该路径上热容为常数。求它。
::: solution
[[#def-heat-capacity]] 的有限形式，$C$ 沿路径为常数，即 $Q = C\,\Delta T$，所以

$$
C = \frac{2.40\times 10^{3}}{6.00} = 400\,\mathrm{J\,K^{-1}}.
$$

这个数是这个样品沿这条路径的热容。除非路径是等容线或等压线，它不是自动的 $C_V$ 或 $C_P$。题目说路径已向实验者指明，但没有说是哪条路径，算术也不需要这个名字。
:::
:::

::: exercise 两个容器和一个旋塞 {#exr-stopcock level=2 check="120000"}
体积 $V_A = 0.0200\,\mathrm{m^3}$ 的容器装着压强 $P_A = 3.00\times 10^{5}\,\mathrm{Pa}$ 的理想气体。它经一个关闭的旋塞与一个抽空、体积 $V_B = 0.0300\,\mathrm{m^3}$ 的容器相连。打开旋塞，整套装置末态温度与初态相同。求末态压强。
::: solution
不增不减气体，$T$ 回到原值，所以 [[#eq-ideal]] 两端的 $nT$ 相同。于是 $PV$ 相同：

$$
P_A V_A = P_f (V_A + V_B).
$$

第二个容器只贡献体积、不贡献初始 $PV$，因为它被抽过真空。故

$$
P_f = P_A \frac{V_A}{V_A + V_B} = (3.00\times 10^{5})\times \frac{0.0200}{0.0500} = (3.00\times 10^{5})\times 0.400 = 1.20\times 10^{5}\,\mathrm{Pa}.
$$

这个论证只在端点使用 [[#eq-ideal]]。气体涌过旋塞期间并不处于一个平衡态。这股涌动的能量账是自由膨胀，在 [[thermodynamics/first-law]]。
:::
:::

::: exercise 循环乘积：算出来，不是抄下来 {#exr-cyclic level=3}
对定量理想气体，由 [[#eq-ideal]] 算出 $(\partial P/\partial V)_T$、$(\partial V/\partial T)_P$ 和 $(\partial T/\partial P)_V$，把它们相乘，确认乘积为 $-1$。说明你在何处用到 $T \neq 0$ 和 $V \neq 0$。
::: hint
写出 $P = nRT/V$、$V = nRT/P$ 和 $T = PV/(nR)$，各把下标变量固定求导。先约分再相乘，三个因子就塌缩了。
:::
::: solution
$n$ 与 $R$ 为常数，

$$
\left(\frac{\partial P}{\partial V}\right)_T = -\frac{nRT}{V^2} = -\frac{P}{V},
$$

其中构成 $P/V$ 用到了 $V \neq 0$，并用到了理想气体关系 $nRT/V^2 = P/V$。其次

$$
\left(\frac{\partial V}{\partial T}\right)_P = \frac{nR}{P} = \frac{V}{T},
$$

写成 $V/T$ 时用到了 $T \neq 0$，对 $V = nRT/P$ 求导用到了 $P \neq 0$。由 $T = PV/(nR)$，

$$
\left(\frac{\partial T}{\partial P}\right)_V = \frac{V}{nR} = \frac{T}{P}.
$$

乘积为

$$
\left(-\frac{P}{V}\right)\left(\frac{V}{T}\right)\left(\frac{T}{P}\right) = -1,
$$

前提是每次约分都合法，即 $P \neq 0$、$V \neq 0$、$T \neq 0$。那些状态本来就在把理想气体模型当温度计使用的区域之外。负号只来自等温线：温度固定时，压强随体积增大而下降。这就是 [[#prop-cyclic]] 的理想气体情形，三个因子写了出来，而不是留在一般论证里。
:::
:::

::: exercise 定容温度计 {#exr-thermo level=3 check="273.15*6/5"}
在理想气体极限下，定容气体温度计在温度 $273.15\,\mathrm{K}$ 处读得 $P_1 = 2.50\times 10^{4}\,\mathrm{Pa}$。在未知温度处压强为 $P_2 = 3.00\times 10^{4}\,\mathrm{Pa}$，仍在同一极限下，体积与物质的量不变。求未知温度。
::: hint
理想气体的等容线上，压强正比于热力学温度。比例常数在比值 $P_2/P_1$ 中消掉。
:::
::: solution
[[#eq-isochore]] 说 $T_2 = T_1 (P_2/P_1)$。两个压强已经是理想气体极限下的值，所以不再要求你外推：

$$
\frac{P_2}{P_1} = \frac{3.00\times 10^{4}}{2.50\times 10^{4}} = \frac{3}{2.5} = 1.20 = \frac{6}{5},
$$

$$
T_2 = 273.15\times \frac{6}{5} = 327.78\,\mathrm{K}.
$$

换成摄氏是 $327.78 - 273.15 = 54.63^\circ\mathrm{C}$，题目没有问。若这两个压强是大气密度下的原始读数而不是极限值，[[#def-ideal]] 并没有资格让你把 $327.78\,\mathrm{K}$ 称为热力学温度。让比例成为精确的，正是"极限已经取过"这个假设。
:::
:::
