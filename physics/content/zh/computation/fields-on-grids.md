当未知量只被保存在彼此分离的点上时，导数就成了一次减法。区间上的泊松方程于是成为一个三对角线性方程组，正是 [[computation/linear-algebra]] 中手算过的那一类。波动方程成为一个向时间推进的步子，而只有当波一步至多跨过一个网格单元时，这个步子才是安全的。下面两个问题都有可以在任何算术之前先写下来的答案，所以符号写错、或者步长取长了，都会暴露成一个数，而不是一种感觉。

表中的数字由写在旁边的格式产生。[[computation/integrating-motion]] 的积分器是这里时间步子的前身。网格想要跟上的那个行波，就是 [[oscillations/travelling-waves]] 里的波。

## 二阶差分 {#second}

取节点 $x_j = j h$，间距为固定的 $h$，把保存在 $x_j$ 处的值记作 $\phi_j$。中心二阶差分是

$$
\delta^2 \phi_j = \frac{\phi_{j-1} - 2\phi_j + \phi_{j+1}}{h^2}.
$$

::: definition 中心二阶差分 {#def-delta}
$\delta^2 \phi_j$ 就是上面的中心二阶差分。它是 $\phi''(x_j)$ 的候选代替。两个邻居在两侧等距 $h$ 处，因此泰勒展开中的奇数次幂相消，能够幸存下来的第一个误差含有 $\phi''''$。
:::

::: proposition 对三次多项式精确 {#prop-exact}
若 $\phi$ 是不超过 $3$ 次的多项式，则对任何间距 $h$，在每个内部节点上都有 $\delta^2 \phi_j = \phi''(x_j)$。若 $\phi''''$ 不为零，则

$$
\delta^2 \phi_j = \phi''(x_j) + \frac{h^2}{12}\, \phi''''(x_j) + O(h^4).
$$
::: proof
在 $x_j$ 处展开。$\phi(x_j+h)$ 与 $\phi(x_j-h)$ 中 $h$ 与 $h^3$ 的项相互抵消，得

$$
\phi(x_j+h) + \phi(x_j-h) = 2\phi(x_j) + h^2 \phi''(x_j) + \frac{h^4}{12}\, \phi''''(x_j) + O(h^6).
$$

减去 $2\phi(x_j)$、除以 $h^2$。写成 $O(h^4)$ 的余项来自六阶导数（如果它存在）。不超过 $3$ 次的多项式有 $\phi'''' = 0$，于是余项为零，二阶差分恰好等于 $\phi''$。
:::
:::

下一节的受载弦有 $\phi'''' = 0$，所以网格给出的不是近似，而是精确解的采样。再后面的正弦例子有 $\phi'''' \neq 0$，$h^2/12$ 那一项就是那张表的全部内容。

## 区间上的泊松方程 {#poisson}

方程是

$$
-\phi'' = \rho, \qquad \phi(0) = 0, \qquad \phi(1) = 0.
$$

这个负号与静电学中 $-\nabla^2 \Phi = \rho/\varepsilon_0$ 的约定相同：正的源在接地端之间产生正的 $\phi$。在内部节点上，二阶差分代替 $\phi''$，于是

$$
-\delta^2 \phi_j = \rho_j, \qquad \text{即} \qquad \frac{-\phi_{j-1} + 2\phi_j - \phi_{j+1}}{h^2} = \rho_j.
$$

端点的值不是未知量；当某个邻居落在边界上时，它们被移到右端。

取 $\rho = 1$。积分两次并用上两个边界条件，得

$$
\phi(x) = \frac{x(1-x)}{2}.
$$

四阶导数为零，所以 [[#prop-exact]] 断言每个均匀网格都在节点上复现这条曲线。下面这个短方程组是一次核对，不是某个特定间距的巧劲。

::: example 三个内部节点 {#ex-three}
取 $h = 1/4$。未知节点是 $x = 1/4$、$1/2$、$3/4$，且有 $\phi_0 = \phi_4 = 0$、$\rho = 1$。解这个 $3 \times 3$ 方程组。
::: solution
这里 $h^2 = 1/16$，所以 $-\phi_{j-1} + 2\phi_j - \phi_{j+1} = 1/16$。两端为零，

$$
\begin{aligned}
2\phi_1 - \phi_2 &= \tfrac{1}{16}, \\
-\phi_1 + 2\phi_2 - \phi_3 &= \tfrac{1}{16}, \\
-\phi_2 + 2\phi_3 &= \tfrac{1}{16}.
\end{aligned}
$$

方程组关于中心对称，所以 $\phi_1 = \phi_3$。中间那个方程化为 $2\phi_2 - 2\phi_1 = 1/16$，故 $\phi_2 - \phi_1 = 1/32$。把 $\phi_2 = \phi_1 + 1/32$ 代入第一个方程：

$$
2\phi_1 - \bigl(\phi_1 + \tfrac{1}{32}\bigr) = \tfrac{1}{16}, \qquad \phi_1 = \tfrac{3}{32}.
$$

于是 $\phi_2 = 3/32 + 1/32 = 1/8$，$\phi_3 = 3/32$。写成小数，网格保存的值是 $0.09375$、$0.125$、$0.09375$。
:::
:::

::: example 从公式得到同样的数 {#ex-match}
在 $x = 1/4$、$1/2$、$3/4$ 处求 $x(1-x)/2$。
::: solution
在 $x = 1/4$ 处，$(1/4)(3/4)/2 = 3/32$。在 $x = 1/2$ 处，$(1/2)(1/2)/2 = 1/8$。在 $x = 3/4$ 处又是 $3/32$。这三个网格值不是接近精确解，它们就是精确解。因为 $\phi'''' = 0$，而且矩阵使用的边界值就是真正的边界值，[[#prop-exact]] 早已断言了这一点。一个程序若为这个方程组打出 $10^{-15}$ 量级的残差，它展示的是线性求解中的舍入，不是离散化误差。根本没有离散化误差可展示。
:::
:::

::: widget plot
f: x*(1-x)/2
x: 0, 1
y: 0, 0.15
caption: −φ'' = 1 在 φ(0) = φ(1) = 0 下的精确解 φ = x(1−x)/2。最大值为 1/8，在 x = 1/2 处。任何均匀网格，只要按三个内部节点的例子那样求解，都在每个节点处落在这条曲线上。
:::

源为零是另一个精确情形；它钉住的是两个边界值，而不是一个下垂量。

::: example 无源，端点不等 {#ex-linear}
解 $-\phi'' = 0$，边界为 $\phi(0) = 0$、$\phi(1) = 1$；既求精确解，也在间距 $h = 1/N$ 的网格上求。
::: solution
$\phi'' = 0$ 的通解是 $\phi(x) = Ax + B$。边界条件给出 $B = 0$、$A = 1$，故 $\phi(x) = x$。线性函数的二阶导数为零，由 [[#prop-exact]]，二阶差分也为零。每个内部方程都长成 $0 = 0$。节点随后被两端钉住：$\phi_j = j h = x_j$。网格又一次与精确采样完全一致。若两端都为零，唯一的线性解就是 $\phi = 0$；由下一条结果，它也是唯一的网格解。
:::
:::

::: proposition 唯一解 {#prop-unique}
设 $M$ 是对角元为 $2$、两条相邻对角线上的元为 $-1$ 的 $m \times m$ 矩阵，并设紧靠这块矩阵两侧的网格值为零。则 $M$ 正定。带这些零端的离散方程 $M\phi = h^2 \rho$ 恰有一个解。
::: proof
设 $v_0 = v_{m+1} = 0$。二次型为

$$
v \cdot M v = \sum_{i=1}^{m} v_i \bigl(2v_i - v_{i-1} - v_{i+1}\bigr).
$$

展开 $\sum_{i=0}^{m} (v_{i+1} - v_i)^2$。边界项 $v_0$ 与 $v_{m+1}$ 消失，交叉项把每一对相邻指标恰好扫过一遍，所以这个和等于 $v \cdot M v$。平方和为零仅当每个差 $v_{i+1} - v_i$ 都为零。加上 $v_0 = 0$ 就迫使一切 $v_i = 0$。于是对 $v \neq 0$ 有 $v \cdot M v > 0$，$M$ 可逆，右端 $h^2 \rho$ 只给出一个 $\phi$。
:::
:::

[[#ex-three]] 里的三节点矩阵就是这个 $M$。它的解是用消元法求出的，没有分支。不可能有第二个不同的三元组也满足同一组方程，原因就在 [[#prop-unique]]。

::: warning 二阶导数前面的符号
在零端的 $-\phi'' = 1$ 中，未知量是正的。表达这个方程的矩阵对角元是 $+2$。若反着搭一个对角元为 $-2$、右端仍是 $+1$ 的矩阵，解出来的其实是 $\phi'' = 1$。在 $x = 1/2$、$h = 1/2$ 的单个内部节点上，正确的方程是 $2\phi / h^2 = 1$，所以 $8\phi = 1$、$\phi = 1/8$；反号的方程给出 $\phi = -1/8$。图形是真下垂上下颠倒的复制。在欣赏图像之前先核对中间值的符号，就能抓住这类错误。
:::

## 网格错过的解 {#sine}

现在取精确解为 $\phi(x) = \sin(\pi x)$，于是 $\phi(0) = \phi(1) = 0$，而

$$
-\phi'' = \pi^2 \sin(\pi x).
$$

四阶导数是 $\pi^4 \sin(\pi x)$，不为零。[[#prop-exact]] 预言误差正比于 $h^2$。在这个具体的形状上误差可以写成封闭形式，所以这个预言可以拿去核对，而不是拿去拟合。

::: proposition 网格上的正弦模态 {#prop-sine}
在 $-\delta^2 \phi_j = \pi^2 \sin(\pi x_j)$、两端 $\phi = 0$ 之下，$x_j = j h$、$h = 1/N$ 上的网格解是

$$
\phi_j = \alpha(h)\, \sin(\pi x_j), \qquad \alpha(h) = \left( \frac{\pi h}{2 \sin(\pi h / 2)} \right)^2.
$$

中点处的误差是 $\alpha(h) - 1$。当 $h$ 小时，

$$
\alpha(h) - 1 = \frac{\pi^2 h^2}{12} + O(h^4).
$$
::: proof
$\sin(\pi x_j)$ 的二阶差分来自一个标准三角恒等式。两个邻居贡献 $\sin(\pi(x_j \pm h)) = \sin(\pi x_j)\cos(\pi h) \pm \cos(\pi x_j)\sin(\pi h)$，于是

$$
\delta^2 \sin(\pi x_j) = \frac{2\cos(\pi h) - 2}{h^2}\, \sin(\pi x_j) = -\frac{4}{h^2}\sin^2\Bigl(\frac{\pi h}{2}\Bigr) \sin(\pi x_j).
$$

因此 $-\delta^2$ 把这个模态乘以 $\lambda_h = (4/h^2)\sin^2(\pi h / 2)$。离散方程要求 $\lambda_h \phi_j = \pi^2 \sin(\pi x_j)$。一个解是 $\phi_j = (\pi^2 / \lambda_h) \sin(\pi x_j)$，而 $\pi^2 / \lambda_h$ 就是 $\alpha(h)$。由 [[#prop-unique]] 没有别的解。取 $\theta = \pi h / 2$，展开式 $\sin \theta = \theta - \theta^3/6 + O(\theta^5)$ 给出 $\theta / \sin \theta = 1 + \theta^2/6 + O(\theta^4)$，平方后得到 $1 + \theta^2/3 + O(\theta^4)$。于是 $\theta^2/3 = \pi^2 h^2 / 12$。
:::
:::

在粗间距上这个公式很容易求值，而在那些间距上，$3 \times 3$ 的求解与封闭形式必须吻合。

::: example 只有一个未知量，在中点 {#ex-one}
取 $h = 1/2$，唯一的未知量是 $\phi(1/2)$。分别用差分方程与 $\alpha(h)$ 计算它。
::: solution
两端为零，$h^2 = 1/4$，且 $\sin(\pi/2) = 1$。方程 $-\delta^2 \phi = \pi^2$ 化为 $2\phi / h^2 = \pi^2$，所以 $8\phi = \pi^2$，于是

$$
\phi = \frac{\pi^2}{8} = 1.233701.
$$

精确的中点值是 $1$。误差是 $0.233701$。由上面那条结果，$\alpha(1/2) = \bigl(\pi/2 \big/ \bigl(2 \sin(\pi/4)\bigr)\bigr)^2$。因为 $\sin(\pi/4) = \sqrt{2}/2$，它同样等于 $\pi^2/8$。主项 $\pi^2 h^2/12 = \pi^2/48 = 0.205617$ 方向正确，但仍不到 $0.233701$。在 $h = 1/2$ 处，$O(h^4)$ 那部分还没有变小。
:::
:::

$h$ 减半把主误差除以四。表中列出的是中点处的 $\alpha(h) - 1$，打印到六位小数。

| $h$ | 网格上的 $\phi(1/2)$ | 误差 $\alpha(h)-1$ | $\pi^2 h^2/12$ |
| --- | --- | --- | --- |
| $1/2$ | $1.233701$ | $0.233701$ | $0.205617$ |
| $1/4$ | $1.053029$ | $0.053029$ | $0.051404$ |
| $1/8$ | $1.012951$ | $0.012951$ | $0.012851$ |
| $1/16$ | $1.003219$ | $0.003219$ | $0.003213$ |
| $1/32$ | $1.000804$ | $0.000804$ | $0.000804$ |

从 $h = 1/8$ 到 $h = 1/16$，误差缩小为约 $4.023$ 分之一（$0.012951/0.003219 \approx 4.023$）。从 $h = 1/16$ 到 $h = 1/32$，这个因子是 $4.006$。二阶差分的设计本就是一个 $h^2$ 截断，被求解的方程继承了它。在 $h = 1/32$ 处，主项与真实误差在所打印的六位小数上已经一致。

::: widget plot
f: sin(pi*x)
x: 0, 1
y: 0, 1.25
caption: 零端条件下 −φ'' = π² sin(πx) 的精确解 sin(πx)。网格不会落在这条曲线上。h = 1/4 时，中点的网格值是 1.053，高于真值 1。h 减半把这个超出量约除以四。

由此得出两个习惯。第一，在 $\rho = 1$ 上吻合是对矩阵搭得对不对的检验，因为那里的误差必须为零；它不是对方法阶数的测量。第二，一个看上去不错的间距不能揭示阶；两个间距可以，而且对这个格式那个因子应当接近 $4$。因子接近 $2$ 说明误差只有一阶；对这种中心差分，那意味着有缺陷——通常是端上用了单侧差分，或者分母里用的不是真正的 $h$。

[[computation/linear-algebra]] 的残差检验仍然适用，而且它回答的是另一个问题。$\phi$ 算出之后，用真正交给求解器的那个矩阵造出 $r = h^2 \rho - M\phi$。对 [[#ex-three]]，这个残差是零向量。反之，若把 $\sin(\pi x)$ 的精确采样代入 $M$，残差不为零：那些采样不满足离散方程。残差极小意味着你解出了自己搭的那个矩阵。它并不意味这个矩阵就是那个微分方程。

::: quiz
在 $(0, 1)$ 上解 $-\phi'' = 1$，$\phi(0) = \phi(1) = 0$，间距 $h = 1/4$ 的网格给出三个内部值。哪个说法正确？
- [ ] 它们与 $x(1-x)/2$ 相差约 $h^2$ 量级的误差。
- [x] 它们在三个节点处恰等于 $x(1-x)/2$。这个解的四阶导数为零，所以二阶差分是精确的。
- [ ] 矩阵是奇异的，任意线性函数都是另一个解。
- [ ] 这些值依赖于一条时间步长限制，因为二阶导数的任何网格格式都是波动格式。
::: solution
[[#prop-exact]] 与 [[#ex-three]] 中的显式求解给出 $3/32$、$1/8$、$3/32$，正是 $x(1-x)/2$ 的采样。由 [[#prop-unique]]，矩阵 $M$ 正定，所以这个解没有第二个线性的竞争对手。这个边值问题里没有任何东西沿时间推进。
:::
:::

## 波动方程 {#wave}

一维波动方程

$$
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \qquad u(0, t) = u(1, t) = 0,
$$

在 $u(x, 0) = \sin(\pi x)$、$t = 0$ 处 $\partial u/\partial t = 0$ 之下有精确解

$$
u(x, t) = \sin(\pi x)\, \cos(\pi c\, t).
$$

信息以速度 $c$ 传播。在网格上，中心格式把两个二阶导数都替换掉。用时间下标 $n$、$u_j^n \approx u(x_j, t_n)$，

$$
\frac{u_j^{n+1} - 2 u_j^n + u_j^{n-1}}{\Delta t^2} = c^2\, \delta^2 u_j^n.
$$

整理后，取库朗数 $r = c\, \Delta t / h$，

$$
u_j^{n+1} = 2 u_j^n - u_j^{n-1} + r^2 \bigl(u_{j+1}^n - 2 u_j^n + u_{j-1}^n\bigr).
$$

每个时间层上两端都保持为零。这个格式需要两个时间层才能起步。初速度为零时，泰勒步子 $u(\Delta t) = u(0) + \tfrac{1}{2} \Delta t^2 u_{tt}(0) + O(\Delta t^4)$ 把 $u_{tt}$ 换成 $c^2 \delta^2 u$，给出第一个层

$$
u_j^1 = u_j^0 + \frac{r^2}{2} \bigl(u_{j+1}^0 - 2 u_j^0 + u_{j-1}^0\bigr).
$$

::: definition 库朗数 {#def-courant}
这个格式的库朗数是 $r = c\, \Delta t / h$。它是一步之内真波跨过的网格单元数。格式在时间层 $n$ 只用到 $j-1$、$j$、$j+1$ 处的值。一步之中，数值信号至多移动一个单元。
:::

::: algorithm 中心波动步子 {#alg-wave}
保存两行：$t_n$ 与 $t_{n-1}$ 处的值，两端为零。用上面写出的更新公式造出下一行，然后丢掉最旧的一行。要从静止起步，第一行用上面的半步公式造出，而不是去杜撰一行 $t = -\Delta t$。
:::

当 $r = 1$ 时，半步公式经代数化简塌缩为两个邻居的平均：

$$
u_j^1 = \frac{u_{j+1}^0 + u_{j-1}^0}{2}.
$$

这个平均正是达朗贝尔（d'Alembert）公式。其后的各步都留在它上面。

::: proposition 在 $r = 1$ 处精确 {#prop-exact-wave}
取 $c = 1$、$\Delta t = h$，初速度取为零。设 $f$ 是初始采样，把它向 $[0, 1]$ 之外延拓，使固定端表现为奇反射（端外紧邻处的值是端内紧邻处的值的相反数）。则对每个节点、每个时间层 $t_n = n h$，

$$
u_j^n = \frac{f(x_j + t_n) + f(x_j - t_n)}{2},
$$

这就是波动方程的精确解在网格上的采样。
::: proof
$n = 0$ 时公式给出 $f(x_j)$。$n = 1$ 时，达朗贝尔公式就是邻居平均，而 $r = 1$ 的半步正是同一个平均。假设公式在层 $n$ 与 $n-1$ 成立。$r = 1$ 的更新是 $u_j^{n+1} = u_{j+1}^n + u_{j-1}^n - u_j^{n-1}$。把归纳假设的表达式代入。来自两个邻居的 $f$ 的四个平移副本，是 $f$ 在 $x_j + (n+1)h$、$x_j - (n-1)h$、$x_j + (n-1)h$、$x_j - (n+1)h$ 处的值。减去 $u_j^{n-1}$ 消去了相距 $(n-1)h$ 的那两个副本。剩下的是 $f$ 在 $x_j \pm (n+1)h$ 处的值的平均，正是层 $n+1$ 的公式。奇反射使得端点旁的邻居等于数组中已经保存的边界值 $0$，所以这个模板从不需要网格上没有的值。
:::
:::

::: example 步子等于间距的正弦波 {#ex-cfl-one}
取 $c = 1$、$h = 1/4$、$\Delta t = 1/4$，故 $r = 1$，初值 $u(x, 0) = \sin(\pi x)$。在一个周期内把网格与 $\sin(\pi x)\cos(\pi t)$ 比较。
::: solution
[[#prop-exact-wave]] 可直接适用：$\sin(\pi x)$ 本身就是自己的奇延拓。跑这个步子，直到 $t = 2$，节点值与 $\sin(\pi x)\cos(\pi t)$ 之差最大约 $2 \times 10^{-16}$。这个差是加法中的舍入，不是截断误差。在 $t = 1$ 处，$\cos(\pi) = -1$，内部值是 $-0.707107$、$-1$、$-0.707107$，即 $-\sin(\pi x)$ 的采样。

同样的初始数据配上更小的库朗数就不再精确。在 $h = 1/8$、$r = 1/2$——即 $\Delta t = 1/16$——之下，$t = 1$ 处的中点值给出的是 $-0.999885$ 而不是 $-1$。误差是 $1.152 \times 10^{-4}$。格式依然准确。它只是离开了那个使 $r = 1$ 与达朗贝尔公式完全相同的特殊相消。
:::
:::

在一个 $r$ 值上精确，并不给更大的 $r$ 发放通行证。若 $r > 1$，真解的依赖域伸到不止一个单元之外，而模板没有收到那些单元的讯息。为此付出代价的模态，是网格所能容纳的最短的波。

::: proposition 库朗条件 {#prop-cfl}
对无限网格上的中心格式，写试探模态 $u_j^n = \xi^n e^{i k j h}$。$\xi$ 的取值是下面方程的两个根

$$
\xi^2 - 2A\xi + 1 = 0, \qquad A = 1 - 2 r^2 \sin^2\Bigl(\frac{k h}{2}\Bigr).
$$

对一切波数 $k$ 两个根的模都是 $1$，当且仅当 $r \le 1$。若 $r > 1$，属于 $\sin^2(kh/2) = 1$ 的那个根模大于 $1$，该模态每步增长。
::: proof
把试探模态代入更新公式。二阶差分贡献 $2\cos(kh) - 2 = -4\sin^2(kh/2)$，$\xi$ 的幂次整理后就是那个二次方程。两个根的乘积是 $1$。它们落在单位圆上，恰好当它们是共轭复数、或 $\pm 1$ 这样的实根对，即条件 $A^2 \le 1$，也就是 $|A| \le 1$。当 $r \le 1$ 时有 $0 \le 2 r^2 \sin^2(kh/2) \le 2$，故 $A$ 落在 $[-1, 1]$ 内。当 $r > 1$ 时，取 $\sin^2(kh/2) = 1$ 给出 $A = 1 - 2r^2 < -1$，于是一个根是实数，其模为 $|A| + \sqrt{A^2 - 1} > 1$。
:::
:::

在短网格上，不需要一连串连续的波数也能看到同一个事实。取三个内部节点、$h = 1/4$，把推进时间层对 $(u^n, u^{n-1})$ 的 $6 \times 6$ 矩阵直接对角化。$r = 1$ 时每个本征值的模都是 $1$。$r = 1.2$ 时谱半径是 $2.5196$：一个模态每步被乘以 $2.5196$，其余模态保持模 $1$。

::: example 百分之一振幅的短波 {#ex-grow}
取 $c = 1$、$h = 1/4$、三个内部节点。初值取 $\sin(\pi x)$ 加上短波 $0.01$、$-0.01$、$0.01$。中心格式分别在 $r = 1$ 与 $r = 1.2$ 下运行。
::: solution
初始内部值是 $0.717107$、$0.990000$、$0.717107$。最大绝对值是 $0.990$。

$r = 1$ 时 $\Delta t = 0.25$。到 $t = 2$、即八步之后，内部值回到了 $0.717107$、$0.990000$、$0.717107$。加进去的短波与精确振荡一同乘行。什么也没有增长。

$r = 1.2$ 时 $\Delta t = 0.30$。同一个初始行给出这些最大绝对值：

| 步数 | $t$ | 最大 $\|u\|$ |
| --- | --- | --- |
| $0$ | $0$ | $0.990$ |
| $8$ | $2.4$ | $9.584$ |
| $12$ | $3.6$ | $394.6$ |
| $14$ | $4.2$ | $2507$ |

$t = 2.4$ 处的内部行是 $7.086$、$-9.584$、$7.086$，形状已经是短波而不是 $\sin(\pi x)$。从 $t = 3.6$ 到 $t = 3.9$ 再到 $t = 4.2$，最大值依次为 $394.6$、$996.3$、$2507$，相邻比值是 $2.525$ 与 $2.516$。当增长模态盖过有界的模态之后，这些比值现出的正是谱半径 $2.5196$。精确的弦仍有振幅 $1$。网格没有。

同样的 $r = 1.2$，若从纯 $\sin(\pi x)$ 出发、不添短波，在这套算术下直到 $t = 6$ 数值大小都不超过 $1$。不稳定模态不在初始数据里，所以二十步没有把它暴露出来。舍入最终会给它播下种子。但坐等那次意外不是一种检验。
:::
:::

::: warning 相容的格式照样可以毫无用处
中心格式是相容的：当 $h$ 与 $\Delta t$ 一同趋于零、$r$ 固定不变时，每个二阶差分的泰勒余项趋于零，波动方程的光滑解在到这个余项的精度内满足模板。相容性并没有拦住 $r = 1.2$ 的那次运行。截断误差只对光滑的形状才小；增长的那个模态是网格上最不光洁的形状，而只要 $\Delta t = 1.2\, h/c$——无论 $h$ 多小——对该模态每步的放大就是 $2.52$。保持 $r > 1$ 加密网格，是把爆炸也一起加密了，并没有把它去掉。一次类正弦运行在某一时刻的一幅图，不是步子安全的证据。要比较两个库朗数，或者加入一个你选定大小的短波种子，并要求这个种子保持在它的大小。
:::

## 留给求解器的东西 {#solver}

$m$ 个内部节点上的泊松方程就是 $M\phi = h^2 \rho$，其中 $M$ 是 [[#prop-unique]] 中的矩阵。$m = 3$、$h = 1/4$ 时就是 [[#ex-three]] 解过的方程组。三对角矩阵上的高斯消元只花 $m$ 的一个小倍数次运算，而不是满矩阵的 $m^3/3$。残差 $h^2 \rho - M\phi$ 仍是正确的验收检验，而且它就是 [[computation/linear-algebra]] 里的那个残差。

波动步子不是线性求解。它是一个递推。它的验收检验就是已经算过的那些：$r = 1$ 时正弦采样必须回到舍入误差以内；$r > 1$ 时短波种子不许悄悄蒙混过关。连续弦的能量守恒。这个格式也可以写下一个离散能量，它在 $r \le 1$ 时守恒；但 $r > 1$ 时的增长解会让任何这样的能量一起增长。$r > 1$ 时眼看一个标量保持平稳几步，只说明不稳定模态还没有涨过舍入或种子。

从这个区间过渡到平面上的薄膜或势，就是把同一个二阶差分在每个坐标上写一遍。矩阵变得更大、不再三对角，一个节点处的未知量与四个邻居而非两个耦合。检验不变。二次或双线性精确解必须被复现到舍入。正弦模态在间距减半时误差必须约缩小四倍。波动步子的库朗数必须不超过 $1$，而短波种子必须被看到保持有界。

::: history 理查森，与库朗、弗里德里希斯、勒维
差分法早在十九世纪就是教科书内容。乔治·布尔（Boole）的《Treatise on the Calculus of Finite Differences》出版于 1860 年。二十世纪新出现的，是下定决心把物理偏微分方程放上网格、当作预报来推进。刘易斯·弗莱·理查森（Richardson）用手工——主要靠一把计算尺——完成过一次这样的计算，并于 1922 年以《Weather Prediction by Numerical Process》发表。他在中心点算出的六小时地表气压变化达 $145$ hPa；对真实的六小时变化而言这个趋势大得离谱，而理查森自己判断，这套算术是对一个不自然的初始分布的正当推演。这次失败没有取消这个方法。它说明了初始数据与步子都必须审查——这与本章的残差和库朗数是同一个要求。

限制 $r \le 1$ 是理查德·库朗（Courant）、库尔特·弗里德里希斯（Friedrichs）与汉斯·勒维（Lewy）1928 年提出的条件，见他们发表在《Mathematische Annalen》上关于偏差分方程的论文。他们的陈述讲的是依赖域：数值模板必须足够宽，宽到真解所依赖的每一个点它都收得到讯息。对中心波动格式，这个几何要求就是 $c\, \Delta t \le h$，而 [[#prop-cfl]] 是把同一个要求按增长模态的方式读出来的结果。
:::

::: summary
- 中心二阶差分在不超过 $3$ 次的多项式上等于 $\phi''$。下一项是 $(h^2/12)\phi''''$。
- 零端之下 $-\phi'' = 1$ 的解是 $\phi = x(1-x)/2$。间距 $h = 1/4$ 时网格值恰为 $3/32$、$1/8$、$3/32$。
- 对角元为 $2$、旁边为 $-1$ 的三对角矩阵在零端下正定，所以离散泊松问题只有一个解。
- 对 $-\phi'' = \pi^2 \sin(\pi x)$，网格把 $\sin(\pi x)$ 乘以 $\alpha(h) = \bigl(\pi h / (2\sin(\pi h/2))\bigr)^2$。中点误差每把 $h$ 减半就约除以四，$h = 1/32$ 时是 $0.000804$。
- 初速度为零、$r = c\, \Delta t / h = 1$ 的中心波动格式在节点上复现达朗贝尔公式。$r = 1.2$ 时，振幅 $0.01$ 的短波到 $t = 4.2$ 已经造出 $2507$ 量级的网格值。
- 残差接近零意味着线性方程组被解了出来。它不意味着 $r > 1$ 的波动步子是安全的，也不会把一个不精确的差分变成精确的。
:::

## 习题

::: exercise 下垂量的中点 {level=1 check="0.125"}
在 $(0, 1)$ 上 $-\phi'' = 1$，两端为零，$\phi(1/2)$ 的精确值是多少？
::: solution
$\phi(x) = x(1-x)/2$，所以 $\phi(1/2) = 1/8 = 0.125$。[[#ex-three]] 的三节点网格在中间节点上保存的正是这个值。
:::
:::

::: exercise 四分之一点 {level=1 check="0.09375"}
在 $x = 1/4$ 处求同一个精确解。
::: solution
$(1/4)(3/4)/2 = 3/32 = 0.09375$。这就是 $h = 1/4$ 方程组里的 $\phi_1$。
:::
:::

::: exercise 一个库朗数 {level=1 check="0.8"}
波速 $c = 2$，用 $h = 0.1$、$\Delta t = 0.04$ 推进。$r = c\, \Delta t / h$ 是多少？
::: solution
$r = 2 \times 0.04 / 0.1 = 0.08/0.1 = 0.8$。因为 $r \le 1$，[[#prop-cfl]] 不预言增长模态。这个步子在允许的范围内。它不是格式精确复制达朗贝尔公式的那个特殊值 $r = 1$。
:::
:::

::: exercise 一个节点，恒定源 {level=2 check="0.125"}
取 $h = 1/2$、$-\phi'' = 1$，$\phi(0) = \phi(1) = 0$。未知量只有一个，在 $x = 1/2$。从差分方程求出它。
::: solution
$h^2 = 1/4$，两个邻居都是零，所以 $2\phi / h^2 = 1$。于是 $8\phi = 1$、$\phi = 1/8 = 0.125$。精确的中点值也是 $1/8$。恒定的源给出二次函数解，而二次函数的二阶差分是精确的。
:::
:::

::: exercise $h = 1/4$ 时的右端 {level=2 check="0.0625"}
在 [[#ex-three]] 中，因为 $\rho = 1$，清完分母的方程形如 $-\phi_{j-1} + 2\phi_j - \phi_{j+1} = h^2$。$h = 1/4$ 时 $h^2$ 是多少？
::: solution
$(1/4)^2 = 1/16 = 0.0625$。那个例子里每个方程的右端都是 $1/16$。
:::
:::

::: exercise 阶，取整数 {level=2 check="2"}
在正弦那张表中，$h$ 减半使中点误差乘以趋于 $4$ 的因子。那么误差正比于 $h$ 的哪个整数次幂？
::: solution
$h$ 减半对应因子 $4$，即 $(1/2)^p = 1/4$，所以 $p = 2$。这个幂次就是 [[#prop-exact]] 里的那个幂，也是 [[#prop-sine]] 中展开式 $\alpha(h) - 1 \approx \pi^2 h^2 / 12$ 里的幂。它不是库朗数，也不是 $4$ 本身。$4$ 是因子，$2$ 是阶。
:::
:::

::: exercise 最大的安全步长 {level=2 check="0.25"}
$c = 1$、$h = 1/4$，$r \le 1$ 允许的 $\Delta t$ 最大是多少？
::: solution
$c\, \Delta t / h \le 1$ 给出 $\Delta t \le h/c = 1/4 = 0.25$。就在这个值上，格式正是 [[#prop-exact-wave]] 的精确网格达朗贝尔公式。[[#ex-grow]] 的运行用了 $\Delta t = 0.30$，越过了这个界限，短波于是增长了。
:::
:::

::: exercise 下垂量为何精确 {level=3}
设 $\phi(x) = x(1-x)/2$。直接计算 $\phi(x+h) - 2\phi(x) + \phi(x-h)$，除以 $h^2$，并由此断言：$\rho = 1$ 的离散泊松方程在任意间距下都被 $\phi$ 的采样满足。
::: solution
$\phi(x+h) = (x+h)(1-x-h)/2 = \phi(x) + (h/2)(1-2x) - h^2/2$，而 $\phi(x-h) = \phi(x) - (h/2)(1-2x) - h^2/2$。相加再减去 $2\phi(x)$ 剩下 $-h^2$。除以 $h^2$ 得 $-1$，所以 $\delta^2 \phi = -1$、$-\delta^2 \phi = 1$。每个内部方程都被精确满足。再配上吻合的边界值与 [[#prop-unique]]，网格解就等于采样。
:::
:::

::: exercise 增长的那个根 {level=3}
对 [[#prop-cfl]] 中的二次方程，取 $\sin^2(kh/2) = 1$、$r > 1$。证明一个根的模大于 $1$，另一个根的模小于 $1$。
::: solution
系数 $A$ 等于 $1 - 2r^2$，小于 $-1$。根为 $A \pm \sqrt{A^2 - 1}$，两者都是实数。由 $\xi^2 - 2A\xi + 1$ 的常数项知它们的乘积为 $1$。两者不可能模都为 $1$，因为 $|A| > 1$ 把它们推出了单位圆；也不可能模都大于 $1$，否则乘积会超过 $1$。所以一个模大于 $1$，另一个是它的倒数。那个较大的根，就是网格上最短的波每步的增长。
:::
:::

::: quiz
一次中心格式的波动计算取 $c\, \Delta t = 1.2\, h$，在本章的三节点网格上，从 $\sin(\pi x)$ 加振幅 $0.01$ 的短波出发。哪个说法与运行相符？
- [ ] 只要步子一直迭代，数值与精确波就保持相距不超过 $1$，因为格式是相容的。
- [ ] $r = 1.2$ 与 $r = 1$ 都会增长，因为一切有限差分波动格式都不稳定。
- [x] $r = 1.2$ 时，最大网格值到 $t = 2.4$ 约为 $9.6$，到 $t = 4.2$ 约为 $2507$。同一个初始行在 $r = 1$ 下到 $t = 2$ 已回到初始大小。
- [ ] 增长是弦的某种物理共振，当 $r = 1.2$ 时存在于 $\sin(\pi x)\cos(\pi c t)$ 之中。
::: solution
这些大小在 [[#ex-grow]] 中有记录。模板对光滑函数的相容性约束不住网格上最短的波。微分方程的精确解在任何库朗数下都保持振幅 $1$。这个数 $r$ 是步子的性质，不是弦的性质。
:::
:::
