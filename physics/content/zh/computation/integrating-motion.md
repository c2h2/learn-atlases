能用手解出的弹簧，正是检验数值方法的合适对象。力是光滑的，周期是已知的，能量在任何循环开始运行之前就能写成一个数。若一个方法保不住那个能量，不能把质点放到 $\cos t$ 要求它待的位置，那么它对行星、对从大摆角释放的单摆、对一箱分子，也都靠不住。

本章讲的是把牛顿第二定律沿时间一步步往前推。这个方程是初值问题：此刻的状态，加上变化率的规则，决定了片刻之后的状态。三种规则在同一个振子上比较。前向欧拉沿切线走，任由能量增长。速度韦尔莱法——分子动力学所用的步子——把能量保持在一条窄带里。经典四阶龙格–库塔法每步花四次力的计算，而在这个问题上，它留下的误差远比任何图能显示的还小。

解析的振子见 [[oscillations/simple-harmonic]]。它守恒的能量就是 [[mechanics/work-energy]] 的机械能。拟合、矩阵与本征问题见 [[computation/linear-algebra]]。下面没有任何一处依赖黑箱库。表中的每个数字都由同一节写出的步子产生，取 $m = 1$、$k = 1$、$x(0) = 1$、$v(0) = 0$，以及固定步长 $h$。

## 初值问题 {#ivp}

一个自由度的牛顿第二定律是二阶方程，$\ddot x = a(x, v, t)$。计算机偏爱一阶方程组。把状态取为二元对 $(x, v)$，写成

$$
\dot x = v, \qquad \dot v = a(x, v, t).
$$

解是 $(x, v)$ 平面上的一条曲线。初始条件是该曲线上的一个点。数值的任务是：在没有闭式曲线可给的情况下产生后面的点。

::: definition 初值问题 {#def-ivp}
时间区间上的**初值问题**要求一个函数 $y(t)$ 满足 $\dot y = f(t, y)$，并取给定值 $y(t_0) = y_0$。对直线上的质点，$y$ 是列 $(x, v)$，$f$ 是列 $(v, a(x, v, t))$。
:::

本章一贯使用的线性振子是

$$
m = 1,\qquad k = 1,\qquad \dot x = v,\qquad \dot v = -x,
$$

初始条件为 $x(0) = 1$、$v(0) = 0$。精确解是 $x(t) = \cos t$、$v(t) = -\sin t$。在 $t = 20$ 处，

$$
x(20) = \cos 20 = 0.408082, \qquad v(20) = -\sin 20 = -0.912945,
$$

保留六位小数。周期是 $2\pi$，所以 $t = 20$ 比三个周期多一点。一个方法可能在十分之一个周期内看起来尚可，却在 $t = 20$ 处一无是处。

::: theorem 该振子的能量 {#thm-energy}
沿精确解，机械能

$$
E = \frac12 v^2 + \frac12 x^2
$$

是常数。对上述初始数据，一切 $t$ 都有 $E = \frac12$。
::: proof
沿一条解对所称的能量求导。链式法则给出

$$
\frac{\mathrm{d}E}{\mathrm{d}t} = v\,\dot v + x\,\dot x = v(-x) + x\,v = 0.
$$

初值为 $\frac12 (0)^2 + \frac12 (1)^2 = \frac12$。恒等于零的导数让这个值保持不变。
:::
:::

常数 $\frac12$ 就是诊断量。数值方法造出自己的序列 $(x_n, v_n)$，而那个序列有自己的能量 $E_n = \frac12 v_n^2 + \frac12 x_n^2$。若 $E_n$ 离 $\frac12$ 越走越远，离散轨迹就不是真轨迹的小扰动。若 $E_n$ 待在 $\frac12$ 附近而 $x_n$ 仍离 $\cos t_n$ 很远，方法就是在守恒错误的东西，或者在带着相位误差守恒能量。报告里两个数字都该有：能量误差，以及 $x$ 的误差。

::: example 读出精确能量 {#ex-energy}
同一个质点从 $x = 2$ 处静止释放。$E$ 是多少，最大速率是多少？
::: solution
能量是 $\frac12 (0)^2 + \frac12 (2)^2 = 2$。速率最大时质点在 $x = 0$，故 $\frac12 v^2 = 2$，$\abs{v} = 2$。本章的初始数据 $x(0) = 1$ 是 $E = \frac12$、最大速率为 $1$ 的特例。改变振幅会改变能量而不改变周期，这正是这个振子作为干净检验的原因：方法必须分辨的频率，不依赖能量误差已经长到了多大。
:::
:::

## 前向欧拉 {#euler}

最古老的步子用一条只取步起点信息的弦来代替导数。对单个方程 $\dot y = f(t, y)$，

$$
y_{n+1} = y_n + h\, f(t_n, y_n).
$$

对振子来说这就是两行。加速度在旧位置算出，然后位置和速度都用旧速度与那个加速度更新：

$$
a_n = -x_n, \qquad x_{n+1} = x_n + h\, v_n, \qquad v_{n+1} = v_n + h\, a_n.
$$

::: algorithm 对 $\ddot x = -x$ 的前向欧拉法 {#alg-euler}
给定 $x_n$、$v_n$ 与步长 $h > 0$，取 $a_n = -x_n$，然后

$$
x_{n+1} = x_n + h v_n, \qquad v_{n+1} = v_n + h a_n.
$$

需要计算一次力。产生新加速度的那一步并不使用这个新加速度。
:::

几何图像是切线。在解的图线上，欧拉在 $t_n$ 处画出切线并沿它走时间 $h$，然后画新的切线，如此重复。对二阶导数为零的函数，每一步都是精确的。振子的二阶导数是 $-x$，并不小，所以每一步都犯下一个误差。

::: proposition 一步欧拉的局部误差 {#prop-local}
设真解光滑，且方法从 $t_n$ 处的真实状态出发。当 $h \to 0$ 时，$t_n + h$ 处的真实状态与欧拉状态之差正比于 $h^2$。于是在固定时间 $T$ 上——共 $T/h$ 步——累积误差正比于 $h$。
::: proof
对状态的分量 $y$ 应用带余项的泰勒定理，得

$$
y(t_n + h) = y(t_n) + h\,\dot y(t_n) + \frac12 h^2 \ddot y(\tau)
$$

其中某个 $\tau$ 介于 $t_n$ 与 $t_n + h$ 之间。欧拉保留前两项而丢掉余项。因此，从真值出发的一步，其误差为 $h^2$ 量级。这就是**局部截断误差**。到达固定时间 $T$ 的途中有 $T/h$ 个这样的步。若这些误差只是简单相加，总量就是 $h$ 量级。方程可能在下一次求值之前放大或缩小早先的误差，所以那句话中的常数依赖于 $f$，但对这个单步方法，$h$ 的幂仍是 $1$。欧拉是**一阶**方法：在理论适用的范围内，把 $h$ 减半，就把 $T$ 时刻的误差减半。
:::
:::

"一阶"不是夸奖。它说的是 $h$ 已经小之后误差如何缩放，并没有说误差小。对振子而言，$h$ 必须先小到足以和周期 $2\pi$ 相比，那个缩放律才看得见；而即便到了那时，能量仍可能在漂移。

::: example 手算一步欧拉 {#ex-euler-hand}
从 $(x, v) = (1, 0)$ 出发，取 $h = 0.2$。计算欧拉状态及其能量。
::: solution
起始处的加速度是 $a = -1$。更新为

$$
x_1 = 1 + 0.2 \times 0 = 1, \qquad v_1 = 0 + 0.2 \times (-1) = -0.2.
$$

数值能量是

$$
E_1 = \frac12 (-0.2)^2 + \frac12 (1)^2 = 0.52.
$$

精确能量是 $\frac12$，所以仅仅这一步已经把它抬高了 $0.02$，即 $h^2/2$。$t = 0.2$ 处的精确状态是 $(\cos 0.2,\, -\sin 0.2) \approx (0.9801,\, -0.1987)$。欧拉根本没让 $x$ 移动分毫；速度的大小只是略大了一点。昂贵的是位置误差，它在下一步到来——那时错误速度要乘以 $h$。
:::
:::

那个例子中的能量上升不是舍入的偶然。从 $x = 1$ 静止出发，第一个欧拉步总是给出 $x = 1$、$v = -h$，于是

$$
E = \frac12 + \frac12 h^2.
$$

这个特定问题的后续每一步都继续把一个略错的速度喂给下一个位置。历经许多周期，离散轨道向外螺旋。

## 速度韦尔莱法 {#verlet}

分子动力学很少用前向欧拉。对光滑的力取代它的那个步子——这里写成速度形式——用到区间两端的加速度。

::: algorithm 对 $\ddot x = -x$ 的速度韦尔莱法 {#alg-verlet}
给定 $x_n$、$v_n$ 与 $a_n = -x_n$，

$$
x_{n+1} = x_n + h v_n + \frac12 h^2 a_n,
$$

然后 $a_{n+1} = -x_{n+1}$，并且

$$
v_{n+1} = v_n + \frac12 h\,(a_n + a_{n+1}).
$$

每步在新位置计算一次力。更新速度用的是新旧加速度的半步平均。
:::

位置更新是 $2$ 次泰勒多项式，其中的 $\ddot x$ 换成我们真正知道的加速度。速度更新是 $\dot v = a$ 的梯形公式。对只依赖位置的力，这组式子是时间可逆的：把 $h$ 与 $v$ 同时变号，步子会原路返回。前向欧拉在那个意义下不可逆：欧拉保存的状态里不含用过的加速度，把同一组公式倒着跑是另一个方法。

::: example 手算一步韦尔莱 {#ex-verlet-hand}
从 $(x, v) = (1, 0)$ 出发，取 $h = 0.2$、$a = -1$。计算韦尔莱状态及其能量。
::: solution
新位置是

$$
x_1 = 1 + 0.2 \times 0 + \frac12 (0.2)^2 (-1) = 1 - 0.02 = 0.98.
$$

新加速度是 $-0.98$。新速度是

$$
v_1 = 0 + \frac12 (0.2)\bigl(-1 + (-0.98)\bigr) = 0.1 \times (-1.98) = -0.198.
$$

能量是

$$
E_1 = \frac12 (-0.198)^2 + \frac12 (0.98)^2 = 0.019602 + 0.4802 = 0.499802.
$$

精确状态约为 $(0.9801,\, -0.1987)$，精确能量是 $\frac12$。一步韦尔莱把 $x$ 移动了几乎正确的量，并把能量改变了 $-2.0 \times 10^{-4}$。而在 [[#ex-euler-hand]] 中，同样步长的欧拉步让 $x$ 纹丝未动，把能量抬高了 $0.02$。
:::
:::

卢普·韦尔莱（Verlet）1967 年的论文用的是与之紧密相关的位置递推 $x_{n+1} = 2x_n - x_{n-1} + h^2 a_n$，它需要前两个位置，且完全不保存 $v$。对依赖位置的力，上面的速度形式属于同一族。两种形式都是二阶的：局部误差为 $h^3$ 量级，固定时间 $T$ 处的误差为 $h^2$ 量级。把足够小的步长减半，整体误差除以四。

韦尔莱并不把 $E_n$ 精确保持在 $\frac12$。对这个振子，它让 $E_n$ 在一条宽度按 $h^2$ 收缩的带内振荡。作为实践性质，这比"误差是 $h^2$ 量级"更强，因为一个方法可以是二阶的，却仍让缓慢的漂移在几千个周期里把能量带出这条带。下一节的运行给出几个周期内的这条带。它不是对一切力的证明。

## 经典龙格–库塔步 {#rk4}

龙格–库塔法用若干次类似欧拉的试探来构造一步。经典四阶方法用四次。

::: algorithm 状态 $(x, v)$ 的经典 RK4 {#alg-rk4}
记 $f(x, v) = (v,\, -x)$。给定第 $n$ 步的状态与步长 $h$，

$$
\begin{aligned}
k_1 &= f(x, v), \\
k_2 &= f\bigl(x + \tfrac12 h k_{1x},\; v + \tfrac12 h k_{1v}\bigr), \\
k_3 &= f\bigl(x + \tfrac12 h k_{2x},\; v + \tfrac12 h k_{2v}\bigr), \\
k_4 &= f\bigl(x + h k_{3x},\; v + h k_{3v}\bigr),
\end{aligned}
$$

并以加权平均推进

$$
(x, v)_{n+1} = (x, v)_n + \frac{h}{6}\bigl(k_1 + 2k_2 + 2k_3 + k_4\bigr).
$$

每个 $k_i$ 都是一个二元对。力被计算四次。
:::

权重 $\frac16$、$\frac26$、$\frac26$、$\frac16$ 是辛普森权重。选它们是为了让一步的泰勒展开与真解的泰勒展开到 $h^4$ 项为止全部相合。第一个不相合的项是 $h^5$ 量级。这是局部误差。在固定时间上，整体误差是 $h^4$ 量级。把 $h$ 减半，小的整体误差除以十六——这就是为什么在像这样光滑的问题上，步长稍一减小，RK4 的结果就从"可用"变成"受舍入限制"。

RK4 并不知道这个系统来自机械能。它把 $(x, v)$ 当作任意的一对微分方程。在含摩擦的问题、受驱单摆、或记录下来的函数 $a(t)$ 上，这正是它的优点；而能量不再构成步子的结构性不变量，也正是这个缘故。在短程积分中，四阶精度反正会让能量误差小得微不足道。在几百万个周期的积分中，缓慢的漂移仍可能出现，而韦尔莱或另一种辛格式，正是为阻止它而造的工具。

::: example 数一数力的计算次数 {#ex-cost}
积分到 $t = 20$ 的一次运行取 $h = 0.05$。欧拉、韦尔莱、RK4 各计算多少次加速度？
::: solution
步数是 $20/0.05 = 400$。欧拉与韦尔莱每步计算一次力，各做 $400$ 次计算。RK4 每步四次，共 $1600$ 次。多出的因子四，是阶的代价。在这个振子上，力就是乘以 $-1$，代价看不见。当力要对成千上万个邻居求和，如 [[computation/many-particles]] 那样，因子四就是全部代价，一个只需一次计算的二阶方法可能才是更好的工程选择。
:::
:::

## 一次到二十秒的运行 {#run}

三个算法都从 $(x, v) = (1, 0)$ 积到 $t = 20$，用固定步长 $h = 0.05$，共 $400$ 步。没有自适应，除了寻常的双精度算术之外没有别的舍入，也没有别的力。精确位置是 $\cos 20 = 0.408082$。精确能量是 $\frac12$。

| 方法 | $x(20)$ | $E(20)$ | $E - \tfrac12$ | $x$ 的误差 |
| --- | --- | --- | --- | --- |
| 前向欧拉 | $0.697333$ | $1.357446$ | $+0.857446$ | $+0.289251$ |
| 速度韦尔莱 | $0.406179$ | $0.499739$ | $-2.609 \times 10^{-4}$ | $-1.903 \times 10^{-3}$ |
| 经典 RK4 | $0.408083$ | $0.500000$ | $-4.34 \times 10^{-8}$ | $+9.32 \times 10^{-7}$ |

先读能量列，再读位置列。欧拉不只是漂了：$t = 20$ 处的能量是 $1.357$，几乎是真值的三倍，而这次运行里这个终值正是达到过的最大能量。数值质点摆过 $x = \pm 1$，摆幅达到 $\sqrt{2E} \approx 1.65$。位置误差 $0.29$ 于是不可避免：离散轨道是另一条轨道。

韦尔莱终止于 $E = 0.499739$。运行期间能量待在 $0.499688$ 与 $0.500000$ 之间。差额是万分之几。三个周期之后，位置错了约 $0.002$——在一米长的振幅上是两毫米。若只是把运动画出来，这已经是成功。但对必须在上千个周期里保持准确的相位，$h = 0.05$ 只是个起点，因为哪怕振幅是对的，小小的相位误差也会随时间线性累积。

RK4 的位置误差约 $10^{-6}$，能量误差约 $4 \times 10^{-8}$。在 $x(t)$ 的图上，这次运行与 $\cos t$ 无法分辨。它走到这一步，用了韦尔莱四倍的力的计算。

同样的三个程序取 $h = 0.1$，其余不变，给出的位置误差是

$$
+0.8568 \text{ (欧拉)}, \qquad -7.631 \times 10^{-3} \text{ (韦尔莱)}, \qquad +1.460 \times 10^{-5} \text{ (RK4)}.
$$

与 $h = 0.05$ 的位置误差相比：韦尔莱的误差在 $h$ 减半时缩小了 $4.01$ 倍，正是二阶方法许诺的因子 $2^2$。RK4 的误差缩小了 $15.7$ 倍，接近 $2^4 = 16$。欧拉的误差缩小了约 $3$ 倍，从 $0.857$ 到 $0.289$；$h = 0.1$ 的能量最终到了 $3.66$ 而不是 $1.36$。一阶缩放不那么干净，因为数值解已经离开了当初做局部误差论证的那个邻域。$h = 0.1$ 的欧拉不是 $\cos t$ 的小扰动，而是一条在增长的螺旋。把步长减半会有所改善，而阶的理论只在螺旋被驯服之后才描述得动这个改善。

## 能量在告诉你什么 {#diagnostic}

能量在这里是诊断量，因为我们知道那个精确常数。在没有闭式解的问题上，只要连续系统有守恒量，同一个念头就照样可用。每隔一步、或每隔几十步，在数值状态上算出那个量并画出来。有三种图样值得认出。

稳定爬升——如欧拉那一列——意味着离散动力学的长期性态与微分方程不同。步长取小些，能减少单位时间的爬升，但改变不了这个事实：对要积上许多周期的保守力学系统，它是错误的默认选项。

能量在真值附近小幅振荡、振幅随 $h$ 变小而收缩，是韦尔莱在这个力上的表现。轨道仍然可以有相位误差。能量守恒加上角度不对，就是一个质点以错误的角速度绕着正确的圈转。报告里要把相位、或某个指定时刻 $x$ 的误差，连同能量一起写出来。

能量误差非常小、却缓慢地单向漂移，是 RK4 在很长积分中的典型表现。在 $t = 20$ 内，这漂移在韦尔莱的带旁边看不见；在 $t = 10^5$ 上就未必了。方法的阶与方法的结构性质，是两回事。

还有第四种图样是能量抓不住的。一个把 $\dot v = -x$ 写成 $\dot v = -v$ 的缺陷会耗散能量，而衰减的图线在"没有东西爆炸"的意义上看起来很"稳定"。$\dot v = -v$、$\dot x = v$ 的精确解并不是振子。诊断量必须是那个正确的守恒量，或与已知解的对照，或两者都要。振子挣得它作为检验的地位，正因为两样都有：$E = \frac12$ 与 $x = \cos t$。

一个按本章振子写出的程序打印的能量在一百个周期里都保持在 $0.50$（两位小数），而 $t = 2\pi$ 处的位置是 $0.2$ 而不是 $1$。你能得出什么结论？
::: solution
振幅大致是对的，因为能量是对的，质点不在欧拉的外旋螺旋上。相位错了：一个周期之后精确位置是 $1$，程序却报 $0.2$，即相位差了约 $1.37$ 弧度时的 $\cos \phi$。只凭能量图，这个代码会过关；是它与 $\cos t$ 的对照判了它不及格。表格的两列并存，正是这个缘故。
:::
:::

## 步长、阶与代价 {#step}

步长 $h = 0.05$ 是一个选择，不是定律。周期是 $2\pi \approx 6.28$，所以这个 $h$ 在每个周期里放约 $126$ 步。二阶力学步子一个常见的大致目标是每周期几十步；$126$ 是宽裕的，而韦尔莱在三个周期后 $2 \times 10^{-3}$ 的位置误差，正是这类目标给出的精度。同样的精度下，RK4 可以走更长的步。这里故意让它用同样的 $h$，好让表格比较的是方法本身，而不是一个方法的小心使用者与另一个方法的大意使用者的对比。

阶是关于光滑解与小 $h$ 的陈述。力 $-x$ 光滑到了极点。一次碰撞、分段定义的接触力、或有跳跃的记录加速度，都会把阶砍到实际存在的光滑程度。对一个不是四次可微的力，RK4 造不出四个 $h$ 的幂次来。

舍入终归会挡住步长减小带来的好处。$h = 0.05$ 的 RK4 位置误差已接近 $10^{-6}$。再把 $h$ 减半、指望再降十六倍，就是要求 $6 \times 10^{-8}$ 量级的误差。双精度能表示它，但更小的步意味着更多的运算，而每次运算都要舍入。越过某个取决于机器与公式的点之后，步长越短，答案越坏。若稳定的二阶或四阶运行给出的精度不够用，下一批工具是更高阶的方法、带修正步长的辛方法，或一个让周期更省地被分辨出来的变量代换。而不是在寻常双精度里把步长压到 $10^{-12}$。

自适应步长走的是另一条路。它们估计局部误差——常用两个方法互相比较——并在估计值大的地方把 $h$ 缩短。本章的表格里没有一样是自适应的。自适应程序在振子上可以放心走大步，因为力光滑，时间尺度从不改变。它的价值体现在一颗近日点快、远日点慢的彗星上，体现在一套有两个悬殊时间尺度的化学速率方程上。守恒的问题仍然存在：一个不是围绕能量设计的自适应方法仍可能漂移。检验诊断量要在自适应做完它的工作之后去检，而不是只在定步长的检验里。

::: example 预测更小的韦尔莱误差 {#ex-predict}
$h = 0.05$ 时，韦尔莱在 $x(20)$ 的误差大小为 $1.903 \times 10^{-3}$。设二阶缩放已经建立，估计 $h = 0.025$ 时的大小。
::: solution
步长减半，二阶整体误差除以 $4$。估计值是

$$
1.903 \times 10^{-3} / 4 = 4.76 \times 10^{-4}.
$$

这个假设的内容，就是 $h = 0.1$ 与 $h = 0.05$ 之间已经做过的那个比较——那里的因子是 $4.01$。这是估计，不是测量。新运行的诚实报告就是新运行本身；估计用来决定那次运行值不值得花钱去跑。
:::
:::

## 加速度依赖速度时 {#velocity}

[[#alg-verlet]] 中的韦尔莱公式用的是 $a = -x$，只依赖位置的函数。摩擦、磁力、科里奥利加速度都依赖速度。位置更新于是需要一个加速度，而它本身依赖你正在算到一半的速度。一个干净的办法是改用 RK4，它从未假设加速度不能依赖速度：$f(x, v)$ 可以依赖两个自变量，四次试探始终良定。代价是失去那个让能量带如此收紧的精确时间反演性质。

第二个办法是交错格式：把依赖速度的部分显式处理，或在步内解一个小的线性方程。对线性阻力 $\dot v = -x - \gamma v$，阻力项用梯形公式会得到一个关于 $v_{n+1}$ 的线性方程，可手解。细节要留给你实际拥有的那个力。要领则狭窄得多：不要把只含位置的韦尔莱公式硬贴到依赖速度的力上，还指望代数自行闭合。诚实地写出 $a(x, v)$，然后选一个步子——它在你已经算出的自变量处求值那个加速度，或者它允许你把加速度解出来。

本章的小部件有一个阻尼系数 $c$。$c = 0$ 时它就是检验问题。$c > 0$ 时精确能量不再恒定：阻力做负功。这时往下掉的能量图线恰恰是实情，不是方法出了毛病。诊断量要跟着方程改。对线性阻力，值得盯的量可能是与精确阻尼解的对照——它仍是初等的——而不是与 $\frac12$ 的对照。

::: warning 能量增长来自方法
在这个振子上，前向欧拉抬高能量，即使程序里的每一行都是 [[#alg-euler]] 里的那一行、每一次运算都精确。增长并不是你把 $-x$ 误写成 $+x$ 的迹象；符号写错时，振荡或爆炸另有其相。查过符号之后，还要认得出来：欧拉的外旋螺旋是一个正确实现应有的性态。补救是换一个步子，或把 $h$ 取得小得多，而不是去搜索一个根本不存在的缺陷。
:::

::: example 有阻尼，不再是守恒的检验 {#ex-damped}
把力改成 $\dot v = -x - 0.1 v$，从 $x = 1$ 处静止释放。很长时间之后，正确的数值能量应当怎样？
::: solution
阻力 $-0.1 v$ 与速度反向，其功率 $-0.1 v^2$ 永不为正。机械能 $\frac12 v^2 + \frac12 x^2$ 递减，直到质点停在原点，那里能量为零。向零下落的数值能量与方程相容；先降后又升、或停在非零值上的数值能量则不相容。无阻尼的那张表对这个力是错的图景，韦尔莱围绕 $\frac12$ 的那条带是错的靶子。
:::
:::

## 同样的步子用在何处 {#uses}

振子是检验，不是应用。同样的三个念头，只要多费些记录功夫，就能搬到任何能写成 $\dot y = f(t, y)$ 的系统上。

固定平方反比场中的一颗行星，是两三个二阶方程。力只依赖位置，精确问题的角动量和能量守恒，韦尔莱一类的步子是体面的默认选项。诊断量就是那两个守恒量，外加束缚轨道时与圆锥曲线的对照。连续的问题见 [[mechanics/gravitation]]。

刚体用本体坐标系中的欧拉方程写出时，状态由角速度组成。力矩为零时，动能与角动量的平方是诊断量。力的计算很便宜。阶与可逆性仍然要紧，因为自由转动的模拟可能跑很长时间。

记录下来的实验室加速度存成一张表 $a(t)$，不是保守力，没有能量可守恒。RK4 或任何标准单步方法都合适。不论形式上的阶是多少，步长都不能大于表格真正发生变化的时间。

对邻居求和的力的多粒子情形见 [[computation/many-particles]]。"时间"不再是推进的变量、未知量是场的网格情形见 [[computation/fields-on-grids]]。习惯是通用的：知道阶，知道每步代价，并且盯住连续问题守恒的那个量——如果它守恒的话。

::: history 欧拉、龙格、库塔与韦尔莱
切线步出自欧拉（Euler），写在他《Institutionum calculi integralis》第一卷（1768）中。卡尔·龙格（Runge）在 1895 年系统地给出了通过在若干内点处求导数来提高单步方法阶数的办法。威廉·库塔（Kutta）在 1901 年完成了 [[#alg-rk4]] 所用的那个经典四次计算方法。卢普·韦尔莱（Verlet）在论文《Computer experiments on classical fluids》（《Physical Review》，1967）中，用带他名字的二阶递推积分了以短程力相互作用的粒子的运动。他需要一个对每个粒子都便宜、又不会缓慢加热流体的步子。表格的能量列就是那条要求的演示，演示的题目小到能手算。
:::

::: summary
- 振子 $\ddot x = -x$ 在 $x(0) = 1$、$v(0) = 0$ 下的精确解是 $x = \cos t$，精确能量是 $\frac12$。两者都是诊断量。
- 前向欧拉每步计算一次力，是一阶的，在这个问题上抬高能量。$h = 0.05$ 时，$t = 20$ 处的能量是 $1.357$ 而不是 $0.500$。
- 速度韦尔莱每步计算一次力，对依赖位置的力是二阶的，在同一步长下把能量保持在宽度为 $10^{4}$ 分之几的一条带里。
- 经典 RK4 每步计算四次力，是四阶的，$h = 0.05$ 时在 $t = 20$ 留下 $10^{-6}$ 量级的位置误差。
- 对阶 $1$、$2$、$4$，把 $h$ 减半会把小的整体误差除以 $2$、$4$ 或 $16$。只有当数值解仍贴近真解时，数据里才出现那个因子。
- 能量守恒证明不了相位。若有精确值可凭，就拿 $x(T)$ 去和它对照。
- 依赖速度的力不在只含位置的韦尔莱公式适用范围之内。RK4 仍然适用。阻力之下能量下落，可以是正确的物理。
:::

## 习题

::: exercise 一步欧拉 {level=1 check="0.52"}
振子 $\ddot x = -x$ 从 $(x, v) = (1, 0)$ 出发。走一步大小为 $h = 0.2$ 的前向欧拉步。之后的数值能量是多少？
::: hint
先用 $a = -x$ 更新 $v$，再重算 $x$。在这第一步里，$x$ 不动。
:::
::: solution
$a = -1$，故 $x_1 = 1$、$v_1 = -0.2$。于是 $E = \frac12 (0.04) + \frac12 (1) = 0.52$。
:::
:::

::: exercise 一步韦尔莱 {level=1 check="0.98"}
同样的初始状态、同样的 $h = 0.2$，改用速度韦尔莱。一步之后 $x$ 是多少？
::: hint
位置更新用到 $\frac12 h^2 a$，其中 $a = -1$。
:::
::: solution
$x_1 = 1 + 0 + \frac12 (0.04)(-1) = 0.98$。这个问题不需要速度更新。若要把它与 [[#ex-verlet-hand]] 对照：速度更新给出 $v_1 = -0.198$，能量 $0.499802$。
:::
:::

::: exercise 多少步 {level=1 check="400"}
从 $t = 0$ 到 $t = 20$ 的定步长运行取 $h = 0.05$。共多少步？
::: solution
$20/0.05 = 400$。欧拉与韦尔莱各计算力 $400$ 次。RK4 计算 $1600$ 次。
:::
:::

::: exercise 精确核对点 {level=1 check="0.5"}
不跑数值方法，说出本章初值问题的精确能量，以及 $t = 2\pi$ 处的精确位置。
::: solution
由 [[#thm-energy]]，一切 $t$ 都有 $E = \frac12$。$t = 2\pi$ 时恰好过了一个周期，$\cos 2\pi = 1$、$\sin 2\pi = 0$，故 $(x, v) = (1, 0)$ 如故。
:::
:::

::: exercise 从表格读阶 {level=2}
韦尔莱在 $t = 20$ 的位置误差，$h = 0.1$ 时大小为 $7.631 \times 10^{-3}$，$h = 0.05$ 时为 $1.903 \times 10^{-3}$。哪个阶与这个比值相容？$h = 0.025$ 时你预期多大？
::: hint
把两个误差相除。把商与 $2$、$4$、$16$ 比较。
:::
::: solution
比值是 $7.631 \times 10^{-3} / 1.903 \times 10^{-3} = 4.01$，是 $2^2$，不是 $2^1$ 也不是 $2^4$。观测到的阶是 $2$。再减半一次应当把误差再除以约 $4$，得到 $4.76 \times 10^{-4}$ 附近的大小。
:::
:::

::: exercise 欧拉不是小扰动 {level=2}
$h = 0.1$ 时，前向欧拉在 $t = 20$ 的能量是 $3.658$。具有那个能量的真振子的振幅是多少？为什么一阶缩放描述不好这次运行？
::: solution
能量为 $E$、$k = m = 1$ 的真振子振幅为 $\sqrt{2E}$。这里 $\sqrt{2 \times 3.658} = \sqrt{7.316} \approx 2.70$，而真振幅是 $1$。数值轨迹是另一条能量好几倍的轨道。产出"整体误差正比于 $h$"的泰勒论证是围绕真解展开的；一旦数值状态离开了那个真解的邻域，把 $h$ 减半仍然有帮助，但在 $h$ 小到能量不再失控之前，那个因子未必恰好是 $2$。在本章的比较中，$h = 0.1 \to 0.05$ 把欧拉的位置误差缩小了约 $3$ 倍，而不是 $2$。
:::
:::

::: exercise 相位与振幅 {level=2}
一个韦尔莱积分在每个输出时刻都报告 $E = 0.500$（三位小数），并报告 $x(2\pi) = 0$。精确位置是 $1$。用物理语言描述这个误差。振幅可以接受吗？
::: solution
能量 $0.500$ 意味着振幅 $1$，所以振幅可以接受。一个周期结束时位置是 $0$ 而不是 $1$，意味着数值相位差了约四分之一个周期：质点在该待的释放点上偏偏不在，而是在原点。能量守恒没有察觉这个计时误差。这就是 [[#ex-lying]] 的情形，只是错得更干脆。
:::
:::

::: exercise 依赖速度的力 {level=3}
加速度改成 $a = -x - v$。解释为什么"算出 $a_{n+1} = -x_{n+1}$ 再对两个加速度取平均"这个只含位置的做法不再是一个闭合的步子，并说出本章中公式一字不改仍适用的一个方法。
::: solution
位置更新之后 $x_{n+1}$ 已知，但 $a_{n+1} = -x_{n+1} - v_{n+1}$ 里仍含未知的新速度。于是对 $a_n$ 与 $a_{n+1}$ 取平均以求 $v_{n+1}$，是一个关于 $v_{n+1}$ 的方程，不是直接代入。本章只含位置的韦尔莱清单解不了那个方程。经典 RK4 从不把加速度分成"由 $x$ 可知"与"由 $v$ 可知"两部分：只要试探状态被提出，它对 $f(x, v) = (v,\, -x - v)$ 的四次计算就都有定义，所以同一个 [[#alg-rk4]] 换上新的 $f$ 即可。
:::
:::

::: exercise 邻居求和的代价 {level=3}
分子动力学的力，计算一次所花的时间是一步韦尔莱或 RK4 中其余部分的 $200$ 倍。你需要在固定时间处约 $10^{-3}$ 的位置误差；一次试运行表明韦尔莱在某个 $h$ 达到它，而 RK4 在 $4h$ 达到它。哪个方法做的力的计算更少？少几倍？
::: hint
韦尔莱的整体误差按 $h^2$ 缩放，RK4 按 $h^4$。试运行已经把这个缩放律换算成步长了。数单位时间的计算次数。
:::
::: solution
按单位时间计，韦尔莱做 $1/h$ 次力的计算；若 RK4 的步真的长四倍，它也做 $4/(4h) = 1/h$ 次。两个方法于是用一样多次力的计算，因子是 $1$。常说的"RK4 贵四倍"假设的是同一个 $h$；这里阶已经花在了更长的步上，四次试探由只走四分之一的步数付了账。若试运行的结论是 RK4 只能把步长拉到 $2$ 倍，那 RK4 每单位时间要用 $4/(2h) = 2/h$ 次计算，韦尔莱就便宜一倍。试运行的数字是答案的一部分，光靠阶定不了代价。
:::
:::

::: quiz
对 $\ddot x = -x$ 的一次正确的前向欧拉积分——从 $x = 1$ 静止出发、用 $h = 0.05$ 这样适中的步——通过能量 $E = \frac12 v^2 + \frac12 x^2$ 来观看。能量会怎样？
- [ ] 它在舍入误差内保持在 $\frac12$，因为力是 $-x$，而方法的每一行都与本章清单一致。
- [ ] 它稳定下落到 $0$，因为任何数值方法都耗散能量。
- [x] 它增长，数值振荡变得比振幅 $1$ 还大。增长是方法使然，不是符号写错了。
- [ ] 它在 $\frac12$ 附近宽度正比于 $h^2$ 的带内振荡，那是韦尔莱的性态，不是欧拉的。
::: solution
表格在 $h = 0.05$ 处以欧拉能量 $1.357$ 收尾，而那已是运行期间的最大值。具有那个能量的真振子，振幅大于 $1$。能量下落描述的会是阻力，而这里的力没有阻力；围绕 $\frac12$ 的紧带是同一张表里速度韦尔莱做的事。照着印刷的欧拉公式一字不差，也抵消不了把离散轨道向外推的截断误差。
:::
:::
