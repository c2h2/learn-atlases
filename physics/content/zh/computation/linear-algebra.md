物理计算的大部分内容，在微分方程被网格或步子取代之后，就是一个线性方程。有限差分的拉普拉斯算子变成矩阵；给实验点拟合一条直线的最小二乘是矩阵；平衡位形附近的小振动是矩阵的本征值。本章在小到能手算完成的系统上做这三件事，并记下残差，好让后来的程序能用同一标准来评判。

下面的数字都是直接算出来的——寻常算术——然后用第二种解法解同一组方程来核对。没有一个是照着图描出来的拟合。[[computation/integrating-motion]] 的积分器是本章在时间推进方面的表亲：那里的诊断量是能量，这里的是残差。更大规模拟合的随机样本与正规方程会再现在 [[computation/random-sampling]]。

## 一个线性方程组 {#system}

$n$ 个未知数的 $n$ 元线性方程组是 $A\mathbf{x} = \mathbf{b}$。元素 $A_{ij}$ 在第 $i$ 个方程中乘第 $j$ 个未知数。$n = 2$ 或 $n = 3$ 时能看清算法本身；同样的算法加上主元和残差，就是程序在 $n = 10^4$ 时做的事。

::: definition 残差 {#def-residual}
给定一个候选解 $\mathbf{x}$，**残差**是向量 $\mathbf{r} = \mathbf{b} - A\mathbf{x}$。当 $\mathbf{r} = \mathbf{0}$ 时解是精确的。当 $\mathbf{r}$ 在你关心的尺度上相对 $\mathbf{b}$ 足够小时，数值解对手头的题目就算合格——这是你必须声明的一个决定，不是矩阵的性质。
:::

残差不是误差 $\mathbf{x}_{\text{true}} - \mathbf{x}$。矩阵可能把一个小残差变成 $\mathbf{x}$ 里的大误差，也可能反过来。报告 $\mathbf{r}$ 仍是第一责任，因为 $\mathbf{r}$ 可以在不知道 $\mathbf{x}_{\text{true}}$ 的情况下算出来。从残差到误差的映射是 $A$ 的条件，这在消元法先把一个良态例子解好之后再来谈。

::: example 看得见的残差 {#ex-residual-see}
对方程 $2x + y = 4$ 与 $x - y = -1$，有人提议 $(x, y) = (1, 1)$。计算残差。
::: solution
第一个方程要 $2(1) + 1 = 3$，而右端是 $4$，所以 $\mathbf{r}$ 的第一个分量是 $4 - 3 = 1$。第二个方程要 $1 - 1 = 0$ 对上 $-1$，所以第二个分量是 $-1 - 0 = -1$。故 $\mathbf{r} = (1,\, -1)$。这个提议不是解。解是 $(1, 2)$，因为 $2(1) + 2 = 4$ 且 $1 - 2 = -1$，那个提议的残差才是零。
:::
:::

## 高斯消元 {#elimination}

消元一次清掉主元下面的一列，直到方程组成为三角形。回代从最底下开始。

取那个解最终为 $x = 1$、$y = 2$、$z = -1$ 的方程组：

$$
\begin{aligned}
x + y + z &= 2, \\
2x + y - z &= 5, \\
x - y + 2z &= -3.
\end{aligned}
$$

第二个方程减去第一个方程的两倍，第三个方程减去第一个方程：

$$
\begin{aligned}
x + y + z &= 2, \\
- y - 3z &= 1, \\
- 2y + z &= -5.
\end{aligned}
$$

把新的第二个方程乘 $2$、从第三个方程中减去，就消去了 $y$：

$$
(-2y + z) - 2(-y - 3z) = -5 - 2(1),
$$

即 $7z = -7$，故 $z = -1$。然后 $-y - 3(-1) = 1$，故 $-y = -2$、$y = 2$。再然后 $x + 2 + (-1) = 2$，故 $x = 1$。

同样的算术写成矩阵。方程组是 $A\mathbf{x} = \mathbf{b}$，其中

$$
A = \begin{pmatrix} 1 & 1 & 1 \\ 2 & 1 & -1 \\ 1 & -1 & 2 \end{pmatrix}, \qquad \mathbf{b} = \begin{pmatrix} 2 \\ 5 \\ -3 \end{pmatrix}, \qquad \mathbf{x} = \begin{pmatrix} 1 \\ 2 \\ -1 \end{pmatrix}.
$$

逐行计算，$A\mathbf{x}$ 给出 $(2,\, 5,\, -3)$，所以残差是零向量。上面得到的三角系数矩阵的对角元素是 $1$、$-1$、$7$，其乘积是 $-7$。

::: proposition 主元与行列式 {#prop-pivots}
若对方阵做高斯消元且全程没有换行，则行列式等于各主元的乘积。
::: proof
把某行的倍数加到另一行不改变行列式，而每一次消元都属于这种操作。原矩阵与最后的上三角矩阵因此有相同的行列式。三角矩阵的行列式是其对角元素之积，而那些元素就是主元。
:::
:::

对这个 $A$ 没有换过行，故 $\det A = 1 \cdot (-1) \cdot 7 = -7$。稍后有一句话会说明，为什么引用"$-7$"只是 $\mathbf{x}$ 精确的一个软弱凭证。不过要看出唯一解存在过，主元乘积仍是对的办法：那个乘积不是零。

::: algorithm 高斯消元，$n = 3$ {#alg-gauss}
把方程写成这样：第一个未知数在第一个方程中带非零系数出现，该系数就是主元。用方程 $1$ 的倍数从方程 $2$、$3$ 中消去该未知数在主元以下的部分。对剩下的 $2 \times 2$ 块中的第二个未知数重复一遍。解出最后一个方程，然后向上回代。
:::

用主元 $A_{11}$ 消去元素 $A_{i1}$ 的乘数是 $A_{i1}/A_{11}$。若主元为零，这个乘数不存在，必须先换行再除。若主元只是小，乘数就大，主元行里已有的任何误差都会被乘上一个大数、浇进下面的各行。换行让主元成为该列中可选的最大元素，这就是**部分主元**。它修不好一个真正病态的矩阵；它能阻止方法在别的方程本可提供寻常大小的主元时，凭空造出一个巨大的乘数。

::: example 从下往上解同一个方程组 {#ex-backsub}
用 $z = -1$ 和方程 $-y - 3z = 1$。解出 $y$，并连同 $x = 1$ 代入 $x - y + 2z = -3$ 核对。
::: solution
$-y - 3(-1) = 1$ 给出 $-y + 3 = 1$，故 $y = 2$。然后 $x - y + 2z = 1 - 2 + 2(-1) = -3$，与第三个右端吻合。三元组 $(1,\, 2,\, -1)$ 满足全部三个原方程，所以残差是零向量。一个打印出这个三元组和 $10^{-15}$ 量级残差的程序，展示的是舍入，不是第二个解。
:::
:::

::: warning 小主元
大于 $1$ 的乘数会放大主元行里已存的任何误差，而回代又要除以那个同样的小主元。在三位有效数字的截尾之下，$10^{-3}\, x + y = 1$ 与 $x + y = 2$ 若保留 $10^{-3}$ 作主元，会得到 $(x, y) = (2.00,\, 0.998)$。精确解是 $x = 1/0.999 = 1.001001\ldots$、$y = 0.998999\ldots$。先换行，让主元为 $1$，同样的截尾给出 $x = 1.00$。部分主元就是这个换行。它修不好行与行真正几乎平行的矩阵。算术见 [[#ex-pivot]]。
:::

::: example 三位有效数字截尾，换行与不换行 {#ex-pivot}
用消元解 $10^{-3}\, x + y = 1$ 与 $x + y = 2$，每个结果都截尾到三位有效数字。做两遍：一遍以第一个方程为主元行，一遍先换行。截尾的意思是：把数写成 $\pm\, d.dd \times 10^{e}$ 并舍去后面的数字，不进位。
::: solution
精确解是 $x = 1/0.999 = 1.001001\ldots$、$y = 1 - 10^{-3} x = 0.998999\ldots$。

不换行时乘数是 $1/10^{-3} = 1000$，已经三位。第一个方程缩放后是 $x + 1000\, y = 1000$。用第二个方程减去它：$x$ 的系数是 $1 - 1 = 0$；$y$ 的系数是 $1 - 1000 = -999$，而 $-999 = -9.99 \times 10^{2}$ 保持三位；右端是 $2 - 1000 = -998$。新方程是 $-999\, y = -998$，故

$$
y = \frac{998}{999} = 0.998998\ldots,
$$

截尾为 $0.998$。回代入存下的第一个方程 $10^{-3}\, x + y = 1$：

$$
10^{-3}\, x = 1 - 0.998 = 0.002, \qquad x = \frac{0.002}{10^{-3}} = 2.00.
$$

算出的数对是 $(2.00,\, 0.998)$。它对原方程组的残差是 $(0,\, -0.998)$：第一个方程满足了，第二个差了将近 $1$。$y$ 的误差本是 $10^{-3}$ 量级；除以主元 $10^{-3}$ 把它变成了 $x$ 里 $1$ 量级的误差。

现在换行，让主元方程为 $x + y = 2$，乘数是 $10^{-3}$。新的第二个方程有

$$
y\text{ 的系数 } 1 - 10^{-3} = 0.999, \qquad \text{右端 } 1 - 2 \times 10^{-3} = 0.998.
$$

于是 $y = 0.998/0.999 = 0.998998\ldots$，同样截尾为 $0.998$。回代入 $x + y = 2$ 得 $x = 2 - 0.998 = 1.002$，而 $1.002$ 截尾为 $1.00$。三位数字如今与精确值 $1.001$ 相符。唯一的改动是哪一个方程提供了主元。
:::
:::

## 最小二乘 {#least}

四个点不在一条直线上：$(0, 1)$、$(1, 2)$、$(2, 2)$、$(3, 4)$。模型 $y = a + bx$ 有两个自由数、四个条件。不存在同时满足四个条件的 $(a, b)$。最小二乘的选法使竖直残差的平方和最小：

$$
S(a, b) = \sum_{i=1}^{4} \bigl(y_i - a - b x_i\bigr)^2.
$$

令 $\partial S/\partial a = 0$、$\partial S/\partial b = 0$。求导带下一个因子 $-2$ 和残差，驻点条件就是**正规方程**

$$
\begin{aligned}
n a + \Bigl(\sum x_i\Bigr) b &= \sum y_i, \\
\Bigl(\sum x_i\Bigr) a + \Bigl(\sum x_i^2\Bigr) b &= \sum x_i y_i.
\end{aligned}
$$

::: theorem 直线的正规方程 {#thm-normal}
对模型 $y = a + bx$ 与 $n$ 个点，使 $S$ 最小的 $a$ 与 $b$ 的值满足上面的 $2 \times 2$ 方程组——前提是这些和真的算了出来。就结论的方向而言，二阶导数检验并非必要：$S$ 是平方和，以下零为界，而正规方程是线性的，所以它们给出的驻点就是最小值。
::: proof
对求和号内逐项求导：$\partial S/\partial a = -2 \sum (y_i - a - b x_i)$，$\partial S/\partial b = -2 \sum x_i (y_i - a - b x_i)$。令两者为零，约去公因子 $-2$，再展开。第一个方程中 $a$ 的系数是点的个数；$b$ 的系数是 $\sum x_i$，它也是第二个方程中 $a$ 的系数；第二个方程中 $b$ 的系数是 $\sum x_i^2$。
:::
:::

对这四个点，

$$
\sum x = 6,\quad \sum y = 9,\quad \sum xy = 18,\quad \sum x^2 = 14,\quad n = 4.
$$

正规方程是 $4a + 6b = 9$ 与 $6a + 14b = 18$。第一式乘 $3$、第二式乘 $2$：

$$
12a + 18b = 27, \qquad 12a + 28b = 36.
$$

相减：$10b = 9$，故 $b = 0.9$。然后 $4a + 6(0.9) = 9$，故 $4a = 3.6$、$a = 0.9$。拟合直线是

$$
y = 0.9 + 0.9\, x.
$$

::: example 拟合的残差 {#ex-rss}
计算 $y = 0.9 + 0.9x$ 的四个残差与残差平方和。
::: solution
在 $x = 0, 1, 2, 3$ 处，直线的预测值是 $0.9$、$1.8$、$2.7$、$3.6$。数据是 $1$、$2$、$2$、$4$。残差（数据减直线）是

$$
0.1,\quad 0.2,\quad -0.7,\quad 0.4.
$$

平方和是 $0.01 + 0.04 + 0.49 + 0.16 = 0.70$。没有别的 $a$ 与 $b$ 能使这个和更小。四个点上 $0.70$ 的和，不是在声称这条直线是自然定律，它只是没射中的尺寸。$x = 2$ 那个点贡献了 $0.70$ 中的 $0.49$。
:::
:::

::: widget plot
f: 0.9+0.9*x
x: -0.2, 3.2
y: 0, 4.5
caption: 对点 (0, 1)、(1, 2)、(2, 2)、(3, 4) 的最小二乘直线 y = 0.9 + 0.9x。这些点本身没有画出来。直线从点附近穿过，却不过其中任何一个。残差平方和是 0.70。
:::

正规方程是一个 $2 \times 2$ 方程组，即便拟合是精确的，它也可能病态——只要所有 $x_i$ 都远离原点且彼此靠得很近。对 $(0, 1)$、$(1, 2)$、$(2, 2)$、$(3, 4)$ 手算 $\sum x_i^2$ 人畜无害。下面四个点会显示同样的和如何变得咄咄逼人。

::: example 六位有效数字看不见的直线 {#ex-centre}
点 $(1000,\, 12)$、$(1001,\, 12.01)$、$(1002,\, 12.02)$、$(1003,\, 12.03)$ 在直线 $y = 2 + 0.01\, x$ 上。列出正规方程，记下分母 $n\sum x^2 - (\sum x)^2$，然后把该分母的两项都截尾到六位有效数字。再把每个 $x$ 换成 $x - 1001.5$ 重复一遍拟合。
::: solution
各和为 $n = 4$、$\sum x = 4006$、$\sum y = 48.06$、$\sum xy = 48132.14$、$\sum x^2 = 4012014$。$b$ 的分母是

$$
4 \times 4012014 - 4006^2 = 16048056 - 16048036 = 20.
$$

在精确算术下解正规方程给出 $a = 2$、$b = 1/100$，正是那些点所在的那条直线。残差平方和为零。相减的那两个数前六位相同：把 $16048056$ 与 $16048036$ 截尾到六位有效数字，两次都得到 $16048000$，分母成了 $0$。一个在六位算术下列正规方程的程序，会对四个明明躺在直线上的点报告说它找不到斜率。

正规矩阵 $\begin{pmatrix} 4 & 4006 \\ 4006 & 4012014 \end{pmatrix}$ 的本征值约为 $4.012018 \times 10^{6}$ 与 $4.985 \times 10^{-6}$。条件数——两者之比——约为 $8.048 \times 10^{11}$。数据在第十一位的改动就能让算出的 $(a, b)$ 在小数点前面挪动一位。这与下文条件一节里近乎平行的行是同一个现象，这里它不是由物理产生，而是由坐标原点的选择产生。

把横坐标中心化：$x' = x - 1001.5$ 取值 $-3/2$、$-1/2$、$1/2$、$3/2$。于是 $\sum x' = 0$、$\sum (x')^2 = 5$。模型写成 $y = a' + b x'$，斜率 $b$ 不变。现在

$$
b = \frac{\sum x' y}{\sum (x')^2} = \frac{1/20}{5} = \frac{1}{100}, \qquad a' = \frac{48.06}{4} = 12.015,
$$

且 $a = a' - b \times 1001.5 = 12.015 - 10.015 = 2$。中心化后的正规矩阵是对角阵，元素为 $4$ 与 $5$，故条件数是 $5/4 = 1.25$。六位算术对付分母 $5$ 毫无困难。拟合出的还是那条直线，是原点挪了位置。
:::
:::

## 本征值 {#eigen}

方阵 $A$ 作用在向量上。**本征向量**是 $A$ 不转动的那个方向，**本征值**是沿该方向的伸缩率：$A\mathbf{v} = \lambda \mathbf{v}$，其中 $\mathbf{v} \neq \mathbf{0}$。小振动、惯量张量的主轴、耦合弹簧的简正模，问的都是这些方向。解析理论见 [[analytical-mechanics/small-oscillations]]。这里的问题是：怎么把数算出来。

对对称的 $2 \times 2$ 矩阵，特征多项式就够了。取

$$
A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}.
$$

则 $\det(A - \lambda I) = (2 - \lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = (\lambda - 1)(\lambda - 3)$。本征值为 $\lambda_1 = 1$、$\lambda_2 = 3$。对应 $\lambda = 3$ 的向量满足 $(2 - 3)v_1 + v_2 = 0$，即 $v_2 = v_1$。归一化：$\mathbf{v}_2 = (1,\, 1)/\sqrt{2}$。对应 $\lambda = 1$ 的向量满足 $v_2 = -v_1$，故 $\mathbf{v}_1 = (1,\, -1)/\sqrt{2}$。

::: definition 本征对与残差 {#def-eigen}
数 $\lambda$ 与非零向量 $\mathbf{v}$ 构成 $A$ 的一个**本征对**，当 $A\mathbf{v} - \lambda \mathbf{v} = \mathbf{0}$。对一对候选值，**本征残差**是向量 $A\mathbf{v} - \lambda \mathbf{v}$。对本征对，它的长度为零。报告这个长度，并同时说明 $\mathbf{v}$ 是否被缩放成长度 $1$，因为拉伸 $\mathbf{v}$ 也拉伸残差。
:::

一旦 $\mathbf{v}$ 取上面归一化后的向量，这个 $A$ 的两个精确本征对的本征残差长度都是 $0$（到机器精度）。这个检验就是 $\mathbf{r} = \mathbf{b} - A\mathbf{x}$ 在本征值问题里的表亲。

大型对称矩阵不靠展开特征多项式来解。多项式的根即便对中等大小的 $n$ 也是很差的本征值算法，因为根对系数敏感。幂迭代是最小的方法，它展示的用 $A\mathbf{v}$ 而不用多项式来做这件事的思想。

::: algorithm 幂迭代 {#alg-power}
从非零向量 $\mathbf{v}^{(0)}$ 出发。重复：置 $\mathbf{w} = A\mathbf{v}$，然后 $\mathbf{v} = \mathbf{w}/\lVert\mathbf{w}\rVert$。长度 $\lVert A\mathbf{v}\rVert$ 趋于模最大的本征值——前提是该本征值为实、为单，且模严格大于其余本征值，并且起始向量不恰好与它的本征向量正交。
:::

对这个 $A$，从 $\mathbf{v}^{(0)} = (1,\, 0)$ 出发。前六个归一化向量与瑞利商 $\mathbf{v}\cdot A\mathbf{v}$（对本征单位向量它恰等于 $\lambda$）如下：

| 步数 | $v_1$ | $v_2$ | $\mathbf{v}\cdot A\mathbf{v}$ |
| --- | --- | --- | --- |
| 1 | $0.894427$ | $0.447214$ | $2.800000$ |
| 2 | $0.780869$ | $0.624695$ | $2.975610$ |
| 3 | $0.732793$ | $0.680451$ | $2.997260$ |
| 4 | $0.715782$ | $0.698324$ | $2.999695$ |
| 5 | $0.710011$ | $0.704191$ | $2.999966$ |
| 6 | $0.708076$ | $0.706136$ | $2.999996$ |

目标是 $\mathbf{v}_2 = (0.707107,\, 0.707107)$ 与 $\lambda = 3$。六次乘以 $2 \times 2$ 矩阵，就把瑞利商做到了第六位小数才出错。较小的本征值 $\lambda = 1$ 没有出现。幂迭代之所以生来如此，是因为它找的就是占优的那个。要得到 $\lambda = 1$，得在一个能剔除已找到方向的算法里换一个不同的起点，或者用特征多项式——对 $n = 2$，后者才是诚实的工具。

这张表不是舍入的巧合。记 $\lambda = 3$ 的 $\mathbf{u} = (1,\, 1)/\sqrt{2}$、$\lambda = 1$ 的 $\mathbf{w} = (1,\, -1)/\sqrt{2}$。这两个向量标准正交，起始向量可分解为

$$
(1,\, 0) = \frac{\mathbf{u} + \mathbf{w}}{\sqrt{2}}.
$$

每乘一次 $A$，$\mathbf{u}$ 分量乘 $3$、$\mathbf{w}$ 分量乘 $1$，所以相对于占优方向，多余的那个方向每一步都轻一个因子 $1/3$。

::: proposition $k$ 步之后的瑞利商 {#prop-rayleigh}
对这个 $A$ 与这个起点，$k$ 次归一化之后的瑞利商恰好是

$$
R_k = \frac{3^{2k+1} + 1}{3^{2k} + 1}.
$$

特别地 $R_1 = 14/5 = 2.8$，而 $R_6 = 1594324/531442 = 3 - 2/531442$，六位小数等于 $2.999996$。
::: proof
把 $A$ 作用 $k$ 次：$A^{k}(1,\, 0) = (3^{k}\, \mathbf{u} + \mathbf{w})/\sqrt{2}$。向量 $\mathbf{u}$ 与 $\mathbf{w}$ 标准正交，故

$$
\lVert 3^{k}\, \mathbf{u} + \mathbf{w} \rVert = \sqrt{3^{2k} + 1}.
$$

归一化后的向量因此是 $\mathbf{v} = (3^{k}\, \mathbf{u} + \mathbf{w}) / \sqrt{3^{2k} + 1}$，且

$$
A\mathbf{v} = \bigl(3^{k+1}\, \mathbf{u} + \mathbf{w}\bigr) / \sqrt{3^{2k} + 1}.
$$

两者的点积是 $(3^{2k+1} + 1)/(3^{2k} + 1)$，因为一切交叉项 $\mathbf{u}\cdot\mathbf{w}$ 都消失。$k = 1$ 时该分数是 $28/10 = 14/5$。$k = 6$ 时 $3^{12} = 531441$、$3^{13} = 1594323$，故

$$
R_6 = \frac{1594324}{531442} = 3 - \frac{2}{531442}.
$$

差 $3 - 2/531442$ 是 $2.999996236\ldots$，表格第六行就是它截到六位小数的数。
:::
:::

因子 $3^{-k}$ 就是全部速率。六步之后它等于 $1/729 \approx 1.372 \times 10^{-3}$，这就是第六个向量仍与 $(1,\, 1)/\sqrt{2}$ 在小数点后第三位有差别、而再多一步大约能再赚一个三倍的缘故。若两个本征值本是 $3$ 与 $2.9$，同一个证明会把 $1/3$ 换成 $2.9/3 \approx 0.967$，六步几乎纹丝不动。只有当一个本征值的模远远甩开其余的，幂迭代才快。

::: example 幂法一步 {#ex-power}
把 $A$ 作用到 $(1,\, 0)$ 上，归一化，计算瑞利商。
::: solution
$A(1,\, 0) = (2,\, 1)$，其长度为 $\sqrt{5} = 2.236068$。归一化向量是 $(2,\, 1)/\sqrt{5} = (0.894427,\, 0.447214)$。于是

$$
A\mathbf{v} = \frac{1}{\sqrt{5}}\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\begin{pmatrix} 2 \\ 1 \end{pmatrix} = \frac{1}{\sqrt{5}}\begin{pmatrix} 5 \\ 4 \end{pmatrix},
$$

且 $\mathbf{v}\cdot A\mathbf{v} = (2\cdot 5 + 1\cdot 4)/5 = 14/5 = 2.8$。表格第一行就是这套算术，不是什么舍入之谜。
:::
:::

## 条件 {#condition}

回到残差与误差。$2 \times 2$ 矩阵 $\begin{pmatrix} 1 & 1 \\ 1 & 1.001 \end{pmatrix}$ 可逆，其行列式为 $0.001$。方程 $A\mathbf{x} = (2,\, 2.001)$ 的解恰为 $(1,\, 1)$。把右端改小一点，改成 $(2,\, 2)$，第二个方程如今与第一个方程最多只差那个 $0.001$。解出来的是一个非常不同的 $\mathbf{x}$。

写明白些：$x + y = 2$ 与 $x + 1.001 y = 2$ 蕴含 $0.001 y = 0$，故 $y = 0$、$x = 2$。$\mathbf{b}$ 的一个元素改动 $0.001$，就让解从 $(1,\, 1)$ 移到 $(2,\, 0)$。$(2,\, 0)$ 在*原*方程组 $A\mathbf{x} = (2,\, 2.001)$ 中的残差是 $(0,\, 0.001)$，在 $\mathbf{b}$ 旁边看着微小；$\mathbf{x}$ 的误差却不然。当 $A$ 的行近乎平行时，小残差不担保小误差。

::: example 行列式只是警告，不是检验 {#ex-det}
由 [[#prop-pivots]]，本章 $3 \times 3$ 消元的矩阵行列式为 $-7$。为什么"行列式等于 $-7$"不足以判定解 $(1, 2, -1)$ 是精确的？
::: solution
行列式的大小取决于各行所用的单位。把每个方程乘 $10$，行列式乘 $10^3$，解却不会更精确。你逐元素算出的残差用的是 $\mathbf{b}$ 的单位，能与数据比较；行列式不能。用行列式来看主元乘积非零、因而唯一解存在；用残差来看你手里那个向量是不是那个解。
:::
:::

本课程里的实用规则很短。消元之后，把 $A$ 乘上算出的 $\mathbf{x}$、从 $\mathbf{b}$ 中减去。得到本征对之后，把 $A$ 乘上 $\mathbf{v}$、减去 $\lambda\mathbf{v}$。若这些向量不小，方法就还没有完工，无论教科书公式许诺过什么。若它们很小而矩阵近乎奇异，把这一点说出来，并且不要引用 $\mathbf{x}$ 的十二位数字。

::: history 高斯、勒让德与幂法
最小二乘法由阿德里安-马里·勒让德（Legendre）于 1805 年发表，载于《Nouvelles méthodes pour la détermination des orbites des comètes》。卡尔·弗里德里希·高斯（Gauss）于 1809 年在《Theoria motus corporum coelestium》中发表此法，并声称自 1795 年就已使用。优先权之争争的就是那段未发表的用法。两人都想从多于未知数个数的观测中求出轨道，那正是四个点与两个系数的情形。对线性方程组的系统性消元，早于高斯这个名字。十九世纪的天文计算贡献的习惯是：把乘数组织好，使一大批方程能算完而不丢一列。[[#alg-power]] 的幂迭代是二十世纪的求占优本征值的工具，理查德·冯·米塞斯（von Mises）在 1929 年发表了它的实用版本。对本章的 $2 \times 2$ 矩阵，特征多项式仍是更短的路线；幂迭代之所以在此，是为了让你亲眼见过本征对的残差如何缩小。
:::

::: summary
- 算出的 $A\mathbf{x} = \mathbf{b}$ 的解用残差 $\mathbf{b} - A\mathbf{x}$ 来检验；对消元例子 $(x, y, z) = (1, 2, -1)$，它是零。不换行时 $\det A$ 等于主元乘积，这里是 $-7$。
- 部分主元避免不必要的小主元。三位有效数字截尾之下，保留 $10^{-3}$ 作主元会把 $10^{-3} x + y = 1$、$x + y = 2$ 的解做成 $x = 2$，而真值是 $x = 1.001$。
- 点 $(0, 1)$、$(1, 2)$、$(2, 2)$、$(3, 4)$ 的最小二乘直线是 $y = 0.9 + 0.9x$，残差平方和为 $0.70$。
- 明明在一条直线上的点，若 $x$ 值远离原点，仍能让正规矩阵近乎奇异。减去 $x$ 的平均值，直线不变，而例中的条件数从约 $8.05 \times 10^{11}$ 降到 $1.25$。
- 对角元为 $2$、非对角元为 $1$ 的对称矩阵，本征值为 $3$ 与 $1$。从 $(1, 0)$ 出发的幂迭代逼近本征值 $3$，$k$ 步后的瑞利商是 $(3^{2k+1}+1)/(3^{2k}+1)$，六步之后是 $2.999996$。
- 当 $A$ 的行近乎平行时，小残差可以坐在 $\mathbf{x}$ 的大误差上。引用残差时要连同这个警告。
:::

## 习题

::: exercise 消去一列 {level=1}
在 $3 \times 3$ 方程组中，第一个方程是 $x + y + z = 2$，第二个是 $2x + y - z = 5$。从第二个方程减去第一个方程的两倍之后，剩下什么方程？
::: solution
$(2x + y - z) - 2(x + y + z) = 5 - 4$，故 $-y - 3z = 1$。未知数 $x$ 没了。这就是本章三角方程组的第二个方程。
:::
:::

::: exercise 完成这个三元组 {level=1 check="1"}
三角方程组包含 $7z = -7$ 与 $-y - 3z = 1$。从 $x + y + z = 2$ 求 $x$。核对值就是 $x$ 的值。
::: solution
$z = -1$。然后 $-y - 3(-1) = 1$，故 $y = 2$。然后 $x + 2 - 1 = 2$，故 $x = 1$。
:::
:::

::: exercise 截尾消元 {level=2 check="2"}
每个结果都截尾到三位有效数字，不换行。对 $10^{-3}\, x + y = 1$ 与 $x + y = 2$，消元给出 $x$ 的哪个值？截尾之前的精确值是 $1.001$（三位小数）。
::: hint
乘数是 $10^{3}$。相减之后第二个方程是 $-999\, y = -998$。回代之前把 $998/999$ 截尾到三位。
:::
::: solution
$y = 998/999 = 0.998998\ldots$ 截尾为 $0.998$。然后 $10^{-3}\, x = 1 - 0.998 = 0.002$，故 $x = 2$。同样的步骤在 [[#ex-pivot]] 中完整写出。
:::
:::

::: exercise 拟合的斜率 {level=1 check="0.9"}
$(0, 1)$、$(1, 2)$、$(2, 2)$、$(3, 4)$ 的正规方程是 $4a + 6b = 9$ 与 $6a + 14b = 18$。求 $b$。
::: hint
消去 $a$。一种做法是第一式乘 $3$、第二式乘 $2$。
:::
::: solution
$12a + 18b = 27$ 与 $12a + 28b = 36$。相减：$10b = 9$，故 $b = 0.9$。于是 $a = 0.9$ 也一样。
:::
:::

::: exercise 没射中的平方和 {level=2 check="0.7"}
用 $a = b = 0.9$，计算四个数据点处的残差平方和。
::: solution
预测值：$0.9$、$1.8$、$2.7$、$3.6$。对 $1$、$2$、$2$、$4$ 的残差：$0.1$、$0.2$、$-0.7$、$0.4$。平方：$0.01$、$0.04$、$0.49$、$0.16$。和：$0.70$。
:::
:::

::: exercise 特征多项式 {level=2}
对 $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$，计算 $\det(A - \lambda I)$ 与两个本征值。
::: solution
$A - \lambda I = \begin{pmatrix} 2-\lambda & 1 \\ 1 & 2-\lambda \end{pmatrix}$，行列式为 $(2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = (\lambda - 1)(\lambda - 3)$。本征值是 $1$ 与 $3$。
:::
:::

::: exercise 一步之后的瑞利商 {level=2 check="2.8"}
对这个 $A$ 的幂迭代从 $(1, 0)$ 出发。第一次归一化之后，瑞利商 $\mathbf{v}\cdot A\mathbf{v}$ 等于什么数？
::: solution
$A(1, 0) = (2, 1)$，归一化为 $(2, 1)/\sqrt{5}$。商为 $14/5 = 2.8$，如 [[#ex-power]] 所示。
:::
:::

::: exercise $\lambda = 1$ 的向量 {level=2}
对同一个 $A$ 求 $\lambda = 1$ 的单位本征向量，并给出其本征残差的长度。
::: solution
$(A - I)\mathbf{v} = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}\mathbf{v} = \mathbf{0}$ 迫使 $v_2 = -v_1$。单位取法是 $(1,\, -1)/\sqrt{2}$。于是 $A\mathbf{v} = 1\cdot\mathbf{v}$ 精确成立，本征残差长度为 $0$。
:::
:::

::: exercise 近乎平行的行 {level=3}
精确解方程组 $x + y = 2$ 与 $x + 1.001 y = 2$。与 $x + y = 2$ 与 $x + 1.001 y = 2.001$ 的解 $(1, 1)$ 比较。$\mathbf{b}$ 里变了什么？$\mathbf{x}$ 里变了什么？
::: solution
第一个方程组的两个方程相减：$0.001 y = 0$，故 $y = 0$、$x = 2$。第二个方程组的右端是 $(2,\, 2.001)$，解是 $(1, 1)$。$\mathbf{b}$ 的一个元素变了 $0.001$，解就从 $(1, 1)$ 移到 $(2, 0)$——长度为 $\sqrt{2}$ 的移动。矩阵是同一个。对 $(2, 0)$ 按第二个右端算出的残差不大，是 $0.001$ 量级，而 $\mathbf{x}$ 的误差不小。这就是本章关于条件的警告。
:::
:::

::: exercise 为什么正规方程是线性的 {level=3}
$S(a, b) = \sum (y_i - a - b x_i)^2$。证明 $\partial S/\partial a = 0$ 是 $a$ 与 $b$ 的线性方程，并说出作为系数出现的各个和。
::: solution
$\partial S/\partial a = -2\sum(y_i - a - b x_i) = 0$ 约去 $-2$ 并展开成 $n a + (\sum x_i) b = \sum y_i$。$a$ 的系数是点的个数，$b$ 的系数是 $\sum x_i$，右端是 $\sum y_i$。这些系数没有一个依赖 $a$ 或 $b$，所以方程是线性的。配套的那个 $\partial S/\partial b = 0$ 在和号内多带一个因子 $x_i$，就是第二个正规方程。
:::
:::

::: quiz
四个点 $(0, 1)$、$(1, 2)$、$(2, 2)$、$(3, 4)$ 用 $y = a + bx$ 按最小二乘意义拟合。哪个说法正确？
- [ ] 直线经过全部四个点，因为四个点决定一条直线。
- [ ] 不存在最好的直线，因为两个未知数满足不了四个条件。
- [x] 直线 $y = 0.9 + 0.9x$ 使竖直残差的平方和最小，该和等于 $0.70$。它不过其中任何一个点。
- [ ] 斜率是 $\sum y / \sum x = 9/6 = 1.5$，$\sum x^2$ 没有角色。
::: solution
两个未知数满足不了四个独立条件，所以直线会错过这些点。最小二乘仍由正规方程选出 $S$ 的唯一最小元；对这几个点，那个最小元是 $a = b = 0.9$，$S = 0.70$。比值 $\sum y/\sum x$ 不是斜率；斜率是 $2 \times 2$ 方程组里的第二个未知数，而 $\sum x^2 = 14$ 进入了那个方程组。
:::
:::
