运动学（[[mechanics/motion-2d]]）说明的是一个加速度是什么。它并不解释，为什么冰面上的冰球与草地在同一时刻处于同一位置的同一个冰球，稍后却有不同的加速度。区别在于与外界的相互作用。牛顿定律把这种相互作用变成一个称为**力**的向量，并且限定了在哪些参考系中力与运动的关系最简单。

三条定律各司其职。第一定律挑选参考系。第二定律在这些参考系内，把一个物体所受的合力与它的动量变化率联系起来。第三定律约束力必须成对出现，且分别作用在不同的物体上。几乎每一个后续问题，都是对某一个物体应用第二定律：图上有它受到的每一个力，而没有一个力属于别的图。

两个警告应当放在开头，因为它们正是"很有把握的错误答案"的常见来源。重力和一个表面的法向支持力可以大小相等，却仍然不是一对第三定律的力。而圆周运动的向内加速度——[[mechanics/motion-2d]] 中的 $v^{2}/R$——是由指向圆心的那些真实力共同产生的。"向心力"是它们的向内净贡献的名字，不是在它们旁边多画的一支箭头。除题目另有说明外，取 $g = 9.80\,\mathrm{m/s^{2}}$。

## 惯性系与第一定律

一条提到加速度的定律必须说明是相对什么而言。相对刹车汽车的加速度不是相对路面的加速度；一条在两个参考系中对同样的力都成立的定律，将不是牛顿所说的那条定律。

::: definition 惯性系 {#def-inertial}
**自由质点**是所受合力为零的质点。若在一个参考系中，每个自由质点都做匀速运动——沿直线以恒定速率运动，或保持静止——则称该参考系为**惯性系**。牛顿**第一定律**断言惯性系存在。定律定义了它们。
:::

第一定律不是第二定律在 $\mathbf{F} = \mathbf{0}$ 时的特例。下面使用的第二定律已经默认了惯性系。挑选这些参考系的正是第一定律。在一个相对惯性系加速的参考系中，自由质点不做匀速运动，于是同样的力不满足 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$（其中 $\mathbf{a}$ 是在该系中测得的）。本章不引入虚拟力。下面每一个 $\mathbf{F} = m\mathbf{a}$ 都写在惯性系中。

相对惯性系匀速运动的参考系本身也是惯性系。相对它加速或转动的参考系则不是。对本课程而言，地面是足够好的惯性系；地球自转引起的科里奥利偏转忽略不计。加速上升的电梯，或弯道上汽车的内部，不是惯性系。地面参考系是应用定律的参考系，电梯或汽车则是具有加速度的物体。

在这套牛顿力学的记账里，引力是一种力。因此自由下落的质点不是 [[#def-inertial]] 意义上的自由质点：相对地面它的合力就是它的重力，它在加速。固定在下落电梯上的参考系不是惯性系。在它内部，释放的物体相对电梯的加速度为零，尽管引力并没有消失。本章把重力当作一种力，把地面当作惯性系。

::: intuition 第一定律的用法
第一定律是一个检验，不是拿去代入的公式。若拿不准某个参考系，就问自由质点在它内部做什么。匀速运动意味着这个参考系可用，第二定律可以作为 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 使用。自由质点的任何其他表现，意味着这个参考系对这条方程不可用。检验在代数之前。
:::

## 动量、质量与第二定律

第二定律真正管的是动量，不是加速度。只有质量恒定时加速度才登场。

::: definition 动量与第二定律 {#def-momentum}
质量为 $m$、速度为 $\mathbf{v}$ 的质点的**动量**是

$$
\mathbf{p} = m\mathbf{v}.
$$ {#eq-momentum}

牛顿**第二定律**说，质点所受的合力等于其动量的变化率，

$$
\mathbf{F}_{\mathrm{net}} = \deriv{\mathbf{p}}{t}.
$$ {#eq-second}

若 $m$ 恒定，这就是 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$，其中 $\mathbf{a} = \deriv{\mathbf{v}}{t}$。质量 $m$ 是一个正的标量，在本课程的每个惯性系中都相同。它量度质点的惯性：对给定的合力，质量越大，加速度越小。
:::

::: proof
若 $m$ 不依赖时间，对 [[#eq-momentum]] 用乘积法则得 $\deriv{\mathbf{p}}{t} = m\,\deriv{\mathbf{v}}{t} = m\mathbf{a}$。代入 [[#eq-second]] 就是 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$。这一步靠的是 $m$ 的恒定性。它不是一个对正在增加或减少质量的物体仍然成立的恒等改写。
:::

火箭正是这一步排除在外的例子。燃气携带动量喷出，所以时刻 $t$ 的火箭本体与稍后的火箭本体不是同一堆物质。对火箭写 $\mathbf{F} = m\mathbf{a}$，或者在 $\mathbf{F} = \deriv{(m\mathbf{v})}{t}$ 中把 $\mathbf{v}$ 只取作火箭的速度，都会丢掉那份动量，得到错误的推力。[[mechanics/momentum]] 中的动量平衡把 [[#eq-second]] 用于一个组成固定的系统——喷出的燃气也包括在内。在此之前，这里的每个 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 都假定质量恒定。

力是向量。在惯性系中这条方程逐分量成立：$m$ 恒定时 $F_{\mathrm{net},x} = m a_x$、$F_{\mathrm{net},y} = m a_y$。一个分量的力只产生那个分量的加速度。这就是为什么在几何条件允许时要把坐标轴沿加速度方向选取：这样一个分量方程带着已知的加速度（常常是零），另一个分量方程则转而解出力。

::: definition 重力 {#def-weight}
一个物体的**重力**是引力作用在它上面的力。在地球附近、相对地球半径很小的运动中，这个力是

$$
\mathbf{W} = m\mathbf{g},
$$

一个大小为 $mg$、方向向下的向量，本章各题中取 $g = 9.80\,\mathrm{m/s^{2}}$。重力是一种力。质量不是力，也不是 $mg$。
:::

一个质量为 $70.0\,\mathrm{kg}$ 的人在地球附近重 $70.0\times 9.80 = 686\,\mathrm{N}$。在月球上——表面重力加速度约为 $1.62\,\mathrm{m/s^{2}}$——重力约为 $113\,\mathrm{N}$，而质量仍是 $70.0\,\mathrm{kg}$。体重秤读的是接触力，只有竖直加速度为零时它才等于重力。

力的 SI 单位是牛顿，$1\,\mathrm{N} = 1\,\mathrm{kg\,m/s^{2}}$。把一个重力写成"$5\,\mathrm{kg}$，方向向下"是把质量与力混为一谈：$5.00\,\mathrm{kg}$ 物体的重力是 $49.0\,\mathrm{N}$。

## 第三定律与受力图

力成对出现，而一对中的两个力绝不是施加在同一个物体上的。

::: definition 牛顿第三定律 {#def-third}
若物体 $A$ 对物体 $B$ 施加一个力，则 $B$ 也对 $A$ 施加一个力。这两个力大小相等、方向相反、且属于同一种类：都是引力，或都是接触力，或都是电磁力。它们作用在不同的物体上。它们是同时的。
:::

"同一种类"正是排除假配对的条件。书静止时，地球对书的引力与桌面对书的向上推力可以相等，但它们仍不是一对第三定律的力：一个是引力，另一个是接触力，而且都作用在书上。地球那一引力的配对力是书对地球的引力。法向支持力的配对力是书对桌面的接触推力。这两个配对力都不画在书的图上。

当重力与法向支持力相等时，这个相等来自第二定律。若 $a_y = 0$，那一个物体上的竖直方向的力之和为零。在电梯里这个相等不再成立，而每一对真正的第三定律力仍然保持相等。第三定律的一对力在任何情形下都匹配；重力与法向支持力只在 $a_y = 0$ 且没有其他竖直力时才匹配。

::: example 桌上的书 {#ex-book}
一本质量为 $2.00\,\mathrm{kg}$ 的书静止在水平桌面上。取 $g = 9.80\,\mathrm{m/s^{2}}$。指认书受到的力，说出每个力的第三定律配对力，并求它们的大小。
::: solution
书的受力图包含两个力，而且只有两个。

重力是地球对书的引力，大小 $2.00\times 9.80 = 19.6\,\mathrm{N}$，向下。它的第三定律配对力是书对地球的引力，$19.6\,\mathrm{N}$，向上，作用在地球上。这个配对力不画在书的图上。

法向支持力是桌面对书的接触推力，向上。书静止，所以 $a_y = 0$。取向上为正，$N - 19.6 = 0$，故 $N = 19.6\,\mathrm{N}$。它的第三定律配对力是书对桌面的接触推力，$19.6\,\mathrm{N}$，向下，作用在桌面上。这个配对力也不画在书的图上。

重力与法向支持力相等，是因为加速度为零，而不是因为 [[#def-third]] 把它们配成一对。它们通不过"同一种类"的检验，而且作用在同一个物体上。若桌面是一部有非零竖直加速度的电梯的地板，$N$ 会变而重力不会。第三定律配对力的种类不变：地球与书，通过引力；书与桌面，通过接触。
:::
:::

画图是决定代数有没有机会的那一步。这些规则短得可以写成一条流程。

::: algorithm 受力图 {#alg-fbd}
隔离一个物体，只画它。画出别的物体施加在它**上面**的每一个力，并标明每个力的施力者。不要画这个物体施加在其他物体上的力，也不要画同一对第三定律力的两个成员。选择坐标轴，最好沿加速度方向。写出 $\sum F_x = m a_x$ 与 $\sum F_y = m a_y$，其中 $m$ 恒定。左边只包含图上那些力。加速度不是力，也不按力来画。若两个物体用一根轻而不可伸长的绳连接，绳长不变这个约束会把它们的加速度联系起来；它不是一个额外的力。
:::

轻绳还有一个推论。一段质量为零的绳不可能有非零的合力，否则它的加速度将是无穷大。因此张力在绳的两端同样地拉。经过一个无摩擦、转动惯量可忽略的滑轮，两侧的张力相同。有质量的滑轮不服从这个结论；那时两侧张力不同，那是 [[mechanics/rotation]] 的问题。

- [x] 重力与法向支持力相等是因为加速度为零，它们不是第三定律的一对。
- [ ] 无论桌子怎样运动，书受到的法向支持力都是 $mg$。
- [ ] 书的受力图应当同时画出地球对书的引力和书对地球的引力。
::: solution

:::

## 摩擦、阿特伍德机与斜面

一个表面可以施加垂直于自身的**法向支持力**和平行于自身的摩擦力。法向支持力的大小由垂直方向的第二定律决定。它只在物体静止于水平面、且没有其他竖直力时等于 $mg$；在斜面上、在电梯里、抵着墙时都不等于 $mg$。

::: definition 干摩擦 {#def-friction}
两个固体表面之间的干摩擦有两种状态。**静摩擦力**在两表面互不滑动时起作用。它的大小是在不超过某个上限的前提下阻止滑动所需的任何值：

$$
\abs{f_{\mathrm{s}}} \le \mu_{\mathrm{s}} N,
$$

方向与即将发生的滑动相反。**动摩擦力**在两表面滑动时起作用。它的大小是 $\mu_{\mathrm{k}} N$，方向阻碍两表面的相对运动。两种情形下 $N$ 都是法向支持力，不是 $mg$ 的别名。系数 $\mu_{\mathrm{s}}$ 与 $\mu_{\mathrm{k}}$ 无量纲，且通常 $\mu_{\mathrm{k}} \le \mu_{\mathrm{s}}$。
:::

静摩擦力不是 $N$ 的固定比例。这个不等式是一个上限：一本书静止在水平桌面上、侧向没有任何推力时，$f_{\mathrm{s}} = 0$。只有到了将要滑动的临界点，$\abs{f_{\mathrm{s}}}$ 才达到 $\mu_{\mathrm{s}} N$。只要滑动继续，动摩擦力就有确定的大小 $\mu_{\mathrm{k}} N$。对一个已知贴着不动的物体使用 $\mu_{\mathrm{s}} N$，是斜面上最常见的数值错误。

::: theorem 阿特伍德机 {#thm-atwood}
两个质量 $m_1$ 与 $m_2$（$m_2 > m_1$）用一根轻而不可伸长的绳连接，绳跨过无摩擦、转动惯量可忽略的滑轮。质量恒定，参考系是惯性系。则 $m_2$ 下降、$m_1$ 上升，加速度大小为

$$
a = \frac{(m_2 - m_1)\, g}{m_1 + m_2},
$$ {#eq-atwood-a}

而张力在整根绳中相同，

$$
T = \frac{2 m_1 m_2 g}{m_1 + m_2}.
$$ {#eq-atwood-t}
:::

::: proof
绳长固定，所以两个质量的加速度大小相等。对 $m_2$ 取向下为正方向，对 $m_1$ 取向上为正方向，使正的 $a$ 表示 $m_2$ 下降。每个质量各自是一个受力问题。

$m_2$ 受到的力是向下的重力 $m_2 g$ 与向上的张力 $T$，所以 $m_2 g - T = m_2 a$。$m_1$ 一侧张力向上、重力向下，所以 $T - m_1 g = m_1 a$。两个方程中的张力相同，因为绳是轻的、滑轮无摩擦，这正是 [[#alg-fbd]] 所要求的。

把两个方程相加。张力消去：

$$
(m_2 - m_1)\, g = (m_1 + m_2)\, a, \qquad a = \frac{(m_2 - m_1)\, g}{m_1 + m_2}.
$$

这就是 [[#eq-atwood-a]]。回代到 $m_1$ 的方程：

$$
T = m_1 g + m_1 a = m_1 g\left(1 + \frac{m_2 - m_1}{m_1 + m_2}\right) = m_1 g\cdot\frac{2 m_2}{m_1 + m_2} = \frac{2 m_1 m_2 g}{m_1 + m_2}.
$$

$m_2$ 的方程给出同样的张力：$T = m_2(g - a) = 2 m_1 m_2 g/(m_1 + m_2)$。若 $m_1 = m_2$，则 $a = 0$ 且 $T = m_1 g$，这正是两个等质量物体悬挂静止的情形。假设条件是本质性的。有质量的滑轮会使两侧张力不同，可伸长的绳会使两个加速度不同。
:::

::: example 两千克与三千克的质量 {#ex-atwood}
取 $m_1 = 2.00\,\mathrm{kg}$、$m_2 = 3.00\,\mathrm{kg}$、$g = 9.80\,\mathrm{m/s^{2}}$，并采用 [[#thm-atwood]] 的理想化条件。求加速度与张力，并分别对每个质量进行校验。
::: solution
[[#eq-atwood-a]] 与 [[#eq-atwood-t]] 给出

$$
a = \frac{(3.00 - 2.00)\times 9.80}{2.00 + 3.00} = \frac{9.80}{5.00} = 1.960\,\mathrm{m/s^{2}},
$$

$$
T = \frac{2\times 2.00\times 3.00\times 9.80}{5.00} = \frac{117.6}{5.00} = 23.52\,\mathrm{N}.
$$

质量较大的下降。单独校验 $m_2$。它的重力是 $3.00\times 9.80 = 29.40\,\mathrm{N}$，所以向下的合力是 $29.40 - 23.52 = 5.88\,\mathrm{N}$，而 $m_2 a = 3.00\times 1.960 = 5.88\,\mathrm{N}$。校验 $m_1$。向上的合力是 $23.52 - 2.00\times 9.80 = 23.52 - 19.60 = 3.92\,\mathrm{N}$，而 $m_1 a = 2.00\times 1.960 = 3.92\,\mathrm{N}$。每张受力图都在同一个 $a$ 和同一个 $T$ 下满足第二定律。若两个校验互相矛盾，错处就在产生 $a$ 与 $T$ 的代数里，而不在"应当校验"这个想法里。
:::
:::

::: application 阿特伍德为什么造这台机器
乔治·阿特伍德（George Atwood）在《论物体的直线运动与旋转》（*A Treatise on the Rectilinear Motion and Rotation of Bodies*，1784）中用这一装置测量 $g$：加速度足够小，便于计时。由 [[#eq-atwood-a]]，测得的 $a$ 给出 $g = (m_1 + m_2)a/(m_2 - m_1)$，前提是绳轻而滑轮消耗的力矩可忽略。
:::

斜面就是坐标轴旋转后的同一条第二定律。对重力分量最有用的检验是水平极限。$\theta = 0$ 时表面水平，所以重力沿斜面向下的分量必须为零，法向支持力必须是 $mg$。分量 $mg\sin\theta$ 沿斜面向下、$mg\cos\theta$ 压向斜面，能通过这个检验，因为 $\sin 0 = 0$、$\cos 0 = 1$。把两个分量弄反就通不过。

::: proposition 粗糙斜面上的滑块 {#prop-incline}
质量为常数 $m$ 的滑块保持在与水平面成 $\theta$ 角的直斜面上。取 $x$ 沿斜面向下、$y$ 沿外法线方向。法向支持力为 $N = mg\cos\theta$。

若滑块静止，静摩擦力沿斜面向上，大小为 $f_{\mathrm{s}} = mg\sin\theta$，而这只有在 $\tan\theta \le \mu_{\mathrm{s}}$ 时才可能。此时滑块贴着不动。数值 $\mu_{\mathrm{s}} N$ 是摩擦力的可用上限，不是实际作用的摩擦力。

若滑块沿斜面向下滑动，动摩擦力沿斜面向上，大小为 $\mu_{\mathrm{k}} N$，沿斜面向下的加速度为

$$
a = g\,(\sin\theta - \mu_{\mathrm{k}}\cos\theta).
$$ {#eq-incline}

若滑块改为沿斜面向上滑动，动摩擦力反向，沿斜面向下的加速度为 $g\,(\sin\theta + \mu_{\mathrm{k}}\cos\theta)$。
:::

::: proof
只要滑块留在表面上，垂直于斜面的加速度就是零，所以 $\sum F_y = 0$。外法线方向是 $N$，重力向内贡献 $mg\cos\theta$——这由上面 $\theta = 0$ 的检验确定。于是 $N - mg\cos\theta = 0$，即 $N = mg\cos\theta$。除 $\theta = 0$ 外，它不是 $mg$。

若滑块静止，则同样有 $\sum F_x = 0$。沿斜面向下的方向，$mg\sin\theta - f_{\mathrm{s}} = 0$，所以 $f_{\mathrm{s}} = mg\sin\theta$，方向沿斜面向上，以阻止即将发生的滑动。[[#def-friction]] 只有在 $mg\sin\theta \le \mu_{\mathrm{s}} N = \mu_{\mathrm{s}} mg\cos\theta$ 时才允许这一点。当 $\cos\theta > 0$ 时，这就是 $\tan\theta \le \mu_{\mathrm{s}}$。当不等式成立且滑块被放置为静止时，它贴着不动，动摩擦系数根本用不上。

若滑块向下滑，则沿斜面向上有 $f_{\mathrm{k}} = \mu_{\mathrm{k}} N$，且

$$
mg\sin\theta - \mu_{\mathrm{k}} mg\cos\theta = m a, \qquad a = g\,(\sin\theta - \mu_{\mathrm{k}}\cos\theta).
$$

质量消去。若滑块沿斜面向上滑，摩擦反向、指向斜面下方，这就是上面那条命题的最后一句话。动摩擦公式假定滑块仍在滑动。一旦它停下，静摩擦接手。由于 $\mu_{\mathrm{k}} \le \mu_{\mathrm{s}}$，一个陡到 $\tan\theta > \mu_{\mathrm{s}}$ 的斜面不可能使滑块静止，而已经在向下滑的滑块会持续加速。
:::

::: example 贴住还是滑动 {#ex-incline}
一个滑块放在 $30^{\circ}$ 的斜面上。取 $g = 9.80\,\mathrm{m/s^{2}}$。先设它已经在向下滑动，$\mu_{\mathrm{k}} = 0.200$，求加速度。再改设它被放置为静止且 $\mu_{\mathrm{s}} = 0.70$：它贴住吗？对质量为 $2.00\,\mathrm{kg}$ 的滑块，在两种情形下分别求法向支持力与摩擦力。
::: solution
用 [[#prop-incline]]。滑块向下滑动期间，

$$
a = 9.80\,\bigl(\sin 30^{\circ} - 0.200\cos 30^{\circ}\bigr) = 9.80\,\bigl(0.500 - 0.200\times 0.8660\bigr) = 9.80\times 0.3268 = 3.203\,\mathrm{m/s^{2}},
$$

沿斜面向下。对 $m = 2.00\,\mathrm{kg}$，

$$
N = mg\cos 30^{\circ} = 9.80\sqrt{3} = 16.97\,\mathrm{N}, \qquad f_{\mathrm{k}} = 0.200\times 9.80\sqrt{3} = 3.395\,\mathrm{N}
$$

沿斜面向上。沿斜面向下的合力是 $mg\sin 30^{\circ} - f_{\mathrm{k}} = 9.80 - 3.395 = 6.405\,\mathrm{N}$，而 $6.405/2.00 = 3.203\,\mathrm{m/s^{2}}$，与公式一致。法向支持力不是 $mg = 19.6\,\mathrm{N}$。

放置为静止时，滑块在 $\tan\theta \le \mu_{\mathrm{s}}$ 时贴住。这里 $\tan 30^{\circ} = 1/\sqrt{3} = 0.577$，而 $0.577 < 0.70$，所以它贴住。在有什么东西使滑块动起来之前，动摩擦毫不相干。实际作用的静摩擦力是 $f_{\mathrm{s}} = mg\sin 30^{\circ} = 9.80\,\mathrm{N}$，沿斜面向上，而不是 $\mu_{\mathrm{s}} N$。可用上限是 $\mu_{\mathrm{s}} N = 0.70\times 16.97 = 11.88\,\mathrm{N}$，而 $9.80\,\mathrm{N}$ 在这个上限之内——这与比较 $\tan 30^{\circ} \le 0.70$ 是同一件事。若后来滑块被推着滑动，动摩擦的计算卷土重来，而 $\mu_{\mathrm{s}}$ 从加速度中消失。
:::
:::

::: widget incline
angle: 30
mu: 0.2
caption: 把倾角调大到滑块开始滑动，并将 μ 与 tan θ 比较。在 30°、这个 μ 之下滑块已经在滑动，所以先把倾角调小到它贴住，再调大并观察这一转变：只有当 tan θ 不超过 μ 时它才贴住。
:::

这个 widget 对贴住检验和滑动加速度使用同一个系数。比较 $\mu$ 与 $\tan\theta$：只有当 $\tan\theta$ 不超过 $\mu$ 时滑块才贴住，而在那个状态中 $\mu N$ 并不是实际作用的摩擦力。

::: example 电梯中的视重 {#ex-lift}
一个质量为 $70.0\,\mathrm{kg}$ 的人站在电梯里的体重秤上。取 $g = 9.80\,\mathrm{m/s^{2}}$，取向上为正。求电梯以 $2.00\,\mathrm{m/s^{2}}$ 向上加速、以 $2.00\,\mathrm{m/s^{2}}$ 向下加速，以及缆绳断裂、电梯自由下落时秤的读数。
::: solution
秤读的是法向支持力，即地板对人的接触力。人受到的力是向上的 $N$ 和向下的重力 $mg$。重力在整个题目的每一部分都是 $70.0\times 9.80 = 686\,\mathrm{N}$；质量不变，$g$ 也不变。在地面的惯性系中写第二定律，

$$
N - mg = m a, \qquad N = m(g + a),
$$

其中 $a$ 向上为正。

向上加速 $a = +2.00\,\mathrm{m/s^{2}}$ 给出 $N = 70.0\times(9.80 + 2.00) = 70.0\times 11.80 = 826\,\mathrm{N}$。向下加速 $a = -2.00\,\mathrm{m/s^{2}}$ 给出 $N = 70.0\times(9.80 - 2.00) = 70.0\times 7.80 = 546\,\mathrm{N}$。自由下落是 $a = -g$，于是 $N = 0$：秤读数为零。这不是因为重力消失了，而是因为人和电梯一起加速，不再需要接触力。三个读数是同一个重力对应的三个不同的法向支持力。它们是"$N$ 与 $mg$ 并没有被第三定律粘在一起"这一说法的具体形式。
:::
:::

## 水平面内的圆周运动

匀速圆周运动有指向圆心、大小为 $v^{2}/R$ 的加速度。那个结果是运动学，在 [[mechanics/motion-2d]] 中证明过。牛顿第二定律把它变成对力的要求：在惯性系中，指向圆心的合力大小为 $m v^{2}/R$。**向心力**这个说法指的就是这个向内的合力。它是一个名字，不是新的施力者，也不在实际作用的力之外多画出来。

::: proposition 水平路面转弯 {#prop-curve}
质量为常数 $m$ 的车辆以恒定速率 $v$ 驶过半径为 $R$ 的水平弯道，参考系是固定在地面上的惯性系。竖直加速度为零，所以 $N = mg$。水平加速度大小为 $v^{2}/R$、指向圆心，而在水平路面上唯一的水平力是轮胎处的静摩擦力——轮胎没有侧向滑动。因此

$$
f_{\mathrm{s}} = \frac{m v^{2}}{R}, \qquad \mu_{\mathrm{s}} \ge \frac{v^{2}}{R g}.
$$ {#eq-mu-min}

最小系数是 $v^{2}/(R g)$。若轮胎正在侧滑，摩擦是动摩擦，轨迹不再是预定的圆，上面的命题就不再描述这一运动。
:::

::: proof
竖直平衡（没有其他竖直力）是 $N - mg = 0$。水平方向上，[[mechanics/motion-2d]] 给出沿半径 $R$ 的圆以恒定速率运动所需的向内加速度 $v^{2}/R$。因此地面参考系中的第二定律要求向内的合力 $m v^{2}/R$。

在水平路面上，重力与法向支持力是竖直的。剩下的水平力是摩擦。它是静摩擦：轮胎在滚动，接触斑没有在路面上滑过。静摩擦可以指向圆心，而且会指向圆心，直到它的上限 $\mu_{\mathrm{s}} N = \mu_{\mathrm{s}} mg$。当所需的摩擦不超过这个上限时，运动才可能：

$$
\frac{m v^{2}}{R} \le \mu_{\mathrm{s}} m g, \qquad \mu_{\mathrm{s}} \ge \frac{v^{2}}{R g}.
$$

受力图上没有任何东西标作"向心力"——除非那是对 $f_{\mathrm{s}}$ 本身的描述。再加一支向内的箭头就会把同一个要求数两遍，并且凭空造出一个不属于任何物体的施力者。
:::

::: example 水平弯道上的汽车 {#ex-car}
一辆质量为 $1000\,\mathrm{kg}$ 的汽车以 $20.0\,\mathrm{m/s}$ 驶过半径 $50.0\,\mathrm{m}$ 的水平弯道。取 $g = 9.80\,\mathrm{m/s^{2}}$。求所需的向内力，以及能够提供它的最小静摩擦系数。若改为 $\mu_{\mathrm{s}} = 0.70$，求汽车能够驶过弯道的最大速率。
::: solution
所需的向内力就是 [[#prop-curve]] 中的合力，

$$
\frac{m v^{2}}{R} = \frac{1000\times 20.0^{2}}{50.0} = \frac{1000\times 400}{50.0} = 8000\,\mathrm{N},
$$

由指向圆心的静摩擦力提供。法向支持力是 $N = mg = 1000\times 9.80 = 9800\,\mathrm{N}$。最小系数是

$$
\mu_{\mathrm{s,min}} = \frac{v^{2}}{R g} = \frac{400}{50.0\times 9.80} = \frac{400}{490} = 0.816,
$$

它也就是 $8000/9800 = 0.816$。没有额外的向心箭头：这 $8000\,\mathrm{N}$ **就是**摩擦。

若 $\mu_{\mathrm{s}} = 0.70$，则 $20.0\,\mathrm{m/s}$ 太快。最大速率满足 $v^{2} = \mu_{\mathrm{s}} R g$：

$$
v = \sqrt{0.70\times 50.0\times 9.80} = \sqrt{343} = 18.52\,\mathrm{m/s}.
$$

超过这个速率汽车就会侧滑。在地面参考系中没有任何东西把它向外推：它只是没有产生弯道所要求的那么大的向内加速度。
:::
:::

::: warning 两支不该出现的箭头
不要把同一对第三定律力的两个成员画在同一张受力图上。配对力作用在另一个物体上；画进来要么抵消一个真实的力，要么添加一个物体并没有受到的力。不要在实际作用的力旁边多画一支向心力箭头。在水平弯道上，向内的力就是图上已有的静摩擦。第二支向内箭头没有施力者。同一个习惯还表现为地面参考系中向外的"离心力"。地面是惯性系，所以没有这样的力。向外的感觉属于汽车的（非惯性）参考系，而 [[#def-inertial]] 已经把它排除在 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 之外。
:::

::: quiz
一辆汽车以恒定速率驶过水平弯道。关于受力图的哪种描述是对的？
- [ ] 在摩擦、重力、法向支持力之外，再画一支指向圆心的向心力箭头。
- [ ] 动摩擦向外，背离圆心。
- [x] 静摩擦指向圆心。"向心力"说的就是这个向内的贡献，它不是多出来的一支箭头。
- [ ] 法向支持力是水平的，指向圆心。
::: solution
向内的力是静摩擦，因为轮胎没有侧向滑动。法向支持力是竖直的。多画一支向心箭头会把摩擦数两遍，而动摩擦描述的是侧滑，不是这里的运动。
:::
:::

::: history 《自然哲学的数学原理》，以及 F = ma 的形式
牛顿（Newton）的《自然哲学的数学原理》（*Philosophiae Naturalis Principia Mathematica*，1687）提出了三条运动定律与万有引力的平方反比定律。他把第二定律表述为力与"运动的变化"之间的正比关系，而那里的"运动"就是动量，即 [[#def-momentum]] 采用的读法。$\mathbf{F} = m\mathbf{a}$ 的形式是后来的澄清：欧拉（Euler）在 1750 年发表了这种形式的分量方程。本章在质量恒定时使用 $\mathbf{F} = m\mathbf{a}$。平方反比定律是 [[mechanics/gravitation]] 的主题。
:::

## 后续内容

[[mechanics/motion-2d]] 中的那些加速度现在有了原因：重力给出 $a_y = -g$，指向圆心的合力 $m v^{2}/R$ 给出圆周运动。[[mechanics/work-energy]] 把 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 沿路径积分。[[mechanics/momentum]] 把它对时间积分——碰撞，以及被 $\mathbf{F} = m\mathbf{a}$ 拒之门外的火箭，都在那里处理。[[mechanics/rotation]] 对有大小的物体重复同一套路，而具有转动惯量的滑轮两侧张力不再相等。

与位移成正比的回复力，令它等于 $ma$，就是 [[oscillations]] 中的振动方程。在写下那条方程之前，第一定律仍然负责决定参考系。

::: summary
- 惯性系是自由质点在其内做匀速运动的参考系。第一定律断言这样的参考系存在，而 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$ 只在它们内部使用。
- 动量是 $\mathbf{p} = m\mathbf{v}$，合力等于 $\deriv{\mathbf{p}}{t}$。质量恒定时得到 $\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$。火箭不属于这一情形；见 [[mechanics/momentum]]。
- 质量不是重力。在地球附近，重力是大小为 $mg$、方向向下的力。
- 第三定律的一对力大小相等、方向相反、种类相同，且作用在不同物体上。重力与法向支持力不是第三定律的一对。
- 受力图上画一个物体和它受到的每一个力。法向支持力不总是 $mg$，而 $\abs{f_{\mathrm{s}}} = \mu_{\mathrm{s}} N$ 只在将要滑动的临界点成立。
- 理想阿特伍德机有 $a = (m_2 - m_1)g/(m_1 + m_2)$ 和 $T = 2 m_1 m_2 g/(m_1 + m_2)$。
- 在粗糙斜面上被放置为静止的滑块，当 $\tan\theta \le \mu_{\mathrm{s}}$ 时贴住。向下滑动时 $a = g(\sin\theta - \mu_{\mathrm{k}}\cos\theta)$，且 $N = mg\cos\theta$。
- 水平弯道上向内的力是大小为 $m v^{2}/R$ 的静摩擦，所以 $\mu_{\mathrm{s}} \ge v^{2}/(Rg)$。向心力是这个合力的名字，不是多出来的一支箭头。
:::

## 习题

::: exercise 五千克的重力 {#exr-weight level=1 check="49"}
求地球附近质量 $5.00\,\mathrm{kg}$ 的物体的重力，以牛顿计。取 $g = 9.80\,\mathrm{m/s^{2}}$。
::: solution
重力是 $mg$，不是 $m$。方向向下已约定在内，

$$
W = 5.00\times 9.80 = 49.0\,\mathrm{N}.
$$

质量在每个参考系、每颗行星上都是 $5.00\,\mathrm{kg}$。重力是一种力，而这个数值用的是地球表面的重力加速度。答案是 $49.0\,\mathrm{N}$。
:::
:::

::: exercise 合力的大小 {#exr-net level=1 check="6"}
质量 $3.00\,\mathrm{kg}$ 的质点在惯性系中具有大小 $2.00\,\mathrm{m/s^{2}}$ 的加速度。质量恒定。求它所受合力的大小，以牛顿计。
::: solution
由 [[#def-momentum]]，因为 $m$ 恒定，$\mathbf{F}_{\mathrm{net}} = m\mathbf{a}$。于是大小满足

$$
\abs{\mathbf{F}_{\mathrm{net}}} = m\abs{\mathbf{a}} = 3.00\times 2.00 = 6.00\,\mathrm{N}.
$$

合力的方向就是加速度的方向。题目没有问方向。答案是 $6.00\,\mathrm{N}$。
:::
:::

::: exercise 水平桌面上的法向支持力 {#exr-normal level=1 check="78.4"}
质量 $8.00\,\mathrm{kg}$ 的滑块静止在水平桌面上，没有其他竖直方向的力。取 $g = 9.80\,\mathrm{m/s^{2}}$。求桌面对滑块的法向支持力，以牛顿计。
::: solution
竖直加速度为零，所以竖直方向的第二定律说法向支持力与重力平衡：

$$
N = mg = 8.00\times 9.80 = 78.4\,\mathrm{N},
$$

方向向上。这个相等来自 $a_y = 0$，不是第三定律。$N$ 的第三定律配对力是滑块对桌面向下的推力，它不是滑块受到的力。答案是 $78.4\,\mathrm{N}$。
:::
:::

::: exercise 阿特伍德机的加速度 {#exr-atwood level=2 check="4.9"}
理想阿特伍德机（[[#thm-atwood]] 的意义下）两质量 $m_1 = 1.00\,\mathrm{kg}$、$m_2 = 3.00\,\mathrm{kg}$。取 $g = 9.80\,\mathrm{m/s^{2}}$。求加速度的大小，以 $\mathrm{m/s^{2}}$ 计。
::: solution
质量较大的下降。[[#eq-atwood-a]] 给出

$$
a = \frac{(3.00 - 1.00)\times 9.80}{1.00 + 3.00} = \frac{2.00\times 9.80}{4.00} = \frac{19.6}{4.00} = 4.90\,\mathrm{m/s^{2}}.
$$

所问的加速度是 $4.90\,\mathrm{m/s^{2}}$，质量较大的一侧下降。
:::
:::

::: exercise 斜面上的最小静摩擦系数 {#exr-mus level=2 check="1/sqrt(3)"}
一个滑块被放置于 $30^{\circ}$ 斜面上保持静止。求使滑块保持静止的最小静摩擦系数。答案是一个纯数。
::: hint
当 $\tan\theta \le \mu_{\mathrm{s}}$ 时滑块贴住。最小系数就是这个角的正切。
:::
::: solution
由 [[#prop-incline]]，当 $\tan\theta \le \mu_{\mathrm{s}}$ 时静止是可能的，不等式不成立时静止不可能。因此仍能"抓住"滑块的最小系数是

$$
\mu_{\mathrm{s}} = \tan 30^{\circ} = \frac{1}{\sqrt{3}}.
$$

把沿斜面向下的分量 $mg\sin\theta$ 与最大摩擦 $\mu_{\mathrm{s}} mg\cos\theta$ 比较时，质量和 $g$ 都消去。动摩擦不会出现，因为滑块静止。恰在这个数值上滑块处于将要滑动的临界点，且 $f_{\mathrm{s}} = \mu_{\mathrm{s}} N$。系数再小一点它就会滑动。答案是 $1/\sqrt{3}$。
:::
:::

::: exercise 水平弯道的向内力 {#exr-bend level=2 check="4000"}
一辆质量为 $800\,\mathrm{kg}$ 的车以恒定速率 $10.0\,\mathrm{m/s}$ 驶过半径 $20.0\,\mathrm{m}$ 的水平弯道。求所需的向内力的大小，以牛顿计。
::: solution
运动就是 [[#prop-curve]] 中的水平转弯。向内力的大小为

$$
\frac{m v^{2}}{R} = \frac{800\times 10.0^{2}}{20.0} = \frac{800\times 100}{20.0} = 4000\,\mathrm{N},
$$

由指向圆心的静摩擦提供。所求的力是 $4000\,\mathrm{N}$。
:::
:::

::: exercise 电梯中秤的读数 {#exr-lift level=2 check="580"}
一个质量为 $50.0\,\mathrm{kg}$ 的人站在电梯里的体重秤上，电梯以 $1.80\,\mathrm{m/s^{2}}$ 向上加速。取 $g = 9.80\,\mathrm{m/s^{2}}$，向上为正。求秤的读数，以牛顿计。
::: solution
秤读的是人受到的法向支持力。向上为正，$N - mg = ma$，所以

$$
N = m(g + a) = 50.0\times(9.80 + 1.80) = 50.0\times 11.60 = 580\,\mathrm{N}.
$$

重力是 $50.0\times 9.80 = 490\,\mathrm{N}$，那不是读数。多出的 $90\,\mathrm{N}$ 是 $ma$，由向上的加速度所要求。答案是 $580\,\mathrm{N}$。
:::
:::

::: exercise 桌面上的滑块与悬挂的物体 {#exr-hang level=3 check="2.45"}
质量 $3.00\,\mathrm{kg}$ 的滑块在水平桌面上滑动。动摩擦系数为 $0.250$。一根轻绳从滑块水平地连到桌边的无摩擦轻滑轮，再竖直向下连到悬挂的 $2.00\,\mathrm{kg}$ 质量。悬挂的物体在下降。取 $g = 9.80\,\mathrm{m/s^{2}}$。求加速度的大小，以 $\mathrm{m/s^{2}}$ 计。
::: hint
画两张受力图。桌面上的动摩擦是 $\mu_{\mathrm{k}}$ 乘以法向支持力，而水平桌面上的法向支持力就是滑动滑块的重力。绳把两个加速度约束为大小相同。
:::
::: solution
桌面滑块的 $N = m_{\mathrm{t}} g = 3.00\times 9.80 = 29.4\,\mathrm{N}$，因为竖直加速度为零而绳水平地拉。动摩擦阻碍朝向滑轮的运动：

$$
f_{\mathrm{k}} = 0.250\times 29.4 = 7.35\,\mathrm{N}.
$$

取正方向为悬挂物体下降的方向、桌面滑块朝向滑轮运动的方向。绳轻而滑轮无摩擦，所以张力 $T$ 在两个方程中相同。对悬挂物体，$m_{\mathrm{h}} g - T = m_{\mathrm{h}} a$。对桌面滑块，$T - f_{\mathrm{k}} = m_{\mathrm{t}} a$。相加：

$$
m_{\mathrm{h}} g - f_{\mathrm{k}} = (m_{\mathrm{h}} + m_{\mathrm{t}})\, a,
$$

$$
a = \frac{2.00\times 9.80 - 7.35}{2.00 + 3.00} = \frac{19.60 - 7.35}{5.00} = \frac{12.25}{5.00} = 2.45\,\mathrm{m/s^{2}}.
$$

校验：$T = 3.00\times 2.45 + 7.35 = 14.70\,\mathrm{N}$。悬挂物体的合力于是为 $19.60 - 14.70 = 4.90\,\mathrm{N}$，等于 $m_{\mathrm{h}} a$；桌面滑块的合力为 $7.35\,\mathrm{N}$，等于 $m_{\mathrm{t}} a$。加速度为 $2.45\,\mathrm{m/s^{2}}$。
:::
:::

::: exercise 无摩擦的倾斜弯道 {#exr-bank level=3 check="45"}
一辆车以恒定速率 $v$ 驶过半径为 $R$ 的圆形弯道，路面与水平面成 $\theta$ 角倾斜。没有摩擦。证明 $\tan\theta = v^{2}/(R g)$。再设速率与半径满足 $v^{2} = R g$，求车辆无需摩擦提供侧向力即可驶过弯道的倾斜角，以度计。
::: hint
法向支持力垂直于路面。它的竖直分量与重力平衡，水平分量就是向内的力 $m v^{2}/R$。把两个分量方程相除。
:::
::: solution
没有摩擦，所以车受到的力是重力和垂直于路面的法向支持力 $N$。把 $N$ 分解为竖直分量 $N\cos\theta$ 和指向弯道圆心的水平分量 $N\sin\theta$。竖直加速度为零：

$$
N\cos\theta = mg.
$$

水平加速度是 $v^{2}/R$、指向圆心——由匀速圆周运动的运动学——所以第二定律写作

$$
N\sin\theta = \frac{m v^{2}}{R}.
$$

第二个方程除以第一个。质量和法向支持力消去：

$$
\tan\theta = \frac{v^{2}}{R g}.
$$

路面无摩擦，车在水平面内做圆周运动。若 $v^{2} = R g$，则 $\tan\theta = 1$，故 $\theta = 45^{\circ}$。角度为 $45$ 度。
:::
:::
