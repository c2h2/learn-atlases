短跑运动员腿部肌肉、一缸葡萄汁里的酵母细胞和一个红细胞，共用着同一条途径：**糖酵解**的十个反应把一个葡萄糖分子拆成两个丙酮酸分子，并在不需要任何氧气的情况下赚到一小笔又快又稳的 ATP。在线粒体和氧气齐备的细胞里，丙酮酸随后被彻底拆解：它的碳以二氧化碳的形式离开，进入**柠檬酸循环**；它的电子则装载到 NAD⁺ 与 FAD 上，送往[[biochemistry/oxidative-phosphorylation]]的呼吸链。这两条途径合起来就是分解代谢的树干：糖、脂肪与蛋白质都汇入其中，它们产生的中间产物又是生物合成的原料。

本章讲的是这些途径的化学与逻辑，而不是名词的背诵。每一步都是你在有机化学里熟悉的反应类型——磷酰基转移、经烯二醇的醛糖-酮糖异构化、逆羟醛裂解、经硫酯的醛氧化、脱水、氧化脱羧。每一步在自由能地图上也都各有位置，而这张地图决定了哪些步骤可以被调控、哪些步骤只能随浓度摆动。所用的工具是[[biochemistry/bioenergetics]]的工具——$\Delta_\mathrm{r}G' = \Delta_\mathrm{r}G^{\circ\prime} + RT\ln Q'$（[[biochemistry/bioenergetics#prop-actual-dg]]）、经共享中间产物的偶联（[[biochemistry/bioenergetics#prop-coupling]]）以及还原电势——再加上[[biochemistry/enzymes]]与[[biochemistry/protein-function]]的酶动力学与别构理论。标准自由能取 pH 7、$298\ \mathrm{K}$ 下的生化值：糖酵解取自 Berg、Tymoczko、Gatto 与 Stryer（第 9 版），柠檬酸循环取自 Nelson 与 Cox（第 8 版）；不同书的表格相差几个 $\mathrm{kJ\,mol^{-1}}$，因为它们所指的条件略有差别。本课仅供教学之用。

## 糖酵解：十个反应

糖酵解发生在每一种细胞的细胞质溶胶中。它分为两个阶段。在**准备阶段**（第 1–5 步），细胞*花费*两个 ATP，把葡萄糖磷酸化两次，并把它拆成两个可以互变的三碳磷酸糖。在**放能阶段**（第 6–10 步，每个葡萄糖运行两轮），每个三碳单元都被 NAD⁺ 氧化，其磷酰基交给 ADP，生成四个 ATP。

| 步骤 | 酶 | 反应 | $\Delta_\mathrm{r}G^{\circ\prime}$ | $\Delta_\mathrm{r}G'$（红细胞） |
|---|---|---|---|---|
| 1 | 己糖激酶 | 葡萄糖 + ATP → 6-磷酸葡萄糖 + ADP | $-16.7$ | $-33.5$ |
| 2 | 磷酸葡萄糖异构酶 | 6-磷酸葡萄糖 ⇌ 6-磷酸果糖 | $+1.7$ | $-2.5$ |
| 3 | 磷酸果糖激酶（PFK） | 6-磷酸果糖 + ATP → 1,6-二磷酸果糖 + ADP | $-14.2$ | $-22.2$ |
| 4 | 醛缩酶 | 1,6-二磷酸果糖 ⇌ 磷酸二羟丙酮 + 3-磷酸甘油醛 | $+23.8$ | $-1.3$ |
| 5 | 磷酸丙糖异构酶 | 磷酸二羟丙酮 ⇌ 3-磷酸甘油醛 | $+7.5$ | $+2.5$ |
| 6 | 3-磷酸甘油醛脱氢酶 | GAP + $\mathrm{P_i}$ + $\mathrm{NAD^+}$ ⇌ 1,3-二磷酸甘油酸 + NADH + $\mathrm{H^+}$ | $+6.3$ | $-1.7$ |
| 7 | 磷酸甘油酸激酶 | 1,3-BPG + ADP ⇌ 3-磷酸甘油酸 + ATP | $-18.8$ | $+1.3$ |
| 8 | 磷酸甘油酸变位酶 | 3-磷酸甘油酸 ⇌ 2-磷酸甘油酸 | $+4.4$ | $+0.8$ |
| 9 | 烯醇化酶 | 2-磷酸甘油酸 ⇌ 磷酸烯醇式丙酮酸 + $\mathrm{H_2O}$ | $+1.7$ | $-3.3$ |
| 10 | 丙酮酸激酶 | 磷酸烯醇式丙酮酸 + ADP → 丙酮酸 + ATP | $-31.4$ | $-16.7$ |

（自由能单位为 $\mathrm{kJ\,mol^{-1}}$；细胞内数值由人红细胞在 $37\ \mathrm{^\circ C}$ 下实测的稳态浓度算出（Berg 等）。第 5、7、8 步那些小的正值在浓度测量的不确定度之内，意思是"接近于零"；一个有净正向流量的步骤不可能真正有 $\Delta_\mathrm{r}G' > 0$。）

这张表的两个特征是一切后续内容的钥匙。第一，标准值很不靠谱：醛缩酶拥有全途径最大的正 $\Delta_\mathrm{r}G^{\circ\prime}$，却承担着与其他每一步相同的流量。第二，在细胞中，十个步骤里有七个的 $\Delta_\mathrm{r}G'$ 距零不过几个 $\mathrm{kJ\,mol^{-1}}$，而三个——己糖激酶、PFK 与丙酮酸激酶——远离平衡。这一格局不是巧合；它正是一条途径被构造成可控制的方式，我们将在[[#def-control]]中把它说精确。

::: proposition 糖酵解的计量关系 {#prop-glycolysis}
糖酵解的总反应为
$$
\mathrm{glucose} + 2\,\mathrm{NAD^+} + 2\,\mathrm{ADP} + 2\,\mathrm{P_i} \rightarrow 2\,\mathrm{pyruvate} + 2\,\mathrm{NADH} + 2\,\mathrm{H^+} + 2\,\mathrm{ATP} + 2\,\mathrm{H_2O},
$$ {#eq-glycolysis}
其 $\Delta_\mathrm{r}G^{\circ\prime} = -73.5\ \mathrm{kJ\,mol^{-1}}$；在红细胞中，由表中的数值可得 $\Delta_\mathrm{r}G' \approx -96\ \mathrm{kJ\,mol^{-1}}$。葡萄糖（碳的平均氧化数为 0）被氧化为丙酮酸（平均 $+\tfrac23$）；每个葡萄糖释放的四个电子出现在两个 NADH 中。
:::

::: proof 把各步加和
第 1–5 步把一个葡萄糖和两个 ATP 转化为两个 3-磷酸甘油醛（GAP）和两个 ADP：醛缩酶给出一个 GAP 和一个磷酸二羟丙酮（DHAP），磷酸丙糖异构酶再把 DHAP 变成第二个 GAP。随后第 6–10 步作用于每个 GAP：第 6 步消耗 $\mathrm{P_i}$ 与 $\mathrm{NAD^+}$ 并生成 NADH；第 7 步生成一个 ATP；第 9 步放出一个水；第 10 步生成第二个 ATP。因此每个葡萄糖，放能阶段由 $2$ 个 GAP、$2\,\mathrm{P_i}$、$2\,\mathrm{NAD^+}$ 与 $4$ 个 ADP 产生 $4$ 个 ATP、$2$ 个 NADH 与 $2$ 个水。减去投入的 2 个 ATP 即得[[#eq-glycolysis]]。因为吉布斯能是状态函数（[[biochemistry/bioenergetics#prop-coupling]]），标准自由能就是各步数值之和，其中第 6–10 步计两次：
$$
(-16.7 + 1.7 - 14.2 + 23.8 + 7.5) + 2(6.3 - 18.8 + 4.4 + 1.7 - 31.4) = 2.1 - 75.6 = -73.5\ \mathrm{kJ\,mol^{-1}},
$$
细胞内的数值同样相加得 $-57.0 + 2(-19.6) = -96.2\ \mathrm{kJ\,mol^{-1}}$。至于氧化数，葡萄糖 $\mathrm{C_6H_{12}O_6}$ 的碳平均氧化数为 0，而丙酮酸 $\mathrm{CH_3COCOO^-}$ 的三个碳分别为 $-3$、$+2$ 与 $+3$，平均 $+\tfrac23$；于是两个丙酮酸比一个葡萄糖多承担 $4$ 个单位的氧化，即被 $2\,\mathrm{NAD^+}$ 取走的四个电子。
:::

### 准备阶段的化学

**己糖激酶**把 MgATP 的 γ-磷酰基转移到葡萄糖的 6-羟基上（[[biochemistry/bioenergetics#ex-hexokinase]]）。产物被关在细胞里，因为没有转运 6-磷酸葡萄糖的转运体，它已经交给了这个细胞的代谢。**磷酸葡萄糖异构酶**把醛糖变成酮糖：酶打开吡喃环，一个广义碱取走 C2 上的质子，给出 *cis*-烯二醇（酸）中间体，再在 C1 上加质子，即在 C2 处得到酮——这就是碱催化的醛糖-酮糖异构化（Lobry de Bruyn–van Ekenstein 重排），葡萄糖在碱性溶液中缓慢发生的就是它。异构化的用意是把羰基放到 C2 上，这样后来 C3 与 C4 之间的逆羟醛裂解就能把己糖切成两个三碳碎片；若是醛糖，切出来就会是二碳和四碳的碎片。

**磷酸果糖激酶**磷酸化 1-羟基。这是糖酵解的第一个**关键步骤（committed step）**：1,6-二磷酸果糖除了糖酵解别无出路（相比之下，6-磷酸葡萄糖还可以去合成糖原或进入磷酸戊糖途径），所以途径主要就在这一点上受调控。接下来就是切割。

::: example 醛缩酶步骤：机理与热力学 {#ex-aldolase}
醛缩酶把 1,6-二磷酸果糖（FBP）切成磷酸二羟丙酮（DHAP）与 3-磷酸甘油醛（GAP），$\Delta_\mathrm{r}G^{\circ\prime} = +23.8\ \mathrm{kJ\,mol^{-1}}$。(a) 描述动物（I 类）酶的机理。(b) 在人红细胞中，稳态浓度约为 $[\mathrm{FBP}] = 31$、$[\mathrm{DHAP}] = 138$、$[\mathrm{GAP}] = 18.5\ \mu\mathrm{mol\,dm^{-3}}$（Berg 等）。计算 $37\ \mathrm{^\circ C}$ 下的 $K'$ 与 $\Delta_\mathrm{r}G'$。(c) 若三者都在 $1\ \mathrm{mmol\,dm^{-3}}$，$\Delta_\mathrm{r}G'$ 是多少？
::: solution
(a) 这是一个**逆羟醛**裂解。在碱催化的逆羟醛化学里，β-碳上的醇盐赶出一个烯醇盐；醛缩酶做的是同一件事，只是用了好得多的离去基团——它把开链糖的 C2 酮转变为一个亚胺鎓离子。一步一步看：活性位点赖氨酸（肌肉酶中的 Lys229）的 ε-氨基进攻 C2 羰基，经过质子转移与失水，形成一个**质子化的席夫碱**（亚胺鎓）。一个碱性残基取走 C4 羟基的质子；C3–C4 键断裂，其电子流向缺电子的亚胺鎓，给出一个**烯胺**，而 GAP（C4–C6）作为醛被释放。烯胺在 C3 上质子化，再生亚胺鎓，随后亚胺鎓被水解——水进攻、赖氨酸离去——释放 DHAP（C1–C3）并解放酶。亚胺鎓扮演的角色相当于普通羟醛反应中羰基的角色，但它是强得多的电子阱，所以类碳负离子的烯胺中间体得以稳定（[[biochemistry/enzymes]]，共价催化）。用硼氢化钠还原酶-底物混合物可以把席夫碱捕获为稳定的仲胺并使酶失活，共价中间体就是这样被证明的。

(b) 在 $310.15\ \mathrm{K}$，$RT = 2.579\ \mathrm{kJ\,mol^{-1}}$，$K' = \exp(-23.8/2.579) = 9.8\times10^{-5}\ \mathrm{mol\,dm^{-3}}$（这个常数带单位，因为一个分子生成两个）。质量作用比为
$$
Q' = \frac{[\mathrm{DHAP}][\mathrm{GAP}]}{[\mathrm{FBP}]} = \frac{(1.38\times10^{-4})(1.85\times10^{-5})}{3.1\times10^{-5}} = 8.2\times10^{-5}\ \mathrm{mol\,dm^{-3}},
$$
所以 $\Delta_\mathrm{r}G' = 23.8 + 2.579\ln(8.24\times10^{-5}) = 23.8 - 24.3 = -0.5\ \mathrm{kJ\,mol^{-1}}$。反应基本处于平衡（$Q'/K' = 0.84$），带一点微弱的正向驱动力。（Berg 表中列出的 $-1.3\ \mathrm{kJ\,mol^{-1}}$ 来自稍有不同的数据组；两者都说"接近零"。）

(c) 若三者都在 $10^{-3}\ \mathrm{mol\,dm^{-3}}$，$Q' = 10^{-3}$，$\Delta_\mathrm{r}G' = 23.8 + 2.579\ln10^{-3} = 23.8 - 17.8 = +6.0\ \mathrm{kJ\,mol^{-1}}$：裂解将倒着进行。因为一个分子变成两个，稀释有利于裂解：三种物质每整体稀释十倍，$\Delta_\mathrm{r}G'$ 降低 $RT\ln 10 = 5.94\ \mathrm{kJ\,mol^{-1}}$。微摩尔量级的代谢物浓度，加上后续步骤对 GAP 的持续移除，正是一个 $\Delta_\mathrm{r}G^{\circ\prime}$ 很大为正的反应得以正向进行的原因。
:::
:::

**磷酸丙糖异构酶**（TPI）经由另一个烯二醇中间体把 DHAP 变成 GAP，用谷氨酸作广义碱、组氨酸作广义酸。它的 $k_\mathrm{cat}/K_\mathrm{M}$ 约为 $10^{8}$–$10^{9}\ \mathrm{dm^3\,mol^{-1}\,s^{-1}}$，接近扩散极限：TPI 是一把"完美"的酶，即[[biochemistry/enzymes]]意义上的完美，其速率取决于底物到达得有多快。平衡时 DHAP 约占优 $20 : 1$，但 GAP 被移除得太快，异构酶只好不停地往正方向喂料。

### 放能阶段：氧化与底物水平磷酸化

糖酵解的核心事件是把醛氧化成羧酸——一个强放能反应——并把它与一个酰基磷酸（高磷酰基转移势的化合物）的生成偶联起来。偶联由酶上的一个共价中间体完成。

::: example 把氧化与 ATP 合成偶联：GAPDH 与磷酸甘油酸激酶 {#ex-gapdh}
(a) 描述 3-磷酸甘油醛脱氢酶（GAPDH）如何保存醛氧化的自由能。(b) 用 $\Delta_\mathrm{r}G^{\circ\prime} = +6.3$（GAPDH）与 $-18.8\ \mathrm{kJ\,mol^{-1}}$（磷酸甘油酸激酶），在 $298\ \mathrm{K}$ 下求各步以及这对偶联反应的 $K'$，并解释两种酶为什么表现得像一个整体。
::: solution
(a) 活性位点半胱氨酸的硫负离子进攻 GAP 的醛碳，形成**硫半缩醛**。随后一个氢负离子从该碳转移到结合的 $\mathrm{NAD^+}$ 烟酰胺环的 C4 上，把硫半缩醛氧化成**硫酯**——富能的酰基酶。NADH 离去，结合一个新的 $\mathrm{NAD^+}$。接着无机磷酸进攻硫酯的羰基（磷解而非水解），四面体中间体崩塌，赶出半胱氨酸硫负离子，给出**酰基磷酸** 1,3-二磷酸甘油酸。倘若硫酯被水水解，氧化的自由能就会作为热损失掉；用磷酸把它捕获，就把它保存在一个羧酸与磷酸的混合酸酐里，其标准水解自由能为 $-49.4\ \mathrm{kJ\,mol^{-1}}$（[[biochemistry/bioenergetics]]）。（砷酸与磷酸相似，能被该酶接受，但生成的 1-砷酸-3-磷酸甘油酸会自发水解，于是糖酵解继续进行却不在第 7 步生成 ATP——这是结构类似物解偶联的教科书例子。）

(b) $K'(\mathrm{GAPDH}) = \exp(-6300/2479) = 0.079$，$K'(\mathrm{PGK}) = \exp(18\,800/2479) = 2.0\times10^{3}$。对二者之和 GAP + $\mathrm{P_i}$ + $\mathrm{NAD^+}$ + ADP → 3-磷酸甘油酸 + NADH + $\mathrm{H^+}$ + ATP，$\Delta_\mathrm{r}G^{\circ\prime} = -12.5\ \mathrm{kJ\,mol^{-1}}$，$K' = 0.079 \times 2.0\times10^3 = 1.5\times10^{2}$（[[biochemistry/bioenergetics#prop-coupling]]）。两步共享中间体 1,3-BPG，而它保持在很低的浓度（红细胞中约 $1\ \mu\mathrm{mol\,dm^{-3}}$），因为 PGK 消耗它的速度与 GAPDH 生成它的速度一样快。缺少另一方，任何一步都进行不了：不利的氧化被有利的磷酰基转移拉动。这就是**底物水平磷酸化**——由高能磷酸底物转移生成 ATP，而不是由质子梯度生成。
:::
:::

**磷酸甘油酸变位酶**把磷酰基从 C3 搬到 C2，经由酶上的磷酸组氨酸和中间体 2,3-二磷酸甘油酸（同样的化合物，在红细胞中由一个旁路大量生成，调节血红蛋白的氧亲和力，[[biochemistry/protein-function]]）。**烯醇化酶**借助两个 $\mathrm{Mg^{2+}}$ 取走 C2 质子并把 C3 羟基以水的形式消去（经烯醇盐的 E1cB 型脱水），生成**磷酸烯醇式丙酮酸**（PEP）。脱水几乎不改变分子的能量含量，却重新分配了它：在 PEP 中，磷酰基把分子保持在烯醇式，而水解产生的烯醇立即互变异构成稳定得多的酮。这个互变异构正是 PEP 拥有代谢中最高的磷酰基转移势（$-61.9\ \mathrm{kJ\,mol^{-1}}$）的原因，也是**丙酮酸激酶**把磷酰基交给 ADP 时强放能的原因。

### 丙酮酸与 NADH 的去向

只有把第 6 步消耗的 NAD⁺ 再生出来，糖酵解才能继续。有氧气和线粒体时，NADH 的电子被传递（经跨过线粒体内膜的穿梭体）给呼吸链，丙酮酸则进入线粒体被氧化。没有氧气时，细胞必须用 NADH 还原糖酵解的某个产物。肌肉与红细胞用乳酸脱氢酶把丙酮酸还原为**乳酸**，这是一个近平衡步骤（[[biochemistry/bioenergetics#ex-ldh]]）。酵母把丙酮酸脱羧为乙醛（丙酮酸脱羧酶，需焦磷酸硫胺素），再还原为**乙醇**（醇脱氢酶）。两种发酵的总氧化还原平衡相同——没有净氧化——每个葡萄糖都只产出 2 个 ATP；它们的好处是速度快，且不依赖氧气。

::: warning 乳酸不是废物，发酵也不是细胞万不得已时才用的"备用方案"
有两个常见的误解。第一个认为运动肌肉产生的乳酸是无用的死端毒物。实际上乳酸被运出到血液，并被心脏（把它完全氧化）和肝脏（把它变回葡萄糖——**科里循环**）重新氧化；生成它的反应是可逆的。生成乳酸是快速再生 $\mathrm{NAD^+}$ 的办法，而不是处理碳的办法。第二个误解认为细胞只在缺氧时才用糖酵解。红细胞没有线粒体，只会用糖酵解；许多快速增殖的细胞——包括许多肿瘤细胞——即便氧气充足，也把它大部分葡萄糖转成乳酸（瓦尔堡效应），因为生物合成需要糖酵解中间产物，而且按单位酶量计，糖酵解比氧化磷酸化生成 ATP 更快。这两句话都不是医疗建议；它们说明的是流量与产率是两种不同的设计目标。
:::

## 代谢流量的控制

一条途径就像一组串联的水管。大多数管子很粗——酶大量过剩、反应接近平衡——少数几根很细。要改变流量，就得去调那几根细的。"粗"与"细"的热力学描述如下。

::: definition 近平衡步骤与非平衡步骤；流量控制 {#def-control}
对表观平衡常数为 $K'$、细胞内质量作用比为 $Q'$ 的途径某一步，**不平衡比**为 $\rho = Q'/K'$，于是 $\Delta_\mathrm{r}G' = RT\ln\rho$。若 $\rho$ 接近 1（实践中 $\lvert\Delta_\mathrm{r}G'\rvert$ 不超过几个 $\mathrm{kJ\,mol^{-1}}$，$\rho \gtrsim 0.1$），该步骤就是**近平衡**的：它的酶容量远大于途径流量，正逆速率几乎相消，净流量随底物与产物的浓度而定。若 $\rho \ll 1$（$\Delta_\mathrm{r}G'$ 强负），该步骤是**非平衡**的（常称*不可逆*）：酶只朝一个方向接近其满容量工作，流量取决于它的活性。**代谢控制**就是通过改变酶的活性——别构效应物、共价修饰或酶量——来调节途径流量，而它主要施于非平衡步骤，尤其是**关键步骤**，即该途径独有的第一个不可逆反应。定量地，酶 $i$ 的**流量控制系数**为
$$
C^J_i = \frac{\partial\ln J}{\partial\ln E_i},
$$ {#eq-fcc}
即稳态流量 $J$ 的相对变化对酶 $i$ 用量的相对变化之比；对线性途径，各系数服从**加和定理** $\sum_i C^J_i = 1$。
:::

调控必须坐在非平衡步骤上，其原因来自自由能与两个方向流量之间的一个简单关系。

::: proposition 流-力关系 {#prop-flux-force}
对按单一机理进行的反应，正向与逆向单向流量之比由自由能变决定：
$$
\frac{J^+}{J^-} = \frac{K'}{Q'} = \mathrm{e}^{-\Delta_\mathrm{r}G'/RT}, \qquad J_\mathrm{net} = J^+ - J^- = J^+\left(1 - \mathrm{e}^{\Delta_\mathrm{r}G'/RT}\right).
$$ {#eq-flux-force}
近平衡步骤（$\Delta_\mathrm{r}G' \to 0$）有 $J^+ \approx J^-$，能随浓度变化朝任一方向承载净流量；而 $310\ \mathrm{K}$ 下 $\Delta_\mathrm{r}G' = -20\ \mathrm{kJ\,mol^{-1}}$ 的步骤有 $J^+/J^- \approx 2\times10^{3}$，于是净流量基本上就是正向流量，而正向流量由酶的活性设定。这一关系假定反应沿单一路线进行（从而微观可逆性对它成立），且浓度是理想的。
:::

::: proof
先看单个基元步骤 $\mathrm{A} \rightleftharpoons \mathrm{B}$，其质量作用速率为 $J^+ = k_+[\mathrm A]$、$J^- = k_-[\mathrm B]$。平衡时两者相等，故 $k_+/k_- = [\mathrm B]_\mathrm{eq}/[\mathrm A]_\mathrm{eq} = K'$（细致平衡）。偏离平衡时，$J^+/J^- = (k_+/k_-)([\mathrm A]/[\mathrm B]) = K'/Q'$。对多步酶机理 $\mathrm{E} + \mathrm{S} \rightleftharpoons \mathrm{ES} \rightleftharpoons \cdots \rightleftharpoons \mathrm{E} + \mathrm{P}$，把同一论证用于每个基元步骤再连乘（稳态下沿一串步骤的单向流量之比相乘），得 $J^+/J^- = \prod_j (k_{+j}/k_{-j}) \cdot [\mathrm S]/[\mathrm P] = K'/Q'$，因为各基元平衡常数的乘积就是总反应的 $K'$（Haldane 关系）。最后，由[[biochemistry/bioenergetics#prop-actual-dg]]，$\Delta_\mathrm{r}G' = RT\ln(Q'/K')$，所以 $J^+/J^- = \mathrm{e}^{-\Delta_\mathrm{r}G'/RT}$，相减即得净流量。取 $\Delta_\mathrm{r}G' = -20\ \mathrm{kJ\,mol^{-1}}$、$RT = 2.579\ \mathrm{kJ\,mol^{-1}}$，得 $\mathrm{e}^{20/2.579} = 2.3\times10^{3}$。
:::

::: example 哪些糖酵解步骤可以被调控？ {#ex-flux-ratios}
用 $\Delta_\mathrm{r}G'$ 的红细胞数值（醛缩酶按[[#ex-aldolase]]重算为 $-0.45\ \mathrm{kJ\,mol^{-1}}$），计算 $310\ \mathrm{K}$ 下己糖激酶、磷酸葡萄糖异构酶、PFK、醛缩酶与丙酮酸激酶的 $J^+/J^-$，并加以解释。
::: solution

| 磷酸葡萄糖异构酶 | $-2.5$ | $2.6$ | $0.62$ |
| PFK | $-22.2$ | $5.5\times10^3$ | $1.000$ |

对醛缩酶，正向流量只比逆向大 19 %：酶正向运转的速率约为途径净流量的六倍，逆向也快得相差无几。把它抑制一半几乎不会改变净流量——浓度会略有调整，$\rho$ 会略降，流量照旧。对 PFK，逆向流量可以忽略；净流量*就是*酶的正向速率，所以凡是改变 PFK 活性的因素都直接改变途径流量。己糖激酶、PFK 与丙酮酸激酶是糖酵解的三个控制点，也正是糖异生必须用另外的酶绕开的步骤，因为离平衡这么远的反应不能简单地倒过来运行。

### 磷酸果糖激酶如何受控

PFK 是一个四聚体，其对 6-磷酸果糖的速率曲线呈 S 形，服从[[biochemistry/protein-function#prop-mwc]]的齐变（MWC）模型。它的效应物读取细胞的能量状态：

- **ATP** 既是底物也是别构**抑制剂**，结合在另一个调节位点上，稳定低亲和力的 T 态。ATP 充裕时，糖酵解减速。
- **AMP** 与 **ADP** 解除 ATP 的抑制。因为腺苷酸激酶使 $2\,\mathrm{ADP} \rightleftharpoons \mathrm{ATP} + \mathrm{AMP}$ 保持在近平衡，[ATP] 的微小下降会造成 [AMP] 大幅*相对*上升，AMP 因此成为灵敏的警报信号。
- **柠檬酸**，柠檬酸循环的第一个中间产物，在肌肉与肝脏中抑制 PFK：循环已经饱和，再造丙酮酸毫无意义。
- **质子**起抑制作用，防止产生过多的乳酸。
- **2,6-二磷酸果糖**由一个独立的、受激素调控的双功能激酶/磷酸酶生成，是肝脏中最强的激活剂：它提高 PFK 对 6-磷酸果糖的亲和力，并克服 ATP 的抑制。胰高血糖素在血糖偏低时发出信号，使双功能酶磷酸化，从而降低 2,6-二磷酸果糖、减慢糖酵解，并解除对糖异生酶果糖 1,6-二磷酸酶的抑制——这种**相互（reciprocal）**调控使两条方向相反的途径不会同时全速运转。

## 从丙酮酸到乙酰辅酶A

在需氧细胞中，丙酮酸被运入线粒体基质，由**丙酮酸脱氢酶复合体**（PDH）转化为乙酰辅酶A。这是一个由三种酶、五种辅酶组成的巨大装配体：
$$
\mathrm{pyruvate} + \mathrm{CoA} + \mathrm{NAD^+} \rightarrow \mathrm{acetyl\text{-}CoA} + \mathrm{CO_2} + \mathrm{NADH}, \qquad \Delta_\mathrm{r}G^{\circ\prime} = -33.4\ \mathrm{kJ\,mol^{-1}} .
$$
其化学是一个可以顺着箭头逐步跟踪的序列。在 **E1**（真正的丙酮酸脱氢酶）中，焦磷酸硫胺素（TPP）的 C2 碳负离子（鎓叶立德）加到丙酮酸的酮羰基上；加合物失去 $\mathrm{CO_2}$——噻唑鎓环充当电子阱——给出羟乙基-TPP，一个被稳定的碳负离子（烯胺）。这个碳负离子进攻 **E2** 上**硫辛酰胺**臂的二硫键，把二碳单元以乙酰硫酯的形式转移过去，并把硫辛酰胺还原为二硫醇。E2 随后把乙酰基转给辅酶A的巯基。在 **E3**（二氢硫辛酰胺脱氢酶）中，还原态的硫辛酰胺被酶结合的 FAD 重新氧化，FAD 再把电子交给 NAD⁺。长长的硫辛酰-赖氨酸臂在三个活性位点之间摆动，中间产物从复合体上一步也不离开——这是**底物通道**的一个例子。

因为动物体内乙酰辅酶A不能变回丙酮酸，PDH 是糖碳朝氧化或脂肪合成的不可逆承诺，并受到严格调控：它的产物乙酰辅酶A与 NADH 抑制它；一个专职的 **PDH 激酶**通过磷酸化使它失活（受高 ATP/ADP、NADH/NAD⁺ 与乙酰辅酶A/辅酶A 比率的刺激），而一个 **PDH 磷酸酶**使它复活（受收缩肌肉中 $\mathrm{Ca^{2+}}$ 与脂肪组织中胰岛素的刺激）。

## 柠檬酸循环

**柠檬酸循环**（三羧酸循环或克雷布斯循环）把乙酰辅酶A的乙酰基彻底氧化为 $\mathrm{CO_2}$。它是催化性地做到的：四碳载体草酰乙酸接受乙酰基，六碳产物在两次氧化脱羧中失去两个碳（以 $\mathrm{CO_2}$ 形式），剩下的四碳单元重新被氧化成草酰乙酸。八个步骤（Nelson 与 Cox；$\Delta_\mathrm{r}G^{\circ\prime}$ 单位为 $\mathrm{kJ\,mol^{-1}}$）为：

| 步骤 | 酶 | 反应（简化） | $\Delta_\mathrm{r}G^{\circ\prime}$ |
|---|---|---|---|
| 1 | 柠檬酸合酶 | 乙酰辅酶A + 草酰乙酸 + $\mathrm{H_2O}$ → 柠檬酸 + 辅酶A | $-32.2$ |
| 2 | 乌头酸酶 | 柠檬酸 ⇌ 异柠檬酸（经 *cis*-乌头酸） | $+13.3$ |
| 3 | 异柠檬酸脱氢酶 | 异柠檬酸 + $\mathrm{NAD^+}$ → α-酮戊二酸 + $\mathrm{CO_2}$ + NADH | $-20.9$ |
| 4 | α-酮戊二酸脱氢酶复合体 | α-酮戊二酸 + 辅酶A + $\mathrm{NAD^+}$ → 琥珀酰辅酶A + $\mathrm{CO_2}$ + NADH | $-33.5$ |
| 5 | 琥珀酰辅酶A合成酶 | 琥珀酰辅酶A + GDP（或 ADP） + $\mathrm{P_i}$ ⇌ 琥珀酸 + GTP（或 ATP） + 辅酶A | $-2.9$ |
| 6 | 琥珀酸脱氢酶 | 琥珀酸 + FAD（酶结合） ⇌ 延胡索酸 + $\mathrm{FADH_2}$ | $0$ |
| 7 | 延胡索酸酶 | 延胡索酸 + $\mathrm{H_2O}$ ⇌ L-苹果酸 | $-3.8$ |
| 8 | 苹果酸脱氢酶 | L-苹果酸 + $\mathrm{NAD^+}$ ⇌ 草酰乙酸 + NADH | $+29.7$ |

有机化学同样似曾相识。柠檬酸合酶经 Claisen 型缩合形成 C–C 键：一个天冬氨酸取走乙酰辅酶A甲基的质子，硫酯的烯醇（酸）进攻草酰乙酸的酮羰基，柠檬酰辅酶A中间体再被水解——硫酯的水解正是该步强放能的来源。乌头酸酶把叔醇柠檬酸（无法被氧化）经脱水再水合异构化为仲醇异柠檬酸，用铁硫簇作 Lewis 酸。异柠檬酸脱氢酶把仲醇氧化成酮，而这个酮如今位于羧酸的 β 位，β-酮酸于是轻易地失去 $\mathrm{CO_2}$——即[[organic-2/enols-enolates]]中的 β-酮酸脱羧。α-酮戊二酸脱氢酶是 PDH 复合体的近亲，具有相同的三酶、TPP-硫辛酰胺-FAD 逻辑。琥珀酰辅酶A合成酶用硫酯的自由能生成 GTP 或 ATP（动物细胞各有一种同工酶，比例随组织而异），这是循环中唯一的底物水平磷酸化。琥珀酸脱氢酶是循环中唯一的膜结合酶，也是呼吸链的复合体 II，用 FAD 把一个 $\mathrm{CH_2{-}CH_2}$ 氧化成反式 $\mathrm{CH{=}CH}$，因为这个脱氢反应的自由能小到不足以还原 NAD⁺。延胡索酸酶立体专一地加水给出 L-苹果酸，苹果酸脱氢酶收拢整个环。

::: proposition 柠檬酸循环的计量关系 {#prop-tca}
循环每运行一圈实现
$$
\mathrm{acetyl\text{-}CoA} + 3\,\mathrm{NAD^+} + \mathrm{FAD} + \mathrm{GDP} + \mathrm{P_i} + 2\,\mathrm{H_2O} \rightarrow 2\,\mathrm{CO_2} + 3\,\mathrm{NADH} + \mathrm{FADH_2} + \mathrm{GTP} + 2\,\mathrm{H^+} + \mathrm{CoA},
$$ {#eq-tca}
由表中数值 $\Delta_\mathrm{r}G^{\circ\prime} = -50.3\ \mathrm{kJ\,mol^{-1}}$。草酰乙酸再生而不被消耗；乙酰基的两个碳氧化到 $\mathrm{CO_2}$ 释放的八个电子以三个 NADH 与一个 $\mathrm{FADH_2}$ 出现。
:::

::: proof 碳、电子与自由能的记账
把八个反应相加，每种中间产物（柠檬酸、异柠檬酸、α-酮戊二酸、琥珀酰辅酶A、琥珀酸、延胡索酸、苹果酸）都生成一次又消耗一次，草酰乙酸在第 1 步被消耗、第 8 步重新生成，于是全部相消。剩下的就是输入的乙酰辅酶A、两个 $\mathrm{CO_2}$（第 3、4 步）、三个 NADH（第 3、4、8 步）、一个 $\mathrm{FADH_2}$（第 6 步）、一个 GTP（第 5 步），以及第 1、7 步消耗的水（乌头酸酶拿掉的水它又放了回去）。电子计数：乙酰基两个碳的氧化数为 $-3$（甲基）与 $+3$（硫酯羰基），而在 $\mathrm{CO_2}$ 中两者都在 $+4$，所以共移走 $7 + 1 = 8$ 个电子；三个 NADH 与一个 $\mathrm{FADH_2}$ 承载 $3 \times 2 + 2 = 8$ 个。自由能：$-32.2 + 13.3 - 20.9 - 33.5 - 2.9 + 0 - 3.8 + 29.7 = -50.3\ \mathrm{kJ\,mol^{-1}}$。（严格地说，每圈放出的两个 $\mathrm{CO_2}$ 来自在更早各圈作为草酰乙酸进入的碳，而不是刚加进来的乙酰基——但净记账是相同的。）
:::

上述证明里最后那句话值得认真对待，因为同位素标记实验依赖于它，而且它说明循环是一个循环，不是一条直线途径。

::: example 追踪乙酰辅酶A的碳原子 {#ex-label}
羰基碳带 $^{14}\mathrm C$ 标记的乙酰辅酶A喂给线粒体。标记最先出现在第几圈循环放出的 $\mathrm{CO_2}$ 中？假定没有其他反应移除或添加循环中间产物。
::: solution
追踪原子。柠檬酸合酶把乙酰辅酶A的甲基碳连到草酰乙酸的羰基碳（C2）上；乙酰基的羰基碳成为柠檬酸乙酰来源一侧臂端的羧基。乌头酸酶立体专一地作用于*草酰乙酸来源*的那条臂（柠檬酸是前手性的，酶能分辨它的两条 $\mathrm{CH_2COO^-}$ 臂），所以羟基移入那条臂，异柠檬酸脱氢酶把连在中心碳上的羧基作为 $\mathrm{CO_2}$ 移走——那是个草酰乙酸的碳。α-酮戊二酸脱氢酶接着移走酮基旁的那个羧基——又是一个草酰乙酸的碳。所以在**第一**圈，两个 $\mathrm{CO_2}$ 都不含标记：两个乙酰碳都存活进了琥珀酰辅酶A。到琥珀酸——一个对称分子——标记在两个羧基碳之间被打乱；它最终落在再生草酰乙酸的 C1 或 C4 上。在**第二**圈，作为 $\mathrm{CO_2}$ 放出的两个碳都源自草酰乙酸的羧基碳，所以全部标记在第二圈离开。（同理，甲基标记会到达草酰乙酸的内部碳，要到第三圈及以后才释放，每次一半。）最早显示这一立体专一性——像柠檬酸这样的对称分子被酶不对称地对待——的实验，使奥格斯顿（Alexander Ogston）在 1948 年提出三点附着思想，并最终引出前手性的概念。
:::

### 推动循环：苹果酸脱氢酶问题

苹果酸脱氢酶的 $\Delta_\mathrm{r}G^{\circ\prime} = +29.7\ \mathrm{kJ\,mol^{-1}}$，在 $37\ \mathrm{^\circ C}$ 下表观平衡常数约为 $10^{-5}$。取线粒体游离 $[\mathrm{NAD^+}]/[\mathrm{NADH}]$ 约为 10，平衡给出 $[\mathrm{oxaloacetate}]/[\mathrm{malate}] \approx 10^{-5} \times 10 = 10^{-4}$，而基质中的草酰乙酸确实被维持在极低（低微摩尔级或更低）的浓度。这一步被下一步拉动：柠檬酸合酶凭借其硫酯水解有 $\Delta_\mathrm{r}G^{\circ\prime} = -32.2\ \mathrm{kJ\,mol^{-1}}$，所以两步合起来是放能的（标准条件下 $-2.5\ \mathrm{kJ\,mol^{-1}}$，在细胞中更有利，因为乙酰辅酶A远高于草酰乙酸）。这与 GAPDH 和磷酸甘油酸激酶是同一条偶联原理：低浓度的中间产物从一个酶交到另一个酶。

### 循环的调节

柠檬酸循环受其三个强放能步骤——柠檬酸合酶、异柠檬酸脱氢酶与 α-酮戊二酸脱氢酶——以及其入口 PDH 处供需两端的控制。NADH/NAD⁺ 与 ATP/ADP 的高比率意味着呼吸链壅塞、能量充裕，它们抑制所有这些酶；ADP 激活异柠檬酸脱氢酶；收缩肌肉释放的 $\mathrm{Ca^{2+}}$ 激活异柠檬酸与 α-酮戊二酸脱氢酶（以及 PDH 磷酸酶），于是功一开始循环就加速。因为循环的脱氢酶依赖 NAD⁺，循环的速率与呼吸链重新氧化 NADH 的速率直接挂钩——也就是与对 ATP 的需求挂钩（[[biochemistry/oxidative-phosphorylation]]）。

循环还是**两用（amphibolic）**的：它既服务于分解，也服务于生物合成。α-酮戊二酸与草酰乙酸被抽调去合成谷氨酸与天冬氨酸，琥珀酰辅酶A用于合成血红素，柠檬酸被输出到细胞质溶胶为脂肪酸合成提供乙酰辅酶A，草酰乙酸则离开（以苹果酸形式）用于糖异生。每一次抽调都必须由一个**回补（anaplerotic）**（"填充"）反应来平衡，其中最重要的是丙酮酸羧化酶：丙酮酸 + $\mathrm{HCO_3^-}$ + ATP → 草酰乙酸 + ADP + $\mathrm{P_i}$，它被乙酰辅酶A激活——乙酰辅酶A正是在宣告需要更多草酰乙酸来接纳它。

## 糖异生：把途径倒过来运行

肝脏与肾脏用乳酸、甘油和大多数氨基酸的碳骨架合成葡萄糖。这一**糖异生**逆向使用糖酵解的七个近平衡酶，但不能逆转过三个非平衡步骤；它对每一个都用不同的酶绕行：

1. **丙酮酸 → 磷酸烯醇式丙酮酸**，分两步：丙酮酸羧化酶（线粒体、需生物素、用 ATP）生成草酰乙酸，磷酸烯醇式丙酮酸羧激酶（用 GTP）把它脱羧并磷酸化为 PEP。总反应为丙酮酸 + ATP + GTP → PEP + ADP + GDP + $\mathrm{P_i}$，$\Delta_\mathrm{r}G^{\circ\prime} = +31.4 - 30.5 = +0.9\ \mathrm{kJ\,mol^{-1}}$——花费两个磷酸酐来制造一个高能烯醇磷酸，反应于是变得容易可逆。
2. **1,6-二磷酸果糖 → 6-磷酸果糖**由果糖 1,6-二磷酸酶催化，是一个水解（$\Delta_\mathrm{r}G^{\circ\prime} = +14.2 - 30.5 = -16.3\ \mathrm{kJ\,mol^{-1}}$），受 AMP 与 2,6-二磷酸果糖抑制。
3. **6-磷酸葡萄糖 → 葡萄糖**由肝脏与肾脏内质网上的葡萄糖 6-磷酸酶完成（$-13.8\ \mathrm{kJ\,mol^{-1}}$），这就是只有这两个器官能把游离葡萄糖释放入血的原因。

::: example 合成葡萄糖的代价 {#ex-gng}
(a) 写出由两个丙酮酸进行糖异生的总反应方程。(b) 由糖酵解表计算它的 $\Delta_\mathrm{r}G^{\circ\prime}$，并与逆转糖酵解比较。(c) 同时运行糖酵解与糖异生能达到什么？
::: solution
(a) 数一数核苷酸。每个葡萄糖，丙酮酸羧化酶用 2 个 ATP，磷酸烯醇式丙酮酸羧激酶用 2 个 GTP（每个丙酮酸各一个），逆转的磷酸甘油酸激酶步骤用 2 个 ATP（每个 3-磷酸甘油酸一个）；两个磷酸酶释放 $\mathrm{P_i}$ 而不生成 ATP。逆转的 GAPDH 步骤消耗两个 NADH。总反应方程为
$$
2\,\mathrm{pyruvate} + 4\,\mathrm{ATP} + 2\,\mathrm{GTP} + 2\,\mathrm{NADH} + 2\,\mathrm{H^+} + 6\,\mathrm{H_2O} \rightarrow \mathrm{glucose} + 4\,\mathrm{ADP} + 2\,\mathrm{GDP} + 6\,\mathrm{P_i} + 2\,\mathrm{NAD^+} .
$$
(b) 简单逆转糖酵解会有 $\Delta_\mathrm{r}G^{\circ\prime} = +73.5\ \mathrm{kJ\,mol^{-1}}$。糖异生就是这个逆反应加上四个额外磷酸酐键的水解（花六个，而逆转只需两个）：$73.5 - 4 \times 30.5 = -48.5\ \mathrm{kJ\,mol^{-1}}$。让途径朝生成葡萄糖的方向"爬坡"的代价是每个葡萄糖多付四个 ATP 当量；回报是它现在热力学上有利，而且因为不可逆步骤使用另外的酶，它可以被分开调控。

(c) 若 PFK 与果糖 1,6-二磷酸酶同时活跃，二者之和就是 ATP + $\mathrm{H_2O}$ → ADP + $\mathrm{P_i}$：一个**底物循环**，除了水解 ATP 散发热量什么都不做。相互调控（由 AMP、柠檬酸与 2,6-二磷酸果糖）通常防止这一点。然而，一个受控的小底物循环能把净流量对效应物的响应放大——在某些昆虫的飞行肌中，它还用来产热。
:::

## 后续内容

这里产生的 NADH 与 $\mathrm{FADH_2}$ 在其电子抵达氧气之前一文不值；[[biochemistry/oxidative-phosphorylation]]将追踪它们穿过呼吸链，解释自由能如何储存为质子动力势，并完成葡萄糖的 ATP 产量（约 30–32 个 ATP）。柠檬酸循环也是脂肪与蛋白质分解代谢的会合点：β-氧化向它输送乙酰辅酶A，氨基酸骨架则从丙酮酸、乙酰辅酶A、α-酮戊二酸、琥珀酰辅酶A、延胡索酸与草酰乙酸各处进入（[[biochemistry/lipid-nitrogen-metabolism]]），在那里我们还会看到胰岛素与胰高血糖素如何跨组织协调本章的各个控制点。由 6-磷酸葡萄糖出发的糖原合成与分解接[[biochemistry/carbohydrates-lipids]]。带流量控制系数的代谢控制分析，是代谢工程以及[[kinetics]]中动力学网络模型的定量语言。

::: history
糖酵解途径是在 1920 与 1930 年代由酵母发酵与肌肉提取液的研究弄清出来的，它建立在毕希纳（Eduard Buchner）1897 年的无细胞发酵以及哈登（Arthur Harden）与杨（William Young）在酵母汁中发现己糖双磷酸与一种耐热辅因子（1905–06 年）的工作之上。反应序列主要由恩布登（Gustav Embden）、迈耶霍夫（Otto Meyerhof）与帕尔纳克（Jakub Parnas）搭建起来——途径以他们的名字命名（恩布登-迈耶霍夫-帕尔纳克途径）——还有瓦尔堡（Otto Warburg）、诺伊贝格（Carl Neuberg）以及卡洛尔与格蒂·科里夫妇（Carl and Gerty Cori）的贡献；到 1940 年前后，十个步骤全部已知。迈耶霍夫因肌肉中乳酸的工作获 1922 年诺贝尔生理学或医学奖，科里夫妇因催化性的糖原转化获 1947 年奖，他们 1929 年描述了肌肉与肝脏之间的乳酸-葡萄糖循环。丙酮酸的氧化则难得多。圣捷尔吉（Albert Szent-Györgyi）1935 年证明少量四碳二元羧酸就能催化性地刺激切碎的鸽胸肌的呼吸；1937 年，克雷布斯（Hans Krebs）与约翰逊（William Arthur Johnson）在谢菲尔德证明柠檬酸由草酰乙酸生成又重新生成，从而提出了这个循环；他们的论文被《自然》退稿，同年发表于《Enzymologia》。缺失的"活性乙酸"在弗里茨·李普曼（Fritz Lipmann）1940 年代中期发现辅酶A、费奥多尔·吕嫩（Feodor Lynen）1951 年证明乙酰基以硫酯形式挂在其上之后，被认定就是乙酰辅酶A。克雷布斯与李普曼分享 1953 年诺贝尔生理学或医学奖。带控制系数与加和定理的代谢控制分析由卡瑟（Henrik Kacser）与伯恩斯（James Burns）（1973 年）以及独立地由海因里希（Reinhart Heinrich）与拉波波特（Tom Rapoport）（1974 年）建立。
:::

::: summary
- 糖酵解把葡萄糖拆成两个丙酮酸，净赚 2 个 ATP 与 2 个 NADH；第 1–5 步投入 2 个 ATP，第 6–10 步（运行两次）经底物水平磷酸化生成 4 个 ATP。
- 每一步都是熟悉的有机反应：磷酰基转移、烯二醇异构化、经赖氨酸席夫碱的逆羟醛裂解（醛缩酶）、经硫酯与磷解的醛氧化（GAPDH）、脱水成烯醇磷酸（烯醇化酶）。
- 在细胞中，糖酵解有七步近平衡；己糖激酶、PFK 与丙酮酸激酶远离平衡，是控制点。标准值（醛缩酶的 $\Delta_\mathrm{r}G^{\circ\prime} = +23.8\ \mathrm{kJ\,mol^{-1}}$）指不出它们；细胞的 $\Delta_\mathrm{r}G'$ 值可以。
- 流-力关系 $J^+/J^- = \mathrm{e}^{-\Delta_\mathrm{r}G'/RT}$ 解释了控制为什么坐在非平衡步骤上；流量控制系数 $C^J_i = \partial\ln J/\partial\ln E_i$ 之和为 1。
- PFK 是关键步骤，受 ATP、柠檬酸与 $\mathrm{H^+}$ 抑制，受 AMP 与 2,6-二磷酸果糖激活；相互调控防止它与糖异生白白循环。
- PDH 复合体（TPP、硫辛酰胺、辅酶A、FAD、NAD⁺）把丙酮酸不可逆地转化为乙酰辅酶A；柠檬酸循环每圈把一个乙酰基氧化为 2 个 $\mathrm{CO_2}$，生成 3 个 NADH、1 个 $\mathrm{FADH_2}$ 与 1 个 GTP。
- 糖异生绕过三个不可逆步骤（丙酮酸羧化酶 + 磷酸烯醇式丙酮酸羧激酶、果糖 1,6-二磷酸酶、葡萄糖 6-磷酸酶），每个葡萄糖花费 6 个磷酸酐键，使总反应变为有利（$\approx -48\ \mathrm{kJ\,mol^{-1}}$）。
:::

## 习题

::: exercise 平衡时的磷酸丙糖异构酶 {level=1 check="0.0485"}
对 DHAP ⇌ GAP，$\Delta_\mathrm{r}G^{\circ\prime} = +7.5\ \mathrm{kJ\,mol^{-1}}$。计算 $298.15\ \mathrm K$ 下的 $K'$，以及平衡时以 GAP 形式存在的丙糖百分比。（$K'$ 保留三位有效数字输入。）
::: solution
$K' = \exp(-7500/(8.314 \times 298.15)) = \exp(-3.025) = 0.0485$。平衡时 $[\mathrm{GAP}]/[\mathrm{DHAP}] = 0.0485$，所以 GAP 占丙糖总量的 $0.0485/1.0485 = 4.6\,\%$。然而糖酵解把所有的 DHAP 都转化成了 GAP，因为 GAPDH 不断移除 GAP，而极快的 TPI 则不断重建平衡。
:::
:::

::: exercise 来自糖原的 ATP {level=1 check="3"}
糖原磷酸化酶用无机磷酸而非 ATP 从糖原释出葡萄糖 1-磷酸，磷酸葡萄糖变位酶把它变成 6-磷酸葡萄糖。每单位转化为乳酸的糖原葡萄糖，无氧糖酵解净生成多少 ATP？（输入 ATP 的数目。）
::: solution
从 6-磷酸葡萄糖出发跳过了己糖激酶步骤，所以只投入一个 ATP（在 PFK 处）而不是两个。放能阶段照样生成 4 个 ATP。净得：$4 - 1 = 3$ 个 ATP 每葡萄糖单位。GAPDH 处生成的 NADH 被乳酸脱氢酶重新氧化，所以 NADH 没有净增。这就是肌肉糖原对短跑如此有效的燃料的原因。
:::
:::

::: exercise 一个乙酰基产生的还原载体 {level=1 check="10"}
按每个 NADH 计 2.5 个 ATP、每个 $\mathrm{FADH_2}$ 计 1.5 个 ATP（[[biochemistry/oxidative-phosphorylation#prop-atp-stoich]]），一个乙酰辅酶A在柠檬酸循环与呼吸链中完全氧化共产生多少 ATP（或 GTP）当量？（输入 ATP 当数的数目。）
::: solution
一圈产生 3 个 NADH、1 个 $\mathrm{FADH_2}$ 与 1 个 GTP（[[#prop-tca]]）：$3 \times 2.5 + 1 \times 1.5 + 1 = 10$ 个 ATP 当量。再加上糖酵解的 2 个 ATP 与 2 个 NADH、以及 PDH 的 NADH（按每个丙酮酸计），葡萄糖的整个氧化约为 30–32 个 ATP，取决于细胞质 NADH 如何进入线粒体。
:::
:::

::: exercise 提高醛缩酶底物的浓度 {level=2 check="5.49"}
用[[#ex-aldolase]]的红细胞浓度与数据，计算若 FBP、DHAP 与 GAP 都浓缩十倍时 $37\ \mathrm{^\circ C}$ 下醛缩酶的 $\Delta_\mathrm{r}G'$。（$\Delta_\mathrm{r}G'$ 以 $\mathrm{kJ\,mol^{-1}}$ 保留三位有效数字输入。）
::: solution
三个浓度都乘 10 使 $Q' = [\mathrm{DHAP}][\mathrm{GAP}]/[\mathrm{FBP}]$ 乘 10：$Q' = 8.235\times10^{-4}$。于是 $\Delta_\mathrm{r}G' = 23.8 + 2.5787\ln(8.235\times10^{-4}) = 23.8 - 18.31 = 5.49\ \mathrm{kJ\,mol^{-1}}$，为正：反应将倒过来进行。等价地，原来的 $-0.45$ 加上 $RT\ln 10 = 5.94$ 也得 $5.49$。对反应物与产物分子数不等的反应，绝对浓度水平很重要，不只是比率。
:::

::: exercise 磷酸果糖激酶处的单向流量 {level=2 check="5500"}
在红细胞中，PFK 在 $310\ \mathrm K$ 下 $\Delta_\mathrm{r}G' = -22.2\ \mathrm{kJ\,mol^{-1}}$。计算正逆单向流量之比 $J^+/J^-$，以及被逆向流量抵消的正向流量份额。（$J^+/J^-$ 保留两位有效数字输入。）
::: solution
由[[#eq-flux-force]]，$J^+/J^- = \exp(22.2/2.5787) = \exp(8.609) = 5.5\times10^3$，即保留两位有效数字为 $5500$。逆向流量抵消正向流量的 $1/5480 = 0.018\,\%$。实际上，PFK 就是一个单向阀；它的活性设定流量，这就是它受到层层调控的原因。
:::

::: exercise 线粒体中的草酰乙酸 {level=2 check="1.0e-4"}
对 L-苹果酸 + $\mathrm{NAD^+}$ ⇌ 草酰乙酸 + NADH + $\mathrm{H^+}$，$\Delta_\mathrm{r}G^{\circ\prime} = +29.7\ \mathrm{kJ\,mol^{-1}}$。假定该反应在 $310\ \mathrm K$ 的基质中处于平衡且 $[\mathrm{NAD^+}]/[\mathrm{NADH}] = 10$，计算 $[\mathrm{oxaloacetate}]/[\mathrm{malate}]$。若 [malate] 为 $0.2\ \mathrm{mmol\,dm^{-3}}$，[oxaloacetate] 是多少？（比率保留两位有效数字输入。）
::: solution
$K' = \exp(-29\,700/(8.314 \times 310.15)) = \exp(-11.52) = 9.96\times10^{-6}$。平衡时 $[\mathrm{OAA}]/[\mathrm{malate}] = K'[\mathrm{NAD^+}]/[\mathrm{NADH}] = 9.96\times10^{-5} = 1.0\times10^{-4}$。[malate] $= 0.2\ \mathrm{mmol\,dm^{-3}}$ 时，$[\mathrm{OAA}] \approx 2\times10^{-8}\ \mathrm{mol\,dm^{-3}} = 20\ \mathrm{nmol\,dm^{-3}}$——远低于其他中间产物的浓度。极低的草酰乙酸浓度由柠檬酸合酶拉向前进，后者对草酰乙酸的 $K_\mathrm{M}$ 相应地很低。
:::

::: solution
(a) 丙酮酸 → PEP：丙酮酸激酶的逆反应（$+31.4$）加上一个额外的 NTP 水解（$-30.5$）：$+0.9\ \mathrm{kJ\,mol^{-1}}$。FBP → F6P：PFK 的逆反应（$+14.2$）加上 ATP 水解（$-30.5$）：$-16.3$。G6P → 葡萄糖：己糖激酶的逆反应（$+16.7$）加上 ATP 水解：$-13.8\ \mathrm{kJ\,mol^{-1}}$。

(b) 逆转的近平衡步骤：第 2、4、5 步各一次，$-1.7 - 23.8 - 7.5 = -33.0$；第 6–9 步两次，$2(-6.3 + 18.8 - 4.4 - 1.7) = +12.8$。绕行：$2(+0.9) - 16.3 - 13.8 = -28.3$。总计：$-33.0 + 12.8 - 28.3 = -48.5\ \mathrm{kJ\,mol^{-1}}$，等于 $+73.5 - 4 \times 30.5$，如[[#ex-gng]]。这种分解显示额外 ATP 花在哪里：在三个绕行处，恰好在糖酵解不可逆之处。

::: exercise 甲基标记经过四轮循环 {level=3 check="0.25"}
**甲基**碳带 $^{14}\mathrm C$ 标记的乙酰辅酶A进入柠檬酸循环，中间产物不增不减。四轮完整循环之后，仍有标记留在循环中间产物中的分数是多少？逐圈解释推理。
::: hint
用[[#ex-label]]的原子对应：每圈放出的两个 $\mathrm{CO_2}$ 来自启动该圈的草酰乙酸的两个羧基碳，而琥珀酸的对称性把标记在等价位置之间随机化。
:::
::: solution
第 1 圈：甲基碳成为柠檬酸乙酰来源一侧臂的 $\mathrm{CH_2}$ 并存活（两个 $\mathrm{CO_2}$ 都来自草酰乙酸的碳）。到琥珀酸，它是两个等价亚甲基碳之一，所以在新的草酰乙酸中它位于 C2 或 C3（内部碳）——标记保留：100 %。第 2 圈：草酰乙酸的内部碳不会被释放；草酰乙酸的 C2 成为琥珀酸的一个内部（亚甲基）碳，C3 成为一个羧基碳（琥珀酰辅酶A的硫酯碳）。在琥珀酸处随机化之后，一半标记进入下一个草酰乙酸的羧基位置，一半留在内部位置——仍然 100 % 保留。第 3 圈：羧基碳被释放，所以一半标记离开；剩下 50 %，在本圈末又一次均分在内部与羧基位置。第 4 圈：剩余部分再走一半。四轮后保留的分数：$1 \times 1 \times \tfrac12 \times \tfrac12 = 0.25$。这种由同分异构体的核磁共振或质谱测得的标记模式，被用来测量穿过循环及其回补支路的流量。
:::
:::

::: exercise 途径中共享的控制 {level=3 check="23"}
一个线性的三酶途径实测流量控制系数 $C^J_1 = 0.6$、$C^J_2 = 0.3$。(a) 求 $C^J_3$。(b) 假定 $C^J_2$ 在变化范围内保持不变，估计酶 2 的用量加倍时流量增加的百分比。(c) 解释为什么过量表达单个"限速"酶很少能大幅提高流量。（增加的百分比取整数输入。）
::: solution
(a) 由[[#def-control]]的加和定理，$C^J_3 = 1 - 0.6 - 0.3 = 0.1$。(b) 若 $C = \mathrm{d}\ln J/\mathrm{d}\ln E$ 为常数，则 $J \propto E^{C}$，所以 $E_2$ 加倍使 $J$ 乘 $2^{0.3} = 1.231$：增加约 23 %。(c) 随着过量表达的酶活性升高，它之前的中间产物下降、之后的上升，于是它变得更接近平衡、控制系数减小，而其他酶的控制系数增大（它们之和必须仍为 1）。控制是整个系统的属性，分布于各个步骤之间；$C = 1$ 的"限速步骤"是极限情形，不是常态。所以代谢工程师通常同时上调几种酶。
:::
