每个细胞都携带一套以四个字母的化学字母表写成的指令，而每个细胞每秒钟都要把这套指令阅读数千次。指令是脱氧核糖核酸（DNA）；工作副本是核糖核酸（RNA）；产物是蛋白质。这一信息流——DNA 的复制、转录为 RNA、翻译为蛋白质——常被画成由方框与箭头组成的示意图，但每一支箭头都是一个化学反应：一个亲核试剂进攻磷原子，一个胺进攻酯。本章把核酸当作化学来处理。我们从单体与连接它们的键讲起，解释双螺旋为什么形成、把它的两条链维系在一起的能量有多大，展示热量如何使双链分开、细胞又如何复制它们，最后以把碱基序列变成氨基酸序列的那些反应收尾。全章使用的非共价力都来自[[biochemistry/water-noncovalent]]；聚合反应的自由能账目则为[[biochemistry/bioenergetics]]埋下伏笔。

## 核苷酸：单体

核酸是**核苷酸**的聚合物，而每个核苷酸都有三个值得拆开分别考察的部分，因为每一部分各有一份工作。

**碱基**是平面的芳香含氮杂环（[[organic-2/heterocycles]]），分两族。**嘌呤**——腺嘌呤（A）与鸟嘌呤（G）——是并合双环体系（一个嘧啶环并上一个咪唑环）。**嘧啶**是单个六元环：胞嘧啶（C）、胸腺嘧啶（T，只在 DNA 中）与尿嘧啶（U，只在 RNA 中）。胸腺嘧啶就是 5-甲基尿嘧啶。每个碱基都能沿一条边缘提供和接受氢键，而这条边缘承载着信息。

**糖**是五碳呋喃糖：RNA 中是 β-D-核糖，DNA 中是 β-D-2-脱氧核糖，后者缺少 C2 上的羟基。糖的原子用撇号编号（1′ 到 5′），以免与碱基的原子混淆。

**磷酸**连接糖。在 pH 7 时每个磷酸二酯带一个负电荷（其 $\mathrm{p}K_\mathrm{a}$ 约为 1），所以核酸是一个每个核苷酸带一个电荷的多聚阴离子——这是它的物理化学中最重要的一条事实。

::: definition 核苷、核苷酸与磷酸二酯骨架 {#def-nucleotide}
**核苷**是碱基通过 **β-N-糖苷键**（连到嘌呤的 N9 或嘧啶的 N1）接在核糖或 2′-脱氧核糖的 C1′ 上构成的：腺苷、鸟苷、胞苷、尿苷与脱氧胸苷。**核苷酸**是核苷的磷酸酯，通常在 5′-羟基上：腺苷 5′-一磷酸（AMP）、脱氧鸟苷 5′-三磷酸（dGTP），如此等等。在核酸中，核苷酸由 **3′,5′-磷酸二酯键**相连：酯化于一个糖的 5′-OH 的磷酸，同时又酯化于前一个糖的 3′-OH。因此链有方向：一端带游离的 5′-磷酸，另一端带游离的 3′-OH，序列总是从 **5′ 端向 3′ 端**书写（5′-ACGT-3′，常简写为 ACGT）。
:::

双螺旋的碱基对由碱基的氢键边缘构成，所以碱基的质子化状态很重要。它们的环氮是弱碱，其 N–H 基团是弱酸：典型数值（Saenger，《核酸结构原理》）是腺嘌呤 N1 质子化的 $\mathrm{p}K_\mathrm{a} \approx 3.5$，胞嘧啶 N3 为 $4.2$，而鸟嘌呤失去 N1–H、胸腺嘧啶与尿嘧啶失去 N3–H 的 $\mathrm{p}K_\mathrm{a}$ 为 $9.2$–$9.7$。这些值都远离 7，所以在生理 pH 下碱基是中性的，几乎完全以**氨基式与酮式（内酰胺式）互变异构体**存在；稀少的亚氨基式与烯醇式会与错误的伙伴配对，它们偶尔出现是自发突变的一个来源。

### 为什么 DNA 用脱氧核糖和胸腺嘧啶

缺失的 2′-羟基是 DNA 充当档案、RNA 充当工作副本的化学原因。在 RNA 中，2′-OH 紧邻磷酸二酯。在碱性条件下（或借助金属离子、核糖核酸酶的帮助），2′-烷氧负离子以分子内、in-line（同轴）的方式对相邻的磷发动类似 $\mathrm{S_N2}$ 的取代：下一个核苷酸的 5′-氧离去，链被切断，生成 **2′,3′-环磷酸**，后者进一步水解为 2′- 与 3′-磷酸的混合物。一个五原子之内的分子内亲核试剂带来巨大的速率优势（[[kinetics/homogeneous-catalysis]]的有效摩尔浓度论证），所以 RNA 在稀碱中数小时即被水解，而 DNA 安然无恙。DNA 的磷酸二酯没有这样的邻居，据估计它在中性 pH、室温下的无催化水解半衰期在 $10^{7}$ 年以上——对一个必须使用一生的分子来说，这是再理想不过的性质。

以胸腺嘧啶代替尿嘧啶则关乎修复。胞嘧啶会缓慢水解失去氨基（脱氨）而变成尿嘧啶。如果 DNA 本来就含尿嘧啶，修复酶就无法区分脱氨的 C 与真正的 U；因为 DNA 用 T，DNA 中出现的任何 U 都是损伤，尿嘧啶-DNA 糖基化酶会把它切除。

::: example 用吸光度测定 DNA {#ex-a260}
碱基在 $260\ \mathrm{nm}$ 附近有强吸收（$\pi \rightarrow \pi^*$ 带，[[spectroscopy/electronic-spectroscopy]]）。实验室规则是：在 $1\ \mathrm{cm}$ 比色皿中吸光度 $A_{260} = 1.00$ 的双链 DNA 溶液约含 $50\ \mu\mathrm{g\,cm^{-3}}$。（a）一个稀释 20 倍的样品读得 $A_{260} = 0.412$。未稀释样品的浓度是多少？（b）取一个碱基对（钠盐）的平均摩尔质量为 $650\ \mathrm{g\,mol^{-1}}$，这条规则相当于每个碱基对多大的摩尔吸收系数？（c）加热时，稀释样品的吸光度升至 $0.56$。发生了什么？
::: solution
（a）由朗伯-比尔定律，吸光度与浓度成正比，所以稀释样品含 $0.412 \times 50 = 20.6\ \mu\mathrm{g\,cm^{-3}}$，原样品为 $20 \times 20.6 = 412\ \mu\mathrm{g\,cm^{-3}}$，即 $0.41\ \mathrm{mg\,cm^{-3}}$。

（b）$50\ \mu\mathrm{g\,cm^{-3}} = 50\ \mathrm{mg\,dm^{-3}}$，即碱基对 $0.050/650 = 7.69\times10^{-5}\ \mathrm{mol\,dm^{-3}}$。由 $A = \varepsilon c l$，
$$
\varepsilon = \frac{1.00}{(7.69\times10^{-5}\ \mathrm{mol\,dm^{-3}})(1\ \mathrm{cm})} = 1.30\times10^{4}\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}\ \text{每个碱基对},
$$
即每个核苷酸约 $6500$。这远低于游离核苷酸的 $\varepsilon_{260}$（dAMP 约 $15\,400$，dCMP 约 $7400$），因为螺旋中堆叠的碱基吸收更弱——**减色效应**。

（c）比值 $0.56/0.412 = 1.36$：吸光度升了约三分之一，因为两条链分开了、碱基去堆积了（**增色效应**）。这一上升是追踪 DNA 熔解的标准方法，而 DNA 熔解正是第三节的主题。它也解释了为什么单链的换算系数不同——单链 DNA 每个吸光度单位约 $33\ \mu\mathrm{g\,cm^{-3}}$，RNA 为 $40$。
:::
:::

## 双螺旋

1953 年，沃森（James Watson）与克里克（Francis Crick）把上述化学与富兰克林（Rosalind Franklin）的 X 射线照片、以及查加夫（Erwin Chargaff）发现的一组组成规律结合起来。规律先于结构问世。

::: proposition 查加夫规则 {#prop-chargaff}
在任何生物的双链 DNA 中，以碱基的摩尔分数计，
$$
x_\mathrm{A} = x_\mathrm{T}, \qquad x_\mathrm{G} = x_\mathrm{C}, \qquad\text{于是}\qquad x_\mathrm{A} + x_\mathrm{G} = x_\mathrm{T} + x_\mathrm{C} = \tfrac12 .
$$
比值 $(x_\mathrm{G} + x_\mathrm{C})$，即 **GC 含量**，随物种而异（细菌中约 $25\ \%$ 到 $70\ \%$ 以上），但在同一物种内恒定。这些是关于双链 DNA 的**经验规则**：对单链基因组（噬菌体 φX174 有 $x_\mathrm{A} \neq x_\mathrm{T}$）、对 RNA、或对双链中单独取出的一条链都不成立。
:::

::: proof 为什么这些规则由碱基配对得出
在沃森-克里克模型中，一条链上的每个腺嘌呤都正对另一条链上的胸腺嘧啶，每个鸟嘌呤都正对胞嘧啶，所以两条链**互补**。数一数这个双链体：若一条链含 $n_\mathrm{A}$、$n_\mathrm{T}$、$n_\mathrm{G}$、$n_\mathrm{C}$ 个各碱基，则伙伴链分别含 $n_\mathrm{T}$、$n_\mathrm{A}$、$n_\mathrm{C}$、$n_\mathrm{G}$ 个。求和，双链体含 $n_\mathrm{A} + n_\mathrm{T}$ 个腺嘌呤和同样多个胸腺嘧啶，含 $n_\mathrm{G} + n_\mathrm{C}$ 个鸟嘌呤和同样多个胞嘧啶，无论序列如何。每个碱基对恰含一个嘌呤和一个嘧啶，所以嘌呤占全部碱基的一半。没有任何条件约束 $n_\mathrm{A}$ 相对于 $n_\mathrm{G}$ 的多少，这正是 GC 含量可以自由变化的原因。查加夫的测定（1950 年）是观察，互补性是解释；互补性在单链基因组上的失效是对它的检验。
:::

配对本身由几何固定。**沃森-克里克 A·T 对**有两根氢键（腺嘌呤的 N6–H 到胸腺嘧啶的 O4，以及胸腺嘧啶的 N3–H 到腺嘌呤的 N1）；**G·C 对**有三根（O6…H–N4、N1–H…N3 和 N2–H…O2）。两种配对的整体形状几乎相同，两个糖的 C1′ 原子间距离同为 $1.08\ \mathrm{nm}$，所以任何序列都能契合同一规则的骨架——这正是螺旋能够携带任意信息的性质。这些氢键即[[biochemistry/water-noncovalent#def-hbond]]中定义的那些。

在常见形式 **B-DNA** 中，结构具有以下特征（数值取自 Berg 等第 9 版，对溶液中的 DNA）：

- 两条**反平行**链——一条沿轴 5′→3′ 向上，另一条 5′→3′ 向下——绕成直径约 $2.0\ \mathrm{nm}$ 的**右手**螺旋；
- 糖-磷酸骨架在外侧，与水及抗衡离子接触；碱基对在内侧堆叠，几乎垂直于轴；
- 每个碱基对上升 $0.34\ \mathrm{nm}$，每圈约 $10.5$ 个碱基对，故螺距约 $3.6\ \mathrm{nm}$；
- 因为配对的两个糖苷键不在直径的两端，形成宽阔的**大沟**与狭窄的**小沟**；蛋白质读取序列主要靠与大沟中暴露的碱基边缘形成氢键。

失水的 DNA，以及双链 RNA 和 RNA-DNA 杂合体（其 2′-OH 不允许 B 型的糖褶曲），采取更宽、更紧密的 **A 型**，每圈约 11 个碱基对、上升 $0.26\ \mathrm{nm}$。嘌呤与嘧啶交替的序列可形成 **Z-DNA**，一种每圈约 12 个碱基对的左手螺旋。

### 是什么把螺旋维系在一起

人们容易脱口而出"氢键"。这只是部分答案，而且是较小的那部分。分开的单链上的碱基也是氢键结合的——与水结合——所以形成一个碱基对是在*交换*氢键而不是创造氢键，每对的净自由能增益很小。另有三个贡献决定稳定性：

1. **碱基堆积。**平面芳香碱基以 $0.34\ \mathrm{nm}$ 的间隔堆叠，获得范德华（色散）与偶极-偶极吸引，并把它们的面埋起来避开水，这就是[[biochemistry/water-noncovalent#def-hydrophobic]]的疏水效应。堆积取决于*相邻*的碱基对，这就是对双链稳定性最准确的描述是**最近邻模型**（SantaLucia，1998）的原因：十个不同的相邻碱基对堆中每一个贡献自己的 $\Delta G^\circ$，在 $37\ \mathrm{^\circ C}$、$1\ \mathrm{mol\,dm^{-3}}$ NaCl 下约为 $-2$ 到 $-9\ \mathrm{kJ\,mol^{-1}}$，含 G·C 对的堆最有利益。
2. **静电排斥**：两条链的磷酸基之间的排斥对抗双链体。它被抗衡离子屏蔽：按[[biochemistry/water-noncovalent#prop-coulomb]]的论证，溶液中的阳离子（以及细胞中的 $\mathrm{Mg^{2+}}$ 或多胺）聚集在骨架周围、减小排斥，所以双链稳定性随盐浓度上升。
3. **构象熵。**两条柔性单链形成一条刚性双链时失去大量自由度；这使双链形成的 $\Delta S^\circ$ 大而负，也是短双链在适中温度就解体的原因。

::: warning G·C 对更稳定并不是"因为第三根氢键" {#warn-hbond}
G·C 含量高的 DNA 熔解温度更高、仅仅因为 G·C 对有三根氢键而 A·T 对只有两根——这种常见解释是不完整的。配对形成时，与水的氢键被打破，所以每根氢键的净贡献很小。更大的差别在**堆积**：涉及 G·C 对的堆远比只涉及 A·T 的堆有利，而同时包含这两种效应的最近邻参数，才是定量预言熔解温度的东西。同样，把查加夫规则读成"A = G"也是错的：这些规则把每个嘌呤与一个特定的嘧啶配对。
:::

::: example 由一个测定推出组成 {#ex-composition}
某种细菌的 DNA 被发现含 $21.0\ \%$ 的胸腺嘧啶（按摩尔分数计）。（a）若该 DNA 是双链的，给出其余碱基的百分比。（b）对一条单链 DNA 含 $21.0\ \%$ 胸腺嘧啶的病毒，重做此题。
::: solution
（a）由[[#prop-chargaff]]，$x_\mathrm{A} = x_\mathrm{T} = 21.0\ \%$。其余 $100 - 42.0 = 58.0\ \%$ 是等量的 G + C：$x_\mathrm{G} = x_\mathrm{C} = 29.0\ \%$。GC 含量为 $58.0\ \%$。

（b）什么也说不了。单链不与互补链配对，所以其组成不受约束；其余三个百分比必须实测。罗伯特·辛舍海默（Robert Sinsheimer）1959 年正是这样认识到 φX174 DNA 是单链的：它的碱基比例违反了查加夫规则。
:::
:::

### 长度与拓扑

碱基对很小，但基因组很长。*E. coli* 染色体有 $4.64\times10^{6}$ 个碱基对，所以在 B 型下长 $4.64\times10^{6} \times 0.34\ \mathrm{nm} = 1.58\ \mathrm{mm}$——约为容纳它的细胞长度的 800 倍。一个人类的二倍体细胞含约 $6.2\times10^{9}$ 个碱基对，即约 $2\ \mathrm{m}$ 的 DNA，装在一个几微米宽的细胞核里。包装靠缠绕与盘绕实现：在真核生物中，147 个碱基对绕每个**核小体**约 1.7 圈——核小体是一个由八组蛋白组成的圆盘，其大量的赖氨酸与精氨酸侧链中和了磷酸基。

在闭合环状 DNA 中，或在末端被蛋白质固定的长环中，两条链不切断就无法解开。一条链绕另一条链的次数成为拓扑不变量。

::: definition 连接数与超螺旋 {#def-linking}
对共价闭合的双链 DNA，**连接数** $Lk$ 是把分子平放时一条链穿过另一条链的次数；它是整数，不切断一条链就无法改变。它等于**缠绕数** $Tw$（螺旋绕自身轴的圈数）与**伸展数** $Wr$（轴本身在空间中的盘绕）之和：
$$
Lk = Tw + Wr .
$$
$N$ 个碱基对、每圈 $h$ 个碱基对的松弛分子有 $Lk_0 = N/h$。**超螺旋密度**为 $\sigma = (Lk - Lk_0)/Lk_0$；从多数细胞分离出的 DNA 是**负超螺旋**的，$\sigma \approx -0.06$。**拓扑异构酶**改变 $Lk$：Ⅰ 型酶通过切断一条链以 1 为步长改变，Ⅱ 型酶通过让一个双链片段穿过暂时性的双链断裂以 2 为步长改变（第二种需要 ATP 水解）。
:::

负超螺旋储存的自由能使双链局部更容易分开——这是复制与转录共同的头一步。

::: example 质粒的超螺旋 {#ex-supercoil}
一个 $5250$ 碱基对的环状质粒分离下来时 $\sigma = -0.060$。取每圈 $10.5$ 个碱基对，求 $Lk_0$、$Lk$ 与变化 $\Delta Lk$。若全部亏缺都由螺旋解开而非伸展数吸收，能留下多少个碱基对不配对？
::: solution
$Lk_0 = 5250/10.5 = 500.0$。于是 $\Delta Lk = \sigma\,Lk_0 = -0.060 \times 500 = -30$，故 $Lk = 470$。30 圈的亏缺若全部化作缠绕数的减少，相当于解开 $30 \times 10.5 = 315$ 个碱基对——约质粒的 $6\ \%$。实际上大部分亏缺以伸展数的形式出现（电镜下看到的交织"扭紧橡皮筋"形状），但储存的应变正是 RNA 聚合酶或复制起点能以很少额外自由能打开一个泡的原因。
:::
:::

## 熔解与退火

加热双链 DNA 溶液，在一个窄的温度区间内 $260\ \mathrm{nm}$ 的吸光度会上升约三分之一（[[#ex-a260]]）：两条链分开了。缓慢冷却，它们又重新找到自己的伙伴（**退火**）。跃迁的中点就是**熔解温度** $T_\mathrm{m}$。对长的天然 DNA，$T_\mathrm{m}$ 取决于 GC 含量与盐；Marmur 与 Doty（1962）在标准柠檬酸盐氯化钠缓冲液（$0.15\ \mathrm{mol\,dm^{-3}}$ NaCl，$0.015\ \mathrm{mol\,dm^{-3}}$ 柠檬酸钠）中找到了经验关系 $T_\mathrm{m} = 69.3 + 0.41\,(\%\mathrm{GC})\ \mathrm{^\circ C}$。对短双链——分子生物学的引物与探针——一个简单的两态模型使跃迁可以定量，并显示浓度为什么重要。

::: proposition 短双链的两态熔解 {#prop-melting}
设两条互补、非自互补的单链 A 与 B，各自总浓度为 $c$（故单链总浓度 $C_\mathrm{T} = 2c$），以单一的全有或全无步骤 $\mathrm{A + B \rightleftharpoons AB}$ 形成双链体，标准焓与熵为 $\Delta H^\circ$ 和 $\Delta S^\circ$（均为负，与温度无关）。若 $\theta$ 是处于双链中的单链分数，则
$$
\frac{\theta}{(1-\theta)^2} = K c, \qquad K = \exp\!\left(-\frac{\Delta H^\circ - T\Delta S^\circ}{RT}\right),
$$ {#eq-theta}
而熔解温度——$\theta = \tfrac12$ 处——为
$$
T_\mathrm{m} = \frac{\Delta H^\circ}{\Delta S^\circ + R\ln(C_\mathrm{T}/4)} .
$$ {#eq-tm}
浓度以 $\mathrm{mol\,dm^{-3}}$ 计（相对标准的 $1\ \mathrm{mol\,dm^{-3}}$）。条件是模型的假设：没有部分配对的中间体、理想稀溶液，且跃迁区间内 $\Delta C_p \approx 0$。
:::

::: proof 双分子平衡的质量作用
在分数 $\theta$ 下，$[\mathrm{AB}] = \theta c$ 且 $[\mathrm{A}] = [\mathrm{B}] = (1-\theta)c$，所以
$$
K = \frac{[\mathrm{AB}]}{[\mathrm{A}][\mathrm{B}]} = \frac{\theta c}{(1-\theta)^2c^2} = \frac{\theta}{(1-\theta)^2 c},
$$
整理即得[[#eq-theta]]，且 $K = \exp(-\Delta G^\circ/RT)$，其中 $\Delta G^\circ = \Delta H^\circ - T\Delta S^\circ$（[[thermodynamics/reaction-equilibrium]]）。在 $\theta = \tfrac12$ 时左边等于 $0.5/0.25 = 2$，所以 $K(T_\mathrm{m}) = 2/c = 4/C_\mathrm{T}$。取对数，
$$
-\frac{\Delta H^\circ}{RT_\mathrm{m}} + \frac{\Delta S^\circ}{R} = \ln\frac{4}{C_\mathrm{T}} \quad\Longrightarrow\quad \Delta H^\circ = T_\mathrm{m}\left(\Delta S^\circ + R\ln\frac{C_\mathrm{T}}{4}\right),
$$
即[[#eq-tm]]。显式求解二次方程 $Kc\,\theta^2 - (2Kc + 1)\theta + Kc = 0$ 取 0 到 1 之间的根，得 $\theta = 2Kc/\bigl(2Kc + 1 + \sqrt{4Kc + 1}\bigr)$，即图中所画的形状。因为反应是双分子的，$K$ 要乘一个浓度：提高 $C_\mathrm{T}$ 使平衡移向双链并抬高 $T_\mathrm{m}$。对单分子跃迁（发夹，或实际上两条链无法彼此扩散开来的长基因组双链体），$T_\mathrm{m} = \Delta H^\circ/\Delta S^\circ$，与浓度无关。
:::

::: example 引物双链的熔解温度 {#ex-tm}
一个 12 碱基对的双链在 $1\ \mathrm{mol\,dm^{-3}}$ NaCl 中，$\mathrm{A + B \rightarrow AB}$ 的 $\Delta H^\circ = -380\ \mathrm{kJ\,mol^{-1}}$、$\Delta S^\circ = -1070\ \mathrm{J\,K^{-1}\,mol^{-1}}$，数值大小与最近邻表给出的一致。（a）求 $C_\mathrm{T} = 2.0\ \mu\mathrm{mol\,dm^{-3}}$ 时的 $T_\mathrm{m}$。（b）求 $C_\mathrm{T} = 200\ \mu\mathrm{mol\,dm^{-3}}$ 时的 $T_\mathrm{m}$。（c）求 $37\ \mathrm{^\circ C}$ 下的 $\Delta G^\circ$ 与 $K$。
::: solution
（a）$R\ln(C_\mathrm{T}/4) = 8.314 \times \ln(5.0\times10^{-7}) = 8.314 \times (-14.509) = -120.6\ \mathrm{J\,K^{-1}\,mol^{-1}}$，所以
$$
T_\mathrm{m} = \frac{-380\,000\ \mathrm{J\,mol^{-1}}}{(-1070 - 120.6)\ \mathrm{J\,K^{-1}\,mol^{-1}}} = 319.2\ \mathrm{K} = 46.0\ \mathrm{^\circ C}.
$$
（b）浓度增大一百倍，给分母的对数项加上 $R\ln 100 = 38.3\ \mathrm{J\,K^{-1}\,mol^{-1}}$：$8.314 \ln(5.0\times10^{-5}) = -82.3$，故 $T_\mathrm{m} = 380\,000/1152.3 = 329.8\ \mathrm{K} = 56.6\ \mathrm{^\circ C}$。仅凭浓度就有十度之差：这就是寡核苷酸的熔解温度总是连同单链浓度一起引用的原因。

（c）$\Delta G^\circ = \Delta H^\circ - T\Delta S^\circ = -380.0 - (310.15)(-1.070) = -48.1\ \mathrm{kJ\,mol^{-1}}$，所以 $K = \exp(48\,140/(8.314 \times 310.15)) = 1.3\times10^{8}$。一个结合常数为 $10^{8}$ 的双链，当链浓度为微摩尔级时，在 $46\ \mathrm{^\circ C}$ 仍几乎一半解离：要紧的是 $Kc$，不是 $K$。
:::
:::

图中对两个浓度都画出了[[#eq-theta]]。跃迁之所以陡峭，是因为 $\Delta H^\circ$ 很大：几度之间，双链就从大部分形成变为大部分熔解，这正是熔解成为有用诊断、聚合酶链式反应（PCR）得以工作的原因。

## 复制：抄写序列

互补性立即提示了 DNA 如何被复制，沃森与克里克在 1953 年就曾如此评论：把两条链分开，让每条都模板合成一个新的伙伴。梅塞尔森（Matthew Meselson）与斯塔尔（Franklin Stahl）在 1958 年用 $^{15}\mathrm{N}$ 培养细菌、再转入 $^{14}\mathrm{N}$ 并按密度分离 DNA，证实复制是**半保留的**：每个子代双链体含一条旧链和一条新链。

### 聚合酶反应

每一种 DNA 与 RNA 聚合酶的化学都相同。进来的核苷酸是 **5′-三磷酸核苷**（DNA 用 dATP、dGTP、dCTP、dTTP）；生长链的末端是与模板配对的游离 **3′-OH**。3′-氧进攻三磷酸的 **α-磷**，与 β-磷之间的键断裂，无机**焦磷酸**（$\mathrm{PP_i}$）离去：
$$
(\mathrm{dNMP})_n + \mathrm{dNTP} \rightarrow (\mathrm{dNMP})_{n+1} + \mathrm{PP_i} .
$$
其机理——由被"逮个正着"的聚合酶晶体结构揭示——使用**两个金属离子**，通常是 $\mathrm{Mg^{2+}}$，由保守的天冬氨酸羧基配位。金属离子 A 配位 3′-氧并降低其羟基的 $\mathrm{p}K_\mathrm{a}$，使之能以类烷氧负离子的亲核试剂进攻；金属离子 B 配位 β-和 γ-磷酸，中和离去焦磷酸上累积的负电荷；两者都桥连 α-磷并稳定五配位的过渡态。进攻是 in-line 的，用手性硫代磷酸酯做的实验显示磷上的构型翻转——磷上发生单次 $\mathrm{S_N2}$ 型取代的标志。

由化学可推出两个结论。第一，链只沿 **5′→3′ 方向**生长，因为每个新键所需的能量由进来的核苷酸的三磷酸携带，而不是由链携带。第二，聚合酶不能起始一条链：它需要一个 3′-OH 来延伸，在细胞中这由引发酶合成的一小段 RNA **引物**提供。

::: example 焦磷酸酶把聚合反应推向一方 {#ex-pyrophosphate}
细胞含有无机焦磷酸酶，它水解 $\mathrm{PP_i + H_2O \rightarrow 2\,P_i}$，$\Delta G^{\circ\prime} = -19.2\ \mathrm{kJ\,mol^{-1}}$（Nelson 与 Cox，第 8 版）。在 $37\ \mathrm{^\circ C}$ 下，把这一水解与核苷酸添加偶联，使总平衡常数乘以多大的因子？
::: solution
两个反应偶联时，它们的标准吉布斯能相加、平衡常数相乘（[[biochemistry/bioenergetics#prop-coupling]]）。多出的因子是
$$
\exp\!\left(\frac{19\,200\ \mathrm{J\,mol^{-1}}}{(8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(310.15\ \mathrm{K})}\right) = e^{7.446} = 1.7\times10^{3}.
$$
核苷酸添加本身只是适度有利，因为一个磷酸酐键换成了自由能相近的磷酸二酯键，而积累的 $\mathrm{PP_i}$ 会使它逆转（聚合酶在体外确实催化焦磷酸解）。摧毁焦磷酸使每一步实际上不可逆，代价是每个核苷酸花费两个磷酸酐键。同样的装置驱动 RNA 的合成以及翻译中氨基酸的活化。
:::
:::

### 前导链与后随链

因为两条模板链反平行，而每种聚合酶都按 5′→3′ 工作，复制叉上的两条新链的制造方式不同。**前导链**沿叉移动的方向连续合成。**后随链**以相反方向分成小片段合成——**冈崎片段**，细菌中约 1000–2000 个核苷酸，真核生物中 100–200 个——每个片段都由自己的 RNA 引物起始。引物随后被移除并由 DNA 取代，**DNA 连接酶**封闭每个留下的缺口，利用 ATP（真核生物与许多病毒）或 NAD⁺（细菌）的能量，经由腺苷酰化的酶和 AMP–DNA 中间体形成最后的磷酸二酯键。在叉的前方，**解旋酶**利用 ATP 把两条链分开，单链结合蛋白使它们保持分开，拓扑异构酶缓解前进的叉本会堆积的正超螺旋（[[#def-linking]]）。

::: example 复制一个细菌染色体需要多长时间？ {#ex-replication-time}
*E. coli* 染色体（$4.64\times10^{6}$ 碱基对，环状）由单个起点经两个反向移动的叉复制，每个叉在 $37\ \mathrm{^\circ C}$ 下约每秒 $1000$ 个核苷酸。估算复制时间。*E. coli* 如何在丰富培养基中每 20 分钟分裂一次？
::: solution
每个叉复制半个染色体：$t = (4.64\times10^{6}/2)/(1000\ \mathrm{s^{-1}}) = 2320\ \mathrm{s} \approx 39\ \mathrm{min}$，与实测的 40 分钟相符。更快的分裂之所以可能，是因为新一轮复制在上一轮完成之前就从起点开始了，所以一个快速生长的细胞同时含有带着几套复制叉的染色体。相比之下，人类的一条染色体由总共数万个起点复制，叉的移动速度只有每秒几十到几百个核苷酸。
:::
:::

### 忠实性

聚合酶在四种核苷酸中做选择时，大约每 $10^{4}$–$10^{5}$ 次添加出一次错。仅靠碱基配对还要差：溶液中正确与错误配对之间的自由能差只相当于接近 $10^{-2}$ 的错误率。其余部分来自**几何选择**——活性部位在新形成的配对周围闭合并检查其形状，只有沃森-克里克配对才合适——以及**动力学校对**步骤。许多复制型聚合酶还有 **3′→5′ 外切核酸酶**，在延伸之前把错配的核苷酸从链末端切除（使忠实性提高约 100 倍），复制后的**错配修复**又纠正其余的大部分（再提高 100 到 1000 倍）。*E. coli* 的总错误率约为每碱基对每次复制 $10^{-10}$。对复制 $6.2\times10^{9}$ 个碱基对的人体细胞而言，这就是每次分裂约 $0.6$ 个新错误——很小，但不是零，而且是进化与癌症的共同原料。

## 转录：从 DNA 到 RNA

**转录**把基因的一条链抄成 RNA。RNA 聚合酶使用核糖核苷 5′-三磷酸（ATP、GTP、CTP、UTP）以及与 DNA 聚合酶相同的两金属离子化学，但它不需要引物：它在**启动子**序列处打开约 14 个碱基对的泡，从头起始一条链。它以 3′→5′ 读取**模板链**，因而以 5′→3′ 合成 RNA；所以 RNA 与另一条 DNA 链——**编码链**——序列相同，只是以 U 代替 T。细菌只有一种 RNA 聚合酶，其 σ 因子识别启动子；真核生物有三种核 RNA 聚合酶，其中 RNA 聚合酶 Ⅱ 合成信使 RNA。RNA 聚合酶的校对很有限（它们可以回退并切掉错误掺入的核苷酸），其错误率约为 $10^{-5}$，因为 RNA 分子是短命的副本，所以可以容忍。

::: warning 模板链与编码链 {#warn-strands}
RNA 转录产物**与模板链互补**，并**与编码链序列相同（U 代替 T）**。常见两个错误：把转录产物写成编码链的互补链；忘记互补序列是反平行的，以致 5′-ATGC-3′ 的互补链必须写作 5′-GCAT-3′，而不是 5′-TACG-3′。在习惯成为自动之前，始终显式写出每条序列的两端。
:::

在真核生物中，初级转录物在离开细胞核之前要经过加工。一个 7-甲基鸟苷**帽子**通过不寻常的 5′–5′ 三磷酸连接接在 5′ 端；约 200 个腺苷酸的 **poly(A) 尾**加在 3′ 端；**内含子**经**剪接**移除。剪接是纯粹的磷酰基转移化学。第一步，内含子中一个特定腺苷（分支点）的 2′-OH 进攻 5′ 剪接位点的磷酸，释放带有游离 3′-OH 的上游外显子，并形成环状**套索**。第二步，那个 3′-OH 进攻 3′ 剪接位点的磷酸，把两个外显子连接起来并释放套索。两步都是**转酯化**：磷酸二酯键的数目不变，所以化学本身不需要能量输入（剪接体把 ATP 用于其构象重排）。在某些自剪接内含子中，仅 RNA 就催化这些反应——这就是**核酶**（催化性 RNA）的发现。

## 翻译：从 RNA 到蛋白质

### 遗传密码

四个碱基必须指定二十种氨基酸。两个碱基一组只有 $4^2 = 16$ 种组合，太少；三个一组给出 $4^3 = 64$ 种，够用且绰绰有余。

::: definition 遗传密码 {#def-code}
**遗传密码**是 64 个**密码子**——信使 RNA 中连续的碱基三联体——与氨基酸之间的对应关系。它具有以下性质：
- **三联体、不重叠**：mRNA 从一个固定的起点开始按 5′→3′ 以连续密码子阅读，无间隔、无标点，所以有三种可能的**阅读框**，起始密码子选定其中之一；
- **简并**：61 个**有义密码子**编码 20 种氨基酸，所以多数氨基酸有几个同义密码子，它们通常第三个碱基不同；
- **起始与终止信号**：AUG 编码甲硫氨酸，也充当通常的**起始密码子**；UAA、UAG 与 UGA 是**终止密码子**，由释放因子而非 tRNA 读取；
- **几乎通用**：同样的对应关系在细菌、古菌与真核生物中都成立，只有少数例外（例如在脊椎动物线粒体中，UGA 编码色氨酸）。
:::

密码子由**转运 RNA**（tRNA）读取。tRNA 是约 76 个核苷酸长、折叠成 L 形的接头分子，其 3′ 端携带一个氨基酸，另一端有一个与密码子反平行配对的**反密码子**。克里克（Crick）的**摆动假说**（1966）解释了为什么不到 61 种 tRNA 就够用：反密码子的第一个碱基（与密码子的第三个碱基配对）可以形成非标准配对，G 与 U，以及肌苷（I）与 U、C 或 A。

### 给 tRNA 装载氨基酸

密码与化学之间的桥梁由**氨酰-tRNA 合成酶**搭成，每种氨基酸一种。每种合成酶分两步活化其氨基酸：
$$
\begin{aligned}
\text{氨基酸} + \mathrm{ATP} &\rightarrow \text{氨酰-AMP} + \mathrm{PP_i},\\
\text{氨酰-AMP} + \mathrm{tRNA} &\rightarrow \text{氨酰-tRNA} + \mathrm{AMP}.
\end{aligned}
$$
第一步，羧酸根进攻 ATP 的 α-磷，形成混酸的羧-磷酸酐，一种活化的酰基衍生物（[[organic-2/carboxylic-derivatives]]）。第二步，tRNA 末端腺苷的 2′- 或 3′-羟基进攻这个酰基，给出**酯**。焦磷酸的水解再次使过程不可逆，所以装载一个 tRNA 花费两个磷酸酐键。准确性由双重筛选保证：活性部位拒斥比正确氨基酸大的氨基酸，而一个独立的**编辑位点**水解任何更小的、错载的氨基酸（例如异亮氨酰-tRNA 合成酶水解缬氨酰-$\mathrm{tRNA^{Ile}}$）。错误率约为 $10^{-4}$ 分之一。

### 核糖体与肽键

**核糖体**（细菌 70S，真核生物 80S）是由两个亚基组成的核糖核蛋白机器。小亚基结合 mRNA 并检查密码子-反密码子配对；大亚基形成肽键。它有三个 tRNA 位点：A（氨酰基）、P（肽基）与 E（出口）。每个延伸循环中：

1. 一个氨酰-tRNA 与结合 GTP 的延伸因子 EF-Tu（真核生物中为 EF1A）形成复合物进入 A 位；正确的密码子-反密码子配对触发 GTP 水解并释放该因子；
2. **肽基转移**：A 位氨酰-tRNA 游离的 α-氨基进攻把生长中的肽连接在 P 位 tRNA 上的那个酯的羰基碳；四面体中间体崩塌，P 位 tRNA 的 3′-氧离去，肽链增长一个残基，接在 A 位 tRNA 上；
3. **移位**由延伸因子 EF-G（EF2）上的 GTP 水解驱动，把 tRNA 移到 P 位与 E 位，把 mRNA 移过一个密码子。

第 2 步是酯的氨解——热力学上下坡，因为酰胺比酯更稳定——而催化它的不是蛋白质，而是**核糖体 RNA**：大亚基的原子结构（2000 年）显示活性部位够得着之处没有任何蛋白质侧链。约 $10^{7}$ 倍的速率增强主要来自把两个底物就位并组织水，这是一个熵效应。所成的肽键即[[biochemistry/amino-acids-proteins#def-peptide]]中的平面酰胺。细菌核糖体每秒添加约 15–20 个氨基酸；A 位出现终止密码子时结合一个释放因子，触发肽基–tRNA 酯的水解，释放完成的链。

::: example 解读一条消息 {#ex-decode}
一个 mRNA 的序列为 5′-GCCAUGGCUUGGAAAUAGCU-3′。（a）从第一个 AUG 开始，找出所编码的肽。（b）写出从 AUG 到终止密码子这片区域 DNA 的编码链与模板链。（c）数一数合成这个肽消耗的磷酸酐键，每个 tRNA 的装载算两个，每个延伸循环算两个 GTP，忽略起始与终止。
::: solution
（a）从第一个 AUG 起三个一读：AUG GCU UGG AAA UAG。按标准密码，它们分别是 Met、Ala、Trp、Lys 与终止，所以肽是 **Met-Ala-Trp-Lys**。（起始之前的 GCC 与终止之后的 CU 不翻译。）

（b）编码链具有 mRNA 的序列，U 换 T：5′-ATGGCTTGGAAATAG-3′。模板链是其反平行的互补链，按 5′→3′ 写出，即先倒序再互补：5′-CTATTTCCAAGCCAT-3′。

（c）四个 tRNA 被装载（$4 \times 2 = 8$ 个键），形成三个肽键，每个需要 EF-Tu 一个 GTP 和 EF-G 一个 GTP（$3 \times 2 = 6$）：不算起始与终止共 $14$ 个。一般地，一个 $n$ 残基的蛋白质约花费 $2n + 2(n-1) = 4n - 2$——即每个肽键约四个磷酸酐键，超过 $120\ \mathrm{kJ\,mol^{-1}}$ 的自由能（每个 $-30.5\ \mathrm{kJ\,mol^{-1}}$）来形成一个水解自由能只有 $-10\ \mathrm{kJ\,mol^{-1}}$ 量级的键。多花的部分买的是速度与准确性，不是热力学可行性。
:::
:::

翻译的准确性——约每 $10^{4}$ 个密码子出一个错——给蛋白质长度设了上限：一个 $L$ 残基的蛋白质每个残基都正确的概率是 $(1-\varepsilon)^{L} \approx e^{-\varepsilon L}$。图显示了为什么细胞负担得起几百个残基的蛋白质，而要制造最大的那些却需要高保真。

::: widget plot

x: 0, 3000

## 后续内容

核苷酸的化学远远超出信息本身。ATP、NAD⁺、FAD 与辅酶 A 都是核苷酸，本章的磷酰基转移反应就是[[biochemistry/bioenergetics]]和[[biochemistry/glycolysis-citric-acid]]中能量代谢的反应。核糖体形成的肽键折叠成[[biochemistry/amino-acids-proteins]]中的结构，而剪接与肽基转移的 RNA 催化提醒我们：[[biochemistry/enzymes]]中的酶未必是蛋白质。[[#prop-melting]]的双链熔解热力学是 PCR、DNA 测序与杂交探针的基础，而药物与 DNA 及细菌核糖体的结合——许多抗生素作用于肽基转移酶中心或解码位点——将在[[medicinal-chemistry/drug-targets]]与[[medicinal-chemistry/biologics]]中展开，在那里，核酸本身也成了药物。

::: history
米歇尔（Friedrich Miescher）1869 年从白细胞的细胞核中分离出一种富磷物质，称之为"核素"（nuclein）。科塞尔（Albrecht Kossel）在 1880 年代到 1900 年代初鉴定了它的碱基（1910 年获诺贝尔生理学或医学奖），莱文（Phoebus Levene）鉴定了核糖（1909）与脱氧核糖（1929）并说明了核苷酸的组装方式。1944 年，艾弗里（Oswald Avery）、麦克劳德（Colin MacLeod）与麦卡蒂（Maclyn McCarty）证明转化肺炎链球菌的物质是 DNA；赫尔希（Alfred Hershey）与蔡斯（Martha Chase）用标记噬菌体做的实验（1952）指向同样的结论。查加夫（Erwin Chargaff）于 1950 年发表了他的碱基比例。富兰克林（Rosalind Franklin）与戈斯林（Raymond Gosling）的 B-DNA 衍射照片（"照片 51"，1952）与查加夫规则支撑了沃森（James Watson）与克里克（Francis Crick）的双螺旋（1953）；沃森、克里克与威尔金斯（Maurice Wilkins）获 1962 年诺贝尔生理学或医学奖，而富兰克林已于 1958 年去世。科恩伯格（Arthur Kornberg）1956 年分离出 DNA 聚合酶 Ⅰ，梅塞尔森（Matthew Meselson）与斯塔尔（Franklin Stahl）1958 年证实了半保留复制，冈崎令治（Reiji Okazaki）与冈崎恒子（Tsuneko Okazaki）1968 年描述了后随链的不连续合成。尼伦伯格（Marshall Nirenberg）与马特伊（Heinrich Matthaei）1961 年读出第一个密码子，到 1966 年密码全部破译。切赫（Thomas Cech，1982）与奥尔特曼（Sidney Altman，1983）发现了催化性 RNA（1989 年诺贝尔化学奖），而拉马钱德兰（Venkatraman Ramakrishnan）、斯泰茨（Thomas Steitz）与约纳特（Ada Yonath）的小组 2000 年发表的核糖体亚基原子结构表明核糖体是一种核酶，他们因此获 2009 年诺贝尔化学奖。
:::

::: summary
- 核苷酸是碱基 + 糖 + 磷酸；核酸是 3′,5′-磷酸二酯聚合物，有 5′→3′ 方向，每个残基一个负电荷。缺失的 2′-OH 使 DNA 对水解的抵抗力远高于 RNA。
- 双链 DNA 服从查加夫规则（$x_\mathrm{A} = x_\mathrm{T}$，$x_\mathrm{G} = x_\mathrm{C}$），因为它的反平行链互补；B-DNA 是右手螺旋，上升 $0.34\ \mathrm{nm}$、每圈约 10.5 个碱基对。
- 双链稳定性主要来自碱基堆积（最近邻模型），受磷酸排斥（被盐屏蔽）和构象熵对抗；氢键贡献的是专一性多于稳定性。
- 闭合 DNA 有固定的连接数 $Lk = Tw + Wr$；细胞 DNA 带负超螺旋（$\sigma \approx -0.06$），拓扑异构酶改变 $Lk$。
- 对双分子双链，$T_\mathrm{m} = \Delta H^\circ/[\Delta S^\circ + R\ln(C_\mathrm{T}/4)]$：熔解温度随单链浓度、盐与 GC 含量而升高。
- 所有聚合酶都通过两个金属离子、以 in-line 方式对 α-磷进攻，把核苷 5′-三磷酸加到 3′-OH 上并释放焦磷酸；因此链按 5′→3′ 生长，焦磷酸的水解使每一步不可逆。
- 复制是半保留的，前导链连续、后随链不连续（冈崎片段）；选择、校对与错配修复给出约每碱基对 $10^{-10}$ 的错误。
- 三联体、简并、几乎通用的遗传密码由经氨酰-tRNA 合成酶装载的 tRNA 读取；核糖体 RNA 通过酯的氨解催化肽键形成，代价是每残基约四个磷酸酐键。
:::

## 习题

::: exercise 查加夫规则 {level=1 check="20"}
一份双链 DNA 样品含 $30.0\ \%$ 的鸟嘌呤（碱基的摩尔百分比）。它的碱基中腺嘌呤占多少百分比？（输入百分比。）
::: solution
由查加夫规则 $x_\mathrm{C} = x_\mathrm{G} = 30.0\ \%$，所以 G + C $= 60.0\ \%$，A + T $= 40.0\ \%$，二者平分：$x_\mathrm{A} = x_\mathrm{T} = 20.0\ \%$。这份 DNA 的 GC 含量是 $60\ \%$。
:::
:::

::: exercise 由吸光度求 DNA 浓度 {level=1 check="32.5"}
一份双链 DNA 溶液在 $1.00\ \mathrm{cm}$ 比色皿中 $A_{260} = 0.650$。用换算关系 $A_{260} = 1.00 \leftrightarrow 50\ \mu\mathrm{g\,cm^{-3}}$，求其浓度。（以 $\mu\mathrm{g\,cm^{-3}}$ 输入浓度。）
::: solution
$c = 0.650 \times 50\ \mu\mathrm{g\,cm^{-3}} = 32.5\ \mu\mathrm{g\,cm^{-3}}$。按每个碱基对 $650\ \mathrm{g\,mol^{-1}}$，这相当于碱基对 $5.0\times10^{-5}\ \mathrm{mol\,dm^{-3}}$。换算关系只对双链 DNA 成立；若样品部分熔解，吸光度会更高，估计就偏大。
:::
:::

::: exercise 互补链与转录物 {level=1}
（a）写出 5′-GATTACA-3′ 的互补链，5′ 端在前。（b）若 5′-GATTACA-3′ 是某个短基因的模板链，RNA 转录物的序列是什么？（c）若它是编码链，转录物又是什么？
::: solution
（a）逐个碱基取互补（G→C，A→T，T→A，C→G）得 3′-CTAATGT-5′，再倒过来按 5′→3′ 写出：**5′-TGTAATC-3′**。（b）转录物与模板互补，T 换 U：**5′-UGUAAUC-3′**。（c）转录物与编码链序列相同，T 换 U：**5′-GAUUACA-3′**。把每条序列的两端都写出来，就能避免写出方向错误的互补链这一经典错误。
:::
:::

::: exercise 探针的熔解温度 {level=2 check="33.3"}
两条互补（非自互补）寡核苷酸形成双链，$\Delta H^\circ = -290\ \mathrm{kJ\,mol^{-1}}$、$\Delta S^\circ = -820\ \mathrm{J\,K^{-1}\,mol^{-1}}$。用两态模型求单链总浓度为 $1.0\ \mu\mathrm{mol\,dm^{-3}}$ 时的熔解温度。（$T_\mathrm{m}$ 以 °C 输入，保留一位小数。）
::: solution
由[[#eq-tm]]，$R\ln(C_\mathrm{T}/4) = 8.314 \ln(2.5\times10^{-7}) = 8.314 \times (-15.202) = -126.4\ \mathrm{J\,K^{-1}\,mol^{-1}}$。于是
$$
T_\mathrm{m} = \frac{-290\,000}{-820 - 126.4}\ \mathrm{K} = \frac{290\,000}{946.4}\ \mathrm{K} = 306.4\ \mathrm{K} = 33.3\ \mathrm{^\circ C}.
$$
若没有浓度项，"熔解温度" $\Delta H^\circ/\Delta S^\circ = 353.7\ \mathrm{K}$ 会高出约 $47\ \mathrm{K}$：对双分子双链，稀释熵是问题的大部分。
:::
:::

::: exercise 细菌染色体的复制 {level=2 check="49.0"}
某种细菌有一条 $5.0\times10^{6}$ 碱基对的单一环状染色体，由一个起点双向复制，每个叉的移动速度为每秒 $850$ 个核苷酸。一轮复制需要多长时间？（时间以分钟输入，保留三位有效数字。）
::: solution
两个叉各复制 $2.5\times10^{6}$ 个碱基对：$t = 2.5\times10^{6}/850\ \mathrm{s} = 2941\ \mathrm{s} = 49.0\ \mathrm{min}$。若细胞分裂比这更快，它必须在旧轮完成之前在起点开始新的轮次（多叉复制）。
:::
:::

::: exercise 超螺旋密度 {level=2 check="-0.05"}
一条 $4200$ 碱基对的闭合环状 DNA 的连接数 $Lk = 380$。取松弛 B-DNA 每圈 $10.5$ 个碱基对，计算超螺旋密度 $\sigma$。该分子是正超螺旋还是负超螺旋？需要多少次拓扑异构酶 Ⅰ 反应才能使之松弛？（输入 $\sigma$。）
::: solution
$Lk_0 = 4200/10.5 = 400$，所以 $\sigma = (380 - 400)/400 = -0.050$。该分子是**负**超螺旋（欠旋），细胞 DNA 通常如此。Ⅰ 型拓扑异构酶以 1 为步长改变 $Lk$，所以需要 20 次断链-穿链反应使之松弛（Ⅱ 型以 2 为步长，需要 10 次）。
:::
:::

::: exercise 由熔解温度求 GC 含量 {level=2 check="50.5"}
某种细菌的基因组 DNA 在标准柠檬酸盐氯化钠中于 $90.0\ \mathrm{^\circ C}$ 熔解。用 Marmur-Doty 关系估算其 GC 含量，并说明这一关系为何不像[[#eq-tm]]那样含单链浓度。（GC 含量以百分比输入，保留一位小数。）
::: solution
$\%\mathrm{GC} = (90.0 - 69.3)/0.41 = 50.5\ \%$——接近 *E. coli* 的值（约 $50.8\ \%$）。这一关系不含浓度，是因为长的基因组双链体在许多独立区域同时熔解，而两条链在别处仍然彼此维系在一起：每个局部的熔解实际上是单分子的，每个区域的 $T_\mathrm{m} = \Delta H^\circ/\Delta S^\circ$。它只是对某一种缓冲液的经验拟合，在其他盐浓度下不加修正不可套用。
:::
:::

::: exercise 自互补双链 {level=3 check="37.1"}
一条**自互补**链（如 5′-CGCGAATTCGCG-3′）与自身的一份拷贝形成双链，$2\,\mathrm{A} \rightleftharpoons \mathrm{A_2}$。（a）设单链总浓度为 $C_\mathrm{T}$、处于双链中的单链分数为 $\theta$，证明 $T_\mathrm{m} = \Delta H^\circ/(\Delta S^\circ + R\ln C_\mathrm{T})$。（b）对 $\Delta H^\circ = -290\ \mathrm{kJ\,mol^{-1}}$、$\Delta S^\circ = -820\ \mathrm{J\,K^{-1}\,mol^{-1}}$、$C_\mathrm{T} = 1.0\ \mu\mathrm{mol\,dm^{-3}}$，求 $T_\mathrm{m}$ 并与前一道习题中非自互补的结果比较。（$T_\mathrm{m}$ 以 °C 输入，保留一位小数。）
::: hint
双链含两条单链，所以 $[\mathrm{A_2}] = \theta C_\mathrm{T}/2$、$[\mathrm{A}] = (1-\theta)C_\mathrm{T}$。写出 $K$ 并令 $\theta = \tfrac12$。
:::
::: solution
（a）$K = [\mathrm{A_2}]/[\mathrm{A}]^2 = (\theta C_\mathrm{T}/2)/[(1-\theta)^2 C_\mathrm{T}^2] = \theta/[2(1-\theta)^2 C_\mathrm{T}]$。在 $\theta = \tfrac12$ 时为 $0.5/(2 \times 0.25\,C_\mathrm{T}) = 1/C_\mathrm{T}$。于是 $-\Delta H^\circ/RT_\mathrm{m} + \Delta S^\circ/R = -\ln C_\mathrm{T}$，即 $\Delta H^\circ = T_\mathrm{m}(\Delta S^\circ + R\ln C_\mathrm{T})$，即所求结果。

（b）$R\ln(1.0\times10^{-6}) = -114.9\ \mathrm{J\,K^{-1}\,mol^{-1}}$；$T_\mathrm{m} = 290\,000/934.9\ \mathrm{K} = 310.2\ \mathrm{K} = 37.1\ \mathrm{^\circ C}$。这比相同总浓度下两条不同单链的 $33.3\ \mathrm{^\circ C}$ 高 $3.8\ \mathrm{K}$：自互补时每条单链都是潜在伙伴，所以有效浓度项大四倍（$C_\mathrm{T}$ 而不是 $C_\mathrm{T}/4$）。实际上自互补序列在最近邻表中还带一个小的 $\Delta S^\circ$ 对称性修正，出于同样的计数原因。
:::
:::

::: exercise 一个蛋白质的成本与准确性 {level=3 check="0.951"}
某细胞合成一个 500 残基的蛋白质。（a）用每残基约四个磷酸酐键（$4n - 2$，见[[#ex-decode]]）和每键 $\Delta G^{\circ\prime} = -30.5\ \mathrm{kJ\,mol^{-1}}$，估算每摩尔蛋白质花掉的标准自由能。（b）若每个密码子以 $1.0\times10^{-4}$ 的概率被独立误读，多大比例的分子不含错误？（c）通过更多校对可以使翻译更准确。用每残基的成本解释：细胞为什么不把错误率压到 DNA 复制的水平。（(b) 的无错比例保留三位有效数字输入。）
::: hint
对 (b)，每个残基独立的正确概率是 $1 - \varepsilon$，所以 500 个全对的概率是 $(1-\varepsilon)^{500}$。
:::
::: solution
（a）$4 \times 500 - 2 = 1998$ 个磷酸酐键；$1998 \times 30.5\ \mathrm{kJ\,mol^{-1}} = 6.09\times10^{4}\ \mathrm{kJ\,mol^{-1}} \approx 61\ \mathrm{MJ}$ 每摩尔蛋白质（细胞条件下更多，因为 ATP 水解的放能比其标准值多）。

（b）$(1 - 1.0\times10^{-4})^{500} = e^{500\ln(0.9999)} = 0.951$：约 $95\ \%$ 的分子是完美的，而其余的大部分只含一个常常无害的保守替换。

（c）每一道拒绝错误氨酰-tRNA 的校对步骤也会拒绝一些正确的并消耗 GTP，所以更高的准确性要同时付出能量与速度。蛋白质是一次性产品：偶尔一个 faulty 分子会被降解并更换，所以 $10^{-4}$ 的错误率是个不错的折中。DNA 才是母本，它出错会被每一个后代继承，这就值得为之投入多得多的校对与修复——正是这些使其错误率降到 $10^{-10}$。
:::
