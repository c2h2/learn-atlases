每一个红细胞都面临一项看似不可能的任务。在肺里，氧分压约$100\ \mathrm{Torr}$，它必须装载尽可能多的氧；几秒钟之后，在氧压已降到$20\ \mathrm{Torr}$的工作肌肉里，它又必须把绝大部分氧放掉。一个蛋白质若结合氧紧到足以在肺中装满，看来就必定在组织中死死攥住不放；而一个在组织中容易释放的蛋白质，看来就必定在肺中装载不佳。血红蛋白解决这个问题的办法是*随装载而改变亲和力*：第一个氧分子结合得弱，最后几个结合得强，结果是一条 S 形结合曲线，恰好在机体使用的压力范围内从大体空置翻转为大体装满。它的单链表亲肌红蛋白——肌肉的氧库——做不到这一点，只能以简单的双曲线结合。

本章把这个故事变成化学。我们从蛋白质与配体的平衡讲起——饱和分数与解离常数——然后认识血红素基团与两种氧载体，导出度量协同性的希尔方程，并建立别构的齐变（莫诺-怀曼-尚热，Monod–Wyman–Changeux）模型：在模型里，蛋白质在两种亲和力不同的形状之间切换。同一套思想解释了质子、二氧化碳与 2,3-二磷酸甘油酸如何调节氧的输送，解释胎儿血液为何能从母血中夺取氧气，也解释单个氨基酸替换如何造成镰状细胞贫血症。它们还是[[biochemistry/enzymes]]中酶调节与[[medicinal-chemistry/drug-binding]]中药物结合的基础。结构词汇——螺旋、亚基、四级结构——出自[[biochemistry/amino-acids-proteins]]，平衡的算术出自[[general-chemistry-2/chemical-equilibrium]]。

## 结合平衡

蛋白质做的事，大多始于结合：抗体识别抗原，受体结合激素，转运蛋白抓住待运的货物，酶握紧它的底物。结合的伙伴无论大小都称为**配体**。最简单的情形——一个蛋白质分子 P 有一个结合位点，加上配体 L——是一个普通的化学平衡，
$$
\mathrm{P} + \mathrm{L} \rightleftharpoons \mathrm{PL},
$$
两个数就把它完全描述。

::: definition 解离常数与饱和分数 {#def-saturation}
对稀溶液中的平衡 $\mathrm{PL} \rightleftharpoons \mathrm{P} + \mathrm{L}$，**解离常数**为
$$
K_\mathrm{d} = \frac{[\mathrm{P}][\mathrm{L}]}{[\mathrm{PL}]},
$$
单位与浓度相同（其倒数 $K_\mathrm{a} = 1/K_\mathrm{d}$ 是结合常数）。**饱和分数**$\theta$（对氧载体常写作 $Y$）是被占据的结合位点分数：
$$
\theta = \frac{[\mathrm{PL}]}{[\mathrm{P}] + [\mathrm{PL}]} = \frac{[\mathrm{L}]}{K_\mathrm{d} + [\mathrm{L}]},
$$ {#eq-hyperbola}
其中 $[\mathrm{L}]$ 是*游离*配体的浓度。对 $\mathrm{O_2}$ 这类气体，溶解浓度与其分压成正比（亨利定律），所以同一方程可写成 $Y = p_{\mathrm{O_2}}/(P_{50} + p_{\mathrm{O_2}})$，其中 $P_{50}$ 是一半位点被填满时的分压。$K_\mathrm{d}$ 或 $P_{50}$ 小意味着亲和力高。
:::

双曲线[[#eq-hyperbola]]可由把第一个式的分子分母同除以 $[\mathrm{PL}]$ 并用 $[\mathrm{P}]/[\mathrm{PL}] = K_\mathrm{d}/[\mathrm{L}]$ 得出。它描绘一条等轴双曲线。关于它有三件事值得熟记于心。第一，恰在 $[\mathrm{L}] = K_\mathrm{d}$ 时 $\theta = \tfrac12$：*解离常数就是把蛋白质半饱和时的配体浓度*。第二，曲线收尾很慢：从 $10\ \%$ 升到 $90\ \%$ 饱和度需要配体浓度增加 81 倍（$[\mathrm{L}] = K_\mathrm{d}/9$ 到 $9K_\mathrm{d}$）。第三，标准结合吉布斯自由能为
$$
\Delta_\mathrm{bind}G^\circ = -RT\ln K_\mathrm{a} = RT\ln\frac{K_\mathrm{d}}{c^\circ},
$$
其中 $c^\circ = 1\ \mathrm{mol\,dm^{-3}}$，所以在 $298\ \mathrm{K}$ 下亲和力每十倍值 $RT\ln 10 = 5.7\ \mathrm{kJ\,mol^{-1}}$——差不多就是一根氢键。这部分自由能的来源——氢键、静电作用与疏水效应——见[[biochemistry/water-noncovalent#def-hydrophobic]]。

::: example 一个纳摩尔级的结合剂 {#ex-nanomolar}
某蛋白质在 $298\ \mathrm{K}$ 下以 $K_\mathrm{d} = 10\ \mathrm{nmol\,dm^{-3}}$ 结合其配体。计算 $\Delta_\mathrm{bind}G^\circ$，并求游离配体浓度为 $10\ \mathrm{nmol\,dm^{-3}}$、$100\ \mathrm{nmol\,dm^{-3}}$ 和 $1\ \mu\mathrm{mol\,dm^{-3}}$ 时的饱和分数。
::: solution
$$
\Delta_\mathrm{bind}G^\circ = RT\ln\frac{K_\mathrm{d}}{c^\circ} = (8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(298.15\ \mathrm{K})\ln(1.0\times10^{-8}) = -45.7\ \mathrm{kJ\,mol^{-1}}.
$$
由[[#eq-hyperbola]]：$[\mathrm{L}] = K_\mathrm{d}$ 时 $\theta = 0.50$；$10K_\mathrm{d}$ 时 $\theta = 10/11 = 0.909$；$100K_\mathrm{d}$ 时 $\theta = 100/101 = 0.990$。即使游离配体超过 $K_\mathrm{d}$ 一百倍，仍每百个位点有一个空着。注意*游离*二字：若蛋白质浓度与 $K_\mathrm{d}$ 相当，结合会消耗配体，加入的总配体浓度就不等于游离浓度——[[#exr-depletion]]处理的就是这种情形。
:::
:::

## 肌红蛋白、血红蛋白与血红素基团

氧是蛋白质的糟糕配体。它小、非极性、没有成氢键的基团，而且没有哪种氨基酸侧链能可逆地结合它。于是自然界动用金属：**血红素**基团——原卟啉 IX 环，由四个吡咯氮把一个铁(II)离子络在中心。在肌红蛋白与血红蛋白中，脱氧状态下的铁都是五配位——四个卟啉氮加**近端组氨酸**（His F8，即 F 螺旋的第八个残基）的咪唑——$\mathrm{O_2}$ 结合在第六个空位上。第二个组氨酸——**远端组氨酸**（His E7）——位于另一侧，与结合的氧形成氢键。

蛋白质与金属同样重要。水中的游离血红素几秒内就被氧化：两个血红素与一个 $\mathrm{O_2}$ 形成 μ-过氧桥，铁最终以 $\mathrm{Fe^{3+}}$ 收场，而它不再结合氧。血红素埋在珠蛋白的疏水口袋里遇不上伙伴，因而以 $\mathrm{Fe(II){-}O_2}$ 的形式可逆结合 $\mathrm{O_2}$（常被描述为 $\mathrm{Fe(III){-}O_2^{-}}$，一种类超氧化物的加合物，这正是远端组氨酸那根氢键有助之处）。缓慢的氧化在红细胞中仍然发生，生成**高铁血红蛋白**，而一种酶（高铁血红蛋白还原酶）把铁还原回 $\mathrm{Fe^{2+}}$。这个口袋还歧视一氧化碳：游离血红素结合 CO 的强度约为 $\mathrm{O_2}$ 的 20 000 倍，但在珠蛋白中这一偏好降到约 200 倍，部分原因是远端组氨酸与结合的 $\mathrm{O_2}$ 成氢键而不与 CO 成氢键。一氧化碳有毒，是因为即便降低后的这种偏好也足以让它占据血红素位点，并且由下文将描述的协同性使剩余的氧更难释放。

**肌红蛋白**（Mb）是一条 153 个残基的单多肽，折叠成八段 α 螺旋（A–H）环绕一个血红素。它在肌肉中储存氧气并加速其扩散，以双曲线结合 $\mathrm{O_2}$，$P_{50} \approx 2.8\ \mathrm{Torr}$（$0.37\ \mathrm{kPa}$）。**血红蛋白**（Hb）是一个四聚体 $\alpha_2\beta_2$，由两类链（141 与 146 个残基）组成，每条链的折叠都与肌红蛋白相似、各携一个血红素；在红细胞中、pH 7.4 下它有 $P_{50} \approx 26\ \mathrm{Torr}$（$3.5\ \mathrm{kPa}$）和一条 S 形曲线。（数值取自 Berg、Tymoczko、Gatto 与 Stryer 第 9 版；$1\ \mathrm{Torr} = 1\ \mathrm{mmHg} = 133.3\ \mathrm{Pa}$。）这个四聚体最宜看作由两个 $\alpha\beta$ 二聚体组成的二聚体：$\alpha_1\beta_1$ 接触面大而刚硬，而两个二聚体相接处的 $\alpha_1\beta_2$ 接触面正是协同性发生作用之处。

::: example 为什么血液需要血红蛋白 {#ex-capacity}
人血约含 $150\ \mathrm{g\,dm^{-3}}$ 血红蛋白（四聚体 $M \approx 64\,500\ \mathrm{g\,mol^{-1}}$）。$37\ \mathrm{^\circ C}$ 下 $\mathrm{O_2}$ 在血浆中的溶解度约为每 Torr $1.3\ \mu\mathrm{mol\,dm^{-3}}$。试比较完全饱和的血红蛋白所携带的氧与 $p_{\mathrm{O_2}} = 100\ \mathrm{Torr}$ 下溶解的氧。
::: solution
四聚体浓度为 $150/64\,500 = 2.33\times10^{-3}\ \mathrm{mol\,dm^{-3}}$，每个四聚体有四个血红素，故氧位点为 $9.30\ \mathrm{mmol\,dm^{-3}}$。$100\ \mathrm{Torr}$ 下溶解的氧为 $100 \times 1.3\ \mu\mathrm{mol\,dm^{-3}} = 0.13\ \mathrm{mmol\,dm^{-3}}$。两者之比为 $9.30/0.13 \approx 72$：血红蛋白把血液的携氧能力大约提高到七十倍。以体积计，每升 $9.30\ \mathrm{mmol}$ 的 $\mathrm{O_2}$ 在 $0\ \mathrm{^\circ C}$、$1\ \mathrm{atm}$（$22.4\ \mathrm{dm^3\,mol^{-1}}$）下约 $0.21\ \mathrm{dm^3}$——即人们熟悉的"每 100 mL 血液 20 mL 氧"。没有载体，心脏就得快上约七十倍地泵血。
:::
:::

## 协同性与希尔方程

把肌红蛋白与血红蛋白的饱和度对 $p_{\mathrm{O_2}}$ 作图，差别一目了然：肌红蛋白陡升，到 $25\ \mathrm{Torr}$ 已 $90\ \%$ 满；血红蛋白起步缓慢、仿佛不愿动弹，然后在 $20$–$40\ \mathrm{Torr}$ 附近陡升并趋于平缓。S 形意味着一个血红素上的结合提高了其余血红素的亲和力：**正协同**。1910 年，希尔（Archibald Hill）提出了一种简单的量化办法，那时还没有人知道血红蛋白有四个位点。

::: proposition 希尔方程 {#prop-hill}
设有 $n$ 个位点的蛋白质以全或无的方式结合配体，即只有空载形态 $\mathrm{P}$ 与满载形态 $\mathrm{PL}_n$ 大量存在：$\mathrm{P} + n\,\mathrm{L} \rightleftharpoons \mathrm{PL}_n$。则饱和分数为
$$
Y = \frac{[\mathrm{L}]^{n}}{K_{0.5}^{\,n} + [\mathrm{L}]^{n}}, \qquad \log\frac{Y}{1 - Y} = n\log[\mathrm{L}] - n\log K_{0.5},
$$ {#eq-hill}
其中 $K_{0.5}$ 是半饱和时的配体浓度（对气体即 $P_{50}$，半饱和分压）。对真实蛋白质，全或无假设从不精确；此时把方程用作经验式，把 $n$ 换成**希尔系数** $n_\mathrm{H}$，它定义为 $\log[Y/(1-Y)]$ 对 $\log[\mathrm{L}]$ 的**希尔图**在 $Y = \tfrac12$ 处的斜率。对有 $n$ 个相同位点的蛋白质，$n_\mathrm{H} = 1$ 表示无协同性，$1 < n_\mathrm{H} \le n$ 为正协同，$n_\mathrm{H} < 1$ 为负协同（或是不同亲和力位点的混合）。
:::

::: proof 由全或无平衡导出
写出总解离常数 $K = [\mathrm{P}][\mathrm{L}]^n/[\mathrm{PL}_n]$，它的单位是浓度的 $n$ 次幂；由 $K = K_{0.5}^{\,n}$ 定义 $K_{0.5}$。被占据的位点分数等于被占位点数 $n[\mathrm{PL}_n]$ 除以位点总数 $n([\mathrm{P}] + [\mathrm{PL}_n])$：
$$
Y = \frac{[\mathrm{PL}_n]}{[\mathrm{P}] + [\mathrm{PL}_n]} = \frac{[\mathrm{L}]^n/K}{1 + [\mathrm{L}]^n/K} = \frac{[\mathrm{L}]^n}{K_{0.5}^{\,n} + [\mathrm{L}]^n}.
$$
在 $[\mathrm{L}] = K_{0.5}$ 处分母两项相等且 $Y = \tfrac12$，这就为记号正了名。用 $Y$ 除以 $1 - Y = K_{0.5}^{\,n}/(K_{0.5}^{\,n} + [\mathrm{L}]^n)$ 得 $Y/(1-Y) = ([\mathrm{L}]/K_{0.5})^n$，取对数即得[[#eq-hill]]中斜率为 $n$ 的直线。$n = 1$ 时方程化为[[#eq-hyperbola]]的双曲线。由于中间形态 $\mathrm{PL}, \mathrm{PL}_2, \dots$ 总是以一定量存在，真实的结合没有全或无那么突兀，实测斜率小于位点数；可以证明（Cornish-Bowden，《Fundamentals of Enzyme Kinetics》）正协同时它绝不可能超过 $n$。
:::

人血红蛋白的 $n_\mathrm{H} \approx 2.8$，远不到四：它协同性很强但并不完美。血红蛋白的希尔图实际上只在中段是直的；在极低与极高饱和度处斜率回归 1，因为那里结合的几乎是一单纯一的构象群体。两条相互错开的渐近线分别度量低亲和力态与高亲和力态的亲和力——这正是下一节两态模型的一幅直观图景。

::: warning 希尔系数不是结合位点数 {#warn-hill}
人们很容易把 $n_\mathrm{H} = 2.8$ 读作"血红蛋白结合 2.8 个氧分子"，或把希尔方程当作机理来用。两者都错。血红蛋白结合四个 $\mathrm{O_2}$；希尔系数是*协同性的度量*——结合曲线在半饱和处的陡峭程度——它的最大可能值是位点数，只有在非物理的全或无极限中才能达到。$n_\mathrm{H} = 1$ 的蛋白质仍可有若干个位点（彼此独立的），而 $n_\mathrm{H} < 1$ 可能来自位点的不同质，而非真正的负协同。$K_{0.5}$ 也不是任何单独一步的解离常数：它是整条结合曲线的半饱和浓度。要弄清每一步做了什么，你需要一个状态明确的模型，比如下面这个。
:::

## 别构：齐变模型与序变模型

**别构**（希腊语 *allos*，其他；*stereos*，实体）指配体结合在空间上分离的另一个位点，通过构象改变传递，从而调节蛋白质在某一位点的活性。协同性是配体调节自身结合的特例（**同促**效应）；由别的分子来调节——对血红蛋白是质子、$\mathrm{CO_2}$ 与 2,3-BPG，对酶是途径的终产物——则是**异促**效应。血红蛋白中的结构基础由佩鲁茨（Max Perutz）查明：脱氧四聚体具有 **T**（紧张，tense）四级结构，受亚基间盐桥的牵制；含氧四聚体则为 **R**（松弛，relaxed）结构，其中一个 $\alpha\beta$ 二聚体相对于另一个转了约 $15^\circ$。

$\mathrm{O_2}$ 的结合如何拨动这个开关？脱氧血红蛋白中高自旋的 $\mathrm{Fe^{2+}}$ 太大，坐不进卟啉平面，而是朝近端组氨酸一侧偏离平面约 $0.4\ \text{Å}$，卟啉呈穹窿状。结合氧后铁变为低自旋、半径缩小、移入平面，把 His F8 连同整条 F 螺旋一起拉动。这一运动传到 $\alpha_1\beta_2$ 界面，T 结构的盐桥在那里被绷紧、最终断裂。一旦有足够多的亚基结合了氧，T 结构就不再是更稳定的一个，整个四聚体随即扣入 R——其中其余空置的血红素摆脱牵制，亲和力更高。

::: proposition 莫诺-怀曼-尚热（齐变）模型 {#prop-mwc}
假设由 $n$ 个相同亚基组成的寡聚蛋白存在于 R 与 T 两种构象中，且**所有亚基一起改变**（对称性守恒）；每个位点独立结合配体，R 态的解离常数为 $K_\mathrm{R}$，T 态为 $K_\mathrm{T}$；无配体时两态平衡，$L = [\mathrm{T}_0]/[\mathrm{R}_0]$（**别构常数**）。令 $\alpha = [\mathrm{L}]/K_\mathrm{R}$、$c = K_\mathrm{R}/K_\mathrm{T}$，则
$$
Y = \frac{\alpha(1 + \alpha)^{n-1} + Lc\alpha(1 + c\alpha)^{n-1}}{(1 + \alpha)^n + L(1 + c\alpha)^n},
$$ {#eq-mwc}
而处于 R 态的分子分数为 $(1 + \alpha)^n/[(1 + \alpha)^n + L(1 + c\alpha)^n]$。当 $L \gg 1$ 且 $c \ll 1$ 时结合具有协同性：蛋白质起初大多处于低亲和力的 T 态，被其配体拉入高亲和力的 R 态。异促激活剂通过降低 $L$ 起作用，抑制剂则通过抬高 $L$。
:::

::: proof 用结合多项式清点状态
令 $\mathrm{R}_i$ 为结合了 $i$ 个配体的 R 构象。各位点独立结合，而选定哪 $i$ 个位点被占的方式有 $\binom{n}{i}$ 种，故由平衡得 $[\mathrm{R}_i] = [\mathrm{R}_0]\binom{n}{i}\alpha^i$，其中每次微观结合贡献一个因子 $[\mathrm{L}]/K_\mathrm{R} = \alpha$。同样 $[\mathrm{T}_i] = [\mathrm{T}_0]\binom{n}{i}(c\alpha)^i = L[\mathrm{R}_0]\binom{n}{i}(c\alpha)^i$。由二项式定理，蛋白质总量为
$$
\sum_i\bigl([\mathrm{R}_i] + [\mathrm{T}_i]\bigr) = [\mathrm{R}_0]\bigl[(1 + \alpha)^n + L(1 + c\alpha)^n\bigr] = [\mathrm{R}_0]\,Z(\alpha),
$$
这就定义了**结合多项式** $Z$。被占位点数为 $\sum_i i\,([\mathrm{R}_i] + [\mathrm{T}_i])$，而由于 $\sum_i i\binom{n}{i}x^i = x\,\mathrm{d}(1 + x)^n/\mathrm{d}x = nx(1 + x)^{n-1}$，它等于 $[\mathrm{R}_0]\,n[\alpha(1 + \alpha)^{n-1} + Lc\alpha(1 + c\alpha)^{n-1}]$。除以位点总数 $n[\mathrm{R}_0]Z$ 即得[[#eq-mwc]]。（等价地，$Y = (\alpha/n)\,\mathrm{d}\ln Z/\mathrm{d}\alpha$，这是对任何结合多项式都成立的通用法则。）R 态分数就是 $Z$ 中的 R 部分除以 $Z$。校核：$L = 0$ 给出 $Y = \alpha/(1 + \alpha)$，即以 $K_\mathrm{R}$ 为常数的双曲线；$L \to \infty$ 给出以 $K_\mathrm{T}$ 为常数的双曲线；$c = 1$（两态亲和力相同）时无论 $L$ 为何值都得双曲线——协同性要求两态的亲和力不同。
:::

::: example 一个 MWC 四聚体 {#ex-mwc}
对 $L = 1.0\times10^4$、$c = 0.010$ 的四聚体，求 $\alpha = 0$、$1$、$10$ 和 $100$ 处处于 R 态的分子分数与饱和度 $Y$。在 $298\ \mathrm{K}$ 下，结合一个 R 位点与结合一个 T 位点的自由能差是多少？
::: solution
由 $Z = (1 + \alpha)^4 + 10^4(1 + 0.01\alpha)^4$：

- $\alpha = 0$：$Z = 1 + 10^4$；R 态分数 $= 1/10\,001 = 1.0\times10^{-4}$；$Y = 0$。
- $\alpha = 1$：$(2)^4 = 16$，$10^4(1.01)^4 = 10\,406$；R 态分数 $= 16/10\,422 = 1.5\times10^{-3}$；[[#eq-mwc]]的分子为 $1\cdot 2^3 + 10^4(0.01)(1.01)^3 = 8 + 103.0 = 111.0$，故 $Y = 111.0/10\,422 = 0.011$。
- $\alpha = 10$：$11^4 = 14\,641$，$10^4(1.1)^4 = 14\,641$——相等；R 态分数 $= 0.50$；分子 $= 10(1331) + 10^4(0.01)(10)(1.331) = 13\,310 + 1331 = 14\,641$，故 $Y = 14\,641/29\,282 = 0.50$。
- $\alpha = 100$：$101^4 = 1.0406\times10^8$，$10^4(2)^4 = 1.6\times10^5$；R 态分数 $= 0.998$；$Y = 0.989$。

在 $\alpha = 1$ 处——非协同的 R 态蛋白质此时应半满——这个四聚体只满 $1\ \%$，因为几乎所有分子都在 T 态；到 $\alpha = 100$ 时已满 $99\ \%$ 且几乎全为 R。半饱和需要 $[\mathrm{L}] = 10K_\mathrm{R}$，之所以如此，是因为这些数值满足 $Lc^{n/2} = 1$（[[#exr-mwc-symmetry]]），而在该处对希尔图数值求斜率得 $n_\mathrm{H} = 3.0$。单位点亲和力之比 $c = K_\mathrm{R}/K_\mathrm{T} = 0.01$ 对应 $\Delta\Delta G^\circ = -RT\ln c = (8.314)(298.15)\ln 100 = 11.4\ \mathrm{kJ\,mol^{-1}}$，即结合 R 更有利 $11.4\ \mathrm{kJ\,mol^{-1}}$。每结合一个配体，就把构象平衡按每个位点 $1/c$ 的因子推动——结合两个配体后 $L c^2 = 1$，R 与 T 数量相等。
:::
:::

齐变模型有一个对手。在科什兰（Daniel Koshland）、内梅希（George Némethy）与菲尔默（David Filmer）的**序变模型**（1966）中，每个亚基在结合配体时各自改变构象（诱导契合），已变的亚基通过界面改变邻近亚基的亲和力；允许两种形状亚基混存的杂合四聚体。序变模型能产生负协同也能产生正协同，这是齐变模型做不到的；而齐变模型用很少的参数就解释了异促效应物如何作用于整个寡聚体。血红蛋白在四级结构层次上大体以齐变方式行动，每种构象内部另有序变的三级变化；许多酶——如天冬氨酸转氨甲酰酶（被 CTP 抑制、被 ATP 激活）——与齐变模型符合得很好，也有些酶显示出只有序变模型才容许的负协同。

## 氧结合的调节分子

血红蛋白的氧亲和力不是固定属性；它被异促效应物连续地调节，而这些效应物都优先结合 T 态，因而抬高 $P_{50}$（曲线"右移"）。

**质子与波尔效应。** pH 降低会下调血红蛋白的氧亲和力。T 态中有几个基团——尤其是每条 β 链 C 端的 His146（其咪唑鎓与 Asp94 形成盐桥）以及 α 链的 N 端氨基——的 $\mathrm{p}K_\mathrm{a}$ 高于 R 态，因为它们的正电荷被邻近的负电基团稳定。因此质子结合 T 比结合 R 更牢，而由偶联原理（若 A 有利于 B，则 B 也有利于 A），结合氧会释放质子：
$$
\mathrm{HHb^{+}} + \mathrm{O_2} \rightleftharpoons \mathrm{HbO_2} + \mathrm{H^+}
$$
（按每个血红素书写，生理条件下每结合一个 $\mathrm{O_2}$ 约释放 0.5 个质子）。对人血，波尔系数 $\Delta\log P_{50}/\Delta\mathrm{pH}$ 约为 $-0.48$。代谢旺盛的组织产生酸（乳酸，以及来自 $\mathrm{CO_2}$ 的碳酸），所以恰恰在需要氧的地方氧更容易被释放；在肺中则发生相反的过程。

**二氧化碳。** 大部分 $\mathrm{CO_2}$ 以碳酸氢盐形式运输，由红细胞中的碳酸酐酶催化 $\mathrm{CO_2 + H_2O \rightleftharpoons HCO_3^- + H^+}$ 生成，其质子对波尔效应有贡献；碳酸氢盐缓冲系本身见[[biochemistry/water-noncovalent#ex-bicarbonate]]。另有一部分直接与球蛋白链上不带电的 N 端氨基反应生成**氨基甲酸酯**（carbamate），
$$
\mathrm{R{-}NH_2 + CO_2 \rightleftharpoons R{-}NH{-}COO^- + H^+},
$$
即胺的孤对进攻 $\mathrm{CO_2}$ 的亲电碳。带负电的氨基甲酸根形成额外的盐桥稳定 T 态，所以 $\mathrm{CO_2}$ 既通过其质子、也通过自身降低氧亲和力。

**2,3-二磷酸甘油酸。** 除去所有效应物的血红蛋白结合氧几乎与肌红蛋白一样紧（$P_{50}$ 约 $1\ \mathrm{Torr}$，Berg 等）。红细胞含有 2,3-二磷酸甘油酸（2,3-BPG）——糖酵解的一种副产物——浓度与血红蛋白相当。每个分子带约五个负电荷，结合在 T 四聚体两条 β 链之间的中心空腔中，由一圈正电基团（每条 β 链的 His2、Lys82 与 His143）抓住；R 态的空腔太窄，容不下它。通过稳定 T 态，2,3-BPG 把 $P_{50}$ 抬高到实测的 $26\ \mathrm{Torr}$。适应高原时其水平上升，使曲线右移、有利于卸氧。

**胎儿血红蛋白。** 胎儿血红蛋白 $\alpha_2\gamma_2$ 的 γ 链以丝氨酸取代 His143，使 BPG 位点上少掉两个正电荷。它结合 2,3-BPG 更弱，T 态少受稳定，因而氧亲和力更高（胎儿血液中 $P_{50}$ 约 $19\ \mathrm{Torr}$）——胎儿正是借此经胎盘从母血中汲取氧气（[[#exr-fetal]]）。

::: example 工作肌肉中的波尔效应 {#ex-bohr}
工作肌肉中毛细血管 pH 从 $7.4$ 降到约 $7.2$。用波尔系数 $-0.48$，求新的 $P_{50}$，以及肺（$100\ \mathrm{Torr}$，pH $7.4$，$P_{50} = 26\ \mathrm{Torr}$）与肌肉（$20\ \mathrm{Torr}$，pH $7.2$）之间释放的容量分数，取 $n_\mathrm{H} = 2.8$。
::: solution
$\Delta\log P_{50} = (-0.48)(7.2 - 7.4) = +0.096$，故 $P_{50} = 26 \times 10^{0.096} = 32.4\ \mathrm{Torr}$。在肌肉处，$(20/32.4)^{2.8} = 0.258$，$Y = 0.258/1.258 = 0.205$。血液到达时 $Y = 0.978$（见[[#ex-o2-delivery]]），故释放 $0.978 - 0.205 = 0.77$ 的容量，而恒定 pH 下为 $0.65$。pH 只变化 0.2 个单位就使供氧增加五分之一，而氧压梯度毫无变化：别构效应物读取组织的代谢状态并调节载体。
:::
:::

## 开关失灵时：镰状细胞血红蛋白

别构机器中每一个残基的重要性，最触目惊心不过地由**镰状细胞贫血症**显示出来。血红蛋白 S 中，β 链第 6 位的谷氨酸被缬氨酸取代（β Glu6Val），这是 β-珠蛋白基因中单个碱基改变的结果（[[biochemistry/nucleic-acids#def-code]]）。新的缬氨酸位于表面，造出一块疏水补丁。在脱氧（T）态，这块补丁恰好嵌进相邻四聚体上互补的疏水口袋（由 β 链的 Phe85 与 Leu88 形成），于是脱氧-HbS 聚合成纤维，把红细胞扭成镰刀状、堵塞毛细血管并缩短细胞的寿命。含氧-HbS 不聚合，因为 R 结构中口袋被藏了起来。因此本病是一种构象平衡的失调：任何提高细胞中脱氧血红蛋白分数的因素都有利于聚合，而提高 HbS 的氧亲和力或增加胎儿血红蛋白（它不参与共聚合）的策略，正是要移动这一平衡。携带一个基因拷贝的人（镰状细胞性状）对恶性疟原虫（*Plasmodium falciparum*）疟疾有部分抵抗力，这就是该等位基因在疟疾流行地区常见的原因。

## 后续内容

本章的两幅图景——饱和曲线与两态开关——在整个生物化学中反复出现。服从简单米氏动力学的酶，其速率曲线正是[[#eq-hyperbola]]那样的双曲线，只是 $K_\mathrm{M}$ 扮演着 $K_\mathrm{d}$ 的角色；而别构酶有 S 形曲线，要用希尔方程与 MWC 方程分析（[[biochemistry/enzymes#prop-mm]]以及[[biochemistry/enzymes]]的调节一节）。[[biochemistry/glycolysis-citric-acid]]中糖酵解与柠檬酸循环的不可逆步骤受别构效应物控制，2,3-BPG 本身就出自糖酵解的一条旁路。受体占据、激动剂与拮抗剂的逻辑、以及药物设计中的结合自由能在[[medicinal-chemistry/drug-binding]]中展开。结合多项式的统计力学含义——对配位状态求和的配分函数——是[[statistical-thermodynamics/partition-function]]的主题，而触发 T→R 转变的铁的自旋态变化则是[[coordination-chemistry]]的晶体场化学。

::: history
生理学先于化学而来。1904 年，克里斯蒂安·玻尔（Christian Bohr）、哈塞尔巴尔赫（Karl Hasselbalch）与克罗格（August Krogh）证明二氧化碳降低血液的氧亲和力，这一效应后来以玻尔命名。希尔（Archibald Vivian Hill）1910 年为拟合 S 形氧结合曲线提出了他的经验方程；1925 年，阿代尔（Gilbert Adair）由渗透压测量证明血红蛋白是摩尔质量约 $68\,000\ \mathrm{g\,mol^{-1}}$ 的四聚体，并写下了以他命名的四步结合方程。鲍林（Linus Pauling）、伊塔诺（Harvey Itano）、辛格（S. Jonathan Singer）与韦尔斯（Ibert Wells）1949 年用电泳证明镰状细胞血红蛋白与正常蛋白质的电荷不同，称其为"分子病"；英格拉姆（Vernon Ingram）1956–57 年把这一差别定位为单个谷氨酸到缬氨酸的改变。佩鲁茨（Max Perutz）历经二十多年的工作，于 1960 年得到 $5.5\ \text{Å}$ 分辨率的马氧合血红蛋白结构（比肯德鲁（John Kendrew）的肌红蛋白晚两年），并与肯德鲁分享 1962 年诺贝尔化学奖；他 1970 年提出的立体化学机理把铁的移动与四级结构的变化联系起来。莫诺（Jacques Monod）、怀曼（Jeffries Wyman）与尚热（Jean-Pierre Changeux）的齐变模型发表于 1965 年，科什兰（Daniel Koshland）、内梅希（George Némethy）与菲尔默（David Filmer）的序变模型发表于 1966 年；1967 年，贝内施（Reinhold Benesch）与鲁思·贝内施（Ruth Benesch）、以及独立发现的沙努坦（Arnold Chanutin）与柯尔尼什（Rosa Curnish），发现 2,3-BPG 调节红细胞中血红蛋白的氧亲和力。
:::

::: summary
- 单一位点的结合平衡有 $\theta = [\mathrm{L}]/(K_\mathrm{d} + [\mathrm{L}])$：$[\mathrm{L}] = K_\mathrm{d}$ 时半饱和，从 10 % 到 90 % 跨度 81 倍，且 $\Delta_\mathrm{bind}G^\circ = RT\ln(K_\mathrm{d}/c^\circ)$，亲和力每十倍约 $5.7\ \mathrm{kJ\,mol^{-1}}$。
- 肌红蛋白与血红蛋白在由近端组氨酸固定的五配位 $\mathrm{Fe^{2+}}$ 血红素上结合 $\mathrm{O_2}$；珠蛋白防止氧化并降低对 CO 的偏好。
- 肌红蛋白以双曲线结合（$P_{50} \approx 2.8\ \mathrm{Torr}$）；血红蛋白是 $\alpha_2\beta_2$ 四聚体，协同结合（$P_{50} \approx 26\ \mathrm{Torr}$，$n_\mathrm{H} \approx 2.8$），向工作肌肉输送的氧约为非协同载体的两倍。
- 希尔系数度量结合曲线在半饱和处的陡峭程度；它至多是位点数，不是化学计量。
- MWC 模型中，对称的寡聚体在 T（低亲和力）与 R（高亲和力）之间切换；协同性要求 $L \gg 1$ 且 $c \ll 1$，异促效应物通过改变 $L$ 起作用。
- 质子（波尔效应）、$\mathrm{CO_2}$（碳酸氢盐与氨基甲酸酯）与 2,3-BPG 稳定 T 并抬高 $P_{50}$，于是氧在组织活跃处被释放；胎儿血红蛋白结合 2,3-BPG 弱，亲和力更高。
- 镰状细胞血红蛋白（β Glu6Val）在 T 态聚合，是一种构象平衡的疾病。
:::

::: exercise 肌红蛋白的饱和度 {level=1 check="0.915"}
肌红蛋白 $P_{50} = 2.8\ \mathrm{Torr}$。$p_{\mathrm{O_2}} = 30\ \mathrm{Torr}$ 时有多大分数的位点被占据？（$Y$ 保留三位有效数字输入。）
::: solution
$Y = p/(P_{50} + p) = 30/(2.8 + 30) = 30/32.8 = 0.915$。肌红蛋白在这个压力下已九成以上饱和，而血红蛋白此时只约 60 % 满（见后面的习题），这就是肌肉中氧从血红蛋白流向肌红蛋白的原因。
:::
:::

::: exercise 微摩尔级结合剂的自由能 {level=1 check="-34.2"}
某激素与受体的解离常数为 $K_\mathrm{d} = 1.0\ \mu\mathrm{mol\,dm^{-3}}$（$298.15\ \mathrm{K}$）。计算标准结合吉布斯自由能（标准浓度 $1\ \mathrm{mol\,dm^{-3}}$）。（$\Delta_\mathrm{bind}G^\circ$ 以 $\mathrm{kJ\,mol^{-1}}$ 输入，保留三位有效数字。）
::: solution
$\Delta_\mathrm{bind}G^\circ = RT\ln(K_\mathrm{d}/c^\circ) = (8.314)(298.15)\ln(1.0\times10^{-6}) = -34\,246\ \mathrm{J\,mol^{-1}} = -34.2\ \mathrm{kJ\,mol^{-1}}$。与[[#ex-nanomolar]]中纳摩尔级的结合剂（$-45.7\ \mathrm{kJ\,mol^{-1}}$）相比，差值为 $11.4\ \mathrm{kJ\,mol^{-1}} = 2 \times RT\ln 10$：从 $1\ \mu\mathrm{mol\,dm^{-3}}$ 到 $10\ \mathrm{nmol\,dm^{-3}}$ 是亲和力的一百倍，即两个十倍因子，每个值 $5.71\ \mathrm{kJ\,mol^{-1}}$。
:::
:::

::: exercise 百分之九十的占有率 {level=1 check="45"}
某单一位点蛋白质的 $K_\mathrm{d} = 5.0\ \mu\mathrm{mol\,dm^{-3}}$。多大的游离配体浓度给出 $\theta = 0.90$？（浓度以 $\mu\mathrm{mol\,dm^{-3}}$ 输入。）
::: solution
整理[[#eq-hyperbola]]得 $[\mathrm{L}] = K_\mathrm{d}\,\theta/(1 - \theta) = 5.0 \times 0.90/0.10 = 45\ \mu\mathrm{mol\,dm^{-3}}$，即九倍 $K_\mathrm{d}$。同样，$\theta = 0.10$ 需要 $K_\mathrm{d}/9$，这就是正文所说的 81 倍跨度。
:::
:::

::: exercise 30 Torr 下的血红蛋白 {level=2 check="0.599"}
用希尔方程（$P_{50} = 26\ \mathrm{Torr}$，$n_\mathrm{H} = 2.8$）计算 $30\ \mathrm{Torr}$ 下血红蛋白的饱和度。（$Y$ 保留三位有效数字输入。）
::: solution
$(30/26)^{2.8} = \exp[2.8\ln(1.1538)] = \exp(0.4007) = 1.493$，故 $Y = 1.493/2.493 = 0.599$。压力只比 $P_{50}$ 高 $4\ \mathrm{Torr}$，饱和度就从 0.50 升到 0.60；若是 $P_{50}$ 相同的双曲线，则为 $30/56 = 0.536$。$P_{50}$ 附近的陡峭正是协同性的含义。
:::
:::

::: exercise 由两点求希尔系数 {level=2 check="2.83"}
一份血红蛋白样品在 $15\ \mathrm{Torr}$ 时饱和 20 %，在 $40\ \mathrm{Torr}$ 时饱和 80 %。假设这两点之间希尔方程成立，求 $n_\mathrm{H}$ 与 $P_{50}$。（$n_\mathrm{H}$ 保留三位有效数字输入。）
::: hint
写出两点处的 $\log[Y/(1-Y)]$ 并相减。
:::
::: solution
$Y/(1-Y)$ 在 $15\ \mathrm{Torr}$ 为 $0.25$，在 $40\ \mathrm{Torr}$ 为 $4$。由[[#eq-hill]]，$n_\mathrm{H} = \Delta\log[Y/(1-Y)]/\Delta\log p = \log(4/0.25)/\log(40/15) = 1.2041/0.4260 = 2.83$。由于两点关于 $Y = \tfrac12$ 对称（$0.25 \times 4 = 1$），$P_{50}$ 就是两者的几何平均：$\sqrt{15 \times 40} = 24.5\ \mathrm{Torr}$。
:::
:::

::: exercise 配体耗竭 {level=2 #exr-depletion check="0.730"}
一位点蛋白质（$K_\mathrm{d} = 0.10\ \mu\mathrm{mol\,dm^{-3}}$）与其配体混合，两者的*总*浓度都是 $1.0\ \mu\mathrm{mol\,dm^{-3}}$。求复合物的浓度，并把饱和分数与误用总配体代入[[#eq-hyperbola]]所得的值比较。（$[\mathrm{PL}]$ 以 $\mu\mathrm{mol\,dm^{-3}}$ 输入，保留三位有效数字。）
::: hint
令 $[\mathrm{P}] = P_\mathrm{t} - x$、$[\mathrm{L}] = L_\mathrm{t} - x$，其中 $x = [\mathrm{PL}]$，解二次方程。
:::
::: solution
由 $K_\mathrm{d} = (P_\mathrm{t} - x)(L_\mathrm{t} - x)/x$ 得 $x^2 - (P_\mathrm{t} + L_\mathrm{t} + K_\mathrm{d})x + P_\mathrm{t}L_\mathrm{t} = 0$，其物理根为
$$
x = \frac{(P_\mathrm{t} + L_\mathrm{t} + K_\mathrm{d}) - \sqrt{(P_\mathrm{t} + L_\mathrm{t} + K_\mathrm{d})^2 - 4P_\mathrm{t}L_\mathrm{t}}}{2} = \frac{2.10 - \sqrt{4.41 - 4.00}}{2} = \frac{2.10 - 0.6403}{2} = 0.730\ \mu\mathrm{mol\,dm^{-3}}.
$$
故 $\theta = 0.73$，游离配体只有 $0.27\ \mu\mathrm{mol\,dm^{-3}}$（校核：$0.27 \times 0.27/0.73 = 0.10$）。把总配体代入双曲线会得到 $1.0/1.1 = 0.91$，这是一个过高估计，因为加入的配体有四分之一已被蛋白质拉出溶液。双曲线只对*游离*配体成立，而游离配体只有在 $P_\mathrm{t} \ll K_\mathrm{d}$ 或 $L_\mathrm{t} \gg P_\mathrm{t}$ 时才等于总配体；强结合的测量必须用这个二次方程。
:::
:::

::: exercise 胎儿血红蛋白与母体血红蛋白 {level=3 #exr-fetal check="18.3"}
胎盘中，母血与胎血在约 $30\ \mathrm{Torr}$ 下交换氧气。取母血 $P_{50} = 26\ \mathrm{Torr}$、胎血 $19\ \mathrm{Torr}$，两者 $n_\mathrm{H} = 2.8$。(a) 计算 $30\ \mathrm{Torr}$ 下两者的饱和度及其百分点之差。(b) 解释这一差别的分子根源。(c) 为什么一个像肌红蛋白那样结合（双曲线，$P_{50} = 3\ \mathrm{Torr}$）的胎儿氧载体会是糟糕的设计？（(a) 的差以百分点输入，保留三位有效数字。）
::: hint
两次使用希尔方程；对 (c)，想想胎儿组织中的卸氧。
:::
::: solution
(a) 母血：$Y = 0.599$（同上一道希尔方程习题）。胎血：$(30/19)^{2.8} = \exp[2.8\ln(1.5789)] = \exp(1.2785) = 3.591$，故 $Y = 3.591/4.591 = 0.782$。差为 $78.2 - 59.9 = 18.3$ 个百分点：在相同氧压下，胎儿血红蛋白保持的氧明显更多，于是氧从母体的血红蛋白流向胎儿的血红蛋白，直到压力相等。
(b) 胎儿血红蛋白（$\alpha_2\gamma_2$）的 γ 链在 2,3-BPG 位点以丝氨酸取代 β 链的 His143。中心空腔中少了两个正电荷，2,3-BPG 结合 T 态更弱，T 相对于 R 少受稳定（有效上 $L$ 变小），曲线左移。没有 2,3-BPG 时两种血红蛋白的亲和力相近：这一差别是异促调节，而不是不同的血红素。
(c) 亲和力只有在氧还能被释放时才有用。若是 $P_{50} = 3\ \mathrm{Torr}$ 的双曲线，胎儿载体在胎盘会完全装载，但在胎儿组织的 $20$–$25\ \mathrm{Torr}$ 下仍约饱和 85–90 %（比较[[#ex-o2-delivery]]中的肌红蛋白），几乎不供氧。真正的设计是适度的左移——足以在胎盘赢得交换——同时保持 S 形，使氧能在组织中被交出。
:::
:::

::: exercise 对称 MWC 蛋白的半饱和 {level=3 #exr-mwc-symmetry}
(a) 由[[#eq-mwc]]证明：若 $Lc^{n/2} = 1$，则 MWC 蛋白质在 $\alpha = c^{-1/2}$ 处恰好半饱和，且此时恰好一半分子处于 R 态。(b) 用 $L = 10^4$、$c = 0.01$、$n = 4$ 验证。(c) 用语言解释：为什么抬高 $L$ 的异促抑制剂会把半饱和点移到更高的配体浓度。
::: hint
代入 $\alpha = c^{-1/2}$，于是 $c\alpha = c^{1/2}$，并把 $(1 + \alpha)^n$ 提出因子 $c^{-n/2}$，与 $L(1 + c\alpha)^n$ 比较。
:::
::: solution
(a) 当 $\alpha = c^{-1/2}$ 时，$1 + \alpha = c^{-1/2}(c^{1/2} + 1) = c^{-1/2}(1 + c\alpha)$。于是 $(1 + \alpha)^n = c^{-n/2}(1 + c\alpha)^n = L(1 + c\alpha)^n$（当 $Lc^{n/2} = 1$）：结合多项式的 R 项与 T 项相等，故一半分子为 R。分子部分，$\alpha(1 + \alpha)^{n-1} = c^{-1/2}\cdot c^{-(n-1)/2}(1 + c\alpha)^{n-1} = c^{-n/2}(1 + c\alpha)^{n-1}$，而 $Lc\alpha(1 + c\alpha)^{n-1} = c^{-n/2}\,c\,c^{-1/2}(1 + c\alpha)^{n-1} = c^{-n/2}c^{1/2}(1 + c\alpha)^{n-1}$。因此分子为 $c^{-n/2}(1 + c\alpha)^{n-1}(1 + c^{1/2})$，分母为 $2c^{-n/2}(1 + c\alpha)^n = 2c^{-n/2}(1 + c\alpha)^{n-1}(1 + c^{1/2})$，故 $Y = \tfrac12$。
(b) $Lc^{2} = 10^4 \times 10^{-4} = 1$，且 $c^{-1/2} = 10$：$\alpha = 10$ 处半饱和且 R 态分数为 0.50，与[[#ex-mwc]]中所见一致。
(c) 优先结合 T 的抑制剂抬高有效的 $L$，因此必须结合更多的配体分子——每个都贡献有利于 R 的因子 $1/c$——才能使 R 与 T 的群体平衡。曲线因此移向更高的配体浓度（$L$ 适度增大时还略变陡）。2,3-BPG 就是这样把血红蛋白的 $P_{50}$ 从约 $1\ \mathrm{Torr}$ 抬高到 $26\ \mathrm{Torr}$ 的。
:::
:::

::: exercise 读希尔图 {level=2 check="2.8"}
协同性一节中的希尔图显示血红蛋白饱和度中央区域的合成数据。读出希尔图中最小二乘直线的斜率（拖动一个数据点，看看它有多灵敏），并由 $x$ 截距求 $P_{50}$。（$n_\mathrm{H}$ 输入到小数点后一位。）
::: solution
拟合直线的斜率为 $2.77$，四舍五入为 $2.8$，在 $x = 1.41$ 附近穿过 $y = 0$；由于 $Y = \tfrac12$ 使 $\log[Y/(1-Y)] = 0$，$\log_{10}P_{50} = 1.41$，故 $P_{50} \approx 26\ \mathrm{Torr}$。（这些数据由 $n_\mathrm{H} = 2.8$、$P_{50} = 26\ \mathrm{Torr}$ 加小扰动生成。）真实血红蛋白数据中这条直线只在曲线中段成立；饱和度低于约 5 %、高于约 95 % 时斜率弯回 1，用整段数据拟合直线会低估协同性。
:::
