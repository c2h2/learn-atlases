一个营养良好的成年人身上大约带着 $0.4\ \mathrm{kg}$ 糖原和 $10$–$15\ \mathrm{kg}$ 三酰甘油。糖原只够维持一天的普通生活；脂肪则够维持一个月以上。候鸟靠脂肪飞越海洋，冬熊靠它睡过整个冬天，耗尽肌糖原的马拉松跑者则靠氧化它继续跑下去——虽然慢一些。脂肪是比糖更好的储存形式，因为它的碳更还原——每个碳有更多电子可以交给氧气——也因为它是无水储存的。氨基酸则正好相反：身体根本没有氨基酸库，不被用于蛋白质合成的那部分会被分解，碳骨架或烧掉或变成葡萄糖，氮则变成尿素。

本章补全代谢的地图。我们将把脂肪酸从脂肪细胞一路追到线粒体、穿过 β-氧化，用[[biochemistry/oxidative-phosphorylation#prop-atp-stoich]]的 P/O 比给它算账，解释酮体，然后讲脂肪酸合成——它不是 β-氧化的逆过程，而是一条有自己酶系、载体与区室的独立途径。接着转向氨基酸：磷酸吡哆醛介导的转氨基、氨的释放，以及尿素循环——人类发现的第一个代谢循环。最后讲本课程各条途径如何由激素和几个关键调控分子跨组织整合起来。热力学工具来自[[biochemistry/bioenergetics]]，控制逻辑来自[[biochemistry/glycolysis-citric-acid#def-control]]。本章仅供教学，不是医疗或营养建议；凡出现疾病之处，都只用来说明机理。

## 脂肪酸的动员与活化

脂肪组织中的三酰甘油被脂酶——脂肪三酰甘油脂酶、激素敏感性脂酶与单酰甘油脂酶——水解为甘油与三个脂肪酸。脂解由胰高血糖素与肾上腺素开启：它们升高环腺苷酸、激活蛋白激酶 A；胰岛素则将其关闭。脂肪酸水溶性差，在血液中结合血清清蛋白运输；甘油去肝脏，由甘油激酶与 3-磷酸甘油脱氢酶把它变成磷酸二羟丙酮——一个既是糖酵解又是糖异生的中间产物。膳食三酰甘油则以另一种方式到达组织：包装在脂蛋白颗粒（乳糜微粒）里，但殊途同归：游离脂肪酸进入细胞。

在细胞内，脂肪酸首先被线粒体外膜上的脂酰辅酶A合成酶**活化**为其辅酶A硫酯：
$$
\mathrm{RCOO^-} + \mathrm{CoA} + \mathrm{ATP} \rightarrow \mathrm{RCO{-}SCoA} + \mathrm{AMP} + \mathrm{PP_i}, \qquad \mathrm{PP_i} + \mathrm{H_2O} \rightarrow 2\,\mathrm{P_i} .
$$
羧酸根进攻 ATP 的 α-磷，生成**脂酰腺苷酸**（一个混合酸酐）与焦磷酸；随后辅酶A的巯基把 AMP 取代下来。这个反应本身接近平衡，但焦磷酸酶对焦磷酸的快速水解使总活化以两个磷酸酐键为代价变成不可逆——即[[biochemistry/bioenergetics]]中的腺苷酰基转移偶联。

脂酰辅酶A不能跨过线粒体内膜。**肉碱穿梭**改为搬运脂酰基：外膜上的肉碱棕榈酰转移酶 I（CPT I）把它转给肉碱的羟基，一个转位酶把脂酰肉碱与游离肉碱交换着运入基质，CPT II 再把脂酰基转回辅酶A。CPT I 是脂肪酸氧化的闸门，它被**丙二酰辅酶A**——脂肪酸合成的第一个中间产物——抑制：靠一个分子，细胞就不会去氧化自己正在合成的脂肪酸。

## β-氧化

在基质中，脂酰辅酶A每次被截短两个碳，靠的是一组四个反应的循环序列；它叫 β-氧化，因为碳链被剪断之前，β-碳（C3）先被氧化成酮：

1. **脂酰辅酶A脱氢酶**从 α-与 β-碳上各移走一个氢，生成 *trans*-$\Delta^2$-烯酰辅酶A。电子交给酶结合的 FAD，再经电子转移黄素蛋白（ETF）交给呼吸链中的泛醌——所以这一步每个值 $1.5$ 个 ATP，与琥珀酸一样。
2. **烯酰辅酶A水合酶**把水加到双键上，给出 L-3-羟基脂酰辅酶A。双键与硫酯羰基共轭，使这是一个 Michael 型加成：氢氧根（活化的水）进攻 β-碳，烯醇盐在 α-碳质子化。
3. **3-羟基脂酰辅酶A脱氢酶**用 $\mathrm{NAD^+}$ 把仲醇氧化成酮，给出 3-酮脂酰辅酶A与 NADH。
4. **β-酮硫解酶**用第二个辅酶A裂解 β-酮硫酯：活性位点半胱氨酸进攻酮羰基，C2–C3 键断裂，α-碳以乙酰辅酶A的烯醇盐形式离去——一次**逆 Claisen 缩合**。产物是乙酰辅酶A和一个短两个碳的脂酰辅酶A，先接在酶上，再转交给辅酶A。

这一序列——脱氢成烯、加水、醇脱氢成酮——与柠檬酸循环中琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸那一段（[[biochemistry/glycolysis-citric-acid]]）完全相同，只不过用在一长条链上。它是氧化羰基旁 $\mathrm{CH_2}$ 的通用策略。

::: proposition 饱和脂肪酸的 ATP 产量 {#prop-beta-yield}
含偶数 $n$ 个碳的无支链饱和脂肪酸完全氧化（在细胞质中活化、在线粒体中氧化）要经过 $n/2 - 1$ 轮 β-氧化，生成 $n/2$ 个乙酰辅酶A、$n/2 - 1$ 个 $\mathrm{FADH_2}$（以 ETF 还原的泛醇形式）与 $n/2 - 1$ 个 NADH。按 NADH 的 P/O 比 $2.5$、$\mathrm{FADH_2}$ 的 $1.5$，以及每个在柠檬酸循环中氧化的乙酰辅酶A值 $10$ 个 ATP 当量计算，净产量为
$$
Y(n) = 4\left(\frac n2 - 1\right) + 10\cdot\frac n2 - 2 = 7n - 6\ \ \text{ATP} ,
$$ {#eq-beta-yield}
所以棕榈酸（$n = 16$）产 $106$ 个 ATP，硬脂酸（$n = 18$）产 $120$ 个。$-2$ 是活化花掉的两个磷酸酐键。这一结果假定线粒体紧密偶联、且取常规 P/O 比；$\Delta p$ 因质子渗漏而损失多少，真实产量就低多少。
:::

::: proof 数轮数与载体
每轮把 $\mathrm{C}_n$-脂酰辅酶A变成 $\mathrm{C}_{n-2}$-脂酰辅酶A加一个乙酰辅酶A，并伴随一个 $\mathrm{FADH_2}$（第 1 步）与一个 NADH（第 3 步）：
$$
\mathrm{C}_n\text{-acyl-CoA} + \mathrm{FAD} + \mathrm{NAD^+} + \mathrm{H_2O} + \mathrm{CoA} \rightarrow \mathrm{C}_{n-2}\text{-acyl-CoA} + \mathrm{FADH_2} + \mathrm{NADH} + \mathrm{H^+} + \mathrm{acetyl\text{-}CoA} .
$$
从 $n$ 个碳出发，最后一轮作用于四碳的丁酰辅酶A，生成*两个*乙酰辅酶A，所以 $n/2 - 1$ 轮生成 $n/2$ 个乙酰辅酶A。每轮经载体得 $1.5 + 2.5 = 4$ 个 ATP；每个乙酰辅酶A在循环中值 $3 \times 2.5 + 1.5 + 1 = 10$ 个 ATP 当量（[[biochemistry/glycolysis-citric-acid#prop-tca]]）；活化花 $2$ 个。相加得 $Y = 4(n/2 - 1) + 5n - 2 = 2n - 4 + 5n - 2 = 7n - 6$。$n = 16$ 时 $112 - 6 = 106$；$n = 18$ 时 $126 - 6 = 120$。
:::

::: example 脂肪与葡萄糖作燃料的比较 {#ex-palmitate}
(a) 比较棕榈酸（$M = 256.42\ \mathrm{g\,mol^{-1}}$）与葡萄糖（$M = 180.16\ \mathrm{g\,mol^{-1}}$，32 个 ATP）每个碳原子、每克产生的 ATP。(b) 从氧化数解释这一差别。(c) 为什么脂肪作为*储存*形式的优势比 (a) 显示的还要大？
::: solution
(a) 棕榈酸根：每碳 $106/16 = 6.6$ 个 ATP，每克 $106/256.42 = 0.413$ mol ATP。葡萄糖：每碳 $32/6 = 5.3$ 个 ATP，每克 $32/180.16 = 0.178$ mol ATP。按质量计，脂肪酸的 ATP 价值是葡萄糖的 $0.413/0.178 = 2.3$ 倍。

(b) 葡萄糖中碳的平均氧化数为 0；棕榈酸 $\mathrm{C_{16}H_{32}O_2}$ 中是 $(2\times2 - 32)/16 = -1.75$。所以脂肪酸的每个碳比葡萄糖的每个碳大约多 $1.75$ 个电子可以交给氧，而 ATP 产量本质上就是送进呼吸链的电子数。葡萄糖已经"烧掉一部分"了；它的氧原子只增加质量，不增加还原力。

(c) 糖原是带着水储存的，大约含自身质量两倍的水（[[biochemistry/carbohydrates-lipids]]），而三酰甘油以近乎无水的小滴储存。所以按储存组织每克计，脂肪在 ATP 意义上的优势约为 $2.3 \times 3 \approx 7$，接近由燃烧热除以水合倍数得到的约六倍（$37$ 对 $17\ \mathrm{kJ\,g^{-1}}$）。如果人的脂肪库改以糖原形式保存，其重量要增加好几倍。
:::

### 不饱和与奇数链脂肪酸

天然不饱和脂肪酸带 *cis* 双键，位置常常是奇数（油酸是 *cis*-$\Delta^9$）。三轮 β-氧化之后，油酰辅酶A变成 *cis*-$\Delta^3$-烯酰辅酶A，而水合酶对它无能为力。**烯酰辅酶A异构酶**把双键移到 *trans*-$\Delta^2$ 位置，β-氧化继续——只是那一轮的脂酰辅酶A脱氢步骤被跳过，于是少生成一个 $\mathrm{FADH_2}$：油酸产 $120 - 1.5 = 118.5$ 个 ATP。双键位于偶数位置的多不饱和脂肪酸还需要一个 2,4-二烯酰辅酶A还原酶，它消耗 NADPH。

奇数碳的脂肪酸最后剩下**丙酰辅酶A**。它被需生物素的丙酰辅酶A羧化酶羧化为 D-甲基丙二酰辅酶A，差向异构为 L 型，再由甲基丙二酰辅酶A变位酶重排——这是人体需要辅酶 $\mathrm{B_{12}}$ 的两种酶之一，该辅酶利用其 Co–C 键均裂产生的碳自由基——变成琥珀酰辅酶A。琥珀酰辅酶A是柠檬酸循环的中间产物，可以变成草酰乙酸，所以奇数链脂肪酸的最后三个碳不同于乙酰辅酶A，能够贡献给葡萄糖的合成。

### 酮体

禁食时的肝脏恰好在 β-氧化开得最快的时候把草酰乙酸抽调去糖异生。于是乙酰辅酶A积累到柠檬酸循环接纳不了的程度，肝脏便把它转化为**酮体**：两个乙酰辅酶A缩合成乙酰乙酰辅酶A（硫解酶倒转运行），第三个加进来生成 3-羟基-3-甲基戊二酰辅酶A（HMG-CoA，由 HMG 辅酶A合酶催化），HMG-CoA 裂解酶释放**乙酰乙酸**，其中一部分被 NADH 还原为 **D-3-羟基丁酸**；少量乙酰乙酸自发脱羧为**丙酮**。肝脏自己不能利用酮体，因为它缺少活化乙酰乙酸的酶；它把酮体当作水溶性燃料输出。心肌与骨骼肌很乐意使用它们；禁食数日后，大脑的大部分能量也来自它们，从而降低对葡萄糖的需求，省下本要分解去糖异生的肌肉蛋白。

::: definition 酮体与酮体生成 {#def-ketone}
**酮体**是乙酰乙酸、D-3-羟基丁酸与丙酮，由乙酰辅酶A在肝脏线粒体中生成（**酮体生成**），其条件是脂肪酸氧化速率超过柠檬酸循环的容量——典型原因是草酰乙酸被转去糖异生。在肝外组织，乙酰乙酸由琥珀酰辅酶A:3-氧酸辅酶A转移酶活化为乙酰乙酰辅酶A，代价是本来要由琥珀酰辅酶A生成的那一个 GTP，再由硫解酶把它切成两个乙酰辅酶A。乙酰乙酸（$\mathrm{p}K_\mathrm{a} \approx 3.6$）与 3-羟基丁酸（$\mathrm{p}K_\mathrm{a} \approx 4.7$）都是羧酸，在生理 pH 下几乎完全解离，所以每由中性脂肪酸生成一个分子，就向血液释放一个质子。
:::

::: example 酮体：燃料价值与酸负荷 {#ex-ketone}
(a) 一个心肌细胞从一个 D-3-羟基丁酸、一个乙酰乙酸各能得到多少 ATP？(b) 未经控制的 1 型糖尿病中，没有胰岛素，酮体生成失控。假定酮酸在血浆中积累到 $10\ \mathrm{mmol\,dm^{-3}}$，每个质子消耗一个碳酸氢根。从 $[\mathrm{HCO_3^-}] = 24\ \mathrm{mmol\,dm^{-3}}$、$p_{\mathrm{CO_2}} = 40\ \mathrm{mmHg}$（溶解 $\mathrm{CO_2}$ $1.2\ \mathrm{mmol\,dm^{-3}}$，$\mathrm{p}K_\mathrm{a}' = 6.1$）出发，估计若 $p_{\mathrm{CO_2}}$ 不变时血浆的 pH。
::: solution
(a) 3-羟基丁酸先被 NAD⁺ 氧化为乙酰乙酸（一个 NADH，$2.5$ 个 ATP）。乙酰乙酸被琥珀酰辅酶A活化，放弃了一个本可由琥珀酰辅酶A生成的 GTP（$-1$）。硫解酶给出两个乙酰辅酶A，值 $20$ 个 ATP。所以乙酰乙酸给 $20 - 1 = 19$ 个 ATP，3-羟基丁酸给 $19 + 2.5 = 21.5$ 个 ATP。

(b) pH 7.4 时乙酰乙酸的解离分数为 $1/(1 + 10^{3.6 - 7.4}) = 0.9998$，所以每生成一摩尔基本就释放一摩尔 $\mathrm{H^+}$，由碳酸氢根缓冲：$\mathrm{H^+} + \mathrm{HCO_3^-} \rightarrow \mathrm{CO_2} + \mathrm{H_2O}$。碳酸氢根降到 $24 - 10 = 14\ \mathrm{mmol\,dm^{-3}}$。由亨德森-哈塞尔巴尔赫方程（[[biochemistry/water-noncovalent#prop-hh]]），
$$
\mathrm{pH} = 6.1 + \log_{10}\frac{14}{1.2} = 6.1 + 1.07 = 7.17 ,
$$
比 $6.1 + \log_{10}(24/1.2) = 7.40$ 低。这就是**代谢性酸中毒**。实际上呼吸加深、$p_{\mathrm{CO_2}}$ 下降，使 pH 部分回升；这个计算说明了对肺开放的碳酸氢根体系为什么是身体的主要防线（[[biochemistry/water-noncovalent#ex-bicarbonate]]）。这个例子说明的是酸负荷的化学，不是临床指导。
:::

## 脂肪酸的合成

脂肪酸在细胞质中合成，主要在肝脏、脂肪组织与泌乳期的乳腺，条件是糖类充裕。这条途径每次添加两个碳，每一轮循环看起来像倒运行的 β-氧化——缩合、酮还原、脱水、烯还原——但几乎每个细节都不同：

| 特征 | β-氧化 | 脂肪酸合成 |
|---|---|---|
| 区室 | 线粒体基质 | 细胞质溶胶 |
| 脂酰载体 | 辅酶A | 酰基载体蛋白（ACP；磷酸泛酰巯基乙胺臂） |
| 二碳供体/产物 | 释放乙酰辅酶A | 丙二酰-ACP 提供两个碳，失去 $\mathrm{CO_2}$ |
| 氧化还原辅酶 | FAD、$\mathrm{NAD^+}$（氧化） | NADPH（还原） |
| 3-羟基中间产物的立体化学 | L | D |
| 酶的组织形式 | 各自独立的酶 | 一条多功能脂肪酸合酶二聚体（动物） |
| 关键控制 | CPT I（被丙二酰辅酶A抑制） | 乙酰辅酶A羧化酶 |

乙酰辅酶A在线粒体中生成（来自丙酮酸），本身不能跨过内膜。它以**柠檬酸**的形式输出，ATP-柠檬酸裂解酶在细胞质中把它切回乙酰辅酶A与草酰乙酸，每个乙酰基花一个 ATP；草酰乙酸被还原为苹果酸，再由苹果酸酶脱羧成丙酮酸，同时生成 NADPH，丙酮酸返回线粒体。

关键步骤是**乙酰辅酶A羧化酶**（ACC）把乙酰辅酶A羧化为**丙二酰辅酶A**——一个需生物素的酶。ATP 把碳酸氢根活化为氨甲酰磷酸式的羧基磷酸，后者羧化生物素的 N1′；长长的生物素-赖氨酸臂把羧基带到第二个位点，乙酰辅酶A的烯醇盐在那里进攻它。ACC 被柠檬酸激活（柠檬酸促进其聚合成活性纤维），被棕榈酰辅酶A抑制（终产物抑制），并被 AMP 激活的蛋白激酶（AMPK）磷酸化而失活——AMPK 是细胞的能量感应器。

既然 $\mathrm{CO_2}$ 转眼又丢掉，为什么还要羧化？两个乙酰硫酯缩合成乙酰乙酰硫酯是 Claisen 缩合，其平衡站在反应物一边——这就是 β-氧化中硫解酶沿裂解方向运行的原因。在脂肪酸合成中，β-酮脂酰-ACP 合酶让生长中的脂酰链（接在酶的一个半胱氨酸上）与丙二酰-ACP 反应；丙二酰-ACP 的**脱羧**生成烯醇盐亲核试剂，$\mathrm{CO_2}$ 的释放使缩合强放能。装上车箱时花掉的 ATP，买的是一个不能倒退的反应。随后 β-酮脂酰-ACP 被 NADPH 还原为 D-3-羟基脂酰-ACP，脱水成 *trans*-$\Delta^2$-烯酰-ACP，再被 NADPH 还原为饱和脂酰-ACP，长两个碳。七轮之后，十六碳的棕榈酰-ACP 被硫酯酶释放。

::: proposition 棕榈酸合成的计量关系 {#prop-fas}
细胞质中由乙酰辅酶A合成棕榈酸为
$$
8\,\mathrm{acetyl\text{-}CoA} + 7\,\mathrm{ATP} + 14\,\mathrm{NADPH} + 6\,\mathrm{H^+} \rightarrow \mathrm{palmitate} + 8\,\mathrm{CoA} + 14\,\mathrm{NADP^+} + 7\,\mathrm{ADP} + 7\,\mathrm{P_i} + 6\,\mathrm{H_2O} .
$$ {#eq-fas}
一般地，$n$ 个碳的饱和脂肪酸（$n$ 为偶数）需要 $n/2$ 个乙酰辅酶A、$n/2 - 1$ 个 ATP（制丙二酰辅酶A）与 $n - 2$ 个 NADPH，另外每个以柠檬酸形式运出线粒体的乙酰基还要一个 ATP。
:::

::: proof
乙酰辅酶A羧化酶用七个 ATP 把七个乙酰辅酶A做成七个丙二酰辅酶A：$7\,\mathrm{acetyl\text{-}CoA} + 7\,\mathrm{CO_2} + 7\,\mathrm{ATP} \rightarrow 7\,\mathrm{malonyl\text{-}CoA} + 7\,\mathrm{ADP} + 7\,\mathrm{P_i}$（羧化的质子从略）。剩下那个乙酰辅酶A为合酶"点火"。七轮延伸中的每一轮加上来自一个丙二酰单元的两个碳、放出一个 $\mathrm{CO_2}$、用掉两个 NADPH（一个还原酮、一个还原烯）、放出一个水（脱水）：共 $7 \times 2 = 14$ 个 NADPH 与 $7$ 个水。放出的 $\mathrm{CO_2}$ 与固定的 $\mathrm{CO_2}$ 相等，相消。硫酯酶释放棕榈酸消耗一个水，净余 $6$ 个。相加即得[[#eq-fas]]。对 $n$ 个碳，同样的计数给出 $n/2 - 1$ 轮、$n/2 - 1$ 个 ATP 与 $2(n/2 - 1) = n - 2$ 个 NADPH。经柠檬酸的路线还要为每个送到细胞质的乙酰辅酶A在 ATP-柠檬酸裂解酶处再付一个 ATP。
:::

::: example NADPH 从哪里来？ {#ex-nadph}
(a) 合成一个棕榈酸需要多少 NADPH？若每个 NADPH 计 $2.5$ 个 ATP 并算上柠檬酸路线，以 ATP 当量计的总代价是多少？(b) 若苹果酸酶为每个输出的乙酰基提供一个 NADPH，其余的需要多少个在磷酸戊糖途径氧化支中被氧化的 6-磷酸葡萄糖（每个给 2 个 NADPH）来供应？
::: solution
(a) 按[[#prop-fas]]，需要 14 个 NADPH。代价：7 个 ATP（ACC）+ 8 个 ATP（ATP-柠檬酸裂解酶，八个乙酰基）+ $14 \times 2.5 = 35$ 个 ATP 当量（NADPH），共 $50$ 个 ATP 当量——这还不算那八个乙酰辅酶A本身，它们本可在柠檬酸循环中产出 80 个 ATP。日后把棕榈酸氧化可拿回 106 个 ATP（[[#prop-beta-yield]]）：以脂肪形式储存再回收乙酰碳，保住了其价值的 $106/(80 + 50) = 82\,\%$。

(b) 苹果酸酶提供 8 个 NADPH（输出的柠檬酸生成的每个草酰乙酸一个），剩 $14 - 8 = 6$ 个交给磷酸戊糖途径：需要氧化 $6/2 = 3$ 个 6-磷酸葡萄糖成 5-磷酸核酮糖与 $\mathrm{CO_2}$。（戊糖由转酮醇酶与转醛醇酶回收为糖酵解中间产物。）两种 NADPH 来源在不同组织中的使用比例不同；脂肪组织很大程度上依赖磷酸戊糖途径。
:::
:::

::: warning 脂肪酸合成不是 β-氧化的逆过程，乙酰辅酶A也不能净生成葡萄糖
有两个错误需要防范。第一个是把合成与分解当作同一条途径的两个方向。它们共享化学的逻辑，但在区室、载体、辅酶、立体化学与酶上全都不同（见上表），而且受相互调控——ACC 造丙二酰辅酶A，丙二酰辅酶A封住 CPT I——于是细胞不会去氧化自己正在合成的脂肪酸。第二个是以为动物能把脂肪变成葡萄糖。乙酰辅酶A的两个碳进入柠檬酸循环，但每一循环都有两个碳以 $\mathrm{CO_2}$ 离开（[[biochemistry/glycolysis-citric-acid#prop-tca]]），所以草酰乙酸没有*净*增，而丙酮酸脱氢酶又是不可逆的。在动物体内，只有三酰甘油的甘油和奇数链脂肪酸的最后三个碳能变成葡萄糖。（植物与许多细菌可以，它们用乙醛酸循环绕过两次脱羧。）
:::

## 氨基酸分解代谢与尿素循环

蛋白质处于持续更新之中——一个人每天降解再合成几百克蛋白质——摄入超出合成所需的氨基酸则被氧化。它们的分解代谢分两部分：移去 α-氨基，其氮最终主要进入尿素；以及把碳骨架降解为七种常见中间产物之一。

### 转氨基作用

大多数氨基酸通过与 α-酮戊二酸的**转氨基作用**失去氨基，α-酮戊二酸变成谷氨酸：
$$
\text{氨基酸} + \alpha\text{-酮戊二酸} \rightleftharpoons \alpha\text{-酮酸} + \text{谷氨酸} .
$$
催化这些反应的转氨酶使用来自维生素 $\mathrm{B_6}$ 的辅酶**5′-磷酸吡哆醛**（PLP）。转氨基的表观平衡常数接近 1，所以它们是双向可运行的近平衡反应，既服务于分解代谢，也服务于非必需氨基酸的合成。其中两个尤为重要：丙氨酸转氨酶（丙氨酸 + α-酮戊二酸 ⇌ 丙酮酸 + 谷氨酸）与天冬氨酸转氨酶（天冬氨酸 + α-酮戊二酸 ⇌ 草酰乙酸 + 谷氨酸）。

::: example 需 PLP 转氨基的机理 {#ex-plp}
逐步用电子转移描述丙氨酸转氨酶如何把丙氨酸变成丙酮酸，以及酶如何回到起始状态。
::: solution
静息酶中 PLP 的醛以一个亚胺（席夫碱）与活性位点赖氨酸的 ε-氨基相连——**内部醛亚胺**。(i) 丙氨酸的氨基进攻亚胺碳，经过质子转移释放赖氨酸：**转亚胺化**给出**外部醛亚胺**，丙氨酸的氮如今以 C=N 双键连在辅酶上。(ii) 此时已成自由碱的赖氨酸取走丙氨酸的 α-氢。C–H 键的电子流入扩展的 π 体系：C=N 键变成 C–N⁻，与吡啶环共轭，而质子化的环氮充当**电子阱**，把碳负离子稳定为**醌型**中间体。(iii) 同一个赖氨酸此时已被质子化，把一个质子交给原醛基的碳（辅酶的 C4′）。C=N 键因此完成迁移：它如今位于氮与丙氨酸原来的 α-碳之间——一个**酮亚胺**。(iv) 水进攻酮亚胺碳，C–N 键断裂释放**丙酮酸**，氮留在辅酶上成为**磷酸吡哆胺**（PMP）。反应的半程对 α-酮戊二酸恰好是精确的逆过程：PMP 与酮酸缩合成酮亚胺，质子搬回原位，赖氨酸水解（转亚胺化）释放**谷氨酸**并再生内部醛亚胺。辅酶把氨基从一个酮酸带到了另一个酮酸（**乒乓机制**，[[biochemistry/enzymes]]）。同样的电子阱化学——只是断掉 α-碳上的另一种键——让其他需 PLP 的酶催化氨基酸的脱羧、外消旋与消除。
:::
:::

### 氨的释放

谷氨酸收集大多数氨基酸的氨基。在肝脏线粒体中，**谷氨酸脱氢酶**用 $\mathrm{NAD^+}$ 或 $\mathrm{NADP^+}$ 以氧化脱氨把氮以铵的形式移走：
$$
\mathrm{glutamate} + \mathrm{NAD(P)^+} + \mathrm{H_2O} \rightleftharpoons \alpha\text{-酮戊二酸} + \mathrm{NH_4^+} + \mathrm{NAD(P)H} + \mathrm{H^+} .
$$
氨有毒，对大脑尤其如此，部分因为它把 α-酮戊二酸从柠檬酸循环中抽走（变成谷氨酸与谷氨酰胺），扰乱神经递质与 pH 平衡。所以其他组织以无毒形式把氮送往肝脏：大多数组织以**谷氨酰胺**形式（由谷氨酰胺合成酶用谷氨酸与 $\mathrm{NH_4^+}$、耗 ATP 合成），肌肉则以**丙氨酸**形式（把丙酮酸转氨成丙氨酸）。在肝脏中，丙氨酸交回丙酮酸用于糖异生，葡萄糖再回到肌肉——**葡萄糖-丙氨酸循环**，科里循环中负责运氮的那一对等物。

### 尿素循环

哺乳动物把多余的氮大部分以**尿素** $\mathrm{(NH_2)_2CO}$ 排出，尿素在肝脏中由一个横跨线粒体与细胞质的循环制成：

1. **氨甲酰磷酸合成酶 I**（线粒体）用 $\mathrm{NH_4^+}$、碳酸氢根与两个 ATP 合成氨甲酰磷酸：一个 ATP 把碳酸氢根活化为羧基磷酸，氨进攻生成氨基甲酸，第二个 ATP 把氨基甲酸磷酸化。该酶被 **N-乙酰谷氨酸**别构激活，而氨基酸水平高时 N-乙酰谷氨酸浓度上升。
2. **鸟氨酸氨甲酰转移酶**把氨甲酰基转给鸟氨酸，生成**瓜氨酸**，后者被输出到细胞质。
3. **精氨酸代琥珀酸合成酶**把瓜氨酸与**天冬氨酸**——第二个氮的来源——缩合，用 ATP，且 ATP 被切成 AMP 与焦磷酸（脲基氧被活化为瓜氨酸酰-AMP 中间体）。
4. **精氨酸代琥珀酸裂解酶**消去**延胡索酸**，给出**精氨酸**。
5. **精氨酸酶**把精氨酸水解为**尿素**与鸟氨酸，鸟氨酸返回线粒体。

::: proposition 尿素循环的计量关系与代价 {#prop-urea}
尿素循环的总反应为
$$
\mathrm{CO_2} + \mathrm{NH_4^+} + \mathrm{aspartate} + 3\,\mathrm{ATP} + 2\,\mathrm{H_2O} \rightarrow \mathrm{urea} + \mathrm{fumarate} + 2\,\mathrm{ADP} + 2\,\mathrm{P_i} + \mathrm{AMP} + \mathrm{PP_i},
$$ {#eq-urea}
（质子从略，这在对生化方程的惯例中是常见做法），$\mathrm{PP_i}$ 水解后每个尿素消耗四个磷酸酐键。若延胡索酸经苹果酸与草酰乙酸转回天冬氨酸——延胡索酸酶、苹果酸脱氢酶（产生 NADH）与转氨基——则 NADH 值 $2.5$ 个 ATP，净代价降为每个尿素约 $1.5$ 个 ATP。
:::

::: proof
把五步相加：氨甲酰磷酸合成用 $\mathrm{NH_4^+}$、$\mathrm{CO_2}$（以碳酸氢根）与 2 个 ATP，给出 2 个 ADP 与一个 $\mathrm{P_i}$；鸟氨酸氨甲酰转移酶释放第二个 $\mathrm{P_i}$；精氨酸代琥珀酸合成酶用天冬氨酸与一个 ATP，给出 AMP 与 $\mathrm{PP_i}$；裂解酶释放延胡索酸；精氨酸酶用一个水释放尿素并再生鸟氨酸，后者与第 2 步消耗的鸟氨酸相消，瓜氨酸、精氨酸代琥珀酸与精氨酸亦然。数一数原子就会看到，质子从略时总方程需要两个水才能配平，其中一个是精氨酸酶的底物；结果即[[#eq-urea]]。能量代价：两个 ATP → ADP，加一个 ATP → AMP + $\mathrm{PP_i}$，再由 $\mathrm{PP_i} \rightarrow 2\,\mathrm{P_i}$，共 $2 + 2 = 4$ 个磷酸酐键。延胡索酸的回收：延胡索酸 → 苹果酸（延胡索酸酶）→ 草酰乙酸 + NADH（苹果酸脱氢酶）→ 天冬氨酸（天冬氨酸转氨酶，从谷氨酸取氮）。NADH 在呼吸链中产 $2.5$ 个 ATP，所以净代价为每个尿素 $4 - 2.5 = 1.5$ 个 ATP。尿素循环与柠檬酸循环经延胡索酸与天冬氨酸的这一联系，有时称为克雷布斯双循环。
:::

### 碳骨架的去向

氮移走之后，二十个碳骨架只降解为七种产物：丙酮酸、乙酰辅酶A、乙酰乙酰辅酶A、α-酮戊二酸、琥珀酰辅酶A、延胡索酸与草酰乙酸。骨架给出丙酮酸或柠檬酸循环中间产物的氨基酸是**生糖的**：它们能净提供草酰乙酸，从而生成葡萄糖。给出乙酰辅酶A或乙酰乙酰辅酶A的是**生酮的**。只有亮氨酸与赖氨酸完全生酮；异亮氨酸、苯丙氨酸、酪氨酸、色氨酸与苏氨酸两者兼是；其余都是生糖的。长期禁食时，肌肉蛋白是生糖碳的主要来源，这就是大脑转向酮体、降低葡萄糖需求能保护身体蛋白质的原因。

## 代谢的整合

本课程的各条途径并非彼此独立：它们共享中间产物、争夺同一些辅酶，并被一起调控。整合在三个层面上进行。

**组织各有专职。** **肝脏**维持血糖（糖原分解与糖异生），合成酮体与尿素，并最先处理大部分膳食营养素。**骨骼肌**为自己储存糖原，静息时氧化脂肪酸；冲刺时依靠磷酸肌酸与无氧糖酵解。**脂肪组织**储存并释放三酰甘油。**大脑**通常几乎只用葡萄糖——成人一天 $100\ \mathrm{g}$ 以上——长期饥饿时也用酮体；它基本不能氧化脂肪酸。**红细胞**没有线粒体，只靠糖酵解。

**激素传递营养状态信号。** 餐后，胰脏 β-细胞的**胰岛素**促进肌肉与脂肪组织摄取葡萄糖、促进糖原合成、糖酵解与脂肪酸合成，抑制脂解、糖异生与酮体生成；它的许多效应经关键酶的去磷酸化介导。禁食时，**胰高血糖素**作用于肝脏（**肾上腺素**作用于肝与肌肉），经环腺苷酸与蛋白激酶 A 把同一批酶朝相反的方向磷酸化：糖原磷酸化酶被激活、糖原合酶被失活，双功能酶降低 2,6-二磷酸果糖，使糖异生压过糖酵解（[[biochemistry/glycolysis-citric-acid]]），乙酰辅酶A羧化酶被抑制，于是丙二酰辅酶A下降、CPT I 向脂肪酸打开线粒体之门。

**几个分子在细胞内充当开关。** 丙二酰辅酶A在脂肪酸合成与氧化之间做裁决。柠檬酸宣告燃料充裕（激活 ACC、抑制 PFK）。AMP 被 AMPK 感知，宣告能量电荷下降，于是开启分解代谢（摄取葡萄糖、氧化脂肪酸），关掉耗能的合成。而脂肪酸氧化的产物——乙酰辅酶A、NADH 与柠檬酸——抑制丙酮酸脱氢酶与 PFK，于是烧脂肪的组织省下葡萄糖（菲利普·兰德尔（Philip Randle）等人 1963 年描述的葡萄糖-脂肪酸循环）。

::: solution
禁食升高胰高血糖素、降低胰岛素。蛋白激酶 A 磷酸化乙酰辅酶A羧化酶（AMPK 也可能参与），于是丙二酰辅酶A下降、CPT I 解除抑制：脂肪酸氧化增加，并且由于草酰乙酸被转去糖异生，酮体生成也增加。双功能酶被磷酸化，2,6-二磷酸果糖下降，PFK 减速，果糖 1,6-二磷酸酶解除抑制，于是糖异生上升。
:::
:::

## 后续内容

本章为本课程的代谢叙述收尾。[[biochemistry/enzymes]]中发展起来的别构酶与共价修饰调控、[[biochemistry/protein-function]]的结合理论，正是[[medicinal-chemistry]]设计作用于这些途径的酶抑制剂的基础（他汀类之于 HMG-CoA 还原酶——胆固醇路线上排在 HMG 辅酶A合酶之后的那个酶——是经典例子）。由脂肪酸制成的膜脂质见[[biochemistry/carbohydrates-lipids]]；氮收支联系到[[biochemistry/nucleic-acids]]中核苷酸的合成；这里认识的辅酶——生物素、PLP、辅酶 $\mathrm{B_{12}}$、硫辛酰胺——将在[[organic-2]]中作为反应机理再度登场，其中含金属者在[[coordination-chemistry/bioinorganic]]中。

::: history
1904 年，克诺普（Franz Knoop）给狗喂末端带苯基的脂肪酸，发现偶数碳的以苯乙酸衍生物排出，奇数碳的以苯甲酸衍生物排出：碳链必定每次被剪短两个碳，且氧化发生在 β-碳。1949 年，肯尼迪（Eugene Kennedy）与莱宁杰（Albert Lehninger）证明脂肪酸氧化在线粒体中进行；1950 年代初，吕嫩（Feodor Lynen）等人确定了辅酶A硫酯中间体。1958 年，瓦基勒（Salih Wakil）发现脂肪酸合成需要碳酸氢根并经由丙二酰辅酶A，表明合成是一条独立的途径；布洛赫（Konrad Bloch）与吕嫩因胆固醇与脂肪酸代谢的工作分享 1964 年诺贝尔生理学或医学奖。氮化学方面，舍恩海默（Rudolf Schoenheimer）1930 年代用同位素标记氨基酸的实验表明，身体蛋白质在不断降解与再合成（《身体的动态状态》一书于 1942 年遗著出版）。布劳恩施泰因（Alexander Braunstein）与克里茨曼（Maria Kritzmann）1937 年描述了转氨基作用。尿素循环由克雷布斯（Hans Krebs）与亨泽莱特（Kurt Henseleit）根据肝切片实验（显示鸟氨酸与瓜氨酸起催化作用）于 1932 年提出，是被发现的第一个代谢循环，比克雷布斯的柠檬酸循环早五年。1967 年，欧文（Oliver Owen）、卡希尔（George Cahill）等人证明，禁食者大脑的大量能量来自酮体。
:::

::: summary
- 脂肪酸以脂酰辅酶A形式活化（两个磷酸酐键），经肉碱穿梭进入线粒体（闸门是 CPT I，被丙二酰辅酶A抑制），再经脱氢（FAD）、加水、脱氢（NAD⁺）、硫解的循环序列被氧化。
- $n$ 个碳的饱和脂肪酸产 $7n - 6$ 个 ATP：棕榈酸 106 个。脂肪每克产 ATP 约为葡萄糖的 2.3 倍，因为它的碳更还原，而且它是无水储存的。
- 不饱和脂肪酸需要一个异构酶（有时还要一个还原酶）；奇数链脂肪酸给出丙酰辅酶A，经甲基丙二酰辅酶A（需辅酶 $\mathrm{B_{12}}$）变成琥珀酰辅酶A。
- 禁食时肝脏把多余的乙酰辅酶A变成酮体，为心肌、肌肉与饥饿中的大脑供能；它们的酸在 pH 7.4 下完全解离，会消耗碳酸氢根。
- 脂肪酸合成在细胞质中用丙二酰辅酶A（乙酰辅酶A羧化酶，关键步骤）、ACP、NADPH 与一个多功能合酶；棕榈酸需要 8 个乙酰辅酶A、7 个 ATP 与 14 个 NADPH。丙二酰基的脱羧驱动缩合。
- 氨基经需 PLP 的转氨基汇集到谷氨酸，再由谷氨酸脱氢酶以铵释放；尿素循环把铵氮与天冬氨酸氮变成尿素，代价是四个磷酸酐键（回收延胡索酸后净约 1.5 个 ATP）。
- 碳骨架或是生糖的或是生酮的；胰岛素、胰高血糖素、肾上腺素、AMPK 与细胞内信号（丙二酰辅酶A、柠檬酸、AMP）协调肝、肌肉、脂肪组织与大脑之间的各条途径。
:::

## 习题

::: exercise 硬脂酸的产量 {level=1 check="120"}
按 P/O 比 2.5 与 1.5，一个硬脂酸（18:0）完全氧化产生多少 ATP？（输入 ATP 的数目。）
::: solution
八轮 β-氧化给出 8 个 $\mathrm{FADH_2}$（$12$ 个 ATP）与 8 个 NADH（$20$ 个 ATP）；9 个乙酰辅酶A给出 $90$ 个；活化花 $2$ 个。总计 $12 + 20 + 90 - 2 = 120$，即 $n = 18$ 时的 $7n - 6$（[[#prop-beta-yield]]）。
:::
:::

::: exercise 硬脂酸所需的 NADPH {level=1 check="16"}
细胞质由乙酰辅酶A合成一个硬脂酸（18:0）需要多少 NADPH？（输入 NADPH 的数目。）
::: solution
按[[#prop-fas]]，$n - 2 = 16$ 个 NADPH：从起点的乙酰基开始经八轮延伸，每轮两次还原。（在动物体内，由棕榈酸延长到硬脂酸实际上是在内质网上用丙二酰辅酶A与 NADPH 进行的，但数目相同。）
:::
:::

::: exercise 来自膳食蛋白的尿素 {level=1 check="34.3"}
一个处于氮平衡的成年人每天吃 $100\ \mathrm{g}$ 蛋白质。蛋白质按质量约含 $16\,\%$ 的氮。若这些氮全部以尿素（$M = 60.06\ \mathrm{g\,mol^{-1}}$，每个分子两个 N）排出，每天产生多少克尿素？（质量以克保留三位有效数字输入。）
::: solution
氮：$0.16 \times 100 = 16\ \mathrm{g}$，即 $16/14.007 = 1.142\ \mathrm{mol}$ N。尿素：$1.142/2 = 0.571\ \mathrm{mol}$，即 $0.571 \times 60.06 = 34.3\ \mathrm g$。（实际上有少量氮以铵、肌酐与尿酸形式离开，所以尿素略少于此数。）代价是每天 $4 \times 0.571 = 2.3\ \mathrm{mol}$ 磷酸酐键，占每日 ATP 周转的百分之几（[[biochemistry/bioenergetics]]）。
:::
:::

::: exercise 油酸 {level=2 check="118.5"}
油酸是 *cis*-$\Delta^9$-十八碳烯酸（18:1）。解释为什么它完全氧化产生的 ATP 比硬脂酸少，并计算产量。（输入 ATP 的数目。）
::: solution
三轮 β-氧化后，双键位于 *cis*-$\Delta^3$，烯酰辅酶A异构酶把它移到 *trans*-$\Delta^2$——正是脂酰辅酶A脱氢酶本来要制造的那个双键。所以那一轮跳过 FAD 偶联的脱氢，少生成一个 $\mathrm{FADH_2}$。产量：$120 - 1.5 = 118.5$ 个 ATP。脂肪酸中的每个双键都是朝氧化方向已经走掉的一步：脂肪越不饱和，它携带的还原力就越少。
:::
:::

::: exercise 一整个三酰甘油 {level=2 check="336.5"}
计算一个三棕榈酸甘油酯完全氧化的 ATP 产量。甘油先被甘油激酶磷酸化（1 个 ATP），被 NAD⁺ 氧化为磷酸二羟丙酮（细胞质 NADH 经苹果酸-天冬氨酸穿梭进入线粒体，$2.5$ 个 ATP），随后走糖酵解与丙酮酸氧化。（ATP 数目保留一位小数输入。）
::: solution
三个棕榈酸根：$3 \times 106 = 318$。甘油：$-1$（激酶）$+2.5$（3-磷酸甘油脱氢酶）$+2$（糖酵解下半程的底物水平 ATP）$+2.5$（GAPDH 的 NADH）$+2.5$（丙酮酸脱氢酶）$+10$（循环中的乙酰辅酶A）$= 18.5$。总计每分子 $318 + 18.5 = 336.5$ 个 ATP（$M = 807.3\ \mathrm{g\,mol^{-1}}$），即每克 $0.417$ mol ATP——与游离棕榈酸基本相同，因为甘油只占质量的一小部分。
:::
:::

::: exercise 酮体的酸负荷 {level=2 check="7.17"}
重做[[#ex-ketone]](b)的计算，求 $10\ \mathrm{mmol\,dm^{-3}}$ 酮酸积累后、$p_{\mathrm{CO_2}}$ 恒定时的血浆 pH，起始为 $24\ \mathrm{mmol\,dm^{-3}}$ 碳酸氢根与 $1.2\ \mathrm{mmol\,dm^{-3}}$ 溶解 $\mathrm{CO_2}$（$\mathrm{p}K_\mathrm{a}' = 6.1$）。再求把 pH 拉回 7.40 所需的 $p_{\mathrm{CO_2}}$（单位 mmHg；$1.2\ \mathrm{mmol\,dm^{-3}}$ 相当于 $40\ \mathrm{mmHg}$）。（$p_{\mathrm{CO_2}}$ 恒定时 pH 保留两位小数输入。）
::: solution
$\mathrm{pH} = 6.1 + \log_{10}(14/1.2) = 6.1 + 1.067 = 7.17$。要在 $[\mathrm{HCO_3^-}] = 14$ 时恢复 pH 7.40，比率必须重新是 20，所以溶解 $\mathrm{CO_2}$ 必须降到 $14/20 = 0.70\ \mathrm{mmol\,dm^{-3}}$，即 $p_{\mathrm{CO_2}} = 40 \times 0.70/1.2 = 23\ \mathrm{mmHg}$。更快更深的呼吸可达到其中一部分——代谢性酸中毒的呼吸代偿。
:::
:::

::: exercise 一个奇数链脂肪酸 {level=3 check="100"}
十七烷酸（17:0）被活化后进行 β-氧化，直到剩下丙酰辅酶A。丙酰辅酶A被转化为琥珀酰辅酶A（丙酰辅酶A羧化酶用 1 个 ATP），琥珀酰辅酶A在柠檬酸循环中被氧化为草酰乙酸。只计算这些步骤（不计草酰乙酸的进一步氧化），求 ATP 产量。（输入 ATP 的数目。）
::: hint
先数轮数：每次去掉两个碳，直到剩下三个。再数琥珀酰辅酶A → 琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸产生什么。
:::
::: solution
七轮 β-氧化把 $\mathrm{C_{17}}$ 变成 $\mathrm{C_3}$，生成 7 个 $\mathrm{FADH_2}$、7 个 NADH 与 7 个乙酰辅酶A：$7 \times 4 + 7 \times 10 = 98$ 个 ATP。活化：$-2$。丙酰辅酶A → 琥珀酰辅酶A：$-1$。琥珀酰辅酶A → 草酰乙酸：GTP（$1$）、$\mathrm{FADH_2}$（$1.5$）、NADH（$2.5$）：$+5$。总计 $98 - 2 - 1 + 5 = 100$ 个 ATP。生成的草酰乙酸是循环中间产物的净增益，所以可用于糖异生——而要把它完全氧化，它必须离开循环（以磷酸烯醇式丙酮酸形式，或经苹果酸酶到丙酮酸）再以乙酰辅酶A进入，那还会再增加 ATP。
:::
:::

::: exercise 储存脂肪的代价 {level=3 check="50"}
(a) 用[[#prop-fas]]，每个运出线粒体的乙酰基（以柠檬酸形式）计一个 ATP、每个 NADPH 计 $2.5$ 个 ATP，计算由线粒体乙酰辅酶A合成一个棕榈酸的代价（以 ATP 当量计）。(b) 把它与日后氧化棕榈酸的产量、以及那八个乙酰辅酶A若立即氧化可得的产量比较。以脂肪形式储存保住了多大份额的能量？（合成代价以 ATP 当量输入。）
::: solution
(a) $7$（乙酰辅酶A羧化酶）$+ 8$（ATP-柠檬酸裂解酶）$+ 14 \times 2.5$（NADPH）$= 7 + 8 + 35 = 50$ 个 ATP 当量。(b) 氧化棕榈酸产 $106$。八个乙酰辅酶A立即氧化本可得 $80$。所以把它们储存为脂肪先付 $50$、日后收回 $106$，净得 $56$ 而不是 $80$——或者换个说法，这一来回保住了总价值的 $106/(80 + 50) = 82\,\%$。储存是昂贵的，但比没有仓库便宜得多；而且所谓"代价"有一部分是名义上的，因为磷酸戊糖途径生成的 NADPH 本来也不会去制造 ATP。
:::
:::

::: exercise 排氮的净代价 {level=3 check="1.5"}
(a) 导出尿素循环的总反应并数出消耗的磷酸酐键。(b) 说明延胡索酸回收为天冬氨酸如何收回部分代价，并以每个尿素的 ATP 计出净代价。(c) 解释循环为什么需要第二个氮以天冬氨酸而非第二个铵的形式到来。（净代价以每个尿素的 ATP 输入。）
::: solution
(a) 如[[#prop-urea]]的证明：氨甲酰磷酸合成酶 I 用 2 个 ATP（2 个键），精氨酸代琥珀酸合成酶用 1 个 ATP → AMP + $\mathrm{PP_i}$，$\mathrm{PP_i}$ 的水解使它算 2 个键；共 4 个。(b) 延胡索酸 → 苹果酸 → 草酰乙酸产生一个 NADH（$2.5$ 个 ATP），草酰乙酸与谷氨酸的转氨基再生天冬氨酸（不耗能；谷氨酸携带的是从其他氨基酸收集来的氮）。净代价 $4 - 2.5 = 1.5$ 个 ATP 每个尿素。(c) 游离铵浓度必须保持很低，因为它有毒，而氨甲酰磷酸合成酶 I 只在线粒体中以一个高亲和力、受严格调控的酶固定它。把第二个氮以天冬氨酸（由谷氨酸池转氨生成）送来，肝脏便能处置从所有氨基酸收集来的氮而不抬高游离铵，并经延胡索酸与草酰乙酸把尿素合成与柠檬酸循环偶联起来。
:::
