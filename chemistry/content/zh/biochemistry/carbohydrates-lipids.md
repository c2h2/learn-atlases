一片面包、一件棉衫和一只螃蟹的壳由同一种糖——D-葡萄糖（对螃蟹来说，是它的 *N*-乙酰化氨基衍生物）——以不同方式连接而成。淀粉几分钟就被消化；纤维素完好无损地穿肠而过；几丁质则为昆虫披甲一生。区别只是一个碳原子上的一个立体化学描述符——α 还是 β——以及这个选择如何传播进一条链的形状。一滴橄榄油和每个细胞外面的膜同样由寥寥几种脂肪酸建成，但一个是毫无特征的液体，另一个是两分子厚、在 $4\ \mathrm{nm}$ 之间维持约 $70\ \mathrm{mV}$ 电压——约 $2\times10^{7}\ \mathrm{V\,m^{-1}}$ 的电场——的薄片。本章从你已经掌握的有机化学（立体中心、半缩醛与缩醛、酯）和[[biochemistry/water-noncovalent]]的非共价作用出发解释这两族分子，然后提出每个细胞都必须回答的热力学问题：把一个分子或一个离子运过一层膜，代价是多少？立体化学的语言见[[organic-1/stereochemistry]]；缩醛化学见[[organic-2/carbonyl-addition]]。

## 单糖

**单糖**是分子式为 $(\mathrm{CH_2O})_n$（$n = 3$ 到 $7$）的多羟基醛或酮。醛类称**醛糖**，酮类称**酮糖**，碳数给出名称的其余部分：丙糖、丁糖、戊糖、己糖。最小的是甘油醛（一个醛丙糖）和二羟丙酮（一个酮丙糖），两者都是糖酵解的中间物。最重要的是醛己糖 D-葡萄糖、酮己糖 D-果糖，以及 RNA 和 DNA 里的醛戊糖 D-核糖与 2-脱氧-D-核糖（[[biochemistry/nucleic-acids]]）。

### 构型：D 与 L

开链醛糖中除羰基碳和末端 $\mathrm{CH_2OH}$ 外，每个碳都是立体中心。于是含 $n$ 个碳的醛糖有 $n - 2$ 个立体中心和 $2^{n-2}$ 个立体异构体。糖化学家不用 *R*/*S* 描述符标注它们，而用更古老的**费歇尔惯例**：在费歇尔透视式里把链竖画、羰基放在上方，看*离羰基最远*的那个立体中心。它的羟基指向右边，这个糖就是 **D**；指向左边就是 **L**——这是与 D-、L-甘油醛的比较。天然糖绝大多数是 D。D/L 标记对旋光的方向什么也没说（D-果糖是左旋的），对其余立体中心也什么也没说——它们编码在俗名里：D-葡萄糖、D-甘露糖和 D-半乳糖是八个 D-醛己糖中的三个。

只在恰好一个立体中心上构型不同的两个糖互为**差向异构体**：D-甘露糖是 D-葡萄糖的 C-2 差向异构体，D-半乳糖是它的 C-4 差向异构体。差向异构化是实实在在的生物化学反应——牛奶中的半乳糖正是通过在核苷酸活化的糖上翻转 C-4 而转成葡萄糖的——所以这个词不只是记账。

::: example 数一数醛己糖 {#ex-aldohexoses}
立体异构的醛己糖共有多少个？其中 D 型有几个？D-葡萄糖与 L-葡萄糖是什么关系？
::: solution
醛己糖 $\mathrm{OHC{-}(CHOH)_4{-}CH_2OH}$ 在 C-2、C-3、C-4 和 C-5 有立体中心，故有 $2^4 = 16$ 个立体异构体。D/L 标记只由 C-5 决定，而 C-2 到 C-4 可取 $2^3 = 8$ 种排布中的任意一种，所以有 8 个 D-醛己糖（阿洛糖、阿卓糖、葡萄糖、甘露糖、古洛糖、艾杜糖、半乳糖、塔罗糖）和它们的 8 个 L 对映体。L-葡萄糖是 D-葡萄糖的镜像：它在*全部四个*立体中心上都不同，而不只是 C-5。若只改变 C-5，得到的是另一个 D/L 标记不同的糖——L-艾杜糖——一个非对映体，而不是对映体。这是费歇尔惯例最常见的疏漏：D 和 L 命名一对对映体，但这对对映体是*由一个碳来指定*的。
:::
:::

### 成环

醛与醇可逆地加成给出**半缩醛**（[[organic-2/carbonyl-addition]]）。在糖里这两个基团在同一个分子上，当它们相隔恰当的原子数时，加成是分子内的且强烈有利：五元环和六元环的环张力很小，而把两个基团带到一起的熵代价已由分子链预付。在 D-葡萄糖中，C-5 羟基进攻 C-1 醛基，得到一个含一个氧的六元环，参照吡喃称为**吡喃糖**；C-4 羟基进攻则得五元的**呋喃糖**，参照呋喃命名。果糖是 2-酮糖，形成半缩酮；在蔗糖和果糖-1,6-二磷酸中它是呋喃型。在水的平衡混合物中，超过 $99\ \%$ 的葡萄糖是环状的，开链醛型不到百分之一。

成环在原来的羰基碳上产生一个新的立体中心——**异头碳**：氧可以进攻平面醛的任一个面。

::: definition 异头物与变旋作用 {#def-anomer}
环状糖的两个非对映体只在异头碳（醛糖的 C-1、2-酮糖的 C-2）上构型不同，称为**异头物**。**$\alpha$ 异头物**的异头羟基与携带 D/L 参考碳的 $\mathrm{CH_2OH}$ 基团位于环的异侧（在 D-糖的哈沃斯透视式里，异头 OH 指向下方）；**$\beta$ 异头物**则在同侧（指向上方）。由于环经游离羰基形态开开合合，两个异头物在溶液中相互转化；新溶的纯异头物的旋光度直到达到平衡值为止的这种变化，称为**变旋作用**。
:::

**哈沃斯透视式**把环画成一个侧看的扁平六边形，环氧在右后方；费歇尔透视式中指向右边的基团画在下方。真实的吡喃糖是**椅型**。在 $\beta$-D-吡喃葡萄糖中，每个取代基（包括异头羟基）都处于平伏位置——葡萄糖是唯一能做到的醛己糖，人们不禁要把这一点与它在自然界中的统治地位联系起来。在 $\alpha$-D-吡喃葡萄糖中，异头羟基是直立的。

::: example 两种异头物各有多少？ {#ex-mutarotation}
纯 $\alpha$-D-吡喃葡萄糖的比旋光度 $[\alpha]_\mathrm{D} = +112.2^\circ$，纯 $\beta$-D-吡喃葡萄糖为 $+18.7^\circ$，而 $25\ \mathrm{^\circ C}$ 下的葡萄糖溶液平衡后稳定在 $+52.7^\circ$（数值按 Berg 等和 Nelson 与 Cox 的给出）。假定有明显量的只有两种吡喃异头物，求各自在平衡时的分数、平衡常数 $K = [\beta]/[\alpha]$，以及 $\alpha \rightleftharpoons \beta$ 在 $298.15\ \mathrm{K}$ 的 $\Delta G^\circ$。
::: solution
旋光度可加：若 $\beta$ 型占分数 $x$，则
$$
52.7 = 112.2\,(1 - x) + 18.7\,x \quad\Rightarrow\quad x = \frac{112.2 - 52.7}{112.2 - 18.7} = \frac{59.5}{93.5} = 0.636.
$$
所以溶液含 $63.6\ \%$ 的 $\beta$ 型和 $36.4\ \%$ 的 $\alpha$ 型，$K = 0.636/0.364 = 1.75$。于是
$$
\Delta G^\circ = -RT\ln K = -(8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(298.15\ \mathrm{K})\ln 1.75 = -1.39\ \mathrm{kJ\,mol^{-1}}.
$$
$\beta$ 型占优，但优势远小于环己烷上一个直立羟基通常的代价约 $3\ \mathrm{kJ\,mol^{-1}}$：$\alpha$ 型直立的异头羟基被**异头效应**部分稳定——与环氧相邻的电负性取代基偏好直立位置（解释是环氧的一对孤对电子向直立 $\mathrm{C{-}O}$ 键的 $\sigma^*$ 轨道给予）。小的呋喃型和开链群体使"两组分"假设的误差只有约 $1\ \%$。
:::
:::

变旋作用趋近平衡的过程是一级的。无催化时室温下需要几小时；酸和碱都能加速（开环是一种广义酸碱催化的半缩醛断裂，[[kinetics/homogeneous-catalysis]]），在细胞中则由变旋酶催化。下图显示旋光度向平衡值的衰减。

### 还原糖与衍生物

由于环会打开，带游离异头羟基的环状糖在慢反应中表现为醛：它能还原温和的氧化剂，如碱性溶液中的 $\mathrm{Cu^{2+}}$（斐林试验和本尼迪特试验，析出红色 $\mathrm{Cu_2O}$）或 $\mathrm{Ag^+}$（托伦斯试验）。这样的糖称为**还原糖**。葡萄糖氧化酶在 C-1 把 $\beta$ 异头物氧化成内酯，是葡萄糖试纸和传感器的基础。酮糖也呈阳性，因为碱通过烯二醇把它异构为醛糖——糖酵解中磷酸己糖异构酶催化的正是同一个反应（[[biochemistry/glycolysis-citric-acid]]）。

细胞对单糖做大量改造。**磷酸酯**如 6-磷酸葡萄糖是糖在细胞内的工作形态：负电荷把它们关在细胞质里，又给酶提供一个结合把手。**氨基糖**以氨基取代一个羟基（氨基葡萄糖；几丁质和细菌细胞壁中的 *N*-乙酰氨基葡萄糖，GlcNAc）。**脱氧糖**缺少一个羟基（2-脱氧核糖）。**糖酸**与**糖醇**来自氧化和还原（葡糖酸、葡糖醛酸、山梨醇）。

## 糖苷键

半缩醛与第二个醇反应、失去一分子水，得到**缩醛**。在糖里，缩醛碳就是异头碳，新形成的键就是糖苷键。

::: definition 糖苷键 {#def-glycosidic}
**糖苷键**是从一个糖的异头碳到另一个分子的氧（**O-糖苷**）或氮（**N-糖苷**）的键，由取代异头羟基而形成。它按异头构型和它所连接的两个碳编号命名：麦芽糖中一个葡萄糖的 C-1（$\alpha$）与下一个葡萄糖的 O-4 相连，写作 **Glc(α1→4)Glc**。生成糖苷就把异头碳的构型固定下来：环再也打不开，这个糖苷残基不变旋，也不能还原斐林试液。异头碳仍是游离半缩醛的那个残基是一个**还原端**；链的另一端（C-4 羟基游离）是**非还原端**。
:::

化学上，糖苷就是缩醛：对碱稳定，可被稀酸经氧碳鎓离子水解；在生物体内由**糖苷酶**水解，后者对糖和异头构型都是专一的。在细胞中，糖苷键不是靠游离糖与醇缩合来制造的——水中的平衡站在水解一边——而是靠**糖基转移酶**，把糖从一个活化的供体（一种核苷糖，如 UDP-葡萄糖）转移过来。

::: example 糖苷键稳定吗？ {#ex-maltose}
对麦芽糖 + $\mathrm{H_2O} \rightarrow 2$ 葡萄糖，Nelson 与 Cox 给出 $\Delta G^{\circ\prime} = -15.5\ \mathrm{kJ\,mol^{-1}}$。计算 $298.15\ \mathrm{K}$ 的平衡常数，并把它与"麦芽糖溶液在中性 pH 下可存放数年"这一事实调和起来。
::: solution
$$
K = \exp\!\left(-\frac{\Delta G^{\circ\prime}}{RT}\right) = \exp\!\left(\frac{15\,500\ \mathrm{J\,mol^{-1}}}{(8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(298.15\ \mathrm{K})}\right) = e^{6.253} = 5.2\times10^{2}.
$$
浓度以 $\mathrm{mol\,dm^{-3}}$ 计（水的活度为 1），$K = [\mathrm{glucose}]^2/[\mathrm{maltose}] = 520\ \mathrm{mol\,dm^{-3}}$：在任何实际浓度下，平衡时水解都基本进行到底。（$K$ 有单位，因为一个分子变成两个；这也是稀释推动水解更进一步的原因。）这个键之所以尚存，是因为水解很慢：中性 pH、室温下糖苷键未催化的半衰期以百万年计，因为氧碳鎓离子的过渡态只有在酸催化下才能达到。糖苷酶可达 $10^{15}$ 以上的速率增强。热力学不稳定，动力学惰性：这种组合正是一种储存聚合物所需要的，因为细胞何时释放葡萄糖，由它决定何时让酶起作用。
:::
:::

### 二糖

营养上有三种二糖要紧。**麦芽糖** Glc(α1→4)Glc，来自淀粉消化，是还原糖。**乳糖** Gal(β1→4)Glc，即牛奶中的糖；其葡萄糖端有还原性。它由乳糖酶切开；断奶后肠道乳糖酶减少的人消化不了它，于是由结肠细菌发酵（乳糖不耐受）。**蔗糖** Glc(α1↔2β)Fru 把*两个*糖的异头碳连在一起，所以两个环都打不开：蔗糖是**非还原糖**——这也是植物用它运输碳的原因之一，因为它不像还原糖那样缓慢地与蛋白质的氨基反应。

::: quiz
下列哪种糖给出阴性的本尼迪特试验（无红色 $\mathrm{Cu_2O}$）？
- [ ] 乳糖，Gal(β1→4)Glc
- [ ] 麦芽糖，Glc(α1→4)Glc
- [x] 蔗糖，Glc(α1↔2β)Fru
- [ ] D-果糖
::: solution
阳性试验需要一个能开成羰基的游离异头碳。乳糖和麦芽糖各有一个有还原性的葡萄糖端。果糖是自由的，在碱性溶液中经烯二醇异构为醛糖，所以也能还原铜(II)。蔗糖把葡萄糖和果糖的异头碳互相连接，两个都被锁成缩醛，因而无还原性。
:::
:::

::: warning α/β 不是 D/L，而且糖苷一旦形成就不能改变 {#warn-anomer}
两种常见的错误。其一，$\alpha$ 和 $\beta$ 是*异头物*——在一个碳上构型不同的非对映体——与 D/L 那一对对映体毫不相干：$\alpha$-D-葡萄糖和 $\beta$-D-葡萄糖都是 D。其二，变旋作用是游离半缩醛的性质。异头碳一旦进入糖苷键，它的构型就被固定：纤维素不可能"变旋成"淀粉；人体消化不了纤维素，是因为我们没有作用于 $\beta$(1→4) 糖苷键的酶，而不是因为葡萄糖有什么不同。烹煮、咀嚼和胃酸都不能把一种变成另一种。
:::

## 多糖

**多糖**（聚糖）是几十个到几万个单糖残基的聚合物。**同多糖**只含一类残基；**杂多糖**含好几类。与蛋白质和核酸不同，多糖不是按模板制造的：它们的长度和分支由合成它们的酶决定，并且是可变的。

**淀粉**——植物的储存葡聚糖——是**直链淀粉**（无分支的 Glc(α1→4) 链，多达数千个残基）与**支链淀粉**（同样的链，每 24–30 个残基有一个 $\alpha$(1→6) 分支点）的混合物。**糖原**是肝和肌肉中的动物储存葡聚糖，具有支链淀粉式的构造而每 8–12 个残基就有一个分支，形成一个致密、近球形的颗粒。分支有动力学上的用意：糖原磷酸化酶只从非还原端切下葡萄糖，而每多一个分支就多一个端，所以高度分支的分子能够快速释放葡萄糖。

$\alpha$(1→4) 连接天生带一个折弯：相邻残基彼此旋转，于是直链淀粉卷成一个中空螺旋，每圈约六个残基。淀粉遇碘的著名蓝黑色，来自穿进螺旋内部的线形多聚碘链。**纤维素**则通体是 Glc(β1→4)。在 $\beta$ 连接中每个残基相对上一个翻转 $180^\circ$，链直而平，各链内的环氧到 3-OH 氢键把它保持在这一形状。平行的链再横向氢键成片层，片层堆叠，结果是一根抗张强度接近钢的微纤维——木材和棉花的材料。**几丁质**是同样的结构，只是以 GlcNAc 代替葡萄糖。食物与膳食纤维的区别，就是一个键的立体化学。

::: example 为什么储存糖原而不是葡萄糖？ {#ex-glycogen-osmotic}
Nelson 与 Cox 估计，一个肝细胞中的糖原相当于约 $0.4\ \mathrm{mol\,dm^{-3}}$ 的游离葡萄糖。若以游离葡萄糖储存，用范特霍夫方程 $\Pi = cRT$ 估算它在 $37\ \mathrm{^\circ C}$ 产生的额外渗透压，并与细胞质约 $0.3\ \mathrm{mol\,dm^{-3}}$ 的总渗透浓度比较。
::: solution
用 SI 单位，$c = 0.4\ \mathrm{mol\,dm^{-3}} = 400\ \mathrm{mol\,m^{-3}}$，于是
$$
\Pi = cRT = (400\ \mathrm{mol\,m^{-3}})(8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(310.15\ \mathrm{K}) = 1.03\times10^{6}\ \mathrm{Pa} \approx 10\ \mathrm{bar}.
$$
这个水平的游离葡萄糖会使细胞的溶质浓度增加不止一倍，水会涌进直到质膜涨破。同样多的葡萄糖装在一个约 $10^{4}$–$10^{5}$ 个残基的糖原颗粒里，在渗透压上几乎什么都不是，因为渗透压数的是颗粒数而不是质量（Nelson 与 Cox 给出的糖原有效浓度接近 $0.01\ \mu\mathrm{mol\,dm^{-3}}$）。聚合是细胞储存可溶性燃料的方案。（范特霍夫方程是理想稀溶液的极限，对这类估算已经足够；见[[general-chemistry-2/liquids-solutions]]。）
:::
:::

碳水化合物还作为**糖缀合物**连接到蛋白质和脂质上。**糖蛋白**携带经由天冬酰胺氮（*N*-连接）或丝氨酸、苏氨酸氧（*O*-连接）连接的寡糖；ABO 血型抗原是只差一个末端糖的糖脂和糖蛋白。细菌细胞壁是**肽聚糖**——GlcNAc 与 *N*-乙酰胞壁酸交替、由短肽交联——即溶菌酶攻击的结构，其合成被青霉素阻断（[[medicinal-chemistry/drug-targets]]）。**蛋白聚糖**携带长的、高度硫酸化的、带负电的糖胺聚糖链（硫酸乙酰肝素、硫酸软骨素），在软骨中锁住水。

## 脂质

**脂质**由一条性质而非一种结构来定义：它们是那些难溶于水、可溶于非极性溶剂的生物分子。其中包括燃料（三酰甘油）、膜组分（磷脂、鞘脂、固醇）和信号分子（类固醇激素、类花生酸）。

### 脂肪酸

**脂肪酸**是带长烃链（通常无分支）的羧酸，碳数通常为偶数（12–24），因为它是每次两个碳地从乙酰辅酶A搭建起来的（[[biochemistry/lipid-nitrogen-metabolism]]）。简写给出链长、双键数和从羧基碳数起的位置：棕榈酸是 16:0，油酸 18:1(Δ9)，亚油酸 18:2(Δ9,12)。天然双键几乎总是 *cis*，而在多不饱和酸中彼此被一个 $\mathrm{CH_2}$ 基团隔开（亚甲基间隔）。营养标签则从甲基端数起：亚油酸是 $\omega$-6，$\alpha$-亚麻酸 18:3(Δ9,12,15) 是 $\omega$-3 脂肪酸。由于 $\mathrm{p}K_\mathrm{a} \approx 4.5$–$5$，脂肪酸在 pH 7 以羧酸根阴离子存在。

| 脂肪酸 | 简写 | 熔点 / °C |
|---|---|---|
| 月桂酸 | 12:0 | 44.2 |
| 肉豆蔻酸 | 14:0 | 53.9 |
| 棕榈酸 | 16:0 | 63.1 |
| 硬脂酸 | 18:0 | 69.6 |
| 油酸 | 18:1(Δ9) | 13.4 |
| 亚油酸 | 18:2(Δ9,12) | 1–5 |
| $\alpha$-亚麻酸 | 18:3(Δ9,12,15) | −11 |

（数据来自 Nelson 与 Cox《Lehninger Principles of Biochemistry》表 10-1。）两个趋势可见。每多一个 $\mathrm{CH_2}$，相邻链间就多一份色散接触，所以熔点随长度上升。一个 *cis* 双键在链中打一个 $30^\circ$ 的刚性折，妨碍紧密堆积：一个双键使熔点比硬脂酸低约 $56\ \mathrm{K}$，每再多一个就再降一些。这就是为什么猪油和黄油（富含饱和链）在室温是固体，而橄榄油（主要是油酸盐）和鱼油（多不饱和）是液体。*反*式脂肪由工业部分氢化产生，链是直的，堆积起来与饱和脂肪酸一样。

### 三酰甘油

**三酰甘油**（甘油三酯）是甘油与三个脂肪酸形成的三酯。它们是中性的、几乎完全不极性的，是动物的主要能量库。与糖原相比它的优势有两条：碳更还原（完全氧化约释放 $37\ \mathrm{kJ\,g^{-1}}$，碳水化合物只有约 $17\ \mathrm{kJ\,g^{-1}}$），而且以无水形式储存——糖原却携带约相当于自身质量两倍的水合水。就每克储存组织而言，脂肪大约保持水合糖原六倍的能量。三酰甘油用碱水解得到甘油和脂肪酸盐——**皂化**，肥皂的古老化学（[[organic-2/carboxylic-derivatives]]）。

### 膜脂

膜脂是**两亲性**的：一个极性头基连着两条非极性尾。

- **甘油磷脂**以 3-磷酸甘油为基础：两个脂肪酸分别酯化在 C-1 和 C-2（典型的是 C-1 饱和、C-2 不饱和），C-3 上的磷酸再连一个头基醇。与胆碱相连的是磷脂酰胆碱（偶极离子型，动物膜中最常见的脂质）；与乙醇胺相连的是磷脂酰乙醇胺；与丝氨酸相连的是带负电的磷脂酰丝氨酸，保留在健康细胞的内层；与肌醇相连的是磷脂酰肌醇，是一类信号分子的来源。
- **鞘脂**以鞘氨醇为基础——一种带内置长链的氨基醇；一个以酰胺键连接的脂肪酸提供第二条尾。**鞘磷脂**有磷酸胆碱头基；**鞘糖脂**携带糖，构成细胞外表的识别面。
- **固醇**（动物中主要是**胆固醇**）有一个刚性的稠合四环母核和唯一的羟基。胆固醇待在双分子层中：羟基在界面，环系插在烃链之间。

一个两亲分子在水中形成胶束还是双分子层，是个几何问题，而一个无量纲数就能概括。

::: definition 临界堆积参数 {#def-packing}
对烃体积为 $v$、最大（完全伸展）链长为 $l_\mathrm{c}$、在水界面处头基最优面积为 $a_0$的两亲分子，**临界堆积参数**为
$$
P = \frac{v}{a_0\,l_\mathrm{c}}.
$$
作为经验指南（Israelachvili、Mitchell 和 Ninham），$P < \tfrac13$ 倾向于形成球形胶束，$\tfrac13 < P < \tfrac12$ 圆柱形胶束，$\tfrac12 < P < 1$ 柔性双分子层与囊泡，$P > 1$ 反相。对含 $n$ 个碳的饱和链，坦福德（Tanford）估计 $v \approx (0.0274 + 0.0269\,n)\ \mathrm{nm^3}$，$l_\mathrm{c} \approx (0.154 + 0.1265\,n)\ \mathrm{nm}$。
:::

这个参数把定性图像变成计算：一个大头基下一条尾巴是一个圆锥，可以堆成球；同一个头基下两条尾巴构成圆柱，可以堆成平片。

::: example 胶束还是双分子层？ {#ex-packing}
二棕榈酰磷脂酰胆碱（DPPC）有两条 16:0 链，头基面积约 $0.64\ \mathrm{nm^2}$。它的溶血磷脂 lyso-PC 只有一条 16:0 链，头基大致相同。预测它们在水中各形成什么聚集体。
::: solution
单条 16 碳链：$v = 0.0274 + 0.0269 \times 16 = 0.4578\ \mathrm{nm^3}$，$l_\mathrm{c} = 0.154 + 0.1265 \times 16 = 2.178\ \mathrm{nm}$。对 DPPC，烃体积翻倍而长度不变：
$$
P_\mathrm{DPPC} = \frac{2 \times 0.4578}{0.64 \times 2.178} = 0.66, \qquad P_\mathrm{lyso} = \frac{0.4578}{0.64 \times 2.178} = 0.33.
$$
DPPC 落在双分子层区间，形成囊泡（脂质体）；lyso-PC 处在胶束边界，形成胶束，实际上起着破坏膜的洗涤剂的作用。蛇毒磷脂酶 A₂ 从膜磷脂上除去一条链，其部分毒性就在于产生溶血磷脂。用于抽提膜蛋白的洗涤剂（十二烷基硫酸盐、Triton X-100）正是同一条理由：$P$ 小于 $\tfrac13$ 的单链两亲分子。
:::
:::

## 生物膜

膜脂的聚集由**疏水效应**驱动（[[biochemistry/water-noncovalent#def-hydrophobic]]）：把烃链移出水的有效接触就释放出有序化的水、提高溶剂的熵，于是双分子层自发组装、撕裂后又能重新封口。**脂双分子层**厚约 $5\ \mathrm{nm}$，两层头基之间是约 $3\ \mathrm{nm}$ 的烃核心。核心是具有烃的极性的液体（相对介电常数约 2，对比水的 78），仅此一条就决定了它的通透性。

### 流动镶嵌模型

在**流动镶嵌模型**（Singer 与 Nicolson，1972）中，蛋白质嵌入或附着在一个两维的脂质流体里。**整合膜蛋白**横穿双分子层，通常是约 20 个残基长的 $\alpha$ 螺旋束，外侧面是疏水的（或者，在细菌、线粒体和叶绿体的外膜中，是 $\beta$ 桶）；**外周蛋白**结合在表面。脂质和许多蛋白质都能快速横向扩散。在二维中，时间 $t$ 后的均方位移为 $\langle r^2\rangle = 4Dt$，磷脂的侧向扩散系数约 $1\ \mu\mathrm{m^2\,s^{-1}}$，所以一秒内一个脂质分子能探索约 $\sqrt{4 \times 1 \times 1}\ \mu\mathrm{m} = 2\ \mu\mathrm{m}$——一根细菌那么长。横向扩散即从一层**翻转**到另一层的 flip-flop，需要把一个极性头基拽过烃核心，没有酶时极其缓慢（几小时到几天）。因此膜是**不对称**的：两层组分不同，由 ATP 驱动的翻转酶维持；而磷脂酰丝氨酸出现在外层，是一个细胞正在死亡的信号。

双分子层还会"熔化"。低于转变温度 $T_\mathrm{m}$，链伸展而有序（凝胶相）；高于它则无序（流动相）。纯 DPPC 的 $T_\mathrm{m} = 41\ \mathrm{^\circ C}$；链更短或含不饱和键则更低。细胞靠调节链的组成来保持膜的流动性——在寒冷中生长的细菌制造更多不饱和脂肪酸——而胆固醇充当流动性的缓冲剂：它使流动的链有序、使凝胶相的链无序，于是尖锐的转变被抹平成宽缓的过渡。

### 通透性

小的非极性分子（$\mathrm{O_2}$、$\mathrm{CO_2}$、$\mathrm{N_2}$、类固醇激素）溶入核心便快速穿过双分子层。小的不带电极性分子（水、尿素、甘油）慢一些，大的极性分子（葡萄糖）和离子则几乎不能：双分子层对 $\mathrm{Na^+}$ 或 $\mathrm{K^+}$ 的通透系数约 $10^{-12}\ \mathrm{cm\,s^{-1}}$，比水小约 $10^{9}$ 倍。原因是静电的：一个离子的玻恩能 $\propto z^2/\varepsilon_\mathrm{r}$，当它从水（$\varepsilon_\mathrm{r} \approx 78$）移到烃（$\varepsilon_\mathrm{r} \approx 2$）时上升超过 $100\ \mathrm{kJ\,mol^{-1}}$（[[biochemistry/water-noncovalent#prop-coulomb]]）。所以纯净的双分子层是一流的绝缘体，离子和极性养分的几乎全部交通都需要蛋白质。

## 跨膜转运

膜转运蛋白分三类。**通道**形成可开可关的水孔；离子沿其电化学梯度以高达每秒 $10^{7}$–$10^{8}$ 个离子的速率穿过，选择性由一个滤器的几何决定（$\mathrm{K^+}$ 通道剥去 $\mathrm{K^+}$ 的合水水分子、代之以恰好适合 $\mathrm{K^+}$ 而对较小的 $\mathrm{Na^+}$ 间距过大的羰基氧）。**载体**（转运蛋白）在一侧结合底物、改变构象、在另一侧释放，速率低得多（每秒 $10^2$–$10^{4}$）。**泵**是把转运与 ATP 水解偶联起来的载体。

这一切服从一条热力学规则。驱动转运的量是**电化学势**之差，它合并了一个浓度项和一个电学项。

::: proposition 转运的自由能 {#prop-transport}
在稀溶液近似下、温度 $T$，把 $1\ \mathrm{mol}$ 电荷数为 $z$ 的溶质从膜外（浓度 $c_\mathrm{out}$，电势 $\psi_\mathrm{out}$）转移到膜内（$c_\mathrm{in}$，$\psi_\mathrm{in}$），
$$
\Delta G_\mathrm{t} = RT\ln\frac{c_\mathrm{in}}{c_\mathrm{out}} + zF\,\Delta\psi, \qquad \Delta\psi = \psi_\mathrm{in} - \psi_\mathrm{out}.
$$ {#eq-transport}
若 $\Delta G_\mathrm{t} < 0$，转运自发进行（被动转运）；若 $\Delta G_\mathrm{t} > 0$，就必须与一个放能过程偶联（主动转运）。平衡时 $\Delta G_\mathrm{t} = 0$ 给出离子处于平衡时的膜电位，即**能斯特方程**：
$$
\Delta\psi_\mathrm{eq} = \frac{RT}{zF}\ln\frac{c_\mathrm{out}}{c_\mathrm{in}}.
$$ {#eq-nernst-membrane}
:::

::: proof 从电化学势出发
电势为 $\psi$ 的一相中离子 $i$ 的电化学势为 $\tilde\mu_i = \mu_i^\circ + RT\ln(c_i/c^\circ) + z_iF\psi$：[[thermodynamics/mixtures]]中理想稀近似下的化学势（活度以浓度代替），加上把每摩尔电荷带到该电势所需的电功 $z_iF\psi$。标准化学势 $\mu_i^\circ$ 两侧相同，因为溶剂相同。把 $1\ \mathrm{mol}$ 从外移到内，吉布斯能改变 $\tilde\mu_i(\mathrm{in}) - \tilde\mu_i(\mathrm{out})$；标准项相消，对数合并为 $RT\ln(c_\mathrm{in}/c_\mathrm{out})$，电学项合并为 $zF(\psi_\mathrm{in} - \psi_\mathrm{out})$，即[[#eq-transport]]。令其为零、解出 $\Delta\psi$ 即得[[#eq-nernst-membrane]]。对不带电溶质（$z = 0$）电学项消失，平衡就是两侧浓度相等。
:::

生物学家引用膜电位用内减外；静息动物细胞的 $\Delta\psi \approx -70\ \mathrm{mV}$（内负）。$37\ \mathrm{^\circ C}$ 时 $RT\ln 10 = 5.94\ \mathrm{kJ\,mol^{-1}}$，所以每个十倍浓度比值值 $5.94\ \mathrm{kJ\,mol^{-1}}$，而每单位电荷 $F \times 0.1\ \mathrm{V} = 9.65\ \mathrm{kJ\,mol^{-1}}$：对离子，电学项与浓度项同样重要。下图把两者都画了出来。

### 被动转运与易化扩散

葡萄糖自己不可能以有用的速率穿过双分子层，但多数动物细胞经由 GLUT 转运蛋白以**易化扩散**吸收它。易化扩散是被动的——它只会把葡萄糖沿浓度梯度移动（$z = 0$，故 $\Delta G_\mathrm{t} < 0$ 意味着 $c_\mathrm{in} < c_\mathrm{out}$）——但它由蛋白质介导，因此快速、专一而且**可饱和**。载体在胞外侧结合葡萄糖，翻面，在胞内释放，所以通量服从与酶相同的悬线双曲线（[[biochemistry/enzymes#prop-mm]]）：
$$
J = \frac{J_\mathrm{max}\,c_\mathrm{out}}{K_\mathrm{t} + c_\mathrm{out}},
$$
其中转运常数 $K_\mathrm{t}$ 扮演 $K_\mathrm{M}$ 的角色（红细胞的转运蛋白 GLUT1，Nelson 与 Cox 给出 $K_\mathrm{t} \approx 1.5\ \mathrm{mmol\,dm^{-3}}$）。相比之下，透过脂质的简单扩散服从菲克定律，通量 $= P\,\Delta c$，与浓度成正比且不饱和。

### 主动转运

**初级主动转运**直接使用 ATP。动物细胞质膜上的 **Na⁺/K⁺-ATP 酶**每水解一个 ATP 泵出三个 $\mathrm{Na^+}$、泵入两个 $\mathrm{K^+}$。它是一种 **P 型 ATP 酶**：磷酸化自身的一个天冬氨酸残基，磷酸化与去磷酸化的两种形态朝向膜的相反两侧，对离子的亲和力不同。因为每个循环移出一个净正电荷，它是**生电性**的，直接对内侧的负电有贡献。它消耗静息动物 ATP 的很大一块——总体四分之一或更多，神经组织中多得多。

::: example 钠泵的代价 {#ex-na-k-pump}
某典型哺乳动物细胞（数值按 Berg 等）$[\mathrm{Na^+}]_\mathrm{in} = 12$、$[\mathrm{Na^+}]_\mathrm{out} = 145$、$[\mathrm{K^+}]_\mathrm{in} = 140$、$[\mathrm{K^+}]_\mathrm{out} = 4\ \mathrm{mmol\,dm^{-3}}$，$\Delta\psi = -70\ \mathrm{mV}$。计算 $37\ \mathrm{^\circ C}$ 下泵出 $3\ \mathrm{Na^+}$、泵入 $2\ \mathrm{K^+}$ 所需的自由能，并与细胞中 ATP 水解的自由能（约 $-50$ 到 $-60\ \mathrm{kJ\,mol^{-1}}$，[[biochemistry/bioenergetics#ex-atp-cell]]）比较。
::: solution
$310.15\ \mathrm{K}$ 时 $RT = 2.579\ \mathrm{kJ\,mol^{-1}}$，每单位电荷 $F\,|\Delta\psi| = (96\,485)(0.070) = 6.754\ \mathrm{kJ\,mol^{-1}}$。

**钠出。**从内到外，[[#eq-transport]]中的符号反转：$\Delta G = RT\ln(c_\mathrm{out}/c_\mathrm{in}) + zF(\psi_\mathrm{out} - \psi_\mathrm{in})$，且 $\psi_\mathrm{out} - \psi_\mathrm{in} = +0.070\ \mathrm{V}$：
$$
\Delta G_\mathrm{Na} = 2.579\ln\frac{145}{12} + 6.754 = 6.425 + 6.754 = +13.18\ \mathrm{kJ\,mol^{-1}}.
$$
两项都反对这次移动：钠在浓度上被推向上坡*而且*逆着把阳离子拉进来的电场向外。

**钾入。**$\Delta G_\mathrm{K} = 2.579\ln(140/4) + (1)(96.485)(-0.070) = 9.168 - 6.754 = +2.41\ \mathrm{kJ\,mol^{-1}}$。这里电场帮忙，浓度的代价大部分在电学上得到偿还。

**总计。**$3(13.18) + 2(2.41) = 39.5 + 4.8 = 44.4\ \mathrm{kJ}$ 每循环。细胞条件下 ATP 水解提供 $50$–$60\ \mathrm{kJ\,mol^{-1}}$，所以每循环一个 ATP 足够，且留有余量使泵保持向前。标准值 $\Delta G^{\circ\prime} = -30.5\ \mathrm{kJ\,mol^{-1}}$ 则*不够*：泵的运转有赖于细胞把 ATP 维持在远离其与 ADP 和磷酸盐的平衡的位置。
:::
:::

**次级主动转运**利用泵建立的离子梯度去推动另一种溶质上坡。**同向转运体**让两者同向移动，**逆向转运体**反向。肠道和肾脏的 **Na⁺–葡萄糖同向转运体** SGLT1 每运进一个葡萄糖就带入两个 $\mathrm{Na^+}$，于是钠内流的大下坡自由能能把葡萄糖在上皮细胞内浓集，葡萄糖再经 GLUT2 以易化扩散进入血液。心肌的 $\mathrm{Na^+/Ca^{2+}}$ 交换体是一种逆向转运体；大肠杆菌的乳糖通透酶是一种 $\mathrm{H^+}$–乳糖同向转运体，由[[biochemistry/oxidative-phosphorylation#prop-pmf]]的质子梯度驱动。

::: example 钠能把葡萄糖浓集到什么程度？ {#ex-sglt}
用[[#ex-na-k-pump]]的钠浓度和膜电位，求 SGLT1（每个葡萄糖 2 个 Na⁺）在 $37\ \mathrm{^\circ C}$ 能维持的最大比值 $[\text{葡萄糖}]_\mathrm{in}/[\text{葡萄糖}]_\mathrm{out}$。一个 1 : 1 的同向转运体能达到多少？
::: solution
一个 $\mathrm{Na^+}$ 进入时，$\Delta G_\mathrm{Na} = RT\ln(12/145) + F(-0.070) = -6.425 - 6.754 = -13.18\ \mathrm{kJ\,mol^{-1}}$。整个过程 $2\,\mathrm{Na^+_{out}} + \mathrm{Glc_{out}} \rightarrow 2\,\mathrm{Na^+_{in}} + \mathrm{Glc_{in}}$ 在平衡时达到
$$
RT\ln\frac{[\text{葡萄糖}]_\mathrm{in}}{[\text{葡萄糖}]_\mathrm{out}} + 2\Delta G_\mathrm{Na} = 0 \quad\Rightarrow\quad \frac{[\text{葡萄糖}]_\mathrm{in}}{[\text{葡萄糖}]_\mathrm{out}} = \exp\!\left(\frac{26.36}{2.579}\right) = e^{10.22} = 2.8\times10^{4}.
$$
1 : 1 的同向转运体只给 $e^{5.11} = 1.7\times10^{2}$。偶联的化学计量数以指数的形式进来：第二个钠把可达到的比值平方。实际上细胞把这个比值维持在远低于极限的地方，但这个余量意味着即使肠腔中葡萄糖浓度很低，它也能被完全吸收。同样的推理适用于每一个偶联转运体：最大比值是偶联自由能除以 $RT$ 后的指数。
:::
:::

## 后续内容

葡萄糖以 6-磷酸葡萄糖的身份进入代谢，它的分解与再合成是[[biochemistry/glycolysis-citric-acid]]的主题；由 UDP-葡萄糖合成糖原以及磷酸化酶对其的受控降解在那里、并在[[biochemistry/lipid-nitrogen-metabolism]]的激素整合中重新出现，那一章也涵盖这里遇到的脂肪酸的氧化与合成。[[#prop-transport]]的膜电位与电化学势论证，正是[[biochemistry/oxidative-phosphorylation]]化学渗透学说中用于质子的同一套论证——线粒体内膜对离子的不通透在那里成了制造 ATP 的手段。驱动钠泵的 ATP 热力学在[[biochemistry/bioenergetics]]中展开，能斯特方程的电化学在[[electrochemistry/cell-thermodynamics]]，而两亲分子的自组装——胶束、囊泡及其在药物递送中的应用——将在[[polymer-chemistry/polymer-solutions]]和[[medicinal-chemistry/pharmacokinetics]]中归来。

::: history
奥古斯丁-皮埃尔·迪布吕诺在 1846 年观察到新配葡萄糖溶液的旋光度随放置而变化——变旋作用——尽管它的解释要等到环状结构的确立。埃米尔·费歇尔在 1888 至 1894 年间确立了葡萄糖及其异构体的相对构型，用的是基利安（Kiliani）链延长法和所得二酸的对称性，并因糖与嘌呤的工作获 1902 年诺贝尔化学奖；D/L 惯例出自他手。沃尔特·诺曼·哈沃斯在二十世纪二十年代证明葡萄糖通常是六元的吡喃糖，并引入了以他命名的透视式；他与保罗·卡雷尔分享 1937 年诺贝尔化学奖。膜方面，埃维尔特·戈尔泰尔与弗朗索瓦·格伦德尔 1925 年从红细胞抽提脂质，铺成单分子层，发现面积约为细胞表面积的两倍，从而提出双分子层。延斯·克里斯蒂安·斯库 1957 年在蟹神经中发现 Na⁺/K⁺-ATP 酶（1997 年诺贝尔化学奖），罗伯特·克雷恩 1960 年提出钠-葡萄糖共转运，S. 乔纳森·辛格与加斯·尼科尔森 1972 年发表流动镶嵌模型。
:::

::: summary
- 单糖是多羟基醛和酮；含 $n$ 个碳的醛糖有 $2^{n-2}$ 个立体异构体，按离羰基最远的立体中心标 D 或 L。差向异构体只差一个立体中心。
- 糖环化成半缩醛（吡喃糖、呋喃糖），产生经变旋作用互变的 $\alpha$ 与 $\beta$ 异头物；平衡时葡萄糖约 64 % 为 $\beta$ 型。
- 糖苷键是异头碳上的缩醛；它锁定异头构型，对水解热力学不稳定而动力学惰性，在细胞中由核苷糖合成。
- $\alpha$(1→4) 葡聚糖（淀粉、糖原）成螺旋，是燃料；$\beta$(1→4) 葡聚糖（纤维素）成直的氢键纤维。分支给糖原许多非还原端以便快速动员；聚合成大分子避免了渗透压力。
- 脂肪酸的熔点随链长上升、随 *cis* 双键急剧下降；三酰甘油每克储存组织约含水合糖原六倍的能量。
- 两亲脂质经疏水效应自组装；堆积参数 $P = v/(a_0 l_\mathrm{c})$ 预测胶束（单链）或双分子层（双链）。膜是两维流体，flip-flop 缓慢，对离子的通透性极低。
- 转运服从 $\Delta G_\mathrm{t} = RT\ln(c_\mathrm{in}/c_\mathrm{out}) + zF\Delta\psi$；易化扩散被动且可饱和；Na⁺/K⁺-ATP 酶每个 ATP 泵出 3 个 Na⁺、泵入 2 个 K⁺；次级转运体利用离子梯度，化学计量数充当指数。
:::

## 习题

::: exercise D-醛戊糖 {level=1 check="4"}
D-醛戊糖共有几个？说出 RNA 中含的那一个，并说明 2-脱氧-D-核糖与它有何不同。（输入 D-醛戊糖的数目。）
::: solution
醛戊糖 $\mathrm{OHC{-}(CHOH)_3{-}CH_2OH}$ 有三个立体中心（C-2、C-3、C-4），得 $2^3 = 8$ 个立体异构体。C-4 决定 D 或 L，故有 $2^2 = 4$ 个 D-醛戊糖：D-核糖、D-阿拉伯糖、D-木糖和 D-来苏糖。RNA 含 D-核糖（$\beta$-呋喃型）；DNA 的糖 2-脱氧-D-核糖在 C-2 以 H 代替 OH，这既去掉了那里的立体中心，更重要的是去掉了使 RNA 易受碱催化水解的相邻羟基。
:::
:::

::: exercise 还原还是不还原 {level=1}
判断下列物质有无还原性并说明理由：(a) D-半乳糖；(b) 乳糖；(c) 蔗糖；(d) 海藻糖 Glc(α1↔1α)Glc；(e) $\alpha$-D-吡喃葡萄糖甲苷；(f) 糖原。
::: solution
(a) 还原性：游离半缩醛可开成醛。(b) 还原性：葡萄糖残基的异头碳是游离的。(c) 非还原性：两个异头碳都在糖苷键里。(d) 非还原性，理由相同：两个葡萄糖以 C-1 连 C-1。(e) 非还原性：异头碳是缩醛（甲基糖苷），不能打开。(f) 每个糖原分子有一个还原端（实际上连在糖原蛋白上）和数千个非还原端；就实际目的而言糖原是非还原的，因为还原端占残基的比例可以忽略。
:::

::: exercise 钾的平衡电位 {level=1 check="-95"}
$37\ \mathrm{^\circ C}$ 下 $[\mathrm{K^+}]_\mathrm{in} = 140$、$[\mathrm{K^+}]_\mathrm{out} = 4\ \mathrm{mmol\,dm^{-3}}$，计算 $\mathrm{K^+}$ 处于平衡时的膜电位 $\Delta\psi = \psi_\mathrm{in} - \psi_\mathrm{out}$。（$R = 8.314\ \mathrm{J\,K^{-1}\,mol^{-1}}$，$F = 96\,485\ \mathrm{C\,mol^{-1}}$。）（$\Delta\psi$ 以 mV 输入，取整到毫伏。）
::: solution
由[[#eq-nernst-membrane]]，取 $z = 1$：$\Delta\psi = (RT/F)\ln(c_\mathrm{out}/c_\mathrm{in}) = (26.73\ \mathrm{mV})\ln(4/140) = (26.73)(-3.555) = -95\ \mathrm{mV}$。典型细胞的静息电位约 $-70\ \mathrm{mV}$，接近但没那么负，因为静息膜主要（却不是唯一）对 $\mathrm{K^+}$ 通透；小的 $\mathrm{Na^+}$ 泄漏（其能斯特电位为 $+67\ \mathrm{mV}$）把它往正的方向拉。
:::
:::

::: exercise 平衡时的半乳糖 {level=2 check="0.72"}
$\alpha$-D-吡喃半乳糖的 $[\alpha]_\mathrm{D} = +150.7^\circ$，$\beta$-D-吡喃半乳糖为 $+52.8^\circ$；平衡混合物为 $+80.2^\circ$。假定只有两种吡喃糖存在，求平衡时 $\beta$ 异头物的分数，以及 $\alpha \rightleftharpoons \beta$ 在 $298.15\ \mathrm{K}$ 的 $\Delta G^\circ$。（$\beta$ 的分数保留两位有效数字输入。）
::: solution
$x_\beta = (150.7 - 80.2)/(150.7 - 52.8) = 70.5/97.9 = 0.720$，即约 $72\ \%$ 为 $\beta$ 型。$K = 0.720/0.280 = 2.57$，$\Delta G^\circ = -RT\ln K = -(8.314)(298.15)\ln 2.57 = -2.34\ \mathrm{kJ\,mol^{-1}}$。与葡萄糖一样，异头 OH 处于平伏位置的异头物占优。
:::
:::

::: exercise GLUT1 的饱和 {level=2 check="0.769"}
GLUT1 对葡萄糖的 $K_\mathrm{t} = 1.5\ \mathrm{mmol\,dm^{-3}}$。当胞外葡萄糖浓度为 $5.0\ \mathrm{mmol\,dm^{-3}}$、胞内浓度可忽略时，它以最大内流的多大分数工作？$10\ \mathrm{mmol\,dm^{-3}}$ 时呢？（$5.0\ \mathrm{mmol\,dm^{-3}}$ 时的分数保留三位有效数字输入。）
::: solution
$J/J_\mathrm{max} = c/(K_\mathrm{t} + c) = 5.0/6.5 = 0.769$。$10\ \mathrm{mmol\,dm^{-3}}$ 时，$10/11.5 = 0.870$。血糖翻倍，摄取只增加 $13\ \%$：转运体接近饱和，使血糖波动时红细胞和脑的葡萄糖供应保持稳定。
:::
:::

::: exercise 侧向扩散 {level=2 check="25"}
一个磷脂的侧向扩散系数为 $1.0\ \mu\mathrm{m^2\,s^{-1}}$。用 $\langle r^2\rangle = 4Dt$，其均方根位移达到 $10\ \mu\mathrm{m}$（一个典型动物细胞的尺寸）需要多久？与 flip-flop 比较。（时间以秒输入。）
::: solution
$t = \langle r^2\rangle/4D = (10\ \mu\mathrm{m})^2/(4 \times 1.0\ \mu\mathrm{m^2\,s^{-1}}) = 25\ \mathrm{s}$。因为位移只随 $\sqrt t$ 增长，十倍的距离要一百倍的时间。纯双分子层中磷脂的 flip-flop 要几小时到几天——比横向穿过整个细胞大约慢 $10^{3}$ 到 $10^{4}$ 倍，因为极性头基必须穿过烃核心；这就是膜不对称性得以维持的原因。
:::
:::

::: exercise 泵钙 {level=3 check="39.0"}
质膜 $\mathrm{Ca^{2+}}$-ATP 酶把钙泵出细胞。计算 $37\ \mathrm{^\circ C}$、$[\mathrm{Ca^{2+}}]_\mathrm{in} = 0.10\ \mu\mathrm{mol\,dm^{-3}}$、$[\mathrm{Ca^{2+}}]_\mathrm{out} = 2.0\ \mathrm{mmol\,dm^{-3}}$、$\Delta\psi = -70\ \mathrm{mV}$ 时把 $1\ \mathrm{mol}$ 的 $\mathrm{Ca^{2+}}$ 运出细胞所需的自由能，并判断一个 ATP（细胞内约 $-55\ \mathrm{kJ\,mol^{-1}}$）能泵一个还是两个钙离子。（每摩尔 $\mathrm{Ca^{2+}}$ 的自由能以 $\mathrm{kJ\,mol^{-1}}$ 保留三位有效数字输入。）
::: hint
浓度比是 $2\times10^{4}$，而 $z = 2$ 使电学项加倍。
:::
::: solution
外运时 $\Delta G = RT\ln(c_\mathrm{out}/c_\mathrm{in}) + zF(\psi_\mathrm{out} - \psi_\mathrm{in}) = (2.579)\ln(2.0\times10^{-3}/1.0\times10^{-7}) + 2(96.485)(0.070)$。第一项是 $2.579 \times 9.903 = 25.54\ \mathrm{kJ\,mol^{-1}}$，第二项 $13.51\ \mathrm{kJ\,mol^{-1}}$，总计 $39.0\ \mathrm{kJ\,mol^{-1}}$。一个 ATP（约 $55\ \mathrm{kJ\,mol^{-1}}$）付得起一个 $\mathrm{Ca^{2+}}$（$39\ \mathrm{kJ}$），付不起两个（$78\ \mathrm{kJ}$）；质膜泵确实每个 ATP 移动一个 $\mathrm{Ca^{2+}}$（与质子交换，从而降低电学代价）。它所维持的上万倍梯度，正是 $\mathrm{Ca^{2+}}$ 成为如此有效的细胞内信号的原因：打开少量通道，就能在几毫秒内使胞质浓度上升十倍。
:::

::: exercise 一般同向转运极限 {level=3}
一个同向转运体把不带电溶质 S 的吸收与 $n$ 个电荷为 $z$ 的离子的进入相偶联。(a) 用[[#prop-transport]]证明平衡时
$$
\frac{[\mathrm{S}]_\mathrm{in}}{[\mathrm{S}]_\mathrm{out}} = \left(\frac{c_\mathrm{out}}{c_\mathrm{in}}\right)^{n}\exp\!\left(-\frac{nzF\Delta\psi}{RT}\right),
$$
其中 $c$ 指偶联离子。(b) 对大肠杆菌的乳糖通透酶（对 $\mathrm{H^+}$：$n = 1$，$z = +1$），细胞质比介质碱 $0.5$ 个 pH 单位，$25\ \mathrm{^\circ C}$ 时 $\Delta\psi = -120\ \mathrm{mV}$，估算乳糖积累的最大比值。
::: hint
把整个偶联过程的自由能写成 S 的一项加 $n$ 项离子项，令其为零，再取指数。pH 差 $0.5$ 就是 $[\mathrm{H^+}]$ 的 $10^{0.5}$ 倍。
:::
::: solution
(a) 对过程 $\mathrm{S_{out}} + n\,\mathrm{X^{z}_{out}} \rightarrow \mathrm{S_{in}} + n\,\mathrm{X^{z}_{in}}$，把转运自由能相加：$\Delta G = RT\ln([\mathrm{S}]_\mathrm{in}/[\mathrm{S}]_\mathrm{out}) + n[RT\ln(c_\mathrm{in}/c_\mathrm{out}) + zF\Delta\psi]$。平衡时 $\Delta G = 0$，故 $\ln([\mathrm{S}]_\mathrm{in}/[\mathrm{S}]_\mathrm{out}) = n\ln(c_\mathrm{out}/c_\mathrm{in}) - nzF\Delta\psi/RT$；取指数即得结果。(b) 细胞质更碱，所以 $c_\mathrm{out}/c_\mathrm{in} = [\mathrm{H^+}]_\mathrm{out}/[\mathrm{H^+}]_\mathrm{in} = 10^{0.5} = 3.16$。电学因子是 $\exp[-(96\,485)(-0.120)/(8.314 \times 298.15)] = e^{4.671} = 106.8$。比值为 $3.16 \times 106.8 \approx 3.4\times10^{2}$。驱动力大部分是电学的：[[biochemistry/oxidative-phosphorylation#prop-pmf]]的质子动力势以两种形式储能，而这个转运体把两种都花掉。
:::
:::

::: exercise 溶血脂质 {level=3 check="0.33"}
用坦福德公式和 $a_0 = 0.64\ \mathrm{nm^2}$，计算一条 16:0 链的溶血磷脂酰胆碱的堆积参数，并预测把它少量加到 DPPC 囊泡上的效应。为什么除去 C-2 脂肪酸的磷脂酶会损伤膜？（$P$ 保留两位有效数字输入。）
::: solution
$v = 0.0274 + 0.0269 \times 16 = 0.4578\ \mathrm{nm^3}$，$l_\mathrm{c} = 0.154 + 0.1265 \times 16 = 2.178\ \mathrm{nm}$，所以 $P = 0.4578/(0.64 \times 2.178) = 0.33$——处在球形与圆柱形的边界，呈锥形。少量 lyso-PC 进入 DPPC 囊泡的外层，通过偏好正曲率使双分子层渗漏；量再大一些就把双分子层溶成混合胶束，就像任何洗涤剂那样。磷脂酶 A₂ 把双链的成膜分子（$P \approx 0.66$）变成单链的成胶束分子加一条游离脂肪酸，等于就地变膜为洗涤剂。这是许多蛇毒、蜂毒以及释放花生四烯酸用于信号传导的酶的作用机理的一部分。
:::
