本课程迄今遇到的每一个反应，靠的都是分子自身的热能：碰撞的玻尔兹曼高能尾巴（[[kinetics/collision-theory]]）、靠 $RT$ 之助翻越的能垒、从平衡布居中抽样的过渡态（[[kinetics/transition-state-theory]]）。光化学从根本上改换了规则。吸收了一个光子的分子并不是借热量去攀爬基态能垒——它是被*整个举起*，放到一张激发态势能面上，携带着几百 $\mathrm{kJ\,mol^{-1}}$ 的电子能量，而任何 $\mathrm{300\ K}$ 的碰撞都提供不了这样的能量。在这张面上，分子有不同的键级、不同的几何构型、不同的酸性、不同的自旋，以及另一组能垒，其中大多数远比黑暗中保护同一个分子的那些能垒小得多。这就是光为什么能驱动热力学上坡的反应；为什么有些反应在 $\mathrm{200\ K}$ 和 $\mathrm{300\ K}$ 下速率相同；以及为什么光的量子（而不是浓度）成了速率方程中的自然单位。光化学动力学就是这套替代经济的记账法：吸收了多少光子；激发态分子中有多大比例去做化学、而不是把光发射回去；以及各条相互竞争的失活途径各自跑得多快。

## 光改变了什么：飞秒时间尺度上的激发

::: definition 电子激发与弗兰克-康登原理 {#def-excitation}
**电子激发**是指一个电子被从占据分子轨道提升到未占据分子轨道，由吸收一个能量 $h\nu$ 恰等于两态之间能隙的光子引起。由于电子跃迁耗时约 $10^{-15}\ \mathrm{s}$，而分子振动耗时 $10^{-14}$–$10^{-13}\ \mathrm{s}$，事件期间原子核实际上是被冻结的：吸收是画在*基态*几何坐标上的两张势能面之间的**竖直跃迁**。这就是**弗兰克-康登原理**。于是分子以基态几何构型到达激发面——通常远在激发态最小值之上——并在 $10^{-13}$–$10^{-11}\ \mathrm{s}$ 内通过**振动弛豫**在那里热化，而这远早于任何化学变化（至少需要 $10^{-12}\ \mathrm{s}$）可能发生的时候。
:::

其动力学后果就是本课的中心对照。热反应是从平衡布居中挑选出的稀有事件：速率是尝试频率乘以超过基态能垒的玻尔兹曼分数 $e^{-E_\mathrm{a}/RT}$，并且每升高几 $\mathrm{K}$ 就翻倍。光化学反应根本不是从尾巴里挑选的——光子*创造*了反应性布居，其速率由光强决定，且基本上与温度无关，因为激发态分子在激发面上反应，那里的能垒很小。一个基态能垒为 $250\ \mathrm{kJ\,mol^{-1}}$ 的反应（$\mathrm{C=C}$ 双键的 $\pi$ 键能垒，这就是*顺*、*反*烯烃不会在你桌面上互变的原因）在黑暗中不可见，在灯下几秒即达终了。

而热力学并未被违反，只是重新记账。相关的自由能变化不再是暗反应的 $\Delta G$，而是每个分子的 $\Delta G - h\nu$：**一个分子加一个光子**，能够战胜远大于该光子热力学对手的 $\Delta G$。一个 $\mathrm{300\ nm}$ 光子携带 $\mathrm{399\ kJ\,mol^{-1}}$（按每摩尔光子计）的自由能（[[#ex-photon-energy]]），所以黑暗中上坡 $50\ \mathrm{kJ\,mol^{-1}}$ 的异构化——比如反式二苯乙烯（*trans*-stilbene）变顺式——在 $\mathrm{300\ nm}$ 光照下顺利进行；而受照混合物停下的位置不是热力学平衡，而是**光稳态**，其组成由两个方向的吸收带和量子产率决定，而非由 $\Delta G$ 决定。光是一种你可以按艾因斯坦（einstein）计量、并随时关掉的试剂。

::: proposition 吸收的光：朗伯-比尔定律的动力学形式 {#prop-absorption}
强度为 $I_0$（单位时间单位面积的能量）的单色平行光束穿过浓度为 $c$、光程为 $z$ 的吸收溶液，服从（常用的以 $10$ 为底的单位）
$$
I(z) = I_0\,10^{-\varepsilon c z} = I_0\,10^{-A},
\qquad A = \varepsilon c z,
$$
其中 $\varepsilon$ 是摩尔吸收系数，单位 $\mathrm{dm^{3}\,mol^{-1}\,cm^{-1}}$，$A$ 为吸光度。因此长度为 $\ell$ 的比色皿**吸收**的强度为
$$
I_\text{abs} = I_0 - I(\ell) = I_0\left(1 - 10^{-A}\right),
$$
而在**低吸光度极限**（$A \ll 1$）下，由于 $10^{-A} = e^{-2.303A} \approx 1 - 2.303A$，
$$
I_\text{abs} \approx 2.303\,I_0 A = 2.303\,I_0\,\varepsilon c \ell .
$$
在光化学动力学中只有 $I_\text{abs}$ 算数：透射的光子什么也不做。自然单位是**艾因斯坦**——一摩尔光子，即 $N_\mathrm{A} = 6.022\times10^{23}$ 个光子——以及以艾因斯坦 $\mathrm{s^{-1}}$ 计的**光子通量**；以艾因斯坦 $\mathrm{s^{-1}}$ 为单位的强度乘以量子产率就直接给出摩尔速率。
:::

::: example 一个光子与一个艾因斯坦的能量 {#ex-photon-energy}
求 $\lambda = \mathrm{300\ nm}$ 光的一个光子的能量、以及一个艾因斯坦该光的能量，并与键能比较。
::: solution
$$
E = \frac{hc}{\lambda} = \frac{6.626\times10^{-34}\ \mathrm{J\,s} \times 2.998\times10^{8}\ \mathrm{m\,s^{-1}}}{300\times10^{-9}\ \mathrm{m}} = 6.62\times10^{-19}\ \mathrm{J}.
$$
一个艾因斯坦就是摩尔数的这种光子：
$$
E_\mathrm{m} = 6.62\times10^{-19} \times 6.022\times10^{23} = 3.99\times10^{5}\ \mathrm{J\,mol^{-1}} = 399\ \mathrm{kJ\,mol^{-1}}.
$$
作为参照：断裂一个 $\mathrm{C{-}Br}$ 键约需 $293\ \mathrm{kJ\,mol^{-1}}$，一个 $\mathrm{C=C}$ 的 $\pi$ 键约 $265\ \mathrm{kJ\,mol^{-1}}$，所以单个 $\mathrm{300\ nm}$ 光子携带的能量足以断裂其中任何一个——这正是烷基溴在近紫外光下光解、烯烃发生异构化的原因。$\mathrm{436\ nm}$ 的蓝光每个艾因斯坦携带 $274\ \mathrm{kJ\,mol^{-1}}$：仍有断键之力，这也是可见光光化学需要带隙小或键弱的敏化剂染料的原因。波长依赖全在 $1/\lambda$ 里：波长减半，光子能量加倍。
:::
:::

::: example 灯的光子通量 {#ex-lamp-flux}
一盏光解灯把 $\mathrm{5.0\ W}$ 的辐射功率以 $\lambda = \mathrm{313\ nm}$ 谱线送入反应容器。求光子通量，以每秒光子数和每秒艾因斯坦计。
::: solution
每个光子的能量：
$$
E = \frac{hc}{\lambda} = \frac{1.986\times10^{-25}\ \mathrm{J\,m}}{313\times10^{-9}\ \mathrm{m}} = 6.35\times10^{-19}\ \mathrm{J}.
$$
每秒光子数：
$$
\frac{P}{E} = \frac{5.0\ \mathrm{J\,s^{-1}}}{6.35\times10^{-19}\ \mathrm{J}} = 7.9\times10^{18}\ \mathrm{s^{-1}}.
$$
以艾因斯坦计：
$$
\frac{7.9\times10^{18}}{6.022\times10^{23}} = 1.3\times10^{-5}\ \mathrm{einstein\,s^{-1}} = 13\ \mu\mathrm{mol\,s^{-1}}.
$$
两个被算术掩盖的告诫。第一，这里的 $\mathrm{5.0\ W}$ 是*波长 $\mathrm{313\ nm}$ 处被化学吸收的辐射功率*，不是插电功率：一盏标称 $\mathrm{125\ W}$ 的灯在有用谱线上可能只输出几瓦，其余都是热。第二，这是*到达*的光通量；*吸收*的通量是 $I_0(1-10^{-A})$，只有它进入速率方程。
:::
:::

::: example 低吸光度近似及其检验 {#ex-iabs-lowA}
某溶液在灯的波长处 $\varepsilon = 150\ \mathrm{dm^{3}\,mol^{-1}\,cm^{-1}}$，$c = 2.00\times10^{-4}\ \mathrm{mol\,dm^{-3}}$，置于 $\mathrm{1.00\ cm}$ 比色皿中。多大比例的光被吸收？把精确表达式与极限 $I_\text{abs}/I_0 \approx 2.303 A$ 比较。
::: solution
$A = \varepsilon c \ell = 150 \times 2.00\times10^{-4} \times 1.00 = 0.0300$。精确值：
$$
\frac{I_\text{abs}}{I_0} = 1 - 10^{-0.0300} = 1 - 0.9332 = 0.0667 .
$$
近似值：$2.303 \times 0.0300 = 0.0691$，高估 $3.5\ \%$。在 $A = 0.10$ 处，同一近似误差达 $12\ \%$；在 $A = 1$ 处它预言 $I_\text{abs} = 2.3 I_0$——荒谬。经验规则：只在 $A \approx 0.05$ 以下使用 $I_\text{abs} \approx 2.303 I_0 A$，此时它精确到百分之几；正是它使低吸光度光化学对吸收组分浓度为一级，因为此时吸收强度正比于 $c$。
:::
:::

## 斯塔克-爱因斯坦定律与量子产率

::: definition 量子产率；斯塔克-爱因斯坦定律 {#def-quantum-yield}
光化学过程的**量子产率** $\Phi$ 定义为
$$
\Phi = \frac{\text{反应分子数（或事件数）}}{\text{吸收光子数}} = \frac{\text{产物摩尔数}}{\text{吸收艾因斯坦数}} ,
$$
是一个纯数。**斯塔克-爱因斯坦光化学等价定律**指出：给定频率的光以 $h\nu$ 为单位起作用：*一个光子被一个分子吸收，产生一个初级光化学事件*。由此，**初级**步骤的速率就是吸收光子通量，$v_\text{prim} = I_\text{abs}$，且初级量子产率不可能超过 $1$。表观 $\Phi$ 之所以不同于 $1$，是因为初级事件*之后*发生的事：失活途径使分子原样返回、把 $\Phi$ 压到 $1$ 以下；链载体和次级化学把每个吸收光子的效果放大、把 $\Phi$ 推到 $1$ 以上。
:::

::: example 由摩尔数与艾因斯坦数求量子产率 {#ex-phi-measure}
顺式二苯乙烯溶液在 $\mathrm{313\ nm}$ 下照射 $\mathrm{25.0\ min}$；校准过的光量计显示样品吸收 $2.00\times10^{-8}\ \mathrm{einstein\,s^{-1}}$。分析测得生成 $1.05\times10^{-5}\ \mathrm{mol}$ 反式二苯乙烯。求 $\Phi$。
::: solution
吸收的艾因斯坦数：
$$
2.00\times10^{-8}\ \mathrm{einstein\,s^{-1}} \times 1500\ \mathrm{s} = 3.00\times10^{-5}\ \mathrm{einstein}.
$$
量子产率：
$$
\Phi = \frac{1.05\times10^{-5}\ \mathrm{mol}}{3.00\times10^{-5}\ \mathrm{einstein}} = 0.35 .
$$
每吸收三个光子有两个顺式分子完成异构化：激发态大约三次里有两次没能反应，在逃离扭曲张几何之前就把能量交给了发射、内转换或逆向异构化。注意 $\Phi$ 之所以无量纲，只是因为我们数的是*吸收的*艾因斯坦；若不测 $A$ 而用入射通量，得到的将是一个随浓度和光程改变的、没有意义的"产率"。
:::
:::

::: warning Φ ≫ 1 并不推翻斯塔克-爱因斯坦定律 {#warn-phi-gt1}
氢气的光氯化 $\mathrm{H_2 + Cl_2 \rightarrow 2\,HCl}$ 在某些条件下量子产率高达 $10^{6}$；$\mathrm{H_2 + Br_2}$ 链给出几十。这对"一个光子一个事件"并非例外：光子仍然恰好产生一个初级事件（比如一次 $\mathrm{Cl_2}$ 解离），但那个事件孕育出一个**链载体**，在死亡之前周转数千次，正如 [[kinetics/chain-reactions]] 中那样。$\Phi > 1$ 是链机理的*证据*，而它高出 $1$ 多少，就是对动力学链长的一次测量。斯塔克-爱因斯坦定律真正深刻的例外只有两类：**双光子过程**，即分子几乎同时需要两个光子（其速率正比于 $I^2$，除激光下外可忽略）；以及上述链反应，其中*初级*产率是 1，而*表观*产率是光子之后的化学。绝不要从 $\Phi = 10^{3}$ 得出"一个光子直接完成了一千个反应"；要得出：一个光子启动了一场失控。
:::

## 雅布隆斯基图作为动力学方案

::: definition 雅布隆斯基图与失活途径 {#def-jablonski}
**雅布隆斯基图**把电子态按自旋多重度分列排布——单线态 $\mathrm{S_0, S_1, S_2, \ldots}$、三线态 $\mathrm{T_1}$，每个态内再叠振动能级——并把它们之间的跃迁画成箭头。各途径及其典型一级速率常数：
- **吸收** $\mathrm{S_0 \rightarrow S_n}$：强度意义上 $10^{12}$–$10^{14}\ \mathrm{s^{-1}}$，竖直（弗兰克-康登）；
- 同一态内的**振动弛豫**：$10^{13}$–$10^{11}\ \mathrm{s^{-1}}$；
- **内转换（IC）**，*同一*自旋态之间 $\mathrm{S_n \rightarrow S_{n-1}}$：$10^{14}$–$10^{11}\ \mathrm{s^{-1}}$；
- **荧光**，$\mathrm{S_1 \rightarrow S_0 + }h\nu_\mathrm{f}$：自旋允许，$k_\mathrm{f} \sim 10^{8}$–$10^{7}\ \mathrm{s^{-1}}$，寿命 $10^{-9}$–$10^{-7}\ \mathrm{s}$；
- **系间窜越（ISC）**，$\mathrm{S_1 \rightarrow T_1}$：自旋禁阻但自旋-轨道允许，$10^{11}$–$10^{6}\ \mathrm{s^{-1}}$，重原子增强；
- **磷光**，$\mathrm{T_1 \rightarrow S_0 + }h\nu_\mathrm{p}$：自旋禁阻，$10^{3}$–$0.1\ \mathrm{s^{-1}}$，寿命 $10^{-3}$–$10\ \mathrm{s}$ 甚至更长；
- 被溶质 $\mathrm{Q}$ **猝灭**：双分子，$k_q[\mathrm{Q}]$；
- **能量传递**（如 $\mathrm{S_1}$ 或 $\mathrm{T_1}$ 把能量交给邻居）与**电子转移**（激发态分子既是远更强的还原剂，也是远更强的氧化剂）。
由于振动弛豫和内转换快于荧光，发射几乎总是来自相应多重度的最低态——**卡莎规则**——这就是荧光光谱几乎不依赖激发波长的原因。
:::

这张图不是情绪板；它是一个**动力学方案**。每个箭头都是一个一级速率常数（双分子的那些是 $k_q[\mathrm{Q}]$），$\mathrm{S_1}$ 的布居按所有这些常数之和衰减，而每个量子产率都是一个分支比。

::: proposition 由方案求量子产率与寿命 {#prop-phi-tau}
设激发态 $\mathrm{S_1}$ 经荧光 $k_\mathrm{f}$、内转换 $k_\mathrm{IC}$、系间窜越 $k_\mathrm{ISC}$ 和猝灭 $k_q[\mathrm{Q}]$ 去布居，全为一级或拟一级。则
$$
\Phi_\mathrm{f} = \frac{k_\mathrm{f}}{k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC} + k_q[\mathrm{Q}]},
$$
而激发态布居按指数衰减，
$$
\frac{1}{\tau} = k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC} + k_q[\mathrm{Q}],
\qquad
\frac{1}{\tau_0} = k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC} \quad (\text{无猝灭剂}),
$$
其中 $\tau_0$ 是**自然（辐射）寿命**。特别地 $\Phi_\mathrm{f} = k_\mathrm{f}\,\tau$：观测寿命*测量的是分母*，所以两者合起来就给出各个常数。**斯特里克勒-贝尔格关系**把辐射常数与吸收光谱联系起来：$k_\mathrm{f}$ 随跃迁频率的三次方和吸收带强度增长，因为让分子吸收光子的同一个跃迁偶极矩也让它发射光子——强吸收的发色团就是快而亮的发射体，自然寿命约几个 $\mathrm{ns}$。
:::

::: proof 量子产率作为分支比 {#proof-phi}
设无限短激发脉冲之后 $[\mathrm{S_1}](0) = [\mathrm{S_1}]_0$ 且无猝灭剂。布居服从
$$
\frac{\mathrm{d}[\mathrm{S_1}]}{\mathrm{d}t} = -\left(k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC}\right)[\mathrm{S_1}] = -\frac{[\mathrm{S_1}]}{\tau_0},
\qquad
[\mathrm{S_1}](t) = [\mathrm{S_1}]_0\,e^{-t/\tau_0}.
$$
发射光子总数是荧光速率对时间的积分：
$$
N_\mathrm{f} = \int_0^\infty k_\mathrm{f}[\mathrm{S_1}]\,\mathrm{d}t
= k_\mathrm{f}[\mathrm{S_1}]_0 \int_0^\infty e^{-t/\tau_0}\,\mathrm{d}t
= k_\mathrm{f}\,\tau_0\,[\mathrm{S_1}]_0 .
$$
除以被激发分子数，并把 $\tau_0^{-1}$ 写成那个和，即得 $\Phi_\mathrm{f} = k_\mathrm{f}\tau_0 = k_\mathrm{f}/(k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC})$。加上猝灭剂会往每个分母同时添上 $k_q[\mathrm{Q}]$——既加到发射积分里，也加到衰减速率里——这就是[[#prop-stern-volmer]]的全部内容。同样的论证把分子换成 $k_\mathrm{ISC}$ 就给出三线态产率 $\Phi_\mathrm{T}$，换成反应常数 $k_\mathrm{r}$ 就给出化学产率 $\Phi_\mathrm{r} = k_\mathrm{r}\tau$；任何过程的量子产率都是它的速率常数乘以观测寿命。
:::

::: example 由速率常数求 Φ_f 与 τ {#ex-phifrom-k}
某荧光团 $k_\mathrm{f} = 5.0\times10^{7}\ \mathrm{s^{-1}}$，$k_\mathrm{IC} = 1.0\times10^{7}\ \mathrm{s^{-1}}$，$k_\mathrm{ISC} = 4.0\times10^{7}\ \mathrm{s^{-1}}$。求 $\Phi_\mathrm{f}$ 与 $\tau_0$。再加入猝灭剂使 $k_q[\mathrm{Q}] = 2.0\times10^{7}\ \mathrm{s^{-1}}$：求新的 $\Phi_\mathrm{f}$ 与 $\tau$。
::: solution
无猝灭剂时：
$$
\frac{1}{\tau_0} = (5.0 + 1.0 + 4.0)\times10^{7} = 1.0\times10^{8}\ \mathrm{s^{-1}}
\quad\Longrightarrow\quad
\tau_0 = 1.0\times10^{-8}\ \mathrm{s} = 10.0\ \mathrm{ns},
$$
$$
\Phi_\mathrm{f} = k_\mathrm{f}\tau_0 = 5.0\times10^{7} \times 1.0\times10^{-8} = 0.50 .
$$
有猝灭剂时总和变为 $1.2\times10^{8}\ \mathrm{s^{-1}}$，故 $\tau = 8.3\ \mathrm{ns}$，$\Phi_\mathrm{f} = 5.0\times10^{7}\times8.3\times10^{-9} = 0.42$。检验就是定理本身：$\Phi_\mathrm{f}/\Phi_\mathrm{f}^{(0)} = 0.42/0.50 = 0.83 = \tau/\tau_0$——猝灭把产率和寿命按*同一*因子压低，因为两者本是同一个分支比。
:::
:::

caption: 短脉冲后的激发态布居 $y = [\mathrm{S_1}]/[\mathrm{S_1}]_0$，时间以自然寿命 $\tau_0$ 为单位：精确指数 $e^{-t/\tau_0}$ 与欧拉法、休恩法、RK4 近似对照，步长 $h$ 可调。每条失活途径——荧光、内转换、系间窜越、猝灭——只改变*斜率* $1/\tau$，绝不改变指数形状，因为它们都是一级。所以从衰减曲线读 $\tau$ 永远是 $\ln y$ 对 $t$ 的直线拟合，而加入猝灭剂只是把直线变得更陡。
:::

::: warning 大 Φ_f 配短 τ 与大 Φ_f 配长 τ 是两种不同的材料 {#warn-bright-lifetime}
$\Phi_\mathrm{f} = k_\mathrm{f}\tau$ 是一个乘积，同一个值可以来自相反的平衡。一个 $\Phi_\mathrm{f} = 0.9$、$\tau = 1\ \mathrm{ns}$ 的荧光团有 $k_\mathrm{f} \approx 9\times10^{8}\ \mathrm{s^{-1}}$：它天生明亮，没有别的过程与之竞争。一个 $\Phi_\mathrm{f} = 0.9$、$\tau = 10\ \mathrm{ms}$ 的磷光体有 $k_\mathrm{f} \approx 90\ \mathrm{s^{-1}}$：它发射得慢是因为*禁阻*，而它保持激发的时间足够长，长到碰撞、氧和邻近分子都能找到它。前者是荧光标准品；后者是氧传感器和三重态光敏剂，而互换角色则毫无用处。只报量子产率而不报寿命（或反之），读者就无法分辨你给他的是哪种材料——而设计一个敏化剂意味着选择 $k_\mathrm{ISC}$ 和 $\tau_\mathrm{T}$，不只是"产率高"。
:::

::: history
光化学等价定律——一个光子、一个被活化的分子——由斯塔克（Stark）于 1908 年提出，并由爱因斯坦（Einstein）于 1912 年给出其经典形式，这是量子假说最早应用于化学的实例之一；该定律固定了*初级*步骤，而此后数十年发现大多数吸收的光子并*不*走向化学，正是这使量子产率成为一个待测之数而非自然常数。雅布隆斯基（Jablonski）1933 与 1935 年的图把荧光、磷光与暗途径汇成至今仍印在每本教科书上的那幅动力学图景；卡莎（Kasha）1950 年的规则——发射来自每个多重度的最低能级——解释了发射为何无视激发波长。暗态本身变得可测，要等到诺里什（Norrish）与波特（Porter）在 1950 年代发展闪光光解：用电容器放电脉冲激发样品，靠吸收捕捉短命的自由基与三重态；他们因使化学的快速中间体成为动力学的常规对象，与艾根（Eigen）分享了 1967 年诺贝尔化学奖。
:::

## 猝灭动力学：斯特恩-福尔默方程

::: proposition 斯特恩-福尔默方程 {#prop-stern-volmer}
猝灭剂 $\mathrm{Q}$ 以速率常数为 $k_q$ 的双分子步骤使激发态失活，给衰减速率添上 $k_q[\mathrm{Q}]$。于是荧光强度 $I_\mathrm{f}$ 与观测寿命 $\tau$ 都服从**斯特恩-福尔默方程**，
$$
\frac{I_{\mathrm{f}0}}{I_\mathrm{f}} = 1 + K_\mathrm{SV}[\mathrm{Q}],
\qquad K_\mathrm{SV} = k_q\,\tau_0 ,
$$
并且，*仅对***动态（碰撞）猝灭**，寿命之比给出同一条直线，
$$
\frac{\tau_0}{\tau} = 1 + k_q\tau_0[\mathrm{Q}] .
$$
$K_\mathrm{SV}$ 的单位是 $\mathrm{dm^{3}\,mol^{-1}}$；$I_{\mathrm{f}0}/I_\mathrm{f}$ 对 $[\mathrm{Q}]$ 的斯特恩-福尔默图是过 $1$、斜率为 $k_q\tau_0$ 的直线。若强度下降而寿命不降，则猝灭是**静态**的——$\mathrm{Q}$ 在基态与荧光团结合，除去了发光分子而不减慢幸存者的寿命——两个测量的对比即可分辨机理。
:::

::: proof 斯特恩-福尔默方程 {#proof-sv}
由[[#proof-phi]]，任意猝灭剂浓度下的荧光强度正比于量子产率，$I_\mathrm{f} \propto \Phi_\mathrm{f} = k_\mathrm{f}\tau$，其中
$$
\frac{1}{\tau} = \frac{1}{\tau_0} + k_q[\mathrm{Q}].
$$
取未猝灭与猝灭强度之比：
$$
\frac{I_{\mathrm{f}0}}{I_\mathrm{f}} = \frac{\Phi_{\mathrm{f}0}}{\Phi_\mathrm{f}}
= \frac{k_\mathrm{f}\tau_0}{k_\mathrm{f}\tau} = \frac{\tau_0}{\tau}
= \tau_0\left(\frac{1}{\tau_0} + k_q[\mathrm{Q}]\right)
= 1 + k_q\tau_0[\mathrm{Q}],
$$
第二行用了 $\Phi_\mathrm{f} = k_\mathrm{f}\tau$，第三行代入了衰减速率。两个可测之比是同一条直线，斜率 $K_\mathrm{SV} = k_q\tau_0$。这个乘积的分解就是物理：$\tau_0$ 说激发态活着等待被猝灭的时间有多长，$k_q$ 说一次碰撞猝灭它的效率有多高，二者之积就是荧光对 $[\mathrm{Q}]$ 的灵敏度。对静态猝灭，同样的代数对 $\tau$ 失效：被络合的分子既不发射也不衰变，所以幸存者保持 $\tau = \tau_0$，而强度按结合因子下降——这恰恰是分辨两者的方法。
:::

::: example 斯特恩-福尔默拟合：k_q 与 τ₀ {#ex-sv-fit}
某奎宁衍生物的荧光被碘离子猝灭，数据如下：

| $[\mathrm{I^-}]/\mathrm{mol\,dm^{-3}}$ | 0 | 0.010 | 0.020 | 0.030 | 0.040 |
|---|---|---|---|---|---|
| $I_{\mathrm{f}0}/I_\mathrm{f}$ | 1.00 | 1.50 | 2.00 | 2.50 | 3.00 |

独立的寿命测量给出 $\tau_0 = 5.0\ \mathrm{ns}$。求 $K_\mathrm{SV}$ 与 $k_q$，并加解释。
::: solution
比值每 $0.010\ \mathrm{mol\,dm^{-3}}$ 上升 $0.50$：图是过 $1.00$、斜率为
$$
K_\mathrm{SV} = \frac{3.00 - 1.00}{0.040} = 50\ \mathrm{dm^{3}\,mol^{-1}}
$$
的直线。于是
$$
k_q = \frac{K_\mathrm{SV}}{\tau_0} = \frac{50}{5.0\times10^{-9}} = 1.0\times10^{10}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}} .
$$
这就是扩散控制的上限：$\mathrm{298\ K}$ 下水中的斯莫卢霍夫斯基极限 $k_\text{diff} = 8RT/(3\eta) \approx 7\times10^{9}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$（见 [[kinetics/reaction-dynamics]]），所以 $\mathrm{I^-}$ 与激发分子之间*几乎每次*碰撞都发生猝灭。斯特恩-福尔默图本身无法说明强度下降来自碰撞还是络合；实测 $\tau$ 随 $[\mathrm{I^-}]$ 按同一因子缩短这一事实，证明了动态猝灭。
:::
:::

::: quiz
某染料的荧光强度在加入 $0.020\ \mathrm{mol\,dm^{-3}}$ 猝灭剂后降为一半，但时间分辨测量显示荧光寿命保持 $4.0\ \mathrm{ns}$ 不变。发生了什么？
- [x] 静态猝灭：猝灭剂在基态与染料结合，除去了一半发光分子，而未络合的分子照常活 $4.0\ \mathrm{ns}$。
- [ ] 动态猝灭，$k_q = 2.5\times10^{10}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$。
- [ ] 仪器坏了：强度和寿命总是一起下降。
- [ ] 猝灭剂加快了荧光，抵消了自己的效果。
::: solution
动态猝灭必须按与强度相同的因子缩短寿命（$\tau_0/\tau = I_{\mathrm{f}0}/I_\mathrm{f}$，见[[#proof-sv]]）；寿命不变而强度减半是基态络合的特征签名。另请注意 $k_q = 2.5\times10^{10}$ 将超过扩散极限，这本身就是"动态解读有误"的警报。
:::
:::

猝灭不仅是待校正的麻烦；它是一种*测量*。氧分子是三线态，它以接近扩散极限的 $k_q$ 通过能量传递猝灭许多荧光态和磷光态，于是斯特恩-福尔默直线把寿命或强度换算成氧浓度——这就是细胞培养与包装中光学氧传感器的原理，用气体混合物校准一次即可。显微术中的荧光寿命成像反其道而行：它绘制的是 $\tau$ 而非强度，因为 $\tau$ 不受染料多少、灯漂移和你恰好收集到多少光的影响，而强度对这三者都身不由己。两个应用都只是测量语境：它们赖以成立的化学是[[#prop-phi-tau]]的分支代数。

## 光化学速率方程与链量子产率

::: proposition 光化学速率方程 {#prop-photo-rate}
若每个吸收的光子以量子产率 $\Phi$ 生成产物，则产物生成速率为
$$
\frac{\mathrm{d}[\mathrm{P}]}{\mathrm{d}t} = \frac{\Phi\,I_\text{abs}}{V} = \frac{\Phi\,I_0}{V}\left(1 - 10^{-\varepsilon c \ell}\right),
$$
其中 $I_\text{abs}$ 以艾因斯坦 $\mathrm{s^{-1}}$ 计，$V$ 为受照体积。两个极限要紧。**低吸光度**下，$\mathrm{d}[\mathrm{P}]/\mathrm{d}t \propto \Phi I_0 \varepsilon c\ell$：对吸收剂一级，对强度一级。**高吸光度**（$A > 2$）下，光在光程的最前一小段内几乎耗尽，速率对浓度为零级、正比于 $I_0$，且局限在薄层内——这就是为什么量子产率要在稀的、充分搅拌的样品上测量。由于速率由 $I_\text{abs}$ 而非热学的 $e^{-E_\mathrm{a}/RT}$ 决定，初级光化学步骤几乎没有温度依赖：光化学速率的阿伦尼乌斯图是平的，直到次级热步骤接管。
:::

检验这一结构的经典探针是氢气的光化学链反应。在 $\mathrm{H_2 + Br_2}$ 光解中，一个吸收的光子大约给出十个 $\mathrm{HBr}$ 分子——一条不大的链。在 $\mathrm{H_2 + Cl_2}$ 中产率达到 $10^{4}$–$10^{6}$：光子裂解 $\mathrm{Cl_2}$，每个 $\mathrm{Cl\cdot}$ 循环 $\mathrm{Cl\cdot + H_2 \rightarrow HCl + H\cdot}$、$\mathrm{H\cdot + Cl_2 \rightarrow HCl + Cl\cdot}$ 数千次。当链很长且以自由基-自由基步骤终止时，[[kinetics/chain-reactions]] 的稳态分析给出速率正比于 $I_\text{abs}^{1/2}$ 而非 $I_\text{abs}$，于是*量子产率*随光强下降，
$$
\Phi \propto I_\text{abs}^{-1/2},
$$
因为光强加倍使链的数目加倍，却使每条链缩短 $\sqrt{2}$：更多的引发，更短的周转。观察到 $\Phi \propto I^{-1/2}$，作为长链双分子终止的证据，与速率方程本身同样有力；观察到 $\Phi \propto I^{+1}$ 则是双光子吸收的证据。整套机制——以 $I_\text{abs}$ 引发、传递、终止、稳态——正是[[kinetics/reaction-mechanisms]]，只是把热引发速率换成 $I_\text{abs}$。

**光敏化**把光化学扩展到不吸收光的分子。敏化剂 $\mathrm{S}$ 吸收光，经 ISC 进入三线态，再把它的三线态能量交给无法直接到达自身三线态的底物 $\mathrm{A}$：$\mathrm{S \rightarrow {}^1S \rightarrow {}^3S}$，随后 $\mathrm{{}^3S + A \rightarrow S + {}^3A}$。化学此后就属于 $\mathrm{{}^3A}$——对烯烃而言，三线态加成抹掉了 $\pi$ 键对几何的记忆，*顺*、*反*混合物被打乱到一个光稳态组成（$\mathrm{365\ nm}$ 光下的二苯甲酮是教科书式的敏化剂）。同样的三线态能量传递解释了溶解氧最著名的反应：基态 $\mathrm{O_2}$ 是三线态，接受能量变成单线态氧，$\mathrm{{}^3S + {}^3O_2 \rightarrow S + {}^1O_2}$，一种对二烯和硫化物加成的亲电氧化剂；此处描述到动力学所需为止，其机理属于光化学有机化学。敏化也解释了为什么底物完全不吸收的光也能驱动反应——其动力学签名是速率跟随*敏化剂*的吸收，而非底物的。

## 安全：紫外辐射与光稳态混合物

::: warning 紫外光是试剂——请当试剂对待 {#warn-uv}
紫外辐射按波长分类，因为其危害各不相同：**UVA**（$\mathrm{315}$–$\mathrm{400\ nm}$）到达晶状体和视网膜，造成慢性损伤与皮肤老化；**UVB**（$\mathrm{280}$–$\mathrm{315\ nm}$）是红斑（晒伤）与皮肤致癌波段，也是常见的光解波段（$\mathrm{313\ nm}$ 汞线）；**UVC**（$\mathrm{100}$–$\mathrm{280\ nm}$，包括 $\mathrm{254\ nm}$ 杀菌线）被角膜阻挡——在其上引起疼痛的光性角膜炎——也被普通玻璃阻挡，但杀菌灯仍绝不可直视，且其产生的臭氧需要通风。紫外灯需要透过可见光而阻挡紫外线的屏蔽（多数灯罩即为此设计）、联锁装置，以及"不戴对应波段防护眼罩绝不开灯"的习惯；注意损伤是*光化学*的，它随不可见波长下的暴露时间累积，当时不给任何疼痛警告。样品与灯同样要防：光稳态混合物不是安全混合物——持续光照会积累远离热力学极小值的光产物（张力异构体、氧生成的过氧化物、裂解碎片），有时还在密封管中；要预期光化学已经造出了*某种东西*，浓缩之前先分析，绝不要把含氧的密封烧瓶留在阳光下。
:::

## 后续内容

本课当作公设处理的激发态的飞秒诞生——先竖直、再弛豫——正是分子束与激光实验如今直接观看的过程：能量按量子态的分配见 [[kinetics/reaction-dynamics]]，该章也给出斯特恩-福尔默例子中用到的斯莫卢霍夫斯基扩散极限。链量子产率 $\Phi \propto I^{-1/2}$ 是 [[kinetics/chain-reactions]] 的一章，那里完整算出自由基链的稳态处理，而光化学引发不过是 $R_\mathrm{i} = I_\text{abs}$。而雅布隆斯基图的激发态势能面，是[[kinetics/transition-state-theory]]中单一基态鞍点的多面推广：热反应穿过一个过渡态，激发分子则搜寻两张面相触的*锥形交叉*，并沿那里落回 $\mathrm{S_0}$——视觉、光稳定性以及大多数低于 1 的光化学量子产率背后的漏斗。

::: summary
- 光在飞秒时间尺度激发（弗兰克-康登）：分子被举上激发态势能面，而不是攀爬基态能垒，所以 $\Delta G > 0$ 的反应在 $\Delta G - h\nu < 0$ 时进行——一个分子加一个光子。
- 只有吸收的光算数：$I_\text{abs} = I_0(1 - 10^{-A})$，在 $A \approx 0.05$ 以下 $I_\text{abs} \approx 2.303 I_0 A$；强度按艾因斯坦（$\mathrm{mol}$ 光子）记账。
- 斯塔克-爱因斯坦：一个光子一个初级事件，故初级速率为 $I_\text{abs}$、$\Phi_\text{prim} \le 1$；表观 $\Phi \ne 1$ 来自失活（$\Phi < 1$）、链（$\Phi \gg 1$）或双光子步骤（$\Phi \propto I$）。
- 雅布隆斯基图是动力学方案：每条途径是一个一级常数，$\Phi_i = k_i\tau$ 且 $1/\tau = \sum k$；荧光自旋允许而快（$10^{-9}$–$10^{-7}\ \mathrm{s}$），磷光自旋禁阻而慢（$10^{-3}$–$10\ \mathrm{s}$）。
- 斯特恩-福尔默：动态猝灭下 $I_{\mathrm{f}0}/I_\mathrm{f} = \tau_0/\tau = 1 + k_q\tau_0[\mathrm{Q}]$；强度降而寿命不降意味着静态猝灭。
- $k_q$ 在水中受扩散封顶于 $\sim 10^{10}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$，所以接近上限的 $K_\mathrm{SV}/\tau_0$ 意味着每次碰撞都猝灭。
- $\mathrm{d}[\mathrm{P}]/\mathrm{d}t = \Phi I_\text{abs}/V$：低吸光度下对光强一级，高吸光度下对吸收剂零级；链产率 $\Phi \propto I^{-1/2}$ 暴露长链。
- 紫外危害按波段区分（UVA/UVB/UVC），损伤是光化学的、当时无痛；光稳态混合物会积累反应性光产物。
:::

::: exercise 254 nm 的光子能量 {level=1 check="471"}
求 $\mathrm{254\ nm}$ 光一个艾因斯坦的能量。（以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
$E_\mathrm{m} = N_\mathrm{A}hc/\lambda = 6.022\times10^{23} \times 6.626\times10^{-34} \times 2.998\times10^{8} / 254\times10^{-9} = 4.71\times10^{5}\ \mathrm{J\,mol^{-1}} = 471\ \mathrm{kJ\,mol^{-1}}$——足以断裂大多数单键，这就是为什么 $\mathrm{254\ nm}$ 被称为"破坏性"波长，也是为什么杀菌灯还会在空气中制造臭氧。
:::
:::

某样品在 $\mathrm{313\ nm}$ 处吸收 $4.00\times10^{-8}\ \mathrm{einstein\,s^{-1}}$。照射 $\mathrm{10.0\ min}$ 后生成 $6.0\times10^{-6}\ \mathrm{mol}$ 产物。求量子产率。
::: solution
吸收的艾因斯坦数：$4.00\times10^{-8} \times 600 = 2.40\times10^{-5}$。$\Phi = 6.0\times10^{-6} / 2.40\times10^{-5} = 0.25$。两位有效数字，由 $6.0\times10^{-6}$ 决定；答案说每四个吸收的光子生成一个产物分子，其余四分之三的激发经由失活或逆反应损失。
:::

::: exercise 使荧光减半的猝灭剂浓度 {level=2 check="0.021"}
某荧光团 $\tau_0 = 4.0\ \mathrm{ns}$，被 $k_q = 1.2\times10^{10}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$ 动态猝灭。使荧光强度减半需要多大猝灭剂浓度？（以 $\mathrm{mol\,dm^{-3}}$ 输入 $[\mathrm{Q}]$，保留两位有效数字。）
::: solution
强度减半即 $I_{\mathrm{f}0}/I_\mathrm{f} = 2 = 1 + k_q\tau_0[\mathrm{Q}]$，故 $[\mathrm{Q}] = 1/(k_q\tau_0) = 1/(1.2\times10^{10} \times 4.0\times10^{-9}) = 1/48 = 0.021\ \mathrm{mol\,dm^{-3}}$。注意捷径：半猝灭浓度永远是 $1/K_\mathrm{SV}$，而这里 $k_q\tau_0 = 48\ \mathrm{dm^{3}\,mol^{-1}}$ 正处扩散极限，所以每次碰撞都算数。
:::

::: exercise 有猝灭剂时的寿命 {level=2 check="2.4"}
已知 $\tau_0 = 6.0\ \mathrm{ns}$、$K_\mathrm{SV} = 25.0\ \mathrm{dm^{3}\,mol^{-1}}$，求 $[\mathrm{Q}] = 0.060\ \mathrm{mol\,dm^{-3}}$ 时的观测荧光寿命。（以 ns 输入 $\tau$。）
::: solution
$\tau = \tau_0/(1 + K_\mathrm{SV}[\mathrm{Q}]) = 6.0/(1 + 25.0\times0.060) = 6.0/2.5 = 2.4\ \mathrm{ns}$。若猝灭是动态的，同一因子 $2.5$ 必须出现在强度之比中——这一一致性检验就是碰撞猝灭的实验定义。
:::

::: exercise 从雅布隆斯基方案到斯特恩-福尔默 {level=3}
从[[#def-jablonski]]的动力学方案出发——$\mathrm{S_1}$ 经 $k_\mathrm{f}$、$k_\mathrm{IC}$、$k_\mathrm{ISC}$ 和 $k_q[\mathrm{Q}]$ 衰变——导出 (a) $\Phi_\mathrm{f} = k_\mathrm{f}\tau$，其中 $1/\tau = \sum k + k_q[\mathrm{Q}]$；(b) 强度的斯特恩-福尔默方程。然后说明：$I_{\mathrm{f}0}/I_\mathrm{f}$ 对 $[\mathrm{Q}]$ 的图*只有*在已知 $\tau_0$ 时才给出 $k_q$，并解释为什么上弯的斯特恩-福尔默图意味着静态与动态猝灭同时存在。
::: solution
(a) 脉冲后 $[\mathrm{S_1}] = [\mathrm{S_1}]_0 e^{-t/\tau}$，其中 $1/\tau = k_\mathrm{f} + k_\mathrm{IC} + k_\mathrm{ISC} + k_q[\mathrm{Q}]$（所有一级出口之和）。每个激发分子的发射总量：$\Phi_\mathrm{f} = \int_0^\infty k_\mathrm{f}e^{-t/\tau}\mathrm{d}t / 1 = k_\mathrm{f}\tau$。(b) $[\mathrm{Q}] = 0$ 时 $\Phi_{\mathrm{f}0} = k_\mathrm{f}\tau_0$，故 $I_{\mathrm{f}0}/I_\mathrm{f} = \tau_0/\tau = \tau_0(1/\tau_0 + k_q[\mathrm{Q}]) = 1 + k_q\tau_0[\mathrm{Q}]$。斜率是*乘积* $k_q\tau_0$：斜率相同而 $\tau_0$ 不同的两个荧光团，其 $k_q$ 不同，所以寿命不是可选项。最后一问，静态猝灭在动态因子*之外*再乘上一个结合因子 $1 + K_\mathrm{S}[\mathrm{Q}]$：$I_{\mathrm{f}0}/I_\mathrm{f} = (1 + K_\mathrm{S}[\mathrm{Q}])(1 + k_q\tau_0[\mathrm{Q}])$，两条直线之积，因而向上弯曲；破绽在于 $\tau_0/\tau$ 此时保持*低于*强度直线，因为只有动态部分缩短寿命。
:::

::: exercise 从灯到浓度：完整的光化学速率计算 {level=3 check="0.032"}
一盏光解灯在 $\mathrm{365\ nm}$ 输出 $\mathrm{8.0\ W}$，全部进入 $\mathrm{25.0\ cm^{3}}$ 的搅拌比色皿，溶液在 $\mathrm{365\ nm}$ 的吸光度 $A = 1.00$。反应 $\mathrm{A \rightarrow P}$ 在该波长的量子产率 $\Phi = 0.12$。照射 $\mathrm{5.00\ min}$ 后产物 $\mathrm{P}$ 的浓度是多少？（以 $\mathrm{mol\,dm^{-3}}$ 输入，保留两位有效数字；假设 $A$ 保持在 $1$ 附近，体积即受照体积。）
::: solution
光子能量：$E = hc/\lambda = 1.986\times10^{-25}/365\times10^{-9} = 5.44\times10^{-19}\ \mathrm{J}$。光子通量：$8.0/5.44\times10^{-19} = 1.47\times10^{19}\ \mathrm{s^{-1}} = 2.44\times10^{-5}\ \mathrm{einstein\,s^{-1}}$。吸收分数：$1 - 10^{-1.00} = 0.900$，故 $I_\text{abs} = 2.20\times10^{-5}\ \mathrm{einstein\,s^{-1}}$。速率：$\mathrm{d}n_\mathrm{P}/\mathrm{d}t = \Phi I_\text{abs} = 0.12 \times 2.20\times10^{-5} = 2.64\times10^{-6}\ \mathrm{mol\,s^{-1}}$。$300\ \mathrm{s}$ 内：$n_\mathrm{P} = 7.9\times10^{-4}\ \mathrm{mol}$，
$$
[\mathrm{P}] = \frac{7.9\times10^{-4}}{0.0250\ \mathrm{dm^{3}}} = 0.032\ \mathrm{mol\,dm^{-3}} .
$$
隐藏的假设是吸光度恒定：$A = 1$ 意味着速率对 $\mathrm{A}$ 几乎零级（光全部吸收），所以恒速率估计相当可靠——但当 $\mathrm{A}$ 漂白到 $A \approx 0.5$ 以下时速率开始下降，真实答案会低于 $0.032$。
:::
