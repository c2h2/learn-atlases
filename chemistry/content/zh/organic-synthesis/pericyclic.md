把环戊-1,3-二烯与马来酸酐在室温下混合，几分钟之内就有白色固体结晶析出：一个双环酸酐，同时生成了两根新的碳碳键和一个六元环，不需要催化剂，没有离子，没有自由基，而且在若干可能的立体异构体中只得到某一个。加热 (2*E*,4*Z*,6*E*)-辛-2,4,6-三烯，它闭环为 *cis*-5,6-二甲基环己-1,3-二烯，绝不会得到 *trans* 异构体；而用紫外光照射它，生成的却是 *trans* 异构体。这些就是**周环反应**：键经由一个由相互作用的轨道构成的环状阵列，在同一步协同的过程中生成和断裂的反应。它们一度被称为"没有机理的反应"，因为它们不表现出有机化学家用来描述机理的任何中间体；在 1965 年罗伯特·伯恩斯·伍德沃德（Woodward）与罗尔德·霍夫曼（Hoffmann）用轨道对称性守恒把它们解释清楚之前，它们的立体化学看上去反复无常。

对合成化学家来说，周环反应格外宝贵。它们一步生成多个键和至多四个立体中心，立体专一性由轨道对称性决定，原子经济性完美。狄尔斯-阿尔德反应是合成中最强力的成环反应；克莱森重排与科普重排以可预见的几何，把立体化学从一根键传递到另一根键。本章定义周环反应的类别，建立用来预测反应是否允许、其立体化学将会如何的前线轨道分析与伍德沃德-霍夫曼分析，并逐一讨论环加成、电环化反应与 σ-迁移重排及其在合成中的用途。π 轨道的背景在[[organic-2/conjugation]]，更形式化的表述在[[quantum-chemistry/huckel-theory]]。

## 周环反应的类别 {#sec-classes}

::: definition 周环反应及其类别 {#def-pericyclic}
**周环反应**是一类协同反应，其中所有的成键与断键都经由一个由连续重叠的轨道构成的环状过渡态，在同一步中发生。主要类别有：

- **环加成** — 两个 π 体系结合成一个环并生成两根新的 σ 键；写成 $[m + n]$，其中 $m$、$n$ 为每个组分的电子（或原子）数目：狄尔斯-阿尔德反应是一个 $[4 + 2]$ 环加成。其逆过程是一个**逆环反应**。
- **电环化反应** — 一个共轭多烯闭环，在其两端之间生成一根新的 σ 键，或相反（开环）。
- **σ-迁移重排** — 一根 σ 键跨过一个 π 体系迁移到新位置；写成 $[i, j]$，即旧 σ 键与新 σ 键之间每个片段的原子数：科普重排与克莱森重排是 $[3,3]$ 迁移，氢绕环戊二烯的迁移是 $[1,5]$ 迁移。
- **基团转移**（ene 反应）与**螯环反应**（在单个原子上生成或断裂两根 σ 键，如卡宾或 $\mathrm{SO_2}$ 的加成）。

一个组分若新键在同一面生成（或旧键在同一面断裂），它**同面**（suprafacial，s）反应；若在相反的面上，则**异面**（antarafacial，a）。
:::

用弯箭头的语言说，周环反应的箭头绕着一个环画成一圈：以丁-1,3-二烯与乙烯的狄尔斯-阿尔德反应为例，乙烯 C=C 的 π 电子移动去与二烯的 C1 形成一根 σ 键；C1=C2 的 π 电子移动形成新的 C2=C3 π 键；而 C3=C4 的 π 电子移动，从 C4 形成一根 σ 键回到乙烯的另一个碳。六个电子流转一周，而这三处移动同时发生。箭头的方向（顺时针或逆时针）是任意的；这种含糊本身就是一个信号：没有任何一对电子是"亲核试剂"——反应由轨道重叠控制，而不是由电荷控制。

## 多烯的前线轨道 {#sec-fmo}

$n$ 个碳的线形共轭多烯的 π 轨道由休克尔理论给出，它们有一个简单而普遍的表达式。

::: proposition 线形多烯的休克尔轨道 {#prop-huckel}
在休克尔近似下（库仑积分 $\alpha$，相邻原子间共振积分 $\beta < 0$，忽略重叠），由 $n$ 个 $sp^2$ 碳原子组成的线形共轭链，其 π 分子轨道 $\psi_k = \sum_j c_{jk}\phi_j$，$k = 1, \ldots, n$，具有如下能量与系数
$$
E_k = \alpha + 2\beta\cos\frac{k\pi}{n+1}, \qquad c_{jk} = \sqrt{\frac{2}{n+1}}\,\sin\frac{jk\pi}{n+1}.
$$ {#eq-huckel}
轨道 $\psi_k$ 在原子之间有 $k - 1$ 个节面。其端位系数 $c_{1k}$ 与 $c_{nk}$ 当 $k$ 为奇数时同号，当 $k$ 为偶数时异号。
:::

::: proof
久期方程为 $(\alpha - E)c_j + \beta(c_{j-1} + c_{j+1}) = 0$，$j = 1, \ldots, n$，边界条件 $c_0 = c_{n+1} = 0$（链端）。试取 $c_j = \sin(j\theta)$：利用 $\sin((j-1)\theta) + \sin((j+1)\theta) = 2\sin(j\theta)\cos\theta$，方程成为 $(\alpha - E + 2\beta\cos\theta)\sin(j\theta) = 0$，于是 $E = \alpha + 2\beta\cos\theta$。边界条件 $c_{n+1} = \sin((n+1)\theta) = 0$ 要求 $\theta = k\pi/(n+1)$，$k = 1, \ldots, n$，即得[[#eq-huckel]]；因子 $\sqrt{2/(n+1)}$ 使轨道归一化，因为 $\sum_{j=1}^n \sin^2(jk\pi/(n+1)) = (n+1)/2$。函数 $\sin(jk\pi/(n+1))$ 在 $j = 1$ 与 $j = n$ 之间变号 $k - 1$ 次，即节面数。最后 $c_{nk} = \sin(nk\pi/(n+1)) = \sin(k\pi - k\pi/(n+1)) = (-1)^{k+1}\sin(k\pi/(n+1)) = (-1)^{k+1}c_{1k}$：端位对奇数 $k$ 同号，对偶数 $k$ 异号。$\blacksquare$
:::

最后这一句话是周环选择性的关键。对**乙烯**（$n = 2$）：HOMO 为 $\psi_1$（端位同相），LUMO 为 $\psi_2$（反相）。对**丁二烯**（$n = 4$，能量 $\alpha \pm 1.618\beta$、$\alpha \pm 0.618\beta$）：HOMO 为 $\psi_2$（端位反相），LUMO 为 $\psi_3$（同相）。对**己三烯**（$n = 6$，$\alpha \pm 1.802\beta$、$\pm 1.247\beta$、$\pm 0.445\beta$）：HOMO 为 $\psi_3$（同相），LUMO 为 $\psi_4$（反相）。这一图样随电子对数交替变化。

**前线分子轨道（FMO）理论**（福井谦一（Fukui），始于 1952 年）指出：两个分子反应时的主导相互作用，发生在一个分子的 HOMO 与另一个分子的 LUMO 之间；二者的能量差越小、新键生成处轨道瓣的重叠越大，这一相互作用就越强。协同环加成要求**两根新键同时都有成键重叠**。对 $[4s + 2s]$ 狄尔斯-阿尔德反应，丁二烯的 HOMO（$\psi_2$，端位反相）遇上乙烯的 LUMO（$\psi_2^*$，端位反相）：两端的符号都匹配，于是两根键可以在两个组分的同一面上同时生成。另一种配对——乙烯的 HOMO（同相）与丁二烯的 LUMO（同相）——同样匹配。两个乙烯的热 $[2s + 2s]$ 环加成，把同相的 HOMO 与反相的 LUMO 配在一起：一端成键，另一端反键。它在热反应中**对称性禁阻**，事实也正是烯烃加热并不二聚。在紫外光下一个乙烯被激发，一个电子被提升到 $\psi_2^*$，后者成为它新的 HOMO；这如今与另一个乙烯的 LUMO 相匹配，于是**光化学 [2+2] 环加成是允许的**。

::: example 环加成的对称性分析 {#ex-fmo}
用[[#prop-huckel]]的端位相位规则判断下列每个全同面的热环加成是否允许：(a) $[4s + 2s]$（丁二烯 + 乙烯）；(b) $[2s + 2s]$；(c) $[4s + 4s]$（两个丁二烯）；(d) $[6s + 4s]$（己三烯 + 丁二烯）。
::: solution
同面-同面环加成，当一个组分的 HOMO 与另一个组分的 LUMO 具有**相同**的端位相位关系（同为同相或同为反相）时才是允许的，这样两端才能都以成键方式重叠。由[[#prop-huckel]]，含 $N$ 个 π 电子的多烯（$k = N/2$）的 HOMO 在 $N/2$ 为奇数时端位同相、为偶数时反相；LUMO（$k = N/2 + 1$）则相反。

(a) 丁二烯 HOMO（$k = 2$，反相），乙烯 LUMO（$k = 2$，反相）：匹配。**允许**（6 电子）。

(b) 乙烯 HOMO（$k = 1$，同相），乙烯 LUMO（$k = 2$，反相）：不匹配。**禁阻**（4 电子）。

(c) 丁二烯 HOMO（$k = 2$，反相），丁二烯 LUMO（$k = 3$，同相）：不匹配。**禁阻**（8 电子）。

(d) 己三烯 HOMO（$k = 3$，同相），丁二烯 LUMO（$k = 3$，同相）：匹配。**允许**（10 电子）。

这一图样——同面环加成对 $4q + 2$ 个电子（6，10，…）允许，对 $4q$（4，8，…）禁阻——是一般规则[[#prop-wh]]的环加成情形。
:::
:::

## 狄尔斯-阿尔德反应 {#sec-diels-alder}

狄尔斯-阿尔德反应把一个共轭**双烯体**（四个 π 电子）与一个**亲双烯体**（一个烯或炔，两个 π 电子）连接成一个环己烯。它在合成中的威力在于其可预测性。

- **双烯必须取 s-*cis* 构象。** 两根双键必须位于中间单键的同一侧，C1 与 C4 才能都够到亲双烯体。被锁定为 s-*cis* 的环状双烯，如环戊二烯，尤其活泼（环戊二烯在室温下就以自身为双烯体和亲双烯体经狄尔斯-阿尔德反应二聚，使用前需加热"裂解"回单体）。带大体积 (*Z*)-1-取代基的双烯难以采取 s-*cis* 构象，反应迟缓。
- **电子需求。** "正常"电子需求的狄尔斯-阿尔德反应，是富电子双烯（给电子取代基 OMe、烷基、$\mathrm{OSiMe_3}$ 提高其 HOMO）与缺电子亲双烯体（吸电子取代基 CHO、COR、$\mathrm{CO_2R}$、CN 降低其 LUMO）之间的反应。缩小 HOMO–LUMO 能隙会加快反应：丁二烯与乙烯要在高温高压下才反应，而环戊二烯与马来酸酐在室温即可反应。路易斯酸通过与亲双烯体的羰基氧配位、进一步降低其 LUMO 而加速反应。
- **立体专一性。** 两个组分都同面反应，因此亲双烯体取代基的相对构型在产物中保持（*cis* 仍为 *cis*，*trans* 仍为 *trans*），而双烯 C1 与 C4 上的"外侧"取代基最终彼此 *cis*。
- **内型规则（经验规则，阿尔德（Alder）1937）。** 当亲双烯体带有不饱和取代基（C=O、CN）时，动力学产物通常使该取代基处于**内型**（endo）——朝向双烯正在生成的 π 键、在过渡态里位于双烯下方——即使外型产物常常更稳定。这一偏好归因于取代基的 π 轨道与双烯的 C2、C3 之间有利的**二级轨道相互作用**，再叠加上静电与溶剂效应；它是一种动力学偏好，通常值每摩尔几千焦。
- **区域选择性（"*邻位*–*对位*"规则，经验规则）。** 1-取代双烯与单取代亲双烯体主要给出"*邻位*"（1,2-二取代）环己烯；2-取代双烯主要给出"*对位*"（1,4）产物。前线轨道理论对此有解释：HOMO 与 LUMO 系数最大的原子优先成键，双烯 C1 上的给体使 C4 的 HOMO 系数变大，而亲双烯体上的吸电子基使其 β-碳的 LUMO 系数变大。

::: example 环戊二烯与马来酸酐 {#ex-endo}
描述环戊-1,3-二烯与马来酸酐（呋喃-2,5-二酮）的狄尔斯-阿尔德反应：电子的移动、产物的立体化学，以及为什么生成内型加成物。
::: solution
**电子移动。** 在同一步协同过程中：马来酸酐 C=C 的 π 电子与环戊二烯的 C1 形成一根 σ 键；双烯的 C1=C2 π 电子移去形成 C2=C3 π 键；而 C3=C4 的 π 电子从 C4 向酸酐的另一个烯碳形成一根 σ 键。环戊二烯的 $\mathrm{CH_2}$（C5）成为一碳桥。

**产物。** *cis*-5-降冰片烯-2,3-二甲酸酐（3a,4,7,7a-四氢-4,7-亚甲基-2-苯并呋喃-1,3-二酮）。两个羰基在亲双烯体上原本 *cis*，在产物中仍是 *cis*（同面加成）。它们可以朝向产物的两碳 C=C 桥（内型——在过渡态里位于双烯下方），也可以朝向一碳的 $\mathrm{CH_2}$ 桥（外型）。室温下反应基本上只给出**内型**加成物。

**为什么是内型。** 在内型过渡态中，酸酐的 C=O π 轨道正好位于双烯的 C2 与 C3 下方，而那里双烯的 HOMO 有可观的系数；这些二级相互作用（那里并不生成新键）降低了内型过渡态。外型加成物热力学上略更稳定，而长时间加热——当反应变得可逆（逆狄尔斯-阿尔德反应）时——外型产物的比例会升高：动力学控制与热力学控制的教科书案例（[[organic-synthesis/carbon-carbon-bonds#prop-control]]）。原子经济性为 $100\,\%$。环戊二烯易燃，马来酸酐有腐蚀性且是呼吸道致敏剂，所以这个实验（一个常见的教学制备实验）须在通风橱内、在指导教师监督下进行。
:::

::: example 区域化学与立体化学一起看 {#ex-regio}
预测 (*E*)-1-甲氧基丁-1,3-二烯与丙烯醛（acrolein）反应的主要产物。

**区域化学。** 双烯 C1 上的甲氧基给体提高其 HOMO，并使 C4 的系数最大。醛受体降低亲双烯体的 LUMO，并使其最大系数位于端位 $\mathrm{CH_2}$（β-碳）。大–大相互作用把双烯 C4 与亲双烯体的 $\mathrm{CH_2}$ 连起来，于是另一根新键把双烯 C1（带 OMe）与带 CHO 的碳连起来：得"*邻位*"产物 **2-甲氧基环己-3-烯-1-甲醛**，OMe 与 CHO 在相邻的碳上。

**立体化学。** (*E*)-甲氧基是双烯的一个"外侧"取代基；醛以内型方式接近时，CHO 基团落在与 C1 外侧取代基同一侧，因此主产物是 ***cis*** 异构体（外消旋，因为两个反应物都没有手性）。路易斯酸催化同时提高区域选择性与内型选择性。不对称版本使用手性路易斯酸或有机催化剂（[[organic-synthesis/stereoselective-synthesis]]）。
:::

各种变体把这一反应大大推广开来：**丹尼谢夫斯基双烯**（1-甲氧基-3-三甲基硅氧基丁-1,3-二烯，1974）水解后给出环己烯酮；**杂狄尔斯-阿尔德反应**以羰基或亚胺为亲双烯体，生成二氢吡喃与四氢吡啶；**分子内**狄尔斯-阿尔德反应一次构筑两个环；而**反电子需求**反应把缺电子双烯（1,2,4,5-四嗪）与富电子或带张力的亲双烯体配对，这一反应如今用于标记生物分子。密切相关的 **1,3-偶极环加成**（胡格（Huisgen），1960 年代）是叠氮化物、氧化腈、硝酮与重氮化合物对烯和炔的加成，生成五元杂环；铜(I)催化的叠氮化物-炔环加成（瓦列里·福金（Fokin）与巴里·夏普利斯（Sharpless）；莫滕·梅达尔（Meldal），2002）是"点击化学"的原型（2022 年诺贝尔化学奖，与卡罗琳·贝尔托西（Bertozzi）分享）。低分子量的有机叠氮化物有爆炸性，只能少量、在溶液中使用，并须做风险评估。

## 伍德沃德-霍夫曼规则 {#sec-wh}

前线轨道论证可以表述为一条覆盖所有周环反应的规则。

::: proposition 广义伍德沃德-霍夫曼规则 {#prop-wh}
把反应体系拆成若干组分（π 键、σ 键、孤对电子），每个组分或同面或异面反应。一个**热**周环反应对称性允许，当 $(4q + 2)_\mathrm{s}$ 与 $(4r)_\mathrm{a}$ 组分的总数为**奇数**；一个**光化学**反应（第一激发态）在这一数为**偶数**时允许。这里 $q, r = 0, 1, 2, \ldots$，下标数目指组分中的电子数。允许意味着反应能够经由一个没有对称性强加势垒的协同过渡态进行；它不意味着反应快。
:::

::: proof 经由芳香性过渡态的论证
一个等价的表述（齐默尔曼（Zimmerman）与迪尤尔（Dewar），1966）把过渡态中轨道的环状阵列当作一个环来处理。若可以选取基轨道，使沿环相邻轨道之间的相位倒转（变号）数目为偶数——一个**休克尔**阵列——则该阵列在含 $4q + 2$ 个电子时被稳定化（"芳香"）；若相位倒转的数目为奇数——一个**默比乌斯**阵列——它在含 $4q$ 个电子时被稳定化，这可由对一个带一个负共振积分的环作休克尔型计算得出。一个异面组分向阵列引入一次相位倒转（它的两端在轨道的相对两面上成键），一个同面组分则不引入。当热反应的过渡态在基态是芳香的，反应就允许。逐例计数：含 $N$ 个电子的全同面阵列（休克尔）当 $N = 4q + 2$ 时芳香，亦即 $(4q+2)_\mathrm{s}$ 组分数为奇数（若干组分之和恰为 $4q + 2$，当且仅当属于 $(4q+2)$ 的组分数为奇数）。每个异面组分都把休克尔 ↔ 默比乌斯互换，从而把 $4q$ 与 $4q + 2$ 的角色对调；把 $(4r)_\mathrm{a}$ 组分与 $(4q+2)_\mathrm{s}$ 组分放在一起计数，奇偶判据保持不变。在第一激发态中，稳定化图样反转（一个电子占据原来的 LUMO），于是奇偶条件翻转。$\blacksquare$
:::

### 电环化反应

在电环化关环中，多烯的两端旋转，使它们的 p 轨道沿轴向相对。它们可以朝同一方向旋转（**同旋**，conrotatory，在 WH 分析中相当于一个组分异面），或朝相反方向旋转（**对旋**，disrotatory，同面）。由规则[[#prop-wh]]得到：

| π 电子数 | 热 | 光化学 |
|---|---|---|
| $4q$（4，8 …） | 同旋 | 对旋 |
| $4q + 2$（2，6 …） | 对旋 | 同旋 |

前线轨道图像很直接：HOMO 的两端必须旋转到同号的瓣相遇。对己三烯（HOMO $\psi_3$，端位同相），对旋使同号瓣相接；对丁二烯（HOMO $\psi_2$，端位反相），同旋使同号瓣相接。光激发使 $\psi_{k+1}$ 成为 HOMO，相位关系与旋转方式都随之反转。

::: example 电环化的立体化学 {#ex-electrocyclic}
预测 (a) 加热 (2*E*,4*Z*,6*E*)-辛-2,4,6-三烯；(b) 光照它；(c) 加热 *cis*-3,4-二甲基环丁-1-烯 的产物。
::: solution
(a) 六个 π 电子，热：**对旋**。两个端位甲基都在"外侧"（*E*）；对旋把两者都转向上（或都转向下），于是它们落在同一面：***cis*-5,6-二甲基环己-1,3-二烯**。

(b) 光化学，六个电子：**同旋**。一端顺时针转，另一端也顺时针转；一个甲基朝上，另一个朝下：***trans*-5,6-二甲基环己-1,3-二烯**。

(c) 环丁烯开环是四电子关环的逆过程：热，**同旋**。在 *cis* 异构体中两个甲基在同一面；同旋把一个向外转、一个向内转，给出 **(2*E*,4*Z*)-己-2,4-二烯**——而绝不会是 (*E*,*E*) 或 (*Z*,*Z*) 异构体，那两者需要对旋。*trans*-3,4-二甲基环丁烯开环得 (*E*,*E*)-二烯，两个甲基都向外转（向内转会造成严重的位阻碰撞，这一精细效应称为扭旋选择性）。
:::
:::

**纳扎罗夫环化**（一个二乙烯基酮在路易斯酸或布朗斯特酸活化下闭环为环戊烯酮）是一个戊二烯基正离子的四电子同旋电环化。自然界中一个漂亮的例子是皮肤中**维生素 D₃** 的生成：紫外光使 7-脱氢胆固醇的 B 环经光化学六电子同旋开环，生成前维生素 D₃，后者再经受一次热 $[1,7]$-氢迁移得到维生素 D₃。

### σ-迁移重排

在 $[i, j]$ σ-迁移重排中，一根两侧有 π 体系的 σ 键移到新的位置。套用[[#prop-wh]]：

- **$[1,5]$-氢迁移**（六个电子）热反应允许以同面方式进行——氢跨过 π 体系的一个面迁移——在环戊二烯中可观察到，其取代基在室温下绕环"行走"。$[1,3]$-与 $[1,7]$-氢迁移则必须异面：对 $[1,3]$ 几何上不可能，对柔性的 $[1,7]$ 则可能（如维生素 D 的生成）。
- **$[3,3]$ 迁移**（六个电子，两个烯丙基片段都同面）热反应允许。**科普重排**把一个己-1,5-二烯变成异构的己-1,5-二烯；**克莱森重排**把一个烯丙基乙烯基醚变成 γ,δ-不饱和羰基化合物（C=O 键的生成使它基本上不可逆），并把一个烯丙基芳基醚变成 2-烯丙基苯酚。

$[3,3]$ 迁移通常经由一个**椅式**过渡态进行，类似环己烷，它允许起始烯烃的几何被可预测地转译成新立体中心的构型。合成价值极大的变体包括 1,5-二烯-3-醇的**含氧科普重排**（oxy-Cope）——当醇用氢化钾与 18-冠-6 去质子化时加速 $10^{10}$–$10^{17}$ 倍（**阴离子含氧科普重排**，大卫·埃文斯（Evans）与安德鲁·戈洛布（Golob），1975）——以及 **Johnson–Claisen**（烯丙醇 + 原乙酸三乙酯）与 **Ireland–Claisen**（烯丙酯的硅基烯酮缩醛）重排。

::: example 芳香族克莱森重排 {#ex-claisen}
描述烯丙基苯基醚在加热下转变为 2-烯丙基苯酚的过程，为每一处电子移动命名，并解释为什么烯丙基是经由它原来的端位碳接上去的。
::: solution
**第 1 步：$[3,3]$ 迁移。** 经由一个含氧、烯丙基的三个碳和两个环碳的六元（椅式或船式）过渡态，在同一步协同过程中：烯丙基 C=C（中心碳与端基 $\mathrm{CH_2}$ 之间）的 π 电子从那个端基碳向*邻位*环碳形成一根新的 σ 键；*邻位*碳与带氧环碳之间的环 π 电子移动形成一根 C=O π 键；而 O–$\mathrm{CH_2}$ σ 键的电子移动，在原来的 O–$\mathrm{CH_2}$ 碳与烯丙基中心碳之间形成一根新的 C=C π 键。产物是 6-烯丙基环己-2,4-二烯-1-酮，一个非芳香的二烯酮。

**第 2 步：互变异构。** *邻位*的 C–H（在如今带烯丙基的 $sp^3$ 碳上）以质子的形式失去，其电子形成环上的 C=C；C=O 的 π 电子移到氧上，氧再被质子化。芳香性得以恢复，得到 2-烯丙基苯酚。

**烯丙基翻转。** 由于新的 C–C 键在远离氧的烯丙基端位（烯丙基的 C3）形成，挂在那个碳上的标记最终会接到环上——这正是确立协同机理的证据之一，与交叉产物的缺失一起（[[organic-synthesis/mechanism-determination]]）。若两个*邻位*都被占据，这个二烯酮就经历第二次（科普）$[3,3]$ 迁移到达*对位*。
:::
:::

::: algorithm 应用伍德沃德-霍夫曼规则 {#alg-wh}
1. **分类**反应（环加成、电环化、σ-迁移、ene），并**计数**每个组分中的电子数。
2. **选定要检验的几何**（每个组分是同面还是异面；电环化反应是同旋还是对旋）。
3. **计数** $(4q + 2)_\mathrm{s}$ 与 $(4r)_\mathrm{a}$ 组分。奇数：热允许；偶数：光化学允许（[[#prop-wh]]）。等价地，检查前线轨道的端位相位（[[#prop-huckel]]）。
4. **检查允许的几何是否可达**：跨短 π 体系的异面接键（$[1,3]$-H 迁移、$[2s + 2a]$ 烯烃二聚）通常张力太大，允许的路径因此不可达。
5. 由允许的几何（内/外型、同旋/对旋、椅/船式）**预测立体化学**，再用位阻论证加以修正。
:::

::: quiz
下列哪些周环反应在所指的几何下是热允许的？
- [x] 己三烯的对旋关环
- [x] 同面的 $[1,5]$-氢迁移
- [ ] 两个烯烃的同面-同面 $[2+2]$ 环加成
- [ ] 环丁烯的对旋开环
::: solution
己三烯（6 电子，对旋时一个 $(4q+2)_\mathrm{s}$ 组分）：奇数，允许。$[1,5]$-H 同面：π 组分加 σ 键共 6 个电子，按 $[\sigma 2_\mathrm{s} + \pi 4_\mathrm{s}]$ 分析：一个 $(4q+2)_\mathrm{s}$ 组分，允许。$[2_\mathrm{s} + 2_\mathrm{s}]$：两个 $(4q+2)_\mathrm{s}$ 组分，偶数——只能光化学。环丁烯开环是四电子电环化反应，热反应同旋，因此对旋禁阻。
:::
:::

::: warning "禁阻"不等于"不可能"，"允许"不等于"快" {#warn-forbidden}
伍德沃德-霍夫曼规则针对的是**协同**路径。"禁阻"的产物仍可能经分步路径生成：烯酮与缺电子烯烃的热 [2+2] 环加成，经扭曲的、在烯酮上异面的几何或经偶离子进行；四氟乙烯经双自由基二聚；而过渡金属能催化形式上禁阻的反应（烯烃复分解经金属杂环丁烷进行，[[organometallics-catalysis/metathesis-polymerisation]]）。反过来，一个"允许"的反应也可能因为张力、位阻或轨道能量匹配差造成的大势垒而缓慢——丁二烯与乙烯需要 $165\ ^\circ\mathrm{C}$ 和高压。这些规则对协同反应立体化学的预测极为出色；它们不预测速率。而内型规则只是一种动力学倾向，不是定律：许多狄尔斯-阿尔德反应，特别是分子内的，是外型选择性的。
:::

::: history
奥托·迪尔斯（Diels）与库尔特·阿尔德（Alder）在 1928 年描述了双烯合成（1950 年诺贝尔化学奖），阿尔德在 1937 年提出了内型规则。路德维希·克莱森（Claisen）在 1912 年报告了烯丙基乙烯基醚与烯丙基芳基醚的重排，亚瑟·科普（Cope）在 1940 年报告了全碳版本。福井谦一（Fukui）在 1952 年引入前线轨道反应性指数。伍德沃德（Woodward）在维生素 B₁₂ 合成中对电环化步骤立体化学的研究，导致他与罗尔德·霍夫曼（Hoffmann）的合作——后者计算了轨道相关；他们的第一篇论文《电环化反应的立体化学》（"Stereochemistry of electrocyclic reactions"）于 1965 年发表于《美国化学会志》（*Journal of the American Chemical Society*），他们的专著《轨道对称性守恒》（*The Conservation of Orbital Symmetry*）则在 1969–70 年问世。齐默尔曼（Zimmerman）与迪尤尔（Dewar）在 1966 年各自独立提出了休克尔-默比乌斯芳香性过渡态的表述。福井与霍夫曼分享了 1981 年的诺贝尔化学奖；伍德沃德已于 1979 年去世。
:::

## 后续内容

不对称狄尔斯-阿尔德反应与手性辅基、手性催化剂控制的克莱森重排，属于[[organic-synthesis/stereoselective-synthesis]]；在许多全合成中，狄尔斯-阿尔德步骤与 $[3,3]$ 迁移是关键的新键形成事件（[[organic-synthesis/total-synthesis]]），伍德沃德自己的合成也包括在内。狄尔斯-阿尔德 retron（一个环己烯）与 1,6-二羰基化合物的重新连接在[[organic-synthesis/retrosynthesis]]中引入。这些规则背后的轨道理论在[[quantum-chemistry/huckel-theory]]中展开，光化学周环反应则在[[kinetics/photochemistry]]中。

::: summary
- 周环反应是协同的，具有环状过渡态；类别：环加成 $[m+n]$、电环化反应、σ-迁移 $[i,j]$、ene 反应与螯环反应。
- 线形多烯的休克尔轨道：$E_k = \alpha + 2\beta\cos(k\pi/(n+1))$，$c_{jk} \propto \sin(jk\pi/(n+1))$；HOMO 端位的同相与反相随电子对数交替。
- 伍德沃德-霍夫曼：当 $(4q+2)_\mathrm{s}$ 加 $(4r)_\mathrm{a}$ 组分数为奇数时热反应允许，为偶数时光化学允许；电环化热反应对 $4q$ 电子同旋，对 $4q+2$ 电子对旋。
- 狄尔斯-阿尔德反应（$[4s+2s]$）需要 s-*cis* 双烯，富电子双烯与缺电子亲双烯体的组合最快，立体专一（同面），通常内型选择性（动力学、经验）与"*邻位*/*对位*"区域选择性。
- $[3,3]$ 迁移（科普、克莱森、含氧科普、Ireland–Claisen）经椅式过渡态进行，可预测地传递立体化学；同面 $[1,5]$-H 迁移热允许。
- "允许"指协同路径而言；它预测立体化学，不预测速率。
:::

用[[#prop-wh]]判断下列各反应热反应是否允许：(a) $[\pi 4_\mathrm{s} + \pi 2_\mathrm{s}]$；(b) $[\pi 2_\mathrm{s} + \pi 2_\mathrm{a}]$；(c) 同面 $[1,3]$-H 迁移的 $[\sigma 2_\mathrm{s} + \pi 2_\mathrm{s}]$；(d) $[\pi 6_\mathrm{s} + \pi 4_\mathrm{s}]$。

::: exercise 丁二烯的休克尔轨道 {level=3}
在休克尔近似下写出丁-1,3-二烯的久期行列式并求解，得到四个能量。求 HOMO 的系数，并证明其端位系数符号相反。利用这一结果解释为什么丁二烯热闭环成环丁烯必须是同旋的。
::: hint
令 $x = (\alpha - E)/\beta$；该行列式是 $x$ 的四次式，可分解为 $x^2$ 的二次式。
:::
::: solution
令 $x = (\alpha - E)/\beta$，对角元为 $x$、相邻元为 $1$ 的三对角矩阵的行列式为 $x^4 - 3x^2 + 1 = 0$，于是 $x^2 = (3 \pm \sqrt5)/2$，$x = \pm 1.618, \pm 0.618$。因 $E = \alpha - x\beta$ 且 $\beta < 0$，由低到高的能量为 $\alpha + 1.618\beta$、$\alpha + 0.618\beta$、$\alpha - 0.618\beta$、$\alpha - 1.618\beta$，与[[#eq-huckel]]一致。对 HOMO（$E = \alpha + 0.618\beta$，$x = -0.618$）：方程 $xc_1 + c_2 = 0$ 与 $c_1 + xc_2 + c_3 = 0$ 给出 $c_2 = 0.618c_1$，$c_3 = -c_1 - xc_2 = -c_1 + 0.382c_1 = -0.618c_1$，由对称性 $c_4 = -c_1$。归一化：$c = (0.602, 0.372, -0.372, -0.602)$。端位系数符号相反。要在 C1 与 C4 之间形成一根 σ 键，必须让同号的瓣重叠；由于 C1 的上瓣为正而 C4 的上瓣为负，两端必须朝同一方向旋转（同旋），使 C1 的上方正瓣去迎接 C4 的下方正瓣。对旋会把异号的瓣带到一起（反键），因此热反应禁阻。
:::

::: exercise 一个阴离子含氧科普重排 {level=3}
3-甲基己-1,5-烯-3-醇用氢化钾与 18-冠-6 在 THF 中处理，反应液用氯化铵水溶液后处理。指明产物，描述每一处电子移动，并解释冠醚的作用。
::: hint
把双烯从 C1 编号到 C6，OH 与甲基在 C3 上。哪根键断裂？哪根键生成？
:::
::: solution
**去质子化。** 氢负离子夺走 O–H 质子（放出 $\mathrm{H_2}$），得到钾的烷氧负离子；18-冠-6 牢牢络住 $\mathrm{K^+}$，留下一个"裸露"的、电子密度极高的烷氧负离子。**$[3,3]$ 迁移。** 在椅式六元过渡态中，三对电子同时移动：C1=C2 的 π 电子形成新的 C1–C6 σ 键；C5=C6 的 π 电子移去形成新的 C4=C5 π 键；而 C3–C4 σ 键断裂，其电子形成 C2=C3 π 键。由于 C3 带着 $\mathrm{O^-}$，C2=C3 键是**烯醇负离子**的一部分。烷氧基氧的给电子作用在过渡态中削弱 C3–C4 键，这就是巨大（$10^{10}$–$10^{17}$）加速的根源；形成紧密离子对的钾（不加冠醚）会削弱这种加速。**后处理。** 烯醇负离子在碳上（C2）质子化得到酮。产物为 $\mathrm{CH_3CO{-}CH_2CH_2CH_2{-}CH{=}CH_2}$：**庚-6-烯-2-酮**。这一反应把容易制得的叔烯丙醇（由烯丙基溴化镁对丁-3-烯-2-酮加成得到）变成带一根新 C–C 键的 δ,ε-不饱和酮；由于烯醇负离子比烷氧负离子稳定得多，反应不可逆。
:::
