假设有任务要你合成 4-苯基丁-3-烯-2-酮——那作为"苄叉丙酮"（benzalacetone）出售的浅黄色固体——或者甾体化学家称为维兰德-米歇尔酮（Wieland–Miescher ketone）的双环二酮。没有人会递给你一张配方。你在[[organic-1]]与[[organic-2]]里学过几十个反应——亲核取代、格氏加成、羟醛缩合与克莱森缩合、迈克尔加成——但按正向认识这些反应，与知道该把哪些串起来、按什么次序、从什么出发，并不是一回事。一个学生若靠盯着起始原料问"我能对它做什么"来规划合成，很快就会淹死在可能性里：每个化合物都能发生几十个反应，每个产物又能再生出几十个，正向可能性的树呈指数生长。

埃利亚斯·詹姆斯·科里（Elias James Corey）在 1960 年代使之系统化的解决办法，是**从目标分子往回推**。我们不再问起始原料能变成什么，而是问：在终点的前一步，目标分子可能是由什么做出来的。每一步反向操作都断掉目标分子中含有的一根键——一次**切断**——把目标分子变成更简单的碎片。对每个碎片重复这一过程，最终抵达买得到的化合物。由于每一步反向操作都必须对应一个可靠的正向反应，这一分析在每个阶段都锚定在真正行得通的化学上。本章建立**逆合成分析**的语言：切断、合成子及其合成等价物、官能团互变、告诉我们哪些切断是"天然的"那些极性模式，以及决定各条在纸上都走得通的路线之间取舍的策略性算术——总产率、汇聚性、原子经济性。课程其余各章提供工具：氧化与还原（[[organic-synthesis/redox-in-synthesis]]）、保护基（[[organic-synthesis/protecting-groups]]）、碳碳键形成（[[organic-synthesis/carbon-carbon-bonds]]）、周环反应与立体选择性反应，以及它们在[[organic-synthesis/total-synthesis]]中的综合运用。

## 往回思考：切断与合成子 {#sec-language}

我们需要一套精确的词汇，因为粗心的逆合成会把假想的碎片和真实的试剂混为一谈。

::: definition 目标分子、切断、合成子与合成等价物 {#def-disconnection}
**目标分子**（TM）是要制作的化合物。**切断**是假想地劈开目标分子中的一根键，书写时用一根从目标分子指向碎片的双纵杆**逆合成箭头** $\Rightarrow$，并在被断的键上画一条波浪线或标以 "dis"。它是一个成键反应的逆过程。极性键的切断通常是**异裂的**：它给出两个理想化的带电碎片，称为**合成子**——一个是电子对受体（正离子，亲电合成子 $a$），一个是电子对供体（负离子，亲核合成子 $d$）。**合成等价物**（即试剂）是反应起来仿佛它就是该合成子的真实化合物。只有当存在可靠的反应能把两个合成等价物接合起来形成这根键、且具有可接受的化学选择性、区域选择性和立体选择性时，一次切断才是成立的。
:::

合成子只是一种记账工具。把 2-苯基丙-2-醇中带羟基的碳与苯基之间的 C–C 键切断，给出合成子 $\mathrm{Ph^-}$ 与 $\mathrm{(CH_3)_2C^+{-}OH}$。两者都不以那种形式存在。它们的合成等价物是苯基溴化镁（其中 C–Mg 键的极性使碳带负电的一端）与丙酮（其羰基碳是亲电的）。正向反应即[[organic-2/carbonyl-addition]]中的格氏加成。用文字说：极性 C–Mg 键的电子对进攻羰基碳；C=O π 键断裂，其电子移到氧上生成镁的烷氧负离子；后处理时含水酸再把烷氧负离子的氧质子化，得到醇。

并非每根键都适合立即切断。我们经常先*在纸上*把一个官能团变成另一个，让某个已知的切断变得可用。

::: definition 官能团互变与官能团添加 {#def-fgi}
**官能团互变**（FGI）是不改变碳骨架而把一个官能团变成另一个的逆合成步骤——例如把胺变成酰胺或硝基化合物、把醇变成酮、把烯烃变成醇——因为正向反应（还原、氧化、消除……）可靠，而新的基团使某次切断成为可能。**官能团添加**（FGA）则添加一个目标分子所没有的基团（例如一个稍后除去的羰基，或一个稍后氢化的双键），理由相同。两者都用标着 "FGI" 或 "FGA" 的逆合成箭头书写。
:::

例如，仲胺 $\mathrm{R{-}CH_2{-}NH{-}R'}$ 直接切断很别扭，因为用卤代烷对胺烷基化会过度烷基化。经 FGI 变成酰胺 $\mathrm{R{-}CO{-}NH{-}R'}$（正向：氢化铝锂还原）之后，分子的 C–N 键就能干净地切断为一个酰氯与一个胺。还原胺化（$\mathrm{RCHO + H_2NR'}$，再加氢化物还原剂）一次操作就达到同样目的，在[[organic-synthesis/redox-in-synthesis]]中讨论。

### 先切断哪里

经验凝练成一份简短的准则清单。它们是启发法而非定律，一个好的合成有时会事出有因地违反其中一条。

::: algorithm 一次逆合成分析 {#alg-retro}
1. **画出目标分子，指出其官能团与立体中心。**给碳链编号，记下杂原子之间的关系（1,2-、1,3-、1,4-……；见[[#prop-dioxygen]]）。
2. **先切断与杂原子相连的键**（酯、酰胺、醚、缩醛与胺中的 C–O、C–N、C–S）：这些键由可靠的极性反应形成，切断它们常常揭示出碳骨架。
3. **寻找回推结构（retron）**——预示某个强有力反应的结构模式：1,3-双氧化的碳链或 α,β-不饱和羰基（羟醛或克莱森）、1,5-二羰基（迈克尔）、环己烯酮（罗宾逊增环）、环己烯（狄尔斯-阿尔德）、联芳基（交叉偶联）。
4. **切断 C–C 键**，在分支点和官能团旁边，尽量使用极性协调（consonant）的合成子（[[#def-polarity]]）；用 FGI 或 FGA 造出某次切断所需要的官能团。
5. **优先选择最能简化的切断**：在分子中部切断的（汇聚性，[[#prop-convergent]]）、利用对称性的、去掉环或立体中心的、或给出商业可得碎片的。
6. **检查每一个正向步骤**的化学选择性（别的基团会反应吗）、区域选择性与立体选择性；在需要处加上保护基（[[organic-synthesis/protecting-groups]]）。
7. **对每个碎片重复此过程**，直到每条分支都终结于可得的起始原料；然后正向写出合成路线，附上试剂与条件，并统计步数与总产率。
:::

::: example 一种酰胺类药物：对乙酰氨基酚 {#ex-paracetamol}
对乙酰氨基酚（paracetamol，acetaminophen）是 $N$-(4-羟基苯基)乙酰胺，$\mathrm{HO{-}C_6H_4{-}NH{-}CO{-}CH_3}$，教科书级的镇痛药。提出一步切断，给出正向反应并用文字叙述其机理，并用以乙酸酐为酰化试剂的那一步计算原子经济性（摩尔质量：对氨基苯酚 $109.13$、乙酸酐 $102.09$、对乙酰氨基酚 $151.16\ \mathrm{g\,mol^{-1}}$）。
::: solution
**切断。** 遵循[[#alg-retro]]第 2 条准则，断开酰胺的 C–N 键。合成子是芳基胺负离子 $\mathrm{HO{-}C_6H_4{-}NH^-}$（供体）与酰基正离子 $\mathrm{CH_3C^+{=}O}$（受体）。合成等价物：对氨基苯酚（中性胺的亲核性已经足够；多余的那个质子稍后失去）与乙酸酐，一种比乙酰氯温和得多的便利酰化试剂。

**机理。** 胺氮的孤对电子进攻乙酸酐的一个羰基碳；C=O 的 π 电子移到那个氧上，给出带 $\mathrm{N^+{-}H}$ 与 $\mathrm{O^-}$ 的四面体中间体。随后氧的孤对电子重建 C=O π 键，与中心氧相连的键断裂，其电子随乙酸根离去。最后乙酸根（或另一个碱）从带正电的氮上拿走一个质子，得到中性酰胺与乙酸。

**化学选择性。** 分子中有两个亲核的基团：$\mathrm{NH_2}$ 与酚羟基 OH。氮的亲核性更强（它电负性较低，把孤对电子抓得较松），所以在一当量酸酐与温和条件下，酰胺有选择地生成。

**原子经济性**（反应物质量中最终进入产物的比例，[[green-chemistry/green-metrics]]）：
$$
\text{AE} = \frac{151.16}{109.13 + 102.09} = \frac{151.16}{211.22} = 71.6\,\%.
$$
损失掉的 $28.4\,\%$ 是副产物乙酸；若用乙酰氯，副产物将是 HCl，事后还得加以中和。
:::
:::

::: example 三次格氏切断 {#ex-grignard}
请分别切断带羟基的碳的每根键，提出 2-苯基丁-2-醇 $\mathrm{PhC(OH)(CH_3)CH_2CH_3}$ 的合成。你会选哪一条？
::: solution
叔醇的带羟基的碳上有三根 C–C 键，每一根都可切断为一个碳负离子合成子（等价物：格氏试剂或有机锂试剂）与一个酮：

(a) 切断 Ph–C：$\mathrm{PhMgBr}$ + 丁-2-酮，$\mathrm{CH_3COCH_2CH_3}$。

(b) 切断 $\mathrm{CH_3CH_2}$–C：$\mathrm{CH_3CH_2MgBr}$ + 苯乙酮，$\mathrm{PhCOCH_3}$。

(c) 切断 $\mathrm{CH_3}$–C：$\mathrm{CH_3MgBr}$（或 $\mathrm{CH_3Li}$）+ 苯丙酮，$\mathrm{PhCOCH_2CH_3}$。

三条路线都离廉价的商业化合物只有一步，取舍于是取决于实际因素。丁-2-酮与苯乙酮都有 α-氢，格氏试剂可能充当碱把酮烯醇化，而不是加到酮上；对无位阻的甲基酮这是个小问题。路线 (b) 是常用的。每种情形的产物都是外消旋的，因为格氏试剂同等地进攻平面酮的两个面（如何控制这一点见[[organic-synthesis/stereoselective-synthesis]]）。注意，酯的切断——两当量格氏试剂加到酯上——只有当三个基团中*两个*相同时才可用，这里并非如此。
:::
:::

## 极性：协调模式与冲突模式 {#sec-polarity}

切断羰基旁的 C–C 键之所以有吸引力，是因为羰基会使其邻近的碳极化。羰基碳是亲电的（合成子 $a^1$，上标按从带杂原子的碳数起的位置计，该碳为位置 1）。α-碳经由烯醇或烯醇负离子是亲核的（$d^2$）。通过共轭，α,β-不饱和羰基的 β-碳又是一个亲电的（$a^3$），迈克尔加成即如此。模式交替出现：杂原子使它所连碳链的奇数位碳带受体特性、偶数位碳带供体特性。

::: definition 天然极性、协调与极性反转 {#def-polarity}
从带氧或氮官能团的碳（该碳为 $1$）开始向外给一条碳链的碳编号。杂原子引起的**天然极性**使奇数号碳成为受体位点（$a^1$、$a^3$、$a^5$……），偶数号碳成为供体位点（$d^2$、$d^4$……）。在带有两个这样的基团的分子中，若两个基团在各碳上要求的极性处处一致，模式就是**协调**的；若相互冲突，就是**冲突**的。**极性反转**（umpolung；德语"极性倒转"；该术语由迪特尔·西巴赫（Dieter Seebach）推广）指让一个碳以其与天然极性相反的方式反应的任何策略——例如，一个酰基碳（天然为 $a^1$）充当亲核试剂（$d^1$）反应。
:::

::: proposition 双氧化规则（经验规则） {#prop-dioxygen}
对于在碳 $i$ 与 $j$ 上带有两个氧官能团（羰基或羟基）的碳链，记 $n = j - i + 1$（即"1,$n$"关系）：

- 若 $n$ 为**奇数**（1,3-与 1,5-关系），极性模式协调，目标分子可由一个天然供体与一个天然受体对接而成——1,3 用**羟醛**或**克莱森**反应，1,5 用**迈克尔**加成；
- 若 $n$ 为**偶数**（1,2-、1,4-与 1,6-关系），模式冲突，在两个被官能团化的碳之间切断，要么需要一个**极性反转**试剂（1,2 与 1,4 用酰基负离子等价物；1,4 用高烯醇负离子或 α-羰基正离子等价物），要么需要一次**重连接**——两个基团经切开一个环或一根双键而一起生成，例如 1,6 用环己烯的臭氧化裂解。

这条规则是关于常用试剂的启发法，不是定律：它说的是用经典的供体（烯醇负离子、有机金属试剂）与受体（羰基、烯酮、卤代烷），哪些切断是现成的。
:::

::: proof 论证
给碳链编号，使两个带氧的碳为 $1$ 与 $n$。从第一个基团数起，碳 $m$ 在 $m$ 为奇数时是受体。从第二个基团数起，同一个碳位于 $n - m + 1$，所以它在 $n - m + 1$ 为奇数、亦即 $m$ 与 $n$ 同奇偶时是受体。因此两个基团在碳 $m$ 上意见一致，当且仅当"$m$ 为奇数"与"$m$ 与 $n$ 同奇偶"同真或同假——$n$ 为奇数时这对每个 $m$ 都成立，$n$ 为偶数时对每个 $m$ 都不成立。于是对奇数 $n$，两基团之间的每根键都可切断为一个天然供体与一个天然受体；而对偶数 $n$，任何这样的切断都会产生一个极性不天然的合成子。$\blacksquare$
:::

这个论证看一个例子最清楚。4-羟基丁-2-酮 $\mathrm{CH_3COCH_2CH_2OH}$ 中，羰基碳 C2 与带羟基的碳 C4 处于 1,3-关系。切断 C3–C4 给出丙酮在 C3 的烯醇负离子（相对酮为 $d^2$ 合成子）与在 C4 的阳离子 $\mathrm{^+CH_2OH}$（相对羟基为 $a^1$ 合成子），其合成等价物是甲醛：一次羟醛反应。两个基团"意见一致"。

::: example 一个 1,3-模式：交叉羟醛合成苄叉丙酮 {#ex-benzalacetone}
请切断 4-苯基丁-3-烯-2-酮 $\mathrm{PhCH{=}CHCOCH_3}$，并提出正向合成。解释为什么这一交叉羟醛不会伴随大量的自身缩合。
::: solution
**FGI。** α,β-不饱和酮是 β-羟基酮的脱水产物：$\mathrm{PhCH{=}CHCOCH_3 \Rightarrow PhCH(OH)CH_2COCH_3}$（FGI，正向：消去水）。β-羟基酮呈 1,3-关系，按[[#prop-dioxygen]]是协调的。

**切断。** 断 C3–C4 键（α-碳与带羟基的碳之间）。合成子：烯醇负离子 $\mathrm{^-CH_2COCH_3}$ 与 $\mathrm{PhCH^+{-}OH}$。等价物：丙酮加碱（含水氢氧化钠），以及苯甲醛。

**正向机理**（克莱森-施密特（Claisen–Schmidt）缩合，[[organic-2/condensations]]）。氢氧根夺走丙酮的一个 α-质子；C–H 的电子变成烯醇负离子的 C=C π 键（并经共振在氧上带上负电荷）。烯醇负离子的 α-碳进攻苯甲醛的羰基碳，醛的 π 电子移到氧上生成烷氧负离子，再被水质子化。随后氢氧根夺走位于新的 C–O 与酮之间、双重活化的 α-质子，生成一个烯醇负离子，它的电子把氢氧根从 β-碳上赶出去（E1cB 消除），生成共轭烯酮。

**选择性。** 苯甲醛没有 α-氢，不能形成烯醇负离子，只能充当亲电试剂；它又是比丙酮更活泼的亲电试剂，所以丙酮的烯醇负离子进攻苯甲醛甚于进攻另一分子丙酮。脱水由新 C=C 与芳环和酮两者的共轭驱动，使总反应基本上不可逆。使用过量丙酮可抑制另一个甲基上的第二次缩合（那将给出二苄叉丙酮）。
:::
:::

::: example 一个 1,5-模式与一个环：维兰德-米歇尔酮 {#ex-wieland-miescher}
维兰德-米歇尔酮，8a-甲基-3,4,8,8a-四氢萘-1,6(2*H*,7*H*)-二酮（$\mathrm{C_{11}H_{14}O_2}$，$M = 178.23\ \mathrm{g\,mol^{-1}}$），是一个用作甾体与萜类砌块的双环烯酮-酮。请对它做逆合成，并计算由 2-甲基环己烷-1,3-二酮（$126.16\ \mathrm{g\,mol^{-1}}$）与丁-3-烯-2-酮（甲基乙烯基酮，MVK，$70.09\ \mathrm{g\,mol^{-1}}$）出发的正向总过程的原子经济性。
::: solution
**回推结构。** 目标分子含有一个环己烯酮，与一个环己酮稠合于一个带甲基的季碳。环己烯酮是**罗宾逊增环反应**（迈克尔加成继以分子内羟醛缩合）的回推结构。

**第 1 步（FGI 与羟醛切断）。**在纸上把烯酮加水成 β-羟基酮，再把环的 C=C 键当作羟醛反应产物切断：环打开成一个三酮，2-甲基-2-(3-氧代丁基)环己烷-1,3-二酮。羟醛键把甲基酮的端位碳（烯醇负离子，供体）连到环的一个羰基（受体）上——β-羟基酮中的 1,3-关系，协调。

**第 2 步（迈克尔切断）。**三酮的侧链酮与每个环羰基之间是 1,5-关系。切断环的季碳与侧链之间的键：合成子是 2-甲基环己烷-1,3-二酮的烯醇负离子（供体，一个非常稳定的烯醇负离子，因为负电荷由两个羰基分担）与阳离子 $\mathrm{^+CH_2CH_2COCH_3}$（受体，$a^3$），其等价物是 MVK。

**正向。** 碱在 C2 使二酮去质子化；烯醇负离子的碳进攻 MVK 的 β-碳，C=C 的 π 电子移到羰基上生成一个在碳上质子化的烯醇负离子。第二阶段（经典方法用吡咯烷，或用 L-脯氨酸不对称催化，即[[organic-synthesis/stereoselective-synthesis]]中的 Hajos–Parrish–Eder–Sauer–Wiechert 反应），甲基酮生成烯胺或烯醇负离子，分子内进攻一个环羰基闭成六元环；脱水给出烯酮。

**原子经济性。** 总体：二酮 + MVK → 产物 + $\mathrm{H_2O}$：
$$
\text{AE} = \frac{178.23}{126.16 + 70.09} = \frac{178.23}{196.25} = 90.8\,\%.
$$
只损失水。MVK 有毒、是催泪剂且易于聚合；须在通风橱中戴好防护装备操作，使用它的工作需要监督与风险评估。
:::
:::

### 冲突模式与极性反转

现在看一个 1,4-二酮，如 1-苯基戊烷-1,4-二酮 $\mathrm{PhCO{-}CH_2CH_2{-}COCH_3}$。切断中心的 C2–C3 键，给出一个烯醇负离子（对一个酮为 $d^2$）加另一个酮 α-碳上的正离子（$a^2$ 合成子——冲突），或反之亦然。在羰基旁、C1 与 C2 之间切断，则给出苯甲酰负离子 $\mathrm{PhC^-{=}O}$（$d^1$，不天然）与 $\mathrm{^+CH_2CH_2COCH_3}$（$a^3$，天然——又是 MVK）。每个方案都需要一个极性不天然的合成子，正像[[#prop-dioxygen]]所预测的。

化学家为**酰基负离子** $\mathrm{RC^-{=}O}$ 设计了几种合成等价物：

- **1,3-二噻烷**（科里与西巴赫，1965）。醛与丙烷-1,3-二硫醇转化为它的环状硫缩醛。两个硫原子之间 C2–H 的酸性足够强（$\mathrm{p}K_\mathrm{a} \approx 31$），可被丁基锂夺走；所得负离子被卤代烷烷基化，或加到羰基化合物与环氧化物上，最后把硫缩醛水解回酮（用汞(II)盐，或更温和地用 $N$-溴代丁二酰亚胺或双(三氟乙酰氧基)碘苯等氧化性试剂）。
- **氰醇负离子**：把 O-保护的氰醇 $\mathrm{RCH(OSiR_3)CN}$ 在腈的 α-位去质子化，烷基化，然后揭开面纱得酮。
- **亲核催化**：氰离子（苯偶姻缩合，它构造 1,2-模式）或噻唑鎓、三唑鎓卡宾（苯偶姻与 **Stetter** 反应）加到醛上，生成一个亲核的中间体，其中原来的羰基碳成了供体。

::: example 一个 1,4-模式：Stetter 反应 {#ex-stetter}
请提出 1-苯基戊烷-1,4-二酮的一步合成，并描述催化剂如何使苯甲醛的极性反转。
::: solution
**切断。** 断 C1–C2：$d^1$ 苯甲酰负离子 + $a^3$ MVK。**Stetter 反应**（赫尔曼·斯特特（Hermann Stetter），1970 年代）以催化方式提供苯甲酰负离子等价物：苯甲醛 + 丁-3-烯-2-酮，用催化量的噻唑鎓盐与温和的碱（三乙胺）。

**文字机理。** (1) 碱夺走噻唑鎓环上酸性的 C2–H，得到一个亲核的卡宾（叶立德），其 C2 上的孤对电子进攻苯甲醛的羰基碳；C=O 的 π 电子移到氧上。(2) 一个质子（经由碱）从原来的醛碳转移到氧上，得到烯胺醇，即**布雷斯洛中间体**，其中原来的羰基碳如今是与氮和硫相连的富电子 C=C 的一部分——一个供体。(3) 该碳以迈克尔加成进攻 MVK 的 β-碳；MVK 的 π 电子移动生成烯醇负离子。(4) 质子转移到烯醇负离子的碳上，得到一个四面体加成物，它的 O–H 质子被夺走；烷氧负离子重建 C=O，与噻唑鎓 C2 相连的键断裂，释放出 1,4-二酮并再生卡宾催化剂。

苯甲醛与 MVK 的每一个原子都进入产物（AE $= 100\,\%$）。1,4-二酮是经保尔-克诺尔（Paal–Knorr）合成制呋喃、吡咯与噻吩的经典前体（[[organic-2/heterocycles]]），这就是这一切断要紧的原因。
:::
:::

**1,6-模式**最容易靠**重连接**制作：在纸上把 1,6-二羰基的两端接起来形成一个环己烯；正向方向上，环己烯的臭氧化裂解（或另一种氧化断裂）一次揭开两个羰基。环己烯又是狄尔斯-阿尔德反应的回推结构（[[organic-synthesis/pericyclic]]），所以一个 1,6-二羰基距简单的双烯与亲双烯体可能只有两步。工业上，制尼龙-6,6 用的己二酸（adipic acid）就是靠六元环的氧化断裂制造的（环己醇/环己酮用硝酸），是同一逻辑的大规模版本。

::: quiz
下列哪些是酰基负离子合成子 $\mathrm{CH_3C^-{=}O}$ 的合理合成等价物？
- [x] 2-锂代-2-甲基-1,3-二噻烷，在 C–C 键形成之后再水解硫缩醛
- [x] O-硅化的乙醛氰醇的负离子 $\mathrm{CH_3C^-(OSiR_3)CN}$，事后再揭开面纱成酮
- [ ] 丙酮的锂烯醇负离子 $\mathrm{CH_2{=}C(OLi)CH_3}$
- [ ] 乙酰氯 $\mathrm{CH_3COCl}$
::: solution
酰基负离子等价物必须把乙酰基的*碳*作为亲核试剂递送出来。锂代的二噻烷与保护的氰醇负离子，都在日后成为羰基碳的那个碳上带有碳负离子。丙酮的烯醇负离子是在 α-碳（$d^2$）上亲核，而不是在羰基碳上。乙酰氯是酰基*正离子* $\mathrm{CH_3C^+{=}O}$ 的等价物——极性恰好相反。
:::
:::

::: warning 合成子不是试剂 {#warn-synthon}
人们很容易把 $\mathrm{Ph^-}$ 或 $\mathrm{CH_3CO^+}$ 写得像瓶子里真有这些东西，或者因为两个合成子"看起来般配"就接受任何切断。由此生两种错误。其一，合成子可能没有任何实用的等价物：合成子 $\mathrm{^+CH_2COCH_3}$（$a^2$ 正离子）形式上对应一个 α-卤代酮，但 α-卤代酮是强催泪剂，且与烯醇负离子会以好几种相互竞争的方式反应，所以这一切断很少是最佳选择。其二，一次切断可以对应一个真实的反应，却在*这个*底物上失败：对同时带有酯基的酮做格氏加成、两个烯醇化能力相当的伙伴之间的羟醛反应。接受一次切断之前，务必说出真实试剂的名字，把正向反应在头脑里走一遍，检查分子里其余每一个官能团。
:::

## 在若干路线之间做选择 {#sec-strategy}

一次逆合成分析很少只产生一条路线。左右取舍的是两个问题：多少物料能活着走完整个序列，以及它产生多少废物。

### 产率算术与汇聚性

::: proposition 线性与汇聚式路线的总产率 {#prop-convergent}
在 $n$ 步、分步产率为 $p_1, p_2, \ldots, p_n$ 的**线性**合成中，总产率为
$$
Y_\text{linear} = \prod_{i=1}^{n} p_i = p^n \quad\text{若每个 } p_i = p.
$$ {#eq-linear-yield}
在**汇聚式**合成中，碎片分开制备，稍后对接。对任一起始原料而言，总产率是沿它到目标分子的路径上各步产率的乘积，而评价一条路线通常看它的**最长线性序列**（LLS）。若目标分子由两个各经 $k$ 步制成的碎片在最后一步对接而成（共 $2k+1$ 步），则 $Y = p^{k+1}$，而同样的 $2k+1$ 步若线性地做下来则是 $p^{2k+1}$。
:::

::: proof
每一步把其投入的分数 $p_i$ 转化为产出，与该物料的经历无关，所以各分数沿一条路径相乘。汇聚情形中，始于碎片 A 的物料只经过 A 支的 $k$ 步和最后的对接步，共 $k+1$ 步；它从不经过 B 支。其产率于是为 $p^{k+1}$，碎片 B 同理。线性情形中，目标分子的每个原子都经过全部 $2k+1$ 步。由于 $0 < p < 1$，当 $k \geq 1$ 时 $p^{k+1} > p^{2k+1}$。$\blacksquare$
:::

两个推论值得直说。其一，**步数是残酷的**：十步、每步高达 $90\,\%$，物料只剩 $0.9^{10} = 34.9\,\%$；十步、每步 $80\,\%$，只剩 $10.7\,\%$。其二，**汇聚性在长路线中回报最大**，因为指数大约减半。它还降低风险：若后期的对接失败，两条短路线比一条长路线更容易重做，而昂贵的中间体暴露在更少的步骤之下。

::: example 需要多少起始原料？ {#ex-mass}
一个目标分子（$M = 400\ \mathrm{g\,mol^{-1}}$）由 7 步线性路线制备，每步产率 $85\,\%$。(a) 总产率是多少？(b) 一条替代路线用 3 步各制一个碎片，最后一步对接（各步产率也都是 $85\,\%$）。最长线性序列上的产率是多少？(c) 两条路线各需多少摩尔第一个起始原料来生产一摩尔目标分子？
::: solution
(a) $0.85^7 = 0.3206$，即 **32.1 %**。

(b) 最长线性序列为 $3 + 1 = 4$ 步：$0.85^4 = 0.5220$，即 **52.2 %**。

(c) 线性：每摩尔目标分子需第一个起始原料 $1/0.85^7 = 3.12\ \mathrm{mol}$。汇聚式：*每个*碎片的起始原料各需 $1/0.85^4 = 1.92\ \mathrm{mol}$。汇聚路线虽然用两种起始原料，但每种所需的过量更小，而昂贵的后期中间体在更少的步骤里制成。注意两条路线都包含七个操作；汇聚改变的是产率，不是实验室工作量。
:::
:::

当若干路线分叉又汇合时，把规划问题看作一张网络会有帮助。因为产率相乘，$-\ln Y = \sum_i (-\ln p_i)$：若给每步赋予"代价" $-100\ln p_i$，总产率最高的路线就是总代价最小的路径，而最短路算法能找到它。

### 原子经济性与废物

产率衡量我们相对于理论最大量得到多少产物。它对一同进烧瓶的其他一切的质量不置一词。巴里·特罗斯特（Barry Trost）的**原子经济性**（1991）衡量内在于一条路线*方程*的效率。

::: definition 原子经济性 {#def-atom-economy}
对一个反应或一个序列，写成配平方程时，**原子经济性**为
$$
\text{AE} = \frac{M(\text{目标产物})}{\sum M(\text{化学计量方程中的所有反应物})} \times 100\,\%.
$$ {#eq-ae}
出现在配平方程中的试剂要计入；催化剂与溶剂不计。原子经济性是所选化学的性质，与产率无关。工艺化学家还使用 **E 因子**（每单位质量产物产生的废物质量，包括溶剂与产率损失）与**过程质量强度**，见[[green-chemistry/green-metrics]]。
:::

加成反应（狄尔斯-阿尔德、氢化、迈克尔、Stetter）的 $\text{AE} = 100\,\%$；缩合损失一个小分子；取代与消除损失一个离去基团；使用化学计量试剂的反应，如维蒂希反应（[[organic-synthesis/carbon-carbon-bonds]]），它丢弃三苯基膦氧化物（$278\ \mathrm{g\,mol^{-1}}$），即使产率很高原子经济性也可能很低。

::: example 通往布洛芬的两条路线 {#ex-ibuprofen}
布洛芬，2-[4-(2-甲基丙基)苯基]丙酸（$\mathrm{C_{13}H_{18}O_2}$，$M = 206.28\ \mathrm{g\,mol^{-1}}$），是路线取舍的教科书案例。最初的 Boots 路线（1960 年代）从 2-甲基丙基苯（异丁苯）出发走六步：傅-克乙酰化、与氯乙酸乙酯的 Darzens 缩合、水解并脱羧成醛、生成肟、脱水成腈、水解。1990 年代初的 BHC（Boots–Hoechst–Celanese）路线只要三步：用乙酸酐的傅-克乙酰化（HF 兼作催化剂与溶剂，循环利用）、酮催化氢化成醇、醇与一氧化碳的钯催化羰基化。比较两条路线的原子经济性，把 Boots 路线的化学计量试剂记作乙酸酐、氯乙酸乙酯、乙醇钠、$\mathrm{H_3O^+}$、羟胺和两分子水（反应物质量之和 $514.99\ \mathrm{g\,mol^{-1}}$）。
::: solution
**Boots 路线：** $\text{AE} = 206.28/514.99 = 40.1\,\%$。试剂的大部分质量以乙酸、氯化钠、乙醇、二氧化碳和铵盐的形式离去。

**BHC 路线：** 总方程为
$$
\mathrm{C_{10}H_{14} + C_4H_6O_3 + H_2 + CO \rightarrow C_{13}H_{18}O_2 + CH_3CO_2H},
$$
摩尔质量 $134.22 + 102.09 + 2.02 + 28.01 = 266.34\ \mathrm{g\,mol^{-1}}$，故
$$
\text{AE} = \frac{206.28}{266.34} = 77.4\,\%,
$$
而且唯一的副产物乙酸本身有用（若把它也算作产物，数字将升到约 $99\,\%$）。BHC 路线步数减半，并用催化剂（HF、雷尼镍或 Pd/C、钯羰基化催化剂）取代化学计量试剂。从逆合成看，它的关键一招是把羧酸看作苄位醇的羰基化——把 C–$\mathrm{CO_2H}$ 键切断到 CO，这是最初的方案设计者当年没有的切断。新的反应创造新的切断。
:::
:::

### 其他策略考量

除产率与原子经济性外，评价一条路线还要看：

- **化学选择性与保护基。** 每次保护与脱保护增加两步；能靠巧妙安排步骤顺序（例如最后才引入敏感基团）避开保护基的路线通常更好（[[organic-synthesis/protecting-groups]]）。
- **立体化学。** 早早地、在控制之下设定立体中心的路线，胜过最后不得不分离异构体的路线（[[organic-synthesis/stereoselective-synthesis]]）。
- **试剂的可得性、成本与安全。** 需要剧毒、爆炸性或不稳定试剂的切断，即使短也不是好选择。
- **稳健性与可放大性。** 结晶性的中间体、耐微量水和空气的反应、不需要色谱的步骤，能使一条路线走出研究实验室。

科里把[[#alg-retro]]的准则归入五族**策略**：*基于变换*（寻找某个强反应的回推结构）、*结构目标*（以某个特定的起始原料为鹄的，比如手性池中某个糖或氨基酸）、*拓扑*（选择切断后最能简化环系的那些键）、*立体化学*（在立体控制之下撤去立体中心）与*基于官能团*（用官能团引导切断）。好的分析会同时使用其中几种。

::: history
化学家制作复杂分子早已几百年，只是没人写下他们如何规划；罗伯特·罗宾逊（Robert Robinson）1917 年的一锅法仿生合成，与罗伯特·伯恩斯·伍德沃德（Robert Burns Woodward）1940 与 1950 年代的合成，都出自非凡的直觉规划。埃利亚斯·詹姆斯·科里把反向逻辑形式化，其讲演以"General methods for the construction of complex molecules"发表于《纯与应用化学》（*Pure and Applied Chemistry*，1967），引入了合成子与逆合成分析这两个术语，并把该方法用于长叶烯（1961）与前列腺素（1969）等的合成。他与 W. 托德·威普克（W. Todd Wipke）在 1969 年（《科学》，*Science*）证明这一分析可以编码为计算机规则（后来称为 LHASA 的程序）。科里与迪特尔·西巴赫于 1965 年引入锂代的 1,3-二噻烷作为酰基负离子等价物，西巴赫 1979 年在《应用化学》（*Angewandte Chemie*）上的综述使"umpolung（极性反转）"成为一个标准概念。斯图尔特·沃伦（Stuart Warren）的《有机合成：切断法》（*Organic Synthesis: The Disconnection Approach*，1982）把该方法带进本科教学，科里与 Xue-Min Cheng 的《化学合成的逻辑》（*The Logic of Chemical Synthesis*，1989）则完整阐发了这些策略。科里获 1990 年诺贝尔化学奖，"表彰他对有机合成理论与方法学的发展"。2018 年以来，在数百万已发表反应上训练出来的计算机规划器（例如 Marwin Segler、Mike Preuss 与 Mark Waller 发表于《自然》（*Nature*）的工作，以及 Bartosz Grzybowski 课题组的 Chematica/Synthia 程序）大规模地复兴了科里 1969 年的想法。
:::

::: summary
- 逆合成分析从目标分子往回推：每次**切断**（$\Rightarrow$）是一个可靠反应的逆过程，给出**合成子**——由**合成等价物**实现的理想化离子。
- **FGI** 与 **FGA** 在纸上改变官能团，让好的切断成为可能；先切断与杂原子相连的键，并寻找回推结构（烯酮 → 羟醛、1,5-二羰基 → 迈克尔、环己烯酮 → 罗宾逊、环己烯 → 狄尔斯-阿尔德）。
- 杂原子使奇数碳带受体、偶数碳带供体特性；**1,3-与 1,5-**双氧化模式是协调的（羟醛、克莱森、迈克尔），**1,2-、1,4-与 1,6-**是冲突的，需要**极性反转**（二噻烷、氰醇、卡宾催化）或**重连接**（臭氧化裂解开环）。
- 总产率是各步产率之积；**汇聚式**路线以最长线性序列论长短，指数大约减半。
- **原子经济性** $= M(\text{产物})/\sum M(\text{反应物})$ 由所选化学决定：加成得 100 %，Boots 的布洛芬路线 40 %，BHC 路线 77 %。
- 接受任何设想的正向步骤之前，检查它的化学、区域与立体选择性，以及试剂的危险性。
:::

## 练习

::: exercise 阿司匹林的原子经济性 {level=1 check="75.0"}
阿司匹林（2-乙酰氧基苯甲酸，$180.16\ \mathrm{g\,mol^{-1}}$）由 2-羟基苯甲酸（水杨酸，$138.12\ \mathrm{g\,mol^{-1}}$）与乙酸酐（$102.09\ \mathrm{g\,mol^{-1}}$）制备。计算原子经济性。（以百分数输入，保留三位有效数字。）
::: solution
$\text{AE} = 180.16/(138.12 + 102.09) = 180.16/240.21 = 0.750 = 75.0\,\%$（[[#eq-ae]]）。切断的是酯的 C–O 键：酚氧（供体）与酰基正离子（受体）。副产物是乙酸。
:::

::: exercise 切断一个叔醇 {level=1}
给出 1,1-二苯基乙-1-醇 $\mathrm{Ph_2C(OH)CH_3}$ 的两个不同的、基于格氏试剂的合成，其中一个要用到酯。
::: solution
(a) 切断一根 Ph–C 键：$\mathrm{PhMgBr}$ + 苯乙酮 $\mathrm{PhCOCH_3}$，一当量。(b) 切断 $\mathrm{CH_3}$–C 键：$\mathrm{CH_3MgBr}$ + 二苯甲酮 $\mathrm{Ph_2CO}$。(c) 因为两个基团相同，把*两根* Ph–C 键都切断：两当量 $\mathrm{PhMgBr}$ + 一个乙酸酯（如乙酸乙酯）。第一当量加到酯羰基上，四面体中间体赶出乙氧基给出苯乙酮，第二当量再加到这个酮上（酮比酯更活泼，反应无法停在酮这一步）。
:::

::: exercise 协调还是冲突？ {level=2}
指出下列化合物的 1,$n$-关系，并判断协调还是冲突：(a) 4-羟基丁-2-酮；(b) 3-羟基-3-甲基丁-2-酮；(c) 己烷-2,5-二酮；(d) 庚烷-2,6-二酮。对每个协调的情形建议一个关键的 C–C 切断。
::: solution
(a) 酮 C2、带羟基的碳 C4：1,3，协调——丙酮烯醇负离子与甲醛的羟醛反应（C3–C4 切断）。(b) 酮 C2、带羟基的碳 C3：1,2，冲突（一个 α-羟基酮；制备方法如把酰基负离子等价物加到丙酮上，或把酮 α-氧化）。(c) C2 与 C5：1,4，冲突（Stetter 型极性反转，或把水解 2,5-二甲基呋喃当作"重连接"）。(d) C2 与 C6：1,5，协调——丙酮的烯醇负离子（或稳定的等价物，如乙酰乙酸乙酯，再脱羧）对 MVK 的迈克尔加成，切断 C3–C4。
:::

::: exercise 10 克产物要多少原料 {level=2 check="14.3"}
你需要 $10.0\ \mathrm{g}$ 某目标分子（$M = 400\ \mathrm{g\,mol^{-1}}$），它由 6 步线性路线制备，每步产率 $80\,\%$。第一个起始原料的 $M = 150\ \mathrm{g\,mol^{-1}}$，一对一进入产物。需要它多少克？（质量以克输入，保留三位有效数字。）
::: solution
目标分子：$10.0/400 = 0.0250\ \mathrm{mol}$。总产率 $0.8^6 = 0.2621$。起始原料：$0.0250/0.2621 = 0.0954\ \mathrm{mol}$，即 $0.0954 \times 150 = 14.3\ \mathrm{g}$。若换成长最长线性序列为 4 步的汇聚路线，每个碎片的起始原料只需 $0.0250/0.8^4 \times 150 = 9.16\ \mathrm{g}$。
:::
:::

::: exercise 一个查尔酮 {level=2 check="92.0"}
切断 (*E*)-1,3-二苯基丙-2-烯-1-酮（查尔酮，$\mathrm{PhCOCH{=}CHPh}$，$208.26\ \mathrm{g\,mol^{-1}}$），给出正向反应，并计算由苯乙酮（$120.15\ \mathrm{g\,mol^{-1}}$）与苯甲醛（$106.12\ \mathrm{g\,mol^{-1}}$）出发的原子经济性。（原子经济性以百分数输入，保留三位有效数字。）
::: solution
FGI 到 β-羟基酮 $\mathrm{PhCOCH_2CH(OH)Ph}$（1,3，协调），再切断 C2–C3：苯乙酮的烯醇负离子 + 苯甲醛，一次克莱森-施密特缩合，水相 NaOH、乙醇中进行，与[[#ex-benzalacetone]]的做法完全相同。苯甲醛不能烯醇化，所以是唯一的亲电试剂；苯乙酮是唯一的亲核试剂；脱水成共轭烯酮推动反应完成。$\text{AE} = 208.26/(120.15 + 106.12) = 208.26/226.27 = 92.0\,\%$；水是唯一的副产物。
:::
:::

::: exercise 经重连接制 1,6-二羰基 {level=3}
提出由环己酮合成 6-氧代庚醛 $\mathrm{CH_3CO(CH_2)_4CHO}$。
::: hint
在纸上把 C1 与 C6 接起来。你得到什么环、什么取代基？
:::
::: solution
**分析。** 醛碳（C1）与酮碳（C6）呈 1,6-关系：冲突。把它们重连接为一根 C=C 双键：目标分子就是**1-甲基环己烯**的臭氧化裂解产物（带甲基的烯碳变成酮，CH 烯碳变成醛）。1-甲基环己烯 $\Rightarrow$（FGI，脱水）1-甲基环己-1-醇 $\Rightarrow$（格氏切断）环己酮 + $\mathrm{CH_3MgBr}$。

**正向。** (1) $\mathrm{CH_3MgBr}$ 加到环己酮上（C–Mg 的电子进攻羰基碳，π 电子移到氧上；酸性后处理使烷氧负离子质子化）。(2) 酸催化脱水（如磷酸，边生成边蒸馏）：OH 被质子化，水离去生成叔碳正离子，失去一个环上的质子主要给出取代较多、位于环内的烯烃 1-甲基环己烯（札依采夫）。(3) 低温臭氧化继以还原性后处理（二甲硫醚或三苯基膦）断裂 C=C，得 6-氧代庚醛；若用氧化性后处理则得到酮酸。臭氧有毒，臭氧化物会爆炸，所以反应要在低温、溶液中进行，在防护屏后操作，并在浓缩之前完成还原性后处理（[[organic-synthesis/redox-in-synthesis]]）。
:::
:::

::: exercise 烯胺路线制 1,4-二酮 {level=3}
2-(2-氧代丙基)环己-1-酮是一个 1,4-二酮，要由环己酮制备，且不使用 α-卤代酮。分析目标分子的极性，并提出一条先烷基化、后氧化的路线。解释烷基化为什么通过烯胺来做，而不是锂烯醇负离子。
::: hint
端烯是一个被掩蔽的甲基酮（瓦克（Wacker）氧化）。
:::
::: solution
**极性。** 环 C1（酮）与侧链 C2′（酮）隔着环 C2 与侧链 C1′ 相连：1,4-关系，冲突。切断环 C2–C1′ 需要一个 $d^2$ 的环烯醇负离子和一个 $a^2$ 的侧链正离子（α-卤代酮），或反过来——两边总有一边是不天然的。

**用 FGI 求解。** 用侧链酮的一个合成等价物——端烯——来代替它：$\mathrm{{-}CH_2COCH_3 \Rightarrow {-}CH_2CH{=}CH_2}$（FGI；正向：**瓦克氧化**，$\mathrm{PdCl_2}$ 催化剂，CuCl 与 $\mathrm{O_2}$，含水 DMF，把端烯转化为甲基酮）。于是 2-烯丙基环己酮在环 C2–C1′ 处切断为一个天然的 $d^2$ 环烯醇负离子与一个烯丙基正离子，后者的等价物是烯丙基溴——协调。

**正向。** (1) 环己酮 + 吡咯烷（酸催化，除水）→ 烯胺。(2) 用烯丙基溴烷基化：氮的孤对电子推入 C=C，其 β-碳进攻烯丙位碳，顶出溴离子（$\mathrm{S_N2}$），得到亚胺离子盐。(3) 亚胺离子含水水解 → 2-烯丙基环己酮。(4) 瓦克氧化 → 2-(2-氧代丙基)环己-1-酮。

**为什么用烯胺（斯特克（Stork），1963）。**烯胺是中性、温和的亲核试剂：一次烷基化之后，亚胺离子产物不再有亲核性，所以双烷基化被抑制，而且反应不需要强碱。锂烯醇负离子会与单烷基化的酮发生质子交换，给出单、双烷基化产物的混合物。烯丙基溴有毒、是催泪剂：须在通风橱中使用，并有监督。
:::

::: exercise 最短路，最高产率 {level=3 check="0.590"}
证明：选择总产率最高的路线，等价于在每步权重为 $-\ln p_i$ 时选择总权重最小的路径。然后比较一条每步都 $90\,\%$ 的五步路线与一条三步路线（三步分别为 $80$、$70$ 与 $95\,\%$）。（把较优路线的总产率以小数输入，保留三位有效数字。）
::: solution
$Y = \prod p_i$，而 $\ln$ 严格递增，所以最大化 $Y$ 就是最大化 $\ln Y = \sum \ln p_i$，亦即最小化 $\sum(-\ln p_i)$。每个权重都是正的（因为 $p_i < 1$），这正是 Dijkstra 算法正确的条件。五步各 $0.90$：$0.9^5 = 0.590$（总权重 $5 \times 0.105 = 0.527$）。三步：$0.80 \times 0.70 \times 0.95 = 0.532$（权重 $0.223 + 0.357 + 0.051 = 0.631$）。**较长的路线更好**，$Y = 0.590$。实践中五步路线的人工与溶剂也更多，真正的决定还会权衡这些因素。
:::
