本课程中的大多数反应是在拼接或改造碎片的同时让碳骨架原封不动。而合成中最有力的一些转变做的恰恰相反：它们**重排骨架本身**。一个碳正离子通过把相邻基团带着它的成键电子对移动，找到更稳定的排布；一个肟通过把碳迁移到氮上变成酰胺；一个酮环缩小或扩大一个原子；一个卡宾插进 C=C 键生成三元环；一个自由基回咬五个原子之外的烯烃并闭合成环。这些反应涉及一些活泼中间体——碳正离子、卡宾、氮宾与自由基——它们只存在纳秒甚至更短，而在早期的课程里，它们主要作为不需要的副产物的来源出现。在这里我们学会有意地利用它们。

本章分三个部分。第一部分是**阳离子型及相关 1,2-迁移**：瓦格纳-米尔魏因（Wagner–Meerwein）重排与频哪醇重排，以及向缺电子氮（贝克曼（Beckmann）、霍夫曼（Hofmann）、库尔提斯（Curtius））和向氧（拜耳-维利格（Baeyer–Villiger），在[[organic-synthesis/redox-in-synthesis]]中见过）的迁移，再加上法沃尔斯基（Favorskii）缩环。第二部分是**卡宾、类卡宾与氮宾**：环丙烷化、插入反应与沃尔夫（Wolff）重排。第三部分是把**自由基反应**当作合成工具：锡烷链反应、自由基环化及其动力学，以及现代的替代办法。这些中间体的证据——捕获、标记、立体化学与自由基钟——来自[[organic-synthesis/mechanism-determination]]，自由基链反应的基础在[[organic-1/radical-reactions]]。

## 向缺电子中心的 1,2-迁移 {#sec-shifts}

::: definition 1,2-迁移 {#def-shift}
**1,2-迁移**（或称向缺电子中心的 [1,2]-σ迁移）是指基团 G——氢（氢负离子迁移）、烷基、芳基或乙烯基——带着它的成键电子对，从一个原子迁移到相邻的缺电子原子（碳正离子、氮宾鎓型或卡宾中心、或正在失去离去基团的原子）上。在过渡态中，迁移基团通过一个三中心两电子键桥连两个原子。它离开的原子成为新的缺电子中心（常由相邻的孤对电子稳定，如氧碳鎓离子中的情形）。
:::

::: proposition 1,2-迁移的立体化学（经验概括） {#prop-shift-stereo}
在向缺电子碳、氮或氧的协同 1,2-迁移中：(1) 迁移基团**带着自己的构型迁移（构型保持）**，因为它从离不开它的成键电子对，且是从一个面被递送过去的；(2) 迁移的基团是与正在离去的离去基团（或是预先生成的阳离子的空轨道）**反式共平面**的那个，这样正在断裂的 σ 键才能与接受它的 σ* 或空 p 轨道重叠；(3) 若迁移与离去基团的离去协同进行，则迁移的**终点**构型翻转。最能稳定部分正电荷的基团迁移最容易（大致为芳基 ≈ H > 叔 > 仲 > 伯烷基 > 甲基），但立体电子排列的要求优先于固有的迁移倾向。
:::

::: proof 论证
迁移基团 G 以 σ 键连在原子 C1 上，迁往相邻的缺电子原子 C2。当 C1–G 键与 C2 上的空 p 轨道平行（或与正在被占据的 σ* 轨道所属的 C2–X 键反式共平面）时，轨道重叠最大：这就是反式共平面要求。在此过程中，G 使用其轨道的同一个瓣，通过三中心键同时与 C1 和 C2 成键，因此 G 是同面转移的，它自身的构型不变——在沃尔夫、库尔提斯、霍夫曼与拜耳-维利格反应中迁移光学富集的 *sec*-丁基等基团的实验证实了这一点，它们都完全保持构型。在 C2 上，G 从与离去基团相反的一面到达（背面进攻，如同 $\mathrm{S_N2}$），所以若 C2 是立体中心且离去是协同的，C2 就发生翻转。$\blacksquare$
:::

### 瓦格纳-米尔魏因重排与频哪醇重排

当碳正离子在带有氢或烷基的碳旁边生成时，1,2-迁移可以把它变成一个更稳定的阳离子。这类**瓦格纳-米尔魏因**迁移解释了萜类与甾体的骨架重排——异冰片转化为樟莰、羊毛甾醇的生物合成——以及二级底物 $\mathrm{S_N1}$ 与 E1 反应中纠缠不清的混合物（[[organic-1/nucleophilic-substitution]]）。

**频哪醇重排**是合成上最有用的版本。用酸处理的 1,2-二醇从一个碳上失去水生成碳正离子；相邻 带羟基的碳上的一个基团发生迁移；所得阳离子被氧的孤对电子稳定为质子化的酮。

::: example 频哪醇重排 {#ex-pinacol}
描述 2,3-二甲基丁烷-2,3-二醇（频哪醇）在酸催化下重排为 3,3-二甲基丁-2-酮（频哪酮）的机理，并预测 2-甲基-1,1-二苯基丙烷-1,2-二醇的产物。
::: solution
**频哪醇。** (1) 一个羟基氧的孤对电子从酸中接过质子。(2) C–$\mathrm{OH_2^+}$ 键异裂，电子随水离去，给出一个叔碳正离子。(3) 相邻 带羟基碳上的一个甲基带着它的成键电子对，经由三中心过渡态迁移到阳离子碳上；正电荷移到失去甲基的那个碳上，在那里立即被相邻氧的孤对电子稳定，形成 C=O⁺–H（质子化的酮）。(4) 氧失去质子给出 3,3-二甲基丁-2-酮。推动力是强 C=O 键的生成：氧碳鎓离子比叔碳正离子稳定得多。

**2-甲基-1,1-二苯基丙烷-1,2-二醇**，$\mathrm{Ph_2C(OH){-}C(OH)(CH_3)_2}$。原则上可以生成两种阳离子。C1 电离给出**二苯甲基型阳离子**，靠离域进两个苯环得到稳定，远比 C2 上的叔阳离子稳定——所以水从 C1 离去。随后一个甲基从 C2 迁移到 C1（C2 上没有别的基团可以迁移：C2 带着两个甲基和一个 OH），C2 成为羰基碳：**3,3-二苯基丁-2-酮**，$\mathrm{CH_3CO{-}CPh_2{-}CH_3}$。规则是：先确定哪个阳离子生成（更稳定的那个），再问哪个基团迁移。
:::
:::

**半频哪醇**重排通过在 β-羟基化合物的一个碳上安放一个离去基团（磺酸酯，或被路易斯酸打开的环氧化物），在更温和的条件下达到同样的结果。当迁移的键是环的一部分时，就发生扩环：在**蒂芬诺-杰米扬诺夫**（Tiffeneau–Demjanov）反应中，1-(氨甲基)环烷醇被亚硝酸重氮化，氮气从伯重氮离子上离去，环 C–C 键迁移，给出环大一号的环烷酮。

### 向氮的迁移：贝克曼、霍夫曼与库尔提斯重排

**贝克曼重排。** 肟（$\mathrm{R_2C{=}NOH}$）被酸或通过活化 OH（磺酰氯、$\mathrm{PCl_5}$、三聚氯氰）转化为酰胺。OH 被变成离去基团；当它从氮上离去时，与它处于**反位（anti）**的基团从碳迁移到氮上；随后水进攻所得腈鎓离子，互变异构给出酰胺。由于肟的几何构型决定哪个基团迁移，(*E*)-与 (*Z*)-肟给出不同的酰胺。

**霍夫曼与库尔提斯重排。** 霍夫曼重排中，伯酰胺用溴和碱处理：N-溴代、去质子化与溴离子的离去触发烷基从羰基碳向氮的迁移，生成**异氰酸酯**（$\mathrm{R{-}N{=}C{=}O}$）。库尔提斯重排中，酰基叠氮在温和加热下失去氮气，同样是协同迁移给异氰酸酯。异氰酸酯水解给出少一个碳的伯胺（经由氨基甲酸，后者失去 $\mathrm{CO_2}$），或被醇捕获为氨基甲酸酯（例如用叔丁醇直接给出 Boc 保护的胺）。两者都在迁移碳上**保持**构型。酰基叠氮与许多低分子量的有机叠氮化物有爆炸性；现代操作用叠氮磷酸二苯酯从酸在溶液中现生成它们，不经分离直接使用，在小规模或流动装置中进行，并先做风险评估。

::: example 贝克曼重排制己内酰胺 {#ex-beckmann}
环己酮肟在工业上转化为己内酰胺（ε-己内酰胺），即尼龙-6 的单体。描述机理并解释为什么环会扩大。
::: solution
(1) 在强酸中（经典工艺用发烟硫酸），肟的氧被质子化（或被磺化），把 OH 变成好的离去基团。(2) 环上与离去基团处于反位的 C–C 键在水离去的同时从碳迁移到氮：该环键的成键电子对移到氮上，N–O 键断裂、其电子随氧离去，生成一个环状**腈鎓离子**（含 $\mathrm{C{\equiv}N^+}$ 的七元环）。因为迁移的是环键，氮被插进环里，环从六个原子长到七个原子。(3) 水的孤对电子进攻腈鎓碳；失去质子给出亚氨酸（酰亚胺醇互变异构体）。(4) 互变异构（质子从 O 移到 N）给出酰胺，己内酰胺。对环己酮肟来说，环的两个碳是等价的，所以肟的几何构型无关紧要。这一工业过程年产量达数百万吨；它的主要缺点——中和酸时生成的硫酸铵——已促使发展在固体酸（沸石）催化剂上的气相工艺（[[green-chemistry/chemical-industry]]）。
:::
:::

### 法沃尔斯基重排

带 α′-氢的 α-卤代酮与醇盐或氢氧化物反应，给出重排后的酯或酸。2-氯环己-1-酮与甲醇钠反应，产物是环戊烷甲酸甲酯——一次**缩环**。用文字叙述：甲醇钠拿走 α′-质子（在羰基另一侧的 α-碳上），生成烯醇负离子；烯醇负离子碳在分子内从 α-碳上顶出氯离子，闭成张力很大的**环丙酮**；甲醇钠加到环丙酮的羰基上，给出质子化的四面体烷氧负离子；它重建 C=O 时断裂环丙烷的两根键之一——断裂的那根留下更稳定的碳负离子，后者立即被甲醇质子化。α-卤代酮是催泪剂并刺激皮肤，须在通风橱中操作。

## 卡宾、类卡宾与氮宾 {#sec-carbenes}

::: definition 卡宾与类卡宾 {#def-carbene}
**卡宾**是具有两个非键电子的二价碳的中性物种 $\mathrm{R_2C\colon}$。**单线态**卡宾的两个电子配对在一个类似 $sp^2$ 的轨道里，留下一个空 p 轨道（因此它既亲核又亲电，以协同步骤反应）；**三线态**卡宾的两个电子自旋未配对、分处不同轨道（双自由基行为，分步反应）。亚甲基 $\mathrm{CH_2}$ 的基态是三线态；带 π 给体取代基的卡宾（二卤代卡宾、N-杂环卡宾）基态是单线态。**类卡宾**是与金属结合、能在不生成自由卡宾的情况下转移一个"卡宾单元"的物种（西蒙斯-史密斯（Simmons–Smith）试剂 $\mathrm{ICH_2ZnI}$；由重氮化合物生成的铑(II)卡宾）。氮的类似物 $\mathrm{RN\colon}$ 是**氮宾**。
:::

**环丙烷化。** 单线态卡宾与类卡宾以一步协同过程加到烯烃上，因此加成是**立体专一的**——*cis*-烯烃给出 *cis*-二取代环丙烷——而三线态卡宾经由可旋转的双自由基分步加成，给出混合物（斯凯尔（Skell）判据，1956）。常用来源：**二氯卡宾**，来自氯仿与浓氢氧化钠水溶液在两相催化条件下（$\mathrm{CHCl_3}$ 去质子化，随后 $\mathrm{CCl_3^-}$ 失去氯离子，属 α-消除）；**西蒙斯-史密斯试剂**，由二碘甲烷与锌-铜偶或二乙基锌制备（古川（Furukawa）改良法）；以及**金属卡宾**，由重氮化合物如重氮乙酸乙酯在铑(II)或铜催化剂下生成。重氮化合物有毒且可能爆炸，重氮甲烷尤其是一种剧毒、可爆炸的气体；这类试剂只在专门条件下使用，或改用以（三甲基硅基）重氮甲烷为代表的安全替代物——它本身经吸入也急性中毒。

::: example 立体专一与定向的环丙烷化 {#ex-simmons-smith}
预测西蒙斯-史密斯试剂与 (a)（*Z*）-己-3-烯、(b) 环己-2-烯-1-醇反应的产物，并解释立体化学。
::: solution
(a) 锌类卡宾经由"蝴蝶"过渡态把 $\mathrm{CH_2}$ 同时送到烯烃的两个碳上：烯烃 π 电子进攻 $\mathrm{CH_2}$ 碳，同时 C–I 键断裂（碘离子移到锌上），C–Zn 键的电子形成第二根新的 C–C 键。两根键都在同一面生成，所以两个乙基的 *cis* 关系保持不变：***cis*-1,2-二乙基环丙烷**。

(b) 锌原子先与羟基氧配位，类卡宾被送到烯烃**与 OH 同一侧**的面上：产物主要是 ***cis*-双环[4.1.0]庚-2-醇**（环丙烷与羟基 *syn*），非对映选择性很高（西蒙斯（Simmons）与史密斯（Smith）；温斯坦（Winstein）的定向版本）。与钒和钛的环氧化一样，一个羟基能够把试剂引到自己身上（[[organic-synthesis/stereoselective-synthesis]]）。
:::
:::

**C–H 插入。** 铑(II)羧酸盐催化剂把重氮羰基化合物变成亲电的金属卡宾，后者插入 C–H 键，常常在分子内形成五元环，并在被官能团化的碳上保持构型（戴维斯（Davies）等发展了对映选择性的分子间版本）。

**沃尔夫重排。** α-重氮酮在加热、光照或银(I)存在下失去 $\mathrm{N_2}$，同时羰基碳上的基团协同迁移到原来的重氮碳，生成**烯酮**；烯酮加上水、醇或胺，给出羧酸、酯或酰胺。与由酰氯制备重氮酮相结合，它构成了**阿恩特-艾斯特特（Arndt–Eistert）同系化**（羧酸链增加一个碳），例如用来把 α-氨基酸在保持构型的情况下变成 β-氨基酸。环状重氮酮的缩环沃尔夫重排可用来制备张力环。

## 自由基作为合成工具 {#sec-radicals}

自由基反应有可与极性化学互补的优点：自由基不带电荷，所以溶剂对它们的影响很小；它们能容忍游离的 OH、NH 和许多其他官能团；它们在位阻的、叔的中心上反应自如，而这些正是 $\mathrm{S_N2}$ 的差底物；它们对烯烃的分子内加成成环很快，即使成环生成的是季碳。它们的反应性靠**链反应**来控制：把自由基浓度保持得极低，使自由基-自由基的终止很少发生，让每个自由基与非自由基分子反应生成新的自由基。

### 锡烷化学与自由基链

经典体系用三丁基氢化锡 $\mathrm{Bu_3SnH}$，加少量引发剂（偶氮二异丁腈，AIBN，受热失去 $\mathrm{N_2}$ 生成 2-氰基丙-2-基自由基）。把卤代烷 RBr 还原为 RH 时：

1. **引发。** 引发剂自由基从 $\mathrm{Bu_3Sn{-}H}$ 上夺取氢原子（弱 Sn–H 键，约 $310\ \mathrm{kJ\,mol^{-1}}$，均裂，两个碎片各得一个电子），生成三丁基锡自由基 $\mathrm{Bu_3Sn^\bullet}$。
2. **传递，第 1 步。** $\mathrm{Bu_3Sn^\bullet}$ 从 RBr 上夺取溴原子：C–Br 键均裂，一个电子与锡自由基的单电子配成 Sn–Br 键，另一个留在碳上，生成烷基自由基 $\mathrm{R^\bullet}$。
3. **传递，第 2 步。** $\mathrm{R^\bullet}$ 从 $\mathrm{Bu_3SnH}$ 夺取氢原子，生成 R–H 并再生 $\mathrm{Bu_3Sn^\bullet}$，链得以继续。
4. **终止。** 偶尔两个自由基互相结合。

同一条链也能除去其他基团：在**巴顿-麦克孔比（Barton–McCombie）脱氧**（巴顿（Barton）与麦克孔比（McCombie），1975）中，醇先变成硫代羰基衍生物（黄原酸酯或硫代羰基咪唑酯）；锡自由基加到硫上，C–O 键碎裂给出烷基自由基与一个稳定的羰基化合物，烷基自由基再由 $\mathrm{Bu_3SnH}$ 还原。有机锡化合物有毒，且残留的锡难以从产物中除去，因此如今更常用硅烷（三(三甲基硅基)硅烷，TTMSS）、催化量锡加化学计量的硼氢化物，以及**光氧化还原催化**（自 2008 年起，用吸收可见光的钌、铱配合物或有机染料转移单电子，由麦克米伦（MacMillan）、尤恩（Yoon）、斯蒂芬森（Stephenson）等发展）。

### 自由基环化及其动力学

如果自由基 $\mathrm{R^\bullet}$ 内部带有一个位置合适的烯烃，它可以在碰到一个锡烷分子之前先完成分子内加成。己-5-烯-1-基自由基环化很快，而且几乎只按 **5-*exo*-trig** 方式进行——生成五元环、把自由基留在环外，得环戊基甲基自由基——而不是 6-*endo*-trig 生成环己基自由基（约 98:2），尽管环己基自由基其实更稳定。这一偏好源于立体电子效应：自由基必须以约 $107^\circ$ 的角度进攻烯烃碳（就像亲核试剂进攻 C=O 那样），五个原子的链带更容易对较近的碳达到这个进攻角（贝克维斯（Beckwith）的准则，1970–80 年代，与鲍德温（Baldwin）1976 年针对极性成环的规则平行）。

::: proposition 环化与还原的竞争 {#prop-clock}
设自由基 $\mathrm{R^\bullet}$ 或者环化（一级速率常数 $k_\mathrm{c}$），或者被 $\mathrm{Bu_3SnH}$ 还原（二级速率常数 $k_\mathrm{H}$）。若锡烷的浓度实际上恒定（拟一级条件，或缓慢滴加锡烷），环化产物与未环化产物之比为
$$
\frac{[\text{环化产物}]}{[\text{未环化产物}]} = \frac{k_\mathrm{c}}{k_\mathrm{H}[\mathrm{Bu_3SnH}]}.
$$ {#eq-clock}
若 $k_\mathrm{c}$ 已知（**自由基钟**），测定比值就给出 $k_\mathrm{H}$，反之亦然。
:::

::: proof
每个生成的 $\mathrm{R^\bullet}$ 有两种结局；它环化的概率是 $k_\mathrm{c}/(k_\mathrm{c} + k_\mathrm{H}[\mathrm{Bu_3SnH}])$，被还原的概率是 $k_\mathrm{H}[\mathrm{Bu_3SnH}]/(k_\mathrm{c} + k_\mathrm{H}[\mathrm{Bu_3SnH}])$，与该自由基此前的经历无关。（环化后的自由基随后也会被还原，但这不改变分支比。）两个概率之比即[[#eq-clock]]。当反应过程中 $[\mathrm{Bu_3SnH}]$ 发生变化时，每一时刻的比值由瞬时浓度给出，总比值由积分得到。$\blacksquare$
:::

对 $25\ ^\circ\mathrm{C}$ 的己-5-烯基自由基，$k_\mathrm{c} = 2.3\times10^{5}\ \mathrm{s^{-1}}$，$\mathrm{Bu_3SnH}$ 向伯烷基自由基转移氢原子的速率常数为 $k_\mathrm{H} = 2.4\times10^{6}\ \mathrm{dm^3\,mol^{-1}\,s^{-1}}$（查特吉利亚洛格鲁（Chatgilialoglu）、英戈尔德（Ingold）与斯卡亚诺（Scaiano），1981）。因此只有当 $[\mathrm{Bu_3SnH}]$ 远低于 $k_\mathrm{c}/k_\mathrm{H} \approx 0.1\ \mathrm{mol\,dm^{-3}}$ 时环化才占优势。

::: example 规划一次自由基环化 {#ex-cyclisation}
6-溴己-1-烯用 $\mathrm{Bu_3SnH}$ 与 AIBN 处理。预测锡烷浓度分别保持在 (a) $0.10$ 与 (b) $0.010\ \mathrm{mol\,dm^{-3}}$ 时的两个主产物及其比值（速率常数取上面 25 °C 的数据）。要得到 95 % 以上的环化，你会怎么做？
::: solution
锡基自由基攫取 Br，给己-5-烯-1-基自由基。它或者从 $\mathrm{Bu_3SnH}$ 夺 H（给**己-1-烯**），或者按 5-*exo* 环化（自由基碳加到烯烃的 C5 上；π 键的一个电子与自由基的单电子配成新的 C–C 键，另一个电子留在 C6 上，成为环外的伯自由基），生成环戊基甲基自由基，后者被还原为**甲基环戊烷**。

(a) 比值 $= 2.3\times10^{5}/(2.4\times10^{6} \times 0.10) = 0.96$：约 49 % 甲基环戊烷，51 % 己-1-烯。

(b) 比值 $= 2.3\times10^{5}/(2.4\times10^{6} \times 0.010) = 9.6$：约 91 % 甲基环戊烷。

要超过 95 %（比值大于 19），$[\mathrm{Bu_3SnH}] < 2.3\times10^{5}/(19 \times 2.4\times10^{6}) = 5.0\times10^{-3}\ \mathrm{mol\,dm^{-3}}$：用注射泵把锡烷缓慢加到溴化物的稀溶液里，或者用催化量的 $\mathrm{Bu_3SnCl}$ 加化学计量还原剂氰基硼氢化钠，后者使锡烷浓度全程保持低位。（两种结局之比与溴化物的浓度无关，因为两步都发生在同一个自由基生成之后。）
:::
:::

自由基环化在**级联**反应中最见功力。柯伦（Curran）1985 年对三环倍半萜 hirsutene 的合成，在一次串联自由基环化中闭合了两个五元环：一个伯自由基先按 5-*exo* 环化到一个烯烃上，新生成的自由基再按 5-*exo* 环化到一个炔烃上，给出乙烯基自由基，被锡烷还原。这一级联在一个操作里建成了线形并环的三环骨架，相对立体化学正确。自由基也会分子间加到缺电子烯烃上（**吉斯（Giese）反应**）；原子转移自由基加成与环化则用卤原子转移而非氢转移来传递链条。

::: algorithm 经由活泼中间体设计反应 {#alg-intermediate}
1. **确定中间体**：判断条件将生成什么（酸加醇或烯烃生成碳正离子；重氮化合物或 α-消除生成卡宾；卤代物、黄原酸酯或光氧化还原步骤生成自由基）。
2. **列出它可能的结局**：阳离子——1,2-迁移、消除、被亲核试剂捕获；卡宾——环丙烷化、插入、沃尔夫重排；自由基——环化、碎裂、原子转移、还原。
3. **估计相对速率**，利用已知的钟与选择性规则（阳离子的稳定性与迁移倾向，[[#prop-shift-stereo]]；5-*exo* 优先于 6-*endo*；[[#prop-clock]]）。
4. **调节条件**以偏向想要的结局：捕获剂的浓度、温度、路易斯酸、催化剂。
5. **检查立体化学**：迁移基团的构型保持、反式共平面排列、卡宾加成的立体专一性，以及自由基环化的椅式过渡态。
6. **评估前体（重氮化合物、叠氮化物、有机锡试剂）的危险性**，选择最安全的等价方案。
:::

::: quiz
苯乙酮的 (*E*)-肟（苯基与 OH 互为反位）发生贝克曼重排，产物是什么？
- [x] $N$-苯基乙酰胺（乙酰苯胺），$\mathrm{CH_3CONHPh}$
- [ ] $N$-甲基苯甲酰胺，$\mathrm{PhCONHCH_3}$
- [ ] 苯甲腈与甲醇
- [ ] 只有苯乙酮与羟胺
::: solution
与正在离去的离去基团互为反位的基团迁移到氮上（[[#prop-shift-stereo]]）。在 (*E*)-肟中苯基与 OH 反位，所以苯基迁移：腈鎓离子 $\mathrm{CH_3C{\equiv}N^+Ph}$ 被水进攻并互变异构为乙酰苯胺。甲基迁移会给出 $N$-甲基苯甲酰胺，那要从 (*Z*)-肟才能得到。水解回到酮在含水酸中可以与之竞争，但那不是重排产物。
:::
:::

::: warning 碳正离子不管你要不要都会重排 {#warn-rearrange}
只要一个反应经过碳正离子，就要问 1,2-迁移能否给出更稳定的阳离子。3,3-二甲基丁-1-烯的酸催化水合主要给出 2,3-二甲基丁-2-醇，而不是 3,3-二甲基丁-2-醇，因为二级阳离子在水进攻之前先发生了甲基迁移变成叔阳离子。苯与 1-氯丙烷的傅-克烷基化主要给异丙苯（枯烯）。新戊基体系的电离与甲基迁移同时发生。合成上的对策是：在重排有害的地方避免游离阳离子——改用 $\mathrm{S_N2}$ 条件、用傅-克酰基化再还原代替烷基化、用羟汞化与硼氢化-氧化代替酸催化水合；或者反其道而行之，把底物设计成让你想要的重排成为最快的路径。
:::

::: history
鲁道夫·菲蒂希（Rudolf Fittig）在 1860 年观察到频哪醇转化为频哪酮；格奥尔格·瓦格纳（Georg Wagner，1899）与汉斯·米尔魏因（Hans Meerwein，1914–1922）解释了萜类的骨架重排；米尔魏因对樟莰盐酸盐重排中碳正离子中间体的提议（1922）是物理有机化学的奠基思想之一。恩斯特·奥托·贝克曼（Ernst Otto Beckmann）于 1886 年发现了贝克曼重排，奥古斯特·威廉·冯·霍夫曼（August Wilhelm von Hofmann）于 1881 年发现了霍夫曼重排，特奥多尔·库尔提斯（Theodor Curtius）于 1890 年发现了库尔提斯重排，路德维希·沃尔夫（Ludwig Wolff）于 1902 年、阿列克谢·法沃尔斯基（Alexei Favorskii）于 1894 年分别发现了各自的重排。霍华德·西蒙斯（Howard Simmons）与罗纳德·史密斯（Ronald Smith）于 1958 年报道了锌类卡宾环丙烷化，威廉·冯·埃格斯·杜林（William von Eggers Doering）与菲利普·斯凯尔（Philip Skell）在 1950 年代弄清了卡宾的自旋与立体化学。摩西·戈姆伯格（Moses Gomberg）的三苯甲基自由基（1900）证明了碳自由基的存在；锡烷自由基链的合成应用自 1960 年代兴起（亨利·奎维拉（Henry Kuivila）），并因阿瑟尔斯坦·贝克维斯（Athelstan Beckwith）的环化研究、基思·英戈尔德（Keith Ingold）的绝对速率常数和德里克·巴顿（Derek Barton）的脱氧（1975）而变得可以预测。丹尼斯·柯伦（Dennis Curran）的串联自由基环化（1985）与吉伯特·斯特克（Gilbert Stork）的乙烯基自由基环化表明，自由基能够建成复杂的多环天然产物。
:::

## 后续内容

阳离子环化与重排是萜类与甾体的生物合成和实验室合成的核心，多烯环化的案例研究见[[organic-synthesis/total-synthesis]]。自由基钟及其背后的动力学方法在[[kinetics/chain-reactions]]，自由基聚合在[[polymer-chemistry/radical-polymerisation]]，金属卡宾在[[organometallics-catalysis/metathesis-polymerisation]]。拜耳-维利格氧化作为贝克曼重排"向氧"的对应物，已在[[organic-synthesis/redox-in-synthesis]]中讲过。

::: summary
- 1,2-迁移中，基团带着它的电子对迁往相邻的缺电子中心；迁移的是与离去基团反式共平面的那个基团，且它保持自己的构型。
- 频哪醇重排：先生成更稳定的阳离子，再让相邻基团迁移，得到羰基；环状版本（半频哪醇、蒂芬诺-杰米扬诺夫）扩大或缩小环。
- 向氮的迁移：贝克曼（肟 → 酰胺；反位基团迁移；己内酰胺）、霍夫曼与库尔提斯（酰胺或酰基叠氮 → 异氰酸酯 → 少一个碳的胺，构型保持）；法沃尔斯基（α-卤代酮 → 经环丙酮得酯；缩环）。
- 单线态卡宾与类卡宾（西蒙斯-史密斯、铑(II)卡宾）立体专一地环丙烷化，并可被 OH 定向；沃尔夫重排给出烯酮（阿恩特-艾斯特特同系化）。重氮化合物与叠氮化物是重大危险源。
- 自由基链（引发、传递、终止）用 $\mathrm{Bu_3SnH}$ 或更安全的替代品还原卤代物与黄原酸酯，并完成 5-*exo*-trig 环化。
- 环化 : 未环化 $= k_\mathrm{c}/(k_\mathrm{H}[\mathrm{Bu_3SnH}])$；对己-5-烯基（$k_\mathrm{c} = 2.3\times10^{5}\ \mathrm{s^{-1}}$），要把 $[\mathrm{Bu_3SnH}]$ 保持在约 $5\times10^{-3}\ \mathrm{mol\,dm^{-3}}$ 以下才能得到 95 % 环化。
:::

::: exercise 苯频哪醇 {level=1}
预测 1,1,2,2-四苯基乙烷-1,2-二醇（苯频哪醇）用酸处理的产物，并描述关键步骤。
::: solution
任一 OH 质子化并失水，都给出被两个苯环稳定的三苯基取代碳正离子 $\mathrm{Ph_2C^+{-}C(OH)Ph_2}$。相邻碳上的一个苯基带着它的成键电子对迁移到阳离子碳上；正电荷移到 带羟基碳上并被氧的孤对电子稳定；失去质子给出 **1,2,2,2-四苯基乙-1-酮**（苯频哪酮，$\mathrm{Ph_3C{-}CO{-}Ph}$）。

::: exercise 贝克曼重排与一种药物 {level=1}
1-(4-羟基苯基)乙-1-酮的 (*E*)-肟（芳基与 OH 反位）发生贝克曼重排。产物是什么？
::: solution
与 OH 反位的芳基迁移到氮上，给出 $N$-(4-羟基苯基)乙酰胺——**对乙酰氨基酚（扑热息痛）**。这条贝克曼路线（赫斯特-赛拉尼斯）是 4-氨基苯酚乙酰化法的工业替代路线（[[organic-synthesis/retrosynthesis#ex-paracetamol]]）。

::: exercise 达到 95 % 环化所需的氢化物浓度 {level=2 check="0.0050"}
能使 $25\ ^\circ\mathrm{C}$ 己-5-烯基自由基环化至少达 $95\,\%$ 的恒定 $\mathrm{Bu_3SnH}$ 浓度上限是多少？（浓度以 $\mathrm{mol\,dm^{-3}}$ 输入，保留两位有效数字。）
::: solution
环化 $95\,\%$ 意味着比值为 $95/5 = 19$：$[\mathrm{Bu_3SnH}] = k_\mathrm{c}/(19k_\mathrm{H}) = 2.3\times10^{5}/(19 \times 2.4\times10^{6}) = 5.0\times10^{-3}\ \mathrm{mol\,dm^{-3}}$（[[#ex-cyclisation]]）。

::: exercise 立体专一的环丙烷化 {level=2}
预测 (a)（*E*）-丁-2-烯与二氯卡宾（来自 $\mathrm{CHCl_3}$、NaOH、相转移催化剂）以及 (b)（*Z*）-丁-2-烯与气相光化学生成的三线态亚甲基的反应产物。解释立体化学的差别。
::: solution
(a) 二氯卡宾基态是单线态；它以一步协同过程从同一面加到两个碳上，保持烯烃几何：***trans*-1,1-二氯-2,3-二甲基环丙烷**（外消旋）。(b) 三线态卡宾先加到一个碳上，生成 1,3-双自由基，其两个未成对电子自旋平行，无法立即配成第二根键；在自旋反转允许闭环之前，原来的 C=C 键已经发生旋转，于是 *cis*- 与 *trans*-1,2-二甲基环丙烷的混合物生成。立体专一性是斯凯尔判断单线态与三线态卡宾的试金石。
:::

::: exercise 法沃尔斯基缩环 {level=2}
给出 2-氯环己-1-酮在甲醇中的甲醇钠作用下转化为环戊烷甲酸甲酯的机理，命名每一处电子移动。
::: solution
(1) 甲醇钠拿走 C6（α′-碳）上的质子，C–H 电子形成烯醇负离子的 C=C（C1=C6），负电荷在氧上。(2) 烯醇负离子的 C6 从背面进攻 C2，C2–Cl 键断裂、氯离子离去，闭成与五元环并环的环丙酮（双环[3.1.0]己-6-酮）。(3) 甲醇氧的孤对电子进攻张力的环丙酮羰基碳，π 电子移到氧上。(4) 烷氧负离子的孤对电子重建 C=O，原来羰基碳的两根环丙烷键之一断裂，电子归碳成为碳负离子（这里两根键是等价的）；碳负离子被甲醇质子化。环失去一个碳进入酯：**环戊烷甲酸甲酯**。
:::

::: exercise 计入氢化物消耗时导出钟方程 {level=3}
一次自由基环化的初始锡烷浓度为 $[\mathrm{H}]_0$，底物浓度 $[\mathrm{S}]_0 = [\mathrm{H}]_0$，反应进行中氢化物被消耗（每个产物分子消耗一个）。证明 $\mathrm{d}U/\mathrm{d}C = k_\mathrm{H}[\mathrm{H}]/k_\mathrm{c}$，其中 $U$ 与 $C$ 是未环化与环化产物的浓度，并定性解释为什么总体比值 $C/U$ 大于 $k_\mathrm{c}/(k_\mathrm{H}[\mathrm{H}]_0)$。
::: hint
每个自由基有两个竞争的结局；两种产物都消耗一个氢化物。
:::
::: solution
在任一时刻，自由基以某个速率 $v$ 生成，每个自由基以概率 $p_\mathrm{c} = k_\mathrm{c}/(k_\mathrm{c} + k_\mathrm{H}[\mathrm{H}])$ 环化，以概率 $1 - p_\mathrm{c}$ 被直接还原（稳态自由基浓度被约去）。于是 $\mathrm{d}C/\mathrm{d}t = vp_\mathrm{c}$，$\mathrm{d}U/\mathrm{d}t = v(1 - p_\mathrm{c})$，得 $\mathrm{d}U/\mathrm{d}C = (1 - p_\mathrm{c})/p_\mathrm{c} = k_\mathrm{H}[\mathrm{H}]/k_\mathrm{c}$。由于 $[\mathrm{H}] = [\mathrm{H}]_0 - (C + U)$ 随反应进行而下降，$\mathrm{d}U/\mathrm{d}C$ 递减，反应后期有更大分数的自由基发生环化。因此积分得到的比值超过初始值 $k_\mathrm{c}/(k_\mathrm{H}[\mathrm{H}]_0)$；精确的速率测量要么让氢化物大量过量（使 $[\mathrm{H}] \approx [\mathrm{H}]_0$），要么把表达式严格积分。这就是用"自由基钟"校准速率常数的道理（贝克维斯、英戈尔德）。
:::
:::

::: exercise 用库尔提斯重排制胺 {level=3}
把（*S*）-2-甲基丁酸转化为（*S*）-丁-2-胺。解释为什么构型保持，指出主要的危险，以及现代操作如何管理它。
::: hint
立体中心就是发生迁移的那个碳。
:::
::: solution
**序列。** (1) 酸与叠氮磷酸二苯酯和三乙胺反应（羧酸根进攻磷，把叠氮顶出来；叠氮随后进攻活化的酰基碳，把二苯基磷酸顶出去），在溶液中生成酰基叠氮。(2) 温和加热：酰基叠氮失去 $\mathrm{N_2}$——与离去氮分子的 N–N 键断裂、其电子归剩下的氮，同时 *sec*-丁基带着它的成键电子对从羰基碳迁移到那个氮上——一步协同完成，给（*S*）-2-异氰酸酯基丁烷。(3) 用叔丁醇捕获异氰酸酯（醇氧进攻异氰酸酯碳）得 Boc 保护的胺，再用酸除去 Boc（[[organic-synthesis/protecting-groups]]）；或者直接用水酸水解异氰酸酯（经由氨基甲酸，后者失去 $\mathrm{CO_2}$）。产物：（*S*）-丁-2-胺。**构型保持**：迁移碳从不变成游离状态；它带着成键电子对从一个面迁移过去（[[#prop-shift-stereo]]），所以它另外三个取代基的空间排布不变。CIP 描述符保持 *S*，因为优先次序（N > 乙基 > 甲基 > H，取代原来的 C(=O) > 乙基 > 甲基 > H）不变。**危险性**：酰基叠氮有潜在爆炸性，而酸中可能生成的叠氮酸剧毒且可爆炸；现代操作从不分离酰基叠氮，使其保持在稀溶液中，在小规模或连续流动装置中进行（任一时刻存量很小），并遵循书面的风险评估。
:::

::: exercise 蒂芬诺-杰米扬诺夫反应的扩环 {level=3}
1-(氨甲基)环己-1-醇与亚硝酸（由亚硝酸钠与含水酸在 0 °C 制备）反应给环庚酮。提出机理，并解释为什么迁移的是环键，而不是羟基离去。
::: solution
(1) 亚硝酸生成亚硝鎓离子 $\mathrm{NO^+}$；伯胺的孤对电子进攻它，经质子转移和失水后生成伯**重氮离子** $\mathrm{R{-}CH_2{-}N_2^+}$。(2) 二氮是极好的离去基团，从 $\mathrm{CH_2}$ 碳上离去；与其离去协同，相邻 带羟基碳上的一根环 C–C 键（与 C–N 键反式共平面）带着它的电子对迁移到 $\mathrm{CH_2}$ 碳上，避免了伯碳正离子。环中如今有七个碳，正电荷落在原来的 带羟基碳上，被羟基氧的孤对电子稳定为质子化的酮。(3) 失去质子给出**环庚酮**。羟基没有离去，因为缺电子中心生成在*相邻*的碳上；OH 扮演的是使迁移有利的"推动"角色（半频哪醇模式），C=O 的生成驱动了反应。亚硝酸分解为有毒的氮氧化物，重氮盐不得分离；反应要在低温、溶液中、通风橱内进行。
:::
