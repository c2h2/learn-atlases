上一章我们遇到了一个任何试剂选择都解决不了的问题：4-乙酰基苯甲酸甲酯不能只把酯还原而让酮完好无损，因为任何能进攻酯的氢化物都会更快地进攻酮。只要一个分子含有两个相似的官能团，而我们要转化其中一个却不动另一个，同样的困难就会出现——一个氨基酸要在活化其酸的同时不让它的胺反应，一个糖有五个羟基而只氧化其中一个，一个格氏试剂遇到同一分子中任何 O–H 或 N–H 都会自毁。一般的解决办法是把必须幸存的基团**保护**起来：暂时把它变成一个对所到来反应条件惰性的衍生物，完成所需的转化，然后再**脱保护**恢复原来的基团。

保护基是合成中最具实用价值、也最不起眼的工具之一。每一次保护都要花费两步（上与下），每一步的产率都低于 100 %，还增加分子量、试剂和废物。因此，一个好的合成计划要尽量少用保护基，并且挑选得使每一个都能在不动其余保护基的条件下被除去。本章概览醇、二醇、羰基化合物、胺和羧酸的主要保护基，逐一解释每次安装与除去的机理，对选择性作定量讨论，并展开核心思想——**正交保护**，正是这条设计原理使肽合成、寡糖合成和大多数长线全合成成为可能。

## 保护基必须满足的条件 {#sec-criteria}

::: definition 保护基 {#def-pg}
**保护基**（PG）是暂时连到某个官能团上、使该官能团对本无法耐受的反应条件不再活泼、并在稍后除去以再生原官能团的基团。一个有用的保护基应当：(1) 能有选择地、以高产率、用易得的试剂引入；(2) 对期间必须经受的一切条件都稳定；(3) 能有选择地、以高产率、在不影响分子其余部分的条件下被除去；(4) 不引入新的立体中心（或者该立体中心无所谓）；(5) 除去后易于与产物分离；并且理想情况下 (6) 廉价且产生的废物少。
:::

::: definition 正交保护基 {#def-orthogonal}
如果一组保护基中的每一个都能在不动其他任何成员的条件下、按任意次序用各自的一套条件除去，则这组保护基是**正交**的。靠同一类条件以不同速率除去的基团（例如两个都能被酸断裂的硅醚）不是正交的，而是**分级**的（graduated）：它们只能按某一种次序、并且只能靠控制时间和条件来有选择地除去（[[#prop-selective]]）。
:::

打开保护基的四把主要"钥匙"是**酸**、**碱或亲核试剂**、**氟离子**（对付硅）以及**还原或氧化**（氢解、Pd(0)、单电子氧化剂）。由不同钥匙打开的基团通常彼此正交。

## 醇的保护 {#sec-alcohols}

### 硅醚

硅醚 $\mathrm{R{-}O{-}SiR'_3}$ 是使用最广的一类醇保护基。它们由醇与硅烷基氯化物（或更活泼的硅烷基三氟甲磺酸酯）在碱存在下制得。叔丁基二甲基氯硅烷（TBSCl，也写作 TBDMS 氯化物）是科里（Corey）与文卡泰什瓦鲁（Venkateswarlu）1972 年确立的条件：DMF 中的咪唑。用文字叙述：咪唑氮的孤对电子进攻硅，把氯离子顶出去，生成活泼的硅基咪唑鎓离子；随后醇氧的孤对电子进攻硅，Si–N 键断裂、其电子回到咪唑上；第二个咪唑把 O–H 质子拿走。尽管基团体积很大，硅上的取代仍然很快，因为硅比碳大，能够在三方双锥形的过渡态或中间体中容纳五个基团。

硅上烷基的大小既控制醚形成的难易，也控制其断裂的难易。

| 硅基 | 缩写 | 对酸的相对稳定性 | 对碱的相对稳定性 |
|---|---|---|---|
| 三甲基硅基 | TMS | 1 | 1 |
| 三乙基硅基 | TES | 64 | 10–100 |
| 叔丁基二甲基硅基 | TBS (TBDMS) | 20 000 | ~20 000 |
| 三异丙基硅基 | TIPS | 700 000 | 100 000 |
| 叔丁基二苯基硅基 | TBDPS | 5 000 000 | ~20 000 |

（相对水解速率的近似值，取倒数即得稳定性，汇编于格林（Greene）的《有机合成中的保护基》（*Protective Groups in Organic Synthesis*）。）TMS 醚对多数用途而言太不稳定；TBS 是常备主力；TIPS 和 TBDPS 能熬过会除去 TBS 的条件。体积还带来**保护的位置选择性**：TBSCl，以及更甚的 TBDPSCl 与三苯甲基氯（trityl 氯化物），与伯醇的反应快于仲醇。

**氟离子除去。** 硅醚能被氟离子断裂——THF 中的四丁基氟化铵（TBAF），或 HF–吡啶。氟离子的孤对电子进攻硅，生成五配位的氟硅酸盐阴离子；随后 Si–O 键断裂，其电子带着成为烷氧负离子的氧离去，在后处理中被质子化。推动力是 Si–F 键的强度（平均键焓约 $565\ \mathrm{kJ\,mol^{-1}}$，而 Si–O 约为 $450\ \mathrm{kJ\,mol^{-1}}$）。由于氟离子是其他任何常用保护基都不用的钥匙，硅醚与多数其他基团正交。但 TBAF 具有碱性，会使敏感底物发生消除或酰基迁移；用乙酸加以缓冲会有帮助。

::: example 有选择地保护伯醇 {#ex-tbs}
丁烷-1,3-二醇有一个伯羟基和一个仲羟基。如何只保护伯羟基，随后如何把仲醇氧化成酮而不影响被保护的一端？
::: solution
**保护。** 一当量 TBSCl，咪唑，DMF（或二氯甲烷），0 °C 至室温。伯 OH 位阻较小，进攻硅基咪唑鎓离子更快；产物是 4-（叔丁基二甲基硅氧基）丁-2-醇，$\mathrm{TBSO{-}CH_2CH_2CH(OH)CH_3}$，伴有少量双硅醚（用色谱分离）。要更高的选择性，用体积更大的 TBDPSCl 或三苯甲基氯，它们与仲醇的反应慢得多。

**氧化。** Swern 或 Dess–Martin 氧化（[[organic-synthesis/redox-in-synthesis]]）把仲醇转化为酮；两者都不碰硅醚。避免 Jones 试剂，其含水硫酸会断裂伯醇的 TBS 醚。用 TBAF/THF **脱保护**即得 4-羟基丁-2-酮。
:::
:::

::: proposition 分级保护基的选择性除去 {#prop-selective}
设有两个被保护的基团 A 与 B 在同一条件下按拟一级过程断裂，速率常数 $k_\mathrm{A} > k_\mathrm{B}$。当 A 还剩下分数 $f_\mathrm{A}$ 时，B 的剩余分数为
$$
f_\mathrm{B} = f_\mathrm{A}^{\,k_\mathrm{B}/k_\mathrm{A}}.
$$ {#eq-selective}
特别地，要在至多只损失 $1\,\%$ 的 B 的情况下除去 $99\,\%$ 的 A（$f_\mathrm{A} = 0.01$），需要 $k_\mathrm{A}/k_\mathrm{B} \geq \ln 0.01/\ln 0.99 \approx 460$。
:::

::: proof
一级动力学给出同一时刻 $t$ 有 $f_\mathrm{A} = e^{-k_\mathrm{A}t}$ 与 $f_\mathrm{B} = e^{-k_\mathrm{B}t}$。消去 $t = -\ln f_\mathrm{A}/k_\mathrm{A}$ 得 $\ln f_\mathrm{B} = (k_\mathrm{B}/k_\mathrm{A})\ln f_\mathrm{A}$，即[[#eq-selective]]。对于数值条件，$f_\mathrm{B} \geq 0.99$ 要求 $(k_\mathrm{B}/k_\mathrm{A})\ln 0.01 \geq \ln 0.99$，即 $k_\mathrm{A}/k_\mathrm{B} \geq \ln 0.01/\ln 0.99 = 4.605/0.01005 = 458$。$\blacksquare$
:::

labels: \text{较快断裂的基团 A}; \text{较慢断裂的基团 B}
caption: 同一断裂条件下两种硅醚的剩余分数对 $k_\mathrm{A}t$ 的曲线，选择性 $s = k_\mathrm{A}/k_\mathrm{B}$（[[#eq-selective]]）。默认 $s = 312$ 是 TBS 与 TES 耐酸稳定性数字之比（$20\,000/64$）：当 $99\,\%$ 的 TES 醚已除去（$k_\mathrm{A}t = 4.6$）时，还有 $98.5\,\%$ 的 TBS 醚剩余。把 $s$ 降到 10 或 20——两个环境略有不同的仲 TBS 醚之间就是这种量级的差别——任何反应时间都给不出干净的结果。分级选择性只在速率比达到几百倍时才可行。
:::

::: example 在 TBS 存在下除去 TES {#ex-tes-tbs}
一个分子上有一个 TES 醚和一个 TBS 醚，都连在仲醇上。利用表中的耐酸相对稳定性，温和酸处理除去 $99\,\%$ 的 TES 醚后，TBS 醚能剩下多大分数？更可靠的方案是什么？
::: solution
速率比为 $k_\mathrm{TES}/k_\mathrm{TBS} = 20\,000/64 = 312$。由[[#eq-selective]]，$f_\mathrm{TBS} = 0.01^{1/312} = e^{-4.605/312} = e^{-0.01476} = 0.985$：$98.5\,\%$ 保留。这不错，但它依赖于两个醇的位阻相近；表中的比值是平均值，环境可以使其偏移一个数量级。这类分级除去确实在常用（例如甲醇中的吡啶鎓对甲苯磺酸盐，或稀乙酸），但一对**正交**的组合——例如 TBS 醚与苄基醚，分别用氟离子和氢解除去——根本不依赖速率比。
:::
:::

### 苄基及相关醚

**苄基醚**（$\mathrm{ROCH_2Ph}$，Bn）由威廉姆逊反应制备：氢化钠使醇去质子化（H⁻ 拿走质子，放出 $\mathrm{H_2}$），烷氧负离子的孤对电子在 $\mathrm{S_N2}$ 反应中进攻溴化苄的苄位碳，把溴离子顶出去。苄基醚能耐强碱、亲核试剂、氢化物、多数氧化剂和中等强度的酸；它们靠**氢解**（$\mathrm{H_2}$，Pd/C）除去，后者断裂苄位 C–O 键，给出醇和甲苯。**4-甲氧基苄基**（PMB）醚还可以用 2,3-二氯-5,6-二氰基-1,4-苯醌（DDQ）**氧化**除去：富电子芳环向 DDQ 转移一个电子，所得自由基阳离子失去一个苄性质子和第二个电子，生成被甲氧基稳定的氧碳鎓离子，水加成后生成半缩醛，后者碎解为醇和 4-甲氧基苯甲醛。普通苄基醚与 DDQ 的反应慢得多，因此 PMB 可以在 Bn 存在下被除去。

### 缩醛与酯

**缩醛型醚**——四氢吡喃基醚（THP，来自 3,4-二氢-2*H*-吡喃与酸催化）、甲氧基甲基醚（MOM）与 2-（三甲基硅基）乙氧基甲基醚（SEM）——对碱、亲核试剂和氢化物稳定，由含水酸除去。THP 会引入一个新的立体中心（缩醛碳），因此手性醇给出非对映体混合物，使 NMR 谱复杂化。氯甲基甲基醚是经典的 MOM 试剂，为已知的人类致癌物；MOM 醚如今常改用其他方法制备，如与二甲氧基甲烷进行缩醛交换。

**酯**——乙酸酯（Ac）、苯甲酸酯（Bz）、特戊酸酯（Piv，$\mathrm{(CH_3)_3CCO}$）——用酸酐或酰氯与碱（吡啶，常加催化量的 4-（二甲氨基）吡啶，DMAP）制备，用碱（甲醇中的碳酸钾，或氢氧化物）除去。它们对酸和氧化剂稳定，但对氢化物或有机金属试剂不稳定。体积大的特戊酸酯远比乙酸酯抗水解。

### 二醇

1,2-与 1,3-二醇以环缩醛的形式一起保护。**丙酮缩酮**（异亚丙基缩酮，来自丙酮或 2,2-二甲氧基丙烷加酸）偏爱 1,2-二醇，生成五元 1,3-二氧戊环：若形成六元 1,3-二氧六环，两个甲基中必有一个要处在直立键上，产生严重的 1,3-二直立相互作用。**苄叉缩醛**（来自苯甲醛）偏爱 1,3-二醇与六元 1,3-二氧六环，其中唯一的苯基占据平伏键。苄叉缩醛可以**还原性**且区域选择性地开环（DIBAL-H，或 $\mathrm{NaBH_3CN}$ 加 HCl），在一个氧上留下苄基醚、另一个氧上留下游离 OH——这是区分两个羟基的一条途径。

## 羰基的保护 {#sec-carbonyl}

醛和酮以**缩醛**保护，最常用的是来自乙烷-1,2-二醇的环状 1,3-二氧戊环；它对碱、亲核试剂、有机金属试剂、氢化物和多数氧化剂稳定，用含水酸除去。

::: example 保护酮以便还原酯 {#ex-acetal}
说明如何把 4-乙酰基苯甲酸甲酯转化为 1-[4-（羟甲基）苯基]乙-1-酮，并逐步描述缩醛形成的机理。
::: solution
**计划。** (1) 乙烷-1,2-二醇，催化量对甲苯磺酸，甲苯，加热并用 Dean–Stark 分水器除水：酮变成它的 2-甲基-1,3-二氧戊环；酯不受影响。(2) $\mathrm{LiAlH_4}$ 的 THF 溶液把酯还原为伯醇；缩醛没有亲电碳，不反应。(3) 含水酸（丙酮或 THF 中的稀 HCl）水解缩醛，再生酮。

**缩醛形成的机理。** (a) 酸把羰基氧气化（用其一对孤对电子），生成氧碳鎓型阳离子。(b) 二醇的一个羟基氧用孤对电子进攻羰基碳；C=O 的 π 电子移到被质子化的氧上，给出质子化半缩醛；失去一个质子得中性半缩醛。(c) 半缩醛的 OH 被质子化并以水的形式离去，其 C–O 键电子随它而去；将成为环氧的那个氧（已经连在碳上）的孤对电子推入形成 C=O⁺ 双键——一个**氧碳鎓离子**。(d) 二醇的第二个羟基在分子内进攻这个阳离子，闭成五元环；(e) 失去质子得缩醛。每一步都可逆；除去水（Dean–Stark）使平衡移向缩醛，加入过量水（脱保护）则使其退回。(d) 中的分子内闭环与环缩醛有利的熵（两分子生成两分子，而不是三分子生成两分子）使二氧戊环远比链状二甲缩醛易于形成。
:::
:::

**硫代缩醛**（1,3-二硫戊环与二噻烷，来自硫醇与路易斯酸）对含水酸也是稳定的，因此与氧缩醛正交。它们用汞(II)盐或氧化法除去，也可以直接用 Raney 镍还原为 $\mathrm{CH_2}$。如我们在[[organic-synthesis/retrosynthesis]]中见到的，1,3-二噻烷还可用作酰基负离子等价物。

## 胺的保护 {#sec-amines}

胺具有亲核性，且（伯胺与仲胺）有酸性的 N–H 键，会摧毁有机金属试剂。它们通常以**氨基甲酸酯**保护，$\mathrm{R_2N{-}CO{-}OR'}$：氮的孤对电子离域进羰基，因此既不显碱性也不显亲核性。选择哪个烷氧基 $\mathrm{OR'}$，决定了打开它的"钥匙"。

- **Boc**（叔丁氧羰基），用二碳酸二叔丁酯（$\mathrm{Boc_2O}$）引入。由**酸**除去（三氟乙酸，或二氧六环中的 HCl）。机理：氨基甲酸酯的羰基氧被质子化；酯氧与叔丁基之间的键断裂，电子留在氧上，放出稳定的叔丁基阳离子（它失去质子生成 2-甲基丙烯，或被清除剂捕获）；所得氨基甲酸失去二氧化碳，C–N 键电子移到氮上，给出铵盐。富电子侧链（吲哚、硫醚）会被叔丁基阳离子烷基化，这就是要加入水、三异丙基硅烷或硫苯甲醚等清除剂的原因。
- **Cbz** 或 **Z**（苄氧羰基，贝格曼（Bergmann）与泽尔瓦斯（Zervas），1932），用氯甲酸苄酯引入。由**氢解**除去：苄位 C–O 键断裂给出甲苯和氨基甲酸，后者脱羧。也可被 HBr/乙酸断裂。
- **Fmoc**（9-芴甲氧羰基，卡尔皮诺（Carpino），1970），用 Fmoc-Cl 或 Fmoc-OSu 引入。由**碱**除去，典型条件是 DMF 中的哌啶，经由 E1cB 消除（见下文关于 Fmoc 除去的习题）。对酸稳定。
- **Alloc**（烯丙氧羰基），由 **Pd(0)** 在烯丙基清除剂（吗啉，苯基硅烷）存在下除去：钯对烯丙基–O 键的氧化加成释放出氨基甲酸酯。
- **磺酰胺**：对甲苯磺酰基（Ts）非常牢固（用溶金属还原或强酸除去）；2- 或 4-硝基苯磺酰基（Ns，福永（Fukuyama），1995）在温和条件下被硫负离子除去，经由在缺电子芳环上的芳香亲核取代。

::: example Boc 与 Fmoc 除去的机理 {#ex-boc-fmoc}
一个二肽的 N 端带 Boc，另一个二肽带 Fmoc。写出前者与三氟乙酸、后者与哌啶反应的产物，并解释为什么另一个基团在各自的处理下能幸存。
::: solution
**Boc/TFA。** 如前述：羰基氧质子化；O–C(CH₃)₃ 键异裂给出叔丁基阳离子（→ 2-甲基丙烯或清除剂加合物）；氨基甲酸脱羧；产物是成三氟乙酸盐的肽胺。Fmoc 氨基甲酸酯对酸稳定，因为其 9-芴甲酯基无法容易地生成稳定阳离子（C–O 键连在伯碳上），于是没有电离路径可用。

**Fmoc/哌啶。** 芴环的 C9–H 酸性异常地高（DMSO 中 $\mathrm{p}K_\mathrm{a}$ 约 23），因为所得阴离子是芴体系内的环戊二烯基型芳香阴离子。哌啶拿走这个质子——它的孤对电子接住 H⁺，C–H 电子形成碳负离子。碳负离子的电子对随后与相邻的 $\mathrm{CH_2}$ 形成 C=C 键，断开 $\mathrm{CH_2}$–O 键并把氨基甲酸酯阴离子赶出去（E1cB 消除）。氨基甲酸酯失去 $\mathrm{CO_2}$ 给出游离胺。另一产物二苯并富烯是活泼的迈克尔受体；过量哌啶与它加成，防止它烷基化刚刚解放出来的胺。Boc 氨基甲酸酯没有处于可消除位置的酸性 C–H，胺碱对它无可奈何。
:::
:::

## 羧酸的保护 {#sec-acids}

羧酸以酯保护，按除去它的钥匙选择：**甲酯或乙酯**（碱水解，LiOH 或 NaOH）、**叔丁酯**（酸，与 Boc 相同的阳离子机理）、**苄酯**（氢解）、**烯丙酯**（Pd(0)），以及硅酯（极不稳定，用于暂时保护）。在肽化学中，氮上用 Fmoc、侧链上用叔丁酯与叔丁醚的组合——均耐酸不稳定——是标准的 **Fmoc/*t*Bu 策略**；梅里菲尔德（Merrifield）较老的 Boc/苄基策略依靠分级的耐酸性（TFA 除去 Boc，液态 HF 除去苄基型基团），而非真正的正交性。

## 策略：正交性与保护的成本 {#sec-strategy}

::: algorithm 设计保护基策略 {#alg-pg}
1. **列出每一个官能团**：路线中每个中间体里用到的、以及每组反应条件涉及的所有官能团。
2. **标出冲突**：每一个会在为本应稳定的另一基团而设的条件下反应的基团。
3. **先试用不保护的办法消除冲突**：重排步骤顺序（让敏感基团晚出场），改用化学选择性更强的试剂，或以潜形式携带某个基团（以硝基代胺、以烯烃代酮、以酯代醇）。
4. **对剩下的冲突选择保护基**：对所经手的全部条件稳定（[[#def-pg]]），并且其"钥匙"彼此正交、又与计划中的反应正交（[[#def-orthogonal]]）。
5. **规划除去次序**，并尽可能在最后一步同时除去多个基团（全局脱保护），或把某次脱保护与另一次转化合并。
6. **算成本账**：每个基团增加两步；与一条免保护基的路线比较总产率。
:::

成本是乘性的。若一条路线需要 $m$ 个保护基，安装与除去的产率分别为 $p_\mathrm{on}$ 与 $p_\mathrm{off}$，则总产率乘以 $(p_\mathrm{on}p_\mathrm{off})^m$，并增加 $2m$ 步。三个保护基、每次操作 $95\,\%$，代价是因子 $0.95^6 = 0.735$——还没有做任何有效化学，四分之一原料已经没了。这本账，连同产生的废物，推动了走向**免保护基合成**的运动，由霍夫曼（Hoffmann，2006）倡导，巴拉恩（Baran）课题组在海洋生物碱的合成（2007）中加以示范——以化学选择性的反应与审慎的步骤安排使保护成为多余。

::: example 固相肽合成：累积产率 {#ex-spps}
在 Fmoc 固相肽合成中，每个残基由两步操作加上——除去 Fmoc，并偶联下一个 Fmoc-氨基酸。若每步操作完成 $99.0\,\%$，经 19 次添加（38 步操作）后，树脂上结合的链中有多大分数是正确的 20 肽？要达到 $90\,\%$ 需要每步多高的效率？
::: solution
$0.990^{38} = 0.682$：只有 $68\,\%$ 的链是正确的；其余是缺失一个或多个残基的缺失序列，与产物差别极小，难以分离。要求 $90\,\%$：$p^{38} = 0.90$，故 $p = 0.90^{1/38} = e^{\ln 0.90/38} = e^{-0.002773} = 0.99723$，即每步 $99.7\,\%$。这就是为什么每次脱保护与偶联都要用过量试剂驱向完全、加以监测（例如监测每次 Fmoc 除去释放的二苯并富烯-哌啶加合物在紫外区的吸收）、不完全就重来。这也是正交性在此处如此要紧的原因：侧链保护基哪怕每个循环损失 $0.1\,\%$，经过一长段合成后也会在百分之几的链上丢失。
:::
:::

::: quiz
一个合成中间体带有 TBS 醚、苄基醚和甲酯。哪种试剂**只**除去苄基醚？
- [x] $\mathrm{H_2}$，Pd/C，乙酸乙酯中
- [ ] 四丁基氟化铵的 THF 溶液
- [ ] 氢氧化锂的含水 THF 溶液
- [ ] DDQ 的湿二氯甲烷溶液
::: solution
氢解断裂苄位 C–O 键，既不碰硅醚也不碰酯。TBAF 除去 TBS 基团；LiOH 水解甲酯；DDQ 快速除去 PMB 醚，但对普通苄基醚只是缓慢，故不是首选。（若分子里还有一个烯烃，氢化也会把它还原——这是[[#alg-pg]]第 2 步要记下的冲突。）
:::
:::

::: warning 保护基不是隐形的 {#warn-pg}
人们很容易把保护基当作被动的标记。它不是。体积大的硅基会改变构象，并能阻挡或指引邻近碳上的试剂；苄基和 PMB 醚会配位路易斯酸并可参与相邻基团参与的反应；酰基在碱或酸条件下会在相邻羟基之间迁移（糖与甘油衍生物中的乙酰迁移是出了名的麻烦）；THP 增加一个立体中心；氮上的 Boc 可被强亲核试剂进攻。脱保护试剂也有副作用：TBAF 呈碱性，TFA 会产生叔丁基阳离子，氢解会还原烯烃和硝基。务必把后面每一步的条件拿到每一个在场的保护基面前过一遍，并预期被保护的分子与未保护分子的行为会有所不同。
:::

::: history
保护基随着肽与糖的合成而变得不可或缺。埃米尔·费歇尔（Emil Fischer）在 1900 年前后的糖与肽工作中使用了酰基与缩醛衍生物；马克斯·贝格曼（Max Bergmann）与莱奥尼达斯·泽尔瓦斯（Leonidas Zervas）于 1932 年引入苄氧羰基（Cbz，"Z"）基，使可控的肽合成成为可能；文森特·迪维尼奥（Vincent du Vigneaud）用它完成了第一个肽类激素催产素的全合成（1953；1955 年诺贝尔化学奖）。路易斯·卡尔皮诺（Louis Carpino）引入 Boc 基（1957），并同格蕾丝·汉（Grace Han）引入 Fmoc 基（1970）。布鲁斯·梅里菲尔德（Bruce Merrifield）的固相肽合成（1963；诺贝尔化学奖 1984）依靠分级的耐酸性，埃里克·阿瑟顿（Eric Atherton）与鲍勃·谢泼德（Bob Sheppard）在 1970 年代末发展的 Fmoc/*t*Bu 策略使之成为正交的。科里（Corey）与文卡泰什瓦鲁（Venkateswarlu）于 1972 年引入 TBS 基。格林（Greene）的《有机合成中的保护基》（*Protective Groups in Organic Synthesis*，1981；后期版本与彼得·武茨（Peter Wuts）合编）和科琴斯基（Kocieński）的《保护基》（*Protecting Groups*，1994）成为标准参考书。
:::

## 后续内容

保护基出现在几乎每一个多步合成中：在[[organic-synthesis/carbon-carbon-bonds]]的碳碳成键里，有机金属试剂要求把所有酸性质子掩蔽起来；在[[organic-synthesis/stereoselective-synthesis]]里，一个保护基有时能把试剂引向一个面；在[[organic-synthesis/total-synthesis]]的战略规划中，保护基的选择与出场时机往往决定一条长路线的成败。肽合成与蛋白质化学（[[biochemistry/amino-acids-proteins]]）以及肽类药物的合成（[[medicinal-chemistry/biologics]]）都建立在本章的正交策略之上。

::: summary
- 保护基要能被选择性地安装与除去，并熬过中间的一切；每次保护花费两步，并把总产率乘以 $p_\mathrm{on}p_\mathrm{off}$。
- 醇：硅醚（耐酸性 TMS < TES < TBS < TIPS、TBDPS；氟离子除去），苄基醚（氢解；PMB 也可用 DDQ），缩醛（THP、MOM；酸），酯（碱）；二醇作丙酮缩酮（1,2）或苄叉缩醛（1,3）。
- 羰基：1,3-二氧戊环（酸上酸下，除水驱动形成）；要求耐酸时用硫代缩醛。
- 胺：由不同钥匙打开的氨基甲酸酯——Boc（酸）、Cbz（氢解）、Fmoc（碱，E1cB）、Alloc（Pd(0)）；羧酸作甲酯、叔丁酯、苄酯或烯丙酯。
- **正交**基团由不同钥匙按任意次序除去；**分级**基团由同一钥匙以不同速率除去，$f_\mathrm{B} = f_\mathrm{A}^{k_\mathrm{B}/k_\mathrm{A}}$——干净的选择性需要速率比达到几百倍。
- 用[[#alg-pg]]作计划：先设法通过重排步骤顺序或使用潜官能团来避免保护。
:::

## 练习

::: exercise 分级的硅醚 {level=1 check="35"}
利用表中的耐酸相对稳定性，同一酸性条件下 TBS 醚的水解比 TIPS 醚快多少倍？（输入倍数。）
::: solution
$700\,000/20\,000 = 35$。由[[#eq-selective]]，除去 $99\,\%$ 的 TBS 醚会留下 $0.01^{1/35} = 87.7\,\%$ 的 TIPS 醚——不干净。靠酸区分 TBS/TIPS 不可靠；更好的选择是对硅上位阻更敏感的氟离子，或改用另一对组合。
:::
:::

::: exercise 肽合成的累积产率 {level=1 check="74.0"}
一条 31 肽用 Fmoc 固相合成制备，30 个脱保护/偶联循环（60 步操作），每步效率 $99.5\,\%$。有多大分数具有正确序列？（百分比保留三位有效数字输入。）
::: solution
$0.995^{60} = 0.740$，即 $74.0\,\%$（[[#ex-spps]]）。
:::

::: exercise 挑选保护基 {level=1}
为下列各情形建议一个保护基：(a) 必须熬过格氏反应、且稍后要在无酸条件下释放的醇 OH；(b) 必须熬过 $\mathrm{LiAlH_4}$ 的酮；(c) 必须熬过催化氢化、并用酸除去的胺；(d) 必须在含水碱中稳定、并靠氢解释放的羧酸。
::: solution
(a) TBS 醚（耐有机金属试剂，TBAF 除去）。(b) 1,3-二氧戊环（乙烷-1,2-二醇，酸催化）。(c) Boc（耐 $\mathrm{H_2}$/Pd，TFA 除去）；Cbz 不行，因为氢解会把它除去。(d) 苄酯。
:::

::: exercise 选择性脱保护 {level=2 check="0.933"}
两个被保护的醇在同一条件下以 $k_\mathrm{A}/k_\mathrm{B} = 100$ 的速率比断裂。当 $99.9\,\%$ 的 A 已除去时，B 还剩多大分数？（分数保留三位有效数字输入。）
::: solution
$f_\mathrm{B} = f_\mathrm{A}^{k_\mathrm{B}/k_\mathrm{A}} = 0.001^{0.01} = e^{0.01\ln 0.001} = e^{-0.0691} = 0.933$（[[#eq-selective]]）。把 A 的除去率从 $99\,\%$ 推进到 $99.9\,\%$，B 要多损失几个百分点：若 $f_\mathrm{A} = 0.01$，本可保住 $95.5\,\%$。
:::
:::

::: exercise THP 醚与非对映体 {level=2}
用文字给出（*S*）-丁-2-醇与 3,4-二氢-2*H*-吡喃酸催化形成 THP 醚的机理，并解释为什么产物显示两组 NMR 信号。
::: solution
酸把二氢吡喃烯醚 C=C 的质子加到 C3（离氧较远的碳）上：π 电子形成新的 C–H 键，环氧的孤对电子稳定 C2 上的正电荷，生成氧碳鎓离子。醇氧的孤对电子进攻 C2；失去 O–H 质子给出缩醛，2-(丁-2-基氧基)氧杂环己烷。环上的 C2 成为新的立体中心，生成时毫无控制，所以产物是接在（*S*）-丁基上的 (2*R*) 与 (2*S*) 缩醛的近似等量混合物：**非对映体**，NMR 谱不同。（若用外消旋醇，则生成两对非对映体共四个立体异构体。）这是 THP 的一个实际缺点。
:::
:::

::: exercise Fmoc 的除去 {level=2}
解释为什么 Fmoc 的除去用哌啶很快、而用三乙胺极慢，以及为什么二苯并富烯副产物必须被清除。
::: solution
Fmoc 的除去是 E1cB 消除，第一步是夺去芴的 C9–H 质子（[[#ex-boc-fmoc]]）。对这一质子转移，哌啶这类仲胺在动力学上是比受阻的叔胺如三乙胺（其氮被三个乙基挤在一起）更好的碱，因此速率高得多。更重要的是，哌啶——亲核试剂——以迈克尔方式加到二苯并富烯上（其孤对电子进攻环外 $\mathrm{CH_2}$，C=C 电子形成芴基负离子，随后被质子化），得到稳定的加合物。若没有亲核清除剂，二苯并富烯会与肽新解放的 N 端胺反应使它永久封端，或发生聚合。
:::
:::

::: exercise 区分三个羟基 {level=3}
从丁烷-1,2,4-三醇出发，设计一条序列制取 4-(苄氧基)丁烷-1,2-二醇。解释你所依赖的环大小选择性。
::: hint
哪一种缩醛偏爱 1,2-二醇？
:::
::: solution
(1) **成丙酮缩酮**：2,2-二甲氧基丙烷（或丙酮），催化量对甲苯磺酸。1,2-二醇生成五元 1,3-二氧戊环；若由 2,4-二醇生成六元 1,3-二氧六环，丙酮缩酮的一个甲基将被迫处于直立键而产生 1,3-二直立相互作用，故在平衡条件下 2-(2,2-二甲基-1,3-二氧戊环-4-基)乙-1-醇占主导。(2) 对剩下的伯 OH 进行**苄基化**：NaH（去质子化，放出 $\mathrm{H_2}$），然后溴化苄（苄位碳上的 $\mathrm{S_N2}$）。丙酮缩酮对碱稳定。(3) **除去丙酮缩酮**：含水酸（甲醇中的稀 HCl，或乙酸-水）水解缩醛（[[#ex-acetal]]的逆过程），苄基醚完好，得 4-(苄氧基)丁烷-1,2-二醇。若要区分的本是 1,3-关系，就应选苄叉缩醛（六元环，苯基平伏）。
:::

::: exercise 免保护步骤的盈亏平衡点 {level=3 check="66.2"}
路线 1 保护三个基团（三次安装与三次除去，各 $95\,\%$），使关键步以 $90\,\%$ 产率进行。路线 2 完全不用保护，其关键步受副反应拖累。关键步产率低于多少时路线 2 比路线 1 更差（只计这些步骤）？（产率以百分数输入，保留三位有效数字。）
::: solution
路线 1：$0.95^6 \times 0.90 = 0.735 \times 0.90 = 0.662$，即 $66.2\,\%$。路线 2 给出 $p_\mathrm{key}$，只有当 $p_\mathrm{key} < 66.2\,\%$ 时它才更差。而且路线 2 还少六步，废物与人工都更少，所以实践中即使其产率略低于盈亏点也宁愿选它——它还避免了那六步中任何一步在昂贵的后期中间体上失败的风险。
:::
