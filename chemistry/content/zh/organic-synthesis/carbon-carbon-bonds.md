碳骨架决定了一个分子之所以为该分子。官能团可以相互转化、加以保护、并调节其氧化水平（[[organic-synthesis/redox-in-synthesis]]、[[organic-synthesis/protecting-groups]]），但每一条合成路线迟早都必须把碳接到碳上——而选择形成哪些键、用什么反应去形成，决定了整条路线的形状。用[[organic-synthesis/retrosynthesis]]的语言说，每一次 C–C 切断都给出一个亲核合成子与一个亲电合成子，我们的任务是为两者都找到可靠的合成等价物，并且与分子中其余的一切相容。

本章按所用亲核试剂的类型来组织主要的 C–C 成键反应。**有机金属试剂**（有机锂、格氏、有机铈与有机铜化合物）加到羰基与烯酮上，1,2-与 1,4-加成之间的平衡可由我们控制。**磷与硫的叶立德及碳负离子**把羰基变成烯烃（维蒂希反应与 Horner–Wadsworth–Emmons 反应）或环氧化物。**烯醇负离子、烯醇与烯胺**——即[[organic-2/enols-enolates]]与[[organic-2/condensations]]的亲核试剂——被烷基化、酰基化，并加到醛与迈克尔受体上，而我们必须控制生成的是哪一个烯醇负离子。最后，**过渡金属交叉偶联**把经典极性化学难以连接的两个 $sp^2$ 碳接在一起；其机理在[[organometallics-catalysis/cross-coupling]]中展开，烯烃复分解在[[organometallics-catalysis/metathesis-polymerisation]]中展开，因此这里把两者都只当作策略工具来处理。

## 有机金属亲核试剂 {#sec-organometallic}

有机锂与格氏试剂（[[organometallics-catalysis/main-group-organometallics]]）是碳负离子最直接的合成等价物。它们快速、不可逆地加到醛与酮上（给出仲醇与叔醇）、加到酯上（加两次，给出叔醇）、加到腈上（一次，亚胺水解后给出酮）、加到环氧化物上（在位阻较小的碳上），以及加到二氧化碳上（给出羧酸）。它们的局限也正来自同一份反应性：它们是强碱，会被任何 O–H、N–H 或酸性 C–H 摧毁，而且遇到位阻的或酸性的酮时发生烯醇化而不是加成。

三种改造扩展了它们的适用范围：

- **有机铈试剂**由有机锂与无水氯化铈(III)经转金属化制得（Tsuneo Imamoto，1980 年代），碱性大大减弱但仍是亲核的，能干净地加到容易烯醇化的酮上。
- **Weinreb 酰胺**，即 $N$-甲氧基-N-甲基酰胺（Steven Nahm 与 Steven Weinreb，1981），与恰好一当量的有机金属试剂反应给出酮，解决了酯过度加成的问题。
- **有机铜酸盐**，$\mathrm{R_2CuLi}$（吉尔曼（Gilman）试剂），加到 α,β-不饱和羰基化合物的 β-碳上，而不是加到羰基碳上。

::: example 由 Weinreb 酰胺制备酮 {#ex-weinreb}
以 $N$-甲氧基-N-甲基苯甲酰胺为原料制备 1-苯基丁-1-酮（丁酰苯），并解释为什么反应停在酮这一步，而苯甲酸甲酯与丙基溴化镁却给出叔醇。
::: solution
**反应。** $\mathrm{PhCON(OMe)Me}$ + $\mathrm{CH_3CH_2CH_2MgBr}$（约一当量）在 THF 中于 0 °C 反应，随后加酸性水溶液：$\mathrm{PhCOCH_2CH_2CH_3}$。

**机理。** C–Mg 键的电子进攻酰胺的羰基碳，C=O 的 π 电子移到氧上，生成四面体烷氧负离子。镁同时结合这个烷氧负离子的氧与 N-甲氧基的氧，形成一个**五元螯合环**。该螯合物在反应温度下是稳定的：只要镁还抓着它，烷氧负离子就无法把自己的电子推回去以赶出 $\mathrm{^-N(OMe)Me}$，因此只要有机金属试剂尚存，烧瓶中就不存在酮。水相后处理时螯合物被质子化，中性的四面体中间体随即崩解——带 O–H 的氧的孤对电子重建 C=O，$\mathrm{HN(OMe)Me}$ 离去——于是在格氏试剂已被消灭之后才释放出酮。

**酯的对比。** 对苯甲酸甲酯，四面体中间体会立刻崩解（甲氧基负离子是很好的离去基团，且没有螯合），于是*在格氏试剂存在之下*就生成了丁酰苯。酮比酯更亲电，因此它比剩余的酯被进攻得更快，产物便是 4-苯基庚-4-醇。
:::
:::

### 1,2-加成与 1,4-加成

α,β-不饱和羰基化合物（烯酮）有两个亲电位点：羰基碳（1,2-加成）与 β-碳（1,4-加成，即共轭加成，[[organic-2/conjugation]]）。

::: proposition 向烯酮加成的区域选择性（经验规则） {#prop-12-14}
**不可逆**加成的**硬**亲核试剂——体积小、电荷高、反应性由电荷主导（有机锂、格氏试剂、四氢铝锂）——通常进攻烯酮的羰基碳（1,2-加成，动力学控制），那里带较多的正电荷。**软**亲核试剂——可极化、反应性由轨道重叠主导（有机铜酸盐、硫醇盐、1,3-二羰基化合物的烯醇负离子、烯胺）——以及**可逆**加成的亲核试剂（氰化物、胺、平衡条件下的稳定化烯醇负离子）主要给出 1,4-加成，其原因不是 β-碳的 LUMO 系数较大，就是 1,4-加合物因保留了强 C=O 键而在热力学上更有利。这条规则是经验性的；任一位点上的位阻、路易斯酸与溶剂都能改变结果。
:::

::: example 甲基锂还是二甲基铜酸锂？ {#ex-cuprate}
预测环己-2-烯-1-酮与下列试剂反应的产物：(a) 甲基锂，然后水相后处理；(b) 二甲基铜酸锂，然后水相后处理；(c) 二甲基铜酸锂，然后烯丙基溴。
::: solution
(a) **1,2-加成**：C–Li 键的电子进攻羰基碳，π 电子移到氧上；后处理使烷氧负离子质子化：**1-甲基环己-2-烯-1-醇**。

(b) **1,4-加成**：铜酸盐的铜(I)与 C=C 配位，一个甲基被递送到 β-碳（C3）上——机理上经由一个铜(III)中间体发生还原消除。C=C 的 π 电子移动形成 C2=C1 烯醇负离子，负电荷在氧上。后处理时锂烯醇负离子在碳上质子化，得到 **3-甲基环己-1-酮**。

(c) (b) 中生成的锂烯醇负离子本身就是亲核试剂，而且是区域专一性地生成于 C2。不去质子化它，而是加入亲电试剂：烯醇负离子的 C2 进攻烯丙基溴的烯丙位碳（$\mathrm{S_N2}$），把溴离子顶出去。产物是 **2-烯丙基-3-甲基环己-1-酮**，主要为 *trans* 异构体，因为烯丙基溴从新引入甲基的对面进攻烯醇负离子的一面。这种"共轭加成-烯醇负离子捕获"在一步之内建成两根 C–C 键，曾被斯特克（Stork）与野依良治（Noyori）用于前列腺素的三组分合成。
:::
:::

## 烯化反应：由 C=O 构建 C=C {#sec-olefination}

### 维蒂希反应

维蒂希（Wittig）的反应（1954）用**鏻叶立德** $\mathrm{Ph_3P^+{-}C^-HR}$（$\mathrm{Ph_3P{=}CHR}$）把醛或酮变成烯烃。叶立德由三苯基膦与卤代烷（一次给出鏻盐的 $\mathrm{S_N2}$ 反应）制备，然后对简单烷基用强碱（正丁基锂、六甲基二硅基氨基钠）去质子化，对被共轭的酯或酮稳定的叶立德则用温和碱。

在无锂条件下，其机理如今被理解如下。叶立德的碳负离子与羰基碳形成 C–C 键，同时羰基的氧与磷成键——这是一步不同步的 [2+2] 环加成，生成四元环**氧磷杂环丁烷**。随后环以逆 [2+2] 步骤碎裂：P–C 与 C–O 两根环键断裂，C–C 键变成 C=C 双键，而氧留在磷上，成为三苯基膦氧化物。极强的 P=O 键的生成（远超 $500\ \mathrm{kJ\,mol^{-1}}$）驱动了反应。

**立体化学**取决于叶立德：

- **非稳定化叶立德**（R = 烷基）反应快而不可逆，经过一个较早的、皱褶的过渡态，其中取代基彼此回避的方式有利于 *cis*-氧磷杂环丁烷：它们主要给出 (*Z*)-烯烃，在不含锂盐时与醛反应尤其如此。
- **稳定化叶立德**（R = $\mathrm{CO_2Et}$、COR、CN）反应较慢，经过较晚的过渡态，主要给出 (*E*)-烯烃。
- **半稳定化叶立德**（R = 芳基、乙烯基）给出混合物。

### Horner–Wadsworth–Emmons 反应及相关反应

**Horner–Wadsworth–Emmons**（HWE）反应使用膦酸酯 $\mathrm{(EtO)_2P(O)CH^-CO_2Et}$ 的碳负离子，以 NaH 或更温和的碱（氯化锂加 DBU，即 Masamune–Roush 条件）产生。膦酸酯碳负离子比相应的鏻叶立德亲核性更强；它加到醛上生成烷氧负离子，后者闭环成氧磷杂环丁烷，再碎裂为烯烃与二烷基磷酸根负离子。由于加成可逆、中间体彼此平衡，**(*E*)-烯烃**以高选择性生成。磷酸酯副产物溶于水——相比常常必须用色谱除去的三苯基膦氧化物，这是巨大的实用优势。W. Clark Still 与 Cesare Gennari（1983）发现，带缺电子三氟乙氧基的膦酸酯在钾碱与冠醚存在下给出 (*Z*)-烯酸酯，因为消除变得比平衡更快。

其他烯化反应补全了工具箱：杂芳基砜的 **Julia–Kocieński** 反应（*E*-选择性）、β-硅基醇的 **Peterson** 消除（借助酸或碱可得任意构型）、用于酯与位阻酮亚甲基化的钛亚甲基试剂（Tebbe 与 Petasis 试剂），以及**烯烃复分解**（[[organometallics-catalysis/metathesis-polymerisation]]），它在两个烯烃之间形成 C=C 键，包括成环在内（关环复分解），环的大小几乎任意。

::: example 通往肉桂酸乙酯的两条路线 {#ex-olefination}
(*E*)-3-苯基丙-2-enoate ethyl （肉桂酸乙酯）既可由苯甲醛经维蒂希反应与 $\mathrm{Ph_3P{=}CHCO_2Et}$ 制备，也可由 HWE 反应与膦酰乙酸三乙酯及 NaH 制备。比较 HWE 路线的立体选择性、实用性与原子经济性（不计碱），并计算苯甲醛与 $\mathrm{Ph_3P{=}CH_2}$ 亚甲基化为苯乙烯的原子经济性。摩尔质量：苯甲醛 $106.12$、膦酰乙酸三乙酯 $224.19$、肉桂酸乙酯 $176.21$、$\mathrm{Ph_3P{=}CH_2}$ $276.32$、苯乙烯 $104.15\ \mathrm{g\,mol^{-1}}$。
::: solution
**选择性。** 两种试剂都被酯稳定，因此都主要给出 (*E*)-烯烃；HWE 反应通常选择性更高，常常远高于 90:10。

**实用性。** HWE 的副产物二乙基磷酸钠可用水洗去；维蒂希路线产生的 $\mathrm{Ph_3PO}$（$278.29\ \mathrm{g\,mol^{-1}}$）是结晶性固体，常与产物一同流出。

**HWE 的原子经济性。**
$$
\text{AE} = \frac{176.21}{106.12 + 224.19} = \frac{176.21}{330.31} = 53.3\,\%.
$$
**维蒂希亚甲基化的原子经济性。**
$$
\text{AE} = \frac{104.15}{106.12 + 276.32} = \frac{104.15}{382.44} = 27.2\,\%.
$$
维蒂希亚甲基化近四分之三的反应物质量最终变成了三苯基膦氧化物。正因如此，催化性的替代方案（复分解，或用催化量膦与硅烷还原剂的维蒂希反应）颇具吸引力（[[green-chemistry/green-metrics]]）。
:::
:::

## 烯醇负离子：控制位置与方式 {#sec-enolates}

烯醇负离子是最多才多艺的碳亲核试剂：它们被卤代烷烷基化，被酯与酰氯酰基化（克莱森反应），加到醛上（羟醛反应）与烯酮上（迈克尔反应）。合成的挑战在于：当一个酮可能给出两种烯醇负离子时只生成**一种**，停在**单**烷基化，使 **C**-烷基化胜过 **O**-烷基化，并且——对羟醛反应而言——控制立体化学（[[organic-synthesis/stereoselective-synthesis]]）。

### 动力学烯醇负离子与热力学烯醇负离子

一个不对称酮，例如 2-甲基环己-1-酮，可以在 C2 去质子化（取代较多的 α-碳，给出四取代烯醇负离子），也可以在 C6 去质子化（取代较少，给出三取代烯醇负离子）。

::: definition 动力学烯醇负离子与热力学烯醇负离子 {#def-kinetic-enolate}
**动力学烯醇负离子**是生成更快的那一种——通常通过夺走较易接近、位阻较小的 α-质子获得——所需条件是去质子化快速、完全且不可逆：强、体积大而非亲核的碱（二异丙基氨基锂，LDA，其共轭酸 $\mathrm{p}K_\mathrm{a} \approx 36$）、稍过量的碱、低温（$-78\ ^\circ\mathrm{C}$）与非质子溶剂（THF）。**热力学烯醇负离子**是较稳定的那一种——通常是取代较多的，如同烯烃一样——并在允许平衡的条件下占主导：较弱的碱或稍过量的酮（它在烯醇负离子之间传递质子）、质子溶剂、较高温度或较长时间。
:::

::: proposition 动力学控制与热力学控制下的产物比 {#prop-control}
若两种产物 P₁ 与 P₂ 由同一反应物经竞争的不可逆步骤生成，活化吉布斯自由能相差 $\Delta\Delta G^\ddagger = \Delta G^\ddagger_2 - \Delta G^\ddagger_1$，则产物比为
$$
\frac{[\mathrm{P_1}]}{[\mathrm{P_2}]} = \exp\!\left(\frac{\Delta\Delta G^\ddagger}{RT}\right) \quad\text{（动力学控制）}.
$$ {#eq-kinetic-ratio}
若 P₁ 与 P₂ 快速互变，比值由它们的吉布斯自由能差 $\Delta G^\circ = G^\circ_2 - G^\circ_1$ 决定：$[\mathrm{P_1}]/[\mathrm{P_2}] = \exp(\Delta G^\circ/RT)$（热力学控制）。两种情形下 P₁ 的分数都是 $1/(1 + e^{-\Delta/RT})$。
:::

::: proof
动力学控制下，两种产物都由同一反应物分别以速率 $k_1[\mathrm{R}]$ 与 $k_2[\mathrm{R}]$ 生成，所以每一时刻都有 $\mathrm{d}[\mathrm{P_1}]/\mathrm{d}[\mathrm{P_2}] = k_1/k_2$，从零积分得 $[\mathrm{P_1}]/[\mathrm{P_2}] = k_1/k_2$。过渡态理论 $k_i = (k_\mathrm{B}T/h)e^{-\Delta G^\ddagger_i/RT}$ 给出 $k_1/k_2 = e^{(\Delta G^\ddagger_2 - \Delta G^\ddagger_1)/RT}$。热力学控制下产物处于平衡，$K = [\mathrm{P_2}]/[\mathrm{P_1}] = e^{-\Delta G^\circ/RT}$。P₁ 的分数为 $r/(1 + r)$，其中 $r$ 为比值，它等于 $1/(1 + r^{-1})$。$\blacksquare$
:::

::: example 在 2-甲基环己酮的两侧烷基化 {#ex-enolate-regio}
说明如何把 2-甲基环己-1-酮甲基化于 (a) C6，给出 2,6-二甲基环己-1-酮；(b) C2，给出 2,2-二甲基环己-1-酮。用 LDA 于 $-78\ ^\circ\mathrm{C}$ 时，C6 与 C2 烯醇负离子的动力学比约为 99:1；在室温的平衡条件下约为 10:90。这些比值对应的自由能差各是多少？
::: solution
(a) **动力学烯醇负离子**：把酮加到 THF 中 $-78\ ^\circ\mathrm{C}$ 的 LDA（1.05 当量）里。体积大的氨基负离子夺走 C6 的质子（那里的 $\mathrm{CH_2}$ 比甲基旁边的 C2–H 位阻小）：N 的孤对电子拿走质子，C–H 的电子形成烯醇负离子的 C=C，C=O 的 π 电子移到与锂配位的氧上。然后是碘甲烷：烯醇负离子的碳 C6 进攻甲基碳，把碘离子顶出去（$\mathrm{S_N2}$）。产物：2,6-二甲基环己-1-酮（*cis*/*trans* 混合物）。由[[#eq-kinetic-ratio]]，$\Delta\Delta G^\ddagger = RT\ln 99 = 8.314 \times 195.15 \times 4.595\ \mathrm{J\,mol^{-1}} = 7.5\ \mathrm{kJ\,mol^{-1}}$。

(b) **热力学烯醇负离子**：用稍微不足的碱，或在室温用较弱的碱生成烯醇负离子，让未反应的酮穿梭质子，使烯醇负离子彼此平衡。取代较多的四取代烯醇负离子（C1=C2）占主导，$\Delta G^\circ = RT\ln 9 = 8.314 \times 298.15 \times 2.197\ \mathrm{J\,mol^{-1}} = 5.4\ \mathrm{kJ\,mol^{-1}}$。使用它的一个更干净的办法，是把已平衡的烯醇负离子捕获为其三甲基硅基烯醇醚（豪斯（House）的方法），纯化那个硅醚，再用甲基锂重新生成指定的锂烯醇负离子，然后加入碘甲烷。在 C2 烷基化得到 2,2-二甲基环己-1-酮。即便在动力学控制下也可能发生一些多烷基化，因为产物酮会与剩余的烯醇负离子交换质子；恰好使用一当量强碱与活性高的烷基化试剂可把它减到最少。
:::
:::

### 稳定化烯醇负离子及其等价物

一个 1,3-二羰基化合物——丙二酸二乙酯（水中 $\mathrm{p}K_\mathrm{a} \approx 13$）或乙酰乙酸乙酯（$\approx 11$）——被烷氧基负离子完全去质子化，而其烯醇负离子是软的、有选择性的亲核试剂，能被干净地单烷基化。烷基化之后，水解与脱羧除去了"活化"的酯。这就是制羧酸的**丙二酸酯**合成法与制甲基酮的**乙酰乙酸乙酯**合成法，它们是合成子 $\mathrm{^-CH_2CO_2H}$ 与 $\mathrm{^-CH_2COCH_3}$ 的合成等价物。

::: example 一次丙二酸酯合成 {#ex-malonate}
由丙二酸二乙酯与溴化苄制备 3-苯基丙酸。描述脱羧的机理。
::: solution
(1) 乙醇中的乙醇钠在中心 $\mathrm{CH_2}$ 处把丙二酸二乙酯去质子化（共轭碱被两个羰基共同稳定）。(2) 烯醇负离子的碳进攻溴化苄的苄位碳，顶出溴离子，得到苄基丙二酸二乙酯。(3) 水相氢氧根把两个酯都水解（在每个羰基上加成-消除）；酸化得到苄基丙二酸。(4) 加热时，**β-二羧酸经六元环状过渡态脱羧**：一个羧基的 O–H 氢转移到另一个羧基的羰基氧上；与此同时，中心碳与该羧基碳之间的 C–C 键断裂，其电子移去同剩余的羰基碳形成 C=C，二氧化碳离去。产物是 3-苯基丙酸的烯醇，它互变异构为酸。总起来说，$\mathrm{PhCH_2Br}$ 被接到了合成子 $\mathrm{^-CH_2CO_2H}$ 上。
:::
:::

**烯胺**（斯特克（Stork），1954–63）是由酮与仲胺制成的中性烯醇负离子等价物；它们被活性卤代烷烷基化，并加到迈克尔受体上，生成的亚胺离子再水解回酮（[[organic-synthesis/retrosynthesis]]）。**烯醇硅醚**在路易斯酸存在下与醛反应（**向山（Mukaiyama）羟醛反应**，1973），并与烯酮反应（向山-迈克尔反应），使本来会自缩合的一对伙伴之间得以进行交叉羟醛反应。

## 交叉偶联作为策略工具 {#sec-coupling}

上面的极性反应把一个 $sp^3$ 或羰基碳接到亲核试剂上。两个 $sp^2$ 碳之间的键——芳基–芳基、芳基–乙烯基、乙烯基–乙烯基——难以用那种方法构建，因为芳基与乙烯基卤代物不发生 $\mathrm{S_N2}$ 反应。**钯催化的交叉偶联**填补了这个空缺。它的机理（氧化加成、转金属化、还原消除）、配体设计与动力学在[[organometallics-catalysis/cross-coupling]]中讨论；对计划合成要紧的是：

- **切断。** 一个联芳基、苯乙烯、二烯、芳基炔或芳胺，在通往环的那根键处切断为一个有机卤代物（或三氟甲磺酸酯）与一个有机金属试剂（Suzuki 用硼酸，Negishi 用有机锌，Stille 用有机锡，Sonogashira 用端炔，Heck 用烯烃，Buchwald–Hartwig 用胺）。
- **官能团容忍度。** Suzuki 偶联容忍酮、酯、腈、硝基、游离的 OH 与 NH，以及水——这些基团会摧毁格氏试剂。这常常省去了对保护基的需要。
- **卤代物之间的化学选择性。** 氧化加成的次序 I > OTf ≈ Br ≫ Cl 允许在多卤代环上做分步偶联。
- **立体专一性。** 乙烯基卤与乙烯基硼试剂偶联时烯烃构型保持不变，因此事先设定的构型（例如通过炔烃硼氢化）被带进产物。
- **法规与成本问题。** 药物中残留的钯有限量（ICH Q3D），所以偶联常常放在路线早期，或者在其后加一道除金属的工序。

::: example 为什么是 Suzuki 偶联而不是格氏反应 {#ex-suzuki-strategy}
为 1-([1,1′-联苯]-4-基)乙-1-酮（4-乙酰基联苯）规划一条合成。解释为什么基于格氏试剂的联芳基合成是个糟糕的选择。
::: solution
**切断。** 断开芳基–芳基键：4-溴苯乙酮 + 苯硼酸（或溴苯 + 4-乙酰基苯硼酸）。正向：带膦配体的 Pd(0) 催化剂、水相碳酸钾、有机共溶剂、温和加热。4-溴苯乙酮是好底物：吸电子的乙酰基加速 C–Br 键的氧化加成。

**为什么不用格氏？** 由 4-溴苯乙酮制成的芳基格氏试剂会进攻自己的酮（或别的分子的酮），所以酮必须先保护为缩醛、再脱保护——多出两步。用苯基溴化镁去加 4-卤代芳基酮同样会进攻酮。基于格氏试剂的联芳基偶联（Kumada）无论如何也需要催化剂，而且几乎不容忍官能团。Suzuki 反应容忍这个酮，使用空气稳定、低毒的硼试剂，且无需保护——一条免保护基的路线（[[organic-synthesis/protecting-groups]]）。
:::
:::

::: algorithm 选择 C–C 成键反应 {#alg-cc}
1. **给要形成的键分类**：按两端碳的杂化类型与邻近的官能团（[[organic-synthesis/retrosynthesis#prop-dioxygen]]的双氧化模式）。
2. **羰基旁的 $sp^3$ 碳（α-碳）**：烯醇负离子烷基化（动力学或热力学，[[#def-kinetic-enolate]]）、丙二酸酯/乙酰乙酸酯等价物、烯胺。
3. **羰基碳接到新基团**：有机金属加成（RLi、RMgX；对可烯醇化的酮用 $\mathrm{CeCl_3}$；要酮用 Weinreb 酰胺）；用预先制成的烯醇负离子或烯醇硅醚做羟醛反应。
4. **烯酮的 β-碳**：铜酸盐或其他软亲核试剂（迈克尔反应），[[#prop-12-14]]；考虑捕获生成的烯醇负离子。
5. **由 C=O 得 C=C**：维蒂希（非稳定化 → *Z*）、HWE（→ *E*）、Still–Gennari（→ *Z* 烯酸酯）、Julia–Kocieński；或由两个烯烃做复分解。
6. **$sp^2$–$sp^2$ 或 $sp^2$–$sp$**：交叉偶联（首选 Suzuki；Negishi、Stille、Sonogashira、Heck）。
7. **成环**：以上各法的分子内版本、罗宾逊增环反应、狄尔斯-阿尔德反应（[[organic-synthesis/pericyclic]]）、关环复分解、自由基环化（[[organic-synthesis/rearrangements-radicals]]）。
8. **检查相容性**：与现存的其余每个基团相容，并优先选择能免掉保护基的方案。
:::

::: quiz
哪些条件有利于 2-甲基环己-1-酮生成**取代较少**的（动力学）烯醇负离子？
- [x] THF 中 −78 °C 用 LDA（1.05 当量），把酮加到碱中
- [ ] 乙醇中乙醇钠回流
- [ ] 酮对 LDA 稍过量，升温至室温数小时
- [ ] 室温下 *tert*-丁醇中的 *tert*-丁醇钾
::: solution
动力学控制要求由强而受阻的碱在低温、非质子溶剂中进行快速、不可逆、完全的去质子化，且没有过量酮来穿梭质子。乙醇中的乙氧基与 *tert*-丁醇中的 *tert*-丁氧基都不够强，无法完全去质子化，而质子溶剂会使烯醇负离子平衡；室温下酮过量同样允许平衡到取代较多的（热力学）烯醇负离子。
:::
:::

::: warning "碳负离子"试剂首先是碱 {#warn-basicity}
人们很容易把 $\mathrm{RMgBr}$ 或 $\mathrm{RLi}$ 读作"R⁻"，把它加到切断所要求的任何亲电试剂上。但这些试剂属于有机化学中最强的碱之列：简单烷基负离子的共轭酸 $\mathrm{p}K_\mathrm{a}$ 在 45 以上。任何比这更酸的质子——醇、胺、端炔、羧酸，或容易烯醇化的酮的 α-质子——都会以快于加成的速率被夺走，毁掉一当量试剂，往往还毁掉底物的反应性。在提出任何有机金属加成之前，列出分子中的每一个酸性质子；要么保护它，要么心中有数地使用过量试剂（双负离子策略），要么改用碱性较弱的亲核试剂（有机铈、有机锌、交叉偶联中的硼酸、稳定化烯醇负离子）。
:::

::: history
维克托·格林尼亚（Grignard）于 1900 年发现了有机镁卤化物（1912 年诺贝尔化学奖）。亨利·吉尔曼（Gilman）于 1952 年制备了二甲基铜酸锂，赫伯特·豪斯（House）、埃利亚斯·科里（Corey）与加里·波斯纳（Posner）在 1960 年代把铜酸盐发展为合成试剂。格奥尔格·维蒂希（Wittig）与乌尔里希·舍尔科普夫（Schöllkopf）于 1954 年报道了烯化反应（维蒂希与赫伯特·布朗（Brown）分享 1979 年诺贝尔化学奖）；莱奥波尔德·霍纳（Horner，1958）以及威廉·沃兹沃思（Wadsworth）与威廉·埃蒙斯（Emmons，1961）引入了膦酸酯变体。吉伯特·斯特克（Stork）的烯胺烷基化（1954，全文 1963）、豪斯（House）对烯醇负离子区域化学与烯醇硅醚的研究（1960 年代）、向山照昭（Mukaiyama）的烯醇硅醚路易斯酸介导羟醛反应（1973）以及史蒂文·纳姆（Nahm）与史蒂文·韦恩雷布（Weinreb）的酰胺（1981），赋予了烯醇负离子与酰基化学现代的精确性。钯交叉偶联因 2010 年授予理查德·赫克（Heck）、根岸英一（Negishi）与铃木章（Suzuki）的诺贝尔化学奖而获得承认，复分解因 2005 年的诺贝尔化学奖（肖万（Chauvin）、格拉布（Grubbs）、施罗克（Schrock））而获得承认，由此建成了现代 C–C 合成的工具箱。
:::

## 后续内容

控制键在*哪里*生成只是故事的一半；控制它们的空间三维排列是另一半。本章的羟醛、烷基化与共轭加成反应将在[[organic-synthesis/stereoselective-synthesis]]中重现，连同羟醛立体化学的 Zimmerman–Traxler 模型、烯醇负离子烷基化的手性辅基与不对称催化。协同的 C–C 成键——狄尔斯-阿尔德反应以及克莱森与科普重排——是[[organic-synthesis/pericyclic]]的主题，自由基的 C–C 成键则见[[organic-synthesis/rearrangements-radicals]]。在[[organic-synthesis/total-synthesis]]中，我们将看到关键的 C–C 切断如何决定一整条合成路线的战略。

::: summary
- 有机锂与格氏试剂加到 C=O 上；对可烯醇化的酮用 $\mathrm{CeCl_3}$，要停在酮用 Weinreb 酰胺（稳定的螯合四面体中间体）。
- 硬而不可逆的亲核试剂对烯酮做 1,2-加成；软的（铜酸盐、稳定化烯醇负离子、硫醇盐）做 1,4-加成（经验规则）；铜酸盐加成之后可以接着捕获烯醇负离子。
- 维蒂希：非稳定化叶立德 → (*Z*)-烯烃，稳定化 → (*E*)；HWE → (*E*)，且副产物溶于水；Still–Gennari → (*Z*)；维蒂希亚甲基化的原子经济性只有约 27 %。
- 动力学烯醇负离子（LDA，−78 °C）在取代较少的 α-碳上生成，热力学烯醇负离子在取代较多的 α-碳上；产物比遵循 $\exp(\Delta\Delta G/RT)$，所以几 kJ mol⁻¹ 就决定了结果。
- 丙二酸酯、乙酰乙酸酯、烯胺与烯醇硅醚化学提供了有选择性而温和的烯醇负离子等价物。
- 交叉偶联（[[organometallics-catalysis/cross-coupling]]）以广泛的官能团容忍度构建 $sp^2$–$sp^2$ 键，并常常免去保护的需要。
:::

::: exercise 温度与动力学选择性 {level=2 check="27"}
某动力学烯醇负离子比在 $195.15\ \mathrm{K}$ 下为 99:1。假设 $\Delta\Delta G^\ddagger$ 与温度无关，在 $273.15\ \mathrm{K}$（仍为动力学控制）下会得到什么比值？（比值以 $x$:1 中的 $x$ 输入，保留两位有效数字。）
::: solution
$\Delta\Delta G^\ddagger = RT\ln 99 = 8.314 \times 195.15 \times 4.595 = 7456\ \mathrm{J\,mol^{-1}}$。在 $273.15\ \mathrm{K}$：比值 $= \exp(7456/(8.314 \times 273.15)) = \exp(3.283) = 27$，即约 27:1（$96\,\%$）。还没等任何平衡发生，把去质子化升温到 0 °C 就已经损失了选择性。
:::

::: exercise 一次乙酰乙酸乙酯合成 {level=2}
从乙酰乙酸乙酯制备己-2-酮，指明试剂并用文字描述每一步。
::: solution
己-2-酮是 $\mathrm{CH_3CO{-}CH_2{-}CH_2CH_2CH_3}$：切断 C3–C4 键给出合成子 $\mathrm{^-CH_2COCH_3}$（等价物：乙酰乙酸乙酯的烯醇负离子）与一个丙基正离子（等价物：1-溴丙烷）。(1) 乙醇中的乙醇钠夺走乙酰乙酸乙酯酸性的 C2–H，得到稳定化的烯醇负离子。(2) 1-溴丙烷：烯醇负离子的碳进攻 $\mathrm{CH_2Br}$ 的碳，顶出溴离子，得到 2-乙酰基戊酸乙酯。(3) 水相氢氧根把酯皂化；酸化得到 β-酮酸。(4) 加热经六元环状过渡态使其脱羧（O–H 氢交给酮的氧，C–C 键断裂，$\mathrm{CO_2}$ 离去），得到己-2-酮的烯醇，它互变异构为酮。

::: solution
(a) **Heck**：4-溴苯乙酮 + 丙烯酸乙酯，Pd(OAc)₂/膦，三乙胺，加热。对 C–Br 的氧化加成（被乙酰基加速），丙烯酸酯以芳基接到端基 $\mathrm{CH_2}$ 的方式顺式插入，顺式 β-氢消除给出 (*E*)-肉桂酸酯，碱辅助再生 Pd(0)（[[organometallics-catalysis/cross-coupling]]）。酮毫发无损；唯一的问题是残留钯与催化剂的成本。(b) **HWE**：4-乙酰基苯甲醛 + 膦酰乙酸三乙酯，用温和碱（LiCl/DBU，Masamune–Roush）。膦酸酯负离子与醛（位阻较小、亲电性较强）的反应远快于与酮的反应，因此烯化选择性地发生在醛上，且 *E* 选择性很高；但 NaH 之类的强碱可能使甲基酮烯醇化而引起羟醛副反应，这正是选择较温和条件的原因。两条路线都不错；Heck 路线的起始原料更便宜、更易得，而 HWE 路线避免了钯。工艺化学家会根据原料成本与金属残留要求来做决定。

::: exercise 克莱森缩合为什么需要一整当量碱 {level=3 check="5.3"}
乙酸乙酯的克莱森缩合在生成中性 β-酮酸酯这一步是不利的，但产物（乙酰乙酸乙酯，$\mathrm{p}K_\mathrm{a} \approx 10.7$）被乙氧基（乙醇，$\mathrm{p}K_\mathrm{a} \approx 16$）去质子化，把反应推至完全。计算去质子化这一步的 $\log_{10}K$，解释为什么需要化学计量的碱，并预测 2-甲基丙酸乙酯会发生什么——它的克莱森产物在两个羰基之间没有 α-氢。（$\log_{10}K$ 保留两位有效数字输入。）
::: solution
对 $\mathrm{EtO^- + HA \rightleftharpoons EtOH + A^-}$，$\log_{10}K = \mathrm{p}K_\mathrm{a}(\mathrm{EtOH}) - \mathrm{p}K_\mathrm{a}(\mathrm{HA}) = 16 - 10.7 = 5.3$，故 $K \approx 2\times10^{5}$。缩合本身（烯醇负离子加到酯上、失去乙氧基）在热力学上是上坡的或大抵打平；最后对双重活化的 C–H 的去质子化把整串平衡拉向产物一边。由于产物最终以其烯醇负离子形式存在，每个分子消耗一当量乙氧基——催化量的碱在转化了百分之几之后就会被耗尽。酸性后处理随后给出中性的 β-酮酸酯。2-甲基丙酸乙酯本应给出 2,2,4-三甲基-3-氧代戊酸乙酯，它的两个羰基之间**没有**酸性氢：没有任何东西推动平衡，在乙氧基存在下反应失败（逆克莱森占上风）。这时需要改而使用能把酯完全且不可逆地去质子化的更强碱（例如三苯甲基钠，或先用 LDA 处理，再加酰氯）。
:::
