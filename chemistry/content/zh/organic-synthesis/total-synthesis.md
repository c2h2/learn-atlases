1828 年，弗里德里希·维勒（Friedrich Wöhler）由氰酸铵制得尿素，证明"有机"化合物可以从无机原料出发制造。一个半世纪之后，罗伯特·伯恩斯·伍德沃德（Robert Burns Woodward）与阿尔伯特·埃申莫瑟（Albert Eschenmoser）率领约百名合作者历时十二年完成了维生素 B₁₂——一个在围绕钴原子的钴啉环上带有九个立体中心的分子。今天，化学家制造出紫杉醇（paclitaxel，Taxol）这样带张力八元环与十一个立体中心的分子，而抗癌药艾立布林（eribulin）——海洋天然产物 halichondrin B 的简化类似物——由六十多步的序列生产。**全合成**——从简单的商品原料出发完整化学合成一个复杂天然产物——两个世纪以来一直是有机化学的试金石。

为什么要制造一个海绵或树本来就会制造的分子？从历史上说，合成**证明了结构**：在 X 射线晶体学与 NMR 之前，一个结构在被制造出来之前算不上确定，而它到今天仍能纠正被误定的结构。合成**供应**大自然只给极微量的化合物，并制造大自然根本不造的**类似物**，使生物活性得以研究与改进。最重要的是，它**推动方法的发明**：前几章的许多反应——伍德沃德-霍夫曼规则、夏普莱斯与埃文斯的方法、交叉偶联与复分解的大部分——之所以被发现或改进，正是因为某条合成需要它们。这最后一章问：一条复杂的全合成如何规划、如何评价。我们给出度量（步数、最长线性序列、理想度），纵览主要的战略思想（汇聚式、级联与仿生反应、对称性、立体控制），并研读一些里程碑式的合成，看本课程的工具如何在其中协同工作。

## 度量一条合成 {#sec-measures}

::: definition 步、最长线性序列与总产率 {#def-lls}
一个**步**指一个反应（或一锅串起的若干反应）后对中间体做一次分离或后处理。一条合成的**步数**是从商品原料到目标的总步数。**最长线性序列**（LLS）是目标中任一原子所经受的最大步数，即合成树中从某个商品原料到目标的最长路径。**总产率**通常沿 LLS 报出，等于该序列各步产率的乘积（[[organic-synthesis/retrosynthesis#prop-convergent]]）。**形式合成**止步于一个此前已被他人转化为目标的中间体；**接力合成**则使用降解天然产物所得的物料来完成路线的一部分。
:::

步数要紧，因为产率相乘，也因为每一步都消耗时间、溶剂与纯化。但步与步并不等价。詹姆斯·亨德里克森（James Hendrickson）（1975）把**理想合成**定义为只使用**骨架构造反应**（形成骨架 C–C 键的反应）、从本来就带有所需官能团的化合物出发、不做官能团调整、不加保护、不做事后又被逆转的氧化水平改变。坦雅·盖希（Tanja Gaich）与菲尔·巴拉恩（Phil Baran）（2010）把它定量化了。

::: definition 理想度 {#def-ideality}
对于一条 $N$ 步的合成，其中 $n_\mathrm{c}$ 步是**构造**反应（骨架 C–C 或 C–杂原子键的形成）、$n_\mathrm{sr}$ 步是**战略性氧化还原**反应（直接安装目标中已有、且氧化水平正确的官能团的氧化或还原），理想度为
$$
\text{理想度} = \frac{n_\mathrm{c} + n_\mathrm{sr}}{N} \times 100\,\%.
$$ {#eq-ideality}
非战略步包括保护、脱保护、不改变骨架也不设定最终氧化水平的官能团互变，以及事后又被撤销的氧化还原步。理想度是效率的启发式度量；与原子经济性一样，它不管产率、成本与安全。
:::

::: example 给一条路线打分 {#ex-ideality}
一条 12 步合成包含六步成 C–C 键的反应、两步分别安装目标最终酮与醇的氧化、两次保护、一次脱保护，以及一次把酯还原成醛并立即用于一次烯化。计算它的理想度。一条更理想的路线会设法去掉哪些步？
::: solution
构造步：6。战略性氧化还原：2（两步都设定最终氧化水平）。酯到醛的还原是为下一步构造反应备料，本身不算战略——氧化水平只是被改变以便进行烯化——所以记作非战略步，与两次保护和一次脱保护同列。理想度 $= (6 + 2)/12 \times 100\,\% = 66.7\,\%$（[[#eq-ideality]]）。更好的路线会重新排序、让敏感基团在冲突反应之后才引入，从而避免保护基（[[organic-synthesis/protecting-groups#alg-pg]]），并让烯化伙伴从一开始就以醛的氧化水平进场（例如用商品醛，或用一步到位的方法，如把韦恩雷布（Weinreb）酰胺用 DIBAL-H 还原后直接串联使用）。
:::
:::

## 战略思想 {#sec-strategy}

在[[organic-synthesis/retrosynthesis#alg-retro]]的基本算法之外，最好的合成里反复出现几条战略思想。

- **汇聚式。** 分别制备大碎片，在晚期把它们接起来（[[organic-synthesis/retrosynthesis#prop-convergent]]）。可靠的碎片偶联——交叉偶联、野崎-桧山-岸（Nozaki–Hiyama–Kishi）反应、HWE 烯化、酯化与大环内酯化、复分解——就是汇聚式合成的铰链。
- **构建复杂度的关键反应。** 一次狄尔斯-阿尔德反应、一次多烯环化、一次自由基或阳离子级联、或一次 $[3,3]$ 重排，可能一步形成几根键、几个环与几个立体中心（[[organic-synthesis/pericyclic]]、[[organic-synthesis/rearrangements-radicals]]）。规划常常从在目标中认出这类反应的回推结构开始。
- **仿生合成。** 在烧瓶里重现大自然使用的那一步——制造甾体与萜的阳离子引发多烯环化、酚的氧化偶联、某些生物合成中提出的分子内狄尔斯-阿尔德反应。
- **对称性与双向合成。** 带隐藏对称性的目标可以同时官能化对称中间体的两端，把操作数减半。
- **立体化学战略。** 尽早决定每个立体中心将如何设定——手性池、辅基、催化剂还是底物控制——以及以什么次序，使每个新中心都能被前一个控制（[[organic-synthesis/stereoselective-synthesis]]）。
- **保护基最小化与氧化还原经济**（巴拉恩（Baran），霍夫曼（Hoffmann）；"步骤经济"，保罗·温德（Paul Wender））：不做不构建目标的步。
- **面向功能的合成与改向合成**（温德；塞缪尔·达尼谢夫斯基（Samuel Danishefsky））：当目标是生物活性时，制造保留关键特征（"药效基团"）的更简单类似物，或从晚期中间体分支出去制造大量类似物。

::: algorithm 规划一条全合成 {#alg-total}
1. **分析目标**：环系、立体中心、官能团、敏感特征（张力环、不稳定酯、共轭多烯）、对称性，以及任何生物合成线索。
2. **找出战略性键与关键反应**：最能简化环系的切断、能揭示构建复杂度反应之回推结构的切断，以及把分子切成大小相近碎片的切断。
3. **规划立体化学序列**：哪些立体中心可用现有方法设定，哪些能把控制接力给邻居，绝对构型从何而来。
4. **安排步骤次序**，让敏感基团晚出场、冲突最小化；选定保护基及其脱除次序（[[organic-synthesis/protecting-groups#alg-pg]]）。
5. **评估方案**：LLS、预期总产率、理想度、试剂的可得性与危险性。比较备选方案。
6. **先在模型化合物上试验风险最大的步**，并留好后备切断：多数合成都会因为遇到意想不到的化学而被重新规划数次。
:::

## 案例研究 {#sec-cases}

以下合成都是本领域的经典，在尼科劳（Nicolaou）与索伦森（Sorensen）的《全合成经典》（*Classics in Total Synthesis*）中有详细讨论。我们只谈战略，不纠缠试剂与条件。

### 利血平（伍德沃德，1956）：一场狄尔斯-阿尔德反应定下基调

利血平（reserpine）是产于萝芙木（*Rauvolfia*）属植物的吲哚生物碱，曾广泛用于治疗高血压，有六个立体中心，其中五个在 E 环上。伍德沃德的洞见是：1,4-苯醌与 (*E*)-2,4-戊二烯酸甲酯之间的一次**狄尔斯-阿尔德反应**会给出一个 *cis*-并环双环加合物，带三个相邻立体中心且相对构型正确——正如同面、内型选择性的环加成所规定的（[[organic-synthesis/pericyclic#ex-endo]]）。这个刚性、折叠的双环骨架随后充当模板：试剂从其凸面进攻，于是更多立体中心由底物控制设定。后来，环系被打开并重新组织，在接到含吲哚部分之前把 E 环连同其全部取代基先造好。

::: example 狄尔斯-阿尔德反应给出立体中心 {#ex-reserpine}
解释为什么 1,4-苯醌与 (*E*)-2,4-戊二烯酸甲酯的狄尔斯-阿尔德加合物带三个新的、相对构型确定的立体中心，以及双环中间体为什么有利于设定后续立体中心。
::: solution
**新立体中心。** 醌的 C=C（亲双烯体）加到二烯酸酯的 C2 与 C5 上（酯基在 C1，连在 C2 上；末端 $\mathrm{CH_2}$ 即 C5）。两个环并碳（原醌的 CH 碳）成为立体中心，带酯基的二烯碳也是。对亲双烯体的同面加成使环并必然是 *cis*（醌 C=C 上的两个氢留在同一面）。内型取向——过渡态中醌的羰基压在二烯下方——固定了环并与带酯基碳之间的关系：按内型规则，酯（(*E*)-二烯的一个"外"取代基）最终与亲双烯体的内型取代基——醌环碳——处于 *cis*，因而落在环并氢的对面。于是一步生成三个立体中心，其相对构型由机理固定。

**双环控制。** *cis*-并双环体系像半开的书本一样折叠。试剂接近它剩下的双键与羰基时，从敞开的凸面而不是凹面进攻，于是新立体中心以高选择性相对于已有立体中心被设定——在把环展开之前安装 E 环其余立体中心的可预测办法。
:::
:::

### 前列腺素 F₂α（科里，1969）：分支点中间体

前列腺素是一类类激素脂质，环戊烷环上带两条互为 *trans* 的侧链与至多四个立体中心。科里的路线围绕一个单多面手的中间体搭建，如今称为**科里内酯**（Corey lactone，氧化后即科里醛），从它可以制出多种前列腺素——"分支点"战略的早期例子。要点如下：

1. 一个 5-取代环戊二烯与 2-氯丙烯腈（一种"酮等价物"，因为氯代腈的碳后来水解成酮）的**狄尔斯-阿尔德反应**造出一个双环[2.2.1]庚烷，取代基与新键的关系确定。
2. 转化为双环酮后，一次**拜耳-维利格（Baeyer–Villiger）氧化**插入氧，迁移碳保持构型，得到内酯（[[organic-synthesis/redox-in-synthesis#prop-aptitude]]）。
3. 水解并进行**碘内酯化**（羧酸根从碘的对面进攻环烯烃上生成的碘鎓离子）设定另外两个立体中心，形成 γ-内酯。
4. 用三丁基氢化锡**脱碘**（自由基还原，[[organic-synthesis/rearrangements-radicals]]）、调整保护基与氧化水平，得到科里醛。
5. 下侧链经一次**HWE 烯化**接上（得 (*E*)-烯酮）；上侧链在内酯被 DIBAL-H 还原成内半缩醛（lactol）后，经与不稳定化叶立德的**维蒂希反应**接上（得 (*Z*)-烯烃）（[[organic-synthesis/carbon-carbon-bonds]]）。

这条路线几乎展示了本课程的所有主题：周环构建、一次保持构型的重排、一次立体专一环化、自由基还原、化学选择性氢化物还原，以及两种按烯烃几何挑选的互补烯化。它的主要弱点——C15 酮以中等选择性还原成 (*S*)-醇——后来促使科里发展了对映选择性 CBS 还原（[[organic-synthesis/stereoselective-synthesis]]）。

### 黄体酮（W. S. 约翰逊，1971）：仿生多烯环化

在大自然里，甾体的四个环由无环三萐氧化角鲨烯（oxidosqualene）经一条阳离子–烯烃加成的酶促级联一步形成。吉尔伯特·斯特克（Gilbert Stork）与阿尔伯特·埃申莫瑟曾各自提出（1955）：这类环化经椅式构象进行，*trans* 烯烃给出 *trans*-并环。威廉·S. 约翰逊（William S. Johnson）的实验室把它变成了实验室方法。在黄体酮（progesterone）合成中，一个一端带环戊烯醇（阳离子引发位）、中间带两个 *trans*-三取代烯烃、另一端带炔（终止位）的无环前体被酸处理。烯丙醇电离给出烯丙基阳离子；每个烯烃依次进攻上一步生成的阳离子，一次操作关三个新环且环并构型正确（*trans*-反式-*trans* 稠合），炔关闭五元 D 环——最后的阳离子被溶剂体系捕获成乙烯基阳离子，后来显现为黄体酮的乙酰基侧链。臭氧解加一次分子内羟醛缩合随后完成 A 环。

::: example 多烯级联如何控制立体化学 {#ex-polyene}
用 Stork–Eschenmoser 假说解释为什么多烯环化中的 *trans* 烯烃导致 *trans* 环并，以及为什么反应能以一种相对构型形成多个立体中心。
::: solution
在级联中，阳离子经椅式过渡态加到最近的烯烃上；烯烃的 π 电子形成新的 C–C 键，正电荷移到烯烃另一个（取代更多的）碳上，它随即成为下一个烯烃的亲电体。对烯烃的加成实际上对双键是 *anti* 的：阳离子进攻烯烃的一个面，被链牵在背面的下一个烯烃再从那个面进攻新阳离子。对椅式中的 *trans*-二取代（或三取代）烯烃，烯烃两个碳上的取代基最终处于平伏位且分居两面——也就是说，新环并处的两个氢或烷基是 *trans* 的。由于每个新环都在一个几何由烯烃几何与上一个环决定的椅式中生成，每个新立体中心的相对构型都被固定：全 *trans* 烯烃给出天然甾体的全 *trans*-反式 环并。唯一不受机理决定的立体化学选择是绝对构型，它跟随引发环戊烯醇的构型（一个立体中心控制所有其他中心：*远程底物控制*）。约翰逊 1971 年的合成用的是外消旋物料，所以得到外消旋黄体酮；用对映富集的引发基就能得到单一对映体。
:::
:::

### 奎宁：作为证明的合成，以及证明的负担

奎宁——金鸡纳树皮里的抗疟生物碱——有很长的合成史。1944 年，伍德沃德与威廉·冯·埃格斯·多林格（William von Eggers Doering）制成了一个化合物——奎宁托辛（quinotoxine）——而保罗·拉贝（Paul Rabe）与卡尔·金德勒（Karl Kindler）曾在 1918 年报道把它转化为奎宁。因此伍德沃德-多林格的工作是一次**形式合成**，依赖一个只被简略描述过的 1918 年转化。吉尔伯特·斯特克（Stork）2001 年发表了第一个完全立体选择性的奎宁全合成，并质疑 1918 年的转化是否如所述奏效；2007–08 年，亚伦·史密斯（Aaron Smith）与罗伯特·威廉姆斯（Robert Williams）按原始文献重复了拉贝-金德勒操作，证明它确实给出奎宁，从而确认了那次形式合成。这段公案说明一个普遍道理：一条合成的主张，站得住脚与否取决于每一步（包括旧文献里的步）的可重复性，以及最终产物与真实样品的表征对比。

### 紫杉醇与供应问题

紫杉醇（paclitaxel，Taxol）从太平洋紫杉树皮中分离，1992 年获批为抗癌药，而不毁掉大量树木就无法从树皮供应。罗伯特·霍顿（Robert Holton）与 K. C. 尼科劳（K. C. Nicolaou）两组都在 1994 年报道了全合成：尼科劳走汇聚式路线，连接两个六元环碎片并用麦克马里（McMurry）偶联关闭八元环；霍顿走线性路线，从手性池里的一个萜出发。两者都不适合生产：供应来自**半合成**——以可再生欧洲红豆杉的针叶中提取的 10-去乙酰巴卡亭 III（10-deacetylbaccatin III）为原料——后来又加上**植物细胞发酵**。全合成贡献的则是对构效关系的理解与新方法。相比之下，halichondrin 类似物**艾立布林**（eribulin，卫材（Eisai），2010 年获批）完全靠合成生产，建立在久松义人（Yoshito Kishi）1992 年 halichondrin B 全合成及其野崎-桧山-岸偶联的运用之上，因为没有自然资源可供货。

::: example 一个单萜香料的短合成 {#ex-terpineol}
α-萜品醇（α-terpineol），2-(4-甲基环己-3-烯-1-基)丙-2-醇，是一个带丁香花香的单萜醇。请从 2-甲基丁-1,3-二烯（异戊二烯）与丙烯酸甲酯提出一个两步外消旋合成，并按本章的度量评价它。
::: solution
**逆合成。** 叔醇 $\mathrm{{-}C(CH_3)_2OH}$（两个相同的甲基）可切断为一个酯加两当量 $\mathrm{CH_3MgBr}$（[[organic-synthesis/retrosynthesis#ex-grignard]]）。这个酯，4-甲基环己-3-烯-1-甲酸甲酯，是一个环己烯——狄尔斯-阿尔德的回推结构——甲基与酯基处于 1,4（"*对位*"）关系，正符合 2-取代二烯与单取代亲双烯体的预期（[[organic-synthesis/pericyclic]]）。

**正向。** (1) 异戊二烯 + 丙烯酸甲酯，加热（或用路易斯酸催化剂以提高 "*对位*" 选择性并降低温度）：得 4-甲基环己-3-烯-1-甲酸甲酯。二烯 C2 上的甲基供体增大 C1 的 HOMO 系数，C1 与丙烯酸的 β-碳（LUMO 系数最大）成键，把酯基放到甲基的 1,4 位。(2) 过量的甲基溴化镁：第一当量加到酯羰基上并顶出甲氧基，得甲基酮，第二个当量更速快地进攻它；酸后处理给外消旋 α-萜品醇。

**评价。** 两步，都是构造反应：理想度 $100\,\%$。狄尔斯-阿尔德步的原子经济性 $100\,\%$。产物是外消旋的；天然 α-萜品醇两个对映体都存在，所以香料用途外消旋体可以接受。对映选择性版本可在第 1 步用手性路易斯酸催化剂（[[organic-synthesis/stereoselective-synthesis]]）。（工业上，α-萜品醇由蒎烯——一个手性池萜——经酸催化水合即阳离子开环制得，这说明"最好"的路线取决于最便宜的现货原料。）
:::
:::

::: quiz
一条合成用 9 步制得碎片 A，6 步制得碎片 B，把两者偶联，再经 4 步到目标。哪些说法正确？
- [x] 最长线性序列是 14 步（9 + 1 步偶联 + 4）。
- [x] 总步数是 20。
- [ ] 总产率应沿碎片 B 的分支报出，因为它更短。
- [ ] 若碎片 B 用 3 步、碎片 A 用 12 步制备，合成会更汇聚。
::: solution
LLS $= 9 + 1 + 4 = 14$；总步数 $= 9 + 6 + 1 + 4 = 20$。总产率按惯例沿 LLS（最长分支）报出。让碎片更不均等（12 与 3）会把 LLS 拉长到 17，使路线*更不*汇聚；汇聚度在碎片复杂度相近、偶联发生在晚期时最大。
:::
:::

::: warning 一条合成的分量，取决于它的结构证明与可重复性 {#warn-claims}
对任何合成主张都适用两条告诫。其一，**目标的结构本身可能是错的**：许多天然产物曾被误定结构，按提议结构合成得到的化合物图谱与之不符。著名的例子是 hexacyclinol：2006 年有人声称已合成其最初提出的结构；斯科特·里奇诺夫斯基（Scott Rychnovsky）用 NMR 计算预言结构有误，当年晚些时候约翰·波尔科（John Porco）的实验室合成了修订后的结构并用 X 射线晶体学确认。合成样品与天然样品的对比——NMR、旋光、色谱——是证明的一部分。其二，**主张依赖每一步**，包括从文献借来的步（形式合成与接力合成便是），所以必须报告完整的实验细节与表征数据。步数与理想度是有用的度量，但一条无法重复的短合成，分量抵不过一条能重复的长合成。
:::

::: history
维勒（Wöhler）的尿素（1828）与赫尔曼·科尔贝（Hermann Kolbe）由二硫化碳合成乙酸（1845）证明有机化合物可由无机物制得；威廉·亨利·珀金（William Henry Perkin）1856 年尝试合成奎宁，却得到了染料苯胺紫（mauveine），开创了合成染料工业。埃米尔·费歇尔（Emil Fischer）1890 年前后合成了葡萄糖及其异构体（1902 年诺贝尔奖）；罗伯特·罗宾逊（Robert Robinson）关于生物碱与甾体的工作为他赢得 1947 年诺贝尔奖。罗伯特·伯恩斯·伍德沃德以奎宁（形式合成，1944，与多林格（Doering）合作）、胆固醇与可的松（1951）、利血平（1956）、叶绿素（1960）与维生素 B₁₂（与埃申莫瑟（Eschenmoser）合作，1972 年完成）等合成改造了这个领域，并于 1965 年获诺贝尔化学奖，"以表彰他在有机合成艺术上的卓越成就"。W. S. 约翰逊（Johnson）的仿生多烯环化（1960–70 年代）、E. J. 科里（Corey）系统化的逆合成分析以及前列腺素、银杏内酯等的合成（1990 年诺贝尔奖）、久松义人（Kishi）的 halichondrin 工作，以及霍顿（Holton）与尼科劳（Nicolaou）的紫杉醇合成（1994）标记了后来的里程碑。K. C. 尼科劳与埃里克·索伦森（Erik Sorensen）的《全合成经典》（*Classics in Total Synthesis*，1996），及其后续卷册（2003，与斯科特·斯奈德（Scott Snyder）；2011，与杰森·陈（Jason Chen）），记录了这些与许多其他合成。
:::

## 后续内容

全合成是这门课程汇合的地方：逆合成规划（[[organic-synthesis/retrosynthesis]]）、机理理解（[[organic-synthesis/mechanism-determination]]）、氧化还原与保护基战术、C–C 键形成、周环、立体选择性与自由基方法。它的方法直接流向药物化学——天然产物类似物在那里被制造与优化（[[medicinal-chemistry/structure-activity]]、[[medicinal-chemistry/drug-case-studies]]），也流向工艺化学——路线在那里为安全、成本与可持续性重新设计（[[green-chemistry/green-metrics]]、[[green-chemistry/chemical-industry]]）。计算规划与自动合成——科里 LHASA 程序的现代传人——正在改变找到路线的方式，但每一个方案仍须在烧瓶里验证。

::: summary
- 全合成证明并纠正结构，供应稀缺化合物与类似物，并驱动新反应的发明。
- 一条合成以步数、**最长线性序列**、沿 LLS 的总产率与**理想度** $= (n_\mathrm{c} + n_\mathrm{sr})/N$ 度量；物料需求按 $1/p^n$ 增长。
- 战略思想：汇聚式、构建复杂度的关键反应（狄尔斯-阿尔德、级联、$[3,3]$ 重排）、仿生步骤、对称性、预定的立体化学序列、最少保护与氧化还原经济、面向功能的设计。
- 伍德沃德的利血平把狄尔斯-阿尔德加合物当立体化学模板；科里的前列腺素合成以周环、重排、自由基与烯化步骤造出分支点中间体；约翰逊的黄体酮用由烯烃几何与椅式过渡态控制的仿生多烯级联。
- 形式合成与接力合成依赖先前的转化（奎宁，1944；2008 年确认）；紫杉醇的供应来自半合成，艾立布林则完全由合成生产。
- 每个主张都建立在合成与天然样品的匹配以及可重复的实验细节之上。
:::

## 练习

::: exercise 理想度 {level=1 check="66.7"}
一条 12 步合成有六步构造反应与两步战略性氧化还原。它的理想度是多少？（保留三位有效数字输入。）
::: solution
$(6 + 2)/12 \times 100 = 66.7\,\%$（[[#eq-ideality]]、[[#ex-ideality]]）。
:::
:::

::: exercise 最长线性序列 {level=1 check="12"}
碎片 A 需 7 步，碎片 B 需 9 步；一步偶联后，再经两步到达目标。LLS 是多少？（输入步数。）
::: solution
最长的分支是 B：$9 + 1 + 2 = 12$ 步（[[#def-lls]]）。总步数是 $7 + 9 + 1 + 2 = 19$。
:::
:::

::: exercise 沿 LLS 的总产率 {level=1 check="14.2"}
若一条 12 步最长线性序列的每一步都以 $85\,\%$ 产率进行，总产率是多少？（百分数保留三位有效数字输入。）
::: solution
$0.85^{12} = 0.142$，即 $14.2\,\%$。
:::
:::

::: exercise 物料倍率 {level=2 check="8.2"}
一条 20 步线性序列每步产率 $90\,\%$，每摩尔目标产物需要多少摩尔起始物料？（保留两位有效数字输入。）
::: solution
$1/0.9^{20} = 1/0.1216 = 8.2$。若换成同样每步产率、LLS 为 12 的汇聚式路线，每种碎片原料只需 $1/0.9^{12} = 3.5$ mol。
:::
:::

::: exercise 读懂科里的前列腺素路线 {level=2}
就科里前列腺素 F₂α 合成的下列各步，指出反应类别并说明它依赖的立体化学或化学选择性原理：(a) 与 2-氯丙烯腈的狄尔斯-阿尔德反应；(b) 拜耳-维利格氧化；(c) 碘内酯化；(d) HWE 反应；(e) 接上侧链的维蒂希反应。
::: solution
(a) $[4+2]$ 环加成：同面加成决定双环骨架的相对构型；2-氯丙烯腈充当酮等价物（酮烯自身给 [2+2] 加合物）。(b) 拜耳-维利格：取代较多（仲、桥头）的碳带构型迁移，区域选择性插入 O。(c) 亲电环化：碘在烯烃一面生成碘鎓离子，羧酸根从对面进攻（*anti* 加成），形成立体化学确定的五元内酯。(d) 与稳定化膦酸酯的 HWE 烯化：得 (*E*)-烯酮。(e) 无盐条件下与不稳定化叶立德的维蒂希反应：得 (*Z*)-烯烃，与天然前列腺素一致（[[organic-synthesis/carbon-carbon-bonds]]）。
:::
:::

::: exercise 形式合成 {level=2}
以奎宁为例说明全合成、形式合成与接力合成的区别，并说明史密斯与威廉姆斯 2008 年的工作为何重要。
::: solution
**全合成**从商品原料到目标，每一步都实际完成（或至少有描述且可重复）。**形式合成**到达一个已被他人转化为目标的已知中间体，其余步骤依赖对方的报道。**接力合成**使用降解天然产物所得的中间体，以检验或完成后续步骤。伍德沃德与多林格 1944 年的工作到达奎宁托辛，依赖拉贝与金德勒 1918 年把奎宁托辛转化为奎宁的转化——这是形式合成。由于 1918 年的描述简略、几十年无人重复，斯特克（2001）质疑这条路线是否真的走通过。史密斯与威廉姆斯重复了拉贝-金德勒序列并得到奎宁，表明那次形式合成是成立的。这段公案说明：形式合成的可靠程度，只与它所依赖的文献步骤一样。
:::
:::

::: exercise 一个两步萜合成 {level=3}
更细致地分析[[#ex-terpineol]]中 α-萜品醇的合成：(a) 用前线轨道系数解释狄尔斯-阿尔德步的区域化学；(b) 解释为什么恰好消耗两当量（实践中稍过量）的 $\mathrm{CH_3MgBr}$；(c) 提出如何以单一对映体得到产物。
::: hint
异戊二烯的哪个碳带最大的 HOMO 系数？
:::
::: solution
(a) 异戊二烯 C2 上的甲基供体抬高 HOMO 并增大其 C1（邻近取代碳的末端）系数。丙烯酸甲酯的 LUMO 最大系数在 β-碳（末端 $\mathrm{CH_2}$）上。这两个原子之间的成键把带酯基的碳放到二烯 C4 的旁边，于是产物环中带甲基的烯碳与带酯基的碳处于 1,4——"*对位*"产物，4-甲基环己-3-烯-1-甲酸甲酯（[[organic-synthesis/pericyclic]]）。路易斯酸能放大 LUMO 系数差，从而提高选择性。(b) 第一当量加到酯上，四面体中间体顶出甲氧基，得甲基酮；酮比酯亲电性更强，消耗第二当量得叔醇盐。任何酸性杂质（水、醇）都会额外消耗试剂，所以要用稍过量的量。(c) 选择：不对称狄尔斯-阿尔德反应，用手性路易斯酸催化剂，或在丙烯酸酯上装手性辅基（埃文斯噁唑烷酮丙烯酰胺，事后除去——不过那时格氏步就要用在相应的酯上）；或用脂肪酶或形成非对映体盐结晶对外消旋 α-萜品醇（或中间体酸）做动力学拆分（[[organic-synthesis/stereoselective-synthesis]]）。
:::
:::

::: exercise 带数字的汇聚式规划 {level=3 check="0.149"}
碎片 A 用 8 步、每步 $85\,\%$ 制备；碎片 B 用 5 步、每步 $90\,\%$。两者以 $75\,\%$ 产率偶联，再经三步各 $90\,\%$ 完成目标。计算以碎片 A 的原料计的总产率，并与以 B 的原料计的产率比较。你会先设法改进哪条碎片路线，为什么？（以 A 计的总产率以分数输入，保留三位有效数字。）
::: solution
以 A 计：$0.85^8 \times 0.75 \times 0.90^3 = 0.2725 \times 0.75 \times 0.729 = 0.149$。以 B 计：$0.90^5 \times 0.75 \times 0.90^3 = 0.5905 \times 0.75 \times 0.729 = 0.323$。碎片 A 的分支既是最长也是产率最低的：它决定 LLS（12 步），每摩尔目标需其原料 $1/0.149 = 6.7$ mol，而 B 只需 $3.1$ mol。改进 A——提高它的每步产率、缩短它，或重新分配复杂度、把 A 的一些步移入 B——收益最大。偶联步（75 %）为两个分支所共有，同样是首要目标，因为对它的每一点改进都同时惠及双方。
:::
