香芹酮（carvone）的两个对映体熔点相同、NMR 谱相同、对非手性试剂的反应性也相同，然而 (*R*)-香芹酮是留兰香的气味，(*S*)-香芹酮是葛缕子的气味。我们的鼻子和酶、受体一样是手性的，分得清对映体。药物也一样：一种手性药物的两个对映体往往 potency……药效强度、代谢和副作用都不同；自 1990 年代以来，监管机构要求对新手性药物的每一个对映体都做出表征，实践中这意味着大多数手性药物都以单一对映体开发。左旋多巴（L-DOPA，治帕金森病）、β-受体阻滞剂与"他汀"类药物都是例子。有选择地制造一种立体异构体——**立体选择性合成**——因此是现代有机化学的中心任务之一。

前几章的反应会创造立体中心：加到 C=O 上、烯醇负离子烷基化、羟醛反应、狄尔斯-阿尔德反应与 $[3,3]$ 重排。本章问的是如何控制*生成哪一种*立体异构体。我们先看选择性的度量以及它们对应的能量差。然后看由底物中已有立体中心控制的**非对映选择性**反应（Felkin–Anh 模型与螯合模型、环的立体控制、Zimmerman–Traxler 羟醛），以及引入手性的四种途径：**手性池**、**手性辅基**、**手性试剂**与**不对称催化**。最后讲**动力学拆分**：有选择地消耗外消旋体中的一个对映体。立体化学词汇（*R*/*S*、对映体、非对映体）见[[organic-1/stereochemistry]]。

## 选择性的度量与解释 {#sec-measures}

::: definition 对映体过量与非对映体过量 {#def-ee}
对于摩尔分数为 $x_R$ 与 $x_S$ 的对映体混合物，**对映体过量**为
$$
\mathrm{ee} = \frac{\lvert x_R - x_S\rvert}{x_R + x_S},
$$
通常以百分数表示；**对映体比**（er）为 $x_R : x_S$。外消旋体 $\mathrm{ee} = 0$，单一对映体 $\mathrm{ee} = 100\,\%$，且 $\mathrm{er} = (1 + \mathrm{ee}) : (1 - \mathrm{ee})$。一对非对映体的**非对映体过量**（de）与**非对映体比**（dr）定义类似。一个反应若优先生成某一种立体异构体而胜过其余，它是**立体选择性**的；若立体异构不同的起始原料按机理必然给出立体异构不同的产物，它是**立体专一**的（如 $\mathrm{S_N2}$ 构型翻转或同面狄尔斯-阿尔德加成）。
:::

对映体过量用手性固定相色谱（HPLC 或 GC）、在手性溶剂化试剂或手性衍生化试剂存在下测 NMR（后者把对映体变成可区分的非对映体）、或——较不可靠地——由旋光度与纯对映体的旋光度比较测得。

::: proposition 由活化能差求对映体过量 {#prop-ee}
若两个对映体（或非对映体）产物由共同起点经吉布斯自由能相差 $\Delta\Delta G^\ddagger$ 的两个过渡态不可逆地生成，则在动力学控制下
$$
\mathrm{er} = \exp\!\left(\frac{\Delta\Delta G^\ddagger}{RT}\right), \qquad \mathrm{ee} = \tanh\!\left(\frac{\Delta\Delta G^\ddagger}{2RT}\right).
$$ {#eq-ee}
:::

::: proof
由过渡态理论（[[organic-synthesis/carbon-carbon-bonds#prop-control]]），速率之比即产物之比为 $e^{\Delta\Delta G^\ddagger/RT}$；记作 $r$。则 $\mathrm{ee} = (r - 1)/(r + 1)$。写 $r = e^{2u}$，其中 $u = \Delta\Delta G^\ddagger/2RT$，则 $\mathrm{ee} = (e^{2u} - 1)/(e^{2u} + 1) = (e^{u} - e^{-u})/(e^{u} + e^{-u}) = \tanh u$。$\blacksquare$
:::

:::

::: example 一个 ee 对应多大能量？ {#ex-ee-energy}
一次不对称还原在 $-78\ ^\circ\mathrm{C}$ 给出 95:5 的 (*R*)-醇。(a) ee 是多少？(b) $\Delta\Delta G^\ddagger$ 是多少？(c) 若 $\Delta\Delta G^\ddagger$ 在 $25\ ^\circ\mathrm{C}$ 下不变，会得到什么比值？
::: solution
(a) $\mathrm{ee} = (95 - 5)/(95 + 5) = 90\,\%$。(b) $\Delta\Delta G^\ddagger = RT\ln(95/5) = 8.314 \times 195.15 \times \ln 19\ \mathrm{J\,mol^{-1}} = 8.314 \times 195.15 \times 2.944 = 4.78\ \mathrm{kJ\,mol^{-1}}$。(c) 在 $298.15\ \mathrm{K}$，$\mathrm{er} = \exp(4778/(8.314 \times 298.15)) = \exp(1.927) = 6.9$，即约 87:13（$75\,\%$ ee）。降温是提高选择性的廉价手段，代价是速率。（实际上 $\Delta\Delta G^\ddagger$ 会随温度改变，因为 $\Delta\Delta H^\ddagger$ 与 $\Delta\Delta S^\ddagger$ 的贡献不同；有时选择性甚至会在某个"等转化温度"处反转。）
:::
:::

## 底物控制：非对映选择性反应 {#sec-substrate}

当分子中已经含有一个立体中心时，反应基团附近的两个面就是非对映异位的，试剂以不同速率进攻它们。

### 立体中心旁羰基的加成

与带大（L）、中（M）、小（S）取代基的立体中心相邻的羰基，会被优先从一个面进攻。唐纳德·克拉姆（Donald Cram）1952 年提出过一条规则；如今使用的模型是马克·谢雷（Marc Chérest）与休·费尔金（Hugh Felkin）（1968）提出的，并经阮成安（Nguyen Trong Anh）与奥迪尔·艾森斯坦（Odile Eisenstein）（1977）改进。

::: algorithm Felkin–Anh 模型 {#alg-felkin}
1. **摆好立体中心**，使其最大的基团 L（或 C–X σ* 轨道能最低的那个基团——OR、Cl 这类电负性取代基，即"极性 Felkin–Anh"情形）与羰基平面**垂直**。
2. **让亲核试剂从 L 的反面进攻**，沿比尔吉-杜尼茨（Bürgi–Dunitz）轨迹——与 C=O 键约成 $107^\circ$，即避开氧、朝 α-碳上方斜着进来。与生成键处于反式的 C–L 键的 σ* 轨道会降低过渡态的能量。
3. **在 L 垂直的两种构象中，选亲核试剂从基团 S 一侧通过的那一种**（另一个基团 M 于是处于与羰基氧邻位交叉的位置）。
4. **读出产物**——把亲核试剂加在那个面上。若该取代基能与羰基氧一起螯合金属（α- 或 β-烷氧基与 $\mathrm{Mg^{2+}}$、$\mathrm{Zn^{2+}}$、$\mathrm{Ti^{4+}}$），就改用**螯合模型**（克拉姆环式模型）：螯合环锁住构象，亲核试剂从剩下的较大取代基的对面进攻，常常给出相反的非对映体。
:::

::: example Felkin–Anh 控制与螯合控制 {#ex-felkin}
预测下列反应的主产物：(a) (*S*)-2-苯基丙醛与甲基溴化镁；(b) 一个 2-苄氧基酮 $\mathrm{BnO{-}CH(CH_3){-}CO{-}CH_3}$ 与格氏试剂在螯合性金属存在下反应，并与位阻大的硅基保护类似物 $\mathrm{TBSO{-}CH(CH_3){-}CO{-}CH_3}$ 比较。
::: solution
(a) L = 苯基，M = 甲基，S = H。把 Ph 摆在与 C=O 平面垂直处；甲基从 Ph 的反面加成，从氢的一侧通过，立体中心的甲基与氧处于邻位交叉。搭建这一几何并指定 CIP 次序（新中心处 OH > CH(Ph)CH₃ 碳 > CH₃ > H；旧中心处 CH(OH)CH₃ > Ph > CH₃ > H）给出 **(2*S*,3*S*)-3-苯基丁-2-醇** 为主（Felkin）产物，选择性中等，格氏加成通常 2–3:1。亲核试剂更位阻、温度更低，选择性更高。

(b) 用苄基醚时，镁可同时结合羰基氧与醚氧形成五元螯合物；此时立体中心上的甲基遮住一个面，亲核试剂从另一个面进攻：**螯合控制**，比值常常超过 10:1。用体积大的 TBS 醚时，螯合被阻止（硅醚是弱路易斯碱，且硅基很大），适用极性 Felkin–Anh 模型：C–O 键与羰基平面垂直并处于亲核试剂的反面。于是两个保护基导向**相反**的非对映体——保护基被当作立体控制元件使用（[[organic-synthesis/protecting-groups#warn-pg]]）。
:::
:::

### 环的立体控制

环让两个面一目了然。氢化物加到 4-*叔*丁基环己-1-酮上（*叔*丁基锁定椅式构象）可以从**直立**面发生，给出平伏醇（*trans*），也可以从**平伏**面发生，给出直立醇（*cis*）。小的氢化物试剂如 $\mathrm{LiAlH_4}$ 与 $\mathrm{NaBH_4}$ 偏好直立进攻（*trans* 约 9:1），因为平伏方向接近时，新键生成之际会与相邻的直立 C–H 键产生扭转张力。位阻大的试剂如 L-Selectride（$\mathrm{LiBH(}s\mathrm{Bu)_3}$）无法越过 C3 与 C5 上的直立氢，从平伏方向进攻，主要给出 *cis*（直立）醇，通常超过 90:10。试剂的大小就这样在同一分子的两个非对映体之间做选择。类似的推理——从折叠双环分子的凸面进攻——控制着多环天然产物合成的相当一部分立体化学。

### 羟醛反应：Zimmerman–Traxler 模型

当 α-碳带取代基的烯醇负离子加到醛上时，生成两个新立体中心，得到 *syn* 与 *anti* 非对映体（相对按锯齿形画出的主链而言）。霍华德·齐默尔曼（Howard Zimmerman）与玛丽乔·特拉克勒（Marjorie Traxler）（1957）提出，金属烯醇负离子经一个**六元椅式过渡态**反应，其中金属同时结合烯醇负离子氧与醛氧。

::: proposition 烯醇负离子几何与羟醛相对构型（Zimmerman–Traxler） {#prop-zt}
对于经闭椅式六元过渡态（醛取代基取平伏位）进行的金属烯醇负离子羟醛反应，(*Z*)-烯醇负离子给出 *syn* 羟醛，(*E*)-烯醇负离子给出 *anti* 羟醛。这一对应关系对硼烯醇负离子最强（其短 B–O 键给出紧凑的过渡态），对锂烯醇负离子较弱；对经开放过渡态进行的反应则失效（路易斯酸介导的向山羟醛反应）。
:::

::: proof 论证
在椅式过渡态中，烯醇负离子的 C=C 与醛的 C=O 构成 C1–O（连金属）、C2=C3 与 C3–C4（生成中）几根键；醛的取代基 R 取伪平伏位，以避免与金属配体的 1,3-二直立相互作用。烯醇负离子的 α-取代基（在 C2 上）由烯醇负离子几何固定：在 (*Z*)-烯醇负离子中它与 O–金属键处于 *cis*，占据的位置在成键后使它落在锯齿形主链上与新 OH 同一侧：*syn*。在 (*E*)-烯醇负离子中它与 O–金属处于 *trans*，最终落在另一侧，产物为 *anti*。由于烯醇负离子的几何经由一个刚性椅式传递，产物的相对构型由机理决定，而非由热力学决定。$\blacksquare$
:::

烯醇负离子几何本身也可以控制：酮与三氟甲磺酸二丁基硼加一个位阻胺给出 (*Z*)-硼烯醇负离子，而二环己基氯化硼与三乙胺给出 (*E*)-烯醇负离子；氨基锂碱在 THF 中主要给出 (*E*)-酯烯醇负离子，在 HMPA 或 DMPU 存在下则给出 (*Z*)（罗伯特·爱尔兰（Robert Ireland）的模型）。把烯醇负离子控制与手性辅基或催化剂结合，就同时控制了绝对构型。

## 引入手性：四种策略 {#sec-strategies}

底物控制把已有的手性转化为新的立体中心；它无法从非手性原料创造手性。为此我们需要手性来源：手性池、辅基、试剂或催化剂。

### 手性池

大自然提供了许多廉价的光学纯化合物：氨基酸、糖、羟基酸（乳酸、苹果酸、酒石酸）、萜（薄荷醇、香芹酮、樟脑、蒎烯）与生物碱。从其中一种出发的合成"借用"了它的立体中心。抗流感药奥司他韦的经典路线从 (−)-莽草酸出发；许多聚酮合成从 (*S*)-乳酸酯或 (*R*)-3-羟基丁酸酯出发。局限在于目标的立体中心必须能映射到某种现成天然化合物的立体中心上，而且常常只有一个对映体是廉价的。

### 手性辅基

**手性辅基**是一个光学纯的基团，临时连到底物上以控制某个反应的立体化学，随后被除去并最好能回收。除去之前的产物是非对映体，所以即使选择性不完美，也能用普通色谱或结晶分离——一个决定性的实用优势。最著名的辅基是大卫·埃文斯（David Evans）的**噁唑烷-2-酮**（1981–82），由缬氨酸或苯丙氨酸衍生的氨基醇制得。*N*-酰基噁唑烷-2-酮去质子化（LDA 或 NaHMDS）给出与金属螯合的 (*Z*)-烯醇负离子；噁唑烷酮 C4 上的取代基（异丙基或苄基）挡住一个面，卤代烷从另一个面接近。用三氟甲磺酸二丁基硼时，同样的辅基给出"埃文斯 *syn*"羟醛，选择性极高。辅基的除去可经水解（氢过氧化锂，它有选择地进攻环外羰基）、还原（成醇）或转化为韦恩雷布（Weinreb）酰胺。

::: example 一次埃文斯烷基化 {#ex-evans}
用埃文斯辅基勾画出 (*R*)-2-甲基-3-苯基丙酸的合成，并指出每一个立体化学决定是在哪一步做出的。
::: solution
(1) **酰化**：(*S*)-4-苄基噁唑烷-2-酮在 N 上去质子化（丁基锂），再用丙酰氯酰化：得到 N-丙酰基噁唑烷酮。(2) **烯醇化**：NaHMDS、$-78\ ^\circ\mathrm{C}$，生成 (*Z*)-烯醇负离子，经 Na 在烯醇负离子氧与噁唑烷酮羰基氧之间螯合，这固定了辅基的取向。(3) **烷基化**：溴化苄从远离 C4 苄基的烯醇负离子一面接近；烯醇负离子的碳进攻苄位碳（$\mathrm{S_N2}$），顶出溴离子。非对映选择性通常高于 95:5——立体化学决定就是在这里、由辅基的 C4 立体中心做出的。少数非对映体可用色谱除去，得到 de 本质上 100 % 的物料。(4) **裂解**：含水 THF 中的 LiOH/$\mathrm{H_2O_2}$——氢过氧负离子进攻环外酰基羰基（比氨甲酸酯的更具亲电性、位阻更小），把噁唑烷酮氮负离子赶出去，过氧酸在后处理中被还原为酸——得到 (*R*)-2-甲基-3-苯基丙酸并回收辅基。这办法的代价是两步额外的操作（接上与拆下）和一当量手性化合物；它的优点是可靠，以及非对映体可以分离。
:::
:::

### 手性试剂与不对称催化

**手性试剂**把手性带在试剂自身里——例如赫伯特·C. 布朗（Herbert C. Brown）的二异蒎烷基硼烷，由 (+)- 或 (−)-α-蒎烯制得，用于不对称硼氢化与烯丙基化。**不对称催化**只用手性催化剂的亚化学计量用量，每个催化剂分子造出许多分子手性产物：制造单一对映体最经济的方式。里程碑式的方法包括：

- **不对称氢化。** 威廉·诺尔斯（William Knowles）的手性双膦 DIPAMP 的铑配合物，自 1970 年代起被孟山都公司用于氢化烯酰胺前体生产 L-DOPA，ee 约 95 %。野依良治（Noyori）的钌–BINAP 催化剂（1980 年代）氢化功能化烯烃与酮；β-酮酯给出 ee 超过 99 % 的 β-羟基酯（3-氧代丁酸甲酯用 (*R*)-BINAP–Ru 催化剂得 (*R*)-3-羟基丁酸甲酯）。机理与配体见[[organometallics-catalysis/hydrogenation-hydroformylation]]。
- **夏普莱斯（Sharpless）不对称环氧化**（胜木（Tsutomu Katsuki）与 K. 巴里·夏普莱斯（K. Barry Sharpless），1980）。烯丙醇以叔丁基过氧化氢、钛(IV)异丙氧化物与一种光学纯酒石酸二乙酯（DET）环氧化。烯丙醇结合到钛上，酒石酸把氧的递送引导到一个面上。一个助记法：把烯丙醇画成竖直的烯烃、$\mathrm{CH_2OH}$ 在右下方；L-(+)-DET 从下面递氧，D-(−)-DET 从上面。有分子筛时，反应在钛与酒石酸上是催化的（5–10 mol %）。
- **夏普莱斯不对称双羟基化**（1988 年起）：催化量 $\mathrm{OsO_4}$ 搭配源自金鸡纳生物碱的配体（以 AD-mix-α 与 AD-mix-β 出售，铁氰化钾作共氧化剂），适用于几乎所有烯烃取代模式。
- **Corey–Bakshi–Shibata（CBS）还原**（1987）：酮被硼烷还原，用源自脯氨酸的催化量噁唑硼烷；催化剂的氮结合硼烷，其硼在较小取代基那一侧结合酮的氧，经六元过渡态分子内递送氢负离子。
- **有机催化。** 小的手性有机分子不用金属就能催化对映选择性反应。(S)-脯氨酸催化分子内羟醛反应（Hajos–Parrish–Eder–Sauer–Wiechert 反应，1971，它不对称地给出[[organic-synthesis/retrosynthesis#ex-wieland-miescher]]的维兰德-米歇尔酮），并且——本杰明·利斯特（Benjamin List）、理查德·勒纳（Richard Lerner）与卡洛斯·巴尔巴斯（Carlos Barbas）2000 年证明——经烯胺中间体催化分子间羟醛；戴维·麦克米伦（David MacMillan）的咪唑烷酮（2000）经亚胺离子催化狄尔斯-阿尔德反应，降低烯醛的 LUMO。
- **生物催化。** 改造过的酶——酮还原酶、转氨酶、脂肪酶——在温和含水条件下给出极高的 ee。在降糖药西格列汀的生产中，一支改造过的转氨酶（默沙东与 Codexis，2010）取代了铑催化的不对称氢化。

::: example 一次夏普莱斯环氧化 {#ex-sharpless}
香叶醇，(*E*)-3,7-二甲基辛-2,6-二烯-1-醇，用 $\mathrm{Ti(O}i\mathrm{Pr)_4}$、L-(+)-酒石酸二乙酯与叔丁基过氧化氢在 4 Å 分子筛存在下于 $-20\ ^\circ\mathrm{C}$ 反应。哪个烯烃反应，生成什么产物，反应为什么是催化的？
::: solution
**化学选择性。** 只有烯丙位的 2,3-双键反应：醇与钛结合（置换掉异丙氧基），结合在同一个钛上的过氧化物把自己的氧分子内递送给最近的烯烃，正如[[organic-synthesis/redox-in-synthesis]]中钒催化的反应。远处 6,7-位的烯烃原封不动。

**对映选择性。** 钛–酒石酸配合物是一个二聚体，酒石酸的酯基挡住所结合烯丙醇的一个面。用 L-(+)-DET 时产物是 **(2*S*,3*S*)-2,3-环氧香叶醇**，ee 通常高于 90 %。

**催化。** 水会水解钛–酒石酸配合物并终止循环；分子筛把水除去，使 5–10 mol % 的钛与酒石酸得以周转多次（Gao、夏普莱斯与合作者，1987）。浓的有机过氧化物是危险的氧化剂；叔丁基过氧化氢以商品溶液使用，该反应需要风险评估与监督。
:::
:::

## 动力学拆分 {#sec-resolution}

若一个手性催化剂或试剂与外消旋体中一个对映体的反应快于另一个，未反应的起始原料就在反应较慢的对映体上富集。

::: proposition 动力学拆分（卡根（Kagan）） {#prop-kr}
设外消旋底物的两个对映体按一级（或准一级）过程反应，速率常数为 $k_\mathrm{fast}$ 与 $k_\mathrm{slow}$，定义**选择性因子** $s = k_\mathrm{fast}/k_\mathrm{slow}$。在转化率 $c$（全部底物中被消耗的分数）处，剩余底物的对映体过量 $\mathrm{ee_{SM}}$ 满足
$$
s = \frac{\ln\!\big[(1 - c)(1 - \mathrm{ee_{SM}})\big]}{\ln\!\big[(1 - c)(1 + \mathrm{ee_{SM}})\big]}.
$$ {#eq-kagan}
拆分所得起始原料的最大产率是 $50\,\%$，且只有在 $s \to \infty$ 的极限下才趋近它。
:::

::: proof
从等量出发，各归一化为 $\tfrac12$。经时间 $t$ 后剩余分数为 $u_\mathrm{f} = e^{-k_\mathrm{fast}t}$ 与 $u_\mathrm{s} = e^{-k_\mathrm{slow}t}$，于是 $u_\mathrm{f} = u_\mathrm{s}^{\,s}$。剩余底物量为 $1 - c = \tfrac12(u_\mathrm{f} + u_\mathrm{s})$，其过量 $\mathrm{ee_{SM}} = (u_\mathrm{s} - u_\mathrm{f})/(u_\mathrm{s} + u_\mathrm{f})$。于是 $(1 - c)(1 + \mathrm{ee_{SM}}) = \tfrac12(u_\mathrm{s} + u_\mathrm{f}) \times 2u_\mathrm{s}/(u_\mathrm{s} + u_\mathrm{f}) = u_\mathrm{s}$，同理 $(1 - c)(1 - \mathrm{ee_{SM}}) = u_\mathrm{f}$。取对数，$\ln u_\mathrm{f} = s\ln u_\mathrm{s}$ 即[[#eq-kagan]]。由于慢的对映体至多占底物的一半，至多有 $50\,\%$ 的起始原料能以光学纯回收，而且只能在慢对映体一点都没反应的极限下达到。$\blacksquare$
:::

::: widget parametric
fx: 100*(1 - (t + t^s)/2)
fy: 100*(t - t^s)/(t + t^s)
t: 0.0001, 1
x: 0, 100
y: 0, 100
sliders: s=20:1.5:200:0.5
trace: false
equal: false
caption: 动力学拆分：剩余起始原料的对映体过量（纵轴，%）对转化率（横轴，%），选择性因子为 $s$（[[#eq-kagan]]），以慢对映体剩余分数 $t$ 为参数描出。$s = 20$ 时，$62\,\%$ 转化率处达到 $99\,\%$ ee，剩下至多 $38\,\%$ 的物料；$s = 200$ 时在略超 $50\,\%$ 处达到。$s = 5$ 时必须消耗掉大部分物料才能达到高 ee。由于*起始原料*的 ee 在终点附近陡升，即使中等选择性因子也能交付光学纯的回收物料——代价是产率。动态动力学拆分——使起始原料在反应条件下迅速消旋——可以打破 $50\,\%$ 的上限。
:::

::: example 动力学拆分该做到多深 {#ex-kr}
某脂肪酶以 $s = 20$ 酰化一个外消旋仲醇的 (*R*)-对映体。(a) $50\,\%$ 转化率时，剩余 (*S*)-醇的 ee 是多少？(b) 达到 $99\,\%$ ee 时转化率是多大，此时 (*S*)-醇的最大产率是多少？
::: solution
利用证明中的参数化：$u_\mathrm{f} = u_\mathrm{s}^{20}$，$1 - c = \tfrac12(u_\mathrm{s} + u_\mathrm{f})$，$\mathrm{ee} = (u_\mathrm{s} - u_\mathrm{f})/(u_\mathrm{s} + u_\mathrm{f})$，数值求解。

(a) $c = 0.50$ 要求 $u_\mathrm{s} + u_\mathrm{s}^{20} = 1.00$；解得 $u_\mathrm{s} = 0.894$，$u_\mathrm{f} = 0.106$，故 $\mathrm{ee_{SM}} = 0.788/1.000 = 79\,\%$。

(b) $\mathrm{ee} = 0.99$ 要求 $u_\mathrm{f}/u_\mathrm{s} = u_\mathrm{s}^{19} = 0.01/1.99 = 0.00503$，于是 $u_\mathrm{s} = 0.00503^{1/19} = 0.757$，$u_\mathrm{f} = 0.0038$，且 $1 - c = \tfrac12(0.757 + 0.0038) = 0.380$。转化率须达到 $62\,\%$；至多有 $38\,\%$ 的外消旋体以 $99\,\%$ ee 的 (*S*)-醇回收（占原来 (*S*)-对映体的 76 %）。生成的酯在 (*R*)-对映体上富集，但由于它从反应一开始就在生成，其 ee 较低。用[[#eq-kagan]]验证：$\ln(0.380 \times 0.01)/\ln(0.380 \times 1.99) = \ln 0.0038/\ln 0.756 = -5.57/-0.279 = 20$。
:::
:::

::: quiz
关于立体选择性合成，哪些说法是正确的？
- [x] 298 K 下 90 % ee 的产物对应两个竞争过渡态之间约 7.3 kJ mol⁻¹ 的差。
- [x] 用手性辅基得到的产物在除去辅基之前是非对映体，所以可以用普通色谱分离。
- [ ] 动力学拆分中，只要 $s$ 足够大，拆分所得起始原料最多可以 100 % 的产率回收。
- [ ] (*Z*)-硼烯醇负离子经 Zimmerman–Traxler 椅式主要给出 *anti* 羟醛。
::: solution
95:5（90 % ee）对应 $\Delta\Delta G^\ddagger = RT\ln 19 = 7.3\ \mathrm{kJ\,mol^{-1}}$。连在辅基上的产物是非对映体，故可分离。动力学拆分至多把外消旋体的 50 % 交付为单一对映体（除非底物消旋化：动态动力学拆分）。(*Z*)-烯醇负离子给出 *syn* 羟醛（[[#prop-zt]]）。
:::
:::

::: warning 旋光度不是纯度的度量 {#warn-rotation}
人们很想用测得的比旋光度与纯对映体的文献值比较来确定 ee。这不可靠：旋光度数值小，对浓度、溶剂、温度与波长都敏感；少量强旋光的杂质就能占尽风光；旋光度与 ee 的关系并不总是线性（霍罗（Horeau）效应）；而"纯"对映体的文献值后来常常被证明其实指的是不纯的样品。请用分离方法（手性 HPLC 或 GC）或用带手性衍生化试剂的 NMR 确定 ee，并以外消旋体作对照，使两个对映体都能被看到。类似地，不要把*相对*构型（哪一种非对映体）与*绝对*构型（哪一个对映体）混为一谈：对外消旋底物做非对映选择性反应，得到的是外消旋产物。
:::

::: history
路易·巴斯德（Louis Pasteur）1848 年手工分离了酒石酸铵钠的对映体晶体，1857 年又发现微生物有选择地消耗其中一个对映体——第一次动力学拆分。埃米尔·费歇尔（Emil Fischer）1890 年代关于糖的工作引入了由既有立体中心出发的不对称诱导；唐纳德·克拉姆（Cram）的规则（1952）、休·费尔金（Felkin）的模型（1968）与安（Anh）、艾森斯坦（Eisenstein）的轨道改进（1977）使之可以预测。齐默尔曼（Zimmerman）与特拉克勒（Traxler）关于羟醛的椅式模型发表于 1957 年。戴维·埃文斯（Evans）1981 年引入噁唑烷酮辅基。催化不对称氢化由威廉·诺尔斯（Knowles）（孟山都的 L-DOPA 工艺，1970 年代）与野依良治（Noyori）（Ru–BINAP，1980 年代）开创；胜木（Katsuki）与巴里·夏普莱斯（Sharpless）1980 年报道了不对称环氧化；诺尔斯、野依与夏普莱斯分享了 2001 年诺贝尔化学奖。佐尔坦·豪约斯（Zoltan Hajos）与戴维·帕里什（David Parrish），以及独立地乌尔里希·埃德尔（Ulrich Eder）、格哈德·绍尔（Gerhard Sauer）与鲁道夫·维歇特（Rudolf Wiechert），1971 年报道了脯氨酸催化的不对称羟醛环化；2000 年本杰明·利斯特（List）与戴维·麦克米伦（MacMillan）的工作之后，有机催化成为一种通用方法，并获 2021 年诺贝尔奖认可。
:::

## 后续内容

本章的立体控制方法是[[organic-synthesis/total-synthesis]]的骨架：在那里，各个立体中心按什么次序、用哪种方法设定，往往就是战略本身。不对称氢化背后的有机金属机理见[[organometallics-catalysis/hydrogenation-hydroformylation]]；单一对映体在药物作用与开发中的作用见[[medicinal-chemistry/drug-binding]]与[[medicinal-chemistry/drug-development]]。酶——大自然的手性催化剂——见[[biochemistry/enzymes]]。

::: summary
- $\mathrm{ee} = \lvert x_R - x_S\rvert/(x_R + x_S)$；动力学控制下 $\mathrm{er} = e^{\Delta\Delta G^\ddagger/RT}$、$\mathrm{ee} = \tanh(\Delta\Delta G^\ddagger/2RT)$：298 K 下 90 % ee 需要 7.3、99 % ee 需要 13.1 kJ mol⁻¹。
- Felkin–Anh：L 与 C=O 垂直，亲核试剂沿比尔吉-杜尼茨轨迹从 L 的反面进攻、从 S 一侧通过；能螯合的 α-烷氧基会反转选择性（螯合控制）。
- 环己酮：小氢化物直立进攻（平伏 OH），大氢化物平伏进攻（直立 OH）。
- Zimmerman–Traxler：(*Z*)-烯醇负离子 → *syn* 羟醛，(*E*)-烯醇负离子 → *anti*，经椅式过渡态（硼最好）。
- 手性来源：手性池、辅基（埃文斯噁唑烷酮；非对映体可分离）、手性试剂，以及不对称催化（野依氢化、夏普莱斯环氧化与双羟基化、CBS 还原、有机催化、酶）。
- 动力学拆分：$s = \ln[(1-c)(1-\mathrm{ee})]/\ln[(1-c)(1+\mathrm{ee})]$；除非底物消旋化（动态动力学拆分），至多 50 % 产率得到单一对映体。
:::

## 练习

::: exercise 由比值到 ee {level=1 check="94"}
一个不对称反应以 97:3 给出两个对映体。ee 是多少？（以百分数输入。）
::: solution
$(97 - 3)/(97 + 3) = 0.94 = 94\,\%$（[[#def-ee]]）。
:::
:::

::: exercise 90 % ee 需要的能量 {level=1 check="7.3"}
在 $298.15\ \mathrm{K}$ 达到 $90\,\%$ ee 需要多大的活化吉布斯自由能差？（以 $\mathrm{kJ\,mol^{-1}}$ 输入，保留两位有效数字。）
::: solution
90 % ee 意味着 er = 95:5 = 19。$\Delta\Delta G^\ddagger = RT\ln 19 = 8.314 \times 298.15 \times 2.944 = 7.3\ \mathrm{kJ\,mol^{-1}}$（[[#eq-ee]]）。
:::
:::

::: exercise 直立还是平伏？ {level=1}
预测 4-*叔*丁基环己-1-酮被 (a) $\mathrm{NaBH_4}$ 与 (b) L-Selectride 还原的主非对映体，并解释。
::: solution
(a) 小的硼氢化物做直立进攻（平伏方向接近会与相邻直立 C–H 键产生扭转张力），给出平伏醇：***trans*-4-*叔*丁基环己-1-醇**。(b) 位阻大的三烷基硼氢化物被 C3 与 C5 上的直立氢挡住直立面，从平伏方向进攻，给出直立醇：***cis*-4-*叔*丁基环己-1-醇**。
:::
:::

::: exercise 靠降温换选择性 {level=2 check="99.6"}
某催化剂以与温度无关的 $\Delta\Delta G^\ddagger = 10.0\ \mathrm{kJ\,mol^{-1}}$ 区分两个过渡态。在 $195.15\ \mathrm{K}$ 得到多少 ee？（ee 以百分数输入，保留三位有效数字。）
::: solution
$\mathrm{ee} = \tanh(10\,000/(2 \times 8.314 \times 195.15)) = \tanh(3.082) = 0.996$，即 $99.6\,\%$。在 $298.15\ \mathrm{K}$，同一催化剂给出 $\tanh(2.017) = 96.5\,\%$。
:::
:::

::: exercise Felkin 还是螯合？ {level=2}
一个 α-甲氧基醛要用格氏试剂处理。解释 (a) 添加 $\mathrm{MgBr_2}$ 或以 $\mathrm{TiCl_4}$ 作添加剂，与 (b) 把甲氧基换成 TBDPS 醚，这两种选择如何能给出相反的非对映体。
::: solution
(a) 使用螯合性金属时，醛氧与甲氧基氧结合金属成五元环；构象被锁定为 C–OMe 键与 C=O 大致重叠式，亲核试剂从 α-取代基的对面进攻（螯合控制）。(b) TBDPS 醚太位阻、碱性太弱，无法螯合，于是适用极性 Felkin–Anh 模型：C–O 键摆在与羰基垂直、处于亲核试剂反面的位置，亲核试剂从小基团（H）一侧通过。这两种过渡态把亲核试剂送到醛的相反两面，所以产物彼此是非对映体——*syn* 与 *anti* 的 1,2-二醇衍生物。
:::
:::

::: exercise 半程转化率的动力学拆分 {level=2 check="67"}
某外消旋底物以 $s = 10$ 做动力学拆分。$50\,\%$ 转化率时剩余起始原料的 ee 是多少？（ee 以百分数输入，保留两位有效数字。）
::: solution
解 $u + u^{10} = 1$（由 $1 - c = \tfrac12(u_\mathrm{s} + u_\mathrm{f}) = 0.5$ 且 $u_\mathrm{f} = u_\mathrm{s}^{10}$）：$u_\mathrm{s} = 0.835$，$u_\mathrm{f} = 0.165$。$\mathrm{ee} = (0.835 - 0.165)/1.000 = 0.67 = 67\,\%$。验证：$\ln(0.5 \times 0.33)/\ln(0.5 \times 1.67) = -1.80/-0.180 = 10$（[[#eq-kagan]]）。
:::
:::

::: exercise 推导 tanh 定律 {level=3}
从过渡态理论出发推导[[#eq-ee]]。然后证明当 $\Delta\Delta G^\ddagger$ 很小时 ee 近似与 $\Delta\Delta G^\ddagger/T$ 成正比，并估算 $\Delta\Delta G^\ddagger = 1.0\ \mathrm{kJ\,mol^{-1}}$、$298\ \mathrm{K}$ 时的 ee。
::: hint
$u$ 很小时 $\tanh u \approx u$。
:::
::: solution
对由同一反应物出发的两个竞争不可逆路径（比如前手性底物结合在手性催化剂上），$k_i = (k_\mathrm{B}T/h)\exp(-\Delta G^\ddagger_i/RT)$，指前因子相同，所以任一时刻产物比都是 $r = k_1/k_2 = \exp(\Delta\Delta G^\ddagger/RT)$（两个产物都出自同一个池）。于是 $\mathrm{ee} = (r - 1)/(r + 1) = \tanh(\Delta\Delta G^\ddagger/2RT)$，如[[#prop-ee]]的证明。对小的 $u = \Delta\Delta G^\ddagger/2RT$，$\tanh u = u - u^3/3 + \ldots \approx u$，故 $\mathrm{ee} \approx \Delta\Delta G^\ddagger/2RT$，正比于 $\Delta\Delta G^\ddagger/T$。$1.0\ \mathrm{kJ\,mol^{-1}}$、$298\ \mathrm{K}$：$u = 1000/(2 \times 8.314 \times 298) = 0.202$，$\mathrm{ee} \approx 20\,\%$（精确值 $\tanh 0.202 = 19.9\,\%$）。"两个产物来自共同且快速平衡的反应物态集合"这一假设就是 Curtin–Hammett 条件；若催化剂–底物配合物之间不互相转化，比值还要取决于它们的布居数。
:::
:::

::: exercise 99 % ee 需要多少转化率 {level=3 check="62"}
利用[[#eq-kagan]]，求 $s = 20$ 的动力学拆分给出 $99\,\%$ ee 起始原料时的转化率，以及相应的最大产率。（转化率以百分数输入，保留两位有效数字。）
::: hint
对慢对映体的剩余分数 $u_\mathrm{s}$ 作图：$\mathrm{ee} = (u_\mathrm{s} - u_\mathrm{s}^{s})/(u_\mathrm{s} + u_\mathrm{s}^{s})$。
:::
::: solution
$\mathrm{ee} = 0.99$ 给出 $u_\mathrm{s}^{s-1} = (1 - 0.99)/(1 + 0.99) = 0.005025$，于是 $u_\mathrm{s} = 0.005025^{1/19} = 0.757$，$u_\mathrm{f} = 0.757^{20} = 0.0038$。则 $1 - c = \tfrac12(0.757 + 0.0038) = 0.380$，即 $c = 0.62$，转化率 $62\,\%$，至多 $38\,\%$ 的外消旋体以对映体富集的起始原料回收（[[#ex-kr]]）。若 $s = 50$，同样的 ee 只需 $55\,\%$ 转化率。
:::
:::

::: exercise 规划一个光学纯醇 {level=3}
提出三种不同的方法，从非手性或外消旋起始原料得到 (*R*)-1-苯基乙-1-醇，并比较它们的最大产率与实际要求。
::: solution
(1) **苯乙酮的不对称还原**：CBS 还原（硼烷加催化量的脯氨酸衍生噁唑硼烷）、野依不对称转移氢化（Ru–TsDPEN 催化剂，甲酸/三乙胺或异丙醇），或用带辅因子循环系统的酮还原酶。最大产率 100 %；ee 通常高于 95 %；需要手性催化剂，但不需要分离对映体。(2) **外消旋 1-苯基乙醇的脂肪酶动力学拆分**（例如南极假丝酵母（*Candida antarctica*）脂肪酶 B 与乙酸乙烯酯），它把 (*R*)-醇酰化得更快：分离 (*R*)-乙酸酯再水解。最大产率 50 %（[[#prop-kr]]）；简单、温和、便宜。(3) **动态动力学拆分**：把脂肪酶与一种钌催化剂组合——后者经由可逆氧化成苯乙酮使醇消旋（贝克沃尔（Bäckvall）的方法）——于是全部物料都能经由快反应的 (*R*)-对映体汇入 (*R*)-乙酸酯：最大产率 100 %。第四种经典选择是**非对映体衍生物结晶拆分**（例如邻苯二甲酸的半酯，以手性胺的盐结晶），除非把不要的对映体消旋回收，上限为 50 %。选择取决于规模、催化剂成本，以及 50 % 的上限能否接受。
:::
