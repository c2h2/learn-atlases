4-乙酰基苯甲酸甲酯有两个羰基，一个酮，一个酯。硼氢化钠还原酮而不动酯；氢化铝锂把两者都还原；而没有任何常用氢化物能只还原酯而放过酮。氧化则给出镜像般的问题：伯醇可以被停在醛，也可以被带过去变成羧酸；烯烃可以被环氧化、双羟基化或断裂；一个带两个烯烃或两个醇的分子需要一个能在它们之间做出选择的试剂。真实合成中的大多数步骤根本不是碳碳成键，而是这类**氧化水平的调整**，而合成技艺的很大一部分，就是从拥挤的氧化剂与还原剂目录中挑出恰好只做所需之事、别的什么都不做的那一个。

本章为这份目录建立秩序。我们先介绍一个簿记工具——碳原子的氧化水平——它一眼就能告诉我们，一个拟议中的官能团互变（[[organic-synthesis/retrosynthesis#def-fgi]]）需要氧化剂、还原剂还是都不需要。然后我们过一遍主要的氧化（醇、烯烃、酮）与还原（氢化物试剂、催化氢化、溶金属还原、脱氧），逐一用文字描述每个机理步骤，并对停在中间氧化水平这一核心问题作定量讨论。贯穿全章的指导观念是**化学选择性**：一个官能团在其他官能团存在下优先反应。

## 氧化水平 {#sec-levels}

::: definition 碳原子的氧化水平 {#def-level}
有机化合物中一个碳原子的**氧化水平**，是它与比碳电负性大的原子（O、N、卤素、S）所成键的数目，双键计两次，三键计三次。与碳和与氢的成键不计。实际上：

| 水平 | 实例（所讨论的碳） |
|---|---|
| 0 | 烷烃的 C–H 碳 |
| 1 | 醇、醚、卤代烷、胺 |
| 2 | 醛、酮、缩醛、亚胺、偕二卤代物 |
| 3 | 羧酸、酯、酰胺、酰氯、腈、原酸酯 |
| 4 | 二氧化碳、碳酸酯、脲、异氰酸酯的碳 |

烯烃与炔烃按惯例被赋予其水合产物的水平：烯烃的两个碳各分担一个"水平"（烯烃处于醇的水平，炔烃处于酮的水平）。
:::

::: proposition 氧化水平与对氧化还原试剂的需求 {#prop-levels}
使每个碳都停留在同一氧化水平的官能团互变（酯 ⇄ 酰胺 ⇄ 腈 ⇄ 酸；酮 ⇄ 缩醛 ⇄ 亚胺；醇 ⇄ 卤代物 ⇄ 醚）可以用极性的非氧化还原试剂经取代、加成或消除来完成。使碳骨架的总氧化水平改变 $\Delta L$ 的互变，则需要交付每分子 $|\Delta L|$ 个两电子当量的氧化剂（$\Delta L > 0$）或还原剂（$\Delta L < 0$），例如 $|\Delta L|$ 个氢负离子。
:::

::: proof
氧化水平是对一个碳交给电负性伙伴的电子数（成对地）的形式计数。一种杂原子被另一种取代（O 换 Cl，N 换 O），以及水或醇跨 C=X 键的加成或消除，都是把一根 C–杂原子键换成另一根 C–杂原子键，因此计数不变，不需要给出或移走电子。把一根 C–杂原子键换成 C–H 键（氢负离子递送），或在原来 C–H 的位置创建一根新的 C–杂原子键（移走氢负离子，或质子加两个电子），使计数每根键改变一，这就需要一个两电子的还原剂或氧化剂。当有机金属试剂与羰基化合物之间形成 C–C 键时（格氏加成），羰基碳下降一个水平，而与电正性金属相连的那个碳在形式上被氧化：有机金属试剂本身就是那个两电子还原剂，因此不会另有一个氧化还原试剂出现。$\blacksquare$
:::

于是，酯（$\mathrm{RCO_2R'}$，水平 3）还原为伯醇（$\mathrm{RCH_2OH}$，水平 1）需要**两个**氢负离子当量；酯到醛，一个；腈到胺，两个（水平 3 到水平 1）。而羧酸变成酰胺根本*不需要*氧化还原试剂，只需要活化。数氧化水平可以防止规划中一个常见错误：提出一个实际上是还原的"水解"或"取代"。

## 氧化醇 {#sec-alcohols}

伯醇被氧化为醛并进一步到羧酸；仲醇到酮；叔醇抵抗氧化，因为带羟基的碳上没有 C–H。几乎在每种方法中，关键步骤都是同一个：醇氧挂到一个缺电子原子上（Cr、S、I、N、Ru），然后碱拿走带羟基碳上的 C–H 质子，而缺电子原子接受氧那边那根键的电子对——一次**跨 C–O 的消除**。

- **铬(VI)**：Jones 试剂（含水硫酸-丙酮中的 $\mathrm{CrO_3}$）把伯醇带到酸；二氯甲烷中的氯铬酸吡啶鎓（PCC，科里（Corey），1975）停在醛，因为在缺水条件下不会生成可被继续氧化的醛水合物。铬(VI)化合物有毒、致癌，并产生重金属废物，因此已在很大程度上被取代。
- **活化的二甲基亚砜**：**Swern 氧化**（斯沃恩（Swern），1978）用草酰氯在 $-78\ ^\circ\mathrm{C}$ 活化的 DMSO，然后加三乙胺。它温和、无金属、停在醛。副产物是二甲硫醚（恶臭）、一氧化碳（有毒）和二氧化碳，所以须在通风橱中进行。
- **高价碘**：**Dess–Martin 高碘烷**（DMP，1983）在室温、中性条件下氧化醇，常常只需几分钟。其前体 2-碘酰基苯甲酸（IBX）干燥时对撞击敏感，因此两者都要小心并在小规模下操作。
- **氮氧自由基催化**：TEMPO（2,2,6,6-四甲基哌啶-1-氧基）以次氯酸钠为终端氧化剂（Anelli 条件）催化地把伯醇氧化为醛，已用于工业规模；真正的氧化剂是氧铵阳离子。
- **钌**：高钌酸四丙基铵（TPAP）配合 N-甲基吗啉 N-氧化物（NMO）作共氧化剂（莱（Ley）与格里菲思（Griffith），1987）。
- **二氧化锰**只氧化**烯丙位与苄位**醇，这是宝贵的化学选择性：同一分子中的饱和醇完好无损。
- **醛到酸**：**平尼克（Pinnick）氧化**（亚氯酸钠 $\mathrm{NaClO_2}$，缓冲，加 2-甲基丁-2-烯清除次氯酸副产物）即便是敏感的醛也能转化为酸。

::: example Swern 氧化逐步解析 {#ex-swern}
描述 3-苯基丙-1-醇氧化为 3-苯基丙醛的机理，并解释为什么在加入碱之前温度必须一直保持很低。
::: solution
1. **活化。** DMSO 的一个氧孤对电子进攻草酰氯的羰基碳；C=O 的 π 电子移到氧上再推回来，把氯离子赶出去。这给出酰氧基硫鎓离子 $\mathrm{Me_2S^+{-}O{-}CO{-}COCl}$。氯离子进攻带正电的硫，S–O 键断裂，草酰基碎片碎解为 $\mathrm{CO}$、$\mathrm{CO_2}$ 与氯离子：产物是氯化二甲基硫鎓氯化物 $\mathrm{Me_2S^+Cl\ Cl^-}$。
2. **醇的加成。** 醇氧的孤对电子进攻硫，把氯离子顶出去；失去 O–H 质子给出烷氧基硫鎓离子 $\mathrm{RCH_2O{-}S^+Me_2}$。
3. **叶立德生成与消除。** 三乙胺从一个 S-甲基上拿走质子（因邻近 $\mathrm{S^+}$ 而变酸），生成硫叶立德 $\mathrm{RCH_2O{-}S^+(Me){-}CH_2^-}$。随后碳负离子经五元环状过渡态在分子内夺走带羟基碳上的氢：C–H 电子形成新的 C=O π 键，O–S 键断裂、其电子归硫。产物是醛 $\mathrm{PhCH_2CH_2CHO}$ 与二甲硫醚。

**温度。** 氯硫鎓与烷氧基硫鎓中间体在约 $-60\ ^\circ\mathrm{C}$ 以上会分解（烷氧基硫鎓离子可发生 Pummerer 型重排，生成甲硫基甲基醚副产物），所以活化与醇加成都在 $-78\ ^\circ\mathrm{C}$ 进行，只有当碱引发了所需的消除之后才让混合物升温。任何阶段都没有水，因此不生成醛水合物，向酸的过度氧化无从发生。
:::
:::

### 停在醛

过度氧化是一个定量问题：醛一边由醇生成，一边被进一步氧化消耗。

::: proposition 连续一级反应的中间体 {#prop-consecutive}
对 $\mathrm{A} \xrightarrow{k_1} \mathrm{B} \xrightarrow{k_2} \mathrm{C}$，拟一级速率常数 $k_1 \neq k_2$，初始 $[\mathrm{A}]_0$、$[\mathrm{B}]_0 = [\mathrm{C}]_0 = 0$，
$$
\frac{[\mathrm{B}](t)}{[\mathrm{A}]_0} = \frac{k_1}{k_2 - k_1}\left(e^{-k_1t} - e^{-k_2t}\right),
$$ {#eq-consec}
它在 $t_\mathrm{max} = \ln(k_2/k_1)/(k_2 - k_1)$ 达到最大，此时
$$
\frac{[\mathrm{B}]_\mathrm{max}}{[\mathrm{A}]_0} = r^{\,r/(1-r)}, \qquad r = \frac{k_2}{k_1}.
$$ {#eq-bmax}
:::

::: proof
$\mathrm{d}[\mathrm{A}]/\mathrm{d}t = -k_1[\mathrm{A}]$ 给出 $[\mathrm{A}] = [\mathrm{A}]_0e^{-k_1t}$。于是 $\mathrm{d}[\mathrm{B}]/\mathrm{d}t + k_2[\mathrm{B}] = k_1[\mathrm{A}]_0e^{-k_1t}$；乘以积分因子 $e^{k_2t}$ 并从 $0$ 以 $[\mathrm{B}]_0 = 0$ 积分，得[[#eq-consec]]。令 $\mathrm{d}[\mathrm{B}]/\mathrm{d}t = 0$：$k_1e^{-k_1t} = k_2e^{-k_2t}$，于是 $e^{(k_2-k_1)t} = k_2/k_1$，$t_\mathrm{max} = \ln r/(k_2 - k_1)$。在此时刻 $e^{-k_2t} = (k_1/k_2)e^{-k_1t}$，所以 $[\mathrm{B}]/[\mathrm{A}]_0 = \frac{k_1}{k_2 - k_1}e^{-k_1t}(1 - k_1/k_2) = (k_1/k_2)e^{-k_1t_\mathrm{max}}$。由 $k_1t_\mathrm{max} = \ln r/(r - 1)$，$e^{-k_1t_\mathrm{max}} = r^{-1/(r-1)}$，且 $[\mathrm{B}]_\mathrm{max}/[\mathrm{A}]_0 = r^{-1}\,r^{-1/(r-1)} = r^{-r/(r-1)} = r^{r/(1-r)}$。$\blacksquare$
:::

x: 0, 8

caption: 连续氧化中醇、醛、酸的分数对无量纲时间 $k_1t$ 的曲线（[[#eq-consec]]），$r = k_2/k_1$ 为过度氧化与第一步氧化两个速率常数之比。当 $r = 0.1$（例如干燥二氯甲烷中的 PCC 之类的试剂，或 Swern 氧化，其 $r$ 实际上为零）时，醛的峰值为 $77\,\%$；当 $r = 2$ 时它从不超过 $25\,\%$。由于在水中生成的醛水合物比醇被氧化得快得多，含水氧化剂的 $r$ 很大——这就是为什么 Jones 试剂把伯醇一路带到酸，而选醛的方法必须在无水条件下工作。
:::

::: example 能有多少醛？ {#ex-bmax}
某含水性氧化剂以 $k_1$ 氧化某伯醇，以 $k_2$ 氧化其醛。求 (a) $k_2 = 0.10\,k_1$ 与 (b) $k_2 = 10\,k_1$ 时醛的最大分数及其出现的时间。
::: solution
(a) $r = 0.10$：$[\mathrm{B}]_\mathrm{max}/[\mathrm{A}]_0 = 0.10^{0.10/0.90} = 0.10^{0.1111} = 0.774$，即 $77\,\%$，出现在 $k_1t_\mathrm{max} = \ln(0.10)/(0.10 - 1) = 2.56$。在恰当的时间停止反应可得到可用的产率，但会留下一些醇、也生成一些酸。

(b) $r = 10$：$[\mathrm{B}]_\mathrm{max}/[\mathrm{A}]_0 = 10^{-10/9} = 0.077$，即 $7.7\,\%$，出现在 $k_1t_\mathrm{max} = \ln 10/9 = 0.256$。醛几乎一生成就被氧化掉了：这个方法制造的是酸，不是醛。对中间氧化水平的选择性需要一个使 $k_2 \ll k_1$ 的试剂，糟糕的比值靠掌握时间是救不回来的。
:::
:::

## 氧化烯烃与酮 {#sec-alkenes}

**环氧化。** 过氧羧酸，最常用的是间氯过氧苯甲酸（mCPBA），以一步协同过程把一个氧原子转移给烯烃（普里列让（Prilezhaev）反应）。用文字说：烯烃的 π 电子进攻末端亲电的过氧氧；同时弱的 O–O 键断裂，其电子移去形成羧酸的 C=O；原来羰基氧的孤对电子接过过氧酸的 O–H 质子；而 O–H 键的电子回到正在被转移的氧上，形成它的第二根 C–O 键。环状的"蝴蝶"过渡态把两根 C–O 键都送到同一面，所以反应是**立体专一的**：*cis*-烯烃给 *cis*-环氧化物。过氧酸是亲电试剂，所以富电子（取代较多）的烯烃反应更快：四取代 > 三取代 > 二取代 > 单取代，而缺电子的烯酮需要亲核环氧化（碱性过氧化氢，先进攻 β-碳）。纯净的 mCPBA 对撞击敏感；为安全计，出售时与酸和水混在一起。

**双羟基化。** 四氧化锇以协同的 [3+2] 环加成加到烯烃上，生成环状锇酸酯，水解得 *syn*-1,2-二醇。因为 $\mathrm{OsO_4}$ 挥发且剧毒（可损伤角膜），实际用催化量并以化学计量的共氧化剂 NMO 配合（Upjohn 法，1976），后者把 Os(VI) 重新氧化为 Os(VIII)。不对称版本（夏普利斯（Sharpless））在[[organic-synthesis/stereoselective-synthesis]]。*Anti*-二醇来自环氧化后用酸催化开环加水，水从与环氧化物氧相反的一面进攻。

**氧化断裂。** **臭氧解**把 C=C 断成两个羰基。臭氧跨双键加成（1,3-偶极环加成）生成初级臭氧化物（1,2,3-三氧五环），后者碎解为一个羰基化合物与一个羰基氧化物；二者以相反的取向重新结合，得二级臭氧化物（1,2,4-三氧五环）。还原性后处理（二甲硫醚、三苯基膦、锌-乙酸）给醛和酮；氧化性后处理（过氧化氢）把醛碎片变成羧酸；硼氢化钠给醇。臭氧化物与过氧化物类副产物浓缩时有爆炸性，所以臭氧解在低温、溶液中进行，并在蒸除溶剂之前完成后处理。催化的 $\mathrm{OsO_4}$ 配合高碘酸钠（Lemieux–Johnson）经由二醇达到同样的断裂。

**瓦克（Wacker）氧化。** 端烯被催化量的氯化钯(II)转化为甲基酮，由氯化铜(II)和氧气再把钯重新氧化。水在取代较多的碳上（马尔科夫尼科夫）进攻与钯配位的烯烃，随后 β-氢消除、互变异构给出酮；这是把一个在合成中始终以烯烃形式携带的甲基酮可靠地"揭开面纱"的办法（[[organic-synthesis/retrosynthesis]]）。

**拜耳-维利格氧化。** 过氧酸（或过氧化氢加路易斯酸）把酮转化为酯、环酮转化为内酯。机理用文字说：过氧酸末端带 O–H 的氧加到羰基碳上（酸催化），C=O 的 π 电子移到氧上，给出四面体过氧半缩醛——**克里格（Criegee）中间体**。然后在关键步骤中，一个羰基取代基带着它的成键电子对从碳迁移到相邻的过氧氧上，同时弱的 O–O 键断裂、羧酸盐离去；原羰基的氧把孤对电子推回去重建 C=O。迁移基团**保持**构型地迁移，最能稳定正电荷的基团迁移最快。

::: proposition 拜耳-维利格反应的迁移倾向（经验） {#prop-aptitude}
拜耳-维利格反应中从碳迁移到氧的基团，按迁移倾向递减的大致次序为：叔烷基 > 环己基 ≈ 仲烷基 ≈ 苄基 ≈ 苯基 > 伯烷基 > 甲基。醛通常给羧酸（氢迁移），富电子芳醛例外，它们给甲酸酯（芳基迁移；达金（Dakin）反应）。迁移碳保持构型。这个次序是经验性的；它反映迁移基团在过渡态中承受部分正电荷的能力，并受立体电子要求修正（迁移的键必须与正在断裂的 O–O 键反式共平面）。
:::

::: example 拜耳-维利格反应的区域化学 {#ex-bv}
预测 mCPBA 与 (a) 2-甲基环己-1-酮、(b) 1-苯基乙-1-酮（苯乙酮）、(c) 1-环己基乙-1-酮反应的产物。为每个产物命名。
::: solution
(a) 二级环碳 C2（带甲基者）优先于一级环碳 C6 迁移，所以氧插入 C1 与 C2 之间：**7-甲基氧杂环庚-2-酮**（一个七元内酯，甲基在紧邻环氧的碳上）。构型保持意味着对映体纯的酮给出对映体纯的内酯。

(b) 苯基而不是甲基迁移：**乙酸苯酯**，$\mathrm{CH_3CO{-}OPh}$。

(c) 仲环己基而不是甲基迁移：**乙酸环己酯**，$\mathrm{CH_3CO{-}O{-}C_6H_{11}}$。水解这样的酯，就完成了一次保持构型的甲基酮到醇的转化——一个有用的官能团互变。
:::
:::

## 还原 {#sec-reductions}

### 氢化物试剂

金属氢化物把 $\mathrm{H^-}$ 递给亲电碳。它们的选择性遵循两个因素：试剂给出氢负离子的容易程度（Al–H 键比 B–H 键更极性、更活泼），以及路易斯酸的金属是否活化羰基氧。

| 试剂 | 易被还原 | 通常不反应 | 备注 |
|---|---|---|---|
| $\mathrm{NaBH_4}$（MeOH、EtOH 中） | 醛、酮、酰氯 | 酯、酸、酰胺、腈、烯烃 | 每个 B 四个氢化物；温和、耐受 |
| $\mathrm{NaBH_4/CeCl_3}$（Luche） | 酮 1,2（烯酮亦可，1,2） | — | 由烯酮给烯丙醇 |
| $\mathrm{LiAlH_4}$（醚、THF 中） | 几乎所有极性 C=O、C≡N；酯、酸、酰胺（到胺）、环氧化物 | 孤立的烯烃 | 与水与醇剧烈反应放出 $\mathrm{H_2}$ |
| DIBAL-H，$i\mathrm{Bu_2AlH}$ | 酯 → 醛（$-78\ ^\circ\mathrm{C}$）；腈 → 醛 | — | 一个氢化物；路易斯酸的 Al |
| $\mathrm{LiBH_4}$ | 酯、醛、酮 | 酸、酰胺 | Li⁺ 活化酯 |
| $\mathrm{BH_3{\cdot}THF}$ | 羧酸、酰胺；烯烃（硼氢化） | 酯、硝基 | 亲电试剂：进攻富电子的 C=O |
| $\mathrm{NaBH_3CN}$、$\mathrm{NaBH(OAc)_3}$ | 亚胺鎓离子（还原胺化） | 醛、酮（pH 6–7 时慢） | $\mathrm{NaBH_3CN}$ 遇酸可放出 HCN |
| L-Selectride，$\mathrm{LiBH(}s\mathrm{Bu)_3}$ | 位阻的酮，从位阻较小的一面 | — | 体积大：环己酮给直立键醇 |

硼氢化物还原的机理，用文字说：$\mathrm{BH_4^-}$ 的一个 B–H 键把它的电子对（连同氢）交给羰基碳，形成新的 C–H 键；C=O 的 π 电子移到氧上，给出与硼成键（或被醇溶剂质子化）的烷氧负离子。每个硼氢化物都能依次交出全部四个氢负离子。$\mathrm{LiAlH_4}$ 与酯作用时，第一个氢负离子给出四面体中间体，它赶出烷氧基生成醛；醛比酯更亲电，立即被第二个氢负离子还原为伯烷氧负离子，所以醛无法被分离出来。用 DIBAL-H 于 $-78\ ^\circ\mathrm{C}$，铝先与酯的羰基氧配位（路易斯酸碱），然后交出它仅有的一个氢负离子；所得四面体铝半缩醛在**低温下稳定**，只在水相后处理、剩余试剂已被销毁之后才崩解为醛。

**亲电性**的还原剂硼烷表现出相反的选择性。它首先配位到路易斯碱性最强的氧上：羧酸形成酰氧基硼烷并放出 $\mathrm{H_2}$，被活化的羰基随即在分子内被还原。酯的羰基氧碱性较弱，反应缓慢。所以 $\mathrm{BH_3}$ 能在酯存在下还原酸，而 $\mathrm{LiBH_4}$ 能在酸（以其不反应的羧酸盐形式）存在下还原酯。

::: example 一次化学选择性还原与一个内酯 {#ex-levulinate}
4-氧代戊酸乙酯（乙酰丙酸乙酯，一种生物质来源的化学品）用乙醇中的硼氢化钠处理，粗产物与微量酸共热。预测产物。能否还原酯而保留酮？
::: solution
$\mathrm{NaBH_4}$ 还原酮（水平 2 → 1）而不动酯（水平 3）：产物是 4-羟基戊酸乙酯。加酸后，新生羟基的氧在分子内进攻酯的羰基碳（生成五元环：OH 在 C4，酯碳是 C1），给出四面体中间体，它赶出乙醇：**5-甲基氧杂环戊-2-酮**（γ-戊内酯），一种溶剂和燃料添加剂。还原酯而保留酮无法直接做到——任何能还原酯的氢化物都更快地还原酮。解决办法是把酮**保护**为缩醛（耐 $\mathrm{LiAlH_4}$），还原酯，再用水酸除去缩醛（[[organic-synthesis/protecting-groups]]）。这是一条一般规则：当两个基团中更活泼的正是你要保留的那个时，就保护它。
:::
:::

::: example 硼氢化物还原的化学计量 {#ex-nabh4}
把 $10.0\ \mathrm{g}$ 环己酮（$98.14\ \mathrm{g\,mol^{-1}}$）还原为环己醇，至少需要多少质量的硼氢化钠（$M = 37.83\ \mathrm{g\,mol^{-1}}$）？为什么实际用量更多？
::: solution
环己酮：$10.0/98.14 = 0.1019\ \mathrm{mol}$，需要 $0.1019\ \mathrm{mol}$ 氢负离子（$\Delta L = -1$，[[#prop-levels]]）。每个 $\mathrm{BH_4^-}$ 提供四个，所以需 $0.1019/4 = 0.02547\ \mathrm{mol}$，即 $0.02547 \times 37.83 = 0.964\ \mathrm{g}$。实践中使用 0.5–1 摩尔当量的 $\mathrm{NaBH_4}$（最低量的 2–4 倍），因为试剂与醇溶剂缓慢反应（放出氢气），而且部分烷氧基化的硼氢化物中靠后的氢化物转移得更慢。放出的氢气意味着反应容器要排气，并要远离点火源。
:::
:::

### 催化氢化、溶金属还原与脱氧

**催化氢化**（$\mathrm{H_2}$ 配 Pd/C、$\mathrm{PtO_2}$ 或 Raney 镍）把氢以 *syn* 方式加到 C=C 与 C≡C 键上，还还原硝基为胺、亚胺为胺，并（较慢地）还原芳环和酮。它的化学选择性靠催化剂调节：**林德拉（Lindlar）催化剂**（负载在经铅与喹啉毒化的碳酸钙上的钯）把炔烃停在 *cis*-烯烃；Pd/C 断裂苄位的 C–O 与 C–N 键（**氢解**，用于除去苄基保护基）；均相催化剂按位阻与配位基团加以区分（[[organometallics-catalysis/hydrogenation-hydroformylation]]）。氢气极易燃，干燥的 Pd/C 可引燃溶剂，所以氢化装置要在惰气保护下、用合适的器材搭建。

**溶金属还原**用液氨中的碱金属：炔烃给 *trans*-烯烃（经由自由基负离子、质子化、第二个电子和一个采取 *trans* 几何的乙烯基负离子），**比尔奇（Birch）还原**把苯环变成环己-1,4-二烯（给电子取代基留在剩余双键上，吸电子取代基落在 $sp^3$ 碳上）。这些操作涉及活泼金属与一种低温、有毒的溶剂，只在受过专门训练并有相应设备时进行。

把酮或醛脱氧为 $\mathrm{CH_2}$（$\Delta L = -2$）：**沃尔夫-凯惜纳（Wolff–Kishner）还原**（肼与氢氧化钾，高温，经由腙，其去质子化并失去 $\mathrm{N_2}$ 给出被质子的碳负离子）在强碱条件下进行；**克莱门森（Clemmensen）还原**（锌汞齐，HCl）在强酸条件下；**硫代缩醛–Raney 镍**法在中性条件下。在它们之间做选择是一个化学选择性的决定：哪些其他基团能熬过碱、酸或镍？

::: algorithm 选择氧化还原试剂 {#alg-reagent}
1. **写出每个发生变化的碳的氧化水平**（[[#def-level]]），看清这一步必须做什么、需要多少个当量。
2. **列出分子中所有其他官能团**，以及它们对候选氧化剂或还原剂的可能反应（用上表）。
3. **选择能胜任的最温和试剂**，优先选择催化法与良性副产物；对中间水平，选 $k_2 \ll k_1$ 的试剂（[[#prop-consecutive]]）。
4. **把条件**（酸性、碱性、含水、温度）**与对酸、碱、水敏感的基团逐一核对**。
5. **若没有试剂足够有选择性，重排步骤次序**（在敏感基团安装之前做还原）**或保护**竞争的那个基团。
:::

::: quiz
哪种试剂能一步把 4-氧代环己烷-1-羧酸甲酯变成 4-羟基环己烷-1-羧酸甲酯？
- [x] 甲醇中的硼氢化钠，0 °C
- [ ] THF 中的氢化铝锂，然后水相后处理
- [ ] DIBAL-H（1 当量），−78 °C
- [ ] 硼烷–THF
::: solution
只应还原酮（水平 2 → 1），留下酯（水平 3）。$\mathrm{NaBH_4}$ 快速还原酮而极慢地还原酯。$\mathrm{LiAlH_4}$ 会把两个都还原，给出二醇。DIBAL-H 也会进攻酮，它的用处是酯 → 醛，而不是酮的选择性。硼烷是亲电性还原剂，还原酮很慢，选它是为了酸和酰胺。
:::
:::

::: warning 有机化学里的"氧化"不只是加氧 {#warn-oxidation}
学生常按是否有氧出现来给反应分类。这种判法两头都错。环己烯脱氢为苯，或醇脱氢为酮，都是没有加氧的氧化；烯烃与 HBr 生成烷基溴涉及一根 C–Br 键，但氧化水平没有变化（一个碳升，另一个降）；烯烃加水加了氧，却根本不是氧化——烯烃和醇处于同一水平（[[#def-level]]）。同样，环氧化物与由它制得的 *anti*-二醇也处于同一水平，所以开环不需要氧化还原试剂。要数的是对杂原子的键，不是氧原子的个数。
:::

::: history
铬基氧化主导了二十世纪早期：尤尔特·琼斯（Ewart Jones）与合作者在 1940 年代引入"Jones 试剂"，刘易斯·萨雷特（Lewis Sarett）于 1953 年引入三氧化铬-吡啶配合物，埃利亚斯·科里（E. J. Corey）与 J. 威廉·萨格斯（J. William Suggs）于 1975 年引入 PCC。寻找更温和、无金属的氧化剂产生了 DMSO 系方法——科恩布卢姆（Kornblum，1957）、菲茨纳-莫法特（Pfitzner–Moffatt，1963），以及大村贤二（Kenji Omura）与丹尼尔·斯沃恩（Daniel Swern）的草酰氯活化法（1978）——以及丹尼尔·德斯（Daniel Dess）与詹姆斯·马丁（James Martin）的高碘烷（1983）。阿道夫·冯·拜耳（Adolf von Baeyer）与维克托·维利格（Victor Villiger）于 1899 年报道了酮的过氧酸氧化，尼古拉·普里列让（Nikolai Prilezhaev）于 1909 年报道了烯烃被过氧酸的环氧化。还原方面，赫尔曼·欧文·施莱辛格（Hermann Irving Schlesinger）与赫伯特·C. 布朗（Herbert C. Brown）在战时研究中发现了硼氢化钠（1953 年发表），氢化铝锂则由芬霍尔特（Finholt）、邦德（Bond）与施莱辛格于 1947 年报道；布朗因硼氢化-氧化分享了 1979 年诺贝尔化学奖。保罗·萨巴捷（Paul Sabatier）在镍上的催化氢化（1912 年诺贝尔化学奖，与维克托·格林尼亚（Victor Grignard）分享）与亚瑟·比尔奇（Arthur Birch）对芳环的溶金属还原（1944）补齐了基本工具箱。
:::

## 后续内容

本章的氧化还原官能团互变出现在其后的几乎每个合成中。当没有试剂足够有选择性时，保护基（[[organic-synthesis/protecting-groups]]）解决那些情形，如[[#ex-levulinate]]。环氧化、双羟基化与酮还原的对映选择性版本在[[organic-synthesis/stereoselective-synthesis]]，拜耳-维利格反应将在[[organic-synthesis/rearrangements-radicals]]的重排中重新出现。它们的催化版本及其绿色化学优点是[[organometallics-catalysis/hydrogenation-hydroformylation]]与[[green-chemistry/green-principles]]的主题。

::: summary
- 碳的**氧化水平**（对杂原子的键数）表明一个官能团互变是否需要氧化还原试剂、需要多少个两电子当量：酯 → 醇需要两个氢化物，酸 → 酰胺一个也不要。
- 醇的氧化（Swern、Dess–Martin、TEMPO/次氯酸钠、TPAP、PCC；烯丙位/苄位用 $\mathrm{MnO_2}$）靠把氧挂到缺电子原子上再消除带羟基碳上的 C–H 完成；无水条件停在醛。
- 连续氧化中醛的最大分数是 $r^{r/(1-r)}$，$r = k_2/k_1$：选择性来自试剂，而不是掌握时间。
- 烯烃的氧化：协同、立体专一的环氧化（富电子烯烃更快），催化 $\mathrm{OsO_4}$/NMO 的 *syn*-双羟基化，臭氧解配还原性或氧化性后处理，瓦克氧化给甲基酮。
- 拜耳-维利格反应在较易迁移基团的一侧把 O 插到羰基旁边（叔 > 仲 ≈ 芳基 > 伯 > 甲基，经验），且构型保持。
- 氢化物选择性：$\mathrm{NaBH_4}$（醛、酮）< $\mathrm{LiBH_4}$（加上酯）< $\mathrm{LiAlH_4}$（几乎一切）；DIBAL-H 在 $-78\ ^\circ\mathrm{C}$ 把酯停在醛；亲电的 $\mathrm{BH_3}$ 偏爱酸和酰胺。
- 当没有任何试剂能区分两个基团时，重排步骤次序或加以保护。
:::

为每个转化选择试剂：(a) 环己醇 → 环己酮；(b) 辛-1-烯-3-醇 → 辛-1-烯-3-酮，保留 C=C；(c) 己-2-炔 →（*Z*）-己-2-烯；(d) 苯甲酸甲酯 → 苯甲醛；(e) 4-硝基苯甲酸 → 4-硝基苯甲醇。

::: exercise 醛的最高可能产率 {level=2 check="0.854"}
某伯醇氧化的醛过度氧化比值为 $k_2/k_1 = 0.050$。可达到的醛的最大分数是多少？（以分数输入，保留三位有效数字。）
::: solution
$[\mathrm{B}]_\mathrm{max}/[\mathrm{A}]_0 = r^{r/(1-r)} = 0.050^{0.050/0.950} = 0.050^{0.05263} = e^{0.05263 \ln 0.050} = e^{-0.1577} = 0.854$，出现在 $k_1t = \ln(0.05)/(0.05 - 1) = 3.15$（[[#eq-bmax]]）。
:::

::: exercise 拜耳-维利格预测 {level=2}
预测 mCPBA 与 (a) 4-叔丁基环己-1-酮、(b) 3,3-二甲基丁-2-酮（频哪酮）、(c) 4-甲氧基苯甲醛反应的主产物。用[[#prop-aptitude]]逐一解释。
::: solution
(a) C=O 旁的两个环碳是等价的二级碳；任一迁移都给 **5-叔丁基氧杂环庚-2-酮**。叔丁基离反应中心很远，不参与。(b) *叔*丁基（叔）优先于甲基迁移：***叔*丁基乙酸酯（乙酸叔丁酯）**，$\mathrm{CH_3CO{-}OC(CH_3)_3}$。(c) 富电子芳基优先于氢迁移（对位甲氧基的氧通过芳环给出孤对电子，稳定迁移碳上的部分正电荷）：**甲酸-4-甲氧基苯酯**，水解得 4-甲氧基苯酚。苯甲醛本身主要给苯甲酸。
:::
:::

::: exercise 由酮酯制内酯 {level=2}
为[[#ex-levulinate]]中由 4-氧代戊酸乙酯生成 γ-戊内酯写出完整的文字机理，命名每一处电子移动。
::: solution
**还原。** 硼氢化物的 B–H 键把它的电子对交给酮羰基碳（C4），形成 C–H；C=O 的 π 电子移到氧上，给出烷氧负离子，它从乙醇取得质子得仲醇。酯未受影响。**内酯化（酸催化）。** 一个质子加到酯羰基氧上（用其一对孤对电子），使羰基碳更亲电。C4 羟基氧的一对孤对电子进攻羰基碳（C1），生成五元环，同时 C=O 的 π 电子移到被质子化的氧上，给出中性 OH。质子转移把一个质子从（如今带正电的）环氧移到乙氧基的氧上。随后 OH 的孤对电子重建 C=O π 键，与质子化乙氧基的键断裂，释放乙醇；羰基氧失去质子给出中性内酯。五元环形成很快，因为分子内反应熵上有利。
:::
:::

::: exercise 一个酮酯的三种产物 {level=3}
从 4-乙酰基苯甲酸甲酯 $\mathrm{CH_3CO{-}C_6H_4{-}CO_2CH_3}$ 出发，给出短序列制取 (a) 4-(1-羟乙基)苯甲酸甲酯、(b) 1-[4-(羟甲基)苯基]乙-1-酮、(c) 4-乙基苯甲酸。解释每一例中的选择性问题。
::: hint
在 (b) 中，要被还原的基团是较不活泼的那个。
:::
::: solution
(a) $\mathrm{NaBH_4}$，甲醇，0 °C：还原酮，不碰酯。(b) 必须还原酯而让更活泼的酮幸存——直接做不到。把酮保护为它的 1,3-二氧戊环（乙烷-1,2-二醇，催化量对甲苯磺酸，除水）；用 $\mathrm{LiAlH_4}$ 还原酯（缩醛对氢化物惰性）；再用水酸除去缩醛（温和条件下苄位伯醇完好）（[[organic-synthesis/protecting-groups]]）。(c) 把酮脱氧为 $\mathrm{CH_2}$：沃尔夫-凯惜纳还原（肼，KOH，高沸点二元醇，加热）把芳基酮变成乙基，并在同样强碱的条件下把甲酯皂化；酸化一步即得 4-乙基苯甲酸。（或者，酸中 Pd/C 上的催化氢解经由苄醇把芳基酮还原为 $\mathrm{CH_2}$，随后水解酯。）肼有毒且疑似致癌；反应须在通风橱中、有人监督地进行。
:::

::: exercise 定向环氧化对电子效应环氧化 {level=3}
香叶醇（(*E*)-3,7-二甲基辛-2,6-二烯-1-醇）有两个三取代烯烃，C2=C3（与 OH 烯丙位相邻）与 C6=C7。预测 (a) 一当量 mCPBA 与 (b) 催化量乙酰丙酮氧钒加叔丁基过氧化氢各自生成的主要单环氧化物。解释。
::: hint
哪个烯烃更富电子？金属连在醇上时够得着哪个烯烃？
:::
::: solution
(a) mCPBA 是亲电试剂；两个烯烃都是三取代的，但 C2=C3 键受近旁 C–O 键诱导吸电子的轻微钝化。环氧化主要发生在远端的 **6,7-双键**，给 6,7-环氧香叶醇。(b) 钒(V)把烯丙醇以醇盐形式、把过氧化氢同时结合在同一金属上；过氧氧在分子内被递给最近的烯烃 **C2=C3**，选择性极高（夏普利斯（Sharpless）与米凯尔森（Michaelson），1973），给 2,3-环氧香叶醇。6,7-烯烃距离太远，够不到金属结合的氧化剂，完好无损。这一对比说明了化学选择性的两大来源：本征的电子反应性，以及官能团的**定向**递送。不对称版本（夏普利斯-胜沼环氧化）在[[organic-synthesis/stereoselective-synthesis]]展开。
:::
