一块手机电池在$45\ \mathrm{g}$的重量里装着约$15\ \mathrm{Wh}$，以$3.8\ \mathrm{V}$供一天的电，并能在失去五分之一的容量之前充放五百次。这些数字的每一个都是一块电化学。电压是锂在两种固体之间化学势之差除以法拉第常数。容量是这些固体能够吸入又放出的锂离子数目，以法拉第计数。能量是电压对电荷的积分。而那五百次循环是一场谈判出来的休战，对手是那些热力学上本该在首次充电时就毁掉这块电池的副反应——电解液在两个电极上都不稳定，它能幸存只因有它自身分解产物形成的一层膜护着。

本章把[[electrochemistry/cell-thermodynamics]]的热力学与[[electrochemistry/electrode-kinetics]]、[[electrochemistry/voltammetry]]的动力学与传质用于实际电池。我们定义性能指标，推导理论容量与能量，解释嵌入电极的电压曲线，分析功率受什么限制，然后看看主宰市场的两种化学体系——铅酸与锂离子——以及电池如何老化。危险只作描述、不作操作规程：与真实电池（尤其是锂电池）打交道需要训练、合适的设备与风险评估。

## 电池的语言

**电池**严格说是一组串接的单体，但这个词也用于单个单体。**一次**电池用一次（碱性锌-二氧化锰、心脏起搏器用的锂-碘电池）；**二次**（即可充电）电池则设计为靠逆转反应来再充电。由于同一块电极放电时是阳极、充电时是阴极，电池工程师改说**负极**与**正极**，以极性命名，而极性不变。（在锂离子电池文献中，按放电时的角色约定："anode"指负极，"cathode"指正极。）

::: definition 容量、能量与功率 {#def-capacity}
电池的**容量**$Q$是完全放电时给出的电荷量，常用安时（$1\ \mathrm{Ah} = 3600\ \mathrm{C}$）。电极材料的**比容量**是单位质量的容量，单位$\mathrm{mAh\,g^{-1}}$。放出的**能量**为
$$
W = \int_0^{Q} V\,\mathrm{d}q \approx \bar{V}Q ,
$$
$V$为端电压，$\bar V$为其平均值；**比能量**是$W/m$（$\mathrm{Wh\,kg^{-1}}$），**能量密度**是$W/V_\mathrm{cell}$（$\mathrm{Wh\,dm^{-3}}$）。**功率**为$P = VI$。**$n$C**的放电电流在$1/n$小时内放完额定容量（$3.0\ \mathrm{Ah}$的电池以2C放电给出$6.0\ \mathrm{A}$、持续$30\ \mathrm{min}$）。一个循环的**库仑效率**是放电给出的电荷与充电输入的电荷之比；**能量效率**是对应的能量之比，因放电电压低于充电电压而更低。
:::

::: proposition 理论比容量与理论比能量 {#prop-theoretical}
摩尔质量为$M$（$\mathrm{g\,mol^{-1}}$）、每个化学式单元交换$n$个电子的电极材料，其理论比容量为
$$
q_\mathrm{th} = \frac{nF}{3.6\,M}\ \mathrm{mAh\,g^{-1}} ,
$$ {#eq-capacity}
而一个每摩尔反应转移$\nu$个电子、每摩尔反应反应物总质量为$m_\mathrm{r}$（$\mathrm{kg}$）、平均电压为$\bar E$的电池，其理论比能量为
$$
w_\mathrm{th} = \frac{\nu F\bar E}{3600\,m_\mathrm{r}}\ \mathrm{Wh\,kg^{-1}} .
$$ {#eq-specific-energy}
:::

::: proof
一摩尔化学式单元交换$n$摩尔电子，电荷$nF$库仑，质量$M$克。由$1\ \mathrm{mAh} = 3.6\ \mathrm{C}$，每克电荷为$nF/M$库仑$= nF/(3.6M)$ mAh。能量方面，每摩尔反应的可逆电功为$-\Delta_\mathrm{r}G = \nu F\bar E$焦耳（[[electrochemistry/cell-thermodynamics#prop-dg]]，其中$\bar E$是开路电势在反应区间上的平均），而$1\ \mathrm{Wh} = 3600\ \mathrm{J}$；除以反应物质量即得结果。这是一个上限：只算活性材料、按热力学电压、完全用尽。
:::

作为数量级，$F/3.6 = 26\,801\ \mathrm{mAh\,mol^{-1}}$，所以摩尔质量$100\ \mathrm{g\,mol^{-1}}$、交换一个电子的材料值$268\ \mathrm{mAh\,g^{-1}}$。

::: example 锂离子电池电极的理论容量 {#ex-capacities}
求(a)石墨（完全嵌锂成$\mathrm{LiC_6}$）、(b)$\mathrm{LiCoO_2}$、(c)锂金属的理论比容量。实际上$\mathrm{Li_{1-x}CoO_2}$只在$x = 0$与$x \approx 0.5$之间循环；这给出多大容量？
::: solution
(a)每个$\mathrm{C_6}$单元（$M = 72.06\ \mathrm{g\,mol^{-1}}$）一个电子：$q = 26\,801/72.06 = 372\ \mathrm{mAh\,g^{-1}}$（每克碳）。(b)$\mathrm{LiCoO_2}$，$M = 97.87\ \mathrm{g\,mol^{-1}}$：$q = 26\,801/97.87 = 274\ \mathrm{mAh\,g^{-1}}$。(c)Li，$M = 6.94\ \mathrm{g\,mol^{-1}}$：$q = 3862\ \mathrm{mAh\,g^{-1}}$——石墨的十倍，这就是锂金属负极迟迟是奋斗目标的原因。$\mathrm{LiCoO_2}$在$\Delta x = 0.5$区间循环得$137\ \mathrm{mAh\,g^{-1}}$；脱出更多锂会使层状结构失稳并氧化电解液，所以实用的层状氧化物在电压上限与容量之间做交换。高镍变体如$\mathrm{LiNi_{0.8}Mn_{0.1}Co_{0.1}O_2}$可达约$200\ \mathrm{mAh\,g^{-1}}$。
:::
:::

## 嵌入电极的电压

在锂离子电池中，锂离子经电解液在两种主体固体之间来回穿梭，电子走外电路，电池反应是锂从一个主体转移到另一个主体，例如每转移1摩尔锂对应$\mathrm{LiC_6 + 2\,Li_{0.5}CoO_2 \rightarrow C_6 + 2\,LiCoO_2}$。开路电压于是只取决于每个主体束缚锂的牢度。

::: proposition 嵌入电池的开路电压 {#prop-ocv}
对锂从负主体（锂在其内的化学势为$\mu_\mathrm{Li}^{-}$）转移到正主体（$\mu_\mathrm{Li}^{+}$）的电池，开路电压为
$$
E_\mathrm{ocv} = -\frac{\mu_\mathrm{Li}^{+} - \mu_\mathrm{Li}^{-}}{F} .
$$ {#eq-ocv}
若主体是一格位等价的晶格、占据率为$x$、嵌入离子间无相互作用，则电极对锂金属的电势为
$$
E(x) = E^\circ - \frac{RT}{F}\ln\frac{x}{1-x} ,
$$ {#eq-lattice}
再计入平均场相互作用能$\Omega$（正规溶液项）便多加一项$-(\Omega/F)(1 - 2x)$。当$\Omega > 2RT$时模型预测分相，电压在两相区内为常数。
:::

::: proof
电池反应是$\mathrm{Li}(\text{负主体中}) \rightarrow \mathrm{Li}(\text{正主体中})$，$\nu = 1$，故$\Delta_\mathrm{r}G = \mu_\mathrm{Li}^{+} - \mu_\mathrm{Li}^{-}$、$E = -\Delta_\mathrm{r}G/F$。（等价地，每个电极上都有平衡$\mathrm{Li^+(electrolyte) + e^-(electrode) \rightleftharpoons Li(host)}$，两式相减时电解液项相消。）

对主体，数组态：$N$个格位，占据$xN$个。组态熵为$S = -Nk_\mathrm{B}[x\ln x + (1-x)\ln(1-x)]$，若每个嵌入的Li具有能量$\varepsilon_0$（无相互作用），则在不含$x$的项之外$G = xN\varepsilon_0 - TS$。每摩尔的化学势为$\mu_\mathrm{Li} = N_\mathrm{A}\,\partial G/\partial(xN) = \mu^\circ + RT\ln[x/(1-x)]$。对锂金属（$\mu_\mathrm{Li}^{-} = \mu^\circ_\mathrm{Li(s)}$），由[[#eq-ocv]]得[[#eq-lattice]]，其中$E^\circ = -(\mu^\circ - \mu^\circ_\mathrm{Li(s)})/F$。嵌入离子间的平均场相互作用对每摩尔格位加一个正规溶液的过量吉布斯能$\Omega x(1 - x)$，其导数$\Omega(1 - 2x)$并入$\mu_\mathrm{Li}$，给出额外的电压项。当$\Omega > 2RT$，$\mu_\mathrm{Li}(x)$不再单调：出现一段$\partial\mu/\partial x < 0$的成分区间，固溶体不稳定，体系分裂为贫锂相与富锂相，恰如正规液体混合物的分层（[[thermodynamics/phase-equilibria]]）。两相区内相组成固定，所以$\mu_\mathrm{Li}$——以及电压——是常数（固定$T$与$p$下对两组元三相——两个固相加参考——用吉布斯相律）。
:::

::: example 一对锂电极的比能量 {#ex-li-ion-energy}
对电池$\mathrm{C_6}$（石墨）| 电解液 | $\mathrm{Li_{1-x}CoO_2}$，在$\Delta x = 0.5$区间循环、平均电压$3.7\ \mathrm{V}$，以两种电极活性材料的质量为基准求理论比能量。
::: solution
每转移1摩尔Li：负极需1摩尔$\mathrm{C_6}$（$72.06\ \mathrm{g}$），正极每个化学式单元只交换$0.5$个Li、需2摩尔$\mathrm{LiCoO_2}$（$195.7\ \mathrm{g}$，其中已含锂）。总$m_\mathrm{r} = 267.8\ \mathrm{g}$。由[[#eq-specific-energy]]，取$\nu = 1$：
$$
w_\mathrm{th} = \frac{96\,485\times3.7}{3600\times0.2678}\ \mathrm{Wh\,kg^{-1}} = 370\ \mathrm{Wh\,kg^{-1}} .
$$
这一化学体系的商用电池达到约$200\ \mathrm{Wh\,kg^{-1}}$；其余质量是电解液、隔膜、铜与铝集流体、粘结剂、导电碳与外壳。因此提高比能量既要改进活性材料，也要减少非活性质量——更厚的电极、更薄的箔——而这又会恶化传输与功率。
:::
:::

## 为什么实际电池给出的更少

零电流下端电压为$E_\mathrm{ocv}$。一旦有电流，前三章的每个过程都要抽税。

::: proposition 端电压与最大功率 {#prop-power}
以电流$I$放电时，端电压为
$$
V = E_\mathrm{ocv} - IR_\Omega - |\eta_\mathrm{act,+}| - |\eta_\mathrm{act,-}| - |\eta_\mathrm{conc}| ,
$$ {#eq-terminal}
即欧姆（$IR_\Omega$：电解液、隔膜、接触）、活化（每个电极上的巴特勒-福尔默）与浓差（传质）损耗之和。充电时各项变号，$V > E_\mathrm{ocv}$。若损耗近似正比于电流，$V = E_\mathrm{ocv} - IR_\mathrm{int}$，则输出的功率$P = IV$在
$$
P_\mathrm{max} = \frac{E_\mathrm{ocv}^2}{4R_\mathrm{int}} \quad\text{当}\quad I = \frac{E_\mathrm{ocv}}{2R_\mathrm{int}}, \quad V = \frac{E_\mathrm{ocv}}{2}
$$ {#eq-pmax}
处取最大值，此时供电的能量效率只有$50\,\%$。
:::

::: proof
[[#eq-terminal]]就是回路周围的基尔霍夫（Kirchhoff）电压定律：热力学驱动力减去把电流驱动经过每个"电阻性"过程所需的电势差。线性模型下$P = I(E_\mathrm{ocv} - IR_\mathrm{int})$；令$\mathrm{d}P/\mathrm{d}I = E_\mathrm{ocv} - 2IR_\mathrm{int} = 0$得$I = E_\mathrm{ocv}/2R_\mathrm{int}$、$P_\mathrm{max} = E_\mathrm{ocv}^2/4R_\mathrm{int}$。在该点，反应的吉布斯能输送给负载的比例是$V/E_\mathrm{ocv} = \tfrac{1}{2}$；另一半耗散在电池内部变成热。（大电流下活化损耗是对数的而非线性的，所以线性模型会高估电极迟缓的电池的功率。）
:::

::: example 电池的功率 {#ex-power}
某锂离子电池$E_\mathrm{ocv} = 3.70\ \mathrm{V}$、$R_\mathrm{int} = 50\ \mathrm{m\Omega}$。求$10\ \mathrm{A}$下的端电压与最大功率。
::: solution
$V = 3.70 - 10\times0.050 = 3.20\ \mathrm{V}$；电池输出$32\ \mathrm{W}$，同时在内部耗散$I^2R = 5.0\ \mathrm{W}$，效率$3.20/3.70 = 86\,\%$。最大功率$E^2/4R = 3.70^2/0.20 = 68\ \mathrm{W}$，在$37\ \mathrm{A}$处，电池内部产热$34\ \mathrm{W}$。几十克重的密封电池里的这些热量，正是高倍率工作需要热管理的原因。内阻本身随降温（电导率更低、动力学更慢）与老化而升高。
:::
:::

高倍率下可用容量也会下降，因为电解液内与电极颗粒内的浓度梯度在活性材料用尽之前就把电压推到了截止值。对铅酸电池，Wilhelm Peukert（1897）把这经验地表示为$I^{k}t = \text{常数}$：$t$为电流$I$下的放电时间，$k \approx 1.1$–$1.3$（是经验规律，不是定理）。在双对数坐标上把比能量对功率比作图——**Ragone图**——一图概括每种技术的权衡：超级电容器（[[electrochemistry/double-layer]]）占据高功率、低能量的一角，燃料电池（[[electrochemistry/fuel-cells-electrolysis]]）占高能量、中等功率的一角，电池在中间。

## 铅酸电池

普朗泰（Gaston Planté）1859年的电池——今天按产量计仍是最常见的可充电电池——用硫酸中的铅与二氧化铅极板。放电时两极板都变成硫酸铅：
$$
\begin{aligned}
\text{负极：}\quad &\mathrm{Pb(s) + HSO_4^-(aq) \rightarrow PbSO_4(s) + H^+(aq) + 2e^-}\\
\text{正极：}\quad &\mathrm{PbO_2(s) + HSO_4^-(aq) + 3H^+(aq) + 2e^- \rightarrow PbSO_4(s) + 2H_2O(l)}\\
\text{总反应：}\quad &\mathrm{Pb(s) + PbO_2(s) + 2H_2SO_4(aq) \rightarrow 2PbSO_4(s) + 2H_2O(l)}
\end{aligned}
$$
酸是反应物，放电时被消耗，所以电解液的比重（从充满电的约$1.28$到放完电的约$1.12$）直接指示荷电状态。

::: example 铅酸电池的热力学 {#ex-lead-acid}
已知$E^\circ(\mathrm{PbO_2/PbSO_4}) = +1.6913\ \mathrm{V}$、$E^\circ(\mathrm{PbSO_4/Pb}) = -0.3588\ \mathrm{V}$（CRC，硫酸根形式），求$E^\circ_\mathrm{cell}$、$\Delta_\mathrm{r}G^\circ$，以及以反应物$\mathrm{Pb + PbO_2 + 2H_2SO_4}$为基准的理论比能量。
::: solution
$E^\circ = 1.6913 - (-0.3588) = 2.050\ \mathrm{V}$，取$\nu = 2$，$\Delta_\mathrm{r}G^\circ = -2\times96\,485\times2.050\ \mathrm{J\,mol^{-1}} = -395.6\ \mathrm{kJ\,mol^{-1}}$。每摩尔反应的反应物质量为$207.2 + 239.2 + 2\times98.08 = 642.6\ \mathrm{g}$。由[[#eq-specific-energy]]，
$$
w_\mathrm{th} = \frac{2\times96\,485\times2.050}{3600\times0.6426}\ \mathrm{Wh\,kg^{-1}} = 171\ \mathrm{Wh\,kg^{-1}} .
$$
实际电池只给出$30$–$40\ \mathrm{Wh\,kg^{-1}}$：板栅、电解液中的水、极板活性物质的不完全利用（硫酸铅是绝缘体并堵塞孔隙）都要花质量。这块电池之所以能用，全凭动力学。在$2.05\ \mathrm{V}$下电解液本应分解——负极板比氢电势低$0.36\ \mathrm{V}$，正极板比氧电势高$0.46\ \mathrm{V}$——但铅上的氢超电势与二氧化铅上的氧超电势都很大（[[electrochemistry/electrode-kinetics]]），除接近充满时外析气都很慢。
:::
:::

电池的失效方式由它的化学决定：**硫酸盐化**——长期搁置在放电状态的电池长出难以逆转的大$\mathrm{PbSO_4}$晶体；正极板栅的腐蚀；以及过充时析气失水——阀控式密封设计靠让氧在负极板复合来把失水降到最低。铅及其化合物有毒（反复暴露的生殖毒性与器官损伤是其GHS危险类别之一），电解液有腐蚀性，但铅酸电池的闭环回收是所有消费产品中最彻底的之一。

## 锂离子电池

::: definition 锂离子（"摇椅式"）电池 {#def-li-ion}
**锂离子电池**用低电势储锂的负极（石墨，常掺部分硅；或$1.55\ \mathrm{V}$的钛酸锂$\mathrm{Li_4Ti_5O_{12}}$，寿命长）与高电势储锂的正极（层状氧化物$\mathrm{LiMO_2}$，$\mathrm{M} = \mathrm{Ni, Mn, Co, Al}$；尖晶石$\mathrm{LiMn_2O_4}$；或橄榄石$\mathrm{LiFePO_4}$），中间隔以浸了非水电解液（通常$1\ \mathrm{mol\,dm^{-3}}$六氟磷酸锂$\mathrm{LiPF_6}$溶于碳酸乙烯酯与链状碳酸酯的混合物）的多孔聚合物隔膜。放电时$\mathrm{Li^+}$离开负主体，穿过电解液，进入正主体，电子走外电路；充电时两者反向。正常工作状态下不存在锂金属。
:::

非水电解液在所难免：石墨对$\mathrm{Li^+/Li}$工作在约$0.1\ \mathrm{V}$，即对标准氢电极$-2.9\ \mathrm{V}$，远低于水被还原的电势。事实上碳酸酯电解液同样不稳定：它对锂低于约$0.8\ \mathrm{V}$时在石墨表面被还原。首次充电时，还原产物——碳酸锂、烷基碳酸锂、氟化锂与聚合物——形成一层纳米厚的**固体电解质界面相**（SEI），它导锂离子而不导电子，从而阻止进一步还原。碳酸乙烯酯不可或缺，因为它的还原产物在石墨上形成好的SEI；化学上几乎相同的碳酸丙烯酯则不行，它会共嵌入并把石墨剥层。SEI不可逆地消耗锂——首循环通常损失电池容量的$5$–$10\,\%$——其缓慢而持续的再生长是老化的主因。

::: quiz
某锂离子电池在$25\,^\circ\mathrm{C}$下充电。关于它的电极，哪种说法正确？
- [ ] 充电时石墨电极是阳极，因为它是负极
- [x] 充电时锂从正主体中被氧化脱出并嵌入石墨，石墨此时是阴极
- [ ] 正极始终是阴极，所以充电时它被还原
- [ ] 充电时电解液的锂离子浓度持续升高
::: solution
充电时外电源把电子压入石墨，石墨被还原（锂嵌入）：那一刻它是阴极，尽管它仍是负极。正极被氧化（锂脱出），所以充电时它是阳极。电解液浓度整体不变，因为锂离子离开一个电极的速度等于进入另一个电极的速度；只有电流流过时才有瞬态梯度。
:::
:::

::: warning 电解液的稳定性与电压窗口 {#warn-window}
电池电压不能超过其电解液的电化学稳定窗口——除非有钝化界面相护着它：负极上是SEI，正极上是一层较薄的正极电解质界面相。常见的错误是从嵌入电势表里挑一个高电压正极，就期待电池对应有相应高的电压：对锂超过约$4.3$–$4.5\ \mathrm{V}$时碳酸酯电解液被氧化、过渡金属溶出，电池迅速衰减。同样，对SEI而言"热力学稳定"是错误的框架：它是一道动力学势垒，任何把它裂开的因素（硅嵌锂时膨胀可达$300\,\%$；低温大电流充电）都会暴露出新鲜电极表面、让副反应重来。
:::

### 安全性

锂离子电池的危险来自可燃电解液与储存的化学能量的组合。电池若被过热、过充、压碎或内部短路（例如低温快充时在石墨上镀出的锂金属枝晶），放热反应——SEI分解、嵌锂石墨与电解液反应、以及约$150$–$250\,^\circ\mathrm{C}$以上（视化学体系而定）层状氧化物释放氧——会彼此加速而成**热失控**，泄出可燃且有毒的气体（包括$\mathrm{LiPF_6}$来的氟化氢）并起火。$\mathrm{LiFePO_4}$的磷酸根氧结合牢固、不会释放，比高镍氧化物耐受得多。实际防护在于限制电压、电流与温度的电池管理电子线路，受热闭孔的隔膜，以及安全的贮存、运输与处置；损坏的电池只能由受过训练的人用合适的设备处理。

## 老化

电池在存放（**日历老化**）与使用（**循环老化**）中都会失去容量、增加电阻。主要机制有：SEI生长消耗可循环的锂；颗粒开裂与过渡金属溶出使活性物质损失（溶出的金属迁移到负极并催化进一步的SEI生长）；高充电倍率或低温下锂在石墨上析出；粘结剂与导电网络退化。每一样都被高温与高荷电状态加速——这就是电池半电、低温存放寿命最长、而电动车电池包往往留空容量两端不用尽的原因。

::: proposition 钝化膜的抛物线生长 {#prop-sei}
若SEI由某个受反应物（溶剂分子或电子）经现有膜扩散控制的反应生长，生长速率与当前厚度$L$成反比，则
$$
L(t) = \sqrt{L_0^2 + 2kt}\ \approx \sqrt{2kt}\quad (L \gg L_0),
$$
而膜消耗的容量正比于$\sqrt{t}$。
:::

::: proof
两个表面浓度固定、厚$L$的膜中的扩散通量正比于$1/L$（菲克（Fick）第一定律）。若膜的生长量正比于通量，则$\mathrm{d}L/\mathrm{d}t = k/L$。分离变量，$L\,\mathrm{d}L = k\,\mathrm{d}t$，从$t = 0$时的$L_0$积分得$L^2 - L_0^2 = 2kt$。单位面积的膜消耗固定的锂，所以一旦$L \gg L_0$，失去的锂（容量）正比于$L - L_0 \approx \sqrt{2kt}$。同一个"抛物线定律"也支配金属上保护膜的生长（[[electrochemistry/corrosion]]）。
:::

::: example 日历衰减的预测 {#ex-fade}
某电池在$45\,^\circ\mathrm{C}$存放，按[[#prop-sei]]的SEI生长机制在$100$天内失去$4.0\,\%$的容量。它何时会失去$10\,\%$？若生长常数$k$的激活能为$50\ \mathrm{kJ\,mol^{-1}}$，$25\,^\circ\mathrm{C}$下失去$10\,\%$需要多久？
::: solution
损失$\propto\sqrt{t}$：$10/4 = \sqrt{t/100\ \mathrm{d}}$，故$45\,^\circ\mathrm{C}$下$t = 100\times2.5^2 = 625$天。$25\,^\circ\mathrm{C}$下$k$缩小为原来的$\exp[-(50\,000/8.314)(1/298.15 - 1/318.15)] = \exp(-1.268) = 0.281$，固定损失下$t \propto 1/k$，故$t = 625/0.281 = 2220$天，约六年。这正是加速老化试验背后的推理；要紧的提醒是不同机制的激活能不同，加速试验可能被一个在室温下并不重要的机制主导。
:::
:::

::: history 两个世纪的可充电电池 {#hist-batteries}
加斯东·普朗泰（Gaston Planté）1859年向法国科学院演示了可充电的铅酸电池，卡米尔·福尔（Camille Faure）1881年的涂膏式极板使它变得实用。乔治·勒克朗谢（Georges Leclanché）1866年的锌-二氧化锰电池是今日碱性一次电池的鼻祖。Waldemar Jungner 1899年为镍-镉电池申请了专利，托马斯·爱迪生（Thomas Edison）1901年为镍-铁电池申请了专利。锂离子时代始于M. 斯坦利·惠廷厄姆（M. Stanley Whittingham）可充电的锂-二硫化钛电池（*Science*，1976），它证明锂可以可逆地嵌入层状主体。1980年Koichi Mizushima、约翰·古迪纳夫（John Goodenough）及同事报道了$4\ \mathrm{V}$附近的$\mathrm{Li_{x}CoO_2}$正极；1985年吉野彰（Akira Yoshino）把它与碳负极组合成电池，避开了锂金属；索尼1991年将锂离子电池商品化。Emanuel Peled 1979年描述了固体电解质界面相；Akshaya Padhi与古迪纳夫1997年提出$\mathrm{LiFePO_4}$。古迪纳夫、惠廷厄姆与吉野彰分享了2019年诺贝尔化学奖。
:::

## 超越锂离子电池

若干化学体系正为未来的市场竞争，而格局变化很快；以下只是2026年的一个快照。**钠离子电池**用硬碳负极与层状氧化物或普鲁士蓝类似物正极，避开锂、镍与钴，已在固定式储能与小型车辆上进入商业化生产，比能量约$100$–$160\ \mathrm{Wh\,kg^{-1}}$。**固态电池**用陶瓷或聚合物锂导体（[[electrochemistry/conductivity]]）取代液体电解液，期望由此安全地启用锂金属负极；如何在循环中始终保持界面接触仍是核心挑战。**锂硫电池**的理论比能量十分可观，却受中间多硫化物溶解的困扰。大型固定式储能还用**氧化还原液流电池**：能量储存在电解液罐中（例如处于若干氧化态的钒），泵过电堆，于是能量与功率可以独立定标。同时，2010年到2020年代中期锂离子电池包的价格下跌了约$90\,\%$（BloombergNEF年度调查），这是电动车与电网电池普及如此迅速的主因。

## 后续内容

电池储存的能量总要来自某处；[[electrochemistry/fuel-cells-electrolysis]]讨论直接把化学燃料转化的装置和用电制氢的电解池，用的是与[[#eq-terminal]]相同的损耗分析。嵌入材料本身——层状氧化物、尖晶石、橄榄石、它们的缺陷与相变——属于[[materials-chemistry]]，而集流体与外壳的腐蚀归[[electrochemistry/corrosion]]。生命周期问题——采矿、回收、制造的碳足迹——在环境课程与工业课程中展开。

::: summary
- 容量、比能量（$\bar V Q/m$）、功率、倍率、库仑效率与能量效率是性能指标；理论容量为$nF/3.6M$ mAh g⁻¹、理论比能量为$\nu F\bar E/3600m_\mathrm{r}$ Wh kg⁻¹，是实际电池只能部分达到的上限。
- 嵌入电池的开路电压是锂在两个主体间化学势之差除以$F$；晶格气体主体给出$E = E^\circ - (RT/F)\ln[x/(1-x)]$，强吸引相互作用导致两相与平坦的平台（$\mathrm{LiFePO_4}$）。
- 端电压是$E_\mathrm{ocv}$减去欧姆、活化与浓差损耗；最大功率$E^2/4R_\mathrm{int}$只在$50\,\%$的效率下取得。
- 铅酸电池（$E^\circ = 2.05\ \mathrm{V}$，理论$171\ \mathrm{Wh\,kg^{-1}}$，实际$30$–$40$）放电时消耗其酸，靠铅与二氧化铅上大的析气超电势得以存续。
- 锂离子电池在石墨与氧化物或磷酸盐主体之间穿梭$\mathrm{Li^+}$，碳酸酯电解液由固体电解质界面相保护；热失控是其主要危险。
- 老化以SEI生长（容量损失大致$\propto\sqrt{t}$）、颗粒开裂、金属溶出与锂析出为主，高温与高荷电状态加速一切机制。
:::

::: exercise 一个倍率 {level=1 check="6.0"}
多大的电流相当于$3.0\ \mathrm{Ah}$电池的2C放电？放电能持续多久（忽略倍率引起的容量损失）？（电流以A为单位填写。）

::: exercise 圆柱电池的比能量 {level=1 check="235"}
一只质量为$46\ \mathrm{g}$的圆柱电池以平均电压$3.6\ \mathrm{V}$放出$3.0\ \mathrm{Ah}$。求它的比能量。（以$\mathrm{Wh\,kg^{-1}}$为单位填写。）

::: exercise 铅酸电池的电动势 {level=2 check="2.050"}
用$E^\circ(\mathrm{PbO_2/PbSO_4}) = 1.6913\ \mathrm{V}$与$E^\circ(\mathrm{PbSO_4/Pb}) = -0.3588\ \mathrm{V}$，求铅酸电池的$E^\circ$，并定性解释为什么充满电的电池（硫酸约$5\ \mathrm{mol\,kg^{-1}}$）开路电压高于此值。（$E^\circ$以V为单位填写。）
::: solution
$E^\circ = 1.6913 + 0.3588 = 2.050\ \mathrm{V}$。电池反应消耗两摩尔$\mathrm{H_2SO_4}$、生成两摩尔水，所以能斯特方程为$E = E^\circ + (RT/2F)\ln[a(\mathrm{H_2SO_4})^2/a(\mathrm{H_2O})^2]$。浓硫酸的平均活度远大于1，水的活度又被压低，两项都使$E$升高，充满电的电池约达$2.1\ \mathrm{V}$；随着酸被消耗电压下降，这就是开路电压能指示荷电状态的原因。

::: exercise 由电压读荷电状态 {level=2 check="0.875"}
$25\,^\circ\mathrm{C}$下，理想的晶格气体正电极（[[#eq-lattice]]）的占据率$x$为多少时，其电势比$E^\circ$低$50\ \mathrm{mV}$？（填写$x$。）

$E^\circ - E = (RT/F)\ln[x/(1-x)] = 0.050\ \mathrm{V}$，故$\ln[x/(1-x)] = 0.050/0.025693 = 1.946$，$x/(1-x) = 7.00$，得$x = 7/8 = 0.875$。理想曲线从$x = 0.25$到$x = 0.75$只变化$\pm28\ \mathrm{mV}$；实际斜坡电极因为相互作用与格位能量分布变化更大，这有利于荷电状态的估计。

::: exercise 锂硫电池的理论能量 {level=3 check="2508"}
对电池反应$2\mathrm{Li + S \rightarrow Li_2S}$、平均电压$2.15\ \mathrm{V}$，求硫的理论比容量与以反应物质量计的理论比能量。评论为什么实际电池只达到其中一小部分。（比能量以$\mathrm{Wh\,kg^{-1}}$为单位填写。）

硫每个原子交换两个电子：$q = 2\times26\,801/32.06 = 1672\ \mathrm{mAh\,g^{-1}}$。取$\nu = 2$、$m_\mathrm{r} = 2(6.94) + 32.06 = 45.94\ \mathrm{g}$，$w_\mathrm{th} = 2\times96\,485\times2.15/(3600\times0.04594)\ \mathrm{Wh\,kg^{-1}} = 2508\ \mathrm{Wh\,kg^{-1}}$（用$M(\mathrm{Li_2S}) = 45.95$四位数字内结果相同）。实际电池需要过量的锂、大量溶解并穿梭多硫化物中间体的电解液、以及导电碳（硫与$\mathrm{Li_2S}$都是绝缘体）；这些合起来把实际比能量压到几百$\mathrm{Wh\,kg^{-1}}$，而多硫化物在两极之间的穿梭还降低库仑效率。

::: exercise 平方根衰减 {level=3 check="625"}
对生长受自身膜内扩散控制的膜推导抛物线定律$L = \sqrt{2kt}$。某电池头$100$天按此机制失去$4.0\,\%$的容量。多少天后它会失去$10\,\%$？（以天数为单位填写。）
::: solution
由$\mathrm{d}L/\mathrm{d}t = k/L$且$L(0) \approx 0$，得$L^2 = 2kt$。容量损失正比于$L$，故正比于$\sqrt{t}$：$t_{10} = 100\ \mathrm{d}\times(10/4.0)^2 = 625\ \mathrm{d}$。真实的衰减曲线常先按$\sqrt{t}$走，等析锂或活性物质损失接管后转为线性或加速（出现"拐点"）——所以用早期数据外推是偏乐观的。
:::

::: exercise 电池的产热 {level=3 check="0.539"}
某电池$R_\mathrm{int} = 0.050\ \Omega$、$(\partial E_\mathrm{ocv}/\partial T)_p = -0.10\ \mathrm{mV\,K^{-1}}$，在$25\,^\circ\mathrm{C}$下以$3.0\ \mathrm{A}$放电。用能量平衡$\dot q = I(E_\mathrm{ocv} - V) - IT(\partial E_\mathrm{ocv}/\partial T)_p$求其放热速率，并指出其中的可逆部分。（$\dot q$以W为单位填写。）
::: hint
第二项是单位电荷的$T\Delta_\mathrm{r}S$，见[[electrochemistry/cell-thermodynamics#prop-temp]]。
:::
::: solution
不可逆热（焦耳热与超电势热）：$I(E - V) = I^2R = 9.0\times0.050 = 0.450\ \mathrm{W}$。可逆热（熵热）：$-IT(\partial E/\partial T)_p = -3.0\times298.15\times(-1.0\times10^{-4}) = 0.089\ \mathrm{W}$。合计$0.539\ \mathrm{W}$。可逆项在充电时变号（成为$-0.089\ \mathrm{W}$，即冷却）；放电时它的符号取决于反应熵，而反应熵随荷电状态变化；在小电流下它可以占主导——这就是量热法对电池热力学如此灵敏的探测手段的原因。
:::
