为什么苯的反应性远低于其分子式所暗示的水平？为什么丁二烯在 $217\ \mathrm{nm}$ 处吸收光，而乙烯在 $170\ \mathrm{nm}$ 以上却是透明的？这两个事实与数字 $6$ 有什么关系？Hückel 于 1931 年提出的理论用一个简洁到化学家心算即可完成的模型回答了这三个问题：把平面共轭分子约化为只含 $\pi$ 电子的单电子问题，全部参数只有两个——电子定域在某个碳上的能量 $\alpha$，以及电子在相邻成键碳之间跃迁的共振能 $\beta$——其余的一切都不过一个久期行列式，即把变分线性方法（[[quantum-chemistry/approximation-methods]]）用到一张图上。苯的离域能、芳香性的 $4n + 2$ 规则、使苯的六个键完全等同的键级、染料的颜色、决定分子如何反应的前线轨道，全都由这两个参数导出。这套理论同时也是量子化学史上最诚实的失败：它的数值系统性地出错，而出错的方式恰恰能教会我们模型能够断言什么、不能够断言什么；我们将自始至终保持这份诚实。

## $\pi$ 电子模型

::: definition Hückel 模型 {#def-huckel-model}
对一个平面共轭分子，在 $\pi$ 骨架的每个原子 $r$ 上取一个 $\mathrm{p_z}$ 轨道 $\phi_r$，并把单电子哈密顿量与重叠矩阵在基 $\{\phi_r\}$ 下写成
$$
H_{rr} = \alpha\ (\text{库仑积分}), \qquad
H_{rs} = \begin{cases} \beta, & r\ \text{与}\ s\ \text{成键},\\ 0, & \text{其他}, \end{cases}
\qquad S_{rs} = \delta_{rs},
$$
其中 $\alpha$ 与 $\beta$ 是常数，对每个碳都相同，且 $\beta < 0$。分子轨道 $\psi = \sum_r c_r \phi_r$ 的 $\pi$ 电子能量为 $E = \alpha + x\beta$，其中 $x$ 是分子图的邻接矩阵 $A$ 的本征值：对每个 $r$ 都有 $\sum_{s\ \text{与}\ r\ \text{成键}} c_s = x\,c_r$。
:::

这个定义里藏着三条近似，你应该能随口说出它们的名字。第一是 $\sigma$/$\pi$ 分离：$\sigma$ 骨架（[[bonding-structure/covalent-lewis]]）把分子撑成平面，它的电子不计入问题；只有垂直于分子平面的 $\mathrm{p_z}$ 轨道里的电子才感受到这个问题。第二是芯哈密顿量近似：每个 $\pi$ 电子都在原子核与 $\sigma$ 电子的平均场中运动，$\pi$–$\pi$ 排斥被忽略——总 $\pi$ 电子能量只是一份单电子能量之和，每个轨道填两个电子（自旋相反，泡利原理）。第三是零重叠与参数近似：即使相邻原子之间也取 $S_{rs} = \delta_{rs}$，而且无论几何如何，每一对成键原子都共享同一个 $\beta$。因此 Hückel 理论是一个关于*拓扑*的模型：进入问题的只有哪些原子成键，绝无它们相距多远。

::: warning $\beta$ 是负数——“$x$ 越大”意味着“能量越低” {#warn-beta-sign}
因为 $E = \alpha + x\beta$ 而 $\beta < 0$，*成键最强*的轨道对应邻接矩阵*最大*的本征值 $x$：苯中的 $x = +2$ 位于 $\alpha + 2\beta$，在 $\alpha$ 之下。把能级图上下读反，是这个题目里最常见的错误。当书上说“苯的 $\pi$ 能量是 $6\alpha + 8\beta$”，它的意思是能量比 $6\alpha$ *低* $8|\beta|$；当它说某个能级“因共轭而升高”，它的意思是该能级的 $\beta$ 系数*变小*了。
:::

:::example 数清 $\pi$ 电子 {#ex-count}
丁二烯、苯、环戊二烯负离子 $\mathrm{C_5H_5^-}$、吡啶、烯丙基自由基的 Hückel 模型各计入多少个 $\pi$ 电子？
:::solution
每个中性碳的 $\mathrm{p_z}$ 轨道贡献一个电子，再按电荷调整：（a）四个 $\mathrm{sp^2}$ 碳，$4$ 个 $\pi$ 电子；（b）$6$ 个；（c）五个碳贡献 $5$ 个，负电荷是一对进入环 $\pi$ 体系的电子——共 $6$ 个 $\pi$ 电子；（d）吡啶的氮在 $\pi$ 计数中相当于一个 CH（它的 $\mathrm{p_z}$ 里有一个电子；它的孤对电子处在分子平面内的 $\mathrm{sp^2}$ 轨道上，不计入）——$6$ 个 $\pi$ 电子；（e）$3$ 个。（c）与（d）的记账法——孤对电子住在哪儿——正是下文杂原子规则的全部内容。
:::
:::

## 久期行列式：乙烯与烯丙基

::: proposition Hückel 久期方程 {#prop-secular}
Hückel 模型的定态是久期方程
$$
(\alpha - E)c_r + \beta \sum_{s\ \text{与}\ r\ \text{成键}} c_s = 0 \quad \text{对每个 } r
$$
的解，它存在非零解当且仅当久期行列式 $\det(xI - A)$ 为零，其中 $x = (E - \alpha)/\beta$，$A$ 是 $\pi$ 网络的邻接矩阵。每个根 $x$ 对应一个轨道能量 $E = \alpha + x\beta$；系数 $c_r$ 给出轨道本身；把根从上往下依次填入两个电子，即得 $\pi$ 电子能量 $E_\pi = n_\mathrm{e}\,\alpha + \left(\sum_{\text{occ}} x\right)\beta$，其中 $n_\mathrm{e}$ 是 $\pi$ 电子数。
:::

这就是 [[quantum-chemistry/approximation-methods]] 的变分线性方法把 [[#def-huckel-model]] 的哈密顿量代入 $HC = ESC$ 的结果；除了这些，什么也不必再假设，下面的一切结果都是线性代数。

:::example 乙烯：$2 \times 2$ 行列式 {#ex-ethene}
求解乙烯 $\mathrm{H_2C=CH_2}$ 的 Hückel 问题，给出 $\pi$ 电子能量。
:::solution
久期方程为 $xc_1 + c_2 = 0$ 与 $c_1 + xc_2 = 0$，于是 $x^2 - 1 = 0$，$x = \pm 1$：
$$
E_\pm = \alpha \pm \beta, \qquad
\psi_\pm = \tfrac{1}{\sqrt 2}(\phi_1 \pm \phi_2).
$$
较低的状态（$x = +1$，成键，两核之间没有节面）收下两个 $\pi$ 电子：$E_\pi = 2\alpha + 2\beta$，是一个电子定域在一个 $\mathrm{p_z}$ 轨道上时能量的两倍——$\pi$ 键就是让电子同时住在两个碳上而赚到的能量 $2|\beta|$。上面的轨道 $\psi_-$ 带着它的节面，系数 $x = -1$，是*反键*轨道；这套语言和 $\sigma/\pi$ 图景来自 [[bonding-structure/molecular-orbitals]]，只不过在这里它们是被算出来的，而不是被断言的。
:::
:::

:::example 烯丙基：三个碳，一个非键能级 {#ex-allyl}
建立并求解烯丙基体系 $\mathrm{C_1-C_2-C_3}$ 的久期行列式，求烯丙基正离子 $\mathrm{C_3H_5^+}$ 的 $\pi$ 电子能量与电荷分布。
:::solution
以 $x = (E-\alpha)/\beta$ 记，行列式为
$$
\begin{vmatrix} x & 1 & 0 \\ 1 & x & 1 \\ 0 & 1 & x \end{vmatrix}
= x(x^2 - 1) - x = x(x^2 - 2) = 0
\qquad\Longrightarrow\qquad
x = \sqrt 2,\ 0,\ -\sqrt 2,
$$
$$
E = \alpha + \sqrt 2\,\beta\ (\times 1), \quad \alpha\ (\times 1), \quad \alpha - \sqrt 2\,\beta\ (\times 1).
$$
中间那个能级的 $x = 0$：能量恰为 $\alpha$，是一个*非键*分子轨道，其系数满足 $c_1 + c_3 = 0$ 且 $c_2 = 0$——它只住在两端，对能量既无帮助也无妨害。正离子有 $2$ 个 $\pi$ 电子，双双住进最上面的能级：$E_\pi = 2\alpha + 2\sqrt 2\,\beta = 2\alpha + 2.828\,\beta$。对比另一幅图像——一个定域的 $\mathrm{C=C}$ 双键加一个空的 $\mathrm{p}$ 轨道，能量 $2\alpha + 2\beta$：离域使正离子降低了 $2(\sqrt 2 - 1)|\beta| = 0.828\,|\beta|$，这就是*离域能*（DE）。占据轨道的系数是 $c_1 = c_3 = 1/2$、$c_2 = 1/\sqrt 2$，所以两电子在两端的电子密度为 $2c_1^2 = 2c_3^2 = 0.5$、在中间为 $2c_2^2 = 1.0$：C2 恰好保住了它中性时应得的一个 $\pi$ 电子，而缺席的那个电子——整个 $+1$ 电荷——均等地坐在 C1 与 C3 上。这正是正离子的弯箭头共振式所说的事，如今带上了数字。
:::
:::

## 丁二烯：共轭、键级与颜色

:::example 丁-1,3-二烯 {#ex-butadiene}
求解丁二烯的 Hückel 行列式，得出四个能级、相对两个孤立双键的离域能、$\pi$ 键级以及 HOMO–LUMO 能隙。
:::solution
链状 $\mathrm{C_1-C_2-C_3-C_4}$ 的久期行列式为
$$
\begin{vmatrix} x & 1 & 0 & 0 \\ 1 & x & 1 & 0 \\ 0 & 1 & x & 1 \\ 0 & 0 & 1 & x \end{vmatrix}
= x^4 - 3x^2 + 1 = 0
\qquad\Longrightarrow\qquad
x^2 = \tfrac{3 \pm \sqrt 5}{2},
$$
$$
x = 1.618,\ 0.618,\ -0.618,\ -1.618
\qquad (\text{黄金分割 } \varphi = 1.618 \text{ 登场了}).
$$
四个 $\pi$ 电子填满上面两个能级：$E_\pi = 2(1.618 + 0.618)\beta + 4\alpha = 4\alpha + 4.472\,\beta$。对比两个孤立乙烯键的 $2(2\alpha + 2\beta) = 4\alpha + 4\beta$，离域能为 $0.472\,|\beta|$——共轭确实稳定了丁二烯，尽管远不及我们即将在苯处看到的 $2|\beta|$。键级 $p_{rs} = \sum_{\text{occ}} n_j c_{jr}c_{js}$ 算得
$$
p_{12} = 2(0.372 \times 0.602) + 2(0.602 \times 0.372) = 0.894,
\qquad
p_{23} = 2(0.602^2 - 0.372^2) = 0.447,
$$
所以形式上的单键 C2–C3 携带着 $0.45$ 个 $\pi$ 键：它更短，且有旋转势垒；而末端碳表现出增强的反应活性（“自由价”）——“共轭把双键摊开”这句话的定量版本。最低激发把一个电子从 HOMO（$x = 0.618$）提升到 LUMO（$x = -0.618$），能隙 $1.236\,|\beta|$。

诚实的定标：把丁二烯实测的 $217\ \mathrm{nm}$ 吸收（$E = 1240/217 = 5.71\ \mathrm{eV}$）当作这个能隙，得 $|\beta| = 5.71/1.236 = 4.6\ \mathrm{eV}$。同一个 $\beta$ 将*无法*复现热化学数据（见下文）——请记住这份紧张关系。
:::
:::

:::proposition 配对定理 {#prop-pairing}
若 $\pi$ 网络是*交替*的——其原子可分成两套（“加星”与“未加星”），使得每条键都只连接不同套的原子——则它的本征值成对出现：$x$ 与 $-x$。特别地，成键能级与反键能级数目相等；而奇数交替烃（烯丙基、苄基）必有一个位于 $x = 0$ 的非键能级。
:::

:::proof
设 $\{c_r\}$ 满足 $\sum_{s \to r} c_s = x c_r$（对 $r$ 的邻居 $s$ 求和）。给原子加星，使加星原子的每个邻居都未加星，并定义 $c'_r = c_r$（加星处）、$c'_r = -c_r$（未加星处）。当 $r$ 加星时，$\sum_{s \to r} c'_s = -\sum_{s \to r} c_s = -x c_r = -x c'_r$；当 $r$ 未加星时，$\sum_{s \to r} c'_s = +\sum_{s \to r} c_s = x c_r = -x c'_r$。于是 $\{c'_r\}$ 是以 $-x$ 为本征值的解：谱关于 $\alpha$ 对称。奇数交替烃两套原子数不等（加星的一套多一个原子），$N$ 个本征矢量不可能全部配对，必有一个满足 $x = -x$，即 $x = 0$。$\blacksquare$
:::

:::warning 离域能取决于你减去哪个参考 {#warn-de}
上面引用的每个 DE 都是相对某组选定的定域双键——现实中并不作为分子存在的乙烯单元——之差。换参考（用环己烯代替乙烯，或用氢化数据），数字就会变。更糟的是，没有任何一个 $\beta$ 能自圆其说：丁二烯的光谱要求 $|\beta| \approx 4.6\ \mathrm{eV}$，苯的实验共振能（$\approx 150\ \mathrm{kJ\,mol^{-1}}$）对照 $2|\beta|$ 要求 $|\beta| \approx 0.8\ \mathrm{eV}$，而丁二烯自己的实验共轭能（$\approx 15\ \mathrm{kJ\,mol^{-1}}$）对照 $0.472|\beta|$ 要求的还要小。失败不在算术——在于单组态的 $\pi$ 模型忽略了电子关联与 $\sigma$ 骨架弛豫，而它们的抵消方式因体系而异。Hückel 离域能只能用来*排序*（苯 ≫ 丁二烯 ≫ 烯丙基），绝不能用来*做预算*。
:::

## 苯与 $4n + 2$ 规则

:::example 苯 {#ex-benzene}
求解苯环的 Hückel 问题，导出它的离域能、键级，以及它的六个键为何等同的理由。
:::solution
环状六元行列式（链状行列式加四个角上的 $1$）分解为
$$
\det(xI - A) = x^6 - 6x^4 + 9x^2 - 4 = (x - 2)(x + 2)(x - 1)^2(x + 1)^2,
$$
即环的本征值为 $x_k = 2\cos(2\pi k/6)$，$k = 0, \dots, 5$：
$$
x = 2,\quad 1,\ 1,\quad -1,\ -1,\quad -2
\qquad\Longrightarrow\qquad
E = \alpha + 2\beta,\ \alpha + \beta\ (\times 2),\ \alpha - \beta\ (\times 2),\ \alpha - 2\beta .
$$
六个 $\pi$ 电子恰好填满最低的三个能级：$E_\pi = 2(\alpha+2\beta) + 4(\alpha+\beta) = 6\alpha + 8\beta$。对比三个孤立双键的 $6\alpha + 6\beta$，离域能为 $2|\beta|$——我们遇到的所有烃中每个电子最大的离域能，也是“芳香稳定化”的量子力学内容。成键的那组能级是*闭合*的：全部填满，与空着的反键组之间隔着 $2|\beta|$ 的能隙。

相邻原子间的键级：对三个占据能级求和 $2c_rc_s$，每条键都得 $p_{12} = 2/3$——六个键完全相同，介于单键（$0$）与双键（$1$）之间，与 X 射线衍射的结果（$0.139\ \mathrm{nm}$，介于 $0.154$ 与 $0.134\ \mathrm{nm}$ 之间）严丝合缝。配对定理（[[#prop-pairing]]）保证谱必然对称：苯是交替烃，加星与未加星两套各三个原子。
:::
:::

环谱 $x_k = 2\cos(2\pi k/N)$ 有一幅漂亮的图像：把 $N$ 边形内接于半径为 $2$ 的圆，一个顶点朝下；各顶点的高度就是以 $\beta$ 为单位的能级（**福斯特圆**）。六边形：一个顶点在 $+2$，两个在 $+1$，两个在 $-1$，一个在 $-2$。

:::proposition $4n + 2$ 规则 {#prop-4n2}
一个含 $N$ 个环原子的单环共轭烃，当且仅当它拥有 $2, 6, 10, 14, \dots$ 个 $\pi$ 电子（即 $4n + 2$ 个）时，其成键 $\pi$ 能级构成闭壳层——一个非简并的最低能级之后跟着成对的简并能级且全部填满。含 $4n$ 个 $\pi$ 电子的环则有一个半满的简并对，是开壳层的。
:::

:::proof
环能级为 $x_k = 2\cos(2\pi k/N)$，$k = 0, 1, \dots, N-1$：$x = 2$ 处一个能级（所有系数相等，无节面），随后是能量成对相等的 $k$ 与 $N-k$，并且——仅当 $N$ 为偶数时——$x = -2$ 处一个能级（系数完全交替）。从上往下填：$x = 2$ 能级收 $2$ 个电子，每对简并轨道收 $4$ 个。闭壳层因此容纳 $2 + 4m$ 个电子：恰是 $4n + 2$。$4n$ 个电子则把最后一对简并轨道填到一半（两个电子分住两个等能量轨道），按洪特规则不稳定，并诱发了破坏对称性的畸变——这就是反芳香的情形。$\blacksquare$
:::

所以在这个模型里，芳香性不是什么神秘的额外作用力：它是*对环做的闭壳层算术*，与原子情形下稀有气体之所以惰性的理由同出一源（[[quantum-chemistry/many-electron-atoms]]）。它的实验特征——额外的稳定性、均等化的键长、环电流在核磁共振中留下的抗磁位移印记（[[spectroscopy/nmr-principles]]）——都由闭壳层导出。

:::quiz
下列物种中，哪个的 Hückel 基态是闭壳层的？
- [ ] 环丁二烯，$\mathrm{C_4H_4}$
- [x] 卓鎓离子，$\mathrm{C_7H_7^+}$
- [ ] 环戊二烯基正离子，$\mathrm{C_5H_5^+}$
- [ ] 烯丙基自由基，$\mathrm{C_3H_5^{\bullet}}$
:::solution
卓鎓离子有 $6$ 个 $\pi$ 电子——$4n + 2$ 的数目——把 $x = 2$ 和简并的 $x = 1.247$ 一对恰好填满。环丁二烯（$4e$）与环戊二烯基正离子（$4e$）都把简并对填到一半（开壳层，反芳香），烯丙基自由基（$3e$）则让非键能级单占据。
:::
:::

## 反芳香性与芳香离子

:::example 环丁二烯：拒绝当正方形的正方形 {#ex-cbd}
把 Hückel 理论用于正方形的环丁二烯，判断它是否芳香。
:::solution
正方环的 $x_k = 2\cos(2\pi k/4)$：$x = 2,\ 0,\ 0,\ -2$，于是它的四个 $\pi$ 电子给出 $E_\pi = 4\alpha + 4\beta$——相对两个孤立双键的离域能为*零*。更糟的是，两个非键能级简并且半满（按洪特规则各住一个电子）：开壳层的正方形意味着极端的反应活性。分子逃生的办法是畸变成矩形，从而解除简并（一对相对的键成键、另一对反键），代价是把双键定域化——一次 Jahn–Teller 畸变。用 Hückel 的话说，反芳香性不是“芳香性的反面”，而是*闭合壳层失败*：没有离域能，开壳层，发生畸变。环丁二烯在低温下可以检出，温度稍高几秒内即二聚。
:::
:::

:::example 五元环与七元环离子 {#ex-ions}
环戊二烯基的能级为 $x = 2,\ 0.618\ (\times 2),\ -1.618\ (\times 2)$。请对 $\mathrm{C_5H_5^-}$、$\mathrm{C_5H_5^{\bullet}}$ 与 $\mathrm{C_5H_5^+}$ 作出分类；并对七元环的卓鎓离子 $\mathrm{C_7H_7^+}$ 作同样的处理，其能级为 $x = 2,\ 1.247\ (\times 2),\ -0.445\ (\times 2),\ -1.802\ (\times 2)$。
:::solution
负离子有 $6$ 个 $\pi$ 电子：$2 + 4$ 恰好填满闭壳层，$E_\pi = 6\alpha + 6.472\,\beta$——芳香性；环戊二烯（$\mathrm{p}K_\mathrm{a} = 16$）之所以酸性与水相当——对碳氢化合物的 C–H 键而言这是荒谬的——唯一合理的解释就是其共轭碱是芳香性的。自由基（$5e$）与正离子（$4e$）都把简并对填到一半——开壳层，非芳香或反芳香，相应地难以捉摸。卓鎓离子把 $6$ 个 $\pi$ 电子填入 $2$ 与 $1.247 \times 2$ 的能级：闭壳层，$E_\pi = 6\alpha + 8.99\,\beta$，芳香性——这就是卓鎓盐能装进试剂瓶的原因，这个事实在 Hückel 之前无从理解。$2, 6, 10$ 个电子闭合 $3, 5, 7$ 元环的模式，正是 $4n+2$ 规则在苯之外的应用。
:::
:::

## 稠环：萘

:::example 萘 {#ex-naph}
建立萘的 $10 \times 10$ Hückel 行列式并解读其解：$x = 2.303,\ 1.618,\ 1.303,\ 1.000,\ 0.618,\ -0.618,\ -1.000,\ -1.303,\ -1.618,\ -2.303$。
:::solution
十个 $\pi$ 电子填满上面五个能级：$E_\pi = 2(2.303 + 1.618 + 1.303 + 1.000 + 0.618)\beta + 10\alpha = 10\alpha + 13.68\,\beta$。相对五个孤立双键，离域能为 $3.68\,|\beta|$——总量上大于苯的 $2|\beta|$，但每环只有 $1.84\,|\beta|$，苯是 $2|\beta|$：萘是芳香性的，但*每环的芳香性更低*，它（氧化、加成）比苯更容易反应，恰如每环数字所预言。谱关于 $x = 0$ 对称——萘是交替烃（两套各 $5$ 个）——而 HOMO–LUMO 能隙 $1.236\,|\beta|$ 小于苯的 $2|\beta|$，所以它吸收更偏红（$315\ \mathrm{nm}$ 对 $204\ \mathrm{nm}$），并发出蓝色荧光。建立行列式是习题的事；求解它是计算机的事，而这正是历史的寓意：Hückel 的化学跑在它的算术前面，直到二十世纪四十年代，Coulson 学派（借助手摇计算机）才把苯型烃的数据表填满。
:::
:::

## 杂原子、模型的边界与后继者

杂原子的引入方式是改动相关原子上的两个数字：$H_{rr} = \alpha + h_\mathrm{X}\beta$，与它成键的 $H_{rs} = k_{\mathrm{X,C}}\beta$，其中 $h, k$ 由实验数据拟合——这些规则是*经验推广*，不是推导。[[#ex-count]] 的记账法承担了化学的绝大部分：吡啶的氮贡献一个 $\pi$ 电子（它的孤对电子在分子平面内，$\pi$ 体系看不见它，这正是吡啶虽为芳香族却是一把趁手的碱——共轭酸 $\mathrm{p}K_\mathrm{a} = 5.2$——的原因），而吡咯的氮贡献两个（孤对电子*就是*芳香六隅体的三分之二，所以质子化氮意味着赔上芳香性，吡咯因此是极弱的碱）。呋喃、噻吩、组氨酸里的咪唑、血红素里的卟啉：同样的两个参数，加一张图。

这套模型的局限值得单独总结。一个 $\beta$ 管所有键，几何被抹平；一个组态，关联能就被略去（[[#warn-de]] 那场离域能灾难的根源）；模型对 $\sigma$ 骨架只字不提，所以它无法预言分子*是否*平面，只能告诉你平面能换来什么；由轨道能隙得到的跃迁能量，也漏掉了本该包含的电子–空穴吸引（[[spectroscopy/electronic-spectroscopy]]）。历经这一切而幸存下来的，是它的概念内核——拓扑决定能级图样，闭壳层决定稳定性，前线轨道（HOMO、LUMO）决定反应性——而它之所以幸存，是因为它是一套系统展开的首项。后继者每丢掉一个近似都要补上另一个：扩展 Hückel 与半经验方法保住图、加上参数化；Hartree–Fock（[[computational-chemistry/hartree-fock]]）与密度泛函理论（[[computational-chemistry/density-functional-theory]]）保住“电子在场中运动”的念头，改由波函数或密度自洽地计算这个场，对所有电子，不再要 $\beta$。Hückel 理论就是电子结构计算把一切丢得起的东西全丢掉之后的样子——这也正是它至今仍是化学家计算的第一个对象的原因。

:::history
Robinson 在 1925 年提出芳香六隅体——六个电子是关键数字，却没有任何机制。Hückel 在 1931 年补上了机制，把平面烃的 $\pi$ 问题约化为一个久期行列式，并对环提出了 $4n + 2$ 规则；他发表在《物理学手册》（*Handbuch der Physik*，1936 年）中的“量子数学”一章使其广为流传。Pauling、Sherman 与 Whatley 在 1933 年用热化学测出苯的共振能，开启了 Hückel 的数字与量热计之间的长期争论。Coulson 在 1939–1941 年的系列论文建立了交替烃理论——配对定理、$\pi$ 键级、自由价；Wheland 1944 年的专著把这套形式化语言交到化学家手中。Frost 的圆口诀（1953 年）让环能级图变成一道作图题，而 Dewar 在二十世纪五十年代开创的前线轨道与微扰分子轨道纲领，把 HOMO 与 LUMO 从记账工具变成了反应机理的语言。
:::

## 通向何处

本文导出的能级图样，是 [[spectroscopy/electronic-spectroscopy]]（能隙即颜色）与 [[spectroscopy/nmr-principles]]（环电流即芳香印记）的 $\pi$ 体系输入；闭壳层论证是 [[bonding-structure/molecular-orbitals]] 的量子力学一半；久期行列式技术小处是 [[quantum-chemistry/approximation-methods]]，大处是 [[computational-chemistry/hartree-fock]]；而这些能级理应带上的对称性标签，则由 [[quantum-chemistry/molecular-symmetry]] 提供——它还顺便解释了苯的 $204\ \mathrm{nm}$ 带为何强、$255\ \mathrm{nm}$ 带为何弱。用箱中粒子估算同一组多烯能隙（[[quantum-chemistry/model-systems]]）是上文 $1/N$ 定律的连续极限表亲——两个彼此独立的量子模型，在颜色的算术上不谋而合。

:::summary
- Hückel 理论只保留平面共轭分子的 $\pi$ 电子：$H_{rr} = \alpha$，成键对 $H_{rs} = \beta < 0$，$S = I$；问题就是一张图的邻接矩阵，$E = \alpha + x\beta$。
- 乙烯给出 $E_\pi = 2\alpha + 2\beta$；烯丙基多出一个位于 $\alpha$ 的非键能级，其正离子离域能为 $0.83|\beta|$，正电荷均分在两端碳上。
- 丁二烯：$x = \pm 1.618, \pm 0.618$，$E_\pi = 4\alpha + 4.472\beta$，离域能 $= 0.472|\beta|$，键级 $0.894/0.447$，能隙 $1.236|\beta|$——多烯能隙按 $4|\beta|\sin(\pi/2(N+1))$ 收缩，颜色随共轭增长而来。
- 苯：$E_\pi = 6\alpha + 8\beta$，离域能 $= 2|\beta|$，所有键级 $2/3$，闭壳层且能隙 $2|\beta|$——芳香性即闭壳层算术。
- $4n + 2$ 规则源于环能级 $2\cos(2\pi k/N)$（福斯特圆）：闭壳层容纳 $2, 6, 10, \dots$ 个电子；$4n$ 个电子的环开壳层并发生畸变（环丁二烯）。
- 芳香离子闭合同样的壳层：$\mathrm{C_5H_5^-}$ 与 $\mathrm{C_7H_7^+}$ 是芳香性的；萘是芳香性的，但每环少一些（$1.84|\beta|$ 对 $2|\beta|$）。
- 没有任何一个 $\beta$ 能同时迁就光谱（由丁二烯得 $\approx 4.6\ \mathrm{eV}$）与热化学（由苯得 $\approx 0.8\ \mathrm{eV}$）：Hückel 离域能只排序，不做预算。
- 模型幸存的内核——拓扑、闭壳层、前线轨道——是每一个现代电子结构方法的首项。
:::

## 习题

:::exercise 烯丙基自由基 {level=1 check="2.828"}
烯丙基能级为 $x = \sqrt 2, 0, -\sqrt 2$。烯丙基*自由基*有三个 $\pi$ 电子。把 $E_\pi = 3\alpha + c\,\beta$ 写出，填入 $c$。
:::solution
两个电子占据 $x = \sqrt 2$，一个电子占据 $x = 0$：$E_\pi = 2\alpha + 2\sqrt 2\,\beta + \alpha = 3\alpha + 2.828\,\beta$，故 $c = 2\sqrt 2 = 2.828$。非键电子分文不取——这就是烯丙基自由基如此容易生成的原因。
:::
:::

:::exercise 丁二烯的颜色 {level=1 check="2.97"}
取 $|\beta| = 2.40\ \mathrm{eV}$。丁二烯的 HOMO–LUMO 能隙是多少 eV？（填入以 eV 为单位的能隙。）
:::solution
能隙 $= (0.618 - (-0.618))|\beta| = 1.236 \times 2.40 = 2.97\ \mathrm{eV}$，即 $\lambda = 1240/2.97 = 418\ \mathrm{nm}$。实测吸收在 $217\ \mathrm{nm}$——用热化学定出的 $\beta$ 的单参数模型严重低估了能隙，这是 [[#warn-de]] 中定标问题的另一副面孔。
:::
:::

:::exercise 苯的稳定化能 {level=1 check="480"}
取 $|\beta| = 240\ \mathrm{kJ\,mol^{-1}}$。苯的 Hückel 离域能是多少 $\mathrm{kJ\,mol^{-1}}$？（填入离域能。）
:::solution
离域能 $= 2|\beta| = 480\ \mathrm{kJ\,mol^{-1}}$。实验共振能只有约 $150\ \mathrm{kJ\,mol^{-1}}$：即便在这个（已经偏低的）$\beta$ 下模型仍高估三倍，因为被略去的关联与 $\sigma$ 项并不小——排序可以，做预算不行。
:::
:::

:::exercise 环戊二烯负离子 {level=2 check="6.472"}
环戊二烯基能级为 $x = 2, 0.618\ (\times 2), -1.618\ (\times 2)$。把 $\mathrm{C_5H_5^-}$ 的 $\pi$ 电子能量写成 $6\alpha + c\,\beta$，填入 $c$。
:::solution
六个电子：$2$ 个在 $x = 2$，$4$ 个在简并的 $x = 0.618$ 一对：$c = 2(2) + 4(0.618) = 4 + 2.472 = 6.472$。壳层闭合——芳香性——这就是 $\mathrm{C_5H_5^-}$ 如此容易生成的原因（环戊二烯 $\mathrm{p}K_\mathrm{a} = 16$）。
:::
:::

:::exercise 烯丙基负离子的键级 {level=2 check="0.707"}
烯丙基负离子的占据能级为 $\psi_1$（$x = \sqrt 2$，系数 $1/2, 1/\sqrt 2, 1/2$）与 $\psi_2$（$x = 0$，系数 $1/\sqrt 2, 0, -1/\sqrt 2$）。计算 C1 与 C2 之间的 $\pi$ 键级 $p_{12} = \sum_{\text{occ}} n_j c_{j1}c_{j2}$。（填入 $p_{12}$。）
:::solution
四个电子，每个能级两个：$p_{12} = 2(\tfrac12 \cdot \tfrac{1}{\sqrt 2}) + 2(\tfrac{1}{\sqrt 2}\cdot 0) = 0.707$。非键分子轨道对成键毫无贡献（它的 C2 系数为零）：负离子多出来的电子对住在一个把两端与中间“断开”的轨道里——离域，却不在相邻原子间成键。
:::
:::

:::exercise 用己三烯定标 $\beta$ {level=2 check="5.40"}
己三烯（$N = 6$）在 $258\ \mathrm{nm}$ 吸收；其 Hückel 能隙为 $4|\beta|\sin(\pi/14)$。由这条谱线求 $|\beta|$，单位 eV。（填入以 eV 为单位的 $|\beta|$。）
:::solution
$E = 1240/258 = 4.81\ \mathrm{eV}$；$\sin(\pi/14) = 0.2225$，故能隙为 $0.890\,|\beta|$，$|\beta| = 4.81/0.890 = 5.40\ \mathrm{eV}$。可丁二烯要的是 $4.6\ \mathrm{eV}$，苯的热化学要的是 $0.8$：一个参数拟合不了三个实验，拟合值随体系漂移，正是模型略去关联留下的指纹。
:::
:::

:::exercise 推导环谱 {level=3}
证明环状 Hückel 方程 $c_{r-1} + c_{r+1} = x c_r$（指标模 $N$）的解为 $c_r = N^{-1/2} e^{2\pi i k r/N}$，对应 $x_k = 2\cos(2\pi k/N)$，并由此导出 $N$ 元环的福斯特圆能级图样。$4n+2$ 的计数究竟在哪里进入？
:::solution
代入即得：$e^{2\pi ik(r-1)/N} + e^{2\pi ik(r+1)/N} = e^{2\pi ikr/N}(e^{-2\pi ik/N} + e^{2\pi ik/N}) = 2\cos(2\pi k/N)\, c_r$，故 $x_k = 2\cos(2\pi k/N)$——即内接于半径 $2$、一顶点朝下的圆的 $N$ 边形各顶点的高度（福斯特圆）。周期性把 $k$ 限制为 $N$ 个整数，给出 $x = 2$ 处一个能级、$k$ 与 $N-k$ 的简并对，以及（仅偶数 $N$）$x = -2$ 处一个能级。从 $x = 2$ 开始每个能级填两个电子：非简并的最低能级收 $2$ 个，每对简并轨道收 $4$ 个，闭壳层因此容纳 $2 + 4m = 4n + 2$ 个电子；$4n$ 个电子则把一对简并轨道填到一半。$4n+2$ 规则就是这份填充的算术——没有额外的物理。
:::
:::

:::exercise 卓鎓三重奏 {level=3}
利用卓鎓离子能级 $x = 2,\ 1.247\ (\times 2),\ -0.445\ (\times 2),\ -1.802\ (\times 2)$，对正离子、自由基与负离子 $\mathrm{C_7H_7^{\pm}}$ 分别计算 $E_\pi$（写成 $n_e\,\alpha + c\beta$，$n_e$ 为 $\pi$ 电子数），并预言哪些能以稳定的闭壳层物种存在。
:::solution
正离子（$6e$）：$c = 2(2) + 4(1.247) = 8.99$——闭壳层，芳香性，稳定（卓鎓四氟硼酸盐是可以装瓶的固体）。自由基（$7e$）：$c = 8.99 - 0.445 = 8.545$——反键简并对里多出一个电子，开壳层，活泼。负离子（$8e$）：$c = 8.99 - 2(0.445) = 8.10$——仍是开壳层（按洪特规则简并对中各住一个电子），与反芳香沾边，作为自由离子无人得见。这个家族里只有 $4n+2$ 的成员闭合了壳层；七元环对 $6$ 个电子芳香，对 $7$ 个或 $8$ 个则不。
:::
:::

:::exercise 用计算机算萘 {level=3 check="1.84"}
写出萘（两个六元环共用一条边）的 $10 \times 10$ 邻接矩阵，数值求其本征值。以 $|\beta|$ 为单位计算相对五个孤立双键的离域能，再给出*每环*的离域能。（填入以 $|\beta|$ 为单位的每环离域能。）
:::solution
本征值为 $x = \pm 2.303, \pm 1.618, \pm 1.303, \pm 1.000, \pm 0.618$（对称——配对定理，两套各 $5$ 个）。十个电子：$E_\pi = 10\alpha + 13.68\,\beta$，离域能总量 $= 3.68\,|\beta|$，每环 $1.84\,|\beta|$，苯为 $2|\beta|$。萘每环付出的芳香稳定化少于苯——与它更易氧化、更易加成的化学性质一致，也与“苯环稠合必然摊薄每环芳香性”这一事实一致。
