[[quantum-chemistry/quantum-foundations]]中的薛定谔方程是一个微分方程，而像一切微分方程那样，它只对少数几个势能精确可解。这少数几个并非数学便利的偶然：势箱、台阶、环、振子、转子与库仑势，正是真实分子的哈密顿量在其重要构型附近所取的*形状*，这就是为什么把它们解通一次便一劳永逸地换来理解。一个共轭染料对它的 $ \pi $ 电子就是一个势箱；核内的一个 $ \alpha $ 粒子是一个躲在势垒后面、却能渗漏出去的粒子；绕苯环运动的电子是环上的粒子；而这些对应中的每一个，都把一幅定性的化学图像变成了一台光谱仪可以对照的数字。

本课求解平动的模型体系——一维、二维与三维的无限与有限方势阱，以及环——并把每一个都用到一个化学问题上。三个主题贯穿始终。其一，*量子化是边界条件的效应*：束缚态之所以分立，是因为局域在一区域内的波必须装下整数个半波长，而不是因为加入了什么新物理。其二，*波函数是概率幅*：探测器数的是 $ |\psi|^{2} $ 而不是 $ \psi $，量子概率与经典概率的差别即使在势箱基态里也清晰可见。其三，*指数规律称王*：在经典禁区里波函数按 $ e^{-\kappa x} $ 衰减，而正是这个衰减——而不是任何翻越势垒的英雄主义——让扫描隧道显微镜能看见原子、让原子核在地质年代里嬗变。

## 一维无限方势阱

::: definition 无限方势阱 {#def-well}
长度为 $ L $ 的**无限方势阱**（一维势箱中的粒子）是如下势能：
$$
V(x) = \begin{cases} 0, & 0 \le x \le L, \\ \infty, & \text{其他}。 \end{cases}
$$
阱内粒子自由运动；阱壁不可穿透，所以波函数必须在 $ x = 0 $ 与 $ x = L $ 处以及阱外为零。它是这样一类情形的理想化：电子被远大于所关心能量的势约束在分子尺度的区域内——染料链上的一个 $ \pi $ 电子，或金属表面的一个电子。
:::

阱内 $ V = 0 $，定态薛定谔方程不过是 $ -\left(\hbar^{2}/2m\right)\mathrm{d}^{2}\psi/\mathrm{d}x^{2} = E\psi $，其通解是两个行波的叠加，等价地是一个驻波与一个余弦的叠加。物理全在那两个边界条件里。

::: proposition 势箱中的粒子 {#prop-box}
质量为 $ m $ 的粒子在长度为 $ L $ 的一维势箱中具有归一化本征函数与本征值
$$
\psi_{n}(x) = \sqrt{\frac{2}{L}}\,\sin\frac{n\pi x}{L}, \qquad
E_{n} = \frac{n^{2}h^{2}}{8mL^{2}}, \qquad n = 1, 2, 3, \dots
$$
量子数 $ n $ 从 $ 1 $ 开始：不存在零能态，**零点能** $ E_{1} = h^{2}/8mL^{2} $ 就是粒子可能的最低能量。
:::

::: proof
阱内方程为 $ \psi'' = -k^{2}\psi $，其中 $ k^{2} = 2mE/\hbar^{2} $。通解为 $ \psi = A\sin kx + B\cos kx $。$ x = 0 $ 处的阱壁给出 $ \psi(0) = B = 0 $；于是 $ x = L $ 处的阱壁要求 $ \sin kL = 0 $，故 $ kL = n\pi $，$ n $ 为正整数（$ n = 0 $ 会使 $ \psi $ 处处为零，负 $ n $ 只改变一个整体符号）。因此 $ k_{n} = n\pi/L $，
$$
E_{n} = \frac{\hbar^{2}k_{n}^{2}}{2m} = \frac{n^{2}\pi^{2}\hbar^{2}}{2mL^{2}} = \frac{n^{2}h^{2}}{8mL^{2}} 。
$$
归一化定出 $ A $：$ \int_{0}^{L}A^{2}\sin^{2}(n\pi x/L)\,\mathrm{d}x = A^{2}L/2 = 1 $，故 $ A = \sqrt{2/L} $。整数 $ n $ 在推导中哪里都没有被假设过——它是波必须适配在两壁之间的要求所强制的，正如弦的泛音由其端点所强制。
:::

有用的数值形式来自 $ h^{2}/8m_{\mathrm{e}} = 0.376\ \mathrm{eV\,nm^{2}} $：对电子，$ E_{1}/\mathrm{eV} = 0.376/(L/\mathrm{nm})^{2} $。分子尺度的约束花费几个电子伏特——与化学键和紫外光同一货币——这就是为什么量子力学而非经典物理是化学的自然语言（见 [[general-chemistry-1/quantum-atom]]）。

::: example 分子尺寸势箱里的电子 {#ex-electron-box}
一个电子被约束在长度 $ L = 0.50\ \mathrm{nm} $ 的一维势箱中，大约是一个小共轭分子的长度。求前两个能级，以及 $ 1 \rightarrow 2 $ 跃迁吸收的光的波长。
::: solution
由 $ h^{2}/8m_{\mathrm{e}} = 0.376\ \mathrm{eV\,nm^{2}} $，
$$
E_{1} = \frac{0.376}{(0.50)^{2}} = 1.50\ \mathrm{eV}, \qquad
E_{2} = 4E_{1} = 6.02\ \mathrm{eV}。
$$
跃迁能为 $ \Delta E = E_{2} - E_{1} = 3E_{1} = 4.51\ \mathrm{eV} $，由 $ hc = 1240\ \mathrm{eV\,nm} $，
$$
\lambda = \frac{1240\ \mathrm{eV\,nm}}{4.51\ \mathrm{eV}} = 275\ \mathrm{nm}，
$$
紫外光。一个分子尺寸势箱里的单个电子已经像分子一样吸收：电子光谱的量级从 $ h^{2}/8mL^{2} $ 里自己掉出来，不需任何额外输入。另注意能梯结构 $ E_{n} \propto n^{2} $：间距随能量*变宽*，$ \Delta E_{n\rightarrow n+1} = (2n + 1)E_{1} $，与氢原子相反——在那里间距变窄（[[quantum-chemistry/hydrogen-atom]]）。
:::
:::

## 波函数在说什么

定态是含 $ n - 1 $ 个内部**波节**的驻波，波节处 $ \psi = 0 $ 因而 $ \psi^{2} = 0 $：处于状态 $ n $ 的粒子在这些点上*永远*不会被找到，这是一个没有经典类比的陈述。概率密度 $ \psi_{n}^{2} = (2/L)\sin^{2}(n\pi x/L) $ 远非均匀，而这正是玻恩解释第一次做实事的地方。

::: widget plot
f: 2*sin(pi*x)^2; 2*sin(2*pi*x)^2; 2*sin(3*pi*x)^2
x: 0, 1
y: 0, 2.2
labels: n=1; n=2; n=3
caption: 长度为 $ L $ 的势箱最低三个状态的概率密度 $ \psi_n^2 $，对 $ x/L $ 作图。基态在中心处最大、在阱壁处为零；激发态发展出波节（共 $ n-1 $ 个），而随着 $ n $ 增大，它们的振荡平均趋向平坦的经典分布——对应原理一线可见。
:::

::: example 基态的量子概率 {#ex-prob-third}
求势箱基态粒子 (a) 出现在箱中央三分之一内、(b) 出现在中央一半内的概率，并与经典预言比较。
::: solution
$$
P = \int_{L/3}^{2L/3}\frac{2}{L}\sin^{2}\frac{\pi x}{L}\,\mathrm{d}x
= \left[\frac{x}{L} - \frac{\sin(2\pi x/L)}{2\pi}\right]_{1/3}^{2/3}
= \frac{1}{3} + \frac{\sqrt{3}}{2\pi} = 0.609 。
$$
经典地，弹跳的粒子恰好花三分之一的时间在中央三分之一内，所以量子粒子在中心处*过度*局域了 $ 1.8 $ 倍。对中央一半，同样的积分给出 $ P = \tfrac{1}{2} + 1/\pi = 0.818 $，而经典值为 $ \tfrac{1}{2} $。势箱基态是最简单的例子，说明一个将延续到每个真实分子的事实：量子粒子避开阱壁、挤在经典概率只是中等的地方。激发态在局部把符号反转——$ n = 2 $ 时密度在中心处为零——只有当 $ n $ 很大时振荡才平均回经典值。
:::
:::

::: quiz
一个粒子处于势箱的 $ n = 6 $ 态。它最可能在哪里被找到？
- [x] 在六个位置上（$ \psi_{6}^{2} $ 的极大处，即 $ x = L/12, 3L/12, \dots, 11L/12 $），其中包括靠近阱壁、经典粒子最可能出现的点，也包括经典粒子仍能到达的点。
- [ ] 只在箱中心，即基态取极大的地方。
- [ ] 均匀地：一旦 $ n $ 很大，每个位置等可能。
- [ ] 在六个波节处，即波弯曲最大的地方。
::: solution
$ \psi_{6}^{2} = (2/L)\sin^{2}(6\pi x/L) $ 有 $ n = 6 $ 个极大（在 $ x = L/12, 3L/12, \dots, 11L/12 $）与 $ 5 $ 个内部波节，波节处概率恰为零。即使在 $ n = 6 $，分布也远非均匀；均匀只在许多振荡的粗粒平均中重现，这正是对应原理的内容。波节与最概然恰恰相反：零振幅、零概率，而且——[[quantum-chemistry/huckel-theory]] 将展示——是反键的化学签名。
:::
:::

::: warning 零点能不是一张许可证 {#warn-zpe}
$ E_{1} > 0 $ 常被转述为"粒子永不能静止"，而从这一步滑到"所以没有东西真正静止，所以能从真空中提取能量"只需一个不小心的动作。诚实的内容更窄也更奇：把粒子局域到 $ L $ 的区域，由不确定性原理就强制出动量展宽 $ \Delta p \gtrsim \hbar/2L $，而这个展宽的动能就是零点能。它是约束的代价，一切被约束的东西都要付——这就是为什么它随箱变大而*减小*、对自由粒子消失。它不是一台取之不尽的能量银行：基态是*最低*态，而 $ E_{1} = h^{2}/8mL^{2} $ 的全部用处恰恰在于它不可提取。
:::

## 二维与三维：分离变量与简并

对边长为 $ L_{x}, L_{y}, L_{z} $ 的长方体箱，势能是一维项之和，$ V = V_{x}(x) + V_{y}(y) + V_{z}(z) $，方程可分离：写 $ \psi = X(x)Y(y)Z(z) $，除以 $ \psi $，每一边都必须是常数。每个因子满足自己的箱方程，于是能量直接相加。

::: proposition 高维箱中的粒子 {#prop-2d}
对不可穿透壁的长方体箱，
$$
E = \frac{h^{2}}{8m}\left(\frac{n_{x}^{2}}{L_{x}^{2}} + \frac{n_{y}^{2}}{L_{y}^{2}} + \frac{n_{z}^{2}}{L_{z}^{2}}\right), \qquad
\psi = \psi_{n_{x}}(x)\,\psi_{n_{y}}(y)\,\psi_{n_{z}}(z),
$$
量子数 $ n_{x}, n_{y}, n_{z} = 1, 2, 3, \dots $ 相互独立。当两个或更多不同状态共享同一能量时，该能级是**简并**的，状态数即其**简并度**。在立方箱中 $ L_{x} = L_{y} = L_{z} $，不同的三元组可给出相同的平方和，于是出现简并；降低对称性（拉长一条边）就把简并解除。
:::

::: example 方箱的简并度 {#ex-degeneracy}
一个粒子被约束在二维方箱中。以 $ E_{81} = h^{2}/8mL^{2} $ 为单位列出前六个能级及其简并度，并指出第一个简并来自两种*不同*激发的能级。
::: solution
这里 $ E/E_{81} = n_{x}^{2} + n_{y}^{2} $：

| $ E/E_{81} $ | 状态 $ (n_{x}, n_{y}) $ | 简并度 |
|---|---|---|
| 2 | (1,1) | 1 |
| 5 | (1,2), (2,1) | 2 |
| 8 | (2,2) | 1 |
| 10 | (1,3), (3,1) | 2 |
| 13 | (2,3), (3,2) | 2 |
| 17 | (1,4), (4,1) | 2 |

$ 5E_{81} $ 能级已经简并：$ x $ 中一个量子或 $ y $ 中一个量子花费相同，因为两边等长。第一个把*不同量子数*混在一起的简并能级是 $ 13E_{81} = 2^{2} + 3^{2} $，其简并仅来自置换；真正偶然的简并——同一平方和的不同分拆，如 $ 50E_{81} = 1^{2} + 7^{2} = 5^{2} + 5^{2} $——是数论上的稀客。三维立方箱的前几个能级以 $ h^{2}/8mL^{2} $ 为单位是 $ 3, 6, 9, 11, 12, 14 $，即和 $ n_{x}^{2} + n_{y}^{2} + n_{z}^{2} $，简并度为 $ 1, 3, 3, 3, 1, 6 $：第一个六重简并能级 $ 14 = 1^{2} + 2^{2} + 3^{2} $，是三个不同量子数的六个置换。
:::
:::

::: warning 简并是对称性，不是巧合 {#warn-degeneracy}
一切系统性的简并都是对称性的投影：方箱的二重简并说的是 $ x $ 与 $ y $ 可互换；立方箱 $ 14 $ 能级的六重简并说的是三条轴彼此等价。一旦对称性破缺——长方箱、畸变分子——简并就解除。现在要养成的习惯，正是群论将要形式化的那一个（[[quantum-chemistry/molecular-symmetry]]）：在问*什么*简并之前，先问哈密顿量*为什么允许*它简并；在相信一个算出来的简并度之前，先问什么会把它分裂。
:::

## 隧穿：有限势垒

把阱壁改成有限高 $ V_{0} $，波函数就不再在边界处死掉：垒内薛定谔方程化为 $ \mathrm{d}^{2}\psi/\mathrm{d}x^{2} = \kappa^{2}\psi $，其中 $ \kappa^{2} = 2m(V_{0} - E)/\hbar^{2} $——正曲率，指数解。让 $ \psi $ 及其斜率跨过宽度 $ L $ 的势垒匹配，对不透明势垒（$ \kappa L \gg 1 $）得透射概率

$$
T \approx e^{-2\kappa L}, \qquad
\kappa = \frac{\sqrt{2m(V_{0} - E)}}{\hbar}。
$$ {#eq-tunnel}

能量 $ E < V_{0} $ 的经典粒子一个也过不去；量子粒子却不会被*拦住*——波渗漏出去，在另一侧一个行波重新出现，振幅被穿过势垒的衰减压低。粒子并没有"借能量翻过去"：它自始至终保持能量 $ E $，垒区是波函数（而非粒子）按衰减长度 $ \kappa^{-1} $ 付账的地方。

::: example 扫描隧道显微镜为什么能看见原子 {#ex-stm}
扫描隧道显微镜（STM）中，电子在尖针与表面之间的真空隙中隧穿。把势垒高取为功函数 $ V_{0} - E = \phi = 4.5\ \mathrm{eV} $。求衰减常数，并证明每增加 $ 0.1\ \mathrm{nm} $ 间隙电流约降十倍。
::: solution
对电子，
$$
\kappa = \frac{\sqrt{2m_{\mathrm{e}}\phi}}{\hbar}
= \frac{\sqrt{2 \times 9.109\times10^{-31}\ \mathrm{kg} \times 4.5 \times 1.602\times10^{-19}\ \mathrm{J}}}{1.055\times10^{-34}\ \mathrm{J\,s}}
= 1.09\times10^{10}\ \mathrm{m^{-1}} = 10.9\ \mathrm{nm^{-1}} 。
$$
$ T = e^{-2\kappa L} $ 要降十倍需 $ 2\kappa L = \ln 10 = 2.303 $，即
$$
L = \frac{2.303}{2 \times 10.9\ \mathrm{nm^{-1}}} = 0.106\ \mathrm{nm}，
$$
约一个原子直径。[[#eq-tunnel]] 的指数就是 STM 能工作的全部理由：电流是一台具有亚埃灵敏度的高度计，所以恒流扫描逐原子地测绘表面——又因为隧穿电子取样的是表面的*波函数*而非原子核，图像是电子结构的图像。间隙从 $ 0.10\ \mathrm{nm} $ 变成 $ 0.30\ \mathrm{nm} $ 会把电流砍掉 $ e^{2 \times 10.9 \times 0.20} \approx 77 $：一层吸附分子已是一道深深的阴影。
:::
:::

同一个方程统治着原子核。一个几 MeV 的 $ \alpha $ 粒子躲在宽几十飞米、高约 $ 29\ \mathrm{MeV} $ 的库仑势垒后面；其衰变常数为 $ \lambda = \nu T $，其中尝试频率 $ \nu \sim 10^{21}\ \mathrm{s^{-1}} $ 是粒子撞击势垒的速率（$ \nu = v/2R $，速度 $ v $ 的粒子在半径 $ R $ 的核内弹跳）。因为 $ T $ 对势垒*面积*是指数关系，横跨十七个数量级的半衰期只来自因子二以内的 $ \alpha $ 能量跨度——盖革-努特尔（Geiger–Nuttall）定律，1928 年由伽莫夫（Gamow）以及格尼（Gurney）与康登（Condon）给出解释（[[#ex-gamow]]）。

## 共轭分子作为电子的势箱

::: algorithm 线性染料的自由电子箱模型 {#algo-box}
1. 数 $ \pi $ 电子：共轭链每个碳一个，共 $ N $ 个；每个箱能级容纳两个。
2. 箱长取 $ L = (N + 1) \times 140\ \mathrm{pm} $：链上每个连接取一个 C–C 键长，两端再各加一个键长给末端氢原子。
3. 从 $ n = 1 $ 向上填能级（泡利原理）：最高占据能级为 $ n = N/2 $。
4. 最低吸收为 $ n = N/2 \rightarrow N/2 + 1 $，其能量为
$$
\Delta E = \frac{\left[(N/2 + 1)^{2} - (N/2)^{2}\right]h^{2}}{8m_{\mathrm{e}}L^{2}} = \frac{(N + 1)\,h^{2}}{8m_{\mathrm{e}}L^{2}} 。
$$
5. 用 $ \lambda = hc/\Delta E $、$ hc = 1240\ \mathrm{eV\,nm} $ 换算。
:::

::: example 作为势箱的己三烯 {#ex-hexatriene}
把箱模型用于全反式己三烯 $ \mathrm{CH_2{=}CH{-}CH{=}CH{-}CH{=}CH_2} $，与其气相吸收最大 $ 258\ \mathrm{nm} $ 比较。
::: solution
六个 $ \pi $ 电子填满 $ n = 1, 2, 3 $，所以跃迁是 $ 3 \rightarrow 4 $，以 $ h^{2}/8mL^{2} $ 为单位系数为 $ (4^{2} - 3^{2}) = 7 $。箱长 $ L = 7 \times 140\ \mathrm{pm} = 0.98\ \mathrm{nm} $，故
$$
\Delta E = \frac{7 \times 0.376\ \mathrm{eV\,nm^{2}}}{(0.98\ \mathrm{nm})^{2}} = 2.74\ \mathrm{eV},
\qquad
\lambda = \frac{1240}{2.74} = 452\ \mathrm{nm}。
$$
模型预言蓝光，分子却吸收紫外：波长长了 $ 1.75 $ 倍。这一失败与成功同样有教益，下表显示它是系统性的——但模型*做对*的趋势同样是系统性的。
:::
:::

|---|---|---|---|
| 丁二烯 | 4 | 323 | 217 |
| 己三烯 | 6 | 452 | 258 |
| 辛四烯 | 8 | 582 | 290 |
| $ \beta $-胡萝卜素 | 22 | 1487 | 451 |

::: widget plot
f: a*(x+1)

labels: \text{箱模型，} \lambda = a(N+1)

:::

线性增长正是库恩自由电子定律的内容：由 $ L \propto N $ 与 $ \Delta E \propto (N + 1)/L^{2} $，跃迁能按 $ 1/N $ 下降、波长按 $ N $ 拉伸——这就是为什么增加共轭双键能把吸收从紫外一路开进可见光，为什么 $ \beta $-胡萝卜素（十一个共轭双键）吃掉蓝光而显橙色。系统性的高估有一个固体物理解释：碳核的周期势并不平坦，在 $ \pi $ 带顶附近电子的响应如同比自由电子更轻（$ m^{*} < m_{\mathrm{e}} $），这使能隙变宽、波长变短。花青染料则朝反方向失败——简单箱对七甲川离子预言 $ 460\ \mathrm{nm} $，实测 $ 780\ \mathrm{nm} $——因为它们的正电荷与可极化末端把电子云*拉伸*到核骨架之外。一个为它量身打造的分子上两个方向都会错的模型，既是警告也是老师。

::: warning 箱模型是计算器，不是图像 {#warn-boxmodel}
[[#algo-box]] 里烤进了三个误差，而没有一个误差是"电子其实不在箱里"。(i) 平坦势能忽略了核的周期拉扯，而那恰恰是打开带隙的东西。(ii) 电子彼此并不忽略：$ \pi $–$ \pi $ 排斥抬高占据能级、压低空能级，使能隙缩小。(iii) 箱长是一个带着猜测灵敏度的猜测——$ \lambda \propto L^{2} $，所以 $ L $ 上 $ 10\ \% $ 的误差是 $ \lambda $ 上 $ 20\ \% $ 的误差。用这个模型做趋势、做量级、做"共轭为什么红移"的*理由*；绝不要把它的波长当作预言引用。这些光谱的定量理论是 [[quantum-chemistry/huckel-theory]]，实验一面见 [[spectroscopy/electronic-spectroscopy]]。
:::

## 环上的粒子

把箱弯成半径 $ r $ 的圆，坐标就变成角 $ \phi $，边界条件是周期性的：$ \psi(\phi + 2\pi) = \psi(\phi) $——电子从不被约束在某段弧上，它只是分不清 $ \phi = 0 $ 在哪里。

::: proposition 环上的粒子 {#prop-ring}
半径 $ r $ 的环上（转动惯量 $ I = mr^{2} $）质量 $ m $ 的粒子有
$$
E_{m_{l}} = \frac{m_{l}^{2}\hbar^{2}}{2I} = \frac{m_{l}^{2}\hbar^{2}}{2mr^{2}}, \qquad
\psi_{m_{l}}(\phi) = \frac{1}{\sqrt{2\pi}}\,e^{\mathrm{i}m_{l}\phi}, \qquad
m_{l} = 0, \pm 1, \pm 2, \dots
$$
绕环轴的角动量量子化，$ L_{z} = m_{l}\hbar $。$ m_{l} = 0 $ 能级非简并且 $ E = 0 $——*转动没有零点能*——其余每个能级二重简并，$ +m_{l} $ 与 $ -m_{l} $（顺时针与逆时针）能量相同。
:::

::: proof
环上动能为 $ -\left(\hbar^{2}/2I\right)\mathrm{d}^{2}\psi/\mathrm{d}\phi^{2} $，所以方程是 $ \psi'' = -\left(2IE/\hbar^{2}\right)\psi $，解为 $ e^{\mathrm{i}m\phi} $，其中 $ m^{2} = 2IE/\hbar^{2} $。单值性要求 $ e^{\mathrm{i}m(\phi + 2\pi)} = e^{\mathrm{i}m\phi} $，即 $ m $ 为整数——可正、可负、可为零。这里零是允许的，与箱不同：$ e^{\mathrm{i}0\phi} $ 是常数，没有波节，也不违反任何边界条件。对 $ E $ 求解即得命题。与箱的对照就是功课：箱壁把曲率（动能）强加给基态；环的周期性却容许一个平坦、无节、零能的态。转动可以"静止"；箱中的平动不能。
:::

::: example 环电流与芳香六隅体 {#ex-benzene-ring}
把苯的 $ \pi $ 电子建模为可在半径 $ r = 140\ \mathrm{pm} $（C–C 键长）的环上自由运动的粒子。求 $ m_{l} = 0, \pm1, \pm 2 $ 能级的能量，填入六个电子，并解释为什么 $ 6 $ 在环上是闭壳层数。
::: solution
由 $ \hbar^{2}/2m_{\mathrm{e}} = 0.0381\ \mathrm{eV\,nm^{2}} $ 与 $ r = 0.14\ \mathrm{nm} $，
$$
E_{m_{l}} = m_{l}^{2}\,\frac{0.0381}{(0.14)^{2}}\ \mathrm{eV} = 1.94\,m_{l}^{2}\ \mathrm{eV}，
$$
所以能级位于 $ 0 $（$ m_{l} = 0 $，一个态）、$ 1.94\ \mathrm{eV} $（$ m_{l} = \pm1 $，两个态）与 $ 7.8\ \mathrm{eV} $（$ m_{l} = \pm2 $，两个态）。六个电子填满 $ m_{l} = 0 $（两个）与 $ m_{l} = \pm1 $（四个）：在幻数 $ 2, 6, 10, \dots $（能级 $ 0, \pm1, \pm2 $ 的容量 $ 2, 4, 4, \dots $）处形成**闭壳层**。有六个 $ \pi $ 电子的环到第一激发态有大能隙，其电子云没有低成本的极化方式——而外加磁场能使满壳层中顺时针与逆时针的电流相互错开，产生抗磁环电流，其质子核磁共振签名正是芳香性的定义。四个电子（环丁二烯）或八个会把一对简并态留成半满：开壳层、活泼、反芳香或畸变。箱根本没有壳层结构——它的能级 $ 1, 4, 9, \dots $ 永不闭合——这也是理解环状共轭是一种真正新型量子物质的一种方式，详见 [[quantum-chemistry/huckel-theory]]。
:::
:::

环也是微波光谱背后的转动模型：与箱不同，它的光谱*按间距量子化*——纯转动谱线在 $ \Delta E = \hbar^{2}\Delta(m_{l}^{2})/2I $ 处——而它没有零点能，正是一个分子可以在空间中静止、却沿化学键永不静止的原因（[[quantum-chemistry/vibration-rotation]]）。

::: history
模型体系是新力学奏效的证明：薛定谔（Schrödinger）1926 年的论文在通往氢原子的路上解出了箱与转子。1928 年，伽莫夫（Gamow）以及独立的格尼（Gurney）与康登（Condon）把势垒穿透用于 $ \alpha $ 衰变，重现了盖革-努特尔定律——一个盖革计数器里看得见的量子效应。瓦尔特·库恩（Kuhn）1948 年提出染料颜色的自由电子模型，在没有人能计算那么大的分子之前几十年就用电子箱拟合了多烯光谱。1981 年，IBM 苏黎世实验室的宾尼希（Binnig）与罗雷尔（Rohrer）造出扫描隧道显微镜，把同一个指数用于原子尺度成像，并与鲁斯卡（Ruska）分享 1986 年诺贝尔物理学奖。
:::

## 后续内容

箱在约束设定量级的地方都会重现：量子点的颜色、石墨烯纳米带中的导电电子、统计力学中正比于 $ L^{3} $ 的平动配分函数（[[statistical-thermodynamics/partition-function]]）。隧穿指数在 [[kinetics/transition-state-theory]] 的透射系数里、在电子转移里、在每一台扫描探针里重现。环是 [[quantum-chemistry/vibration-rotation]] 中刚性转子模型的前一半，也是 [[quantum-chemistry/huckel-theory]] 中休克尔环模型的种子。而你已开始数的简并度，正是 [[quantum-chemistry/molecular-symmetry]] 群论的第一批特征标。这里解出的每个模型，都是 [[quantum-chemistry/approximation-methods]] 的近似方法将为真实分子绘制的那片领土上的一张坐标图。

::: summary
- 量子化是几何：把波约束在区域内强制 $ kL = n\pi $，得 $ E_{n} = n^{2}h^{2}/8mL^{2} $ 与零点能 $ E_{1} = h^{2}/8mL^{2} $——它是局域的代价，不是免费能量的来源。
- 对电子 $ h^{2}/8m_{\mathrm{e}} = 0.376\ \mathrm{eV\,nm^{2}} $：分子尺度的约束花费电子伏特，所以箱模型跃迁落在紫外与可见光区。
- $ |\psi|^{2} $ 不平坦：基态挤向中心（中央三分之一内概率 $ 0.609 $，经典值 $ 0.333 $），激发态有 $ n - 1 $ 个波节，经典行为只作为许多振荡的平均而重现。
- 高维箱分离成一维问题；简并度数的是量子数共享同一平方和的方式，而每个系统性简并都指认一个对称性。
- 在势垒中 $ \psi $ 按 $ e^{-\kappa x} $ 衰减，$ \kappa = \sqrt{2m(V_{0} - E)}/\hbar $，且 $ T \approx e^{-2\kappa L} $：对 $ 4.5\ \mathrm{eV} $ 功函数，STM 电流每 $ 0.11\ \mathrm{nm} $ 降十倍；$ \alpha $ 衰变半衰期在能量因子二内横跨十七个数量级。
- 多烯的自由电子箱模型给出库恩线性定律 $ \lambda \propto N $，但斜率高估约六倍；它解释了共轭为什么使颜色红移，却不预言波长。
- 环上 $ m_{l} = 0, \pm1, \pm2, \dots $，$ E = m_{l}^{2}\hbar^{2}/2I $：无零点能，$ \pm m_{l} $ 给出二重简并，壳层在 $ 2, 6, 10 $ 个电子处闭合——苯芳香性的环电流起源。
:::

## 练习

::: exercise 零点能 {level=1 check="4.18"}
一个电子被约束在长度 $ 0.30\ \mathrm{nm} $ 的一维势箱中。其零点能是多少？（以 eV 输入。）
::: solution
$ E_{1} = 0.376/(0.30)^{2} = 4.18\ \mathrm{eV} $。把一个电子挤压到一个键长的尺度，花费比一个强共价键还多：把电子挤得够狠，它就在化学上变得暴力。
:::
:::

::: exercise 基态概率 {level=1 check="0.82"}
对长度 $ L $ 的势箱基态，粒子出现在箱中央一半内的概率是多少？（输入该概率。）
::: solution
$ P = \int_{L/4}^{3L/4}(2/L)\sin^{2}(\pi x/L)\,\mathrm{d}x = \left[x/L - \sin(2\pi x/L)/2\pi\right]_{1/4}^{3/4} = \tfrac{1}{2} + 1/\pi = 0.82 $。经典答案是 $ 0.50 $：量子基态显著偏向中心。
:::
:::

::: exercise 方箱的简并度 {level=1 check="3"}
对二维方箱中的粒子，能级 $ E = 50\,h^{2}/8mL^{2} $ 的简并度是多少？（输入简并度。）
::: solution
$ 50 = n_{x}^{2} + n_{y}^{2} $ 有解 $ (1,7) $、$ (5,5) $、$ (7,1) $：简并度 $ 3 $。其中两个来自对称性（置换 $ x $ 与 $ y $），而 $ (5,5) $ 态是对称的那个——平方和的偶然简并，长方箱会把它分裂。
:::
:::

::: exercise STM 衬度 {level=2 check="77"}
功函数 $ 4.5\ \mathrm{eV} $ 的 STM 中，针尖-表面间隙从 $ 0.10\ \mathrm{nm} $ 增大到 $ 0.30\ \mathrm{nm} $ 时，隧穿电流降为原来的几分之一？（输入该因子。）
::: solution
$ \kappa = 10.9\ \mathrm{nm^{-1}} $，因子为 $ e^{2\kappa\Delta L} = e^{2 \times 10.9 \times 0.20} = e^{4.35} = 77 $。单个吸附原子层（$ \sim 0.3\ \mathrm{nm} $）将给出 $ e^{6.5} \approx 680 $：STM 以指数方式成像形貌，这是它的强项，也是它的解释陷阱。
:::
:::

::: exercise 辛四烯的箱模型 {level=2 check="582"}
把自由电子箱模型（[[#algo-box]]）用于辛四烯（$ 8\ \pi $ 电子，$ L = 9 \times 140\ \mathrm{pm} $）。预言最低吸收波长。（以 nm 输入。）
::: solution
跃迁 $ 4 \rightarrow 5 $：$ \Delta E = (25 - 16) \times 0.376/(1.26)^{2} = 9 \times 0.376/1.588 = 2.13\ \mathrm{eV} $，故 $ \lambda = 1240/2.13 = 582\ \mathrm{nm} $。实测 $ 290\ \mathrm{nm} $。模型把波长翻倍，却复现了红移趋势——错误就是功课，见 [[#ex-hexatriene]]。
:::
:::

::: exercise 环的能级间距 {level=2 check="1.94"}
一个电子在半径 $ 140\ \mathrm{pm} $ 的环上运动。$ m_{l} = \pm 1 $ 能级的能量是多少？（以 eV 输入。）
::: solution
$ E_{\pm1} = \hbar^{2}/2m_{\mathrm{e}}r^{2} = 0.0381/(0.14)^{2} = 1.94\ \mathrm{eV} $。$ m_{l} = \pm2 $ 能级位于 $ 4 \times 1.94 = 7.8\ \mathrm{eV} $：$ m_{l}^{2} $ 的 $ 1 : 4 : 9 $ 图样，且除 $ m_{l} = 0 $ 外每个能级加倍。
:::
:::

::: exercise 伽莫夫的计算 {#ex-gamow level=3}
一个能量 $ E = 4.27\ \mathrm{MeV} $ 的 $ \alpha $ 粒子（$ m_{\alpha}c^{2} = 3727\ \mathrm{MeV} $）穿过库仑势垒 $ V(r) = 2Z_{\mathrm{d}}e^{2}/4\pi\varepsilon_{0}r = 259.2\ \mathrm{MeV\,fm}/r $ 从 $ ^{238}\mathrm{U} $（$ Z_{\mathrm{d}} = 90 $）逸出，垒区在 $ R = 9\ \mathrm{fm} $ 之外。用 WKB 指数
$$
G = \int_{R}^{R_{2}}\frac{\sqrt{2m_{\alpha}\left(V(r) - E\right)}}{\hbar}\,\mathrm{d}r
= \frac{\sqrt{2m_{\alpha}E}}{\hbar}\,R_{2}\left[\arccos\sqrt{\frac{R}{R_{2}}} - \sqrt{\frac{R}{R_{2}}\left(1 - \frac{R}{R_{2}}\right)}\right],
$$
其中 $ R_{2} = 259.2/E $ 为外转折点、$ \hbar c = 197.3\ \mathrm{MeV\,fm} $，计算 $ T = e^{-2G} $ 与半衰期 $ t_{1/2} = \ln 2/(\nu T) $，尝试频率 $ \nu = v/2R $、$ v = \sqrt{2E/m_{\alpha}} $。与实测的 $ 4.5 \times 10^{9}\ \mathrm{y} $ 比较并评论。
::: solution
$ R_{2} = 259.2/4.27 = 60.7\ \mathrm{fm} $，$ R/R_{2} = 0.148 $。方括号为 $ \arccos(0.385) - \sqrt{0.148 \times 0.852} = 1.176 - 0.355 = 0.820 $。前置因子为 $ \sqrt{2 \times 3727 \times 4.27}/197.3 = 178.7/197.3 = 0.906\ \mathrm{fm^{-1}} $，故 $ G = 0.906 \times 60.7 \times 0.820 = 45.0 $，$ T = e^{-90} = 8 \times 10^{-40} $。由 $ v/c = \sqrt{2 \times 4.27/3727} = 0.048 $，$ \nu = v/2R = 8 \times 10^{20}\ \mathrm{s^{-1}} $，得 $ t_{1/2} = \ln 2/(8 \times 10^{20} \times 8 \times 10^{-40}) \approx 1 \times 10^{18}\ \mathrm{s} \approx 3 \times 10^{10}\ \mathrm{y} $——与实测的 $ 4.5 \times 10^{9}\ \mathrm{y} $ 相差在一个数量级以内。伽莫夫 1928 年的判词依然成立：$ E $ 改变因子二，$ G $ 改变几十，于是半衰期改变*几十个数量级*——对 $ ^{212}\mathrm{Po} $（$ E = 8.78\ \mathrm{MeV} $，$ Z_{\mathrm{d}} = 82 $）重做一遍即可复现，结果接近 $ 10^{-6}\ \mathrm{s} $，实测 $ 3 \times 10^{-7}\ \mathrm{s} $。化学中最稀有的半衰期横跨十七个数量级，出自一个指数。
:::
:::

::: exercise 箱何时转入可见光？ {level=3}
在 $ L = (N + 1) \times 140\ \mathrm{pm} $ 的箱模型中，证明最低吸收波长为 $ \lambda = 8m_{\mathrm{e}}c\,(N + 1)d^{2}/h $，其中 $ d = 140\ \mathrm{pm} $——对 $ N $ 是线性的（库恩定律）——并求模型的吸收首次到达可见光红边 $ 700\ \mathrm{nm} $ 时的链长。多烯的实测斜率约为每碳 $ 11\ \mathrm{nm} $；模型的斜率对其有效质量意味着什么？物理的解答是什么？
::: solution
$ \Delta E = (N + 1)h^{2}/8m_{\mathrm{e}}L^{2} $ 配上 $ L = (N + 1)d $ 坍缩为 $ \Delta E = h^{2}/8m_{\mathrm{e}}(N + 1)d^{2} $，故 $ \lambda = hc/\Delta E = 8m_{\mathrm{e}}c(N + 1)d^{2}/h = 64.6(N + 1)\ \mathrm{nm} $：线性，斜率每碳 $ 64.6\ \mathrm{nm} $。令 $ 64.6(N + 1) = 700 $ 得 $ N + 1 = 10.8 $，即约 $ N = 10 $ 个 $ \pi $ 电子（五个双键）——而按每碳 $ 11\ \mathrm{nm} $ 的实测多烯斜率，需要 $ N \approx 60 $（$ \beta $-胡萝卜素 $ N = 22 $，只到 $ 451\ \mathrm{nm} $）。由于 $ \lambda \propto 1/m $，实测的每碳 $ 11\ \mathrm{nm} $ 斜率对应平坦势公式中 $ m^{*} \approx 6m_{\mathrm{e}} $ 的有效质量——但解答不是一个重电子：平坦的箱根本就是错的势。核的周期点阵与电子间 $ \pi $–$ \pi $ 排斥重塑了能级（能带有效质量、电子关联），而这些正是休克尔方法（[[quantum-chemistry/huckel-theory]]）与近似方法（[[quantum-chemistry/approximation-methods]]）为捕捉它们而建造的东西。
:::
