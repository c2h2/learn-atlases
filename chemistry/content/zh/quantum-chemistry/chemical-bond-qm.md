从经典的角度看，分子是一个矛盾体：带正电的核相距几十皮米却不会飞散，而带负电的电子——彼此排斥、同时被每一个核吸引——却排布成刚硬到可以衍射、活泼到可以燃烧、特异到一种构型闻起来有香蕉味而下一种毫无气味。化学中没有任何东西比化学键更纯粹地是量子客体：经典静电学绑不住两个氢原子——两个质子相斥、两个电子相斥、质子与电子相吸，但"每个电子守住自己出身的核"这种幼稚图像在大多数距离上给出净排斥。键由两种没有经典类比的原料构成：一个电子可以离域在两个中心上，而两个自旋相反的电子可以占据同一个空间函数，从而把把电荷挤压到核间区域所付出的动能代价只付一次。本课就从这两个事实出发推导化学键。

推导分两个阶段。第一，因为核比电子重几千倍，电子问题可以在核冻结于固定位置的前提下求解，得到的电子能量加上核排斥就变成核几何的势能函数：玻恩–奥本海默（Born–Oppenheimer）近似，化学中每一张结构图的地基。第二，冻结核的电子问题本身有两条对立的进攻路线，它们正是化学的两大极限图像：分子轨道（MO）理论把一电子轨道铺满整个分子并按楼层入住；价键（VB）理论让电子对定域在特定核之间，再混合不同的配对方式。两者都是同一个精确波函数的近似，都从相反方向向它收敛；而氢分子离子 $\mathrm{H}_{2}^{+}$ 凭借它的单个电子，成为唯一一个每一步都能闭式完成、两种图像可以毫不留情地对照的系统。

自始至终把基准数字摆在眼前：$\mathrm{H}_{2}^{+}$ 解离为 $\mathrm{H} + \mathrm{H}^{+}$，$D_{\mathrm{e}} = 2.79\ \mathrm{eV}$，$R_{\mathrm{e}} = 105.7\ \mathrm{pm}$；$\mathrm{H}_{2}$ 解离为两个氢原子，$D_{\mathrm{e}} = 4.75\ \mathrm{eV}$，$R_{\mathrm{e}} = 74.1\ \mathrm{pm}$（扣去零点能后 $D_{0} = 4.48\ \mathrm{eV}$）。三条警告伴随全课：玻恩–奥本海默的地基并非坚不可摧（光化学就活在它开裂的地方）；反键轨道是有真实能量的真实状态，不是简单的"没有键"；极性键的"离子性百分比"是模型依赖的记账工具，不是电荷的测量。

## 玻恩–奥本海默近似

完整的分子哈密顿量包含每个粒子的动能和每一对库仑项。对 $\mathrm{H}_{2}$，用实验室坐标写有六个动能项和十个库仑项；第一步是把它拆成无穷重核部分加修正项。因为动能算符按 $1/m$ 缩放，而像 $\mathrm{H}_{2}$ 这样的分子里核带着电子质量的 $1836$ 倍（或更多），核运动之"慢"恰好精确到允许先解电子问题。

::: definition 玻恩–奥本海默近似 {#def-bo}
把核固定在位置 $\{\mathbf{R}_{I}\}$，求解**电子薛定谔方程**
$$
\hat{H}_{\text{el}}\,\psi_{\text{el}}(\mathbf{r};\{\mathbf{R}_{I}\}) = \left[-\sum_{i}\frac{\hbar^{2}}{2m_{\mathrm{e}}}\nabla_{i}^{2} + \sum_{i<A}\frac{-Z_{A}e^{2}}{4\pi\varepsilon_{0} r_{iA}} + \sum_{i<j}\frac{e^{2}}{4\pi\varepsilon_{0} r_{ij}}\right]\psi_{\text{el}} = E_{\text{el}}(\{R_{I}\})\,\psi_{\text{el}}
$$
对每个核几何求解后，加回（此时为常数的）核排斥，得到核运动所在的**势能曲线**
$$
V(R) = E_{\text{el}}(R) + \frac{e^{2}}{4\pi\varepsilon_{0} R}
$$ {#eq-pes}
对 $\mathrm{H}_{2}^{+}$，$E_{\text{el}}$ 就是一个电子在两个质子场中的能量。核随后在这张曲面上振动转动，仿佛它是一个普通的势——这就是为什么分子有一个键长、一个力常数、一个可以用单一几何解释的光谱。
:::

这个近似由质量比控制，而其中的标度关系值得精确陈述，因为它解释了分子光谱为什么落在它们所在的位置。

::: proposition 电子与核的时间尺度分离 {#prop-bo-times}
电子能量以哈特里 $E_{\mathrm{h}}$ 为量级、长度以 $a_{0}$ 为量级，所以电子运动的周期为 $\tau_{\text{el}} \sim \hbar/E_{\mathrm{e}} = 2.42\times10^{-17}\ \mathrm{s}$。质量为 $M$ 的核在曲率 $k \sim E_{\mathrm{h}}/a_{0}^{2}$ 的电子势阱中振动，$\hbar\omega \sim \sqrt{\hbar^{2}k/M} \sim E_{\mathrm{e}}\,(m_{\mathrm{e}}/M)^{1/2}$：振动量子比电子能量小 $\sim(m_{\mathrm{e}}/M)^{1/2} \approx 1/43$（对 $\mathrm{H}_{2}$），转动常数再小一个 $m_{\mathrm{e}}/M$。每一层描述都比上一层细一个数量级——这正是本课程的记账顺序：先键，再振动转动（[[quantum-chemistry/vibration-rotation]]），最后电子结构。
:::

::: example $\mathrm{H}_{2}$ 的时间尺度比 {#ex-bo-times}
基态 $\mathrm{H}_{2}$ 的谐振间距为 $\tilde{\nu} = 4401\ \mathrm{cm^{-1}}$。计算经典振动周期及其与原子时间单位之比。
::: solution
振动频率 $\nu = c\tilde{\nu} = 2.998\times10^{10}\ \mathrm{cm\,s^{-1}} \times 4401\ \mathrm{cm^{-1}} = 1.32\times10^{14}\ \mathrm{s^{-1}}$，所以核完成一次全摆动需要
$$
T = \frac{1}{\nu} = 7.58\times10^{-15}\ \mathrm{s} = 7.58\ \mathrm{fs}.
$$
原子时间单位为 $\hbar/E_{\mathrm{h}} = 2.419\times10^{-17}\ \mathrm{s}$，故比值 $T/\tau_{0} = 313$。核完成一次摆动的时间内，电子完成了三百多个轨道周期该有的位相演化：每一瞬间电子都处于它所见的核位置的（近乎）基态。这就是玻恩–奥本海默近似的全部数字内容。
:::
:::

::: warning 玻恩–奥本海默何时失效 {#warn-bo}
当两张电子面接近或相交时近似失效，因为核波函数会耦合原本假定独立的电子态。后果：锥形交叉（conical intersection）在几十飞秒内把激发分子导回基态（视觉、臭氧、每一剂紫外吸收剂的光化学）；姜–泰勒（Jahn–Teller）效应使坐在交叉点上的对称分子发生畸变；电子转移反应之所以以它那个速率进行，是因为核运动拖着体系穿过曲线交叉。一条有用的规则：基态热化学里玻恩–奥本海默是安全的，光子做的一切都可疑。
:::

## $\mathrm{H}_{2}^{+}$：可以精确求解的键

核固定在相距 $R$ 处之后，$\mathrm{H}_{2}^{+}$ 就是两个质子场中的一个电子——一个可在旋转椭球坐标中分离、可精确到任意精度的问题（精确解给出 $D_{\mathrm{e}} = 2.79\ \mathrm{eV}$，$R_{\mathrm{e}} = 105.7\ \mathrm{pm}$，即 $2.00\,a_{0}$）。但成键的全部物理已经出现在最简单的可能试探函数里，而且与量子化学的大部分内容不同，这个最简猜测可以闭式地手算出来。

设 $A$、$B$ 是以指数 $\zeta$ 分别定域在两个质子上的归一化氢 $1s$ 函数。试探波函数是一个线性组合，

$$
\psi_{\pm} = N_{\pm}\,(A \pm B),
\qquad
N_{\pm} = \frac{1}{\sqrt{2 \pm 2S}},
\qquad
S = \int A\,B\ \mathrm{d}\tau,
$$ {#eq-lcao}

::: definition 原子轨道线性组合（LCAO） {#def-lcao}
**LCAO 近似**用成键原子上的原子轨道构造分子轨道：$\psi = c_{A}A + c_{B}B$。系数由变分原理确定——对 $\langle\psi|\hat{H}|\psi\rangle/\langle\psi|\psi\rangle$ 关于 $c_{A}, c_{B}$ 求极小——产生一个 $2\times2$ 久期行列式。对对称的 $\mathrm{H}_{2}^{+}$，两个解是等权组合 $\psi_{+}$（核间无节面，记作 $\sigma_{\mathrm{g}}$）与 $\psi_{-}$（一个节面，$\sigma_{\mathrm{u}}$）：成键轨道与反键轨道。
:::

::: proposition $\mathrm{H}_{2}^{+}$ 的两个 LCAO 能量 {#prop-lcao}
记 $H_{AA} = \langle A|\hat{H}|A\rangle$、$H_{AB} = \langle A|\hat{H}|B\rangle$（含核排斥 $1/R$），变分能量为
$$
E_{\pm} = \frac{H_{AA} \pm H_{AB}}{1 \pm S}.
$$
在原子单位下，令 $\rho = \zeta R$，所需的一切积分都是初等的：
$$
S = \mathrm{e}^{-\rho}\left(1+\rho+\tfrac{1}{3}\rho^{2}\right),
\qquad
J = \left\langle A\left|\frac{1}{r_{B}}\right|A\right\rangle = \zeta\left[\frac{1}{\rho} - \mathrm{e}^{-2\rho}\left(1+\frac{1}{\rho}\right)\right],
$$
$$
I = \left\langle A\left|\frac{1}{r_{A}}\right|B\right\rangle = \zeta\,\mathrm{e}^{-\rho}(1+\rho) = \langle A|1/r_{B}|B\rangle,
\qquad
H_{AA} = \frac{\zeta^{2}}{2} - \zeta + \frac{1}{R} - J,
\qquad
H_{AB} = (\zeta-2)I - \frac{\zeta^{2}}{2}S + \frac{S}{R}.
$$
单电子哈密顿量为 $\hat{H} = -\tfrac{1}{2}\nabla^{2} - 1/r_{A} - 1/r_{B} + 1/R$；$J$ 是定域在核 $A$ 上的电荷感受到的核 $B$ 的吸引，$I$ 是它的交换对应项。
:::

两条曲线 $E_{\pm}(R)$ 就是单电子键的全部故事的一幅图画。

::: example $R = 2\,a_{0}$ 处的 LCAO 能量 {#ex-lcao-energy}
取 $\zeta = 1$，计算 $R = 2.0\,a_{0}$ 处 $\mathrm{H}_{2}^{+}$ 的 $E_{+}$ 与 $E_{-}$，并给出该几何下的结合能。
::: solution
$\rho = 2.0$：$S = \mathrm{e}^{-2}(1+2+\tfrac{4}{3}) = 0.586$，$I = 2\mathrm{e}^{-2} = 0.406$，$J = \tfrac{1}{2} - \mathrm{e}^{-4}(1+\tfrac{1}{2}) = 0.473$。于是 $H_{AA} = -\tfrac{1}{2} + \tfrac{1}{2} - 0.473 = -0.473$，$H_{AB} = -I - \tfrac{1}{2}S + \tfrac{1}{2}S = -0.406$（$\zeta=1$、$R=2$ 时 $S/R$ 项与 $\zeta^{2}S/2$ 相消）。故
$$
E_{+} = \frac{-0.473 - 0.406}{1.586} = -0.554\ \text{哈特里},
\qquad
E_{-} = \frac{-0.473 + 0.406}{0.414} = -0.161\ \text{哈特里}.
$$
相对分离的 $\mathrm{H} + \mathrm{H}^{+}$ 极限（$-0.5$ 哈特里），成键态降低 $0.054$ 哈特里 $= 1.46\ \mathrm{eV}$——在此几何下是束缚的，尽管还不是曲线极小处（$2.49\,a_{0}$ 处的 $1.76\ \mathrm{eV}$）。反键态高出极限 $0.339$ 哈特里 $= 9.2\ \mathrm{eV}$：一个节面的代价远非一个瓣的收益所能补偿。
:::
:::

能量降低有一个可见的来源：成键波函数把电子密度堆进核间区域——那里它同时吸引两个核——而反键波函数恰恰把密度从那里赶了出去。

::: example 中点处的密度 {#ex-density}
在成键极小 $R = 2.49\,a_{0}$（$\zeta = 1$，$S = 0.460$）处，把 $\psi_{+}^{2}$ 与两原子在该处密度的平均比较，再对 $\psi_{-}^{2}$ 做同样的事。
::: solution
中点处 $r_{A} = r_{B} = R/2$，故 $A = B = \mathrm{e}^{-R/2} = \mathrm{e}^{-1.246} = 0.288$，$A^{2} = 0.0827$。于是
$$
\psi_{+}^{2}(\text{mid}) = \frac{(A+B)^{2}}{2+2S} = \frac{4A^{2}}{2+2S} = \frac{4\times0.0827}{2.920} = 0.113,
$$
对比原子基准 $\tfrac{1}{2}(A^{2}+B^{2}) = A^{2} = 0.0827$：堆积因子 $2/(1+S) = 1.37$，比原子提供的密度多三十七个百分点。对 $\psi_{-}$，分子 $(A-B)^{2} = 0$：反键轨道在中点有节面，该处密度恰为零——电子恰恰被从它们本可以同时束缚两个核的区域撤走，核排斥得不到屏蔽。成键，字面意义上，就是电荷坐在哪里的问题。
:::
:::

::: warning 重叠不是小修正 {#warn-overlap}
在 $R_{\mathrm{e}}$ 处重叠 $S = 0.46$——按量子化学大多数场合的标准（远离的基团之间 $S \sim 0.01$）这是巨大的。一切都继承了它：归一化 $1/\sqrt{2+2S}$、$E_{\pm}$ 中的分母 $1\pm S$，以及"共振矩阵元是 $H_{AB} - ES$（而非 $H_{AB}$）"这一事实。两个相关的陷阱。其一，"反键"不等于"不成键"：$\sigma_{\mathrm{u}}$ 是货真价实的本征态，成键电子多于反键电子的分子照样可以结合（第 3 节）。其二，能量降低并不简单地是"被两个核而不是一个核吸引"——$\mathrm{H}_{2}^{+}$ 极小处电子其实束缚得更紧（$\zeta$ 式的收缩有帮助，如图中滑块所示），动能实际上是上升的；键由势能付账，由维里定理（virial theorem）记账（[[#thm-virial]]）。
:::

## 分子轨道语言

**分子轨道**是整个（核固定的）分子的一电子波函数。对双原子分子，轨道按轨道角动量沿核轴的分量分类——$\lambda = 0, 1, 2$ 给出 $\sigma, \pi, \delta$ 轨道——同核分子还按对中点的反演行为分类：gerade（$\mathrm{g}$，不变号）或 ungerade（$\mathrm{u}$，变号）。$\mathrm{H}_{2}^{+}$ 的 $\psi_{+}$ 是 $\sigma_{\mathrm{g}}$ 轨道，$\psi_{-}$ 是 $\sigma_{\mathrm{u}}$。轨道从底部开始填，每个填两个电子（泡利原理），与原子轨道完全一样。

::: definition 键级 {#def-bond-order}
**键级**为 $\frac{1}{2}(n_{\text{成键}} - n_{\text{反键}})$。$\mathrm{H}_{2}^{+}$：$\sigma_{\mathrm{g}}$ 中一个电子，键级 $\tfrac{1}{2}$——它是真实存在的，$D_{0} = 2.65\ \mathrm{eV}$，光谱学刻画最彻底的离子。$\mathrm{H}_{2}$：两个电子，键级 $1$。$\mathrm{He}_{2}^{+}$：键级 $\tfrac{1}{2}$，同样真实。$\mathrm{He}_{2}$：$\sigma_{\mathrm{g}}^{2}\sigma_{\mathrm{u}}^{2}$，键级 $0$——没有键，这就是氦是单原子气体的原因。注意键级数的是键的条数，不是强度：$\mathrm{H}_{2}^{+}$ 的半键（$2.79\ \mathrm{eV}$）超过 $\mathrm{H}_{2}$ 全键（$4.75\ \mathrm{eV}$）的一半，因为第二个电子在吸引核的同时也要付出电子间排斥。
:::

::: quiz
为什么 $\mathrm{He}_{2}$ 在电子基态不是束缚分子？
- [ ] 两个核太重，无法隧穿进一个键。
- [x] $\sigma_{\mathrm{g}}$ 填两个电子、$\sigma_{\mathrm{u}}$ 再填两个，成键被反键占据抵消，键级为零。
- [ ] 氦的电子是自旋配对的，而配对的电子不能成键。
- [ ] $\sigma_{\mathrm{u}}$ 轨道非物理，所以 $\mathrm{He}_{2}$ 无法填满它。
::: solution
键级 $\tfrac{1}{2}(2-2) = 0$：反键占据拆掉成键的那份，核排斥在任何距离上都得不到屏蔽。（氦确实形成一个范德华二聚体——势阱比化学键浅一千倍，只束缚一个振动能级——来自这套单电子图像完全看不见的关联电子运动。）自旋配对恰恰是成键的*前提*（第 4 节），而 $\sigma_{\mathrm{u}}$ 与 $\sigma_{\mathrm{g}}$ 一样物理——从中拿走一个电子的 $\mathrm{He}_{2}^{+}$ 就是稳定离子。
:::

## 价键理论：作为配对自旋的键

MO 理论先造轨道再放电子；价键理论从化学家想要的答案出发——一对电子共享于 $A$ 与 $B$ 之间——再从结构式搭建波函数。海特勒（Heitler）与伦敦（London）1927 年对 $\mathrm{H}_{2}$ 的处理是第一个量子力学化学键计算，它的逻辑值得知道，因为它指认了真正造成成键的东西。

::: proposition 海特勒–伦敦波函数 {#prop-hl}
把电子 $1$ 给核 $A$、电子 $2$ 给核 $B$，写出 $\Phi = A(1)B(2)$。交换两个全同电子得 $B(1)A(2)$，正确的空间对称性是组合
$$
\Psi_{\pm} = A(1)B(2) \pm B(1)A(2).
$$
因为总波函数必须反对称，空间对称的 $\Psi_{+}$ 与反对称的自旋单重态 $\frac{1}{\sqrt{2}}(\alpha\beta - \beta\alpha)$——自旋反平行——配对，是束缚的；空间反对称的 $\Psi_{-}$ 与三重态自旋函数配对，是排斥的。键存在当且仅当自旋配对：造成成键的是空间函数的交换对称性，而不是任何新的"交换力"。
:::

物理内容就在空间对称性里。$\Psi_{+}$ 在核间区域被增强（两项在那里相加），所以单重态把电荷拉进核间，正如单电子情形 $\psi_{+}^{2}$ 所做的那样。$\Psi_{-}$ 中每当两个电子被交换两项就相消——反对称空间函数让电子平均而言彼此远离，但它同时掏空核间区域、让中点平面空出来，核排斥得不到屏蔽。三重态 $\mathrm{H}+\mathrm{H}$ 曲线在所有距离上都是排斥的，所以两个自旋平行的氢原子只能散射：**自旋配对不是键的细节，它就是键本身**。

与 MO 理论的对照既有启发性又是定量的。把 MO 基态函数 $(\sigma_{\mathrm{g}})^{2}$（$\sigma_{\mathrm{g}} \propto A + B$）用电子坐标写开：

::: example MO 波函数的离子含量 {#ex-ionic-weight}
把 $(A(1)+B(1))(A(2)+B(2))$ 展开为"电子 1 在 X、电子 2 在 Y"形式的项，确定离子性（两个电子在同一核上）权重占多少。$R \to \infty$ 时出了什么错？
::: solution
乘积为 $A(1)A(2) + A(1)B(2) + B(1)A(2) + B(1)B(2)$。中间两项是共价的——一边一个电子——外面两项是离子的：两个电子都在 $A$（即 $A$ 处 $\mathrm{H}^{-}$、$B$ 处 $\mathrm{H}^{+}$）或都在 $B$。四项中两项离子：简单 MO 函数在任何距离上都是 $50\,\%$ 离子性的，包括无穷远。但 $\mathrm{H}^{-} + \mathrm{H}^{+}$ 比两个基态氢原子高 $I(\mathrm{H}) - A(\mathrm{H}) = 13.60 - 0.75 = 12.85\ \mathrm{eV}$，所以 $R\to\infty$ 时 MO 函数根本不解离成 $\mathrm{H} + \mathrm{H}$——它把巨大的、非物理的离子成分带进了渐近线。海特勒–伦敦函数有正确的极限（纯共价），却漏掉了真实分子*在*平衡处确实想要的离子项——混入 $\mathrm{H}^{-}\mathrm{H}^{+}$ 能让电子互相避让。现代计算用变分权重混合共价与离子结构来同时修补两处缺陷——精确答案是 $D_{\mathrm{e}} = 4.75\ \mathrm{eV}$。
:::
:::

## 数字怎么说

把已验证的结果汇总，近似的层级就一目了然：

| 体系 | 方法 | $D_{\mathrm{e}}/\mathrm{eV}$ | $R_{\mathrm{e}}/\mathrm{pm}$ |
|---|---|---|---|
| $\mathrm{H}_{2}^{+}$ | LCAO，$\zeta = 1$ | 1.76 | 132 |
| $\mathrm{H}_{2}^{+}$ | LCAO，$\zeta = 1.24$（最优） | 2.35 | 106 |
| $\mathrm{H}_{2}^{+}$ | 精确（分离变量） | 2.79 | 105.7 |
| $\mathrm{H}_{2}$ | 哈特里–福克极限 | 4.53 | $\approx 73$ |
| $\mathrm{H}_{2}$ | 精确（詹姆斯–库利奇及后继） | 4.75 | 74.1 |

表里有两课。其一，变分原理守规矩：每个近似能量都在精确值之上，改进轨道（滑块技巧）收回大部分差距——对 $\mathrm{H}_{2}^{+}$，把指数从 $1$ 放大到 $1.24$ 就把 $D_{\mathrm{e}}$ 从 $1.76$ 带到 $2.35\ \mathrm{eV}$，因为收缩的轨道既把每个核束缚得更好、又把键区铺得更好。其二，对 $\mathrm{H}_{2}$，最好的单行列式（哈特里–福克）答案差 $0.22\ \mathrm{eV}$——**电子相关能**，$0.008$ 哈特里，键的 $5\,\%$。这 $5\,\%$ 是让电子在每一瞬间互相避让所收回的能量，是轨道近似本身的代价；詹姆斯–库利奇 1933 年的波函数显式建在电子间距离 $r_{12}$ 上，把它收了回来，把量子化学送上了地图。现代的 $\mathrm{H}_{2}$ 计算与实验符合到总能的十亿分之几——化学键是物理学中被理解得最精确的客体。

::: theorem 平衡处的维里定理 {#thm-virial}
对哈密顿量为纯库仑型的分子，在势能曲线的驻点处，
$$
2\langle \hat{T} \rangle + \langle \hat{V} \rangle = 0
\qquad\Longleftrightarrow\qquad
\langle \hat{T} \rangle = -E,
\qquad
\langle \hat{V} \rangle = 2E,
$$
其中 $E$ 是该几何下的总能量（电子加核排斥）。因此平衡处的成键记账为：势能下降键能的两倍，动能*上升*一个键能。电子在分子中平均比在分离原子中束缚得更紧——是收缩、而不是铺展，付了键的账——动能的账单由势能的收益来付。
:::

::: example $\mathrm{H}_{2}^{+}$ 的维里记账 {#ex-virial}
$\mathrm{H}_{2}^{+}$ 精确极小处 $E = -0.6026$ 哈特里。给出 $\langle \hat{T} \rangle$ 与 $\langle \hat{V} \rangle$，并对照分离原子极限检验定理。
::: solution
$\langle \hat{T} \rangle = -E = 0.6026$ 哈特里，$\langle \hat{V} \rangle = 2E = -1.2053$ 哈特里。在 $\mathrm{H} + \mathrm{H}^{+}$ 极限：$E = -0.5$，$T = 0.5$，$V = -1.0$。所以在 $R_{\mathrm{e}}$ 成键时，$\Delta T = +0.103$ 哈特里（电子收缩、加速），而 $\Delta V = -0.205$ 哈特里——两倍大、反号，净得 $0.103$ 哈特里 $= 2.79\ \mathrm{eV}$ 的结合。能量算对却违反维里比的波函数在别处藏着错误；变分计算通常都这样检查。
:::
:::

## 极性键

两端放上不同的核，系数 $c_{A}, c_{B}$ 就不再相等：电负性更大的原子贡献能量更低的原子轨道、赢得更大的系数，于是成键轨道向它极化，键获得偶极矩。对 $\mathrm{HF}$，$\psi_{\sigma} \approx c_{\mathrm{F}}\,2p\sigma_{\mathrm{F}} + c_{\mathrm{H}}\,1s_{\mathrm{H}}$，$c_{\mathrm{F}} > c_{\mathrm{H}}$；不均等共享的极端是离子键，而介于两者之间的整个区间是同一个波函数、一个参数。

偶极矩度量这种不均等，但只是粗略地：朴素的离子性估计把观测偶极除以"观测键长上放满电荷"的偶极。

::: example 由偶极求 $\mathrm{HCl}$ 的离子性 {#ex-hcl-ionic}
$\mathrm{HCl}$ 的 $\mu = 1.08\ \mathrm{D}$，$R_{\mathrm{e}} = 127.5\ \mathrm{pm}$。估计它的离子性百分比，并与鲍林（Pauling）的电负性估计 $1 - \mathrm{e}^{-(\Delta\chi)^{2}/4}$（$\Delta\chi = 0.98$）比较。
::: solution
相距 $127.5\ \mathrm{pm}$ 的满电荷给出 $\mu_{\text{ionic}} = eR = 127.5 \times 0.04803 = 6.12\ \mathrm{D}$（一个电子电荷跨 $100\ \mathrm{pm}$ 是 $4.803\ \mathrm{D}$）。比值 $1.08/6.12 = 0.176$：约 $18\,\%$ 离子性。鲍林公式给出 $1 - \mathrm{e}^{-0.98^{2}/4} = 1 - \mathrm{e}^{-0.240} = 0.21$，即 $21\,\%$——来自完全不同的测量（键能）的同一个故事，吻合到两个模型的粗糙程度以内。同样的算术用于 $\mathrm{HF}$（$1.83\ \mathrm{D}$，$91.7\ \mathrm{pm}$）得 $1.83/4.40 = 42\,\%$：最常见的键中最极性的一个。
:::
:::

::: warning 离子性百分比不是电荷 {#warn-ionic}
偶极是整个电荷分布的属性，而 $\mu/eR$ 的"离子性"把全部偶极记到一根键坐标上。原子极化、重叠密度自身的偶极、孤对电子的回流都有贡献：$\mathrm{CO}$ 的 $\mu = 0.11\ \mathrm{D}$ 且负端在碳上，然而布居分析把可观的正电荷放在碳上——小偶极不意味着非极性键，大偶极也不意味着满电荷。将 $18\,\%$ 离子性的 $\mathrm{HCl}$ 当作恰好与反应性相关的记账惯例，而不是"$0.18\,e$ 已经搬家"的陈述。
:::

::: history
量子键论诞生于同一年。1927 年，瓦尔特·海特勒（Walter Heitler）与弗里茨·伦敦（Fritz London）把新的波动力学用于 $\mathrm{H}_{2}$，完成了第一个化学键计算——单重态成键、三重态排斥、交换积分为引擎——同一卷里，马克斯·玻恩（Max Born）与 J. 罗伯特·奥本海默（J. Robert Oppenheimer）给出了冻结核的近似，而且出名地是以一篇分子论文附录的形式。洪特（Friedrich Hund）在 1927–28 年建立了双原子光谱的分子轨道分类，马利肯（Robert Mulliken）在整个三十年代初把它发展为一般理论，生造了"分子轨道"（1932）、"键级"和沿用至今的 $\sigma,\pi,\delta$ 记号。最初的海特勒–伦敦计算给出了键但太弱，决定性的定量一击来自 1933 年：哈罗德·詹姆斯（Harold James）与阿瑟·库利奇（Arthur Coolidge）用显含电子间距离 $r_{12}$ 的变分展开进攻 $\mathrm{H}_{2}$，把它的键能做到了化学精度——第一个定性键问世仅六年，定量的键就存在了，"量子力学解释化学结合"的论断就此盖棺。鲍林（Linus Pauling）随后把整个学科带回化学：1931 年起的杂化与共振，以及《化学键的本质》（*The Nature of the Chemical Bond*，1939）——让一代化学家用轨道思考的那本书；库尔森（Coulson）的《价》（*Valence*，1952）为下一代人完成了综合。马利肯因分子的分子轨道理论获 1966 年诺贝尔化学奖；早已与化学界决裂的海特勒什么也没得到。
:::

## 通向何处

这里解决的两轨道久期问题是本课程后续一切方法的种子。把基组从两个原子轨道扩大到一个，$2\times2$ 行列式就变成分子轨道计算的 Roothaan 方程（[[quantum-chemistry/approximation-methods]]）；限制为每个碳一个 $p_{z}$ 轨道，就变成苯乃至整个 $\pi$ 化学的休克尔理论（[[quantum-chemistry/huckel-theory]]）；按对称性给轨道分类，$\mathrm{g/u}$ 与 $\sigma/\pi$ 标签就变成附带选择定则的不可约表示（[[quantum-chemistry/molecular-symmetry]]）。把许多电子填进轨道，同样的 LCAO 逻辑支撑着原子的哈特里–福克处理（[[quantum-chemistry/many-electron-atoms]]）。这里导出的势能曲线正是振动转动光谱所测量的东西（[[quantum-chemistry/vibration-rotation]]），而成键与反键曲线之间的电子跃迁是每一场光化学反应的第一步（[[spectroscopy/electronic-spectroscopy]]）。键级记账是化学家所画之线的量子辩护——也是元素周期表所编码的键强与极性趋势的量子辩护（[[general-chemistry-1/periodicity]]）。

::: summary
- 玻恩–奥本海默近似在固定核的场中解电子；电子能量加核排斥即势能曲线。它由 $(m_{\mathrm{e}}/M)^{1/2}$ 控制：$\mathrm{H}_{2}$ 中核每振动一次电子执行约 $300$ 个循环。
- $\mathrm{H}_{2}^{+}$ LCAO：$E_{\pm} = (H_{AA} \pm H_{AB})/(1 \pm S)$，$S = \mathrm{e}^{-\rho}(1+\rho+\rho^{2}/3)$，$\rho = \zeta R$。$\zeta = 1$：$D_{\mathrm{e}} = 1.76\ \mathrm{eV}$、$132\ \mathrm{pm}$；$\zeta = 1.24$：$2.35\ \mathrm{eV}$、$106\ \mathrm{pm}$；精确：$2.79\ \mathrm{eV}$、$105.7\ \mathrm{pm}$。
- 成键轨道把密度集中到核间（中点处相对原子基准 $+37\,\%$）；反键轨道在那里有节面，在所有距离上都排斥。
- MO 语言：按绕轴角动量分 $\sigma/\pi/\delta$，按反演分 $\mathrm{g/u}$；键级 $= \tfrac{1}{2}(n_{\text{成键}} - n_{\text{反键}})$ 解释了 $\mathrm{H}_{2}^{+}$、$\mathrm{H}_{2}$、$\mathrm{He}_{2}^{+}$ 与 $\mathrm{He}_{2}$ 的缺席。
- 价键：空间对称的单重态（自旋反平行）海特勒–伦敦函数成键，三重态不成。自旋配对就是键。
- $(\sigma_{\mathrm{g}})^{2}$ 有 $50\,\%$ 离子性且解离错误；海特勒–伦敦解离正确但结合不足；精确的 $\mathrm{H}_{2}$ 波函数两类结构都需要，还需要相关：$D_{\mathrm{e}} = 4.75\ \mathrm{eV}$，其中哈特里–福克给 $4.53$。
- 平衡处维里定理：$T = -E$，$V = 2E$——成键是势能下降两倍键能、动能上升一倍键能。
- 极性键：LCAO 系数不等；按偶极比 $\mu/eR$，$\mathrm{HCl}$ 约 $18\,\%$ 离子性，$\mathrm{HF}$ 约 $42\,\%$——是惯例，不是电荷。
:::

$\zeta = 1$ 的 $\mathrm{H}_{2}^{+}$ LCAO 成键曲线极小在 $R = 2.49\,a_{0}$。换算成皮米。（以 pm 输入键长。）
::: solution
$R = 2.49 \times 52.92\ \mathrm{pm} = 132\ \mathrm{pm}$。精确键长 $105.7\ \mathrm{pm}$：简单 LCAO 高估 $25\,\%$，因为未收缩的 $1s$ 轨道太弥散——$\zeta = 1.24$ 的最优值把它拉到 $106\ \mathrm{pm}$，基本精确。

::: exercise 成键轨道的归一化 {level=1 check="0.585"}
$A$、$B$ 各已归一化，$R_{\mathrm{e}}$ 处重叠 $S = 0.460$，计算 $\psi_{+} = N_{+}(A+B)$ 的归一化常数 $N_{+}$。（输入无量纲数值。）
::: solution
$\langle\psi_{+}|\psi_{+}\rangle = N_{+}^{2}(1 + S + S + 1) = N_{+}^{2}(2 + 2S) = 1$，故 $N_{+} = 1/\sqrt{2.920} = 0.585$。重叠把模长撑大 $46\,\%$，常数相应压缩轨道——在这里忘掉 $S$，由 $\psi_{+}$ 构造的一切密度和能量都会虚高。
:::

::: exercise HF 的离子性 {level=1 check="41.6"}
$\mathrm{HF}$ 的 $\mu = 1.83\ \mathrm{D}$，$R_{\mathrm{e}} = 91.7\ \mathrm{pm}$。用偶极比 $\mu/eR$ 估计其离子性百分比。（输入百分比。）
::: solution
$eR = 91.7 \times 0.04803 = 4.40\ \mathrm{D}$，离子性 $= 1.83/4.40 = 0.416$，即 $41.6\,\%$。鲍林公式取 $\Delta\chi = 1.78$ 给 $1-\mathrm{e}^{-0.79} = 55\,\%$——两个估计把真相夹在中间，而真相是：偶极比和键能公式都不测量"电荷"。
:::
:::

::: exercise 固定几何下的结合 {level=2 check="1.46"}
用 [[#prop-lcao]] 的闭式，计算 $\zeta = 1$ 时 $R = 2.0\,a_{0}$ 处 $\mathrm{H}_{2}^{+}$ 的结合能（相对 $\mathrm{H}+\mathrm{H}^{+}$，以 eV 计）。（输入该几何下的 $D_{\mathrm{e}}$，单位 eV。）
::: solution
$S = 0.586$，$I = 0.406$，$J = 0.473$，$H_{AA} = -0.473$，$H_{AB} = -0.406$，故 $E_{+} = -0.879/1.586 = -0.554$ 哈特里，对分离的 $-0.5$：$D_{\mathrm{e}}(R=2) = 0.054$ 哈特里 $= 1.46\ \mathrm{eV}$。曲线极小更深（$2.49\,a_{0}$ 处 $1.76\ \mathrm{eV}$），所以 $R = 2\,a_{0}$ 在内（排斥）壁上——处于该几何的分子会被向外推。
:::

::: exercise 由光谱看玻恩–奥本海默 {level=2 check="313"}
基态 $\mathrm{H}_{2}$ 的 $\tilde{\nu} = 4401\ \mathrm{cm^{-1}}$。计算一个经典振动周期与原子时间单位 $\hbar/E_{\mathrm{h}} = 2.419\times10^{-17}\ \mathrm{s}$ 之比。（输入无量纲比值。）
::: solution
$\nu = c\tilde{\nu} = 2.998\times10^{10} \times 4401 = 1.319\times10^{14}\ \mathrm{s^{-1}}$，$T = 7.58\times10^{-15}\ \mathrm{s}$，比值 $= 7.58\times10^{-15}/2.419\times10^{-17} = 313$。电子重新适应核运动，每周期位相误差约 $1/313$——这就是玻恩–奥本海默近似在这个分子上的定量内容。
:::
:::

::: exercise 维里记账 {level=2 check="-1.21"}
$\mathrm{H}_{2}^{+}$ 精确极小处总能量 $-0.6026$ 哈特里。给出总势能（电子加核排斥）的期望值，以哈特里计。（输入 $\langle \hat{V} \rangle$，单位哈特里。）
::: solution
库仑体系驻点处的维里定理给 $\langle \hat{V} \rangle = 2E = -1.21$ 哈特里（且 $\langle \hat{T} \rangle = -E = +0.60$）。势能是总能的两倍且为负：键由势能驱动，相对分离原子动能上升 $0.10$ 哈特里，因为电子收缩了。
:::

::: exercise 推导 LCAO 能量 {level=3}
从 $\psi = c_{A}A + c_{B}B$（$A, B$ 不正交）的变分条件出发，写出久期行列式，并对 $c_{A} = \pm c_{B}$ 的对称情形推导 $E_{\pm} = (H_{AA} \pm H_{AB})/(1 \pm S)$。
::: solution
对 $E = (c_{A}^{2}H_{AA} + 2c_{A}c_{B}H_{AB} + c_{B}^{2}H_{AA})/(c_{A}^{2} + 2c_{A}c_{B}S + c_{B}^{2})$（用 $H_{BB}=H_{AA}$、$S_{AB}=S$）关于 $c_{A}, c_{B}$ 求极小，得
$$
\begin{vmatrix} H_{AA} - E & H_{AB} - ES \\ H_{AB} - ES & H_{AA} - E \end{vmatrix} = 0
\quad\Longrightarrow\quad
H_{AA} - E = \pm(H_{AB} - ES).
$$
解出：$E(1 \pm S) = H_{AA} \pm H_{AB}$，即 $E_{\pm} = (H_{AA} \pm H_{AB})/(1 \pm S)$，本征向量比 $c_{B}/c_{A} = \pm1$。因 $H_{AB} < 0$，$+$ 根——对称组合——是较低的一个：它的分子多负 $2|H_{AB}|$，压过了分母 $1+S$ 变大的代价。注意重叠 $S$ 乘在 $E$ 上：这是广义本征问题 $H\mathbf{c} = ES\mathbf{c}$，不是普通的——与 [[quantum-chemistry/approximation-methods]] 的 Roothaan 方程同构。
:::
:::

::: exercise 解离检验 {level=3}
显式证明海特勒–伦敦函数 $\Psi_{+} = A(1)B(2) + B(1)A(2)$ 在 $R \to \infty$ 解离正确，而 $(\sigma_{\mathrm{g}})^{2}$ 不正确；并用 $I(\mathrm{H}) = 13.60\ \mathrm{eV}$、$A(\mathrm{H}) = 0.75\ \mathrm{eV}$ 计算 MO 函数的离子尾巴在无穷远造成的每摩尔能量误差。
::: solution
$R\to\infty$ 时 $\Psi_{+}$ 只含 $A(1)B(2)$ 与 $B(1)A(2)$——一边一个电子，两种不可区分的方式，能量 $E(\mathrm{H}) + E(\mathrm{H})$：正确。$(\sigma_{\mathrm{g}})^{2} \propto [A(1)+B(1)][A(2)+B(2)]$ 保留了 $A(1)A(2) + B(1)B(2)$，即离子结构 $\mathrm{H}^{-}\mathrm{H}^{+}$ 与 $\mathrm{H}^{+}\mathrm{H}^{-}$，高出 $I - A = 12.85\ \mathrm{eV}$。一半权重在那里，MO 函数在无穷远的期望值就比真实极限高约 $0.5 \times 12.85 \approx 6\ \mathrm{eV}$（确切数字取决于重叠与穿透项）——约 $600\ \mathrm{kJ\,mol^{-1}}$，比键本身还大。这就是单行列式 MO 理论无法描述断键的原因，也是双自由基、过渡金属化学与拉伸的键要求多组态波函数的原因：离子与共价结构近乎简并，必须显式混合。
:::
:::

::: exercise 成键–反键劈裂 {level=3 check="7.50"}
对 $R = 2.49\,a_{0}$、$\zeta = 1$ 的 $\mathrm{H}_{2}^{+}$，用 [[#prop-lcao]] 的闭式计算 $E_{+}$ 与 $E_{-}$，并给出劈裂 $E_{-} - E_{+}$，以 eV 计。（输入劈裂，单位 eV。）
::: solution
$\rho = 2.493$：$S = \mathrm{e}^{-2.493}(1+2.493+2.493^{2}/3) = 0.460$，$I = \mathrm{e}^{-2.493}(3.493) = 0.289$，$J = 1/2.493 - \mathrm{e}^{-4.986}(1+1/2.493) = 0.401 - 0.010 = 0.392$。于是
$$
H_{AA} = \tfrac{1}{2} - 1 + 0.401 - 0.392 = -0.490,
\qquad
H_{AB} = -0.289 - 0.230 + 0.460\times0.401 = -0.335,
$$
故 $E_{+} = (-0.490 - 0.335)/1.460 = -0.565$ 哈特里，$E_{-} = (-0.490 + 0.335)/0.540 = -0.287$ 哈特里。劈裂 $E_{-} - E_{+} = 0.276$ 哈特里 $= 7.50\ \mathrm{eV}$（用未舍入值）：平衡处的 $\sigma_{\mathrm{g}}$–$\sigma_{\mathrm{u}}$ 能隙——打断这个键的电子跃迁之能量，在真空紫外（[[spectroscopy/electronic-spectroscopy]]）。注意不对称性：成键能级只被压低 $0.065$ 哈特里，反键能级却被抬高 $0.211$——反键的代价高于成键的收益，这就是闭壳层原子如 $\mathrm{He}$ 不成键的原因。
