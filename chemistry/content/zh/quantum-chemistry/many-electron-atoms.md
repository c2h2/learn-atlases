给氢加上一个电子，精确解就失去了。氦原子——三个粒子、四个坐标——无法分离成一电子问题，因为每个电子感受的是另一个电子的*瞬时*位置；任何变量替换都解不开这个死结。然而元素周期表——它的壳层结构、它的化学族、氧二价氖惰性这些事实——却从这个不可解的问题中以完全的规律性浮现出来。调和这两者的，是 1920 年代量子力学最伟大的思想成就之一：一套选择得如此高明的*近似*，以至于上百种元素的化学都从几条原理中推出。其中三条主导本课：**轨道近似**（每个电子在平均场中运动）、**泡利原理**（波函数在任意两个电子交换下变号），以及你将在 [[quantum-chemistry/approximation-methods]] 中掌握的**变分与微扰机器**。我们从作为一切原子理论试金石的氦出发，一路组织到安排原子光谱的项符号。

## 氦：第一个两电子原子

氦的非相对论哈密顿量，把核固定在原点（对原子而言玻恩-奥本海默步骤是平凡的），为

$$
\hat H = -\frac{\hbar^{2}}{2m_\mathrm{e}}\nabla_1^{2} -\frac{\hbar^{2}}{2m_\mathrm{e}}\nabla_2^{2}
-\frac{2e^{2}}{4\pi\varepsilon_0 r_1} -\frac{2e^{2}}{4\pi\varepsilon_0 r_2}
+\frac{e^{2}}{4\pi\varepsilon_0 r_{12}} .
$$ {#eq-he-hamiltonian}

::: definition 氦的精确哈密顿量 {#def-he-hamiltonian}
方程 [[#eq-he-hamiltonian]] 包含两个一电子算符——每个电子的动能与核吸引——再加上**电子排斥项** $e^{2}/4\pi\varepsilon_0 r_{12}$，其中 $r_{12}$ 是两电子的瞬时距离。前四项是相互独立的类氢算符之和；第五项把两个电子的坐标耦合起来，使方程不可分离。每一个多电子原子的近似，本质上都是把这个耦合替换为可处理的东西，再为丢失的部分作修正。
:::

最粗糙的可处理选择是把排斥项整个删掉：于是每个电子占据氦离子裸核的类氢 $1s$ 轨道，$\psi = 1s(1)\,1s(2)$，能量就是 $Z = 2$ 时类氢 $1s$ 能量的两倍。

:::example 乘积波函数与问题的规模 {#ex-he-product}
用每电子 $E_{1s} = -Z^{2}\times 13.60\ \mathrm{eV}$，计算乘积波函数 $\psi = 1s(1)1s(2)$ 的氦能量，与由两级电离能得到的实验值（$24.59 + 54.42\ \mathrm{eV}$，NIST）比较；再把 $e^{2}/4\pi\varepsilon_0 r_{12}$ 当微扰，用原子单位下 $\langle r_{12}^{-1}\rangle = \tfrac{5}{8}Z$ 的结果估计排斥效应的一阶效果。
::: solution
乘积能量为 $2\times(-4\times13.60\ \mathrm{eV}) = -108.8\ \mathrm{eV}$，而实验值为 $-79.0\ \mathrm{eV}$：忽略排斥使结合过深 $30\ \mathrm{eV}$，接近 40%。以一阶恢复排斥，加上 $+\tfrac{5}{8}Z$ 哈特里 $= +1.25\times27.21\ \mathrm{eV} = +34.0\ \mathrm{eV}$，得 $-108.8 + 34.0 = -74.8\ \mathrm{eV}$——与实验只差 $4.2\ \mathrm{eV}$，约 5%。剩下的 $4.2\ \mathrm{eV}$ 就是**相关能**：原子之所以得到这份能量，是因为每个电子在另一个电子的*瞬时*场而非平均场中运动，两者互相回避得比无关联乘积所允许的更好一点。能恢复其中哪怕一小部分的波函数就已经优于独立粒子图像；而全部恢复，正是 [[computational-chemistry/electron-correlation]] 的纲领。
:::
:::

::: warning 乘积波函数还不是反对称的 {#warn-product-not-antisym}
$\psi = 1s(1)1s(2)$ 里藏着两个错误，切不可混为一谈。一个是物理的：如上所示，它忽略了电子相关。另一个是形式的：在按粒子交换把波函数反对称化之前，它根本就不是合法的两电子波函数，因为电子是费米子。对氦的基态，这两个错误恰好可分——用自旋相反的电子把乘积反对称化，空间部分不变——但对激发组态和分子，反对称性会直接重排能量本身。绝不要把轨道乘积当作最终答案。
:::

## 自旋与泡利原理

::: definition 电子自旋 {#def-spin}
斯特恩-盖拉赫实验（1922）表明，银原子在非均匀磁场中分成*两*束；乌伦贝克（Uhlenbeck）与古兹密特（Goudsmit）（1925）把这一结果解释为电子的内禀角动量，量子数 $s = \tfrac{1}{2}$：即**自旋**。它的投影只取两个值，$m_s = \pm\tfrac{1}{2}$，用自旋函数 $\alpha$（向上，$m_s = +\tfrac{1}{2}$）与 $\beta$（向下，$m_s = -\tfrac{1}{2}$）书写。自旋没有经典对应，也没有坐标空间的波函数：一电子态是**自旋轨道** $\chi(\mathbf{r}, m_s) = \phi(\mathbf{r})\,\sigma(m_s)$，即轨道 $\phi$ 乘以自旋函数 $\sigma \in \{\alpha, \beta\}$。
:::

::: definition 泡利不相容原理 {#def-pauli}
任何电子体系的总波函数在**交换任意两个电子的全部坐标（空间与自旋）时必须变号**：$\Psi(\ldots i \ldots j \ldots) = -\Psi(\ldots j \ldots i \ldots)$。因此由一套完整量子数指定的一电子态是唯一的：原子中没有两个电子能共享全部四个量子数 $n, l, m_l, m_s$——这就是熟悉的光谱学形式的不相容原理。
:::

构造反对称函数的紧凑办法是**斯莱特（Slater）行列式**。对处于自旋轨道 $\chi_a$ 与 $\chi_b$ 的两个电子，

$$
\Psi(1,2) = \frac{1}{\sqrt{2}}
\begin{vmatrix}
\chi_a(1) & \chi_b(1) \\
\chi_a(2) & \chi_b(2)
\end{vmatrix}
= \frac{1}{\sqrt{2}}\bigl[\chi_a(1)\chi_b(2) - \chi_b(1)\chi_a(2)\bigr],
$$ {#eq-slater-det}

若 $\chi_a = \chi_b$ 行列式为零——不相容是内建的，不是外加的。对氦的基态，$\chi_a = 1s\alpha$、$\chi_b = 1s\beta$，[[#eq-slater-det]] 因子化：空间部分是对称乘积 $1s(1)1s(2)$，自旋部分是反对称的**单重态** $[\alpha(1)\beta(2) - \beta(1)\alpha(2)]/\sqrt{2}$。这就是为什么两个电子*可以*共享 $1s$ 轨道——它们靠自旋区分——而第三个不能：三列只有两个自旋轨道的行列式为零。仅此一条事实就生成了元素周期表的壳层结构。

反对称性有一个没有经典对应的物理后果。若两个电子自旋*平行*，空间波函数反对称，在两电子重合处为零：彼此周围带着一个**交换空穴**运动，其相互排斥因而降低。氦的激发组态 $1s\,2s$ 中，三重态（自旋平行）纯因这一交换效应而比单重态（自旋反平行）低约 $0.8\ \mathrm{eV}$——你在 [[quantum-chemistry/chemical-bond-qm]] 中将看到，正是同一个物理使氢的共价键成为可能。

## 搭建元素周期表

::: proposition 构造原理 {#prop-aufbau}
在轨道近似下，原子的基态电子排布由把电子依次放入能量最低的可用自旋轨道构成，每个空间轨道两个电子、自旋配对，并受泡利原理约束。轨道能序服从经验性的 $n + \ell$ 规则：$n + \ell$ 小的轨道较低，$n + \ell$ 相同时 $n$ 小的较低——给出 $1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f \ldots$ 这条规则是对计算与实测轨道能量的一种概括，不是定理；它的例外在下面讨论。
:::

按序填充重现了周期表的 2、8、8、18、18、32 各周期与化学族：碱金属在每个区块末尾多一个 $s$ 电子，卤素缺一个 $p$ 电子，稀有气体闭合一个壳层。两类例外值得点名。铬是 $[\mathrm{Ar}]\,3d^{5}4s^{1}$ 而非 $3d^{4}4s^{2}$，铜是 $[\mathrm{Ar}]\,3d^{10}4s^{1}$ 而非 $3d^{9}4s^{2}$（铌、钼、银、金行为类似）：把一个 $s$ 电子提升进 $d$ 壳层的能量代价，被半满或全满 $d$ 亚壳层的交换稳定化以及减小的 $s$–$d$ 排斥所补偿。教训是：电子排布是能量竞争的*结果*，不是规则——原子采取使能量最小的任何排布。

:::example 第一排过渡金属及其离子的电子排布 {#ex-configurations}
写出铁（$Z = 26$）以及离子 $\mathrm{Fe^{2+}}$、$\mathrm{Fe^{3+}}$ 的基态电子排布。先电离的是哪个轨道？为什么它不是中性原子中能量最高的轨道？
::: solution
铁为 $[\mathrm{Ar}]\,3d^{6}4s^{2}$。电离先失去 $4s$ 电子：$\mathrm{Fe^{2+}} = [\mathrm{Ar}]\,3d^{6}$，$\mathrm{Fe^{3+}} = [\mathrm{Ar}]\,3d^{5}$。表面上的悖论——中性原子中 $3d$ 在 $4s$ *之后*填充，却*先于* $4s$ 被电离——一旦接受轨道能量依赖占据数就化解了：$3d$ 轨道紧缩、屏蔽很差，随核电荷积累与 $d$ 电子增多而急剧降到 $4s$ 之下。中性原子中 $4s$ 略低故先填；阳离子中 $3d$ 低得多，$4s$ 电子成了最外层、最容易失去的。同样的逻辑解释了为什么钪与钇失去 $d$ 电子给出 $d^{0}$ 离子。
:::
:::

## 屏蔽与钻穿

对氢，能量只依赖 $n$；对一切其他原子，能量同时依赖 $n$ *和* $\ell$，祸首就是方程 [[#eq-he-hamiltonian]] 中的 $1/r_{12}$ 项。$2s$ 轨道的电子在其径向分布中有一个虽小却关键的瓣位于 $1s$ 壳层*之内*（见 [[quantum-chemistry/hydrogen-atom]]），在那里它几乎感受到全部核电荷；而 $2p$ 电子被离心势垒挡在核外，几乎被 $1s$ 电子对完全屏蔽。这一**钻穿**差异——不是任何额外的力——正是 $2s$ 低于 $2p$ 的原因、亚壳层结构存在的原因，并且在 $3d$–$4s$ 边界上放大之后，也是第一过渡系从钾开始的原因。

::: algorithm 斯莱特规则 {#alg-slater}
估计目标电子的**屏蔽常数** $\sigma$，从而 $Z_\mathrm{eff} = Z - \sigma$，并把该电子当作类氢的，能量 $E \approx -Z_\mathrm{eff}^{2}\,(13.60\ \mathrm{eV})/n^{*2}$：
1. 把电子排布写成分组 $(1s)\,(2s,2p)\,(3s,3p)\,(3d)\,(4s,4p)\,(4d)\,(4f)\,(5s,5p)\ldots$
2. 位于目标电子分组*右侧*的各分组中的电子不贡献。
3. 对 $ns$ 或 $np$ 电子：同组中每个*其他*电子贡献 $0.35$（$1s$ 组内为 $0.30$）；$n-1$ 层中每个电子贡献 $0.85$；$n-2$ 层及更内层每个电子贡献 $1.00$。
4. 对 $nd$ 或 $nf$ 电子：其左侧每个电子贡献 $1.00$；同组每个其他电子贡献 $0.35$。
5. 于是 $Z_\mathrm{eff} = Z - \sigma$。
:::

:::example 钾为什么是 $[Ar]\,4s^1$ 而不是 $[Ar]\,3d^1$ {#ex-ks-zeff}
对钾（$Z = 19$，电子排布 $1s^{2}2s^{2}2p^{6}3s^{2}3p^{6}4s^{1}$）的 $4s$ 电子与 $3d$ 电子分别应用斯莱特规则，判断哪个轨道较低。再对钙的 $4s$ 以及钪的 $3d$ 与 $4s$ 电子各做一遍。
::: solution
对钾的 $4s$ 电子：八个 $n-1$ 层电子（$3s,3p$）贡献 $8\times0.85 = 6.80$，十个内层电子贡献 $10\times1.00 = 10.00$，故 $\sigma = 16.80$，$Z_\mathrm{eff}(4s) = 19 - 16.80 = 2.20$。对钾的 $3d$ 电子，所有电子都在其左侧，故 $\sigma = 18\times1.00 = 18.00$，$Z_\mathrm{eff}(3d) = 1.00$。$4s$ 电子钻穿氩实，感受到的电荷多出一倍有余：$4s$ 远低于 $3d$，所以钾是 $[Ar]\,4s^{1}$。钙的 $4s$ 从其伙伴处多得一点：$\sigma = 0.35 + 6.80 + 10.00 = 17.15$，$Z_\mathrm{eff} = 2.85$。到钪，规则给出 $Z_\mathrm{eff}(3d) = 21 - 18 = 3.00$、$Z_\mathrm{eff}(4s) = 21 - (0.35 + 9\times0.85 + 10.00) = 3.00$——打平。打平是规则失效的信号，不是物理：完整计算表明从钪开始占据的 $3d$ 低于 $4s$，这正是钪化学是 $3d^{1}$ 的原因，也是 $3d$ 系沿周期收缩的原因。
:::
:::

:::widget plot

labels: \text{3d 电子}, \text{4s 电子}

第二周期各元素的第一电离能（CRC 手册数据：Li $520$、Be $899$、B $801$、C $1086$、N $1402$、O $1314$、F $1681$、Ne $2081\ \mathrm{kJ\,mol^{-1}}$）总体上升，因为 $Z_\mathrm{eff}$ 在攀升，但有两个凹陷，它们是亚壳层结构的指纹。

:::example 硼与氧的凹陷 {#ex-ie-anomaly}
解释为什么硼的第一电离能（$801\ \mathrm{kJ\,mol^{-1}}$）*低于*铍（$899$），氧（$1314$）低于氮（$1402$），尽管 $Z_\mathrm{eff}$ 沿周期单调增加。
::: solution
硼的最外层电子是第一个 $2p$ 电子，因其对 $1s$ 实钻穿较差而能量高于 $2s$——移走它移走的是一个能量*更高*的电子，所以尽管核电荷更大，电离能反而下降。氮的电子排布是 $2p^{3}$，每个 $p$ 轨道各一个电子、自旋全部平行、彼此因交换而稳定；氧是 $2p^{4}$，第四个 $p$ 电子必须配进已占据的轨道，付出约 $1\ \mathrm{eV}$ 的配对（及额外排斥）能。电离氧是从*一对*电子中移走一个，恰好解除这笔开销，而解除的收益超过了 $Z_\mathrm{eff}$ 的增长。同一配对论证也解释了为什么 $\mathrm{N^{+}}$ 的电离比 $\mathrm{O^{+}}$ 所暗示的更难，以及为什么半满亚壳层作为稳定性母题在本课反复出现。
:::
:::

::: warning 斯莱特规则是模型，不是测量 {#warn-slater}
斯莱特规则是一个经验配方（斯莱特，1930），精度大约两位有效数字；而 $Z_\mathrm{eff}$ 本身不是可观测量：不同定义——斯莱特的、由轨道能量来的克莱门蒂-莱蒙迪（Clementi–Raimondi）的、由电离能来的穆勒-布莱克曼的——在第二位数字上就不一致。写 $Z_\mathrm{eff} = 2.20$，绝不写 $2.2000$；绝不要把两个斯莱特值打平（如上面钪的情形）当作物理简并；也绝不要用规则去裁定它们本来就是照着拟合的能序。它们的价值是定性的：它们使钻穿与收缩*可计算*，让你能用数字而不是形容词来论证。
:::

## 项符号：整个原子的量子数

当存在多个电子时，好量子数不再是各个 $m_{l_i}, m_{s_i}$，而是*总量*。对本课中的轻原子，**LS（罗素-桑德斯）耦合**适用：静电排斥强于自旋-轨道耦合，于是 $\hat{L} = \sum_i \hat{\ell}_i$ 与 $\hat{S} = \sum_i \hat{s}_i$ 近似守恒，$J$ 由 $\hat{J} = \hat{L} + \hat{S}$ 给出。

::: definition 原子项符号 {#def-term-symbols}
原子态记为 $^{2S+1}L_{J}$，其中 $L$ 以大写字母 S、P、D、F、$\ldots$ 对应 $L = 0, 1, 2, 3, \ldots$，$S$ 是总自旋量子数，$2S+1$ 是**自旋多重度**，$J$ 从 $|L - S|$ 到 $L + S$ 以 1 为步长取值（因此当 $L = 0$ 时唯一的能级是 $J = S$）。给定 $L, S$ 的称为*项*；项定了 $J$ 之后称为*能级*；每个能级含 $2J + 1$ 个态。例：钠 D 线是跃迁 $3s\ \,^{2}\mathrm{S}_{1/2} \rightarrow 3p\ \,^{2}\mathrm{P}_{1/2,\,3/2}$，波长 $589.6$ 与 $589.0\ \mathrm{nm}$——单一轨道组态因精细结构劈裂成相距 $17\ \mathrm{cm^{-1}}$ 的两个能级。
:::

一个电子排布之所以劈裂成若干项，是因为泡利原理删去了单电子态的大部分朴素组合。碳的 $2p^{2}$ 排布给出标准的计数：六个自旋轨道（$m_l = +1, 0, -1$ 各有 $\alpha, \beta$）两个一组共有 $\binom{6}{2} = 15$ 个**微观状态**，而各项必须恰好解释十五个态：$^{1}\mathrm{S}$（1 个态）$+\ ^{3}\mathrm{P}$（$3 \times 3 = 9$ 个态）$+\ ^{1}\mathrm{D}$（5 个态）$= 15$。

::: proposition 洪特规则 {#prop-hund}
对一个电子排布的最低项：(i) **自旋多重度最大**的项最低（平行自旋的交换稳定化）；(ii) 同多重度中 **$L$ 最大**的最低（轨道角动量大的电子彼此回避得更好）；(iii) 最低项内部的能级，若亚壳层**不足半满**则 $J = |L - S|$，**超过半满**则 $J = L + S$（自旋-轨道耦合常数在半满处变号）。洪特规则是基态中可靠性极高的经验规律。
:::

:::example 轻 p 区的最低能级 {#ex-ground-terms}
导出 C（$2p^{2}$）、N（$2p^{3}$）、O（$2p^{4}$）与 F（$2p^{5}$）的基态能级。
::: solution
碳：$p^{2}$ 可用的最大 $S$ 是 $S = 1$（三重态），而三重态内泡利原理只允许 $L = 1$（$^{3}\mathrm{D}$ 需要两个自旋平行的电子占据同一 $m_l$）：最低项为 $^{3}\mathrm{P}$，亚壳层不足半满，洪特规则 (iii) 给出 $J = |1-1| = 0$：$\mathrm{C}\ ^{3}\mathrm{P}_{0}$。氮：$S = \tfrac{3}{2}$ 迫使 $L = 0$（三个 $m_l$ 各占一次），得 $^{4}\mathrm{S}_{3/2}$。氧超过半满——按空穴图像等价于两个 $p$ 空穴，所以项仍是 $^{3}\mathrm{P}$、$^{1}\mathrm{D}$、$^{1}\mathrm{S}$，但此时规则 (iii) 选 $J = 1 + 1 = 2$：$\mathrm{O}\ ^{3}\mathrm{P}_{2}$。氟只有一个空穴：$^{2}\mathrm{P}_{3/2}$。注意光谱证实的这个模式：碳与氧共享同一个项却不共享 $J$；氧的整个 $^{3}\mathrm{P}$ 三重态只跨 $227\ \mathrm{cm^{-1}}$，与室温 $kT = 207\ \mathrm{cm^{-1}}$ 相当，这就是基态氧实际上是一个热混合三重态的原因。
:::
:::

::: quiz
氦的激发排布 $1s\,2p$ 给出一个单重项与一个三重项。哪个较低，为什么？
- [x] 三重项：平行自旋通过交换空穴使电子彼此回避，降低了排斥——与洪特第一同理。
- [ ] 单重项：自旋反平行使电子得以共享空间，增强了对核的屏蔽。
- [ ] 二者精确简并：静电哈密顿量不含自旋项。
- [ ] $J$ 较大的那个，按洪特第三规则。
::: solution
三重态比对应的单重态低——$1s\,2s$ 情形约 $0.8\ \mathrm{eV}$，$1s\,2p$ 约 $0.2\ \mathrm{eV}$。哈密顿量确实不含自旋——但反对称性把自旋与*空间*绑在一起，而三重态的空间部分使电子回避（选项 1）。选项 3 是经典陷阱：哈密顿量里没有自旋，能量却依赖自旋，原因正是泡利原理。从历史上看，氦光谱的两族线（正氦与副氦）之所以成为谜题，恰恰因为族间跃迁极弱——自旋改变是不利的。
:::
:::

## 后续内容

把轨道近似定量化——每个电子处于核与其余电子*平均*云自洽场中，反对称性由行列式强加，场反复迭代至自洽——就是**哈特里-福克方法**：从哈特里 1928 年的方案出发，经福克与斯莱特在 1929–30 年发展，详见 [[computational-chemistry/hartree-fock]]；剩下的相关能，即氦的那 $4.2\ \mathrm{eV}$，是 [[computational-chemistry/electron-correlation]] 的主题。你将在 [[quantum-chemistry/approximation-methods]] 中学到的两大近似方法，正是上面用过的工具——氦的排斥用一阶微扰，更好的轨道用变分法；而泡利原理的交换物理将在 [[quantum-chemistry/chemical-bond-qm]] 中作为化学键的引擎重现。本课定量解释的周期趋势，就是 [[general-chemistry-1/periodicity]] 中定性罗列的那些；项符号则是 [[spectroscopy/electronic-spectroscopy]] 与原子钟的语言。

::: history
莫塞莱（Moseley）在 1913–14 年测量了各元素的 $K_\alpha$ X 射线谱线，发现 $\sqrt{\nu} \propto (Z - 1)$：元素周期表按核电荷排序；一个电子对另一个电子的"屏蔽"在成为理论之前先成为了可测量的数字。泡利（Pauli）1925 年为解释周期与反常塞曼效应提出了不相容原理；乌伦贝克（Uhlenbeck）与古兹密特（Goudsmit）同年提出电子自旋，两者合起来解释了碱金属双线。海森堡（Heisenberg）1928 年证明，铁磁体中使自旋排列的"交换力"与劈裂氦各项的是同一个静电加泡利的效应——自旋排列不过是反对称性的幻象。斯莱特（Slater）1930 年发表了他的屏蔽规则；康登（Condon）与肖特利（Shortley）1935 年的《原子光谱理论》固定了原子物理沿用到今天的项符号记法与角动量代数。
:::

::: summary
- 电子排斥项 $e^{2}/4\pi\varepsilon_0 r_{12}$ 使一切多电子原子不可分离；氦的精确能量为 $-79.0\ \mathrm{eV}$，无关联乘积给 $-108.8\ \mathrm{eV}$，一阶微扰给 $-74.8\ \mathrm{eV}$——$4.2\ \mathrm{eV}$ 的缺口就是相关能。
- 电子是费米子：总波函数在交换下反对称，可紧凑地写成斯莱特行列式；泡利原理就是行列式在两个自旋轨道重合时为零。
- 平行自旋带着交换空穴从而降低排斥——洪特第一规则、氦的单重-三重劈裂、乃至共价键的共同起源。
- 带 $n + \ell$ 能序的构造原理重现周期表；铬与铜表明电子排布是能量最小化的结果而非规则，阳离子先电离 $4s$ 再电离 $3d$。
- 亚壳层结构（$E$ 依赖 $\ell$）源于钻穿：斯莱特规则把钻穿变成 $Z_\mathrm{eff}$，解释了钾中 $4s$ 先于 $3d$（$2.20$ 对 $1.00$）与 $3d$ 收缩——但规则是经验的，只有两位有效数字。
- 电离能趋势带着配对的指纹：硼的凹陷是钻穿，氧的凹陷是配对。
- 整个原子记为 $^{2S+1}L_{J}$；微观状态计数（$p^{2}$ 为 15）确定各项，洪特规则确定基态能级：C $^{3}\mathrm{P}_{0}$、N $^{4}\mathrm{S}_{3/2}$、O $^{3}\mathrm{P}_{2}$。
:::

## 练习

::: exercise 电子排布 {level=1}
写出砷（$Z = 33$）、钼（$Z = 42$）与钯原子（$Z = 46$，抗磁性）的基态电子排布。
::: solution
砷：$[\mathrm{Ar}]\,3d^{10}4s^{2}4p^{3}$。钼遵循铬的模式：$[\mathrm{Ar}]\,3d^{5}4s^{1}$（半满 $d$ 加交换能）。钯是著名的例外 $[\mathrm{Kr}]\,4d^{10}$——两个 $5s$ 电子被提升以补全 $4d$ 亚壳层，这就是钯抗磁、且极易形成 Pd(0) 配合物的原因。
:::
:::

::: exercise 氯的斯莱特计算 {level=1 check="6.10"}
用斯莱特规则求氯（$Z = 17$）一个 $3p$ 电子的 $Z_\mathrm{eff}$。（输入无量纲数值。）
::: solution
分组 $(1s)^{2}(2s,2p)^{8}(3s,3p)^{7}$。$n = 3$ 组内其他电子：$6\times0.35 = 2.10$；$n-1$ 层：$8\times0.85 = 6.80$；$1s$ 对：$2\times1.00 = 2.00$。总计 $\sigma = 10.90$，故 $Z_\mathrm{eff} = 17 - 10.90 = 6.10$。
:::
:::

::: exercise 钾的斯莱特计算 {level=1 check="2.20"}
用斯莱特规则求钾（$Z = 19$）$4s$ 电子的 $Z_\mathrm{eff}$。（输入无量纲数值。）
::: solution
八个 $3s,3p$ 电子贡献 $8\times0.85 = 6.80$，十个内层电子贡献 $10.00$，故 $\sigma = 16.80$，$Z_\mathrm{eff} = 19 - 16.80 = 2.20$——是 $3d$ 值 $1.00$ 的两倍多，这就是 $4s$ 先填充的原因。
:::
:::

::: exercise 氦的一阶微扰 {level=2 check="-74.8"}
用无微扰乘积能量 $-108.8\ \mathrm{eV}$ 与一阶排斥修正 $\langle r_{12}^{-1}\rangle = \tfrac{5}{8}Z$（原子单位，$1\ \mathrm{Ha} = 27.21\ \mathrm{eV}$），计算氦基态能量的一阶估计。（以 eV 输入。）
::: solution
修正为 $+\tfrac{5}{8}\times2\ \mathrm{Ha} = +1.25\ \mathrm{Ha} = +34.0\ \mathrm{eV}$，得 $-108.8 + 34.0 = -74.8\ \mathrm{eV}$。相对实验值 $-79.0\ \mathrm{eV}$ 的误差为 $+4.2\ \mathrm{eV}$，即相关能加上未缩放轨道的不完善。
:::
:::

::: exercise 钪的打平 {level=2}
斯莱特规则对钪给出 $Z_\mathrm{eff}(3d) = Z_\mathrm{eff}(4s) = 3.00$。真实原子如何？这对规则的局限说明了什么？
::: solution
光谱把钪的 $3d$ 电子放在远低于 $4s$ 处（$3d$–$4s$ 间隔约 $1.4\ \mathrm{eV}$，钪的化学是 $3d^{1}4s^{2}$ 且先电离 $4s$）。规则打平，是因为规则 4 让左侧每个电子对 $3d$ 电子贡献全额 $1.00$ 的屏蔽，忽略了 $3d$ 径向极大值位于大部分 $4s$ 密度*之内*这一事实。打平是两参数配方的伪影；物理——钻穿与 $3d$ 沿系的收缩——仍然成立，但只有完整的轨道计算（或实验）才能裁定能序。
:::
:::

::: exercise 氦激发排布的项 {level=2}
列出氦排布 $1s\,2s$ 与 $1s\,2p$ 产生的各项，并把每个排布内的项按能量排序。
::: solution
$1s\,2s$：$S = 0$ 或 $1$，$L = 0$，得 $^{1}\mathrm{S}_{0}$ 与 $^{3}\mathrm{S}_{1}$；按交换论证三重态较低（$1s\,2s\ ^{3}\mathrm{S}_{1}$ 是氦的亚稳态，高于基态 $19.82\ \mathrm{eV}$）。$1s\,2p$：$L = 1$，故 $^{1}\mathrm{P}_{1}$ 与 $^{3}\mathrm{P}_{0,1,2}$；仍是三重态较低，其内部各能级几乎等距、几乎不劈裂（氦的自旋-轨道耦合极小）。一个电子在 $1s$、另一个在别处的排布总是给出一对单重-三重——旧量子论中氦光谱两族线的由来。
:::
:::

::: exercise 导出 p² 的各项 {level=3}
按 $(M_L, M_S)$ 取值枚举 $2p^{2}$ 排布的十五个微观状态，并从表中导出各项 $^{1}\mathrm{S}$、$^{3}\mathrm{P}$、$^{1}\mathrm{D}$。
::: solution
把每个允许的自旋轨道对（同一自旋轨道不得重占）按 $M_L = m_{l_1} + m_{l_2}$ 与 $M_S = m_{s_1} + m_{s_2}$ 列表。角点 $M_L = \pm 2$ 只与 $M_S = 0$ 出现（$m_l = \pm1$ 中配对的电子）：$M_L = -2, \ldots, +2$ 共五个态，全部 $M_S = 0$——这就是 $^{1}\mathrm{D}$。余下的态中有 $M_S = \pm 1$、$M_L = -1, 0, +1$ 的条目：一个 $3 \times 3$ 的九态方块——这就是 $^{3}\mathrm{P}$。剩下的恰是 $M_L = 0, M_S = 0$ 的一个态：$^{1}\mathrm{S}$。总计 $5 + 9 + 1 = 15$，且没有泡利允许的态剩余，故项表完备。洪特规则随后选出 $^{3}\mathrm{P}$（$S$ 最大）、$L = 1$（三重态唯一选择）、$J = 0$（不足半满）：基态能级为 $^{3}\mathrm{P}_{0}$，碳的光谱证实了这一点。
:::
:::

::: exercise 用变分法处理氦 {level=3 check="1.69"}
把两个 $1s$ 轨道中的核电荷 $Z = 2$ 换成变分参数 $Z'$（第二个电子屏蔽第一个）。以原子单位计的能量为 $E(Z') = Z'^{2} - 2ZZ' + \tfrac{5}{8}Z'$，其中 $Z = 2$。求最小化后的最佳 $Z'$。（输入 $Z'$，无量纲。）
::: solution
$E(Z') = Z'^{2} - 3.375Z'$，故 $\mathrm{d}E/\mathrm{d}Z' = 2Z' - 3.375 = 0$ 给出 $Z' = 1.6875 \approx 1.69$：每个电子约看到裸核电荷的 $84\ \%$。能量为 $E = -1.6875^{2}\ \mathrm{Ha} = -2.848\ \mathrm{Ha} = -77.5\ \mathrm{eV}$——优于一阶微扰（$-74.8\ \mathrm{eV}$），与实验只差 $1.5\ \mathrm{eV}$，因为缩放后的轨道收缩以平衡核吸引与排斥。这就是变分原理的最简形式，也是 [[quantum-chemistry/approximation-methods]] 及之后一切轨道优化的模板。
:::
