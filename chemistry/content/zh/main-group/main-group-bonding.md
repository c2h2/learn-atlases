八隅律是化学中最成功的谎言。它对第二周期非常好用——甲烷、氨、水、氟碳化合物——可是周期表还在往下延伸，较重的主族元素便从三个系统的方向打破它：电子太少（硼烷、$\mathrm{BF_3}$），按计数规则电子太多（$\mathrm{SF_6}$、$\mathrm{XeF_2}$、$\mathrm{I_3^-}$），以及计数规则所要求的重键缺少足够的轨道（$\mathrm{SiO_2}$拒绝成为分子）。本章表明，这三种失效有同一个解药：不再计数**两个原子之间**的电子对，而是在三个或更多原子上构建分子轨道。三中心键并不是什么奇特的例外——它就是三个原子核共享电子的普通量子力学；一旦你会画它的轨道，超价、乙硼烷、硅–硅双键之弱以及整个“双键规则”便作为同一个故事自然得出。这里使用的分子轨道方法即[[bonding-structure/molecular-orbitals]]中的方法；它预测的形状用[[bonding-structure/vsepr]]中的价层电子对互斥规则来解读。

## 电子记账及其三种失效

::: definition 打破八隅律的三种方式 {#def-electron-count}
主族中心原子偏离八个价电子的方式恰好有三种。它可以是**缺电子的**——电子数少于与所有近邻形成二中心键所需的数目（$\mathrm{BH_3}$，6个电子；$\mathrm{BeH_2}$，4个）。（不要把它与$\mathrm{Al_2Cl_6}$混淆，后者电子是够的：每个氯桥是一个普通的$\mathrm{Al{-}Cl}$键加上一个由氯孤对电子形成的配位键，每个铝都满足八隅。）它可以是**超价的**——按离子计数规则分配到的电子多于八个（$\mathrm{PF_5}$：10；$\mathrm{SF_6}$：12；$\mathrm{XeF_2}$：10；$\mathrm{I_3^-}$：中心碘上10个）。或者它可以是**奇电子的**——电子总数为奇数（$\mathrm{NO}$、$\mathrm{NO_2}$、$\mathrm{ClO_2}$），我们把它当作前两种情形的极限情况来处理。经典的修补办法是用$d$轨道“扩展八隅”；而自20世纪80年代以来得到定量计算支持的现代办法是**多中心成键**：多出的电子对占据分布在三个或更多原子上的轨道，$d$轨道不起显著作用。
:::

反对$d$轨道参与的证据是定量的：第三周期中心原子（P、S、Cl）的$3d$轨道能量太高，无法与配体的$2p$轨道强烈混合。对$\mathrm{SF_6}$的布居分析表明硫上带有很大的**正**电荷，氟上带负电荷；$3d$布居至多为零点几个电子，计算所需的$d$函数起的是极化函数的作用（让硫的电子密度得以畸变），而不是容纳成键电子对的价轨道。计数规则作为**记账**保留下来；其中的物理是多中心成键。

## 超价：三中心四电子键

::: proposition 三中心四电子键 {#prop-3c4e}
当中心原子$M$与两个共线配体$L$结合，并且拥有一个价轨道和相当于两个电子的“额外”容量时，三个原子轨道（$L$、$M$、$L$）组合成三个分子轨道：一个成键组合，一个定域在两个端基原子上的**非键**组合，以及一个反键组合。四个电子填入前两个。结果是**一个净键分布在两段连接上**：每一段$M{-}L$连接都比普通的二中心键更长、更弱，分子在中心处呈直线形，而最高占据轨道——只在端基上有电子密度的非键轨道——是活泼的碱性位点。
:::

::: proof 三轨道模型 {#proof-3c}
在休克尔近似下，取三个共线轨道$\phi_1, \phi_2, \phi_3$（端基、中心、端基），最近邻共振积分为$\beta < 0$。久期行列式给出能量
$$
E = \alpha + \sqrt{2}\,\beta,\qquad E = \alpha,\qquad E = \alpha - \sqrt{2}\,\beta,
$$
系数为$\psi_1 = \tfrac{1}{2}\phi_1 + \tfrac{\sqrt{2}}{2}\phi_2 + \tfrac{1}{2}\phi_3$（成键），$\psi_2 = \tfrac{1}{\sqrt{2}}(\phi_1 - \phi_3)$（非键：它有一个**穿过**中心原子的节面），$\psi_3$为反键。填入四个电子后，三中心总能量（这里是$\sigma$骨架；烯丙基体系是具有相同久期方程的$\pi$类似物）为
$$
2(\alpha + \sqrt{2}\beta) + 2\alpha = 4\alpha + 2\sqrt{2}\,\beta ,
$$
而两个普通的二中心键给出$2 \times 2(\alpha + \beta) = 4\alpha + 4\beta$。由于$\beta$为负，$2\sqrt{2}\beta > 4\beta$：三中心排布的稳定化比两个正常键**少**——超价键本质上是弱的——但比一个二中心键加一对非键电子（$4\alpha + 2\beta$）更稳定，这正是第二个配体能够被结合的原因。这四个电子构成由两段连接共享的一个键，而$\psi_2$的电子密度完全位于端基原子上。
:::

证明中假设三个原子完全相同。在实际分子中，中心原子与端基原子不同；用能量为$\alpha_\mathrm{M}$的中心轨道和能量为$\alpha_\mathrm{L}$的端基轨道求解同一个久期方程，就可以看出这带来什么变化。以$\alpha_\mathrm{L}$为能量零点、以$|\beta|$为单位，记$x = (\alpha_\mathrm{M} - \alpha_\mathrm{L})/|\beta|$，非键能级恰好保持在$0$（它没有中心原子成分，因此感受不到$\alpha_\mathrm{M}$），另外两个能级为$E = \tfrac{1}{2}\left(x \mp \sqrt{x^2 + 8}\right)$。

::: example 三种物种，同一种键 {#ex-3c-species}
$\mathrm{XeF_2}$（直线形，$\mathrm{Xe{-}F}\ 198\ \mathrm{pm}$）、$\mathrm{I_3^-}$（直线形，$\mathrm{I{-}I}\ 290\ \mathrm{pm}$，而$\mathrm{I_2}$中为$267\ \mathrm{pm}$）和$\mathrm{HF_2^-}$（对称，$\mathrm{F{-}H}$约$114\ \mathrm{pm}$，$\mathrm{F\cdots F}$约$227\ \mathrm{pm}$）看起来毫不相干。证明它们是同一种键。
::: solution
每一个都是在三个共线轨道中有四个电子的$\mathrm{L{-}M{-}L}$单元。对$\mathrm{XeF_2}$：一个容纳两个电子的氙$5p$轨道，加上每个氟$2p$轨道各一个电子。对$\mathrm{I_3^-}$：可以看作$\mathrm{I^-}$向$\mathrm{I_2}$的$\sigma^*$轨道给电子，这是同样的三轨道四电子组合。对$\mathrm{HF_2^-}$：中间是$\mathrm{H\ 1s}$轨道，每个氟上一个$2p$轨道，四个电子来自一个$\mathrm{F{-}H}$键电子对和一个氟离子孤对电子。$\mathrm{XeF_2}$和$\mathrm{I_3^-}$是直线形的，因为它们是$\mathrm{AX_2E_3}$：中心周围五个电子域，排成三角双锥，三对孤对电子位于赤道平面（在那里排斥最小），两个配体位于轴向。$\mathrm{HF_2^-}$的氢上没有孤对电子；它是直线形的，因为$1s$轨道与位于两侧相对位置的两个配体重叠最好。三者的连接都很长，原因相同——每段各为半个键：$\mathrm{I_3^-}$中为$290\ \mathrm{pm}$，而$\mathrm{I_2}$中为$267\ \mathrm{pm}$；$\mathrm{HF_2^-}$中每段$\mathrm{H{-}F}$连接为$114\ \mathrm{pm}$，而游离HF中为$92\ \mathrm{pm}$。端基是活泼位点：$\mathrm{I_3^-}$释放出$\mathrm{I_2}$，$\mathrm{XeF_2}$转移$\mathrm{F}$或$\mathrm{F^-}$，而$\mathrm{HF_2^-}$正是无水HF成为如此特殊的溶剂的原因。一幅轨道图像，三章描述性化学。
:::
:::

::: example 六氟化硫：十二个电子，六个等价键 {#ex-sf6}
$\mathrm{SF_6}$有六个相同的$\mathrm{S{-}F}$键（$156.4\ \mathrm{pm}$），化学上几乎是惰性的。三中心图像如何给出六个等价键？“打破八隅律的12个电子”又到哪里去了？
::: solution
构建六个氟$\sigma$轨道的对称性匹配组合：它们张成$a_{1g} + e_g + t_{1u}$。硫的$3s$与$a_{1g}$匹配，三个$3p$轨道与$t_{1u}$匹配；排除$d$轨道后，没有任何硫价轨道具有$e_g$对称性，因此配体组合中的$e_g$那一对（四个电子）保持非键并以氟为中心。只有$a_{1g}$与$t_{1u}$组合——八个电子——是成键的，它们的反键伙伴是空的。十二个电子，六段等价连接，四对成键电子：每段$\mathrm{S{-}F}$连接的键级为三分之二。这就是$\mathrm{SF_6}$配位饱和的原因，而且由于$\mathrm{S{-}F}$键被屏蔽在氟笼之内，它在动力学上是惰性的。“硫周围有12个电子”是把成键电子对归给硫所产生的记账假象；实际电子密度使硫带很强的正电、每个键都是极性的，只有八个电子处在含硫的成键轨道中。比较$\mathrm{PF_5}$（三角双锥，两种键长——轴向键是较弱的三中心型连接）和$\mathrm{SF_4}$（跷跷板形：价层电子对互斥理论中$\mathrm{AX_4E}$的一个位置被孤对电子占据）。
:::
:::

::: warning “扩展八隅”是记账，而不是机理 {#warn-dorbitals}
这一主题中萦绕着两个错误。第一个是说硫“用它的$3d$轨道来扩展八隅”：定量计算表明$\mathrm{SF_6}$的$d$轨道布居接近非键基线，旧的$sp^3d^2$杂化说法已经过时——但这种说法在较早的教科书中仍然存在，所以遇到时要认得出来。第二个是由于八隅并未真正扩展，便断定超价分子并没有真正成键——它们确实成键，其键级、键长和振动频率都与上述三中心四电子模型相符。正确的表述是：**一对超价连接是一个三中心四电子键（一对成键电子和一对非键电子）；像乙硼烷中那样的缺电子桥是三中心二电子的版本。八隅律是一种二中心近似，它的失效是悄无声息的，而不是轰轰烈烈的。**
:::

## 缺电子：三中心二电子键

::: definition 乙硼烷与$\mathrm{B{-}H{-}B}$桥 {#def-3c2e}
$\mathrm{B_2H_6}$有十二个价电子，恰好够四个端基二中心$\mathrm{B{-}H}$键（八个电子）加两个三中心桥（四个电子）。如果再画一个二中心$\mathrm{B{-}B}$键，就需要十四个电子和七段连接；乙硼烷既没有多余的电子对，也没有这个键。它通过**桥连**解决连接问题：两个氢位于两个硼之间，每个由一个**三中心二电子键**维系（每个硼贡献一个近似$sp^3$杂化轨道，加上H的$1s$：三个轨道，两个电子位于能量最低的成键组合中）。该结构有四个端基$\mathrm{B{-}H}$键（$119\ \mathrm{pm}$，正常）和四段桥连$\mathrm{B{-}H}$连接（$133\ \mathrm{pm}$，较长，正如半个键所应有的那样），$\mathrm{B\cdots B} = 177\ \mathrm{pm}$。每个硼参与两个端基键和两个桥，因此周围有相当于四对电子的成键——在计数意义上是八隅——却没有任何二中心$\mathrm{B{-}B}$键。桥连是划算的：二聚反应$2\,\mathrm{BH_3} \rightarrow \mathrm{B_2H_6}$强烈放热（估计值约为$-150\ \mathrm{kJ\,mol^{-1}}$量级；$\mathrm{BH_3}$过于活泼，无法直接精确测量），这就是游离甲硼烷只能以瞬态物种或$\mathrm{H_3B{\cdot}THF}$之类的加合物形式出现的原因。
:::

同一种键型也维系着聚合型固态氢化物。晶态$\mathrm{BeH_2}$是由共顶点的$\mathrm{BeH_4}$四面体构成的三维网络，每个氢通过一个$\mathrm{Be{-}H{-}Be}$三中心二电子键桥连两个铍原子；$\mathrm{AlH_3}$是由$\mathrm{AlH_6}$八面体通过同类$\mathrm{Al{-}H{-}Al}$桥共顶点构成的网络。对比$\mathrm{Al_2Cl_6}$的氯桥（端基$\mathrm{Al{-}Cl}$约$206\ \mathrm{pm}$；四个桥连$\mathrm{Al{-}Cl}$键相等，气相中约$225\ \mathrm{pm}$）。它们看起来相似，但根本不缺电子。桥连氯有多余的孤对电子，所以每个$\mathrm{Al{-}Cl{-}Al}$桥只不过是两个普通的二中心二电子键：一个正常的$\mathrm{Al{-}Cl}$键，以及一个由氯孤对电子进入另一个铝的空$3p$轨道而形成的配位键。一旦形成，两个键就无法区分（共振使四个桥连键都相等），每个铝有四对成键电子——一个八隅。氢桥需要多中心轨道，因为氢没有第二对电子可以给出；卤桥则不需要。

::: proposition 韦德规则 {#prop-wade}
对于硼烷簇$\mathrm{B_nH_{n+m}}$（以及碳硼烷，其中一个$\mathrm{CH}$单元比$\mathrm{BH}$多贡献一个骨架电子），计算**骨架电子**数，再将总和减半得到电子对数：每个$\mathrm{BH}$（或相当于$\mathrm{CH^+}$的）顶点贡献$2$个电子，每个额外的氢贡献$1$个，每个负电荷贡献$1$个。这些增量是电子，不是电子对。于是
$$
\text{骨架电子对数} = \begin{cases} n+1 & \text{闭式（closo，闭合多面体）}\\ n+2 & \text{巢式（nido，缺一个顶点）}\\ n+3 & \text{网式（arachno，缺两个顶点）} \end{cases}
$$
这条规则之所以成立，是因为三角面多面体的骨架恰好需要$n+1$对电子来完成其三维成键（一个径向组合与离域的切向组合），而去掉顶点就需要增加电子对来封闭敞开的面。
:::

::: example 计数骨架电子对 {#ex-wade-count}
对$\mathrm{B_2H_6}$、$\mathrm{B_5H_9}$、$\mathrm{B_6H_6^{2-}}$和$\mathrm{B_4H_{10}}$进行分类。
::: solution
$\mathrm{B_2H_6}$：$2 \times 2 + 4 \times 1 = 8$个电子$= 4$对$= n+2$ → 形式上为**巢式**（对应$n+1 = 3$个顶点的母体闭式多面体是三角形，去掉一个顶点；对这样小的分子，分类只是记账而非几何）。$\mathrm{B_5H_9}$：$5 \times 2 + 4 = 14 \to 7 = 5+2$ → **巢式**（四方锥，由八面体而来）。$\mathrm{B_6H_6^{2-}}$：$6 \times 2 + 2 = 14 \to 7 = 6+1$ → **闭式**（八面体——确实是稳定的八面体闭式硼酸根二价阴离子）。$\mathrm{B_4H_{10}}$：$4 \times 2 + 6 = 14 \to 7 = 4+3$ → **网式**（蝶形：去掉两个相邻顶点的八面体）。这条规则的妙处在于，一行算术就能为你从未见过的化学式预测出**结构类型**；碳硼烷$\mathrm{C_2B_6H_8}$（$2\times3 + 6\times2 = 18 \to 9 = 8+1$，闭式）出色地证实了它。
:::
:::

## 双键规则：较重元素为何保持简单

::: proposition 双键规则 {#prop-double-bond-rule}
第二周期以下的元素形成的$\pi$键越来越弱，因为$np$–$np$重叠随$p$轨道尺寸的增大而急剧下降（$\pi$键需要在随$n$增大的距离上实现侧面接触）。其经验内容是：在第二周期，$\pi$增量很大——$\mathrm{C{=}C}$（$602$）略少于两个$\mathrm{C{-}C}$键（$2 \times 346 = 692$），而$\mathrm{C{=}O}$（$799$）胜过两个$\mathrm{C{-}O}$（$716$），$\mathrm{N{\equiv}N}$（$945$）胜过三个$\mathrm{N{-}N}$（$489$）——所以重键常常胜出。在第二周期以下，重键远远比不上它所取代的单键，网络结构胜出。因此$\mathrm{CO_2}$是以双键结合的小分子，而$\mathrm{SiO_2}$是单键网络；$\mathrm{N_2}$是三键结合的气体，而磷是$\mathrm{P_4}$固体；烯烃司空见惯，而乙硅烯十分罕见。
:::

数字让这条规则一目了然。平均键焓（$\mathrm{kJ\,mol^{-1}}$；较重元素重键的数值是由少数稳定化合物和计算得到的估计值，误差约$\pm 30$）：$\mathrm{C{-}C}\ 346$，$\mathrm{C{=}C}\ 602$（与单键之比：$1.74$）；$\mathrm{Si{-}Si}\ 226$，$\mathrm{Si{=}Si}$约$310$（$1.37$）；$\mathrm{C{-}O}\ 358$，$\mathrm{C{=}O}\ 799$（$2.23$）；$\mathrm{Si{-}O}\ 452$，$\mathrm{Si{=}O}$约$640$（$1.42$）；$\mathrm{N{-}N}\ 163$，$\mathrm{N{\equiv}N}\ 945$（$5.8$——三键是一笔财富，而氮的化学就是在花这笔钱）；$\mathrm{P{-}P}\ 201$，$\mathrm{P{=}P}$约$310$（$1.5$）。对每一个第三周期元素，与电负性近邻形成的两个单键都胜过一个双键——硅的大部分化学就浓缩在这一个不等式里。

利用上面的键焓，预测并论证碳和硅的氧化物的结构与标准状态。
::: solution
按每个$\mathrm{EO_2}$计数化学键。分子有两个双键；网络有四个单键。对碳：$2 \times 799 = 1598\ \mathrm{kJ\,mol^{-1}}$对$4 \times 358 = 1432$，分子领先$166\ \mathrm{kJ\,mol^{-1}}$，所以$\mathrm{CO_2}$是气体。对硅：$2 \times 640 = 1280$对$4 \times 452 = 1808$，网络领先$528\ \mathrm{kJ\,mol^{-1}}$。（在网络中每个硅有四个$\mathrm{Si{-}O}$键、每个氧有两个，所以每个$\mathrm{SiO_2}$单元恰好有四个键——无需再减半。）二氧化硅是由$\mathrm{SiO_4}$四面体构成的巨型固体，熔点接近$1700\ \mathrm{^\circ C}$，而$\mathrm{CO_2}$在$-78\ \mathrm{^\circ C}$升华。同一个不等式解释了为什么暴露在空气或水蒸气中的硅会生成一层致密的$\mathrm{SiO_2}$（硅微电子学有意生长的稳定绝缘氧化物），以及为什么硅氧烷$\mathrm{Si{-}O{-}Si}$链——硅酮——是硅的特征聚合物。
:::
:::

::: example 成链：各元素能连成多长的链？ {#ex-catenation}
碳链可长达数百万个原子并能在空气中存在；硅烷$\mathrm{Si}_n\mathrm{H}_{2n+2}$只有短链为人所知，而且会自燃。利用$D(\mathrm{O{=}O}) = 498\ \mathrm{kJ\,mol^{-1}}$和上面的键焓，比较碳和硅向链键中插入一个氧原子的焓变$\mathrm{E{-}E} + \tfrac{1}{2}\,\mathrm{O_2} \rightarrow \mathrm{E{-}O{-}E}$，并解释两者行为的差别。
::: solution
对两种元素作同一个比较：断开一个$\mathrm{E{-}E}$键和半个$\mathrm{O{=}O}$键，形成两个$\mathrm{E{-}O}$键。
$$
\text{C：}\quad 346 + 249 - 2(358) = -121\ \mathrm{kJ\,mol^{-1}};\qquad
\text{Si：}\quad 226 + 249 - 2(452) = -429\ \mathrm{kJ\,mol^{-1}}.
$$
两者都是放热的：碳链在空气中**同样**是热力学不稳定的，任何烃都是如此（它燃烧生成$\mathrm{CO_2}$和水是强放热的）。差别部分在于程度——氧化一个$\mathrm{Si{-}Si}$键放出的热量是碳的三倍半——但主要在于速率。烃受到**动力学保护**：碳小且配位饱和，$\mathrm{C{-}C}$和$\mathrm{C{-}H}$键是非极性的，没有可供进攻试剂利用的低能空轨道，而且与三重态$\mathrm{O_2}$的反应需要由火焰或火花引发的自由基链。硅更大、正电性更强：它的键是极性的且较长，亲核试剂（水、氧的孤对电子）可以通过可及的$\sigma^*$轨道进攻它，因此硅烷无需引发剂就能与空气和水反应。由此预测：**$\mathrm{Si{-}Si}$和$\mathrm{Si{-}H}$键是硅化学的活泼位点**，长的$\mathrm{Si{-}Si}$链只有在每个硅都带有大体积有机基团时才能存在——即聚硅烷。坚固的硅聚合物，硅酮，是建立在$\mathrm{Si{-}O{-}Si}$之上的，而这正是计算表明硅所偏爱的键。
:::
:::

::: warning 不要用dπ–pπ反馈键来挽救八隅律 {#warn-dpi}
较早的书用孤对电子向空$d$轨道的$d\pi{-}p\pi$给予，来解释硅和磷的酰胺的平面性、硅氮烷中短的$\mathrm{Si{-}N}$键以及$\mathrm{P{=}O}$键的强度。现代计算否定了显著的$d$轨道占据；这些效应实际上来自**负超共轭**（孤对电子向相邻键的$\sigma^*$轨道给予）、简单的静电作用，以及——对$\mathrm{P{=}O}$而言——很强的离子性$\mathrm{P^+{-}O^-}$特征。当你想为第三周期元素搬出$d$轨道时，先问一问极化与$\sigma^*$接受能否解释这一事实；它们几乎总是能够解释。
:::

## 奇电子与低价

奇电子主族分子从另一个角度展示了同样的物理：$\mathrm{NO}$（11个价电子）在低温下二聚为反磁性的$\mathrm{N_2O_2}$；$\mathrm{NO_2}$将其奇电子配对，生成无色的$\mathrm{N_2O_4}$（$\Delta H \approx -57\ \mathrm{kJ\,mol^{-1}}$，这是演示勒夏特列原理的经典注射器实验）；$\mathrm{ClO_2}$也是奇电子分子，它不二聚，但浓缩时有危险的爆炸性。与之对称，缺电子分子是**路易斯酸**——这是[[main-group/inorganic-acids-bases]]的主题。$\mathrm{BF_3}$是第二周期中心（平面形，有空的$2p$轨道），它与$\mathrm{NH_3}$结合生成$\mathrm{F_3B{-}NH_3}$，以一个配位键补全硼的八隅。第3周期的类似物$\mathrm{AlCl_3}$则自我满足：它通过配位氯桥二聚为$\mathrm{Al_2Cl_6}$，而不是作为八隅不完整的单体存在。注意贯穿本章的模式：**一个未填满的轨道与一个填满的轨道相遇，在二中心计数不足之处就形成一个键**——路易斯酸碱加合物、乙硼烷的桥和超价氟化物的共同点仅此而已，而它们也只需要这一个共同点。

::: quiz
为什么$\mathrm{XeF_2}$是直线形而不是弯曲形？
- [x] 两段$\mathrm{Xe{-}F}$连接是建立在一个氙$p$轨道上的一个三中心四电子键，而氙的三对孤对电子位于五个电子域三角双锥排布的赤道平面上——于是轴向$\mathrm{F{-}Xe{-}F}$角为$180^\circ$。
- [ ] 氙使用$sp^3d$杂化轨道，两对额外的孤对电子把键排斥成直线。
- [ ] 每个$\mathrm{Xe{-}F}$都是普通的二中心键，$\mathrm{XeF_2}$是氙上没有孤对电子的$\mathrm{AB_2}$分子。
- [ ] 氟的孤对电子相互排斥形成反式排布，氙只是随之而定。
::: solution
三中心四电子键沿氙$p$轨道的轴形成——这确定了键的方向。按价层电子对互斥理论的电子域计数，氙有两对成键电子和三对孤对电子：五个电子域，三角双锥电子构型。孤对电子占据三个赤道位置，彼此相隔$120^\circ$而不是$90^\circ$，两个氟位于轴向：$\mathrm{AX_2E_3}$，直线形。选项(b)是本章已经拆穿的杂化说法；选项(c)忽略了氙的孤对电子（8个价电子 + 来自氟的2个 = Xe周围10个，五个电子域）；选项(d)颠倒了因果——决定几何构型的是氙的电子对，而不是氟的。

## 后续内容

三中心键在元素概览各章中反复出现：[[main-group/groups-13-14]]中的硼烷与硼氢化物还原剂，较重族的簇阴离子，[[main-group/halogens-noble-gases]]中的氙的氟化物。双键规则支配着[[main-group/groups-13-14]]中的硅酮与硅酸盐，也支配着[[main-group/groups-15-16]]中三键结合的$\mathrm{N_2}$与单键结合的$\mathrm{P_4}$之间、分子型$\mathrm{N_2O_5}$与笼状$\mathrm{P_4O_{10}}$之间的对比。这里所假定的价层电子对互斥形状在[[bonding-structure/vsepr]]中推导，分子轨道方法见[[bonding-structure/molecular-orbitals]]，故事中路易斯酸的那一半在[[main-group/inorganic-acids-bases]]中继续。

::: history
硼烷的结构是20世纪中叶化学中最大的结构难题：化学式画不出来，核磁共振谱在预期一种氢的地方出现了两种氢。具有三中心$\mathrm{B{-}H{-}B}$键的乙硼烷桥式结构由朗格特-希金斯（H. Christopher Longuet-Higgins）与贝尔（R. P. Bell）于1943年提出，并由电子衍射证实（Hedberg与Schomaker，1951）。利普斯科姆（William Lipscomb）先在明尼苏达、后在哈佛，于20世纪50年代主要通过对这些空气敏感化合物的低温X射线晶体学测定了高级硼烷的结构，并发展了关于其三中心成键的拓扑理论；他获得了1976年诺贝尔化学奖。达勒姆的韦德（Kenneth Wade）把这些簇的规律归纳为以他命名的骨架电子计数规则（1971）。超价分子的三中心四电子键由皮门特尔（George Pimentel）提出（1951），并由伦德尔（Robert Rundle）加以发展；$d$轨道的作用问题则由20世纪80和90年代的定量计算解决（例如Reed与Weinhold关于$\mathrm{SF_6}$的工作，1986）。第一个含$\mathrm{Si{=}Si}$键的稳定化合物——四(2,4,6-三甲苯基)乙硅烯（tetramesityldisilene；West、Fink与Michl，1981）——表明了双键规则的真正含义：这种键并非不可能，只是弱；当大体积取代基阻挡了本会把它们变成单键低聚物的反应时，它们就能存在。
:::

::: summary
- 八隅律有三种失效方式——缺电子、超价、奇电子——三者都由跨越三个或更多中心的分子轨道修补，而不是由$d$轨道修补。
- 三中心四电子键（一个键分布在两段共线连接上）解释了$\mathrm{XeF_2}$、$\mathrm{I_3^-}$和$\mathrm{HF_2^-}$的直线形、长键和端基反应性。
- 像$\mathrm{SF_6}$这样的超价分子具有极性的、主要属于配体的成键轨道；“扩展八隅”只是记账，$d$轨道杂化已经过时。
- 三中心二电子键构成乙硼烷的桥，并借助韦德规则（$n+1$/$n+2$/$n+3$对骨架电子）预测硼烷与碳硼烷的簇结构。
- $\pi$成键沿周期向下崩溃：第二周期的重键可以胜过它所取代的单键（$\mathrm{C{=}O}$、$\mathrm{N{\equiv}N}$），而在第二周期以下则落败——这就是$\mathrm{CO_2}$与$\mathrm{SiO_2}$、聚硅烷与硅酮背后的双键规则。
- 氧化链键$\mathrm{E{-}E} + \tfrac{1}{2}\mathrm{O_2} \rightarrow \mathrm{E{-}O{-}E}$对碳（$-121$）和硅（$-429\ \mathrm{kJ\,mol^{-1}}$）都是放热的；碳链能在空气中存在是因为受到动力学保护，硅链则不然。
- 卤桥（如$\mathrm{Al_2Cl_6}$中）是成对的普通二中心键，其中一个是配位键；氢桥（乙硼烷、$\mathrm{BeH_2}$、$\mathrm{AlH_3}$）需要三中心二电子键。
:::

::: exercise 韦德计数 {level=1 check="12"}

::: exercise 天生更弱 {level=2 check="0.71"}
由三轨道模型证明，三中心四电子单元的成键能量小于两个普通二中心键，并求两者稳定化能之比。（输入比值，保留两位小数。）
::: solution
三中心：$4\alpha + 2\sqrt{2}\beta$；两个二中心键：$2 \times 2(\alpha + \beta) = 4\alpha + 4\beta$。成键部分为$2\sqrt{2}\beta$对$4\beta$，比值为$2\sqrt{2}/4 = 1/\sqrt{2} = 0.71$：超价单元保留了两个正常键约百分之七十的稳定化能，并分布在两段连接上。这就是超价连接长而弱的原因，也是$\mathrm{XeF_2}$之类的化合物容易放出一个配体的原因——它们是氟化剂和氧化剂。
:::

::: exercise 半个键的长度 {level=2 check="285"}
鲍林关于键长与键级$n$的经验关系为$r(n) = r(1) - 60\log_{10} n$（以pm计）。取$\mathrm{I_2}$的$r(1) = 267\ \mathrm{pm}$，并对三中心四电子键的每段连接取$n = \tfrac{1}{2}$，预测对称$\mathrm{I_3^-}$离子中的$\mathrm{I{-}I}$距离。（以pm为单位输入，保留三位有效数字。）
::: solution
$r = 267 - 60\log_{10}(0.5) = 267 + 60(0.301) = 267 + 18.1 = 285\ \mathrm{pm}$。对称三碘化物中的观测值约为$290\ \mathrm{pm}$：半键图像解释了大部分键长的增加。在许多盐中该离子是不对称的，一段较短、一段较长，因为抗衡离子的电场把四个电子推向一端——三中心键是软的，容易畸变。
:::

::: exercise 为什么$\mathrm{HF_2^-}$对称而$\mathrm{HCl_2^-}$不对称 {level=2}
$\mathrm{HF_2^-}$是稳定的对称离子。$\mathrm{HCl_2^-}$虽已知，但其氢键较弱，且常常不对称。解释原因。
::: solution
对称的三中心四电子键要求中心的$1s$轨道同时与两个卤素轨道都很好地重叠。在二氟氢根中，$\mathrm{F\cdots F}$距离约为$227\ \mathrm{pm}$，质子位于正中，距每个氟$114\ \mathrm{pm}$——只比游离HF中的键（$92\ \mathrm{pm}$）长$22\ \mathrm{pm}$，因此两段连接都是强的半键。氯更大（$\mathrm{H{-}Cl}$ $127\ \mathrm{pm}$），其$3p$轨道更弥散、电负性更小，因此三中心相互作用更弱；$\mathrm{HCl_2^-}$（已知存在于例如四烷基铵盐中）的氢键弱得多，在许多盐中质子更靠近其中一个氯。同样的尺寸匹配逻辑解释了为什么$\mathrm{O{-}H\cdots O}$氢键常见且强，而$\mathrm{S{-}H\cdots S}$氢键很弱。
:::

::: exercise 碳硼烷的结构 {level=2 check="7"}
把每个$\mathrm{CH}$当作贡献3个骨架电子的顶点，预测$\mathrm{C_2B_4H_6}$的结构类型和形状。（输入骨架电子对数。）
::: solution
骨架电子：$2 \times 3 + 4 \times 2 = 14$，即$7$对。有$n = 6$个顶点，$7 = n+1$：**闭式**，八面体$\mathrm{C_2B_4}$笼，已知有1,2-（碳原子相邻）和1,6-（碳原子相对）两种异构体。也要核对氢的记账：每个顶点带一个端基H，没有额外的桥连氢，所以$\mathrm{C_2B_4H_6}$恰好是闭式化学式。在确定结构之前同时核对电子数和氢原子数，是一个好习惯。
:::

::: exercise 氧化一条链 {level=2 check="-429"}
利用$\mathrm{Si{-}Si}\ 226$、$\mathrm{Si{-}O}\ 452$和$\mathrm{O{=}O}\ 498\ \mathrm{kJ\,mol^{-1}}$，估算$\mathrm{{\equiv}Si{-}Si{\equiv}} + \tfrac{1}{2}\,\mathrm{O_2} \rightarrow \mathrm{{\equiv}Si{-}O{-}Si{\equiv}}$的$\Delta_\mathrm{r}H$。再与碳的类似反应（$\mathrm{C{-}C}\ 346$，$\mathrm{C{-}O}\ 358$）比较，说明为什么聚乙烯能在空气中存在，而不带大体积取代基的聚硅烷不能。（以$\mathrm{kJ\,mol^{-1}}$为单位输入硅的$\Delta_\mathrm{r}H$。）
::: solution
断开的键：一个$\mathrm{Si{-}Si}$（$226$）和半个$\mathrm{O{=}O}$（$249$）；形成的键：两个$\mathrm{Si{-}O}$（$904$）。$\Delta_\mathrm{r}H \approx 226 + 249 - 904 = -429\ \mathrm{kJ\,mol^{-1}}$。对碳，$346 + 249 - 716 = -121\ \mathrm{kJ\,mol^{-1}}$。两者都是有利的，所以行为上的差别并不在于碳链在空气中热力学稳定——它们并不稳定。聚乙烯之所以能存在，是因为它的氧化很慢（非极性键，碳上没有可及的空轨道，自由基链需要引发）；硅链的键是极性的、较长，易受进攻，而且驱动力大得多。平均键焓使这只是一个粗略估计，误差为几十$\mathrm{kJ\,mol^{-1}}$。
:::

::: exercise 氧化物不等式 {level=3 check="528"}
利用键焓$\mathrm{C{-}O}\ 358$、$\mathrm{C{=}O}\ 799$、$\mathrm{Si{-}O}\ 452$、$\mathrm{Si{=}O}\ 640\ \mathrm{kJ\,mol^{-1}}$，对E = C和E = Si分别计算单键网络（每个E四个单键，每个O两个）相对于分子型二氧化物（$\mathrm{O{=}E{=}O}$）每个化学式单元的焓优势，指出每种情况下哪种结构胜出，并解释为什么二氧化碳仍能与碱性氧化物轻易反应，而二氧化硅不能。（以$\mathrm{kJ\,mol^{-1}}$为单位输入硅的网络优势。）

:::
::: solution
每个$\mathrm{EO_2}$，分子有两个$\mathrm{E{=}O}$键，网络有四个$\mathrm{E{-}O}$键。碳：分子$2 \times 799 = 1598$，网络$4 \times 358 = 1432$；分子以$166\ \mathrm{kJ\,mol^{-1}}$胜出（网络的“优势”为$-166$）。硅：分子$2 \times 640 = 1280$，网络$4 \times 452 = 1808$；网络以$528\ \mathrm{kJ\,mol^{-1}}$胜出。这一反转就是算术形式的双键规则。与碱性氧化物的反应是另一种比较：$\mathrm{CaO + CO_2 \rightarrow CaCO_3}$把一个$\mathrm{C{=}O}$ π键转化为一个$\mathrm{C{-}O^-}$ σ键，并获得很大的晶格能，在室温下是放能的（加热石灰石使其逆转）。二氧化硅的网络本来就由单键构成，没有弱的π键可以交换；它只溶于热的浓碱或熔融碳酸盐中，产物是硅酸盐。
:::

::: exercise 两种桥 {level=3}
$\mathrm{B_2H_6}$和$\mathrm{Al_2Cl_6}$都是由两个桥连原子维系的二聚体。对每一个，计算可用于桥的电子数并描述其成键；然后解释为什么三氯化硼在气相中是单体，而三氯化铝会二聚。
::: hint
计算整个分子的价电子数，减去端基二中心键中的电子。再问一问桥连H和桥连Cl各有多少对可用的孤对电子。
:::
::: solution
**乙硼烷**：12个价电子；四个端基$\mathrm{B{-}H}$键用去8个，剩下4个给两个桥——每个$\mathrm{B{-}H{-}B}$单元一对，即三中心二电子键。氢没有孤对电子，因此不可能有其他描述。**$\mathrm{Al_2Cl_6}$**：48个价电子。四个端基$\mathrm{Al{-}Cl}$键用去8个，端基氯的孤对电子占24个；其余16个属于两个桥连氯。每个桥连氯形成两个普通的二中心键——四个电子，与每个铝各成一个键（其中一个源于配位）——并保留两对孤对电子。所以这些桥**不是**多中心的：它们是四个二中心二电子键，每个铝有四对成键电子。单体与二聚体：二聚把两对$\mathrm{Cl}$孤对电子变成两个$\mathrm{Al{-}Cl}$键，补全了铝的八隅，而大的铝原子有空间容纳四个氯。硼很小：一个硼周围四个氯会很拥挤，桥连$\mathrm{B{-}Cl{-}B}$角也会有张力。于是单体$\mathrm{BCl_3}$转而通过氯孤对电子向硼的空$2p$轨道的π给予，部分缓解其缺电子状态。尺寸决定了哪一种缺电子的解药负担得起。
:::
