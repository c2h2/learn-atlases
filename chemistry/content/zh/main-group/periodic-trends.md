对主族化学家来说，元素周期表是一张关于**原因**的周期表。后续各章中的每一个反应、结构与材料——铯与水反应的剧烈、氮的惰性、高氯酸的酸性、铅(II)比铅(IV)更稳定——都可以追溯到少数几个在周期表上平滑变化的可测量量：原子或离子有多大，它把自己的电子抓得多紧，它对共用电子的吸引有多强，以及它能承受失去多少个电子。本章把这些量精确化，确定它们的变化规律，并且——同样重要的是——把反常现象逐一编目，因为在主族化学中，正是这些反常（F–F键弱、惰性电子对、镓出人意料地小）显露出真正的物理。这些规律最初已在[[general-chemistry-1/periodicity]]中描绘过；在这里我们把它们当作工作工具，学会用它们来**计算**，而不只是背诵。

## 尺寸：第一个规律

::: definition 原子与离子的半径 {#def-radii}
在确定测量约定之前，并不存在所谓“原子的半径”。**共价半径**是以单键相连的两个相同原子间距离的一半（由$\mathrm{C{-}C}$键长得$r(\mathrm{C}) = 76\ \mathrm{pm}$），**金属半径**是金属中最近邻距离的一半，**范德华半径**是最近的非键接触距离。**离子半径**是对晶体中离子–离子距离的一种拟合划分，它依赖于配位数和所假定的划分方式——这就是半径要按配位数列表的原因（下面的数值是香农（Shannon）给出的八面体配位值）。有了这一保留，这些数字的可移植性好得惊人：$\mathrm{Li^+}\ 76$，$\mathrm{Na^+}\ 102$，$\mathrm{K^+}\ 138$，$\mathrm{Rb^+}\ 152$，$\mathrm{Cs^+}\ 167\ \mathrm{pm}$；$\mathrm{Mg^{2+}}\ 72$，$\mathrm{Ca^{2+}}\ 100$，$\mathrm{Sr^{2+}}\ 118$，$\mathrm{Ba^{2+}}\ 135\ \mathrm{pm}$；$\mathrm{O^{2-}}\ 140$，$\mathrm{F^-}\ 133$，$\mathrm{Cl^-}\ 181$，$\mathrm{S^{2-}}\ 184\ \mathrm{pm}$。
:::

两条规则组织起半径表。**同族自上而下半径增大**：每个周期增加一个电子层，核电荷虽然增大，但新增的内层电子几乎完全屏蔽了它。**同周期从左到右半径减小**：电子加入**同一**电子层而核电荷增大，同层电子相互屏蔽很差，因此外层电子感受到的有效核电荷$Z_\mathrm{eff}$上升，把它们拉近。阳离子比其母体原子小（价层已失去，剩下的电子每个感受到更高的$Z_\mathrm{eff}$），阴离子比母体原子大（满层中额外的电子–电子排斥）；一个有用的记账事实是：$\mathrm{M^+}$大致与前一个稀有气体等电子，直径约为原子的一半。

::: example 等电子系列 {#ex-isoelectronic}
把$\mathrm{O^{2-}}$、$\mathrm{F^-}$、$\mathrm{Na^+}$、$\mathrm{Mg^{2+}}$和$\mathrm{Al^{3+}}$按尺寸排序，并定量解释这一顺序。
::: solution
五者都有十个电子——氖的电子排布——因此在系列**内部**屏蔽没有任何变化；变化的只有核电荷，依次为$Z = 8, 9, 11, 12, 13$。电子数不变而$Z$增大，同一电子云被拉得更紧，所以顺序为
$$
\mathrm{O^{2-}}\ (140) > \mathrm{F^-}\ (133) > \mathrm{Na^+}\ (102) > \mathrm{Mg^{2+}}\ (72) > \mathrm{Al^{3+}}\ (53.5)\ \mathrm{pm}.
$$
注意其中的算术：核电荷从8（$\mathrm{O^{2-}}$）升到13（$\mathrm{Al^{3+}}$），两端离子的半径之比为$140/53.5 \approx 2.6$。等电子系列最清楚地表明，尺寸是电子数与核电荷之间的较量，只要原子核能增加质子而不增加电子层，原子核就占上风。
:::
:::

::: example 镓为什么不比铝大 {#ex-ga-al}
铝和镓同族，但它们的共价半径几乎相同（$121$和$122\ \mathrm{pm}$），第一电离能相差不到$1\ \mathrm{kJ\,mol^{-1}}$（$578$和$579$），而且镓是两者中电负性**更大**的一个（鲍林标度上$1.81$对$1.61$）。同族向下，原子本应更大、更易电离。为什么这里不成立？
::: solution
从Al（$Z = 13$）到Ga（$Z = 31$）增加了十八个质子。其中八个与正常电子层的$3s$、$3p$和$4s$电子相对应，这些电子屏蔽良好。另外十个与$3d$电子相对应，而$d$电子屏蔽很差：它们的径向分布集中在与$4s$、$4p$价电子相同的区域，而不是在其内侧，因此它们并不处在原子核与价层“之间”。于是镓的$4p$电子感受到的$Z_\mathrm{eff}$比按电子层计数所预期的更高——即**d区收缩**——预期的尺寸增大与电离能降低被抵消了。同样的论证，把十个$3d$电子换成十四个$4f$电子，就得到**镧系收缩**：它使$\mathrm{Zr^{4+}}$（$72\ \mathrm{pm}$）与$\mathrm{Hf^{4+}}$（$71\ \mathrm{pm}$）几乎成为孪生，也使铊（共价半径$145\ \mathrm{pm}$）仅比铟（$142\ \mathrm{pm}$）略大。需要记住的推论：紧接在新填满的$d$或$f$亚层之后的元素（$3d$系列之后的Ga、Ge、As、Se；$4f$与$5d$之后的Tl、Pb、Bi）比平滑的族规律所预测的更小，对电子抓得更紧——本章将反复用到这一化学事实。
:::
:::

## 电离能：失去多少个电子，有多难

::: definition 逐级电离能 {#def-ie}
**第一电离能**$IE_1$是过程$\mathrm{M(g) \to M^+(g) + e^-(g)}$所需的最低能量；**第二电离能**$IE_2$从阳离子中再移去一个电子，依此类推。它们都是正值，而且逐级增大，因为从带正电越来越多的离子中移去电子代价越来越高。代表性数值（$\mathrm{kJ\,mol^{-1}}$）：$\mathrm{Li}\ 520$，$\mathrm{Na}\ 496$，$\mathrm{K}\ 419$，$\mathrm{Rb}\ 403$，$\mathrm{Cs}\ 376$；$\mathrm{Be}\ 900$，$\mathrm{B}\ 801$，$\mathrm{C}\ 1086$，$\mathrm{N}\ 1402$，$\mathrm{O}\ 1314$，$\mathrm{F}\ 1681$，$\mathrm{Ne}\ 2081$；$\mathrm{He}\ 2372$（所有元素中最大）。
:::

族的规律（向下：变小）与周期的规律（向右：变大）直接由尺寸论证得出，但有两个系统性的小波折：$IE_1(\mathrm{B}) < IE_1(\mathrm{Be})$，因为硼的第五个电子进入$2p$轨道，其能量高于已填满的$2s$亚层；$IE_1(\mathrm{O}) < IE_1(\mathrm{N})$，因为氧的第四个$2p$电子必须在一个轨道中成对，要付出成对排斥的代价。两者都只让“平滑”规律偏离百分之几，但它们是亚层结构真实存在的证据，而且在每个周期中重复出现。

化学上起决定作用的不是平滑的部分，而是**跃变**：一旦突破一个电子层，$IE_2 \gg IE_1$。镁的逐级电离能为$738$、$1451$、$7733\ \mathrm{kJ\,mol^{-1}}$——第三级电离打入氖原子实，没有任何晶格能或水合能能够偿还这一代价。跃变的位置确定了未知元素的价态，从而确定了它所在的族。

::: proposition 斯莱特规则 {#prop-slater}
一个电子感受到的有效核电荷可估计为$Z_\mathrm{eff} = Z - \sigma$，其中屏蔽常数$\sigma$由各项贡献相加而成：较高组中的电子屏蔽$0$；同一$(ns, np)$组中的电子每个屏蔽$0.35$（$1s$除外，为$0.30$）；$n-1$层中的电子屏蔽$0.85$；更内层的电子屏蔽$1.00$。对于$d$和$f$电子，同组贡献为$0.35$，所有内侧电子屏蔽$1.00$。
:::

::: proof 周期的斜率
取第3周期原子中的一个$3p$电子。斯莱特规则给出$\sigma = 2(1.00) + 8(0.85) + (Z - 11)(0.35)$，因此
$$
Z_\mathrm{eff} = Z - 8.80 - 0.35(Z - 11) = 0.65\,Z - 4.95 .
$$
系数$0.65$即$1 - 0.35$：在同一电子层内，每增加一个电子只屏蔽与之同时增加的那个质子的35 %，所以$Z_\mathrm{eff}$——以及随之变化的结合能，和反向变化的半径——沿周期以每个元素$0.65$的斜率线性漂移。类氢估计$E \propto Z_\mathrm{eff}^2/n^{*2}$于是预测，从Na（$Z_\mathrm{eff} = 2.20$）到Ar（$Z_\mathrm{eff} = 0.65\times 18 - 4.95 = 6.75$），$IE_1$增大为$(6.75/2.20)^2 \approx 9.4$倍；观测比值为$1521/496 \approx 3.1$。（氯的值$6.10$是同一直线上的前一步。）这一差距来自模型所忽略的、不断增大的电子–电子排斥——但周期规律的**方向**是斯莱特规则给出的，这就足以作出预测。
:::

我们可以直接检验斯莱特规则的数值。如果最外层电子是主量子数$n = 3$的类氢电子，它的电离能就是$IE = 13.606\ \mathrm{eV} \times (Z_\mathrm{eff}/3)^2$；反过来，每个测得的$IE_1$都定义了一个“观测”有效电荷$Z_\mathrm{eff} = 3\sqrt{IE_1/13.606\ \mathrm{eV}}$。下图对两者作了比较。

::: example 由电离能确定元素 {#ex-ie-jump}
某元素的电离能为$IE = 578,\ 1817,\ 2745,\ 11578\ \mathrm{kJ\,mol^{-1}}$（第一至第四）。它在哪一族？它的常见化合物应有怎样的化学式？
::: solution
前三级电离能不大且平滑增长；第四级是第三级的四倍多。因此有三个价电子，第四个电子来自内层，该元素属于**第13族**（这些数值是铝的）。预期为$\mathrm{E^{3+}}$化合物——$\mathrm{AlCl_3}$、$\mathrm{Al_2O_3}$。既然单看$IE_1$只比钠的略大一点，为什么不是$\mathrm{E^+}$？因为假想的固体$\mathrm{Al^+Cl^-}$对歧化反应$3\,\mathrm{AlCl} \to 2\,\mathrm{Al} + \mathrm{AlCl_3}$是不稳定的：$+3$态多付出的电离能，被三价离子大得多的晶格能（或键能）绰绰有余地偿还——这就是[[bonding-structure/ionic-bonding]]中的玻恩-哈伯论证。单体$\mathrm{AlCl}$只以高温气体的形式存在。
:::

## 电子亲和能与电负性

::: definition 电子亲和能 {#def-ea}
以焓表示的**第一电子亲和能**$\Delta_\mathrm{ea}H_1$是过程$\mathrm{X(g) + e^- \to X^-(g)}$的焓变；过程放热时该值为负，而把“电子亲和能”列为**放出**的千焦数（正值）的数据表使用的是相反的符号——引用之前务必核对。放出的数值（$\mathrm{kJ\,mol^{-1}}$）：$\mathrm{F}\ 328$，$\mathrm{Cl}\ 349$，$\mathrm{Br}\ 325$，$\mathrm{I}\ 295$，$\mathrm{H}\ 73$，$\mathrm{O}\ 141$（第一），$\mathrm{S}\ 200$。电子亲和能放热最多的是氯而不是氟：向氟紧凑的$n = 2$层加入一个电子，会把它挤进电子–电子排斥很强的区域，而随着同族向下电子层增大，这一效应便消失了。第二电子亲和能总是吸热的（把电荷推到电荷上）——即[[bonding-structure/ionic-bonding]]中关于$\mathrm{O^{2-}}$的故事。
:::

::: definition 电负性与鲍林标度 {#def-en}
**电负性**$\chi$衡量**分子中**原子吸引成键电子的倾向。鲍林由键焓$D$（以eV计）定义了电负性之差：
$$
\chi_\mathrm{A} - \chi_\mathrm{B} = \sqrt{D(\mathrm{A{-}B}) - \sqrt{D(\mathrm{A{-}A})\,D(\mathrm{B{-}B})}}\,,
$$
即极性键相对于同核键平均值所多出的稳定性的平方根——部分电荷带来的静电红利。取定$\chi(\mathrm{H}) = 2.20$，就得到熟悉的标度：$\mathrm{F}\ 3.98$，$\mathrm{O}\ 3.44$，$\mathrm{Cl}\ 3.16$，$\mathrm{N}\ 3.04$，$\mathrm{C}\ 2.55$，$\mathrm{H}\ 2.20$，$\mathrm{Na}\ 0.93$，$\mathrm{Cs}\ 0.79$。电负性向上、向右增大，与$Z_\mathrm{eff}$除以尺寸的变化相一致。
:::

::: example 计算氯的鲍林电负性 {#ex-pauling-cl}
利用$D(\mathrm{H{-}H}) = 436$，$D(\mathrm{Cl{-}Cl}) = 243$，$D(\mathrm{H{-}Cl}) = 431\ \mathrm{kJ\,mol^{-1}}$，计算$\chi(\mathrm{Cl})$。
::: solution
换算为电子伏特（$1\ \mathrm{eV} = 96.485\ \mathrm{kJ\,mol^{-1}}$）：$D(\mathrm{H{-}H}) = 4.519$，$D(\mathrm{Cl{-}Cl}) = 2.519$，$D(\mathrm{H{-}Cl}) = 4.467\ \mathrm{eV}$。于是
$$
\chi(\mathrm{Cl}) - \chi(\mathrm{H}) = \sqrt{4.467 - \sqrt{4.519 \times 2.519}} = \sqrt{4.467 - 3.374} = \sqrt{1.093} = 1.05,
$$
所以$\chi(\mathrm{Cl}) = 2.20 + 1.05 = 3.25$（计算中保留未修约的值），与表列值$3.16$接近（残差取决于鲍林的后继者采用哪一套键焓数据和哪种平均方式）。用$D(\mathrm{F{-}F}) = 159$和$D(\mathrm{H{-}F}) = 567\ \mathrm{kJ\,mol^{-1}}$作同样的计算，得到$\chi(\mathrm{F}) = 3.97$——标度的最大值锚点。这个练习值得做一次，因为它表明电负性并不是什么神秘的性质：它就是重新整理过的键焓数据。
:::
:::

差值$\Delta\chi$可预测键的极性：**离子性百分数**可以很好地近似为$100\left[1 - \exp\!\left(-(\Delta\chi)^2/4\right)\right]$，由此得$\mathrm{C{-}H}$为$3\ \%$（$\Delta\chi = 0.35$），$\mathrm{O{-}H}$为$32\ \%$（$1.24$），$\mathrm{H{-}F}$为$55\ \%$（$1.78$）。这个公式是鲍林的经验内插，并非定律，可以用实验来检验。一个双原子分子若带电荷$\pm\delta e$、相距$r$，其偶极矩为$\mu = \delta e r$；同样键长下完全离子化的$\mathrm{H^+X^-}$的偶极矩为$\mu_\mathrm{ion} = e r$，即每$100\ \mathrm{pm}$为$4.803\ \mathrm{D}$。比值$\mu/\mu_\mathrm{ion}$就是测得的“离子性”。

不同原子之间的键没有纯粹共价的；[[bonding-structure/ionic-bonding]]的离子模型与[[bonding-structure/covalent-lewis]]的共价模型是同一连续谱的两端，主族化学就处在两者之间。

## 氧化态与惰性电子对

::: definition 氧化态 {#def-oxstate}
原子的**氧化态**是把它的化学键按离子方式分配之后——每个成键电子对归电负性较大的一方——留在它上面的电荷。它是一种记账手段，而不是测得的电荷（在$\mathrm{CO_2}$中碳形式上为$+4$，实际所带正电荷却很少），必须与把成键电子对平分的**形式电荷**相区别。对主族元素，最高氧化态等于价层$s + p$电子数：第1、2族即族序数，在IUPAC 1–18族编号中第13–17族为族序数减十（因此铝为$+3$，磷为$+5$，氯为$+7$）。对于较重的p区元素，常见的较低氧化态与这一最高值相差二。
:::

最后那一条——氧化态相差二——就是**惰性电子对效应**，它是较重p区元素化学的主导模式。

::: definition 惰性电子对效应 {#def-inert-pair}
在第13–15族中自上而下，比族价低二的**较低氧化态**变得越来越稳定：$\mathrm{Tl^+}$胜过$\mathrm{Tl^{3+}}$，$\mathrm{Pb^{2+}}$胜过$\mathrm{Pb^{4+}}$，$\mathrm{Bi^{3+}}$胜过$\mathrm{Bi^{5+}}$。这不是第17族的规律：碘(VII)比溴(VII)更稳定。“留在家里”的两个电子是$ns^2$电子对——即**惰性电子对**——它们越往下越不愿成键，因为$d$与$f$电子屏蔽差以及相对论收缩把$s$轨道拉向内侧（铊、铅、铋的$6s$电子对可测地被稳定化了），而$np$电子仍然可以参与成键。
:::

::: example 铅(II)与铅(IV) {#ex-lead}
$\mathrm{PbO}$在空气中稳定；$\mathrm{PbO_2}$是强氧化剂，$E^\circ(\mathrm{PbO_2,H^+/Pb^{2+}}) = +1.46\ \mathrm{V}$，一种经典的锰定性检验是把锰(II)溶液与$\mathrm{PbO_2}$在浓硝酸中煮沸，生成$\mathrm{MnO_4^-}$的紫色（$E^\circ(\mathrm{MnO_4^-/Mn^{2+}}) = +1.51\ \mathrm{V}$）。解释为什么铅(IV)是氧化剂，为什么尽管$1.46 < 1.51$该检验仍然有效，并预测锡的稳定氧化态。
::: solution
从$\mathrm{Pb(II)}$变为$\mathrm{Pb(IV)}$要移去$6s^2$电子对，因此代价是$IE_3 + IE_4$：铅约为$7160\ \mathrm{kJ\,mol^{-1}}$，锡约为$6870$。从锡到铅，这笔代价增加约$290\ \mathrm{kJ\,mol^{-1}}$，而本应偿还它的化学键却变得更长、更弱。因此$\mathrm{Pb(IV)}$化合物**想要**得到两个电子——它们是氧化剂——而$\mathrm{Pb(II)}$是稳定的归宿。锰检验的总反应为
$$
5\,\mathrm{PbO_2} + 2\,\mathrm{Mn^{2+}} + 4\,\mathrm{H^+} \rightarrow 5\,\mathrm{Pb^{2+}} + 2\,\mathrm{MnO_4^-} + 2\,\mathrm{H_2O},
$$
$E^\circ_\mathrm{cell} = 1.46 - 1.51 = -0.05\ \mathrm{V}$：在**标准**条件下略为不利。有两点挽救了它。反应消耗四个质子，所以浓酸推动它向前（能斯特项中含$[\mathrm{H^+}]^{-4}$）；而且肉眼只需极低浓度的深色$\mathrm{MnO_4^-}$即可察觉，所以很小的反应程度就够了。当两个电势如此接近时，由条件决定结果——绝不要把$0.05\ \mathrm{V}$的差值读成定论。锡位于铅之上：$\mathrm{Sn(IV)}$（如$\mathrm{SnO_2}$、$\mathrm{SnCl_4}$）是稳定态，$\mathrm{Sn^{2+}}$是温和的**还原剂**（$E^\circ(\mathrm{Sn^{4+}/Sn^{2+}}) = +0.15\ \mathrm{V}$，因此$\mathrm{SnCl_2}$能把$\mathrm{Fe^{3+}}$还原为$\mathrm{Fe^{2+}}$）。要带走的规则：在同一族中，最高氧化态的氧化能力自上而下**增强**，较低氧化态的还原能力**减弱**。
:::
:::

::: warning 惰性电子对是一种倾向，而非定律 {#warn-inert-pair}
人们很容易用单一原因来“解释”$\mathrm{Tl(I)}$的稳定性。实际上有两项同时变化。惰性电子对的代价$IE_2 + IE_3$，铝为$4562\ \mathrm{kJ\,mol^{-1}}$，铊为$4849\ \mathrm{kJ\,mol^{-1}}$：由于屏蔽差与相对论收缩，移去$6s$电子对要多花约$290\ \mathrm{kJ\,mol^{-1}}$。而必须偿还这笔代价的化学键更弱：气态$\mathrm{AlCl_3}$中$\mathrm{Al{-}Cl}$键的平均键焓约为$426\ \mathrm{kJ\,mol^{-1}}$（[[#ex-alcl-mean]]），而氯化铊(III)结合得如此之弱，以致稍加热就失去氯，不存在可靠的气相数值。较高的电离代价与较弱的化学键都有利于$\mathrm{Tl(I)}$。这一效应可以被压倒：$\mathrm{TlF_3}$存在（小而硬的氟离子形成强键），而$\mathrm{TlI_3}$实际上是$\mathrm{Tl^+(I_3^-)}$。用这一效应来排列稳定性，但绝不要据此宣称某个化合物不可能存在。
:::

## 对角线关系与第二周期的个性

::: definition 对角线关系 {#def-diagonal}
第1、2和13族中小而高电荷的第一个成员，与下一周期、右边一族的元素相似：**Li–Mg**、**Be–Al**、**B–Si**。原因在于离子势$z/r$。半径相近（$\mathrm{Li^+}\ 76\ \mathrm{pm}$，$\mathrm{Mg^{2+}}\ 72\ \mathrm{pm}$），但电荷不同：$\mathrm{Mg^{2+}}$的$z/r$约为$\mathrm{Li^+}$的两倍。相匹配的是高$z/r$所产生的**化学性质**——部分共价性、热不稳定性、相同的溶解度模式——而不是两个离子势在数值上相等。
:::

::: example 锂，镁的冒充者 {#ex-li-mg}
锂是唯一能与$\mathrm{N_2}$直接反应的碱金属（$\mathrm{6\,Li + N_2 \to 2\,Li_3N}$），其热力学产物是普通氧化物$\mathrm{Li_2O}$而不是过氧化物或超氧化物，其碳酸盐受热分解（$\mathrm{Li_2CO_3 \to Li_2O + CO_2}$），其氟化物、磷酸盐和碳酸盐都微溶。为什么？
::: solution
这些全都是镁的行为，而且每一条都源于离子势高的小阳离子。$\mathrm{Li^+}$只带一个电荷，但它如此之小，以致其极化能力接近$\mathrm{Mg^{2+}}$，并以同样的方式使$\mathrm{N^{3-}}$、$\mathrm{CO_3^{2-}}$等大阴离子变形。（它偏爱氧化物而不是过氧化物也是同一效应：小阳离子与小的$\mathrm{O^{2-}}$离子结合时获得的晶格能最多。）这些小阳离子盐的高晶格能压倒了水合项，使$\mathrm{LiF}$、$\mathrm{Li_3PO_4}$、$\mathrm{Li_2CO_3}$沉淀。同样的$z/r$逻辑使氢氧化铍像氢氧化铝一样具有两性，使硼酸像硅酸一样是弱含氧酸。对角线关系不是需要死记的巧合——它们是透过静电作用来解读的元素周期表。
:::
:::

p区的第二周期又有自己的个性，主要可追溯到极小的尺寸和紧凑的$2p$轨道。（这**不是**缺少$d$轨道的问题：正如[[main-group/main-group-bonding]]所表明的，较重元素其实也不使用它们的$d$轨道。）有三个反复出现的推论。第一，第二周期原子**很少形成四个以上的二中心键**：在$77\ \mathrm{pm}$的碳周围装不下更多配体，因此不存在与$\mathrm{SiF_6^{2-}}$对应的$\mathrm{CF_6^{2-}}$。当成键是多中心键时，确实会出现更高的配位：硼在二十面体硼烷和$\mathrm{B_{12}H_{12}^{2-}}$中是六配位的（五个硼近邻加一个氢），碳在碳硼烷中可达五或六个近邻。第二，它们形成**最强的$\pi$键**：碳的双键化学和氮$945\ \mathrm{kJ\,mol^{-1}}$的三键都建立在短程$2p$–$2p$重叠之上。第三，成链能力因元素而异：碳链无可匹敌，但氮链和氧链很弱（短的$\mathrm{N{-}N}$与$\mathrm{O{-}O}$键两端孤对电子相互排斥），因此硫的环和链（$\mathrm{S_8}$、多硫烷）远胜于氧。氮、氧和氟也是能形成强氢键的原子。元素概览各章的很大一部分，就是这些推论沿各族向下延续的故事。

## 后续内容

这里汇集的尺寸与能量数据贯穿以后的每一章：晶格焓与水合焓（[[bonding-structure/ionic-bonding]]中的玻恩-朗德与卡普斯钦斯基方法）决定了[[main-group/hydrogen-s-block]]中s区化合物的溶解度；$Z_\mathrm{eff}$与轨道尺寸决定了[[main-group/main-group-bonding]]中较重元素为何形成三中心键；中心原子的电负性决定了[[main-group/inorganic-acids-bases]]中含氧酸的强度；惰性电子对决定了[[main-group/inorganic-redox]]中哪些氧化态值得作图。量子力学背景——屏蔽、钻穿、$s$、$p$、$d$的能级次序——见[[general-chemistry-1/quantum-atom]]，我们所引用的循环的热化学见[[general-chemistry-1/thermochemistry]]。

::: history
周期系始于模式识别：门捷列夫（Mendeleev）1869年的周期表按原子量与化合价组织元素，并且——这是决定性的——留下了空位，还详细预言了填补空位的元素。物理解释等了半个世纪——莫塞莱（Moseley）1913年的X射线测量使原子**序数**成为排序变量，斯莱特（Slater）1930年的屏蔽规则则把$Z_\mathrm{eff}$变成了伏案即可完成的算术。鲍林（Pauling）1932年的电负性标度把键焓纳入了这幅图景，而现代的半径数据集——香农（Shannon）1976年的离子半径表、科尔德罗（Cordero）2008年的共价半径——是本章每一个预测背后默默无闻的经验基础设施。反常现象也不断出现：镧系收缩由戈尔德施密特（Victor Goldschmidt）于20世纪20年代命名，而定量完成惰性电子对故事所需的$6s$轨道相对论稳定化，直到20世纪后期才成为标准的教科书化学。
:::

::: summary
- 半径沿周期减小、沿族增大；在等电子系列中，尺寸只由核电荷决定，阳离子小，阴离子大。
- 斯莱特规则给出的$Z_\mathrm{eff}$沿周期的斜率为每个质子$0.65$：这是半径、电离能与电负性背后的引擎。
- 突破内层时电离能发生跃变——跃变确定族；B和O处的小凹陷揭示了亚层结构。
- 氯的电子亲和能胜过氟：加到氟紧凑的$n = 2$层上的电子承受更多排斥。由$\Delta\chi$估计的离子性百分数只是粗略的指引；偶极矩给出测量值。
- 电负性是重新整理过的键焓数据；$\Delta\chi$可估计键的极性，不同原子之间的键没有纯粹共价的。
- 主族元素的最高氧化态等于其价层$s + p$电子数（第13–17族为族序数 − 10）。惰性电子对效应使第13–15族中自上而下低二的氧化态趋于稳定：电离代价上升而键焓下降，因此最高氧化态沿族向下成为更强的氧化剂。
- 对角线关系（Li–Mg、Be–Al、B–Si）是极化能力的匹配；第二周期元素小、形成强$\pi$键、限于四个二中心键——原因在于尺寸，而不在于缺少$d$轨道。
:::

## 习题

::: exercise 等电子排序 {level=1}
把$\mathrm{N^{3-}}$、$\mathrm{O^{2-}}$、$\mathrm{F^-}$、$\mathrm{Na^+}$、$\mathrm{Mg^{2+}}$按离子半径从大到小排序，并说明所依据的原理。
::: solution
它们都与氖等电子（$10\ e^-$），因此半径随核电荷单调减小：$\mathrm{N^{3-}}\ (146) > \mathrm{O^{2-}}\ (140) > \mathrm{F^-}\ (133) > \mathrm{Na^+}\ (102) > \mathrm{Mg^{2+}}\ (72)\ \mathrm{pm}$（$\mathrm{N^{3-}}$的数值为四配位，其余为六配位）。电子数不变而$Z$增大：电子云被抓得越来越紧。
:::
:::

::: exercise 由电离能确定族 {level=1 check="2"}
某元素的电离能为$IE = 590,\ 1145,\ 4912,\ 6491\ \mathrm{kJ\,mol^{-1}}$。输入它的族序数。
::: solution
大的跃变出现在第二与第三级电离之间（$1145 \to 4912$，为$4.3$倍），所以有两个价电子：**第2族**（这些数值是钙的）。
:::
:::

::: exercise 哪个更大？ {level=1}
对每一对，指出哪个更大并说明理由：(a) $\mathrm{Cl^-}$或$\mathrm{Cl}$；(b) $\mathrm{Na^+}$或$\mathrm{Mg^{2+}}$；(c) $\mathrm{S^{2-}}$或$\mathrm{Se^{2-}}$。
::: solution
(a) $\mathrm{Cl^-}$（离子半径$181\ \mathrm{pm}$，原子的共价半径$99\ \mathrm{pm}$）：在核电荷不变的情况下，增加的电子使同层排斥增大。(b) $\mathrm{Na^+}$（$102$对$72\ \mathrm{pm}$）：两者等电子，而Mg多一个质子。(c) $\mathrm{Se^{2-}}$：同族向下增加了一个新电子层，内层的屏蔽几乎是完全的。
:::
:::

::: exercise 氯的斯莱特规则 {level=2 check="6.1"}
用斯莱特规则计算氯（$Z = 17$）一个$3p$电子的$Z_\mathrm{eff}$。（输入$Z_\mathrm{eff}$。）
::: solution
该$3p$电子看到同一$(3s, 3p)$组中$Z - 11 = 6$个其他电子，$n = 2$层中$8$个，$1s$中$2$个：$\sigma = 6(0.35) + 8(0.85) + 2(1.00) = 2.10 + 6.80 + 2.00 = 10.90$，因此$Z_\mathrm{eff} = 17 - 10.90 = 6.10$。与朴素的“17 − 10个内层电子 = 7”相比：斯莱特规则中内层的部分屏蔽使结果降低约一个单位。
:::
:::

::: exercise 氟的电负性 {level=2 check="3.97"}
利用$D(\mathrm{H{-}H}) = 436$，$D(\mathrm{F{-}F}) = 159$，$D(\mathrm{H{-}F}) = 567\ \mathrm{kJ\,mol^{-1}}$以及$\chi(\mathrm{H}) = 2.20$，计算氟的鲍林电负性。（输入$\chi(\mathrm{F})$，保留两位小数。）
::: solution
以eV计：$4.519$，$1.648$，$5.877$。于是$\chi(\mathrm{F}) - 2.20 = \sqrt{5.877 - \sqrt{4.519 \times 1.648}} = \sqrt{5.877 - 2.729} = \sqrt{3.148} = 1.774$，所以$\chi(\mathrm{F}) = 3.97$——在修约误差内与表列值$3.98$一致，而它只由三个键焓得出。
:::
:::

::: exercise 由偶极矩求离子性 {level=2 check="18.1"}
氯化氢的偶极矩$\mu = 1.109\ \mathrm{D}$，键长$127.5\ \mathrm{pm}$（$1\ \mathrm{D} = 3.336\times10^{-30}\ \mathrm{C\,m}$，$e = 1.602\times10^{-19}\ \mathrm{C}$）。计算离子性百分数$100\,\mu/(er)$，并与鲍林公式在$\Delta\chi = 0.96$时的结果比较。（输入由偶极矩求得的离子性百分数。）
::: solution
电荷完全分离时$\mu_\mathrm{ion} = er = (1.602\times10^{-19}\ \mathrm{C})(1.275\times10^{-10}\ \mathrm{m}) = 2.043\times10^{-29}\ \mathrm{C\,m} = 6.12\ \mathrm{D}$。于是$100 \times 1.109/6.12 = 18.1\ \%$。鲍林公式给出$100\left[1 - \exp(-0.96^2/4)\right] = 20.6\ \%$：两者接近，正如正文中的图对所有较重卤化氢所显示的那样。数据足以支持三位有效数字。
:::
:::

::: exercise Al–Cl键的平均键焓 {#ex-alcl-mean level=2 check="426"}
由$\Delta_\mathrm{f}H^\circ(\mathrm{AlCl_3,g}) = -584.6$，$\Delta_\mathrm{f}H^\circ(\mathrm{Al,g}) = +330.0$和$\Delta_\mathrm{f}H^\circ(\mathrm{Cl,g}) = +121.3\ \mathrm{kJ\,mol^{-1}}$（标准数据表，298 K），求气态单体$\mathrm{AlCl_3}$中$\mathrm{Al{-}Cl}$键的平均键焓。（以$\mathrm{kJ\,mol^{-1}}$为单位输入，保留三位有效数字。）
::: solution
原子化过程$\mathrm{AlCl_3(g)} \rightarrow \mathrm{Al(g)} + 3\,\mathrm{Cl(g)}$的
$$
\Delta_\mathrm{r}H^\circ = 330.0 + 3(121.3) - (-584.6) = 1278.5\ \mathrm{kJ\,mol^{-1}},
$$
这是三个$\mathrm{Al{-}Cl}$键的焓，因此平均值为$1278.5/3 = 426\ \mathrm{kJ\,mol^{-1}}$。注意参考状态：这是气相中的平面**单体**。固态氯化铝和$\mathrm{Al_2Cl_6}$二聚体含有桥连氯，每个键会给出不同的数值——务必核对表列平均键焓所指的是哪种物种。
:::
:::

::: exercise 铊的两副面孔 {level=2}
$\mathrm{TlCl_3}$是强氧化剂，加热时失去氯生成$\mathrm{TlCl}$，而$\mathrm{AlCl_3}$热稳定性很好。已知Al的$IE_2 + IE_3 = 4562\ \mathrm{kJ\,mol^{-1}}$，Tl的为$4849\ \mathrm{kJ\,mol^{-1}}$，并利用上一题的Al–Cl平均键焓，解释这一差别。
::: solution
账本的两边都在变化。移去惰性电子对，铊要多花约$290\ \mathrm{kJ\,mol^{-1}}$。偿还的是两个额外的$\mathrm{M{-}Cl}$键（气相中）或三价离子额外的晶格能（固相中），而对于大的铊原子，两者都更小：它与氯的键比铝的$426\ \mathrm{kJ\,mol^{-1}}$的键更长、更弱，盐的晶格能也随阳离子增大而降低。因此$\mathrm{Tl^{3+}}$把电子从氯离子那里夺回来，$\mathrm{Tl(I)}$胜出；而铝较低的电离代价和较强的化学键使天平倒向另一边。惰性电子对既是电离效应，也是键焓效应。
:::
:::

::: exercise 推导周期规律 {level=3 check="16"}
利用类氢表达式$IE \propto Z_\mathrm{eff}^2$（$n$固定），以及斯莱特规则给出的Li（$1.30$，$2s$电子）和F（$5.20$，$2p$电子）的$Z_\mathrm{eff}$，估计$IE_1(\mathrm{F})/IE_1(\mathrm{Li})$，并与实验值（$1681/520 = 3.23$）比较。模型为什么高估，什么能定性地修正它？（输入预测的比值。）
::: hint
先根据命题核对两个$Z_\mathrm{eff}$值：锂的$2s$电子被两个$1s$电子各以$0.85$屏蔽；氟的$2p$电子被六个其他$n = 2$电子各以$0.35$、两个$1s$电子各以$0.85$屏蔽。然后考虑**留下的**电子的能量会发生什么变化。
:::
::: solution
锂：$3 - 2(0.85) = 1.30$；氟：$9 - 6(0.35) - 2(0.85) = 5.20$。类氢比值为$(5.20/1.30)^2 = 16$，而观测值为$3.2$。模型之所以高估，是因为它把被移去的电子当作处于固定电荷$Z_\mathrm{eff}$场中的独立粒子。电离能实际上是原子与离子能量之差：当氟的七个$n = 2$电子之一离开时，其余六个失去了一个排斥伙伴，能量向下弛豫，这部分抵偿了电离的代价。同层电子越多，这种缓解越大，因此模型的高估沿周期增大（正文中的图对第3周期显示了同样的情况）。所以斯莱特规则是用于**排序与判断方向**的工具，而不是用于定量计算能量的——本章正是这样使用它们的。
:::
:::

::: exercise 实验室中的镧系收缩 {level=3}
锆和铪在每一种矿石中都共生，而且出了名地难以分离，而锆和钛（同族、上一周期）却很容易分离。离子半径：$\mathrm{Ti^{4+}}\ 60.5$，$\mathrm{Zr^{4+}}\ 72$，$\mathrm{Hf^{4+}}\ 71\ \mathrm{pm}$。用本章的知识解释这两个现象，预测$\mathrm{TiO_2}$和$\mathrm{ZrO_2}$哪个是碱性更强的氧化物，并说明同样的推理能否给$\mathrm{ZrO_2}$和$\mathrm{HfO_2}$排序。
::: hint
分离方法利用的是水合、配合物形成与溶解度上的差异，而这些都取决于电荷与半径。氧化物的碱性随阳离子极化能力（$z/r$）的增大而减弱。

::: solution
化学相似性取决于电荷与半径。$\mathrm{Zr^{4+}}$与$\mathrm{Hf^{4+}}$电荷相同，半径只差$1\ \mathrm{pm}$，因为在两者之间加入的十四个$4f$电子对多出的十四个质子屏蔽得如此之差（镧系收缩），以致预期的尺寸增长被抵消了。因此它们的水合能、配合物稳定性和盐的溶解度几乎相同，工业分离需要利用配合物形成上微小差异的多级溶剂萃取。$\mathrm{Ti^{4+}}$小$11.5\ \mathrm{pm}$，其化学差异足以直接分离。关于碱性：钛的$z/r$为$4/60.5 = 0.066$，锆的为$4/72 = 0.056\ \mathrm{pm^{-1}}$，所以$\mathrm{Ti^{4+}}$对氧离子的极化更强，$\mathrm{TiO_2}$是共价性更强、酸性更强（两性）的氧化物；**$\mathrm{ZrO_2}$的碱性更强**。至于锆与铪，半径论证给不出可用的答案：$1\ \mathrm{pm}$的差值处于半径本身的不确定度之内。氧化铪(IV)通常被描述为比氧化锆的碱性略**强**一点，这一差别来自简单的$z/r$模型无法分辨的成键细节——它提醒我们，规律论证在哪里不再提供信息。
