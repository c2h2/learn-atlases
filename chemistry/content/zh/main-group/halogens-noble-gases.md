第17族和第18族位于每个周期的末尾，但它们以截然相反的方式结束这个周期。卤素——氟、氯、溴、碘（以及放射性的砹）——比稀有气体构型少一个电子，是已知最活泼的元素之一；氟几乎与一切物质反应，包括玻璃、水，以及我们将会看到的氙。稀有气体——从氦到氡——已经具有这种构型，在七十年间被认为根本没有化学性质。本章表明，这两族受同一小组物理量支配：键焓（尤其是反常地弱的$\mathrm{F{-}F}$键）、电负性、标准电势背后的盖斯循环，以及[[main-group/main-group-bonding#prop-3c4e]]中的三中心四电子键，它既维系着三碘离子，也维系着二氟化氙。一路上我们会遇到漂白剂的化学、卤素含氧阴离子的化学，以及化学史上一个被推翻的重大教条。

## 作为单质的卤素

卤素以双原子分子$\mathrm{X_2}$的形式存在。它们的物理性质沿族向下平稳变化，唯一的例外是键焓：

| | $\mathrm{F_2}$ | $\mathrm{Cl_2}$ | $\mathrm{Br_2}$ | $\mathrm{I_2}$ |
|---|---|---|---|---|
| 25 °C时的状态与颜色 | 淡黄色气体 | 黄绿色气体 | 红棕色液体 | 有光泽的黑色固体，紫色蒸气 |
| 熔点 / 沸点 / °C | $-220$ / $-188$ | $-101$ / $-34$ | $-7$ / $59$ | $114$ / $184$ |
| $D(\mathrm{X{-}X})$ / $\mathrm{kJ\,mol^{-1}}$ | 159 | 243 | 193 | 151 |
| 电子亲和能（放出）/ $\mathrm{kJ\,mol^{-1}}$ | 328 | 349 | 325 | 295 |
| $\chi$（鲍林） | 3.98 | 3.16 | 2.96 | 2.66 |
| $r(\mathrm{X^-})$ / pm | 133 | 181 | 196 | 220 |
| $E^\circ(\mathrm{X_2/X^-})$ / V | $+2.87$ | $+1.36$ | $+1.09$ | $+0.54$ |

熔点和沸点的升高源于色散力随分子尺寸和极化率的增大而增强（[[bonding-structure/intermolecular-forces]]）。颜色来自电子从最高占据轨道（$\pi^*$）跃迁到最低未占轨道（$\sigma^*$）；这一能隙沿族向下变窄，因此吸收从氟的近紫外区，经过氯和溴的紫光和蓝光区，移到碘的黄绿光区，碘因而呈紫色。键焓从氯到碘按正常方式变化，因为键越长重叠越少——而氟远远落在这一趋势之下。$\mathrm{F{-}F}$键很短（$142\ \mathrm{pm}$），所以每个氟原子上的三对孤对电子与另一个氟原子上的孤对电子挤在一起，它们之间的排斥削弱了这个键。同样的效应也削弱了$\mathrm{O{-}O}$和$\mathrm{N{-}N}$单键（[[main-group/groups-15-16]]）。这带来一个重大后果：氟分子很容易断开，因而氟是最活泼的元素。

::: definition 作为热化学循环的标准电势 {#def-x-cycle}
电对$\mathrm{\tfrac12 X_2 / X^-(aq)}$的标准电势衡量由单质生成水合卤离子的吉布斯自由能，采用惯例值（$\mathrm{H^+(aq)} = 0$）时$E^\circ = -\Delta_\mathrm{f}G^\circ(\mathrm{X^-,aq})/F$。其焓的部分可以由经过气态物种的循环构建：
$$
\tfrac12\mathrm{X_2(std)} \xrightarrow{\ \Delta_\mathrm{at}H^\circ\ } \mathrm{X(g)} \xrightarrow{\ -E_\mathrm{ea}\ } \mathrm{X^-(g)} \xrightarrow{\ \Delta_\mathrm{hyd}H^\circ(\mathrm{X^-})\ } \mathrm{X^-(aq)},
$$
其中$\Delta_\mathrm{at}H^\circ$为键焓的一半（对溴和碘，还要加上从标准态出发的汽化焓或升华焓的一半），$E_\mathrm{ea}$是以放出能量表示的电子亲和能，水合焓采用同一惯例标度。比较两种卤素时，惯例会相互抵消。
:::

::: example 为什么氟是最强的氧化剂 {#ex-f-oxidant}
氯的电子亲和能更大，但氟却是强得多的氧化剂。利用下列数据（标准数据表，$298\ \mathrm{K}$，$\mathrm{kJ\,mol^{-1}}$），找出[[#def-x-cycle]]循环中起决定作用的步骤。

| | $\Delta_\mathrm{at}H^\circ$ | $E_\mathrm{ea}$ | $\Delta_\mathrm{f}H^\circ(\mathrm{X^-,aq})$ | $\Delta_\mathrm{f}G^\circ(\mathrm{X^-,aq})$ |
|---|---|---|---|---|
| F | 79.4 | 328.2 | $-332.6$ | $-278.8$ |
| Cl | 121.3 | 348.6 | $-167.2$ | $-131.2$ |
::: solution
**电势。** $E^\circ = -\Delta_\mathrm{f}G^\circ/F$：氟为$278\,800/96\,485 = 2.89\ \mathrm{V}$（表值为$2.87$，在数据精度范围内一致），氯为$131\,200/96\,485 = 1.36\ \mathrm{V}$。

**循环。** $\Delta_\mathrm{f}H^\circ(\mathrm{X^-,aq}) = \Delta_\mathrm{at}H^\circ - E_\mathrm{ea} + \Delta_\mathrm{hyd}H^\circ$。用氟减去氯：
$$
\underbrace{-165.4}_{\text{总计}} = \underbrace{-41.9}_{\text{原子化}} + \underbrace{+20.4}_{\text{电子亲和能}} + \Delta\Delta_\mathrm{hyd}H^\circ \quad\Rightarrow\quad \Delta\Delta_\mathrm{hyd}H^\circ = -143.9\ \mathrm{kJ\,mol^{-1}}.
$$
氟在电子亲和能上损失$20\ \mathrm{kJ\,mol^{-1}}$，从它的弱键上获得$42\ \mathrm{kJ\,mol^{-1}}$，并从其小阴离子的水合中获得$144\ \mathrm{kJ\,mol^{-1}}$——这是迄今最大的一项。（绝对水合焓，$\mathrm{F^-}$约为$-504$，$\mathrm{Cl^-}$约为$-361\ \mathrm{kJ\,mol^{-1}}$，给出相同的差值。）这与使锂成为水中最强还原剂的模式相同（[[main-group/hydrogen-s-block#ex-li-potential]]）：小离子水合强烈，而电势是水合离子的性质，而不是孤立原子的性质。在气相中，或在生成氟化物晶格的金属表面上，$\mathrm{F^-}$的小尺寸以同样的方式由大的晶格能得到回报。
:::
:::

电势的顺序就是置换的顺序：每种卤素都能氧化位于其下方的卤离子，$\mathrm{Cl_2 + 2\,Br^- \rightarrow 2\,Cl^- + Br_2}$，$\mathrm{Br_2 + 2\,I^- \rightarrow 2\,Br^- + I_2}$。氟的电势$2.87\ \mathrm{V}$远高于氧–水电对的$1.23\ \mathrm{V}$，因此氟会把水本身氧化为氧气，$\mathrm{F_2}$不可能有水溶液化学。

### 卤素的制备

每种卤素都是通过氧化其卤离子制得的，方法取决于这种氧化有多难。

- **氟**：没有任何化学氧化剂能在实用规模上由氟离子制得$\mathrm{F_2}$，而水溶液电解只会得到氧气。氟由无水熔盐$\mathrm{KF \cdot 2HF}$在约$70$–$100\ \mathrm{^\circ C}$下电解制得，使用碳阳极和由钝化氟化物膜保护的钢或蒙乃尔合金容器——这正是莫瓦桑在1886年首次成功的方法。
- **氯**：盐水的氯碱电解（[[main-group/hydrogen-s-block]]）。在这里，阳极必须使氯离子的氧化（$1.36\ \mathrm{V}$）优先于水的氧化（pH 0时为$1.23\ \mathrm{V}$，在中性盐水中更低），而它之所以能做到，只是因为在所用的涂层钛阳极上析氧的超电势更大——这是对产物的动力学选择，与[[main-group/groups-15-16#ex-ostwald]]中的奥斯特瓦尔德法相同。
- **溴**：取自富含溴离子的卤水和海水（含溴离子约$65\ \mathrm{mg\,dm^{-3}}$），用氯氧化，$\mathrm{Cl_2 + 2\,Br^- \rightarrow 2\,Cl^- + Br_2}$，再用水蒸气或空气吹出挥发性的溴。
- **碘**：取自与天然气井和油井伴生的卤水，同样通过氧化碘离子；也取自智利硝石矿床中所含的碘酸盐，通过还原（用亚硫酸氢盐把$\mathrm{IO_3^-}$还原为$\mathrm{I_2}$）。

这些单质都有危险。氟和氯是剧毒、腐蚀性气体（GHS06、GHS05；氯作为氧化剂还标有GHS03）；溴是挥发性、强腐蚀性的液体，会造成严重灼伤并产生有毒蒸气；所有这些都只能在通风橱中、在适当防护下操作，而涉及氟的工作需要专门的装置和培训。氟化氢和氢氟酸格外危险，因为氟离子会渗透皮肤并结合人体内的钙；即使是小面积灼伤也需要专门的急救和医疗处理。作为酸的卤化氢，以及HF为何是弱酸，已在[[main-group/inorganic-acids-bases#ex-hf-weak]]中讨论过。

## 卤素互化物与多卤化物

卤素彼此化合，生成**卤素互化物**$\mathrm{XY}_n$，其中X是较重（电负性较小）的卤素，Y是较轻的卤素。

::: definition 卤素互化物 {#def-interhalogen}
中性卤素互化物的化学式为$\mathrm{XY}$、$\mathrm{XY_3}$、$\mathrm{XY_5}$和$\mathrm{XY_7}$——Y原子数总是**奇数**，从而分子具有偶数个电子，没有未成对自旋。已知的化合物有：$\mathrm{ClF}$、$\mathrm{BrF}$、$\mathrm{IF}$、$\mathrm{BrCl}$、$\mathrm{ICl}$、$\mathrm{IBr}$；$\mathrm{ClF_3}$、$\mathrm{BrF_3}$、$\mathrm{IF_3}$、$\mathrm{I_2Cl_6}$（$\mathrm{ICl_3}$的二聚体）；$\mathrm{ClF_5}$、$\mathrm{BrF_5}$、$\mathrm{IF_5}$；以及$\mathrm{IF_7}$（BrF、IF和$\mathrm{IF_3}$除在低温下外都会分解或歧化）。中心原子总是较重的卤素，最高的配位数只有在最大的中心原子周围配以氟时才能达到。它们的形状正如价层电子对互斥理论所预测：$\mathrm{XY_3}$为T形（$\mathrm{AX_3E_2}$），$\mathrm{XY_5}$为四方锥形（$\mathrm{AX_5E}$），$\mathrm{IF_7}$为五角双锥形（$\mathrm{AX_7}$）。
:::

有两个因素决定哪些化合物能够存在。**尺寸**：要在中心原子周围容纳七个配体，需要大的中心原子和小的配体，所以只有碘能结合七个配体，而且只能是氟；氯最多结合五个氟，并且氯从不作为较大卤素的中心原子。**电负性**：超价分子中的键是三中心四电子键，它把负电荷放在外围原子上（[[main-group/main-group-bonding#prop-3c4e]]），这适合把电负性最大的配体氟放在电正性最强的中心原子碘周围。卤素互化物一般比卤素本身更活泼（$\mathrm{F_2}$除外），因为它们极性的$\mathrm{X^{\delta+}{-}Y^{\delta-}}$键为进攻试剂提供了一个亲电中心，而非极性的$\mathrm{X{-}X}$键没有。三氟化氯是已知最猛烈的氟化剂之一：它能点燃许多材料，包括一些通常被认为不可燃的材料，只由专业人员操作。

::: example 三氟化氯的形状 {#ex-clf3}
预测$\mathrm{ClF_3}$的形状，并解释为什么它的两个轴向$\mathrm{Cl{-}F}$键（$170\ \mathrm{pm}$）比赤道$\mathrm{Cl{-}F}$键（$160\ \mathrm{pm}$）长，以及为什么$\mathrm{F_{ax}{-}Cl{-}F_{eq}}$键角是$87.5^\circ$而不是$90^\circ$。
::: solution
氯为中心原子的电子计数贡献七个价电子，每个氟贡献一个：$7 + 3 = 10$个电子，五对，电子对呈三角双锥排布（[[bonding-structure/vsepr]]）。三对成键，两对为孤对电子；孤对电子占据赤道位置，在那里它们只有两个而不是三个$90^\circ$的相邻电子对。因此分子是**T形**的：一个赤道氟和两个轴向氟。从成键角度看，赤道$\mathrm{Cl{-}F}$键是普通的二中心二电子键，而两个轴向氟共用氯的一个$p$轨道，形成线形的$\mathrm{F{-}Cl{-}F}$三中心四电子键——每个连接的键级为$\tfrac12$，因此更长、更弱。轴向氟原子略微**偏离**赤道上的孤对电子（孤对电子比成键电子对占据更多空间），使它们与赤道氟之间的夹角缩小到$87.5^\circ$。同样的分析给出$\mathrm{BrF_3}$的T形以及$\mathrm{BrF_5}$的四方锥形（一对孤对电子，$\mathrm{AX_5E}$），其底面上的氟原子略微向锥顶弯曲，远离孤对电子。
:::
:::

### 多卤离子

卤离子与卤素分子加合形成**多卤**阴离子。最著名的是三碘离子，它在碘溶于碘化钾溶液时生成：
$$
\mathrm{I_2(aq) + I^-(aq) \rightleftharpoons I_3^-(aq)}, \qquad K \approx 7.0\times10^{2}\ \text{（}25\ \mathrm{^\circ C}\text{时）}.
$$
$\mathrm{I_3^-}$是线形的，沿$\mathrm{I{-}I{-}I}$轴有一个三中心四电子键，其价层与$\mathrm{XeF_2}$和$\mathrm{ICl_2^-}$等电子。这个平衡解释了为什么实验室中的“碘溶液”是碘的碘化钾溶液：单质碘在水中的溶解度只有约$1.3\times10^{-3}\ \mathrm{mol\,dm^{-3}}$。它也是产生淀粉–碘蓝色的物种——多碘链穿入直链淀粉的螺旋中——这一颜色被用作碘量法的终点（[[main-group/groups-15-16#ex-iodometry]]）。多卤化物盐遵循[[main-group/hydrogen-s-block#prop-size-matching]]的尺寸匹配原理：$\mathrm{I_3^-}$这样的大阴离子与大阳离子形成稳定的固体盐（$\mathrm{CsI_3}$、$\mathrm{[NR_4]I_3}$），而$\mathrm{Na^+}$这样的小阳离子得不到稳定的不含溶剂的三碘化物盐。

有些卤素互化物是[[main-group/inorganic-acids-bases#def-autoionization]]意义上的自电离溶剂：液态三氟化溴通过$\mathrm{2\,BrF_3 \rightleftharpoons [BrF_2]^+ + [BrF_4]^-}$导电，因此在其中，氟离子给予体是碱，氟离子接受体是酸。

::: quiz
下列哪个卤素互化物化学式**不是**已知中性化合物的化学式？
- [ ] $\mathrm{BrF_5}$
- [ ] $\mathrm{IF_7}$
- [x] $\mathrm{ClF_4}$
- [ ] $\mathrm{ICl}$
::: solution
中性卤素互化物的端基原子数为奇数，即$\mathrm{XY}_n$中$n = 1, 3, 5, 7$，从而所有电子都成对；$\mathrm{ClF_4}$将是一个具有奇数个电子的自由基。离子$\mathrm{[ClF_4]^-}$（平面正方形）和$\mathrm{[ClF_4]^+}$确实存在，因为加上或移去一个电子恢复了偶数电子数。$\mathrm{BrF_5}$、$\mathrm{IF_7}$和$\mathrm{ICl}$都是已知的。
:::

## 卤素的含氧酸与含氧阴离子

氯、溴和碘形成氧化态为$+1$、$+3$、$+5$和$+7$的含氧酸（氟只形成不稳定的$\mathrm{HOF}$）。对氯而言：

| 氧化态 | 酸 | 阴离子 | $\mathrm{p}K_\mathrm{a}$ | 阴离子的形状 |
|---|---|---|---|---|
| $+1$ | 次氯酸 $\mathrm{HOCl}$ | 次氯酸根 $\mathrm{OCl^-}$ | 7.5 | — |
| $+3$ | 亚氯酸 $\mathrm{HClO_2}$ | 亚氯酸根 $\mathrm{ClO_2^-}$ | 2.0 | 角形 |
| $+5$ | 氯酸 $\mathrm{HClO_3}$ | 氯酸根 $\mathrm{ClO_3^-}$ | 强酸 | 三角锥形 |
| $+7$ | 高氯酸 $\mathrm{HClO_4}$ | 高氯酸根 $\mathrm{ClO_4^-}$ | 强酸 | 四面体形 |

它们的酸强度已在[[main-group/inorganic-acids-bases#ex-chlorine-oxoacids]]中由鲍林规则推出。这里我们考察它们的氧化还原化学，这才是实际兴趣所在：氯漂白剂、二氧化氯和高氯酸盐都是它的产物。

氯在酸性（pH 0）和碱性（pH 14）溶液中的拉蒂默行（单位为伏特）为
$$
\text{酸性：}\quad \mathrm{ClO_4^-} \xrightarrow{\,1.20\,} \mathrm{ClO_3^-} \xrightarrow{\,1.19\,} \mathrm{HClO_2} \xrightarrow{\,1.64\,} \mathrm{HOCl} \xrightarrow{\,1.63\,} \mathrm{Cl_2} \xrightarrow{\,1.36\,} \mathrm{Cl^-}
$$
$$
\text{碱性：}\quad \mathrm{ClO_4^-} \xrightarrow{\,0.37\,} \mathrm{ClO_3^-} \xrightarrow{\,0.30\,} \mathrm{ClO_2^-} \xrightarrow{\,0.68\,} \mathrm{ClO^-} \xrightarrow{\,0.42\,} \mathrm{Cl_2} \xrightarrow{\,1.36\,} \mathrm{Cl^-}
$$
$\mathrm{Cl_2/Cl^-}$电对不含$\mathrm{H^+}$，在两种条件下相同；其余电对都涉及氧，因而涉及质子，从pH 0到pH 14它们下降约$0.8$–$1.2\ \mathrm{V}$。

::: proposition 卤素在碱中的歧化 {#prop-x-disprop}
当
$$
E^\circ_\mathrm{acid}(\mathrm{HOX/X_2}) > E^\circ(\mathrm{X_2/X^-}) > E^\circ_\mathrm{base}(\mathrm{OX^-/X_2})
$$
时，卤素$\mathrm{X_2}$在酸中对歧化为$\mathrm{X^-}$和$\mathrm{HOX}$是稳定的，而在碱中则歧化为$\mathrm{X^-}$和$\mathrm{OX^-}$。对氯而言，$1.63 > 1.36 > 0.42\ \mathrm{V}$，所以$\mathrm{Cl_2 + 2\,OH^- \rightarrow Cl^- + OCl^- + H_2O}$基本上进行完全，而在酸中有利的是逆反应（归中）。溴和碘也是如此。这些是关于平衡的陈述；反应速率以及$\mathrm{OX^-}$进一步歧化为$\mathrm{XO_3^-}$，取决于温度和卤素种类。
:::

::: proof 两次应用歧化判据
根据[[main-group/inorganic-redox#prop-disproportionation]]的歧化判据，当拉蒂默行中某中间物种右侧的电势超过其左侧的电势时，该物种发生歧化。$\mathrm{X_2}$是介于$\mathrm{X^-}$（右侧，电势$E^\circ(\mathrm{X_2/X^-})$）与$+1$价物种（左侧）之间的中间体。在酸中，左侧电势$E^\circ(\mathrm{HOX/X_2})$较大，所以$\mathrm{X_2}$稳定；在碱中，左侧电势为$E^\circ(\mathrm{OX^-/X_2})$，若它小于$E^\circ(\mathrm{X_2/X^-})$，则$\mathrm{X_2}$歧化。卤离子电对与pH无关，而含氧电对每个pH单位下降约$0.059\ \mathrm{V}$（跨过该酸的$\mathrm{p}K_\mathrm{a}$时下降更多），因此在两个极端之间必定存在一个交叉pH。
:::

::: example 漂白剂：制备与保存 {#ex-bleach}
家用漂白剂是把氯气通入冷的氢氧化钠溶液制得的。(a) 写出反应式，求$298\ \mathrm{K}$下的$E^\circ_\mathrm{cell}$和$\log K$。(b) 解释为什么漂白剂绝不能与酸性清洁剂混合。(c) 解释为什么热碱液得到的是氯酸盐而不是次氯酸盐。
::: solution
(a) $\mathrm{Cl_2 + 2\,OH^- \rightarrow Cl^- + OCl^- + H_2O}$。还原半反应为$\mathrm{Cl_2/Cl^-}$（$1.36\ \mathrm{V}$），氧化半反应为碱中$\mathrm{OCl^-/Cl_2}$（$0.42\ \mathrm{V}$）的逆反应，每个氯原子转移一个电子：$E^\circ_\mathrm{cell} = 1.36 - 0.42 = 0.94\ \mathrm{V}$，$\log K = 0.94/0.0592 = 15.9$。反应进行完全。(b) 在酸中电势的大小顺序颠倒（$1.63 > 1.36$），所以次氯酸根与氯离子**归中**回到氯：$\mathrm{OCl^- + Cl^- + 2\,H^+ \rightarrow Cl_2 + H_2O}$。氯气被放出——这是家庭中毒的常见原因，已在[[main-group/inorganic-redox]]中定量分析过。（对$1\ \mathrm{bar}$的气态$\mathrm{Cl_2}$，水解常数$K = [\mathrm{HOCl}][\mathrm{H^+}][\mathrm{Cl^-}]/p(\mathrm{Cl_2})$为$10^{(1.36 - 1.63)/0.0592} \approx 3\times10^{-5}$；以溶解的$\mathrm{Cl_2}$计，约为$4\times10^{-4}$。）(c) 次氯酸根本身对于生成氯离子和氯酸根在热力学上是不稳定的，$\mathrm{3\,OCl^- \rightarrow ClO_3^- + 2\,Cl^-}$（[[#exr-chlorate]]），但该反应在室温下很慢。加热使其加速，所以氯在热碱液中总体上生成氯酸盐，$\mathrm{3\,Cl_2 + 6\,OH^- \rightarrow ClO_3^- + 5\,Cl^- + 3\,H_2O}$——这是制备氯酸盐的传统途径。因此商品漂白剂需低温保存，保质期有限。
:::
:::

**二氧化氯**$\mathrm{ClO_2}$是一个奇电子分子（19个价电子），与$\mathrm{NO_2}$不同，它不二聚。它由氯酸盐在现场制备，是木浆的主要漂白剂，取代了单质氯，以减少氯代有机副产物的生成；它在浓时会爆炸，总是以稀的气体或溶液形式处理。**高氯酸根**是这一系列中的悖论：它位于酸性弗罗斯特图的顶端，在热力学上是表中最强的氧化剂之一，但稀的高氯酸盐溶液在室温下是惰性的，因此高氯酸根在电化学中被用作“不配位、不反应”的阴离子。这种惰性是动力学上的——氯被埋在由氧原子构成的四面体内部，没有可供还原剂进攻的孤对电子或低能空轨道。然而，热的浓高氯酸以及与有机物或还原剂接触的固体高氯酸盐可能发生爆炸性反应；它们被归类为氧化剂（GHS03），需要特别的防护措施。高氯酸盐也是某些饮用水源中的环境污染物，它会干扰甲状腺对碘离子的摄取。

溴和碘形成类似的系列，但有两点不同。溴(VII)态，即高溴酸根，直到1968年才被制得，它是比高氯酸根或高碘酸根更强的氧化剂——这是紧接$3d$系列之后的元素出现不规则性的一个例子（[[main-group/periodic-trends#ex-ga-al]]）。而碘由于更大，与氧能达到更高的配位数：常见的高碘酸不是$\mathrm{HIO_4}$，而是正高碘酸$\mathrm{H_5IO_6}$，六个氧以八面体方式围绕碘，正如碲给出$\mathrm{Te(OH)_6}$，而硫和硒给出四面体形的酸。高碘酸盐在有机化学中用于断裂1,2-二醇，碘酸盐是碘量分析中的基准物质。

## 稀有气体

稀有气体发现得晚，因为它们什么都不做：它们先是作为密度上的反常、后来作为光谱中无法解释的谱线而被发现。

::: example 瑞利的氩 {#ex-rayleigh}
1894年，瑞利勋爵发现，一个充满“大气氮”（除去氧、水和二氧化碳后的空气）的玻璃球容纳$2.3102\ \mathrm{g}$气体，而同一个球充满由亚硝酸铵或其他化合物化学制得的氮时容纳$2.2990\ \mathrm{g}$。假设多出的质量来自氩（$M = 39.95$，而$\mathrm{N_2}$为$28.013\ \mathrm{g\,mol^{-1}}$），估算大气氮中氩的摩尔分数，并与现代空气组成（按体积$\mathrm{N_2}$ $78.08\ \%$，Ar $0.934\ \%$）比较。
::: solution
在相同的温度、压力和体积下，两次充气的气体物质的量相同（阿伏加德罗原理），所以质量之比等于平均摩尔质量之比：$2.3102/2.2990 = 1.004872$。若氩以摩尔分数$f$与氮混合，相对于氮的平均摩尔质量为$(1 - f) + f(39.95/28.013) = 1 + 0.42612f$。令其等于$1.004872$，得$f = 0.004872/0.42612 = 0.0114$，即$1.14\ \%$。现代数据中，氩在空气的氮–氩部分中占$0.934/(78.08 + 0.934) = 1.18\ \%$；瑞利测得的半个百分点的质量差（精确到克的小数点后四位）就足以找到一种元素。（氖、氦、氪和氙也存在，但它们合起来不到空气的$0.003\ \%$。）
:::

### 稀有气体化合物

电离能沿族向下稳步降低，到氙时其值$1170\ \mathrm{kJ\,mol^{-1}}$已不大于许多经常被氧化的分子的电离能。这一观察就是巴特利特发现的全部内容。

::: widget plot

caption: 从氖（$x = 2$，第2周期）到氡（$x = 6$）的稀有气体第一电离能（单位$\mathrm{kJ\,mol^{-1}}$；氦为2372，超出图示范围），与$\mathrm{O_2}$分子的电离能（水平线）相比较。1962年，巴特利特刚刚证明六氟化铂能把$\mathrm{O_2}$氧化为$\mathrm{O_2^+[PtF_6]^-}$。氙的电离能$1170$与氧的相差不到$5\ \mathrm{kJ\,mol^{-1}}$，因此他推断$\mathrm{PtF_6}$也应能氧化氙——结果确实如此。氪比这条线高$186\ \mathrm{kJ\,mol^{-1}}$，不被$\mathrm{PtF_6}$氧化；氩和氖远在其上。氡位于氙之下，更为活泼，但其放射性使它的化学研究仅限于示踪研究。
:::

巴特利特的产物最初被写作$\mathrm{Xe^+[PtF_6]^-}$，后来发现是含有$\mathrm{[XeF]^+}$盐的更复杂的混合物，但它确立了氙具有化学性质。数月之内，人们通过加热或辐照氙–氟混合物，由单质直接制得了氙的氟化物：$\mathrm{XeF_2}$、$\mathrm{XeF_4}$和$\mathrm{XeF_6}$，产物取决于氟的比例和压力。

::: example 氙的氟化物的结构 {#ex-xef}
预测$\mathrm{XeF_2}$、$\mathrm{XeF_4}$和$\mathrm{XeF_6}$的形状，并在不使用$d$轨道的情况下描述$\mathrm{XeF_2}$和$\mathrm{XeF_4}$的成键。
::: solution
**价层电子对互斥理论。** 氙有八个价电子。$\mathrm{XeF_2}$：$8 + 2 = 10$个电子，五对，两对成键：$\mathrm{AX_2E_3}$，三对孤对电子位于三角双锥的赤道位置，所以分子是**线形**的。$\mathrm{XeF_4}$：$8 + 4 = 12$个电子，六对，四对成键：$\mathrm{AX_4E_2}$，两对孤对电子在八面体上处于**反式**位置，所以分子是**平面正方形**的。$\mathrm{XeF_6}$：$8 + 6 = 14$个电子，七对，六对成键：$\mathrm{AX_6E}$，价层电子对互斥理论预测其为**畸变八面体**；在气相中它确实不是正八面体，而且畸变是流变性的（孤对电子在各个面之间移动），而固体中含有$\mathrm{[XeF_5]^+}$和$\mathrm{F^-}$单元。

**成键。** 在$\mathrm{XeF_2}$中，氙的一个$5p$轨道与指向它的两个氟轨道形成线形的三中心四电子键（[[main-group/main-group-bonding#prop-3c4e]]）：一对成键电子离域于$\mathrm{F{-}Xe{-}F}$上，一对非键电子位于氟原子上，每个$\mathrm{Xe{-}F}$连接的键级为$\tfrac12$，每个氟带部分负电荷。$\mathrm{XeF_4}$用两个相互垂直的$5p$轨道形成两个这样的键，给出平面正方形。这个模型解释了为什么只有电负性最大的配体（F，以及氧化物和氟氧化物中的O）能稳定氙的化合物：三中心键把负电荷放在外围原子上。维系$\mathrm{I_3^-}$的也是同一个模型，$\mathrm{XeF_2}$与之价层等电子。
:::
:::

::: warning “惰性”是一项测量结果，而不是一条定律 {#warn-inert}
在被发现后的七十年里，稀有气体一直被称为“惰性气体”，八隅律被当作充满的$s^2p^6$壳层禁止成键来讲授。曾有几位化学家提出异议——鲍林在1933年预言氙的氟化物和含氧酸应当存在——但早期的尝试失败了，这一信念变得根深蒂固。1962年的教训不是八隅律错了，而是它是一个关于能量的陈述，而能量是可以比较的：氙的电离能与氧的相当，而氟的弱键以及它与其他原子形成的强键使氟化反应放热。$\mathrm{Xe{-}F}$的平均键焓只有约$130\ \mathrm{kJ\,mol^{-1}}$，但这仍超过$\mathrm{F{-}F}$键焓的一半，而这就是所需的全部条件。2000年，氩也证明了同样的事情：人们在极低温度下的固体氩基质中制得了HArF——“惰性”与“活泼”的界线取决于人们观察得多仔细，也取决于温度。
:::

氙的氟化物水解生成氧化合物。$\mathrm{XeF_6}$与水反应生成三氧化氙，$\mathrm{XeF_6 + 3\,H_2O \rightarrow XeO_3 + 6\,HF}$；$\mathrm{XeO_3}$是强吸热化合物，干燥时会爆炸，因此只由专业人员在稀溶液中处理。在碱中，氙(VI)歧化为氙和高氙酸根$\mathrm{[XeO_6]^{4-}}$，其中氙为$+8$价——这是水溶液中已知最强的氧化剂之一。氪形成$\mathrm{KrF_2}$，这是一种热力学上不稳定但可以分离的化合物，也是最强的氧化性氟化剂之一。稀有气体化学如今是主族化学中一个规模虽小但已确立的分支，遵循着与其余部分完全相同的规则。

## 后续内容

卤素几乎出现在其他每一门课程中：在[[organic-1/nucleophilic-substitution]]和[[organic-1/radical-reactions]]中作为离去基团和参与卤化反应，在[[coordination-chemistry/inorganic-mechanisms]]中作为配体并体现反位效应，在[[green-chemistry/industrial-inorganic]]的氯碱工业和氟工业中，以及在破坏平流层臭氧的氯和溴催化循环中，后者在[[environmental-chemistry/stratospheric-ozone]]中讨论。持久性有机卤素污染物是[[environmental-chemistry/pollutants-fate]]的主题。用以解释卤素互化物、三碘离子和氙的氟化物的三中心成键是在[[main-group/main-group-bonding]]中建立的，而用于氯含氧阴离子的电势图则来自[[main-group/inorganic-redox]]。本章完成了对主族元素的概览；d区——在那里部分填充的$d$壳层带来了颜色、磁性和一种新的成键方式——是[[coordination-chemistry/coordination-compounds]]的主题。

::: history
舍勒（Carl Wilhelm Scheele）于1774年用盐酸与二氧化锰共热制得了氯，但把它当作一种含氧的化合物；戴维（Humphry Davy）于1810年证明它是一种元素，并根据希腊语中“淡绿色”一词为之命名。碘由库尔图瓦（Bernard Courtois）于1811年在海藻灰中发现，溴由巴拉尔（Antoine Jérôme Balard）于1826年在蒙彼利埃制盐的残液中发现（勒维希（Carl Löwig）大约同时独立分离出了溴）。氟在19世纪的大部分时间里都未能被分离出来，好几位尝试者因此受伤，直到莫瓦桑（Henri Moissan）于1886年在低温下电解溶于无水氟化氢的氟化钾而得到它；他获得了1906年诺贝尔化学奖。瑞利勋爵（Lord Rayleigh）和拉姆齐（William Ramsay）于1894年宣布发现氩（瑞利获得1904年诺贝尔物理学奖，拉姆齐获得同年的诺贝尔化学奖）；拉姆齐于1895年鉴定了地球上的氦，并与特拉弗斯（Morris Travers）于1898年发现了氖、氪和氙。不列颠哥伦比亚大学的巴特利特（Neil Bartlett）于1962年制得了第一个稀有气体化合物；同年，阿贡国家实验室的克拉森（Howard Claassen）、塞利格（Henry Selig）和马姆（John Malm）报道了四氟化氙，德国霍佩（Rudolf Hoppe）的研究组报道了二氟化氙。2000年，赫尔辛基的雷萨宁（Markku Räsänen）研究组制得了第一个中性氩化合物HArF。
:::

::: summary
- 卤素的性质沿族向下平稳变化，唯有键焓例外：$\mathrm{F{-}F}$键（$159\ \mathrm{kJ\,mol^{-1}}$）弱，原因是短键两端孤对电子之间的排斥。
- 尽管氯的电子亲和能更大，氟却是水中最强的氧化剂（$2.87\ \mathrm{V}$），因为它的弱键，尤其是小的$\mathrm{F^-}$离子的大水合焓，在盖斯循环中胜出；氟能氧化水，必须通过电解熔融氟化物制备。
- 卤素互化物$\mathrm{XY}_n$中$n$为奇数，较重的卤素居中，形状符合价层电子对互斥理论（T形的$\mathrm{XY_3}$、四方锥形的$\mathrm{XY_5}$、五角双锥形的$\mathrm{IF_7}$）；$\mathrm{I_3^-}$和$\mathrm{ClF_3}$的轴向键都是三中心四电子键。
- 卤素在酸中稳定，在碱中歧化（对氯，$1.63 > 1.36 > 0.42\ \mathrm{V}$）：这就是漂白剂的制法，也说明了漂白剂为何不能遇酸、热碱液为何生成氯酸盐。
- 卤素含氧阴离子在酸中是强氧化剂，在碱中较温和；高氯酸根在热力学上很强，但在动力学上惰性；碘的大尺寸使它形成八面体形的$\mathrm{H_5IO_6}$。
- 稀有气体的反应性随电离能降低而增大：巴特利特把氙（$1170$）与$\mathrm{O_2}$（$1165\ \mathrm{kJ\,mol^{-1}}$）相比较，从而得到了第一个氙化合物；$\mathrm{XeF_2}$（线形）、$\mathrm{XeF_4}$（平面正方形）和$\mathrm{XeF_6}$（畸变八面体）都符合价层电子对互斥理论和三中心成键。
:::

::: exercise 氟的电势 {level=1 check="2.89"}
由$\Delta_\mathrm{f}G^\circ(\mathrm{F^-,aq}) = -278.8\ \mathrm{kJ\,mol^{-1}}$（$F = 96\,485\ \mathrm{C\,mol^{-1}}$）计算$E^\circ(\mathrm{F_2/F^-})$，并解释为什么不能通过电解氟化钠水溶液制备氟。（以伏特为单位输入$E^\circ$，保留三位有效数字。）
::: solution
对于相对于氢电极的$\mathrm{\tfrac12 F_2 + e^- \rightarrow F^-}$，$\Delta_\mathrm{r}G^\circ = \Delta_\mathrm{f}G^\circ(\mathrm{F^-,aq}) = -FE^\circ$，所以$E^\circ = 278\,800/96\,485 = 2.89\ \mathrm{V}$（数据表给出$2.87$，所用数据略有不同）。在水溶液中的阳极上，水在$1.23\ \mathrm{V}$（中性溶液中更低）被氧化为氧气，远低于$2.87\ \mathrm{V}$；而且即使生成了氟，它也会氧化水。电解氟化物水溶液得到的是氧气，而不是氟。

由$\Delta_\mathrm{at}H^\circ$（$\mathrm{Cl}$ $121.3$，$\mathrm{Br}$ $111.9\ \mathrm{kJ\,mol^{-1}}$，分别从标准态$\mathrm{Cl_2(g)}$和$\mathrm{Br_2(l)}$出发）、电子亲和能（放出$348.6$、$324.5\ \mathrm{kJ\,mol^{-1}}$）和$\Delta_\mathrm{f}H^\circ(\mathrm{X^-,aq})$（$-167.2$、$-121.6\ \mathrm{kJ\,mol^{-1}}$），求$\Delta_\mathrm{hyd}H^\circ(\mathrm{Br^-}) - \Delta_\mathrm{hyd}H^\circ(\mathrm{Cl^-})$。哪一项对使氯成为更强的氧化剂贡献最大？（以$\mathrm{kJ\,mol^{-1}}$为单位输入差值，保留一位小数。）
::: solution
利用$\Delta_\mathrm{f}H^\circ(\mathrm{X^-,aq}) = \Delta_\mathrm{at}H^\circ - E_\mathrm{ea} + \Delta_\mathrm{hyd}H^\circ$，用溴减去氯：$45.6 = -9.4 + 24.1 + \Delta\Delta_\mathrm{hyd}H^\circ$，所以$\Delta\Delta_\mathrm{hyd}H^\circ = +30.9\ \mathrm{kJ\,mol^{-1}}$：溴离子的水合放热少$31\ \mathrm{kJ\,mol^{-1}}$。氯的循环比溴的多放热$45.6\ \mathrm{kJ\,mol^{-1}}$，其中水合贡献$30.9$，电子亲和能贡献$24.1$，而原子化起反作用（$-9.4$，因为溴从液态原子化更容易）。水合再次占主导，只是不如氟与氯相比时那样压倒性。
:::

::: exercise 碘化钾中的碘 {level=2 check="0.0495"}
碘在纯水中的溶解度为$1.33\times10^{-3}\ \mathrm{mol\,dm^{-3}}$。取$\mathrm{I_2 + I^- \rightleftharpoons I_3^-}$的$K = 7.0\times10^{2}$，假设$[\mathrm{I_2}]$保持在其饱和值，求碘在$0.100\ \mathrm{mol\,dm^{-3}}$ KI中的饱和溶液里溶解碘的总浓度（$[\mathrm{I_2}] + [\mathrm{I_3^-}]$）。（以$\mathrm{mol\,dm^{-3}}$为单位输入总浓度，保留三位有效数字。）
::: solution
设$y = [\mathrm{I_3^-}]$；则$[\mathrm{I^-}] = 0.100 - y$，且$y = K[\mathrm{I_2}][\mathrm{I^-}] = 700 \times 1.33\times10^{-3} \times (0.100 - y) = 0.931(0.100 - y)$。所以$y(1 + 0.931) = 0.0931$，$y = 0.0482\ \mathrm{mol\,dm^{-3}}$。溶解碘的总浓度$= 0.0482 + 0.00133 = 0.0495\ \mathrm{mol\,dm^{-3}}$，约为其在水中溶解度的37倍——这就是碘试剂总是用碘化物溶液配制的原因。

::: exercise 估算XeF₂的生成焓 {level=2 check="-107"}
取$\mathrm{XeF_2}$中$\mathrm{Xe{-}F}$的平均键焓为$133\ \mathrm{kJ\,mol^{-1}}$，$D(\mathrm{F{-}F}) = 159\ \mathrm{kJ\,mol^{-1}}$，估算$\Delta_\mathrm{f}H^\circ(\mathrm{XeF_2,g})$。然后论证为什么类似的氩化合物$\mathrm{ArF_2}$预计不稳定。（以$\mathrm{kJ\,mol^{-1}}$为单位输入估算值，精确到个位。）
::: solution
$\mathrm{Xe(g) + F_2(g) \rightarrow XeF_2(g)}$断开一个$\mathrm{F{-}F}$键，形成两个$\mathrm{Xe{-}F}$键：$\Delta_\mathrm{f}H^\circ \approx 159 - 2(133) = -107\ \mathrm{kJ\,mol^{-1}}$，与约$-108\ \mathrm{kJ\,mol^{-1}}$的实验值一致。该化合物之所以能形成，是因为$\mathrm{F{-}F}$键很弱：即使是弱至$133\ \mathrm{kJ\,mol^{-1}}$的键也足以绰绰有余地偿还它。对氩而言，三中心键需要电荷从氩转移到氟，而氩的电离能比氙高$351\ \mathrm{kJ\,mol^{-1}}$；$\mathrm{Ar{-}F}$键会弱得多，肯定不到$159$的一半，所以$\mathrm{ArF_2}$相对于单质是不稳定的。
:::

::: exercise 次氯酸根变为氯酸根 {#exr-chlorate level=3 check="0.40"}
利用氯在碱中的拉蒂默行，(a) 求碱中的$E^\circ(\mathrm{OCl^-/Cl^-})$和$E^\circ(\mathrm{ClO_3^-/OCl^-})$；(b) 求$\mathrm{3\,OCl^- \rightarrow ClO_3^- + 2\,Cl^-}$的$E^\circ_\mathrm{cell}$和$\log K$；(c) 解释为什么漂白剂仍以次氯酸盐的形式出售。（以伏特为单位输入$E^\circ_\mathrm{cell}$，保留两位小数。）
::: hint
两个电对都跨越拉蒂默行中的不止一步。按电子数加权合并各步，然后对$\mathrm{OCl^-}$应用歧化判据。
:::
::: solution
(a) $\mathrm{OCl^- \rightarrow Cl_2 \rightarrow Cl^-}$：每步每个氯转移一个电子，所以$E^\circ(\mathrm{OCl^-/Cl^-}) = (1 \times 0.42 + 1 \times 1.36)/2 = 0.89\ \mathrm{V}$。$\mathrm{ClO_3^- \rightarrow ClO_2^- \rightarrow OCl^-}$：每步两个电子，所以$E^\circ(\mathrm{ClO_3^-/OCl^-}) = (2 \times 0.30 + 2 \times 0.68)/4 = 0.49\ \mathrm{V}$。(b) 还原半反应为$\mathrm{OCl^-/Cl^-}$，氧化半反应为$\mathrm{ClO_3^-/OCl^-}$的逆反应；配平的反应转移四个电子（一个$\mathrm{OCl^-}$从$+1$变为$+5$；两个从$+1$变为$-1$）。$E^\circ_\mathrm{cell} = 0.89 - 0.49 = 0.40\ \mathrm{V}$，$\log K = 4 \times 0.40/0.0592 = 27$。(c) 平衡压倒性地偏向氯酸根，但该反应在室温下很慢（它对次氯酸根为二级反应，且活化能相当大），所以漂白剂在低温下可保存数月。在弗罗斯特图上，次氯酸根位于$\mathrm{Cl^-}$与$\mathrm{ClO_3^-}$连线的上方——热力学判了它的死刑，动力学给了它缓刑。
:::

::: exercise 氪为何抵挡住了巴特利特 {level=3}
巴特利特的推理只比较了电离能。(a) 利用上表，求电离氪比电离氙多花多少能量。(b) 形成$\mathrm{M^+[PtF_6]^-}$的其他各项——$\mathrm{PtF_6}$的电子亲和能和盐的晶格能——对氙和氪几乎相同。为什么？(c) 已知与氙的反应只是适度放热，解释为什么氪不反应，并说明为什么$\mathrm{KrF_2}$仍能通过其他方法制得。
::: hint
对(b)，晶格能取决于离子的尺寸，而$\mathrm{[PtF_6]^-}$比两种稀有气体阳离子都大得多。
:::
::: solution
(a) $1351 - 1170 = 181\ \mathrm{kJ\,mol^{-1}}$。(b) 电子亲和能只是$\mathrm{PtF_6}$本身的性质，对两者完全相同。按卡普斯钦斯基公式，晶格能随$1/(r_+ + r_-)$变化；由于大的$\mathrm{[PtF_6]^-}$阴离子在半径和中占主导，$\mathrm{Kr^+}$与$\mathrm{Xe^+}$半径的适度差异只使晶格能改变几个百分点——这正是[[main-group/hydrogen-s-block#prop-size-matching]]的尺寸匹配原理所描述的阳离子尺寸效应被稀释的情形。(c) 如果与氙的反应放热的幅度小于约$180\ \mathrm{kJ\,mol^{-1}}$，额外的电离代价就使与氪的反应变为吸热，又没有多少熵增可以帮忙，所以反应不会发生。$\mathrm{KrF_2}$的制法不同：在极低温度下对氪–氟混合物进行放电或辐照，产生氟原子，并在产物分解之前将其捕获。$\mathrm{KrF_2}$相对于单质在热力学上不稳定，但在低温下动力学上可以持久存在——这是一种通过提供能量、而不是通过找到一条下坡路径而制得的化合物。
:::
