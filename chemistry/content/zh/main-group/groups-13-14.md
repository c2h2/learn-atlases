第13族和第14族从两种已知最硬的非金属——硼和金刚石——一直延伸到两种柔软而致密的金属：铊和铅。沿途它们提供了飞机和饮料罐所用的金属（铝）、生命的元素（碳）、信息时代的元素（硅）以及地壳的主体（硅酸盐）。有两条主线组织着这两族。第13族只有三个价电子却有四个价轨道，因此其较轻的成员是**缺电子的**：它们是路易斯酸，它们形成桥连，它们形成簇。第14族恰好有四个电子对应四个轨道，因此其化合物是电子恰足的，而有趣的对比在于碳与其下方所有元素之间——碳的$\pi$键与长链，对比硅的单键网络。沿两族向下，[[main-group/periodic-trends#def-inert-pair]]的惰性电子对效应逐渐占据主导，直到铊偏爱$+1$、铅偏爱$+2$。这里所用的成键模型——三中心键、韦德规则与双键规则——来自[[main-group/main-group-bonding]]。

## 硼：电子太少的非金属

单质硼是一种黑色、极硬、高熔点（$2076\ \mathrm{^\circ C}$）的半导体。它的几种晶型无一例外都由$\mathrm{B_{12}}$二十面体构成，二十面体之间以二中心键和三中心键相连。这种结构是缺电子的第一个迹象：硼的电子太少，无法让每个原子形成四个普通的二中心键，于是它构建多面体，让电子在面上而不是在棱上共享——这正是韦德规则所计数的簇成键（[[main-group/main-group-bonding#prop-wade]]）。

硼与电负性较大的原子形成的化合物，以平面三角形$\mathrm{BX_3}$的空$2p$轨道为主导。三卤化硼是路易斯酸（其反常的顺序$\mathrm{BF_3} < \mathrm{BCl_3} < \mathrm{BBr_3}$已在[[main-group/inorganic-acids-bases#ex-bx3]]中解释）；$\mathrm{BF_3}$与氟离子形成$\mathrm{[BF_4]^-}$，并与醚和胺形成稳定的加合物。**硼酸**$\mathrm{B(OH)_3}$是一种特殊的弱酸，因为它的作用方式是接受氢氧根，而不是给出质子，
$$
\mathrm{B(OH)_3 + 2\,H_2O \rightleftharpoons [B(OH)_4]^- + H_3O^+}, \qquad \mathrm{p}K_\mathrm{a} = 9.24,
$$
它的盐——**硼酸盐**——由平面三角形$\mathrm{BO_3}$和四面体$\mathrm{BO_4}$单元构成环和链（最常见的矿石硼砂是$\mathrm{Na_2[B_4O_5(OH)_4]\cdot 8H_2O}$）。氧化硼与二氧化硅熔融得到**硼硅酸盐玻璃**，其热膨胀系数低，使实验室玻璃器皿经得起加热。

### 硼烷与硼氢化物

硼的氢化物是典型的缺电子分子。最简单的可分离硼烷是乙硼烷$\mathrm{B_2H_6}$，它含有两个$\mathrm{B{-}H{-}B}$三中心二电子桥键（[[main-group/main-group-bonding#def-3c2e]]）；较高级的硼烷（$\mathrm{B_4H_{10}}$、$\mathrm{B_5H_9}$、$\mathrm{B_{10}H_{14}}$）是三角面多面体的碎片，而闭式阴离子$\mathrm{B_nH_n^{2-}}$（$n = 6$–$12$）是完整的三角面多面体——$\mathrm{B_{12}H_{12}^{2-}}$是一个完美的二十面体，稳定到能在强酸或强碱中煮沸而不分解。乙硼烷的制法是在醚类溶剂中把氢负离子转移给卤化硼，
$$
\mathrm{3\,NaBH_4 + 4\,BF_3 \rightarrow 2\,B_2H_6 + 3\,NaBF_4},
$$
它是一种有毒的自燃性气体（在潮湿空气中可自发着火），只能由受过训练的人员在密闭装置中操作。

乙硼烷的反应发生在桥键上。路易斯碱把二聚体对称地裂解为两个加合物，$\mathrm{B_2H_6 + 2\,THF \rightarrow 2\,H_3B{\cdot}THF}$，由此得到的“$\mathrm{BH_3}$”等价物在**硼氢化**反应中加成到烯烃上（硼加到取代较少的碳上，氢加到取代较多的碳上），这是[[organic-1/alkenes-alkynes]]中制备反马氏规则醇的入口。接受氢负离子得到**四氢硼酸根**（硼氢根）阴离子$\mathrm{[BH_4]^-}$，它与甲烷等电子；硼氢化钠是一种温和、耐水的还原剂，能把醛和酮还原为醇。$\mathrm{B{-}H}$键是氢负性的（$\chi(\mathrm{B}) = 2.04 < \chi(\mathrm{H}) = 2.20$），这就是硼烷作为氢负离子给体、并与水和醇反应放出$\mathrm{H_2}$的原因——即[[main-group/hydrogen-s-block#def-hydrides]]中的氢化物分类。

### 氮化硼与环硼氮烷：与碳等电子

一个$\mathrm{B{-}N}$单元有$3 + 5 = 8$个价电子，与$\mathrm{C{-}C}$相同。因此氮化硼模仿碳：**六方氮化硼**具有由稠合$\mathrm{B_3N_3}$六元环构成的类石墨层，而在高压下制得的**立方氮化硼**具有金刚石结构，硬度仅次于金刚石。这种模仿是结构上的，而不是电子性质上的。六方BN呈白色，是电绝缘体，不同于黑色、导电的石墨，因为电负性差在已填充的$\pi$能带（位于氮上）与空的$\pi$能带（位于硼上）之间打开了一个大能隙；而且它的层以硼正对氮的方式堆叠，使相反的部分电荷相遇，而不像石墨那样错开。

::: definition 等电子类似物 {#def-isoelectronic}
两个物种若具有相同数目的价电子，且分布在相同的原子骨架上，则它们是**等电子的**：$\mathrm{BH_4^-}$、$\mathrm{CH_4}$与$\mathrm{NH_4^+}$；$\mathrm{N_2}$、$\mathrm{CO}$、$\mathrm{CN^-}$与$\mathrm{NO^+}$；$\mathrm{CO_2}$、$\mathrm{N_2O}$与$\mathrm{NO_2^+}$；苯与环硼氮烷$\mathrm{B_3N_3H_6}$；石墨与六方BN。等电子物种通常具有相同的形状和成键方式（相同的路易斯结构和价层电子对互斥计数）；但它们一般**不**具有相同的反应性、极性或颜色，因为这些性质取决于电子在电负性不同的原子之间如何分布。
:::

::: example 环硼氮烷不是苯 {#ex-borazine}
环硼氮烷$\mathrm{B_3N_3H_6}$是由$\mathrm{BH}$和$\mathrm{NH}$单元交替组成的平面六元环，与苯等电子，绰号“无机苯”。苯在室温下不与氯化氢反应，而环硼氮烷却能加成三分子$\mathrm{HCl}$，生成$\mathrm{B_3N_3H_9Cl_3}$。预测每个H和Cl加到哪里，并用电负性解释两者的差别。
::: solution
在$\mathrm{B{-}N}$键中，$\pi$电子来自氮的孤对电子（在没有形式电荷的路易斯结构中，硼有一个空$p$轨道，氮有一对孤对电子），并且仍集中在电负性较大的氮上（$\chi = 3.04$对$2.04$）。因此这个环是极性的：硼带$\delta+$，具有路易斯酸性；氮带$\delta-$，具有碱性。$\mathrm{HCl}$按极性方向加成到每个$\mathrm{B{=}N}$键上，$\mathrm{H^{\delta+}}$加到氮上，$\mathrm{Cl^{\delta-}}$加到硼上，得到饱和的环己烷类似物$\mathrm{(ClHB{-}NH_2)_3}$，其中每个硼带有$\mathrm{H}$和$\mathrm{Cl}$，每个氮带有两个氢。苯环是非极性的，加成会失去它的$\pi$离域能（约$150\ \mathrm{kJ\,mol^{-1}}$的芳香稳定化能），所以苯抵抗加成。环硼氮烷可失去的离域能要少得多，因为它的$\pi$电子密度定域在氮上。这个例子正是定义中那条附加说明的体现：相同的电子数给出相同的形状，却不给出相同的化学性质。
:::
:::

## 铝与第13族较重的金属

铝是地壳中含量最多的金属，然而直到19世纪80年代它还是一种贵金属，因为它的氧化物异常稳定。由于$E^\circ(\mathrm{Al^{3+}/Al}) = -1.66\ \mathrm{V}$，且其线在埃林厄姆图上位置极低，氧化铝在任何可行的温度下都不能被碳还原（[[main-group/inorganic-redox#ex-zn-mg-smelting]]），而水溶液电解只会产生氢气。现代工业分两个阶段。

**拜耳法**提纯铝土矿，后者是铝的氢氧化物-氧化物与铁的氧化物和二氧化硅的混合物。热的浓氢氧化钠把两性的铝溶解为铝酸根，$\mathrm{Al(OH)_3(s) + OH^-(aq) \rightarrow [Al(OH)_4]^-(aq)}$，而碱性的氧化铁(III)作为“赤泥”留下。冷却并加入晶种后，平衡逆转，纯净的$\mathrm{Al(OH)_3}$结晶析出；在$1000\ \mathrm{^\circ C}$以上煅烧得到氧化铝$\mathrm{Al_2O_3}$。整个分离依赖于[[main-group/inorganic-acids-bases#def-oxides]]中的两性带：铝的氧化物酸性足以溶于碱，铁的氧化物则不然。

**霍尔-埃鲁法**电解溶于熔融冰晶石$\mathrm{Na_3AlF_6}$中的氧化铝，温度约为$960\ \mathrm{^\circ C}$——远低于氧化铝的熔点$2072\ \mathrm{^\circ C}$。铝在以碳为衬里的阴极上析出，氧与碳阳极反应，阳极随之消耗：
$$
\mathrm{2\,Al_2O_3 + 3\,C \rightarrow 4\,Al + 3\,CO_2}.
$$
电解槽在约$4$–$4.5\ \mathrm{V}$、数十万安培下运行，电流效率接近$95\ \%$，每千克金属耗电约$13$–$15\ \mathrm{kWh}$；正是这一能耗使铝的回收如此重要——回收只需其约二十分之一的能量。

金属铝受一层几纳米厚的致密氧化膜保护，划破后立即重新生成；破坏这层膜（用汞，或在强碱溶液中使氧化物以铝酸根形式溶解），金属就会与水剧烈反应。同样的氧化膜经电解加厚，就是**阳极氧化**铝。

### 酸性的水合离子

::: definition 水合阳离子的酸性 {#def-aqua-acidity}
水中的金属离子是一个与六个（或四个）水分子结合的路易斯酸，结合的水是比自由水更强的布朗斯特酸，因为阳离子从$\mathrm{O{-}H}$键中吸引电子密度：
$$
\mathrm{[M(H_2O)_6]^{z+} + H_2O \rightleftharpoons [M(OH)(H_2O)_5]^{(z-1)+} + H_3O^+}.
$$
酸性随阳离子的电荷半径比$z/r$（其极化能力）增大而增强：$\mathrm{[Na(H_2O)_n]^+}$的$\mathrm{p}K_\mathrm{a}$约为$14$（实际上呈中性），$\mathrm{[Mg(H_2O)_6]^{2+}}$为$11.4$，$\mathrm{[Al(H_2O)_6]^{3+}}$为$5.0$，$\mathrm{[Fe(H_2O)_6]^{3+}}$约为$2$，后者部分共价的$\mathrm{Fe{-}O}$键增强了这一效应。
:::

::: example 为什么铝盐呈酸性 {#ex-al-hydrolysis}
取$\mathrm{[Al(H_2O)_6]^{3+}}$的$\mathrm{p}K_\mathrm{a} = 5.0$，忽略进一步的水解步骤，计算$0.10\ \mathrm{mol\,dm^{-3}}$氯化铝溶液的pH。然后解释缓慢加入氢氧化钠时会发生什么。
::: solution
$K_\mathrm{a} = 1.0\times10^{-5}$，$c = 0.10\ \mathrm{mol\,dm^{-3}}$。由于$c/K_\mathrm{a} = 10^4$，弱酸近似$[\mathrm{H_3O^+}] = \sqrt{K_\mathrm{a}c} = \sqrt{1.0\times10^{-6}} = 1.0\times10^{-3}\ \mathrm{mol\,dm^{-3}}$是很好的（精确解二次方程得$9.95\times10^{-4}$），因此pH为$3.00$——与稀乙酸溶液一样酸。加碱会从水合离子上逐步移去质子，在中性pH附近生成中性、难溶的$\mathrm{Al(OH)_3(H_2O)_3}$（白色胶状沉淀，实际上是聚合的氢氧化物）；碱过量时第四个质子也被移去，沉淀以$\mathrm{[Al(OH)_4]^-}$的形式重新溶解。酸性、沉淀、再溶解：这一序列就是在一支试管中观察到的两性，也恰好是拜耳法正向和逆向运行的化学。水处理利用的是同一种沉淀：加入原水中的硫酸铝形成胶状氢氧化物，把细小颗粒从悬浮液中扫除。
:::
:::

铝的卤化物表现出与硼相同的缺电子性。氯化铝在固态中是层状晶格，在熔体和蒸气中是以氯桥连的二聚体$\mathrm{Al_2Cl_6}$（[[main-group/main-group-bonding]]解释了为什么这些桥键与乙硼烷的不同，是普通的二电子键），只有在高温下才是单体。它的路易斯酸性驱动[[organic-2/aromatic-substitution]]中的傅-克反应，在那里它从卤代烷或酰卤上夺取卤离子以生成亲电试剂。

铝以下，族的金属性增强，惰性电子对开始出现。**镓**在$29.8\ \mathrm{^\circ C}$熔化，却在$2000\ \mathrm{^\circ C}$以上才沸腾，是所有元素中液态温度范围最宽的；它的化合物砷化镓和氮化镓是激光器和发光二极管的半导体。**铟**给出氧化铟锡，即触摸屏的透明导体。**铊**主要为$+1$价：$\mathrm{Tl^+}$（$150\ \mathrm{pm}$）在尺寸上类似$\mathrm{K^+}$，在卤化物难溶这一点上类似$\mathrm{Ag^+}$，而它与钾的相似正是其高毒性的根源——人体通过钾通道摄取它。铊化合物被列为急性毒性和蓄积性毒物；教学实验室不使用它们。

## 碳

### 同素异形体

碳的同素异形体是成键如何决定性质的一课。

| | 成键 | C–C距离 / pm | 密度 / $\mathrm{g\,cm^{-3}}$ | 特性 |
|---|---|---|---|---|
| 金刚石 | $sp^3$，三维网络 | 154 | 3.515 | 最硬的天然材料，绝缘体，室温下所有块状固体中热导率最高 |
| 石墨 | $sp^2$层，$\pi$离域 | 层内142；层间335 | 2.266 | 柔软、润滑，沿层平面导电 |
| $\mathrm{C_{60}}$ | 弯曲的$sp^2$笼 | 139和145 | 1.65 | 分子固体；可溶于芳香溶剂 |
| 石墨烯 | 单层石墨 | 142 | — | 半金属，载流子迁移率极高 |

富勒烯、碳纳米管和石墨烯发现于1985年至2004年之间，在[[materials-chemistry/nanomaterials]]中展开讨论。经典的问题是前两者之间的关系。在$298\ \mathrm{K}$和$1\ \mathrm{bar}$下，石墨是稳定形态：对$\mathrm{C(graphite) \rightarrow C(diamond)}$，$\Delta_\mathrm{r}H^\circ = +1.895\ \mathrm{kJ\,mol^{-1}}$，$\Delta_\mathrm{r}G^\circ = +2.900\ \mathrm{kJ\,mol^{-1}}$。金刚石之所以能保存下来，是因为转化需要断开并重建共价网络中的每一个键；能垒高到使金刚石在室温下可以无限期地保持亚稳态。但金刚石密度更大，而压力有利于密度较大的相。

::: proposition 反应吉布斯自由能对压力的依赖 {#prop-dg-pressure}
在恒温下，对于摩尔体积变化为$\Delta_\mathrm{r}V$的转变，
$$
\left(\frac{\partial \Delta_\mathrm{r}G}{\partial p}\right)_T = \Delta_\mathrm{r}V, \qquad\text{因此}\qquad \Delta_\mathrm{r}G(p) \approx \Delta_\mathrm{r}G^\circ + \Delta_\mathrm{r}V\,(p - p^\circ)
$$
条件是各相为凝聚相且忽略其压缩性。向密度较大的相的转变（$\Delta_\mathrm{r}V < 0$）随压力升高而变得更有利，并在$p \approx p^\circ - \Delta_\mathrm{r}G^\circ/\Delta_\mathrm{r}V$以上成为自发过程。
:::

::: proof 由基本方程出发
对每一相，$\mathrm{d}G_\mathrm{m} = V_\mathrm{m}\,\mathrm{d}p - S_\mathrm{m}\,\mathrm{d}T$（[[thermodynamics/free-energy]]），所以在恒定$T$下，$(\partial G_\mathrm{m}/\partial p)_T = V_\mathrm{m}$。用产物相的方程减去反应物相的方程，得到$(\partial \Delta_\mathrm{r}G/\partial p)_T = \Delta_\mathrm{r}V$。若$\Delta_\mathrm{r}V$与压力无关（不可压缩固体近似，对于金刚石和石墨在所涉及的压力范围内准确到百分之几），从$p^\circ$积分到$p$即得线性形式。令$\Delta_\mathrm{r}G(p) = 0$即得平衡压力。
:::

::: example 金刚石在什么压力下稳定？ {#ex-diamond}
利用表中的密度（$M = 12.011\ \mathrm{g\,mol^{-1}}$）和$\Delta_\mathrm{r}G^\circ = +2.900\ \mathrm{kJ\,mol^{-1}}$，估计$298\ \mathrm{K}$下金刚石在热力学上稳定所需的最低压力。
::: solution
摩尔体积：石墨$12.011/2.266 = 5.301\ \mathrm{cm^3\,mol^{-1}}$；金刚石$12.011/3.515 = 3.417\ \mathrm{cm^3\,mol^{-1}}$。所以$\Delta_\mathrm{r}V = -1.883\ \mathrm{cm^3\,mol^{-1}} = -1.883\times10^{-6}\ \mathrm{m^3\,mol^{-1}}$。于是
$$
p - p^\circ = -\frac{\Delta_\mathrm{r}G^\circ}{\Delta_\mathrm{r}V} = \frac{2900\ \mathrm{J\,mol^{-1}}}{1.883\times10^{-6}\ \mathrm{m^3\,mol^{-1}}} = 1.54\times10^{9}\ \mathrm{Pa},
$$
约$1.5\ \mathrm{GPa}$，即大气压的$15\,000$倍（$p^\circ$即$10^{5}\ \mathrm{Pa}$与之相比可以忽略）。注意单位换算：$\mathrm{J\,m^{-3}} = \mathrm{Pa}$。在室温下，这个压力能使金刚石稳定，却不能使它**生成**，因为转化太慢。因此工业合成在较高温度下进行，以获得可用的速率；又因为平衡压力随温度升高而升高（石墨的熵较高），需要在$1500$–$2000\ \mathrm{K}$下施加约$5$–$6\ \mathrm{GPa}$的压力，并用熔融的过渡金属作溶剂，溶解石墨并析出金刚石。天然金刚石以同样的方式在地幔中$150\ \mathrm{km}$以下形成，并由火山喷发迅速带到地表。
:::
:::

### 氧化物与碳化物

碳的氧化物从有利的一面展示了双键规则。**一氧化碳**与$\mathrm{N_2}$等电子，键焓为$1076\ \mathrm{kJ\,mol^{-1}}$，是所有双原子分子中最强的；它通过碳原子与低氧化态金属结合（[[organometallics-catalysis/ligands-complexes]]中的羰基化合物），并与血红蛋白中的铁结合，其强度约为氧的两百倍，这使它成为一种危险的窒息性气体（GHS06，急性毒性），既看不见也闻不到。**二氧化碳**是碳酸的分子型酸酐，碳酸奇特的$\mathrm{p}K_\mathrm{a}$已在[[main-group/inorganic-acids-bases#warn-oxoacid-exceptions]]中剖析。

与氢化物一样，**碳化物**按其搭配元素的电负性分类。与最活泼的正电性金属形成的是类盐碳化物：碳化钙$\mathrm{CaC_2}$含有乙炔根离子$\mathrm{C_2^{2-}}$（与$\mathrm{N_2}$和CO等电子），与水反应生成乙炔，$\mathrm{CaC_2 + 2\,H_2O \rightarrow Ca(OH)_2 + C_2H_2}$。与硅和硼形成的是共价网络：碳化硅（金刚砂）和碳化硼是磨料和装甲陶瓷。与较大的过渡金属形成的是间隙型碳化物：碳化钨$\mathrm{WC}$是切削工具所用的硬质合金。

## 硅、硅酸盐与硅酮

硅的制法是在约$2000\ \mathrm{^\circ C}$的电弧炉中用碳还原石英，$\mathrm{SiO_2 + 2\,C \rightarrow Si + 2\,CO}$，得到纯度约$99\ \%$的冶金级硅。对电子工业而言，这远远不够纯。金属硅与氯化氢反应转化为三氯硅烷，$\mathrm{Si + 3\,HCl \rightarrow HSiCl_3 + H_2}$，这是一种液体（沸点$32\ \mathrm{^\circ C}$），经分馏提纯后在热的硅棒上分解，重新得到单质（西门子法）。然后从熔体中提拉单晶（直拉法，即丘克拉斯基法），得到杂质含量以十亿分之一或更低计的硅——即[[materials-chemistry/electronic-structure-solids]]中的材料。

### 硅酸盐

地壳约90 %由硅酸盐矿物组成，它们令人眼花缭乱的化学式由一个结构单元支配：$\mathrm{SiO_4}$四面体。根据双键规则（[[main-group/main-group-bonding#prop-double-bond-rule]]），硅与氧形成四个单键而不是双键，因此它的氧化物会聚合：四面体通过共用顶角氧连接，构成孤岛、环、链、层和骨架。一条计数规则就能把结构转化为化学式。

::: algorithm 由连接方式求硅酸盐的化学式 {#alg-silicate}
1. 确定每个$\mathrm{SiO_4}$四面体与其他四面体共用的顶角数$s$（$0 \le s \le 4$；若各四面体不同，取平均值）。
2. 每个共用（桥连）氧一半属于两个四面体中的每一个；每个未共用（端基）氧完全属于一个四面体。每个硅对应的氧数：$(4 - s) + s/2 = 4 - s/2$。
3. 硅为$+4$、氧为$-2$，每个硅对应的电荷为$4 - 2(4 - s/2) = s - 4$。因此重复单元为$[\mathrm{SiO}_{4 - s/2}]^{(4 - s)-}$。
4. 乘以真实重复单元中的四面体数目（环的大小或链的重复周期）以消去分数，并用阳离子核对总电荷。
5. 若铝取代某个四面体中的硅，每次取代增加一个负电荷，必须由一个额外的阳离子来平衡。

| $s$ | 单元 | 结构类型 | 实例 |
|---|---|---|---|
| 0 | $\mathrm{SiO_4^{4-}}$ | 孤立四面体（正硅酸盐） | 橄榄石$\mathrm{(Mg,Fe)_2SiO_4}$ |
| 1 | $\mathrm{Si_2O_7^{6-}}$ | 双四面体 | 钪钇石$\mathrm{Sc_2Si_2O_7}$ |
| 2 | $\mathrm{(SiO_3)}_n^{2n-}$ | 环或单链 | 绿柱石$\mathrm{Be_3Al_2Si_6O_{18}}$；辉石，如$\mathrm{MgSiO_3}$ |
| 2.5 | $\mathrm{(Si_4O_{11})}_n^{6n-}$ | 双链 | 角闪石（石棉矿物） |
| 3 | $\mathrm{(Si_2O_5)}_n^{2n-}$ | 层 | 云母、黏土、滑石$\mathrm{Mg_3Si_4O_{10}(OH)_2}$ |
| 4 | $\mathrm{SiO_2}$ | 三维骨架 | 石英；含Al时为长石和沸石 |
:::

::: example 解读三种矿物的化学式 {#ex-silicates}
用[[#alg-silicate]]确定下列矿物中硅酸盐的类型：(a) 绿柱石$\mathrm{Be_3Al_2Si_6O_{18}}$；(b) 滑石$\mathrm{Mg_3Si_4O_{10}(OH)_2}$；(c) 正长石$\mathrm{KAlSi_3O_8}$。
::: solution
(a) 阳离子带$3(+2) + 2(+3) = +12$，所以硅酸盐单元为$\mathrm{Si_6O_{18}^{12-}}$：每个硅对应三个氧和$2-$电荷，即$s = 2$。化学式单元中恰好有六个硅，且没有链，所以它是由六个四面体组成的**环**——六元环堆叠成孔道，绿柱石晶体呈六方柱状（祖母绿和海蓝宝石都是着色的绿柱石）。(b) 除去属于镁层而不属于四面体的氢氧根，剩下$\mathrm{Si_4O_{10}}$；三个$\mathrm{Mg^{2+}}$（$+6$）减去两个$\mathrm{OH^-}$（$-2$）余下$+4$需要平衡，所以单元为$\mathrm{Si_4O_{10}^{4-}}$，即每两个硅对应$\mathrm{Si_2O_5^{2-}}$：每个硅$2.5$个氧，$s = 3$，是**层**。滑石的层是电中性的，仅靠微弱的色散力结合在一起，这就是它成为最软的矿物并有滑腻感的原因。(c) 数出四面体中心原子，$\mathrm{Al} + 3\,\mathrm{Si} = 4$，对应八个氧：每个四面体中心原子两个氧，$s = 4$，是**骨架**。纯$\mathrm{SiO_2}$骨架是中性的；每四个硅中有一个被铝取代，使骨架成为$\mathrm{[AlSi_3O_8]^-}$，钾离子位于其空腔中以平衡电荷（第5步）。以这种方式构成的长石约占地壳的一半。
:::
:::

铝取代进入骨架（第5步）产生了**铝硅酸盐**：长石、黏土（遇水膨胀并能交换阳离子的层状铝硅酸盐）以及**沸石**——一类开放骨架，其分子尺寸的空腔和孔道使它们成为洗涤剂中的离子交换剂、分子筛以及石油炼制中的酸催化剂（[[materials-chemistry/porous-materials]]）。一条经验规律——**勒文施泰因规则**——指出两个以铝为中心的四面体几乎从不共用一个氧（避免$\mathrm{Al{-}O{-}Al}$连接），因此没有哪种沸石骨架中的铝多于硅。这是对矿物和合成沸石的观察，而不是定律；已知有少数例外。

::: warning 硅酸盐结构不是水中的分子 {#warn-silicates}
写出$\mathrm{SiO_4^{4-}}$或$\mathrm{Si_6O_{18}^{12-}}$，容易让人想象这些阴离子像硫酸根那样自由漂浮。并非如此。$4-$阴离子碱性太强，无法在水中存在（原硅酸$\mathrm{Si(OH)_4}$的$\mathrm{p}K_\mathrm{a} \approx 9.8$，后续的去质子化越来越困难），在溶液中硅酸盐可逆地缩合和解聚，形成不断变化的低聚物混合物。表中的化学式描述的是晶体内部四面体的连接方式，其中负电荷由与端基氧成键的阳离子平衡。同样，辉石中的“链”是贯穿晶体的结构基元，而不是可以分离出来的聚合物分子。用这个算法来解读结构和化学式，绝不要用它预测溶液中的物种。
:::

### 硅酮

硅酮（聚硅氧烷）是具有无机主链$\mathrm{({-}SiR_2{-}O{-})}_n$和有机侧基（通常为甲基）的聚合物。它们由**直接法**（罗乔-米勒法）制得：硅在约$300\ \mathrm{^\circ C}$下于铜催化剂上与氯甲烷反应，
$$
\mathrm{Si + 2\,CH_3Cl \rightarrow (CH_3)_2SiCl_2},
$$
同时生成少量$\mathrm{(CH_3)_3SiCl}$和$\mathrm{CH_3SiCl_3}$。水解把每个$\mathrm{Si{-}Cl}$变为$\mathrm{Si{-}OH}$，硅醇脱水缩合，于是二甲基二氯硅烷（两个官能团，“D”）生成链和环，三甲基氯硅烷（一个，“M”）封闭链端，甲基三氯硅烷（三个，“T”）形成支化点和交联。选择混合比例就决定了产品：油、脂、橡胶或树脂。性质来自主链。$\mathrm{Si{-}O}$键很强（$452\ \mathrm{kJ\,mol^{-1}}$），赋予热稳定性和抗氧化性；$\mathrm{Si{-}O{-}Si}$键角很大（约$140$–$150^\circ$）且极易弯曲，链又能自由旋转，所以聚二甲基硅氧烷在远低于室温时仍保持柔韧（其玻璃化转变温度接近$-125\ \mathrm{^\circ C}$）；而甲基朝外，使材料憎水且化学惰性。硅酮是无机化学因双键规则而得的回报：硅作为分子做不到的事（酮的类似物$\mathrm{R_2Si{=}O}$不能分离），它作为聚合物做到了。

## 锗、锡和铅

锗是半导体（1947年的第一个晶体管就是用它制成的），其化学性质与硅相近。锡和铅是金属，受惰性电子对效应支配：$\mathrm{Sn(IV)}$是锡的稳定氧化态，$\mathrm{Sn(II)}$是温和的还原剂；而$\mathrm{Pb(II)}$是铅的稳定氧化态，$\mathrm{Pb(IV)}$是强氧化剂（[[main-group/periodic-trends#ex-lead]]）。

锡还显示了两种同素异形体可以多么接近。灰锡（$\alpha$-锡）具有金刚石结构，是半导体，在$13.2\ \mathrm{^\circ C}$以下稳定；普通的金属白锡（$\beta$-锡）在此温度以上稳定。这一转变非常缓慢，白锡可以在低温下保存很长时间，但灰锡一旦成核，就会以碎裂粉末的形式蔓延（“锡疫”）。这是现代锡焊料加入少量其他金属的原因之一。

铅是**铅酸蓄电池**的元素，按质量计，铅酸蓄电池仍是最常见的可充电电池。放电时铅(IV)被还原、铅(0)被氧化，两者都变成硫酸铅(II)：
$$
\mathrm{Pb(s) + PbO_2(s) + 2\,H_2SO_4(aq) \rightarrow 2\,PbSO_4(s) + 2\,H_2O(l)}, \qquad E^\circ = 1.69 - (-0.36) = 2.05\ \mathrm{V},
$$
这是一个归中反应，即歧化的逆反应，由中间氧化态——惰性电子对态$\mathrm{Pb(II)}$——的稳定性所驱动。铅及其化合物对神经系统和生殖有毒（GHS08）；它们在油漆、汽油和水管中的使用已基本淘汰，而铅酸蓄电池是工业中回收最彻底的产品之一。

::: quiz
关于第14族元素，下列哪种说法正确？
- [ ] 硅形成与$\mathrm{CO_2}$类似的$\mathrm{SiO_2}$分子，只是它们在固态中凝聚。
- [x] 稳定氧化态从碳、硅、锗、锡的$+4$变为铅的$+2$。
- [ ] 在室温常压下，金刚石是碳的热力学稳定形态。

::: solution
惰性电子对效应使$\mathrm{Pb(II)}$成为铅的稳定氧化态，而较轻的成员（包括锡）偏爱$+4$。二氧化硅是$\mathrm{Si{-}O}$单键的网络，而不是由$\mathrm{O{=}Si{=}O}$分子构成的固体（双键规则）；金刚石是亚稳的，由石墨生成金刚石的$\Delta_\mathrm{r}G^\circ = +2.9\ \mathrm{kJ\,mol^{-1}}$；六方BN是绝缘体，因为硼与氮之间的电负性差打开了一个大能隙——等电子的结构并不意味着等同的性质。

## 后续内容

硼和铝的缺电子性以路易斯酸性的形式贯穿整个有机化学（硼氢化、傅-克反应、硼氢化物还原），并出现在[[organometallics-catalysis/main-group-organometallics]]的金属-碳化学中。硅酸盐、沸石和半导体是[[materials-chemistry/porous-materials]]、[[materials-chemistry/electronic-structure-solids]]和[[materials-chemistry/nanomaterials]]的核心，硅酮则加入[[polymer-chemistry/polymer-structure]]中的无机聚合物之列。在地质时间尺度上控制大气$\mathrm{CO_2}$的碳酸盐-硅酸盐风化循环属于[[environmental-chemistry/earth-system-chemistry]]的内容。在本课程中，下一章[[main-group/groups-15-16]]把双键规则带入氮和磷，用它解释为什么一种元素是三键分子构成的气体，而下一种元素却是由$\mathrm{P_4}$四面体构成的固体。

::: history
1808年，盖-吕萨克（Joseph Louis Gay-Lussac）和泰纳尔（Louis Jacques Thénard）在巴黎、戴维（Humphry Davy）在伦敦各自独立地用钾还原硼酸，分离出了硼。奥斯特（Hans Christian Ørsted）于1825年制得不纯的铝，维勒（Friedrich Wöhler）于1827年制得较纯的产品，但铝一直是贵金属，直到1886年霍尔（Charles Martin Hall）和埃鲁（Paul Héroult）各自独立地发明了在熔融冰晶石中电解制铝的方法；拜耳（Karl Josef Bayer）的氧化铝工艺随后于1888年问世。施托克（Alfred Stock）从1912年起制备并表征了挥发性的硼氢化物，为处理它们发明了玻璃真空线，并于1926年与波兰德（Erich Pohland）一起制得了环硼氮烷；利普斯科姆（William Lipscomb）对硼烷结构的研究获得了1976年诺贝尔奖，布朗（Herbert C. Brown）的硼氢化反应（1956）分享了1979年的诺贝尔奖。通用电气公司的罗乔（Eugene Rochow）和德国的米勒（Richard Müller）在20世纪40年代初各自独立地发现了合成甲基氯硅烷的直接法，使硅酮成为一个产业。通用电气公司一个包括霍尔（H. Tracy Hall）在内的团队首次可重复地合成了金刚石（1955年宣布）。碳的同素异形体在二十年内被改写了两次：$\mathrm{C_{60}}$由克罗托（Harold Kroto）、柯尔（Robert Curl）、斯莫利（Richard Smalley）及其合作者于1985年发现（1996年诺贝尔化学奖），石墨烯由海姆（Andre Geim）和诺沃肖洛夫（Konstantin Novoselov）于2004年分离出来（2010年诺贝尔物理学奖）。
:::

::: summary
- 第13族是缺电子的：$\mathrm{BX_3}$和$\mathrm{AlX_3}$是路易斯酸，硼酸接受氢氧根（$\mathrm{p}K_\mathrm{a}\ 9.24$），硼烷靠三中心键结合在一起，并用韦德规则计数。
- $\mathrm{B{-}N}$与$\mathrm{C{-}C}$等电子：BN在结构上模仿石墨和金刚石，环硼氮烷在结构上模仿苯，但极性改变了颜色、导电性和反应性。
- 铝分两个阶段提取——拜耳法利用两性，霍尔-埃鲁法在冰晶石中电解氧化铝——而由于$z/r$高，其水合离子是弱酸（$\mathrm{p}K_\mathrm{a} \approx 5$）。
- 石墨是碳的稳定形态；由$(\partial\Delta_\mathrm{r}G/\partial p)_T = \Delta_\mathrm{r}V$，室温下金刚石在约$1.5\ \mathrm{GPa}$以上变得稳定，工业上在$5$–$6\ \mathrm{GPa}$附近制造。
- 硅酸盐的化学式由每个$\mathrm{SiO_4}$四面体共用的顶角数$s$决定：$[\mathrm{SiO}_{4-s/2}]^{(4-s)-}$，从孤岛（$s = 0$）到骨架（$s = 4$）；铝的取代增加电荷，产生长石、黏土和沸石。
- 硅酮利用了强而柔韧的$\mathrm{Si{-}O}$主链；其结构由M、D、T三种氯硅烷的混合比例决定。
- 沿两族向下，惰性电子对占据主导：$\mathrm{Tl(I)}$和$\mathrm{Pb(II)}$是稳定氧化态，$\mathrm{Pb(IV)}$是氧化剂，铅酸蓄电池依靠向$\mathrm{Pb(II)}$的归中反应工作。
:::

十个$\mathrm{BH}$单元贡献$10 \times 2 = 20$个电子，四个额外的氢再贡献$4$个：共$24$个电子，即$12$对。$n = 10$，$12 = n + 2$：**巢式**，即闭式十一顶点三角面多面体（十八面体）去掉一个顶点——一个篮子形的簇，四个额外的氢在其开口面周围桥连。

::: exercise 铝电解槽的一天 {level=2 check="2295"}
一个铝电解槽在$300\ \mathrm{kA}$下运行，电流效率为$95.0\ \%$。它在$24.0\ \mathrm{h}$内生产多少质量的铝（$M = 26.98\ \mathrm{g\,mol^{-1}}$）？（$F = 96\,485\ \mathrm{C\,mol^{-1}}$。）若槽电压为$4.2\ \mathrm{V}$，估计每千克的耗电量。（输入质量，单位kg，精确到千克。）
::: solution
电量$= 3.00\times10^{5}\ \mathrm{A} \times 86\,400\ \mathrm{s} = 2.592\times10^{10}\ \mathrm{C}$，其中$95.0\ \%$即$2.462\times10^{10}\ \mathrm{C}$用于沉积金属。电子的物质的量$= 2.462\times10^{10}/96\,485 = 2.552\times10^{5}$；每个铝原子需要三个电子，所以为$8.507\times10^{4}\ \mathrm{mol}$，即$8.507\times10^{4} \times 26.98\ \mathrm{g} = 2.295\times10^{6}\ \mathrm{g} = 2295\ \mathrm{kg}$——一个电解槽一天产铝两吨多。能量$= 4.2\ \mathrm{V} \times 2.592\times10^{10}\ \mathrm{C} = 1.089\times10^{11}\ \mathrm{J}$，即$30\,240\ \mathrm{kWh}$，相当于每千克$13.2\ \mathrm{kWh}$，在正文所述范围之内。

::: exercise 金刚石相线的斜率 {level=2 check="1.79"}
对$\mathrm{C(graphite) \rightarrow C(diamond)}$，$\Delta_\mathrm{r}S^\circ = -3.363\ \mathrm{J\,K^{-1}\,mol^{-1}}$，$\Delta_\mathrm{r}V = -1.883\ \mathrm{cm^3\,mol^{-1}}$。用克拉佩龙方程$\mathrm{d}p/\mathrm{d}T = \Delta S/\Delta V$求石墨-金刚石平衡线的斜率，并以$298\ \mathrm{K}$下的$1.54\ \mathrm{GPa}$为起点，估计$1500\ \mathrm{K}$下的平衡压力。（输入斜率，单位$\mathrm{MPa\,K^{-1}}$，保留三位有效数字。）

::: exercise 环硼氮烷与氮化硼 {level=2}
(a) 画出无形式电荷的环硼氮烷路易斯结构，以及含$\mathrm{B{=}N}$双键的共振式；在后者中标出形式电荷。(b) 解释为什么六方BN的层以B对N的方式堆叠，而石墨的层是错开的。(c) 说明为什么六方BN可在空气中用作高温润滑剂和坩埚材料，而石墨在这种条件下会燃烧。
::: solution
(a) 无形式电荷的结构：由单键连接、$\mathrm{BH}$与$\mathrm{NH}$交替的六元环，每个氮带一对孤对电子，每个硼有一个空$p$轨道。在含三个$\mathrm{B{=}N}$键的共振式中，每个氮有四个键（形式电荷$+1$），每个硼有四个键（形式电荷$-1$）——形式电荷的分布与电负性**相反**，这就是这个共振式只有部分贡献、$\pi$电子密度主要留在氮上的原因。(b) 在BN中硼原子带$\delta+$，氮原子带$\delta-$；让每个硼正对下一层的一个氮，可使层间静电吸引最大。石墨没有部分电荷，其错开的（ABAB）堆叠使$\pi$电子云之间的排斥最小。(c) 在某种意义上，BN在化学上已经是“烧过”的形态——它强而有极性的$\mathrm{B{-}N}$键和宽能隙使它在空气中直到约$1000\ \mathrm{^\circ C}$都耐氧化（会形成一层保护性的氧化硼表皮），而石墨在低得多的温度下就燃烧生成$\mathrm{CO_2}$。它的层像石墨的层一样能相互滑动，因而具有润滑性。

::: exercise 推导硅酸盐规则 {level=3}
(a) 由氧的计数和电中性证明[[#alg-silicate]]中的式子$[\mathrm{SiO}_{4-s/2}]^{(4-s)-}$。(b) 将其应用于角闪石双链（其中一半四面体共用两个顶角，一半共用三个），给出含四个硅原子的重复单元。(c) 证明每三个硅对应一个铝的骨架每四个四面体带$1-$电荷，并给出钠长石的化学式。
::: hint
对(b)，先对各四面体的$s$取平均，再套用公式，然后乘以四。
:::
::: solution
(a) 每个四面体有四个氧。$4 - s$个未共用的氧只属于它自己，$s$个共用氧中的每一个由两个四面体平分，所以每个硅对应的氧数$= (4 - s) + s/2 = 4 - s/2$。由氧化态得电荷$4 + (4 - s/2)(-2) = s - 4$，即每个硅对应一个电荷为$(4 - s)-$的阴离子。(b) 平均$s = (2 + 3)/2 = 2.5$：每个硅对应的氧数$= 4 - 1.25 = 2.75$，每个硅电荷$1.5-$。四个硅：$\mathrm{Si_4O_{11}^{6-}}$，即角闪石单元（如透闪石$\mathrm{Ca_2Mg_5(Si_4O_{11})_2(OH)_2}$，其阳离子提供$4 + 10 = 14$个正电荷，对应$12 + 2 = 14$个负电荷）。(c) $s = 4$时，四个四面体的骨架有八个氧。三个Si(IV)和一个Al(III)的正电荷为$3(4) + 3 = 15$，负电荷为$16$，所以骨架为$\mathrm{[AlSi_3O_8]^-}$，每个铝一个负电荷，钠长石为$\mathrm{NaAlSi_3O_8}$。用铝取代第二个硅需要一个二价阳离子，如钙长石$\mathrm{CaAl_2Si_2O_8}$，它仍然遵守勒文施泰因规则。

::: exercise 拜耳法留下了什么 {level=3}
铝土矿含有铝的氢氧化物-氧化物、氧化铁(III)、二氧化硅以及少量镓。(a) 用[[main-group/inorganic-acids-bases#def-oxides]]中的氧化物分类和[[#def-aqua-acidity]]中的水合离子酸性，解释为什么热的氢氧化钠能溶解铝而不能溶解铁。(b) 二氧化硅也会被侵蚀，然后与铝酸根反应沉淀出钠铝硅酸盐；为什么这会使工艺同时损失氢氧化钠和铝？(c) 世界上大部分镓是从拜耳法溶液中回收的。为什么镓跟随铝？
::: hint
镓位于铝的正下方；比较$\mathrm{Al^{3+}}$、$\mathrm{Ga^{3+}}$和$\mathrm{Fe^{3+}}$的尺寸（53.5、62和64.5 pm），并回想d区收缩。
:::
::: solution
(a) $\mathrm{Al^{3+}}$小而高电荷，所以$\mathrm{Al(OH)_3}$是两性的：在强碱中它从结合的水上失去一个质子（等价地说，接受$\mathrm{OH^-}$），形成可溶的$\mathrm{[Al(OH)_4]^-}$。氧化铁(III)是碱性的；在该工艺的氢氧根浓度和温度下，它不形成稳定的可溶性羟基阴离子，因此作为赤泥留下。(b) 二氧化硅是酸性氧化物，以硅酸根形式溶解，但硅酸根和铝酸根随后与钠离子结合，沉淀出难溶的钠铝硅酸盐（“脱硅产物”）；它的每一个单元都从溶液中带走钠（以NaOH损失）和铝（以产品损失），这就是高硅铝土矿加工成本高的原因。(c) $\mathrm{Ga^{3+}}$与$\mathrm{Al^{3+}}$电荷相同，并且由于d区收缩，尺寸大不了多少；$\mathrm{Ga(OH)_3}$同样是两性的，以$\mathrm{[Ga(OH)_4]^-}$形式溶解。因此镓随铝进入溶液，在溶液循环使用过程中富集，并从中回收。铁(III)虽然尺寸与镓(III)相近，却因为其氧化物是碱性的而留下；仅凭尺寸和电荷并不能决定两性，两性还取决于$\mathrm{M{-}O}$键的共价性。
:::
