第15族与第16族的头两个成员是构成空气99 %的气体——氮和氧；接下来的两个成员是能在空气中燃烧的固体——磷和硫。元素周期表中很少有哪两对相邻元素差别如此之大，而这种差别正是[[main-group/main-group-bonding#prop-double-bond-rule]]中双键规则最引人注目的体现。氮和氧形成短而强的$\pi$键，因此它们的单质是小的多重键分子$\mathrm{N{\equiv}N}$和$\mathrm{O{=}O}$。磷和硫形成的$\pi$键很弱、单键却很好，因此它们成链成环，形成$\mathrm{P_4}$四面体和$\mathrm{S_8}$环。这四种元素共同提供了产量最大的两种无机化学品（硫酸和氨）、养活约一半人类的化肥，以及每一个活细胞中的磷酸盐化学与硫化学。本章借助工具箱来解读它们的化学：用键焓解释结构，用弗罗斯特图解释氧化还原（[[main-group/inorganic-redox]]），用鲍林规则解释含氧酸（[[main-group/inorganic-acids-bases]]），用平衡热力学解释工业过程。

## 氮：空气中最强的键

$\mathrm{N_2}$分子的键焓为$945\ \mathrm{kJ\,mol^{-1}}$，键级为三，最高占据轨道与最低未占轨道之间能隙很大，没有偶极矩，电离能（$1503\ \mathrm{kJ\,mol^{-1}}$）几乎与氩（$1521$）一样高。它既不是好的酸，也不是好的碱，既不是好的氧化剂，也不是好的还原剂；从化学上说，它几乎是惰性的。然而在热力学上，它对许多试剂并不特别稳定：$\mathrm{N_2 + 3\,H_2 \rightarrow 2\,NH_3}$在室温下是放能的，氮在水中被空气氧化为硝酸根也是如此。氮的惰性是**动力学**上的：每个反应都必须从削弱三键开始，而断开三键的第一步所需的能量远多于后续各步。这正是自然界用固氮酶（[[coordination-chemistry/bioinorganic]]）、工业界用哈伯-博施法所解决的问题。

::: definition 固氮 {#def-fixation}
**固氮**是指把大气中的$\mathrm{N_2}$转化为生物或化学家可以利用的化合物——氨、硝酸盐或有机含氮化合物——的任何过程。它在生物体内发生（共生细菌和自生细菌中的固氮酶，在室温常压下进行，每个$\mathrm{N_2}$约消耗16个ATP），在闪电中发生（在极高温度下由$\mathrm{N_2}$和$\mathrm{O_2}$生成NO），也在工业上通过哈伯-博施法发生；如今该法向生物圈提供的固定氮，大致与陆地上全部自然过程所提供的相当。
:::

### 哈伯-博施法

合成氨是热力学与动力学之间工业折中的典范：
$$
\mathrm{N_2(g) + 3\,H_2(g) \rightleftharpoons 2\,NH_3(g)}, \qquad \Delta_\mathrm{r}H^\circ = -91.8\ \mathrm{kJ\,mol^{-1}},\qquad \Delta_\mathrm{r}S^\circ = -198.1\ \mathrm{J\,K^{-1}\,mol^{-1}}.
$$
该反应放热，并把四摩尔气体变为两摩尔，因此平衡在**低温**和**高压**下有利于氨。但在低温下，即使在最好的催化剂上，反应也根本无法进行。因此工厂在约$400$–$500\ \mathrm{^\circ C}$下运行，此时助催化的铁催化剂（由磁铁矿还原成的铁，以氧化钾和氧化铝为助催化剂）足够快；同时采用$100$–$300\ \mathrm{bar}$的压力，以挽回部分因高温而损失的平衡产率；氨从离开合成塔的气体中冷凝分出，未反应的气体循环使用。氢来自天然气的水蒸气重整（[[main-group/hydrogen-s-block]]），这就是为什么氨的生产约占全球$\mathrm{CO_2}$排放量的百分之一到二。

::: proposition 压力与气相平衡的组成 {#prop-kx}
对于化学计量系数为$\nu_i$（产物取正）的理想气体反应，令$\Delta\nu = \sum_i \nu_i$为气体物质的量的变化。在总压$p$下，以摩尔分数$x_i$表示，
$$
K = \prod_i \left(\frac{p_i}{p^\circ}\right)^{\nu_i} = K_x \left(\frac{p}{p^\circ}\right)^{\Delta\nu}, \qquad K_x = \prod_i x_i^{\nu_i}.
$$
$K$只取决于温度，所以当$\Delta\nu < 0$时，组成商$K_x = K(p/p^\circ)^{-\Delta\nu}$随压力增大：升高压力使平衡移向气体分子数较少的一侧。当$\Delta\nu = 0$时，压力对组成没有影响。真实气体在数百巴下会偏离这一关系，精确处理需要用逸度代替压力。
:::

::: proof 平衡常数中的道尔顿定律
对理想气体，$p_i = x_i p$（道尔顿分压定律，[[general-chemistry-1/gases]]）。代入热力学平衡常数，$\prod_i (x_i p/p^\circ)^{\nu_i} = \prod_i x_i^{\nu_i} \cdot (p/p^\circ)^{\sum_i \nu_i}$，即得结果。由于$K = \exp(-\Delta_\mathrm{r}G^\circ/RT)$在给定温度下是固定的，因子$(p/p^\circ)^{\Delta\nu}$必须由$K_x$的变化来补偿。对于合成氨，$\Delta\nu = 2 - 4 = -2$，所以$K_x = K(p/p^\circ)^2$：压力加倍，组成商变为四倍。
:::

::: example 氨的平衡产率 {#ex-haber}
把$\Delta_\mathrm{r}H^\circ$和$\Delta_\mathrm{r}S^\circ$视为常数、把气体视为理想气体，(a) 求$\Delta_\mathrm{r}G^\circ > 0$的温度下限；(b) 求$723\ \mathrm{K}$（$450\ \mathrm{^\circ C}$）下的$K$；(c) 求在$723\ \mathrm{K}$和$200\ \mathrm{bar}$下、由化学计量比$1 : 3$的原料气出发时，氨的平衡摩尔分数。
::: solution
(a) $\Delta_\mathrm{r}G^\circ = 0$时$T = 91\,800/198.1 = 463\ \mathrm{K}$（$190\ \mathrm{^\circ C}$）。高于此温度，标准吉布斯自由能为正，$K < 1$。

(b) $\Delta_\mathrm{r}G^\circ(723\ \mathrm{K}) = -91.8 + 723 \times 0.1981 = +51.4\ \mathrm{kJ\,mol^{-1}}$，所以
$$
K = \exp\!\left(\frac{-51\,430}{8.314 \times 723}\right) = 1.93\times10^{-4}.
$$
(c) 根据[[#prop-kx]]，从$1\ \mathrm{mol}$ $\mathrm{N_2}$和$3\ \mathrm{mol}$ $\mathrm{H_2}$出发，设反应进度为$\xi$：各物质的量为$1 - \xi$、$3(1 - \xi)$和$2\xi$，总量为$4 - 2\xi$。以分压$p_i = x_i p$表示，
$$
K = \frac{x_{\mathrm{NH_3}}^2}{x_{\mathrm{N_2}}x_{\mathrm{H_2}}^3}\left(\frac{p}{p^\circ}\right)^{-2}
\quad\Rightarrow\quad
\frac{4\xi^2(4 - 2\xi)^2}{27(1 - \xi)^4} = K\left(\frac{p}{p^\circ}\right)^2 = 1.93\times10^{-4} \times 200^2 = 7.70 .
$$
这个四次方程必须数值求解（下图用牛顿法求解）：$\xi = 0.534$，于是$x_{\mathrm{NH_3}} = 2(0.534)/(4 - 1.068) = 0.364$。平衡时约有$36\ \%$的氨，与这些条件下的实测值接近，尽管$K$只有$2\times10^{-4}$；压力以平方的形式出现，正是$200^2 = 4\times10^{4}$挽救了产率。实际的合成塔一次通过达不到平衡，通常只得到15–25 %的氨，这就是循环必不可少的原因。
:::
:::

::: warning 勒夏特列原理不是速率方程 {#warn-le-chatelier}
“反应放热，所以要在低温下进行”，就平衡而言是对的，就工厂而言却是错的。勒夏特列原理预言平衡移动的方向，却对达到平衡的快慢只字不提。低于约$650\ \mathrm{K}$时，即使铁催化剂也无法以有用的速率解离$\mathrm{N_2}$（$\mathrm{N_2}$在铁表面的解离吸附是决速步），所以在平衡产率最佳的温度下运行的合成塔几乎什么也生产不出来。操作温度由动力学选定；然后再用压力、循环和产物冷凝来挽回产率。同样的逻辑在下文的接触法以及工业化学的大部分领域中反复出现。
:::

### 氮的氢化物、氧化物与含氧酸

氨是弱碱（$\mathrm{NH_4^+}$的$\mathrm{p}K_\mathrm{a}$为$9.25$），是极好的配体，其液体还是碱金属的溶剂（[[main-group/hydrogen-s-block]]）。肼$\mathrm{N_2H_4}$含有一个弱的$\mathrm{N{-}N}$单键（$163\ \mathrm{kJ\,mol^{-1}}$），是强还原剂，被氧化为$\mathrm{N_2}$时释放出三键的能量；它有毒并被归类为致癌物，用作火箭燃料正是利用了这种能量释放。

氮在从$+1$到$+5$的每一个氧化态都形成氧化物：$\mathrm{N_2O}$（直线形，与$\mathrm{CO_2}$等电子；一种麻醉剂，也是强效温室气体）、$\mathrm{NO}$（奇电子自由基，生物信号分子，也是空气在高温下燃烧的最初产物）、$\mathrm{N_2O_3}$、$\mathrm{NO_2}$（棕色自由基，二聚为无色的$\mathrm{N_2O_4}$，$\Delta_\mathrm{r}H^\circ = -57.2\ \mathrm{kJ\,mol^{-1}}$）以及$\mathrm{N_2O_5}$（硝酸的酸酐；在固体中为离子型的$\mathrm{[NO_2]^+[NO_3]^-}$）。亚硝酸$\mathrm{HNO_2}$是弱酸（$\mathrm{p}K_\mathrm{a}$为$3.3$）；硝酸$\mathrm{HNO_3}$是强酸——[[main-group/inorganic-acids-bases#prop-pauling-rules]]的含氧酸规则对两者都作出了预言。

::: example 奥斯特瓦尔德法：催化剂选择产物 {#ex-ostwald}
硝酸的制法是在约$900\ \mathrm{^\circ C}$下，让氨在铂铑合金网上被空气氧化，接触时间约为一毫秒。两个反应相互竞争：
$$
\text{(1)}\ \ \mathrm{4\,NH_3 + 5\,O_2 \rightarrow 4\,NO + 6\,H_2O}, \qquad \text{(2)}\ \ \mathrm{4\,NH_3 + 3\,O_2 \rightarrow 2\,N_2 + 6\,H_2O}.
$$
利用$\Delta_\mathrm{f}G^\circ$（$298\ \mathrm{K}$，$\mathrm{kJ\,mol^{-1}}$）：$\mathrm{NH_3(g)}$ $-16.4$，$\mathrm{NO(g)}$ $+87.6$，$\mathrm{H_2O(g)}$ $-228.6$，比较这两个反应，并解释为什么工厂仍能以超过90 %的选择性生产NO。
::: solution
$$
\Delta_\mathrm{r}G^\circ_1 = 4(87.6) + 6(-228.6) - 4(-16.4) = 350.4 - 1371.6 + 65.6 = -955.6\ \mathrm{kJ\,mol^{-1}},
$$
$$
\Delta_\mathrm{r}G^\circ_2 = 6(-228.6) - 4(-16.4) = -1306.0\ \mathrm{kJ\,mol^{-1}}.
$$
两者都极为有利，而生成$\mathrm{N_2}$的途径还要有利$350\ \mathrm{kJ}$；在平衡时几乎不会有NO留存，因为NO本身相对于$\mathrm{N_2}$和$\mathrm{O_2}$就不稳定（$\Delta_\mathrm{f}G^\circ > 0$）。这个过程之所以可行，是因为它从不接近平衡。在铂表面上，吸附的氨碎片氧化为NO很快，而两个氮原子复合为$\mathrm{N_2}$相对较慢；气体在一毫秒之内就被扫离铂网并冷却，在动力学产物分解之前把它“冻结”下来。随后NO被空气氧化为$\mathrm{NO_2}$（$\mathrm{2\,NO + O_2 \rightarrow 2\,NO_2}$），再被水吸收（$\mathrm{3\,NO_2 + H_2O \rightarrow 2\,HNO_3 + NO}$，NO循环使用）。这个例子提醒我们，催化剂的作用不只是加快反应达到平衡：通过有选择地加速某一条途径，它决定了体系走向**哪一个**平衡。
:::
:::

::: solution
$\mathrm{HNO_2}$右侧的电势为$E^\circ(\mathrm{HNO_2/NO}) = 0.996\ \mathrm{V}$。左侧双电子电对$\mathrm{NO_3^-/HNO_2}$的电势是按电子数加权的平均值$(1 \times 0.803 + 1 \times 1.07)/2 = 0.94\ \mathrm{V}$（[[main-group/inorganic-redox#prop-weighted-average]]）。由于$0.996 > 0.94$，歧化判据得到满足：
$$
\mathrm{3\,HNO_2 \rightarrow NO_3^- + 2\,NO + H^+ + H_2O}, \qquad E^\circ_\mathrm{cell} = 0.996 - 0.94 = 0.06\ \mathrm{V}\ (n = 2).
$$

:::
:::

硝酸根位于图的右侧高处，所以在热力学上它是酸中的强氧化剂（$E^\circ(\mathrm{NO_3^-/NO}) = 0.96\ \mathrm{V}$），浓硝酸能溶解铜和银，而单靠氢离子无法氧化它们。然而在中性溶液中，硝酸根在动力学上很迟钝：它的还原需要多次电子转移和氧原子转移，因此硝酸盐化肥会在土壤和水中长期留存，直到被微生物还原。这种人为活性氮向河流与近海水体的输入通量是[[environmental-chemistry/natural-waters]]的主题。

## 磷与第15族的较重元素

白磷由$\mathrm{P_4}$四面体构成，$\mathrm{P{-}P}$键长$221\ \mathrm{pm}$，键角$60^\circ$，远离磷几乎纯$p$的成键轨道所偏爱的$90$–$100^\circ$。这种张力使它很活泼：白磷在空气中约$30\ \mathrm{^\circ C}$以上即自燃，在缓慢氧化时于暗处发光（化学发光——“磷光”一词即源于此，尽管两者机理不同），而且剧毒。它保存在水下，只能在适当的防护措施下操作；它被归类为自燃物（GHS02）、急性毒性物质（GHS06）和腐蚀性物质。在隔绝空气的条件下于约$300\ \mathrm{^\circ C}$加热，四面体打开，变为聚合的、活性低得多的红磷；在高压下它变为黑磷，即热力学上稳定的形态，具有像起皱的石墨那样的褶皱层状结构，是一种半导体。

为什么磷是$\mathrm{P_4}$而不是$\mathrm{P_2}$？六个$\mathrm{P{-}P}$单键（每个$\mathrm{P_4}$为$6 \times 201 = 1206\ \mathrm{kJ\,mol^{-1}}$）比两个$\mathrm{P{\equiv}P}$三键（$2\,\mathrm{P_2}$为$2 \times 490 = 980\ \mathrm{kJ\,mol^{-1}}$）多出$200\ \mathrm{kJ\,mol^{-1}}$以上；对于氮，同样的比较结果正好相反（$2 \times 945 = 1890$对$6 \times 163 = 978$），相差$900$以上。$\mathrm{P_2}$分子只存在于约$800\ \mathrm{^\circ C}$以上的蒸气中。

磷以磷矿石（氟磷灰石$\mathrm{Ca_5(PO_4)_3F}$）的形式开采。其中大部分从未变成单质：它用硫酸处理，制成磷酸和化肥（“湿法”），
$$
\mathrm{Ca_5(PO_4)_3F + 5\,H_2SO_4 + 10\,H_2O \rightarrow 3\,H_3PO_4 + 5\,CaSO_4{\cdot}2H_2O + HF},
$$
同时产生大量堆存的副产物石膏。单质磷用于制取高纯磷酸和磷化学品，它在约$1500\ \mathrm{^\circ C}$的电炉中生产，其中二氧化硅把钙带走成为炉渣，碳则还原磷酸盐：
$$
\mathrm{2\,Ca_3(PO_4)_2 + 6\,SiO_2 + 10\,C \rightarrow P_4 + 6\,CaSiO_3 + 10\,CO}.
$$

### 磷的氧化物、含氧酸与卤化物

磷在氧气不足时燃烧生成$\mathrm{P_4O_6}$，在氧气过量时生成$\mathrm{P_4O_{10}}$。两者都是以$\mathrm{P_4}$四面体为基础的笼状结构，在六条棱中各插入一个氧原子，而$\mathrm{P_4O_{10}}$中每个磷上还连有一个端基氧；与之相比，$\mathrm{N_2O_5}$是小的分子——又是双键规则。$\mathrm{P_4O_{10}}$与水的反应$\mathrm{P_4O_{10} + 6\,H_2O \rightarrow 4\,H_3PO_4}$放热极为剧烈，因此它是已知最有效的干燥剂之一。磷酸及其同类（亚磷酸$\mathrm{H_3PO_3}$，含一个$\mathrm{P{-}H}$键，只有两个酸性质子；次磷酸$\mathrm{H_3PO_2}$，只有一个）已在[[main-group/inorganic-acids-bases#ex-phosphorus-oxoacids]]中分析过。磷酸盐脱水缩合生成含$\mathrm{P{-}O{-}P}$键的二磷酸盐和多磷酸盐；这些键的水解在热力学上有利，但在没有催化剂时很慢，这恰恰使ATP成为[[biochemistry/bioenergetics]]中良好的能量货币。

卤化物表现出[[main-group/main-group-bonding]]中讨论过的那种超价。$\mathrm{PCl_3}$为三角锥形；$\mathrm{PCl_5}$在气相中为三角双锥，但固体是离子型的$\mathrm{[PCl_4]^+[PCl_6]^-}$——四面体阳离子和八面体阴离子比三角双锥堆积得更好。两种氯化物都被水剧烈水解，生成$\mathrm{HCl}$和一种含氧酸（$\mathrm{PCl_3 + 3\,H_2O \rightarrow H_3PO_3 + 3\,HCl}$），并被归类为腐蚀性物质和吸入有毒物质。

::: example 为什么较重氢化物的键角接近90° {#ex-hydride-angles}
第15族氢化物的$\mathrm{H{-}E{-}H}$键角为：$\mathrm{NH_3}$ $106.7^\circ$，$\mathrm{PH_3}$ $93.5^\circ$，$\mathrm{AsH_3}$ $92.1^\circ$，$\mathrm{SbH_3}$ $91.7^\circ$；第16族为：$\mathrm{H_2O}$ $104.5^\circ$，$\mathrm{H_2S}$ $92.1^\circ$，$\mathrm{H_2Se}$ $90.6^\circ$。解释为什么只有第二周期的氢化物键角接近四面体角。
::: solution
键角接近$90^\circ$意味着中心原子几乎用纯$p$轨道成键，而把孤对电子保留在几乎纯$s$的轨道中；键角接近$109.5^\circ$则意味着$s$轨道与$p$轨道充分混合（杂化）。决定是哪一种情况的因素有两个。第一是**混合的代价**：杂化把$s$成分提升到成键轨道中，而$s$–$p$能量间隔，加上重原子大而弥散的$s$轨道与氢重叠较差，使得杂化沿族向下越来越不划算。第二是**空间压力**：在小的第二周期原子周围，成键电子对彼此靠近、强烈排斥，从而使键角张开（价层电子对互斥的论证，[[bonding-structure/vsepr]]）；在具有长$\mathrm{E{-}H}$键的大原子周围（$\mathrm{P{-}H}$为$142\ \mathrm{pm}$，而$\mathrm{N{-}H}$为$101\ \mathrm{pm}$），电子对相距很远，排斥很弱。两个因素指向同一方向，所以较重的氢化物使用几乎纯的$p$轨道。由此得到的一个推论是：磷上的孤对电子主要是$3s$，紧凑且方向性较弱，所以$\mathrm{PH_3}$是比$\mathrm{NH_3}$弱得多的碱（$\mathrm{PH_4^+}$的$\mathrm{p}K_\mathrm{a}$约为$-14$，而$\mathrm{NH_4^+}$为$9.25$），尽管膦对软金属是极好的配体。
:::
:::

磷以下，该族变得金属化。**砷**和**锑**是类金属，其氧化物是两性的；砷化合物具有急性毒性和致癌性（地下水中的砷是南亚和东亚部分地区的重大公共卫生问题），并据此分类。**铋**是金属，其化学是$\mathrm{Bi(III)}$的化学；由于惰性电子对效应，铋(V)（如铋酸钠中）是强氧化剂，能把$\mathrm{Mn^{2+}}$氧化为高锰酸根。铋作为重元素还有一点不同寻常：它的毒性很低，因此铋盐可以用于医药。

## 氧

双氧是**三重态**：它能量最高的两个电子以平行自旋占据两个简并的$\pi^*$轨道（[[bonding-structure/molecular-orbitals]]中的分子轨道结论），这使液氧能明显地被磁铁吸引。三重基态解释了一个悖论：氧在热力学上是强氧化剂（$E^\circ(\mathrm{O_2/H_2O}) = 1.23\ \mathrm{V}$），然而有机物在空气中并不会突然起火，因为大多数有机分子是单重态，三重态与单重态直接反应生成单重态产物是自旋禁阻的，因而很慢。一旦有自由基存在（在火焰中，或由金属离子催化），这一限制便解除了。**单线态氧**中两个$\pi^*$电子配对占据同一个轨道，其能量比基态高$94\ \mathrm{kJ\,mol^{-1}}$；它由光化学产生，是活泼的氧化剂（[[kinetics/photochemistry]]）。

**臭氧**$\mathrm{O_3}$是弯曲分子（键角$116.8^\circ$，两个$\mathrm{O{-}O}$键均为$127.8\ \mathrm{pm}$，介于单键与双键之间），由$\mathrm{O_2}$经紫外光或放电生成。它是比$\mathrm{O_2}$更强的氧化剂（$E^\circ(\mathrm{O_3/O_2}) = 2.08\ \mathrm{V}$），用于水的消毒；在地面污染空气中是呼吸道刺激物；在平流层中则是抵御紫外辐射的屏障（[[environmental-chemistry/stratospheric-ozone]]）。其他元素的氧化物已在[[main-group/inorganic-acids-bases#def-oxides]]中被分为酸性、碱性和两性氧化物；过氧化物和超氧化物已在[[main-group/hydrogen-s-block]]中随碱金属一起介绍；过氧化氢在热力学上倾向于歧化的不稳定性则已在[[main-group/inorganic-redox]]中详细分析。

## 硫

硫能成链，氧却不能：$\mathrm{S{-}S}$键（$266\ \mathrm{kJ\,mol^{-1}}$）比$\mathrm{O{-}O}$键（$146\ \mathrm{kJ\,mol^{-1}}$）强得多，因为相邻氧原子上的孤对电子被短键拉得很近，彼此强烈排斥。两个硫单键也胜过一个$\mathrm{S{=}S}$双键，所以单质硫是环状分子，而不是双原子分子。

::: definition 硫的同素异形体 {#def-sulfur}
室温下硫的稳定形态是**斜方**（$\alpha$）硫，由皇冠形的$\mathrm{S_8}$环构成。高于$95.3\ \mathrm{^\circ C}$时，同样的环以不同方式堆积，成为**单斜**（$\beta$）硫，它在约$119\ \mathrm{^\circ C}$熔化为由$\mathrm{S_8}$环组成的淡黄色流动液体。高于$159\ \mathrm{^\circ C}$时，环打开成为双自由基链，链相互连接成长达数十万个原子的聚合物，液体的黏度增大约一万倍；温度再升高时，链断裂，黏度又下降。把聚合态液体倒入冷水中，得到有弹性的**弹性硫**，它会缓慢地变回斜方$\mathrm{S_8}$。人们还制得并表征了许多其他的环（$\mathrm{S_6}$、$\mathrm{S_7}$、$\mathrm{S_{12}}$以及更大的环）。
:::

硫化氢$\mathrm{H_2S}$是弱酸（$\mathrm{p}K_\mathrm{a1} = 7.0$），也是软配体，这就是软阳离子的金属硫化物如此难溶的原因——这是经典定性分析的基础，也是铜、锌、铅硫化物矿石的成因。它还是一种剧毒气体（GHS06，吸入急性毒性，作用机理与氰化物相当：它阻断细胞色素c氧化酶），尤其危险的是，在危险浓度下，嗅觉被麻痹，臭鸡蛋气味随之消失。

### 二氧化硫、三氧化硫与接触法

硫燃烧生成二氧化硫$\mathrm{SO_2}$，这是一种弯曲分子，是中等强度的还原剂（在葡萄酒和果脯中用作抗氧化防腐剂），也是燃烧含硫燃料之处酸雨的来源（[[environmental-chemistry/particulates-acid-deposition]]）。由它制成的硫酸是产量最大的无机化学品，每年远超两亿吨，其中大部分用于生产磷肥。**接触法**分为三步：把硫（主要从天然气和石油的脱硫中回收）燃烧为$\mathrm{SO_2}$；在五氧化二钒催化剂上把$\mathrm{SO_2}$氧化为$\mathrm{SO_3}$，
$$
\mathrm{2\,SO_2(g) + O_2(g) \rightleftharpoons 2\,SO_3(g)}, \qquad \Delta_\mathrm{r}H^\circ = -197.8\ \mathrm{kJ\,mol^{-1}},\qquad \Delta_\mathrm{r}S^\circ = -188.0\ \mathrm{J\,K^{-1}\,mol^{-1}};
$$
然后不用水而用浓硫酸吸收$\mathrm{SO_3}$，得到发烟硫酸（$\mathrm{H_2S_2O_7}$），再加以稀释。$\mathrm{SO_3}$直接与水反应会放出大量的热，形成无法捕集的酸雾。

::: example 转化器的运行 {#ex-contact}
(a) 利用上面的数据，假设$\Delta_\mathrm{r}H^\circ$和$\Delta_\mathrm{r}S^\circ$为常数，求$700\ \mathrm{K}$下$\mathrm{SO_2}$氧化的$K$。(b) 转化器由三到四段串联的催化剂床层构成，床层之间设有冷却，且常在最后一段床层之前先吸收$\mathrm{SO_3}$（“两转两吸”）。解释这两项设计。
::: solution
(a) $\Delta_\mathrm{r}G^\circ(700\ \mathrm{K}) = -197.8 + 700 \times 0.1880 = -66.2\ \mathrm{kJ\,mol^{-1}}$，且
$$
K = \exp\!\left(\frac{66\,200}{8.314 \times 700}\right) = 8.7\times10^{4}.
$$
$K$如此之大，即使在约$1\ \mathrm{bar}$下平衡转化率也很高，这就是该过程不需要高压的原因（与合成氨不同）。(b) 钒催化剂需要约$700\ \mathrm{K}$才能起作用，而反应强烈放热。在绝热床层中，气体随反应而自行升温，温度升高时$K$减小（在$\Delta_\mathrm{r}G^\circ = 0$的$1052\ \mathrm{K}$下，$K$将为1）；单段床层会停在不高的转化率上。在床层之间冷却气体，使每段床层能在较低温度下更接近平衡。在最后一段床层之前吸收已生成的$\mathrm{SO_3}$，移去了一种产物——这里是有意地运用勒夏特列原理——使剩余的$\mathrm{SO_2}$几乎完全转化，通常高于99.7 %，既提高了产率，又降低了$\mathrm{SO_2}$排放。
:::
:::

浓硫酸的第一步解离是强酸，第二步解离为中等强度（$\mathrm{p}K_\mathrm{a2} = 1.99$）；它是强脱水剂（通过夺去水的组成元素使糖炭化），热的浓硫酸还是氧化剂。它的稀释放出大量的热；“把酸加入水中，切勿把水加入酸中”这条规则的目的，是让密度大的酸沉入较多的水中并被其冷却，而不是让少量的水在酸表面沸腾而飞溅。它被归类为腐蚀性物质（GHS05），会造成严重灼伤。

### 硫的含氧阴离子

硫的含氧阴离子比任何其他元素都多，因为它兼具多种氧化态和成链的倾向。下表列出最重要的几种及硫的平均氧化态：

| 阴离子 | 化学式 | S的平均氧化态 | 结构与化学 |
|---|---|---|---|
| 硫酸根 | $\mathrm{SO_4^{2-}}$ | $+6$ | 四面体；碱性极弱，室温下氧化还原惰性 |
| 亚硫酸根 | $\mathrm{SO_3^{2-}}$ | $+4$ | 三角锥形；还原剂；两可配体（见[[main-group/inorganic-acids-bases#ex-sulfite]]） |
| 硫代硫酸根 | $\mathrm{S_2O_3^{2-}}$ | $+2$ | 硫酸根中一个氧被S取代；还原剂和软配体 |
| 连四硫酸根 | $\mathrm{S_4O_6^{2-}}$ | $+2.5$ | $\mathrm{^-O_3S{-}S{-}S{-}SO_3^-}$；硫代硫酸根的氧化产物 |
| 连二亚硫酸根 | $\mathrm{S_2O_4^{2-}}$ | $+3$ | $\mathrm{S{-}S}$键弱；强还原剂，用于纺织品漂白 |
| 过二硫酸根 | $\mathrm{S_2O_8^{2-}}$ | 形式上为$+7$（实际为含过氧桥的$+6$） | $\mathrm{^-O_3S{-}O{-}O{-}SO_3^-}$；最强的常见氧化剂之一，$E^\circ = 2.01\ \mathrm{V}$ |

平均氧化态为分数或超过族最高值，说明离子中的原子并不等同：在硫代硫酸根中，中心硫更宜描述为$+4$或$+6$，端基硫为$0$或$-2$，取决于$\mathrm{S{-}S}$键如何分配；在过二硫酸根中，硫为$+6$，其中两个氧是过氧基（$-1$）。氧化态只是一种记账方式（[[main-group/periodic-trends#def-oxstate]]）。

::: example 碘量法滴定 {#ex-iodometry}
在碘量法中，把氧化剂加入过量的碘离子中，以淀粉为指示剂，用标准硫代硫酸钠滴定析出的碘：
$$
\mathrm{I_2 + 2\,S_2O_3^{2-} \rightarrow 2\,I^- + S_4O_6^{2-}}.
$$
(a) 证明这是一个氧化还原反应，并求每个硫代硫酸根转移的电子数。(b) 取经稀释的家用漂白剂溶液$25.0\ \mathrm{cm^3}$，在酸中用过量KI处理（$\mathrm{OCl^- + 2\,I^- + 2\,H^+ \rightarrow Cl^- + I_2 + H_2O}$），消耗$0.1000\ \mathrm{mol\,dm^{-3}}$硫代硫酸钠$18.40\ \mathrm{cm^3}$。求稀释后样品中次氯酸根的浓度。
::: solution
(a) 碘从$0$变为$-1$：每个$\mathrm{I_2}$得到两个电子。硫的平均氧化态从$\mathrm{S_2O_3^{2-}}$中的$+2$升高到$\mathrm{S_4O_6^{2-}}$中的$+2.5$：对两个硫代硫酸根（四个硫）而言，升高$4 \times 0.5 = 2$，所以每个硫代硫酸根失去一个电子。两个硫代硫酸根通过一个新的$\mathrm{S{-}S}$键相连，这是一种氧化偶联。(b) 消耗的硫代硫酸根$= 18.40\times10^{-3}\ \mathrm{dm^3} \times 0.1000\ \mathrm{mol\,dm^{-3}} = 1.840\times10^{-3}\ \mathrm{mol}$。碘$= 9.200\times10^{-4}\ \mathrm{mol}$（每个$\mathrm{I_2}$对应两个硫代硫酸根），等于次氯酸根的量（每个$\mathrm{OCl^-}$对应一个$\mathrm{I_2}$）。浓度$= 9.200\times10^{-4}\ \mathrm{mol}/0.0250\ \mathrm{dm^3} = 0.0368\ \mathrm{mol\,dm^{-3}}$。这一方法具有普遍性：任何能把碘离子定量转化为碘的氧化剂都可以这样测定，因为硫代硫酸根与碘的反应快速、符合化学计量，并且终点清晰无误（淀粉–碘的蓝色络合物消失）。经典操作步骤见[[analytical-chemistry/classical-analysis]]。
:::
:::

### 硫的卤化物与较重的氧族元素

六氟化硫$\mathrm{SF_6}$是八面体分子，其十二个电子已在[[main-group/main-group-bonding#ex-sf6]]中被安排进三中心键；它在热力学上对水解不稳定，却能经受沸水或熔融碱的作用：六个氟原子屏蔽了小的硫原子，使其免受进攻，亲核试剂也没有低能量的反应途径。这种惰性使它成为高压开关设备中理想的绝缘气体，而它极长的大气寿命使它成为已知最强效的温室气体之一，如今正因此受到管控。与之相反，带有一对孤对电子的$\mathrm{SF_4}$（跷跷板形，$\mathrm{AX_4E}$）很活泼，用作氟化试剂。

硒是必需的微量元素（存在于若干种酶的硒代半胱氨酸中），过量则有毒；它的灰色同素异形体是光电导体，曾是复印机的核心。碲是类金属，用于碲化镉太阳能电池。钋由玛丽·居里和皮埃尔·居里于1898年发现，放射性极强；它的所有同位素都具有放射性，其化学只能在专门的设施中研究。

- [x] 接触法不需要高压，因为在操作温度下$\mathrm{SO_2}$氧化的$K$很大。

::: solution
在$700\ \mathrm{K}$下，$\mathrm{2\,SO_2 + O_2 \rightleftharpoons 2\,SO_3}$的$K \approx 9\times10^{4}$，所以在约$1\ \mathrm{bar}$下转化率就很高；合成氨在其操作温度下$K \approx 2\times10^{-4}$，因而需要高压。氮的不活泼是动力学上的（在弗罗斯特图上$\mathrm{NH_4^+}$位于$\mathrm{N_2}$之下，合成氨在室温下是放能的）。硫形成环是因为两个单键胜过一个双键——即双键规则。$\mathrm{PH_3}$是比$\mathrm{NH_3}$**弱**得多的布朗斯特碱，因为它的孤对电子处在弥散的、主要为$s$的轨道中。

[[main-group/halogens-noble-gases]]中的卤素完成了p区的讨论，把本章的含氧酸方法和弗罗斯特图方法推广到氯、溴和碘。固氮、固氮酶以及酶中的铁硫簇在[[coordination-chemistry/bioinorganic]]中展开；氮循环与硫循环、酸雨和平流层臭氧见[[environmental-chemistry/tropospheric-chemistry]]、[[environmental-chemistry/particulates-acid-deposition]]和[[environmental-chemistry/stratospheric-ozone]]；工业过程——哈伯-博施法、奥斯特瓦尔德法和接触法——见[[green-chemistry/industrial-inorganic]]。使铁、铂和氧化钒催化剂发挥作用的表面动力学是[[kinetics/surface-kinetics]]和[[organometallics-catalysis/heterogeneous-catalysis]]的主题。磷配体——膦——在[[organometallics-catalysis/ligands-complexes]]中处于核心地位，而磷酸酯是[[biochemistry/nucleic-acids]]的骨架。

磷是第一种其发现时间与发现者都可以确定的元素：布兰德（Hennig Brand）于1669年在汉堡蒸馏蒸干的尿液残渣而得到它，并因其发光而为之命名。氮于1772年由爱丁堡的卢瑟福（Daniel Rutherford）认识到，即燃烧和呼吸除去氧和“固定空气”之后剩下的那部分空气；氧由舍勒（Carl Wilhelm Scheele，约1771–1772年，1777年发表）和普里斯特利（Joseph Priestley，1774年）制得，并由拉瓦锡（Antoine Lavoisier）解释为燃烧的媒介。接触法由菲利普斯（Peregrine Phillips）于1831年取得专利，但直到1900年前后才实现工业化，先用铂、后用钒作催化剂。奥斯特瓦尔德（Wilhelm Ostwald）于1902年为氨催化氧化制硝酸取得专利。哈伯（Fritz Haber）于1909年在实验室中演示了氨的合成，博施（Carl Bosch）及其巴斯夫（BASF）团队，加上米塔施（Alwin Mittasch）对催化剂的系统筛选，于1913年在奥堡（Oppau）建成了第一座工厂；哈伯获得1918年度诺贝尔化学奖，博施分享了1931年的诺贝尔化学奖。玛丽·居里（Marie Curie）和皮埃尔·居里（Pierre Curie）于1898年宣布发现钋。埃特尔（Gerhard Ertl）对铁催化剂的表面科学研究确认了吸附$\mathrm{N_2}$的解离是决速步，这项工作获得了2007年诺贝尔化学奖。
:::

::: summary
- 双键规则把每一族一分为二：$\mathrm{N_2}$和$\mathrm{O_2}$是多重键双原子分子，$\mathrm{P_4}$和$\mathrm{S_8}$是单键分子，因为第二周期的$\pi$键强，较重元素的$\pi$键弱。
- 氮的惰性是动力学上的。哈伯-博施法在放热、气体分子数减少的平衡（$723\ \mathrm{K}$下$K \approx 2\times10^{-4}$）与铁催化剂上的反应速率之间取得平衡；高压挽回产率（$200\ \mathrm{bar}$下约$36\ \%$）。
- 催化剂可以选择产物：尽管$\mathrm{N_2}$是热力学产物，奥斯特瓦尔德法仍生成NO。
- 氮的弗罗斯特图表明，$\mathrm{NH_4^+}$是酸中最稳定的氧化态，硝酸根和各种氧化物是强氧化剂，而$\mathrm{HNO_2}$、羟胺和肼容易歧化。
- 较重的氢化物键角接近$90^\circ$，孤对电子碱性弱；$\mathrm{PCl_5}$在固体中是离子型的；$\mathrm{P_4O_{10}}$是笼状分子，也是强效干燥剂。
- 氧是三重态，所以它与单重态分子的反应很慢；臭氧是更强的氧化剂。
- 硫能成链（$\mathrm{S{-}S}$ $266$对$\mathrm{O{-}O}$ $146\ \mathrm{kJ\,mol^{-1}}$），拥有丰富的同素异形体和含氧阴离子，并通过接触法转化为硫酸；接触法需要催化剂和床层间冷却，但不需要高压。
:::

## 习题

::: exercise 氮的氧化态 {level=1}
给出$\mathrm{NH_4^+}$、$\mathrm{N_2H_4}$、$\mathrm{NH_2OH}$、$\mathrm{N_2O}$、$\mathrm{NO}$、$\mathrm{HNO_2}$、$\mathrm{NO_2}$和$\mathrm{HNO_3}$中氮的氧化态，并指出哪些是奇电子分子。
::: solution
$-3$、$-2$、$-1$、$+1$、$+2$、$+3$、$+4$、$+5$：氮跨越从$-3$到$+5$的全部九个氧化态（$\mathrm{N_2}$为$0$）。NO（11个价电子）和$\mathrm{NO_2}$（17个）是奇电子自由基；两者都会在一定程度上二聚，$\mathrm{NO_2}$容易二聚为$\mathrm{N_2O_4}$，NO只在固态和液态中二聚。
:::
:::

::: exercise 氨合成的转折温度 {level=1 check="463"}
利用$\mathrm{N_2 + 3\,H_2 \rightleftharpoons 2\,NH_3}$的$\Delta_\mathrm{r}H^\circ = -91.8\ \mathrm{kJ\,mol^{-1}}$和$\Delta_\mathrm{r}S^\circ = -198.1\ \mathrm{J\,K^{-1}\,mol^{-1}}$，假设两者都与温度无关，求$\Delta_\mathrm{r}G^\circ = 0$时的温度。（以K为单位输入温度，精确到开尔文。）
::: solution
$T = \Delta_\mathrm{r}H^\circ/\Delta_\mathrm{r}S^\circ = 91\,800/198.1 = 463\ \mathrm{K}$。低于此温度$K > 1$，高于此温度$K < 1$；工业过程在远高于此温度下运行，因为催化剂需要热量，如[[#warn-le-chatelier]]所述。
:::
:::

::: exercise 用价层电子对互斥理论判断形状 {level=1}
预测$\mathrm{NO_2^+}$、$\mathrm{NO_2^-}$、$\mathrm{SO_3}$、$\mathrm{SO_3^{2-}}$、$\mathrm{SF_4}$和$\mathrm{[PCl_6]^-}$的形状。
::: solution
$\mathrm{NO_2^+}$：两个成键区域，N上无孤对电子，直线形（与$\mathrm{CO_2}$等电子）。$\mathrm{NO_2^-}$：两个成键区域加一对孤对电子，弯曲形（约$115^\circ$）。$\mathrm{SO_3}$：三个区域，平面三角形。$\mathrm{SO_3^{2-}}$：三个键和一对孤对电子，三角锥形。$\mathrm{SF_4}$：四个键和一对孤对电子，$\mathrm{AX_4E}$，跷跷板形，孤对电子处于赤道位置。$\mathrm{[PCl_6]^-}$：六个键，八面体形。
:::
:::

::: exercise 处于极限的SO₂转化器 {level=2 check="1052"}
对于$\mathrm{2\,SO_2 + O_2 \rightleftharpoons 2\,SO_3}$，$\Delta_\mathrm{r}H^\circ = -197.8\ \mathrm{kJ\,mol^{-1}}$。由$S^\circ$（$\mathrm{J\,K^{-1}\,mol^{-1}}$）：$\mathrm{SO_3}$ $256.8$，$\mathrm{SO_2}$ $248.2$，$\mathrm{O_2}$ $205.2$计算$\Delta_\mathrm{r}S^\circ$，并求$K = 1$时的温度。（以K为单位输入温度，精确到开尔文。）
::: solution
$\Delta_\mathrm{r}S^\circ = 2(256.8) - 2(248.2) - 205.2 = -188.0\ \mathrm{J\,K^{-1}\,mol^{-1}}$（主要来自一摩尔气体的消失）。$\Delta_\mathrm{r}G^\circ = 0$时$K = 1$：$T = 197\,800/188.0 = 1052\ \mathrm{K}$。温度接近此值的绝热催化剂床层几乎不再生成$\mathrm{SO_3}$，这就是要在床层之间冷却气体的原因。
:::
:::

::: exercise 铜盐的碘量法测定 {level=2 check="0.0920"}
铜(II)能氧化碘离子：$\mathrm{2\,Cu^{2+} + 4\,I^- \rightarrow 2\,CuI(s) + I_2}$。取$25.00\ \mathrm{cm^3}$硫酸铜(II)溶液，用过量KI处理，析出的碘消耗$0.1000\ \mathrm{mol\,dm^{-3}}$硫代硫酸钠$23.00\ \mathrm{cm^3}$。求$\mathrm{Cu^{2+}}$的浓度，并解释为什么尽管$E^\circ(\mathrm{Cu^{2+}/Cu^+}) = 0.15\ \mathrm{V}$小于$E^\circ(\mathrm{I_2/I^-}) = 0.54\ \mathrm{V}$，该反应仍能进行。（以$\mathrm{mol\,dm^{-3}}$为单位输入浓度，保留三位有效数字。）
::: solution
硫代硫酸根$= 2.300\times10^{-3}\ \mathrm{mol}$；$\mathrm{I_2} = 1.150\times10^{-3}\ \mathrm{mol}$；$\mathrm{Cu^{2+}} = 2 \times 1.150\times10^{-3} = 2.300\times10^{-3}\ \mathrm{mol}$（每个$\mathrm{I_2}$对应两个$\mathrm{Cu^{2+}}$，故每个硫代硫酸根对应一个$\mathrm{Cu^{2+}}$）。浓度$= 2.300\times10^{-3}/0.02500 = 0.0920\ \mathrm{mol\,dm^{-3}}$。标准电势针对的是水合$\mathrm{Cu^+}$；而这里铜(I)以CuI沉淀（$K_\mathrm{sp} \approx 10^{-12}$），使$[\mathrm{Cu^+}]$大大降低，把$\mathrm{Cu^{2+}/CuI}$电对的有效电势提高到约$0.86\ \mathrm{V}$——高于碘的电势。沉淀与配位一样会移动电势，正如[[main-group/inorganic-redox]]中金–氰化物的例子。
:::
:::

::: exercise NO₂的二聚 {level=2 check="6.74"}
对于$\mathrm{2\,NO_2(g) \rightleftharpoons N_2O_4(g)}$，$298.15\ \mathrm{K}$下$\mathrm{NO_2}$的$\Delta_\mathrm{f}G^\circ$为$51.31\ \mathrm{kJ\,mol^{-1}}$，$\mathrm{N_2O_4}$为$97.89\ \mathrm{kJ\,mol^{-1}}$。计算$K$，并定性预测密封管中的平衡混合物在(a) 加热和(b) 压缩时颜色如何变化。（$\Delta_\mathrm{r}H^\circ = -57.2\ \mathrm{kJ\,mol^{-1}}$。）（输入$K$，保留三位有效数字。）
::: solution
$\Delta_\mathrm{r}G^\circ = 97.89 - 2(51.31) = -4.73\ \mathrm{kJ\,mol^{-1}}$；$K = \exp(4730/(8.314 \times 298.15)) = 6.74$。(a) 二聚放热，所以加热使平衡移向棕色的$\mathrm{NO_2}$，气体颜色变深。(b) 压缩起初使气体颜色变深（同样多的分子处在更小的体积中），随后由于平衡移向分子数较少的一侧，即无色的$\mathrm{N_2O_4}$，颜色有所变浅。两种效应都是标准的演示实验；$\mathrm{NO_2}$吸入有毒，所以管子是密封的。
:::

::: exercise 氮的弗罗斯特图 {level=2}
根据图中各点，(a) 求八电子电对$\mathrm{NO_3^-/NH_4^+}$的电势；(b) 证明羟胺倾向于歧化为$\mathrm{N_2}$和$\mathrm{NH_4^+}$而不稳定；(c) 解释为什么$\mathrm{N_2}$虽然不是最低点，却是自然界中含氮化合物被氧化或还原时通常的最终产物。
::: solution
(a) $\mathrm{NH_4^+}\ (-3, -0.815)$与$\mathrm{NO_3^-}\ (5, 6.229)$之间的斜率为$(6.229 + 0.815)/8 = 0.88\ \mathrm{V}$。(b) 从$\mathrm{NH_4^+}\ (-3, -0.815)$到$\mathrm{N_2}\ (0, 0)$的弦在$(-1)$处的高度为$-0.815 \times 1/3 = -0.27$；羟胺位于$(-1, 1.87)$，远在其上方，所以$\mathrm{3\,NH_3OH^+ \rightarrow N_2 + NH_4^+ + 2\,H^+ + 3\,H_2O}$是强烈有利的。(c) $\mathrm{N_2}$接近底部，仅比$\mathrm{NH_4^+}$高$0.82\ \mathrm{V}$（按三个电子计），并且在动力学上几乎惰性：一旦生成，在常温下没有催化剂就不会被进一步还原或氧化。因此经过$\mathrm{N_2}$的反应就停在那里，这就是为什么土壤中的反硝化作用把氮以$\mathrm{N_2}$（和少量$\mathrm{N_2O}$）而不是铵的形式返回大气。
:::

::: exercise 合成氨中的压力 {level=3}
利用$723\ \mathrm{K}$下的$K = 1.93\times10^{-4}$和[[#ex-haber]]的方法，(a) 证明在低转化率下，氨的摩尔分数近似与压力成正比；(b) 用这一近似估计$100\ \mathrm{bar}$下的$x_{\mathrm{NH_3}}$，并与精确解$\xi = 0.403$比较；(c) 解释为什么工业界不干脆采用$1000\ \mathrm{bar}$。
::: hint
当$\xi \ll 1$时，把$(4 - 2\xi)$换成$4$，把$(1 - \xi)$换成$1$，然后解出$\xi$。
:::
::: solution
(a) 对小的$\xi$：$4\xi^2 \times 16/27 \approx K(p/p^\circ)^2$，所以$\xi \approx \sqrt{27K/64}\,(p/p^\circ)$，且$x_{\mathrm{NH_3}} \approx 2\xi/4 = \xi/2$，两者都与$p$成正比。(b) $\sqrt{27 \times 1.93\times10^{-4}/64} = 9.02\times10^{-3}$，所以在$100\ \mathrm{bar}$下$\xi \approx 0.902$，$x \approx 0.45$——这一近似严重失效，因为转化率并不小。精确解$\xi = 0.403$给出$x = 0.806/3.194 = 0.252$。线性估计只在几巴下有效；在工业压力下$(1 - \xi)^4$项不可忽略，产率的增长远慢于$p$（从$100\ \mathrm{bar}$下的$25\ \%$到$200$下的$36\ \%$）。(c) 产率的收益递减、压缩能耗与厚壁容器成本的急剧上升，以及高温高压下氢对钢的脆化，都限制了压力。早期的工厂确实在高达约$1000\ \mathrm{bar}$下运行（克洛德法），但现代工厂在较低压力下使用更好的催化剂并加以循环；最优值是经济上的，而不是热力学上的。
:::

::: exercise 硫代硫酸根与氧化态之谜 {level=3}
硫代硫酸根由亚硫酸盐溶液与硫一起煮沸制得：$\mathrm{SO_3^{2-} + S \rightarrow S_2O_3^{2-}}$。(a) 利用这一合成推断其结构，并给两个硫原子指定氧化态。(b) 在酸中，硫代硫酸根分解：$\mathrm{S_2O_3^{2-} + 2\,H^+ \rightarrow S + SO_2 + H_2O}$。对这一反应进行分类。(c) 在合成中以单质硫形式引入的$^{35}\mathrm{S}$标记，在酸分解后全部出现在单质硫中。这说明了什么？
::: hint
亚硫酸根的硫上有一对孤对电子。把单质硫原子看作与之结合的路易斯酸。
:::
::: solution
(a) 亚硫酸根中硫的孤对电子进攻硫环，加上一个硫原子：硫代硫酸根是$\mathrm{[S{-}SO_3]^{2-}}$，即硫酸根的一个氧被硫取代所得的四面体。如果新加入的硫保持其$0$（它来自单质），则中心硫保持亚硫酸根的$+4$——平均值$+2$掩盖了两个截然不同的原子。（若改为把$\mathrm{S{-}S}$键按离子方式分配给端基硫，则得到$+6$和$-2$；两种描述都只是记账。）(b) 形式上它是合成反应的逆反应：端基硫以单质硫（$0$）离开，中心硫以$\mathrm{SO_2}$（$+4$）离开；按平均氧化态（$+2 \rightarrow 0$和$+4$）看，它是歧化反应。(c) 两个硫原子并不交换：以单质形式加入的那个原子正是回到单质的那个原子。这证实了(a)中两个硫不等同的结构，并表明平均氧化态歪曲了化学实质。这类同位素标记实验是硫代硫酸根结构最早的证据之一。
:::
