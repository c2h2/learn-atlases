一份汽油样品含有数百种烃；一份血液血浆提取液可能含一种药物、它的三种代谢物和一千种内源化合物；一种精油含一百种萜烯，彼此只差一个双键的位置。任何光谱仪都无法在这样的混合物中可靠地测定某一种化合物——信号相互重叠。几乎每个分析实验室都在使用的解决办法，是先分离、后测量。**色谱法**让混合物的各组分随流动相流经固定相，各组分被保留的程度取决于它对固定相的亲和力，从而把各组分分开。现代气相色谱仪一小时能分辨数百种化合物；液相色谱仪联用检测器，能测定血浆中每毫升纳克级的药物。

这一思想以及最简单的形式——薄层、纸和柱色谱，比移值$R_\mathrm{F}$，以及分配与保留之间的联系——见[[laboratory-methods/chromatography-basics]]。本章建立仪器色谱所用的定量理论：用保留因子和选择性因子描述保留；用塔板高度和范第姆特（van Deemter）方程描述谱带展宽；再把两者结合起来、并在两个峰重叠时告诉我们应该改变什么的**分离度**。然后我们考察两大仪器技术——气相色谱与高效液相色谱——它们的色谱柱和检测器，以及色谱峰如何变成定量结果。

## 保留

在柱色谱中，样品以窄谱带的形式注入柱头；流动相携带它流过色谱柱；柱出口处的检测器记录一张**色谱图**——信号对时间的曲线，每个被分离的组分对应一个峰。完全不与固定相相互作用的化合物在**死时间**（滞留时间）$t_\mathrm{M}$流出，即流动相流过色谱柱所需的时间。被保留的化合物较晚流出，流出的时刻是它的**保留时间**$t_\mathrm{R}$；差值$t_\mathrm{R}' = t_\mathrm{R} - t_\mathrm{M}$是**调整保留时间**，即它花在固定相中的时间。

::: definition 保留因子、分配系数与选择性因子 {#def-retention}
设溶质在柱内固定相（体积$V_\mathrm{S}$）与流动相（体积$V_\mathrm{M}$）之间分配，**分配系数**为$K = c_\mathrm{S}/c_\mathrm{M}$，即其平衡浓度之比。**保留因子**（容量因子）是两相中物质量之比，
$$
k = \frac{n_\mathrm{S}}{n_\mathrm{M}} = K\frac{V_\mathrm{S}}{V_\mathrm{M}} = \frac{K}{\beta},
$$
其中$\beta = V_\mathrm{M}/V_\mathrm{S}$是**相比**。对满足$k_2 > k_1$的两个溶质，**选择性因子**（分离因子）为$\alpha = k_2/k_1 = K_2/K_1 > 1$。
:::

::: proposition 保留时间与保留因子 {#prop-retention-time}
若色谱柱各处的分配平衡建立得足够快，溶质谱带就以流动相线速度的$1/(1+k)$这一分数向前移动，于是
$$
t_\mathrm{R} = t_\mathrm{M}(1 + k), \qquad k = \frac{t_\mathrm{R} - t_\mathrm{M}}{t_\mathrm{M}} .
$$ {#eq-retention}
:::

::: proof
溶质分子只在处于流动相中时才移动，此时速度为流动相的线速度$u$。平衡时，任一时刻处于流动相中的溶质分数为$n_\mathrm{M}/(n_\mathrm{M} + n_\mathrm{S}) = 1/(1+k)$。按遍历性论证——某一时刻处于流动相中的分子分数，等于单个分子在长时间内停留在其中的时间分数——每个分子以速度$u$运动的时间分数为$1/(1+k)$，所以谱带的平均速度为$u/(1+k)$。柱长$L = ut_\mathrm{M} = [u/(1+k)]\,t_\mathrm{R}$，由此得到[[#eq-retention]]。
:::

保留因子在约$1$到$10$之间是使用上最有利的范围：低于$1$时，化合物流出得太接近死时间，无法与其他弱保留的化合物分开；高于$10$–$20$时，分析变慢，峰又宽又矮。选择性是分离的化学所在：$\alpha$取决于固定相、流动相（在液相色谱中）和温度；最能决定两种化合物究竟能否分开的，正是$\alpha$而不是别的什么。

## 谱带展宽与塔板高度

以窄塞形式注入的谱带到达检测器时，已展宽成一个大致高斯型的峰。展宽来自若干随机过程，其中每个过程都给谱带的位置增加一份方差。衡量一根色谱柱柱效的，是它按行进距离的比例把谱带展宽得有多小。

::: definition 理论塔板数与塔板高度 {#def-plates}
对标准偏差为$\sigma$（以时间计）、在$t_\mathrm{R}$处流出的高斯峰，**理论塔板数**为
$$
N = \left(\frac{t_\mathrm{R}}{\sigma}\right)^2 = 5.545\left(\frac{t_\mathrm{R}}{w_{1/2}}\right)^2 = 16\left(\frac{t_\mathrm{R}}{w_\mathrm{b}}\right)^2,
$$ {#eq-plates}
其中$w_{1/2} = 2\sqrt{2\ln2}\,\sigma = 2.355\sigma$是半峰宽，$w_\mathrm{b} = 4\sigma$是峰底宽（拐点处切线与基线交点之间的宽度）。**塔板高度**（理论塔板高度）为$H = L/N$，即每块塔板对应的柱长；用长度单位表示，$H = \sigma_L^2/L$，即谱带方差除以单位行进长度。$H$小意味着柱效高。
:::

"塔板"这一说法来自与蒸馏塔的类比——在蒸馏塔中每块塔板是一个平衡级；在色谱中它不过是单位长度方差的度量，其所以有用，是因为各独立展宽过程的方差可以相加。

::: proposition 范第姆特方程 {#prop-van-deemter}
对填充柱或开口管柱，塔板高度与流动相线速度$u$的关系近似为
$$
H = A + \frac{B}{u} + Cu,
$$ {#eq-van-deemter}
其中$A$描述通过填充床的**多条路径**（涡纹扩散）（对直径为$d_\mathrm{p}$的颗粒，$A \approx 2\lambda d_\mathrm{p}$，$\lambda$是量级为$1$的填充因子；开口管中$A = 0$），$B = 2\gamma D_\mathrm{M}$描述溶质在流动相中的**纵向扩散**（扩散系数$D_\mathrm{M}$，$\gamma \le 1$是障碍因子），$C$描述相之间和相内部的**传质阻力**，正比于$d_\mathrm{p}^2/D_\mathrm{M}$（对厚度为$d_\mathrm{f}$的固定相液膜则正比于$d_\mathrm{f}^2/D_\mathrm{S}$）。$H$有极小值
$$
H_\mathrm{min} = A + 2\sqrt{BC} \quad\text{当}\quad u_\mathrm{opt} = \sqrt{B/C} .
$$ {#eq-optimum}
:::

::: proof
每种机理都贡献单位长度的独立方差，所以$H = \sum_i H_i$。*纵向扩散*：谱带在柱中停留的时间为$t = L/u_\mathrm{band}$，在此期间溶质沿轴向扩散，增加方差$\sigma_L^2 = 2Dt$（随机走动的爱因斯坦关系）。起作用的时间是在流动相中度过的时间$L/u$，于是$\sigma_L^2 = 2\gamma D_\mathrm{M}L/u$，$H = \sigma_L^2/L = 2\gamma D_\mathrm{M}/u = B/u$。*多条路径*：在填充床中，分子沿长短不一的通道行进；若每个分子走$L/d_\mathrm{p}$步、每步长约$d_\mathrm{p}$的随机行程（相对平均位置向前或向后），则方差的量级为$(L/d_\mathrm{p})d_\mathrm{p}^2 = Ld_\mathrm{p}$，与$u$无关，故$H \approx 2\lambda d_\mathrm{p} = A$。*传质*：分子扩散进入或离开固定相或静止孔道需要有限的时间；在这段时间里，流动相把它们的邻居带走了正比于$u$乘以交换时间（$\propto d^2/D$）的一段距离。步长$\ell \propto ud^2/D$、发生频率$\propto D/d^2$的随机走动，在柱中停留时间$\propto L/u$之内，给出方差$\propto (L/u)(D/d^2)(ud^2/D)^2 = Lud^2/D$，故$H = Cu$，其中$C \propto d^2/D$。三项相加即得[[#eq-van-deemter]]。令$\dd H/\dd u = -B/u^2 + C = 0$，得$u_\mathrm{opt} = \sqrt{B/C}$，再代回得$H_\mathrm{min} = A + B\sqrt{C/B} + C\sqrt{B/C} = A + 2\sqrt{BC}$。
:::

::: example 从色谱图上求柱效 {#ex-efficiency}
在一根$15.0\ \mathrm{cm}$的HPLC色谱柱上，某峰在$t_\mathrm{R} = 8.25\ \mathrm{min}$流出，半峰宽$0.110\ \mathrm{min}$。求$N$与$H$，并把$H$与$3.0\ \mu\mathrm{m}$的颗粒直径作比较。
::: solution
由[[#eq-plates]]，
$$
N = 5.545\left(\frac{8.25}{0.110}\right)^2 = 5.545\times5625 = 3.12\times10^{4},\qquad H = \frac{L}{N} = \frac{150\ \mathrm{mm}}{3.12\times10^4} = 4.8\ \mu\mathrm{m}.
$$
这是$1.6$个颗粒直径。装填良好、在近最优线速度下操作的色谱柱给出$H \approx 2$–$3\,d_\mathrm{p}$（**折合塔板高度**$h = H/d_\mathrm{p}$为$2$–$3$），所以这根柱的表现非常出色。在半峰高处测量更受青睐，因为它较少受峰拖尾以及画切线之困难的影响。
:::
:::

并非所有的峰都是高斯型的。**拖尾**（后沿拉长）源于强吸附位点——对碱性分析物，即硅胶上电离的残余硅醇基——以及超载或受损的色谱柱；**前伸**则由等温线朝另一方向弯曲的色谱柱超载所致。两者都损害分离度和定量，峰不对称因子是一项例行的系统适用性检查。

## 分离度

如果两个峰最大值之间的距离相对于它们的宽度来说足够大，这两个峰就分开了。

::: proposition 分离度方程 {#prop-resolution}
相邻两峰的**分离度**为
$$
R_\mathrm{s} = \frac{t_{\mathrm{R}2} - t_{\mathrm{R}1}}{\tfrac12(w_{\mathrm{b}1} + w_{\mathrm{b}2})} .
$$
对于一根$N$块塔板的色谱柱上宽度相近的两个峰，它可以写成**Purnell方程**
$$
R_\mathrm{s} = \frac{\sqrt{N}}{4}\cdot\frac{\alpha - 1}{\alpha}\cdot\frac{k_2}{1 + k_2},
$$ {#eq-purnell}
它把控制分离度的三个因素分离开来：柱效$N$、选择性$\alpha$和保留$k$。$R_\mathrm{s} = 1.0$意味着等高的高斯峰约有$2\ \%$重叠；$R_\mathrm{s} = 1.5$（"基线分离"）只留下约$0.1\ \%$。
:::

::: proof
取第二个峰的峰底宽度代表两者：由[[#eq-plates]]，$\tfrac12(w_{\mathrm{b}1} + w_{\mathrm{b}2}) \approx w_{\mathrm{b}2} = 4t_{\mathrm{R}2}/\sqrt{N}$。利用[[#eq-retention]]，$t_{\mathrm{R}2} - t_{\mathrm{R}1} = t_\mathrm{M}(k_2 - k_1)$，且$t_{\mathrm{R}2} = t_\mathrm{M}(1 + k_2)$。于是
$$
R_\mathrm{s} = \frac{t_\mathrm{M}(k_2 - k_1)}{4t_\mathrm{M}(1+k_2)/\sqrt{N}} = \frac{\sqrt{N}}{4}\cdot\frac{k_2 - k_1}{1 + k_2} = \frac{\sqrt{N}}{4}\cdot\frac{k_2 - k_1}{k_2}\cdot\frac{k_2}{1 + k_2},
$$
而$(k_2 - k_1)/k_2 = 1 - 1/\alpha = (\alpha - 1)/\alpha$。对等高的两个高斯峰，$R_\mathrm{s}$就是以$4\sigma$为单位的间距；越过两峰中点后尾部的重叠，对每个峰都是$\Phi(-2R_\mathrm{s})$，在$R_\mathrm{s} = 1$时为$2.3\ \%$，在$1.5$时为$0.13\ \%$。
:::

:::

Purnell方程是方法开发的配方。**柱效**只以$\sqrt{N}$进入：柱长加倍使$N$加倍（分析时间也加倍），却只把$R_\mathrm{s}$提高到$\sqrt{2} = 1.41$倍。**保留**通过$k/(1+k)$起作用，它从$k = 0$起陡升到约$k = 5$，然后趋于平坦：把$k$提高到约$5$–$10$以上，换来的分离度很少，花费的时间却很多。**选择性**是最有威力的杠杆：$\alpha$从$1.05$变到$1.10$，$(\alpha-1)/\alpha$几乎加倍，而要用柱效赶上来得用四倍的塔板。因此，通常首先尝试的变动是更换固定相、改变流动相的溶剂或pH，或改变温度。

::: example 分离难分物对所需的塔板数 {#ex-plates-needed}
两种异构体的$\alpha = 1.050$，$k_2 = 5.0$。要达到$R_\mathrm{s} = 1.5$需要多少块塔板？若换一种固定相，在$k$相同的情况下把$\alpha$提高到$1.10$，结果又如何？
::: solution
把[[#eq-purnell]]重排，
$$
N = 16R_\mathrm{s}^2\left(\frac{\alpha}{\alpha - 1}\right)^2\left(\frac{1 + k_2}{k_2}\right)^2 = 16\times2.25\times\left(\frac{1.050}{0.050}\right)^2\times\left(\frac{6.0}{5.0}\right)^2 = 16\times2.25\times441\times1.44 = 2.29\times10^4 .
$$
取$\alpha = 1.10$：$(1.10/0.10)^2 = 121$代替$441$，于是$N = 6.3\times10^3$——柱长只需四分之一，分析时间也只有四分之一。[[#ex-efficiency]]中那根$15\ \mathrm{cm}$的柱（约$3\times10^4$块塔板）足以应付第一种情形；$5\ \mathrm{cm}$的柱就能应付第二种。
:::
:::

::: example 读一张色谱图 {#ex-chromatogram}
未被保留的标记物在$1.20\ \mathrm{min}$流出；两个化合物分别在$5.40$和$5.90\ \mathrm{min}$流出，峰底宽度分别为$0.30$和$0.32\ \mathrm{min}$。求$k_1$、$k_2$、$\alpha$、$R_\mathrm{s}$，以及由第二个峰得到的理论塔板数；然后用[[#eq-purnell]]核对$R_\mathrm{s}$。
::: solution
由[[#eq-retention]]：$k_1 = (5.40 - 1.20)/1.20 = 3.50$，$k_2 = (5.90 - 1.20)/1.20 = 3.92$，故$\alpha = 3.92/3.50 = 1.119$。分离度：$R_\mathrm{s} = 0.50/(\tfrac12\times0.62) = 1.61$。塔板数：$N = 16(5.90/0.32)^2 = 5.4\times10^3$。Purnell方程：$R_\mathrm{s} = (\sqrt{5439}/4)(0.119/1.119)(3.92/4.92) = 18.44\times0.1064\times0.797 = 1.56$，与直接测得的值合理一致；小小的差异来自用第二个峰的宽度代表两个峰的宽度。
:::
:::

## 气相色谱法

在**气相色谱**（GC）中，流动相是惰性的载气（氦气、氢气或氮气），固定相是液膜或固体吸附剂。样品必须挥发且热稳定——粗略地说，摩尔质量约在$500\ \mathrm{g\,mol^{-1}}$以下、沸点低于$400$–$450\ ^\circ\mathrm{C}$；羧酸、糖和氨基酸等极性化合物通过**衍生化**（硅烷化、甲基化、酰化）变成挥发性的。

现代GC使用**开口管（毛细管）柱**：内径$0.1$–$0.53\ \mathrm{mm}$、长$10$–$60\ \mathrm{m}$的熔融石英管，内壁涂有$0.1$–$5\ \mu\mathrm{m}$厚的交联聚硅氧烷或聚乙二醇液膜。因为没有填充物，$A = 0$且压降很小，所以柱子可以做得很长，$N$可达$10^5$以上。固定相决定选择性，遵循"相似相溶"的原则：非极性的聚（二甲基硅氧烷）主要按沸点分离，而极性的聚乙二醇（"蜡"）相对醇类及其他形成氢键的化合物保留很强。样品经加热的**分流/不分流进样口**引入：浓样品只有一部分进入色谱柱（分流模式）；痕量分析则让整个样品全部转移（不分流模式）。

温度是GC中控制保留的主要变量，因为$\ln K$随$1/T$线性变化（范特霍夫关系）：温度每升高$15$–$30\ \mathrm{K}$，保留时间通常减半。对挥发性跨度大的混合物，采用**程序升温**——在运行过程中升高柱温——让挥发性化合物在低温下流出（此时它们分得好），重质化合物随后流出而不过分展宽，从而使整个色谱图上的峰宽大致相近。

保留时间取决于柱的尺寸、流速和温度，因此在实验室之间传递时使用的是**保留指数**：它把化合物标在一条由正构烷烃定义的标尺上。

::: definition Kováts保留指数 {#def-kovats}
在恒温条件下，若某化合物的调整保留时间$t_\mathrm{R}'$落在含$n$个和$n + 1$个碳原子的正构烷烃的调整保留时间之间，其**保留指数**为
$$
I = 100\left[n + \frac{\log t_\mathrm{R}'(\text{化合物}) - \log t_\mathrm{R}'(n)}{\log t_\mathrm{R}'(n+1) - \log t_\mathrm{R}'(n)}\right] .
$$
按定义，含$n$个碳原子的正构烷烃在任何固定相上的$I$都等于$100n$。对数插值反映的是同一同系物内$\log t_\mathrm{R}'$随碳原子数的线性依赖。（程序升温时，改为对保留时间本身、而不是其对数作线性内插。）
:::

::: example 一个保留指数 {#ex-kovats}
恒温下，在聚（二甲基硅氧烷）柱上测得调整保留时间：正己烷$4.20\ \mathrm{min}$，正庚烷$7.50\ \mathrm{min}$，某未知物$5.90\ \mathrm{min}$。求该未知物的保留指数。
::: solution
$$
I = 100\left[6 + \frac{\log5.90 - \log4.20}{\log7.50 - \log4.20}\right] = 100\left[6 + \frac{0.1476}{0.2518}\right] = 100\times6.586 = 659 .
$$
使用相同固定相的实验室之间，保留指数可重现到几个单位以内；标准固定相上的指数库与质谱一起用于化合物的鉴定。若某化合物的质谱与库中条目相符、保留指数却相差$50$个单位，那它很可能不是那个化合物。
:::
:::

**GC检测器。** **氢火焰离子化检测器**（FID）让柱流出物在氢气-空气火焰中燃烧；有机化合物产生离子（经由$\mathrm{CH}$自由基和化学电离），被收集为大致与碳原子数成正比的电流。它灵敏（每秒皮克级的碳）、在约$10^7$范围内呈线性，并对几乎所有有机化合物都有响应，而对水、空气和二氧化碳没有响应，这使它成为使用最广的主力检测器。**热导检测器**对包括永久性气体在内的一切都有响应，但灵敏度较低。**电子捕获检测器**（ECD）用放射性$\beta$源（$^{63}\mathrm{Ni}$）维持一支恒定电流，能捕获电子的化合物——首先是卤代化合物——使该电流减小；它用于以飞克级水平测定有机氯农药和多氯联苯。元素选择性检测器对氮和磷（NPD）或硫有响应。而信息量最大的检测器——**质谱仪**——是[[analytical-chemistry/hyphenated-methods]]的主题。

## 高效液相色谱法

在**高效液相色谱**（HPLC）中，流动相是液体，以高压泵输送，流过装有细小颗粒的色谱柱——通常是直径$1.7$–$5\ \mu\mathrm{m}$的多孔二氧化硅，表面化学键合了固定相。GC做不了的样品HPLC能做：难挥发、极性、离子型、热不稳定和大分子——大多数药物、生物分子、染料和聚合物。

占主导地位的模式是**反相**色谱：非极性固定相（键合到硅胶上的十八烷基，"C18"链）配极性流动相（水掺乙腈或甲醇）。保留随溶质疏水性的增大而增强，随流动相中有机相比例的增加而减弱；作为经验规则，$\log k$随有机改性剂体积分数大致线性下降，有机相每增加$10\ \%$，$k$约降为二到三分之一。因此在HPLC中，流动相是主要的变量，正如温度之于GC。对可电离的分析物，（缓冲）流动相的pH控制电离分数，从而控制保留——这正是[[analytical-chemistry/equilibria-in-analysis]]中$\alpha$函数在起作用。**梯度洗脱**——运行过程中有机相比例不断升高——就是程序升温在液相中的对应物。其他模式还包括**正相**色谱（极性固定相、非极性溶剂）、测定极强极性化合物的**亲水作用**色谱（HILIC）、测定无机离子和氨基酸的**离子交换**与**离子色谱**（配抑制器和电导检测），以及按尺寸分离聚合物和蛋白质、用于测定摩尔质量分布的**体积排阻**色谱（[[polymer-chemistry/polymer-characterisation]]）。

HPLC的发展趋势是颗粒越来越小。由于$A \propto d_\mathrm{p}$、$C \propto d_\mathrm{p}^2$，$d_\mathrm{p}$减半大致使$H_\mathrm{min}$减半，并把$u_\mathrm{opt}$推向更高的速度，从而允许在同样的分离度下用更短的柱、做更快的分析。代价是压力：按达西（Darcy）定律，填充床两端的压降正比于$uL\eta/d_\mathrm{p}^2$，所以亚$2\ \mu\mathrm{m}$颗粒要求额定压力$100\ \mathrm{MPa}$以上的泵（**超高效**液相色谱，UHPLC）。表面多孔（"核-壳"）颗粒以实心为核、多孔薄壳为层，缩短了扩散路径，在较低压力下就能获得大致相同的增益。

**HPLC检测器。** **紫外-可见吸光度检测器**最常见，常用的是二极管阵列，每几分之一秒记录一张完整光谱；它在一支光程约$10\ \mathrm{mm}$、体积几微升的流动池中服从[[analytical-chemistry/molecular-spectrometry]]的比尔-朗伯（Beer–Lambert）定律，而沿峰各处记录的光谱可以检验峰是否为纯物质。**荧光**检测器对有荧光或经衍生的分析物更灵敏、更有选择性。**示差折光**检测器是通用型的，但不灵敏且与梯度洗脱不兼容；**蒸发光散射**检测器和**带电气溶胶**检测器对非挥发性分析物近乎通用。**电化学**检测器在电极上氧化或还原分析物（[[analytical-chemistry/electroanalytical]]），而质谱仪则再次是最强大的。

::: warning 峰面积不等于物质量 {#warn-response}
人们很容易把色谱图直接读成组成：一个峰的面积是另一个的两倍，该化合物的量就一定多一倍。只有对响应因子对所有化合物都相同的检测器，这个说法才成立，而几乎没有任何检测器如此。紫外检测器的响应正比于所选波长处的$\varepsilon$，不同化合物的$\varepsilon$可能相差几个数量级；FID大致按碳原子数成比例响应，但对连有氧或卤素的碳响应弱得多；ECD的响应可相差百万倍。定量必须对每种分析物分别校准，最好使用内标（[[analytical-chemistry/statistics-calibration#def-internal-standard]]）。还有两点告诫：单一对称的峰并不是单一化合物的证明（共洗脱很常见；要用第二根柱、另一个波长或一张质谱去核查）；当峰宽变化时，稳健的度量是面积而不是峰高。
:::

## 从色谱峰到结果

定量色谱对每个峰作积分，再通过校准把面积与浓度联系起来。**外标**法用单独进样的标准溶液建立校准；它依赖可重现的进样体积——现代自动进样器能做到（相对标准偏差约$0.2$–$0.5\ \%$）。**内标**法向每个样品和标准中加入已知量的不干扰化合物，使用面积比，从而消去进样体积的波动；如果内标是在样品制备之前加入的，还能消去萃取过程中的损失。对复杂样品，**标准加入法**校正检测器中的基体效应。每次运行前的**系统适用性**试验——对关键物对的分离度、理论塔板数、峰不对称性以及重复进样的重复性——检验色谱柱和仪器当天是否适合该分析之用。

::: quiz
在反相柱上，两个峰的$k_2 = 2$，只有部分分离（$R_\mathrm{s} = 0.9$）。单独作哪一项改动，最有可能高效地达到基线分离？
- [ ] 把柱长加倍。
- [ ] 提高流速，让峰变锐。
- [x] 更换有机改性剂（例如从甲醇换成乙腈）或改变pH，以改变$\alpha$。
- [ ] 注入更大的体积，让峰变大。
::: solution
柱长加倍给出$R_\mathrm{s} = 0.9\times\sqrt{2} = 1.27$：仍非基线分离，时间却用两倍。在最优值以上继续提高流速，会经$Cu$项*增大*$H$，反而降低分离度。加大进样量会使峰展宽。改变选择性——甲醇与乙腈的氢键和偶极特性不同，pH则改变酸性、碱性溶质的电离——可以改变$\alpha$；[[#eq-purnell]]表明$\alpha$是最有效的杠杆。（降低洗脱强度、把$k_2$从$2$提到$5$附近也会有帮助，可使$k/(1+k)$从$0.67$升到$0.83$。）
:::
:::

## 后续内容

把GC和HPLC与质谱联用——以及用同位素标记内标定量——是[[analytical-chemistry/hyphenated-methods]]的主题。用于纯化的制备色谱与快速柱色谱见[[laboratory-methods/separation-purification]]。聚合物的体积排阻色谱在[[polymer-chemistry/polymer-characterisation]]中讨论，污染物的气相与液相色谱分析在[[environmental-chemistry/environmental-monitoring]]中。作为$K之基础的分配热力学，见[[thermodynamics/mixtures]]。

::: history
米哈伊尔·茨维特（Tsvet）在碳酸钙柱上分离植物色素，并于1906年的论文中为这一方法命名为色谱法。阿彻·马丁（Martin）与理查德·辛格（Synge）在1941年引入了分配色谱和塔板理论（1952年获诺贝尔化学奖），同一篇论文中还提出流动相可以是气体；安东尼·詹姆斯（James）与马丁于1952年实现了气液色谱。范第姆特（van Deemter）、苏茨魏格（Zuiderweg）与克林根贝格（Klinkenberg）于1956年发表了他们的塔板高度方程。马塞尔·戈雷（Golay）于1957年引入开口管柱；1979年，赫利特-帕卡德公司的丹德诺（Dandeneau）与泽伦纳（Zerenner）推出了柔性熔融石英毛细管柱。埃尔文·科瓦茨（Kováts）于1958年提出了他的保留指数。詹姆斯·洛夫洛克（Lovelock）在20世纪50年代末发明了电子捕获检测器。高效液相色谱成长于20世纪60年代末霍尔瓦特（Horváth）、休伯（Huber）、柯克兰（Kirkland）等人的工作之上；1975年，哈米什·斯莫尔（Small）及其合作者推出了带电导检测的离子色谱。
:::

::: summary
- 保留：$t_\mathrm{R} = t_\mathrm{M}(1+k)$，保留因子$k = K/\beta$；选择性$\alpha = k_2/k_1$；有用的$k$值约在$1$到$10$之间。
- 柱效：$N = (t_\mathrm{R}/\sigma)^2 = 5.545(t_\mathrm{R}/w_{1/2})^2$，$H = L/N$；装填良好的柱子给出$H \approx 2$–$3\,d_\mathrm{p}$。
- 范第姆特方程$H = A + B/u + Cu$把多条路径、纵向扩散和传质阻力的方差相加；在$u_\mathrm{opt} = \sqrt{B/C}$处$H_\mathrm{min} = A + 2\sqrt{BC}$。
- 分离度$R_\mathrm{s} = (\sqrt{N}/4)[(\alpha-1)/\alpha][k_2/(1+k_2)]$：柱效以平方根进入，所以选择性是最强的杠杆；$R_\mathrm{s} = 1.5$即基线分离。
- GC在毛细管柱上分离挥发性化合物；温度控制保留，保留指数传递鉴定信息，FID、ECD和MS是主要检测器。
- 反相HPLC按疏水性分离，流动相组成和pH是主要变量；颗粒更小，分离更快，压力也更高。
- 定量需要对每种分析物校准——检测器的响应因子各不相同——最好辅以内标和系统适用性检查。
:::

## 习题

::: exercise 保留因子 {level=1 check="8.0"}
某化合物在死时间为$1.40\ \mathrm{min}$的柱上于$12.6\ \mathrm{min}$流出。求$k$，以及该化合物处于流动相中的时间分数。（输入$k$。）
::: solution
$k = (12.6 - 1.40)/1.40 = 8.0$。处于流动相中的时间分数为$1/(1 + k) = 0.11$。$k$为$8$已处在使用范围的上端；稍强一点的流动相就能缩短分析时间。
:::
:::

::: exercise 由峰底宽求理论塔板数 {level=1 check="9800"}
$t_\mathrm{R} = 10.40\ \mathrm{min}$处的峰，峰底宽$0.42\ \mathrm{min}$。求$N$。（$N$保留两位有效数字。）
::: solution
$N = 16(10.40/0.42)^2 = 16\times613.2 = 9.8\times10^3$。峰底宽度比半峰宽更难测准，这就是[[#eq-plates]]第二种形式更受青睐的原因。
:::
:::

::: exercise 一对峰的分离度 {level=1 check="1.34"}
$9.85$与$10.40\ \mathrm{min}$处的峰，峰底宽分别为$0.40$和$0.42\ \mathrm{min}$。求$R_\mathrm{s}$。这对峰达到基线分离了吗？（输入$R_\mathrm{s}$。）
::: solution
$R_\mathrm{s} = 0.55/(\tfrac12\times0.82) = 1.34$。尚未达到基线分离（$1.5$）；对大小相近的峰，重叠不到$1\ \%$，但若一个小峰紧挨一个大峰，小峰的面积就不可靠。
:::
:::

::: exercise 一个Kováts指数 {level=2 check="659"}
核对[[#ex-kovats]]的计算，并预测同一根柱上$I = 680$的化合物的调整保留时间。（输入[[#ex-kovats]]中未知物的指数。）
::: solution
$I = 100[6 + (\log5.90 - \log4.20)/(\log7.50 - \log4.20)] = 100[6 + 0.14760/0.25181] = 658.6$，即$659$。对$I = 680$：$\log t_\mathrm{R}' = \log4.20 + 0.80\times0.25181 = 0.62325 + 0.20145 = 0.82470$，故$t_\mathrm{R}' = 6.68\ \mathrm{min}$。
:::
:::

::: exercise 长柱的代价 {level=2 check="1.41"}
某次分离在$12\ \mathrm{min}$内给出$R_\mathrm{s} = 1.00$。若在相同的线速度下把柱长加倍，分离度是多少？运行需要多长时间？（输入新的$R_\mathrm{s}$。）
::: solution
$N$加倍而$R_\mathrm{s} \propto \sqrt{N}$，所以$R_\mathrm{s} = 1.41$；保留时间加倍，运行需$24\ \mathrm{min}$——柱压也加倍。把柱长加倍，是换取分离度的昂贵办法。
:::
:::

::: exercise 由范第姆特系数求最优流速 {level=2 check="2.0"}
某柱的$A = 1.5\ \mu\mathrm{m}$，$B = 6.0\ \mu\mathrm{m\,mm\,s^{-1}}$，$C = 1.5\ \mu\mathrm{m\,s\,mm^{-1}}$。求$u_\mathrm{opt}$与$H_\mathrm{min}$。（$u_\mathrm{opt}$以$\mathrm{mm\,s^{-1}}$输入。）
::: solution
由[[#eq-optimum]]，$u_\mathrm{opt} = \sqrt{6.0/1.5} = 2.0\ \mathrm{mm\,s^{-1}}$，$H_\mathrm{min} = 1.5 + 2\sqrt{6.0\times1.5} = 1.5 + 6.0 = 7.5\ \mu\mathrm{m}$。以两倍最优速度运行得$H = 1.5 + 1.5 + 6.0 = 9.0\ \mu\mathrm{m}$，只差$20\ \%$，分析时间却减半——这就是色谱柱常常在略高于$u_\mathrm{opt}$处运行的原因，尤其是对高速一侧曲线平坦的小颗粒柱。
:::
:::

::: exercise 内标校准 {level=2 check="3.08"}
含$2.00\ \mathrm{mg\,dm^{-3}}$分析物与$1.00\ \mathrm{mg\,dm^{-3}}$内标的标准溶液给出面积比（分析物/内标）$1.20$。某样品添加内标至$1.00\ \mathrm{mg\,dm^{-3}}$后面积比为$1.85$。求分析物的浓度。（以$\mathrm{mg\,dm^{-3}}$输入。）
::: solution
响应因子$F = (1.20/2.00)/(1.00/1.00) = 0.600$。于是$[\mathrm{X}] = 1.85\times1.00/0.600 = 3.08\ \mathrm{mg\,dm^{-3}}$。结果高于那个单点标准，更好的做法是用覆盖该浓度的多点校准。
:::
:::

::: exercise 目标分离度所需的塔板数 {level=3 check="13800"}
由定义推导[[#eq-purnell]]，并用它求出分离$\alpha = 1.10$、$k_2 = 3.0$的一对化合物、达到$R_\mathrm{s} = 2.0$（给真实样品留出的裕量）所需的塔板数。（$N$保留三位有效数字。）
::: hint
重排为$N = 16R_\mathrm{s}^2[\alpha/(\alpha-1)]^2[(1+k_2)/k_2]^2$。
:::
::: solution
推导即[[#prop-resolution]]的证明。于是$N = 16\times4.0\times(1.10/0.10)^2\times(4.0/3.0)^2 = 64\times121\times1.778 = 1.38\times10^4$。一根用$3\ \mu\mathrm{m}$颗粒填充、长$10\ \mathrm{cm}$、$H = 7\ \mu\mathrm{m}$的柱约给出$1.4\times10^4$块塔板——刚刚好。
:::
:::

::: exercise 更小的颗粒 {level=3 check="1.70"}
某方法用一根$15\ \mathrm{cm}$、$5\ \mu\mathrm{m}$颗粒的色谱柱，在最优速度下对关键物对给出$R_\mathrm{s} = 1.20$。假设各种颗粒在最优处的折合塔板高度$h = H/d_\mathrm{p}$相同，问$15\ \mathrm{cm}$、$2.5\ \mu\mathrm{m}$颗粒的柱给出多大的分离度？若在各自的最优速度下运行（该速度按$1/d_\mathrm{p}$缩放），压力上升为原来的几倍？（输入新的$R_\mathrm{s}$。）
::: hint
$N = L/(hd_\mathrm{p})$；压力$\propto uL\eta/d_\mathrm{p}^2$。
:::
::: solution
$h$不变时$d_\mathrm{p}$减半使$H$减半、$N$加倍，所以$R_\mathrm{s} = 1.20\times\sqrt{2} = 1.70$——达到基线分离。最优速度加倍（按$D_\mathrm{M}/d_\mathrm{p}$缩放），分析时间随之减半；而压力$\propto u/d_\mathrm{p}^2$上升为$2\times4 = 8$倍。一个在$25\ \mathrm{MPa}$下运行的方法将需要$200\ \mathrm{MPa}$，超过许多UHPLC泵的额定值；实际中往往改走缩短柱子的路线，用一部分分离度增益换取时间和压力的巨大节省。
:::
:::
