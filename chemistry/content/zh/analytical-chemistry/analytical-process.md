某学校报告说，其一个饮水机流出的水“含铅”。这是危机还是不足为奇？只要检测得足够仔细，任何供水中都含有**一些**铅；真正要紧的问题是含量多少、与限值相比如何——世界卫生组织的准则值为$10\ \mu\mathrm{g\,dm^{-3}}$——以及我们对这个数值有多大把握。要回答这个问题，化学工作者必须确定究竟测什么（溶解态铅？包括颗粒物在内的总铅？在管道中停留一夜后的首次放流水，还是放水冲洗之后的水？），采集真正能代表这一对象的试样，在既不损失也不引入铅的前提下把铅转化为仪器能够测定的形式，用标准进行测量，并给出不确定度足够小、能区分$8$与$12\ \mu\mathrm{g\,dm^{-3}}$的结果。其中每一步都可能毁掉答案，而实验室里最昂贵的仪器也挽救不了一个选择不当的试样。

这一连串决策就是**分析过程**，也是本章的主题。分析化学常被当作一份技术目录来讲授——滴定、光谱仪、色谱仪——本课程的其余部分也确实会深入讨论这些技术。但技术只是其中一环。这里我们审视整条链：提出的是什么问题，试样是什么、如何采集，如何制备，以及报告的数值必须包含哪些信息才有用。沿途我们将推导出支配前几个环节的三个定量结论：采样方差与测量方差相加；试样必须包含的颗粒数由二项分布得出；多次少量萃取优于一次大量萃取。其背后的实验技能——天平、容量玻璃仪器和标准溶液——见[[laboratory-methods/volumetric-technique]]，不确定度的语言见[[laboratory-methods/measurement-uncertainty]]。

## 分析化学要回答的问题

::: definition 分析物、基体、试样与干扰 {#def-analyte-matrix}
**分析物**（待测物）是我们希望确定其种类或含量的化学物种（铅、葡萄糖、某种农药残留）。**试样**是实际送到实验室的那部分物料，**基体**是试样中除分析物以外的一切——河水试样中的水、盐类和有机质；食品中的蛋白质、脂肪和骨骼。**干扰**是指对给定量的分析物而言，能够改变测量信号的任何组分或基体效应：或者它自身产生信号（**光谱**干扰或**加和性**干扰），或者它改变对分析物的响应（**基体**效应或**乘积性**效应）。**定性分析**确定存在哪些物种；**定量分析**确定含量多少；**形态分析**区分一种元素的不同化学形态（亚砷酸盐与砷酸盐、甲基汞与无机汞），这些形态的毒性往往相差极大。
:::

区分分析物与基体之所以重要，是因为分析方法很少是**专属的**——只对分析物响应——甚至往往也不是很**有选择性的**。用原子光谱法测“铅”，响应的是铅原子，而不管它们来自什么化合物；pH电极对钠离子也有少许响应；$260\ \mathrm{nm}$处的紫外吸光度对溶液中的每一种芳香化合物都有响应。分析化学的很大一部分，就是使非专属的测量表现得如同专属测量一样的技艺：通过分离、掩蔽、在与试样相似的基体中校准，或者以干扰物无法模仿的方式测量信号。

方法还可按信号与含量的关系来分类。在**绝对**（或**化学计量**）方法中，结果仅由质量或体积以及配平的化学方程式得出：重量分析法称量已知化学式的沉淀，滴定分析法测量按已知比例反应的标准试剂的体积（[[analytical-chemistry/classical-analysis]]）。在**相对**（或**仪器**）方法中，信号——吸光度、电流、峰面积——必须用已知浓度的标准进行校准，因为其比例常数取决于仪器、日期和基体（[[analytical-chemistry/statistics-calibration]]）。大多数现代测量是相对测量，这就是校准和标准物质占据分析工作者如此多精力的原因。

### 作为一系列决策的分析过程

::: algorithm 分析过程 {#alg-analytical-process}
1. **明确问题。** 与需要结果的人商定：要测什么（哪种分析物及其哪种形态），在什么物料中，处于什么含量水平，要求多大的不确定度，多快出结果，以及用于什么决策。当结果的不确定度足以支持该决策、又不比值得付出代价的程度更小时，该结果就是**满足预期用途的**。
2. **选择方法。** 使方法的性能指标——选择性、灵敏度、检出限、工作范围、精密度、正确度、所需试样量、速度、成本——与问题相匹配；若有经过确认的方法或标准方法，则优先采用。
3. **制订采样计划并采样。** 确定在何处、何时、采集多少物料，使其能代表整体（**批**），以及在分析之前如何保存（冷藏、酸化、避光保存）。
4. **制备试样。** 干燥、研磨并均匀化；溶解或萃取分析物；除去或掩蔽干扰；浓缩或稀释到工作范围——这一切都不能损失分析物，也不能引入污染。
5. **测量。** 用标准校准仪器，在测定未知样的同时测定空白、平行样和质控样，并记录每一个读数。
6. **评价。** 把信号换算为浓度，校正空白和稀释倍数，并评定不确定度；在相信未知样的结果之前，先检查质控结果。
7. **报告并采取行动。** 以决策所需的单位给出结果，并附上其不确定度、所用方法和任何局限；然后由提出问题的人作出决策——而这一决策可能又把你送回第1步。
:::

这一顺序是逻辑上的，并不总是时间上的：好的分析工作者在第3步之前就会考虑第6步，因为所需的试样数和平行测定次数取决于要达到的不确定度。本章其余部分讨论仪器之前的步骤——采样和制备——以及仪器之后的步骤，即报告，因为最大的误差通常就隐藏在这些地方。

### 含量水平与单位

::: definition 痕量分析中的浓度单位 {#def-ppm}
对于固体，**质量分数**$w_\mathrm{B} = m_\mathrm{B}/m$用百分数（每$100\ \mathrm{g}$中的$\mathrm{g}$数）、$\mathrm{mg\,kg^{-1}}$（按质量计的百万分之一，“ppm”）或$\mu\mathrm{g\,kg^{-1}}$（十亿分之一，“ppb”，$10^9$分之$1$）表示。对于稀水溶液，以$\mathrm{mg\,dm^{-3}}$表示的**质量浓度**$\rho_\mathrm{B} = m_\mathrm{B}/V$在数值上几乎等于按质量计的ppm，因为$1\ \mathrm{dm^3}$稀溶液的质量接近$1\ \mathrm{kg}$；同样，$\mu\mathrm{g\,dm^{-3}} \approx$ ppb。物质的量浓度$c_\mathrm{B} = n_\mathrm{B}/V$由$\rho_\mathrm{B}$除以摩尔质量得到。按照惯例，含量为$1$–$100\ \%$的分析物称为**常量**组分，$0.01$–$1\ \%$的称为**微量**组分，低于$0.01\ \%$（$100\ \mathrm{ppm}$）的称为**痕量**组分，低于约$1\ \mathrm{ppb}$的称为**超痕量**组分。
:::

IUPAC和《国际单位制》手册（SI brochure）都不提倡使用缩写ppm和ppb，因为它们掩盖了比值是按质量、体积还是物质的量计的（在气体分析中，“ppm”通常指$10^{-6}$的**摩尔**分数，写作$\mu\mathrm{mol\,mol^{-1}}$）。只要有任何疑问，就应明确写出单位；本课程正是这样做的。含量水平对方法选择很重要：滴定法和重量分析法非常适合常量组分，在痕量水平则毫无用处；而原子光谱法和质谱法可达到超痕量水平，但如果不经大幅稀释就勉强用来测定常量组分，精密度就会变差。

::: example 从仪器读数到质量分数 {#ex-soil-lead}
将$0.2503\ \mathrm{g}$干燥土壤测试份用酸消解，消解液定容至$50.00\ \mathrm{cm^3}$。从中移取$5.00\ \mathrm{cm^3}$分取液稀释至$50.00\ \mathrm{cm^3}$，用原子光谱法测定，读得铅含量为$0.0832\ \mathrm{mg\,dm^{-3}}$。经过相同步骤处理的试剂空白读数为$0.0012\ \mathrm{mg\,dm^{-3}}$。求干燥土壤中铅的质量分数，以$\mathrm{mg\,kg^{-1}}$表示。
::: solution
首先对读数进行空白校正，因为空白经历了完全相同的稀释：被测溶液中为$0.0832 - 0.0012 = 0.0820\ \mathrm{mg\,dm^{-3}}$。还原十倍稀释（$5.00 \to 50.00\ \mathrm{cm^3}$）：消解液中含$0.820\ \mathrm{mg\,dm^{-3}}$。消解液体积为$0.05000\ \mathrm{dm^3}$，因此铅的质量为
$$
m_\mathrm{Pb} = 0.820\ \mathrm{mg\,dm^{-3}} \times 0.05000\ \mathrm{dm^3} = 0.0410\ \mathrm{mg}.
$$
除以测试份质量，并把克换算为千克：
$$
w_\mathrm{Pb} = \frac{0.0410\ \mathrm{mg}}{0.2503\times10^{-3}\ \mathrm{kg}} = 164\ \mathrm{mg\,kg^{-1}}.
$$
三位有效数字，受空白校正后读数（$0.0820$，三位有效数字）的限制。把整个计算写成一个乘积——读数$\times$稀释倍数$\times$体积$/$质量——这一习惯可以防止常规分析中最常见的错误：漏乘或重复乘稀释倍数。还要注意，结果针对的是**干燥**土壤；“以收到样计”的结果会按水分含量的比例偏低，报告中必须说明是哪一种。
:::
:::

## 采样：决定下限的一步

仪器只能测量放进去的东西。如果消解罐中的$0.25\ \mathrm{g}$不能代表田间的一吨土壤，那么此后无论多么小心，结果也不会正确。采样误差往往是结果不确定度中最大的单项贡献，而且实验室中的平行测定无法揭示它。

::: definition 采样的层级 {#def-sample-terms}
**批**（或**总体**）是要对其作出决策的全部物料——一卡车矿石、一个湖泊、一个生产批次的片剂。**原始试样**是从批中采集的各**份样**（增量）的集合；经过研磨和混合，将其缩减为**实验室试样**，分析工作者再从中取出用于各次分析的**测试份**。当试样的组成是批的组成的无偏估计时，该试样就具有**代表性**。在**随机采样**中，批的每一部分被选中的机会相等；在**系统采样**中，按空间或时间上的固定间隔采集份样；在**分层采样**中，将批分为可明显区分的不同层（料堆的各层、生产线的各班次），并按比例对每一层采样；当只关心平均值时，**混合试样**把各份样合并为一个试样。
:::

有两类不均匀性使采样变得困难。**分布不均匀性**是大尺度上的离析：密度大的颗粒沉到容器底部，排污口下游的河水比上游污染更重，罐的顶部与底部不同。混合可以减小这种不均匀性，分层采样或随机采样可以将其平均掉。**组成不均匀性**是指各个颗粒的组成彼此不同——一颗矿粒要么富含矿物，要么是废石——它无法通过混合消除：即使是从充分混匀的粉末中完全随机地采得的试样，由于其所含颗粒数有限，组成也会波动。只有取更多的颗粒（更大的试样，或把同样质量研磨得更细）才能减小它。

### 采样方差与测量方差相加

一个结果带有来自两个独立来源的分散性：从批中采集的不同试样之间的差异（采样），以及对同一试样重复测量之间的差异（测量，包括制备）。合并二者的算法正是你在不确定度传递中已经熟悉的那一套。

::: proposition 采样方差与测量方差相加 {#prop-variance-sampling}
若采样误差与测量误差相互独立，则单个结果的总方差为
$$
s_\mathrm{o}^2 = s_\mathrm{s}^2 + s_\mathrm{m}^2,
$$ {#eq-variance-add}
其中$s_\mathrm{s}$是采样标准偏差，$s_\mathrm{m}$是测量标准偏差。若对$n_\mathrm{s}$个独立试样各分析$n_\mathrm{m}$次，并对全部结果取平均，则总平均值的方差为
$$
s^2(\bar{x}) = \frac{s_\mathrm{s}^2}{n_\mathrm{s}} + \frac{s_\mathrm{m}^2}{n_\mathrm{s}\,n_\mathrm{m}} .
$$ {#eq-nested-variance}
:::

::: proof
把一个结果写作$x = \mu + e_\mathrm{s} + e_\mathrm{m}$，其中$\mu$是批的真值，$e_\mathrm{s}$是该试样组成对$\mu$的偏离（均值为零，方差为$\sigma_\mathrm{s}^2$），$e_\mathrm{m}$是测量误差（均值为零，方差为$\sigma_\mathrm{m}^2$）。对于独立变量，和的方差等于方差之和，由此得到[[#eq-variance-add]]。对于总平均值，试样$j$贡献$\bar{x}_j = \mu + e_{\mathrm{s},j} + \frac{1}{n_\mathrm{m}}\sum_k e_{\mathrm{m},jk}$，其方差为$\sigma_\mathrm{s}^2 + \sigma_\mathrm{m}^2/n_\mathrm{m}$——平行测量把测量误差平均掉了，却丝毫没有触动试样本身的偏离。对$n_\mathrm{s}$个独立的试样平均值再取平均，就把该方差除以$n_\mathrm{s}$：
$$
\mathrm{Var}(\bar{x}) = \frac{1}{n_\mathrm{s}}\left(\sigma_\mathrm{s}^2 + \frac{\sigma_\mathrm{m}^2}{n_\mathrm{m}}\right),
$$
用估计值$s$代替$\sigma$，即为[[#eq-nested-variance]]。利用对若干试样进行平行分析所得的数据作单因素方差分析，可以从实际数据中把这两个分量分离出来。
:::

实际的教训毫不含糊。对同一试样重复测量只能减小第二项；无论做多少次平行测定，第一项始终保持为$s_\mathrm{s}^2$。当采样占主导时——对固体和环境物料通常如此——力气应当花在采集更多试样上，而不是更仔细地测量一个试样。由[[#eq-variance-add]]可得一条粗略规则：一旦$s_\mathrm{m} < s_\mathrm{s}/3$，改进测量使总标准偏差的变化不到$5\ \%$，因为$\sqrt{1 + 1/9} = 1.054$。

::: example 九次分析花在哪里 {#ex-allocation}
对于一批动物饲料，蛋白质含量的相对采样标准偏差为$3.0\ \%$，相对测量标准偏差为$1.0\ \%$。实验室能承担九次分析。比较以下方案平均值的相对标准偏差：(a) 一个试样分析九次；(b) 九个试样各分析一次；(c) 三个试样各分析三次。
::: solution
以$s_\mathrm{s} = 3.0$和$s_\mathrm{m} = 1.0$（以百分数计）代入[[#eq-nested-variance]]：
$$
\begin{aligned}
\text{(a)}\ & n_\mathrm{s} = 1,\ n_\mathrm{m} = 9: & s &= \sqrt{9.0/1 + 1.0/9} = \sqrt{9.11} = 3.0\ \%,\\
\text{(b)}\ & n_\mathrm{s} = 9,\ n_\mathrm{m} = 1: & s &= \sqrt{9.0/9 + 1.0/9} = \sqrt{1.11} = 1.05\ \%,\\
\text{(c)}\ & n_\mathrm{s} = 3,\ n_\mathrm{m} = 3: & s &= \sqrt{9.0/3 + 1.0/9} = \sqrt{3.11} = 1.76\ \%.
\end{aligned}
$$
方案(a)几乎毫无用处：对一个试样的九次仔细测量能把该试样的蛋白质含量确定到$0.33\ \%$，但对整批只能确定到$3\ \%$——而九个平行结果之间的良好一致性**看起来**还令人放心。方案(b)在工作量相同的情况下好三倍。实际方案还要权衡成本（采集一个试样的花费可能比分析一个试样更多），这就引出了[[#exr-cost-allocation]]中的最优分配。
:::
:::

### 试样必须包含多少颗粒

组成不均匀性可以用一个简单到能精确求解的模型来定量描述。设想一种由两类粒径相同的颗粒组成的粉末：其中（按数目计）分数为$p$的颗粒含有分析物，其余为不含分析物的空白颗粒。一个试样含有随机抽取的$n$个颗粒。于是其中含分析物颗粒的数目是一个随机变量，它的分散程度就是采样误差。

::: proposition 颗粒混合物的采样 {#prop-binomial-sampling}
若从充分混匀的批中随机抽取含$n$个颗粒的试样，批中含分析物颗粒所占的分数为$p$，则含分析物颗粒的数目$k$服从二项分布，均值为$np$，标准偏差为$\sqrt{np(1-p)}$。因此试样中分析物含量的相对标准偏差为
$$
\sigma_\mathrm{r} = \sqrt{\frac{1-p}{np}}, \qquad\text{所以}\qquad n = \frac{1-p}{p\,\sigma_\mathrm{r}^2}
$$ {#eq-particles}
即为达到选定的相对标准偏差$\sigma_\mathrm{r}$所需的颗粒数。该结果假定颗粒大小相同、分析物含量相同，且批远大于试样。
:::

::: proof
$n$个颗粒中的每一个都独立地以概率$p$含有分析物，因此$k$是$n$个独立伯努利变量之和，每个变量的均值为$p$，方差为$p(1-p)$。均值相加，（由独立性）方差也相加：$\E[k] = np$，$\Var(k) = np(1-p)$。试样中的分析物含量与$k$成正比，因此其相对标准偏差为
$$
\sigma_\mathrm{r} = \frac{\sqrt{np(1-p)}}{np} = \sqrt{\frac{1-p}{np}}.
$$
解出$n$即得[[#eq-particles]]。（如果批并不远大于试样，不放回抽取会使$k$服从超几何分布，方差按有限总体校正因子减小；对于现场规模的批，这个因子与1无法区分。）
:::

::: example 采样前先研磨 {#ex-grinding}
某矿物粉末中（按数目计）$1.0\ \%$的颗粒是一种矿石矿物。所有颗粒都是直径$0.50\ \mathrm{mm}$、密度$2.7\ \mathrm{g\,cm^{-3}}$的球体。(a) 为使相对采样标准偏差为$1.0\ \%$，测试份必须包含多少颗粒？(b) 相应的质量是多少？(c) 若先把粉末研磨至$0.10\ \mathrm{mm}$，需要多大质量？
::: solution
(a) 由[[#eq-particles]]，取$p = 0.010$，$\sigma_\mathrm{r} = 0.010$：
$$
n = \frac{1 - 0.010}{0.010 \times (0.010)^2} = 9.9\times10^{5}\ \text{个颗粒}.
$$

(b) 一个颗粒的体积为$\tfrac{4}{3}\pi(0.025\ \mathrm{cm})^3 = 6.54\times10^{-5}\ \mathrm{cm^3}$，质量为$6.54\times10^{-5} \times 2.7 = 1.77\times10^{-4}\ \mathrm{g}$。测试份质量必须为$9.9\times10^5 \times 1.77\times10^{-4}\ \mathrm{g} = 1.7\times10^{2}\ \mathrm{g}$——约$175\ \mathrm{g}$，远远超过任何消解罐的容量。

(c) 所需颗粒数不变，但每个颗粒的质量与其直径的立方成正比：直径缩小为五分之一，质量就除以$5^3 = 125$，因此为$175/125 = 1.4\ \mathrm{g}$。这就是为什么实验室试样要在取测试份**之前**研磨成细粉：研磨不改变组成，却使每克中的颗粒数成倍增加。
:::
:::

实际粉末的粒径和组成都有一定分布，吉（Pierre Gy）的采样理论借助形状因子、粒度分布因子和解离因子，把[[#prop-binomial-sampling]]推广到这类粉末。英格梅尔斯（Ingamells）提出了一个较简单的经验形式，其依据是这样的观察：对于充分混匀的物料，测试份质量$m$与以百分数表示的相对采样标准偏差$R$的平方之积大致为常数：
$$
m R^2 = K_\mathrm{s}.
$$ {#eq-ingamells}
**英格梅尔斯采样常数**$K_\mathrm{s}$是使采样标准偏差为$1\ \%$的测试份质量。它可由[[#eq-particles]]得出，因为$n$与$m$成正比，而$R^2 \propto 1/n$。用若干平行测试份在某一质量下测定一次$R$，[[#eq-ingamells]]就能预测达到任何其他目标所需的质量。

::: example 使用采样常数 {#ex-ingamells}
某磨细岩石的$1.00\ \mathrm{g}$平行测试份给出金的相对采样标准偏差为$4.0\ \%$（已用[[#eq-variance-add]]扣除测量的贡献）。多大的测试份质量能得到$1.0\ \%$？多大质量能得到$2.0\ \%$？
::: solution
$K_\mathrm{s} = mR^2 = 1.00\ \mathrm{g} \times (4.0)^2 = 16\ \mathrm{g}$。对$R = 1.0\ \%$，$m = 16/1.0^2 = 16\ \mathrm{g}$；对$R = 2.0\ \%$，$m = 16/2.0^2 = 4.0\ \mathrm{g}$。金是典型的困难情形：它以稀疏的离散颗粒形式存在，因此[[#eq-particles]]中的$p$极小，火试金实验室通常要取几十克，而硅酸盐分析只需取十分之一克。
:::
:::

::: warning 平行结果精密并不能证明试样有代表性 {#warn-replicates}
对一个测试份做五次平行测量，发现它们的一致性在$0.5\ \%$以内，这说明你的**测量**是精密的。它丝毫不能说明测试份是否代表批：每个平行结果都继承了同样的采样误差，而这种误差在这组数据内部是看不见的（[[#ex-allocation]]，方案(a)）。要看到采样误差，必须分析若干个独立采集的试样（或测试份），并把它们的分散程度与平行测定的分散程度进行比较。同样的陷阱也出现在时间上：对一瓶河水的三次读数并不能描述这条河一整天的情况。另一个相关的错误是，把对单独一勺物料混匀**之后**取出的若干子样的平均值当作若干个试样——它们是同一试样的平行样，而不是批的独立试样。
:::

### 试样的保存

试样从采集的那一刻起就开始变化。溶解的金属会吸附到容器壁上（用硝酸把水样酸化至$\mathrm{pH} < 2$可使其保持在溶液中）；溶解气体会逸出或进入（氧气和二氧化碳在几分钟内就会改变地下水的pH和氧化还原状态，因此这些指标要在现场测定）；微生物会消耗硝酸盐、磷酸盐和有机分析物（冷藏至约$4\ ^\circ\mathrm{C}$并尽快分析可以减缓其作用）；光会使某些农药和维生素分解（使用棕色玻璃瓶）。容器本身也可能引入分析物——玻璃会溶出硼和钠，塑料会释放邻苯二甲酸酯并吸附非极性有机物。每种分析物都有各自的保存规定，写在标准方法中，还有**保存期限**，超过这一期限，即使经过保存的试样也不再可信。

## 试样的制备

大多数仪器需要均匀的溶液（对色谱法而言，则是干净的提取液），其中分析物处于已知体积中并落在工作范围内。达到这一点通常比测量本身花费更长时间，而分析物的损失或引入也正发生在这里。

**干燥与均匀化。** 固体要干燥至恒重（或另行测定含水量），以便结果能以干基表示，然后研磨并混合；研磨设备不得造成污染（碳化钨研磨机会引入钨和钴，钢制研磨机会引入铁和铬）。

**溶解与分解。** 金属、合金和许多矿物可溶于无机酸。有机基体（食品、组织、塑料）用**湿法消解**破坏：在热硝酸中（常加过氧化氢），于微波加热的密闭容器中进行，这在加压下提高了沸点，并防止汞和砷等易挥发元素的损失。硅酸盐除氢氟酸外不溶于其他酸，或者与偏硼酸锂等熔剂在约$1000\ ^\circ\mathrm{C}$下**熔融**，再将冷却后的熔块溶于稀酸。**干法灰化**——在马弗炉中加热以烧掉有机物——操作简单，但会损失易挥发元素。

这里的危害严重而具体。氢氟酸能穿透皮肤并与下方组织中的钙结合，引起深度灼伤和全身中毒，而且可能数小时内都不觉疼痛；只有经过专门培训、配备防护装备并备有葡萄糖酸钙凝胶时才能操作。热的浓高氯酸是强氧化剂，可与有机物发生爆炸性反应，并在普通通风管道中形成对撞击敏感的高氯酸盐沉积物，因此只能在先用硝酸预氧化之后、并在专用的带冲洗装置的通风橱中使用。密闭容器消解依赖于额定耐压的容器和经过验证的程序。所有这些都是在监督下、依据书面风险评估进行的实验室工作，决不可临时凑合。

**分离与预富集。** 当分析物过稀或基体产生干扰时，就把分析物转移到体积更小、更干净的相中——通过液-液萃取、在装有少量吸附剂的小柱上进行固相萃取、沉淀、蒸馏或离子交换。将$500\ \mathrm{cm^3}$水样中的分析物收集在小柱上并用$5\ \mathrm{cm^3}$洗脱，就浓缩了一百倍，这使有效检出限降低同样的倍数（前提是空白不随之升高）。

### 液-液萃取的定量处理

萃取使溶质在两种互不相溶的液体之间转移，通常是水和一种有机溶剂。达到平衡时，溶质按照取决于其对各相亲和力的比例分配于两相之间。

::: definition 分配比 {#def-distribution-ratio}
对于在水相和与之互不相溶的有机相之间分配的溶质S，平衡时单一化学形态的**分配系数**为$K_\mathrm{D} = [\mathrm{S}]_\mathrm{org}/[\mathrm{S}]_\mathrm{aq}$。**分配比**$D$是各种形态的**总**分析浓度之比，
$$
D = \frac{c_\mathrm{org}}{c_\mathrm{aq}},
$$
它是决定回收率的量。对于只有中性形态才进入有机相的弱酸HA，$D = K_\mathrm{D}\,[\mathrm{H^+}]/([\mathrm{H^+}] + K_\mathrm{a})$，因此可以用pH来“开启”或“关闭”$D$：在pH远低于$\mathrm{p}K_\mathrm{a}$时，$D$接近$K_\mathrm{D}$；在高于$\mathrm{p}K_\mathrm{a}$时，pH每升高一个单位，$D$下降为原来的十分之一。
:::

::: proposition 多次萃取 {#prop-extraction}
若体积为$V_\mathrm{aq}$的水溶液用每份体积为$V_\mathrm{org}$的新鲜有机溶剂萃取$n$次，且$D$为常数，则残留在水相中的溶质分数为
$$
q_n = \left(\frac{V_\mathrm{aq}}{V_\mathrm{aq} + D\,V_\mathrm{org}}\right)^{n}.
$$ {#eq-extraction}
对于固定的溶剂总体积，$q_n$随$n$增大而减小：多次少量萃取比一次大量萃取除去更多的溶质。
:::

::: proof
设萃取前水相中溶质的量为$N$。平衡时两相中的量分别为$c_\mathrm{aq}V_\mathrm{aq}$和$c_\mathrm{org}V_\mathrm{org} = D c_\mathrm{aq} V_\mathrm{org}$，二者之和为$N$。因此$c_\mathrm{aq}(V_\mathrm{aq} + DV_\mathrm{org}) = N$，残留在水中的分数为
$$
q = \frac{c_\mathrm{aq}V_\mathrm{aq}}{N} = \frac{V_\mathrm{aq}}{V_\mathrm{aq} + DV_\mathrm{org}}.
$$
分出有机层，再加入新鲜溶剂；剩余部分中又有同样的分数$q$留下，因此萃取$n$次后的分数为$q^n$，即[[#eq-extraction]]。为了进行比较，固定溶剂总体积$V$，并把它分成$n$份，每份$V/n$。令$a = DV/V_\mathrm{aq}$，
$$
q_n = \left(1 + \frac{a}{n}\right)^{-n},
$$
而$(1 + a/n)^n$随$n$增大而递增并趋于$e^{a}$（这就是[数学图谱](/learn/maths/)中的复利数列），所以$q_n$递减并趋于极限$e^{-a}$。分份有帮助，但收益递减：极限$e^{-a}$永远无法被超越。
:::

x: 0, 6
y: 0, 1
sliders: D=3:0.5:20:0.5

caption: 由[[#eq-extraction]]得到的、用每份$30\ \mathrm{cm^3}$的溶剂连续萃取$x$次后$100\ \mathrm{cm^3}$水中残留的溶质分数，分配比$D$由滑块设定（曲线仅在整数$x = n$处有意义）。第二条曲线是总体积同为$V = 30x\ \mathrm{cm^3}$时的$e^{-DV/V_\mathrm{aq}}$：即把这一总体积分成无穷多份极小部分时所能达到的极限。在$D = 3$时，三份萃取留下$14.6\ \%$；一份$90\ \mathrm{cm^3}$则会留下$27\ \%$。把$D$滑到$20$，一次萃取就已除去$86\ \%$——对于强烈倾向于溶剂的溶质，分几份萃取的重要性就小得多。
:::

::: example 一次大量还是三次少量萃取？ {#ex-extraction}
用总共$90\ \mathrm{cm^3}$的溶剂从$100\ \mathrm{cm^3}$水中萃取$D = 3.0$的分析物。比较用$90\ \mathrm{cm^3}$萃取一次和每次$30\ \mathrm{cm^3}$萃取三次。
::: solution
萃取一次：$q_1 = 100/(100 + 3.0\times 90) = 100/370 = 0.270$，因此$27.0\ \%$留在水中，回收率为$73.0\ \%$。

萃取三次：每次$q = 100/(100 + 3.0\times30) = 100/190 = 0.526$，$q_3 = 0.526^3 = 0.146$，因此$14.6\ \%$留下，回收率为$85.4\ \%$。

同样的溶剂，同样的总体积，损失几乎减半。若用$30\ \mathrm{cm^3}$的份数达到$99\ \%$的回收率，需要$n \ge \ln 0.01/\ln 0.526 = 7.2$，即萃取八次——这有力地提示我们，对于$D = 3$的溶质，与其无休止地重复萃取，不如设法提高$D$（调节pH、向水中加盐、更换溶剂）。
:::
:::

## 质量：空白、回收率与标准物质

一个结果的可信程度，取决于证明该程序**在这一次**确实有效的证据。这些证据来自与未知样一同测定的已知组成的样品。

::: definition 空白、加标回收率与标准物质 {#def-blank-crm}
**方法（试剂）空白**包含除试样以外的一切，并经历每一个步骤；它的信号衡量来自试剂、器皿和空气的污染，并从试样信号中扣除。**现场空白**是带到采样现场、像试样一样处理的不含分析物的水，用以揭示采集和运输过程中的污染。**加标样**是在一部分实际试样中加入已知量分析物所得的样品；其**回收率**
$$
R = \frac{c_\mathrm{spiked} - c_\mathrm{unspiked}}{c_\mathrm{added}}\times 100\ \%
$$
检验基体是否抑制或增强了响应，或者分析物是否在制备中损失。**有证标准物质**（CRM）是一种尽可能与试样相似的物料，其分析物含量已由公认的机构给出定值并注明不确定度（例如美国国家标准与技术研究院（NIST）、欧盟委员会联合研究中心或中国计量科学研究院）；分析有证标准物质可以检验**正确度**。当一个结果通过不间断的、有文件记录的校准链（每一级校准都注明不确定度）与SI单位相联系时，该结果就具有**计量溯源性**。
:::

回收率和标准物质回答的是不同的问题。以溶解盐形式加入试样中的标准，即使在原有的、被锁在矿物颗粒内部的分析物只被消解部分提取时，也可能被完全回收；基体相近的有证标准物质能发现这一问题，加标则不能。反过来，有证标准物质也未必与你的具体试样相似。良好的做法是两者并用，并把结果随时间画在质量控制图上（[[analytical-chemistry/statistics-calibration]]），以便在缓慢漂移毁掉一个月的报告之前就发现它。

::: example 解读回收率 {#ex-recovery}
某河水试样测得镍$12.4\ \mu\mathrm{g\,dm^{-3}}$。另一份加标$20.0\ \mu\mathrm{g\,dm^{-3}}$（体积变化可忽略）的试样测得$31.1\ \mu\mathrm{g\,dm^{-3}}$。在同一批测定中，镍含量为$25.0 \pm 0.6\ \mu\mathrm{g\,dm^{-3}}$的河水有证标准物质测得$23.6\ \mu\mathrm{g\,dm^{-3}}$。这些结果说明了什么？
::: solution
回收率：$R = (31.1 - 12.4)/20.0 \times 100\ \% = 93.5\ \%$。有证标准物质的读数为其认定值的$23.6/25.0 = 94.4\ \%$。两者指向同一方向：在这种基体中，该方法的读数偏低约$6\ \%$——可能是基体对信号的抑制，[[analytical-chemistry/statistics-calibration]]中用标准加入法或内标法处理这一问题。$6\ \%$的偏倚是否要紧取决于用途：许多法规方法在痕量水平接受大约$80$–$120\ \%$的回收率，但在限值附近，$6\ \%$的偏倚可能使决策翻转。除非方法规程规定要进行回收率校正，否则不要用除以$0.935$的办法来“校正”结果；应在报告结果的同时报告回收率。检验有证标准物质的差异是否真实（而非随机分散）的显著性检验，是下一章的主题。
:::
:::

## 选择方法：满足预期用途

问题明确之后，方法的选择就是一项匹配工作。**性能指标**是方法的可测量特性：

- **正确度**（大量结果的平均值与真值的接近程度；缺乏正确度即为**偏倚**）和**精密度**（各结果彼此之间的接近程度；批内为重复性，实验室之间为再现性）。二者共同构成**准确度**，即单个结果与真值的接近程度。
- **选择性**：方法对分析物而不对其他组分产生响应的程度。
- **灵敏度**：按IUPAC的含义，是校准函数的斜率——单位浓度变化引起的信号变化。它与检出限**不是**一回事，尽管二者有关联。
- **检出限**和**定量限**：能与空白区分的最小浓度，以及能以可接受的精密度测定的最小浓度（[[analytical-chemistry/statistics-calibration]]）。
- **工作范围**：响应可用的浓度区间，从定量限到开始出现非线性或饱和为止。
- 实用特性：所需试样质量或体积、分析通量、每个试样的成本、所需技能，以及方法带来的危害和废物。

最好的方法很少是最灵敏的方法。用超痕量技术测定奶粉中的钙（按质量计约$1\ \%$），需要$10^5$倍的稀释，而每次稀释都会增加不确定度；而配位滴定用一支滴定管就能达到千分之几的精度。测定同一奶粉中的镉（几十$\mu\mathrm{g\,kg^{-1}}$）用滴定法是不可能的，用质谱法则是常规工作。满足预期用途还以一种有益的方式从下方限定了不确定度：工厂质量控制的结果可能需要$\pm 0.5\ \%$，而对一千口井进行砷的筛查调查，与其用$\pm 2\ \%$的慢速方法只测五十口井，不如用$\pm 20\ \%$的快速方法。

::: quiz
某实验室对污染场地的一勺土壤分析了八次；八个铅结果的相对标准偏差为$0.8\ \%$。场地负责人据此断定，该场地的铅含量已知到约$1\ \%$以内。错在哪里？
- [ ] 没有错：八次平行测定已足够多，$0.8\ \%$是很小的相对标准偏差。
- [x] 平行测定只衡量了测量精密度；一勺土壤的采样误差是看不见的，而且很可能大得多。
- [ ] 相对标准偏差应当除以$\sqrt{8}$，所以真正的不确定度是$0.3\ \%$。
- [ ] 没有有证标准物质就不能分析土壤中的铅，因此这些结果毫无意义。
::: solution
八个结果都来自同一勺土壤，因此它们共有这一勺的采样误差（[[#prop-variance-sampling]]）。场地的空间变异——对受污染土地而言往往达到百分之几十——根本没有进入数据。除以$\sqrt{8}$只会使解读上的错误更严重。有证标准物质可以检验正确度，这很有价值，但它同样不能解决代表性的问题。补救办法是按照经过规划的采样布点采集若干个独立试样。
:::
:::

## 报告结果

报告的结果是写给将据此采取行动的人的信息。它应当无歧义地说明被测量（“硝酸消解后，粒径< 2 mm的干燥土壤中的总铅”），给出数值及其扩展不确定度和包含因子（“$164 \pm 12\ \mathrm{mg\,kg^{-1}}$，$k = 2$”），说明方法、采样和分析的日期，以及任何限定说明（回收率超出正常范围、收到试样时已超过保存期限）。低于检出限的值应报告为“小于”该限值（或注明该限值），决不能报告为零，也决不能干脆从数据集中删去，因为这样做会使由该数据集计算的每一个平均值都产生偏倚。有效数字服从不确定度：对于$\pm 12$，结果$164$应报告到个位，而不是写成$163.80$。

[[#alg-analytical-process]]的每一步都会留下记录——采样计划、表明试样在何时由何人保管的样品流转记录单、实验记录本、仪器文件、校准和质控数据——使结果能够被重现和辩护。获得认可的实验室按照ISO/IEC 17025（检测和校准实验室能力的国际标准）记录所有这些内容，并参加能力验证：由许多实验室分析同一物料的若干份，并以公议值为准对每个实验室进行评分。从实验记录本到最终报告的记录伦理，是[[laboratory-methods/reporting-integrity]]的主题。

## 后续内容

把读数转化为带有如实不确定度的结果所需的统计学——显著性检验、校准曲线、标准加入法、内标法和检出限——见[[analytical-chemistry/statistics-calibration]]。这里遇到的萃取平衡和溶解平衡将在[[analytical-chemistry/equilibria-in-analysis]]中系统展开，并成为[[analytical-chemistry/classical-analysis]]中绝对方法的基础。试样制备随每一种仪器技术反复出现：[[analytical-chemistry/atomic-spectrometry]]中的酸消解液，[[analytical-chemistry/chromatography]]中的提取液和衍生物，以及[[analytical-chemistry/hyphenated-methods]]中用于校正制备过程损失的同位素标记内标。环境监测——其中采样设计往往主导不确定度——将在[[environmental-chemistry]]中讨论。

::: history
系统分析作为一门学科，在很大程度上归功于弗雷泽纽斯（Carl Remigius Fresenius），他的《定性化学分析导论》（*Anleitung zur qualitativen chemischen Analyse*，1841）和《定量化学分析导论》（*Anleitung zur quantitativen chemischen Analyse*，1846）成为标准教材；1862年，他创办了《分析化学杂志》（*Zeitschrift für analytische Chemie*），这是第一份专门致力于该领域的期刊。采样统计学则晚得多才出现。吉（Pierre Gy）从20世纪50年代起为采矿业发展了颗粒物料采样理论，并在《颗粒物料的采样：理论与实践》（*Sampling of Particulate Materials: Theory and Practice*，1979）中加以阐述。英格梅尔斯（C. O. Ingamells）和斯维策（P. Switzer）于1973年在《塔兰塔》（*Talanta*）上提出了采样常数。在质量方面，检测实验室能力的国际标准ISO/IEC 17025于1999年首次发布（现行版本为2017年版），而Eurachem的指南《分析方法的适用性》（*The Fitness for Purpose of Analytical Methods*，1998；第二版2014）为“满足预期用途”这一说法在分析化学中给出了可操作的定义。
:::

::: summary
- 分析过程从明确问题开始，经过方法选择、采样、制备、测量和评价，直到报告结果；当结果的不确定度适合它所服务的决策时，该结果就满足预期用途。
- 分析物、基体和干扰是基本词汇；绝对方法（重量分析法、滴定分析法）只需要质量、体积和化学计量关系，相对方法需要校准。
- 采样方差与测量方差相加，$s_\mathrm{o}^2 = s_\mathrm{s}^2 + s_\mathrm{m}^2$；对同一试样的平行测定只减小测量项，因此当采样占主导时，力气应当花在采集更多试样上。
- 对于颗粒物料，二项分布模型给出所需颗粒数$n = (1-p)/(p\sigma_\mathrm{r}^2)$；研磨得更细会使每克中的颗粒数成倍增加，而$mR^2 = K_\mathrm{s}$给出测试份质量的标度关系。
- 制备（干燥、消解、萃取、预富集）既不能损失也不能引入分析物；$n$次少量萃取留下$q_n = [V_\mathrm{aq}/(V_\mathrm{aq} + DV_\mathrm{org})]^n$，优于一次大量萃取。
- 每批都测定的空白、加标回收率和有证标准物质，是结果正确的证据；溯源性将结果与SI相联系。
- 报告被测量、数值、不确定度、方法和限定说明；低于检出限的值应报告为“小于”，决不能报告为零。
:::

## 习题

::: exercise 大米中的镉 {level=1 check="5"}
测得$0.500\ \mathrm{g}$米粉测试份中含镉$2.5\ \mu\mathrm{g}$。以$\mathrm{mg\,kg^{-1}}$表示其质量分数，并说明它属于常量、微量、痕量还是超痕量组分。（输入以$\mathrm{mg\,kg^{-1}}$表示的质量分数。）
::: solution
$w = 2.5\ \mu\mathrm{g}/0.500\ \mathrm{g} = 5.0\ \mu\mathrm{g\,g^{-1}} = 5.0\ \mathrm{mg\,kg^{-1}}$（分子和分母同乘以$1000$）。这相当于$5.0\times10^{-6}$，即$5.0\times10^{-4}\ \%$，远低于$0.01\ \%$而高于$1\ \mathrm{ppb}$：属于痕量组分。（对大米而言这一数值非常高：精米中镉的法规限量在$0.2$–$0.4\ \mathrm{mg\,kg^{-1}}$量级。）
:::
:::

::: exercise 还原稀释 {level=1 check="300"}
将$0.5000\ \mathrm{g}$某肥料试样溶解并定容至$100.0\ \mathrm{cm^3}$。移取$5.00\ \mathrm{cm^3}$分取液稀释至$50.00\ \mathrm{cm^3}$，测得其中含锌$0.150\ \mathrm{mg\,dm^{-3}}$（空白可忽略）。求肥料中锌的质量分数。（以$\mathrm{mg\,kg^{-1}}$为单位输入，保留三位有效数字。）
::: solution
还原十倍稀释：储备溶液含$1.50\ \mathrm{mg\,dm^{-3}}$。在$0.1000\ \mathrm{dm^3}$中即为$0.150\ \mathrm{mg}$锌，来自$0.5000\ \mathrm{g} = 5.000\times10^{-4}\ \mathrm{kg}$试样：
$$
w = \frac{0.150\ \mathrm{mg}}{5.000\times10^{-4}\ \mathrm{kg}} = 300\ \mathrm{mg\,kg^{-1}} \;(0.0300\ \%).
$$
写成一行：$0.150 \times (50.00/5.00) \times 0.1000/(5.000\times10^{-4}) = 300$。
:::
:::

::: exercise 结合实例的术语 {level=1}
对于生菜中硝酸盐的测定，指出(a) 分析物，(b) 基体，(c) 紫外吸光度法中一种可能的干扰，以及(d) 该方法是绝对方法还是相对方法。然后，若从一个市场摊位购买20棵生菜，从中选出五棵，切碎并一起捣匀，取$2.0\ \mathrm{g}$匀浆进行提取，请指出其中的试样、实验室试样和测试份。
::: solution
(a) 硝酸根离子$\mathrm{NO_3^-}$。(b) 水、糖类、蛋白质、色素、其他离子——生菜中的其他一切成分。(c) 在紫外区有吸收的溶解有机物（一种加和性光谱干扰）；亚硝酸盐，它在$210$–$220\ \mathrm{nm}$附近也有吸收。(d) 相对方法：吸光度必须用硝酸盐标准进行校准。批是该摊位的存货（20棵生菜）；选出的五棵生菜是原始试样；匀浆是实验室试样（严格地说，是混合试样）；$2.0\ \mathrm{g}$是测试份。如果这五棵是图方便选出的（最上面的五棵），试样可能不具有代表性。
:::
:::

::: exercise 需要萃取几次？ {level=2 check="10"}
用每份$10.0\ \mathrm{cm^3}$的溶剂从$50.0\ \mathrm{cm^3}$水中萃取$D = 5.0$的溶质。使水中残留少于$0.10\ \%$所需的最少萃取次数是多少？（输入萃取次数。）
::: solution
每次萃取留下$q = 50.0/(50.0 + 5.0 \times 10.0) = 0.500$。需要$0.500^n < 0.0010$，即$n > \ln 0.0010/\ln 0.500 = 9.97$，所以$n = 10$（且$0.5^{10} = 9.8\times10^{-4}$，恰好低于$0.10\ \%$）。用相同总量溶剂一次以$100\ \mathrm{cm^3}$萃取，则会留下$50/(50 + 500) = 9.1\ \%$。
:::
:::

::: exercise 稀少的颗粒 {level=2 check="1.25"}
在一批谷物货物中，（按数目计）$0.20\ \%$的谷粒受到一种真菌毒素污染，其余是洁净的。为使测得的毒素含量的相对采样标准偏差为$2.0\ \%$，试样必须包含多少谷粒？假定所有受污染谷粒的污染程度相同。（以百万为单位输入谷粒数，保留三位有效数字。）
::: solution
由[[#eq-particles]]，取$p = 0.0020$，$\sigma_\mathrm{r} = 0.020$：
$$
n = \frac{1 - 0.0020}{0.0020 \times 0.020^2} = \frac{0.998}{8.0\times10^{-7}} = 1.25\times10^{6}\ \text{粒}.
$$
按每粒约$0.04\ \mathrm{g}$计，这大约是$50\ \mathrm{kg}$谷物——这就是为什么真菌毒素的采样方案规定要采集大量的合并试样，先研磨再分取子样；也是为什么实际的污染（各谷粒之间极不均匀）会使问题比这一模型所显示的更糟。
:::
:::

::: exercise 四个试样，各分析两次 {level=2 check="1.13"}
某物料的相对采样标准偏差$s_\mathrm{s} = 2.0\ \%$，相对测量标准偏差$s_\mathrm{m} = 1.5\ \%$。求四个试样各分析两次时总平均值的相对标准偏差。（以百分数输入，保留三位有效数字。）
::: solution
由[[#eq-nested-variance]]，
$$
s(\bar{x}) = \sqrt{\frac{2.0^2}{4} + \frac{1.5^2}{4\times 2}} = \sqrt{1.000 + 0.281} = \sqrt{1.281} = 1.13\ \%.
$$
把分析次数加倍（四个试样，各分析四次）只能把它减小到$\sqrt{1.000 + 0.141} = 1.07\ \%$；改为把试样数加倍（八个试样，各分析两次）则得到$\sqrt{0.500 + 0.141} = 0.80\ \%$。
:::
:::

::: exercise 加标样的回收率 {level=1 check="93.5"}
某废水试样测得铜$12.4\ \mu\mathrm{g\,dm^{-3}}$；加标$20.0\ \mu\mathrm{g\,dm^{-3}}$的一份测得$31.1\ \mu\mathrm{g\,dm^{-3}}$。求加标回收率，并说明它能证明什么、不能证明什么。（以百分数输入回收率，保留三位有效数字。）
::: solution
$R = (31.1 - 12.4)/20.0 \times 100\ \% = 93.5\ \%$。它表明，在这种基体中，测量对**加入的、溶解态的**铜有响应，存在约$6.5\ \%$的损失或抑制。它不能证明**原有的**铜（可能结合在颗粒或有机配合物中）在制备过程中被完全释放；检验这一点要用基体匹配的有证标准物质。
:::
:::

::: exercise 最优分配 {#exr-cost-allocation level=3 check="1.5"}
采集并制备一个试样的成本为$c_\mathrm{s}$，每次测量的成本为$c_\mathrm{m}$，因此$n_\mathrm{s}$个试样、每个测量$n_\mathrm{m}$次的方案成本为$C = n_\mathrm{s}c_\mathrm{s} + n_\mathrm{s}n_\mathrm{m}c_\mathrm{m}$。(a) 证明：在预算固定时，方差[[#eq-nested-variance]]在$n_\mathrm{m} = (s_\mathrm{m}/s_\mathrm{s})\sqrt{c_\mathrm{s}/c_\mathrm{m}}$时最小。(b) 对$s_\mathrm{s} = 2.0\ \%$、$s_\mathrm{m} = 1.5\ \%$、$c_\mathrm{s} = 40$和$c_\mathrm{m} = 10$（货币单位）计算其值，并说明实际中你会怎么做。（输入最优$n_\mathrm{m}$，保留两位有效数字。）
::: hint
利用预算消去$n_\mathrm{s}$，使方差成为仅关于$n_\mathrm{m}$的函数，然后求导。
:::
::: solution
(a) 由预算得$n_\mathrm{s} = C/(c_\mathrm{s} + n_\mathrm{m}c_\mathrm{m})$。代入，
$$
V(n_\mathrm{m}) = \frac{1}{n_\mathrm{s}}\left(s_\mathrm{s}^2 + \frac{s_\mathrm{m}^2}{n_\mathrm{m}}\right) = \frac{1}{C}\left(c_\mathrm{s} + n_\mathrm{m}c_\mathrm{m}\right)\left(s_\mathrm{s}^2 + \frac{s_\mathrm{m}^2}{n_\mathrm{m}}\right) = \frac{1}{C}\left(c_\mathrm{s}s_\mathrm{s}^2 + c_\mathrm{m}s_\mathrm{m}^2 + n_\mathrm{m}c_\mathrm{m}s_\mathrm{s}^2 + \frac{c_\mathrm{s}s_\mathrm{m}^2}{n_\mathrm{m}}\right).
$$
令$\mathrm{d}V/\mathrm{d}n_\mathrm{m} = (c_\mathrm{m}s_\mathrm{s}^2 - c_\mathrm{s}s_\mathrm{m}^2/n_\mathrm{m}^2)/C = 0$，得$n_\mathrm{m}^2 = c_\mathrm{s}s_\mathrm{m}^2/(c_\mathrm{m}s_\mathrm{s}^2)$，即$n_\mathrm{m} = (s_\mathrm{m}/s_\mathrm{s})\sqrt{c_\mathrm{s}/c_\mathrm{m}}$；二阶导数$2c_\mathrm{s}s_\mathrm{m}^2/(Cn_\mathrm{m}^3) > 0$确认这是极小值。

(b) $n_\mathrm{m} = (1.5/2.0)\sqrt{40/10} = 0.75 \times 2 = 1.5$。实际中$n_\mathrm{m}$必须是整数：针对实际预算比较$n_\mathrm{m} = 1$和$2$（此处二者给出的单位成本方差几乎相等），如果还希望用双份测量来检查过失误差，就选择$2$。这个公式说出了直觉所提示的道理：只有当测量噪声相对于采样较大，或者试样很昂贵时，平行测量才划算。
:::
:::

::: exercise 确定金分析的称样量 {level=3 check="5.12"}
某磨细矿石的$0.50\ \mathrm{g}$平行测试份给出金的总相对标准偏差为$5.0\ \%$；其中仅测量一项贡献$1.4\ \%$。(a) 求相对采样标准偏差和英格梅尔斯常数。(b) 多大的测试份质量能使采样标准偏差为$1.5\ \%$？(c) 为什么实验室可能更愿意把矿石研磨得更细？（以克为单位输入(b)的质量，保留三位有效数字。）
::: hint
在使用$mR^2 = K_\mathrm{s}$之前，先从总方差中减去测量方差。
:::
::: solution
(a) 由[[#eq-variance-add]]，$s_\mathrm{s}^2 = 5.0^2 - 1.4^2 = 25.00 - 1.96 = 23.04$，所以$s_\mathrm{s} = 4.80\ \%$。于是$K_\mathrm{s} = mR^2 = 0.50\ \mathrm{g} \times 23.04 = 11.5\ \mathrm{g}$。

(b) $m = K_\mathrm{s}/R^2 = 11.52/1.5^2 = 5.12\ \mathrm{g}$。

(c) $5\ \mathrm{g}$的测试份可能超出溶解和测量步骤所能良好处理的量（需要更多的酸，溶解的基体更多，空白更大）。研磨得更细会增加每克中的金粒数，从而降低$K_\mathrm{s}$本身——由[[#ex-grinding]]，所需质量大致随粒径的立方下降，前提是金粒确实被解离并被破碎，而不是被涂抹在研磨机上或损失掉。
:::
:::

::: exercise 用pH控制萃取 {level=3 check="0.93"}
苯甲酸（$\mathrm{p}K_\mathrm{a} = 4.20$；中性分子在某有机溶剂与水之间的$K_\mathrm{D}$取$100$，这是一个示意性数值）用一份$25.0\ \mathrm{cm^3}$的溶剂从$50.0\ \mathrm{cm^3}$水溶液中萃取。利用[[#def-distribution-ratio]]中的$D = K_\mathrm{D}[\mathrm{H^+}]/([\mathrm{H^+}] + K_\mathrm{a})$，求pH $2.00$和pH $7.00$时残留在水中的分数，并解释如何利用这一点把苯甲酸与中性化合物分离。（输入pH $7.00$时的残留分数，保留两位有效数字。）
::: hint
先求出各pH下的$D$；然后一次萃取留下$q = V_\mathrm{aq}/(V_\mathrm{aq} + DV_\mathrm{org})$。
:::
::: solution
$K_\mathrm{a} = 10^{-4.20} = 6.31\times10^{-5}$。

在pH $2.00$时：$D = 100 \times 10^{-2}/(10^{-2} + 6.31\times10^{-5}) = 99.4$，因此$q = 50.0/(50.0 + 99.4\times25.0) = 50.0/2535 = 0.020$：约$2\ \%$残留，$98\ \%$被萃取。

在pH $7.00$时：$D = 100 \times 10^{-7}/(10^{-7} + 6.31\times10^{-5}) = 0.158$，因此$q = 50.0/(50.0 + 0.158\times25.0) = 50.0/53.96 = 0.93$：$93\ \%$以苯甲酸根形式留在水中。

分离方法由此直接得出。把苯甲酸和中性化合物（其$D$与pH无关）的溶液在溶剂中与缓冲至pH $7$或更高的水一起振荡：中性化合物进入溶剂，苯甲酸根留在水中。然后把水层酸化至pH $2$再次萃取：苯甲酸此时转入新鲜溶剂中。这种酸碱萃取是色谱分析之前处理酸性分析物的标准净化步骤。
:::
