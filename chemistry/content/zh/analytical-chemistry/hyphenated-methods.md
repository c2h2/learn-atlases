一个常规的农药残留实验室，用一次约十五分钟的进样，就能对果蔬筛查数百种农药。一个毒理学实验室确证尿样中的某种药物，其把握足以在法庭上作证。一个反兴奋剂实验室把人体自身合成的睾酮与作为药物服用的睾酮区分开来。每一例中，都是色谱先按时间分离混合物，质谱仪再测量由各化合物生成的离子的质荷比，对流出的物质进行鉴定和定量。这种把分离装置与光谱检测器连用、以连字符书写的组合——GC–MS、LC–MS、LC–MS/MS、GC–ICP-MS——称为**联用技术**。任何一半都独木难支：色谱说不出峰是什么；质谱仪面对同时混进来的一千种化合物，也说不出哪个离子来自哪种物质。

本章说明两半如何连接、组合如何应用。我们先看把色谱柱流出液变成气相离子的接口与离子源，再看质量分析器及其分辨力与质量准确度，然后是牺牲信息换取灵敏度的几种采集模式——全扫描、选择离子监测与选择反应监测。接着处理支配定量工作的两个问题：**基体效应**——它使同样量的分析物在不同样品中给出不同的信号——以及它的解药：用同位素标记内标的**同位素稀释**。质谱的基本原理——电离、碎裂、同位素峰形与谱图解析——在[[spectroscopy/mass-spectrometry]]中展开；分离原理见[[analytical-chemistry/chromatography]]；校准统计见[[analytical-chemistry/statistics-calibration]]。

## 把色谱仪接到质谱仪上

根本的困难在于压力。质谱仪的分析器工作于约$10^{-3}$–$10^{-5}\ \mathrm{Pa}$的真空下，使离子得以飞行而不发生碰撞；色谱仪输出的却是常压或更高压力的气流或液流。

**GC–MS**解决这个问题很容易。毛细管柱携带约$1\ \mathrm{cm^3\,min^{-1}}$的氦气，现代真空泵毫不费力就能把它抽走，因此色谱柱经加热的传输线直接引入离子源。标准的离子源是**电子电离**（EI）：用$70\ \mathrm{eV}$的电子轰击分子，生成分子自由基正离子$\mathrm{M^{+\bullet}}$，它们以可重复的方式碎裂。由于$70\ \mathrm{eV}$下的EI谱几乎与仪器无关，可以和由数十万张参考谱图组成的谱库比对。较软的**化学电离**（CI）使用甲烷或氨等反应气，在需要分子质量时给出碎裂很少的质子化分子$[\mathrm{M+H}]^+$。

**LC–MS**更难：$0.2$–$1\ \mathrm{cm^3\,min^{-1}}$的液流会变成每分钟数百立方厘米的蒸气。突破在于常压电离。**电喷雾电离**（ESI）中，色谱柱流出液通过一根保持数千伏电压的毛细管；液体被拉成锥体，碎裂为高度带电的雾滴，雾滴因蒸发（有热氮辅助）而收缩，直到电荷密度迫使离子进入气相。离子经一个小孔被引入一系列差动抽真空级。ESI是软电离：它从极性分子给出$[\mathrm{M+H}]^+$、$[\mathrm{M+Na}]^+$或$[\mathrm{M-H}]^-$，从蛋白质给出多电荷离子$[\mathrm{M}+z\mathrm{H}]^{z+}$，即使大的生物分子也落入普通分析器的$m/z$范围。**大气压化学电离**（APCI）在加热管中使流出液汽化，由电晕放电引发的离子-分子反应使其电离；它适合极性较小、分子较小的物质。

这些离子源对色谱提出了条件。LC–MS只能用挥发性缓冲试剂（甲酸铵或乙酸铵、甲酸或乙酸）；磷酸盐和其他不挥发盐会在离子源上结垢。离子对试剂和某些表面活性剂会抑制电离。而且，由于ESI的电离效率取决于同一时刻到达液滴的所有其他物质，共流出的基体化合物会改变分析物的信号——即下文讨论的基体效应。

## 质量分析器：分辨力与质量准确度

质量分析器按$m/z$分离离子。常见类型在分辨力、质量准确度、速度以及允许的扫描模式上有所不同。

::: definition 分辨力与质量准确度 {#def-resolving-power}
质量分析器在质荷比为$m/z$的峰处的**分辨力**为$R = m/\Delta m$，其中$\Delta m$是峰的半高全宽（FWHM定义）。两个高度相近、相隔$\Delta m$的峰，恰能分辨的条件是$R \approx m/\Delta m$。一次测量的**质量准确度**是测量质量与理论（精确）质量之差，通常以ppm表示：
$$
\delta = \frac{m_\mathrm{measured} - m_\mathrm{theoretical}}{m_\mathrm{theoretical}}\times10^6\ \mathrm{ppm} .
$$
**名义质量**（单位分辨）仪器能分开相邻的整数质量；**高分辨精确质量**（HRAM）仪器能分开名义质量相同而精确质量不同的离子，精确到几个ppm或更好。
:::

- **四极杆**质量过滤器让$m/z$单一的离子一次一个地通过四根平行杆，杆上同时施加射频与直流电压。它为单位分辨，坚固而便宜，是常规GC–MS和LC–MS的标准分析器。
- **三重四极杆**（QqQ）在两个质量过滤四极杆之间有一个碰撞池。第一级选择一个**前体离子**，它在池中与氩或氮碰撞而碎裂（碰撞诱导解离），第三级选择一个**产物离子**。这就是**串级质谱**（MS/MS）。
- **飞行时间**（TOF）分析器把一包离子加速到相同的动能，测量它们沿无场管飞行的时间；由$\tfrac12mv^2 = zeU$，较轻的离子先到，且$t \propto \sqrt{m/z}$。TOF每秒记录完整谱图数千次，分辨力约$10^4$–$10^5$，质量准确度为几个ppm。
- **轨道阱**（Orbitrap）捕获绕中心纺锤形电极轨道运动的离子；其轴向振荡频率$\omega \propto \sqrt{z/m}$以像电流的形式测出，并经傅里叶变换转为谱图，分辨力高于$10^5$，质量准确度为亚ppm到几个ppm。傅里叶变换离子回旋共振仪器利用强磁场中的回旋频率，数值还要高。

质量准确度之所以强大，是因为精确质量不是整数。每种核素的质量亏损（来自其结合能）使每个元素式都有一个特征精确质量：$\mathrm{C_{17}H_{19}NO_3}$和$\mathrm{C_{18}H_{23}NO_2}$的名义质量都是$285$，精确中性质量却相差$0.036\ \mathrm{u}$，一台$R = 20\,000$、准确度$5\ \mathrm{ppm}$的仪器能轻易区分两者。几个ppm以内的精确质量，连同同位素峰形，通常就能把一个小分子的元素式缩小到少数几个候选。

## 采集模式：信息与灵敏度的权衡

与色谱联用的质谱仪随峰流出色谱柱而反复记录谱图。色谱峰只持续几秒；要把峰形描述得足以定量，每个峰上大约需要$10$–$20$个测量点，因此分析器的每个**循环**必须远快于一秒。这个循环时间如何分配，决定了实验能做什么。

- **全扫描**模式中，四极杆在每个循环内扫过整个$m/z$范围（比如$50$–$550$），记录完整谱图。把每张谱图中所有离子电流之和随时间作图，得到**总离子流色谱图**（TIC）；从存储的谱图中提取某一选定$m/z$处的电流，得到**提取离子色谱图**（EIC）。全扫描对鉴定未知物必不可少。
- **选择离子监测**（SIM）中，四极杆在目标分析物若干个特征的$m/z$值之间跳转，把整个循环都用于它们。不记录谱图，但每个选定离子被测量的时间长得多，信噪比随之升高。
- 在三重四极杆上的**选择反应监测**（SRM，也称多反应监测，MRM）中，第一四极杆选择分析物的前体离子，第三级选择它的某个产物离子。共流出的基体化合物现在必须既有相同的前体质量*又有*相同质量的碎片才会产生干扰，于是化学背景几乎消失。SRM是复杂基体中目标化合物痕量定量的标准——血浆中的药物、食品中的农药、谷物中的真菌毒素。

::: proposition 更长驻留时间带来的信噪比增益 {#prop-dwell}
若离子到达检测器是平均速率为$r$（每秒离子数）的泊松过程，且噪声以计数统计为主，则驻留时间$\tau$内计得的离子数的平均值为$r\tau$、标准差为$\sqrt{r\tau}$，于是信噪比为
$$
\frac{S}{N} = \sqrt{r\tau} .
$$ {#eq-dwell}
把循环时间$T_\mathrm{c}$用于$n$个离子而不是$M$个质量通道，每个离子的驻留时间增至$M/n$倍，信噪比增至$\sqrt{M/n}$倍。
:::

::: proof
对泊松过程，长度$\tau$的区间内的计数$X$有$\E[X] = r\tau$和$\Var(X) = r\tau$（泊松变量的方差等于均值）。信号是平均计数，噪声是其标准差，所以$S/N = r\tau/\sqrt{r\tau} = \sqrt{r\tau}$。对$M$个通道作全扫描时，每个通道每个循环获得驻留时间$T_\mathrm{c}/M$；对$n$个离子作SIM时，每个获得$T_\mathrm{c}/n$。两者$S/N$之比为$\sqrt{(T_\mathrm{c}/n)/(T_\mathrm{c}/M)} = \sqrt{M/n}$。（当化学背景而非计数噪声主导时——复杂样品的单级MS中常常如此——增益要小些；SRM则直接对付背景本身。）
:::

::: widget plot
f: sqrt(500/x)
x: 1, 50
y: 0, 25
labels: \text{相对全扫描的信噪比增益}
caption: 在相同循环时间内，选择离子监测相对于$500$个质量通道全扫描的信噪比增益，见[[#eq-dwell]]，对监测的离子数（$x$）作图。监测4个离子时增益约$11$；监测50个，仍有约$3$。这一增益只有在噪声受计数统计限制时才真实存在；在不洁净的基体中，选定$m/z$处的化学背景与分析物一样被高效地测得，这正是最苛刻的工作要采用串级质谱（SRM）的原因。
:::

::: example 全扫描还是SIM？ {#ex-sim}
一台GC–MS以$0.50\ \mathrm{s}$的循环扫描$m/z$ $50$–$549$（$500$个通道）。分析物的主要离子在其峰顶以$2.0\times10^4$离子每秒到达检测器。(a) 全扫描时该$m/z$每个循环计得多少离子？相对标准偏差是多大？(b) 相同循环下对四个离子做SIM，再算一遍。
::: solution
(a) 每通道驻留时间：$0.50/500 = 1.0\ \mathrm{ms}$。计数：$2.0\times10^4\times1.0\times10^{-3} = 20$；相对标准偏差$1/\sqrt{20} = 22\ \%$。

(b) 每离子驻留时间：$0.50/4 = 125\ \mathrm{ms}$。计数：$2500$；相对标准偏差$1/\sqrt{2500} = 2.0\ \%$。信噪比提高了$\sqrt{125} = 11.2$倍，与[[#prop-dwell]]一致。代价是四个选定$m/z$之外的任何东西都不再被记录：意外的污染物就看不见了。
:::
:::

## 鉴定：保留、离子与同位素峰形

联用方法中的鉴定建立在若干互相独立的证据之上，其中任何单独一项都可能失效：

1. **保留时间**（或保留指数）与同一序列中测定的标准物质一致，且落在狭窄的容差之内；
2. **质谱图**（全扫描），或**若干特征离子**或跃迁的存在（SIM、SRM）——通常至少两个；
3. 这些离子强度之**比**在规定的容差内与标准物质一致（例如，欧盟关于农药残留的指南接受离子比率相对于标准物质$\pm30\ \%$以内）；
4. 对精确质量仪器，**精确质量**在几个ppm以内，以及**同位素峰形**。

同位素峰形对氯和溴特别有信息量。氯是$75.76\ \%$的$^{35}\mathrm{Cl}$和$24.24\ \%$的$^{37}\mathrm{Cl}$；溴是$50.69\ \%$的$^{79}\mathrm{Br}$和$49.31\ \%$的$^{81}\mathrm{Br}$（IUPAC代表性同位素组成）。因此，含$n$个氯原子的离子呈现一组相隔两个质量单位的峰，其强度服从二项分布。

::: example 识别两个氯 {#ex-isotope-pattern}
GC–MS全扫描中一个峰显示$m/z$ $146$、$148$和$150$处的离子，相对强度为$100$、$64$和$10$。该离子含几个氯原子？预测含一个和三个氯原子时的强度。
::: solution
$n$个氯时的强度正比于$\binom{n}{k}q^{n-k}p^k$，其中$q = 0.7576$、$p = 0.2424$，于是各相邻峰与第一个峰之比是$p/q = 0.3200$的幂级数。$n = 1$：$100 : 32$。$n = 2$：$100 : 2\times32.0 : 32.0^2/100 = 100 : 64.0 : 10.2$——即观测到的峰形。$n = 3$：$100 : 3\times32.0 : 3\times(0.320)^2\times100 : (0.320)^3\times100 = 100 : 96 : 31 : 3.3$。该离子含两个氯；$m/z = 146$且含$\mathrm{Cl_2}$，与$\mathrm{C_6H_4Cl_2^{+\bullet}}$——某二氯苯的分子离子——相符。是哪个异构体必须由保留时间判定，因为三种二氯苯给出的EI谱几乎相同。
:::
:::

## 基体效应

在电喷雾中，分析物离子与液滴里所有其他物质争夺有限的表面电荷和通往液滴表面的位置。因此，来自样品的共流出化合物——盐、血浆中的磷脂、食品中的色素和糖——可能**抑制**（有时**增强**）分析物的电离。某一确定量的分析物的信号于是取决于样品，用溶剂做的校准就会给出有偏的结果。APCI和EI受影响小得多，但并非免疫。

::: definition 基体效应 {#def-matrix-effect}
**基体效应**按如下方式量化：比较加入空白样品提取液*之后*的分析物响应$B$与同浓度纯溶剂中的响应$A$：
$$
\mathrm{ME} = \left(\frac{B}{A} - 1\right)\times100\ \% .
$$
负值表示抑制，正值表示增强。比较*提取之前*加入的分析物响应与$B$，得到提取本身的**回收率**；两者之积是总的**过程效率**。
:::

::: example 血浆提取液中的离子抑制 {#ex-matrix-effect}
$10\ \mathrm{ng\,cm^{-3}}$的某药物在溶剂中给出峰面积$1.21\times10^6$，加入经蛋白沉淀的血浆提取液后为$8.42\times10^5$。计算基体效应，并求未知样品若不加校正、直接用溶剂标准定量时的偏差。
::: solution
$\mathrm{ME} = (8.42\times10^5/1.21\times10^6 - 1)\times100\ \% = (0.696 - 1)\times100\ \% = -30\ \%$。含$10\ \mathrm{ng\,cm^{-3}}$的血浆样品会被报成约$7.0\ \mathrm{ng\,cm^{-3}}$。更糟的是，抑制程度随病人而异（脂质含量不同）、沿色谱而变化（磷脂在特征区域洗脱），无法用一个因子校正。补救办法按大致优先顺序：与分析物共流出、受到同样抑制的同位素标记内标；更好的样品净化（固相萃取、除磷脂）；用色谱改动把分析物移离抑制区域；稀释提取液；基体匹配校准；标准加入法。
:::
:::

::: warning 内标的好坏取决于它与分析物的相似程度 {#warn-internal-standard}
内标只有在与分析物完全同样地经历基体效应时才能校正之，这要求它与分析物共流出并以相同的方式电离。一个晚三十秒洗脱的结构类似物可能处在截然不同的抑制环境中，使校正越校越坏。即使是氘标记内标，反相色谱也可能使其与未标记分析物稍有分离（氘代化合物常保留略低），若它恰洗脱在抑制区的边缘，两者受到的抑制就不相同；$^{13}\mathrm{C}$或$^{15}\mathrm{N}$标记内标的共流出更为严格。标记内标还必须不含未标记物质，其标记也不能在制备过程中因交换而丢失（氧或氮上的氘会与溶剂质子交换；碳上的氘通常不会）。最后，内标只能校正它加入之后发生的事——它必须在样品制备一开始就加入，才能校正提取损失。
:::

## 同位素稀释

化学分析中最准确的定量方法，是向样品中加入已知量的、同位素组成经过改变的分析物本身——**加标**——并用质谱测定混合后两种同位素形态之比。样品与加标一旦混匀平衡，此后任何损失都同样影响两种形态，于是回收率、基体效应和漂移统统抵消。**同位素稀释质谱法**（IDMS）被国际计量界承认为基准比率方法，用于认证标准物质和确立临床化学中的参考值。

对有机分析物，标记内标（例如带三个$^{13}\mathrm{C}$或若干个氘原子）与分析物质量不同，两者的离子分别测量。若同位素分布不重叠，计算就只是响应因子接近$1$的内标法：$c_x = c_\mathrm{IS}\,(A_x/A_\mathrm{IS})/\mathrm{RRF}$，其中相对响应因子$\mathrm{RRF}$由校准求得。对元素，分析物与加标由相同的同位素以不同的比例组成，计算必须同时顾及两者中的每一种同位素。

::: proposition 同位素稀释方程 {#prop-idms}
某样品含$n_x$摩尔某元素，其同位素$a$和$b$的量分数（丰度）为$a_x$和$b_x$。加入$n_y$摩尔丰度为$a_y$和$b_y$的加标（富集$b$）并达到平衡。若混合物的测得量比$R = n(a)/n(b)$已经校正了仪器的质量偏差，则
$$
n_x = n_y\,\frac{Rb_y - a_y}{a_x - Rb_x} .
$$ {#eq-idms}
$n_x$的相对不确定度是$R$的相对不确定度乘以**误差放大因子**
$$
f(R) = R\left(\frac{b_y}{Rb_y - a_y} + \frac{b_x}{a_x - Rb_x}\right),
$$
它在$R = \sqrt{(a_x/b_x)(a_y/b_y)}$处取最小值，即样品与加标同位素比的几何平均。
:::

::: proof
混合物中同位素$a$的量为$n_xa_x + n_ya_y$，$b$的量为$n_xb_x + n_yb_y$。于是
$$
R = \frac{n_xa_x + n_ya_y}{n_xb_x + n_yb_y} \quad\Rightarrow\quad R\,n_xb_x + R\,n_yb_y = n_xa_x + n_ya_y \quad\Rightarrow\quad n_x(a_x - Rb_x) = n_y(Rb_y - a_y),
$$
即[[#eq-idms]]。测量的只是一个比率，因此平衡之后按相同比例移走$a$和$b$的任何损失都不改变$R$。不确定度方面，对$\ln n_x = \ln n_y + \ln(Rb_y - a_y) - \ln(a_x - Rb_x)$求导：
$$
\frac{\partial\ln n_x}{\partial\ln R} = R\,\frac{\partial\ln n_x}{\partial R} = R\left(\frac{b_y}{Rb_y - a_y} + \frac{b_x}{a_x - Rb_x}\right) = f(R),
$$
所以$u(n_x)/n_x = f(R)\,u(R)/R$。记$R_x = a_x/b_x$、$R_y = a_y/b_y$，有$R_y < R < R_x$；则$f = R/(R - R_y) + R/(R_x - R)$。令$\dd f/\dd R = 0$得$-R_y/(R - R_y)^2 + R_x/(R_x - R)^2 = 0$，即$(R_x - R)/(R - R_y) = \sqrt{R_x/R_y}$，其解为$R = \sqrt{R_xR_y}$。在两个极端——混合物以样品为主（$R\to R_x$）或以加标为主（$R\to R_y$）——$f$发散，因为那时$R$几乎不随$n_x$变化。
:::

::: example 同位素稀释法测铅 {#ex-idms}
向$1.000\ \mathrm{g}$沉积物中加入富$^{206}\mathrm{Pb}$的铅加标$50.0\ \mathrm{nmol}$（$^{208}\mathrm{Pb}$ $0.30\ \%$、$^{206}\mathrm{Pb}$ $99.5\ \%$）。消解、平衡并经ICP-MS测量后，混合物中经质量偏差校正的比率$^{208}\mathrm{Pb}/^{206}\mathrm{Pb}$为$0.400$。样品自身的铅另行测得$^{208}\mathrm{Pb}$ $52.4\ \%$、$^{206}\mathrm{Pb}$ $24.1\ \%$。求沉积物的铅含量，以$\mu\mathrm{g\,g^{-1}}$表示（$M(\mathrm{Pb}) = 207.2\ \mathrm{g\,mol^{-1}}$；把它作为样品铅的近似值）。
::: solution
由[[#eq-idms]]，取$a = {}^{208}\mathrm{Pb}$、$b = {}^{206}\mathrm{Pb}$：
$$
n_x = 50.0\ \mathrm{nmol}\times\frac{0.400\times0.995 - 0.003}{0.524 - 0.400\times0.241} = 50.0\times\frac{0.395}{0.4276} = 46.2\ \mathrm{nmol}.
$$
质量：$46.2\times10^{-9}\times207.2 = 9.57\times10^{-6}\ \mathrm{g}$，故沉积物含铅$9.57\ \mu\mathrm{g\,g^{-1}}$。之所以必须测定样品自身的同位素组成，是因为铅的组成在自然界中会变化（部分来自铀和钍衰变的放射成因）——这一性质正被用于追溯铅污染的来源。$R = 0.400$处的误差放大为$1.23$，因此$0.2\ \%$的比率不确定度约给结果贡献$0.25\ \%$。
:::
:::

::: quiz
为什么同位素稀释能校正不完全的提取，外标校准却不能？
- [ ] 因为质谱仪检测同位素比其他检测器更灵敏。
- [x] 因为加标与分析物平衡之后，损失按相同的比例移走两种形态，而测量的只是两者之比。
- [ ] 因为加标增加了分析物的总量，损失所占的比例就小了。
- [ ] 因为同位素标记化合物在提取过程中不会损失。
::: solution
被测量的量是一个比率；平衡之后任何不区分同位素的过程——提取不完全、吸附、蒸发损失、离子抑制、灵敏度下降——对分子和分母的影响相同。决定性的条件是平衡：在任何损失发生之前，加标必须处于与分析物相同的化学形态和环境。若在对难处理矿物的不完全消解*之后*才加标，它就无法校正仍封存在矿物内部的分析物。
:::
:::

## 形态分析：色谱与元素特异性检测联用

一个元素的毒性与迁移性取决于它的化学形态。砷甜菜碱是鱼中主要的砷化合物，几乎无毒；无机亚砷酸盐和砷酸盐却是致癌物；甲基汞以无机汞不会的方式在食物链中富集；铬(VI)比铬(III)危险得多。[[analytical-chemistry/atomic-spectrometry]]给出的总量结果无法区分它们。**形态分析**把一种分离——砷形态用HPLC（常为离子交换），有机汞和有机锡化合物用衍生化后的GC——与ICP-MS相连，后者以高灵敏度、并且很大程度上不依赖化学形态地检测每个流出物种中的元素。**形态特异性同位素稀释**用同位素富集的单个物种的形态，可校正制备过程中的损失以及物种之间的相互转化。

## 选择与验证联用方法

| 问题 | 典型选择 |
|---|---|
| 挥发性、热稳定的有机物；未知物鉴定 | GC–MS（EI，全扫描，谱库检索） |
| 痕量水平的目标挥发性残留物 | GC–MS/MS（SRM） |
| 极性、不挥发或热不稳定的目标物（药物、农药、真菌毒素） | LC–MS/MS（ESI，SRM）加标记内标 |
| 未知物筛查或极多目标物的筛查 | LC–HRMS（TOF或Orbitrap，精确质量） |
| 元素形态 | HPLC–ICP-MS或GC–ICP-MS |

验证遵循[[analytical-chemistry/statistics-calibration]]，并加上MS特有的项目：基体效应须在数个独立来源的空白基体中测定；鉴定判据（保留、离子比率、质量准确度）事先固定；残留（carry-over）通过在最高浓度标准之后注入一个空白来检查；分析物在基体中以及在自动进样器中的稳定性亦须确证。质谱仪是复杂的仪器，配有高压电源、真空系统和加热的离子源，而LC–MS的溶剂易燃；这些与其他仪器一样，在实验室的通用风险评估下运行。

## 后续内容

质谱图的解析——碎裂规律、重排、氮规则以及其他元素的同位素峰形——在[[spectroscopy/mass-spectrometry]]中展开，并在[[spectroscopy/structure-problems]]中用于结构测定。药物与代谢物的LC–MS/MS是[[medicinal-chemistry/pharmacokinetics]]中药代动力学研究的分析支柱，同样的方法也用于监测[[environmental-chemistry/environmental-monitoring]]和[[environmental-chemistry/pollutants-fate]]中的污染物。蛋白质组学——通过酶解肽段的LC–MS/MS鉴定和定量数千种蛋白质——建立在[[biochemistry/amino-acids-proteins]]之上。

::: history
罗兰·戈尔克（Gohlke）和弗雷德·麦克拉弗蒂（McLafferty）在陶氏化学公司于20世纪50年代中期把一台气相色谱仪接到一台飞行时间质谱仪上，这就是第一台GC–MS。拉格纳·吕哈格（Ryhage）的喷射分离器以及J.思罗克·沃森（Watson）和克劳斯·比曼（Biemann）的溢流分离器（均为1964年）从填充柱流出液中除去大部分载气，而直接连接离子源的熔融石英毛细管柱使GC–MS在20世纪80年代成为常规技术。马尔科姆·多尔（Dole）于1968年演示了由电喷雾获得气相离子，约翰·费恩（Fenn）及其同事在20世纪80年代把它发展成大分子的分析离子源；费恩与田中耕一（Tanaka）因生物大分子的软电离共享2002年诺贝尔化学奖。理查德·约斯特（Yost）和克里斯蒂·恩克（Enke）于1978年建造了第一台三重四极杆质谱仪。亚历山大·马卡罗夫（Makarov）发明了轨道阱，2005年实现商品化。同位素稀释可追溯到乔治·德海韦西（Hevesy）20世纪10至20年代的放射性示踪工作，并于20世纪40至50年代建立在质谱的基础之上；如今它是临床化学和元素分析中最高级别参考方法的基础。
:::

::: summary
- 联用技术把按时间的分离（GC、LC）与按质量的鉴定（MS）结合起来；面对复杂混合物，任何一半都不够用。
- GC可直接接EI离子源，其可重复的谱图供谱库检索；LC需要常压电离（ESI、APCI）、挥发性缓冲试剂，并须注意基体效应。
- 分辨力$R = m/\Delta m$和质量准确度（ppm）决定了分析器能区分什么；四极杆为单位分辨，TOF和Orbitrap分析器给出精确质量。
- 全扫描用于鉴定；计数统计下SIM把信噪比提高$\sqrt{M/n}$倍；三重四极杆上的SRM消除化学背景，是痕量目标定量的标准。
- 鉴定综合保留时间、若干离子及其比率、精确质量与同位素峰形（氯和溴为二项分布）。
- 基体效应$\mathrm{ME} = (B/A - 1)\times100\ \%$使ESI结果有偏；共流出的同位素标记内标可校正之。
- 同位素稀释$n_x = n_y(Rb_y - a_y)/(a_x - Rb_x)$只测一个比率，使平衡之后的损失抵消；误差放大在$R = \sqrt{R_xR_y}$附近最小。
:::

## 习题

::: exercise 质量准确度 {level=1 check="-2.0"}
理论$m/z$为$304.1549$的离子测得$304.1543$。求质量误差，以ppm表示。（输入两位有效数字。）
::: solution
$\delta = (304.1543 - 304.1549)/304.1549\times10^6 = -0.0006/304.1549\times10^6 = -2.0\ \mathrm{ppm}$。精确质量鉴定的常用接受窗口是$\pm5\ \mathrm{ppm}$。
:::
:::

::: exercise 分辨力 {level=1 check="30000"}
要分开$m/z$ $300.1000$和$300.1100$的两个离子，需要多大的分辨力（FWHM）？（输入$R$。）
::: solution
$R = m/\Delta m = 300.10/0.0100 = 3.0\times10^4$。TOF或Orbitrap仪器可提供这种分辨力；四极杆（此处$R \approx 300$）不行。
:::
:::

::: exercise 一个氯 {level=1 check="0.320"}
用IUPAC丰度$75.76\ \%$的$^{35}\mathrm{Cl}$和$24.24\ \%$的$^{37}\mathrm{Cl}$，求含一个氯原子的离子的强度比$\mathrm{M+2}/\mathrm{M}$（忽略其他元素）。（输入三位有效数字的比率。）
::: solution
$24.24/75.76 = 0.320$，即M : M+2约为$3:1$——单个氯的标志。小分子对M+2的$^{13}\mathrm{C}$贡献（两个$^{13}\mathrm{C}$原子）很小。
:::
:::

::: exercise 用标记内标定量 {level=2 check="22.3"}
血浆样品加入$20.0\ \mathrm{ng\,cm^{-3}}$的$^{13}\mathrm{C_6}$标记内标。提取后LC–MS/MS峰面积为$4.15\times10^5$（分析物跃迁）和$3.62\times10^5$（内标）。校准求得相对响应因子为$1.03$。求分析物浓度。（以$\mathrm{ng\,cm^{-3}}$输入，三位有效数字。）
::: solution
$c_x = c_\mathrm{IS}(A_x/A_\mathrm{IS})/\mathrm{RRF} = 20.0\times(4.15/3.62)/1.03 = 20.0\times1.1464/1.03 = 22.3\ \mathrm{ng\,cm^{-3}}$。提取中的任何损失或电离中的任何抑制都同样影响分析物与内标，在比率中抵消。
:::
:::

::: exercise 测量基体效应 {level=2 check="-30"}
验证[[#ex-matrix-effect]]中的基体效应，并在提取*前*加入血浆的分析物响应为$7.66\times10^5$时求过程效率。（以百分数输入基体效应，两位有效数字。）
::: solution
$\mathrm{ME} = (8.42/12.1 - 1)\times100 = -30\ \%$。回收率$= 7.66\times10^5/8.42\times10^5 = 91.0\ \%$。过程效率$= 7.66\times10^5/1.21\times10^6 = 63.3\ \%$，等于$0.696\times0.910$。把两种效应分开，能告诉分析者该往哪里改进：这里提取很好，问题出在电离抑制。
:::
:::

::: exercise 两个氯 {level=2 check="10.2"}
导出含两个氯原子的离子的M、M+2和M+4峰的相对强度，令M为$100$。（输入M+4的强度。）
::: solution
$0$、$1$和$2$个重同位素原子的概率为$q^2$、$2pq$和$p^2$，其中$q = 0.7576$、$p = 0.2424$：即$0.5740$、$0.3673$和$0.0588$。相对M：$100 : 64.0 : 10.2$。这一簇峰是快速的直观指纹；三个氯时为$100 : 96 : 31 : 3.3$。
:::
:::

::: exercise 一道同位素稀释计算 {level=3 check="9.57"}
由混合物中两种同位素的量出发推导[[#eq-idms]]。然后验证[[#ex-idms]]：求沉积物的铅质量分数。最后说明，若略去质量偏差校正、仪器把$^{208}\mathrm{Pb}/^{206}\mathrm{Pb}$测高$1\ \%$，结果会偏向哪一边。（以$\mu\mathrm{g\,g^{-1}}$输入铅含量，三位有效数字。）
::: hint
在[[#eq-idms]]中，$R$在分子中带正号，在分母中带负号。
:::
::: solution
推导即[[#prop-idms]]的证明。数值上，$n_x = 50.0\times(0.3980 - 0.003)/(0.524 - 0.0964) = 50.0\times0.3950/0.4276 = 46.19\ \mathrm{nmol}$，即$46.19\times10^{-9}\times207.2\ \mathrm{g} = 9.57\ \mu\mathrm{g}$，在$1.000\ \mathrm{g}$中：$9.57\ \mu\mathrm{g\,g^{-1}}$。$R$偏高$1\ \%$（$0.404$）时，$n_x = 50.0\times(0.4020 - 0.003)/(0.524 - 0.09736) = 50.0\times0.3990/0.4266 = 46.76\ \mathrm{nmol}$：结果将偏高$1.2\ \%$，比率误差被乘以了$f(0.400) = 1.23$。ICP-MS中这种量级的质量偏差很常见，这就是它要用认证同位素组成的标准物质来校正的原因。
:::
:::

::: exercise SIM带来的增益 {level=3 check="11.2"}
利用[[#prop-dwell]]，求在相同循环时间内对四个离子做SIM相对于$500$个通道全扫描的信噪比增益。然后解释为什么在严重污染的提取液中观测增益可能只有两三倍，以及SRM如何补救。（输入三位有效数字的理论增益。）
::: solution
增益$= \sqrt{M/n} = \sqrt{500/4} = \sqrt{125} = 11.2$。在不洁净的提取液中，选定$m/z$处的噪声以共流出的、名义质量相同的基体化合物离子（化学噪声）为主，SIM测它们和分析物一样高效：背景随驻留时间增高的速度与信号一样快，所以比率改善远小于计数统计的估计。SRM要求干扰物与分析物既有相同的前体质量又有相同的产物离子质量，能做到者寥寥，于是化学背景大幅下降，检出限改善几个数量级。
:::
