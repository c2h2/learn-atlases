某实验室购入一种河流沉积物的有证标准物质（CRM），其铅含量认证为$25.0\ \mu\mathrm{g\,g^{-1}}$。五份试料经该实验室的常规方法消解、测量，给出$24.1$、$24.6$、$23.8$、$24.4$和$24.9\ \mu\mathrm{g\,g^{-1}}$。每个结果都偏低，但每个结果也都离得不远。这方法真有系统偏差，还是对$25.0$作五次诚实测量得到均值$24.36$本来就是正常现象？下周，这家实验室要根据一条校准线报告一位陌生人花园土壤中的铅，而园主会想知道消解液中的$5.25\ \mathrm{mg\,dm^{-3}}$是否真的可能是$5.0$。而当仪器读出一个"几乎为零"的空白时，必须有人来判定：信号低于多少时，诚实的报告应当写"未检出"。

这些就是本章的问题，回答它们靠一套不大的统计工具：比较结果用的置信区间与显著性检验、由校准线读出浓度的不确定度、对付基体效应与损失的标准加入法和内标法、检出限，以及表明方法持续正常工作的验证与控制图。其背后的基本概念——均值、标准偏差、平均值的标准不确定度与不确定度传播——见[[laboratory-methods/measurement-uncertainty]]；带标准误差的最小二乘直线在[[laboratory-methods/data-graphs]]中推导。这里我们用它们来做决策。

## 置信区间与t分布

设$n$个平行结果$x_1,\dots,x_n$来自真值为$\mu$、标准偏差为$\sigma$的正态分布。均值$\bar{x}$本身服从正态分布，其标准偏差为$\sigma/\sqrt{n}$。若知道$\sigma$，区间$\bar{x} \pm 1.96\,\sigma/\sqrt{n}$在$95\ \%$的重复实验中会包含$\mu$。但我们从不知道$\sigma$；手头只有样本标准偏差$s$，而它由寥寥几个结果算出时可能偏离很远。威廉·戈塞特（Gosset）1908年算出了为补偿这一点区间必须加宽多少。

::: definition 平均值的置信区间 {#def-confidence-interval}
来自正态分布的$n$个独立结果，样本均值为$\bar{x}$、样本标准偏差为$s$，则真值$\mu$在置信水平$1-\alpha$下的**置信区间**为
$$
\mu = \bar{x} \pm \frac{t\,s}{\sqrt{n}}, \qquad t = t_{1-\alpha/2,\ n-1},
$$ {#eq-ci}
其中$t_{1-\alpha/2,\,\nu}$是**学生t分布（Student's $t$分布）**在$\nu = n-1$个**自由度**下的双侧临界值。这个区间是对整个程序的陈述：这样构造的区间在$1-\alpha$比例的重复实验中会包含$\mu$。
:::

量$t = (\bar{x}-\mu)/(s/\sqrt{n})$服从学生分布，它形似正态曲线但尾部更厚，因为$s$本身也在波动。结果少时尾部极厚：$95\ \%$的$t$值在$\nu = 1$时为$12.71$，$\nu = 2$时为$4.30$，$\nu = 4$时为$2.78$，$\nu = 9$时为$2.26$，只有$\nu$很大时才接近正态值$1.96$。这就是平行双次测定提供的精密度信息极少、精密度要紧时分析者力求至少做五六个平行测定的定量原因。

[[#eq-ci]]中的区间只覆盖随机误差。有系统偏差的方法会在错误的值周围给出一个看起来完全有效的区间——这正是标准物质的用场。

## 显著性检验

**显著性检验**要问的是：观察到的差异是否大于随机误差可能造成的程度。我们设立**原假设**$H_0$——"方法没有偏差"、"两种方法一致"、"两种精密度相等"——由数据计算检验统计量，再问：若$H_0$为真，至少这么极端的值出现的概率有多大？该概率就是**p 值**。若它低于选定的**显著性水平**$\alpha$（通常$0.05$），我们就拒绝$H_0$；否则保留它，但这不等于证明它成立。

两类错误都可能发生。**第一类错误**拒绝了真实的原假设（我们"发现"了并不存在的偏差），其概率为$\alpha$。**第二类错误**保留了虚假的原假设（我们漏掉了真实的偏差），其概率$\beta$取决于真实效应有多大、结果有多少。检验的**功效**$1-\beta$随$n$增大：小但真实的偏差在三个平行测定下不可见，在三十个下则一目了然。

::: proposition t检验 {#prop-t-tests}
设结果独立且服从正态分布。

1. **均值与参考值$\mu_0$的比较**：
$$
t = \frac{\bar{x}-\mu_0}{s/\sqrt{n}}, \qquad \nu = n-1 .
$$ {#eq-t-one}
2. **两个均值$\bar{x}_1$、$\bar{x}_2$的比较**：两组分别有$n_1$和$n_2$个结果、标准偏差相近：
$$
t = \frac{\bar{x}_1-\bar{x}_2}{s_\mathrm{p}\sqrt{1/n_1 + 1/n_2}}, \qquad s_\mathrm{p}^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}, \qquad \nu = n_1+n_2-2 .
$$ {#eq-t-two}
3. **配对比较**：若两种方法用于同样的$n$个样品，求出差值$d_i$，用[[#eq-t-one]]把其均值与零检验：$t = \bar{d}/(s_d/\sqrt{n})$，$\nu = n-1$。

每种情形下，当$\lvert t\rvert > t_{1-\alpha/2,\,\nu}$时，在水平$\alpha$下拒绝$H_0$。
:::

::: proof
对(1)：$H_0$下$\bar{x}$服从均值为$\mu_0$、标准偏差为$\sigma/\sqrt{n}$的正态分布，所以$z = (\bar{x}-\mu_0)/(\sigma/\sqrt{n})$是标准正态变量。量$(n-1)s^2/\sigma^2$服从自由度为$n-1$的$\chi^2$分布，且与$\bar{x}$独立（正态样本的一条性质）。标准正态变量与$\sqrt{\chi^2_\nu/\nu}$之比按定义就是自由度为$\nu$的学生t，而
$$
\frac{z}{\sqrt{s^2/\sigma^2}} = \frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}\cdot\frac{\sigma}{s} = \frac{\bar{x}-\mu_0}{s/\sqrt{n}},
$$
其中$\sigma$相消。对(2)：$H_0$（均值相等）下，若两组共用同一个$\sigma$，则$\bar{x}_1-\bar{x}_2$服从均值为零、方差为$\sigma^2(1/n_1+1/n_2)$的正态分布。对该共同$\sigma^2$的最佳估计按自由度为各方差加权，即$s_\mathrm{p}^2$；$(n_1+n_2-2)s_\mathrm{p}^2/\sigma^2$是自由度为$n_1+n_2-2$的$\chi^2$，同样的相消给出[[#eq-t-two]]。对(3)，差值消去了两法共有的样品间分析物含量的差异，$d_i$是一组$n$个结果，其均值按(1)与零检验。
:::

::: example 方法有系统偏差吗？ {#ex-crm-bias}
在$95\ \%$水平下检验引言中的五个铅结果（$24.1$、$24.6$、$23.8$、$24.4$、$24.9\ \mu\mathrm{g\,g^{-1}}$）是否与认证值$25.0\ \mu\mathrm{g\,g^{-1}}$有显著差异。忽略认证值的不确定度。
::: solution
均值为$\bar{x} = 121.8/5 = 24.36\ \mu\mathrm{g\,g^{-1}}$。各值对其偏差为$-0.26, 0.24, -0.56, 0.04, 0.54$，其平方和为$0.732$，所以
$$
s = \sqrt{\frac{0.732}{4}} = 0.428\ \mu\mathrm{g\,g^{-1}} .
$$
由[[#eq-t-one]]，
$$
t = \frac{24.36 - 25.0}{0.428/\sqrt{5}} = \frac{-0.64}{0.191} = -3.35 .
$$
$\nu = 4$时$t_\mathrm{crit} = 2.78$。由于$\lvert t\rvert = 3.35 > 2.78$，差异在$95\ \%$水平下显著（$p = 0.029$）：方法读数约偏低$2.6\ \%$。同样的结论可由$95\ \%$置信区间得到：$24.36 \pm 2.78\times0.191 = 24.36 \pm 0.53$，即$23.83$到$24.89\ \mu\mathrm{g\,g^{-1}}$，其中不含$25.0$。$2.6\ \%$的偏差**要紧不要紧**是适用性的另一问题；统计只告诉我们它是真实的。实际工作中认证值带有自己的不确定度，比较前必须把它与$s/\sqrt{n}$合并——认证为$25.0 \pm 0.8$的标准物质根本无法揭示这一偏差。
:::
:::

在用[[#eq-t-two]]作两样本检验合并标准偏差之前，应先检查它们是否相容。工具是方差之比。

::: definition 两个方差的F检验 {#def-f-test}
要检验两组结果的精密度是否相同，计算
$$
F = \frac{s_1^2}{s_2^2}, \qquad s_1 \ge s_2,
$$
自由度为$\nu_1 = n_1-1$（分子）和$\nu_2 = n_2-1$（分母）。对水平$\alpha$的双侧检验，若$F$超过表列的$F_{1-\alpha/2;\,\nu_1,\nu_2}$，则精密度有显著差异。若确有差异，均值的比较改用韦尔奇（Welch）形式的t检验，它不作合并。
:::

::: example 测定矿石中铁的两种方法 {#ex-two-means}
对同一份均质化矿石中的铁（结果以铁的质量分数计）用重铬酸钾滴定（六个结果：$10.42, 10.37, 10.51, 10.45, 10.40, 10.47$）和电感耦合等离子体发射（五个结果：$10.31, 10.38, 10.25, 10.35, 10.29$）测定。两种方法在$95\ \%$水平下一致吗？
::: solution
滴定：$\bar{x}_1 = 10.437$，$s_1 = 0.0505$。ICP：$\bar{x}_2 = 10.316$，$s_2 = 0.0508$。

**精密度。**$F = (0.0508/0.0505)^2 = 1.01$，远低于$F_{0.975;\,4,5} = 7.39$：精密度相容，可以合并。

**合并标准偏差。**
$$
s_\mathrm{p} = \sqrt{\frac{5\times0.0505^2 + 4\times0.0508^2}{9}} = 0.0506 .
$$
**均值。**
$$
t = \frac{10.437 - 10.316}{0.0506\sqrt{1/6 + 1/5}} = \frac{0.121}{0.0306} = 3.94 .
$$
$\nu = 9$时$t_\mathrm{crit} = 2.26$。差异（$0.12$个百分点）显著（$p = 0.003$）：至少一法有偏差。检验说不出是哪一法；用两种方法都分析过的有证标准矿石则可以。
:::
:::

### 离群值

一组结果中有时有一个看起来不对。若已知原因——洒掉一滴、滴定管里有气泡、质量录入错误——就直接舍弃该结果并记录原因。若原因不明，可用**格拉布斯（Grubbs）检验**一类方法把可疑值与其余各值比较：$G = \lvert x_\mathrm{suspect} - \bar{x}\rvert/s$，其中$\bar{x}$和$s$由*包含可疑值在内*的全部结果算出，再与表列临界值比较（$n = 6$、$95\ \%$时$G_\mathrm{crit} = 1.887$）。更早的迪克森（Dixon）Q检验，$Q = \text{间距}/\text{极差}$，对小样本量起同样的作用。

::: warning 把结果剔除到数据好看为止 {#warn-outliers}
离群值检验很容易被滥用。对同一组数据反复使用，最终会把任何碍事的结果都剥掉；对小样本量，它剔除真实值的频率高得惊人，而且真实分布的尾部越厚（实际分析数据往往如此），它剔得越轻易。仅凭统计理由剔除一个值，只能剔一次，只能用事先选定的检验，并且总要报告（"一个结果$10.9$经格拉布斯检验在$95\ \%$水平下被剔除"）。一组数据含有可疑值时，往往更好的办法是报告中位数——单个离谱值拖不动它——或采用稳健统计，而不是删除数据。而反复出现的"离群值"不是离群值：它是关于方法的信息。
:::

## 校准与未知物浓度的不确定度

大多数仪器方法是**相对**的：信号与浓度的联系只通过标准溶液建立。我们测量$n$个浓度为$x_i$、信号为$y_i$的标准溶液，拟合最小二乘直线$y = a + bx$，再测量未知物、把它的信号$y_0$换算成浓度
$$
x_0 = \frac{y_0 - a}{b} .
$$ {#eq-x0}
斜率$b$是该方法的**灵敏度**；各点围绕直线的散布由
$$
s_{y/x} = \sqrt{\frac{\sum_i \left(y_i - a - bx_i\right)^2}{n-2}},
$$
即**残差的标准偏差**来度量，自由度为$n-2$，因为拟合了两个参数。$a$、$b$及其标准误差的最小二乘公式在[[laboratory-methods/data-graphs]]中推导。分析者真正需要的是$x_0$的不确定度。

::: proposition 由校准线求浓度的不确定度 {#prop-sx0}
对用不加权最小二乘拟合$n$个点得到的直线校准，信号散布恒定为$s_{y/x}$，由未知物$m$个平行信号的平均值$\bar{y}_0$求得的浓度$x_0$的标准偏差为
$$
s_{x_0} = \frac{s_{y/x}}{b}\sqrt{\frac{1}{m} + \frac{1}{n} + \frac{(\bar{y}_0 - \bar{y})^2}{b^2 \sum_i (x_i - \bar{x})^2}},
$$ {#eq-sx0}
其中$\bar{x}$与$\bar{y}$是校准数据的均值。置信区间为$x_0 \pm t\,s_{x_0}$，$t$取$n-2$个自由度。该式是近似式，在直线确定得足够好时成立（粗略地说，当$t\,s_b/b < 0.1$时）。
:::

::: proof
把拟合直线经由其形心写成$y = \bar{y} + b(x - \bar{x})$，于是[[#eq-x0]]变为$x_0 = \bar{x} + (\bar{y}_0 - \bar{y})/b$。进入的独立随机量有三个：$\bar{y}_0$（方差$\sigma^2/m$，来自未知物的$m$个平行测定）、$\bar{y}$（方差$\sigma^2/n$）和$b$（方差$\sigma^2/S_{xx}$，其中$S_{xx} = \sum (x_i-\bar{x})^2$）。$\bar{y}$与$b$不相关，正是把直线写成过形心形式的原因：$b = \sum (x_i-\bar{x})y_i/S_{xx}$，而它与$\bar{y} = \frac{1}{n}\sum y_i$的协方差正比于$\sum (x_i-\bar{x}) = 0$。一阶不确定度传播给出
$$
\begin{aligned}
\sigma^2_{x_0} &= \left(\frac{\partial x_0}{\partial \bar{y}_0}\right)^2\frac{\sigma^2}{m} + \left(\frac{\partial x_0}{\partial \bar{y}}\right)^2\frac{\sigma^2}{n} + \left(\frac{\partial x_0}{\partial b}\right)^2\frac{\sigma^2}{S_{xx}} \\
&= \frac{1}{b^2}\frac{\sigma^2}{m} + \frac{1}{b^2}\frac{\sigma^2}{n} + \frac{(\bar{y}_0-\bar{y})^2}{b^4}\frac{\sigma^2}{S_{xx}},
\end{aligned}
$$
因为$\partial x_0/\partial b = -(\bar{y}_0-\bar{y})/b^2$。把$\sigma^2/b^2$提到括号外，并用其估计值$s_{y/x}$代替$\sigma$，即得[[#eq-sx0]]。对$b$的一阶展开正是要求斜率确定得好的原因。
:::

三个项各有一个可以据以行动的含义。$1/m$项是未知物自身信号的散布：多测几次。$1/n$项是直线高度（截距位置）的不确定度：多用几个标准溶液。最后一项是斜率的不确定度，被未知物到形心的距离放大：布置标准溶液，使未知物落在量程中段附近，并把它们铺开使$S_{xx}$尽量大。

::: example 土壤消解液中的铅 {#ex-calibration}
铅标准溶液给出下列原子吸光度读数：

| $x$ / $\mathrm{mg\,dm^{-3}}$ | $0$ | $2.00$ | $4.00$ | $6.00$ | $8.00$ | $10.00$ |
|---|---|---|---|---|---|---|
| $y$（吸光度） | $0.009$ | $0.158$ | $0.301$ | $0.472$ | $0.609$ | $0.766$ |

一份土壤消解液测量三次，给出$0.405$、$0.412$和$0.398$。求消解液中铅的浓度及其$95\ \%$置信区间。
::: solution
**直线。**$\bar{x} = 5.00$，$\bar{y} = 0.38583$，$S_{xx} = \sum(x_i-\bar{x})^2 = 70.0$。最小二乘斜率与截距为
$$
b = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{S_{xx}} = 0.075843\ \mathrm{dm^3\,mg^{-1}}, \qquad a = \bar{y} - b\bar{x} = 0.00662 .
$$
由残差得$s_{y/x} = 0.00730$（$\nu = 4$）。

**未知物。**$\bar{y}_0 = 0.4050$，所以
$$
x_0 = \frac{0.4050 - 0.00662}{0.075843} = 5.253\ \mathrm{mg\,dm^{-3}} .
$$
**其不确定度。**由[[#eq-sx0]]，取$m = 3$、$n = 6$：
$$
s_{x_0} = \frac{0.00730}{0.07584}\sqrt{\frac{1}{3} + \frac{1}{6} + \frac{(0.4050-0.3858)^2}{0.07584^2\times70.0}} = 0.0962\times\sqrt{0.5000 + 0.0009} = 0.0681\ \mathrm{mg\,dm^{-3}} .
$$
$t_{0.975,4} = 2.78$，结果为$x_0 = 5.25 \pm 0.19\ \mathrm{mg\,dm^{-3}}$（$95\ \%$）。注意斜率项的贡献几乎为零，因为未知物靠近形心；不确定度几乎全部来自$1/m$和$1/n$两项。那么消解液"真的"可能是$5.0$吗？$5.0$恰在区间（$5.06$到$5.44$）之外，所以$5.0$的可能性不大，但也不悬殊。
:::

关于校准线还有两点。第一，**相关系数**$r$（或$R^2$）是线性的糟糕检验：上面六个点给出$r = 0.99974$，而一组有明显弯曲的点可以给出$r = 0.995$。应当检查残差——弯曲或漏斗形的残差图才是"直线加不加权都不对"的证据。第二，若散布随浓度增大（宽量程上常常如此），各点便应享有不等的权重$w_i \propto 1/s_i^2$，作**加权**最小二乘拟合；不加权拟合在低浓度处给出的区间过宽、在高浓度处过窄。

## 标准加入法

在纯水中配制的校准线假定分析物在样品中给出与在标准溶液中相同的单位浓度信号。情况常常并非如此。火焰原子吸收中，黏的消解液比水抽吸得慢；电喷雾质谱中，共洗脱的化合物抑制电离；极谱法中，表面活性剂改变电极响应。这类**基体效应**改变斜率。当标准溶液无法匹配基体时，就在样品自身里面校准。

::: proposition 标准加入法 {#prop-standard-addition}
把等体积$V_x$的样品分置于体积为$V_\mathrm{t}$的若干容量瓶中；分别加入递增体积$V_{\mathrm{s},i}$、浓度为$c_\mathrm{s}$的标准溶液，都稀释至刻度。若信号正比于瓶中分析物的浓度、且每个瓶中的比例常数相同，则信号对加入浓度$x_i = c_\mathrm{s}V_{\mathrm{s},i}/V_\mathrm{t}$呈线性：
$$
y_i = k\left(\frac{c_xV_x}{V_\mathrm{t}} + x_i\right),
$$
最小二乘直线$y = a + bx$与$x$轴交于$x = -a/b$，于是
$$
\frac{c_xV_x}{V_\mathrm{t}} = \frac{a}{b}, \qquad c_x = \frac{a}{b}\cdot\frac{V_\mathrm{t}}{V_x} .
$$ {#eq-standard-addition}
外推值$x_\mathrm{E} = a/b$的标准偏差为
$$
s_{x_\mathrm{E}} = \frac{s_{y/x}}{b}\sqrt{\frac{1}{n} + \frac{\bar{y}^2}{b^2\sum_i(x_i-\bar{x})^2}} .
$$ {#eq-sxe}
该方法要求响应线性且过原点（空白无信号，或先扣除空白），并且只校正**按比例**的基体效应。
:::

::: proof
第$i$瓶中分析物的浓度是样品的贡献$c_xV_x/V_\mathrm{t}$（因$V_x$和$V_\mathrm{t}$相同，各瓶相同）加上加入的$x_i$。乘以$k$即得线性形式，截距$a = kc_xV_x/V_\mathrm{t}$、斜率$b = k$；二者之比消去了未知的$k$，这就是改变$k$的基体效应得以抵消的原因。至于不确定度：外推点相当于在信号$y_0 = 0$处从直线读出的浓度，没有对未知物信号作平行测量（没有$1/m$项——"未知信号"零是精确的）。在[[#eq-sx0]]中代入$\bar{y}_0 = 0$、删去$1/m$项即得[[#eq-sxe]]。若响应含有加和性的空白信号，它会加到$a$上而被算作分析物：标准加入法无法校正加和性干扰。
:::

::: example 标准加入法测铜 {#ex-standard-addition}
取五个$25.00\ \mathrm{cm^3}$葡萄酒分样，移入$50.00\ \mathrm{cm^3}$容量瓶；分别加入$0$、$1.00$、$2.00$、$3.00$和$4.00\ \mathrm{cm^3}$的$50.0\ \mathrm{mg\,dm^{-3}}$铜标准溶液，稀释至刻度。吸光度：$0.214$、$0.318$、$0.427$、$0.530$、$0.638$。求葡萄酒中铜的浓度及其$95\ \%$置信区间。
::: solution
加入浓度为$x_i = 50.0 \times V_{\mathrm{s},i}/50.00 = 0, 1.00, 2.00, 3.00, 4.00\ \mathrm{mg\,dm^{-3}}$。最小二乘直线为$y = 0.2134 + 0.1060\,x$，$s_{y/x} = 0.00155$（$\nu = 3$），$\bar{y} = 0.4254$，$S_{xx} = 10.0$。于是
$$
x_\mathrm{E} = \frac{0.2134}{0.1060} = 2.013\ \mathrm{mg\,dm^{-3}}, \qquad s_{x_\mathrm{E}} = \frac{0.00155}{0.1060}\sqrt{\frac{1}{5} + \frac{0.4254^2}{0.1060^2\times10.0}} = 0.0197\ \mathrm{mg\,dm^{-3}} .
$$
这是容量瓶中的浓度；葡萄酒被稀释了$V_\mathrm{t}/V_x = 2$倍，所以$c_x = 4.03\ \mathrm{mg\,dm^{-3}}$。$t_{0.975,3} = 3.18$，区间为$\pm 2\times3.18\times0.0197 = \pm 0.13$：$c_x = 4.03 \pm 0.13\ \mathrm{mg\,dm^{-3}}$。相对不确定度（$3\ \%$）比读数$0.4\ \%$的散布所暗示的大，因为结果是向外测点之外的外推；加入量应足够大，使原信号大约增至两倍或三倍。
:::
:::

## 内标

有些误差不是按比例的基体效应，而是逐次进样之间的波动：气相色谱的自动进样器这次给$1.0\ \mu\mathrm{l}$、下次给$0.96\ \mu\mathrm{l}$；等离子体的效率随雾化器堵塞而漂移；萃取中损失了部分分析物。若向每个样品和标准中加入已知量的、不同的但相似的物质，它就经受同样的波动，而信号之**比**对波动免疫。

::: definition 内标与响应因子 {#def-internal-standard}
**内标**S是样品中不存在的物质，以已知浓度加入每个标准溶液和样品，其信号对实验变量的响应与分析物X相同。**响应因子**$F$由下式定义：
$$
\frac{A_\mathrm{X}}{[\mathrm{X}]} = F\,\frac{A_\mathrm{S}}{[\mathrm{S}]},
$$
其中$A$为信号（峰面积、发射强度）。$F$用已知组成的混合物测出，然后用于求加入了已知$[\mathrm{S}]$的样品中的$[\mathrm{X}]$：$[\mathrm{X}] = (A_\mathrm{X}/A_\mathrm{S})\,[\mathrm{S}]/F$。
:::

::: example 气相色谱中的内标 {#ex-internal-standard}
一混合物含$10.0\ \mathrm{mg\,dm^{-3}}$分析物和$8.0\ \mathrm{mg\,dm^{-3}}$内标，给出峰面积比$A_\mathrm{X}/A_\mathrm{S} = 1.32$。某样品加入内标至$8.0\ \mathrm{mg\,dm^{-3}}$后给出$A_\mathrm{X}/A_\mathrm{S} = 0.875$。求加标样品中的$[\mathrm{X}]$。
::: solution
由标准混合物，
$$
F = \frac{A_\mathrm{X}/[\mathrm{X}]}{A_\mathrm{S}/[\mathrm{S}]} = \frac{A_\mathrm{X}}{A_\mathrm{S}}\cdot\frac{[\mathrm{S}]}{[\mathrm{X}]} = 1.32\times\frac{8.0}{10.0} = 1.056 .
$$
在样品中，
$$
[\mathrm{X}] = \frac{A_\mathrm{X}}{A_\mathrm{S}}\cdot\frac{[\mathrm{S}]}{F} = 0.875\times\frac{8.0}{1.056} = 6.63\ \mathrm{mg\,dm^{-3}} .
$$
若进样体积小$4\ \%$，两个峰面积都会缩小$4\ \%$，比值——从而结果——不变。实际工作中，$F$由工作范围内$A_\mathrm{X}/A_\mathrm{S}$对$[\mathrm{X}]/[\mathrm{S}]$的校准线确定，而不是靠单一混合物。
:::
:::

最好的内标是与分析物化学上几乎完全相同、但检测器能加以区分的物质。最理想的情形是分析物自身的同位素标记版本，用质谱测量：它在萃取、色谱和电离中都与分析物行为完全相同；这就是同位素稀释，在[[analytical-chemistry/hyphenated-methods]]中展开。

::: quiz
某实验室用火焰发射法测定血清中的钠。血清比水标准溶液黏，到达火焰的速度更慢，其单位浓度的钠信号更低。哪种做法能校正这一点？
- [ ] 使用更多水标准溶液，使$S_{xx}$更大。
- [x] 标准加入法或基体匹配的标准溶液，因为误差是基体造成的斜率改变。
- [ ] 扣除用去离子水测量的空白。
- [ ] 以更宽的置信区间报告结果。
::: solution
黏度改变了样品相对于标准溶液的灵敏度$b$——按比例的基体效应。增加标准溶液只会让**错误**的斜率变得更精密；空白扣除校正的是加和性误差，不是按比例误差；更宽的区间不去除偏差。在基体中校准（标准加入法，或在类血清基体中配制标准溶液）给出正确的斜率。火焰光度法中使用锂内标正是出于这一原因，因为黏度对锂和钠的影响相同。
:::
:::

## 检出限与定量限

每个空白都给出波动的信号。若分析物信号足够小，就无法与这些波动区分开，而有两个不同的问题要问：给定一个测得的信号，我们该不该**判定**分析物存在？必须有多少分析物存在，我们才能**可靠地**检出它？劳埃德·柯里（Currie）1968年的分析表明这两个问题需要两个不同的限值。

::: proposition 临界水平与检出限 {#prop-detection}
设净信号（信号减空白均值）服从标准偏差$\sigma_0$的正态分布，且$\sigma_0$在零浓度附近不依赖于浓度。给定假阳性概率$\alpha$与假阴性概率$\beta$：

1. **临界水平**——净信号高于它即判为"检出"——为$L_\mathrm{C} = z_{1-\alpha}\,\sigma_0$；
2. **检出限**——能以概率$1-\beta$超过$L_\mathrm{C}$的最小真实净信号——为
$$
L_\mathrm{D} = L_\mathrm{C} + z_{1-\beta}\,\sigma_0 = (z_{1-\alpha} + z_{1-\beta})\,\sigma_0 .
$$ {#eq-ld}

$\alpha = \beta = 0.05$时，$z = 1.645$，$L_\mathrm{D} = 3.29\,\sigma_0$。除以灵敏度$b$，它们就化为浓度。广泛采用的约定**检出限**$\mathrm{LOD} = 3s_0/b$与**定量限**$\mathrm{LOQ} = 10s_0/b$（此处相对标准偏差约为$10\ \%$）是同一思想的取整版本。
:::

::: proof
不含分析物时，净信号为$\mathcal{N}(0, \sigma_0^2)$。阈值$L_\mathrm{C}$被偶然超过的概率为$\alpha$，当$L_\mathrm{C}/\sigma_0 = z_{1-\alpha}$，即单侧正态分位数；这就是判定限。再设真实净信号为$L$。测量值为$\mathcal{N}(L, \sigma_0^2)$，它落在$L_\mathrm{C}$**以下**——假阴性——的概率为$\Phi\big((L_\mathrm{C}-L)/\sigma_0\big)$。令其等于$\beta$得$(L - L_\mathrm{C})/\sigma_0 = z_{1-\beta}$，即$L_\mathrm{D} = L_\mathrm{C} + z_{1-\beta}\sigma_0$。取$\alpha = \beta = 0.05$，$L_\mathrm{D} = 2\times1.645\,\sigma_0 = 3.29\,\sigma_0$。（若$\sigma_0$由少数几个空白估计，$z$换成$t$，限值更大。）
:::

图使这种不对称一目了然。真实含量恰为临界水平的样品只有一半时间给出"检出"的判定；检出限定得更高，使处于该水平的样品$95\ \%$的情况下能被检出。

::: example 铅的检出限 {#ex-lod}
[[#ex-calibration]]的铅方法十个平行空白给出标准偏差$0.0021$吸光度单位。以$\mathrm{mg\,dm^{-3}}$求LOD和LOQ。
::: solution
$b = 0.07584\ \mathrm{dm^3\,mg^{-1}}$，
$$
\mathrm{LOD} = \frac{3\times0.0021}{0.07584} = 0.083\ \mathrm{mg\,dm^{-3}}, \qquad \mathrm{LOQ} = \frac{10\times0.0021}{0.07584} = 0.28\ \mathrm{mg\,dm^{-3}} .
$$
因此读数为$0.15\ \mathrm{mg\,dm^{-3}}$的消解液属于检出但未定量：应报告为"检出，低于定量限（$0.28\ \mathrm{mg\,dm^{-3}}$）"。两点告诫：LOD指的是所测溶液，必须按稀释倍数和样品质量换算，才得到原始土壤中的方法检出限；而且它应当来自走完**整个**流程的空白（包括消解），因为制备过程中的沾污通常主导$s_0$。
:::
:::

## 方法验证与质量控制

方法用于真实样品之前要经过**验证**：用实验证明它适用于预期用途。性能特性（例如Eurachem指南和药物领域ICH Q2中的表述）为：

- **选择性**：响应来自分析物而非来自可能的干扰（通过添加干扰物检验，或通过与独立方法比较）。
- **正确度**：均值与真值的接近程度，用有证标准物质（[[#ex-crm-bias]]）或加标回收率评估。
- **精密度**：**重复性**（同一分析者、同一仪器、同一天）与**中间精密度**或**再现性**（不同日期、分析者或实验室）。再现性标准偏差通常为重复性的一倍半到两倍。
- **线性与工作范围**：在预定范围内作残差图。
- **检出限与定量限**（[[#prop-detection]]）。
- **耐用性**：对条件的微小有意变动不敏感（pH $\pm 0.2$、温度$\pm 2\ \mathrm{K}$、另一批号的色谱柱）。
- **测量不确定度**：综合上述各项的不确定度预算。

验证证明方法**能够**工作。**质量控制**证明它今天**确实**工作了。标准工具是**休哈特（Shewhart）控制图**：每个批次都分析一份稳定的控制物质，把结果对时间作图，中心线取长期均值$\mu$，**警告限**在$\mu \pm 2\sigma$，**行动限**在$\mu \pm 3\sigma$。对处于统计控制中的过程，大约每二十个点有一个落在警告限外，约每千个点有三个落在行动限外。一个点超出行动限、连续两个点在同一侧超出警告限、或中心线一侧出现一长串点（常用七到九个点，取决于所用的判定规则）都表明情况发生了变化，该批结果在查明原因之前不应放行。

::: algorithm 分析批次的运行步骤 {#alg-batch}
1. 按接受标准核查仪器（波长、灵敏度、基线）。
2. 测量校准空白和标准溶液；检查残差，并确认灵敏度在其通常范围内。
3. 测量一个走完整个流程的试剂空白、一份控制物质，以及一个加标样品或有证标准物质。
4. 测量样品，每隔十到二十个用一个核查标准穿插，以监测漂移。
5. 把控制结果画在它的控制图上；只有控制、空白、回收率和核查标准全部在其限值之内才放行该批。
6. 每个结果连同其不确定度一起报告，低于LOQ的值按"低于定量限"报告。
:::

这些工具在后续每一章都会用到。校准线与检出限随光谱方法在[[analytical-chemistry/molecular-spectrometry]]和[[analytical-chemistry/atomic-spectrometry]]中重现，在那里基体效应使标准加入法和内标成为常规。内标在[[analytical-chemistry/chromatography]]中必不可少，并在同位素稀释中达到其最佳形态（[[analytical-chemistry/hyphenated-methods]]）。把一种方法与参考值比较，正是[[analytical-chemistry/classical-analysis]]中经典绝对方法用来认证标准物质的方式。更深入的统计学——方差分析、回归诊断、贝叶斯方法——见数学图谱（[/learn/maths/](/learn/maths/)）。

::: history
威廉·西利·戈塞特（Gosset）是都柏林吉尼斯（Guinness）啤酒厂的化学师，以笔名发表了如今以该笔名命名的分布，载于《平均数的可能误差》（*The probable error of a mean*，*Biometrika*，1908）。罗纳德·费希尔（Fisher）在《研究工作的统计方法》（*Statistical Methods for Research Workers*，1925）中把显著性检验、方差分析和$F$分布（斯内德科（Snedecor）为向他致敬而命名）置于实验科学的中心。沃尔特·休哈特（Shewhart）1924年在贝尔电话实验室引入控制图，并在《制造产品质量的经济控制》（*Economic Control of Quality of Manufactured Product*，1931）中加以论述。就分析化学而言，迪安（Dean）与迪克森（Dixon）1951年在*Analytical Chemistry*上发表了针对小样本的Q检验，格拉布斯（Grubbs）1950年在*Annals of Mathematical Statistics*上提出了他的离群值判据，柯里（Currie）在《定性检出与定量测定的限值》（*Limits for qualitative detection and quantitative determination*，*Analytical Chemistry*，1968）中定义了临界水平、检出限与测定限。
:::

::: summary
- 均值的$1-\alpha$置信区间为$\bar{x} \pm ts/\sqrt{n}$，$\nu = n-1$；学生t为$s$的不确定度而把区间加宽。
- 显著性检验把统计量与它在原假设下的分布比较：均值与参考值的$t$检验、两个均值（合并）或配对结果的$t$检验；两个方差的$F$检验。
- 离群值只有已知原因时才舍弃，否则只按事先选定的检验舍弃一次——并且剔除总要报告。
- 由校准线求得的浓度的$s_{x_0} = (s_{y/x}/b)\sqrt{1/m + 1/n + (\bar{y}_0-\bar{y})^2/(b^2S_{xx})}$；在形心处最小；$r$不是线性的检验。
- 标准加入法在样品内部校准，校正按比例的基体效应；结果是外推，故不确定度更大。
- 内标通过信号之比校正对分析物与标准同等起作用的各种波动。
- 临界水平$1.645\sigma_0$与检出限$3.29\sigma_0$（$\alpha = \beta = 0.05$）回答的是不同的问题；LOD $= 3s_0/b$与LOQ $= 10s_0/b$是工作中采用的约定。
- 验证确立正确度、精密度、范围、限值与耐用性；带$\pm2\sigma$警告限和$\pm3\sigma$行动限的控制图表明方法保持受控。
:::

::: exercise 由空白求检出限 {level=1 check="0.042"}
某荧光方法的灵敏度为每$\mathrm{nmol\,dm^{-3}}$ $250$计数，七个空白读数的标准偏差为$3.5$计数。按$3s_0/b$约定，检出限是多少？（LOD以$\mathrm{nmol\,dm^{-3}}$输入。）
::: solution
$\mathrm{LOD} = 3\times3.5/250 = 0.042\ \mathrm{nmol\,dm^{-3}}$。LOQ为$10\times3.5/250 = 0.14\ \mathrm{nmol\,dm^{-3}}$。只有七个空白时，$s_0$本身约有$30\ \%$的不确定度，这是检出限只报一到两位有效数字的原因之一。
:::

::: exercise 使用响应因子 {level=1 check="3.1"}
某色谱方法中，$5.00\ \mathrm{mg\,dm^{-3}}$分析物与$4.00\ \mathrm{mg\,dm^{-3}}$内标给出面积比$A_\mathrm{X}/A_\mathrm{S} = 0.940$。某样品加入内标至$4.00\ \mathrm{mg\,dm^{-3}}$后给出$A_\mathrm{X}/A_\mathrm{S} = 0.583$。求加标样品中的$[\mathrm{X}]$。（$[\mathrm{X}]$以$\mathrm{mg\,dm^{-3}}$输入。）
::: solution
$F = 0.940\times4.00/5.00 = 0.752$。于是$[\mathrm{X}] = 0.583\times4.00/0.752 = 3.10\ \mathrm{mg\,dm^{-3}}$。更快的路线：在相同$[\mathrm{S}]$下比值缩小为$0.583/0.940 = 0.620$，所以$[\mathrm{X}] = 0.620\times5.00 = 3.10\ \mathrm{mg\,dm^{-3}}$。
:::

::: exercise 配对比较 {level=2 check="4"}
六个水样用离子色谱法和分光光度法测定硝酸盐（以$\mathrm{mg\,dm^{-3}}$计）：

| 样品 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| IC | $12.4$ | $8.6$ | $15.1$ | $10.2$ | $6.9$ | $13.5$ |
| 分光光度法 | $12.1$ | $8.5$ | $14.6$ | $10.1$ | $6.5$ | $13.3$ |

用配对$t$检验判断两法在$95\ \%$水平下是否有差异。为什么此处作非配对的两样本检验是错的？（输入$t$的值。）
::: solution
差值为$0.3, 0.1, 0.5, 0.1, 0.4, 0.2$，$\bar{d} = 0.267$，$s_d = 0.163$。于是$t = 0.267/(0.163/\sqrt{6}) = 4.00$。$\nu = 5$时$t_\mathrm{crit} = 2.57$：两法有显著差异，IC结果约高$0.27\ \mathrm{mg\,dm^{-3}}$。非配对检验会把样品间硝酸盐含量（$7$到$15\ \mathrm{mg\,dm^{-3}}$）的大幅变动放进标准偏差，把小小的系统差异淹没；配对之所以能消去它，是因为每个样品都是它自己的对照。
:::

::: exercise 一个可疑结果 {level=2 check="1.90"}
六次测定某样品，结果为$10.2$、$10.4$、$10.3$、$10.1$、$10.9$和$10.3$。对值$10.9$计算格拉布斯统计量$G$，并在$95\ \%$水平下作出判定（$n = 6$时$G_\mathrm{crit} = 1.887$）。对这个结果加以评论。（输入$G$。）
::: solution
用全部六个值，$\bar{x} = 10.367$，$s = 0.2805$，所以$G = (10.9 - 10.367)/0.2805 = 1.90$。这刚刚超过$1.887$，所以该值在$95\ \%$水平下被剔除——但只是刚刚超过；在$99\ \%$水平下（$G_\mathrm{crit} = 1.973$）它将保留。这样勉强的判定值得查一下记录（那次测定有什么异常吗？），并尽可能再做一次测量；报告中应写明该值被剔除、用的是哪个检验。中位数$10.3$几乎不受该判定的影响。
:::

::: exercise 单点标准加入 {level=2 check="1.38"}
$10.00\ \mathrm{cm^3}$样品给出信号$0.240$。向同一溶液中再加入$0.100\ \mathrm{cm^3}$的$100.0\ \mathrm{mg\,dm^{-3}}$标准溶液后，信号为$0.410$。计入体积的变化，求样品中分析物的浓度。（以$\mathrm{mg\,dm^{-3}}$输入。）
::: hint
写$S_1 = kc_x$与$S_2 = k\,(c_xV_x + c_\mathrm{s}V_\mathrm{s})/(V_x + V_\mathrm{s})$，消去$k$。
:::
::: solution
两式相除，
$$
\frac{S_2}{S_1} = \frac{c_xV_x + c_\mathrm{s}V_\mathrm{s}}{c_x(V_x+V_\mathrm{s})} \quad\Rightarrow\quad c_x = \frac{S_1c_\mathrm{s}V_\mathrm{s}}{S_2(V_x+V_\mathrm{s}) - S_1V_x} = \frac{0.240\times100.0\times0.100}{0.410\times10.10 - 0.240\times10.00} = \frac{2.40}{1.741} = 1.38\ \mathrm{mg\,dm^{-3}} .
$$
忽略$1\ \%$的稀释将给出$1.41$。单次加入很快，但既不能检验线性，也无法从拟合得到不确定度估计；还是以多次加入为佳。
:::

::: exercise 未知物要测几次？ {level=3 check="6"}
对[[#ex-calibration]]的校准，均值信号为$0.405$的未知物，至少平行读数$m$次才能把$95\ \%$置信半宽压到$0.16\ \mathrm{mg\,dm^{-3}}$以下？不论$m$多大，这套校准能达到的最小半宽是多少？（输入$m$。）
::: hint
用$t = 2.78$（自由度属于校准线）按[[#eq-sx0]]对$m = 4, 5, 6, \dots$计算$t\,s_{x_0}$。
:::
::: solution
$s_{y/x}/b = 0.09624$，根号内的括号为$1/m + 1/6 + 0.0009$。$m = 5$：$2.776\times0.09624\times\sqrt{0.2000 + 0.1676} = 0.162$；$m = 6$：$2.776\times0.09624\times\sqrt{0.1667+0.1676} = 0.154$。所以$m = 6$。当$m\to\infty$，半宽趋于$2.776\times0.09624\times\sqrt{0.1676} = 0.109\ \mathrm{mg\,dm^{-3}}$，由校准本身决定；要更低就需要更多的标准溶液（更大的$n$）或噪声更小的测量（更小的$s_{y/x}$）。
:::

::: exercise 标准加入结果的不确定度 {level=3 check="0.64"}
证明[[#eq-sxe]]可由[[#eq-sx0]]导出。然后把它用于这组数据：加入分析物（以测量溶液中的浓度计）$0$、$5.0$、$10.0$、$15.0\ \mu\mathrm{g\,dm^{-3}}$，信号为$0.112$、$0.205$、$0.301$、$0.390$。求$x_\mathrm{E}$及其$95\ \%$置信半宽。（半宽以$\mu\mathrm{g\,dm^{-3}}$输入。）
::: hint
令$\bar{y}_0 = 0$并去掉$1/m$项。拟合有$n - 2 = 2$个自由度；$t_{0.975,2} = 4.30$。
:::
::: solution
外推点相当于在信号$y = 0$处读线，这不是测量、没有方差，所以$1/m$项消失；到形心的距离化为$(0 - \bar{y})^2 = \bar{y}^2$；这就是[[#eq-sxe]]。对这组数据：$b = 0.01860$、$a = 0.1125$、$s_{y/x} = 0.00212$、$\bar{y} = 0.252$、$S_{xx} = 125$。于是$x_\mathrm{E} = 0.1125/0.01860 = 6.05\ \mu\mathrm{g\,dm^{-3}}$，且
$$
s_{x_\mathrm{E}} = \frac{0.00212}{0.01860}\sqrt{\frac{1}{4} + \frac{0.252^2}{0.01860^2\times125}} = 0.1140\times\sqrt{0.250 + 1.468} = 0.150\ \mu\mathrm{g\,dm^{-3}} .
$$
半宽为$4.30\times0.150 = 0.64\ \mu\mathrm{g\,dm^{-3}}$，所以$x_\mathrm{E} = 6.0 \pm 0.6\ \mu\mathrm{g\,dm^{-3}}$——散布不到$1\ \%$的读数却带来$10\ \%$的不确定度，全因外推和自由度太少。
:::

::: exercise 更严格的检出限 {level=3 check="3.97"}
监管方希望假阳性比假阴性更罕见：$\alpha = 0.01$、$\beta = 0.05$。用[[#prop-detection]]求以$\sigma_0$为单位的临界水平和检出限。用文字解释为什么降低$\alpha$会抬高$L_\mathrm{D}$，即使$\beta$不变。（输入$L_\mathrm{D}/\sigma_0$。）
::: solution
$z_{0.99} = 2.326$、$z_{0.95} = 1.645$，所以$L_\mathrm{C} = 2.33\,\sigma_0$，$L_\mathrm{D} = (2.326 + 1.645)\sigma_0 = 3.97\,\sigma_0$。降低$\alpha$使判定阈值$L_\mathrm{C}$上移，深入空白分布的尾部。真实信号必须更大，才有$95\ \%$的分布落在新阈值之上，所以检出限随临界水平抬高同样的量。在$\sigma_0$固定时，两种错误率此消彼长；只有更小的$\sigma_0$（更多空白、更安静的仪器、更干净的试剂）才能把两个限值同时降低。
:::
