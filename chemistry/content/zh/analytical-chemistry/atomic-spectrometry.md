饮用水法规为大约二十种元素列出了限值——砷、镉、铬、铜、铅、汞、镍、硒、铀等等——浓度从每升几毫克到低至每升微克的几分之一。一个水实验室每天要测定数百个水样中的全部这些元素，每个结果都可溯源并注明不确定度。任何滴定或显色反应都做不到这一点。承担这项工作的是**原子光谱法**：样品在高温下被分解为自由原子（或原子离子），原子按每种元素独有的波长吸收或发射的光被检测，或者按其质量被检测。由于原子谱线窄而有特征，这些方法选择性极高；而由于样品被破坏成原子，它们测定的是元素的总量，不论其化学形态如何。

本章涵盖主要技术：**原子吸收光谱法**（AAS）及其火焰与石墨炉原子化器、**电感耦合等离子体发射光谱法**（ICP-OES）与**电感耦合等离子体质谱法**（ICP-MS）。我们将推导激发态的玻尔兹曼粒子数分布——它解释了为什么吸收与发射对温度的响应如此不同；原子谱线的多普勒宽度——它解释了为什么原子吸收需要线光源；以及一种经典干扰背后的电离平衡。原子光谱的一般理论（光谱项符号、选择定则）见[[quantum-chemistry/many-electron-atoms]]；校准方法——尤其是标准加入法与内标法——见[[analytical-chemistry/statistics-calibration]]，吸光度的算术则是[[analytical-chemistry/molecular-spectrometry]]中的那套。

## 原子、谱线与温度

自由原子具有分立的电子能级，因此在尖锐的波长处吸收和发射。钠的D线位于$589.0$和$589.6\ \mathrm{nm}$（$3s$基态与两个$3p$能级之间的跃迁）、铜的$324.8\ \mathrm{nm}$谱线、铅的$283.3\ \mathrm{nm}$谱线和锌的$213.9\ \mathrm{nm}$谱线都是典型的分析线。在火焰或等离子体中，谱线的宽度为几皮米（$10^{-3}$–$10^{-2}\ \mathrm{nm}$）——比溶液中分子的吸收带宽一千倍——这就是元素之间光谱重叠是例外而非常态的原因。

从溶液走到自由原子是最困难的一步。**雾化器**把溶液变成细小气溶胶；在火焰或等离子体中，液滴失去溶剂（脱溶剂），干颗粒汽化，分子解离成原子（原子化），一部分原子发生电离。每一步都可能进行得不完全，而依赖于样品基体的不完全性正是大多数干扰的根源。

::: proposition 激发态的粒子数分布 {#prop-boltzmann}
在温度为$T$、处于局部热平衡的火焰或等离子体中，处于激发态$j$的原子数与处于基态$0$的原子数之比为
$$
\frac{N_j}{N_0} = \frac{g_j}{g_0}\exp\!\left(-\frac{\Delta E}{k_\mathrm{B}T}\right),
$$ {#eq-boltzmann}
其中$g$为统计权重（简并度，总角动量为$J$的能级为$2J + 1$），$\Delta E = hc/\lambda$是波长$\lambda$处跃迁的能量。
:::

::: proof
热平衡中，原子处于能量为$E$的某一量子态的概率正比于$e^{-E/k_\mathrm{B}T}$（玻尔兹曼分布，[[statistical-thermodynamics/boltzmann-distribution]]）。简并度为$g$的一个能级由$g$个能量相同的态组成，所以能级的粒子数正比于$g\,e^{-E/k_\mathrm{B}T}$。对能级$j$与$0$取比值，归一化的配分函数相消，剩下[[#eq-boltzmann]]。局部热平衡（碰撞快得足以使粒子数保持其玻尔兹曼值）对于常压火焰是很好的近似，对于氩等离子体的分析区也是合理的近似。
:::

::: example 有多少钠原子被激发？ {#ex-boltzmann}
对钠的$589.0\ \mathrm{nm}$谱线（$3s\ {}^2\mathrm{S}_{1/2}\rightarrow3p\ {}^2\mathrm{P}_{3/2}$，故$g_0 = 2$，$g_j = 4$），求$2500\ \mathrm{K}$（空气-乙炔火焰）与$6000\ \mathrm{K}$（等离子体的分析区）下的$N_j/N_0$。若火焰温度升高$10\ \mathrm{K}$，激发态粒子数变化百分之几？
::: solution
$\Delta E = hc/\lambda = (6.626\times10^{-34}\times2.998\times10^{8})/(589.0\times10^{-9}) = 3.373\times10^{-19}\ \mathrm{J}$（$2.105\ \mathrm{eV}$）。于是
$$
\begin{aligned}
T = 2500\ \mathrm{K}:&\quad \frac{N_j}{N_0} = 2\exp\!\left(-\frac{3.373\times10^{-19}}{1.381\times10^{-23}\times2500}\right) = 2e^{-9.77} = 1.14\times10^{-4},\\
T = 6000\ \mathrm{K}:&\quad \frac{N_j}{N_0} = 2e^{-4.07} = 0.034 .
\end{aligned}
$$
在火焰中，即使对这么低的能级，也大约每九千个原子才有一个被激发。对$\ln(N_j/N_0)$关于$T$求导，在$2500\ \mathrm{K}$下得$\Delta E/(k_\mathrm{B}T^2) = 3.9\times10^{-3}\ \mathrm{K^{-1}}$，所以升温$10\ \mathrm{K}$使激发态粒子数——以及发射强度——约增加$3.9\ \%$，而基态粒子数$N_0 \approx N$基本不变。
:::
:::

这个例子包含了整个领域的核心对比。**发射**强度正比于$N_j$，而$N_j$是一小部分原子，且随温度强烈变化；**吸收**则取决于$N_0$，它几乎是全部原子，并且几乎与温度无关。因此火焰发射只对易激发的元素（碱金属，其火焰光度法仍用于钠和钾的测定）好用，而且需要非常稳定的火焰。$6000$–$8000\ \mathrm{K}$的等离子体几乎能激发所有元素，这就是ICP**发射**取代火焰发射的原因；而在火焰中，**吸收**成了首选方法。

## 原子吸收光谱法

在AAS中，分析线波长的光穿过原子云，测其吸光度；与分子一样，$A = \log_{10}(P_0/P)$在工作范围内与基态原子的数密度成正比。

光源是这种方法的关键，原因在于原子谱线的宽度。带宽为$0.2\ \mathrm{nm}$的单色器所通过的光带比吸收线宽一百倍。如果采用连续光源，原子只会移去狭缝所通过的光中薄薄的一片，吸光度既小又非线性（[[analytical-chemistry/molecular-spectrometry]]中非单色光偏差的极端形式）。艾伦·沃尔什（Alan Walsh）1955年的解决办法，是用一盏能发射该元素自身谱线、且比吸收线更窄的灯作光源：**空心阴极灯**——其阴极由待测元素制成，低压放电产生的谱线比火焰中的还要窄。这样单色器只需把灯的一条谱线与它的邻近谱线分开。

::: proposition 原子谱线的多普勒宽度 {#prop-doppler}
质量为$m$、温度为$T$的气体原子按麦克斯韦速度分布运动，每个原子吸收或发射的波长因多普勒效应而发生偏移。所得谱线轮廓为高斯型，其半高全宽为
$$
\Delta\lambda_\mathrm{D} = \frac{\lambda}{c}\sqrt{\frac{8k_\mathrm{B}T\ln2}{m}} .
$$ {#eq-doppler}
:::

::: proof
沿视线方向的速度分量$v_x$服从麦克斯韦分布$f(v_x) \propto \exp(-mv_x^2/2k_\mathrm{B}T)$，这是方差为$\sigma_v^2 = k_\mathrm{B}T/m$的高斯分布。以$v_x \ll c$运动的原子与之发生作用的光，其波长偏移$\delta\lambda = \lambda v_x/c$，所以以$\delta\lambda$计的谱线轮廓是标准偏差为$\sigma_\lambda = (\lambda/c)\sqrt{k_\mathrm{B}T/m}$的高斯分布。高斯函数在$\exp(-\delta\lambda^2/2\sigma_\lambda^2) = \tfrac12$处降为半高，即$\delta\lambda = \sigma_\lambda\sqrt{2\ln2}$，故全宽为$2\sqrt{2\ln2}\,\sigma_\lambda$；把系数并入根号——$(2\sqrt{2\ln2})^2 = 8\ln2$——即得[[#eq-doppler]]。
:::

对$589\ \mathrm{nm}$、$2500\ \mathrm{K}$的钠，[[#eq-doppler]]给出$\Delta\lambda_\mathrm{D} = 4.4\ \mathrm{pm}$；对$283.3\ \mathrm{nm}$的铅则为$0.70\ \mathrm{pm}$，因为铅更重且谱线波长更短（[[#exr-doppler]]）。与火焰气体的碰撞叠加了量级相当的**压力变宽**（洛伦兹变宽），所以火焰吸收线有几皮米宽。空心阴极灯在几百帕、几百开尔文下工作，其谱线还要窄得多。

### 火焰与石墨炉

**火焰AAS**把溶液连续抽吸进入狭缝燃烧器，得到沿光程$5$–$10\ \mathrm{cm}$长的火焰。空气-乙炔火焰（约$2400$–$2600\ \mathrm{K}$）适合大多数元素；生成难挥发氧化物的元素（如铝、硅、钛、钒）则需要更热的氧化亚氮-乙炔火焰（约$2900$–$3100\ \mathrm{K}$）。火焰AAS速度快（每个元素几秒）、精密度好（$0.5$–$1\ \%$）、费用低，大多数元素的检出限约为$1$–$100\ \mu\mathrm{g\,dm^{-3}}$。它的弱点在于效率：抽吸的溶液大部分成为废液，而每个原子只在光程中停留几毫秒。

**石墨炉AAS**（电热AAS）把$10$–$50\ \mu\mathrm{l}$样品放入光程中的小石墨管，按程序电热升温：**干燥**（约$100$–$150\ ^\circ\mathrm{C}$）除去溶剂；**灰化**（热解，数百至上千摄氏度）破坏有机物，并在不损失分析物的前提下尽可能使基体挥发；**原子化**（约一秒内升至$2000$–$2700\ ^\circ\mathrm{C}$）释放出一团原子云，在管中停留约一秒；最后的**净化**步骤烧掉残留物。由于整个样品在微小体积中被原子化并保留其中，检出限比火焰低约百倍到千倍——许多元素可达$\mu\mathrm{g\,dm^{-3}}$以下。代价是测量较慢（每个元素几分钟）、精密度较差、干扰更严重；对这些干扰，可以用**基体改进剂**（硝酸钯与硝酸镁、磷酸铵）在灰化阶段稳定分析物，可以在均匀加热的管中采用平台原子化，并测量积分（峰面积）吸光度来加以驯服。

::: definition 特征浓度与特征质量 {#def-characteristic}
AAS方法的灵敏度用**特征浓度**$c_0$（火焰）来表示，即产生$0.0044$吸光度（也就是$1\ \%$吸收，因为$-\log_{10}0.99 = 0.0044$）的分析物浓度；对石墨炉则用**特征质量**$m_0$，即产生$0.0044\ \mathrm{s}$积分吸光度的分析物质量。在线性范围内，$c = c_0A/0.0044$，$m = m_0A_\mathrm{int}/0.0044\ \mathrm{s}$。特征值描述的是灵敏度，不是检出限——后者还取决于噪声（[[analytical-chemistry/statistics-calibration#prop-detection]]）。
:::

::: example 用石墨炉测铅 {#ex-gfaas}
某石墨炉仪器上铅的特征质量为$m_0 = 12\ \mathrm{pg}$。消解后的血液样品（进样前十倍稀释）进样$20\ \mu\mathrm{l}$，空白校正后的积分吸光度为$0.110\ \mathrm{s}$。求进样溶液以及血液中的铅浓度。
::: solution
石墨炉中铅的质量为
$$
m = m_0\frac{A_\mathrm{int}}{0.0044\ \mathrm{s}} = 12\ \mathrm{pg}\times\frac{0.110}{0.0044} = 300\ \mathrm{pg}.
$$
在$20\ \mu\mathrm{l}$中，即$300\ \mathrm{pg}/20\ \mu\mathrm{l} = 15\ \mathrm{pg\,\mu l^{-1}} = 15\ \mu\mathrm{g\,dm^{-3}}$。做过十倍稀释前的血液含$150\ \mu\mathrm{g\,dm^{-3}}$。实际工作中，结果应由校准得出（最好基体匹配，或采用标准加入法），特征质量只用来核查仪器性能是否符合指标——$m_0$漂移超过约$20\ \%$的石墨炉需要检修。
:::
:::

### 原子吸收中的干扰

干扰分为两组。

**光谱干扰**产生于分析物以外的东西在分析波长处吸收或散射。两条原子线的直接重叠很少见。更常见得多的是分子的**背景吸收**和原子云中颗粒的**散射**，在含盐或含有机物基体的石墨炉中尤其如此。因此**背景校正**是标准操作。氘灯的连续光谱几乎不被窄的原子线吸收、却被宽的背景完全吸收，据此可以测出背景并把它扣除。**塞曼（Zeeman）**校正对原子化器施加磁场，把原子线分裂，使原子在一种偏振下不再吸收灯线，而背景对两种偏振都吸收；它对结构化背景的校正更可靠。

**非光谱干扰**改变由给定浓度产生的自由原子数目。

- **化学干扰**：分析物生成不能完全原子化的化合物。磷酸根、硫酸根、铝酸根和硅酸根在空气-乙炔火焰中与钙生成难挥发盐，从而抑制钙。对策：**释放剂**（镧或锶，优先结合磷酸根）、**保护剂**（EDTA，把钙结合成挥发性形式），或更热的氧化亚氮-乙炔火焰。
- **电离干扰**：在高温火焰中，易电离元素的一部分原子损失为离子，而离子不在原子线的波长处吸收。由于电离度取决于自由电子的浓度，另一种易电离元素的存在会改变信号。对策是**消电离剂**（[[#ex-ionisation]]）。
- **物理（传输）干扰**：黏度、表面张力或溶解固体总量的差异改变雾化速率；用基体匹配、标准加入法或内标法校正。

电离平衡$\mathrm{M} \rightleftharpoons \mathrm{M^+} + \mathrm{e^-}$由**萨哈（Saha）方程**描述，它是由统计力学导出的气相电离平衡常数：
$$
\frac{n_{\mathrm{M^+}}n_\mathrm{e}}{n_\mathrm{M}} = 2\frac{g_{\mathrm{M^+}}}{g_\mathrm{M}}\left(\frac{2\pi m_\mathrm{e}k_\mathrm{B}T}{h^2}\right)^{3/2}\exp\!\left(-\frac{E_\mathrm{i}}{k_\mathrm{B}T}\right),
$$ {#eq-saha}
其中$n$为数密度，$E_\mathrm{i}$为电离能，$m_\mathrm{e}$为电子质量。等式右边只取决于元素和温度；电离分数$n_{\mathrm{M^+}}/(n_\mathrm{M} + n_{\mathrm{M^+}})$则取决于$n_\mathrm{e}$，而$n_\mathrm{e}$由*所有*现存的易电离元素共同决定。

::: example 抑制钠的电离 {#ex-ionisation}
在$2500\ \mathrm{K}$空气-乙炔火焰的模型计算中，钠的[[#eq-saha]]右边为$1.3\times10^{16}\ \mathrm{m^{-3}}$。求$n_\mathrm{e} = 1.0\times10^{16}\ \mathrm{m^{-3}}$时钠的电离分数；再求加入大量过量的钾盐把$n_\mathrm{e}$提高到$1.0\times10^{18}\ \mathrm{m^{-3}}$时的电离分数。为什么这能改善分析？
::: solution
记$S = 1.3\times10^{16}$，则$n_{\mathrm{Na^+}}/n_\mathrm{Na} = S/n_\mathrm{e}$，电离分数为$(S/n_\mathrm{e})/(1 + S/n_\mathrm{e}) = S/(S + n_\mathrm{e})$：
$$
n_\mathrm{e} = 1.0\times10^{16}:\ \frac{1.3}{1.3 + 1.0} = 0.57; \qquad n_\mathrm{e} = 1.0\times10^{18}:\ \frac{1.3\times10^{16}}{1.01\times10^{18}} = 0.013 .
$$
不加消电离剂时，一半以上的钠损失为离子，而且更糟的是，损失的分数取决于每个样品含有多少其他易电离元素，于是样品与标准的行为不同。在*标准溶液和样品溶液里都*加入过量钾后，钠的电离降到约$1\ \%$，而且更重要的是，它在每种溶液中变得相同。（这里的数字只是说明趋势；火焰中的实际电离度取决于火焰本体、观测高度以及偏离平衡的程度。）
:::
:::

## 电感耦合等离子体发射光谱法

**电感耦合等离子体**（ICP）是由水冷感应线圈经射频场（通常$27$或$40\ \mathrm{MHz}$、$1$–$1.5\ \mathrm{kW}$）在常压下于石英炬管内维持的氩气放电。被振荡场加速的电子使氩原子电离，等离子体达到$6000$–$10\,000\ \mathrm{K}$。样品气溶胶由中心氩气流载带，穿过环形等离子体中心的通道，在约$5000$–$7000\ \mathrm{K}$下停留几毫秒——时间足够长、温度足够高，几乎能把一切原子化，并把大多数元素激发（且大部分电离）。

在**ICP-OES**中，发射光由高分辨率光谱仪分光，通常是用二维固态检测器一次记录数百条谱线的中阶梯光栅。它的优点源于物理本身：高温消除了大多数化学干扰；等离子体是**光学薄**的（发射的光不被再吸收），所以校准曲线在四到六个数量级内是线性的；并且所有元素同时测定。检出限通常为$0.1$–$10\ \mu\mathrm{g\,dm^{-3}}$。等离子体可以侧向观测（**径向**，基体效应较少）或沿轴向观测（**轴向**，光程长，检出限更低）。

炽热、多谱线光源的代价是**光谱干扰**：ICP会激发铁、铈、铀等富谱线元素的数千条谱线，氩本身也发射。每种元素都有若干条可选的谱线，分析工作者针对手头的基体选择不受重叠影响的谱线，在谱线两侧的点上做背景校正，并在无法避免重叠时使用元素间校正因子。非光谱效应（雾化的变化、高盐样品对等离子体的负载）用**内标**校正，例如向每种溶液中加入钇或钪（[[#exr-icp-internal]]）。

::: warning 光谱干净不等于结果正确 {#warn-atomic}
原子光谱法的选择性如此之高，以致人们很容易假定一条干净、峰形良好的谱线或峰必定属于分析物、必定是正确的。两个结论都推不出来。在ICP-MS中，高氯样品里$m/z = 75$处形状完美的峰可能主要来自$^{40}\mathrm{Ar}^{35}\mathrm{Cl}^+$而不是砷；在ICP-OES中，基体元素的一条小谱线可以伏在分析线之下；在AAS中，背景吸收若不加校正，看上去与原子吸收一模一样。而且即使信号正确，只要样品消解不完全（难熔硅酸盐、氧化物），分析物在灰化或消解中损失（汞、砷、硒具有挥发性），或标准溶液与样品的酸度和含盐量不同，结果照样会错。要用基体相似的有证标准物质、加标回收率以及第二条谱线或同位素来核查。
:::

## 电感耦合等离子体质谱法

ICP是优良的**离子**源：大多数元素在等离子体中有$90\ \%$以上以单电荷离子形式存在，因为氩的电离能（$15.76\ \mathrm{eV}$）几乎高于其他所有元素。在**ICP-MS**中，离子经采样锥和截取锥（孔径约$1\ \mathrm{mm}$）从常压等离子体被吸入真空，由离子透镜聚焦，按质荷比分离——通常用**四极杆**质量分析器，以单位分辨率一次通过一个$m/z$——然后计数。大多数元素的检出限在$0.1$–$10\ \mathrm{ng\,dm^{-3}}$（万亿分之一量级），线性范围覆盖八到十个数量级，而且同位素逐一测量，从而允许**同位素稀释**——所有校准方法中最准确的一种（[[analytical-chemistry/hyphenated-methods]]）。

ICP-MS也有自己的干扰。

- **同量异位素干扰**：不同元素的同位素具有相同的名义质量（$^{58}\mathrm{Fe}$与$^{58}\mathrm{Ni}$，$^{204}\mathrm{Hg}$与$^{204}\mathrm{Pb}$）。通过改选另一种同位素来避开，或利用干扰元素的另一种同位素从数学上校正。
- **多原子离子干扰**：由氩、溶剂和基体形成的分子离子，如$^{56}\mathrm{Fe}^+$上的$^{40}\mathrm{Ar}^{16}\mathrm{O}^+$、$^{80}\mathrm{Se}^+$上的$^{40}\mathrm{Ar}_2^+$、$^{75}\mathrm{As}^+$上的$^{40}\mathrm{Ar}^{35}\mathrm{Cl}^+$以及$^{51}\mathrm{V}^+$上的$^{35}\mathrm{Cl}^{16}\mathrm{O}^+$。它们在四极杆之前的**碰撞/反应池**中被除去：氦碰撞模式配动能歧视（KED），多原子离子比同质量的原子离子在碰撞中损失更多能量，从而被能量壁垒滤除；反应性气体（氢气、氨气、氧气）把干扰物或分析物转化为另一个质量。**高分辨**（扇形磁场）仪器则利用精确质量的微小差别把干扰物与分析物分开。
- **双电荷离子**：第二电离能低的元素（钡、稀土）会形成一些$\mathrm{M^{2+}}$，出现在质量的一半处（$^{138}\mathrm{Ba}^{2+}$在$m/z = 69$，叠在$^{69}\mathrm{Ga}^+$上）。
- **基体效应**：高浓度的溶解固体沉积在锥上，抑制电离和传输（由于离子束中的空间电荷效应，较重离子比较多轻离子占优势）。因此样品的总溶解固体保持在约$0.2\ \%$以下，并使用覆盖整个质量范围的内标。

::: example 把砷与氩氯化物分开 {#ex-resolution}
精确质量为：$^{75}\mathrm{As}$ $74.92160$、$^{40}\mathrm{Ar}$ $39.96238$、$^{35}\mathrm{Cl}$ $34.96885\ \mathrm{u}$。要把$^{75}\mathrm{As}^+$与$^{40}\mathrm{Ar}^{35}\mathrm{Cl}^+$分开，需要多高的质量分辨率$R = m/\Delta m$？四极杆做得到吗？
::: solution
$m(^{40}\mathrm{Ar}^{35}\mathrm{Cl}) = 39.96238 + 34.96885 = 74.93123\ \mathrm{u}$（电子质量在差值中相消）。$\Delta m = 74.93123 - 74.92160 = 0.00963\ \mathrm{u}$，于是
$$
R = \frac{m}{\Delta m} = \frac{74.92}{0.00963} \approx 7.8\times10^{3} .
$$
四极杆只有单位分辨率（$R \approx m$，这里约为$75$），无法把它们分开；扇形磁场仪器的中分辨率模式（$R \approx 4000$）也不行，其高分辨率模式（$R \approx 10\,000$）可以做到，但灵敏度代价不小。实际工作中，这种干扰在碰撞/反应池中消除——例如用氦动能歧视，或让$\mathrm{As^+}$与氧反应生成$m/z = 91$处的$\mathrm{AsO^+}$，避开干扰。
:::
:::

::: quiz
某实验室需要在每周几百个河流水样中测定$25$种元素，浓度从几十$\mathrm{mg\,dm^{-3}}$的钠到低于$1\ \mu\mathrm{g\,dm^{-3}}$的镉和铅。作为单一选择，哪种技术最合适？
- [ ] 火焰AAS，因为它便宜且精密度好。
- [ ] 石墨炉AAS，因为在AAS诸方法中它的检出限最低。
- [x] ICP-MS（主量元素可并用ICP-OES），因为它是多元素技术、速度快，并能达到$\mu\mathrm{g\,dm^{-3}}$以下的水平。
- [ ] 火焰发射光度法，因为河水里主要是碱金属。
::: solution
火焰AAS一次测一种元素，达不到$\mu\mathrm{g\,dm^{-3}}$以下的镉。石墨炉AAS能做到，但每个样品每个元素要几分钟，对几百个样品测$25$种元素并不可行。ICP-MS每个样品几分钟就能测完全部元素，灵敏度绰绰有余；主量元素极高的浓度可以稀释后测定，或用ICP-OES测定——后者在高浓度处的宽线性范围正可方便利用。火焰光度法只能测少数几种易激发的元素。
:::
:::

## 各技术的比较

| | 火焰AAS | 石墨炉AAS | ICP-OES | ICP-MS |
|---|---|---|---|---|
| 典型检出限 | $1$–$100\ \mu\mathrm{g\,dm^{-3}}$ | $0.01$–$1\ \mu\mathrm{g\,dm^{-3}}$ | $0.1$–$10\ \mu\mathrm{g\,dm^{-3}}$ | $0.0001$–$0.01\ \mu\mathrm{g\,dm^{-3}}$ |
| 每次测定的元素数 | 一种 | 一种（几种） | 多种，同时 | 多种，快速顺序 |
| 线性范围（数量级） | 2–3 | 2–3 | 4–6 | 8–10 |
| 主要干扰 | 化学、电离 | 背景、基体 | 光谱重叠 | 多原子离子、同量异位素、基体 |
| 相对成本 | 低 | 中等 | 高 | 最高 |

表中的数字是典型的数量级，不是技术指标；它们随元素和仪器而变。还有一种技术是**原子荧光光谱法**，与氢化物发生或冷蒸气发生联用，测定砷、硒和汞：把它们化学转化为挥发性的氢化物或汞蒸气，与基体分离后，以极低的检出限测量。这些方法的危害来自高压与射频设备、压缩气体（尤其是乙炔，必须使用带回火防止器、经过良好减压的合格钢瓶）、火焰和等离子体的紫外辐射、燃烧器产生的有毒烟气（原子化器上方必须装排风罩），以及消解所用的浓酸。

## 后续内容

原子光谱法的样品消解——微波辅助酸消解、熔融，以及痕量水平下损失与污染的风险——已在[[analytical-chemistry/analytical-process]]中讨论。把ICP-MS与色谱仪联用，以分离元素的化学形态（海产品中的砷甜菜碱与亚砷酸盐、甲基汞与无机汞）称为**形态分析**，它属于[[analytical-chemistry/hyphenated-methods]]的联用技术，该章还将展开同位素稀释。离子源截然不同的有机质谱见[[spectroscopy/mass-spectrometry]]。水体、土壤和空气中的痕量金属是[[environmental-chemistry/environmental-monitoring]]的主题。

::: history
罗伯特·本生（Bunsen）与古斯塔夫·基尔霍夫（Kirchhoff）以他们1859–61年的火焰研究开创了光谱化学分析，其间他们凭借谱线发现了铯（1860）和铷（1861）。在墨尔本CSIRO工作的艾伦·沃尔什（Walsh）构思了以空心阴极光源进行的原子吸收光谱法，1955年发表于*Spectrochimica Acta*；鲍里斯·利沃夫（L'vov）从20世纪50年代末在列宁格勒发展了石墨炉，沃尔特·斯拉文（Slavin）的小组在1980年代初推广了稳定平台炉。伯明翰的斯坦利·格林菲尔德（Greenfield）（1964年）与埃姆斯的韦尔默·法塞尔（Fassel）和理查德·温特（Wendt）（1965年）各自独立地把电感耦合等离子体引入作为发射光源。罗伯特·豪克（Houk）、法塞尔及其合作者于1980年演示了ICP质谱，其基础是艾伦·格雷（Gray）在英国的等离子体质谱工作，第一台商品仪器于1983年问世。
:::

::: summary
- 原子光谱法把样品转化为自由原子或离子；其窄而有特征的谱线带来高选择性，测得的是元素总量。
- 玻尔兹曼比值$N_j/N_0 = (g_j/g_0)e^{-\Delta E/k_\mathrm{B}T}$在火焰中极小且随温度强烈变化：吸收（基态）适合火焰；发射需要等离子体。
- 多普勒宽度为皮米量级，$\Delta\lambda_\mathrm{D} = (\lambda/c)\sqrt{8k_\mathrm{B}T\ln2/m}$，所以AAS需要线光源（空心阴极灯）或极高分辨率的光谱仪。
- 火焰AAS快速而精密；石墨炉原子化整个样品，使检出限降低百倍至千倍，但干扰更多，须靠基体改进剂和背景校正驯服。
- 化学干扰用释放剂、保护剂或更热的火焰消除；电离干扰（萨哈平衡）用过量易电离元素消除。
- ICP-OES给出线性范围宽的同时多元素分析，但光谱丰富；ICP-MS达到$\mathrm{ng\,dm^{-3}}$水平并能测同位素，多原子离子干扰在碰撞/反应池中除去。
- 信号干净不是结果正确的证明：要用有证标准物质、回收率和备选谱线或同位素验证。
:::

::: exercise 特征浓度 {level=1 check="0.049"}
$2.00\ \mathrm{mg\,dm^{-3}}$的铜标准溶液在火焰AAS中给出$0.180$的吸光度。求特征浓度。（$c_0$以$\mathrm{mg\,dm^{-3}}$输入。）
::: solution
$c_0 = 0.0044\times2.00/0.180 = 0.049\ \mathrm{mg\,dm^{-3}}$。$0.049\ \mathrm{mg\,dm^{-3}}$的铜溶液吸收灯发射光的$1\ \%$。制造商列出的特征浓度用来核查仪器工作是否正常。
:::

::: exercise 石墨炉的算术 {level=1 check="7.5"}
铅的$m_0 = 12\ \mathrm{pg}$，进样$20\ \mu\mathrm{l}$得$A_\mathrm{int} = 0.0550\ \mathrm{s}$。求进样溶液中铅的浓度。（以$\mu\mathrm{g\,dm^{-3}}$输入。）
::: solution
$m = 12\times0.0550/0.0044 = 150\ \mathrm{pg}$；$150\ \mathrm{pg}/20\ \mu\mathrm{l} = 7.5\ \mu\mathrm{g\,dm^{-3}}$。
:::

::: exercise 把铁与氩氧化物分开 {level=1 check="2500"}
$^{56}\mathrm{Fe}$与$^{40}\mathrm{Ar}^{16}\mathrm{O}$的精确质量为$55.93494$和$55.95730\ \mathrm{u}$。什么分辨率$m/\Delta m$能把它们分开？（$R$保留两位有效数字。）
::: solution
$\Delta m = 0.02236\ \mathrm{u}$；$R = 55.935/0.02236 = 2.5\times10^3$。扇形磁场仪器在中分辨率（$R \approx 4000$）下能把它们分开；四极杆不行，所以铁在碰撞模式或反应模式下测定，或者测$^{57}\mathrm{Fe}$（丰度$2.1\ \%$）——这时取而代之的干扰是$^{40}\mathrm{Ar}^{16}\mathrm{O}^1\mathrm{H}^+$。
:::
:::

::: exercise 锌的激发 {level=2 check="4.05"}
对锌的$213.857\ \mathrm{nm}$共振线（$g_j/g_0 = 3$），求$6000\ \mathrm{K}$下的$N_j/N_0$。（比值以$10^{-5}$为单位输入。）
::: solution
$\Delta E = hc/\lambda = 9.289\times10^{-19}\ \mathrm{J}$（$5.80\ \mathrm{eV}$）；$\Delta E/k_\mathrm{B}T = 9.289\times10^{-19}/(1.381\times10^{-23}\times6000) = 11.21$；$N_j/N_0 = 3e^{-11.21} = 4.05\times10^{-5}$。在$2500\ \mathrm{K}$下该比值将是$6\times10^{-12}$：锌用火焰吸收或等离子体发射测定，绝不用火焰发射测定。
:::
:::

::: exercise 发射对温度的敏感性 {level=2 check="3.9"}
利用[[#eq-boltzmann]]导出$N_j$每开尔文的相对变化，并计算$2500\ \mathrm{K}$下升温$10\ \mathrm{K}$时钠$589.0\ \mathrm{nm}$发射的百分数变化。（输入百分数。）
::: solution
$\dd\ln N_j/\dd T = \Delta E/(k_\mathrm{B}T^2)$（$N_0 \approx N$视为常数）。由$\Delta E/k_\mathrm{B} = 2.105\ \mathrm{eV}\times11\,604.5\ \mathrm{K\,eV^{-1}} = 24\,430\ \mathrm{K}$：$24\,430/2500^2 = 3.91\times10^{-3}\ \mathrm{K^{-1}}$，即每$10\ \mathrm{K}$为$3.9\ \%$。火焰发射法要把火焰温度稳定到约一开尔文，才能达到$0.4\ \%$的精密度——要求之高近乎苛刻，这是AAS在大多数元素上取代火焰发射的原因之一。
:::
:::

::: exercise ICP-OES中的内标 {#exr-icp-internal level=2 check="0.939"}
含$1.00\ \mathrm{mg\,dm^{-3}}$锰和钇内标的标准溶液给出强度$1520$（Mn）与$10\,200$（Y）。含相同钇浓度的样品给出$1210$（Mn）与$8650$（Y）。求锰的浓度，并说明钇信号下降表明了什么。（Mn以$\mathrm{mg\,dm^{-3}}$输入。）
::: solution
比值：标准$1520/10\,200 = 0.1490$；样品$1210/8650 = 0.1399$。$c(\mathrm{Mn}) = 1.00\times0.1399/0.1490 = 0.939\ \mathrm{mg\,dm^{-3}}$。若不用内标，就会报$1210/1520 = 0.796$，偏低$15\ \%$。钇信号下降$15\ \%$说明样品基体（黏度或含盐量较高）降低了雾化效率或等离子体激发；只要Mn与Y受到的扰动相同，内标就能校正这一点，而选择激发能相近的谱线最能确保这一点。
:::
:::

::: exercise 铅谱线的多普勒宽度 {#exr-doppler level=3 check="0.70"}
从麦克斯韦分布导出[[#eq-doppler]]，并计算铅$283.3\ \mathrm{nm}$谱线在$2500\ \mathrm{K}$下的多普勒宽度（$M = 207.2\ \mathrm{g\,mol^{-1}}$）。与典型AAS单色器的带宽（$0.2$–$0.7\ \mathrm{nm}$）比较。（$\Delta\lambda_\mathrm{D}$以pm输入。）
::: solution
推导即[[#prop-doppler]]的证明。取$m = 207.2\times1.6605\times10^{-27} = 3.441\times10^{-25}\ \mathrm{kg}$：
$$
\sqrt{\frac{8k_\mathrm{B}T\ln2}{m}} = \sqrt{\frac{8\times1.381\times10^{-23}\times2500\times0.6931}{3.441\times10^{-25}}} = 746\ \mathrm{m\,s^{-1}},
$$
所以$\Delta\lambda_\mathrm{D} = 283.3\ \mathrm{nm}\times746/2.998\times10^8 = 7.05\times10^{-4}\ \mathrm{nm} = 0.70\ \mathrm{pm}$。单色器的通带宽度约为它的$300$–$1000$倍；只有线光源才能与吸收线相匹配。
:::
:::

::: exercise 消电离剂 {level=3 check="0.013"}
利用[[#ex-ionisation]]的模型（钠的$S = 1.3\times10^{16}\ \mathrm{m^{-3}}$），证明电离分数为$S/(S + n_\mathrm{e})$。若某样品所含易电离的基体元素足以把$n_\mathrm{e}$从$1.0\times10^{16}$提高到$3.0\times10^{16}\ \mathrm{m^{-3}}$，钠的原子吸收信号变为原来的几倍？然后再求加入过量铯把$n_\mathrm{e}$固定在$1.0\times10^{18}\ \mathrm{m^{-3}}$时的电离分数。（输入那个分数。）
::: hint
吸收信号正比于以中性原子形式存在的钠的分数$n_\mathrm{e}/(S + n_\mathrm{e})$。
:::
::: solution
由[[#eq-saha]]，$n_{\mathrm{Na^+}}/n_{\mathrm{Na}} = S/n_\mathrm{e}$；电离分数为$(S/n_\mathrm{e})/(1 + S/n_\mathrm{e}) = S/(S + n_\mathrm{e})$。中性原子分数：$n_\mathrm{e} = 1.0\times10^{16}$时为$1.0/2.3 = 0.435$，$3.0\times10^{16}$时为$3.0/4.3 = 0.698$，所以样品相对于标准的信号*升高*到$1.60$倍——$60\ \%$的正误差。所有溶液中都加过量铯时，电离分数为$1.3\times10^{16}/1.013\times10^{18} = 0.013$，样品自身对$n_\mathrm{e}$贡献的微小变化就几乎无关紧要了。
:::
