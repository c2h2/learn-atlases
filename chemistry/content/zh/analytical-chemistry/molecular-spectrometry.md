往含微量铁(II)的水中滴加几滴1,10-菲啰啉（1,10-phenanthroline），溶液会呈现橙红色，其深浅与铁的量成正比：含$2\ \mathrm{mg\,dm^{-3}}$铁的溶液呈明显的浅橙色，含$0.2\ \mathrm{mg\,dm^{-3}}$的肉眼几乎看不出颜色，但用分光光度计很容易测量。测量有色（或吸收紫外光的）溶液吸收了多少光，是定量分析中最古老、至今仍是最常用的仪器方法：临床分析仪每小时运行数百个酶法和显色测定；水实验室用它测硝酸根、磷酸根和氨；在生物化学中，每一个蛋白质和核酸浓度都是从$280$或$260\ \mathrm{nm}$处的吸光度开始的；它也是液相色谱中最常用的检测器。

本章建立紫外与可见光区的**定量分子吸收光谱法**以及它的更灵敏的近亲**分子荧光**。我们将推导朗伯-比尔（Beer–Lambert）定律及其成立条件，说明光谱仪的内部构造，以及它的非理想因素——有限的带宽、杂散光、噪声——如何弯折校准线并决定吸光度的最佳范围，按多个波长测量来解析混合物，并处理荧光信号、它的线性范围与猝灭。产生这些光谱的电子跃迁（π → π*、n → π*、电荷转移与d–d谱带）在[[spectroscopy/electronic-spectroscopy]]中讲解；这里把吸光度当作一种测量来处理，并使用[[analytical-chemistry/statistics-calibration]]中的校准统计。

## 朗伯-比尔定律

一束辐射功率为$P_0$的单色辐射进入样品；出射功率为$P$。一部分光子被分析物分子吸收，分子被激发到激发电子态，然后（通常）把能量以热的形式失去。

::: definition 透射比、吸光度与摩尔吸收系数 {#def-absorbance}
样品的**透射比**为$T = P/P_0$，其**吸光度**为
$$
A = -\log_{10}T = \log_{10}\frac{P_0}{P} .
$$
实际测量中$P_0$是**参比**透过的功率（装有溶剂和试剂但不含分析物的吸收池），于是池窗上的反射损失和溶剂的吸收相互抵消。对光程$b$中物质的量浓度为$c$的单一吸光物种，**摩尔吸收系数**（旧称"摩尔吸光率"或"消光系数"）为$\varepsilon = A/(bc)$，常用单位是$\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。它取决于物种、波长、溶剂和温度。
:::

::: proposition 朗伯-比尔定律 {#prop-beer-lambert}
单色辐射穿过均匀、不散射、吸光分子彼此独立作用的溶液时，
$$
A = \varepsilon\,b\,c ,
$$ {#eq-beer}
而对互不作用的多种吸光物质的混合物，$A = b\sum_i\varepsilon_ic_i$：吸光度具有加和性。
:::

::: proof
考虑溶液在深度$x$处、厚度为$\dd x$的薄层。每个吸光分子对光束呈现的有效截面为$\sigma$（一个面积），薄层中单位面积上的分子数为$N_\mathrm{A}c\,\dd x$（$c$以单位体积的物质的量计）。只要分子互不遮蔽（稀溶液）且每个分子独立吸收，薄层吸收的光子分数就恰好等于其面积被遮挡的分数$\sigma N_\mathrm{A}c\,\dd x$。于是
$$
\frac{\dd P}{P} = -\sigma N_\mathrm{A}c\,\dd x .
$$
从$x = 0$（$P = P_0$）积分到$x = b$，
$$
\ln\frac{P}{P_0} = -\sigma N_\mathrm{A}c\,b, \qquad A = \log_{10}\frac{P_0}{P} = \frac{\sigma N_\mathrm{A}}{\ln10}\,bc = \varepsilon bc,
$$
其中$\varepsilon = \sigma N_\mathrm{A}/\ln10$。对多种物种，被遮挡的分数相加，所以指数相加。这些前提——单一波长（$\sigma$取单一值）、无散射、分子彼此独立、浓度不改变现存的物种——恰好就是其失效将引起下文所讨论各种偏离的那些条件。
:::

截面的解释让数字变得直观。染料强允许的π → π*谱带$\varepsilon \approx 10^4$–$10^5\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$，对应$\sigma \approx 10^{-16}\ \mathrm{cm^2}$，与发色团的几何尺寸相当：这样的分子几乎吸收每一条"击中"它的光子。禁戒跃迁，如水合过渡金属离子的d–d谱带，$\varepsilon$只有$1$–$100$，酮的n → π*谱带约为$10$–$30$。因此做痕量定量分析时，要把分析物转化为强吸收的配合物或染料——铁(II)与1,10-菲啰啉（$510\ \mathrm{nm}$处$\varepsilon = 1.11\times10^{4}$）、磷酸根转化为钼蓝、亚硝酸根转化为偶氮染料（格里斯（Griess）反应）、氨转化为靛酚蓝。

::: example 1,10-菲啰啉分光光度法测定铁 {#ex-iron-phen}
取$10.00\ \mathrm{cm^3}$井水水样，用羟胺（把全部铁还原为$\mathrm{Fe^{2+}}$）处理，加缓冲溶液，再加1,10-菲啰啉混匀，然后稀释至$100.0\ \mathrm{cm^3}$。在$510\ \mathrm{nm}$处用$1.00\ \mathrm{cm}$吸收池对试剂空白测得其吸光度为$0.456$。取三(菲啰啉)合铁(II)配合物的$\varepsilon = 1.11\times10^4\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$，求井水中铁的浓度，以$\mathrm{mg\,dm^{-3}}$计。
::: solution
在所测溶液中，由[[#eq-beer]]，
$$
c = \frac{A}{\varepsilon b} = \frac{0.456}{1.11\times10^{4}\times1.00} = 4.11\times10^{-5}\ \mathrm{mol\,dm^{-3}} .
$$
水样被稀释了十倍，所以井水原来含$4.11\times10^{-4}\ \mathrm{mol\,dm^{-3}}$，即$4.11\times10^{-4}\times55.845\times10^3 = 22.9\ \mathrm{mg\,dm^{-3}}$的铁——这是一份含铁很高的水。在常规工作中不会依赖文献$\varepsilon$：改用同一台仪器在相同条件下测得的校准线的斜率来代替它，这就自动考虑了带宽和试剂空白。
:::
:::

## 光谱仪的内部

一台紫外-可见分光光度计由四部分组成。

- **光源。** 氘灯（$190$–$350\ \mathrm{nm}$）和卤钨灯（$350$–$1100\ \mathrm{nm}$），或覆盖两个区域的氙闪光灯。
- **波长选择器。** **单色器**（入射狭缝、按波长对辐射色散的衍射光栅、出射狭缝）只让一个窄波长带通过。它的**光谱带宽**——所透过光带的半高宽度，典型为$0.5$–$2\ \mathrm{nm}$——由狭缝宽度和光栅的色散决定。简单的光度计改用滤光片，带宽为$10$–$40\ \mathrm{nm}$。
- **样品室。** 紫外区用石英（熔融二氧化硅）吸收池，可见区用玻璃或塑料吸收池，光程通常为$1.000\ \mathrm{cm}$。
- **探测器。** 光电倍增管（灵敏度极高，单通道）、硅光电二极管，或**二极管阵列**、CCD——后者在样品**后面**对光束分光，从而一次记录全部波长。

在**单光束**仪器中，参比和样品先后测量，光源或探测器在两次读数之间的漂移就是一种误差。**双光束**仪器用旋转反射镜（斩波器）劈分光束，每秒多次交替测量参比和样品，抵消漂移。**二极管阵列**仪器在几分之一秒内记录整张光谱，这使它特别适宜作液相色谱的检测器和动力学测量之用；其分辨率由二极管的数目和间距决定。

## 对朗伯-比尔定律的偏离

吸光度对浓度的校准线在高吸光度处常常弯曲。弯曲很少是[[#prop-beer-lambert]]本身失效；而是它的某一条前提失效。

**化学偏离。** 若分析物参与一个位置随浓度移动的平衡，则现存的物种随$c$改变。未加缓冲的二铬酸盐溶液，$\mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O} \rightleftharpoons 2\,\mathrm{HCrO_4^-}$，稀释时向右移动，而两种离子的光谱不同。弱酸型指示剂在总浓度改变时会改变其酸/碱之比，除非对pH进行缓冲。对策是化学性的：缓冲pH，加入过量试剂使配合反应完全，或在**等吸收点**测量——两种可相互转化的物种$\varepsilon$相同的波长处，吸光度只取决于两者的总量。

**真实偏离。** 浓度高时（$\gtrsim 0.01\ \mathrm{mol\,dm^{-3}}$）分子间距近到足以扰动彼此的电荷分布，而且溶液的折射率发生变化；$\varepsilon$便取决于$c$。这是该定律真实的极限，但在痕量分析中很少成为问题。

**仪器偏离**最为常见。其中两种占主导。

::: proposition 复合光与杂散光的影响 {#prop-deviations}
1. **复合光（非单色光）。** 若光束含有功率相等（各为$P_0/2$）、分析物摩尔吸收系数分别为$\varepsilon_1 \ne \varepsilon_2$的两个波长，则测得的吸光度为
$$
A_\mathrm{app} = -\log_{10}\frac{10^{-\varepsilon_1bc} + 10^{-\varepsilon_2bc}}{2},
$$ {#eq-polychromatic}
它总是小于平均值$\tfrac12(\varepsilon_1 + \varepsilon_2)bc$，且随$c$增大愈发向下弯离它（**负偏离**）。
2. **杂散光。** 若参考功率的比例$s$不经样品（或在样品不吸收的波长上）就到达检测器，则真实吸光度为$A$的样品测得的吸光度为
$$
A_\mathrm{app} = -\log_{10}\frac{10^{-A} + s}{1 + s},
$$ {#eq-stray}
当$A\to\infty$时趋于上限$\log_{10}[(1+s)/s]$。
:::

::: proof
(1) 检测器测量的是总功率。两个波长处透过的功率分别为$\tfrac12P_0\,10^{-\varepsilon_1bc}$和$\tfrac12P_0\,10^{-\varepsilon_2bc}$，所以$P/P_0 = \tfrac12(10^{-\varepsilon_1bc} + 10^{-\varepsilon_2bc})$，即得[[#eq-polychromatic]]。因为$10^{-x}$是凸函数，$10^{-x_1}$与$10^{-x_2}$的均值不小于$10^{-(x_1+x_2)/2}$（詹森（Jensen）不等式），仅当$x_1 = x_2$时取等号；取$-\log_{10}$使不等号反向，所以$A_\mathrm{app} \le \tfrac12(x_1 + x_2)$。差距随$\lvert x_1 - x_2\rvert = \lvert\varepsilon_1 - \varepsilon_2\rvert bc$增大，即随浓度增大。

(2) 把杂散功率$sP_0$加到两个读数上，参比读数为$P_0(1 + s)$，样品读数为$P_0(10^{-A} + s)$。两者之比即得[[#eq-stray]]。当$A\to\infty$时，$10^{-A}\to0$，$A_\mathrm{app}\to\log_{10}[(1+s)/s]$。
:::

::: widget plot

:::

::: example 杂散光会带来多大的误差？ {#ex-stray}
某分光光度计在工作波长处的杂散光为$0.10\ \%$。真实吸光度为$1.00$、$2.00$和$3.00$的样品，它显示的吸光度各是多少？
::: solution
由[[#eq-stray]]，取$s = 0.0010$：
$$
\begin{aligned}
A = 1.00:&\quad A_\mathrm{app} = -\log_{10}\frac{0.1000 + 0.0010}{1.0010} = 0.996, \\
A = 2.00:&\quad A_\mathrm{app} = -\log_{10}\frac{0.0100 + 0.0010}{1.0010} = 1.959, \\
A = 3.00:&\quad A_\mathrm{app} = -\log_{10}\frac{0.0010 + 0.0010}{1.0010} = 2.699 .
\end{aligned}
$$
误差分别为$-0.4\ \%$、$-2.0\ \%$和$-10\ \%$。当$A = 3$时只有$0.1\ \%$的光透过样品——与杂散光的量相同——仪器无法区分二者。校准因此应保持在$A \approx 1.5$以下；浓样品应当稀释，而不是在弯曲的校准线的高端读数。
:::
:::

复合光偏离解释了为什么测量要在吸收**最大值**处进行——那里$\varepsilon$在光谱带宽内变化很小——绝不在谱带的陡峭一侧进行。经验法则是光谱带宽应小于吸收带宽的约十分之一；对可见区溶液中宽的吸收带（宽约$50$–$100\ \mathrm{nm}$），$2\ \mathrm{nm}$的带宽绰绰有余。

### 吸光度的最佳范围

校准线上哪个位置测得最精密？若主要噪声是透射比读数中恒定的不确定度$\sigma_T$（热检测器或固定分辨读数器的仪器就是如此），则吸光度很低时不精密，因为$P$与$P_0$几乎相等、其小差值噪声很大；吸光度很高时也不精密，因为$P$太小。

::: proposition 透射比噪声恒定时浓度的相对误差 {#prop-photometric-error}
若唯一的误差是$T$中的恒定标准偏差$\sigma_T$，则由朗伯-比尔定律求得的浓度的相对标准偏差为
$$
\frac{\sigma_c}{c} = \frac{0.4343\,\sigma_T}{T\,\lvert\log_{10}T\rvert} = \frac{0.4343\,\sigma_T}{A\,10^{-A}},
$$ {#eq-photometric-error}
在$A = 0.4343$（$T = 36.8\ \%$）处最小。
:::

::: proof
由$c = -\log_{10}T/(\varepsilon b) = -\ln T/(\varepsilon b\ln10)$，得$\dd c/\dd T = -1/(\varepsilon bT\ln10)$。传播标准偏差$\sigma_T$，
$$
\frac{\sigma_c}{c} = \frac{\lvert\dd c/\dd T\rvert\,\sigma_T}{c} = \frac{\sigma_T/(\varepsilon bT\ln10)}{\lvert\ln T\rvert/(\varepsilon b\ln10)} = \frac{\sigma_T}{T\lvert\ln T\rvert} = \frac{0.4343\,\sigma_T}{T\lvert\log_{10}T\rvert} .
$$
求最小值即最大化$g(T) = -T\ln T$：$g'(T) = -\ln T - 1 = 0$给出$T = e^{-1} = 0.368$，即$A = \log_{10}e = 0.4343$。
:::

:::

## 混合物的分析

因为吸光度具有加和性，$n$种吸光物质的混合物可以在$n$个（或更多个）波长处测量来解析。对在同一吸收池中于$\lambda_1$和$\lambda_2$处测定的两组分X和Y，
$$
\begin{aligned}
A_1 &= \varepsilon_{\mathrm{X},1}bc_\mathrm{X} + \varepsilon_{\mathrm{Y},1}bc_\mathrm{Y},\\
A_2 &= \varepsilon_{\mathrm{X},2}bc_\mathrm{X} + \varepsilon_{\mathrm{Y},2}bc_\mathrm{Y},
\end{aligned}
$$ {#eq-mixture}
这是关于两个未知浓度的两个线性方程。当每个组分各在一个波长处占主导时，问题条件良好，即$\varepsilon$值矩阵远离奇异。现代做法是测量整张光谱，并用最小二乘法把它拟合为纯组分光谱的线性组合；这样利用了全部数据，并能通过残差暴露出预料之外的组分。

::: example 两组分混合物 {#ex-mixture}
两种染料X和Y的$\varepsilon$（单位$\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$）为：在$\lambda_1$处$\varepsilon_{\mathrm{X}} = 1.20\times10^4$、$\varepsilon_\mathrm{Y} = 2.0\times10^3$；在$\lambda_2$处$\varepsilon_\mathrm{X} = 1.5\times10^3$、$\varepsilon_\mathrm{Y} = 9.0\times10^3$。某混合物在$1.00\ \mathrm{cm}$吸收池中给出$A_1 = 0.580$、$A_2 = 0.470$。求$c_\mathrm{X}$和$c_\mathrm{Y}$。
::: solution
方程[[#eq-mixture]]即
$$
\begin{aligned}
12\,000\,c_\mathrm{X} + 2\,000\,c_\mathrm{Y} &= 0.580,\\
1\,500\,c_\mathrm{X} + 9\,000\,c_\mathrm{Y} &= 0.470 .
\end{aligned}
$$
由克莱姆法则，行列式为$12\,000\times9\,000 - 2\,000\times1\,500 = 1.050\times10^8$，于是
$$
c_\mathrm{X} = \frac{0.580\times9\,000 - 2\,000\times0.470}{1.050\times10^8} = \frac{4\,280}{1.050\times10^8} = 4.08\times10^{-5}, \qquad c_\mathrm{Y} = \frac{12\,000\times0.470 - 1\,500\times0.580}{1.050\times10^8} = 4.54\times10^{-5}
$$
（两者均以$\mathrm{mol\,dm^{-3}}$计）。验算：$A_1 = 12\,000\times4.08\times10^{-5} + 2\,000\times4.54\times10^{-5} = 0.580$。若两条光谱相似，行列式就会很小，吸光度的小误差便会在浓度中造成大误差。
:::
:::

吸光度还可用来跟踪滴定（**分光光度滴定**：吸光度对体积的曲线是两条在滴定终点相交的直线），并用**连续变化法**（Job法）测定配合物的化学计量：测量金属与配体总浓度恒定、摩尔分数改变的一系列溶液，配合物的吸光度在其化学式对应的摩尔分数处出现极大。

::: warning 吸光度不是化合物单独决定的性质 {#warn-absorbance}
人们常把文献$\varepsilon$值当作自然常数，由单次读数计算浓度。但$\varepsilon$取决于波长、带宽、溶剂、pH、温度以及（对配合物）配合是否完全，而*所测*吸光度还包含空白和一切杂散光。表中的$\varepsilon$值只是灵敏度的指南，不是校准。同样，高吸光度不等于好吸光度：约$1.5$以上的值已被杂散光扭曲；一条延伸到$A = 2.5$的"线性"校准几乎总是把弯曲的曲线硬拟合成了直线。应改为稀释样品。试剂空白也不是可选项：许多显色试剂在分析波长处本身就略有吸收。
:::

## 分子荧光

分子吸收光子被激发后，可以经由若干途径返回基态。先经快速振动弛豫到第一激发单重态$\mathrm{S_1}$的最低振动能级（皮秒之内），然后可以发射光子（**荧光**，寿命通常为纳秒），或以热的形式损失能量（**内转换**），或转移到三重态（**系间窜越**），由三重态发出的慢发射是**磷光**。由于发光能级低于把它激发起来的能级，荧光发生在比激发光更长的波长处（**斯托克斯位移**）。被吸收的光子中以荧光形式再发射的比例称为**荧光量子产率**$\Phi_\mathrm{F}$。

荧光在与激发光束垂直的方向上、以暗背景为对照进行测量。这是它相对吸收法的最大优点：吸收光谱法必须在两个大信号（$P_0$与$P$）之间检测一个小差值，而荧光是在几乎为零的背景上检测一个小信号。对同一化合物，荧光法通常比吸收法灵敏$10^2$到$10^4$倍，而且选择性也更高，因为激发波长和发射波长都可以选择。

::: proposition 荧光信号 {#prop-fluorescence}
用功率为$P_0$的单色辐射激发稀溶液时，到达检测器的荧光功率为
$$
F = k\,\Phi_\mathrm{F}\,P_0\left(1 - 10^{-\varepsilon bc}\right) \approx 2.303\,k\,\Phi_\mathrm{F}\,P_0\,\varepsilon bc \quad (\varepsilon bc \lesssim 0.05),
$$ {#eq-fluorescence}
其中$k$为发射光子中被收集的比例（几何因素、检测器效率）。荧光只在低吸光度下正比于浓度，并正比于激发功率。
:::

::: proof
由[[#eq-beer]]，吸收的功率为$P_0 - P = P_0(1 - 10^{-\varepsilon bc})$。被吸收光子中的比例$\Phi_\mathrm{F}$被再发射（假设激发光子与发射光子按同一标度计数，或把$k$并入单位），这些光子中又有比例$k$到达检测器。当$x = \varepsilon bc$很小时，$10^{-x} = e^{-x\ln10} \approx 1 - x\ln10$，所以$1 - 10^{-x} \approx 2.303x$，即线性形式。由级数的下一项可知，对小$x$线性形式的相对误差约为$1.15x$，在$x \approx 0.045$处达到$5\ \%$。
:::

在上述很小的吸光度以上，信号低于线性；而在高浓度下信号实际上反而**降低**：大部分激发光在前窗附近就被吸收，永远到不了检测器观测的区域，而且若吸收带与发射带重叠，发射的光还会被再吸收。这就是**内滤效应**，它使荧光校准只在低浓度范围内有用——而这恰恰是需要荧光测定的范围。

荧光还会因**猝灭**而减弱：激发态分子与猝灭剂（溶解氧、卤离子、重原子化合物）碰撞，以不发光的方式失去能量。

::: proposition 斯特恩-沃尔默方程 {#prop-stern-volmer}
若猝灭剂Q以速率常数$k_\mathrm{q}$经碰撞使激发态失活，与寿命为$\tau_0$的未猝灭衰减相竞争，则
$$
\frac{F_0}{F} = 1 + K_\mathrm{SV}[\mathrm{Q}], \qquad K_\mathrm{SV} = k_\mathrm{q}\tau_0,
$$ {#eq-stern-volmer}
其中$F_0$与$F$分别为不加和加入猝灭剂时的荧光强度。
:::

::: proof
设激发态$\mathrm{M^*}$以恒定速率$I_\mathrm{a}$生成，以总速率常数$k_0 = 1/\tau_0$的一级过程衰减（辐射速率$k_\mathrm{r}$加非辐射速率），并按速率$k_\mathrm{q}[\mathrm{Q}][\mathrm{M^*}]$被猝灭。稳态下$[\mathrm{M^*}] = I_\mathrm{a}/(k_0 + k_\mathrm{q}[\mathrm{Q}])$。荧光强度为$k_\mathrm{r}[\mathrm{M^*}]$，所以
$$
\frac{F_0}{F} = \frac{k_0 + k_\mathrm{q}[\mathrm{Q}]}{k_0} = 1 + k_\mathrm{q}\tau_0[\mathrm{Q}] .
$$
这里的稳态处理与[[kinetics/photochemistry]]中的相同。
:::

::: example 斯特恩-沃尔默图 {#ex-stern-volmer}
测定稀硫酸中奎宁的荧光随加入氯化物的变化，得到示例数据：$[\mathrm{Cl^-}] = 0$、$0.010$、$0.020$、$0.030$和$0.040\ \mathrm{mol\,dm^{-3}}$时，$F_0/F = 1.00$、$1.21$、$1.42$、$1.62$和$1.85$。求$K_\mathrm{SV}$；若$\tau_0 = 19\ \mathrm{ns}$（约为稀酸中奎宁测得的寿命），再求$k_\mathrm{q}$。这对测定奎宁水中的奎宁意味着什么？
::: solution
$F_0/F$对$[\mathrm{Cl^-}]$的最小二乘直线斜率为$K_\mathrm{SV} = 21.1\ \mathrm{dm^3\,mol^{-1}}$，截距为$0.998$（接近模型要求的$1$，支持该模型）。于是
$$
k_\mathrm{q} = \frac{K_\mathrm{SV}}{\tau_0} = \frac{21.1}{1.9\times10^{-8}} = 1.1\times10^{9}\ \mathrm{dm^3\,mol^{-1}\,s^{-1}},
$$
与水中扩散控制极限（大约$10^{10}$）相当，符合碰撞猝灭剂的特征。实际推论：酸化奎宁样品绝不能用盐酸；含$0.01\ \mathrm{mol\,dm^{-3}}$氯离子的样品就会损失约六分之一的信号（$1/1.21 = 0.83$）；奎宁应在稀硫酸中测定，并用同一介质中的标准溶液校准。
:::
:::

猝灭对定量荧光是麻烦，但也是传感原理：生物反应器和血气分析仪中的氧传感器测量的是发光的钌或铂配合物被猝灭的程度，许多用于金属离子的荧光探针靠的是离子结合时把猝灭开启或关闭来工作。

::: quiz
某染料的荧光校准在$1\ \mu\mathrm{mol\,dm^{-3}}$以下呈线性，但一个已知约含$100\ \mu\mathrm{mol\,dm^{-3}}$的样品给出的读数却**低于**$1\ \mu\mathrm{mol\,dm^{-3}}$标准溶液的读数。最可能的解释是：
- [ ] 染料在浓样品中分解了。
- [x] 内滤效应：高吸光度下激发光在到达观测区域之前就被吸收，信号因此下降。
- [ ] 发射单色器中的杂散光。
- [ ] 斯托克斯位移依赖于浓度。
::: solution
[[#eq-fluorescence]]只在$\varepsilon bc \lesssim 0.05$时线性；在线性范围上限一百倍的浓度处，溶液在入射窗附近吸收了大部分激发光，而检测器观测的是吸收池的中部，看到的发射很少。发射光的再吸收又加重这一效应。对策是稀释至读数落在线性范围内；一个快捷的检验是：把样品稀释十倍，信号应当降为十分之一。
:::
:::

## 后续内容

同样的吸光度算术，把比色皿中的分子换成火焰中的原子，就是原子吸收的基础（[[analytical-chemistry/atomic-spectrometry]]）。紫外-可见吸光度与荧光是液相色谱中最常用的检测器（[[analytical-chemistry/chromatography]]）。吸收谱带的成因、选律与弗兰克-康登（Franck–Condon）原理见[[spectroscopy/electronic-spectroscopy]]；过渡金属配合物的颜色见[[coordination-chemistry/spectra-of-complexes]]；激发态的光物理（包括猝灭动力学）见[[kinetics/photochemistry]]。在生物化学中，蛋白质在$280\ \mathrm{nm}$和核酸在$260\ \mathrm{nm}$的吸光度几乎是每个实验的第一个测量（[[biochemistry/amino-acids-proteins]]）。

::: history
皮埃尔·布格（Bouguer）（《光度学试论》，*Essai d'optique sur la gradation de la lumière*，1729）与约翰·海因里希·朗伯（Lambert）（《光度学》，*Photometria*，1760）发现光的透过分数随光程按指数规律下降，奥古斯特·比尔（Beer）1852年证明对溶液中的浓度同样成立。乔治·加布里埃尔·斯托克斯（Stokes）1852年把荧光解释为在比被吸收光更长的波长处的发射，荧光（fluorescence）一词即由萤石（fluorite）而来。奥托·斯特恩（Stern）与马克斯·沃尔默（Volmer）1919年发表了对荧光猝灭的分析。第一台广泛取得成功的商品紫外-可见分光光度计是1941年的贝克曼（Beckman）DU，采用石英棱镜单色器和光电池；阿米科（Aminco）公司20世纪50年代中期的分光荧光计与美国国立卫生研究院的罗伯特·鲍曼（Bowman）合作研制，为荧光测量做了同样的事。保罗·约布（Job）1928年提出了连续变化法。
:::

::: summary
- 对单色辐射、稀溶液以及彼此独立、不散射的吸光物质，吸光度$A = -\log_{10}T = \varepsilon bc$；互不作用物种的吸光度相加。
- 一台光谱仪组合了光源、带宽有限的波长选择器、吸收池和检测器；双光束与二极管阵列设计可减小漂移、快速记录光谱。
- 化学偏离来自依赖于浓度的平衡；仪器偏离来自复合光（负偏离）和杂散光（上限为$\log[(1+s)/s]$）。
- 透射比噪声恒定时最佳吸光度为$0.434$；校准应保持在约$0.1$到$1.5$之间，并在吸收最大值处测量。
- 混合物通过在多个波长处解$A_\lambda = b\sum_i\varepsilon_{i,\lambda}c_i$来解析，最好用整谱最小二乘拟合。
- 荧光$F = k\Phi_\mathrm{F}P_0(1 - 10^{-\varepsilon bc})$只在$A \approx 0.05$以下线性；因为以对暗背景测量，它比吸收法更灵敏、更有选择性。
- 碰撞猝灭服从$F_0/F = 1 + k_\mathrm{q}\tau_0[\mathrm{Q}]$；它既是基体误差的来源，也是一种传感原理。
:::

## 习题

::: exercise 由透射比求吸光度 {level=1 check="0.456"}
某溶液在其吸收最大处透过入射光的$35.0\ \%$。其吸光度是多少？（输入$A$。）
::: solution
$A = -\log_{10}0.350 = 0.456$。注意两种标度的不对称：$10\ \%T$对应$A = 1$，$1\ \%T$对应$A = 2$，$50\ \%T$对应$A = 0.301$。
:::
:::

::: exercise 摩尔吸收系数 {level=1 check="14900"}
$2.50\times10^{-5}\ \mathrm{mol\,dm^{-3}}$的某染料溶液在$1.00\ \mathrm{cm}$吸收池中的吸光度为$0.372$。求$\varepsilon$，并求$1.00\times10^{-5}\ \mathrm{mol\,dm^{-3}}$的溶液在$5.00\ \mathrm{cm}$吸收池中的吸光度。（$\varepsilon$以$\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$输入。）
::: solution
$\varepsilon = 0.372/(1.00\times2.50\times10^{-5}) = 1.49\times10^4\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。在更长光程的吸收池中，$A = 1.488\times10^4\times5.00\times1.00\times10^{-5} = 0.744$。对稀样品，用更长的吸收池是提高灵敏度的简便办法，前提是空白也在同一吸收池中测量。
:::
:::

::: exercise 相对量子产率 {level=1 check="0.402"}
一种新的荧光物质在乙醇（折射率$1.360$）中于吸光度$0.0480$处给出积分发射$5.10\times10^5$（任意单位）。在相同的仪器条件下，硫酸奎宁的$0.5\ \mathrm{mol\,dm^{-3}}$ $\mathrm{H_2SO_4}$溶液（折射率$1.333$；取常用值$\Phi_\mathrm{F} = 0.546$）在吸光度$0.0520$处给出$7.82\times10^5$。用$\Phi = \Phi_\mathrm{ref}(F/F_\mathrm{ref})(A_\mathrm{ref}/A)(n^2/n_\mathrm{ref}^2)$求新化合物的$\Phi_\mathrm{F}$。（输入$\Phi_\mathrm{F}$。）
::: solution
三个比值为$F/F_\mathrm{ref} = 5.10/7.82 = 0.6522$、$A_\mathrm{ref}/A = 0.0520/0.0480 = 1.0833$、$(n/n_\mathrm{ref})^2 = (1.360/1.333)^2 = 1.0409$。于是$\Phi = 0.546\times0.6522\times1.0833\times1.0409 = 0.402$。两个吸光度都在$0.05$以下，[[#eq-fluorescence]]的线性形式适用，被吸收的分数正比于$A$；折射率因子校正两种溶剂中收集到发射的立体角不同。
:::
:::

::: exercise 两种染料的混合物 {level=2 check="2.81"}
用[[#ex-mixture]]中的$\varepsilon$值，第二个混合物在$1.00\ \mathrm{cm}$吸收池中给出$A_1 = 0.395$、$A_2 = 0.300$。求$c_\mathrm{X}$和$c_\mathrm{Y}$。（$c_\mathrm{X}$以$10^{-5}\ \mathrm{mol\,dm^{-3}}$为单位输入。）
::: solution
行列式仍是$1.050\times10^8$：$c_\mathrm{X} = (0.395\times9\,000 - 2\,000\times0.300)/1.050\times10^8 = 2\,955/1.050\times10^8 = 2.81\times10^{-5}\ \mathrm{mol\,dm^{-3}}$，而$c_\mathrm{Y} = (12\,000\times0.300 - 1\,500\times0.395)/1.050\times10^8 = 3\,007.5/1.050\times10^8 = 2.86\times10^{-5}\ \mathrm{mol\,dm^{-3}}$。在$\lambda_2$处验算：$1\,500\times2.814\times10^{-5} + 9\,000\times2.864\times10^{-5} = 0.300$。
:::
:::

::: exercise 高吸光度下的杂散光 {level=2 check="2.09"}
某仪器有$0.50\ \%$的杂散光。真实吸光度为$2.50$的样品它显示的吸光度是多少？它至多能显示多大的吸光度？（输入显示的吸光度。）
::: solution
由[[#eq-stray]]：$A_\mathrm{app} = -\log_{10}[(10^{-2.50} + 0.0050)/1.0050] = -\log_{10}(0.008162/1.0050) = 2.09$，误差$16\ \%$。上限为$\log_{10}(1.005/0.005) = 2.30$。
:::
:::

::: exercise 氧的猝灭 {level=2 check="2.0"}
某荧光物质在无氧溶剂中$\tau_0 = 10\ \mathrm{ns}$；猝灭剂浓度为$0.050\ \mathrm{mol\,dm^{-3}}$时荧光强度减半。求$k_\mathrm{q}$。（$k_\mathrm{q}$以$10^9\ \mathrm{dm^3\,mol^{-1}\,s^{-1}}$为单位输入。）
::: solution
$F_0/F = 2.0 = 1 + K_\mathrm{SV}\times0.050$，所以$K_\mathrm{SV} = 20\ \mathrm{dm^3\,mol^{-1}}$，$k_\mathrm{q} = 20/1.0\times10^{-8} = 2.0\times10^{9}\ \mathrm{dm^3\,mol^{-1}\,s^{-1}}$。对长寿命的荧光物质，即使空气饱和水中约$0.3\ \mathrm{mmol\,dm^{-3}}$的溶解氧也会引起明显猝灭，这就是这类样品要脱气的原因。
:::
:::

::: exercise 最佳吸光度 {level=3 check="0.4343"}
推导[[#eq-photometric-error]]并证明最优值位于$A = \log_{10}e$。再证明若$P$中的噪声改为正比于$\sqrt{P}$（散粒噪声，$\sigma_T = k\sqrt{T}$），最优点移到$A = 2\log_{10}e = 0.869$。（输入$\sigma_T$恒定时的最佳吸光度。）
::: hint
第二种情形下最小化$\sqrt{T}/(T\lvert\ln T\rvert) = 1/(\sqrt{T}\lvert\ln T\rvert)$，即最大化$-\sqrt{T}\ln T$。
:::
::: solution
第一部分就是[[#prop-photometric-error]]的证明：最大化$-T\ln T$，得$T = e^{-1}$、$A = \log_{10}e = 0.4343$。散粒噪声下，$\sigma_c/c = k\sqrt{T}/(T\lvert\ln T\rvert) = k/(\sqrt{T}\lvert\ln T\rvert)$。最大化$h(T) = -T^{1/2}\ln T$：$h'(T) = -\tfrac12T^{-1/2}\ln T - T^{-1/2} = 0$给出$\ln T = -2$，$T = e^{-2} = 0.135$，$A = 2\log_{10}e = 0.869$。物理含义：当噪声本身随透过的光变少而变小时，多吸收一些反而划算。
:::
:::

::: exercise 复合光偏差有多大？ {level=3 check="-1.27"}
滤光光度计的带通内实际上包含两个等功率的波长，分析物的$\varepsilon$在两处分别为$2000$和$1600\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。对$1.00\ \mathrm{cm}$吸收池中的$5.00\times10^{-4}\ \mathrm{mol\,dm^{-3}}$溶液，求显示的吸光度及其相对于预期值$\tfrac12(\varepsilon_1 + \varepsilon_2)bc$的百分误差。（误差以百分计输入。）
::: solution
$\varepsilon_1bc = 1.000$、$\varepsilon_2bc = 0.800$。由[[#eq-polychromatic]]，$A_\mathrm{app} = -\log_{10}[(0.1000 + 0.1585)/2] = -\log_{10}0.12924 = 0.8886$。预期值为$0.900$，所以误差为$(0.8886 - 0.900)/0.900 = -1.27\ \%$。若校准标准与样品的浓度范围相近，这一误差大部分会相消；把低浓度处做的校准向上外推时它才成为问题。
:::
:::

::: exercise 荧光的线性范围 {level=3 check="0.045"}
用[[#eq-fluorescence]]求真实荧光信号比线性近似低$5\ \%$时的吸光度$x = \varepsilon bc$，即解$(1 - 10^{-x})/(2.303x) = 0.95$。对$\varepsilon = 8.0\times10^4\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$的染料，在$1.00\ \mathrm{cm}$吸收池中这对应多大的浓度？（输入$x$。）
::: hint
先把$10^{-x} = e^{-2.303x}$展开到二阶得初估值，再数值细化。
:::
::: solution
二阶近似下，$(1 - e^{-u})/u \approx 1 - u/2$，其中$u = 2.303x$；令$1 - u/2 = 0.95$得$u = 0.10$、$x = 0.043$。精确解（牛顿法或计算器）为$x = 0.045$。对该染料，$c = 0.045/(8.0\times10^4\times1.00) = 5.6\times10^{-7}\ \mathrm{mol\,dm^{-3}}$——对强吸收的荧光物质，线性范围上限远低于每升一微摩尔，这就是荧光校准范围很低的原因。
:::
:::
