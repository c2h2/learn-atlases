1868 年，爱丁堡的克拉姆·布朗（Alexander Crum Brown）与弗雷泽（Thomas Fraser）把一系列植物生物碱——士的宁、马钱子碱、吗啡、烟碱等——转化为它们的 *N*-甲基季铵盐，发现产物无论母体的作用如何，如今都像箭毒一样麻痹肌肉。他们断定生理作用是化学组成的函数，并问这个函数能否写出来。一个半世纪后，这个问题仍然界定着药物化学。给定一个先导化合物（[[medicinal-chemistry/hits-and-leads]]），它的哪些部分对活性重要？什么可以改变，改成什么？在化合物被合成出来之前，能否预测改变的效果？

研究生物活性随结构如何变化的学问称为**构效关系**（SAR）。本章先讲定性工具箱——探查官能团、定义**药效团**、变换碳骨架、限制构象、用**生物电子等排体**替换基团——再讲定量的一套：哈梅特取代基常数、疏水常数 $\pi$、**汉施分析**与 **Free–Wilson** 方法，它们把活性表达为对理化描述符的线性自由能关系。结合的自由能图景来自[[medicinal-chemistry/drug-binding]]；芳环上取代基的电子效应已在[[organic-2/aromatic-substitution]]中建立；线性自由能关系的物理有机化学见[[kinetics/transition-state-theory]]。

## 探查先导：哪些基团要紧？

关于一个先导，最初的问题关于它的官能团。每个羟基、胺、羰基与芳环，要么正在与靶点形成一处相互作用，要么是乘客。经典做法是合成一次只去掉或**掩蔽**一个基团的类似物——羟基转成甲醚（不再是氢键供体）、胺转成酰胺（不再呈碱性，因而不再带电）、酮还原成醇（几何与受体强度都变了）——并测量活性发生了什么变化。

解读用的是自由能标度。$298\ \mathrm{K}$ 下活性降低十倍意味着结合自由能损失 $5.7\ \mathrm{kJ\,mol^{-1}}$；去掉后使活性损失 100 倍以上的基团正在形成重要相互作用，而去掉后活性变化不到两三倍的基团多半没有。但推断并不密不透风。改变可以间接起作用——酚甲基化同时增大体积、改变构象偏好；胺酰化改变分子的 $\log D$，从而改变它在细胞测定中的浓度。来自细胞或动物测定的 SAR 把结合与药代动力学混在一起，最干净的 SAR 来自纯化靶点的结合或酶测定。

::: definition 药效团 {#def-pharmacophore}
**药效团**是立体与电子特征——氢键供体与受体、正负可电离基团、芳环与疏水中心——连同它们在三维中的相对位置的集合，是分子与某一特定靶点相互作用并产生（或阻断）其反应所必需的。它是一个抽象：说的是特征，不是特定原子或官能团，所以结构不同的分子可以共享同一个药效团（IUPAC，韦缪特与同事，1998）。
:::

重要基团一旦确定，它们的空间排布就是药效团。例如 β肾上腺素受体拮抗剂（β受体阻滞剂），经典药效团是一个芳氧基丙醇胺：一个带支链烷基（异丙基或叔丁基）、生理 pH 下质子化的仲胺；氮 β 位碳上一个羟基，(*S*) 构型；以及一个经 $\mathrm{{-}OCH_2{-}}$ 连接的芳环。普萘洛尔（萘环）、阿替洛尔（*对*位取代苯）与噻吗洛尔（噻二唑）的芳环部分完全不同，却以同样的排布呈现同样三个特征。药效团模型用于在数据库中搜寻新骨架（基于配体的虚拟筛选，[[medicinal-chemistry/hits-and-leads]]），并解释为什么看起来不相关的分子作用于同一受体。

::: example 解读一组去基团数据 {#ex-removal}
某先导抑制剂 $K_\mathrm{I} = 20\ \mathrm{nmol\,dm^{-3}}$。类似物给出：酚 OH → OMe，$K_\mathrm{I} = 18\ \mu\mathrm{mol\,dm^{-3}}$；酚 OH → H，$K_\mathrm{I} = 15\ \mu\mathrm{mol\,dm^{-3}}$；环甲基 → H，$K_\mathrm{I} = 40\ \mathrm{nmol\,dm^{-3}}$；仲胺 N–H → N–CH₃，$K_\mathrm{I} = 25\ \mathrm{nmol\,dm^{-3}}$。哪些基团属于药效团？$298\ \mathrm{K}$ 下各处相互作用值多少？
::: solution
把每个比值换算成 $\Delta\Delta G = RT\ln(K_\mathrm{analogue}/K_\mathrm{lead})$。OH → OMe：比值 900，$\Delta\Delta G = 5.71\log 900 = 16.9\ \mathrm{kJ\,mol^{-1}}$。OH → H：比值 750，$16.4\ \mathrm{kJ\,mol^{-1}}$。甲基 → H：比值 2，$1.7\ \mathrm{kJ\,mol^{-1}}$。N–H → N–CH₃：比值 1.25，$0.6\ \mathrm{kJ\,mol^{-1}}$。酚显然必不可少，而且既然去掉它与把它甲基化的损害相当，它是在充当氢键*供体*（醚仍能充当受体）。环甲基只贡献不大的疏水作用，胺的 N–H 不是对靶点的供体（但氮本身作为碱仍可能重要：甲基化保持其碱性）。酚 OH 属于药效团；甲基是改造的候选。
:::
:::

## 变换骨架

药效团已知后，化学家变换分子的其余部分以改善效价、选择性与性质。标准套路不多，最好从结合自由能与[[medicinal-chemistry/pharmacokinetics]]所描述的理化代价来想。

- **同系化与链支化。** 给烷基链逐个加亚甲基，活性通常先升到最优再下降：链先是填满疏水口袋，然后溢出（或亲脂性变得过头）。支化改变形状，并能在分支点阻断代谢。
- **换环。** 用吡啶替换苯，增加一个氢键受体并把 $\log P$ 降约 1.4；用噻吩替换，保持形状与芳香性；给环加氢，增加三维性与溶解度。并环与扩环改变取代基之间的夹角。
- **延伸。** 加一个能够到相邻口袋的基团可以增加一处相互作用——片段生长的基础。
- **构象限制。** 柔性分子以一种构象结合。通过成环、引入双键、或加一个偏置某个扭转角的取代基把它锁定在该构象上，就消除了构象熵代价（每冻结一根可旋转键约 $1$–$4\ \mathrm{kJ\,mol^{-1}}$）与达到结合构象的应变。若锁错了构象，活性急剧下降——这本身就揭示了活性构象。刚性类似物也常常结合更少的脱靶点，因为它们能采取的形状更少。

小的结构改变有时带来意想不到的大效价变化：**活性悬崖**。**“魔术甲基”**效应——加一个甲基带来十倍甚至更大的效价提升——通常是构象效应：甲基迫使联芳基扭转、迫使酰胺采取结合几何，或置换一个位置不当的水分子。活性悬崖是一个系列中最有信息量的数据，而**匹配分子对**分析在多个系列中比较同一个小改变的效果，用来弄清哪些改变普遍有用。

### 等排体与生物电子等排体

::: definition 等排体与生物电子等排体 {#def-bioisostere}
**等排体**（朗缪尔（Irving Langmuir），1919）是价电子数目与排布相同的原子、离子或分子，例如 $\mathrm{N_2}$ 与 $\mathrm{CO}$，或 $\mathrm{N_2O}$ 与 $\mathrm{CO_2}$，它们具有相似的物理性质。**生物电子等排体**（弗里德曼（Harris Friedman），1951）是能在生物活性分子中相互替换而保持活性的基团，因为它们共享对相互作用重要的特征——大小、形状、电子分布、氢键模式、酸性或亲脂性。**经典**生物电子等排体遵循价电子类比（例如 $\mathrm{{-}CH_2{-}}$、$\mathrm{{-}NH{-}}$、$\mathrm{{-}O{-}}$、$\mathrm{{-}S{-}}$）；**非经典**生物电子等排体不共享原子数或电子数，而是模拟某种性质（例如用四氮唑代替羧酸）。一个替换是否生物等排，是针对特定靶点的经验发现，不是基团本身的性质。
:::

生物电子等排替换用于在保住活性的同时修好别的什么。常见替换：

| 基团 | 生物电子等排体 | 通常得到什么 |
|---|---|---|
| $\mathrm{{-}CO_2H}$（$\mathrm{p}K_\mathrm{a} \approx 4$–$5$） | 1*H*-四氮唑-5-基（$\mathrm{p}K_\mathrm{a} \approx 4.5$–$5$）、酰磺酰胺、异羟肟酸 | 酸性相似，电荷更离域，亲脂性更高，无酰基葡萄糖醛酸苷代谢物 |
| $\mathrm{{-}H}$ | $\mathrm{{-}F}$ | 大小相似，阻断 P450 氧化，改变邻近基团的 $\mathrm{p}K_\mathrm{a}$ |
| $\mathrm{{-}C(O)O{-}}$（酯） | 酰胺、1,2,4-噁二唑 | 抗酯酶 |
| $\mathrm{{-}C(O)NH{-}}$（酰胺） | 1,2,3-三唑、*E*-烯烃、氟代烯烃、逆酰胺 | 抗蛋白酶（肽模拟物） |
| 苯环 | 吡啶、噻吩；*对*位二取代环可用双环[1.1.1]戊烷 | 亲脂性更低，溶解度更好，新的伸出方向 |
| $\mathrm{{-}OH}$（酚） | $\mathrm{{-}NHSO_2CH_3}$、吲唑 NH、苯并咪唑酮 | 抗葡萄糖醛酸化，保留供体 |
| $\mathrm{C{-}H}$ | $\mathrm{C{-}D}$ | P450 氧化更慢（动力学同位素效应） |

血管紧张素受体拮抗剂氯沙坦是一个著名的例子：把联苯上的羧酸换成四氮唑，得到的化合物效价约高十倍且可口服。另一例是西咪替丁的历史。$\mathrm{H_2}$ 拮抗剂美替米胺（metiamide）含一个硫脲，在一些患者中引起粒细胞缺乏（白细胞减少），这一效应被归于硫脲。布莱克（James Black）的小组把硫脲的 $\mathrm{C{=}S}$ 换成 $\mathrm{C{=}N{-}CN}$：氰胍与硫脲一样平面、极性、强偶极、弱碱性，所得化合物西咪替丁保住了活性，成为第一批“重磅炸弹”药物之一。

::: warning 生物电子等排体由靶点定义，不由表格定义 {#warn-bioisostere}
生物电子等排体表格是一份“在哪里成功过”的替换清单。它们是思想的来源，不是预测的来源。四氮唑有羧酸的酸性，但更大，电荷摊在四个氮上，而且在任何一个原子上都是更弱的氢键受体；在一个用两个安置精确的精氨酸抓住羧酸根的口袋里，替换可能失去大部分活性。氟“大小与氢相似”，电子上却截然不同：它改变邻近基团的酸性、相邻键的构象（*gauche* 效应）与分子的偶极。每个替换都必须检验，并测量它对活性之外性质的影响。
:::

## 定量构效关系

定性套路一级一级地改变效价。汉施（Corwin Hansch）在 1960 年代初的洞见是：对以同一机理起作用的一系列化合物，这些级的*大小*常常能与取代基的几个理化参数相关联。这类关联是**线性自由能关系**：既然平衡常数（或速率常数）的 $\log$ 正比于自由能，叠加自由能贡献就意味着叠加对数。

### 电子效应：哈梅特方程

::: proposition 哈梅特方程（经验的线性自由能关系） {#prop-hammett}
对一系列*间*位或*对*位取代苯衍生物的反应或平衡，带取代基 X 的化合物的平衡（或速率）常数 $K_\mathrm{X}$ 与未取代化合物的 $K_\mathrm{H}$ 之关系为
$$
\log_{10}\frac{K_\mathrm{X}}{K_\mathrm{H}} = \rho\,\sigma_\mathrm{X},
$$ {#eq-hammett}
其中**取代基常数** $\sigma_\mathrm{X}$ 只依赖 X 及其位置，由水中 $25\ \mathrm{^\circ C}$ 下取代苯甲酸的解离定义（对此 $\rho = 1$），而**反应常数** $\rho$ 只依赖反应与条件。
:::

::: proof 为什么预期线性关系
这个关系是经验的，但它的形式来自两个假设。把化合物 X 的反应自由能变化写为 $\Delta G_\mathrm{X} = -RT\ln K_\mathrm{X}$。假设 (i) 取代基改变反应自由能的量 $\delta\Delta G_\mathrm{X} = \Delta G_\mathrm{X} - \Delta G_\mathrm{H}$ 可分解为取代基的性质（它在反应中心给电子或吸电子的强弱）与反应的性质（反应对那里电子密度的敏感度）之积，$\delta\Delta G_\mathrm{X} = -a_\mathrm{X}b_\mathrm{R}$；并且 (ii) 对一个反应族中的每个反应，用同一组 $a_\mathrm{X}$ 都成立。则 $\log(K_\mathrm{X}/K_\mathrm{H}) = a_\mathrm{X}b_\mathrm{R}/(RT\ln 10)$。选一个参考反应——苯甲酸的解离——并为它定义 $\sigma_\mathrm{X} = \log(K_\mathrm{X}/K_\mathrm{H})$，于是它的 $\rho = 1$；对任何其他反应，$\rho = b_\mathrm{R}/b_\mathrm{ref}$，[[#eq-hammett]] 随之成立。当取代基在远处、不能与反应中心发生立体相互作用时，这些假设成立，这就是*邻*位取代基被排除的原因；当与反应中心的共轭在不同反应之间变化时则失效——这是另有 $\sigma^+$ 与 $\sigma^-$ 两套标度的原因。
:::

正 $\sigma$ 表示吸电子（硝基，$\sigma_p = 0.78$；氰基，0.66；氯，0.23）；负表示给电子（甲基，$\sigma_p = -0.17$；甲氧基，$-0.27$；氨基，$-0.66$）。对酸，$\log(K_\mathrm{X}/K_\mathrm{H}) = \mathrm{p}K_\mathrm{a,H} - \mathrm{p}K_\mathrm{a,X}$，所以 $\mathrm{p}K_\mathrm{a,X} = \mathrm{p}K_\mathrm{a,H} - \rho\sigma_\mathrm{X}$。在药物设计中，σ 预测芳香酸、酚与苯胺的 $\mathrm{p}K_\mathrm{a}$——并进而预测它们的电离与 $\log D$——还描述对结合的电子学贡献。

::: example 预测 pKₐ 值 {#ex-hammett}
苯甲酸在水中 $25\ \mathrm{^\circ C}$ 的 $\mathrm{p}K_\mathrm{a} = 4.20$。用 $\sigma_p(\mathrm{NO_2}) = 0.78$、$\sigma_p(\mathrm{OCH_3}) = -0.27$ 与 $\sigma_m(\mathrm{Cl}) = 0.37$，预测 4-硝基-、4-甲氧基-与 3-氯苯甲酸的 $\mathrm{p}K_\mathrm{a}$。（实测值为 3.44、4.47 与 3.83。）
::: solution
取 $\rho = 1$，$\mathrm{p}K_\mathrm{a,X} = 4.20 - \sigma_\mathrm{X}$：4-硝基，$4.20 - 0.78 = 3.42$；4-甲氧基，$4.20 + 0.27 = 4.47$；3-氯，$4.20 - 0.37 = 3.83$。预期符合到 0.02 以内，因为这些酸*定义*了 σ 值。有意思的地方是甲氧基的符号：氧电负性强，但在*对*位它的孤对通过共轭给入环，压过了它的诱导吸电子，于是酸被削弱。在*间*位，共轭给电子够不到羧基碳，$\sigma_m(\mathrm{OCH_3}) = +0.12$。
:::
:::

### 亲脂性：π 常数

汉施与藤田敏夫（Toshio Fujita）意识到，辛醇-水分配系数以同样的方式呈加和行为。

::: definition 疏水取代基常数 π {#def-pi}
取代基 X 对母体化合物的**疏水取代基常数**为
$$
\pi_\mathrm{X} = \log_{10}P_\mathrm{X} - \log_{10}P_\mathrm{H},
$$ {#eq-pi}
其中 $P$ 是中性化合物的辛醇-水分配系数。数值对苯环上的取代基成表（汉施、利奥与同事）：例如 $\pi(\mathrm{CH_3}) = 0.56$，$\pi(\mathrm{Cl}) = 0.71$，$\pi(\mathrm{Br}) = 0.86$，$\pi(\mathrm{CF_3}) = 0.88$，$\pi(\mathrm{F}) = 0.14$，$\pi(\mathrm{OCH_3}) = -0.02$，$\pi(\mathrm{NO_2}) = -0.28$，$\pi(\mathrm{OH}) = -0.67$，$\pi(\mathrm{NH_2}) = -1.23$。一级近似下 π 值是**加和**的，$\log P \approx \log P_\mathrm{parent} + \sum\pi$，只要取代基之间没有电子或立体的相互作用；这是一种经验规律性，因为 $\log P$ 是转移自由能，而无相互作用基团的自由能增量相加。
:::

::: example 估算 log P {#ex-pi}
苯的 $\log P = 2.13$。估算氯苯、甲苯、4-氯甲苯与苯酚的 $\log P$。（实测：2.84、2.73、3.33、1.46。）
::: solution
氯苯：$2.13 + 0.71 = 2.84$。甲苯：$2.13 + 0.56 = 2.69$。4-氯甲苯：$2.13 + 0.71 + 0.56 = 3.40$。苯酚：$2.13 - 0.67 = 1.46$。单取代的估算精确或近乎精确（它们定义了 π）；二取代化合物高估了 0.07，这是基团间小电子作用的典型误差。计算 $\log P$（“clogP”）的片段法程序把同样的加和性推广到整个分子，并为相互作用的基团设置校正因子。
:::
:::

### 汉施分析

::: proposition 汉施方程与最优亲脂性 {#prop-hansch}
对以同一机理起作用的同系物系列，设 $C$ 为产生固定生物效应的摩尔浓度。汉施的**经验**模型把效价表达为取代基参数的线性自由能关系，
$$
\log_{10}\frac{1}{C} = -a\,\pi^2 + b\,\pi + \rho\,\sigma + c, \qquad a > 0,
$$ {#eq-hansch}
其系数 $a$、$b$、$\rho$ 与 $c$ 由多元线性回归求出。效价在**最优亲脂性**
$$
\pi_0 = \frac{b}{2a}
$$ {#eq-pi0}
处最大（当方程以 $\log P$ 书写时，在 $\log P_0 = b/2a$ 处）。
:::

::: proof
各项都有物理动机。生物试验中的效价既取决于到达部位（穿过水相与脂相的转运——汉施把它建模为随机行走，其成功率先随亲脂性升、后随其降，因为亲脂性太强的化合物被擒在遇到的第一层膜或脂肪里，而亲水性太强的一种也进不去），也取决于结合（部分是疏水的，对 π 线性；部分是电子的，由[[#eq-hammett]]对 σ 线性）。π 的抛物线是带有极大值的最简单函数。对最优值，固定 σ 求导：
$$
\frac{\partial\log(1/C)}{\partial\pi} = -2a\pi + b = 0 \quad\Rightarrow\quad \pi_0 = \frac{b}{2a},
$$
而 $\partial^2/\partial\pi^2 = -2a < 0$ 确认这是极大。因为模型是经验的，最优值的存在是对每个系列有待检验的发现，不是理论的推论；库比尼（Hugo Kubinyi）的双线性模型（1977）先线性升后线性降，常常拟合得更好。
:::

汉施分析给出的不止预测。ρ 的符号与大小说明吸电子基团是否有助于结合；π 系数接近 1 提示取代基完全埋藏在疏水环境；最优 $\log P$ 接近 2 常见于必须穿越血脑屏障的化合物。而且方程指出了系列中最好的化合物位于描述符空间的何处，提示下一个该合成哪个取代基。

::: example 一次汉施拟合 {#ex-hansch}
σ 几乎相同（都是烷基或类烷基）的一系列 4-取代类似物给出以下效价：$(\pi, \log 1/C) = (0, 4.05), (0.5, 4.58), (1.0, 5.02), (1.5, 5.10), (2.0, 5.03), (2.5, 4.60), (3.0, 3.95)$。拟合一条抛物线，求最优 π，并预测 $\pi = 1.98$（叔丁基）与 $\pi = 0.56$（甲基）哪个取代基应更有效价。
::: solution
最小二乘（下面的回归图）给出 $\log(1/C) = -0.502\pi^2 + 1.489\pi + 4.017$。由[[#eq-pi0]]，$\pi_0 = 1.489/(2 \times 0.502) = 1.48$。预测效价：叔丁基，$-0.502(1.98)^2 + 1.489(1.98) + 4.017 = 4.99$；甲基，$-0.502(0.56)^2 + 1.489(0.56) + 4.017 = 4.69$。叔丁基化合物应约高效价一倍（$10^{0.30}$）。最优位于乙基或异丙基附近（$\pi \approx 1.0$–$1.5$）；预测继续往正丁基或更大延伸会失去活性。这一预测假设体积大的叔丁基没有 π 不描述的立体冲突——若有，应加入立体参数（塔夫特（Taft）的 $E_\mathrm{s}$ 或体积）。
:::
:::

### Free–Wilson 分析

弗里（Spencer Free）与威尔逊（James Wilson）（1964）提出了一个完全不需要理化参数的模型：每个位置的每个取代基对 $\log(1/C)$ 贡献一个固定增量，
$$
\log\frac{1}{C} = \mu + \sum_{i}\sum_{j} a_{ij}x_{ij},
$$ {#eq-freewilson}
其中 $x_{ij} = 1$ 表示位置 $i$ 上存在取代基 $j$，否则为 0；$a_{ij}$ 是其贡献，$\mu$ 是母体的活性。贡献由化合物矩阵上的回归拟合。Free–Wilson 分析可预测数据集中已见过的取代基的未测组合；它不能预测新取代基，并且在取代基相互作用（非加和性）时失效，而这本身就有诊断意义——例如提示结合方式改变。

::: example 检验加和性 {#ex-freewilson}
某母体化合物（1、2 位为 H）的 $\mathrm{pIC_{50}} = 5.0$。位置 1 取 Cl、CH₃ 或 H，位置 2 取 OCH₃ 或 H，实测值为：(Cl, H) 5.8；(CH₃, H) 5.4；(H, OCH₃) 5.5；(Cl, OCH₃) 6.2；(CH₃, OCH₃) 6.9。由单取代化合物求 Free–Wilson 贡献，预测两个双取代化合物，并在 $298\ \mathrm{K}$ 下解释任何出入。
::: solution
母体 $\mu = 5.0$，单取代化合物直接给出增量：$a_{1,\mathrm{Cl}} = 5.8 - 5.0 = 0.8$，$a_{1,\mathrm{CH_3}} = 0.4$，$a_{2,\mathrm{OCH_3}} = 0.5$。（化合物多于未知数时应以最小二乘拟合。）加和性预测 (Cl, OCH₃) $= 5.0 + 0.8 + 0.5 = 6.3$，(CH₃, OCH₃) $= 5.0 + 0.4 + 0.5 = 5.9$。前者在典型测定误差（±0.1–0.2 log 单位）内与实测 6.2 一致。后者被低估 1.0 log 单位：这一对的实际效价是加和预测的十倍，多出 $5.71 \times 1.0 = 5.7\ \mathrm{kJ\,mol^{-1}}$ 的结合自由能。这种**非加和性**说明两个取代基不是独立起作用的——也许甲基与甲氧基一起迫使的扭转预组织了结合构象，或这个组合把分子带入了另一种结合方式。这是去拿一个晶体结构的信号，不是拿来平均掉的噪声。
:::
:::

汉施分析与 Free–Wilson 分析互补。汉施方程在描述符空间内插值与外推，所以能建议从未合成过的取代基，但它需要能抓住相关物理的描述符；Free–Wilson 模型不需要描述符，但只是重新分配已见过的信息。混合模型——在汉施方程上加 Free–Wilson 指示变量——用于某个位置呈加和而另一个位置不呈加和的场合。

## 建立并信任 QSAR 模型

现代定量构效关系早已超出 σ 与 π。描述符包括计算 $\log P$、极性表面积、摩尔折射度（体积与极化率的度量）、供体与受体的计数、拓扑指数；而在**3D-QSAR**方法（如比较分子场分析（CoMFA；克拉默（Richard Cramer）与同事，1988））中，还有对齐分子与探针原子在上千个格点上的立体与静电相互作用能。机器学习模型——随机森林、支持向量机、图神经网络——把活性拟合到数百乃至数千个这样的描述符。模型越灵活，拟合噪声的危险就越大。

::: definition 拟合优度与交叉验证预测力 {#def-q2}
对 $n$ 个化合物，实测活性 $y_i$、均值 $\bar y$ 与拟合值 $\hat y_i$，**决定系数**为
$$
r^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}.
$$
**交叉验证**的 $q^2$ 把每个拟合值换成*不*含化合物 $i$ 重拟合（留一法）或不含一批化合物重拟合的模型的预测 $\hat y_{(i)}$：
$$
q^2 = 1 - \frac{\mathrm{PRESS}}{\sum_i (y_i - \bar y)^2}, \qquad \mathrm{PRESS} = \sum_i \bigl(y_i - \hat y_{(i)}\bigr)^2 .
$$ {#eq-q2}
$r^2$ 度量模型对建它所用法数据的描述程度；$q^2$ 估计它对未见数据的预测能力。由于每个被留出点的预测平均而言至少和拟合值一样差，实践中 $q^2 \le r^2$。
:::

一个 $r^2 = 0.95$ 而 $q^2 = 0.2$ 的模型只是记住了它的训练集。由此得出几条全部**经验**的实用规则：每个被拟合描述符至少用五个化合物（托普利斯（John Topliss）与科斯特洛（Robert Costello），1972：比值更低时，随机数对随机描述符的回归也会给出漂亮的 $r^2$）；最终的模型要用一个对它做出一无所知的同类外部集合来检验，这些化合物最好是时间上后来才合成的；还要记住模型的准确度不可能超过测定的准确度（通常 ±0.2–0.3 log 单位），所以任何低于它的均方根误差都可疑。QSAR 模型还有**适用域**：它只对与训练化合物相似的化合物做预测。

::: example 拟合还是预测？ {#ex-q2}
20 个化合物的五描述符模型残差平方和 $\sum(y_i - \hat y_i)^2 = 0.90$；对均值的总平方和 $\sum(y_i - \bar y)^2 = 9.0$（log 单位的平方）；留一法交叉验证给出 $\mathrm{PRESS} = 4.5$。计算 $r^2$ 与 $q^2$，并就每个描述符的化合物数加评论。
::: solution
$r^2 = 1 - 0.90/9.0 = 0.90$；由[[#eq-q2]]，$q^2 = 1 - 4.5/9.0 = 0.50$。差距很大：模型解释了它被拟合所用的 90 % 的方差，却只解释未见化合物一半的方差。20 个化合物、5 个描述符，比值为 4，低于 5 的指导线，所以应当删减描述符集——一个只有两三个描述符、$q^2$ 接近其 $r^2$ 的模型会更可信赖。均方根预测误差 $\sqrt{4.5/20} = 0.47$ log 单位，约合效价的三倍。
:::
:::

### 设计下一个化合物：托普利斯树

药物化学家在手里只有十几个化合物时很少去拟合完整的 QSAR 模型。托普利斯 1972 年提出一个操作方案，一次一个化合物地运用汉施分析的逻辑，针对苯环上的取代基。

::: algorithm 芳香取代基的托普利斯决策树（节选） {#algo-topliss}
从未取代的苯基化合物（H）出发：
1. 合成 **4-氯**类似物（π 与 σ 皆正）。把它与母体的效价比较：更高（M）、相同（E）或更低（L）。
2. 若为 **M**，亲脂性与吸电子之一或两者有助：合成 **3,4-二氯**（两者都进一步增大）。若它又更好，朝更大的 π + σ（例如 3-CF₃-4-Cl）继续；若更差，则最优已超过或达到立体极限。
3. 若为 **E**，π 与 σ 的收益可能在相互抵消（例如负的 ρ 被正的 π 系数抵住）：合成 **4-甲基**（π 正，σ 负）。
4. 若为 **L**，要么吸电子有害，要么 4 位有立体问题：合成 **4-甲氧基**（π ≈ 0，σ 负）；若仍更差，就探索 3-位。
5. 每个分叉处，下一个取代基都应选最能区分关于 π 与 σ 系数符号的剩余假设的那个。
:::

这个方案之所以管用，是因为每次比较都是对[[#eq-hansch]]中符号的粗略测量；它的威力在于用几次合成而非一个完整矩阵就能到达一个好的取代基。它的局限与汉施分析相同：它假定化合物以同一种方式结合，而一次立体冲突或一处新相互作用就会推翻它。

## 优化整个分子

效价只是先导必须获得的性质之一。一个药物还必须选得准、可溶解、可渗透、代谢稳定、无 hERG 通道阻滞（[[medicinal-chemistry/drug-targets]]）之类的毒性隐患，而且造得出来。**多参数优化**把它们放在一起处理，而实践中的大量 SAR 就是寻找修复一个性质而不破坏其他性质的改变。标志性套路是：

- **阻断代谢。** 被细胞色素P450（[[medicinal-chemistry/pharmacokinetics]]）氧化的*对*位用氟封顶；苄基甲基换成 CF₃ 或删去；富电子环换成缺电子杂环。
- **降低亲脂性。** $\log P$ 每降一个单位，溶解度通常改善、清除率与脱靶结合通常降低。芳环中 CH 换 N、在指向溶剂一侧加极性基团、给环加氢都是典型手法。目标是提高 LLE（[[medicinal-chemistry/hits-and-leads#def-le]]），提高单位亲脂性换来的效价。
- **调节 p*K*ₐ。** 胺附近的氟降低其 p*K*ₐ（每个 β-氟约 1–2 个单位），降低 pH 7.4 下质子化的分数，这可以改善渗透性或减少对亲脂性碱易犯的 hERG 结合。
- **溶剂暴露的手柄。** 配体指向结合位点之外、伸入溶剂的部分可以自由改动，以调节溶解度与药代动力学；伊马替尼这类激酶抑制剂在那里带着一个增溶的哌嗪（[[medicinal-chemistry/drug-case-studies]]）。
- **前药。** 活性形式无法吸收时——通常因为太 polar——用可裂解基团把极性基团掩蔽：依那普利（二元酸依那普利拉的乙酯）是经典案例。

::: example 氟与碱性 {#ex-fluorine}
某先导含哌啶氮，$\mathrm{p}K_\mathrm{a} = 9.8$。在氮的 β 位引入一个氟把 $\mathrm{p}K_\mathrm{a}$ 降到 8.2（常用范围内的一个示意位移）。计算前后化合物在 pH 7.4 下未电离的分数，以及若中性碱的 $\log P$ 不变时 $\log D_{7.4}$ 的改变。
::: solution
对碱，未电离分数为 $f = 1/(1 + 10^{\mathrm{p}K_\mathrm{a} - \mathrm{pH}})$（[[medicinal-chemistry/pharmacokinetics#eq-logd-base]]）。改造前：$f = 1/(1 + 10^{2.4}) = 1/252.2 = 3.97\times10^{-3}$。改造后：$f = 1/(1 + 10^{0.8}) = 1/7.31 = 0.137$。由于 $\log D = \log P + \log f$，$\log D$ 上升 $\log(0.137/3.97\times10^{-3}) = 1.54$ 个单位。穿越膜的中性分数约增加 35 倍。实践中氟还会轻微改变 $\log P$ 并可能改变构象，所以它对渗透性与结合的影响必须实测——而且如果质子化的胺对靶点形成盐桥，效价可能下降。
:::
:::

::: quiz
一个 Free–Wilson 模型已对 30 个类似物拟合，它们含 H、F、Cl 或 CH₃ 于 3 位，H 或 OH 于 5 位。它能正当做到下列哪些？
- [x] 预测 3 位 Cl、5 位 OH 的未测类似物的活性。
- [ ] 预测 3-溴类似物的活性。
- [ ] 预测中心环从苯改为吡啶的化合物的活性。
- [ ] 证明 3-取代基与疏水口袋相互作用。
::: solution
Free–Wilson 增量只对训练集中的取代基与位置存在，所以模型能预测已知取代基的新*组合*（如果加和），但不能预测新取代基（溴），更不能预测新骨架。它的增量是相关性，不是结构证据：疏水性的解读需要汉施式的分析、一个结构或进一步实验。
:::
:::

## 后续内容

SAR 告诉我们什么要紧；蛋白质结构告诉我们为什么。[[medicinal-chemistry/structure-based-design]]用晶体结构、对接与自由能计算把本章的套路从经验变成深思熟虑；[[medicinal-chemistry/drug-case-studies]]沿着产生 β-内酰胺类、ACE 抑制药、他汀与激酶抑制剂的 SAR 战役追踪。这里讨论的性质改变的药代动力学后果见[[medicinal-chemistry/pharmacokinetics]]。多元线性回归与交叉验证在 Maths Atlas（`/learn/maths/`）中有处理，σ 背后的物理有机化学见[[organic-2/aromatic-substitution]]。

::: summary
- 构效关系靠一次去掉或掩蔽一个基团来发现，并把变化读成自由能（$298\ \mathrm{K}$ 下每十倍 $5.7\ \mathrm{kJ\,mol^{-1}}$）；必要特征及其三维排布构成药效团。
- 骨架改变——同系化、换环、延伸与构象限制——调效价；“魔术甲基”这类活性悬崖通常是构象性的。
- 生物电子等排体（四氮唑换羧酸、F 换 H、杂环换苯）在保住活性的同时改变其他性质；替换是否奏效是每个靶点的经验发现。
- 哈梅特方程 $\log(K_\mathrm{X}/K_\mathrm{H}) = \rho\sigma$ 与加和常数 $\pi = \log P_\mathrm{X} - \log P_\mathrm{H}$ 是经验的线性自由能关系。
- 汉施分析 $\log(1/C) = -a\pi^2 + b\pi + \rho\sigma + c$ 把效价与亲脂性和电子效应关联，给出最优 $\pi_0 = b/2a$；Free–Wilson 分析拟合加和的取代基增量，非加和性预示结合方式的改变。
- QSAR 模型以交叉验证 $q^2$ 与外部预测评判，而不是 $r^2$；每个化合物少用描述符，并留在适用域内。
- 先导优化是多参数的：阻断代谢、降低亲脂性、调节 p*K*ₐ 与使用前药，与效价同等要紧。
:::

从某酶抑制剂上删去一个羟基使 $K_\mathrm{I}$ 增大三十倍。计算 $298\ \mathrm{K}$ 下结合自由能的损失。（$\Delta\Delta G$ 以 $\mathrm{kJ\,mol^{-1}}$ 输入，保留两位有效数字。）

::: exercise 一次哈梅特预测 {level=1 check="3.97"}
用 $\sigma_p(\mathrm{Cl}) = 0.23$ 与苯甲酸的 $\mathrm{p}K_\mathrm{a} = 4.20$，预测 4-氯苯甲酸在水中 $25\ \mathrm{^\circ C}$ 的 $\mathrm{p}K_\mathrm{a}$。（输入 $\mathrm{p}K_\mathrm{a}$。）
::: solution
取 $\rho = 1$，$\mathrm{p}K_\mathrm{a} = 4.20 - 0.23 = 3.97$（实测 3.98）。氯的诱导吸电子强于其共轭给电子，稳定羧酸根。
:::

::: exercise 加和的亲脂性 {level=1 check="3.55"}
苯的 $\log P = 2.13$。用 $\pi(\mathrm{Cl}) = 0.71$ 估算 1,4-二氯苯的 $\log P$，并与实测值 3.44 比较。（输入估算的 $\log P$。）
::: solution
$\log P \approx 2.13 + 2 \times 0.71 = 3.55$，高估 0.11。两个氯都从环上吸电子，所以每个在有对方在场时都比独自存在时略微不那么亲脂——一种小的相互作用项，正是片段法 clogP 方法所要校正的那一类。
:::

::: exercise 交叉验证 {level=1 check="0.7"}
某 QSAR 模型的总平方和为 $4.0$，留一法 $\mathrm{PRESS} = 1.2$（log 单位的平方）。计算 $q^2$。（$q^2$ 保留一位有效数字。）
::: solution
由[[#eq-q2]]，$q^2 = 1 - 1.2/4.0 = 0.70$。一般认为高于约 0.5 的值表明模型具有真正的预测能力，但须经外部测试集证实。
:::

::: exercise 酚的哈梅特 {level=2 check="9.16"}
酚在水中的解离在 $25\ \mathrm{^\circ C}$ 下 $\rho = 2.23$，苯酚的 $\mathrm{p}K_\mathrm{a} = 9.99$。预测 3-氯苯酚（$\sigma_m = 0.37$）的 $\mathrm{p}K_\mathrm{a}$。解释为什么 ρ 比苯甲酸的大。（$\mathrm{p}K_\mathrm{a}$ 输入到小数点后两位。）
::: solution
$\mathrm{p}K_\mathrm{a} = 9.99 - 2.23 \times 0.37 = 9.99 - 0.825 = 9.16$（实测 9.12）。苯氧负离子的负电荷在直接连于环的氧上，并部分离域入环，所以环上取代基强烈影响其稳定性；苯甲酸根中电荷坐在羧酸根上，被羧基碳与环隔开，反应因而没那么灵敏。对能以共轭接受苯氧负离子电荷的*对*位取代基（NO₂、CN），必须改用增强常数 $\sigma^-$。
:::

::: exercise 一次 Free–Wilson 预测 {level=2 check="6.9"}
某系列母体 $\mathrm{pIC_{50}} = 6.0$，4-氟类似物 $\mathrm{pIC_{50}} = 6.3$，*N*-甲基类似物 6.6。假设加和，预测 4-氟-*N*-甲基化合物的 $\mathrm{pIC_{50}}$，并说明若实测值为 5.6 你会得出什么结论。（输入预测的 $\mathrm{pIC_{50}}$。）
::: solution
$\mathrm{pIC_{50}} = 6.0 + 0.3 + 0.6 = 6.9$。实测 5.6 将比预测低 1.3 log 单位（20 倍），一个强负相互作用：两个改变不能同时做而不破坏彼此的收益——比如因为 *N*-甲基化改变构象，使氟化的环不再落在原来的位置。这一对将成为结构研究的优先对象。
:::

::: exercise 用汉施方程选取代基 {level=2 check="5.23"}
某系列 4-取代类似物的 $\log(1/C) = -0.20\pi^2 + 0.88\pi + 0.95\sigma + 4.10$。用数值（π，σ_p）：CH₃（0.56，−0.17）、Cl（0.71，0.23）、Br（0.86，0.23）、CF₃（0.88，0.54）、OCH₃（−0.02，−0.27）、NO₂（−0.28，0.78），求预测效价最高的取代基与固定 σ 时的最优 π。（输入最佳取代基预测的 $\log(1/C)$。）
::: solution
代入：H，4.10；CH₃，$-0.20(0.314) + 0.493 - 0.162 + 4.10 = 4.37$；Cl，4.84；Br，4.93；CF₃，$-0.20(0.774) + 0.774 + 0.513 + 4.10 = 5.23$；OCH₃，3.83；NO₂，4.58。CF₃ 最佳，因为它把大的 π 与强吸电子结合起来（ρ 为正）。固定 σ 的最优值为 $\pi_0 = 0.88/(2 \times 0.20) = 2.2$，远超任何单个小的取代基，所以双取代（比如 3-CF₃-4-Cl）值得一探——尽管此方程忽略的立体效应可能插话。
:::

::: exercise 为柔性买单 {level=3 check="26"}
一个柔性先导以 $K_\mathrm{d} = 1.0\ \mu\mathrm{mol\,dm^{-3}}$ 结合。一个成环类似物把三根可旋转键恰好在结合构象上冻结，无应变、不改变任何接触。(a) 取示意值：每根在结合时被冻结的可旋转键的熵代价 $3.0\ \mathrm{kJ\,mol^{-1}}$，估算成环类似物在 $298\ \mathrm{K}$ 的 $K_\mathrm{d}$。(b) 解释为什么实际收益通常更小，以及成环导致活性大量*损失*会告诉你什么。（$K_\mathrm{d}$ 以 $\mathrm{nmol\,dm^{-3}}$ 输入，保留两位有效数字。）
::: hint
成环类似物免于支付 $3 \times 3.0\ \mathrm{kJ\,mol^{-1}}$；用 $\exp(\Delta\Delta G/RT)$ 把这份自由能增益换算成倍数。
:::
::: solution
(a) 增益为 $\Delta\Delta G = 9.0\ \mathrm{kJ\,mol^{-1}}$，即 $\exp(9000/(8.314 \times 298.15)) = \exp(3.63) = 37.7$ 倍。于是 $K_\mathrm{d} = 1000\ \mathrm{nmol\,dm^{-3}}/37.7 = 26\ \mathrm{nmol\,dm^{-3}}$。

(b) 这个估算假定自由配体的转子本来完全自由，而且新的环不增添应变、新的立体接触或去溶剂化改变；实践中环会引入小应变，柔性配体本就一定程度上占据结合构象，而每个键的熵代价本身就 vary（估计范围约 1 到 4 $\mathrm{kJ\,mol^{-1}}$）。3–10 倍的收益很常见；40 倍是乐观的。大的损失——比如说 100 倍——意味着环把分子锁在了活性构象之外的构象上，这本身是有价值的信息：一组刚性类似物可以描出活性构象。
:::

::: exercise 从第一性原理做汉施 {level=3}
(a) 证明：若取代基对结合自由能的贡献正比于它从水到辛醇的转移自由能，$\delta\Delta_\mathrm{b}G = \beta\,\delta\Delta_\mathrm{tr}G$，则 $\log(1/C)$ 对 π 线性，斜率为 β。(b) 证明加上 $-a\pi^2$ 项会产生最优值，并对 $a = 0.30$、$b = 1.2$ 求最优 π 与相对母体的最大效价增益。(c) 解释为什么最优 $\log P$ 可能出现在细胞或整体动物测定中，却不会出现在纯化蛋白的结合测定中。
::: hint
$\pi = \log P_\mathrm{X} - \log P_\mathrm{H} = -\delta\Delta_\mathrm{tr}G/(RT\ln 10)$，其中 $\Delta_\mathrm{tr}G$ 是从水到辛醇的转移自由能。
:::
::: solution
(a) $\log P = -\Delta_\mathrm{tr}G/(RT\ln 10)$，所以 $\pi_\mathrm{X} = -\delta\Delta_\mathrm{tr}G_\mathrm{X}/(RT\ln 10)$。若有效浓度 $C$ 是使固定分数靶点被占据的浓度，则 $C \propto K_\mathrm{d}$ 且 $\log(1/C) = -\Delta_\mathrm{b}G/(RT\ln 10) + \text{const}$。于是 $\log(1/C_\mathrm{X}) - \log(1/C_\mathrm{H}) = -\beta\,\delta\Delta_\mathrm{tr}G/(RT\ln 10) = \beta\pi_\mathrm{X}$：对 π 线性，斜率 β。斜率为 1 意味着取代基在结合位点中被去溶剂化得像在辛醇中一样彻底。

(b) $\log(1/C) = -a\pi^2 + b\pi + c$ 的导数为 $-2a\pi + b$，在 $\pi_0 = b/2a = 1.2/0.60 = 2.0$ 处为零；二阶导数 $-2a$ 为负，所以这是极大。相对母体（$\pi = 0$）的增益为 $-a\pi_0^2 + b\pi_0 = b^2/4a = 1.44/1.20 = 1.2$ log 单位，即 16 倍。

(c) 在纯化蛋白测定中，配体自由地处在已知浓度的缓冲液里，与疏水位点的结合随亲脂性一直改善，直到溶解度失败。在细胞或动物中，化合物必须分配穿过水相与脂相区室：亲脂性太强的化合物结合膜、血浆蛋白与脂肪，代谢更快、溶解度更低，于是靶点处的自由浓度下降。抛物线描述的就是这种转运与分布，这就是汉施的最优 $\log P$ 值在简单体系中最大、在整体生物体中最小的原因。
:::
