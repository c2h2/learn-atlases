假设靶点已经选定并验证（[[medicinal-chemistry/drug-targets]]）。现在必须有人找到一个能结合它的分子。干草堆有多大？对类药有机分子数目——稳定、由 C、H、N、O、S 与卤素构成、至多约 30 个重原子——的估计达到 $10^{60}$ 量级（博哈切克（Regine Bohacek）与同事，1996）。最大的实体筛选化合物库容纳几百万个化合物，而化学家如今可以检索的“按需合成”虚拟目录也不过约 $10^{10}$。化学家与其说是在搜寻化学空间，不如说是在仔细采样其中选定的微小角落。最初的活性分子——**苗头化合物**（hits）——从哪里来？我们怎么知道它们是真的？又该如何决定哪些苗头值得投入把苗头变成**先导化合物**（lead）、最终变成候选药物的多年工作？

本章沿几条主要路线展开：自然自己的分子、**高通量筛选**（HTS）对大型化合物库的系统测试（连同判断一个测定能否信赖的统计），从极小、结合很弱的分子出发的**基于片段**的方法，以及计算与 DNA 编码的方法。沿途我们定义让化学家比较大小不同的分子、避免一味把化合物做得更大更油的指标——**配体效率**与**亲脂性配体效率**。通篇使用的结合自由能标度来自[[medicinal-chemistry/drug-binding]]。

## 苗头化合物从哪里来

::: definition 苗头化合物、先导化合物与候选药物 {#def-hit}
**苗头化合物**是这样的化合物：其对靶点在初试中的活性经复测证实，具有浓度-效应曲线，并有证据表明它作用于靶点而非测定方法本身。**先导化合物**是这样的苗头（或一组相关苗头）：其效价、选择性、理化性质与合成可及性使它值得优化，且有构效关系表明它可以被改进。**候选药物**是被选中进入临床前开发的一个优化过的化合物（[[medicinal-chemistry/drug-development]]）。这些定义是制药工业的工作惯例；具体界限（比如苗头要求微摩尔效价、先导要求亚微摩尔）因机构与靶点而异。
:::

### 天然产物

在历史的大部分时间里，药物就是天然产物，而天然产物至今仍是先导的丰饶来源。演化已经筛选过它们结合生物大分子的能力：它们往往富含立体中心与环，缺少平面芳香体系，占据着合成化合物库很少造访的化学空间区域。纽曼（David Newman）与克拉格（Gordon Cragg）对 1981 至 2019 年间批准的一切新药的分析发现，小分子药物中很大一部分——四分之一到二分之一，取决于是否把仿天然产物设计的合成分子计入——是天然产物、其半合成衍生物或其模拟物。

例子都是有名的。青霉素来自霉菌（弗莱明（Alexander Fleming），1928）；他汀类来自真菌代谢物（[[medicinal-chemistry/drug-case-studies]]）。抗疟的内过氧化物倍半萜内酯青蒿素，由屠呦呦（Tu Youyou）的组于 1972 年从 *Artemisia annua*（黄花蒿）中分离，其思路源于一部描述该植物冷水浸取的四世纪中国古籍；她分享了 2015 年诺贝尔生理学或医学奖。紫杉醇（paclitaxel，Taxol）取自太平洋红豆杉的树皮，能稳定微管；其结构由沃尔（Monroe Wall）与瓦尼（Mansukh Wani）于 1971 年报道。来自土壤真菌的免疫抑制剂环孢素使器官移植成为常规。天然产物的难处在于供应与合成：许多化合物在不能人工养殖的生物体内产量极微，复杂的结构又使类似物的合成很难——紫杉醇如今由欧洲红豆杉针叶中的前体半合成，或以植物细胞发酵生产。

### 从已知出发

许多项目从靶点的天然配体或已有药物出发。布莱克（James Black）与加勒林（Robin Ganellin）在 Smith Kline & French 的 $\mathrm{H_2}$ 拮抗剂项目就从组胺本身出发：对咪唑环与侧链的系统改造，经布立米胺与美他米胺，走到西咪替丁（1976 年上市）——第一个通过受体机制抑制胃酸分泌的药物。韦缪特（Camille Wermuth）把从旧药的*副作用*出发的相关策略命名为“副作用活性的选择性优化”（SOSA）：副作用变成主作用，而起点分子已被知晓安全且类药。西地那非本为心绞痛研发，却意外被发现对勃起功能有明显作用，这一副作用最终成为适应证，是人所共知的例子。

### 表型筛选

也可以不对着纯化的靶点测试化合物，而在细胞或生物体上测试，寻找期望的**表型**改变——细菌被杀死、癌细胞系停止分裂、胞内某种蛋白重新分布。靶点事后再鉴定（如果能鉴定出来的话）。斯威尼（David Swinney）与安东尼（Jason Anthony）2011 年发现，在 FDA 1999 至 2008 年间批准的首创新药中，出自表型筛选的多于出自以靶点为基础的方法。表型筛选能找到谁也没有预料到的机理；其代价是难以知道化合物*为什么*有效。

## 高通量筛选

**高通量筛选**（HTS）以微型化测定逐个测试典型规模 $10^5$–$10^6$ 个化合物的库，每个化合物只用一个浓度（常为 $10\ \mu\mathrm{mol\,dm^{-3}}$），在 384 或 1536 孔板中进行，由机器人操作。读出信号——荧光、发光、吸光度、放射性计数——与阳性对照（完全抑制）和阴性对照（不加化合物）比较。整个筛选战役能否成功，全看测定能否在板间漂移、加样误差与一百万次虚报机会存在的情况下，可靠地把活性化合物与非活性化合物分开。

::: proposition Z′ 因子 {#prop-zprime}
设某测定的阳性与阴性对照给出均值为 $\mu_\mathrm{p}$、$\mu_\mathrm{n}$，标准差为 $\sigma_\mathrm{p}$、$\sigma_\mathrm{n}$ 的信号。把**分离带**定义为两个对照均值各向内三个标准差处的点之间的间隙：$\lvert\mu_\mathrm{p} - \mu_\mathrm{n}\rvert - 3(\sigma_\mathrm{p} + \sigma_\mathrm{n})$。**Z′ 因子**是分离带占动态范围 $\lvert\mu_\mathrm{p} - \mu_\mathrm{n}\rvert$ 的分数：
$$
Z' = 1 - \frac{3(\sigma_\mathrm{p} + \sigma_\mathrm{n})}{\lvert\mu_\mathrm{p} - \mu_\mathrm{n}\rvert}.
$$ {#eq-zprime}
若信号服从正态分布，$Z' > 0$ 表示两个对照的 $\pm 3\sigma$ 带互不重叠，于是每个对照群体中越出自己那一带、越朝对方一侧的分数不足约 0.14 %。按惯例（Zhang、Chung 与 Oldenburg，1999），$Z' \geq 0.5$ 的测定被认为适合筛选、堪称优秀；$Z' = 1$ 是没有噪声的理想测定。
:::

::: proof
对正态分布，超出均值 $3\sigma$ 以上的值占分数 $\tfrac12\operatorname{erfc}(3/\sqrt 2) = 0.00135$，以下同。于是阳性对照带（设 $\mu_\mathrm{p} > \mu_\mathrm{n}$）止于 $\mu_\mathrm{p} - 3\sigma_\mathrm{p}$，阴性对照带止于 $\mu_\mathrm{n} + 3\sigma_\mathrm{n}$；两带相隔 $(\mu_\mathrm{p} - \mu_\mathrm{n}) - 3(\sigma_\mathrm{p} + \sigma_\mathrm{n})$ 宽，而这个宽度为正时两带恰好不相交。除以动态范围即得[[#eq-zprime]]，它在同一条件下为正。这个标度使该统计量与信号的单位无关，从而可以比较不同种类的测定；常数 3 是约定，不是由筛选规模导出的。
:::

::: example 测定合格吗？ {#ex-zprime}
一个荧光测定中，未抑制（阴性对照）孔平均给 100 单位，$\sigma = 5$；完全抑制（阳性对照）孔平均给 10，$\sigma = 4$。求 $Z'$。一个测试化合物给 70 单位，相当于百分之多少的抑制？
::: solution
由[[#eq-zprime]]，$Z' = 1 - 3(5 + 4)/(100 - 10) = 1 - 27/90 = 0.70$：一个优秀的测定。抑制百分数在两个对照之间的标尺上度量：$100 \times (100 - 70)/(100 - 10) = 33\ \%$。阴性对照的噪声占动态范围的 $5/90 = 5.6\ \%$，所以 33 % 处的单孔距未抑制均值约六个标准差，应判为活性——但仍须复测。
:::
:::

### 假阳性：统计学与化学

筛选一百万个化合物就是一百万次统计检验。若信号偏离阴性对照均值三个标准分以上即判为活性，那么有分数 0.00135 的*非活性*化合物单凭偶然就会越过阈值。

::: widget distribution

b: 6
caption: 零假设为化合物没有效应时测定信号的分布（以距非活性化合物均值的标准差计）。$3\sigma$ 之外的阴影尾部概率为 $0.00135$；在一场 $10^6$ 个非活性化合物的筛选中，它包含其中约 1350 个。把阈值 $a$ 移到 4，尾部降到 $3\times10^{-5}$（约 32 个化合物）——代价是漏掉真正的弱活性化合物。
:::

::: example 有多少“苗头”是真的？ {#ex-ppv}
一个 $10^{6}$ 个化合物的库含 100 个真正的活性化合物，在 $3\sigma$ 阈值下每一个被该测定检出的概率为 0.90。越过阈值的化合物中，有多大分数是真活性化合物？
::: solution
真阳性：$100 \times 0.90 = 90$。假阳性：$(10^6 - 100) \times 0.00135 = 1350$。阳性预测值为 $90/(90 + 1350) = 0.063$：初筛苗头中只有约 6 % 是真的。这就是贝叶斯定理在起作用：当真活性化合物稀少时，即使是出色的测定也主要产出虚报。复设双份有帮助——两次独立的偶然越界比一次罕见得多——而每个苗头随后都必须由完整的浓度-效应曲线和一个采用不同读出信号的独立测定加以确证。
:::
:::

偶然只是假阳性来源之一；化学还供应更多。有些化合物本身发光或猝灭荧光；有些是氧化还原循环体，在还原性缓冲液中产生过氧化氢；有些是活泼亲电体，能修饰任何蛋白质；有些络合金属离子。贝尔（Jonathan Baell）与霍洛韦（Georgina Holloway）在 2010 年把这些反复出现的元凶编目为 **PAINS**（泛测定干扰化合物，pan-assay interference compounds）——绕丹宁、醌、邻苯二酚与某些烯酮等在其中。肖凯特（Brian Shoichet）的组在 2002 年证明，许多筛选苗头是**聚集体**：在微摩尔浓度下它们形成胶体颗粒，捕获并使酶部分变性，给出的抑制是非特异的、极陡的，加一点非离子去污剂即被消除。聚集如此常见，以致含去污剂的对照复测已成标准操作。

### 苗头化合物的确证

一个确证了的苗头有浓度-效应曲线，通常用四参数 logistic 函数拟合
$$
y = y_\mathrm{min} + \frac{y_\mathrm{max} - y_\mathrm{min}}{1 + ([\mathrm{I}]/\mathrm{IC_{50}})^{n_\mathrm{H}}},
$$ {#eq-logistic}
这是一个经验形式，简单 1 : 1 抑制剂的希尔系数 $n_\mathrm{H}$ 接近 1。比这陡得多的曲线（$n_\mathrm{H} \geq 2$）是警号——可能来自聚集、共价或紧密结合行为，或者蛋白质变性。

::: widget plot
f: 100/(1 + 10^(n*(x - p))); 100/(1 + 10^(x - p))
x: -9, -3
y: 0, 105
sliders: p=-6:-8:-4:0.1; n=1:0.5:4:0.1
labels: \text{Hill 斜率 } n; \text{参照，斜率 } 1
hlines: 50
caption: 剩余酶活性的百分数对 $x = \log_{10}([\mathrm{I}]/\mathrm{mol\,dm^{-3}})$ 作图，出自[[#eq-logistic]]，$\log_{10}\mathrm{IC_{50}} = p$。行为良好的 1 : 1 抑制剂（$n = 1$）从 90 % 活性降到 10 % 需要 81 倍的浓度范围。把 $n$ 升到 3，同样的变化只发生在约 4 倍的范围内——这是聚集体的典型“悬崖”：在临界聚集浓度之下它不抑制，之上则几乎完全抑制。
:::

除曲线之外，苗头还须用直接观测结合的**生物物理**方法确证：表面等离子体共振（动理学，[[medicinal-chemistry/drug-binding]]）、等温滴定量热法、配体观测或蛋白质观测 NMR、热迁移试验，以及最重要的——复合物的晶体结构。化合物要重新合成或重新购买，用 LC–MS 与 NMR 核查其身份与纯度，因为出人意料的多数筛选“苗头”原来只是杂质或分解产物。

## 度量品质：配体效率

苗头大小不同，而大小能买来亲和力：其他条件相同时，分子越大，接触越多。单以效价比较一个 15 个重原子的 $10\ \mu\mathrm{mol\,dm^{-3}}$ 苗头与一个 40 个重原子的 $100\ \mathrm{nmol\,dm^{-3}}$ 苗头，会选后者——而它可能恰是更差的起点，因为优化几乎总是加原子，而药物应留在[[medicinal-chemistry/pharmacokinetics#def-ro5]]的性质限度之内。

::: definition 配体效率与亲脂性配体效率 {#def-le}
$N_\mathrm{HA}$ 个非氢（“重”）原子的化合物的**配体效率**是每重原子的结合自由能（霍普金斯（Andrew Hopkins）、格鲁姆（Colin Groom）与亚历克斯（Alexander Alex），2004）：
$$
\mathrm{LE} = \frac{-\Delta_\mathrm{b}G^\circ}{N_\mathrm{HA}} = \frac{RT\ln 10\;\mathrm{p}K_\mathrm{d}}{N_\mathrm{HA}} \approx \frac{1.36\,\mathrm{p}K_\mathrm{d}}{N_\mathrm{HA}}\ \mathrm{kcal\,mol^{-1}} = \frac{5.71\,\mathrm{p}K_\mathrm{d}}{N_\mathrm{HA}}\ \mathrm{kJ\,mol^{-1}}\ \ (298\ \mathrm{K}),
$$ {#eq-le}
其中 $\mathrm{p}K_\mathrm{d}$ 可换成 $\mathrm{p}K_\mathrm{I}$，或近似地换成 $\mathrm{pIC_{50}}$。**亲脂性配体效率**（利森（Paul Leeson）与斯普林索普（Brian Springthorpe），2007）为 $\mathrm{LLE} = \mathrm{p}K_\mathrm{d} - \log P$（或 $\log D$）。两者都是**经验**指标。按惯例 LE 以每重原子 $\mathrm{kcal\,mol^{-1}}$ 报出，约 $0.3$（约 $1.25\ \mathrm{kJ\,mol^{-1}}$）以上算好；对口服药，LLE 达到 5 以上被视为理想。
:::

0.3 这条界限有个简单的来历。一个 38 个重原子（摩尔质量约 $500\ \mathrm{g\,mol^{-1}}$）的药物级分子若 LE = 0.3，则 $\mathrm{p}K_\mathrm{d} = 0.3 \times 38/1.36 = 8.4$，是药物典型的效价。起始 LE 远低于 0.3 的苗头若要长到纳摩尔效价而不超限，就得一边长大一边变得更高效——而这样的事很少发生。LLE 针对第二种虚增：靠添加亲脂性换来的效价，而它往往伴随溶解度差、代谢清除快、滥合的脱靶结合与毒性。举例说，LLE 为 5 相当于 $\log P = 3$ 时 $\mathrm{p}K_\mathrm{d}$ 为 8。

::: example 比较一个片段与一个先导 {#ex-le}
一个 12 个重原子的片段以 $K_\mathrm{d} = 200\ \mu\mathrm{mol\,dm^{-3}}$ 结合；由它衍生出的先导有 36 个重原子，$K_\mathrm{d} = 5.0\ \mathrm{nmol\,dm^{-3}}$。在 $298\ \mathrm{K}$ 下分别计算两者的配体效率，以每重原子 $\mathrm{kJ\,mol^{-1}}$ 与 $\mathrm{kcal\,mol^{-1}}$ 表示。
::: solution
片段：$\mathrm{p}K_\mathrm{d} = -\log(2.0\times10^{-4}) = 3.70$，$-\Delta_\mathrm{b}G^\circ = 5.71 \times 3.70 = 21.1\ \mathrm{kJ\,mol^{-1}}$，$\mathrm{LE} = 21.1/12 = 1.76\ \mathrm{kJ\,mol^{-1}}$ $= 0.42\ \mathrm{kcal\,mol^{-1}}$ 每重原子。先导：$\mathrm{p}K_\mathrm{d} = 8.30$，$-\Delta_\mathrm{b}G^\circ = 47.4\ \mathrm{kJ\,mol^{-1}}$，$\mathrm{LE} = 1.32\ \mathrm{kJ\,mol^{-1}}$ $= 0.31\ \mathrm{kcal\,mol^{-1}}$ 每重原子。先导语价高 40 000 倍，效率却更低：加进去的 24 个原子每个只贡献 $(47.4 - 21.1)/24 = 1.10\ \mathrm{kJ\,mol^{-1}}$，不及片段的平均值。这是常态——小片段的 LE 最高，因为少数处在最佳位置的原子干了大部分工作——也正因此有人提出 LE 的依赖大小的版本。
:::
:::

x: 0, 50
y: 0, 14
sliders: a=0.4:0.2:0.6:0.01
labels: \mathrm{p}K_\mathrm{d}\ \text{当 LE} = a; \text{LE} = 0.3

caption: 随重原子数 $x$ 增加，维持给定配体效率（每重原子 $\mathrm{kcal\,mol^{-1}}$）所需的 $\mathrm{p}K_\mathrm{d}$，由[[#eq-le]]改写而来：$\mathrm{p}K_\mathrm{d} = \mathrm{LE}\cdot N_\mathrm{HA}/1.364$。三个点是[[#ex-le]]的片段与先导，以及一个 LE = 0.3 的 38 原子药物。一个 38 原子、落在 LE = 0.3 线以下的化合物，若不突破尺寸指南就不可能成为纳摩尔药物。注意直线爬升之快：50 个重原子处 LE = 0.3 已要求 $\mathrm{p}K_\mathrm{d} = 11$。

::: warning 效率指标是指南，不是物理常数 {#warn-le}
配体效率是用原子上一个对数量除以原子数，而该对数量的零点取决于标准态 $c^\circ = 1\ \mathrm{mol\,dm^{-3}}$ 的任意选择。把标准态改成 $1\ \mathrm{mmol\,dm^{-3}}$，每个 LE 值都会变，对小分子变得更多——所以大小悬殊的分子之间的 LE 比较部分是约定的产物。原子彼此也不平等：一个氯与一个氟计数相同。LE 与 LLE 用于比较同一系列中大小相近的化合物、或标记低效的生长，是有价值的；把它们当作自身就应最大化的量，就会误导。
:::

## 基于片段的发现

基于片段的药物发现（FBDD）把效率论证变成策略。不去筛选一百万个药物级分子，而在高浓度下筛选约一千个极小的分子——“片段”——接受极弱的结合，然后在晶体结构的引导下把高效的结合剂生长为先导。

为什么小分子反而是好的起点？汉恩（Michael Hann）、利奇（Andrew Leach）与哈珀（Gavin Harper）在 2001 年给出一个简单模型：一个随机分子*恰好*匹配结合位点的概率随其复杂度陡降，因为每一个额外基团也必须合适；而存在*可检出*相互作用的概率随复杂度上升。于是简单分子更可能以一种全部“对”的方式结合，尽管弱。而且采样片段空间所需的分子少得多：雷蒙（Jean-Louis Reymond）的枚举数据库 GDB-11（2007）发现至多 11 个重原子（C、N、O 与 F）的可能分子只有约 $2.6\times10^{7}$ 个，而药物级分子约 $10^{60}$ 个，所以 $10^3$ 个片段对片段空间的覆盖，远非 $10^6$ 个常规化合物对它们那片空间的覆盖可比。

::: definition 三规则（经验的） {#def-ro3}
阿斯泰克斯（Astex）的康格里夫（Miles Congreve）与同事（2003）观察到，好的片段苗头通常摩尔质量低于 $300\ \mathrm{g\,mol^{-1}}$，氢键供体至多 3 个、受体至多 3 个、计算 $\log P$ 至多 3（后来又建议补充：可旋转键至多 3 根、极性表面积至多 $60\ \text{Å}^2$）。与五规则一样，这条**经验**“三规则”描述的是过去成功的例子；它用来设计片段库，不用来预测结合。
:::

片段的 $K_\mathrm{d}$ 介于约 $10\ \mu\mathrm{mol\,dm^{-3}}$ 到 $10\ \mathrm{mmol\,dm^{-3}}$——对多数生化测定都太弱——所以要用生物物理方法检测：蛋白质观测 NMR（费西克（Stephen Fesik）与同事在雅培 1996 年发明的“SAR by NMR”法，观测 $^{15}\mathrm{N}$ 标记蛋白质酰胺化学位移随片段结合而移动）、配体观测 NMR、表面等离子体共振、热迁移，最重要的则是浸泡过片段溶液的蛋白质晶体的 X 射线晶体学。晶体结构显示每个片段究竟在何处、以何种方式结合，正是这一点让弱苗头有了用。

随后片段以三种方式被优化：**生长**（加原子伸入相邻的子口袋，尽可能保持 LE）、**合并**（把重叠片段的特征合为一个分子）或**连接**（用连接链把结合在相邻位点的两个片段连起来）。连接许诺最大的跨越，因为结合自由能可以相加。

::: proposition 连接两个片段的自由能 {#prop-linking}
设片段 A 与 B 以解离常数 $K_\mathrm{A}$ 与 $K_\mathrm{B}$ 独立地结合蛋白质的相邻位点，再用连接链把两者接成同时结合两个位点、解离常数为 $K_\mathrm{AB}$ 的分子 A–B。则
$$
\Delta G_\mathrm{AB} = \Delta G_\mathrm{A} + \Delta G_\mathrm{B} + \Delta G_\mathrm{link}, \qquad K_\mathrm{AB} = \frac{K_\mathrm{A}K_\mathrm{B}}{E_\mathrm{M}},
$$ {#eq-linking}
其中各 $\Delta G$ 都是标准结合自由能；$E_\mathrm{M} = c^\circ\exp(-\Delta G_\mathrm{link}/RT)$ 是第一个片段结合后第二个片段的**有效摩尔浓度**，它收纳了连接省下的熵以及连接链的应变、错位与相互作用。理想连接（$\Delta G_\mathrm{link} \approx 0$，$E_\mathrm{M} \approx 1\ \mathrm{mol\,dm^{-3}}$）将给出 $K_\mathrm{AB} = K_\mathrm{A}K_\mathrm{B}/c^\circ$。
:::

::: proof
自由能是状态函数，所以我们可以沿任一路径从分离的物种到达复合物 $\mathrm{P{\cdot}(A{-}B)}$。先结合 A（$\Delta G_\mathrm{A}$），再让 B 结合相邻位点（$\Delta G_\mathrm{B}$，两位点独立则不变），然后在两个已结合的片段之间形成共价连接。这最后一步分子内过程的自由能，相对于 A 与 B 在游离溶液中连接的相应变化（配体的游离态与结合态在此相同，故在结合自由能中抵消），定义了 $\Delta G_\mathrm{link}$。求和即得第一个方程。把每个 $\Delta G = RT\ln(K/c^\circ)$ 代入并取指数，得 $K_\mathrm{AB}/c^\circ = (K_\mathrm{A}/c^\circ)(K_\mathrm{B}/c^\circ)\exp(\Delta G_\mathrm{link}/RT)$，按所定义的 $E_\mathrm{M}$ 即第二个方程。其物理内涵——詹克斯（William Jencks）在 1981 年强调过——是那个巨大的不利项，结合时整体平动与转动熵的损失，被两个分离片段各付出一次，被连接的分子只付一次；这份节省使 $\Delta G_\mathrm{link}$ 可以为负，$E_\mathrm{M}$ 原则上可以超过 $1\ \mathrm{mol\,dm^{-3}}$。
:::

::: example 连接两个片段 {#ex-linking}
两个片段以 $K_\mathrm{A} = 1.0\ \mathrm{mmol\,dm^{-3}}$、$K_\mathrm{B} = 0.50\ \mathrm{mmol\,dm^{-3}}$ 结合相邻位点。最好的连接化合物 $K_\mathrm{AB} = 1.0\ \mu\mathrm{mol\,dm^{-3}}$。在 $298\ \mathrm{K}$ 下求有效摩尔浓度与 $\Delta G_\mathrm{link}$，并求理想连接本应给出的亲和力。
::: solution
由[[#eq-linking]]，$E_\mathrm{M} = K_\mathrm{A}K_\mathrm{B}/K_\mathrm{AB} = (1.0\times10^{-3})(5.0\times10^{-4})/(1.0\times10^{-6}) = 0.50\ \mathrm{mol\,dm^{-3}}$。结合自由能为 $\Delta G_\mathrm{A} = RT\ln(10^{-3}) = -17.1$、$\Delta G_\mathrm{B} = -18.8$、$\Delta G_\mathrm{AB} = -34.2\ \mathrm{kJ\,mol^{-1}}$，故 $\Delta G_\mathrm{link} = -34.2 - (-17.1 - 18.8) = +1.7\ \mathrm{kJ\,mol^{-1}}$。理想连接本应给出 $K_\mathrm{AB} = 5\times10^{-7}\ \mathrm{mol\,dm^{-3}}$，只优两倍。把毫摩尔级与亚毫摩尔级的片段做到微摩尔级化合物是很大的收获（比好的那个片段好一千倍），但实践中连接链很少做到 $E_\mathrm{M} \gg 1\ \mathrm{mol\,dm^{-3}}$，因为要在不产生应变的前提下让连接链原封不动地保持两种结合模式，实难找到。这就是生长比连接更常用的原因。
:::
:::

这一方法已产出若干药物。维莫非尼（vemurafenib），2011 年获批治疗黑色素瘤的激酶 BRAF V600E 突变体抑制剂，是第一个：Plexxikon 的科学家用一个结合激酶铰链区的 7-氮杂吲哚片段，在晶体结构引导下把它生长出来。维奈克拉（venetoclax，2016），[[medicinal-chemistry/drug-targets]]提到的 BCL-2 抑制剂，源自两个由 SAR by NMR 找到、结合相关蛋白 BCL-xL 沟槽中相邻位点的片段，两者被连接后又经过大量优化。

## 计算与编码化合物库

**虚拟筛选**把计算构造的大型化合物库对接进蛋白质结构，用打分函数排序（[[medicinal-chemistry/structure-based-design]]）。库可以极大，因为最后一步之前什么也不必合成：可由库存砌块一两步合成的“按需合成”化合物集合现已超过 $10^{10}$ 个，而数亿到数十亿分子量级的对接战役已为 GPCR 与酶找到过强效配体。**基于配体**的虚拟筛选则转而搜寻与已知活性分子相似的分子——凭子结构指纹，或凭三维形状与药效团匹配（[[medicinal-chemistry/structure-activity]]）。

**DNA 编码化合物库**（DEL）由布伦纳（Sydney Brenner）与勒纳（Richard Lerner）于 1992 年提出，把合成与条形码结合。在分装-合并（split-and-pool）合成中，每加一个砌块，就把一段短 DNA 序列接到生长的分子上作为记录，于是一支管中可以含 $10^8$–$10^{10}$ 种带 DNA 标签的不同化合物。混合物与固定化的靶点温育，未结合的化合物洗去，结合者的 DNA 标签经 PCR 扩增后测序，即揭示出它们的结构。

::: example 分装-合并的算术 {#ex-del}
一个 DNA 编码化合物库分三个循环构建，每个循环用 1000 种不同砌块；每个循环后把合并的物料分成 1000 份进入下一循环。库中含多少个化合物？需要多少个独立反应？若用 $10^{-15}$ mol 的化合物总量来筛选这个库，每个成员大致有多少个分子？
::: solution
化合物数目：$1000^3 = 1.0\times10^{9}$。反应数目：只有 $3 \times 1000 = 3000$，因为每个反应都是对含有前面各轮全部产物的混合物进行的；这就是分装-合并组合化学的经济之处。每个成员的分子拷贝数：$(10^{-15}\ \mathrm{mol})(6.022\times10^{23}\ \mathrm{mol^{-1}})/10^{9} = 6.0\times10^{-1}$——平均不足一个。实践中使用的量大得多，使每个成员约有 $10^5$–$10^6$ 个拷贝，但上面的计算说明了 DEL 筛选为何依赖 PCR 扩增：每个化合物只有飞摩尔到阿托摩尔的量，只有 DNA 标签才使它可被检出。
:::
:::

## 从苗头到先导

**苗头到先导**（hit-to-lead）阶段把一份确证苗头名单变成一到两个先导系列。它的逻辑是分流淘汰：尽可能早、尽可能便宜地抛弃不能成的东西。

::: algorithm 苗头的分流淘汰与苗头到先导 {#algo-triage}
1. **确证活性**：取新称的固体复测，完整浓度-效应，Hill 斜率接近 1，活性不受去污剂影响。
2. **确证机理**：读出信号不同的正交试验，结合靶点的生物物理证据，条件允许时加上晶体结构。
3. **清除隐患**：标出 PAINS 与活泼基团，核查纯度与身份，检验对近旁同源物与常见“高频命中”panel 的选择性。
4. **聚类**为化学系列，在紧邻类似物中寻找构效关系（快速购买或合成类似物）：小改动带来效价有章可循之变化的系列可以优化；SAR 平坦的孤苗多半不能。
5. **评估性质**：配体效率与 LLE、溶解度、渗透性、肝微粒体代谢稳定性、早期安全性警示（hERG、细胞毒性）。
6. **选定先导**：一个或少数几个系列，兼具效价、效率、可操作的合成、每一项短板都有改进空间，且知识产权可以得到保护。
:::

::: quiz
一个筛选苗头 $\mathrm{IC_{50}} = 2\ \mu\mathrm{mol\,dm^{-3}}$，希尔系数 3.2，其活性在缓冲液加入 0.01 % Triton X-100 后消失。最可能的解释是什么？
- [ ] 高度协同的别构抑制剂，应优先推进。
- [x] 它形成胶体聚集体，非特异地抑制酶。
- [ ] 它是共价抑制剂，这解释了陡峭的曲线。
- [ ] 去污剂使酶变性，结果无法解释。
::: solution
极陡的曲线且被少量非离子去污剂消除，是聚集体型抑制的签名（麦戈文（Plamen McGovern）、肖凯特与同事，2002）。这一浓度的去污剂会破坏胶体而基本不伤害酶——这一点用对照抑制剂核查。共价抑制剂表现的是时间依赖性，不是去污剂敏感性。
:::
:::

::: history
早期药物发现是在动物身上筛天然提取物与染料：埃尔利希（Paul Ehrlich）的团队测试了数百种砷剂才找到洒尔佛散（1909–1910）；多马克（Gerhard Domagk）1935 年发现百浪多息来自对偶氮染料在感染小鼠中的筛选。弗莱明（Alexander Fleming）1928 年观察到那块抗菌霉菌，弗洛里（Howard Florey）与钱恩（Ernst Chain）的牛津团队 1940 年纯化了青霉素并证明其效应。沃尔与瓦尼 1971 年报道紫杉醇的结构，屠呦呦的组 1972 年分离出青蒿素。布莱克与加勒林对组胺的理性改造在 1970 年代初产出西咪替丁。机器人高通量筛选在 1980 年代末与 1990 年代随组合化学一起在制药工业中成长；张晋胡（Ji-Hu Zhang）、查恩（Thomas Chung）与奥尔登堡（Kevin Oldenburg）1999 年发表 Z′ 因子。布伦纳与勒纳 1992 年提出 DNA 编码化学。费西克（Stephen Fesik）的组 1996 年引入 SAR by NMR，汉恩与同事 2001 年提出复杂度模型，康格里夫与同事 2003 年提出三规则，霍普金斯与同事 2004 年提出配体效率。2011 年获批的维莫非尼是第一个出自片段筛选的上市药物。
:::

## 后续内容

先导只是起点。[[medicinal-chemistry/structure-activity]]描述对先导的系统改造——药效团、生物电子等排体与定量构效关系；[[medicinal-chemistry/structure-based-design]]描述用蛋白质结构指导这种改造，包括用于虚拟筛选的分子对接。分流淘汰中检查的药代动力学性质见[[medicinal-chemistry/pharmacokinetics]]。筛选的统计学用到假设检验与贝叶斯定理，Maths Atlas（`/learn/maths/`）两者皆有；[[analytical-chemistry/statistics-calibration]]中对测量不确定度的处理可直接用于测定数据。

::: summary
- 苗头来自天然产物、已知配体与药物、表型筛选、$10^5$–$10^6$ 个化合物的高通量筛选、片段筛选、虚拟筛选与 DNA 编码化合物库；化学空间（约 $10^{60}$ 个类药分子）只能采样。
- 测定的品质由 $Z' = 1 - 3(\sigma_\mathrm{p} + \sigma_\mathrm{n})/\lvert\mu_\mathrm{p} - \mu_\mathrm{n}\rvert$ 概括；$Z' \geq 0.5$ 为优秀。
- 活性化合物稀少时，多数初筛苗头是假阳性（贝叶斯）；苗头必须经浓度-效应、正交测定与生物物理确证，并检查 PAINS 与聚集（陡峭的希尔斜率、去污剂敏感性）。
- 配体效率 $\mathrm{LE} = -\Delta_\mathrm{b}G^\circ/N_\mathrm{HA} \approx 1.36\,\mathrm{p}K_\mathrm{d}/N_\mathrm{HA}\ \mathrm{kcal\,mol^{-1}}$ 与 $\mathrm{LLE} = \mathrm{p}K_\mathrm{d} - \log P$ 是防止靠大小与亲脂性获得效价的经验指标；常以 LE ≈ 0.3、LLE ≈ 5 为目标。
- 基于片段的发现用生物物理方法在高浓度下筛小分子（经验三规则），再依晶体结构生长、合并或连接它们；连接给出 $K_\mathrm{AB} = K_\mathrm{A}K_\mathrm{B}/E_\mathrm{M}$。
- 苗头到先导是分流淘汰：确证、清除隐患、找到 SAR 有章可循且性质良好的系列。
:::

## 习题

::: exercise 配体效率 {level=1 check="0.4"}
一个有 25 个重原子的苗头 $K_\mathrm{d} = 50\ \mathrm{nmol\,dm^{-3}}$。计算它在 $298\ \mathrm{K}$ 的配体效率。（LE 以每重原子 $\mathrm{kcal\,mol^{-1}}$ 输入，保留一位有效数字。）
::: solution
$\mathrm{p}K_\mathrm{d} = -\log(5.0\times10^{-8}) = 7.30$。由[[#eq-le]]，$\mathrm{LE} = 1.364 \times 7.30/25 = 0.40\ \mathrm{kcal\,mol^{-1}}$ 每重原子（$1.67\ \mathrm{kJ\,mol^{-1}}$）。一个效率极高的苗头。
:::
:::

::: exercise 亲脂性配体效率 {level=1 check="5.5"}
化合物 A 的 $\mathrm{pIC_{50}} = 8.0$、$\log D = 3.5$；化合物 B 的 $\mathrm{pIC_{50}} = 7.0$、$\log D = 1.5$。计算两者的 LLE，并问按这一判据谁是更好的起点。（输入较高的 LLE。）
::: solution
$\mathrm{LLE_A} = 8.0 - 3.5 = 4.5$；$\mathrm{LLE_B} = 7.0 - 1.5 = 5.5$。化合物 B 效价低十倍，却更会用它的亲脂性；它的效价更可能来自特异的相互作用，优化时也留有更多添加亲脂基团的余地。
:::
:::

::: exercise 勉强合格的测定的 Z′ {level=1 check="0.34"}
某测定的对照给出 $\mu_\mathrm{n} = 60$、$\sigma_\mathrm{n} = 8$，$\mu_\mathrm{p} = 10$、$\sigma_\mathrm{p} = 3$。计算 $Z'$ 并评论。（$Z'$ 保留两位有效数字。）
::: solution
$Z' = 1 - 3(8 + 3)/(60 - 10) = 1 - 33/50 = 0.34$。测定可用但勉强（$0 < Z' < 0.5$）：它会产生许多假阳性与假阴性。问题大部分出在阴性对照的噪声上，应首先解决它。
:::
:::

::: exercise 至少找到一个苗头的概率 {level=2 check="0.632"}
设活性化合物随机出现在库中，频率为百万分之一（$10^{-5}$）。若筛选 $10^{5}$ 个化合物且每个活性化合物都能检出，至少找到一个的概率是多少？（用泊松近似。概率保留三位有效数字。）
::: solution
活性化合物数目的期望为 $\lambda = 10^5 \times 10^{-5} = 1$。泊松分布下一个也没有的概率是 $e^{-1} = 0.368$，故至少一个的概率为 $1 - e^{-1} = 0.632$。把化合物量加倍，概率升到 $1 - e^{-2} = 0.865$。用 $10^6$ 规模的库，不是因为苗头有保证，而是为了有好几个彼此独立的系列可供选择。
:::
:::

::: exercise 大小的代价 {level=2 check="11"}
一个 50 个重原子的化合物，若要在 $298\ \mathrm{K}$ 下达到每重原子 $0.30\ \mathrm{kcal\,mol^{-1}}$ 的配体效率，需要多大的 $\mathrm{p}K_\mathrm{d}$？评论其含义。（$\mathrm{p}K_\mathrm{d}$ 保留两位有效数字。）
::: solution
由[[#eq-le]]，$\mathrm{p}K_\mathrm{d} = \mathrm{LE}\cdot N_\mathrm{HA}/1.364 = 0.30 \times 50/1.364 = 11$。$10^{-11}\ \mathrm{mol\,dm^{-3}}$ 的 $K_\mathrm{d}$ 对小分子而言罕见，测它需要专门的方法。大分子的 LE 几乎必然更低；对它们要放宽 LE 界限，更看重别的度量（LLE、性质）。
:::
:::

::: exercise 高效地生长一个片段 {level=2 check="5.6"}
一个 10 个重原子的片段 $\mathrm{p}K_\mathrm{d} = 3.5$。若加入六个原子且 LE 严格保持不变，生长后的化合物应有怎样的 $\mathrm{p}K_\mathrm{d}$？（$\mathrm{p}K_\mathrm{d}$ 保留两位有效数字。）
::: solution
LE 恒定时 $\mathrm{p}K_\mathrm{d}$ 正比于 $N_\mathrm{HA}$：$\mathrm{p}K_\mathrm{d} = 3.5 \times 16/10 = 5.6$。片段的 LE 为 $1.364 \times 3.5/10 = 0.48\ \mathrm{kcal\,mol^{-1}}$ 每重原子，所以六个新原子须共贡献 $0.48 \times 6 = 2.9\ \mathrm{kcal\,mol^{-1}}$（$12\ \mathrm{kJ\,mol^{-1}}$）——亲和力约提高一百余倍。
:::
:::

::: exercise 由第一性原理连接片段 {level=3}
(a) 利用[[#prop-linking]]证明：两个 $\mathrm{p}K_\mathrm{d} = 3$ 的片段若理想连接（$E_\mathrm{M} = 1\ \mathrm{mol\,dm^{-3}}$），产物 $\mathrm{p}K_\mathrm{d} = 6$；且若连接链不增加重原子，其配体效率等于两个片段 LE 的平均。(b) 改用一根三个重原子的连接链，产物 $\mathrm{p}K_\mathrm{d} = 5$。设每个片段 10 个重原子，比较片段与产物的 LE，并求 $E_\mathrm{M}$。(c) 从物理上解释为什么 $E_\mathrm{M}$ 原则上可以超过 $1\ \mathrm{mol\,dm^{-3}}$。
::: hint
对数形式下，[[#eq-linking]]写作 $\mathrm{p}K_\mathrm{AB} = \mathrm{p}K_\mathrm{A} + \mathrm{p}K_\mathrm{B} + \log_{10}(E_\mathrm{M}/c^\circ)$。
:::
::: solution
(a) $\mathrm{p}K_\mathrm{AB} = 3 + 3 + \log 1 = 6$。若不增加原子，$N_\mathrm{HA}(\mathrm{AB}) = N_\mathrm{A} + N_\mathrm{B}$ 且 $-\Delta G_\mathrm{AB} = -\Delta G_\mathrm{A} - \Delta G_\mathrm{B}$，故 $\mathrm{LE_{AB}} = (N_\mathrm{A}\mathrm{LE_A} + N_\mathrm{B}\mathrm{LE_B})/(N_\mathrm{A} + N_\mathrm{B})$，即按原子数加权的平均。

(b) 片段：$\mathrm{LE} = 1.364 \times 3/10 = 0.41$（各）。产物：$1.364 \times 5/23 = 0.30\ \mathrm{kcal\,mol^{-1}}$ 每重原子。$\log(E_\mathrm{M}/c^\circ) = 5 - 6 = -1$，故 $E_\mathrm{M} = 0.10\ \mathrm{mol\,dm^{-3}}$；$\Delta G_\mathrm{link} = +5.7\ \mathrm{kJ\,mol^{-1}}$。连接的化合物比任一片段强一百倍，效率却更低，因为连接链不完美，还添上了不形成任何接触的原子。

(c) 每个单独结合的片段都要付出失去自身整体平动与转动的巨大熵代价；连接的分子只付一次。若连接链能把两个片段分毫不差、无应变地保持在各自的结合位置而不损失相互作用，这份节省就使 $\Delta G_\mathrm{link}$ 为负，从而 $E_\mathrm{M} > 1\ \mathrm{mol\,dm^{-3}}$——“超加和性”。分子内反应的有效摩尔浓度达到 $10^{2}$ 以上者已有记载，但连接链通常因残余柔性与几何不完美而损失一部分节省。
:::

::: exercise 重复测量与假阳性 {level=3 check="0.978"}
在[[#ex-ppv]]的筛选中，所有越过 $3\sigma$ 阈值的化合物以同一阈值各自独立地复测一次。(a) 设假阳性纯属随机噪声（两次检验之间独立），且每个真活性化合物再次被检出的概率仍为 0.90，两次都判活的化合物中真活性化合物占什么分数？(b) 若 20 个非活性化合物是可重复的伪象（干扰化合物或聚集体），在每次检验中都越过阈值，重算一次。（(a) 的分数保留三位有效数字。）
::: hint
数出两次都通过的真活性化合物（$100 \times 0.90^2$）与偶然两次都通过的非活性化合物（$(10^6 - 100) \times 0.00135^2$）。
:::
::: solution
(a) 两次都通过的真活性化合物：$100 \times 0.81 = 81$。偶然两次都通过的非活性化合物：$999\,900 \times (0.00135)^2 = 999\,900 \times 1.822\times10^{-6} = 1.82$。真活性分数为 $81/(81 + 1.82) = 0.978$，比单次检验后的 0.063 大幅上升。

(b) 那些伪象两次都通过，而其余 $999\,880$ 个非活性化合物仍贡献 1.82 个偶然双通过：真活性分数为 $81/(81 + 1.82 + 20) = 0.788$。重复测量消除噪声，消除不了伪象。干扰化合物、聚集体与活泼分子每次都给出同样的假信号，只有读出信号不同的正交试验、去污剂对照复测与生物物理结合测量才能把它们排除。
:::
