一片现代药片通常含有几毫克摩尔质量约 $400\ \mathrm{g\,mol^{-1}}$ 的有机分子——大约 $10^{19}$ 个分子，散布在一个约含 $10^{27}$ 个水分子、上万种不同蛋白质的身体的水分之中。然而这个分子能可测量地改变某一生理过程，却几乎不碰其他任何东西。它之所以能做到这一点，只是因为它找到并结合了一个特定的生物大分子——它的**靶点**——并结合后改变了靶点的所作所为。药物化学始于这样一个思想，它是埃尔利希（Paul Ehrlich）在二十世纪初以一句箴言说出的：*corpora non agunt nisi fixata*——“物质非结合不生效”。

本章概览药物所结合的大分子的种类——酶、受体、离子通道、转运体和核酸——并介绍把药物浓度与靶点上发生的事情联系起来的定量思想：**分数占据**、把酶测定结果换算成抑制常数（Cheng–Prusoff 关系）、**不可逆**抑制剂的动理学，以及以自由能差表达的**选择性**。这一切背后的结合平衡与酶动理学已在[[biochemistry/protein-function]]与[[biochemistry/enzymes]]中建立；这里把它们应用到药物上。结合在分子水平上*怎样*发生——那些力、热力学，以及激动剂与拮抗剂之别——是[[medicinal-chemistry/drug-binding]]的主题。

整个课程中，药物、疾病与数字的出现只是为了说明化学。这只是教育内容，不是医疗建议：本章没有任何数值是剂量或治疗推荐，治疗决定属于遵循现行指南的临床医生。

## 什么样的蛋白质能成为药物靶点

大多数药物靶点是蛋白质，而且几乎所有靶点都有一个口袋：一条裂隙或空腔，体积通常为 $300$–$1000\ \text{Å}^3$，内壁由极性与非极性侧链混合衬成，小分子能装进去，水能被置换出来。这个口袋通常是蛋白质结合自身天然配体的地方——底物、激素或神经递质——但并非必须如此：蛋白质上别处的**别构**位点同样可以加以利用。

::: definition 药物靶点与成药性 {#def-target}
**药物靶点**是这样一种生物大分子（通常是蛋白质，有时是 RNA 或 DNA）：药物与之结合后其功能发生改变，且这种功能改变产生治疗作用。若一个靶点能以有用的亲和力结合一个可口服吸收的小分子（惯例上指解离常数 $K_\mathrm{d} \lesssim 1\ \mu\mathrm{mol\,dm^{-3}}$），就具有**可成药性**，而这实际上要求存在足够深、足够封闭且部分疏水的口袋。当有证据——遗传学、药理学或临床的——表明改变某个靶点的活性会改变疾病的进程时，该靶点对这种疾病就是**经过验证的**。
:::

成药性与验证彼此独立。一个蛋白质可能有一个漂亮的口袋却与疾病毫无关系，也可能在疾病中居于核心却有一张任何小分子都抓不住的平坦、无特征的表面。霍普金斯（Andrew Hopkins）与格鲁姆（Colin Groom）在 2002 年估计，人类约 20 000 个蛋白质编码基因中约 3,000 个编码的蛋白质属于已知能结合类药分子的家族——“可成药基因组”——而其中只有部分与疾病相联系。桑托斯（Rita Santos）与同事（2017）的清点统计了 667 个人类蛋白质，它们是当时美国已批准的约 1,600 种小分子与生物药的靶点，另有约 200 个靶点在病原体中。靶点集中于少数几个家族：

| 家族 | 药物实例 | 药物作用方式 |
|---|---|---|
| G 蛋白偶联受体（GPCR） | β受体阻滞剂、抗组胺药、阿片类药物 | 作为膜受体的激动剂或拮抗剂 |
| 离子通道 | 局部麻醉药、苯二氮䓬类、钙通道阻滞剂 | 阻滞孔道或调节门控 |
| 酶（包括激酶与蛋白酶） | 阿司匹林、他汀类、ACE 抑制药、伊马替尼、HIV 蛋白酶抑制剂 | 抑制催化 |
| 核受体 | 糖皮质激素、他莫昔芬 | 作为胞内转录因子的激动剂或拮抗剂 |
| 转运体与泵 | SSRI、质子泵抑制剂、地高辛 | 阻断转运 |
| 核酸 | 顺铂、多柔比星、氨基糖苷类 | 结合 DNA 或核糖体 RNA |

已批准药物中约三分之一作用于 GPCR（豪泽（David Hauser）与同事在 2017 年统计了作用于 108 个 GPCR 的 475 种药物），而上述几个家族合起来占据了其余靶点的大部分。这种集中并不完全是历史的偶然：这些家族拥有为结合小分子而演化出的成形口袋。

## 占据：从浓度到靶点

关于任何药物的第一个定量问题是：在给定浓度下，它的靶点分子中有多大比例结合着药物分子？这与[[biochemistry/protein-function]]中就氧与肌红蛋白提出的问题是同一个，答案也相同。

::: proposition 分数占据 {#prop-occupancy}
设药物 L 可逆地结合单一一类独立位点 R，$\mathrm{R + L \rightleftharpoons RL}$，解离常数为 $K_\mathrm{d} = [\mathrm{R}][\mathrm{L}]/[\mathrm{RL}]$。平衡时被占据位点的分数为
$$
\theta = \frac{[\mathrm{RL}]}{[\mathrm{R}] + [\mathrm{RL}]} = \frac{[\mathrm{L}]}{K_\mathrm{d} + [\mathrm{L}]},
$$ {#eq-occupancy}
其中 $[\mathrm{L}]$ 是**游离**（未结合）药物浓度。若药物大大过量于位点，游离浓度就等于总浓度。
:::

::: proof
位点总数为 $[\mathrm{R}]_0 = [\mathrm{R}] + [\mathrm{RL}]$。由 $K_\mathrm{d}$ 的定义，$[\mathrm{R}] = K_\mathrm{d}[\mathrm{RL}]/[\mathrm{L}]$。代入得
$$
\theta = \frac{[\mathrm{RL}]}{K_\mathrm{d}[\mathrm{RL}]/[\mathrm{L}] + [\mathrm{RL}]} = \frac{[\mathrm{L}]}{K_\mathrm{d} + [\mathrm{L}]}.
$$
推导中没有任何一步假定细胞如何使用占据分数；它就是纯质量作用，在平衡下成立，适用于单一配体与独立的相同位点。当位点总浓度与 $K_\mathrm{d}$ 相比不可忽略时，结合会耗去游离药物，$[\mathrm{L}]$ 必须由把质量作用与药物及位点两者的守恒结合起来的二次方程求出（[[medicinal-chemistry/drug-binding]]中有一道习题）。
:::

有三个值得熟记于心的推论。$[\mathrm{L}] = K_\mathrm{d}$ 时半数位点被占据，所以 $K_\mathrm{d}$ 就是一种药物的浓度标尺：“纳摩尔级”药物指其 $K_\mathrm{d}$ 在 $10^{-9}\ \mathrm{mol\,dm^{-3}}$ 量级。由 $\theta/(1-\theta) = [\mathrm{L}]/K_\mathrm{d}$，占据分数从 50 % 升到 90 % 需要浓度提高九倍，从 90 % 再升到 99 % 又需十一倍——对 $\log[\mathrm{L}]$ 作图时曲线很平缓，从 10 % 到 90 % 大约跨越两个数量级。而由于双曲线只依赖比值 $[\mathrm{L}]/K_\mathrm{d}$，$K_\mathrm{d}$ 低一百倍的药物用低一百倍的浓度就能达到同样的占据分数；亲和力买来的是更低的浓度，而不是更高的上限。

::: example 受体的占据分数 {#ex-occupancy}
某受体拮抗剂以其受体结合的 $K_\mathrm{d} = 2.0\ \mathrm{nmol\,dm^{-3}}$。(a) 游离药物浓度为 $18\ \mathrm{nmol\,dm^{-3}}$ 时，受体的多大比例被占据？(b) 要达到 99 % 占据需要多高的游离浓度？
::: solution
(a) 由[[#eq-occupancy]]，$\theta = 18/(2.0 + 18) = 0.90$：90 % 的受体上结合着药物分子。

(b) 改写公式得 $[\mathrm{L}] = K_\mathrm{d}\,\theta/(1-\theta) = 2.0 \times 0.99/0.01 = 198 \approx 2.0\times10^2\ \mathrm{nmol\,dm^{-3}}$，是达到 90 % 所需浓度的十一倍。把占据分数从 90 % 推到 99 %，意味着体内一切地方的浓度都要提高十倍，包括药物弱结合着的其他每一种蛋白质上——这就是为什么药物很少被设计成只在接近全部占据时才起效。
:::
:::

::: warning 占据取决于靶点处的游离浓度 {#warn-free}
[[#eq-occupancy]]中的浓度是浸润靶点的液体中游离药物的浓度，不是血样中测得的总量。许多药物 90 % 以上与白蛋白等血浆蛋白结合，只有未结合部分才能到达并占据靶点（[[medicinal-chemistry/pharmacokinetics]]）。同样，占据不是效应：完全激动剂可能在 10 % 占据时就产生最大效应，而拮抗剂可能要 90 % 占据才看得出效果。占据是化学与药理学之间的联系环节，不是链条的末端。
:::

## 酶作为靶点

约三分之一的小分子药物抑制某种酶。可逆抑制的理论已在[[biochemistry/enzymes]]中建立：竞争性抑制剂以解离常数 $K_\mathrm{I}$ 结合游离酶，使表观米氏常数升高为 $K_\mathrm{M}(1 + [\mathrm{I}]/K_\mathrm{I})$，而不改变 $V_\mathrm{max}$。然而药物化学家很少直接测 $K_\mathrm{I}$，他们测的是 $\mathrm{IC_{50}}$——在特定测定条件下使速率减半的抑制剂浓度——而这两个不是同一个数。

::: proposition Cheng–Prusoff 关系 {#prop-cheng}
对遵循米氏动力学的酶的竞争性抑制剂，抑制剂过量于酶时，在底物浓度 $[\mathrm{S}]$ 下使初速率减半的浓度为
$$
\mathrm{IC_{50}} = K_\mathrm{I}\left(1 + \frac{[\mathrm{S}]}{K_\mathrm{M}}\right).
$$ {#eq-cheng}
:::

::: proof
无抑制剂时 $v_0 = V_\mathrm{max}[\mathrm{S}]/(K_\mathrm{M} + [\mathrm{S}])$。有竞争性抑制剂时 $v_i = V_\mathrm{max}[\mathrm{S}]/(K_\mathrm{M}(1 + [\mathrm{I}]/K_\mathrm{I}) + [\mathrm{S}])$。令 $v_i = v_0/2$ 并约去 $V_\mathrm{max}[\mathrm{S}]$：
$$
K_\mathrm{M}\left(1 + \frac{[\mathrm{I}]}{K_\mathrm{I}}\right) + [\mathrm{S}] = 2(K_\mathrm{M} + [\mathrm{S}]) \quad\Rightarrow\quad \frac{K_\mathrm{M}[\mathrm{I}]}{K_\mathrm{I}} = K_\mathrm{M} + [\mathrm{S}],
$$
于是 $[\mathrm{I}] = K_\mathrm{I}(1 + [\mathrm{S}]/K_\mathrm{M})$，即[[#eq-cheng]]。过量条件允许我们用抑制剂总浓度作为 $[\mathrm{I}]$；对 $K_\mathrm{I}$ 与酶浓度相当的“紧密结合”抑制剂，该关系不成立，$\mathrm{IC_{50}}$ 不可能低于约酶浓度的一半。
:::

这一关系由 Cheng（Yung-Chi Cheng）与 Prusoff（William Prusoff）于 1973 年发表，它的实践含义是：$\mathrm{IC_{50}}$ 是某个测定的属性，不是分子的属性。两家实验室在不同底物浓度下测试同一抑制剂会报出不同的数值；一个在低底物测定中看起来强效的化合物，在天然底物丰富的细胞里可能失去很大一部分效价——这一点对在毫摩尔浓度 ATP 的竞争中作战的激酶抑制剂极其要紧（[[medicinal-chemistry/drug-case-studies]]）。

::: example 把 IC₅₀ 换算成 Kᵢ {#ex-cheng}
某竞争性抑制剂在 $[\mathrm{S}] = 50\ \mu\mathrm{mol\,dm^{-3}}$ 的测定中给出 $\mathrm{IC_{50}} = 120\ \mathrm{nmol\,dm^{-3}}$，该酶的 $K_\mathrm{M} = 25\ \mu\mathrm{mol\,dm^{-3}}$。求 $K_\mathrm{I}$，并预测在 $[\mathrm{S}] = K_\mathrm{M}/5$ 的测定中测得的 $\mathrm{IC_{50}}$。
::: solution
由[[#eq-cheng]]，$K_\mathrm{I} = \mathrm{IC_{50}}/(1 + [\mathrm{S}]/K_\mathrm{M}) = 120/(1 + 50/25) = 120/3 = 40\ \mathrm{nmol\,dm^{-3}}$。在 $[\mathrm{S}] = 5\ \mu\mathrm{mol\,dm^{-3}}$ 时，$\mathrm{IC_{50}} = 40(1 + 0.2) = 48\ \mathrm{nmol\,dm^{-3}}$。分子本身没有变，只是来自底物的竞争不同了。竞争性抑制剂的测定通常在 $[\mathrm{S}] \approx K_\mathrm{M}$ 下进行，此时 $\mathrm{IC_{50}} = 2K_\mathrm{I}$，这样化合物之间的效价可比，测定对竞争性与反竞争性抑制剂的灵敏度也相同。
:::
:::

### 过渡态类似物

酶抑制剂设计中最有力的思想出自[[biochemistry/enzymes]]中关于过渡态结合的论证：酶结合其反应过渡态比结合底物更紧，紧的倍数恰好等于它加速反应的倍数。一个在几何构型、电荷分布上类似过渡态的稳定分子，因而能捕获那份巨大亲和力中的一部分。肽水解经过四面体中间体，所以蛋白酶抑制剂用四面体、不可水解的基团替换待水解的酰胺：HIV 抑制剂中的羟亚乙基或羟乙胺单元（[[medicinal-chemistry/structure-based-design]]）、次膦酸酯，或与活性部位丝氨酸加成形成四面体硼酸酯的硼酸（硼替佐米，一种蛋白酶体抑制剂）。他汀类模拟 HMG-辅酶 A 还原的四面体中间体；奥司他韦则模拟流感神经氨酸酶切割唾液酸时那个扁平的氧鎓离子样过渡态。

### 不可逆抑制剂与共价抑制剂

有些药物与其靶点形成共价键。阿司匹林把它的乙酰基转移给 COX-1 通道中的一丝氨酸（Ser530），将其永久封闭；青霉素类把细菌转肽酶的活性部位丝氨酸酰化（[[medicinal-chemistry/drug-case-studies]]）；质子泵抑制剂奥美拉唑在酸中活化为亚磺酰胺，与 $\mathrm{H^+/K^+}$-ATPase 的半胱氨酸形成二硫键。现代的**靶向共价抑制剂**——如激酶抑制剂伊布替尼与奥希替尼——带有一个温和的亲电体（丙烯酰胺），被安置在与结合位点附近一个特定半胱氨酸反应的位置上。这类抑制剂的动理学是两步的：先可逆结合，再形成共价键。

::: proposition 不可逆抑制的动理学 {#prop-inactivation}
对机理
$$
\mathrm{E + I} \underset{}{\overset{K_\mathrm{I}}{\rightleftharpoons}} \mathrm{E{\cdot}I} \xrightarrow{\ k_\mathrm{inact}\ } \mathrm{E{-}I},
$$
设可逆步骤处于快速平衡（解离常数 $K_\mathrm{I}$）且抑制剂过量，活性酶（$\mathrm{E}$ 加 $\mathrm{E{\cdot}I}$）按指数衰减，$[\mathrm{E}]_\mathrm{active}(t) = [\mathrm{E}]_0\,e^{-k_\mathrm{obs}t}$，其中
$$
k_\mathrm{obs} = \frac{k_\mathrm{inact}[\mathrm{I}]}{K_\mathrm{I} + [\mathrm{I}]}.
$$ {#eq-kobs}
低抑制剂浓度下 $k_\mathrm{obs} \approx (k_\mathrm{inact}/K_\mathrm{I})[\mathrm{I}]$；二级常数 $k_\mathrm{inact}/K_\mathrm{I}$ 就是衡量共价抑制剂效率的量。
:::

::: proof
设 $A = [\mathrm{E}] + [\mathrm{E{\cdot}I}]$ 为尚未被共价修饰的酶。快速平衡给出 $[\mathrm{E{\cdot}I}] = [\mathrm{E}][\mathrm{I}]/K_\mathrm{I}$，于是 $A$ 中以可逆复合物形式存在的分数为 $[\mathrm{I}]/(K_\mathrm{I} + [\mathrm{I}])$——正是[[#eq-occupancy]]的占据。只有该复合物反应，速率为 $k_\mathrm{inact}[\mathrm{E{\cdot}I}]$，故
$$
\frac{dA}{dt} = -k_\mathrm{inact}[\mathrm{E{\cdot}I}] = -\frac{k_\mathrm{inact}[\mathrm{I}]}{K_\mathrm{I} + [\mathrm{I}]}\,A.
$$
$[\mathrm{I}]$ 恒定（过量）时，这是关于 $A$ 的一级过程，速率常数为[[#eq-kobs]]，积分即得指数衰减。其形式与米氏方程完全相同，$k_\mathrm{inact}$ 扮演的角色相当于 $k_\mathrm{cat}$——这并非巧合，因为失活就是酶–抑制剂复合物的一次“反应”。
:::

::: example 共价抑制剂有多快？ {#ex-inactivation}
某共价抑制剂 $K_\mathrm{I} = 2.0\ \mu\mathrm{mol\,dm^{-3}}$，$k_\mathrm{inact} = 0.010\ \mathrm{s^{-1}}$。在 $[\mathrm{I}] = 1.0\ \mu\mathrm{mol\,dm^{-3}}$ 下，求 $k_\mathrm{obs}$、活性酶的半衰期，以及 $10$ 分钟后剩余的活性分数。
::: solution
由[[#eq-kobs]]，$k_\mathrm{obs} = (0.010\ \mathrm{s^{-1}})(1.0)/(2.0 + 1.0) = 3.33\times10^{-3}\ \mathrm{s^{-1}}$。半衰期为 $\ln 2/k_\mathrm{obs} = 208\ \mathrm{s}$，约 $3.5$ 分钟。$600\ \mathrm{s}$ 后剩余分数为 $e^{-(3.33\times10^{-3})(600)} = e^{-2.00} = 0.135$，即 86 % 的酶已失活。效率常数 $k_\mathrm{inact}/K_\mathrm{I} = 5.0\times10^{3}\ \mathrm{dm^3\,mol^{-1}\,s^{-1}}$。注意只要抑制剂存在，失活就持续进行：不可逆抑制剂的效应取决于浓度*和*时间，所以用单一孵育时间测出的 $\mathrm{IC_{50}}$ 对它并不是一个有意义的常数。
:::
:::

sliders: c=1:0.1:20:0.1; K=2:0.5:10:0.1; k=0.6:0.1:2:0.05

被不可逆抑制的酶一直失活，直到细胞合成出新蛋白，所以此类药物作用持续的时间由**靶点的再合成速率**决定，而不由药物离开身体的快慢决定。阿司匹林是经典例证：它一小时内左右即从血浆中清除，但被它作用过的血小板因没有细胞核而无法制造新的 COX-1；它们的血栓烷合成在其剩余约 7–10 天寿命内一直被压制，只有骨髓释放新血小板时才恢复。

### 选择性毒性

当靶点属于病原体时，药物必须在病原体的蛋白质与宿主的同类版本之间做出区分——或者打击一条宿主没有的途径。磺胺类药物阻断二氢蝶啶合酶，这是细菌需要而人类没有（我们从膳食摄取叶酸）的叶酸合成酶；它们是底物对氨基苯甲酸的结构类似物。甲氧苄啶抑制二氢叶酸还原酶（DHFR），这是细菌与人类都有的酶，但它结合细菌酶比结合人酶紧约 $10^4$–$10^5$ 倍。这种选择性自然地表达为解离常数之比，而这个比值又可化为自由能之差。

::: definition 选择性 {#def-selectivity}
药物对靶点 A 相对第二种蛋白质 B 的**选择性**是比值 $S = K_\mathrm{d}(\mathrm{B})/K_\mathrm{d}(\mathrm{A})$（或 $K_\mathrm{I}$ 值之比；$\mathrm{IC_{50}}$ 值之比只有在测定等价时才有意义）。由于标准结合吉布斯能为 $\Delta_\mathrm{b}G^\circ = RT\ln(K_\mathrm{d}/c^\circ)$，选择性对应于结合自由能之差
$$
\Delta\Delta_\mathrm{b}G^\circ = \Delta_\mathrm{b}G^\circ(\mathrm{B}) - \Delta_\mathrm{b}G^\circ(\mathrm{A}) = RT\ln S.
$$ {#eq-selectivity}
$298\ \mathrm{K}$ 下，选择性每十倍对应 $RT\ln 10 = 5.71\ \mathrm{kJ\,mol^{-1}}$。
:::

::: example 以自由能差表达选择性 {#ex-selectivity}
某抗菌抑制剂结合细菌酶的 $K_\mathrm{I} = 1.0\ \mathrm{nmol\,dm^{-3}}$，结合人酶的 $K_\mathrm{I} = 30\ \mu\mathrm{mol\,dm^{-3}}$（甲氧苄啶类型的示意数值）。在 $310\ \mathrm{K}$ 下把选择性表示为比值与 $\Delta\Delta_\mathrm{b}G^\circ$，并与一根氢键的强度比较。
::: solution
$S = (30\times10^{-6})/(1.0\times10^{-9}) = 3.0\times10^{4}$。由[[#eq-selectivity]]，$\Delta\Delta_\mathrm{b}G^\circ = (8.314\ \mathrm{J\,K^{-1}\,mol^{-1}})(310\ \mathrm{K})\ln(3.0\times10^4) = 26.6\ \mathrm{kJ\,mol^{-1}}$。埋藏在蛋白质中的一根中性氢键对结合净贡献大约只有 $2$–$6\ \mathrm{kJ\,mol^{-1}}$（[[medicinal-chemistry/drug-binding]]），所以这一水平的选择性相当于在一中酶里形成、在另一种酶里没形成的少数几个相互作用。对甲氧苄啶而言，晶体结构显示细菌与脊椎动物 DHFR 活性部位形状上的微小差异就已足够。
:::
:::

## 受体

药理学中的**受体**是这样一种蛋白质：其职责是识别化学信号——激素或神经递质——并把信号转导为细胞反应。模仿信号并产生效应的药物是**激动剂**；占据受体却不激活它、从而阻断天然信号的药物是**拮抗剂**（[[medicinal-chemistry/drug-binding]]）。四个结构超家族几乎涵盖所有受体。

**G 蛋白偶联受体**（GPCR）是单次以 α 螺旋穿越细胞膜七条的单条多肽，配体结合位点通常位于近胞外面由螺旋围成的口袋中。人类约有 800 个 GPCR 基因，约半数是嗅觉受体。激动剂稳定一种活性构象，其中螺旋的胞质端散开，露出一条缝隙结合异三聚体 G 蛋白；G 蛋白的 α 亚基把 GDP 换成 GTP 后解离，去调节一个效应器。$\mathrm{G_s}$ 激活腺苷酸环化酶（升高环 AMP），$\mathrm{G_i}$ 抑制它，$\mathrm{G_q}$ 激活磷脂酶 C（释放三磷酸肌醇与二酰甘油，进而释放 $\mathrm{Ca^{2+}}$）。β肾上腺素受体（β受体阻滞剂与哮喘支气管扩张剂的靶点）、组胺 $\mathrm{H_1}$ 与 $\mathrm{H_2}$ 受体、阿片受体、多巴胺与 5-羟色胺受体以及血管紧张素 $\mathrm{AT_1}$ 受体都是 GPCR。

这个级联放大信号。一个被激活的受体在被关断之前可激活许多 G 蛋白；每个被激活的腺苷酸环化酶制造许多 cAMP 分子；每个释放出来的蛋白激酶 A 催化亚基磷酸化许多底物蛋白。这就是为什么几百个被占据的受体就能在携带数万个受体的细胞里产生满反应，也是为什么对激动剂而言，效应与占据不成正比。

**配体门控离子通道**是结合神经递质后打开孔道的多亚基膜蛋白。神经肌肉接头的烟碱型乙酰胆碱受体（被箭毒样肌松药阻断）与氯离子通道 $\mathrm{GABA_A}$ 受体都是例子。苯二氮䓬类结合在 $\mathrm{GABA_A}$ 受体两个亚基之间有别于 GABA 位点的位点上，增强 GABA 的作用；它们是**正别构调节剂**而非激动剂，这是其效应在天然递质缺席时自动封顶的原因之一。

**酶联受体**——如胰岛素受体与表皮生长因子受体这类受体酪氨酸激酶——有一个胞外结合结构域、一条跨膜螺旋和一个胞内激酶结构域，配体诱导的二聚化使其激活。小分子药物通常靶向胞内激酶结构域的 ATP 位点；抗体则靶向胞外结构域（[[medicinal-chemistry/biologics]]）。

**核受体**是可溶的胞内蛋白质（人类有 48 个），结合亲脂性激素——类固醇、甲状腺激素、维甲酸——然后作为转录因子作用于 DNA。针对它们的药物必须穿越细胞膜。配体改变配体结合结构域 C 端螺旋（螺旋 12）的位置，由它决定募集共激活蛋白还是共抑制蛋白。他莫昔芬用于雌激素受体阳性的乳腺癌：它结合雌激素受体，并凭借其体积庞大的碱性侧链把螺旋 12 固定在乳腺组织中的失活位置——而在骨和子宫中却表现为部分激动剂。这种组织依赖的行为给了这一类药物它的名字：选择性雌激素受体调节剂。

## 离子通道与转运体

**电压门控离子通道**随膜电位开启和关闭，在静息、开放与失活态之间循环，许多药物优先结合其中某一状态。利多卡因等局部麻醉药从细胞内侧阻断电压门控钠通道：它们经开放的通道到达孔道内的位点，并与开放态和失活态结合得最紧。高频发放的神经在这些状态上花的时间更多，因而被阻断得更多——**使用依赖性阻滞**，由希尔（Bertil Hille）的调制受体假说（1977）解释。化学在每一步上都紧要：利多卡因是叔胺（$\mathrm{p}K_\mathrm{a} \approx 7.9$），以中性碱的形式穿越膜，却以阳离子的形式在孔道内结合，所以局部 pH 控制着到达位点的药量。二氢吡啶类钙通道阻滞剂（氨氯地平）和许多抗癫痫药以同样的状态依赖方式作用于电压门控通道。一个重要而并非本意的通道靶点是心脏的 hERG 钾通道：许多互不相关的药物都能阻断它，从而延长心电图的 QT 间期，开发中必须对此加以检验（[[medicinal-chemistry/drug-development]]）。

**转运体**把分子运过膜，本身就是靶点。选择性 5-羟色胺再摄取抑制剂（氟西汀、舍曲林）阻断 5-羟色胺转运体 SERT，提高突触间隙中递质的浓度。SGLT2 抑制剂（列净类）阻断肾脏中的钠-葡萄糖共转运体。主动转运体——ATP 驱动的泵——包括 $\mathrm{Na^+/K^+}$-ATPase（被强心苷地高辛抑制）与胃 $\mathrm{H^+/K^+}$-ATPase（被质子泵抑制剂不可逆抑制）。奥美拉唑是一件巧妙的化学作品：一个弱碱性前药，富集于壁细胞酸性的分泌小管中，质子化在那里触发它重排为活泼的亚磺酰胺，捕获泵上半胱氨酸的巯基。药物只在需要它的地方被活化。

::: quiz
某药物阻断一个靶点，其作用持续数天，尽管药物本身在几小时内就从血浆中消失。哪些解释与此相容？
- [x] 药物共价钝化其靶点，作用持续到新的靶点蛋白被制造出来。
- [ ] 药物的 $K_\mathrm{d}$ 极低，所以游离浓度降为零后占据分数依然很高。
- [x] 药物与其靶点解离极慢（驻留时间长），所以占据滞后于浓度。
- [ ] Cheng–Prusoff 关系使 $\mathrm{IC_{50}}$ 随药物被清除而下降。
::: solution
共价钝化（阿司匹林、质子泵抑制剂）使作用持续时间取决于靶点的再合成；极慢的解离速率常数使游离药物离去后靶点仍被占据，因为在清除的时间尺度上平衡无法重新建立（[[medicinal-chemistry/drug-binding]]）。单凭平衡的 $K_\mathrm{d}$ 做不到这一点：平衡时游离药物为零意味着占据为零，无论 $K_\mathrm{d}$ 多小。Cheng–Prusoff 关系讲的是测定中的底物竞争，与持续时间无关。
:::
:::

## 核酸及其他靶点

DNA 是肿瘤化学治疗中第一个被透彻理解的药物靶点，对它发动打击的方式在化学上有三种。**嵌入剂**——如多柔比星这类平面多环芳香阳离子——滑入相邻碱基对之间，使双螺旋解旋并伸长；多柔比星还把拓扑异构酶 II 困在它与 DNA 的切割复合物中，这大概才是它主要的细胞毒作用。**沟结合剂**是新月形分子，契合 AT 丰富序列的小沟。**共价修饰剂**与碱基上的亲核位点反应，其中鸟嘌呤的 N7 原子亲核性最强。顺铂，*cis*-$[\mathrm{PtCl_2(NH_3)_2}]$，是教科书水平的化学范例：在细胞内氯离子浓度低的环境中，一个氯配体被水取代，水合配离子先结合一个鸟嘌呤的 N7，再结合相邻鸟嘌呤的 N7，形成 1,2-链内交联，使双螺旋出现扭结，并被识别这种损伤的蛋白质触发细胞死亡。*trans* 异构体无法形成这种交联几何，因而无活性——这是早期的证明：立体化学决定药物作用，对无机分子与对有机分子一样。这类药物作用于一切分裂中的细胞，所以它们的核心问题是选择性，而不是效价。

RNA 是日益重要的靶点。许多抗生素结合细菌的核糖体 RNA：氨基糖苷类结合 30S 亚基的解码位点，大环内酯类结合 50S 亚基的出口通道；选择性来自细菌与人类核糖体的差异。利司扑兰（risdiplam）于 2020 年获 FDA 批准治疗脊髓性肌萎缩症，它是一小分子，结合前体 mRNA–剪接体复合物并改变 *SMN2* 基因转录本的剪接方式。寡核苷酸药物靠碱基配对而非形状识别 RNA，将在[[medicinal-chemistry/biologics]]中讨论。

最后，许多重要靶点是**蛋白质-蛋白质相互作用**，其界面大（$1500$–$3000\ \text{Å}^2$）且平坦。它们曾长期被认为不可被小分子成药，但界面往往把结合能量集中在少数几个“热点”残基上。2016 年获批的维奈克拉结合抗凋亡蛋白 BCL-2 的 BH3 结合沟，把它的促凋亡伙伴置换出来；它出自一次基于片段的筛选（[[medicinal-chemistry/hits-and-leads]]）。

## 靶点的选择与验证

在动手做任何化学之前，一个项目必须决定追逐哪个靶点。选错的代价极其高昂：临床期失败的候选药物绝大多数失败于对患者不够有效，这往往意味着错的是靶点而不是分子。

::: algorithm 为一个靶点积累证据 {#algo-validation}
1. **生物学理据。** 弄清靶点在哪里表达、做什么、其活性在疾病中如何改变（组织样品、通路分析）。
2. **人类遗传学证据。** 寻找靶点基因携带功能缺失或功能获得变异的人，以及变异与疾病风险之间的关联。遗传学支持大致使靶点药物在试验中成功的概率翻倍（或更多）（Nelson 等，2015；King 等，2019）。
3. **实验性扰动。** 敲除或削弱靶点（动物基因敲除、RNA 干扰、细胞中 CRISPR 编辑），检验疾病相关表型是否改变。
4. **药理学扰动。** 若有选择性的**工具化合物**或抗体，在细胞与动物模型中测试；检验效应是否随靶点占据而变动。
5. **成药性与安全性。** 评估是否存在合适的口袋（结构、同源物），以及在其表达的一切部位抑制靶点是否可能可以耐受（敲除表型、重要器官中的表达）。
6. **决策。** 权衡证据，并为临床试验定义一个靶点结合与效应之间可测量的联系（生物标志物）。
:::

::: example 由人类遗传学验证的靶点 {#ex-pcsk9}
2003 年，在 LDL 胆固醇极高的法国家族中发现了 *PCSK9* 基因的功能获得突变；2006 年科恩（Jonathan Cohen）、霍布斯（Helen Hobbs）与同事的一项研究显示，携带 *PCSK9* 功能缺失变异的人 LDL 胆固醇比非携带者低约 15–28 %，冠心病风险也低得多。PCSK9 是一种分泌蛋白，结合 LDL 受体并把它导向降解。这些证据对一个阻断 PCSK9 的药物意味着什么？为什么第一个此类药物是抗体而不是小分子？
::: solution
遗传学证据说明了两件任何动物实验都提供不了的事：降低 PCSK9 活性会在人类中降低 LDL，而且终生低活性与良好健康相容（个别人完全没有功能性 PCSK9 却很健康）。于是疗效与安全两方面的论证在药物存在之前就已经完成。然而这个靶点通过 PCSK9 与 LDL 受体之间一片平坦界面上的蛋白质-蛋白质相互作用行事——小分子难以下药，却正是抗体的理想目标，因为抗体以皮摩尔级亲和力结合这样的表位。抗体依洛尤单抗（evolocumab）与阿利西尤单抗（alirocumab）于 2015 年获批，距遗传学发现约十年（[[medicinal-chemistry/biologics]]）。
:::
:::

::: history
受体概念有两位创始人。兰利（John Newport Langley）1905 年研究烟碱与箭毒对肌肉的作用时提出，药物作用于细胞中的“接受物质”；埃尔利希（Paul Ehrlich）从染料、毒素与抗毒素的研究中发展出特异“侧链”即受体的思想，并据此系统搜寻能结合寄生虫而不结合宿主的化学品。他的砷剂洒尔佛散（砷凡纳明，1910）对梅毒有效，是第一个设计出来的化学治疗剂。克拉克（Alfred Joseph Clark）在二十二三十年代至三十年代把质量作用定律用于药物-受体结合，给出[[#prop-occupancy]]的占据理论。多马克（Gerhard Domagk）1935 年发现抗菌染料百浪多息，同年特雷富埃尔夫妇等人在巴斯德研究所证明它经由代谢产物磺胺起效，揭开了抗菌化学治疗的纪元；伍兹（Donald Woods）1940 年证明对氨基苯甲酸可逆转磺胺的作用，这是药物作为抗代谢物的第一个清楚例子。阿奎斯特（Raymond Ahlquist）1948 年把肾上腺素受体分为 α 与 β 两型；布莱克（James Black）在六七十年代设计出 β受体阻滞剂普萘洛尔与 $\mathrm{H_2}$ 拮抗剂西咪替丁，表明可以有意靶向受体亚型；布莱克与埃利恩（Gertrude Elion）、希钦斯（George Hitchings）分享 1988 年诺贝尔生理学或医学奖，后两人曾设计 6-巯基嘌呤与 DHFR 抑制剂甲氧苄啶等抗代谢物。罗森伯格（Barnett Rosenberg）1965 年发现从电极释出的铂化合物能停止细菌细胞分裂，由此引出顺铂。受体药理学的结构时代以 β₂肾上腺素受体与其 G 蛋白复合物的晶体结构（科比尔卡（Brian Kobilka）组，2011）达于顶点；莱夫科维茨（Robert Lefkowitz）与科比尔卡因 GPCR 研究分享 2012 年诺贝尔化学奖。
:::

后面每一章都会取这些靶点之一，对它提出一个化学问题。[[medicinal-chemistry/drug-binding]]解释分子*为什么*结合——$K_\mathrm{d}$ 背后的力与热力学——并定量的区分激动剂与拮抗剂。[[medicinal-chemistry/pharmacokinetics]]追问药物如何达到[[#eq-occupancy]]所要求的靶点处游离浓度。[[medicinal-chemistry/hits-and-leads]]与[[medicinal-chemistry/structure-activity]]展示新靶点的分子如何找到并改进，[[medicinal-chemistry/structure-based-design]]展示靶点的三维结构如何指导设计，[[medicinal-chemistry/drug-case-studies]]则顺着四个药物类别的历史追踪酶与受体。小分子够不着的靶点——表面平坦的胞外蛋白、RNA 序列、根本没有活性部位的蛋白质——是[[medicinal-chemistry/biologics]]的领地。底层的生物化学见[[biochemistry/protein-function]]（结合）、[[biochemistry/enzymes]]（动理学与抑制）与[[biochemistry/carbohydrates-lipids]]（膜与转运）。

::: summary
- 药物靶点是大分子——多为带结合口袋的蛋白质——其功能的改变产生治疗作用；成药性（小分子能结合吗）与验证（调节它有用吗）是两个独立的问题。
- GPCR、离子通道、酶、核受体、转运体与核酸占了已批准药物靶点的几乎全部；约三分之一的药物作用于 GPCR。
- 平衡时分数占据为 $\theta = [\mathrm{L}]/(K_\mathrm{d} + [\mathrm{L}])$，其中 $[\mathrm{L}]$ 为游离浓度；10 % 到 90 % 占据跨越 81 倍的浓度范围。
- 对竞争性抑制剂，$\mathrm{IC_{50}} = K_\mathrm{I}(1 + [\mathrm{S}]/K_\mathrm{M})$：$\mathrm{IC_{50}}$ 是测定条件的属性，不独是分子的属性。
- 不可逆抑制剂以 $k_\mathrm{obs} = k_\mathrm{inact}[\mathrm{I}]/(K_\mathrm{I} + [\mathrm{I}])$ 失活；其作用持续到靶点被重新合成，$k_\mathrm{inact}/K_\mathrm{I}$ 度量其效率。
- 选择性 $S = K_\mathrm{d}(\mathrm{B})/K_\mathrm{d}(\mathrm{A})$ 对应 $\Delta\Delta_\mathrm{b}G^\circ = RT\ln S$，$298\ \mathrm{K}$ 下每十倍 $5.7\ \mathrm{kJ\,mol^{-1}}$。
- 受体信号被放大，所以激动剂的效应与占据不成正比；通道阻滞剂常常状态依赖；许多药物（奥美拉唑、顺铂）在靶点附近被化学活化。
- 人类遗传学证据是最有力的靶点验证形式之一。
:::

## 习题

::: exercise 给定占据所需的浓度 {level=1 check="20"}
某药物以 $K_\mathrm{d} = 5.0\ \mathrm{nmol\,dm^{-3}}$ 结合其靶点。多大的游离浓度给出 80 % 占据？（浓度以 $\mathrm{nmol\,dm^{-3}}$ 输入。）
::: solution
由[[#eq-occupancy]]，$[\mathrm{L}] = K_\mathrm{d}\,\theta/(1-\theta) = 5.0 \times 0.80/0.20 = 20\ \mathrm{nmol\,dm^{-3}}$，即四倍 $K_\mathrm{d}$。
:::
:::

::: exercise 从半拥占到几乎全占据 {level=1 check="19"}
要把某药物靶点的占据分数从 50 % 提高到 95 %，游离浓度必须提高多少倍？（输入倍数。）
::: solution
由于 $\theta/(1-\theta) = [\mathrm{L}]/K_\mathrm{d}$，浓度正比于 $\theta/(1-\theta)$。50 % 时该比值为 1；95 % 时为 $0.95/0.05 = 19$。浓度须提高十九倍，与 $K_\mathrm{d}$ 取何值无关。
:::
:::

::: exercise 高底物下的测定 {level=1 check="110"}
某竞争性抑制剂对 $K_\mathrm{M} = 0.10\ \mathrm{mmol\,dm^{-3}}$ 的酶的 $K_\mathrm{I} = 10\ \mathrm{nmol\,dm^{-3}}$。在 $[\mathrm{S}] = 1.0\ \mathrm{mmol\,dm^{-3}}$ 下进行的测定中，测得的 $\mathrm{IC_{50}}$ 是多少？（$\mathrm{IC_{50}}$ 以 $\mathrm{nmol\,dm^{-3}}$ 输入。）
::: solution
由[[#eq-cheng]]，$\mathrm{IC_{50}} = 10(1 + 1.0/0.10) = 10 \times 11 = 110\ \mathrm{nmol\,dm^{-3}}$。在十倍于 $K_\mathrm{M}$ 的测定中做实验，抑制剂显得比它的 $K_\mathrm{I}$ 弱十一倍。
:::
:::

::: exercise 选择性的窗口 {level=2 check="16.6"}
某激酶抑制剂对其靶点的 $K_\mathrm{d} = 0.50\ \mathrm{nmol\,dm^{-3}}$，对一个相关激酶的 $K_\mathrm{d} = 400\ \mathrm{nmol\,dm^{-3}}$。(a) 游离浓度为 $5.0\ \mathrm{nmol\,dm^{-3}}$ 时，两种激酶各被占据几分之几？(b) 在 $298.15\ \mathrm{K}$ 下把选择性表达为 $\Delta\Delta_\mathrm{b}G^\circ$。（$\Delta\Delta_\mathrm{b}G^\circ$ 以 $\mathrm{kJ\,mol^{-1}}$ 输入，保留三位有效数字。）
::: solution
(a) 靶点：$\theta = 5.0/(0.50 + 5.0) = 0.909$。相关激酶：$\theta = 5.0/(400 + 5.0) = 0.0123$。这一浓度下靶点被占据 91 %，脱靶蛋白仅 1.2 %。

(b) $S = 400/0.50 = 800$，故 $\Delta\Delta_\mathrm{b}G^\circ = RT\ln S = (8.314)(298.15)\ln 800\ \mathrm{J\,mol^{-1}} = 16.6\ \mathrm{kJ\,mol^{-1}}$——略不到三个十倍，每个十倍值 $5.71\ \mathrm{kJ\,mol^{-1}}$。
:::
:::

::: exercise 信号级联的放大 {level=2 check="1000000"}
β肾上腺素受体通路的一个简化模型中，一个被激动剂占据的受体在脱敏之前激活 20 个 $\mathrm{G_s}$ 蛋白；每个 $\mathrm{G_s}$ 激活一个腺苷酸环化酶，后者活动期间制造 100 个 cAMP 分子；四个 cAMP 分子释放一个 PKA 全酶的两个催化亚基；每个催化亚基磷酸化 1000 个底物分子。一个被占据的受体会带来多少次底物磷酸化？（输入数值。）
::: solution
cAMP 制造量：$20 \times 100 = 2000$。激活的 PKA 全酶：$2000/4 = 500$，释放 $500 \times 2 = 1000$ 个催化亚基。磷酸化数：$1000 \times 1000 = 1.0\times10^{6}$。有了百万倍的放大，只被激动剂占据一小部分受体就能使下游反应饱和，这就是激动剂的 $\mathrm{EC_{50}}$ 常远低于其 $K_\mathrm{d}$ 的原因（[[medicinal-chemistry/drug-binding]]）。
:::
:::

::: exercise 局部麻醉药与组织 pH {level=2 check="0.24"}
利多卡因是叔胺，其共轭酸的 $\mathrm{p}K_\mathrm{a} = 7.9$。只有中性碱能穿越神经膜。计算 pH 7.4 以及 pH 6.9（发炎组织的典型值）下以中性碱形式存在的分数。解释为什么局部麻醉药在发炎组织中效果较差。（pH 7.4 的分数保留两位有效数字。）
::: solution
对碱 B 与其共轭酸 $\mathrm{BH^+}$，亨德森-哈塞尔巴尔赫方程给出 $[\mathrm{B}]/[\mathrm{BH^+}] = 10^{\mathrm{pH} - \mathrm{p}K_\mathrm{a}}$，故中性分数为 $1/(1 + 10^{\mathrm{p}K_\mathrm{a} - \mathrm{pH}})$。pH 7.4：$1/(1 + 10^{0.5}) = 1/(1 + 3.16) = 0.24$。pH 6.9：$1/(1 + 10^{1.0}) = 0.091$。酸性组织把可透膜的分数削减约 2.6 倍，于是到达轴突内部——阳离子在那里阻断钠通道——的药物减少。同一药物需要中性形式来行路、带电形式来作战——这是[[medicinal-chemistry/pharmacokinetics]]反复出现的主题。
:::
:::

::: exercise 靶点的归类 {level=2}
对每种药物，说出靶点家族，并指出该药物是激动剂、拮抗剂、调节剂、抑制剂还是阻滞剂：(a) 普萘洛尔；(b) 奥美拉唑；(c) 苯二氮䓬类；(d) 顺铂；(e) 乳腺组织中的他莫昔芬；(f) 利多卡因。
::: solution
(a) GPCR（β肾上腺素受体）：竞争性拮抗剂。(b) 转运体——胃 $\mathrm{H^+/K^+}$-ATPase，一种主动泵——经酸活化后被不可逆抑制。(c) 配体门控离子通道（$\mathrm{GABA_A}$ 受体）：在有别于 GABA 位点的位点上的正别构调节剂。(d) DNA，核酸靶点：共价交联剂。(e) 核受体（雌激素受体）：在乳腺组织中为拮抗剂（整体上是选择性调节剂，他处有部分激动作用）。(f) 电压门控离子通道（钠通道）：使用依赖性孔道阻滞剂。
:::
:::

::: exercise 共价失活的动力学 {level=3 check="1150"}
某靶向共价抑制剂 $k_\mathrm{inact} = 4.0\times10^{-3}\ \mathrm{s^{-1}}$。在抑制剂浓度等于 $K_\mathrm{I}$ 时，灭活 90 % 的酶需要多久？若浓度升到 $9K_\mathrm{I}$，时间如何变化？（第一个时间以秒输入，保留三位有效数字。）
::: hint
由[[#eq-kobs]]求 $k_\mathrm{obs}$，再解 $e^{-k_\mathrm{obs}t} = 0.10$。
:::
::: solution
$[\mathrm{I}] = K_\mathrm{I}$ 时，$k_\mathrm{obs} = k_\mathrm{inact}/2 = 2.0\times10^{-3}\ \mathrm{s^{-1}}$。令 $e^{-k_\mathrm{obs}t} = 0.10$ 得 $t = \ln 10/k_\mathrm{obs} = 2.303/(2.0\times10^{-3}) = 1.15\times10^{3}\ \mathrm{s}$，即 $1150\ \mathrm{s}$，约 19 分钟。$9K_\mathrm{I}$ 时 $k_\mathrm{obs} = 0.9\,k_\mathrm{inact} = 3.6\times10^{-3}\ \mathrm{s^{-1}}$，$t = 640\ \mathrm{s}$。浓度增加九倍，时间只缩短 1.8 倍，因为在 $K_\mathrm{I}$ 处可逆复合物已半饱和，化学步骤 $k_\mathrm{inact}$ 给速率封顶。
:::
:::

::: exercise 反竞争性抑制剂的 IC₅₀ {level=3}
某反竞争性抑制剂只结合酶-底物复合物，解离常数为 $K_\mathrm{I}'$，故 $v_i = V_\mathrm{max}[\mathrm{S}]/(K_\mathrm{M} + [\mathrm{S}](1 + [\mathrm{I}]/K_\mathrm{I}'))$。把它作为 $[\mathrm{S}]$ 的函数导出其 $\mathrm{IC_{50}}$，并与[[#eq-cheng]]比较对底物浓度的依赖。对底物在酶被抑制时会积累的酶，反竞争性抑制剂为何可能有吸引力？
::: hint
令 $v_i = v_0/2$，其中 $v_0 = V_\mathrm{max}[\mathrm{S}]/(K_\mathrm{M} + [\mathrm{S}])$，解出 $[\mathrm{I}]$。
:::
::: solution
令 $v_i = v_0/2$ 并约去 $V_\mathrm{max}[\mathrm{S}]$：$K_\mathrm{M} + [\mathrm{S}](1 + [\mathrm{I}]/K_\mathrm{I}') = 2K_\mathrm{M} + 2[\mathrm{S}]$，故 $[\mathrm{S}][\mathrm{I}]/K_\mathrm{I}' = K_\mathrm{M} + [\mathrm{S}]$，得
$$
\mathrm{IC_{50}} = K_\mathrm{I}'\left(1 + \frac{K_\mathrm{M}}{[\mathrm{S}]}\right).
$$
其依赖关系恰是竞争性情形的镜像：底物升高时反竞争性抑制剂*更*有效，在饱和底物下趋于 $K_\mathrm{I}'$；竞争性抑制剂则变弱。若抑制一条途径中的酶会使其底物积累（被阻断步骤的上游常常如此），竞争性抑制剂会被逐步挤出去，而反竞争性抑制剂反增效力——这就是有人说反竞争性抑制是作用于代谢途径的药物中最有效方式的原因。
:::
