电子天平稳定下来，显示 $0.5106\ \mathrm{g}$。在把它抄进实验记录本之前，先问一问：最后一位数字声称了什么？它声称这台天平能把这个物体与轻 $0.0001\ \mathrm{g}$ 的物体、以及重 $0.0001\ \mathrm{g}$ 的物体区分开——而厂家说明书说，读数可能有多达 $\pm 0.0002\ \mathrm{g}$ 的误差，所以诚实的表述不是"质量是 $0.5106\ \mathrm{g}$"，而是"质量落在以 $0.5106\ \mathrm{g}$ 为中心的某个区间内，而这个区间大约有 $0.0004\ \mathrm{g}$ 宽"。**任何测量都不是一个点；任何测量都是一个以最可能值为中心的区间。**本章的一切，都源于认真对待这句话。如果测量是一个区间，那么计算就是区间算术，结果就是一个区间，而一份把区间藏起来的报告——无论是抄下计算器打印的每一位数字，还是只给平均值却不给它的分散度——丢弃信息之彻底，不亚于一个贴错标签的试剂瓶。

这套词汇不多却讲究，而且被滥用的频率极高，报纸上如此，实验报告里也如此。日常语言里"准确"和"精确"几乎是同义词；在实验台上它们指两种不同的性质，一个测量可以只具备其一。本章把两者分开，建立重复测量与有效数字的算术，并推导传递规则，使一个多步骤的配制从称量到最后的稀释都保持诚实。这些不是为了让习题集显得繁琐而强加的记账规则；它们是阻止一个建立在两位测量上的十位数字答案骗过任何人——首先是你自己——的那套机器。

## 准确度、精密度与两类误差

::: definition 准确度与精密度 {#def-accuracy-precision}
**准确度**是测量值与真值的接近程度；它的对立面是**系统误差**（偏倚），一种可重现的偏移，把每次测量都朝同一方向挪动。**精密度**是重复测量彼此之间的接近程度；它的对立面是**随机误差**，单次读数围绕其平均值的不可预言的分散。准确度用大量测量的平均值与真值之差来量化；精密度用重复测量自身的标准偏差来量化。一个方法可以精密而不准确、准确而不精密、两者兼备，或两者皆无——四种组合确实是不同的情形，各有不同的对策。
:::

传统的图景是飞镖靶。紧紧聚集在靶心周围的投掷既准确又精密。紧紧聚集在偏离中心处的投掷——角落里整齐的一堆——精密而不准确：投掷者是稳定的，而且稳定地错着，这正是系统误差所做的事。均匀散布在靶心四周的投掷平均而言是准确的，但不精密：单次读数很差，但它们会相互抵消。散布在远离中心处的投掷两者皆非，任何算术都救不了它们。

在实验台上，随机误差是天平末位数字的闪动，是你不同日子读滴定管时弯月面落在刻度线上方或下方的一小格，是天平盘旁掠过的一缕气流，是星期二高了两度的室温。这类误差正负机会相同，对单次读数不遵循任何你可以预言的图样，而且——这是它们的可救之处——取平均时会部分抵消。随机误差决定你的**精密度**，而重复是它唯一的对策。

系统误差则完全是另一回事。一台未校准的天平，每次称量都偏高 $1.0000\ \mathrm{g}$；一支 $25.00\ \mathrm{cm^3}$ 移液管，实际放出 $25.10\ \mathrm{cm^3}$；滴定管尖里困着一个气泡，使每次读出的体积偏大；一种变色点落在化学计量点之外一个 pH 单位的指示剂。每次读数都被朝同一方向挪动大致相同的量。这些读数彼此之间可以吻合得极漂亮——它们只是一致地吻合在一个错误的数字上。

::: warning 重复测量永远暴露不了系统误差 {#warn-precision-not-accuracy}
对一支校准很差的移液管，五次精密的读数就是五个精密的错误数字。取平均缩小随机误差，对系统误差分毫不动：每次放出 $+0.10\ \mathrm{cm^3}$ 的偏倚，在一百次重复之后依然和一次之后一样大，而有偏读数的平均值与单次读数一样偏——只是偏得更自信。标准偏差极小并不证明测量正确；它只证明仪器稳定，这是两回事。猎取系统误差要用别的手段：用有证标准砝码校准天平，用称量移液管所放水的质量来校准移液管，做试剂空白以发现杂质，分析真实含量已知的有证标准物质，或用一种独立方法了结有争议的结果。精密度由重复确立；准确度只能由与更好事物的比较确立。
:::

## 重复测量：平均值与其分散度

当随机误差是限制所在，办法就是重复测量，让统计发挥作用。

::: definition 平均值、标准偏差与相对标准偏差 {#def-mean-sd}
对 $n$ 次重复测量 $x_1, x_2, \ldots, x_n$，**平均值**为
$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i ,
$$
**样本标准偏差**为
$$
s = \sqrt{\frac{\sum_{i=1}^{n}\left(x_i - \bar{x}\right)^2}{n-1}} .
$$
分母出现 $n-1$（自由度），是因为偏差是从同一组数据拟合出的平均值量起的，这用掉了一个自由度；用 $n-1$，估计才是无偏的。**相对标准偏差**（RSD，或变异系数）是 $s/\bar{x}$，通常以百分数报出——它说出分散度占信号的几分之几，也是在不同大小的测量之间作比较时应当看的数。
:::

对分散的测量，标准偏差扮演着典型误差的角色：如果分散大致对称、呈钟形——即**正态分布**，许多小的独立原因相加时你得到的就是它——那么约 $68\ \%$ 的单次读数落在平均值一个标准偏差之内，约 $95\ \%$ 落在两个之内。所以报告值 $\bar{x} \pm s$ 声称"一次新读数约三次中有两次落在此区间内"，$\bar{x} \pm 2s$ 声称"约二十次中有十九次"。

::: proposition 平均值的标准不确定度 {#prop-sem}
若 $n$ 次重复测量是来自同一分布（标准偏差为 $\sigma$）的独立抽样，则**平均值的标准不确定度**为
$$
u(\bar{x}) = \frac{\sigma}{\sqrt{n}} \approx \frac{s}{\sqrt{n}} .
$$
四次读数的平均值，其不确定度只有单次读数的一半；一百次的平均值只有其十分之一：改善以工作量的平方根到来，这就是化学家做五次重复而不做五十次的原因。
:::

::: proof 独立读数的方差相加 {#proof-sem}
对独立随机变量，方差相加：$\mathrm{Var}(x_1 + x_2) = \mathrm{Var}(x_1) + \mathrm{Var}(x_2)$，因为变量之间没有共同模式时协方差项为零。把这一点用于平均值，并把常数因子 $1/n$ 提到方差号外（它以平方 $1/n^2$ 留下）：
$$
\mathrm{Var}(\bar{x}) = \mathrm{Var}\!\left(\frac{1}{n}\sum_{i=1}^{n} x_i\right) = \frac{1}{n^2}\sum_{i=1}^{n}\mathrm{Var}(x_i) = \frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}.
$$
开方即得平均值的标准偏差 $\sigma/\sqrt{n}$，再以测得的 $s$ 代替未知的 $\sigma$，就得到 $u(\bar{x}) = s/\sqrt{n}$。第一步里藏着两条告诫。其一，它要求*独立*：共享一台漂移的仪器或一个重复的个人习惯的读数是相关的，协方差项不会消失，平均它们所消除的分散比公式承诺的少。其二，它对偏倚只字未提——整个推导处理的只是数据所处平均值（无论对错）周围的分散。
:::

::: widget distribution
dist: normal
params: mu=25.00, sigma=0.03
a: 24.94
b: 25.06
caption: 移液管反复放出 $25\ \mathrm{cm^3}$ 体积，读数就像这条正态曲线一样围绕平均值分散，标准偏差为 $0.03\ \mathrm{cm^3}$。从 $24.94$ 到 $25.06\ \mathrm{cm^3}$ 的阴影带是 $\pm 2\sigma$ 区间，包含约 $95\ \%$ 的读数——一次新读数落在带外虽有可能，但并不常见。让目光扫过两条尾巴，注意三个标准偏差之外几乎没有概率生存：这就是一次读数比它的同伴偏离五个 $s$ 时值得起疑的原因。
:::

::: example 平均值、标准偏差与平均值的不确定度 {#ex-burette-stats}
一名学生把一支 $25\ \mathrm{cm^3}$ 移液管五次排空到已去皮的小烧杯中并称量水，得到放出体积 $24.98$、$25.02$、$24.97$、$25.03$ 和 $24.95\ \mathrm{cm^3}$。报告平均值及其标准偏差、相对标准偏差和平均值的标准不确定度。
::: solution
平均值是
$$
\bar{x} = \frac{24.98 + 25.02 + 24.97 + 25.03 + 24.95}{5} = \frac{124.95}{5} = 24.99\ \mathrm{cm^3}.
$$
与平均值的偏差为 $-0.01$、$+0.03$、$-0.02$、$+0.04$、$-0.04\ \mathrm{cm^3}$；它们的平方为 $0.0001$、$0.0009$、$0.0004$、$0.0016$、$0.0016$，总和为 $0.0046\ \mathrm{cm^6}$。于是
$$
s = \sqrt{\frac{0.0046}{5-1}} = \sqrt{0.00115} = 0.034\ \mathrm{cm^3},
\qquad
\mathrm{RSD} = \frac{0.034}{24.99} = 0.0014 = 0.14\ \%.
$$
平均值的标准不确定度为
$$
u(\bar{x}) = \frac{s}{\sqrt{n}} = \frac{0.034}{\sqrt{5}} = \frac{0.034}{2.236} = 0.015\ \mathrm{cm^3}.
$$
把移液管的放出体积报为 $24.99 \pm 0.02\ \mathrm{cm^3}$（平均值的标准不确定度，$n = 5$）。读一读这些数字：$s = 0.034\ \mathrm{cm^3}$ 正是一支 A 级移液管应有的水平，所以学生是在量器的极限上工作，而不是在糟蹋它；而平均值比任何单次放出都可信，这正是做五次称量的全部理由。
:::
:::

## 有效数字

在不确定度预算出现之前，有一种更粗糙的速记，而它至今仍是实验台会话的语言：有效数字。

::: definition 有效数字 {#def-sig-figs}
**有效数字**是一个测量数中对它的量级携带真实信息的数字：
- 非零数字总是有效的：$2.54$ 有三位。
- 夹心零——夹在两个非零数字之间的零——是有效的：$2.004$ 有四位。
- 前导零从不有效——它们只负责定位小数点：$0.0025$ 有两位。
- 小数点右边的末尾零是有效的：$2.500$ 有四位，并且比 $2.5$ 声称了更多信息。
- 整数中的末尾零是有歧义的：$1500$ 可能表示两位、三位或四位有效数字。写 $1.5\times10^{3}$ 或 $1.500\times10^{3}$，把你想说的说明白。
**精确数**——事物的计数、像 $1000\ \mathrm{mg} = 1\ \mathrm{g}$ 这样的定义、以及化学计量系数——不携带不确定度，从不限制结果的位数；参见[[general-chemistry-1/stoichiometry]]中精确的计数数字。
算术规则：**乘法与除法**，结果所带的有效数字与有效数字最少的因子相同；**加法与减法**，结果所带的小数位数与最不精确的项相同。
:::

这两条规则并非任意：它们是下一节传递规则的粗糙形态。乘以一个在第三位就不确定的因子，不会让你对乘积的第四位有把握；加上一个在个位就不确定的数，不会让你对和的百分位有把握。像 $0.5106\ \mathrm{g}$（四位）这样的测量携带量级为五千分之一的相对不确定度，而 $0.5\ \mathrm{g}$（两位）携带量级约十分之一——位数是相对不确定度的粗糙代理，这正是它按乘法方式表现的原因。

::: example 有效数字运算与舍入链 {#ex-sig-fig-arithmetic}
把每个结果取到正确的位数：(a) $0.06017 \times 5.1234$；(b) $25.00 + 0.2342$；(c) $25.00 \times 0.1025$；在 (c) 中只在最后舍入一次。
::: solution
(a) $0.06017$ 有四位（前导零不计），$5.1234$ 有五位，所以乘积取四位：$0.06017 \times 5.1234 = 0.30827498\ldots$，报为 $0.3083$。
(b) 加法按小数位数运作：$25.00$ 精确到百分位，$0.2342$ 精确到万分位，所以和只精确到百分位：$25.00 + 0.2342 = 25.2342$，报为 $25.23$。
(c) 两个因子都有四位，所以乘积取四位。精确乘积是 $2.5625$——第五位是一个恰好的平局。计算器与统计学家使用的"四舍六入五成双"约定给出 $2.562$；较旧的"逢五进一"规则给出 $2.563$。两者都说得通，而争论本身就是教训：有争议的数字是最后一位，它本来就不确定。说不通的是把舍入连成链——$2.5625 \to 2.563 \to 2.56$——因为每一次中间舍入都犯下一个你随后当作事实的错误。让计算器给出的所有数字通过中间步骤，只在最后舍入一次，那时你已经知道哪一位是最后一位诚实的数字。
:::
:::

::: warning 计算器不能替你决定有效数字 {#warn-calculator-digits}
计算器为你的滴定计算打印出 $0.10254672897$，并没有使结果达到十位准确；它只是显示了十个数字，这是两回事。第三、四位之后的数字是对噪声做算术。纪律有三条。**只在最后舍入一次**——中间舍入会累积，并能挪动最后一位。让**不确定度而不是计算器决定最后一位有效数字**：把不确定度报在它第一个不确定的数字上，并把数值舍入到与之对齐，于是 $c = 0.102547 \pm 0.00003\ \mathrm{mol\,dm^{-3}}$ 写成 $(1.02547 \pm 0.00003) \times 10^{-1}$，$24.99 \pm 0.015\ \mathrm{cm^3}$ 写成 $24.99 \pm 0.02\ \mathrm{cm^3}$。还有，结果永远不要报得比产生它的最差一步更精——由两位天平读数算出的产率就是两位产率，无论电子表格显示多少位。
:::

::: quiz
数 $0.05060$ 包含多少位有效数字？
- [ ] 三位——末尾的零只是占位符，小数点后的零从不计数。
- [x] 四位——数字 5、0、6 和末尾的 0 是有效的；两个前导零只负责定位小数点。
- [ ] 五位——除最前面的零以外，每个数字都计数。
- [ ] 六位——写下来的每个数字都计数，前导零也包括在内。
::: solution
四位。前导零从不有效：它们只定位小数点，而 $5.060\times10^{-2}$ 是同一个测量、同样的四位。夹在 5 与 6 之间的夹心零是有效的，而末尾的零恰恰*因为*被写下来才是有效的：它声称读数做到了小数点后第四位，所以 $0.05060$ 是比 $0.0506$ 更精确的陈述。这就是为什么科学计数法是书写带歧义零的数的诚实方式——位数一眼可见。
:::
:::

## 不确定度的传递

真实的结果同时由多个测量构成：浓度来自质量和体积，稀释来自储备液和两件量器。每个输入是一个区间，问题是输出区间有多宽。答案取决于输入是否独立，而标准的工作假设是它们独立。

::: proposition 不确定度传递规则 {#prop-propagation}
设 $z$ 由带标准不确定度 $u_x$、$u_y$ 的独立测量量 $x$、$y$ 构成。
- **和或差**，$z = x + y$ 或 $z = x - y$。最坏情形：$u_z = u_x + u_y$。独立随机误差按平方和开方（方和根）合成：
$$
u_z = \sqrt{u_x^2 + u_y^2}.
$$
- **积或商**，$z = xy$ 或 $z = x/y$。最坏情形：相对不确定度相加。按平方和开方：
$$
\left(\frac{u_z}{z}\right)^2 = \left(\frac{u_x}{x}\right)^2 + \left(\frac{u_y}{y}\right)^2 .
$$
- **幂**，$z = x^{n}$：相对不确定度乘以 $|n|$：$u_z/z = |n|\,u_x/x$。
- **常用对数**，$z = \log x$：$z$ 的绝对不确定度是 $x$ 的相对不确定度除以 $\ln 10$：
$$
u_z = \frac{1}{\ln 10}\,\frac{u_x}{x}.
$$
平方和开方是独立随机误差的正确合成方式，因为方差相加；最坏情形相加是故意的过高估计，对安全裕度有用，误差相关时必须使用（比如在同一支校准很差的滴定管上读出的两个体积）。日常工作用平方和开方。注意这些规则造成的不对称：对和，要紧的是*绝对*不确定度，所以把 $25.00 \pm 0.03$ 与 $0.5 \pm 0.1$ 相加时受粗项限制；对积，要紧的是*相对*不确定度，所以一个小质量上 $1\ \%$ 的不确定度可以压过大体积上 $0.1\ \%$ 的不确定度。
:::

::: proof 由一阶泰勒展开导出乘积规则 {#proof-product-rule}
设 $z = f(x, y)$，每个输入带一个小的随机误差，于是
$$
\delta z \approx \frac{\partial z}{\partial x}\,\delta x + \frac{\partial z}{\partial y}\,\delta y .
$$
把它平方，并对实验的许多次重复取平均。平方项平均为方差，交叉项 $\overline{\delta x\,\delta y}$ 平均为零，因为独立误差配上正伙伴与配上负伙伴的机会相同：
$$
u_z^2 = \left(\frac{\partial z}{\partial x}\right)^2 u_x^2 + \left(\frac{\partial z}{\partial y}\right)^2 u_y^2 .
$$
对 $z = xy$，偏导数为 $\partial z/\partial x = y$、$\partial z/\partial y = x$，所以 $u_z^2 = y^2 u_x^2 + x^2 u_y^2$。除以 $z^2 = x^2 y^2$：
$$
\left(\frac{u_z}{z}\right)^2 = \left(\frac{u_x}{x}\right)^2 + \left(\frac{u_y}{y}\right)^2 ,
$$
这就是乘积规则。对 $z = x/y$，写 $z = x\,y^{-1}$：偏导数是 $1/y$ 与 $-x/y^2$，平方消去负号，所以商的传递与积完全相同。对 $z = x^n$，$\mathrm{d}z/\mathrm{d}x = n\,x^{n-1}$ 给出 $u_z = |n|\,x^{n-1}u_x$；除以 $x^n$ 得 $u_z/z = |n|\,u_x/x$。对 $z = \log_{10} x$，$\mathrm{d}z/\mathrm{d}x = 1/(x\ln 10)$ 立即给出对数规则——这就是为什么 pH 的小数部分携带氢离子浓度的*相对*不确定度：$[\mathrm{H^+}]$ 上 $2\ \%$ 的不确定度变成 pH 上 $0.02/\ln 10 = 0.009$。和规则是 $z = x \pm y$ 的特例，其偏导数为 $\pm 1$。整个构造是一阶的：它假设不确定度与量本身相比很小（几个百分点），对不确定得厉害的输入它会失效。
:::

::: example 稀释配制标准溶液的不确定度 {#ex-dilution-propagation}
一名学生用移液管把 $25.00\ \mathrm{cm^3}$ 的 $0.1000\ \mathrm{mol\,dm^{-3}}$ 储备液移入 $250.0\ \mathrm{cm^3}$ 容量瓶，稀释至刻度。取 $u(V_\mathrm{pip}) = 0.03\ \mathrm{cm^3}$、$u(V_\mathrm{flask}) = 0.12\ \mathrm{cm^3}$、$u(c_\mathrm{stock}) = 0.0002\ \mathrm{mol\,dm^{-3}}$。稀标准溶液的浓度及其不确定度是多少？
::: solution
浓度为 $c = c_\mathrm{stock}\,V_\mathrm{pip}/V_\mathrm{flask} = 0.1000 \times 25.00/250.0 = 0.01000\ \mathrm{mol\,dm^{-3}}$。这是积与商，所以相对不确定度按平方和开方合成：
$$
\frac{u_c}{c} = \sqrt{\left(\frac{0.0002}{0.1000}\right)^2 + \left(\frac{0.03}{25.00}\right)^2 + \left(\frac{0.12}{250.0}\right)^2} = \sqrt{(2.0\times10^{-3})^2 + (1.2\times10^{-3})^2 + (4.8\times10^{-4})^2}.
$$
三个平方为 $4.0\times10^{-6}$、$1.44\times10^{-6}$、$0.23\times10^{-6}$；其和为 $5.67\times10^{-6}$，所以 $u_c/c = 2.38\times10^{-3}$，即 $0.24\ \%$。于是
$$
u_c = 0.01000 \times 2.38\times10^{-3} = 0.000024\ \mathrm{mol\,dm^{-3}},
$$
标准溶液为 $c = (1.000 \pm 0.002) \times 10^{-2}\ \mathrm{mol\,dm^{-3}}$。这份预算值得在合上记录本之前读一遍：储备液贡献方差的 $71\ \%$，移液管 $25\ \%$，容量瓶只有 $4\ \%$。如果这个浓度要紧，重新校准容量瓶将一无所获；该改进的地方是储备液。
:::
:::

::: example 不确定度预算：哪一步占主导？ {#ex-uncertainty-budget}
为配制 $2.00\times10^{-3}\ \mathrm{mol\,dm^{-3}}$ 的邻苯二甲酸氢钾溶液，一名学生用移液管把 $5.00\ \mathrm{cm^3}$ 的 $0.1000\ \mathrm{mol\,dm^{-3}}$ 储备液移入 $250.0\ \mathrm{cm^3}$ 容量瓶。不确定度：移液管 $u = 0.01\ \mathrm{cm^3}$，容量瓶 $u = 0.12\ \mathrm{cm^3}$，储备液 $u = 0.00005\ \mathrm{mol\,dm^{-3}}$。建立预算，并说出你会改变什么。
::: solution
相对不确定度：储备液 $0.00005/0.1000 = 5.0\times10^{-4}$；移液管 $0.01/5.00 = 2.0\times10^{-3}$；容量瓶 $0.12/250.0 = 4.8\times10^{-4}$。按平方和开方，
$$
\frac{u_c}{c} = \sqrt{(5.0\times10^{-4})^2 + (2.0\times10^{-3})^2 + (4.8\times10^{-4})^2} = \sqrt{0.25\times10^{-6} + 4.0\times10^{-6} + 0.23\times10^{-6}} = 2.1\times10^{-3},
$$
所以 $u_c = 2.00\times10^{-3} \times 2.1\times10^{-3} = 4.2\times10^{-6}\ \mathrm{mol\,dm^{-3}}$，$c = (2.000 \pm 0.004)\times10^{-3}\ \mathrm{mol\,dm^{-3}}$。方差的份额是移液管 $89\ \%$、容量瓶 $5\ \%$、储备液 $6\ \%$：$5.00\ \mathrm{cm^3}$ 的移液管就是全部问题所在，恰如 $1/V$ 曲线所预言——小体积的放出要付出大的相对代价。其余各项合起来只贡献移液管方差的八分之一，所以改进容量瓶或储备液是白费力气。办法是不要再放小体积：如果化学允许，改称量这份试液——$5\ \mathrm{cm^3}$ 溶液约 $5\ \mathrm{g}$，而称准到 $\pm 0.0003\ \mathrm{g}$ 的 $5\ \mathrm{g}$ 只有 $0.006\ \%$ 的相对不确定度，比移液管好三十倍。重量法稀释（称量，而不是量取）正是分析实验室配制稀标准溶液的实际做法。
:::
:::

## 数字从何而来：允差

传递规则告诉你如何合成不确定度；它们没有告诉你不确定度*是*多少。来源有两个。如果可以重复测量，它的分散直接给出 $s$，而 $s/\sqrt{n}$ 给出平均值的不确定度。但并非总能重复——一次 A 级移液管的放出就是它本来的样子——这时数字来自厂家的**允差**：量器或仪器经检定合格所允许显示的最大偏差。A 级允差（例如 Harris《定量化学分析》（Quantitative Chemical Analysis））包括：$25\ \mathrm{cm^3}$ 单标线移液管 $\pm 0.03\ \mathrm{cm^3}$，$250\ \mathrm{cm^3}$ 容量瓶 $\pm 0.12\ \mathrm{cm^3}$，$50\ \mathrm{cm^3}$ 滴定管全量程放出 $\pm 0.05\ \mathrm{cm^3}$；分析天平通常为 $\pm 0.0002\ \mathrm{g}$。B 级量器大约松一倍，而教学实验室的量器常常两者都不是。

允差是一个极限，不是标准偏差：真实体积在 $[-t, +t]$ 这个盒子内的某处，盒内各处并无优劣之分。这是一个**矩形（均匀）分布**，而对矩形分布，标准偏差——标准不确定度——是允差除以 $\sqrt{3}$。一个在 $\pm 0.03\ \mathrm{cm^3}$ 内各处等可能的读数，其 $u = 0.03/\sqrt{3} = 0.017\ \mathrm{cm^3}$。当你确实预期误差围绕零聚成钟形——对同一体积的重复读数——就按正态处理并使用 $s$；当你只知道一个极限，就除以 $\sqrt{3}$。天平还值得多一分小心：差减称量用到两次读数（毛重与净重），两个独立的不确定度按平方和开方合成，$\sqrt{2} \times 0.0002/\sqrt{3} = 0.0002\ \mathrm{g}$——这就是"称出一克左右"成为好建议的原因：$0.0002\ \mathrm{g}$ 是 $1\ \mathrm{g}$ 的 $0.02\ \%$，却是 $0.025\ \mathrm{g}$ 的 $0.8\ \%$。

::: example 从允差到标准不确定度 {#ex-tolerance-to-uncertainty}
把一支 $25.00\ \mathrm{cm^3}$ A 级单标线移液管的允差 $\pm 0.03\ \mathrm{cm^3}$ 换算成标准不确定度和相对标准不确定度。与把允差本身当作不确定度的做法作比较。
::: solution
对矩形分布，
$$
u(V) = \frac{0.03}{\sqrt{3}} = 0.017\ \mathrm{cm^3},
\qquad
\frac{u(V)}{V} = \frac{0.017}{25.00} = 6.9\times10^{-4} = 0.069\ \%.
$$
把允差直接当作 $u$ 则给出 $0.03/25.00 = 0.12\ \%$——保守了 $\sqrt{3}$ 倍，是想要一个快速而安全的数字时常见的实验台约定。无论哪种方式，结论都相同，而且值得大声说出来：一次 $25\ \mathrm{cm^3}$ 放出的不确定度出现在体积的*第三*位有效数字上，所以建立在一次这样的放出之上的滴定结果不能诚实地携带四位数字。滴定管讲的是同一个故事：其全量程允差 $\pm 0.05\ \mathrm{cm^3}$ 是 $50\ \mathrm{cm^3}$ 的 $0.1\ \%$，却是 $5\ \mathrm{cm^3}$ 的 $1\ \%$——在化学允许的范围内，尽量多用滴定管的量程。
:::
:::

::: history
误差统计理论源于天文学与大地测量学，而非化学，它是靠继承到达实验台的。十八世纪五十年代，博斯科维奇（Roger Boscovich）在调和关于木星轨道的矛盾观测时，迈尔（Tobias Mayer）在对月球观测数据分组取平均时，发表了从互相矛盾的观测中提炼单一最佳值的最早系统方案——博斯科维奇以残差绝对值之和最小为准的法则，预告了我们今天所说的稳健拟合。勒让德（Legendre）在 1805 年把现代方法公之于世：选取使误差*平方*之和最小的值，即最小二乘，刊于《确定彗星轨道的新方法》（Nouvelles méthodes pour la détermination des orbites des comètes）的寥寥数页之中。高斯（Gauss）声称拥有优先权，并在 1809 年给出了深刻的理由：若误差服从正态分布，最小二乘值就是最概然值——把这套做法与本章 $\pm 2s$ 区间所假定的钟形曲线拴在一起。十九世纪的物理实验室从天文学家那里继承了加权平均、剔除可疑读数与引用或然误差的一整套做法。最后一步是行政性的，它改变了每一座分析实验室的日常：1993 年，一个国际计量机构委员会发表了《测量不确定度表示指南》（Guide to the Expression of Uncertainty in Measurement，GUM），给全世界一个关于 $\pm$ 号的统一语言——独立不确定度按平方和开方合成，说明你报的是标准偏差还是扩展区间，并给出包含程度。本章的规则，就是教学实验室真正用得上的那个尺寸的 GUM 规则。
:::

## 后续内容

你已学会手工携带的区间，在[[laboratory-methods/data-graphs]]里成为一个被拟合的对象：最小二乘直线携带其斜率与截距的不确定度——还是同一条平方和开方规则，一次用于许多读数。[[laboratory-methods/volumetric-technique]]是本章允差咬人之处：润洗、读弯月面、等待流出与温度，各是一个潜在的系统误差，而这些技术正是为逐一关闭它们而设计的。完整的统计处理——$t$ 检验、置信区间、可疑值检验、带不确定度带的校准直线——在[[analytical-chemistry/statistics-calibration]]；[[analytical-chemistry/classical-analysis]]把整份预算用于滴定分析与重量分析，那里每一滴都继承你刚刚学过的算术。单位与位数的原始语境见[[general-chemistry-1/matter-measurement]]。

::: summary
- 任何测量都是一个区间：报告数值连同其不确定度，并让不确定度——而不是计算器——决定最后一位有效数字。
- 准确度是接近真值（受系统误差限制）；精密度是可重复（受随机误差限制）。重复只缩小随机误差；校准、空白与标准物质才是发现系统误差的办法。
- $n$ 次独立读数的平均值有标准不确定度 $s/\sqrt{n}$：四次重复把单次的分散减半，一百次把它减到十分之一。
- 有效数字是粗糙的不确定度记账：积与商取最少位数，和与差取最少小数位，精确数从不限制，只在最后舍入一次。
- 独立随机误差按平方和开方传递：和用绝对不确定度，积与商用相对不确定度，幂把相对不确定度乘以 $|n|$，对数除以 $\ln 10$。
- 量器允差是极限不是标准偏差：矩形分布的允差除以 $\sqrt{3}$ 得标准不确定度，两次天平读数按平方和开方合成。
- 改进之前先建预算：相对不确定度按 $1/V$ 与 $1/m$ 增长，所以小体积与小质量占主导——而且通常只有一项值得修。
:::

一支 $25.00\ \mathrm{cm^3}$ A 级单标线移液管的允差为 $\pm 0.03\ \mathrm{cm^3}$。把允差本身当作不确定度，计算一次全量程放出的相对不确定度。（以 $\%$ 输入相对不确定度。）
::: solution
$u/V = 0.03/25.00 = 1.2\times10^{-3} = 0.12\ \%$。（若按矩形分布的要求先把允差除以 $\sqrt{3}$，则得 $0.069\ \%$；本题要求的是保守的实验台约定。）

::: exercise 滴定商的传递 {level=2 check="2.4e-4"}
一次滴定给出 $c_\mathrm{B} = c_\mathrm{A}\,V_\mathrm{A}/V_\mathrm{B}$，其中 $c_\mathrm{A} = 0.1000 \pm 0.0002\ \mathrm{mol\,dm^{-3}}$，$V_\mathrm{A} = 22.50 \pm 0.03\ \mathrm{cm^3}$（滴定管放出），$V_\mathrm{B} = 25.00 \pm 0.03\ \mathrm{cm^3}$（移液管）。求 $c_\mathrm{B}$，并按平方和开方传递不确定度求 $u(c_\mathrm{B})$。（以 $\mathrm{mol\,dm^{-3}}$ 为单位、用科学计数法输入 $u(c_\mathrm{B})$。）
::: solution
$c_\mathrm{B} = 0.1000 \times 22.50/25.00 = 0.0900\ \mathrm{mol\,dm^{-3}}$。相对不确定度：$0.0002/0.1000 = 2.0\times10^{-3}$；$0.03/22.50 = 1.33\times10^{-3}$；$0.03/25.00 = 1.2\times10^{-3}$。按平方和开方，
$$
\frac{u_c}{c} = \sqrt{(2.0\times10^{-3})^2 + (1.33\times10^{-3})^2 + (1.2\times10^{-3})^2} = \sqrt{4.0 + 1.78 + 1.44}\times10^{-6} = 2.69\times10^{-3},
$$
所以 $u(c_\mathrm{B}) = 0.0900 \times 2.69\times10^{-3} = 2.4\times10^{-4}\ \mathrm{mol\,dm^{-3}}$，$c_\mathrm{B} = (9.00 \pm 0.02)\times10^{-2}\ \mathrm{mol\,dm^{-3}}$。最大的单一贡献者是滴定剂的标定，而不是量器。
:::

::: exercise 平均值的不确定度 {level=2 check="0.012"}
四次重复质量给出样本标准偏差 $s = 0.024\ \mathrm{g}$。计算其平均值的标准不确定度。（以 $\mathrm{g}$ 输入。）
::: solution
$u(\bar{x}) = s/\sqrt{n} = 0.024/\sqrt{4} = 0.024/2 = 0.012\ \mathrm{g}$。注意平方根的代价：要把这 $0.012\ \mathrm{g}$ 再减半，需要四倍的读数，共十六次。

::: exercise 最坏情形与平方和开方 {level=2}
把 $25.00 \pm 0.03\ \mathrm{cm^3}$ 的一种溶液与 $20.00 \pm 0.05\ \mathrm{cm^3}$ 的另一种溶液混合。计算总体积及其不确定度：(a) 用最坏情形相加；(b) 用平方和开方。哪个更大，大多少倍？各自何时才是正确的规则？
::: solution
总体积 $45.00\ \mathrm{cm^3}$。(a) 最坏情形：$u = 0.03 + 0.05 = 0.08\ \mathrm{cm^3}$。(b) 平方和开方：$u = \sqrt{0.03^2 + 0.05^2} = \sqrt{0.0034} = 0.058\ \mathrm{cm^3}$。最坏情形大，大 $0.08/0.058 = 1.4$ 倍。平方和开方对独立随机误差是正确的，因为它让典型情形——一个误差为正、一个为负——部分抵消，而这正是大多数时候实际发生的事；最坏情形则假设两个误差同时取同方向的极值，只有当误差相关（两个体积都在同一支校准很差的滴定管上读出）或你必须保证一个界时，它才是正确的规则。
:::

::: exercise 推导商规则 {level=3}
由乘积规则和幂规则推导商的平方和开方规则：$z = x/y$ 时 $\left(u_z/z\right)^2 = \left(u_x/x\right)^2 + \left(u_y/y\right)^2$——然后再由一般的一阶公式 $u_z^2 = (\partial z/\partial x)^2 u_x^2 + (\partial z/\partial y)^2 u_y^2$ 推导一次。导数中的负号为什么从不出现在结果里？
::: hint
把 $z = x\,y^{-1}$ 写出，先对 $y^{-1}$ 应用幂规则：$y^{-1}$ 的相对不确定度用 $y$ 的相对不确定度如何表示？然后对 $x$ 与 $y^{-1}$ 应用乘积规则。
:::
::: solution
第一条路：由 $n = -1$ 的幂规则，$y^{-1}$ 的相对不确定度为 $|-1|\,u_y/y = u_y/y$——取倒数不改变一个量的相对不确定度。再对 $z = x\,y^{-1}$ 用乘积规则，得 $(u_z/z)^2 = (u_x/x)^2 + (u_{y^{-1}}/y^{-1})^2 = (u_x/x)^2 + (u_y/y)^2$。第二条路：$\partial z/\partial x = 1/y$，$\partial z/\partial y = -x/y^2$，所以
$$
u_z^2 = \frac{u_x^2}{y^2} + \frac{x^2 u_y^2}{y^4}.
$$
除以 $z^2 = x^2/y^2$：$(u_z/z)^2 = (u_x/x)^2 + (u_y/y)^2$。负号消失是因为它被平方了——而这不是需要道歉的数学巧合：$x$ 与 $y$ 的独立误差同样可能相互抵消或相互加强，所以交叉项的平均效应为零，只有平方存活。除法并不比乘法更安全，第一次除以一个又小又不确定的体积时，值得记住这一点。
:::
:::

::: exercise 一份完整的不确定度预算 {level=3}
你按下法配制标准溶液：在分析天平上（每次读数允差 $\pm 0.0002\ \mathrm{g}$，共两次读数）用差减法称取 $0.1000\ \mathrm{g}$ 干燥过的基准物质，溶解后在 $250.0\ \mathrm{cm^3}$ A 级容量瓶中定容（$\pm 0.12\ \mathrm{cm^3}$），再用 A 级移液管（$\pm 0.03\ \mathrm{cm^3}$）移取该溶液 $25.00\ \mathrm{cm^3}$ 等分试液。把每项允差当作不确定度，为等分试液中基准物质的量 $n = (m/M)\,(V_\mathrm{pip}/V_\mathrm{flask})$ 建立相对不确定度预算。哪一项占主导，占方差的多少份额？你会做哪一项改变？
::: solution
相对不确定度：差减称量的 $u(m) = \sqrt{2}\times0.0002 = 0.0003\ \mathrm{g}$，故 $u_m/m = 0.0003/0.1000 = 2.8\times10^{-3}$（$0.28\ \%$）；移液管 $0.03/25.00 = 1.2\times10^{-3}$（$0.12\ \%$）；容量瓶 $0.12/250.0 = 4.8\times10^{-4}$（$0.048\ \%$）。按平方和开方，总和为 $\sqrt{(2.8\times10^{-3})^2 + (1.2\times10^{-3})^2 + (4.8\times10^{-4})^2} = 3.1\times10^{-3}$，即 $0.31\ \%$。方差的份额是称量 $83\ \%$、移液管 $15\ \%$、容量瓶 $2\ \%$：占主导的是*小质量*，不是量器——$0.0003\ \mathrm{g}$ 的不确定度落在 $0.1000\ \mathrm{g}$ 上，就是称得少的代价。唯一的改变：多称一些。改用 $1.0000\ \mathrm{g}$ 配制同样浓度的溶液（或称更大的质量、在更大的容量瓶中定容后移取等分试液），称量项降到 $0.028\ \%$，总预算降到 $0.13\ \%$，主导权交给移液管——这时预算就会告诉你：停止改进，收工回家。
:::
