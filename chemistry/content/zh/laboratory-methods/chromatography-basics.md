1900年初，植物学家米哈伊尔·茨维特（Mikhail Tswett）正在海德堡工作。他把菠菜叶磨碎，将绿色提取液倒进一根装满研细白垩的玻璃管，本指望一次冲洗就能把色素洗回来。然而落下来的却是一道彩虹。当溶剂渗滤过白垩时，提取液分离成一条条界限分明的色带——绿色的叶绿素、黄色的叶黄素、橙色的胡萝卜素——以不同的速度沿柱子下行，每一条带都是与其余物质分离开的纯色素。茨维特的装置里没有任何新东西：粉末、溶剂、重力。使它奏效的，正是你在[[laboratory-methods/separation-purification]]里遇到的那个分配平衡——在那里，溶质按固定比例把自己分配到两个互不相溶的液体之间。在分液漏斗里摇动一次，就只施加了*一次*那个平衡，而一次施加只能把溶质移动很短的距离——这就是为什么单靠萃取几乎从不能分离相似的化合物。色谱柱则把同一个不起眼的平衡施加一万次：一万个在两相之间的小小选择，每一个都极轻微地偏袒固定相所喜的溶质、让它多留片刻，而一万个小小的偏向累加起来，就成了任何单次萃取都无法分开的物质的完全分离。一个弱原理被施加许多次，胜过强原理被施加一次，而这句话就是整个色谱理论的雏形。

本章把这一思想定量化。我们将说出两相的名字，以及固体留住溶质的两种方式；学习薄层色谱——这项能在十分钟里回答"我的反应完了没有？""我的产物纯不纯？"的实验台技术；从相比出发推导比移值 $R_\mathrm{f}$，看清它究竟是什么、又究竟是什么都不是；把同样的化学搬到柱子上，在那里谱带变成馏分，保留体积登场；最后以纸色谱收尾——正是这项技术在1941年得到的解释，最终揭示了茨维特究竟发现了什么。贯穿全章，数字很小，算术很简单——力量完全在于重复。

## 思想：两相，其中一相在移动

每一个色谱分离都有同样的两种组分。**固定相**是一种固体，或作为薄膜涂覆在多孔固体载体上的液体，被固定在某处不动：铝板上一层硅胶，一张纤维素片，玻璃管内填装的颗粒床。**流动相**是渗滤穿过或流过它的液体或气体，带着样品一起前进。流动相移动时，样品中的每个溶质按自身的分配行为在两相之间分配自己——这是[[laboratory-methods/separation-purification]]中分配系数 $D$ 的色谱表亲——并且随着新鲜流动相的不断到来，分配一次又一次地重新建立。

::: definition 色谱法 {#def-chromatography}
**色谱法**是这样一类分离技术：溶解或悬浮在**流动相**——液体或气体——中的混合物，被携带穿过或流过一个**固定相**——固体，或保持在固体载体上的液体——使每个组分在两相之间反复地分配或吸附。只被固定相弱弱留住的组分，几乎把全部时间都花在随流动相赶路之上，谁也无法追上它；被牢牢留住的组分，大部分时间停在原地，被远远抛在后面。分离是许多次重复分布累积起来的结果，而不是任何单独一次分布的结果。
:::

两种留住机制占统治地位。在**吸附色谱**中，固定相是极性固体——硅胶或氧化铝（aluminium oxide）——溶质粘在其表面上。硅胶表面铺满了硅醇基 $\mathrm{Si{-}OH}$，它们抓住任何能与它们形成氢键或偶极缔合的溶质：醇、酸和胺紧紧扒住；烃类几乎不肯落脚。在**分配色谱**中，固定相是保持在惰性载体上的液膜，溶质因优先溶解于两种液体之一而分离——纸色谱这种最古老的形式正是如此，被保持的液体是水（见下文纸色谱一节）。接下来几节的数学对两种机制完全相同；不同的只是偏好的来源。

液相色谱分离的流动相称为**展开剂**（或洗脱剂），被它带着下行的溶质说成是被**洗脱**。展开剂有一种叫洗脱强度的排序，而在极性吸附剂上，你必须记住的规则很短：**展开剂极性越强，一切在硅胶上跑得越快**。极性展开剂与溶质争夺同样的极性表面位点，把溶质从表面敲进流动相；在硅胶上，己烷几乎推不动一个醇，在己烷里加一点乙酸乙酯就能让它上路，而纯乙酸乙酯则让几乎所有东西都奔跑起来。这里描述的排布——极性固定相、较弱极性的流动相——称为**正相**色谱；它的镜像，即非极性固定相（键合长烃链的硅胶）加极性流动相，是**反相**色谱，它把洗脱顺序倒转过来。反相是现代药物分析的主力，在[[analytical-chemistry/chromatography]]中展开；本章留在硅胶上，因为那才是你在实验台上要装填的东西。

## 薄层色谱

薄层色谱（TLC）把整个思想放到一块平板上，并在溶剂爬上十厘米的时间里回答化学家每天要问的两个问题——这个混合物里有几种化合物，我的反应进行到什么程度了。商品薄层板是一片薄薄的铝片或玻璃片，上面涂着约 $0.1$–$0.2\ \mathrm{mm}$ 厚的硅胶层，硅胶以硫酸钙黏合剂固定，并含有一种荧光染料，使本章的数字可以用肉眼量出来。

::: definition 比移值 {#def-rf}
薄层板展开之后，斑点的**比移值** $R_\mathrm{f}$ 为
$$
R_\mathrm{f} = \frac{\text{斑点中心移动的距离}}{\text{展开剂前沿移动的距离}}.
$$
两个距离都从原点（点样处所在的基线）量起，都用相同的单位，所以 $R_\mathrm{f}$ 是一个没有单位的纯数。它永远小于一，因为溶质从不能超过携带它的溶剂；一个从不接触固定相的化合物会有 $R_\mathrm{f} = 1$，而一个永远粘在原点上的则是 $R_\mathrm{f} = 0$。
:::

::: algorithm 薄层色谱的操作 {#alg-tlc}
1. **用铅笔画一条基线**，距板底约 $1\ \mathrm{cm}$。铅笔的石墨不溶解、不会跑；圆珠笔或钢笔墨水会随前沿一起爬上去，毁掉整个实验。
2. **点样要小。** 把毛细管蘸入溶液，轻触基线，用温和的气流或耐心等待来弄干斑点；重复两三次，在不把斑点摊大的前提下多载一些样品。宽的斑点日后会变成宽而重叠的谱带——小而浓是一切。
3. **准备展开槽。** 向带盖玻璃槽中倒入展开剂，深约 $0.5\ \mathrm{cm}$——液面必须保持在基线*之下*，否则样品会溶进槽里的储液，而不是爬上板去。摇动展开槽使槽壁润湿。
4. **展开。** 把板立入槽中，盖好盖子，放到前沿升至距板顶约 $1\ \mathrm{cm}$ 处。取出板，立刻用铅笔标出前沿位置——要在溶剂蒸发之前——然后把板弄干。
5. **显色。** 在 $254\ \mathrm{nm}$ 紫外灯下观察：板上的染料发荧光，吸收紫外线的化合物呈暗斑（隔着防护屏观察，绝不可直视灯管）。把板在碘晶体上方短暂掠过，碘使大多数有机化合物显棕色；或浸入显色剂，如胺和氨基酸用的茚三酮。
6. **测量。** 用铅笔圈出每个斑点，用直尺量出斑点距离与前沿距离，对每个斑点算出 $R_\mathrm{f}$。
:::

第3步里藏着初学者唯一会做错细节的地方，所以要把理由大声说出来：**盖子盖上，是因为展开剂必须与槽内空气达成蒸气平衡。** 在敞口的槽里，前沿上升时溶剂会从板面蒸发；蒸发使板变冷，最先带走展开剂中跑得最快的组分，使前沿爬得歪歪扭扭、爬到一半还会变速。在充满展开剂饱和蒸气的槽里，什么都不蒸发，前沿又直又平地前进，$R_\mathrm{f}$ 值在一次又一次实验之间才有意义。盖子还把可燃蒸气挡在房间之外：普通 TLC 用的展开剂——己烷、乙酸乙酯、乙酸、丙-2-醇——全都易燃；用过的板、毛细管和废溶剂要投进固体废物桶和有机溶剂桶，绝不可倒入下水道，也绝不可丢进普通垃圾桶。不要把晾干的板对着嘴吹去粉尘：硅胶层是细小的可吸入粉末，清理薄板的正确办法是让废物桶而不是你的肺来收集它。这一切都是寻常的实验台工作，但却是与可燃物和细粉尘为伴的实验台工作，必须在监督之下、对照风险评估来做，正如[[laboratory-methods/lab-safety]]中处处要求的那样。

$R_\mathrm{f}$ 是什么：在*指定展开剂、指定薄板类型和加盖展开槽的条件下*化合物的一种可重现性质——重现性足以让化学家在记录本里写下"乙酸乙酯/己烷 $1:3$，$R_\mathrm{f}\ 0.35$"，而另一栋楼里的同事就能复现。$R_\mathrm{f}$ 不是什么：它不是熔点那样的物理常数。换展开剂，板上每个 $R_\mathrm{f}$ 都会变；不注明展开剂的 $R_\mathrm{f}$ 是一个没有单位的数字。单个斑点也不是纯度的证明。一个化合物在紫外灯下、碘熏之后、喷显色剂之后——三种响应不同化学的显色方法——都只显示一个斑点，那是纯度的*证据*，因为杂质必须躲过全部三种方法才行；但两个一起迁移、在同一波长处吸收的化合物，看起来会和一个完全一样。诚实的说法是"在此展开剂下 TLC 检不出杂质"。

::: example 测定 $R_\mathrm{f}$ 值 {#ex-rf-measure}
一块薄层板在乙酸乙酯/己烷混合剂中展开，直到溶剂前沿从基线起移动了 $5.1\ \mathrm{cm}$。一个斑点其中心距基线 $3.2\ \mathrm{cm}$。确定比移值，位数要诚实。
::: solution
$$
R_\mathrm{f} = \frac{3.2\ \mathrm{cm}}{5.1\ \mathrm{cm}} = 0.627\ldots = 0.63.
$$
厘米相消——$R_\mathrm{f}$ 无量纲——而这两个距离是用直尺对厘米刻度读出的，只支持约两位有效数字，所以 $R_\mathrm{f} = 0.63$。两条实验台笔记。距离要量到斑点的*中心*——化合物大部分所在之处——而不是它的前缘；前沿要在板还湿时立刻标出，因为一个没做标记就蒸发掉的前沿意味着实验报废——前沿未知，$R_\mathrm{f}$ 根本无从算起。
:::
:::

::: example 用 TLC 跟踪反应 {#ex-rf-reaction-monitor}
一个氧化反应把起始原料 $\mathrm{A}$（在所选展开剂中 $R_\mathrm{f} = 0.45$）变成极性更强的产物（$R_\mathrm{f} = 0.20$）。一名学生在一块板上点三个道：第1道，一滴起始原料溶液；第2道，一滴反应混合物；第3道，共点——两滴加在基线的同一点上，一起点上。展开后，第1道在 $0.45$ 处显示一个斑点；第2道在 $0.20$ 和 $0.45$ 处各显示一个斑点；第3道两个斑点都显示。反应完成了吗？
::: solution
没有。第2道在 $0.20$ 处的斑点证明产物已经生成，但它在 $0.45$ 处的斑点恰好落在起始原料迁移的位置上，所以未反应的 $\mathrm{A}$ 仍然存在。第3道的共点才是细致的地方：如果反应混合物里那个上斑点只是一个碰巧在 $0.45$ 处迁移、却不是 $\mathrm{A}$ 的化合物，那么共点会因超载而裂成两个紧邻的斑点；事实是它在 $0.45$ 处显示一个干净的斑点，与反应混合物确实含有 $\mathrm{A}$ 相符。结论：反应已经生成产物，但尚未完成——让它继续反应，再次取样。共点这一道是了结"$R_\mathrm{f}$ 相同也回答不了是不是同一化合物"这类问题的标准办法，同样的逻辑会在[[laboratory-methods/identifying-compounds]]中再次出现。
:::
:::

## 比移值为何如此表现

$R_\mathrm{f}$ 之所以是它那个样子，直接来自[[laboratory-methods/separation-purification]]的分配平衡。用 $k$ 表示一个溶质不分配到两种大量液体之间、而分配到薄板两相之间的比例，以物质的量计量：

$$
k = \frac{\text{固定相中溶质的量}}{\text{流动相中溶质的量}}.
$$

（$k$ 就是分配系数 $D$ 乘以薄板所在区域两相的量之比；它是同一个平衡穿上了色谱工作者的衣服。）

::: proposition 从相比到比移值 {#prop-rf}
若一个溶质以相比 $k$ 分配到色谱体系的固定相与流动相之间，则它的比移值为
$$
R_\mathrm{f} = \frac{1}{1 + k}.
$$
被牢牢留住的溶质（$k$ 大）$R_\mathrm{f}$ 小；完全不被留住的溶质（$k = 0$）随前沿一起跑，$R_\mathrm{f} = 1$；而 $k = 1$——每一瞬间两相中的量相等——恰好停在板的正中间。
:::

::: proof 时间份额论证 {#proof-rf}
溶质分子只在处于流动相中时才移动；被吸附在硅胶上时，它就一动不动地待在原处。平衡时，处于流动相中的溶质分子份额为
$$
\frac{n_\mathrm{m}}{n_\mathrm{m} + n_\mathrm{s}} = \frac{1}{1 + n_\mathrm{s}/n_\mathrm{m}} = \frac{1}{1 + k},
$$
而由于分子在两相之间不断且同等地交换，这也是任何一个分子花在移动上的*时间份额*。在溶剂前沿移动距离 $L$ 的时间里，溶质因此移动
$$
\text{移动的距离} = (\text{处于流动相的时间份额}) \times (\text{前沿移动的距离}) = \frac{L}{1 + k},
$$
这里假设分子只要处于流动相中，就以前沿的速度移动。除以 $L$ 即得 $R_\mathrm{f} = 1/(1+k)$。值得点名的假设有两条：平衡相对于流动足够快（否则分子的平均就错了），以及所有溶质在流动相中的迁移率相同；对于在饱和槽中缓慢展开的薄板，两者都是不错的近似。
:::

把这个结果读成一张后果表。在正相硅胶板上，极性更强的溶质吸附更强，于是 $k$ 更大、$R_\mathrm{f}$ 更小：醇躲到基线附近，而烃类随前沿兜风。极性更强的展开剂去争夺硅醇基位点，*同时压低每一个 $k$*，把板上所有 $R_\mathrm{f}$ 一起抬高——这就是为什么面对一块所有东西都粘在原点的板，放之四海皆准的第一招就是"提高极性"。而由于 $k$ 属于展开剂的程度不亚于属于溶质，命题本身永远说不出换了展开剂之后 $R_\mathrm{f}$ 会变成什么；它只在条件固定时把 $R_\mathrm{f}$ 与 $k$ 拴在一起。引用 $R_\mathrm{f}$ 而不注明展开剂，永远不要这样做。

::: quiz
在 $30\ \%$ 乙酸乙酯/己烷中展开的正相硅胶板上，一个斑点停在 $R_\mathrm{f} = 0.10$ 处。要让它往板上更高处移动，你应当——
- [x] 增大展开剂中乙酸乙酯的比例。
- [ ] 减小展开剂中乙酸乙酯的比例。
- [ ] 改用纯己烷。
- [ ] 什么都不做：$R_\mathrm{f}$ 是化合物的性质，改不了。
::: solution
增大乙酸乙酯的比例。在 $R_\mathrm{f} = 0.10$ 时，溶质的 $k = 1/0.10 - 1 = 9$：它把十分之九的时间粘在硅胶上。乙酸乙酯是混合剂中极性的那一个，它的比例越大，争夺硅醇基位点就越凶，$k$ 随之降低、$R_\mathrm{f}$ 随之升高；纯己烷（各选项中最弱极性的展开剂）会把斑点压得离基线更近。第四个选项把记账当成了物理：$R_\mathrm{f}$ 在固定条件下可重现，但 $k$——连同 $R_\mathrm{f}$——取决于展开剂、两相和温度，恰如分配系数一样。
:::
:::

::: example 选择展开剂的强度 {#ex-rf-choose-eluent}
在 $10\ \%$ 乙酸乙酯/己烷中，一个斑点的 $R_\mathrm{f} = 0.05$——离基线近得毫无用处。大约怎样的展开剂改动能让它进入可用的范围 $R_\mathrm{f} \approx 0.3$–$0.5$？$k$ 必须下降多少倍？
::: solution
用 $k = 1/R_\mathrm{f} - 1$ 把目标换算成相比。$R_\mathrm{f} = 0.05$ 时溶质的 $k = 19$；$R_\mathrm{f} = 0.35$ 时它将是 $k = 1.9$；$R_\mathrm{f} = 0.5$ 时 $k = 1.0$。所以 $k$ 大约必须下降十倍——而提高展开剂极性正是压低 $k$ 的手段，于是这一步就是把乙酸乙酯的比例大幅提高，例如从 $10\ \%$ 提到 $30$–$40\ \%$，跑一块试验板，再作调整。十倍这个估计并不是对新 $R_\mathrm{f}$ 的预言——$k$ 不是一个能在换展开剂之前就算出来的固定数——但它告诉你要尝试的改动*幅度*，一块试验板就能了结。如果连强展开剂都把斑点留在基线上，那说明这个化合物对硅胶体系来说极性太强，诚实的选择是反相板，或者干脆换一种分离。
:::
:::

## 柱色谱

把薄板竖起来，把床层做厚，让溶剂连续不断地流过，TLC 就成了**柱色谱**：同样的化学，竖直而连续。玻璃管中用起始展开剂把细硅胶调成浆料填装，得到一床平整的硅胶；混合物溶在尽可能少的溶剂里，作为一条窄带加在柱顶；再不断补加展开剂，任其在重力下流下。谱带迁移时，溶质分离成一条条界限分明的有色或无色的谱带，与板上完全一样——弱留住的化合物超过强留住的——而化学家的活是在它们离开柱子时接住：把体积大致相等的**馏分**收集在一排试管里，每支的点一块 TLC 板，把只含一种化合物的试管合并、蒸干。固定组成的展开剂推不动所有东西时，就在运行途中提高极性——**梯度洗脱**——先用弱展开剂分开跑得动的化合物，最后用强展开剂把顽固的洗下来。

::: definition 保留体积 {#def-retention}
溶质的**保留体积** $V_\mathrm{R}$ 是把它的谱带中心带到柱出口所必须流过柱子的展开剂体积。若 $V_0$ 是**间隙体积**——填充床中保有的流动相体积，即洗脱一个 $k = 0$ 的化合物所需的体积——则
$$
V_\mathrm{R} = V_0\,(1 + k).
$$
保留体积是柱色谱工作者的 $R_\mathrm{f}$：同一个相比 $k$，这一次用溶剂的立方厘米而不是迁移的厘米来量度。
:::

这个关系就是[[#proof-rf]]的时间份额论证，只不过读它用的是流量计而不是直尺。谱带以流动相速度的 $1/(1+k)$ 前进，所以它穿过柱子所需的时间是不被保留的化合物的 $(1+k)$ 倍；展开剂以恒定流速流下，所以这段更长时间里流过的体积，就是不被保留的化合物穿柱期间流过的体积的 $(1+k)$ 倍——而那个体积正是 $V_0$。一个 $k = 9$ 的醇需要十个柱体积的展开剂才能洗脱；一个 $k = 0.2$ 的烃只需略多于一个。这就是为什么被强留住的化合物既要求更强的展开剂、又要求极大的耐心，也是为什么一次分离的体积尺度由 $k$ 决定，恰如板上距离的尺度一样。

两条谱带之间，一切成败系于**谱带展宽**。每种溶质离开柱子时不是一片无限薄的切片，而是一条有限宽度的谱带，而只要谱带保持得比它们之间的距离窄，分离就还活着。每条谱带都以窄开始、随时间变宽：分子在扩散，有的顺着颗粒之间的快通道下行，有的在慢通道里磨蹭——跑得又长又慢，扩散得到的时间就多，即使 $k$ 相差充裕，也会得到又宽又重叠的谱带。锐利的谱带来自相反的习惯——窄而浓的起始谱带；细而匀、无裂缝无沟道的硅胶填充；平稳、不慌也不怠的流速；永不干涸的床层。塔板与分离度的定量理论属于[[analytical-chemistry/chromatography]]；在实验台上，规则是定性的、也是绝对的——起始时把谱带做窄，之后尽量少扰动它。

::: warning 绝不让柱子流干 {#warn-column}
如果溶剂液面落到固定相床层顶面之下，空气就会被吸进床层，硅胶开裂，而展开剂——永远走阻力最小的路——会顺着裂缝沟流，而不是流过硅胶。一旦如此，谱带就会涂抹开来，分离即告报废，再加多少展开剂也修不回来：随时补满展开剂、盖好储液瓶；床层当真流干了，就重新装柱。同一条警告还有第二副面孔，为人而非为样品：硅胶和氧化铝是细小的可吸入粉尘，构成呼吸危害，所以粉末要在通风橱里称量，绝不在敞开的空气中倾倒或吹撒粉尘，用过的薄板、废柱和废展开剂要投入指定的固体废物桶和溶剂桶。展开剂本身是易燃液体，要在通风橱里、远离点火源使用。这一切都不是神经过敏；这是把[[laboratory-methods/lab-safety]]的风险评估应用到那一种同时与几克细粉和几升溶剂打交道的技术上——而且这一切都必须在监督之下进行。
:::

::: example 预测硅胶柱上的洗脱顺序 {#ex-column-order}
己烷、乙酸乙酯和丙-1-醇的混合物加到硅胶柱上，展开剂是强度恒定的乙酸乙酯/己烷。化合物以什么顺序离开柱子？为什么？
::: solution
极性最弱的先走：**先己烷，再乙酸乙酯，最后丙-1-醇**。己烷是烃，没有任何形成氢键的办法；它在硅胶上的 $k$ 几乎为零，在接近 $V_0$ 处洗脱。乙酸乙酯是极性酯——能与表面偶极缔合，但不能给出氢键——$k$ 居中。丙-1-醇的 $\mathrm{OH}$ 基既给又收氢键，把硅醇基抓得最紧，$k$ 最大，最后离开；若在板上，它的 $R_\mathrm{f}$ 会最小。板和柱上顺序相同，因为决定两者的正是同一个 $k$——这也正是为什么可以用十分钟的 TLC 板为柱分离探路：板上能分开的，管子里就能分开。
:::
:::

## 纸色谱与分配理论

远在薄板和柱子之前就有了纸——而理论正是在纸上定案的。纸色谱中，一条色谱纸在近一端处点样，纸的下端浸入浅盘中的溶剂，溶剂借毛细作用沿纸爬升，带着样品一起走；斑点被定位，其 $R_\mathrm{f}$ 值的算法与板上完全一样。茨维特用吸附解释他的白垩，于是用同样的方式解释纸也顺理成章。1941年，阿切尔·马丁（Archer Martin）与理查德·辛格（Richard Synge）证明这是错的，而他们的纠正是一切现代色谱的奠基思想：**纸色谱是分配，不是吸附。** 纤维素强烈亲水，即使摸起来干的纸也在纤维之间保持着一层结合水；那层水膜就是固定相，从它旁边爬过的有机溶剂就是流动相。溶质因优先溶解于两种液体之一而分离——一场沿一条纸带进行了一千次的液液萃取——而[[#prop-rf]]的同一个 $R_\mathrm{f} = 1/(1+k)$ 逻辑原封不动地适用，只是 $k$ 现在是两种液体之间的分配系数。

经典的示范是丁-1-醇/乙酸/水这一溶剂系统，其中纸中保持的水是固定相，被有机蒸气饱和的混合液是流动相。糖类——多羟基化合物，彼此主要差别在于对水相对于有机溶剂的偏好程度——沿着纸带整齐地铺开，每个 $R_\mathrm{f}$ 由各自的分配系数决定；氨基酸无色、在纸上不可见，喷上茚三酮后，茚三酮与它们反应生成紫色斑点，而它们因同样的理由分离。马丁与辛格的洞见不止解释了纸：它宣告*任何*一对互不相溶的液体，一静一动，都会按分配分离——此后十年，这两人一直在证明这一点，先在纸上，然后在1952年用气体作流动相。

这些实验台技术的仪器后代是[[analytical-chemistry/chromatography]]的主题。**高效液相色谱**是用泵压驱动、穿过几微米直径颗粒的柱色谱，配一个流动检测器实时描出上图那样的峰；**气相色谱**用气体流动相和气化的样品，以茨维特从未想象过的威力分离挥发性混合物——燃料、香水、血液酒精。在这一切之中，物理都是本章的物理：在固定相与流动相之间反复分配，$k$ 决定谁在动，重复决定谁出逃。把这样的柱子接到质谱仪上，分离开的化合物在洗脱时被逐一鉴定——那就是[[analytical-chemistry/hyphenated-methods]]的联用方法——但分离本身，这一页的读者已经完全懂了。

::: history
米哈伊尔·茨维特（Mikhail Tswett）是研究植物色素的植物学家。1900–1903年间，先在海德堡、后在俄国工作的他，把色素提取液倒进装满碎白垩和碳酸钙的柱子，看着色带形成：绿色的叶绿素带、黄色的叶黄素带、橙色的胡萝卜素带，每一条都可分离、可收集。他把这种方法命名为 *chromatography*——"书写颜色"，源自希腊语 $\chi\rho\alpha\mu\alpha$（颜色）与 $\gamma\rho\alpha\mu\mu\alpha$（书写）——并认真发表了论文，但他投稿的德国期刊不肯要植物生理学，他的同代人正沉迷于新兴的离子物理化学，对那几根彩色试管置之不理。这项技术沉睡了三十年。1941年，阿切尔·马丁（Archer Martin）与理查德·辛格（Richard Synge）在他们剑桥的小实验室里，把这类分离重新解释为两个液相之间的分配；这一思想在1944年结出纸色谱，结出运动液相之间的逆流分配，并在1952年——马丁与他的学生安东尼·詹姆斯（Antony James）一起——结出气液色谱，这些工作为马丁与辛格赢得了1952年诺贝尔化学奖。茨维特1919年去世，生前眼见自己的方法未能流行；此后每一张色谱图，都是他没能看到的平反。
:::

## 后续内容

本章的 $k$ 所扩展的那个分配系数 $D$，在[[laboratory-methods/separation-purification]]中展开：那里萃取对同一个平衡只施加一次，而色谱施加一万次；[[#ex-rf-reaction-monitor]]的共点逻辑，会在[[laboratory-methods/identifying-compounds]]中以混合熔点和对照分析的身份归来——在那里，TLC 纯度是样品值得去测任何物理常数之前必须通过的一关。仪器室——柱子、泵、检测器、塔板与分离度、高效液相色谱与气相色谱——是[[analytical-chemistry/chromatography]]；分离与鉴定的联姻，气相色谱-质谱与液相色谱-质谱，是[[analytical-chemistry/hyphenated-methods]]；至于光谱学检测器本身，则是[[analytical-chemistry/molecular-spectrometry]]。使加盖展开槽奏效的蒸气平衡，与[[general-chemistry-2/liquids-solutions]]是同一种物理；而你报告的每一个 $R_\mathrm{f}$ 那两位数字的诚实，则是[[laboratory-methods/measurement-uncertainty]]的算术。上面每一句话里的危害——易燃展开剂、可吸入粉尘、紫外灯——都能在[[laboratory-methods/lab-safety]]中得到妥善的评估。

::: summary
- 色谱法靠把一个分配平衡施加许多次来分离：每个组分在固定相与流动相之间反复分配或吸附，弱留住的组分超过强留住的。
- 吸附色谱（硅胶或氧化铝：极性表面留住极性溶质）与分配色谱（保持在载体上的液膜）是两种机制；在硅胶上，极性更强的展开剂让一切跑得更快。
- 比移值 $R_\mathrm{f} = \text{斑点距离}/\text{前沿距离}$ 无量纲且永远小于一，只有对注明名称的展开剂、薄板和展开槽才是可重现的性质。
- 以 $k$ 为固定相/流动相的量比，$R_\mathrm{f} = 1/(1+k)$：强留住的溶质 $R_\mathrm{f}$ 小，极性溶质粘在正相硅胶上，而极性展开剂同时抬高每一个 $R_\mathrm{f}$。
- TLC 的操作要领：铅笔基线、小斑点、为蒸气平衡而加盖的展开槽、$254\ \mathrm{nm}$ 紫外灯加碘与显色剂显色；三种方法下一个斑点是证据而非证明，共点了结身份问题。
- 在柱上，保留体积为 $V_\mathrm{R} = V_0(1+k)$；锐利的谱带来自窄的点样、细匀的填充与平稳的流速——以及绝不让床层流干，那会让展开剂沟流、毁掉分离。
- 纸色谱是分配（马丁与辛格，1941年）：纤维素中保持的水对抗有机溶剂；高效液相色谱与气相色谱是其仪器后代，联用方法把它们与质谱耦合起来。
:::

## 练习

::: exercise 测定 $R_\mathrm{f}$ {level=1 check="0.79"}
一块展开后的 TLC 板上，溶剂前沿从基线起移动了 $5.8\ \mathrm{cm}$，一个斑点的中心位于距基线 $4.6\ \mathrm{cm}$ 处。计算比移值。（输入比移值。）
::: solution
$R_\mathrm{f} = 4.6\ \mathrm{cm}/5.8\ \mathrm{cm} = 0.793\ldots = 0.79$。单位相消；直尺只支持两位数字。
:::
:::

::: exercise 先出柱者 {level=1}
苯甲酸甲酯与苯甲酸的混合物加到硅胶柱上。哪个化合物先洗脱出来？为什么？
::: solution
苯甲酸甲酯。这个酯只能在它的羰基上接受氢键、与硅胶表面偶极缔合，所以 $k$ 小；苯甲酸通过它的 $\mathrm{COOH}$ 基给出强氢键，把硅醇基抓得紧得多，$k$ 更大——它第二个洗脱（而且常常带尾，因为酸与硅胶的作用特别强）。在正相硅胶上，永远是最弱极性的先出。
:::
:::

::: exercise 展开槽为什么要加盖 {level=1}
用你自己的话解释：为什么 TLC 展开槽在展开之前要盖上盖子，以及为什么展开剂液面必须低于基线。
::: solution
加盖的展开槽会充满展开剂蒸气，直到空气与液体达成平衡。没有那个饱和气氛，上升中的溶剂就会从板面蒸发：前沿变慢并走偏，展开剂的组成随其易挥发组分先逸出而漂移，$R_\mathrm{f}$ 值不再可重现。盖子同时把可燃蒸气关在槽内。展开剂液面必须低于基线，否则斑点就*浸在*液面之下：样品不是被带上板，而是溶进槽里的储液，实验即告丢失。
:::
:::

::: exercise 从 $R_\mathrm{f}$ 到相比 {level=2 check="1.5"}
一个斑点在硅胶板上的 $R_\mathrm{f} = 0.40$。计算此条件下该化合物的相比 $k$。（输入 $k$。）
::: solution
把 $R_\mathrm{f} = 1/(1+k)$ 重排为 $k = 1/R_\mathrm{f} - 1$，得 $k = 1/0.40 - 1 = 2.5 - 1 = 1.5$。该化合物把 $1/(1+1.5) = 0.40$ 的时间花在流动相中——与起点的数字相同，这就是自洽性检验。
:::
:::

::: exercise 更换展开剂 {level=2}
一个斑点在 $10\ \%$ 乙酸乙酯/己烷中的 $R_\mathrm{f} = 0.25$。一位同事在 $30\ \%$ 乙酸乙酯/己烷中展开同一化合物。新的 $R_\mathrm{f}$ 是升还是降？你能否从 $R_\mathrm{f} = 1/(1+k)$ 算出它的值？解释之。
::: solution
升高：极性更强的展开剂争夺硅醇基位点，压低 $k$，于是 $R_\mathrm{f} = 1/(1+k)$ 增大。但新的值无法*算出*，因为 $k$ 本身是展开剂的性质——公式在条件固定时把 $R_\mathrm{f}$ 与 $k$ 拴在一起，却对化学改变时 $k$ 如何变化只字未提。诚实的工作流程是[[#ex-rf-choose-eluent]]的那一个：估计改变的方向和幅度，跑一块试验板，再调整。（定性地：$R_\mathrm{f} = 0.25$ 时 $k$ 为 $3$；酯的比例增至三倍会把斑点推上板的更高处，但究竟多高是一个实验。）
:::
:::

::: exercise 证明未知物就是对照品 {level=2}
有人告诉你一种白色固体"应该"是咖啡因，并且手头有咖啡因对照品。设计一个 TLC 实验，把鉴定做到 TLC 所能允许的最强，并准确说明结果能证明什么、不能证明什么。
::: solution
在一块板上点三个道：未知物单独一道，对照品单独一道，再把两者点在同一点上作共点一道。在一种展开剂中展开，干燥，先在 $254\ \mathrm{nm}$ 紫外灯下显色，再用碘，再用显色剂；然后在*第二种化学性质不同的展开剂*中重复整块板（例如先用乙酸乙酯/己烷体系，再用丙-2-醇/氨水体系）。如果未知物与对照品在两种展开剂中 $R_\mathrm{f}$ 相同，三种显色方法都不显示额外斑点，而且——决定性的一点——共点给出一个圆整的单斑而不是一对或一条拖尾，那么鉴定就达到了 TLC 允许的最强程度。它是证据，不是证明：一个化合物在两种展开剂系统中都与咖啡因同行、在三种显色下都与咖啡因吻合，那它几乎肯定是咖啡因；但两个相似的化合物可以藏在一起，而证明属于[[laboratory-methods/identifying-compounds]]的混合熔点，或属于[[analytical-chemistry/molecular-spectrometry]]的波谱学。
:::
:::

::: exercise 推导保留体积 {level=3}
从 $k$ 的定义和[[#proof-rf]]的时间份额结果出发，推导 $V_\mathrm{R} = V_0(1 + k)$，并说明你用到的每一条假设。
::: hint
先在时间里做。若流动相穿过柱子需要 $t_0$，谱带需要多久？然后利用展开剂以恒定流速流动这一事实，把时间换算成体积，并记住按定义 $V_0$ 是什么。
:::
::: solution
设柱长为 $L$，流动相以速度 $u$ 移动，则不被保留的化合物以 $t_0 = L/u$ 穿柱。按时间份额论证，溶质谱带以 $u/(1+k)$ 前进，所以它需要
$$
t_\mathrm{R} = \frac{L}{u/(1+k)} = (1+k)\,t_0 .
$$
展开剂以恒定的体积流速 $F$ 流动，所以时间 $t$ 内流过柱子的体积为 $Ft$；按定义，不被保留的化合物在 $V_0 = F t_0$ 处洗脱，而溶质在
$$
V_\mathrm{R} = F t_\mathrm{R} = F(1+k)t_0 = V_0(1+k).
$$
假设即[[#proof-rf]]的那些，外加两条：流速 $F$ 要恒定；且没有会把谱带中心涂抹出 $V_\mathrm{R}$ 之外的展宽。

::: exercise 一块板上的四个斑点 {level=3}
混合物点样于硅胶，在 $20\ \%$ 乙酸乙酯/己烷中展开。出现四个斑点，$R_\mathrm{f}$ 值为：A $0.85$，B $0.62$，C $0.60$，D $0.15$。(a) 按极性给四个化合物排序，最强的在前。(b) 计算四个 $k$ 值。(c) B 与 C 几乎分不开；说出一种应能把它们分得更好的展开剂改动，和一种会让它们更糟的改动，并为两者辩护。
::: solution
(a) 在正相硅胶上，$R_\mathrm{f}$ 越小意味着被留得越强、意味着越极性：$\mathrm{D} > \mathrm{B} \approx \mathrm{C} > \mathrm{A}$，D 最极性，A（靠近前沿）最弱极性。(b) 用 $k = 1/R_\mathrm{f} - 1$：A 得 $k = 0.18$，B 得 $0.61$，C 得 $0.67$，D 得 $5.7$——B 与 C 的 $k$ 只差 $9\ \%$，这就是它们几乎分不开的原因。(c) 更好：*降低*乙酸乙酯的比例。更弱的展开剂抬高每一个 $k$，而停在板中部 $R_\mathrm{f}$ 处的一对，会随着减速走向 $R_\mathrm{f} \approx 0.3$–$0.4$ 而彼此散开——在那里，$k$ 的微小差别会显示为看得见的间隙。更糟：*提高*乙酸乙酯的比例——更强的展开剂把每个斑点推向前沿，把整个图样压缩到溶剂前沿跟前，把 B 和 C 挤成一条拖尾。（改*溶剂*而不是改强度——把乙酸乙酯换成另一种极性展开剂——攻击的是选择性，往往是更根本的解法；上图说明了值得购买的为什么是距离而不是锐利。）
