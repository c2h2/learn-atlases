几毫克白色粉末躺在毛细管里，加热块缓缓爬过 $120\,^{\circ}\mathrm{C}$，忽然，那根压得紧紧的晶体柱闪出了光泽：$121\,^{\circ}\mathrm{C}$ 时出现第一滴液体，到 $123\,^{\circ}\mathrm{C}$ 已不见任何固体。你翻开常数表查苯甲酸：$122\,^{\circ}\mathrm{C}$。你证明了自己的物质是苯甲酸吗？没有——你只是*支持*了它，而这是一个不同且更诚实的动词。鉴定是一场用数字及其不确定度来下的对子棋：一个纯净化合物带着一套物理常数——熔点、沸点、密度、折射率、旋光度——而你所测得的，要与已发表的数值一个区间对一个区间地比较。每一次比较都在加强或削弱一个假说；任何单次比较都证明不了什么，因为不同的化合物会碰巧共享常数，身份从不由一个数字证明，只由若干彼此独立的数字支持。比较本身正是[[laboratory-methods/measurement-uncertainty]]的主题：测得熔程 $121\text{–}123\,^{\circ}\mathrm{C}$ 对上文献值 $122\,^{\circ}\mathrm{C}$，是两个区间相一致，而本章全部的分寸感就在于知道每一种一致各值多少。

纯度在先。下面每一个常数在不纯的样品上都一文不值——不纯的固体熔化得又低又宽，不纯的液体沸程拖长、密度读错——所以鉴定工作流永远从纯化与纯度检查开始，而不是从测量开始（[[laboratory-methods/separation-purification]]、[[laboratory-methods/chromatography-basics]]）。只有到那时，常数才成为证据；也只有到那时，问题才从"这可能是什么"变成"如果我错了，哪一个独立测量会不同意？"这个问题，以及回答它的种种测量，就是本章要教的东西。

## 熔点

::: definition 熔点 {#def-melting-point}
纯结晶固体的**熔点**是其固相与液相在 $101.3\ \mathrm{kPa}$ 下共存平衡时的温度。在实验室里它以**熔程**报告：从出现第一滴液体到固体完全澄清所记录的两个温度。纯化合物熔化**尖锐**——熔程 $1$–$2\,^{\circ}\mathrm{C}$，以文献值为中心——而熔程的位置与宽度都是信息：位置说的是身份，宽度说的是纯度。
:::

文献值本身也是一次测量，由某个纯化了该化合物、缓慢读数并发表数字的人做出；把它当作文献值上下约 $\pm 1\,^{\circ}\mathrm{C}$ 的一个区间，而不是当作福音。配得上与它比较的技术，细小而苛刻。把干燥固体研成细粉，经毛细管吸入 $1$–$2\ \mathrm{mm}$ 高——再多就无法均温、只会加宽熔程。毛细管是锋利的玻璃：装样前先在火焰上把开口端烧闭，或直接用出厂已封口的管子，用完丢进利器盒，绝不入废物桶。把它装进电加热块或油浴——两者的表面都烫得能灼伤皮肤，而油必须保持在其闪点以下——并缓慢升温：接近预期熔点时以 $1$–$2\,^{\circ}\mathrm{C}\,\mathrm{min^{-1}}$ 上升。升温太快读数偏高，因为毛细管里的样品总是落后于报告温度的传感器，而熔化本身又吸热；快速扫描只是筛查工具，缓慢升温才是测量。

::: proposition 熔点降低 {#prop-depression}
可溶杂质既**降低**又**加宽**一个化合物的熔程。对杂质 2 在化合物 1 中的稀理想溶液——杂质溶于液相而被排斥在固相之外——液相线的降低为
$$
\Delta T \approx K\,x_2,
\qquad
K = \frac{R\,T_\mathrm{f}^{2}}{\Delta_\mathrm{fus}H_\mathrm{m}},
$$
其中 $x_2$ 是杂质的摩尔分数，$T_\mathrm{f}$、$\Delta_\mathrm{fus}H_\mathrm{m}$ 是纯化合物的熔点与摩尔熔化焓。对有机化合物，$K$ 通常在 $50$–$150\ \mathrm{K}$ 之间——苯甲酸约为 $72\ \mathrm{K}$（$T_\mathrm{f} = 395.4\ \mathrm{K}$，$\Delta_\mathrm{fus}H_\mathrm{m} = 18.0\ \mathrm{kJ\,mol^{-1}}$）——所以一个摩尔百分点的溶解杂质大约赔上一度，几个摩尔百分点就赔上好几度。此关系只对稀理想溶液成立；它就是[[general-chemistry-2/liquids-solutions]]为溶剂讨论过的凝固点降低，只不过这次从固相一侧读出。
:::

::: proof 为什么杂质既降低熔点又加宽熔程 {#proof-depression}
熔化发生在固相与液相的化学势在 $101.3\ \mathrm{kPa}$ 下相等之处。对纯化合物，这发生在单一温度 $T_\mathrm{f}$ 上，那里 $\mu_1(\mathrm{s}) = \mu_1^{*}(\mathrm{l})$。加入可溶杂质，液相成为溶液，其中组分 1 的化学势为
$$
\mu_1(\mathrm{l}) = \mu_1^{*}(\mathrm{l}) + RT\ln x_1,
$$
其中 $x_1 < 1$：混合熵把液相中组分 1 的化学势*拉低*了，而固相——纯净的，杂质被排斥在其晶格之外——纹丝不动。于是在 $T_\mathrm{f}$ 上液相比固相更稳定，固体就要熔化；只有把温度降得更低才能恢复平衡。定量地，要求在新温度上 $\mu_1(\mathrm{s}) = \mu_1^{*}(\mathrm{l}) + RT\ln x_1$，并在 $T_\mathrm{f}$ 与 $T$ 之间积分吉布斯-亥姆霍兹关系、取 $\Delta_\mathrm{fus}H_\mathrm{m}$ 为常数，得
$$
\ln x_1 = -\frac{\Delta_\mathrm{fus}H_\mathrm{m}}{R}\left(\frac{1}{T} - \frac{1}{T_\mathrm{f}}\right).
$$
对稀杂质，$\ln x_1 = \ln(1 - x_2) \approx -x_2$，而 $\frac{1}{T} - \frac{1}{T_\mathrm{f}} = \frac{T_\mathrm{f} - T}{T\,T_\mathrm{f}} \approx \frac{\Delta T}{T_\mathrm{f}^{2}}$，于是 $\Delta T \approx \left(R\,T_\mathrm{f}^{2}/\Delta_\mathrm{fus}H_\mathrm{m}\right)x_2$——即命题。加宽来自把同一方程倒过来读：温度升高时，熔出的液体增多，杂质浓缩进这日益缩小的液相，$x_1$ 进一步下降，平衡温度也随之下降。因此固相与溶液共存不在一点，而是沿一条**液相线**，从低共熔温度直到完全澄清——在预期 $1$–$2\,^{\circ}\mathrm{C}$ 之处出现 $4$–$5\,^{\circ}\mathrm{C}$ 的熔程，正是那条液相线在替你揭发杂质。
:::

::: widget plot

x: 0, 0.3

labels: \text{熔点}
caption: 稀混合物的液相线：熔点随可溶杂质摩尔分数 $x$ 的变化，纯物质的熔点 $t_0$ 由滑块设定。直线以常数 $a$ 决定的速率下降——对许多有机物约为每单位摩尔分数 $100\ \mathrm{K}$——所以几个摩尔百分点的溶解杂质就要赔掉好几度。真实实验中，同样的降低总伴随着熔程的加宽，而告诉你样品不纯的，与其说是熔点的下降，不如说是熔程的宽度。
:::

同样的热力学把熔点变成了对*身份*的检验，而不仅是纯度的检验：**混合熔点**。把样品与约其一半质量的疑似化合物的对照真实样品一起研磨，再熔化混合物。若两者是同一种物质，这"混合物"根本就不是混合物——它仍是纯化合物，尖锐的熔程原封不动地停在文献值上。若两者不同，则彼此互为可溶杂质，[[#prop-depression]] 保证出现降低且加宽的熔程。一个数字不能告诉你你手里是*哪种*化合物；混合熔点却能告诉你两个样品是否同一化合物，而这股否定的力量正是它的价值所在。

::: example 哪个候选物存活？ {#ex-melting-point-candidates}
一种干燥的白色固体在 $121\text{–}123\,^{\circ}\mathrm{C}$ 尖锐熔化。候选表给出苯甲酸（文献值 $122\,^{\circ}\mathrm{C}$）、萘（$80\,^{\circ}\mathrm{C}$）与尿素（$133\,^{\circ}\mathrm{C}$）。哪个存活？熔点究竟确立了什么？
::: solution
比较区间。测得熔程 $121\text{–}123\,^{\circ}\mathrm{C}$ 在读数误差内与苯甲酸的 $122\,^{\circ}\mathrm{C}$ 一致；它比萘高 $40$ 度、比尿素低 $10$ 度，而没有任何杂质能把熔点压低 $40$ 度还保持熔程尖锐——混合物会熔得又低*又*宽。只有苯甲酸存活。但要读清发生了什么：一个常数*排除*了两个候选物，并*支持*了第三个。在文献值处尖锐熔化，说的是"纯，且与苯甲酸一致"——它并不排除那些同样在 $122\,^{\circ}\mathrm{C}$ 附近熔化的化合物，这样的化合物有好几种（阿司匹林就熔于 $122\text{–}123\,^{\circ}\mathrm{C}$）。接下来的测量必须是彼此独立的。
:::
:::

::: example 混合熔点拆穿"双胞胎" {#ex-mixed-melting-point}
两个未知物 A 与 B 都是干燥的白色结晶固体，且各自在 $122\text{–}123\,^{\circ}\mathrm{C}$ 尖锐熔化。一个学生把等质量的 A 与 B 一起研磨，混合物在 $115\text{–}120\,^{\circ}\mathrm{C}$ 熔化。A 与 B 是同一种化合物吗？
::: solution
它们是不同的化合物，而混合物已经这么说了。若 A 与 B 是同一种物质，把它们磨在一起不会改变任何东西："混合物"仍是纯化合物，熔程会保持在 $122\text{–}123\,^{\circ}\mathrm{C}$ 而依旧尖锐。然而熔程降了好几度并加宽到 $5\,^{\circ}\mathrm{C}$——降低*加*加宽，正是 [[#prop-depression]] 的确切签名：每种化合物都是另一种中的可溶杂质，这一对如今沿其低共熔点与澄清点之间的液相线熔化。（一种合理的解读：A 是苯甲酸，B 是阿司匹林，两者的文献熔点恰好都在 $122\text{–}123\,^{\circ}\mathrm{C}$——这个巧合，单个熔点永远揭发不了，混合熔点五分钟就能揭发。）
:::
:::

::: quiz
一种干燥的白色固体恰好在文献熔点处尖锐熔化。这一事实：
- [ ] 证明该化合物就是那种物质，因为两个独立测量相一致。
- [x] 与该化合物是那种物质相一致，但并不证明之，因为不同的化合物可以共享同一个熔点。
- [ ] 证明该化合物是纯的，但对它是什么只字未提。
- [ ] 意味着文献值一定错了。
::: solution
一致，而非证明。不同的化合物确实会共享熔点——苯甲酸与阿司匹林都熔于 $122\text{–}123\,^{\circ}\mathrm{C}$，而各种异构体共享常数的程度还常常比这更接近——所以单个吻合的常数是线索，不是判决。尖锐确实支持纯度，所以关于纯度的那个选项对了一半，但在文献值处尖锐熔化的事实同时支持着两个说法，而一个也不证明。补救之道不是把同一个测量再做一遍，而是做不同的测量：与对照真实样品做混合熔点，然后做光谱（[[#warn-melting-not-proof]]）。
:::
:::

## 沸点、密度与折射率

对液体，常数换了，逻辑未变。液体的**沸点**是其蒸气压等于外压的温度——它不是液体单独的属性，而是液体在*那一天、那个气压*下的属性（[[general-chemistry-2/liquids-solutions]]）。克劳修斯-克拉佩龙斜率 $\mathrm{d}T/\mathrm{d}p = RT^{2}/(\Delta_\mathrm{vap}H_\mathrm{m}\,p)$ 对典型有机液体约合每 $\mathrm{kPa}$ $0.3\ ^{\circ}\mathrm{C}$，所以 $10\ \mathrm{kPa}$ 的天气起伏——稀松平常——就能把乙醇的沸点挪动近 $3\ ^{\circ}\mathrm{C}$。不注明气压的沸点根本不是常数；与表值比较之前，先用气压-沸点诺模图把它校正到 $101.3\ \mathrm{kPa}$，并把实测值与校正值一并报告。沸点也是液体常数中最不具鉴别力的：它难以读到 $1\ ^{\circ}\mathrm{C}$ 以内，而共享一个沸点的化合物远比共享一个熔点的多。

**密度** $\rho = m/V$ 更诚实，因为 $m$ 与 $V$ 都能测得好。称一个**比重瓶**（带毛细管磨口塞的小瓶，已校准为在指定温度下容纳指定体积），装满、擦干、再称，然后相除；或者把一支校准过的吸量管里的液体放到天平上，把吸量管体积当作 $V$。报告时注明温度，因为液体会受热膨胀：$20\ ^{\circ}\mathrm{C}$ 时 $\rho = 0.789\ \mathrm{g\,cm^{-3}}$，其后站着 [[laboratory-methods/measurement-uncertainty]] 的不确定度预算。

::: definition 折射与折射率 {#def-refraction}
光在介质中变慢，**折射率** $n = c/v$ 度量的就是慢的程度；一条光线穿过折射率为 $n_1$ 与 $n_2$ 的两种介质的界面时发生偏折，遵循**斯涅尔定律**
$$
n_1\sin\theta_1 = n_2\sin\theta_2,
$$
其中 $\theta$ 从法线量起。由于 $n$ 依赖波长与温度，报告时两者都要注明：钠 D 线（$589\ \mathrm{nm}$）、$20\ ^{\circ}\mathrm{C}$，写作 $n_\mathrm{D}^{20} = 1.4741$。**阿贝折射仪**用一两滴液体就能测：液膜夹在两块棱镜之间，手持仪器对着校准刻度一分钟读完。折射率是液体常数中的主力，因为它只需极少的样品就能精确到四五个有效数字——也相应地对纯度极其敏感：一滴溶入的致密杂质就能把第四位数字挪走。
:::

密度与折射率搭配起来十分有力：它们响应不同的分子性质（堆积与分子间作用力；极化率），所以两种液体很少两者都相同。它们也是只需几滴、且不破坏样品的两个常数。

::: example 由两个常数鉴定无色液体 {#ex-liquid-identification}
一种干燥的无色液体读得 $n_\mathrm{D}^{20} = 1.447$、$20\ ^{\circ}\mathrm{C}$ 时 $\rho = 1.489\ \mathrm{g\,cm^{-3}}$。候选表上写着：二氯甲烷（$n_\mathrm{D}^{20} = 1.424$，$\rho = 1.326\ \mathrm{g\,cm^{-3}}$）、氯仿（$1.447$，$1.489$）、水（$1.333$，$0.998$）、甲苯（$1.497$，$0.867$）。鉴定它，并说明这个鉴定有多强。
::: solution
两个实测常数在测量精度内都与氯仿完全吻合：二氯甲烷的 $n_\mathrm{D}^{20}$ 差了 $0.023$（是读数误差的五十倍），其余候选物在任何一个常数上都不接近。两个独立常数一致是证据，不是证明——诚实的下一步是第三个独立测量，若指认错了它就会不同意：当天气压下的沸点，校正到 $101.3\ \mathrm{kPa}$，应落在 $61\ ^{\circ}\mathrm{C}$ 附近（二氯甲烷会给 $40\ ^{\circ}\mathrm{C}$），或者光谱应显出氯仿的图样。还要注意这种吻合预设了什么：样品是干燥而纯净的，因为一个溶入的致密杂质可能把两个常数从别处一起拖到这组数值上来。
:::
:::

## 旋光度

::: definition 比旋光度 {#def-rotation}
**手性**化合物会让穿过其溶液（或纯液体）的**平面偏振光**的偏振面发生旋转。观测角 $\alpha$ 与光程长度及光束中的分子数成正比，所以**比旋光度**把这两个因素归一化掉：
$$
[\alpha]^{T}_{\mathrm{D}} = \frac{\alpha}{l\,c},
$$
其中 $\alpha$ 是以度计的观测旋光度，$l$ 是以**分米**计的样品管长度，$c$ 是以 $\mathrm{g\,mL^{-1}}$ 计的浓度。报告时要注明温度、波长（惯例用钠 D 线）、溶剂与浓度，因为这四者都是数字的一部分：$[\alpha]^{20}_\mathrm{D} = +66.5\ (\mathrm{c}\ 1.00,\ \mathrm{H_2O})$。一个化合物的两个**对映异构体**旋转大小相等、方向相反，所以旋光的方向（相对于文献）报告你手里是*哪只手*——但绝不绝对：$(+)$ 与 $(-)$ 不与任何固定的结构描述符挂钩。**外消旋体**读数为零，其两半恰好抵消，这正是旋光度既能鉴定身份又能度量对映体组成的原因。
:::

::: history 手工分拣出的手性 {#hist-pasteur}
1848 年，二十五岁的巴斯德（Louis Pasteur）——斯特拉斯堡一位年轻的化学讲师——接过了酒石酸盐问题：来自酒桶的酒石酸盐会旋转偏振光，而在酿酒沉淀物中发现的"副酒石酸"（外消旋酸）组成相同，却什么都不旋转。在放大镜下，把钠铵盐的晶体一颗一颗地分拣，巴斯德发现了两种互为镜像的晶体——而把每种分别溶解，它们的溶液把偏振光的偏振面旋转得大小相等、方向相反。外消旋体，他已证明，是一对等大反向的组分的混合物：**对映异构体**的第一次拆分，分子手性的诞生，凭一枚放大镜、一把镊子和一台**旋光仪**尘埃落定——这台仪器正是今天任何教学实验室里那台"样品管加棱镜"装置的直系祖先。此后近一个世纪，在红外光谱、核磁共振与质谱存在之前，旋光度是化学家回答"这是什么分子"时所能拿出的最强物理证据之一，而比旋光度至今仍是手性天然产物与药物被报告时的指纹。
:::

::: example 测量比旋光度 {#ex-specific-rotation}
一个学生把 $0.40\ \mathrm{g}$ 干燥的手性固体溶于足够溶剂配成 $10.0\ \mathrm{mL}$ 溶液，在 $20\ ^{\circ}\mathrm{C}$ 用 D 线、在 $1.0\ \mathrm{dm}$ 样品管中测得旋光度 $\alpha = +4.8^{\circ}$。计算比旋光度，并对照该化合物 $+120^{\circ}$ 的文献值作出解读。
::: solution
浓度为 $c = 0.40\ \mathrm{g} / 10.0\ \mathrm{mL} = 0.040\ \mathrm{g\,mL^{-1}}$，于是
$$
[\alpha]^{20}_\mathrm{D} = \frac{\alpha}{l\,c} = \frac{+4.8^{\circ}}{1.0\ \mathrm{dm} \times 0.040\ \mathrm{g\,mL^{-1}}} = +120^{\circ}.
$$
实测值与文献值同号同量级：样品与该化合物的对映体纯形式相一致。这个读数还带着两个埋伏：若样品是*另一个*对映体，样品管会读 $-4.8^{\circ}$；而外消旋体无论该固体在其他所有常数上吻合得多么完美，都会读 $0^{\circ}$。与其他常数一样，旋光度要连同其不确定度报告——这里 $1.0\ \mathrm{dm}$ 的样品管和两位的 $\alpha$ 把结果限制在约两位有效数字，而这恰好足以把 $+120^{\circ}$ 与 $0^{\circ}$ 或 $-120^{\circ}$ 区分开。
:::
:::

## 定性化学检验

物理常数说的是*哪种化合物*；定性检验说的是*哪些官能团*，而且用的是一块点滴板和几滴试剂。其逻辑是一棵决策树，而不是单一检验：每个反应回答一个是/否问题，把候选清单修剪一轮，而提问的顺序要对眼前样品讲得通。教学规模的标准筛子是：

- **焰色反应。** 洁净的镍铬丝蘸取氯化物放入蓝色火焰：钠把火焰染成挥之不去的黄色，铜染出一抹绿色。粗糙，但对离子快捷。
- **2,4-二硝基苯肼（2,4-DNP）。** 与试剂（溶于强酸）生成黄色到橙色沉淀，标记出**羰基**——醛或酮。试剂强酸性且染渍；各一滴就是整个实验。
- **托伦斯试剂。** 洁净管壁上的银镜（或灰色沉淀）标记出**醛**。托伦斯试剂必须现用现配、按需取量，用剩的立即用稀酸销毁——**绝不**存放或久置，因为它放置时生成的沉积物会爆炸。
- **溴水。** 橙色溴水与该液体在*通风橱里*振荡（溴有毒且腐蚀，其蒸气会替你下判断）：**烯烃**在黑暗中立即使其褪色，因为溴加成到双键上。
- **三氯化铁。** 滴加中性水溶液 $\mathrm{FeCl_3}$ 一滴：浓烈的紫色标记出**酚**（及其他强螯合的烯醇），来自铁(III)-苯氧负离子配合物。
- **碳酸盐。** 药匙尖的一撮固体加入稀盐酸：二氧化碳剧烈冒泡，标记出**碳酸盐**。
- **溶解性。** 第一个分类不花分文：物质溶于水、稀酸还是稀碳酸氢钠溶液，把酸与中性物、小极性分子与大非极性分子分开。

这些检验无一例外都是试管或点滴板规模的实验，用最小安全量进行，且事先查阅并评估过每种试剂的危险性——正如本图谱中每一个其他实验一样，实践鉴定工作必须在监督下、在风险评估之下进行（[[laboratory-methods/lab-safety]]）。

::: example 选择能定夺的检验 {#ex-choosing-tests}
各给出一个化学检验，用以区分 (a) 环己烷与环己烯；(b) 乙酸与乙酸乙酯。写出每个化合物的预期现象。
::: solution
(a) 溴水，黑暗中：环己烯立即使橙色溶液褪色——双键上的加成——而环己烷让它保持橙色。（焰色或密度也会不同，但溴水才是回答结构问题的那个检验。）(b) 几粒碳酸氢钠，或水与稀盐酸对照：乙酸与碳酸氢钠起泡——它比碳酸强，把碳酸从溶液中赶出来成为 $\mathrm{CO_2}$——且溶于水，而乙酸乙酯是中性酯，不见气泡，也只微溶。注意正在学习的模式：所选检验必须瞄准候选物之间的*差异*（一个 C=C；一个比碳酸强的酸），而不是它们碰巧不同的任何性质。
:::
:::

## 鉴定工作流

::: algorithm 由物理常数鉴定化合物 {#alg-identification}
1. **干燥并纯化。** 重结晶或蒸馏，直到样品就是你以为的那个东西（[[laboratory-methods/separation-purification]]）。在潮湿或不纯样品上测的常数不是坏测量；它测的是另一种物质。
2. **先查纯度，再查身份。** 薄层色谱上一个斑点，和/或尖锐的熔程；沸程拖开 $5\ ^{\circ}\mathrm{C}$ 的液体不是一个化合物（[[laboratory-methods/chromatography-basics]]）。此步不过关就回到第 1 步——在它过关之前，下面每个常数都一文不值。
3. **测量与状态相称的常数。** 固体：熔点，然后与对照真实样品做混合熔点。液体：沸点（注明气压，校正到 $101.3\ \mathrm{kPa}$）、密度、$n_\mathrm{D}^{20}$。手性：比旋光度。
4. **把每个常数与文献作区间对区间的比较**，带上你的测量不确定度与文献值自身的分散度（[[laboratory-methods/measurement-uncertainty]]）。
5. **诚实地掂量结论。** 一个吻合的常数是线索；两个独立的吻合常数是证据；拒绝降低的混合熔点，或一张吻合的光谱，才是定案的一锤（[[spectroscopy/nmr-principles]]、[[spectroscopy/mass-spectrometry]]）。
6. **标记、记录、收存。** 每个数字连同其不确定度与来源记入记录本；绝不把已鉴定的未知物放回公用试剂架。
:::

::: warning 单个吻合的常数永远不能证明身份 {#warn-melting-not-proof}
苯甲酸与阿司匹林共享熔点；异构体成对地碰巧共享折射率与密度；候选表上的三个化合物里可以有两个与你的固体吻合到度，而你仍然错。防止你被愚弄的习惯是一个问题，在每次吻合之后都要问：*如果我错了，哪一个独立测量会不同意？*如果答案是"我做过的测量里没有"，那你手里是线索而不是鉴定——那就去做那个测量：混合熔点、第二个常数、光谱。这条警告还有社会性的一半：你鉴定过的未知物如今是一个关于世界的主张，所以绝不要把它放回公用试剂架，那里下一位同学会相信你写的标签。
:::

## 后续内容

本章的一切都建立在[[laboratory-methods/separation-purification]]的纯化与[[laboratory-methods/chromatography-basics]]的纯度检查之上：在它们之前，常数毫无意义。连同不确定度与文献出处报告常数，是[[laboratory-methods/reporting-integrity]]的主题；每次比较背后的区间算术，是[[laboratory-methods/measurement-uncertainty]]。现代的定案者——把"与……一致"变成"已鉴定"的那些测量——是光谱：[[spectroscopy/nmr-principles]]中的氢谱与碳谱，[[spectroscopy/mass-spectrometry]]中的分子质量与裂解图样，以及[[spectroscopy/vibrational-spectroscopy]]中官能团的指纹，后者一分钟就能做完定性检验决策树当年的全部工作。沸点的气压依赖，以及熔点降低背后的依数性逻辑，在[[general-chemistry-2/liquids-solutions]]中详细展开。

::: summary
- 纯化合物有一套物理常数；鉴定是把每个测得的常数作为一个区间与发表值比较——而没有任何单个常数能证明身份。
- 纯结晶固体在文献熔点处尖锐熔化（$1$–$2\ ^{\circ}\mathrm{C}$）；可溶杂质*既*降低*又*加宽熔程，满足 $\Delta T \approx K x_2$，$K$ 约为每单位摩尔分数 $100\ \mathrm{K}$ 的量级。
- 慢读熔点（接近熔点时 $1$–$2\ ^{\circ}\mathrm{C}\,\mathrm{min^{-1}}$）：升温快则读数偏高，因为样品落后于传感器。
- 保持尖锐的混合熔点支持"同一化合物"；降低的混合熔点证明"不同化合物"——固体鉴定中最有价值的单个数字。
- 对液体：沸点只有连同气压才有意义（校正到 $101.3\ \mathrm{kPa}$）；密度与折射率 $n_\mathrm{D}^{20}$ 精确、对纯度敏感，且只需几滴。
- 旋光度 $[\alpha]^{T}_\mathrm{D} = \alpha/(l\,c)$ 报告手性化合物及其手性方向；对映异构体旋转等大反向，外消旋体完全不旋。
- 定性检验（2,4-DNP、托伦斯试剂、溴水、三氯化铁、碳酸盐、溶解性）构成一棵决策树，在微量规模下运行、危险性先行评估；托伦斯试剂现用现配、用后即毁，绝不存放。
- 工作流：纯化，查纯度，测与状态相称的常数，连同不确定度比较——一个吻合是线索，两个是证据，混合熔点或光谱才是定案的一锤。
:::

## 练习

::: exercise 降低且加宽：纯还是不纯？ {level=1}
某固体文献熔点为 $122\text{–}123\,^{\circ}\mathrm{C}$，从一次重结晶回收后熔于 $118\text{–}122\,^{\circ}\mathrm{C}$。又宽又低的熔程是说该化合物不纯，还是说它纯？给出热力学理由，以及一个值得最先排除的平庸解释。
::: solution
不纯——或者至少不干燥。熔程既降低（提前 $4$ 度开始）又加宽（$4\ ^{\circ}\mathrm{C}$ 宽，而预期是 $1$–$2\ ^{\circ}\mathrm{C}$），而 [[#prop-depression]] 说可溶杂质干的恰恰就是这两件事：它按 $\Delta T \approx K x_2$ 压低液相线，又因为杂质在熔出的液体中不断浓缩，平衡在一个温度跨度上持续存在。纯化合物不可能熔得宽。那个平庸的解释：残留的溶剂或水*就是*杂质——烘得不干的样品与弄脏的样品表现完全一样——所以在怪罪外来化合物之前，第一步是恒重烘干、重装一根毛细管。
:::
:::

::: exercise 比旋光度 {level=1 check="-31.6"}
一个学生把 $0.500\ \mathrm{g}$ 手性固体溶于溶剂并定容到 $10.0\ \mathrm{mL}$，然后在 $20\ ^{\circ}\mathrm{C}$、用钠 D 线、在 $1.00\ \mathrm{dm}$ 样品管中测得 $\alpha = -1.58^{\circ}$。计算比旋光度。（请输入比旋光度，以度计；它为负值。）
::: solution
$c = 0.500/10.0 = 0.0500\ \mathrm{g\,mL^{-1}}$，于是
$$
[\alpha]^{20}_\mathrm{D} = \frac{\alpha}{l\,c} = \frac{-1.58^{\circ}}{1.00\ \mathrm{dm} \times 0.0500\ \mathrm{g\,mL^{-1}}} = -31.6^{\circ}.
$$
负号是结果的一部分：样品是左旋对映体，而文献比较必须针对同一溶剂、温度与波长下报告的数值。
:::
:::

::: exercise 一种检验，两种化合物 {level=1}
说出一个能区分丙醛与丙酮的化学检验，并写出各自的实验现象。为什么 2,4-DNP *不能*区分它们？
::: solution
托伦斯试剂，现用现配：丙醛是醛，把它还原成银镜（或灰色银），而丙酮是酮，毫无反应。2,4-DNP 作为区分检验不合格，因为它回答的是另一个问题——它标记羰基，而*两个*化合物都有羰基，对任何一个都会给出橙色沉淀。能区分的检验必须瞄准差异（那个易被氧化的醛基 C–H），而不是共享的官能团。安全一如既往：托伦斯试剂以点滴板用量现配，实验结束立即用稀酸销毁。
:::
:::

::: exercise 杂质有多少？ {level=2 check="0.04"}
某纯化合物的熔点为 $122.0\ ^{\circ}\mathrm{C}$，实测其澄清点降低了 $4.0\ \mathrm{K}$。用 $\Delta T = K x_2$、取 $K = 100\ \mathrm{K}$，估计可溶杂质的摩尔分数。（摩尔分数以小数输入。）
::: solution
$x_2 = \Delta T / K = 4.0/100 = 0.040$：在化合物自身的分子中间，杂质分子约占 $4\ \%$。这种粗略值得看清：$4$ 度的熔点——在实验台上再明显不过——只对应几个摩尔百分点，这正是"熔于正确温度"与"纯"不是同义词的原因，也是纯化被列为 [[#alg-identification]] 第一步的原因。（这个估计假设稀理想溶液、且杂质被排斥在固相之外；若杂质较重，*质量*分数可能是摩尔分数的几倍。）
:::
:::

::: exercise 由装满液体的比重瓶求密度 {level=2 check="0.789"}
一个空而干燥、容量 $50.00\ \mathrm{cm^3}$ 的比重瓶重 $18.236\ \mathrm{g}$；在 $20\ ^{\circ}\mathrm{C}$ 装满一种无色液体并塞好塞子后重 $57.686\ \mathrm{g}$。计算密度，并从表中鉴定该液体：环己烷（$0.779\ \mathrm{g\,cm^{-3}}$）、乙醇（$0.789$）、水（$0.998$）、二氯甲烷（$1.326$）。（密度以 $\mathrm{g\,cm^{-3}}$ 输入。）
::: solution
液体的质量为 $57.686 - 18.236 = 39.450\ \mathrm{g}$，于是
$$
\rho = \frac{m}{V} = \frac{39.450\ \mathrm{g}}{50.00\ \mathrm{cm^3}} = 0.789\ \mathrm{g\,cm^{-3}},
$$
与乙醇吻合。这个鉴定是*线索*而非判决：密度只是一个常数，诚实的下一个测量是 $n_\mathrm{D}^{20}$（乙醇 $1.361$，环己烷 $1.426$——密度几乎混淆的这一对在折射上相去甚远）或沸点。还要注意区间算术：天平的不确定度在第四位小数，比重瓶校准的不确定度在体积的第三位数字，所以密度诚实到约三位有效数字——足以把乙醇与环己烷分开，但仅勉强够。
:::
:::

::: exercise 为什么升温太快读数偏高 {level=2}
一个学生把熔点仪以 $10\ ^{\circ}\mathrm{C}\,\mathrm{min^{-1}}$ 猛拧，把某化合物的熔点记成了比文献值高 $5$ 度，且熔程很宽。该化合物很可能其实是纯的。请从热流的方向与传感器所在的位置出发，解释为什么升温太快会把读数偏向*高*的一侧，并把熔程加宽。
::: solution
热从加热块经传感器、经毛细管壁流入样品——所以样品永远是整个回路里*最冷*的东西，而传感器报告的是它自己的温度，不是样品的温度。加热期间，这个差与升温速率成正比：在 $10\ ^{\circ}\mathrm{C}\,\mathrm{min^{-1}}$ 下，样品可能比传感器落后好几度。当样品终于到达其真实熔点时，传感器已经高出好几度，于是读数偏高；熔程加宽，是因为厚厚一柱粉末的不同部分在不同时刻到达熔化温度，也因为熔化本身吸热、拽住样品而传感器一骑绝尘。在 $1$–$2\ ^{\circ}\mathrm{C}\,\mathrm{min^{-1}}$ 下，滞后缩到一度以内，读数——以及它的尖锐——才变得可信。这条教训适用于任何有传感器又有样品的测量：仪器读的是传感器所在之处，而每一分钟的缓慢升温都在为你兑换准确度。
:::
:::

::: exercise 设计一套鉴定方案 {level=3}
你手里是一瓶约 $2\ \mathrm{cm^3}$ 的干燥无色液体，没有任何标签。设计完整的鉴定方案：测哪些量，按什么顺序，每一步的判据是什么。并明确说出：在你即将落笔定名之时，什么结果会*证伪*你当时领先的那个假说。
::: hint
按花费与预设给测量排序：纯度在先（沸程很宽、留有残渣或显出两个斑点的液体不是一个化合物，任何常数都毫无意义）；然后是只需一滴的常数（折射、密度）；然后是耗样品的（沸点）；最后是一个独立的结构核查。证伪意味着说出那个若你出错就会不同意的测量——并且真的去做它。
:::
::: solution
(1) 纯度：测 $n_\mathrm{D}^{20}$，并观察一次小量蒸馏或一块薄层板——单一化合物给一个斑点、给不随馏分漂移的常数；不纯则先纯化（[[#alg-identification]]）。(2) 两个滴量常数：$n_\mathrm{D}^{20}$ 与 $20\ ^{\circ}\mathrm{C}$ 的 $\rho$；把候选清单缩到在不确定度内两者都吻合的那些。(3) 当天气压下的沸点，校正到 $101.3\ \mathrm{kPa}$；这是第三个独立常数，还顺带确认干燥（尖锐的沸程）。(4) 一个独立于以上三个数字的结构核查：针对幸存候选物之间差异的定性检验（C=C 用溴水，羰基用 2,4-DNP，胺与酸用稀酸或碳酸氢钠溶解性），或者最好是红外或核磁共振谱。(5) 每个常数连同不确定度与文献值来源一并报告。证伪，具体地说：若常数指向氯仿，那么接近 $40\ ^{\circ}\mathrm{C}$ 的沸点（二氯甲烷），或 $^{1}\mathrm{H}$ NMR 中 $\delta = 7.3$ 附近的单峰对不上，都会与这个指认不同意——所以要在把名字写上试剂瓶*之前*测沸点、拿光谱。若一切吻合，鉴定得到支持；若任何一个测量不同意，假说即死，从第 1 步重来。
:::
:::

::: exercise 三候选物谜题 {level=3}
未知物 X 是干燥的白色固体，在 $122\text{–}123\,^{\circ}\mathrm{C}$ 尖锐熔化。候选物：苯甲酸（$122\ ^{\circ}\mathrm{C}$）、阿司匹林（$122\text{–}123\ ^{\circ}\mathrm{C}$）、扁桃酸（$119\text{–}121\ ^{\circ}\mathrm{C}$）。混合熔点：X + 苯甲酸熔于 $122\text{–}123\,^{\circ}\mathrm{C}$；X + 阿司匹林熔于 $112\text{–}120\,^{\circ}\mathrm{C}$。鉴定 X 并解释每个观察。X + 扁桃酸本会显示什么？这个谜题需要那个实验吗？
::: solution
X 是苯甲酸。与对照苯甲酸的混合物根本不是混合物——同一化合物加同一化合物仍是纯化合物——所以熔程保持在 $122\text{–}123\,^{\circ}\mathrm{C}$ 而依旧尖锐（[[#prop-depression]] 的反面：$x_2 = 0$ 时 $\Delta T = 0$）。与阿司匹林的混合物降低到 $112\text{–}120\,^{\circ}\mathrm{C}$ 并加宽：阿司匹林是苯甲酸中的可溶杂质，于是这一对沿液相线熔化，而 X 不可能是阿司匹林。扁桃酸自己的文献熔点（$119\text{–}121\ ^{\circ}\mathrm{C}$）已经低于 X 的尖锐熔程，而那个混合物即使做了，也会像阿司匹林那个一样降低、加宽——不同的化合物，彼此互为杂质。这个谜题并*不*需要第三个实验：两个混合结果已经排除了阿司匹林、确认了与苯甲酸的同身份。但一份谨慎的报告还是会把它做掉，因为"不降低"是承重的观察，而对它的一个确认太单薄——并且会再以一张光谱收尾，因为混合熔点证明的是"与我拿去混合的那瓶东西相同"，而那瓶东西自己的标签，是你并未核查过的一个文献值（[[#warn-melting-not-proof]]）。
:::
:::
