1825 年，李比希（Liebig）在他专门建造的吉森教学实验室里，从大半个欧洲招收学生来"动手做"中学化学——同时他记着一本名为《事故登记簿》（*Unfallbuch*）的书，把每一起事故都记录在案：在学生手中炸开的瓶子，灼进实验台、也灼进搁在台边的那只手的酸。这本登记簿不是官僚主义。它承认了一个事实：实验室是一个地方，其中细小而重复的错误不断累积，直到某一次变成伤害；而打断这种累积的唯一可靠办法是一项*训练出来的技能*：找出危害，估计风险，装上控制，检查它是否有效，然后写下来。海报和讲座打断不了这种累积；习惯才能。本章讲的就是这些习惯，以及习惯背后的理由——因为知道*为什么*的化学家，能把一条规则延伸到规则手册从未预见的场合。

::: history 从事故登记簿到 GHS 之路 {#hist-safety-road}
1852 年，本生（Bunsen）在操作砷化合物时因实验台爆炸失去了一只眼睛的视力；在他身旁工作的年轻罗斯科（Roscoe）也在同一次爆炸中受伤。李比希的《事故登记簿》及其后继者记录了成千上万起这样的事件，而一个世纪以来，应对之道多半只是个人的小心谨慎。转折出现在 1980 年代的"知情权"立法——尤其是美国职业安全与健康管理局（OSHA）1986 年的《危害沟通标准》，它首次赋予劳动者法定权利去获取雇主掌握的危害信息，并迫使整个行业把知识写进标签。此后，互不兼容的各国符号体系经过数十年磨合，汇聚到联合国《全球化学品统一分类和标签制度》（GHS）之上；其第一版于 2003 年问世，如今实际上随地球上每一批化学品运输同行。你瓶子上那张标签，是一场持续了一百五十年、争论"谁必须告诉你什么"的终点。
:::

## 危害、风险与风险评估

整个实验室安全建立在一条区分之上，这条区分值得说得完全准确。

::: definition 危害与风险 {#def-hazard-risk}
**危害**是物质、混合物或过程的固有属性：造成伤害的能力（灼伤皮肤、点燃、中毒、助长火灾）。**风险**则是伤害在特定情形下真正落到特定人头上的机会：**风险 = 可能性 × 严重度，以暴露为条件**。危害是化学品的属性；风险是你*正在用它做的那件事*的属性。浓乙酸在通风库房里的密封桶中，有真实的危害（腐蚀性、易燃），风险却极低；同样的酸倒进拥挤实验台上的敞口烧杯，危害不变而风险高得多。前者你通常改不了；后者你能改，而这就是安全工作的全部内容。
:::

"暴露"一词承载了全部分量，而暴露经四条途径到达人体。**吸入**在化学实验室中占主导：敞口容器的蒸气、称量时扬起的粉尘、沸腾产生的雾滴、加热产生的烟，都被送进肺部，而那里的气体交换表面大、薄、供血充沛。吸入多少取决于挥发性、温度、通风以及你的脸离容器多近——这就是"在通风橱内离开口至少 15 cm 处操作"直接打击暴露项、而非吹毛求疵的原因。**皮肤与眼睛接触**既包括显而易见的溅洒，也包括与污染手套的长时间接触：许多物质造成伤害的方式，是被*贴压*在皮肤上足够久而渗透进去。**食入**几乎总是自己不小心——摸过化学品的手去碰嘴，在洗过玻璃器皿的台面上喝饮料，用嘴吸移液管（一律禁止，因为它的失效模式是吞下腐蚀性液体）。**注入**——污染的针头或锋利玻璃把物质送进皮下——是最快的途径，因为它完全绕过了皮肤屏障；它很少发生，而这正是锐器必须进专用锐器盒的原因。

由于风险是两个因子的乘积，就可以从任一侧打击它：降低可能性（密闭体系、训练、台面不杂乱），或降低严重度（更小的量、更低的浓度、在瓶子与脸之间放一扇拉门）。把这件事有意识地做出来的标准工具，是一个简短的程序。

::: algorithm 五步风险评估 {#alg-risk-assessment}
**输入：**你即将开展的实验、所涉化学品与用量、仪器设备，以及周围的人。**输出：**一份写下来并付诸行动的预案，把风险降到你愿意向同事担保的水平。
1. **识别危害。**动手之前读完每种化学品的安全数据表（见下文）；记下 GHS 象形图与危险性说明；再加上过程本身的物理危害——明火、热玻璃器皿、真空内爆、压力、腐蚀性废液。
2. **确定谁可能受到伤害、如何受到。**先是你自己，但还有邻座的同学、清理你废液的保洁员、任何哮喘或乳胶过敏的人；为每项危害指明暴露途径。
3. **评估并控制。**对每项风险，先问什么可以消除或替代，再伸手去拿设备；然后采用工程控制与安全的工作方式，最后才是个人防护装备（控制措施层级，见下文）。在化学允许之处减少用量与浓度。
4. **记录并行动。**把结论写下来——教学实验一段话就够——做好预案要求的准备（找到溢液处理包、确认洗眼器位置、给废液容器贴好标签），并向与你一起工作的人交底。
5. **复查并更新。**若你更换了试剂、规模或步骤，评估即告过期；任何事故或未遂事故之后都要重新审视。
:::

教学实验室常把第 3 步形式化为**风险矩阵**：给每个已识别事件的可能性（从罕见到几乎必然）与严重度（从急救到致命）打分，读出一个等级，判断该活动按原计划是否可接受、还是需要更多控制。矩阵是交流工具，不是计算器——它的价值在于迫使两个化学家去争论一个数字，而不是对彼此的直觉挥手了事。下面的交互图用曲线表达了同一个意思。

## 危害的传递：GHS 与安全数据表

你无法评估一个没人告诉你的危害，也不能指望总有人当面告诉你。危害沟通的存在，是为了让一瓶在一个国家生产、经第二国运输、被第三国学生打开的化学品，自带警告而来。做这件事的体系，是联合国的**全球化学品统一分类和标签制度**（GHS），自 2000 年代起在多数国家生效。

::: definition GHS 标签：象形图、信号词、H 说明与 P 说明 {#def-ghs}
一张 GHS 标签最多带有九个标准化的**象形图**——白底黑色符号，外罩红边菱形——每个命名一个*危害类别*：**爆炸物**（爆炸的炸弹）、**易燃**（火焰）、**氧化性**（圆圈上的火焰）、**加压气体**（气瓶）、**腐蚀性**（两支试管把手和一块表面浇上液体）、**急性毒性**（骷髅与交叉骨）、**健康危害**（躯干轮廓、胸口带星芒，用于致癌物、呼吸致敏物与器官毒物）、**感叹号**（刺激品、有害品、皮肤致敏物、麻醉效应），以及**环境危害**（枯树与死鱼）。一个**信号词**——较严重类别用*危险*（Danger），较轻类别用*警告*（Warning）——定下音量，两族编号句子承载细节：**H 说明**（危险性说明）命名危害（"H314：造成严重皮肤灼伤和眼损伤"），**P 说明**（防范说明）规定预防（"P280：戴防护手套/穿防护服/戴护眼罩"）。同一个象形图在世界每一只瓶子上意味着同一个类别——这就是它存在的全部意义。
:::

读标签是一门十秒钟的技能：记下象形图，把信号词当作总音量旋钮，然后读 H 说明看*是什么*伤害、读 P 说明看*该怎么做*。标签只是摘要；完整的文件是安全数据表。

::: definition 安全数据表 {#def-sds}
**安全数据表**（SDS，旧称 MSDS）是随化学品同行的十六节标准化文件：(1) 化学品及企业标识，(2) 危险性概述，(3) 成分/组成信息，(4) 急救措施，(5) 消防措施，(6) 泄漏应急处置，(7) 操作处置与储存，(8) 接触控制/个体防护，(9) 理化特性，(10) 稳定性和反应性，(11) 毒理学信息，(12) 生态学信息，(13) 废弃处置，(14) 运输信息，(15) 法规信息，(16) 其他信息。实验之前至少读五节：**2**（GHS 分类与象形图）、**7**（如何操作与储存——不相容性住在这里）、**8**（供应商认为你需要的通风与个人防护装备）、**10**（它与什么反应、分解成什么、是否会生成过氧化物或发生聚合），以及 **11**（毒理学终点——哪些器官、哪种暴露、哪些效应）。第 4、5、6、13 节，你应当在事故、溢液或废液瓶出现*之前*就知道它们在哪里。
:::

::: warning 象形图是危害类别，不是风险排名 {#warn-pictograms}
三种误读要趁早纠正，否则迟早付出代价。第一，象形图并不按"最安全"到"最危险"排队：骷髅与交叉骨标记的是*急性*毒性，而一只只带感叹号的瓶子，其慢性效应可能比泼一下急性毒性品更糟——各类别回答的是不同的问题。第二，"健康危害"对*多少*才算危险一无所言：它标记的是一类效应（致癌、器官损伤、致敏），不是剂量—反应的量级，而同一类别内部的浓度可以相差好几个数量级。第三，也是最危险的一条，**没有象形图不等于"安全"**——它的意思是"未按 GHS 标准分类"，这既不包括科学尚未发现的功效，也不包括那种先把你手上的油脂慢慢抽干、二十年都测不出异常的溶剂，更不包括一只热烧杯这个简单事实。一只没有标签的瓶子不是无害的瓶子，而是一只未经评估的瓶子，应当被当作房间里最危险的东西。
:::

::: quiz
浓硫酸瓶上必须带哪个 GHS 象形图？
- [x] 腐蚀（两支试管把手和一块表面浇上液体）。
- [ ] 骷髅与交叉骨（急性毒性）。
- [ ] 圆圈上的火焰（氧化性）。
- [ ] 枯树与死鱼（环境危害）。
::: solution
浓硫酸被划入皮肤腐蚀类别（H314：造成严重皮肤灼伤和眼损伤），因此必须使用**腐蚀**象形图，信号词为*危险*。它未按经口、吸入或皮肤接触标准划入急性毒性（骷髅与交叉骨），按通常供货状态也不在氧化性类别（圆圈上的火焰——热的浓酸在*化学上*是氧化剂，但分类依据的是试验标准，不是直觉），也未划入环境危害。凭化学直觉猜象形图恰恰是要避免的错误：分类是依据明确标准的法律—技术行为，所以请读标签和安全数据表。
:::
:::

::: example 实验前读 SDS：浓硝酸 {#ex-read-sds}
你即将使用几 $\mathrm{cm^3}$ 浓硝酸。SDS 第 2 节给出两个象形图——圆圈上的火焰与腐蚀——信号词为*危险*，H 说明包括 H272（"可能加剧火灾；氧化剂"）、H314（"造成严重皮肤灼伤和眼损伤"）与 H335（"可能造成呼吸道刺激"）。第 10 节警告该酸腐蚀金属，并与碱和有机物剧烈反应。因为每一行，你在实验前后要分别做些什么不同的事？
::: solution
**H272（氧化剂）：**储存规则彻底改变——硝酸必须远离燃料与有机物：不与乙醇或丙酮同在易燃品架上，不与它们同盘搬运，且溅到有机吸附材料（锯末、布、纸巾）上的溢液要避开处理，因为浸透的材料可能自行起火。**H314（腐蚀性）：**戴防溅护目镜，检查手套对酸的穿透时间，台面清空，并在开瓶*之前*确认洗眼器位置。**H335 以及浓硝酸久置冒出的棕色二氧化氮烟气：**在通风橱内量取，拉门降到操作允许的低处。**第 10 节不相容性：**不得在密闭容器里用浓碱中和溢液（反应放热并升压），金属药匙不得留在酸里，废酸进贴标签的酸性水相废液容器——绝不进有机废液瓶，因为氧化剂进有机废液瓶正是废液间起火的方式。一行 SDS，改变一个行为：这就是"读 SDS"的含义。
:::
:::

## 工程控制与个人防护装备

当风险评估出来的结果太大，你就要安装控制措施，而控制措施有尊卑，称为**控制措施层级**。顶端是**消除**：不做这一步，不产生这份废液，不让这瓶试剂进楼。其次是**替代**：一间实验室把萃取课上的苯（已知人类致癌物）换成甲苯，它不是靠小心让活动变安全——它改变了危害本身，这是再多小心都做不到的。然后是**工程控制**：通风橱、溶剂柜、替你托住烧瓶的铁架台。再是**管理控制**：培训、书面规程、标识、高风险作业的伙伴制度。**个人防护装备排在最底层**——不是因为它不重要，而是因为它是其他一切控制都失效后剩下的那道控制，它只保护穿戴者本人，而且它无声地失效（一只被穿透的手套，感觉与干净的手套一模一样）。个人防护装备是最后一道防线，永远不是方案本身。

通风橱是教学实验室的主力工程控制，值得把它当作一台装置来理解，而不是当作一条迷信。

::: proposition 面风速 {#prop-face-velocity}
一台以 $Q$（单位 $\mathrm{m^3\,h^{-1}}$）的体积流量、经面积 $A$（单位 $\mathrm{m^2}$）的拉门口排风的通风橱，其平均**面风速**为
$$
v = \frac{Q}{3600\,A}
$$
单位 $\mathrm{m\,s^{-1}}$。教学实验室通常按工作拉门高度下 $v$ 保持在 $0.4$ 至 $0.6\ \mathrm{m\,s^{-1}}$ 之间验收：低于该范围，蒸气会逸出围控；远高于该范围，拉门口边缘的湍流会把空气*拖出*橱外，围控从另一个方向失效。
:::

::: proof 面风速关系式 {#proof-face-velocity}
在这些速度下空气表现为不可压缩流体，而稳态下经拉门口每小时进入橱内的空气体积，必须等于排风排出的体积——橱内没有空气积累。排风每小时排出 $Q\ \mathrm{m^3}$，即每秒 $Q/3600\ \mathrm{m^3}$；若开口上的平均速度为 $v$，则每秒穿过开口的体积为 $vA$。令两个速率相等，
$$
vA = \frac{Q}{3600}
\qquad\Longrightarrow\qquad
v = \frac{Q}{3600\,A},
$$
单位也对得上：$\mathrm{m^3\,h^{-1}}$ 除以 $\mathrm{h\,s^{-1}} \times \mathrm{m^2}$ 剩下 $\mathrm{m\,s^{-1}}$。两个推论在实验台上要紧。第一，$v \propto 1/A$：拉门抬高，开口加倍，面风速减半——所以拉门*就是*控制；保护你的不是通风橱，而是拉门高度。第二，开口上的速度剖面并不平坦，这就是验收范围按平均值给出的原因，也是拉门立柱上的显示器本身就是台需要校准的仪器、应受与天平同等尊重的原因——见[[analytical-chemistry/statistics-calibration]]。
:::

::: example 检查一台通风橱 {#ex-face-velocity}
一台宽 $1.20\ \mathrm{m}$ 的通风橱，拉门口高 $0.40\ \mathrm{m}$，显示器读得排风量 $850\ \mathrm{m^3\,h^{-1}}$。求平均面风速，并判断它是否落在工作范围 $0.4$–$0.6\ \mathrm{m\,s^{-1}}$ 内。然后求一名学生嫌仪器放不下、把拉门抬到 $0.80\ \mathrm{m}$ 后的面风速。
::: solution
开口面积 $A = 1.20 \times 0.40 = 0.48\ \mathrm{m^2}$，于是
$$
v = \frac{Q}{3600\,A} = \frac{850}{3600 \times 0.48} = \frac{850}{1728} = 0.49\ \mathrm{m\,s^{-1}},
$$
稳稳落在 $0.4$–$0.6\ \mathrm{m\,s^{-1}}$ 之内：通风橱按验收状态工作。把拉门抬高使面积加倍到 $0.96\ \mathrm{m^2}$，风速减半到 $0.25\ \mathrm{m\,s^{-1}}$——低于范围，于是你产生的蒸气如今在去往开口的路上横穿你的脸。排风机没有变；变的是*活动*，风险随之而变。同样的危害，不同的暴露，不同的答案。
:::
:::

台面纪律由物理推出：在开口以内至少 $15\ \mathrm{cm}$ 处操作，拉门保持在工作允许的最低处、人走即全闭，并且绝不要把通风橱当化学品储存柜——存放的瓶子会挡住气流缝隙，毁掉上面证明所依赖的那个速度剖面。

手套是实验室里被信任过头的物件，因为手套笼统地说不是"化学品防护"；它是特定材料，对每种特定化学品有一个特定的**穿透时间**，由制造商公布，从首次接触测到可检出的渗透。丁腈橡胶对许多水溶液、稀酸和醇类表现良好；乳胶戴水相作业舒服，但对多数有机溶剂很差，且本身就是致敏原；氯丁橡胶适合稀酸稀碱；丁基橡胶是酮类与酯类的选择。一些小而侵蚀性强的分子——二氯甲烷就是其中之一——几分钟就能穿透薄的一次性手套，所以"合手"的手套对那瓶试剂未必"防护"。把手套当耗材用：使用前检查溶胀与变色，污染后即换，脱手套时别把内容物转移到你的手机、键盘和脸上。护目镜围绕眼睛密封，防御来自正面、侧面和下方的溅液；防护眼镜只替眼睛挡冲击、别的都挡不住，所以防溅作业——以及一切腐蚀性操作——要求护目镜，大量转移时外面再加面屏。再加上不体面却必要的部分：及大腿中部的扣紧实验服、包脚的鞋、束起的长发，以及在有蒸气积聚可能的区域不戴隐形眼镜（隐形眼镜本身不危险，但它让你在最初几分钟的关键时刻无法用洗眼器冲洗眼睛）。

## 存放、操作与废弃物处理

储存是把危害沟通向时间维度延伸：绝不可相遇的化学品，就绝不可*同架存放*。**氧化剂远离燃料与有机物**——硝酸、高锰酸盐与过氧化物离开易燃品架、不进易燃品柜，因为氧化剂供养一场靠限制空气扑不灭的火，而被溢液浸透的有机材料碰上氧化剂可能自行点燃。**酸远离碱与碳酸盐**——一只裂开的酸瓶把酸滴到固体碳酸钠上，会在关着门的柜子里释放二氧化碳直到柜门被顶开；酸浇到浓碱上放出的热足以把液体煮沸（[[general-chemistry-1/solutions-reactions]]里的中和焓，就是让溢液清理变成"热手"任务的同一个数字）。**易燃品进柜**，用为它们建造的柜子，只放教学需要的量、不再多。每一只瓶子和废液容器都带着写明**名称、浓度、日期与责任人**的标签，外加象形图；标签溶掉脱落的瓶子不是"匿名瓶"，而是*未分类瓶*，它应走未知化学品处置程序，而不是进你的实验。而最古老的规则至今有效，因为它依然管用：**实验室内禁止饮食**——食入途径只需要一次马虎的午餐，而存放试剂的冰箱绝不该有可能存放三明治。

::: example 储存谜题：托盘上的四只瓶子 {#ex-storage-puzzle}
一批到货用一只托盘送来：浓硝酸、乙醇、氢氧化钠水溶液和氯化钠溶液。送回库房路上，哪两只瓶子绝不能同盘？为什么？再按隔离规则检查其余各对。
::: solution
**硝酸与乙醇**是禁忌的一对：氧化剂（H272）与易燃液体（H226）在托盘里相距几厘米地同行，而托盘在你绊倒时是会翻的——这是燃料与氧源预先混合好的火灾，而且两者的 SDS 第 10 节都写明了这一不相容性。其余各对相形之下无害，但仍值得推演一遍：硝酸与氢氧化钠是酸对碱，同时破碎就是一场剧烈飞溅的中和，所以大体积时二者应分盘并加次级容器盛装；氯化钠溶液是唯一不违反任何规则的乘客。普遍原则：按*不相容性*隔离，而不是按字母顺序；绝不让单一事故（一只翻倒的托盘）同时提供一场反应的两半。
:::
:::

操作规则是同一套物理的近距离版本。瓶子用托盘或提篮搬运，绝不提瓶颈。开瓶时瓶口偏离面部，闻气味用手扇闻，绝不把鼻子凑到瓶口。浓酸的稀释值得单独一条规则，因为算术容易，放热不容易：

::: example 稀释浓盐酸 {#ex-dilution-hcl}
你需要 $500.0\ \mathrm{cm^3}$ 的 $2.00\ \mathrm{mol\,dm^{-3}}$ 盐酸，而库存瓶上写着 $12.0\ \mathrm{mol\,dm^{-3}}$。需要多少体积的浓库存液？如何配制？（本操作及一切类似配制，都须在监督下、经风险评估后进行：酸有腐蚀性，其蒸气有刺激性，且稀释放热强烈。）
::: solution
所需 $\mathrm{HCl}$ 的物质的量为 $cV = 2.00 \times 0.5000 = 1.00\ \mathrm{mol}$，所以库存液体积为
$$
V = \frac{1.00\ \mathrm{mol}}{12.0\ \mathrm{mol\,dm^{-3}}} = 0.0833\ \mathrm{dm^3} = 83.3\ \mathrm{cm^3}
$$
（[[general-chemistry-1/matter-measurement]]里的物质的量算术）。现在说规则：**永远把酸加进水里，绝不把水加进酸里。**向烧杯里量取约 $200\ \mathrm{cm^3}$ 水，然后在通风橱内把 $83.3\ \mathrm{cm^3}$ 浓酸分次加入并搅拌。浓酸稀释时离子水合每摩尔放出数十千焦热量；若把水加*进*酸里，最初几滴水落在致密炽热的酸层上可能爆炸性沸腾，把浓酸溅遍台面和操作者，而把酸加进大量水中，则一次就被全部体积稀释并冷却。待溶液冷却，定量转移（把烧杯冲洗进容量瓶）至 $500\ \mathrm{cm^3}$ 容量瓶，定容，倒转混匀。量筒量的是酸；容量瓶量的是*最终体积*——绝不在容量瓶本身里溶解或稀释，它的校准只对应一个温度，而它细长的瓶颈是热量最不该去的地方。
:::
:::

废液是带着你指纹的化学品，而且要在产生*之前*就分好类别：**含卤有机废液**（二氯甲烷、氯仿及其洗涤液——氯让焚烧化学变得讨厌，值得花钱分开）、**不含卤有机废液**（乙醇、丙酮、己烷）、**含重金属水相废液**（铜、铅、铬、汞的溶液——按金属回收，而非排放），以及供中和的**酸性/碱性水相废液**。什么都不许进下水道：下水道是一场不受控制的稀释，而"只有几 $\mathrm{cm^3}$ 而已"恰恰是一千名学生乘以一吨的那道算术。废液容器要贴标签、保持密闭、保持小体积——你操作的量越小，下游每一个问题就越小，这正是教学实验室转向微量实验的原因。

::: example 给一次实验的废液分类 {#ex-waste-classification}
萃取课结束时，你手里有一支分液漏斗，内有水层（水、硫酸铜和少量硫酸）和二氯甲烷层，另有二氯甲烷洗涤漏斗的洗涤液。每部分去哪里？
::: solution
三个去处，没有一个是水槽。**二氯甲烷层与二氯甲烷洗涤液**进*含卤有机废液*容器——二氯甲烷带健康危害象形图（疑似致癌物），不得排空也不得排放。**水层**进*含重金属水相废液*容器：硫酸铜被分类为对水生生物毒性极大并具有长期持续影响（H410），所以把这一股废液钉在金属回收路线上的是铜，而不是稀酸。其余洗涤液按其主要危害走同样逻辑。注意*同一支漏斗*产生两股废液：分类跟着每个容器的内容物走，不跟着实验走；"图省事倒在一起"是把两种危害合并成一个更糟的问题。
:::
:::

## 出了事故怎么办

没有哪道控制是完美的，所以安全的最后一部分是演练过的响应。**眼睛：**用洗眼器冲洗整整 **15 分钟**——撑开眼睑，转动眼球，让一位同事开始计时并陪着你；隐形眼镜在冲洗*过程中*摘出，而不是之前；15 分钟感觉荒唐，直到你想起另一边的选择：在你与它争论的当口，那个化学品仍在不停反应。然后就医，并带上瓶子或 SDS。**皮肤与身体：**大体积溅洒和着火的衣物用紧急冲淋装置（停下、卧倒、遮盖，然后冲淋；灭火毯靠窒息灭火，适合扑灭小火盆火，不适合裹一个惊慌失措的人）。**火灾：**知道哪种灭火器对应哪类火——水或泡沫对普通可燃物（A 类），泡沫、干粉或二氧化碳对易燃液体（B 类），干粉或二氧化碳对电气火灾，其中二氧化碳是实验室首选，因为它不在仪器上留下任何东西；金属火灾绝不用水。**溢液：**警告全场，远离蒸气云，用与该化学品匹配的溢液处理包由外向内处置，并把清理出的废物按它如今变成的化学品来装袋。

任何事故的序列都是固定的：**先保护人**（包括你自己——第二个伤员帮不了任何人），**移除或隔离源头**（关气、关加热板、把瓶子盖好），**通报**（立即、大声地告诉技术员或指导教师），**报告**（离开之前写下来）。每一起事故*和每一次未遂事故*都要报告：那只本该摔碎却被台沿挂住的瓶子，你转头时已经放下的拉门。未遂事故是安全能产出的唯一免费数据——吉森登记簿之所以宝贵，恰恰因为其中多数条目是未遂事故——而一个报告未遂事故的实验室，是用一点难为情换信息。

## 后续内容

安全是科学方法中保护科学家的那一部分，它倚靠着本课程的其余章节：你上面用来让酸变安全的物质的量与稀释算术在[[general-chemistry-1/matter-measurement]]，决定一种溶剂向你的呼吸贡献多少的蒸气压在[[general-chemistry-2/liquids-solutions]]，而让风险评估不止是一种心情的那些带着不确定度的诚实数字在[[laboratory-methods/measurement-uncertainty]]。之后每一章技术都是本章的应用：[[laboratory-methods/separation-purification]]里的溶剂，选择时兼顾危害与分配系数；[[laboratory-methods/identifying-compounds]]里的定性检验之所以微量，是因为小剂量是世上最便宜的控制。你今天灌满的那些废液容器，将成为[[analytical-chemistry/analytical-process]]里绿色化学的账目——原子经济性与废物因子，是安全被设计进流程、而不是螺栓在台面上的样子。

::: summary
- 危害是固有属性；风险是以暴露为条件的可能性 × 严重度——安全工作改变的是风险，因为危害通常是固定的。
- 暴露经四条途径到来——吸入、皮肤/眼睛接触、食入、注入——本章每项控制都打击其中一条。
- 五步风险评估（识别、谁与如何、评估并控制、记录并行动、复查更新）是写下来、可重复的程序，不是一种感觉。
- GHS 标签用九个象形图、信号词与 H-/P 说明传递危害类别；十六节的 SDS 是完整文件，第 2、7、8、10、11 节是实验前的必读。
- 象形图不排名次，而沉默的意思是"未分类"，不是"安全"。
- 控制按层级排序：消除、替代、工程、管理——个人防护装备最后，因为它无声地失效。
- 通风橱靠面风速 $v = Q/(3600\,A)$ 提供保护，维持在 $0.4$–$0.6\ \mathrm{m\,s^{-1}}$ 附近；拉门就是控制，操作在开口以内 $15\ \mathrm{cm}$ 处进行。
- 按不相容性隔离（氧化剂离燃料，酸离碱与碳酸盐），一切贴标签，废液按类别归位，每起事故与未遂事故都报告。
:::

::: exercise 象形图与 H 说明 {level=1}
把每条 H 说明与它所属的 GHS 象形图配对，并命名危害类别：(a) H226"易燃液体和蒸气"；(b) H272"可能加剧火灾；氧化剂"；(c) H314"造成严重皮肤灼伤和眼损伤"；(d) H400"对水生生物毒性极大"。
::: solution
(a) 火焰——易燃液体。(b) 圆圈上的火焰——氧化性液体和固体。(c) 腐蚀——皮肤腐蚀（1 类）。(d) 环境危害——对水生环境有害。在教学实验室浓度下，(c) 的信号词为*危险*，(a)、(b)、(d) 为*警告*。
:::
:::

::: exercise 面风速 {level=1 check="0.56"}
一台宽 $1.50\ \mathrm{m}$ 的通风橱，拉门口高 $0.30\ \mathrm{m}$，排风量为 $900\ \mathrm{m^3\,h^{-1}}$。用 $v = Q/(3600\,A)$ 计算平均面风速。（以 $\mathrm{m\,s^{-1}}$ 输入面风速，保留两位小数。）它是否在工作范围 $0.4$–$0.6\ \mathrm{m\,s^{-1}}$ 之内？
::: solution
$A = 1.50 \times 0.30 = 0.45\ \mathrm{m^2}$，所以 $v = 900/(3600 \times 0.45) = 900/1620 = 0.56\ \mathrm{m\,s^{-1}}$——在范围之内。
:::
:::

::: exercise 稀释体积 {level=1 check="20.8"}
你需要用 $12.0\ \mathrm{mol\,dm^{-3}}$ 的库存液配制 $250.0\ \mathrm{cm^3}$ 的 $1.00\ \mathrm{mol\,dm^{-3}}$ 盐酸。应量取多少体积的库存液？（以 $\mathrm{cm^3}$ 输入体积，保留一位小数。）酸与水按什么顺序混合，为什么？
::: solution
$n = 1.00 \times 0.2500 = 0.250\ \mathrm{mol}$，所以 $V = 0.250/12.0 = 0.0208\ \mathrm{dm^3} = 20.8\ \mathrm{cm^3}$。酸入水，绝不水入酸：稀释放热强烈，水滴落在浓酸上可能使其沸腾飞溅，而把酸搅进大量水中则立即被冷却和稀释。
:::
:::

::: exercise 储存隔离 {level=2}
四只瓶子要送回库房：丙酮（易燃）、浓硫酸（腐蚀性）、高锰酸钾水溶液（氧化性、腐蚀性）、稀乙酸（腐蚀性）。为两个货架和一个易燃品柜提出隔离方案，给出每个位置的理由，并指出必须相距最远的那一对。
::: solution
丙酮进易燃品柜（H226；挥发性强，而柜子限制蒸气积聚与火灾暴露）。高锰酸钾放在远离一切有机物与燃料的氧化剂架上（H272）。两种酸——硫酸与乙酸——共用一个酸架，远离碱、碳酸盐和氧化剂架。必须相距最远的一对是**高锰酸钾与丙酮**：强氧化剂与易燃挥发液体，正是"氧气另行供应"的经典火灾组合，而一次倾倒的货架会在无人选择的情况下把它们混在一起。硫酸与高锰酸钾也值得分开（酸会浓缩氧化能力），但燃料才是让高锰酸钾—丙酮成为最坏一对的原因。
:::
:::

::: exercise 为挥发性腐蚀品选择控制与个人防护装备 {level=2}
某规程要求你量取 $50\ \mathrm{cm^3}$ 浓盐酸（腐蚀性，H314；在空气中强烈发烟）并按例题稀释。在层级中仍然适用的各标题（消除/替代、工程、管理、个人防护装备）下列出你将采用的控制措施，并说明每条属于哪个标题。
::: solution
**消除/替代：**问实验能否用更低浓度或更小体积进行——由技术员为全班配好一份 $2.00\ \mathrm{mol\,dm^{-3}}$ 的工作液，就取代了三十名学生各开一次浓试剂瓶。**工程：**在通风橱内以工作面风速量取与稀释，拉门放低；在托盘上方操作以承接滴液。**管理：**开始前读过风险评估；不单独作业；确认洗眼器、冲淋装置与溢液处理包位置；库存液预先分发，使瓶子只开一次。**个人防护装备：**防溅护目镜（不只是防护眼镜），检查过对酸穿透时间的丁腈手套并正确脱除，扣紧的实验服与包脚的鞋。注意个人防护装备排在最后，且不提供通风橱已经做到之外的任何东西——它是为失效准备的，不是为方案准备的。
:::
:::

::: exercise 风险矩阵 {level=2}
一名学生计划在过道旁的实验台上，用加热板在敞口烧瓶中加热 $30\ \mathrm{cm^3}$ 乙醇，并用本生灯加热水浴"因为加热板占着"。用 $5 \times 5$ 矩阵（可能性与严重度各 1–5，等级 = 乘积），给"易燃蒸气被点燃"这一事件打分：(i) 按原计划；(ii) 改用密闭加热套、在远离过道的通风橱内进行之后。每次改变打击的是哪个因子？在教学实验室里，你会坚持 8（满分 25）的等级阈值吗？
::: solution
(i) 按原计划：乙醇的闪点远低于水浴温度，蒸气在持续产生；明火是*有意*在场的，过道又添了一条绊倒—泼洒路径——可能性 4，严重度 4（灼伤，可能起火）→ 等级 16：不可接受，停下重新设计。(ii) 密闭加热套移除了点火源，通风橱围控蒸气：可能性降到 2，严重度仍是 4（热液体仍能烫伤）→ 等级 8：在个人防护装备与洗眼器就位的前提下勉强可接受。重新设计打击的是*可能性*一列（点火源、蒸气释放）；个人防护装备只能触及*严重度*，这正是它排位更低的原因。阈值取 8 意味着"任何很可能发生、或可能造成严重伤害的事件，批准前都需要重新设计"——在教学实验室里这是一条站得住的线。
:::

::: exercise 一份迷你风险评估 {level=3}
为"从水中重结晶几克粗苯甲酸"写一份迷你风险评估（按[[#alg-risk-assessment]]的每一步各写一段）：加热板加热，热过滤，冷却结晶，减压过滤。危害、控制、废液与应急都要覆盖——并记住"溶剂是水"不等于"风险为零"。
::: hint
沿着*过程*危害过一遍，而不只是看瓶子：什么是热的，什么在抽滤，什么能割伤人，滤液里有什么？苯甲酸是刺激品（感叹号），而粗产品可能带着制取它时残留的酸性杂质——母液去哪里？
:::
::: solution
**1. 危害：**热液体与蒸汽（烫伤）；与冷玻璃器一模一样的热玻璃器；处于真空下的抽滤瓶（内爆与割伤）；苯甲酸固体，一种刺激品（感叹号），研磨时还是粉尘；粗品中的酸性杂质；真空管线把水倒吸入泵。**2. 谁与如何：**你（热过滤时的烫伤、割伤、溅入眼）；邻座（蒸汽、脚下洒出的晶体）；保洁员（湿滑的废弃物）。**3. 评估并控制：**用加热板而非明火（水不可燃，但纸和外套可燃）；加热前加入沸石；热玻璃器用坩埚钳与耐热手套；热过滤戴护目镜；减压过滤经带支管保护的抽滤瓶并串接安全瓶，先放空泵*再*拆管，以免水倒吸；用量保持教学规模。**4. 记录并行动：**处理固体时戴护目镜与手套，溢液吸纸备好；酸性母液进酸性水相废液容器，回收固体进贴标签的产物瓶——都不进水槽，因为一千次酸性漂洗就是一吨酸；确认洗眼器位置。**5. 复查：**若日后把该操作改成乙醇重结晶，整份评估都要改写——溶剂变成易燃的，加热板的问题随之变得紧迫。本题的要点：一个以水为溶剂的实验仍然产出了完整的评估，因为危害在*过程*之中，而这正是第 1 步的意义。
:::

::: exercise 事故复盘 {level=3}
阅读这份事故报告，列出你能找到的每一条违规操作——至少六条——并给出每条的正确做法：*"阿依莎提着一只装满溶剂的 2.5 L 大瓶的瓶颈穿过实验室，在敞开的实验台上给烧杯续液，然后把开着盖的瓶子留在台上待会儿再用，接着用嘴吸移液管吸取该液体、用手指计时，随后仍戴着那副手套走到隔壁台写记录。她身后地上那只瓶子被撞倒后，她用纸巾把溢液拖干，把纸巾扔进普通垃圾桶，并且没有向任何人提起这次溢液，因为没有人受伤。"*
::: hint
逐句对照四条暴露途径、控制措施层级和废液规则来评分；最后一句包含两条独立的违规，其中一条关于报告。
:::
::: solution
(1) 提大瓶的瓶颈搬运——应用托盘或提篮、双手搬运，因为瓶颈是看起来最结实、实际最薄弱的部位，而 2.5 L 的破碎是一次严重暴露。(2) 在敞开台面上续液——挥发性溶剂应在通风橱内量取，否则蒸气会在逸出途中经过你的脸。(3) 瓶子敞口放置——除倾倒的瞬间外容器应保持密闭；敞口的瓶子是一个持续的源项。(4) 用嘴吸移液管——永远用洗耳球或移液器；食入途径不需要任何帮助。(5) 戴着手套去写记录——手套留着它的内容物；碰公共物品前先脱掉。(6) 浸透溶剂的纸巾进普通垃圾桶——被污染的吸附材料就是按其污染物归类的化学废物，而一桶浸透的纸是一根慢燃的引信。(7) 未通知任何人——溢液必须立即报告，好让他人避开蒸气和湿滑的地面。(8) 把"没有人受伤"当成结局——那是一次未遂事故，而未遂事故正是防止下一条记录变成伤害的免费数据。她跳过的序列：保护人，隔离源头，通报，报告。
:::
