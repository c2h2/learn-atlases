定量化学由两种操作定义：把某种东西放到天平上，再把另一样东西的已知体积送进烧瓶。教学实验室里的每一个产率、每一个浓度、每一个测得的平衡常数、每一个由分析得到的化学式，最终都由天平读出的质量和量器放出的体积搭建起来——而[[laboratory-methods/measurement-uncertainty]]的算术对两者都定下了不近人情的标准：一个准确到 $0.1\ \%$ 的结果，不可能由一堆比 $0.1\ \%$ 更差的步骤拼成，因为相对不确定度按平方和开方合成，最差的一步支配着答案。一支 $25\ \mathrm{cm^3}$ 移液管以 $0.12\ \%$ 放出，一台分析天平以 $0.02\ \%$ 称量一克，而由两者搭建的浓度，到头来限制你的不是天平前的细心，而是手里那支玻璃。**技术就是保护这个数字的东西。**本章的每一个习惯——润洗、视线平齐读弯月面、关严防风罩、干燥箱里的第二个小时——都为了关闭测量系统性变坏的一条特定通道而存在。

上一章把一个测量当作一个区间，并建立了区间合成的规则。这一章讲的是操作本身。它从做称量的仪器讲起，经过放体积的量器，走到把两者结合起来的两个操作：配制准确已知浓度的溶液（**标准溶液**），以及让它与另一种溶液定量反应（**滴定**）。最后以最纯粹的形态讲重量分析的思想——把东西烘干，直到质量不再改变——因为一个还在变化的质量根本算不上测量。

## 分析天平

::: definition 分析天平 {#def-balance}
**分析天平**是分度值为 $0.0001\ \mathrm{g}$（$0.1\ \mathrm{mg}$）或更优的天平。**分度值**（readability）——显示所能示出的最小增量——与不确定度不是一回事：重复性、线性与校准合起来，把单次读数的不确定度定为通常的 $\pm 0.0002\ \mathrm{g}$；而差减称量用到两次读数，所以送进容器里的质量携带 $u(m) \approx 0.0002\ \mathrm{g}$，恰如[[laboratory-methods/measurement-uncertainty]]中方和根论证所示。使用分析天平必须调平（水准泡居中）、预热（电子线路稳定至少 $30\ \mathrm{min}$；许多实验室为此让天平常开）、在关严的**防风罩**后面，并且样品放在容器里——绝不把粉末或液体直接放到天平盘上。
:::

为什么坚持一台显示四位小数的天平有 $\pm 0.0002\ \mathrm{g}$ 的不确定度？因为显示的最后一位是最吵的数字：它随气流、温度漂移、静电荷以及载荷在盘上的位置而闪动。一台好天平的重复性——对同一物体反复称量的标准偏差——通常就有 $0.1$–$0.2\ \mathrm{mg}$，校准不确定度再按平方和开方叠加上去。所以对单次读数，诚实的陈述是 $\pm 0.0002\ \mathrm{g}$；一次称量的相对不确定度就是这个数除以质量：$1\ \mathrm{g}$ 的 $0.02\ \%$，$0.1\ \mathrm{g}$ 的 $0.2\ \%$，$0.01\ \mathrm{g}$ 的 $2\ \%$。这就是为什么分析规程在化学允许时都要求克量级的称量，也是为什么"称出约 $1\ \mathrm{g}$，称准"是比"称出 $0.0100\ \mathrm{g}$"更好的建议。

把一个已知质量送进烧瓶有两条路。**差减称量法**是分析工作的默认做法：样品装在带塞的称量瓶里，先称；把其中一部分倾入受器，此时称量瓶不在天平上；再称称量瓶，失去的质量就是送出的质量。不必把任何东西定量转移——天平已经准确记录了离开称量瓶的有多少——而且同一只称量瓶可以连续分出几份等分试液，每一份都记得和第一份一样清楚。直接称量（容器去皮、加样、关罩、读数）适用于不在天平上久放的固体，但它逼你去凑一个目标质量，并逼你把药匙上看得见的每一粒都冲洗进烧瓶。

两条禁令是绝对的。绝不称量热的或温的物体：它在天平盘上激起对流气流，使读数漂移并偏低，持续受热还会损坏衡量机构；坩埚从干燥箱出来应进**干燥器**，而不是上天平，只有回到实验台温度才能上秤。绝不在敞开的天平盘上方用药匙加试剂：一把料撒进五位天平的机构，就是一张维修单，和一台让此后每个使用者都受害的受污染仪器；加样时药匙应斜伸进容器，罩门敞开，盘上别放别的东西。

::: warning 显示出的最后一位数字是声称，不是事实 {#warn-balance}
一台显示 $0.5106\ \mathrm{g}$ 的天平，并没有声称知道质量到小数点后第四位；它只是显示了小数点后四位，这是两回事。记录你守得住的——质量连同 $\pm 0.0002\ \mathrm{g}$——并让不确定度而不是显示屏决定最后一位有效数字，[[laboratory-methods/measurement-uncertainty]]对此一再坚持。两种失效方式让这条警告变得具体。**静电荷**：塑料称量盘在盘上拖动，或倾倒一种绝缘粉末，留下的电荷对天平盘的静电力会使表观质量以毫克计地漂移，不可重现，有时持续几分钟；给容器放电（接地的金属药匙、静电消除器），粉末改用玻璃或金属称量盘，并把一个不肯稳定的读数当作脏量器来对待，而不是当作一台慢天平。**吸湿性样品**在称量过程中不断增重：稳步爬升的显示屏不是出了故障，而是样品在从空气里喝水——称得要快，用带塞容器，或者另选一种基准物质。
:::

## 容量仪器

::: definition 量入式与量出式 {#def-tc-td}
容量量器在 $20\ ^\circ\mathrm{C}$ 下按两种方式之一校准。标 **TC**（to contain，量入式）的——每一只容量瓶——以恰好容纳其标称体积校准；倒空时沿内壁流下的那层液膜属于校准的一部分，所以量入式容器绝不用来放出准确体积。标 **TD**（to deliver，量出式）的——移液管与滴定管——以放出其标称体积校准，那层壁膜和尖端的残留已由厂家扣除。**等待式移液管**靠重力流出，尖端贴着受器壁，流尽后再等待（约 $10\ \mathrm{s}$）；残留在尖端里的液体绝不可吹出，因为它正是校准已经扣除过的那份残留。**吹出式移液管**以管身上端的一两个磨砂环标为记，它的校准约定是尖端残留*必须*吹出。两种约定一混淆，每次放出就要错掉百分之几立方厘米——对小移液管就是 $0.1\ \%$ 以上，而且作为系统误差送进你的每一个结果。
:::

水润湿干净的玻璃，所以水在滴定管或移液管里的表面是凹的**弯月面**：视线与弯月面同高，读弯月面的最低点。视线不在该平面内就引入视差，因为刻度线与弯月面处在玻璃中不同的深度，你看到的水平面便取决于你从多高去看。这就是滴定管的规则是*初读数与末读数在同一视线高度读取*的原因：眼睛两次都错在同一个地方，同一个视差误差便同时进入两次读数，并在滴定体积中抵消。把一张深色卡举在弯月面稍下方，能把弯月面衬得清楚得多；要用它。

清洗不是家务，是校准。水在干净的玻璃上应成连续的膜流下，而不是散成水滴；挂在壁上的水滴意味着油脂，而油脂意味着标称体积是一句谎话。用洗涤剂洗，用自来水再用去离子水冲，成膜流下方可收下这只量器。然而一支洗干净的湿移液管，就是一支装满蒸馏水的移液管：直接从储备瓶吸液，你放出的就是被壁上水膜稀释过的溶液。补救只花十秒钟——用*这支移液管即将移取的那份溶液*本身润洗两三次，每次少量，润洗液倒入废液，让留下的膜就是那份溶液。绝不可只用水润洗然后就装液。

量筒是 $1$–$2\ \%$ 级别的量器，烧杯和锥形瓶上的刻度只是装饰。用它们量洗涤用的溶剂、或冷浴用的大致水量；绝不用它们配制标准溶液。还要记住玻璃上那个 $20\ ^\circ\mathrm{C}$ 的含义：水每升高 $1\ ^\circ\mathrm{C}$ 约膨胀 $0.021\ \%$，所以趁温定容的溶液冷却后会缩到刻度以下，浓度就按每摄氏度约 $0.02\ \%$ 偏高。五度就是 $0.1\ \%$——一次好滴定的全部误差预算，就这样败给了急躁。

你真正会用的几件量器，其 A 级允差（例如 Harris《定量化学分析》（Quantitative Chemical Analysis））：

| 量器 | 标称体积 | A 级允差 |
|---|---|---|
| 单标线移液管（量出式） | $25.00\ \mathrm{cm^3}$ | $\pm 0.03\ \mathrm{cm^3}$ |
| 容量瓶（量入式） | $250.0\ \mathrm{cm^3}$ | $\pm 0.12\ \mathrm{cm^3}$ |
| 滴定管，全量程放出（量出式） | $50\ \mathrm{cm^3}$ | $\pm 0.05\ \mathrm{cm^3}$ |

分析天平每次读数贡献 $\pm 0.0002\ \mathrm{g}$。B 级量器大约松一倍，而教学实验室的量器常常两者都不是。记住[[laboratory-methods/measurement-uncertainty]]的教训：允差是一个极限，不是标准偏差；而相对代价按 $1/V$ 运行：$25\ \mathrm{cm^3}$ 移液管的 $\pm 0.03\ \mathrm{cm^3}$ 是 $0.12\ \%$，容量瓶的 $\pm 0.12\ \mathrm{cm^3}$ 只有 $0.048\ \%$，滴定管的 $\pm 0.05\ \mathrm{cm^3}$ 是满 $50\ \mathrm{cm^3}$ 的 $0.1\ \%$，却是 $5\ \mathrm{cm^3}$ 放出的 $1\ \%$。

::: quiz
在用标准溶液充满一支容量移液管之前，应该用什么润洗它的内壁？
- [x] 用这支移液管即将移取的那份溶液本身，少量润洗，倒入废液。
- [ ] 用蒸馏水，并尽量沥干——移液管首先必须干净。
- [ ] 用这份等分试液即将移入的那份溶液，少量润洗。
- [ ] 什么都不用：洗得合格的移液管不需要润洗。
::: solution
应当用待移取的溶液本身。干净是前提，不是全部：洗过沥干的移液管内衬着一层蒸馏水膜，直接从储备瓶装液，放出的就是被这层膜稀释过的溶液——在每一份等分试液里都埋下一个小小的、方向为负的偏倚。用溶液本身两三次少量润洗并倒入废液，就把水膜换成了真货。用受器里的溶液润洗会因混合而改变移液管的内容物，而只用水则把稀释原封留下。同一条规则管着滴定管（用滴定剂润洗）；而它下面那只锥形瓶恰恰相反，*不*用等分试液润洗——因为滴定测的是瓶内溶质的量，不是瓶内液体的体积，在那里润洗等于添上滴定管随后要付账的溶质。
:::
:::

## 标准溶液

**标准溶液**是准确已知浓度的溶液；浓度本身的算术在[[general-chemistry-1/solutions-reactions]]。有些标准溶液可以靠称量配制：溶下一个已知质量的纯物质，稀释到已知体积。这条路只对一类特殊的试剂敞开。

::: definition 基准物质 {#def-primary-standard}
**基准物质**是可以以已知且不变的组成获得、仅凭称量就能配制准确已知浓度的标准溶液的试剂。四条要求：**高纯度**（$99.9\ \%$ 以上，且可检定）；**在空气中稳定**——不吸湿，不与水、二氧化碳和氧气反应，且分解温度高于干燥温度；**组成确定**——化学式必须就是事实，包括水合状态，而且干燥必须可预期地除去水，而不是除去一部分；以及**相当高的摩尔质量**，使一定物质的量对应的质量足够大，称量的相对误差就小。邻苯二甲酸氢钾 $\mathrm{KHC_8H_4O_4}$（$M = 204.22\ \mathrm{g\,mol^{-1}}$，$110\ ^\circ\mathrm{C}$ 干燥）和无水碳酸钠 $\mathrm{Na_2CO_3}$（$M = 105.99\ \mathrm{g\,mol^{-1}}$，$270\ ^\circ\mathrm{C}$ 干燥）四条全满足。氢氧化钠在第二条上失败——它在你盯着天平盘看的时候吸收水和二氧化碳——盐酸在第三条上失败：浓酸按质量只含约 $37\ \%$，而且氯化氢不断从中逸出。这两种"不合格者"的溶液先大致配好，再对着基准物质**标定**。
:::

摩尔质量这一条，正是[[#def-balance]]中相对不确定度论证的反面：$0.0250\ \mathrm{mol}$ 的邻苯二甲酸氢钾是 $5.1\ \mathrm{g}$，称准到 $0.006\ \%$ 的相对不确定度；而同样物质的量若换成一摩尔质量 $42\ \mathrm{g\,mol^{-1}}$ 的假想物质，就只有 $1.1\ \mathrm{g}$，相对误差大三倍。一个重的分子，就是便宜的准确度来源。

::: proposition 稀释 {#prop-dilution}
把浓度为 $c_1$ 的溶液的体积 $V_1$ 放入容量瓶，加水至最终体积 $V_2$，所得溶液的浓度为
$$
c_2 = \frac{c_1 V_1}{V_2}
\qquad\text{等价地}\qquad
c_1 V_1 = c_2 V_2 .
$$
条件是稀释过程中溶质的物质的量守恒：它不与任何东西反应，转移中不损失，而最终体积读自容量瓶自己的刻度，不是由加水量算出来的。
:::

::: proof 稀释守恒的是物质的量，不是体积 {#proof-dilution}
浓度为 $c$ 的溶液的体积 $V$ 中，溶质的物质的量为 $n = cV$（[[general-chemistry-1/stoichiometry]]）。从储备液移出的等分试液含 $n_1 = c_1 V_1$。稀释只加溶剂；它不加溶质，而且在命题的条件下也不毁灭溶质——所以瓶内之物仍含 $n_1$ 的溶质，只是如今摊在体积 $V_2$ 里：
$$
c_2 = \frac{n_1}{V_2} = \frac{c_1 V_1}{V_2},
$$
两边乘以 $V_2$ 即得 $c_1 V_1 = c_2 V_2$。注意这个证明*没有*说什么：它没有说 $V_2 = V_1 + V_\text{水}$。混合体积不可加——乙醇与水混合会收缩，连稀盐溶液也有自己的偏摩尔体积——这正是为什么配方说"定容至刻度"，而绝不说"加入 $V_2 - V_1$ 的水"。不确定度遵循[[laboratory-methods/measurement-uncertainty]]的乘积规则：
$$
\left(\frac{u_{c_2}}{c_2}\right)^2 = \left(\frac{u_{c_1}}{c_1}\right)^2 + \left(\frac{u_{V_1}}{V_1}\right)^2 + \left(\frac{u_{V_2}}{V_2}\right)^2 ,
$$
其中 $u_{c_1}$ 是储备液的不确定度：稀释继承误差，自己只添上量器的那一份。
:::

::: algorithm 从固体基准物质到标准溶液 {#alg-standard}
用干燥过的、摩尔质量为 $M$ 的基准物质配制 $250.0\ \mathrm{cm^3}$ 浓度为 $c$ 的标准溶液：
1. 算出目标质量 $m = cVM$；用差减法把干燥好的基准物质称准到 $\pm 0.0002\ \mathrm{g}$，记下实际质量——浓度将由你*称到的*质量计算，而不是由你*想称的*质量计算。
2. 在烧杯里用 $100$–$150\ \mathrm{cm^3}$ 去离子水溶解，旋动至每一粒晶体消失。溶解慢可微微加热，但必须把溶液冷到实验台温度再继续。
3. 定量转移：沿玻璃棒倾入 $250.0\ \mathrm{cm^3}$ 容量瓶，再把烧杯、玻璃棒和漏斗各用少量水冲洗三四次并入瓶中。冲洗液是配制的组成部分，不是废物。
4. 加水至刻度下方约 $1\ \mathrm{cm^3}$ 处，再改用滴管逐滴加水，直到弯月面最低点恰好落在刻度上，视线与其同高，溶液处于 $20\ ^\circ\mathrm{C}$。
5. 塞上瓶塞，用手指顶住，倒转二十次，让液体跑遍瓶的全长；摇晃不等于混匀。
6. 给容量瓶贴标签：名称、取合理位数的浓度、日期、姓名，以及实验室要求的场合加上不确定度。没有标签的标准溶液就是一堆废玻璃。
:::

::: example 称取邻苯二甲酸氢钾标准溶液 {#ex-khp-mass}
要配制 $250.0\ \mathrm{cm^3}$ 的 $0.1000\ \mathrm{mol\,dm^{-3}}$，你应称取多少在 $110\ ^\circ\mathrm{C}$ 干燥过的邻苯二甲酸氢钾？
::: solution
所需物质的量为
$$
n = cV = 0.1000\ \mathrm{mol\,dm^{-3}} \times 0.2500\ \mathrm{dm^3} = 0.02500\ \mathrm{mol},
$$
质量为
$$
m = nM = 0.02500\ \mathrm{mol} \times 204.22\ \mathrm{g\,mol^{-1}} = 5.1055\ \mathrm{g}.
$$
用差减法称取约 $5.106\ \mathrm{g}$——假设计量结果为 $5.1062\ \mathrm{g}$——标准溶液的浓度由你实际拥有的质量算出：
$$
c = \frac{5.1062\ \mathrm{g}}{204.22\ \mathrm{g\,mol^{-1}} \times 0.2500\ \mathrm{dm^3}} = 0.10001\ \mathrm{mol\,dm^{-3}}.
$$
往下走之前读一读这份预算：称 $5.106\ \mathrm{g}$ 到 $\pm 0.0003\ \mathrm{g}$，代价是 $0.006\ \%$；而容量瓶的 A 级允差代价是 $0.12/250.0 = 0.048\ \%$。容量瓶以近一个数量级占主导，这份标准溶液立在约 $0.05\ \%$ 上——这就是为什么克量级的基准物质，是多数滴定实验室里最守规矩的一个数字。
:::
:::

::: example 由储备液稀释 {#ex-dilution-stock}
你需要 $250.0\ \mathrm{cm^3}$ 的 $0.008000\ \mathrm{mol\,dm^{-3}}$ 邻苯二甲酸氢钾，手头只有[[#ex-khp-mass]]那份 $0.10001\ \mathrm{mol\,dm^{-3}}$ 标准溶液。怎么办？结果有多好？
::: solution
把 $c_1 V_1 = c_2 V_2$ 重排（[[#prop-dilution]]）：
$$
V_1 = \frac{c_2 V_2}{c_1} = \frac{0.008000\ \mathrm{mol\,dm^{-3}} \times 250.0\ \mathrm{cm^3}}{0.10001\ \mathrm{mol\,dm^{-3}}} = 19.998\ \mathrm{cm^3} \approx 20.00\ \mathrm{cm^3}.
$$
用移液管移取储备液 $20.00\ \mathrm{cm^3}$ 放入 $250.0\ \mathrm{cm^3}$ 容量瓶，定容；浓度为 $c = 0.10001 \times 20.00/250.0 = 0.008001\ \mathrm{mol\,dm^{-3}}$。这份预算发人深省：移液管如今放出的比它的标称体积还少，$0.03/20.00 = 0.15\ \%$ 比它在 $25\ \mathrm{cm^3}$ 时付的更多；与容量瓶的 $0.048\ \%$ 按平方和开方合成，稀释后的标准溶液立在 $0.16\ \%$ 上——比它所从来的储备液差三倍。稀释在浓度上便宜，在不确定度上从不免费。
:::
:::

::: example 系列稀释，以及不确定度如何累积 {#ex-serial-dilution}
实验室需要一份很稀的标准溶液：把 $0.1000\ \mathrm{mol\,dm^{-3}}$ 储备液 $25.00\ \mathrm{cm^3}$ 定容至 $250.0\ \mathrm{cm^3}$（溶液 A），再取 A 液 $25.00\ \mathrm{cm^3}$ 定容至 $250.0\ \mathrm{cm^3}$（溶液 B）。B 的浓度是多少？若忽略储备液自身的不确定度，其相对不确定度又是多少？
::: solution
每一步把浓度乘以 $25.00/250.0 = 1/10$，所以
$$
c_\mathrm{B} = 0.1000 \times \frac{25.00}{250.0} \times \frac{25.00}{250.0} = 0.001000\ \mathrm{mol\,dm^{-3}}.
$$
每一步携带同样两项量器误差，而两步相互独立，方差相加：
$$
\frac{u_{c_\mathrm{B}}}{c_\mathrm{B}} = \sqrt{2\left[\left(\frac{0.03}{25.00}\right)^2 + \left(\frac{0.12}{250.0}\right)^2\right]} = \sqrt{2\left[(1.2\times10^{-3})^2 + (4.8\times10^{-4})^2\right]} = 1.8\times10^{-3},
$$
即 $0.18\ \%$，得 $c_\mathrm{B} = (1.000 \pm 0.002) \times 10^{-3}\ \mathrm{mol\,dm^{-3}}$。两点要记住。浓度缩小了 $100$ 倍，不确定度却只增长了 $50\ \%$：相对误差相乘而不相加，所以系列稀释是便宜的——但并不免费，你添加的每一步都买来一份新的量器误差。而移液管贡献每步方差的 $(1.2/1.29)^2 = 86\ \%$：$25\ \mathrm{cm^3}$ 的放出又是薄弱环节，恰如下方那条双曲线所预言。
:::
:::

## 滴定

滴定是用滴定管来做的称量：把一种溶液（**滴定剂**）的测量体积，送进另一种溶液（**等分试液**）的测量体积，直到反应完全，再由化学计量关系把体积换算成浓度。这套技术是一道道防线的序列。滴定管用滴定剂本身润洗两次、倒入废液，理由与移液管相同。先装液到旋塞以上，再把旋塞全开一下，充满尖嘴并排出气泡：中途消失的气泡会让滴定管记下从未到达烧瓶的液体，滴定体积便读数偏大。调到零或近零，擦干尖嘴。弯月面读到 $0.02\ \mathrm{cm^3}$——刻度间隔 $0.1\ \mathrm{cm^3}$，有了深色卡，五分之一格确实可以分辨——并且初、末读数在同一视线高度读取，让视差抵消。放出时尖端贴着锥形瓶壁，旋动烧瓶，临近终点时用洗瓶冲洗内壁；最后一毫升，把半滴放到壁上，再冲洗进去。

先做一次快速的**粗滴定**，找到终点落在哪里；然后放慢重复，直到相邻滴定体积互差在 $0.05$–$0.10\ \mathrm{cm^3}$ 以内。互差在此限内的滴定体积称为**平行一致**，只把平行一致的体积取平均：粗滴定不是坏测量，它根本就不是测量——它是侦察。**化学计量点**是反应的化学计量完全之点，是滴定曲线上一个理论点；**滴定终点**是指示剂的变色，是一个离理论点不远的真实事件。两者之间的间隙就是滴定误差；让终点的变色落在滴定曲线突跃部分上的指示剂——这是[[general-chemistry-2/buffers-titrations]]的主题——能把滴定误差压到比读数误差还小。没有足够敏锐的指示剂时，就改用电位法找终点。

::: example 用邻苯二甲酸氢钾标定氢氧化钠 {#ex-naoh-standardisation}
一名学生用差减法称取干燥过的邻苯二甲酸氢钾 $0.4856\ \mathrm{g}$，溶解，加酚酞，用氢氧化钠溶液滴定。平行一致的滴定体积为 $23.60$、$23.55$ 和 $23.65\ \mathrm{cm^3}$。碱的浓度是多少？
::: solution
平行一致滴定体积的平均值为
$$
\bar{V} = \frac{23.60 + 23.55 + 23.65}{3} = 23.60\ \mathrm{cm^3} = 0.02360\ \mathrm{dm^3}.
$$
邻苯二甲酸氢钾是一元酸——只有一个酸性氢——所以它的物质的量为
$$
n = \frac{0.4856\ \mathrm{g}}{204.22\ \mathrm{g\,mol^{-1}}} = 2.378\times10^{-3}\ \mathrm{mol},
$$
它与碱一比一反应，
$$
\mathrm{KHC_8H_4O_4 + NaOH \rightarrow KNaC_8H_4O_4 + H_2O},
$$
所以放出的碱液含有同样多的物质的量：
$$
c_\mathrm{NaOH} = \frac{2.378\times10^{-3}\ \mathrm{mol}}{0.02360\ \mathrm{dm^3}} = 0.1008\ \mathrm{mol\,dm^{-3}}.
$$
预算，从简：$\pm 0.0003\ \mathrm{g}$ 落在 $0.4856\ \mathrm{g}$ 上是 $0.06\ \%$；滴定体积的平均（三个读数跨 $0.10\ \mathrm{cm^3}$）约 $0.05\ \%$；邻苯二甲酸氢钾的纯度与摩尔质量在实用上就是准确的。总计约 $0.1\ \%$：$c_\mathrm{NaOH} = 0.1008 \pm 0.0001\ \mathrm{mol\,dm^{-3}}$。四位数字，正是这套技术支撑得起的——不多，也不少。
:::
:::

## 恒重

::: definition 恒重 {#def-constant-mass}
对固体干燥——或灼烧——**至恒重**，指相邻两次处理（在规定温度下干燥、在**干燥器**中冷却、称量）所得质量之差在规定限内，教学实践通常约定约 $\pm 0.3\ \mathrm{mg}$，严格的重量分析取 $\pm 0.2\ \mathrm{mg}$。冷却必须在干燥器中进行，因为热物体加热了周围的空气，读数偏低且漂移，而且许多干燥过的固体在几分钟内就会重新吸收实验室空气中的水分。第一次干燥几乎从来不够：水藏在沉淀的孔隙里、晶体之间，结晶水走得也慢；反过来，一种受热缓慢分解的固体会永远失重下去。这就是为什么判据是相邻质量的一致，而绝不是固定的干燥时间——"烘两小时"是一份食谱，不是一个结果。
:::

::: example 达到恒重了吗？ {#ex-constant-mass}
盛有干燥沉淀的瓷坩埚称了三次，每次之间再干燥一小时：$12.4517$、$12.4498$ 和 $12.4496\ \mathrm{g}$。空坩埚质量为 $10.2318\ \mathrm{g}$。达到恒重了吗？你报告多少沉淀质量？
::: solution
相邻差：$12.4517 - 12.4498 = 0.0019\ \mathrm{g}$，即 $1.9\ \mathrm{mg}$——远超 $\pm 0.3\ \mathrm{mg}$ 判据，所以头一对不恒重；$12.4498 - 12.4496 = 0.0002\ \mathrm{g}$，即 $0.2\ \mathrm{mg}$——在限内。恒重于第三次称量达到。报告最后一次质量，而不是最后两次的平均，因为第二次读数取得时质量还在往下漂。沉淀质量为
$$
12.4496\ \mathrm{g} - 10.2318\ \mathrm{g} = 2.2178\ \mathrm{g}.
$$
往下走之前，把第一个差再读一遍：仅仅多出的一个小时里，就有 $1.9\ \mathrm{mg}$ 水离开了那只坩埚。一套"烘两小时即算干燥"的规程，会把每一份它称过的沉淀都报重 $1.9\ \mathrm{mg}$——质量的 $0.09\ \%$——方向单一，悄无声息。恒重是干燥完成的唯一诚实检验。
:::
:::

在**重量分析法**中，沉淀*就是*测量本身：把待测组分沉淀、过滤、洗涤到洗液中不再检出母液的离子、干燥或灼烧至恒重、称量，再由沉淀的化学式算出待测组分的量——那是[[analytical-chemistry/classical-analysis]]的学问以最纯粹的形态出场。同一个习惯在低一层同样称职：重结晶产物必须先干燥至恒重，别人才会相信它的熔点和产率（[[laboratory-methods/separation-purification]]、[[laboratory-methods/identifying-compounds]]）。

::: history
弗里德里希·莫尔（Friedrich Mohr，1806–1879）是一位德国药剂师，他在十九世纪五十年代把滴定从一件奇巧之事变成了定量实践。他的《化学滴定分析法教科书》（Lehrbuch der chemisch-analytischen Titrirmethode，1855 年）推广了**刻度滴定管**——在莫尔之前，滴定分析意味着称量滴定管反应前后的质量，因为还没有人想到给它刻上标尺——并汇集了仍以他命名的那些方法，包括氯化物的**莫尔法**：用硝酸银滴定，铬酸盐作指示剂，刚过终点时出现的红色铬酸银告诉你氯化物在何处用完。莫尔还认出**莫尔盐**——六水合硫酸亚铁铵——是一种能在空气中称量的标准物质，而普通硫酸亚铁却一边氧化一边吸水。而由于很少有药剂师能自己获得纯试剂，莫尔把标准溶液、滴定管和说明书成套出售：一条围绕他的滴定方法的小小标准溶液行业成长起来，定量分析成了一个称职的药剂师就能经营的东西——而这恰恰使基准物质的纯度、以及其证书的正直，成为公众信任的问题。
:::

## 后续内容

恒重在实践中的样子——干燥箱、干燥器、坩埚，以及重结晶产物的干燥——在[[laboratory-methods/separation-purification]]里完成。量器并非不会出错，检验它的办法是校准：称出移液管放出的水，除以水的密度，把标称体积对真实体积作图——一条最小二乘校准直线见[[laboratory-methods/data-graphs]]。滴定分析与重量分析的完整处理，包括终点校正与空白滴定，在[[analytical-chemistry/classical-analysis]]；重复滴定体积的统计——做几次重复、哪些可疑值可以剔除——在[[analytical-chemistry/statistics-calibration]]。指示剂的选择与你正在阅读的那条曲线的形状，来自[[general-chemistry-2/buffers-titrations]]；你一路默认使用的浓度算术在[[general-chemistry-1/solutions-reactions]]；而本章每个允差背后的单位与位数，在[[general-chemistry-1/matter-measurement]]和[[laboratory-methods/measurement-uncertainty]]。

::: summary
- 天平显示屏的最后一位是声称：$0.1\ \mathrm{mg}$ 的分度值，每次读数携带 $\pm 0.0002\ \mathrm{g}$，所以要用差减法称、称克量级、绝不称温物，并提防静电荷造成的漂移读数。
- 量入式容纳，量出式放出：等待式移液管绝不吹出，带环标的必须吹出；弯月面视线平齐来读，滴定管的初末两次读数用同一视线高度。
- 干净的玻璃成膜流下，不成滴；量器用即将放出的溶液润洗，绝不只用水；量筒与烧杯刻度只配做粗活。
- 基准物质要纯、在空气中稳定、不吸湿、组成确定、摩尔质量相当高（邻苯二甲酸氢钾、无水 $\mathrm{Na_2CO_3}$）；氢氧化钠与盐酸的溶液必须对着它标定。
- 稀释守恒的是物质的量，不是体积：$c_1 V_1 = c_2 V_2$，在 $20\ ^\circ\mathrm{C}$ 定容至刻度，并预期每一步继承储备液的不确定度、再添上自己量器的那一份。
- 滴定做到互差 $0.10\ \mathrm{cm^3}$ 以内的平行一致，只把平行一致的体积取平均；选指示剂要让滴定终点落在化学计量点上。
- 恒重指相邻质量互差约 $\pm 0.3\ \mathrm{mg}$ 以内；它是干燥完成的唯一证明，也是重量分析法的地基。
:::

## 练习

::: exercise 称取碳酸钠标准溶液 {level=1 check="1.325"}
要配制 $250.0\ \mathrm{cm^3}$ 的 $0.0500\ \mathrm{mol\,dm^{-3}}$，应称取多少无水碳酸钠 $\mathrm{Na_2CO_3}$（$M = 105.99\ \mathrm{g\,mol^{-1}}$）？（以 $\mathrm{g}$ 输入质量。）
::: solution
$m = cVM = 0.0500\ \mathrm{mol\,dm^{-3}} \times 0.2500\ \mathrm{dm^3} \times 105.99\ \mathrm{g\,mol^{-1}} = 1.3249\ \mathrm{g}$，所以用差减法称取约 $1.325\ \mathrm{g}$，再由实际送出的质量算出准确浓度。在烧杯中溶解，连同冲洗液转入 $250.0\ \mathrm{cm^3}$ 容量瓶，定容，倒转二十次（[[#alg-standard]]）。
:::
:::

::: exercise 稀释体积 {level=1 check="50.00"}
要配制 $250.0\ \mathrm{cm^3}$ 的 $0.0200\ \mathrm{mol\,dm^{-3}}$，应移取 $0.1000\ \mathrm{mol\,dm^{-3}}$ 盐酸多少体积？（以 $\mathrm{cm^3}$ 输入体积。）
::: solution
$V_1 = c_2 V_2 / c_1 = 0.0200 \times 250.0 / 0.1000 = 50.00\ \mathrm{cm^3}$。用 A 级移液管分 $25.00 + 25.00\ \mathrm{cm^3}$ 两次移入 $250.0\ \mathrm{cm^3}$ 容量瓶（实验室若有 $50\ \mathrm{cm^3}$ 的单标线移液管也可一次移取），定容。注意这种酸不是基准物质（[[#def-primary-standard]]）——那个 $0.1000\ \mathrm{mol\,dm^{-3}}$ 本身，也只和它背后的标定一样好。
:::
:::

::: exercise 平行一致滴定体积的平均 {level=1 check="23.85"}
一名学生的四次滴定体积为 $23.80$、$25.40$、$23.90$ 和 $23.85\ \mathrm{cm^3}$。报告平均滴定体积。（以 $\mathrm{cm^3}$ 输入平均值。）
::: solution
$25.40\ \mathrm{cm^3}$ 那次是粗滴定——它与平行一致相差超过 $1.5\ \mathrm{cm^3}$，是侦察，不是数据。其余三次互差在 $0.10\ \mathrm{cm^3}$ 以内，平行一致：$\bar{V} = (23.80 + 23.90 + 23.85)/3 = 23.85\ \mathrm{cm^3}$。把粗滴定也平均进去会得到 $24.24\ \mathrm{cm^3}$——一个完全由记账制造出来的 $1.6\ \%$ 误差。
:::
:::

::: exercise 由标定求浓度 {level=2 check="0.1037"}
一名学生称取干燥过的邻苯二甲酸氢钾（$M = 204.22\ \mathrm{g\,mol^{-1}}$）$0.5106\ \mathrm{g}$，溶解后用氢氧化钠溶液滴定；平行一致滴定体积的平均为 $24.10\ \mathrm{cm^3}$。碱的浓度是多少？（以 $\mathrm{mol\,dm^{-3}}$ 输入。）
::: solution
$n(\mathrm{KHP}) = 0.5106/204.22 = 2.500\times10^{-3}\ \mathrm{mol}$，与氢氧根一比一反应，所以 $c_\mathrm{NaOH} = 2.500\times10^{-3}\ \mathrm{mol} / 0.02410\ \mathrm{dm^3} = 0.1037\ \mathrm{mol\,dm^{-3}}$。四位数字，与质量和滴定体积各四位相配；预算见[[#ex-naoh-standardisation]]。
:::
:::

::: exercise 容量瓶的相对不确定度 {level=2 check="0.048"}
一只 $250.0\ \mathrm{cm^3}$ A 级容量瓶的允差为 $\pm 0.12\ \mathrm{cm^3}$。把允差本身当作不确定度，计算一次定容至刻度的相对不确定度。（以 $\%$ 输入。）
::: solution
$u/V = 0.12/250.0 = 4.8\times10^{-4} = 0.048\ \%$。容量瓶是实验室里*最便宜*的体积——比 $25\ \mathrm{cm^3}$ 移液管的 $0.12\ \%$ 好四倍——这就是为什么定容很少成为预算中的薄弱环节，也正是[[#ex-khp-mass]]里天平退居其次、容量瓶反而占主导的唯一原因：称量做得太好了。
:::
:::

::: exercise 两步稀释 {level=2 check="0.00500"}
把 $0.500\ \mathrm{mol\,dm^{-3}}$ 的溶液 $20.00\ \mathrm{cm^3}$ 移入 $250.0\ \mathrm{cm^3}$ 容量瓶，定容；再移取该溶液 $25.00\ \mathrm{cm^3}$ 放入 $200.0\ \mathrm{cm^3}$ 容量瓶，定容。最终浓度是多少？（以 $\mathrm{mol\,dm^{-3}}$ 输入。）
::: solution
$c = 0.500 \times (20.00/250.0) \times (25.00/200.0) = 0.500 \times 0.0800 \times 0.125 = 0.00500\ \mathrm{mol\,dm^{-3}}$。每个因子都是一个稀释比，不是体积相加（[[#prop-dilution]]）；三位数字的储备液把答案限制在三位。
:::
:::

::: exercise 一份标准溶液的完整预算 {level=3}
你按下法配制邻苯二甲酸氢钾标准溶液：在分析天平上（每次读数允差 $\pm 0.0002\ \mathrm{g}$，共两次读数）用差减法称取 $1.0211\ \mathrm{g}$，在 $250.0\ \mathrm{cm^3}$ A 级容量瓶（$\pm 0.12\ \mathrm{cm^3}$）中定容，再用 A 级移液管（$\pm 0.03\ \mathrm{cm^3}$）移取 $25.00\ \mathrm{cm^3}$ 等分试液。把每项允差当作不确定度，为等分试液中邻苯二甲酸氢钾的物质的量 $n = (m/M)\,(V_\mathrm{pip}/V_\mathrm{flask})$ 建立相对不确定度预算，指出占主导的项及其方差份额，并与[[laboratory-methods/measurement-uncertainty]]中称取 $0.1000\ \mathrm{g}$ 的那份预算作比较。
::: solution
差减称量：$u(m) = \sqrt{2}\times0.0002 = 0.0003\ \mathrm{g}$，故 $u_m/m = 0.0003/1.0211 = 2.9\times10^{-4}$（$0.029\ \%$）；容量瓶：$0.12/250.0 = 4.8\times10^{-4}$（$0.048\ \%$）；移液管：$0.03/25.00 = 1.2\times10^{-3}$（$0.12\ \%$）。按平方和开方，
$$
\frac{u_n}{n} = \sqrt{(2.9\times10^{-4})^2 + (4.8\times10^{-4})^2 + (1.2\times10^{-3})^2} = 1.3\times10^{-3},
$$
即 $0.13\ \%$。方差的份额是移液管 $82\ \%$、容量瓶 $13\ \%$、称量 $5\ \%$：占主导的现在是移液管，不是天平。与前面那份预算的对照就是教训：那里称 $0.1000\ \mathrm{g}$ 要付 $0.28\ \%$，压倒一切；多称十倍质量，称量项的方差缩小百倍，主导权移到量器手里——在那里，不换一支更好的移液管或改用称量法取等分试液，就难以再改进。预算告诉了你该修什么，而你修好了。
:::

::: exercise 推导稀释公式，再传递两次 {level=3}
由物质的量守恒推导 $c_1 V_1 = c_2 V_2$，并说明使推导成立的那个物理条件。然后对两步系列稀释——储备液 $V_1$ 定容至 $V_2$，再取该液 $V_3$ 定容至 $V_4$——传递不确定度，证明
$$
\left(\frac{u_{c_\mathrm{final}}}{c_\mathrm{final}}\right)^2 = \left(\frac{u_{c_1}}{c_1}\right)^2 + \left(\frac{u_{V_1}}{V_1}\right)^2 + \left(\frac{u_{V_2}}{V_2}\right)^2 + \left(\frac{u_{V_3}}{V_3}\right)^2 + \left(\frac{u_{V_4}}{V_4}\right)^2,
$$
并对两次相同的 $25.00 \rightarrow 250.0\ \mathrm{cm^3}$ A 级步骤（储备液不确定度可忽略）求值。
::: hint
把每一步写成浓度与无量纲比之积，$c_\mathrm{final} = c_1 \times (V_1/V_2) \times (V_3/V_4)$，然后问：[[laboratory-methods/measurement-uncertainty]]的乘积规则对四个独立因子之积说了什么？
:::
::: solution
守恒：等分试液 $V_1$ 携带 $n = c_1 V_1$ 的溶质；稀释至 $V_2$ 只加溶剂，所以 $c_2 = n/V_2 = c_1 V_1/V_2$，即 $c_1 V_1 = c_2 V_2$。条件是溶质的物质的量守恒——不与溶剂反应、转移中不损失——这也是为什么最终体积读自刻度、而不是由加水量算出（[[#proof-dilution]]）。传递方面，写 $c_\mathrm{final} = c_1 (V_1/V_2)(V_3/V_4)$：四个独立测量量的积与商，于是两次套用乘积规则就给出题面所述的相对不确定度平方和。取 $u_{V_1} = u_{V_3} = 0.03\ \mathrm{cm^3}$、$u_{V_2} = u_{V_4} = 0.12\ \mathrm{cm^3}$：
$$
\frac{u_c}{c} = \sqrt{2(1.2\times10^{-3})^2 + 2(4.8\times10^{-4})^2} = 1.8\times10^{-3},
$$
$0.18\ \%$——与[[#ex-serial-dilution]]同一个答案，如今可以看作一般规则：稀释链条里每一次移取的体积、每一次定容的体积，都贡献自己的相对方差，而小放出按 $1/V$ 的顺序占主导。
:::
