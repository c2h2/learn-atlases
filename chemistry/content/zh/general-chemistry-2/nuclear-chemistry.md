考古炉灶里的一块木炭，只需数一数它所含的一种稀有同位素的衰变，就能把年代定到几个世纪以内；一家医院可以在周一上午订购一管锝-99m，并确切知道到周五它几乎已衰变殆尽；而太阳四十五亿年来持续发光，靠的是在其中心把氢聚变成氦。这三个事实都建立在原子核的一个奇特属性之上：某些质子与中子的组合并不稳定，它们按自己的时钟衰变——这是一个任何化学家、任何炉子、任何压力都既无法拨停也无法拨快的时钟。核化学就是关于这个时钟、以及它所储存的巨大能量的化学。

能量的尺度，正是原子核与电子云有本质区别的地方。燃烧一千克煤大约释放 $2.4\times10^{7}\ \mathrm{J}$；裂变一千克铀-235 约释放 $8\times10^{13}\ \mathrm{J}$，是前者的三百五十万倍，因为原子核内部的力是核力而非静电力，它们引起的质量变化终于大到可以称量。本章的一切——衰变定律、结合能曲线、反应堆与放射性碳定年——都出自两个观念：原子核靠一种表现为可测质量亏损的能量结合在一起；而放射性衰变是你在 [[general-chemistry-2/rates-intro]] 中见过的那类一级过程，只不过受支配的是核物理而非化学物理。

## 核素图

::: definition 核素、同位素与同量异位素 {#def-nuclide}
**核素**是由质子数 $Z$（决定元素）与中子数 $N$ 共同指定的一种核物种；其**核子数**或质量数为 $A = Z + N$，记作 ${}^{A}_{\ Z}\mathrm{X}$，例如铀-238 写作 ${}^{238}_{\ 92}\mathrm{U}$。**同位素**是 $Z$ 相同而 $N$ 不同的核素（$^{12}\mathrm{C}$、$^{13}\mathrm{C}$、$^{14}\mathrm{C}$）；**同量异位素**是 $A$ 相同而 $Z$ 不同的核素（$^{14}\mathrm{C}$ 与 $^{14}\mathrm{N}$）；**同中子异位素**则 $N$ 相同。化学性质几乎完全由 $Z$ 与电子决定，所以同一元素的各同位素在化学上几乎全同——而这恰恰是放射性同位素能够充当稳定同位素示踪剂的原因。
:::

::: proposition 稳定带 {#prop-band}
在已知的约三千种核素中，稳定的只有大约二百五十种。把它们画在 $N$ 对 $Z$ 的图上，它们落在一条狭窄的**稳定带**上：轻核的稳定带沿 $N \approx Z$ 而行，但随后弯到这条线之上，在铋（$Z = 83$）附近达到 $N/Z \approx 1.5$，因为质子之间不断增长的库仑斥律要求额外的中子——中子只提供吸引而不提供排斥——来把核维系在一起。$Z > 83$ 的核素没有一个是稳定的，而 $Z > 92$（铀）的核素在自然界中也不以可观的数量存在。稳定带之上的核素富中子，以 $\beta^-$ 发射衰变；带之下的核素缺中子，以 $\beta^+$ 发射或电子俘获衰变；最重的核则抛出 $\alpha$ 粒子。
:::

稳定带是一个经验规律——在这一层次上它只是被概括，而不是被推导；它的终极解释是核力的量子力学。注意它已经告诉你的东西：日常生活的元素（C、N、O、Fe）都坐在或靠近 $N \approx Z$ 线上，而每一个天然放射性核素——铀、镭、钾-40——都远离这条线，并且它所在的位置定性地告诉你它将如何死去。

::: quiz
为什么稳定带会随 $Z$ 增大而向富中子一侧弯曲？
- [x] 质子之间的电斥力作用于整个核的长程范围，而相互吸引的核力是短程的，所以额外的中子只增加吸引而不增加排斥。
- [ ] 在高 $Z$ 处中子变得比质子轻，所以自然更偏爱中子。
- [ ] 强相互作用在 $Z = 20$ 以上改变符号。
- [ ] 重核需要中子来增加电子壳层的数目。
::: solution
质子气的库仑能大致按 $Z^2$ 增长且作用于一切距离，而每个核子只通过短程核力吸引它最近的邻居。因此增加中子就稀释了单位核吸引所分担的电排斥，稳定的比值 $N/Z$ 便从 $1$ 攀升到约 $1.5$。
:::
:::

## 放射性衰变的方式

::: definition 衰变方式 {#def-decay-modes}
**α 衰变**抛出一个氦-4 核：${}^{A}_{\ Z}\mathrm{X} \rightarrow {}^{A-4}_{\ Z-2}\mathrm{Y} + {}^{4}_{2}\mathrm{He}$。**β⁻ 衰变**把一个中子变成一个质子，放出一个电子与一个反中微子：$\mathrm{n} \rightarrow \mathrm{p} + \mathrm{e}^- + \bar{\nu}_\mathrm{e}$，于是 $A$ 不变而 $Z$ 加一。**β⁺ 衰变**把一个质子变成一个正电子与一个中微子，使 $Z$ 减一；**电子俘获**通过吸收一个内层电子达到同样效果，$\mathrm{p} + \mathrm{e}^- \rightarrow \mathrm{n} + \nu_\mathrm{e}$。**γ 发射**从一个受激的核态放出一个高能光子，$Z$ 与 $A$ 都不变；它通常跟随在某次把子核留在受激态的衰变之后。放出中微子（或反中微子），是因为若不把它算进去，观测到的能量、动量与角动量就不守恒。
:::

::: proposition 核子数与电荷数守恒 {#prop-conservation}
在每一个核反应方程中，两侧的核子数总和 $A$ 与电荷数总和 $Z$ 各自平衡（一旦把电子的 $Z = -1$ 计入，电荷平衡是精确的）。这套记账法可以由母核与辐射直接认定子核，也几乎就是核方程算术的全部：一次 $\alpha$ 发射使 $A$ 减 $4$、$Z$ 减 $2$；一次 $\beta^-$ 发射在 $A$ 不变下使 $Z$ 加 $1$；一次 $\beta^+$ 发射或电子俘获使 $Z$ 减 $1$。
:::

::: example 配平一次 α 衰变 {#ex-balance-alpha}
写出 ${}^{238}_{\ 92}\mathrm{U}$ 的 $\alpha$ 衰变方程，然后确定在其衰变系末端把 ${}^{238}_{\ 92}\mathrm{U}$ 连接到稳定的 ${}^{206}_{\ 82}\mathrm{Pb}$ 需要多少次 $\alpha$ 与 $\beta^-$ 衰变。
::: solution
$\alpha$ 粒子就是 ${}^{4}_{2}\mathrm{He}$，所以子核的 $A = 238 - 4 = 234$、$Z = 92 - 2 = 90$，即钍：
$$
{}^{238}_{\ 92}\mathrm{U} \rightarrow {}^{234}_{\ 90}\mathrm{Th} + {}^{4}_{2}\mathrm{He}.
$$
对整条衰变系，设发生 $n_\alpha$ 次 $\alpha$ 衰变、$n_\beta$ 次 $\beta^-$ 衰变。核子数给出 $238 - 4n_\alpha = 206$，故 $n_\alpha = 8$。电荷再给出 $92 - 2\times 8 + n_\beta = 82$，故 $n_\beta = 6$。铀系因此由八次 $\alpha$ 与六次 $\beta^-$ 衰变构成——这个事实你在核素图上就能数出来，无需死记衰变链。
:::
:::

::: warning 核速率不是化学速率 {#warn-unchanging}
一个核素的衰变常数 $\lambda$ 由核本身决定，并且在一阶近似下完全不受温度、压力、颗粒大小或化学键合的影响。把一克 $^{226}\mathrm{Ra}$ 加热一千开尔文、把它溶在酸里或把它压进金属，都测不出其半衰期有任何变化——这与你在 [[general-chemistry-2/rates-intro]] 里学到的关于速率常数的一切恰好相反，在那里升温 $10\ \mathrm{K}$ 就能使速率翻倍。原因在于能量尺度：化学环境对核能级的扰动不过电子伏特量级甚至更小，而衰变涉及的是兆电子伏特。（唯一诚实的例外是电子俘获，其速率略微依赖核处的电子密度，在不同化学状态之间可能有千分之几的移动。）正是这种不变性，使核时钟能够被当作时钟来使用。
:::

## 衰变定律

::: definition 活度 {#def-activity}
放射性样品的**活度** $A_\mathrm{act}$ 是其单位时间的衰变数，
$$
A_\mathrm{act} = -\frac{\mathrm{d}N}{\mathrm{d}t} = \lambda N,
$$
其中 $N$ 是放射性核的数目、$\lambda$ 是**衰变常数**。SI 单位是**贝可勒尔**（$\mathrm{Bq} = 1\ \mathrm{s^{-1}}$）；旧的**居里**为 $3.7\times10^{10}\ \mathrm{Bq}$，即一克镭的活度。由于 $N$ 极其庞大，即使"微小"的活度也代表着一个个核在彼此无关的随机时刻单独衰变。
:::

::: proposition 衰变定律 {#prop-decay-law}
放射性衰变是一级过程：$t$ 时刻剩余的核数为
$$
N = N_0\,\mathrm{e}^{-\lambda t},
$$
半衰期为 $t_{1/2} = \dfrac{\ln 2}{\lambda}$，与起始量无关；平均寿命为 $\tau = 1/\lambda$。活度按同一个指数衰减，$A_\mathrm{act} = \lambda N_0\,\mathrm{e}^{-\lambda t}$。
:::

::: proof
定义性的假设是：每个核在接下来的 $\mathrm{d}t$ 内都有相同的恒定概率 $\lambda\,\mathrm{d}t$ 发生衰变，与它已经存在多久、与邻近的核在做什么都无关（核不会"磨损"）。于是 $\mathrm{d}t$ 内的期望衰变数正比于现存的核数，$-\mathrm{d}N = \lambda N\,\mathrm{d}t$。分离变量，从 $t = 0$ 时的 $N_0$ 积分到 $t$ 时的 $N$，
$$
\int_{N_0}^{N} \frac{\mathrm{d}N}{N} = -\lambda \int_0^t \mathrm{d}t
\quad\Longrightarrow\quad
\ln\frac{N}{N_0} = -\lambda t,
$$
即衰变定律。令 $N/N_0 = \tfrac12$ 即得 $t_{1/2} = \ln 2/\lambda$；其中的因子 $\ln 2$ 正是 [[general-chemistry-2/rates-intro]] 中一级积分速率定律里出现的那个，因为数学完全相同。平均寿命由 $\tau = \int_0^\infty t\,\lambda\,\mathrm{e}^{-\lambda t}\,\mathrm{d}t = 1/\lambda$ 给出。
:::

::: example 一克铀的活度 {#ex-activity-gram}
求 $1.00\ \mathrm{g}$ 纯 ${}^{238}\mathrm{U}$（$t_{1/2} = 4.47\times10^{9}\ \mathrm{y}$）的活度。
::: solution
原子数为
$$
N = \frac{1.00\ \mathrm{g}}{238.05\ \mathrm{g\,mol^{-1}}} \times 6.022\times10^{23}\ \mathrm{mol^{-1}} = 2.53\times10^{21},
$$
换算到秒的衰变常数为
$$
\lambda = \frac{\ln 2}{4.47\times10^{9}\ \mathrm{y} \times 3.156\times10^{7}\ \mathrm{s\,y^{-1}}} = 4.92\times10^{-18}\ \mathrm{s^{-1}}.
$$
因此 $A_\mathrm{act} = \lambda N = 1.24\times10^{4}\ \mathrm{s^{-1}} = 1.24\times10^{4}\ \mathrm{Bq}$：仅仅一克，每秒钟就有一万两千次衰变，而每一次衰变都是那条通向铅-206 的衰变系的第一步。半衰期长意味着每克的活度*低*——同样数目的原子若换成半衰期为一天的同位素，活度会高出数百万倍。
:::
:::

::: example 为什么医用同位素是短命的 {#ex-tc99m}
锝-99m（$t_{1/2} = 6.01\ \mathrm{h}$）是诊断核医学的主力。配制好的剂量经过 $24.0\ \mathrm{h}$ 后还剩多少？为什么示踪剂需要的半衰期是几小时——而不是几天、更不是几年？
::: solution
$$
\frac{N}{N_0} = \left(\frac{1}{2}\right)^{24.0/6.01} = \left(\frac{1}{2}\right)^{3.99} = 0.063,
$$
百分之六。半衰期的选择是一种权衡：要长到让剂量熬过制备、运输与成像扫描，又要短到让病人的总辐射暴露在一两天内衰减干净。碘-131（$t_{1/2} = 8.02\ \mathrm{d}$）处在医用范围的另一端，因为治疗用同位素需要在甲状腺内持续数天释放剂量。$^{99m}\mathrm{Tc}$ 的衰变常数为 $\lambda = \ln 2 / 6.01\ \mathrm{h} = 0.115\ \mathrm{h^{-1}}$。
:::
:::

::: warning 半衰期是统计，不是承诺 {#warn-halflife}
"两个半衰期之后什么都不剩"错在两头。其一，指数函数永远到不了零：$n$ 个半衰期后还剩 $2^{-n}$，所以十个半衰期后原始群体中每千个核仍有一个在场。其二，定律数的是*期望值*：对于少数几个原子，实际剩余数按二项分布涨落，而单个核要么在下一个半衰期内衰变、要么不——半衰期不是拴在每个原子上的倒计时器。对宏观样品，相对涨落约为 $1/\sqrt{N}$，完全可以忽略；而对现代单原子质谱的微小样品，它恰恰就是全部学问。
:::

::: example 放射性碳定年 {#ex-c14}
一处炉灶的木炭含有现代碳 $^{14}\mathrm{C}$ 活度的 $79.5\%$。为这块木炭定年，并估计测量分数的 $\pm 3\%$ 不确定度如何传播进年代。
::: solution
活的碳每克含约 $0.23\ \mathrm{Bq}$ 的 $^{14}\mathrm{C}$，由宇宙射线在大气中的生成维持；树死之后供应停止，该同位素便以 $t_{1/2} = 5730\ \mathrm{y}$、$\lambda = 1.21\times10^{-4}\ \mathrm{y^{-1}}$ 衰变。由 $N/N_0 = \mathrm{e}^{-\lambda t}$，
$$
t = \frac{1}{\lambda}\ln\frac{N_0}{N} = \frac{\ln(1/0.795)}{1.21\times10^{-4}\ \mathrm{y^{-1}}} = 1.90\times10^{3}\ \mathrm{y}.
$$
对 $t = -\lambda^{-1}\ln(N/N_0)$ 微分得 $|\delta t| = \delta f/(\lambda f) = 0.03/(1.21\times10^{-4}\times 0.795) \approx 310\ \mathrm{y}$：$3\%$ 的计数误差约值三个世纪。这个方法的假设——大气 $^{14}\mathrm{C}$ 水平恒定、样品封闭、不与地下水交换——正是年代要用年轮校准的原因，也正是其有效量程止于约 $5\times10^{4}$ 年的原因，因为那时原始活度只剩不到 $0.2\%$。钾-氩法（$^{40}\mathrm{K}$ 的 $t_{1/2} = 1.25\times10^{9}\ \mathrm{y}$）与铀-铅钟把同样的一级算术延伸到岩石、乃至地球本身的年龄。
:::
:::

## 结合能：为什么铁是顶峰

::: proposition 质量亏损与结合能 {#prop-mass-defect}
核的质量*小于*其 $Z$ 个质子与 $N$ 个中子质量之和。这个差值——**质量亏损** $\Delta m$——通过 $E = \Delta m\,c^2$ 对应于**结合能** $E_\mathrm{B}$，即把核拆散成自由核子所必须提供的能量。取 $1\ \mathrm{u} = 1.66054\times10^{-27}\ \mathrm{kg}$、$c = 2.998\times10^{8}\ \mathrm{m\,s^{-1}}$，一个原子质量单位值 $1\ \mathrm{u}\,c^2 = 931.5\ \mathrm{MeV}$。**每个核子的结合能** $E_\mathrm{B}/A$ 从氢起急剧上升，在铁-56 附近达到约 $8.8\ \mathrm{MeV}$ 的宽阔极大值，然后缓慢下降到铀-238 的约 $7.6\ \mathrm{MeV}$。曲线的两端都是能量之源：重核通过裂向极大值而释放能量（裂变），轻核通过聚向极大值而释放能量（聚变），而铁峰核素——两种过程的灰烬——则什么能量也放不出。
:::

::: example α 粒子的结合能 {#ex-he4}
已知 $m({}^{1}\mathrm{H}) = 1.00783\ \mathrm{u}$、$m_\mathrm{n} = 1.00866\ \mathrm{u}$、$m({}^{4}\mathrm{He}) = 4.00260\ \mathrm{u}$，求 ${}^{4}\mathrm{He}$ 的结合能，以及每摩尔氦对应的焦耳数。
::: solution
质量亏损为
$$
\Delta m = 2(1.00783) + 2(1.00866) - 4.00260 = 0.03038\ \mathrm{u},
$$
于是
$$
E_\mathrm{B} = 0.03038\ \mathrm{u} \times 931.5\ \mathrm{MeV\,u^{-1}} = 28.30\ \mathrm{MeV},
$$
即每核子 $7.07\ \mathrm{MeV}$——对如此轻的核来说异常之高，这正是 $\alpha$ 粒子成为重元素衰变首选抛射物的原因。换算成化学单位：每个核 $28.30\ \mathrm{MeV}$ 相当于 $28.30\times10^{6} \times 1.602\times10^{-19}\ \mathrm{J} \times 6.022\times10^{23}\ \mathrm{mol^{-1}} \approx 2.7\times10^{9}\ \mathrm{kJ\,mol^{-1}}$：每摩尔约为一根强化学键的一百万倍。
:::
:::

::: example 用焦耳说话的裂变与聚变 {#ex-fission-fusion}
一个 ${}^{235}\mathrm{U}$ 核裂变约释放 $200\ \mathrm{MeV}$。求每千克铀-235 的能量，并与煤的 $2.4\times10^{7}\ \mathrm{J\,kg^{-1}}$ 比较。然后用 $m({}^{2}\mathrm{H}) = 2.01410\ \mathrm{u}$、$m({}^{3}\mathrm{H}) = 3.01605\ \mathrm{u}$ 求聚变反应 ${}^{2}\mathrm{H} + {}^{3}\mathrm{H} \rightarrow {}^{4}\mathrm{He} + {}^{1}\mathrm{n}$ 的每核子能量，并与裂变的每核子能量比较。
::: solution
二百 MeV 即每个核 $200 \times 1.602\times10^{-13}\ \mathrm{J} = 3.20\times10^{-11}\ \mathrm{J}$。一千克包含 $1000/235.04 \times 6.022\times10^{23} = 2.56\times10^{24}$ 个核，所以
$$
E = 3.20\times10^{-11}\ \mathrm{J} \times 2.56\times10^{24} = 8.2\times10^{13}\ \mathrm{J\,kg^{-1}},
$$
约为煤的 $3.4\times10^{6}$ 倍——这就是一座煤电厂传送带规模的燃料，为何换成反应堆只剩铁锹规模的原因。至于聚变，质量亏损为
$$
\Delta m = 2.01410 + 3.01605 - 4.00260 - 1.00866 = 0.01889\ \mathrm{u},
$$
得 $Q = 0.01889 \times 931.5 = 17.6\ \mathrm{MeV}$ 每次反应。分摊到参与的五个核子上是每核子 $3.5\ \mathrm{MeV}$，是裂变 $200/235 = 0.85\ \mathrm{MeV}$ 每核子的四倍。按千克计聚变胜出，因为它从结合能曲线上低得多的地方出发；工程难点在于库仑势垒要求 $10^{8}\ \mathrm{K}$ 的温度。
:::
:::

## 原子核与社会

**裂变反应堆**维持着一个可控的链式反应：${}^{235}\mathrm{U}$ 的每次裂变放出二到三个中子，其中至少一个必须再引发一次裂变，反应才能自持。**慢化剂**（轻水、重水或石墨）给中子减速，因为慢中子裂变 ${}^{235}\mathrm{U}$ 的概率大得多；由中子吸收材料（硼、镉、铪）制成的**控制棒**把增殖系数精确调到一。电厂卖的是热而非裂变本身：热驱动汽轮发电机组，与煤炉毫无二致——所以说反应堆是一颗核做心脏的热机。废物问题真实存在且可以注明日期：乏燃料含有半衰期数十年的裂变产物（铯-137、锶-90）和半衰期数千年的次锕系核素；截至 2026 年，唯一获得运行许可的民用乏燃料深地质处置库在芬兰的奥尔基洛托（2023 年获得许可）。

**聚变**为太阳提供动力（质子-质子链），也是巨大科研投入的对象；氘在海水中实际上取之不尽，聚变也不产生长寿命的锕系废物，但把 $10^{8}\ \mathrm{K}$ 的等离子体经济地约束住，在净发电的层面上仍未解决。

::: warning 辐照不是污染 {#warn-irradiation}
让一件物品或一种食品穿过 $\gamma$ 辐射，会沉积能量并杀死微生物，但不会使物品带上放射性，因为设计正当的辐照装置或放疗光束中的光子与中子不会以任何可观的量使其核素发生嬗变。把辐射的*源*与放射性物质的*污染*混为一谈，是公众对核技术大多数恐惧的根源：被污染的物品携带的是不稳定原子本身，必须去污；而被辐照过的物品什么也没带上。同样，"辐射"也不是单一的危险：一张纸就能挡住 $\alpha$ 粒子，但一个*在体内*的 $\alpha$ 发射体——被吸入或吞下——比体外同样的活度危险得多，因为短射程把能量集中在了几层细胞里。
:::

辐射剂量是分层的度量的。**活度**（贝可勒尔）数衰变；**吸收剂量**（戈瑞，$\mathrm{Gy} = 1\ \mathrm{J\,kg^{-1}}$）数每千克沉积的能量；**有效剂量**（希沃特，$\mathrm{Sv}$）再按辐射类型——每戈瑞的 $\alpha$ 辐射造成的生物损伤约为 $\gamma$ 的二十倍——并按组织对吸收剂量加权。在危险类别的层面上：高急性剂量造成确定性损伤（放射病），其严重程度在阈值以上随剂量增长；而低剂量携带随机性风险——多年后癌症与可遗传效应的概率升高，辐射防护中假定其随剂量增长且无阈值。为了诚实的参照，天然本底——主要来自地面的氡，加上宇宙射线和你自己体内的 $^{40}\mathrm{K}$——全球平均每年约 $2.4\ \mathrm{mSv}$；而整个安全体系建立在 **ALARA** 原则之上：通过缩短在源附近的时间、拉大距离（强度按 $1/r^2$ 衰减）、加设屏蔽（$\alpha$ 用纸，$\beta$ 用塑料或玻璃，$\gamma$ 用几厘米铅或几米混凝土；而对高能的纯 $\beta$ 发射体绝不用铅屏蔽，因为会产生韧致辐射 X 射线），把剂量保持在*合理可达的最低水平*。

::: history
放射性由贝可勒尔（Becquerel）于 1896 年发现：他发现铀盐能透过黑纸使照相底片感光——这是一种原子的属性，与化学状态和光照都无关。玛丽·居里（Curie）与皮埃尔·居里在 1898 年从数吨沥青铀矿中分离出钋与镭，并造出了"radioactive"（放射性的）这个词。卢瑟福（Rutherford）与索迪（Soddy）在 1902–1903 年证明发射会把一种元素变成另一种元素，并引入了半衰期；卢瑟福此前已把 $\alpha$、$\beta$ 射线命名。查德威克（Chadwick）于 1932 年发现中子，它既是缺失的核组分，又是（因不带电的）嬗变的理想炮弹——费米（Fermi）的小组在 1934 年用它轰击了周期表上的大多数元素。1938 年，哈恩（Hahn）与施特拉斯曼（Strassmann）在铀的中子轰击产物中发现了钡，而迈特纳（Meitner）与弗里施（Frisch）把它解释为原子核的分裂，并仿照细胞的分裂把它命名为裂变。伽莫夫（Gamow）与独立工作的格尼与康登在 1928 年用量子隧穿解释了 $\alpha$ 衰变——这是波动力学在核内的第一次胜利，也是通向 [[quantum-chemistry/quantum-foundations]] 的纽带；而结合能曲线的形状则由冯·魏茨泽克（Weizsäcker）1935 年的液滴半经验质量公式所说明。
:::

## 后续内容

衰变动力学就是一级动力学换了个核的时钟——[[general-chemistry-2/rates-intro]] 的积分定律、半衰期与指数图像原封不动地适用。质能关系在 [[general-chemistry-2/entropy-free-energy]] 中再次出现，提醒我们能量账与质量账本是同一本账；本章的同位素质量与摩尔算术建立在 [[general-chemistry-1/atoms-and-moles]] 之上；$\alpha$ 衰变就是隧穿，其推导见 [[quantum-chemistry/quantum-foundations]]；而支配每个人辐射剂量的那些天然放射性——氡、$^{40}\mathrm{K}$、宇宙射线——属于 [[environmental-chemistry/earth-system-chemistry]] 的内容。

::: summary
- 核素由 $Z$ 与 $N$ 定义；稳定核素落在一条狭窄的带上，该带在高 $Z$ 处弯向富中子一侧（$N/Z \approx 1.5$），而 $Z > 83$ 无一稳定。
- 衰变方式：$\alpha$ 使 $A$ 减 4、$Z$ 减 2；$\beta^-$ 使 $Z$ 加 1；$\beta^+$ 与电子俘获使 $Z$ 减 1；$\gamma$ 都不变——把 $A$ 与 $Z$ 配平，方程就自己写好了。
- 衰变是一级的：$N = N_0 e^{-\lambda t}$，$t_{1/2} = \ln 2/\lambda$，活度 $A = \lambda N$；半衰期由核决定，与化学、温度、压强无关。
- 放射性定年就是把衰变定律倒过来读；放射性碳的量程约 $5\times10^{4}$ 年，铀-铅与钾-氩则到地球的年龄。
- 每个核子的结合能在铁-56 附近达到 $8.8\ \mathrm{MeV}$ 的极大；重核裂变与轻核聚变都沿曲线向上走，分别释放每核子 $0.85$ 与最高 $3.5\ \mathrm{MeV}$。
- 一千克铀-235 携带 $8\times10^{13}\ \mathrm{J}$，是化学燃料的数百万倍；反应堆是以可控链式反应为热源的热机，而其废物是千年尺度的工程难题。
- 剂量的层次是活度、能量（戈瑞）、加权风险（希沃特）；天然本底超过大多数人工源，防护的支点是时间、距离、屏蔽与 ALARA。
:::

## 练习

::: exercise 完成核方程 {level=1}
${}^{234}_{\ 90}\mathrm{Th}$ 以 $\beta^-$ 发射衰变。写出方程并指明子核。
::: solution
$\beta^-$ 发射在 $A$ 不变下使 $Z$ 加一：
$$
{}^{234}_{\ 90}\mathrm{Th} \rightarrow {}^{234}_{\ 91}\mathrm{Pa} + {}^{0}_{-1}\mathrm{e} + \bar{\nu}_\mathrm{e}.
$$
子核是镤-234。（反中微子带走自旋与部分能量，但既不带 $A$ 也不带 $Z$。）
:::
:::

::: exercise 剩余分数 {level=1 check="12.5"}
碘-131 的 $t_{1/2} = 8.02\ \mathrm{d}$。$24.06\ \mathrm{d}$ 后样品还剩多少？（以百分数输入。）
::: solution
$24.06/8.02 = 3.00$ 个半衰期，故分数为 $(1/2)^3 = 0.125$，即 $12.5\%$。
:::
:::

::: exercise 衰变常数 {level=1 check="0.115"}
锝-99m 的 $t_{1/2} = 6.01\ \mathrm{h}$。求其衰变常数。（以 $\mathrm{h^{-1}}$ 输入 $\lambda$。）
::: solution
$\lambda = \ln 2 / t_{1/2} = 0.693/6.01 = 0.115\ \mathrm{h^{-1}}$。
:::
:::

::: exercise 一克的活度 {level=2 check="12400"}
求 $1.00\ \mathrm{g}$ ${}^{238}\mathrm{U}$（$t_{1/2} = 4.47\times10^{9}\ \mathrm{y}$）的活度。（以 Bq 输入活度。）
::: solution
$N = 6.022\times10^{23}/238.05 = 2.53\times10^{21}$ 个原子，$\lambda = \ln 2/(4.47\times10^{9}\times3.156\times10^{7}\ \mathrm{s}) = 4.92\times10^{-18}\ \mathrm{s^{-1}}$，故 $A = \lambda N = 1.24\times10^{4}\ \mathrm{Bq}$。半衰期长、活度温和——在固定摩尔量下，每克活度与半衰期成反比。
:::
:::

::: exercise 数一条衰变系 {level=2 check="8"}
衰变系 ${}^{235}_{\ 92}\mathrm{U} \rightarrow {}^{207}_{\ 82}\mathrm{Pb}$ 中发生多少次 $\alpha$ 衰变？（输入 $\alpha$ 粒子的数目。）
::: solution
核子数：$235 - 207 = 28 = 4n_\alpha$，故 $n_\alpha = 8$。电荷再要求 $92 - 16 + n_\beta = 82$，所以还有 $n_\beta = 6$ 次 $\beta^-$ 衰变——但题目只问了那八个 $\alpha$ 粒子。
:::
:::

::: exercise 一个放射性碳年代 {level=2 check="1900"}
一件木器的现代 $^{14}\mathrm{C}$ 活度为 $79.5\%$。为它定年。（以年输入年代；取 $t_{1/2} = 5730\ \mathrm{y}$。）
::: solution
$t = \lambda^{-1}\ln(N_0/N) = (5730/\ln 2)\times\ln(1/0.795) = 8258\times0.2295 = 1.90\times10^{3}\ \mathrm{y}$。
:::
:::

::: exercise α 粒子的结合能 {level=3 check="7.07"}
已知 $m({}^{1}\mathrm{H}) = 1.00783\ \mathrm{u}$、$m_\mathrm{n} = 1.00866\ \mathrm{u}$、$m({}^{4}\mathrm{He}) = 4.00260\ \mathrm{u}$、$1\ \mathrm{u}\,c^2 = 931.5\ \mathrm{MeV}$，求 ${}^{4}\mathrm{He}$ 的每核子结合能。（以 MeV 每核子输入。）
::: solution
$\Delta m = 2(1.00783) + 2(1.00866) - 4.00260 = 0.03038\ \mathrm{u}$；$E_\mathrm{B} = 0.03038\times931.5 = 28.30\ \mathrm{MeV}$；每核子 $28.30/4 = 7.07\ \mathrm{MeV}$。对轻核而言很高——双幻的 $\alpha$ 粒子结合得异常紧，这就是它整体被发射的原因。
:::
:::

::: exercise 裂变燃料 {level=3 check="8.2"}
一个 ${}^{235}\mathrm{U}$ 核裂变释放 $200\ \mathrm{MeV}$。求每千克铀-235 释放的能量。（以 $10^{13}\ \mathrm{J\,kg^{-1}}$ 为单位输入。）
::: solution
每个核 $200\ \mathrm{MeV} = 3.20\times10^{-11}\ \mathrm{J}$；每千克 $N = (1000/235.04)\times6.022\times10^{23} = 2.56\times10^{24}$ 个核，故 $E = 8.2\times10^{13}\ \mathrm{J\,kg^{-1}}$。与煤的 $2.4\times10^{7}\ \mathrm{J\,kg^{-1}}$ 相比是 $3.4\times10^{6}$ 倍：这就是火车拉来的燃料与装在口袋里的燃料之间的全部差别。
:::
:::

::: exercise 聚变对裂变，按核子计 {level=3 check="17.6"}
对 ${}^{2}\mathrm{H} + {}^{3}\mathrm{H} \rightarrow {}^{4}\mathrm{He} + {}^{1}\mathrm{n}$，已知 $m({}^{2}\mathrm{H}) = 2.01410\ \mathrm{u}$、$m({}^{3}\mathrm{H}) = 3.01605\ \mathrm{u}$、$m({}^{4}\mathrm{He}) = 4.00260\ \mathrm{u}$、$m_\mathrm{n} = 1.00866\ \mathrm{u}$，求每次反应释放的能量。（以 MeV 输入。）并把每核子的能量与裂变的 $0.85\ \mathrm{MeV}$ 每核子比较。
::: solution
$\Delta m = (2.01410 + 3.01605) - (4.00260 + 1.00866) = 0.01889\ \mathrm{u}$，故 $Q = 0.01889\times931.5 = 17.6\ \mathrm{MeV}$。分摊到五个核子是每核子 $3.5\ \mathrm{MeV}$，为裂变 $0.85$ 的四倍：聚变从结合能曲线上低得多的地方出发，所以每个核子下落得更远。难点是库仑势垒——聚变需要一颗恒星中心，或其等价物，才能启动。
:::
:::
