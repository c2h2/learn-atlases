热力学数据表会告诉你，金刚石在室温下应当变成石墨，氢气和氧气的混合气应当变成水，一片面包应当慢慢氧化成二氧化碳和水。这些判断全都正确，可没有一件发生在你看得见的时限内：钻戒是永恒（就人生而言）的，混合气在烧瓶里放上几年都纹丝不动，直到一颗火花到来；而面包能保存到明天。热力学回答的是"朝哪个方向、进行到什么程度"；对"有多快"它一言不发。**化学动力学**研究的正是第二个问题——反应有多快，速率如何依赖浓度与温度，以及反应实际走过的那一串分子事件——它的*机理*。速率的跨度几乎超出想象：中和反应 $\mathrm{H^+(aq) + OH^-(aq) \rightarrow H_2O(l)}$ 基本受扩散控制，溶液一混合即告完成；而船体的锈蚀要按季节计，$\mathrm{^{238}U}$ 的放射性衰变要按十亿年计。本章建立描述这一切多样性所需的词汇和寥寥几个方程：速率、速率方程、积分速率方程、阿伦尼乌斯方程，以及催化剂。

## 有多快？速率及其测量

::: definition 反应速率 {#def-rate}
**反应速率**是反应物转化为产物的快慢，用单位时间内的物质的量浓度变化来表示。对于恒容下的单一反应，速率的定义应使之不依赖于你观察哪一种物种：对
$$
a\,\mathrm{A} + b\,\mathrm{B} \rightarrow c\,\mathrm{C} + d\,\mathrm{D}
\qquad\text{速率} = -\frac{1}{a}\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = -\frac{1}{b}\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = \frac{1}{c}\frac{\mathrm{d}[\mathrm{C}]}{\mathrm{d}t} = \frac{1}{d}\frac{\mathrm{d}[\mathrm{D}]}{\mathrm{d}t},
$$
其中 $[\mathrm{X}]$ 是 $\mathrm{X}$ 的浓度，单位为 $\mathrm{mol\,dm^{-3}}$。时间区间上的**平均速率**是商 $\Delta[\mathrm{X}]/\Delta t$；（瞬时）**速率**是该商当 $\Delta t \rightarrow 0$ 的极限，即浓度–时间曲线上切线的斜率。化学计量因子 $1/a$、$1/b$、…使速率成为刻画*反应*本身的单一正数，而不属于任何一种物质；没有它们，速率就会随你选择测量什么而改变。
:::

你看不到分子碰撞，所以任何速率都是通过追踪某个宏观性质随时间的变化来测定的：用分光光度法追踪反应溶液的颜色（一个经典的本科实验是高锰酸根 $\mathrm{MnO_4^-}$ 的紫色随草酸将其还原而褪去）、生成气体的体积或压力、随离子出现或消失而变化的电导率、一种手性糖转化为另一种时平面偏振光旋转角的变化，或在已知时刻取出反应液等份、淬灭后测定浓度。把性质对时间作图，换算成浓度，任一时刻的速率就是切线斜率。**初始速率** $v_0$，即 $t = 0$ 处的斜率，地位特殊，因为在那一刻浓度正是你配制时的浓度，逆反应尚未发生，缓慢的副反应也还没来得及开始。

::: example 消耗速率与生成速率 {#ex-rate-stoich}
五氧化二氮在气相中按 $2\,\mathrm{N_2O_5(g)} \rightarrow 4\,\mathrm{NO_2(g)} + \mathrm{O_2(g)}$ 分解。某时刻 $[\mathrm{N_2O_5}]$ 正以 $4.8\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$ 下降。求该时刻 (a) 反应速率、(b) $\mathrm{O_2}$ 的生成速率、(c) $\mathrm{NO_2}$ 的生成速率。
::: solution
(a) 按对 $\mathrm{N_2O_5}$ 取因子 $1/2$ 的速率定义，
$$
\text{速率} = -\frac{1}{2}\frac{\mathrm{d}[\mathrm{N_2O_5}]}{\mathrm{d}t} = \frac{4.8\times10^{-4}}{2} = 2.4\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}.
$$
(b) 每单位反应进度出现一个 $\mathrm{O_2}$，故 $\mathrm{d}[\mathrm{O_2}]/\mathrm{d}t = \text{速率} = 2.4\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。(c) 每单位进度出现四个 $\mathrm{NO_2}$，故 $\mathrm{d}[\mathrm{NO_2}]/\mathrm{d}t = 4\times2.4\times10^{-4} = 9.6\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。

注意这笔验算：反应物以 $4.8\times10^{-4}$ 下降，产物以 $9.6\times10^{-4}$ 和 $2.4\times10^{-4}$ 上升，三个速率之比恰为 $2:4:1$——恰是化学计量系数。单一的数值 $2.4\times10^{-4}$ 是*反应*的速率；其余是*物种*的速率。
:::
:::

::: quiz
对同一个反应，一位学生写下 $-\mathrm{d}[\mathrm{N_2O_5}]/\mathrm{d}t = \mathrm{d}[\mathrm{O_2}]/\mathrm{d}t$。这为什么是错的？
- [x] $\mathrm{N_2O_5}$ 的消失是 $\mathrm{O_2}$ 出现速度的两倍，两个导数之间差着化学计量系数带来的因子 2。
- [ ] 没有错；两个速率总是相等。
- [ ] 两个导数单位不同，无法比较。
- [ ] 它只在达到平衡后才成立。
::: solution
每生成一个 $\mathrm{O_2}$ 就消耗两个 $\mathrm{N_2O_5}$，所以 $-\mathrm{d}[\mathrm{N_2O_5}]/\mathrm{d}t = 2\,\mathrm{d}[\mathrm{O_2}]/\mathrm{d}t$。两个导数的单位相同，而且这个关系在每一时刻都成立，不只是平衡时——它是记账，不是化学。正确的写法是 $-\tfrac{1}{2}\,\mathrm{d}[\mathrm{N_2O_5}]/\mathrm{d}t = \mathrm{d}[\mathrm{O_2}]/\mathrm{d}t = \text{速率}$。
:::
:::

## 速率方程

::: definition 速率方程、反应级数 {#def-rate-law}
**速率方程**把速率表示为体系中各物种浓度的函数，最常见的是幂律形式
$$
v = k\,[\mathrm{A}]^{m}[\mathrm{B}]^{n}\cdots
$$
指数 $m$ 称为**对 A 的反应级数**，$n$ 为对 B 的级数，和 $m + n + \cdots$ 为**总级数**。比例常数 $k$ 是**速率常数**；在固定温度下它完全不依赖浓度。级数 $m, n, \ldots$ 由**实验**测定，一般*不是*化学计量系数；它们可以是整数、零、分数，甚至负数。$k$ 的单位必须使速率以 $\mathrm{mol\,dm^{-3}\,s^{-1}}$ 计：对总级数 $o$，$k$ 的单位是 $\mathrm{mol^{1-o}\,dm^{3(o-1)}\,s^{-1}}$——一级为 $\mathrm{s^{-1}}$，二级为 $\mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$，三级为 $\mathrm{dm^{6}\,mol^{-2}\,s^{-1}}$。
:::

必须彻底抵制从配平方程式直接读出速率方程的诱惑。这只对**基元反应**——单次分子事件——成立，而且即便那时也只对其自身的那一步成立。总反应 $2\,\mathrm{NO(g)} + \mathrm{O_2(g)} \rightarrow 2\,\mathrm{NO_2(g)}$ 恰好是三级的，$v = k[\mathrm{NO}]^2[\mathrm{O_2}]$；但反应 $\mathrm{H_2(g) + Br_2(g) \rightarrow 2\,HBr(g)}$ 服从一个分母中含项的速率方程，$v = k[\mathrm{H_2}][\mathrm{Br_2}]^{1/2}/(1 + k'[\mathrm{HBr}]/[\mathrm{Br_2}])$，带着半级数和产物抑制，谁也无法从方程式猜出来。级数是关于机理的事实，而机理是发现出来的，不是假设出来的。

::: proposition 初始速率法 {#prop-initial-rates}
设速率方程为 $v = k[\mathrm{A}]^m[\mathrm{B}]^n$，你在若干次实验中测定初始速率 $v_0$，各次实验只改变起始浓度。若某次实验把 $[\mathrm{A}]$ 加倍（$[\mathrm{B}]$ 不变）而使初始速率变为二倍……四倍……，则 $m = 1$，$2$，…，一般地
$$
m = \frac{\ln\!\big(v_0' / v_0\big)}{\ln\!\big([\mathrm{A}]'/[\mathrm{A}]\big)} \quad (\text{其余浓度固定}).
$$
$m$ 与 $n$ 确定后，$k$ 由任何一次实验代入即得。把某种试剂大量过量（**分离法**）就把它浓度折进一个表观速率常数成为常数，从而可以一次只测一个级数。
:::

::: example 由初始速率数据定级数：NO + O2 {#ex-initial-rates}
对 $\mathrm{25\,^\circ C}$ 下的 $2\,\mathrm{NO(g)} + \mathrm{O_2(g)} \rightarrow 2\,\mathrm{NO_2(g)}$，此类实验给出的示例性初始速率数据如下：

| 实验 | $[\mathrm{NO}]/\mathrm{mol\,dm^{-3}}$ | $[\mathrm{O_2}]/\mathrm{mol\,dm^{-3}}$ | $v_0\ /\mathrm{mol\,dm^{-3}\,s^{-1}}$ |
|---|---|---|---|
| 1 | 0.010 | 0.010 | $7.0\times10^{-3}$ |
| 2 | 0.020 | 0.010 | $2.8\times10^{-2}$ |
| 3 | 0.010 | 0.020 | $1.4\times10^{-2}$ |

确定级数与速率常数。
::: solution
实验 1 与 2 只差 $[\mathrm{NO}]$ 加倍，速率升为 $2.8\times10^{-2}/7.0\times10^{-3} = 4.0 = 2^2$：反应**对 NO 为二级**。实验 1 与 3 只差 $[\mathrm{O_2}]$ 加倍，速率加倍：**对** $\mathrm{O_2}$ **为一级**。速率方程为 $v = k[\mathrm{NO}]^2[\mathrm{O_2}]$，总三级——对一个表观速率方程而言这是真正罕见的事。由实验 1，
$$
k = \frac{7.0\times10^{-3}}{(0.010)^2(0.010)} = 7.0\times10^{3}\ \mathrm{dm^{6}\,mol^{-2}\,s^{-1}},
$$
单位按 $o = 3$ 的规则得出。把实验 2 与 3 代入可得同一 $k$（到所给位数）——这种一致性正是该方法的意义所在。
:::
:::

::: warning 速率常数不是速率，级数不是系数 {#warn-order}
本章存在的目的之一就是防止三种混淆。第一，$k$ 与 $v$ 是两个不同的对象：$v$ 随反应进行、浓度下降而改变，而 $k$（恒温下）不变；一个反应可以 $k$ 很大而速率很小，只因为浓度很小——高层大气就是如此。第二，速率方程中的级数**不是**化学计量系数，除非那一步是基元反应：$2\,\mathrm{NO} + \mathrm{O_2}$ 呈三级是机理造成的巧合，而方程式里带"2"的大多数反应并不是二级。第三，$k$ 很大对反应进行到什么程度一无所告——速率与平衡是两个独立的问题，一个热力学上有利的反应可以因 $k$ 太小而观察不到任何变化。
:::

## 积分速率方程

::: proposition 三个积分速率方程 {#prop-integrated}
对恒容下单一反应物 $\mathrm{A} \rightarrow$ 产物、速率方程 $v = k[\mathrm{A}]^{o}$ 且逆反应可忽略的体系，积分 $-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k[\mathrm{A}]^{o}$ 得

| 级数 $o$ | $[\mathrm{A}](t)$ | 直线图 | 斜率 | 半衰期 $t_{1/2}$ |
|---|---|---|---|---|
| 0 | $[\mathrm{A}]_0 - kt$ | $[\mathrm{A}]$ 对 $t$ | $-k$ | $[\mathrm{A}]_0/2k$ |
| 1 | $[\mathrm{A}]_0\,e^{-kt}$ | $\ln[\mathrm{A}]$ 对 $t$ | $-k$ | $(\ln 2)/k$ |
| 2 | $[\mathrm{A}]_0/(1 + kt[\mathrm{A}]_0)$ | $1/[\mathrm{A}]$ 对 $t$ | $+k$ | $1/(k[\mathrm{A}]_0)$ |

半衰期 $t_{1/2}$ 是 $[\mathrm{A}]$ 降到一半所需的时间，**只对一级反应是常数**；零级反应中它随反应进行而缩短，二级反应中它增长。这些形式也适用于在**拟级**条件下进行的较高级数反应：此时除一种试剂外其余试剂均大量过量，其浓度被吸收进 $k$ 中。
:::

::: proof 一级积分速率方程及其半衰期 {#proof-first-order}
对 $o = 1$，速率方程为 $\mathrm{d}[\mathrm{A}]/\mathrm{d}t = -k[\mathrm{A}]$。分离变量，
$$
\frac{\mathrm{d}[\mathrm{A}]}{[\mathrm{A}]} = -k\,\mathrm{d}t,
$$
从 $t = 0$ 时的 $[\mathrm{A}]_0$ 积分到时刻 $t$ 的 $[\mathrm{A}]$：
$$
\int_{[\mathrm{A}]_0}^{[\mathrm{A}]} \frac{\mathrm{d}[\mathrm{A}]}{[\mathrm{A}]} = -k\int_0^t \mathrm{d}t
\qquad\Longrightarrow\qquad
\ln\frac{[\mathrm{A}]}{[\mathrm{A}]_0} = -kt,
$$
即 $[\mathrm{A}] = [\mathrm{A}]_0 e^{-kt}$：一级浓度按**指数**衰减，而 $\ln[\mathrm{A}]$ 对 $t$ 的图是斜率为 $-k$ 的直线，这就是一级反应的识别方式。现在在 $t = t_{1/2}$ 处令 $[\mathrm{A}] = [\mathrm{A}]_0/2$：
$$
\ln\frac{1}{2} = -k\,t_{1/2}
\qquad\Longrightarrow\qquad
t_{1/2} = \frac{\ln 2}{k},
$$
其中不含 $[\mathrm{A}]_0$。一级反应从任何浓度降到其一半所用的时间都相同——这就是放射性样品或一级样品降到四分之一恰好需要两个半衰期、而不是一个的原因。二级方程可用同样方法在习题中推导。
:::

::: example 五氧化二氮：半衰期与指数定律 {#ex-n2o5}
$\mathrm{N_2O_5}$ 在 $\mathrm{CCl_4}$ 溶液中于 $\mathrm{25\,^\circ C}$ 按 $2\,\mathrm{N_2O_5} \rightarrow 4\,\mathrm{NO_2} + \mathrm{O_2}$ 分解，为一级反应，$k = 1.7\times10^{-3}\ \mathrm{s^{-1}}$（标准数据表值）。从 $[\mathrm{N_2O_5}]_0 = 0.100\ \mathrm{mol\,dm^{-3}}$ 出发，求 (a) 半衰期，(b) 分解 $75\,\%$ 所需时间，(c) $20.0\ \mathrm{min}$ 后的浓度。
::: solution
(a) $t_{1/2} = \ln 2 / k = 0.6931/1.7\times10^{-3} = 4.1\times10^{2}\ \mathrm{s}$，约 $6.8\ \mathrm{min}$。
(b) 分解 $75\,\%$ 即剩余四分之一，而四分之一就是两次减半：$t = 2t_{1/2} = 8.2\times10^{2}\ \mathrm{s} \approx 13.6\ \mathrm{min}$。等价地 $\ln(0.100/0.025)/k = \ln 4/k$，同一个数。
(c) $[\mathrm{N_2O_5}] = 0.100 \times e^{-(1.7\times10^{-3})(1200)} = 0.100 \times e^{-2.04} = 0.013\ \mathrm{mol\,dm^{-3}}$。

值得在脑中做两个合理性检验。$20\ \mathrm{min} \approx 3$ 个半衰期之后，浓度应略高于 $0.100/8 = 0.0125$，事实正是如此。而 (b) 的答案无论 $k$ 为何都必须恰为 (a) 的两倍，因为一级反应的半衰期不在乎它从哪里出发。
:::
:::

::: quiz
碳-14 以 $5730$ 年的半衰期衰变。测量同一块古木的 $1\ \mathrm{g}$ 样品与 $1\ \mathrm{mg}$ 样品。下列说法哪个正确？
- [x] 两个样品都在 $5730$ 年内失去其 $\mathrm{^{14}C}$ 的一半，因为放射性衰变是一级过程，半衰期与起始量无关。
- [ ] $1\ \mathrm{g}$ 样品失去一半 $\mathrm{^{14}C}$ 需要一千倍的时间。
- [ ] 样品大小不同，半衰期无法使用。
- [ ] 较小的样品每克衰变得更快。
::: solution
一级半衰期为 $(\ln 2)/k$，不含初始量——见上面的证明。$1\ \mathrm{g}$ 样品的*活度*（每秒衰变数）是一千倍大，因为原子多一千倍；但每年损失的*比例*完全相同。正是这种无关性，使碳-14 测年对一片木屑和一根房梁同样有效。
:::
:::

::: warning 半衰期只对一级才是"半衰期" {#warn-halflife}
"$t_{1/2} = 0.693/k$" 被引用得太频繁，以至于常被当作 $k$ 的定义；它不是。它是一级反应的*推论*。零级反应 $t_{1/2} = [\mathrm{A}]_0/2k$——起始浓度加倍，半衰期也加倍，而反应在 $t = [\mathrm{A}]_0/k$ 处彻底结束（许多酶促反应对底物恰为零级，正因为酶已饱和，这也正是它们突然停止的原因）。二级反应 $t_{1/2} = 1/(k[\mathrm{A}]_0)$——按半衰期的说法反应在*减速*，每个半衰期是上一个的两倍。若一次实验测得的相继半衰期不相等，反应就不是一级；而测量半衰期如何变化，本身就是求级数的方法。
:::

## 温度：阿伦尼乌斯方程

::: proposition 阿伦尼乌斯方程 {#prop-arrhenius}
大多数反应的速率常数随热力学温度 $T$ 的变化近似为
$$
k = A\,e^{-E_\mathrm{a}/RT}
\qquad\Longleftrightarrow\qquad
\ln k = \ln A - \frac{E_\mathrm{a}}{R}\cdot\frac{1}{T},
$$
其中 $A$ 是**指前因子**（或频率因子），$E_\mathrm{a}$ 是**活化能**，$R$ 是气体常数。$\ln k$ 对 $1/T$ 的图（**阿伦尼乌斯图**）是一条斜率为 $-E_\mathrm{a}/R$、截距为 $\ln A$ 的直线；而在两个温度之间，
$$
\ln\frac{k_2}{k_1} = \frac{E_\mathrm{a}}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right).
$$
这个方程是一条**经验规则**——它在中等温度区间内对极广的一类反应拟合得很好，且其中 $E_\mathrm{a}$ 与 $A$ 被当作常数——但它不是自然定律：$A$ 实际上随 $T$ 缓慢变化；有些反应的阿伦尼乌斯图弯曲甚至斜率为负；少数无能垒反应的活化能为*负*的小值。
:::

::: example 由两个温度求活化能 {#ex-arrhenius}
气相 $\mathrm{N_2O_5}$ 分解的数据表列活化能 $E_\mathrm{a} = 103\ \mathrm{kJ\,mol^{-1}}$，$\mathrm{25\,^\circ C}$ 下 $k = 3.4\times10^{-5}\ \mathrm{s^{-1}}$。估算 $\mathrm{55\,^\circ C}$ 下的 $k$ 以及速率增大的倍数。
::: solution
取 $T_1 = 298.15\ \mathrm{K}$，$T_2 = 328.15\ \mathrm{K}$，
$$
\ln\frac{k_2}{k_1} = \frac{103\times10^{3}}{8.314}\left(\frac{1}{298.15} - \frac{1}{328.15}\right) = 12\,390 \times 3.066\times10^{-4} = 3.80,
$$
故 $k_2/k_1 = e^{3.80} = 45$，$k_2 = 45 \times 3.4\times10^{-5} = 1.5\times10^{-3}\ \mathrm{s^{-1}}$。升温 $30\ \mathrm{K}$ 使速率增大四十五倍——这就是为什么厨房里既有"每降 $\mathrm{10\,K}$ 保质期约增三倍"的冷藏经验，也有"每升 $10\ \mathrm{K}$ 速率翻倍"的口诀，而且两者都只是经验之谈。

计算中要多保留几位：过早把 $3.066\times10^{-4}$ 舍入，答案就会差几个百分点，而指数函数对 $E_\mathrm{a}/RT$ 中粗疏的惩罚远比对其他任何量的惩罚重。
:::
:::

速率常数为什么应当对 $1/T$ 呈指数？碰撞理论能给出这个形状（虽谈不上精确）：在大气压的气体中，分子每立方分米每秒碰撞约 $10^{28}$ 次，所以若*每次*碰撞都反应，$k$ 将大得离谱。只有当碰撞沿中心连线的能量超过阈值 $E_0$ 时反应才发生，而高于 $E_0$ 的碰撞的玻尔兹曼分数是 $e^{-E_0/RT}$——指数由此而来。剩下的 $A = PZ$ 是碰撞频率 $Z$ 乘以一个不大于 1 的**取向因子** $P$：NO₂ 分子必须以正确的原子相碰，复杂分子的反应 $P$ 很小。现代表述即过渡态理论，用活化自由能 $\Delta^\ddagger G$ 取代阈值，详见 [[kinetics/transition-state-theory]]；眼下，把 $E_\mathrm{a}$ 当作阿伦尼乌斯图斜率的实验测量值即可，不必赋予它更多神秘色彩。

::: example "每 10 K 翻倍"口诀背后藏着多大的活化能？ {#ex-rule-of-thumb}
在室温附近，许多反应每升温 $10\ \mathrm{K}$ 速率约翻倍。对 $298 \rightarrow 308\ \mathrm{K}$ 这一步，这对应多大的活化能？
::: solution
令 $k_2/k_1 = 2$，由双温方程解出 $E_\mathrm{a}$：
$$
E_\mathrm{a} = \frac{R\ln 2}{\dfrac{1}{298.15} - \dfrac{1}{308.15}} = \frac{8.314 \times 0.6931}{1.088\times10^{-4}} = 5.3\times10^{4}\ \mathrm{J\,mol^{-1}},
$$
约 $53\ \mathrm{kJ\,mol^{-1}}$。所以这条口诀实际上是在说：大量常见反应——酯的水解、糖的分解、使食物腐败的微生物与氧化过程——的活化能都在 $50\ \mathrm{kJ\,mol^{-1}}$ 上下。远高于它的反应（如 $\mathrm{N_2O_5}$ 的 $103\ \mathrm{kJ\,mol^{-1}}$）升温时比口诀快得多；低于它的反应以及扩散控制的反应，则几乎感觉不到恒温箱的档位。这也是冷冻保鲜的定量原因：在 $\mathrm{-18\,^\circ C}$ 而非 $\mathrm{25\,^\circ C}$ 下，一个活化能 $50\ \mathrm{kJ\,mol^{-1}}$ 的腐败反应要慢约 $2\times10^{3}$ 倍。
:::
:::

## 催化剂

::: definition 催化剂 {#def-catalyst}
**催化剂**是一种提高反应速率而自身在总反应中不被消耗的物质：它参与机理中的一步或多步，并在后续步骤中再生，从而在净方程中消去。它起作用的方式是提供一条**活化能更低的替代路径**——一个不同的机理，而不是同一条机理变得友善。催化剂对正、逆反应的加速*完全相同*（这是微观可逆性的推论：它必须稳定过渡态，而过渡态位于两个方向之间），所以它只改变达到平衡的快慢，绝不改变平衡的位置。催化具有**专一性**——水解某种酯的催化剂可能对它的异构体视而不见——而催化剂常被不可逆地结合它们的物质**中毒**。
:::

::: example 降低能垒换来多少？ {#ex-catalyst}
过氧化氢的分解 $2\,\mathrm{H_2O_2(aq)} \rightarrow 2\,\mathrm{H_2O(l)} + \mathrm{O_2(g)}$ 未催化时很慢；碘离子提供一条能垒较低的两步路径（$\mathrm{H_2O_2 + I^- \rightarrow H_2O + IO^-}$，随后 $\mathrm{IO^- + H_2O_2 \rightarrow H_2O + O_2 + I^-}$，$\mathrm{I^-}$ 复原）。若催化路径在 $\mathrm{25\,^\circ C}$ 的活化能低 $25\ \mathrm{kJ\,mol^{-1}}$，并假设 $A$ 相近，速率常数增大多少倍？
::: solution
$$
\frac{k_\text{cat}}{k_\text{uncat}} = \exp\!\left(\frac{\Delta E_\mathrm{a}}{RT}\right) = \exp\!\left(\frac{25\,000}{8.314 \times 298.15}\right) = e^{10.1} = 2.4\times10^{4}.
$$
仅仅低 $25\ \mathrm{kJ\,mol^{-1}}$——只有典型键能的百分之几——的能垒，就在室温换来两万四千倍的速率提升。这就是催化是化学家手中最有力的杠杆的原因，也是酶（其降垒幅度比任何非催化路径还多几十 $\mathrm{kJ\,mol^{-1}}$）能达到 $10^{10}$ 以上速率增强的原因。
:::
:::

::: warning 催化剂做不了不可能的事 {#warn-catalyst}
催化剂加速的是趋近平衡的过程；它不能改变平衡常数、$\Delta_\mathrm{r}G^\circ$ 或平衡产率，因为它从*两侧*把能垒压低完全相同的量。若一个反应热力学上被禁止（$\Delta_\mathrm{r}G$ 强烈为正），任何催化剂都无法使它进行——催化剂不是魔法，声称某催化剂"让不可能的反应发生"是混淆了速率与限度。催化剂也不改变反应热：盖斯定律对总变化成立，无论走哪条路径。催化剂*能够*做到、且在工业上反复做到的是：在若干可能产物中选择最快生成的那一个，即选择性——那是动力学而非热力学的馈赠。
:::

::: history
阿伦尼乌斯（Arrhenius）在多年研究糖的转化等溶液反应之后，于 1889 年提出了他的指数速率方程，引入了"arrheniusche Energie"——反应分子必须具有的平均能量以上的能量——给了动力学第一个分子层面的解释。奥斯特瓦尔德（Ostwald）在 1894 年前后创造了*催化*一词与"催化剂"这个名词，并写出第一个普遍的催化理论，与范特霍夫（van 't Hoff）同台竞技，后者对反应速率及速率与平衡关系的研究使 1884–1902 年成为物理化学的奠基十年。博登斯坦（Bodenstein）1913 年对氢与溴反应的处理引入了**稳态近似**，并证明链机理能够再现一个古怪的表观速率方程——由此开启了链反应的时代，欣谢尔伍德（Hinshelwood）与谢苗诺夫（Semyonov）在 1930 年代将其发扬光大。这条线索直接通向本图谱的动力学与催化课程。
:::

## 后续内容

下一章化学平衡，无非是正、逆两个速率——各自带着自己的阿伦尼乌斯温度依赖——变得相等的状态；[[general-chemistry-2/chemical-equilibrium]] 将把它讲精确，并说明为什么速率常数之比就是平衡常数。放射性衰变是已知最纯粹的一级过程，其测年与医学应用在 [[general-chemistry-2/nuclear-chemistry]]。速率方程、分离法与稳态方法以及机理的整套工具在 [[kinetics/rate-laws]] 与 [[kinetics/reaction-mechanisms]] 中展开；碰撞理论与过渡态理论见 [[kinetics/collision-theory]] 与 [[kinetics/transition-state-theory]]；链反应见 [[kinetics/chain-reactions]]；而本章只用一个例题引入的催化，在 [[kinetics/homogeneous-catalysis]] 中是一门完整的学问。

::: summary
- 反应速率按 $1/\nu$ 化学计量因子定义，使它对反应是一个数而非每种物质一个数；速率作为浓度–时间曲线的斜率来测量，常用初始速率。
- 速率方程 $v = k[\mathrm{A}]^m[\mathrm{B}]^n$ 是实验事实；级数不是系数，$k$ 的单位取决于总级数。
- 积分速率方程各给一条直线：$[\mathrm{A}]$ 对 $t$（零级）、$\ln[\mathrm{A}]$ 对 $t$（一级）、$1/[\mathrm{A}]$ 对 $t$（二级）；一级按指数衰减。
- $t_{1/2} = (\ln 2)/k$ 只对一级成立——恒定的半衰期是一级动力学的指纹；零级与二级的半衰期依赖 $[\mathrm{A}]_0$。
- 阿伦尼乌斯方程 $k = Ae^{-E_\mathrm{a}/RT}$ 是经验式但适用极广；$E_\mathrm{a}$ 是 $\ln k$ 对 $1/T$ 图的斜率，指数使速率对温度极其敏感。
- 碰撞理论把指数解释为超过阈值的玻尔兹曼分数，$A = PZ$ 承载碰撞频率与取向。
- 催化剂提供低能垒路径，同等加速正逆反应，既不能移动平衡，也不能使被禁止的反应成为可能。
:::

## 练习

::: exercise 平均速率 {level=1 check="0.003"}
某反应最初 $40.0\ \mathrm{s}$ 内 A 的浓度从 $0.400$ 降到 $0.280\ \mathrm{mol\,dm^{-3}}$。这段时间内 A 的平均消耗速率是多少？（以 $\mathrm{mol\,dm^{-3}\,s^{-1}}$ 输入速率。）
::: solution
$\bar{v} = \Delta[\mathrm{A}]/\Delta t = (0.400 - 0.280)/40.0 = 3.0\times10^{-3}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。*消耗*速率取正值报告；导数 $\mathrm{d}[\mathrm{A}]/\mathrm{d}t$ 本身是 $-3.0\times10^{-3}$。
:::
:::

::: exercise 化学计量速率 {level=1 check="0.00024"}
对 $2\,\mathrm{N_2O_5(g)} \rightarrow 4\,\mathrm{NO_2(g)} + \mathrm{O_2(g)}$，某时刻 $\mathrm{N_2O_5}$ 的消耗速率为 $4.8\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。该时刻 $\mathrm{d}[\mathrm{O_2}]/\mathrm{d}t$ 是多少？（以 $\mathrm{mol\,dm^{-3}\,s^{-1}}$ 输入。）
::: solution
$\mathrm{d}[\mathrm{O_2}]/\mathrm{d}t = \tfrac{1}{2} \times 4.8\times10^{-4} = 2.4\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$：每失去两个五氧化二氮分子出现一个氧分子。
:::
:::

::: exercise 由速率常数求半衰期 {level=1 check="408"}
某一级反应的 $k = 1.7\times10^{-3}\ \mathrm{s^{-1}}$。它的半衰期是多少？（以秒输入。）
::: solution
$t_{1/2} = \ln 2/k = 0.6931/1.7\times10^{-3} = 408\ \mathrm{s}$，约 $6.8\ \mathrm{min}$。注意答案不依赖起始浓度——这就是一级反应的标志。
:::
:::

::: exercise 由速率方程求速率 {level=2 check="0.00189"}
某反应服从 $v = k[\mathrm{A}]^2[\mathrm{B}]$，$k = 0.42\ \mathrm{dm^{6}\,mol^{-2}\,s^{-1}}$。当 $[\mathrm{A}] = 0.15$、$[\mathrm{B}] = 0.20\ \mathrm{mol\,dm^{-3}}$ 时速率是多少？（以 $\mathrm{mol\,dm^{-3}\,s^{-1}}$ 输入速率。）$k$ 的单位对总级数说了什么？
::: solution
$v = 0.42 \times (0.15)^2 \times 0.20 = 0.42 \times 0.0225 \times 0.20 = 1.9\times10^{-3}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。单位 $\mathrm{dm^{6}\,mol^{-2}\,s^{-1}}$ 正是总级数 $3$ 所要求的单位（$\mathrm{mol^{1-o}dm^{3(o-1)}s^{-1}}$ 取 $o = 3$），确认三级——级数 $2 + 1$ 虽分属不同物种也要相加。
:::
:::

::: exercise 达到 90 % 的时间 {level=2 check="1350"}
对 $\mathrm{25\,^\circ C}$ 下 $\mathrm{N_2O_5}$ 在 $\mathrm{CCl_4}$ 中的一级分解（$k = 1.7\times10^{-3}\ \mathrm{s^{-1}}$），反应物分解 $90\,\%$ 需要多久？（以秒输入时间，保留三位有效数字。）
::: solution
分解 $90\,\%$ 即剩余 $10\,\%$：$t = \ln(1/0.10)/k = \ln 10 / 1.7\times10^{-3} = 2.303/1.7\times10^{-3} = 1.35\times10^{3}\ \mathrm{s} \approx 23\ \mathrm{min}$。这是 $3.32$ 个半衰期（$\log_2 10$），是个有用的检验：十个半衰期只剩 $0.1\ \%$。
:::
:::

::: exercise 由温度系数求活化能 {level=2 check="106"}
某反应在 $\mathrm{35\,^\circ C}$ 的速率常数是 $\mathrm{25\,^\circ C}$ 的四倍。估算活化能。（以 $\mathrm{kJ\,mol^{-1}}$ 输入 $E_\mathrm{a}$。）
::: solution
$E_\mathrm{a} = R\ln 4\,\big/\!\left(\tfrac{1}{298.15} - \tfrac{1}{308.15}\right) = 8.314 \times 1.386 / 1.088\times10^{-4} = 1.06\times10^{5}\ \mathrm{J\,mol^{-1}} = 106\ \mathrm{kJ\,mol^{-1}}$。每 $10\ \mathrm{K}$ 翻倍对应 $53\ \mathrm{kJ\,mol^{-1}}$；四倍恰是对数的两倍，故活化能也是两倍——双温方程对 $\ln(k_2/k_1)$ 是线性的。
:::
:::

::: exercise 二级积分速率方程 {level=3}
把二级速率方程 $-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k[\mathrm{A}]^2$ 从 $[\mathrm{A}]_0$ 积分到 $[\mathrm{A}]$，导出半衰期 $t_{1/2} = 1/(k[\mathrm{A}]_0)$。并用结果判断：某二级反应从 $[\mathrm{A}]_0 = 0.050\ \mathrm{mol\,dm^{-3}}$ 起 $37\ \mathrm{s}$ 完成 $50\,\%$；再完成一半（共 $75\,\%$）需要多久？
::: solution
分离变量：$-\mathrm{d}[\mathrm{A}]/[\mathrm{A}]^2 = k\,\mathrm{d}t$，而 $\int \mathrm{d}[\mathrm{A}]/[\mathrm{A}]^2 = -1/[\mathrm{A}]$，故
$$
\frac{1}{[\mathrm{A}]} - \frac{1}{[\mathrm{A}]_0} = kt.
$$
令 $[\mathrm{A}] = [\mathrm{A}]_0/2$ 得 $t_{1/2} = (2/[\mathrm{A}]_0 - 1/[\mathrm{A}]_0)/k = 1/(k[\mathrm{A}]_0)$。于是 $k = 1/(t_{1/2}[\mathrm{A}]_0) = 1/(37 \times 0.050) = 0.54\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$，而*第二个*半衰期从 $[\mathrm{A}]_0/2$ 出发，所以是它的两倍长：$74\ \mathrm{s}$。到 $75\,\%$ 共需 $37 + 74 = 111\ \mathrm{s}$。二级反应的半衰期一个接一个地加倍——与一级相反——因为速率依赖 $[\mathrm{A}]^2$，浓度减半使速率变为四分之一。
:::
:::

::: exercise 两个温度，一次消元 {level=3 check="315"}
某反应 $E_\mathrm{a} = 50\ \mathrm{kJ\,mol^{-1}}$，在 $298\ \mathrm{K}$ 下进行。在什么温度下它的速率是原来的三倍？（以开尔文输入温度，保留三位有效数字。）
::: solution
由 $\ln 3 = (E_\mathrm{a}/R)(1/T_1 - 1/T_2)$ 解 $T_2$：
$$
\frac{1}{T_2} = \frac{1}{298.15} - \frac{8.314 \times 1.0986}{50\,000} = 3.3540\times10^{-3} - 1.827\times10^{-4} = 3.171\times10^{-3},
$$
故 $T_2 = 315\ \mathrm{K}$（$\mathrm{42\,^\circ C}$）。在两个阿伦尼乌斯方程之间消去 $A$——把一个 $\ln k$ 从另一个中减去——是*那个*标准动作：它对任何一对 $(T, k)$ 都适用，且永远不需要知道 $A$。
:::
:::

::: exercise 一个解释三级方程的机理 {level=3}
反应 $2\,\mathrm{NO} + \mathrm{O_2} \rightarrow 2\,\mathrm{NO_2}$ 实测为三级，$v = k_\text{obs}[\mathrm{NO}]^2[\mathrm{O_2}]$，且 $k_\text{obs}$ 随温度升高而*略降*。提出一个含 NO 快速前置平衡二聚的两步机理，用前置平衡近似导出速率方程，并把 $k_\text{obs}$ 与表观活化能用各步的量表示。$k_\text{obs}$ 为什么会随温度下降？
::: solution
机理：第一步 $\mathrm{2\,NO \rightleftharpoons N_2O_2}$，快速，平衡常数 $K$；第二步 $\mathrm{N_2O_2 + O_2 \rightarrow 2\,NO_2}$，慢，速率常数 $k_2$。前置平衡：$[\mathrm{N_2O_2}] = K[\mathrm{NO}]^2$，故产物生成速率为
$$
v = k_2[\mathrm{N_2O_2}][\mathrm{O_2}] = k_2 K\,[\mathrm{NO}]^2[\mathrm{O_2}],
\qquad k_\text{obs} = k_2 K.
$$
三级之所以出现，是因为在唯一的慢事件之前，两个 NO 分子已储存在前置平衡配合物中。现在 $k_2 \propto e^{-E_{\mathrm{a},2}/RT}$ 随温度上升，但对放热的二聚反应（$\Delta H < 0$），$K \propto e^{-\Delta H/RT}$ 随温度*下降*，于是
$$
E_{\mathrm{a,app}} = E_{\mathrm{a},2} + \Delta H,
$$
若二聚放热足够多，表观活化能——从而 $k_\text{obs}$——就随加热而减小。表观活化能甚至可以为负，这也是阿伦尼乌斯方程被标注为经验式的理由之一：它描述 $k$ 的行为，而 $E_\mathrm{a}$ 的解释属于机理。
:::
:::
