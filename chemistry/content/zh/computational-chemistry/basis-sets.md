对分子的每一次量子化学计算都始于两个选择：*方法*（哈特里-福克、MP2、耦合簇、密度泛函）与*基组*——分子轨道在其中展开的函数集合。输出文件与论文把两者并列报告，如"B3LYP/6-31G*"或"CCSD(T)/cc-pVTZ"，而第二个选择与第一个同样要紧。太小的基组能产生比方法之间的差异还大的误差；太大的基组则可能让计算根本无法进行。本课解释基函数是什么、为什么几乎所有程序都用高斯函数尽管它形状不对、基组如何按有系统的层级搭建、结果如何外推到完备基组极限，以及如何修正有限原子心基组的一个特征性伪影——基组叠加误差。

## 为什么需要基组，它又必须做到什么

在[[computational-chemistry/hartree-fock#prop-roothaan]]中，分子轨道被展开为$\psi_i = \sum_\mu C_{\mu i}\phi_\mu$，从而把哈特里-福克方程化为矩阵问题$\mathbf{FC} = \mathbf{SC}\boldsymbol\varepsilon$。由变分原理，扩大基组只会降低能量，而在*完备*基组的极限下即达到哈特里-福克极限。对关联方法同样如此，只是那里的基组还必须描述电子被激发到的*虚*轨道。因此，一个好的基组必须

1. 把占据轨道描述好，尤其是化学发生的价层区域；
2. 足够灵活，使轨道能随原子成键而改变大小与形状（收缩、扩张、极化）；
3. 对关联方法，提供与电子对相互关联所及区域相似的虚轨道——这要求更高角动量的函数；
4. 让积分——尤其是那约$K^{4}/8$个双电子积分——算起来便宜。

最后一条要求实际上支配了整个设计。

## 斯莱特函数与高斯函数

氢原子的精确轨道按$e^{-Zr/n}$衰减，并在核处有尖点。这种形式的函数是自然的选择。

::: definition 斯莱特型与高斯型轨道函数 {#def-sto-gto}
以核为中心的**斯莱特型轨道函数**（STO）形如
$$
\phi^\mathrm{STO}_{\zeta,n,l,m}(r, \theta, \varphi) = N\,r^{n-1}e^{-\zeta r}\,Y_{lm}(\theta, \varphi),
$$
指数为$\zeta$。**高斯型轨道函数**（GTO）的笛卡儿形式为
$$
\phi^\mathrm{GTO}_{\alpha,i,j,k}(\mathbf{r}) = N\,x^{i}y^{j}z^{k}e^{-\alpha r^{2}},
$$
指数为$\alpha$，其中$x, y, z$以球心为原点度量，$l = i + j + k$是角动量（$l = 0$：s；$1$：p；$2$：d）。归一化的s型高斯函数为$(2\alpha/\pi)^{3/4}e^{-\alpha r^{2}}$；归一化的$1s$斯莱特函数为$(\zeta^{3}/\pi)^{1/2}e^{-\zeta r}$。d壳层有六个笛卡儿分量（$x^{2}, y^{2}, z^{2}, xy, xz, yz$），但只有五个*球面*（纯）分量；第六个笛卡儿组合$x^{2} + y^{2} + z^{2}$是一个s型函数。各程序默认采用的分量并不相同。
:::

斯莱特函数在核处有正确的尖点（$r = 0$处$\mathrm{d}\psi/\mathrm{d}r = -Z\psi$，即卡托（Kato）尖点条件），在远程有正确的指数衰减。高斯函数两者都没有：它在核处是平的，衰减又太快。它的好处在于数学。

::: proposition 高斯乘积定理 {#prop-gpt}
中心在$\mathbf{A}$与$\mathbf{B}$的两个s型高斯函数之积，是中心在两点连线上某一点的单个高斯函数：
$$
e^{-\alpha\lvert\mathbf{r}-\mathbf{A}\rvert^{2}}\,e^{-\beta\lvert\mathbf{r}-\mathbf{B}\rvert^{2}} = K_{AB}\,e^{-p\lvert\mathbf{r}-\mathbf{P}\rvert^{2}}, \qquad
p = \alpha + \beta, \quad \mathbf{P} = \frac{\alpha\mathbf{A} + \beta\mathbf{B}}{\alpha + \beta}, \quad K_{AB} = \exp\!\left(-\frac{\alpha\beta}{\alpha + \beta}\lvert\mathbf{A}-\mathbf{B}\rvert^{2}\right).
$$
带多项式前置因子的高斯函数之积同样是中心在$\mathbf{P}$的高斯函数的有限和。
:::

::: proof
指数为$-\alpha(\mathbf{r}-\mathbf{A})^{2} - \beta(\mathbf{r}-\mathbf{B})^{2} = -p\,r^{2} + 2\mathbf{r}\cdot(\alpha\mathbf{A} + \beta\mathbf{B}) - \alpha A^{2} - \beta B^{2}$。对$\mathbf{r}$配方，
$$
-p\left(\mathbf{r} - \mathbf{P}\right)^{2} + p P^{2} - \alpha A^{2} - \beta B^{2},
$$
而常数项等于$\frac{(\alpha\mathbf{A} + \beta\mathbf{B})^{2}}{p} - \alpha A^{2} - \beta B^{2} = -\frac{\alpha\beta}{p}\left(A^{2} - 2\mathbf{A}\cdot\mathbf{B} + B^{2}\right) = -\frac{\alpha\beta}{p}\lvert\mathbf{A}-\mathbf{B}\rvert^{2}$。每个笛卡儿因子$(x - A_x)^{i}$都可写成$\left[(x - P_x) + (P_x - A_x)\right]^{i}$并按二项式展开，所以多项式前置因子产生$\mathbf{P}$处高斯函数的有限和。
:::

该定理把对四个高斯中心的一切双电子积分归约为仅对*两个*中心$\mathbf{P}$与$\mathbf{Q}$的积分，后者可用博伊斯（Boys）函数$F_0(t) = \int_0^{1}e^{-tu^{2}}\,\mathrm{d}u = \tfrac{1}{2}\sqrt{\pi/t}\,\mathrm{erf}\sqrt{t}$及其高阶类比写成封闭形式求值。对斯莱特函数不存在这样的归约，多心积分只能靠缓慢的数值求积。博伊斯1950年提出高斯基函数正是为此。算一个斯莱特函数积分的代价抵得上许多个高斯函数的，于是策略就是用若干个高斯函数去仿似每个斯莱特函数——速度上的收益远超过多出来的函数数目。

::: example $\mathrm{H_2}$中的高斯乘积 {#ex-gpt}
$\alpha = \beta = 1.00\ a_0^{-2}$的两个s高斯函数位于$\mathrm{H_2}$的两个质子上，相距$R = 1.40\ a_0$。它们的乘积中心在哪里？指数是多少？前置因子$K_{AB}$是多少？
::: solution
$p = 2.00\ a_0^{-2}$，$\mathbf{P}$是键的中点（指数相等），而$K_{AB} = \exp\left[-(1 \times 1/2)(1.40)^{2}\right] = e^{-0.98} = 0.375$。这个乘积——正是堆积起成键电荷的重叠密度$\phi_\mathrm{A}\phi_\mathrm{B}$——是键正中间一个收缩的高斯函数。指数不等时，中心向较紧的函数移动。前置因子按$e^{-\mu R^{2}}$衰减，所以相距很远的高收缩函数之间的积分可以忽略——这就是积分筛选的基础。
:::
:::

### 单个高斯函数有多糟？

氢原子展示了形状不对的代价。对单个归一化s高斯函数$\phi = (2\alpha/\pi)^{3/4}e^{-\alpha r^{2}}$，期望值为$\langle T\rangle = 3\alpha/2$与$\langle V\rangle = -2\sqrt{2\alpha/\pi}$（以$\mathrm{E_h}$计），于是
$$
E(\alpha) = \frac{3\alpha}{2} - 2\sqrt{\frac{2\alpha}{\pi}} .
$$ {#eq-h-gaussian}

::: example 单个高斯函数下的氢原子 {#ex-h-one-gaussian}
最小化[[#eq-h-gaussian]]，并与精确值$-0.5\ \mathrm{E_h}$比较。
::: solution
$\mathrm{d}E/\mathrm{d}\alpha = \tfrac{3}{2} - \sqrt{2/\pi\alpha} = 0$得$\sqrt{\alpha} = \tfrac{2}{3}\sqrt{2/\pi}$，即$\alpha^{*} = 8/9\pi = 0.2829\ a_0^{-2}$。此时$\langle T\rangle = 4/3\pi$、$\langle V\rangle = -8/3\pi$（最优点处维里比$-V/T = 2$成立，这也必须成立），于是
$$
E^{*} = -\frac{4}{3\pi} = -0.4244\ \mathrm{E_h},
$$
比精确值高$0.0756\ \mathrm{E_h} = 2.06\ \mathrm{eV} = 198\ \mathrm{kJ\,mol^{-1}}$——误差$15\ \%$，来自尖点区（那里高斯函数的密度太小）与尾部（那里它衰减得太快）。然而这个高斯函数与精确$1s$函数的重叠达$0.978$：波函数看着几乎全对，只要它在势能集中的核附近是错的，能量就可能很差。
:::
:::

## 收缩高斯函数与极小基组

每个原子轨道用许多独立高斯函数会使基组庞大，而积分数目按四次方增长。折中之计是**收缩**。

::: definition 收缩高斯函数 {#def-contraction}
**收缩高斯型轨道函数**是同一中心、同一角部分的若干**原始**高斯函数的固定线性组合：
$$
\phi^\mathrm{CGTO}_\mu(\mathbf{r}) = \sum_{p=1}^{L} d_{p\mu}\,g_p(\alpha_{p\mu}, \mathbf{r}),
$$
收缩系数$d_{p\mu}$与指数$\alpha_{p\mu}$在设计基组时即已固定；自洽场中变分的只是收缩函数的系数$C_{\mu i}$。积分仍在原始函数上求值（费用随$L^{4}$增长），但变分函数数目$K$——以及由此决定的线性代数费用，对关联方法而言还有其余一切的费用——由收缩函数决定。
:::

最简单的收缩基组是**STO-$n$G**族（赫雷（Hehre）、斯图尔特（Stewart）与波普（Pople），1969）：每个斯莱特函数用$n$个高斯函数的最小二乘拟合代替。对指数$\zeta = 1$的$1s$斯莱特函数，STO-3G采用的指数为$0.109818$、$0.405771$与$2.22766\ a_0^{-2}$，系数为$0.444635$、$0.535328$与$0.154329$（乘以归一化原始函数）。由于对$e^{-\zeta r}$的高斯拟合与对$e^{-r}$的拟合之间只差$r$的缩放，其他任何$\zeta$的指数就是$\zeta = 1$的指数乘以$\zeta^{2}$。

::: example 需要多少个高斯函数？ {#ex-h-convergence}
表中给出用$n$个指数与系数*全部*经过优化的s高斯函数（未收缩）计算的氢原子能量，以及STO-$n$G值（其指数由对斯莱特函数的最小二乘拟合固定，而非能量最小化）。每加一个函数的误差是多少？这一比较说明了什么？

| $n$ | 优化$E/\mathrm{E_h}$ | 误差$/\mathrm{mE_h}$ | STO-$n$G $E/\mathrm{E_h}$ |
|---|---|---|---|
| $1$ | $-0.42441$ | $75.6$ | $-0.42422$ |
| $2$ | $-0.48581$ | $14.2$ | $-0.48116$ |
| $3$ | $-0.49698$ | $3.02$ | $-0.49491$ |
| $4$ | $-0.49928$ | $0.72$ | |
| $5$ | $-0.49981$ | $0.19$ | |
| $6$ | $-0.49995$ | $0.054$ | |
::: solution
每加一个高斯函数，误差缩小到约$1/4$–$1/5$（$75.6 \to 14.2 \to 3.0 \to 0.72 \to 0.19 \to 0.054\ \mathrm{mE_h}$）：大致是指数收敛，但按化学的标准算很慢，毕竟$1\ \mathrm{mE_h} = 2.6\ \mathrm{kJ\,mol^{-1}}$。即便用了六个高斯函数，一个氢原子的能量仍留有$0.14\ \mathrm{kJ\,mol^{-1}}$的误差，几乎全部来自尖点区。STO-3G比精确能量高$5.1\ \mathrm{mE_h}$（$13\ \mathrm{kJ\,mol^{-1}}$），比能量优化的三个高斯函数组更差，因为它的指数是为拟合斯莱特函数的*形状*而非使能量最小而选定的。在分子中，这些核心区误差在反应物与产物之间大体抵消，所以化学能容忍它们；但它们解释了为什么小基组给出的绝对能量很差。
:::
:::

**极小基组**对每个占据原子轨道只取一个收缩函数（对占据$2p$的元素取完整p组）：H与He一个函数，Li–Ne五个（$1s, 2s, 2p_x, 2p_y, 2p_z$）。用于分子计算时，斯莱特指数按分子优化：STO-3G中的氢取$\zeta = 1.24$而非原子中的$\zeta = 1$，因为轨道在成键时会收缩。这一选择把孤立原子的能量抬升到$-0.46658\ \mathrm{E_h}$——每个基组都内含此类妥协的一例。

## 价层分裂、极化函数与弥散函数

极小基组无法改变轨道的*大小*：氧的$2p$函数在$\mathrm{O_2}$中、在水中、在氢氧化物中都一模一样。三种加密办法可对此补救。

**价层分裂。**每个价轨道用两个（或三个）收缩函数描述，一紧一松；自洽场按成键需要混合二者，使轨道变大或变小。变化很小的内层轨道保留单个函数。例如在**6-31G**中，每个内层轨道是六个原始函数的一个收缩，每个价轨道则分裂为三个原始函数构成的内层收缩加一个外层原始函数。"双ζ"（DZ）与"三ζ"（TZ）指每个价轨道两个或三个函数。

**极化函数**是角动量高于该原子任何占据轨道的函数：碳或氧上的d函数，氢上的p函数。把p函数混入氢的s轨道会使其电荷中心沿键移动；把d混入p会使p瓣弯曲、极化。精确的几何（尤其是键角与氮的锥体形变程度）、$\mathrm{SF_6}$一类的超价分子，尤其是关联计算，都少不了极化函数。在波普记法中，6-31G*（即6-31G(d)）向重原子加d函数，6-31G**（6-31G(d,p)）则连氢也加p函数。

**弥散函数**是指数非常小、延伸到远离核处的s与p函数。电子密度束缚松的地方就需要它们：阴离子、激发态与里德伯（Rydberg）态、氢键受体、极化率与远程相互作用。波普的"+"（6-31+G*）把它们加在重原子上，"++"则连氢也加；邓宁（Dunning）的"aug-"前缀对已有的每种角动量各加一个弥散函数。

::: example 数一数基函数 {#ex-counting}
水分子在STO-3G、6-31G、6-31G*（笛卡儿d）与6-31G**中各有多少个收缩基函数？6-31G中又有多少个原始高斯函数？
::: solution
- STO-3G：O有$1s, 2s, 2p_{x,y,z}$共$5$个；每个H有$1$个；共$7$个。
- 6-31G：O有$1$个内层s$ + 2 \times$（$2s$ + 三个$2p$）= $9$；每个H有$2$个（$1s$分裂）；共$13$个。
- 6-31G*：在O上加六个笛卡儿d函数：$15 + 2 + 2 = 19$。
- 6-31G**：每个H加三个p函数：$19 + 6 = 25$。

6-31G中的原始函数：氧内层$6$个，内价层$4 \times 3 = 12$个（2s与2p共用指数），外价层$4$个，共$22$个；每个氢$3 + 1 = 4$个；分子共$30$个。从STO-3G到6-31G**，$K$乘以$25/7 = 3.6$，双电子积分数目约乘以$3.6^{4} \approx 160$。
:::
:::

::: warning 更大并不自动意味着更好，名称里还藏着差别 {#warn-basis}
三种误解很常见。其一，"更大"的基组对*给定方法*并不总是更好：哈特里-福克与DFT随基组大小收敛很快，超过三ζ几乎无利可图，而关联方法收敛极慢，把高等级关联方法配一个小基组（比如CCSD(T)/6-31G）会浪费该方法大部分的精度。其二，波普基组是为哈特里-福克优化的，并非为相关能的有系统收敛而设计；为此设计的是cc-pV$X$Z族。其三，记号里藏着约定：6-31G*在某些程序中默认用六个笛卡儿d函数，在另一些程序中用五个球面函数，给出的能量不同；"DZP"在不同论文里含义也不一。报告基组务必精确；与文献值比较时，要查清用的是哪些分量。
:::

## 相关一致基组与基组极限

为关联计算，邓宁1989年引入了**相关一致**基组cc-pV$X$Z（correlation-consistent polarised valence $X$-zeta，相关一致极化价层$X$ζ；基数$X$ = D、T、Q、5、6分别对应$2, 3, 4, 5, 6$）。其设计原则是：函数按壳层添加，每层贡献大致相当的相关能：碳的cc-pVDZ为$[3s2p1d]$；cc-pVTZ每种类型各加一个函数、再加一个更高角动量的函数，为$[4s3p2d1f]$；cc-pVQZ为$[5s4p3d2f1g]$。每一步都添上完整一层，于是能量随$X$平滑且*有系统地*收敛。

| 水分子 | cc-pVDZ | cc-pVTZ | cc-pVQZ | cc-pV5Z |
|---|---|---|---|---|
| 函数数（球面） | $24$ | $58$ | $115$ | $201$ |

相关能收敛缓慢，是因为精确波函数在两电子坐标上有一个**尖点**：两个电子靠近时，$\Psi$线性依赖于$r_{12}$（这是核尖点对电子-电子情形的类比），而光滑单电子函数的乘积只有靠高角动量才能表示这种折角。对氦原子与二阶微扰论的分析表明，角动量为$l$的函数对相关能的贡献按$(l + \tfrac{1}{2})^{-4}$衰减，所以截断在$l_\mathrm{max}$会留下正比于$l_\mathrm{max}^{-3}$的误差。在cc-pV$X$Z中$l_\mathrm{max}$随$X$增长，于是有下面的结论。

::: proposition 向完备基组极限的两点外推 {#prop-cbs}
若基数为$X$的基组中的相关能具有$E_X = E_\mathrm{CBS} + A\,X^{-3}$的形式，则由基数$X$与$Y$的两次计算即可定出极限：
$$
E_\mathrm{CBS} = \frac{X^{3}E_X - Y^{3}E_Y}{X^{3} - Y^{3}} .
$$
此式只用于*相关*能；哈特里-福克能量收敛更快（随$X$大致呈指数），通常直接取最大基组的值或另行外推。$X^{-3}$形式是渐近结果，只有对$X \geq 3$才可靠。
:::

::: proof
写$E_X = E_\mathrm{CBS} + A X^{-3}$与$E_Y = E_\mathrm{CBS} + A Y^{-3}$，第一式乘$X^{3}$、第二式乘$Y^{3}$：$X^{3}E_X = X^{3}E_\mathrm{CBS} + A$，$Y^{3}E_Y = Y^{3}E_\mathrm{CBS} + A$。两式相减消去$A$：$X^{3}E_X - Y^{3}E_Y = (X^{3} - Y^{3})E_\mathrm{CBS}$，即得结果。$X^{-3}$律本身来自$(l + \tfrac{1}{2})^{-4}$的分波增量：$\sum_{l > L}(l + \tfrac{1}{2})^{-4} \approx \int_{L}^{\infty}(l + \tfrac{1}{2})^{-4}\,\mathrm{d}l \approx \tfrac{1}{3}L^{-3}$，而cc-pV$X$Z中第一行原子的最高角动量恰为$l_\mathrm{max} = X$。
:::

::: example 外推相关能 {#ex-cbs}
设某小分子的价层相关能（量级与水在CCSD(T)水平的典型值相当）为$E_3 = -0.2850\ \mathrm{E_h}$（cc-pVTZ）与$E_4 = -0.2960\ \mathrm{E_h}$（cc-pVQZ）。估计CBS极限，并估计四ζ值的剩余误差。
::: solution
$$
E_\mathrm{CBS} = \frac{4^{3}(-0.2960) - 3^{3}(-0.2850)}{4^{3} - 3^{3}} = \frac{-18.944 + 7.695}{37} = -0.3040\ \mathrm{E_h}.
$$
四ζ值仍比极限高$8.0\ \mathrm{mE_h} = 21\ \mathrm{kJ\,mol^{-1}}$，且$A = (E_3 - E_\mathrm{CBS}) \times 27 = 0.514\ \mathrm{E_h}$。绝对相关能收敛得慢得令人痛苦；*相对*能量收敛更快，因为误差很大一部分来自每个核附近类内层的区域与近程尖点，而它们在反应中几乎不变。显式关联（F12）方法把$r_{12}$依赖直接写进波函数，用三ζ基组就能接近CBS结果。
:::
:::

## 基组叠加误差

有限大小的原子心基组还有一个对弱相互作用很重要的后果。在复合物$\mathrm{A\cdots B}$中，A的电子可以利用B的基函数来改善自身的描述，反之亦然。单独计算的单体则没有这种助力。于是相互作用能$\Delta E = E_\mathrm{AB} - E_\mathrm{A} - E_\mathrm{B}$偏负得太过——复合物被人为稳定化了。这就是**基组叠加误差**（basis-set superposition error, BSSE）。它在完备基组极限下消失，对小心基组与弱相互作用最大，此时可占结合能的很大比例。

::: algorithm 反叠加校正（counterpoise，博伊斯–贝尔纳迪） {#alg-counterpoise}
1. 优化或选定复合物AB的几何。
2. 计算$E_\mathrm{AB}^{\mathrm{AB}}$，即复合物在完整基组中的能量。
3. 在每个单体*在复合物中的*几何下、在完整二聚体基组中计算各单体：算$E_\mathrm{A}^{\mathrm{AB}}$时让B的基函数以**鬼函数**（无核也无电子的函数）身份在场，$E_\mathrm{B}^{\mathrm{AB}}$同理。
4. 反叠加校正后的相互作用能为$\Delta E^\mathrm{CP} = E_\mathrm{AB}^{\mathrm{AB}} - E_\mathrm{A}^{\mathrm{AB}} - E_\mathrm{B}^{\mathrm{AB}}$。
5. 若要的是相对*弛豫*单体的结合能，还需加上形变能：每个单体在复合物几何下的能量减去其在自身优化几何下的能量，两者都在单体基组中计算。
:::

::: example 氢键二聚体的反叠加校正 {#ex-bsse}
在一个用双ζ基组计算水二聚体的示例计算中，未校正的相互作用能为$-25.0\ \mathrm{kJ\,mol^{-1}}$。鬼函数在场时，给体单体的能量相对其在相同几何下用自身基组算得的能量降低$2.1\ \mathrm{kJ\,mol^{-1}}$，受体降低$1.6\ \mathrm{kJ\,mol^{-1}}$。问反叠加校正后的相互作用能是多少？
::: solution
BSSE就是单体在二聚体基组中能量的总降低，$2.1 + 1.6 = 3.7\ \mathrm{kJ\,mol^{-1}}$。校正后的相互作用能为$\Delta E^\mathrm{CP} = -25.0 + 3.7 = -21.3\ \mathrm{kJ\,mol^{-1}}$。双ζ基组下氢键$15\ \%$的校正量是典型值；对苯二聚体这类色散束缚的复合物，小基组下可超过$50\ \%$。有人认为反叠加校正*过度*校正，因为配对方的占据轨道在复合物中对本单体并不可用（泡利不相容），作为鬼函数却可用；实践中安全的选择是用大基组并施加校正，而且随基组增大，未校正值与校正值应当互相靠拢。
:::
:::

::: quiz
要计算氟离子与水分子的结合能，基组选择中最要紧的是什么？
- [ ] 相互作用是静电性的，极小基组就够了。
- [x] 弥散函数必不可少，因为阴离子的电子束缚很松；而且结果应当做反叠加校正，或直接在更大的基组中计算。
- [ ] 氟离子很小，只有内层函数重要。
- [ ] 只要用关联方法，基组选择就无关紧要。
::: solution
阴离子的外层电子束缚很松，其密度延伸到远离核处；没有弥散函数，阴离子就被描述得过于收缩、能量过高，从而破坏结合能。水的响应也需要极化函数，而且BSSE必须加以控制。
:::
:::

## 其他基组族与实用选择

波普与邓宁基组之外，广泛使用的还有：魏根德（Weigend）与阿尔里希斯（Ahlrichs）的**卡尔斯鲁厄**def2系列（def2-SVP、def2-TZVP、def2-QZVP，覆盖周期表大部分元素且彼此一致）；延森（Jensen）为DFT优化的**极化一致**pc-$n$基组；以及**有效核势**（ECP，赝势），它用拟合的势取代重原子的内层电子，既降低费用又内置了主要的标量相对论效应。对固体，自然的选择是**平面波**$e^{i\mathbf{k}\cdot\mathbf{r}}$：它不居于原子上（因此既无BSSE也无Pulay力），其品质由单一能量截断控制，并与赝势联用，因为要描述核尖点将需要极大的截断能。

分子计算的实用指南：

| 用途 | 合理的起步基组 |
|---|---|
| DFT几何与频率 | 筛选用def2-SVP或6-31G*；最终结构用def2-TZVP |
| DFT反应能 | def2-TZVP或更大，阴离子需弥散函数 |
| MP2或CCSD(T)能量 | cc-pVTZ与cc-pVQZ并做CBS外推，或三ζ配合F12方法 |
| 弱相互作用 | aug-cc-pVTZ或更大，并做反叠加校正 |
| 重元素（Kr以后） | def2系列及其配套ECP |

## 后续内容

基组收敛是一个反复出现的主题：关联方法（[[computational-chemistry/electron-correlation]]）需要的基组比哈特里-福克与DFT（[[computational-chemistry/density-functional-theory]]）大得多，而每种方法的费用都以基函数数目的幂次来表述。[[computational-chemistry/potential-energy-surfaces]]中提到的Pulay力，源于原子心基函数随核一起移动。对材料，平面波基组是标准选择（[[materials-chemistry]]）。

::: history
斯莱特1930年提出了他的简化解析原子轨道。1950年博伊斯证明高斯函数使一切分子积分都可以解析处理，现代几乎所有程序都建立在这一想法之上。赫雷、斯图尔特与波普1969年发表了STO-$n$G极小基组，随后是价层分裂的4-31G（1971）与6-31G（1972）；极化函数由哈里哈兰（Hariharan）与波普的6-31G*系列补上（1973），克里希南（Krishnan）、宾克利（Binkley）、西格（Seeger）与波普1980年发表了6-311G**。邓宁1989年引入相关一致的cc-pV$X$Z族，肯德尔（Kendall）、邓宁与哈里森（Harrison）1992年补上弥散增广系列。反叠加校正出自博伊斯与贝尔纳迪（Bernardi）（1970）。$X^{-3}$外推由黑尔加克（Helgaker）、克洛珀（Klopper）、科赫（Koch）与诺加（Noga）于1997年提出，其基础是施瓦茨（Schwartz）（1962）对氦的分波分析。
:::

::: summary
- 轨道在有限基组中展开；基组增大时，能量从上方逼近该方法的极限。
- 斯莱特函数有正确的尖点与衰减；高斯函数没有，但高斯乘积定理使一切积分解析可求，于是用收缩高斯函数仿似斯莱特函数。
- 单个高斯函数给出氢原子$-4/3\pi = -0.4244\ \mathrm{E_h}$；每加一个高斯函数，误差缩小约四倍。
- 价层分裂函数使轨道能变大小；极化函数（C、N、O上的d；H上的p）使轨道能变形状；弥散函数描述阴离子与弱相互作用。
- 由于电子-电子尖点，相关能收敛缓慢，在cc-pV$X$Z中按$X^{-3}$收敛；两点外推$E_\mathrm{CBS} = (X^{3}E_X - Y^{3}E_Y)/(X^{3} - Y^{3})$可估计极限。
- 基组叠加误差在有限基组中过度稳定复合物；博伊斯–贝尔纳迪反叠加校正用鬼函数计算单体。
- 基组要与方法和性质匹配，并且报告精确。
:::

cc-pVDZ在碳上有$[3s2p1d]$（14个球面函数），在氢上有$[2s1p]$（5个函数）。苯共有多少个基函数？（输入数值。）

::: exercise 最优的单个高斯函数 {level=2 check="0.2829"}
证明单个归一化s高斯函数下氢原子的能量$E(\alpha) = 3\alpha/2 - 2\sqrt{2\alpha/\pi}$在$\alpha^{*} = 8/9\pi$处取极小，并求其值。（以$a_0^{-2}$为单位、保留四位有效数字输入$\alpha^{*}$。）
::: solution
$E'(\alpha) = \tfrac{3}{2} - \sqrt{2/\pi}\,\alpha^{-1/2} = 0$得$\alpha^{1/2} = \tfrac{2}{3}\sqrt{2/\pi}$，所以$\alpha^{*} = \tfrac{4}{9} \times \tfrac{2}{\pi} = 8/9\pi = 0.2829\ a_0^{-2}$，且$E^{*} = 4/3\pi - 8/3\pi = -4/3\pi = -0.4244\ \mathrm{E_h}$。
:::

::: exercise 两点外推 {level=2 check="-0.3139"}
某分子在cc-pVTZ与cc-pVQZ下的MP2价层相关能分别为$-0.2783\ \mathrm{E_h}$与$-0.2989\ \mathrm{E_h}$。用$X^{-3}$公式估计CBS极限。（以$\mathrm{E_h}$为单位、保留四位小数输入$E_\mathrm{CBS}$。）
::: solution
$E_\mathrm{CBS} = [64(-0.2989) - 27(-0.2783)]/37 = (-19.1296 + 7.5141)/37 = -11.6155/37 = -0.3139\ \mathrm{E_h}$。
:::

::: exercise 反叠加校正的算术 {level=2 check="-14.6"}
中等基组下复合物AB的$E_\mathrm{AB}^{\mathrm{AB}} = -230.418\,62\ \mathrm{E_h}$、$E_\mathrm{A}^{\mathrm{AB}} = -154.732\,18\ \mathrm{E_h}$、$E_\mathrm{B}^{\mathrm{AB}} = -75.680\,88\ \mathrm{E_h}$（两单体各在其复合物几何下、含鬼函数计算）。计算反叠加校正后的相互作用能。（以$\mathrm{kJ\,mol^{-1}}$为单位、保留三位有效数字输入。）
::: solution
$\Delta E^\mathrm{CP} = -230.41862 - (-154.73218 - 75.68088) = -230.41862 + 230.41306 = -0.00556\ \mathrm{E_h}$，而$-0.00556 \times 2625.50\ \mathrm{kJ\,mol^{-1}} = -14.6\ \mathrm{kJ\,mol^{-1}}$。注意弱相互作用对总能量位数的要求：几个$\mathrm{kJ\,mol^{-1}}$的相互作用能是总值第六位有效数字上的差。
:::

::: exercise 推导单个高斯函数的能量 {level=3 check="-0.4244"}
对$\phi = (2\alpha/\pi)^{3/4}e^{-\alpha r^{2}}$，推导$\langle -\tfrac{1}{2}\nabla^{2}\rangle = 3\alpha/2$与$\langle -1/r\rangle = -2\sqrt{2\alpha/\pi}$，并由此得最小能量。验证最小点处的维里定理。（以$\mathrm{E_h}$为单位、保留四位小数输入$E^{*}$。）
::: hint
用$\int_0^{\infty}r^{2n}e^{-a r^{2}}\,\mathrm{d}r = \frac{(2n-1)!!}{2^{n+1}a^{n}}\sqrt{\pi/a}$与$\int_0^{\infty}r\,e^{-ar^{2}}\,\mathrm{d}r = 1/2a$。动能用$\langle T\rangle = \tfrac{1}{2}\int\lvert\nabla\phi\rvert^{2}\,\mathrm{d}\mathbf{r}$。
:::
::: solution
$\nabla\phi = -2\alpha\mathbf{r}\phi$，所以$\langle T\rangle = \tfrac{1}{2}\int 4\alpha^{2}r^{2}\phi^{2}\,\mathrm{d}\mathbf{r} = 2\alpha^{2}\langle r^{2}\rangle$。由$\phi^{2} = (2\alpha/\pi)^{3/2}e^{-2\alpha r^{2}}$（指数为$2\alpha$的高斯函数），$\langle r^{2}\rangle = 3/(2 \cdot 2\alpha) = 3/4\alpha$，故$\langle T\rangle = 3\alpha/2$。势能：$\langle 1/r\rangle = (2\alpha/\pi)^{3/2}\,4\pi\int_0^{\infty}r\,e^{-2\alpha r^{2}}\,\mathrm{d}r = (2\alpha/\pi)^{3/2}\,4\pi/(4\alpha) = 2\sqrt{2\alpha/\pi}$。最小化得$\alpha^{*} = 8/9\pi$，$\langle T\rangle = 4/3\pi$，$\langle V\rangle = -8/3\pi$，于是$\langle V\rangle = -2\langle T\rangle$（库仑势的维里定理），且$E^{*} = -4/3\pi = -0.4244\ \mathrm{E_h}$。
:::
:::

::: exercise 用s高斯函数做氦的哈特里-福克计算 {level=3 check="4.41"}
氦的哈特里-福克能量，用$n$个完全优化的s高斯函数时为$-2.30099$（$n = 1$）、$-2.74707$（$n = 2$）、$-2.83568$（$n = 3$）与$-2.85516\ \mathrm{E_h}$（$n = 4$）；哈特里-福克极限为$-2.86168\ \mathrm{E_h}$。计算$n = 2 \to 3$与$n = 3 \to 4$的误差以及相邻误差之比，并与氢（[[#ex-h-convergence]]）比较。这对"较重的原子为何需要内层更多原始函数的基组"有何提示？（输入$n = 2$与$n = 3$误差之比，保留三位有效数字。）
::: solution
误差：$0.56069$、$0.11461$、$0.02600$、$0.00652\ \mathrm{E_h}$。比值：$0.11461/0.02600 = 4.41$（要输入的数）与$0.02600/0.00652 = 3.99$。这些与氢的$4$–$5$倍很接近，但绝对误差大若干倍（单高斯氢的$0.0756\ \mathrm{E_h}$对上氦的$0.561\ \mathrm{E_h}$，达$7.4$倍），因为随核电荷增大，尖点变得更尖锐，而能量也更集中于核附近。因此对碳或氯原子，精确的内层需要六个以上的原始函数，这正是6-31G对内层用六个原始函数的原因；而化学发生的价层区域则给予更多*灵活性*（分裂收缩）而非更多原始函数。
:::
