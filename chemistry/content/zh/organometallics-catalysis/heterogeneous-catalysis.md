前面几章的均相催化剂是分子：每个金属原子都相同，每个配体都能命名，每个中间体原则上都能在溶液中观察到。世界上大部分催化并不这样工作。养活全世界约一半人口的氨在多孔铁上合成；汽油在沸石晶体上裂化；汽车尾气在分散于氧化铝上的铂、钯、铑纳米颗粒上净化；人造奶油、硫酸、甲醇、环氧乙烷与聚丙烯全部在固体上生产。在**多相催化**中，催化剂是另一个相——几乎总是固体——反应在它的表面上发生。固体易于与产物分离、耐高温，能在连续反应器中使用数年，工业界因此偏爱它。代价是活性位点难以看清：在真实催化剂上，只有一小部分且不断变化的表面原子在做功。

本章追问这些位点是什么、如何计量。动力学框架——吸附等温式、Langmuir–Hinshelwood 与 Eley–Rideal 机理、Sabatier 原理、转化频率与 Haber–Bosch 循环——已在[[kinetics/surface-kinetics]]中建立，本章在其上继续而不重复。这里考察金属表面活性位点的**结构**、**负载型**金属催化剂及其分散度的测定、使催化剂得以比较与设计的**描述符**（吸附能、d 带中心）、**沸石与氧化物**、多孔颗粒施加的**传质**极限，以及**表征**工作催化剂所用的手段。自始至终，我们把表面化学与本课程的分子金属有机化学接通：化学吸附的 CO、表面烷基与氢化物都是金属有机物种，许多表面反应不过是化了装的基元步骤。

## 金属表面的活性位点

金属表面并不均匀。密排面如 fcc(111) 由**平台**组成，其原子只有九个近邻，而不是体相的十二个；**台阶**露出七个近邻的原子；台阶中的**扭结**与孤立的**吸附原子**近邻更少。泰勒（Hugh Taylor）1925 年提出，催化发生在少数特殊的"活性中心"上；表面科学使这一想法精确化：低配位原子结合吸附质更强（未饱和的价更多），而且常常提供几何合适的原子集团来断裂某个键。例如，N₂ 在钌上的解离几乎只发生在台阶位点，五个金属原子能在 N≡N 键拉长时结合两个氮原子。

::: definition 结构敏感性 {#def-structure-sensitivity}
若一个催化反应的转化频率（每个表面金属原子的速率，[[kinetics/surface-kinetics]]）几乎不依赖于颗粒大小与暴露的晶面，则它是**结构不敏感**的；若 TOF 随它们强烈变化，则它是**结构敏感**的。这一区分是经验性的，由布达尔（Michel Boudart）在 1960 年代引入。铂上烯烃加氢是经典的结构不敏感反应（活性位点由吸附层自身形成，在任何晶面上都差不多）；铁上合成氨以及一般的 N₂ 或 CO 解离则强烈结构敏感。Somorjai 课题组在铁单晶上发现，(111)、(100) 与 (110) 面的合成氨速率之比为 $418 : 25 : 1$（1982 年）：开放的 (111) 面露出七配位铁原子，密排的 (110) 面只有八配位的。
:::

结构敏感性之所以要紧，是因为各类位点的比例取决于颗粒大小。几纳米的金属颗粒有很大一部分原子落在棱与角上；20 nm 的颗粒则几乎全是平台。对结构敏感反应，"最佳"颗粒大小是一个需要寻找的最优值，这也是催化剂的活性会在数月使用中随颗粒烧结长大而改变的原因。

## 负载型金属催化剂与分散度

贵金属昂贵，而只有表面原子能做功，所以催化剂把金属铺成纳米颗粒分散在高比表面的**载体**上——氧化铝、二氧化硅、二氧化钛、碳、氧化铈——典型负载量为质量 $0.1$–$5\ \%$。载体可以不只是惰性支架：它能稳定颗粒防止烧结、提供酸性或储氧位点，并与金属发生电子相互作用（陶斯特（Samuel Tauster）1978 年在二氧化钛负载金属上描述的"强金属-载体相互作用"——被还原的氧化物层爬过金属表面，抑制 H₂ 与 CO 的化学吸附）。

::: definition 分散度 {#def-dispersion}
负载金属的**分散度** $D$ 是处于表面的金属原子所占的分数，
$$
D = \frac{N_\text{surface}}{N_\text{total}}, \qquad 0 < D \le 1.
$$
用**选择性化学吸附**测定：探针分子只吸附在金属上而不吸附在载体上，并假定化学计量——氢在 Pt、Pd、Ni、Rh 上解离，通常取每个表面金属原子一个 H 原子（$\mathrm{H/M_s} = 1$）；CO 通常线性配位，约每个表面原子一个，不过桥式配位使化学计量不那么确定。于是 $D = (\text{吸附的 H 原子摩尔数})/(\text{金属摩尔数})$。
:::

::: proposition 分散度与颗粒大小 {#prop-dispersion-size}
对直径 $d$ 的金属颗粒（近似为球，或视为一个面贴住载体、五个面外露的立方体），原子体积为 $v_m$、每个表面原子平均面积为 $a_m$，
$$
D = \frac{6\,v_m}{a_m\,d}.
$$ {#eq-dispersion}
对铂（$M = 195.08\ \mathrm{g\,mol^{-1}}$、$\rho = 21.45\ \mathrm{g\,cm^{-3}}$、$a_m = 8.07\ \text{Å}^2$），得 $D \approx 1.12/(d/\mathrm{nm})$。这一关系适用于 $d$ 大于约 $1.5\ \mathrm{nm}$；对更小的团簇，$D$ 趋近 1，连续介质图像失效。
:::

::: proof
直径 $d$ 的球体积为 $\pi d^3/6$，表面积为 $\pi d^2$。原子总数 = 体积除以原子体积，$N_\text{total} = \pi d^3/(6v_m)$；表面原子数 = 面积除以每个表面原子的面积，$N_\text{surface} = \pi d^2/a_m$。两者之比为
$$
D = \frac{\pi d^2/a_m}{\pi d^3/(6v_m)} = \frac{6v_m}{a_m d}.
$$
棱长 $d$、一个面贴着载体的立方体露出五个面、面积 $5d^2$，含 $d^3/v_m$ 个原子；两者之比为 $5v_m/(a_m d)$，与同一形式相近；按惯用的"等效"直径选法，通常保留因子 6。对铂，$v_m = M/(\rho N_\mathrm{A}) = 195.08/(21.45 \times 6.022\times10^{23})\ \mathrm{cm^3} = 1.510\times10^{-23}\ \mathrm{cm^3} = 15.10\ \text{Å}^3$，所以 $D = 6 \times 15.10/(8.07\,d/\text{Å}) = 11.2/(d/\text{Å}) = 1.12/(d/\mathrm{nm})$。$\blacksquare$
:::

::: example 由化学吸附求分散度与转化频率 {#ex-chemisorption}
某 $1.00\,\%$（质量）$\mathrm{Pt/Al_2O_3}$ 催化剂每克吸附 $20.0\ \mu\mathrm{mol}$ 的 $\mathrm{H_2}$（扣除载体吸附后的不可逆吸附量）。(a) 设 $\mathrm{H/Pt_s} = 1$，求分散度与平均颗粒直径。(b) 在某测试反应中，该催化剂每克每秒转化 $5.0\ \mu\mathrm{mol}$ 底物。TOF 是多少？
::: solution
(a) 每克含铂：$0.0100\ \mathrm{g}/195.08\ \mathrm{g\,mol^{-1}} = 51.3\ \mu\mathrm{mol}$。吸附的氢**原子**：$2 \times 20.0 = 40.0\ \mu\mathrm{mol}$，等于表面 Pt 原子数。于是
$$
D = \frac{40.0}{51.3} = 0.780, \qquad d = \frac{1.12\ \mathrm{nm}}{0.780} = 1.44\ \mathrm{nm}.
$$
(b) TOF 是每个表面位点的速率：$\mathrm{TOF} = 5.0\ \mu\mathrm{mol\,s^{-1}\,g^{-1}}/40.0\ \mu\mathrm{mol\,g^{-1}} = 0.125\ \mathrm{s^{-1}}$。看看这个数值携带了多少假设：H/Pt 化学计量、每个表面原子同样活泼、载体不吸附任何东西。对结构敏感反应，"每个表面原子"的 TOF 是把活性极不相同的位点取平均，两个 TOF 相同的催化剂可能有完全不同的活性位点。
:::
:::

## 描述符：为何某些金属比另一些更好

Sabatier 原理（[[kinetics/surface-kinetics]]）说：好的催化剂结合关键中间体既不能太弱（无法活化），也不能太强（表面被自己的中间体中毒）。两个经验关系把这个想法变成数字。

第一个是 **Brønsted–Evans–Polanyi（BEP）关系**：对一族相似的表面反应——比如 N₂ 在不同金属上的解离——活化能随反应能线性变化，$E_\mathrm{a} = E_0 + \alpha\,\Delta E$，$0 < \alpha < 1$。第二个是**标度关系**的观察：相关物种（N、NH、NH₂；C、CH、CH₂、CH₃）的吸附能在不同金属之间互为线性函数，所以单个**描述符**——往往是一个原子的吸附能——就能预言所有吸附能。这些规律主要由诺斯科夫（Jens Nørskov）课题组 1990 与 2000 年代的大量密度泛函计算确立（[[computational-chemistry/density-functional-theory]]）。

::: proposition 由 BEP 关系得到的 Sabatier 火山 {#prop-volcano}
考虑一个在表面上有两步连续反应的催化反应：反应物活化为吸附中间体，活化能由 BEP 关系给出 $E_1 = E_0 + \alpha\,\Delta E$（$\Delta E < 0$ 为中间体的吸附能，越负表示结合越强）；以及中间体的移除，活化能 $E_2 = -\Delta E$（吸附物种的脱附或反应，假定其随结合强度成标度）。若总速率由较慢的一步限制，且公共指前因子为 $\nu$，则
$$
\ln\frac{r}{\nu} = \frac{1}{RT}\min\!\left(\Delta E,\ -E_0 - \alpha\,\Delta E\right),
$$ {#eq-volcano}
呈"火山"形，最大值位于最优结合能 $\Delta E^* = -E_0/(1+\alpha)$。
:::

::: proof
两步的速率分别为 $r_1 = \nu e^{-E_1/RT}$ 与 $r_2 = \nu e^{-E_2/RT}$。串联步骤中一步远慢于另一步时，总速率近似为较慢者的速率，$r = \min(r_1, r_2)$。取对数，$\ln(r/\nu) = \min(-E_1, -E_2)/RT = \min(-E_0 - \alpha\Delta E,\ \Delta E)/RT$。弱结合（$\Delta E$ 接近零）时第一个自变量较小：活化限制速率，且随结合变强而改善（对 $\Delta E$ 的斜率为 $-\alpha/RT$，即 $\Delta E$ 越负速率越高）。强结合时第二个较小：移除限制速率，随结合变强而下降（斜率 $1/RT$）。两条直线交于 $\Delta E = -E_0 - \alpha\Delta E$，即 $\Delta E^* = -E_0/(1 + \alpha)$，火山之巅。真实的火山顶部圆滑，因为两步在顶部都有贡献，覆盖度效应也会移动直线，但直线分支与最优点的存在只由这两条假设得出。$\blacksquare$
:::

::: example 朝火山顶端设计 {#ex-volcano}
对服从[[#prop-volcano]]、$E_0 = 100\ \mathrm{kJ\,mol^{-1}}$、$\alpha = 0.50$、$500\ \mathrm{K}$ 的反应：(a) 求最优吸附能；(b) 把 $\Delta E = -40\ \mathrm{kJ\,mol^{-1}}$ 的金属与 $\Delta E = -100\ \mathrm{kJ\,mol^{-1}}$ 的金属的速率同最优点处的速率比较。
::: solution
(a) $\Delta E^* = -E_0/(1+\alpha) = -100/1.50 = -66.7\ \mathrm{kJ\,mol^{-1}}$。在最优点，两个能垒都等于 $66.7\ \mathrm{kJ\,mol^{-1}}$。

(b) $RT = 4.157\ \mathrm{kJ\,mol^{-1}}$。$\Delta E = -40$ 时：活化能垒 $E_1 = 100 - 0.50 \times 40 = 80\ \mathrm{kJ\,mol^{-1}}$，移除能垒 $40$；较慢一步的能垒为 $80$，故 $r/r^* = e^{-(80 - 66.7)/4.157} = e^{-3.21} = 0.040$。$\Delta E = -100$ 时：$E_1 = 50$，$E_2 = 100$；较慢一步的能垒为 $100$，故 $r/r^* = e^{-(100 - 66.7)/4.157} = e^{-8.02} = 3.3\times10^{-4}$。结合过强 $33\ \mathrm{kJ\,mol^{-1}}$ 的代价大于结合过弱 $27\ \mathrm{kJ\,mol^{-1}}$，因为强结合支更陡（斜率 $1$ 对 $\alpha = 0.5$）。把强结合金属与弱结合金属做成合金，使其吸附能移向最优点，是标准的设计策略——例如用于合成氨的钴钼氮化物，尽管两种纯金属都不在顶部附近，它却坐落在顶部附近。
:::
:::

金属为何在结合强度上互不相同？哈默（Bjørk Hammer）与诺斯科夫的 **d 带模型**（1995 年）主要归因于金属 $d$ 态相对费米能级的能量。吸附质的轨道与窄的金属 $d$ 带相互作用，形成成键与反键态；d 带中心越高，反键态越高、其中被填充的越少，结合就越强。沿过渡系向左移动抬高 d 带中心、增强结合（W、Mo 极强烈地结合 N 与 O），向右移动则降低；而金——$d$ 带已满且深居费米能级之下，反键的吸附质态被填满——几乎什么都不结合，是最"贵族"的金属。应变、合金化与低配位数都会移动 d 带中心，从而调节反应性。该模型是[[organometallics-catalysis/ligands-complexes]]中协同成键的表面类比：金属表面化学吸附的 CO 靠 σ 给予与 π 反馈结合，与羰基配合物完全一样；其红外伸缩振动波数从顶位到桥位再到空穴位的下降，正对应端基、$\mu_2$ 到 $\mu_3$ 羰基的下降。

## 沸石与氧化物

**沸石**是结晶铝硅酸盐，其共顶角 $\mathrm{SiO_4}$ 与 $\mathrm{AlO_4}$ 四面体骨架围出分子尺寸的孔道与笼（[[main-group/groups-13-14]]、[[materials-chemistry/porous-materials]]）。骨架中每个铝带一个负电荷；当这一电荷由质子平衡时，桥式羟基 $\mathrm{Si{-}O(H){-}Al}$ 就是一个**布朗斯特酸位**，强度与浓硫酸相当。沸石是流化催化裂化（沸石 Y，1960 年代初）、异构化与烷基化、以及甲醇制烃化学（ZSM-5，Mobil 1972 年专利）所用的酸催化剂。

它们独特的性质是**择形选择性**。只有小到能进入孔道的分子才接触得到酸位（反应物择形）；只有小到能离开的产物才逃得出来（产物择形）；对腔体来说太笨重的过渡态被抑制（过渡态择形）。ZSM-5 的孔道约 $0.55\ \mathrm{nm}$ 宽；在甲苯烷基化中它主要生成细长的 1,4-二甲苯（对二甲苯），因为*邻*位与*间*位异构体扩散出去慢得多，在晶体内部逃脱之前先被异构化了。

::: example H-ZSM-5 的酸位密度 {#ex-zsm5}
ZSM-5 的晶胞含 $96$ 个四面体（T）原子与 $192$ 个氧原子。对 $\mathrm{Si/Al} = 25$ 的质子型，求每个晶胞的 Al 数、晶胞 $\mathrm{H_nAl_nSi_{96-n}O_{192}}$ 的摩尔质量，以及布朗斯特酸位的理论密度（$\mathrm{mmol\,g^{-1}}$）。
::: solution
由 $\mathrm{Si/Al} = 25$，$n_\mathrm{Si} = 25\,n_\mathrm{Al}$ 且 $n_\mathrm{Si} + n_\mathrm{Al} = 96$，故每晶胞 $n = n_\mathrm{Al} = 96/26 = 3.69$。摩尔质量：
$$
M = 3.69\,(1.008 + 26.982) + (96 - 3.69)(28.085) + 192\,(15.999) = 103.3 + 2592.6 + 3071.8 = 5768\ \mathrm{g\,mol^{-1}}.
$$
每个 Al 一个质子，给出每 $5768\ \mathrm{g}$ $3.69\ \mathrm{mol}$ 酸位：
$$
\frac{3.69}{5768}\ \mathrm{mol\,g^{-1}} = 6.40\times10^{-4}\ \mathrm{mol\,g^{-1}} = 0.640\ \mathrm{mmol\,g^{-1}}.
$$
实测值（氨程序升温脱附或胺滴定）通常略低，因为部分铝位于骨架之外，部分质子在焙烧中流失。提高 Si/Al 会减少酸位数目，但使每个酸位稍强，骨架也更疏水、更稳定。
:::
:::

**金属氧化物**按马尔斯（Pieter Mars）与范克雷维伦（Dirk van Krevelen）1954 年最早提出的机理催化氧化：底物被氧化物的**晶格氧**氧化，留下还原位（氧空位与低价金属阳离子），随后气相 $\mathrm{O_2}$ 把该位重新氧化。两个半反应发生在不同地点，可用同位素标记的 $^{18}\mathrm{O_2}$ 分别研究：产物中先出现晶格 $^{16}\mathrm{O}$。接触法制硫酸中的五氧化二钒（$\mathrm{SO_2 \rightarrow SO_3}$；严格说工作条件下是熔盐催化剂）、丙烯氧化与氨氧化中的钼酸铋，以及汽油车**三效催化剂**中负责储氧的氧化铈，都按这种方式工作。三效催化剂在氧化铝-氧化铈涂层上的 Pt、Pd 与 Rh 上同时氧化 CO 与烃并还原 NO，但只在化学计量空燃比附近的狭窄窗口内；$\mathrm{Ce^{4+}/Ce^{3+}}$ 的可逆氧化还原通过储存与释放氧气来加宽这个窗口。

::: warning 催化剂并非原封不动 {#warn-catalyst-change}
"催化剂不被消耗"这一定义只对*总*反应成立，对催化剂的*结构*并不成立。在反应条件下，金属颗粒会重塑、晶面化、烧结，有时溶解再形成；表面被吸附质、积碳（"coke"）与氧化物覆盖；助剂迁移；氧化物部分还原；沸石失去骨架铝。在真空腔里或从反应器取出后表征的催化剂，可能与工作时的催化剂毫不相像。表面科学与实践之间的这种"压力鸿沟"与"材料鸿沟"，正是现代催化剂研究强调**原位**（in situ）与**操作态**（operando）表征——在催化剂以真实的温度与压力周转时同步测量其结构——的原因，也正是催化剂*失活*（烧结、硫中毒、积碳）与活性同等重要的原因。
:::

## 颗粒内部的传质

工业催化剂是几毫米大的多孔颗粒或挤条，活性表面大部分在孔*内*。反应物必须扩散进来、产物扩散出去；若本征反应比扩散快，内部就会反应物不足，只有外壳在起作用。

::: proposition 西勒模数与有效因子 {#prop-thiele}
对恒温一级反应，速率常数为 $k$（以单位颗粒体积计），半厚度为 $L$ 的平板状颗粒，孔内有效扩散系数 $D_\text{eff}$，外表面浓度 $c_s$，稳态浓度分布为 $c(x) = c_s\cosh(\phi x/L)/\cosh\phi$，其中
$$
\phi = L\sqrt{\frac{k}{D_\text{eff}}}
$$
为**西勒（Thiele）模数**，而**有效因子**——实际速率与整个颗粒都处于 $c_s$ 时的速率之比——为
$$
\eta = \frac{\tanh\phi}{\phi}.
$$ {#eq-thiele}
$\phi \ll 1$ 时 $\eta \to 1$（动力学控制）；$\phi \gg 1$ 时 $\eta \to 1/\phi$（强扩散限制）。对半径 $R$、$\phi = R\sqrt{k/D_\text{eff}}$ 的球，结果为 $\eta = (3/\phi^2)(\phi\coth\phi - 1)$。
:::

::: proof
在距中心 $x$ 处取平板的薄片，扩散进入减去扩散离开等于反应消耗。用 Fick 定律，稳态下得
$$
D_\text{eff}\frac{\mathrm{d}^2c}{\mathrm{d}x^2} = kc,
$$
边界条件为表面处 $c(L) = c_s$，中心处 $\mathrm{d}c/\mathrm{d}x = 0$（对称）。通解为 $c = A\cosh(x\sqrt{k/D_\text{eff}}) + B\sinh(x\sqrt{k/D_\text{eff}})$；对称条件定出 $B = 0$，表面条件定出 $A = c_s/\cosh\phi$。单位平板表面积的总速率等于经表面扩散进入的通量：
$$
r_\text{obs} = D_\text{eff}\left.\frac{\mathrm{d}c}{\mathrm{d}x}\right|_{x = L} = D_\text{eff}\,\frac{c_s\phi}{L}\tanh\phi.
$$
若无扩散限制，半板的速率应为 $kc_sL$。两者之比为
$$
\eta = \frac{D_\text{eff}c_s\phi\tanh\phi/L}{kc_sL} = \frac{\phi\tanh\phi}{kL^2/D_\text{eff}} = \frac{\phi\tanh\phi}{\phi^2} = \frac{\tanh\phi}{\phi}.
$$
两个极限由小 $\phi$ 时 $\tanh\phi \approx \phi$、大 $\phi$ 时 $\tanh\phi \to 1$ 得出。球形结果来自同一衡算在球坐标下的写法 $D_\text{eff}\,r^{-2}(r^2c')' = kc$，其在原点正则的解为 $c \propto \sinh(\phi r/R)/r$。这一分析出自西勒（Ernest Thiele，1939 年），假定恒温条件与一级动力学。$\blacksquare$
:::

::: example 反应受扩散限制吗？ {#ex-thiele}
某一级反应的本征速率常数 $k = 10\ \mathrm{s^{-1}}$（以单位颗粒体积计），孔内有效扩散系数 $1.0\times10^{-7}\ \mathrm{m^2\,s^{-1}}$。对半厚度 $1.0\ \mathrm{mm}$ 与 $0.10\ \mathrm{mm}$ 的平板颗粒，计算 $\phi$ 与 $\eta$。强限制区下表观活化能会怎样？
::: solution
$\sqrt{k/D_\text{eff}} = \sqrt{10/1.0\times10^{-7}}\ \mathrm{m^{-1}} = 1.0\times10^{4}\ \mathrm{m^{-1}}$。
$L = 1.0\ \mathrm{mm}$ 时：$\phi = (1.0\times10^{-3})(1.0\times10^{4}) = 10$，$\eta = \tanh 10/10 = 0.100$：催化剂的潜力只用了十分之一。
$L = 0.10\ \mathrm{mm}$ 时：$\phi = 1.0$，$\eta = \tanh 1.0/1.0 = 0.762$。
强扩散限制区内，$r_\text{obs} = \eta k c_s \approx (1/\phi)kc_s \propto \sqrt{kD_\text{eff}}$。$k$ 服从阿伦尼乌斯、活化能为 $E_\mathrm{a}$，而 $D_\text{eff}$ 随温度变化很弱，所以表观活化能约为 $E_\mathrm{a}/2$。实测活化能在较高温度（那里 $k$、亦即 $\phi$ 变大）减半，是孔扩散限制的经典诊断判据；速率依赖于颗粒大小同样是判据。本征动力学必须在压碎的催化剂上测定，那里的 $\phi$ 很小。
:::
:::

## 如何表征工作中的催化剂

没有任何单一手段能"看见"活性位点；催化剂化学家组合多种手段，各回答一个不同的问题。

| 问题 | 方法 | 能给出什么 |
|---|---|---|
| 有多少表面？ | $\mathrm{N_2}$ 物理吸附（BET，[[kinetics/surface-kinetics]]） | 总比表面积、孔体积与孔径分布 |
| 有多少*金属*表面？ | $\mathrm{H_2}$、CO 或 $\mathrm{N_2O}$ 化学吸附 | 分散度、金属面积（[[#ex-chemisorption]]） |
| 什么物相、多大颗粒？ | X射线衍射、Scherrer 分析；电子显微镜（TEM、STEM） | 结晶物相；晶粒尺寸；颗粒尺寸分布与形状 |
| 什么氧化态、什么近邻？ | X射线光电子能谱（XPS）；X射线吸收（XANES、EXAFS） | 表面组成与氧化态；配位数与键长，亦可在操作态（*operando*）下测定 |
| 吸附了什么、在哪里？ | CO 或吡啶的红外光谱；程序升温脱附（TPD）、程序升温还原（TPR） | 结合位点（顶位对桥式 CO）；布朗斯特对路易斯酸位（吡啶鎓带约 $1545\ \mathrm{cm^{-1}}$，路易斯结合吡啶约 $1450\ \mathrm{cm^{-1}}$）；位点强度分布；可还原性 |
| 表面长什么样？ | 扫描隧道显微镜、模型单晶上的 LEED | 平台、台阶、吸附层的原子结构 |

**Scherrer 公式**用衍射峰的宽化估计平均晶粒尺寸（[[materials-chemistry/diffraction]]）：$\tau = K\lambda/(\beta\cos\theta)$，其中 $\lambda$ 为 X射线波长，$\beta$ 为峰宽（扣除仪器宽化后的半高全宽，以弧度计），$\theta$ 为布拉格角，$K \approx 0.9$ 为形状因子。

::: example 由 XRD 测晶粒尺寸 {#ex-scherrer}
某负载铂催化剂的 Pt(111) 反射用 Cu Kα 辐射（$\lambda = 0.15406\ \mathrm{nm}$）测得，出现在 $2\theta = 39.8^\circ$，校正后的宽度为 $0.80^\circ$。取 $K = 0.9$ 估算晶粒尺寸，并与[[#ex-chemisorption]]中另一个样品 $1.44\ \mathrm{nm}$ 的化学吸附估计比较。同一份样品上两种方法为何可能不一致？
::: solution
把宽度化为弧度：$\beta = 0.80 \times \pi/180 = 0.01396\ \mathrm{rad}$。以 $\theta = 19.9^\circ$，$\cos\theta = 0.9403$：
$$
\tau = \frac{0.9 \times 0.15406\ \mathrm{nm}}{0.01396 \times 0.9403} = 10.6\ \mathrm{nm}.
$$
这个样品的晶粒大得多（分散度约 $1.12/10.6 \approx 0.11$）。在*同一*份样品上，两种方法常常不一致，因为它们对颗粒的加权不同：XRD 只看得到大到足以产生衍射峰的晶域（约 $2\ \mathrm{nm}$ 以下的颗粒几乎不可见），给出由最大晶粒主导的体积加权平均；化学吸附数的是表面原子，由最小的颗粒主导。宽的粒度分布、非晶颗粒、或一个颗粒由多个晶域构成，都会造成分歧。逐个测量颗粒的 TEM 用来调和两者。
:::
:::

::: quiz
某催化剂的每克活性在颗粒从 3 mm 压碎到 0.3 mm 时加倍，再继续压碎到 0.1 mm 时不再变化。这说明什么？
- [x] 3 mm 颗粒受孔扩散限制；0.3 mm 时有效因子已接近 1，测得的是本征动力学。
- [ ] 压碎创造了新的活性位点，所以 0.1 mm 粉末应该更活泼。
- [ ] 该反应是结构不敏感的。
- [ ] 所有尺寸下反应都受外部传热限制。
::: solution
速率依赖于颗粒尺寸，说明存在内扩散传质限制（[[#prop-thiele]]）；速率一旦与尺寸无关，$\phi$ 已很小、$\eta \approx 1$。压碎不会显著改变比表面积（比表面积几乎全在孔内），所以"新位点"不是解释。结构敏感性说的是位点的原子本性，不是颗粒尺寸。
:::
:::

## 后续内容

本章把分子金属有机化学与承担大部分工业催化的固体连接起来，为课程收尾。表面反应的动力学、Langmuir 与 BET 等温式、Sabatier 原理与 Haber–Bosch 法见[[kinetics/surface-kinetics]]；沸石与其他多孔固体的结构见[[materials-chemistry/porous-materials]]；固体的衍射与电子结构见[[materials-chemistry/diffraction]]与[[materials-chemistry/electronic-structure-solids]]；密度泛函描述符见[[computational-chemistry/density-functional-theory]]。化学工业中的多相催化——氨、硫酸、甲醇、裂化与重整——在[[green-chemistry/industrial-inorganic]]与[[green-chemistry/petrochemicals]]中综述；能源催化（燃料电池、电解池）见[[electrochemistry/fuel-cells-electrolysis]]。两个世界之间的桥梁正在生长：单原子催化剂、金属有机框架与表面金属有机化学把结构明确的分子位点接到固体载体上，追求均相催化剂的选择性与固体的稳健兼得。

::: history
1823 年德贝赖纳（Döbereiner）的灯——氢气在铂棉上被点燃——是多相催化的第一次实际应用，贝采里乌斯（Berzelius）于 1835 年创造了"催化"（*catalysis*）一词。萨巴蒂埃（Paul Sabatier）与桑德雷恩斯（Jean-Baptiste Senderens）1897 年发现镍催化加氢，萨巴蒂埃分享了 1912 年诺贝尔奖；诺曼（Wilhelm Normann）的油脂加氢硬化（1902 年）与哈伯-博施（Haber–Bosch）合成氨工艺（1913 年起在巴斯夫奥保（Oppau）工厂投产）使表面催化成为工业。朗缪尔（Irving Langmuir）的吸附研究（1915–18）为他赢得 1932 年诺贝尔奖，泰勒于 1925 年提出活性中心，堀田（Juro Horiuti）与波兰尼（Michael Polanyi）于 1934 年提出他们的加氢机理，胡德里（Eugene Houdry）的催化裂化于 1937 年投产。西勒于 1939 年分析了孔扩散；马尔斯与范克雷维伦于 1954 年描述了晶格氧的氧化；沸石裂化催化剂于 1960 年代初问世，ZSM-5 于 1972 年获专利。陶斯特于 1978 年报道了强金属-载体相互作用，哈默与诺斯科夫于 1995 年提出 d 带模型，埃特尔（Gerhard Ertl）因对固体表面化学过程的表面科学研究——包括合成氨与 CO 氧化——获得 2007 年诺贝尔奖。
:::

::: summary
- 多相催化剂在表面上工作；低配位原子（台阶、扭结、棱边）常常是活性位点，结构敏感反应（N₂ 解离、NH₃ 合成：Fe(111) : (100) : (110) ≈ 418 : 25 : 1）强烈依赖于暴露了哪些位点。
- 负载型催化剂把金属铺成纳米颗粒；分散度 $D = N_\text{surface}/N_\text{total}$ 由选择性化学吸附测定，与尺寸的关系为 $D = 6v_m/(a_md)$（对 Pt 约 $1.12/d_\mathrm{nm}$）。TOF 是每个表面位点的速率。
- BEP 关系与标度关系使一个吸附能充当描述符；一侧受活化限制、另一侧受产物移除限制的速率给出 Sabatier 火山，最优点 $\Delta E^* = -E_0/(1+\alpha)$。d 带中心解释了结合强度的趋势。
- 沸石是具择形选择性的固体酸（桥式 Si–O(H)–Al 位点；酸密度由 Si/Al 决定）；氧化物按 Mars–van Krevelen 机理用晶格氧进行氧化。
- 多孔颗粒中，$\phi = L\sqrt{k/D_\text{eff}}$，$\eta = \tanh\phi/\phi$（平板）；强扩散限制给出 $\eta \approx 1/\phi$、依赖尺寸的速率与减半的表观活化能。
- 表征手段组合物理吸附、化学吸附、XRD（Scherrer）、电子显微镜、XPS、X射线吸收、探针分子红外与程序升温方法——最好在*操作态*下进行，因为工作催化剂在变化。
:::

某衍射峰位于 $2\theta = 39.8^\circ$，用 $\lambda = 0.15406\ \mathrm{nm}$ 测得，校正后宽度 $0.80^\circ$。取 $K = 0.9$ 估算晶粒尺寸。（尺寸以 nm 输入，保留三位有效数字。）

$\tau = 0.9 \times 0.15406/(0.01396 \times \cos 19.9^\circ) = 0.13865/(0.01396 \times 0.9403) = 10.6\ \mathrm{nm}$（[[#ex-scherrer]]）。

::: exercise 高硅沸石的酸位 {level=2 check="0.406"}
计算 $\mathrm{Si/Al} = 40$ 的 H-ZSM-5 的理论布朗斯特酸位密度（每晶胞 96 个 T 原子与 192 个 O 原子；原子量 H 1.008、Al 26.982、Si 28.085、O 15.999）。（密度以 $\mathrm{mmol\,g^{-1}}$ 输入，保留三位有效数字。）
::: solution
每晶胞 $n_\mathrm{Al} = 96/41 = 2.341$。$M = 2.341(1.008 + 26.982) + 93.659(28.085) + 192(15.999) = 65.5 + 2630.4 + 3071.8 = 5767.7\ \mathrm{g\,mol^{-1}}$。密度 $= 2.341/5767.7\ \mathrm{mol\,g^{-1}} = 4.06\times10^{-4}\ \mathrm{mol\,g^{-1}} = 0.406\ \mathrm{mmol\,g^{-1}}$。（晶胞质量几乎不随 Si/Al 改变，因为 Al + H 与 Si 的质量几乎相同。）
:::

::: exercise 火山的最优点 {level=2 check="-62.5"}
对服从[[#prop-volcano]]、$E_0 = 100\ \mathrm{kJ\,mol^{-1}}$、$\alpha = 0.60$ 的反应，求中间体的最优吸附能。（$\Delta E^*$ 以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
$\Delta E^* = -E_0/(1 + \alpha) = -100/1.60 = -62.5\ \mathrm{kJ\,mol^{-1}}$。更大的 $\alpha$（活化的过渡态"更晚"）把最优点推向更弱的结合。
:::

::: exercise 孔扩散与表观活化能 {level=3}
从[[#eq-thiele]]出发，证明在强扩散极限下，单位颗粒体积的观测速率为 $r_\text{obs} \approx c_s\sqrt{kD_\text{eff}}/L$，并由此得出表观活化能为 $E_\text{app} \approx (E_\mathrm{a} + E_\mathrm{D})/2$，其中 $E_\mathrm{D}$ 是孔扩散的（很小的）活化能。再解释为什么在此极限下 $n$ 级反应的表观反应级数变为 $(n+1)/2$。
::: hint
关于级数，注意 $n$ 级反应的广义西勒模数含有 $c_s^{(n-1)/2}$。
:::
::: solution
$\phi \gg 1$ 时 $\eta \approx 1/\phi$，故 $r_\text{obs} = \eta k c_s \approx kc_s/\phi = kc_s/(L\sqrt{k/D_\text{eff}}) = c_s\sqrt{kD_\text{eff}}/L$。写出 $k = A e^{-E_\mathrm{a}/RT}$、$D_\text{eff} = D_0e^{-E_\mathrm{D}/RT}$，则
$$
r_\text{obs} \propto \sqrt{AD_0}\,e^{-(E_\mathrm{a} + E_\mathrm{D})/2RT},
$$
表观活化能 $-R\,\mathrm{d}\ln r_\text{obs}/\mathrm{d}(1/T)$ 为 $(E_\mathrm{a} + E_\mathrm{D})/2 \approx E_\mathrm{a}/2$，因为 $E_\mathrm{D}$ 通常只有几个 $\mathrm{kJ\,mol^{-1}}$。对 $n$ 级反应 $r = kc^n$，衡算式 $D_\text{eff}c'' = kc^n$ 有广义西勒模数 $\phi_n = L\sqrt{\tfrac{n+1}{2}\,kc_s^{\,n-1}/D_\text{eff}}$，以及同样的大 $\phi$ 极限 $\eta \approx 1/\phi_n$。于是 $r_\text{obs} = \eta kc_s^n \propto kc_s^n/(c_s^{(n-1)/2}\sqrt{k}) = \sqrt{k}\,c_s^{(n+1)/2}$：表观级数为 $(n+1)/2$。一级反应仍是一级，二级反应表现出 1.5 级，零级反应表现出 0.5 级。扩散限制由此同时扭曲活化能与级数——这又是要在小颗粒上测量本征动力学的一个理由。
:::
:::

::: exercise 桥接分子与表面 {level=3}
Pt(111) 表面化学吸附的 CO 在某些样品的低覆盖度下在约 $2090\ \mathrm{cm^{-1}}$ 处、在另一些样品上则约 $1850\ \mathrm{cm^{-1}}$ 处出现红外吸收带。(a) 借用[[organometallics-catalysis/ligands-complexes]]的分子类比，把吸收带指认给顶位与桥式 CO。(b) 用谐振子估算式 $k = \mu(\tilde\nu/130.28)^2$（$\mu = 6.856\ \mathrm{u}$），比较两种位点的 C–O 力常数。(c) 用 d 带模型解释为什么 CO 在金表面上结合弱得多，而载体氧化物上的小金颗粒对 CO 氧化却有活性（Haruta（Masatake Haruta）1980 年代末的发现）。
::: solution
(a) 与一个金属原子结合的 CO（顶位、端基）只从一个金属得到反馈，吸收靠近 $2100$–$2000\ \mathrm{cm^{-1}}$；桥连两个金属原子的 CO 从两个金属都得到反馈，吸收靠近 $1900$–$1800\ \mathrm{cm^{-1}}$。所以 $2090\ \mathrm{cm^{-1}}$ 是顶位 CO，$1850\ \mathrm{cm^{-1}}$ 是桥式 CO——正是金属羰基簇合物中端基/μ₂ 的区分。
(b) 顶位：$k = 6.856 \times (2090/130.28)^2 = 6.856 \times 257.4 = 1765\ \mathrm{N\,m^{-1}}$。桥式：$k = 6.856 \times (1850/130.28)^2 = 6.856 \times 201.6 = 1383\ \mathrm{N\,m^{-1}}$。桥式 CO 的键软约 $22\,\%$，反映 $2\pi^*$ 轨道占据更多。
(c) 金的 $5d$ 带深居费米能级之下。CO $5\sigma$ 轨道与金 $d$ 带之间形成的反键态位于费米能级以下且被填满，抵消了 σ 键的大部分；来自深 $d$ 带向 $2\pi^*$ 的反馈也很弱；因此延展的金表面结合 CO 很弱，也不解离 $\mathrm{O_2}$。还原性氧化物如 $\mathrm{TiO_2}$ 或 $\mathrm{Fe_2O_3}$ 上的小金颗粒（几纳米）则不同：其低配位的棱边与角原子有位置更高的 $d$ 态，结合 CO 更强；金属-氧化物周边则提供 $\mathrm{O_2}$ 被活化的位点（可能经由类似 Mars–van Krevelen 的步骤涉及晶格氧）。活性只在临界粒径以下才出现——结构敏感性的一个醒目例子，也提醒我们"贵金属"说的是块体金属，不是纳米颗粒。
