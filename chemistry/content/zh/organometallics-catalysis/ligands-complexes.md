一氧化碳是弱路易斯碱：它几乎不与 $\mathrm{BH_3}$ 结合，在水中不被质子化，而它的孤对电子位于一根极强三键中电负性*较小*的那个原子上。然而，它在室温下就能与镍金属结合，能把血红蛋白中的氧置换出来，还能与第 6 至 10 族几乎每一种过渡金属形成中性、挥发性、极其稳定的化合物。这一现象的解释——对金属而言，CO 的用处与其说在于给予电子，不如说在于*接受*电子——正是理解让整个金属有机化学运转起来的配体家族的关键：羰基、膦、烯烃、炔烃、卡宾、环戊二烯基与芳烃。

本章逐个讲解这些配体。对每一种我们都问：它怎样成键（σ 给予、π 反馈，还是两者兼有）；这种成键如何体现在测量中——红外伸缩振动波数、键长、NMR 位移；化学家又如何用它来调节金属的电子密度和金属周围的空间。[[organometallics-catalysis/organometallic-bonding]]中的电子计数告诉我们每个配体给出*多少个*电子；本章讲的则是它*怎样*给出、又拿回什么。

## 金属羰基配合物与协同键

CO 的前线轨道决定了一切。其最高占据轨道 $5\sigma$ 是定域在碳上的孤对电子，相对于 C–O 略呈反键；其最低未占轨道是二重简并的 $2\pi^*$ 对，它们对 C–O 是反键的，且较大的瓣位于碳一侧。于是两者都指向经碳配位的金属，这正是 CO 以 C 而非 O 键合的原因。

::: definition 协同（Dewar–Chatt–Duncanson）键 {#def-synergic}
当两种相互作用同时起作用时，配体与金属形成**协同**键：已满配体轨道向金属的空 σ 对称轨道的**σ 给予**，以及π 对称的满金属 $d$ 轨道向空配体轨道（CO、烯烃与炔烃的 $\pi^*$；膦中 P–R 键的 $\sigma^*$；二氢配合物中 H–H 的 $\sigma^*$）的**π 反馈**。两种相互作用彼此增强：给予使金属电子更富，因而成为更好的 π 给予体；反馈从金属抽走电子密度，使其成为更好的 σ 接受体。由于反馈占据的是配体*内部*的反键轨道，它削弱并拉长配体内的键（C–O、C=C、H–H），同时增强金属–配体键。这一模型由 Michael Dewar（1951 年）以及 Joseph Chatt 与 Leonard Duncanson（1953 年）针对烯烃配合物提出。
:::

对 CO 而言，两个组分把 C–O 键朝相反的方向拉扯。来自弱反键的 $5\sigma$ 的 σ 给予单独作用会*略微*增强 C–O 键；向 $2\pi^*$ 的 π 反馈则强烈削弱它。在中性与负离子羰基配合物中几乎总是反馈占优，C–O 伸缩振动波数 $\tilde\nu(\mathrm{CO})$ 低于自由分子值 $2143\ \mathrm{cm^{-1}}$。只有在少数几乎不反馈的阳离子配合物——$\mathrm{Au^+}$、$\mathrm{Pt^{2+}}$ 或 $\mathrm{[Fe(CO)_6]^{2+}}$ 的"非经典"羰基——中，$\tilde\nu(\mathrm{CO})$ 才升到 $2143\ \mathrm{cm^{-1}}$ 以上。

### 红外光谱测量的是什么

红外光谱能直接读出反馈的多少，因为伸缩振动波数取决于键的力常数。

::: proposition 伸缩振动波数、力常数与同位素位移 {#prop-harmonic}
把 C–O 基团看作力常数为 $k$、约化质量为 $\mu = m_\mathrm{C}m_\mathrm{O}/(m_\mathrm{C} + m_\mathrm{O})$ 的谐振子，其伸缩振动波数为
$$
\tilde\nu = \frac{1}{2\pi c}\sqrt{\frac{k}{\mu}} = 130.28\ \sqrt{\frac{k/(\mathrm{N\,m^{-1}})}{\mu/\mathrm{u}}}\ \mathrm{cm^{-1}},
$$ {#eq-harmonic}
第一个形式中 $c$ 以 $\mathrm{cm\,s^{-1}}$、$\mu$ 以千克计。同位素取代改变 $\mu$ 而不改变 $k$（力常数由电子结构决定，玻恩-奥本海默近似使其与核质量无关），于是
$$
\frac{\tilde\nu'}{\tilde\nu} = \sqrt{\frac{\mu}{\mu'}}.
$$ {#eq-isotope}
这一近似把每个 CO 当作孤立振子；在含多个羰基的配合物中，CO 振子相互耦合、给出对称与反对称组合，但平均波数仍跟踪平均力常数。
:::

::: proof
对质量为 $m_1$、$m_2$、键伸长为 $x$ 的双原子分子，两原子的牛顿运动方程在质心参考系中合并为关于相对坐标的一个方程 $\mu\ddot x = -kx$，其中 $\mu = m_1m_2/(m_1+m_2)$。其解以角频率 $\omega = \sqrt{k/\mu}$ 振动；频率为 $\nu = \omega/2\pi$，波数为 $\tilde\nu = \nu/c$，即得[[#eq-harmonic]]的第一个形式。换算单位，$\mu = (\mu/\mathrm{u}) \times 1.66054\times10^{-27}\ \mathrm{kg}$、$c = 2.99792\times10^{10}\ \mathrm{cm\,s^{-1}}$，于是
$$
\frac{1}{2\pi c\sqrt{1.66054\times10^{-27}}} = \frac{1}{(1.88365\times10^{11})(4.07497\times10^{-14})} = 130.28,
$$
即那个数值常数。在量子谐振子中，同一个 $\omega$ 决定能级间距 $\hbar\omega$，因此红外基频跃迁就发生在这一波数（[[spectroscopy/vibrational-spectroscopy]]）。对 $k$ 相同的两个同位素物种取[[#eq-harmonic]]之比，除 $\mu$ 外一切相消，即得[[#eq-isotope]]。$\blacksquare$
:::

::: example 反馈把 CO 削弱了多少？ {#ex-force-constant}
自由 $^{12}\mathrm{C}^{16}\mathrm{O}$ 在 $2143\ \mathrm{cm^{-1}}$ 处吸收；$\mathrm{[Cr(CO)_6]}$ 的红外活性 C–O 伸缩振动约位于 $2000\ \mathrm{cm^{-1}}$。估算两者的 C–O 力常数，并求配位使该键削弱了百分之几。原子质量取 $12.000$ 与 $15.995\ \mathrm{u}$。
::: solution
约化质量 $\mu = (12.000)(15.995)/27.995 = 6.856\ \mathrm{u}$。把[[#eq-harmonic]]改写为 $k = \mu(\tilde\nu/130.28)^2$：
$$
k_\text{自由} = 6.856 \times \left(\frac{2143}{130.28}\right)^2 = 6.856 \times 270.6 = 1855\ \mathrm{N\,m^{-1}},
\qquad
k_\mathrm{Cr} = 6.856 \times \left(\frac{2000}{130.28}\right)^2 = 1616\ \mathrm{N\,m^{-1}}.
$$
力常数下降了 $(1855 - 1616)/1855 = 12.9\,\%$，约 $13\,\%$。由于 $k \propto \tilde\nu^2$，波数下降 $6.7\,\%$ 就是刚度下降 $13\,\%$。（这些是近似力常数：$\mathrm{[Cr(CO)_6]}$ 实测的 $T_{1u}$ 谱带是六个羰基的耦合振动，且忽略了非谐性，但相关配合物之间的比较是可靠的。）
:::
:::

::: example 证明一条谱带是 C–O 伸缩振动 {#ex-isotope}
$2143\ \mathrm{cm^{-1}}$ 处的谱带被指认为自由 $^{12}\mathrm{C}^{16}\mathrm{O}$ 的伸缩振动。换成 $^{13}\mathrm{C}^{16}\mathrm{O}$ 后它应移到何处？这个实验在金属有机化学中有何用处？
::: solution
$\mu(^{13}\mathrm{C}^{16}\mathrm{O}) = (13.003)(15.995)/28.998 = 7.172\ \mathrm{u}$。由[[#eq-isotope]]，
$$
\tilde\nu' = 2143 \times \sqrt{\frac{6.856}{7.172}} = 2143 \times 0.9777 = 2095\ \mathrm{cm^{-1}},
$$
移动了 $48\ \mathrm{cm^{-1}}$（实测值为 $2096\ \mathrm{cm^{-1}}$）。在配合物中，经 $^{13}\mathrm{CO}$ 标记后按这一比例移动的谱带就是 C–O 伸缩振动；不动的谱带属于其他基团。标记单个羰基、观察哪些谱带移动，还能指明哪些羰基在交换、进入的 CO 最终落在哪里——这正是[[organometallics-catalysis/elementary-reactions]]中机理实验的关键。
:::
:::

三条规律使羰基的红外光谱成为例行诊断工具：

1. **电荷。**在等电子序列中，每增加一个负电荷就抬高金属的 $d$ 能级、增大反馈，使 $\tilde\nu(\mathrm{CO})$ 下降约 $100\ \mathrm{cm^{-1}}$：$\mathrm{[V(CO)_6]^-}$ $1858$、$\mathrm{[Cr(CO)_6]}$ $2000$、$\mathrm{[Mn(CO)_6]^+}$ $2090\ \mathrm{cm^{-1}}$（该序列绘制于[[coordination-chemistry/ligand-field-mo]]）。
2. **其他配体。**把某个羰基替换成给予更强、接受更弱的配体（胺、三烷基膦），留给其余羰基的金属电子密度就更多，其波数随之下降。这就是下文托尔曼电子参数的基础。
3. **桥连。**桥连两个金属的 CO（$\mu_2$）从两个金属都获得反馈，约在 $1850$–$1750\ \mathrm{cm^{-1}}$ 吸收；盖面的 $\mu_3$-CO 更低，约 $1730$–$1620\ \mathrm{cm^{-1}}$；中性配合物的端基羰基大致位于 $2125$ 到 $1850\ \mathrm{cm^{-1}}$ 之间。这些范围都是经验值，边缘处相互重叠。

### 用对称性数红外谱带

C–O 伸缩振动谱带的数目取决于 $\mathrm{M(CO)}_n$ 单元的对称性而不仅是 $n$，因此红外光谱是几何构型的快捷判据。

::: algorithm 红外活性 C–O 伸缩振动谱带数 {#alg-ir-bands}
1. 确定配合物的点群（[[quantum-chemistry/molecular-symmetry]]）。
2. 把每个 C–O 键看作一个矢量。对每一类对称操作，数出被该操作**保持不动**的矢量数（被移到别处的矢量贡献 $0$；留在原处的贡献 $1$）。由此得到可约表示 $\Gamma_\mathrm{CO}$ 的特征标。
3. 用约化公式 $n_i = \frac{1}{h}\sum_R g_R\,\chi(R)\,\chi_i(R)$ 约化 $\Gamma_\mathrm{CO}$，其中 $h$ 为群阶，$g_R$ 为每类操作的数目。
4. 属于按 $x$、$y$ 或 $z$ 变换的不可约表示的 C–O 伸缩振动是**红外活性**的；数出它们（每个二重或三重简并的 E 或 T 表示给一条谱带）。
:::

::: example *顺*还是*反*？ {#ex-cis-trans}
把 $\mathrm{[Mo(CO)_6]}$ 的两个羰基换成三苯基膦，可得 *顺*- 或 *反*-$\mathrm{[Mo(CO)_4(PPh_3)_2]}$。一种异构体只显示一条强的 C–O 谱带，另一种显示四条。哪个是哪个？用[[#alg-ir-bands]]判断，并用 $\mathrm{[Mo(CO)_5(PPh_3)]}$ 检验这个方法。
::: solution
**$\mathrm{M(CO)_5L}$，点群 $C_{4v}$**（操作 $E$、$2C_4$、$C_2$、$2\sigma_v$、$2\sigma_d$；$h = 8$）。$\Gamma_\mathrm{CO}$ 的特征标：$E$ 保持全部 5 个矢量；$C_4$ 只保持轴向 CO，1；$C_2$，1；每个 $\sigma_v$ 包含轴向 CO 与两个赤道 CO，3；每个 $\sigma_d$ 只包含轴向的那一个，1。故 $\Gamma_\mathrm{CO} = (5, 1, 1, 3, 1)$。约化：
$$
n(A_1) = \tfrac18(5 + 2 + 1 + 6 + 2) = 2,\quad n(B_1) = \tfrac18(5 - 2 + 1 + 6 - 2) = 1,\quad n(E) = \tfrac18(10 + 0 - 2 + 0 + 0) = 1,
$$
$A_2$、$B_2$ 的系数为零。$\Gamma_\mathrm{CO} = 2A_1 + B_1 + E$。$A_1$（$z$）与 $E$（$x, y$）红外活性，$B_1$ 非活性：**三**条谱带，与 $\mathrm{M(CO)_5L}$ 配合物的观测一致。

***反*-$\mathrm{M(CO)_4L_2}$，$D_{4h}$。**四个羰基位于一个正方形上。同样的步骤给出 $\Gamma_\mathrm{CO} = A_{1g} + B_{1g} + E_u$；只有 $E_u$（按 $x, y$ 变换）红外活性：**一**条谱带。对称的 $A_{1g}$ 与 $B_{1g}$ 伸缩振动只具拉曼活性——这是对称中心的必然结果（互斥律）。

***顺*-$\mathrm{M(CO)_4L_2}$，$C_{2v}$。**对应 $E$、$C_2$、$\sigma_v$、$\sigma_v'$ 的特征标 $(4, 0, 2, 2)$ 约化为 $2A_1 + B_1 + B_2$，全部红外活性：**四**条谱带。

所以只有一条谱带的异构体是*反*式的，有四条的是*顺*式的。（对于庞大的 $\mathrm{PPh_3}$，*反*式异构体通常是热力学产物。）
:::
:::

## 膦：调节电子与空间

叔膦 $\mathrm{PR_3}$ 是催化中用途最广的配体，因为它最重要的两个性质——给予电子的强度与占据的空间——几乎可以通过改变取代基 R 而独立调节。膦通过磷的孤对电子成为良好的 σ 给予体，通过 P–R $\sigma^*$ 轨道成为中等强度的 π 接受体；电负性取代基（芳氧基、烷氧基、F）压低这些 $\sigma^*$ 轨道，使 $\mathrm{PF_3}$ 与亚磷酸酯 $\mathrm{P(OR)_3}$ 成为可与 CO 相比的 π 接受体。

::: definition 托尔曼电子参数与锥角 {#def-tolman}
膦 L 的**托尔曼电子参数**（TEP）是 $\mathrm{[Ni(CO)_3L]}$ 在二氯甲烷中 $A_1$ 的 C–O 伸缩振动谱带的波数。给予更强、接受更弱的 L 留给羰基用于反馈的电子密度更多，TEP *更低*。典型数值（Tolman，1977）：$\mathrm{P}t\mathrm{Bu_3}$ $2056.1$、$\mathrm{PMe_3}$ $2064.1$、$\mathrm{PPh_3}$ $2068.9$、$\mathrm{P(OEt)_3}$ $2076.3$、$\mathrm{P(OMe)_3}$ $2079.5$、$\mathrm{PF_3}$ $2110.8\ \mathrm{cm^{-1}}$。Tolman 发现 TEP 对取代基贡献 $\chi_i$ 近似可加：
$$
\mathrm{TEP} \approx 2056.1 + \sum_{i=1}^{3}\chi_i\ \ \mathrm{cm^{-1}},
$$
例如 $\chi(t\mathrm{Bu}) = 0$、$\chi(\mathrm{Me}) = 2.6$、$\chi(\mathrm{Ph}) = 4.3$、$\chi(\mathrm{OEt}) = 6.8$、$\chi(\mathrm{OMe}) = 7.7$、$\chi(\mathrm{F}) = 18.2$（一个经验关联）。

**托尔曼锥角** $\theta$ 度量空间体积：它是以金属为顶点（在 Tolman 的构造中距磷 $2.28\ \text{Å}$）的圆锥的顶角，该圆锥恰好包围取代基的范德华表面。典型数值：$\mathrm{PF_3}$ $104^\circ$、$\mathrm{P(OMe)_3}$ $107^\circ$、$\mathrm{PMe_3}$ $118^\circ$、$\mathrm{PPh_3}$ $145^\circ$、$\mathrm{PCy_3}$ $170^\circ$、$\mathrm{P}t\mathrm{Bu_3}$ $182^\circ$、$\mathrm{P(}o\text{-tolyl)}_3$ $194^\circ$。
:::

锥角与 TEP 一起给出一张二维"配体地图"，可据此为具体的催化任务挑选膦。大锥角有利于低配位数：$\mathrm{[Pd(P}t\mathrm{Bu_3)_2]}$ 是稳定的二配位配合物，且在溶液中会失去一分子膦，生成高活性的单配位 $\mathrm{Pd(P}t\mathrm{Bu_3)}$——正是在[[organometallics-catalysis/cross-coupling]]中活化芳基氯化物的物种。小而富电子的膦（如 $\mathrm{PMe_3}$）则稳定高配位数与高氧化态。对于**螯合双膦** $\mathrm{R_2P(CH_2)_nPR_2}$，关键的几何变量是**齿合角** P–M–P：1,2-双(二苯基膦)乙烷（dppe）约 $85^\circ$，1,1′-双(二苯基膦)二茂铁（dppf）约 $99^\circ$，Xantphos 约 $110^\circ$（典型数值来自晶体结构与模型计算；随金属而变）。宽齿合角有利于还原消除，在氢甲酰化中也有利于生成直链醛（[[organometallics-catalysis/hydrogenation-hydroformylation]]）。

::: example 预测电子参数 {#ex-tolman}
用 Tolman 的可加性规则估算二甲基苯基膦 $\mathrm{PMe_2Ph}$ 与甲基二苯基亚膦酸酯 $\mathrm{Ph_2P(OMe)}$ 的 TEP。哪个是更好的给予体？
::: solution
$\mathrm{PMe_2Ph}$：$2056.1 + 2(2.6) + 4.3 = 2065.6\ \mathrm{cm^{-1}}$（Tolman 的实测值为 $2065.3$）。$\mathrm{Ph_2P(OMe)}$：$2056.1 + 2(4.3) + 7.7 = 2072.4\ \mathrm{cm^{-1}}$。$\mathrm{PMe_2Ph}$ 的 TEP 更低，意味着其镍中心向 CO 反馈更多，所以 $\mathrm{PMe_2Ph}$ 是更强的净给予体；把芳基换成烷氧基使磷更多地带吸电子取代基，既降低其孤对能量（σ 给予变弱），又压低其 P–O $\sigma^*$ 轨道（π 接受变强）。两种效应把 TEP 推向同一方向。
:::
:::

N-杂环卡宾（见下文）的 TEP 约 $2050\ \mathrm{cm^{-1}}$（在类似的镍、或更安全的铑与铱羰基配合物上测得并经换算），比 $\mathrm{P}t\mathrm{Bu_3}$ 还低：它们是常用配体中最强的中性给予配体。

::: warning ν(CO) 低不等于配体"更好" {#warn-tep}
TEP 度量的是某一个金属、在一种几何下的*净*电子给予——σ 给予减去 π 接受。它既不度量配体结合的强度（CO 本身的类 TEP 波数很高，却因反馈而与低价金属结合得非常牢固），也不度量配体在催化中的表现——位阻效应常常起主导作用。两个 TEP 相同的配体，若一个锥角 $120^\circ$、另一个 $180^\circ$，反应性可能完全不同。务必同时考虑电子与空间两类参数，并记住二者都是在模型配合物上测得的经验描述符。
:::

## 烯烃与炔烃

Zeise 盐中的化学键就是 Dewar–Chatt–Duncanson 键在乙烯上的体现。充满的 C=C π 轨道向金属的空 σ 轨道给予，金属的满 $d$ 轨道则向空的 C=C $\pi^*$ 反馈。两种效应都削弱 C=C 键：σ 给予抽走成键 π 密度，反馈加入反键 π* 密度。

这一描述的两个极限是**π 配合物**——反馈适中，C=C 键只比自由烯烃略长，取代基仍近乎共面；以及**金属环丙烷**——反馈很强，C–C 键接近单键，随着碳原子趋于 $sp^3$ 杂化，取代基向远离金属的方向弯折。键长显示出这一渐变：自由乙烯 $1.337\ \text{Å}$；Zeise 盐的阴离子 $\mathrm{[PtCl_3(C_2H_4)]^-}$（Pt(II)，反馈弱）约 $1.375\ \text{Å}$；$\mathrm{[Pt(C_2H_4)(PPh_3)_2]}$（富电子的 Pt(0)）约 $1.43\ \text{Å}$。在金属环丙烷极限下电子数不变（共价计数中 L 配体与 X₂"金属环"都给两个电子），但金属的形式氧化态升高二——这是金属有机化学中的氧化态必须看作形式之一的理由（[[organometallics-catalysis/organometallic-bonding#warn-formal-os]]）。

配位改变烯烃的化学性质。与缺电子阳离子金属（如 Pd(II)）结合后，烯烃失去 π 密度而变为**亲电的**：水或醇从与金属相反的一面进攻它——这是 Wacker 法把乙烯氧化为乙醛的关键一步。与富电子金属结合时，烯烃既受到保护，又被活化而可迁移插入 M–H 或 M–C 键——这是构建聚合物与醛的步骤（[[organometallics-catalysis/elementary-reactions]]）。炔烃类似地配位，但还能动用其第二个、垂直的 π 体系：在多数单核配合物中作两电子给予体；当金属有合适的空 $d$ 轨道时作四电子给予体；并在 $\mathrm{[Co_2(CO)_6(\mu\text{-}RC{\equiv}CR)]}$ 这类配合物中桥连两个金属，与四面体烷等瓣相似。

## 卡宾：Fischer、Schrock 与 N-杂环卡宾

卡宾配合物含有金属–碳双键 $\mathrm{L_nM{=}CR_2}$。由于同一个化学式掩盖着相反的极性，人们区分两种极端类型。

::: definition Fischer 卡宾与 Schrock 卡宾 {#def-carbenes}
**Fischer 卡宾**（E. O. Fischer，1964，例如 $\mathrm{[(CO)_5W{=}C(OMe)Ph]}$）结合在带 π 接受体辅配体的低价、中晚期过渡金属上，卡宾碳上带 π 给予取代基（OR、$\mathrm{NR_2}$）。它可描述为单线态卡宾把孤对电子给予金属（一个 **L** 配体），金属向卡宾空 $p$ 轨道的反馈很弱；卡宾碳是**亲电的**，受亲核试剂进攻（胺置换 OMe 基团，如同酯的氨解）。

**Schrock 卡宾**或称**烷基叉**（R. R. Schrock，1974，例如 $\mathrm{[Ta(CH}t\mathrm{Bu)(CH_2}t\mathrm{Bu)_3]}$）结合在处于高氧化态的早期过渡金属上，没有 π 接受体辅配体，碳上只有 H 或烷基取代基。它可描述为三线态卡宾与金属的两个未成对电子形成两根共价键（σ 与 π）——一个 **X₂** 配体——M=C 键极化为 $\mathrm{M^{\delta+}{=}C^{\delta-}}$：碳是**亲核的**，反应起来像磷叶立德的碳，能把酮转化为烯烃。

**N-杂环卡宾**（NHC），如 1,3-双(2,4,6-三甲基苯基)咪唑-2-亚基（IMes），是被两个相邻氮孤对稳定的单线态卡宾；它们是极强的 σ 给予体、弱 π 接受体，以 L 配体方式结合、M–C 本质上是一根单键，可充当强韧的膦替代品。
:::

两类金属–碳双键在催化中各司其职。Schrock 的钼、钨烷基叉与 Grubbs 的钌烷基叉实现烯烃**复分解**（[[organometallics-catalysis/metathesis-polymerisation]]）；NHC 则是造就第二代 Grubbs 催化剂与许多最活泼的钯交叉偶联催化剂的配体。计数与形式一致：$\mathrm{[(CO)_5W{=}C(OMe)Ph]}$ 是 W(0)、六个 L 配体，$6 + 12 = 18$；$\mathrm{[Ta(CH}t\mathrm{Bu)(CH_2}t\mathrm{Bu)_3]}$ 是 Ta(V)、$d^0$，含一个 X₂ 烷基叉与三个 X 烷基，$5 + 2 + 3 = 10$——一个强缺电子配合物，靠庞大的新戊基在空间上受到保护。

::: example Fischer 还是 Schrock？ {#ex-carbene-type}
判断下列卡宾配合物的类型并预言进攻位点：(a) $\mathrm{[(CO)_5Cr{=}C(OMe)CH_3]}$ 与甲胺；(b) $\mathrm{[Cp_2Ti{=}CH_2]}$（由 Tebbe 试剂产生）与酮 $\mathrm{R_2C{=}O}$。
::: solution
(a) Cr(0)、低氧化态、五个 π 接受羰基、卡宾碳上有 π 给予的 OMe：**Fischer 卡宾**。卡宾碳亲电，颇像酯的羰基碳。甲胺的氮孤对进攻卡宾碳，形成四面体中间体；C–OMe 键断裂并失去甲醇，得到氨基卡宾 $\mathrm{[(CO)_5Cr{=}C(NHMe)CH_3]}$。更强的 π 给予体（N）取代更弱的（O），增强了对亲电碳的稳定。

(b) Ti(IV)、$d^0$、配体为 Cp、无 π 接受体、卡宾碳上只有 H：**Schrock 烷基叉**，极化为 $\mathrm{Ti^{\delta+}{=}CH_2^{\delta-}}$。亲核的亚甲基碳进攻酮的羰基碳，同时亲氧的钛结合羰基氧，形成氧杂钛杂环丁烷四元环。这个环朝另一个方向断裂，给出烯烃 $\mathrm{R_2C{=}CH_2}$ 与一根极强的 Ti=O 键。该反应能把酮亚甲基化——甚至酯也可以（Wittig 试剂做不到）——是与复分解类似的 [2+2]/逆-[2+2] 序列。
:::
:::

## 环戊二烯基与芳烃配体：夹心与半夹心

环戊二烯基配体 $\mathrm{C_5H_5}$（Cp）是金属有机化学中最重要的"旁观"配体：它占据三个配位位置、给出五个电子（共价计数；离子计数中按 $\mathrm{C_5H_5^-}$ 计六个），与几乎每种金属都结合牢固，而且自身很少参与反应。它的 π 分子轨道像[[quantum-chemistry/huckel-theory]]中苯的那样构造：一个全同相、$a$ 对称的轨道，加上两组二重简并轨道 $e_1$ 与 $e_2$。在二茂铁中，已充满的配体 $a$ 与 $e_1$ 轨道向金属的 $d_{z^2}$/$s$ 与 $d_{xz}$/$d_{yz}$ 轨道给予，金属的 $d_{xy}$ 与 $d_{x^2-y^2}$ 轨道则微弱地向空的 $e_2$ 组反馈。九个低能轨道恰好容纳 18 个电子，二茂铁是教科书式的 18 电子分子：橙色、空气稳定、可升华，电化学行为又极其良好，以至于二茂铁鎓/二茂铁电对是非水溶剂中电极电势的 IUPAC 推荐内标。

其他茂金属则逐个电子地检验 18 电子规则：

| 茂金属 | VE | 未成对电子 | 行为 |
|---|---|---|---|
| $\mathrm{Cp_2V}$ | 15 | 3 | 紫色，对空气敏感 |
| $\mathrm{Cp_2Cr}$ | 16 | 2 | 红色，对空气极其敏感 |
| $\mathrm{Cp_2Mn}$ | 17 | 5（高自旋） | 很大程度上是离子型的，固态为聚合物 |
| $\mathrm{Cp_2Fe}$ | 18 | 0 | 空气稳定，可逆氧化 |
| $\mathrm{Cp_2Co}$ | 19 | 1 | 强还原剂，生成 $\mathrm{Cp_2Co^+}$（18） |
| $\mathrm{Cp_2Ni}$ | 20 | 2 | 绿色，易被氧化为 $\mathrm{Cp_2Ni^+}$ |

超出 18 的电子进入一对金属–环反键轨道；它们拉长 M–C 键并使配合物易于氧化。少于 18 时，配合物有空的成键或非键能级，对给予体和氧有反应性。五甲基环戊二烯基配体 $\mathrm{C_5Me_5}$（Cp*）比 Cp 给予性更强、体积大得多，能稳定那些否则会分解的活性物种——$\mathrm{Cp^*_2ZrMe^+}$、$\mathrm{Cp^*Ir(PMe_3)}$。

**芳烃**配体以六电子 L₃ 给予体方式配位：Ernst Otto Fischer 与 Walter Hafner 于 1955 年制得二苯铬 $\mathrm{[Cr(\eta^6\text{-}C_6H_6)_2]}$（18 电子）。在 $\mathrm{[Cr(\eta^6\text{-}C_6H_6)(CO)_3]}$ 这类半夹心配合物中，强接受体 $\mathrm{Cr(CO)_3}$ 单元从环上抽走电子密度，使环易受**亲核**进攻，其 C–H 键和苄位的酸性也增强——芳烃正常亲电化学的反转（[[organic-2/aromatic-substitution]]）。

::: example 茂金属的磁性 {#ex-metallocenes}
二茂铬有两个未成对电子。计算它的仅自旋磁矩，并从电子数出发解释为什么二茂铬容易与 CO 反应而二茂铁却不能。
::: solution
$N$ 个未成对电子的仅自旋磁矩为 $\mu_\text{so} = \sqrt{N(N+2)}\ \mu_\mathrm{B}$（[[coordination-chemistry/magnetism]]），故 $N = 2$ 时 $\mu_\text{so} = \sqrt{8} = 2.83\ \mu_\mathrm{B}$。二茂铬有 $6 + 5 + 5 = 16$ 个电子（Cr(II)、$d^4$）：两个最低的金属能级已被占据，但成键/非键能级组中有一个轨道未填满，所以配合物在配位和电子两方面都不饱和，能够接受一个两电子给予体。二茂铁有 18 个电子，九个低能轨道全部填满；再加配体就必须把电子放进金属–配体反键轨道，因此二茂铁毫无结合 CO 的倾向，其化学是环上的化学（它发生亲电取代，像一个电子非常富集的芳烃）。
:::
:::

## 氢化物与二氢配合物

金属氢化物 M–H 是 X 配体；由于金属 $d$ 电子的屏蔽，其 $^{1}\mathrm{H}$ NMR 信号出现在异常低的化学位移处，通常在 $\delta\ 0$ 到 $-25$ 之间——这是辨认催化中间体的诊断工具。1984 年 Gregory Kubas 与合作者发现 $\mathrm{[W(CO)_3(P}i\mathrm{Pr_3)_2]}$ 能在*不*断开 H–H 的情况下结合氢分子：配合物 $\mathrm{[W(CO)_3(P}i\mathrm{Pr_3)_2(\eta^2\text{-}H_2)]}$ 中的 H–H 键只比自由 $\mathrm{H_2}$ 略长（自由分子 $0.74\ \text{Å}$；此类配合物中约 $0.8$–$0.9\ \text{Å}$），以侧基 L 配体的方式结合。二氢配体通过 H–H 成键轨道作 σ 给予体，并向 H–H $\sigma^*$ 轨道作 π 接受体；随着反馈增大，H–H 键连续伸长直至断裂，配合物变为*二氢化物*——这正是[[organometallics-catalysis/elementary-reactions]]中氧化加成被定格的中间阶段。二氢配合物与二氢化物的区分依据是短的 NMR $T_1$ 弛豫时间，以及 HD 同位素体中大的 H–D 耦合常数（几十赫兹，而自由 HD 为 $43\ \mathrm{Hz}$、二氢化物中只有几赫兹）。

::: quiz
三种组成为 $\mathrm{[ML(CO)_5]}$ 的配合物，其最高波数的 C–O 谱带分别位于 $2120$、$2080$ 与 $2050\ \mathrm{cm^{-1}}$。配体 L 是 $\mathrm{PF_3}$、$\mathrm{PPh_3}$ 与 $\mathrm{PMe_3}$，顺序未知。哪种指定与托尔曼电子参数一致？
- [x] $\mathrm{PF_3}$ $2120$，$\mathrm{PPh_3}$ $2080$，$\mathrm{PMe_3}$ $2050$
- [ ] $\mathrm{PMe_3}$ $2120$，$\mathrm{PPh_3}$ $2080$，$\mathrm{PF_3}$ $2050$
- [ ] $\mathrm{PPh_3}$ $2120$，$\mathrm{PF_3}$ $2080$，$\mathrm{PMe_3}$ $2050$
::: solution
最强的净给予体留给其余羰基用于反馈的电子密度最多，因而给出最低的波数：$\mathrm{PMe_3}$（TEP $2064.1$）< $\mathrm{PPh_3}$（$2068.9$）< $\mathrm{PF_3}$（$2110.8$）。$\mathrm{PF_3}$ 是与 CO 相当的 π 接受体，与羰基争夺反馈，从而抬高它们的波数。
:::
:::

## 后续内容

本章的配体是此后一切的工具。CO 与膦出现在[[organometallics-catalysis/hydrogenation-hydroformylation]]的每个催化循环里——氢甲酰化的速率由膦的解离控制，其选择性则由齿合角决定。烯烃的配位及其金属环丙烷极限是[[organometallics-catalysis/elementary-reactions]]中迁移插入的出发点；Schrock 与 Grubbs 烷基叉驱动复分解，Cp 配体则构成了[[organometallics-catalysis/metathesis-polymerisation]]中茂金属聚合催化剂的骨架。庞大而富电子的膦与 NHC 使芳基氯化物的交叉偶联成为实用反应（[[organometallics-catalysis/cross-coupling]]）。本章用到的红外与 NMR 方法在[[spectroscopy/vibrational-spectroscopy]]与[[spectroscopy/nmr-principles]]中展开。

::: history
第一个金属羰基配合物 $\mathrm{[Ni(CO)_4]}$ 由 Mond（Ludwig Mond）与合作者于 1890 年发现；Hieber（Walter Hieber）自 1920 年代起对羰基氢化物与羰基阴离子的系统研究奠定了这一领域。1951 年 Dewar（Michael Dewar）以及 1953 年 Chatt（Joseph Chatt）与 Duncanson（Leonard Duncanson）提出了烯烃成键的协同模型。Fischer（Ernst Otto Fischer）与 Hafner（Walter Hafner）于 1955 年报道了二苯铬，Fischer 与 Maasböl（Alfred Maasböl）于 1964 年报道了第一个卡宾配合物 $\mathrm{[(CO)_5W{=}C(OMe)Ph]}$。Öfele（Karl Öfele）与 Wanzlick（Hans-Werner Wanzlick）于 1968 年各自独立制得了第一批 N-杂环卡宾金属配合物；Arduengo（Anthony Arduengo）于 1991 年分离出稳定的游离 NHC。Schrock（Richard Schrock）于 1974 年报道了第一个钽烷基叉配合物。Tolman（Chadwick Tolman）1977 年发表在 *Chemical Reviews* 上的综述提出了至今仍在用来挑选膦的电子参数与锥角；Kubas（Gregory Kubas）课题组于 1984 年描述了第一个二氢配合物。
:::

::: summary
- CO、烯烃、炔烃、膦与 $\mathrm{H_2}$ 以协同方式成键：向金属 σ 给予，并向空的配体轨道（$\pi^*$ 或 $\sigma^*$）π 反馈；反馈削弱配体内部的键。
- $\tilde\nu(\mathrm{CO})$ 反映反馈：随负电荷（每个单位约 $100\ \mathrm{cm^{-1}}$）、随给予性更强的辅配体、随桥连而下降；同位素标记下 $k = \mu(\tilde\nu/130.28)^2$、$\tilde\nu'/\tilde\nu = \sqrt{\mu/\mu'}$。
- 红外活性 C–O 伸缩振动谱带数由对称性决定：$\mathrm{M(CO)_5L}$ 3 条，*反*-$\mathrm{M(CO)_4L_2}$ 1 条，*顺*式 4 条。
- 膦的电子性质（托尔曼电子参数，对取代基可加）与空间性质（锥角；螯合配体用齿合角）可分别调节；二者都是经验描述符。
- 烯烃配位从 π 配合物连续过渡到金属环丙烷；与缺电子金属配位的烯烃是亲电的。
- Fischer 卡宾（低价、带 π 给予取代基）是亲电的 L 配体；Schrock 烷基叉（高价早期金属）是亲核的 X₂ 配体；NHC 是极强的 σ 给予体。
- 二茂铁是经典的 18 电子夹心分子；15–20 电子的茂金属显示出空的或反键的能级带来的后果。二氢配合物是被定格的氧化加成。
:::

自由 $^{12}\mathrm{C}^{16}\mathrm{O}$ 在 $2143\ \mathrm{cm^{-1}}$ 处吸收。在谐振子近似下预言 $^{13}\mathrm{C}^{18}\mathrm{O}$ 的波数（原子质量 $13.003$ 与 $17.999\ \mathrm{u}$）。（波数以 $\mathrm{cm^{-1}}$ 输入，保留四位有效数字。）
::: solution
$\mu(^{13}\mathrm{C}^{18}\mathrm{O}) = (13.003)(17.999)/31.002 = 7.549\ \mathrm{u}$，而 $\mu(^{12}\mathrm{C}^{16}\mathrm{O}) = 6.856\ \mathrm{u}$。由[[#eq-isotope]]，$\tilde\nu' = 2143\sqrt{6.856/7.549} = 2143 \times 0.9530 = 2042\ \mathrm{cm^{-1}}$。
:::

::: exercise 面式三羰基的红外谱带 {level=1 check="2"}
面式 $\mathrm{[Mo(CO)_3(PMe_3)_3]}$（点群 $C_{3v}$）预期有几条红外活性的 C–O 伸缩振动谱带？（输入谱带数。）
::: solution
三个 C–O 矢量对 $E$、$2C_3$、$3\sigma_v$ 给出特征标 $(3, 0, 1)$，约化为 $A_1 + E$；二者皆红外活性，故**两**条谱带。经式异构体（$C_{2v}$）给出 $2A_1 + B_1$（或 $B_2$），全部活性：三条谱带——这是快速区分两种异构体的办法。
:::
:::

$9 + 5 + 5 = 19$（Co(II)、$d^7$）。第 19 个电子占据金属–环反键轨道；二茂钴是强单电子还原剂，因为氧化后得到 18 电子的二茂钴鎓阳离子。

::: exercise 顺式双取代羰基的红外谱带 {level=3 check="4"}
推导顺式 $\mathrm{[Mo(CO)_4(PPh_3)_2]}$（$C_{2v}$）红外活性 C–O 伸缩振动谱带的数目，写出 $\Gamma_\mathrm{CO}$ 的特征标与约化过程。取 $C_2$ 轴平分 P–Mo–P 角；平面 $\sigma_v(xz)$ 包含 Mo 与两个与磷互为反位的羰基，$\sigma_v'(yz)$ 包含 Mo 与两个互为反位的羰基。（输入谱带数。）
::: hint
$C_{2v}$ 特征标表：$A_1$ $(1,1,1,1)$ $z$；$A_2$ $(1,1,-1,-1)$；$B_1$ $(1,-1,1,-1)$ $x$；$B_2$ $(1,-1,-1,1)$ $y$。
:::
::: solution
逐个操作来看：$E$ 保持全部四个 CO 矢量，$\chi = 4$。$C_2$ 轴不穿过任何羰基（它平分 P–Mo–P 以及两个与 P 互为反位的羰基之间的角），所以每个 CO 都被移走：$\chi = 0$。$\sigma_v(xz)$ 包含两个与磷互为反位的羰基：$\chi = 2$。$\sigma_v'(yz)$ 包含两个互为反位的羰基：$\chi = 2$。故 $\Gamma_\mathrm{CO} = (4, 0, 2, 2)$。取 $h = 4$：
$$
\begin{aligned}
n(A_1) &= \tfrac14(4 + 0 + 2 + 2) = 2, & n(A_2) &= \tfrac14(4 + 0 - 2 - 2) = 0,\\
n(B_1) &= \tfrac14(4 - 0 + 2 - 2) = 1, & n(B_2) &= \tfrac14(4 - 0 - 2 + 2) = 1.
\end{aligned}
$$
$\Gamma_\mathrm{CO} = 2A_1 + B_1 + B_2$；$A_1$（$z$）、$B_1$（$x$）与 $B_2$（$y$）全部红外活性，故**四**条谱带。（哪个 $B$ 对应哪个取决于坐标轴约定，但总数不变。）
:::
:::

::: exercise 解读一个烯烃配合物 {level=3}
在三个铂配合物中测得烯烃的 C=C 键长：$\mathrm{[PtCl_3(C_2H_4)]^-}$ $1.375\ \text{Å}$；$\mathrm{[Pt(C_2H_4)(PPh_3)_2]}$ $1.43\ \text{Å}$；以及四氟乙烯与 $\mathrm{Pt(PPh_3)_2}$ 的配合物，其中 C–C 距离接近单键。(a) 用 Dewar–Chatt–Duncanson 模型解释这一趋势。(b) 沿着这个序列，你预期烯烃碳的 $^{13}\mathrm{C}$ NMR 化学位移以及 C–H（或 C–F）键与 C–C 轴的夹角如何变化？(c) 若把第三个配合物描述为金属环丙烷，铂的形式氧化态是多少？价电子数是否改变？
::: solution
(a) 在 Zeise 盐阴离子中铂是 Pt(II)、$d^8$，带三个 π 给予的氯，负电荷散布在一个收缩得比较紧的金属上：来自乙烯的 σ 给予占主导、反馈很弱，所以 C=C 键只从 $1.337\ \text{Å}$ 略为伸长。在 $\mathrm{[Pt(C_2H_4)(PPh_3)_2]}$ 中金属是 Pt(0)、$d^{10}$，配有两个强 σ 给予的膦：其满 $d$ 轨道能量高，向乙烯 $\pi^*$ 轨道强烈反馈，使 C=C 伸长到 $1.43\ \text{Å}$。四氟乙烯的 $\pi^*$ 轨道低得多（氟强烈吸电子），因此接受更多的反馈，C–C 键逼近单键：金属环丙烷极限。

(b) 随着反馈增大，烯烃碳由 $sp^2$ 向 $sp^3$ 再杂化。它们的 $^{13}\mathrm{C}$ 信号明显移向低化学位移（高场，朝 $sp^3$ 碳的区域），取代基向远离金属的方向弯折，于是 C–H（C–F）键与 C–C 轴的夹角从约 $120^\circ$ 减小、趋向四面体的 $109.5^\circ$——取代基不再与 C–C 键共面。

(c) 作为金属环丙烷，$\mathrm{C_2F_4}$ 单元是一个双阴离子 X₂ 配体，形成两根 Pt–C σ 键，所以铂形式上是 Pt(II)、$d^8$，而不是 Pt(0)。价电子数不变：共价法中 L 配体给 2 个电子，X₂ 配体给 $1 + 1 = 2$ 个，故 $\mathrm{VE} = 10 + 4 + 2 = 16$，两种描述都一样。两种描述是同一连续统的两个极限；形式氧化态随描述而变，电子数不变。
:::
