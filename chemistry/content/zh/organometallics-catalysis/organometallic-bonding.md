1827 年，丹麦药剂师 William Christopher Zeise 把四氯化铂与乙醇一起煮沸，加入氯化钾，得到了黄色晶体，其中含有一个与铂结合的乙烯分子：$\mathrm{K[PtCl_3(C_2H_4)]\cdot H_2O}$，Zeise 盐。没有人说得清，一个饱和的金属离子如何能在不毁掉不饱和烃的前提下把它握住；这个问题等了 125 年才等到答案。今天，带金属-碳键的化合物以吨计地生产：每一只聚乙烯瓶都是在钛或铬的烷基上生长出来的，几乎每个现代候选药物都要经过钯-芳基中间体，工业食醋里的乙酸则是由甲醇在铑或铱的甲基配合物上制成的。本课程讲述这些化合物如何构建、有何作为，以及它们的基元反应如何组合成催化循环。

这第一章提供记账法。我们要问：什么是金属有机化合物？它的金属-碳键有多强的极性？——最重要的是——如何**统计过渡金属周围的电子数**，使我们能预言哪些配合物稳定、哪些有反应性、哪些空着一个位置等待底物。计数立足于 [[coordination-chemistry/ligand-field-mo]]的分子轨道图像，18 电子规则就是在那里针对八面体羰基化合物引入的；这里我们把它推广到烷基、氢化物、烯丙基、环戊二烯基、芳烃与金属团簇，并弄清它在哪些地方失灵。

## 金属-碳键

::: definition 金属有机化合物 {#def-organometallic}
**金属有机化合物**至少含有一根金属（按惯例也包括硼或硅这样的类金属）与有机基团碳原子之间的直接键合。金属羰基化合物如 $\mathrm{[Ni(CO)_4]}$ 与氰根配合物有 M–C 键，通常算作金属有机化合物；金属醇盐 $\mathrm{M{-}OR}$ 与胺配合物则不是，它们的有机基团是经氧或氮连接的。配体中与金属键合的连续原子数为**齿合数**，记作 $\eta^n$（"eta-$n$"）：侧基结合乙烯为 $\eta^2$，三个碳全部键合的烯丙基为 $\eta^3$，五个碳全部键合的平面环戊二烯环为 $\eta^5$。桥连 $k$ 个金属原子的配体写作 $\mu_k$（桥连两个时简写作 $\mu$）。
:::

金属-碳键跨越从近乎离子到近乎共价的全部范围，其极性几乎控制着它化学性质的方方面面。碳的鲍林电负性为 $2.55$；锂为 $0.98$，镁 $1.31$，锌 $1.65$，硼 $2.04$，硅 $1.90$，钯 $2.20$，铂 $2.28$。每一种情形中碳都是键的负端，所以金属有机基团的行为相当于*碳负离子等价体*：它是亲核试剂，也是碱。鲍林关于电负性差为 $\Delta\chi$ 的两原子间键的离子性的经验公式，
$$
\text{离子性} = 1 - e^{-(\Delta\chi)^2/4},
$$ {#eq-pauling-ionic}
虽粗糙，却把这些试剂排对了序：C–Li 约 $46\,\%$，C–Mg $32\,\%$，C–Al $20\,\%$，C–Zn $18\,\%$，C–Si $10\,\%$，C–B $6\,\%$，而 C–Pd 只有 $3\,\%$。有机锂试剂进攻几乎所有亲电试剂，包括盛装它们的醚类溶剂；格氏试剂加成到酮上，但在低温下不加成到多数酯上；有机锌与有机硼化合物非要有催化剂或活化剂不可，否则根本不跟羰基反应；四甲基硅烷惰性到可用作 NMR 波谱的参考物质。这一趋势的专题是 [[organometallics-catalysis/main-group-organometallics]]。

### 热力学稳定性与动力学稳定性

对主族元素来说，M–C 键沿族向下变弱。第 14 族四甲基化物的平均键焓大致为 $358$（C–C，在新戊烷中）、$311$（Si–C）、$249$（Ge–C）、$217$（Sn–C）与 $152\ \mathrm{kJ\,mol^{-1}}$（Pb–C）（数值取自 Elschenbroich 所著 *Organometallics* 的汇编）：重原子更大、更弥散的价轨道与碳 $2sp^3$ 的重叠变差。四乙基铅曾被用作抗爆剂，恰恰是因为其较弱的 Pb–C 键在发动机中断裂、生成乙基自由基。对过渡金属，趋势反转——$5d$ 金属形成的 M–C（以及 M–H）键比 $3d$ 金属的更强——因为 $5d$ 轨道更伸展、重叠更好；这是相对论效应导致的轨道膨胀的结果，它同时也解释了为什么铂与铱的配合物常常可以分离，而镍与钴的类似物却不能。

多年间人们相信过渡金属烷基是*热力学*不稳定的，因为能分离出来的简单烷基少之又少：$\mathrm{Ti(CH_2CH_3)_4}$ 无法分离，四甲基钛在远低于室温时就分解。Geoffrey Wilkinson 课题组在 1970 年代初证明，问题出在*动力学*上。典型的 M–C 键焓（约 $150$–$300\ \mathrm{kJ\,mol^{-1}}$）与主族烷基的相当；毁掉大多数过渡金属烷基的是一条容易的低能量分解路径，尤其是 **β-氢消除**（[[organometallics-catalysis/elementary-reactions]]）：金属 β 位碳上的氢转移到金属的一个空位上，释放出烯烃。没有 β-氢的烷基——甲基、苄基、新戊基 $\mathrm{CH_2C(CH_3)_3}$、（三甲基硅基）甲基 $\mathrm{CH_2Si(CH_3)_3}$——或 β-氢够不到金属的烷基，要坚固得多：六甲基钨 $\mathrm{[W(CH_3)_6]}$ 由 Shortland 与 Wilkinson 于 1973 年制得，四苄基锆已是商品试剂。在金属有机化学里，稳定几乎总是意味着*没有便宜的路径可走*，而不是热力学深井。

::: warning "稳定"通常指动力学稳定 {#warn-stability}
把化合物可以分离，读作关于键强度的一种陈述，是人之常情。对金属有机化合物而言这通常是错的。二乙基锌与三甲基铝的 M–C 键相当体面，它们却遇空气即燃，因为氧化为金属氧化物与二氧化碳是强放能的，且能垒很低。六甲基钨在室温下尚能存在，不是因为 W–C 键强，而是因为甲基没有可消除的 β-氢。每当遇到某化合物"稳定"的说法，都要问：对什么稳定（热、空气、水、光）？这种稳定是热力学的还是动力学的？
:::

## 配体作为 L、X 与 Z：共价键分类

要数电子，就需要一套一致的说法来标明每个配体带来几个电子。常用的有两套方案，只要各自一贯地使用，它们给出的总数相同。

::: definition L、X 与 Z 配体 {#def-lxz}
在**共价键分类**（Malcolm Green，1995）中，每一段金属-配体相互作用都按*中性*配体对键贡献的电子数归入三类之一：

- **L** 配体把一对孤对电子（或成键电子对）给到金属：二电子配键，$\mathrm{M \leftarrow L}$。例：$\mathrm{CO}$、$\mathrm{PR_3}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$、$\eta^2$-烯烃、二氢配合物中的 $\mathrm{H_2}$、N-杂环卡宾。
- **X** 配体在中性时是一电子自由基，与金属形成正常的二电子共价键，金属与配体各出一个电子：$\mathrm{H}$、$\mathrm{CH_3}$、$\mathrm{Ph}$、$\mathrm{Cl}$、$\mathrm{OR}$、$\eta^1$-烯丙基、酰基 $\mathrm{C(O)R}$。
- **Z** 配体是接受*来自*金属的一对电子的路易斯酸：$\mathrm{BR_3}$、$\mathrm{AlCl_3}$。Z 配体少见，不给计数增加电子。

多齿合配体是组合：$\eta^3$-烯丙基为 **LX**（三电子），$\eta^5$-环戊二烯基 $\mathrm{C_5H_5}$（Cp）为 **L₂X**（五电子），$\eta^6$-苯为 **L₃**（六电子），$\eta^4$-二烯为 **L₂**（四电子）。直线型亚硝酰 $\mathrm{M{-}N{\equiv}O}$ 的行为如 **LX**（三电子），弯曲型亚硝酰如 **X**（一电子）。
:::

另一套**离子法**则设想每个 X 配体以闭壳层阴离子的形式被移去——氢化物 $\mathrm{H^-}$、甲基负离子 $\mathrm{CH_3^-}$、氯离子 $\mathrm{Cl^-}$、环戊二烯负离子 $\mathrm{C_5H_5^-}$（芳性的六 π 电子阴离子）——各给金属*两个*电子，金属则留下相应的正氧化态。这是 [[coordination-chemistry/ligand-field-mo]]计数算法所用的方法，优点是直接给出氧化态与 $d^n$ 组态。共价法更快，还免去判断例如 NO 究竟是 $\mathrm{NO^+}$ 还是 $\mathrm{NO^-}$。两种方法建立在同样四个量之上。

::: definition 价电子数、氧化态、$d^n$ 与配位数 {#def-counts}
对处于周期表第 $g$ 族的金属（中性金属原子有 $g$ 个价电子：Cr、Mo、W 为 $g = 6$；Fe、Ru、Os 为 $8$；Ni、Pd、Pt 为 $10$）构成的配合物 $\mathrm{[M L_\ell X_x]^{q}}$，有 $\ell$ 个 L 型与 $x$ 个 X 型相互作用、总电荷为 $q$：

- **价电子数** $\mathrm{VE} = g + 2\ell + x - q$；
- **氧化态** $\mathrm{OS} = x + q$；
- **$d$ 电子数** $n = g - \mathrm{OS}$，给出组态 $d^n$；
- **配位数** $\mathrm{CN} = \ell + x$，数每一个 L 与 X 相互作用（故 $\eta^5$-Cp 贡献 3，$\eta^6$-苯贡献 3）。

每一根金属-金属键为它所连接的*每个*金属的电子计数加 1（两金属共享一对共价电子，故按惯例每一方都看作另一方的 X 配体，而不改变氧化态）。
:::

::: proposition 离子法与共价法的计数一致 {#prop-count-agree}
对任何配合物 $\mathrm{[ML_\ell X_x]^q}$，用离子法计数（X 配体作二电子阴离子，金属处于氧化态 $x + q$）得到的价电子数与共价法的 $\mathrm{VE} = g + 2\ell + x - q$ 相同。
:::

::: proof
离子法中，每个 X 配体都以 $\mathrm{X^-}$ 的形式被移去，并从金属带走一个电子。总电荷为 $q$ 的配合物因此含有一个电荷为 $x + q$的金属离子，这就是氧化态。该离子有 $g - (x + q)$ 个价电子，对过渡金属而言全部是 $d$ 电子（离子中 $(n+1)s$ 能级位于 $(n)d$ 之上）。配体则各给两个电子：L 配体给 $2\ell$，阴离子 $\mathrm{X^-}$ 给 $2x$。总数为
$$
\mathrm{VE}_\text{离子} = \big[g - (x + q)\big] + 2\ell + 2x = g + 2\ell + x - q = \mathrm{VE}_\text{共价}.
$$
两种方法只差在说每一根 M–X 键的电子"属于"哪一方；金属价层中的总数是分子的性质，而不是记账方式的性质。同样的代数说明 $n = g - \mathrm{OS}$ 正是把每一根 M–X 键都划归配体之后，留在金属上的非键（或 π 成键）$d$ 电子数。
:::

::: algorithm 共价法（中性配体法）的电子计数 {#alg-covalent-count}
1. 写出金属的族号 $g$（中性原子时的价电子数）。
2. 按[[#def-lxz]]把每个配体归入 L、X 或组合（LX、L₂X、L₃ …）；数出 $\ell$ 与 $x$。
3. 每根金属-金属键加 1 个电子。
4. 减去总电荷：$\mathrm{VE} = g + 2\ell + x - q$（再加上金属-金属键的电子）。
5. 求 $\mathrm{OS} = x + q$ 与 $d^n$（$n = g - \mathrm{OS}$）；检查氧化态化学上是否合理。
6. 把 $\mathrm{VE}$ 与 18 比较（平面正方形 $d^8$ 则与 16 比较，[[#prop-16-18]]）：计数偏低预示配位不饱和、有潜在反应性的配合物。
:::

::: example 六个计数 {#ex-six-counts}
数出下列配合物的价电子数，并给出氧化态与 $d^n$：(a) $\mathrm{[Fe(\eta^5\text{-}C_5H_5)(CO)_2(CH_3)]}$；(b) $\mathrm{[RhCl(PPh_3)_3]}$（Wilkinson 催化剂）；(c) $\mathrm{[Ti(\eta^5\text{-}C_5H_5)_2Cl_2]}$；(d) $\mathrm{[IrCl(CO)(PPh_3)_2]}$（Vaska 配合物）；(e) $\mathrm{[W(CH_3)_6]}$；(f) 二茂钴鎓离子 $\mathrm{[Co(\eta^5\text{-}C_5H_5)_2]^+}$。
::: solution
用 $\mathrm{VE} = g + 2\ell + x - q$ 与 $\mathrm{OS} = x + q$。

(a) Fe，$g = 8$。Cp 是 L₂X；两个 CO 是 L；$\mathrm{CH_3}$ 是 X。故 $\ell = 4$，$x = 2$，$q = 0$：$\mathrm{VE} = 8 + 8 + 2 = 18$。$\mathrm{OS} = +2$，$d^6$。这个 "FpMe" 配合物是经典的空气稳定 18 电子烷基配合物。

(b) Rh，$g = 9$；三个 $\mathrm{PPh_3}$（L），一个 Cl（X）：$\mathrm{VE} = 9 + 6 + 1 = 16$。Rh(I)，$d^8$，平面正方形：16 电子配合物，正与 $d^8$ 的预期相符。

(c) Ti，$g = 4$；两个 Cp（各为 L₂X）与两个 Cl：$\ell = 4$，$x = 4$，$\mathrm{VE} = 4 + 8 + 4 = 16$。Ti(IV)，$d^0$。高氧化态的早过渡金属常常不足 18 电子：没有 $d$ 电子去填满剩下的轨道，空间拥挤又妨碍更多配体结合。

(d) Ir，$g = 9$；CO 与两个 $\mathrm{PPh_3}$（L），Cl（X）：$\mathrm{VE} = 9 + 6 + 1 = 16$。Ir(I)，$d^8$，平面正方形。

(e) W，$g = 6$；六个 $\mathrm{CH_3}$（X）：$\mathrm{VE} = 6 + 6 = 12$。W(VI)，$d^0$。一个 12 电子配合物，之所以能存在，是因为它的配体没有一个带 β-氢（[[#warn-stability]]）。

(f) Co，$g = 9$；两个 Cp：$\ell = 4$，$x = 2$，$q = +1$：$\mathrm{VE} = 9 + 8 + 2 - 1 = 18$。Co(III)，$d^6$。中性的二茂钴有 19 个电子，是强还原剂，恰恰因为失去一个电子就得到这个 18 电子阳离子。
:::
:::

::: warning 氧化态是形式性的 {#warn-formal-os}
氧化态是由[[#def-counts]]定义的记账工具，不是金属上的电荷。在 $\mathrm{[W(CH_3)_6]}$ 中钨是 "W(VI)"，但分子里绝没有 $\mathrm{W^{6+}}$ 离子那样的东西：W–C 键几乎是非极性的，算出来的钨原子电荷也很小。同样，$\mathrm{[Fe(CO)_4]^{2-}}$ 中的 "Fe(−II)" 并不意味铁带着两个负电荷——大部分电荷经反馈作用分散到了羰基氧上。把形式氧化态与 $d^n$ 计数用在它们擅长的地方：预言磁性、几何构型以及哪些基元反应可以发生（$d^0$ 金属不能发生氧化加成）。不要用它估算电荷，也不要在同一次计数中混用离子法与共价法（把 Cp 算作五个电子*同时*又让金属取离子氧化态，就会把一个电子重复计入）。
:::

## 为什么是十八？规则及其例外

主族的八隅律有一个过渡金属的对应版本。过渡金属原子有九个价轨道——一个 $(n+1)s$、三个 $(n+1)p$ 与五个 $nd$——正如八隅体填满第二周期原子的四个 $s$ 与 $p$ 轨道那样，十八个电子填满全部九个。

::: proposition 18 电子规则（经验性） {#prop-18e-general}
第 6–10 族带强 σ 给予体与 π 接受体配体（CO、膦、烯烃、Cp、芳烃、氢化物、烷基）的低价过渡金属的稳定可分离配合物，价电子数通常为 **18**。电子数少的配合物**配位不饱和**，倾向于继续结合配体；电子数多的配合物倾向于失去一个配体或一个电子。这条规则是**经验性的**：它是一条有分子轨道理由支撑的观测规律，并有许多已被充分理解的例外。
:::

::: proof 分子轨道理由
设金属经每个 σ 给予轨道结合 $m$ 个配体（$m \le 9$）。$m$ 个配体轨道与九个金属价轨道中的 $m$ 个组合，给出 $m$ 条成键与 $m$ 条反键分子轨道；对良好的 σ 给予体，成键 MO 能量低，反键 MO 能量高。剩下的 $9 - m$ 个金属轨道没有 σ 伙伴，是**非键**的——八面体配合物中就是那三个 $t_{2g}$ 轨道（$m = 6$，$9 - m = 3$）。若配体是 π 接受体，这些非键轨道便与空的配体 $\pi^*$ 轨道重叠，能量*降低*，成为弱成键。于是低能级就是 $m$ 条 σ 成键 MO 与 $9 - m$ 条非键或 π 成键 MO：共 $m + (9 - m) = 9$ 条轨道，容纳
$$
2m + 2(9 - m) = 18
$$
个电子，与 $m$ 无关。电子少了，就留下空的低能轨道（供进入配体的孤对落座）；电子多了，就必须占据 σ 反键轨道，削弱金属-配体键、有利于失配体。当某个"非键"轨道被推得很高（下一条命题），或 σ 反键轨道并不够高（水、卤离子这类弱场配体，计数从 12 到 22 都常见，见 [[coordination-chemistry/ligand-field-mo]]），或金属电正性太强、$d$ 轨道太高以至于配体根本挤不下（早过渡金属、镧系）时，这一论证失效。
:::

::: proposition 平面正方形 $d^8$ 配合物的 16 电子规则（经验性） {#prop-16-18}
$d^8$ 金属——Rh(I)、Ir(I)、Ni(II)、Pd(II)、Pt(II)、Au(III)——的平面正方形配合物以 **16** 价电子为稳定。Tolman 的"16 与 18 电子规则"（1972）指出：过渡金属的抗磁性金属有机配合物只有具备 16 或 18 个价电子时才以显著浓度存在，且其基元反应经由 16 或 18 电子的中间体进行。与它的母规则一样，这是一条经验性概括。
:::

::: proof 理由
平面正方形配合物（$m = 4$）中，四个 σ 给予轨道沿 $\pm x$ 与 $\pm y$ 方向。金属的 $s$、$p_x$、$p_y$ 与 $d_{x^2-y^2}$ 轨道用于 σ 成键；$d_{xy}$、$d_{xz}$、$d_{yz}$ 与 $d_{z^2}$ 轨道非键（或 π 成键），容纳八个 $d$ 电子。第九个价轨道 $p_z$ 垂直于平面，没有配体与之重叠，而且作为 $(n+1)p$ 轨道远高于 $d$ 组。因此它实际上*不是*低能轨道：可用的低能轨道只有八条，容纳 $2 \times 8 = 16$ 个电子。空的 $p_z$ 恰是第五个配体进攻平面正方形配合物时所利用的轨道——这就是 16 电子 $d^8$ 配合物既稳定又有反应性的原因，催化剂需要的正是这种组合。
:::

16/18 交替是均相催化的节律。16 电子配合物结合底物变成 18 电子；18 电子配合物失去一个配体腾出空位。下表列出遵守与无视这些规则的各家族。

| 配合物 | VE | 评注 |
|---|---|---|
| $\mathrm{[Cr(CO)_6]}$、$\mathrm{[Fe(CO)_5]}$、$\mathrm{[Ni(CO)_4]}$ | 18 | 偶数族金属的二元羰基 |
| $\mathrm{[Fe(\eta^5\text{-}C_5H_5)_2]}$、$\mathrm{[Cr(\eta^6\text{-}C_6H_6)_2]}$ | 18 | 二茂铁、二苯铬 |
| $\mathrm{[Mn_2(CO)_{10}]}$、$\mathrm{[Co_2(CO)_8]}$ | 每个金属 18 | 奇电子片段经 M–M 键两两配对 |
| $\mathrm{[V(CO)_6]}$ | 17 | 顺磁性；拥挤得无法二聚 |
| $\mathrm{[Co(\eta^5\text{-}C_5H_5)_2]}$、$\mathrm{[Ni(\eta^5\text{-}C_5H_5)_2]}$ | 19、20 | 电子进入反键轨道；易被氧化 |
| $\mathrm{[RhCl(PPh_3)_3]}$、$\mathrm{[PtCl_4]^{2-}}$ | 16 | 平面正方形 $d^8$ |
| $\mathrm{[Ti(\eta^5\text{-}C_5H_5)_2Cl_2]}$、$\mathrm{[W(CH_3)_6]}$ | 16、12 | $d^0$ 早金属：电子太少、空间太小 |

## 多齿合配体与齿合数变化

烃类配体能改变与金属键合的原子数，而齿合数的每一次改变都是电子计数的改变。这一灵活性是金属有机化学中反应性最重要的来源之一：配体从 $\eta^5$"滑"到 $\eta^3$，不离开就把金属上相当于两个电子的空间腾了出来。

| 配体 | 键合方式 | 类别 | 电子数（共价法） | 电子数（离子法，按阴离子或中性计） |
|---|---|---|---|---|
| 烷基、芳基、H、Cl | $\eta^1$ | X | 1 | 2（$\mathrm{R^-}$、$\mathrm{H^-}$、$\mathrm{Cl^-}$） |
| CO、$\mathrm{PR_3}$、烯烃 | $\eta^1$ / $\eta^2$ | L | 2 | 2 |
| 烯丙基 $\mathrm{C_3H_5}$ | $\eta^1$ / $\eta^3$ | X / LX | 1 / 3 | 2 / 4（$\mathrm{C_3H_5^-}$） |
| 丁二烯 | $\eta^4$ | L₂ | 4 | 4 |
| 环戊二烯基 | $\eta^5$ | L₂X | 5 | 6（$\mathrm{C_5H_5^-}$） |
| 苯 | $\eta^6$ | L₃ | 6 | 6 |
| 环庚三烯基 $\mathrm{C_7H_7}$ | $\eta^7$ | L₃X | 7 | 6（$\mathrm{C_7H_7^+}$） |
| 亚硝酰，直线型 / 弯曲型 | $\eta^1$ | LX / X | 3 / 1 | 2（$\mathrm{NO^+}$）/ 2（$\mathrm{NO^-}$） |

::: example 烯丙基配体改变齿合数 {#ex-allyl-slip}
五羰基锰酸钠 $\mathrm{Na[Mn(CO)_5]}$ 与烯丙基氯反应生成 $\mathrm{[Mn(\eta^1\text{-}C_3H_5)(CO)_5]}$。微微加热，它便失去一分子 CO，得到 $\mathrm{[Mn(\eta^3\text{-}C_3H_5)(CO)_4]}$。数出两个配合物的电子数，并解释为什么失去 CO。
::: solution
在 $\mathrm{[Mn(\eta^1\text{-}C_3H_5)(CO)_5]}$ 中，烯丙基只经其 $\mathrm{CH_2}$ 碳键合，作 X 配体；它的 $\mathrm{C{=}C}$ 双键游离在外。Mn 的 $g = 7$：$\mathrm{VE} = 7 + 5\times 2 + 1 = 18$，Mn(I)，$d^6$。加热时一分子 CO 解离，留下 16 电子的 $\mathrm{[Mn(\eta^1\text{-}C_3H_5)(CO)_4]}$；悬垂的双键摆进来占据空位，把烯丙基从 X 变成 LX。产物的 $\mathrm{VE} = 7 + 4 \times 2 + 3 = 18$ 依旧，仍是 Mn(I)。η¹ → η³ 的转化由熵驱动（一分子变成两分子，且 CO 以气体逸出），也由这个三碳配体类螯合物的稳定性驱动。两种配合物可由 $^{1}\mathrm{H}$ NMR 区分：η¹-烯丙基显示一个乙烯基，η³-烯丙基则显示一个中心 CH 与两两成端的质子，分别与中心氢呈 *syn* 与 *anti*。
:::
:::

同样的逻辑解释了著名的**茚基效应**。茚基配体是一个并合了苯环的环戊二烯环，它比 Cp 容易得多地从 $\eta^5$ 滑到 $\eta^3$，因为在 $\eta^3$ 形态下苯环重新获得完整的芳性。于是 $\mathrm{[Rh(\eta^5\text{-}C_9H_7)(CO)_2]}$ 这类配合物经缔合机理置换 CO——进入的配体在环滑动的同时结合，计数保持 18——且比它的 Cp 类似物快好几个数量级。我们在 [[organometallics-catalysis/elementary-reactions]]中还要回到它。

## σ 给予体、π 接受体与协同键

上表中的配体满足金属的能力并不相同。只给予的配体——$\mathrm{NH_3}$、$\mathrm{H_2O}$、烷基、氢化物——是 **σ 给予体**。CO、异腈 $\mathrm{CNR}$、膦、烯烃与芳烃这类配体既是 σ 给予体*又是* **π 接受体**：除把一对电子给入金属的空 σ 轨道外，它们还有 π 对称的空轨道（CO 与烯烃的 $\pi^*$、膦的 P–C $\sigma^*$），从满的金属 $d$ 轨道接受电子密度。两种相互作用彼此增强。σ 给予使金属富电子，从而成为更好的 π 给予体；π 反馈移走 σ 给予堆积在低价金属上的电荷，使金属能接受更多 σ 密度。这种**协同**键——Michael Dewar（1951 年）以及 Joseph Chatt 与 Leonard Duncanson（1953 年）针对烯烃的首次描述——正是让 0 甚至负氧化态的金属——$\mathrm{[Ni(CO)_4]}$ 中的 $\mathrm{Ni(0)}$、$\mathrm{[Fe(CO)_4]^{2-}}$ 中的 $\mathrm{Fe(-II)}$——得以存在的原因。

反馈也正是 18 电子规则对 π 接受体配体最为灵验的原因：反馈把[[#prop-18e-general]]证明中那 $9 - m$ 条"非键"轨道压低，使之成为真正的成键轨道，并拉大它们与上方能级的间隙。细节——红外特征、Tolman 的电子与空间参数、烯烃结合方式的金属环丙烷极限、Fischer 与 Schrock 卡宾——是 [[organometallics-catalysis/ligands-complexes]]的主题。

## 金属-金属键与团簇

奇电子片段可以通过彼此共享电子达到 18。两个 17 电子的 $\mathrm{Mn(CO)_5}$ 片段结合成 $\mathrm{[Mn_2(CO)_{10}]}$，带一根无桥的 Mn–Mn 键；两个 17 电子的 $\mathrm{Co(CO)_4}$ 片段给出 $\mathrm{[Co_2(CO)_8]}$。更大的聚集体——**团簇**——遵循同样的逻辑，至少在它们还小的时候如此。

::: proposition 遵守 18 电子规则的团簇中的金属-金属键 {#prop-mm-bonds}
设团簇含 $N$ 个金属原子、总价电子数为 $V$（各金属族数之和，加上配体电子，减去电荷，不计金属-金属键），若每个金属都靠形成二中心二电子金属-金属键达到 18 电子，则这种键的数目为
$$
B = \frac{18N - V}{2}.
$$ {#eq-mm-bonds}
:::

::: proof
每根金属-金属键都是一对共享电子。逐个金属计数时，金属 $i$ 与 $j$ 之间的一根键给 $i$ 的计数加 1、给 $j$ 的计数加 1（[[#def-counts]]），所以对所有金属求和时，每根键给总数加 $2$。若每个金属都有 18，各计数之和就是 $18N$；它等于不计金属-金属键时已有的电子 $V$ 加上 $2B$。于是 $18N = V + 2B$，$B = (18N - V)/2$。推导假定定域的二中心键、且每个金属恰好达到 18——对至多四五个金属的团簇这是合理的，对更大的、离域的团簇则失效。
:::

::: example 由电子计数定团簇骨架 {#ex-clusters}
预言下列团簇的金属-金属键数目与金属骨架：(a) $\mathrm{[Fe_3(CO)_{12}]}$，(b) $\mathrm{[Co_4(CO)_{12}]}$ 与 (c) $\mathrm{[Rh_6(CO)_{16}]}$（X 射线衍射已知其六个铑原子构成八面体）。
::: solution
(a) $V = 3 \times 8 + 12 \times 2 = 48$；$B = (54 - 48)/2 = 3$。三个金属以三根键相连构成**三角形**，与观测一致（十二个羰基中有两个在固体中桥在一根 Fe–Fe 棱上；计数不变，因为桥连 CO 仍是两金属共享的二电子 L 配体）。

(b) $V = 4 \times 9 + 24 = 60$；$B = (72 - 60)/2 = 6$。四个原子以六根键相连：两两成键，构成**四面体**，与观测一致。

(c) $V = 6 \times 9 + 16 \times 2 = 86$；$B = (108 - 86)/2 = 11$。可八面体有 **12** 条棱，条条都是 Rh–Rh 成键距离。定域键计数失效。大团簇最好用离域的骨架成键来描述，就像 [[main-group/groups-13-14]]中的硼烷：**多面体骨架电子对理论**（Wade–Mingos 规则）预言过渡金属的*闭式*（closo）八面体团簇有 $14N + 2 = 86$ 个价电子——恰是实际测得的计数。18 电子规则是单核配合物与小团簇的工具，它在这里的失效是信息而非错误：它告诉我们成键已经离域。
:::
:::

### 等瓣相似类比

Roald Hoffmann 的**等瓣相似类比**（诺贝尔演讲，1982）把金属有机片段与有机片段连接起来。若两个片段的前线轨道数目、对称性、能量与形状大体相同，且含有相同数目的电子，它们便是**等瓣相似**的。甲基自由基 $\mathrm{CH_3}$ 有一个单占据、类似 $sp^3$ 的轨道，背向氢原子；它离八隅体差一个电子。片段 $\mathrm{Mn(CO)_5}$——少了一个配体的八面体——有一个单占据的杂化轨道指向空位，离 18 电子差一个。它们等瓣相似，写作 $\mathrm{CH_3} \leftrightarrow \mathrm{Mn(CO)_5}$；事实上两者都二聚（乙烷；$\mathrm{[Mn_2(CO)_{10}]}$），也都形成 $\mathrm{H{-}CH_3}$ / $\mathrm{H{-}Mn(CO)_5}$ 和混搭的 $\mathrm{CH_3{-}Mn(CO)_5}$。同样地，$\mathrm{CH_2} \leftrightarrow \mathrm{Fe(CO)_4}$（两个轨道、差两个电子），$\mathrm{CH} \leftrightarrow \mathrm{Co(CO)_3}$（三个轨道、差三个电子）。经验法则：离 18 差 $k$ 个电子的片段，行为就像离 8 差 $k$ 个电子的有机片段。

::: example 一个金属有机四面体烷 {#ex-isolobal}
团簇 $\mathrm{[Co_3(CO)_9(\mu_3\text{-}CCH_3)]}$ 含一个钴原子三角形，其一个面上被 $\mathrm{C{-}CH_3}$ 基团盖住。试证它与四面体烷 $\mathrm{C_4H_4}$（就其四甲基衍生物而言）等瓣相似，并核验每个钴的电子数。
::: solution
每个 $\mathrm{Co(CO)_3}$ 片段有 $9 + 6 = 15$ 个电子，离 18 差三，带三条前线轨道：与 $\mathrm{CH}$ 等瓣相似——后者有五个电子，离八隅体差三。盖顶基团 $\mathrm{C{-}CH_3}$ 本身就是一个 CR 片段，有三条前线轨道。把四面体烷的三个 CH（或 CR）顶点换成三个 $\mathrm{Co(CO)_3}$ 顶点，便得到 $\mathrm{[Co_3(CO)_9(CR)]}$——一个带三个金属角的"四面体烷"。核验：每个钴有 $9 + 3\times2$（CO）$+ 2$（两根 Co–Co 键）$+ 1$（与盖顶碳的一根键）$= 18$。盖顶碳与钴成三根键、与 $\mathrm{CH_3}$ 成一根，共四根，就像任何 $sp^3$ 碳一样。这一类比由有机化学预言了团簇的结构；同样的推理说明为什么 $\mathrm{[Co_4(CO)_{12}]}$（四个 $\mathrm{Co(CO)_3}$ 顶点）像 $\mathrm{C_4R_4}$ 一样是四面体。
:::
:::

::: history
Zeise 盐（1827）是第一个过渡金属的金属有机化合物；Frankland（Edward Frankland）的二乙基锌（1849）诞生于他试图分离"乙基自由基"的过程中，是第一个主族烷基；Frankland 创造了金属有机（organometallic）一词，并从这些化合物中提炼出化合价的概念。Mond（Ludwig Mond）、Langer（Carl Langer）与 Quincke（Friedrich Quincke）于 1890 年在一氧化碳侵蚀镍制阀门时发现了四羰基镍，Mond 把 $\mathrm{[Ni(CO)_4]}$ 的挥发性变成了精炼镍的工艺。Langmuir（Irving Langmuir）于 1921 年指出，稳定的羰基化合物让金属拥有下一个稀有气体的电子数，Sidgwick（Nevil Sidgwick）的"有效原子序数"规则（1927）把这一观察推广开来。这门现代学科始于二茂铁：Kealy（Thomas Kealy）与 Pauson（Peter Pauson）于 1951 年在 *Nature* 上报道了 $\mathrm{Fe(C_5H_5)_2}$（Miller（Samuel Miller）、Tebboth（John Tebboth）与 Tremaine（John Tremaine）于 1952 年独立报道），1952 年 Wilkinson（Geoffrey Wilkinson）、Rosenblum（Myron Rosenblum）、Whiting（Mark Whiting）与 Woodward（Robert Woodward），以及独立地 Fischer（Ernst Otto Fischer）与 Pfab（Wolfgang Pfab），提出了夹心结构。Fischer 与 Wilkinson 分享 1973 年诺贝尔化学奖。Tolman（Chadwick Tolman）于 1972 年提出 16 与 18 电子规则，Hoffmann（Roald Hoffmann）在 1982 年诺贝尔演讲中阐述了等瓣相似类比，Green（Malcolm Green）于 1995 年发表了共价键分类。
:::

::: summary
- M–C 键向碳一端极化；其离子性从 Li、Mg 经 Zn、B 一路降到后过渡金属，亲核反应性随之下降。
- 许多过渡金属烷基因 β-氢消除而*动力学*不稳定；没有 β-氢的烷基（$\mathrm{CH_3}$、$\mathrm{CH_2Ph}$、$\mathrm{CH_2CMe_3}$、$\mathrm{CH_2SiMe_3}$）则坚固。
- 配体分为 L（二电子给予体）、X（一电子、类自由基）与 Z（接受体）；多齿合配体由它们组合而成（η³-烯丙基 LX、η⁵-Cp L₂X、η⁶-芳烃 L₃）。
- 对 $\mathrm{[ML_\ell X_x]^q}$：$\mathrm{VE} = g + 2\ell + x - q$，$\mathrm{OS} = x + q$，$d^n$ 中 $n = g - \mathrm{OS}$；两种计数只要各自一贯地使用就彼此一致。
- 18 电子规则（平面正方形 $d^8$ 为 16）是经验规则，可用九条低能价轨道（$p_z$ 用不上时只有八条）给出理由；它对带 π 接受体配体的低价金属灵验，对 $d^0$ 早金属、弱场配合物与大团簇失效。
- 齿合数改变（烯丙基 η¹ ⇌ η³、茚基 η⁵ ⇌ η³）改变电子计数，并在不丢配体的情况下打开配位位置。
- 小团簇中 M–M 键数为 $(18N - V)/2$；等瓣相似片段（$\mathrm{CH_3} \leftrightarrow \mathrm{Mn(CO)_5}$、$\mathrm{CH} \leftrightarrow \mathrm{Co(CO)_3}$）让有机结构来预言金属有机结构。
:::

数出 $\mathrm{[Ni(\eta^3\text{-}C_3H_5)_2]}$ 的价电子数。（输入价电子数。）
::: solution

::: exercise 九氢合铼酸根离子 {level=1 check="7"}
离子 $\mathrm{[ReH_9]^{2-}}$ 有九个氢化物配体。求铼的氧化态与价电子数。（输入 Re 的氧化态。）
::: solution
Re 在第 7 族。$x = 9$、$q = -2$：$\mathrm{OS} = x + q = 9 - 2 = +7$，即 Re(VII)，$d^0$。$\mathrm{VE} = 7 + 9 - (-2) = 18$。九配位的 18 电子配合物：九个金属价轨道全部用于与氢的 σ 键，即[[#prop-18e-general]]证明中 $m = 9$ 的极限情形。
:::

::: exercise C–Al 键的离子性 {level=1 check="20"}
用鲍林电负性 $\chi(\mathrm{C}) = 2.55$、$\chi(\mathrm{Al}) = 1.61$ 与[[#eq-pauling-ionic]]，估算三甲基铝中 Al–C 键的离子性百分数。（百分数保留两位有效数字。）
::: solution
$\Delta\chi = 0.94$，$(\Delta\chi)^2/4 = 0.2209$，$e^{-0.2209} = 0.8018$，故离子性为 $1 - 0.8018 = 0.198$，即约 **20 %**。介于 C–Zn（$18\,\%$）与 C–Mg（$32\,\%$）之间：三烷基铝比二烷基锌活泼，却不及格氏试剂；与两者一样，纯品都是自燃的。
:::

::: exercise 十二羰基三钌 {level=2 check="3"}
若每个钌都遵守 18 电子规则，$\mathrm{[Ru_3(CO)_{12}]}$ 含几根 Ru–Ru 键？（输入键数。）
::: solution
$V = 3 \times 8 + 12 \times 2 = 48$；$B = (3 \times 18 - 48)/2 = 3$：钌原子构成的三角形，每个钌带四个端羰基。每个 Ru：$8 + 8 + 2 = 18$。（与铁的类似物不同，$\mathrm{[Ru_3(CO)_{12}]}$ 没有桥羰基；更大的金属三角形使桥连不那么有利。）
:::

::: exercise 五个金属的团簇 {level=2 check="9"}
锇团簇 $\mathrm{[Os_5(CO)_{16}]}$ 电中性、只带端羰基。[[#prop-mm-bonds]]预言它有几根 Os–Os 键？哪个五顶点多面体有那么多条棱？（输入键数。）
::: solution
$V = 5 \times 8 + 16 \times 2 = 72$，$B = (5 \times 18 - 72)/2 = (90 - 72)/2 = 9$。**三角双锥**有 9 条棱（赤道三角形里三条，两个顶点各引出三条），这正是 $\mathrm{[Os_5(CO)_{16}]}$ 观测到的骨架。四方锥只有 8 条棱，需要 74 个电子。
:::

::: exercise 等瓣相似片段 {level=2 check="2"}
片段 $\mathrm{Rh(\eta^5\text{-}C_5H_5)(CO)}$ 常被说成与 $\mathrm{CH_2}$ 等瓣相似。它离 18 电子差几个？解释这一类比，并预言 $\mathrm{[\{CpRh(CO)\}_2(\mu\text{-}CH_2)]}$ 的结构。（输入离 18 电子所差的电子数。）
::: solution
Rh：$9 + 5$（Cp）$+ 2$（CO）$= 16$，所以该片段离 18 电子差 **2** 个。它有两条前线轨道——把 Cp 看作占据八面体的三个位置时，那两条指向两个缺失配位位置的轨道——里面有两条电子，恰如单线态 $\mathrm{CH_2}$：两条前线轨道，离八隅体差二。于是 $\mathrm{CpRh(CO)} \leftrightarrow \mathrm{CH_2}$；正如两个 $\mathrm{CH_2}$ 生成乙烯、三个生成环丙烷，$\mathrm{[\{CpRh(CO)\}_2(\mu\text{-}CH_2)]}$ 这类化合物——带 Rh–Rh 键与桥亚甲基的双金属杂环丙烷——就是环丙烷的金属有机类似物。每个 Rh：$9 + 5 + 2 + 1$（Rh–Rh）$+ 1$（Rh–$\mathrm{CH_2}$）$= 18$。
:::

::: exercise 直线型与弯曲型亚硝酰 {level=3}
(a) 证明 $\mathrm{[Co(CO)_3(NO)]}$ 只有当 NO 呈直线型（三电子 LX 配体）时才服从 18 电子规则，并指出与它等电子的二元羰基化合物。(b) 在四方锥配合物 $\mathrm{[IrCl_2(NO)(PPh_3)_2]}$ 中，亚硝酰占据顶点位置，Ir–N–O 角约为 $123^\circ$。分别把 NO 当作弯曲型（一电子 X）与直线型（LX）来数电子，并解释配合物为什么选择弯曲型。
::: hint
对 (b)，两种方法都数一遍，与 18 比较。弯曲型 NO 的氮上有一对孤对电子，与氧之间是双键，就像有机亚硝基化合物。
:::
::: solution
(a) 直线型 NO（LX，3 电子）：$\mathrm{VE} = 9 + 3 \times 2 + 3 = 18$。弯曲型 NO（X，1 电子）给出 16，而一个 16 电子的类 $d^{10}$ 四面体配合物本应再结合一个配体，但它并没有。把 NO 换成 CO、把 Co 换成 Ni（多一个质子、配体少给一个电子）便得 $\mathrm{[Ni(CO)_4]}$：两个分子等电子，都是四面体、都是 18 电子。用离子的语言说，NO 是 $\mathrm{NO^+}$，与 CO 等电子，而 Co 是 Co(−I)，$d^{10}$，与 Ni(0) 一样。

(b) 弯曲型 NO（X）：$\ell = 2$，$x = 3$（两个 Cl 加 NO），$\mathrm{VE} = 9 + 4 + 3 = 16$，Ir(III)，$d^6$。直线型 NO（LX）：$\mathrm{VE} = 9 + 4 + 2 + 3 = 18$，用离子语言说是 Ir(I)，$d^8$，配体为 $\mathrm{NO^+}$。按 18 电子规则直线型更好，但看看最后一对电子会落到哪里。四方锥中，四个底面配体把 $d_{x^2-y^2}$ 推得很高，$d^8$ 金属必须把第四对电子放进 $d_{z^2}$，而 $d_{z^2}$ 正对着顶点配体、与它 σ 反键。把 NO 掰弯，那对电子便离开金属、成为氮上的孤对（$sp^2$ 的氮，如有机亚硝基化合物 $\mathrm{R{-}N{=}O}$）：金属变成 $d^6$，反键轨道排空，配合物成为 16 电子的 Ir(III) 物种。亚硝酰是一个电子储库，按金属的需要在一与三电子之间切换；M–N–O 角（直线型接近 $180^\circ$，弯曲型接近 $120^\circ$）就是这一选择的结构性读出；弯曲型的 ν(NO) 也明显下降。
:::

::: exercise 当 18 电子规则遇上一个更大的团簇 {level=3 check="12"}
$\mathrm{[Os_6(CO)_{18}]}$ 是只带端羰基的中性团簇。(a) 用[[#eq-mm-bonds]]预言 Os–Os 键的数目。(b) 它的结构是*双盖四面体*（一个四面体的两个面再被金属原子盖住）。数一数那个多面体的棱。(c) 与 $\mathrm{[Rh_6(CO)_{16}]}$（[[#ex-clusters]]）比较，解释为什么两个六金属团簇的骨架不同。（输入 Os–Os 键数。）
::: hint
盖在三角形面上的原子会形成三根新键。
:::
::: solution
(a) $V = 6 \times 8 + 18 \times 2 = 84$；$B = (6 \times 18 - 84)/2 = (108 - 84)/2 = 12$。

(b) 四面体有 6 条棱；两个盖顶原子各给所坐的面加 3 根键：$6 + 3 + 3 = 12$ 条棱。定域计数与观测结构完全吻合。

(c) $\mathrm{[Rh_6(CO)_{16}]}$ 有 86 个电子，比 $\mathrm{[Os_6(CO)_{18}]}$ 多两个，定域计数给出 11 根键——可它的八面体有 12 条棱。两个团簇都是"六个金属"，但双盖四面体由三角形并合而成，沿每条棱的二中心键是不错的描述；而闭合的八面体有一套笼状轨道体系，最好用离域的骨架电子对来描述：Wade–Mingos 计数对*闭式*八面体给出 $14N + 2 = 86$，而双盖四面体与*单盖*三角双锥是同一个多面体，其计数为母体*闭式*三角双锥的计数加盖顶的 $12$：$14 \times 5 + 2 + 12 = 84$。选择多面体的是骨架电子计数，而不是金属数目；18 电子规则只有在成键保持定域时才灵验。
:::
