一种分子式为$\mathrm{C_4H_8O_2}$的无色液体散发着梨糖的香味。符合该分子式的结构有四个是酯——乙酸乙酯、丙酸甲酯、甲酸丙酯与甲酸异丙酯——此外还有十来个是酸、羟基酮或环醚。一张质子核磁共振谱，在几毫克样品上记录五分钟，就能了结这场争论：三个信号，面积比$2:3:3$，$\delta\,4.12$处一条四线信号，$2.04$处一条尖锐单线，$1.26$处一条三线信号。到本课前，你就能把这句话读成一个结构：$\mathrm{CH_3C(O)OCH_2CH_3}$。核磁共振是化学中结构测定最强大的单一工具，因为每个信号都携带四条彼此独立的信息——有几类核、每一类处于什么电子环境、每一类有几个、每个又与哪些核耦合——并且因为二维实验把最后一条变成了一张化学键的显式地图。

[[spectroscopy/nmr-principles]]解释了化学位移与自旋-自旋耦合的由来：电子环流对原子核的屏蔽，以及核自旋取向通过成键电子的传递。本课把这两个量视为给定的，教你*使用*它们：把一张$^{1}\mathrm{H}$谱、一张带DEPT编辑的$^{13}\mathrm{C}$谱，以及一组COSY、HSQC与HMBC相关信号，变成分子的连接方式，并把耦合常数与NOE变成立体化学。描述结构的词汇——连接方式、官能团、不饱和度——来自[[organic-1/organic-structures]]；立体化学的词汇来自[[organic-1/stereochemistry]]。

## 质子谱中的四条信息

一张常规$^{1}\mathrm{H}$谱是吸收强度对化学位移$\delta$的曲线，$\delta$以距四甲基硅烷（TMS，$\delta = 0$）的百万分率（ppm）计，大$\delta$（"低场"，去屏蔽）在*左*侧。在读谱之前，先把已知的分子式换算成环数加$\pi$键数。

::: definition 不饱和度 {#def-dbe}
对化合物$\mathrm{C}_c\mathrm{H}_h\mathrm{N}_n\mathrm{O}_o\mathrm{X}_x$（X = 卤素），**不饱和度**（双键等价数，DBE）为
$$
\mathrm{DBE} = \frac{2c + 2 + n - h - x}{2},
$$ {#eq-dbe}
即环数与$\pi$键数之和。氧与硫不参与计算。苯环计为四（一个环、三个$\pi$键），$\mathrm{C{=}O}$或$\mathrm{C{=}C}$计为一，$\mathrm{C{\equiv}N}$计为二。
:::

对$\mathrm{C_4H_8O_2}$，$\mathrm{DBE} = (8 + 2 - 8)/2 = 1$：一个环或一个双键。小分子中$\mathrm{DBE}$不小于4时，就应在$\delta\,6.5$–$8.5$区间寻找芳环。

谱图本身分四轮读：**信号数目**（有几组化学等价质子）、**化学位移**（每组接在什么基团上）、**积分**（每组有几个质子）与**多重性**（邻近原子上有几个质子）。第一轮需要对"等价"有精确的观念。

::: definition 同位的、对映异位的与非对映异位的核 {#def-equivalence}
把分子中的两个核各用一个试验基团Z取代一次，比较两种产物，即可判定这两个核的关系。

- 若产物相同（两个核可被分子的某个旋转轴$C_n$操作或绕单键的快速旋转互相交换），则它们是**同位的**：在任何环境中都化学等价，给出一个信号。甲基的三个质子同位的。
- 若产物互为对映体（两个核只被某个镜面或其他非真操作互相交换），则它们是**对映异位的**：在非手性溶剂中等价、给出一个信号，但在手性溶剂中可能不同。乙醇的两个$\mathrm{CH_2}$质子是对映异位的。
- 若产物是非对映体，则它们是**非对映异位的**：化学*不*等价，化学位移一般不同，并且彼此耦合。手性中心旁的两个$\mathrm{CH_2}$质子，如$\mathrm{CH_3CH_2CH(OH)CH_3}$（丁-2-醇）中的那两个，无论键转多快都是非对映异位的。

化学等价、并且对其余每个核的耦合也完全相同的核称为**磁等价**；只有磁等价基团才给出下文简单的一级图样。
:::

### 化学位移区间

化学位移反映局部电子密度与邻近$\pi$体系的各向异性场。电负性的邻居吸走电子密度并去屏蔽；$\pi$键使处于环平面或双键平面内的质子去屏蔽（把苯置于$\delta\,7.27$的环流效应），使其上方的质子屏蔽。下表数值是$\mathrm{CDCl_3}$溶液的典型值，辑自Pretsch、Bühlmann与Badertscher（《Structure Determination of Organic Compounds》）以及Silverstein等人的汇编。

| 质子环境 | 典型$\delta_\mathrm{H}$ / ppm |
|---|---|
| 烷基$\mathrm{C{-}CH_3}$、$\mathrm{C{-}CH_2{-}C}$ | 0.8–1.8 |
| 紧邻$\mathrm{C{=}O}$、$\mathrm{C{=}C}$或芳环的$\mathrm{CH}$ | 2.0–2.7 |
| 炔$\mathrm{{\equiv}C{-}H}$ | 1.8–3.1 |
| 连在带N、卤素或O的碳上的$\mathrm{CH}$ | 2.2–4.5 |
| 烯$\mathrm{{=}C{-}H}$ | 4.5–6.5 |
| 芳环$\mathrm{Ar{-}H}$ | 6.5–8.5 |
| 醛$\mathrm{{-}CHO}$ | 9.4–10.1 |
| 羧酸$\mathrm{{-}COOH}$ | 10–13（宽） |
| 醇、酚、胺、酰胺的$\mathrm{O{-}H}$、$\mathrm{N{-}H}$ | 0.5–9，多变 |

最后一行是对一切规则的例外：连在杂原子上的质子参与氢键与化学交换，其位移随浓度、温度与溶剂而变，信号也常常很宽。

对处于两个取代基之间的亚甲基，有一个有用的经验加和方案。

::: proposition Shoolery规则（经验式） {#prop-shoolery}
亚甲基$\mathrm{X{-}CH_2{-}Y}$的化学位移可估计为
$$
\delta(\mathrm{XCH_2Y}) \approx 0.23 + \sigma_\mathrm{X} + \sigma_\mathrm{Y},
$$ {#eq-shoolery}
其中$0.23$是甲烷的位移，取代基常数（ppm）为：$\mathrm{{-}CH_3}$ 0.47、$\mathrm{{-}C{=}C}$ 1.32、$\mathrm{{-}COOR}$ 1.55、$\mathrm{{-}NR_2}$ 1.57、$\mathrm{{-}C(O)R}$ 1.70、$\mathrm{{-}C{\equiv}N}$ 1.70、$\mathrm{{-}I}$ 1.82、$\mathrm{{-}Ph}$ 1.85、$\mathrm{{-}Br}$ 2.33、$\mathrm{{-}OR}$ 2.36、$\mathrm{{-}Cl}$ 2.53、$\mathrm{{-}OH}$ 2.56、$\mathrm{{-}OC(O)R}$ 3.13（Silverstein等人的表列数据）。该规则是经验的；当X与Y都是官能团时通常能准到约$\pm 0.2$ ppm，而当其中一个是烷基或两者相互作用时就不那么可靠。
:::

该规则之所以成立，是因为各取代基的屏蔽贡献到一阶为止是对局部电子密度的独立微扰；在并非独立之处它就失效——例如经由$\mathrm{CH_2}$共轭的两个羰基，或把取代基固定在特定几何构型上的环。针对次甲基质子、烯烃（Pascual–Meier–Simon增量）与苯环都有推广版本；它们都是实测数据的插值，而不是定律。

::: example 估计亚甲基位移 {#ex-shoolery}
估算(a) 氯化苄$\mathrm{PhCH_2Cl}$、(b) 二氯甲烷$\mathrm{CH_2Cl_2}$与(c) 丁-2-酮$\mathrm{CH_3C(O)CH_2CH_3}$的$\mathrm{CH_2}$质子的$\delta_\mathrm{H}$，并与实测值$4.57$、$5.30$与$2.44$ ppm比较。
::: solution
用表列常数代入式[[#eq-shoolery]]。

(a) $\delta = 0.23 + 1.85\ (\mathrm{Ph}) + 2.53\ (\mathrm{Cl}) = 4.61$ ppm，实测$4.57$。

(b) $\delta = 0.23 + 2 \times 2.53 = 5.29$ ppm，实测$5.30$。

(c) $\delta = 0.23 + 1.70\ (\mathrm{C(O)R}) + 0.47\ (\mathrm{CH_3}) = 2.40$ ppm，实测$2.44$。

三者都与实测相差$0.05$ ppm以内，比该规则通常的表现还好。对乙酸乙酯的$\mathrm{OCH_2}$做同样计算，$0.23 + 3.13 + 0.47 = 3.83$ ppm，比实测的$4.12$低了$0.3$ ppm：当某个取代基是普通烷基时规则精度下降，这正是其陈述要附带提醒的原因。
:::
:::

### 积分

只要谱图在扫描之间留有足够长、使每个质子都回到平衡的弛豫延迟（通常取最长$T_1$的五倍），$^{1}\mathrm{H}$信号的面积就与产生它的质子数成正比。谱仪以任意单位把积分打印成一个数字或一个台阶高度；只有比值有意义。

要把积分换算成质子数，把各项除以最小值，在该比值中寻找最简单的整数组合，再把总数缩放到分子式的氢数。积分可靠到百分之几：$2.96 : 2.02$就是$3 : 2$，而不是$3 : 2.02$。对混合物，各项积分除以其质子数后测得的是*摩尔*比，这就是以内标做定量核磁共振（qNMR）的基础。

::: example 由质子谱推乙酸乙酯 {#ex-ethyl-acetate}
某化合物$\mathrm{C_4H_8O_2}$的$^{1}\mathrm{H}$信号为$\delta\,4.12$（四重峰，$J = 7.1$ Hz，积分20.4）、$2.04$（单峰，积分30.9）与$1.26$（三重峰，$J = 7.1$ Hz，积分30.6）。推断其结构。
::: solution
**不饱和度。**$\mathrm{DBE} = 1$：一个$\mathrm{C{=}O}$或$\mathrm{C{=}C}$，或一个环。

**积分。**总和为$81.9$个单位对应$8$个H，故三个信号各含$20.4 \times 8/81.9 = 1.99$、$3.02$与$2.99$个质子：$\mathrm{CH_2}$、$\mathrm{CH_3}$、$\mathrm{CH_3}$。

**多重性。**四重峰（$2$ H）有三个邻近质子；三重峰（$3$ H）有两个，且两信号共享$J = 7.1$ Hz，说明它们彼此耦合：一个乙基$\mathrm{CH_3CH_2{-}}$。单峰的甲基在相邻原子上没有质子。

**位移。**$4.12$处的$\mathrm{CH_2}$在连氧的碳上，且该值高于醚或醇的$3.4$–$3.6$，符合酯氧$\mathrm{{-}OC(O)R}$的预期。$2.04$处的甲基单峰紧邻羰基。

**拼合。**$\mathrm{CH_3CH_2O{-}}$与$\mathrm{CH_3C(O){-}}$恰好用尽$\mathrm{C_4H_8O_2}$，唯一的DBE就是$\mathrm{C{=}O}$：该化合物是乙酸乙酯，$\mathrm{CH_3C(O)OCH_2CH_3}$。其异构体丙酸甲酯$\mathrm{CH_3CH_2C(O)OCH_3}$也有一个乙基和一个甲基单峰，但位移互换了角色：甲基单峰是连氧的那个（$\delta\,3.67$），四重峰紧邻羰基（$\delta\,2.32$）。区分两者的是*位移*，不是多重性。
:::
:::

## 多重性与耦合常数

自旋-自旋耦合按邻近核的自旋状态分裂所观察核的信号。当耦合基团之间以赫兹计的位移差远大于其耦合常数（实践上$\Delta\nu/J \gtrsim 10$）时，图样是**一级**的，并遵循一条计数规则。

::: proposition n + 1 规律 {#prop-multiplicity}
在一级谱中，以相同耦合常数$J$与$n$个全同自旋-$\tfrac12$核耦合的质子（或一组等价质子）给出间隔为$J$的$n + 1$条线，强度比为二项式系数$\binom{n}{k}$，$k = 0, \ldots, n$（帕斯卡三角：$1{:}1$、$1{:}2{:}1$、$1{:}3{:}3{:}1$，……）。若它以不同常数$J_1, J_2, \ldots$与$n_1, n_2, \ldots$个核的几组核耦合，多重峰最多有$(n_1 + 1)(n_2 + 1)\cdots$条线。更一般地，与$n$个自旋为$I$的全同核耦合给出$2nI + 1$条线。磁等价核之间的耦合不出现在谱中。
:::

::: proof 自旋态计数 {#proof-multiplicity}
在一阶极限下，被观察跃迁的能量移动$J \sum_i m_i$，其中$m_i = \pm\tfrac12$是邻居$i$的磁量子数；邻居自身的自旋状态不随跃迁改变。对$n$个全同邻居，和$\sum_i m_i$取值$\tfrac{n}{2} - k$，$k = 0, 1, \ldots, n$——即相隔一个单位的$n + 1$个值——而给出每个值的组态数就是从$n$个自旋中选出哪$k$个朝下的选法数$\binom{n}{k}$。室温下$\alpha$与$\beta$态的布居在约$10^{-5}$以内相等，故每种组态等概率，线强正比于$\binom{n}{k}$。对两组核，移动$J_1 \sum m_i + J_2 \sum m_j$独立地组合，给出两组线数的乘积（若某些组合重合则更少——当$J_1 = J_2$时图样塌缩为$n_1 + n_2 + 1$条线）。对自旋$I$，每个核贡献$2I + 1$个$m$值，$n$个核的$\sum m_i$从$-nI$到$+nI$：$2nI + 1$条线。磁等价组内的耦合不可见，源于被观察跃迁保持该组总自旋守恒，这一结果在[[spectroscopy/nmr-principles]]中已证。
:::

该规律的氘版本在每一张氘代氯仿中记录的谱上都看得见：$\mathrm{CDCl_3}$的$^{13}\mathrm{C}$信号在$\delta\,77.16$处是$1{:}1{:}1$三重峰，因为一个$^{2}\mathrm{H}$核（$I = 1$）给出$2 \times 1 \times 1 + 1 = 3$条线。

::: example 1-溴丙烷的丙基 {#ex-propyl}
1-溴丙烷$\mathrm{BrCH_2CH_2CH_3}$在$\delta\,3.40$（2 H）、$1.89$（2 H）与$1.03$（3 H）处显示信号。预告各自的多重性，并解释为什么中间信号通常被描述成六重峰。
::: solution
$\mathrm{BrCH_2}$质子（$3.40$，被溴去屏蔽）在C2上有两个邻居：三重峰。$\mathrm{CH_3}$（$1.03$）有两个邻居：三重峰。中间的$\mathrm{CH_2}$在C1上有两个邻居、在C3上有三个。按一般规律它最多可显示$(2+1)(3+1) = 12$条线。但两个邻碳耦合都接近$7$ Hz（自由旋转的链上，无论取代基如何，$^{3}J$平均为$6$–$8$ Hz），于是线重合得仿佛五个邻居全同，给出$5 + 1 = 6$条强度$1{:}5{:}10{:}10{:}5{:}1$的线——表观六重峰。只有在高场并做分辨率增强时，两个$J$值的细微不等才会使内线加宽或分裂。
:::
:::

### 典型耦合常数

$J$的大小本身就是结构信息，因为它取决于耦合核之间的键数与几何构型。跨两个键的耦合是**同碳的**（geminal，$^{2}J$），跨三个键的是**邻碳的**（vicinal，$^{3}J$），四个或更多键的是**远程的**。$^{1}\mathrm{H}$–$^{1}\mathrm{H}$耦合的典型量级（Pretsch等人）：

| 耦合 | 典型$J$ / Hz |
|---|---|
| 同碳，$\mathrm{sp^3}$ $\mathrm{CH_2}$（非对映异位） | 12–15（符号为负） |
| 同碳，端烯$\mathrm{{=}CH_2}$ | 0–3 |
| 邻碳，自由旋转的$\mathrm{H{-}C{-}C{-}H}$ | 6–8 |
| 邻碳，环己烷直立-直立 | 8–13 |
| 邻碳，环己烷直立-平伏或平伏-平伏 | 2–5 |
| 烯烃*反式*$\mathrm{H{-}C{=}C{-}H}$ | 12–18 |
| 烯烃*顺式*$\mathrm{H{-}C{=}C{-}H}$ | 6–12 |
| 醛$\mathrm{H{-}C{-}CHO}$ | 1–3 |
| 芳环*邻位* / *间位* / *对位* | 7–9 / 1–3 / 0–1 |
| 烯丙位$\mathrm{H{-}C{=}C{-}C{-}H}$（$^{4}J$） | 0–3 |
| 刚性环中的"W"排列（$^{4}J$） | 1–3 |

仅其中两行就能解决许多立体化学问题：烯烃耦合$16$ Hz是*E*构型，$10$ Hz是*Z*构型；环己烷椅式构象中$10$ Hz的耦合要求两个质子是直立的。后一条事实有定量理论。

::: proposition Karplus关系（经验形式） {#prop-karplus}
相邻$\mathrm{sp^3}$碳上质子的邻碳耦合依赖于$\mathrm{H{-}C{-}C{-}H}$单元的二面角$\phi$，近似为
$$
{}^{3}J(\phi) = A\cos^{2}\phi + B\cos\phi + C ,
$$ {#eq-karplus}
在$\phi = 180^\circ$附近（反叠，antiperiplanar）最大，在$0^\circ$附近（顺叠，synperiplanar）稍小，在$90^\circ$附近接近零。Karplus最初的价键计算（1959年）给出（Hz）$0^\circ \le \phi \le 90^\circ$时${}^{3}J = 8.5\cos^{2}\phi - 0.28$，$90^\circ \le \phi \le 180^\circ$时${}^{3}J = 9.5\cos^{2}\phi - 0.28$，本课即采用这一参数形式。真实耦合还取决于取代基电负性、键角与键长；Haasnoot、de Leeuw与Altona（1980年）的推广参数形式加入了电负性项，定量工作应当使用它们。
:::

这一形状背后的物理是重叠：耦合通过$\mathrm{C{-}H}$成键电子传递，两条$\mathrm{C{-}H}$键隔着$\mathrm{C{-}C}$键的相互作用在共面时（$0^\circ$或$180^\circ$）最大、正交时消失。由于$\cos^{2}\phi$是对称的，一个耦合常数可以对应多达四个二面角；该关系是对所提几何构型的检验，而不是反演公式。

::: example 归属葡萄糖的端基异构体 {#ex-anomers}
在$\mathrm{D_2O}$中，达平衡的D-葡萄糖溶液显示两个端基（H1）二重峰：$\delta\,5.22$（$J = 3.7$ Hz，积分36）与$\delta\,4.64$（$J = 7.9$ Hz，积分64）。在$^{4}C_1$椅式中，两个端基异构体的H2都是直立的。归属这两个信号，并给出平衡组成。
::: solution
在$\beta$端基异构体中，$\mathrm{C1{-}OH}$是平伏的，故H1是直立的，与直立的H2反叠：$\phi \approx 180^\circ$，式[[#eq-karplus]]预测$9.5 - 0.28 = 9.2$ Hz。在$\alpha$端基异构体中H1是平伏的，与H2成邻位交叉：$\phi \approx 60^\circ$，预测$8.5 \times 0.25 - 0.28 = 1.9$ Hz。因此大耦合（$7.9$ Hz）的二重峰是$\delta\,4.64$处的$\beta$-H1，小的那个（$3.7$ Hz）是$\delta\,5.22$处的$\alpha$-H1。1959年的曲线两种情形都偏了$1$–$2$ Hz——环氧与羟基降低反叠耦合、抬高邻位交叉耦合——但归属立足于*大*与*小*的对比，这一点是稳健的。每个信号是一个质子，故积分直接给出摩尔比：$36 : 64$，即$36\,\%$的$\alpha$与$64\,\%$的$\beta$，葡萄糖在水中的变旋平衡。
:::
:::

::: warning 二级谱与并非二重峰的"二重峰" {#warn-second-order}
n + 1 规律只在$\Delta\nu \gg J$时成立。由于以赫兹计的$\Delta\nu$随磁场增大而$J$不变，一张谱在$400$ MHz可以是一级的、在$60$ MHz却是二级的：两个信号$0.30$ ppm的间隔在$60$ MHz下是$18$ Hz，在$400$ MHz下是$120$ Hz，而$J$是$7$ Hz。随着$\Delta\nu/J$下降，两个耦合多重峰的内线以外线为代价增长（**屋顶效应**，它恰好指向耦合伙伴，很实用），还会出现额外的线，表观间隔也不再等于$J$。带两个不同取代基的对位二取代苯显示两个各$2$ H的表观二重峰，但自旋体系是$\mathrm{AA'BB'}$——化学等价而非磁等价的对——线间隔并不精确等于$^{3}J_{ortho}$。把这类图样当作取代模式的指纹来读，而不是当作可测量的多重峰。
:::

### 可交换质子与非对映异位质子

连在氧与氮上的质子彼此交换，痕量酸或碱即可催化。当交换在核磁共振时间尺度上很快（速率远大于以赫兹计的$J$）时，这样的质子感受到邻居自旋状态的平均，表现为一个单峰，也不分裂它的邻居：普通乙醇的$\mathrm{OH}$是单峰，$\mathrm{CH_2}$是简单的四重峰。在极纯、极干的乙醇中，或在靠氢键锁住OH而减慢交换的$\mathrm{DMSO{-}d_6}$中，$\mathrm{OH}$表现为三重峰，$\mathrm{CH_2}$表现为四重峰的二重峰。

诊断办法是**$\mathrm{D_2O}$振摇**：往样品中加一滴$\mathrm{D_2O}$，振摇，重新记录。可交换的$\mathrm{OH}$、$\mathrm{NH}$与$\mathrm{COOH}$质子被氘取代，而氘不出现在$^{1}\mathrm{H}$谱中，于是它们的信号消失，同时出现一个新的$\mathrm{HOD}$信号（在$\mathrm{D_2O}$中约$\delta\,4.8$，在$\mathrm{CDCl_3}$中作为单独一相约$4.7$）。酰胺NH质子交换很慢，可以存在几分钟甚至几小时，这一性质被用来测量蛋白质中溶剂可及性。

非对映异位质子（见[[#def-equivalence]]）是相反的陷阱：在缩写式中"看起来一样"、其实不一样的质子。$\mathrm{PhCH(CH_3)CH_2OH}$的$\mathrm{CH_2}$给出两个分开的信号，各为一个双二重峰（彼此的同碳耦合，与次甲基的邻碳耦合），因为分子的对称操作不能把它们交换。连在手性中心上的异丙基的两个甲基同样是非对映异位的，常常给出两个二重峰。

::: quiz 非对映异位与否？

## 碳-13谱与DEPT

碳-13自旋为$\tfrac12$，但天然丰度只有$1.07\,\%$，磁旋比只有质子的四分之一，所以同一份样品的$^{13}\mathrm{C}$谱比$^{1}\mathrm{H}$谱灵敏度低约$6000$倍，需要多得多的扫描。低丰度带来一个福音：两个$^{13}\mathrm{C}$核相邻的概率约为$(0.0107)^{2} \approx 10^{-4}$，碳-碳耦合在常规谱中不可见。

碳-质子耦合很大（$\mathrm{sp^3}$的$^{1}J_\mathrm{CH} \approx 125$ Hz、$\mathrm{sp^2}$的$160$ Hz、$\mathrm{sp}$碳的$250$ Hz），本会把每个信号变成一片重叠的多重峰。因此常规谱以**宽谱质子去耦**记录：在整个质子位移范围连续照射质子，其自旋状态被打乱得比$J$还快，每个化学上不同的碳都表现为一条线。去耦还通过核Overhauser效应增强连质子碳的信号（最多$1 + \gamma_\mathrm{H}/2\gamma_\mathrm{C} \approx 3$倍），而季碳因无相连质子、弛豫时间长而保持微弱。因此**常规$^{13}\mathrm{C}$积分不与碳数成正比**，不用于计数。

*能*数的是线的数目，它等于对称性不同的碳的数目。位移范围约$220$ ppm，是质子的二十倍，所以偶然重叠很少发生。

| 碳环境 | 典型$\delta_\mathrm{C}$ / ppm |
|---|---|
| 烷基$\mathrm{CH_3}$、$\mathrm{CH_2}$、$\mathrm{CH}$、季碳 | 0–50 |
| $\mathrm{C{-}N}$、$\mathrm{C{-}O}$（胺、醇、醚、酯） | 40–90 |
| 炔$\mathrm{C{\equiv}C}$ | 65–90 |
| 烯与芳环$\mathrm{C{=}C}$ | 100–160 |
| 腈$\mathrm{C{\equiv}N}$ | 115–125 |
| 羧酸、酯、酰胺 | 160–185 |
| 醛、酮 | 190–220 |

要弄清每个碳带几个质子，就做**DEPT**实验（极化转移无畸变增强）。磁化经$^{1}J_\mathrm{CH}$从质子转移到碳，使灵敏度提高约$\gamma_\mathrm{H}/\gamma_\mathrm{C} \approx 4$倍；序列最后一个翻转角为$\theta$的质子脉冲，按相连质子的数目设定每个信号的符号与大小。

::: proposition DEPT编辑 {#prop-dept}
在末级质子脉冲角为$\theta$的DEPT实验中，带$n$个质子的碳的信号正比于
$$
S_{\mathrm{CH}_n}(\theta) \propto n\,\sin\theta\,\cos^{n-1}\theta :
\qquad
S_\mathrm{CH} \propto \sin\theta,\quad
S_{\mathrm{CH_2}} \propto \sin 2\theta,\quad
S_{\mathrm{CH_3}} \propto 3\sin\theta\cos^{2}\theta ,
$$ {#eq-dept}
季碳（$n = 0$）无信号。于是DEPT-45把所有连质子碳显示为正；**DEPT-90**只显示CH碳；**DEPT-135**使CH与$\mathrm{CH_3}$为正、$\mathrm{CH_2}$为*负*。对比宽谱去耦谱与DEPT-90、DEPT-135，即可把每个碳分类为C、CH、$\mathrm{CH_2}$或$\mathrm{CH_3}$。
:::

::: proof 推导概要 {collapsed}
在序列的极化转移部分（Doddrell、Pegg与Bendall，1982年）之后，$\mathrm{CH}_n$基的碳磁化以涉及碳与全部$n$个相连质子的异核多量子相干形式存在。末级质子脉冲$\theta$独立地作用于每个质子。要在随后的演化中观察到碳上的信号，需要$n$个质子中恰好一个被转换成反相态——该态重聚焦为碳磁化，幅值$\sin\theta$——而其余$n - 1$个质子保持原态，各贡献幅值$\cos\theta$。选哪个质子为"主动"的有$n$种选法，故信号为$n\sin\theta\cos^{n-1}\theta$。代入$n = 1, 2, 3$即得式[[#eq-dept]]中的三个函数。$\theta = 90^\circ$时$\cos\theta = 0$消去一切$n > 1$的项，只剩CH；$\theta = 135^\circ$时$\cos\theta < 0$，$\mathrm{CH_2}$项中的奇次幂$\cos^{1}\theta$使其为负，而偶次幂$\cos^{2}\theta$保持$\mathrm{CH_3}$为正。$n = 0$时没有质子可传递极化，根本无信号。
:::

- 2-甲基丙-1-醇$\mathrm{(CH_3)_2CHCH_2OH}$：3（两个甲基等价）；

- 1-甲氧基丙烷$\mathrm{CH_3OCH_2CH_2CH_3}$：4；2-甲氧基丙烷$\mathrm{CH_3OCH(CH_3)_2}$：3；

剩下两个候选。它们的$^{13}\mathrm{C}$位移种类相似——一个连氧碳在$\delta\,66$–$69$附近，一个甲基碳在$15$–$31$附近——但DEPT立刻把它们分开。DEPT-135中，乙醚显示$\mathrm{OCH_2}$（$\delta\,65.9$）*朝下*、$\mathrm{CH_3}$（$15.4$）朝上；2-甲基丙-2-醇只显示其甲基信号（$31.2$）朝上，因为季碳$\mathrm{C{-}OH}$（$69.1$）消失了。$^{1}\mathrm{H}$谱同样吻合：乙醚给出一个四重峰（$\delta\,3.48$，4 H）与一个三重峰（$1.21$，6 H），而2-甲基丙-2-醇给出一个$9$ H单峰（$1.28$）与一个位置随浓度而变、经$\mathrm{D_2O}$振摇即消失的$1$ H的OH单峰。（位移：SDBS，$\mathrm{CDCl_3}$谱。）

## 二维相关实验

一维谱列出碎片，却不说它们如何连接。二维实验把连接明确化。每种实验中，脉冲序列先让磁化在一组频率上演化（在可变延迟$t_1$期间），再在另一组频率上检测（$t_2$期间）；对两个时间变量做傅里叶变换，得到一张图，每当磁化在$\delta_1$处的核与$\delta_2$处的核之间转移过，图上的$(\delta_1, \delta_2)$处就出现一个**交叉峰**。转移的机制决定了交叉峰的含义。

::: definition 四种标准相关实验 {#def-2d}
- **COSY**（相关谱，$^{1}\mathrm{H}$–$^{1}\mathrm{H}$）：交叉峰连接两个存在标量耦合的质子，通常隔两或三个键（$^{2}J$、$^{3}J$）；W排列与烯丙位的四键弱峰也会出现。谱图关于对角线对称，对角线上就是普通的一维谱。
- **HSQC**（异核单量子相干，$^{1}\mathrm{H}$–$^{13}\mathrm{C}$）：交叉峰把每个质子连到与它*直接成键*的碳上，经由$^{1}J_\mathrm{CH} \approx 125$–$170$ Hz。季碳不给峰；非对映异位的$\mathrm{CH_2}$质子在同一碳位移处给出两个峰。编辑型HSQC使$\mathrm{CH_2}$峰与CH、$\mathrm{CH_3}$符号相反，正如DEPT-135。
- **HMBC**（异核多键相关，$^{1}\mathrm{H}$–$^{13}\mathrm{C}$）：交叉峰把一个质子连到*相隔两或三个键*的碳上（$^{2}J_\mathrm{CH}$、$^{3}J_\mathrm{CH}$，典型$2$–$10$ Hz；延迟通常按约$8$ Hz优化），一键相关被抑制。HMBC看得见季碳，并能跨越杂原子与羰基建立相关，这是任何H–H实验都做不到的。
- **NOESY**（核Overhauser效应谱，$^{1}\mathrm{H}$–$^{1}\mathrm{H}$）：交叉峰连接两个**空间上接近**（通常在约$5\ \mathrm{\AA}$以内）的质子，无论它们是否邻近成键。对刚性分子，交叉峰强度在初始速率区随核间距$r$按$r^{-6}$变化，故NOESY测量构象与相对构型。
:::

$r^{-6}$律使NOE成为一把灵敏的尺：相距$3.5\ \mathrm{\AA}$的一对质子给出的交叉峰，比$2.5\ \mathrm{\AA}$的一对弱$(3.5/2.5)^{6} = 7.5$倍。用已知间距的一对（$1.78\ \mathrm{\AA}$的同碳$\mathrm{CH_2}$，或$2.5\ \mathrm{\AA}$的芳环邻位质子）定标，就能把强度换算成距离：$r = r_\mathrm{ref}\,(I_\mathrm{ref}/I)^{1/6}$。由于是六次方根，强度差两倍也只使距离变$12\,\%$——这正是成千上万个NOE距离能决定蛋白质结构的原因。

::: warning HMBC：两键还是三键，以及缺失的峰 {#warn-hmbc}
HMBC交叉峰说的是"两键*或*三键"，实验本身无法区分。更糟的是，$^{3}J_\mathrm{CH}$遵循自己的Karplus式依赖，二面角接近$90^\circ$时可以接近零，而$^{2}J_\mathrm{CH}$常常很小，所以*缺失*的HMBC峰证明不了任何事。芳环中$^{3}J_\mathrm{CH}$（约$7$–$8$ Hz）大于$^{2}J_\mathrm{CH}$（$1$–$2$ Hz），故芳烃质子的最强HMBC峰指向与它*间位*的碳。从存在的相关构建结构，每个键都要用至少两条独立的相关检验，而绝不从缺失下结论。
:::

相关信号要系统地拼合。

::: algorithm 由一维与二维核磁共振谱拼合结构 {#alg-assemble}
1. 由分子式（高分辨质谱，[[spectroscopy/mass-spectrometry]]）计算DBE（式[[#eq-dbe]]）。
2. 由$^{13}\mathrm{C}$与DEPT谱把每个碳列为C、CH、$\mathrm{CH_2}$或$\mathrm{CH_3}$并记下位移；检验相连质子加上可交换质子（HSQC中缺失、或经$\mathrm{D_2O}$振摇消失的那些）合计等于分子式的H数。
3. 用HSQC把每个质子信号挂到它的碳上，使每个$^{1}\mathrm{H}$积分与多重性都归属于一个编号的碳。
4. 用COSY（连同多重性）把连质子碳连成**自旋体系**：以H–H耦合相连的$\mathrm{CH}_n$基链。每个自旋体系止于季碳或杂原子。
5. 用HMBC把各自旋体系跨越季碳、羰基与杂原子桥接起来，从信息量最大的质子开始（甲基单峰给出强而明确的HMBC峰）。
6. 用与位移及红外谱（[[spectroscopy/vibrational-spectroscopy]]）相符的官能团，说明剩余的原子与DBE。
7. 用**每一项**观测——每个位移、多重性、$J$值与相关——以及其余候选结构来检验所提结构；然后用$J$值与NOESY确定立体化学。
:::

::: solution
**DBE** $= (18 + 2 - 10)/2 = 5$。四个芳质子（$\delta_\mathrm{H}\,6.9$–$8.0$）与四条芳碳线（$\delta_\mathrm{C}\,113$–$164$）提示一个苯环（DBE 4）；第五个是$196.8$处的羰基——一个共轭酮（芳基酮在$196$–$198$附近，而$1676\ \mathrm{cm^{-1}}$的红外带低于饱和酮的$1715$，证实共轭）。

**对称性。**九个碳只给七条线，且两个各$2$ H的芳烃信号：两对等价的环CH碳（$130.6$、$113.7$）加两个环季碳（$163.5$、$130.3$）。有两对等价CH的环是*对位*二取代的；两个"二重峰"就是[[#warn-second-order]]中的$\mathrm{AA'BB'}$图样。

**碎片。**$\delta_\mathrm{H}\,3.87$、碳在$55.5$的甲基单峰是甲氧基$\mathrm{OCH_3}$。$2.55$、碳在$26.3$的甲基单峰是乙酰基甲基$\mathrm{CH_3C(O){-}}$。$163.5$的环碳去屏蔽得很厉害：它连着氧。

**连接（HMBC）。**H8（$2.55$）与羰基（两键）以及环季碳C1（$130.3$，三键）相关：乙酰基在C1上。H9（$3.87$）跨越氧与C4（$163.5$）相关：甲氧基在C4上。$7.94$的环质子看到羰基与C4——各三键——所以它们是H2/6，位于乙酰基的邻位并被其去屏蔽；$6.93$的质子位于给电子甲氧基的邻位并被其屏蔽，是H3/5，隔三键看到C1。

**结构：**$\mathrm{4{-}CH_3OC_6H_4C(O)CH_3}$，1-(4-甲氧基苯基)乙-1-酮（4-甲氧基苯乙酮）。每一项数据都有了结；异构体4-甲基苯甲酸甲酯$\mathrm{4{-}CH_3C_6H_4COOCH_3}$分子式与对称性相同，但其羰基在$167$附近（酯）、芳甲基在$\delta_\mathrm{H}\,2.4$/$\delta_\mathrm{C}\,21.6$附近，且其$\mathrm{OCH_3}$在HMBC中与羰基而非环碳相关。（位移：SDBS。）
:::

## 实用要点

几个实用事实决定一张谱是否可信。$^{1}\mathrm{H}$核磁共振样品通常为$2$–$10$ mg溶于$0.6\ \mathrm{cm^3}$氘代溶剂；谱仪利用溶剂的氘信号锁场；残留的质子化溶剂给出参考信号（$\mathrm{CDCl_3}$中的$\mathrm{CHCl_3}$，$\delta_\mathrm{H}\,7.26$；$\mathrm{DMSO{-}d_5}$的$2.50$；$\mathrm{D_2O}$中约$4.8$的$\mathrm{HOD}$），溶剂吸收的水给出一个可变的小峰（$\mathrm{CDCl_3}$中$1.56$，$\mathrm{DMSO{-}d_6}$中$3.33$）。固体杂质会使线加宽，必须滤除。

::: remark 核磁共振实验室的安全
氘代氯仿带有氯仿的一切危害：吞咽或吸入有害，刺激皮肤与眼睛，并被列为疑似致癌物与生殖毒性物（GHS健康危害与感叹号象形图）。在通风橱中戴手套、护目镜制样，试剂瓶保持密闭，溶液按卤代废物处置。超导磁体本身也是一种危险：其杂散场能使心脏起搏器及其他植入设备停摆、消磁磁条卡，并把铁磁性工具与气瓶猛烈吸入磁体，因此只有非磁性物体才能进入划定的界线之内，而低温液体（液氦与液氮）的操作要留给受过训练的人员。与一切实验工作一样，制样需要监督与风险评估。
:::

## 后续内容

本课的工具与红外谱、质谱在[[spectroscopy/structure-problems]]中合用，上面那套流程将在完整的未知物上演练；它们需要的分子式来自[[spectroscopy/mass-spectrometry]]的高分辨质量，官能团来自[[spectroscopy/vibrational-spectroscopy]]。同样的相关逻辑，在$^{13}\mathrm{C}$、$^{15}\mathrm{N}$标记样品上推广到三维、四维，就能测定溶液中蛋白质的结构；本课用于葡萄糖端基异构体的耦合常数与NOE论证，正是[[organic-synthesis]]中日常的立体化学工具。电子自旋的磁矩大得多，其超精细图样在[[spectroscopy/epr]]中遵循同样的计数规律（[[#prop-multiplicity]]）。

::: history
第一张化学分辨的质子谱是乙醇谱，1951年由阿诺德（James Arnold）、达尔马蒂（S. S. Dharmatti）与帕卡德（Martin Packard）发表：三条线、强度比$3{:}2{:}1$，表明同一种元素在同一分子中因环境不同而给出分开的信号。Varian Associates的James Shoolery于1959年发表了他的亚甲基位移加和规则，同年Martin Karplus由价键理论导出了邻碳耦合对二面角的依赖。Jean Jeener于1971年提出二维实验的构想，Walter Aue、Enrico Bartholdi与Richard Ernst于1976年对其分析并演示（COSY）；Jeener、Meier、Bachmann与Ernst于1979年引入NOESY。DEPT由David Doddrell、David Pegg与Michael Bendall于1982年提出，HMBC由Ad Bax与Michael Summers于1986年提出。恩斯特（Richard Ernst）因傅里叶变换与二维核磁共振获1991年诺贝尔化学奖，维特里希（Kurt Wüthrich）因用基于NOE的核磁共振测定溶液中生物大分子的结构分享2002年化学奖。
:::

::: summary
- 从分子式开始：$\mathrm{DBE} = (2c + 2 + n - h - x)/2$数的是环加$\pi$键。
- $^{1}\mathrm{H}$谱给出四样东西：信号数目（等价质子组——提防非对映异位的$\mathrm{CH_2}$）、位移（环境；$\mathrm{XCH_2Y}$用Shoolery经验加和）、积分（质子比，按分子式缩放）与多重性。
- 一级多重峰遵循带二项式强度的n + 1 规律，不等耦合给$(n_1+1)(n_2+1)$条线，自旋$I$给$2nI + 1$条线；它们要求$\Delta\nu/J \gtrsim 10$，否则出现屋顶与$\mathrm{AA'BB'}$图样。
- 耦合常数编码几何：烯烃*反式*$12$–$18$ vs *顺式*$6$–$12$ Hz；芳环*邻位*$7$–$9$、*间位*$1$–$3$ Hz；邻碳$\mathrm{sp^3}$耦合遵循Karplus关系，反叠质子大、邻位交叉质子小。
- 可交换的OH/NH/COOH质子位移多变，经$\mathrm{D_2O}$振摇即消失。
- 宽谱去耦$^{13}\mathrm{C}$谱数对称性不同的碳（不靠积分）；DEPT-90只显示CH，DEPT-135使CH与$\mathrm{CH_3}$朝上、$\mathrm{CH_2}$朝下，季碳在DEPT中缺席。
- COSY把耦合的质子连成自旋体系，HSQC把质子挂到其碳上，HMBC跨越季碳与杂原子桥接两或三个键，NOESY（$\propto r^{-6}$）给出通过空间距离与立体化学。
:::

## 习题

::: exercise 不饱和度 {level=1 check="5"}
计算$\mathrm{C_8H_8O}$的不饱和度，并说出它提示什么结构特征。（输入DBE。）
::: solution
$\mathrm{DBE} = (2 \times 8 + 2 - 8)/2 = 5$。其中四个最可能是一个苯环，第五个是$\mathrm{C{=}O}$或$\mathrm{C{=}C}$——苯乙酮$\mathrm{PhC(O)CH_3}$、苯乙醛$\mathrm{PhCH_2CHO}$与4-甲基苯甲醛都是例子。由核磁共振谱在它们之间决断。
:::
:::

::: exercise 由积分到质子数 {level=1 check="6"}
某化合物$\mathrm{C_5H_{10}O}$显示两个$^{1}\mathrm{H}$信号，积分分别为$41.2$与$61.5$。较大的信号代表几个质子？（输入质子数。）
::: solution
总和$41.2 + 61.5 = 102.7$个单位对应$10$个H，故较大信号含$61.5 \times 10/102.7 = 5.99 \approx 6$个质子，较小的含$4$个。一个$4\,\mathrm{H}$四重峰与一个$6\,\mathrm{H}$三重峰就应是戊-3-酮$\mathrm{(CH_3CH_2)_2CO}$：羰基上两个等价的乙基。
:::
:::

::: exercise 数碳信号 {level=1 check="3"}
1,4-二甲苯（对二甲苯）的宽谱去耦$^{13}\mathrm{C}$谱显示几条线？（输入线数。）
::: solution
分子具有$D_{2h}$对称性。两个甲基碳等价（一条线），连甲基的两个环碳等价（一条线），四个环CH碳等价（一条线）：共$3$条线。1,2-异构体会显示4条，1,3-异构体5条，所以光靠碳线数就能区分三种二甲苯。
:::
:::

::: exercise Shoolery估算 {level=2 check="4.64"}
用Shoolery规则估计苄醇$\mathrm{PhCH_2OH}$的$\mathrm{CH_2}$质子的化学位移。（以ppm输入$\delta$。）
::: solution
$\delta \approx 0.23 + \sigma_\mathrm{Ph} + \sigma_\mathrm{OH} = 0.23 + 1.85 + 2.56 = 4.64$ ppm。$\mathrm{CDCl_3}$中实测约$4.67$ ppm。把醇制成乙酸酯后以$\sigma_{\mathrm{OC(O)R}} = 3.13$替换$\sigma_\mathrm{OH}$，预测$5.21$ ppm（实测约$5.10$）：醇的酰化使$\mathrm{CH{-}O}$信号向低场移约$0.5$ ppm，是标准的诊断。
:::
:::

::: exercise 多重峰最多的线数 {level=2 check="12"}
1-溴丙烷中间的$\mathrm{CH_2}$与$\mathrm{BrCH_2}$的两个质子及$\mathrm{CH_3}$的三个质子耦合。若两个邻碳耦合常数不同且都能分辨，该多重峰显示几条线？（输入线数。）
::: solution
与两个等价质子的耦合把信号分裂为三重峰；每条线再被三个等价质子分裂为四重峰：$(2+1)(3+1) = 12$条线，三重峰的四重峰（或四重峰的三重峰）。由于实际两个耦合几乎相等（约$7$ Hz），十二条线中许多重合，观察到的图样是表观六重峰，如[[#ex-propyl]]。
:::
:::

::: exercise 由J求二面角 {level=2 check="159"}
在环上相邻$\mathrm{sp^3}$碳的两个质子之间测得邻碳耦合为$8.0$ Hz。用$90^\circ \le \phi \le 180^\circ$分支的1959年Karplus参数估计二面角。（以度输入$\phi$。）
::: hint
解$9.5\cos^{2}\phi - 0.28 = 8.0$，取$\cos\phi < 0$的根。
:::
::: solution
$\cos^{2}\phi = (8.0 + 0.28)/9.5 = 0.8716$，故$\cos\phi = -0.9336$，$\phi = 159^\circ$。在$0$–$90^\circ$分支上，$8.5\cos^{2}\phi - 0.28 = 8.0$需要$\cos^{2}\phi = 0.974$、$\phi = 9^\circ$——六元环不可能采取的重排排列——所以反叠附近的解才是物理的。考虑简单曲线$1$–$2$ Hz的不确定度，老实的结论是"大致反叠，$\phi$在$150$–$180^\circ$之间"，即椅式构象中两个直立质子。
:::
:::

::: exercise 由NOE求距离 {level=3 check="3.15"}
某刚性分子的NOESY谱中，两个*邻位*芳质子（$r = 2.50\ \mathrm{\AA}$）之间交叉峰的强度，是某个芳质子与一个邻近甲基之间交叉峰的四倍。设$r^{-6}$律对两对都成立，估算芳质子–甲基的距离。（以$\mathrm{\AA}$输入$r$。）
::: solution
由$I \propto r^{-6}$，$r = r_\mathrm{ref}(I_\mathrm{ref}/I)^{1/6} = 2.50 \times 4^{1/6}\ \mathrm{\AA} = 2.50 \times 1.260 = 3.15\ \mathrm{\AA}$。六次方根使估计稳健：即使强度比实为$3$或$5$，距离也只变到$2.98$或$3.27\ \mathrm{\AA}$。实践中有两点限制精度。甲基是三个快速旋转的质子，"距离"是对它们的$r^{-6}$加权平均；而且参考对与未知对必须有相同的相关时间，刚性分子内成立，刚性核与柔性侧链之间则不成立。
:::
:::

::: exercise 甲基碳的最佳角度 {level=3 check="35.3"}
从式[[#eq-dept]]出发，找出使$\mathrm{CH_3}$碳DEPT信号最大的脉冲角$\theta$（$0^\circ$到$90^\circ$之间），并把极大值与CH、$\mathrm{CH_2}$的极大值比较。（以度输入$\theta$。）
::: hint
对$3\sin\theta\cos^{2}\theta$关于$\theta$求导并令导数为零。
:::
::: solution
$\dfrac{\mathrm{d}}{\mathrm{d}\theta}\left(3\sin\theta\cos^{2}\theta\right) = 3\cos^{3}\theta - 6\sin^{2}\theta\cos\theta = 3\cos\theta\left(\cos^{2}\theta - 2\sin^{2}\theta\right)$。除$\cos\theta = 0$（极小，信号为零）外，导数在$\tan^{2}\theta = \tfrac12$时为零，即$\tan\theta = 1/\sqrt2$、$\theta = 35.3^\circ$。极大值为$3 \times (1/\sqrt3)(2/3) = 2/\sqrt3 = 1.155$，而CH为$1$（在$90^\circ$）、$\mathrm{CH_2}$为$1$（在$45^\circ$）。一般地，$n\sin\theta\cos^{n-1}\theta$的极大在$\sin\theta = 1/\sqrt n$处，所以碳带的质子越多，最佳角越小。DEPT-135是一种折中，以牺牲约$8\,\%$的$\mathrm{CH_3}$极大值（$1.061/1.155$）换取符号信息。
:::
:::

::: exercise 乙酸乙酯还是丙酸甲酯？ {level=3}
某酯$\mathrm{C_4H_8O_2}$给出$^{1}\mathrm{H}$信号$\delta\,3.67$（3 H，s）、$2.32$（2 H，q，$J = 7.6$ Hz）与$1.14$（3 H，t，$J = 7.6$ Hz），以及约$\delta\,174.8$（C）、$51.5$（$\mathrm{CH_3}$）、$27.5$（$\mathrm{CH_2}$）与$9.2$（$\mathrm{CH_3}$）的$^{13}\mathrm{C}$信号。鉴定它，并指出哪条HMBC相关能不依赖位移论证独立地证明这一归属。
::: solution
出现了乙基（共享$7.6$ Hz的四重峰与三重峰）与一个甲基单峰，与乙酸乙酯（见[[#ex-ethyl-acetate]]）相同，但位移互换了。$3.67$的单峰、碳在$51.5$，是$\mathrm{OCH_3}$；$2.32$的四重峰、碳在$27.5$，是紧邻羰基而非连氧的$\mathrm{CH_2}$（连氧会把它放到$\delta_\mathrm{H}\,4.1$、$\delta_\mathrm{C}\,60$附近）。该化合物是丙酸甲酯，$\mathrm{CH_3CH_2C(O)OCH_3}$。HMBC直接证明连接方式：$\mathrm{OCH_3}$质子（$3.67$）与隔三个键的羰基碳（$174.8$）相关（$\mathrm{H{-}C{-}O{-}C}$），乙基的$\mathrm{CH_2}$（两键）与$\mathrm{CH_3}$（三键）质子也与之相关；而乙酸乙酯中单峰甲基隔两键与羰基相关、隔三键与$\mathrm{OCH_2}$相关，乙基的$\mathrm{CH_3}$（隔四个键）则不然。因此乙基*甲基*质子与羰基的相关才是决定性的。
:::
