把一份冷冻的铜(II)盐溶液、一份经辐照的糖样品，或一滴含有氮氧自由基的血清样品放进约三分之一特斯拉的磁场中，用$9.5\ \mathrm{GHz}$附近的微波照射它，再缓慢扫描磁场。在某一个磁场——而且只在那一个磁场——样品发生吸收。大多数分子是沉默的：它们的电子都已配对，配对的自旋无话可说。但任何带有未成对电子的物种——有机自由基、过渡金属离子、晶体缺陷、三重态——都会应答，而且应答的细节非常丰富。吸收的位置告诉你电子的轨道运动如何与其自旋耦合；谱线分裂成$2, 3, 4, \ldots, 25$条成分的图样告诉你电子造访了哪些磁性核、在每个核上花了多少时间。**电子顺磁共振**（EPR，也称电子自旋共振，ESR）是核磁共振针对未成对电子的孪生技术；由于只有顺磁物种有响应，它能在抗磁性溶剂的海洋中以微摩尔浓度挑出一个自由基。

本课建立共振条件与g值，解释g为何偏离自由电子值，推导等价核与不等价核产生的超精细图样，通过麦康奈尔（McConnell）关系把测得的耦合与休克尔自旋密度联系起来，最后讲述自旋标记、自旋捕获与过渡金属离子。磁共振的语言——拉莫尔（Larmor）进动、布居、弛豫、旋转坐标系——与[[spectroscopy/nmr-principles]]共享，而跃迁与线宽的一般框架属于[[spectroscopy/spectroscopy-principles]]。常数取CODATA 2018值：$\mu_\mathrm{B} = 9.274\,010\times10^{-24}\ \mathrm{J\,T^{-1}}$，$g_\mathrm{e} = 2.002\,319$，$\mu_\mathrm{N} = 5.050\,784\times10^{-27}\ \mathrm{J\,T^{-1}}$，$h$、$k_\mathrm{B}$为精确值。除特别说明外，超精细耦合常数取韦尔（Weil）与博尔顿（Bolton）《电子顺磁共振》（*Electron Paramagnetic Resonance*，2007）汇集的标准文献值。

## 电子塞曼效应与共振条件

电子携带自旋角动量$\hbar\sqrt{S(S+1)}$，其中$S = \tfrac12$，并随之带有一个磁矩；由于电子带负电，磁矩指向自旋的*反*方向。在沿$z$的磁场$\mathbf{B}$中，磁矩的能量为$-\boldsymbol{\mu}\cdot\mathbf{B}$，两个自旋态$m_S = \pm\tfrac12$发生分裂。

::: definition g值与EPR共振条件 {#def-g}
对处于磁场$B$中、有效自旋$S = \tfrac12$的顺磁物种，自旋哈密顿量为$\hat H = g\mu_\mathrm{B}B\hat S_z$，本征值为
$$
E_{m_S} = g\mu_\mathrm{B}B\,m_S, \qquad m_S = \pm\tfrac12 ,
$$ {#eq-zeeman}
其中$\mu_\mathrm{B} = e\hbar/2m_\mathrm{e}$是玻尔磁子，无量纲的**g值**（g因子）是该物种的特征。$m_S = -\tfrac12$态（"$\beta$"）较低。当**共振条件**
$$
h\nu = g\mu_\mathrm{B}B_\mathrm{res}
$$ {#eq-resonance}
满足时，频率为$\nu$的光子的吸收驱动$\Delta m_S = \pm 1$跃迁。自由电子$g = g_\mathrm{e} = 2.002\,319$；在分子中，g是物种的一种属性，如同化学位移。
:::

[[#eq-resonance]]确定了频率与磁场的可用组合。由于$\mu_\mathrm{B}/h = 13.996\ \mathrm{GHz\,T^{-1}}$，自由电子每特斯拉在$28.025\ \mathrm{GHz}$处共振，即每毫特斯拉$28.025\ \mathrm{MHz}$。商品谱仪工作在按雷达波段惯例命名的固定波段：**X波段**（$9$–$10\ \mathrm{GHz}$，共振在$340\ \mathrm{mT}$附近）、**Q波段**（$\approx 34\ \mathrm{GHz}$，$\approx 1.2\ \mathrm{T}$）与**W波段**（$94\ \mathrm{GHz}$，$3.35\ \mathrm{T}$）。与核磁共振不同，EPR固定频率——微波谐振腔只在一个频率上高效——而扫描的是*磁场*。这就是EPR谱对以毫特斯拉（或高斯，$1\ \mathrm{mT} = 10\ \mathrm{G}$）为单位的$B$作图、且可传递的量是g值而不是磁场的原因：同一个自由基在$9.5\ \mathrm{GHz}$下于$339\ \mathrm{mT}$共振，在$34\ \mathrm{GHz}$下则在$1.21\ \mathrm{T}$共振。

::: example 测量g值 {#ex-g-value}
碱性溶液中氧化对苯二酚产生的自由基，在$\nu = 9.5000\ \mathrm{GHz}$的谱仪上给出中心位于$B = 338.40\ \mathrm{mT}$的谱。求其g值并加评论。自由电子将在什么磁场共振？
::: solution
重排[[#eq-resonance]]，
$$
g = \frac{h\nu}{\mu_\mathrm{B}B} = \frac{6.626\,070\times10^{-34}\ \mathrm{J\,s} \times 9.5000\times10^{9}\ \mathrm{s^{-1}}}{9.274\,010\times10^{-24}\ \mathrm{J\,T^{-1}} \times 0.338\,40\ \mathrm{T}} = 2.0058 .
$$
自由电子将在$B = h\nu/g_\mathrm{e}\mu_\mathrm{B} = 338.98\ \mathrm{mT}$处共振，高出$0.58\ \mathrm{mT}$。位移$g - g_\mathrm{e} = +0.0035$对碳中心自由基来说太大（这类自由基的g与$g_\mathrm{e}$相差约$0.001$以内），而典型地属于半醌自由基负离子：其未成对自旋有相当一部分位于自旋-轨道耦合更强的氧原子上。注意所需精度：g值报告到小数点后四位或五位，因此磁场必须测到优于$0.01\ \mathrm{mT}$——实践中用核磁共振高斯计，或对着如DPPH（2,2-二苯基-1-苦肼基，$g = 2.0036$）这样的标准物质测量。
:::
:::

### EPR为何灵敏：布居

X波段的能隙按化学标准虽小，按核磁共振标准却很大。电子的磁矩是质子的$658$倍，所以在同一磁场下电子塞曼分裂大$658$倍；尽管核磁共振磁体比EPR电磁铁强约三十倍，$9.5\ \mathrm{GHz}$的EPR跃迁对应的能量仍是$400\ \mathrm{MHz}$质子跃迁的$24$倍。

::: example X波段的玻尔兹曼布居 {#ex-boltzmann}
计算$S = \tfrac12$物种在$9.50\ \mathrm{GHz}$、$298\ \mathrm{K}$下上、下自旋布居之比，以及布居差分数$(N_\beta - N_\alpha)/(N_\beta + N_\alpha)$。与$400\ \mathrm{MHz}$核磁共振谱仪中的质子比较，再与该样品在液氦中冷却到$4.2\ \mathrm{K}$的情形比较。
::: solution
指数为
$$
\frac{h\nu}{k_\mathrm{B}T} = \frac{6.626\,070\times10^{-34} \times 9.50\times10^{9}}{1.380\,649\times10^{-23} \times 298} = 1.530\times10^{-3},
$$
于是$N_\alpha/N_\beta = \mathrm{e}^{-1.530\times10^{-3}} = 0.998\,47$，极化度为$\tanh(h\nu/2k_\mathrm{B}T) = 7.65\times10^{-4}$——下能级中"多余"的自旋不到千分之一。对$400\ \mathrm{MHz}$的质子，指数为$6.44\times10^{-5}$，极化度$3.2\times10^{-5}$，小$24$倍。把EPR样品冷却到$4.2\ \mathrm{K}$使指数升到$0.109$、极化度升到$5.4\,\%$，提高七十倍：正因如此，加上更慢的弛豫，过渡金属离子的EPR通常在液氦温度测量。更高的极化度、更大的磁矩与更高的频率一起，使EPR按每个自旋计本质上比核磁共振灵敏得多；现代X波段谱仪可在一条窄线上检测约$10^{10}$–$10^{11}$个自旋。
:::
:::

### 磁场调制与一阶导数谱

连续波（CW）EPR谱仪记录的不是吸收线本身，而是它的**一阶导数**。在缓慢扫描的主磁场上叠加一个小的高频振荡场，通常为$100\ \mathrm{kHz}$、振幅小于线宽；相敏（锁相）检测器从微波信号中挑出以调制频率振荡的分量。该分量正比于吸收曲线在当前磁场处的*斜率*，所以记录到的曲线在中心处过零，低场一侧有正瓣、高场一侧有负瓣。这一手法抑制了所有其他频率的噪声并使重叠的谱线锐化，代价是一条需要一些练习才能读懂的曲线。

::: widget plot
f: w^2/(x^2+w^2); -2*x*w^3/(x^2+w^2)^2
x: -1, 1
y: -0.8, 1.1
sliders: w=0.1:0.02:0.4:0.01
labels: \text{吸收}; \text{一阶导数（EPR记录）}
caption: 半高半宽为`w`（单位mT）的洛伦兹吸收线及其一阶导数——即磁场调制EPR谱仪记录到的形状——对$B - B_\mathrm{res}$作图。导数在吸收极大处过零；它的两个极值位于$\pm w/\sqrt{3}$，因此**峰-峰宽度**为$\Delta B_\mathrm{pp} = 2w/\sqrt{3}$，半高全宽为$\sqrt{3}\,\Delta B_\mathrm{pp}$（对高斯线，因子为$\sqrt{2\ln 2} = 1.177$）。把线调宽，观察导数的两个瓣如何分离、变平——在导数谱中宽线是微弱的，这就是弛豫快的金属离子必须降温才能被看到的原因之一。
:::

::: warning EPR记录不是吸收谱 {#warn-derivative}
把导数谱当成吸收谱来读会犯三种错误。第一，线的位置是**过零点**，不是任一极值峰。第二，导数线的*高度*不正比于自旋数目：对形状相同的线，它按（自旋数目）/（宽度）$^{2}$变化，所以宽一倍的线看起来弱四倍。要比较浓度必须积分两次（导数→吸收→面积）。第三，在超精细多重峰中，只有当各成分的宽度都相同时，相对峰高才符合二项式强度——这对流动溶液中的小有机自由基通常成立，而对金属配合物常常不成立。
:::

## g为何偏离2：自旋-轨道耦合

若未成对电子表现得像一个自由自旋，每个自由基都会在$g_\mathrm{e}$处共振，g值便不包含任何化学信息。（$g_\mathrm{e}$本身就比$2$大$0.0023$，这是量子电动力学修正，$g_\mathrm{e} \approx 2(1 + \alpha/2\pi + \cdots)$，$\alpha$为精细结构常数，1948年由施温格（Schwinger）首次算出。）但在分子中，电子还有轨道角动量，而轨道运动自带磁矩。在多数分子中轨道角动量是**湮灭**（quenched）的：基态是实函数轨道、非简并，$\langle \hat L_z \rangle = 0$。自旋-轨道耦合（耦合常数$\zeta$或$\lambda$）把少量激发态轨道角动量混回基态，电子的有效磁矩随之改变。

::: proposition 自旋-轨道耦合引起的g位移 {#prop-g-shift}
对轨道基态非简并的自由基或离子，对自旋-轨道耦合$\lambda\hat{\mathbf{L}}\cdot\hat{\mathbf{S}}$与轨道塞曼项作二阶微扰，得到沿轴$i$加场时的
$$
g_{ii} = g_\mathrm{e} - 2\lambda\sum_{n \neq 0}\frac{\lvert\langle 0\vert\hat L_i\vert n\rangle\rvert^{2}}{E_n - E_0} ,
$$ {#eq-g-shift}
其中求和遍历激发轨道态$n$。位移的量级为$\lambda/\Delta E$：自旋-轨道耦合弱（轻原子）或激发态很远时很小；其正负取决于$\lambda$的符号——壳层不足半满为负（$\lambda > 0$），壳层超过半满为正（$\lambda < 0$，如$\mathrm{Cu^{2+}}$，$d^{9}$，以及氧上的空穴）。
:::

::: proof 公式的由来（概要） {#proof-g-shift}
把哈密顿量写成$\hat H_0 + \mu_\mathrm{B}B(\hat L_i + g_\mathrm{e}\hat S_i) + \lambda\hat{\mathbf L}\cdot\hat{\mathbf S}$。在轨道基态$\vert 0\rangle$中，一阶轨道项为零，因为对实、非简并波函数$\langle 0\vert\hat L_i\vert 0\rangle = 0$（$\hat L_i$纯虚，其在实态中的期望值既是实的又是虚的，故为零）。二阶时，轨道塞曼算符与自旋-轨道耦合的交叉项给出能量
$$
E^{(2)} = -2\sum_{n\neq 0}\frac{\langle 0\vert\mu_\mathrm{B}B\hat L_i\vert n\rangle\langle n\vert\lambda\hat L_i\hat S_i\vert 0\rangle}{E_n - E_0} = -2\lambda\mu_\mathrm{B}B\,\hat S_i\sum_{n\neq 0}\frac{\lvert\langle 0\vert\hat L_i\vert n\rangle\rvert^{2}}{E_n - E_0},
$$
（因子2计入算符的两种排列次序）。这一项对$B$与$\hat S_i$都是线性的，与自旋塞曼项$g_\mathrm{e}\mu_\mathrm{B}B\hat S_i$完全同形，故可并入有效$g_{ii}$：即[[#eq-g-shift]]。其余二阶项或自旋无关（抗磁性），或正比于$\lambda^{2}$（$S > \tfrac12$时的零场效应）。
:::

这一命题一目了然地解释了经验范围。碳的原子自旋-轨道耦合常数仅约$28\ \mathrm{cm^{-1}}$，而有机$\pi$自由基的激发态位于基态以上约$3\times10^{4}\ \mathrm{cm^{-1}}$，所以$\lvert g - g_\mathrm{e}\rvert \sim 10^{-3}$：烃自由基位于$g = 2.0025$–$2.0030$（甲基$2.0026$，苯自由基负离子$2.0028$）。氮（$\zeta \approx 76\ \mathrm{cm^{-1}}$）与氧（$\zeta \approx 151\ \mathrm{cm^{-1}}$）把g推得更高：氮氧自由基$2.006$，半醌$2.004$–$2.005$，过氧自由基约$2.015$。较重的原子与过渡金属离子，$\lambda$达数百$\mathrm{cm^{-1}}$且有低能的$d$–$d$激发态，位移可达$0.1$以上：$\mathrm{Cu^{2+}}$配合物的g介于$2.05$与$2.4$之间。因此g值是关于未成对电子*住在哪里*的第一道粗略指纹。

### 各向异性：g是张量

在[[#eq-g-shift]]中矩阵元依赖于轴$i$，所以一般而言g依赖于分子在磁场中的取向——g是一个对称张量，沿分子固定轴有三个主值$g_{xx}, g_{yy}, g_{zz}$。在流动溶液中，分子翻滚（皮秒到纳秒时间尺度）把张量平均为各向同性值$g_\mathrm{iso} = \tfrac13(g_{xx} + g_{yy} + g_{zz})$。在单晶中，谱线随晶体旋转而移动。在冻结溶液或粉末中，一切取向同时存在，光谱变成**粉末图样**：吸收铺展在$h\nu/g_\mathrm{max}\mu_\mathrm{B}$到$h\nu/g_\mathrm{min}\mu_\mathrm{B}$的整个磁场范围上，导数曲线在与主值对应的磁场处出现特征。

对具有三重或更高次对称轴的物种（**轴向**体系），两个主值重合：沿特殊轴加场为$g_\parallel$，垂直平面内任意方向加场为$g_\perp$，且$g(\theta)^{2} = g_\parallel^{2}\cos^{2}\theta + g_\perp^{2}\sin^{2}\theta$。由于垂直于轴的取向构成一个完整的圆而平行取向只有两个极点，$g_\perp$特征在粉末谱中占主导——一个大的导数形峰——而$g_\parallel$在另一端表现为较弱的台阶。四方拉长的$\mathrm{Cu^{2+}}$配合物，其未成对电子在$d_{x^2-y^2}$，通常显示$g_\parallel \approx 2.2$–$2.4 > g_\perp \approx 2.05 > g_\mathrm{e}$；次序$g_\parallel > g_\perp > 2$本身就是$d_{x^2-y^2}$基态的诊断特征，配体场的讨论见[[coordination-chemistry/crystal-field-theory]]。

- [ ] $\mathrm{Cu^{2+}}$配合物。
- [ ] 过氧自由基$\mathrm{ROO^\bullet}$。
- [ ] $S = 0$的物种。
::: solution
g值与$g_\mathrm{e}$相差在$0.0005$以内，意味着几乎没有混入轨道角动量：自旋位于自旋-轨道耦合弱的轻原子上，如烃自由基。$\mathrm{Cu^{2+}}$（$g \approx 2.05$–$2.4$）与过氧自由基（$g \approx 2.015$，自旋主要位于氧）偏移大得多。$S = 0$的物种根本没有EPR谱。
:::

## 超精细耦合

EPR谱中最丰富的信息来自电子自旋与磁性核的相互作用——**超精细相互作用**。自旋为$I$的核有$2I + 1$种取向$m_I = -I, \ldots, +I$，每一种在电子处产生略微不同的局域磁场。因此每种取向把电子的共振移动不同的量，一条线变成$2I + 1$条。

::: definition 各向同性超精细耦合 {#def-hyperfine}
对在溶液中快速翻滚、与自旋为$I_k$的核$k$相互作用的$S = \tfrac12$物种，自旋哈密顿量为
$$
\hat H = g\mu_\mathrm{B}B\hat S_z + \sum_k h A_k\,\hat{\mathbf S}\cdot\hat{\mathbf I}_k ,
$$
其中$A_k$（单位$\mathrm{MHz}$）是核$k$的**各向同性超精细耦合常数**。当$A_k \ll g\mu_\mathrm{B}B/h$时，能量到一阶为$E = g\mu_\mathrm{B}Bm_S + \sum_k hA_k m_S m_{I,k}$，允许的跃迁（$\Delta m_S = \pm1$，$\Delta m_I = 0$）发生在磁场
$$
B = B_0 - \sum_k a_k\,m_{I,k}, \qquad a_k = \frac{hA_k}{g\mu_\mathrm{B}}, \qquad B_0 = \frac{h\nu}{g\mu_\mathrm{B}} ,
$$ {#eq-hf-lines}
其中**超精细分裂**$a_k$以毫特斯拉为单位。当$g = g_\mathrm{e}$时，$A/\mathrm{MHz} = 28.025\times a/\mathrm{mT}$。
:::

核自旋态几乎等布居（其分裂比电子的小一千倍），所以一个核产生的超精细多重峰的$2I+1$个成分强度相等。在允许的EPR跃迁中核自旋不翻转——它是一位旁观者，只是其取向移动了共振磁场，很像[[spectroscopy/nmr-principles]]中邻近自旋移动质子的核磁共振线，但耦合大一千倍且以磁场单位表示。

### 各向同性耦合的来源：费米接触相互作用

磁偶极子通过空间与另一个偶极子相互作用给出各向异性的能量，分子翻滚时平均为零。能在翻滚中保存下来的各向同性耦合必有另一种起源：电子必须在核*处*具有有限的概率密度。

::: proposition 费米接触相互作用 {#prop-fermi}
核g因子为$g_N$的核的各向同性超精细耦合正比于核处的未成对自旋密度，
$$
a_\mathrm{iso} = \frac{2\mu_0}{3}\,g_N\mu_\mathrm{N}\,\rho_\mathrm{s}(0), \qquad \rho_\mathrm{s}(0) = \lvert\psi(0)\rvert^{2}\ \text{对于单个处于轨道}\psi\text{中的未成对电子} ,
$$ {#eq-fermi}
以磁场单位（特斯拉）计。只有具有$s$成分的轨道才有$\psi(0) \neq 0$，所以纯$p$、$d$或$\pi$轨道不直接贡献任何耦合；$\pi$自由基节面内核的各向同性耦合间接来自自旋极化，并可为负。
:::

::: proof 以氢原子作检验 {#proof-fermi}
费米结果源于均匀磁化球内部的磁场$\tfrac{2}{3}\mu_0\mathbf{M}$应用于摊布在电子占据区域内的核磁矩；我们在$\psi(0)$精确已知的唯一情形上检验它。对处于$1s$态的氢，$\lvert\psi(0)\rvert^{2} = 1/\pi a_0^{3}$（[[quantum-chemistry/hydrogen-atom]]），取质子的$g_N = 5.585\,695$，
$$
a_\mathrm{iso} = \frac{2 \times 1.256\,637\times10^{-6}\ \mathrm{T\,m\,A^{-1}}}{3} \times \frac{5.585\,695 \times 5.050\,784\times10^{-27}\ \mathrm{J\,T^{-1}}}{\pi \times (5.291\,772\times10^{-11}\ \mathrm{m})^{3}} = 50.77\ \mathrm{mT}.
$$
改用约化质量的玻尔半径$a_0(1 + m_\mathrm{e}/m_\mathrm{p})$，$\lvert\psi(0)\rvert^{2}$乘以$(1 + m_\mathrm{e}/m_\mathrm{p})^{-3}$，得$50.69\ \mathrm{mT}$，与实测值$50.68\ \mathrm{mT}$（$1420.41\ \mathrm{MHz}$——著名的星际氢$21\ \mathrm{cm}$线）相比。符合到$0.02\,\%$，证实各向同性耦合量度的是核处的$s$电子密度。
:::

氢原子给出了标度：一个*完全*处于氢$1s$轨道的电子产生$50.7\ \mathrm{mT}$。因此质子耦合为$2.3\ \mathrm{mT}$的自由基，其该氢上的有效$1s$自旋密度只有约$4.5\,\%$。超精细耦合是单占据分子轨道（SOMO）的地图，逐原子画出。

### 等价核产生的图样

::: proposition 等价核的超精细图样 {#prop-patterns}
一组$n$个自旋为$I$、耦合同为$a$的等价核，把一条EPR线分裂成
$$
2nI + 1
$$
条等距谱线，间距为$a$，总跨度$2nIa$。强度是得到每个总$M_I = \sum m_I$的方式数：对$I = \tfrac12$是二项式系数$\binom{n}{k}$（帕斯卡三角形：$1{:}1$，$1{:}2{:}1$，$1{:}3{:}3{:}1$，……）；对$I = 1$（$^{14}\mathrm{N}$，$^{2}\mathrm{H}$）是$(1 + x + x^{2})^{n}$的系数（$1{:}1{:}1$，$1{:}2{:}3{:}2{:}1$，……）。不等价组相乘：含$n_1, n_2, \ldots$个自旋为$I_1, I_2, \ldots$的核的各组给出至多$\prod_j(2n_jI_j + 1)$条线。
:::

::: proof 取向的计数 {#proof-patterns}
由[[#eq-hf-lines]]，线的移动只依赖于对等价核求和的总和$M_I = \sum_k m_{I,k}$，它从$-nI$到$+nI$按整数步变化：$2nI + 1$个值，磁场间隔为$a$。核取向的全部$(2I+1)^{n}$种组合等布居，所以总$M_I$的线的强度就是给出该和的组合数。对$I = \tfrac12$，从$n$个自旋中选出朝"上"的$k$个的方式数为$\binom{n}{k}$；对一般$I$，计数是$(1 + x + \cdots + x^{2I})^{n}$中$x^{M_I + nI}$的系数，因为每个核贡献一个因子。对不等价组，移动彼此独立地相加，于是第一组图样的每条线被第二组的完整图样分裂，依此类推；除非偶然重合使谱线并线，谱线总数是乘积。
:::

::: example 甲基自由基 {#ex-methyl}
甲基自由基$\mathrm{CH_3^\bullet}$由光解或辐照制得并捕获在低温基质中，其$g = 2.0026$，三个等价质子的$a_\mathrm{H} = 2.30\ \mathrm{mT}$。预言$9.500\ \mathrm{GHz}$下X波段的谱：线的数目、位置与相对强度。$\mathrm{CD_3^\bullet}$会显示什么？
::: solution
三个等价的$I = \tfrac12$核给出$2 \times 3 \times \tfrac12 + 1 = 4$条线，强度$1{:}3{:}3{:}1$。中心在$B_0 = h\nu/g\mu_\mathrm{B} = 338.94\ \mathrm{mT}$，各线位于$B_0 - a M_I$，$M_I = +\tfrac32, +\tfrac12, -\tfrac12, -\tfrac32$：
$$
335.49,\quad 337.79,\quad 340.09,\quad 342.39\ \mathrm{mT},
$$
间隔$2.30\ \mathrm{mT}$，总跨度$3a = 6.90\ \mathrm{mT}$。对$\mathrm{CD_3^\bullet}$，电子结构以及每个核处的自旋密度不变，所以由[[#eq-fermi]]，耦合按核g因子缩放：$a_\mathrm{D} = a_\mathrm{H}\times g_N(\mathrm{D})/g_N(\mathrm{H}) = 2.30 \times 0.1535 = 0.353\ \mathrm{mT}$。氘的$I = 1$，三个氘给出$2\times3\times1 + 1 = 7$条线，强度$1{:}3{:}6{:}7{:}6{:}3{:}1$，铺展在仅$6 \times 0.353 = 2.12\ \mathrm{mT}$的范围内。氘代是证明某个耦合归属哪些氢的标准办法。
:::

当存在若干组等价核时，谱中可以有几十条线，手工构建它是一项常规技能。

::: algorithm 绘制超精细棒图 {#alg-stick}
要预测含若干组等价核的自由基的各向同性谱：
1. 把磁性核归成对称等价核组，查每组自旋$I_j$与耦合$a_j$。
2. 把各组按$a_j$从大到小排序。
3. 从$B_0 = h\nu/g\mu_\mathrm{e}$处一条强度为1的线开始。
4. 用最大的一组把它分裂成$2n_1I_1 + 1$条间距$a_1$的线，强度按[[#prop-patterns]]。
5. 把所得的*每条*线用下一组分裂，强度相乘，对每组重复。
6. 把落在同一磁场的线的强度相加；不同谱线的总数至多为$\prod_j(2n_jI_j + 1)$，总宽度为$\sum_j 2n_jI_ja_j$。
7. 要与实测曲线比较，就把棒线转成所观测宽度的导数线；要分析实测曲线，就反着跑这些步骤——最外侧的线（强度1）以其与下一条线的间距给出最小的耦合，而总宽度必须等于$\sum_j 2n_jI_ja_j$。
:::

::: example 乙基自由基 {#ex-ethyl}
溶液中的乙基自由基$\mathrm{CH_3CH_2^\bullet}$有$a(\alpha\text{-H}, 2\mathrm{H}) = 2.24\ \mathrm{mT}$与$a(\beta\text{-H}, 3\mathrm{H}) = 2.69\ \mathrm{mT}$（费森登（Fessenden）与舒勒（Schuler），1963）。构建其棒图。
::: solution
按[[#alg-stick]]：较大的耦合属于三个$\beta$质子，它们把中心线分裂成距中心$\pm1.345$与$\pm4.035\ \mathrm{mT}$的$1{:}3{:}3{:}1$四重峰。四重峰的每条线再被两个$\alpha$质子分裂成间距$2.24\ \mathrm{mT}$的$1{:}2{:}1$三重峰。结果有$4 \times 3 = 12$条线；相对$B_0$，括号内为强度，
$$
\pm0.895\,(3),\quad \pm1.345\,(6),\quad \pm1.795\,(1),\quad \pm3.585\,(3),\quad \pm4.035\,(2),\quad \pm6.275\,(1)\ \mathrm{mT}.
$$
总宽度$3(2.69) + 2(2.24) = 12.55\ \mathrm{mT} = 2 \times 6.275$，理应如此。由于两个耦合相近，三重峰相互交错：这谱乍看并不像"四重峰的三重峰"，棒图是唯一可靠的归属办法。这里藏着一个值得注意的事实——离自由基中心远一个键的$\beta$质子，耦合反而*比*$\alpha$质子更强——下一节解释其所以然。

## 自旋密度与麦康奈尔关系

在平面$\pi$自由基（如甲基自由基或苯自由基负离子）中，未成对电子占据由碳$2p_z$轨道构成的$\pi$轨道，而$2p_z$轨道在分子平面上有节面——氢核恰好就在分子平面上。由公式[[#eq-fermi]]，这些**α质子**不该有任何接触耦合，甲基自由基却显示$2.30\ \mathrm{mT}$。解释是**自旋极化**：未成对$\pi$电子与$\mathrm{C{-}H}$ $\sigma$键的两个电子的交换作用略有差别。洪特型交换使靠近碳的$\sigma$电子更倾向于与$\pi$电子自旋*相同*，从而在氢处留下少量*相反*自旋的过剩。质子处诱发的自旋密度为负，且正比于所连碳上的$\pi$自旋密度。

::: proposition 麦康奈尔关系 {#prop-mcconnell}
对于连在$\pi$自由基的$sp^{2}$碳上的α质子，
$$
a_\mathrm{H} = Q\,\rho_\mathrm{C} ,
$$ {#eq-mcconnell}
其中$\rho_\mathrm{C}$是碳上的未成对$\pi$自旋密度，$Q$是经验常数，约$-2.3$至$-2.7\ \mathrm{mT}$（标定：甲基自由基$\rho = 1$给出$Q = -2.30\ \mathrm{mT}$；苯自由基负离子$\rho = \tfrac16$给出$Q = -2.25\ \mathrm{mT}$；芳基大离子用接近$-2.7\ \mathrm{mT}$的值拟合最好）。在简单休克尔理论中，$\rho_\mathrm{C} = c_\mathrm{C}^{2}$，即该碳$p$轨道在SOMO中系数的平方。这一关系是经验性的——$Q$多少依赖于电荷与几何构型——且只适用于α质子；准确度约$10\,\%$。
:::

由于连续波谱只给出$\lvert a\rvert$，$Q$的负号在普通谱中不可见（它是由自由基核磁共振与ENDOR确定的）；对谱线图样只有大小要紧。**β质子**——连在自由基中心相邻碳上的质子，如乙基中的$\mathrm{CH_3}$——以另一种方式耦合，即**超共轭**：$\mathrm{C{-}H}$键与单占据$p$轨道直接重叠，把正自旋密度放进氢的$1s$轨道。耦合取决于$\mathrm{C{-}H}$键与$p$轨道轴之间的二面角$\theta$：$a_\beta \approx B\rho_\mathrm{C}\cos^{2}\theta$，$B$约为$5\ \mathrm{mT}$；对自由旋转的甲基$\langle\cos^{2}\theta\rangle = \tfrac12$，这就是乙基的$a_\beta$（$2.69\ \mathrm{mT}$）与$a_\alpha$相当、甚至更大的原因。在刚性自由基中，角度依赖关系是构象探针。

::: example 萘自由基负离子的自旋密度 {#ex-naphthalene}
在醚类溶剂中用钠还原萘得到萘自由基负离子$\mathrm{C_{10}H_8^{\bullet-}}$。它的额外电子进入休克尔LUMO（$x = -0.618$，[[quantum-chemistry/huckel-theory]]），其系数平方在四个α位（1, 4, 5, 8）为$0.181$，在四个β位（2, 3, 6, 7）为$0.069$，在桥头碳为$0$。（a）取$Q = -2.7\ \mathrm{mT}$预言耦合。（b）谱有几条线？实测耦合为$0.490$与$0.183\ \mathrm{mT}$。
::: solution
（a）由公式[[#eq-mcconnell]]，$\lvert a_\alpha\rvert = 2.7 \times 0.181 = 0.49\ \mathrm{mT}$，$\lvert a_\beta\rvert = 2.7 \times 0.069 = 0.19\ \mathrm{mT}$，与$0.490$和$0.183\ \mathrm{mT}$符合得极好。实测耦合给出$\lvert Q\rvert = 0.490/0.181 = 2.71$与$0.183/0.069 = 2.65\ \mathrm{mT}$：单一的$Q$同时拟合两类位置，这才是对该关系的真正检验。

（b）两组各四个等价质子给出$(2\times4\times\tfrac12 + 1)^{2} = 5 \times 5 = 25$条线：间距$0.490\ \mathrm{mT}$的$1{:}4{:}6{:}4{:}1$五重峰，每条线再被间距$0.183\ \mathrm{mT}$的$1{:}4{:}6{:}4{:}1$五重峰分裂，强度从$1$到$36$。桥头碳不连氢，在休克尔理论中也不带自旋；这张谱是LUMO节面结构的直接实验图像——而它在1953–1956年与休克尔理论相符这一事实，是对$\pi$体系分子轨道理论最早的定量证实之一。

::: warning 数谱线不等于数核 {#warn-counting}
实测谱常比$\prod(2n_jI_j + 1)$条线更少。大多重峰的外侧线很弱（萘负离子最外侧的线只有中心强度的$1/36$），可能淹没在噪声里；恰好接近简单整数比的耦合会使谱线重合；小于线宽的耦合只表现为谱线变宽。反过来，杂质或第二种自由基会增加谱线。对任何归属方案都要从三方面检验：谱线数目、相对强度、总宽度$\sum 2n_jI_ja_j$——并且在可能时模拟谱图，与记录曲线比较。
:::

麦康奈尔关系有一个漂亮的推论，即求和规则。单一SOMO中的休克尔自旋密度对所有碳原子求和为1，所以对一个每个带自旋的碳都连一个氢的烃离子，谱的总宽度$\sum_j n_j\lvert a_j\rvert = \lvert Q\rvert\sum\rho = \lvert Q\rvert$。苯负离子跨$6 \times 0.375 = 2.25\ \mathrm{mT}$，萘负离子$4(0.490) + 4(0.183) = 2.69\ \mathrm{mT}$：整张谱的宽度就是$\lvert Q\rvert$的直接估计。

## 自旋标记与自旋捕获

大多数有研究价值的分子不是自由基，但EPR仍可以通过"接上"或"抓住"一个自由基来研究它们。

**硝酰自旋标记。** 带大位阻烷基的氮氧自由基（nitroxide）$\mathrm{R_2N{-}O^\bullet}$（如TEMPO，2,2,6,6-四甲基哌啶-1-氧自由基）是可以装瓶保存的稳定自由基。未成对电子居于氮与氧共享的$\pi^{*}$轨道，所以谱是$^{14}\mathrm{N}$（$I = 1$）给的$1{:}1{:}1$三重峰，$a_\mathrm{N} \approx 1.5$–$1.7\ \mathrm{mT}$（在极性、形成氢键的溶剂中更大），$g_\mathrm{iso} \approx 2.006$。氮超精细张量与$g$张量各向异性很强，三重峰的线形取决于氮氧自由基翻滚的快慢：转动相关时间低于约$0.1\ \mathrm{ns}$时是三条等高的锐线；到几纳秒时谱线越来越不等高、逐渐加宽；运动冻结时是跨度约$7\ \mathrm{mT}$的宽刚性极限粉末图样。把氮氧自由基共价接到蛋白质的某个半胱氨酸上（定点自旋标记），它就报告局部的运动性与极性；脉冲实验中两个标记之间的偶极相互作用可测$1.5$–$8\ \mathrm{nm}$的距离。

**自旋捕获。** 寿命极短的自由基（如$\mathrm{HO^\bullet}$或超氧阴离子）永远积累不到可检出的浓度。**自旋捕获剂**（硝酮或亚硝基化合物）与瞬态自由基加成，生成持久的氮氧自由基，其耦合常数指明被捕获的是什么。用DMPO（5,5-二甲基-1-吡咯啉-N-氧化物），羟自由基给出DMPO–OH加合物，$a_\mathrm{N} = a_\mathrm{H} \approx 1.49\ \mathrm{mT}$：一个氮（$1{:}1{:}1$）与一个β质子（$1{:}1$）耦合相等，由[[#alg-stick]]给出四条$1{:}2{:}2{:}1$的谱线，这是教科书级的指纹。[[organic-1/radical-reactions]]的自由基中间体、脂质过氧化与酶促氧化还原化学中的自由基，实践中就是靠自旋捕获检出的——但要注意加合物也可能经非自由基途径生成，所以对照实验必不可少。

## 过渡金属离子

$d$壳层半满的过渡金属离子是另一大类EPR活性物种，在这里自旋哈密顿量的每一项都变大：$g$位移可达$0.1$以上，与金属核的超精细耦合为$5$–$20\ \mathrm{mT}$，而对$S > \tfrac12$，零场分裂甚至可以超过微波量子。有两个一般性结果统摄这一领域。

::: proposition 克拉默斯定理 {#prop-kramers}
在无磁场时，**奇**数个电子的体系的每个能级至少二重简并，无论电场（配体场）的对称性如何。这样的**克拉默斯离子**（$d^{1}$、$d^{3}$、$d^{5}$、$d^{7}$、$d^{9}$以及所有自由基）总是有一对简并的能级可被磁场分裂，因此只要弛豫足够慢（通常在低温），就总是给出EPR信号。**偶**数个电子且$S \geq 1$的离子（非克拉默斯离子，如高自旋$d^{6}$的$\mathrm{Fe^{2+}}$或$d^{8}$的$\mathrm{Ni^{2+}}$）的简并可被低对称场与零场分裂完全解除，在X波段常常**对EPR沉默**。
:::

该定理是时间反演对称的推论，而电场不能破坏时间反演对称：对半整数总自旋，一个态的时间反演伙伴是另一个与之正交、能量相同的态（克拉默斯，1930年）。只有磁场能解除这重简并。这就是生物EPR集中于$\mathrm{Cu^{2+}}$、血红素蛋白中的低自旋$\mathrm{Fe^{3+}}$、奇电子数的铁硫簇、$\mathrm{Mn^{2+}}$与$\mathrm{Mo^{5+}}$，而还原态$\mathrm{Fe^{2+}}$位点常常"不可见"的原因（[[coordination-chemistry/bioinorganic]]）。

两种情形能清楚地展示金属超精细结构。

- **铜(II)**，$d^{9}$，$S = \tfrac12$。两种天然同位素$^{63}\mathrm{Cu}$（$69\,\%$）与$^{65}\mathrm{Cu}$（$31\,\%$）都有$I = \tfrac32$，所以每个$g$特征都分裂成**四**条等距等强的线；两种同位素的磁矩只差$7\,\%$，它们的四重峰几乎完全重合。四方配合物的冻结溶液中，低场处的$g_\parallel$区显示四条分得很开的线，$A_\parallel$典型为$13$–$20\ \mathrm{mT}$，而$g_\perp$区是强而常常分辨不佳的峰。$g_\parallel$与$A_\parallel$共同给铜位点分类——例如"蓝"铜蛋白的$A_\parallel$异常地小。
- **锰(II)**，高自旋$d^{5}$，$S = \tfrac52$，$^{55}\mathrm{Mn}$（$100\,\%$，$I = \tfrac52$）。其半满壳层是轨道单重态（$^{6}S$），自旋-轨道效应极小，$g \approx 2.00$；在水溶液中零场分裂被平均掉，$[\mathrm{Mn(H_2O)_6}]^{2+}$给出一组干净的六重峰——六条等强的线，间距约$9.5\ \mathrm{mT}$——生物与环境样品中常见的污染信号，也是方便的磁场标尺。

::: example 解读金属超精细图样 {#ex-metal}
一种金属蛋白在$9.40\ \mathrm{GHz}$下的冻结溶液谱显示，低场处有四条等强、等距、中心在$B = 298.5\ \mathrm{mT}$、间距$17.0\ \mathrm{mT}$的线，另有一个强的导数特征在$327.6\ \mathrm{mT}$。鉴定金属离子，并以$\mathrm{MHz}$计算$g_\parallel$、$g_\perp$与$A_\parallel$。
::: solution
四条等强的线意味着一个$2I + 1 = 4$、$I = \tfrac32$的核；再结合低场（$g_\parallel$）特征带大分裂的轴向谱，这是$\mathrm{Cu^{2+}}$的标志。由公式[[#eq-resonance]]，
$$
g_\parallel = \frac{h\nu}{\mu_\mathrm{B}B_\parallel} = \frac{6.626\,070\times10^{-34} \times 9.40\times10^{9}}{9.274\,010\times10^{-24} \times 0.2985} = 2.250, \qquad
g_\perp = \frac{h\nu}{\mu_\mathrm{B}\times 0.3276\ \mathrm{T}} = 2.050 .
$$
$g_\parallel > g_\perp > g_\mathrm{e}$的次序表明基态为$d_{x^2-y^2}$（四方拉长或平面四配位的铜）。以频率为单位换算耦合要用该特征的$g$：$A_\parallel = g_\parallel\mu_\mathrm{B}a_\parallel/h = 2.250 \times 13.996\ \mathrm{GHz\,T^{-1}} \times 0.0170\ \mathrm{T} = 535\ \mathrm{MHz}$（约$0.0179\ \mathrm{cm^{-1}}$）。若用自由电子因子$28.0\ \mathrm{MHz\,mT^{-1}}$换算，会低估$11\,\%$——当$g$偏离2时，务必用实际的$g$换算磁场分裂。
:::
:::

用自由离子$\lambda(\mathrm{Cu^{2+}}) \approx -830\ \mathrm{cm^{-1}}$与$d$–$d$激发能$(1.2$–$1.5)\times10^{4}\ \mathrm{cm^{-1}}$代入公式[[#eq-g-shift]]估算这类$g$值，得$g_\parallel = g_\mathrm{e} - 8\lambda/\Delta_{xy} \approx 2.45$–$2.56$，比观测值偏大；这一差度是共价度的度量——共价度把未成对电子离域到配体上，削弱了有效轨道角动量。因此EPR是探测金属-配体共价度最直接的实验手段之一，这一主题在[[coordination-chemistry/ligand-field-mo]]与[[coordination-chemistry/magnetism]]中继续展开。

::: remark 实验与安全注记
EPR样品通常封于石英管中（玻璃含顺磁杂质且吸收微波）；水样品需要扁池或毛细管，因为水强烈吸收微波并使谐振腔失谐。微波功率很低（毫瓦级至约$200\ \mathrm{mW}$）且封闭在波导中，但电磁铁的杂散磁场会吸引铁磁性工具，并可能影响心脏起搏器等植入器械，故出入受控。低温工作使用液氮（$77\ \mathrm{K}$）或液氦（$4.2\ \mathrm{K}$）低温恒温器：低温液体造成冻伤，蒸发时还会在封闭房间内排挤氧气，故须在装有氧监测仪的通风房间内戴面罩与低温手套操作。与一切实验工作相同，测量须在指导下、经风险评估后进行。
:::

## 后续内容

EPR与核磁共振共享形式体系，两者在双共振方法中相遇：**ENDOR**（电子-核双共振）以类核磁共振的频率、高得多的分辨率测量超精细耦合；**动态核极化**把[[#ex-boltzmann]]中电子的巨大极化转移给核，把核磁共振信号提高若干数量级（[[spectroscopy/nmr-principles]]）。脉冲EPR是傅里叶变换核磁共振的对应物，测量弛豫时间与电子-电子距离。$g$张量与超精细张量可用[[computational-chemistry]]的密度泛函方法常规计算，而EPR测得的自旋密度正是[[quantum-chemistry/huckel-theory]]的休克尔与分子轨道图像的的实验面目。在无机与生物化学中，EPR鉴定催化剂与酶中金属中心的氧化态与自旋态，从[[biochemistry/oxidative-phosphorylation]]的铁硫簇到[[coordination-chemistry/bioinorganic]]的铜位点；在材料科学中它数半导体中的缺陷与悬挂键；在有机化学中它检出那些动力学只能推断其存在的自由基中间体。

::: history
电子具有自旋和约一个玻尔磁子的磁矩这一观念，来自斯特恩-盖拉赫实验（1922年）与乌伦贝克、古兹米特对原子光谱的解释（1925年）。费米于1930年推导了超精细结构的接触公式，同年克拉默斯证明了指名于他的简并定理。电子顺磁共振本身由扎沃伊斯基1944年在喀山首次观测到——铜盐与锰盐，射频、几毫特斯拉的磁场；随后战时微波雷达的发展使X波段谱仪成为可能，牛津的布利（Brebis Bleaney）小组在1940年代末与1950年代确立了对过渡金属离子的自旋哈密顿量描述。施温格1948年对反常磁矩的计算解释了$g_\mathrm{e}$为何不恰好是2。1953年韦斯曼与合作者分辨出萘自由基负离子的超精细结构，1956年麦康奈尔把质子耦合与$\pi$自旋密度联系起来；麦康奈尔小组1965年把氮氧自旋标记引入生物膜与蛋白质的研究。
:::

::: summary
- EPR检测含未成对电子的物种；共振条件为$h\nu = g\mu_\mathrm{B}B$，$g_\mathrm{e} = 2.0023$时为$28.025\ \mathrm{MHz\,mT^{-1}}$，所以X波段（$9.5\ \mathrm{GHz}$）的共振在$340\ \mathrm{mT}$附近。谱按磁场扫描记录，记为一阶导数；位置取过零点。
- $g$值因自旋-轨道混合偏离$g_\mathrm{e}$，$\Delta g \sim -2\lambda\lvert L\rvert^{2}/\Delta E$：碳自由基$2.0025$–$2.003$，氧、氮中心自由基$2.004$–$2.02$，金属离子偏离$0.1$以上；$g$是张量，在溶液中由翻滚平均，在冻结样品中铺展成粉末图样（$g_\parallel$、$g_\perp$）。
- 各向同性超精细耦合是费米接触相互作用，$a = \tfrac{2}{3}\mu_0 g_N\mu_\mathrm{N}\lvert\psi(0)\rvert^{2}$：氢原子为$50.7\ \mathrm{mT}$，是核处$s$自旋密度的直接量度。
- $n$个自旋为$I$的等价核给$2nI + 1$条线（质子的二项式$1{:}3{:}3{:}1$，单个$^{14}\mathrm{N}$的$1{:}1{:}1$）；不等价的组相乘，从最大耦合开始逐级构建的棒图可归属谱图（乙基：12条线；萘负离子：25条）。
- $\pi$自由基的α质子耦合服从麦康奈尔经验关系$a_\mathrm{H} = Q\rho_\mathrm{C}$，$Q \approx -2.3$至$-2.7\ \mathrm{mT}$，休克尔$\rho = c^{2}$；β质子经超共轭按$\cos^{2}\theta$耦合。
- 氮氧自旋标记报告运动与距离；自旋捕获把瞬态自由基（DMPO–OH：$1{:}2{:}2{:}1$）转化为持久、可鉴定的氮氧自由基。
- 克拉默斯离子（奇电子数）总是给出EPR；$\mathrm{Cu^{2+}}$显示四条金属超精细线（$I = \tfrac32$）且$g_\parallel > g_\perp > 2$，$\mathrm{Mn^{2+}}$给六条线（$I = \tfrac52$）。
- EPR在X波段、$298\ \mathrm{K}$的极化度为$7.6\times10^{-4}$，约为$400\ \mathrm{MHz}$质子的24倍；冷却到$4.2\ \mathrm{K}$升至约$5\,\%$。
:::

## 习题

::: exercise DPPH标准 {level=1 check="338.77"}
磁场标准物质DPPH的$g = 2.0036$。它在运行于$9.5000\ \mathrm{GHz}$的谱仪上于何磁场共振？（以mT输入$B$。）
::: solution
$B = h\nu/g\mu_\mathrm{B} = (6.626\,070\times10^{-34} \times 9.5000\times10^{9})/(2.0036 \times 9.274\,010\times10^{-24})\ \mathrm{T} = 0.338\,77\ \mathrm{T} = 338.77\ \mathrm{mT}$。某样品的谱线若比DPPH低场$0.4\ \mathrm{mT}$，其$g$值就大约大$2.0036 \times 0.4/338.8 = 0.0024$：微小的磁场差就编码着鉴别自由基的$g$位移。
:::
:::

::: exercise 数谱线 {level=1 check="6"}
水中的羟甲基自由基$^\bullet\mathrm{CH_2OH}$有$a(\mathrm{CH_2}) = 1.74\ \mathrm{mT}$与$a(\mathrm{OH}) = 0.115\ \mathrm{mT}$（后者只在交换缓慢的条件下才分辨得出）。其完全分辨的谱有几条线？（输入谱线数目。）
::: solution
两个等价的$\mathrm{CH_2}$质子给出$1{:}2{:}1$三重峰；羟基质子把每条线再分裂成二重峰。共$3 \times 2 = 6$条线，即二重峰的三重峰，跨$2(1.74) + 0.115 = 3.60\ \mathrm{mT}$。若羟基质子与溶剂快速交换（如在酸性或碱性溶液中），其耦合被平均掉，只剩三重峰——这是核磁共振中熟悉的OH交换效应之EPR版。
:::
:::

::: exercise 磁场单位与频率单位 {level=1 check="64.5"}
把甲基自由基的耦合$a_\mathrm{H} = 2.30\ \mathrm{mT}$（$g = 2.0026$）换算成频率单位。（以MHz输入$A$。）
::: solution
$A = g\mu_\mathrm{B}a/h = 2.0026 \times 13.996\ \mathrm{GHz\,T^{-1}} \times 2.30\times10^{-3}\ \mathrm{T} = 64.5\ \mathrm{MHz}$。对有机自由基，$g$与$g_\mathrm{e}$如此接近，用因子$28.0\ \mathrm{MHz\,mT^{-1}}$即已足够；对金属离子则不然（见[[#ex-metal]]）。
:::
:::

::: exercise 可换算至Q波段的g值测量 {level=2 check="2.0056"}
某氮氧自旋标记在运行于$9.7720\ \mathrm{GHz}$的谱仪上于$348.12\ \mathrm{mT}$共振。求$g$，并预言同一自由基在$34.000\ \mathrm{GHz}$下的共振磁场。（$g$保留四位小数输入。）
::: solution
$g = h\nu/\mu_\mathrm{B}B = (6.626\,070\times10^{-34} \times 9.7720\times10^{9})/(9.274\,010\times10^{-24} \times 0.348\,12) = 2.0056$。在$34.000\ \mathrm{GHz}$下磁场随频率同比缩放：$B = 348.12 \times 34.000/9.7720 = 1211.2\ \mathrm{mT} = 1.2112\ \mathrm{T}$。以mT计的超精细分裂（在一阶近似下）不随频率缩放，而以磁场单位计的$g$差异则正比于$\nu$增大——这就是高频EPR能分辨X波段下重叠在一起的微小$g$各向异性的原因。
:::
:::

::: exercise 液氮温度下的极化度 {level=2 check="0.296"}
计算$S = \tfrac12$物种在$9.50\ \mathrm{GHz}$、$77\ \mathrm{K}$下的分数布居差$\tanh(h\nu/2k_\mathrm{B}T)$，并求它超过$298\ \mathrm{K}$下数值的倍数。（以百分比输入布居差。）
::: solution
$h\nu/k_\mathrm{B}T = (6.626\,070\times10^{-34} \times 9.50\times10^{9})/(1.380\,649\times10^{-23} \times 77) = 5.92\times10^{-3}$，故极化度为$\tanh(2.96\times10^{-3}) = 2.96\times10^{-3} = 0.296\,\%$。$298\ \mathrm{K}$下为$0.0765\,\%$；增益为$298/77 = 3.9$倍，因为当$h\nu \ll k_\mathrm{B}T$时极化度正比于$1/T$（居里定律）。信号的实际增长常常超过这个数，因为低温下弛豫变慢还会使谱线变窄。
:::
:::

::: exercise 蒽负离子的休克尔预测 {level=2 check="0.522"}
蒽的休克尔LUMO中，系数平方在9、10位为$0.193$，在1、4、5、8位为$0.097$，在2、3、6、7位为$0.048$。取$Q = -2.7\ \mathrm{mT}$，预言蒽自由基负离子的三个质子耦合及其谱的谱线数。（以mT输入$\lvert a_{9,10}\rvert$。）
::: hint
对每组用$\lvert a\rvert = \lvert Q\rvert c^{2}$，再把三组的谱线数相乘。
:::
::: solution
$\lvert a_{9,10}\rvert = 2.7 \times 0.193 = 0.522\ \mathrm{mT}$，$\lvert a_{1}\rvert = 2.7 \times 0.097 = 0.26\ \mathrm{mT}$，$\lvert a_{2}\rvert = 2.7 \times 0.048 = 0.13\ \mathrm{mT}$。实测值约为$0.534$、$0.274$与$0.151\ \mathrm{mT}$（韦尔与博尔顿）——大小次序与比值都对，且自旋密度在中心环上最大，而中心环也正是蒽发生反应的位置（Diels–Alder加成、氧化成蒽醌）。三组各含2、4、4个质子，所以谱有$3 \times 5 \times 5 = 75$条线。
:::

::: exercise 全氘代苯负离子 {level=3 check="13"}
苯自由基负离子$\mathrm{C_6H_6^{\bullet-}}$显示七条线，$a_\mathrm{H} = 0.375\ \mathrm{mT}$。预言$\mathrm{C_6D_6^{\bullet-}}$的谱：耦合、谱线数目，以及中心线与最外侧线的强度比。（$g_N(\mathrm{D})/g_N(\mathrm{H}) = 0.1535$。）（输入谱线数目。）
::: hint
氘的$I = 1$。展开$(1 + x + x^{2})^{6}$。
:::
::: solution
同位素取代不改变自旋密度，所以由费米接触公式$a_\mathrm{D} = 0.375 \times 0.1535 = 0.0576\ \mathrm{mT}$。六个等价的$I = 1$核给出$2 \times 6 \times 1 + 1 = 13$条线。其强度是$(1 + x + x^{2})^{6}$的系数：$1{:}6{:}21{:}50{:}90{:}126{:}141{:}126{:}90{:}50{:}21{:}6{:}1$，中心线比最外侧的线强$141$倍。整张谱只跨$12 \times 0.0576 = 0.69\ \mathrm{mT}$，以典型的$0.02$–$0.05\ \mathrm{mT}$线宽勉强能分辨——全氘代常常被有意用来*压窄*质子耦合分辨不出的EPR谱（例如自旋标记的谱）。
:::

::: exercise 宽度求和规则 {level=3 check="2.69"}
（a）证明：对一个每个休克尔自旋密度非零的碳都恰好连一个氢的平面烃自由基离子，麦康奈尔关系预言谱的总宽度（最外侧线到最外侧线）为$\lvert Q\rvert$。（b）用实测的萘负离子耦合（$4 \times 0.490$与$4 \times 0.183\ \mathrm{mT}$）计算总宽度，它估计$\lvert Q\rvert$。（以mT输入宽度。）（c）为什么桥头碳不会破坏这一定则？
::: solution
（a）对质子（$I = \tfrac12$）总宽度为$\sum_j 2n_jIa_j = \sum_j n_j\lvert a_j\rvert$，即对所有质子的$\lvert a\rvert$求和。以带质子$k$的碳满足$\lvert a_k\rvert = \lvert Q\rvert\rho_k$代入，得$\lvert Q\rvert\sum_k\rho_k$。SOMO是归一化的，休克尔理论中$\sum_\mathrm{C} c_\mathrm{C}^{2} = 1$（忽略重叠），而若每个$\rho \neq 0$的碳都带一个质子，则对质子的求和等于对全部碳的求和：宽度$= \lvert Q\rvert$。
（b）$4(0.490) + 4(0.183) = 1.960 + 0.732 = 2.69\ \mathrm{mT}$，故$\lvert Q\rvert \approx 2.69\ \mathrm{mT}$——接近[[#ex-naphthalene]]中用的$2.7\ \mathrm{mT}$，而大于苯负离子的$2.25\ \mathrm{mT}$（六个质子，$6 \times 0.375$）：$Q$并非完美常数。
（c）萘LUMO中桥头系数恰好为零（该轨道有一节面穿过中心键），所以不连氢的碳不带自旋，求和不缺项。对蒽负离子，桥头原子带有小密度（休克尔理论中$4 \times 0.008$），故实测宽度略小于$\lvert Q\rvert$——而休克尔理论之外的自旋极化效应会在某些原子上放小额负自旋密度，所以这一定则终究只是近似的。
:::

::: exercise 线宽与弛豫时间 {level=3 check="65.6"}
一条$g = g_\mathrm{e}$的洛伦兹型EPR谱线的峰-峰宽度为$\Delta B_\mathrm{pp} = 0.100\ \mathrm{mT}$。（a）导出$\Delta B_\mathrm{pp}$与吸收的半高半宽$\Gamma$之间的关系。（b）对均匀增宽谱线，$\Gamma = 1/(\gamma_\mathrm{e}T_2)$，其中$\gamma_\mathrm{e} = g_\mathrm{e}\mu_\mathrm{B}/\hbar$。求$T_2$。（以ns输入$T_2$。）
::: solution
（a）洛伦兹函数为$L(x) = \Gamma^{2}/(x^{2} + \Gamma^{2})$，$x = B - B_\mathrm{res}$。其导数$L'(x) = -2x\Gamma^{2}/(x^{2} + \Gamma^{2})^{2}$在$L''(x) = 0$处取极值：求导得$(x^{2} + \Gamma^{2}) - 4x^{2} = 0$，即$x = \pm\Gamma/\sqrt{3}$。故$\Delta B_\mathrm{pp} = 2\Gamma/\sqrt{3}$，即$\Gamma = (\sqrt{3}/2)\Delta B_\mathrm{pp}$，半高全宽为$\sqrt{3}\,\Delta B_\mathrm{pp}$。
（b）$\Gamma = 0.866 \times 0.100\ \mathrm{mT} = 8.66\times10^{-5}\ \mathrm{T}$；$\gamma_\mathrm{e} = 2.002\,319 \times 9.274\,010\times10^{-24}/1.054\,572\times10^{-34} = 1.7609\times10^{11}\ \mathrm{s^{-1}\,T^{-1}}$。于是$T_2 = 1/(1.7609\times10^{11} \times 8.66\times10^{-5}) = 6.56\times10^{-8}\ \mathrm{s} = 65.6\ \mathrm{ns}$。电子弛豫比核磁共振中质子弛豫（秒量级）快一百万倍，这就是脉冲EPR需要纳秒脉冲的原因，也是快弛豫金属离子（室温下$T_2$为皮秒量级）的谱线宽到看不见、除非冷却样品的原因。
:::
:::
