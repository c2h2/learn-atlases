一位同事递给你一支小瓶，里面是一种熔点$38\ ^\circ\mathrm{C}$、带着淡淡山楂气味的无色固体。标签已经掉了，笔记本上只写着"$\mathrm{C_9H_{10}O_2}$?"。一小时之内，你就能拿到一张高分辨质谱、一张红外光谱以及氢谱与碳-13谱；而这四项测量合在一起，几乎总能无可置疑地鉴定出化合物。它们中任何一项单独都做不到。质谱给出分子式却几乎不谈连接方式；红外报出官能团却不报它们坐在哪里；核磁共振谱绘出碳氢骨架，却既称不出分子的重量，也看不见腈基上的氮。测定结构是一门让每一项数据都与同一个结构相符——并证明再无别的结构符合得同样好——的手艺。本课把[[spectroscopy/mass-spectrometry]]、[[spectroscopy/vibrational-spectroscopy]]与[[spectroscopy/nmr-structure]]的各自技能汇成一个流程，然后拿难度递增的未知物来演练，上面那只小瓶就在其中。

下文引用的所有谱学数据都是这些真实化合物的典型值，取自有机化合物光谱数据库（SDBS，日本产业技术综合研究所AIST）以及Pretsch、Bühlmann与Badertscher的相关表；除特别说明外，核磁共振数据来自$\mathrm{CDCl_3}$溶液，δ以四甲基硅烷为标准、以ppm计，$J$以Hz计。同位素质量取自2020年原子质量评估（AME2020），同位素丰度取自IUPAC，每个数值都经过重新计算。

## 分子式先行 {#sec-formula}

没有分子式的结构题是一个答案太多的题。分子式锁定了你必须摆下的原子数目，并且只需一步算术，就给出答案必须含有的环数与重键数。得到它有三条路，好的做法至少并用其中两条。

**燃烧分析**给出C、H、N的质量分数（氧由差求得），从而给出*实验式*——最小的整数比。它分不出$\mathrm{C_3H_6O}$（丙酮，$M = 58$）与$\mathrm{C_6H_{12}O_2}$（乙酸丁酯，$M = 116$）：两者都是$62.04\,\%$的C与$10.41\,\%$的H。由质谱得到的摩尔质量提供倍数。

**低分辨质谱**给出分子离子$\mathrm{M^{+\bullet}}$（电子电离）或假分子离子如$[\mathrm{M+H}]^+$、$[\mathrm{M+Na}]^+$（电喷雾）的标称质量，其同位素峰图数出碳数并揭示氯、溴与硫。**高分辨质谱**（HRMS）把$m/z$测到几个ppm，足以在同标称质量的分子式之间做出选择，因为没有两种同位素的质量恰好是整数：$^1\mathrm{H} = 1.007\,825\ \mathrm{u}$，$^{14}\mathrm{N} = 14.003\,074\ \mathrm{u}$，$^{16}\mathrm{O} = 15.994\,915\ \mathrm{u}$，而$^{12}\mathrm{C} = 12$是按定义恰好为12。

::: definition 不饱和度（双键当量数） {#def-dbe}
对分子式$\mathrm{C}_c\mathrm{H}_h\mathrm{N}_n\mathrm{O}_o\mathrm{X}_x$（X = F、Cl、Br、I；二价的O与S任意数目），**不饱和度**或称**双键当量数**（DBE）为
$$
\mathrm{DBE} = c - \frac{h + x}{2} + \frac{n}{2} + 1 .
$$ {#eq-dbe}
DBE是以该分子式写出的任何结构中环数加$\pi$键数：一个$\mathrm{C{=}C}$或$\mathrm{C{=}O}$计1，一个$\mathrm{C{\equiv}C}$或$\mathrm{C{\equiv}N}$计2，一个苯环计4（一个环加三条$\pi$键）。它与[[organic-1/organic-structures]]中的不饱和度是同一个量，只是按元素写出。
:::

::: proposition DBE给出环数与π键数 {#prop-dbe}
对于C四价、N三价、O与S二价、H与卤素一价的中性闭壳分子，式[[#eq-dbe]]总是返回一个非负整数，等于环数加$\pi$键数。更一般地，以$n_i$记价数为$v_i$的原子数，
$$
\mathrm{DBE} = 1 + \frac{1}{2}\sum_i n_i\,(v_i - 2) .
$$ {#eq-dbe-general}
:::

::: proof 数分子图的边 {#proof-dbe}
把分子看作一个连通图：原子是顶点，级数为$k$的键是$k$条边。每个原子贡献与其价数相同数目的边端，故边数为$E = \tfrac12\sum_i n_i v_i$。$V = \sum_i n_i$个顶点的连通图恰好需要$V - 1$条边才成为树（一个只含$\sigma$键的无环骨架）；超出这些的每条边要么闭成一个环，要么在已相连的原子之间加一条键，即一条$\pi$键。于是
$$
\mathrm{DBE} = E - (V - 1) = \frac{1}{2}\sum_i n_i v_i - \sum_i n_i + 1 = 1 + \frac{1}{2}\sum_i n_i(v_i - 2),
$$
即式[[#eq-dbe-general]]。代入C的$v = 4$、N的$3$、O与S的$2$、H与X的$1$，得$1 + \tfrac12(2c + n - h - x) = c - \tfrac{h+x}{2} + \tfrac{n}{2} + 1$，即式[[#eq-dbe]]。二价原子$v - 2 = 0$而消去，这就是氧从不改变计数值的原因。结果为半整数意味着该分子式不可能属于中性闭壳分子：它是自由基、是离子（偶电子正离子如$\mathrm{C_7H_7^+}$给出$4.5$），或者算错了。
:::

价数假定要留意。砜中的硫、氧膦中的磷，其键数多于"正常"价数，式[[#eq-dbe]]把$\mathrm{S{=}O}$或$\mathrm{P{=}O}$键当作单键计，于是会低估你会画出的$\pi$键数目。这只是记账方式，不是化学：只要画结构时使用同样的价数，计数仍然自洽。

::: proposition 氮规则 {#prop-nitrogen}
对只含C、H、N、O、S、Si、P与卤素的分子，其标称质量（每个元素取最丰同位素计算）为**奇数当且仅当分子含奇数个氮原子**。EI谱中的分子离子$\mathrm{M^{+\bullet}}$有同样的奇偶性；不含氮分子的偶电子碎片离子的$m/z$为*奇*数，奇电子碎片离子（来自重排）的$m/z$为*偶*数。
:::

::: proof 质量与价数的奇偶性 {#proof-nitrogen}
列出各元素的标称质量与价数：H $(1, 1)$，C $(12, 4)$，N $(14, 3)$，O $(16, 2)$，F $(19, 1)$，Si $(28, 4)$，P $(31, 3)$，S $(32, 2)$，Cl $(35, 1)$，Br $(79, 1)$，I $(127, 1)$。除氮以外，每个元素的质量与价数奇偶相同。总价数$\sum_i n_i v_i = 2E$是偶数，故奇价原子的个数为偶。奇*质量*原子的个数等于这个个数减去氮（奇价、偶质量），所以标称质量为奇恰好当$n$为奇。移去一个电子不改变质量数，故$\mathrm{M^{+\bullet}}$遵循同一规则；偶电子碎片与闭壳分子相差一个氢原子（或一个单电子的成键缺额），把奇偶性翻转。
:::

氮规则是结构测定中最快的检验。$m/z\ 135$处的EI分子离子要求一个（或三个）氮；不含氮化合物的$m/z\ 93$基峰作为偶电子离子本不可能存在，所以它必是重排来的自由基正离子，否则化合物其实含氮。

### 同位素峰图：数碳与数卤素

碳含$1.07\,\%$的$^{13}\mathrm{C}$（IUPAC），所以含$c$个碳的分子每个碳贡献约为$\mathrm{M}$之$1.08\,\%$的$\mathrm{M+1}$峰（即丰度比$0.0107/0.9893$），此外$^2\mathrm{H}$、$^{15}\mathrm{N}$（每个N贡献$0.37\,\%$）与$^{17}\mathrm{O}$还有小贡献。九个碳的$\mathrm{M+1}$峰仅碳就贡献约$\mathrm{M}$的$9.7\,\%$，加上氢与氧共$9.9\,\%$——对强分子离子，这个测量大约能准到$\pm1$个碳，对弱分子离子则毫无用处。氯（$^{35}\mathrm{Cl} : {}^{37}\mathrm{Cl} = 75.76 : 24.24$）与溴（$^{79}\mathrm{Br} : {}^{81}\mathrm{Br} = 50.69 : 49.31$）显眼得多：一个氯给出$\mathrm{M} : \mathrm{M+2} = 100 : 32$，一个溴接近$1 : 1$，$k$个等价卤原子给出两个丰度的二项展开$(a + b)^k$。硫的$^{34}\mathrm{S}$（$4.25\,\%$）给出每个硫约$4.4\,\%$的不大$\mathrm{M+2}$。

::: example 由精确质量选定分子式 {#ex-hrms}
有山楂气味的固体的EI谱显示$\mathrm{M^{+\bullet}}$在$m/z\ 150.0677$，$\mathrm{M+1}$峰为$10\,\%$，无明显$\mathrm{M+2}$。标称质量150的候选分子式有$\mathrm{C_9H_{10}O_2}$、$\mathrm{C_8H_{10}N_2O}$、$\mathrm{C_{10}H_{14}O}$、$\mathrm{C_8H_6O_3}$与$\mathrm{C_9H_{14}N_2}$。哪个相符？结构必须含有多少个环加$\pi$键？
::: solution
该离子是自由基正离子，其质量等于中性单同位素质量减去一个电子（$0.000\,549\ \mathrm{u}$）。对$\mathrm{C_9H_{10}O_2}$：
$$
9(12.000\,000) + 10(1.007\,825) + 2(15.994\,915) - 0.000\,549 = 150.0675 .
$$
其余各分子式同法算得$150.0788$（$\mathrm{C_8H_{10}N_2O}$）、$150.1039$（$\mathrm{C_{10}H_{14}O}$）、$150.0311$（$\mathrm{C_8H_6O_3}$）与$150.1151$（$\mathrm{C_9H_{14}N_2}$）。相对观测值$150.0677$的误差为$+1.1$、$-74$、$-241$、$+244$与$-316$ ppm；现代仪器大约能准到$\pm 3$ ppm，故只有$\mathrm{C_9H_{10}O_2}$存活。同位素数据也吻合：$10\,\%$的$\mathrm{M+1}$正是九个碳应有的（预测$9.9\,\%$），$\mathrm{M+2}$的缺席排除了Cl、Br与S。标称质量为偶，与零个（或两个）氮相容（[[#prop-nitrogen]]）——HRMS已经替我们选定了零个。最后
$$
\mathrm{DBE} = 9 - \frac{10}{2} + 1 = 5 ,
$$
这是苯环（四）再加一个环或$\pi$键的签名——非常常见的是一个羰基。注意：若忽略电子质量，在此质量下每个候选都会偏移$3.7$ ppm：数值不大，却超过一台好仪器的误差预算。
:::
:::

::: warning 分子离子可能缺席 {#warn-missing-m}
EI谱中最高质量的峰未必是$\mathrm{M^{+\bullet}}$。叔醇、许多醚与缩醛以及高度支化的烷烃碎裂太快，以至分子离子微弱或不存在，醇的最高可见峰常常是$\mathrm{M} - 18$（丢失水）。三项检验保护你：假定的$\mathrm{M}$必须遵守氮规则；由它到后续各峰的丢失必须在化学上合理（丢失15、18、28、29、31很常见；丢失4到13或21到25几乎不可能）；若有疑问，软电离方法——电喷雾或化学电离，在$\mathrm{M} + 1$或$\mathrm{M} + 23$处给出$[\mathrm{M+H}]^+$或$[\mathrm{M+Na}]^+$——会显示完整的分子。把碎片误当分子离子会毒化后面每一步，因为分子式与DBE随之全错。
:::

## 每种谱各自贡献什么

每项技术回答的问题不同，诀窍是只问每项技术它擅长回答的问题。

| 技术 | 能可靠回答的 | 薄弱或无法回答的 |
|---|---|---|
| MS / HRMS | 分子式；Cl、Br、S；特征丢失与碎片离子 | 异构体的连接方式；立体化学 |
| IR | $\mathrm{O{-}H}$、$\mathrm{N{-}H}$、$\mathrm{C{=}O}$、$\mathrm{C{\equiv}N}$、$\mathrm{C{\equiv}C}$的有无；羰基的类型 | 碳骨架；没有参比谱时约$1500\ \mathrm{cm^{-1}}$以下的一切 |
| $^{13}\mathrm{C}$ NMR（带DEPT） | 不等价碳的数目；C、CH、CH$_2$、CH$_3$；羰基与芳碳 | 碳的相对数目（峰高不是定量的） |
| $^1\mathrm{H}$ NMR | 质子环境的数目；其比例（积分）；邻居（$n+1$多重性、$J$）；化学环境（δ） | 季碳与杂原子（只能间接看到） |
| 二维核磁共振（COSY、HSQC、HMBC） | 哪些质子相互耦合；哪个质子挂在哪个碳上；两键与三键的C–H联系 | ——（一维谱不够用时的工具） |

有几个地标数值应当记在脑中，因为它们一眼就能定下多数题目（典型区间取自Pretsch等）：

- **红外。**宽$3200$–$3550\ \mathrm{cm^{-1}}$：氢键O–H；非常宽的$2500$–$3300$且伴羰基：羧酸；一条或两条较锐的$3300$–$3500$：N–H；$2250$：腈；$1735$–$1750$：饱和酯；$1705$–$1725$：饱和酮或酸；$1680$–$1690$：芳基酮；$1650$–$1690$：酰胺（酰胺I带），二级酰胺还在$1550$附近有酰胺II带；$1600$与$1500$：芳环。
- **$^{13}\mathrm{C}$。**$195$–$215$：酮与醛的$\mathrm{C{=}O}$；$165$–$180$：酸、酯与酰胺的$\mathrm{C{=}O}$；$110$–$160$：芳碳与烯碳；$50$–$90$：连氧碳（连氮约$40$–$60$）；$0$–$45$：其余$sp^3$碳。
- **$^1\mathrm{H}$。**$9.5$–$10$：醛；$10$–$13$：羧酸；$6.5$–$8.2$：芳烃；$4.5$–$6.5$：烯；$3.3$–$4.5$：连氧的$\mathrm{CH}$（OCH$_3$在$3.7$–$3.9$附近）；$2.0$–$2.7$：C=O的α位或芳环上的$\mathrm{CH}$；$0.8$–$1.8$：烷基。

DEPT-135值得单独说一句，因为它把碳计数变成氢计数：CH与$\mathrm{CH_3}$信号朝上，CH$_2$信号朝下，季碳（包括大多数羰基）消失；DEPT-90只显示CH。把所有DEPT指认碳上的氢加起来与分子式对照，立刻显出杂原子上的氢——OH、NH、SH——那是任何碳谱都看不见的。

## 结构测定的流程

有经验的光谱学家并不照搬固定配方，但确实遵循一个次序，因为每一步都缩小下一步必须搜索的空间。

::: algorithm 由组合谱图确定结构 {#alg-structure}
1. **分子式。**由HRMS确立分子式，或由标称$\mathrm{M}$加燃烧分析；检验氮规则与同位素峰图（碳数、Cl、Br、S）。
2. **DBE。**用式[[#eq-dbe]]算环加$\pi$键。DBE $\ge 4$提示苯环；DBE $= 1$容许一个环*或*一个双键。
3. **官能团。**从红外读O–H、N–H、C=O（及其类型）、C≡N、C≡C；像记录*存在*什么一样仔细记录*缺失*什么。
4. **碳数与碳型。**数$^{13}\mathrm{C}$信号；少于分子式的碳数意味着对称。用DEPT（或HSQC）把每个碳分类为C、CH、CH$_2$或CH$_3$；把碳上氢加和与分子式对照。
5. **质子碎片。**把$^1\mathrm{H}$积分化成加和等于分子式$h$的质子整数；由位移与多重性写出碎片（CH$_3$CH$_2$–O、CH$_3$C=O、对位二取代环……）。$J$相同的耦合属于相邻基团。
6. **拼合。**用余下的原子与DBE把碎片接成与它们全部相容的每一个结构——列出*所有*候选，而不只是首先想到的那一个。
7. **区分。**对每个候选预测位移、多重性、红外谱带与关键碎片离子；淘汰与任何数据矛盾的候选。一维数据无法决断时用二维核磁共振（尤其是HMBC）。
8. **验证。**用每一项观测检验幸存的结构——每个峰、每个积分、每个缺席。一个解释不了的信号，要么是能指名的杂质，要么是结构错误的征兆。
:::

两种习惯区分可靠的解答与侥幸的猜测。其一，*先枚举，再选择*：第6步要求写出碎片允许的每一个结构，因为最常见的错误是停在第一个说得过去的异构体上。其二，*让缺席发言*：没有O–H伸缩，一举排除醇与酸；氢谱在δ 3.0以上没有信号，排除OCH基团；$^{13}\mathrm{C}$在$160$以上没有信号，除极罕见情形外排除羰基。

## 未知物解析实例

下面四个未知物难度递增：一个简单酯；一个带可交换质子的醇；一个带几乎同形异构体的芳烃；以及一个质谱中有重排的含氮化合物。

::: example 未知物A：果香液体，C₅H₁₀O₂ {#ex-ester}
一种带果香的无色液体，燃烧分析得C $58.80\,\%$、H $9.87\,\%$；EI质谱显示$m/z\ 102$处微弱的$\mathrm{M^{+\bullet}}$以及$m/z\ 57$与$29$处的强峰。红外：$1738$（强）、$1190\ \mathrm{cm^{-1}}$（强），除C–H外$3000\ \mathrm{cm^{-1}}$以上无吸收。核磁共振数据：

| $^1\mathrm{H}$ δ | 多重峰形（$J$/Hz） | 积分 | $^{13}\mathrm{C}$ δ | DEPT |
|---|---|---|---|---|
| 4.12 | 四重峰（7.1） | 2 | 174.5 | C |
| 2.31 | 四重峰（7.6） | 2 | 60.3 | CH$_2$ |
| 1.25 | 三重峰（7.1） | 3 | 27.6 | CH$_2$ |
| 1.13 | 三重峰（7.6） | 3 | 14.2 | CH$_3$ |
| | | | 9.1 | CH$_3$ |

鉴定该化合物。
::: solution
**分子式。**氧由差求得$100 - 58.80 - 9.87 = 31.33\,\%$。除以原子量：$\mathrm{C}\ 58.80/12.011 = 4.896$，$\mathrm{H}\ 9.87/1.008 = 9.79$，$\mathrm{O}\ 31.33/15.999 = 1.958$；比为$2.50 : 5.00 : 1$，即实验式$\mathrm{C_5H_{10}O_2}$（$M = 102.13$）。102处的分子离子说明实验式与分子式重合。质量为偶，无氮。

**DBE** $= 5 - 10/2 + 1 = 1$：一个环或一条$\pi$键。

**红外。**$1738\ \mathrm{cm^{-1}}$处的强带、$1190$附近的强C–O伸缩而没有O–H，是一个饱和酯，正好用掉唯一的DBE和两个氧。

**$^{13}\mathrm{C}$。**五个碳五条信号：无对称性。$174.5$（C）是酯羰基，$60.3$（$\mathrm{CH_2}$）是连氧碳，余下三个烷基碳。

**$^1\mathrm{H}$。**积分$2:2:3:3$合计10，与分子式吻合。两组四重峰–三重峰对意味着两个乙基；配对的耦合常数把它们配对：$4.12$的四重峰（$J = 7.1$）配$1.25$的三重峰（$J = 7.1$），$2.31$的四重峰（$J = 7.6$）配$1.13$的三重峰（$J = 7.6$）。第一个乙基连在氧上（δ 4.12的OCH$_2$，碳在60.3）；第二个连在羰基上（δ 2.31的$\mathrm{CH_2C{=}O}$）。

**拼合。**$\mathrm{CH_3CH_2{-}C(=O){-}O{-}CH_2CH_3}$：**丙酸乙酯**。$\mathrm{C_5H_{10}O_2}$的异构酯全被氢谱排除：丁酸甲酯会在δ 3.67显示OCH$_3$单峰；乙酸丙酯会有δ 2.05的乙酰基单峰；乙酸异丙酯会有δ 5.0附近的七重峰与6H二重峰。分子式相同的戊酸会显示$2500$到$3300$的宽红外带以及δ 11附近的质子。

**用质谱验证。**羰基处的α-断裂给出丙酰正离子（酰基正离子）$\mathrm{CH_3CH_2C{\equiv}O^+}$（$m/z\ 57$）与乙基正离子（$m/z\ 29$）：两者均可见。每项数据都有了着落。

::: example 未知物B：芳香醇，C₈H₁₀O {#ex-alcohol}
一种无色液体的$\mathrm{M^{+\bullet}}$在$m/z\ 122$（HRMS $122.0726$，合$\mathrm{C_8H_{10}O}$），EI峰在$m/z\ 107$（基峰）、$79$与$77$。红外：宽而强的$3360$；$3030$；$1600$、$1495$、$1450$；$1075$；强的$760$与$700\ \mathrm{cm^{-1}}$。核磁共振：

|---|---|---|---|---|
| 7.38–7.25 | 多重峰 | 5 | 145.8 | C |
| 4.89 | 四重峰（6.5） | 1 | 128.5 | CH |
| 1.90 | 宽单峰 | 1 | 127.5 | CH |
| 1.49 | 二重峰（6.5） | 3 | 125.4 | CH |
| | | | 70.4 | CH |

样品经一滴$\mathrm{D_2O}$振摇后，δ 1.90的信号消失。鉴定该化合物。
::: solution
**DBE** $= 8 - 10/2 + 1 = 4$：苯环是显而易见的候选，红外（$3030$的芳C–H，$1600$与$1495$的环伸缩）、五个芳$^{13}\mathrm{C}$……实为四条芳信号（145.8、128.5、127.5、125.4）以及δ 7.3附近的五质子多重峰都证实了它。

**环的取代模式。**五个芳烃质子意味着**单取代**苯；四条芳碳信号恰好与之相合（*ipso*碳、2个*邻位*、2个*间位*、1个*对位*——由对称性成对等价）。$760$与$700\ \mathrm{cm^{-1}}$的强面外弯曲是经典的单取代苯峰对。

**羟基。**红外$3360\ \mathrm{cm^{-1}}$的宽带是氢键O–H，那个随$\mathrm{D_2O}$消失的宽单质子宽峰（交换$\mathrm{ROH + D_2O \rightleftharpoons ROD + HOD}$）就是该质子：其位移取决于浓度与温度，除"是个OH"外不携带结构信息。DEPT计数证实了它：碳上氢为$3\times\mathrm{CH}$（芳基，$2+2+1 = 5$个H）$+ 1$（δ 70.4）$+ 3$（CH$_3$）$= 9$，比分子式的十个少一。

**侧链。**剩下$\mathrm{C_2H_4}$加OH：一个δC 70.4（连氧）的CH，其质子（δ 4.89）是四重峰，以$J = 6.5$与一个甲基二重峰（δ 1.49，$J = 6.5$）耦合。这就是$\mathrm{CH_3{-}CH(OH){-}}$，而且它必须接在环上（δ 4.89的CH同时被氧与环移向低场）。

**拼合。**$\mathrm{C_6H_5{-}CH(OH){-}CH_3}$：**1-苯乙醇**（1-phenylethanol）。其异构体都不符：2-苯乙醇$\mathrm{C_6H_5CH_2CH_2OH}$会给出两个2H三重峰（δ 3.85与2.86）与两个CH$_2$碳；苄基甲基醚没有OH而有一个OCH$_3$单峰；甲基苄醇会显示4H的芳烃图样以及δ 2.3附近的ArCH$_3$单峰。

**质谱。**$m/z\ 107$的基峰是$\mathrm{M} - 15$：氧旁的α-断裂赶出甲基自由基，留下共振稳定的氧鎓离子$\mathrm{C_6H_5CH{=}OH^+}$——一个奇质量的偶电子离子，正是[[#prop-nitrogen]]所要求的；$m/z\ 79$与$77$由它丢失CO而来，并接苯基正离子。注意分子是手性的：谱图分不出对映体，任一纯对映体或外消旋体在非手性溶剂中给出完全相同的数据。

::: quiz 哪个酯？
某化合物$\mathrm{C_4H_8O_2}$的红外在$1742\ \mathrm{cm^{-1}}$，氢谱是三个不含单峰的信号？不对——是恰好三个信号：δ 4.12（四重峰，2H）、2.05（单峰，3H）、1.26（三重峰，3H）。它是哪个化合物？
- [ ] 丙酸甲酯，$\mathrm{CH_3CH_2CO_2CH_3}$
- [x] 乙酸乙酯，$\mathrm{CH_3CO_2CH_2CH_3}$
- [ ] 丁酸，$\mathrm{CH_3CH_2CH_2CO_2H}$
- [ ] 甲酸丙酯，$\mathrm{HCO_2CH_2CH_2CH_3}$
::: solution
δ 4.12的四重峰是氧上紧邻一个CH$_3$（1.26的三重峰）的CH$_2$，所以乙基是*烷氧基*部分；δ 2.05的单峰是羰基上的甲基。这就是乙酸乙酯。丙酸甲酯的排布正好相反——δ 3.67的OCH$_3$单峰，紧邻羰基的δ 2.33CH$_2$四重峰。丁酸会显示宽O–H带与δ 11附近的质子；甲酸丙酯会有δ 8.1的甲酰基单峰。两个酯有相同的碎片（乙基、甲基、酯基）；只有化学位移说明哪个基团在酯氧的哪一边。
:::

## 陷阱、杂质与一致性检验

多数错误的结构不是读谱读错造成的，而是读得太过：给一个假峰赋予意义，或没注意一个信号藏着两个信号。下面是常见陷阱的简短清单。

**可交换质子。**OH、NH与SH质子的位移随浓度、温度、溶剂与含水量而变；它们常常很宽，可能看不到与邻居的耦合（快速交换把耦合平均掉了），甚至完全不可见。在$\mathrm{CDCl_3}$中，醇的OH可以落在δ 1到5的任何地方，酰胺NH在5.5到8.5，羧酸OH在10到13。检验办法是$\mathrm{D_2O}$振摇；在交换很慢的DMSO-$d_6$中，OH质子变得锐利并确实显示耦合（二级醇的$\mathrm{CH{-}OH}$二重峰），由此可分伯、仲、叔醇。

**溶剂与常见杂质。**氘代溶剂的氘代率从不是100 %，样品也极少有100 %纯。$\mathrm{CDCl_3}$中，残留的$\mathrm{CHCl_3}$在δ 7.26给一个单峰（溶剂碳在δC 77.16给$1:1:1$三重峰）；溶解的水在δ 1.56附近给单峰；洗玻璃器皿带来的丙酮在2.17，二氯甲烷在5.30，乙酸乙酯在4.12（四重峰）、2.05（单峰）与1.26（三重峰），润滑脂在0.86与1.26。这些数值（以及其他溶剂的）由Gottlieb、Kotlyar与Nudelman（1997）以及Fulmer等（2010）列表给出；把那张表放在谱仪旁边。注意乙酸乙酯——最常用的重结晶与色谱溶剂——恰好模仿乙酯的OCH$_2$CH$_3$基团——这正是要把积分与分子式核对、而不是轻信图样的理由。

**对称性减少信号数。**等价核给一个信号，所以化合物显示的信号常少于它的碳数或质子数：对位二取代环（两条芳CH信号），叔丁基（一个9H单峰，两个碳），异丙基（一个6H二重峰）。反过来，非对映异位质子——手性中心旁的两个CH$_2$氢——*不*等价，可以给出两个信号与一个额外耦合。先数信号，再问什么样的对称性能解释这个数目。

**重叠信号。**位移几乎相等的两个不同基团给出一个表观多重峰，其积分是两者之和——δ 1.25与1.27的两个甲基看起来像一个6H二重峰。警告信号是除不尽分子式的积分，以及违反$n+1$规律的多重性。换用更高场、更换溶剂（苯-$d_6$使许多信号移$0.1$–$0.5$ ppm）或二维谱可以把它们分开。

**季碳与杂原子在$^1\mathrm{H}$中不可见。**羰基、腈、季碳或醚氧会打断耦合网络：两侧的质子互不耦合（除弱的远程耦合外），氢谱于是分裂成孤立的**自旋体系**。跨越这些"哑"原子把自旋体系连起来，是分子式、红外——以及决定性的——HMBC谱的工作，后者显示两键与三键的C–H相关。

::: warning 合理的结构不等于确证的结构 {#warn-proof}
"说得通"还不够；只有当一个结构解释每项数据*并且*每个说得通的候选都被至少一项与它矛盾的数据排除时，结构才算确立。最常见的失误有：停在第一个想到的异构体上（未知物C就有一个能吻合大部分数据的酯异构体）；因为某个小峰碍事就忽略它（它可能是OH，也可能是混合物的征兆）；把$^{13}\mathrm{C}$峰高当积分用（季碳弛豫慢、无核Overhauser增强，因而很弱）；以及把文献式的位移值当作精确值（预测位移对$^1\mathrm{H}$大约准到$\pm 0.2$ ppm，对$^{13}\mathrm{C}$准到$\pm 3$–$5$ ppm）。当决断系于一个小差别时，去拿第二项独立的数据：一个HMBC交叉峰、一个真实样品的参比谱、一个熔点。
:::

未知物A的结构可以概括成一张碎片图，碎片经由两个"哑"原子——羰基碳与酯氧——相连。两个质子自旋体系（各为一个乙基）互不耦合；把它们连起来的是化学——分子式、红外的酯带，必要时还有两个CH$_2$到δC 174.5羰基碳的HMBC相关。

caption: 丙酸乙酯（未知物A）的连接关系。带权重的边是$^1\mathrm{H}$谱中看到的邻位耦合（$J$/Hz）：它们定义两个分离的自旋体系$\mathrm{CH_3}$(a)–$\mathrm{CH_2}$(b)与$\mathrm{CH_2}$(c)–$\mathrm{CH_3}$(d)。不带标签的边经过羰基碳与酯氧，它们不连质子，因而打断耦合网络。哪个乙基在酯的哪一边由化学位移决定（OCH$_2$在δ 4.12，CH$_2$C=O在δ 2.31），并可用HMBC证实——两组CH$_2$质子都与羰基碳相关，但只有δ 4.12的质子经氧与它相隔三键。
:::

最后一轮**一致性检验**只需两分钟，却能抓住多数错误：

- 所提结构的原子加和等于分子式，其环加$\pi$键等于DBE。
- 积分化成质子数后加和等于分子式的氢数；DEPT氢加上可交换质子也等于。
- $^{13}\mathrm{C}$信号数等于该结构对称性不等价碳的数目。
- 每个耦合都出现两次，以相同的$J$出现在它连接的两个基团上。
- $1500\ \mathrm{cm^{-1}}$以上每条强红外谱带都有归属，结构应有的谱带一条不缺。
- 主要碎片离子来自合理的断裂，其奇偶性遵守氮规则。

## 后续内容

真实的结构题更大：含三十个碳的天然产物、立体化学要命的反应产物、$0.1\,\%$水平的杂质。同一流程规模照上，只是工具变了。二维核磁共振——COSY追自旋体系、HSQC把每个质子挂到它的碳上、HMBC跨越季碳与杂原子搭桥、NOESY测空间距离从而定相对构型——成为主干，[[spectroscopy/nmr-structure]]有讲述。串联质谱与LC–MS无需分离就能指认混合物的组分（[[spectroscopy/mass-spectrometry]]）。计算机辅助结构解析程序枚举与分子式及二维相关相容的每个结构并按预测谱排序，量子化学的位移预测能在非对映体之间决断。有晶体时，X射线衍射直接给出结构，包括绝对构型。这些题目所需的立体化学词汇在[[organic-1/stereochemistry]]，而你要鉴定产物的那些反应挤满[[organic-2/carbonyl-addition]]及其后的各章。

::: history
在光谱学之前，一个结构靠降解为已知化合物和靠独立合成来证明——一种天然产物可以占住一间实验室几十年。转变在二战之后迅速到来。商用红外光谱仪在1940年代遍及工业实验室；1951年斯坦福的阿诺德（James Arnold）、达尔马蒂（S. S. Dharmatti）与帕卡德（Martin Packard）分辨出乙醇的三个质子信号，表明核磁共振能分辨化学环境；1950年代，Fred McLafferty与Klaus Biemann弄清了有机离子如何碎裂，使质谱可以解读。Robert Silverstein与G. Clayton Bassler在《有机化合物的波谱鉴定》（*Spectrometric Identification of Organic Compounds*，第一版1963年）中把这套合并方法写成教材，至今仍在印行。1965年起，斯坦福的DENDRAL项目——Joshua Lederberg、Edward Feigenbaum、Bruce Buchanan与Carl Djerassi——建成了最早的专家系统之一，从质谱提出结构，是今天计算机辅助结构解析的祖先。让·热内尔（Jean Jeener）1971年提出、恩斯特（Richard Ernst）发展的二维核磁共振（1991年诺贝尔化学奖）使大分子的连接方式成为常规；而Gottlieb、Kotlyar与Nudelman（1997）的核磁共振杂质实用表成为有机化学中被引最多的论文之一。
:::

::: summary
- 从分子式开始：HRMS（准到几个ppm，自由基正离子记得减电子质量），或标称$\mathrm{M}$加燃烧分析；同位素峰图数碳（每个C约$1.1\,\%$的$\mathrm{M+1}$）并显出Cl（$100 : 32$）、Br（约$1 : 1$）与S。
- $\mathrm{DBE} = c - (h+x)/2 + n/2 + 1$计数环加$\pi$键（它是分子图的边数减一棵生成树）；DBE $\ge 4$提示苯环。
- 氮规则：奇标称质量$\Leftrightarrow$奇数个N；无氮分子的偶电子碎片$m/z$为奇。
- 每项技术只问它擅长回答的：红外问官能团（及其缺席），$^{13}\mathrm{C}$/DEPT问碳数与碳型，$^1\mathrm{H}$问质子比、邻居与环境，质谱问分子式与特征丢失，HMBC跨越哑原子连接自旋体系。
- 遵循流程——分子式、DBE、官能团、碳、质子碎片、拼出*所有*候选、区分、验证——选择异构体之前先枚举。
- 提防陷阱：可交换的OH/NH（用$\mathrm{D_2O}$），溶剂与杂质峰（$\mathrm{CDCl_3}$中$\mathrm{CHCl_3}$ 7.26、$\mathrm{H_2O}$ 1.56），对称性减少的信号数，重叠的多重峰，以及不定量的$^{13}\mathrm{C}$强度。
- 只有当一个结构解释每项数据、而每个候选都至少被一项数据否证时，结构才算证明。
:::

## 习题

::: exercise 不饱和度 {level=1 check="5"}
计算$\mathrm{C_{10}H_{12}O_2}$的双键当量数，并说明它意味着什么。（输入DBE。）
::: solution
$\mathrm{DBE} = 10 - 12/2 + 1 = 5$。五个环加$\pi$键：极可能是一个苯环（四）加一个C=O或C=C。丁香酚型苯酚、苯乙酸乙酯、4-甲氧基苯基丙酮、苯甲酸丙酯？——不，苯甲酸丙酯也是$\mathrm{C_{10}H_{12}O_2}$——都符合；单靠分子式留下几十个候选，这就是需要谱图的原因。
:::
:::

::: exercise 数碳信号 {level=1 check="3"}
1,3,5-三甲苯（均三甲苯）的$^1\mathrm{H}$信号在δ 6.78（单峰，3H）与2.26（单峰，9H）。它的质子去耦$^{13}\mathrm{C}$谱显示几个信号？（输入信号数。）
::: solution
分子有三重对称（点群$D_{3h}$）：三个甲基碳全等价，三个连甲基的环碳全等价，三个CH环碳全等价。九个碳因此给**三**条信号（实测在δC 137.7（C）、127.0（CH）与21.2（$\mathrm{CH_3}$）附近）。氢谱相应地简单：两个单峰比$3 : 9 = 1 : 3$，芳烃质子彼此*间位*且等价，故看不到分辨的耦合。
:::
:::

::: exercise 氮规则 {level=1 check="11"}
一个只含C、H与一个N的胺的EI分子离子在$m/z\ 121$，含八个碳。它含几个氢？（输入H原子数。）
::: solution
$\mathrm{C_8N}$的质量为$8 \times 12 + 14 = 110$，余$121 - 110 = 11$给氢：$\mathrm{C_8H_{11}N}$。奇数质量与一个氮相符。用DBE检验：$8 - 11/2 + 1/2 + 1 = 4$，是整数——中性闭壳分子必须如此——并提示一个苯环，如苯乙胺、*N*,*N*-二甲基苯胺或乙基苯胺。若算术给出半整数的DBE，氢数就算错了。
:::
:::

::: exercise 由精确质量定分子式 {level=2 check="2"}
某化合物给$\mathrm{M^{+\bullet}}$于$m/z\ 136.0519$。候选是$\mathrm{C_8H_8O_2}$、$\mathrm{C_9H_{12}O}$与$\mathrm{C_5H_4N_4O}$。哪个正确？（输入正确分子式中氧原子的数目。）
::: solution
自由基正离子质量（中性单同位素质量减$0.000\,549$）：$\mathrm{C_8H_8O_2}$，$96 + 8.062\,600 + 31.989\,829 - 0.000\,549 = 136.0519$；$\mathrm{C_9H_{12}O}$，$136.0883$；$\mathrm{C_5H_4N_4O}$，$136.0380$。误差为$0.1$、$-267$与$+103$ ppm，故分子式是$\mathrm{C_8H_8O_2}$，含**2**个氧（DBE 5；苯甲酸甲酯与4-甲氧基苯甲醛是它的异构体）。富氮候选还以一种更微妙的方式通不过氮规则检验：四个氮给偶数质量，单靠氮规则无法排除它——只有精确质量能。
:::

::: exercise 溴氯同位素峰图 {level=2 check="129"}
1-溴-4-氯苯含一个Br与一个Cl。用$^{35}\mathrm{Cl} : {}^{37}\mathrm{Cl} = 75.76 : 24.24$与$^{79}\mathrm{Br} : {}^{81}\mathrm{Br} = 50.69 : 49.31$，预测$\mathrm{M+2}$与$\mathrm{M+4}$峰相对$\mathrm{M}$的高度（忽略$^{13}\mathrm{C}$）。（以$\mathrm{M}$之百分比输入$\mathrm{M+2}$的高度。）
::: solution
同位素异构体的概率相乘：$\mathrm{M}$（$^{79}\mathrm{Br}{}^{35}\mathrm{Cl}$）$= 0.5069 \times 0.7576 = 0.3840$；$\mathrm{M+2}$（$^{81}\mathrm{Br}{}^{35}\mathrm{Cl}$或$^{79}\mathrm{Br}{}^{37}\mathrm{Cl}$）$= 0.4931 \times 0.7576 + 0.5069 \times 0.2424 = 0.3736 + 0.1229 = 0.4964$；$\mathrm{M+4}$（$^{81}\mathrm{Br}{}^{37}\mathrm{Cl}$）$= 0.4931 \times 0.2424 = 0.1195$。相对$\mathrm{M}$：$100 : 129 : 31$。$\mathrm{M+2}$峰*高于*$\mathrm{M}$——这个图样一眼认出BrCl，两个Cl（$100 : 64 : 10$）与两个Br（$100 : 195 : 95$）都模仿不了。
:::

::: exercise 一个小酯 {level=2 check="57"}
一种液体$\mathrm{C_4H_8O_2}$显示红外$1740\ \mathrm{cm^{-1}}$与$^1\mathrm{H}$核磁共振δ 3.67（单峰，3H）、2.33（四重峰，$J = 7.6$，2H）、1.14（三重峰，$J = 7.6$，3H）；$^{13}\mathrm{C}$ δ 174.9、51.6、27.5、9.2。鉴定它，并给出由丢失甲氧基自由基的α-断裂生成的酰基正离子的$m/z$。（输入$m/z$。）
::: solution
DBE $= 4 - 4 + 1 = 1$，被酯的C=O用掉（$1740\ \mathrm{cm^{-1}}$，δC 174.9）。δ 3.67、δC 51.6的3H单峰是OCH$_3$——甲酯；乙基（四重峰δ 2.33、三重峰1.14，$J$相同）在羰基上，其CH$_2$在δ 2.33，是CH$_2$C=O的典型值。该化合物是**丙酸甲酯**，$\mathrm{CH_3CH_2CO_2CH_3}$；其异构体乙酸乙酯（见上面的小测）的OCH$_2$四重峰在δ 4.12、乙酰基单峰在2.05。从$\mathrm{M^{+\bullet}}$（88）丢失$\mathrm{CH_3O^\bullet}$（31）得$m/z$ **57**的$\mathrm{CH_3CH_2C{\equiv}O^+}$，按氮规则它必是奇质量的偶电子离子。
:::
:::

::: exercise 两个芳基酮 {level=3 check="7"}
某化合物$\mathrm{C_9H_{10}O}$的红外在$1683\ \mathrm{cm^{-1}}$；$^1\mathrm{H}$ δ 7.86（二重峰，$J = 8.2$，2H）、7.25（二重峰，$J = 8.2$，2H）、2.57（单峰，3H）、2.41（单峰，3H）；质谱$m/z$ 134、119（基峰）、91。(a) 鉴定它，并解释为什么它不是苯丙酮$\mathrm{C_6H_5COCH_2CH_3}$。(b) 它的$^{13}\mathrm{C}$谱显示几个信号？（输入$^{13}\mathrm{C}$信号数。）
::: hint
先算DBE；然后问：两个各2H、$J$相同的二重峰对环意味着什么。
:::
::: solution
(a) DBE $= 9 - 5 + 1 = 5$：一个苯环加C=O；红外$1683\ \mathrm{cm^{-1}}$的谱带是共轭（芳基）酮。两个各2H、只有一个邻位$J$的二重峰意味着对位二取代环。两个甲基单峰一个是乙酰基（δ 2.57，在C=O上），一个是芳基甲基（δ 2.41，在环上）。该化合物是**1-(4-甲基苯基)乙-1-酮**（4′-甲基苯乙酮）。苯丙酮会显示单取代环（5H：7.97（2H）、7.55（1H）、7.45（2H））与一个乙基——δ 2.99的四重峰与1.23的三重峰——根本没有单峰。质谱也吻合：$134 - 15 = 119$是4-甲基苯甲酰离子（α-断裂丢$\mathrm{CH_3^\bullet}$），它丢失CO给出$m/z\ 91$的$\mathrm{C_7H_7^+}$离子；苯丙酮则丢乙基自由基，给出$m/z\ 105$的苯甲酰离子。

(b) 对位环有一张过C1与C4的镜面，六个碳给四条信号（C1、C2/6、C3/5、C4）；加上C=O、乙酰基的CH$_3$与芳基的CH$_3$：**7**条信号（实测在δC 197.8、143.9、134.8、129.3、128.5、26.5、21.6附近）。
:::

::: exercise 一个带七重峰的酮 {level=3 check="43"}
一种挥发性液体$\mathrm{C_5H_{10}O}$的红外在$1715\ \mathrm{cm^{-1}}$（无O–H，$2720$附近无醛C–H）；$^1\mathrm{H}$ δ 2.58（七重峰，$J = 7.0$，1H）、2.13（单峰，3H）、1.10（二重峰，$J = 7.0$，6H）；$^{13}\mathrm{C}$ δ 212.5、41.6、27.5、18.2。(a) 鉴定化合物，并明确排除戊-2-酮与戊-3-酮。(b) 它的EI基峰来自留下较小酰基正离子的α-断裂。给出其$m/z$。（输入$m/z$。）
::: solution
(a) DBE $= 5 - 5 + 1 = 1$，被饱和酮用掉（$1715\ \mathrm{cm^{-1}}$，δC 212.5）；$2720\ \mathrm{cm^{-1}}$附近无醛C–H伸缩、δ 9.7附近无质子，排除了戊醛。五个碳只给四条碳信号说明两个碳等价：6H二重峰是CH上两个等价的甲基（那个七重峰：$6 + 1 = 7$条线），即异丙基；δ 2.13的3H单峰是甲基酮。结构为$\mathrm{CH_3C(=O)CH(CH_3)_2}$，**3-甲基丁-2-酮**。戊-3-酮$(\mathrm{CH_3CH_2})_2\mathrm{CO}$只会显示一个四重峰与一个三重峰（$2:3$）与三条碳信号；戊-2-酮会显示一个3H单峰、一个2H三重峰、一个2H六重峰与一个3H三重峰，以及五条碳信号。

(b) 羰基两侧的α-断裂分别给$(\mathrm{CH_3})_2\mathrm{CHC{\equiv}O^+}$（$m/z\ 71$）或$\mathrm{CH_3C{\equiv}O^+}$；基峰是$m/z$ **43**的乙酰正离子（$12 + 3 + 12 + 16$），异丙基正离子（也是43）有所贡献。相比之下，戊-3-酮的基峰在$m/z\ 57$（$\mathrm{C_2H_5CO^+}$）。
:::

::: exercise 其他元素的DBE {level=3 check="12"}
从式[[#eq-dbe-general]]出发，导出四价Si与三价P的分子式$\mathrm{C}_c\mathrm{H}_h\mathrm{Si}_s\mathrm{P}_p\mathrm{O}_o$的DBE表达式，并用于三苯基膦$\mathrm{C_{18}H_{15}P}$。用数结构中环与$\pi$键的办法检验你的答案。（输入三苯基膦的DBE。）
::: solution
C与Si的$v - 2 = 2$，P的$1$，O的$0$，H的$-1$：$\mathrm{DBE} = 1 + \tfrac12(2c + 2s + p - h) = c + s - \tfrac{h}{2} + \tfrac{p}{2} + 1$。硅的行为与碳完全相同，三价磷与氮完全相同。对$\mathrm{C_{18}H_{15}P}$：$\mathrm{DBE} = 18 - 7.5 + 0.5 + 1 = $ **12**。结构$\mathrm{P(C_6H_5)_3}$有三个苯环，每个是一环加三条$\pi$键：$3 \times 4 = 12$。对三苯基膦氧化物$\mathrm{C_{18}H_{15}OP}$，分子式仍给12，因为P=O键在把P按"三价"、O按二价记账时算作单键加零——与[[#proof-dbe]]之后讨论的砜的记账注意事项相同。
:::

::: exercise 认出杂质 {level=2}
$\mathrm{CDCl_3}$中的1-苯乙醇样品，除[[#ex-alcohol]]的信号外，还在δ 7.26（单峰）、5.30（单峰）、2.05（单峰）、4.12（四重峰）与1.26（三重峰）处显示小信号，且OH信号移到了δ 2.3。解释每个多余信号以及OH的移动。
::: solution
δ 7.26是溶剂中残留的$\mathrm{CHCl_3}$（总是存在，部分掩在该化合物的芳烃多重峰下）；δ 5.30是二氯甲烷；δ 2.05（单峰）、4.12（四重峰）与1.26（三重峰）按$3 : 2 : 3$之比是乙酸乙酯，大概是色谱留下的——三个信号必须按该比例相互积分，这就是区分溶剂与化合物一部分的办法。OH位移取决于浓度、温度与含水量：氢键使更浓或更干的样品移向低场，所以从δ 1.90移到2.3在结构上毫无意义。Gottlieb等（1997）与Fulmer等（2010）的表把这些全列了出来；对付溶剂的办法是更久地真空干燥，而不是重新解读。
:::
