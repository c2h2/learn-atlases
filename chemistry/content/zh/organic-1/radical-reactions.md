本课程到目前为止画出的每一个机理，做的都是电子*对*的交易：亲核试剂给出一对电子，离去基团带走一对电子，碳正离子守着一个空轨道干等（[[organic-1/acidity-mechanism]]、[[organic-1/nucleophilic-substitution]]）。这是离子式的化学之道，也是溶液中绝大多数有机反应的进行方式。但还有第二条平行的流通体系，在其中键是*平均*断裂的，每个碎片各得一个电子，主角是电中性、短命、携带一个未成对电子的物种：**自由基**。自由基化学不是奇异的附录。工业规模的甲烷氯化、醇酸油漆的固化、从购物袋到人工髋关节的种种塑料制品、一罐陈年坚果里油脂的酸败、打火机的火焰，以及免疫系统的氧化爆发，全都是自由基链式过程。本章将从一个记账思想——单电子账本——建立起整个学科，并在一则漂亮的物理逻辑推理处达到高潮：为什么溴是一个挑剔的完美主义抽氢剂，而氯却来者不拒；哈蒙德假说如何把这一差别变成数字。

## 自由基、均裂与鱼钩箭头

::: definition 自由基与均裂 {#def-radical}
**自由基**（旧称游离基）是携带一个或多个**未成对电子**的物种；本章的碳自由基在碳上带有七个价电子，用一个点书写：$\mathrm{CH_3^{\bullet}}$。共价键由一对电子构成，因此它可以以两种方式断裂。**均裂**（均裂分解）把键*平均*断开：每个碎片各带走一个电子，$\mathrm{A{-}B \rightarrow A^{\bullet} + B^{\bullet}}$，其代价是键的解离焓（BDE）。**异裂**把键*不均*断开：一个碎片带走两个电子，生成离子——这就是 [[organic-1/nucleophilic-substitution]] 整章的化学。单电子的移动用**鱼钩箭头**（半箭头的箭头，$\rightharpoonup$）表示：一个鱼钩对应一个电子，而一个键的均裂需要*两个*鱼钩，各指向一个原子。
:::

均裂的能量代价就是 BDE 本身，而这个代价决定了制造自由基的条件。$243\ \mathrm{kJ\,mol^{-1}}$ 的键至多对应波长 $492\ \mathrm{nm}$ 的光（[[#ex-photolysis]]）——可见的蓝绿光，这就是为什么氯和溴在阳光下或灯下能与烷烃反应，而在黑暗中一动不动。加热也行，只要 $T$ 高到让一部分分子在振动中携带住 BDE 的能量（对 $\mathrm{Cl_2}$ 约在 $250\ \mathrm{^\circ C}$ 以上）。化学家的第三个花招是把一根弱键藏进外表稳定的分子里：**过氧化物**带着一根只有约 $150$–$170\ \mathrm{kJ\,mol^{-1}}$ 的 $\mathrm{O{-}O}$ 键，温和加热即可把它们劈成两个氧自由基；**AIBN**（偶氮二异丁腈）受热碎裂并放出氮气，$\mathrm{N_2}$，这个离去之有利使它在 $60\ \mathrm{^\circ C}$ 就足以驱动反应。这些就是标准的*自由基引发剂*。

::: example 什么光能劈开氯气？ {#ex-photolysis}
$\mathrm{Cl{-}Cl}$ 的 BDE 为 $243\ \mathrm{kJ\,mol^{-1}}$，$\mathrm{Br{-}Br}$ 为 $193\ \mathrm{kJ\,mol^{-1}}$。求能够均裂两者各自的最长波长（$hcN_\mathrm{A} = 119\,627\ \mathrm{kJ\,nm\,mol^{-1}}$），并说明这对两种卤素的光化学意味着什么。
::: solution
一爱因斯坦（一摩尔光子）携带 $hcN_\mathrm{A}/\lambda$ 的能量，故均裂要求 $\lambda \le hcN_\mathrm{A}/B$：
$$
\lambda(\mathrm{Cl_2}) = \frac{119\,627}{243} = 492\ \mathrm{nm} \quad \text{（蓝绿光）},
\qquad
\lambda(\mathrm{Br_2}) = \frac{119\,627}{193} = 620\ \mathrm{nm} \quad \text{（橙红光）}.
$$
两个阈值都落在*可见光*区——卤素的颜色*就是*它们的光化学：卤素吸收的光，恰恰就是能把它们杀死的光。$\mathrm{C{-}C}$ $\sigma$ 键（$350\ \mathrm{kJ\,mol^{-1}}$）需要 $342\ \mathrm{nm}$ 的紫外光，这就是为什么烷烃对阳光透明，为什么阳光不会把原油裂解、却会把它氯化。
:::
:::

碳自由基长什么样？甲基自由基 $\mathrm{CH_3^{\bullet}}$ 是*平面*的（或一个极浅、快速翻转的棱锥）：碳近似 $sp^{2}$ 杂化，三个 $\mathrm{C{-}H}$ 键共面，单电子坐在垂直于该平面的未杂化 $p$ 轨道里。两个推论随之而来。第一，自由基在任何有意义的意义上都**不是**立体中心：平面（或快速翻转）的中间体两面都可能被进攻，所以发生在立体碳上的自由基反应会外消旋化——与 [[organic-1/nucleophilic-substitution]] 中 $\mathrm{S_N1}$ 机理的外消旋化是同一个论证。第二，$p$ 轨道是半满而非全空：自由基缺电子（七个电子，不是八个），但它不是阳离子，也不像碳正离子那样搜寻孤对电子。记住这个不对称——它就是下面那则警告的种子。

## 自由基稳定性：键能证据

::: proposition 自由基稳定性顺序 {#prop-stability}
碳自由基被烷基取代基和共振所稳定，稳定性顺序为
$$
\text{苄基} \approx \text{烯丙基} > 3^\circ > 2^\circ > 1^\circ > \text{甲基} > \text{乙烯基/芳基}.
$$
证据是 $\mathrm{C{-}H}$ 键的解离焓（$\mathrm{kJ\,mol^{-1}}$，常用数据表的气相数据）：甲烷 $440$；伯 $423$（乙烷）；仲 $413$；叔 $400$；烯丙位 $369$（丙烯）。阶梯每下一级，意味着留下的自由基更稳定，因为解离一根更弱的 $\mathrm{C{-}H}$ 键花的能量更少。烷基通过**超共轭**起稳定作用——相邻 $\mathrm{C{-}H}$ $\sigma$ 电子向半满 $p$ 轨道的给予——而烯丙基和苄基自由基被**离域**稳定：单电子占据一个铺展在三个（或更多）碳上的 $\pi$ 分子轨道，所以烯丙基自由基 $\mathrm{CH_2{=}CH{-}CH_2^{\bullet}}$ 是一个单一的共振杂化体，而不是两个结构式。
:::

把这些数字读成能量阶梯：$440 \rightarrow 423 \rightarrow 413 \rightarrow 400$，从甲烷到叔只降了 $17\ \mathrm{kJ\,mol^{-1}}$，而烯丙位键还要再弱 $54\ \mathrm{kJ\,mol^{-1}}$。这 $54\ \mathrm{kJ\,mol^{-1}}$ 的烯丙稳定化正是烯丙位溴代（下一节）存在的全部理由，而且它把烷基自由基之间 $23\ \mathrm{kJ\,mol^{-1}}$ 的差距比了下去——共振优于超共轭的*效应*排序，你在 [[organic-1/alkenes-alkynes]] 的碳正离子和 [[organic-1/acidity-mechanism]] 的酸性论证里已经见过。

::: warning 自由基不是改头换面的碳正离子 {#warn-radical-misconceptions}
三个误解，每个都要扣分，有时还要赔玻璃器皿。**（1）***"稳定性顺序 $3^\circ > 2^\circ > 1^\circ$ 说明自由基像阳离子一样缺电子，所以同样的推理可以照搬。"* 顺序相同，*理由*不同：碳正离子有一个**空**轨道、八隅体不完整，迫切需要一个完整电子对，这就是它抓取亲核试剂、靠迁移一对电子重排的原因；自由基有一个**单占据**轨道，靠*离域一个电子*（超共轭、共振）获得稳定，对亲核试剂和极性溶剂效应基本无感。把阳离子的直觉带进自由基化学，你会预测出永远不会发生的进攻和重排。**（2）** *"只要有过氧化物，任何卤化氢都能反马氏加成。"* 它对 HBr 有效，*而且只有*作为链反应时有效：[[#sec-peroxide]] 一节的焓账表明 $\mathrm{HCl}$ 和 $\mathrm{HI}$ 各有一个链传递步骤过不去。**（3）** *"鱼钩箭头不过是自由基反应里的弯箭头。"* 鱼钩移动*一个*电子；弯箭头移动*一对*。均裂断键是两个鱼钩，各给一个原子——在那里画一个全头箭头，你画的就是异裂，是另一个反应。
:::

## 书写链机理：甲烷的氯化

::: algorithm 链机理算法 {#alg-chain}
自由基链恰好包含三类步骤，三类都写出来，机理才算完成。**（1）链引发：** 一个非自由基前体（经光、热或引发剂）分裂*产生*自由基——这是唯一使自由基数目从零上升的步骤。**（2）链传递（链增长）：** 自由基与一个闭壳层分子反应，生成一个新的闭壳层分子和一个*新的*自由基；新自由基重复这个过程。把链传递写成一个循环，其中自由基在上一步被消耗、在下一步被再生，并**检查各链传递步骤之和等于总反应**——这个和就是你的链传递写对了的检验。**（3）链终止：** 两个自由基相遇结合（或歧化）为闭壳层产物；链就此死去。链终止步骤从不出现在链传递步骤的加和中；引发与终止的存在解释了为什么链需要持续的光或热：撤掉引发，终止就会把反应磨到停止。
:::

把算法用于甲烷氯化 $\mathrm{CH_4 + Cl_2 \rightarrow CH_3Cl + HCl}$。**链引发：** 光照下（$\lambda \le 492\ \mathrm{nm}$）$\mathrm{Cl_2 \rightarrow 2\,Cl^{\bullet}}$。**链传递：**

$$
\mathrm{Cl^{\bullet} + CH_4 \rightarrow HCl + CH_3^{\bullet}}
\qquad\text{然后}\qquad
\mathrm{CH_3^{\bullet} + Cl_2 \rightarrow CH_3Cl + Cl^{\bullet}}
$$

——第一步消耗的氯原子在第二步再生，于是一个 $\mathrm{Cl^{\bullet}}$ 可以跑上千个循环；两步之和正是总反应，完全符合算法的要求。**链终止：** 体系中任何一对自由基都可能结合——$\mathrm{Cl^{\bullet} + Cl^{\bullet} \rightarrow Cl_2}$、$\mathrm{CH_3^{\bullet} + Cl^{\bullet} \rightarrow CH_3Cl}$，以及 $\mathrm{2\,CH_3^{\bullet} \rightarrow C_2H_6}$。最后一条意味深长：每一次甲烷氯化都会出现痕量乙烷产物，而对它的检出正是甲基自由基确实在烧瓶里游动的证据之一。终止*按分子计是罕见的*——自由基的稳态浓度极低，所以自由基遇到的几乎总是闭壳层分子而不是另一个自由基——但它是唯一的出口，而这台稳态机器正是 [[kinetics/reaction-mechanisms]] 与 [[kinetics/chain-reactions]] 的内容。

::: example 甲烷氯化链的焓账 {#ex-methane-chain}
用 [[#prop-stability]] 中的 BDE 以及表值 $\mathrm{Cl{-}Cl}\ 243$、$\mathrm{H{-}Cl}\ 431$、$\mathrm{C{-}Cl}\ 339\ \mathrm{kJ\,mol^{-1}}$（甲烷 $\mathrm{C{-}H}\ 440$），计算每个链传递步骤和总反应的 $\Delta H$，并评论哪一步是难的一步。
::: solution
每个链传递步骤断一根键、成一根键，故 $\Delta H = \mathrm{BDE(broken)} - \mathrm{BDE(formed)}$：
$$
\Delta H_1 = 440 - 431 = +9\ \mathrm{kJ\,mol^{-1}},
\qquad
\Delta H_2 = 243 - 339 = -96\ \mathrm{kJ\,mol^{-1}},
$$
$$
\Delta H_{\text{overall}} = 440 + 243 - (339 + 431) = -87\ \mathrm{kJ\,mol^{-1}} = (+9) + (-96). \checkmark
$$
链传递第一步——抽取氢——是*吸热的*，是这对步骤里难的一步；链传递第二步——自由基进攻 $\mathrm{Cl_2}$——是一份下坡的礼物。链的总焓强放热，但它的命运由上坡的那一步决定：选择性的一切（下文）都住在那里。
:::
:::

## 选择性：统计乘以化学

含多种氢的烷烃的一氯化给出混合物，而这个混合物是定量的化学：每种产物的量等于该类氢的*数目*乘以抽取其中一个的*内在难易*。每氢相对速率（约室温下测得）为

$$
\text{氯化： } 1 : 3.8 : 5
\qquad\text{与}\qquad
\text{溴化： } 1 : 82 : 1600
\qquad (1^\circ : 2^\circ : 3^\circ).
$$

氯几乎不加辨别——叔氢被抽走的概率只有伯氢的五倍，并不比"多五个"的统计优势高多少。溴的辨别力则近乎荒谬地强。

::: example 2-甲基丁烷的一氯化 {#ex-2mb-chlorination}
2-甲基丁烷 $\mathrm{(CH_3)_2CHCH_2CH_3}$ 有四种氢。用每氢速率 $1 : 3.8 : 5$ 预测其一氯化的产物分布。
::: solution
标出各位置：C2 上两个等价的甲基带 $6\ \mathrm{H}$（伯，给 1-氯-2-甲基丁烷）；C3 带 $2\ \mathrm{H}$（仲，给 2-氯-3-甲基丁烷）；C2 带 $1\ \mathrm{H}$（叔，给 2-氯-2-甲基丁烷）；末端甲基 C4 带 $3\ \mathrm{H}$（伯，给 1-氯-3-甲基丁烷）。数目乘以速率：
$$
6 \times 1 = 6.0;\quad 2 \times 3.8 = 7.6;\quad 1 \times 5 = 5.0;\quad 3 \times 1 = 3.0;
\qquad \text{总计} = 21.6,
$$
所以混合物依次为 $27.8\,\%$、$35.2\,\%$、$23.1\,\%$ 和 $13.9\,\%$。仲氢产物尽管氢的数目只有前者的三分之一，仍以微弱优势领先——但注意没有任何单一主产物：未活化烷烃的氯化是一锅粥，这是合成的局限，不是意外。
:::
:::

::: example 2-甲基丙烷的一溴化 {#ex-2mp-bromination}
2-甲基丙烷 $\mathrm{(CH_3)_3CH}$ 有 $9$ 个伯氢和 $1$ 个叔氢。按每氢速率 $1 : 1600$，一溴化产物中 2-溴-2-甲基丙烷占多大分数？
::: solution
叔的反应性 $= 1 \times 1600 = 1600$；伯的反应性 $= 9 \times 1 = 9$；叔溴化物的分数为
$$
\frac{1600}{1600 + 9} = 0.994 = 99.4\,\%.
$$
十个氢里的一个，却是 $99.4\,\%$ 的产物：溴化是一个*合成*反应，氯化只是一个*统计*反应。同一底物若用氯（$1 : 5$）只能得到 $5/(5+9) = 36\,\%$ 的叔产物——这道算术见 [[#exr-chloro-2mp]]。
:::
:::

::: widget plot

选择性是活化能之差，而活化能之差是玻尔兹曼因子——所以它必然依赖温度。若叔、伯两条路径相差 $\Delta E_\mathrm{a} = 18.3\ \mathrm{kJ\,mol^{-1}}$（即在 $298\ \mathrm{K}$ 给出 $1600 : 1$ 的那个值，见 [[#exr-delta-ea]]），则其比值为 $e^{\Delta E_\mathrm{a}/RT}$，且*随 $T$ 升高而趋向 1*：同一个溴化反应在 $298\ \mathrm{K}$ 给 $99.4\,\%$ 叔产物，在 $500\ \mathrm{K}$ 约给 $90\,\%$，在 $800\ \mathrm{K}$ 给 $64\,\%$。热的溴是马虎的溴；选择性是低温的奢侈品。

## 溴为什么挑剔：哈蒙德假说在此发力

::: proposition 卤代选择性的哈蒙德解释 {#prop-hammond-selectivity}
对抽取氢的链传递步骤 $\mathrm{X^{\bullet} + R{-}H \rightarrow H{-}X + R^{\bullet}}$，步骤焓为 $\Delta H_1 = \mathrm{BDE}(R{-}H) - \mathrm{BDE}(H{-}X)$，用表列 $\mathrm{H{-}X}$ 键（$\mathrm{H{-}F}\ 568$、$\mathrm{H{-}Cl}\ 431$、$\mathrm{H{-}Br}\ 366$、$\mathrm{H{-}I}\ 298\ \mathrm{kJ\,mol^{-1}}$）从甲烷抽取氢的代价是
$$
\Delta H_1/\mathrm{kJ\,mol^{-1}}: \quad \mathrm{F}\ -128, \quad \mathrm{Cl}\ +9, \quad \mathrm{Br}\ +74, \quad \mathrm{I}\ +142.
$$
按**哈蒙德假说**（[[organic-1/acidity-mechanism]]），氯化那步放热（或几乎不吸热）的抽取有一个**早期、类反应物的过渡态**，碳上尚未发展出多少自由基特征——所以 $3^\circ$ 与 $1^\circ$ 自由基之间 $17\ \mathrm{kJ\,mol^{-1}}$ 的稳定性差别几乎传不到能垒上，氯因此不挑剔。溴的抽取强**吸热**，其过渡态**晚期、类自由基**：新生自由基几乎完全成形，其稳定性差别几乎全额兑现，于是溴高度挑剔。*步骤越吸热，过渡态越晚，过渡态就越完整地继承它所生成之自由基的稳定性顺序。*
:::

这个命题做出一个定量预测。若溴化的晚过渡态是一个*完美的*自由基，伯（$423$）与叔（$400$）$\mathrm{C{-}H}$ 键 $23\ \mathrm{kJ\,mol^{-1}}$ 的差别会全额出现在能垒差里，$298\ \mathrm{K}$ 下的选择性应为 $e^{23/RT} \approx 10\,800$；实测的 $1600$ 对应 $\Delta\Delta E_\mathrm{a} = RT\ln 1600 = 18.3\ \mathrm{kJ\,mol^{-1}}$，约为焓差的 $80\,\%$——一个晚过渡态，只差一点点就完美。氯的早过渡态以相反的结果兑现同一条关系：可能的 $23\ \mathrm{kJ\,mol^{-1}}$ 里只付了 $\Delta\Delta E_\mathrm{a} = RT\ln 5 = 4.0\ \mathrm{kJ\,mol^{-1}}$。能垒与反应焓之间的这种线性关系（此处即其一个实例）就是 Bell–Evans–Polanyi 原理：一族反应，一条直线。

同样这四个数字解释了*哪些卤素根本可用*。氟化的两个链传递步骤都强放热（$\Delta H_1 = -128$，且 $\Delta H_2 = 159 - 452 = -293\ \mathrm{kJ\,mol^{-1}}$）：$\mathrm{F^{\bullet}}$ 与任何东西的每次碰撞都发生抽取，链失控，反应爆炸——$\mathrm{F_2}$ 不是选择性试剂，而是爆破作业。碘化的 $\Delta H_1 = +142\ \mathrm{kJ\,mol^{-1}}$：抽取步骤太吸热，链根本启动不了（总反应也吸热，$+59\ \mathrm{kJ\,mol^{-1}}$），$\mathrm{I_2}$ 就是不传递。氯和溴——抽取步骤负担得起（对甲烷各为 $+9$ 和 $+74\ \mathrm{kJ\,mol^{-1}}$）、第二步强放热——正是自由基链卤代能成为一门化学（而不是爆炸或无事发生）的两种卤素。

::: quiz
烷烃的溴化远比氯化更有选择性。本章认可哪一种解释？
- [ ] $\mathrm{Br^{\bullet}}$ 是比 $\mathrm{Cl^{\bullet}}$ 更强的碱，所以它挑选酸性最强的氢。
- [x] $\mathrm{Br^{\bullet}}$ 的抽取是吸热的，故按哈蒙德假说其过渡态晚期、类自由基，自由基稳定性全额体现在能垒上；氯的放热抽取有一个早过渡态，几乎感觉不到它。
- [ ] 溴原子更大，所以它只抽取最容易接近的氢——选择性是空间效应。

::: solution
第 2 项就是 [[#prop-hammond-selectivity]] 的哈蒙德论证：吸热步骤的晚过渡态继承自由基的稳定性顺序。C–H 的酸性（第 1 项）是离子概念，在烷基 C–H 之间几乎不动；空间效应（第 3 项）有一点作用，但产生不了 $1600 : 1$ 的比；而低温确实会*锐化*既有的选择性（见上文之图），但溴在室温就挑剔、氯却不挑剔——差别在 $\Delta E_\mathrm{a}$，不在温度计上。
:::

## 两个局限与一个补救：多卤代与烯丙位溴代

自由基氯化有一个内置的升级问题：产物仍然有 $\mathrm{C{-}H}$ 键，而 $\mathrm{Cl_2}$ 还在，于是 $\mathrm{CH_3Cl}$ 被再次氯化成 $\mathrm{CH_2Cl_2}$，再 $\mathrm{CHCl_3}$，再 $\mathrm{CCl_4}$。多卤代只能靠向反应器大量通入过量甲烷来抑制，使氯原子在统计上更可能再遇到 $\mathrm{CH_4}$——这是工业花招，不是合成办法。加上氯的选择性差，这就是为什么自由基卤代主要在氢的数目少且等价时、或能利用溴的选择性时、或下面这个特殊情形里才挣得饭碗。

那个情形就是**烯丙位溴代**。[[#prop-stability]] 把烯丙位 $\mathrm{C{-}H}$ 定价为 $369\ \mathrm{kJ\,mol^{-1}}$，于是 $\mathrm{Br^{\bullet}}$ 的抽取只花 $369 - 366 = +3\ \mathrm{kJ\,mol^{-1}}$——基本热中性，因此温和条件下也快。高温下，或在低 $\mathrm{Br_2}$ 浓度条件下，*烯烃*因此在烯丙位发生取代，而不是 [[organic-1/alkenes-alkynes]] 的加成：烯丙自由基被共振稳定，它接着从 $\mathrm{Br_2}$ 抽取 $\mathrm{Br}$、再生 $\mathrm{Br^{\bullet}}$，并把双键（若共振杂化体要求移位就移位）留在产物里。实验室试剂 **NBS**（N-溴代丁二酰亚胺）的存在就是为了把 $\mathrm{Br_2}$ 浓度压得*低而恒定*——由储库缓慢释放——使这点可怜的 $\mathrm{Br_2}$ 永远攒不够驱动离子加成的量。低 $\mathrm{Br_2}$：取代赢；黑暗中高 $\mathrm{Br_2}$：[[organic-1/alkenes-alkynes]] 的溴鎓离子赢。同一烯烃，同种元素，相反反应——由机理决定，本课程一贯如此。

## 过氧化物效应：HBr 的反马氏加成 {#sec-peroxide}

::: history
碳自由基的存在是被定案下来的，不是被假设出来的。1929 年，帕内特（Paneth）用他的"镜面管"——一种挥发性有机铅化合物在密封镀镜毛细管的一端分解，自由基行进并被销毁之处镜面重新镀上——证明甲基自由基在气相中拥有真实、可测的寿命。1933 年，哈拉施（Kharasch）与哈德森（Hudson）报告：有过氧化物存在时 HBr 以*反*马氏方式加到烯烃上，并用示踪与抑制实验证明责任在一条自由基链："过氧化物效应"由此成为教科书机理。直接看见自由基要等闪光光解——诺里什（Norrish）与波特（Porter）用纳秒级光脉冲产生自由基并以吸收光谱观察——他们因此与艾根（Eigen）共享 1967 年诺贝尔化学奖，后者用弛豫方法（[[kinetics/rate-laws]] 已见）从溶液一侧进攻同一片前沿。
:::

黑暗中，$\mathrm{HBr}$ 按 [[organic-1/alkenes-alkynes]] 的离子机理加到丙烯上：$\mathrm{H^{+}}$ 先加，更稳定的阳离子生成，溴离子随后跟上——马氏。有过氧化物（或光照）时，一条链接管，区域化学翻转。**链引发：** $\mathrm{ROOR \rightarrow 2\,RO^{\bullet}}$，接着 $\mathrm{RO^{\bullet} + HBr \rightarrow ROH + Br^{\bullet}}$。**链传递：**

$$
\mathrm{Br^{\bullet} + CH_3CH{=}CH_2 \rightarrow BrCH_2CH^{\bullet}CH_3}
\qquad\text{然后}\qquad
\mathrm{BrCH_2CH^{\bullet}CH_3 + HBr \rightarrow BrCH_2CH_2CH_3 + Br^{\bullet}}
$$

仔细读第一个链传递步骤，因为它是"为什么反马氏"的全部答案：$\mathrm{Br^{\bullet}}$ 加到*末端*碳上，使新自由基坐在*中间*碳上——一个仲自由基而不是伯自由基。溴原子去*自由基不去*的地方，因为决定取向的正是自由基的稳定性，与阳离子机理一模一样；但由于自由基是*溴先加成*造出来的，产物里溴就落在取代较少的碳上。于是这条链把区域化学一个氢一个氢地交还给马氏的世界：$\mathrm{H}$ 与 $\mathrm{Br}$ 的净加成，其中 $\mathrm{Br}$ 反马氏。

::: example 为什么只有 HBr：三种酸的焓检验 {#ex-hbr-hcl-hi}
对 $\mathrm{HX}$ 跨 $\mathrm{C{=}C}$ 双键的自由基加成，链传递第一步成一根 $\mathrm{C{-}X}$ 键、断一根 $\pi$ 键（$266\ \mathrm{kJ\,mol^{-1}}$）；第二步成一根仲 $\mathrm{C{-}H}$ 键（$413$）、断一根 $\mathrm{H{-}X}$ 键。用 $\mathrm{H{-}Cl}\ 431$、$\mathrm{H{-}Br}\ 366$、$\mathrm{H{-}I}\ 298$；$\mathrm{C{-}Cl}\ 339$、$\mathrm{C{-}Br}\ 285$、$\mathrm{C{-}I}\ 234\ \mathrm{kJ\,mol^{-1}}$：对每种酸计算两个链传递焓，判断谁能维持一条链。
::: solution
$$
\begin{array}{c|ccc}
 & \Delta H_1 = 266 - \mathrm{BDE(C{-}X)} & \Delta H_2 = \mathrm{BDE(H{-}X)} - 413 & \text{成链？}\\
\mathrm{HCl} & 266 - 339 = -73 & 431 - 413 = +18 & \text{否：第二步吸热}\\
\mathrm{HBr} & 266 - 285 = -19 & 366 - 413 = -47 & \text{是：两步均放热}\\
\mathrm{HI} & 266 - 234 = +32 & 298 - 413 = -115 & \text{否：第一步吸热}
\end{array}
$$
对 $\mathrm{HCl}$，$\mathrm{H{-}Cl}$ 键太强：碳自由基无法把 $\mathrm{H}$ 从 $\mathrm{HCl}$ 上抢下来（$+18\ \mathrm{kJ\,mol^{-1}}$），链死在第二步。对 $\mathrm{HI}$，$\mathrm{C{-}I}$ 键太弱：$\mathrm{I^{\bullet}}$ 不肯加到 $\pi$ 键上（$+32\ \mathrm{kJ\,mol^{-1}}$），链死在第一步。只有 $\mathrm{HBr}$ 两步都下坡——这就是"过氧化物翻转区域化学"只适用于一种试剂、而不适用于一类试剂的原因。（三个总加成都是放热的；总放热*不是*判据——**两个链传递步骤**都必须可行，因为链是按步付账的。）
:::
:::

## 更广阔世界中的自由基

**自由基聚合**是同一套链传递逻辑改行办的材料厂。引发剂自由基（来自过氧化物或 AIBN）加到乙烯上生成碳自由基，后者再加乙烯、再加一个——每次加成消耗一根双键、在链端再生一个自由基——直到两条链端相遇、以结合或歧化终止：
$$
\mathrm{In^{\bullet} + n\,CH_2{=}CH_2 \rightarrow In{-}(CH_2CH_2)_n{-}CH_2CH_2^{\bullet}}
$$
产物是聚乙烯，而链式聚合之"链"就是本章的自由基链；其动力学、分子量统计和现代控制变体（把自由基群体维持在稳态控制之下）见 [[polymer-chemistry/radical-polymerisation]] 与 [[polymer-chemistry/controlled-polymerisation]]。

**自动氧化**是自由基化学不请自来的链。氧分子在常见分子中很特别，因为它是*三重态*——一个双自由基，两个未成对电子分坐两个 $\pi^{\ast}$ 轨道——所以它以扩散控制速率加到碳自由基上，生成过氧自由基 $\mathrm{ROO^{\bullet}}$，后者再从更多底物抽取氢，传播一条插入氧的链。醚在氧旁碳上尤其脆弱，放置中一瓶未开封的醚会慢慢把自己的一部分变成有机过氧化物——这类化合物被划为爆炸物和氧化性危害（GHS 火焰与圆圈火焰象形图），若把醚蒸干就会浓缩在最后几滴里。这就是实验室醚要标注日期、用前检测过氧化物、并绝不蒸干的原因：这个危害是一条你正准备浓缩的自由基链。

**抗氧化剂**是断链者，其机理是焓。酚类——零食里的丁基羟基甲苯（BHT）、细胞膜里的 $\alpha$-生育酚（维生素 E）——带着一根被削弱的 $\mathrm{O{-}H}$ 键（约 $360\ \mathrm{kJ\,mol^{-1}}$），因为留下的苯氧自由基把单电子离域进了芳环。过氧自由基于是抽取那个酚氢而不是脂质氢，而生成的苯氧自由基既稳定又笨拙，懒得继续任何一条链：它只是等着，与另一个自由基配了对。伤害之被中和，不是靠消灭自由基，而是靠*把它提升到一个不那么有攻击性的职位*——与本章通篇的热力学逻辑相同，只是站在防守一方。在活细胞里，超氧自由基阴离子 $\mathrm{O_2^{\bullet-}}$——由免疫酶在氧化爆发中刻意产生、也被呼吸作用不可避免地泄漏——由超氧化物歧化酶管理，理由与任何自由基必须被管理的理由相同：一个未成对电子是一支等着底物上膛的枪。燃烧补全这幅图景——火焰是一条由 $\mathrm{H^{\bullet}}$、$\mathrm{O^{\bullet}}$ 和 $\mathrm{HO^{\bullet}}$ 组成的支链自由基链，其分支恰恰是火自我加速的原因，而它的化学抑制靠提供能封顶分支步骤的自由基起效。

## 后续内容

本章的烯丙基与苄基自由基是 [[organic-2/aromatic-substitution]] 侧链化学的入口，烯丙自由基的共振稳定则是 [[organic-2/conjugation]] 将全面展开的共轭主题的一个实例。这里使用的稳态与链动力学机器在 [[kinetics/chain-reactions]] 与 [[kinetics/reaction-mechanisms]] 中形式化，光化学引发在 [[kinetics/photochemistry]]。链增长思想放大到材料，就是 [[polymer-chemistry/radical-polymerisation]]。而本章一路画下的对照——离子对自由基、电子对对单电子、弯箭头对鱼钩箭头——是本课程最后一个机理家族；把它与 [[organic-1/alkenes-alkynes]] 的加成、[[organic-1/nucleophilic-substitution]] 的取代对读一遍，有机化学（一）的地图就完整了。

::: summary
- 自由基携带未成对电子；均裂（一边一个电子，鱼钩箭头）产生自由基，代价是 BDE——$\mathrm{Cl_2}$ 的 $243\ \mathrm{kJ\,mol^{-1}}$ 意味着可见光（$\le 492\ \mathrm{nm}$）就能引发氯化。
- 自由基稳定性 $3^\circ > 2^\circ > 1^\circ$，烯丙基与苄基远在其上，证据是 $\mathrm{C{-}H}$ BDE（甲烷 $440$，伯/仲/叔 $423/413/400$，烯丙位 $369$）；自由基靠离域一个电子稳定，而不是靠凑满八隅体。
- 链机理 = 链引发 + 链传递（自由基被消耗又被再生；各链传递步骤之和必须等于总反应）+ 链终止；甲烷氯化的两个链传递步骤是 $+9$ 和 $-96\ \mathrm{kJ\,mol^{-1}}$。
- 产物分布是统计乘以内在难易：氯化（每氢 $1 : 3.8 : 5$）给混合物，溴化（$1 : 82 : 1600$）从 2-甲基丙烷给 $99.4\,\%$ 叔产物；选择性因它是玻尔兹曼因子而随温度侵蚀。
- 哈蒙德假说解释整个选择性图景：吸热的抽取（Br）有一个晚期、类自由基的过渡态，继承自由基稳定性；放热的抽取（Cl）的过渡态很早，继承不到——于是 $\mathrm{F_2}$ 爆炸而 $\mathrm{I_2}$ 根本启动不了。
- 自由基氯化受多卤代之限；NBS 的烯丙位溴代利用 $369\ \mathrm{kJ\,mol^{-1}}$ 的烯丙位键与低而恒定的 $\mathrm{Br_2}$ 浓度，在离子本领会加成的地方做取代。
- 过氧化物效应翻转 HBr 的区域化学，因为 $\mathrm{Br^{\bullet}}$ 先加成以生成更稳定的自由基；$\mathrm{HCl}$ 栽在第二步（$+18\ \mathrm{kJ\,mol^{-1}}$），$\mathrm{HI}$ 栽在第一步（$+32\ \mathrm{kJ\,mol^{-1}}$）。
- 自由基链同时运转着世界的光明与阴暗面：聚合造出聚乙烯；自动氧化败坏乙醚（过氧化物危害）；酚类抗氧化剂以一根弱 $\mathrm{O{-}H}$ 和一个离域的、慵懒的苯氧自由基止链。
:::

::: exercise 抽取仲氢 {level=1 check="-18"}
用 $\mathrm{C{-}H}\ 413$、$\mathrm{H{-}Cl}\ 431\ \mathrm{kJ\,mol^{-1}}$ 计算链传递步骤 $\mathrm{Cl^{\bullet} + R_2CH{-}H \rightarrow HCl + R_2CH^{\bullet}}$ 的 $\Delta H$。（以 $\mathrm{kJ\,mol^{-1}}$ 输入 $\Delta H$。）
::: solution
$\Delta H = 413 - 431 = -18\ \mathrm{kJ\,mol^{-1}}$。放热，故过渡态很早——这正是氯不在乎氢是伯、仲还是叔的原因。
:::

::: exercise 溴的光解 {level=1 check="620"}
已知 $\mathrm{Br{-}Br}$ 为 $193\ \mathrm{kJ\,mol^{-1}}$，求能均裂溴的最长波长（$hcN_\mathrm{A} = 119\,627\ \mathrm{kJ\,nm\,mol^{-1}}$）。（以 nm 输入 $\lambda$。）
::: solution
$\lambda = 119\,627/193 = 620\ \mathrm{nm}$——橙红光。溴的红棕色就是它被吸收的光，而被吸收的光就是被解离的光：灯下溴色的褪去，就是你能看见的链引发步骤。
:::
:::

::: exercise 容易的那个链传递步骤 {level=1 check="-92"}
用 $\mathrm{Br{-}Br}\ 193$、$\mathrm{C{-}Br}\ 285\ \mathrm{kJ\,mol^{-1}}$ 计算 $\mathrm{R^{\bullet} + Br_2 \rightarrow R{-}Br + Br^{\bullet}}$ 的 $\Delta H$。（以 $\mathrm{kJ\,mol^{-1}}$ 输入 $\Delta H$。）
::: solution
$\Delta H = 193 - 285 = -92\ \mathrm{kJ\,mol^{-1}}$。溴化的第二步与氯化的（$-96$）一样放热；两种卤素行为的全部差异都住在第一步里。
:::

::: exercise 2-甲基丙烷的氯化 {level=2 check="35.7" #exr-chloro-2mp}
2-甲基丙烷有 $9$ 个伯氢和 $1$ 个叔氢。按每氢氯化速率 $1 : 5$，一氯化产物中 2-氯-2-甲基丙烷占百分之多少？（输入百分数。）
::: solution
叔：$1 \times 5 = 5$；伯：$9 \times 1 = 9$；分数 $= 5/(5+9) = 35.7\,\%$。对比同一底物溴化的 $99.4\,\%$：统计完全相同，变的只是内在选择性。
:::
:::

::: exercise 甲烷溴化的完整链 {level=2}
写出光化学溴化甲烷 $\mathrm{CH_4 + Br_2 \rightarrow CH_3Br + HBr}$ 的完整链机理，并给出每个链传递步骤的 $\Delta H$（$\mathrm{C{-}H}\ 440$；$\mathrm{Br{-}Br}\ 193$；$\mathrm{C{-}Br}\ 285$；$\mathrm{H{-}Br}\ 366\ \mathrm{kJ\,mol^{-1}}$），解释为什么这条链需要持续的光源，以及为什么它干净地停在 $\mathrm{CH_3Br}$ 而不升级为多溴代。
::: solution
链引发：$\mathrm{Br_2 \rightarrow 2\,Br^{\bullet}}$（$\lambda \le 620\ \mathrm{nm}$）。链传递：$\mathrm{Br^{\bullet} + CH_4 \rightarrow HBr + CH_3^{\bullet}}$，$\Delta H = 440 - 366 = +74\ \mathrm{kJ\,mol^{-1}}$；然后 $\mathrm{CH_3^{\bullet} + Br_2 \rightarrow CH_3Br + Br^{\bullet}}$，$\Delta H = 193 - 285 = -92\ \mathrm{kJ\,mol^{-1}}$；总和 $-18\ \mathrm{kJ\,mol^{-1}}$。链终止：$\mathrm{2\,Br^{\bullet} \rightarrow Br_2}$、$\mathrm{CH_3^{\bullet} + Br^{\bullet} \rightarrow CH_3Br}$、$\mathrm{2\,CH_3^{\bullet} \rightarrow C_2H_6}$。$+74\ \mathrm{kJ\,mol^{-1}}$ 的抽取步骤使链很慢——它的难步要爬 $74\ \mathrm{kJ\,mol^{-1}}$ 的坡——且总反应放热寥寥（$-18\ \mathrm{kJ\,mol^{-1}}$），所以灯一灭链就停（终止快过传递）：持续的光源是硬性要求。干净的一溴代：从 $\mathrm{CH_3Br}$ 上再抽第二个氢意味着进攻一根被电负性溴强化的 $\mathrm{C{-}H}$ 键，而溴化晚期、类自由基的过渡态让这笔代价几乎全额兑现——反应停在单取代，靠的是选择性，不是统计。
:::
:::

::: exercise 2,3-二甲基丁烷的氯化 {level=2 check="45.5"}
2,3-二甲基丁烷 $\mathrm{(CH_3)_2CHCH(CH_3)_2}$ 有 $12$ 个等价的伯氢和 $2$ 个等价的叔氢。按每氢速率 $1 : 5$，一氯化有多少百分比发生在叔碳上？（输入百分数。）
::: solution
叔的反应性 $= 2 \times 5 = 10$；伯的 $= 12 \times 1 = 12$；叔产物 $= 10/(10+12) = 45.5\,\%$。$6 : 1$ 的氢数失衡换来一个几乎对半的混合物：这就是"几乎不挑剔"的样子，也是没人会问氯"主产物是哪个？"的原因——没有主产物。
:::

::: exercise 从选择性到能垒差 {level=3 #exr-delta-ea}
$298\ \mathrm{K}$ 下溴化的每氢叔/伯选择性为 $1600 : 1$。把它换算成活化能之差（$R = 8.314\ \mathrm{J\,K^{-1}\,mol^{-1}}$），与 $\mathrm{C{-}H}$ 键解离焓之差 $423 - 400 = 23\ \mathrm{kJ\,mol^{-1}}$ 比较，并用哈蒙德与 Bell–Evans–Polanyi 的语言解释这个比值。
::: solution
$\Delta\Delta E_\mathrm{a} = RT\ln 1600 = 8.314 \times 298 \times 7.378\ \mathrm{J\,mol^{-1}} = 18.3\ \mathrm{kJ\,mol^{-1}}$。比值 $18.3/23 = 0.80$ 说明过渡态表达了约 $80\,\%$ 的自由基稳定性差别：一个*晚期*过渡态，正如哈蒙德对一步吸热 $47$–$74\ \mathrm{kJ\,mol^{-1}}$ 的步骤所要求的，但并非完全如此——这一族反应的 Bell–Evans–Polanyi 斜率 $\alpha \approx 0.8$。对氯做同样的算术：$RT \ln 5 = 4.0\ \mathrm{kJ\,mol^{-1}}$，$\alpha \approx 0.17$——一个早期过渡态。两个选择性数字，一条直线：卤素们正坐在哈蒙德要求它们坐的位置上。
:::

::: exercise HI 为什么在 HBr 成功之处失败 {level=3}
对 $\mathrm{HI}$ 跨丙烯的自由基加成（一条本应给 1-碘丙烷的链），计算两个链传递焓（$\pi$：$266$；$\mathrm{C{-}I}\ 234$；$\mathrm{H{-}I}\ 298$；仲 $\mathrm{C{-}H}\ 413\ \mathrm{kJ\,mol^{-1}}$），并解释为什么尽管总加成放热，反应仍然失败。然后说明：把 $\mathrm{HCl}$ 链的第二步倒过来跑——链*原则上*能跑的唯一方式——也不是救赎。
::: solution
第一步：$\Delta H_1 = 266 - 234 = +32\ \mathrm{kJ\,mol^{-1}}$；第二步：$\Delta H_2 = 298 - 413 = -115\ \mathrm{kJ\,mol^{-1}}$；总计 $-83\ \mathrm{kJ\,mol^{-1}}$。总反应放热，链却死在第一步：$\mathrm{I^{\bullet}}$ 不肯加到 $\pi$ 键上，因为 $\mathrm{C{-}I}$ 键几乎偿还了 $\pi$ 键的全部成本、却恰恰差在那一点点上，而链不能像银行在没有资本时那样向后面的放热步骤透支——每个链传递步骤都必须自己可行。对 $\mathrm{HCl}$，第二步是 $431 - 413 = +18\ \mathrm{kJ\,mol^{-1}}$；把它倒过来跑（碳自由基去从*产物*上抢 $\mathrm{H}$）根本不是链传递——那是一个已经失败的步骤的微观逆过程，它只会消耗产物而不会制造产物。链是按步付账的：这一句话就回答了所有"为什么不是 $\mathrm{HCl}$ 或 $\mathrm{HI}$？"的问题。
:::
