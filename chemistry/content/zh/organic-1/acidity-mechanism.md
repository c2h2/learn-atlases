本课程中的每一个机理都是关于电子从富集之处流向匮乏之处的故事，而几乎每个故事都由两个问题决定：*质子往哪边走*，以及*谁进攻谁*。本章建立回答这两个问题的整套工具。第一是布朗斯特酸性，用 $K_\mathrm{a}$ 与 $\mathrm{p}K_\mathrm{a}$ 定量，并配一条算术规则——平衡规则——让你凭一张数据表就能预测任何质子转移的平衡位置。第二是解释这些数值为何恰好落在它们所在之处的四个结构因素，使这张表成为你据以推理而不是死记的东西。第三是亲核试剂与亲电试剂，有机化学的两个永恒角色。第四是弯箭头形式体系本身：一套拼写规则严格的语法，其中箭头移动电子对、电荷守恒、八隅体绝不被打破。最后是反应能量曲线，在这里我们把反应*想要*做什么（热力学，$\Delta G^\circ$）与它能多快做到（动力学，$\Delta G^{\ddagger}$）区分开来——这一区分是 $\mathrm{p}K_\mathrm{a}$ 表无法替你做的。从亲核取代往后的全部内容都用这门语言写成，所以这里没有一样是可选的。

## 布朗斯特酸、$K_\mathrm{a}$ 与 $\mathrm{p}K_\mathrm{a}$

::: definition 布朗斯特酸、碱与共轭对 {#def-broensted}
**布朗斯特酸**是质子（$\mathrm{H^+}$）给体；**布朗斯特碱**是质子受体。任何酸碱反应都把一个质子从酸转移给碱，方程两边各是一对**共轭酸碱对**，恰好相差一个 $\mathrm{H^+}$：
$$
\mathrm{CH_3COOH + HO^- \rightleftharpoons CH_3COO^- + H_2O}
$$
从左往右读，乙酸（酸）把质子给氢氧根（碱），产物是乙酸的**共轭碱**（乙酸根）和氢氧根的**共轭酸**（水）。既能给出质子又能接受质子的物种——水、碳酸氢根 $\mathrm{HCO_3^-}$、乙醇——称为**两性物质**。
:::

酸碱反应是平衡，而平衡就有位置。因此酸的强度不是含糊的倾向，而是它与水反应的可测平衡常数，$\mathrm{HA + H_2O \rightleftharpoons A^- + H_3O^+}$：

::: proposition 酸解离常数与 $\mathrm{p}K_\mathrm{a}$ {#prop-ka}
$$
K_\mathrm{a} = \frac{[\mathrm{A^-}][\mathrm{H_3O^+}]}{[\mathrm{HA}]},
\qquad
\mathrm{p}K_\mathrm{a} = -\log_{10} K_\mathrm{a}.
$$
因为 $\mathrm{p}K_\mathrm{a}$ 是*负*对数，酸**越强**，$\mathrm{p}K_\mathrm{a}$ **越小**——$\mathrm{p}K_\mathrm{a}$ 每一个单位对应 $K_\mathrm{a}$ 里的十个因子。经由 $\Delta_\mathrm{r}G^\circ = -RT\ln K_\mathrm{a}$，一个 $\mathrm{p}K_\mathrm{a}$ 单位在 $\mathrm{298\ K}$ 下也是 $2.303\,RT = 5.71\ \mathrm{kJ\,mol^{-1}}$ 的标准自由能：乙酸的 $\mathrm{p}K_\mathrm{a} = 4.76$ 意味着把它电离需要 $\Delta_\mathrm{r}G^\circ = 5.71 \times 4.76 = 27.2\ \mathrm{kJ\,mol^{-1}}$。两个推论把整个主题串在一起。**强酸必有弱共轭碱**：共轭碱越想把质子抢回来，酸就越舍不得给出。并且**酸性是对水测定的**：在水中，比 $\mathrm{H_3O^+}$（$\mathrm{p}K_\mathrm{a} = -1.7$）更强的酸都无法存续，因为它会立刻把质子交给水——*拉平效应*。
:::

下表是本章使用的 $\mathrm{p}K_\mathrm{a}$ 阶梯；记住它的地标，而不是每个数字。数值为 $\mathrm{25\ ^\circ C}$ 下的标准数据表值（碳酸的数值是水溶液中 $\mathrm{CO_2}$ 的*表观* $\mathrm{p}K_\mathrm{a}$，即实践中要紧的那个数）。

| 酸 | $\mathrm{p}K_\mathrm{a}$ | 共轭碱 | 酸 | $\mathrm{p}K_\mathrm{a}$ | 共轭碱 |
|---|---|---|---|---|---|
| $\mathrm{HBr}$ | $-9$ | $\mathrm{Br^-}$ | $\mathrm{NH_4^+}$ | $9.25$ | $\mathrm{NH_3}$ |
| $\mathrm{H_3O^+}$ | $-1.7$ | $\mathrm{H_2O}$ | 苯酚 $\mathrm{C_6H_5OH}$ | $10.0$ | $\mathrm{C_6H_5O^-}$ |
| $\mathrm{CF_3COOH}$ | $0.5$ | $\mathrm{CF_3COO^-}$ | 乙硫醇 $\mathrm{CH_3CH_2SH}$ | $10.5$ | $\mathrm{CH_3CH_2S^-}$ |
| $\mathrm{ClCH_2COOH}$ | $2.9$ | $\mathrm{ClCH_2COO^-}$ | $\mathrm{H_2O}$ | $15.7$ | $\mathrm{HO^-}$ |
| $\mathrm{CH_3COOH}$ | $4.76$ | $\mathrm{CH_3COO^-}$ | 乙醇 $\mathrm{CH_3CH_2OH}$ | $16$ | $\mathrm{CH_3CH_2O^-}$ |
| $\mathrm{H_2CO_3}$（表观） | $6.4$ | $\mathrm{HCO_3^-}$ | 丙酮（α $\mathrm{C{-}H}$） | $19.3$ | 烯醇负离子 |
| | | | 乙炔 $\mathrm{HC{\equiv}CH}$ | $25$ | $\mathrm{HC{\equiv}C^-}$ |

从上往下读这张阶梯，就读出了质子转移的整个反应性地图：$\mathrm{H_3O^+}$ 以上的一切都会被水摧毁；水以下的一切，只有低于约 15.7 才能被氢氧根去质子化；而远端——烯烃与烷烃的 $\mathrm{C{-}H}$ 键——酸性强弱程度使得那里的碳负离子是试剂，而不是能用碱配制的物种。

::: example 弱酸溶液的 pH {#ex-ph-weak-acid}
$0.10\ \mathrm{mol\,dm^{-3}}$ 乙酸水溶液的 pH 是多少？已知 $\mathrm{p}K_\mathrm{a} = 4.76$。
::: solution
$K_\mathrm{a} = 10^{-4.76} = 1.74\times10^{-5}$。令 $x = [\mathrm{H_3O^+}] = [\mathrm{CH_3COO^-}]$，$[\mathrm{CH_3COOH}] = 0.10 - x$，则
$$
K_\mathrm{a} = \frac{x^2}{0.10 - x}.
$$
因为 $K_\mathrm{a}$ 很小，先试 $x \ll 0.10$：$x \approx \sqrt{K_\mathrm{a} \times 0.10} = \sqrt{1.74\times10^{-6}} = 1.32\times10^{-3}\ \mathrm{mol\,dm^{-3}}$，这是 $0.10$ 的 $1.3\,\%$——远低于使近似成立的 $5\,\%$ 界限。精确解二次方程得 $x = 1.31\times10^{-3}\ \mathrm{mol\,dm^{-3}}$，于是
$$
\mathrm{pH} = -\log_{10}\left(1.31\times10^{-3}\right) = 2.88 .
$$
两个值得养成习惯的合理性检验：$0.1\ \mathrm{mol\,dm^{-3}}$ 的弱酸应落在 $\mathrm{pH}\ 2$ 到 $4$ 之间；并且 $\mathrm{pH}$ 必须*高于* $\tfrac{1}{2}(\mathrm{p}K_\mathrm{a} - \log_{10} c) = 2.88$——这正是你刚推出的公式。用氯乙酸（$\mathrm{p}K_\mathrm{a} = 2.9$）做同样的算术见 [[#exr-ph-chloro]]。
:::
:::

::: history
两大酸碱定义发表于同一年——1923 年。丹麦物理化学家布朗斯特（Brønsted）与英国化学家劳里（Lowry）各自独立提出了质子转移定义，把酸碱化学从当时流行的限水、限氢氧根的定义中解救出来；承袭范特霍夫（van 't Hoff）平衡传统的布朗斯特立刻看出，这使酸性强弱成为可测的平衡位置问题。同一系列论文中，路易斯（Lewis）提出了更宽的定义——酸接受电子*对*——它涵盖完全没有质子的反应，成为我们表述亲电试剂的语言。弯箭头本身来得稍早又稍晚：鲁宾逊（Robinson）在 1922 年画出了第一个电子对箭头，英戈尔德（Ingold）在 1920 与 1930 年代把它系统化为此后每本有机化学教科书使用的机理语法。
:::

## 平衡规则：一次减法预测平衡位置

::: proposition 平衡规则 {#prop-equilibrium-rule}
对任何质子转移
$$
\mathrm{acid_1 + base_2 \rightleftharpoons base_1 + acid_2}
\qquad
K_\mathrm{eq} = 10^{\,\mathrm{p}K_\mathrm{a}(\mathrm{acid_2}) \;-\; \mathrm{p}K_\mathrm{a}(\mathrm{acid_1})},
$$
其中 $\mathrm{acid_1}$ 是左边的酸、$\mathrm{acid_2}$ 是右边的酸。用文字说：**平衡偏向携带较弱酸（较高 $\mathrm{p}K_\mathrm{a}$）的一侧**，且 $\mathrm{p}K_\mathrm{a}$ 每差一个单位就偏向十倍。相差 $3$ 个单位以上意味着反应超过 $99.9\,\%$——化学上完全进行；差值接近零意味着得到混合物。
:::

::: proof 由两个解离常数导出规则 {#proof-equilibrium-rule}
写出两个酸的解离及其常数：
$$
K_\mathrm{a}(\mathrm{acid_1}) = \frac{[\mathrm{base_1}][\mathrm{H_3O^+}]}{[\mathrm{acid_1}]},
\qquad
K_\mathrm{a}(\mathrm{acid_2}) = \frac{[\mathrm{base_2}][\mathrm{H_3O^+}]}{[\mathrm{acid_2}]} .
$$
第一式除以第二式：$[\mathrm{H_3O^+}]$ 相消，剩下的恰是质子转移的平衡商，
$$
\frac{K_\mathrm{a}(\mathrm{acid_1})}{K_\mathrm{a}(\mathrm{acid_2})}
= \frac{[\mathrm{base_1}][\mathrm{acid_2}]}{[\mathrm{acid_1}][\mathrm{base_2}]}
= K_\mathrm{eq}
= 10^{-\mathrm{p}K_\mathrm{a}(\mathrm{acid_1}) + \mathrm{p}K_\mathrm{a}(\mathrm{acid_2)}} .
$$
这个证明揭示了规则的真正含义：水合氢离子是通货，比较 $\mathrm{p}K_\mathrm{a}$ 就是拿每个酸对质子的需求对同一标准比价。它还显示了自由能内涵：$\Delta_\mathrm{r}G^\circ = -RT \ln K_\mathrm{eq} = -2.303\,RT\left[\mathrm{p}K_\mathrm{a}(\mathrm{acid_2}) - \mathrm{p}K_\mathrm{a}(\mathrm{acid_1})\right]$，每个单位的量值为 $5.71\ \mathrm{kJ\,mol^{-1}}$，所以 $\mathrm{p}K_\mathrm{a}$ 阶梯其实是伪装起来的自由能阶梯。
:::

::: example 氢氧根：它能去质子化哪些酸？ {#ex-hydroxide-acetate}
用平衡规则定量判断水溶液中的氢氧根能否完成对 (a) 乙酸、(b) 苯酚、(c) 乙炔的去质子化。$\mathrm{HO^-}$ 的共轭酸是 $\mathrm{H_2O}$，$\mathrm{p}K_\mathrm{a} = 15.7$。
::: solution
每种情形中，反应物酸是底物、产物酸是水，故 $K_\mathrm{eq} = 10^{15.7 - \mathrm{p}K_\mathrm{a}(\mathrm{substrate})}$。
**(a)** 乙酸：$K_\mathrm{eq} = 10^{15.7 - 4.76} = 10^{10.94} = 8.7\times10^{10}$——十亿比一的胜利；羧酸被氢氧根中和实际上不可逆。
**(b)** 苯酚：$K_\mathrm{eq} = 10^{15.7 - 10.0} = 10^{5.7} = 5.0\times10^{5}$——完全，尽管不那么压倒性；苯酚溶于氢氧化钠水溶液，但（我们将会看到）不溶于碳酸氢钠。
**(c)** 乙炔：$K_\mathrm{eq} = 10^{15.7 - 25} = 10^{-9.3} = 5.0\times10^{-10}$——氢氧根差了九个数量级。乙炔负离子是极强的碱，水会瞬间摧毁它；制备它需要共轭酸*比乙炔更弱*的碱，如 $\mathrm{NH_2^-}$——[[#ex-choose-base]] 将完成这笔算术。
:::
:::

:::

::: example 碳酸氢钠试验：由一次减法得出的鉴别法 {#ex-bicarbonate}
稀碳酸氢钠溶液遇乙酸冒泡，遇苯酚不冒泡。定量解释；产物酸是碳酸，$\mathrm{p}K_\mathrm{a} = 6.4$（表观）。
::: solution
乙酸：$K_\mathrm{eq} = 10^{6.4 - 4.76} = 10^{1.64} = 44$。平衡只向右四十来倍，但逸出的 $\mathrm{CO_2}$ 把它拉到底——开放体系不断抽走产物，于是气泡持续不断。苯酚：$K_\mathrm{eq} = 10^{6.4 - 10.0} = 10^{-3.6} = 2.5\times10^{-4}$——一千倍*不利于*反应，无 $\mathrm{CO_2}$，无气泡。实验台上五秒钟的试验能区分羧酸与苯酚，因为它们的 $\mathrm{p}K_\mathrm{a}$ 恰好分列碳酸两侧：[[organic-1/organic-structures]] 里的官能团试验原来是伪装起来的平衡规则减法。
:::
:::

::: warning $\mathrm{p}K_\mathrm{a}$ 只预测位置，绝不预测速度——而且共轭强度反向 {#warn-pka-rate}
三个误解，每一个都会毁掉考卷。**(1)** *$K_\mathrm{eq}$ 大意味着反应快。* 完全不是：热力学说平衡在哪，动力学说到达要多久。氢氧根去质子化乙炔并不*慢*，只是在 $10^{-9}$ 处停下；而某些 $\Delta_\mathrm{r}G^\circ < 0$ 的反应（金刚石变石墨）要等上地质年代才进行。速率由 $\Delta G^{\ddagger}$ 支配，那是一个完全不同的数——速度住在下面的能量曲线一节里。**(2)** *强酸的共轭碱是强碱。* 恰恰相反：强度沿共轭对反向传递，因为在水中 $\mathrm{p}K_\mathrm{a}(\mathrm{acid}) + \mathrm{p}K_\mathrm{b}(\mathrm{base}) = 14$。$\mathrm{HO^-}$ 是强碱，正因为它的共轭酸水是很弱的酸；乙酸根作为碱软弱无力，恰恰因为乙酸给质子相当慷慨。**(3)** *$\mathrm{p}K_\mathrm{a}$ 标度按"显然"的方向排列。* 它是负对数：$-9$ 是强，$50$ 是绝望。这张阶梯要按方向记——往下，酸越弱，共轭碱越强——而不是按数字。
:::

::: quiz
哪种碱能把乙炔（$\mathrm{p}K_\mathrm{a} = 25$）去质子化到有用的程度，为什么？
- [ ] $\mathrm{HO^-}$，因为氢氧根在水中是强碱。
- [x] $\mathrm{NH_2^-}$，因为它的共轭酸 $\mathrm{NH_3}$（$\mathrm{p}K_\mathrm{a} = 38$）是比乙炔更弱的酸：$K_\mathrm{eq} = 10^{38-25} = 10^{13}$。
- [ ] $\mathrm{CH_3COO^-}$，因为乙酸根是弱酸的共轭碱。
- [ ] 任何一个都行——所有阴离子都是碱，而质子转移都很快。
::: solution
规则比较的是*酸与酸*：只有产物酸比反应酸更弱（$\mathrm{p}K_\mathrm{a}$ 更高）反应才成立。氢氧根给出水（$15.7 < 25$，失败）；乙酸根给出乙酸（$4.76 \ll 25$，以 $2\times10^{20}$ 失败）；氨基负离子给出氨（$38 > 25$，以 $10^{13}$ 成功）。快慢（第 4 项）与位置无关——见 [[#warn-pka-rate]]。
:::
:::

## 数值为何落在它们所在之处：原子、共振、诱导、轨道

::: proposition 四个解释性因素 {#prop-four-factors}
酸性随共轭碱的稳定化而增强。四种效应使阴离子稳定，按典型大小递减排列：**(A) 原子**——沿周期表同族向下，较大的体积把电荷摊到更大的空间，酸性急剧上升（$\mathrm{CH_3CH_2SH}$ $10.5$ 对 $\mathrm{CH_3CH_2OH}$ $16$）；横越一行，电负性占主导，酸性随电负性上升（$\mathrm{CH_3CH_3}$ $50$ $<$ $\mathrm{NH_3}$ $38$ $<$ $\mathrm{H_2O}$ $15.7$）。**(R) 共振**——把电荷离域到几个原子上胜过定域（由 $4.76$ 的 $\mathrm{CH_3COO^-}$ 对由 $16$ 的 $\mathrm{CH_3CH_2O^-}$；由 $10.0$ 的苯酚负离子）。**(I) 诱导**——电负性原子通过 $\sigma$ 键拉走电荷，此效应随距离衰减（乙酸 $4.76$，氯乙酸 $2.9$，三个氟把三氟乙酸拉到 $0.5$）。**(O) 轨道**——孤对电子所占轨道的 s 成分越多，电子被核束缚得越紧，阴离子越稳定：$sp$（$50\,\%$ s）$25$ $<$ $sp^2$（$33\,\%$）$44$ $<$ $sp^3$（$25\,\%$）$50$。
:::

因素的排序本身就是一个事实：原子与共振意见相左时，原子获胜。乙硫醇（$\mathrm{p}K_\mathrm{a} = 10.5$）比乙醇（$16$）强十万倍，尽管乙硫醇负离子没有任何共振可享——硫较大的体积稳定孤立的负电荷远胜于氧较小的体积，而当你沿一列*向下*移动时，体积胜过一切其他因素。这就是为什么硫醇是后续章节中柔软、亲核性强的试剂，而醇在活化之前安静地待着。

共振解释有机化学中最重要的两次酸性跃升。乙酸根把电荷摊在两个等价的氧上——两个 $\mathrm{C{-}O}$ 键完全相同，多余电子由两个氧共同保管——而乙氧基把电荷独自扛在一个氧上：$4.76$ 对 $16$，$10^{11}$ 倍。苯酚负离子离域进环里却永不等价（电荷落在碳上、且一次只落一个氧），苯酚的 $10.0$ 恰好落在两个极端之间：有共振，但共振不完美。

诱导效应较弱且对距离敏感。氯乙酸（$2.9$）比乙酸强六十倍，因为电负性的氯沿 $\sigma$ 骨架拖拽电子密度，分散羧酸根的电荷；每多一个键效应约减半——3-氯丁酸在 $4.0$ 附近、4-氯丁酸在 $4.5$ 附近，而丁酸是 $4.8$——三氟乙酸（$0.5$）则显示三个氟的叠加拉力。氟代系列走得更远：氟乙酸约 $2.6$，低于氯乙酸的 $2.9$，与氟更大的电负性一致。

最后是轨道因素，它是唯一能作用于纯 $\mathrm{C{-}H}$ 酸性的因素，因此也是横亘在你与烃类之间的唯一因素。$sp$ 杂化轨道有 $50\,\%$ s 成分，其电子在核附近停留的时间更多、能量更低：乙炔（$25$）比乙烯（$44$）强 $10^{19}$ 倍，乙烯又比乙烷（$50$）强 $10^{6}$ 倍。常规使用的碱都够不着 $\mathrm{p}K_\mathrm{a} \approx 44$；$sp$ 碳酸在 $25$ 是化学实际上能够攀爬的最低一级。

按酸性递增排列三氟乙酸、乙酸、苯酚、乙硫醇、乙醇与乙炔，并指出各自的主导因素。
::: solution
类乙烷的 $\mathrm{C{-}H}$ 已超出口，从最弱起步：**乙炔**（$25$，仅轨道因素）$<$ **乙醇**（$16$，原子因素：氧，电荷定域）$<$ **乙硫醇**（$10.5$，原子因素沿列向下：硫胜氧）$<$ **苯酚**（$10.0$，共振入环但不完美）$<$ **乙酸**（$4.76$，在两个*等价*氧间的共振）$<$ **三氟乙酸**（$0.5$，共振加三个氟的诱导）。注意这个排序并非单一因素的整齐排队：苯酚与乙硫醇彼此只差三倍，因为不同的因素——共振对原子大小——恰好落在相近的位置。因素预测*数量级*；接近平手要靠数据表来分。
:::
:::

::: example 选一种碱来制造碳负离子 {#ex-choose-base}
你要尽可能完全地把丙酮（α $\mathrm{C{-}H}$ 的 $\mathrm{p}K_\mathrm{a} = 19.3$）变成它的烯醇负离子。用平衡规则评估氢氧根、乙氧基负离子与氨基负离子。
::: solution
各碱的共轭酸：水 $15.7$，乙醇 $16$，氨 $38$。
$$
\mathrm{HO^-}:\ K_\mathrm{eq} = 10^{15.7 - 19.3} = 10^{-3.6} = 2.5\times10^{-4};
\qquad
\mathrm{CH_3CH_2O^-}:\ K_\mathrm{eq} = 10^{16 - 19.3} = 5\times10^{-4};
\qquad
\mathrm{NH_2^-}:\ K_\mathrm{eq} = 10^{38 - 19.3} = 10^{18.7} = 5\times10^{18}.
$$
氢氧根与乙氧基使酮 $99.9\,\%$ 以上保持质子化——这并非无用（$0.03\,\%$ 稳态浓度的烯醇负离子足以驱动第二门课程的羰基化学），但谈不上*制备*。氨基负离子以十八个数量级胜出，是经典选择；一条减法就告诉了你试剂瓶标签永远说不出的东西。
:::
:::

## 亲核试剂与亲电试剂：两个永恒角色

::: definition 亲核试剂与亲电试剂 {#def-nuc-elec}
**亲核试剂**（"亲核的"）是电子对给体——**路易斯碱**——它带着自己的一对电子进攻一个原子形成新键。**亲电试剂**（"亲电的"）是电子对受体——**路易斯酸**。亲核试剂是阴离子或带孤对电子、$\pi$ 键的中性物种（$\mathrm{HO^-}$、$\mathrm{CN^-}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$、$\mathrm{Br^-}$、烯烃的 $\pi$ 键）；亲电试剂是阳离子，或带部分或完整正电荷、八隅体不满、带有离去基团的中性原子（$\mathrm{H^+}$、碳正离子、$\mathrm{C{=}O}$ 的碳、$\mathrm{CH_3Br}$ 的碳、$\mathrm{AlCl_3}$、$\mathrm{BF_3}$）。本课程每一支弯箭头都从亲核试剂指向亲电试剂：从电子所在之处，到电子被需要之处。
:::

碱性与亲核性是表亲，不是双胞胎，这一区分是下一章的预告。**碱性是热力学的**：质子转移走多远，用共轭酸的 $\mathrm{p}K_\mathrm{a}$ 度量。**亲核性是动力学的**：一个物种进攻亲电*碳*有多快，用速率常数度量。横越周期表一行，两者亦步亦趋（$\mathrm{NH_2^-} > \mathrm{HO^-} > \mathrm{F^-}$ 两者皆然），因为抓取质子的同一份富电子性也抓取碳。在质子性溶剂中沿一列向下，两者分道扬镳：$\mathrm{I^-}$ 是弱碱却是极好的亲核试剂，因为大而软的阴离子容易甩掉溶剂笼，奔向碳的途中也容易极化。空间位阻则把它们粗暴地拆开：*叔*丁氧基 $\mathrm{(CH_3)_3CO^-}$ 是比乙氧基更强的碱，却是个糟糕透顶的亲核试剂，因为质子伸手可及而碳不是——这个事实在 [[organic-1/elimination]] 里决定整个反应的结果。

## 弯箭头：机理的语法

::: algorithm 画弯箭头 {#alg-curly-arrows}
**(1)** 箭头始于**电子源**——孤对电子或化学键（绝不始于原子，绝不始于正电荷）——指向**电子去处**：某个原子（电子对将作为新孤对落座之处）或两个原子之间（电子对将成为新键之处）。**(2)** 一支弯箭头移动一对**电子**，不是单个电子；单电子（鱼钩）箭头留待 [[organic-1/radical-reactions]]。**（3）** 电荷守恒：所画物种的总电荷在箭头前后相同。**(4)** 尊重八隅体：第二周期原子（C、N、O、F）不得以超过八个电子收尾——若某孤对在八隅体已满时发起进攻，就必须有另一根键在同一步中离开。**(5)** 平衡用**鱼尾双箭头**（两个半箭头，产物有利时正向画长些）；单个 $\mathrm{H^+}$ 转移通常画成两支箭头——源到质子，键回到它自己的原子。
:::

用文字读出来，这套语法就像句法固定的句子。氢氧根加乙酸：*氢氧根氧上的孤对进攻乙酸的质子；$\mathrm{O{-}H}$ 键的电子退回氧上*，得到水和乙酸根——两支箭头，两边电荷都是 $-1$，八隅体未破。逆反应，乙酸根加水合氢离子：*乙酸根某个氧上的孤对进攻 $\mathrm{H_3O^+}$ 的一个质子；$\mathrm{O{-}H}$ 键的电子退回水的氧上*。平衡规则接着告诉你哪支鱼尾更长：$K_\mathrm{eq} = 10^{15.7-4.76} \gg 1$，所以正向箭头是长的那支。

::: example 用文字与箭头写出的完整机理 {#ex-arrow-mechanism}
液氨中的氨基钠把乙炔去质子化。用弯箭头描述机理，并核对每条记账规则。
::: solution
一步，两支箭头。*$\mathrm{NH_2^-}$ 氮上的孤对进攻乙炔的质子；$\mathrm{C{-}H}$ 键的电子退回 $sp$ 碳上*，得到乙炔负离子（$\mathrm{HC{\equiv}C^-}$，即乙炔化物）和氨。记账：规则 1——两支箭头都始于电子源（孤对、键），终于质子和碳；规则 2——都是电子对；规则 3——电荷反应前 $-1$（在氮上）、反应后 $-1$（在碳上），钠反离子是旁观者，哪里也不用写；规则 4——碳自始至终保持八隅体（失一键、得一孤对）；规则 5——平衡常数是 $10^{38-25} = 10^{13}$，所以诚实的画法里正向鱼尾明显更长。这样制得的乙炔负离子是在合成中搭建碳碳键的亲核试剂——本章酸碱化学第一次变成建筑施工。
:::
:::

::: warning 箭头追逐电子，绝不追逐质子 {#warn-arrow-start}
初学者最常见的箭头是画反的——从*失去*东西的原子画向*得到*东西的原子，仿佛原子才是被搬动的角色。原子在反应中确实会动，但弯箭头只追踪电子，而电子住在孤对和键里。三条规则能抓住所有坏箭头：箭尾必须碰到孤对或键；箭头告诉你两个电子恰好到达何处，所以要数一数去处上的电子（一个已经带着三根键和一对孤对的氧若再收下一对，就有了十个电子——不可能，所以必须有一根键离开）；电荷必须跨步平衡。如果你的箭头从 "$\mathrm{H^+}$" 出发，那不是弯箭头，那是许愿。
:::

## 能量曲线：反应如何翻越地形

::: definition 反应坐标、过渡态、中间体 {#def-energy-profile}
**反应能量曲线**把体系的自由能对**反应坐标**作图——一条从反应物出发、翻过势垒、到达产物的复合坐标。**过渡态**（活化络合物，标记 $\ddagger$）是势垒顶端的能量*极大*：不是物种，绝不可分离，是所有反应轨迹必须经过的几何构型；它高出起始物的量是**活化自由能** $\Delta G^{\ddagger}$，决定速率。**中间体**是两座极大之间真正的*极小*：具有有限寿命的真实物种，坐在深到（有时）能捕获的势阱里。总自由能变 $\Delta G^\circ$ 是两个端点之差，决定平衡，$K_\mathrm{eq} = e^{-\Delta G^\circ/RT}$；对一步反应，$\Delta G^{\ddagger}_{\mathrm{f}} - \Delta G^{\ddagger}_{\mathrm{r}} = \Delta G^\circ$ 严格成立。
:::

这条定义所强制的区分，正是 [[#warn-pka-rate]] 所要求的区分：$\Delta G^\circ$ 与 $\Delta G^{\ddagger}$ 是两个独立的数。强放能的质子转移若势垒很高也会很慢，热中性的反应若势垒很低也能快如闪电。动力学与热力学是两个不同的问题——*多快*与*多远*——能量曲线一次回答两个。

::: proposition 哈蒙德假设与催化剂的诚实 {#prop-hammond}
**哈蒙德（Hammond）假设：**过渡态与能量上更接近的那个稳定物种（反应物或产物）相似。**放能**步骤因此有**早的**、类反应物的过渡态；**吸能**步骤有**晚的**、类产物的过渡态——这就是为什么质子转移的吸能方向，其势垒*感受*得到产物的不稳定。**催化剂**提供一条 $\Delta G^{\ddagger}$ 更低的替代路径，且对两个方向降低同样的量，使 $\Delta G^\circ$、$K_\mathrm{eq}$ 与本课每一个 $\mathrm{p}K_\mathrm{a}$ 纹丝不动：催化剂只让反应更快，绝不让反应更有利。
:::

::: example 从能量曲线上读出数字 {#ex-profile-numbers}
$\mathrm{298\ K}$ 下一步反应的 $\Delta G^{\ddagger}_{\mathrm{f}} = 50\ \mathrm{kJ\,mol^{-1}}$、$\Delta G^\circ = -20\ \mathrm{kJ\,mol^{-1}}$。求 $\Delta G^{\ddagger}_{\mathrm{r}}$、$K_\mathrm{eq}$，以及若催化剂把正向势垒降到 $38\ \mathrm{kJ\,mol^{-1}}$ 后的速率比。
::: solution
$\Delta G^{\ddagger}_{\mathrm{r}} = \Delta G^{\ddagger}_{\mathrm{f}} - \Delta G^\circ = 50 - (-20) = 70\ \mathrm{kJ\,mol^{-1}}$：逆反应要爬势垒*还要*爬热力学的高坡。
$$
K_\mathrm{eq} = e^{-\Delta G^\circ/RT} = e^{20000/2478.8} = e^{8.07} = 3.2\times10^{3},
\qquad
\frac{k_\mathrm{cat}}{k_\mathrm{uncat}} = e^{(50-38)\times10^{3}/2478.8} = e^{4.84} = 1.3\times10^{2}.
$$
十二点五 $\mathrm{kJ\,mol^{-1}}$ 换来一百倍速率——记住汇率 $RT\ln 10 = 5.71\ \mathrm{kJ\,mol^{-1}}$ 每十倍，正是给 $\mathrm{p}K_\mathrm{a}$ 标度定价的同一个常数。按哈蒙德假设，放能的正向步骤有早的、类反应物的过渡态，而催化剂必须把逆向势垒同样降到 $70 - 12 = 58\ \mathrm{kJ\,mol^{-1}}$：两个方向，同样的量，永远如此。
:::
:::

caption: 牛顿法求解精确的弱酸方程 $x^2 + K_\mathrm{a} x - K_\mathrm{a} c = 0$，$x = [\mathrm{H_3O^+}]$，对应 $0.10\ \mathrm{mol\,dm^{-3}}$ 乙酸：根为 $x = 1.31\times10^{-3}\ \mathrm{mol\,dm^{-3}}$，pH $2.88$——本题的近似 $\sqrt{K_\mathrm{a} c}$ 精确到三位数字。同一台机器能解根本没有封闭解的问题：多元的碳酸、按真实称量配制的缓冲液，或恰好使某酸 $99\,\%$ 去质子化的 pH。平衡算术只是算术；近似只是方便，而牛顿永远在那里负责核对。

## 后续内容

本课是语法课，之后每一章都用它写句子。[[organic-1/nucleophilic-substitution]] 是把平衡规则与箭头语法用到碳而不是氢上：亲核试剂、亲电试剂、离去基团，以及两个互相竞争的机理，其快慢取决于 $\Delta G^{\ddagger}$ 而非 $\Delta G^\circ$。[[organic-1/elimination]] 加上进攻还是去质子化的选择——碱性与亲核性之争，以及从 [[organic-1/conformations]] 继承来的 *anti* 几何要求。这里作为亲核试剂登场的 $\pi$ 键，将在 [[organic-1/alkenes-alkynes]] 里变成追逐亲电试剂的一方；我们推迟的鱼钩箭头属于 [[organic-1/radical-reactions]]；$\Delta G^{\ddagger}$ 与速率常数之间的定量桥梁在 [[kinetics/transition-state-theory]] 搭建。贯穿全篇所假定的路易斯结构与电负性机器在 [[bonding-structure/covalent-lewis]]。

::: summary
- 布朗斯特酸给出 $\mathrm{H^+}$；强度是向水转移的平衡常数 $K_\mathrm{a}$，而 $\mathrm{p}K_\mathrm{a} = -\log_{10} K_\mathrm{a}$ 是*反向*的：越小越强，一个单位 $= 5.71\ \mathrm{kJ\,mol^{-1}}$。
- 平衡规则：$K_\mathrm{eq} = 10^{\mathrm{p}K_\mathrm{a}(\mathrm{product\ acid}) - \mathrm{p}K_\mathrm{a}(\mathrm{reactant\ acid})}$；平衡偏向含较弱酸的一侧，$|\Delta\mathrm{p}K_\mathrm{a}| \ge 3$ 即完全。
- 强酸必有弱共轭碱；$\mathrm{p}K_\mathrm{a}$ 阶梯是自由能阶梯，它预测位置，绝不预测速率。
- 四个因素解释这张阶梯：原子大小沿列向下（硫醇 $10.5$ 胜醇 $16$）、共振（羧酸根 $4.76$，苯酚负离子 $10.0$）、诱导（氯 $2.9$，三氟 $0.5$，随距离衰减）、轨道 s 成分（$sp$ $25$ $<$ $sp^2$ $44$ $<$ $sp^3$ $50$）。
- 亲核试剂是路易斯碱（电子对给体），亲电试剂是路易斯酸；亲核性是动力学的，碱性是热力学的，庞大而强碱的试剂做不好亲核试剂。
- 弯箭头始于孤对或键，移动电子对，守恒电荷，绝不超八隅体；鱼尾箭头表示平衡，鱼钩箭头留给自由基章。
- 能量曲线区分 $\Delta G^{\ddagger}$（速率）与 $\Delta G^\circ$（位置）；过渡态是极大，中间体是极小；哈蒙德假设把过渡态结构与能量上更近的一侧挂钩；催化剂把两个方向的势垒降低同样的量。
:::

## 练习

::: exercise 由 $\mathrm{p}K_\mathrm{a}$ 到 $K_\mathrm{a}$ {#exr-ka-tfa level=1 check="0.32"}
三氟乙酸的 $\mathrm{p}K_\mathrm{a} = 0.5$。它的 $K_\mathrm{a}$ 是多少？（输入平衡常数。）
::: solution
$K_\mathrm{a} = 10^{-0.5} = 0.32$。$\mathrm{p}K_\mathrm{a}$ 低于零意味着 $K_\mathrm{a} > 1$；在 $0.5$ 处它是强酸，但在通常浓度下并未完全电离。
:::
:::

::: exercise 一次减法 {#exr-keq-phenol level=1 check="500000"}
计算苯酚 $+\ \mathrm{HO^-} \rightarrow$ 苯酚负离子 $+\ \mathrm{H_2O}$ 的 $K_\mathrm{eq}$（$\mathrm{p}K_\mathrm{a}$：苯酚 $10.0$，水 $15.7$）。（输入平衡常数。）
::: solution
$K_\mathrm{eq} = 10^{15.7 - 10.0} = 10^{5.7} = 5.0\times10^{5}$：完全去质子化，苯酚溶于碱水溶液。
:::
:::

::: exercise 去质子化分数 {#exr-fraction level=1 check="90.9"}
$\mathrm{pH} = 11.0$ 时，苯酚（$\mathrm{p}K_\mathrm{a} = 10.0$）有多大百分比处于去质子化状态？（输入百分比。）
::: solution
分数 $= 100/(1 + 10^{10.0 - 11.0}) = 100/1.1 = 90.9\,\%$。高出 $\mathrm{p}K_\mathrm{a}$ 一个单位即碱型对酸型 $10:1$——即小图中 $\mathrm{pH} = \mathrm{p}K_\mathrm{a} + 1$ 处的那条曲线。
:::
:::

::: exercise 较强的弱酸的 pH {#exr-ph-chloro level=2 check="2.13"}
求 $0.050\ \mathrm{mol\,dm^{-3}}$ 氯乙酸（$\mathrm{p}K_\mathrm{a} = 2.9$）的 pH。（输入 pH。）
::: solution
$K_\mathrm{a} = 10^{-2.9} = 1.26\times10^{-3}$。近似 $x = \sqrt{K_\mathrm{a} c} = 7.9\times10^{-3}$ 占 $c$ 的 $16\,\%$——太大，故解二次方程 $x^2 + K_\mathrm{a} x - K_\mathrm{a} c = 0$：$x = 7.33\times10^{-3}\ \mathrm{mol\,dm^{-3}}$，$\mathrm{pH} = 2.13$。较强的弱酸会惩罚抄近路；newton 小图解的正是这个二次方程。
:::
:::

::: exercise 氢氧根生成烯醇负离子 {#exr-keq-acetone level=2 check="0.00025"}
计算丙酮 $+\ \mathrm{HO^-} \rightleftharpoons$ 烯醇负离子 $+\ \mathrm{H_2O}$ 的 $K_\mathrm{eq}$（$\mathrm{p}K_\mathrm{a}$：丙酮 $19.3$，水 $15.7$）。（输入平衡常数。）
::: solution
$K_\mathrm{eq} = 10^{15.7 - 19.3} = 10^{-3.6} = 2.5\times10^{-4}$：氢氧根只留下约 $0.03\,\%$ 的酮成为烯醇负离子——足以催化，不足以制备。
:::
:::

::: exercise 给定 pH 下的比值 {#exr-ratio level=2 check="0.01"}
某溶液含苯酚（$\mathrm{p}K_\mathrm{a} = 10.0$），缓冲于 $\mathrm{pH} = 8.0$。比值 $[\mathrm{C_6H_5O^-}]/[\mathrm{C_6H_5OH}]$ 是多少？（输入比值。）
::: solution
由 $K_\mathrm{a} = [\mathrm{A^-}][\mathrm{H_3O^+}]/[\mathrm{HA}]$：比值 $= 10^{\mathrm{pH} - \mathrm{p}K_\mathrm{a}} = 10^{-2} = 0.01$。低于 $\mathrm{p}K_\mathrm{a}$ 两个单位，$99\,\%$ 处于质子化形态——这就是为什么把苯酚萃取进碱水溶液要把 pH 推到 12 附近。
:::
:::

::: exercise 推导平衡规则与亨德森–哈塞尔巴尔赫方程 {#exr-derive level=3}
仿照 [[#proof-equilibrium-rule]] 从两个 $K_\mathrm{a}$ 表达式导出平衡规则，再从单个 $K_\mathrm{a}$ 表达式导出亨德森–哈塞尔巴尔赫（Henderson–Hasselbalch）方程 $\mathrm{pH} = \mathrm{p}K_\mathrm{a} + \log_{10}\!\big([\mathrm{A^-}]/[\mathrm{HA}]\big)$，并用它求由 $0.10\ \mathrm{mol\,dm^{-3}}$ 乙酸与 $0.010\ \mathrm{mol\,dm^{-3}}$ 乙酸钠配成的缓冲液的 pH。
::: solution
把 $K_\mathrm{a} = [\mathrm{A^-}][\mathrm{H_3O^+}]/[\mathrm{HA}]$ 重排得 $[\mathrm{H_3O^+}] = K_\mathrm{a}[\mathrm{HA}]/[\mathrm{A^-}]$；两边取 $-\log_{10}$：$\mathrm{pH} = \mathrm{p}K_\mathrm{a} + \log_{10}([\mathrm{A^-}]/[\mathrm{HA}])$。缓冲液：$\mathrm{pH} = 4.76 + \log_{10}(0.010/0.10) = 4.76 - 1 = 3.76$。注意其结构：亨德森–哈塞尔巴尔赫方程就是平衡规则用于酸自身的共轭对，只要用平衡浓度它就是精确的——"近似"只在于假设平衡浓度等于你配进去的量。缓冲液抗酸，因为加入的 $\mathrm{H_3O^+}$ 被 $\mathrm{A^-}$ 消耗（平衡规则：$10^{4.76-(-1.7)} \approx 3\times10^{6}$ 偏向乙酸），抗碱，因为加入的 $\mathrm{HO^-}$ 被 $\mathrm{HA}$ 消耗（$10^{10.94}$）。

::: exercise 能量曲线、催化剂与选碱 {#exr-profile level=3}
两种碱 $\mathrm{B_1}$ 与 $\mathrm{B_2}$ 进攻同一个亲电试剂。$\mathrm{B_1}$ 的共轭酸 $\mathrm{p}K_\mathrm{a} = 11$，$\mathrm{B_2}$ 的为 $17$；两个质子转移放能都超过 $10$ 个 $\mathrm{p}K_\mathrm{a}$ 单位。成键步骤的 $\Delta G^{\ddagger}_1 = 45\ \mathrm{kJ\,mol^{-1}}$、$\Delta G^{\ddagger}_2 = 56\ \mathrm{kJ\,mol^{-1}}$（$\mathrm{298\ K}$）。(a) 对同一个 $\mathrm{p}K_\mathrm{a} = 5$ 的酸，哪个质子转移的 $K_\mathrm{eq}$ 更大？(b) 哪个碱与亲电试剂反应更快，快几倍？(c) 某催化剂把两个势垒相对无催化路径的*超出量*各减半——说明每一步的 $K_\mathrm{eq}$ 会怎样。(d) 哈蒙德将较快那步的过渡态放在哪里？
::: solution
(a) 在 $\mathrm{B + HA \rightarrow BH^+ + A^-}$ 中，反应物酸是那个公共酸（$\mathrm{p}K_\mathrm{a} = 5$），产物酸是 $\mathrm{B_1H^+}$（$11$）与 $\mathrm{B_2H^+}$（$17$）：$K_\mathrm{eq} = 10^{11-5} = 10^{6}$ 对 $10^{17-5} = 10^{12}$。较强的碱 $\mathrm{B_2}$ 在热力学上获胜。(b) 速率只由 $\Delta G^{\ddagger}$ 决定：$\mathrm{B_1}$，快 $e^{(56-45)\times10^{3}/2478.8} = e^{4.44} = 85$ 倍。经典的解耦：较弱的碱反应更快——碱性（位置）与亲核性（速率）分道扬镳，正如预告所言。(c) 什么都不变：催化剂把正、逆势垒降低同样的量，所以每一步的 $\Delta G^\circ$ 与 $K_\mathrm{eq}$ 都不变。(d) 该步骤放能（质子转移达 $10^{6}$；成键步骤同样下坡），所以按哈蒙德假设它的过渡态是早的、类反应物的——它的能量、从而它的速率，几乎感受不到产物的不稳定。
