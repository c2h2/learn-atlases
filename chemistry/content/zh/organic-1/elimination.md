在 [[organic-1/nucleophilic-substitution]] 中，试剂是走向碳的：亲核试剂把电子对交给亲电中心，离去基团带着成键电子离开，一根键替换另一根键。消除反应是这个故事的逆向主题。离去基团照样离开，但碳上没有任何东西去填补它的位置；试剂转而充当**碱**，从相邻碳上夺走一个质子，而原先维系这个质子的电子对落进两个碳之间的空档，撑开一根 $\pi$ 键。产物是烯烃——而 [[organic-1/alkenes-alkynes]] 的亲电加成化学，在精确的微观意义上，正是这个反应倒过来跑。两个问题组织起整章：夺走的是*哪个* $\beta$-氢，因而生成哪个烯烃（一个**区域选择性**问题）？当同一个试剂两样都能干时，反应又*如何*在消除与取代之间做选择？沿途我们会领教物理有机化学最锋利的一课：机理不是单凭产物推断出来的，而是动力学、同位素效应与几何三者共同指认的。

## 总反应与电子记账

::: definition 消除、$\beta$-消除与脱卤化氢 {#def-elimination}
**消除反应**是从分子中除去两个原子或基团、并在其位置形成一根多重键的反应。在本章占主导的 **$\beta$-消除**（或称 **1,2-消除**）中，**$\alpha$-碳**上的离去基团与相邻**$\beta$-碳**上的氢一道丢失，因此新 $\pi$ 键永远位于 $\alpha$-碳与 $\beta$-碳之间：
$$
\mathrm{{-}C^{\beta}H{-}C^{\alpha}X{-} \longrightarrow {-}C^{\beta}{=}C^{\alpha}{-} + H^+ + X^-}.
$$

当离去基团是卤素、碱是氢氧化物或醇盐时，反应称为**脱卤化氢**，

$$
\mathrm{RCH_2CHX R' + B^- \longrightarrow RCH{=}CHR' + HB + X^-}.
$$

弯箭头记账是三根箭头、三处键变化：*碱的孤对电子进攻 $\beta$-氢；$\mathrm{C{-}H}$ 键的电子落入 $\mathrm{C^{\alpha}{-}C^{\beta}}$ 空档成为 $\pi$ 键；$\mathrm{C^{\alpha}{-}X}$ 键的电子跟着离去基团落到 X 上*。注意粒子数目：两种反应物粒子变成三种产物粒子——这个事实将如我们即将看到的，通过熵项 $-T\Delta S$ 决定整个反应的结果。
:::

碱的强度从 [[organic-1/acidity-mechanism]] 的同一把梯子上读出：消除反应的常用碱有氢氧化物（共轭酸 $\mathrm{H_2O}$ 的 $\mathrm{p}K_\mathrm{a}$：$15.7$）、乙醇盐（$16$）、叔丁醇盐（$18$）以及脒类碱 DBU（共轭酸 $\mathrm{p}K_\mathrm{a} \approx 12$）。DBU 是富有教益的例外：它的共轭酸是被共振稳定的脒鎓阳离子，所以按梯子它是*中等*强度的碱——但它体积巨大、几乎毫无亲核性，且质子转移极快，因而成为出色的消除促进剂。碱性（平衡停在哪里）与夺质子的速率（碱多快抓住*这个*氢）是两种性质，而大体积碱恰恰活在两者之间的缝隙里。

::: example 映射 2-溴丁烷的消除产物 {#ex-map-2bromobutane}
2-溴丁烷 $\mathrm{CH_3CHBrCH_2CH_3}$ 经 $\beta$-消除能得到哪些烯烃？各位于哪个氢？暂且不管立体化学。
::: solution
$\alpha$-碳是 C2（带 Br）。它有两个 $\beta$-碳：C1（甲基，三个等价氢）与 C3（$\mathrm{CH_2}$，两个氢）。从 C1 夺氢得**丁-1-烯**；从 C3 夺氢得**丁-2-烯**，后者以 $E$、$Z$ 两种异构体存在，故烯烃产物共三种。没有别的 $\beta$-碳，也就没有别的消除产物——一切"生成哪个烯烃"的问题都化归为数 $\beta$-碳、再在其中分辨。C4 相对于 C2 是 $\gamma$-碳，其氢不可能在 1,2-消除中被夺走。
:::
:::

## E2：一步、二级、且对几何有硬性要求

::: proposition E2 的速率方程 {#prop-e2-rate}
双分子消除 **E2** 以单步协同方式进行——夺质子、$\pi$ 键成键与离去基团脱落全在同一个过渡态里完成——其总级数为二的速率方程为
$$
v = k_\mathrm{E2}\,[\mathrm{RX}][\mathrm{B^-}]:
$$
底物或碱任一者加倍，速率即加倍。这条速率方程上系着三条机理事实。**（1）**两种粒子都在过渡态里，中间不容他物：没有碳正离子，没有中间体，没有重排。**（2）**$\mathrm{C{-}H}$ 键正在决速步中断裂，所以把该氢换成 D 会使反应变慢，呈现**一级动力学同位素效应** $k_\mathrm{H}/k_\mathrm{D} \approx 2$–$7$——C–D 的零点能优势（约 $5\ \mathrm{kJ\,mol^{-1}}$，在 $\mathrm{298\ K}$ 下折算为 $e^{5000/2478.8} \approx 7$）必须在过渡态中偿还。**（3）**速率次序为叔 $>$ 仲 $>$ 伯（2-卤代丁烷对乙醇钠的典型相对次序约为 $50 : 7 : 1$），与 $\mathrm{S_N2}$ *相反*，因为其过渡态已带烯烃特征，而烷基能稳定初生的 $\pi$ 键（哈蒙德假说，见 [[organic-1/acidity-mechanism]]）。
:::

一个如此简单的机理为什么会有几何要求？因为电子必须*赶路*，而接收它们的轨道是有形状的。

::: definition 反式共平面要求 {#def-antiperiplanar}
两根键处于同一平面且二面角为 $180^\circ$ 时称为**反式共平面**（$0^\circ$ 时称**顺式共平面**）。E2 过渡态要求 $\mathrm{C^{\beta}{-}H}$ $\sigma$ 键与 $\mathrm{C^{\alpha}{-}X}$ $\sigma^*$ 轨道反式共平面，因为这个步骤用轨道语言说，就是从 $\sigma_{\mathrm{C-H}}$ 成键轨道向 $\sigma^*_{\mathrm{C-X}}$ 反键轨道的给电子——与 $\mathrm{S_N2}$ 的"背面进攻"逻辑同源，只是靶子换成了质子。只有当两根键共面且相对时，$\mathrm{C{-}H}$ 成键电子对才能在 $\pi$ 键闭合之际与 $\sigma^*$ 的大背面瓣重叠；二面角为 $60^\circ$ 时重叠积分为零。顺式共平面消除在对称性上是允许的，但要在过渡态中付出其余键的重叠、拥挤排布，因而罕见得多——真正的顺式消除属于其他机理（胺氧化物的柯普消除、酯的热解消除），它们把 H 与离去基团强行按在*顺式*位置。
:::

用纽曼投影式读这个要求，它就变成了一个数数的游戏。

::: example 2-溴丁烷的哪些氢符合条件？ {#ex-newman-2bromobutane}
沿 $\mathrm{C2{-}C3}$ 键观察 2-溴丁烷，使 Br 与 C3 的某个氢处于*反式*。那个旋转异构体给出哪个烯烃？其余产物又从何而来？
::: solution
前碳 C2 带 Br、H 与 $\mathrm{CH_3}$（C1）；后碳 C3 带 H、H 与 $\mathrm{CH_3}$（C4）。绕 $\mathrm{C2{-}C3}$ 旋转，使 Br 与选定的 $\beta$-氢成 $180^\circ$；该旋转异构体里只有这个氢能被夺走。当 Br 与"夺走它恰好使两个甲基落在异侧"的那个 C3 氢反式时，产物是 ($E$)-丁-2-烯（*trans*-2-丁烯）；与另一个 C3 氢反式则两个甲基落在同侧，得 ($Z$)-丁-2-烯（*cis*-2-丁烯）。第三个旋转异构体把 Br 摆在甲基 C1 某个氢的反位，其消除得丁-1-烯。于是 [[#ex-map-2bromobutane]] 的三种产物各来自三个不同的旋转异构体，产物比度量的是三个反式共平面过渡态的自由能——而不只是各旋转异构体的布居。
:::
:::

::: history
本章两条对立的规则比解释它们的机理更古老。1875 年，俄国化学家札依采夫（Saytzeff/Zaitsev）在研究戊基卤与酯的消除时记录道：氢倾向于从已带氢最少的 $\beta$-碳上离开——多取代烯烃占优——这条概括自此以他命名。十年之后，霍夫曼（Hofmann）在发展其彻底甲基化法以剖析胺类的过程中，于季铵与锍的氢氧化物消除里发现了相反的选择性，并据此建立起可预言的"最少规则"；两条规则都活了下来，因为它们各有机理。至于动力学骨架——把 E1 与 E2 分别指认为一级与二级速率方程，并与 $\mathrm{S_N1}$、$\mathrm{S_N2}$ 并列为饱和碳的四条基本通道——则由休斯（Hughes）与英戈尔德（Ingold）在 1930 至 1940 年代的一系列论文中搭建；反式共平面的几何要求，随后不久也从环状与甾体卤化物的立体化学中被提炼出来。
:::

## 区域选择性：札依采夫规则与其背后的数据

::: proposition 札依采夫规则（一条经验规则） {#prop-zaitsev}
**札依采夫规则：**从不对称底物消除 $\mathrm{HX}$ 时，主产物是取代较多的（烷基化程度较高的）烯烃。它是一条**经验规则**——对小醇盐典型行为的小结，而非焊死了一个机理的自然法则——其物理基础是烯烃的稳定性，可由氢化热直接度量（$\mathrm{kJ\,mol^{-1}}$，标准数据表值）：

| 烯烃 | $\Delta_\mathrm{hyd}H$ / $\mathrm{kJ\,mol^{-1}}$ | 取代程度 |
|---|---|---|
| $\mathrm{CH_2{=}CHCH_2CH_3}$（丁-1-烯） | $-30.3$ | 单取代 |
| ($Z$)-丁-2-烯 | $-28.6$ | 二取代，*cis* |
| ($E$)-丁-2-烯 | $-27.6$ | 二取代，*trans* |
| 2-甲基丁-2-烯 | $-26.9$ | 三取代 |

每个烷基使双键稳定约 $1$–$2\ \mathrm{kJ\,mol^{-1}}$（超共轭：相邻 $\mathrm{C{-}H}$ $\sigma$ 电子对向 $\pi^*$ 轨道的给电子），而 *trans* 因省去甲基–甲基接触比 *cis* 低 $1.0\ \mathrm{kJ\,mol^{-1}}$。由于 E2 过渡态带烯烃特征，这些稳定性会反映到过渡态能量上（又是哈蒙德），于是多取代烯烃生成得更快。预期规则将在以下情形失效：过渡态的烯烃特征不足以让它"在乎"，或碱根本够不着——大体积碱、大体积底物，以及下文的环己烷二直立键约束。
:::

2-溴丁烷的典型产物分布（代表性的数据表值，只计消除产物）把这场竞争说得明明白白：乙醇钠/乙醇中，丁-1-烯 $12\,\%$、*cis*-2-丁烯 $27\,\%$、*trans*-2-丁烯 $61\,\%$——札依采夫烯烃共 $88\,\%$，其中 $E$ 异构体又因 $1.0\ \mathrm{kJ\,mol^{-1}}$ 的稳定性差而占先（$1.0\ \mathrm{kJ\,mol^{-1}}$ 之差在反应温度下不过 $e^{1000/(8.314 \times 350)} \approx 1.4$ 倍，这就是 *cis* 仍大量出现的原因）。换叔丁醇钾则图像反转：丁-1-烯约 $52\,\%$。原因是够不够得着，而不是稳定性：末端 C1 甲基的氢摊在开阔空地上，取用便宜；而内部 $\beta$-氢窝在分子腹地、离去基团自己的烷基取代基背后。叔丁醇钾这样大的碱夺末端氢付出的空间代价更小，于是生成霍夫曼产物的过渡态反而更低。霍夫曼自己的体系——季铵与锍的氢氧化物——选择性反转也是同一类原因：体积巨大、带正电的离去基团使过渡态提前，$\beta$-氢的*酸性与可及性*（统计与静电的）便压过了烯烃稳定性。

::: example 用条件来选烯烃 {#ex-zaitsev-hofmann}
预测 2-溴-2-甲基丁烷在 (a) 乙醇钠/乙醇与 (b) 叔丁醇钾/叔丁醇中的主烯烃，并各自用上文数据说明理由。
::: solution
底物有两类 $\beta$-氢：连在 C2 上的两个等价甲基共六个（夺之得 2-甲基丁-1-烯，二取代），以及 C3 上的两个（夺之得 2-甲基丁-2-烯，三取代）。**(a)** 乙醇钠体积小：札依采夫规则适用，三取代烯烃胜出——2-甲基丁-2-烯是主产物，其优势植根于氢化数据表上它相对二取代对手约 $1.5\ \mathrm{kJ\,mol^{-1}}$ 的领先。**(b)** 叔丁醇钾够不着内部氢：2-甲基丁-1-烯成为主产物。两个反应同一底物、同一机理、同一离去基团——产物却相反，完全由碱的形状决定。这就是本章的中心合成事实：*试剂决定区域化学*。
:::
:::

## 环己烷的否决权：把消除当作椅式问题

在开链分子里，旋转总能把 H 与 X 带到 $180^\circ$：反式共平面要求花费的是一个旋转异构体，不是一根键。环己烷环里，几何被椅式冻住。两根环键反式共平面，当且仅当它们处于反式二直立键——两者皆直立、位于相邻碳、指向环的相反两面。平伏的离去基团没有任何反式共平面的氢：它到每个 $\beta$-氢的二面角都是 $\pm 60^\circ$。因此环己烷上的 E2 只能等待把离去基团翻成直立的那次翻环；届时它*唯一*能夺的氢是直立氢——而那未必是札依采夫规则会选中的氢。

::: example 4-叔丁基环己基的检验：顺式快，反式慢 {#ex-diaxial-tbc}
4-叔丁基环己基溴的两种异构体各与强碱作用。叔丁基（A值 $23\ \mathrm{kJ\,mol^{-1}}$，[[organic-1/conformations]]）把环锁死。预测哪种异构体消除更快，快大约多少。
::: solution
对 1,4-二取代环，*trans* 可以双平伏，*cis* 则是（平伏，直立）。叔丁基锁在平伏位（另一椅式要付 $23\ \mathrm{kJ\,mol^{-1}}$，其布居只有前者 $1/1.07\times10^{4}$），于是 **cis** 异构体带着**直立**溴：两侧都备好了反式共平面的直立氢，E2 随即发生。**trans** 异构体带着平伏溴：不存在反式共平面的氢，反应必须等待那次付出整整 $23\ \mathrm{kJ\,mol^{-1}}$ 的翻环（把溴翻直立，也把叔丁基翻直立）。速率比约即反应性椅式的平衡比，$e^{23000/(8.314 \times 298)} \approx 1.1\times10^{4}$——cis 异构体快约一万倍。同样的逻辑解释了经典的薄荷基氯/新薄荷基氯：薄荷基氯恰好只有一个反式共平面的 $\beta$-氢，它通向*非*札依采夫的二取代烯烃，而且是唯一产物，因为札依采夫路线没有可夺的二直立氢。几何与札依采夫相左时，几何说了算。
:::
:::

::: warning 三条不是法则的经验之谈 {#warn-rules-of-thumb}
**（1）**"札依采夫规则是自然法则"。它是经验倾向，对小醇盐与无张力开链底物好用，却会败给空间可及性（霍夫曼条件）与环上的二直立键要求——[[#ex-diaxial-tbc]] 表明，几何与热力学每次相左，几何都赢。**（2）**"E2 只需要强碱"。它需要强碱**并且**需要一个反式共平面的 H–C–C–X 排列；碱在场而几何缺席的底物根本不走 E2（上面的 trans-溴化物不是迟钝，是在等一次翻环）。**（3）**"加热只是让反应变快"。热改变的是**选择性**，不只是速度：消除握着一个随 $T$ 增长的熵优势（下一节），所以同一只烧瓶在 $25\ ^\circ\mathrm{C}$ 与 $80\ ^\circ\mathrm{C}$ 可以给出不同的产物比，而不只是同样产物多一些。
:::

## E1：经由碳正离子的消除

::: definition E1 机理 {#def-e1}
**E1**（单分子消除）经碳正离子分两步移去 H 与 X：底物在慢的决速步中**电离**——$\mathrm{RX \rightarrow R^+ + X^-}$——随后（弱）碱从碳正离子上夺去一个 $\beta$-氢作为快的第二步。速率方程为一级，$v = k_\mathrm{E1}[\mathrm{RX}]$：碱不出现，因为它只在瓶颈之后才到场。E1 是 $\mathrm{S_N1}$（[[organic-1/nucleophilic-substitution]]）的消除孪生：两者共享*同一步*电离，从同一个碳正离子出发相互竞争，所以 E1 出现在 $\mathrm{S_N1}$ 出现的一切地方——叔底物、电离性溶剂、弱碱——并被热所促进。三条推论：没有立体电子要求（碳正离子是平面的，任何 $\beta$-氢都能走）；**碳正离子重排**成为可能（能给出更稳定碳正离子的氢负离子与烷基迁移会先于消除发生）；札依采夫选择性是常态，因为给碳正离子去质子的过渡态富烯烃特征，稳定性得以尽情施展。
:::

由于 $\mathrm{S_N1}$ 与 E1 共享第一步，产物比就由*第二步*的竞争决定——溶剂捕获碳正离子对去质子化——两条通道在有效势垒上通常只差 $1$–$2\ \mathrm{kJ\,mol^{-1}}$，在 $350\ \mathrm{K}$ 即 $1.4$–$2$ 倍。这就是溶剂解温度决定产物比的原因：加热，消除份额上升；冷却，取代获胜。

::: example 2-溴-2-甲基丙烷的溶剂解 {#ex-e1-tertbutyl}
2-溴-2-甲基丙烷在温热的含水乙醇中给出叔丁醇、它的乙基醚和一种烯烃。写出速率方程，指认机理，并预测烯烃份额随温度如何变化。
::: solution
速率 $= k[\mathrm{(CH_3)_3CBr}]$——一级，与水和乙醇无关：电离成叔丁基碳正离子是决速步，且为三种产物所共有。随后碳正离子被水捕获（$\mathrm{S_N1}$ → 醇）、被乙醇捕获（$\mathrm{S_N1}$ → 醚），或被溶剂去质子（$\mathrm{E1}$ → 2-甲基丙烯）。不可能重排（碳正离子已是叔的），也无立体化学可言。升温提高烯烃份额——下一节的熵论证——这就是溶剂解"回流之下趋于消除"的原因。同一底物若换乙醇钠，则彻底抛弃 E1 改走 E2：强碱、二级动力学、无碳正离子、无醚。
:::
:::

## 热与熵：为什么高温下消除胜出

消除把两种粒子变成三种；取代把两种粒子变成两种。消除的产物侧因此携带巨大的熵优势——粒子更多、平动更多、自由度更多——而成烯的焓变并不特别慷慨，自由能 $\Delta G = \Delta H - T\Delta S$ 恰好按 $\Delta S$ 的比例随温度改善。同样的论证应当跑在动力学一侧：E2 过渡态比 $\mathrm{S_N2}$ 对手更松散、更趋于碎裂，故 $S^{\ddagger}_\mathrm{E2} > S^{\ddagger}_\mathrm{SN2}$。用如下模型刻画这场竞争：$\Delta\Delta H^{\ddagger} = \Delta H^{\ddagger}_\mathrm{E2} - \Delta H^{\ddagger}_\mathrm{SN2} = +15\ \mathrm{kJ\,mol^{-1}}$（取代的焓势垒较低），$\Delta\Delta S^{\ddagger} = +40\ \mathrm{J\,mol^{-1}\,K^{-1}}$（消除握有熵优势）。于是

$$
\Delta\Delta G^{\ddagger}(T) = \Delta\Delta H^{\ddagger} - T\,\Delta\Delta S^{\ddagger}
= 15 - 0.040\,T \ \ \mathrm{kJ\,mol^{-1}},
$$

在 $T^* = 15\,000/40 = 375\ \mathrm{K}$ 处归零。$\mathrm{298\ K}$ 时 $\Delta\Delta G^{\ddagger} = +3.1\ \mathrm{kJ\,mol^{-1}}$，$k_\mathrm{E2}/k_\mathrm{SN2} = e^{-3100/2478.8} = 0.29$：消除约 $22\,\%$。$\mathrm{373\ K}$ 时比值为 $0.98$——并驾齐驱。$\mathrm{450\ K}$ 时 $\Delta\Delta G^{\ddagger} = -3.0\ \mathrm{kJ\,mol^{-1}}$，消除取走 $69\,\%$。一个数 $\Delta S$ 替"热促进消除"这句口诀干了全部的活：每升高一度，熵优势就被多兑现一分。

caption: 模型化的选择性差 $\Delta\Delta G^{\ddagger} = \Delta\Delta H^{\ddagger} - T\Delta\Delta S^{\ddagger}$（单位 $\mathrm{kJ\,mol^{-1}}$）对温度的曲线，焓优势归取代（$+15\ \mathrm{kJ\,mol^{-1}}$），熵优势归消除（$+40\ \mathrm{J\,mol^{-1}\,K^{-1}}$）。竖直直线 $T^* = 375\ \mathrm{K}$ 之上差值为负，消除是较快通道；之下则取代占先。直线之所以是直的，是因为在此温区内 $\Delta H^{\ddagger}$ 与 $\Delta S^{\ddagger}$ 视为与温度无关——这是个好近似，也是单一交叉温度得以存在的原因。

## 预测胜者：底物、试剂、温度

::: algorithm 预测取代与消除的竞争 {#alg-compete}
给定底物与试剂，按五个问题依次过筛定产物。**（1）底物类别。**甲基与伯碳不可能成碳正离子（无 $\mathrm{S_N1}$/E1），消除也慢（E2 过渡态没有烯烃稳定化）；叔碳做不了 $\mathrm{S_N2}$（背面被堵），一旦电离就绝不再等亲核试剂；仲底物是必争之地，由试剂与温度裁决。**（2）试剂：是碱还是亲核试剂？**读共轭酸 $\mathrm{p}K_\mathrm{a}$ 定强度（$\ge 13$：强碱；$\le 11$：弱碱），看结构定体积：$\alpha$-碳带三个以上取代基的负离子（叔丁醇盐）或并环含氮碱（DBU）是强碱、差亲核试剂——它们走消除。好的弱碱亲核试剂（$\mathrm{I^-}$、$\mathrm{Br^-}$、$\mathrm{RS^-}$、$\mathrm{CN^-}$、$\mathrm{N_3^-}$）走取代。**（3）温度。**约 $320$–$350\ \mathrm{K}$ 以上，或凡选择本已接近平手，就把熵红利记到消除账上（下面的第 5 步正是热）。**（4）溶剂。**极性质子溶剂鼓励电离（弱试剂配 $\mathrm{S_N1}$/E1）；非质子溶剂让负离子裸露，磨利 $\mathrm{S_N2}$/E2。**（5）宣读判决。**强碱 + 叔 → E2。强碱 + 伯 → 仅当碱体积大或热时 E2，否则 $\mathrm{S_N2}$。强碱 + 仲 → 热而体积大时 E2 主导，冷而体积小时 $\mathrm{S_N2}$ 竞争。弱碱 + 叔（或仲，慢）→ $\mathrm{S_N1}$ + E1 混合物，消除份额随温度上升。弱碱 + 伯或甲基 → 不反应（若有好亲核试剂则 $\mathrm{S_N2}$）。
:::

::: example 给四个烧瓶定性 {#ex-classify}
预测主要通道与主有机产物：(a) 2-溴丁烷 + 乙醇钠/乙醇，$\mathrm{50\ ^\circ C}$；(b) 2-溴丁烷 + 叔丁醇钾/叔丁醇，$\mathrm{40\ ^\circ C}$；(c) 2-溴丁烷在含少量乙醇的水中，$\mathrm{60\ ^\circ C}$；(d) 2-溴-2-甲基丙烷在水中，$\mathrm{25\ ^\circ C}$。
::: solution
**(a)** 仲底物、强碱（乙醇钠，共轭酸 $\mathrm{p}K_\mathrm{a} = 16$）、加热：E2 主导并伴少量 $\mathrm{S_N2}$；札依采夫产物，($E$)-丁-2-烯为主。**（b）** 同一底物、大体积强碱：E2 且区域化学反转——丁-1-烯（霍夫曼）为主。**（c）** 弱碱/弱亲核试剂、仲底物：慢的 $\mathrm{S_N1}$ + E1 溶剂解；丁-2-醇（伴随外消旋化）加上被热抬高的丁-2-烯份额。**（d）** 叔底物、弱试剂、冷：$\mathrm{S_N1}$ 赢得混合物——叔丁醇为主，2-甲基丙烯为次；加热则烯烃份额攀升。注意 (a) 与 (b) 只差一个负离子的形状，(c) 与 (d) 只差带离去基团碳的取代度——这套算法无非这两个变量再加一支温度计。
:::
:::

::: quiz
某仲卤代烷与乙醇钠反应。哪种改动最能提高消除/取代比，为什么？
- [ ] 把溶剂换成极性非质子溶剂，因为裸露的负离子优先消除。
- [x] 升高温度，因为随着 $T$ 上升，消除在 $-T\Delta S$ 上对取代步步进逼——两种粒子变成三种。
- [ ] 把乙醇钠改为四倍过量，因为 E2 对碱是一级而 $\mathrm{S_N2}$ 不是。
- [ ] 把卤素换成碘，因为更好的离去基团专门促进消除。
::: solution
E2 与 $\mathrm{S_N2}$ 都对碱一级，都被更好的离去基团加速，所以过量（第 3 项）与碘（第 4 项）同时加速两条通道而不大偏袒；极性非质子溶剂（第 1 项）往往*更*磨利 $\mathrm{S_N2}$。温度才是有选择性的杠杆：两条通道的熵差按正比于 $T$ 的比例转化为选择性，上文 $\Delta\Delta G^{\ddagger}(T)$ 模型展示的正是这一点。
:::
:::

## 合成中的消除——以及安全

脱卤化氢是*制造*烯烃的主力，当烯烃要在合成中别处派用场时：先安装离去基团（从醇出发，经磺酸酯或卤代烃——[[organic-1/alcohols-ethers]]），再选碱定烯——小醇盐取札依采夫异构体，叔丁醇钾或 DBU 取霍夫曼异构体，环几何拥有最终否决权。烯烃很少就是目标：它是把手，是平台，[[organic-1/alkenes-alkynes]] 的加成化学将把它官能化为醇、卤代烃、二醇与羰基化合物。在实验台上，危险属于整个类别：低分子量的烯烃是极易挥发、无色、有气味的气体或低沸点液体（2-甲基丙烯约在 $-7\ ^\circ\mathrm{C}$ 沸腾）——GHS 火焰象形图，易燃，比空气重的蒸气会贴地奔向点火源——所以产生它们的反应须在通风橱中用密闭或排气系统进行，远离电火花与明火。酸性副产物（HX）有腐蚀性，由反应中的碱就地吸收，或在抵达真空管线之前被吸收阱捕集；此类实验只应在指导之下、完成风险评估之后进行。

## 后续内容

消除与加成是一对搭档，[[organic-1/alkenes-alkynes]] 打开这对搭档的另一半：亲电加成本章亲手做出的那些双键，马尔科夫尼科夫规则作为札依采夫规则的镜像，以及碳正离子重排作为 E1 与它们共享的标志。[[organic-1/alcohols-ethers]] 提供离去基团（磺酸酯、质子化的醇）与竞争的脱水反应；[[organic-1/nucleophilic-substitution]] 仍是你将要画出的每一只烧瓶上的竞争通道。本章的单电子近亲——自由基加成与反马氏过氧化物效应——在 [[organic-1/radical-reactions]]；而把速率方程与过渡态结构（同位素效应、活化熵）定量连接起来的机器，在 [[kinetics/transition-state-theory]] 中正式建造。

::: summary
- 消除从相邻两碳上各去一个 H 与一个离去基团并撑开一根 $\pi$ 键；新双键永远位于 $\alpha$-与 $\beta$-碳之间，两种粒子变三种。
- E2 是协同的二级反应，$v = k[\mathrm{RX}][\mathrm{B^-}]$，有一级动力学同位素效应，并按 $3^\circ > 2^\circ > 1^\circ$ 进行，因为其过渡态带烯烃特征。
- E2 要求反式共平面的 H–C–C–X 排列（$\sigma_{\mathrm{C-H}} \rightarrow \sigma^*_{\mathrm{C-X}}$ 给电子）；在环己烷中这意味着反式二直立键，该要求凌驾一切区域规则。
- 札依采夫规则——多取代烯烃占优——是经验的，植根于烯烃稳定性（氢化热：单取代到三取代 $-30.3$ 至 $-26.9\ \mathrm{kJ\,mol^{-1}}$；*trans* 比 *cis* 低 $1.0\ \mathrm{kJ\,mol^{-1}}$）。
- 大体积碱（叔丁醇钾、DBU）与巨大的离去基团（霍夫曼的铵、锍氢氧化物）给少取代的霍夫曼产物，因为决定势垒的是可及性与酸性，而非烯烃稳定性。
- E1 是单分子的，与 $\mathrm{S_N1}$ 共享电离步，无几何要求，允许重排，伴随叔底物、弱碱与热出现。
- 热促进消除，因为 $\Delta\Delta G^{\ddagger} = \Delta\Delta H^{\ddagger} - T\Delta\Delta S^{\ddagger}$：$+40\ \mathrm{J\,mol^{-1}\,K^{-1}}$ 的熵优势在一个交叉温度处扭转乾坤。
- 预测是一套算法：先底物类别，再碱的强度与体积，然后温度与溶剂——而试剂的形状、不只是它的 $\mathrm{p}K_\mathrm{a}$，决定区域化学。
:::

::: exercise 数一数烯烃 {level=1 check="3"}
2-溴丁烷经 $\beta$-消除能得到多少种不同的烯烃产物（$E/Z$ 异构体分开计数）？（输入数目。）
::: solution
三种：丁-1-烯、($E$)-丁-2-烯与 ($Z$)-丁-2-烯。两个 $\beta$-碳，但 C3 的两个氢通向 $E$、$Z$ 两种异构体，而 C1 的氢给末端烯烃——见 [[#ex-map-2bromobutane]]。
:::

::: exercise 速率方程 {level=1 check="4"}
某反应按 E2 机理进行。底物与碱的浓度都加倍。速率增大为原来的几倍？（输入倍数。）
::: solution
$v = k[\mathrm{RX}][\mathrm{B^-}]$，故 $2 \times 2 = 4$。两种粒子都在唯一的过渡态里；这个 $2\times2$ 检验正是休斯与英戈尔德区分 E2 与 E1 的手段。
:::

::: exercise 等待直立椅式 {level=1 check="0.000093"}
$\mathrm{298\ K}$ 下，对 *trans*-1-溴-4-叔丁基环己烷，取叔丁基的 A值为 $23\ \mathrm{kJ\,mol^{-1}}$，计算溴处于直立位的分子分数（E2 的反应性椅式）。（输入分数。）
::: solution
$[\mathrm{ax}]/[\mathrm{eq}] = e^{-23000/(8.314 \times 298)} = 9.3\times10^{-5}$，分数为 $9.3\times10^{-5}/(1 + 9.3\times10^{-5}) \approx 9.3\times10^{-5}$。十万个分子里只有九个带直立溴——这就是 [[#ex-diaxial-tbc]] 中两种异构体 $10^{4}$ 倍速率差的由来。
:::
:::

::: exercise *trans*:*cis* 比值 {level=2 check="1.41"}
($E$)-与 ($Z$)-丁-2-烯的氢化热之差为 $1.0\ \mathrm{kJ\,mol^{-1}}$。假设 E2 过渡态继承了这一差值，预测 $\mathrm{350\ K}$ 下的 *trans*:*cis* 产物比。（输入比值 $[\textit{trans}]/[\textit{cis}]$。）
::: solution
$e^{1000/(8.314 \times 350)} = e^{0.343} = 1.41$。$1\ \mathrm{kJ\,mol^{-1}}$ 的稳定性差在反应温度下只值 $1.4$ 倍——这就是札依采夫消除仍交付大量 *cis* 异构体的原因，也是产物比不能拿氢化数据表直接照抄的原因。
:::
:::

::: exercise 交叉温度 {level=2 check="375"}
一对竞争的 E2/$\mathrm{S_N2}$ 反应，$\Delta\Delta H^{\ddagger} = +15\ \mathrm{kJ\,mol^{-1}}$，$\Delta\Delta S^{\ddagger} = +40\ \mathrm{J\,mol^{-1}\,K^{-1}}$（消除相对取代）。两条通道等速的温度是多少？（$T$ 以开尔文输入。）
::: solution
$\Delta\Delta G^{\ddagger} = 0$ 当 $T^* = \Delta\Delta H^{\ddagger}/\Delta\Delta S^{\ddagger} = 15\,000/40 = 375\ \mathrm{K}$。其下取代较快，其上消除较快——newton 组件解的正是同一个方程。
:::
:::

::: exercise 室温下的消除份额 {level=2 check="22.5"}
上述那对反应在 $\mathrm{298\ K}$ 下 $k_\mathrm{E2}/k_\mathrm{SN2} = 0.29$。若底物别无通道，有多大百分比变成消除产物？（输入百分比。）
::: solution
分数 $= 0.29/1.29 = 0.225$，即 $22.5\,\%$。当通道平行且不可逆时，速率常数之比*就是*产物比——动力学变成产物分布的标准方式。
:::

::: exercise 由共享碳正离子看 E1 产物比 {level=3}
在一次 E1/$\mathrm{S_N1}$ 溶剂解中，碳正离子 $\mathrm{R^+}$ 被溶剂捕获的速率常数为 $k_\mathrm{N} = 1.2\times10^{7}\ \mathrm{s^{-1}}$，被去质子的速率常数为 $k_\mathrm{E} = 2.0\times10^{7}\ \mathrm{s^{-1}}$（第二步的速率常数；碱即溶剂，故两者对 $\mathrm{R^+}$ 均为一级）。对 $\mathrm{R^+}$ 使用稳态近似，证明产物比 $[\text{烯烃}]/[\text{醚}]$ 等于 $k_\mathrm{E}/k_\mathrm{N}$ 并求值；再证明总速率方程对底物单独为一级。
::: solution
电离速率常数为 $k_1$ 且忽略 $\mathrm{X^-}$ 的回结合，则 $\mathrm{d}[\mathrm{R^+}]/\mathrm{d}t = k_1[\mathrm{RX}] - (k_\mathrm{N} + k_\mathrm{E})[\mathrm{R^+}] \approx 0$，故 $[\mathrm{R^+}] = k_1[\mathrm{RX}]/(k_\mathrm{N} + k_\mathrm{E})$。两产物的生成速率分别为 $k_\mathrm{E}[\mathrm{R^+}]$ 与 $k_\mathrm{N}[\mathrm{R^+}]$——同一个分母在比值中相消：$[\text{烯烃}]/[\text{醚}] = k_\mathrm{E}/k_\mathrm{N} = 2.0/1.2 = 1.7$。底物的总消耗为 $k_1[\mathrm{RX}]$：一级，碱不在速率方程里，尽管碱决定产物比——这是对"E1 中碱只做选择、从不驱动"最锋利的例证。
:::

::: exercise 设计一个烯烃 {level=3}
你需要 (a) 2-甲基丁-2-烯与 (b) 2-甲基丁-1-烯，各作主产物，原料为 2-溴-2-甲基丁烷。为两者各选试剂与温度，对照氢化数据表说明理由，并解释为什么丁-2-烯式的 *cis*/*trans* 论证在这里派不上用场。
::: solution
**(a)** 小体积强碱，热：乙醇钠/乙醇回流。札依采夫规则交付三取代烯烃；它相对二取代异构体约 $1.5\ \mathrm{kJ\,mol^{-1}}$ 的氢化优势，配上能同时触及两个位点的小碱，已经足够。**(b)** 大体积强碱，温和温度：叔丁醇钾/叔丁醇，碱只够得着甲基氢，2-甲基丁-1-烯凭可及性获胜。这套论证无法推进到 $E/Z$ 分辨，因为 2-甲基丁-1-烯带一个 $\mathrm{CH_2}$ 端基（无第二个取代基，无 $E/Z$ 对），2-甲基丁-2-烯同样在一个双键碳上带两个甲基——丁-2-烯的那套几何词汇在这些分子上根本没有指称对象，这提醒我们：只有当双键*两个*碳各带两个不同基团时，$E/Z$ 才存在。
:::
