画一个乙烷分子，你画的是两个由一条线相连的四面体碳；把它平铺在纸面上，你就已经隐含地选定了绕那条线旋转两个 $\mathrm{CH_3}$ 基团所能得到的无穷多种排列中的**一种**。这些排列并不是你画得不好的图——它们是分子每秒钟要造访数亿次的真实结构，而且它们的能量并不全都相等。研究能量如何随单键旋转而变化、环如何约束这种旋转的学问，就是**构象分析**；这是有机化学中三维图像不再只是绘图约定、而开始做算术的第一个地方：它解释了丁烷为什么以那样的方式沸腾，环己烷为什么是椅式，为什么二取代环的一个异构体的丰度能比另一个高上千倍，而且——在你遇到它们很久之前就已注定——解释了为什么消除反应要求对位交叉（*anti*）几何、为什么酶会在意药物分子把环的哪一面递到活性部位。本课从一个思想出发搭建整座大厦：分子采取能让原子彼此舒适地分开的形状，而能量的记账法告诉你那些形状是哪些。

## σ键的旋转与扭转角

::: definition 构象与扭转角 {#def-conformer}
**构象**（构象异构体）是分子的原子之间仅相差绕单（$\sigma$）键旋转而得到的各种排列。**扭转角**（二面角）$\phi$ 是在纽曼投影式中，所选 $\mathrm{C{-}C}$ 键前端碳上的某根键与后端碳上某根键之间的夹角：$\phi = 0^\circ$ 表示两根键相互重叠，$\phi = 60^\circ$ 表示它们交叉式地相隔 $60^\circ$。链上相距更远的两根键之间的**二面角**（例如丁烷两端甲基的 $\mathrm{H{-}C}$ 键之间）按同样方式定义，而且正是机理真正关心的量。
:::

有两种绘图约定能让你在纸面上观察这些旋转。在**纽曼投影式**中，你沿所选 $\mathrm{C{-}C}$ 键正对过去看：前端碳是一个点，后端碳是一个圆，六根取代基是辐条——三根来自圆心，三根来自圆周。在**锯架式**中，你斜着看这根键，它呈现为一条斜线并带着自己的取代基，更接近分子实际的摆放方式，但难以从中读取角度。测量扭转角、比较构象时用纽曼投影式；需要一眼看到整个碳骨架时用锯架式。

由于绕 $\sigma$ 键的旋转是运动而不是反应，构象异构体之间的互变不需要断裂任何东西。乙烷的旋转能垒为 $12.6\ \mathrm{kJ\,mol^{-1}}$（数据表值），在室温（$\mathrm{298\ K}$）下，按 Eyring 型估计 $k \approx (k_\mathrm{B}T/h)\,e^{-\Delta G^{\ddagger}/RT}$，相当于每个分子约 $4\times10^{10}$ 次每秒。这就是为什么你能装一瓶"乙烷"却永远分不出它的各个构象：它们不是可分离的物质，而是一种物质的、被访问得太快而无法分离的状态。

::: definition 扭转张力 {#def-torsional}
**扭转张力**是构象能量中因相邻原子上的键由交叉式被迫变为重叠式而上升的那部分。它的物理起源是相邻 $\sigma$ 键的成键电子对被迫平行时相互排斥、使体系失稳的相互作用，再加上重叠的氢原子本身的拥挤。每个分子都在其能量最高的转动状态上支付扭转张力；乙烷支付 $3 \times 4.2 = 12.6\ \mathrm{kJ\,mol^{-1}}$，即三次各 $4.2\ \mathrm{kJ\,mol^{-1}}$ 的 $\mathrm{H{-}H}$ 重叠相互作用。
:::

::: example 乙烷：能垒买来了什么 {#ex-ethane}
乙烷的旋转能垒位于交叉式极小值之上 $12.6\ \mathrm{kJ\,mol^{-1}}$。假如能垒不是这样而是恰等于热能本身（$\mathrm{298\ K}$ 下 $RT = 2.48\ \mathrm{kJ\,mol^{-1}}$），大约有多大比例的乙烷分子会处于或高于重叠式顶端？这对"分子形状"的概念意味着什么？
::: solution
真实能垒处的玻尔兹曼因子为 $e^{-12600/2478.8} = 6.2\times10^{-3}$：正常条件下，任一瞬时大约只有一百六十个分子中有一个具有越顶的能量，所以分子大部分时间待在交叉式几何附近，"交叉式乙烷"是有意义的说法。若能垒只有 $RT$，因子就是 $e^{-1} = 0.37$——每种几何都与别的几何几乎同样被占据，旋转在所有时间尺度上都是自由的，谈论分子的**那个**形状就毫无意义。几倍于 $RT$ 的能垒的存在，正是构象分析得以成立的前提。
:::
:::

## 丁烷：扭转张力遇上空间张力

::: definition 空间张力（范德华张力） {#def-steric}
**空间张力**是强迫两个未成键原子靠近到小于其范德华半径之和所付出的能量代价——闭合电子壳层重叠时的量子力学排斥。与扭转张力不同，它并不关心重叠本身；它关心的是**距离**。它在无环化学中的原型是**邻位交叉丁烷相互作用**：在邻位交叉丁烷中（两个甲基之间 $\phi = 60^\circ$），两个甲基碳近到足以相互排斥，仅此一项相互作用就值 $3.8\ \mathrm{kJ\,mol^{-1}}$（数据表值）。
:::

丁烷 $\mathrm{CH_3CH_2CH_2CH_3}$，沿中心 $\mathrm{C2{-}C3}$ 键观察，是扭转张力与空间张力相互竞争的最小分子，它的能量曲线 $E(\phi)$ 是此后一切曲线的模板。取对位交叉构象（$\phi = 180^\circ$，两个甲基相对）为零点。旋转到 $\phi = 60^\circ$ 得邻位交叉丁烷，$+3.8\ \mathrm{kJ\,mol^{-1}}$：交叉式，扭转上舒适，但带一个甲基–甲基邻位交叉相互作用。继续转到 $\phi = 120^\circ$：一个重叠式极大，含两次 $\mathrm{CH_3{-}H}$ 重叠和一次 $\mathrm{H{-}H}$ 重叠，$2(5.9) + 4.2 = 16.0\ \mathrm{kJ\,mol^{-1}}$。在 $\phi = 0^\circ$，两个甲基相互重叠：**全重叠式**构象，一次 $\mathrm{CH_3{-}CH_3}$ 重叠加两次 $\mathrm{H{-}H}$ 重叠，$10.6 + 2(4.2) = 19.0\ \mathrm{kJ\,mol^{-1}}$。$\phi = 360^\circ$ 的循环随后经由 $300^\circ$ 处镜像的邻位交叉构象、在 $180^\circ$ 处回到对位交叉而重复。

::: example 丁烷的能量记账 {#ex-butane-profile}
利用上面的相互作用数值（$\mathrm{H{-}H}$ 重叠 $4.2$、$\mathrm{CH_3{-}H}$ 重叠 $5.9$、$\mathrm{CH_3{-}CH_3}$ 重叠 $10.6$、邻位交叉 $\mathrm{CH_3 \cdots CH_3}$ $3.8\ \mathrm{kJ\,mol^{-1}}$），列出丁烷 $E(\phi)$ 在 $0$–$360^\circ$ 内的所有驻点及其能量，并检验极大与极小的数目是否与分子的对称性自洽。
::: solution
极小：$\phi = 180^\circ$ 的对位交叉（$0\ \mathrm{kJ\,mol^{-1}}$），以及 $\phi = 60^\circ$ 与 $300^\circ$ 两个等价的邻位交叉构象（各 $+3.8\ \mathrm{kJ\,mol^{-1}}$）。极大：$\phi = 120^\circ$ 与 $240^\circ$ 两个等价的混合重叠式（$+16.0\ \mathrm{kJ\,mol^{-1}}$），以及 $\phi = 0^\circ$（$=360^\circ$）唯一的**全重叠式**（$+19.0\ \mathrm{kJ\,mol^{-1}}$）。每转一周三个极小、三个极大，两个邻位交叉极小与两个混合重叠极大互为镜像——曲线的*形状*只经由分子的内在对称性在 $180^\circ$ 周期上重复，而 $180^\circ$ 处唯一的深阱正是对位交叉占统治地位的原因。这种分解并不是这些数值的独立证据——它只是检验以乙烷和丁烷本身标定的相互作用数值能否复现丁烷。
:::
:::

::: example 丁烷里有多少邻位交叉构象？ {#ex-gauche-pop}
估算 $\mathrm{298\ K}$ 下处于邻位交叉构象的丁烷分子比例，取对位交叉 $\rightarrow$ 邻位交叉的 $\Delta G^\circ = 3.8\ \mathrm{kJ\,mol^{-1}}$，并忽略重叠式极大（它们是过渡态，不是布居）。
::: solution
每一个对位交叉对应*两个*等价的邻位交叉构象（$\phi = 60^\circ$ 与 $300^\circ$），故邻位交叉分数为
$$
f_{\mathrm{g}} = \frac{2\,e^{-3800/2478.8}}{1 + 2\,e^{-3800/2478.8}} = \frac{2 \times 0.216}{1 + 2 \times 0.216} = 0.30 .
$$
室温下约 $30\,\%$ 的丁烷分子处于邻位交叉——是样品的三分之一，不是痕量——尽管每个邻位交叉构象都比对位交叉差 $3.8\ \mathrm{kJ\,mol^{-1}}$。简并度（因子二）与 $3.8\ \mathrm{kJ\,mol^{-1}}$ 相对 $RT = 2.48\ \mathrm{kJ\,mol^{-1}}$ 的渺小，都朝同一方向使劲。这是统计构象分析的第一课：不利的构象并非不存在，能量决定的是布居，而不是存在。
:::

## 环张力：拜尔的洞见与褶皱的环

::: definition 环张力 {#def-ring-strain}
**环张力**是环状分子相对于具有相同成键组成的无环分子的超额能量，它等于**角张力**（键角被迫偏离其偏好值，$sp^3$ 碳约为 $109.5^\circ$）、**扭转张力**（环无法避免的重叠键）与**空间张力**（跨环及邻位交叉型接触）之和。环烷烃的**张力能**可由量热法直接测定：依据按 $\mathrm{CH_2}$ 基团列表的燃烧热。
:::

1885 年，拜尔（Baeyer）论证说，若环是**平面**正多边形，则环丙烷的内角必为 $60^\circ$、环丁烷为 $90^\circ$——远离 $109.5^\circ$——而环戊烷的 $108^\circ$ 应几乎无张力，环己烷的 $120^\circ$ 反而应变张力重重。燃烧数据可以检验这一预言。长链无张力烷烃中每个 $\mathrm{CH_2}$ 的燃烧热为 $658.6\ \mathrm{kJ\,mol^{-1}}$；任何超额部分即张力，近似均摊到环的各碳上：

| 环 | 每 $\mathrm{CH_2}$ 的 $\Delta_\mathrm{c}H$ / $\mathrm{kJ\,mol^{-1}}$ | 每 $\mathrm{CH_2}$ 张力 / $\mathrm{kJ\,mol^{-1}}$ | 总张力 / $\mathrm{kJ\,mol^{-1}}$ |
|---|---|---|---|
| 环丙烷 | 697.0 | 38.4 | 115 |
| 环丁烷 | 686.1 | 27.5 | 110 |
| 环戊烷 | 663.8 | 5.2 | 26 |
| 环己烷 | 658.6 | 0 | $\approx 0$ |
| 环庚烷 | 662.3 | 3.7 | 26 |
| 环辛烷 | 663.6 | 5.0 | 40 |

::: proposition 由燃烧数据求张力能 {#prop-combustion}
对测得燃烧热为 $\Delta_\mathrm{c}H_\mathrm{m}$ 的环烷烃 $\mathrm{(CH_2)_{\mathit{n}}}$，总张力能为
$$
E_\mathrm{strain} = \Delta_\mathrm{c}H_\mathrm{m} - n \times \left(658.6\ \mathrm{kJ\,mol^{-1}}\right),
$$
以无张力的长链烷烃每 $\mathrm{CH_2}$ 增量为参考。该方法假定每个 $\mathrm{CH_2}$ 在无张力环境中对燃烧热的贡献相同——对链而言极佳，也是本课通篇引用的数据表张力值的来源。
:::

::: example 环丙烷的 115，以及拜尔错在哪里 {#ex-ring-strain}
环丙烷的燃烧热按每 $\mathrm{CH_2}$ 计为 $697.0\ \mathrm{kJ\,mol^{-1}}$。求其总张力能，并把 $\mathrm{C_3}$–$\mathrm{C_8}$ 的张力趋势与拜尔的平面环预言作比较。
::: solution
$E_\mathrm{strain} = 3 \times (697.0 - 658.6) = 3 \times 38.4 = 115\ \mathrm{kJ\,mol^{-1}}$——极其巨大，约相当于一个 $\mathrm{C{-}C}$ 键能的五分之一，也是环丙烷更像烯烃那样加成溴、而不像烷烃那样发生取代的原因。拜尔对小环有张力的判断是对的，但他那张表的结尾错了：他预言环己烷（平面，$120^\circ$）有张力、环戊烷张力最小。数据却恰恰相反——环己烷*无张力*，环戊烷反而带 $26\ \mathrm{kJ\,mol^{-1}}$。毛病出在"平面"二字：五个碳以上的环会**褶皱**出平面，用一点角张力换取扭转张力的消除，直到环己烷找到一种两者皆无的几何——椅式。
:::
:::

## 椅式：环己烷一次性解决所有问题

::: definition 椅式构象，直立键与平伏键 {#def-chair}
环己烷 $\mathrm{C_6H_{12}}$ 的**椅式**构象是这样一种褶皱环：六个 $\mathrm{C{-}C{-}C}$ 角全为 $111.6^\circ$（与 $109.5^\circ$ 相差一度以内），且每根相邻的 $\mathrm{C{-}H}$ 键都是交叉式的——角张力与扭转张力双双为零，与其零张力能自洽。它的十二根 $\mathrm{C{-}H}$ 键分为两类：六根**直立键**，平行于环的三重轴并沿环上下交替；六根**平伏键**，沿环的"赤道"向外张开。每个碳恰好各带一根，且相邻的直立键指向环的相反两面。
:::

用纽曼的眼光读椅式，它的稳定性就变成了算术：沿环上任一根 $\mathrm{C{-}C}$ 键看过去，环己烷处处都是对位交叉——每个 $\mathrm{H{-}C{-}C{-}H}$ 扭转角都是 $\pm 60^\circ$ 或 $180^\circ$，绝不为 $0^\circ$。其他形状为自己的几何付出代价。**船式**构象有两根*重叠式* $\mathrm{C{-}C}$ 键，且"船头""船尾"碳上的两个氢原子隔着环挤在 $0.18\ \mathrm{nm}$ 之内；它比椅式高 $25$–$30\ \mathrm{kJ\,mol^{-1}}$。把船式稍微扭一下即可解除旗杆式拥挤，得到**扭船式**，约高 $21\ \mathrm{kJ\,mol^{-1}}$——它是极小而非极大，也是两个椅式互变所经的中间站。

取代环己烷引出决定性的问题。**直立**取代基沿轴指向环的内部，正面迎上隔着三根键的两个碳上的直立氢——**1,3-二直立键相互作用**，其几何与一个邻位交叉丁烷相互作用完全相同。**平伏**取代基指向外部开阔空间，分文不付。这就是单取代环己烷的全部理论：

::: proposition A值与平伏偏好 {#prop-avalues}
对单取代环己烷 $\mathrm{C_6H_{11}{-}R}$，直立$\rightleftharpoons$平伏平衡的标准自由能 $\Delta G^\circ$ 称为该取代基的**A值**（数据表：$\mathrm{CH_3}$ 为 $7.6$；$\mathrm{CH(CH_3)_2}$ 为 $9.3$；$\mathrm{C(CH_3)_3}$ 为 $23\ \mathrm{kJ\,mol^{-1}}$）。甲基环己烷中的直立甲基形成两次 1,3-二直立 $\mathrm{CH_3 \cdots H}$ 接触，每次等于一个 $3.8\ \mathrm{kJ\,mol^{-1}}$ 的丁烷邻位交叉相互作用：$2 \times 3.8 = 7.6$，恰为甲基的 A值。布居服从玻尔兹曼因子，
$$
\frac{[\mathrm{eq}]}{[\mathrm{ax}]} = e^{-\Delta G^\circ / RT}, \qquad \Delta G^\circ = -RT \ln K .
$$
:::

::: proof 从A值到布居比 {#proof-boltzmann}
$\mathrm{C_6H_{11}R}$ 的两个椅式由一个一级平衡相连，除翻环路径本身外别无势垒，故在温度 $T$ 下它们的数目服从关于自由能差 $\Delta G^\circ = G_\mathrm{ax} - G_\mathrm{eq}$ 的玻尔兹曼分布：
$$
\frac{N_\mathrm{ax}}{N_\mathrm{eq}} = e^{-\left(G_\mathrm{ax} - G_\mathrm{eq}\right)/RT} = e^{-\Delta G^\circ/RT}.
$$
把 $K = [\mathrm{eq}]/[\mathrm{ax}] = N_\mathrm{eq}/N_\mathrm{ax}$ 代入即得 $\Delta G^\circ = -RT \ln K$，即一般的等温式关系特化到一个异构化反应——标准态之所以相消，是因为两者是同一分子的纯构象态。对甲基环己烷，$\mathrm{298\ K}$ 下：$\Delta G^\circ/RT = 7600/2478.8 = 3.07$，故 $K = e^{3.07} = 21.5$。证明中没有一步是甲基特有的：同一个指数能把任何A值换算成任何比例，这正是A值表就是布居表的原因。
:::

::: example 甲基环己烷：21 比 1 {#ex-methylcyclohexane}
甲基环己烷的A值为 $7.6\ \mathrm{kJ\,mol^{-1}}$。计算 $\mathrm{298\ K}$ 下平伏:直立的比值，以及甲基处于平伏位的分子分数。
::: solution
$$
\frac{[\mathrm{eq}]}{[\mathrm{ax}]} = e^{7600/(8.314 \times 298)} = e^{3.07} = 21.5 ,
$$
所以任一瞬时约每 $22$ 个分子中有 $21$ 个——$95.5\,\%$——带平伏甲基，直立椅式只是 $4.5\,\%$ 的少数派。数字 $21.5$ 不是奇闻：它就是 $e^{2 \times 3.8 / RT}$，两个丁烷邻位交叉相互作用的指数化，并且能复现微波与核磁共振谱。还要注意指数如何惩罚体积：异丙基（$9.3$）给出 $42.6$，叔丁基（$23$）给出 $1.07\times10^{4}$——叔丁基在大多数场合就是一把把环锁死在单一椅式上的锁。
:::
:::

:::

::: warning 翻环不断键——而平伏也不是自然法则 {#warn-flip}
两个误区，都值得及早扼杀。**（1）**翻环不是反应：没有键断裂，没有取代基脱落；环经过扭船式，直立变平伏，而"向上"保持"向上"——原来"上-直立"的取代基变成"上-平伏"，所以*cis*/*trans* 关系（构型）在翻环中毫发无损，直立/平伏（构象）则不然。混淆二者会让每一道二取代环的题都无解。**（2）**"平伏更有利"只对*无张力*椅式中的*单个*取代基成立。一个叔丁基（$23\ \mathrm{kJ\,mol^{-1}}$）能把环锁得死死的，以至于第二个较小的基团常常被*迫*直立——而在存在 1,3-二直立烷基–烷基接触的环里，或当杂原子孤对电子偏好直立时（异头效应，那是有机化学二的内容），平伏偏好会缩小甚至反转。A值是数据，不是戒律。
:::

::: quiz
室温下环己烷环每秒翻环约 $10^{5}$ 次（由约 $45\ \mathrm{kJ\,mol^{-1}}$ 的扭船式势垒作 Eyring 估计；核磁共振只有在样品远冷于室温时才能分辨两个椅式）。甲基环己烷的一次翻环完成了什么？
- [ ] 把*cis*异构体变成*trans*异构体，因为甲基换到了环的另一面。
- [x] 把上-直立甲基变成上-平伏甲基：直立/平伏变了，上/下（构型）没变，所以没有生成新化合物。
- [ ] 断裂并重建环上的一根 $\mathrm{C{-}C}$ 键，这就是翻环有活化势垒的原因。
- [ ] 把大部分样品变成邻位交叉构象，因为环经过了船式形状。
::: solution
第二项正确。翻环是构象变化：每个取代基保持自己的面（上的仍向上），同时直立与平伏互换，所以*cis*/*trans* 构型不受触动（第一、三项不成立——没有键断裂，这也正是势垒约 $45\ \mathrm{kJ\,mol^{-1}}$、远低于键能的原因）。第四项的邻位交叉语言属于丁烷的开链旋转，不属于椅式的翻环。
:::
:::

::: history
椅式并非一目了然；它被赢得了两次。1885 年拜尔（Baeyer）把平面环作为其张力理论的地基，讽刺的是，他最成功的预言（环戊烷无张力）恰恰因为"平面"二字而错。1921 年赫尔曼·萨克森（Sachse）提出了褶皱的椅式与船式，但他的论文一直无人问津，直到恩斯特·莫尔（Mohr）于 1922 年将其发表，并附上六甲基苯衍生物的 X 射线证据。哈塞尔（Hassel）在 1936 年用气相电子衍射直接证明了椅式——第一个饱和环的精确结构——而巴顿（Barton）在 1950 年的一对论文中把椅式变成了化学：直立与平伏取代基、1,3-二直立相互作用与A值解释了甾体化学中方方面面的反应性与稳定性，创立了现代**构象分析**。哈塞尔与巴顿共获 1969 年诺贝尔化学奖，"以表彰他们对构象分析思想及其应用的贡献"。
:::

## 翻环与双椅式博弈

翻环把环己烷本身两个等价的椅式互变，但对取代环而言两个椅式*并不*等价——一个把取代基放在直立位，另一个放在平伏位——其自由能差就是A值。翻环很快（甲基环己烷的扭船式势垒约 $45\ \mathrm{kJ\,mol^{-1}}$，所以两个椅式只有在低温核磁共振中才都看得见），但*比例*由热力学定死。于是给任何分子的两个椅式排序就是记账：写出两个椅式，数 1,3-二直立接触，取指数。

::: example 当叔丁基当裁判时，哪个椅式获胜？ {#ex-two-chairs}
考察 *cis*-1-叔丁基-4-甲基环己烷。一个椅式中叔丁基平伏、甲基直立；另一个（翻环之后）叔丁基直立、甲基平伏。哪个占统治地位？差多少？
::: solution
椅式 A 的代价是一个直立甲基：$7.6\ \mathrm{kJ\,mol^{-1}}$。椅式 B 的代价是一个直立叔丁基：$23\ \mathrm{kJ\,mol^{-1}}$。两者相差 $23 - 7.6 = 15.4\ \mathrm{kJ\,mol^{-1}}$，故
$$
\frac{[\mathrm{A}]}{[\mathrm{B}]} = e^{15400/2478.8} = e^{6.21} \approx 500 .
$$
五百比一，偏向甲基直立的那个椅式——分子宁可接受甲基的 1,3-二直立罚单，也不接受叔丁基的，因为叔丁基多出来的两个甲基会把二直立接触成倍放大。这就是构象化学的标准手法：用一个庞大的"锚"取代基冻结环，好从从容容地研究（或利用）第二个基团的位置。
:::
:::

## 二取代环己烷：顺式与反式

有了两个取代基，构型（*cis*/*trans*）与构象（哪个椅式）就成了两层问题，而分析是一张表，不是谜。对 **1,2-**与 **1,4-**二取代环，*trans*（反式）异构体可以做到双平伏（e,e），*cis*（顺式）异构体则被迫取（ax,eq）；对 **1,3-**二取代环角色互换——*cis*-1,3 是（e,e），*trans*-1,3 是（ax,ax）。（e,e）椅式翻环得（ax,ax）椅式，对两个甲基高 $2 \times 7.6 = 15.2\ \mathrm{kJ\,mol^{-1}}$；（ax,eq）椅式翻环得（eq,ax）椅式，对相同基团而言两者简并。

::: example 给二甲基环己烷的椅式排序 {#ex-dimethyl}
对 *trans*-1,2-、*cis*-1,3-与 *cis*-1,4-二甲基环己烷，各用（ax,eq）记号写出两个椅式，给出两者间的张力差，并说出 1,4-异构体对中哪个更稳定。
::: solution
*trans*-1,2：（e,e）$\rightleftharpoons$（ax,ax），差 $15.2\ \mathrm{kJ\,mol^{-1}}$，压倒性地是（e,e）。*cis*-1,3：（e,e）$\rightleftharpoons$（ax,ax），又是 $15.2\ \mathrm{kJ\,mol^{-1}}$——1,3-对中*舒适*的是顺式异构体。*cis*-1,4：（ax,eq）$\rightleftharpoons$（eq,ax），简并，平均张力 $7.6\ \mathrm{kJ\,mol^{-1}}$；*trans*-1,4：（e,e）$\rightleftharpoons$（ax,ax），最佳椅式张力 $0$。所以 *trans*-1,4 比 *cis*-1,4 稳定 $7.6\ \mathrm{kJ\,mol^{-1}}$（两种构型各自最佳椅式之比 $e^{7600/2478.8} = 21.5$），*cis*-1,3 比 *trans*-1,3 稳定 $15.2\ \mathrm{kJ\,mol^{-1}}$——因子 $460$。应当内化的模式是：1,3-*顺式*与 1,2/1,4-*反式*是"可双平伏"的关系；翻环永远改变不了一个分子属于哪一类。
:::
:::

## 中环与椅式的极限

七到十三元的环——**中环**——可以褶皱，却无法摆脱一切：环内部面对面的氢–氢跨环接触重新引入空间张力，而这个尺寸范围内的*反式*双键或*反式并环*张力严重。环庚烷（$26\ \mathrm{kJ\,mol^{-1}}$）褶皱成扭椅式，使扭转张力保持低位；环辛烷（$40\ \mathrm{kJ\,mol^{-1}}$）更糟，因为它的冠式理想形状完全处于*重叠式*，于是改取船–船（"槽"）形；它的构象行为——若干能量相近的形式相互转化——预告了甾体、糖与折叠低聚物的构象化学。大约十二个碳以上，环已经大到本质上是两端接起来的无张力链：张力表触底，椅式的教训原样沿用。

## 后续内容

构象分析是后面三章底下的机器。翻环之后什么被保留——构型固定、构象流动——这套计数是通往 [[organic-1/stereochemistry]] 的门口，在那里 *cis*/*trans* 与 *R*/*S* 成为核心通货。轨道必须沿断裂的键对齐这一要求，最初在本课中以对位交叉扭转的偏好露面，随后作为消除反应的立体电子要求归来——E2 反应要求 $\mathrm{H}$ 与离去基团处于反叠（*anti*-periplanar），这其实是一道伪装成反应的椅式题（[[organic-1/elimination]]）。1,3-二直立相互作用在碳正离子与自由基的稳定性中再次作为空间项出现（[[organic-1/radical-reactions]]），A值本身则在取代基效应的定量比较中归来（[[organic-1/nucleophilic-substitution]]）。通篇假定的键能与杂化思想见 [[bonding-structure/valence-bond]]，而邻位交叉布居里那个因子二，与 [[kinetics/collision-theory]] 中的玻尔兹曼记账是同一套。

::: summary
- 构象之间只差绕 $\sigma$ 键的旋转，互变不断键；扭转角 $\phi$ 在纽曼投影式中度量这一旋转。
- 扭转张力（重叠，每次 $\mathrm{H{-}H}$ 重叠 $4.2\ \mathrm{kJ\,mol^{-1}}$）与空间张力（原子近于范德华半径之和，每个丁烷邻位交叉相互作用 $3.8\ \mathrm{kJ\,mol^{-1}}$）是两种不同的能量，可以相加。
- 丁烷的能量曲线：对位交叉 $0$、邻位交叉 $3.8$、重叠式 $16.0$、全重叠式 $19.0\ \mathrm{kJ\,mol^{-1}}$；因存在两个简并极小，$298\ \mathrm{K}$ 下约 $30\,\%$ 的分子处于邻位交叉。
- 环张力 = 角张力 + 扭转张力 + 空间张力，由燃烧热测定：环丙烷 $115$、环丁烷 $110$、环戊烷 $26$、环己烷 $\approx 0\ \mathrm{kJ\,mol^{-1}}$；五个原子以上的环会褶皱，击败了拜尔的平面模型。
- 椅式的角张力与扭转张力均为零；取代基直立时每一次 1,3-二直立接触付出 $2 \times 3.8\ \mathrm{kJ\,mol^{-1}}$，恰为甲基的A值。
- 布居服从 $[\mathrm{eq}]/[\mathrm{ax}] = e^{-\Delta G^\circ/RT}$：$298\ \mathrm{K}$ 下甲基 $21.5$、异丙基 $42.6$、叔丁基 $1.07\times10^{4}$ 比 1。
- 翻环使直立 $\rightleftharpoons$ 平伏互换，但保持上/下不变，所以构型在翻环中幸存；二甲基环己烷的顺反排序就是一张（e,e）、（ax,eq）、（ax,ax）的记账表。
:::

## 练习

::: exercise 直立键与平伏键的记账 {level=1 check="6"}
环己烷的一个椅式构象带有几根直立氢原子？（输入数字。）
::: solution
六根。六个碳各带一根直立 $\mathrm{C{-}H}$ 和一根平伏 $\mathrm{C{-}H}$，且相邻的直立键沿环上下交替。
:::
:::

::: exercise 由A值到比例 {level=1 check="42.6"}
异丙基环己烷的A值为 $9.3\ \mathrm{kJ\,mol^{-1}}$。计算 $\mathrm{298\ K}$ 下平伏:直立的布居比。（以数字输入比值。）
::: solution
$[\mathrm{eq}]/[\mathrm{ax}] = e^{9300/(8.314 \times 298)} = e^{3.75} = 42.6$。异丙基在布居上的要求是甲基的两倍，能量上却只差 $1.7\ \mathrm{kJ\,mol^{-1}}$——指数放大小差异。
:::
:::

::: exercise 由燃烧热求张力能 {level=1 check="115.2"}
环丙烷的燃烧热按每 $\mathrm{CH_2}$ 计为 $697.0\ \mathrm{kJ\,mol^{-1}}$，而无张力链 $\mathrm{CH_2}$ 为 $658.6\ \mathrm{kJ\,mol^{-1}}$。求环丙烷的总张力能。（以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
$(697.0 - 658.6) \times 3 = 38.4 \times 3 = 115.2\ \mathrm{kJ\,mol^{-1}}$。三个碳均分张力只是因为三个位置全同；在取代的小环中张力并不分得这样均匀。
:::
:::

::: exercise 叔丁基锚 {level=2 check="10700"}
取A值 $23\ \mathrm{kJ\,mol^{-1}}$，计算 $\mathrm{298\ K}$ 下叔丁基环己烷两个椅式（平伏叔丁基 : 直立叔丁基）的平衡比。（以数字输入比值。）
::: solution
$e^{23000/2478.8} = e^{9.28} = 1.07\times10^{4}$，约 $10\,700$ 比 $1$。布居比到了这个量级，直立叔丁基椅式实际上不可观测，这正是叔丁基被用作构象锚的原因。
:::
:::

::: exercise 是构型，不是构象 {level=2 check="460"}
*cis*-1,3-二甲基环己烷的最佳椅式张力为 $0$（e,e）；*trans*-1,3-二甲基环己烷的最佳椅式张力为 $15.2\ \mathrm{kJ\,mol^{-1}}$（ax,ax）。计算 $\mathrm{298\ K}$ 下异构化 *trans* $\rightarrow$ *cis* 的平衡常数。（以数字输入 $K = [\textit{cis}]/[\textit{trans}]$。）
::: solution
$K = e^{15200/2478.8} = e^{6.13} = 460$。注意这是什么、不是什么：这是两个*构型*之间的平衡（互变它们需要断键），却完全由构象张力能算出。翻环改变椅式，但永远不改变答案。
:::
:::

::: exercise 加热构象平衡 {level=2 check="416"}
甲基环己烷（A值 $7.6\ \mathrm{kJ\,mol^{-1}}$，视为与温度无关）在什么温度下平伏分数恰为 $90\,\%$？（以开尔文输入 $T$。）
::: solution
$90\,\%$ 平伏即 $[\mathrm{eq}]/[\mathrm{ax}] = 9$，故 $7600 = RT \ln 9$，$T = 7600/(8.314 \times 2.197) = 416\ \mathrm{K}$。即使在 $143\ \mathrm{^\circ C}$，直立型也只有 $10\,\%$——构象偏好对热度是出了名的顽固。
:::
:::

::: exercise 简并度因子 {level=3}
由玻尔兹曼分布导出丁烷的邻位交叉分数 $f_{\mathrm{g}} = 2e^{-\Delta G/RT}/(1 + 2e^{-\Delta G/RT})$，解释每一个因子，并用 $\Delta G = 3.8\ \mathrm{kJ\,mol^{-1}}$ 计算 $\mathrm{298\ K}$ 与 $\mathrm{500\ K}$ 的值。为什么 $f_{\mathrm{g}}$ 随温度升高趋向 $2/3$ 而不是 $1/2$？
::: solution
对极小构象的配分和为 $Z = 1 + 2e^{-\Delta G/RT}$：一个能量为 $0$ 的对位交叉态，加*两个*能量为 $\Delta G$ 的简并邻位交叉态（$\phi = 60^\circ$ 与 $300^\circ$ 的镜像）。邻位交叉分数即两个邻位交叉玻尔兹曼权重之和除以 $Z$，得所给公式。$\mathrm{298\ K}$：$2(0.216)/(1+0.432) = 0.30$；$\mathrm{500\ K}$：$2e^{-3800/4157}/(1+2e^{-3800/4157}) = 2(0.400)/1.800 = 0.44$。当 $T \rightarrow \infty$，每个指数都趋于 $1$，布居变成纯粹数数：$f_{\mathrm{g}} \rightarrow 2/3$，因为三个极小里有*两个*是邻位交叉。低温下能量决定胜负；高温下简并度决定胜负——同一场竞争贯穿整个统计热力学。
:::
:::

::: exercise 从键角看为什么是椅式 {level=3}
正平面 $n$ 边形的内角为 $(n-2)\times 180^\circ/n$。计算 $n = 3, 4, 5, 6$ 的值及其与 $109.5^\circ$ 的偏差，并用结果解释：为什么拜尔的平面模型预言环己烷有张力，而实测张力能为零。关于椅式的哪两个几何事实化解了这个悖论？
::: solution
平面内角：$60^\circ$（$n=3$，偏差 $49.5^\circ$）、$90^\circ$（$n=4$，$19.5^\circ$）、$108^\circ$（$n=5$，$1.5^\circ$）、$120^\circ$（$n=6$，$10.5^\circ$）。按拜尔的逻辑——张力随角偏差增大——环的排序应为 $3 > 6 > 4 > 5$，即环己烷有张力、环戊烷近乎完美。实测顺序是 $3 > 4 > 5 \approx 7 > 8 \gg 6$。化解之道：只有 $\mathrm{C_3}$（以及大致上的 $\mathrm{C_4}$）被禁锢在自己的平面内，因为三点（或四点）确定一个平面；更大的环会褶皱。于是椅式具有（i）$111.6^\circ$ 的 $\mathrm{C{-}C{-}C}$ 角，与四面体角相差 $2^\circ$ 以内，消灭角张力；（ii）环上每个扭转角都是交叉式，消灭扭转张力——而平面环己烷将同时拥有 $120^\circ$ 角和六根*重叠式* $\mathrm{C{-}H}$ 键。零张力不是运气；它是同时满足两个条件的唯一几何，这就是六元环统治饱和环化学的原因。
:::
