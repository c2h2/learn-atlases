你在 [[organic-1/elimination]] 中构建的每一根双键，都是一份储存在那里的活性电子密度，而本章讲的就是如何把这份储存花出去。$\mathrm{C{=}C}$ 的两根键并不平等：$\sigma$ 骨架把分子维系在一起，而 $\pi$ 键——核轴上下的一团弥散电子云——暴露在外、易极化而且脆弱，约 $266\ \mathrm{kJ\,mol^{-1}}$，而 $\sigma$ 键是 $348$（[[organic-1/organic-structures]]）。化学就从这个不平等中涌出。烷烃只能拿出紧密结合的 $\mathrm{C{-}H}$ 和 $\mathrm{C{-}C}$ $\sigma$ 键，在暗处、室温下什么也不做；烯烃却把它那对束缚松散的电对递给任何缺电子的东西，而随之而来的反应——**亲电加成**——正是这个官能团的标志性反应。我们的计划是先把一个机理学深（质子化生成碳正离子，再由负离子捕获），然后看着它分岔：马尔科夫尼科夫规则及其在碳正离子稳定性中的物理基础；暴露出碳正离子真实存在的重排；三条给出三种不同答案的水合路线；迫使 *anti* 加成的溴鎓离子；氢化与那条用 $\mathrm{kJ\,mol^{-1}}$ 度量烯烃稳定性的氢化热阶梯；羟基化、断裂与环氧化三条氧化路线；最后是炔烃——同样的化学在这里发生两次，而端基 $\mathrm{C{-}H}$ 又添上一笔酸性插曲（[[organic-1/acidity-mechanism]]）。一个机理，众多推论——这就是本章的形状。

## 双键作为亲核试剂

::: definition 亲电加成 {#def-electrophilic-addition}
**亲电加成**是 $\pi$ 键把自己的电子对交给一个**亲电试剂**、原来双键的两个碳各与一个新取代基成键的反应：
$$
\mathrm{C{=}C + E{-}Nu \rightarrow E{-}C{-}C{-}Nu}
$$
$\pi$ 键是**亲核试剂**（路易斯碱，献出电子对的一方）；$\mathrm{E{-}Nu}$ 是亲电试剂，它的键在两根新 $\sigma$ 键形成的同时断裂。原型反应取 $\mathrm{E = H}$、$\mathrm{Nu}$ 为卤素负离子，但同一模式涵盖水合、卤化、氢化与氧化。
:::

加成究竟为什么会发生，其算术就是 [[organic-1/organic-structures]] 里做过的算术：把 $\mathrm{HBr}$ 加到 $\mathrm{C{=}C}$ 上，断一根 $\pi$ 键（$266\ \mathrm{kJ\,mol^{-1}}$）和一根 $\mathrm{H{-}Br}$ 键（$366$），成一根 $\mathrm{C{-}H}$（$413$）和一根 $\mathrm{C{-}Br}$（$285$），故 $\Delta H \approx (266 + 366) - (413 + 285) = -66\ \mathrm{kJ\,mol^{-1}}$。一根弱 $\pi$ 键加一根试剂 $\sigma$ 键，换回两根更强的 $\sigma$ 键——本章几乎每一个加成放热，原因恰在于此。取代没有同等的入场券：裸烯烃不带离去基团，而乙烯基 $\mathrm{C{-}H}$ 太强（$\approx 460\ \mathrm{kJ\,mol^{-1}}$），不可能自行断开。加成就是双键的作为。

在 [[organic-1/acidity-mechanism]] 的弯箭头语法里，原型反应分两步走。**第 1 步：**$\pi$ 电子进攻 $\mathrm{HBr}$ 的质子；$\mathrm{H{-}Br}$ 键断裂，溴离子离去。一个碳得到氢，另一个碳被留下成为缺电子的——一个**碳正离子**。**第 2 步：**溴离子的一只孤对电子落进碳正离子的空 $p$ 轨道，卤代烷就此诞生。第 1 步是**决速步**：它毁掉一根被稳定的 $\pi$ 键、制造出一个高能碳正离子，所以吸能而缓慢；第 2 步则是快速的正负离子结合。这个形状你见过——第 1 步就是 [[organic-1/nucleophilic-substitution]] 里的电离，那里关于碳正离子的一切在这里同样成立。

::: example HBr 加丙烯：机理与热化学 {#ex-hbr-propene}
写出 $\mathrm{HBr + CH_3CH{=}CH_2}$ 的机理，并用平均键焓（$\pi$：$266$；$\mathrm{H{-}Br}$：$366$；$\mathrm{C{-}H}$：$413$；$\mathrm{C{-}Br}$：$285\ \mathrm{kJ\,mol^{-1}}$）估算 $\Delta H$。哪个构造异构体占主导？
::: solution
第 1 步：*$\pi$ 键进攻 $\mathrm{HBr}$ 的质子；$\mathrm{H{-}Br}$ 键断裂为溴离子。*质子化有两种走法：氢加到中间碳上给出伯碳正离子 $\mathrm{CH_3CH_2CH_2^{+}}$；氢加到端碳上给出仲碳正离子 $\mathrm{CH_3CH^{+}CH_3}$。第 2 步：*溴离子进攻带正电的碳。*仲碳正离子路径压倒性胜出（原因马上见），所以产物是 2-溴丙烷 $\mathrm{CH_3CHBrCH_3}$，只有痕量 1-溴丙烷。热化学：断键 $266 + 366 = 632$；成键 $413 + 285 = 698$；$\Delta H \approx 632 - 698 = -66\ \mathrm{kJ\,mol^{-1}}$——放热，与 $\pi$ 换 $\sigma$ 这笔交易的许诺完全一致。
:::
:::

::: proposition 马尔科夫尼科夫规则（马氏规则） {#prop-markovnikov}
**马尔科夫尼科夫规则（马氏规则）**（经验规则，1869）：当试剂 $\mathrm{H{-}X}$ 加到不对称烯烃上时，氢加到双键两个碳中**已带有较多氢**的那个——取代较少的碳——而 $\mathrm{X}$ 加到取代较多的碳。其物理基础根本不是关于氢的定律，而是关于**碳正离子稳定性**的事实：质子化经由较稳定的碳正离子进行，而较稳定的碳正离子生成得较快。碳正离子稳定性次序为 $\mathrm{R_3C^{+}} > \mathrm{R_2CH^{+}} > \mathrm{RCH_2^{+}} \gg \mathrm{CH_3^{+}}$，因为烷基通过诱导效应和超共轭——相邻 $\mathrm{C{-}H}$ $\sigma$ 电子对向空 $p$ 轨道的给电子——稳定缺电子的碳。这条规则是关于单一机理的经验概括：机理一变（自由基加成，[[organic-1/radical-reactions]]），或中间体发生重排（[[#def-rearrangement]]），它就失效。
:::

为什么较稳定的碳正离子生成得更快？哈蒙德（Hammond）假说（[[organic-1/acidity-mechanism]]）回答：第 1 步强烈吸能，所以它的过渡态是**晚**的——在能量上、因而也在结构上，都接近它所生成的碳正离子。凡能稳定碳正离子的因素，几乎等额地稳定通往它的过渡态，于是经过仲碳正离子的路径势垒更低而占主导。这里的区域选择性是**动力学控制**的问题：产物比由过渡态能量差 $\Delta\Delta G^{\ddagger}$ 决定，而不由产物稳定性决定。玻尔兹曼因子把两者互相换算——在 $\mathrm{298\ K}$ 下，
$$
\frac{[\text{主}]}{[\text{次}]} \;=\; e^{\,\Delta\Delta G^{\ddagger}/RT},
$$
所以势垒只差 $7.3\ \mathrm{kJ\,mol^{-1}}$——不到一个 $\mathrm{p}K_\mathrm{a}$ 单位的自由能——就已给出 $19:1$ 的混合物，即 $95\,\%$ 的一种异构体。区域选择性在能量上是廉价的。

::: warning 马氏规则真正说的是什么 {#warn-markovnikov}
三个误解，个个昂贵。**（1）**"规则说的是氢加到哪里。"规则只是助记；机理是"质子化，以便生成较稳定的碳正离子。"说出机理，规则自然成立——例外也一并成立。**（2）**"碳正离子会安分守己。"它们不会：只要升级有利，碳正离子就会从相邻碳上拉来一个氢负离子或一个烷基——**1,2-迁移**——于是按规则死套预测的产物可能是错的产物；见 [[#def-rearrangement]] 与随后的例题。如果你的机理把一个仲碳正离子画在叔碳或季碳旁边，就预期重排。**（3）**"反马氏加成就是把马氏规则倒过来用。"你不能靠把箭头反过来就颠倒区域选择性：同样的离子机理永远汇入较稳定的那个碳正离子。反马氏产物要求一个*不同的机理*——自由基链（HBr 加过氧化物，[[organic-1/radical-reactions]]），或根本不存在碳正离子的硼介导路径——在其中决定新键位置的，是碳正离子稳定性以外的东西。
:::

## 碳正离子会重排

::: definition 1,2-迁移与重排 {#def-rearrangement}
碳正离子的**重排**，是一根 $\sigma$ 键带着它的电子对从相邻碳迁移进空 $p$ 轨道，于是正电荷移到失去这根键的碳上。迁移基团——氢（**1,2-氢负离子迁移**）或烷基（**1,2-甲基迁移**，等等）——带着成键电子对移动，所以电荷守恒，原子一个不少。推动力是稳定性阶梯 $\mathrm{3^\circ > 2^\circ \gg 1^\circ}$：升级碳正离子的迁移很快，降级它的迁移不会发生。只有*相邻*（1,2）迁移来得及竞争，因为迁移基团必须够得着隔壁的空轨道。
:::

重排不是碳正离子机理的丑闻——它是它最好的证据。一个会从自己邻居手里抢氢以变得更稳定的物种，是一个真实存在的物种；任何单一马氏规则都预测不了的产物混合，正是中间体自作主张的指纹。要提防的两种迁移是同一次升级的两套戏服：邻居上有氢就氢负离子迁移，没有就烷基迁移。

::: example 氢负离子迁移：3-甲基丁-1-烯加 HCl {#ex-rearrange-hydride}
$\mathrm{(CH_3)_2CHCH{=}CH_2 + HCl}$ 主要给出 2-氯-2-甲基丁烷，而不是 2-氯-3-甲基丁烷。用机理解释。
::: solution
C1 质子化（取代较少的碳拿氢，马氏规则）把电荷放到 C2：仲碳正离子 $\mathrm{CH_3CH^{+}CH(CH_3)_2}$。这个碳正离子坐在一个带氢的叔碳旁边，于是**1,2-氢负离子迁移**随即发生：C3 上的氢带着成键电子迁到 C2，电荷移到 C3，此时它三配位而呈叔性，$\mathrm{CH_3CH_2C^{+}(CH_3)_2}$——一次 $2^\circ \rightarrow 3^\circ$ 的升级。氯离子在 C3 结合，给出 2-氯-2-甲基丁烷。未重排的马氏氯化物是次要产物：规则对质子化说对了，对第二幕却保持沉默。
:::
:::

::: example 甲基迁移：3,3-二甲基丁-1-烯加 HBr {#ex-rearrange-methyl}
$\mathrm{(CH_3)_3CCH{=}CH_2 + HBr}$ 主要给出 2-溴-2,3-二甲基丁烷。重排从何而来？
::: solution
马氏质子化把 $\mathrm{H}$ 放到 C1、电荷放到 C2——一个坐在**季**碳旁边的仲碳正离子，对未重排的碳正离子来说这是最糟的邻居，因为邻居上没有可供迁移的氢。于是一个**甲基**带着成键电子对从 C3 迁到 C2；电荷移到 C3，C3 变成叔的：$\mathrm{(CH_3)_2C^{+}CH(CH_3)_2}$，即 2,3-二甲基丁-2-基正离子。溴离子结合给出 2-溴-2,3-二甲基丁烷。按规则死套预测的是 2-溴-3,3-二甲基丁烷，那要求分子守着一个挨着季碳的仲碳正离子——分子拒绝在这种处境里停留。
:::
:::

::: algorithm 预测亲电加成产物 {#alg-addition-products}
**（1）**找到 $\pi$ 键，把试剂拆成亲电端和亲核端（$\mathrm{H}$ 然后 $\mathrm{X}$；$\mathrm{Br}$ 然后 $\mathrm{Br}$；$\mathrm{B}$ 然后 $\mathrm{OH}$）。**（2）**把亲电试剂加到使另一碳留下**较稳定碳正离子**的那个烯烃碳上——这一条指令*就是*马氏规则。对协同加成（硼氢化、氢化、经卤鎓离子的卤化），带着反应自己的规则直接跳到第 4 步。**（3）**检查碳正离子是否会**重排**：若一次 1,2-氢负离子或 1,2-烷基迁移能升级它（$2^\circ \rightarrow 3^\circ$，或越过张力环），就取重排后的碳正离子。**（4）**让亲核试剂与带正电的碳结合；平面碳正离子两面都可被进攻。**（5）**套用该反应的**立体化学**——*syn*、*anti* 或不受限（下表汇总）。**（6）**核对账目：加成把整个试剂并入产物，所以产物分子式是烯烃加试剂；并且从结构、而不是从规则出发命名产物。
:::

## 水合：由烯烃制醇

**酸催化水合**是以水为亲核试剂的原型反应。用文字说：$\pi$ 键质子化生成马氏碳正离子；一个水分子进攻碳正离子；第二个水分子夺走多余的质子，催化剂再生。把步骤倒过来读，你就得到 [[organic-1/elimination]] 的 E1 消除——水合*就是*酸催化消除的微观逆反应，所以反应是一个平衡，按勒夏特列原理，稀酸有利于醇，浓酸加热则把消除推回来。碳正离子机理的一切性质都在：马氏区域选择性，以及只要迁移能升级中间体就发生的重排。

**羟汞化–脱汞**存在的意义，是不用碳正离子也拿到同样的马氏醇。概念上：烯烃进攻的不是质子而是汞(II)羧酸盐，金属以桥连方式同时键合两个碳，形成环状**汞鎓离子**——桥连中间体，没有游离碳正离子，重排无从发生；水进攻取代较多的碳（桥在那一端更松、正电荷发展得更充分），随后第二个试剂把碳汞键换成碳氢键。净结果：马氏加水，不重排。代价是汞盐本身——对水生生物剧毒，只能作为待收集的废物处理，绝不可倒入下水道。

**硼氢化–氧化**通过彻底拒绝碳正离子来解决相反的问题——反马氏水合。乙硼烷或硼烷 $\mathrm{BH_3}$（易燃气体，以密封溶液供应；硼上带空轨道的路易斯酸）以单步**协同**方式加过双键：硼和氢从同一面到达（*syn*），经过一个紧凑的四中心过渡态。硼到**取代较少**的碳，有两个互相加强的理由——那里位阻小，而且在过渡态上取代较多的碳承担部分正电荷，它稳定这种电荷的本事更强。没有碳正离子就没有重排。随后碱性的过氧化氢把 $\mathrm{C{-}B}$ 键换成 $\mathrm{C{-}OH}$ 键，并保持碳的构型。净结果：**反马氏、*syn* 水合**。

::: example 一个烯烃，两种醇 {#ex-hydroboration}
1-甲基环己烯既可转化为 1-甲基环己-1-醇，也可转化为 *trans*-2-甲基环己-1-醇。给出两套条件，并解释各自的区域化学与立体化学。
::: solution
**1-甲基环己-1-醇：**稀酸水溶液。C2 质子化在 C1 生成叔碳正离子——马氏规则，而且叔碳正离子无需重排；水进攻，失去一个质子得叔醇。产物碳带着两条相同的环臂，不是立体中心，无需指明立体化学。
***trans*-2-甲基环己-1-醇：**$\mathrm{BH_3}$，然后 $\mathrm{H_2O_2,\ HO^-}$。硼加到位阻较小的 C2，氢加到 C1，两者同面（*syn*）；氧化以构型保持把 B 换成 OH，于是 OH 与 C1 上新生的氢呈 *cis*——这使 OH 与 C1 上的甲基呈 *trans*。反马氏区域化学、*syn* 加成、不重排：硼路径的三个签名，尽在一个产物之中。
:::
:::

## 卤素加成：溴鎓离子

氯和溴直接加过双键，而现象正是 [[organic-1/organic-structures]] 已经记录过的那个：溴的棕色在暗处褪去——这是实验台上检验不饱和度的试验。（溴是挥发性的、腐蚀性的催泪液体，它的蒸气由通风橱负责关住——一个在这里读一读、在实验室里要敬畏的危险。）朴素的离子机理——卤素作亲电试剂、游离碳正离子、卤离子捕获——会预言 *syn* 与 *anti* 加成大致等量，并在碳正离子能升级时发生重排。两者都没有被观察到。加成干净地是**反式**的，而且重排从不出现。

::: proposition 卤鎓离子机理 {#prop-halonium}
$\mathrm{Br_2}$ 或 $\mathrm{Cl_2}$ 对烯烃的加成经由**环状卤鎓离子**：$\pi$ 键进攻 $\mathrm{Br{-}Br}$ 的一个卤素，赶出卤离子，而这同一个卤素用自己的孤对电子向*两个*碳闭合成三元环。桥连离子没有游离碳正离子，所以**（i）**重排不可能发生，**（ii）**卤离子只能从桥的对面进攻——**反式加成**。在不对称烯烃中，取代较多的碳承担较多正电荷（桥在那一端更松），这就是外部亲核试剂优先在取代较多的碳开环的原因。
:::

::: example 溴化的立体化学：丁-2-烯 {#ex-bromination-stereo}
预测 $\mathrm{Br_2}$ 对 (a) (*E*)-丁-2-烯和 (b) (*Z*)-丁-2-烯加成的产物。
::: solution
对对称烯烃的反式加成在每个碳上放一个溴，分居两面。**(a)** 从 *E* 异构体出发，反式加成给出 $(2R,3S)$-2,3-二溴丁烷——**内消旋**化合物，它的两半互为镜像（[[organic-1/stereochemistry]]）。**(b)** 从 *Z* 异构体出发，反式加成给出 $(2R,3R)$ 与 $(2S,3S)$ 一对——外消旋体。烯烃的两个几何异构体给出非对映异构不同的产物：这就是*立体专一*的含义，也正是桥连离子所要求的。一个游离的平面碳正离子会把两种结果旋转搅混在一起。
:::
:::

在**水**里而不是惰性溶剂中进行同一反应，开卤鎓环的亲核试剂就是水而不是卤离子——水是溶剂，凭绝对人数取胜。水进攻桥中取代较多的碳，去质子化随后发生，产物是**卤代醇**：$\mathrm{X}$ 和 $\mathrm{OH}$ 在相邻碳上，*反式*加成，$\mathrm{OH}$ 在取代较多的碳上。这个结果看起来像马氏规则，但它由桥连离子的电子效应强制，而不是由游离碳正离子决定。卤代醇也是通往 [[organic-1/alcohols-ethers]] 中环氧化物的引道。

::: history
弗拉基米尔·马尔科夫尼科夫（Markovnikov）在 1869 年陈述了他的规则，出自喀山一项对当时流行的戊烯（amylene）混合物加碘化氢的研究；他承袭的是札依采夫（Zaytsev）的传统，而本章正是札依采夫消除规则的镜像。加成为什么如此干净——反式、不重排——要等到 1930 年代的机理纲领：罗宾逊（Robinson）与英戈尔德（Ingold）（正是 [[organic-1/nucleophilic-substitution]] 背后取代动力学的那位英戈尔德）学会了把立体化学当作证据来读，确立了桥连卤鎓离子，使反式加成与不重排同时得到解释。本世纪另一个伟大的加成属于赫伯特·布朗（Brown）：硼氢化，自 1950 年代起、由他追寻数十年的硼烷化学发展而来，交付了机理中没有任何碳正离子的反马氏醇，并为他——与格奥尔格·维蒂希（Wittig）分享——赢得 1979 年诺贝尔化学奖。
:::

## 氢化与稳定性阶梯

氢在钯、铂或镍的表面上加过双键。两个氢原子都从金属表面递送，因此加到同一面：催化氢化是 ***syn*** 加成。反应是多相的——烯烃和氢吸附、反应、脱附——而且强放热。危险属于试剂本身而非机理：氢极度易燃，细金属粉末催化剂干涸时可能自燃。

::: proposition 氢化热阶梯 {#prop-stability-ladder}
氢化热（标准数据表值，$\mathrm{kJ\,mol^{-1}}$，均为放热）：乙烯 $-137$；丙烯 $-125$，丁-1-烯 $-127$；*cis*-丁-2-烯 $-120$，*trans*-丁-2-烯 $-116$；2-甲基丙烯 $-119$；2-甲基丁-2-烯 $-113$。由于异构烯烃氢化到同一个烷烃，它们的氢化热度量的就是彼此的相对能量：**双键烷基取代越多，烯烃越稳定**；而在二取代一类中，*E* 异构体比 *Z* 更稳定（此处差 $4\ \mathrm{kJ\,mol^{-1}}$）。能量阶梯为四取代 $<$ 三取代 $<$ 二取代 $<$ 一取代 $<$ 乙烯——每个烷基约 $8$–$10\ \mathrm{kJ\,mol^{-1}}$ 的稳定性，与稳定碳正离子的是同一种超共轭给电子。
:::

::: example 用盖斯定律求异构体能量 {#ex-hydrogenation-hess}
利用 [[#prop-stability-ladder]] 的数据求 (a) *cis*-丁-2-烯 $\rightarrow$ *trans*-丁-2-烯的 $\Delta H$；(b) 用平均键焓（$\pi$：$266$；$\mathrm{H{-}H}$：$436$；$\mathrm{C{-}H}$：$413\ \mathrm{kJ\,mol^{-1}}$）估算 *trans*-丁-2-烯的氢化热并与实测比较。
::: solution
**(a)** 两个异构体都氢化成丁烷，所以盖斯定律允许我们把热化学方程相减：*cis* $\rightarrow$ *trans* 异构化的 $\Delta H = (-120) - (-116) = -4\ \mathrm{kJ\,mol^{-1}}$。*trans* 异构体位于低 $4\ \mathrm{kJ\,mol^{-1}}$ 处——两个甲基离得更远，而氢化热就是说出这一点的天平。**(b)** 氢化断开 $\pi$ 键和 $\mathrm{H{-}H}$ 键（$266 + 436 = 702$），生成两根 $\mathrm{C{-}H}$ 键（$2 \times 413 = 826$）：$\Delta H \approx -124\ \mathrm{kJ\,mol^{-1}}$，对照实测的 $-116$。平均键焓落在预期的百分之几之内，而且照例略微高估了一个被稳定的烯烃的放热量。
:::
:::

## 氧化：邻二醇、断裂与环氧化

冷的稀碱**高锰酸钾**把两个羟基加过双键，加在同一面——***syn* 双羟基化**生成邻二醇——紫色褪为棕色的二氧化锰，即检验的视觉信号。化学本质是一步生成的环状锰酸酯（所以两个氧一起到达）再水解；氧化剂本身是强氧化剂、会染色，按危险类别对待。在更热的剧烈条件下，同一氧化剂直接断开双键——那是下文干净探针的粗兄弟。

**过氧羧酸** $\mathrm{RCO_3H}$ 以一步协同方式把一个氧原子交给 $\pi$ 键，生成**环氧化物**：三元环醚。氧递到一面，所以两根新 $\mathrm{C{-}O}$ 键 *syn* 生成，而张力环把旧 $\pi$ 键的其余部分储存为反应性——环氧化物会被亲核试剂开环，那是 [[organic-1/alcohols-ethers]] 的取代化学。

**臭氧解**是断裂探针。臭氧 $\mathrm{O_3}$——按需用氧气就地制备，因为它有毒，绝不可储存或浓缩——加到 $\pi$ 键上，还原性后处理（锌或二甲基硫醚）把 $\mathrm{C{=}C}$ 彻底断开，并给每个原来的烯烃碳戴上一个羰基氧。因此每个碎片都是烯烃的一半，从它的 $\mathrm{C{=}O}$ 倒读回去。

::: example 从碎片推结构 {#ex-ozonolysis}
某未知烃 $\mathrm{C_7H_{14}}$ 在钯上吸收一当量 $\mathrm{H_2}$，并在还原后处理的臭氧解中给出等摩尔的丙酮与丁-2-酮。提出结构。
::: solution
一当量氢：一根双键，无环。臭氧解剪断 $\mathrm{C{=}C}$ 并给两端戴上氧，所以把反应倒过来跑：剥掉两个羰基氧，用双键把两个羰基碳接起来。丙酮贡献 $\mathrm{(CH_3)_2C{=}}$ 那一半；丁-2-酮贡献 $\mathrm{{=}C(CH_3)CH_2CH_3}$。烯烃是 **2,3-二甲基戊-2-烯**，$\mathrm{(CH_3)_2C{=}C(CH_3)CH_2CH_3}$——$\mathrm{C_7H_{14}}$，与吸氢量一致。四取代双键，这就是它在稳定性阶梯上位置低、断裂比加成更干净的原因。若未知物只给出同一种产物两份，烯烃就是对称的——[[#exr-ozonolysis-set]] 的推理。
:::
:::

## 炔烃：两次加成与一个端基 C–H

炔烃带着两根 $\pi$ 键，所以本章所说的一切在这里发生两次——两端各带一个转折。一当量 $\mathrm{HX}$ 经马氏质子化给出乙烯基卤；第二当量再加，第二次加成同样服从规则，因为被卤素孤对电子稳定的那个碳正离子才是生成的那个——两个卤素最终落在**同一个碳**上（偕二卤代物）。氢化加两当量 $\mathrm{H_2}$ 到烷烃；在毒化催化剂上的部分氢化把两个氢 *syn* 递送，停在 *Z* 烯烃，而 *E* 烯烃由另一种还原抵达——[[organic-1/stereochemistry]] 的几何词汇在这里决定合成拿到哪个产物。炔烃的加成比烯烃慢：第一步的乙烯基正离子把正电荷放在 $sp$ 碳上，而 $sp$ 轨道把电子抓得太紧，这个碳正离子比上文任何 $sp^2$ 碳正离子都更不情愿生成。

水合走同样的分岔。端炔的马氏水合（汞催化，概念上，与羟汞化同样的毒性警告）先生成**烯醇** $\mathrm{C{=}C{-}OH}$，它互变异构——质子和双键交换舞伴——成**甲基酮**。硼氢化–氧化走反马氏，把烯醇的 OH 放在端碳上，于是互变异构体是**醛**。烯醇-酮互变异构是第二课程羰基化学（[[organic-2/carbonyl-addition]]）的预告。

另一端的转折是酸性。炔烃的端基 $\mathrm{C{-}H}$ 的 $\mathrm{p}K_\mathrm{a} \approx 25$——[[organic-1/acidity-mechanism]] 的轨道因子，$50\,\%$ s 成分把共轭碱的孤对电子拴在核边——所以酰胺之类的强碱把端炔变成**炔负离子**，而炔负离子是亲核试剂，按 [[organic-1/nucleophilic-substitution]] 的 $\mathrm{S_N2}$ 机理从伯卤代烃手里取代卤离子，建成一根新的碳碳键。炔烃烷基化是本课程中头一回按订单制造 $\mathrm{C{-}C}$ 键的地方，也是本章以合成而非以清单收尾的原因。

三个问题问尽整张表。*两根新键是什么？*——把试剂读成 $\mathrm{E{-}Nu}$。*哪个碳拿哪个？*——区域化学：离子型加成看碳正离子稳定性，硼看位阻接近，卤鎓看桥的电子效应。*从哪一面？*——立体化学：两根键同时形成或在金属表面形成则 *syn*，桥连离子迫使背面进攻则 *anti*，游离平面碳正离子什么也不决定则不受限。对任何一行答完这三问，产物就自己画出来了。

## 后续内容

水合与卤代醇生成是 [[organic-1/alcohols-ethers]] 加以系统化的醇的两种制备法，上面预告的环氧化物在那里由 [[organic-1/nucleophilic-substitution]] 的取代化学开环。我们推迟讨论的 HBr 反马氏加成是 [[organic-1/radical-reactions]] 的自由基链，那里鱼钩箭头取代弯箭头，过氧化物把规则翻了个底朝天。本章炔烃部分瞥见的烯醇与互变异构体，成为 [[organic-2/carbonyl-addition]] 羰基化学的主角。这里每一个加成都是 [[organic-1/elimination]] 消除的微观逆反应——把两章对着读，机理这门课的半壁就成了一章而非两章。上表所倚仗的立体化学词汇（*syn*、*anti*、内消旋、外消旋、*E*/*Z*）在 [[organic-1/stereochemistry]] 中建成。

::: summary
- $\pi$ 键是亲核试剂：加成拿一根弱 $\pi$ 键（$266\ \mathrm{kJ\,mol^{-1}}$）加一根试剂 $\sigma$ 键，换两根更强的 $\sigma$ 键，所以亲电加成放热（HBr 加过 $\mathrm{C{=}C}$：约 $-66\ \mathrm{kJ\,mol^{-1}}$）。
- 马氏规则是经验的；它的机理是"质子化到较稳定的碳正离子"，由哈蒙德假说辩护——晚的、碳正离子样式的过渡态意味着碳正离子稳定性*就是*势垒高度，$7.3\ \mathrm{kJ\,mol^{-1}}$ 的 $\Delta\Delta G^{\ddagger}$ 买到 $95:5$。
- 碳正离子中间体会经 1,2-氢负离子和 1,2-烷基迁移重排，只要迁移能把 $2^\circ \rightarrow 3^\circ$；重排产物是碳正离子真实存在的证据，也是死套规则的极限。
- 三种水合，三种答案：酸催化（马氏、可逆、会重排）、羟汞化–脱汞（马氏、不重排、桥连汞鎓离子）、硼氢化–氧化（反马氏、*syn*、根本没有碳正离子）。
- 卤化经环状卤鎓离子：*anti* 加成、从不重排；在水中生成卤代醇，$\mathrm{OH}$ 在取代较多的碳上。
- 氢化热度量烯烃稳定性：取代越多越稳定（每个烷基约 $8\ \mathrm{kJ\,mol^{-1}}$），*E* 胜过 *Z*，催化氢化是 *syn*。
- 氧化分岔：冷的稀 $\mathrm{KMnO_4}$ 给 *syn* 二醇，过氧酸给环氧化物，臭氧解把 $\mathrm{C{=}C}$ 断成羰基——一个从碎片倒读的结构探针。
- 炔烃加两次（偕二卤代物；马氏水合经烯醇到甲基酮，反马氏硼氢化到醛），其端基 $\mathrm{C{-}H}$（$\mathrm{p}K_\mathrm{a} \approx 25$）生成用于碳碳键建造的炔负离子。
:::

## 练习

::: exercise HCl 加成的焓 {level=1 check="-54"}
用平均键焓（$\pi$：$266$；$\mathrm{H{-}Cl}$：$431$；$\mathrm{C{-}H}$：$413$；$\mathrm{C{-}Cl}$：$338\ \mathrm{kJ\,mol^{-1}}$）估算 $\mathrm{HCl}$ 加过 $\mathrm{C{=}C}$ 双键的 $\Delta H$。（以 $\mathrm{kJ\,mol^{-1}}$ 输入 $\Delta H$。）
::: solution
断键：$266 + 431 = 697$。成键：$413 + 338 = 751$。$\Delta H \approx 697 - 751 = -54\ \mathrm{kJ\,mol^{-1}}$。放热，与一切 $\pi$ 换 $\sigma$ 型加成相同；$\mathrm{H{-}Cl}$ 键比 $\mathrm{H{-}Br}$ 强，所以 $\mathrm{HCl}$ 的加成比 $\mathrm{HBr}$ 的（$-66$）放热略少。
:::
:::

::: exercise 从阶梯看稳定性 {level=1 check="4"}
*cis*-丁-2-烯与 *trans*-丁-2-烯的氢化热分别为 $-120\ \mathrm{kJ\,mol^{-1}}$ 与 $-116\ \mathrm{kJ\,mol^{-1}}$。*trans* 异构体更稳定多少 $\mathrm{kJ\,mol^{-1}}$？（输入数值。）
::: solution
两个异构体都氢化成丁烷，所以氢化热之差就是能量差：$120 - 116 = 4\ \mathrm{kJ\,mol^{-1}}$。*trans* 异构体在通往同一产物的路上少放出 $4$，说明它出发时就低 $4$。
:::
:::

::: exercise 由势垒差看区域选择性 {level=1 check="95"}
某加成经两个竞争的过渡态进行，二者相差 $\Delta\Delta G^{\ddagger} = 7.3\ \mathrm{kJ\,mol^{-1}}$（$\mathrm{298\ K}$）。预期主异构体的百分数是多少？取 $RT = 2.479\ \mathrm{kJ\,mol^{-1}}$。（输入百分数。）
::: solution
比 $= e^{7.3/2.479} = e^{2.945} = 19.0$，所以主异构体为 $19.0/20.0 = 95\,\%$。这就是正文 newton 图的算术：过渡态上的 $7.3\ \mathrm{kJ\,mol^{-1}}$，就是烧瓶里的 $95:5$。
:::
:::

::: exercise 溴化的焓 {level=2 check="-111"}
用平均键焓（$\pi$：$266$；$\mathrm{Br{-}Br}$：$193$；$\mathrm{C{-}Br}$：$285\ \mathrm{kJ\,mol^{-1}}$）估算 $\mathrm{Br_2}$ 加过 $\mathrm{C{=}C}$ 双键的 $\Delta H$。（以 $\mathrm{kJ\,mol^{-1}}$ 输入 $\Delta H$。）
::: solution
断键：$266 + 193 = 459$。成键：$2 \times 285 = 570$。$\Delta H \approx 459 - 570 = -111\ \mathrm{kJ\,mol^{-1}}$。弱的 $\mathrm{Br{-}Br}$ 键使卤素加成比卤化氢加成更放热——而且反应仍然不需要光或热，这就是溴试验能在暗处进行的原因。
:::
:::

::: exercise 带重排的预测 {level=2}
预测 $\mathrm{HBr}$ 加到 3-甲基戊-1-烯 $\mathrm{CH_2{=}CHCH(CH_3)CH_2CH_3}$ 的主产物，并用文字描述机理。
::: solution
C1 质子化（马氏规则）给出仲碳正离子 $\mathrm{CH_3CH^{+}CH(CH_3)CH_2CH_3}$，它坐在一个带氢的叔碳旁边。1,2-氢负离子迁移把电荷升级到 C3，叔的：$\mathrm{CH_3CH_2C^{+}(CH_3)CH_2CH_3}$。溴离子在 C3 结合，主产物为 **3-溴-3-甲基戊烷**。未重排的 2-溴-3-甲基戊烷是次要产物；两种产物并存，正是碳正离子在被捕获之前先重排了的签名。
:::

给出把 2-甲基丙烯转化为 (a) 2-甲基丙-2-醇和 (b) 2-甲基丙-1-醇的条件，并解释每条路线为什么给出它的产物。
::: solution
**(a)** 稀酸水溶液（若担心重排则用羟汞化–脱汞序列——这里不必，因为叔碳正离子无法再升级）。质子化在中心碳生成叔碳正离子；水在那里进攻：马氏规则，叔醇。**(b)** $\mathrm{BH_3}$，然后 $\mathrm{H_2O_2,\ HO^-}$。硼加到端基 $\mathrm{CH_2}$ 上——位阻较小，且过渡态上的部分正电荷落在取代较多的碳上——氧化把 B 换成 OH：反马氏，伯醇。同一个烯烃，同样净加一分子水，相反的区域化学：决定结果的是机理，不是试剂标签。
:::

::: exercise 臭氧解题组 {level=3 #exr-ozonolysis-set}
三个未知物，各为单一的非环烯烃，在还原后处理的臭氧解中给出下列羰基产物。推断每个烯烃：(a) $\mathrm{C_4H_8}$ 只给出乙醛；(b) $\mathrm{C_6H_{12}}$ 只给出丙酮；(c) $\mathrm{C_5H_{10}}$ 给出乙醛和丙酮。
::: solution
每例都把断裂倒过来跑：用双键把羰基碳接起来，扔掉氧。**(a)** 两半相同——烯烃是对称的：丁-2-烯，$\mathrm{CH_3CH{=}CHCH_3}$（数据无法区分 *E* 或 *Z*）。**(b)** 两个丙酮半片：2,3-二甲基丁-2-烯，$\mathrm{(CH_3)_2C{=}C(CH_3)_2}$。**(c)** 一个 $\mathrm{CH_3CH{=}}$ 半片加一个 $\mathrm{{=}C(CH_3)_2}$ 半片：2-甲基丁-2-烯，$\mathrm{CH_3CH{=}C(CH_3)_2}$。每个答案都符合所给分子式，这就是检验：动手之前先数碎片的碳。
:::

::: exercise 一个烯烃的三种产物 {level=3}
对 1-甲基环戊烯，为下列每个产物提出一步或两步路线：(a) 1-甲基环戊-1-醇；(b) *trans*-2-甲基环戊-1-醇；(c) 1,2-二溴-1-甲基环戊烷。说明每条路线给出其产物的区域化学与立体化学理由。
::: solution
**(a)** 稀酸水溶液：马氏质子化把叔碳正离子放在 C1，水在那里进攻；带羟基的碳带着两条相同的环臂，所以无需指定立体化学。**(b)** $\mathrm{BH_3}$，然后 $\mathrm{H_2O_2,\ HO^-}$：硼到取代较少的 C2，氢到 C1，*syn* 且不重排；构型保持的氧化把 OH 放到与甲基 *trans* 的位置（与 C1 上新生氢 *cis*）。**(c)** $\mathrm{Br_2}$：溴鎓离子桥连 C1 与 C2，溴离子从对面进攻，所以两个溴 *anti*（在环上呈反式），取代较多的碳从开环一步得到它的溴。三种试剂，一个烯烃，三个不同的答案——生成这三个答案的是区域化学与立体化学，不是记忆。
:::
