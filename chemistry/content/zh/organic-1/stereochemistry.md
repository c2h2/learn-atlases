把你的两只手并排放到镜子前：它们由相同的部件构成、按相同的顺序排列，可无论怎样旋转，一只手永远无法与另一只手重合。分子也可以如此，而对碳的化合物来说，其后果贯穿整个化学。香芹酮（carvone）按你至今用过的任何计数规则都是一种化合物——一个分子式、一种连接方式——可你闻一瓶是留兰香，闻它的镜像却是葛缕子，因为你鼻腔里的蛋白质本身就是手性的，对两个对映体的结合方式不同。本章讲的是有机结构的第三维：什么使一个分子具有手性，我们如何无歧义地命名它的三维排列，一种给定的连接方式允许多少种这样的排列，以及我们如何只用一束偏振光就在实验室里把它们区分开。本课程后面的每一章——取代、消除、加成——有一部分都是关于立体化学的故事，而药柜是一个现成的证明：一个分子的两个镜像是两种化合物，不是同一个化合物画了两遍。

## 立体异构体：原子相同，空间排列不同

::: definition 构造异构体与立体异构体 {#def-stereoisomers}
**构造异构体**（异构体）分子式相同而连接方式不同——相互成键的原子不同，如1-丁醇与2-丁醇。**立体异构体**分子式*相同*、连接方式也*相同*，只是原子在空间的排列不同。立体异构体还可再分：**构象异构体**靠单键旋转互变，（对无环分子在室温下）通常无法分离；而**构型异构体**——本章的主题——只有断开化学键才能互变，是可分离、可储存、可以贴标签上架的化合物。
:::

构象异构体与构型异构体的区别在于势垒，而不在于种类：乙烷的交叉式构象确实是"空间排列不同"，但 $12\ \mathrm{kJ\,mol^{-1}}$ 的势垒意味着一瓶乙烷每秒在其中翻转上万亿次；而构型异构体隔着数百 $\mathrm{kJ\,mol^{-1}}$ 的断键势垒——每一对可分离的构型异构体都是一对化合物，各有各的货架标签。

::: example 给异构体对分门别类 {#ex-isomer-pairs}
把下列每一对判为构造异构体或立体异构体；对立体异构体对，再说明（按本章后文的预告）它们是镜像关系还是非镜像关系：(a) 1-丁醇与2-丁醇；(b) 2-丁烯 $\mathrm{CH_3CH{=}CHCH_3}$ 的两种构型；(c) 2-丁醇 $\mathrm{CH_3CH(OH)CH_2CH_3}$ 在C2上的两种原子排布；(d) 环己烷的椅式与扭船式。
::: solution
(a) OH在不同的碳上：连接方式不同，是**构造异构体**。(b) 连接方式相同，但双键不破坏 $\pi$ 键就不能旋转，两侧取代基被锁死：是**立体异构体**，而且两者互不成镜像——这个区别将极其重要，我们称这样的异构体对为*非对映体*。(c) 连接方式相同，但C2上的四个基团可以排成互为镜像的两种方式：是**立体异构体**，镜像对——*对映体*。(d) 连接方式相同，靠键的旋转（褶皱）互变：是**构象异构体**，是立体异构体中作时间平均的特殊情形，我们在 [[organic-1/conformations]] 中处理。
:::
:::

## 手性与对称性判据

::: definition 手性 {#def-chirality}
若一个分子（或任何物体）与其镜像不能重合，则它是**手性**的；若镜像能与自身重合，则是**非手性**的。手性分子的两个镜像形式称为**对映体**。手性是整个分子的性质，判定时要像判双手一样：把分子与它的镜像叠起来，问是否存在*某种*刚性运动（只许旋转，不许断键）使所有原子重合。
:::

::: definition 立体中心 {#def-stereocentre}
**立体中心**（立体异构中心；当它是连着四个不同基团的碳时又称手性中心）是指这样一个原子：其上配体在空间的排布使得交换其中两个就产生另一个立体异构体。连有四个不同基团的四面体碳是有机化学中最常见的立体中心，也是我们首先分析的对象。
:::

这两个定义指向不同的方向，切不可混淆：立体中心是标在单个原子上的局部记号，手性则是对整个分子的总体裁决。严格的总体判据是对称性。一个分子是非手性的，当且仅当它具有**非真转轴** $S_n$——绕轴旋转 $360^\circ/n$ 再对垂直于轴的平面作反映，分子保持不变。普通的旋转轴 $C_n$ 无害：分子可以有 $C_2$ 轴而仍然是手性的。几乎能抓住所有初学者情形的两种对称元素是 $S_1$（普通的镜面 $\sigma$）和 $S_2$（对称中心 $i$）：只要你的分子有镜面或对称中心，它就能与自己的镜像重合，再多的立体中心也救不了它。

::: example 寻找立体中心 {#ex-stereocentres}
下列分子哪些有立体中心，在哪里？(a) 2-戊醇 $\mathrm{CH_3CH(OH)CH_2CH_2CH_3}$；(b) 3-甲基戊烷 $\mathrm{(CH_3CH_2)_2CHCH_3}$；(c) 1,2-二溴环戊烷。
::: solution
(a) C2连着H、OH、$\mathrm{CH_3}$ 和 $\mathrm{CH_2CH_2CH_3}$：四个不同的基团，所以**C2是立体中心**，分子是手性的。(b) C3连着H、$\mathrm{CH_3}$ 和*两个相同的*乙基：不是立体中心；每个乙基的CH₂带着两个氢；**不存在立体中心**，分子是非手性的——陷阱在于因为两条臂画得开就误以为它们不同。(c) C1连着Br、H和两条环臂；C2同理。从C1沿两条臂分别往前走，一条到达带Br的C2，另一条到达不带Br的C5，两条臂不同：**C1和C2都是立体中心**。环上的碳同样适用——在宣布两条臂相同之前，务必沿环走两圈比较。
:::
:::

::: quiz
下列哪一个分子是手性的？
- [x] 2-戊醇
- [ ] 3-戊醇
- [ ] 2,2-二甲基丙烷
- [ ] 2-丙醇
::: solution
2-戊醇有一个立体中心（C2：H、OH、甲基、丙基）且没有镜面，所以是手性的。3-戊醇的中心碳连着H、OH和*两个相同的乙基*；2,2-二甲基丙烷的中心碳连着四个甲基；2-丙醇的带羟基碳连着两个甲基。它们都有一个通过那两个特殊取代基的镜面，都是非手性的。
:::
:::

::: warning 立体中心与手性会分道扬镳 {#warn-stereocentres-not-chirality}
"连四个不同基团就是手性"这一条件反射有三种失效方式。**（1）**含立体中心的分子可以是非手性的：若一个内部镜面把分子分成互为镜像的两半，整个分子就能与自己的镜像重合。这样的化合物称为**内消旋**化合物，下文我们将仔细拆解内消旋酒石酸。**（2）***不*含立体中心的分子可以是手性的：丙二烯类、*(Z)*-环辛烯之类的扭曲烯烃以及受阻联芳基，其手性来自轴或螺旋，而不是不对称碳。**（3）**立体中心的数目甚至在你换一种画法时都不稳定：旋转分子，立体中心不会移动，但对着平面分子式看一眼就会凭空多出或丢掉几个。拿不准时，用对称性判据，不要用计数判据。
:::

## 构型的标定：凯恩-英戈尔德-普雷洛格（CIP）规则

把四面体中心描述成"与通常那个成镜像的形式"毫无用处；我们需要一个名字。凯恩-英戈尔德-普雷洛格（Cahn–Ingold–Prelog，CIP）体系通过对四个基团进行纯机械的排序，给每个立体中心指定一个标记：*R* 或 *S*。

::: algorithm 四面体中心的CIP规则 {#alg-cip}
**（1）**按直接相连原子的**原子序数**给立体中心上的四个基团排序 1 > 2 > 3 > 4：$\mathrm{Br} > \mathrm{Cl} > \mathrm{O} > \mathrm{N} > \mathrm{C} > \mathrm{H}$；孤对电子排在氢之下。**（2）**同位素按**质量数**排序：$\mathrm{T} > \mathrm{D} > \mathrm{H}$。**（3）**平局时**逐层向外**打破：对每个打平的原子，列出它所连的三个取代基（不含你来的那个原子）按降序排列，再逐原子比较两个列表——第一次出现差异处即定胜负；绝不求和。只有整层打平才继续向外。**（4）**多重键用**重复原子**展开：$\mathrm{C{=}O}$ 计为C连着（O, O, H当量）、O连着（C, C）；环则按"打开成树"的方式遍历，环闭合处放重复原子。**（5）**从4号基团**背离**你的方向看中心，读 1 → 2 → 3：顺时针为 ***R***（rectus，右），逆时针为 ***S***（sinister，左）。若最低优先基团朝向你，则读出表观方向后**取反**。
:::

标记以斜体写在括号里、放在名称前面：（*R*）-2-丁醇。整个程序不涉及旋光、味道或来源——*R*/*S* 只是记账，它们与实验的联系只能通过下文一类的测量建立。

::: example （*R*）-与（*S*）-2-丁醇 {#ex-rs-butanol}
标定2-丁醇立体中心的构型：画法为H在虚键上（背离你），OH在上方，乙基在右下，甲基在左下。
::: solution
C2上的优先次序：OH（O，$Z = 8$）为1，H为4；两个含碳基团之间，$\mathrm{CH_2CH_3}$（C连着C,H,H）在第一层就胜过 $\mathrm{CH_3}$（C连着H,H,H），所以乙基为2、甲基为3。H已背离你，读 $\mathrm{OH} \rightarrow \mathrm{C_2H_5} \rightarrow \mathrm{CH_3}$：上 → 右下 → 左下是顺时针，故此画法为（*R*）-2-丁醇。它的镜像——把乙基与甲基对调的同一张图——是（*S*）-2-丁醇。两者是对映体：同名而异标记，是两个不同的化合物。
:::
:::

::: example 同位素打破平局：CHBrClD {#ex-rs-isotope}
溴氯（氘代）甲烷 $\mathrm{CHBrClD}$ 虽然分子式里只出现三种*元素*，却有一个立体中心。排出优先次序，并说明最后一名由什么决定。
::: solution
按原子序数，Br（1）> Cl（2）。剩下两个基团是D和H——同种元素，故用规则（2）：氘（质量数2）优先于氕（质量数1）。优先次序：$\mathrm{Br} > \mathrm{Cl} > \mathrm{D} > \mathrm{H}$。同位素从不能凭自己对抗跨元素的平局，却能打破原子序数打不破的平局：连着H和D的碳中心，或 $\mathrm{CH_3}$ 与 $\mathrm{CDH_2}$ 之争（逐层比较，(D,H,H) 胜 (H,H,H)），都是真正的"四个不同基团"。
:::
:::

::: example 环与双键：3-溴环己烯 {#ex-rs-ring}
3-溴环己烯的C3是立体中心。排出它的四个基团的次序，说明两条环臂如何比较，并标定如下画法的构型：H在虚键上，Br在上方，$=\mathrm{CH}{-}$ 那条臂在右。
::: solution
Br为1，H为4。两条臂都以碳开头，规则（3）带我们向外走。右臂的第一个原子是双键上的C2：规则（4）把 $\mathrm{C{=}C}$ 展开，C2计为连着（C1, C1的重复原子, H）——列表为(C, C, H)。左臂的第一个原子是C4上的 $\mathrm{CH_2}$，连着（C5, H, H）。按降序比较列表，(C, C, H) 在第二项就胜过 (C, H, H)：不饱和的那条臂获胜，所以右臂为2、左臂为3。H背离你时，$\mathrm{Br} \rightarrow \text{右} \rightarrow \text{左}$ 为顺时针：此画法是（*R*）-3-溴环己烯。注意双键获胜不是因为双键"更强"，而是重复原子往列表里添了一个幽灵碳。
:::
:::

## 费歇尔投影式

在旋光性之前，我们还需要一件画图工具，因为链状分子惯用的平面写法其实携带着完整的立体化学信息。

::: algorithm 费歇尔投影式的操作规则 {#alg-fischer}
**费歇尔投影式**把碳链竖直放置、从上端开始编号，并约定**竖直的键指向纸后**（虚键）、**水平的键指向纸前**（楔键）。操作规则：**（1）**在纸面内旋转 $180^\circ$ 是允许的（相当于分子的刚性旋转）；**（2）**旋转 $90^\circ$ 是禁止的——它会把每个中心都变成相反构型；**（3）**在一个中心上交换任意两个基团就翻转该中心；偶数次交换保持不变；**（4）**标定 *R*/*S*：照常排序，若最低优先基团在水平键上，读出表观的 1 → 2 → 3 方向后**取反**（因为水平意味着"朝向你"）。
:::

::: example 从费歇尔投影式看甘油醛 {#ex-fischer-glyceraldehyde}
（+）-甘油醛 $\mathrm{CHO{-}CH(OH){-}CH_2OH}$（2,3-二羟基丙醛）按标准费歇尔投影式画出：CHO在上，$\mathrm{CH_2OH}$ 在下，OH在右，H在左。标定它的构型。
::: solution
C2上的优先次序：OH为1；CHO的碳按重复原子计为（O, O, H），胜过 $\mathrm{CH_2OH}$ 的（O, H, H），故CHO为2、$\mathrm{CH_2OH}$ 为3；H为4。在纸面上读 $\mathrm{OH} \rightarrow \mathrm{CHO} \rightarrow \mathrm{CH_2OH}$（右 → 上 → 下）是逆时针——但H在*水平*键上、朝向你，所以规则（4）把表观答案取反：该中心为 ***R***。（+）-甘油醛就是（*R*）-2,3-二羟基丙醛，费歇尔在1891年正是把它的构型选作整个糖D/L命名体系的基准点——事后证明，他选对了（见下文的历史注记）。
:::
:::

::: example 同一个分子还是镜像？ {#ex-fischer-identity}
2,3-二溴丁烷的投影式A在C2和C3上Br都在右；投影式B在两个中心Br都在左；投影式C在C2上Br在右、C3上Br在左。判断A与B、A与C的关系。
::: solution
B就是A在纸面内转 $180^\circ$ 的结果——上下互换、左右互换——这是刚性旋转，所以**A与B是同一个分子**。逐一算出标记（每个中心上 $\mathrm{Br} > $ 另一个连Br的 $\mathrm{CHBrCH_3}$ 型臂 $> \mathrm{CH_3} > \mathrm{H}$，H在水平键上时取反）得A = (2*S*,3*R*)，B亦然：A是**内消旋**化合物，非手性，与自己的镜像相同。C相对A是一个中心翻转、另一个保持：它是 (2*R*,3*R*)——从另一端重新编号得到的仍是同一对标记，可以自行验证——一个*不是*A的镜像的立体异构体，所以**A与C是非对映体**。只在一个中心上交换了一对基团：正是这一次交换，划开了非手性的内消旋化合物与可拆分的手性分子之间的界限。
:::
:::

## 多个立体中心

::: proposition $2^n$ 上限 {#prop-2n}
含 $n$ 个立体中心的分子**至多**有 $2^n$ 个立体异构体，因为每个中心可以独立地取 *R* 或 *S*。当没有两个中心等价时取到上限；内部对称性会使 $2^n$ 个构型中的一些彼此相同（如内消旋化合物），从而减少数目。枚举立体异构体意味着先列出构型，再按分子的对称性合并。
:::

::: definition 对映体与非对映体 {#def-diastereomers}
**对映体**是互不成镜像的镜像立体异构体：*每个*立体中心都翻转。**非对映体**是不成镜像关系的立体异构体：*部分而非全部*立体中心翻转（或差异在 *E*/*Z* 几何）。对映体成对出现；非对映体则是任意两个非镜像构型异构体之间的关系。
:::

::: example 2,3-二溴戊烷的四个立体异构体 {#ex-dibromopentane}
2,3-二溴戊烷 $\mathrm{CH_3CHBrCHBrCH_2CH_3}$ 在C2和C3各有一个立体中心。它有几个立体异构体？彼此是什么关系？
::: solution
两个中心*不*等价（C2一头是甲基，C3一头是乙基），不存在内部镜面，故 $2^2 = 4$ 个构型两两不同：(2*R*,3*R*)、(2*S*,3*S*)、(2*R*,3*S*) 和 (2*S*,3*R*)。镜像使两个中心同时翻转，所以对映体对是 (2*R*,3*R*)/(2*S*,3*S*) 与 (2*R*,3*S*)/(2*S*,3*R*)；其余任何配对——比如 (2*R*,3*R*) 与 (2*R*,3*S*)——只翻转一个中心而另一个保持，是**非对映体**对。四个立体异构体、两对对映体、任何交叉配对皆为非对映体：这就是取到 $2^n$ 上限时的一般图景。
:::
:::

::: definition 内消旋化合物 {#def-meso}
**内消旋化合物**含有立体中心却是非手性的，因为一个内部镜面把分子的一半映射到另一半。内消旋形式永远与自己的镜像相同，于是它"吃掉" $2^n$ 清单中的两栏：在含两个等价立体中心的对称分子里，(*R*,*S*) 与 (*S*,*R*) 说的是同一个化合物。
:::

::: example 内消旋酒石酸的完整分析 {#ex-meso-tartaric}
酒石酸是2,3-二羟基丁二酸 $\mathrm{HOOC{-}CH(OH){-}CH(OH){-}COOH}$：两个等价的立体中心。枚举它的立体异构体，并逐一分析对称性。
::: solution
$2^2 = 4$ 个构型坍缩为**三个立体异构体**。(2*R*,3*R*) 与 (2*S*,3*S*) 互为非重合的镜像——一对对映体；天然的、来自葡萄酒的是 (2*R*,3*R*)，两者把平面偏振光旋转得等大而反向。(2*R*,3*S*) 构型很特殊：把碳链画成两个OH在同侧的费歇尔投影式，C2与C3之间有一道水平镜面，把上半部分恰好反映到下半部分。分子能与自己的镜像重合——它就是**内消旋**形式，非手性，旋光为零不是因为它是混合物，而是因为每个分子自己的另一半在分子内部抵消了自己的旋转。（计数核对：(2*R*,3*S*) 与 (2*S*,3*R*) 是同一个化合物，故 $4 - 1 = 3$。）酒石酸因此是一种连接方式对应三种可稳定存放的化合物：两个对映体，以及它们各自的一个内消旋非对映体。
:::
:::

## 旋光性：用光读取构型

::: definition 旋光 {#def-optical}
平面偏振光的电场只在一个平面内振动。**手性**物质会旋转这个平面：把检偏器转回消光位所需的角度 $\alpha$ 称为**观测旋光度**，在旋光仪上以钠D线（$\lambda = 589\ \mathrm{nm}$）测量。使偏振面顺时针（向右，沿光离开样品的方向看）旋转的物质为右旋，记 $(+)$；逆时针为左旋，记 $(-)$。非手性物质不产生旋光。
:::

::: proposition 比旋光度 {#prop-rotation}
观测旋光度随光程和光途中的物质量增大，所以把它们除掉：
$$
[\alpha]_\mathrm{D}^{\mathrm{T}} = \frac{\alpha}{l\,c},
\qquad l \text{ 以 } \mathrm{dm} \text{ 计},\quad c \text{ 以 } \mathrm{g\,mL^{-1}} \text{ 计},
$$
称为温度 $T$ 下以D线测定的**比旋光度**。它是化合物的物理常数，如同沸点，但是有条件的：文献值要连同条件一起给出，例如天然酒石酸的 $[\alpha]_\mathrm{D} = +12.0$（c 20，$\mathrm{H_2O}$）——"c 20"表示每 $100\ \mathrm{mL}$ 溶液含 $20\ \mathrm{g}$，即 $c = 0.20\ \mathrm{g\,mL^{-1}}$。$[\alpha]$ 的单位是 $\mathrm{deg\,mL\,g^{-1}\,dm^{-1}}$，通常不写出。
:::

::: example 天然酒石酸的观测旋光度 {#ex-tartaric-rotation}
天然酒石酸的 $[\alpha]_\mathrm{D} = +12.0$（c 20，$\mathrm{H_2O}$，数据表值）。用 $2.00\ \mathrm{dm}$ 样品管装满引文所述的那种溶液（每 $100\ \mathrm{mL}$ 水溶液含 $20\ \mathrm{g}$）。旋光仪读数为多少？
::: solution
把 $[\alpha] = \alpha/(lc)$ 移项：
$$
\alpha = [\alpha]\, l\, c = (+12.0) \times 2.00 \times 0.20 = +4.8^{\circ}.
$$
保留两位有效数字，由数据表的 $+12.0$ 和浓度决定。同一支管装满合成的 (2*S*,3*S*) 对映体读数为 $-4.8^{\circ}$；装满内消旋型——或两种对映体的任意1:1混合物——则读 $0.0^{\circ}$。
:::
:::

::: definition 对映体过量 {#def-ee}
对映体混合物用**对映体过量**描述：
$$
ee = \frac{|c_1 - c_2|}{c_1 + c_2} \times 100\,\%,
$$
即一种对映体超出另一种的百分数：($S$) 与 ($R$) 按90:10混合，$ee = 80\,\%$。纯对映体 $ee = 100\,\%$；**外消旋体**（等摩尔混合物，记 $(\pm)$）$ee = 0$。
:::

::: proposition 旋光度测量对映体过量 {#prop-ee}
因为旋光对光束中的各物种具有可加性（毕奥叠加定律），两种对映体的贡献按混合物中外消旋部分的比例相互抵消，于是
$$
\frac{\alpha_{\text{obs}}}{\alpha_{\text{pure}}} = ee,
\qquad\text{等价地}\qquad
x_{\text{major}} = \frac{1 + ee}{2},\quad x_{\text{minor}} = \frac{1 - ee}{2},
$$
其中 $x$ 是摩尔分数，$\alpha_{\text{pure}}$ 是纯主对映体在相同 $l$、$c$ 与条件下的旋光度。因此一次旋光读数就能确定对映体混合物的组成——这就是旋光法在现代仪器林立之后仍是光学纯度常规检测手段的原因。
:::

::: example 布洛芬样品的对映体过量 {#ex-ibuprofen-ee}
止痛药布洛芬（ibuprofen）通过其 (S)-对映体起效；（*S*）-布洛芬的 $[\alpha]_\mathrm{D} = +61$（c 2，乙醚，数据表值）。某次合成得到的样品在相同条件下测得 $[\alpha]_\mathrm{D} = +55$。求 ee 与百分组成。
::: solution
$$
ee = \frac{+55}{+61} \times 100\,\% = 90.2\,\%.
$$
于是 $x_{(S)} = (1 + 0.902)/2 = 0.951$、$x_{(R)} = 0.049$：样品含 $95.1\,\%$ 的 ($S$) 与 $4.9\,\%$ 的 ($R$)。同样的算术反着跑：目标 ee 为95%就规定了你必须看到的旋光度——质量控制不靠手性色谱柱、靠旋光仪检查手性合成，道理就在这里。
:::
:::

::: widget plot

caption: 两种对映体的混合物观测旋光度（以纯对映体旋光度为单位）对 $(+)$-型摩尔分数 $x$ 的作图。直线 $\alpha_{\text{obs}}/\alpha_{\text{pure}} = 2x - 1$ 正是"旋光可叠加"的表述：它在 $x = 0.5$（外消旋体，光学上死寂）处过零，在两端纯对映体处达到 $\pm 1$。斜率解释了为什么旋光法对*富集*远比对*身份*敏感——在外消旋点附近，$x$ 的微小变化就使读数大幅摆动；而在接近光学纯时读数几乎不动，99% ee 的样品与100% ee 的样品看起来相差无几。

::: warning 旋光能告诉你什么、不能告诉你什么 {#warn-rotation-sign}
**（1）** $R$ 不等于 $(+)$，$S$ 也不等于 $(-)$。标记是由原子序数导出的记账；旋光方向是实验事实。天然酒石酸是 (2*R*,3*R*)、$(+)$；它的对映体是 (2*S*,3*S*)、$(-)$；但（*S*）-布洛芬是 $(+)$，而对许多化合物，一对对映体的两个标记与旋光方向之间跨化合物毫无规律。你永远无法由 *R*/*S* 预测旋光方向，也无法由旋光方向指定构型。**（2）**对映体的物理性质——熔点、沸点、密度、$\mathrm{CDCl_3}$ 中的核磁共振谱——*只有在非手性环境中*才完全相同。在手性世界里它们不同：(+) 与 (−)-香芹酮一个像留兰香、一个像葛缕子，因为嗅觉受体是手性的；对映体在手性色谱柱上先后洗脱；在体内，一个对映体遇到的是由L-氨基酸构建的酶，另一个遇到的同一批酶却视它为陌生人。外消旋体不是"半剂量"：它是另一种物质，有自己的药理。**（3）**旋光度为零不能证明非手性：可能是外消旋体，可能是内消旋化合物，也可能是放在架上外消旋化了的样品。旋光仪只报一个数；解释是你的事。
:::

::: history
旋光性由让-巴蒂斯特·毕奥（Biot）于1815年发现。他发现石英以及糖、酒石酸、樟脑的溶液能旋转偏振光，并且——在他那个时代惊人地——旋光度与浓度成正比，即这种效应是分子层面的。1848年，年轻的路易·巴斯德（Pasteur）研究"副酒石酸"（外消旋酸，其老师巴拉尔从葡萄酒经一条破坏晶体记忆的途径制得）的铵钠盐时，在显微镜下注意到两种晶面取向互为镜像的晶体，用镊子把它们分拣开、分别溶解，测得等大反向的旋光：这是对映体的第一次**拆分**，也是分子不对称性的诞生。1874年，二十二岁的雅各布斯·范特霍夫（van 't Hoff）与约瑟夫·勒贝尔（Le Bel）各自独立提出四面体碳，一举把碳原子的不对称性确立为旋光性的结构基础。1891年，埃米尔·费歇尔（Fischer）把两种甘油醛画成互为镜像的费歇尔投影式，武断地把一个标为D、另一个标为L，把整个糖与氨基酸命名体系锚定在他的猜测上；1949年，J. M. 比尤沃（Bijvoet）利用酒石酸盐中铷对X射线的反常散射，证明费歇尔的猜测——凭运气，一场持续五十八年的五五开——恰好是对的，从此**绝对构型**成为实验事实。
:::

## E/Z异构：烯烃的立体异构

::: definition E与Z标记 {#def-ez}
$\mathrm{C{=}C}$ 双键不破坏 $\pi$ 键（$\approx 266\ \mathrm{kJ\,mol^{-1}}$）就不能旋转，所以每个双键碳的两个取代基被固定在位。把CIP排序分别用在*每个*双键碳的两个基团上：若两个优先级较高的基团位于双键**同侧**，构型为 ***Z***（zusammen，共同）；位于**异侧**则为 ***E***（entgegen，相反）。*E*/*Z* 是构型标记：互变它们是反应，不是旋转。
:::

旧的 *cis*/*trans* 语言比较的是相同基团或主链，一旦烯烃带三个或四个不同取代基就失灵：对 $\mathrm{BrHC{=}CHCl}$，"与谁同侧？"没有答案；对三取代烯烃，可能根本找不出一对相同基团可比。CIP机器永远有答案，因为它从不要求相同基团。

::: example 标定E与Z {#ex-ez-assign}
标定构型：(a) 按C2的甲基与C3的乙基位于同侧画出的3-甲基-2-戊烯；(b) 按Br与Cl位于同侧画出的1-溴-2-氯-1-氟乙烯。
::: solution
(a) C2上的基团是 $\mathrm{CH_3}$（C: H,H,H）与H，甲基胜出。C3上的基团是 $\mathrm{CH_2CH_3}$（C: C,H,H）与 $\mathrm{CH_3}$（C: H,H,H）：第一层乙基胜出。两个胜者——C2的甲基与C3的乙基——按画法在同侧：该化合物是（*Z*）-3-甲基-2-戊烯。注意 *cis*/*trans* 在这里无从下手：四个取代基中没有任何两个相同。(b) C1上 Br（1）> F；C2上 Cl（1）> H。Br与Cl在同侧，即两个较优基团同侧：（*Z*）-1-溴-2-氯-1-氟乙烯。一个提醒：*Z* 不是"两个最大基团同侧"，而是"两个 *CIP 胜者* 同侧"，优先次序看原子序数，不看体积。
:::
:::

烯烃把本章的两半在一个漂亮的边角情形里缝合起来：（*Z*）-环辛烯是非手性的，但***反*-环辛烯**无法把自己扭成镜像——环太小跨不过去——并已被拆分成稳定的对映体：一个手性分子，其手性住在一个扭曲的双键和一个环里，任何地方都没有立体中心。

## 没有立体中心的手性

丙二烯 $\mathrm{R^1R^2C{=}C{=}CR^3R^4}$ 的两个 $\pi$ 体系互相垂直，两端的碳把各自的取代基带进互相垂直的平面；只要每端各有两个*不同*的基团，分子就没有镜面，以对映体形式存在。受阻的单键旋转也能做到：在BINOL这类2,2′-二取代联芳基中，两个萘环近乎垂直，庞大的邻位基团挡住旋转，得到的**阻转异构体**是可分离的化合物——承载手性的是轴或螺旋，而不是不对称碳。

::: example 哪些丙二烯是手性的？ {#ex-allene}
判断2,3-戊二烯 $\mathrm{CH_3CH{=}C{=}CHCH_3}$ 与1,2-丁二烯 $\mathrm{CH_2{=}C{=}CHCH_3}$ 是否手性。
::: solution
2,3-戊二烯每个端碳上各有一个H和一个 $\mathrm{CH_3}$，处于互相垂直的平面。不存在任何镜面：任何包含C{=}C{=}C轴的平面，都会把一端的取代基反映到另一端那个垂直平面里去，对不上。分子与其镜像不能重合——**手性**，原则上可拆分，却没有立体中心。1,2-丁二烯的C1上有两个H；包含该轴以及C4的H与 $\mathrm{CH_3}$ 的平面就是镜面：C4的两个取代基原地不动，C1的两个相同氢互相对调。**非手性**。丙二烯的规则：*每*端两个不同基团，剩下的交给对称性。
:::
:::

## 立体专一性与立体选择性

::: definition 立体选择性与立体专一性反应 {#def-stereoselective}
若一个反应从给定底物优先生成某一种立体异构产物（产物比例偏向一边），称反应是**立体选择性**的；若不同的立体异构*反应物*给出不同的立体异构*产物*——即机理读取起始构型——称反应是**立体专一性**的。立体专一性是关于机理的陈述；立体选择性是关于偏好的陈述。[[organic-1/nucleophilic-substitution]] 中的SN2反应同时是两者的原型：它翻转所进攻的立体中心（立体专一），且合适的底物几乎只给一种产物（立体选择性）。
:::

把这一对词当作后续课程的词汇表来记：" $\mathrm{Br_2}$ 的加成是*反式*选择性的"——这样的句子正是要求你在预测三维产物之前先能命名它。

## 后续内容

构型是即将到来的一切机理中的常驻角色。[[organic-1/nucleophilic-substitution]] 的背面进攻一步之内把（*R*）翻成（*S*）——瓦尔登（Walden）翻转，最早证明四面体碳的反应——而同章的碳正离子化学解释了为什么有些取代反应反而外消旋化。[[organic-1/alkenes-alkynes]] 中的加成——经卤鎓离子的*反式*溴化、*同侧*硼氢化、经平面碳正离子的水合——是戴着反应箭头的立体化学习题；[[organic-1/elimination]] 则取决于E2的*反式共平面*几何。[[organic-2/carbonyl-addition]] 将展示平面羰基给出外消旋产物，直到手性试剂或催化剂打破平局；[[biochemistry/carbohydrates-lipids]] 中的糖与氨基酸是工业规模的立体化学：一个字母——D或L——就决定一种聚合物能否被消化。

::: summary
- 立体异构体连接方式相同而三维排列不同；构型异构体需断键才能互变、可分离为化合物，构象异构体则不能。
- 手性是整个分子的性质，判据是镜像可重合性；实用的对称性判据是"无镜面、无对称中心"。立体中心是局部的；两者在内消旋化合物（有立体中心而非手性）和丙二烯、阻转异构体（手性而无立体中心）中分道扬镳。
- CIP算法按原子序数排序，同位素按质量数，逐层向外比较，多重键与环用重复原子展开；*R*/*S* 与 *E*/*Z* 命名每个立体异构元素的两种排布。
- 费歇尔投影式把三维结构编码成平面图：竖直键朝后、水平键朝前；允许转 $180^\circ$、禁止转 $90^\circ$；最低优先基团在水平键上时要把表观答案取反。
- $n$ 个立体中心至多给 $2^n$ 个立体异构体；内部对称性减少数目，对称分子的 (*R*,*S*) 形式是内消旋化合物——非手性、与自身镜像相同，如酒石酸的三个立体异构体。
- 比旋光度 $[\alpha] = \alpha/(lc)$ 是有条件的物理常数；旋光可加，故 $[\alpha]_{\text{obs}}/[\alpha]_{\text{pure}} = ee$，一次旋光读数即给出对映体混合物的组成。外消旋体旋光为零。
- 当 *cis*/*trans* 找不到相同基团可比时，用 *E*/*Z* 取代；双键几何是构型，被锁在 $\pi$ 键之后。
- 旋光方向与 *R*/*S* 无关；对映体只在手性环境中性质才有差异——这正是生物学能分辨它们的原因。
:::

::: exercise 数立体异构体 {level=1 check="3"}
2,3-二溴丁烷有几个立体异构体（内消旋型只数一次）？（输入数目。）
::: solution
三个：(2*R*,3*R*)、(2*S*,3*S*) 和内消旋的 (2*R*,3*S*) ≡ (2*S*,3*R*)。两个等价立体中心使一对镜像构型坍缩成同一个非手性化合物，故 $2^2 = 4$ 的计数减一。

::: exercise 葡萄糖的观测旋光度 {level=1 check="5.27"}
D-葡萄糖的 $[\alpha]_\mathrm{D} = +52.7$（水，平衡混合物，数据表值）。称取 $10.0\ \mathrm{g}$ 配成 $100.0\ \mathrm{mL}$ 溶液。在 $1.00\ \mathrm{dm}$ 样品管中观测到多大旋光度？（以度输入 $\alpha$。）
::: solution
$c = 10.0/100.0 = 0.100\ \mathrm{g\,mL^{-1}}$，故 $\alpha = [\alpha]\, l\, c = 52.7 \times 1.00 \times 0.100 = +5.27^{\circ}$。保留三位有效数字，由数据表的旋光度决定。

::: exercise 由一次读数求对映体过量 {level=1 check="50"}
某扁桃酸（mandelic acid）样品测得 $[\alpha]_\mathrm{D} = +30.5$；纯（*R*）-扁桃酸在相同条件下 $[\alpha]_\mathrm{D} = +61.0$。该样品的 ee 是多少？（以 % 输入 ee。）
::: solution
$ee = 30.5/61.0 \times 100\,\% = 50\,\%$。样品以（*R*）为主（与纯 $R$ 同号），含 $(1+0.50)/2 = 75\,\%$ 的 ($R$) 与 $25\,\%$ 的 ($S$)。

::: exercise 标定R与S {level=2}
标定下列立体中心的构型（写出优先次序）：(a) 2-丁醇；(b) 2-氯丁烷；(c) $\mathrm{CHBrClD}$；(d) 3-溴环己烯。
::: solution
(a) $\mathrm{OH} > \mathrm{C_2H_5} > \mathrm{CH_3} > \mathrm{H}$；H背离你时OH → Et → Me顺时针，即 [[#ex-rs-butanol]] 中所画的（*R*）-2-丁醇。(b) 2-氯丁烷：$\mathrm{Cl} > \mathrm{C_2H_5} > \mathrm{CH_3} > \mathrm{H}$（乙基的CH₂带(C,H,H)，甲基的带(H,H,H)）；H在虚键上、Cl → Et → Me顺时针/逆时针的两种画法分别是（*R*）/（*S*）-2-氯丁烷。(c) $\mathrm{Br} > \mathrm{Cl} > \mathrm{D} > \mathrm{H}$——同位素按质量数。(d) $\mathrm{Br} > \mathrm{C2}$（$=\!\mathrm{CH}{-}$ 臂，重复原子后为(C,C,H)）$> \mathrm{C4}$ 臂（C,H,H）$> \mathrm{H}$；见 [[#ex-rs-ring]]。
:::

::: exercise 判断关系 {level=2}
判断下列每一对是对映体、非对映体还是同一化合物：(a) (2*R*,3*R*)-与(2*S*,3*S*)-2,3-二溴戊烷；(b) (2*R*,3*R*)-与(2*R*,3*S*)-2,3-二溴戊烷；(c) 内消旋-2,3-二溴丁烷与它的镜像；(d) (2*R*,3*S*)-与(2*S*,3*R*)-2,3-二溴丁烷。
::: solution
(a) 两个中心同时翻转、互不成镜像的镜像：对映体。(b) 一个中心翻转、一个保持：**非对映体**。(c) 内消旋化合物与自己的镜像重合：**同一化合物**——这就是内消旋的定义。(d) 与(c)相同：(2*R*,3*S*) 与 (2*S*,3*R*) 是同一个内消旋形式的两个名字，故为**同一化合物**。对(c)与(d)正是 [[#prop-2n]] 计数陷阱的缩影：$2^n$ 清单把内消旋那一栏数了两遍。
:::
:::

::: exercise 由ee求组成 {level=2 check="90"}
某（S）-氟西汀（fluoxetine）的手性合成宣称对映体过量80%（（S）-型为主）。样品中（S）-氟西汀占百分之多少？（以 % 输入（S）-型的含量。）
::: solution
$x_{(S)} = (1 + ee)/2 = (1 + 0.80)/2 = 0.90$：样品含 $90\,\%$ 的 ($S$) 与 $10\,\%$ 的 ($R$)。快速核对：超出外消旋的富余是两边各 $90 - 50 = 40$ 个百分点，而 $90 - 10 = 80$——正是 ee。
:::

::: exercise 一瓶部分外消旋化的样品 {level=3 check="25"}
一瓶标签为"（S）-布洛芬，$[\alpha]_\mathrm{D} = +61$（c 2，乙醚）"的样品在架上部分外消旋化。称取 $1.00\ \mathrm{g}$ 配成 $50.0\ \mathrm{mL}$，在 $2.00\ \mathrm{dm}$ 样品管中读得 $\alpha = +0.61^{\circ}$。瓶内物质的 ee 是多少？（以 % 输入 ee。）
::: solution
$c = 1.00/50.0 = 0.0200\ \mathrm{g\,mL^{-1}}$，故 $[\alpha]_{\text{obs}} = 0.61/(2.00 \times 0.0200) = +15.25$。于是 $ee = 15.25/61 = 0.25 = 25\,\%$。继续算下去：$x_{(S)} = (1+0.25)/2 = 0.625$，所以这 $1.00\ \mathrm{g}$ 样品含 $0.625\ \mathrm{g}$ 的 ($S$) 与 $0.375\ \mathrm{g}$ 的 ($R$)——瓶子丢掉了三分之一的旋光纯度，而旋光仪一次读数就抓住了它。
:::

::: exercise 对称性与计数 {level=3}
2,4-二溴戊烷 $\mathrm{CH_3CHBrCH_2CHBrCH_3}$ 有两个立体中心和对称的骨架。枚举它的立体异构体，用对称元素指出其中的内消旋型，并解释为什么2,3-二溴戊烷（同样两个立体中心）的数目不同。
::: solution
构型有：(2*R*,4*R*)、(2*S*,4*S*) 和 (2*R*,4*S*)。前两者互为镜像——一对对映体。(2*R*,4*S*) 中，分子有一个过C3、垂直于碳链的镜面：C3连着两条相同的臂（从两侧看都是同一构型的 $\mathrm{CHBrCH_3}$），镜面把上半反映到下半——这就是**内消旋**型，且 (2*R*,4*S*) ≡ (2*S*,4*R*)。总计：**三个**立体异构体，与酒石酸相同。2,3-二溴戊烷没有这样的镜面可用——它的两个中心带着不同的碳链（甲基/乙基对乙基/H臂），任何构型都不可能是自己的镜像，四个全部保留。教训：$2^n$ 上限能否取到，取决于*连接方式的对称性*，而不只是立体中心的数目。
:::
