碳–卤键是一份长期有效的邀请。卤素沿键把电子密度拉向自己，身后的碳因此缺电子，任何带有一对孤对电子的物种——**亲核试剂**——都可以来取用这个位置。结果就是**亲核取代反应**：一个基团在 $sp^3$ 碳上取代另一个基团，例如 $\mathrm{CH_3Br + HO^- \rightarrow CH_3OH + Br^-}$。这看起来是有机化学中最简单的反应，而且记账方式确实简单；不简单的是它*如何*发生。1935 年人们才看清，这类取代反应分为两类机理，动力学不同、立体化学不同、对结构与溶剂的敏感性也不同——而同一个反应可以被你选择的试剂条件从一类强行拉到另一类。在两者之间做出判断，是本课程中第一次真正的机理判断练习，本章将搭建整套工具：离去基团、亲核性、溶剂、底物结构，以及作为机理指纹的两条速率方程。

## 取代反应的问题

::: definition 底物、亲核试剂与离去基团 {#def-substitution}
在**亲核取代反应**中，**亲核试剂**——一个带有可用于成键的孤对电子的物种，记作 $\mathrm{Nu^-}$ 或 $\mathrm{Nu{:}}$——取代 $sp^3$ 碳上的**离去基团** $\mathrm{L^-}$，该碳称为**底物**：
$$
\mathrm{R{-}L + Nu^- \rightarrow R{-}Nu + L^-}.
$$
[[organic-1/acidity-mechanism]] 中的弯箭头记账恰好需要两根箭头：一根从亲核试剂的孤对电子指向碳，另一根从 $\mathrm{C{-}L}$ 键指向离去基团，离去基团带着电子对离开。电荷守恒：负离子亲核试剂与中性底物反应生成中性产物和负离子离去基团；中性亲核试剂（水、醇、氨）先生成正电荷加合物，必须再失去一个质子才能以中性分子结束。
:::

四个问题决定取代反应的一切，我们逐一讨论：离去基团有多好？亲核试剂有多强，"强"是不是同一回事？溶剂起什么作用？被进攻的碳有多拥挤？还有第五个问题——走哪条机理，我们怎么知道——回答方式与动力学课程一致：靠速率方程，它是关于过渡态内容的实验证据（[[kinetics/rate-laws]]）。两种机理将贯穿全章争夺你的注意力：它们叫 $\mathrm{S_N2}$ 和 $\mathrm{S_N1}$，符号里的下标和上标本身就是关于动力学的压缩断言——双分子与单分子。

## 离去基团：带走电子的那一方

取代反应使 $\mathrm{C{-}L}$ 键异裂：离去基团带着两个电子离开。一切让 $\mathrm{L^-}$ 在离开*之后*更稳定的因素——体积、可极化性、共轭、共轭酸的 $\mathrm{p}K_\mathrm{a}$ 低——都会降低断键过渡态的能量，加快反应。

::: proposition 离去能力与共轭酸强度平行 {#prop-leaving}
好的离去基团是弱碱：负离子 $\mathrm{L^-}$ 自身越稳定，它离开得越快。定量地说，离去能力跟随共轭酸 $\mathrm{HL}$ 的 $\mathrm{p}K_\mathrm{a}$——酸越强，其共轭碱越容易离去（$\mathrm{p}K_\mathrm{a}$ 数据列表）：

| 离去基团 $\mathrm{L^-}$ | 共轭酸 $\mathrm{HL}$ | $\mathrm{HL}$ 的 $\mathrm{p}K_\mathrm{a}$ | 离去能力 |
|---|---|---|---|
| $\mathrm{I^-}$ | $\mathrm{HI}$ | $-9$ | 优 |
| $\mathrm{Br^-}$ | $\mathrm{HBr}$ | $-9$ | 优 |
| $\mathrm{Cl^-}$ | $\mathrm{HCl}$ | $-7$ | 良 |
| $\mathrm{TsO^-}$、$\mathrm{MsO^-}$（磺酸根） | $\mathrm{RSO_3H}$ | $\approx -3$ 至 $-6$ | 优 |
| $\mathrm{F^-}$ | $\mathrm{HF}$ | $3.2$ | 差 |
| $\mathrm{HO^-}$ | $\mathrm{H_2O}$ | $15.7$ | 极差 |
| $\mathrm{H_2N^-}$ | $\mathrm{NH_3}$ | $\approx 38$ | 可忽略 |
| $\mathrm{R^-}$（碳负离子） | $\mathrm{R{-}H}$ | $\approx 50$ | 可忽略 |
:::

把这张表读成一句话：氢氧根、氨基负离子和碳负离子不会从碳上掉下来，因为 $\mathrm{HO^-}$、$\mathrm{NH_2^-}$ 和 $\mathrm{CH_3^-}$ 太不稳定、无法生成；碘离子、溴离子、氯离子和磺酸根则容易离去。这就是醇 $\mathrm{R{-}OH}$ 在取代之前必须*活化*的原因：要么在酸中把 $\mathrm{OH}$ 质子化，使离去基团变成中性的水，要么把它转化为**磺酸酯**。用磺化试剂如对甲苯磺酰氯（TsCl）在吡啶中处理醇，会把 $\mathrm{O{-}H}$ 上的氢换成磺酰基，得到对甲苯磺酸酯 $\mathrm{R{-}OTs}$——由于反应只触及氧、从不触及 $\mathrm{C{-}O}$ 键，碳上的构型原封不动：活化以**构型保持**的方式进行。磺酸根负离子是极好的离去基团，因为它的电荷经共轭分散在三个氧上；在三氟甲磺酸根 $\mathrm{CF_3SO_3^-}$ 中，$\mathrm{CF_3}$ 基团又追加了一层诱导吸电子；三氟甲磺酸根是已知最好的离去基团之一。

::: warning 好的亲核试剂不等于好的离去基团 {#warn-nuc-vs-lg}
这两种性质方向相反，初学者却常常把它们混为一谈。氢氧根是强亲核试剂、极差的离去基团；水是弱亲核试剂、尚可的离去基团；对甲苯磺酸酯是极好的离去基团、很弱的亲核试剂，因为它的电荷抹在三个氧上，对向碳提供电子毫无兴趣。原因是同一个稳定性论证的两个读法：亲核性问的是这对电子*递出去*的迫切程度（自由负离子的动力学性质），离去能力问的是负离子*带着电子对走掉之后*有多满足（已离去物种的性质）。碱性——对 $\mathrm{H^+}$ 的热力学亲和力——只在一族结构近似的物种内部才与亲核性相关。绝不要让"强"这个词裸奔：作为碱强、作为亲核试剂强、还是容易离去，是三种不同的断言。
:::

## SN2 机理：一步、背面进攻、构型翻转

::: proposition SN2 机理：二级动力学与构型翻转 {#prop-sn2}
$\mathrm{S_N2}$——双分子亲核取代——是一步反应：亲核试剂形成新键的同时离去基团断开旧键，经过单一过渡态，其中碳与两者都部分成键，$\bigl[\mathrm{Nu\cdots R\cdots L}\bigr]^{\ddagger}$。速率方程为二级，
$$
v = k\,\bigl[\mathrm{R L}\bigr]\bigl[\mathrm{Nu^-}\bigr],
$$
$k$ 的单位是 $\mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$：任一反应物浓度加倍，速率加倍。进攻发生在离去基团的**背面**，三个未变的取代基像伞一样翻向另一侧，因此被进攻中心的构型发生翻转——**瓦尔登翻转**。
:::

为什么是背面？[[bonding-structure/molecular-orbitals]] 给出的轨道答案：亲核试剂的电子对必须进入底物的最低未占轨道，而对 $\mathrm{R{-}L}$ 来说这就是 $\mathrm{C{-}L}$ 键的 $\sigma^{*}$ 轨道。反键轨道的大瓣位于碳上远离离去基团的一侧——从那里进攻，电子密度恰好落在正在断裂的 $\mathrm{C{-}L}$ 键上——而正面被离去基团自己的已占轨道遮蔽，会排斥来袭的电子对。动力学证据同样直接：两种反应物都出现在速率方程里，因为它们都出现在过渡态里；活化熵强烈为负，正如两个粒子合并成一个活化络合物时应有的样子。

::: example 瓦尔登翻转：标记变不变？ {#ex-walden}
(*R*)-2-溴丁烷与 $\mathrm{HO^-}$ 经 $\mathrm{S_N2}$ 反应生成丁-2-醇。产物的构型是什么？
::: solution
反应物中的优先级：$\mathrm{Br} > \mathrm{CH_2CH_3} > \mathrm{CH_3} > \mathrm{H}$。产物中：$\mathrm{OH} > \mathrm{CH_2CH_3} > \mathrm{CH_3} > \mathrm{H}$。背面进攻把 OH 放在 Br 原来位置的反面，其余三个基团穿过碳翻到另一侧，因此几何构型翻转。由于进来的 OH 继承了 Br 原来的最高优先级地位，优先级对应关系是 $1\rightarrow1$、$2\rightarrow2$、$3\rightarrow3$，翻转后的几何读作相反的构型标记：(*R*)-2-溴丁烷给出（***S***）-丁-2-醇。请注意这里究竟证明了什么：*几何*按机理翻转；构型标记的改变只是其结果，而且只是因为优先级恰好一一对应。
:::
:::

::: example 优先级陷阱：翻转了却保留字母的构型 {#ex-trap}
(*R*)-1-溴丙-2-醇 $\mathrm{HOCH_2CHBrCH_3}$ 与二乙基铜锂 $\mathrm{(C_2H_5)_2CuLi}$ 反应，这是一种碳亲核试剂，能干净地经 $\mathrm{S_N2}$ 取代二级亲电试剂。预测产物及其构型标记。
::: solution
乙基以翻转的方式取代溴负离子，得到 2-甲基丁-1-醇 $\mathrm{HOCH_2CH(C_2H_5)CH_3}$。现在排列产物的优先级：$\mathrm{CH_2OH}$（所连碳带 $\mathrm{O,H,H}$）高于 $\mathrm{C_2H_5}$（$\mathrm{C,H,H}$），因此优先级为 $\mathrm{CH_2OH} > \mathrm{C_2H_5} > \mathrm{CH_3} > \mathrm{H}$——进来的乙基排在*第二位*，位于原本就有的羟甲基之后。反应物中的优先级是 $\mathrm{Br} > \mathrm{CH_2OH} > \mathrm{CH_3} > \mathrm{H}$，所以把 1 号位的溴换成 2 号位的乙基，等于交换了前两个优先级：一次标记上的翻转恰好抵消了几何上的翻转。产物是（***R***）-2-甲基丁-1-醇——构型翻转，字母保留。构型翻转是关于空间的陈述；*R*/*S* 是关于优先级的陈述，两本账记法不同。
:::
:::

::: warning 关于翻转与外消旋化的三个误区 {#warn-inversion}
**（1）** $\mathrm{S_N2}$ 的构型*翻转*并不总是构型*标记*的反转：见[[#ex-trap]]就展示了一次翻转却保留字母 *R* 的反应；反过来——几何保持而标记改变——在优先级重新排序时同样可能发生。**（2）** "$\mathrm{S_N1}$ 给出完全外消旋化"是自由的、完全暴露于溶剂的碳正离子从两面等概率被进攻这一理想化极限。实际上，亲核试剂进攻时离去基团并未走远：**离子对**仍然遮蔽着离去基团离开的那一面，因此 $\mathrm{S_N1}$ 产物通常表现出部分翻转过量——常常是 $5$–$20\,\%$ 的对映过量——而不是完美的 50:50 混合物。完全外消旋化是分布的教科书中心，而非其常见结果。**（3）** 无论哪个词都不能告诉你*旋光方向*的任何信息：标记是对原子序数的记账，而旋光是实验事实，正如 [[organic-1/stereochemistry]] 中所确立的——翻转后的产物旋光方向可以是任意的。
:::

::: history
本章的三个奠基年份在意义上相隔一个世纪。1850 年，亚历山大·威廉姆森（Alexander Williamson）发现加热醇盐与卤代烷可得醚——威廉姆森醚合成，至今仍是构建 $\mathrm{C{-}O}$ 键的标准切断，而且在当时未被察觉的情况下，这是一个发生在饱和碳上的反应。1896 年，保罗·瓦尔登（Paul Walden）使苹果酸、氯代丁二酸及其盐之间的一系列反应循环往复，每一步都把一个对映体转化为另一个——*瓦尔登翻转*——这是碳的四个键指向四面体顶角、并能像雨伞一样里外翻出的第一个直接证据。1935 年，埃里克·休斯（Eric Hughes）与克里斯托弗·英戈尔德（Christopher Ingold）用动力学解剖了这个领域：叔丁基氯的水解是一级，且不受加入亲核试剂的影响，而溴乙烷的水解是二级；并且双分子一类发生翻转，单分子一类发生外消旋化。$\mathrm{S_N1}$ 与 $\mathrm{S_N2}$ 的命名出自这项工作，物理有机化学也由此奠基。
:::

## 空间效应：底物活性顺序

背面进攻意味着亲核试剂必须伸向一个被自身取代基半包围的碳，而过渡态在一个碳周围挤了五个基团，产物却只有四个。因此反应位点附近的每个取代基都要付出速率代价，而且代价极其高昂：

| 底物类别 | 实例 | 相对 $\mathrm{S_N2}$ 速率 |
|---|---|---|
| 甲基 | $\mathrm{CH_3Br}$ | $30$ |
| 伯 | $\mathrm{CH_3CH_2Br}$ | $1$ |
| 仲 | $\mathrm{(CH_3)_2CHBr}$ | $10^{-2}$ |
| 叔 | $\mathrm{(CH_3)_3CBr}$ | $\sim 10^{-6}$ |
| 新戊基，$\mathrm{(CH_3)_3CCH_2Br}$ | （相对 $\mathrm{CH_3CH_2Br}$） | $10^{-5}$ |

顺序 甲基 $>$ 伯 $>$ 仲 $\gg$ 叔 是关于 $\mathrm{S_N2}$ 最具预测力的单一事实：叔底物根本不做 $\mathrm{S_N2}$。新戊基一行是著名的反常——新戊基溴形式上是伯卤代烷，反应却比乙基溴慢约 $10^{5}$ 倍，因为隔一个键的叔丁基会挡在亲核试剂的进攻路线上：$\beta$-支化的影响几乎与 $\alpha$-支化一样强烈。

::: example 慢到什么程度？ {#ex-neopentyl}
在 $0.10\ \mathrm{mol\,dm^{-3}}$ 的两种反应物浓度下，乙基溴的某取代反应在 $1.0\ \mathrm{min}$ 内完成 $90\,\%$。在相同浓度与温度下，同样的反应在新戊基溴上需要多久？甲基溴比异丙基溴快多少？
::: solution
达到固定转化率所需的时间与速率成反比，因此新戊基需要 $1.0\ \mathrm{min} / 10^{-5} = 1.0\times10^{5}\ \mathrm{min}$——$10^{5}/1440 \approx 69$ 天，而乙基只要一分钟。甲基对仲是 $30 / 10^{-2} = 3000$：三千倍。$\mathrm{S_N2}$ 中的空间效应不是微调旋钮；它们横跨五个数量级，这就是底物结构是每一个预测中第一个问题的原因。
:::
:::

## SN1 机理：先电离

::: proposition SN1 机理：一级动力学、平面中间体 {#prop-sn1}
$\mathrm{S_N1}$ 是两步的逐步取代。第一步慢而且是决速步，是自发**电离**：$\mathrm{R{-}L \rightarrow R^+ + L^-}$。第二步快，是碳正离子被周围任何亲核试剂捕获——通常是溶剂。速率方程为一级，
$$
v = k\,\bigl[\mathrm{R L}\bigr],
$$
$k$ 的单位是 $\mathrm{s^{-1}}$：亲核试剂不出现在速率方程中，因为它在我们等待的过渡态之后才到场。中间体是平面 $sp^2$ 碳正离子，两面都可被进攻，因此立体中心上的取代给出外消旋化并伴随部分翻转过量。
:::

::: definition 碳正离子及其稳定性 {#def-carbocation}
**碳正离子**是正电荷位于三配位、$sp^2$ 杂化碳上的正离子：一个平面中心，带一个垂直于三个 $\sigma$ 键的空 $p$ 轨道。稳定性随烷基取代急剧升高，$3^\circ > 2^\circ \gg 1^\circ \gg$ 甲基，因为相邻的 $\mathrm{C{-}H}$ 与 $\mathrm{C{-}C}$ $\sigma$ 键把电子密度捐赠给空 $p$ 轨道（超共轭），烷基还有诱导推电子作用；烯丙基与苄基碳正离子还额外获得共轭稳定。若碳正离子能通过从相邻碳迁移一个氢负离子或烷基而得到更稳定的碳正离子，它就会迁移——**重排**——这一主题在 [[organic-1/alkenes-alkynes]] 中展开。
:::

碳正离子的稳定性顺序被电离过渡态直接继承（[[organic-1/acidity-mechanism]] 中的哈蒙德（Hammond）假说指出，过渡态与它所通向的高能中间体相似），所以 $\mathrm{S_N1}$ 遵循 $3^\circ > 2^\circ \gg 1^\circ$：恰好是 $\mathrm{S_N2}$ 所禁止的底物顺序。两种机理互为结构上的镜像——让一个拥挤的因素稳定了另一个。当溶剂本身就是亲核试剂时，反应称为**溶剂解**：水/丙酮中的水解、乙醇中的醇解，等等。溶剂解速率随溶剂电离能力的增强而急剧上升，因为过渡态比反应物更带离子性，质子性极性介质会为电荷分离买单。

::: example 一级溶剂解 {#ex-solvolysis}
$25\,^\circ\mathrm{C}$ 下水/乙醇中 2-氯-2-甲基丙烷（叔丁基氯）的溶剂解服从 $v = k\,[(\mathrm{CH_3})_3\mathrm{CCl}]$，$k = 1.00\times10^{-3}\ \mathrm{s^{-1}}$。（a）半衰期是多少？（b）反应掉 $90\,\%$ 需要多久？（c）水是最终进入产物的亲核试剂；速率方程对"在固定底物浓度下把水浓度加倍"说了什么？
::: solution
（a）一级反应，故 $t_{1/2} = \ln 2 / k = 0.693 / 1.00\times10^{-3} = 693\ \mathrm{s}$，约 $12\ \mathrm{min}$。（b）反应掉 $90\,\%$ 剩下十分之一，故 $t_{90} = \ln 10 / k = 2.303 / 1.00\times10^{-3} = 2.3\times10^{3}\ \mathrm{s}$。（c）什么也不说——速率方程里没有 $[\mathrm{H_2O}]$，因为水在决速电离*之后*才进攻。（实际上改变水的比例会改变溶剂的电离能力，从而改变 $k$ 本身；要点是*速率方程*——动力学特征——里没有亲核试剂。）这种缺席就是诊断依据：亲核试剂不在速率方程里，就不在过渡态里，而亲核试剂参与过渡态的机理——$\mathrm{S_N2}$——就被排除了。
:::
:::

## 亲核性与碱性的对比

**碱性**是热力学性质：与 $\mathrm{H^+}$ 反应的平衡位置，用 $\mathrm{p}K_\mathrm{a}$ 度量。**亲核性**是动力学性质：进攻碳的速率常数。在同一个电子倾向占主导的地方，两者相关——但也仅止于此。在元素周期表同一行中，亲核性与碱性平行：$\mathrm{NH_2^- > HO^- > F^-}$，而在烷基相匹配时 $\mathrm{RO^-}$ 强于 $\mathrm{HO^-}$——负离子总是比它自己的共轭酸更具亲核性，$\mathrm{HO^- \gg H_2O}$，因为负电荷就是被捐赠的那对电子。在**质子**溶剂中沿一列向下，顺序反转：$\mathrm{I^- > Br^- > Cl^- \gg F^-}$。原因是溶剂化：像氟离子这样小而电荷密集的负离子会抓住一层氢键结合的紧密溶剂壳，进攻之前必须把这层壳剥掉——去溶剂化代价随负离子变小而增大。大而可极化的碘离子几乎不被溶剂化，其弥散的电子云也容易变形以形成新键，因此进攻很快。在**非质子**介质中，负离子不形成氢键，卤离子的顺序大体回到碱性顺序，氟离子成为凶猛的亲核试剂。

::: quiz
在甲醇中，卤离子的 $\mathrm{S_N2}$ 亲核性由强到弱的正确排序是哪个？
- [x] $\mathrm{I^-} > \mathrm{Br^-} > \mathrm{Cl^-} > \mathrm{F^-}$
- [ ] $\mathrm{F^-} > \mathrm{Cl^-} > \mathrm{Br^-} > \mathrm{I^-}$
- [ ] $\mathrm{Cl^-} > \mathrm{Br^-} > \mathrm{I^-} > \mathrm{F^-}$
- [ ] 四者相同，因为它们都带 $-1$ 电荷
::: solution
在质子溶剂中，顺序由去溶剂化代价与可极化性决定，而非碱性：氟离子在每次碰撞中都要拖着一层紧密的溶剂壳，碘离子几乎什么都不拖，所以 $\mathrm{I^-}$ 最快、$\mathrm{F^-}$ 最慢。碱性顺序（第二个选项）在极性非质子溶剂中才是对的，那里的负离子是"裸"的——这正是要点所在：亲核性是（试剂，溶剂）*这一对*的性质，从来不是试剂单独的性质。
:::
:::

## 溶剂效应

溶剂能把取代反应的速率改变好几个数量级，而且通过两种不同的机制。**极性质子**溶剂——水、醇、羧酸——与负离子形成氢键，这*稳定了亲核试剂*、减慢 $\mathrm{S_N2}$，却又*稳定了电离的离子性过渡态与产物*、从而加速 $\mathrm{S_N1}$：这两个后果把两条途径推向相反的方向，而质子溶剂在"电离能力"与"溶剂化负离子的能力"两项上都很高。**极性非质子**溶剂——二甲基亚砜（DMSO，$\mathrm{(CH_3)_2SO}$）、二甲基甲酰胺（DMF）、丙酮、乙腈——极性足够溶解离子型试剂并通过氧或氮上的孤对电子很好地溶剂化其正离子，却不能与负离子形成氢键，负离子因此"裸奔"到场，怒不可遏。氟离子的 $\mathrm{S_N2}$ 速率从甲醇换到 DMSO 可提高多达 $10^{6}$ 倍；这一个效应就是合成化学家把负离子型 $\mathrm{S_N2}$ 反应放在 DMSO、DMF 或丙酮而不是相应醇里做的原因。实用的搭配是：强负离子亲核试剂加极性非质子溶剂做 $\mathrm{S_N2}$；弱中性亲核试剂加极性质子、高电离能力溶剂做 $\mathrm{S_N1}$。

## 两条途径竞争时

对两种机理都能走的底物——尤其是仲底物——两条速率方程直接相加：$v = k_1[\mathrm{R L}] + k_2[\mathrm{R L}][\mathrm{Nu^-}]$，而按 $\mathrm{S_N2}$ 进行的取代分数为 $k_2[\mathrm{Nu^-}]/\bigl(k_1 + k_2[\mathrm{Nu^-}]\bigr)$。提高亲核试剂浓度是一个可以连续操作的开关。

::: example 两条途径的交叉点 {#ex-compete}
某仲底物 $\mathrm{R{-}Br}$ 在 $25\,^\circ\mathrm{C}$ 的乙醇中电离，$k_1 = 2.0\times10^{-4}\ \mathrm{s^{-1}}$，与叠氮根离子的 $\mathrm{S_N2}$ 反应 $k_2 = 1.0\times10^{-2}\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$。叠氮根浓度为多少时，（a）两条途径速率相等，（b）$90\,\%$ 的取代经 $\mathrm{S_N2}$ 进行？
::: solution
（a）两速率相等即 $k_2[\mathrm{N_3^-}] = k_1$，亦即 $[\mathrm{N_3^-}] = k_1/k_2 = 2.0\times10^{-4} / 1.0\times10^{-2} = 0.020\ \mathrm{mol\,dm^{-3}}$。（b）$90\,\%$ 经 $\mathrm{S_N2}$ 需要 $k_2[\mathrm{N_3^-}] = 9k_1$，故 $[\mathrm{N_3^-}] = 9 \times 0.020 = 0.18\ \mathrm{mol\,dm^{-3}}$。这场竞争靠亲核试剂九倍而非九十倍就能取胜：交叉点对 $[\mathrm{Nu^-}]$ 是线性的，因为只有一条途径包含它。
:::
:::

## 预测反应机理

::: algorithm 预测 SN1 与 SN2 {#alg-predict}
**（1）底物。** 甲基或伯：$\mathrm{S_N2}$（新戊基型：几乎两者皆非）。叔：绝不做 $\mathrm{S_N2}$；介质若能使其电离则走 $\mathrm{S_N1}$。仲：两者都可能——继续。**（2）亲核试剂。** 强而带负电（$\mathrm{HO^-}$、$\mathrm{RO^-}$、$\mathrm{N_3^-}$、$\mathrm{CN^-}$、$\mathrm{RS^-}$、$\mathrm{I^-}$）推向 $\mathrm{S_N2}$；弱而中性（$\mathrm{H_2O}$、$\mathrm{ROH}$）只留 $\mathrm{S_N1}$ 一条路，且仅当底物能形成稳定碳正离子。**（3）溶剂。** 极性非质子（DMSO、DMF、丙酮、乙腈）有利于 $\mathrm{S_N2}$；极性质子、高电离能力（水、醇、羧酸）有利于 $\mathrm{S_N1}$。**（4）离去基团。** 未活化的 $\mathrm{OH}$、$\mathrm{OR}$ 或 $\mathrm{F}$ 意味着根本不发生取代——先活化（质子化，或转化为磺酸酯）。**（5）判定。** 伯底物 + 强亲核试剂 + 非质子溶剂：$\mathrm{S_N2}$ 且翻转。叔底物 + 弱亲核试剂 + 质子溶剂：$\mathrm{S_N1}$ 且外消旋化、可能重排。仲底物：非质子溶剂中的强亲核试剂给 $\mathrm{S_N2}$；质子溶剂中的弱亲核试剂给 $\mathrm{S_N1}$——而高温下的强*碱*会把底物交给消除反应（[[organic-1/elimination]]）。
:::

::: example 四个分类 {#ex-classify}
预测主要的取代途径，并在存在立体中心时给出立体化学结果：（a）1-溴丁烷 + $\mathrm{NaN_3}$，DMSO 中；（b）2-氯-2-甲基丙烷，水/丙酮中；（c）(*R*)-2-溴丁烷 + $\mathrm{NaI}$，丙酮中；（d）溴代环己烷 + 乙醇钠，乙醇中。
::: solution
（a）伯底物、强负离子亲核试剂、极性非质子溶剂：教科书式的 $\mathrm{S_N2}$；后处理得戊腈，不涉及立体中心。（b）叔底物、弱中性亲核试剂、电离性溶剂：$\mathrm{S_N1}$；得 2-甲基丙-2-醇，一级动力学，无立体中心。（c）仲底物配好亲核试剂但弱碱，在极性非质子溶剂中：$\mathrm{S_N2}$——芬克尔斯坦（Finkelstein）条件，生成的 $\mathrm{NaBr}$ 在丙酮中沉淀，推动平衡。碘接手溴的 1 号优先级，因此标记反转：产物是（***S***）-2-碘丁烷。（d）仲底物加强碱：取代与消除竞争，高温下消除占优——得到环己烯而不是醚；取代/消除的边界是 [[organic-1/elimination]] 的主题。
:::
:::

## 取代反应在合成中的应用

取代反应是卤代烷变成其他一切物质的途径。**腈**：氰根离子经 $\mathrm{S_N2}$ 取代伯卤代烷，$\mathrm{R{-}Br \rightarrow R{-}CN}$，增加一个碳，并把产物交给水解（羧酸）或还原（伯胺）——最常用的一碳增链。**叠氮化物**：$\mathrm{N_3^-}$ 是异常出色的 $\mathrm{S_N2}$ 试剂——强亲核而弱碱，因此即使在二级中心也能取代，而不像氢氧根或醇盐那样引起消除——有机叠氮化物经还原（[[organic-2/amines]] 中预告）转化为伯胺，而不会像直接进攻氨那样发生过度烷基化。**醚**：威廉姆森醚合成把醇盐 $\mathrm{RO^-}$ 与伯（最好：甲基或伯）卤代烷经 $\mathrm{S_N2}$ 偶联；选择位阻小的一方作卤代烷，因为叔卤代烷遇到醇盐时，醇盐扮演的是碱，于是发生消除。顺带一句安全提示：许多卤代烷是危险品——挥发性强，而且其烷基化生物分子的本领恰恰是危害所在，其中若干种被列为致癌物或疑似致癌物——这正是教学实验室在通风橱里而不是在实验台上操作它们的原因。

## 后续内容

取代反应从不独行：本章的每一个底物与碱都有一个消除反应的孪生兄弟，[[organic-1/elimination]] 将讨论 $\mathrm{S_N2}$ 与 E2 的竞争、$\mathrm{S_N1}$ 的消除对应物 E1，以及决定两者取舍的立体电子几何。这里引入的碳正离子会发生重排、加成到 $\pi$ 键上，并在 [[organic-1/alkenes-alkynes]] 中主导马氏规则；磺酸酯对醇的活化在 [[organic-1/alcohols-ethers]] 中连同环氧化合物的开环一起回归，后者是带环张力的 $\mathrm{S_N2}$ 反应。"速率方程即证据"的逻辑在 [[kinetics/reaction-mechanisms]] 与 [[kinetics/transition-state-theory]] 中定量展开，而使背面进攻成为可能的 $\sigma^{*}$ 轨道在 [[bonding-structure/molecular-orbitals]] 中讨论。

::: summary
- 亲核取代在 $sp^3$ 碳上以亲核试剂取代离去基团；弯箭头从亲核试剂的孤对电子画到碳，从 $\mathrm{C{-}L}$ 键画到离去基团。
- 离去能力与共轭酸强度平行：$\mathrm{I^-}$、$\mathrm{Br^-}$、$\mathrm{Cl^-}$ 与磺酸根容易离去；$\mathrm{HO^-}$、$\mathrm{H_2N^-}$ 与碳负离子不然——醇要先经质子化或磺酸酯化来活化，后者碳上构型保持。
- $\mathrm{S_N2}$ 是一步反应，$v = k\,[\mathrm{RL}][\mathrm{Nu^-}]$：背面进攻 $\sigma^{*}$ 轨道，瓦尔登构型翻转，底物顺序甲基 $>$ $1^\circ$ $>$ $2^\circ$ $\gg$ $3^\circ$ 横跨五个数量级，新戊基反常说明 $\beta$-支化同样算数。
- $\mathrm{S_N1}$ 是逐步反应，$v = k\,[\mathrm{RL}]$：决速电离生成平面碳正离子（$3^\circ > 2^\circ \gg 1^\circ$），因离子对遮蔽其离开的那一面而外消旋化并伴随部分翻转，只要再迁移一次就能得到更好的碳正离子就必然重排。
- 碱性是热力学的，亲核性是动力学的；同一行内亲核性与碱性平行，质子溶剂中同一列向下则反转（$\mathrm{I^- > Br^- > Cl^- \gg F^-}$），原因是去溶剂化代价。
- 极性质子溶剂通过稳定离子加速 $\mathrm{S_N1}$；极性非质子溶剂（DMSO、DMF、丙酮）使负离子不被溶剂化，把 $\mathrm{S_N2}$ 加速多达 $10^{6}$。
- 按算法预测：先看底物类别，再看亲核试剂、溶剂与离去基团；仲底物与竞争场合正是判断——以及速率方程——做决定之处。
:::

::: solution
$30 / 1 = 30$。甲基胜伯基三十倍——被两个氢替换掉的取代基就值三十倍——而伯对仲还要再乘 $100$。

::: exercise 溶剂解的半衰期 {level=1 check="693"}
某叔氯代烷在水/丙酮中的 $\mathrm{S_N1}$ 溶剂解 $k = 1.00\times10^{-3}\ \mathrm{s^{-1}}$。其半衰期是多少？（$t_{1/2}$ 以秒作答。）
::: solution
$t_{1/2} = \ln 2 / k = 0.693 / 1.00\times10^{-3} = 693\ \mathrm{s}$。一级反应，半衰期与起始底物量无关——与 $\mathrm{S_N2}$ 不同：在 $\mathrm{S_N2}$ 里底物加倍什么也不减半，亲核试剂加倍则一切加倍。
:::

::: exercise 部分翻转的对映过量 {level=1 check="40"}
某光学纯仲底物的 $\mathrm{S_N1}$ 溶剂解，产物分析显示立体中心上 $70\,\%$ 翻转、$30\,\%$ 保持。产物的对映过量是多少？（% ee 以数字作答。）
::: solution
$ee = 70 - 30 = 40\,\%$：一个对映体超出另一个的量就是翻转过量，因为翻转与保持给出同一化合物相反的两个构型标记。"完美外消旋化"的 $\mathrm{S_N1}$ 给 $0\,\%$ ee；这里的 $40\,\%$ 正是离子对效应的可见证据。
:::

::: exercise 一个 SN2 速率 {level=2 check="0.0002"}
对极性非质子溶剂中的 $\mathrm{CH_3Br + HO^- \rightarrow CH_3OH + Br^-}$，$25\,^\circ\mathrm{C}$ 时 $k = 0.040\ \mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$。当 $[\mathrm{CH_3Br}] = 0.050\ \mathrm{mol\,dm^{-3}}$、$[\mathrm{HO^-}] = 0.10\ \mathrm{mol\,dm^{-3}}$ 时，初始速率是多少？（$v$ 以 $\mathrm{mol\,dm^{-3}\,s^{-1}}$ 作答。）
::: solution
$v = k\,[\mathrm{CH_3Br}][\mathrm{HO^-}] = 0.040 \times 0.050 \times 0.10 = 2.0\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}}$。两个浓度都线性进入：任一减半，速率减半——速率方程的内容是关于过渡态的陈述。
:::

::: exercise 构型标记的算术 {level=2}
预测每个 $\mathrm{S_N2}$ 反应的产物及其构型标记，并说明每种情况下标记是否反转：（a）(*R*)-2-碘丁烷 + $\mathrm{HO^-}$；（b）(*R*)-1-溴丙-2-醇 + $\mathrm{CN^-}$（产物：3-羟基-2-甲基丙腈，$\mathrm{HOCH_2CH(CH_3)CN}$）。
::: solution
（a）反应物优先级 $\mathrm{I} > \mathrm{Et} > \mathrm{Me} > \mathrm{H}$，产物 $\mathrm{OH} > \mathrm{Et} > \mathrm{Me} > \mathrm{H}$：进来的基团继承 1 号位，几何翻转，于是标记反转——（***S***）-丁-2-醇。（b）反应物：$\mathrm{Br} > \mathrm{CH_2OH} > \mathrm{CH_3} > \mathrm{H}$。产物 C2：$\mathrm{CH_2OH}$（$\mathrm{O,H,H}$）$> \mathrm{CN}$（按重复规则为 $\mathrm{N,N,N}$——但第一圈的氧仍然胜过氮）$> \mathrm{CH_3} > \mathrm{H}$：进来的 CN 占 2 号位，相对于溴原来的次序交换了 1、2 两个优先级。几何翻转叠加一次优先级对换，得到字母的保持：（***R***）-3-羟基-2-甲基丙腈。同一机理、同样翻转的几何、不同的记账——这正是见[[#ex-trap]]的要点。
:::
:::

::: exercise 判断机理 {level=2}
$\mathrm{S_N1}$、$\mathrm{S_N2}$、两者皆可或两者皆非——并给出产物：（a）1-溴丁烷 + $\mathrm{NaCN}$，DMSO 中；（b）2-溴-2-甲基丁烷，乙醇中；（c）戊-1-醇 + $\mathrm{NaBr}$，水中；（d）(*S*)-2-溴丁烷 + $\mathrm{CH_3CO_2^-}$，DMF 中（设取代为主）。
::: solution
（a）$\mathrm{S_N2}$：伯底物、强负离子亲核试剂、极性非质子溶剂；戊腈。（b）$\mathrm{S_N1}$：叔底物、弱中性亲核试剂、电离性质子溶剂；溶剂捕获得到的乙基醚与醇，涉及立体中心处外消旋。（c）两者皆非：溴离子是好的离去基团，但底物是未活化的醇——$\mathrm{HO^-}$ 不离去；在 $\mathrm{OH}$ 被活化之前没有反应。（d）$\mathrm{S_N2}$：仲底物配中等强度的亲核试剂（乙酸根负离子因共轭而稳定、是弱碱），在极性非质子溶剂中；翻转给出（***R***）-仲丁基乙酸酯——酯的氧从溴继承 1 号优先级，因此字母反转。
:::

::: exercise 两步立体化学接力 {level=3}
(*R*)-丁-2-醇先用 TsCl 在吡啶中处理，分离得到的中间体再与 DMF 中的 $\mathrm{NaN_3}$ 反应。写出推理：中间体是什么、标记如何？最终产物是什么、标记如何？翻转发生在序列的哪一步？
::: solution
对甲苯磺酰化只取代 $\mathrm{O{-}H}$ 上的氢；$\mathrm{C{-}O}$ 键从未断裂，因此中间体是（***R***）-丁-2-基-4-甲基苯磺酸酯（*R*-2-丁基对甲苯磺酸酯）——保持。随后叠氮根在二级碳上做 $\mathrm{S_N2}$，以翻转方式取代对甲苯磺酸根；在磺酸酯和叠氮化物中，所连原子（先 O 后 N）对两条碳链都保持 1 号优先级，因此标记反转：产物是（***S***）-2-叠氮丁烷。一步保持、一步翻转：整个接力翻转了中心，而每一步各自都遵守了规则。叠氮化物还原（未问）将给出（***S***）-丁-2-胺且字母保持，因为 N 仍是 1 号。

::: exercise 交叉点的推导 {level=3}
某底物经两条途径反应，速率方程为 $v_1 = k_1[\mathrm{RL}]$（$\mathrm{S_N1}$）与 $v_2 = k_2[\mathrm{RL}][\mathrm{Nu^-}]$（$\mathrm{S_N2}$）。推导按 $\mathrm{S_N2}$ 进行的取代分数随 $[\mathrm{Nu^-}]$ 的函数，并证明达到分数 $f$ 需要 $[\mathrm{Nu^-}] = \dfrac{f}{1-f}\cdot\dfrac{k_1}{k_2}$。用见[[#ex-compete]]的常数计算 $f = 0.99$ 时的浓度。
::: solution
两条途径争夺同一底物，因此 $\mathrm{S_N2}$ 分数就是速率之比 $v_2/(v_1 + v_2) = k_2[\mathrm{Nu^-}]/\bigl(k_1 + k_2[\mathrm{Nu^-}]\bigr)$；$[\mathrm{RL}]$ 约去——产物比与底物有多少无关。令其等于 $f$ 并求解：$k_2[\mathrm{Nu^-}](1-f) = f k_1$，故 $[\mathrm{Nu^-}] = \dfrac{f}{1-f}\cdot\dfrac{k_1}{k_2}$，证毕。以 $k_1/k_2 = 0.020\ \mathrm{mol\,dm^{-3}}$、$f = 0.99$ 代入：$[\mathrm{Nu^-}] = 99 \times 0.020 = 2.0\ \mathrm{mol\,dm^{-3}}$。百分之九十九的纯度花的是百分之九十的五十倍——这种向纯度逼近的双曲线形状，就是化学家实际使用过量亲核试剂、改用非质子溶剂（提高 $k_2$）、或直接选择 $k_1$ 可忽略的底物的现实理由。
