乙醇与甲醚共享分子式 $\mathrm{C_2H_6O}$，除此之外几乎毫无共同之处：乙醇在 $351\,\mathrm{K}$ 沸腾，可与水混溶并会致醉，而甲醚在 $248\,\mathrm{K}$ 沸腾，是一种仅微溶于水的。差别在于连接方式——乙醇中氧带着一个氢（$\mathrm{CH_3CH_2{-}OH}$），甲醚中氧被楔在两个碳之间（$\mathrm{CH_3{-}O{-}CH_3}$）。一根键，$\mathrm{O{-}H}$ 对 $\mathrm{C{-}O}$，决定了沸点、溶解度与反应性；构建与断裂这些键的反应便是本章的主题，并通过张力环氧化物闭合整个循环。

## 结构、氢键与物理性质

::: definition 醇、醚与环氧化物 {#def-alcohol-ether}
**醇**的羟基 $\mathrm{-OH}$ 连在 $sp^3$ 碳上；按该碳所连碳原子的数目，醇分为**伯**（$1^\circ$）、**仲**（$2^\circ$）与**叔**（$3^\circ$）三类——丙-1-醇、丙-2-醇与 2-甲基丙-2-醇即这三类。**醚**的氧与两个碳相连，$\mathrm{R{-}O{-}R'}$；当氧与其相连的两个碳闭合成三元环时，该化合物为**环氧化物**（oxirane），是环醚中张力大且反应性极强的一支。酚（$\mathrm{Ar{-}OH}$）*不是*醇：芳环彻底改变化学性质，[[organic-1/acidity-mechanism]]已有展示。
:::

一种分子间作用力占据主导。$\mathrm{O{-}H}$ 键高度极化，其氢小而裸露，足以紧压邻近氧上的孤对电子：醇彼此**形成氢键**，断裂一个氢键（$\approx 20\,\mathrm{kJ\,mol^{-1}}$）的代价远高于断裂相近质量烷烃或醚中的色散力。

| 化合物 | 类别 | $M\,/\mathrm{g\,mol^{-1}}$ | 沸点 / $\mathrm{K}$ |
|---|---|---|---|
| 丙烷 | 烷烃 | $44.1$ | $231$ |
| 丁烷 | 烷烃 | $58.1$ | $273$ |
| 甲醚 | 醚 | $46.1$ | $248$ |
| 乙醇 | $1^\circ$ 醇 | $46.1$ | $351$ |
| 丙-2-醇 | $2^\circ$ 醇 | $60.1$ | $356$ |
| 丙-1-醇 | $1^\circ$ 醇 | $60.1$ | $370$ |
| 乙氧基乙烷（乙醚） | 醚 | $74.1$ | $308$ |
| 丁-1-醇 | $1^\circ$ 醇 | $74.1$ | $391$ |

同样的氢键解释了溶解性：前三元醇与水任意比例混溶，而每增加一个 $\mathrm{CH_2}$ 溶解度约减半——丁-1-醇仅溶至约 $1\,\mathrm{mol\,dm^{-3}}$。醚只能接受氢键而不能给出，却是极佳的溶剂——下文有机金属化学的标准介质。

**甲醇**本身毒性轻微；其代谢物却不然：醇脱氢酶将其氧化为甲醛继而甲酸根，后者破坏线粒体呼吸，损伤集中于视神经；临床解毒剂以大量乙醇竞争同一活性位点。**乙二醇** $\mathrm{HOCH_2CH_2OH}$ 味甜而致命，机理相同——被氧化为乙二酸，其钙盐在肾脏中结晶。两者均带 GHS 骷髅头急性毒性分类。

::: example 不查表排序 {#ex-bp-rank}
将丙-1-醇、丙-2-醇、乙氧基乙烷与丁烷按沸点升序排列，并解释其中两种不能自身形成氢键的化合物。
::: solution
丁烷（仅色散力）最低，$273\,\mathrm{K}$；乙氧基乙烷更重且极性，故沸点较高为 $308\,\mathrm{K}$，但因无 $\mathrm{O{-}H}$ 不能给出氢键，比其醇类异构体低 $60$–$80\,\mathrm{K}$。丙-2-醇（$356\,\mathrm{K}$）低于丙-1-醇（$370\,\mathrm{K}$）：支链更圆，色散接触面积更小。顺序：丁烷 $<$ 乙氧基乙烷 $<$ 丙-2-醇 $<$ 丙-1-醇。给体胜过受体；同类之中支化降低沸点。
:::
:::

## 醇的酸性：醇盐作为试剂

醇是弱酸——弱到在取代反应章节中其酸性不可见，又强到其共轭碱是合成中最有用的试剂之一。列表如下（本课程采用值）：

| 酸 | $\mathrm{p}K_\mathrm{a}$ | 共轭碱 |
|---|---|---|
| 苯酚 | $10.0$ | 苯氧负离子 |
| 水 | $15.7$ | 氢氧根 |
| 乙醇 | $16$ | 乙氧负离子 |
| 丙-2-醇 | $17$ | 异丙氧负离子 |
| 2-甲基丙-2-醇 | $18$ | *叔*丁氧负离子 |
| 乙炔 | $25$ | 乙炔负离子 |
| 氢气 $\mathrm{H_2}$ | $35$ | 氢负离子 |
| 氨 | $38$ | 氨基负离子 |

::: proposition 醇是弱酸；醇盐是强碱也是良好亲核试剂 {#prop-alcohol-acidity}
醇在 $\mathrm{p}K_\mathrm{a} \approx 16$–$18$ 去质子化——酸性与水相当，弱于苯酚（后者因共振取胜）。平衡规则有两个推论。**(1)** 醇盐在水中无法存活：*叔*丁氧负离子被水质子化，$K_\mathrm{eq} = 10^{18 - 15.7} = 2\times10^{2}$，乙氧负离子同向 $K_\mathrm{eq} \approx 2$——在水中一切醇盐都变成氢氧根。**(2)** 要*制备*醇盐，需要共轭酸远弱于醇的碱：氢负离子（$K_\mathrm{eq} = 10^{35 - 16} = 10^{19}$，$\mathrm{H_2}$ 以气体逸出）或氨基负离子（$10^{22}$）。醇盐既是强碱又是良好的负离子亲核试剂——对伯卤代烃按 $\mathrm{S_N2}$ 取代，对其余一切发生消除，[[organic-1/elimination]]的竞赛规则已有规定。体积增大使差别更尖锐：*叔*丁氧负离子是差的亲核试剂、极佳的选择性碱。
:::

::: example 醇盐溶液的 pH {#ex-alkoxide-ph}
将乙醇钠 $0.010\,\mathrm{mol\,dm^{-3}}$ 溶于水。pH 为多少？对乙氧负离子，$K_\mathrm{b} = K_\mathrm{w}/K_\mathrm{a}(\mathrm{ethanol})$。
::: solution
$K_\mathrm{b} = 10^{-14}/10^{-16} = 10^{2}$——对碱而言极大，因为乙醇是极弱的酸。解 $x^{2}/(0.010 - x) = 100$ 得 $x = 0.009999\,\mathrm{mol\,dm^{-3}}$：质子化基本完全，正如[[#prop-alcohol-acidity]]所预测，故 $[\mathrm{HO^-}]$ 等于分析浓度，$\mathrm{pOH} = 2.00$，$\mathrm{pH} = 12.00$。乙醇钠在水中*就是*氢氧化钠，且是化学计量意义上的。
:::
:::

::: example 选择制备乙醇钠的碱 {#ex-choose-ethoxide}
用平衡常数判断：氢氧根、氢负离子（$\mathrm{NaH}$）、氨基负离子（$\mathrm{NaNH_2}$）或乙炔负离子（$\mathrm{HC{\equiv}C^-}$）能否将乙醇"完全"转化为乙氧负离子（完全指 $K_\mathrm{eq} > 10^{3}$）。
::: solution
每个反应均为 $\mathrm{CH_3CH_2OH + B^- \rightleftharpoons CH_3CH_2O^- + HB}$，$K_\mathrm{eq} = 10^{\mathrm{p}K_\mathrm{a}(\mathrm{HB}) - 16}$。氢氧根：$K_\mathrm{eq} = 10^{15.7 - 16} = 0.5$——掷硬币，无法用于制备。氢负离子：$K_\mathrm{eq} = 10^{35 - 16} = 10^{19}$，且 $\mathrm{H_2}$ 冒泡逸出——标准选择。氨基负离子：$K_\mathrm{eq} = 10^{38 - 16} = 10^{22}$，大材小用但完全。乙炔负离子：左边酸是乙醇（$16$），右边是乙炔（$25$），故 $K_\mathrm{eq} = 10^{16 - 25} = 10^{-9}$：乙炔负离子被乙醇*摧毁*。平衡朝更弱的酸方向移动。
:::
:::

## 醇的制备

三条路线占主导。**烯烃水合**（[[organic-1/alkenes-alkynes]]）：含酸水溶液按马氏规则经碳正离子加上 $\mathrm{H}$ 与 $\mathrm{OH}$（可能重排）；硼氢化–氧化则反马氏加上，无正离子、无重排。**羰基化合物还原**：$\mathrm{NaBH_4}$ 与 $\mathrm{LiAlH_4}$ 将氢负离子送至极化的 $\mathrm{C{=}O}$ 碳，氧质子化即得醇；$\mathrm{NaBH_4}$ 温和，可在醇中使用，止于醛与酮，而 $\mathrm{LiAlH_4}$ 还能还原酯与酸，但遇水即毁，故须在干醚中进行。**格氏加成**：$\mathrm{RMgX}$ 所携碳表现为 $\mathrm{R^{\delta-}}$——其共轭酸 $\mathrm{p}K_\mathrm{a} \approx 50$ 的碳负离子等价体；它加成到羰基碳上构建 $\mathrm{C{-}C}$ 键（甲醛 $\rightarrow 1^\circ$，醛 $\rightarrow 2^\circ$，酮 $\rightarrow 3^\circ$），并被任何 $\mathrm{O{-}H}$ 瞬间淬灭——故玻璃仪器须干燥，醇只能是产物而绝非常溶剂。机理见[[organic-2/carbonyl-addition]]。

::: algorithm 选择通往醇的切断 {#alg-alcohol-disconnection}
按顺序倒推。**(1) 定出连羟基的碳**（带 $\mathrm{OH}$ 的碳）并分类为 $1^\circ$、$2^\circ$ 或 $3^\circ$。**(2) 尝试 C–C 切断**：$3^\circ$ 醇最多有三种切断方式得酮 + $\mathrm{RMgX}$，$2^\circ$ 得醛 + $\mathrm{RMgX}$，$1^\circ$ 得甲醛 + $\mathrm{RMgX}$；弃去任何携带 $\mathrm{-OH}$、$\mathrm{-NH}$、$\mathrm{-SH}$ 或羰基的格氏试剂，因为它们会摧毁试剂。**(3) 尝试还原**：若将连羟基碳上的 $\mathrm{C{-}H}$ 或 $\mathrm{C{-}C}$ 键换成对 O 的 $\pi$ 键后得到同骨架的羰基化合物，则选 $\mathrm{NaBH_4}$（醛/酮级）或 $\mathrm{LiAlH_4}$（酯或酸级，无水）。**(4) 尝试水合**：酸催化得马氏产物，硼氢化–氧化得反马氏产物。**(5) 检查细则**：重排决定酸催化水合可用与否；格氏路线要求其余基团均无质子。
:::

::: example 一个醇的两种切断 {#ex-grignard-plan}
为 2-甲基丁-2-醇 $\mathrm{(CH_3)_2C(OH)CH_2CH_3}$ 提出两条格氏路线，并说明由 3-羟基丁-2-酮加甲基溴化镁出发的路线为何失败。
::: solution
断开连羟基碳上三个基团之一。**(a)** 断乙基：丙酮 + 乙基溴化镁，再水系后处理。**(b)** 断甲基：丁-2-酮 + 甲基溴化镁。三个取代基中有两个相同，故只有两组不同的组合。所提路线栽在细则上：3-羟基丁-2-酮带 $\mathrm{O{-}H}$，而格氏试剂——其共轭酸 $\mathrm{p}K_\mathrm{a} \approx 50$ 的碱——被它淬灭（$K_\mathrm{eq} \approx 10^{50-16} = 10^{34}$），远快于对羰基的加成。
:::
:::

## 把 OH 变成离去基团

::: warning 氢氧根不离去——"氧化"也与氧气无关 {#warn-oh-leaving}
本节旨在清除三个误解。**(1)** *醇能取代是因为 $\mathrm{OH}$ 能离去。* $\mathrm{HO^-}$ 位于[[organic-1/nucleophilic-substitution]]离去基团表的最底端（共轭酸 $\mathrm{p}K_\mathrm{a} = 15.7$）：它绝不会自行离开 $sp^3$ 碳。先活化——质子化使离去基团成为中性的水，或转化为磺酸酯，其负离子把电荷铺在三个氧上。**(2)** *磺酰化使碳构型翻转或外消旋。*两者皆非：$\mathrm{TsCl}$ 在氧上反应，$\mathrm{C{-}O}$ 键从未断裂，构型保持；翻转发生在稍后的 $\mathrm{S_N2}$ 步骤。**(3)** *"氧化"就是与 $\mathrm{O_2}$ 反应。*氧化指碳失去电子密度——增加与电负性原子的键或减少 $\mathrm{C{-}H}$；本章的氧化剂是不含氧气分子的盐，如重铬酸盐(VI)。
:::

**质子化与 HX。** 浓氢卤酸将醇转化为卤代烃：$\mathrm{R{-}OH + HX \rightarrow R{-}X + H_2O}$。叔醇按 $\mathrm{S_N1}$ 进行——自由正离子意味着可能重排、可能外消旋；伯醇按 $\mathrm{S_N2}$，干净且不重排。**磺酸酯。** 对甲苯磺酰氯（$\mathrm{TsCl}$）在吡啶中将 $\mathrm{O{-}H}$ 的氢替换为磺酰基，得甲苯磺酸酯 $\mathrm{R{-}OTs}$，$\mathrm{C{-}O}$ 键与手性中心原封不动——活化伴随**保持**；随后亲核试剂按 $\mathrm{S_N2}$ 取代极佳的甲苯磺酸根离去基团（共轭酸 $\mathrm{p}K_\mathrm{a} \approx -3$），并发生翻转。**$\mathrm{PBr_3}$ 与 $\mathrm{SOCl_2}$** 在一口瓶中把伯、仲醇变为溴代物与氯代物，标准 $\mathrm{PBr_3}$ 情形下碳上构型翻转。

::: example 双重翻转接力 {#ex-double-inversion}
（*R*）-丁-2-醇与 $\mathrm{TsCl}$ 在吡啶中反应；分离得到的中间体再与 $\mathrm{NaBr}$ 在 DMF 中搅拌。给出中间体与产物及其各自构型标记，并指出哪里发生了翻转、哪里没有。
::: solution
第一步只触及氧：中间体为（***R***）-丁-2-基 4-甲基苯磺酸酯——碳上保持，因为 $\mathrm{C{-}O}$ 键从未断裂。第二步是教科书式 $\mathrm{S_N2}$：溴离子从磺酸酯的背面进攻 C2，磺酸根携电子对离去——翻转。连上的溴继承被它取代的氧的 1 号优先权，故标记随几何构型一起翻转：产物为（***S***）-2-溴丁烷。先保持、后翻转——总体翻转，每一步都是[[organic-1/nucleophilic-substitution]]的规则。
:::
:::

## 醇的氧化

有机化学中氧化的诚实定义是碳上的记账：每个与更强电负性原子的键记 $+1$，每个与氢的键记 $-1$（$\mathrm{C{-}C}$ 键记零）。氧化使数值升高，还原使其降低，烧瓶旁并不需要 $\mathrm{O_2}$。

::: proposition 醇的氧化阶梯 {#prop-oxidation-ladder}
醇氧化脱去 $\mathrm{O{-}H}$ 质子与连羟基碳上的一个 $\mathrm{C{-}H}$：**$1^\circ$ 醇先氧化为醛、再氧化为羧酸；$2^\circ$ 醇氧化为酮即止；$3^\circ$ 醇不氧化**，因为连羟基的碳没有氢可脱。醛的中停是条件问题：强水相氧化剂如酸化重铬酸盐(VI)氧化的不是醛本身而是其*水合物*——水加过 $\mathrm{C{=}O}$ 形成的偕二醇——故在水中反应直达羧酸；无水氧化剂如氯铬酸吡啶盐（PCC）从不让水合物形成，醛即分离产物。每级台阶都是两电子氧化：乙醇连羟基碳走 $-1 \rightarrow +1 \rightarrow +3$。
:::

::: example 记账实演 {#ex-ox-bookkeeping}
指认下列化合物中官能化碳的氧化数：(a) $\mathrm{CH_3CH_2OH}$、$\mathrm{CH_3CHO}$、$\mathrm{CH_3COOH}$；(b) 丙-2-醇、丙酮；(c) 2-甲基丙-2-醇，并用这些数字解释丙酮为何抗进一步氧化而乙醛不然。
::: solution
(a) 乙醇连羟基碳：一键连 O、两键连 H：$-1$。乙醛：两键连 O、一键连 H：$+1$。乙酸：三键连 O：$+3$。每级 $+2$——两电子氧化。(b) 丙-2-醇：$0$；丙酮：$+2$。(c) 2-甲基丙-2-醇：$+1$，且无 $\mathrm{C{-}H}$ 可失——醇氧化的第一步无从发生，这正是叔醇惰性的结构原因。丙酮在更高一级因同样原因抵抗——其羰基碳也无氢——而乙醛保留其 $\mathrm{C{-}H}$，继续攀升。
:::
:::

## 醚

::: proposition 威廉姆森醚合成 {#prop-williamson}
醚按 $\mathrm{S_N2}$ 装配：醇盐 $\mathrm{RO^-}$ 从另一片段上取代卤离子或磺酸根，$\mathrm{R'{-}X + RO^- \rightarrow R'{-}OR + X^-}$。因该步为 $\mathrm{S_N2}$，**卤代烃必须是甲基或伯**（仲的慢且与 E2 竞争；叔的绝不可行——醇盐以碱的身份相遇，产物是[[organic-1/elimination]]的烯烃）。切断规则：把*位阻小*的片段放在卤代烃一侧，取代多的放在氧一侧。对立方法——两分子伯醇酸催化缩合——同样类 $\mathrm{S_N2}$ 且是温度竞赛：低温利醚，高温利脱水成烯。醚本身极其惰性——碱、氢化物与格氏试剂的标准*溶剂*；只有热浓氢卤酸才能断裂它们。
:::

::: example 设计威廉姆森合成 {#ex-williamson-design}
如何经威廉姆森路线制备 (a) 1-甲氧基丁烷与 (b) 2-甲氧基-2-甲基丙烷（MTBE，燃料添加剂）？对每一例，说明"显然的"另一种切断错在何处。
::: solution
(a) 这里两种切断都可行，因为候选卤代烃都是甲基或伯：甲氧负离子 + 1-溴丁烷，或丁氧负离子 + 溴甲烷；常用前者因为 1-溴丁烷便宜。(b) 显然的切断——*叔*丁基溴 + 甲氧负离子——彻底失败：叔卤代烃加强碱得 E2，产物是 2-甲基丙烯。反过来：甲基卤（甲基无法消除）+ *叔*丁氧负离子，$\mathrm{(CH_3)_3CO^- + CH_3I \rightarrow (CH_3)_3C{-}O{-}CH_3}$。[[#prop-williamson]]的规则：位阻大的片段搭载在氧上。
:::
:::

- [ ] 2-溴丙烷 + 乙醇钠，因为仲卤代烃在 $\mathrm{S_N2}$ 中最活泼。
::: solution
选项 2：负离子亲核试剂加伯卤代烃正是 $\mathrm{S_N2}$ 配方，且恰好接起目标分子的两个骨架。选项 1 接错骨架——异丙氧负离子 + 溴乙烷得乙基异丙基醚。选项 3 失败，因为中性乙醇作为亲核试剂太弱。选项 4 把仲卤代烃与强碱放在一起，E2 胜出：得丙烯而非醚——[[#prop-williamson]]的失败模式。
:::
:::

::: history
1850 年，亚历山大·威廉姆森（Williamson）发表了以其名字命名的合成——醇盐与卤代烷共热——首次暗示饱和碳上的取代自有其规则；他是在纠正查尔斯·武兹（Wurtz），后者稍早关于醚的工作（以及仍以他命名的卤代烃钠偶联）已表明烷基会迁移到氧上。1859 年武兹还由乙烯氯醇与碱制得第一个环氧化物——环氧乙烷——即此后每门课程都在讲授的同一分子内闭环。一个世纪后环氧乙烷成为工业巨人：银催化乙烯氧化，经开环聚合支撑起百万吨级的聚乙二醇生产，而该气体的直接用途（灭菌、熏蒸）随其被确立为人类致癌物（IARC 1 类）而收缩。现代回声是 1980 年代巴里·夏普莱斯（Sharpless）的烯丙醇不对称环氧化——定向制造单一环氧化物对映体——荣获 2001 年诺贝尔化学奖的一半。
:::

## 环氧化物：张力环，慷慨的反应性

::: definition 环氧化物及其生成 {#def-epoxide}
**环氧化物**（oxirane）是氧与两个碳构成三元环的醚：$\mathrm{C{-}O{-}C}$ 角被强行压到约 $60^\circ$，而四面体偏好为 $109.5^\circ$，环张力——环氧乙烷本身列表值约 $113\,\mathrm{kJ\,mol^{-1}}$——是开环时释放的储存驱动力。两种标准生成法，均由烯烃而来（[[organic-1/alkenes-alkynes]]）。**过氧酸环氧化**：$\mathrm{RCO_3H}$ 以一步协同将 O 原子转移给双键，两个新 $\mathrm{C{-}O}$ 键在同一面生成——*顺*式且立体专一。**卤代醇闭环**：先加 $\mathrm{X_2}$ 与水（卤鎓离子在取代较多的碳被水打开，反式），再加碱——醇盐对相邻 $\mathrm{C{-}X}$ 碳作分子内 $\mathrm{S_N2}$，逐出卤离子；两步净结果为氧对双键的反式加成。
:::

::: proposition 环氧化物开环：条件选择碳 {#prop-epoxide-opening}
环氧化物在两种条件下都能与亲核试剂反应，二者对不对称环氧化物给出相反的区域化学。**碱性条件**（$\mathrm{Nu^-}$：氢氧根、醇盐、胺）：亲核试剂对**取代较少**的环碳作 $\mathrm{S_N2}$ 进攻——位阻决定——该碳翻转；醇盐产物被溶剂质子化。**酸性条件**（$\mathrm{ROH}$ 加强酸催化）：环氧化物的氧先质子化，亲核试剂进攻**取代较多**的碳，它在过渡态中承载较多正电荷（部分碳正离子特征，但无自由正离子——不重排，且被进攻的碳仍翻转）。酸中的水开环得*反式*（anti）**1,2-二醇**。
:::

::: warning 环氧化物区域化学随条件翻转 {#warn-epoxide-regio}
第一课程有机化学中最常被忽略的一次符号变化：*同一个不对称环氧化物，溶液呈碱性还是酸性决定它从哪一端打开。*碱性条件下亲核试剂已充分生成、位阻掌权——它进攻位阻较小的碳，"取代较多的碳更亲电"给出错误产物。酸性条件下亲核试剂中性而弱、环氧化物已质子化、电子效应掌权——取代较多的碳带电荷而被进攻，"位阻小者胜"再次出错。两种机制共享一个立体化学事实：进攻来自被断裂 $\mathrm{C{-}O}$ 键的背面，故被进攻的碳翻转，新基团呈*反式*。环氧化物也不是"普通醚"：乙醚对乙醇钠安然无恙；张力环氧化物则会反应，$113\,\mathrm{kJ\,mol^{-1}}$ 的张力释放买单。
:::

::: example 一种环氧化物，两种产物 {#ex-epoxide-regio}
预测 1,2-环氧丁烷与 (a) 甲醇中 $\mathrm{NaOCH_3}$、(b) 含少量硫酸的甲醇反应的主产物。命名每一产物并指认被进攻的碳。
::: solution
环氧化物碳为 C1（$\mathrm{CH_2}$ 端，伯）与 C2（仲，连乙基）。**(a)** 碱性：甲氧负离子按 $\mathrm{S_N2}$ 进攻位阻较小的 C1；环氧氧留在 C2 上并被甲醇质子化。产物：$\mathrm{CH_3OCH_2CH(OH)CH_2CH_3}$，**1-甲氧基丁-2-醇**。(b) 酸性：质子化环氧化物把大部分正电荷放在 C2；中性甲醇进攻 C2，环氧氧成为 C1 的醇。产物：$\mathrm{HOCH_2CH(OCH_3)CH_2CH_3}$，**2-甲氧基丁-1-醇**。同样的原子，相反的连接——[[#warn-epoxide-regio]]的翻转——且两种情形中亲核试剂都从离去的 $\mathrm{C{-}O}$ 键的反面到达。
:::
:::

一条安全注记：最简单的环氧化物也最危险。环氧乙烷在 $284\,\mathrm{K}$ 沸腾——室温即为气体——极易燃，被列为人类致癌物（IARC 1 类）与致突变物，其烷基化反应性正是上文开环化学在 DNA 上的演出。使用仅限封闭系统；本章较大的环氧化物是挥发性易燃液体，在通风橱中操作。

## 后续内容

本章是第一课程各章会师之地：[[organic-1/alkenes-alkynes]]的烯烃把醇送进来，[[organic-1/elimination]]把它们再送出去，[[organic-1/nucleophilic-substitution]]的机械装置运转其间每一次互变。此处许诺的还原与格氏加成在[[organic-2/carbonyl-addition]]中逐箭头剖析，氧化阶梯的羧酸终点在[[organic-2/carboxylic-derivatives]]中自成化学，胺的类似物贯穿[[organic-2/amines]]重现。此后的合成题，就是在互变图上的行走。

::: summary
- 醇按连羟基碳分 $1^\circ/2^\circ/3^\circ$；醚以氧连接两个碳；环氧化物是张力环醚（$\approx 113\,\mathrm{kJ\,mol^{-1}}$）。乙醇（$351\,\mathrm{K}$）与甲醚（$248\,\mathrm{K}$）是相差 $103\,\mathrm{K}$ 的 $\mathrm{C_2H_6O}$ 异构体，因为只有醇能给出氢键。
- 醇在 $\mathrm{p}K_\mathrm{a} = 16$–$18$ 附近去质子化；醇盐是强碱与良好亲核试剂，在水中无法存活，须以 $\mathrm{NaH}$（$K_\mathrm{eq} = 10^{19}$，$\mathrm{H_2}$ 逸出）或氨基负离子制备。
- 醇来自烯烃水合（经正离子得马氏，硼氢化得反马氏）、羰基还原（$\mathrm{NaBH_4}$ 温和，$\mathrm{LiAlH_4}$ 怕水）与格氏加成——后者构建 $\mathrm{C{-}C}$ 键却被任何 $\mathrm{O{-}H}$ 摧毁。
- $\mathrm{HO^-}$ 绝不离开 $sp^3$ 碳：以质子化活化（$3^\circ$ 走 $\mathrm{S_N1}$ 有重排风险，$1^\circ$ 走 $\mathrm{S_N2}$）或以磺酸酯化活化——磺酰化在碳上保持，随后的 $\mathrm{S_N2}$ 取代翻转。
- 氧化是 C–H/O 记账：$1^\circ \rightarrow$ 醛 $\rightarrow$ 酸（强水相氧化剂经水合物进行；无水 PCC 止于醛），$2^\circ \rightarrow$ 酮，$3^\circ$ 因缺连羟基碳 $\mathrm{C{-}H}$ 而惰性。
- 威廉姆森醚合成是 $\mathrm{S_N2}$：醇盐加甲基或伯卤代烃，绝不用叔（E2 胜）；伯醇酸催化缩合与成烯反应随温度竞争。
- 环氧化物碱性下在取代较少的碳开环，酸性下在取代较多的碳开环（部分正离子特征），始终反式加成；水解得反式 1,2-二醇。
- 危害分类层面：甲醇与乙二醇经氧化代谢物（甲酸根；乙二酸根）中毒；环氧乙烷是易燃致癌气体——仅限封闭系统。
:::

## 练习

::: exercise 醚的同分异构体 {level=1 check="3"}
分子式 $\mathrm{C_4H_{10}O}$ 的无环醚构造异构体有多少个？（输入数字。）
::: solution
三个：1-甲氧基丙烷、2-甲氧基丙烷与乙氧基乙烷。把四个碳按氧两侧 $1+3$（直链或支链丙基）或 $2+2$ 分配：三种醚；$\mathrm{C_4H_{10}O}$ 的其余异构体是醇。
:::
:::

::: exercise 叔丁醇钠溶液的 pH {level=1 check="12"}
将*叔*丁醇钠 $0.010\,\mathrm{mol\,dm^{-3}}$ 溶于水。已知 $\mathrm{p}K_\mathrm{a}$(2-甲基丙-2-醇) $= 18$，pH 为多少？（输入 pH。）
::: solution
$K_\mathrm{b} = 10^{-14}/10^{-18} = 10^{4}$：水的质子化完全，$[\mathrm{HO^-}] = 0.010\,\mathrm{mol\,dm^{-3}}$，$\mathrm{pH} = 12.00$——与乙氧负离子同解（见[[#ex-alkoxide-ph]]）：任何比氢氧根强的碱都被水拉平为氢氧根。
:::
:::

::: exercise 氧化数台阶 {level=1 check="2"}
丙-2-醇氧化为丙酮时，官能化碳的氧化数变化是多少？（输入失去的电子数，正整数。）
::: solution
丙-2-醇连羟基碳：一键连 O、一键连 H $\rightarrow 0$。丙酮：两键连 O $\rightarrow +2$。变化为 $+2$：每一步醇 $\rightarrow$ 羰基都是两电子氧化，与[[#ex-ox-bookkeeping]]的阶梯一致。
:::
:::

::: exercise 氢氧根对乙醇 {level=2 check="0.5"}
用平衡规则计算 $\mathrm{CH_3CH_2OH + NaOH \rightleftharpoons CH_3CH_2O^-\,Na^+ + H_2O}$ 的 $K_\mathrm{eq}$，$\mathrm{p}K_\mathrm{a}$ 取 $16$（乙醇）与 $15.7$（水）。（输入 $K_\mathrm{eq}$。）
::: solution
$K_\mathrm{eq} = 10^{15.7 - 16} = 10^{-0.3} = 0.5$。平衡停在*更弱的酸*一边——乙醇是更弱的酸，故氢氧根让大部分乙醇保持质子化。$0.5$ 不是制备方法；这就是该拿 $\mathrm{NaH}$ 而非 $\mathrm{NaOH}$ 的原因。
:::
:::

::: exercise 水中的醇盐，定量地 {level=2 check="200"}
计算 $\mathrm{(CH_3)_3CO^- + H_2O \rightleftharpoons (CH_3)_3COH + HO^-}$ 的 $K_\mathrm{eq}$，$\mathrm{p}K_\mathrm{a}$ 取 $18$（2-甲基丙-2-醇）与 $15.7$（水）。这个数字对"叔丁醇钾溶于水"说明了什么？（输入 $K_\mathrm{eq}$。）
::: solution
$K_\mathrm{eq} = 10^{18 - 15.7} = 10^{2.3} = 2\times10^{2}$。两百倍地偏向氢氧根：叔丁醇钾在水中不能以本来面目存在——溶液就是氢氧化钾加叔丁醇——醇盐化学是*醇中*醇盐的化学。
:::
:::

::: exercise 预测产物 {level=2}
给出主有机产物：(a) 1-溴丁烷 + 甲醇中甲醇钠；(b) 2-溴-2-甲基丙烷 + 甲醇中甲醇钠；(c) 丁-1-烯，1. $\mathrm{RCO_3H}$，2. 含酸水溶液。
::: solution
(a) 丁基甲基醚 $\mathrm{CH_3OCH_2CH_2CH_2CH_3}$：伯卤代烃 + 强亲核试剂 = 威廉姆森 $\mathrm{S_N2}$。(b) 2-甲基丙烯：叔卤代烃 + 强碱 = E2，正是[[#prop-williamson]]的失败模式。(c) 丁烷-1,2-二醇：过氧酸给 1,2-环氧丁烷（顺式 O 转移），含酸水溶液将其水解为*反式* 1,2-二醇；对端基环氧化物，[[#warn-epoxide-regio]]的两种机制殊途同归于同一二醇。
:::
:::

::: exercise 氢负离子的算术 {level=3}
对 $\mathrm{CH_3CH_2OH + NaH \rightarrow CH_3CH_2O^-Na^+ + H_2}$，取 $\mathrm{p}K_\mathrm{a}(\mathrm{H_2}) = 35$、$\mathrm{p}K_\mathrm{a}$(乙醇) $= 16$、$298\ \mathrm{K}$。计算 $K_\mathrm{eq}$ 与 $\Delta_\mathrm{r}G^\circ$，并准确说明逸出的 $\mathrm{H_2}$ 在平衡数字已言明的之外还增添了什么。
::: solution
$K_\mathrm{eq} = 10^{35 - 16} = 10^{19}$。取 $R = 8.314\ \mathrm{J\,mol^{-1}\,K^{-1}}$：$\Delta_\mathrm{r}G^\circ = -RT\ln K_\mathrm{eq} = -8.314 \times 298 \times 19 \times 2.303 = -1.08\times10^{5}\ \mathrm{J\,mol^{-1}} \approx -108\ \mathrm{kJ\,mol^{-1}}$。该数字描述*封闭*容器的平衡。气体改变了记账：$\mathrm{H_2}$ 以气泡离开溶液，逆反应永远找不到搭档，转化在实际中进行到底——开放系统形式的勒夏特列原理。
:::
:::

::: exercise 一种烯烃的三种产物 {level=3}
以丁-1-烯及任意无机或一碳试剂出发，提出 (a) 丁烷-1,2-二醇、(b) 1-甲氧基丁-2-醇与 (c) 2-甲氧基丁-1-醇的合成路线。论证每一区域化学结果。
::: solution
共同第一步：丁-1-烯 + $\mathrm{RCO_3H}$ $\rightarrow$ 1,2-环氧丁烷（协同顺式 O 转移；卤代醇路线——$\mathrm{Br_2/H_2O}$ 后加碱——亦可）。**(a)** 含酸水溶液（或碱）：水开环再质子化得丁烷-1,2-二醇；对端基环氧化物，两种机制给出同一二醇。**(b)** $\mathrm{NaOCH_3/CH_3OH}$：碱性 $\mathrm{S_N2}$ 进攻位阻较小的 C1——1-甲氧基丁-2-醇。**(c)** $\mathrm{CH_3OH}$ 加强酸催化：质子化环氧化物，进攻取代较多的 C2——2-甲氧基丁-1-醇。(b)/(c) 一对即[[#prop-epoxide-opening]]在同一底物上的区域化学翻转；两产物均在被进攻碳上以反式立体化学生成。
:::
