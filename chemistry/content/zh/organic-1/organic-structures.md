有机化学是碳化合物的化学，而它的第一个技能，是熟练使用化学工作者真正使用的那套缩写记法。没有人会把一个大分子的每个碳、每个氢都画出来；我们画的是**键线式**：每个顶点和线段末端都代表一个碳，碳上的氢由化合价隐含。官能团——分子中反应的部分——则明确画出，因为化学就发生在那里。这一课建立这套词汇：碳为什么能产生如此多的化合物、编码这些化合物的记法、决定其反应性的官能团，以及把结构变成唯一名称、又能变回去的 IUPAC 命名系统。本课程后续的一切——构象、立体化学、机理——都用这套记法书写，所以这里花的功夫会在之后的每一课里得到回报。

## 碳，以及为什么化合物如此之多

::: definition 四价与成链性 {#def-tetravalence}
碳是四价的：它在稳定的中性化合物中形成四个键。其价电子构型 $2s^2 2p^2$ 可杂化为 $sp^3$、$sp^2$ 或 $sp$，键角分别约为 $109.5^\circ$、$120^\circ$ 和 $180^\circ$。碳还极擅长**成链性**（catenation）——以长链和环与自身成键——因为 $\mathrm{C{-}C}$ 键很强（$\approx 348\ \mathrm{kJ\,mol^{-1}}$），而其他元素可利用的替代方式并不会使链失稳。硅也能成链，但硅–硅键较弱、硅–氧键又太强，于是硅的化学走向了硅酸盐，而不是生命。
:::

支撑这一说法的数字值得大致记住，因为它们在第一根弯箭头画出来之前，就解释了这门学科的两大反应模式。典型的键长与平均键解离焓（标准数据表值）如下：

| 键 | 键长 / $\mathrm{pm}$ | $\bar{D}/\mathrm{kJ\,mol^{-1}}$ |
|---|---|---|
| $\mathrm{C{-}C}$ | 154 | 348 |
| $\mathrm{C{=}C}$ | 134 | 614 |
| $\mathrm{C{\equiv}C}$ | 120 | 839 |
| $\mathrm{C{-}H}$ | 109 | 413 |
| $\mathrm{C{-}O}$ | 143 | 358 |
| $\mathrm{C{=}O}$ | 123 | 745 |
| $\mathrm{C{-}Cl}$ | 177 | 338 |

把第二、三行合起来读：一个 $\pi$ 键（$614 - 348 = 266\ \mathrm{kJ\,mol^{-1}}$）比一个 $\sigma$ 键弱得多，所以当 $\mathrm{HBr}$ 加到 $\mathrm{C{=}C}$ 上时，我们用一个 $\pi$ 键加一个 $\sigma$ 键换回两个更强的 $\sigma$ 键，反应因此放热。碳碳双键于是是一处有反应活性的电子密度仓库——这是加成那一章的主题——而烷烃的 $\mathrm{C{-}C}$ 与 $\mathrm{C{-}H}$ 键相比之下索然无味。这个对比，而不是某张反应清单，才是官能团概念的地基。

由此带来的规模难以夸大：碳化合物的结构数据库现已收录超过一亿条条目，且每年约新增一百万条；仅 $\mathrm{C_{30}}$ 烷烃的理论异构体数目就超过 $4 \times 10^{9}$。没有哪种记忆能编目这样一门学科，也不必去编——官能团思想把它压缩了，因为一个分子的行为大体就是它那少数几个基团所作所为的总和，只被周围环境微弱地调制。本课程后面的一切，都是这一压缩的精细化。

记法上的后果是：大多数原子并不明写。**键线式**在每个顶点和线段末端放一个碳，并省去碳上的氢；杂原子（O、N、S、卤素）及其氢则明确写出。像 $\mathrm{CH_3CH_2OH}$ 这样的缩写式介于完整结构式与键线式之间。熟练，意味着能在这三种表示之间随意往返，能看着一条六个端点的折线立刻读出"己烷，$\mathrm{C_6H_{14}}$"。

键线式是平面的，而分子不是。当第三维重要时——在本课程里它常常重要——平面图上再加一条约定：**楔形键**（画成逐渐变宽的三角形）从纸面指向你，**虚线键**（画成一串短平行线）指向纸面之后，普通线则躺在纸面内。因此，一个碳周围画成两条普通线加一个楔形键加一个虚线键的四个单键，读作"四面体——而且空间朝向如此"。这条小小的约定，就是图纸与模型的全部区别，而 [[organic-1/stereochemistry]] 将把它变成一个计数问题。

::: example 读一个键线式 {#ex-skeletal-read}
3-甲基己烷的键线式是一条六顶点的折线，在第三个顶点上带一个一碳支链。写出其分子式，并数出每个碳上的氢。
::: solution
母链六个碳加一个甲基支链共 $\mathrm{C_7H_{16}}$。按化合价数氢：C1 上三个，C2 上两个，C3 上一个（它连着支链），C4、C5 各两个，C6 上三个，支链甲基上三个——共十六个，与 $n = 7$ 时的烷烃通式 $\mathrm{C}_n\mathrm{H}_{2n+2}$ 相符。
:::
:::

::: example 数一个支链异构体的原子 {#ex-isooctane}
"异辛烷"，辛烷值标度的 100 点，就是 2,2,4-三甲基戊烷。由名称写出其缩写式并数出原子数。它的氢中有多少个连在不再连其他碳的碳上？
::: solution
母链戊烷为 $\mathrm{C1{-}C2{-}C3{-}C4{-}C5}$；C2 上两个甲基、C4 上一个甲基，得缩写式 $\mathrm{(CH_3)_3CCH_2CH(CH_3)_2}$。碳数：$5 + 3 = 8$；氢数：$3(3) + 2 + 1 + 2(3) = 18$，即 $\mathrm{C_8H_{18}}$，仍是 $\mathrm{C}_n\mathrm{H}_{2n+2}$。所有不再连其他碳的碳都是甲基：C2 上三个、C4 上两个，共五个甲基，所以十八个氢中有 $5 \times 3 = 15$ 个在伯碳上。按碳的*种类*——伯、仲、叔、季——计数，是追踪机理的第一个习惯，因为反应关心的是取代模式，而不是分子式。
:::
:::

::: quiz
下列哪一个**不是**开链烷烃？
- [ ] $\mathrm{C_4H_{10}}$
- [x] $\mathrm{C_5H_{10}}$
- [ ] $\mathrm{C_6H_{14}}$
- [ ] $\mathrm{C_3H_8}$
::: solution
开链烷烃的分子式必须是 $\mathrm{C}_n\mathrm{H}_{2n+2}$。$\mathrm{C_5H_{10}}$ 比 $\mathrm{C_5H_{12}}$ 少两个氢，意味着一个环或一个 $\pi$ 键——一个不饱和度——所以它不是烷烃。
:::
:::

## 不饱和度

::: definition 不饱和度 {#def-dou}
一个分子式的**不饱和度**（氢缺指数）是其结构必须包含的环数加 $\pi$ 键数：
$$
\mathrm{DoU} = \frac{2C + 2 + N - H - X}{2},
$$
其中 $C, N, H, X$ 是碳、氮、氢与卤素的个数。氧和硫不改变计数；每个环或每个 $\pi$ 键贡献一个不饱和度。
:::

这套记账背后有道理，不是死记的规则。饱和开链化合物是 $\mathrm{C}_n\mathrm{H}_{2n+2}$；每个环或 $\pi$ 键去掉两个氢；卤素一比一地顶替氢（所以并入 $H$ 计数）；氮插入一个额外的 $\mathrm{CH}$ 当量并带来一个氢（故有 $+N$）。氧把自己插进已有的 $\mathrm{C{-}H}$ 或 $\mathrm{C{-}C}$ 键而不改变氢数，这就是它不可见的原因。

::: example 数不饱和度 {#ex-dou}
求 (a) $\mathrm{C_4H_8O}$、(b) $\mathrm{C_7H_7NO_2}$、(c) $\mathrm{C_6H_6}$、(d) $\mathrm{C_6H_{12}O_6}$ 的不饱和度。
::: solution
(a) $\mathrm{DoU} = (2\times 4 + 2 - 8)/2 = 1$：一个环或一个双键；氧对计数不可见。(b) $\mathrm{DoU} = (2\times 7 + 2 + 1 - 7)/2 = 4$：芳环的四个不饱和度，如间硝基甲苯（*meta*-nitrotoluene）。(c) $\mathrm{DoU} = (2\times 6 + 2 - 6)/2 = 4$：苯的一个环加三个 $\pi$ 键。(d) $\mathrm{DoU} = (2\times 6 + 2 - 12)/2 = 1$：葡萄糖可以是开链而含一个 $\mathrm{C{=}O}$，或（溶液中主要的存在形式）成一个环而无羰基——光凭分子式说不清是哪一种，要由光谱裁决。
:::
:::

这正是不饱和度是结构解析第一步的原因：在解读任何一张谱图之前，分子式已经告诉你答案必须包含多少环和重键，而四个不饱和度就是一封寻找苯环的邀请函。把分子式与谱图合起来解读的完整方案，见 [[spectroscopy/structure-problems]]。

## 官能团

官能团是有机分子的反应单元；碳氢骨架大体是旁观者。本课程涉及的各官能团连同其在命名中贡献的后缀或前缀收集如下。

::: definition 主要官能团 {#def-groups}
**烯烃** $\mathrm{C{=}C}$（后缀 *-ene*，烯）、**炔烃** $\mathrm{C{\equiv}C}$（*-yne*，炔）、**卤代烃** $\mathrm{R{-}X}$（前缀 *fluoro-*、*chloro-*、*bromo-*、*iodo-*，氟/氯/溴/碘代）、**醇** $\mathrm{R{-}OH}$（*-ol*，醇）、**硫醇** $\mathrm{R{-}SH}$（*-thiol*，硫醇）、**醚** $\mathrm{R{-}O{-}R'}$（作取代基时为 *alkoxy-*，烷氧基）、**胺** $\mathrm{R{-}NH_2}$（*-amine*，胺）、**醛** $\mathrm{R{-}CHO}$（*-al*，醛）、**酮** $\mathrm{R_2C{=}O}$（*-one*，酮）、**羧酸** $\mathrm{R{-}COOH}$（*-oic acid*，某酸）、**酯** $\mathrm{R{-}COOR'}$（*-oate*，某酸某酯）、**酰胺** $\mathrm{R{-}CONH_2}$（*-amide*，某酰胺）、**腈** $\mathrm{R{-}C{\equiv}N}$（*-nitrile*，腈）。当多个官能团同时存在时，IUPAC 优先顺序最高者成为后缀，其余以前缀列出；你最先需要的顺序是：酸 > 酯 > 酰胺 > 醛 > 酮 > 醇 > 胺 > 烯 > 炔。
:::

有两个结构观念把整张表组织起来。其一，羰基 $\mathrm{C{=}O}$ 出现在五个条目中（醛、酮、酸、酯、酰胺），并统治课程的后半程；区分它们的只是挂在羰基碳上的东西，而上面的优先顺序几乎正是这些取代基稳定该基团能力的顺序。其二，杂原子基团（醇、胺、硫醇、醚）带着孤对电子，因而既是酸碱化学也是取代化学的候选者——这就是接下来两章谈酸性和弯箭头的原因。

::: warning 数碳的陷阱 {#warn-parent-chain}
母体名称数的是*包含主官能团*的最长链，而不是碰巧存在的最长链。一条五碳链在中部带一个甲基支链时，只有穿过支链选链才能命名为戊烷衍生物；选错母体是命名中最常见的初学者错误，而且它会不动声色地改掉每一个位次。
:::

::: example 在真实分子中识别官能团 {#ex-aspirin}
阿司匹林（乙酰水杨酸）是 $\mathrm{o{-}CH_3COOC_6H_4COOH}$：一个苯环带着一个羧基，并且在其邻位连着一个与 $\mathrm{C(=O)CH_3}$ 相连的 $\mathrm{O}$。列出它的官能团，并只凭这些官能团预测它应当发生的一个反应。
::: solution
三个官能团：**芳环**、**羧酸**（$\mathrm{-COOH}$）和**酯**（$\mathrm{-O{-}C(=O){-}}$，它写得与常见的 $\mathrm{R{-}COOR'}$ 方向相反，因为环上的氧就是酯的单键氧——它既不是醚也不是酮）。凭官能团：羧酸使它呈酸性（$\mathrm{p}K_\mathrm{a} \approx 3.5$，比一般脂肪酸强，因为环传递了相邻氧的吸电子作用），而酯应当在热碱水中水解为水杨酸的羧酸盐加乙酸根。两个预测都正确——读官能团就是在读反应性。
:::
:::

## 命名：IUPAC 系统

::: proposition IUPAC 算法 {#prop-nomenclature}
给一个结构命名：（1）找出包含主官能团的最长链——它决定母体氢化物（meth-、eth-、prop-、but-、pent-、hex-、hept-、oct-、non-、dec-，甲、乙、丙、丁、戊、己、庚、辛、壬、癸）；（2）从使主官能团位次最低的一端开始编号，其次是重键，再次是取代基；（3）取代基按字母顺序以前缀列出，字母排序时不计倍数前缀（di-、tri-）；（4）接上主官能团的后缀，元音开头的后缀前去掉词尾的 "e"（pentan-2-ol，但 1-bromopentane 保留 e）。当两个编号方向给出相同的位次组时，按首次差别定夺；若仍平手，则字母序居前的取代基取较低位次。标点也承载含义：数字与数字之间用逗号、数字与字母之间用连字符，所以 2,3-二甲基戊烷与 2-(1-甲基乙基)戊烷的标点是关于结构的断言，不是排版装饰；复杂取代基放在括号里列出，并按其首字母参与字母排序。
:::

::: example 一个支链名称的完整推演 {#ex-naming-branched}
命名 $\mathrm{(CH_3)_2CHCH_2CHClCH_3}$。
::: solution
最长链穿过带氯的碳，含五个碳；第六个碳是甲基支链。从左编号，氯在 C4、甲基在 C2；从右编号，氯在 C2、甲基在 C4。两个方向的位次组都是 $\{2,4\}$，于是按字母顺序破平：chloro（氯）先列出，取较低位次。名称为 **2-氯-4-甲基戊烷**（2-chloro-4-methylpentane）。
:::
:::

::: example 带后缀官能团的命名 {#ex-naming-ol}
命名 $\mathrm{CH_3CH_2CH(OH)CH_2CH_3}$，并说明位次何时可以省略。
::: solution
分子是对称的：从任一端编号都把羟基放在 C3，所以 3-戊烷醇（pentan-3-ol）即使不写位次也无歧义，尽管位次通常仍给出。不对称的醇如 2-戊醇则必须给位次，因为 pentan-2-ol 与 pentan-3-ol 是不同的化合物。
:::
:::

::: example 后缀优先于双键时 {#ex-naming-enone}
命名 $\mathrm{CH_2{=}CHCH_2COCH_3}$。
::: solution
链上有五个碳，带两个特征：一个酮（后缀官能团）和一个双键（不饱和键，以 *-en-* 列出）。主官能团先编号并取较低位次，所以从甲基一端数起：羰基在 C2，双键在 C4 与 C5 之间。名称为 **4-戊烯-2-酮**（pent-4-en-2-one）——而不是 pent-1-en-4-one，那等于牺牲后缀去迁就烯烃。同样的逻辑给出另一端的异构体名为 1-戊烯-3-酮。
:::
:::

::: history
系统命名法是从一个真实问题里长出来的。1890 年以前，重要化合物往往有好几个名字，不断膨胀的文献变得无法使用。1892 年的日内瓦大会（Geneva Congress）产生了第一套国际命名约定，英国与美国的化学会整个二十世纪对其修修补补，形成今天仍在施行的 IUPAC 建议。2013 年的建议把规则朝图论式的精确性作了修订——位次写进名称内部（pentan-2-ol 而非 2-pentanol）即由此而来。与之平行的结构理论史——凯库勒（Kekulé）与古佩尔（Couper）1858 年的四价碳、催生命名法的那批同分异构难题——说明命名不是官僚程序，而是结构本身的形式化编码。
:::

## 物理性质随组成而来

命名与计数只是入场券；官能团之所以重要，是因为它们控制性质。沸点沿同系列升高，因为每个 $\mathrm{CH_2}$ 都增加表面积与色散力：正构烷烃的沸点在小链长处爬升很陡、随后趋缓，从戊烷的 $309\ \mathrm{K}$ 到癸烷的 $447\ \mathrm{K}$。支链化通过减少可供色散作用的分子表面而降低沸点——2,2-二甲基丙烷在 $283\ \mathrm{K}$ 沸腾，比其无支链异构体戊烷（$309\ \mathrm{K}$）低约 $26\ \mathrm{K}$。

points: 3,-42; 4,-1; 5,36; 6,69; 7,98; 8,126; 9,151; 10,174

x: 2, 11
caption: 正构烷烃（$\mathrm{C_3}$–$\mathrm{C_{10}}$，$^\circ\mathrm{C}$）的沸点对其碳数的图，附最小二乘直线。在这个窗口内拟合近乎线性——平均每个 $\mathrm{CH_2}$ 约增加 $30\ \mathrm{^\circ C}$——但*增量*沿系列递减（丙烷到丁烷 $41\ \mathrm{^\circ C}$，壬烷到癸烷 $23\ \mathrm{^\circ C}$），因为分子越小时色散力增长越快。拖动一个点，看 $R^2$ 下降：同系列数据就是化学家的校准曲线，其线性使我们能只凭分子式把未知沸点估到几度以内。
:::

氢键能把沸点挪动几十度。乙醇（$M = 46$）在 $351\ \mathrm{K}$ 沸腾，而其构造异构体二甲醚在 $248\ \mathrm{K}$、丙烷（$M = 44$）在 $231\ \mathrm{K}$：只有乙醇有一个能把两个分子连成一条液体内聚力所及之链的 $\mathrm{O{-}H}$ 键。同样的效应解释了为什么 1-戊醇在 $411\ \mathrm{K}$ 沸腾，比摩尔质量几乎相同的己烷（$342\ \mathrm{K}$）高约 $70\ \mathrm{K}$，也解释了为什么甲醇到 1-丁醇这些小分子醇与水以任意比例互溶，而 1-戊醇只溶到约 $0.3\ \mathrm{mol\,dm^{-3}}$：羟基支付溶于水的代价，碳氢链则索取代价，超过五个碳后链占了上风。极性比分子式暗示的要温和——氯甲烷的偶极矩是 $1.9\ \mathrm{D}$，甚至 $\mathrm{C{=}O}$ 基团的 $2.4\ \mathrm{D}$ 也只换来部分溶解度——但为下一章极性反应定向的是极性，而不是色散力。

组成还决定官能团在实验室里如何自我宣告，一份简短的经典定性检验清单值得留作反应性的预习：烯烃在黑暗中经 $\pi$ 键的快速加成使棕色的溴溶液褪色；羧酸溶于碳酸氢钠水溶液并放出 $\mathrm{CO_2}$ 气泡，而多数酚不能；醇与钠金属反应放出氢气。每一项检验都不过是把本课程的一个反应变成"这个基团存在吗？"的提问——鉴定的逻辑就是机理的逻辑，只是问得客气些。（此类检验是需在监督与风险评估下进行的课堂演示，不是操作配方。）酸性是另一条大的性质轴，也是对机理支配最直接的一条，将在 [[organic-1/acidity-mechanism]] 中展开。

## 后续内容

四价碳的三维后果——一条折线真正长什么样——是 [[organic-1/conformations]] 的主题；当一个碳连着四个*不同*的基团时，异构体的计数就爆炸成 [[organic-1/stereochemistry]]。这里引入的官能团，在你会用电子流动书写之后，就变成反应机理：先学 [[organic-1/acidity-mechanism]] 这套语法，然后是 [[organic-1/nucleophilic-substitution]] 与 [[organic-1/elimination]]；上面预告过的羰基家族将占满第二门课程 [[organic-2/carbonyl-addition]]。全程假定的成键观念——杂化、键焓、电负性——在 [[bonding-structure/valence-bond]] 中有定量展开。

::: summary
- 键线式以顶点隐含碳、以化合价隐含碳上氢；杂原子及其氢明确画出。
- $\pi$ 键比 $\sigma$ 键弱（$\mathrm{C{=}C}$：$614$ 对 $2 \times 348\ \mathrm{kJ\,mol^{-1}}$），所以多重键是反应位点而烷烃不是。
- 不饱和度数环与 $\pi$ 键：$\mathrm{DoU} = (2C + 2 + N - H - X)/2$；氧与硫不可见，卤素按氢计，氮加一。
- 官能团是反应单元；碳氢骨架是调节溶解度与沸点的旁观者，羰基家族从醛一路排到酰胺。
- IUPAC 名称唯一地编码结构：含主官能团的最长链、最低位次（先后缀、再不饱和键、再取代基前缀）、前缀按字母序列出。
- 物理性质随组成而来：色散力随表面积上升，支链化使其下降，氢键则压倒其所能及的一切。
- 命名是要练的技能，不是要背的知识：每个名称都是施加在一个图上的算法。
:::

## 练习

::: exercise 画键线式 {level=1}
画出 3-乙基-2-甲基己烷的键线式，并给出其分子式。
::: solution
母链己烷在 C2 带一个甲基支链、在 C3 带一个乙基支链；分子式为 $\mathrm{C_9H_{20}}$。
:::
:::

::: exercise 不饱和度 {level=1 check="2"}
$\mathrm{C_5H_8}$ 有多少个不饱和度？输入数字。
::: solution
$\mathrm{DoU} = (2\times 5 + 2 - 8)/2 = 2$：两个环和/或 $\pi$ 键，如环戊烯或 1,4-戊二烯。
:::
:::

::: exercise 数氢 {level=1 check="12"}
2-甲基-3-戊酮 $\mathrm{C_6H_{12}O}$ 有多少个氢原子？输入数字。
::: solution
分子式直接给出：十二个氢。从结构看，羰基消耗一个不饱和度，其余分子式就是一个取代戊烷。
:::
:::

::: exercise 按优先顺序命名 {level=2}
正确命名 $\mathrm{HOCH_2CH{=}CHCH_2OH}$，并解释编号。
::: solution
醇羟基是后缀官能团，链编号使它们位次最低；双键随后作为不饱和键列出。羟基在 C1 与 C5 时，双键位于 C2 与 C3 之间（由对称性也等价于 C3 与 C4），所以正确名称是 **2-戊烯-1,5-二醇**（pent-2-ene-1,5-diol），几何构型确定后再加 *E* 或 *Z* 标记（见 [[organic-1/stereochemistry]]）。
:::
:::

::: exercise 由名称到结构 {level=2}
画出 4-溴-2-甲基-2-戊醇，并指出哪些碳是立体中心。
::: solution
结构为 $\mathrm{(CH_3)_2C(OH)CH_2CHBrCH_3}$。C2 连着两个相同的甲基，不是立体中心；C4 连着 H、Br 和两个不同的碳取代基，**是**立体中心。
:::
:::

::: exercise 官能团识别 {level=2}
指出苯甲酸甲酯 $\mathrm{C_6H_5COOCH_3}$ 中的每一个官能团，并预测其沸点应高于还是低于甲基环己烷（$344\ \mathrm{K}$，摩尔质量相近）。
::: solution
一个芳环和一个酯基。甲氧基的碳属于酯，不是独立的醚；环也不是烯烃。酯有极性但没有 $\mathrm{O{-}H}$，不能自身形成氢键，但其偶极和大的可极化 $\pi$ 体系抬高了沸点：苯甲酸甲酯在 $473\ \mathrm{K}$ 沸腾，远高于甲基环己烷。
:::
:::

::: exercise 由谱图定结构 {level=3}
某化合物 $\mathrm{C_4H_8O}$ 显示一个不饱和度，并在 $1715\ \mathrm{cm^{-1}}$ 附近有强红外吸收带。给出两个与数据相符的结构。
::: solution
羰基吸收带指明醛或酮，一个不饱和度说明分子是开链的。相符的结构包括丁醛 $\mathrm{CH_3CH_2CH_2CHO}$、2-丁酮 $\mathrm{CH_3COCH_2CH_3}$ 和 2-甲基丙醛 $\mathrm{(CH_3)_2CHCHO}$。
:::
:::

::: exercise 数异构体 {level=3}
枚举分子式为 $\mathrm{C_5H_{12}O}$ 的全部开链仲醇，并给出其 IUPAC 名称。
::: solution
仲醇的醇羟基碳恰带一个氢和两个碳取代基。可能性为 2-戊醇、3-戊醇和 3-甲基-2-丁醇。（1-戊醇与 2-甲基-1-丁醇是伯醇；2-甲基-2-丁醇与 2-甲基-2-丙醇是叔醇。）仲醇恰好三个。
:::
:::
