苯曾是一场持续四十年的丑闻。法拉第（Faraday）1825 年分离出它，元素分析给出实验式 CH——碳氢一比一的化合物，氢含量远低于任何类烯烃物质，因为烯烃是 $\mathrm{C_nH_{2n}}$。然而苯能加氢，燃烧时冒出黑烟，能溶解溴而不使其褪色。它发生取代——一个氢被一个溴取代，一个氢被一个硝基取代——而且有史以来制备的每一种一取代苯都只有一种形态，仿佛六个位置完全等同。六个碳的链带三个双键不可能做到这一点；环可以，1865 年凯库勒（Kekulé）的环解释了一切，除了最要紧的那件事：三个双键的环应该有像三个烯烃的行为，而苯一点都不像。答案要到 1930 年代连同新量子力学才到来：环状共轭不是共轭乘以三——它是另一种物质形态。本章把这一思想精确化，交给你那条把环分为芳香、反芳香与仅仅不饱和的计数规则，并展示证明这条规则从来不只是关于苯的离子与杂环。

## 证据：到底稳定多少？

::: definition 芳香性、反芳香性、非芳香性 {#def-aromaticity}
**芳香**化合物是环状、平面、完全共轭的体系，其 $\pi$ 电子占据成键分子轨道的闭壳层，因而具有额外的热力学稳定性（**共振**能或**离域**能），并且特征性地不愿发生加成：它偏爱能保住环的取代。**反芳香**化合物是带 $4n$ 个 $\pi$ 电子的环状、平面、完全共轭体系，它把电子留在非键或反键轨道上，使其*不如*开链类似物稳定。**非芳香**化合物只是缺少前提条件之一——通常是平面性或连续共轭——行为像普通烯烃。这三个词命名的是三种不同的实验，不是同一性质的三个等级。
:::

热化学证据只是一次减法。环己烯（一个孤立双键）的氢化放热 $-119.7\ \mathrm{kJ\,mol^{-1}}$；1,3-环己二烯放热 $-231.8\ \mathrm{kJ\,mol^{-1}}$，即单烯的两倍再减去普通共轭的 $\approx 8\ \mathrm{kJ\,mol^{-1}}$。若苯是"环己-1,3,5-三烯"，它应放出单烯值的三倍，约 $-359\ \mathrm{kJ\,mol^{-1}}$。它实际放出 $-208.4\ \mathrm{kJ\,mol^{-1}}$。

::: example 苯的共振能 {#ex-resonance-energy}
利用上面的氢化数据——环己烯 $-119.7$，苯 $-208.4\ \mathrm{kJ\,mol^{-1}}$——计算苯的共振能，并与 [[organic-2/conjugation]] 中丁-1,3-二烯 $14.7\ \mathrm{kJ\,mol^{-1}}$ 的共轭能比较。（共振能以正数作答，单位 $\mathrm{kJ\,mol^{-1}}$。）
::: solution
假想的环己三烯将以 $3 \times (-119.7) = -359.1\ \mathrm{kJ\,mol^{-1}}$ 氢化；苯实际给出 $-208.4\ \mathrm{kJ\,mol^{-1}}$。差额为 $359.1 - 208.4 = 150.7$，所以苯被稳定约 $151\ \mathrm{kJ\,mol^{-1}}$——单个丁二烯单元共轭能的十倍，多到足以让苯拒绝会消耗掉这笔能量的加成反应。这个比较就是整章教训浓缩成的一个数字：环里的六个 $\pi$ 电子不是三个共轭双烯；它们是闭壳层。
:::
:::

结构证据指向同一方向。苯的六个碳–碳键全部是 $1.397\ \mathrm{\AA}$——比烯烃的 $1.34\ \mathrm{\AA}$ 长，比烷烃的 $1.54\ \mathrm{\AA}$ 短，而且*彼此相等*，1930 年代以来的 X 射线与电子衍射早已表明。磁学证据最为壮观，你在光谱学课程中还会再遇到它：环中循环的 $\pi$ 电子在磁场中维持一个**环电流**，在环外增强磁场、在环内抵消磁场，于是苯的质子在 $\delta\ 7.27$ 共振——远在烯烃之下场区——而被安置在更大芳香环*内部*的质子则在负位移处共振。

## 轨道图像：$p$ 轨道的环闭合壳层

::: proposition 苯的分子轨道与弗罗斯特圆 {#prop-benzene-mo}
正六边形上的六个平行 $p$ 轨道组合成六个 $\pi$ 分子轨道，其能量由**弗罗斯特圆**给出：把多边形的一个顶点朝内（指向下方）内接于以 $\alpha$ 为心、半径 $2\beta$ 的圆，各顶点的竖直位置就是轨道能量。对苯而言，能级为 $\alpha+2\beta$（一个轨道，全部同相）、$\alpha+\beta$ 上的简并二重态、$\alpha-\beta$ 上的简并二重态，以及 $\alpha-2\beta$（完全交替）。六个 $\pi$ 电子恰好填满最低三个能级——一个闭合的成键壳层，到 LUMO 二重态有大间隙，所有成键轨道占满而反键轨道全空。
:::

caption: 苯的六个 $\pi$ 分子轨道能级，以 $\beta$ 为单位（滑块 $s$ 缩放能量轴）：$\alpha+2\beta$ 一个能级，$\alpha+\beta$ 一对简并，$\alpha-\beta$ 一对简并，$\alpha-2\beta$ 一个——六边形的弗罗斯特圆图案。六个电子填满 $\alpha=0$ 线以上的三个能级后停手：闭壳层，到第一对空轨道有 $2\beta$ 的间隙。拖动 $s$，图案不变——壳层结构是六边形对称性的性质，与能量标度无关，这就是为什么"六个 $\pi$ 电子"对任何六元环（无论其原子是什么）都是魔法数字。
:::

同样的作图用于其他多边形便是整个学科的引擎。三角形（环丙烯基）给出一个低能级加其上一个简并对；正方形（环丁二烯）给出一个低能级、两个*恰在* $\alpha$ 上的简并能级和一个高能级；五边形（环戊二烯基）给出一个低能级加两对简并对；七边形（环庚三烯基）给出一个低能级加三对。用不同的电子数填充，规则便自行宣告。

::: proposition 休克尔规则 {#prop-huckel}
平面、环状、完全共轭（单环）体系在具有 $4n+2$ 个 $\pi$ 电子（$n = 0, 1, 2, \ldots$：2、6、10、14，…）时是**芳香**的，在具有 $4n$ 个（4、8、12，…）时是**反芳香**的。理由是弗罗斯特圆：$4n+2$ 个电子恰好填满非简并的最低能级和整数个简并对——闭壳层——而 $4n$ 个电子留下半满的简并组，这不稳定，会驱动畸变、双自由基行为或失去平面性。该规则是轨道算术的经验总结，且只对单环体系陈述；多环与三维芳香性需要更多机器。
:::

::: example 数到芳香 {#ex-count}
分类并各用一个从句说明理由：(a) 环丙烯基碳正离子 $\mathrm{C_3H_3^+}$；(b) 环丁二烯 $\mathrm{C_4H_4}$；(c) 环戊二烯基负离子 $\mathrm{C_5H_5^-}$；(d) 环庚三烯基（草鎓）碳正离子 $\mathrm{C_7H_7^+}$；(e) 环辛四烯 $\mathrm{C_8H_8}$。
::: solution
(a) 2 个 $\pi$ 电子：$4(0)+2$——芳香的，而且是最小的。(b) 4 个 $\pi$ 电子：$4n$——若平面则反芳香，于是它畸变成矩形并剧烈二聚以逃脱。(c) 6 个 $\pi$ 电子（两个双键加上 $p$ 轨道中的负离子孤对）：芳香——这就是环戊二烯异常酸性的原因。(d) 6 个 $\pi$ 电子（三个双键加上空 $p$ 轨道）：芳香，这就是草鎓盐可以分离的原因。(e) 8 个 $\pi$ 电子：$4n$，平面化将导致反芳香——分子拒绝平面化，采取盆状构型、双键定域，所以是非芳香的，像多烯一样反应。注意这个模式：电子数说了算，分子便服从。
:::
:::

::: warning 休克尔规则有前提条件 {#warn-huckel-preconditions}
规则是在你检查完三个前提*之后*才数电子的，而考试中的多数错答不是错在数数，是错在检查。**环状**且**完全共轭**：环庚三烯本身不芳香——$\mathrm{CH_2}$ 碳没有 $p$ 轨道，回路是断的；只有它的碳正离子才是。**平面**：[10]轮烯有 $4(2)+2 = 10$ 个 $\pi$ 电子却不芳香，因为平面环会迫使两个内部氢相撞；它皱缩起来，行为像一个戊烯。能把内部清空或环足够大的 [14]轮烯与 [18]轮烯*确实*芳香——规则说的是轨道，但氢也有投票权。还有，**芳香不等于"气味好闻"**：这个名字是早期苯系物气味的历史偶然，而环戊二烯——芳香性环戊二烯基负离子的前体——闻起来一点也好闻不了。
:::

## 芳香离子：证明规则的酸度

休克尔 1931 年陈述他的规则时，其多数著名例证还不存在。它们以离子的形式到来，证据常常是一个 $\mathrm{p}K_\mathrm{a}$ 值。

::: example 为什么环戊二烯是"强"烃 {#ex-cp-acidity}
环戊二烯的 $\mathrm{p}K_\mathrm{a} \approx 16$；丙烯（烯丙位 $\mathrm{C{-}H}$）约 43；丙烷约 50。解释前者的 27 个单位差距，并说在水中制取环戊二烯基负离子需要什么碱。
::: solution
从丙烯移去 $\mathrm{H^+}$ 得到离域在三碳上的烯丙基负离子——是稳定化，但只是普通共轭。从环戊二烯移去 $\mathrm{H^+}$ 得到 $\mathrm{C_5H_5^-}$：平面环、五个 $p$ 轨道、六个 $\pi$ 电子——休克尔芳香闭壳层，电荷均分在五个碳上。产物的芳香性值几十 $\mathrm{kJ\,mol^{-1}}$ 的酸性，而 $27$ 个 $\mathrm{p}K_\mathrm{a}$ 单位在 $298\ \mathrm{K}$ 是 $27 \times 5.7 = 154\ \mathrm{kJ\,mol^{-1}}$——与苯的共振能同量级，也必须同量级，因为该负离子与苯在完全相同的意义上是六电子芳香体。在水中连氢氧根都太弱（习题集会让你算出有多弱）：醇盐、$\mathrm{NaH}$ 之类的氢负离子源或金属钠能使其去质子化，而且该负离子稳定到可以以盐的形式分离。
:::
:::

::: widget newton
f: (x/(0.1-x))^2 - 0.01
x0: 0.01
x: 0, 0.1
caption: 牛顿法求 $0.10\ \mathrm{mol\,dm^{-3}}$ 环戊二烯遇 $0.10\ \mathrm{mol\,dm^{-3}}$ 氢氧根时环戊二烯基负离子的平衡浓度 $x$：反应 $\mathrm{CpH + HO^- \rightleftharpoons Cp^- + H_2O}$ 的 $K = K_\mathrm{a}(\mathrm{CpH})/K_\mathrm{w} = 10^{-16}/10^{-14} = 0.01$，故 $(x/(0.1-x))^2 = 0.01$，$x = 0.0091\ \mathrm{mol\,dm^{-3}}$——只有 $9\,\%$ 去质子化。芳香性使环戊二烯成为其尺寸内酸性最强的烃，但它仍是*弱酸*：负离子的芳香稳定化是 $150\ \mathrm{kJ\,mol^{-1}}$ 的馈赠，不是质子化水的许可证。
:::

碳正离子一侧的故事同样有教益。用氢负离子受体处理环庚三烯，从 $sp^3$ 碳上移去 $\mathrm{H^-}$（连同它的两个电子），在七个中心上留下六个 $\pi$ 电子：**草鎓碳正离子**，其盐——氯化物、四氟硼酸盐——是普通的结晶固体，在水中稳定，七个 C–C 键全等（$1.38\ \mathrm{\AA}$），七个质子全等。1931 年休克尔规则预言了稳定的 $\mathrm{C_7H_7^+}$；1950 年代初 Doering 与 Knox 制出了它的盐，规则获得了它最常被引用的确认。同样的逻辑使环丙烯基碳正离子（2 个 $\pi$ 电子）可以三苯基环丙烯鎓盐的形式分离（Breslow，1950 年代末），并且——正确地——预言环戊二烯基*碳正离子*（4 个 $\pi$ 电子）与环庚三烯基*负离子*（8 个 $\pi$ 电子）是反芳香的，从未作为简单物种被制得。

::: history
本章的证据分四幕积累。1905 年理查德·威尔施泰特（Richard Willstätter）经一条不可能产生别的东西的路线合成了他相信是环己-1,3,5-三烯的物质——发现它是一种活泼的三烯，与苯毫无相似之处；这个悖论（其实说话的是苯的稳定性）四分之一个世纪都没有解决。1925 年罗伯特·罗宾逊（Robert Robinson）提出**芳香六隅体**，把六个电子计为环稳定性的单元，这一记账规则比轨道壳层早了六年。1931 年埃里希·休克尔（Erich Hückel）从量子力学导出 $4n+2$ 条件，莱纳斯·鲍林（Linus Pauling）在 1933 年补上共振能语言。1950 年代规则的预言被实验兑现——Doering 与 Knox 的草鎓盐、Hafner 的环戊二烯基负离子盐、Breslow 的环丙烯鎓盐——而 1963 年克劳斯·福格尔（Klaus Vogel）的 [18]轮烯以其抗磁环电流（外部质子 $\delta\ 9.3$，内部 $\delta\ -3.0$）表明芳香性是电子数的性质而非六个碳的性质。
:::

## 反芳香性：规则的黑暗孪生子

反芳香性在瓶子里比芳香性罕见，原因很简单：分子会躲避它。环丁二烯，$4\pi$ 的正方形，从 1900 年代起就有人追寻；在无固体的纯净状态下高于 $35\ \mathrm{K}$ 它几秒内便二聚，直到 1990 年代初京特·迈尔（Günther Maier）才在低温氩基质中捕获足够的量记录到红外光谱。已知的一切与理论严丝合缝：它是*矩形*而非正方形（$1.34$/$1.54\ \mathrm{\AA}$ 的键长交替被冻结，因为正方形会让两个电子半填充一对简并轨道——姜-泰勒畸变是分子为糟糕电子构型收拾残局的方式），其氢化焓远比四个双键应有的更放热：反芳香性是*负的*稳定化。

::: example 环辛四烯：拒绝服从的分子 {#ex-cot}
环辛四烯有 8 个 $\pi$ 电子。其 X 射线结构显示交替的键长（$1.34$ 与 $1.47\ \mathrm{\AA}$）和盆状构象；它使溴褪色并容易氢化。用钾金属处理得到 $\mathrm{K_2C_8H_8}$，其 $^1\mathrm{H}$ NMR 显示*单个*尖锐的质子信号，其 X 射线结构显示八个键等长的平面八角形。解释这两个观察。
::: solution
中性分子有 $4n$ 个 $\pi$ 电子，平面化将使其反芳香；它通过皱缩成破坏轨道重叠的盆形来逃脱，定域出四个普通双键——于是有烯烃化学和交替键长。双负离子有 $8+2 = 10 = 4(2)+2$ 个 $\pi$ 电子：平面化此时受到*奖赏*，环扁平化为正八角形，所有键等化，单个 NMR 信号就是十个等价质子受环电流位移的共振。一个分子，两种电子数，两种结构：电子数是老板，几何构型跟随。
:::
:::

哪个物种是芳香的？

- [ ] 环丁二烯 $\mathrm{C_4H_4}$（4 个 $\pi$ 电子）。
- [ ] 平面的环辛四烯 $\mathrm{C_8H_8}$（8 个 $\pi$ 电子）。
- [ ] 环戊二烯基碳正离子 $\mathrm{C_5H_5^+}$（4 个 $\pi$ 电子）。

只有环丙烯基碳正离子：$2 = 4(0)+2$ 个电子处于平面、完全共轭的环——最小的休克尔体系，$n=0$ 也算。其余三个都是 $4n$ 电子：环丁二烯与环戊二烯基碳正离子若平面则反芳香（后者在溶液化学中绝不生成，正因如此），而环辛四烯干脆避免平面化，所以它是非芳香而非反芳香——正是警示板块坚持的区分。
:::

## 杂芳香性与规则的下一步

把芳香环中的一个 CH 换成杂原子，规则依然成立，但必须仔细数——问题永远是孤对电子坐在 $\pi$ 体系*里面*还是*外面*的 $sp^2$ 轨道上。吡啶的氮经其 $p$ 轨道贡献一个电子，把孤对留在环平面内（那对孤对正是吡啶碱性的来源）；吡咯的氮贡献两个，它的孤对就是 $p$ 轨道里的那对（这正是吡咯不碱的原因）。两者都是六电子芳香体，而它们截然不同的化学——吡啶缺电子、吡咯富电子——是 [[organic-2/heterocycles]] 的主题。薁（azulene），一个稠合的 $4n+4n+2$ 烃，偶极矩约 $1.0\ \mathrm{D}$，靠把电子密度转移成稠合的环戊二烯基负离子/环庚三烯基碳正离子对而芳香；硼嗪，"无机苯"，只是弱芳香，因为把电子拉向氮所付出的代价超过离域的收益。

## 后续内容

芳香性是苯*取代*而非加成的原因，而该取代的机理——芳基正离子（芳鎓离子），其生成耗费芳香性、其去质子化又买回芳香性——在 [[organic-2/aromatic-substitution]]。同样的闭壳层逻辑解释了为什么 [[organic-2/carbonyl-addition]] 的羰基化合物加成而非取代，也解释了你刚学会计算的环戊二烯酸性如何使金属有机化学课程的环戊二烯基配体成为可能。环电流是磁学现象，严格来说属于光谱学课程；弗罗斯特圆背后的休克尔分子轨道机器在 [[quantum-chemistry/huckel-theory]] 中推导；"闭壳层"的前线轨道表述在 [[bonding-structure/molecular-orbitals]] 中展开。

::: summary
- 芳香化合物是具有 $4n+2$ 个 $\pi$ 电子的环状、平面、完全共轭体系：成键闭壳层、共振能（苯：由氢化得 $\approx 151\ \mathrm{kJ\,mol^{-1}}$）、等化的键、环电流，以及偏爱取代胜过加成。
- 弗罗斯特圆把休克尔规则变成几何：$4n+2$ 个电子填满最低能级和完整的简并对；$4n$ 个电子半填充一对简并轨道。
- 反芳香的 $4n$ 体系被*去稳定化*，靠畸变（环丁二烯的矩形）或失去平面性（环辛四烯的盆）逃脱；非芳香体系根本从未有过回路。
- 规则的前提——环状、完全共轭、平面——必须先于数电子检查：环庚三烯与 [10]轮烯有电子数却没有结构。
- 芳香离子是规则的证明：环戊二烯的 $\mathrm{p}K_\mathrm{a} \approx 16$（芳香负离子）、可分离的草鎓盐（芳香碳正离子）、以及从未被观察到的环戊二烯基碳正离子（反芳香）。
- 杂原子按孤对是否在 $\pi$ 体系内（吡咯）或外（吡啶）贡献一或两个电子——这是接下来两章的钥匙。
:::

## 练习

::: exercise 给环分类 {level=1}
芳香、反芳香还是非芳香：(a) 苯；(b) 环庚三烯；(c) 草鎓碳正离子；(d) 环戊二烯基负离子；(e) 1,3,5-己三烯。
::: solution
(a) 芳香（6 个 $\pi$，平面，环状）。(b) 非芳香——$sp^3$ 的 $\mathrm{CH_2}$ 切断了共轭回路。(c) 芳香（七个中心上 6 个 $\pi$）。(d) 芳香（五个中心上 6 个 $\pi$）。(e) 非芳香——开链，无论多么共轭；"芳香"要求成环。
:::
:::

::: exercise 魔法数字 {level=1 check="6"}
环戊二烯基负离子有多少个 $\pi$ 电子？（以数字作答。）
::: solution
六个：两个 $\pi$ 键的四个，加上脱质子碳在 $p$ 轨道中留下的孤对。$6 = 4(1)+2$：休克尔数，这就是环戊二烯异常酸性的全部理由。
:::
:::

::: exercise 弗罗斯特圆记账 {level=1}
对 $p$ 轨道组成的平面正六边形，有多少个 $\pi$ 分子轨道是成键的（低于 $\alpha$），多少个电子闭合壳层？
::: solution
三个成键轨道（$\alpha+2\beta$ 一个，$\alpha+\beta$ 一对），容纳六个电子。六处的闭壳层正是六边形的特殊之处；四个或八个电子会把 $\alpha+\beta$ 或 $\alpha-\beta$ 的简并对留为部分占据。
:::
:::

::: exercise 共振能 {level=2 check="151"}
环己烯的氢化为 $-119.7\ \mathrm{kJ\,mol^{-1}}$，苯为 $-208.4\ \mathrm{kJ\,mol^{-1}}$。计算苯的共振能。（正数作答，单位 $\mathrm{kJ\,mol^{-1}}$。）
::: solution
$3 \times 119.7 - 208.4 = 359.1 - 208.4 = 150.7 \approx 151\ \mathrm{kJ\,mol^{-1}}$。注意计算假定了什么：三个孤立双键会可加和地氢化，而 1,3-环己二烯的数据（共轭只值约 $8\ \mathrm{kJ\,mol^{-1}}$）使这条基线公平。剩下的 $151\ \mathrm{kJ\,mol^{-1}}$ 是芳香性，这就是为什么苯只在剧烈条件下氢化而环己烯几分钟内便反应。
:::
:::

::: exercise 哪个更酸，酸多少 {level=2}
芴（$\mathrm{p}K_\mathrm{a} \approx 23$）的酸性远超没有五元环并合的联苯基 $\mathrm{CH_2}$ 型烃。用结构解释，并说明芴负离子按休克尔规则是否芳香。
::: solution
芴的 $\mathrm{CH_2}$ 去质子化给出芴负离子：碳负离子孤对进入五元环的回路，中心环成为稠合的环戊二烯基负离子——五碳环里六个 $\pi$ 电子，芳香，电荷还离域进两个苯环。联苯基类似物能离域电荷却无法借此造出一个芳香环。十个 $\mathrm{p}K_\mathrm{a}$ 单位的差距（$57\ \mathrm{kJ\,mol^{-1}}$）是负离子的芳香稳定化，比环戊二烯的小，因为该负离子的电荷铺在更大、对称性更差的体系上。
:::
:::

::: exercise 盆与八角形 {level=2}
已知平面 $4n$ 体系反芳香、平面 $4n+2$ 体系芳香，预测 (a) 中性环辛四烯、(b) 其双负离子、(c) 其单负离子自由基的几何构型与键长。
::: solution
(a) 盆形，$1.34$/$1.47\ \mathrm{\AA}$ 交替：8 个 $\pi$ 电子使平面化反芳香，分子遂定域四个双键。(b) 平面正八角形，八个等长键接近 $1.40\ \mathrm{\AA}$：10 个 $\pi$ 电子，芳香，环电流也包含在内。(c) 尴尬的情形：9 个 $\pi$ 电子两个休克尔数都不是，双负离子的平面性对负离子自由基不可得——预期一个被压平但畸变的结构，实际上负离子自由基在盆状形式间快速互变。本题要点：规则是关于闭壳层的二值陈述，开壳层物种落在其判决之间。
:::
:::

::: exercise 由电子记账看碱性 {level=3}
吡啶的共轭酸 $\mathrm{p}K_\mathrm{a} = 5.2$；吡咯的共轭酸 $\mathrm{p}K_\mathrm{a} \approx 0.4$ 且质子化发生在碳而非氮。用本章的孤对记账解释这两个数值，并预测吡咯在 C2 还是 C3 质子化。
::: solution
吡啶的孤对位于环平面内的 $sp^2$ 轨道，在六电子 $\pi$ 体系之外；质子化它不损失芳香环分毫，所以吡啶是普通的弱碱（$\mathrm{p}K_\mathrm{a}\ 5.2$，对比烷基铵离子的 $10.6$——$sp^2$ 氮把孤对抓得更紧）。吡咯的孤对*就是*其六个 $\pi$ 电子中的两个；质子化氮会把那对电子从回路中抽走、摧毁芳香性—— 在能量上是绝望之举，于是质子化改在 C2 发生，所得碳正离子仍被稳定：C2 进攻产生的类芳鎓中间体有三个共振贡献式（正电荷可位于氮和两个相邻碳），C3 进攻只有两个。是 C2——而同样的三贡献式论证将作为吡咯芳香亲电取代的规则在 [[organic-2/heterocycles]] 中重现。
:::
:::

::: exercise 设计一个芳香离子 {level=3 hint="问每个前体将变成什么：哪个环、回路里多少个电子、那是不是休克尔数？"}
推断下列各物质在指定处理下能否形成芳香物种并写出该物种：(a) 环丙烯酮 + 强酸；(b) 托酚酮（2-羟基环庚-2,4,6-三烯-1-酮）+ 碱；(c) 5-溴环戊-1,3-二烯 + $\mathrm{Ag^+}$（一次电离尝试）。
::: solution
(a) 能：质子化羰基氧给出环碳带正电荷的贡献式——环丙烯基碳正离子，2 个 $\pi$ 电子，芳香。环丙烯酮作为酮异常地碱，正因如此。(b) 能：去质子化给出托酚酮负离子，其中七碳环保持三个双键的 6 $\pi$ 电子草鎓型回路，而负电荷由两个氧均分——一个把电荷停在计数之外的芳香环。这就是托酚酮酸性（$\mathrm{p}K_\mathrm{a} \approx 7$）而普通醇在 16 附近的原因。(c) 不能：用 $\mathrm{Ag^+}$ 拉走溴负离子将给出环戊二烯基*碳正离子*——4 个 $\pi$ 电子，反芳香——电离根本不发生；在普通烯丙基卤代物会电离的地方电离失败，本身就是反芳香性的诊断。贯穿三问的计数教训：休克尔数的是*环回路里*的电子；环外氧经共振给电子或吸电子而不加入计数。
:::
