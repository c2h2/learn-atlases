两课之前，苯环拒绝加成，因为代价是芳香性；羰基接受加成，因为代价不过是一个 $\pi$ 键，而这笔买卖划得来。$\mathrm{C{=}O}$ 双键在一切要紧的方面都是 $\mathrm{C{=}C}$ 双键的反面：氧的电负性把 $\pi$ 电子从碳上拽走，于是碳带部分正电荷、氧带部分负电荷。烯烃追逐亲电试剂；羰基追逐亲核试剂。本课程后半部分的几乎全部内容——氢负离子还原、有机金属成键、羧酸衍生物的化学、再下面两章的烯醇负离子化学——都是同一个反应换了不同的试剂：亲核试剂对羰基碳的加成，而氧正是使这一切成为可能的电子汇。本章建立一般情形：谁来进攻、怎样进攻、酸碱条件必须如何、平衡停在何处。

## 结构：自带把手的亲电试剂

::: definition 极化的羰基 {#def-carbonyl-pol}
羰基中碳为 $sp^2$（平面三角形，键角近 $120\ \mathrm{^\circ}$），$\pi$ 键强烈极化：成键 $\pi$ 轨道主要位于氧上，反键 $\pi^*$ 轨道——LUMO，接受电子的那个轨道——主要位于碳上，大瓣朝向碳的一侧。推论：碳是亲电位点（亲核试剂的进攻*发生在碳上*），氧是碱性和亲核位点（质子化与硅基化*发生在氧上*），且 $\mathrm{C{=}O}$ 键短（甲醛中 $121\ \mathrm{pm}$）而偶极强（甲醛 $2.3\ \mathrm{D}$，而 $\mathrm{C{=}C}$ 几乎为零）。
:::

::: proposition 加成是几何的改变，不只是键的改变 {#prop-sp2-sp3}
亲核加成把羰基碳从 $sp^2$ 变成 $sp^3$：亲核试剂并不沿 $\mathrm{C{=}O}$ 轴正面进攻（那条路会撞上氧的电子云，也够不到 $\pi^*$ 的大瓣），而是以约 $107\ \mathrm{^\circ}$ 的**比尔吉-杜尼茨角**（Bürgi–Dunitz angle，相对于 $\mathrm{C{=}O}$ 键）从碳的面上到达。四面体产物把四个基团塞进原来只有三个的位置，所以加成的平衡常数是一场拔河：生成的强 $\sigma$ 键（$\mathrm{C{-}Nu}$、$\mathrm{O{-}H}$）对拥挤的 $\pi$ 键的断裂，再受电子效应的调制——碳上的吸电子基让碳更饿、让产物烷氧负离子更安分，两种效应都把平衡推向加成。平面 $sp^2$ 还意味着羰基的两个面都可被进攻，这就是醛酮加成创造新手性中心的原理——[[organic-1/stereochemistry]] 的课题就此变成合成手段。
:::

::: example 平衡究竟停在哪里 {#ex-hydrates}
羰基的水合 $\mathrm{R_2C{=}O + H_2O \rightleftharpoons R_2C(OH)_2}$ 在简单化合物之间横跨一千万倍：甲醛 $K_\mathrm{hyd} \approx 2\times10^3$（在水中超过 $99.9\ \%$ 水合），乙醛 $K_\mathrm{hyd} \approx 1$，丙酮 $K_\mathrm{hyd} \approx 1.4\times10^{-3}$，2,2,2-三氯乙醛（氯醛）$K_\mathrm{hyd} \approx 10^4$（可以水合氯醛的形式分离），六氟丙酮 $K_\mathrm{hyd} \approx 10^6$。解释这个顺序。
::: solution
两根杠杆，在同一张图上读数。**位阻：**碳上由两个基团变成四个，所以把 $\mathrm{H}$ 换成 $\mathrm{CH_3}$（乙醛 → 丙酮）付出拥挤代价，$K$ 掉一千倍。**电子效应：**三个氯、或六个氟，诱导拉走电子密度——使羰基碳更正（亲电性更好），并在过渡态中稳定产物偕二醇的氧负离子特征；氟在电子效应上完胜，给出 $K \approx 10^6$。甲醛单凭位阻取胜（两个氢，无烷基给电子）；丙酮两头皆输。本章的总规则一句话：*缺电子、位阻小的羰基什么都加；富电子、位阻大的酮只加最强的亲核试剂。*
:::
:::

## 工具箱：五族亲核试剂

**氢负离子。** $\mathrm{NaBH_4}$ 在室温的水或醇中把 $\mathrm{H^-}$ 递给醛和酮，到此为止；$\mathrm{LiAlH_4}$ 凶猛得多，还能打开酯、酸和酰胺（它们的化学见 [[organic-2/carboxylic-derivatives]]）。还原就是加 $\mathrm{H^-}$ 再质子化烷氧负离子：醛 → $1^\circ$ 醇，酮 → $2^\circ$ 醇。

**有机金属试剂。** 格氏试剂（Grignard reagent）$\mathrm{RMgX}$ 与有机锂 $\mathrm{RLi}$ 是碳负离子等价物——碳碳成键的主力。它们不可逆地加到醛酮上，产物烷氧负离子在后处理质子化后得醇：甲醛 → $1^\circ$，其他任何醛 → $2^\circ$，酮 → $3^\circ$。它们会被任何质子源摧毁（$\mathrm{RMgX + H_2O \rightarrow RH + MgXOH}$），所以反应在干醚中进行，水最后才加。

**氰根。** $\mathrm{HCN}$（由 $\mathrm{NaCN/KCN}$ 加酸原位产生，以保证存在游离 $\mathrm{CN^-}$）可逆加成给出**氰醇**，$\mathrm{R_2C(OH)CN}$——同一个碳上挂着羟基和腈基，水解后是隐藏的 $\beta$-氨基酸或 $\alpha$-羟基酸，且是一碳增长。

**水与醇。** 弱亲核试剂，但经酸催化给出偕二醇；与醇则给缩醛——下一节的主题，也是本课程第一个保护基。

**含氮亲核试剂。** 氨及其衍生物先加成、再脱水，给出 $\mathrm{C{=}N}$ 化合物：亚胺、肟、腙、缩氨脲。是碳上的加成-消除，不是简单加成，但第一步完全相同。

::: example 格氏地图 {#ex-grignard-map}
为下列目标分别给出羰基化合物与有机金属试剂：(a) 戊-3-醇；(b) 2-苯基丙-2-醇；(c) 环己基甲醇。
::: solution
断开与醇碳相邻的 $\mathrm{C{-}C}$ 键，倒读：醇 ← 烷氧负离子 ← 加成。(a) $\mathrm{CH_3CH_2CH(OH)CH_2CH_3}$ 是 $2^\circ$ 醇，两侧一边一个乙基：丙醛 + $\mathrm{CH_3CH_2MgBr}$（或对称地，乙醛 + $\mathrm{CH_3CH_2CH_2MgBr}$——两个答案，挑便宜的那对）。(b) $\mathrm{PhC(OH)(CH_3)_2}$ 是 $3^\circ$：丙酮 + $\mathrm{PhMgBr}$，再水洗后处理（带两个相同甲基的 $3^\circ$ 醇必来自酮加第三个基团的格氏试剂）。(c) 比环多一个碳的 $1^\circ$ 醇：甲醛 + 环己基溴化镁——甲醛技巧是格氏化学抵达 $1^\circ$ 醇的唯一途径。
:::
:::

::: history
亲核试剂是斜着到达而非正面撞上去，这一点由汉斯-胡戈·比尔吉（Bürgi）与杰克·杜尼茨（Dunitz）在 1970–73 年确立：他们将苯亚甲基苯胺与四氰基乙烯的电荷转移配合物结晶，让 X 射线衍射去测量"一个反应进行到一半长什么样"：缺电子烯烃压向亚胺氮的距离与角度，正是亲核试剂以约 $107\ \mathrm{^\circ}$ 而非 $180\ \mathrm{^\circ}$ 进攻 $\mathrm{C{=}N}$ 的角度。"比尔吉-杜尼茨轨迹"由此成为羰基进攻的教科书几何，是晶体结构直接拍下机理的罕见案例，也是一代面选择性立体化学模型的基石。
:::

## 酸碱开关：两种机理，一个中间体

::: proposition 强亲核试剂走碱，弱亲核试剂走酸 {#prop-acid-base-switch}
加成的极限机理有两条。**碱性条件：**亲核试剂进攻中性羰基，生成的烷氧负离子随后质子化——当亲核试剂是强碱（$\mathrm{RMgX}$、$\mathrm{LiAlH_4}$、$\mathrm{HO^-}$）时这是唯一选择，因为酸会摧毁它。**酸性条件：**先把质子加到羰基氧上（质子化发生在碱性位点氧上，而非碳上），所得氧碳鎓离子——比中性羰基亲电得多——被*弱*亲核试剂（$\mathrm{H_2O}$、$\mathrm{ROH}$、胺）捕获，再脱质子收尾。酸催化因此是把弱亲核试剂配上超强亲电试剂；它恰好在亲核试剂强到不需要帮助时失效，这也是缩醛在干酸中生成、在水酸中水解、却完全无视碱的原因。
:::

::: example 缩醛的生成与用途 {#ex-acetal}
苯甲醛溶于过量甲醇，加微量 $\mathrm{H_2SO_4}$，高产率得二甲缩醛；同一溶液加碱则毫无动静；缩醛放回水酸中又变回苯甲醛。给出机理与合成用途。
::: solution
酸把质子放到羰基氧上；甲醇进攻被活化的碳，给出质子化的**半缩醛**，其脱质子给出中性半缩醛（这步可逆且大致热中性——简单醛的半缩醛通常不稳定到无法分离）。然后是真正的功夫：把半缩醛的 $\mathrm{OH}$ 质子化，失水生成共振稳定的氧碳鎓离子（$\mathrm{PhCH^+ \leftrightarrow PhCH{=}O^+Me}$），第二个甲醇将其捕获；脱质子得缩醛。每一步都可逆，所以过量甲醇（或除水）推动缩醛生成，大水则推动水解——是勒夏特列原理，不是新化学。合成用途：缩醛是一个醚样的碳，既无亲电性又无 $\mathrm{O{-}H}$，对碱、氢负离子、有机金属试剂都稳定——所以它在分子其他部位被进攻时*保护*羰基，事后用水酸摘除。又是醛与酮之别：酮缩醛生成迟缓（位阻），且要用二醇来制备（环状缩醛，熵上有利）。
:::
:::

::: definition 亚胺与 pH 最优点 {#def-imines}
含氮亲核试剂 $\mathrm{RNH_2}$、$\mathrm{ROH_2N}$（羟胺）、$\mathrm{R_2NNH_2}$（肼）加到羰基上再脱水：产物是 $\mathrm{C{=}N}$ 化合物——**亚胺**（$\mathrm{R_2C{=}NR'}$）、**肟**或**腙**——经由醇胺（carbinolamine）中间体。速率对 pH 呈钟形：太酸则胺被质子化（无孤对电子，无亲核性）；太碱则醇胺的 $\mathrm{OH}$ 无法以 $\mathrm{OH^-}$ 离去（消除需要把 $\mathrm{OH}$ 质子化）。最优点在 $\mathrm{pH} \approx 4\text{–}5$ 附近，那里游离胺与质子化 $\mathrm{OH}$ 恰好共存。腙与缩氨脲是结晶好、熔点锐的衍生物——醛酮未知的经典鉴定手段——而亚胺生成几乎是所有生物羰基化学的第一幕，从转氨基到糖酵解。
:::

::: warning 选错条件的三种方式 {#warn-conditions}
**(1)** 绝不在质子溶剂里跑格氏或 $\mathrm{LiAlH_4}$：每个分子一个 $\mathrm{O{-}H}$ 当量就瞬间杀死试剂（共轭酸烷烃的 $\mathrm{p}K_\mathrm{a} \approx 50$——酸碱反应快过任何加成）。**(2)** 质子化发生在氧而非碳：在酸催化下画出碳质子化羰基的学生，画的是一个碳正离子，而氧碳鎓离子是免费的。**(3)** 弱亲核试剂需要酸，但酸*太多*会把亲核试剂质子化到死（胺）或质子化到错误的原子；亚胺生成的钟形 pH 曲线就是普遍教训——催化是一种交易，每笔交易都有最优点。
:::

::: example 氰醇生成走多远？ {#ex-cyanohydrin}
$0.10\ \mathrm{mol\,L^{-1}}$ 乙醛与 HCN 反应，使 $\mathrm{CH_3CHO + HCN \rightleftharpoons CH_3CH(OH)CN}$ 的平衡常数 $K = 100$（浓度以 $\mathrm{mol\,L^{-1}}$ 计，两种试剂起始均为 $0.10\ \mathrm{mol\,L^{-1}}$）。求氰醇的平衡浓度。
::: solution

## 面：平面哪一侧被进攻

羰基碳是平面的，所以每一个创造手性中心的加成都原则上可以有两种走法。若醛酮无手性、试剂也无手性，则两个面是对映异位的，产物外消旋——反应没有任何办法偏向一边，任何单独针对反应的实验也永远破不了这个平局。有趣的情形是*手性*羰基化合物，此时两个面是非对映异位的，试剂能读出差别。模型与本章处处相同：亲核试剂沿比尔吉-杜尼茨轨迹到达，大致垂直于 $\mathrm{C{=}O}$ 键，并选择与相邻手性中心最大基团保持最远的接近方式。在**费尔金-安**（Felkin–Anh）图像中，相邻基团取向为最大取代基垂直于羰基（让开来犯的亲核试剂），进攻落在*最小*基团旁边——有氢就落在氢旁。选择性不大（常为 $2\text{–}10 : 1$）但有系统性，这正是不对称诱导、酶催化、以及 [[organic-2/condensations]] 立体化学章节拥有几何而非神秘解释的原因。酶把问题解得绝对：手性结合口袋只呈现一个面，这就是生物学让每一种糖和氨基酸只留一个对映体的底气。

## 后续内容

醛酮加成是序章；下一章的戏剧在于羧酸衍生物*也*加成，但其四面体中间体带着离去基团，于是加成塌缩回去或前进为**取代**——[[organic-2/carboxylic-derivatives]] 就是这个差别的全部故事。同一个四面体中间体，若在碳上脱质子而非在氧上质子化，就变成了烯醇负离子化学：[[organic-2/enols-enolates]]，然后是 [[organic-2/condensations]]。亚胺在 [[organic-2/amines]] 中作为还原胺化与酶催化的亲电试剂回归。这里用到的轨道图像——LUMO 系数、轨迹论证——在 [[bonding-structure/molecular-orbitals]] 中展开，并在 [[organic-1/stereochemistry]] 的面选择性模型中处处兑现。

::: summary
- 羰基是极化的 $\pi$ 键：碳亲电（进攻发生在碳，沿约 $107\ \mathrm{^\circ}$ 的比尔吉-杜尼茨角），氧是碱性位点（质子化发生在氧）。
- 加成把 $sp^2$ 变 $sp^3$；碳缺电子且位阻小时平衡偏向加成——从六氟丙酮（$K_\mathrm{hyd} \approx 10^6$）直到简单酮（$K_\mathrm{hyd} \sim 10^{-3}$）。
- 试剂家族：氢负离子（$\mathrm{NaBH_4}$ 温和，$\mathrm{LiAlH_4}$ 凶猛）、有机金属（不可逆成 C–C，无水，后处理得醇：$\mathrm{HCHO} \to 1^\circ$、$\mathrm{RCHO} \to 2^\circ$、$\mathrm{R_2CO} \to 3^\circ$）、氰根（可逆，氰醇）、水/醇（酸催化）、胺（加成-消除成 $\mathrm{C{=}N}$）。
- 两种机理：强亲核试剂在碱中进攻中性羰基、事后再质子化；弱亲核试剂需要先把氧质子化，而酸催化恰在亲核试剂强到无法幸存时失效。
- 缩醛在干酸中可逆生成、无视碱、在水酸中水解——这就是羰基保护基的定义。
- 亚胺/肟/腙生成在 $\mathrm{pH} \approx 4\text{–}5$ 最快：钟形曲线是酸碱协作的普遍签名，其两种失效方式就是上面警告框的两半。
:::

::: exercise 碳还是氧 {level=1}
判断下列反应发生在羰基的碳还是氧：(a) $\mathrm{CH_3MgBr}$；(b) $\mathrm{H_2SO_4}$（催化质子化）；(c) $\mathrm{NaBH_4}$；(d) 碱存在下的 $\mathrm{Me_3SiCl}$。
::: solution
(a) 碳（亲核试剂进攻亲电的碳）。(b) 氧（质子化发生在碱性位点）。(c) 碳（氢负离子加到碳上；烷氧负离子的氧随后被溶剂质子化）。(d) 氧（硅基化氧的孤对电子——与质子化同一位点偏好，硅是亲电的一方）。
:::
:::

::: exercise 判断正误并说明理由 {level=1}
(a) 醛对亲核加成的反应性高于酮。(b) 酸催化加速 $\mathrm{CH_3Li}$ 对酮的加成。(c) 缩醛对 $\mathrm{NaOH}$ 水溶液稳定。
::: solution
(a) 对——碳上位阻更小，向本就带正电的碳的给电子也更少；两者都让醛的加成井更深。(b) 错——$\mathrm{CH_3Li}$ 碱性太强；酸会先质子化并摧毁它（甲烷），快过任何加成；它在无水非质子条件下对*中性*羰基加成。(c) 对——缩醛需要酸才能打开（醚样碳上没有任何基团能以 $\mathrm{OH^-}$ 或 $\mathrm{RO^-}$ 在碱性条件下离去）；碱正是缩醛执行保护时的溶剂。
:::

::: exercise 设计格氏反应 {level=2}
为 1-苯基丙-1-醇给出两种羰基/试剂断开，并从实用角度取舍。
::: solution
醇碳上挂着 $\mathrm{Ph}$、$\mathrm{H}$、$\mathrm{CH_2CH_3}$：$2^\circ$，所以两半中任何一半都可以是格氏试剂。路线 1：苯甲醛 + $\mathrm{CH_3CH_2MgBr}$。路线 2：丙醛 + $\mathrm{PhMgBr}$。化学上都成立；实用上略偏路线 1（丙醛易挥发，沸点 $49\ \mathrm{^\circ C}$，且更易烯醇化；苯甲醛是稳定液体，无法烯醇化——无 $\alpha$-氢，碱性格氏试剂无从去质子化亲电试剂）。检验能力的问题：两个伙伴中是否有 $\alpha$-氢会被另一个的碱性进攻？这里路线 2 的丙醛有——一个真实但不大的副反应。
:::
:::

::: exercise 保护、进攻、脱保护 {level=2}
4-氧代戊醛同时带有醛和酮。设计一个序列，让格氏试剂*只*与酮反应，最后醛仍是醛。
::: solution
先把醛选择性地保护为环缩醛：乙烷-1,2-二醇，微量酸——*醛*的五元环缩醛优先形成，酮既慢又受位阻不利。然后让格氏试剂进攻游离的酮（无水醚；缩醛碳是醚样的，惰性），水相后处理。最后水酸水解缩醛：二醇经氧碳鎓离去，水将其捕获，醛归位。顺序就是全部答案：若不保护，格氏试剂会优先进攻醛（醛是更好的亲电试剂），所以必须先伪装"不活泼"的基团，再去进攻"活泼"的那个。
:::

::: exercise pH 最优点的定量分析 {level=2}
苯胺（$\mathrm{PhNH_3^+}$ 的 $\mathrm{p}K_\mathrm{a} = 4.6$）的亚胺生成分别在 $\mathrm{pH}\ 2$、$4.5$、$9$ 下进行。已知游离胺是亲核试剂、消除步骤需要酸，给速率排序并解释。
::: solution
$\mathrm{pH}\ 4.5 > \mathrm{pH}\ 2 \approx \mathrm{pH}\ 9$（两个极端都慢，原因相反）。$\mathrm{pH}\ 2$ 时 $\mathrm{pH} = \mathrm{p}K_\mathrm{a} - 2.6$，约 $99.7\ \%$ 的苯胺以 $\mathrm{PhNH_3^+}$ 存在——无孤对电子，无亲核性：加成停摆。$\mathrm{pH}\ 9$ 时胺完全游离，但醇胺的 $\mathrm{OH}$ 不能以 $\mathrm{OH^-}$ 离去，也没有足够的酸来质子化它：消除停摆。在 $\mathrm{pH}$ 接近 $\mathrm{p}K_\mathrm{a}$ 处，游离胺与可用的质子共存——钟形曲线的最大值就在胺的 $\mathrm{p}K_\mathrm{a}$ 附近，这就是"在 $\mathrm{pH}\ 4\text{–}5$ 缓冲"成为配方的原因。
:::

::: exercise 氰醇的记账 {level=3 check="0.073" hint="列出 K = x/(0.10-x)^2，令 u = 0.10-x 解二次方程；单位为 mol L^-1"}
丙酮氰醇生成由 $0.10\ \mathrm{mol\,L^{-1}}$ 丙酮与 $0.10\ \mathrm{mol\,L^{-1}}$ HCN 开始，$K = 100$（化学计量与单位同正文例题）。给出氰醇的平衡浓度，单位 $\mathrm{mol\,L^{-1}}$。
::: solution
$K = x/(0.10-x)^2 = 100$。令 $u = 0.10 - x$（每种试剂未反应的浓度）：$0.10 - u = 100u^2$，即 $100u^2 + u - 0.10 = 0$，故 $u = (-1 + \sqrt{1 + 40})/200 = 0.0270$，$x = 0.073\ \mathrm{mol\,L^{-1}}$。验算：$0.073/(0.027)^2 = 100.1$。二次方程的另一个根给出 $u < 0$，即转化率超过百分之百——化学拒绝它。
:::

::: exercise 机理取证 {level=3}
在 $\mathrm{H_2^{18}O}$ 中水解缩醛，返回的羰基氧含有 $^{18}\mathrm{O}$，且反应对缩醛为一级、对 $\mathrm{H^+}$ 为一级。这两个事实对机理说了什么，哪一步是决速步？
::: solution
标记说明键在哪里断、在哪里成：产物羰基中的氧来自水而非缩醛——缩醛的两个氧都随甲醇离去，进来的水（带 $^{18}\mathrm{O}$）经氧碳鎓离子成为羰基氧。这只有在 $\mathrm{C{-}OMe}$ 键*先于*新的 $\mathrm{C{-}O}$（水）键断裂时才可能：两个事件之间必须存在氧碳鎓中间体。速率方程 $k[\mathrm{缩醛}][\mathrm{H^+}]$ 随后锁定顺序：一个缩醛氧的快速预平衡质子化，接着是共轭酸单分子失甲醇生成氧碳鎓——与 $\mathrm{S_N1}$ 同属 A-1 逻辑，阳离子换成了氧碳鎓。之后的水捕获与质子转移都很快，动力学看不见。
:::
