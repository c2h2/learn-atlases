酯是一个学会了取代的醛。对酮不可逆加成的同一个亲核试剂，加到酰基化合物上之后——这就是全部的差别——*弹出一个离去基团*，因为酰基化合物（$\mathrm{RCO{-}Z}$：氯、羧酸根、烷氧基、酰胺基）的四面体中间体恰好有一个离去基团：挂在羰基碳上的 $\mathrm{Z}$。会塌回羰基的加成根本不是加成，而是**亲核酰基取代**，它是整个家族——酰氯、酸酐、酯、酸、酰胺——的支配性反应；这个家族的成员按一条规则互变，反应性按一个顺序排列。这个顺序——离去基团的阶梯——解释了为什么酰氯在空气中发烟而蛋白质在烧杯里安睡百年，解释了肥皂为何去污、DNA 骨架为何是长存的酯，也解释了为什么在实验室里造一个肽键需要像核糖体一样专职的试剂。

## 不肯停下来的加成：酰基取代

::: definition 亲核酰基取代 {#def-acyl-substitution}
亲核试剂加到酰基化合物 $\mathrm{RCOZ}$ 的羰基碳上，生成四面体中间体——同一个碳上挂着新基团和旧 $\mathrm{Z}$。中间体随即塌缩：氧的电子对落回成 $\pi$ 键，最好的可用离去基团——通常是 $\mathrm{Z}$——被弹出。净结果：$\mathrm{Z}$ 被亲核试剂*取代*，羰基全身而退。这是 $sp^2$ 碳上的加成-消除；与醛酮的加成不同，它通常可逆，因为每个参与者都是酰基化合物，每一步都是同一种步骤。
:::

::: proposition 离去基团阶梯决定反应性顺序 {#prop-ladder}
家族的反应性按**酰氯 $>$ 酸酐 $>$ 酯 $\approx$ 羧酸 $>$ 酰胺 $\gg$ 羧酸根**递减，两个同向的效应造就这个顺序。**离去能力：**被弹出的 $\mathrm{Z^-}$ 的稳定性取决于其共轭酸的强度——$\mathrm{HCl}$ 的 $\mathrm{p}K_\mathrm{a} \approx -7$、$\mathrm{RCO_2H} \approx 5$、$\mathrm{ROH} \approx 16$、$\mathrm{NH_3} \approx 38$——所以氯离子欣然离去，而酰胺负离子（$\mathrm{NH_2^-}$，共轭酸 $\mathrm{p}K_\mathrm{a}$ 38）永不离去。**基态给电子：**$\mathrm{Z}$ 越富电子，越把孤对电子灌进羰基（$\mathrm{Z \rightarrow C{=}O}$ 共振），碳就越不亲电；氮的给电子远强于氧，氯几乎不给。两个效应都把酰胺放在中性阶梯的底端、酰氯放在顶端。羧酸根负离子 $\mathrm{RCO_2^-}$ 在所有成员之下：负电荷排斥亲核试剂，两个等价的氧已经把能给的都给了。
:::

::: example 排序并论证 {#ex-ranking}
将乙酰氯、乙酸酐、乙酸乙酯、乙酰胺和乙酸根对中性水的水解排序，并解释为什么乙酰胺在沸水里能撑几个小时，而乙酰氯在冰水里就爆炸性反应。
::: solution
正是阶梯：$\mathrm{CH_3COCl} \gg (\mathrm{CH_3CO})_2\mathrm{O} > \mathrm{CH_3CO_2Et} > \mathrm{CH_3CONH_2} \gg \mathrm{CH_3CO_2^-}$。乙酰氯集本组最佳离去基团（$\mathrm{Cl^-}$，共轭酸 $\mathrm{p}K_\mathrm{a} \approx -7$）与最不给电子的 $\mathrm{Z}$ 于一身，所以连水这样的弱亲核试剂也加成很快，中间体又立即弹出氯离子；$\mathrm{HCl}$ 逸出平衡，使反应剧烈放热。乙酰胺有最差的离去基团（$\mathrm{NH_2^-}$/$\mathrm{NH_3}$），氮的强给电子在水到来之前就把羰基磨钝；酰胺的中性水解需要*酸或碱催化加加热*——即便如此也要几个小时。乙酸根仅凭静电就对水的亲核进攻免疫。从氯到酰胺约 $10^{12}$ 倍的速率跨度，是阶梯的可视化。
:::

## 互变地图：一切顺流而下

因为阶梯就是自由能的排序，互变自发地**顺流而下**：酰氯遇相应亲核试剂生成酸酐、酯和酰胺；酸酐生成酯和酰胺；酯与胺简单共热即得酰胺（氨解——胺是比任何醇都好的亲核试剂，而酰胺产物或是沉淀、或干脆就是热力学归宿）。逆流而上需要活化：把酸变成酰氯（$\mathrm{SOCl_2}$、草酰氯），或用偶联试剂就地造一个带更好离去基团的临时酯。

::: example 直接氨解 {#ex-aminolysis}
苄胺与乙酸乙酯反应，不加任何催化剂。预测产物，并说明这个中等亲电性的酯为何会反应。
::: solution
$N$-苄基乙酰胺加乙醇。胺既是比乙醇更好的亲核试剂（氮电负性较低，孤对更自由），又是更强的碱，所以回流下对酯的加成足够快，而四面体中间体弹哪个基团都行——但弹回乙氧基只是逆转上一步，而已生成的少量酰胺坐在阶梯底端，乙氧基无从反攻（那需要弹出酰胺负离子——阶梯禁止）。推动氨解的是热力学而非催化：平衡是一台顺流而下的单向棘轮。过量胺既不中和什么也不毒化什么，这是最绿色的酰胺合成。
:::
:::

::: history
酰胺键是生命的键，而选择性成键是肽化学的奠基难题——直到 1954 年约翰·希恩（Sheehan）从羧酸根本身的困境里借来一招。$N$-保护的氨基酸拒绝直接偶联，因为酸坐在阶梯底端；希恩用了 $N,N'$-二环己基碳二亚胺（$\mathrm{DCC}$），其中心碳是个亲电体，酸*加*上去生成 $O$-酰基异脲——一种离去基团为共振稳定脲负离子的酯，一个被突然提拔上阶梯的酰基化合物。氨基酸组分随即对其氨解，脲副产物是中性的、不溶的、化学上惰性的渣滓。希恩路线使第一个酶（核糖核酸酶）的全合成成为可能，并以 HATU、HBTU 等后裔的身份，至今仍是制造一切"不肯自己成键"的酰胺的默认方法。
:::

## 水解：两种机理，一个著名的不对称

::: proposition 碱不可逆地吃掉酯；酸只让酯达到平衡 {#prop-hydrolysis-modes}
**皂化**（$\mathrm{HO^-}$，水，加热）：氢氧根加成，四面体中间体弹出烷氧基，反应*本该*可逆——但产物是羧酸和烷氧基同处一瓶，而那个酸碱反应（$\mathrm{p}K_\mathrm{a}$ 5 对 16，$10^{11}$ 倍）比现场任何反应都快、都放能。最后的质子转移把平衡拉到底：碱水解是*促进*（promotion）而非催化，需要整整一当量氢氧根——这正是把脂肪变成肥皂的反应。**费歇尔酯化**（羧酸 + 醇，催化量酸）：每步可逆且大致热中性，位置全凭浓度——醇漫灌或除水得酯；水漫灌得水解。酸催化的原理是给羰基氧质子化（又是碱性位点），让弱亲核试剂得以加成；它无法把热中性的反应变成不可逆的反应。
:::

::: example 推动平衡 {#ex-fischer}
乙酸与乙醇生成乙酸乙酯，$K \approx 4$。一位学生把酸与醇各 $1.0\ \mathrm{mol}$ 混合，加催化量 $\mathrm{H_2SO_4}$，得到 $67\ \%$ 酯。解释这个数字，并给出两种超过 $95\ \%$ 的办法。
::: solution
以 $x$ 为酯的量，$K = x^2/(1-x)^2 = 4$ 给出 $x/(1-x) = 2$，$x = 2/3$——$67\ \%$ 不是催化的失败；催化剂只决定快慢，平衡本就是 $2:1$。要超过 $95\ \%$ 必须改变物料平衡：(1) 醇漫灌（乙醇作溶剂），让浓度项压倒 $K$；(2) 移走一个产物——蒸出低沸点酯，或用迪安-斯塔克分水器或分子筛把水拖走。两者都是勒夏特列，两者都是常规操作；第三种办法——先把酸不可逆地变成酰氯——是底物熬不住加热或酸时的*化学*解法。
:::
:::

::: example 为什么肥皂是故事的终点 {#ex-saponification}
三硬脂酸甘油酯（一种脂肪）与 $\mathrm{NaOH}$ 水溶液定量地给出甘油和硬脂酸钠；想只加一当量氢氧根就中途收手是不可能的。解释。
::: solution
每个酯都按加成-消除皂化，生成硬脂酸和（甘油上的）烷氧基，而两者一见面，酸就把质子交给烷氧基（$\Delta\mathrm{p}K_\mathrm{a} \approx 11$，$\Delta G \approx -60\ \mathrm{kJ\,mol^{-1}}$）。羧酸根产物坐在阶梯最底端——亲核试剂被静电排斥，离去基团也无影无踪——条件下逆反应不存在。"中途收手"需要抓住一个微秒内就塌缩的四面体中间体，或一个能被进攻的羧酸根，两者都不可能。定量是唯一的可能——这正是碱液溅到皮肤上又滑又皂的原因：它正在皂化你。
:::
:::

::: warning 断哪根 C–O 键 {#warn-cleavage}
酯有两根 $\mathrm{C{-}O}$ 键，断裂可以发生在任一根。普通酯按**酰氧键断裂**水解（断与羰基碳相连的键；烷基保住自己的氧——用 $^{18}\mathrm{O}$ 标记醇证明），但*叔*丁酯和苄酯在酸中改走**烷氧键断裂**，因为它们能生成稳定的 $t\mathrm{Bu^+}$ 或稳定阳离子：$t\mathrm{Bu}$ 酯在水酸中化作异丁烯消失，苄酯在 Pd 上氢解干净。这不是脚注——它是肽与核苷酸化学中两个最常用保护基（酸/醇的 $t\mathrm{Bu}$、胺的 $\mathrm{BOC}$，其*叔*丁基以同样方式离去）的工作原理。认定"酯总是酰氧断裂"的学生，无法解释为什么 $\mathrm{BOC}$ 在 TFA 中几分钟脱落、而甲酯几乎无感。
:::

::: quiz
哪个转化不加活化试剂就*不可能*？
- [x] 乙酰胺 → 乙酸乙酯
- [ ] 乙酰氯 → 乙酰胺
- [ ] 乙酸乙酯 → 乙酰胺
- [ ] 乙酸酐 → 乙酸乙酯
::: solution
酰胺到酯是*逆流*：乙氧基必须弹出酰胺负离子，而阶梯（$\mathrm{NH_3}$ 的 $\mathrm{p}K_\mathrm{a}$ 38 对乙醇的 16）禁止——必须先把酸活化（成氯，或 DCC 类偶联）。其余三个都顺流而下，无需任何帮助。
:::
:::

::: example 驯服还原 {#ex-dibal}
给出试剂：(a) 乙酸乙酯 → 只得乙醇；(b) 乙酸乙酯 → 乙醛；(c) 乙酰胺 → 乙胺。
::: solution
(a) $\mathrm{LiAlH_4}$ 然后水：氢负离子加成，烷氧基离去生成乙醛——而乙醛是醛，比生成它的酯还原得更快，所以两半都以醇收场（乙醛从未逃逸；乙氧基以乙醇形式离去）。(b) DIBAL-H（二异丁基氢化铝），一当量，$-78\ \mathrm{^\circ C}$，然后水解后处理： 位阻较大的铝氢化物只加一次，四面体中间体因与铝螯合而在低温下稳定；后处理时它塌缩成醛，而醛在能被继续还原之前已离开还原环境。停在醛是温度与后处理的把戏，不是试剂的偏好。(c) $\mathrm{LiAlH_4}$：酰胺一路还原成胺——羰基氧整个丢掉（$\mathrm{C{=}O \rightarrow CH_2}$），因为中间体的亚胺离子比现场任何东西还原得都快。$\mathrm{NaBH_4}$ 这三样一样都不干：酯和酰胺对它太不活泼。
:::
:::

## 后续内容

酰基取代是"有退路的四面体中间体"的化学；撤掉退路就回到 [[organic-2/carbonyl-addition]]，把 $\alpha$-碳改造成亲核试剂就进入 [[organic-2/enols-enolates]]——其缩合反应能构建这个家族造不出的 C–C 键。酯与酰胺的互变支撑着 [[organic-2/amines]] 通篇的保护基策略与合成课程的肽化学；阶梯的逻辑在活化酰基的生物学中原样重现（脂酰辅酶A 是硫酯——所谓"高能键"，不过是一个乔装的优良离去基团）。

::: summary
- 酰基化合物（$\mathrm{RCOZ}$）发生**加成-消除**：四面体中间体弹出 $\mathrm{Z}$，亲核试剂因此*取代*酰基碳而非永久加成。
- 反应性阶梯——酰氯 $>$ 酸酐 $>$ 酯 $\approx$ 酸 $>$ 酰胺 $\gg$ 羧酸根——由离去能力（$\mathrm{HZ}$ 的 $\mathrm{p}K_\mathrm{a}$）与 $\mathrm{Z}$ 的基态给电子决定，顶端两者最强、底端最弱。
- 互变顺流免费（酰氯变一切；酯 + 胺变酰胺）；逆流需要活化（$\mathrm{SOCl_2}$、DCC 类偶联）。
- 碱水解（皂化）不可逆，因为最后向羧酸根的质子转移是 $10^{11}$ 倍的棘轮；酸水解/酯化可逆，只能靠浓度操纵。
- 酯可在任一根 $\mathrm{C{-}O}$ 键断裂：酰氧断裂是常态，但 $t\mathrm{Bu}$/苄酯利用烷氧断裂——$\mathrm{BOC}$ 与苄基保护基的基础。
- 还原也读阶梯：$\mathrm{LiAlH_4}$ 把酯变成两个醇、酰胺变成胺；DIBAL-H 在 $-78\ \mathrm{^\circ C}$ 把酯停在醛；$\mathrm{NaBH_4}$ 只在门口礼貌旁观。
:::

## 练习

::: exercise 命名与排序 {level=1}
将丁酰氯、丁酸酐、丁酸甲酯、丁酰胺和丁酸根对与氨反应排序，并命名每种情况下生成的官能团。
::: solution
阶梯：丁酰氯 $>$ 丁酸酐 $>$ 丁酸甲酯 $>$ 丁酰胺（无催化对氨不反应）$\gg$ 丁酸根（惰性）。前三者的产物相同：丁酰胺（氯、酐或酯的氨解）；羧酸根必须先活化，氨才肯成酰胺。
:::
:::

::: exercise 选择试剂 {level=1}
从 $\mathrm{SOCl_2}$、$\mathrm{HO^-/H_2O}$、$\mathrm{H_3O^+/H_2O}$、$\mathrm{CH_3NH_2}$ 中选择：(a) 丙酸 → $N$-甲基丙酰胺（两步）；(b) 丙酸乙酯 → 丙酸，要求不可逆；(c) 丙酰胺 → 丙酸根离子。
::: solution
(a) $\mathrm{SOCl_2}$（酸 → 丙酰氯），然后 $\mathrm{CH_3NH_2}$（顺流氨解）。(b) $\mathrm{HO^-/H_2O}$ 后酸性后处理——皂化是不可逆选项；酸水解只会达到平衡。(c) $\mathrm{HO^-/H_2O}$，加热：酰胺皂化直接给出羧酸盐——若在酸中产物是游离酸，所以"离子型产物"指认了碱性条件。
:::
:::

::: exercise 酰胺为何如此顽固 {level=1}
用阶梯的两个因素，给出乙酰胺水解比乙酸乙酯慢一千倍的两条理由。
::: solution
(1) 离去基团：四面体中间体必须弹出 $\mathrm{NH_2^-}$/$\mathrm{NH_3}$（$\mathrm{p}K_\mathrm{a}$ 38）而非乙氧基（$\mathrm{p}K_\mathrm{a}$ 16）——按 $\mathrm{p}K_\mathrm{a}$ 标度是差 $10^{22}$ 倍的离去基团，过渡态只是部分感受。(2) 基态：氮把孤对灌进羰基的本领远强于氧，所以任何亲核试剂到来之前酰胺碳就已不那么亲电——加成峰与消除峰一起被抬高。
:::
:::

::: exercise 费歇尔的记账 {level=2}
乙酸与甲醇的酯化（$K = 4.0$），计算酯的产率：(a) 酸与醇等摩尔；(b) 酸溶于甲醇，$[\mathrm{MeOH}] = 5.0\ \mathrm{mol\,L^{-1}}$，$[\mathrm{AcOH}]_0 = 0.10\ \mathrm{mol\,L^{-1}}$。
::: solution
(a) $x^2/(1-x)^2 = 4$，$x/(1-x) = 2$，$x = 0.67$——$67\ \%$。(b) 把 $[\mathrm{MeOH}] \approx 5.0\ \mathrm{mol\,L^{-1}}$ 视为常数（溶剂），起始无水：以 $x$ = [酯] = [水]，$K = x^2/(5.0(0.10-x)) = 4.0$，即 $x^2 = 20(0.10 - x)$，$x^2 + 20x - 2 = 0$，$x = (-20 + \sqrt{408})/2 = 0.0995$——$99.5\ \%$。漫灌亲核试剂把平庸的平衡变成制备级的平衡；醇的浓度折进有效常数，而无水起始让产物对从零生长。
:::
:::

::: exercise 保护基逻辑 {level=2}
某肽合成使用 $\mathrm{BOC}$ 保护的氨基酸加 $t\mathrm{Bu}$ 侧链保护，用 TFA（含水三氟乙酸）脱除，而甲酯保留。用断裂机理规则解释两种行为。
::: solution
$\mathrm{BOC}$ 和 $t\mathrm{Bu}$ 酯都带着*叔*丁基：氧质子化后走**烷氧键断裂**，生成稳定的 $t\mathrm{Bu^+}$，再丢质子成异丁烯——一条不可逆、酸驱动、靠阳离子稳定的通路，在 TFA 中很快。甲酯没有这个选项：$\mathrm{CH_3^+}$ 不存在，断裂只能走酰氧键，需要在温和近无水的酸性条件下让水加成到一个弱亲电体上——慢到可以忽略。保护基的正交性就是两种断裂机理之差，这一对是教科书案例。
:::
:::

::: exercise 硫酯的把戏 {level=2}
脂酰辅酶A 硫酯（$\mathrm{RCO{-}SCoA}$）对胺和醇的反应性远高于氧酯，但中性 pH 下无酶时水解很慢。用阶梯的两个因素调和这两半。
::: solution
更活泼，因为硫是比氧更差的 $\pi$ 给体（$3p$ 轨道与羰基 $2p$ 重叠很差），基态给电子因素被削弱——碳更饿；且硫醇盐（RSH 的 $\mathrm{p}K_\mathrm{a} \approx 10$）是比烷氧基（$\mathrm{p}K_\mathrm{a}$ 16）更好的离去基团，优势 $10^6$ 倍。中性 pH 下慢，因为离去基团必须以*硫醇盐*形式离开，而 pH 7 时水这个弱亲核试剂对未活化酯的加成峰依然横在门口——阶梯排的是*中间体*塌缩的难易，但水的加成才是闸门。酶提供广义酸碱催化与邻近效应；生物学的"高能键"就是普通硫酯，被化学提拔上阶梯，被酶充分利用。
:::

::: exercise 还原选择性 {level=3}
4-乙酰苯甲酸甲酯同时带酮和酯。给出试剂实现：(a) 只把酮还原成醇；(b) 只把酯变成醛（保住酮）；(c) 两者全部彻底还原。
::: solution
(a) $\mathrm{NaBH_4}$，温和：酮对氢负离子的加成轻而易举，酯在它火力之下——阶梯的选择性就是试剂的选择性。(b) 难的一个：DIBAL-H、$-78\ \mathrm{^\circ C}$ 仍会先挑酮，所以先把酮保护成缩酮（二醇，微量酸——酮缩酮生成虽慢，但酯毫发无伤），DIBAL-H/$-78\ \mathrm{^\circ C}$ 还原酯，再用水酸揭开酮，顺带不水解任何东西。(c) 过量 $\mathrm{LiAlH_4}$：酮 → $2^\circ$ 醇，酯 → 醇（经由从未逃逸的醛）——一口锅，两级全还原。
:::

::: exercise 同位素作证 {level=3 hint="对两种断裂方式分别追踪标记必须落在哪里；答案是被断的键"}
用 $^{18}\mathrm{O}$ 标记的甲醇（$\mathrm{CH_3^{18}OH}$）在酸催化下与苯甲酸酯化。分离出的苯甲酸甲酯含 $^{18}\mathrm{O}$ 标记，生成的水无标记。(质子化)酸的哪根 $\mathrm{C{-}O}$ 键断裂——酰氧键还是烷氧键？这证明了机理的什么？
::: solution
**酰氧键**断裂——断的是酸自己的 $\mathrm{C{-}OH}$：标记随甲醇的氧进入，并一直连在羰基碳上，所以酸把*自己的*羟基氧交给了水。这只有在"标记甲醇对羰基加成、随后四面体中间体失去酸的 $\mathrm{OH}$（成水）"的机理下才可能——即酰氧断裂的加成-消除机理。烷氧键断裂（甲醇把氧交给酰基）会把标记放进水而不是酯。同位素直接读出断的是哪根键，与一个世纪前定夺酯水解机理的是同一套逻辑。
:::
