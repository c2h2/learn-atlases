在环里放进一个氧、氮或硫，环的整个性格就变了：苯那种不温不火的富电子气质，要么变成吡咯的热切亲核，要么变成吡啶的冷淡缺电子；一个惰性的碳氢化合物，在生物学手里变成了酶的催化机器，在工业手里则成了药物管线的大头——小分子药物中的绝大多数至少含有一个杂环，而 DNA 的四种碱基全都是杂环。本章是一次有向导的环系巡礼：它们如何命名，芳香性如何重新分配它们的电子，以及这些电子如何决定反应发生的位置。

## 环的命名：一套覆盖极广的小词汇表

::: definition 杂环命名：必须背下来的名字集 {#def-heterocycle-naming}
三档词汇表。**三、四元饱和环**：环氧化物（氧丙环，epoxide/oxirane）、吖丙啶（aziridine）、硫杂环丙烷（thiirane）；氧杂环丁烷（oxetane）、吖丁啶（azetidine）——张力大、反应性高。**六元饱和环**：哌啶（$\mathrm{C_5H_{11}N}$）、吗啉（$\mathrm{C_4H_9NO}$，氧与 $\mathrm{NH}$ 相对）、硫杂环己烷。**芳香五元、一个杂原子**：吡咯、呋喃、噻吩。**芳香六元、一个氮**：吡啶；两个氮：嘧啶、哒嗪、吡嗪。**并环**：吲哚（苯并吡咯）、喹啉（苯并吡啶）、苯并呋喃。编号从主杂原子开始（多个不同杂原子时约定 $\mathrm{O} > \mathrm{S} > \mathrm{N}$），并使取代基位次最小；芳香五元环常用希腊字母标位（$\alpha$ = 2 位，$\beta$ = 3 位）。这些名字古老、不规则、且必须背——你即将读到的每一篇文献里，它们每一个都是一个官能团。
:::

## 芳香五元环：杂原子交出两个电子

::: proposition 吡咯型环 π 电子过剩，热爱取代反应 {#prop-five-mem}
吡咯、呋喃、噻吩各自把杂原子的孤对电子贡献出来凑成 $6\pi$ 六电子体系——芳香性强弱顺序是噻吩（共振能约 $120\ \mathrm{kJ\,mol^{-1}}$）$>$ 吡咯（约 $90$）$>$ 呋喃（约 $70$），这个顺序对应着硫出人意料地乐意捐出它的 $3p$ 电子对、而氧舍不得交出它本就需要的那对电子（毕竟氧电负性大）。推论：这些环是**π 电子过剩**的——$\pi$ 电子密度比苯还高——所以它们发生亲电芳香取代**极其容易**，条件远低于苯，而且压倒性地在 **C2**（$\alpha$ 位）发生，因为 C2 进攻的芳基正离子中间体有三个共振式而 C3 只有两个。吡咯活泼到用乙酸硝化剂在 $-10\ \mathrm{^\circ C}$ 就能硝化、用 Vilsmeier 试剂就能甲酰化，而在强酸里会聚合；呋喃芳香性最弱，一不留神就像个环状双烯（会做 Diels–Alder 反应，在酸里会开环）；噻吩则是三兄弟里最像苯的——它扛得住 Friedel–Crafts 条件，硝化时需要货真价实的硝化试剂。吡咯的 N–H 是弱酸性的（按不同标度 $\mathrm{p}K_\mathrm{a} \approx 17$–$23$），而它的氮几乎无碱性，因为那对孤对电子就是六电子体系本身——芳香性一章讲过的道理，现在要派上大用场了。
:::

::: example 吡咯能在苯不敢的地方硝化 {#ex-pyrrole-nitration}
预测吡咯与乙酰硝酸酯（由 $\mathrm{HNO_3}$/乙酸酐制得）在 $-10\ \mathrm{^\circ C}$ 反应的产物，并解释为什么没有 C3 产物、也不需要酸催化。
::: solution
2-硝基吡咯。不需要催化，因为吡咯的 $\pi$ 密度超过苯——环直接进攻温和的 $\mathrm{NO_2^+}$ 等价物，速率比苯快 $10^3$–$10^5$ 倍（吡咯型环硝化相对速率就在这个量级）。C2 胜出，因为 C2 进攻的 $\sigma$ 络合物把正电荷离域到包括氮在内的三个位置，而 C3 进攻少一个稳定共振式；差距大到 C3 产物只是痕量。要避免强酸，因为质子化——无论质子化在环上还是产物上——会毁掉六电子体系，带正电的环会彼此聚合；温和的亲电试剂、温和的条件，是吡咯的化学之道。
:::
:::

::: example 呋喃：一心想当双烯的环 {#ex-furan-diene}
呋喃在室温就与马来酸酐反应给出桥环双加成物，与 HCl 则开环成 1,4-二羰基衍生物。用一个数字解释这两种反应。
::: solution
呋喃的共振能约 $70\ \mathrm{kJ\,mol^{-1}}$，是三兄弟里最低的——失去芳香性对它代价最小。与马来酸酐的 Diels–Alder 反应牺牲呋喃的芳香性换来两根 $\sigma$ 键和一个桥环加成物（酸酐作亲双烯体；加成物是动力学产物，且加热时反应出了名的可逆）；与 HCl 反应时，C2 质子化给出氧碳鎓稳定的阳离子，水进攻开环得 1,4-二羰基等价物（互变异构后是丁二醛类产物）。一个数字——最小的六电子红利——同时预言了两者：呋喃是一个随时差一步就变回丁二烯的芳香环。噻吩以 $120\ \mathrm{kJ\,mol^{-1}}$ 两样都不干；含噻吩燃料的加氢脱硫靠的是硫对金属的亲和力，而不是开环。
:::
:::

## 吡啶：把氮藏了一个电子的苯

::: proposition 吡啶 π 电子短缺：S_EAr 不行，S_NAr 在行 {#prop-pyridine}
吡啶的氮把孤对电子留在环平面的 $sp^2$ 轨道里（可用、有碱性，$\mathrm{p}K_\mathrm{a}$ 5.2），只向六电子体系贡献一个电子——但它的电负性从环上**抽走** $\pi$ 电子密度，使吡啶**π 电子短缺**，像硝基苯。因此亲电取代需要苛刻条件且落在 C3（3 位，"间位型"：C2/C4 进攻的芳基正离子会把正电荷放到氮上）。相反，亲核芳香取代在 C2、C4 却很容易，因为 Meisenheimer 阴离子的电荷能落到氮——环自己的原子上。**Chichibabin 反应**（$\mathrm{NaNH_2}$，加热）以加成–消除机理把吡啶在 C2 胺化，氢负离子作离去基团；2-位和 4-位卤代吡啶对胺和醇盐的反应性堪比酰氯；而 **N-氧化物**把抽电子翻了个面——$\mathrm{O^-}$ 向环给电子，于是吡啶 $N$-氧化物在普通条件下硝化于 C4，4-取代吡啶（药物化学里的"4-吡啶基"骨架）就靠这条迂回路线到达。N-烷基化给出吡啶鎓盐，其环更加饥不择食（其烟酰胺版本 $\mathrm{NAD^+}$ 是生物体接受电子的主力）。
:::

::: example Chichibabin 的氢负离子退场 {#ex-chichibabin}
吡啶与 $\mathrm{NaNH_2}$ 在甲苯中 $100\ \mathrm{^\circ C}$ 反应，然后水解，得 2-氨基吡啶并放出氢气。写出机理，并说明氢负离子的离去何以可能。
::: solution
酰胺负离子加到 C2（该位的阴离子中间体能把电荷放到氮上），给出一个酰胺型负离子稳定的二氢吡啶化物；这个负离子从 C2 赶出 $\mathrm{H^-}$——平时不可想象，但产物是芳香性的 2-氨基吡啶，重新芳香化正是让氢负离子成为离去基团的热动力学驱动力；氢负离子（或负离子向氨的质子转移）放出 $\mathrm{H_2}$，所以反应会冒泡。这个模式是芳香取代一章 $\mathrm{S_NAr}$ 逻辑的变奏：离去基团换成了氢负离子，热动力学的报酬是恢复的芳香性。C4 同理（更强的碱、更高的温度给 4-氨基吡啶）；C3 用这条路到不了——中间体无法把电荷放到氮上。
:::
:::

::: example N-氧化物迂回术 {#ex-n-oxide}
设计由吡啶出发的合成：(a) 4-硝基吡啶；(b) 2-氯吡啶。需要时利用 N-氧化物化学。
::: solution
(a) 吡啶 + $\mathrm{H_2O_2}$/AcOH → 吡啶 $N$-氧化物；硝化（$\mathrm{HNO_3/H_2SO_4}$）→ 4-硝基吡啶 $N$-氧化物（叶立德的 $\mathrm{O^-}$ 端向 C4 给电子——乙烯酰胺型（vinylogous amide）的给电子行为）；脱氧（$\mathrm{PCl_3}$ 或 $\mathrm{H_2/Pd}$）→ 4-硝基吡啶。直接硝化吡啶要 $300\ \mathrm{^\circ C}$ 且给 C3。(b) 吡啶 + $\mathrm{POCl_3}$（或 $\mathrm{SOCl_2}$）→ 2-氯吡啶（经活化的 $N$-氯/氧鎓物种、氯离子进攻 C2——2-卤代吡啶之所以是这么好的 $\mathrm{S_NAr}$ 底物，其 C2 亲电性正是在这一步装上去的）。N-氧化物是吡啶的保护基兼改道器：它驯服环去迎接亲电试剂，并把亲电试剂引向 C4。
:::
:::

## 唑类、吲哚与生物学层

::: definition 唑类：两个氮，两种人格 {#def-azole}
含两个或更多杂原子的五元环：**咪唑**（1,3-二唑：一个吡咯型 $\mathrm{N{-}H}$ 加一个吡啶型 $\mathrm{N}$）、吡唑（1,2-）、噁唑、噻唑、三唑、四唑。咪唑是两性分子——两个氮上一个给质子一个收质子——其共轭酸的 $\mathrm{p}K_\mathrm{a}$ 为 7.0，与生理 pH 近在咫尺，所以咪唑（在组氨酸侧链里）就是酶催化的质子摆渡人：中性 pH 下的广义酸碱催化就是它的岗位职责。去质子的咪唑是极好的亲核试剂和配体（有机金属化学中的 $N$-杂环卡宾即由它衍生），而铜催化的叠氮化物与端炔环加成生成 1,2,3-三唑，是点击反应的原型，也是 2022 年诺贝尔化学奖的一部分（Sharpless、Meldal 与 Bertozzi；第三份奖给的是生物正交化学，不是泛泛的杂环合成）。**吲哚**是苯并合在吡咯 2,3-键上的并环：像吡咯一样 π 电子过剩，在 C3 取代（中间体保住苯环的芳香性）、条件温和——色氨酸、血清素和麦角生物碱都是 3-取代吲哚，而吲哚的 $\mathrm{N{-}H}$ 因六电子体系之故无碱性。
:::

::: example 生理 pH 下的咪唑 {#ex-imidazole}
组氨酸咪唑侧链的共轭酸 $\mathrm{p}K_\mathrm{a}$ 为 7.0（在酶的口袋中略被抬高）。在 $\mathrm{pH}\ 7.4$ 下质子化分数是多少？为什么恰恰是这个数字决定了组氨酸在活性中心被保守保留？
::: solution
$[\mathrm{BH^+}]/[\mathrm{B}] = 10^{7.0-7.4} = 0.40$，故质子化分数 $= 0.40/1.40 = 29\ \%$——71:29 的混合物，质子化状态所能处的最不"表态"的位置。一个在工作 pH 上半质子化的基团，可以毫不费力地充当酸或碱，而微小的环境变化（底物到来、口袋电荷）就能把比例推向任一边：组氨酸是唯一一个天生就在 pH 7 当骑墙质子供体/受体的氨基酸，酶于是用这样的骑墙者 staffing 活性中心。半胱氨酸和赖氨酸在 pH 7 锁死在碱性一侧，天冬氨酸锁死在酸性一侧；只有咪唑坐在栅栏上，而酶的活性中心雇的全是这种骑墙者。下面的 widget 用迭代解同一个方程。
:::
:::

::: warning 芳香不等于惰性 {#warn-heterocycle}
三种要绕开的翻车方式。**(1)** 强酸里的吡咯和呋喃：质子化毁掉六电子体系，带正电的环低聚——"它芳香，扛得住酸"对 π 电子过剩的环是错的。**(2)** Friedel–Crafts 条件或高温亲电试剂下的吡啶：先被烷基化或酰化的是氮的孤对电子，生成的吡啶鎓环对亲电进攻抵抗得更凶——永远先问试剂遇到的是环还是氮。**(3)** 环氧化物和吖丙啶根本不相：含杂原子的三元环是张力亲电试剂，被亲核试剂按 $\mathrm{S_N2}$ 规则开环（碱性：进攻位阻小的碳；酸性：进攻取代多、能稳定阳离子的碳）——就是 [[organic-1/alcohols-ethers]] 的醚化学，穿了件杂环的马甲。
:::

- [ ] 苯

::: history
赢得一个世纪的杂环：2001–02 年，K. Barry 夏普莱斯（Sharpless）及其同事（与莫滕·梅尔达尔（Meldal）独立的铜发现）用铜把叠氮化物与端炔接成 1,2,3-三唑，定量、水相、室温、对氧和几乎一切官能团免疫——"点击化学"。三唑从前只是个小众杂环，一夜之间成了化学生物学、药物发现和材料科学的万能连接子，因为反应的可靠性把杂环合成从烧瓶搬进了机器人；夏普莱斯与梅尔达尔分享 2022 年诺贝尔化学奖，另一位是卡罗琳·贝托齐（Bertozzi），她的生物正交化学是点击化学在活体系统中的姊妹篇。一个共振能只值一个脚注的环，凭一篇论文成了地球上产量最大的杂环。
:::

## 通向何处

杂环是本课程机理安身立命之处：吡啶的 $\mathrm{S_NAr}$ 是 [[organic-2/aromatic-substitution]] 规则的翻转，吡咯的 $\mathrm{S_EAr}$ 是该规则的放大，咪唑的质子账本是 [[organic-2/amines]] 的碱性，而 NAD$^+$/烟酰胺氧化还原对就是代谢里的吡啶鎓化学。重氮偶联在 [[organic-2/amines]] 里用芳胺造了偶氮染料；Mannich 反应和亚胺缩合则喂养着哌啶和吡啶的合成；而这一切的波谱鉴定——取代吡啶的 NMR 图样、三唑的 IR——是波谱课程的素材。[[organic-2/aromaticity]] 的芳香性账本，是你唯一永远不会丢的工具。

::: summary
- 杂环命名靠一小套必背名字（吡咯/呋喃/噻吩，吡啶/嘧啶，哌啶/吗啉，吲哚/喹啉）；编号从杂原子开始。
- 芳香五元环把杂原子孤对电子交进六电子体系：π 电子过剩、C2 容易 $\mathrm{S_EAr}$，芳香性噻吩 $>$ 吡咯 $>$ 呋喃——呋喃红利最低，所以它既是双烯又是酸灾。
- 吡啶把孤对电子留在六电子体系之外：π 电子短缺、有碱性（$\mathrm{p}K_\mathrm{a}$ 5.2），亲电去 C3、亲核去 C2/C4（Chichibabin、2-位卤素取代），N-氧化物把它改道到 C4 亲电取代。
- 唑类把吡咯型和吡啶型氮配成一对：咪唑接近中性的 $\mathrm{p}K_\mathrm{a}$ 使它成为生物学质子摆渡人，铜催化的三唑合成则是 2022 年诺贝尔奖所表彰的点击反应原型。
- 吲哚在温和条件下 C3 取代；其 N–H 无碱性，因为孤对电子就是六电子体系。
- 芳香 ≠ 惰性：π 电子过剩的环死于强酸，吡啶先反应在氮而不是环，三元杂环则是按 $\mathrm{S_N2}$ 规则开环的张力亲电试剂。
:::

::: exercise 哪个环，哪种反应 {level=1}
判断下列各对是亲电取代（EAS）、亲核取代（SNAr），还是都不容易：(a) 吡咯 + $\mathrm{Br_2}$；(b) 吡啶 + $\mathrm{Br_2}$；(c) 2-氯吡啶 + $\mathrm{NaOMe}$；(d) 苯 + $\mathrm{NaOMe}$。
::: solution
(a) EAS，瞬间在 C2 发生（吡咯 π 电子过剩）。(b) 都不容易——吡啶 π 电子短缺；溴代需要极端条件且给 C3。(c) 容易 SNAr：甲氧基加成的中间体把电荷放到氮上（2-卤代吡啶就是杂环里的酰氯）。(d) 都不：苯没有氮来稳定阴离子，也没有理由接受甲醇盐。
:::

::: exercise 碱性，再一次 {level=1}
哌啶（$\mathrm{p}K_\mathrm{a}$ 11.2）对吡啶（5.2）：用芳香性一章的论证解释这六个单位的差距。
::: solution
哌啶的氮是普通 $sp^3$ 胺：孤对电子在 $sp^3$ 轨道里，完全可用，质子化对环毫无影响。吡啶的孤对电子在 $sp^2$ 轨道——离核更近、能量更低、更不乐意成键结合质子——而且环的电负性还在从它身上抽电子；质子化还赔上了芳香环的静电舒适。杂化加芳香抽电子，六个 $\mathrm{p}K_\mathrm{a}$ 单位就是它们付的账：同一个论证把吡咯与环戊胺分开过，只不过这回六电子体系两边都完好无损。
:::

吲哚用温和试剂在低温溴代于 C3。用文字画出 C2 与 C3 进攻的两种 $\sigma$ 络合物，指出哪一种保住苯环的芳香性，并说明为什么这就定了胜负。
::: solution
C3 进攻：正电荷离域到氮上（亚胺正离子式共振式），*同时*并环里剩下的五个碳保住苯式六电子体系——中间体是被芳香性稳定的亚胺正离子。C2 进攻：电荷仍能到氮，但关键共振式里苯式环被破坏。C3 的中间体因此低得多，C3 取代于是成为规律（代谢里的色氨酸化学：亲电试剂——质子化的黄素、Mannich 亚胺正离子——全因这个理由奔向吲哚 C3）。五元环的一般规律（$\alpha$ 优于 $\beta$）在这里被并苯的算术改写：苯环的账本让 $\beta$（C3）赢了，因为 $\alpha$ 进攻要赔掉苯式芳香性。
:::

写出试剂：(a) 吡啶 → 2-氨基吡啶；(b) 吡啶 → 3-溴吡啶；(c) 吡啶 → 1-甲基吡啶鎓碘化物。

::: exercise 环氧化物开环 {level=2}
2-甲基氧丙环（环氧丙烷）与 (a) $\mathrm{NaOMe}$/甲醇；(b) 甲醇加催化量 $\mathrm{H_2SO_4}$。给出主产物和规则。
::: solution
(a) 碱性：$\mathrm{S_N2}$ 在位阻小的碳——甲氧基进攻 C1（$\mathrm{CH_2}$），质子转移后得 1-甲氧基-2-丙醇。(b) 酸性：质子化环氧化物中取代较多的碳带更多阳离子特征，甲醇进攻 C2，开环得 2-甲氧基-1-丙醇——甲氧基在仲碳上，留下伯醇。规则：碱性条件，位阻控制（取代少的碳）；酸性条件，电子控制（取代多的、稳定阳离子的碳）——与醚断裂的分裂一模一样，也是"环氧化物 + 醇盐"和"环氧化物 + 醇/酸"是两种不同合成的原因。
:::

::: exercise 点击及其算术 {level=3 check="28.6" hint="质子化分数 = r/(1+r)，其中 r = 10^(pKa - pH)；答案以百分数计"}
一个咪唑药物片段的共轭酸 $\mathrm{p}K_\mathrm{a}$ 为 7.0。计算它在 $\mathrm{pH}\ 7.4$ 的质子化百分数，并说明当该片段结合到一排羧酸盐围出的酶口袋时，这个百分数如何变化。
::: solution
$r = [\mathrm{BH^+}]/[\mathrm{B}] = 10^{7.0-7.4} = 0.398$；质子化分数 $= 0.398/1.398 = 28.6\ \%$。羧酸盐壁稳定阳离子：$\mathrm{p}K_\mathrm{a}$ 上升（一个羧酸盐对可把咪唑的 $\mathrm{p}K_\mathrm{a}$ 抬向 8–9），于是同一 pH 下质子化分数跳升——结合事件*挑选*了质子化形式，游离药物只有 $29\ \%$ 概率携带的那个质子，在结合时成了一条内置的盐桥。这就是组氨酸在酶中盛行的热力学机关：配体环境为质子化付账，质子化为结合付账。
:::

::: exercise 设计一个吡啶 {level=3}
设计合成：(a) 2-苯氧基-5-硝基吡啶；(b) 由可得的吡啶原料合成 4-氰基吡啶，按定位逻辑安排步骤顺序。
::: solution
(a) 从 2-氯-5-硝基吡啶出发（有商品，或由 2-氯吡啶硝化制得——其环本已 π 电子短缺，且 2-氯吡啶的硝化走 C5（C3 型位置），因为 C2 被占、而 C4/C6 的中间体把电荷放在被氮去稳定化的位置上）。然后苯酚钠以 $\mathrm{S_NAr}$ 取代 2-位氯（中间体电荷在氮上）——先硝化后取代，因为硝基同时加速 $\mathrm{S_NAr}$：两种去稳定化协同工作。(b) 4-吡啶基需要 N-氧化物迂回：吡啶 → $N$-氧化物 → 硝化（C4）→ 脱氧 → 4-硝基吡啶 → 还原（$\mathrm{Fe/HCl}$）→ 4-氨基吡啶 → 重氮化、$\mathrm{CuCN}$ → 4-氰基吡啶。氨基到腈的重氮置换——胺一章见过的——就是杂环摆脱氮的定位暴政的逃生舱。
