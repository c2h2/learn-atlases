上一章给碳装上了电子；这一章把碳对准碳。**缩合反应**是靠丢掉一个小分子——水，或一个烷氧基——来付账的成键反应，而羰基化学的两大缩合是同一个两步主意的两次运行：烯醇负离子（上一章的亲核试剂）进攻羰基（全课程的那个亲电试剂），加成物再消除。羟醛反应给出 $\beta$-羟基羰基，脱水后给出 $\alpha,\beta$-不饱和羰基；克莱森缩合给出 1,3-二羰基——恰恰是让上一章的酸性得以成立的化合物。两者联手建造了聚酮、甾体和一半药物化学论文里分子的碳骨架，而且逻辑干净到一年的合成课浓缩成两次断开。

## 羟醛反应：烯醇负离子找到醛

::: definition 羟醛反应 {#def-aldol}
烯醇负离子加到醛或酮上生成烷氧负离子，质子化后得 **$\beta$-羟基羰基化合物**——"羟醛"（aldol，醛 + 醇，名字来自第一个例子）。新键把供体的 $\alpha$-碳连到受体的羰基碳上；其余一切都是旁观者。碱催化时反应对氢氧根或烷氧根是催化的（产物的 $\alpha$-H 比醇溶剂更酸，所以产物常常以自己的负离子形式离场）；酸催化时经中性烯醇进攻质子化的羰基。逆反应——逆羟醛（retro-aldol）——是真实通路，不是形式：糖在代谢中就是靠它拆解的，这也是羟醛平衡如此依赖底物的原因。
:::

::: proposition 醛积极，酮摆烂，加热收尾 {#prop-aldol-eq}
羟醛加成可逆，平衡由位阻定夺：两分子并成一分子，新的 $\mathrm{C{-}C}$ 键必须补偿失去的 $\mathrm{C{=}O}$ $\pi$ 键和新增的拥挤。乙醛的平衡常数约 $10^3\ \mathrm{L\,mol^{-1}}$——$1\ \mathrm{mol\,L^{-1}}$ 溶液 $98\ \%$ 是羟醛；丙酮约 $2\times10^{-4}\ \mathrm{L\,mol^{-1}}$——同浓度下 $0.02\ \%$，差了五百万倍，因为产物是拥挤的酮-酮对。加热改变算法：羟醛脱水（碱中按 E1cb：先去质子，再弹出氢氧根——氢氧根是差的离去基团，但 E1cb 要等负离子就位才付弹出的账，所以能垒只是弹出这一步）给出 **$\alpha,\beta$-不饱和羰基**，其共轭使总缩合不可逆。脱水还*推动*不利的加成：每例羟醛合成里勒夏特列的搭档，都是烯酮的热力学优势。
:::

::: example 乙醛加倍 {#ex-aldol-acetaldehyde}
乙醛与稀碱室温反应得 3-羟基丁醛；加热得丁-2-烯醛（巴豆醛）。用文字给出两个机理，并计算 $1.0\ \mathrm{mol\,L^{-1}}$ 时以羟醛形式存在的醛分数（$K = 10^3\ \mathrm{L\,mol^{-1}}$）。
::: solution
碱夺 $\alpha$-质子（烯醇负离子保持极小的稳态浓度）；烯醇负离子在碳上进攻第二个乙醛（弯箭头从 $\alpha$-C 到羰基 C，$\pi$ 电子上氧）；烷氧负离子从水或乙醇夺质子得羟醛并再生催化剂。加热：氢氧根夺*另一个* $\alpha$-位（羰基与醇羟基之间——分子里最酸的质子），所得烯醇负离子经 E1cb 步弹出 $\mathrm{HO^-}$ 得共轭烯醛。平衡：以 $x$ 为羟醛浓度，$K = x/(1-2x)^2 = 10^3$；求解（下面的 widget 在迭代它）得 $x = 0.489\ \mathrm{mol\,L^{-1}}$，即 $97.8\ \%$ 的乙醛以羟醛形式结合。同一方程对丙酮取 $K = 2\times10^{-4}$ 得 $x = 2\times10^{-4}\ \mathrm{mol\,L^{-1}}$——醛与酮的五百万倍差距，一行代数。
:::

::: example 做对了的交叉羟醛 {#ex-crossed-aldol}
苯甲醛没有 $\alpha$-氢。预测 (a) 苯甲醛 + 过量乙醛、碱、温热；(b) 苯甲醛 + 丙酮（2 当量）、碱 的产物，并命名这一策略。
::: solution
(a) 一当量乙醛与一当量苯甲醛缩合：乙醛的烯醇负离子进攻苯甲醛（无法烯醇化，所以只能当受体），脱水给共轭烯醛 $\mathrm{PhCH{=}CHCHO}$，肉桂醛——肉桂的醛。(b) 丙酮有两个 $\alpha$-位，缩合两次：二苄叉丙酮 $\mathrm{PhCH{=}CHCOCH{=}CHPh}$，经典的本科实验，其黄色晶体与延伸共轭正是重点。这一策略——把可烯醇化的供体与*不可烯醇化*的受体（苯甲醛、甲醛、二苯甲酮）配对，使只有一方能生成烯醇负离子、交叉产物成为唯一产物——就是**交叉（混合、定向）羟醛**，其最严格的形式是克莱森-施密特（Claisen–Schmidt）缩合（芳香醛 + 酮/醛给肉桂醛型烯酮）。
:::
:::

## 克莱森缩合：自己酰化自己的酯

::: proposition 克莱森缩合及其唯一硬要求 {#prop-claisen}
带 $\alpha$-氢的酯，用*与自身烷氧基匹配*的烷氧基处理，缩合成 **$\beta$-酮酯**：烯醇负离子进攻第二个酯分子，四面体中间体弹出烷氧基（酰基取代，不是加成——离去基团正是酯给取代产物而醛给醇产物的原因），而反应本该是一地热力学鸡毛——酯是差的亲电体，烷氧基是差的离去基团——全靠最后一幕：$\beta$-酮酯产物（$\mathrm{p}K_\mathrm{a} \approx 11$）被瓶中的烷氧基立即去质子化，那步酸碱反应才是热力学引擎。推论：酯需要*两个* $\alpha$-氢（产物必须留一个以便去质子化）；消耗*整整一当量*碱而非催化量；且反应只在产物负离子比碱的共轭酸稳定得多时才成立——这就是乙醇的烷氧基（$\mathrm{p}K_\mathrm{a}$ 16）能从 1,3-二羰基手里拽走一个 11、却永远拽不走普通酯的原因。
:::

::: example 乙酸乙酯变乙酰乙酸乙酯 {#ex-claisen}
写出乙酸乙酯在 $\mathrm{NaOEt/EtOH}$ 中的克莱森缩合及后处理，并解释产物为何在被质子化之前先被去质子化。
::: solution
$2\,\mathrm{CH_3CO_2Et} \rightarrow \mathrm{^-CH_2COCH_2CO_2Et}$（钠盐）$+ \mathrm{EtO^-}$，再 $\mathrm{H_3O^+}$ 后处理得乙酰乙酸乙酯 $\mathrm{CH_3COCH_2CO_2Et}$。机理：乙氧基夺 $\alpha$-质子（平衡，烯醇负离子浓度极小——没关系，它在下游被消耗）；烯醇负离子进攻第二个酯的羰基；四面体中间体塌缩，弹出乙氧基；然后是算术：产物有两个羰基之间的质子（$\mathrm{p}K_\mathrm{a}$ 11），瓶中满是乙氧基（共轭酸 $\mathrm{p}K_\mathrm{a}$ 16），去质子以 $10^5$ 倍顺坡奔涌，把前面每一步上坡都拖着走。去掉这最后一步质子转移，乙酸乙酯的克莱森就是上坡反应——这正是甲酸酯、碳酸酯、苯甲酸酯与草酸酯（无 $\alpha$-H，无法自缩合）在 LDA 烯醇负离子的交叉克莱森里当*受体*的原因。
:::
:::

::: definition 戴克曼缩合与分子内选项 {#def-dieckmann}
**戴克曼（Dieckmann）缩合**是分子内的克莱森：二酯经匹配烷氧基处理环化成环状 $\beta$-酮酯，五、六元环成环顺利（与一切分子内反应的环大小偏好相同）。己二酸二乙酯给 2-氧代环戊烷-1-甲酸乙酯——五元环，因为*一个酯的烯醇负离子碳进攻另一个酯的羰基碳*，按成环原子数。产物两个羰基之间的环质子照旧酸，所以"整整一当量碱"的规则同样适用，而产物经烷基化、水解/脱羧后，就是取代环戊酮与环己酮的入场券。
:::

::: example 从机理导出环大小 {#ex-dieckmann}
己二酸二乙酯与 $\mathrm{NaOEt}$ 给五元环 $\beta$-酮酯；庚二酸二乙酯给六元环。从机理导出两个环大小。
::: solution
从一个酯羰基开始编号：己二酸酯 C1–C6，庚二酸酯 C1–C7。烯醇负离子在 $\alpha$-碳（C2）生成，进攻*另一个*酯的羰基碳——己二酸酯的 C6、庚二酸酯的 C7——因为除自己的羰基外只有它是可用的亲电碳。环即两个成键碳之间（含两端）的原子：己二酸酯 C2–C3–C4–C5–C6（五个），庚二酸酯 C2–C3–C4–C5–C6–C7（六个）。被进攻的羰基成为环酮；*进攻方*的酯保住自己的 $\mathrm{CO_2Et}$ 作 1-位取代基——于是得 2-氧代环戊烷-1-甲酸乙酯与 2-氧代环己烷-1-甲酸乙酯。口诀从机理里掉出来，不用背表：沿链从烯醇负离子碳数到被进攻的羰基碳。
:::
:::

## 倒读缩合反应

::: example 设计好的分子内羟醛 {#ex-intramolecular-aldol}
己-2,5-二酮与碱水溶液反应得 3-甲基环戊-2-烯-1-酮。给出机理，并解释为何五元环胜出。
::: solution
把二酮 $\mathrm{CH_3COCH_2CH_2COCH_3}$ 编号 C1–C6。碱夺端基甲基（C1）的质子；该烯醇负离子分子内进攻*另一个*酮羰基（C5），新键 C1–C5 闭成五元环（原子 C1–C5）。环内：C2 是幸存的酮，C5 是醇碳，挂着 OH 和 C6 甲基。脱水按 E1cb：C1 的质子——既是 C2 酮的 $\alpha$-位、又挨着 C5 羟基——是分子里最酸的；夺走它并从 C5 弹出氢氧根，双键落在 C1 与 C5 之间，与 C2 羰基共轭。按烯酮重新编号（C2 → C1），这正是 3-甲基环戊-2-烯-1-酮：羰基、内双键、$\beta$-碳上的甲基。其他成环方式差在种类而非程度：唯一的另一种分子内进攻是 $\alpha$-碳打自己的羰基（三元环，荒谬），分子间羟醛只会聚成一团。五元环加共轭烯酮：拴系负责选择，脱水负责盖章。
:::
:::

::: warning 羟醛的烂摊子，以及如何脱身 {#warn-aldol-mess}
把一种可烯醇化的醛与碱混在一起，你就接受了所有产物：自加成、双加成、脱水、逆反应乱炖——若合成所要，皆大欢喜；若不是，一团混乱。三条出路：(1) **定向羟醛**——LDA、$-78\ \mathrm{^\circ C}$，预先制成供体烯醇负离子，再加受体（受体须不可烯醇化，或最后加入、且对自己的酸性一无所知）；(2) **烯胺**——斯特克（Stork）的解法：仲胺（吡咯烷、吗啉）把酮变成烯胺，一个中性、只在一处烯醇化的亲核试剂，烷基化、酰基化后在水中东归原形；(3) **分子内化**——二酮除了环化别无选择，所以成环合成偏爱拴在一起的那版。还有命题里的平衡：酮的羟醛需要移除产物（索氏提取、迪安-斯塔克分水）或脱水的推动，否则干脆不发生。
:::

::: quiz
哪一组能干净地给出单一交叉羟醛产物？
- [x] 丙酮的 LDA 烯醇负离子，然后苯甲醛，然后温热
- [ ] 乙醛 + 丙醛，NaOH
- [ ] 丙酮 + 乙醛，NaOH
- [ ] 苯甲醛 + 甲醛，NaOH
::: solution
用 LDA 预制成丙酮烯醇负离子、再加苯甲醛（无 $\alpha$-H，不能自缩合），得单一交叉产物，脱水成苄叉丙酮。两种可烯醇化的醛（第二、三项）至少给四种产物。苯甲醛与甲醛之间没有任何 $\alpha$-氢——谁也无法生成烯醇负离子，所以什么都不发生（它们要走的是坎尼扎罗或交叉坎尼扎罗路线）。
:::
:::

::: history
羟醛反应比烯醇负离子年长。1872 年夏尔-阿道夫·武兹（Wurtz）发现乙醛被稀碱搅拌后加倍成碳数翻倍的新物质，并以其两个官能团命名为 *aldol*——比任何人肯承认碳负离子早二十年，比羰基结构本身尘埃落定早三十年。机理要等 1930–50 年代物理有机学派——英戈尔德（Ingold）传统——确立碳负离子、加成的可逆性与 E1cb 消除；而合成早已跑在理解前面：罗伯特·罗宾逊（Robinson）1920–30 年代的增环反应用羟醛逻辑造环，图里没有一个烯醇负离子；1960–70 年代的定向羟醛终于把武兹撞见的一切交到化学家手里。羟醛化学证明：一个反应可以在被理解之前有用八十年，被理解之后更有用。
:::

## 后续内容

本章造出的 1,3-二羰基正是上一章温和烯醇负离子化学的底物——两章合成一台机器，机器的产出 $\alpha,\beta$-不饱和羰基又是序列里下一个反应的亲电体：烯醇负离子对烯酮的共轭（迈克尔）加成、1,5-二羰基断开、以及熔合环系的罗宾逊增环。烯醇负离子的烷基化与酰基化在 [[organic-2/enols-enolates]] 补齐菜单；亚胺缩合（曼尼希、还原胺化）见 [[organic-2/amines]]；[[organic-2/heterocycles]] 的杂芳合成是请了氮入场的缩合。平衡的思路仍是 [[organic-2/conjugation]] 的那一套。

::: summary
- 羟醛 = 烯醇负离子 + 羰基 → $\beta$-羟基羰基；缩合 = 同一反应再加 E1cb 脱水成共轭 $\alpha,\beta$-不饱和羰基。
- 羟醛加成可逆、由位阻定夺：醛远在产物侧（乙醛 $K \sim 10^3$），酮远在反应侧（丙酮 $K \sim 10^{-4}$）；脱水拯救不利的场合。
- 交叉羟醛只在一方不能烯醇化（苯甲醛、甲醛）或供体烯醇负离子预先制成（LDA，或斯特克的烯胺）时才干净。
- 克莱森 = 烯醇负离子 + 酯，弹烷氧基 → $\beta$-酮酯；要求两个 $\alpha$-氢和一整当量匹配烷氧基，因为产物的去质子化（$\mathrm{p}K_\mathrm{a}$ 11）是热力学引擎。
- 戴克曼是分子内克莱森：二酯环化成五、六元环状 $\beta$-酮酯；环大小从烯醇负离子碳数到被进攻的羰基碳。
- 分子内羟醛胜过分子间的烂摊子，因为拴系强制邻近；产物是哪个能共轭的烯酮——又是热力学在挑环。
:::

## 练习

::: exercise 羟醛产物 {level=1}
给出 (a) 丙醛；(b) 丁-2-酮（一当量，甲基侧自羟醛）的羟醛加成产物（脱水前）。
::: solution
(a) 3-羟基-2-甲基戊醛：丙醛的烯醇负离子（在 C2，$\alpha$-碳）进攻另一个丙醛的羰基（C1），所以产物在供体-C2 与受体-C1 之间长出新的 $\mathrm{C{-}C}$，受体的 OH 在 C3、其乙基成为 3-位取代基。(b) 4-羟基-4-甲基己-2-酮：甲基侧烯醇负离子 $\mathrm{{}^-CH_2COCH_2CH_3}$ 进攻第二个丁-2-酮的羰基碳，得 $\mathrm{CH_3COCH_2C(OH)(CH_3)CH_2CH_3}$。动力学条件下甲基侧是常规供体；取代较多的烯醇负离子（乙基侧）给另一种区域化学。
:::
:::

::: exercise 克莱森资格 {level=1}
下列者在 $\mathrm{NaOEt/EtOH}$ 中能干净自克莱森的是：丙酸乙酯、2-甲基丙酸乙酯、苯甲酸乙酯、乙酸乙酯？逐一解释。
::: solution
乙酸乙酯：能（两个 $\alpha$-H；教科书案例）。丙酸乙酯：能——其 $\alpha$-碳是带两个氢的 $\mathrm{CH_2}$，克莱森化成 2-甲基-3-氧代戊酸乙酯。2-甲基丙酸乙酯：不能——只有一个 $\alpha$-H；产物无法被去质子，热力学引擎熄火（它反而是 LDA 烯醇负离子的良好*受体*）。苯甲酸乙酯：根本没有 $\alpha$-H——只能当受体。规则：当供体要两个 $\alpha$-氢，当干净受体要零个。
:::
:::

::: exercise 缩合还是加成？ {level=1}
判断用词并说明理由：(a) 乙酸乙酯 + 乙氧基 → 乙酰乙酸乙酯；(b) 乙醛 + 稀碱、冷 → 3-羟基丁醛。
::: solution
(a) 缩合：产物丢掉了乙醇（四面体中间体来的烷氧基）——成键的同时弹出小分子。(b) 加成：什么都没丢；羟醛*加成物*就是产物（脱水成烯醛才叫缩合，那需要加热）。"缩合"一词要求有离去的小分子；"羟醛加成"是它前一步的名字。
:::
:::

::: exercise 逆合成羟醛分析 {level=2}
把烯酮 $\mathrm{PhCH{=}CHCOCH_3}$ 断开成它的羟醛前体，并给出条件。
::: solution
烯酮的 $\beta$-碳就是当年受体的羰基碳：断开 $\mathrm{C_\alpha{=}C_\beta}$ 键——供体 = 甲基酮一侧（$\mathrm{COCH_3}$ 带 $\alpha$-CH2），受体 = 苯甲醛。条件：苯甲醛 + 丙酮（过量作溶剂，以偏向单次缩合）、$\mathrm{NaOH}$、乙醇、温热——克莱森-施密特配方给 $\mathrm{PhCH{=}CHCOCH_3}$（苄叉丙酮）。过量丙酮抑制第二次缩合（那会给出二苄叉丙酮）。

::: exercise 查尔酮 {level=2}
查尔酮（chalcone）是 $\mathrm{PhCH{=}CHCOPh}$。给出其合成，并解释为何成烯醇负离子的是苯乙酮而非苯甲醛。
::: solution
苯甲醛（无 $\alpha$-H，受体）+ 苯乙酮（甲基酮，供体），$\mathrm{NaOH/EtOH}$、温热：克莱森-施密特缩合给共轭烯酮（查尔酮，旧文献里的"β-甲基苯乙烯基酮"）。苯乙酮能成烯醇负离子是因为它有 $\alpha$-氢；苯甲醛没有，同一锅碱里它只能当亲电体。产物的共轭（烯酮 + 两个苯基）使脱水不可逆——这就是查尔酮在教学实验室从乙醇里结晶为黄色固体的原因。
:::

::: exercise 戴克曼设计 {level=2}
经由克莱森缩合与一次烷基化合成 2-甲基环戊酮，给出二酯与碱。
::: solution
己二酸二乙酯（$\mathrm{EtO_2C(CH_2)_4CO_2Et}$）经 $\mathrm{NaOEt/EtOH}$ 戴克曼缩合得 2-氧代环戊烷-1-甲酸乙酯；去质子化该 $\beta$-酮酯（$\mathrm{p}K_\mathrm{a}$ 11——碳酸盐或乙氧基即够），碘甲烷甲基化，再水解脱羧（酸水，加热）→ 2-甲基环戊酮。乙酰乙酸酯型序列在环上与在链上完全一样工作：环状 $\beta$-酮酯就是脱羧后酮的烯醇负离子的 2-位可取代合成子。
:::

::: exercise 平衡工程 {level=3 check="0.0002" hint="用逐次近似解 x/(1-2x)^2 = 2e-4；单位为 mol L^-1"}
丙酮自羟醛（$K = 2\times10^{-4}\ \mathrm{L\,mol^{-1}}$），计算 $1.0\ \mathrm{mol\,L^{-1}}$ 丙酮平衡时羟醛的浓度，并解释工业上仍如何由丙酮高产率制异亚丙基丙酮（脱水产物）。
::: solution
$x = K(1-2x)^2$；$x$ 极小，$x \approx 2\times10^{-4}\ \mathrm{mol\,L^{-1}}$——纸面上加成毫无希望。异亚丙基丙酮照样生成，因为羟醛会*脱水*（成异亚丙基丙酮，酸下再进佛尔酮与均三甲苯），下游每一步都把羟醛从平衡里搬走：羟醛 → 烯酮 → 共轭二烯酮的总序列热力学下坡，尽管第一级台阶上坡。连续移除产物（把成水的馏出液蒸走）把 $10^{-4}$ 的平衡变成制备路线——与费歇尔酯化同一套勒夏特列逻辑，跨了一个官能团家族。
:::

::: exercise 机理，双向 {level=3}
逆羟醛是真实反应：1,6-二磷酸果糖在糖酵解中裂成两个三碳糖。用文字写出碱中一般逆羟醛的弯箭头，并说明为何醛的羟醛加成虽有利，生物体的裂解却很快。
::: solution
加成的反面：碱夺 $\beta$-羟基羰基的 $\alpha$-质子（羰基与醇羟基之间那个），所得烯醇负离子的电子对把 $\mathrm{C_\alpha{-}C_\beta}$ 键推到 $\mathrm{C_\beta}$ 上，弹出烷氧基离去基团——羟醛加成的逆过程，E1cb 形状。生物的加速：醛缩酶用一个赖氨酸铵与底物酮生成席夫碱（亚胺离子），于是逆羟醛中渐成的碳负离子被稳定为烯胺，亚胺离子让裂解比任何氢氧根能做的容易得多；两个三碳产物再经水解释放，并被糖酵解的下一个酶卷走。教训就是本章的：羟醛是平衡，生物靠耦合把它倒着开——共价（亚胺离子）催化加产物移除，与烧杯里同样的两根杠杆。
