一个碳–碳双键是一件局域的事：两个碳共享一个 $\pi$ 键，其中的电子或多或少只属于这两个碳。把两个双键拉近到足够近——恰好隔一个单键——就会发生某种性质上全新的事情。$\pi$ 体系不再互为邻居，而开始成为一个体系："属于"一对碳的电子发现自己被四个碳共享，中间的单键变短，分子在更长的波长处吸收光，其氢化焓低于两个孤立烯烃应有的加和，而且它的加成反应分裂成两种产物，其比例可以用温度计来调节。这就是**共轭**，它是本课程的两大核心思想中的第一个——正是这个思想使苯、芳香性、羰基化学以及染料与视觉的颜色变得可以理解。本章在最简单的家园——共轭双烯——中建立这个思想，并同时建立整个机理有机化学中最重要的一对概念：动力学控制与热力学控制。

## 烯丙基体系：三个碳，一对电子

最小的共轭体系有三个碳，两个 $\pi$ 电子铺展在其上。从丙烯的甲基碳上移走一个氢负离子，你得到的不是双键旁边的普通伯碳正离子；你得到的是**烯丙基碳正离子**，其中空轨道与 $\pi$ 键是三个相邻碳上的相邻 $p$ 轨道，两个 $\pi$ 电子占据一个覆盖全部三个碳的轨道。

::: definition 共轭与烯丙基体系 {#def-conjugation}
当一个 $p$ 轨道——处于 $\pi$ 键中、空轨道中、单占据轨道中或容纳孤对电子——与另一个 $p$ 轨道相邻，使二者侧面重叠、其中的电子离域到两个以上原子上时，该体系是**共轭的**。**烯丙基体系** $\mathrm{CH_2{=}CH{-}CH_2}$ 在第三个 $p$ 轨道上带有两个、一个或零个电子，分别给出烯丙基**负离子**、**自由基**与**碳正离子**，它是原型：三个平行的 $p$ 轨道组合成三个分子轨道，电子占据能量最低者可用的轨道。**共轭双烯**是中性的四碳情形：两个 $\pi$ 键恰好被一个 $\sigma$ 键隔开，如丁-1,3-二烯 $\mathrm{CH_2{=}CH{-}CH{=}CH_2}$。
:::

共振语言（[[organic-1/organic-structures]]）把烯丙基碳正离子描述为两个等价结构——正电荷在 C1 或在 C3——的杂化体。杂化体不是在两者之间闪烁的平均；它是一个单一的分子，其静电势图在每个末端显示半个正电荷，其两个碳–碳键等长（$1.39\ \mathrm{\AA}$，介于烯烃 $1.34$ 与烷烃 $1.54$ 之间）。共振是记账方式；分子轨道才是实在，而对烯丙基体系，分子轨道很容易写出来。

::: proposition 烯丙基分子轨道 {#prop-allyl-mo}
三个平行的 $p$ 轨道组合成三个 $\pi$ 分子轨道：$\psi_1$，在所有相邻对之间成键（除分子平面外没有垂直于键轴的节点）；$\psi_2$，非键，带一个穿过中心碳的节点，因此其密度只位于两个末端；以及 $\psi_3^{*}$，强反键，带两个节点。烯丙基碳正离子有两个 $\pi$ 电子，把它们都放进 $\psi_1$；自由基向 $\psi_2$ 加一个电子；负离子再把它配对。在三种物种中，前线轨道都位于末端碳上：负离子的 HOMO 与碳正离子的 LUMO 在 C1 与 C3 上都有大而相等的系数，在 C2 上系数为零。
:::

最后这句话就是烯丙基体系全部反应性的一行表述：无论什么反应，都发生在两端，中间碳是旁观者。它也解释了经典观察——在烯丙基体系的任一端发生取代都给出相同的产物混合物。

::: example 两个离去基团，一个碳正离子，两种产物 {#ex-allyl-mixture}
3-氯丁-1-烯（$\mathrm{CH_2{=}CH{-}CHCl{-}CH_3}$）与 1-氯丁-2-烯（巴豆基氯，$\mathrm{CH_3{-}CH{=}CH{-}CH_2Cl}$）在水/丙酮中的溶剂解都远快于相应的饱和氯化物，而且两者以相同的比例给出相同的两种醇。中间体是什么，两种醇各是什么？
::: solution
任一种氯化物电离都给出*同一个*烯丙基碳正离子，$\mathrm{CH_2{=}CH{-}\overset{+}{C}H{-}CH_3 \leftrightarrow\, ^{+}CH_2{-}CH{=}CH{-}CH_3}$：第一种情形电荷始于 C3，第二种始于同一个离域体系的 C1。水随后可在任一端捕获该碳正离子。进攻仲末端给出丁-3-烯-2-醇 $\mathrm{CH_2{=}CH{-}CH(OH){-}CH_3}$；进攻伯末端给出丁-2-烯-1-醇 $\mathrm{HOCH_2{-}CH{=}CH{-}CH_3}$。两种氯化物都给出两种醇，且比例相同，因为两者都经过同一个中间体——这正是共享碳正离子的诊断特征。相对于饱和氯化物的速率加速是同一离域作用的动力学标志：电离过渡态具有烯丙基碳正离子的特征，并像中间体一样被它稳定。
:::
:::

同一种离域在热化学中也有体现。丙烯中烯丙位 $\mathrm{C{-}H}$ 的键解离焓为 $369\ \mathrm{kJ\,mol^{-1}}$，而丙烷中伯 $\mathrm{C{-}H}$ 为 $423\ \mathrm{kJ\,mol^{-1}}$：自由基产物被 $54\ \mathrm{kJ\,mol^{-1}}$ 的离域所稳定。这就是为什么 $N$-溴代丁二酰亚胺选择性地溴代烯丙位（[[organic-1/radical-reactions]]），也是为什么裂化、燃烧与自氧化总是先攻击分子中双键旁边的位置。

## 丁-1,3-二烯：四个碳，四个轨道

::: definition 共轭、隔离与累积双烯 {#def-diene-classes}
带两个双键的双烯有三种几何构型。**共轭双烯**中两个双键被一个单键隔开（$\mathrm{C{=}C{-}C{=}C}$），$p$ 轨道沿四碳单元连续排布；丁-1,3-二烯是母体。**隔离双烯**中有两个或更多 $sp^3$ 碳插在中间（$\mathrm{C{=}C{-}C{-}C{=}C}$），两个 $\pi$ 键各自独立行动，如戊-1,4-二烯。**累积双烯**（丙二烯型）中两个双键共用一个碳（$\mathrm{C{=}C{=}C}$），其两个 $\pi$ 键位于互相垂直的平面。只有共轭一类有连续的 $\pi$ 体系以及随之而来的性质。
:::

丁-1,3-二烯的四个 $p$ 轨道组合成四个 $\pi$ 分子轨道。用四个 $\pi$ 电子填满最低两个，然后读出推论：HOMO（$\psi_2$）的末端系数同号，因此分子的两端在轨道上是连通的——与 C1 成键的试剂在 C2 与 C3 之间留下的键已经是 $\pi$ 性的；LUMO（$\psi_3^{*}$）的最大系数也在末端。中心 C2–C3 键长 $1.46\ \mathrm{\AA}$，而不是 $sp^3$–$sp^3$ 键的 $1.54\ \mathrm{\AA}$：它具有部分双键性质，绕它旋转的代价因此是 $\approx 25\ \mathrm{kJ\,mol^{-1}}$ 而不是通常的 $12$。

::: proposition 丁二烯的能级与共轭能 {#prop-butadiene-mo}
在最简单的 $\pi$ 分子轨道处理中，丁-1,3-二烯的四个 $\pi$ 轨道按能量递增位于 $\alpha+1.62\beta$、$\alpha+0.62\beta$、$\alpha-0.62\beta$ 与 $\alpha-1.62\beta$（$\beta$ 为负的共振积分），四个电子填满成键对 $\psi_1,\psi_2$。$\pi$ 总能量 $2(\alpha+1.62\beta)+2(\alpha+0.62\beta)=4\alpha+4.48\beta$ 比两个孤立 $\pi$ 键（$4\alpha+4\beta$）低 $0.48\beta$；由于 $\beta$ 为负，这是稳定化——**共轭能**，热化学测得约 $15\ \mathrm{kJ\,mol^{-1}}$。
:::

::: example 用氢化测量共轭 {#ex-hydrogenation}
标准氢化焓为：丁-1-烯 $-126.8\ \mathrm{kJ\,mol^{-1}}$，戊-1,4-二烯（隔离双烯：恰为丁-1-烯的两倍）$-253.6\ \mathrm{kJ\,mol^{-1}}$，丁-1,3-二烯 $-238.9\ \mathrm{kJ\,mol^{-1}}$。求丁-1,3-二烯的共轭能并评论其大小。
::: solution
共轭能就是差额：$-253.6 - (-238.9) = -14.7$，即丁-1,3-二烯比带两个独立双键的分子**稳定 $14.7\ \mathrm{kJ\,mol^{-1}}$**。两点评论。第一，这个数值真实但温和——在这个尺度上共轭不是惊人的键强效应，当苯那大得多的稳定化在 [[organic-2/aromaticity]] 中出现时值得记住这一点。第二，戊-1,4-二烯使比较站得住脚：它的氢化焓确实是丁-1-烯的两倍——隔离双键确实可加和——所以共轭双烯的差额是共轭的性质，而非测量的产物。
:::
:::

有一个结构后果值得花一点时间，因为它不断重现：绕中心单键旋转给出两个平面构象异构体，**s-*顺** 与 **s-*反**（$s$ 指明是*单*键）。s-*反*式更稳定约 $4\ \mathrm{kJ\,mol^{-1}}$——链的两端相距更远——但 s-*顺*式是在成环反应中反应的那一个，因为只有在它里面两端才近到足以与同一个伙伴成键。被锁死为 s-*反*的双烯（如大多数环状双烯）恰好在这些反应中相应地迟钝。

::: example 反应性构象有多少？ {#ex-scis}
丁-1,3-二烯的 s-*顺*构象比 s-*反*构象能量高约 $4\ \mathrm{kJ\,mol^{-1}}$。在 $25\ \mathrm{^\circ C}$ 的平衡混合物中，具有反应性的 s-*顺*构象占多大分数？
::: solution
平衡常数（s-*反* $\rightarrow$ s-*顺*）为 $K = e^{-\Delta G^\circ/RT} = e^{-4000/(8.314\times298.15)} = e^{-1.61} = 0.199$，故 s-*顺*分数为 $0.199/(1+0.199) = 0.17$，约 $17\,\%$。将近六分之一的分子在任何时刻都处于反应性构象，这就是为什么"只有 s-*顺*式反应"与"室温下双烯顺利地进行成环反应"完全相容——反应抽干 s-*顺*池子，s-*反*式随即补充它。
:::
:::

## HBr 的加成：一个质子，两种产物

向丁-1,3-二烯加一当量 HBr，质子加到末端碳上，因为这个选择把正电荷放在烯丙基体系上，而不是放在未稳定的伯碳上。这一步的产物是烯丙基碳正离子 $\mathrm{CH_3{-}\overset{+}{C}H{-}CH{=}CH_2 \leftrightarrow CH_3{-}CH{=}CH{-}\overset{+}{C}H_2}$，溴负离子可以在任一个亲电末端成键。

::: definition 1,2-加成与 1,4-加成 {#def-12-14}
**1,2-加成**是两个新基团加到原双烯相邻的两个原子上：溴负离子进攻烯丙基碳正离子的 C2，产物是 3-溴丁-1-烯 $\mathrm{CH_3CHBrCH{=}CH_2}$，剩下的双键在原来内双键的位置。**1,4-加成**（共轭加成）是两个新基团加到共轭体系的两端：溴负离子进攻 C4，产物是 1-溴丁-2-烯 $\mathrm{CH_3CH{=}CHCH_2Br}$，一个新的 $\pi$ 键出现在 C2 与 C3 之间。两种产物来自同一个中间体；得到哪一种不是由机理决定，而是由两个速率常数之间、以及（若各步可逆）两个平衡常数之间的竞争决定。
:::

实验事实就是本章的教学大纲：

| 温度 | 3-溴丁-1-烯（1,2） | 1-溴丁-2-烯（1,4） |
|---|---|---|
| $-80\ \mathrm{^\circ C}$ | $80\,\%$ | $20\,\%$ |
| $40\ \mathrm{^\circ C}$ | $20\,\%$ | $80\,\%$ |

::: definition 动力学控制与热力学控制 {#def-kin-thermo}
当产物比例等于正向速率常数之比 $k_{1,2}/k_{1,4}$ 时，反应处于**动力学控制**之下——生成产物的那一步不可逆时正是如此：形成快的产物获胜，无论其稳定性如何。当生成产物的那一步可逆、产物之间达到平衡时，反应处于**热力学控制**之下：比例就是平衡常数 $K = e^{-\Delta G^\circ/RT}$，更稳定的产物获胜，无论其速度如何。两者之间的开关是可逆性——实践中由温度和时间提供，因为更高的温度激活了逆反应。
:::

HBr 加成的两种产物是教科书案例。1,2-产物的烯烃*较不*稳定（单取代，而 1,4-产物的烯烃是二取代），但它形成得更快：低温下溴负离子没有机会再离开，比例报告的是速率。1,4-产物更稳定约 $3.6\ \mathrm{kJ\,mol^{-1}}$（见[[#ex-ddg]]从 $40\ \mathrm{^\circ C}$ 比例提取此数值），而在 $40\ \mathrm{^\circ C}$，$\mathrm{C{-}Br}$ 键电离回到烯丙基碳正离子在反应时间尺度上足够快，混合物得以平衡，稳定产物随之积累。

::: proposition 为什么动力学产物是 1,2-产物 {#prop-why-12}
两个效应使 $k_{1,2} > k_{1,4}$。**电荷控制：**在不对称的烯丙基碳正离子 $\mathrm{CH_3{-}\overset{+}{C}H{-}CH{=}CH_2 \leftrightarrow CH_3CH{=}CH{-}\overset{+}{C}H_2}$ 中，取代较多的贡献式把电荷放在仲碳上、对杂化体贡献更大，因此较大的正电荷份额位于 C2，静电作用在那里也给出较大的捕获轨道系数。**邻近效应：**刚刚把质子递给 C1 的溴负离子仍作为接触离子对坐在 C2 旁边，在离子对内部捕获快于扩散到 C4。低温下邻近效应是更大的因素，并随离子对分离而消失。
:::

::: example 提取热力学差值 {#ex-ddg}
$40\ \mathrm{^\circ C}$ 下 HBr 与丁-1,3-二烯的产物混合物平衡于 $80\,\%$ 1,4-产物与 $20\,\%$ 1,2-产物。计算互变 1,2-产物 $\rightarrow$ 1,4-产物的 $\Delta G^\circ$。（$\Delta G^\circ$ 以 $\mathrm{kJ\,mol^{-1}}$ 作答。）
::: solution
平衡常数 $K = 0.80/0.20 = 4.0$，故
$$
\Delta G^\circ = -RT\ln K = -8.314\ \mathrm{J\,K^{-1}\,mol^{-1}} \times 313.15\ \mathrm{K} \times \ln 4.0 = -3.61\ \mathrm{kJ\,mol^{-1}}.
$$
1,4-产物更稳定 $3.6\ \mathrm{kJ\,mol^{-1}}$——一个很小的数，这正是 $120\ \mathrm{K}$ 的温度变化就能翻转比例的原因：$40\ \mathrm{^\circ C}$ 时 $RT$ 为 $2.6\ \mathrm{kJ\,mol^{-1}}$，几个 $\mathrm{kJ\,mol^{-1}}$ 的稳定性差意味着几倍的因子，而非板上钉钉。
:::
:::

::: warning 动力学控制与热力学控制"不是"的三件事 {#warn-kin-thermo}
**（1）**"动力学产物是 1,2-产物"是关于*这个*反应的事实，不是定义。若某产物的过渡态更低*且*势阱更深，它在任何温度都获胜，无控制可言。**（2）**热力学控制不意味着"更高温度让更稳定的产物形成得更快"——它意味着各步已经*可逆*；稳定产物积累是因为不稳定的一再退回同一个烯丙基碳正离子。产物无法电离回去的反应即使在 $400\ \mathrm{^\circ C}$ 也处于动力学控制之下。**（3）**这两个标签不是道德排序：动力学控制下*较不*稳定的产物不是失败也不是杂质，它是另一个问题（"什么形成最快？"）的正确答案，低温捕获动力学产物是一项刻意的标准技术——[[organic-2/enols-enolates]] 中的锂烯醇负离子正是这样生成并捕获的。
:::

::: quiz
丁-1,3-二烯在 $-80\ \mathrm{^\circ C}$ 与一当量 DBr 反应，条件保证产物不再平衡。哪个描述给出主产物？
- [x] D 在 C1、Br 在 C2：动力学 1,2-加成产物。
- [ ] D 在 C1、Br 在 C4：热力学 1,4-加成产物。
- [ ] D 在 C2、Br 在 C3：跨中心键加成。
- [ ] 1,2-与 1,4-加成产物等量，因为烯丙基碳正离子是对称的。
::: solution
$-80\ \mathrm{^\circ C}$ 下动力学产物占优：D 加到末端碳 C1，生成取代较多的烯丙基碳正离子，溴负离子在离子对分离之前于相邻的 C2 被捕获——1,2-加成产物。最后一个选项是陷阱：*母体*烯丙基碳正离子 $\mathrm{C_3H_5^+}$ 是对称的，但甲基取代破坏了对称性，把更多电荷放在 C2，使两个末端化学上不同。
:::
:::

::: history
"共轭"一词是个幸存者：1880 年代它指两个碱性基团与一个酸"成对"的盐，其现代 $\pi$ 体系含义直到 1920 年代才由罗伯特·罗宾逊（Robert Robinson）的工作固定下来，他的**乙烯基同系**（vinylogous series）概念表明双键能隔着单键传递羰基或孤对电子的性质——共轭即通信通道。量子描述随即到来：约翰·斯莱特（John C. Slater）在 1931 年解决了三碳与四碳问题，同年埃里希·休克尔（Erich Hückel）将其推广，莱纳斯·鲍林（Linus Pauling）在 1931–1933 年把整个课题翻译成共振语言，给了有机化学家至今沿用的两套等价词汇。实验骨架是 1930 年代基斯佳科夫斯基（Kistiakowsky）实验室的精密量热，其氢化焓数据——丁-1,3-二烯 $-238.9\ \mathrm{kJ\,mol^{-1}}$——仍是教科书引用的数字。
:::

## 后续内容

共轭不是专题；它是大多数有趣分子的默认状态。$\alpha,\beta$-不饱和羰基化合物——丁-2-烯醛、环己-2-烯酮——是被极化指向氧的共轭四电子体系，而该极化创造了*两个*亲电位点：羰基碳与 $\beta$-碳；亲核试剂在这类体系上 1,2-与 1,4-加成之间的选择是合成中最有用的选择性判断之一，在 [[organic-2/condensations]] 中展开。环状六电子共轭就是苯，[[organic-2/aromaticity]] 的全部内容都来自追问为什么这个数字特殊。跨几十个中心的共轭是 $\beta$-胡萝卜素的 $\pi$ 体系，其 HOMO–LUMO 间隙落在可见区，其颜色是看得见的共轭；吸收的定量处理属于光谱学课程。数学机器——完整的休克尔理论——在 [[quantum-chemistry/huckel-theory]] 中推导，这里假定的轨道记账在 [[bonding-structure/molecular-orbitals]] 中展开。

::: summary
- 共轭是相邻 $p$ 轨道的侧面重叠；它把 $\pi$ 电子离域到两个原子之外，缩短其间的单键并稳定分子。
- 烯丙基体系的三个分子轨道把前线系数放在末端碳上，这就是烯丙位反应发生在两端、且任一烯丙基离去基团给出相同产物混合物的原因。
- 丁-1,3-二烯的四个 $\pi$ 电子填满两个成键轨道；共轭能约 $15\ \mathrm{kJ\,mol^{-1}}$，由氢化焓对照隔离双烯模型测得。
- s-*顺*与 s-*反*构象的互转比普通单键慢（$\approx 25\ \mathrm{kJ\,mol^{-1}}$）；s-*顺*式是成环反应中的反应性构象。
- HX 与共轭双烯的加成经过同一个烯丙基碳正离子，同时给出 1,2-与 1,4-加成产物：$-80\ \mathrm{^\circ C}$ 下比例是动力学的（1,2 占 80:20），$40\ \mathrm{^\circ C}$ 下是热力学控制的（1,4 占 80:20）。
- 动力学控制意味着产物比例等于速率之比（不可逆步骤）；热力学控制意味着它等于平衡常数（可逆步骤）；开关是可逆性，而非温度本身。
- 1,2-产物形成更快，因为取代较多烯丙基末端的电荷控制以及反离子就在旁边；1,4-产物更稳定，因为它的烯烃取代更多。
:::

## 练习

::: exercise 给双烯分类 {level=1}
把下列双烯分类为共轭、隔离或累积：(a) 己-1,5-二烯；(b) 己-1,3-二烯；(c) 己-1,2-二烯；(d) 丁-2-烯醛中的双烯单元。
::: solution
(a) 隔离——两个双键之间隔着两个 $sp^3$ 碳。(b) 共轭——隔一个单键。(c) 累积——丙二烯型，两个双键共用 C2。(d) 共轭，且被极化：$\mathrm{C{=}C}$ $\pi$ 键与 $\mathrm{C{=}O}$ $\pi$ 键共轭，这正是丁-2-烯醛成为"$\alpha,\beta$-不饱和羰基化合物"的原因。
:::
:::

::: exercise 节点 {level=1 check="3"}
丁-1,3-二烯最高的反键 $\pi$ 轨道 $\psi_4^{*}$ 有多少个垂直于 $p$ 轨道轴的节点？（以数字作答。）
::: solution
三个。在线性多烯中第 $k$ 个分子轨道有 $k-1$ 个节点：$\psi_1$ 零个（全部同相），$\psi_2$ 一个，$\psi_3$ 两个，$\psi_4^{*}$ 三个——每一对相邻轨道都反号。节点消耗动能，这就是它们给能级排序的原因。
:::
:::

::: exercise 哪个键更短 {level=1}
在丁-1,3-二烯中，把 C1–C2 与 C2–C3 键长与乙烷型单键的 $1.54\ \mathrm{\AA}$ 相比较，并说出哪个构象更稳定。
::: solution
C1–C2 是真正的 $\pi$ 键，$1.34\ \mathrm{\AA}$。C2–C3 是因共轭而带部分双键性质的单键，$1.46\ \mathrm{\AA}$——短于 $1.54\ \mathrm{\AA}$ 但长于双键。s-*反*构象更稳定约 $4\ \mathrm{kJ\,mol^{-1}}$；s-*顺*构象虽然含量较少，却是几何上为成环反应准备好的那一个。
:::
:::

::: exercise 由能差求平衡组成 {level=2 check="81"}
互变 1,2-产物 $\rightarrow$ 1,4-产物的 $\Delta G^\circ = -3.6\ \mathrm{kJ\,mol^{-1}}$。在 $25\ \mathrm{^\circ C}$ 达到平衡的混合物含多少百分数的 1,4-产物？（以百分数作答。）
::: solution
$K = e^{-\Delta G^\circ/RT} = e^{3600/(8.314\times298.15)} = e^{1.45} = 4.3$，故 1,4-分数为 $4.3/(4.3+1) = 0.81$：$81\,\%$。同样的小能差在 $40\ \mathrm{^\circ C}$ 给出 80:20，在 $25\ \mathrm{^\circ C}$ 给出 81:19——几个 $\mathrm{kJ\,mol^{-1}}$ 的平衡比例对温度只有弱依赖；温度计真正控制的不是比例，而是*达到*平衡的速率。
:::
:::

::: exercise 预测产物 {level=2}
向丁-1,3-二烯加一当量 HBr。(a) 画出两种产物并分别标注 1,2 或 1,4。(b) $-80\ \mathrm{^\circ C}$ 下哪种占优？(c) $40\ \mathrm{^\circ C}$ 平衡后哪种占优？(d) 用一个从句说明为什么热力学产物有较稳定的烯烃。
::: solution
(a) 3-溴丁-1-烯 $\mathrm{CH_3CHBrCH{=}CH_2}$（1,2）与 1-溴丁-2-烯 $\mathrm{CH_3CH{=}CHCH_2Br}$（1,4，$E$ 异构体）。(b) 1,2-产物，动力学控制。(c) 1,4-产物，热力学控制。(d) 它的双键带两个碳取代基而另一个只有一个，烷基经超共轭稳定烯烃——[[organic-1/alkenes-alkynes]] 中确立的烯烃稳定性顺序就是全部解释。
:::
:::

::: exercise 由能垒求动力学选择性 {level=2}
某双烯–HX 加成的两个成键步有 $\Delta G^{\ddagger}_{1,2} - \Delta G^{\ddagger}_{1,4} = -2.2\ \mathrm{kJ\,mol^{-1}}$（1,2-途径更快），指前因子相等。$-80\ \mathrm{^\circ C}$ 下动力学控制给出怎样的 1,2:1,4 比例？
::: solution
$\dfrac{k_{1,2}}{k_{1,4}} = e^{-\Delta\Delta G^{\ddagger}/RT} = e^{2200/(8.314\times193.15)} = e^{1.37} = 3.9$，即约 80:20——与观察值一致。这段算术的要点：$2.2\ \mathrm{kJ\,mol^{-1}}$ 的能垒差，每分子不足 $kT$，在低温下已把产物比例推动四倍。溶液化学中的选择性活在极小的能量上。
:::
:::

::: exercise 寻找交叉点 {level=3}
设 1,4-成键步有较大的指前因子，$A_{1,2}/A_{1,4} = 1/3$，而 1,2-途径有较低的活化能，$E_{\mathrm{a},1,4} - E_{\mathrm{a},1,2} = 2.2\ \mathrm{kJ\,mol^{-1}}$。两速率常数在什么温度相等？低于该温度哪条途径是动力学的？
::: solution
令 $A_{1,2}e^{-E_{1,2}/RT} = A_{1,4}e^{-E_{1,4}/RT}$：则 $\dfrac{A_{1,2}}{A_{1,4}} = e^{-(E_{1,4}-E_{1,2})/RT}$，故 $\ln 3 = \dfrac{2200}{8.314\,T}$，$T = \dfrac{2200}{8.314\times1.0986} = 241\ \mathrm{K}$，约 $-32\ \mathrm{^\circ C}$。低于它，较低能垒的指数优势占主导，1,2-途径是动力学的；高于它，指数因子趋同，1,4-成键步较大的 $A$ 因子接管。动力学控制可以随温度易手——这是标签命名实验而非本质的又一理由。
:::
:::

::: exercise 诚实地写出机理 {level=3 hint="质子化时生成最稳定的烯丙基碳正离子；然后问哪个末端带较大的正电荷份额，哪个产物有取代较多的烯烃。"}
2-甲基丁-1,3-二烯（异戊二烯）与一当量 HBr 在 $-80\ \mathrm{^\circ C}$ 反应主要给出 3-溴-3-甲基丁-1-烯，而平衡产物是 1-溴-3-甲基丁-2-烯。解释两种选择性：给出质子化选择、烯丙基碳正离子与两种成键步，并说明为什么质子化发生在 C1。
::: solution
$\mathrm{CH_2{=}C(CH_3){-}CH{=}CH_2}$ 在末端 C1 质子化把电荷放在 C2——叔的且烯丙位的：$\mathrm{(CH_3)_2\overset{+}{C}{-}CH{=}CH_2 \leftrightarrow (CH_3)_2C{=}CH{-}\overset{+}{C}H_2}$。任何其他质子化都给出没有完整烯丙基离域的二级或一级碳正离子，所以质子去 C1——第一步选择*生成哪个碳正离子*，它选择叔烯丙基的那一个。在叔末端 C2 成键是快的一步：该贡献式主导杂化体，因此 C2 带较大的正电荷份额，而且递给 C1 的溴负离子还在离子对里守在 C2 旁边。产物是 1,2-加成产物 3-溴-3-甲基丁-1-烯，其烯烃单取代。在 C4 成键给出 1,4-加成产物 1-溴-3-甲基丁-2-烯，其烯烃三取代，因此低几个 $\mathrm{kJ\,mol^{-1}}$；升温后两种溴代物都经同一个碳正离子电离回去，三取代烯烃随之积累。动力学：叔电荷加邻近。热力学：烯烃取代度。一个碳正离子，两个问题，两个答案。
:::
