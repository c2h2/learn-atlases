到目前为止，每一章都在从外部进攻羰基碳。本章开辟第二战场：羰基*旁边*的碳，即 $\alpha$-碳——它的氢因结构原因而具有酸性——而它的负离子是碳上的亲核试剂，这是有机合成里最重要的一条事实。烷基负离子不存在；烯醇负离子存在，因为负电荷可以站到它该待的氧上。一旦 $\alpha$-碳能携带电子，羰基的极性就被反转——**极性反转**（umpolung）——碳碳键得以在任何有机金属试剂都直接够不到的位置形成。烷基化、卤代、外消旋化、下一章的缩合反应，以及脂肪酸与甾体全部的生物合成逻辑，都从烯醇负离子穿过。

## α-氢：藏在烃里的酸

::: definition 酮式、烯醇式、烯醇负离子 {#def-enol-enolate}
至少带一个 $\alpha$-氢的羰基化合物与其**烯醇**处于平衡——该互变异构体中 $\alpha$-碳变成烯碳、氧变成羟基（$\mathrm{C{=}C{-}OH}$，故名 *ene* + *ol*）。互变异构体是靠移动一个质子和一根 $\pi$ 键互变的构造异构体；烯醇式通常只是少量组分（丙酮：烯醇式约 $2.5 \times 10^{-4}\ \%$），但它正是酸性条件下与亲电试剂反应的物种。把 $\alpha$-质子彻底拿掉就得到**烯醇负离子**：共振杂化体，电荷分享在 $\alpha$-碳（碳负离子式，亲核的那个）与氧（烯醇盐式，电荷实际主要待的地方）之间。烯醇负离子是双位（ambident）亲核试剂：可以从碳成键，也可以从氧成键，二选一是个反复出现的主题。
:::

::: proposition α-氢为何有酸性 {#prop-acidity}
近似 $\mathrm{p}K_\mathrm{a}$：酮 $\alpha$-H $\approx 19$–$21$（丙酮 19.2），醛 $\approx 17$，酯 $\approx 25$，1,3-二羰基 $\approx 9$–$13$（乙酰丙酮 9.0，丙二酸二乙酯 13），对比烷烃 $\approx 50$、醇 $\mathrm{O{-}H}$ $\approx 16$。烯醇负离子被稳定，是因为电荷离域到了电负性的氧上——电荷在氧上的共振式占主导，这就是烯醇负离子按氧负离子来画、也大体按氧负离子行事、却在碳上反应的原因。两条结构推论：烯醇负离子的 $\alpha$-碳趋于 $sp^2$ 扁平（共轭要求平面），且负离子邻域的吸电子与共轭能力越强，$\mathrm{p}K_\mathrm{a}$ 越低——所以 1,3-二羰基（电荷摊到*两个*羰基上）酸性强到氢氧根都能明显烯醇化它。
:::

::: example 氢氧根不够格 {#ex-acidity}
丙酮（$\mathrm{p}K_\mathrm{a}$ 19.2）对氢氧根（水的 $\mathrm{p}K_\mathrm{a}$ 15.7）：计算烯醇化的平衡常数，以及 $1.0\ \mathrm{mol\,L^{-1}}$ 丙酮遇 $1.0\ \mathrm{mol\,L^{-1}}$ 氢氧根时烯醇负离子的浓度。对合成有何推论？
::: solution
$K = 10^{15.7 - 19.2} = 3.2 \times 10^{-4}$。以 $x$ 为烯醇负离子（也是水）的浓度，$x^2/(1.0-x)^2 = 3.2\times10^{-4}$，故 $x/(1-x) = 0.0178$，$x = 0.017\ \mathrm{mol\,L^{-1}}$——不到百分之二的烯醇负离子。合成的教训：氢氧根与烷氧根只给*催化量*的烯醇负离子，这对质子溶剂中进行的反应（羟醛加成、卤代）正合适，但当烯醇负离子必须当试剂用时毫无用处。要完全转化，得用共轭酸弱得多的碱：LDA（二异丙基氨基锂，共轭酸二异丙胺 $\mathrm{p}K_\mathrm{a} \approx 36$）在 THF、$-78\ \mathrm{^\circ C}$ 下不可逆且完全地烯醇化酮——本课题的烯醇化主力。
:::
:::

## 定向制备烯醇负离子：动力学与热力学

::: proposition 两种烯醇负离子，两种温度 {#prop-kin-thermo}
不对称酮可生成两种烯醇负离子。得到哪一种，取决于去质子化是否可逆。**动力学控制：**LDA、$-78\ \mathrm{^\circ C}$，最快夺走最易接近的质子——位阻较小的 $\alpha$-碳——且烯醇负离子一旦生成便无路可回（在 $-78\ \mathrm{^\circ C}$ 的时间尺度上没有胺来质子化它）：得到*取代较少*的烯醇负离子。**热力学控制：**可逆的碱（匹配醇中的烷氧基）在较高温度下让两种烯醇负离子经由酮互相平衡，*取代较多*（更烯样、更稳定）的烯醇负离子积累。两种情形正是 [[organic-2/conjugation]] 式动力学/热力学推理从加成换到酸性上的一次干净应用。
:::

::: example 哪种烯醇负离子，哪种产物 {#ex-keto-enolate}
2-甲基环己酮分别 (a) 以 LDA、THF、$-78\ \mathrm{^\circ C}$ 处理，再加碘甲烷；(b) 以 $\mathrm{NaOEt}$、EtOH 室温至温热处理，再加碘甲烷。各给出主要产物。
::: solution
(a) 动力学：LDA 从*未取代*的 $\alpha$-碳夺氢（C6 带两个氢；C2 只带一个，还挨着甲基），生成取代较少的烯醇负离子，在碳上烷基化：2,6-二甲基环己酮。(b) 热力学：可逆烯醇化汇入取代较多的烯醇负离子（双键伸向 C2 的那个，三取代），在那里烷基化得 2,2-二甲基环己酮。碘甲烷捕获的是当时存在的烯醇负离子，所以决定构造的是*碱与温度*——而非烷基化试剂。这是酸性论证的合成版：动力学酸性关乎质子被够到的快慢，热力学酸性关乎负离子的稳定。
:::
:::

::: definition 双位与硬软之选 {#def-ambident}
烯醇负离子的两个亲核位点化学性质不同：碳是软的（电荷摊在较大体积上），氧是硬的（电荷集中、电负性高）。与伯卤代烷、磺酸酯的烷基化主要发生在**碳**——与可极化的 $\mathrm{C{-}X}$ 碳软-软配对——尽管部分 $O$-烷基化（烯醇醚）会竞争，配位阳离子越硬（$\mathrm{Li^+}$ 螯合氧、把烷基更多送到氧上）越糟。硅氯试剂（$\mathrm{TMSCl}$）与酰氯在**氧**上反应，生成烯醇硅醚与烯醇酯，因为硅是硬亲电体的头号代表。烯醇硅醚不是弯路而是战略：中性、可分离，且经碳端与软亲电试剂反应（羟醛化学、卤代、环氧化），硅是随手可拆的把手。
:::

::: example 稳定化的烯醇负离子：乙酰乙酸乙酯路线 {#ex-aaa}
以乙酰乙酸二乙酯（乙酰乙酸乙酯合成法）合成戊-2-酮，并说明为何这里单烷基化很容易，而酮的直接烯醇负离子会过度烷基化。
::: solution
$\mathrm{NaOEt/EtOH}$，然后溴乙烷：乙氧基（匹配的烷氧基——不会酯交换）夺走两个羰基之间的质子（$\mathrm{p}K_\mathrm{a}$ 11），稳定化的烯醇负离子在碳上烷基化，而产物虽多了一处取代，却仍比乙醇酸得多，于是以负离子形式待到后处理——没有第二次烷基化。然后酸水、加热：酯水解成 $\beta$-酮酸，其在约 $100\ \mathrm{^\circ C}$ 经六元环状过渡态脱羧——$\mathrm{CO_2}$ 离去的同时把质子送到碳上——得戊-2-酮。乙酰乙酸乙酯合成法制造取代甲基酮；丙二酸酯合成法（$\mathrm{CH_2(CO_2Et)_2}$，同一序列，1,3-二酸脱羧）制造取代乙酸。两者之所以灵，是因为 1,3-二羰基 $\mathrm{p}K_\mathrm{a} \sim 11$ 让温和碱就能把烯醇负离子*完全*生成、且以稳定负离子形式存在——烯醇负离子化学里唯一"太稳定"反而是重点的地方。
:::
:::

## 烯醇：作为亲核试剂进攻亲电试剂的 α-碳

::: proposition α-卤代经由烯醇——且停不下来 {#prop-enol-halogenation}
酸中，烯醇（浓度极小、反应性极大）在碳上进攻 $\mathrm{X_2}$：速率方程对酮与酸为一级、对卤素*零*级——烯醇化是决速步，物理有机的经典结果。碱中卤代更快，因为产物 $\alpha$-卤代酮比原料酮*更*酸（卤素吸电子）：它的质子被优先夺走，卤素再装上，再装——所以甲基酮（$\mathrm{RCOCH_3}$）一路走到 $\mathrm{RCOCX_3}$，随后氢氧根在羰基上取代（氢氧根加成、弹出 $\mathrm{CX_3^-}$——一桩乔装的羧酸衍生物反应）给出 $\mathrm{RCO_2H}$ 加 $\mathrm{HCX_3}$：**卤仿反应**。碘的版本：黄色、带消毒水味的碘仿标记甲基酮（以及乙醇/乙醛，它们氧化后即被卤代）——这就是老的碘仿试验。
:::

::: example 卤仿反应，逐原子记账 {#ex-haloform}
苯乙酮与过量碘的 $\mathrm{NaOH}$ 水溶液反应，得羧酸盐与黄色沉淀。给出产物、配平方程式与机理的两半。
::: solution
苯甲酸盐（$\mathrm{PhCO_2^-}$）与碘仿（$\mathrm{CHI_3}$）：$\mathrm{PhCOCH_3 + 3\,I_2 + 4\,NaOH \rightarrow PhCO_2Na + CHI_3 + 3\,NaI + 3\,H_2O}$。第一半——彻底卤代：每根 $\mathrm{C{-}H}$ 换成 $\mathrm{C{-}I}$ 都让剩余 $\alpha$-质子更酸，所以每一轮烯醇负离子形成得更快；三轮，停不住。第二半——酰基取代：氢氧根加到酮羰基上，四面体中间体弹出 $\mathrm{CI_3^-}$（唯一好到能离去的碳负离子，被三个碘稳定），得苯甲酸，碱立即把它去质子化——正是这一步酸碱反应，如同皂化，让全局不可逆。同一套逻辑解释了为什么碱中丙酮的氯化停在一氯，而酸催化的卤代*能*停在一氯：酸条件下决速步是烯醇化，而吸电子的卤素*拖慢*产物酮的烯醇化——一卤代酮比原料更慢地烯醇化，反应就此止步。
:::
:::

::: warning α-碳上的三个陷阱 {#warn-alpha}
**(1)** 手性 $\alpha$-中心熬不过酸或碱：烯醇化即扁平化，再质子化从两面都来——$(S)$-2-苯基丁酮在催化量酸或催化量碱中都外消旋化，经由共同的平面烯醇/烯醇负离子。$\alpha$-碳的立体化学，其成立条件是附近*没有*酸、碱或光与空气。**(2)** 简单酮的烯醇负离子是强碱：遇仲、叔卤代烷，$\mathrm{E2}$ 消除跑赢烷基化——直接烯醇负离子烷基化是伯卤代烷的反应，句号（或改走硅醚/向山路线）。**(3)** 可烯醇化的酮、强碱、再加一个*亲电羰基*同处一瓶，是自缩合的配方——烯醇负离子会进攻生它的那个酮。这场"灾难"就是羟醛反应，下一章专章讲述。
:::

::: quiz
2-甲基环己酮在 $\mathrm{NaOEt}$/EtOH、$50\ \mathrm{^\circ C}$ 中处理，然后加烯丙基溴。烷基化之前哪种烯醇负离子占主导？
- [x] 取代较多的烯醇负离子（双键伸向 C2）
- [ ] 取代较少的烯醇负离子（双键伸向 C6）
- [ ] 两者一样多——烯醇负离子不互相平衡
- [ ] 热力学产物无法预测
::: solution
取代较多那个：质子溶剂中的烷氧基、温热，意味着可逆去质子化；可逆就意味着平衡组成——三取代、更烯样的烯醇负离子。（若是动力学条件 LDA/$-78\ \mathrm{^\circ C}$，则给 C6 烯醇负离子。）烯醇负离子在碱足够弱、温度足够高时绝对会互相平衡——这就是热力学控制的全部内容。
:::
:::

::: history
控制得到*哪种*烯醇负离子、以及它的*哪个面*，是烯醇负离子化学的长期难题，直到 1979–81 年大卫·埃文斯（Evans）把待烯醇化的底物接到一个手性辅基上——他的噁唑烷-2-硫酮/噁唑烷酮——让分子自己做选择。由 Evans 辅基衍生酰亚胺的硼或钛烯醇负离子是单一几何异构体，其取代基封住一个面，于是羟醛与烷基化反应以画得出来的、椅式过渡态给出 $>99:1$ 的非对映选择性。"埃文斯羟醛"把烯醇负离子的立体控制从运气变成设计，而辅基——一酯键而已——在温和的过氧化锂条件下卸载。烯醇负离子化学花三十年学会制造烯醇负离子；埃文斯教会了它*瞄准*。
:::

## 后续内容

两个烯醇负离子遇一个羰基是羟醛反应，两个带离去基团的羰基化合物相遇是 Claisen——[[organic-2/condensations]] 的全章就是本章的亲核试剂对准上一章的亲电试剂。烯醇负离子的烷基化与酰基化支撑着合成课程的成键章节；烯醇负离子的生物孪生子——硫酯的烯醇负离子——在生物体内建造每一条脂肪酸；极性反转的思想在 [[organic-2/condensations]] 的碳碳断开中、以及 $\beta$-内酰胺的药物化学（[[organic-2/heterocycles]]）里一再回归。动力学/热力学框架与 [[organic-2/conjugation]] 建立的是同一个。

::: summary
- 羰基的 $\alpha$-C–H 有酸性（酮 $\mathrm{p}K_\mathrm{a}$ 19–21，酯 25，1,3-二羰基 9–13），因为烯醇负离子把电荷放上氧；烯醇是中性的、对亲电试剂反应的互变异构体。
- 氢氧根只烯醇化简单酮约 $2\ \%$——做催化化学正好，做计量试剂无用；LDA（胺的 $\mathrm{p}K_\mathrm{a}$ $\approx 36$）在干 THF、$-78\ \mathrm{^\circ C}$ 给出完全、不可逆的烯醇化。
- 不对称酮：LDA/$-78\ \mathrm{^\circ C}$ 给动力学（取代较少）烯醇负离子；烷氧基/质子溶剂/温热给热力学（取代较多）那个——选择来自碱与温度，而非亲电试剂。
- 烯醇负离子是双位的：软亲电试剂（伯 $\mathrm{R{-}X}$）在碳上成键，硬的（$\mathrm{Me_3SiCl}$、酰基）在氧上；烯醇硅醚是可储存、可瞄准的烯醇负离子。
- 1,3-二羰基的烯醇负离子（丙二酸酯、乙酰乙酸乙酯合成法）用温和碱干净烷基化，并经六元环状过渡态脱羧——取代甲基酮与取代乙酸的经典路线。
- 烯醇 + $\mathrm{X_2}$：酸卤代对卤素零级、停在一卤；碱卤代自我加速直到卤仿反应；任何烯醇化都会把 $\alpha$-立体中心扁平化并外消旋化。
:::

## 练习

::: exercise 圈出酸性氢 {level=1}
(a) 环己酮与 (b) 苯乙酮各能形成几种不同的烯醇负离子？各涉及哪些 $\alpha$-位？
::: solution
环己酮：两个 $\alpha$-位是等价的 $\mathrm{CH_2}$——一种烯醇负离子。苯乙酮（$\mathrm{PhCOCH_3}$）：只有甲基带 $\alpha$-氢（带苯基的碳没有）——一种烯醇负离子，且罕见地完全没有区域选择问题。这些"简单"底物的教训：没有选择就没有动力学/热力学难题，这正是只要一种烯醇负离子时的首选底物。
:::
:::

::: exercise 选择碱 {level=1}
要完全烯醇化丙酸乙酯（$\mathrm{p}K_\mathrm{a} \approx 25$），在 $\mathrm{NaOEt}$、LDA、$\mathrm{NaOH}$ 中选一个，并论证。
::: solution
LDA。氢氧根（共轭酸 15.7）与乙氧基（16）弱了十五个 $\mathrm{p}K_\mathrm{a}$ 单位——至多 $10^{-9}$ 的烯醇负离子；而乙氧基虽做不了*完全*烯醇化，却是酯化学正确的*催化*碱，因为它不会酯交换（匹配的烷氧基）。LDA（$\mathrm{p}K_\mathrm{a}$ 36）以十一个单位——$10^{11}$ 倍——胜出，在 THF、$-78\ \mathrm{^\circ C}$ 定量给出酯的烯醇负离子，定向羟醛与酰化化学里的酯烯醇负离子正是这样制造的。
:::
:::

::: exercise 碘仿阳性 {level=1}
下列哪些碘仿试验阳性（黄色 $\mathrm{CHI_3}$）：丙酮、丙醛、乙醇、丙-2-醇、戊-3-酮？
::: solution
丙酮（甲基酮）、乙醇（被次碘酸盐氧化成乙醛，本身即甲基羰基）、丙-2-醇（氧化成丙酮）。丙醛不是（其甲基不在羰基上——无 $\mathrm{COCH_3}$），戊-3-酮也不是（两个乙基，羰基上没有直接相连的甲基）。试验读的是 $\mathrm{CH_3CO{-}}$，或卤代经氧化能够到的 $\mathrm{CH_3CH(OH){-}}$。
:::

::: exercise 动力学与热力学，再来一次 {level=2}
2-甲基环己酮生成热力学烯醇负离子后，在加任何卤代烷之前用 $\mathrm{D_2O}$ 淬灭：给出产物及其氘含量。为何这比烷基化更干净？
::: solution
热力学烯醇负离子的双键在 C1 与 C2 之间；$\mathrm{D_2O}$ 淬灭把一个氘放到 C2，得 2-甲基-2-氘代环己酮，另一个 $\alpha$-位（C6）未动。（反复的烯醇化-淬灭循环最终会把两个位置都交换掉，因为 C6 的质子也是酸性的，但对预先形成的烯醇负离子单次淬灭只在 C2 装一个 D。）比烷基化干净，因为质子化快、不可逆、没有消除与多烷基化副反应——同位素标记报告烯醇负离子的构造，不受烷基化试剂杂质的干扰。
:::

::: exercise 丙二酸酯合成法 {level=2}
以丙二酸二乙酯合成 3-甲基丁酸，说明选哪种碱及原因。
::: solution
在 $\alpha$-碳断开：丙二酸酯碳变成酸的 $\alpha$-碳，所以卤代烷必须提供 $(\mathrm{CH_3})_2\mathrm{CHCH_2{-}}$——异丁基溴，伯卤代烷（适合 $\mathrm{S_N2}$）。序列：$\mathrm{NaOEt/EtOH}$（匹配的烷氧基；底物 $\mathrm{p}K_\mathrm{a}$ 13 意味着乙氧基能烯醇化可观的分数，且产物负离子推动平衡），然后异丁基溴；再酸水、加热（两个酯水解，然后 1,3-二酸脱羧）→ 3-甲基丁酸。一个烷基、一个卤代烷、一个酸：丙二酸酯合成法就是乔装成丙二酸酯的乙酸 $\alpha$-碳取代。
:::

::: exercise 外消旋化的动力学 {level=2}
$(S)$-2-甲基环己酮在 $\mathrm{CH_3OH}$ 中加催化量 $\mathrm{NaOCH_3}$ 会完全失去旋光；纯 $\mathrm{CH_3OH}$ 不加碱则不会。解释两种情形，并说明"完全失去"对中间体意味着什么。
::: solution
有甲氧基时，每一轮烯醇化-再质子化都经过平面、非手性的烯醇负离子：在 C2 的再质子化从两面概率相等，两种构型都生成，反复循环把比例推向 1:1——完全外消旋化。无碱时，烯醇化的能垒（未催化的 $\alpha$-去质子，$\mathrm{p}K_\mathrm{a}$ 20 对抗甲醇的 16）在室温不可逾越，立体中心纹丝不动。旋光*完全*丧失——而非部分——说明中间体是*非手性的*（或在一对对映体形式间快速平衡）：构型的记忆在去质子那一刻即被销毁，而非在再质子化时。
:::

::: exercise 脱羧的几何 {level=3}
3-氧代丁酸在约 $100\ \mathrm{^\circ C}$ 脱羧；丁酸却需要碱石灰红热。用文字画出造成差别的过渡态，并预测 $\mathrm{CO_2}$ 丢失在己烷中快还是在水中快。
::: solution
$\beta$-酮酸把 $\mathrm{CO_2H}$ 悬在酮氧上方：六元环状过渡态中，酸质子转移给酮氧，同时 $\mathrm{C{-}C}$ 断裂、烯醇生成（$\mathrm{C{=}C{-}OH}$ 加 $\mathrm{CO_2}$，再经酮-烯醇互变异构得酮）。每根成键断键都是分子内的、几何上预先安排好的——一条低熵、低焓的通路，丁酸没有（其负离子需在红热下先生成，且质子无处可去）。溶剂：过渡态几乎非极性（中性酸、中性产物、质子在路上），所以反应*在己烷中比在水中快*——水稳定极性的基态（氢键酸）胜过稳定环状过渡态。一个由过渡态极性得出的经典反直觉预言。
:::

::: exercise O 还是 C {level=3 check="3" hint="数出最后的酰基取代步之前，每个甲基酮消耗几分子碘"}
碘仿反应中，每当量苯乙酮在最后的酰基取代步之前消耗几当量 $\mathrm{I_2}$？从机理论证。
::: solution
**3。** 碱促进卤代的每一轮装上一个碘，并再生（更酸的）$\alpha$-质子局面：$\mathrm{COCH_3 \rightarrow COCH_2I \rightarrow COCHI_2 \rightarrow COCI_3}$——三次碘代，三个 $\mathrm{I_2}$。第四步"不是碘代"而是氢氧根加成/弹出 $\mathrm{CI_3^-}$，不消耗碘（第四个碱当量交给了羧酸）。配平方程里每分子苯乙酮 $3\,\mathrm{I_2}$ 正是检验：卤代用三个，取代不用。
:::
