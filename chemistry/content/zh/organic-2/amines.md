氮以氨的有机子嗣的身份进入碳化学：胺。它们是生物分子中带碱性的、亲核的、有鱼腥味的那一半——每个蛋白质的 N 端都带着一个，从多巴胺到血清素的每个神经递质都是胺，肾上腺素（adrenaline）这个名字命名的就是一个带胺的分子。本章覆盖胺章节必须讲的三件事：胺为什么是碱（以及苯胺为什么弱一亿倍）、如何制备胺而不掉进过度烷基化的烂摊子、以及重氮离子——本课程最活泼的物种，一个带着永久离场邀请函的芳环，它把苯胺变成生产一切其他苯衍生物的工厂。

## 结构与碱性：氮的孤对电子的处境

::: definition 胺：锥形且会翻跟头 {#def-amine-structure}
胺是 $\mathrm{RNH_2}$（伯）、$\mathrm{R_2NH}$（仲）、$\mathrm{R_3N}$（叔）与季铵盐 $\mathrm{R_4N^+}$。氮为 $sp^3$ 锥形，孤对电子占据第四个位置——除桥连与张力体系外——锥体经平面（类 $sp^2$）过渡态翻转，室温下约每秒 $10^{10}$ 次（氨的 $\Delta G^{\ddagger} \approx 25\ \mathrm{kJ\,mol^{-1}}$），所以简单手性胺无法拆分：两个对映体互相折叠的速度快过任何瓶子装住它们的速度。季铵盐带四个不同基团、没有孤对电子，构型稳定——没有手性碳的手性分子。
:::

::: proposition 什么让胺显碱性 {#prop-basicity}
碱性是孤对电子与其质子化形式之间的稳定性之争。烷基抬高共轭酸的 $\mathrm{p}K_\mathrm{a}$（铵 9.25；甲胺 10.6；简单烷基胺 10–11），靠诱导与溶剂化。芳胺崩塌：苯胺共轭酸的 $\mathrm{p}K_\mathrm{a}$ 4.6，碱性弱 $10^6$ 倍，因为游离胺中孤对电子向环内给电子（在那里被稳定），而质子化后这份给电子荡然无存——共振稳定的是碱而非酸，这与碱想要的恰好相反。环上取代基完全服从芳香取代的逻辑：苯胺邻/对位的吸电子基把 $\mathrm{p}K_\mathrm{a}$ 压得更低（4-硝基苯胺 1.0——硝基隔着环把孤对电子抽走），给电子基抬高它（4-甲氧基苯胺 5.3）。杂芳烃分裂：吡啶的孤对电子在芳香六电子之外的 $sp^2$ 轨道里，有碱性但攥得紧（$\mathrm{p}K_\mathrm{a}$ 5.2）；吡咯的孤对电子*就是*芳香六电子，质子化它即毁灭芳香性——吡咯比苯胺弱一万倍碱性，有机会就在碳上质子化。
:::

::: example 给碱排序 {#ex-basicity-order}
按水溶液碱性排序：氨、环己胺、苯胺、4-硝基苯胺、吡啶、胍（共轭酸 $\mathrm{p}K_\mathrm{a}$ 13.6）。
::: solution
按共轭酸 $\mathrm{p}K_\mathrm{a}$：胍 13.6 $>$ 环己胺 10.6 $>$ 氨 9.25 $>$ 吡啶 5.2 $>$ 苯胺 4.6 $>$ 4-硝基苯胺 1.0。胍胜出，因为质子化给出胍鎓阳离子，其电荷由三个氮分享——质子化*赚得*共振能，正是苯胺悲剧的镜像。环己胺是平平无奇的脂肪胺（烷基给电子，没有环可漏）；吡啶被 $sp^2$ 攥紧；苯胺与 4-硝基苯胺被共振去活化，程度正比于环对电子的食欲。教训可推广：定位孤对电子——质子化若保住或赚得共振，胺就强；质子化若赔掉共振，胺就弱。
:::
:::

::: example pH 7.4 下有多少被质子化？ {#ex-protonation}
某候选药物带一个脂肪胺，共轭酸 $\mathrm{p}K_\mathrm{a}$ 10.0。在 $\mathrm{pH}\ 7.4$ 的血液中，未质子化（能跨膜）的分数是多少？
::: solution
$[\mathrm{BH^+}]/[\mathrm{B}] = 10^{\mathrm{pH}-\mathrm{p}K_\mathrm{a}} = 10^{-2.6} = 2.5\times10^{-3}$，所以未质子化分数为 $1/(1+398) = 0.25\ \%$。每一千个分子里有九百九十七个以铵离子身份在血流里坐车——水溶、不过膜——而那微小的游离碱分数才是跨膜抵达受体的部分；同样的平衡在每个隔室重新设定。这就是为什么碱性药物在酸性尿液中浓缩（离子截留），也是为什么"加一个碱性胺"是药物化学改善溶解度的第一招：下面的图显示分数如何残酷地跟着 pH 走。
:::

## 制备胺：四条路线与一个过度烷基化难题

::: proposition 直接烷基化失败；基于活化的路线不失败 {#prop-amine-synthesis}
氨加卤代烷给出的胺*比*造出它的氨*更*亲核（烷基给电子），于是再烷基化、再烷基化——反应停在伯、仲、叔、季统计混合的浓汤里。四条出路各自绕开这个陷阱。**过量氨**（大量、醇溶液、封管）：统计偏向首次烷基化。**酰化-还原**：氨或胺 + 酰氯 → 酰胺，再 $\mathrm{LiAlH_4}$ 把 $\mathrm{C{=}O}$ 还原成 $\mathrm{CH_2}$——酰基是单官能团化的把手（酰胺氮不二次酰化，因为酰胺不亲核），产物是干净的 $1^\circ$、$2^\circ$ 或 $3^\circ$ 胺。**还原胺化**：羰基化合物 + 胺，两者缩合成亚胺（羰基加成那一章），同瓶用 $\mathrm{NaBH_3CN}$（温和到 $\mathrm{pH}\ 5$ 下不碰羰基）或催化氢化还原——最好的通用路线，因为亲电体是羰基而非卤代烷，过度烷基化被亚胺的化学计量自我限制。**腈还原**：$\mathrm{RCN} \rightarrow \mathrm{RCH_2NH_2}$（$\mathrm{LiAlH_4}$ 或 $\mathrm{H_2}$/催化剂）——经氰化物从卤代烷增长一个碳；其芳香版是**硝基还原**（$\mathrm{ArNO_2} \rightarrow \mathrm{ArNH_2}$：$\mathrm{Fe/HCl}$、$\mathrm{SnCl_2}$ 或 $\mathrm{H_2/Pd}$），一切苯胺都由 [[organic-2/aromatic-substitution]] 直接产出。
:::

::: example 设计还原胺化 {#ex-reductive-amination}
给出 (a) $N$-甲基-1-苯基乙-1-胺；(b) 叔胺 $\mathrm{PhCH_2N(CH_3)CH_2CH_3}$ 的还原胺化合成。
::: solution
(a) 苯甲醛 + 甲胺 → 原位生成亚胺 $\mathrm{PhCH{=}NCH_3}$；再 $\mathrm{NaBH_3CN}$、$\mathrm{pH}\ 5$ → 胺。(b) 目标氮上的三个基团是 $\mathrm{CH_2Ph}$、$\mathrm{CH_3}$、$\mathrm{C_2H_5}$，所以用两轮还原胺化搭建叔胺。第一轮：苯甲醛 + 甲胺 → 亚胺，$\mathrm{NaBH_3CN}$ → $N$-甲基苄胺，一个仲胺。第二轮：这个仲胺 + 乙醛 → 亚胺离子（仲胺缩合得亚胺离子，没有中性亚胺可用），$\mathrm{PhCH_2N(CH_3){-}CH^+CH_3 \leftrightarrow PhCH_2N^+(CH_3){=}CHCH_3}$，$\mathrm{NaBH_3CN}$ 把氢负离子送到原来的羰基碳上，把它变成 $\mathrm{CH_2}$、装上乙基：$\mathrm{PhCH_2N(CH_3)CH_2CH_3}$。每轮恰好装上一条碳链——羰基碳成为与氮相连的 $\mathrm{CH}$ 或 $\mathrm{CH_2}$——所以苯甲醛供 $\mathrm{CH_2Ph}$、乙醛供乙基，而瓶中没有卤代烷，季盐永远成不了。
:::
:::

::: history
第一种合成抗生素是个胺——更准确地说，是体内被悄悄转化成胺的一种染料。1932 年格哈德·多马克（Domagk）报告红色偶氮染料百浪多息（Prontosil）能保护小鼠免受链球菌之害；1935 年巴斯德研究所丹尼尔·博韦（Bovet）的团队——雅克·特雷富埃尔（Tréfouël）、费德里科·尼蒂（Nitti）与雅克琳·博韦——证明这种染料是前药，在体内被剪切为对氨基苯磺酰胺，一种简单的芳香胺，模拟细菌生长因子对氨基苯甲酸、阻断叶酸合成。磺胺药大幅削减了战时创口感染死亡率，开启了抗生素时代，并教会药物化学它的奠基性把戏：药物可以是伪装，而胺——让分子被酶识别的基团——正是伪装佩戴之处。博韦获 1957 年诺贝尔奖；多马克的奖颁于 1939 年，正是磺胺本要输掉的那场战争开打之年。
:::

## 重氮离子：苯胺的第二职业

::: proposition 重氮盐：冷制，热用，丢氮气 {#prop-diazonium}
伯芳香胺 + 亚硝酸（$\mathrm{NaNO_2}$ 加含水矿酸原位生成）在 $0\text{–}5\ \mathrm{^\circ C}$ 给出**芳基重氮离子** $\mathrm{ArN_2^+}$；脂肪伯胺给出同样的离子只是转瞬——它们立即经类芳基阳离子塌缩成重排、乱炖的混合物（合成脱氨：氨基作为无痕占位基）。芳香离子能在低温存活，是因为正电荷与氮的三键及环分享，但它终究是个带着 $\mathrm{N_2}$——化学中最好的离去基团——的亲电体，这正是全部要点。取代按离子型（桑德迈尔）或自由基型（戈姆贝格-巴赫曼、桑德迈尔变体）通路进行：$\mathrm{CuCl}$、$\mathrm{CuBr}$、$\mathrm{CuCN}$ 装上 $\mathrm{Cl}$、$\mathrm{Br}$、$\mathrm{CN}$；$\mathrm{KI}$ 不需铜就装上 I；水溶液升温装上 OH（经阳离子，所以重排与副产物齐飞）；$\mathrm{HBF_4}$ 沉淀出四氟硼酸盐，加热给 $\mathrm{ArF}$（席曼）——氟苯，任何傅-克逻辑都到不了的地方。偶联：重氮离子的亲电性温和到活化环（酚、芳胺，弱碱性 pH 下）进攻*它的*末端氮，生成有色 $\mathrm{Ar{-}N{=}N{-}Ar'}$ 染料——偶氮染料，以及每一张酚类重氮试验试纸背后的化学。仲胺 + 亚硝酸给 $N$-亚硝胺（$\mathrm{R_2N{-}N{=}O}$），中性、脂溶，经代谢活化后臭名昭著地致癌——腌制肉的亚硝胺问题，以及 2020 年若干沙坦类药物的问题。
:::

::: example 重氮绕行 {#ex-sandmeyer}
给出由苯胺合成 1-溴-3-氯苯的路线，并解释为何没有直接路线可行。
::: solution
两个卤素处于*间位*，而卤素是邻/对位定位基——所以卤苯上的任何直接亲电取代序列都永远搭不出这个骨架。间位关系必须在间位定位基还在环上时确立，而日后能变成卤素的唯一有用间位定位基是硝基，经由它的胺。路线：苯胺 → 重氮化（$\mathrm{NaNO_2/HCl}$）再用次磷酸（$\mathrm{H_3PO_2}$）还原 → 苯（氨基的第一份工作：以 $\mathrm{N_2}$ 离场）；硝化（$\mathrm{HNO_3/H_2SO_4}$）→ 硝基苯；氯化（$\mathrm{Cl_2/FeCl_3}$）→ 1-氯-3-硝基苯——硝基的间位定位是承重的一步；还原（$\mathrm{Fe/HCl}$）→ 3-氯苯胺；重氮化，再 $\mathrm{CuBr}$（桑德迈尔）→ 1-溴-3-氯苯。氨基的超能力不仅在于 $\mathrm{NH_2}$ 随叫随到地变成 $\mathrm{Cl}$、$\mathrm{Br}$、$\mathrm{I}$、$\mathrm{CN}$、$\mathrm{OH}$ 或 $\mathrm{F}$——而在于胺可以被*拆掉*、再*装成另一个基团*：让硝基做间位定位的工，让重氮做替换的活。
:::
:::

::: example 一个偶氮染料，定量地 {#ex-azo-dye}
甲基橙由对氨基苯磺酸、亚硝酸钠、盐酸与 $N,N$-二甲基苯胺制成。给出两步，并指出哪个环是亲电体、哪个是亲核体。
::: solution
第一步：对氨基苯磺酸 + $\mathrm{NaNO_2/HCl}$、$0\ \mathrm{^\circ C}$ → 重氮盐（磺酸基让它水溶）。第二步：加入 $N,N$-二甲基苯胺——*亲核体*，其强给电子的 $\mathrm{NMe_2}$ 活化环进攻重氮的氮（对位于 $\mathrm{NMe_2}$、空着的那个位置）——偶联给出红色两性离子染料，酸中偶氮氮质子化转橙。亲电体：重氮离子（末端 N 是受体原子）；亲核体：活化的环。偶联就是亲电芳香取代换了个不寻常的亲电体——芳香取代那一章的同一个 $\mathrm{S_EAr}$ 骨架，也是为什么偶氮染料在冰浴中制备、对酚用微碱（酚氧负离子更亲核）、对芳胺用微酸。
:::
:::

::: warning 三个胺的危险 {#warn-amine-traps}
**(1)** 氨或胺的直接烷基化会过度烷基化——合成写着"$\mathrm{RBr}$、$\mathrm{NH_3}$"，就等着收混合物；写着"还原胺化"或"酰化-还原"，才等着收产物。**(2)** 重氮溶液干了会爆炸：冷制，在溶液中冷到热用，除非规程明说否则绝不分离（Schiemann 用的 $\mathrm{BF_4^-}$ 盐是故意的例外，而它也是滤出即湿用）。**(3)** 仲胺遇上亚硝酸盐的地方就生成亚硝胺（胃里的化学、腌制食品、原料药杂质——2018–19 年的沙坦召回）；工艺路线里出现仲胺，就是一份亚硝胺风险评估，句号。
:::

## 后续内容

胺的孤对电子是合成课程曼尼希与斯特雷克反应的亲核试剂、调节药物溶解度的碱性位点（上图）、以及拆分的把手——对映体胺与酒石酸或樟脑磺酸成非对映体盐即可分离，这就是仍在生产单一对映体药物的经典拆分。胺与其重氮衍生物喂养 [[organic-2/heterocycles]] 的偶氮与杂芳化学；亚胺化学在酶催化与 [[organic-2/condensations]] 中回归；硝基的占位基逻辑——先装上去，再变身——是芳香取代章节用得最多的推论，[[organic-2/aromatic-substitution]]。

::: summary
- 胺是锥形、会翻转的碱；季铵盐构型稳定，无碳手性中心而手性。
- 碱性读孤对电子的命运：烷基胺 $\mathrm{p}K_\mathrm{a} \approx 10$–$11$；苯胺输给环共振 $10^6$ 倍（4-硝基苯胺 1.0）；吡啶被 $sp^2$ 攥紧（5.2），吡咯根本不碱；胍超碱，因其阳离子赚得共振。
- 质子化状态是亨德森-哈塞尔巴尔赫开关：$\mathrm{p}K_\mathrm{a}$ 10 的胺在血液 pH 下 $99.7\ \%$ 成铵——药物溶解度、渗透与离子截留的基础。
- 四种干净合成绕开过度烷基化：过量氨、酰化-还原、还原胺化（最佳）、腈/硝基还原（芳香路线）。
- 芳基重氮离子（$\mathrm{ArN_2^+}$，$0\text{–}5\ \mathrm{^\circ C}$）以 $\mathrm{N_2}$ 换出 $\mathrm{Cl}$、$\mathrm{Br}$、$\mathrm{I}$、$\mathrm{CN}$、$\mathrm{OH}$、$\mathrm{F}$（席曼），或偶联成偶氮染料；脂肪重氮离子乱炖——合成脱氨。
- 仲胺 + 亚硝酸盐给亚硝胺：按它致癌的本性对待。
:::

在过量氨直接烷基化、酰化-还原、还原胺化之间选择：(a) 由 1-溴己烷制己-1-胺；(b) 由苯胺制二苯胺 $\mathrm{Ph_2NH}$；(c) 由丙胺制三丙胺。
::: solution
(a) *漫灌*过量氨的直接烷基化——统计学得过的唯一情形，氨便宜、可十倍过量使用；腈路线会多一个碳、链长不对。(b) 酰化-还原：苯胺 + 苯甲酰氯 → 苯甲酰苯胺（酰胺不亲核，无二次酰化），再 $\mathrm{LiAlH_4}$ 把羰基还原成 $\mathrm{CH_2}$ → $\mathrm{Ph_2NH}$。(c) 还原胺化，两轮：丙胺 + 丙醛 → 亚胺离子，还原 → 二丙胺；再来一轮丙醛，还原 → 三丙胺。三者中任何一者用直接烷基化都得到统计浓汤。
:::

::: exercise 用胺的逻辑做间位 {level=2}
给出由苯合成 3-溴苯胺的路线，并说出哪一步的定位效应让全局成立。
::: solution
苯 → 硝化（$\mathrm{HNO_3/H_2SO_4}$）→ 硝基苯 → 溴代（$\mathrm{Br_2/FeBr_3}$）→ 1-溴-3-硝基苯（硝基的间位定位是承重的一步）→ 还原（$\mathrm{Fe/HCl}$，或小心地 $\mathrm{H_2/Pd}$）→ 3-溴苯胺。颠倒顺序（先溴代再硝化）只得邻/对位溴硝基苯——与芳香取代章节练习同款的两步对，如今还原是第三幕。
:::
:::

::: exercise 重氮菜单 {level=2}
由 4-溴苯胺出发，给出每个产物的条件：(a) 1-溴-4-碘苯；(b) 4-溴苯酚；(c) 4-溴苯甲腈；(d) 1-溴-4-氟苯。
::: solution
全部从 $\mathrm{NaNO_2/HCl}$（(d) 用 $\mathrm{HBF_4}$）、$0\text{–}5\ \mathrm{^\circ C}$ 开始。(a) 然后 $\mathrm{KI}$ 溶液，升温——碘不需要铜。(b) 然后水，升温——经芳基阳离子，所以准备一些焦油；稀酸，缓慢升温。(c) 然后 $\mathrm{CuCN}$（桑德迈尔；Cu(I) 路线——注意氰化物安全）。(d) $\mathrm{NaNO_2/HBF_4}$，沉淀 $\mathrm{BF_4^-}$ 盐，小心干燥，加热——席曼。氨基已经变成 I、OH、CN、F，而环的其他位置从未被碰过。
:::

::: exercise 拆分 {level=2}
外消旋 1-苯基乙-1-胺须以 $(S)$-对映体交付。给出经典拆分，并解释为何对映体的直接蒸馏或色谱失败而它成功。
::: solution
以外消旋胺与一当量光学纯酸——$(R,R)$- 或 $(S,S)$-酒石酸，或樟脑磺酸——在两种非对映体盐溶解度有差的溶剂中成盐；反复结晶溶解度较小的盐（分级结晶），加碱释放游离胺，萃取。它成功是因为对映体在非手性环境中物理性质全同（蒸馏与硅胶都是非手性的），而非对映体*盐*是不同的化合物，晶格、溶解度、熔点各异——手性酸把一对无法拆分的分子换成一对可分离的，自己留在母液里回收。同样的把戏放大到公斤级，至今仍在运送单一对映体药物。
:::

::: exercise 脱氨取证 {level=3}
戊-1-胺与亚硝酸反应，得戊-2-醇、戊-3-醇与重排产物的混合物，戊-1-醇几乎没有。解释，并说明这锅乱炖还剩什么合成用途。
::: solution
脂肪重氮离子在水进攻的同时或稍前就丢掉 $\mathrm{N_2}$：戊基阳离子在 C1 生成，然后氢负离子迁移沿链跑动（C1 → C2 → C3）快过捕获，于是水捕获的是仲阳离子的平衡混合物——C2 与 C3 的醇，加上消除来的烯烃，以及阳离子想干的任何骨架重排。合成用途：**合成脱氨**——氨基由酮经还原胺化装上，可以带着重排信息被移除；而在刚性环系中阳离子可在重排前被捕获，让 $\mathrm{NH_2}$ 充当自由基与负离子不肯去的位置上 H 或 OH 的占位基。乱炖就是机理的签名，正如苯炔的重排曾经的那样。
:::

::: exercise 离子截留的定量 {level=3 check="99.7" hint="用 [BH+]/[B] = 10^(pKa - pH)；答案是百分数"}
一个弱碱的共轭酸 $\mathrm{p}K_\mathrm{a}$ 为 8.0，存在于血浆（$\mathrm{pH}\ 7.4$）与尿液（$\mathrm{pH}\ 5.4$）中。尿中百分之多少被质子化？为何酸化尿液能加速药物清除？
::: solution
对碱：$[\mathrm{BH^+}]/[\mathrm{B}] = 10^{\mathrm{p}K_\mathrm{a}-\mathrm{pH}}$。尿：$10^{8.0-5.4} = 10^{2.6} = 398$，质子化分数 $= 398/399 = 99.7\ \%$。血浆：$10^{8.0-7.4} = 10^{0.6} = 4.0$，即 $4.0/5.0 = 80\ \%$ 质子化。酸化尿液把游离碱分数变成带电、无法重吸收的铵：药物被截留在膀胱里排出——离子截留，与前面例题同一个方程，倒过来开，在急诊中毒抢救室里救命。
:::
