苯的共振能高达 $151\ \mathrm{kJ\,mol^{-1}}$，这道墙把它和烯烃隔开：加成会把这道墙永久拆掉，所以苯拒绝加成。但存在一条只需"付账一瞬间"的通路——环进攻亲电试剂、暂时失去芳香性，然后在最后一步*交还一个质子*，重新拿回环电流与共振能。净结果就是取代：掉一个氢，上一个基团，芳香性有始有终完好无损。这就是**亲电芳香取代**，芳香环官能团化的反应；再加上第二幕——芳香亲核取代（只有当环穷得走投无路时才管用）——芳香化合物因此拥有了丰富而极其实用的取代化学。本章的第二大主题是：环上一旦有了取代基，这个取代基就会*投票*：决定下一次取代的快慢，也决定它落在哪个位置。学会读票，一千个反应就浓缩成十几条规则。

## 总机理：先失去芳香性，再夺回它

::: definition 亲电芳香取代与芳基正离子 {#def-eas}
在**亲电芳香取代**（$\mathrm{S_EAr}$）中，芳香环与亲电试剂 $\mathrm{E^+}$ 分两步反应。第一步：$\pi$ 电子进攻 $\mathrm{E}$，$\mathrm{E}$ 与某个环碳成键；该碳变为 $sp^3$，环状共轭被切断，产物是阳离子型的**芳基正离子**（又称 **$\sigma$-配合物**或**苯正离子**），正电荷离域在其余五个碳上——虽被稳定，却不再芳香。第二步：碱夺走 $sp^3$ 碳上的质子，其电子对闭合成环，芳香性恢复。净反应：$\mathrm{Ar{-}H + E^+ \rightarrow Ar{-}E + H^+}$。
:::

::: proposition 芳基正离子决定一切 {#prop-arenium}
第一步是决速步，因为它摧毁芳香性；第二步很快，因为它恢复芳香性。由此推出三条结论。**(1)** 总速率取决于亲电试剂的亲电性与环的电子密度，而*不*取决于 $\mathrm{C{-}H}$ 键的强度：观测不到一级动力学同位素效应（$k_\mathrm{H}/k_\mathrm{D} \approx 1$）——$\mathrm{C{-}H}$ 键断裂发生在我们等待的那个过渡态之后。**(2)** 观测不到加成产物，因为任何"加上去就走"的试剂都会让环不再芳香；与之相比，丢掉 $\mathrm{H^+}$ 几乎是免费的。**(3)** 芳基正离子的正电荷位于 $sp^3$ 碳的*邻位*与*对位*（画出三个共振式），这正是全部定位效应的结构钥匙。
:::

::: example 溴代：从不活泼的分子造出亲电试剂
溴水遇到烯烃几秒内褪色；苯却需要 $\mathrm{Br_2}$ 加催化量的 $\mathrm{FeBr_3}$（或铁屑，原位生成）。用机理说明催化剂的作用，用文字描述弯箭头。
::: solution
单独的 $\mathrm{Br_2}$ 对芳香 $\pi$ 体系来说亲电性不够——进攻它要用 $151\ \mathrm{kJ\,mol^{-1}}$ 的芳香性去换一个与中性、只略带缺电子的溴之间的键。$\mathrm{FeBr_3}$ 是铁上带空轨道的路易斯酸，结合溴的一对孤对电子：$\mathrm{Br_2 + FeBr_3 \rightarrow Br^{\delta+}{-}Br{-}FeBr_3^{\delta-}}$，这个极化配合物的外侧溴带相当多的正电荷。环进攻那个溴（弯箭头从 $\pi$ 键指向 Br，从 $\mathrm{Br{-}Br}$ 键指向内侧 Br），得到芳基正离子和 $\mathrm{FeBr_4^-}$；随后 $\mathrm{FeBr_4^-}$ 夺走 $sp^3$ 碳上的质子，电子对闭环，$\mathrm{HBr}$ 与 $\mathrm{FeBr_3}$ 被归还——催化剂在第二步再生，所以是催化的。下一节的每个反应都是这同一副两步骨架，只是制造 $\mathrm{E^+}$ 的办法不同。
:::

## 反应目录：五种亲电试剂，一副骨架

**硝化。** 浓硝酸在浓硫酸中生成**硝鎓离子**：$\mathrm{HNO_3 + 2\,H_2SO_4 \rightarrow NO_2^+ + H_3O^+ + 2\,HSO_4^-}$。$\mathrm{NO_2^+}$（直线形，$\mathrm{O{-}N{-}O}$，与 $\mathrm{CO_2}$ 等电子）进攻环；产物是硝基芳烃 $\mathrm{Ar{-}NO_2}$。硝基是通往胺的发射台——$\mathrm{Ar{-}NO_2}$ 的还原是制备 $\mathrm{Ar{-}NH_2}$ 的标准路线（[[organic-2/amines]]）——这使硝化成为芳香合成中使用最多的第一步。

**磺化。** 发烟硫酸（溶有 $\mathrm{SO_3}$）引入 $\mathrm{SO_3H}$，而磺化是这个家族中可逆的成员：稀酸加蒸汽可把质子放回去。这种可逆性是合成工具——$\mathrm{SO_3H}$ 作可移除的占位基——也意味着磺化的产物比例常常是热力学而非动力学的。

**卤代。** $\mathrm{Cl_2}$ 或 $\mathrm{Br_2}$ 加 $\mathrm{FeX_3}$，如上例；氟代太猛烈不能照此配方，碘代则需要氧化条件来制造 $\mathrm{I^+}$。

**傅-克（Friedel–Crafts）烷基化。** $\mathrm{RCl}$ 加 $\mathrm{AlCl_3}$：路易斯酸从卤代烷上拽走氯，生成类碳正离子的亲电试剂，环对其进攻。两个著名的坑：该阳离子会*重排*（氢负离子与烷基迁移奔向最稳定的阳离子，环才来得及捕获它）；且产物烷基苯*比*原料苯*更*活泼，于是发生多烷基化——除非苯大量过量。

**傅-克酰基化。** $\mathrm{RCOCl}$ 加 $\mathrm{AlCl_3}$ 生成**酰鎓离子** $\mathrm{R{-}C{\equiv}O^+ \leftrightarrow R{-}C^+=O}$，因氧的孤对电子而稳定，因此*免疫重排*；酮产物被自己的羰基*致钝*，所以反应干净地停在单酰基。因此"酰基化-还原"（克莱门森 Clemmensen 或催化氢解）才是得到不重排的正丙基、正丁基侧链的正确两步路线。

::: example 酰基化的补救 {#ex-acylation-fix}
一位学生用 1-氯丙烷和 $\mathrm{AlCl_3}$ 处理苯，期望得到丙苯，却主要得到异丙苯（枯烯）。诊断原因，并给出真正能得到丙苯的合成。
::: solution
$\mathrm{AlCl_3}$ 使 $\mathrm{CH_3CH_2CH_2Cl}$ 电离成伯阳离子样配合物，它在被环捕获之前经氢负离子迁移重排为稳定得多的仲阳离子 $\mathrm{CH_3CH^+CH_3}$；环于是进攻仲阳离子，得到枯烯。补救办法是酰基化：苯 + $\mathrm{CH_3CH_2COCl}$、$\mathrm{AlCl_3}$ 得苯丙酮 $\mathrm{PhCOCH_2CH_3}$（酰鎓离子无法重排——正电荷由氧稳定，碳骨架从不变成自由阳离子），再把羰基还原成 $\mathrm{CH_2}$（克莱门森 $\mathrm{Zn(Hg)/HCl}$，或沃尔夫-凯惜纳 Wolff–Kishner，或催化氢解）即得丙苯。两步，不重排，不多酰基化——酰基化-还原序列正是傅-克烷基化两大缺陷的标准修复方案。
:::
:::

::: history
这个反应的机理分两次战役敲定，相隔六十年。1920–30 年代，克里斯托弗·英戈尔德（Ingold）与埃里克·休斯（Hughes）及其学派用动力学——包括氢/氘同位素效应的*缺失*——证明芳香取代经历慢的亲电进攻和快的脱质子，确立了 $\mathrm{S_EAr}$ 这一类别，与 $\mathrm{S_N1}$、$\mathrm{S_N2}$ 并列。中间体本身则等到 1960 年代乔治·奥拉（Olah）：他把稳定碳正离子溶在 $-70\ \mathrm{^\circ C}$ 的魔酸（$\mathrm{FSO_3H \cdot SbF_5}$）里，直接*采集 NMR 谱*：苯正离子与取代芳基正离子，寿命长到能看清电荷恰在共振式预言的位置。奥拉 1979 年的诺贝尔奖，表彰的正是对英戈尔德推断之物种的直接目击。
:::

## 定位效应：第一个取代基的投票

::: definition 致活、致钝与两种取向 {#def-directing}
若取代环的反应比苯快，该取代基为**致活基团**；比苯慢则为**致钝基团**。若后续取代主要落在*邻位/对位*，称**邻对位定位基**；主要落在间位则为**间位定位基**。整个模式只需对着芳基正离子读一个论证：能向阳离子中间体*供给*电子密度的取代基（共振或诱导）能稳定它——而正电荷位于取代基*相邻*位置的共振式（邻/对位途径）正是给电子基能帮上忙的那些，所以给电子基是邻对位定位基。*吸电子*取代基在所有位置都*去稳定化*中间体，而在正电荷恰位于其旁边的位置去稳定化得最厉害，于是间位——最不差的路径——胜出。致活基团是邻对位定位基；间位定位基都是致钝基团；唯一的例外是卤素：致钝，却是邻对位定位基。
:::

| 类别 | 实例 | 效应 | 定位 |
|---|---|---|---|
| 强给电子基 | $\mathrm{NH_2}$、$\mathrm{NHR}$、$\mathrm{NR_2}$、$\mathrm{OH}$、$\mathrm{O^-}$ | 强致活 | 邻对位 |
| 中等给电子基 | $\mathrm{OR}$、$\mathrm{NHCOR}$、$\mathrm{OCOR}$ | 致活 | 邻对位 |
| 弱给电子基 | $\mathrm{R}$（烷基）、芳基 | 弱致活 | 邻对位 |
| 卤素 | $\mathrm{F}$、$\mathrm{Cl}$、$\mathrm{Br}$、$\mathrm{I}$ | **致钝** | 邻对位 |
| 弱吸电子基 | $\mathrm{CHO}$、$\mathrm{COR}$、$\mathrm{CO_2H}$、$\mathrm{CO_2R}$、$\mathrm{CN}$、$\mathrm{SO_3H}$ | 致钝 | 间位 |
| 强吸电子基 | $\mathrm{NO_2}$、$\mathrm{NR_3^+}$、$\mathrm{CF_3}$ | 强致钝 | 间位 |

文字背后的数字：甲苯的硝化比苯快约 $25$ 倍（烷基给电子，超共轭），而硝基苯比苯慢约一百万倍——硝基的间位产物之所以出现，是因为邻、对位进攻会在某个共振式中把正电荷摆到 $\mathrm{NO_2}$ 正旁边，这一排布极不稳定，于是"只是糟糕"的间位路径凭默认胜出。

::: proposition 卤素例外 {#prop-halogens}
卤素靠电负性做诱导吸电子，却靠共振做给电子（孤对电子灌入环）。诱导效应致钝整个环——卤苯反应比苯慢——但共振给电子*只*在邻/对位芳基正离子中可用，因为那里正电荷恰在卤素旁边，孤对电子才递得出去。邻/对位进攻因此是*被致钝较轻*的路径：卤素一边定位邻对位，一边拖慢反应。定位基由中间体稳定性的*差值*选定；速率反映其绝对稳定性——两次测量，结论可以相反。
:::

::: example 读票 {#ex-read-votes}
预测主要的一硝化产物：(a) 乙苯；(b) 苯甲酸；(c) 氯苯；(d) 苯甲酸甲酯。
::: solution
(a) 乙基是弱烷基给电子基：邻对位，且因位阻对位为主——4-硝基乙苯（邻位次之）。(b) $\mathrm{CO_2H}$ 是羰基吸电子基：间位——3-硝基苯甲酸。(c) 氯：致钝但邻对位定位——2- 与 4-硝基氯苯的混合物，通常对位为主且可分离（邻位异构体因分子内偶极拥挤沸点较低；水蒸气蒸馏先把它带出）。(d) 酯基 $\mathrm{CO_2CH_3}$ 吸电子：间位——3-硝基苯甲酸甲酯。注意 (b) 与 (d) 投的是同一张票：关键在连在环上的那个原子，看它是拉（$\mathrm{C{=}O}$）还是推（孤对电子、$\mathrm{C{-}H}$ 超共轭）。
:::
:::

::: warning 三个定位陷阱 {#warn-directing}
**(1)** "致活基 = 邻对位"是安全的；反过来"邻对位 = 致活基"不安全——卤素是常驻反例，把表背成一个清单的学生必输。**(2)** 苯胺熬不过硝化条件：强酸中碱性的氮被质子化成 $\mathrm{NH_3^+}$，成为 $\mathrm{NR_3^+}$ 型的强致钝*间位*定位基，剩下的部分再被氧化得一塌糊涂。先保护（乙酰化成酰胺，中等强度的邻对位给电子基），再硝化，最后水解。**(3)** 定位效应是偏好不是法律：甲苯硝化仍给出百分之几的间位异构体，混合物才是常态。规则告诉你*主要*产物和速率*方向*——这恰恰是合成所需要的。
:::

## 芳香亲核取代：规则的报复

富电子环追逐亲电试剂；缺电子的环也可以被逼着追逐亲核试剂。普通的氯苯对氢氧根无动于衷——环太富电子，$\mathrm{HO^-}$ 不肯进攻；而 $sp^2$ 碳上的 $\mathrm{S_N2}$ 在几何上不可能（背面进攻得从环里穿出去）。机理有两种，且都需要环的配合。

::: definition 加成-消除机理（$\mathrm{S_NAr}$） {#def-snar}
当强吸电子基（典型为 $\mathrm{NO_2}$）位于离去基团的*邻*位和/或*对*位时，亲核试剂进攻带离去基团的环碳，生成阴离子的**迈森海默配合物**（Meisenheimer complex），其负电荷离域到硝基的氧上；随后离去基团带着一对电子离开，芳香性恢复。加成步决速，由此得出两条可与脂肪族取代区分的预言：离去基团顺序为 $\mathrm{F > Cl > Br > I}$（强极化的 $\mathrm{C{-}F}$ 键使其碳亲电性最强，而断键发生在过渡态*之后*，所以氟作为离去基团的劣势永远记不到账上），且速率随邻/对位硝基数目暴增。
:::

::: example 桑格试剂 {#ex-sanger}
1-氟-2,4-二硝基苯（桑格试剂）在室温即可与胺反应，生成鲜黄色的苯胺衍生物；相应的氯化物慢一个数量级。解释这两个现象。
::: solution
胺进攻 C1（连卤素的碳），因为生成的迈森海默阴离子把电荷同时送到*两个*硝基的邻/对位——离域到四个氧上——即使对中性亲核试剂，加成也很快。黄色来自二硝基苯基发色团与新苯胺氮之间的推拉 $\pi$ 体系：稳定中间体的同一套共轭，也顺带把吸收带进了可见区。氟胜氯的原因见定义：决速的加成只关心亲电性，不关心离去能力，而 $\mathrm{C{-}F}$ 是四种卤代物中碳最缺电子的那个。（历史上这个试剂用来标记蛋白质的 N 端氨基——蛋白质测序中的黄色条带。）
:::
:::

::: definition 消除-加成：苯炔 {#def-benzyne}
没有稳定的硝基、却有很强的碱（典型为液氨中的 $\mathrm{NH_2^-}$）时，芳基卤走第三种机理：碱夺走卤素*邻位*的质子，卤离子离去，环上多出一个形式三键——**苯炔**，其两个 $sp^2$ 类轨道构成一个较弱的、位于环平面内的 $\pi$ 键。随后亲核试剂进攻三键的任一端，阴离子再质子化。由于两个三键碳被竞争性进攻，取代苯炔给出两个区域异构体的*混合物*——这是机理的诊断性指纹，也是罗伯茨（Roberts）1953 年用 $\mathrm{1\text{-}^{14}C}$ 氯苯所作证明的基础：标记在苯胺产物的 C1 与 C2 之间均分，这对加成-消除是不可能的，对对称中间体则是自动的结果。
:::

::: example 预测苯炔混合物 {#ex-benzyne}
预测间溴甲苯与液氨中的 $\mathrm{NaNH_2}$ 反应、再经水处理后的产物。
::: solution
把溴放在 C1、甲基放在 C3；卤素邻位的质子在 C2（两个取代基之间）和 C6，夺走哪一个就得到哪一种苯炔。向 C2 方向消除把三键放在 C1 与 C2 之间：酰胺进攻 C1，质子化后产物保持 1,3-关系（3-甲基苯胺）；酰胺进攻 C2，产物是 2-甲基苯胺。向 C6 方向消除把三键放在 C1 与 C6 之间，进攻两端分别得 3-甲基苯胺或 4-甲基苯胺。所以产物是 2-、3-、4-甲基苯胺的混合物——"应该"是唯一产物的*间位*异构体只是三者之一，来自位阻较小的 C1–C6 苯炔的异构体往往占多。取代模式的重排是该机理的签名：一个"本该"按 $\mathrm{S_NAr}$ 给单一产物的反应给出了两三个，就要怀疑苯炔。
:::

## 后续内容

定位逻辑是整门课程方法的预演：中间体的稳定性决定速率与位置，所以 [[organic-2/carbonyl-addition]] 和 [[organic-2/enols-enolates]] 会把同样的思路用于四面体中间体与烯醇负离子。硝基还原及其下游的重氮化学——桑德迈尔（Sandmeyer）取代、偶联反应——见 [[organic-2/amines]]；杂芳环恰恰按这两种机理取代，只是各有偏好，读懂它们见 [[organic-2/heterocycles]]。定量的一面——取代基的电子效应如何传递、哈梅特（Hammett）相关——属于物理有机处理的内容，可见 [[kinetics/reaction-mechanisms]] 相关材料与光谱课程的 NMR 章节。

::: summary
- 亲电芳香取代分两步：亲电进攻给出不芳香的芳基正离子（决速，无一级同位素效应），脱质子恢复芳香性——取代保住了加成会摧毁的东西。
- 五种标准配方——硝化（$\mathrm{NO_2^+}$）、磺化（$\mathrm{SO_3}$，可逆）、卤代（经 $\mathrm{FeX_3}$ 的 $\mathrm{X^+}$）、傅-克烷基化与酰基化（路易斯酸生成的 $\mathrm{R^+}$ 与酰鎓离子）——共享骨架，只在制造 $\mathrm{E^+}$ 的方式上不同。
- 傅-克烷基化会重排、会多烷基化；酰基化两者都不会，酰基化-还原是直链的干净路线。
- 给电子基致活并定位邻对位；吸电子基致钝并定位间位；唯有卤素兼有致钝与邻对位定位，因为共振救援只够到邻/对位的芳基正离子。
- 定位效应决定合成顺序：硝化苯胺前先保护，1,3-二取代选间位路线，利用磺化的可逆性做可移除占位基。
- 芳香亲核取代要么需要邻/对位硝基（加成-消除，迈森海默配合物，$\mathrm{F > Cl}$ 的离去顺序），要么需要极强的碱（消除-加成，苯炔，产物重排）——产物模式会告诉你跑的是哪一种。
:::

## 练习

::: exercise 制造亲电试剂 {level=1}
写出下列反应的实际亲电试剂及其生成试剂：(a) 硝化；(b) 磺化；(c) 溴代；(d) 傅-克酰基化。
::: solution
(a) $\mathrm{NO_2^+}$，来自 $\mathrm{HNO_3/H_2SO_4}$（硝酸被硫酸质子化、脱水）。(b) $\mathrm{SO_3}$（或质子化的 $\mathrm{SO_3}$），来自发烟硫酸。(c) $\mathrm{Br^+}$ 等价物，即 $\mathrm{Br_2 \cdot FeBr_3}$ 极化配合物。(d) 酰鎓离子 $\mathrm{RCO^+}$，来自 $\mathrm{RCOCl + AlCl_3}$。
:::
:::

::: exercise 给定位基分类 {level=1}
邻对位还是间位，致活还是致钝：(a) $\mathrm{OCH_3}$；(b) $\mathrm{CN}$；(c) $\mathrm{Br}$；(d) $\mathrm{NHCOCH_3}$；(e) $\mathrm{CF_3}$。
::: solution
(a) 邻对位，较强致活（孤对给电子）。(b) 间位，致钝（腈基吸电子）。(c) 邻对位，致钝——例外。(d) 邻对位，中等致活（酰胺氮的孤对部分忙于自己的羰基，给电子弱于 $\mathrm{NH_2}$，但仍是给电子基）。(e) 间位，致钝（纯诱导吸电子，无孤对电子）。
:::
:::

::: exercise 为什么是取代不是加成 {level=1}
环己烯 + $\mathrm{Br_2}$ 发生加成；苯 + $\mathrm{Br_2/FeBr_3}$ 发生取代。各用一句话，从芳基正离子两种归宿的角度说明。
::: solution
对芳基正离子而言，丢 $\mathrm{H^+}$ 恢复芳香性（成本：零；收益：$151\ \mathrm{kJ\,mol^{-1}}$），而捕获 $\mathrm{Br^-}$ 会以同样的代价留下一个不芳香的二烯——中间体一旦存在，取代就是自动的。对环己烯，没有芳香性可恢复，溴离子捕获阳离子中间体是寻常的收尾——所以加成是自动的。同样的中间体，不同的账本。
:::
:::

::: exercise 两步合成 {level=2}
选择步骤顺序并给出试剂：(a) 由苯制 1-溴-3-硝基苯；(b) 由苯制 1-溴-4-硝基苯。
::: solution
(a) 先溴代（$\mathrm{Br_2/FeBr_3}$）？溴把随后的硝化导向邻/对位——方向错了！正确做法：先硝化（$\mathrm{HNO_3/H_2SO_4}$），$\mathrm{NO_2}$ 把随后的溴代导向*间位*（$\mathrm{Br_2/FeBr_3}$）：得 1-溴-3-硝基苯。(b) 先溴代；溴的邻对位定位给出 1-溴-4-硝基苯（2-异构体可分离）。这一对正是教学范例：*第一个*基团决定第二个的位置，所以按你需要的取向决定先装哪个基团。
:::
:::

::: exercise 氟的悖论 {level=2}
脂肪族 $\mathrm{S_N2}$ 中 $\mathrm{R{-}I}$ 最快、$\mathrm{R{-}F}$ 几乎从不反应；而取代硝基苯的 $\mathrm{S_NAr}$ 顺序是 $\mathrm{F > Cl > Br > I}$。如何调和？
::: solution
脂肪族 $\mathrm{S_N2}$ 只有一个过渡态，其中 $\mathrm{C{-}X}$ 键正在*断裂*，所以离去能力（弱碱、可极化：$\mathrm{I^-}$）说了算。$\mathrm{S_NAr}$ 由*加成*决速，此时与卤素的键尚未断裂：要紧的是环碳有多缺电子，而电负性最强的氟靠诱导吸电子使其碳最亲电。$\mathrm{C{-}F}$ 键随后在快的后续步中断裂，其强度无关紧要。机理决定了你能感受到卤素的哪种性质。
:::
:::

::: exercise 苯炔的记账 {level=2}
罗伯茨 1953 年的实验：氯苯的 C1 带 $^{14}\mathrm{C}$，经 $\mathrm{KNH_2/NH_3}$ 处理，所得苯胺的标记在 C1 与 C2 之间 1:1 分布。解释之，并说明 $\mathrm{S_NAr}$ 加成-消除为何给不出这个结果。
::: solution
酰胺夺走邻位质子，无氨的苯炔生成，三键在 C1 与 C2 之间；酰胺以相等概率进攻三键的*任一*碳（未取代苯炔中两者等价）；再质子化后，$\mathrm{NH_2}$ 落在 C1 或 C2，标记跟着碳骨架走——得 1:1 的两种标记苯胺。加成-消除只会在带标记的碳上取代，标记应 100 % 在 C1。重排要求一个对称中间体，而苯炔是唯一符合的候选。
:::
:::

::: exercise 保护再硝化 {level=3}
给出从苯胺到 4-硝基苯胺的高对位选择性三步路线，说明每步的目的，并说明直接硝化为何失败。
::: solution
(1) 乙酰化：乙酸酐把 $\mathrm{NH_2}$ 变成乙酰胺 $\mathrm{NHCOCH_3}$——中等强度的邻对位给电子基，耐酸。(2) 硝化（冷 $\mathrm{HNO_3}$/乙酸或混酸）：体积较大的酰胺主要导向对位，得 4-硝基乙酰苯胺（经典的对位选择性硝化；邻位异构体为少量，重结晶除去）。(3) 水解酰胺（水相酸或碱，加热）：得 4-硝基苯胺。直接硝化失败，因为混酸把胺质子化成 $\mathrm{C_6H_5NH_3^+}$——强致钝的间位定位基——并把环氧化成焦油；保护把一个碱性、易氧化的氮变成温顺、能定位的氮。
:::
:::

::: exercise 读懂复杂环 {level=3}
预测 4-*叔*丁基苯酚单一的主要一硝化产物，并针对每一个相互竞争的定位指令论证你的选择。
::: solution
两个定位基是 $\mathrm{OH}$（强邻对位给电子基）与*叔*丁基（弱烷基给电子基），彼此处于对位，它们的邻位相互错开：2/6 位是 OH 的邻位、tBu 的间位；3/5 位是 tBu 的邻位、OH 的间位。强给电子基压倒弱给电子基：硝化落在 OH 的邻位——2-硝基-4-*叔*丁基苯酚为唯一主要产物（由分子的镜面对称性，2 位与 6 位等价，所以"OH 的邻位"是一种产物而非两种）。位阻推波助澜：进攻 *叔*丁基的邻位本来就不利。对称性加上"强给电子基 $>$ 弱给电子基"的等级给出唯一答案，这正是该底物成为经典教例的原因。
:::
