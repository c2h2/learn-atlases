离子键是我们所教授的最古老的固体物质模型，同时也是最成功的模型之一。看看钠和氯，这两种元素再不同不过了——一种是遇水就嘶嘶起泡的柔软金属，另一种是有毒的黄绿色气体——把它们化合：得到的是一种透明、坚硬、不导电的晶体，熔点为 $801\ \mathrm{^\circ C}$，在空气中稳定，而且是生命所必需的。离子模型定量地解释了这种转变，而它所用的工具不过是库仑定律、元素周期表和一本热化学数据手册。在本课中，我们将用这些部件搭建这个模型：判断原子何时转移电子、计算所得晶体的静电能，并用玻恩-哈伯（Born–Haber）循环把整套账目与实验对照。同样重要的是，我们也将了解这个模型在何处悄然失效——因为懂得了离子图像的局限，这门课程的其余部分、以及[[bonding-structure/covalent-lewis]]中的共价键，才成为必需而非可有可无的东西。

## 原子为何变成离子

孤立的钠原子对其最外层电子束缚很松：第一电离能只有 $494\ \mathrm{kJ\,mol^{-1}}$，因为这个电子处在第三电子层，离核很远，又被十个内层电子屏蔽。氯则相反：紧凑的 $n = 3$ 层上有效核电荷很高，使它的第一电离能高达 $1251\ \mathrm{kJ\,mol^{-1}}$，而它的电子亲和能——捕获一个电子时释放的能量——为 $349\ \mathrm{kJ\,mol^{-1}}$。支配这些数值的周期性趋势在[[general-chemistry-1/periodicity]]中展开；这里要紧的是转移的账目。把一个电子从气态 Na 原子移到气态 Cl 原子上要花费 $494 - 349 = 145\ \mathrm{kJ\,mol^{-1}}$：就孤立的气相原子而言，离子并*不*是免费的。使这笔转移划算的，是离子一旦形成之后的库仑吸引——而在晶体中，每个离子同时吸引几十个近邻，因此与哪怕最紧密的气相离子对相比，回报都大得多。

::: definition 离子、阳离子与阴离子 {#def-ions}
**离子**是带净电荷的原子或分子。**阳离子**是带正电的离子，由中性原子失去电子形成；**阴离子**带负电，由得到电子形成。主族单原子离子如此形成，使得到的物种具有稀有气体的电子排布：$\mathrm{Na^+}$ 与 Ne 等电子，$\mathrm{Cl^-}$ 与 Ar 等电子，$\mathrm{Mg^{2+}}$ 与 Ne 等电子，$\mathrm{O^{2-}}$ 与 Ne 等电子。**第一电离能** $\Delta_\mathrm{i}H$ 是 $\mathrm{M(g) \to M^+(g) + e^-(g)}$ 的焓变（恒为正）；以焓表示的**电子亲和能** $\Delta_\mathrm{ea}H$ 是 $\mathrm{X(g) + e^- \to X^-(g)}$ 的焓变，对周期表右侧附近的大多数非金属为负（放热）。
:::

"离子为了达到稀有气体构型而形成"这句话是一条记账规则，不是因果故事：没有原子会提前谋划。真正的论证是能量上的，而其中每一项都是可测量的——电离能、电子亲和能，以及我们即将计算的晶格焓。

::: example 计算生成气态离子的代价 {#ex-ion-cost}
已知 $\Delta_\mathrm{sub}H(\mathrm{Na}) = +108\ \mathrm{kJ\,mol^{-1}}$、$IE_1(\mathrm{Na}) = +494\ \mathrm{kJ\,mol^{-1}}$、$\tfrac{1}{2} D(\mathrm{Cl_2}) = +122\ \mathrm{kJ\,mol^{-1}}$ 和 $\Delta_\mathrm{ea}H(\mathrm{Cl}) = -349\ \mathrm{kJ\,mol^{-1}}$（标准数据表值），求 $\mathrm{Na(s)} + \tfrac{1}{2}\mathrm{Cl_2(g)} \to \mathrm{Na^+(g)} + \mathrm{Cl^-(g)}$ 的焓变。
::: solution
把这条路径的各步相加——金属升华、解离半摩尔氯气、电离钠、把电子交给氯：
$$
108 + 122 + 494 - 349 = +375\ \mathrm{kJ\,mol^{-1}}.
$$
由单质制备分离的气态离子是强吸热的。然而钠与氯的反应却是剧烈的放热反应，因为离子随后聚集成晶体并释放晶格焓，约 $-787\ \mathrm{kJ\,mol^{-1}}$；$\mathrm{NaCl(s)}$ 的总生成焓为 $-411\ \mathrm{kJ\,mol^{-1}}$。晶格把昂贵的那一步的代价偿付了两倍还不止。
:::
:::

哪怕*一对*离子对也有结合能：在 $\mathrm{NaCl}$ 分子 $236\ \mathrm{pm}$ 的核间距下，点电荷的库仑能为 $-1.389\times10^{5}/236 = -589\ \mathrm{kJ\,mol^{-1}}$，足以覆盖气相转移代价 $+145\ \mathrm{kJ\,mol^{-1}}$ 而有余。至于晶体——每个 $\mathrm{Na^+}$ 同时被六个 $\mathrm{Cl^-}$ 吸引、被六个 $\mathrm{Na^+}$ 排斥——释放的能量还要多；而正确地把这份释放计入账下，正是接下来两节的主题。

## 晶格焓

::: definition 晶格焓 {#def-lattice-enthalpy}
离子晶体的**晶格焓**是下列两个可互逆过程之一的焓变
$$
\mathrm{MX(s) \to M^+(g) + X^-(g)} \qquad \Delta_\mathrm{latt}H > 0 \ \text{(解离约定)},
$$
$$
\mathrm{M^+(g) + X^-(g) \to MX(s)} \qquad \Delta_\mathrm{latt}H < 0 \ \text{(生成约定)}.
$$
它是固体一个**化学式单位**的焓变，而不是一个分子的：固态中的 $\mathrm{NaCl}$ 不是分子，而是一个三维阵列，$\mathrm{NaCl}$ 不过是离子的最简比。典型数值从大的单价卤化物的约 $700\ \mathrm{kJ\,mol^{-1}}$，到小的高电荷氧化物的接近 $4000\ \mathrm{kJ\,mol^{-1}}$。
:::

::: warning 符号约定与单位 {#warn-signs}
晶格焓在一些表中取正（拆开固体所需的能量），在另一些表中取负（固体形成时释放的能量）；$\mathrm{NaCl}$ 的数值表按约定可能写成 $+787$ 或 $-787\ \mathrm{kJ\,mol^{-1}}$，而在同一个玻恩-哈伯循环里混用两种约定，是丢一个负号、得一个错答案的最常见方式。在引用数值*之前*先查清约定，并把定义方程写在它旁边。在下面的方程中，距离必须用皮米、能量用 $\mathrm{kJ\,mol^{-1}}$，常数才适用；$r_0$ 上一个十量级的差错就是答案上一个十量级的差错。
:::

由于静电力没有方向偏好、也没有饱和限制，离子键把每个离子与每一个带异号电荷的近邻都结合起来。这就是为什么离子化合物在室温下是晶体固体而不是分立分子，为什么它们沿平面解理，以及为什么它们的性质取决于整个晶格而不是任何单个键。

## 计算库仑能：玻恩-朗德方程

晶格焓无法直接测量——没有哪个实验能把一块晶体变成仅有的自由气态离子——但它可以*计算*，因为相互作用不过是库仑定律在晶体上的求和。每个离子都处于所有其他离子的场中，而该求和收敛（收敛得很慢，但确实收敛）到一个由几何结构决定的纯数。

::: proposition 玻恩-朗德（Born–Landé）方程 {#prop-bornlande}
把离子晶体视为点电荷阵列并带一项短程排斥项时，其最近邻距离为 $r_0$ 的晶格能为
$$
U_\mathrm{BL} = \frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r_0} \left(1 - \frac{1}{n}\right),
$$
其中 $z_+ e$ 和 $z_- e$ 是离子电荷，$M$ 是**马德隆（Madelung）常数**——一个由晶格几何结构决定的纯数：岩盐型结构为 $1.7476$，氯化铯型为 $1.7627$，闪锌矿型为 $1.6381$，纤锌矿型为 $1.6414$，萤石型（$\mathrm{CaF_2}$）为 $2.5194$——而 $n$ 是**玻恩指数**，描述闭电子壳层之间的短程排斥（类氦离子对 $n \approx 5$，类氖对 $7$，类氩与类氪对 $9$，具有 18 个电子的离子 $10$–$12$）。
:::

::: proof $(1 - 1/n)$ 因子 {#proof-bornlande}
1 摩尔离子对的静电势能，所有间距以最近邻距离 $r$ 标度，为
$$
U(r) = -\frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r} + \frac{N_\mathrm{A} B}{r^n},
$$
其中马德隆常数 $M$ 已经吸收了整个晶格上的交错求和（异号电荷贡献吸引，同号电荷贡献排斥；对一条无限长的交错电荷直线，该和可写成封闭形式，得 $M = 2\ln 2 = 1.386$），而 $B/r^n$ 代表闭壳层之间防止坍缩的陡峭排斥。平衡时，对 $r$ 的导数在 $r = r_0$ 处为零：
$$
\frac{\mathrm{d}U}{\mathrm{d}r} = \frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r^2} - \frac{n N_\mathrm{A} B}{r^{n+1}} = 0
\qquad\Longrightarrow\qquad
B = \frac{M z_+ z_- e^2\, r_0^{\,n-1}}{4 \pi \varepsilon_0\, n}.
$$
把这个 $B$ 代回 $U(r_0)$，排斥项恰好等于吸引项绝对值的 $1/n$，于是
$$
U(r_0) = -\frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r_0} + \frac{1}{n}\cdot\frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r_0}
= -\frac{N_\mathrm{A} M z_+ z_- e^2}{4 \pi \varepsilon_0 r_0}\left(1 - \frac{1}{n}\right).
$$
这个因子的物理意义很简单：在平衡间距处，排斥墙已经承担了 $1/n$ 的记账，因此净结合能是纯库仑吸引的 $(1 - 1/n)$。当 $n = 9$ 时，修正只有 $11\ \%$——晶格能压倒性地是库仑性的，这就是点电荷模型行得通的原因。
:::

前面那个常数值得一次记牢：$N_\mathrm{A} e^2 / (4 \pi \varepsilon_0) = 1.389\times10^{5}\ \mathrm{kJ\,pm\,mol^{-1}}$，因此当 $r_0$ 以皮米计时，玻恩-朗德晶格能（解离，取正）为 $1.389\times10^{5}\, M z_+ z_- (1 - 1/n)/r_0$。

::: example NaCl、MgO 与 CaF$_2$ 的玻恩-朗德和卡普斯钦斯基估算 {#ex-lattice-numbers}
$\mathrm{NaCl}$：$M = 1.7476$，$r_0 = 283\ \mathrm{pm}$，$n = 8$；$\mathrm{MgO}$（同为岩盐型）：$r_0 = 212\ \mathrm{pm}$，$n = 7$。用玻恩-朗德方程估算两者的晶格焓，再用下面的卡普斯钦斯基方程估算 $\mathrm{CaF_2}$（$M = 2.5194$，$r_0 = 233\ \mathrm{pm}$，$n = 8$）。
::: solution
$\mathrm{NaCl}$：
$$
\frac{1.389\times10^{5} \times 1.7476 \times 1}{283} \times \frac{7}{8} = 750\ \mathrm{kJ\,mol^{-1}} \quad (\text{实验值 } 787).
$$
$\mathrm{MgO}$：
$$
\frac{1.389\times10^{5} \times 1.7476 \times 4}{212} \times \frac{6}{7} = 3926\ \mathrm{kJ\,mol^{-1}} \quad (\text{实验值 } \approx 3795\text{–}3850).
$$
用卡普斯钦斯基方程算 $\mathrm{CaF_2}$（$\nu = 3$，$z_+ z_- = 2$）：
$$
\frac{1.202\times10^{5} \times 3 \times 2}{233} \times \left(1 - \frac{34.5}{233}\right) = 2637\ \mathrm{kJ\,mol^{-1}} \quad (\text{实验值 } 2644).
$$
三个结果都与实验值相差在几个百分点以内——对一个把离子当作无特征点电荷的模型来说，这是惊人的符合，也是这些晶体中的结合确实是静电性的最强单项证据。
:::
:::

当晶体结构（从而 $M$）未知时，**卡普斯钦斯基（Kapustinskii）方程**用一个只依赖每个化学式单位中离子数目的经验因子，取代依赖结构的因子。

::: proposition 卡普斯钦斯基方程 {#prop-kapustinskii}
离子晶体的晶格焓（解离）可以在不知其结构的情况下估算为
$$
\Delta_\mathrm{latt}H \approx \frac{1.202\times10^{5}\ \mathrm{kJ\,pm\,mol^{-1}} \times \nu\, z_+ z_-}{r_+ + r_-} \left(1 - \frac{34.5\ \mathrm{pm}}{r_+ + r_-}\right),
$$
其中 $\nu$ 是每个化学式单位中的离子数（$\mathrm{NaCl}$ 为 $2$，$\mathrm{CaF_2}$ 或 $\mathrm{Na_2SO_4}$ 为 $3$），$z_+ z_-$ 是离子电荷数的乘积，$r_+ + r_-$ 是离子半径之和（以皮米计）。这个方程之所以有效，是因为玻恩-朗德因子 $M(1 - 1/n)$ 对结构出奇地不敏感：岩盐型为 $1.53$，萤石型为 $2.24$，而卡普斯钦斯基给出 $0.88\,\nu = 1.76$ 和 $2.64$——约 $10\ \%$ 的系统性高估，被 $34.5\ \mathrm{pm}$ 修正项大体抵消。
:::

## 玻恩-哈伯循环

计算给出晶格焓的一种估算；实验给出另一种，途径是一个热化学循环——它是盖斯定律的一次典范应用（见[[general-chemistry-1/thermochemistry]]）。

::: proposition 玻恩-哈伯循环 {#prop-bornhaber}
因为焓是状态函数，离子晶体的生成焓等于从单质到固体的*任何*路径的焓变之和。选取经由气态离子的路径，
$$
\Delta_\mathrm{f}H^\circ = \Delta_\mathrm{sub}H + \sum \Delta_\mathrm{atom}H + \sum IE + \sum \Delta_\mathrm{ea}H + \Delta_\mathrm{latt}H,
$$
其中这里的 $\Delta_\mathrm{latt}H$ 取生成（负值）约定。其余每一项都可测量——升华焓、键解离焓、逐级电离能、电子亲和能——于是这个循环从可测的量中提取出不可直接测量的晶格焓。反过来，有了计算出的晶格焓，这个循环也能提取未知的电离能或电子亲和能：正是这类循环确立了数据表中的许多数值。
:::

::: example NaCl 的玻恩-哈伯循环 {#ex-nacl-cycle}
从 $\Delta_\mathrm{sub}H(\mathrm{Na}) = +108$、$\tfrac{1}{2}D(\mathrm{Cl_2}) = +122$、$IE_1(\mathrm{Na}) = +494$、$\Delta_\mathrm{ea}H(\mathrm{Cl}) = -349$ 和 $\Delta_\mathrm{f}H^\circ(\mathrm{NaCl, s}) = -411\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）中提取 $\mathrm{NaCl}$ 的晶格焓。
::: solution
把这个循环写成一张从 $\mathrm{Na(s)} + \tfrac{1}{2}\mathrm{Cl_2(g)}$ 经由 $\mathrm{Na^+(g)} + \mathrm{Cl^-(g)}$ 到 $\mathrm{NaCl(s)}$ 的分步表：

| 步骤 | $\Delta H / \mathrm{kJ\,mol^{-1}}$ |
|---|---|
| $\mathrm{Na(s) \to Na(g)}$ | $+108$ |
| $\tfrac{1}{2}\mathrm{Cl_2(g) \to Cl(g)}$ | $+122$ |
| $\mathrm{Na(g) \to Na^+(g) + e^-}$ | $+494$ |
| $\mathrm{Cl(g) + e^- \to Cl^-(g)}$ | $-349$ |
| $\mathrm{Na^+(g) + Cl^-(g) \to NaCl(s)}$ | $\Delta_\mathrm{latt}H$ |
| **总和 $= \Delta_\mathrm{f}H^\circ$** | $-411$ |

气态离子那几步花费 $108 + 122 + 494 - 349 = +375\ \mathrm{kJ\,mol^{-1}}$，于是
$$
\Delta_\mathrm{latt}H = -411 - 375 = -786\ \mathrm{kJ\,mol^{-1}},
$$
按解离约定即 $+786\ \mathrm{kJ\,mol^{-1}}$（表列值 $787$；末位数字取决于所用数据集）。与玻恩-朗德算得的 $750\ \mathrm{kJ\,mol^{-1}}$ 比较：理论与热化学符合到 $5\ \%$，而这是两种中性原子几乎毫无共同之处的晶体。这份符合*就是*离子模型的证据。
:::
:::

::: example MgO 的玻恩-哈伯循环，以及 $\mathrm{O^{2-}}$ 为何存在 {#ex-mgo-cycle}
从 $\Delta_\mathrm{sub}H(\mathrm{Mg}) = +148$、$\tfrac{1}{2}D(\mathrm{O_2}) = +249$、$IE_1(\mathrm{Mg}) = +738$、$IE_2(\mathrm{Mg}) = +1451$、$\Delta_\mathrm{ea}H_1(\mathrm{O}) = -141$、$\Delta_\mathrm{ea}H_2(\mathrm{O}) = +844$ 和 $\Delta_\mathrm{f}H^\circ(\mathrm{MgO, s}) = -602\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）求 $\mathrm{MgO}$ 的晶格焓。
::: solution

| 步骤 | $\Delta H / \mathrm{kJ\,mol^{-1}}$ |
|---|---|
| $\mathrm{Mg(s) \to Mg(g)}$ | $+148$ |
| $\tfrac{1}{2}\mathrm{O_2(g) \to O(g)}$ | $+249$ |
| $\mathrm{Mg(g) \to Mg^+(g) + e^-}$ | $+738$ |
| $\mathrm{Mg^+(g) \to Mg^{2+}(g) + e^-}$ | $+1451$ |
| $\mathrm{O(g) + e^- \to O^-(g)}$ | $-141$ |
| $\mathrm{O^-(g) + e^- \to O^{2-}(g)}$ | $+844$ |
| $\mathrm{Mg^{2+}(g) + O^{2-}(g) \to MgO(s)}$ | $\Delta_\mathrm{latt}H$ |
| **总和 $= \Delta_\mathrm{f}H^\circ$** | $-602$ |

气态离子的花费为 $148 + 249 + 738 + 1451 - 141 + 844 = +3289\ \mathrm{kJ\,mol^{-1}}$，于是
$$
\Delta_\mathrm{latt}H = -602 - 3289 = -3891 \approx -3890\ \mathrm{kJ\,mol^{-1}},
$$
解离值即 $+3890\ \mathrm{kJ\,mol^{-1}}$；表列值因所用数据集与参考态不同而分布在 $3795$–$3925\ \mathrm{kJ\,mol^{-1}}$ 之间。

最有教益的一项是氧的第二电子亲和能，$+844\ \mathrm{kJ\,mol^{-1}}$：把一个电子强行塞给负离子 $\mathrm{O^-}$ 是强**吸热**的，因为你是在把电荷推给电荷。孤立的 $\mathrm{O^{2-}}$ 离子并不存在——气相实验证实它不稳定达数百千焦。使 $\mathrm{O^{2-}}$ 成为现实的是晶格：$\mathrm{MgO}$ 中 $z_+z_- = 4$ 的库仑吸引释放约 $3900\ \mathrm{kJ\,mol^{-1}}$，多出的 $844$ 只是其中一小部分。氧化物离子存在于晶体中，而不是存在于空间里——是环境替自由离子付不起的账单买了单。
:::

为什么 $\mathrm{MgCl_2}$ 是稳定的离子固体，而 $\mathrm{MgCl}$（含 $\mathrm{Mg^+}$）却无法分离出来？
- [x] Mg 的第二电离能由 $2{:}\,1$ 化合物大得多的晶格焓偿还，因此 $\mathrm{MgCl_2}$ 的焓低得多；$\mathrm{MgCl}$ 会发生歧化。
- [ ] 氯不能接受多于一个电子。
- [ ] $\mathrm{Mg^+}$ 有放射性。
- [ ] $\mathrm{MgCl}$ 只在 $800\ \mathrm{^\circ C}$ 以上才分解。
::: solution
歧化反应 $2\,\mathrm{MgCl(s)} \to \mathrm{Mg(s)} + \mathrm{MgCl_2(s)}$ 放热，因为晶格焓大致按 $z_+ z_-$ 缩放：从 $\mathrm{Mg^+Cl^-}$ 到 $\mathrm{Mg^{2+}2Cl^-}$，晶格焓增加不止一倍，压倒了第二电离能多出的 $+738\ \mathrm{kJ\,mol^{-1}}$（第一电离能是 $738$，第二是 $1451$；晶格收益约为 $+2000$）。这就是电正性金属倾向于最高可达氧化态的原因，也是玻恩-哈伯循环是*证明*某个假想氧化态在热力学上不可达的标准方法的原因。
:::
:::

## 周期性趋势与离子模型的局限

玻恩-朗德方程和卡普斯钦斯基方程让趋势一目了然。晶格焓随电荷乘积升高、随离子间距降低，于是 $\mathrm{MgO} \gg \mathrm{NaCl} > \mathrm{KCl} > \mathrm{RbBr}$，且 $\mathrm{Al_2O_3} \gg \mathrm{MgO}$。电荷比尺寸更要紧：$z_+z_-$ 变为四倍胜过距离 $25\ \%$ 的变化，这就是为什么难熔氧化物在 $3000\ \mathrm{^\circ C}$ 附近熔化、而卤化物在 $800\ \mathrm{^\circ C}$ 附近熔化。同样的静电学解释了小而高电荷的氧化物为何硬而难溶，也解释了大而单价的卤化物为何行为相反。

::: warning 当阳离子极化阴离子时离子模型失效 {#warn-fajans}
$\mathrm{AgCl}$、$\mathrm{AgBr}$ 和 $\mathrm{AgI}$ 的溶解度远低于类 NaCl 静电学的预言，也远不那么"离子性"，而它们由玻恩-哈伯循环得到的晶格焓明显*高于*玻恩-朗德值——这份额外的稳定性是纯离子记账看不到的。原因是**极化**：小而高电荷的阳离子（高电荷密度、高极化力）会使大而易变形（可极化性强）的阴离子的电子云变形，而被变形、被共享的电子云按定义就是部分共价键。**法扬斯（Fajans）规则**概括了这一趋势：共价成分随阳离子电荷增大、阳离子半径减小、阴离子尺寸与可极化性增大而增大，也随阳离子具有非稀有气体壳层而增大（像 $\mathrm{Ag^+}$ 这样的 $d^{10}$ 阳离子极化能力很强）。离子模型是一个极限情形；真实晶体介于离子极限与共价极限之间，晶体被极化得越厉害，纯离子的预言就失效得越多。
:::

## 离子化合物的性质

模型靠解释性质而不是只解释能量来赢得地位。四类行为直接由晶格图像得出。

**熔点与硬度。** 熔化离子固体意味着拆散晶格——不是拆成离子（熔体仍是离子的），而是拆成可自由移动、无序排列的离子。能量代价跟随晶格焓：$\mathrm{NaCl}$ 在 $801\ \mathrm{^\circ C}$ 熔化，$\mathrm{MgO}$ 在 $2852\ \mathrm{^\circ C}$，与 $787$ 和 $3890\ \mathrm{kJ\,mol^{-1}}$ 成比例。硬度与高密度同样源于这种无方向、无处不在的吸引。

**脆性。** 离子晶体硬而脆。剪切力若把一层离子沿晶格滑移半个间距，就会使同号电荷彼此相对；于是晶格沿该平面*把自己推开*。这就是 $\mathrm{NaCl}$ 沿平直的 $\{100\}$ 面解理而不弯曲的原因——结合晶体的同一套静电学在剪切下毁灭了它。

**导电性。** 在固体中，离子被锁定在格点上，只有电子可以移动——而那些电子被锁在闭壳层里，比最高占据能级高出 $800\ \mathrm{kJ\,mol^{-1}}$ 以上，所以固态盐是绝缘体。把盐熔化或溶解，离子本身就成了可移动的载流子：熔融 $\mathrm{NaCl}$ 导电，盐水也导电。电解熔融 $\mathrm{NaCl}$ 制金属钠，不过是把这种导电推向极端。（溶解*并不是*创造离子——离子本来就在那里；溶液只是用离子-水吸引取代了晶格。）

**溶解度：晶格与水合的较量。** 溶解离子固体，是用晶格焓（断裂吸热）交换分离离子的水合焓（形成放热）：
$$
\Delta_\mathrm{sol}H = \Delta_\mathrm{latt}H + \Delta_\mathrm{hyd}H(\mathrm{M^+}) + \Delta_\mathrm{hyd}H(\mathrm{X^-}).
$$
一种盐是否溶解，是这两个大项之间的拔河，由它们的差和混合熵决定——这一主题将在[[general-chemistry-2/liquids-solutions]]中正式展开。

::: example 为什么 LiF 微溶而 LiI 极易溶 {#ex-solubility-lif-lii}
由 $\Delta_\mathrm{latt}H(\mathrm{LiF}) = +1037$、$\Delta_\mathrm{latt}H(\mathrm{LiI}) = +753$、$\Delta_\mathrm{hyd}H(\mathrm{Li^+}) = -520$、$\Delta_\mathrm{hyd}H(\mathrm{F^-}) = -515$ 和 $\Delta_\mathrm{hyd}H(\mathrm{I^-}) = -305\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）估算 $\mathrm{LiF}$ 和 $\mathrm{LiI}$ 的 $\Delta_\mathrm{sol}H$，并对照实验事实解读：$\mathrm{LiF}$ 只能溶解到约 $0.04\ \mathrm{mol\,dm^{-3}}$，而 $\mathrm{LiI}$ 可溶解到 $10\ \mathrm{mol\,dm^{-3}}$ 以上。
::: solution
$$
\Delta_\mathrm{sol}H(\mathrm{LiF}) = 1037 - 520 - 515 = +2\ \mathrm{kJ\,mol^{-1}},
$$
$$
\Delta_\mathrm{sol}H(\mathrm{LiI}) = 753 - 520 - 305 = -72\ \mathrm{kJ\,mol^{-1}}.
$$
对 $\mathrm{LiF}$，两个巨大项几乎恰好相消：沿卤素族从 F 到 I，阴离子变大使晶格焓下降 $284\ \mathrm{kJ\,mol^{-1}}$，而阴离子的水合焓只变得不那么有利 $210\ \mathrm{kJ\,mol^{-1}}$——差额上晶格项占上风。$\mathrm{LiF}$ 的 $\Delta_\mathrm{sol}H$ 接近零，溶解度就悬在细小的熵与焓的细节上（微小的 $\mathrm{F^-}$ 的水合使周围的水变有序，熵不利），于是该盐微溶；而 $-72\ \mathrm{kJ\,mol^{-1}}$ 驱动着 $\mathrm{LiI}$，它极易溶。这些数字教出的普遍规则：对像 $\mathrm{Li^+}$ 这样小而硬的阳离子的盐，溶解度沿卤素族*升高*，因为晶格焓比水合焓降得更快。
:::
:::

::: history
晶格能问题在 1910 年代由两条路线进攻，它们至今仍规定着这门学科。1918 年，玻恩（Born）与朗德（Landé）合作，对晶体做了库仑级数求和并得到马德隆常数，把晶格能变成了可计算的量；玻恩的教科书《原子结构讲义》（*Vorlesungen über die Struktur der Atome*）后来把这套方法传给了一代物理学家。哈伯（Haber）在他 1919 年的技术电化学专著中用热化学循环从实验提取晶格能——即玻恩-哈伯循环——并用得到的数值论证黄铜是真正的固溶体，对抗当时占统治地位的合金电化学理论。卡普斯钦斯基（Kapustinskii）不依赖结构的简化出现在 1956 年，使任何人只凭离子半径就能对任何化学式作出估算。银的卤化物的计算晶格焓与实验晶格焓之间的系统性偏差，是纯离子图像并不完备的最早、最清楚的迹象之一，为极化与部分共价性指出了方向。
:::

## 后续内容

晶格能是这门课程的前一半；后一半是共价键，从[[bonding-structure/covalent-lewis]]开始。这里用到的周期性趋势——电离能、电子亲和能、离子半径——在[[general-chemistry-1/periodicity]]中展开，而玻恩-哈伯循环的热化学记账则是[[general-chemistry-1/thermochemistry]]中的盖斯定律用于一条特定路径。离子在晶胞中的堆积、配位数与半径比规则将在[[bonding-structure/solid-structures]]中回来，定量晶体学在[[materials-chemistry/crystal-structures]]。溶解背后的水合-晶格较量在[[general-chemistry-2/liquids-solutions]]中展开，微溶情形在[[general-chemistry-2/solubility-equilibria]]。对电子本身做量子力学处理、并从第一性原理检验点电荷近似的地方，是[[quantum-chemistry/chemical-bond-qm]]。

::: summary
- 离子键是闭壳层离子之间的静电吸引；它无方向、不饱和，这就是离子化合物是晶体固体而不是分子的原因。
- 晶格焓按 $z_+ z_- / r_0$ 缩放：电荷比尺寸更要紧，双电荷氧化物的晶格焓是单价卤化物的数倍。
- 玻恩-朗德方程由结构计算晶格焓（马德隆常数、玻恩指数、由对势极小化得到的 $(1-1/n)$ 因子）；卡普斯钦斯基方程只凭化学式估算到几个百分点。
- 玻恩-哈伯循环把可测的焓——升华、解离、电离、电子亲和能、生成——变成无法直接测量的晶格焓。
- 氧的第二电子亲和能是吸热的：$\mathrm{O^{2-}}$ 之所以存在，是因为晶格替它买了单。
- 熔点、脆性、熔融或溶解时的导电、以及溶解度，都由晶格图像得出；溶解度是晶格焓与水合焓的竞争。
- 大而可极化的离子带来部分共价性（法扬斯规则）；离子模型是一个极限，不是定律。
:::

## 练习

::: exercise 离子半径与配位数 {level=1}
为什么离子半径要按配位数列表？为什么 $\mathrm{Na^+}$（$102\ \mathrm{pm}$）比 $\mathrm{Na}$（$186\ \mathrm{pm}$）小？
::: solution
失去价层后，离子坍缩成稀有气体排布，其余每个电子感受到的有效核电荷更高，所以阳离子比其母原子小得多；阴离子则因为新增的电子-电子排斥使电子层膨胀而更大。半径依赖配位数，是因为更多的邻近离子会把电子云推开、把表观半径撑大——半径是对离子间距的一种拟合划分，不是可观测量。
:::
:::

::: exercise 用卡普斯钦斯基方程估算 KBr {level=1 check="654"}
用卡普斯钦斯基方程估算 $\mathrm{KBr}$ 的晶格焓（$\nu = 2$，$z_+ z_- = 1$，$r_0 = r(\mathrm{K^+}) + r(\mathrm{Br^-}) \approx 329\ \mathrm{pm}$）。（晶格焓以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
$$
\frac{1.202\times10^{5} \times 2 \times 1}{329} \times \left(1 - \frac{34.5}{329}\right) = 730.7 \times 0.895 = 654\ \mathrm{kJ\,mol^{-1}};
$$
实验值约为 $670\ \mathrm{kJ\,mol^{-1}}$。
:::
:::

::: exercise 电荷占主导 {level=1 check="5"}
$\mathrm{MgO}$ 的晶格焓大约是 $\mathrm{NaCl}$ 的多少倍？（输入倍数。）
::: solution
约 $5$ 倍：$\mathrm{MgO}$ 的 $z_+z_- = 4$ 对 $1$，被较短的距离部分抵消，得 $3890/787 \approx 4.9$。电荷重于尺寸——这就是氧化物难熔而卤化物不然的原因。
:::
:::

::: exercise LiF 的玻恩-哈伯循环 {level=2 check="1042"}
用 $\Delta_\mathrm{sub}H(\mathrm{Li}) = 161$、$IE_1(\mathrm{Li}) = 520$、$\tfrac{1}{2}D(\mathrm{F_2}) = 79$、$\Delta_\mathrm{ea}H(\mathrm{F}) = -328$ 和 $\Delta_\mathrm{f}H^\circ(\mathrm{LiF}) = -610\ \mathrm{kJ\,mol^{-1}}$，按解离约定求 $\mathrm{LiF}$ 的晶格焓。（以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
气态离子的花费为 $161 + 79 + 520 - 328 = +432\ \mathrm{kJ\,mol^{-1}}$，于是 $\Delta_\mathrm{latt}H(\text{生成}) = -610 - 432 = -1042$，即解离值 $+1042\ \mathrm{kJ\,mol^{-1}}$；表列值为 $1030$–$1040\ \mathrm{kJ\,mol^{-1}}$。注意 $\mathrm{F_2}$ 异常小的解离焓（$D = 158\ \mathrm{kJ\,mol^{-1}}$），这是短 F–F 键上孤对排斥的结果。
:::
:::

::: exercise 马德隆常数与几何结构 {level=2}
NaCl 型与 CsCl 型晶格的马德隆常数分别为 $1.7476$ 和 $1.7627$。为什么结构相当不同而差别却很小？为什么闪锌矿型结构（$M = 1.638$）在相同 $r_0$ 下给出略不稳定的晶格？
::: solution
马德隆常数对几乎在远程相消的吸引与排斥贡献交错求和；只有近邻贡献要紧，而两种结构的最近邻环境相似（六个和八个交错电荷）。几何结构要紧，但与电荷和距离相比影响很弱。闪锌矿型较小的 $M$ 意味着相同 $r_0$ 下库仑结合略低——一种化合物采取的结构，是使*总*能量（含排斥与离子尺寸）最小的结构，这就是为什么决定结构的是半径比而不是单独的 $M$。
:::
:::

::: exercise 用卡普斯钦斯基方程估算未知物 {level=2 check="2640"}
某二价金属氟化物 $\mathrm{MF_2}$ 有 $r(\mathrm{M^{2+}}) \approx 100\ \mathrm{pm}$、$r(\mathrm{F^-}) = 133\ \mathrm{pm}$。用卡普斯钦斯基方程估算其晶格焓。（以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
$\nu = 3$，$z_+ z_- = 2$，$r_0 = 233\ \mathrm{pm}$：
$$
\frac{1.202\times10^{5} \times 3 \times 2}{233} \times \left(1 - \frac{34.5}{233}\right) = 3096 \times 0.852 = 2640\ \mathrm{kJ\,mol^{-1}}.
$$
（该金属接近 $\mathrm{Fe^{2+}}$ 或 $\mathrm{Co^{2+}}$；$\mathrm{MgF_2}$ 本身 $r_0 = 91 + 133 = 224\ \mathrm{pm}$，估算为 $2790\ \mathrm{kJ\,mol^{-1}}$。）
:::
:::

::: exercise 推导卡普斯钦斯基近似 {level=3}
从玻恩-朗德方程出发，证明把 $M(1 - 1/n)$ 换成 $0.88\,\nu$ 后，岩盐型与萤石型的因子在约 $10\ \%$ 内重现，并解释卡普斯钦斯基方程为什么仍能把晶格焓估算到几个百分点。
::: solution
岩盐型取 $n = 8$：$M(1-1/n) = 1.7476 \times 0.875 = 1.529$，对比 $0.88 \times 2 = 1.76$；萤石型取 $n = 8$：$2.5194 \times 0.875 = 2.20$，对比 $0.88 \times 3 = 2.64$。这一替换分别高估库仑因子 $15\ \%$ 和 $20\ \%$——用于预测尚可接受，这就是估算用卡普斯钦斯基、精确计算用玻恩-朗德的原因。实践中误差之所以被驯服，是因为同一替换与经验修正 $(1 - d/r_0)$（$d = 34.5\ \mathrm{pm}$）配对，使估算随离子靠近而收缩；又因为 $\nu$ 追踪化学式单位中离子对的数目：这两个经验选择是共同对实验晶格焓拟合出来的，所以它们的误差部分相消。
:::

::: exercise 法扬斯规则的应用 {level=3}
$\mathrm{AgCl}$ 在 $455\ \mathrm{^\circ C}$ 熔化，而 $\mathrm{NaCl}$ 在 $801\ \mathrm{^\circ C}$ 熔化，尽管 $\mathrm{Ag^+}$（$115\ \mathrm{pm}$）与 $\mathrm{Na^+}$（$102\ \mathrm{pm}$）的离子半径相近。解释之。然后推理预测 $\mathrm{AgI}$ 的溶解度与 $\mathrm{AgCl}$ 相比如何，以及 $\mathrm{AgCl}$ 的玻恩-哈伯晶格焓与其玻恩-朗德值相比会显示什么。
::: solution
$\mathrm{Ag^+}$ 带有 $4d^{10}$ 壳层，其电子对核电荷的屏蔽很差，所以在半径相近时对阴离子的极化远强于稀有气体型的 $\mathrm{Na^+}$。结合获得共价成分，晶格变软、熔点变低。$\mathrm{AgCl}$ 的玻恩-哈伯晶格焓超过玻恩-朗德预言——这份离子记账看不到的额外稳定性，正是部分共价性的经典标志。对溶解度应用同样的论证：$\mathrm{I^-}$ 比 $\mathrm{Cl^-}$ 更大、可极化性强得多，所以 $\mathrm{AgI}$ 是更共价、更难溶的固体——它的溶解度比 $\mathrm{AgCl}$ 低约 $3\times10^{6}$ 倍（照相定影液之所以有效，是因为硫代硫酸根是更强的配体，能把顽固的 $\mathrm{Ag^+}$ 拉进配合物）。在银的卤化物这一族中，控制化学的是极化，而不是离子半径。
:::
