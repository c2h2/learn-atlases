把目光扫过元素周期表数一数：五分之四的元素是金属。它们的性质是一张[[bonding-structure/covalent-lewis]]的定域键从来无力解释的清单。铜被拉成千米长的导线用于电网——它导电，而且*流动*而不断裂。汞在室温下是*液体*却导电。铁在锻炉中烧得发白而仍保持形状；钠则相反，在温和的火焰中 $98\ \mathrm{^\circ C}$ 即熔化，但两者都导电。金属还发光：钠或铁新切的表面如镜子般映出房间，这是任何定域二电子键的安排都无法解释的，因为定域电子只在分子跃迁的特定能量吸收可见光。导电性、延展性、金属光泽，以及熔点从铯（$28\ \mathrm{^\circ C}$）到钨（$3422\ \mathrm{^\circ C}$）的巨大*跨度*，都要求一种模型：其中价电子根本不定域在原子对之间，而是属于整块样品。最古老的这种模型——**电子海**，正离子浸泡在共享电子的气体中——作为开场白不错，作为结语很差：它说不出为什么金刚石是绝缘体而石墨导电，为什么钠每个原子一个电子却导电、而金刚石每个原子四个电子"本该"导电，也说不出为什么一个纯净、完美周期性的晶体根本不散射它的电子。正确的语言是能带理论：把[[bonding-structure/molecular-orbitals]]的分子轨道放手让它跑到阿伏加德罗常数那么大的数目。

## 能带：巨型分子的分子轨道

把[[bonding-structure/molecular-orbitals]]的 LCAO 机器推到其逻辑极端。两个 H 原子给出两个分子轨道；三个给出三个；一千个给出一千个。对一块宏观晶体，每立方厘米 $N \sim 10^{22}$ 个原子各自贡献其价轨道，$N$ 个轨道构成 $N$ 个分子轨道——只是此时相邻能级间隔约为 $10^{-22}\ \mathrm{eV}$ 量级，小到无法测量。分立的能级模糊成一条**能带**。

::: definition 能带 {#def-band}
**能带**是 $N$ 个原子组合 $N$ 个同类原子轨道时形成的准连续分子轨道集合：$N$ 个分子轨道靠得极近（能级间隔约为带宽的 $1/N$，对 $N \sim 10^{23}$ 完全可以忽略），以至于电子像对连续体一样占据它。能带的**宽度**——典型价带为几个电子伏——度量轨道重叠的强弱：弥散轨道与密堆积结构带宽，紧密定域轨道带窄。内层**芯能级**的轨道在相邻原子间几乎不重叠，保持尖锐：它们基本保持原子性，这正是芯电子光谱在固体中仍能看到"碳 $1s$"与"氧 $1s$"谱线的原因。每条带容纳 $2N$ 个电子，每个轨道两个、自旋相反。
:::

由于每个原子通常拥有若干价轨道，每类原子轨道产生自己的能带——一条 $3s$ 带、三条相互重叠的 $3p$ 带——而谁导电谁不导电的全部故事，都是*每条带容纳多少电子、各带如何被填充*的问题。

::: proposition 能带填充与导电性 {#prop-band-filling}
固体在通常温度下是否导电，由其能带的填充决定（条件：纯净、化学计量比的晶体，温度远低于使其熔化的温度）：

- **部分填充的带 $\Rightarrow$ 导体。**电场的作用方式是把电子轻推到动量略异的近空邻近态。部分填充的带以任意小的能量代价提供这些态。钠是典型：其 $3s$ 带容纳 $2N$ 个电子而含有 $N$ 个——恰好半满。
- **满带与下一条带之间隔以大间隙 $\Rightarrow$ 绝缘体。**金刚石：每个 C 四个价轨道（$2s + 3 \times 2p$）给出总容量 $4N$ 个电子的带，而碳恰好提供 $4N$ 个——成键（价）带*恰好全满*，反键（导）带全空，相隔 $5.5\ \mathrm{eV}$ 的间隙（标准数据表值）。任何电场都推不动什么。
- **满带但间隙小 $\Rightarrow$ 半导体。**热能把一小部分但指数增长的电子激发过间隙，留下可动的空穴。硅：$E_\mathrm{g} = 1.1\ \mathrm{eV}$；锗 $0.67\ \mathrm{eV}$；砷化镓 $1.4\ \mathrm{eV}$（$300\ \mathrm{K}$ 标准数据表值）。
- **能带重叠可以使"偶数"元素金属化。**镁的 $3s$ 带恰好全满（$2N$ 个电子）——但在固体中空的 $3p$ 带在能量上与它重叠，于是两者共享电子，合并体系有可用的空态。镁导电；"电子数为偶"不是判据，*可用态*才是。
:::

填充规则值得一段推导，而不是一句断言——包括那个使所有碱金属成为导体、而若带不重叠就会使所有碱土金属成为绝缘体的计数。

::: proof 态的计数，以及本征半导体的激活律 {#proof-band-counting}
**(i) 容量。**$N$ 个原子贡献 $N$ 个某类原子轨道；LCAO 恰好给出 $N$ 个分子轨道（轨道数守恒，[[bonding-structure/molecular-orbitals#prop-mo-rules]]）；泡利原理在每个轨道放两个电子（自旋相反）。因此一条带容纳 $2N$ 个电子。碱金属每个原子一个价电子：$s$ 带半满，每个碱金属都是导体——从锂到铯，无一例外。碱土金属有两个：$s$ 带将恰好全满，固体本应是绝缘体——而且*确实*会是，如果下一条带（$p$ 型）在它之上的话。在真实的金属中 $s$ 带与 $p$ 带重叠，于是双带体系把 $2N$ 个电子放进 $4N$ 个态：整体部分填充，导电。同样的逻辑给一切分类：十四族在金刚石结构中每个原子四个轨道、四个电子——满价带加间隙，故为绝缘体或半导体。

**(ii) 激活律。**在本征（纯）半导体中，导电需要上带中有电子，这至少花费间隙 $E_\mathrm{g} = E_\mathrm{c} - E_\mathrm{v}$。玻尔兹曼统计论证确定其数目。费米能级之上能量为 $E$ 的任一态的占据数按 $e^{-(E - E_\mathrm{F})/k_\mathrm{B}T}$ 衰减（费米-狄拉克分布，见下文[[#def-fermi-dirac]]的高能尾），故电子与空穴浓度为
$$
n \propto e^{-(E_\mathrm{c} - E_\mathrm{F})/k_\mathrm{B}T}, \qquad p \propto e^{-(E_\mathrm{F} - E_\mathrm{v})/k_\mathrm{B}T}.
$$
电子与空穴成对产生，故 $n = p$，而其乘积与 $E_\mathrm{F}$ 的（不可知、不重要的）位置无关：
$$
n^2 = np \propto e^{-(E_\mathrm{c} - E_\mathrm{v})/k_\mathrm{B}T} = e^{-E_\mathrm{g}/k_\mathrm{B}T}
\qquad\Longrightarrow\qquad
n \propto e^{-E_\mathrm{g}/2k_\mathrm{B}T}.
$$
由于电导率 $\sigma \propto n$，$\ln\sigma$ 对 $1/T$ 作图是斜率为 $-E_\mathrm{g}/2k_\mathrm{B}$ 的直线——这是测带隙的标准实验途径。对硅，$E_\mathrm{g}/2k_\mathrm{B} = 0.55\ \mathrm{eV} / 8.617\times10^{-5}\ \mathrm{eV\,K^{-1}} = 6383\ \mathrm{K}$，故在 $300\ \mathrm{K}$ 载流子占据带有因子 $e^{-6383/300} = e^{-21.3} = 5.7\times10^{-10}$：极小，这就是纯硅导电差的原因——而它指数地*敏感*，这就是为什么它做成热敏电阻如此之好、掺杂之后做成晶体管如此之好。
:::

:::

::: definition 费米-狄拉克分布 {#def-fermi-dirac}
温度为 $T$ 的费米子体系中，能量为 $E$ 的单电子态被占据的概率是**费米-狄拉克分布**
$$
f(E) = \frac{1}{e^{(E - E_\mathrm{F})/k_\mathrm{B}T} + 1},
$$
其中 $E_\mathrm{F}$，**费米能**（或费米能级），是使 $f = \tfrac12$ 的能量——对金属，基本上就是 $\mathrm{300\ K}$ 下最高占据态的能量。$T = 0$ 时分布是一个台阶：$E_\mathrm{F}$ 以下全满，以上全空。在通常温度下，台阶在几个 $k_\mathrm{B}T \approx 0.03\ \mathrm{eV}$ 的窗口内被抹平——而费米能有几个电子伏。只有该窗口内的电子才有够得着的空态，这就是金属之所以如此导电、其电子对比热贡献几乎为零的那个安静理由。
:::

## 从填充读出的推论

::: example 钠、镁、铝：三个邻居，三种填充 {#ex-na-mg-al}
Na（$3s^1$）、Mg（$3s^2$）、Al（$3s^2 3p^1$）是第三周期的邻居。解释它们的导电性，以及它们的电导率沿该行递增的事实（$298\ \mathrm{K}$：$2.1$、$2.3$、$3.5 \times 10^{7}\ \mathrm{S\,m^{-1}}$，标准数据表值）。
::: solution
**Na：**每个原子一个价电子把 $3s$ 带填到一半（$2N$ 个态中 $N$ 个电子）——教科书式导体，[[#prop-band-filling]]。**Mg：**两个电子恰好填满 $3s$ 带——但空的 $3p$ 带与它重叠，于是 $2N$ 个电子铺展在合并 $s$–$p$ 系的 $4N$ 个态上：部分填充，导电。**Al：**三个电子对 $4N$ 个 $s$–$p$ 态，同样部分填充。沿行递增的电导率跟随进入部分填充系的电子数递增——每个原子的载流子更多——并被散射所缓和，这就是为什么增幅是 $1.7$ 倍而不是 $3$ 倍。Mg 的教训是学生最常弄错的一条：它导电*是因为带重叠*，而不是因为"$3s^2$ 电子是离域的"，仿佛满带是一团气体。
:::
:::

::: example 沿十四族下行：五行之内从绝缘体到金属 {#ex-group14}
碳（金刚石）是绝缘体（$E_\mathrm{g} = 5.5\ \mathrm{eV}$），硅（$1.1\ \mathrm{eV}$）与锗（$0.67\ \mathrm{eV}$）是半导体，灰锡（$\alpha$-Sn）是零带隙半金属，铅是金属。解释这一趋势。
::: solution
五者都采取（或派生自）金刚石结构，每个原子四条成键带与四条反键带，容量 $4N$ 由 $4N$ 个价电子填满——问题只在于两组之间的间隙大小。沿列下行，价轨道（$2s,2p \to 6s,6p$）越来越弥散，相邻原子间重叠增强，带*变宽*。窄时相互分开的成键带与反键带随变宽开始重叠，间隙塌缩：$5.5 \to 1.1 \to 0.67 \to 0\ \mathrm{eV}$（灰锡是半金属——间隙趋于零并带一点带重叠），到铅则为负重叠，是真正的金属。同样的物理以缩微形式解释了为什么对其中任何一个加压都会使其金属化：把原子挤近会加宽带、闭合间隙。化学中最熟悉的一列，读对了，就是一卷绝缘体变成金属的连续胶片。
:::
:::

::: example 硅的电导率随温度上升有多快？ {#ex-si-ratio}
用[[#proof-band-counting]]的激活律，计算本征硅在 $330\ \mathrm{K}$ 的电导率与 $300\ \mathrm{K}$ 之比，取 $E_\mathrm{g} = 1.1\ \mathrm{eV}$、$k_\mathrm{B} = 8.617\times10^{-5}\ \mathrm{eV\,K^{-1}}$。
::: solution
$$
\frac{\sigma(330)}{\sigma(300)}
= \exp\!\left[ -\frac{E_\mathrm{g}}{2k_\mathrm{B}}\left(\frac{1}{330} - \frac{1}{300}\right) \right]
= \exp\!\left[ -6383 \times (-3.030\times10^{-4}) \right]
= e^{1.934} = 6.9 .
$$
三十开尔文——一个温暖的下午对凉爽的下午——把电导率乘以近七倍。令指数为 $\ln 2$ 得室温附近倍增间隔约 $10\ \mathrm{K}$，这是每一只硅热敏电阻背后的经验法则。比较铜在同样 $30\ \mathrm{K}$ 内：其电阻率仅上升 $12\ \%$（下一例）。$1/T$ 中的两条斜率——一条缓负、一条陡正——是区分导体两大家族、并使[[#ex-resistivity-trends]]在每一支温度计中都重要的标志。
:::
:::

::: example 为什么热敏电阻的电阻下降而铜的上升 {#ex-resistivity-trends}
铜在室温附近的电阻率遵循 $\rho(T) = \rho_0\left[1 + \alpha (T - T_0)\right]$，$\alpha \approx 3.9\times10^{-3}\ \mathrm{K^{-1}}$（标准数据表值）。从能带图像解释为什么铜的电阻随温度*上升*，而金属氧化物热敏电阻的却*下降*。
::: solution
电导率 $=$（载流子浓度）$\times$（迁移率），两大家族各活在一个因子上。**铜：**其载流子浓度是固定的——半满带由电子数决定，$k_\mathrm{B}T \approx 0.026\ \mathrm{eV}$ 改变不了它——但更热的晶格振动更烈，更早地散射电子（声子缩短平均自由程）。迁移率下降，故 $\rho$ 上升，很好的近似下是线性的：$300 \to 330\ \mathrm{K}$，$\rho$ 增大 $3.9\times10^{-3} \times 30 = 12\ \%$。**热敏电阻（半导体）：**迁移率也随温度下降，但与载流子浓度的指数爆发相比不值一提，$n \propto e^{-E_\mathrm{g}/2k_\mathrm{B}T}$：$30\ \mathrm{K}$ 之间载流子增至数倍（[[#ex-si-ratio]]），而迁移率只降百分之几十。浓度取胜，$\sigma$ 上升，$R$ 下降——*负温度系数*。一根铜丝与一只热敏电阻在同一盏灯加热下朝相反方向变化，因为一个在改变其电子移动得*多容易*，另一个在改变电子*有多少*。
:::
:::

::: quiz
镁的排布是 $3s^2$——每个原子两个价电子，恰好填满 $3s$ 带。为什么镁仍是良导体？
- [x] 空的 $3p$ 带与满的 $3s$ 带重叠，于是合并系只半满、有可用的空态。
- [ ] $3s$ 电子是离域的，离域电子总是导电。
- [ ] 镁原子在室温电离，由离子载流。
- [ ] $3s$ 带实际上只在绝对零度才满，所以任何加热都会释放电子。
::: solution
带重叠：$2N$ 个电子共享 $3s$ 带的 $2N$ 个态与重叠 $3p$ 带的 $2N$ 个态，使合并体系部分填充（[[#prop-band-filling]]、[[#ex-na-mg-al]]）。选项 2 是电子海的口号，而且恰恰是错误类型的答案：一条*完全满*的带，无论其电子多么离域，什么都不导电——满带无处可推。选项 3 混淆了离子导电（电解质）与金属导电；选项 4 把一个已被带重叠解决的带隙当成了热激活问题。
:::
:::

## 掺杂：千万分之一的原子，指数级的威力

::: definition n 型与 p 型半导体 {#def-doping}
**掺杂**是有意加入少量杂质原子，它们提供载流子的代价远低于越过间隙的热激发。把几个硅原子（$4$ 个价电子）换成磷（$5$ 个）：磷的四个电子构成局部键，第五个只松散地束缚于其母离子，在导带底以下 $0.045\ \mathrm{eV}$ 处产生一个**施主**能级（标准数据表值）——一个类氢态，伸展在许多个点阵间距之上、并被硅的高介电常数削弱。在室温（$k_\mathrm{B}T = 0.026\ \mathrm{eV}$）下几乎每个施主都电离，各贡献一个可动电子：**n 型**，由负电荷载流子导电。若换成硼（$3$ 个电子），其空的**受主**能级约在价带顶以上 $0.045\ \mathrm{eV}$，从价带俘获电子，留下可动空穴：**p 型**。百万分之一到亿分之一的掺杂就把载流子浓度提高六到八个数量级——而 $p$-$n$ 结，两类相遇之处，优先沿单一方向导电。
:::

这笔算术——$0.045\ \mathrm{eV}$ 深的掺杂能级对 $1.1\ \mathrm{eV}$ 的间隙——正是半导体物理成为一门技术而非一件奇闻的原因：器件的载流子浓度由*光刻与剂量*决定，而不是由温度和运气决定。1947 年 12 月，在贝尔电话实验室，巴丁（Bardeen）与布拉顿（Brattain）演示了点接触锗放大器，肖克利（Shockley）的结理论把这个器件——**晶体管**——变成一种工程元件；三人分享了 1956 年诺贝尔物理学奖。此后每一只晶体管，以及单块芯片上十亿计的晶体管，都是能带理论的应用：能带、间隙、施主、受主、结。电子海永远无法被开关。

## 过渡金属：d 带承担重任

主族金属导电；过渡金属导电*而且*扛得住。它们的成键增加第二组更窄的带，来自部分填充的 $(n-1)d$ 轨道，与宽的 $s$–$p$ 带重叠。$d$ 轨道足够紧密而保持相当定域——给出强、有方向性、*内聚*的键——又足够伸展而成带，而[[bonding-structure/molecular-orbitals]]的键级逻辑在此换了一个花样适用：$d$ 带每个原子容纳十个电子，从空向半满填充时内聚能*升高*，因为成键 $d$ 态被填充而反键态保持空着。于是内聚能与熔点沿早过渡系攀升、在六族附近达到极大——铬 $1907\ \mathrm{^\circ C}$、钼 $2623\ \mathrm{^\circ C}$、钨 $3422\ \mathrm{^\circ C}$，一切金属中最高的熔点（标准数据表值）——并随反键 $d$ 态开始填充而回落。同样的 $d$ 带解释了一族人人称之为银白的元素的颜色：铜与金看起来是那个样子，因为它们满的 $d$ 带位于费米能级以下几电子伏，蓝光通过把 $d$ 电子激发到其上空态而被吸收（金的吸收边因其 $6s$ 轨道的相对论收缩从紫外移到蓝色——对一个深话题的一句诚实的话）。光泽本身更简单：部分填充的带反射任何低于等离子体能量的光子，对多数金属这在紫外——于是有了镜子。

::: warning 电子海不是模型——它说不出三件事 {#warn-electron-sea}
把"电子海"说一遍然后退休。它不能 (i) **区分金刚石与石墨**：两者都是碳、键看起来定域，只有能带填充加间隙——$4N$ 个态中四个电子，金刚石间隙 $5.5\ \mathrm{eV}$，石墨半满 $\pi$ 带——才说出为什么一个绝缘一个导电（也说不出为什么灰锡是半金属，[[#ex-group14]]）；(ii) **解释为什么纯金属导电这么好**：*完美周期性*的晶格根本不散射布洛赫电子——电阻来自振动与缺陷，而不是电子像弹珠一样撞离子，干净铜在室温的平均自由程是几十纳米，几百个原子间距；(iii) **把两种能量分开**：*带隙*（把电子从价带激发到导带所需的能量，Si $1.1\ \mathrm{eV}$）不是*功函数*（把电子从固体移到真空所需的能量，如铯 $\sim 2.1\ \mathrm{eV}$、铜 $\sim 4.7\ \mathrm{eV}$）——一个是内部台阶，另一个是逃逸费，混淆它们会毁掉每一道光电效应计算。最后，"部分填充的带"不等于"电子像气体一样自由漫游"：载流子是铺满整个晶体的布洛赫波，只有 $E_\mathrm{F}$ 附近那层薄壳才动得了（见[[#def-fermi-dirac]]）。
:::

::: history
德鲁德（Drude）1900 年的金属电子论把价电子当作经典气体——第一个"电子海"，而且带着它错误的热容，是该模型最有教益的失败。修补来自量子统计：泡利（Pauli）不相容原理（1925）要电子层层堆叠，索末菲（Sommerfeld）1928 年的重新表述把费米-狄拉克统计用于金属电子气，证明只有费米能附近的电子参与导电与热容——这一结果在每一本固体物理教材中原样存续。同年，布洛赫（Bloch）在慕尼黑的博士论文中把问题彻底解决：完美周期性晶格中的电子波无散射地传播，其允许能量分裂为被间隙隔开的能带——本课时赖以建立的能带结构的源头；威尔逊（Wilson）1931 年的论文随后用能带填充把固体分类为金属、半导体与绝缘体，正是上面的方案。实际的收获在 1947 年 12 月的贝尔电话实验室：巴丁（Bardeen）与布拉顿（Brattain）造出了第一只晶体管，肖克利（Shockley）的理论将其推广——这个器件的可能性本身，靠抬高与降低掺杂能带之间的势垒来开关电流，对电子海是不可见的，对能带理论却是显然的。
:::

## 后续内容

能带生活在晶格上：决定本课时几何结构的结构、堆积与晶胞见[[bonding-structure/solid-structures]]，它们的衍射见[[materials-chemistry/diffraction]]。能带模型本身——布里渊区、直接带隙与间接带隙、有效质量、费米面——在[[materials-chemistry/electronic-structure-solids]]中展开，并以[[materials-chemistry/crystal-structures]]的晶体学为其语言。而回去的桥就是[[bonding-structure/molecular-orbitals]]中搭起的那座：能带不过是一个勺子大小的分子的分子轨道图。与此同时，离子键与共价键是本课时能带图像在其间插值的两个极限——满间隙与共享带是同一根轴，[[bonding-structure/ionic-bonding]]与[[bonding-structure/covalent-lewis]]已作铺垫。

::: summary
- 能带是由 $N$ 个原子轨道构成的 $N$ 个分子轨道的准连续体；它容纳 $2N$ 个电子，其宽度度量轨道重叠。
- 导体有部分填充的带（Na：$2N$ 个态的 $3s$ 带中 $N$ 个电子）；绝缘体有被大间隙护住的满带（金刚石，$5.5\ \mathrm{eV}$）；半导体有小间隙（Si $1.1$、Ge $0.67$、GaAs $1.4\ \mathrm{eV}$）。
- 能带*重叠*使"满带"元素金属化：Mg 导电是因为 $3s$ 与 $3p$ 带合并，而不是因为其电子自由。
- 本征载流子浓度遵循 $n \propto e^{-E_\mathrm{g}/2k_\mathrm{B}T}$：硅的电导率从 $300$ 到 $330\ \mathrm{K}$ 上升约七倍，约每 $10\ \mathrm{K}$ 倍增。
- 金属与半导体的温度系数相反，因为加热在两者中都散射载流子（迁移率下降），却只在半导体中*产生*载流子（浓度上升，指数式）。
- 掺杂把施主或受主能级放在带边约 $0.045\ \mathrm{eV}$ 处：n 型（Si 中掺 P）与 p 型（Si 中掺 B）是晶体管（贝尔实验室，1947）的原材料。
- 过渡金属的内聚、六族熔点极大（W，$3422\ \mathrm{^\circ C}$）以及 Cu 与 Au 的颜色，都来自与 $s$–$p$ 带重叠的部分填充 $d$ 带。
:::

## 练习

::: exercise 按能带填充分类 {level=1}
判断下列各者是导体、半导体还是绝缘体，并从能带填充给出理由：(a) 铯；(b) 硫（每个 S 原子向 $\mathrm{S_8}$ 环贡献两个半满 $3p$ 轨道，满价带，间隙约 $2.6\ \mathrm{eV}$）；(c) 金刚石；(d) GaAs（平均每个原子四个价电子，与 Si 相同）；(e) 钾。
::: solution
(a) 导体：每个原子一个 $6s$ 电子进入 $2N$ 个态的带——半满。(b) 绝缘体：$\mathrm{S_8}$ 环的成键形成满带，间隙 $2.6\ \mathrm{eV}$——对通常的热占据太大。(c) 绝缘体：$4N$ 个电子恰好填满 $4N$ 个态的价带，间隙 $5.5\ \mathrm{eV}$。(d) 半导体：III–V 平均为每两个原子 $3+5 = 8$ 个电子 $=$ 每个原子 $4$ 个，与 Si 等电子，间隙 $1.4\ \mathrm{eV}$。(e) 导体：半满 $4s$ 带，与一切碱金属相同——[[#prop-band-filling]]。
:::
:::

::: exercise 满带计数 {level=1 check="4"}
一块人造金刚石晶体含 $1.00\ \mathrm{mol}$ 碳原子。其价带（四条 $sp^3$ 成键带）恰好全满。价带容纳多少摩尔电子？（输入摩尔数。）
::: solution
晶体的 $4N$ 个价轨道分裂为一组成键态 $4N$（价带）与一组反键态 $4N$（导带）。碳每个原子提供四个电子，故对 $1.00\ \mathrm{mol}$ 碳，价带容纳 $4N = 4.00\ \mathrm{mol}$ 电子，导带为空——即[[#prop-band-filling]]中恰好满带的绝缘体。
:::
:::

::: exercise 奇电子定理 {level=1}
解释为什么每个原胞含*奇数*个电子的单质固体必是导体，并用该论证给铷分类；然后解释为什么白磷（分子 $\mathrm{P_4}$，满带，间隙约 $2.6\ \mathrm{eV}$）逃脱结论。
::: solution
带的容量以 $2N$ 个电子为一档：每胞偶数个电子*可以*恰好填满整数条带，奇数个却不能——$2N$ 个态的带成对填满，故奇数计数使顶带部分填充，以任意小的能量代价有空态可用：金属。铷（$4s^1$，每胞一个电子）因此单凭计数就是导体。白磷避开定理，因为它的电子锁在 $\mathrm{P_4}$ 分子饱和的定域键里——满带、间隙、绝缘体。定理读作"奇 $\Rightarrow$ 金属"，永远不是"偶 $\Rightarrow$ 金属"，而 $\mathrm{P_4}$ 的逃脱证明判据是能带填充，不是电子计数。
:::
:::

::: exercise 同一斜率下的锗 {level=2 check="3.2"}
用 $n \propto e^{-E_\mathrm{g}/2k_\mathrm{B}T}$ 与 $k_\mathrm{B} = 8.617\times10^{-5}\ \mathrm{eV\,K^{-1}}$，计算锗（$E_\mathrm{g} = 0.67\ \mathrm{eV}$）在 $330\ \mathrm{K}$ 的本征电导率与 $300\ \mathrm{K}$ 之比。（输入比值。）为什么锗是高温整流器的较差选择？
::: solution
指数 $= \frac{0.67}{2 \times 8.617\times10^{-5}} \times \left(\frac{1}{300} - \frac{1}{330}\right) = 3887 \times 3.030\times10^{-4} = 1.178$，故比值为 $e^{1.178} = 3.2$。较小的间隙还意味着在任何温度下远为庞大的*绝对*本征载流子浓度：在硅仍然守规矩的温度下，锗自身免掺杂的载流子就已淹没器件的结，这就是为什么赢得功率电子的是硅而不是锗。
:::
:::

::: exercise 为什么钨是灯丝 {level=2}
钨的熔点为 $3422\ \mathrm{^\circ C}$，一切金属中最高；其邻居铼接近，锇与铱较低，而铯在 $28\ \mathrm{^\circ C}$ 熔化。从能带/d 带图像解释六族极大以及钨在其中的地位，并说明极大为什么恰落在该处。
::: solution
过渡金属的内聚主要来自窄的 $d$ 带：每个原子十个 $d$ 态，从空填充时，只要电子进入*成键* $d$ 态键级就升高，一旦*反键* $d$ 态开始填充就降低。键级在半满——六族，$d^5$——达到峰值，内聚能与熔点亦然：Cr、Mo、W 沿族攀升（$1907$、$2623$、$3422\ \mathrm{^\circ C}$），因为 $5d$ 轨道比 $4d$ 重叠更好、$4d$ 比 $3d$ 更好，而 W 居于两个效应的顶峰。过六族后反键态填充，内聚向贵金属回落。铯，一个宽而半满的带中一个 $6s$ 电子、没有 $d$ 相助，是另一个极端：内聚弱，熔点低于体温。钨灯丝能用，是因为 $3422\ \mathrm{^\circ C}$ 的键强让导线白热（$\sim 3000\ \mathrm{K}$）而不熔化——键级，字面意义上，为你服务。
:::
:::

::: exercise 锡疫，能带理论版 {level=2}
白（$\beta$）锡是金属；灰（$\alpha$）锡在 $13.2\ \mathrm{^\circ C}$ 以下稳定，是具有金刚石结构的零带隙半金属。留在寒冷教堂里的锡器会碎成灰色粉末（"锡疫"）。用[[#ex-group14]]的十四族趋势解释 (a) 为什么 $\alpha$-Sn 不像金刚石那样是绝缘体，(b) 为什么向更致密白锡的转变在加压或升温时发生。
::: solution
(a) $\alpha$-Sn 具有金刚石结构——$4N$ 个电子在 $4N$ 个价态——所以问题只在间隙，而对锡弥散的 $5s/5p$ 轨道，变宽的成键带与反键带恰好相触：间隙 $0$，半金属，载流子浓度小，导电差但真实。(b) 两种形态能量几乎相等，因为竞争在于打开间隙（降低电子能量，灰半金属）与致密堆积（降低体积能量，白金属）之间；$\alpha$-Sn 的间隙如此之小，电子的彩头微乎其微。升温到 $13.2\ \mathrm{^\circ C}$ 以上有利于金属性白锡，加压同样有利，因为压力偏爱更致密的结构并同时加宽带——压力是普遍的金属化剂。未供暖教堂里的旧锡管风琴管碎裂，恰恰因为寒冷使灰锡成为稳定形态；转变一旦播下，便在金属中蔓延。一条由闭合间隙支配的相界：能带理论，以尘埃的形态。
:::

::: exercise 推导容量，然后击穿半导体 {level=3}
(a) 由轨道数守恒与泡利原理推导一条带的容量，并给出金刚石结构中 $N$ 个十四族原子生成的态数与所得各带的总容量。(b) 估算在硅（$E_\mathrm{g} = 1.1\ \mathrm{eV}$）中产生一个电子–空穴对所需的最小光子能量，并解释为什么纯硅对波长 $2.0\ \mu\mathrm{m}$ 的红外光是透明的，而对可见绿光（$2.35\ \mathrm{eV}$）不透明。
::: solution
(a) $N$ 个原子 $\times$ 四个价轨道（$s, p_x, p_y, p_z$）给出 $4N$ 个分子轨道——四条带——总容量 $8N$ 个电子；它们分裂为一组成键态 $4N$（由 $4N$ 个价电子填满）与一组成反键态 $4N$（空）。(b) 最小光子能量即间隙，$1.1\ \mathrm{eV}$；对应波长为 $\lambda = hc/E = (1240\ \mathrm{eV\,nm})/(1.1\ \mathrm{eV}) \approx 1100\ \mathrm{nm} = 1.1\ \mu\mathrm{m}$。$2.0\ \mu\mathrm{m}$ 的光子携带 $0.62\ \mathrm{eV} < E_\mathrm{g}$：带间吸收不可能发生（纯净、无缺陷的硅在可见/近红外没有别的东西可吸收），于是红外穿过——硅是标准的近红外光学材料。$2.35\ \mathrm{eV} > E_\mathrm{g}$ 的绿光光子在产生电子–空穴对时被吸收，故可见光在薄表层内即被衰减。作为带隙测量的透明性：材料是一片其截止边即自身间隙的滤光片。
:::

::: exercise 热敏电阻设计 {level=3 check="63"}
一只金属氧化物热敏电阻由 $E_\mathrm{g} = 1.5\ \mathrm{eV}$ 的陶瓷半导体制成。其电导率在 $300\ \mathrm{K}$ 与 $350\ \mathrm{K}$ 之间变化多少倍？用 $n \propto e^{-E_\mathrm{g}/2k_\mathrm{B}T}$、$k_\mathrm{B} = 8.617\times10^{-5}\ \mathrm{eV\,K^{-1}}$，忽略迁移率变化。（输入比值 $\sigma(350)/\sigma(300)$，取整。）
::: solution
指数 $= \frac{1.5}{2 \times 8.617\times10^{-5}}\left(\frac{1}{300} - \frac{1}{350}\right) = 8704 \times 4.762\times10^{-4} = 4.145$，故 $\sigma(350)/\sigma(300) = e^{4.145} = 63$。五十度的变化使电阻移动近两个数量级——这正是热敏电阻是灵敏温度计、而失控时会热失控的原因：电流越大 $\to$ 热越多 $\to$ 电流越大。铜在同一区间变化 $1 + 3.9\times10^{-3} \times 50 \approx 1.2$——指数对线性，再一次。
:::
