两个氢原子相隔遥远时互不理睬；被推到一处时，它们却做出了任何离子模型都无法解释的事——*共享*电子，成为分子 $\mathrm{H_2}$，其能量比分离的原子低 $436\ \mathrm{kJ\,mol^{-1}}$。谁也不让出电子：两者的电离能完全相同，转移电子只会得不偿失。形成的反而是**共价键**——由两个原子核同时抓住的一对共享电子。这个想法陈述起来简单，影响却极为深远：几乎所有的分子结构——水、DNA、聚乙烯、阿司匹林——都是共享电子对的排布，而化学家为画出它们发明的语言——路易斯结构——是整个学科的工作速记。本课从 $\mathrm{H_2}$ 的能量曲线出发搭建这套语言：如何数电子、如何画电子、如何用形式电荷在几种画法之间做出判断，以及规则在何处失效。

## 共价键

追踪两个 H 原子靠近时的能量。距离很大时什么也不发生。当距离缩小到几百皮米以下，每个电子开始感受到*两个*核的作用，能量下降：共享电子对位于两核之间，屏蔽了核间排斥，同时被两个核吸引。低于平衡距离后，两核彼此看得太清楚，能量陡升。曲线在 $74\ \mathrm{pm}$ 处有一个极小值——一个真实的分子——而势阱深度 $436\ \mathrm{kJ\,mol^{-1}}$ 就是 $\mathrm{H_2}$ 的键解离焓。

::: definition 共价键、电子对与八隅体 {#def-covalent-bond}
**共价键**是一对共享电子同时受两个原子核的吸引，画成一条线（$\mathrm{H–H}$）或一对点（$\mathrm{H{:}H}$）。画在键上的电子称为**成键电子对**；画在单个原子上的一对点称为**孤对电子**（非键电子对）。**八隅体规则**是路易斯（Lewis）提出的经验性观察：主族原子成键时使自己被八个价电子包围（氢和氦为两个）：每个键为它所连接的*两个*原子的计数各贡献两个电子。对 C、N、O 和卤素，八隅体规则是一条可靠得非同寻常的记账规则——但它有记录在案的例外，我们在下文遇到。
:::

曲线背后的量子力学——为什么是*一对*电子、配对又为什么降低能量——是[[quantum-chemistry/chemical-bond-qm]]中处理的交换相互作用，用化学语言则在[[bonding-structure/valence-bond]]中。眼下化学图像已经够用：共价键是一对共享电子，它有确定的长度（势阱极小值的位置）和确定的强度（势阱深度），而且它是*有方向的*，不同于[[bonding-structure/ionic-bonding]]中无方向的离子吸引。

**路易斯点式约定。** 写出元素符号，周围点上它的价电子，先分占、后成对（N 得三个单电子和一对；O 两对和两个单电子；卤素三对和一个单电子）。共享电子对画在符号之间，孤对电子留在外面。每条线是两个电子；每个原子最终都应有八隅体（氢为二电子）。这些约定连同下面的计数规则，足以画出基础结构化学中几乎的一切。

## 构建路易斯结构

::: algorithm 路易斯结构的逐步画法 {#alg-lewis}
**输入：**分子式（给出连接关系则用之，否则推断：电负性最小的原子居中，H 和 F 永远是端基）。**输出：**指定了形式电荷的路易斯结构。
1. **数价电子。** 把所有原子的族价电子相加；每个负电荷加一个，每个正电荷减一个。
2. **搭骨架。** 用单键连接原子；每个键从计数中减去 $2$ 个电子。
3. **补全外圈原子的八隅体**（H 到 2 为止），随填随减。
4. **把剩下的电子给中心原子。** 中心原子此时若有八隅体，停。若不足八个，把相邻原子的一个孤对电子变成第二或第三个键。
5. **检查形式电荷**（见下文）。若同一骨架存在形式电荷更接近零的结构，或把负电荷放在电负性更大原子上的结构，就选它。
6. **核对总数：**形式电荷之和必须等于物种的电荷，画出的电子数必须等于第 1 步的计数。
:::

::: example 碳酸根离子 $\mathrm{CO_3^{2-}}$ {#ex-carbonate}
画出 $\mathrm{CO_3^{2-}}$ 的路易斯结构。
::: solution
**计数：**C 出 $4$，每个 O 出 $6$，$2-$ 电荷加 $2$：$4 + 3\times 6 + 2 = 24$ 个价电子。**骨架：**碳居中（电负性最小，且 H 从不居中），三个 C–O 单键：剩 $24 - 6 = 18$。**外圈八隅体：**每个 O 上三对孤对电子用掉全部 $18$ 个。**中心原子：**碳此时只有 $6$ 个电子——离八隅体差两个键。**转化：**取一个氧的一个孤对电子，把它变成碳的第二个键，得一个 $\mathrm{C=O}$ 和两个 $\mathrm{C–O}$：碳有 $8$，每个氧都有 $8$，共画出 $24$ 个电子。**形式电荷：**碳 $4 - 0 - 4 = 0$；双键 O $6 - 4 - 2 = 0$；每个单键 O $6 - 6 - 1 = -1$。总和 $-2$ ✓。

双键放在哪个氧上？计数规则对三个氧不偏不倚，实验做出裁决：碳酸盐中三个 C–O 键*完全相同*，长 $129\ \mathrm{pm}$。答案是共振——三个等价贡献式，其平均就是真实的离子——见[[#prop-resonance]]。
:::
:::

::: example 水合氢离子 $\mathrm{H_3O^+}$ {#ex-hydronium}
画出 $\mathrm{H_3O^+}$ 的路易斯结构，并指出它的电荷所在。
::: solution
**计数：**$6$（O）$+ 3\times 1$（H）$- 1$（$+$ 电荷）$= 8$ 个电子。**骨架：**三个 O–H 键用去 $6$；氢不拿孤对电子，剩下的 $2$ 个作为一对孤对电子放在氧上。氧有三个键和一对孤对电子——一个八隅体；每个 H 各得其二电子。**形式电荷：**每个 H $1 - 0 - 1 = 0$；氧 $6 - 2 - 3 = +1$。正电荷落在氧上，而那对孤对电子正是 $\mathrm{H_3O^+}$ 本身可作碱的原因：质子若要接上去生成 $\mathrm{H_4O^{2+}}$，位置就是那对电子——但在水中不会发生，因为把两个正电荷放在一个小原子上代价高得离谱。同样"三键一孤对"的格局使氨 $\mathrm{NH_3}$ 呈电中性、其孤对电子可自由结合质子，成为 $\mathrm{NH_4^+}$：在铵离子中，氮有四个键、没有孤对电子、形式电荷 $5 - 0 - 4 = +1$。
:::
:::

## 形式电荷

路易斯结构是记账，而记账需要一张资产负债表。

::: proposition 形式电荷 {#prop-formal-charge}
路易斯结构中某原子的**形式电荷**为
$$
FC = V - N_\text{nb} - \tfrac{1}{2}N_\text{b} \;=\; V - (\text{非键电子}) - (\text{键数}),
$$
其中 $V$ 是自由中性原子的价电子数，$N_\text{nb}$ 是画在该原子上作为孤对电子的电子数，$N_\text{b}$ 是画在它周围键中的电子数（因此每个键贡献 $1$）。形式电荷*不是*部分电荷，也不预测电子实际所在：它是把每个键均等劈开时原子将带的电荷。作为比较工具它出奇地好用：形式电荷最接近零、且任何负形式电荷位于电负性更大原子上的结构，是真实分子的主导贡献式。
:::

::: proof 形式电荷之和等于物种的电荷 {#proof-formal-charge}
把定义对该物种的所有原子 $A$ 求和：
$$
\sum_A FC_A = \sum_A V_A - \sum_A N_{\text{nb},A} - \tfrac{1}{2}\sum_A N_{\text{b},A}.
$$
第一个和是自由中性原子的价电子总数 $V_\text{tot}$。第二个是画出的非键电子总数 $N_\text{nb}$。第三个中，每个键恰好被两个原子共享，并向它们各自的计数贡献 $2$ 个成键电子，所以 $\sum_A N_{\text{b},A} = 2 \times (2 \times \text{键数}) = 2N_\text{b}^\text{tot}$，其中 $N_\text{b}^\text{tot}$ 是成键电子总数；于是 $\tfrac12 \sum_A N_{\text{b},A} = N_\text{b}^\text{tot}$。因此
$$
\sum_A FC_A = V_\text{tot} - \left(N_\text{nb}^\text{tot} + N_\text{b}^\text{tot}\right) = V_\text{tot} - N_\text{tot},
$$
而 $N_\text{tot}$，实际画出的电子数，等于 $V_\text{tot}$ 减去离子的电荷（每个负电荷加一个电子）。所以 $\sum_A FC_A$ 等于物种的电荷。这个证明恰恰就是均等共享的假设：形式电荷是把成键电子按 $50{:}\,50$ 劈开时账本给出的结果，而资产负债表必须配平。
:::

::: example 二氧化硫与扩展八隅体问题 {#ex-so2}
$\mathrm{SO_2}$（$18$ 个价电子）有两种路易斯结构相竞争：(a) $\mathrm{O{=}S{-}O}$，S 上一对孤对电子、一个双键一个单键；(b) $\mathrm{O{=}S{=}O}$，S 上一对孤对电子、两个双键。计算形式电荷并作出判断。
::: solution
硫的 $V = 6$，氧的 $V = 6$。结构 (a)：S 有 $2$ 个非键电子和 $3$ 个键：$FC = 6 - 2 - 3 = +1$；双键 O：$6 - 4 - 2 = 0$；单键 O：$6 - 6 - 1 = -1$。总和 $0$ ✓，但有两个原子带形式电荷。结构 (b)：S 有 $2$ 个非键电子和 $4$ 个键：$FC = 6 - 2 - 4 = 0$；两个 O 都是 $0$。所有形式电荷皆为零，所以教科书规则"使形式电荷最小"偏爱 (b)——代价是把 $10$ 个电子放在硫上。现代观点更诚实：高级计算表明 S–O 键高度极化，除 (a) 已包含的成分外几乎没有双键成分，(b) 的"额外"稳定化最好描述为离子性贡献（$\mathrm{S^+O^-}$ 共振），而不是真正的 $3d$ 轨道参与。两种结构都是合法的记账；教训是：形式电荷规则给*画法*排序，不是给分子排序。
:::
:::

::: example SF$_6$ 与扩展八隅体 {#ex-sf6}
画出 $\mathrm{SF_6}$ 和 $\mathrm{PCl_5}$，并说明八隅体规则对它们说什么。
::: solution
$\mathrm{SF_6}$：$6 + 6\times 7 = 42$ 个价电子。六个 S–F 键用去 $12$；补全六个氟的八隅体用去其余 $30$；硫剩下*六个键、没有孤对电子*——它周围有 $12$ 个电子。$\mathrm{PCl_5}$：$5 + 5\times 7 = 40$；五个键（$10$ 个电子）加五个氯的八隅体（$30$ 个）使磷剩 $10$ 个。两者形式上都**超出八隅体**——第三周期及更重的元素被画出 $10$、$12$ 或更多电子（"扩展八隅体"、"超价"），记账之所以允许，是因为第三周期的价层有对称性合适的 $3d$ 轨道来容纳它们。如实说明的告诫是：现代键分析发现 $d$ 轨道的贡献极小；$\mathrm{SF_6}$ 相对纯八隅体图像的额外稳定性，最好用*三中心键*——电子对同时被三个原子共享——和离子性贡献（$\mathrm{S^+F^-}$ 成分）来描述，而不是六个连到 $3d$ 杂化轨道上的普通二电子键。在教科书层面，扩展八隅体的画法是正确的记账、出色的预测；只是别把画法当成机理。
:::
:::

## 共振

::: proposition 共振与杂化体 {#prop-resonance}
当单个路易斯结构无法排布多重键和孤对电子、使所有原子都得到最佳形式电荷时，若干结构——**共振贡献式**——占据相同的原子位置、只在电子排布上不同。真实分子**不是**其中任何一个贡献式，也**不是**它们的平衡混合物：它是单一的量子力学物种——**共振杂化体**——其电子同时离域于所有贡献式之上。后果是可观测的：键长与键级变得居中且均等化。碳酸根离子中三个 C–O 键都测得 $129\ \mathrm{pm}$——介于甲醇的 $\mathrm{C–O}$ 单键（$143\ \mathrm{pm}$）与羰基化合物的 $\mathrm{C{=}O}$ 双键（$120$–$122\ \mathrm{pm}$）之间——每个键的键级为 $1\tfrac{1}{3}$，即三个等价贡献式上一个双键两个单键的平均。
:::

::: warning 共振箭头不是平衡箭头——八隅体规则也不是自然定律 {#warn-resonance}
两个记号陷阱和一个概念陷阱。第一，共振贡献式用双向箭头 $\mathrm{\leftrightarrow}$ 连接，代表*同一个分子*；平衡用鹰钩箭头 $\rightleftharpoons$，代表*相互转化的不同分子*。用 $\rightleftharpoons$ 写碳酸根的贡献式，等于声称双键随时间在氧之间跳跃——实验说它不跳：每个键永远完全相同。第二，移动电子从不移动原子：需要原子改变位置的贡献式是互变异构体（另一个主题），不是共振。第三，八隅体规则是经验性记账规则，不是自然定律：它奏效是因为八个电子恰好填满第二周期原子的四个 $s$ 和 $p$ 价轨道；它也恰恰在计数失效处失效——不足八个时、奇数个电子时、以及较重元素处。
:::

## 八隅体规则的例外

**缺八隅体。** 最轻元素的缺电子分子停在八个之下。$\mathrm{BeCl_2}$（$16$ 个价电子）只给铍四个，$\mathrm{Cl{-}Be{-}Cl}$；$\mathrm{BF_3}$（$24$ 个）给硼六个，带一个空轨道，使它成为路易斯酸——它接受一个孤对电子（比如来自 $\mathrm{NH_3}$）正是为了补全八隅体。硼的缺八隅体性就是它的无机与有机化学的全部。

**奇电子分子。** 奇数个总数无法配对。一氧化氮 $\mathrm{NO}$（$11$ 个价电子）和二氧化氮 $\mathrm{NO_2}$（$17$ 个）各带一个单电子——它们是**自由基**，它们的化学（NO 作为信号分子、$\mathrm{NO_2}$ 在烟雾化学中）就是自由基化学。$\mathrm{NO_2}$ 部分地通过二聚为无色的 $\mathrm{N_2O_4}$、把电子配对起来，绕开它的奇电子。

**扩展八隅体。** 第三周期及更重的原子被画出 10–12 个价电子（$\mathrm{PCl_5}$、$\mathrm{SF_6}$、$\mathrm{ClF_4^-}$、磷酸根中 P 的五个键），并带上[[#ex-sf6]]中现代的告诫：记账有效，$d$ 轨道的故事大体是错的，三中心键才是更深的解释。

**判断主导贡献式。** 存在若干有效结构时，给它们排序：(i) 形式电荷最接近零者主导；(ii) 在此同等时，负形式电荷位于电负性更大原子者主导；(iii) 把同号电荷放在相邻原子上的结构不受青睐；(iv) 更多共价键（每个第二周期原子都有八隅体）重于其他一切考虑——绝不为省一个形式电荷而破坏碳、氮、氧或氟的八隅体。

## 键级、键长与键能

**键级**是两个原子间共享电子对的数目：单键为 $1$，双键为 $2$，三键为 $3$，离域键为分数（碳酸根：$1\tfrac13$；苯的 C–C：$1\tfrac12$）。三个事实把本章串在一起。键级、键长与键能相互关联：从 C–C 到 C=C 到 C≡C，长度下降（$154$、$134$、$120\ \mathrm{pm}$）、能量上升（$348$、$612$、$837\ \mathrm{kJ\,mol^{-1}}$）——共享的电子越多，把核拉得越近、抓得越牢。这层关系是反向的，但*不是*正比的：三键不是单键的三倍，因为多出的电子对进入 $\pi$ 轨道，其重叠不如所加入的 $\sigma$ 键。而键能是*因键而异*的：C–H 键的 $413\ \mathrm{kJ\,mol^{-1}}$ 在甲烷中与在乙醛中并不相同，这就是为什么表列值是*平均*键焓、用它计算只是估算。

::: example 用平均键焓估算乙烯的加氢 {#ex-bond-enthalpy}
用平均键焓估算 $\mathrm{H_2C{=}CH_2(g) + H_2(g) \to H_3C{-}CH_3(g)}$ 的 $\Delta_\mathrm{r}H$：$\mathrm{C{=}C}\ 612$、$\mathrm{H–H}\ 436$、$\mathrm{C–C}\ 348$、$\mathrm{C–H}\ 413\ \mathrm{kJ\,mol^{-1}}$。
::: solution
列出断什么、成什么，只数*变化*的部分。断：一个 $\mathrm{C{=}C}$（$612$）和一个 $\mathrm{H–H}$（$436$）：$+1048\ \mathrm{kJ\,mol^{-1}}$。成：一个 $\mathrm{C–C}$（$348$）和两个新的 $\mathrm{C–H}$ 键（$2 \times 413 = 826$）：$-1174\ \mathrm{kJ\,mol^{-1}}$。（乙烯中已有的四个 C–H 键不变、相消。）
$$
\Delta_\mathrm{r}H \approx 1048 - 1174 = -126\ \mathrm{kJ\,mol^{-1}}.
$$
由标准生成焓（$\Delta_\mathrm{f}H^\circ$：$\mathrm{C_2H_4}$ 为 $+52.3$；$\mathrm{C_2H_6}$ 为 $-84.7\ \mathrm{kJ\,mol^{-1}}$）得到的实验值为 $-137\ \mathrm{kJ\,mol^{-1}}$——估算偏低 $8\ \%$，很典型。平均键焓是许多化合物上的气相平均值；它们是初步估算、一种*思考方式*，而不是精确数字的来源。
:::
:::

::: warning 平均键焓是平均值——要知道它何时失效 {#warn-mean-bond-enthalpies}
三个局限。(i) **仅限气相**：键焓指孤立分子；溶液中的反应带有溶剂化焓，其差值可能被淹没（同一加氢反应在液相量热计中给出不同的数字）。(ii) **平均值**：表列的 $\mathrm{C–H}$ 值 $413\ \mathrm{kJ\,mol^{-1}}$ 是几十个化合物上的均值；甲烷中的真实键是 $439$，苄基 C–H 则弱得多——生成或断裂异常强或异常弱的键的反应会使估算失效。(iii) **不是单个分子的状态函数**：该方法假定键加和性，所以当反应物与产物之间的共振稳定化不同时就会退化——例如氢化苯会低估吸热代价，因为表列的"三个 C=C"图像忽略了芳香性。用平均键焓来估算、来推理；用生成焓来裁决。
:::

::: quiz
一氧化二氮 $\mathrm{N_2O}$（$16$ 个价电子，骨架 N–N–O）有三个看似合理的贡献式。哪一个是主导的？
- [x] $\mathrm{N{\equiv}N^{{+}}{-}O^{{-}}}$：负形式电荷落在电负性最大的原子氧上。
- [ ] $\mathrm{{^-}N{=}N^{+}{=}O}$：它的键最多。
- [ ] $\mathrm{N{\equiv}O^{+}{-}N^{-}}$：它把三键放在端基氮上。
- [ ] 三者贡献相同——$\mathrm{N_2O}$ 像碳酸根一样是共振杂化体。
::: solution
形式电荷：在 $\mathrm{N{\equiv}N{-}O}$ 中，端基 N 为 $5-2-3 = 0$，中心 N 为 $5-0-4 = +1$，O 为 $6-6-1 = -1$；在 $\mathrm{N{=}N{=}O}$ 中，端基 N 为 $-1$，O 为 $0$。两者形式电荷的大小相同，所以规则 (ii) 裁决：负电荷应属于氧，$\mathrm{N{\equiv}N{-}O}$ 主导（第三个结构 O 居中、氮为负离子，糟糕得多）。实验同意：N–N 距离 $113\ \mathrm{pm}$ 略长于 N≡N 三键（$110\ \mathrm{pm}$），N–O 的 $119\ \mathrm{pm}$ 介于双键与单键之间——杂化体主要是三键-单键。贡献相同需要原子等价，如碳酸根；这里原子并不相同。
:::
:::

::: history
1916 年，路易斯（Lewis）在他 1902 年立方原子模型的基础上，在《美国化学会志》（*Journal of the American Chemical Society*）上发表《原子与分子》（"The Atom and the Molecule"）：原子通过转移或——这是新点子——*共享*电子对成键，而且成键是为了凑满八个电子的壳层。朗缪尔（Langmuir）两个词都不是他造的，却很快把整个领域收入囊中，他在 1919 年推广了这幅图像，引入了**共价**和**八隅体规则**这两个词，把键强与核间电子密度联系起来，并把模型扩展到芳香体系。量子力学的论证在 1927 年随海特勒（Heitler）与伦敦（London）对 $\mathrm{H_2}$ 的处理到来，而集大成在 1939 年随鲍林（Pauling）的《化学键的本质》（*The Nature of the Chemical Bond*）完成——该书把路易斯的记账、量子力学与衍射数据熔铸成一个定量理论，以键级、键长和电负性为工作工具。你今天画的点式图，几乎原封不动，就是路易斯一个世纪前画的图——科学中最罕见的命运：一套记号熬过了每一个本要取代它的理论。
:::

## 后续内容

路易斯结构是本课程所有后续模型的输入。接下来是形状：[[bonding-structure/vsepr]]把电子对变成三维几何，[[bonding-structure/valence-bond]]用杂化轨道与 $\sigma$/$\pi$ 键解释那个形状。配对图像的失败之处——$\mathrm{O_2}$ 的顺磁性、碘蒸气的颜色——在[[bonding-structure/molecular-orbitals]]中得到解决，而你现在能画出的分子*之间*的力在[[bonding-structure/intermolecular-forces]]。这里画出的结构的命名与化学式书写约定在[[general-chemistry-1/formulas-nomenclature]]，电子对键的量子理论在[[quantum-chemistry/chemical-bond-qm]]。

::: summary
- 共价键是被两个原子核吸引的共享电子对；$\mathrm{H_2}$ 的势阱（$74\ \mathrm{pm}$，$436\ \mathrm{kJ\,mol^{-1}}$）是原型，键长与键能是它的两个实测标志。
- 路易斯记账：数价电子（阴离子加、阳离子减），搭骨架，填八隅体，中心原子不够就把孤对电子变成多重键。
- 形式电荷 $FC = V - N_\text{nb} - N_\text{bonds}$ 假定均等共享；形式电荷之和恒等于物种的电荷。
- 主导贡献式的形式电荷最接近零，且负形式电荷在电负性更大的原子上。
- 共振贡献式只在电子上不同；真实分子是单一的杂化体，键被平均、被拉平（碳酸根：三个相同的 $129\ \mathrm{pm}$ 键，键级 $1\tfrac13$）。
- 八隅体规则是经验性记账：对缺八隅体（$\mathrm{BF_3}$、$\mathrm{BeCl_2}$）、奇电子物种（$\mathrm{NO}$、$\mathrm{NO_2}$）和扩展八隅体（$\mathrm{SF_6}$，用三中心键描述更佳）失效。
- 键级越高，键越短越强；平均键焓把反应焓估算到约 $10\ \%$——仅限气相。
:::

## 练习

::: exercise 硝酸根离子 {level=1}
画出硝酸根离子 $\mathrm{NO_3^-}$ 的路易斯结构，指定形式电荷，并说明它有几个共振贡献式。
::: solution
价电子：$5 + 3\times 6 + 1 = 24$。三个 N–O 单键（$6$ 个电子），补全氧的八隅体（$18$ 个）：氮只有 $6$ 个，于是把一个氧的孤对电子变成一个 N=O 双键。形式电荷：N $5 - 0 - 4 = +1$；双键 O $0$；每个单键 O $6 - 6 - 1 = -1$；总和 $-1$ ✓。三个等价贡献式（双键可放在任一氧上），所以真实离子有三个相等的、键级为 $1\tfrac13$ 的键——与碳酸根等电子。
:::
:::

::: exercise 数电子 {level=1}
下列物种的路易斯结构中各画出多少个价电子：(a) $\mathrm{SO_4^{2-}}$，(b) $\mathrm{HCN}$，(c) $\mathrm{NO_2^+}$，(d) $\mathrm{NH_4^+}$？给出每个中心原子周围的电子数。
::: solution
(a) $6 + 4\times 6 + 2 = 32$；硫带四个 $\sigma$ 键（简单八隅体画法中八个电子；若画出 S=O 双键则为十个或十二个）。(b) $1 + 4 + 5 = 10$；结构为 $\mathrm{H{-}C{\equiv}N}$：N 上一对孤对电子，碳有四个键（八个电子），氮有八隅体。(c) $5 + 2\times 6 - 1 = 16$；$\mathrm{O{=}N^{+}{=}O}$，氮带两个双键、没有孤对电子——八个电子，与 $\mathrm{CO_2}$ 等电子。(d) $5 + 4 - 1 = 8$；氮有四个键、没有孤对电子、形式电荷 $+1$。
:::
:::

::: exercise 一氧化碳 {level=1}
画出一氧化碳 $\mathrm{CO}$（十个价电子）的路易斯结构，指定形式电荷，并解释为什么这个结构令人不安。
::: solution
每个原子上各一对孤对电子、加一个三键，$\mathrm{:C{\equiv}O:}$，两个原子都有八隅体：C $4 - 2 - 3 = -1$，O $6 - 2 - 3 = +1$。分子是电中性的，但形式电荷是碳 $-1$、氧 $+1$——按电负性*放反了*。这是八隅体记账完美运转却预测糟糕的例子：真实偶极矩很小，负端在氧上，而 CO 的化学（通过碳的孤对电子与金属成键）遵循形式电荷图像多于电负性图像。这是"一幅画法不是分子"的有用的第一课。
:::
:::

::: exercise 一个平均键焓估算 {level=2 check="-103"}
用平均键焓估算第一步氯化反应 $\mathrm{CH_4(g) + Cl_2(g) \to CH_3Cl(g) + HCl(g)}$ 的 $\Delta_\mathrm{r}H$：$\mathrm{C–H}\ 413$、$\mathrm{Cl–Cl}\ 243$、$\mathrm{C–Cl}\ 328$、$\mathrm{H–Cl}\ 431\ \mathrm{kJ\,mol^{-1}}$。（$\Delta_\mathrm{r}H$ 以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
断：一个 C–H 和一个 Cl–Cl：$413 + 243 = 656\ \mathrm{kJ\,mol^{-1}}$。成：一个 C–Cl 和一个 H–Cl：$328 + 431 = 759\ \mathrm{kJ\,mol^{-1}}$。
$$
\Delta_\mathrm{r}H \approx 656 - 759 = -103\ \mathrm{kJ\,mol^{-1}}.
$$
放热，正如自由基链机理中每一对夺氢/氯化步骤那样——这就是反应一经引发就能进行的原因。
:::
:::

::: exercise 判断贡献式 {level=2}
异氰酸 $\mathrm{HNCO}$ 的两种路易斯结构可写成 $\mathrm{H{-}N{=}C{=}O}$ 和 $\mathrm{H{-}N{-}C{\equiv}O}$（以孤对电子补全八隅体）。计算每种结构中 N、C 和 O 的形式电荷，指出主导贡献式。
::: solution
在 $\mathrm{H{-}N{=}C{=}O}$ 中：氮有三个键（一个连 H，一个双键连 C）和一对孤对电子：$FC = 5 - 2 - 3 = 0$；碳有四个键：$4 - 0 - 4 = 0$；氧有两个键和两对孤对电子：$6 - 4 - 2 = 0$。所有形式电荷皆为零。在 $\mathrm{H{-}N{-}C{\equiv}O}$ 中：氮有两个单键和两对孤对电子：$5 - 4 - 2 = -1$；碳有四个键：$0$；氧有一个三键和一对孤对电子：$6 - 2 - 3 = +1$。因此第二个结构分离了电荷，把正形式电荷放在电负性最大的原子上。形式电荷全为零的第一个结构主导——事实上真实分子（暂不论异氰酸/雷酸化学）只要原子允许就保持累积双键。本题要点：形式电荷在两个都满足八隅体规则的结构之间做出裁决。
:::
:::

::: exercise 碳酸氢根中的形式电荷 {level=2}
指定碳酸氢根离子 $\mathrm{HCO_3^-}$ 主导路易斯结构中的形式电荷，并说明是哪几个氧原子共享电荷。
::: solution
$4 + 1 + 3\times 6 + 1 = 24$ 个价电子。骨架：C 居中，与三个 O 成键，其中一个 O 连 H。取一个 C=O、两个 C–O 和一个 O–H：形式电荷为 C $4-0-4 = 0$；羰基 O $0$；连 H 的氧 $6-4-2 = 0$；剩下的单键 O $6-6-1 = -1$。总和 $-1$ ✓。$-1$ 由两个*不*连氢的氧共享——双键在 C=O 与另一个 C–O 之间共振——这就是为什么碳酸的两步解离得到的离子都有两个等价的 C–O 键、质子坐在氧上。
:::
:::

::: exercise 硫代硫酸根的全面分析 {level=3}
硫代硫酸根 $\mathrm{S_2O_3^{2-}}$ 的骨架为 $\mathrm{O_3S{-}S}$（中心硫与三个氧以及端基硫成键）。画出带形式电荷的主导路易斯结构，并解释教科书上"两个硫的氧化态分别为 $-2$ 和 $+6$、而平均值为 $+2$"这句话。
::: solution
价电子：$2\times 6 + 3\times 6 + 2 = 32$。一个好的低形式电荷结构：中心 S 有两个 S=O 双键、一个 S–O 单键和一个 S–S 单键（六个键，中心 S 无孤对电子）；端基 S 有三对孤对电子。形式电荷：中心 S $6 - 0 - 6 = 0$；双键 O 为 $0$；单键 O $6 - 6 - 1 = -1$；端基 S $6 - 6 - 1 = -1$。总和 $-2$ ✓，两个负形式电荷落在端基 S 和氧上——与硫代硫酸根通过端基硫结合金属一致（它是软的、类硫化物的那一端）。至于氧化态，按电负性分配成键电子：每个 O 取 $-2$（共 $-6$），S–S 键均分，所以端基 S 类 $-2$（硫化物），中心 S 带 $+6$（类硫酸根）：$(-2) + (+6) + 3(-2) = -2$ ✓。平均值 $+2$ 正是碘量滴定（生成连四硫酸根）所测得的——两个硫在光谱和化学上截然不同，这道题在一个离子里道尽了形式电荷、氧化态与现实之间的全部区别。
:::
:::

::: exercise 键焓与生成焓的比较 {level=3 check="-126"}
对加氢反应 $\mathrm{H_2C{=}CH_2(g) + H_2(g) \to H_3C{-}CH_3(g)}$：(a) 用平均键焓估算 $\Delta_\mathrm{r}H$（$\mathrm{C{=}C}\ 612$、$\mathrm{H–H}\ 436$、$\mathrm{C–C}\ 348$、$\mathrm{C–H}\ 413\ \mathrm{kJ\,mol^{-1}}$）；(b) 由 $\Delta_\mathrm{f}H^\circ(\mathrm{C_2H_4}) = +52.3$ 和 $\Delta_\mathrm{f}H^\circ(\mathrm{C_2H_6}) = -84.7\ \mathrm{kJ\,mol^{-1}}$ 计算精确值；(c) 解释偏差的符号与大小。（(a) 的答案以 $\mathrm{kJ\,mol^{-1}}$ 输入。）
::: solution
(a) 断 $612 + 436 = 1048$；成 $348 + 2\times 413 = 1174$；$\Delta_\mathrm{r}H \approx -126\ \mathrm{kJ\,mol^{-1}}$。(b) $\Delta_\mathrm{r}H = -84.7 - 52.3 - 0 = -137\ \mathrm{kJ\,mol^{-1}}$。(c) 估算偏小 $11\ \mathrm{kJ\,mol^{-1}}$（$8\ \%$）。原因内建于方法之中：表列的 $\mathrm{C{=}C}$ 平均焓是许多烯烃上的平均，而 $\mathrm{C–H}$ 平均值由 $sp^3$ 化合物主导，所以用平均值替换真实的烯烃 $\pi$ 键（当产物的两个新 C–H 键在乙烷的特定环境中形成后，它比平均值所暗示的更弱）会使相消略微不足。这个偏差是警告，不是失败：平均键焓把加氢反应算到约 $10\ \%$ 以内；而当反应的答案要紧时，生成焓——包含一切环境细节——才是终审法院。
:::
