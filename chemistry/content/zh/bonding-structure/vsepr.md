$\mathrm{CH_4}$ 的路易斯结构是平面画出的：中间一个碳，四个氢在十字的四个端点上，每条线上两个点。分子不是平面的。甲烷是一个四面体，氨是一个浅金字塔，水是一个键角为 $104.5^\circ$ 的弯曲分子，六氟化硫是一个六个氟全等价的八面体。这些形状早在任何理论解释它们之前就已经被*测定*了——由转动光谱（从转动惯量确定键角），以及由气相电子衍射和 X 射线衍射（直接拍摄原子骨架）——而它们给路易斯的平面图像出的难题是尖锐的：如果甲烷的四个键在纸面上真的彼此成 $90^\circ$ 画出，为什么它们实际上都指向正四面体的顶角，为什么 $\mathrm{CH_2Cl_2}$ 是单一物质，而不是平面四方形碳所应给出的两种异构体？价层电子对互斥理论（VSEPR）用一个几乎简单得令人难堪的思想作答：原子价层中的电子对彼此排斥，并尽可能彼此远离。仅凭这一句话和一次电子计数，就得出主族化学中极大一部分的形状。

## 电子区域

VSEPR 不数键；它数*电子密度区域*。

::: definition 电子区域 {#def-electron-domain}
**电子区域**是原子周围价电子（一对或多对）很可能出现的一个区域。中心原子周围有两类：**成键区域**，每个成键相邻原子一个，无论该键是单键、双键还是三键；以及**非键区域**，每对孤对电子一个。$\mathrm{NO_2}$ 中那样的单个未成对电子也计为一个区域。**电子区域几何**是所有区域的排布；**分子形状**是*仅原子*（即原子核）的排布，孤对电子不可见。
:::

双键只计为一个区域的原因是，它的电子无论多少，都被限制在两个核之间的走廊里——一个 $\pi$ 键在那条走廊的上下增加密度，但并不创造一个新的、密度必须被推离中心原子的方向。几何结构响应的是*电子密度的方向*，而不是多少；多少只作为修正进入，因为一个较肥的区域比一个较瘦的区域排斥得稍强一些。

::: proposition VSEPR 的公设 {#prop-vsepr-postulates}
1. 中心原子周围的电子区域采取**使其相互分离最大化**的排布，使其静电排斥最小化。
2. 这些排斥并不全相等。在同一角度下，**孤对–孤对（lp–lp）> 孤对–成键对（lp–bp）> 成键对–成键对（bp–bp）**。成键对被两个原子核拉住、收进一条细长的通道；孤对只受一个原子核吸引，因而伸展得更开，占据更大的立体角，把邻居挤进去。
3. **多重键比单键排斥得稍强**，因为它的区域里含有更多电子密度。
该理论是经验的、定性的：它从结构数据概括而来，预测的是键角的*趋势*，而不是精确到度的键角。
:::

公设 2 是主力。它解释了为什么看不见的孤对电子的单纯存在就会改变看得见的键之间的角度：孤对是比成键对更肥、更贪的区域，键之间幸存下来的角度，正是孤对多占空间之后剩下的角度。

## 几何阶梯

有**两个区域**时，最宽的分离是一条直线：**直线形，$180^\circ$**——$\mathrm{BeCl_2}$ 蒸气，以及 $\mathrm{CO_2}$ 的每个碳。有**三个**时，区域共面、彼此 $120^\circ$：**平面三角形**——$\mathrm{BF_3}$，$\mathrm{CO_3^{2-}}$。有**四个**时，答案不是正方形（相邻区域 $90^\circ$）而是**四面体**，其 $109.47^\circ$ 的角度是三维空间里自然所能找到的最佳折中——$\mathrm{CH_4}$，$\mathrm{NH_4^{+}}$，$\mathrm{SO_4^{2-}}$。这里已经藏着一个关于理论的教训：它从一开始就是三维的，它预测的形状不是纸面上的形状。

五个区域给出**三角双锥形**，而这种排布值得小心，因为它的位置*并不等价*。三个**赤道**区域构成一个三角形（彼此 $120^\circ$，与每个轴向区域成 $90^\circ$）；两个**轴向**区域位于平面的上下（彼此 $180^\circ$）。数一数每个位置在 $90^\circ$ 处有多少近邻：轴向区域有**三个**（三个赤道区域），赤道区域只有**两个**（两个轴向区域）。由于 $90^\circ$ 排斥支配能量——排斥在最小角度处最强——屋里最宽敞的座位是赤道座位，而**孤对电子取走它们**。这一个计数论证就生成了整个 $\mathrm{AX_5E_{\mathit{n}}}$ 家族，[[#ex-ax5e-series]]将会展示。

六个区域给出**八面体形**：六个位置全等价，所有角度为 $90^\circ$ 或 $180^\circ$。有一个孤对时每个选择都一样；有两个时，第二个孤对走向第一个的**反位**（trans，正对面），因为*顺位*（cis）的一对孤对将彼此成 $90^\circ$——在公设 2 之下这是最坏的排布。因此 $\mathrm{XeF_4}$ 是平面四方形的，而不是随机放置所会给出的变形八面体。

| 区域数 | 基本排布 | 理想角度 | 家族 → 分子形状 | 实例 |
|---|---|---|---|---|
| 2 | 直线形 | $180^\circ$ | $\mathrm{AX_2}$ → 直线形 | $\mathrm{CO_2}$，$\mathrm{BeCl_2(g)}$ |
| 3 | 平面三角形 | $120^\circ$ | $\mathrm{AX_3}$ → 平面三角形；$\mathrm{AX_2E}$ → V 形 | $\mathrm{BF_3}$，$\mathrm{CO_3^{2-}}$；$\mathrm{SO_2}$ |
| 4 | 四面体形 | $109.47^\circ$ | $\mathrm{AX_4}$ → 四面体形；$\mathrm{AX_3E}$ → 三角锥形；$\mathrm{AX_2E_2}$ → V 形 | $\mathrm{CH_4}$；$\mathrm{NH_3}$；$\mathrm{H_2O}$ |
| 5 | 三角双锥形 | $90^\circ$，$120^\circ$，$180^\circ$ | $\mathrm{AX_5}$ → 三角双锥形；$\mathrm{AX_4E}$ → 变形四面体（锯马形）；$\mathrm{AX_3E_2}$ → T 形；$\mathrm{AX_2E_3}$ → 直线形 | $\mathrm{PF_5}$；$\mathrm{SF_4}$；$\mathrm{ClF_3}$；$\mathrm{XeF_2}$ |
| 6 | 八面体形 | $90^\circ$，$180^\circ$ | $\mathrm{AX_6}$ → 八面体形；$\mathrm{AX_5E}$ → 四方锥形；$\mathrm{AX_4E_2}$ → 平面四方形 | $\mathrm{SF_6}$；$\mathrm{BrF_5}$；$\mathrm{XeF_4}$ |

表中 $\mathrm{A}$ 是中心原子，$\mathrm{X}$ 是成键相邻原子，$\mathrm{E}$ 是孤对电子。把它读作两步预测：区域*数目*确定基本排布，$\mathrm{E}$ 的数目确定孤对让出哪些座位。

::: algorithm 用 VSEPR 预测分子形状 {#alg-vsepr}
**输入：**一个主族分子或离子的化学式。**输出：**它的形状，以及它的键角将如何偏离理想值的预测。
1. 数出价电子并画出路易斯结构（[[bonding-structure/covalent-lewis]]），把中心原子选为除氢之外电负性最小的元素。
2. 数中心原子上的电子区域：每个成键相邻原子一个（单键、双键或三键——对计数没有区别），加上每对孤对电子一个。
3. 选择基本排布：2 → 直线形，3 → 平面三角形，4 → 四面体形，5 → 三角双锥形，6 → 八面体形。
4. 放置孤对：三角双锥形中它们取**赤道**位；八面体中第二个孤对取第一个的**反位**；其余排布中所有位置等价。
5. 仅由*原子*的位置命名分子形状。
6. 预测偏差：孤对压缩它所触及的键之间的角度；多重键轻微压缩其邻居；电负性取代基把成键区域拉离中心，使角度得以收小。
:::

::: example 键角阶梯：$\mathrm{CH_4}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$ {#ex-angle-ladder}
三个分子在第二周期中心原子上都有四个电子区域，但它们的键角是 $109.47^\circ$、$107^\circ$ 和 $104.5^\circ$（标准结构数据）。解释这个阶梯。
::: solution
$\mathrm{CH_4}$ 中的碳带来 4 个价电子并形成 4 个键：四个成键区域，没有孤对，一个完美的四面体，每个 $\mathrm{H–C–H}$ 角都等于理想的 $109.47^\circ$。氮带来 5 个：三个 $\mathrm{N–H}$ 键和一对孤对，所以电子几何仍是四面体形，但*分子*形状是三角锥形。孤对是比任何 $\mathrm{N–H}$ 键更肥的区域（公设 2），把三个键压在一起，$\mathrm{H–N–H}$ 角从 $109.47^\circ$ 降到约 $107^\circ$。氧带来 6 个：两个键和*两对*孤对。现在每个键都被两个 lp–bp 排斥挤压，而两对孤对本身也在争抢空间（最强的排斥，lp–lp），所以角度进一步降到 $104.5^\circ$。同一个四面体电子几何由此产生三种不同的形状和三个不同的角度——看不见的孤对书写着看得见的几何。（测得的偶极矩讲述同一个故事：$\mathrm{CH_4}$ 非极性，$\mathrm{NH_3}$ 的 $\mu = 1.47\ \mathrm{D}$，$\mathrm{H_2O}$ 的 $\mu = 1.85\ \mathrm{D}$；一个 $180^\circ$ 的平面 $\mathrm{H_2O}$ 将完全没有偶极。）
:::
:::

::: example $\mathrm{AX_5E_{\mathit{n}}}$ 系列：$\mathrm{SF_4}$、$\mathrm{ClF_3}$、$\mathrm{XeF_2}$ {#ex-ax5e-series}
预测 $\mathrm{SF_4}$、$\mathrm{ClF_3}$ 和 $\mathrm{XeF_2}$ 的形状，并说出孤对坐在哪里。
::: solution
数区域。$\mathrm{SF_4}$ 中的硫：6 个价电子，4 个用于 $\mathrm{S–F}$ 键，剩一对孤对——5 个区域。$\mathrm{ClF_3}$ 中的氯：7 个价电子，3 个键，2 对孤对——5 个区域。$\mathrm{XeF_2}$ 中的氙：8 个价电子，2 个键，3 对孤对——5 个区域。因此三者都从三角双锥形出发，三个问题都归结为*孤对取哪些座位*。放在**轴向**的孤对将遭受三个 $90^\circ$ 排斥（与每个赤道区域）；放在**赤道**，只有两个（与两个轴向区域）。赤道更宽敞，所以每个孤对都取一个赤道座位：

- $\mathrm{SF_4}$，$\mathrm{AX_4E}$：一个赤道座位空出，留下四个键（两个轴向，两个赤道）——**变形四面体（锯马形）**。孤对把轴向键折开（实测 $\mathrm{F_{ax}–S–F_{ax}} \approx 173^\circ$）并挤压赤道那一对（$\mathrm{F_{eq}–S–F_{eq}} \approx 102^\circ$，标准衍射数据）。
- $\mathrm{ClF_3}$，$\mathrm{AX_3E_2}$：两个赤道孤对在三角形中彼此相邻，留下三个键——**T 形**，$\mathrm{F–Cl–F} \approx 87.5^\circ$，lp–lp 排斥把键压到 $90^\circ$ 以下。
- $\mathrm{XeF_2}$，$\mathrm{AX_2E_3}$：整个赤道三角形都是孤对；两个氟占据轴向位——**直线形**，$\mathrm{F–Xe–F} = 180^\circ$，非极性（$\mu = 0$）。

三种氙/卤素化合物，一种电子计数，三种形状——而这些形状正是衍射所发现的。
:::
:::

::: example 八面体系列：$\mathrm{BrF_5}$ 和 $\mathrm{SF_6}$ {#ex-brf5-sf6}
预测 $\mathrm{SF_6}$ 和 $\mathrm{BrF_5}$ 的形状及其偶极矩。
::: solution
$\mathrm{SF_6}$ 中的硫：6 个键，没有孤对，6 个区域——**八面体形**，六个氟全等价，所有角度恰为 $90^\circ$。六个键偶极由对称性抵消（每个键都有一个大小相等、方向相反的伙伴），所以 $\mu = 0$；$\mathrm{SF_6}$ 实际上如此不活泼，以至于它的惰性本身就是氟把硫完全包裹起来的结果。$\mathrm{BrF_5}$ 中的溴：7 个价电子，5 个键，1 对孤对——八面体电子几何，**四方锥形**分子形状。只有一对孤对时六个座位全等价，所以无从选择，但孤对仍然把五个氟压下来：每个 $\mathrm{F–Br–F}$ 角都略小于 $90^\circ$（约 $85^\circ$，标准结构数据），分子是极性的。$\mathrm{SF_6}/\mathrm{BrF_5}$ 这一对把一般道理讲得很干净：移走一个配体、加上一对孤对，电子几何保持不变，但位置的等价性和偶极的抵消同时被破坏。
:::
:::

::: quiz
在 $\mathrm{SF_4}$（5 个电子区域，一对孤对）中，孤对占据三角双锥的赤道位而不是轴向位，因为
- [x] 赤道区域只有两个 $90^\circ$ 的近邻，而轴向区域会有三个——孤对取更宽敞的座位。
- [ ] 赤道座位总是更靠近中心原子，而孤对被它吸引。
- [ ] 轴向座位已经被相邻分子的硫孤对填满了。
- [ ] 孤对必须总是位于电负性最大的原子所在的平面内。
::: solution
排斥由最近的邻居支配，也就是 $90^\circ$ 处的那些。轴向区域在 $90^\circ$ 遇到三个赤道区域；赤道区域只遇到两个轴向的。孤对作为最肥的区域（[[#prop-vsepr-postulates]]的公设 2），通过取只有两次 $90^\circ$ 相遇的赤道座位使其代价最小。其余四个键构成[[#ex-ax5e-series]]中的锯马形。
:::

## 形状与偶极矩：把键当作矢量相加

键偶极是一个矢量，而分子的偶极矩是它们的矢量和——所以形状把"它极性吗？"这个问题变成了算术。

::: definition 分子偶极矩 {#def-molecular-dipole}
分子的**偶极矩** $\mu$ 是其所有电荷分离的合成矢量的大小，以德拜计量（$1\ \mathrm{D} = 3.336\times10^{-30}\ \mathrm{C\,m}$）。在很好的近似下它是**键偶极的矢量和**，每个键偶极沿其键指向电负性较大的原子。当对称性使总和为零时分子是非极性的（$\mu = 0$），无论各个键本身如何；因此测得的偶极矩是关于形状的直接证据。
:::

::: proof 两个键偶极的合成 {#proof-dipole-resultant}
设两个相同的键，每个偶极为 $\mu_\mathrm{b}$，以角度 $\theta$ 相交。取角平分线为 $x$ 轴；两个键与它成 $\pm\theta/2$ 角。垂直于平分线的分量等大反向而抵消；沿它的分量相加：
$$
\mu_\mathrm{res} = 2\,\mu_\mathrm{b}\cos\frac{\theta}{2}.
$$
三种解读。(i) 在 $\theta = 180^\circ$，$\cos 90^\circ = 0$ 且 $\mu_\mathrm{res} = 0$：两个指向相反方向的相同键恰好抵消——这就是为什么 $\mathrm{CO_2}$（$\mu = 0$）必须是直线形而不是弯曲的。(ii) 在 $\theta = 104.5^\circ$、$\mathrm{O–H}$ 键偶极 $\mu_\mathrm{b} = 1.51\ \mathrm{D}$ 时，$\mu_\mathrm{res} = 2 \times 1.51 \times \cos 52.25^\circ = 1.85\ \mathrm{D}$——水的实测偶极矩，精确到三位数字。(iii) 在近直线处写 $\theta = 180^\circ - \delta$；则 $\mu_\mathrm{res} = 2\mu_\mathrm{b}\sin(\delta/2) \approx \mu_\mathrm{b}\,\delta$（$\delta$ 以弧度计），所以偶极随弯曲*线性*开启：一个偏离直线 $10^\circ$ 的分子已经带有约六分之一个键偶极。因此极性度量的是*对直线形的偏离*，而不是弯曲这一事实本身：近直线的分子弱极性，而测得接近零的 $\mu$ 相应地是直线形的强证据。

对于对称排布，总和由对称性为零，而一个代表性计算覆盖一个家族。四个等长矢量指向四面体的四个顶角，其和为零：取 $z$ 分量，每个键与任一选定轴成同一角度 $\alpha$，而四重排布向上的密度与向下一样多；形式地说，四个由四面体群的对称操作相互关联的矢量的合成必须在这些操作下不变，而具有该性质的唯一矢量是 $\mathbf{0}$。因此 $\mathrm{CH_4}$、$\mathrm{CCl_4}$、$\mathrm{SO_4^{2-}}$：非极性。同样的对称论证也消掉了 $\mathrm{BF_3}$（平面内 $120^\circ$ 的三个矢量）、$\mathrm{PF_5}$、$\mathrm{SF_6}$、$\mathrm{XeF_4}$（四个面内键成 $90^\circ$ 加上两对反向的孤对）——而且，关键的是，一旦配体不再全都相同，它就失效了，[[#ex-dipole-vectors]]将会展示。
:::

::: example 它有极性吗？$\mathrm{BF_3}$ 和 $\mathrm{CH_2Cl_2}$ {#ex-dipole-vectors}
判断 $\mathrm{BF_3}$ 和 $\mathrm{CH_2Cl_2}$ 是否极性，对后者用键偶极 $\mu(\mathrm{C–Cl}) = 1.6\ \mathrm{D}$ 和 $\mu(\mathrm{C–H}) = 0.4\ \mathrm{D}$、在理想四面体角下由矢量相加估算。
::: solution
$\mathrm{BF_3}$：三个相同的 $\mathrm{B–F}$ 键在平面内成 $120^\circ$。把一个放在 $x$ 轴上：$x$ 分量为 $\mu(1 + \cos 120^\circ + \cos 240^\circ) = \mu(1 - \tfrac12 - \tfrac12) = 0$，$y$ 分量为 $\mu(0 + \sin 120^\circ + \sin 240^\circ) = 0$。总和恰为零：$\mathrm{BF_3}$ 是**非极性**的，事实上它的实测偶极矩是 $0\ \mathrm{D}$——这是它确实为平面三角形的证据，因为锥形的 $\mathrm{BF_3}$ 将是极性的。

$\mathrm{CH_2Cl_2}$：四个键并非全同，所以没有任何对称性能挽救这个和，分子是**极性**的。用两个占主导的、处于四面体角的 $\mathrm{C–Cl}$ 键，结合[[#proof-dipole-resultant]]估算：
$$
\mu_\mathrm{res} \approx 2 \times 1.6\ \mathrm{D} \times \cos 54.75^\circ = 1.85\ \mathrm{D}.
$$
实测值是 $1.60\ \mathrm{D}$（标准表列数据）。较小的 $\mathrm{C–H}$ 键偶极和真实的角度（$\mathrm{Cl–C–Cl}$ 角张开超过 $109.5^\circ$，以 $\mathrm{H–C–H}$ 角为代价）解释了差异的大部分——键偶极相加是一个可转移性假设，精确到零点几德拜，不是一个恒等式。*真正*精确的比较是对称性论证：$\mathrm{CCl_4}$ 有相同的键而 $\mu = 0$；用氢取代两个氯破坏抵消，得到 $1.60\ \mathrm{D}$。决定极性的是形状，不是键的数目。
:::
:::

:::

::: warning VSEPR 是地图，不是疆域 {#warn-vsepr-limits}
需要记住的三条局限。**第一，键角是趋势，不是测量。**VSEPR 说"低于 $109.5^\circ$，孤对越多越低"；它不是从第一性原理给出 $104.5^\circ$。**第二，在区域不定域或不占主导的地方模型失效。**$\mathrm{H_2S}$ 和水一样有两对孤对和两个键，但它的 $\mathrm{H–S–H}$ 角是 $92.1^\circ$——几乎不怎么弯曲——因为硫与氢的键使用杂化混合很少的轨道，角度由轨道几何而不是区域排斥决定；真正的解释属于[[bonding-structure/valence-bond]]。许多较重的 p 区化合物和大多数过渡金属化合物都这样表现或更糟，因为它们的形状由方向性的金属–配体键支配，而区域计数看不见这些。**第三，"孤对压缩"是一条经验法则，不是定律。**$\mathrm{NF_3}$ 和 $\mathrm{NH_3}$ 一样有一对孤对，但角度只有约 $102^\circ$ 对 $107^\circ$：电负性的氟把成键区域拉向自己，使它们在中心原子附近变薄，于是孤对的压力更加占上风并把键压合。取代基的电负性也移动角度，而 VSEPR 只告诉你要往哪个方向看。
:::

::: history
VSEPR 预测的形状在其祖先出现时正被测定。1929 年维尔（Wierl）的第一批气体电子衍射照片直接揭示了 $\mathrm{CO_2}$ 是直线形而 $\mathrm{CCl_4}$ 是四面体形，整个 1930 年代，衍射和转动光谱填出了一张不断增长的、路易斯结构无法直接读出的键角表。1940 年西奇威克（Sidgwick）与鲍威尔（Powell）扩展了西奇威克早期关于共价半径和键数目的思想，发表了对无机分子中轴向与赤道键合的分析，其中正是用[[#ex-ax5e-series]]的 $90^\circ$ 计数论证把孤对放进三角双锥。1957 年吉尔斯皮（Gillespie）与尼霍尔姆（Nyholm）把整个关联改写成价层电子对排斥的理论，发表在《季度评论》（Quarterly Reviews）上的一篇无机立体化学综述使该模型系统化并具有预测性；吉尔斯皮的著作《分子几何》（*Molecular Geometry*）在几年后出版，以价层电子对互斥之名把它带进了每一间课堂。到 1960 年代，该模型已是标准装备：数电子对成了一种方法，而不是一种记忆术。
:::

## 后续内容

VSEPR 告诉你角度*是*什么；它不能告诉你为什么四个在 $109.47^\circ$ 上等价的方位*根本存在*。这个问题——键为什么指向它们指向的地方——由[[bonding-structure/valence-bond]]中的杂化与价键理论回答，并由[[bonding-structure/molecular-orbitals]]更深刻地回答。形状也是进入宏观性质的入场券：这里算出的偶极矩成为使液体凝聚的力，见[[bonding-structure/intermolecular-forces]]；分子的形状作为晶体的堆积再次出现，见[[bonding-structure/solid-structures]]。最后，形状不仅被预测，而且被*测量*：分子振动的数目与活性由其对称性决定，[[spectroscopy/vibrational-spectroscopy]]将有发展——红外光谱是 VSEPR 形状真实存在的最锐利的独立确证之一。

::: summary
- 电子区域——每个成键相邻原子一个（单键或多键）加上每对孤对电子一个——相互排斥并采取最大分离的排布：直线形、平面三角形、四面体形、三角双锥形、八面体形。
- 分子形状只命名原子的位置；孤对不可见但并非不活动。
- 孤对是比成键对更肥的区域（排斥 lp–lp > lp–bp > bp–bp），所以它们压缩键角：从 $\mathrm{CH_4}$ 到 $\mathrm{NH_3}$ 再到 $\mathrm{H_2O}$ 为 $109.47^\circ \to 107^\circ \to 104.5^\circ$。
- 三角双锥中孤对取赤道位（两个 $90^\circ$ 近邻而不是三个）；八面体中第二个孤对取反位——这是锯马形、T 形、直线形、四方锥形和平面四方形背后的座位计数。
- 偶极矩是矢量和：两个键时 $\mu_\mathrm{res} = 2\mu_\mathrm{b}\cos(\theta/2)$，对称排布（$\mathrm{CO_2}$、$\mathrm{BF_3}$、$\mathrm{CCl_4}$、$\mathrm{SF_6}$）时恰为零——测得的 $\mu$ 是关于形状的证据。
- VSEPR 是定性的、经验的：它预测趋势，在重 p 区化合物（$\mathrm{H_2S}$，$92.1^\circ$）和过渡金属配合物面前吃力，并且既受孤对也受取代基电负性的驱动。
:::

## 练习

::: exercise 命名形状 {level=1}
预测下列每个物种的分子形状：(a) $\mathrm{XeF_4}$；(b) $\mathrm{SO_2}$；(c) $\mathrm{ICl_4^{-}}$；(d) $\mathrm{NO_3^{-}}$。
::: solution
(a) Xe：8 个价电子，4 个键，2 对孤对——6 个区域，八面体电子几何，孤对反位：**平面四方形**。(b) S：6 个价电子；两个 $\mathrm{S–O}$ 键（路易斯图像中一个是双键，无论哪种都是同一个区域）和一对孤对——3 个区域，平面三角形电子几何：**V 形**（角度接近 $120^\circ$；实测约 $119^\circ$）。(c) I：7 个价电子 $+\,1$ 个来自电荷 $= 8$；4 个键，2 对孤对——6 个区域，孤对反位：**平面四方形**，与 $\mathrm{XeF_4}$ 相同。(d) N：5 个价电子 $+\,1 = 6$；三个成键相邻原子，没有孤对（多余的电子密度离域在氧上）——3 个区域：**平面三角形**。
:::
:::

::: exercise 三角双锥的角度 {level=1 check="90"}
$\mathrm{PF_5}$（理想化）中*最小*的键角是多少？（以度输入角度。）
::: solution
三角双锥有赤道–赤道角 $120^\circ$、轴向–赤道角 $90^\circ$ 和轴向–轴向角 $180^\circ$。最小的是 $\boxed{90^\circ}$——而正是这些 $90^\circ$ 的相遇，使孤对通过取赤道位来避免。
:::
:::

::: exercise 数区域 {level=1 check="6"}
$\mathrm{XeF_4}$ 的中心原子带有多少个电子区域？（输入数目。）
::: solution
氙：8 个价电子；4 个共享于 $\mathrm{Xe–F}$ 键，4 个留作两对孤对。四个成键相邻原子 $+\,2$ 对孤对 $= \boxed{6}$ 个区域——八面体电子几何，平面四方形形状。
:::
:::

::: exercise 键角阶梯为什么弯曲 {level=2}
用 VSEPR 的公设解释：(a) 为什么 $\mathrm{H_2O}$（$104.5^\circ$）比 $\mathrm{NH_3}$（$107^\circ$）压缩得更多，尽管两者都有四面体电子几何；(b) 为什么 $\mathrm{NF_3}$（约 $102^\circ$）*小于* $\mathrm{NH_3}$，尽管氟比氢大得多。
::: solution
(a) 两者都有四个区域，但 $\mathrm{NH_3}$ 有一对孤对而 $\mathrm{H_2O}$ 有两对。每个键角都被触及它的孤对挤压，而 lp–lp 排斥——最强的一种——迫使水的两对孤对索取额外空间，于是键被推得更近：两对孤对比一对压缩得更多。(b) 相关的变量不是大小而是电负性。氟把 $\mathrm{N–F}$ 成键区域拉向自己；在氮附近那些区域变薄、彼此弱排斥，而只被氮抓住的孤对保持肥厚而靠近中心。于是 lp–bp 压力压倒 bp–bp 压力，把 $\mathrm{F–N–F}$ 角压到 $\mathrm{H–N–H}$ 值以下。VSEPR 的公设包含两种效应：区域的*电荷*与区域的*数目*同样重要。
:::
:::

::: exercise 水的偶极矩，定量地 {level=2 check="1.85"}
取 $\mathrm{O–H}$ 键偶极为 $1.51\ \mathrm{D}$，键角为 $104.5^\circ$。计算水的偶极矩。（以德拜输入。）
::: solution
两个相等的键偶极成角 $\theta$ 给出 $\mu_\mathrm{res} = 2\mu_\mathrm{b}\cos(\theta/2)$（[[#proof-dipole-resultant]]）：
$$
\mu_\mathrm{res} = 2 \times 1.51 \times \cos 52.25^\circ = 2 \times 1.51 \times 0.6122 = 1.85\ \mathrm{D},
$$
与实测的 $1.85\ \mathrm{D}$ 相符。孤对贡献于真实的电荷分布，但键矢量图像已经命中答案。
:::
:::

::: exercise 锯马而非正方：$\mathrm{AX_4E}$ 家族的极性 {level=2}
$\mathrm{SF_4}$ 的 $\mu = 0.63\ \mathrm{D}$；$\mathrm{XeF_4}$ 的 $\mu = 0$。从它们的形状解释两者，并说明为什么锯马形不能被"四个氟的平面四方形排布加上'上方'的孤对"所取代。
::: solution
$\mathrm{XeF_4}$ 是平面四方形、两对孤对反位：四个键偶极位于平面内成 $90^\circ$ 并成对抵消，而（不可见的）孤对贡献也抵消，因为它们指向相反方向——$\mu = 0$。$\mathrm{SF_4}$ 的锯马形没有这样的抵消：两个轴向 $\mathrm{S–F}$ 偶极朝孤对的一侧弯在一起，两个赤道偶极指向另一侧，留下一个沿 $C_{2v}$ 轴的合成——虽小但非零的 $0.63\ \mathrm{D}$。孤对在平面上方的平面四方形 $\mathrm{SF_4}$ 并*不是* VSEPR 给出的，因为第五个区域将同时与四个邻居成 $90^\circ$；带一个赤道孤对的三角双锥母体只有两个这样的接触，观察到的几何（和偶极）都由那种排布得出。
:::
:::

::: exercise 三种氙的氟化物 {level=3}
预测 $\mathrm{XeF_2}$、$\mathrm{XeF_4}$ 和 $\mathrm{XeF_6}$ 中每一种的形状、理想化角度和极性，并为每一对孤对的位置给出理由。（$\mathrm{XeF_6}$ 最好描述为一个流变的变形八面体——先说出区域计数在变形之前预测什么。）
::: solution
$\mathrm{XeF_2}$：2 个键 $+\,3$ 对孤对 $= 5$ 个区域，三角双锥；三对孤对全在赤道（若在轴向，每对将遭受三个 $90^\circ$ 接触，而赤道只有两个）——**直线形**，$180^\circ$，非极性：两个键偶极共线反向。$\mathrm{XeF_4}$：4 个键 $+\,2$ 对孤对 $= 6$ 个区域，八面体；孤对取反位（*顺位*的一对将彼此成 $90^\circ$——可得到的最坏的单个 lp–lp 接触）——**平面四方形**，$90^\circ$，由四个面内键的成对抵消而非极性。$\mathrm{XeF_6}$：6 个键 $+\,1$ 对孤对 $= 7$ 个区域；简单的区域计数没有干净的答案，实验给出一个流变的变形八面体——诚实的 VSEPR 陈述是：第七个立体化学活性的孤对使理想八面体不稳定，而这正是[[#warn-vsepr-limits]]那一类情形——模型标出自己有效性的边界，而不是一个需要辩护的失败。整个系列的模式就是教训：区域计数完美预测了三个中的两个，并把第三个标记为麻烦。
:::

::: exercise 从偶极矩反推角度 {level=3 check="107"}
$\mathrm{NH_3}$ 的偶极矩是 $1.47\ \mathrm{D}$，$\mathrm{N–H}$ 键偶极是 $1.34\ \mathrm{D}$。假设 $C_{3v}$ 对称性（三个键等价，由三重轴相关联），计算 $\mathrm{H–N–H}$ 键角。（以度输入，取整到最接近的度。）
::: solution
设每个键与三重轴成角 $\alpha$。垂直分量由三重对称性抵消，所以 $\mu = 3\mu_\mathrm{b}\cos\alpha$，得 $\cos\alpha = 1.47/(3 \times 1.34) = 0.3659$，$\alpha = 68.5^\circ$。两个与轴成 $\alpha$、方位角相隔 $120^\circ$ 的键满足（球面三角，或取两个单位矢量的点积）
$$
\cos(\mathrm{HNH}) = \cos^2\alpha + \sin^2\alpha\cos 120^\circ = \tfrac{3}{2}\cos^2\alpha - \tfrac12 = \tfrac{3}{2}(0.1339) - 0.5 = -0.300,
$$
所以 $\mathrm{H–N–H} = \arccos(-0.300) = 107^\circ$——观测到的角度，仅从偶极测量恢复。（与[[#ex-angle-ladder]]对照：偶极和几何是同一个分子的两种读数。）
:::
