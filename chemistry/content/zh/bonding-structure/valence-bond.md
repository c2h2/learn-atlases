VSEPR 是一手漂亮的记账法：数电子对，形状就跟着出来。但它是记账法，不是力学。它说碳上的四个区域指向四面体的顶角，因为排斥把它们放在那里；它没有说*碳为什么根本就有四个等价的成键方向*，我们在[[general-chemistry-1/quantum-atom]]中遇到的轨道——一个球形的 2s 和三个两两垂直的 2p——数目既不是四，也不等价，若说有什么方向的话，它们彼此成 $90^\circ$。价键理论弥合了这个缺口。它的思想——海特勒（Heitler）和伦敦（London）在 1927 年首先对 $\mathrm{H_2}$ 阐明的——是：共价键是一对自旋配对的电子，被束缚在两个原子轨道的*重叠*之中；而它的绝招，主要归功于鲍林（Pauling）和斯拉特（Slater）在 1931 年的工作，是原子自己的轨道可以自由混合成*杂化轨道*，恰好指向键所指的地方。从关于轨道重叠的两行代数里，就得出四面体角本身——不是拟合出来的，而是推导出来的。

## 键即重叠

::: definition 价键 {#def-valence-bond}
当两个原子各以一个**自旋相反**的电子贡献给一个共享的空间区域时，就形成一个**价键**：每个原子的单占据轨道与另一个原子的重叠，两个电子——按泡利不相容原理对同一空间轨道的要求而配对——以反平行自旋落进这个合并的区域。键是*有方向性的*：两个轨道的重叠越强，就有越多电子密度坐在两核之间，两个正电芯就被越有效地相互屏蔽，键也就越短越强。因此两个 $2p$ 轨道之间的重叠取决于它们之间的夹角——正面相对时最大，$90^\circ$ 时为零——而这种角依赖正是分子几何的原材料。
:::

在海特勒与伦敦 1927 年对 $\mathrm{H_2}$ 的处理中，由*空间对称、自旋反平行*的组合构成的双电子波函数在两核之间放入额外的电子密度，使能量降到分离原子能量之下；自旋反对称的伙伴则把密度推出去，使能量升到其上。在他们的描述里，键是一种*交换*效应：一种只有反平行自旋才能获得的能量降低，这正是价饱和的原因——一个电子已配对的氢不再有配对能力，$\mathrm{H_2}$ 就是故事的结尾，而不是 $\mathrm{H_3}$。数字是诚实的：$\mathrm{H–H}$ 键长 $74\ \mathrm{pm}$、键能 $436\ \mathrm{kJ\,mol^{-1}}$（标准表列数据），而经过改进的海特勒-伦敦波函数把两者都复现出来。

现在来看那个迫使杂化登场的问题。基态碳是 $1s^2 2s^2 2p^2$：$2s$ 对已闭壳而惰性，只有**两个** $2p$ 电子未配对——所以一个照构造原理直读出来的碳应当形成*两个*键，成 $90^\circ$（两个 p 轨道之间的夹角），而不是四个。甲烷形成四个。而且四个 $\mathrm{C–H}$ 键是*等价的*——一个 $\mathrm{C–H}$ 键长，一个 $413\ \mathrm{kJ\,mol^{-1}}$ 的键能，一个 $109.47^\circ$ 的键角——而 $\mathrm{CH_4}$ 没有异构体，所以没有任何一个键暗地里不同于其他键。碳的轨道在成键之前必定有什么东西把它们重新铸造过。

## 杂化轨道

::: definition 杂化轨道 {#def-hybrid-orbitals}
**杂化轨道**是*单个*原子的价层轨道（$s$ 与 $p$）的归一化线性组合，选取为沿分子的成键方向指向。由于可用的是一个 $s$ 和三个 $p$ 轨道，标准集合为：
- $\mathbf{sp^3}$：四个杂化轨道，各含 $\tfrac14$ 的 $s$ 与 $\tfrac34$ 的 $p$ 成分，指向四面体的四个顶角（$109.47^\circ$）；
- $\mathbf{sp^2}$：三个杂化轨道（$\tfrac13$ $s$，$\tfrac23$ $p$）在同一平面内成 $120^\circ$，留下一个未杂化的 $p$ 垂直于该平面；
- $\mathbf{sp}$：两个杂化轨道（$\tfrac12$ $s$，$\tfrac12$ $p$）成 $180^\circ$，留下两个未杂化的 $p$ 轨道两两垂直。
混合是记账法，不是机器：杂化轨道张成与原集合*相同的四个轨道*，所以既不创造也不消灭电子，而把一个电子从 $2s$ 提升到 $2p$ 的"代价"（至多几百 $\mathrm{kJ\,mol^{-1}}$）被多形成的键成倍偿还。
:::

每个杂化轨道都强烈有方向性：它是一个球形 $s$ 波与一个双瓣 $p$ 波的*干涉*，在一侧相加、在另一侧相消，于是一侧的瓣长得肥硕，对面的瓣缩成一个残桩——一个恰好适合与邻居正面重叠的瓣。

::: proof 由正交性得出四面体角 {#proof-tetrahedral-angle}
取四个归一化杂化轨道 $\mathrm{h_i} = \tfrac12(\mathrm{s} + \sqrt{3}\,\hat{p}_i)$，其中 $\mathrm{s}$ 是（归一化的）$s$ 轨道，$\hat{p}_i$ 是沿单位矢量 $\mathbf{u}_i$ 指向的归一化 $p$ 轨道。每个杂化轨道都是归一化的，因为 $\langle \mathrm{s}|\mathrm{s}\rangle = 1$，$\langle \hat p_i | \hat p_i \rangle = 1$ 且 $\langle \mathrm{s}|\hat p_i\rangle = 0$：
$$
\langle \mathrm{h_i}|\mathrm{h_i}\rangle = \tfrac14\left(1 + 3\right) = 1 .
$$
现在要求两个不同的杂化轨道**正交**——它们是同一个原子的轨道，而一个原子的轨道彼此正交。$s$–$p$ 交叉项再次由对称性为零，而两个指向夹角 $\theta$ 的 $p$ 轨道（径向部分相同）的重叠为 $\cos\theta$：
$$
\langle \mathrm{h_i}|\mathrm{h_j}\rangle = \tfrac14\left(\langle \mathrm{s}|\mathrm{s}\rangle + 3\,\langle \hat p_i|\hat p_j\rangle\right) = \tfrac14\left(1 + 3\cos\theta\right) \stackrel{!}{=} 0
\quad\Longrightarrow\quad
\cos\theta = -\tfrac13,
$$
所以 $\theta = 109.47^\circ$。四面体角是*唯一*的角度，在此角度下由一个 $s$ 和三个 $p$ 轨道构成的四个等价杂化轨道能够互不重叠地共存。甲烷的几何是一个关于正交性的定理；VSEPR 的排斥论证与这一推导是通往同一张桌子同一个角落的两条路。（每个杂化轨道的 $s$ 成分是 $\left(\tfrac12\right)^2 = \tfrac14$、$p$ 成分是 $\left(\tfrac{\sqrt3}{2}\right)^2 = \tfrac34$，正如所说——而四个杂化轨道恰好用掉 $4 \times \tfrac14 = 1$ 个 $s$ 轨道和 $4 \times \tfrac34 = 3$ 个 $p$ 轨道：轨道是守恒的。）
:::

::: proposition $\mathrm{sp}^n$ 杂化轨道的夹角 {#prop-sp-n-angle}
对于组成为 $\mathrm{sp}^n$（一份 $s$、$n$ 份 $p$）的一组等价杂化轨道，
$$
\mathrm{h_i} = \frac{1}{\sqrt{1+n}}\left(\mathrm{s} + \sqrt{n}\,\hat p_i\right)
\qquad\Longrightarrow\qquad
\langle \mathrm{h_i}|\mathrm{h_j}\rangle = \frac{1 + n\cos\theta}{1+n} = 0
\qquad\Longrightarrow\qquad
\cos\theta = -\frac{1}{n},
$$
所以等价杂化轨道之间的夹角，对 $\mathrm{sp}$（$n=1$）是 $180^\circ$，对 $\mathrm{sp^2}$（$n=2$）是 $120^\circ$，对 $\mathrm{sp^3}$（$n=3$）是 $109.47^\circ$。每个杂化轨道的 $s$ 成分是 $1/(1+n)$：分别为 $50\ \%$、$33\ \%$、$25\ \%$。
:::

一个公式，三种几何——以及其间的一个连续统。拒绝理想键角的真实分子（水的 $104.5^\circ$、甲醛不等的键角）不是这幅图像的例外，而是其改进的证据：杂化并不限于整数 $n$，一个原子可以把*更多的 p 成分倾注进需要张开得大的键、把更多的 s 成分倾注进靠得近的键*——这正是本特规则的内容，下文即将遇到。

::: algorithm 指定杂化类型 {#alg-hybridisation}
**输入：**一个路易斯结构。**输出：**每个中心原子的杂化类型。
1. 对每个原子，数它的**空间位阻数**（steric number）：$\sigma$ 键相邻原子的数目（双键或三键算作*一个*相邻原子）加上孤对电子的数目。
2. 直接读出：位阻数 4 → $\mathrm{sp^3}$；3 → $\mathrm{sp^2}$；2 → $\mathrm{sp}$。
3. 把孤对电子放进杂化轨道（它们比成键杂化轨道更靠近核、能量更低）。
4. 任何未杂化的 $p$ 轨道（$\mathrm{sp^2}$ 剩一个，$\mathrm{sp}$ 剩两个）留给 $\pi$ 键，或留作类孤对的 $p$ 密度。
5. 与 VSEPR（[[bonding-structure/vsepr]]）交叉验证：位阻数等于电子区域计数，所以两个理论必须说出同一种几何。
:::

## σ键与π键

::: definition σ键与π键 {#def-sigma-pi}
**$\sigma$ 键**由*沿*两核连线的重叠形成——正面相对的 $s$–$s$、$s$–$p$、$p$–$p$ 或杂化–杂化重叠——其电子密度关于该轴圆柱对称。**$\pi$ 键**由两个平行未杂化 $p$ 轨道的*侧面*重叠形成，带一个包含该轴的节面。单键是一个 $\sigma$ 键；双键是一个 $\sigma$ 加一个 $\pi$；三键是一个 $\sigma$ 加两个两两垂直的 $\pi$ 键。由于 $\pi$ 键要求平行的 $p$ 轨道，绕双键的扭转会破坏重叠——这就是为什么双键在室温下不自由旋转、从而给出可分离的*顺式*/*反式*异构体，而单键可以旋转。
:::

::: example 甲烷的成键，从头到尾 {#ex-ch4-bonding}
描述 $\mathrm{CH_4}$ 的价键构造，并解释四个等价的键。
::: solution
从碳的基态 $2s^2 2p^2$ 出发：两个未配对电子，预期两个键。把一个 $2s$ 电子提升到空的 $2p$ 轨道：$2s^1 2p^3$，四个未配对电子。激发要花费能量（$2s \to 2p$ 激发为几百 $\mathrm{kJ\,mol^{-1}}$），但四个 $\mathrm{C–H}$ 键代替两个键多释放约 $2 \times 413\ \mathrm{kJ\,mol^{-1}}$——账本大大地偏向四个键一边。现在把四个价轨道混合成四个 $\mathrm{sp^3}$ 杂化轨道，由[[#proof-tetrahedral-angle]]，它们必须指向 $109.47^\circ$；每个与一个氢的 $1s$ 轨道正面重叠，给出一个 $\sigma$ 键。四个键全等价，因为四个杂化轨道全等价——组成相同、重叠相同、键长相同、能量相同——分子就是 VSEPR 预测的那个四面体，如今下面有了机制。
:::
:::

::: example 氨与水：孤对电子占据杂化轨道 {#ex-nh3-h2o-hybrid}
指定 $\mathrm{NH_3}$ 和 $\mathrm{H_2O}$ 的成键，并解释它们的键角（$107^\circ$、$104.5^\circ$）为什么低于 $109.47^\circ$。
::: solution
氮：五个价电子，三个 $\mathrm{N–H}$ 键和一对孤对——位阻数 4，大致 $\mathrm{sp^3}$：三个杂化轨道与氢的 $1s$ 轨道重叠，第四个容纳孤对。氧：两个键和两对孤对——位阻数又是 4，两个杂化轨道成键、两个容纳孤对。但杂化轨道不必是*均等*的那些。只被一个核感受到的孤对能量更低，抓取额外的 **s** 成分（s 轨道穿透到更靠近核处，最能稳定非键电子）；相应地，键由带额外 **p** 成分的杂化轨道构成——而纯 p 轨道会以 $90^\circ$ 相交，低于 $109.47^\circ$。于是把 p 成分推进键里，就把键的角拖向 $90^\circ$：一对孤对给出氨的 $107^\circ$，两对给出水的 $104.5^\circ$。这种 s 与 p 成分的连续重新加权就是本特规则——*原子的 s 成分集中于指向电正性较强取代基的轨道，也集中于孤对*——它是粗糙的 VSEPR 说法"孤对压缩"的定量灵魂。
:::
:::

::: example 乙烯与乙炔：双键与三键的算术 {#ex-ethene-ethyne}
描述 $\mathrm{C_2H_4}$ 和 $\mathrm{C_2H_2}$ 的成键，并用键焓比较 $\sigma$ 与 $\pi$ 重叠。
::: solution
乙烯：每个碳有三个相邻原子、没有孤对——位阻数 3，$\mathrm{sp^2}$。六个 $\mathrm{sp^2}$ 杂化轨道（每个碳三个）搭建 $\sigma$ 骨架：四个 $\mathrm{C–H}$ 和一个 $\mathrm{C–C}$ $\sigma$ 键，全在同一平面内、约 $120^\circ$。每个碳保留一个未杂化的 $2p$ 轨道垂直于该平面；两者平行并以侧面重叠给出一个 $\pi$ 键，其密度位于分子平面的上下。绕 $\mathrm{C=C}$ 的旋转将不得不把这些 $p$ 轨道转出平行，代价约为整个 $\pi$ 键能——所以没有自由旋转。乙炔：每个碳有两个相邻原子——$\mathrm{sp}$，直线形；$\sigma$ 骨架（$2\,\mathrm{C–H} + 1\,\mathrm{C–C}$）使用 sp 杂化轨道，每个碳上剩下的两对 $p$ 给出**两个**垂直的 $\pi$ 键，一圈绕 $\mathrm{C–C}$ 轴的圆柱形密度套袖。

现在是数据（标准平均键焓）：$\mathrm{C–C}$ $348\ \mathrm{kJ\,mol^{-1}}$、$154\ \mathrm{pm}$；$\mathrm{C=C}$ $612\ \mathrm{kJ\,mol^{-1}}$、$134\ \mathrm{pm}$；$\mathrm{C{\equiv}C}$ 约 $837\ \mathrm{kJ\,mol^{-1}}$、$120\ \mathrm{pm}$。双键*不是*单键的两倍：$\pi$ 的贡献是 $612 - 348 = 264\ \mathrm{kJ\,mol^{-1}}$，比伴随它的 $\sigma$ 键弱约 $24\ \%$——侧面重叠不如正面相对。第二个 $\pi$ 只增加 $837 - 612 = 225\ \mathrm{kJ\,mol^{-1}}$。更弱、更高、更暴露：$\pi$ 电子才是活泼的那些，这就是为什么烯烃加溴而烷烃不加。
:::
:::

::: example 两个小分子：$\mathrm{BeCl_2}$、$\mathrm{BH_3}$，以及 $\mathrm{CH_3CN}$ 的计数 {#ex-becl2-bh3-ch3cn}
指定 (a) 气态 $\mathrm{BeCl_2}$（直线形）和 (b) $\mathrm{BH_3}$ 单元（平面三角形）的杂化类型，并 (c) 数出乙腈 $\mathrm{CH_3CN}$ 中所有的 $\sigma$ 键与 $\pi$ 键。
::: solution
(a) 铍有两个成键相邻原子、没有孤对：位阻数 2，**sp**——两个成 $180^\circ$ 的杂化轨道与氯的轨道重叠；直线形分子是[[#prop-sp-n-angle]]中 $n = 1$ 情形的直接类比。(b) 硼：三个相邻原子、没有孤对——**$\mathrm{sp^2}$**，三个成 $120^\circ$ 的杂化轨道；垂直于平面那只空的 $2p$ 轨道正是 $\mathrm{BH_3}$ 成为路易斯酸的原因，等着接受一对电子进去。(c) $\mathrm{CH_3CN}$：甲基碳有四个相邻原子 → $\mathrm{sp^3}$；腈碳有两个（甲基碳和氮）→ $\mathrm{sp}$；氮有一个相邻原子加一对孤对 → $\mathrm{sp}$。计数：$\sigma$ 键 $= 3\,(\mathrm{C–H}) + 1\,(\mathrm{C–C}) + 1\,(\mathrm{C–N}) = 5$；$\mathrm{C{\equiv}N}$ 三键贡献 $2\,\pi$。总计 **5 个 $\sigma$ + 2 个 $\pi$**，而重原子骨架 $\mathrm{C–C{\equiv}N}$ 在腈碳处是直线形，正如 sp 几何所要求。
:::

::: quiz
甲醛 $\mathrm{CH_2O}$ 含有多少个 $\sigma$ 键和 $\pi$ 键？
- [x] 3 个 $\sigma$ 和 1 个 $\pi$：两个 $\mathrm{C–H}$ 和一个 $\mathrm{C–O}$ $\sigma$ 键，加上未杂化的碳 $2p$ 与氧 $2p$ 重叠形成的一个 $\pi$ 键。
- [ ] 2 个 $\sigma$ 和 2 个 $\pi$：碳氧双键提供两个 $\pi$ 键。
- [ ] 3 个 $\sigma$ 和 2 个 $\pi$：氧的每对孤对各形成一个 $\pi$ 键。
- [ ] 4 个 $\sigma$ 和 1 个 $\pi$：氧向自己的孤对贡献一个 $\sigma$ 键。
::: solution
路易斯结构（$\mathrm{H_2C{=}O}$，氧上有两对孤对）给出一个 $\mathrm{C{=}O}$ 双键：一个 $\sigma$ 加一个 $\pi$。加上两个 $\mathrm{C–H}$ $\sigma$ 键：$3\,\sigma + 1\,\pi$。碳是 $\mathrm{sp^2}$（三个相邻原子），它剩下的 $2p$ 与一个氧 $2p$ 形成那唯一的 $\pi$ 键；氧的孤对根本不是键。双键永远是 $\sigma + \pi$，绝不会是 $\pi + \pi$——两个 $\pi$ 键需要两对垂直的 $p$ 轨道，如三键中那样。
:::
:::

::: warning 杂化是一个模型，不是一个事件 {#warn-hybridisation-model}
碳原子中没有任何东西在成键之前自行"激发"和"混合"——杂化是我们对轨道施行的一次*数学重新组合*，因为它使成键分子被正确描述；孤立原子的 $2s$ 与 $2p$ 仍然是对*原子*的正确描述。分子是裁判，而它已经两次开口。第一，甲烷的光电子能谱显示它的八个价电子只占据**两个**能级（$14$ 与 $23\ \mathrm{eV}$ 附近的谱带，强度比 $3:1$），而不是四个等价的能级——四个成键电子并*不*全在同一能量上，所以四面体分子不是四面体原子的四份拷贝。第二，杂化**为几何提供合理化解释；它并不导致几何**：我们选 $\mathrm{sp^3}$ 是因为甲烷是四面体形，而不是相反；当数据要求偏离理想的键角（水、甲醛）时，杂化轨道就滑向非整数的 $n$。把杂化当作原因来用，它就变成循环论证；把它当作方向与 s 成分的记账法来用，它是化学中最有效率的思想之一。
:::

::: history
1927 年，海特勒（Heitler）与伦敦（London）把只有三年历史的波动力学应用于氢分子本身，表明键只出现在反平行自旋之间——把分子维系在一起的是交换能，不是一种新的力。这一纲领传到了鲍林（Pauling）手中，他从 1931 年起的一系列论文用轨道混合建立起定向键并解释了四面体碳；也传到了斯拉特（Slater）手中，他 1931 年的论文《定向价键》（"Directed Valence Bonds"）给出了杂化轨道的一般构造并贡献了这个名字。鲍林 1939 年的著作《化学键的本质》（*The Nature of the Chemical Bond*）把杂化、键级与电负性织成本学科的核心文本，并定下了此后每一代人都在与之争论的词汇表。把键角归因于可变的 s 成分这一改进归功于本特（Bent），他 1961 年发表在《有机化学杂志》（Journal of Organic Chemistry）上的论文提出了至今仍以他命名的规则——这提醒我们：即便一个已有五十年历史的模型，在其创立者仍在写作时，也仍被继续打磨。
:::

## 后续内容

价键理论把电子定域在键里，而这恰恰是它的弱点：拒绝定域的分子——苯等价的键、臭氧两条相同的连接，尤其是 $\mathrm{O_2}$，其顺磁性是配对电子图像无法咽下的——要求伸展到整个分子上的轨道。那就是分子轨道理论，[[bonding-structure/molecular-orbitals]]，同一套量子力学更深的另一半，也是下一章。形式上的根基——交换、海特勒-伦敦波函数，以及每一句"轨道重叠时能量下降"背后的变分法——在[[quantum-chemistry/chemical-bond-qm]]中展开。就眼下而言，把两个模型作为工具并排放着：[[bonding-structure/covalent-lewis]]画出键，VSEPR 把键折弯，杂化解释它们为什么那样弯。

::: summary
- 价键是两个相互重叠的单占据轨道之间共享的一对自旋相反的电子；键强跟随重叠，而交换能（海特勒-伦敦，1927）是键的起源。
- 碳的基态只提供两个未配对电子，而甲烷有四个等价的键：激发加杂化把代价成倍偿还。
- 杂化轨道是一个原子 s 与 p 轨道的归一化混合：$\mathrm{sp^3}$（25 % s，$109.47^\circ$）、$\mathrm{sp^2}$（33 % s，$120^\circ$）、sp（50 % s，$180^\circ$），剩下的 p 轨道留给 $\pi$ 键。
- 等价 $\mathrm{sp}^n$ 杂化轨道之间的夹角仅由正交性得出：$\cos\theta = -1/n$；四面体角是 $\arccos(-1/3)$。
- 位阻数（$\sigma$ 相邻原子 + 孤对）指定杂化类型：4 → $\mathrm{sp^3}$，3 → $\mathrm{sp^2}$，2 → sp；孤对住在杂化轨道里。
- 单键 = $\sigma$；双键 = $\sigma + \pi$；三键 = $\sigma + 2\pi$；$\pi$ 键弱于 $\sigma$（$\mathrm{C{=}C}$ 对 $\mathrm{C–C}$ 为 $612 - 348 = 264\ \mathrm{kJ\,mol^{-1}}$）并冻结旋转。
- 杂化为几何提供合理化解释而非原因；光电子能谱与本特规则（可变的 s 成分）使模型保持诚实。
:::

## 练习

::: exercise 指定杂化类型 {level=1}
给出下列每个物种中心原子的杂化类型：(a) $\mathrm{CO_3^{2-}}$；(b) $\mathrm{NH_4^{+}}$；(c) HCN；(d) $\mathrm{SO_2}$。
::: solution
(a) 碳：三个成键相邻原子、没有孤对——位阻数 3，$\mathrm{sp^2}$（未杂化的 p 进入离域 $\pi$ 体系）。(b) 氮：四个相邻原子、没有孤对——$\mathrm{sp^3}$，四面体形。(c) 碳：两个相邻原子（H 和 N）、没有孤对——sp，直线形；氮也是 sp（一个相邻原子 + 一对孤对）。(d) 硫：两个成键相邻原子和一对孤对——位阻数 3，$\mathrm{sp^2}$，V 形，剩下的 p 形成 $\mathrm{S{=}O}$ 键的 $\pi$ 键。
:::
:::

::: exercise 数 σ 键与 π 键 {level=1 check="9"}
1,3-丁二烯 $\mathrm{CH_2{=}CH{-}CH{=}CH_2}$ 中有多少个 $\sigma$ 键？（输入数目。）
::: solution
六个 $\mathrm{C–H}$ 键和三个 $\mathrm{C–C}$ $\sigma$ 键：$6 + 3 = \boxed{9}$ 个 $\sigma$ 键，外加两个 $\pi$ 键（每个双键一个）。每个单、双、三连接都恰贡献一个 $\sigma$ 键；只有多余的连接贡献 $\pi$。
:::
:::

::: exercise 由 $\cos\theta = -1/n$ 求角 {level=1 check="120"}
对 $\mathrm{sp^2}$ 情形（$n = 2$）解 $\cos\theta = -1/n$。（以度输入角度。）
::: solution
$\cos\theta = -\tfrac12$ 给出 $\theta = \boxed{120^\circ}$——等价 $\mathrm{sp^2}$ 杂化轨道之间的夹角，与[[#proof-tetrahedral-angle]]完全一样由正交性得出，只是以 $n = 2$ 代替 $3$。
:::
:::

::: exercise 水为什么不是甲烷的形状 {level=2}
$\mathrm{H_2O}$ 和 $\mathrm{NH_4^{+}}$ 的中心原子位阻数都是 4，然而 $\mathrm{NH_4^{+}}$ 的键角恰为 $109.47^\circ$，水却是 $104.5^\circ$。用杂化组成解释，并陈述本特规则。
::: solution
$\mathrm{NH_4^{+}}$ 有四对*等价*的成键电子对、没有孤对，所以四个杂化轨道等价，[[#proof-tetrahedral-angle]]强制给出恰好 $\arccos(-1/3)$。水有两个键和两对孤对：孤对因在核附近的穿透作用而稳定，占据 s 成分更高的杂化轨道，而成键杂化轨道相应地富含 p 成分。由于纯 p 轨道以 $90^\circ$ 相交，富 p 的键张开得小于 $109.47^\circ$——两个富 p 的键给出 $104.5^\circ$。本特规则：一个原子把含更多 s 成分的杂化轨道导向电正性取代基（而孤对表现得像最电正性的"取代基"），把含更多 p 成分的导向电负性取代基或需要更小键角之处。
:::
:::

::: exercise 双键不是两个单键 {level=2}
用平均键焓 $\mathrm{C–C}$ $348$、$\mathrm{C{=}C}$ $612$、$\mathrm{C{\equiv}C}$ $837\ \mathrm{kJ\,mol^{-1}}$ 和键长 $154$、$134$、$120\ \mathrm{pm}$，提取 $\pi$ 键的贡献并解释：(a) 为什么它们小于 $\sigma$ 的值；(b) 为什么每一个后续的 $\pi$ 更弱；(c) 这些数字对烯烃与烷烃的加成化学预言了什么。
::: solution
(a) $\pi(\text{第一个}) = 612 - 348 = 264\ \mathrm{kJ\,mol^{-1}}$：侧面 p–p 重叠跨过一个节面，把密度共享在轴的*上下*而不是两核之间，所以本质上不如正面相对——比 $\sigma$ 键弱约 $24\ \%$。(b) $\pi(\text{第二个}) = 837 - 612 = 225\ \mathrm{kJ\,mol^{-1}}$：更短更紧的 $\mathrm{C{\equiv}C}$ 芯把剩下的 p 轨道拉进来，第二个 $\pi$ 套袖又挤着第一个，所以它再次更弱。(c) 把 $\pi$ 变成 $\sigma$ 的反应是放热的：在 $\mathrm{C{=}C}$ 上加 $\mathrm{Br_2}$ 或 HBr，用一个弱的 $\pi$（$264\ \mathrm{kJ\,mol^{-1}}$）换两个新的 $\sigma$ 键，因而有利；而烷烃只有 $\sigma$ 键可断，什么都不加。键能算术就是反应性表。
:::
:::

::: exercise 再数一遍，仔细点 {level=2 check="7"}
乙酸 $\mathrm{CH_3COOH}$ 中有多少个 $\sigma$ 键？（输入数目。）
::: solution
键：三个 $\mathrm{C–H}$、一个 $\mathrm{C–C}$、一个 $\mathrm{C{=}O}$（一个 $\sigma$）、一个 $\mathrm{C–O}$、一个 $\mathrm{O–H}$：$3 + 1 + 1 + 1 + 1 = \boxed{7}$ 个 $\sigma$ 键，外加一个 $\pi$ 键（在羰基中）。氧上的孤对不是键；双键各贡献一个 $\sigma$ 和一个 $\pi$。
:::
:::

::: exercise 推导一般键角 {level=3}
从头推导 $\cos\theta = -1/n$：把 $\mathrm{h_i} = \frac{1}{\sqrt{1+n}}(\mathrm{s} + \sqrt{n}\,\hat p_i)$ 归一化，施加两个杂化轨道的正交性，恢复全部三个教科书键角。然后证明各杂化轨道的 s 成分之和恰为一个 s 轨道。
::: solution
归一化：$\langle \mathrm{h_i}|\mathrm{h_i}\rangle = \frac{1}{1+n}\left(\langle s|s\rangle + n\langle \hat p_i|\hat p_i\rangle + 2\sqrt n\langle s|\hat p_i\rangle\right) = \frac{1+n}{1+n} = 1$，用到 $\langle s|\hat p_i\rangle = 0$（宇称相反）。$i \neq j$ 时的正交性：$\langle \mathrm{h_i}|\mathrm{h_j}\rangle = \frac{1}{1+n}\left(1 + n\,\hat{\mathbf{u}}_i\!\cdot\!\hat{\mathbf{u}}_j\right) = \frac{1 + n\cos\theta}{1+n} = 0$，故 $\cos\theta = -1/n$。于是 $n=1$：$\cos\theta = -1$，$\theta = 180^\circ$（sp）；$n=2$：$-1/2$，$120^\circ$（$\mathrm{sp^2}$）；$n=3$：$-1/3$，$109.47^\circ$（$\mathrm{sp^3}$）。守恒：一组等价 $\mathrm{sp}^n$ 杂化轨道每个杂化轨道含 $1/(1+n)$ 的 s 成分，而由一个 s 轨道构成的杂化轨道数目是 $1+n$——对 $\mathrm{sp^3}$，四个杂化轨道 $\times\ \tfrac14 = 1$ 个 s 轨道、$4 \times \tfrac34 = 3$ 个 p 轨道；对 $\mathrm{sp^2}$，$3 \times \tfrac13 = 1$ 个 s、$3 \times \tfrac23 = 2$ 个 p，留下一个 p 未杂化。这一构造从不发明轨道，也从不丢失轨道——这正是键角被强制的原因。
:::
:::

::: exercise 分析丙二烯 {level=3}
丙二烯是 $\mathrm{H_2C{=}C{=}CH_2}$。给每个碳指定杂化类型，数出 $\sigma$ 键与 $\pi$ 键，并且——难的部分——证明两个 $\pi$ 键迫使两个 $\mathrm{CH_2}$ 基团位于*互相垂直*的平面内。
::: solution
端基碳：各有三个相邻原子 → $\mathrm{sp^2}$，各留一个未杂化的 p。中心碳：两个相邻原子 → sp，直线形，有**两个**未杂化的 p 轨道，两两垂直。中心碳必须用它的两个 p 轨道对每个端基碳各形成一个 $\pi$ 键——而 $\pi$ 键只在*平行*的 p 轨道之间形成。所以左端基的 p 必须与中心碳两个 p 之一平行（设为竖直），右端基的 p 与另一个平行（水平）。因此两个 $\pi$ 体系在构造上就互相垂直，而每个 $\mathrm{CH_2}$ 平面垂直于自己的 p 轨道，便垂直于另一个平面：丙二烯不是平面的，它的两端绕 $\mathrm{C{=}C{=}C}$ 轴旋转了 $90^\circ$。计数：$\sigma = 4\,(\mathrm{C–H}) + 2\,(\mathrm{C–C}) = 6$；$\pi = 2$。（值得注意的推论：一个取代得当的丙二烯虽然没有立体中心却是手性的——垂直的平面使它的两半成为不能重合的镜像，这是杂化几何的一个预言，在该模型发明很久之后得到确证。）
:::
