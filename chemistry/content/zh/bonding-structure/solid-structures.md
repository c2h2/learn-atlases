食盐沿立方面解理，金刚石能切割玻璃，铜能被拉成绵延千米的细丝。三种日常固体，对同一个问题——*积木块如何排列自身？*——给出三种完全不同的答案，而每个答案都由[[bonding-structure/ionic-bonding]]、[[bonding-structure/covalent-lewis]]与[[bonding-structure/metallic-bonding]]中的键型施加于一大群粒子而得出。固体正是这门课程的键模型兑现的地方：一种材料的熔点、硬度、导电性与解理，都能直接从它的结构上读出来。本章先搭建几何词汇（晶格、晶胞、最密堆积），再推出把晶体架构与可测数字联系起来的定量规则（堆积系数、半径比、密度），最后以让这一切变得可见的那个实验技巧收尾：X射线衍射。先做一个区分。**晶态**固体的积木块按在三维中无限重复的图样排列——远程有序。**非晶态**固体（玻璃、大多数聚合物、凝胶）只在几个原子间距的范围内有序：它是被冷却得太快、分子还来不及排列就被原地冻住的液体，一张靠自身连接而僵持住的无序网络——而不是（尽管有教堂窗玻璃缓慢下淌的旧说法）会流动的液体。

## 晶格与晶胞

::: definition 晶格、基元与晶胞 {#def-lattice-basis}
**晶格**是由平移$\mathbf{R} = n_1\mathbf{a} + n_2\mathbf{b} + n_3\mathbf{c}$（$n_i$为整数）生成的无限点阵：每个格点的环境与任何其他格点完全相同。**基元**是附着在每个格点上的原子、离子或原子团。**晶体**= 晶格 + 基元：晶格是脚手架，基元是挂在上面的东西，晶格相同而基元不同的两种晶体是完全不同的材料。**晶胞**是由$\mathbf{a}, \mathbf{b}, \mathbf{c}$张成、仅靠平移就能填满空间的平行六面体；**惯用晶胞**是同时显示晶体对称性的最小方便形状，它可以包含不止一个格点（体心、面心、棱心）。在晶胞之间共享的原子按分数计数：顶角原子属于八个晶胞各$\tfrac18$，棱上原子$\tfrac14$，面上原子$\tfrac12$，体内原子全属本胞。
:::

这套分数记账值得亲手做一遍，因为本章的每一个密度计算都压在这套记账上。

::: example 数立方晶胞中的原子 {#ex-cell-counting}
简单立方（SC）、体心立方（BCC）与面心立方（FCC）金属的惯用立方晶胞中各坐落多少个原子？每个原子的配位数（最近邻的数目）是多少？
::: solution
**SC：**八个顶角$\times\ \tfrac18 = 1$个原子。一个原子沿$\pm x, \pm y, \pm z$方向都有近邻：**CN 6**。**BCC：**顶角$8\times\tfrac18 = 1$加上整个体心原子$= 2$个原子。体心原子与八个顶角原子接触：**CN 8**。**FCC：**顶角$8\times\tfrac18 = 1$加上六个面$\times\ \tfrac12 = 3$，共**4个原子**。面心原子与其所在面的四个顶角原子接触，并在距离$a/\sqrt{2}$处与另外八个面心原子接触：**CN 12**。三种结构的差别在于一个晶胞里装了多少原子、每个原子享有几个近邻——而我们会看到，这两个数字并不独立：配位数越高，堆积越密。
:::
:::

::: definition 七大晶系与十四种布拉维点阵 {#def-crystal-systems}
任何晶格都落入**七大晶系**之一，按惯用晶胞的度量关系（棱长$a,b,c$；夹角$\alpha,\beta,\gamma$）分类：**立方**$a=b=c$，诸角$90^\circ$；**四方**$a=b\neq c$，诸角$90^\circ$；**正交**$a\neq b\neq c$，诸角$90^\circ$；**六方**$a=b\neq c$，$\alpha=\beta=90^\circ$，$\gamma=120^\circ$；**三方（菱方）**$a=b=c$，$\alpha=\beta=\gamma\neq 90^\circ$；**单斜**$a\neq b\neq c$，$\alpha=\gamma=90^\circ\neq\beta$；**三斜**无任何度量约束。再叠上可能的带心类型——简单P、体心I、面心F、单面心C——恰好得到**十四种布拉维点阵**（立方P、I、F；四方P、I；正交P、I、F、C；六方P；三方P；单斜P、C；三斜P）：七个度量类只容得下十四种不同的平移对称。
:::

::: definition 离子结构中的配位数 {#def-coordination-ionic}
在离子结构中，一个离子的**配位数**是包围它的带异号电荷的最近邻的数目；结构用"$m:n$"描述（阳离子CN : 阴离子CN），而电荷平衡迫使$N_+/N_- = n_\mathrm{anion\,CN}/n_\mathrm{cation\,CN}$——份数较少的那种离子需要更多异号近邻。坐在阴离子最密堆积或简单阵列的**空隙**（间隙位置）中的阳离子，其配位数由空隙类型决定：3（三角形）、4（四面体）、6（八面体）或8（立方）。
:::

::: proof SC、BCC 与 FCC 的原子堆积系数 {#proof-packing}
把金属元素的原子当作半径为$r$的等径硬球，它们沿晶胞中最密的可用方向相互接触；**原子堆积系数**为$\mathrm{APF} = N V_\mathrm{atom}/V_\mathrm{cell}$，其中$V_\mathrm{atom} = \tfrac{4}{3}\pi r^{3}$。
**SC。**原子沿立方棱接触：$a = 2r$。取$N = 1$，
$$
\mathrm{APF} = \frac{\tfrac{4}{3}\pi r^{3}}{(2r)^{3}} = \frac{\pi}{6} = 0.524 .
$$
**BCC。**体对角线$\sqrt{3}\,a$穿过两个顶角原子和整个中心原子，彼此全部接触：$4r = \sqrt{3}\,a$，所以$a = 4r/\sqrt{3}$。取$N = 2$，
$$
\mathrm{APF} = \frac{2\cdot\tfrac{4}{3}\pi r^{3}}{\left(4r/\sqrt{3}\right)^{3}} = \frac{\sqrt{3}\,\pi}{8} = 0.680 .
$$
**FCC。**原子沿面对角线接触：$4r = \sqrt{2}\,a$，所以$a = 2\sqrt{2}\,r$。取$N = 4$，
$$
\mathrm{APF} = \frac{4\cdot\tfrac{4}{3}\pi r^{3}}{\left(2\sqrt{2}\,r\right)^{3}} = \frac{\pi}{3\sqrt{2}} = 0.740 .
$$
数值随配位数上升——CN 6时$0.524$，CN 8时$0.680$，CN 12时$0.740$——而最后一个数值恰是等径球可能的最大值（1611年的开普勒（Kepler）猜想，托马斯·黑尔斯（Thomas Hales）于1998年宣布证明、2014年完成形式化验证）：没有任何等径球的排列能填满超过$74.05\ \%$的空间。
:::

## 最密堆积

::: proposition 等径球的最密堆积 {#prop-close-packing}
把等径球在平面内堆成每个球与六个球接触（**六角层**，可能的最密二维堆积）；把第二层放到第一层的凹坑上，第三层就有了选择。若它坐在*第一层*的凹坑正上方，堆叠序列是**ABAB…**，即**六方最密堆积（hcp）**结构（Mg、Zn、Cd）；若它占据*第三种*此前未用过的凹坑，序列是**ABCABC…**，即**立方最密堆积（ccp）**结构——它就是沿体对角线看过去的FCC点阵（Cu、Ag、Au、Ni、Al）。两种堆叠都是CN 12、填满$74.05\ \%$的空间；它们只在堆叠序列上不同，这就是多型现象——混合序列——常见的原因。$N$个球的堆积恰含$N$个**八面体空隙**（CN 6，半径比$0.414$）和$2N$个**四面体空隙**（CN 4，半径比$0.225$）：在FCC晶胞中，四个球"拥有"四个八面体位置（十二条棱心$\times\ \tfrac14$加体心）以及完全落在胞内的八个四面体位置。
:::

空隙的计数不是脚注式的细节——它是构造下面每一种离子结构的记账法，因为离子结构*就是*较大离子的最密堆积（或简单堆积）加上填入空隙的较小离子。

## 离子晶体结构

::: proposition 半径比规则 {#prop-radius-ratio}
对坐在相互接触的阴离子的最密或简单阵列的空隙中的阳离子，要与所有近邻保持稳定接触（且阴离子之间不被挤迫），阳离子/阴离子半径比$r_+/r_-$必须超过一个只依赖空隙配位数的几何下限：
$$
\begin{array}{c|c|c}
\text{阳离子的配位数} & \text{空隙} & \text{最小 } r_+/r_- \\ \hline
3\ (\text{三角形}) & \text{平面} & 0.155 \\
4\ (\text{四面体，闪锌矿}) & \text{四面体} & 0.225 \\
6\ (\text{八面体，岩盐}) & \text{八面体} & 0.414 \\
8\ (\text{立方，CsCl 型}) & \text{立方} & 0.732
\end{array}
$$
给定一个半径比，规则就预言结构类型；它是一条**经验的几何指南**，不是定律——见下面的警告。
:::

::: proof 半径比下限的推导 {#proof-radius-ratio}
四个下限都来自同一种几何：阳离子坐在一个由相互接触的阴离子构成的对称笼子的中心。
**八面体（CN 6）。**取四个阴离子的正方形平面，阳离子在中心。相邻阴离子沿边长为$a$的正方形的*棱*接触：$2r_- = a$，而阳离子-阴离子沿半对角线接触给出$r_+ + r_- = \sqrt{2}\,a/2 = \sqrt{2}\,r_-$。于是
$$
\frac{r_+}{r_-} = \sqrt{2} - 1 = 0.414 .
$$
**立方（CN 8）。**八个阴离子在棱长为$a$的立方体的顶角上，沿立方体的*棱*接触：$2r_- = a$。体心的阳离子沿体对角线与它们接触：$2(r_+ + r_-) = \sqrt{3}\,a = \sqrt{3}\cdot 2r_-$，所以
$$
\frac{r_+}{r_-} = \sqrt{3} - 1 = 0.732 .
$$
**四面体（CN 4）。**四个阴离子在棱长为$a$的立方体的交错顶角上（一个正四面体），沿面对角线接触：$2r_- = \sqrt{2}\,a$。立方体中心的阳离子距离为$\sqrt{3}\,a/2$：$r_+ + r_- = \sqrt{3}\,a/2 = \sqrt{3}\,r_-/\sqrt{2}$，所以$r_+/r_- = \sqrt{6}/2 - 1 = 0.225$。
**三角形（CN 3）。**三个相互接触的阴离子，阳离子在三角形中心：中心到顶点的距离是$r_-/\cos 30^\circ$，所以$r_+ + r_- = 2r_-/\sqrt{3}$，$r_+/r_- = 2/\sqrt{3} - 1 = 0.155$。
低于某个下限时，阳离子小到碰不到它的笼子——它在里面"晃荡"，阴离子彼此接触，同号电荷的排斥使这种排列失稳，于是配位数更低的结构胜出。
:::

空隙数清了，半径比在手，经典结构类型就只是几句简短的描述。**岩盐，NaCl：**$\mathrm{Cl^-}$作ccp（FCC）堆积，$\mathrm{Na^+}$填入*全部*八面体空隙——4个阴离子对应4个八面体空隙，恰好够用——得到6:6配位，每个晶胞$Z = 4$个化学式单位。**氯化铯，CsCl：**两套互相穿插的*简单立方*晶格，每种离子都是立方配位（8:8），$Z = 1$；它*不是*BCC点阵，因为两套子晶格承载的是不同的离子，而格点必须拥有完全相同的环境。**闪锌矿，ZnS：**$\mathrm{S^{2-}}$作FCC堆积，$\mathrm{Zn^{2+}}$填入*一半*四面体空隙（8个中的4个），4:4，$Z = 4$；**纤锌矿**多形体是同一想法的hcp堆叠。**萤石，$\mathrm{CaF_2}$：**$\mathrm{Ca^{2+}}$作FCC堆积，$\mathrm{F^-}$填入*全部*八个四面体空隙——4个Ca对8个F——所以Ca是8配位、F是4配位（8:4），$Z = 4$；**反萤石**（$\mathrm{Na_2O}$）把阳离子与阴离子对调。

::: example 由半径比预测结构 {#ex-radius-ratio-predict}
使用香农（Shannon）型离子半径（与配位数有关；标准数据表值）：$\mathrm{Na^+}$ $102\ \mathrm{pm}$，$\mathrm{Cs^+}$ $167\ \mathrm{pm}$，$\mathrm{Zn^{2+}}$ $74\ \mathrm{pm}$，$\mathrm{Ca^{2+}}$ $100\ \mathrm{pm}$，$\mathrm{Cl^-}$ $181\ \mathrm{pm}$，$\mathrm{S^{2-}}$ $184\ \mathrm{pm}$，$\mathrm{F^-}$ $133\ \mathrm{pm}$——预测$\mathrm{NaCl}$、$\mathrm{CsCl}$、$\mathrm{ZnS}$与$\mathrm{CaF_2}$的结构类型。
::: solution
$$
\mathrm{NaCl:}\ \frac{102}{181} = 0.56;\qquad
\mathrm{CsCl:}\ \frac{167}{181} = 0.92;\qquad
\mathrm{ZnS:}\ \frac{74}{184} = 0.40;\qquad
\mathrm{CaF_2:}\ \frac{100}{133} = 0.75 .
$$
$0.56$落在$[0.414, 0.732)$内：八面体空隙，CN 6——岩盐型，与观测一致。$0.92 \geq 0.732$：立方空隙，CN 8——CsCl型，与观测一致。$0.40 < 0.414$：四面体空隙，CN 4——闪锌矿型，与观测一致（而且只是勉强：$\mathrm{ZnS}$恰在边界附近，这就是它也能以纤锌矿形式存在的原因）。$0.75 \geq 0.732$：钙阳离子想要CN 8，萤石恰好给出这一点，同时让F保持CN 4——与$8{:}4$结构相符。四种化合物，四次除法得出四个正确预言：这些规则*作为指南*灵得出奇，而这恰恰是警告要加上的那个限定词。
:::
:::

## 由晶胞计算密度

::: algorithm 由晶胞计算晶体固体的密度 {#alg-cell-density}
**输入：**化学式、惯用晶胞的棱长$a$（来自衍射）、结构类型。**输出：**理论密度。
1. 按[[#def-lattice-basis]]的分数记账法数出**每个晶胞的化学式单位数$Z$**（岩盐型$Z = 4$；CsCl型$Z = 1$；萤石型$Z = 4$）。
2. 计算晶胞质量$Z\,M/N_\mathrm{A}$，其中$M$是*化学式单位*的摩尔质量。
3. 除以晶胞体积：
$$
\rho = \frac{Z\,M}{N_\mathrm{A}\,a^{3}}.
$$
4. 单位要老实：先把$a$从$\mathrm{pm}$换算成$\mathrm{cm}$（$1\ \mathrm{pm} = 10^{-10}\ \mathrm{cm}$）再立方，并把$\rho$以$\mathrm{g\,cm^{-3}}$报出。
实测晶体密度*就是*这个数（缺陷对它的改变远小于百分之一），于是密度在晶胞模型与天平之间闭合了回路——在历史上，它是晶胞测定的最早检验之一。
:::

::: example 岩盐的密度 {#ex-nacl-density}
$\mathrm{NaCl}$是面心立方，$a = 564\ \mathrm{pm}$、$Z = 4$。计算它的密度（$M = 58.44\ \mathrm{g\,mol^{-1}}$）。
::: solution
$$
\rho = \frac{Z M}{N_\mathrm{A} a^{3}} = \frac{4 \times 58.44\ \mathrm{g\,mol^{-1}}}{6.022\times10^{23}\ \mathrm{mol^{-1}} \times \left(5.64\times10^{-8}\ \mathrm{cm}\right)^{3}} = \frac{233.8}{108.1} = 2.16\ \mathrm{g\,cm^{-3}},
$$
而实测值为$2.17\ \mathrm{g\,cm^{-3}}$（标准数据表值）。一个边长$564\ \mathrm{pm}$的立方体里有四个化学式单位——四个$\mathrm{Na^+}$与四个$\mathrm{Cl^-}$——复现在天平上读出的数值优于半个百分点。同样的算术倒过来跑（由实测$\rho$得$Z$，或由已知$Z$得$a$），正是晶胞最初被确定下来的方式。
:::
:::

## X射线衍射：测定晶胞

::: proposition 布拉格方程 {#prop-bragg}
晶体对波长为$\lambda$的X射线在满足下式的角度$\theta$上产生强衍射：
$$
n\lambda = 2 d \sin\theta ,
$$
其中$d$是一族平行晶面中相邻面的间距，$\theta$是入射束与晶面之间的**掠射角**（衍射仪报出的是$2\theta$，即入射束与接收束之间的夹角）。这一定律是从相继晶面散射的波*同相*返回的条件；它把衍射当作晶面上的镜反射来处理，这就是它只需要面间距的原因。
:::

::: proof 光程差 $2d\sin\theta$ {#proof-bragg}
两条平行射线以角度$\theta$掠过一族间距为$d$的晶面。下面那条射线多穿入一个晶面深：进来的路上它多走$d\sin\theta$，出去的路上再多走$d\sin\theta$——从上面那条射线路径所引垂线构成的两个直角三角形上直接读出。因此总光程差为$2d\sin\theta$。当光程差是波长的整数倍时，波相干加强：
$$
2d\sin\theta = n\lambda, \qquad n = 1, 2, 3, \dots
$$
因为$\sin\theta \le 1$，反射$n\lambda = 2d\sin\theta$只在$n\lambda \le 2d$时才存在：间距太小或波长太长的东西干脆不衍射。而要让$\theta$可测，$\lambda$必须与$d$相当（几百$\mathrm{pm}$），所以X射线——其波长恰与原子间距匹配——是正确的探针；可见光长了$10^{5}$倍，看到的只是一团模糊。
:::

::: example 岩盐的一个布拉格角 {#ex-bragg-nacl}
用$\mathrm{Cu\ K\alpha}$辐射（$\lambda = 154\ \mathrm{pm}$）照射$\mathrm{NaCl}$。岩盐晶胞的$\{200\}$面间距为$d = a/2 = 282\ \mathrm{pm}$。一级反射出现在什么$2\theta$？
::: solution
$$
\sin\theta = \frac{n\lambda}{2d} = \frac{1 \times 154\ \mathrm{pm}}{2 \times 282\ \mathrm{pm}} = 0.273
\qquad\Longrightarrow\qquad
\theta = 15.8^\circ,
$$
所以衍射仪在$2\theta = 31.7^\circ$处记录到峰。（粉末谱图总是以$2\theta$报告，因为动的是探测器而不是晶体。）一个测得的角度就确定了$d$，随之确定晶胞棱长$a = 2d = 564\ \mathrm{pm}$——正是密度例题用掉的那个数。衍射给出晶胞；晶胞给出密度；天平表示同意：模型闭合了。
:::
:::

caption: 对$\mathrm{Cu\ K\alpha}$辐射（$\lambda = 0.154\ \mathrm{nm}$），一级布拉格角$\theta = \arcsin\!\left[n\lambda/(2d)\right]$随面间距$d$（以nm计）的变化曲线。曲线以**弧度**为单位——乘以$180/\pi$才能读成角度（在$d = 0.282\ \mathrm{nm}$、$n = 1$处：$0.277$ rad $= 15.8^\circ$，即上面的例题）。把$n$往上拖，看每条曲线在$d = n\lambda/2$之外消失：在$n\lambda > 2d$处，反正弦没有自变量可取，反射不存在。同一族晶面的高级数出现在更大的角度——衍射仪区分$n = 2$与另一个$d$，靠的正是这一点。
:::

## 晶体固体的四大类

每种晶体固体都是四类之一，区别在于格点上坐的是什么、又是什么把它拉住——而每一类都是本课程某一章换了顶帽子。**离子固体**（NaCl、MgO）：离子靠[[bonding-structure/ionic-bonding]]的库仑能结合；硬而脆（滑移使同号电荷相对、晶体于是劈开），高熔点，熔化或溶解之前是绝缘体，一旦熔化或溶解，可移动的离子就扛起电流。**金属固体**（Cu、Fe）：阳离子浸在离域能带构成的电子海里——[[bonding-structure/metallic-bonding]]解释了它的延展性（电子气容纳滑移）、金属光泽与导电性。**共价网络固体**（金刚石、石英$\mathrm{SiO_2}$、SiC）：原子由有方向性的共价键连成一个巨型分子——[[bonding-structure/covalent-lewis]]与[[bonding-structure/valence-bond]]延伸到无穷大。金刚石（sp³碳，CN 4）是最硬的天然材料，在常压下不熔化而在$3550\ \mathrm{^\circ C}$附近升华；石墨是富有教益的例外——sp²层内以强键结合成二维平面，层*间*只靠色散力维系，所以它软、滑，且面内导电。**分子固体**（冰、固态$\mathrm{I_2}$、干冰）：分立分子靠[[bonding-structure/intermolecular-forces]]的力结合——软、低熔点（干冰在$-78.5\ \mathrm{^\circ C}$升华）、绝缘、易挥发。从性质判断类别只需几秒，从衍射图判断只需一个下午；能在两者之间来回自如才是本事。

::: quiz
惯用岩盐晶胞中包含多少个$\mathrm{NaCl}$化学式单位？
- [x] 4个：四个$\mathrm{Na^+}$与四个$\mathrm{Cl^-}$——阴离子排成FCC阵列（每胞4个），阳离子填满全部四个八面体空隙。
- [ ] 1个：中心一个，如CsCl结构。
- [ ] 8个：八个顶角$\times\ \tfrac18$，每种离子如此。
- [ ] 2个：每套互相穿插的FCC子晶格贡献一个化学式单位。
::: solution
$\mathrm{Cl^-}$坐在FCC点阵上：$8\times\tfrac18 + 6\times\tfrac12 = 4$。$\mathrm{Na^+}$占据全部四个八面体空隙（体心$+$十二条棱心$\times\ \tfrac14 = 1 + 3 = 4$）。所以$Z = 4$个化学式单位——[[#ex-nacl-density]]的密度计算所依赖的那个数。相比之下，CsCl结构的$Z = 1$；把两者混淆是晶胞计数中最常见的错误。
:::
:::

::: warning 半径比是指南，晶胞是记账，玻璃不流动 {#warn-solid-structures}
三个需要撤销的过度断言。**半径比规则是几何，不是热力学。**它们完全忽略晶格能中的共价贡献、大阴离子的可极化性以及温度与压强——而半径比甚至越过最高上限的化合物仍可能保持岩盐型：$\mathrm{RbCl}$（$152/181 = 0.84$）在常压下是6:6，只有被挤压时才采取CsCl型，因为两种结构类型之间的能量差只有几个$\mathrm{kJ\,mol^{-1}}$，而规则在那个分辨率上什么也分辨不出来。用它们来*组织*预言，绝不用来裁决争论；CsCl本身之所以是8:8结构，是因为铯确实大，而不是因为规则这么说。**惯用晶胞是一种选择，初基晶胞才是最小。**FCC的惯用晶胞含4个格点，是因为它被选来显示立方对称；它的初基晶胞是一个恰含1个格点的斜菱面体——形状不同，晶体相同。绝不要把"惯用晶胞中的原子数"与"初基晶胞中的原子数"混为一谈。**非晶固体是刚性的，不是慢速液体。**中世纪窗玻璃的传说是个谣言：老玻璃厚薄不均是吹玻璃的工匠做成那样的，而窗玻璃的弛豫时间超过教堂的年龄。玻璃是一张被冻住的无序网络——近程有序，没有远程有序，也不流动。
:::

::: history
1784 年，勒内·雅斯特·阿维（René Just Haüy）因失手摔碎一块方解石手标本而大受震动（这是有名的轶事），注意到碎片全是菱面体——于是提出每种晶体都由相同的"组成分子"（molécules intégrantes）堆叠而成，这是固体的第一个晶格理论。一个世纪后，脚手架变得可见了：1912 年，马克斯·冯·劳埃（Max von Laue）提出晶体会衍射X射线，瓦尔特·弗里德里希（Walter Friedrich）与保罗·克尼平（Paul Knipping）拍得第一张劳埃照片，同时证明了X射线是波、晶体是周期的。1913 年，二十二岁的威廉·劳伦斯·布拉格（William Lawrence Bragg）写下了 $n\lambda = 2d\sin\theta$，并与父亲威廉·亨利·布拉格（William Henry Bragg）一起解出了最早的晶体结构——1914 年报告岩盐是$\mathrm{Na^+}$与$\mathrm{Cl^-}$交替排列的晶格，其中根本没有任何NaCl*分子*，以直接测量了结了一场关于离子键的长期争论。1915 年的诺贝尔物理学奖随之而来。1929 年，莱纳斯·鲍林（Linus Pauling）发表他的离子晶体结构规则，把半径比、静电价与共用多面体变成一套可操作的固体化学——正是本章至今仍在讲授的框架。
:::

## 后续内容

[[bonding-structure/ionic-bonding]]中计算的晶格能现在可以*真正地*算了，因为马德隆常数属于这里点名的那些结构；[[bonding-structure/metallic-bonding]]往同样的晶格里填入带电子；[[bonding-structure/intermolecular-forces]]解释软端的那些分子晶体。材料课程把一切推广开去：[[materials-chemistry/crystal-structures]]讲真实固体的完整架构，[[materials-chemistry/diffraction]]讲当基元变复杂时布拉格条件会变成什么，[[materials-chemistry/defects]]讲那些让材料变得有用的偏离——空位、掺杂剂、位错。

::: summary
- 晶体是晶格（平移周期性的点阵）加上基元；惯用晶胞是一种记账选择，在晶胞之间共享的原子按分数计数。
- 七个度量类的晶胞给出七大晶系，再加上带心方式，恰好得到十四种布拉维点阵。
- SC、BCC、FCC各含1、2、4个原子，CN分别为6、8、12，分别填满$52.4$、$68.0$、$74.0\ \%$的空间；最密堆积（hcp ABAB、ccp ABCABC）以CN 12达到$74.05\ \%$的上限。
- $N$个球的堆积提供$N$个八面体空隙与$2N$个四面体空隙；离子结构是阴离子堆积加填入空隙的阳离子，半径比下限$0.155/0.225/0.414/0.732$各来自一个几何。
- 岩盐（6:6，$Z=4$）、CsCl型（8:8，$Z=1$）、闪锌矿（4:4，$Z=4$）与萤石（8:4，$Z=4$）是四种原型；半径比作为指南预言它们很灵，作为定律则不然。
- 密度由晶胞得出：$\rho = ZM/(N_\mathrm{A}a^{3})$——NaCl的$564\ \mathrm{pm}$晶胞给出$2.16\ \mathrm{g\,cm^{-3}}$。
- 布拉格方程$n\lambda = 2d\sin\theta$把测得的$2\theta$变成面间距；X射线之所以好用，是因为其波长与原子间距匹配。
- 离子、金属、共价网络与分子固体：四大类，每一类都是本课程一种键模型在块体材料上的读出。
:::

## 练习

::: exercise 晶胞与配位数 {level=1}
对三种立方金属结构（SC、BCC、FCC），分别说出惯用晶胞中的原子数与配位数，并用分数记账验证原子数。
::: solution
SC：$8\times\tfrac18 = 1$个原子，CN 6。BCC：$8\times\tfrac18 + 1 = 2$个原子，CN 8。FCC：$8\times\tfrac18 + 6\times\tfrac12 = 4$个原子，CN 12。配位数来自堆积系数证明中用到的接触方向：沿棱（SC）、沿体对角线（BCC）、沿面对角线（FCC）。
:::
:::

::: exercise 判断固体类型 {level=1}
把下列各固体归类为离子、金属、共价网络或分子，并用给出的性质说明理由：(a) 在$801\ \mathrm{^\circ C}$熔化，熔融时导电、固态时不导电；(b) 在$-78.5\ \mathrm{^\circ C}$升华，不导电；(c) 有延展性、导电、有金属光泽；(d) 已知最硬的天然材料，不溶，在$3550\ \mathrm{^\circ C}$附近升华。
::: solution
(a) 离子——只有晶格熔化后才有可移动的离子（NaCl）。(b) 分子——分立分子只靠色散力结合（干冰，$\mathrm{CO_2}$）。(c) 金属——离域电子同时给出导电性、延展性与金属光泽（铜）。(d) 共价网络——一个巨型sp³键合分子（金刚石）。分类算法是：导电吗？（金属或熔融离子）；熔点高吗？（网络或离子）；熔点低或升华吗？（分子）。
:::
:::

::: exercise 数空隙 {level=1}
最密堆积阴离子的FCC（ccp）晶胞含4个阴离子。这个晶胞含多少个八面体空隙、多少个四面体空隙？它们在哪里？这个数目与普遍规则相符吗？
::: solution
八面体：体心（1个，完全在胞内）加十二条棱心$\times\ \tfrac14 = 3$，共**4**个——每个阴离子一个。四面体：八个完全在胞内的位置，每个顶角下方一个，位于各顶角的$(\pm\tfrac14,\pm\tfrac14,\pm\tfrac14)$处——**8**个，每个阴离子两个。规则"$N$个球给出$N$个八面体与$2N$个四面体空隙"精确成立，而正是这份清单让$\mathrm{Na^+}$能填满岩盐的*全部*八面体空隙、让$\mathrm{Zn^{2+}}$恰好填满闪锌矿的*一半*四面体空隙。
:::

::: exercise KCl 的密度 {level=2 check="1.99"}
$\mathrm{KCl}$采取岩盐结构，$a = 629\ \mathrm{pm}$（$M = 74.55\ \mathrm{g\,mol^{-1}}$）。计算它的密度。（以$\mathrm{g\,cm^{-3}}$输入。）
::: solution
岩盐型意味着$Z = 4$：
$$
\rho = \frac{4 \times 74.55\ \mathrm{g\,mol^{-1}}}{6.022\times10^{23}\ \mathrm{mol^{-1}} \times \left(6.29\times10^{-8}\ \mathrm{cm}\right)^{3}} = \frac{298.2}{149.9} = 1.99\ \mathrm{g\,cm^{-3}},
$$
与实测的$1.98\ \mathrm{g\,cm^{-3}}$（标准数据表值）符合得极好。
:::
:::

::: exercise 预测结构 {level=2}
使用香农型半径$\mathrm{Mg^{2+}}$ $72\ \mathrm{pm}$、$\mathrm{Cs^+}$ $167\ \mathrm{pm}$、$\mathrm{O^{2-}}$ $140\ \mathrm{pm}$、$\mathrm{I^-}$ $206\ \mathrm{pm}$（标准数据表值），预测$\mathrm{MgO}$与$\mathrm{CsI}$中阳离子的配位数和最可能的结构类型。
::: solution
$\mathrm{MgO}$：$72/140 = 0.51$，落在$[0.414, 0.732)$内 → CN 6，岩盐型——正确，用更小的半径比得到与$\mathrm{NaCl}$相同的预言。$\mathrm{CsI}$：$167/206 = 0.81 \geq 0.732$ → CN 8，CsCl型——也正确：碘化铯确实是8:8结构。（作为对照，$\mathrm{ZnO}$的半径比为$74/140 = 0.53$，按规则应落在岩盐窗口内，但它却采取4:4的纤锌矿结构——这是一记经典的提醒：有方向性的、部分共价的键合根本不在半径比的账上。）
:::
:::

::: exercise 一个布拉格角 {level=2 check="18.3"}
用$\mathrm{Cu\ K\alpha}$辐射（$\lambda = 154\ \mathrm{pm}$）观测到来自$d = 245\ \mathrm{pm}$晶面的一级反射。求$\theta$。（以度输入$\theta$。）
::: solution
$\sin\theta = \lambda/(2d) = 154/(2\times245) = 0.314$，所以$\theta = 18.3^\circ$（衍射仪会报$2\theta = 36.6^\circ$）。注意这一定律施加的纪律：若晶面间距只有$70\ \mathrm{pm}$，$\sin\theta$将超过1，在这个波长下一级反射根本不可能存在。
:::
:::

::: exercise 推导立方空隙下限 {level=3}
从第一性原理推导阳离子坐在立方空隙（CN 8）中的半径比下限，并解释为什么取阴离子沿立方体的*棱*而不是沿面对角线接触。
::: solution
把半径为$r_-$的阴离子放在棱长为$a$的立方体的八个顶角上，阳离子在体心。最近的阴离子-阴离子接触沿立方体的棱（长度$a$），比面对角线（$\sqrt2 a$）短，所以密堆积方向——决定接触条件的方向——是棱：$2r_- = a$。阳离子沿体对角线（长度$\sqrt3\,a$）与顶角阴离子接触：$2(r_+ + r_-) = \sqrt3\,a = \sqrt3\cdot 2r_-$，于是$r_+/r_- = \sqrt3 - 1 = 0.732$。低于这个半径比，阳离子会同时失去与全部八个阴离子的接触（"晃荡"起来），静电收益下降，结构切换到八面体的6:6型。同样的"棱还是对角线"的推理，正是八面体下限来自正方形的对角线、四面体下限来自面对角线的原因：永远让*最短*的阴离子-阴离子矢量定标度。
:::
:::

::: exercise 萤石晶胞完全解析 {level=3}
萤石$\mathrm{CaF_2}$有$a = 546\ \mathrm{pm}$，$\mathrm{Ca^{2+}}$在FCC点阵上，$\mathrm{F^-}$填满全部四面体空隙。求$Z$、配位数、用$a$表示的$\mathrm{Ca-F}$键长，以及密度（$M = 78.08\ \mathrm{g\,mol^{-1}}$）。
::: solution
FCC的Ca：$8\times\tfrac18 + 6\times\tfrac12 = 4$。八个四面体空隙全被F占据：8个。所以晶胞含$\mathrm{Ca_4F_8}$——$Z = 4$个化学式单位，与化学式相符。每个位于$(\tfrac14,\tfrac14,\tfrac14)$型位置的F在一个顶角下方，被4个Ca四面体配位；每个Ca被其所在小立方体的全部8个F包围：**8:4配位**，正如半径比$100/133 = 0.75$所要求。Ca–F距离是小卦限立方体体对角线的一半：$d = \sqrt3\,a/4 = 236\ \mathrm{pm}$。密度：
$$
\rho = \frac{4 \times 78.08\ \mathrm{g\,mol^{-1}}}{6.022\times10^{23}\ \mathrm{mol^{-1}} \times \left(5.46\times10^{-8}\ \mathrm{cm}\right)^{3}} = \frac{312.3}{98.0} = 3.19\ \mathrm{g\,cm^{-3}},
$$
与实测的$3.18\ \mathrm{g\,cm^{-3}}$（标准数据表值）相符。
:::
:::

::: exercise hcp 的堆积系数 {level=3}
六方最密堆积结构的晶格参数为$a = 2r$、$c = \sqrt{8/3}\,a$（理想比，$c/a = 1.633$）。它的初基晶胞是六方点阵的一个平行六面体，体积$V = \tfrac{\sqrt{3}}{2}a^{2}c$，含2个球。推导它的原子堆积系数，并解释为什么它必须等于ccp的值。
::: solution
$$
\mathrm{APF} = \frac{2\cdot\tfrac{4}{3}\pi r^{3}}{\tfrac{\sqrt{3}}{2}a^{2}c} = \frac{\tfrac{8}{3}\pi r^{3}}{\tfrac{\sqrt{3}}{2}(2r)^{2}\sqrt{\tfrac{8}{3}}\,(2r)} = \frac{\tfrac{8}{3}\pi}{4\sqrt{3}\cdot\sqrt{\tfrac{8}{3}}} = \frac{\tfrac{8}{3}\pi}{8\sqrt{2}} = \frac{\pi}{3\sqrt{2}} = 0.740 .
$$
与ccp完全相同——而且必须相同：两种堆叠都由相同的密置层构成，层内接触相同，层间球的位置也相同；不同的只是相继层之间的*对位方式*，而对位方式不改变每个球占有的体积。每个局域环境都一样（CN 12），所以每个类似密度的整体性质都重合——这就是为什么hcp与ccp金属的差别在滑移系与延展性，而不在堆积系数。
:::
