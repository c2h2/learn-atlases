共价键是强的：断裂一个$\mathrm{C-C}$键约需$350\ \mathrm{kJ\,mol^{-1}}$，断裂水的$\mathrm{O-H}$键则需$460\ \mathrm{kJ\,mol^{-1}}$以上。然而使乙醇汽化只需$39\ \mathrm{kJ\,mol^{-1}}$，水汽化只需$41\ \mathrm{kJ\,mol^{-1}}$——而且这两个过程根本不破坏任何化学键。乙醇蒸气是完好的$\mathrm{C_2H_5OH}$分子；水蒸气是完好的$\mathrm{H_2O}$分子。汽化所克服的不是分子*内部*的力，而是分子*之间*弱得多的力：通常只有共价键强度的百分之一到十分之一。正是这个小数字决定了宏观世界的一切。它决定了在$298\ \mathrm{K}$时氯气是淡色气体、溴是易挥发液体、碘是灰色固体，尽管三者都是同族的非极性双原子分子。它决定了水的沸点比硫化氢高$160\ \mathrm{K}$：第16族氢化物的沸点为$\mathrm{H_2S}$ $-60.3\ \mathrm{^\circ C}$、$\mathrm{H_2Se}$ $-41.3\ \mathrm{^\circ C}$、$\mathrm{H_2Te}$ $-2.2\ \mathrm{^\circ C}$（标准数据表值），把这条平滑的趋势线外推回第二周期成员，预测水的沸点约为$-80$至$-90\ \mathrm{^\circ C}$——水在常温下是液体，只是因为有一种额外的东西把它凝聚在一起。而同样的力，乘以十亿个接触点，便让壁虎凭借趾垫上的细毛爬上玻璃——那些毛的尖端仅靠电子云的涨落粘在墙上。本章讲的就是这些力：它们是什么，为什么大小如此，以及如何用它们来比较沸点、溶解度与粘度的高低。

## 分子间与分子内

::: definition 分子间力与范德华力族 {#def-intermolecular}
**分子内力**就是化学键：它把同一个分子中的原子结合在一起，破坏它会改变物质本身。**分子间力**作用于分子*之间*、分子与离子之间、或分子与表面之间；它改变分子的排布与相对运动，却从不改变分子本身。所有分子间吸引都有一个**势能极小值**：两个未成键的伙伴在相距很远时既不吸引也不排斥，在中等距离上一个微弱的吸引使能量降低，在很近的距离上电子壳层的重叠产生陡峭的排斥。极小值处的距离是*接触距离*——大约等于两个范德华半径之和——而极小值的深度，通常为$0.1$–$40\ \mathrm{kJ\,mol^{-1}}$，就是相互作用的强度。**范德华（van der Waals）力**是中性、未成键粒子之间的三种静电相互作用：两个永久偶极之间的**开塞姆（Keesom）**力（取向力），永久偶极与其在邻近粒子上诱导出的偶极之间的**德拜（Debye）**力（诱导力），以及瞬时关联偶极之间的**伦敦（London）**力（色散力）。氢键与离子-偶极吸引作为独立的、更强的相互作用也被归入这一族。
:::

这个定义有两个值得注意的特点。第一，势能极小值很浅，所以分子间力不断被热运动破坏又重建：在$\mathrm{298\ K}$下，每个粒子的热能为$k_\mathrm{B}T = 2.48\ \mathrm{kJ\,mol^{-1}}$，与其中大多数相当。这正是液体能够流动、气体得以存在的原因。第二，与共价键不同，分子间力**在电子计数的意义上不具有饱和性**——一个分子可以同时被它接触到的每一个邻居吸引——但它是**短程的**：三个范德华项都按$r^{-6}$衰减，距离加倍，吸引就减弱六十四倍。试与离子间的库仑相互作用对比：它按$r^{-1}$衰减，作用范围贯穿整个晶体；正是这种作用程的差别，决定了离子固体在$800\ \mathrm{^\circ C}$熔化，而分子固体在$100\ \mathrm{^\circ C}$熔化。

## 伦敦色散：普适的吸引

::: proposition 伦敦色散力 {#prop-london}
每个分子——无论极性与否——都具有**瞬时偶极**：在任何瞬间电子都不是对称分布的，时间平均的球对称电荷云之下隐藏着一个不断涨落的电荷分布。这个瞬时偶极使邻近分子的电子云变形，在其中诱导出偶极，两者*同步*涨落：这种关联使相互作用在每一瞬间都是吸引的。对相距$r$的两个相同球形粒子，二阶量子力学微扰理论给出
$$
U_\mathrm{disp} \approx -\frac{3}{4}\cdot\frac{\alpha^{2} I}{(4\pi\varepsilon_0)^{2}\, r^{6}},
$$
其中$\alpha$是极化率（电子云变形的难易），$I$是电离能（电子被束缚的松紧）；对不同的粒子，$\alpha^2 I$被量级为$\alpha_1 \alpha_2 I$的组合代替。色散力**处处存在**，对非极性粒子它是*唯一*的分子间力。它随电子数目及其可极化性增大而增强；又因为一个分子的每个原子都吸引另一个分子的每个原子，它在分子间的**接触面积上具有可加性**。
:::

极化率$\alpha$是应当建立直觉的量：它度量电场能把电子云中心推离核多远，沿族向下急剧增大（外层电子离核更远、受屏蔽更多——见[[general-chemistry-1/periodicity]]），并沿周期从右向左增大。以极化率体积$\alpha/(4\pi\varepsilon_0)$表示，氦为$0.2\times10^{-30}\ \mathrm{m^{3}}$，氙约大二十倍；同样的趋势贯穿卤素与氧族元素。因为色散力在接触上可加，*形状与大小同等重要*：细长的分子可以贴伏在邻居上，而紧凑的分子接触很少。

::: example 卤素沸点阶梯 {#ex-halogen-ladder}
卤素的沸点为$\mathrm{F_2}$ $-188\ \mathrm{^\circ C}$、$\mathrm{Cl_2}$ $-34\ \mathrm{^\circ C}$、$\mathrm{Br_2}$ $59\ \mathrm{^\circ C}$、$\mathrm{I_2}$ $184\ \mathrm{^\circ C}$（标准数据表值）。解释这一阶梯，以及它对各元素在$\mathrm{298\ K}$下状态的预示。
::: solution
四种分子都是非极性的，所以把液体凝聚起来的*唯一*的力是色散力。沿族向下，电子数从$18$（$\mathrm{F_2}$）增至$106$（$\mathrm{I_2}$），电子云的可极化性大增，每增加一个电子层色散势阱就加深数百$\mathrm{J\,mol^{-1}}$——沸点每步分别升高$154$、$93$和$125\ \mathrm{K}$。在$\mathrm{298\ K}$，热能$k_\mathrm{B}T$轻松战胜$\mathrm{F_2}$和$\mathrm{Cl_2}$的势阱（两者皆为气体），与$\mathrm{Br_2}$的大致相当（一种发烟的液体——其势阱足以维持液体，却关不住敞口的试剂瓶），而对$\mathrm{I_2}$则明显力不能及（固体，但具有紫色蒸气压，因为晶体边缘的表面分子仍在逸出）。一种相互作用，一个变量——可极化性——涵盖了物质的三态。
:::
:::

形状论证的实例是戊烷的异构体。正戊烷$\mathrm{CH_3CH_2CH_2CH_2CH_3}$沸点$36.1\ \mathrm{^\circ C}$；异戊烷（2-甲基丁烷）$27.8\ \mathrm{^\circ C}$；新戊烷（2,2-二甲基丙烷）$9.5\ \mathrm{^\circ C}$（标准数据表值）。同一分子式，同一摩尔质量，每一对原子间的色散也相同——但近似球形的新戊烷只能与邻居点接触，而棒状的正戊烷以大片接触面积顺贴其旁，起决定作用的正是吸引性原子-原子接触的数目。

## 取向与诱导：极性分子之间的力

::: proposition 取向（开塞姆）力与诱导（德拜）力 {#prop-orientation-induction}
相距$r$的两个永久偶极$\mu_1$与$\mu_2$的相互作用能为
$$
U_\mathrm{dipole} = \frac{\mu_1 \mu_2}{4\pi\varepsilon_0\, r^{3}}\, f(\theta_1, \theta_2, \phi),
$$
其中$f$是量级为一的角因子：头尾相接则吸引，并排则排斥。在流体中分子不断转动，$f$的*一阶*角平均恰为零——这就是极性分子不会单纯靠静电锁死在一起的原因。但相互作用会使转动偏向：分子处于相互吸引取向的时间略多于相互排斥的取向，其残余的热平均**开塞姆**能为
$$
U_\mathrm{Keesom} = -\frac{2}{3}\cdot\frac{\mu_1^{2}\mu_2^{2}}{(4\pi\varepsilon_0)^{2}\, k_\mathrm{B}T\, r^{6}},
$$
它是吸引的，正比于$r^{-6}$，并且——这是独有之处——*与温度成反比*，因为转动在对抗有序。偶极$\mu$还会极化一个极化率为$\alpha$的中性邻居，而被诱导出的偶极被它的成因所吸引：**德拜诱导**能为
$$
U_\mathrm{Debye} = -\frac{\alpha\, \mu^{2}}{(4\pi\varepsilon_0)^{2}\, r^{6}}.
$$
普通流体中的典型大小：开塞姆力$0.5$–$2\ \mathrm{kJ\,mol^{-1}}$，德拜力更小，色散力$0.1$至数十$\mathrm{kJ\,mol^{-1}}$。
:::

::: proof 开塞姆平均 {#proof-keeesom}
写$U = \dfrac{\mu_1\mu_2}{4\pi\varepsilon_0 r^{3}}\, f$，其中$f = \cos\gamma - 3\cos\theta_1\cos\theta_2$，$\theta_i$是每个偶极与间距轴所成的角，$\gamma$是两个偶极之间的夹角。对所有独立取向取平均（下标$0$）：由于每个余弦的平均都为零，$\langle f \rangle_0 = 0$，所以一阶相互作用消失——"能量的平均"这一朴素结果为零。把玻尔兹曼因子展开到二阶。这一对偶极的相互作用自由能为$A = -k_\mathrm{B}T \ln \langle e^{-U/k_\mathrm{B}T}\rangle_0$；由$\langle U \rangle_0 = 0$，
$$
A \approx -k_\mathrm{B}T \ln\left(1 + \frac{\langle U^{2}\rangle_0}{2 (k_\mathrm{B}T)^{2}}\right) \approx -\frac{\langle U^{2}\rangle_0}{2 k_\mathrm{B}T}.
$$
二阶矩不为零：利用$\langle\cos^{2}\gamma\rangle_0 = \tfrac13$、$\langle\cos^{2}\theta_1\cos^{2}\theta_2\rangle_0 = \tfrac19$和$\langle\cos\gamma\cos\theta_1\cos\theta_2\rangle_0 = \tfrac19$，可得$\langle f^{2}\rangle_0 = \tfrac13 + 9\cdot\tfrac19 - 6\cdot\tfrac19 = \tfrac43$。于是
$$
A = -\frac{1}{2 k_\mathrm{B}T}\left(\frac{\mu_1\mu_2}{4\pi\varepsilon_0 r^{3}}\right)^{2}\cdot\frac{4}{3} = -\frac{2}{3}\cdot\frac{\mu_1^{2}\mu_2^{2}}{(4\pi\varepsilon_0)^{2} k_\mathrm{B}T\, r^{6}}.
$$
一行之内三条教训。这个力*总是吸引的*（二阶效应不会变号）；它按$r^{-6}$，与色散力同程，因为这个幂次正来自偶极场$r^{-3}$的平方；而且分母带着$1/k_\mathrm{B}T$——加热流体，取向力就减弱，因为转动抹平了偏向。对相距$350\ \mathrm{pm}$、$\mathrm{298\ K}$下的两个$\mathrm{HCl}$分子（$\mu = 1.08\ \mathrm{D}$），公式给出$0.7\ \mathrm{kJ\,mol^{-1}}$：真实存在，但远低于$k_\mathrm{B}T$，也低于同一分子中的色散力。取向力最重要的场合，是冷而稠密的流体中强极性分子之间。
:::

::: example 三种摩尔质量为 46 的分子 {#ex-mass-46}
乙醇沸点$78.4\ \mathrm{^\circ C}$，二甲醚$-24.8\ \mathrm{^\circ C}$，丙烷$-42\ \mathrm{^\circ C}$（标准数据表值）。前两者摩尔质量相同（$46.07\ \mathrm{g\,mol^{-1}}$）；丙烷也只有$44.10\ \mathrm{g\,mol^{-1}}$。解释这$100\ \mathrm{K}$的差距。
::: solution
数一数每个分子能做什么。丙烷没有偶极，也没有连在电负性原子上的氢：只有色散力，其沸点就是基线。二甲醚$\mathrm{CH_3OCH_3}$是弯曲的极性分子（偶极-偶极力与诱导力都起作用，还有色散力），其氧带有孤对电子——但它没有$\mathrm{O-H}$键，无法向自身*提供*氢键；比丙烷高出的$30\ \mathrm{K}$正是极性项买来的。乙醇有同样的极性骨架*加上*一个$\mathrm{O-H}$键：它既提供也接受氢键，液态乙醇中的分子连成瞬态网络。氢键——下一节的主题——贡献了余下的$70\ \mathrm{K}$。相同的质量，相同的色散预算，三个沸点：差别完全在于分子彼此表面拿出了什么。
:::
:::

## 氢键

::: proposition 氢键 {#prop-hydrogen-bonding}
**氢键**是这样的吸引$\mathrm{X-H\cdots Y}$：氢与一个小的、强电负性的原子$\mathrm{X}$（实际为N、O或F）共价结合，同时被第二个电负性原子$\mathrm{Y}$上的孤对电子所吸引。其能量为$10$–$40\ \mathrm{kJ\,mol^{-1}}$——远高于范德华力，远低于共价键——而且相互作用具有强烈的**方向性**：当$\mathrm{X-H\cdots Y}$共线时最强。条件之所以苛刻，是因为质子必须小（使正电荷集中、能靠近$\mathrm{Y}$）而$\mathrm{X}$必须电负性强（使$\mathrm{H}$带大量部分正电荷）。氟最完美地满足两者：$\mathrm{F-H\cdots F}$是最强的常见氢键。
:::

证据是氢化物的趋势线。沿每个族向下，二元氢化物随色散力增大而沸点升高——第二周期成员除外，它们荒谬地高居线上：$\mathrm{HF}$沸点$19.5\ \mathrm{^\circ C}$，而$\mathrm{HCl}$（$-85\ \mathrm{^\circ C}$）→$\mathrm{HBr}$（$-66\ \mathrm{^\circ C}$）→$\mathrm{HI}$（$-35\ \mathrm{^\circ C}$）的趋势外推接近$-110\ \mathrm{^\circ C}$；$\mathrm{NH_3}$（$-33\ \mathrm{^\circ C}$）比$\mathrm{PH_3}$（$-88\ \mathrm{^\circ C}$）高$54\ \mathrm{K}$；而水，如引言所示，比其自身趋势高$160\ \mathrm{K}$。每种情形中，分子都有连在N、O或F上的氢——因此能与自身形成氢键。

水是典范。每个$\mathrm{H_2O}$有两个作为提供体的$\mathrm{O-H}$键和两个孤对电子接受体，所以在液体和冰中，每个分子平均形成**两个提供的和两个接受的氢键**——一个四面体连接的、开放的三维网络。网络的几何结构正是冰*比液态水密度小*的原因：在Ih型冰中，每个分子的四个近邻位于四面体的顶角，被氢键距离固定在位，形成带六方通道的开放骨架，密度$0.917\ \mathrm{g\,cm^{-3}}$；而在$0\ \mathrm{^\circ C}$的液体中，部分氢键断裂并塌缩，密度升至$0.9998\ \mathrm{g\,cm^{-3}}$（标准数据表值）——结冰时膨胀百分之九，这就是冰浮于水、湖泊从上往下冻结的原因。没有别的常见物质出于这一原因使固相浮于其液相之上。

用一段话讲生物学对一种$20\ \mathrm{kJ\,mol^{-1}}$相互作用的亏欠：DNA双螺旋的两条链由互补碱基之间的氢键结合在一起——腺嘌呤与胸腺嘧啶之间两个，鸟嘌呤与胞嘧啶之间三个——其*方向性*正是配位特异性的来源，而碱基的相互堆叠则主要是可极化的芳香环之间的色散力。因为单个氢键很弱，加热几十度就能把双螺旋拉开；因为氢键有数十亿个，完整的分子又是稳定的。特异性来自方向性，可逆性来自弱：这一设计贯穿整个分子识别。

::: quiz
谁的沸点更高，为什么？
- [x] $\mathrm{HF}$：分子间形成氢键，而$\mathrm{HCl}$只能依靠色散力和偶极-偶极力——这一反常压过了$\mathrm{HCl}$更大的可极化性。
- [ ] $\mathrm{HCl}$：氯比氟更易极化，色散力总是占上风。
- [ ] $\mathrm{HCl}$：其较大的偶极矩起主导作用。
- [ ] 两者几乎相等，因为$\mathrm{HF}$的氢键被$\mathrm{HCl}$更强的色散力抵消。
::: solution
$\mathrm{HF}$沸点$19.5\ \mathrm{^\circ C}$，$\mathrm{HCl}$沸点$-85\ \mathrm{^\circ C}$——相差$105\ \mathrm{K}$，这一方向对色散论证而言"错"了。在$\mathrm{HCl < HBr < HI}$系列内，色散力确实决定顺序，与可极化性的预言完全一致；$\mathrm{HF}$打破规律，是因为其分子通过$\mathrm{F-H\cdots F}$氢键缔合成链和环。色散力一般而言并不是"弱的那个"（见下文），但这里氢键比两个分子的色散差大若干倍，于是胜出。
:::
:::

## 力的竞争：沸点、溶解度与粘度

::: example 当色散力胜过了偶极 {#ex-chloromethanes}
氯甲烷的沸点：$\mathrm{CH_3Cl}$ $-24\ \mathrm{^\circ C}$（$\mu = 1.9\ \mathrm{D}$）、$\mathrm{CH_2Cl_2}$ $40\ \mathrm{^\circ C}$（$\mu = 1.6\ \mathrm{D}$）、$\mathrm{CHCl_3}$ $61\ \mathrm{^\circ C}$（$\mu = 1.0\ \mathrm{D}$）、$\mathrm{CCl_4}$ $76.7\ \mathrm{^\circ C}$（$\mu = 0$）（标准数据表值）。偶极矩*下降*，沸点却平滑上升。为什么？
::: solution
每个H被Cl取代都带走一点分子极性，却给分子表面添上十个电子和一个大而可极化的氯原子。开塞姆项是被温度稀释的小修正（$k_\mathrm{B}T$的一个分数），而色散力在每个接触上可加、随每个电子增大：从$\mathrm{CH_3Cl}$到$\mathrm{CCl_4}$，色散势阱的加深远超过取向势阱的变浅。这一教训可以推广："极性分子沸点更高"只适用于大小形状相近的*邻近*分子；一旦可极化性不同，色散力就压倒偶极。四氯化碳——完全非极性——沸点比氯甲烷高出一百开尔文。
:::
:::

::: example 乙醇为何与水混溶而己-1-醇几乎不溶 {#ex-solubility-water}
乙醇与水以任意比例混溶；己-1-醇$\mathrm{CH_3(CH_2)_5CH_2OH}$在$20\ \mathrm{^\circ C}$下每升水只溶解约$5.9\ \mathrm{g}$（标准数据表值）。而氯化钠溶于水却不溶于己烷。用分子间力分析这两个现象。
::: solution
溶解，就是用生成的溶质-溶剂吸引去替换被破坏的溶质-溶质与溶剂-溶剂吸引。乙醇的$\mathrm{O-H}$基与水之间既提供又接受氢键，两个碳的链代价很小；这笔交换几乎平衡，混合熵驱动过程达到完全混溶。己-1-醇有同样的头部却有六个碳的链：为了容纳它，水必须沿链长破坏氢键，并把它们重建成包围链的笼，而链只回报以微弱的色散力。溶解度极限——$5.9\ \mathrm{g\,L^{-1}}$除以$102.17\ \mathrm{g\,mol^{-1}}$得$0.058\ \mathrm{mol\,L^{-1}}$，约每千个水分子一个己醇分子——正是氢键记账不再划算之处。每增加一个$\mathrm{CH_2}$，溶解度约降为原来的三到四分之一：疏水效应不是一种新的力，而是一张付不起的氢键账单。氯化钠是同一本账、更大的数字：水的离子-偶极吸引（第一壳层每个水分子数十到数百$\mathrm{kJ\,mol^{-1}}$）几乎恰好偿付晶格焓——$\mathrm{Na^+}$与$\mathrm{Cl^-}$的水合合计释放约$780\ \mathrm{kJ\,mol^{-1}}$，而晶格焓为$+787\ \mathrm{kJ\,mol^{-1}}$，剩下的小额$+3.9\ \mathrm{kJ\,mol^{-1}}$由溶解熵补足（标准数据表值；循环见[[bonding-structure/ionic-bonding]]）。己烷只能提供色散力：没有任何东西付得起晶格账单，盐便沉在杯底，毫不溶解。
:::
:::

::: example 表面张力与粘度：同一张网络，两种感受 {#ex-surface-tension}
水在$20\ \mathrm{^\circ C}$的表面张力为$72.8\ \mathrm{mN\,m^{-1}}$，己烷约$18\ \mathrm{mN\,m^{-1}}$；水的粘度为$1.00\ \mathrm{mPa\,s}$，己烷$0.30\ \mathrm{mPa\,s}$，而丙三醇（甘油）$\mathrm{HOCH_2CH(OH)CH_2OH}$达到约$1.4\ \mathrm{Pa\,s}$（标准数据表值）。解释。
::: solution
表面张力是把一个分子从体相移到表面所需的能量代价——在表面它失去约一半邻居；粘度则是分子相互滑过时受到的拖曳。两者都随分子间势阱的深度与连通性而变。己烷分子只靠色散力结合，所以两个数值都很小。要创造表面或让流动发生，都必须局部破坏水的氢键网络，使两者提高三到四倍。丙三醇每个分子带三个$\mathrm{O-H}$基：它提供并接受一个稠密的三维氢键网络，由此产生的拖曳约为水的一千四百倍——一种糖浆。这一模式是普遍的：粘度与表面张力，是本章一直在校准的那台分子尺度仪器在宏观上的读数。
:::
:::

::: warning 关于"弱"力的三个误解 {#warn-dispersion-weak}
**氢键不是共价键。**它们弱十到二十倍，不计入化合价，也不改变分子的身份——尽管它们也并非纯静电的，而带有一小部分部分共价（电荷转移）成分。把它叫作"键"，学生就会开始把$\mathrm{O-H}$键画到错误的原子上；诚实的名称是强的、有方向性的分子间*相互作用*。**色散力不是"弱的那个"。**它是非极性粒子中唯一的力，在接触面积上可加，对大的可极化体系它支配一切：把石蜡晶体凝聚在一起的是色散力，让壁虎刚毛凭十亿个点接触抓住玻璃的是色散力，使DNA碱基堆叠的也是色散力。开塞姆项与德拜项通常才是小的。**"极性意味着沸点更高"在色散力不同时失效。**[[#ex-chloromethanes]]中的氯甲烷随偶极缩小沸点反而升高；在把功劳归于偶极之前，务必比较大小与可极化性相当的分子。
:::

::: history
范德华（van der Waals）在其1873年的博士论文中首次定量表达了"分子占有体积且相互吸引"，在理想气体方程中加入压强修正$a$与体积修正$b$——这条至今以他名字命名的状态方程为他赢得了1910年的诺贝尔物理学奖。各个具体的力则在等待偶极概念：开塞姆（Keesom）在1912年导出了转动偶极之间的取向力；德拜（Debye）——他在1912–1920年关于极性分子与偶极矩的工作确立了诱导作用、并赋予极性分子以现代含义——在1920年给出了诱导力。最后也是最具普适性的成员由量子力学带来：1930年，伦敦（London）证明两个闭壳层电子云的关联涨落以正比于极化率与电离能、反比于$r^{6}$的能量相互吸引——解释了氦为何能够液化，并给了色散力它的名字和公式。整个家族如今作为同一个静电学的故事连成一体——这个故事由四篇论文、跨越五十七年讲完。
:::

## 后续内容

这里描述的氢键网络，正是凝固成冰的开放晶格——冰是[[bonding-structure/solid-structures]]中列举的**分子晶体**之一；那一章还将说明色散力如何使固体碘和干冰又软又易挥发。蒸气压、蒸发与混合的热力学将在[[general-chemistry-2/liquids-solutions]]中定量展开。全章调用的分子偶极建立在分子形状与键极性之上——键偶极的矢量相加在[[bonding-structure/vsepr]]中展开，部分电荷背后的电负性差异在[[general-chemistry-1/periodicity]]。溶解度那里离子-偶极对抗晶格焓的论证，与[[bonding-structure/ionic-bonding]]的玻恩-哈伯记账首尾闭合。

::: summary
- 分子间力作用于分子之间，强度为共价键的1–10 %；它们决定熔点和沸点、物质状态、溶解度、粘度与表面张力。
- 伦敦色散——瞬时关联偶极，$U \propto -\alpha_1\alpha_2 I/r^{6}$——无处不在，总是吸引，随可极化性与电子数增大，并在接触面积上可加，所以分子形状至关重要。
- 永久偶极之间的开塞姆取向力平均后几乎为零，留下正比于$-\mu_1^2\mu_2^2/(k_\mathrm{B}T r^{6})$的残余；德拜诱导力作用于偶极与诱导偶极之间。两者通常都低于$2\ \mathrm{kJ\,mol^{-1}}$。
- 氢键（$\mathrm{X-H\cdots Y}$，X = N、O、F；10–40 $\mathrm{kJ\,mol^{-1}}$，有方向性）使$\mathrm{H_2O}$、$\mathrm{HF}$和$\mathrm{NH_3}$远高于其氢化物趋势线，使冰浮起，并编码DNA的碱基配对。
- 离子-偶极力是非共价相互作用中最强的，解释了为什么溶解盐的是水而不是己烷。
- 比较沸点靠数力：色散力（大小、形状、接触面积），然后偶极项，然后氢键提供体与接受体——在把功劳归于偶极之前，先确认色散力相当。
:::

## 练习

::: exercise 稀有气体阶梯 {level=1}
稀有气体的沸点：He $-268.9\ \mathrm{^\circ C}$、Ne $-246.0\ \mathrm{^\circ C}$、Ar $-185.8\ \mathrm{^\circ C}$、Kr $-153.2\ \mathrm{^\circ C}$、Xe $-108.1\ \mathrm{^\circ C}$、Rn $-61.6\ \mathrm{^\circ C}$（标准数据表值）。它们沿族单调升高。这些原子可用的唯一分子间力是什么？它为什么增大？
::: solution
色散力，别无其他：稀有气体原子是球形、非极性、闭壳层的，没有偶极也没有氢键。沿族向下原子电子增多，外层离核更远、受屏蔽更多，极化率$\alpha$急剧攀升；由于$U_\mathrm{disp} \propto -\alpha^{2}I/r^{6}$，每一步都加深势阱、抬高沸点。氦的势阱浅到只在绝对零度以上$4\ \mathrm{K}$沸腾——两个氦原子几乎完全拉不住对方。
:::
:::

::: exercise 卤化氢 {level=1}
将$\mathrm{HCl}$、$\mathrm{HBr}$、$\mathrm{HI}$与$\mathrm{HF}$按沸点从低到高排列，并解释前三者的顺序与第四者的位置。
::: solution
从低到高：$\mathrm{HCl}$（$-85\ \mathrm{^\circ C}$）$<$ $\mathrm{HBr}$（$-66\ \mathrm{^\circ C}$）$<$ $\mathrm{HI}$（$-35\ \mathrm{^\circ C}$）$<$ $\mathrm{HF}$（$19.5\ \mathrm{^\circ C}$）。四者都是极性的，但在$\mathrm{HCl}$–$\mathrm{HBr}$–$\mathrm{HI}$之内偶极矩相近而可极化性随卤素升高，所以色散力决定了它们的顺序。单看色散力，$\mathrm{HF}$本应是四者中*最低*的；它最高，是因为$\mathrm{F-H\cdots F}$氢键把液体缔合成链。趋势线上的一个离群点就是氢键的指纹——与$\mathrm{H_2O}$和$\mathrm{NH_3}$同样的特征。
:::
:::

::: exercise 指出主导的力 {level=1}
对每一对，指出主导的分子间力：(a) 两个$\mathrm{CH_4}$分子；(b) 两个$\mathrm{CH_3Cl}$分子；(c) 两个$\mathrm{HF}$分子；(d) 水中的$\mathrm{Na^+}$离子；(e) 溶于水的二甲醚。
::: solution
(a) 色散力——甲烷非极性。(b) 偶极-偶极力（开塞姆力），底下始终还有色散力。(c) 氢键，$\mathrm{F-H\cdots F}$。(d) 离子-偶极力——非共价相互作用中最强的，也是水合焓达数百$\mathrm{kJ\,mol^{-1}}$的原因。(e) 氢键：水提供，醚的氧孤对接受——二甲醚无法向自身提供氢键，却可以做水的网络的客人，这就是它相当易溶的原因。
:::
:::

::: exercise 新戊烷悖论 {level=2}
新戊烷（2,2-二甲基丙烷）的沸点比正戊烷*低*$27\ \mathrm{K}$，熔点却是$-16.5\ \mathrm{^\circ C}$，比正戊烷（$-129.7\ \mathrm{^\circ C}$）*高*约$113\ \mathrm{K}$（标准数据表值）。调和这两个事实。
::: solution
沸腾与熔化度量的是不同的东西。沸腾只需逃出液体，而液体中的吸引由接触面积决定——紧凑、近球形的新戊烷与邻居接触很弱，所以沸点低。熔化则要求*挤进晶体*：固体的晶格焓取决于分子堆积的效率，而新戊烷近球形的对称性使它能在格点上几乎自由旋转，同时以惊人的效率堆积（它形成塑性晶体）。对称的陀螺付出的熔化熵异常之小，建成的晶体却异常稳定。接触面积支配沸腾；堆积支配熔化；新戊烷是两者打架的教科书案例。
:::
:::

::: exercise 两个反常，各一段 {level=2}
定量解释每种情形中是什么打破了趋势：(a) $\mathrm{HF}$的沸点比$\mathrm{HCl}$高$105\ \mathrm{K}$，尽管$\mathrm{HCl}$是更可极化的分子；(b) $\mathrm{CCl_4}$（$\mu = 0$）的沸点比$\mathrm{CH_3Cl}$（$\mu = 1.9\ \mathrm{D}$）高$101\ \mathrm{K}$。
::: solution
(a) $\mathrm{HF}$分子通过量级为$20$–$40\ \mathrm{kJ\,mol^{-1}}$的$\mathrm{F-H\cdots F}$氢键缔合；$\mathrm{HCl}$多出的色散（多34个电子）只值几$\mathrm{kJ\,mol^{-1}}$，所以氢键占主导，$\mathrm{HF}$在$19.5\ \mathrm{^\circ C}$沸腾，而$\mathrm{HCl}$在$-85\ \mathrm{^\circ C}$。(b) 偶极之差是一个远低于$k_\mathrm{B}T$的开塞姆项，但三个H被Cl取代添上三十个电子和三个大而可极化的氯表面：在接触上可加的色散力增长得远多于取向项的缩小。(a)中一个特定的强相互作用胜过了色散力；(b)中色散力胜过了一个特定的弱相互作用。这一对例子是整个排序方法的缩影：列举各力，估计大小，让最大项裁决。
:::
:::

::: exercise 读伦纳德-琼斯势阱 {level=2 check="1.12"}
对势$U(r) = 4\varepsilon\left[(\sigma/r)^{12} - (\sigma/r)^{6}\right]$在$r = r_\mathrm{m}$处取极小值。求比值$r_\mathrm{m}/\sigma$，并给出$r_\mathrm{m}$处的势阱深度。（$r_\mathrm{m}/\sigma$保留两位小数输入。）
::: solution
令$\mathrm{d}U/\mathrm{d}r = 4\varepsilon\left[-12\sigma^{12}r^{-13} + 6\sigma^{6}r^{-7}\right] = 0$，得$2\sigma^{6} = r^{6}$，即$r_\mathrm{m} = 2^{1/6}\sigma = 1.12\,\sigma$。在极小值处$U(r_\mathrm{m}) = 4\varepsilon\left(\tfrac14 - \tfrac12\right) = -\varepsilon$：势阱深度恰为$\varepsilon$，而$\sigma$本身是势能的*零点*，不是接触距离。接触距离比$\sigma$大$12\ \%$——这是六次方根效应，所以读图时值得把两个定义分清。
:::
:::

::: exercise 氢键有多强？ {level=3}
水在$\mathrm{373\ K}$的汽化焓为$40.7\ \mathrm{kJ\,mol^{-1}}$，在$\mathrm{273\ K}$的熔化焓为$6.01\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）。利用"液态水平均每个分子约两个氢键"以及"恒压汽化还要对抗大气做$pV$功"这两个结构事实，用两种方法估算平均氢键能并比较。
::: solution
路线一：汽化几乎破坏全部氢键。恒压下$\Delta_\mathrm{vap}H$的一部分是$pV$功：一摩尔液体变成一摩尔蒸气时$\Delta n_\mathrm{gas}RT \approx RT = 3.1\ \mathrm{kJ\,mol^{-1}}$，剩下约$37.6\ \mathrm{kJ\,mol^{-1}}$的热力学能代价。每个分子断两个键，即每个键$37.6/2 \approx 19\ \mathrm{kJ\,mol^{-1}}$。路线二：冰熔化只破坏网络的一部分——量热与衍射一致给出熔化时约$15\ \%$的氢键消失——所以$6.01\ \mathrm{kJ\,mol^{-1}} \approx 0.15 \times 2 \times E_\mathrm{HB}$，得$E_\mathrm{HB} \approx 20\ \mathrm{kJ\,mol^{-1}}$。两条独立路线在$5\ \%$内一致，这正是对每个水的氢键引用"约$20\ \mathrm{kJ\,mol^{-1}}$"的诚实依据。注意这一估算的假设——熔化只断一小部分且已知的键、蒸气基本无氢键——以及这两个假设都已被光谱与衍射独立检验。
:::
:::

::: exercise 排列 $\mathrm{C_4H_{10}O}$ 异构体的沸点 {level=3}
$\mathrm{C_4H_{10}O}$的异构体沸点：丁-1-醇$117.7\ \mathrm{^\circ C}$；2-甲基丙-1-醇$108\ \mathrm{^\circ C}$；丁-2-醇$99.5\ \mathrm{^\circ C}$；2-甲基丙-2-醇$82.2\ \mathrm{^\circ C}$；乙氧基乙烷（二乙醚）$34.6\ \mathrm{^\circ C}$（标准数据表值）。完整解释这一顺序。
::: solution
五者摩尔质量相同，所以色散力只因形状而异，排序是一个氢键与接触面积的故事。四种醇都提供并接受氢键；醚没有$\mathrm{O-H}$、只能接受，于是退出网络，沸点比最低的醇还低$48\ \mathrm{K}$——二甲醚的教训重演。醇类内部，两种效应交织。支链使分子紧凑，削减色散的接触面积：丁-1-醇（直链）$>$ 2-甲基丙-1-醇（支链）。而*拥挤*的$\mathrm{O-H}$提供氢键的本领较差：羟基埋在三碳（叔碳）上（2-甲基丙-2-醇）使它难以接近接受体，仲醇丁-2-醇居中。观察到的顺序——直链伯醇、支链伯醇、直链仲醇、支链叔醇——恰是这两种效应预言的排名：氢键定标尺，接触面积与位阻可及性定精细结构。
:::
