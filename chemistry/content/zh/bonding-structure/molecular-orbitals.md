把液态氧倒进一块强磁铁的两极之间，它并不会落下：淡蓝色的液体*悬挂*在磁极间的缝隙里，托住它的力与重力毫无关系，而与电子有关。磁铁排斥大多数液体；氧却被*吸进去*。现在去看[[bonding-structure/covalent-lewis]]中画出的 $\mathrm{O_2}$ 的路易斯结构：双键，每个氧上两对孤对电子——每个电子都配对了，而所有电子都配对的分子是*抗磁性*的——会被磁铁微弱排斥。这幅图预言的恰恰与烧杯里发生的相反。还有两个事实同样尖锐。氦双聚分子 $\mathrm{He_2}$ 并不存在：氦是单原子分子，怎样降温都不会在通常意义上得到 $\mathrm{He_2}$ 分子。然而 $\mathrm{He_2^+}$ ——同样的两个原子核、却*少*一个电子——却是一个真实存在的、有束缚的分子，解离能为 $2.8\ \mathrm{eV}$（$\approx 270\ \mathrm{kJ\,mol^{-1}}$，标准数据表值）。而 $\mathrm{H_2^+}$ 用*一个*电子就把两个质子结合在一起，这是任何电子对图像都无法描述的。这些失败都有同一个根源：路易斯结构以及[[bonding-structure/valence-bond]]中定域的电子对坚持认为电子属于*原子*，或者属于*两个原子之间的键*。**分子轨道理论**采取相反的观点：在分子中，单电子状态属于*整个分子*，同时伸展到所有原子核之上。该理论由洪特（Hund）与马利肯（Mulliken）于 1932 年建立（马利肯于 1966 年获得诺贝尔奖），用几行电子记账就解释了上述三个疑难——并交给你自八隅体以来化学中最有用的一套词汇：HOMO 与 LUMO。

## 分子轨道：属于整个分子的电子

从你已经信任的一件事出发：在原子中，电子占据轨道——具有确定能量的单电子波函数，按泡利原理两个两个地填入，与[[general-chemistry-1/quantum-atom]]中完全一样。分子不是原子，但它也是一群在*多个*原子核所产生的场中运动的电子，而$\mathrm{H_2^+}$的薛定谔方程——一个电子、两个质子——无需任何新的物理即可高精度求解。它的解是整个分子的轨道：电子并不"在"某一个质子上；它的波函数包围着两个质子。$\mathrm{H_2^+}$精确解的成功提示了对付一切更复杂问题的策略：给每个电子一个属于整个分子的轨道，再按你已经知道的规则填入这些轨道。

::: definition 分子轨道、LCAO、成键与反键 {#def-mo-lcao}
**分子轨道（MO）**是伸展于整个分子上的单电子波函数；分子的电子占据这些分子轨道，每个轨道两个电子、自旋相反，正如原子填充原子轨道一样。在**LCAO 近似**（原子轨道线性组合，linear combination of atomic orbitals）下，每个分子轨道都写成原子轨道之和 $\psi = \sum_i c_i \phi_i$。两个原子轨道组合时，恰好给出两个分子轨道：

- **成键分子轨道**，即*和* $\psi_+ = \psi_\mathrm{A} + \psi_\mathrm{B}$：相长干涉使核间电子密度*增大*，轨道能量位于母体原子轨道*之下*；
- **反键分子轨道**，即*差* $\psi_- = \psi_\mathrm{A} - \psi_\mathrm{B}$，加星号标记（$\sigma^*$、$\pi^*$）：相消干涉在**核间产生节面**，把密度从成键区域抽走，轨道能量位于母体轨道*之上*。

分子轨道按其对键轴的对称性标记：**$\sigma$**轨道关于键轴圆柱对称（由 s–s、s–p 与头对头 p–p 重叠构成），**$\pi$**轨道有一个含键轴的节面（肩并肩 p–p 重叠）；$\sigma$重叠强于$\pi$重叠，所以成键$\sigma$轨道比成键$\pi$轨道降低得更多，反键$\sigma^*$比$\pi^*$升高得更多。在*同核*双原子分子中，每个分子轨道还额外标记为**g**（偶，*gerade*，对键中心反演不变）或**u**（奇，*ungerade*，反演变号）：你将贯穿本章见到的那些符号——$\sigma_\mathrm{g}(2s)$、$\sigma_\mathrm{u}^*(2s)$、$\pi_\mathrm{u}(2p)$、$\sigma_\mathrm{g}(2p)$、$\pi_\mathrm{g}^*(2p)$、$\sigma_\mathrm{u}^*(2p)$——正是按这一语法读出的。
:::

这个模式——两列波耦合给出一个更低、一个更高的状态——根本不是化学的；它与两个耦合单摆、或[[quantum-chemistry/model-systems]]中箱中粒子的解是同一种数学。两个原子轨道，两个分子轨道：数目守恒，这条记账事实与后文一切结论同样承重。下图展示了位于相距 $1.6$ 个单位的两个核上的两个 1s 型轨道的两种组合，以及决定一切的两种概率密度。

我们凭什么说反键组合确实消耗能量，而不只是看起来不同？答案是一段值得完整做一遍的简短计算，因为它把上面的图像变成一条你可以倚靠的定理。

::: proof LCAO 组合的归一化，以及节面为何消耗能量 {#proof-lcao-normalisation}
设 $\psi_\mathrm{A}$ 与 $\psi_\mathrm{B}$ 是原子 A 与 B 上已归一化的原子轨道，令 $S = \int \psi_\mathrm{A}\psi_\mathrm{B}\,\mathrm{d}\tau > 0$ 为它们的**重叠积分**（相距很远时 $S = 0$，原子合并时 $S \to 1$）。对 $\psi_\pm = N_\pm(\psi_\mathrm{A} \pm \psi_\mathrm{B})$ 要求 $\int \psi_\pm^2\,\mathrm{d}\tau = 1$：
$$
1 = N_\pm^2 \left( \int \psi_\mathrm{A}^2 + \int \psi_\mathrm{B}^2 \pm 2\int \psi_\mathrm{A}\psi_\mathrm{B} \right) = N_\pm^2\,(2 \pm 2S)
\qquad\Longrightarrow\qquad
\psi_\pm = \frac{\psi_\mathrm{A} \pm \psi_\mathrm{B}}{\sqrt{2(1 \pm S)}} .
$$
注意其中已有的不对称：成键轨道被 $1/\sqrt{2(1+S)}$ **稀释**，反键轨道被 $1/\sqrt{2(1-S)}$ **浓缩**，因为差波函数在某处自我抵消、必须在别处补偿。

再看能量。在键的中点，由对称性 $\psi_\mathrm{A} = \psi_\mathrm{B}$，故 $\psi_- = 0$：反键组合在**两核之间有节面**，而 $\psi_+$ 在两核之间没有节点。被迫过零的波函数曲率很大，而曲率就是动能（$\hat{T} = -\hbar^2 2m^{-1} \nabla^2$）：把电子限制在更小的区域——节点所做的正是如此——会抬高它的动能，恰如箱中粒子的能级随 $n^2$ 升高。势能的取向与此一致：$\psi_-$ 把电子密度从核间区域抽走——那里的电子同时被**两个**核吸引——并把它堆到外侧表面，那里它屏蔽核与核、使核–核排斥不受屏蔽。两项朝同一方向变化，所以 $\psi_-$ 位于原子轨道之上而 $\psi_+$ 位于其下。定量地，取库仑积分 $\alpha = \int \psi_\mathrm{A} \hat{H} \psi_\mathrm{A}\,\mathrm{d}\tau < 0$ 与共振积分 $\beta = \int \psi_\mathrm{A} \hat{H} \psi_\mathrm{B}\,\mathrm{d}\tau < 0$，
$$
E_\pm = \frac{\alpha \pm \beta}{1 \pm S},
$$
由于 $\beta < 0$ 且 $S > 0$：$E_+ = (\alpha + \beta)/(1+S) < \alpha$，而 $E_- = (\alpha - \beta)/(1-S) > \alpha$。反键轨道升高之量**多于**成键轨道降低之量——记住这一点，因为它决定了当两者都被占据时会发生什么。
:::

各部件定义完毕，任何一张图的构造都是一套固定程序。

::: proposition 构造分子轨道图的规则 {#prop-mo-rules}
构造分子的分子轨道：

1. **能量匹配：**只组合能量相近的原子轨道。一个原子的 $1s$ 与其搭档的 $1s$ 配对，而不是与高出三个壳层的 $2p$ 配对。
2. **对称性匹配：**只组合净重叠为正的轨道。s 轨道与沿键方向指向的 p 轨道可以组合；s 轨道与取向不对的 p 轨道在正、负区域的重叠相等，组合结果*为零*（净重叠为零）。
3. **轨道数守恒：**$N$ 个原子轨道恰好给出 $N$ 个分子轨道——一半成键、一半反键（两轨道情形：一成一反）。
4. **填充：**按构造原理（先低后高）、泡利原理（每轨道两个电子、自旋相反）与**洪特规则**（简并轨道——$\pi_\mathrm{u}$ 对、$\pi_\mathrm{g}^*$ 对——先单独平行占据、再配对），用分子的电子占据分子轨道。
5. **排序：**在同一壳层构成的集合内，$\sigma$ 组合的分裂强于 $\pi$ 组合：$\sigma_\mathrm{g}$ 最低，$\sigma_\mathrm{u}^*$ 最高。（例外——当 $\pi_\mathrm{u}(2p)$ 落到 $\sigma_\mathrm{g}(2p)$ 之下时——是 s–p 混合，见下文。）

对于*异核*双原子分子，规则依然成立，但能量较低的原子轨道（电负性较大的原子）对成键分子轨道贡献更大，而电负性较小的原子对反键轨道贡献更大——这正是键的极性在这一语言中的来源。
:::

## 键级：成键电子与不帮忙的电子相抵

::: proposition 键级 {#prop-bond-order}
双原子分子的**键级**为
$$
\text{键级} = \frac{1}{2}\left( N_\text{成键} - N_\text{反键} \right),
$$
即成键分子轨道中的电子数减去反键分子轨道中的电子数，再除以二（每共享*一对*电子算一个键）。键级度量净的电子胶量：成键轨道中的一个电子降低能量，反键轨道中的一个电子抬高能量，键就是这场较量中剩下的部分。键级越大，键**越短、越强**——标准数据表值证实了这一点：$\mathrm{N_2}$ 键级为 $3$，键长 $110\ \mathrm{pm}$，解离能 $945\ \mathrm{kJ\,mol^{-1}}$，而 N–N *单*键（如肼中）约为 $145\ \mathrm{pm}$，仅约 $\sim 160\ \mathrm{kJ\,mol^{-1}}$；$\mathrm{O_2}$ 键级为 $2$，$121\ \mathrm{pm}$，$498\ \mathrm{kJ\,mol^{-1}}$，介于 $\mathrm{O_2}$ 的数值与 O–O 单键（$\sim 148\ \mathrm{pm}$、$\sim 146\ \mathrm{kJ\,mol^{-1}}$）之间。键级可以是**分数**——$\tfrac12$、$\tfrac12$、$1\!\tfrac12$、$2\!\tfrac12$ 都出现过——这是任何电子对图像都不允许的。
:::

::: example $\mathrm{H_2}$、$\mathrm{H_2^+}$、$\mathrm{He_2^+}$、$\mathrm{He_2}$：由算术决定存在与否 {#ex-h2-he2-series}
$\mathrm{H_2}$、$\mathrm{H_2^+}$、$\mathrm{He_2^+}$、$\mathrm{He_2}$ 中每一个都把电子填入由两个 $1s$ 轨道构成的两个分子轨道 $\sigma_\mathrm{g}(1s)$ 与 $\sigma_\mathrm{u}^*(1s)$。给出各自的键级与磁学行为，并判断哪些存在。
::: solution
- $\mathrm{H_2}$：两个电子，都在 $\sigma_\mathrm{g}$：排布 $(\sigma_\mathrm{g})^2$，键级 $\tfrac12(2-0) = 1$，全部配对（抗磁性）。存在，$436\ \mathrm{kJ\,mol^{-1}}$。
- $\mathrm{H_2^+}$：一个电子：$(\sigma_\mathrm{g})^1$，键级 $\tfrac12(1-0) = \tfrac12$，一个未成对电子（顺磁性）。存在，$D_0 \approx 2.7\ \mathrm{eV} \approx 260\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）——成键轨道中的*一个*电子就足以把两个质子结合住。键级只有一半，键能却超过 $\mathrm{H_2}$ 的一半：第二个电子通过电子–电子排斥部分抵消了第一个电子的结合。
- $\mathrm{He_2^+}$：三个电子：$(\sigma_\mathrm{g})^2(\sigma_\mathrm{u}^*)^1$，键级 $\tfrac12(2-1) = \tfrac12$，顺磁性。**存在**——$2.8\ \mathrm{eV} \approx 270\ \mathrm{kJ\,mol^{-1}}$，在质谱仪中早已知晓——尽管它比 $\mathrm{H_2}$ 有*更多*的电子，因为其中一个坐在反键轨道里，抵消了一半的胶量。
- $\mathrm{He_2}$：四个电子：$(\sigma_\mathrm{g})^2(\sigma_\mathrm{u}^*)^2$，键级 $\tfrac12(2-2) = 0$。**没有化学键。**因为反键轨道升高之量大于成键轨道降低之量（[[#proof-lcao-normalisation]]），把两者都填满后，这一对原子的能量略*高于*分离原子：氦保持单原子。（在毫开尔文温度下存在极弱的范德华双聚体——那是另一种弱得多的机制，[[bonding-structure/intermolecular-forces]]。）

添上两个电子，失去一个键级，湮灭一个分子：成键电子减反键电子的算术复现了元素周期表中最不近人情的一个事实。
:::
:::

## 第二周期同核双原子分子——以及 s–p 混合开关

从 Li$_2$ 到 $\mathrm{Ne_2}$，价层提供八个原子轨道（每个原子一个 $2s$、三个 $2p$），给出十六个分子轨道；对价电子真正重要的，只是由 $2s$ 与 $2p_z$ 构成的八个（$\sigma$ 组）和由 $2p_x, 2p_y$ 构成的四个（两个简并的 $\pi_\mathrm{u}$ 成键轨道与两个 $\pi_\mathrm{g}^*$ 反键轨道）。朴素的排序把 $\sigma_\mathrm{g}(2p)$ 放在 $\pi_\mathrm{u}(2p)$ 之下，因为 $\sigma$ 重叠更强。现实却把第二周期劈成两半，而其理由是一段漂亮的量子力学。

::: proposition s–p 混合开关 {#prop-sp-mixing}
$\sigma_\mathrm{g}(2s)$ 与 $\sigma_\mathrm{g}(2p)$ 轨道具有*相同的对称性*，因此它们不能相安无事地并存：如同两个同对称性的能级相互靠近，它们**相互排斥、彼此推开**（两者之间的混合在能量接近时最强）。$\sigma_\mathrm{g}(2p)$ 被推高，$\sigma_\mathrm{u}^*(2s)$ 被压低。沿第二周期从左到右，自由原子的 $2s$–$2p$ 能量间隔*增大*（屏蔽不良的 $2p$ 电子比 $2s$ 被拉得更紧）：

- **$\mathrm{Li_2}$ 到 $\mathrm{N_2}$：**$2s$–$2p$ 间隔小，混合强，$\sigma_\mathrm{g}(2p)$ 被推到 $\pi_\mathrm{u}(2p)$ *之上*。排序：$\sigma_\mathrm{g}(2s) < \sigma_\mathrm{u}^*(2s) < \pi_\mathrm{u}(2p) < \sigma_\mathrm{g}(2p) < \pi_\mathrm{g}^*(2p) < \sigma_\mathrm{u}^*(2p)$。
- **$\mathrm{O_2}$、$\mathrm{F_2}$：**间隔大，混合弱，朴素排序成立：$\sigma_\mathrm{g}(2p) < \pi_\mathrm{u}(2p)$。

这个开关不是细节：它决定了 $\mathrm{B_2}$、$\mathrm{C_2}$、$\mathrm{N_2}$、$\mathrm{O_2}$、$\mathrm{F_2}$ 中哪些是顺磁性的，而且是本课程中电子排布出错的最常见单一来源。
:::

::: example $\mathrm{O_2}$：凯旋——为什么液态氧悬在磁铁里 {#ex-o2-magnetism}
画出 $\mathrm{O_2}$（12 个价电子）的分子轨道图，并预言它的磁学行为。
::: solution
氧位于周期右侧，采用*未混合*的排序 $\sigma_\mathrm{g}(2s) < \sigma_\mathrm{u}^*(2s) < \sigma_\mathrm{g}(2p) < \pi_\mathrm{u}(2p) < \pi_\mathrm{g}^*(2p) < \sigma_\mathrm{u}^*(2p)$。填入 12 个电子：$(\sigma_\mathrm{g}2s)^2 (\sigma_\mathrm{u}^*2s)^2 (\sigma_\mathrm{g}2p)^2 (\pi_\mathrm{u}2p)^4$ 用去 10 个；最后两个进入简并的 $\pi_\mathrm{g}^*$ 对，而**洪特规则**把它们以平行自旋放进*不同*的轨道：$(\pi_\mathrm{g}^*)^1 (\pi_\mathrm{g}^*)^1$。

键级 $= \tfrac12(8 - 4) = 2$——路易斯的双键被重新得到。但排布以*两个未成对电子*结尾：$\mathrm{O_2}$ 是**顺磁性**的，磁场会把它吸进去。路易斯结构说不出这一点；[[bonding-structure/valence-bond]]的两个电子对图像给出全配对的 $\mathrm{O_2}$、预言抗磁性——错了。分子轨道理论*解释*了氧的磁性——这一磁性自 1845 年即被观测到，当年法拉第（Faraday）发现氧气被强磁场吸入磁场（而在气体可以被液化之后，又发现液态氧悬挂于磁极之间）——且为一切电子对结构所无法解释——而它所指认的基态（*三重态*，两个平行自旋）正是普通 $\mathrm{O_2}$ 具有 EPR 活性（[[spectroscopy/epr]]）、且其与全配对分子的直接反应因自旋而变慢的原因。悬挂在磁极之间的液态氧，是分子轨道理论被拍摄最多的证明。
:::

::: example $\mathrm{N_2}$ 与 CO：键级三，以及一只有主意的孤对电子 {#ex-n2-co}
画出 $\mathrm{N_2}$（10 个价电子）与 CO 的分子轨道排布，并解读它们的键长（$110$ 与 $113\ \mathrm{pm}$）与解离能（$945$ 与 $1076\ \mathrm{kJ\,mol^{-1}}$，标准数据表值）。为什么一氧化碳通过*碳*与血红蛋白的铁结合？
::: solution
氮位于混合一侧：$\pi_\mathrm{u}(2p)$ 低于 $\sigma_\mathrm{g}(2p)$。十个电子：$(\sigma_\mathrm{g}2s)^2 (\sigma_\mathrm{u}^*2s)^2 (\pi_\mathrm{u}2p)^4 (\sigma_\mathrm{g}2p)^2$。键级 $= \tfrac12(8-2) = 3$：叁键——一个 $\sigma$ 加两个 $\pi$——所有电子配对（抗磁性），与 $110\ \mathrm{pm}$ 以及使氮气惰性的高得惊人的 $945\ \mathrm{kJ\,mol^{-1}}$ 相符。

CO 有同样的十个价电子，与 $\mathrm{N_2}$ **等电子**：键级 $3$，$113\ \mathrm{pm}$，解离能甚至*更高*（$1076\ \mathrm{kJ\,mol^{-1}}$，常见双原子分子中最强的键）。区别在于不对称：氧的较低能量轨道主导成键分子轨道，于是 HOMO——路易斯会称为碳的孤对的那个 $\sigma$ 轨道——较大的瓣**在碳上**。因此 CO 通过碳把这一对电子交给 Fe（同时 Fe 向空的 $\pi^*$ 轨道回授，这就是 CO 与血红素的结合比 $\mathrm{O_2}$ 强约 200 倍的原因——正是同一套前线轨道使 CO 成为毒物）。
:::
:::

::: example $\mathrm{B_2}$：顺磁性作为开关的证据 {#ex-b2-paramagnetism}
用混合排序预言 $\mathrm{B_2}$（6 个价电子）的磁学行为，并解释为什么这一结果是 s–p 混合的*证据*。
::: solution
硼位于开关的最左端，混合最强：$\pi_\mathrm{u}(2p)$ *低于* $\sigma_\mathrm{g}(2p)$。六个电子：$(\sigma_\mathrm{g}2s)^2 (\sigma_\mathrm{u}^*2s)^2$ 之后余两个给简并的 $\pi_\mathrm{u}(2p)$ 对，洪特规则把它们各放一个：$(\pi_\mathrm{u})^1(\pi_\mathrm{u})^1$。键级 $\tfrac12(4-2) = 1$，而——要点在于——**两个未成对电子：$\mathrm{B_2}$ 是顺磁性的**。若朴素排序成立，最后两个电子会在 $\sigma_\mathrm{g}(2p)$ 中配对，$\mathrm{B_2}$ 将是抗磁性的。分子束实验发现的正是顺磁基态：一个六电子分子为两轨道的能量开关作证。（同样的计数使 $\mathrm{C_2}$，$(\pi_\mathrm{u})^4$，键级 $2$、抗磁性。）
:::
:::

::: example 氧系列：键级 $2\tfrac12$、2、$1\tfrac12$、1 {#ex-oxygen-series}
$\mathrm{O_2}$、$\mathrm{O_2^+}$、$\mathrm{O_2^-}$（超氧化物）与 $\mathrm{O_2^{2-}}$（过氧化物）只是在前线 $\pi_\mathrm{g}^*$ 轨道上得失电子而不同。预言它们的键级，并与实测键长 $112$、$121$、$128$ 与 $149\ \mathrm{pm}$（标准数据表值）比较。
::: solution
电离与还原都作用于 HOMO，即 $\pi_\mathrm{g}^*$ 对：

| 物种 | $\pi_\mathrm{g}^*$ 电子数 | 键级 | 键长 / pm |
|---|---|---|---|
| $\mathrm{O_2^+}$ | 1 | $\tfrac12(8-3) = 2.5$ | $112$ |
| $\mathrm{O_2}$ | 2 | $\tfrac12(8-4) = 2$ | $121$ |
| $\mathrm{O_2^-}$ | 3 | $\tfrac12(8-5) = 1.5$ | $128$ |
| $\mathrm{O_2^{2-}}$ | 4 | $\tfrac12(8-6) = 1$ | $149$ |

移走一个*反键*电子使键更强、更短（$\mathrm{O_2^+}$：键级 $2.5$，$D = 643\ \mathrm{kJ\,mol^{-1}}$，而 $\mathrm{O_2}$ 为 $498$）；加入反键电子使键更弱、更长，一直延伸到 $\mathrm{Na_2O_2}$ 的过氧单键与 $\mathrm{H_2O_2}$ 的 O–O 连接。四种物种，一条轨道，键长随半整数计数亦步亦趋——正是这种定量吻合使分子轨道理论成为理论，而非一种画图约定。
:::
:::

::: warning 一段话里的三个陷阱 {#warn-sp-mixing}
第一是排序开关：$\mathrm{B_2}$、$\mathrm{C_2}$ 与 $\mathrm{N_2}$ 把 $\pi_\mathrm{u}(2p)$ 放在 $\sigma_\mathrm{g}(2p)$ *之下*；$\mathrm{O_2}$ 与 $\mathrm{F_2}$ 则相反（[[#prop-sp-mixing]]）。考试就在这个接缝上出题——在填入任何一支箭头*之前*先确定你在开关的哪一侧。第二，分子轨道理论并不废除八隅体，而是**重新推导**它：对 $\mathrm{O_2}$、$\mathrm{N_2}$ 及其同类，价层的成键分子轨道恰好是四条轨道，八个电子恰好填满它们——路易斯的八个电子从记账升格为定理（带着同样诚实的例外：奇电子分子就是奇数）。第三，"反键被占据"不等于"键已断裂"：$\mathrm{He_2^+}$ 有一个反键电子而依然存在，$\mathrm{O_2}$ 还带着两个。一个反键电子*抵消半个键*，仅此而已——键级算的是净值，只有键级 $0$ 才意味着无键。
:::

## HOMO 与 LUMO：化学反应发生之处

::: definition 前线轨道：HOMO 与 LUMO {#def-homo-lumo}
**最高占据分子轨道（HOMO）**是容纳分子中束缚最弱电子的轨道；**最低未占分子轨道（LUMO）**是紧邻其上的空轨道。两者合称**前线轨道**。HOMO 是电子离开的地方：第一电离能（在库普曼斯定理的近似下）等于 HOMO 能量的负值——这就是为什么电离 $\mathrm{O_2}$ 移走的是一个反键 $\pi_\mathrm{g}^*$ 电子、从而*增强*键（[[#ex-oxygen-series]]）。LUMO 是分子被还原或被亲核试剂进攻时电子到达的地方，而 HOMO–LUMO 间隔就是分子第一电子吸收的能量——颜色的来源，详见[[spectroscopy/electronic-spectroscopy]]。
:::

前线词汇的小小代价会带来数倍回报。$\mathrm{N_2}$ 的 HOMO 是一条被紧紧夹在两个氮原子之间、能量很深、难以给出的 $\sigma_\mathrm{g}$ 轨道，这是氮气惰性的原因之一；CO 的 HOMO 是[[#ex-n2-co]]中碳权重较大的 $\sigma$ 轨道，这是 CO 不惰性的原因之一。烯烃或羰基的 $\pi^*$ LUMO 是亲核试剂瞄准的目标；碘 $\mathrm{I_2}$ 的 HOMO–LUMO 间隔很小，其第一吸收落在可见区、蒸气呈紫色，而 $\mathrm{N_2}$ 的巨大间隔把它的吸收推到远紫外、气体无色。当你日后遇到有机化学的弯箭头机理时，你移动的正是这些轨道之间的电子。

::: history
海特勒（Heitler）与伦敦（London）在 1927 年通过处理*共享于*两原子之间的电子的 $\mathrm{H_2}$，开创了化学键的量子理论——这一图像发展为价键理论。分子轨道的替代方案五年后到来：1932 年洪特（Hund）按电子绕核间轴的角动量对分子中电子的状态分类，即 $\sigma$/$\pi$ 记账之下的 $\Sigma$、$\Pi$、$\Delta$ 标记；同年马利肯（Mulliken）开始发表一系列论文，由原子轨道构造分子轨道、引入了"轨道"（orbital）一词本身，并预言了分数键级；马利肯因分子轨道理论的这项工作获得 1966 年诺贝尔化学奖。第三个声音是莱纳德-琼斯（Lennard-Jones），他在 1929 年证明伸展于整个分子上的轨道可以解释定向价键——即价层电子对互斥理论所罗列的那些形状——当时两个对手都尚未完全成形。到三十年代末，两种对立的图像，定域电子对与离域轨道，被承认为同一方程的互补近似，这一休战至今仍在组织化学的语言。
:::

## 后续内容

让分子长大：固体是一个阿伏加德罗常数大小的分子，它的分子轨道密集到合并为能带——这正是[[bonding-structure/metallic-bonding]]的全部内容，也是本课时最后一章要讲导线的原因。这里所做的近似（LCAO、一个电子在其余粒子所产生的场中运动）将在[[quantum-chemistry/chemical-bond-qm]]中接受认真检验，而同样思想用于 $\pi$ 体系、施于苯及一切芳香族的版本在[[quantum-chemistry/huckel-theory]]。g/u 标记与哪些轨道可以混合的对称性规则，是[[quantum-chemistry/molecular-symmetry]]群论的特例。HOMO–LUMO 间隔作为吸收见[[spectroscopy/electronic-spectroscopy]]，$\pi^*$ 轨道中的未成对电子则是[[spectroscopy/epr]]的主题。

::: summary
- 分子轨道属于整个分子；两个原子轨道给出两个分子轨道——成键组合（核间密度，能量较低）与反键组合（核间节面，能量较高），用重叠积分 $S$ 归一化。
- 作图时匹配能量与对称性、守轨道数、按构造原理、泡利与洪特填充。
- 键级 $= \tfrac12(N_\text{成键} - N_\text{反键})$；键级越高键越短越强，分数键级（$\mathrm{H_2^+}$、$\mathrm{He_2^+}$、$\mathrm{O_2^+}$）真实存在。
- $\mathrm{He_2}$ 不存在（键级 $0$）而 $\mathrm{He_2^+}$ 存在（$\tfrac12$）：反键电子抵消键，而不是删除键。
- s–p 混合在 $\mathrm{B_2}$–$\mathrm{N_2}$ 中把 $\sigma_\mathrm{g}(2p)$ 推到 $\pi_\mathrm{u}(2p)$ 之上，而在 $\mathrm{O_2}$、$\mathrm{F_2}$ 中不然——这个开关决定了谁是顺磁性的。
- $\mathrm{O_2}$ 的两个未成对 $\pi_\mathrm{g}^*$ 电子解释了它的顺磁性——这是路易斯结构做不出的预言——而氧系列 $\mathrm{O_2^+}/\mathrm{O_2}/\mathrm{O_2^-}/\mathrm{O_2^{2-}}$ 展示了以皮米读出的键级。
- HOMO 与 LUMO——前线轨道——控制电离、反应性与颜色。
:::

::: exercise 键级与磁性，四种情形 {level=1}
给出 $\mathrm{F_2}$、$\mathrm{Ne_2}$、$\mathrm{C_2}$ 与 $\mathrm{NO}$ 的价层分子轨道排布、键级与磁学行为（NO 按 $\mathrm{O_2}$ 一侧的排序处理；它有 11 个价电子）。
::: solution
$\mathrm{F_2}$（14 个价电子）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2(\sigma_\mathrm{g}2p)^2(\pi_\mathrm{u}2p)^4(\pi_\mathrm{g}^*2p)^4$，键级 $\tfrac12(8-6) = 1$，抗磁性——即 $\mathrm{F}$–$\mathrm{F}$ 的单键（$141\ \mathrm{pm}$，$159\ \mathrm{kJ\,mol^{-1}}$）。$\mathrm{Ne_2}$（16）：每个价层分子轨道全满，键级 $\tfrac12(8-8) = 0$——不存在。$\mathrm{C_2}$（8，混合排序）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2(\pi_\mathrm{u}2p)^4$，键级 $2$，抗磁性。$\mathrm{NO}$（11）：与少一个电子的 $\mathrm{O_2}$ 一样以 $(\pi_\mathrm{g}^*)^1$ 结尾：键级 $\tfrac12(8-3) = 2.5$，**顺磁性**——与其略短而强的键（$115\ \mathrm{pm}$，$631\ \mathrm{kJ\,mol^{-1}}$，介于 N=O 与 N≡O 之间）相符。
:::

::: exercise 超氧化物的键级 {level=1 check="1.5"}
超氧化钾 $\mathrm{KO_2}$ 含 $\mathrm{O_2^-}$ 离子。给出 $\mathrm{O_2^-}$ 的键级。（以小数输入键级。）
::: solution
$\mathrm{O_2^-}$ 有 13 个价电子：比 $\mathrm{O_2}$ 多一个，进入反键的 $\pi_\mathrm{g}^*$ 组。键级 $= \tfrac12(8 - 5) = 1.5$。实测 O–O 键长 $128\ \mathrm{pm}$，正落在 $\mathrm{O_2}$（$121\ \mathrm{pm}$）与过氧化物（$149\ \mathrm{pm}$）之间，恰如一个半键所预言。
:::

::: exercise 氮的正离子 {level=1 check="2.5"}
$\mathrm{N_2}$ 的第一电离从 $\sigma_\mathrm{g}(2p)$ HOMO 移走一个电子。给出 $\mathrm{N_2^+}$ 的键级。（以小数输入键级。）它是顺磁性的吗？
::: solution
键级 $= \tfrac12(7-2) = 2.5$：一个电子是从*成键*轨道移走的，所以键相对 $\mathrm{N_2}$ 变弱、变长（$110 \to 112\ \mathrm{pm}$）——这与 $\mathrm{O_2}$ 电离时的情形相反，后者电子离开的是*反键*轨道、键因而增强（[[#ex-oxygen-series]]）。$\sigma_\mathrm{g}$ 中余下一个电子，$\mathrm{N_2^+}$ 是顺磁性的。
:::
:::

::: exercise 氰离子，等电子家族 {level=2 check="3"}
$\mathrm{CN^-}$ 与 $\mathrm{N_2}$、CO 一样有 10 个价电子。写出它的价层分子轨道排布，给出键级，并预言其 C–N 距离更接近单键（$\sim 147\ \mathrm{pm}$）、双键（$\sim 128\ \mathrm{pm}$）还是叁键（$\sim 116\ \mathrm{pm}$）。（输入键级。）
::: solution
混合排序（碳、氮一侧，与 $\mathrm{N_2}$ 相同）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2(\pi_\mathrm{u}2p)^4(\sigma_\mathrm{g}2p)^2$。键级 $= \tfrac12(8-2) = 3$：叁键，抗磁性，所有轨道配对。C–N 距离应与叁键一族为伍——实测约 $115$–$116\ \mathrm{pm}$，基本是 CO/N₂ 的地盘。HOMO 是碳权重的 $\sigma$ 轨道，这就是氰化物与 CO 一样通过碳与血红素铁结合的原因。
:::

::: exercise NO 对阵 NO⁺ {level=2}
NO 有 11 个价电子；NO⁺ 有 10 个。预言谁的 N–O 键更短更强，并说明电离时磁性如何变化。实测值：$115\ \mathrm{pm}$、$631\ \mathrm{kJ\,mol^{-1}}$ 与 $106\ \mathrm{pm}$、$1025\ \mathrm{kJ\,mol^{-1}}$（标准数据表值）。
::: solution
NO 的第十一个电子占据反键的 $\pi_\mathrm{g}^*$ 轨道；把它移走形成 $\mathrm{NO^+}$ 会把键级从 $2.5$ *提高*到 $3$（与 CO、$\mathrm{N_2}$ 等电子）。所以 $\mathrm{NO^+}$ 必有更短更强的键——数据同意（$106\ \mathrm{pm}$ 对 $115\ \mathrm{pm}$；$1025$ 对 $631\ \mathrm{kJ\,mol^{-1}}$）。磁性：NO 顺磁（一个未成对电子）；$\mathrm{NO^+}$ 全部配对，抗磁。注意与 $\mathrm{N_2} \to \mathrm{N_2^+}$ 的对照：那里电离移走的是*成键*电子、键变弱：变化的方向告诉你 HOMO 是哪一类轨道。
:::

::: exercise 开关生效之处 {level=2}
对每种物种用 s–p 混合开关的正确一侧，给出 $\mathrm{Be_2}$、$\mathrm{B_2^+}$ 与 $\mathrm{N_2^{2-}}$ 的价层排布与磁学行为，并指出你预计哪些键级为零、不结合。
::: solution
$\mathrm{Be_2}$（4 个价电子）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2$，键级 $0$——不结合，与 $\mathrm{He_2}$ 一样；金属铍以另一种方式成键（[[bonding-structure/metallic-bonding]]）。$\mathrm{B_2^+}$（5）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2(\pi_\mathrm{u}2p)^1$——键级 $\tfrac12(3-2) = 0.5$，顺磁（一个 $\pi$ 电子；$\mathrm{B_2}$ 本身有两个）。$\mathrm{N_2^{2-}}$（12，混合排序）：$(\sigma_\mathrm{g}2s)^2(\sigma_\mathrm{u}^*2s)^2(\pi_\mathrm{u}2p)^4(\sigma_\mathrm{g}2p)^2(\pi_\mathrm{g}^*2p)^2$——键级 $\tfrac12(8-4) = 2$，且两个电子分处不同的 $\pi_\mathrm{g}^*$ 轨道，顺磁；它与 $\mathrm{O_2}$ 等电子，并共享其磁性。只有 $\mathrm{Be_2}$ 键级为零。
:::

::: exercise 成键与反键的不对称性 {level=3}
利用[[#proof-lcao-normalisation]]的 $E_\pm = (\alpha \pm \beta)/(1 \pm S)$，证明反键能级高于 $\alpha$ 之量*大于*成键能级低于 $\alpha$ 之量，并由该不等式推出当两条轨道都被占据时双电子键的能量如何变化——即 $\mathrm{He_2}$ 情形。
::: solution
降低量为 $\alpha - E_+ = \alpha - \frac{\alpha+\beta}{1+S} = \frac{-\alpha S - \beta}{1+S}$，升高量为 $E_- - \alpha = \frac{\alpha-\beta}{1-S} - \alpha = \frac{-\alpha S - \beta}{1-S}$。两式分子相同且为正（因 $\alpha < 0$、$\beta < 0$、$S > 0$），而 $1-S < 1+S$，故升高量大于降低量。现在用一对电子占据两条轨道：净移动为 $E_+ + E_- - 2\alpha = (\text{升高量}) - (\text{降低量}) > 0$。因此，双占据的成键轨道*加上*反键轨道位于分离原子*之上*——无键，甚至略有失稳。这就是 $\mathrm{He_2}$ 与 $\mathrm{Ne_2}$ 背后的定理：键级为零不只是"没有胶"，而是净损失，这就是满壳层原子之所以惰性的原因。（确实把稀有气体对结合起来的残余吸引来自涨落力，而非这些轨道——[[bonding-structure/intermolecular-forces]]。）
:::

::: exercise 两种理论，一烧杯氧气 {level=3}
画出 $\mathrm{O_2}$ 的路易斯结构与随之而来的价键描述，再画出分子轨道图。确切指出哪个可观测量区分两种理论、各自预言什么，以及为什么路易斯/价键图像的失败是*结构性*的，而非参数不佳的问题。
::: solution
路易斯：$\mathrm{O{=}O}$，每个氧上两对孤对电子——四个键、四对孤对、十六个电子，每一个都配对。基本形式的价键理论同意：由半满轨道重叠形成两个 $\sigma/\pi$ 键，所有电子配对。两者因此都预言 $\mathrm{O_2}$ 抗磁——被磁铁微弱*排斥*。分子轨道理论先填满 $\pi_\mathrm{u}(2p)^4$，然后按洪特规则把最后两个电子以平行自旋各放进一条简并的 $\pi_\mathrm{g}^*$：顺磁；而实验（悬挂的液体、磁化率、EPR 谱）说是顺磁，定量上恰为两个玻尔磁子的自旋。这一失败是结构性的，因为*两原子之间的对*的任何重排都不可能既留下两个未成对电子、又保持观测到的键级 $2$ 与键长 $121\ \mathrm{pm}$：路易斯计数本身就强制配对。出路——把电子激发成三重双自由基，或引入四中心键——所耗能量远大于它们换回的配对能。教训不是路易斯结构无用（它们把键级、键长趋势与化合价都说得完全正确），而是它们是*电子对的记账*，而氧的基态不是一种配对安排。当两种理论分歧时，数字是终审法庭——本课程的常设教训。
:::
