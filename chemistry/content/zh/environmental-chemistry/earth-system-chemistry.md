为什么你呼吸的空气中含有 $21\ \%$ 的氧气、$78\ \%$ 的氮气和仅约 $0.04\ \%$ 的二氧化碳，而由几乎相同的岩石构成的金星和火星，其大气却几乎完全由 $\mathrm{CO_2}$ 组成？为什么今天释放的一个甲烷分子大约能存活十年，一个水分子约九天，而过量的二氧化碳——在一个我们必须小心界定的意义上——却能持续几个世纪？又为什么大气中的氮至今仍在，热力学明明说它的大部分“本应”以硝酸根的形式溶进海洋？这些都是**环境化学**的问题：研究地球的大气、水体、土壤和生物的化学，把它们当作一个耦合体系来处理——元素在储库之间迁移、改变氧化态，并被阳光、微生物、岩石和人类加工。

这第一堂课要建立本课程后面不断使用的两件工具。第一件是定量的：**箱式模型**，把地球划分为少数几个内部充分混合的储库，储库之间由通量相连，而一个数——**停留时间**——就告诉你一个储库对扰动的响应有多快。第二件是化学的：认识到地球表面是一个**远离平衡的氧化还原体系**，由光合作用维持在远离平衡之处，并由缓慢的动力学保持在远离平衡之处，因此平衡热力学（你在 [[general-chemistry-2/chemical-equilibrium]] 中遇到过）只告诉你事情*可能*朝哪个方向走，而动力学（[[kinetics]]）告诉你的才是它们*实际*有多快。我们把这两件工具都用到碳、氮、硫三大生物地球化学循环上。

## 储库、通量与停留时间

地球系统复杂得无法逐分子建模，所以环境化学家做化学工程师对一座工厂所做的事：画箱子。每个箱子是一个假定内部充分混合的储库——对流层、平流层、表层海洋、深层海洋、陆地生物圈、土壤、沉积物——箱子之间的箭头承载通量。艺术在于选择这样的箱子：其内部混合快于箱子之间的交换；这样每个箱子的含量就能用一个数来描述。

::: definition 储库、存量、通量与稳态 {#def-reservoir}
**储库**（或**箱**）是地球系统中被当作均一处理的一部分。它的**存量**（库存量）$M$ 是其中所含某种选定物质的量，通常以质量计（$\mathrm{Tg} = 10^{12}\ \mathrm{g}$，$\mathrm{Pg} = 10^{15}\ \mathrm{g}$，常按元素的质量计，如 $\mathrm{Pg\,C}$ 或 $\mathrm{Tg\,N}$），或以物质的量计。**通量** $F$ 是进入或离开该储库的速率（$\mathrm{Tg\,yr^{-1}}$、$\mathrm{Pg\,C\,yr^{-1}}$）。单一储库的质量衡算为
$$
\frac{\mathrm{d}M}{\mathrm{d}t} = F_\text{in} - F_\text{out},
$$
其中 $F_\text{in}$ 汇总所有**源**（排放、输入输送、化学生成），$F_\text{out}$ 汇总所有**汇**（沉降、输出输送、化学损耗）。当 $\mathrm{d}M/\mathrm{d}t = 0$，即 $F_\text{in} = F_\text{out}$ 时，储库处于**稳态**。稳态不是平衡：通量不必为零，而在环境中它们几乎从来不为零。
:::

稳态与平衡的区分很重要。一个由一条河补给、由另一条河排出的湖泊，若水位恒定就处于稳态，但水在不断流过它；反之，在化学**平衡**下，每个过程都被它自己的逆过程所抵消（细致平衡原理）。大气中的氧含量处于稳态——光合作用的生产与呼吸、衰变和还原性岩石的风化相平衡——但它与地壳中的有机质、硫化物和二价铁相距平衡甚远，后者只要能较快接触到氧，就会全把它消耗掉。

::: proposition 稳态下的停留时间 {#prop-residence}
对一个处于稳态、存量为 $M$、总输出为 $F_\text{out}$（等于总输入 $F_\text{in}$）的储库，其**停留时间**
$$
\tau = \frac{M}{F_\text{out}} = \frac{M}{F_\text{in}}
$$
是一个分子从进入储库到离开储库之间停留的平均时间。若损耗为一级，$F_\text{out} = kM$，则 $\tau = 1/k$ 也是该物质在储库中的**寿命**：切断源之后，存量按 $M(t) = M_0\,e^{-t/\tau}$ 衰减。
:::

::: proof 停留时间是平均滞留时间 {#proof-residence}
设分子各自独立地离开储库，离开的速率与它已在库内待了多久无关——这正是“充分混合”的含义。那么给定分子在单位时间内离开的概率是常数 $k = F_\text{out}/M$，而一个在 $t = 0$ 进入的分子在时刻 $t$ 仍在库内的概率满足 $\mathrm{d}P/\mathrm{d}t = -kP$，故 $P(t) = e^{-kt}$。在时刻 $t$ 离开的概率密度为 $-\mathrm{d}P/\mathrm{d}t = k e^{-kt}$，于是平均迁移时间为
$$
\langle t \rangle = \int_0^\infty t\,k e^{-kt}\,\mathrm{d}t = \frac{1}{k} = \frac{M}{F_\text{out}} .
$$
数数的论证给出同样的答案：稳态下，单位时间进入 $F_\text{in}$ 个分子，每个平均停留 $\langle t\rangle$，故库内分子数为 $M = F_\text{in}\langle t\rangle$（排队论中的利特尔法则，Little's law）。数数的论证不需要充分混合，这就是即使储库的滞留时间有宽分布，$\tau = M/F$ 仍然有用的原因；但只有一级损耗时，$\tau$ 才同时等于一个衰减扰动的 $e$ 倍衰减时间。
:::

停留时间跨越十五个数量级以上，它们把整个领域组织起来。停留时间短于混合半个球所需时间（约一个月到两个月）的物种分布极不均匀，是“局部”或“区域”污染物——羟基自由基（约一秒）、二氧化氮（约一天）、二氧化硫和细颗粒物（数天到一周）。寿命长于半球间交换时间（约一年）的物种几乎均匀分布，是“全球性”的——甲烷、氧化亚氮、氯氟烃。克里斯蒂安·永格（Christian Junge，1974）提出的一条经验规律对此作了概括：痕量气体的空间相对变率，以其混合比的标准差除以均值来度量，大致与其停留时间成反比。这只是经验法则而非定律，但它解释了为什么夏威夷一座山上一个校准良好的站就能代表全球 $\mathrm{CO_2}$ 记录，而臭氧或 $\mathrm{NO_2}$ 必须在每座城市测量。

::: example 水蒸气的停留时间 {#ex-water-residence}
大气保有约 $12.7\times10^{3}\ \mathrm{km^3}$ 的水（以液态水当量计），全球降水量约为 $486\times10^{3}\ \mathrm{km^3\,yr^{-1}}$（Trenberth 等，2007，*Journal of Hydrometeorology*）。试估计水在大气中的停留时间，并说明其含义。
::: solution
大气水储库接近稳态（全球平均而言蒸发与降水相平衡），故由[[#prop-residence]]
$$
\tau = \frac{M}{F} = \frac{12.7\times10^{3}\ \mathrm{km^3}}{486\times10^{3}\ \mathrm{km^3\,yr^{-1}}} = 0.0261\ \mathrm{yr} = 0.0261\times365\ \mathrm{d} = 9.5\ \mathrm{d}.
$$
数据所能支持的只有两位有效数字：约**九到十天**。有两个推论。其一，水汽的空间变率极大——从湿润热带中占空气的几个百分点，到平流层中的每百万分之几——这正是永格法则对短寿命物种的预言。其二，水汽的量不可能由人类排放设定：任何多余部分都会在几天内降出，其存量反而由温度通过克劳修斯-克拉珀龙方程（[[thermodynamics/phase-equilibria]]）控制。这就是水汽在气候中充当对增暖的**反馈**而非**强迫**的原因（见 [[environmental-chemistry/greenhouse-gases]]）。
:::
:::

## 箱式模型与对扰动的响应

一旦有什么东西发生变化，停留时间就成为一个动力学量。最简单的情形是单个箱子，具有恒定源 $S$ 和一级汇 $kM = M/\tau$。

::: proposition 单箱弛豫 {#prop-onebox}
对一个具源 $S(t)$、一级损耗、寿命为 $\tau$ 的充分混合储库，
$$
\frac{\mathrm{d}M}{\mathrm{d}t} = S - \frac{M}{\tau} .
$$
若 $S$ 恒定，则稳态存量为 $M_\text{ss} = S\tau$，而自任一初始存量 $M_0$ 出发，
$$
M(t) = M_\text{ss} + (M_0 - M_\text{ss})\,e^{-t/\tau} .
$$
储库以指数方式趋近其新的稳态：经过一个寿命，弥合 $63\ \%$ 的差距；经过 $\tau\ln 10 = 2.30\,\tau$，弥合 $90\ \%$；经过 $4.6\,\tau$，弥合 $99\ \%$。源加倍则稳态存量加倍；寿命减半则存量减半。
:::

::: proof 求解单箱方程 {#proof-onebox}
记 $\Delta = M - S\tau$。由于 $S$ 与 $\tau$ 恒定，$\mathrm{d}\Delta/\mathrm{d}t = \mathrm{d}M/\mathrm{d}t = S - M/\tau = -\Delta/\tau$。这是一级衰减，故 $\Delta(t) = \Delta(0)\,e^{-t/\tau}$，即 $M(t) - S\tau = (M_0 - S\tau)e^{-t/\tau}$，以 $M_\text{ss} = S\tau$ 代入即得所果。时刻 $t$ 已弥合的初始差距比例为 $1 - e^{-t/\tau}$；令其等于 $0.90$ 得 $t = \tau\ln 10$。该方程与恒定进料的一级化学反应是同一个线性一阶常微分方程，其解法见 [[kinetics/rate-laws]] 及数学图谱中的[一阶线性方程](/learn/maths/)；环境方面的内容只在于对 $S$ 和 $\tau$ 的解释。
:::

决定趋近快慢的时间常数是**寿命**，而不是扰动当初积累所花的时间。寿命十天的污染物，排控措施在一个月之内就见效；寿命一个世纪的污染物，无论今年做出什么决定，都会把当前存量保持好几代人。这种不对称是以下事实的原因之一：控制酸雨前体物（寿命数天）在十年内就带来可见的改善，而控制氯氟烃（寿命数十年到一个世纪）预计要用掉本世纪的大部分时间才能修复臭氧层（[[environmental-chemistry/stratospheric-ozone]]）。

::: example 甲烷：存量、寿命与单位 {#ex-methane-lifetime}
2020 年代初甲烷的全球平均摩尔分数约为 $1900\ \mathrm{ppb}$（NOAA 全球监测网络）。干空气总质量为 $5.135\times10^{18}\ \mathrm{kg}$，平均摩尔质量为 $28.97\ \mathrm{g\,mol^{-1}}$。甲烷总汇（主要是 $\mathrm{OH}$ 氧化，另有向土壤和平流层的较小损耗）约为 $550\ \mathrm{Tg\,yr^{-1}}$（Saunois 等，2020，*Earth System Science Data*）。求其存量与稳态寿命。
::: solution
干空气的物质的量：
$$
n_\text{air} = \frac{5.135\times10^{21}\ \mathrm{g}}{28.97\ \mathrm{g\,mol^{-1}}} = 1.773\times10^{20}\ \mathrm{mol}.
$$
因此一个 ppb 的甲烷是 $1.773\times10^{11}\ \mathrm{mol}$，即 $1.773\times10^{11}\times16.04\ \mathrm{g} = 2.84\ \mathrm{Tg}$。存量为
$$
M = 1900 \times 2.84\ \mathrm{Tg} = 5.40\times10^{3}\ \mathrm{Tg}.
$$
把大气当作近似稳态（甲烷实际上在缓慢上升，每年约 $0.5\ \%$，故源略大于汇）：
$$
\tau = \frac{5.40\times10^{3}\ \mathrm{Tg}}{550\ \mathrm{Tg\,yr^{-1}}} = 9.8\ \mathrm{yr}.
$$
这个约十年的**大气总寿命**就是 IPCC AR6 引用的数值（约 $9$ 年）。而**扰动寿命**——一个额外脉冲衰减的快慢——则略长一些（AR6：$11.8$ 年），因为额外的甲烷消耗 $\mathrm{OH}$，从而减慢了自己的移除；我们将在 [[environmental-chemistry/tropospheric-chemistry]] 中再遇到这一反馈。注意这个换算因子：有些资料引用 $2.75$–$2.78\ \mathrm{Tg\,ppb^{-1}}$，比我们的 $2.84$ 低百分之几，因为它们对平流层中较低的甲烷混合比作了修正。
:::
:::

::: warning 对 CO₂ 而言，停留时间、寿命与调整时间是三个不同的数 {#warn-co2-lifetime}
人们常说“一个 $\mathrm{CO_2}$ 分子在空气中大约停留五年”。这话不假，却几乎无济于事。约 $870\ \mathrm{Pg\,C}$ 的 $\mathrm{CO_2}$ 与陆地生物圈和海洋交换，毛交换速率分别约为 $120$ 和 $80\ \mathrm{Pg\,C\,yr^{-1}}$，所以单个分子的停留时间是 $870/200 \approx 4$ 年。但这些毛通量是双向的：光合作用吸收的碳被呼吸送回，海洋表层一呼一吸。对**过量**的 $\mathrm{CO_2}$ 真正重要的是**净**移除，而这需要碳混入深层海洋（几个世纪）、被碳酸盐沉积物中和（几千年），最终由硅酸盐风化移除（几十万年）。因此一个 $\mathrm{CO_2}$ 扰动的**调整时间**不是一个数：一个脉冲分几个阶段衰减，大约五分之一在一千年后仍留在大气中。同样的区分——单个分子的停留时间与扰动的衰减——适用于任何其汇是与其它储库交换而非毁灭的物种。
:::

这种多阶段衰减通常写作指数之和，依据的是 IPCC AR5 采用的 Joos 等（2013，*Atmospheric Chemistry and Physics*）的碳循环模型互比较
$$
f(t) = a_0 + \sum_{i=1}^{3} a_i\,e^{-t/\tau_i},
$$ {#eq-bern}
其中 $a_0 = 0.217$，$a_1 = 0.224$（$\tau_1 = 394\ \mathrm{yr}$），$a_2 = 0.282$（$\tau_2 = 36.5\ \mathrm{yr}$），$a_3 = 0.276$（$\tau_3 = 4.3\ \mathrm{yr}$）。常数项 $a_0$ 代表在拟合的时间尺度上（直到约一千年）根本没有被移除的那部分。这只是对某一特定背景状态下模型输出的拟合，不是自然定律，但它概括了物理：表层海洋和陆地的快速吸收，海洋内部较慢的吸收，以及一条长尾。

## 混合比、数密度与大气的结构

在谈论大气化学之前，我们先要知道它的单位。实验室化学家用 $\mathrm{mol\,dm^{-3}}$ 的浓度；大气化学家用另外两种度量，各适合不同的工作。

::: definition 混合比与数密度 {#def-mixing-ratio}
气体 $i$ 的**混合比**（摩尔分数）$x_i$ 是 $i$ 的物质的量除以空气总物质的量，$x_i = n_i/n_\text{air}$；对理想气体它等于体积分数和分压分数 $p_i/p$。痕量气体以百万分之一（$\mathrm{ppm} = 10^{-6}$，$\mathrm{\mu mol\,mol^{-1}}$）、十亿分之一（$\mathrm{ppb} = 10^{-9}$，$\mathrm{nmol\,mol^{-1}}$）或万亿分之一（$\mathrm{ppt} = 10^{-12}$）报告。温室气体以**干空气**摩尔分数报告，以消除水汽稀释的变动。气块膨胀或压缩时混合比守恒，所以它是描述输送的自然变量。**数密度** $n_i$（单位体积的分子数，常用 $\mathrm{cm^{-3}}$）才是进入速率方程的量：
$$
n_i = x_i\,\frac{p}{k_\mathrm{B}T},
$$
其中 $k_\mathrm{B} = 1.380\,649\times10^{-23}\ \mathrm{J\,K^{-1}}$。在 $p = 1\ \mathrm{atm}$、$T = 298\ \mathrm{K}$ 下，空气的总数密度为 $2.46\times10^{19}\ \mathrm{cm^{-3}}$。质量浓度（$\mathrm{\mu g\,m^{-3}}$）用于颗粒物空气质量标准与法规。
:::

::: example 以 ppb 与每立方厘米分子数表示的臭氧 {#ex-ozone-units}
夏日午后，一座海平面监测站报告 $25\ \mathrm{°C}$、$1.000\ \mathrm{atm}$ 下臭氧为 $40\ \mathrm{ppb}$。把它表示为数密度和质量浓度。
::: solution
总数密度：
$$
n_\text{air} = \frac{p}{k_\mathrm{B}T} = \frac{101\,325\ \mathrm{Pa}}{1.3806\times10^{-23}\ \mathrm{J\,K^{-1}} \times 298\ \mathrm{K}} = 2.463\times10^{25}\ \mathrm{m^{-3}} = 2.463\times10^{19}\ \mathrm{cm^{-3}}.
$$
臭氧：
$$
n_{\mathrm{O_3}} = 40\times10^{-9}\times2.463\times10^{19}\ \mathrm{cm^{-3}} = 9.9\times10^{11}\ \mathrm{cm^{-3}}.
$$
质量浓度：$9.85\times10^{17}\ \mathrm{m^{-3}}$ 个分子即 $9.85\times10^{17}/6.022\times10^{23} = 1.64\times10^{-6}\ \mathrm{mol\,m^{-3}}$，乘以 $48.00\ \mathrm{g\,mol^{-1}}$，得 $7.8\times10^{-5}\ \mathrm{g\,m^{-3}} = 79\ \mathrm{\mu g\,m^{-3}}$。$25\ \mathrm{°C}$ 下的经验法则是 $1\ \mathrm{ppb} = M/24.45\ \mathrm{\mu g\,m^{-3}}$（$M$ 以 $\mathrm{g\,mol^{-1}}$ 计），故 $40\times48.00/24.45 = 79\ \mathrm{\mu g\,m^{-3}}$。空气质量指导值以质量单位书写，所以这一换算——它依赖于温度和压强——必须始终注明。
:::
:::

大气不是密度均匀的一只箱子：它随高度变稀薄，因为每一层都支撑着其上空气的重量。

::: proposition 气压公式与标高 {#prop-barometric}
对处于静力平衡、并视为平均摩尔质量 $M$、温度均匀的 $T$ 的理想气体的大气（等温近似），压强 $p$ 随海拔 $z$ 指数下降：
$$
p(z) = p_0\,e^{-z/H}, \qquad H = \frac{RT}{Mg},
$$
其中 $H$ 是**标高**。对空气（$M = 0.02897\ \mathrm{kg\,mol^{-1}}$，$g = 9.81\ \mathrm{m\,s^{-2}}$），$250\ \mathrm{K}$ 时 $H = 7.3\ \mathrm{km}$，$288\ \mathrm{K}$ 时 $H = 8.4\ \mathrm{km}$。数密度同样下降。真实大气并非等温，故 $H$ 随高度而变；但用当地温度时，该律在局部有百分之几的精度。
:::

::: proof 静力平衡 {#proof-barometric}
考察一块水平截面积为 $A$、厚度为 $\mathrm{d}z$ 的薄空气片。它的重量 $\rho g A\,\mathrm{d}z$ 由两侧压强差支撑：$p(z)A - p(z + \mathrm{d}z)A = \rho g A\,\mathrm{d}z$，故 $\mathrm{d}p/\mathrm{d}z = -\rho g$。理想气体状态方程给出 $\rho = pM/(RT)$，于是
$$
\frac{\mathrm{d}p}{\mathrm{d}z} = -\frac{Mg}{RT}\,p = -\frac{p}{H}.
$$
$T$（从而 $H$）恒定时，分离变量得 $\ln(p/p_0) = -z/H$，即 $p = p_0 e^{-z/H}$。数值上，$H = 8.314 \times 250/(0.02897\times9.81) = 7.31\times10^{3}\ \mathrm{m}$。大气质量的一半位于 $H\ln 2 \approx 5\ \mathrm{km}$ 以下，$90\ \%$ 位于约 $17\ \mathrm{km}$ 以下——大致到热带对流层顶。
:::

温度的垂直结构把大气划分成几个化学上重要的层次。**对流层**（地面到 $8$–$17\ \mathrm{km}$，热带更高）中温度随高度平均每公里下降约 $6.5\ \mathrm{K}$，因为空气是从地面被加热的；下暖上冷的空气不稳定，所以对流层在几天到几周内垂直翻转，几乎含有全部的水和天气。**对流层顶**之上是**平流层**（到约 $50\ \mathrm{km}$），其中温度随高度**升高**，因为臭氧吸收太阳紫外（[[environmental-chemistry/stratospheric-ozone]]）；上暖下冷的空气稳定，垂直混合缓慢，进入平流层的空气在那里停留数年。这种稳定性正是被喷入平流层的长寿命污染物——由火山喷发，或作为挺过对流层的氯氟烃——盘桓不去的原因。水平混合更快：绕纬圈数周，一个半球内从极到赤道一两个月，半球之间约一年，半球间空气被热带辐合带部分隔开。

## 地球表面的氧化还原状态

第二件组织性思想是化学的。光合作用是由光驱动的还原反应，
$$
\mathrm{CO_2(g)} + \mathrm{H_2O(l)} \xrightarrow{h\nu} \mathrm{CH_2O} + \mathrm{O_2(g)}, \qquad \Delta_\mathrm{r}G^\circ \approx +480\ \mathrm{kJ\,mol^{-1}},
$$
其中 $\mathrm{CH_2O}$ 代表一个碳水化合物单元。空气中的每一个 $\mathrm{O_2}$ 分子，都在某处与一个还原态碳原子（或通过其反应产物，一个还原态硫或铁原子）配平。几乎所有这些还原性物质都在数年到数百年内又被呼吸回去，但有一小部分被埋入沉积物；经地质时间，这种埋藏建立了大气中的氧，而被埋藏的碳（主要是弥散的干酪根，其中极小一部分成为煤、石油和天然气）和硫化物则保存着相应的还原能力。地球表面因此是一块充好电的巨大电池：氧化的大气和海洋与还原的生物圈和地壳相接触，被动力学势垒隔开。生命与火在局部给它放电；光合作用给它充电。

把每种元素的重要物种排在一条**氧化态阶梯**上是有益的：

| 元素 | 最还原 | 中间 | 最氧化 |
|---|---|---|---|
| 碳 | $\mathrm{CH_4}$（$-4$） | $\mathrm{CH_2O}$、有机质（$0$）、$\mathrm{CO}$（$+2$） | $\mathrm{CO_2}$、$\mathrm{HCO_3^-}$、$\mathrm{CO_3^{2-}}$（$+4$） |
| 氮 | $\mathrm{NH_3}$、$\mathrm{NH_4^+}$、有机 N（$-3$） | $\mathrm{N_2}$（$0$）、$\mathrm{N_2O}$（$+1$）、$\mathrm{NO}$（$+2$）、$\mathrm{NO_2^-}$（$+3$）、$\mathrm{NO_2}$（$+4$） | $\mathrm{HNO_3}$、$\mathrm{NO_3^-}$（$+5$） |
| 硫 | $\mathrm{H_2S}$、$\mathrm{FeS_2}$（$-2$、$-1$）、$(\mathrm{CH_3})_2\mathrm{S}$（$-2$） | $\mathrm{S}$（$0$）、$\mathrm{SO_2}$、$\mathrm{HSO_3^-}$（$+4$） | $\mathrm{H_2SO_4}$、$\mathrm{SO_4^{2-}}$（$+6$） |

在含 $21\ \%$ $\mathrm{O_2}$ 的大气中，热力学稳定的形态是右上角的条目：$\mathrm{CO_2}$、硝酸盐、硫酸盐。排入空气中的还原性物种——甲烷、氨、硫化氢、二甲基硫醚、二氧化硫、一氧化碳——都会被氧化，它们的寿命不取决于热力学（后者有利得压倒一切），而取决于与羟基自由基——大气的主要氧化剂——反应的动力学（[[environmental-chemistry/tropospheric-chemistry]]）。在与空气隔绝的水体和土壤中，微生物把同一条阶梯倒过来用：氧气耗尽后，依次以硝酸盐、锰(IV)、铁(III)、硫酸盐，最后以 $\mathrm{CO_2}$ 本身为氧化剂——这就是 [[environmental-chemistry/natural-waters]] 的氧化还原序列。

::: example 为什么大气中还有氮？ {#ex-sillen}
瑞典化学家西伦（Sillén）在 1960 年代曾问：海洋-大气系统在平衡时会是什么样子。考虑
$$
\mathrm{N_2(g)} + \tfrac{5}{2}\,\mathrm{O_2(g)} + \mathrm{H_2O(l)} \rightleftharpoons 2\,\mathrm{H^+(aq)} + 2\,\mathrm{NO_3^-(aq)} .
$$
用 $\Delta_\mathrm{f}G^\circ(\mathrm{NO_3^-,aq}) = -111.3\ \mathrm{kJ\,mol^{-1}}$ 和 $\Delta_\mathrm{f}G^\circ(\mathrm{H_2O,l}) = -237.13\ \mathrm{kJ\,mol^{-1}}$（NBS 表，298.15 K），求 $\Delta_\mathrm{r}G^\circ$，再求 $\mathrm{pH}\ 8$、含 $1\times10^{-5}\ \mathrm{mol\,dm^{-3}}$ 硝酸盐的海水之上空气（$p_{\mathrm{N_2}} = 0.78$、$p_{\mathrm{O_2}} = 0.21$ bar）条件下的 $\Delta_\mathrm{r}G$。作出解释。
::: solution
标准反应吉布斯能（元素处于标准态，$\mathrm{H^+}$ 按规定为零）：
$$
\Delta_\mathrm{r}G^\circ = 2(-111.3) - (-237.13) = +14.5\ \mathrm{kJ\,mol^{-1}} .
$$
标准条件下（酸浓度为 1 M！）反应略不利。但真实条件下的反应商为
$$
Q = \frac{[\mathrm{H^+}]^2[\mathrm{NO_3^-}]^2}{p_{\mathrm{N_2}}\,p_{\mathrm{O_2}}^{5/2}}, \qquad
\ln Q = 2\ln(10^{-8}) + 2\ln(10^{-5}) - \ln 0.78 - \tfrac{5}{2}\ln 0.21 = -55.7 ,
$$
（水作纯液体，活度 $1$；忽略活度系数），于是
$$
\Delta_\mathrm{r}G = \Delta_\mathrm{r}G^\circ + RT\ln Q = 14.5 + (8.314\times10^{-3})(298.15)(-55.7) = -124\ \mathrm{kJ\,mol^{-1}} .
$$
强负值：反应本会正向进行，直到硝酸盐积累、海水变得酸得多，并消耗掉大气氧的很大一部分。它没有这样做，纯粹是动力学使然。$\mathrm{N{\equiv}N}$ 三键（$945\ \mathrm{kJ\,mol^{-1}}$）使 $\mathrm{N_2}$ 异常惰性；只有闪电、高温燃烧、固氮微生物的固氮酶和哈伯-博施法才能打断它——而生成的硝酸盐又被反硝化细菌送回 $\mathrm{N_2}$。大气的组成是一个**动力学的稳态**，不是平衡，这就是一般的教训：在环境化学中，热力学告诉你方向，速率告诉你状态。
:::
:::

## 碳循环

碳是我们对其循环了解最多的元素，因为它既是生命的通货，又是人为气候变化的主要驱动力。碳循环惯常分为**快**循环——大气、海洋、陆地生物圈和土壤，在几年到几千年的时间尺度上交换——和岩石风化、沉积、俯冲与火山的**慢**地质循环，时间尺度为 $10^{5}$–$10^{8}$ 年。

主要储库如下，数值取自 IPCC AR6 第一工作组第 5 章（2021 年）评估，已作取整：

| 储库 | 碳 / $\mathrm{Pg\,C}$ |
|---|---|
| 大气（工业革命前，约 $278\ \mathrm{ppm}$） | $\approx 590$ |
| 大气（2019 年，约 $410\ \mathrm{ppm}$） | $\approx 870$ |
| 植被 | $450$–$650$ |
| 土壤（不含永久冻土） | $\approx 1500$–$2400$ |
| 永久冻土 | $\approx 1400$ |
| 表层海洋溶解无机碳 | $\approx 900$ |
| 中层与深层海洋溶解无机碳 | $\approx 37\,000$ |
| 化石燃料储量 | $\approx 900$–$1600$ |
| 沉积碳酸盐岩与干酪根 | $\sim 10^{8}$ |

海洋主导着快循环：它持有的碳约为大气的五十倍，几乎全部以碳酸氢根离子的形式存在。这就是海洋最终是大部分化石碳的去处——也是它在此过程中酸化的原因（[[environmental-chemistry/greenhouse-gases]] 与 [[environmental-chemistry/natural-waters]]）。

毛通量是巨大的。陆地总初级生产力（光合作用）约为 $120$–$140\ \mathrm{Pg\,C\,yr^{-1}}$，与植物呼吸、土壤呼吸和火灾几乎平衡；海-气总交换每个方向约为 $80$–$90\ \mathrm{Pg\,C\,yr^{-1}}$。与之相比，人为扰动在通量上小，但符号始终如一。

::: example 2010 年代的全球碳收支 {#ex-carbon-budget}
IPCC AR6（第一工作组第 5 章，2021 年）给出 2010–2019 年的平均通量如下（单位 $\mathrm{Pg\,C\,yr^{-1}}$）：化石燃料与水泥排放 $9.6 \pm 0.5$；土地利用变化净排放 $1.6 \pm 0.7$；大气增量 $5.1 \pm 0.02$；海洋汇 $2.5 \pm 0.6$；陆地汇 $3.4 \pm 0.9$。(a) 检验收支是否闭合。(b) 大气滞留分数是多少？(c) 把大气增量换算成 $\mathrm{CO_2}$ 摩尔分数的上升速率。
::: solution
(a) 源：$9.6 + 1.6 = 11.2$。汇加增长：$5.1 + 2.5 + 3.4 = 11.0$。$0.2\ \mathrm{Pg\,C\,yr^{-1}}$ 的不平衡远在合成不确定度之内（标准不确定度平方和合成，约 $\pm1.4$）；它作为“收支不平衡”报告，并不强行归零。

(b) **大气滞留分数**（airborne fraction）是大气增量除以总排放：
$$
\frac{5.1}{11.2} = 0.46 .
$$
排放的物质中略少于一半留在大气里；其余大致均等地被海洋和陆地吸收。自 1960 年以来排放约增至四倍，而这个分数却异常稳定。

(c) 由[[#ex-methane-lifetime]]，任何气体的一个 ppm 是 $1.773\times10^{14}\ \mathrm{mol}$；对碳是 $1.773\times10^{14}\times12.011\ \mathrm{g} = 2.13\ \mathrm{Pg\,C}$。于是
$$
\frac{5.1\ \mathrm{Pg\,C\,yr^{-1}}}{2.13\ \mathrm{Pg\,C\,ppm^{-1}}} = 2.4\ \mathrm{ppm\,yr^{-1}},
$$
与 NOAA 莫纳罗亚天文台的十年平均增长率吻合。（惯用因子是 $2.124\ \mathrm{Pg\,C\,ppm^{-1}}$。）
:::
:::

截至 2026 年，莫纳罗亚能有把握定年的最近完整年平均是 2024 年的约 $424.6\ \mathrm{ppm}$（NOAA 全球监测实验室与斯克里普斯海洋学研究所合作），比工业革命前约 $278\ \mathrm{ppm}$ 高约 $52\ \%$；2023–2024 年约 $3.7\ \mathrm{ppm}$ 的增量是记录中最大的一次，被一个削弱陆地汇的厄尔尼诺年份推高。全球碳计划（Global Carbon Project）的《全球碳收支 2024》估计 2024 年化石 $\mathrm{CO_2}$ 排放约 $37.4\ \mathrm{Gt\,CO_2}$，即约 $10.2\ \mathrm{Pg\,C}$。引用当前数值前务必核对来源：记录每月更新。

## 氮循环

氮是大气中最丰富的元素，而自相矛盾的是，它又往往是限制植物生长的那个元素，因为几乎全部氮都锁在惰性 $\mathrm{N_2}$ 里（[[#ex-sillen]]）。环境化学家因此把 $\mathrm{N_2}$ 与**活性氮**（$\mathrm{N_r}$）区分开：其余每一种含氮化合物——氨和铵、硝酸盐和亚硝酸盐、氮氧化物 $\mathrm{NO_x} = \mathrm{NO} + \mathrm{NO_2}$、氧化亚氮以及有机氮。

该循环由若干微生物和化学转化构成：

- **固氮**把 $\mathrm{N_2}$ 转化为 $\mathrm{N_r}$：细菌中固氮酶的生物固氮（部分自由生活，部分在豆科植物的根瘤中），闪电的少量贡献（炽热气流中的 $\mathrm{N_2 + O_2 \rightarrow 2\,NO}$），以及——自二十世纪初以来——哈伯-博施法的工业固氮和高温燃烧中伴生的固氮，后者由空气生成 $\mathrm{NO}$。
- **氨化**（矿化）从腐烂的有机质中释放铵。
- **硝化**：好氧细菌和古菌把铵氧化为亚硝酸盐、再氧化为硝酸盐，$\mathrm{NH_4^+ + 2\,O_2 \rightarrow NO_3^- + 2\,H^+ + H_2O}$——这是一个致酸反应，是铵态肥料使土壤酸化的原因之一。
- **反硝化**：在无氧条件下，异养细菌以硝酸盐为电子受体，经 $\mathrm{NO_2^-}$、$\mathrm{NO}$ 和 $\mathrm{N_2O}$ 逐级还原为 $\mathrm{N_2}$；**厌氧氨氧化**（anammox）细菌把铵和亚硝酸盐直接耦合成 $\mathrm{N_2}$。这些过程闭合了循环。

硝化和反硝化都泄漏氧化亚氮 $\mathrm{N_2O}$，它是一种长寿命温室气体（寿命约 $110$ 年），并且自氯氟烃淘汰以来，是按质量计最大的臭氧消耗物质排放。人类对氮循环的扰动按比例远大于对碳循环的扰动：工业与农业固氮如今已与陆地天然生物固氮相当甚至超过，过剩的活性氮在环境中级联而下——在空气中是 $\mathrm{NO_x}$ 和臭氧，是硝酸铵颗粒，是雨中的硝酸，是地下水中的硝酸盐，也是驱动沿海富营养化的营养物质。

海洋中的**雷德菲尔德比率**（Redfield ratio）把氮循环与碳循环联系起来。雷德菲尔德（Redfield，1934）注意到，海洋浮游生物与深海的溶解营养盐几乎共享同一原子比 $\mathrm{C:N:P} = 106:16:1$。这种有机质的再矿化通常写作
$$
(\mathrm{CH_2O})_{106}(\mathrm{NH_3})_{16}\mathrm{H_3PO_4} + 138\,\mathrm{O_2} \rightarrow 106\,\mathrm{CO_2} + 16\,\mathrm{HNO_3} + \mathrm{H_3PO_4} + 122\,\mathrm{H_2O},
$$
这是一个理想化的化学计量（真实浮游生物有变异），它解释了为什么深水中氧下降而硝酸盐和磷酸盐上升，也让海洋学家能由一种营养盐推断其他营养盐。

## 硫循环

硫的氧化态从 $-2$ 跨到 $+6$，在大气、海洋、沉积物和地壳之间迁移。它向大气的天然源以海洋浮游植物产生的**二甲基硫醚**（DMS，$(\mathrm{CH_3})_2\mathrm{S}$）为主，另有火山的 $\mathrm{SO_2}$ 和 $\mathrm{H_2S}$，以及海盐气溶胶（以硫酸盐形式，已是全氧化态）。其人为源压倒性地是 $\mathrm{SO_2}$：来自燃烧含硫的煤和石油以及冶炼硫化物矿石；在二十世纪下半叶的峰值期，它超过了向大气的天然通量。

在大气中，每一种还原态或中间价态的硫物种都会在数天内被氧化为硫酸盐——气相中由 $\mathrm{OH}$，云滴中由过氧化氢和臭氧。硫酸盐形成细颗粒，散射阳光并为云提供凝结核，并以硫酸的形式随雨清除——这是 [[environmental-chemistry/particulates-acid-deposition]] 的主题。在海洋中，硫酸盐是仅次于氯离子的第二丰富的阴离子（约 $28\ \mathrm{mmol\,kg^{-1}}$），停留时间达数百万年。在缺氧沉积物中，硫酸盐还原菌用它氧化有机质，产生的硫化物以铁的硫化物（黄铁矿，$\mathrm{FeS_2}$）形式沉淀；黄铁矿的埋藏，仅次于有机碳，是大气氧的第二大长期来源。

因为人为硫的寿命短，其存量对政策响应迅速。在《长程越界空气污染公约》（1979 年）及其议定书、1990 年《美国清洁空气法》修正案、以及其后的中国电厂排放控制之下，全球人为 $\mathrm{SO_2}$ 排放已较峰值显著下降，其中欧洲和北美的排放自 1980 年以来下降了百分之八十以上（欧洲环境署和美国 EPA 排放清单）。如我们将看到的，更清洁的空气本身也有气候副作用，因为硫酸盐气溶胶此前一直掩盖着部分温室增暖。

::: quiz
某气体在对流层中的平均寿命为 $3$ 天。哪种说法最恰当地描述了它的分布？
- [ ] 在全球几乎均匀，因为对流层是湍流的。
- [x] 高度不均，集中在源附近，因为它在混合到哪怕半个球之前就被移除了。
- [ ] 在每个半球内均匀，但半球之间不同。
- [ ] 集中在平流层，并在其中积累。
::: solution
绕纬圈混合需要数周，半球之间约需一年，所以 $3$ 天寿命的物种在混合开之前就消灭了：按永格法则，其空间变率很大。半球内均匀是几个月到一年寿命的特征；全球均匀需要几年以上的寿命。寿命三天的对流层物种不可能有大量到达平流层，因为穿越对流层顶的交换要几个月。
:::
:::

::: history
元素在生命与地球之间循环的观念可追溯到十九世纪——布森高（Boussingault）1830 年代对农业中氮的田间研究，以及阿伦尼乌斯（Arrhenius）1896 年对大气 $\mathrm{CO_2}$ 倍增所致增暖的估算——但现代框架由俄国矿物学家维尔纳茨基（Vernadsky）确立，他的《生物圈》（*The Biosphere*，1926）把生物体视为移动和转化元素的地质力量。雷德菲尔德（Redfield）1934 年关于浮游生物与海水组成的论文给出了海洋的化学计量。哈伯（Haber）的氨合成（1909 年）由博施（Bosch）于 1913 年在巴斯夫（BASF）实现工业化，开启了人类对氮循环的接管。1958 年基林（Keeling）在夏威夷莫纳罗亚开始连续测量 $\mathrm{CO_2}$；几年之内，记录就显示出北半球生物圈的季节性“呼吸”和化石燃料造成的持续上升，它至今仍是最长的温室气体直接记录。

## 后续内容

本课的两件工具在每一章都会重现。停留时间和箱式模型为 [[environmental-chemistry/stratospheric-ozone]]（为什么氯氟烃能到达平流层）和 [[environmental-chemistry/tropospheric-chemistry]]（为什么羟基自由基控制着几乎一切物种的寿命）的光化学搭好舞台；也用于 [[environmental-chemistry/particulates-acid-deposition]] 中局部污染与全球污染的区分，以及 [[environmental-chemistry/greenhouse-gases]] 中的碳循环与辐射强迫。氧化还原阶梯和海水以碳酸盐为主这两点，将在 [[environmental-chemistry/natural-waters]] 中作定量处理，多箱模型则在 [[environmental-chemistry/pollutants-fate]] 中以逸度模型的面目重现。其中的数学——线性一阶微分方程及其方程组——在[数学图谱](/learn/maths/)中讲述。

::: summary
- 地球系统被建模为由**通量**相连的充分混合**储库**；质量衡算 $\mathrm{d}M/\mathrm{d}t = F_\text{in} - F_\text{out}$。稳态（$\mathrm{d}M/\mathrm{d}t = 0$）不是平衡。
- **停留时间** $\tau = M/F$ 是稳态下的平均迁移时间；对一级损耗它也是寿命，箱子按 $e^{-t/\tau}$ 弛豫到新稳态 $S\tau$。
- 寿命决定污染物的空间尺度：短寿命物种局部且多变，寿命超过约一年的物种全球混合（永格经验法则）。
- 混合比（ppm、ppb）在输送中守恒；数密度 $n = xp/(k_\mathrm{B}T)$ 进入速率方程；质量浓度用于法规。一个 ppm 的气体是 $1.77\times10^{14}\ \mathrm{mol}$，对 $\mathrm{CO_2}$ 即 $2.13\ \mathrm{Pg\,C}$。
- 压强随高度按 $e^{-z/H}$ 下降，标高 $H = RT/(Mg) \approx 7$–$8\ \mathrm{km}$；稳定的平流层与翻转的对流层交换缓慢。
- 地表是氧化的大气覆盖还原的生物圈和地壳，由光合作用和缓慢的动力学维持在远离平衡之处；$\mathrm{N_2}$ 能在空气中幸存只因为动力学惰性。
- 2010–2019 年化石与土地利用排放约 $11.2\ \mathrm{Pg\,C\,yr^{-1}}$，其中约 $46\ \%$ 留在大气中（IPCC AR6）；$\mathrm{CO_2}$ 脉冲分阶段衰减，一千年后约剩五分之一。
- 活性氮和硫循环因化肥生产和燃烧受到强烈扰动；它们的短寿命物种在数年内即响应排放控制。
:::

## 练习

::: exercise 一氧化碳的寿命 {level=1 check="50"}
一氧化碳的全球存量约 $340\ \mathrm{Tg}$，总源强约 $2500\ \mathrm{Tg\,yr^{-1}}$。设其处于稳态，估计寿命。（寿命以天计，保留两位有效数字。）
::: solution
$\tau = M/F = 340/2500\ \mathrm{yr} = 0.136\ \mathrm{yr} = 0.136\times365 = 49.6\ \mathrm{d} \approx 50\ \mathrm{d}$。两个月与混合半个球的时间相当，但短于半球间交换，所以一氧化碳在北半球明显更丰富，因为大部分燃烧发生在北半球。其主要汇是与 $\mathrm{OH}$ 的反应。
:::
:::

::: exercise 从 ppm 到拍克 {level=1 check="894"}
取干空气 $n_\text{air} = 1.773\times10^{20}\ \mathrm{mol}$，把全球平均 $\mathrm{CO_2}$ 摩尔分数 $420\ \mathrm{ppm}$ 换算为大气碳存量。（存量以 $\mathrm{Pg\,C}$ 计，保留三位有效数字。）
::: solution
一个 ppm 是 $1.773\times10^{14}\ \mathrm{mol}$；对碳，$1.773\times10^{14}\times12.011\ \mathrm{g} = 2.129\times10^{15}\ \mathrm{g} = 2.129\ \mathrm{Pg\,C}$。于是 $420\times2.129 = 894\ \mathrm{Pg\,C}$。（用惯用因子 $2.124$ 则为 $892$。）注意单位：拍克碳，而非 $\mathrm{CO_2}$ 的质量；要得 $\mathrm{CO_2}$ 质量需乘以 $44.01/12.011 = 3.664$。
:::
:::

::: exercise CO₂ 的数密度 {level=1 check="10.7"}
求 $420\ \mathrm{ppm}$、$288\ \mathrm{K}$、$1.000\ \mathrm{atm}$ 空气中 $\mathrm{CO_2}$ 分子的数密度。（以 $10^{15}\ \mathrm{cm^{-3}}$ 为单位，保留三位有效数字。）
::: solution
$n_\text{air} = p/(k_\mathrm{B}T) = 101\,325/(1.3806\times10^{-23}\times288) = 2.548\times10^{25}\ \mathrm{m^{-3}} = 2.548\times10^{19}\ \mathrm{cm^{-3}}$。于是 $n_{\mathrm{CO_2}} = 420\times10^{-6}\times2.548\times10^{19} = 1.07\times10^{16}\ \mathrm{cm^{-3}} = 10.7\times10^{15}\ \mathrm{cm^{-3}}$。
:::
:::

::: exercise 清除一种污染物 {level=2 check="8.2"}
某痕量气体的一级大气寿命为 $12$ 年。若其排放完全停止，$30$ 年后剩余存量的百分比是多少？（百分比保留两位有效数字。）
::: solution
$S = 0$ 时，[[#prop-onebox]] 给出 $M(t) = M_0 e^{-t/\tau}$，故 $M/M_0 = e^{-30/12} = e^{-2.5} = 0.082$，即 $8.2\ \%$。同样的计算适用于排放已基本停止的臭氧消耗气体：即使源为零，也需要几十年的时间。
:::
:::

::: exercise 趋近新的稳态 {level=2 check="21"}
在某简单模型中甲烷的扰动寿命取 $9.1$ 年。若其源突然增加 $10\ \%$ 后保持恒定，存量需要多久才能完成到新稳态上升量的 $90\ \%$？（时间以年计，保留两位有效数字。）
::: solution
由[[#prop-onebox]]，差距按 $e^{-t/\tau}$ 弥合，故 $e^{-t/\tau} = 0.10$ 时达到 $90\ \%$：$t = \tau\ln10 = 9.1\times2.303 = 21\ \mathrm{yr}$。台阶的大小（$10\ \%$）无关紧要：时间常数只由寿命决定（在线性模型中；由于 $\mathrm{OH}$ 反馈，真实的扰动寿命本身随甲烷略有增加）。
:::
:::

::: exercise 雷德菲尔德有机质的耗氧量 {level=2 check="138"}
配平雷德菲尔德有机质 $(\mathrm{CH_2O})_{106}(\mathrm{NH_3})_{16}\mathrm{H_3PO_4}$ 完全氧化为 $\mathrm{CO_2}$、$\mathrm{HNO_3}$、$\mathrm{H_3PO_4}$ 和 $\mathrm{H_2O}$。每个化学式单位消耗多少个 $\mathrm{O_2}$？（填入该数。）
::: hint
数电子：碳从 $0$ 到 $+4$，氮从 $-3$ 到 $+5$，磷保持 $+5$；每个 $\mathrm{O_2}$ 接受四个电子。
:::
::: solution
放出的电子：碳 $106\times4 = 424$；氮 $16\times8 = 128$；共 $552$。每个 $\mathrm{O_2}$ 接受 $4$ 个，故 $552/4 = 138\ \mathrm{O_2}$。用原子核对：左边 $\mathrm{H}$ $= 212 + 48 + 3 = 263$；右边 $16 + 3 + 2\times122 = 263$ ✓。左边 $\mathrm{O}$ $= 106 + 4 + 276 = 386$；右边 $212 + 48 + 4 + 122 = 386$ ✓。所以是 $138\ \mathrm{O_2}$，其中 $106$ 个氧化碳，$32$ 个把氨氧化为硝酸盐——这就是为什么深水中耗氧与释硝酸盐之比（$138/16 \approx 8.6$）是一条经典的海洋学约束。
:::
:::

::: exercise 增长物种的表观寿命 {level=3 check="8.33"}
某物种有一级寿命 $\tau$，其源按指数增长，$S(t) = S_0 e^{rt}$。(a) 证明暂态消失后 $M(t) = S(t)\,\tau/(1 + r\tau)$。(b) 一位观测者若假想稳态，会算出“表观寿命”$M/S$。对 $\tau = 10\ \mathrm{yr}$、$r = 0.020\ \mathrm{yr^{-1}}$，她得到什么？（表观寿命以年计，保留三位有效数字。）
::: hint
试形如 $M = A e^{rt}$ 的特解。
:::
::: solution
(a) 把 $M = Ae^{rt}$ 代入 $\mathrm{d}M/\mathrm{d}t = S_0e^{rt} - M/\tau$：$rA = S_0 - A/\tau$，故 $A = S_0\tau/(1 + r\tau)$。通解另加 $Ce^{-t/\tau}$，该项消失；于是 $M(t) \to S(t)\tau/(1 + r\tau)$。(b) $M/S = \tau/(1 + r\tau) = 10/1.20 = 8.33\ \mathrm{yr}$。源在增长的物种永远*低于*其当前源对应的稳态存量，因为存量比源滞后约一个寿命；不对趋势作修正而由 $M/S$ 推寿命会低估之。对甲烷该修正很小（年增约 $0.5\ \%$ 给出 $r\tau \approx 0.05$）；对一个快速增长的工业气体则可能很大。
:::
:::

::: exercise 海水中硝酸盐佯谬 {level=3 check="-119"}
对当今条件重做[[#ex-sillen]]：$p_{\mathrm{N_2}} = 0.7808$，$p_{\mathrm{O_2}} = 0.2095$，$\mathrm{pH} = 8.1$，$[\mathrm{NO_3^-}] = 30\ \mathrm{\mu mol\,dm^{-3}}$（深水的典型值），$298.15\ \mathrm{K}$，忽略活度系数。再估算该反应的平衡常数 $K$，并就它与 $Q$ 相比的大小置评。（$\Delta_\mathrm{r}G$ 以 $\mathrm{kJ\,mol^{-1}}$ 计，保留三位有效数字。）
::: solution
$\ln Q = 2\ln(10^{-8.1}) + 2\ln(3.0\times10^{-5}) - \ln0.7808 - 2.5\ln0.2095 = -37.30 - 20.83 + 0.247 + 3.906 = -53.98$。于是 $\Delta_\mathrm{r}G = 14.53 + 2.479\times(-53.98) = 14.53 - 133.8 = -119\ \mathrm{kJ\,mol^{-1}}$。平衡常数是 $K = e^{-\Delta_\mathrm{r}G^\circ/RT} = e^{-14530/2479} = 2.8\times10^{-3}$，而 $Q = e^{-54.0} \approx 3.6\times10^{-24}$；$Q/K \sim 10^{-21}$，是对平衡的巨大偏离。当然，把硝酸盐提高二十一个数量级是不可能的：在那之前 pH 早已下降、氧气早已耗尽，而正确的平衡计算必须让所有浓度一起调整（西伦发现这样的“平衡海洋”将是酸性的，且大部分氧气会被消耗）。结论依然成立：只有 $\mathrm{N_2}$ 的惰性和反硝化造成的返回通量，才使大气保持现状。
:::
:::

::: exercise 珠穆朗玛峰顶的压强 {level=2 check="30"}
用等温气压公式取 $H = 7.3\ \mathrm{km}$，已知海平面 $101.3\ \mathrm{kPa}$，估算珠穆朗玛峰顶（$8.85\ \mathrm{km}$）的压强。（压强以 kPa 计，保留两位有效数字。）
::: solution
$p = 101.3\,e^{-8.85/7.3} = 101.3\times0.298 = 30\ \mathrm{kPa}$。实测值约 $33\ \mathrm{kPa}$；取冷空气 $H$ 的等温近似低估了它，因为对流层低层比 $250\ \mathrm{K}$ 暖、标高更大。氧的分压同样按比例缩放，因为其摩尔分数不随高度变化。
:::
