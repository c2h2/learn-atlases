1960 年代，地球化学家帕特森（Patterson）决心测定海水和格陵兰冰中的铅，结果发现几乎所有已发表的数值都是错的——不是差百分之几，而是差十倍到一百倍，因为实验室、试剂、采样瓶和分析者本人都被汽油和油漆中的铅污染了。当他建成超洁净实验室、从样品到检测器追踪每一个铅原子之后，真实浓度比任何人原想的低得多，而古代冰与现代冰之间的差别证明工业铅已经污染了整个半球。这件事是环境分析的奠基一课：在痕量水平，你报告的数值只和它背后的程序链一样可靠——采样设计、容器、保存、空白、校准、质量控制和不确定度陈述。

本课程前面各课引用的每一个数字——$\mathrm{CO_2}$ 的 $424.6\ \mathrm{ppm}$、南极上空的道森单位、$\mathrm{PM_{2.5}}$ 的 $\mathrm{\mu g\,m^{-3}}$、每升几纳克的 PFAS——都出自这样一条链。本课讲怎样把它建起来。分析方法本身假定已经学过，见 [[analytical-chemistry]]：校准与检测限（[[analytical-chemistry/statistics-calibration]]）、原子光谱法（[[analytical-chemistry/atomic-spectrometry]]）、色谱法（[[analytical-chemistry/chromatography]]）和联用质谱方法（[[analytical-chemistry/hyphenated-methods]]）。这里添上的是环境所特有的东西：随空间和时间变化的基体、处在可检出边缘的分析物，以及进入法规决策的结果。

## 为什么监测，先决定什么

环境监测有几种用途，每种蕴含一种不同的设计：

- **合规**：这份水、空气或排水是否达到法定限值？统计必须服务于一个已陈述错误率的判定。
- **趋势检测**：耗氯物质在下降吗？湖泊 pH 在恢复吗？$\mathrm{CO_2}$ 上升在加快吗？测量必须在几十年间可比，所以校准标尺和方法必须可溯源且稳定。
- **暴露与风险评估**：人群和生态系统实际遭遇的浓度是多少？
- **源解析与过程理解**：这种污染物从何而来，如何被转化？

::: definition 数据质量目标 {#def-dqo}
**数据质量目标**（DQO）是在采样**之前**确定的定性定量陈述，说明数据将支持什么判定、以及要支持这一判定数据必须好到什么程度：目标分析物与基体、所抽样总体的空间和时间界限、行动水平（例如法规限值）、假阳性与假阴性判定的容许概率，并由此得出所需的检出限、精密度、偏倚和样本数。这一概念由美国 EPA 形式化，是环境项目的通行做法。它把“尽可能多测”变成“为判定所需而测”。
:::

## 采样

环境结果的不确定度大多产生于样品到达实验室之前。一块田地里铅的浓度逐米而变；河流中的硝酸盐随流量和季节而变；公路旁的 $\mathrm{NO_2}$ 在几分钟和几十米的范围内变化。样品是几克或几毫升，却要代表数吨或立方千米，第一个问题是它对将要作出陈述的总体是否**具代表性**。

采样设计包括**随机**采样（每个地点或时刻等概率；无偏，但可能留下空档）、按网格或等间隔的**系统**采样（覆盖好，但可能与周期性变化混叠）、**分层**采样（把总体分成层——土壤类型、深度、季节——分别采样）和**判断**采样（在疑似热点处采样；适合寻找污染，但不适合估计均值）。**组合**样把若干份样合并，以经济地估计均值，代价是失去关于变差的信息。连续监测仪给出时间序列；被动采样器（$\mathrm{NO_2}$ 的扩散管、水中疏水有机物的聚乙烯片）在几天到几周内积分。

::: proposition 估计均值所需的样本数 {#prop-sample-size}
要在 $1 - \alpha$ 置信水平下把总体均值 $\mu$ 估计到不超过误差限 $E$，且抽样标准偏差（样品之间，含分析误差）为 $\sigma$ 时，近似有
$$
n = \left(\frac{z_{1-\alpha/2}\,\sigma}{E}\right)^2,
$$
向上取整，其中 $95\ \%$ 置信时 $z_{1-\alpha/2} = 1.96$。以变异系数 $\mathrm{CV} = \sigma/\mu$ 和相对误差限 $e = E/\mu$ 写成相对形式，则 $n = (z\,\mathrm{CV}/e)^2$。条件：样本独立，样本均值近似正态（中心极限定理），$\sigma$ 由预备研究已知；$n$ 小时把 $z$ 换成学生 $t$ 分布并迭代。空间相关的数据需要改用地理统计方法。
:::

::: proof 置信区间的宽度 {#proof-sample-size}
$n$ 个独立样本均值的标准误为 $\sigma/\sqrt{n}$ 且近似正态，于是 $\bar{x} \pm z_{1-\alpha/2}\sigma/\sqrt{n}$ 以概率 $1 - \alpha$ 覆盖 $\mu$（[[analytical-chemistry/statistics-calibration]]；数学图谱中的[置信区间](/learn/maths/)）。要求半宽 $z\sigma/\sqrt{n} \leq E$ 并对 $n$ 求解即得结果。二次方依赖是给实践者的要旨：误差限减半需要四倍的样本，非均匀的场地（CV 大）可能需要极多的样本。
:::

::: example 需要多少个土壤样品？ {#ex-sample-size}
对一处前工业场地的预备调查发现，表土中铅浓度在采样点之间的变异系数为 $30\ \%$。要在 $95\ \%$ 置信度下把场地均值估计到 $\pm10\ \%$ 以内，需要多少个样品？若 CV 为 $60\ \%$ 呢？
::: solution
$n = (1.96\times0.30/0.10)^2 = 5.88^2 = 34.6$，故 **$35$ 个样品**。$\mathrm{CV} = 60\ \%$ 时数目翻两番到 $139$。由于 $n$ 已大，用 $z$ 而非 $t$ 已经足够（若用 $t_{0.975,34} = 2.03$，$n$ 变为 $37$）。实践中受污染场地极少均匀：铅可能集中在一座旧冶炼厂房附近。把场地划分为若干区带——每区带用自己的设计采样——能以同样的工作量给出更好的估计，并回答风险管理真正关心的问题：热点**在哪里**？
:::
:::

### 容器、保存与保存时限

采集与分析之间，样品可能因在器壁吸附、挥发、沉淀、微生物降解、光解或污染而得失分析物。标准方法因此规定了容器和保存方式：测**痕量金属**的水用酸清洗的聚乙烯或氟聚合物瓶采集；若需“溶解态”金属则经 $0.45\ \mathrm{\mu m}$ 滤膜过滤（这是一个把胶体包括在内的操作性定义），并用超纯硝酸酸化至 pH 低于 $2$，以使金属留在溶液中并停止生物活动；**挥发性有机化合物**装入玻璃小瓶、不留顶空、隔垫密封并冷却；**痕量有机物**装入溶剂淋洗过的棕色玻璃瓶，冷却到约 $4\ \mathrm{°C}$ 并在数天内完成萃取；**营养盐**冷却或冷冻；测 **PFAS** 的样品必须避开氟聚合物器具，否则会被其污染。每项分析都有最大**保存时限**，超过后结果不再视为有效。现场记录——地点、时刻、温度、状况、监管链——也是结果的一部分。

## 痕量分析：检出、空白与富集

::: definition 检出限与定量限 {#def-lod}
**检出限**（LOD）是能以陈述的置信度与零区分开来的最小浓度。一个常用的操作性定义（在假阳性与假阴性率均约 $5\ \%$、空白标准差表征良好时与 IUPAC 建议一致）是
$$
\mathrm{LOD} = \frac{3\,s_\text{blank}}{b},
$$
其中 $s_\text{blank}$ 是空白（或极低水平）重复测量的标准差，$b$ 是校准斜率（单位浓度的信号）。**定量限**（LOQ）——低于它结果不以数值报告——常取 $10\,s_\text{blank}/b$，此时相对标准差约为 $10\ \%$。环境方法常引用**方法检出限**，它由让低水平加标样品走完整套流程确定，包含了萃取与净化的变差，而不只是仪器的变差。
:::

::: widget distribution
dist: normal
params: mu=0, sigma=1
a: 1.645
b: 6
caption: 空白结果的分布，以空白标准差为单位。超出 $1.645\,\sigma$ 的阴影面积，是一个空白被报为“检出”（假阳性）的 $5\ \%$ 概率。把 $\mu$ 移到 $3.29$（严格柯里意义上处于检出限的真实浓度），保留 $1.645$ 起的阴影：这样的样品有 $95\ \%$ 会被检出。人们熟悉的“$3s$”规则与此十分接近；推导与判定限在 [[analytical-chemistry/statistics-calibration]] 中展开。
:::

::: example 河水中镉的检出限 {#ex-lod}
ICP-MS 法测镉的十个过程空白给出信号比（分析物对内标）的标准差 $0.0035$；校准斜率为每 $\mathrm{\mu g\,dm^{-3}}$ $0.0250$。求 LOD 和 LOQ，并判断该方法是否适用于核查一项 $0.08\ \mathrm{\mu g\,dm^{-3}}$ 的环境质量标准（经修订的第 2008/105/EC 号欧盟指令规定的、最软淡水中溶解态镉的年均 EQS）。
::: solution
$\mathrm{LOD} = 3\times0.0035/0.0250 = 0.42\ \mathrm{\mu g\,dm^{-3}}$，$\mathrm{LOQ} = 10\times0.0035/0.0250 = 1.4\ \mathrm{\mu g\,dm^{-3}}$。两者都超出 $0.08\ \mathrm{\mu g\,dm^{-3}}$ 的标准好几倍：该方法分辨不出水体是否达标。欧盟水监测规则（第 2009/90/EC 号指令）要求 LOQ 至多为标准值的 $30\ \%$，这里即 $0.024\ \mathrm{\mu g\,dm^{-3}}$——比本方法低 $60$ 倍。改进可来自降低空白（更洁净的试剂与器皿、洁净实验室）、预富集，或灵敏度更高的仪器模式。要点可以推广：检出限要由判定（DQO）设定，而不是由仪器规格表设定。
:::
:::

**空白**揭示污染与偏倚。**现场空白**（洁净的水带到现场，经采样流程暴露后带回）检测采样设备与操作带来的污染；**运输空白**（从未打开）检测运输与贮存中的污染，对 VOC 很重要；**方法空白**（试剂走完整套实验室流程）检测实验室污染。对无处不在的分析物——铅、锌、邻苯二甲酸酯、硅氧烷、PFAS——设定检出限的通常是空白而非仪器，这就是帕特森关于洁净流程的教训至今仍是核心的原因。

**预富集**把分析物从大体积样品移入小体积萃取液，从而降低检出限：向溶剂的液-液萃取（对 $K_\mathrm{ow}$ 高的化合物高效，依据 [[environmental-chemistry/pollutants-fate]] 的分配规律）、在吸附剂小柱上富集后用少量溶剂洗脱的**固相萃取**（SPE）、挥发物的吹扫捕集或顶空采样，以及海水中痕量金属的螯合树脂。**富集因子**是萃取液与样品中浓度之比，$\mathrm{EF} = (V_\text{sample}/V_\text{extract})\times\text{recovery}$。回收率用加标样品测量，更好的做法是在萃取前加入同位素标记类似物从内部校正。

### 同位素稀释

::: proposition 同位素稀释质谱法 {#prop-idms}
设某元素（或化合物）有两个可测的同位素（或同位素异构体）A 和 B。样品含未知量 $n_x$，同位素物质的量分数为 $a_x$、$b_x$；**稀释剂**（spike）加入量 $n_y$ 已知，富集 B，分数为 $a_y$、$b_y$。稀释剂与样品混合平衡后，混合物中测得的物质的量比为 $R_\mathrm{b} = n(\mathrm{A})/n(\mathrm{B})$。则
$$
n_x = n_y\,\frac{a_y - R_\mathrm{b}\,b_y}{R_\mathrm{b}\,b_x - a_x} .
$$
因为平衡之后只测一个**比值**，其后样品制备中的损失和仪器灵敏度的漂移都会抵消。条件：稀释剂与样品的同位素完全平衡、比值经质量歧视校正、无同量异位素干扰。
:::

::: proof 两个同位素的质量衡算 {#proof-idms}
在混合物中，$n(\mathrm{A}) = a_xn_x + a_yn_y$，$n(\mathrm{B}) = b_xn_x + b_yn_y$。两者之比即测得的 $R_\mathrm{b}$：
$$
R_\mathrm{b}(b_xn_x + b_yn_y) = a_xn_x + a_yn_y
\quad\Longrightarrow\quad
n_x(R_\mathrm{b}b_x - a_x) = n_y(a_y - R_\mathrm{b}b_y),
$$
即得结果。稀释剂一经与分析物混匀，其后的任何损失都以相同比例带走 A 和 B，$R_\mathrm{b}$ 保持不变——这就是同位素稀释被视为基准比率法、并被用来认证标准物质的原因。
:::

::: example 同位素稀释法测海水中的铜 {#ex-idms}
天然铜为 $69.15\ \%$ $^{63}\mathrm{Cu}$ 和 $30.85\ \%$ $^{65}\mathrm{Cu}$（IUPAC）。海水样加入 $1.00\ \mathrm{nmol}$ 富集至 $99.0\ \%$ $^{65}\mathrm{Cu}$（$1.0\ \%$ $^{63}\mathrm{Cu}$）的铜稀释剂，平衡，在螯合树脂上预富集，ICP-MS 测量，得经质量歧视校正的比值 $n(^{63}\mathrm{Cu})/n(^{65}\mathrm{Cu}) = 1.00$。样品中含有多少铜？
::: solution
取 A $= {}^{63}\mathrm{Cu}$，B $= {}^{65}\mathrm{Cu}$：$a_x = 0.6915$，$b_x = 0.3085$，$a_y = 0.010$，$b_y = 0.990$，$R_\mathrm{b} = 1.00$。由[[#prop-idms]]，
$$
n_x = 1.00\ \mathrm{nmol}\times\frac{0.010 - 1.00\times0.990}{1.00\times0.3085 - 0.6915} = 1.00\times\frac{-0.980}{-0.383} = 2.56\ \mathrm{nmol} .
$$
若样品体积为 $0.500\ \mathrm{dm^3}$，则浓度为 $5.1\ \mathrm{nmol\,dm^{-3}}$（约 $0.33\ \mathrm{\mu g\,dm^{-3}}$），是典型的近岸数值。即使在树脂上损失了 $40\ \%$ 的铜，结果也不改变。当 $R_\mathrm{b}$ 接近样品与稀释剂比值的几何平均时精密度最好，这指导了稀释剂加入量的选择。
:::
:::

## 测量大气

环境空气质量监测网使用建立在前面各课化学之上的自动分析仪：

- **臭氧**用**紫外光度法**：测量汞 $253.7\ \mathrm{nm}$ 谱线在轮流充入样品气和除臭氧空气的吸收池中的吸收，按朗伯-比尔定律和吸收截面 $\sigma = 1.1476\times10^{-17}\ \mathrm{cm^2}$（ISO 13964 中的约定值）换算；它是欧盟和美国的参考方法。
- **氮氧化物**用**化学发光法**：$\mathrm{NO + O_3 \rightarrow NO_2^* + O_2}$，$\mathrm{NO_2^* \rightarrow NO_2 + }h\nu$（$600$–$3000\ \mathrm{nm}$），发光强度正比于 $[\mathrm{NO}]$；$\mathrm{NO_2}$ 则让空气通过加热的钼转化器、被还原为 $\mathrm{NO}$ 后以信号增量测量。
- **二氧化硫**用约 $214\ \mathrm{nm}$ 激发的**紫外荧光法**；**一氧化碳**和**二氧化碳**用**非分散红外**吸收（分别在 $4.6$ 和 $4.3\ \mathrm{\mu m}$），本底站的温室气体则越来越多地用**光腔衰荡光谱**，其几公里的有效光程给出所需的精密度。
- **颗粒物**用**重量法**（在控制的温湿度下称量滤膜——参考方法，如欧洲的 EN 12341）和自动等效方法（β射线衰减、振荡微天平、光学计数器），等效方法必须证明与参考方法一致。
- **挥发性有机化合物**用吸附管或采集罐采样后气相色谱；**颗粒物组成**用离子色谱、有机碳与元素碳的热-光学分析和气溶胶质谱。

长期全球记录依靠具有共同校准标尺的网络：WMO 全球大气观测计划维持 $\mathrm{CO_2}$、$\mathrm{CH_4}$、$\mathrm{N_2O}$ 等气体的参考标尺（其中若干种由 NOAA 全球监测实验室担任中心校准实验室），并规定网络的**相容性目标**——北半球 $\mathrm{CO_2}$ 约 $0.1\ \mathrm{ppm}$、$\mathrm{CH_4}$ 约 $2\ \mathrm{ppb}$——小到足以在全球本底上探测区域通量。AGAGE 网络用 GC–MS 测量卤代烃；臭氧柱总量来自地面的多布森和布鲁尔分光光度计以及星载光谱仪，后者还从太空绘制对流层 $\mathrm{NO_2}$、$\mathrm{SO_2}$、甲醛和甲烷的分布图。

::: example 臭氧光度计所需的精密度 {#ex-photometer}
一台紫外光度计的吸收池长 $38\ \mathrm{cm}$。$298\ \mathrm{K}$、$1\ \mathrm{atm}$（$n_\text{air} = 2.46\times10^{19}\ \mathrm{cm^{-3}}$）下 $40\ \mathrm{ppb}$ 的臭氧对应透射光强多么小的相对变化？
::: solution
$[\mathrm{O_3}] = 40\times10^{-9}\times2.46\times10^{19} = 9.85\times10^{11}\ \mathrm{cm^{-3}}$。光学深度为
$$
\tau = \sigma[\mathrm{O_3}]L = 1.1476\times10^{-17}\times9.85\times10^{11}\times38 = 4.3\times10^{-4},
$$
故 $I/I_0 = e^{-\tau} = 0.99957$：百万分之四十的臭氧只使光束变暗 $0.043\ \%$。要分辨 $1\ \mathrm{ppb}$，仪器必须以约 $1\times10^{-5}$ 的把握测量光强比。办法是每隔几秒在样品气与零空气之间切换（使灯的漂移在比值中抵消）、稳定灯与池温，并作平均。因为该方法只依赖 $\sigma$、$L$、$T$ 和 $p$，它几乎是绝对方法，各国的标准光度计都与国际计量局（BIPM）的参考光度计作国际比对。
:::
:::

::: warning NO₂ 监测仪测到的可能并不只是 NO₂ {#warn-interferences}
每种方法都有自己的操作性定义，仪器报告的是它所响应的一切，而不是它标签上写的内容。化学发光法 $\mathrm{NO_x}$ 分析仪的钼转化器不仅把 $\mathrm{NO_2}$，还把一部分 PAN、硝酸、有机硝酸酯和亚硝酸还原为 $\mathrm{NO}$；在远离源的老化空气中，“$\mathrm{NO_2}$”可能被显著高估（对 $\mathrm{NO_2}$ 有选择性的光解转化器可以避免这一点）。重量法 $\mathrm{PM_{2.5}}$ 会损失半挥发的硝酸铵（[[environmental-chemistry/particulates-acid-deposition]]）；“溶解态”金属包括穿过滤膜的 $0.45\ \mathrm{\mu m}$ 以下的胶体；总有机碳分析仪测的是任何能被氧化的东西。把不同方法或不同时段的数据合并时——尤其当要宣称某种趋势时——务必检查操作性定义和已知干扰是否相同。
:::

## 质量保证与质量控制

**质量保证**（QA）是使结果可靠的一整套体系——成文的程序、培训、认可（检测实验室按 ISO/IEC 17025）、审核；**质量控制**（QC）是与样品一起完成的、用以证明这一批结果处于受控状态的那些测量。典型的 QC 要素有：

- **认证标准物质**（CRM）——具有认证浓度与不确定度、可溯源到 SI 单位的天然基体（河水、河口沉积物、城市扬尘），通过分析以检验偏倚；
- **基体加标**——加入已知量的样品，以测量真实基体中的回收率；
- **平行样**——重复采样与分析，以测量精密度；
- **控制图**——稳定控制样的结果对时间作图，在长期均值上下设 $\pm2s$ 的**警告限**和 $\pm3s$ 的**行动限**（休哈特控制图）；点落在行动限之外，或连续若干点位于均值一侧，都表明方法已失控；
- **能力验证**——实验室间比对，各实验室的结果 $x$ 按 $z = (x - X)/\sigma_\mathrm{p}$ 对赋值 $X$ 计分，$\sigma_\mathrm{p}$ 为目标标准差；$\lvert z\rvert \leq 2$ 为满意，$2 < \lvert z\rvert < 3$ 为可疑，$\lvert z\rvert \geq 3$ 为不满意（ISO 13528）。

## 不确定度与判定

::: definition 测量不确定度 {#def-uncertainty}
结果的**标准不确定度** $u$ 是以标准差表示的不确定度。各独立的贡献——采样、缩分、萃取回收率、校准、标准物质的纯度、仪器重复性——按方和根合成（当结果是各输入的乘积或商时，按相对量）：
$$
\frac{u_\mathrm{c}(y)}{y} = \left[\sum_i\left(\frac{u(x_i)}{x_i}\right)^2\right]^{1/2},
$$
遵循《测量不确定度表示指南》（*Guide to the Expression of Uncertainty in Measurement*，GUM，JCGM 100:2008）和 EURACHEM/CITAC 指南《分析测量中不确定度的量化》（*Quantifying Uncertainty in Analytical Measurement*）。**扩展不确定度** $U = ku_\mathrm{c}$，包含因子 $k = 2$，定义一个以约 $95\ \%$ 的概率包含被测量之值的区间。相关的输入需要协方差项。
:::

于是一个结果是否“超过限值”就成了统计判定。结果 $9.0\ \mathrm{\mu g\,dm^{-3}}$、$U = 1.0\ \mathrm{\mu g\,dm^{-3}}$，对限值 $10\ \mathrm{\mu g\,dm^{-3}}$ 而言，既与达标相容，也与（勉强地）不达标相容。法规和合同因此需要一条**判定规则**：例如，只有当结果减去 $U$ 超过限值时才判不达标（把存疑的利益给运营者），或只有当结果加上 $U$ 低于限值时才判达标（把存疑的利益给环境）。用哪条规则是政策性选择，EURACHEM/CITAC 的《不确定度信息在合规评定中的使用》（*Use of Uncertainty Information in Compliance Assessment*）列出了各种选项；化学家的任务是清楚地陈述结果及其不确定度，使规则得以应用。

::: example 合成不确定度分量 {#ex-uncertainty}
一次地下水中农药的测定，各相对标准不确定度为 $2.0\ \%$（校准）、$3.0\ \%$（萃取回收率校正）、$1.5\ \%$（体积与质量测量）和 $4.0\ \%$（样品之间的采样变差）。求合成与扩展相对不确定度。结果为 $0.090\ \mathrm{\mu g\,dm^{-3}}$，限值为 $0.10\ \mathrm{\mu g\,dm^{-3}}$（第 (EU) 2020/2184 号欧盟饮用水指令规定的单一农药指标值）。在要求 $x + U \leq$ 限值的规则下，达标是否得到证明？
::: solution
$u_\mathrm{c}/y = (2.0^2 + 3.0^2 + 1.5^2 + 4.0^2)^{1/2}\ \% = (4 + 9 + 2.25 + 16)^{1/2}\ \% = 31.25^{1/2}\ \% = 5.6\ \%$，且 $U = 2\times5.6 = 11\ \%$（相对）。$x = 0.090$ 时 $U = 0.010\ \mathrm{\mu g\,dm^{-3}}$，故 $x + U = 0.100$：恰在限值上——达标刚好得到证明（就这些数字的精度而言），再取一个样会更稳妥。两个教训：采样变差是最大的单项分量，所以改进采样比改进仪器更有帮助；方和根由最大项主宰——把最小项（$1.5\ \%$）减半几乎不改变 $u_\mathrm{c}$。
:::
:::

::: quiz
某实验室在一次河水硝酸盐的能力验证中报告 $z = -2.8$。它应当得出什么结论？
- [ ] 结果满意，因为 $\lvert z\rvert < 3$。
- [x] 结果可疑：它位于赋值以下 $2$ 到 $3$ 个标准差之间，实验室应调查可能的偏倚（校准、标准溶液、基体效应），尽管按正式分类还不算不满意。
- [ ] 赋值是错的。
- [ ] 该实验室的精密度太好了。
::: solution
按 ISO 13528 的约定，$2 < \lvert z\rvert < 3$ 是警告信号。单个可疑分数约有 $5\ \%$ 的概率纯属偶然，但负号提示偏低的偏倚——例如变质的标准溶液或还原步骤转化不完全——而同一符号的反复警告表明存在系统问题。
:::
:::

## 监测与法规

监测是化学与法律交汇之处。法规不仅规定限值，还规定如何评估达标：欧盟环境空气质量指令（2008/50/EC 及其重订本 (EU) 2024/2881）规定参考方法、监测站数目的下限与选址、数据捕获要求，以及以不确定度表述的数据质量目标；欧盟《水框架指令》（2000/60/EC）及其子指令规定环境质量标准，并经由第 2009/90/EC 号指令规定分析方法的最低性能准则；美国 EPA 公布批准的方法（例如用 LC–MS/MS 测定饮用水中 PFAS 的 EPA 533 和 537.1 号方法）。国际计划——WMO GAW 的大气成分、斯德哥尔摩公约 POPs 的全球监测规划、北极的 AMAP——使用协调一致的方法评估全球趋势和公约的成效。中性的原则是：用于决策的数据必须**适合用途、可溯源，并附带其不确定度**；决策本身则属于监管程序。

监测还一再发现了无人预见的问题：长期多布森记录里显现的南极臭氧洞（[[environmental-chemistry/stratospheric-ozone]]）、2012 年后由大气测量发现的 CFC-11 排放意外回升、全球人群血液中的 PFAS。长期、稳定、校准良好的记录，是环境化学赖以立足的科学基础设施。

::: history
帕特森（Patterson）的洁净实验室铅测量（1965 年起），连同他对地球年龄的同位素测定（1956），表明污染控制是痕量分析的前提。基林（Keeling）的莫纳罗亚记录（始于 1958 年）确立了经校准的连续大气监测的标准。洛弗洛克（Lovelock）的电子捕获检测器（1957）使万亿分之一水平的卤代烃测量成为可能；1971–72 年，他乘“沙克尔顿”号科考船从北大西洋一路测量 CFC-11 直到南极（发表于 *Nature*，1973），证明其已在全球累积。柯里（Currie）关于检出限的论文（*Analytical Chemistry*，1968）奠定了检测判定的统计基础。《测量不确定度表示指南》由 ISO 及伙伴机构于 1993 年出版（现行版本 JCGM 100:2008）。
:::

## 后续内容

分析技术——原子光谱法、色谱法与联用质谱法——在 [[analytical-chemistry]] 中讲解，校准与检测的统计在 [[analytical-chemistry/statistics-calibration]]，分析方案的规划在 [[analytical-chemistry/analytical-process]]。遥感的光谱学原理见 [[spectroscopy/electronic-spectroscopy]] 与 [[spectroscopy/vibrational-spectroscopy]]。监测数据反馈到本课程前面每一章——[[environmental-chemistry/earth-system-chemistry]] 的停留时间、[[environmental-chemistry/stratospheric-ozone]] 的臭氧记录、[[environmental-chemistry/greenhouse-gases]] 的碳收支——也反馈到 [[green-chemistry]] 中更清洁生产的设计。

::: summary
- 先定义判定：数据质量目标确定分析物、行动水平、错误率、检出限和样本数。
- 采样通常主宰不确定度；设计有随机、系统、分层或判断四种，$n = (z\sigma/E)^2$ 个样本可把均值估计到 $\pm E$。
- 容器、保存（金属酸化、冷却、VOC 不留顶空）与保存时限保护样品；现场、运输和方法空白揭示污染，后者常常决定检出限。
- $\mathrm{LOD} \approx 3s_\text{blank}/b$，$\mathrm{LOQ} \approx 10s_\text{blank}/b$；LOQ 必须远低于法规限值（欧盟水规则：至多为标准值的 $30\ \%$）。
- 预富集（SPE、萃取、吹扫捕集）降低检出限；同位素稀释 $n_x = n_y(a_y - R_\mathrm{b}b_y)/(R_\mathrm{b}b_x - a_x)$，因为只测比值而校正了损失。
- 空气监测仪依靠紫外光度法（臭氧）、化学发光（$\mathrm{NO_x}$）、紫外荧光（$\mathrm{SO_2}$）、非分散红外与光腔衰荡（CO、$\mathrm{CO_2}$、$\mathrm{CH_4}$）和重量法（PM）；每种都有操作性定义和已知干扰。
- QC 使用 CRM、加标、平行样、控制图（$\pm2s$ 警告、$\pm3s$ 行动）和能力验证（$\lvert z\rvert \leq 2$ 满意）；不确定度按方和根合成，$U = 2u_\mathrm{c}$，达标判定需要明确的判定规则。
:::

## 练习

::: exercise 检出限 {level=1 check="0.60"}
用比色法测亚硝酸盐的重复空白标准差为 $0.0040$ 吸光度单位；校准斜率为每 $\mathrm{\mu g\,dm^{-3}}$（以亚硝酸盐-N 计）$0.020$ 吸光度单位。按 $3s$ 判据求 LOD。（LOD 以 $\mathrm{\mu g\,dm^{-3}}$ 计，保留两位有效数字。）
::: solution
$\mathrm{LOD} = 3\times0.0040/0.020 = 0.60\ \mathrm{\mu g\,dm^{-3}}$；LOQ 将是 $2.0\ \mathrm{\mu g\,dm^{-3}}$。
:::
:::

::: exercise 固相萃取的富集 {level=1 check="1800"}
$1000\ \mathrm{cm^3}$ 水样通过 SPE 小柱，洗脱并定容至 $0.50\ \mathrm{cm^3}$，分析物回收率 $90\ \%$。富集因子是多少？（因子保留两位有效数字。）
::: solution
$\mathrm{EF} = (1000/0.50)\times0.90 = 2000\times0.90 = 1800$。萃取液仪器检出限为 $1\ \mathrm{\mu g\,dm^{-3}}$ 的方法由此在水中达到约 $0.6\ \mathrm{ng\,dm^{-3}}$——前提是过程空白相应地低。
:::
:::

::: exercise 能力验证得分 {level=1 check="1.6"}
某实验室对赋值 $48\ \mathrm{\mu g\,dm^{-3}}$、目标标准差 $2.5\ \mathrm{\mu g\,dm^{-3}}$ 的测试样报告锌 $52\ \mathrm{\mu g\,dm^{-3}}$。求 $z$ 并评定结果。（填 $z$。）
::: solution
$z = (52 - 48)/2.5 = 1.6$，满意（$\lvert z\rvert \leq 2$）。
:::
:::

::: exercise 需要多少个水样？ {level=2 check="25"}
一组私人水井中硝酸盐的变异系数为 $50\ \%$。要在 $95\ \%$ 置信度下（$z = 1.96$）把均值估计到 $\pm20\ \%$ 以内，必须采多少口井？（填样本数。）
::: solution
$n = (1.96\times0.50/0.20)^2 = 4.9^2 = 24.01$，向上取整为 $25$。改用 $t$ 而非 $z$（$t_{0.975,24} = 2.06$），$n = 26.5 \to 27$，在这个规模上只是小修正。
:::
:::

::: exercise 同位素稀释 {level=2 check="1.76"}
对测得混合比 $n(^{63}\mathrm{Cu})/n(^{65}\mathrm{Cu}) = 0.80$、稀释剂仍为 $1.00\ \mathrm{nmol}$ 的情形重做[[#ex-idms]]。（$n_x$ 以 nmol 计，保留三位有效数字。）
::: solution
$n_x = 1.00\times(0.010 - 0.80\times0.990)/(0.80\times0.3085 - 0.6915) = (0.010 - 0.792)/(0.2468 - 0.6915) = (-0.782)/(-0.4447) = 1.76\ \mathrm{nmol}$。样品中的铜越少，混合比就越接近稀释剂的比值（$0.0101$）；在对数尺度上混合比居于样品比值（$2.24$）与稀释剂比值之间时，结果精密度最高。
:::
:::

::: exercise 扩展不确定度 {level=2 check="11"}
某测定中各独立的相对标准不确定度为 $2.0\ \%$、$3.0\ \%$、$1.5\ \%$ 和 $4.0\ \%$。$k = 2$ 时的扩展相对不确定度是多少？（$U$ 以百分比计，保留两位有效数字。）
::: solution
$u_\mathrm{c} = \sqrt{4 + 9 + 2.25 + 16}\ \% = 5.6\ \%$；$U = 2u_\mathrm{c} = 11\ \%$（同[[#ex-uncertainty]]）。
:::
:::

::: exercise 臭氧光度计的检出限 {level=3 check="0.093"}
(a) 对池长为 $L$ 的紫外光度计，证明可检测的最小臭氧气密度为 $n_\text{min} \approx \delta/(\sigma L)$，其中 $\delta$ 为可分辨的透射光强最小相对变化（$\delta \ll 1$）。(b) 取 $\sigma = 1.1476\times10^{-17}\ \mathrm{cm^2}$、$L = 38\ \mathrm{cm}$、$\delta = 1.0\times10^{-6}$，求 $298\ \mathrm{K}$、$1\ \mathrm{atm}$（$n_\text{air} = 2.46\times10^{19}\ \mathrm{cm^{-3}}$）下对应的混合比。(c) 说出两种降低它的方法。（混合比以 ppb 计，保留两位有效数字。）
::: solution
(a) 光学厚度很小时 $I/I_0 = e^{-\sigma nL} \approx 1 - \sigma nL$，所以相对变化为 $\sigma nL$；令其等于 $\delta$ 即得 $n_\text{min} = \delta/(\sigma L)$。(b) $n_\text{min} = 1.0\times10^{-6}/(1.1476\times10^{-17}\times38) = 2.29\times10^{9}\ \mathrm{cm^{-3}}$，即 $2.29\times10^{9}/2.46\times10^{10} = 0.093\ \mathrm{ppb}$。(c) 加长光程（多次通过池，或有效光程达公里的腔增强方法），或靠更长时间的信号平均、稳定灯与检测器、更快地交替样品气与零空气来提高光强比的精密度。把波长选到更靠近赫特利带峰处帮助不大，因为 $253.7\ \mathrm{nm}$ 已经十分接近。
:::
:::

::: exercise 判定规则 {level=3 check="9.0"}
某实验室对废水中某金属的扩展相对不确定度为 $11.2\ \%$（$k = 2$），与结果成正比。许可限值为 $10.0\ \mathrm{\mu g\,dm^{-3}}$，监管方的判定规则是只有 $x + U \leq$ 限值才证明达标。(a) 能证明达标的最大测量值 $x$ 是多少？(b) 改用另一条规则“只有 $x - U >$ 限值才宣布不达标”，能证明不达标的最低值是多少？(c) 评论两者之间的“灰色区间”。（(a) 的答案以 $\mathrm{\mu g\,dm^{-3}}$ 计，保留两位有效数字。）
::: solution
(a) $x(1 + 0.112) \leq 10.0$，故 $x \leq 8.99 \approx 9.0\ \mathrm{\mu g\,dm^{-3}}$。(b) $x(1 - 0.112) > 10.0$，故 $x > 11.3\ \mathrm{\mu g\,dm^{-3}}$。(c) $9.0$ 与 $11.3$ 之间的结果在 $95\ \%$ 置信度下既不能证明达标也不能证明不达标。灰色区间的宽度由测量不确定度决定，所以减小 $U$（更好的采样、更多的平行样、同位素稀释）会使它变窄；区间内部的风险由谁承担，取决于判定规则的选择，那是监管问题而非化学问题。
:::
:::

::: exercise 控制图 {level=2 check="53.6"}
某控制样的长期均值为 $50.0\ \mathrm{\mu g\,dm^{-3}}$，标准差 $1.2\ \mathrm{\mu g\,dm^{-3}}$。求休哈特控制图的上警告限与上行动限。新一批次的控制样给出 $53.0\ \mathrm{\mu g\,dm^{-3}}$：应如何处理？（上行动限以 $\mathrm{\mu g\,dm^{-3}}$ 计，保留三位有效数字。）
::: solution
上警告限 $50.0 + 2\times1.2 = 52.4$；上行动限 $50.0 + 3\times1.2 = 53.6\ \mathrm{\mu g\,dm^{-3}}$。$53.0$ 介于两者之间：该批次可以接受，但这个结果是一个警告——若下一个控制值也越过警告限（按常用规则，三次中有两次），方法即失控，该批次必须调查并重新分析。
:::
