一捧肥沃的土壤里栖居的生物比地球上的人口还多，但从化学上看，它首要地是一张巨大的、带电的表面。$1\ \mathrm{g}$ 富黏土的土壤能暴露出数百平方米的矿物和有机表面，其中大部分带有负电荷，把钙、镁、钾这些营养阳离子"扣"住免于淋失——同时也吸附、有时又释放铅、镉、铵、农药和酸雨的质子。同样的表面化学经人工设计，就是水处理的化学基础：混凝除去河水中的颗粒物和天然有机物，活性炭吸附痕量有机物，反应屏障把氯代溶剂从地下水中剥除。本课把土壤当作吸附剂和离子交换剂来处理其化学；讨论让水安全可饮、并在使用之后把它洗干净的化学；以及清理受污染土地和地下水的策略——及其化学限度。课程建立在 [[environmental-chemistry/pollutants-fate]] 的分配和 [[environmental-chemistry/natural-waters]] 的形态之上。

## 土壤的化学本质

矿质土壤大约一半是固体、一半是孔隙空间（由水和空气分享）。固体部分是：

- **原生矿物**，继承自母岩（石英、长石、云母），缓慢风化并释放盐基阳离子。
- **黏土矿物**，粒径小于 $2\ \mathrm{\mu m}$ 的次生层状铝硅酸盐。在高岭石这类 **1:1 型黏土**中，每一层由一个硅氧四面体片与一个铝氧八面体片键合而成，层与层之间以氢键结合；它们不膨胀，电荷很少。在 **2:1 型黏土**——蒙皂石（如蒙脱石）、蛭石、伊利石——中，一个八面体片被夹在两个四面体片之间，形成过程中的**类质同象替代**（例如八面体片中 $\mathrm{Mg^{2+}}$ 取代 $\mathrm{Al^{3+}}$，或四面体片中 $\mathrm{Al^{3+}}$ 取代 $\mathrm{Si^{4+}}$）留下**永久负电荷**，由层间可交换阳离子平衡。
- 铁（针铁矿、水铁矿）、铝（三水铝石）和锰的**氧化物与氢氧化物**，其表面羟基的电荷取决于 pH——即**可变电荷**表面。
- **土壤有机质**（腐殖质），富含羧基和酚基的植物与微生物残体的异质混合物，随 pH 升高而解离，使其成为单位质量电荷最大的土壤组分。它还主导疏水有机化合物的吸附（[[environmental-chemistry/pollutants-fate#prop-koc]]）。

可变电荷表面带有可得可失的质子：$\equiv\mathrm{SOH_2^+} \rightleftharpoons \equiv\mathrm{SOH} + \mathrm{H^+} \rightleftharpoons \equiv\mathrm{SO^-} + 2\,\mathrm{H^+}$。在**零电荷点**（pzc）正负位点相抵；低于它表面带正电、吸引阴离子，高于它带负电、吸引阳离子。铁和铝的氧化物的 pzc 约在 pH $7$–$9$，所以在多数土壤中它们带正电，强烈结合含氧酸根阴离子——磷酸根、砷酸根、钼酸根、亚硒酸根——而黏土和有机质带负电，结合阳离子。

## 阳离子交换

::: definition 阳离子交换量与盐基饱和度 {#def-cec}
土壤的**阳离子交换量**（CEC）是其单位质量所持的可交换阳离子电荷量，以每千克厘米正电荷 $\mathrm{cmol(+)\,kg^{-1}}$ 表示（数值上等于旧单位 $\mathrm{meq}/100\ \mathrm{g}$）。它是永久电荷（黏土）与 pH 依赖电荷（有机质、氧化物边缘）之和，因此报告时须注明 pH。典型值：高岭石 $3$–$15$、伊利石 $10$–$40$、蒙皂石 $80$–$120$、蛭石 $100$–$150$、腐殖质 $150$–$300\ \mathrm{cmol(+)\,kg^{-1}}$。**盐基饱和度**是 CEC 中被 $\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{K^+}$ 和 $\mathrm{Na^+}$ 这些"盐基"阳离子占据的份额，余下的是交换性酸（$\mathrm{H^+}$ 和 $\mathrm{Al^{3+}}$）。
:::

交换是按化学计量进行的——电荷对电荷——且可逆。各种阳离子被结合的牢固程度不同：电荷越高、水化半径越小结合越强，得到经验的**感胶离子序** $\mathrm{Al^{3+}} > \mathrm{Ca^{2+}} > \mathrm{Mg^{2+}} > \mathrm{K^+} \approx \mathrm{NH_4^+} > \mathrm{Na^+}$。酸沉降和硝化加入 $\mathrm{H^+}$，把盐基阳离子置换进土壤溶液，它们在那里与硝酸根或硫酸根一起被淋失；盐基饱和度耗尽后土壤酸化，$\mathrm{Al^{3+}}$ 被活化（[[environmental-chemistry/natural-waters#ex-aluminium]]）。

::: proposition 异价交换与稀释效应 {#prop-exchange}
对交换 $2\,\mathrm{Na{-}X} + \mathrm{Ca^{2+}(aq)} \rightleftharpoons \mathrm{Ca{-}X_2} + 2\,\mathrm{Na^+(aq)}$，以当量分数 $E_\mathrm{Ca} + E_\mathrm{Na} = 1$ 表示交换相组成，盖恩斯-托马斯（Gaines–Thomas）选择性系数为
$$
K_\mathrm{GT} = \frac{E_\mathrm{Ca}\,[\mathrm{Na^+}]^2}{E_\mathrm{Na}^2\,[\mathrm{Ca^{2+}}]} ,
$$
于是
$$
\frac{E_\mathrm{Ca}}{E_\mathrm{Na}^2} = K_\mathrm{GT}\,\frac{[\mathrm{Ca^{2+}}]}{[\mathrm{Na^+}]^2} .
$$
若在 $[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]$ 不变的情况下把土壤溶液稀释（或浓缩）某一倍数，比值 $[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]^2$ 就成反比变化：稀释使交换相更偏好二价离子。条件：活度系数与 $K_\mathrm{GT}$ 视为常数（这是近似，因为 $K_\mathrm{GT}$ 随组成而变）。
:::

::: proof 浓度-价效应 {#proof-exchange}
该式来自以交换相的当量分数写出质量作用商（盖恩斯-托马斯约定）。稀释 $\delta$ 倍时，$[\mathrm{Ca^{2+}}]$ 与 $[\mathrm{Na^+}]$ 都下降 $\delta$，故 $[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]^2$ *升高* $\delta$ 倍；在固定 $K_\mathrm{GT}$ 下，$E_\mathrm{Ca}/E_\mathrm{Na}^2$ 升高同样的倍数，而由于 $E_\mathrm{Na} = 1 - E_\mathrm{Ca}$，这使 $E_\mathrm{Ca}$ 增大。其物理是静电的：带电表面旁的扩散层按玻尔兹曼因子 $e^{-z e\psi/k_\mathrm{B}T}$ 富集反离子，$z = 2$ 时因子更大；溶液越稀电位越大，二价离子的优势越大。这就是为什么雨水（稀）把钙留在交换相上，而钠分数高的浓缩灌溉水却让交换相载满钠——这是土壤**碱化（钠质化，sodicity）**的一个成因：钠饱和的黏土分散，土壤失去结构和渗透性。
:::

::: example 交换相上的钙与钠 {#ex-exchange}
与含 $10\ \mathrm{mmol\,dm^{-3}}$ $\mathrm{Na^+}$ 和 $5.0\ \mathrm{mmol\,dm^{-3}}$ $\mathrm{Ca^{2+}}$ 溶液接触的土壤，其 $K_\mathrm{GT} = 0.10\ \mathrm{mol\,dm^{-3}}$。求 $E_\mathrm{Ca}$，以及溶液稀释十倍后的值。
::: solution
$[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]^2 = 5.0\times10^{-3}/(1.0\times10^{-2})^2 = 50\ \mathrm{dm^3\,mol^{-1}}$，故 $E_\mathrm{Ca}/(1 - E_\mathrm{Ca})^2 = 0.10\times50 = 5.0$。记 $a = 5.0$：$aE^2 - (2a + 1)E + a = 0$，即 $5E^2 - 11E + 5 = 0$，取小于 $1$ 的根：
$$
E_\mathrm{Ca} = \frac{11 - \sqrt{121 - 100}}{10} = \frac{11 - 4.58}{10} = 0.64 .
$$
十倍稀释后，$[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]^2 = 500$，$a = 50$：$50E^2 - 101E + 50 = 0$，$E_\mathrm{Ca} = (101 - \sqrt{201})/100 = 0.87$。尽管溶液中每个钙离子仍对应两个钠离子，交换相上钙（按电荷计）已占 $87\ \%$。因此渗入土壤的雨水把钠置换为钙，而蒸发使土壤溶液浓缩、令交换相转向钠——这就是干旱气候下灌溉土壤盐渍化与钠化的化学本质。
:::
:::

::: example 给酸性土壤施石灰 {#ex-liming}
一块耕层（$0$–$20\ \mathrm{cm}$，容重 $1.30\ \mathrm{g\,cm^{-3}}$）的农田表土有 $2.0\ \mathrm{cmol(+)\,kg^{-1}}$ 交换性酸，农人希望用磨碎石灰石（$\mathrm{CaCO_3}$）把它中和。每公顷需要多少石灰石？
::: solution
每公顷土壤质量：$10^{4}\ \mathrm{m^2}\times0.20\ \mathrm{m}\times1300\ \mathrm{kg\,m^{-3}} = 2.6\times10^{6}\ \mathrm{kg}$。酸量：$2.6\times10^{6}\ \mathrm{kg}\times0.020\ \mathrm{mol(+)\,kg^{-1}} = 5.2\times10^{4}\ \mathrm{mol}$ $\mathrm{H^+}$ 当量。每个 $\mathrm{CaCO_3}$ 中和两个：$\mathrm{CaCO_3 + 2\,H{-}X \rightarrow Ca{-}X_2 + CO_2 + H_2O}$（$\mathrm{Al{-}X}$ 类似地反应并沉淀出 $\mathrm{Al(OH)_3}$）。于是 $2.6\times10^{4}\ \mathrm{mol}\times100.09\ \mathrm{g\,mol^{-1}} = 2.6\times10^{6}\ \mathrm{g} = 2.6\ \mathrm{t\,ha^{-1}}$。实际施得更多，因为交换性酸低估了有机质的总滴定酸度，石灰石并非完全纯净或细磨，而且每次施氮肥料都会继续造成酸化。在斯堪的纳维亚，施石灰也用于酸化的湖泊和流域，作为沉降下降期间对症状的治疗。
:::
:::

## 吸附等温式

对于痕量溶质——金属、农药、有机微污染物——在土壤、沉积物和人工吸附剂上的吸附，用**等温式**描述：恒温下，单位质量吸附剂吸附的量 $q$ 作为平衡液相浓度 $C$ 的函数。

::: proposition 朗缪尔（Langmuir）吸附等温式 {#prop-langmuir}
若表面有固定数目的全同、独立位点，每个位点至多容纳一个分子，吸附与脱附处于动态平衡，则
$$
q = \frac{q_\text{max}K_\mathrm{L}C}{1 + K_\mathrm{L}C},
$$
其中 $q_\text{max}$ 是吸附容量（单层覆盖），$K_\mathrm{L}$ 是亲和常数。低 $C$ 时 $q \approx q_\text{max}K_\mathrm{L}C$——线性，且 $K_\mathrm{d} = q_\text{max}K_\mathrm{L}$；高 $C$ 时表面在 $q_\text{max}$ 处饱和。经验**弗罗因德利希（Freundlich）等温式** $q = K_\mathrm{F}C^{1/n}$（典型 $n > 1$）描述位点能量有分布的非均相表面，没有饱和上限；它是拟合函数，不是机理。
:::

::: proof 朗缪尔等温式的动力学推导 {#proof-langmuir}
记 $\theta = q/q_\text{max}$ 为被占据位点的分数。吸附速率与溶质浓度和空位分数成正比，$k_\mathrm{a}C(1 - \theta)$；脱附速率与被占分数成正比，$k_\mathrm{d}\theta$。平衡时二者相等：$k_\mathrm{a}C(1 - \theta) = k_\mathrm{d}\theta$，故 $\theta = K_\mathrm{L}C/(1 + K_\mathrm{L}C)$，其中 $K_\mathrm{L} = k_\mathrm{a}/k_\mathrm{d}$。这与 [[kinetics/surface-kinetics]] 中气体吸附的论证相同，只是以 $C$ 代替压强；其假设（全同独立位点、单层）正是真实土壤上失守之处，这就是弗罗因德利希拟合往往更好的原因。
:::

## 饮用水处理

取自河流、水库或含水层的原水含有颗粒物、天然有机物、微生物，有时还有溶解的铁、锰、砷、硝酸盐或有机微污染物。常规地表水处理厂依次施加一系列步骤，每一步都基于本课讨论过的化学。

**混凝与絮凝。**多数悬浮颗粒和溶解的腐殖物质带负电荷而相互排斥。在 pH $6$–$7$ 投加硫酸铝（"明矾"）或三氯化铁，会沉淀出非晶形氢氧化物，此时它们接近溶解度极小值（[[environmental-chemistry/natural-waters]]），这些氢氧化物中和颗粒电荷并把颗粒卷进不断长大的絮体（"卷扫絮凝"）。水解反应释放质子并消耗碱度：
$$
\mathrm{Al_2(SO_4)_3{\cdot}14H_2O} + 6\,\mathrm{HCO_3^-} \rightarrow 2\,\mathrm{Al(OH)_3(s)} + 3\,\mathrm{SO_4^{2-}} + 6\,\mathrm{CO_2} + 14\,\mathrm{H_2O},
$$
于是每 $1\ \mathrm{mg\,dm^{-3}}$ 明矾（$594\ \mathrm{g\,mol^{-1}}$）消耗 $6\times50.04/594 = 0.51\ \mathrm{mg\,dm^{-3}}$ 碱度（以 $\mathrm{CaCO_3}$ 计），软的低碱度水需要投加石灰或纯碱。絮体沉降（沉淀）或经砂**过滤**除去。混凝还除去大量天然有机物，这一点很重要，因为那些有机物随后会与氯反应。

**软化、除铁锰与特殊处理。**石灰软化把钙沉淀为 $\mathrm{CaCO_3}$（把 pH 抬到约 $10$）、把镁沉淀为 $\mathrm{Mg(OH)_2}$；地下水中的铁和锰被氧化（曝气、氯或高锰酸盐）为不溶的 $\mathrm{Fe(OH)_3}$ 和 $\mathrm{MnO_2}$ 后过滤除去。颗粒活性炭按其等温式吸附痕量有机化合物——农药、嗅味物质、许多 PFAS；离子交换和反渗透去除硝酸盐和 PFAS；砷通过与氢氧化铁共沉淀或在铁氧化物吸附剂上除去。

**消毒。**氯在水中水解，
$$
\mathrm{Cl_2(g)} + \mathrm{H_2O(l)} \rightarrow \mathrm{HOCl(aq)} + \mathrm{H^+(aq)} + \mathrm{Cl^-(aq)},
\qquad
\mathrm{HOCl} \rightleftharpoons \mathrm{H^+} + \mathrm{OCl^-}\quad(\mathrm{p}K_\mathrm{a} = 7.54\ \text{于}\ 25\ \mathrm{°C}),
$$
次氯酸是能穿透细胞壁的中性分子，其消毒效力比次氯酸根阴离子强得多（常被引用的倍数约为 $80$–$100$ 倍）。因此消毒效率随 pH 升高而下降。有氨存在时，氯生成氯胺（$\mathrm{NH_2Cl}$、$\mathrm{NHCl_2}$），它们是较弱但更持久的消毒剂；必须把氯加到超过全部氨被氧化为 $\mathrm{N_2}$ 之点——**折点加氯**——才能建立游离氯余量。臭氧和紫外线是不留持久余量的替代方案。

::: definition 奇克-沃森（Chick–Watson）定律与 Ct 值 {#def-ct}
浓度为 $C$ 的消毒剂对微生物的失活作用常由经验**奇克-沃森定律**描述
$$
\ln\frac{N}{N_0} = -k\,C^{n}t ,
$$
其中 $N/N_0$ 是接触时间 $t$ 后的存活分数，$k$ 是依微生物、消毒剂、pH 和温度而定的致死系数，$n$ 通常接近 $1$。当 $n = 1$ 时，失活只取决于乘积 $Ct$（$\mathrm{mg\,min\,dm^{-3}}$），法规规定对目标微生物达到一定"对数失活"——$\log_{10}(N_0/N) = 2, 3, 4$——所需的 **Ct 值**。它是经验模型；真实的失活曲线常出现肩部和拖尾。
:::

::: example 两个 pH 下的氯 {#ex-hocl}
某水投加游离氯至 $0.50\ \mathrm{mg\,dm^{-3}}$。pH $7.0$ 和 pH $8.0$（$\mathrm{p}K_\mathrm{a} = 7.54$）时以 HOCl 存在的比例是多少？若目标微生物对 HOCl 的所需 Ct 为 $1.0\ \mathrm{mg\,min\,dm^{-3}}$ 且 $\mathrm{OCl^-}$ 的贡献可忽略，各需多长接触时间？
::: solution
HOCl 分数 $= 1/(1 + 10^{\mathrm{pH} - \mathrm{p}K_\mathrm{a}})$。pH $7.0$：$1/(1 + 10^{-0.54}) = 1/1.288 = 0.78$。pH $8.0$：$1/(1 + 10^{0.46}) = 1/3.88 = 0.26$。有效 HOCl：$0.39$ 与 $0.13\ \mathrm{mg\,dm^{-3}}$。接触时间：$1.0/0.39 = 2.6\ \mathrm{min}$ 和 $1.0/0.13 = 7.8\ \mathrm{min}$。pH 升高一个单位，所需接触时间增至三倍。高 pH 的石灰软化水因此常在软化之前消毒，或为此再酸化。
:::
:::

氯还与天然有机物反应：在活化芳香环上发生亲电取代，在甲基酮结构上发生卤仿反应，生成**消毒副产物**（DBP）：三卤甲烷（$\mathrm{CHCl_3}$、$\mathrm{CHBrCl_2}$，……）、卤乙酸等等。某些 DBP 被归类为可能致癌物，截至 2026 年受到监管，例如欧盟《饮用水指令》（EU）2020/2184 对三卤甲烷总量规定指标值 $100\ \mathrm{\mu g\,dm^{-3}}$，美国对三卤甲烷总量规定最大污染物水平 $80\ \mathrm{\mu g\,dm^{-3}}$、对五种卤乙酸规定 $60\ \mathrm{\mu g\,dm^{-3}}$；WHO 对单个化合物给出指导值（如氯仿 $300\ \mathrm{\mu g\,dm^{-3}}$）。氯化之前先用混凝除去有机前体是主要的控制措施。消毒不足的微生物风险远大于 DBP 的风险，这正是 WHO《饮用水水质准则》（*Guidelines for Drinking-water Quality*）的一贯立场：绝不能为控制副产物而牺牲消毒。

## 污水处理

城市污水携带有机物（BOD 达数百 $\mathrm{mg\,dm^{-3}}$）、悬浮固体、铵、磷酸盐、病原体和大量微污染物。常规处理分级除去它们：**一级**沉淀除去固体；**二级**生物处理，通常是活性污泥法，曝气的细菌絮体把有机物氧化为 $\mathrm{CO_2}$ 和生物质，去除 $90\ \%$ 以上的 BOD；以及针对营养盐的**三级**处理。氮先经硝化（曝气池中 $\mathrm{NH_4^+ \rightarrow NO_3^-}$）再经反硝化去除（缺氧池中 $\mathrm{NO_3^- \rightarrow N_2}$，利用污水自身的有机碳作电子供体）——这是按设计应用的 [[environmental-chemistry/natural-waters]] 氧化还原阶梯。磷用铁盐或铝盐沉淀，或以"强化生物除磷"除去。污泥经厌氧消化产生沼气（甲烷），或以其它方式处置。

监管情况，如实陈述：在欧盟，1991 年《城市污水处理指令》已重订为指令（EU）2024/3019，该指令除其它外扩大了三级处理的适用范围，并要求大型污水厂引入"四级"处理以去除微污染物（臭氧氧化或活性炭），其成本在生产者责任延伸制度下部分由制药和化妆品生产者承担；在美国，排放依据《清洁水法》（1972 年）通过许可证制度监管。

## 受污染土地与地下水的修复

受污染场地——旧煤气厂、化工厂、加油站、垃圾填埋场、矿山、军事基地——依据立法管理，如美国《综合环境反应、赔偿和责任法》（CERCLA，即"超级基金"，1980 年）和英国 1990 年《环境保护法》第 2A 部分。修复决策以风险为基础：只有当污染物、途径和受体同时存在时，污染物才构成问题。本课的化学决定了哪些方案可行。

**抽出处理**把受污染的地下水抽出并在地面处理（挥发物用气提，另有活性炭、氧化）。它受到吸附的限制。

::: proposition 冲洗吸附性污染物 {#prop-flushing}
把污染带当作孔隙体积为 $V_\mathrm{p} = nV$ 的充分混合储库，以体积流量 $Q$ 用洁净水冲洗，吸附线性、可逆、快速，用阻滞因子 $R_\mathrm{f}$ 描述（[[environmental-chemistry/pollutants-fate#prop-retardation]]）。溶解浓度于是按
$$
\frac{C}{C_0} = \exp\!\left(-\frac{\mathrm{PV}}{R_\mathrm{f}}\right),
$$
衰减，其中 $\mathrm{PV} = Qt/V_\mathrm{p}$ 是已冲出的孔隙体积数。把浓度降低 $F$ 倍需要 $R_\mathrm{f}\ln F$ 个孔隙体积。条件：充分混合的污染带、平衡吸附、无降解。真实场地表现更差（拖尾），因为有机质上的脱附缓慢、低渗透带中的扩散缓慢，还因为非水相液体在不断溶出。
:::

::: proof 含吸附的质量衡算 {#proof-flushing}
带内总量为 $(V_\mathrm{p} + m_\mathrm{s}K_\mathrm{d})C = V_\mathrm{p}R_\mathrm{f}C$，因为 $R_\mathrm{f} = 1 + \rho_\mathrm{b}K_\mathrm{d}/n = 1 + m_\mathrm{s}K_\mathrm{d}/V_\mathrm{p}$。只有溶解部分流出，流出速率为 $QC$。故 $V_\mathrm{p}R_\mathrm{f}\,\mathrm{d}C/\mathrm{d}t = -QC$，于是 $C = C_0\exp[-Qt/(V_\mathrm{p}R_\mathrm{f})] = C_0\exp(-\mathrm{PV}/R_\mathrm{f})$。令 $C/C_0 = 1/F$ 即得 $\mathrm{PV} = R_\mathrm{f}\ln F$。
:::

**土壤气相抽提**通过对非饱和带抽真空除去挥发性化合物（苯、三氯乙烯），利用的是 $K_\mathrm{aw}$。**生物修复**刺激微生物降解有机污染物：石油烃好氧降解，因此要供氧（空气注入）和营养物；四氯乙烯（PCE）和三氯乙烯（TCE）等氯代乙烯在厌氧条件下被脱卤呼吸细菌（例如 *Dehalococcoides*）*还原*降解，它们以这些化合物为电子受体，所以要注入电子供体（乳酸盐、植物油）。**监测自然衰减**依赖已经发生的降解、吸附和稀释，并以监测数据加以证明。**原位化学氧化**注入高锰酸盐、过硫酸盐或铁活化的过氧化氢（芬顿试剂，产生羟基自由基）。**可渗透反应屏障**是横切羽流开挖、充填反应介质的沟槽；最常用的是颗粒**零价铁**，它在自己腐蚀的表面把氯代溶剂还原：
$$
\mathrm{Fe(s)} \rightarrow \mathrm{Fe^{2+}} + 2\,\mathrm{e^-},\qquad
\mathrm{R{-}Cl} + \mathrm{H^+} + 2\,\mathrm{e^-} \rightarrow \mathrm{R{-}H} + \mathrm{Cl^-} .
$$
金属不能被销毁，因此只能除去（挖掘、土壤淋洗）、固定（投加磷酸盐把铅转化为极难溶的氯磷铅矿 $\mathrm{Pb_5(PO_4)_3Cl}$；提高 pH；投加铁氧化物结合砷）或用植物提取（植物提取，缓慢且仅限于少数超富集物种）。

::: example 反应屏障的用铁量 {#ex-zvi}
三氯乙烯 $\mathrm{C_2HCl_3}$ 在零价铁表面被完全还原为乙烯 $\mathrm{C_2H_4}$。(a) 写出总反应。(b) 每千克 TCE 按化学计量消耗多少铁？(c) 为什么实际消耗大得多？
::: solution
(a) 三步氢解，每步 $\mathrm{R{-}Cl + H^+ + 2\,e^- \rightarrow R{-}H + Cl^-}$，取代三个氯：$\mathrm{C_2HCl_3} + 3\,\mathrm{H^+} + 6\,\mathrm{e^-} \rightarrow \mathrm{C_2H_4} + 3\,\mathrm{Cl^-}$。配上三个 $\mathrm{Fe \rightarrow Fe^{2+} + 2\,e^-}$：
$$
\mathrm{C_2HCl_3} + 3\,\mathrm{Fe} + 3\,\mathrm{H^+} \rightarrow \mathrm{C_2H_4} + 3\,\mathrm{Fe^{2+}} + 3\,\mathrm{Cl^-} .
$$
（在屏障中，途径主要是经氯乙炔和乙炔的 $\beta$-消除，总电子数相同。）(b) 每千克 TCE $3\times55.85/131.39 = 1.28\ \mathrm{kg}$ 铁。(c) 铁还会因还原水而腐蚀，$\mathrm{Fe + 2\,H_2O \rightarrow Fe^{2+} + H_2 + 2\,OH^-}$，以及还原地下水中的溶解氧、硝酸盐和硫酸盐；这些副反应消耗的铁远多于 TCE，并沉淀出碳酸盐和氢氧化物，使屏障逐渐钝化。因此屏障的设计考虑的是数十年的腐蚀，而不是污染物的化学计量。注意该反应还抬高 pH 并产生氢，脱卤细菌能利用氢——化学与生物在此协同。
:::
:::

::: quiz
某场地地下水同时被苯和四氯乙烯（PCE）污染。一位顾问建议注入空气以刺激好氧生物降解。主要的化学反对意见是什么？
- [ ] 苯不能好氧生物降解。
- [x] PCE 主要在厌氧条件下经*还原*脱氯降解；加氧有利于苯的降解，却抑制 PCE 的脱氯。
- [ ] 注气会提高 PCE 的 $K_\mathrm{ow}$。
- [ ] 氧与 PCE 发生爆炸性反应。
::: solution
高氯代乙烯缺电子，充当电子*受体*；它们的微生物降解需要还原条件和电子供体。苯是电子供体，在有氧条件下降解迅速。混合羽流因此常分区或按顺序处理——而在一些天然羽流中，苯等燃料化合物正是驱动 PCE 脱氯的电子供体。
:::
:::

::: warning 把污染物从一个相移走不等于把它销毁 {#warn-transfer}
许多处理和修复步骤转移污染物而非销毁污染物。气提把挥发物从水移入空气（空气随后仍需处理）；活性炭和离子交换把污染物富集到必须再生或处置的介质上；混凝把金属送进污泥；土壤淋洗产生浓缩的细粒组分；反渗透产生浓缩液。PFAS 是当前最清楚的例子：从饮用水中去除是有效的，但废炭或废树脂和浓缩液里是同样几乎不可降解的化合物，需要高温销毁或安全封存。永远把质量衡算追到底——问污染物去了哪里，而不只是问它是否离开了水。
:::

::: history
系统的土壤化学始于约翰·托马斯·韦（John Thomas Way）1850 年为英国皇家农业学会所做的实验，他证明土壤以等当量把铵交换为钙——即阳离子交换的发现——其先声是哈里·汤普森（Harry Thompson）1845 年的观测。欧文·朗缪尔（Irving Langmuir）的吸附等温式（1916–18 年，针对气体在固体上的吸附）与赫伯特·弗罗因德利希（Herbert Freundlich）的经验方程（1906 年）很快被用于土壤。公共供水的氯化 1908 年在泽西城开始，此后被广泛采用，彻底改变了公共健康；荷兰的约翰内斯·鲁克（Johannes Rook）与美国环保局同年发现氯化水中的三卤甲烷，由此开启了消毒副产物的研究。活性污泥法由爱德华·阿登（Edward Ardern）与威廉·洛基特（William Lockett）于 1914 年在曼彻斯特发明。零价铁屏障由罗伯特·吉尔汉姆（Robert Gillham）与斯蒂芬妮·奥汉内辛（Stephanie O'Hannesin）于 1990 年代初在滑铁卢大学提出。
:::

## 后续内容

判定土壤或水体是否达标的分析方法，以及让这些数字站得住脚的质量控制，是 [[environmental-chemistry/environmental-monitoring]] 的主题。从一开始就不制造污染土地的过程设计——更安全的溶剂、催化、废物最小化——是 [[green-chemistry/safer-solvents]] 与 [[green-chemistry/circular-economy]] 的纲领。氧化物的表面化学与双电层在 [[electrochemistry/double-layer]] 中讨论，作为反应屏障驱动力的铁的腐蚀在 [[electrochemistry/corrosion]] 中讨论。

::: summary
- 土壤固体由原生矿物、黏土（2:1 型黏土靠类质同象替代留下永久负电荷）、可变电荷氧化物（pzc 以下带正电，结合含氧酸根阴离子）和有机质（单位质量电荷最大，疏水有机物的主要吸附剂）构成。
- CEC（$\mathrm{cmol(+)\,kg^{-1}}$）与盐基饱和度描述土壤的交换复合体；阳离子按 $\mathrm{Al^{3+}} > \mathrm{Ca^{2+}} > \mathrm{Mg^{2+}} > \mathrm{K^+} > \mathrm{Na^+}$ 的顺序被保持，稀释有利于二价离子（浓度-价效应）。
- 朗缪尔等温式（$q = q_\text{max}K_\mathrm{L}C/(1 + K_\mathrm{L}C)$）会饱和；弗罗因德利希等温式是描述非均相表面的经验幂律。
- 饮用水处理：铝盐或铁盐混凝（每毫克明矾消耗 $0.51\ \mathrm{mg\,dm^{-3}}$ 碱度，以 $\mathrm{CaCO_3}$ 计）、过滤、吸附与消毒；消毒能力取决于 HOCl 分数 $1/(1 + 10^{\mathrm{pH} - 7.54})$ 和 Ct。
- 氯化生成 DBP（三卤甲烷、卤乙酸），通过除去有机前体控制；微生物安全优先。
- 污水处理按设计利用氧化还原阶梯（好氧去 BOD、硝化、反硝化），辅以化学沉淀除磷。
- 抽出处理要使浓度降低 $F$ 倍需要 $R_\mathrm{f}\ln F$ 个孔隙体积；还原脱氯（生物或零价铁）、氧化、气相抽提和固定化按污染物化学选型。许多处理转移而非销毁污染物。
:::

::: exercise 估算 CEC {level=1 check="26"}
某土壤含 $20\ \%$ 蒙皂石（CEC $100\ \mathrm{cmol(+)\,kg^{-1}}$）、$3.0\ \%$ 有机质（测定 pH 下 CEC $200\ \mathrm{cmol(+)\,kg^{-1}}$），以及 CEC 可忽略的石英和长石。估算该土壤的 CEC。（以 $\mathrm{cmol(+)\,kg^{-1}}$ 填入。）
::: solution
$0.20\times100 + 0.030\times200 = 20 + 6 = 26\ \mathrm{cmol(+)\,kg^{-1}}$。可加性只是近似（有机质包裹黏土并封闭部分位点），但它说明了为什么百分之几的腐殖质与大量的黏土同样要紧。
:::

::: solution
$100/(1 + 10^{0.46}) = 100/3.88 = 26\ \%$。

::: exercise 明矾消耗的碱度 {level=1 check="15"}
某水厂投加 $30\ \mathrm{mg\,dm^{-3}}$ 明矾 $\mathrm{Al_2(SO_4)_3{\cdot}14H_2O}$（$594\ \mathrm{g\,mol^{-1}}$）。消耗多少碱度？（以 $\mathrm{mg\,dm^{-3}}$（$\mathrm{CaCO_3}$ 计）填入，保留两位有效数字。）
::: solution
$30/594 = 0.0505\ \mathrm{mmol\,dm^{-3}}$ 明矾消耗 $6\times0.0505 = 0.303\ \mathrm{meq\,dm^{-3}}$，即 $0.303\times50.04 = 15\ \mathrm{mg\,dm^{-3}}$（以 $\mathrm{CaCO_3}$ 计）。碱度只有 $20\ \mathrm{mg\,dm^{-3}}$ 的水将几乎失去缓冲，需要投加碱。
:::

::: exercise 间歇处理的活性炭用量 {level=2 check="4.8"}
某农药在活性炭上的吸附服从朗缪尔等温式，$q_\text{max} = 10\ \mathrm{mg\,g^{-1}}$，$K_\mathrm{L} = 0.50\ \mathrm{dm^3\,mg^{-1}}$。要把 $1.00\ \mathrm{m^3}$ 水的浓度在平衡时从 $10.0$ 降到 $0.50\ \mathrm{mg\,dm^{-3}}$，必须搅拌加入多少炭？（质量以 kg 计，保留两位有效数字。）
::: solution
在最终浓度下，$q = 10\times0.50\times0.50/(1 + 0.25) = 2.0\ \mathrm{mg\,g^{-1}}$。除去的农药为 $(10.0 - 0.50)\ \mathrm{mg\,dm^{-3}}\times1000\ \mathrm{dm^3} = 9500\ \mathrm{mg}$，故需炭 $9500/2.0 = 4750\ \mathrm{g} \approx 4.8\ \mathrm{kg}$。炭是与*最终*的低浓度平衡的，此时它的负载只有容量的五分之一；固定床柱的进炭端与*进水*浓度平衡，用炭效率要高得多。
:::
:::

::: exercise 石灰需要量 {level=2 check="4.5"}
某牧地土壤（$0$–$25\ \mathrm{cm}$，容重 $1.20\ \mathrm{g\,cm^{-3}}$）有 $3.0\ \mathrm{cmol(+)\,kg^{-1}}$ 交换性酸。每公顷需要多少 $\mathrm{CaCO_3}$ 才能中和？（质量以吨计，保留两位有效数字。）
::: solution
土壤质量：$10^{4}\times0.25\times1200 = 3.0\times10^{6}\ \mathrm{kg}$；酸量 $3.0\times10^{6}\times0.030 = 9.0\times10^{4}\ \mathrm{mol(+)}$；$\mathrm{CaCO_3} = 4.5\times10^{4}\ \mathrm{mol} = 4.5\times10^{6}\ \mathrm{g} = 4.5\ \mathrm{t\,ha^{-1}}$。
:::

::: exercise 消毒接触时间 {level=2 check="2.0"}
对某种病毒和 pH $7$、$10\ \mathrm{°C}$ 的游离氯，奇克-沃森定律成立且 $n = 1$、$k = 4.6\ \mathrm{dm^3\,mg^{-1}\,min^{-1}}$（以 $e$ 为底）。$0.50\ \mathrm{mg\,dm^{-3}}$ 下达到 $2$ 对数（$99\ \%$）失活需要多长接触时间？（$t$ 以分钟计，保留两位有效数字。）
::: solution
$\ln(N_0/N) = \ln100 = 4.61 = kCt$，故 $Ct = 4.61/4.6 = 1.0\ \mathrm{mg\,min\,dm^{-3}}$，$t = 1.0/0.50 = 2.0\ \mathrm{min}$。$4$ 对数失活需要两倍的 Ct。真实污水厂会施加安全系数，并连续校核余氯。
:::
:::

::: exercise 抽出处理的孔隙体积数 {level=3 check="29"}
(a) 由质量衡算导出[[#prop-flushing]]。(b) 对 $R_\mathrm{f} = 6.4$ 的萘，要把溶解浓度降低一百倍须抽出多少孔隙体积？(c) 若慢脱附造成的拖尾意味着只有一半吸附质量处于快速平衡，其余部分以 $0.010\ \mathrm{d^{-1}}$ 的一级速率常数释放，定性说明浓度-时间曲线如何变化。（填入 (b) 的孔隙体积数，保留两位有效数字。）
::: solution
(a) 同[[#proof-flushing]]：总质量 $V_\mathrm{p}R_\mathrm{f}C$，流出速率 $QC$，故 $C = C_0e^{-\mathrm{PV}/R_\mathrm{f}}$。(b) $\mathrm{PV} = R_\mathrm{f}\ln100 = 6.4\times4.605 = 29$。(c) 快平衡部分在 $R_\mathrm{f}$ 个孔隙体积的时间尺度上被冲出（有效 $R_\mathrm{f}$ 较小），出现初期的快速下降；随后浓度被慢脱附维持的"拖尾"稳住，只按脱附时间常数（$1/0.010 = 100\ \mathrm{d}$）衰减，与抽得多快无关。停止抽出后，慢组分重新平衡，浓度"反弹"。这两种行为都经常被观测到，这就是修复目标常定为基于风险的浓度而非本底值的原因。
:::

::: exercise 灌溉土壤的钠化 {level=3 check="0.87"}
对[[#ex-exchange]]的交换相（$K_\mathrm{GT} = 0.10\ \mathrm{mol\,dm^{-3}}$），求土壤溶液含 $1.0\ \mathrm{mmol\,dm^{-3}}$ $\mathrm{Na^+}$ 和 $0.50\ \mathrm{mmol\,dm^{-3}}$ $\mathrm{Ca^{2+}}$ 时的 $E_\mathrm{Ca}$。然后利用[[#prop-exchange]]说明：为什么把同样的水蒸发浓缩十倍会增加交换相上的钠，以及这为什么危害土壤结构。（$E_\mathrm{Ca}$ 保留两位有效数字。）
::: solution
$[\mathrm{Ca^{2+}}]/[\mathrm{Na^+}]^2 = 5.0\times10^{-4}/(1.0\times10^{-3})^2 = 500$，故 $E_\mathrm{Ca}/(1 - E_\mathrm{Ca})^2 = 50$；解 $50E^2 - 101E + 50 = 0$ 得 $E_\mathrm{Ca} = (101 - \sqrt{201})/100 = 0.87$。这正是例题中被稀释了十倍的溶液。把它浓缩十倍就回到例题原来的溶液，那时 $E_\mathrm{Ca} = 0.64$、$E_\mathrm{Na} = 0.36$：交换性钠百分比从 $13\ \%$ 升到 $36\ \%$，而水中 Na/Ca 比毫无变化。交换性钠超过约 $15\ \%$ 后，黏土在低矿化度水中会胀散，因为一价离子形成把颗粒相互推开的厚扩散双电层；团粒崩溃、孔隙堵塞、入渗下降。补救方法是施用石膏（$\mathrm{CaSO_4{\cdot}2H_2O}$），提供钙去交换钠。
