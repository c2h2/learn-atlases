一氧化碳是一个很弱的碱。它几乎不溶于酸，偶极矩只有 $0.11\ \mathrm{D}$，在通常条件下不与 $\mathrm{BF_3}$ 或质子生成加合物。然而它在光谱化学序列中居于最顶端，在氰化物之上，并与铬(0)、铁(0)、镍(0)结合，生成稳定的、挥发性的、抗磁性的分子 $\mathrm{[Cr(CO)_6]}$、$\mathrm{[Fe(CO)_5]}$ 与 $\mathrm{[Ni(CO)_4]}$，其中金属根本没有可以用来吸引配体的电荷。相反，氟离子又硬又小、带负电荷，按点电荷的观点本该是全部配体里最强的，实际上却是弱场配体。[[coordination-chemistry/crystal-field-theory]]末尾的警告说得直白：光谱化学序列不是静电的。

出路是把金属-配体相互作用当作真正的化学键来处理。**配体场理论**就是把分子轨道理论用于配合物：金属的价层 $s$、$p$、$d$ 轨道与对称性相同的配体轨道组合，分裂能 $\Delta_\mathrm{o}$ 则表现为非键（或 π 成键、π 反键）的 $t_{2g}$ 组与反键 $e_g^*$ 组之间的能隙。晶体场理论做对的一切——$2 + 3$ 图样、自旋状态判据、姜-泰勒效应——它全部保留，因为这些来自对称性；而晶体场理论做错的，它补上了：π 给与和 π 反馈的作用，光谱与磁共振中看到的共价性，以及支配金属羰基化合物与有机金属化合物的 **18 电子规则**。本章用[[quantum-chemistry/molecular-symmetry]]的工具搭建八面体 MO 图，加上 π 成键，引入角重叠模型作为其定量版本，最后讲电子计数。

## σ 成键的配体群轨道

取八面体配合物 $\mathrm{ML_6}$，先假设每个配体只有一个伸向金属的轨道：一对孤对电子，关于 M–L 轴呈 $\sigma$ 对称。把配体编号为 1（$+x$）、2（$+y$）、3（$-x$）、4（$-y$）、5（$+z$）、6（$-z$），它们的给体轨道记作 $\sigma_1, \dots, \sigma_6$。金属的价层轨道是 $3d$、$4s$、$4p$（第一过渡系）。我们不是让每个金属轨道分别与各配体轨道相互作用，而是先把六个配体轨道组合成对称性匹配的线性组合，使每一个组合至多与一类金属轨道相互作用。

::: definition 配体群轨道 {#def-lgo}
**配体群轨道**（LGO，或称对称性匹配的线性组合，SALC）是按配合物点群的某一个不可约表示变换的配体轨道线性组合。只有*同一*不可约表示的金属轨道与配体群轨道才有非零重叠；它们组合成成键与反键分子轨道，而找不到匹配 LGO 的金属轨道是**非键**的。
:::

::: proposition 八面体的 σ 配体群轨道 {#prop-sigma-lgo}
在 $O_h$ 中，六个配体 σ 轨道约化为
$$
\Gamma_\sigma = A_{1g} + E_g + T_{1u}.
$$ {#eq-gamma-sigma}
金属的 $4s$ 轨道是 $a_{1g}$，三个 $4p$ 轨道是 $t_{1u}$，$3d$ 轨道分成 $e_g$（$d_{z^2}$、$d_{x^2-y^2}$）与 $t_{2g}$（$d_{xy}$、$d_{xz}$、$d_{yz}$）。因此 $s$、$p$ 与 $e_g$ 这一对形成 σ 键，而 $t_{2g}$ 没有 σ 对称的伙伴。归一化的 LGO（略去配体间重叠）为
$$
\begin{aligned}
a_{1g}&: \tfrac{1}{\sqrt6}(\sigma_1 + \sigma_2 + \sigma_3 + \sigma_4 + \sigma_5 + \sigma_6),\\
e_g&: \tfrac{1}{2}(\sigma_1 - \sigma_2 + \sigma_3 - \sigma_4), \quad \tfrac{1}{\sqrt{12}}(2\sigma_5 + 2\sigma_6 - \sigma_1 - \sigma_2 - \sigma_3 - \sigma_4),\\
t_{1u}&: \tfrac{1}{\sqrt2}(\sigma_1 - \sigma_3),\quad \tfrac{1}{\sqrt2}(\sigma_2 - \sigma_4),\quad \tfrac{1}{\sqrt2}(\sigma_5 - \sigma_6).
\end{aligned}
$$
:::

::: proof
可约表示 $\Gamma_\sigma$ 在某个操作下的特征标，等于保持不动的配体 σ 轨道数（每个这样的轨道贡献 $+1$；被挪动的轨道贡献 $0$）。依次考察 $O_h$ 的每个类：$E$ 保留全部 6 个；$8C_3$（绕体对角线）全部挪动，$0$；$6C_2$（绕穿过棱中点的面对角线）全部挪动，$0$；$6C_4$（绕坐标轴）保留该轴上的 2 个；$3C_2 = C_4^2$ 保留 2 个；$i$ 全部挪动，$0$；$6S_4$ 一个都不保留，$0$（$C_4$ 部分保住了轴向的一对，但反映紧接着把它们互换）；$8S_6$，$0$；$3\sigma_h$（坐标平面）保留面内 4 个；$6\sigma_d$（包含一条轴并平分另两条轴的平面）保留该轴上的 2 个。于是
$$
\chi(\Gamma_\sigma) = (6, 0, 0, 2, 2, 0, 0, 0, 4, 2).
$$
用约化公式 $n_i = \frac{1}{h}\sum_R g_R\,\chi(R)\,\chi_i(R)$，取 $h = 48$ 与 $O_h$ 特征标表，对 $A_{1g}$：$\frac{1}{48}(6 + 6\cdot2 + 3\cdot2 + 3\cdot4 + 6\cdot2) = \frac{48}{48} = 1$。对 $E_g$（特征标 $2, -1, 0, 0, 2, 2, 0, -1, 2, 0$）：$\frac{1}{48}(12 + 0 + 3\cdot2\cdot2 + 3\cdot4\cdot2) = \frac{48}{48} = 1$。对 $T_{1u}$（特征标 $3, 0, -1, 1, -1, -3, -1, 0, 1, 1$）：$\frac{1}{48}(18 + 6\cdot2\cdot1 + 3\cdot2\cdot(-1) + 3\cdot4\cdot1 + 6\cdot2\cdot1) = \frac{48}{48} = 1$。其余不可约表示全给出零，而且维数对得上，$1 + 2 + 3 = 6$。

具体的组合可由符号与每个金属轨道的瓣匹配写出：$4s$ 处处为正，所以各配体以相同符号进入；$d_{x^2-y^2}$ 沿 $\pm x$ 为正、沿 $\pm y$ 为负；$d_{z^2}$ 沿 $\pm z$ 有两个大的正瓣，在 $xy$ 平面上有一个小的负环，与权重 $2, 2, -1, -1, -1, -1$ 相匹配；每个 $p$ 轨道经过金属变号，恰与其轴上那对配体的 $\sigma_k - \sigma_{k'}$ 匹配。归一化常数使系数平方和为 1。
:::

MO 图现在由三条事实即可画出。配体的给体轨道在能量上位于金属 $d$ 轨道*之下*（它们是电负性原子上的孤对电子）；金属的 $4s$ 与 $4p$ 在 $3d$ *之上*；而与 $e_g$ 的重叠相当可观。于是得到六个成键 MO（$a_{1g}$、$t_{1u}$、$e_g$），以配体成分为主；非键的 $t_{2g}$ 组，是纯金属 $d$；反键的 $e_g^*$，以金属 $d$ 为主；再高些是反键的 $a_{1g}^*$ 与 $t_{1u}^*$。六对配体孤对电子的十二个电子填满成键轨道，金属的 $d$ 电子则进入 $t_{2g}$ 与 $e_g^*$。二者之间的能隙就是 $\Delta_\mathrm{o}$。

::: intuition Δo 现在意味着什么
在晶体场理论中，$\Delta_\mathrm{o}$ 度量配体电荷对 $e_g$ 的挤压比对 $t_{2g}$ 强多少。在配体场理论中，它度量 $e_g^*$ 轨道*反键*到什么程度：σ 相互作用越强，$e_g^*$ 就被推得离 $d$ 能级越高，$\Delta_\mathrm{o}$ 就越大。好的 σ 给体，是其给体轨道与 $d_{z^2}$、$d_{x^2-y^2}$ 重叠好、能量上又不太低于它们的配体。这就是为什么 $\mathrm{NH_3}$ 与 $\mathrm{CH_3^-}$ 富电子、位置高的孤对电子是强 σ 给体，而氟离子收缩、位置低的 $2p$ 孤对电子是差的 σ 给体——无论电荷如何。
:::

::: example 填充只有 σ 的 MO 图 {#ex-sigma-filling}
用只有 σ 的 MO 图，写出 (a) $\mathrm{[Co(NH_3)_6]^{3+}}$ 与 (b) $\mathrm{[Ni(NH_3)_6]^{2+}}$ 的电子组态，并说明哪些电子定域在金属上。(a) 中每条 Co–N 键的键级是多少？(b) 与之有何不同？
::: solution
(a) 每个 $\mathrm{NH_3}$ 给出两个电子（共 12 个），钴(III)为 $d^6$：共 18 个价电子。十二个配体电子填满 $a_{1g}^2t_{1u}^6e_g^4$；六个金属电子在强场下填满 $t_{2g}^6$，$e_g^*$ 空置。组态为 $(a_{1g})^2(t_{1u})^6(e_g)^4(t_{2g})^6$。六个成键 MO 全满、没有反键 MO 被占据，所以有六条 σ 键，每个 Co–N 接触一条：键级 1。(b) 镍(II)为 $d^8$：20 个价电子，$(a_{1g})^2(t_{1u})^6(e_g)^4(t_{2g})^6(e_g^*)^2$。两个电子进入反键的 $e_g^*$ 组，抵消掉相当于一对成键电子的 σ 成键，摊到六个接触上：每条 Ni–N 键的键级为 $(12 - 2)/2 \div 6 = 5/6$。这与 $\mathrm{[Ni(NH_3)_6]^{2+}}$ 的 Ni–N 键更长、更弱、更活泼相一致——它交换氨只需几毫秒，而 $\mathrm{[Co(NH_3)_6]^{3+}}$ 要几小时甚至几天（[[coordination-chemistry/inorganic-mechanisms]]）。
:::

## π 成键与光谱化学序列

许多配体还有关于 M–L 轴呈 π 对称的轨道：卤离子垂直于键的两对孤对电子；CO、$\mathrm{CN^-}$、bpy 或 $\mathrm{NO^+}$ 的空 $\pi^*$ 轨道；或者膦的空 $\sigma^*$／$3d$ 型受体轨道。每个配体有两个 π 轨道，八面体的十二个配体 π 函数约化为 $T_{1g} + T_{2g} + T_{1u} + T_{2u}$（计数方法与[[#prop-sigma-lgo]]相同）。其中 $T_{1g}$ 与 $T_{2u}$ 与金属的任何价层轨道都不匹配，保持为配体非键；$T_{1u}$ 只能与已经用于 σ 成键的金属 $p$ 轨道弱混合；而 $T_{2g}$ 恰好匹配 σ 相互作用留下的三个非键 $d$ 轨道。**π 成键正是发生在 $t_{2g}$ 上的事。**

::: proposition π 相互作用对 Δo 的影响 {#prop-pi-effect}
设金属 $t_{2g}$ 能级在 $E_d$，配体的 $t_{2g}$ 型 LGO 在 $E_\mathrm{L}$，相互作用矩阵元为 $\beta_\pi$（忽略重叠）。则金属为主的 $t_{2g}$ 轨道的移动为
$$
\delta E(t_{2g}) = \tfrac12\left[(E_\mathrm{L} - E_d) \mp \sqrt{(E_\mathrm{L} - E_d)^2 + 4\beta_\pi^2}\,\right] \approx \frac{\beta_\pi^2}{E_d - E_\mathrm{L}}, \qquad |\beta_\pi| \ll |E_d - E_\mathrm{L}|,
$$ {#eq-pi-shift}
$E_\mathrm{L} > E_d$ 时取上号，$E_\mathrm{L} < E_d$ 时取下号。充满的配体 π 组若位于 $E_d$ **之下**（**π 给体**），会抬高金属的 $t_{2g}$——后者变成 π 反键——从而**减小** $\Delta_\mathrm{o}$。空的配体 π 组若位于 $E_d$ **之上**（**π 受体**），会压低金属的 $t_{2g}$——后者变成 π 成键——从而**增大** $\Delta_\mathrm{o}$。$e_g^*$ 能级在这一级近似下不受影响，因为它没有 π 对称的伙伴。
:::

::: proof
对 $t_{2g}$ 的每个分量（由对称性三者行为相同），两个相互作用的轨道给出行列式
$$
\begin{vmatrix} E_d - E & \beta_\pi \\ \beta_\pi & E_\mathrm{L} - E \end{vmatrix} = 0
\quad\Longrightarrow\quad
E_\pm = \tfrac12(E_d + E_\mathrm{L}) \pm \tfrac12\sqrt{(E_d - E_\mathrm{L})^2 + 4\beta_\pi^2}.
$$
金属为主的轨道是靠近 $E_d$ 的那个根。记 $x = E_\mathrm{L} - E_d$。若 $x < 0$（配体在下方），金属为主的根是 $E_+$，且 $E_+ - E_d = \tfrac12[x + \sqrt{x^2 + 4\beta_\pi^2}] > 0$：被抬高。若 $x > 0$（配体在上方），根是 $E_-$，且 $E_- - E_d = \tfrac12[x - \sqrt{x^2 + 4\beta_\pi^2}] < 0$：被压低。对 $4\beta_\pi^2 \ll x^2$ 展开根式，$\sqrt{x^2 + 4\beta_\pi^2} \approx |x|(1 + 2\beta_\pi^2/x^2)$，两种情形都给出 $\delta E \approx -\beta_\pi^2/x = \beta_\pi^2/(E_d - E_\mathrm{L})$：配体能级在下方为正，在上方为负。由于 $\Delta_\mathrm{o} = E(e_g^*) - E(t_{2g})$ 且 $E(e_g^*)$ 由 σ 成键固定，抬高 $t_{2g}$ 减小 $\Delta_\mathrm{o}$，压低它则增大 $\Delta_\mathrm{o}$。配体轨道是充满还是空置，关系到电子计数：下方充满的给体组贡献的成键电子留在配体一侧；上方空的受体组则让金属的 $t_{2g}$ 电子离域到配体上，这就是**反馈**（back-donation，反馈成键）。
:::

:::

现在光谱化学序列可以理解为一个三段的排序：
$$
\underbrace{\mathrm{I^- < Br^- < Cl^- < F^- < OH^-}}_{\sigma\text{ 给体} + \pi\text{ 给体}} \;<\; \underbrace{\mathrm{H_2O < NH_3 < en}}_{\text{仅 }\sigma\text{ 给体}} \;<\; \underbrace{\mathrm{bpy < phen < CN^- < CO}}_{\sigma\text{ 给体} + \pi\text{ 受体}}.
$$
卤离子有两对垂直于键的充满 $p$ 孤对电子，是 π 给体；氢氧根与氧离子更是如此。水有一个 π 型孤对电子，是弱 π 给体；氨一个也没有，是纯 σ 给体，这就是它强于水的原因。强场一端是带位置低的空 π* 轨道的配体。卤离子内部碘最弱，因为它的 σ 给体轨道弥散、重叠差，而 π 给与仍然可观。甚至氢负离子与甲基——没有 π 轨道的纯 σ 给体——也是强场配体，因为它们位置高的 σ 轨道与 $e_g$ 的相互作用非常强。

::: warning 反馈不是同一位置上的第二条键 {#warn-back-bonding}
学生有时把金属羰基化合物中的反馈想象成电子沿同一条 σ 键流回去。它其实是一个对称性不同的独立相互作用。σ 键用碳的孤对电子（CO 的 $5\sigma$ 轨道）与金属的 $e_g$（以及 $s$、$p$）轨道；π 反馈用充满的金属 $t_{2g}$ 轨道与 CO 的两个空 $2\pi^*$ 轨道，后者垂直于 M–C 轴。两个相互作用互相加强（**协同**成键）：σ 给与使金属更富电子，从而增强反馈；反馈又反过来把电子密度从金属移走，让它能接受更多 σ 密度。另一个错误是认为 π 受体"吸电子"、会使金属带正电。它们稳定的恰恰是**低**氧化态——那里金属有可给的充满 $t_{2g}$ 电子。高氧化态金属的羰基化合物几乎不存在，因为没有 $t_{2g}$ 电子的金属无法反馈。
:::

### 反馈的证据：羰基的伸缩振动频率

进入 CO 的 $2\pi^*$ 轨道的电子削弱 C–O 键，所以红外中 C–O 伸缩振动频率 $\tilde\nu(\mathrm{CO})$ 是反馈强弱的直接探针（[[spectroscopy/vibrational-spectroscopy]]）。游离 CO 在 $2143\ \mathrm{cm^{-1}}$ 吸收。金属羰基化合物中谱带位置更低，并随等电子系列中金属电荷的改变而系统移动。

## 角重叠模型

配体场理论的 MO 形式若不计算重叠与能量就只是定性的。克劳斯·谢费尔（Claus Schäffer）与克里斯蒂安·克利克斯比尔·约根森（Christian Klixbüll Jørgensen）的**角重叠模型**（AOM）保留 MO 图像但把它参数化：每个金属-配体接触贡献一个 σ 参数 $e_\sigma$ 与一个 π 参数 $e_\pi$（每个 π 方向一个），几何构型只通过角因子进入。σ 部分我们已在[[coordination-chemistry/crystal-field-theory#prop-tetrahedral]]中作为记账工具见过；现在为它提供依据并加上 π。

::: proposition d 轨道的 AOM 能量 {#prop-aom}
对金属-配体重叠取到二阶，方向 $\hat{\mathbf n}$ 上的配体使金属 $d$ 轨道升高的反键移动为 $e_\sigma F_\sigma^2 + e_\pi(F_{\pi x}^2 + F_{\pi y}^2)$，其中 $F$ 是角重叠因子，$\lambda = \sigma, \pi$ 时 $e_\lambda = \beta_\lambda^2/(E_d - E_\mathrm{L})$。不同配体的移动相加。对配体相同的八面体与四面体，
$$
\begin{aligned}
O_h&: \quad E(e_g) = 3e_\sigma, \qquad E(t_{2g}) = 4e_\pi, \qquad \Delta_\mathrm{o} = 3e_\sigma - 4e_\pi,\\
T_d&: \quad E(e) = \tfrac83 e_\pi, \qquad E(t_2) = \tfrac43 e_\sigma + \tfrac89 e_\pi, \qquad \Delta_\mathrm{t} = \tfrac43 e_\sigma - \tfrac{16}{9} e_\pi = \tfrac49\Delta_\mathrm{o}.
\end{aligned}
$$ {#eq-aom}
π 给体的 $e_\pi > 0$，π 受体的 $e_\pi < 0$。模型把每条 M–L 相互作用当作独立事件，忽略 $s$–$d$ 混合与配体间相互作用；它描述的是 $d$ 轨道能量，不是总成键能。
:::

::: proof
每个 $d$ 轨道与单个配体轨道的相互作用是一个二能级问题。由[[#eq-pi-shift]]，$|\beta| \ll |E_d - E_\mathrm{L}|$ 时，金属为主的轨道移动 $\beta^2/(E_d - E_\mathrm{L})$。共振积分 $\beta$ 正比于重叠积分，后者可拆成一个径向部分（金属、配体、距离给定时固定）与一个角向部分：σ 是 $d$ 轨道角向函数沿键轴方向的值，π 是其沿垂直于键方向的导数。写 $\beta = \beta_\lambda F_\lambda$，移动即 $e_\lambda F_\lambda^2$。多个配体时，对称性匹配基下的每个 $d$ 轨道与一个 LGO 相互作用，其偶合的平方等于各单独偶合平方之和，所以移动相加。

σ 因子已在[[coordination-chemistry/crystal-field-theory#prop-tetrahedral]]求出：$O_h$ 中 $e_g$ 得 $3e_\sigma$、$t_{2g}$ 得 $0$；$T_d$ 中 $t_2$ 得 $\tfrac43 e_\sigma$、$e$ 得 $0$。$O_h$ 的 π：$x$ 轴上的配体有沿 $y$ 与 $z$ 的两个 π 轨道，分别与 $d_{xy}$、$d_{xz}$ 完全重叠（$F = 1$），与 $d_{x^2-y^2}$、$d_{z^2}$ 完全不重叠。每个 $t_{2g}$ 轨道所在的平面包含四个配体，所以 $E(t_{2g}) = 4e_\pi$，而 $E(e_g)$ 不得到 π 贡献。$T_d$ 的 π：标准角因子（谢费尔有表，Figgis 与希奇曼（Hitchman）的书中也有）给出每个 $e$ 轨道每配体 $\tfrac23$、每个 $t_2$ 轨道每配体 $\tfrac29$，于是 $T_d$ 中 $E(e) = 4 \times \tfrac23 e_\pi = \tfrac83 e_\pi$、$E(t_2) = 4 \times \tfrac29 e_\pi = \tfrac89 e_\pi$，再加上 σ 项。校核：每个配体有两个 π 轨道，在五个 $d$ 轨道上总共应贡献 $2e_\pi$；求和 $2 \times \tfrac23 + 3 \times \tfrac29 = 2$。最后
$$
\Delta_\mathrm{t} = \tfrac43 e_\sigma + \tfrac89 e_\pi - \tfrac83 e_\pi = \tfrac43 e_\sigma - \tfrac{16}{9} e_\pi = \tfrac49(3e_\sigma - 4e_\pi) = \tfrac49\Delta_\mathrm{o}.
$$
因此只要配体相同、距离相同，九分之四的比值在有 π 成键时依然成立。
:::

::: example 从两条光谱定 AOM 参数 {#ex-aom}
六氨合铬(III)的 $\Delta_\mathrm{o} = 21\,500\ \mathrm{cm^{-1}}$，六氯合铬(III)酸根为 $13\,600\ \mathrm{cm^{-1}}$。(a) 把氨当作纯 σ 给体，求 $e_\sigma(\mathrm{NH_3})$。(b) 设对低对称性氯配合物的独立分析给出铬(III)的 $e_\sigma(\mathrm{Cl}) = 5600\ \mathrm{cm^{-1}}$，求 $e_\pi(\mathrm{Cl})$。(c) 预言 *trans*-$\mathrm{[CrCl_2(NH_3)_4]^+}$（Cl 在 $z$ 轴上）中 $t_{2g}$ 组如何分裂。
::: solution
(a) 取 $e_\pi = 0$，$\Delta_\mathrm{o} = 3e_\sigma$，所以 $e_\sigma(\mathrm{NH_3}) = 21\,500/3 = 7170\ \mathrm{cm^{-1}}$。

(b) $13\,600 = 3(5600) - 4e_\pi$ 给出 $e_\pi(\mathrm{Cl}) = (16\,800 - 13\,600)/4 = 800\ \mathrm{cm^{-1}}$：为正，所以氯离子是 π 给体，它的 π 给与从其单纯 σ 成键应得的值中拿走了 $3200\ \mathrm{cm^{-1}}$。

(c) AOM 的能量按配体逐个相加。$d_{xy}$ 处在四个氨的平面内，不面对任何氯：$E = 4e_\pi(\mathrm{N}) = 0$。$d_{xz}$ 所在的平面含两个氨（在 $\pm x$）与两个氯（在 $\pm z$）：$E = 2e_\pi(\mathrm{N}) + 2e_\pi(\mathrm{Cl}) = 1600\ \mathrm{cm^{-1}}$，$d_{yz}$ 同理。于是在 $D_{4h}$ 中 $t_{2g}$ 组分裂为 $b_{2g}$（$d_{xy}$，较低）与 $e_g$（$d_{xz}$、$d_{yz}$，抬高 $1600\ \mathrm{cm^{-1}}$）。这种分裂正是 AOM 参数实际来源的偏振单晶光谱所能分辨的那种，也是 *trans*-二卤配合物的谱带常常肉眼可见地分裂的原因。
:::
:::

## 电子计数：18 电子规则

强 σ 给体与 π 受体的八面体配合物的 MO 图中，有九个轨道是成键或接近非键的——六个 σ 成键 MO（$a_{1g}$、$t_{1u}$、$e_g$）与三个 π 成键的 $t_{2g}$——其上是一大段能隙，隔到 $e_g^*$ 与其他反键能级。九个轨道容纳十八个电子。这就是"稳定羰基化合物使金属拥有下一个稀有气体的电子数"这一老观察的分子轨道含义。

::: proposition 18 电子规则（经验规则） {#prop-18e}
带强 σ 给体与 π 受体配体（CO、膦、烯烃、环戊二烯基、氢负离子、烷基）的低氧化态过渡金属配合物，凡热力学稳定、动力学牢固者，金属周围通常有 18 个价电子：金属的 $d$ 电子加上配体给出的电子。该规则对第 6–10 族元素的八面体、三角双锥与四面体配合物成立得最好。平面正方形 $d^8$ 配合物是 **16** 电子。该规则**不**适用于弱场配体的配合物，它们通常有 12–22 个电子。
:::

::: proof
规则是经验的，但其适用范围可由 MO 图推出。带 π 受体配体时，九个轨道 $a_{1g}$、$t_{1u}$、$e_g$（σ 成键）与 $t_{2g}$（π 成键）全部成键，而下一组轨道 $e_g^*$ 因 σ 相互作用很大而强烈反键。恰好填满九个成键轨道（18 个电子）使成键最大化；电子再少就留下半空的成键轨道，再多则要进入强反键轨道。对弱场 σ 给体与 π 给体，$t_{2g}$ 非键或 π 反键，$e_g^*$ 只是弱反键，无论从 $t_{2g}$ 拿走电子还是往 $e_g^*$ 加电子都几乎不花能量，18 就没有特殊地位。平面正方形 $d^8$ 配合物中，以 $d_{x^2-y^2}$ 为主的轨道强反键，而一个 $p$ 轨道（$p_z$）没有 σ 伙伴、留为空的，所以低能价层轨道只有八个：16 电子。
:::

::: algorithm 价电子计数（离子法） {#alg-electron-count}
1. 把配体电荷按闭壳层物种指定：$\mathrm{Cl^-}$、$\mathrm{H^-}$、$\mathrm{CH_3^-}$、$\mathrm{CN^-}$ 与 $\mathrm{C_5H_5^-}$（Cp）是阴离子；CO、$\mathrm{PR_3}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$ 与烯烃是中性的。
2. 求金属的氧化态及其 $d^n$ 计数（方法见[[coordination-chemistry/coordination-compounds#def-dn]]）。
3. 加上每个配体给出的电子：每个 $\mathrm{Cl^-}$、$\mathrm{H^-}$、$\mathrm{CH_3^-}$、CO、$\mathrm{PR_3}$、$\mathrm{NH_3}$ 或 η²-烯烃给 2 个；en 这类双齿配体给 4 个；η⁵-Cp⁻ 或 η⁶-苯给 6 个。
4. 每条金属-金属单键加 1 个电子。
5. 总和即价电子数。（共价法／中性配体法把 Cl 与 Cp 当作一电子与五电子的自由基、金属当作中性，所得总数相同；两种方法坚持用一种。）
:::

::: example 谁遵守规则？ {#ex-18e}
数出 (a) $\mathrm{[Cr(CO)_6]}$、(b) $\mathrm{[Fe(CO)_5]}$、(c) $\mathrm{[Mn_2(CO)_{10}]}$、(d) 二茂铁 $\mathrm{[Fe(\eta^5\text{-}C_5H_5)_2]}$、(e) $\mathrm{[V(CO)_6]}$、(f) $\mathrm{[PtCl_4]^{2-}}$、(g) $\mathrm{[Cr(H_2O)_6]^{3+}}$ 的价电子数，并加评论。
::: solution
(a) Cr(0)，$d^6$，加 $6 \times 2 = 12$：**18**。(b) Fe(0)，$d^8$，加 $5 \times 2$：**18**。(c) 每个 Mn(0) 为 $d^7$，加五个 CO（10）与一条 Mn–Mn 键（1）：每个金属 **18**。奇电子碎片 $\mathrm{Mn(CO)_5}$（17 电子）二聚以达到 18。(d) Fe(II)，$d^6$，加两个 $\mathrm{Cp^-}$（$2 \times 6$）：**18**，典型的稳定有机金属夹心配合物。(e) V(0)，$d^5$，加 12：**17**。$\mathrm{[V(CO)_6]}$ 以顺磁性深绿色固体存在，易被还原成 18 电子的 $\mathrm{[V(CO)_6]^-}$；与 $\mathrm{Mn(CO)_5}$ 不同，它不二聚，因为六个羰基把钒挤得太满，容不下 V–V 键。(f) Pt(II)，$d^8$，加 8：**16**，平面正方形 $d^8$ 的正常计数。(g) Cr(III)，$d^3$，加 12：**15**。这是一个完全稳定的配合物：水是弱场的 σ 与 π 给体，规则对它无话可说。其他带弱场配体的稳定"例外"还有 $\mathrm{[Ni(en)_3]^{2+}}$（20）与 $\mathrm{[Cu(H_2O)_6]^{2+}}$（21）。
:::
:::

下列配体中，哪些预期会靠 π 相互作用*增大* $\Delta_\mathrm{o}$ 而不是减小它？
- [x] CO
- [ ] $\mathrm{Cl^-}$
- [x] 2,2′-联吡啶
- [ ] $\mathrm{OH^-}$
- [x] $\mathrm{PPh_3}$
::: solution
CO、bpy 与三苯膦在金属 $d$ 能级之上有 π 对称的空轨道（CO 与 bpy 的 $\pi^*$ 轨道、膦的 P–C $\sigma^*$ 轨道）；它们从 $t_{2g}$ 接受电子密度，压低 $t_{2g}$ 并加宽能隙（[[#prop-pi-effect]]）。氯离子与氢氧根在 $d$ 能级之下有充满的 π 型孤对电子；它们抬高 $t_{2g}$、缩窄能隙。
:::

### 四面体配合物与简单图像的极限

在 $T_d$ 中，四个配体 σ 轨道约化为 $A_1 + T_2$。金属的 $s$ 轨道是 $a_1$，$p$ 轨道与 $d_{xy}$、$d_{xz}$、$d_{yz}$ 轨道都属 $t_2$，所以在四面体配合物中 $t_2$ 型 $d$ 轨道是 σ 反键的（还混入一些 $p$），$e$ 对是 σ 非键的——与八面体情形相反，正如晶体场理论中那样。由于 $d$ 与 $p$ 轨道同属 $t_2$ 表示，四面体配合物存在 $d$–$p$ 混合，使其 $d$–$d$ 谱带比八面体配合物的强得多（[[coordination-chemistry/spectra-of-complexes]]的拉波特选律）。高锰酸盐 $\mathrm{[MnO_4]^-}$——一个 $d^0$ 离子——的浓紫色另有起源：它是从氧的非键轨道到空的 $e$ 组的配体到金属电荷转移跃迁，同一个 MO 图即可预言。

::: example 磁共振给出的共价性检验 {#ex-covalency}
$\mathrm{[IrCl_6]^{2-}}$（$d^5$，低自旋，$t_{2g}$ 上一个未成对电子）的 EPR 谱中，每条线都因与氯核的耦合而分裂，分析表明未成对电子约把其百分之几的时间（约 4 %）花在每个氯上。这对 $t_{2g}$ 轨道意味着什么？它与晶体场理论的哪个预言矛盾？
::: solution
按晶体场理论，$t_{2g}$ 电子是纯的铱 $5d$ 电子，不可能与氯核有任何耦合。与氯的超精细耦合说明单占据轨道是一个带配体成分的分子轨道。若每个氯约占 4 %，那么电子的大约 $6 \times 4 = 24\ \%$ 在配体上，只有约四分之三在铱上。该轨道就是[[#prop-pi-effect]]的 π 反键 $t_{2g}^*$ 组合，其中氯的 $3p\pi$ 孤对电子与铱的 $5d_{xy}$ 型轨道混合。这个 1953 年由约翰·欧文（John Owen）与肯尼斯·史蒂文斯（Kenneth Stevens）报道的实验，是最早直接证明"离子型"配合物中金属-配体成键具有显著共价性的实验之一；连同电子云扩展效应，它说服化学家从晶体场理论走向配体场理论。超精细耦合见[[spectroscopy/epr]]。
:::
:::

## 后续内容

本章的 MO 图是后面三个主题的起点。[[coordination-chemistry/spectra-of-complexes]]的光谱以 $\Delta_\mathrm{o}$ 为参数并加上电子排斥；配合物中这种排斥的降低（电子云扩展效应）是共价性的又一个标志。18 电子规则与金属-羰基的协同成键是[[organometallics-catalysis/organometallic-bonding]]的基础，那里同样的计数被用于烯烃、芳烃、卡宾与氢负离子，16 与 18 电子中间体在催化循环中交替出现。σ 给体、π 给体与 π 受体的区分还会在[[coordination-chemistry/inorganic-mechanisms]]的反位效应中重现——那里反位导向能力最强的配体，恰恰是最好的 π 受体与 σ 给体。

::: history
配合物的分子轨道描述几乎与晶体场理论同龄。约翰·范弗莱克（John Hasbrouck Van Vleck）1935 年发表在《化学物理杂志》（*Journal of Chemical Physics*）上的论文已经指出，MO、价键与晶体场三种方法给出同样的对称性图样，而 MO 图像天然包含共价性。计数规则更老：欧文·朗缪尔（Irving Langmuir）1921 年就指出稳定的羰基化合物使金属拥有 18 个电子，内维尔·西季威克（Nevil Sidgwick）在 1920 年代把它推广为"有效原子序数"规则。现代的综合出现在 1950 年代。欧文与史蒂文斯关于 $\mathrm{[IrCl_6]^{2-}}$ 共价性的 EPR 证据（1953），以及约根森与谢费尔关于电子云扩展效应的工作表明配体分担着金属的电子；J. S. 格里菲思（J. S. Griffith）与 L. E. 奥尔格（L. E. Orgel）1957 年在《季刊评论》（*Quarterly Reviews*）上的综述《配体场理论》（"Ligand-field theory"）给这门学科定了名、定了形。克劳斯·谢费尔与克里斯蒂安·克利克斯比尔·约根森于 1965 年提出角重叠模型。金属-羰基与金属-烯烃键的协同 σ 给体／π 受体模型，则归功于迈克尔·杜瓦（Michael Dewar，1951）以及约瑟夫·查特（Joseph Chatt）与伦纳德·邓坎森（Leonard Duncanson，1953）。
:::

::: summary
- 配体群轨道按对称性给配体轨道分类。$O_h$ 中 σ 组约化为 $A_{1g} + E_g + T_{1u}$，与金属的 $s$、$e_g$、$p$ 成键；$t_{2g}$ 组 σ 非键。
- $\Delta_\mathrm{o}$ 是 $t_{2g}$（非键或 π 成键／反键）与 $e_g^*$（σ 反键）之间的能隙。强 σ 给体抬高 $e_g^*$，使其增大。
- π 给体（卤离子、$\mathrm{OH^-}$、$\mathrm{O^{2-}}$）抬高 $t_{2g}$、减小 $\Delta_\mathrm{o}$；π 受体（CO、$\mathrm{CN^-}$、bpy、膦）压低 $t_{2g}$、使其增大。这解释了光谱化学序列。
- 从金属 $t_{2g}$ 向配体 $\pi^*$ 的反馈与 σ 给与协同，表现为 $\tilde\nu(\mathrm{CO})$ 的降低，等电子系列中每单位负电荷约降 $100\ \mathrm{cm^{-1}}$。
- 角重叠模型写出 $\Delta_\mathrm{o} = 3e_\sigma - 4e_\pi$ 与 $\Delta_\mathrm{t} = \tfrac43 e_\sigma - \tfrac{16}{9}e_\pi = \tfrac49\Delta_\mathrm{o}$，并能按配体逐个预言低对称性下的分裂。
- 经验的 18 电子规则（平面正方形 $d^8$ 为 16）适用于带 π 受体配体的低氧化态金属，因为九个成键轨道之下没有大的能隙上方空间；它对弱场配合物不适用。
- EPR 中的配体超精细结构与电子云扩展效应直接表明金属-配体键是共价的。
:::

用 MO 观点解释：(a) 同一金属为何 $\Delta_\mathrm{o}(\mathrm{H_2O}) > \Delta_\mathrm{o}(\mathrm{OH^-})$；(b) 为何 $\Delta_\mathrm{o}(\mathrm{NH_3}) > \Delta_\mathrm{o}(\mathrm{H_2O})$；(c) 氰离子远弱于氨的布朗斯特碱性，为何仍有 $\Delta_\mathrm{o}(\mathrm{CN^-}) > \Delta_\mathrm{o}(\mathrm{NH_3})$。
::: solution
(a) 氢氧根相对 M–O 键有两对 π 对称的充满孤对电子，是比只有一个的更强的 π 给体；π 给与抬高 $t_{2g}$、缩窄 $\Delta_\mathrm{o}$，压过了氢氧根略好的 σ 给与。(b) 氨没有 π 型孤对电子：它是纯 σ 给体，而且氮的孤对电子能量更高（碱性更强，与金属匹配更好），所以把 $e_g^*$ 抬得更高、什么都不压低。(c) 氰既是通过碳的良好 σ 给体，又是 π 受体，其空 $\pi^*$ 轨道压低 $t_{2g}$。布朗斯特碱性度量的是对 $\mathrm{H^+}$ 的亲和力，而 $\mathrm{H^+}$ 根本没有 π 轨道、无从享受反馈；光谱化学序列与质子亲和力的次序是两套不同的标尺。
:::

::: exercise 羰基的电荷系列 {level=2 check="2323"}
用六羰基化合物的最小二乘直线 $\tilde\nu \approx 1980 + 114.4\,q\ \mathrm{cm^{-1}}$（$q$ 为电荷），估算假想的 $d^6$ 正离子 $\mathrm{[Co(CO)_6]^{3+}}$ 的 $\tilde\nu(\mathrm{CO})$，并评论这一外推是否可靠。（估算值以 $\mathrm{cm^{-1}}$ 输入，取整。）
::: solution
$1980 + 114.4 \times 3 = 1980 + 343.2 = 2323\ \mathrm{cm^{-1}}$。这一外推不可靠，原因有二。数据点本身就散布在直线附近（0 到 +1 的台阶比它两边的都小），而且随着正电荷增大，反馈趋于零，$\tilde\nu$ 必定在 σ 给与单独决定的值处变平，不会无限上升。直线拟合只是数据在其范围内的描述，不是定律。
:::

::: exercise 四面体的 AOM {level=2 check="11600/3"}
某四面体配合物的配体参数为 $e_\sigma = 4500\ \mathrm{cm^{-1}}$、$e_\pi = 1200\ \mathrm{cm^{-1}}$。用[[#eq-aom]]求 $e$ 与 $t_2$ 组的能量及 $\Delta_\mathrm{t}$，并验证用同一参数的八面体配合物满足 $\Delta_\mathrm{t} = \tfrac49\Delta_\mathrm{o}$。（$\Delta_\mathrm{t}$ 以 $\mathrm{cm^{-1}}$ 输入。）
::: solution
$E(e) = \tfrac83 \times 1200 = 3200\ \mathrm{cm^{-1}}$，$E(t_2) = \tfrac43 \times 4500 + \tfrac89 \times 1200 = 6000 + 1066.7 = 7066.7\ \mathrm{cm^{-1}}$，故 $\Delta_\mathrm{t} = 3866.7\ \mathrm{cm^{-1}}$。闭合公式一致：$\tfrac43(4500) - \tfrac{16}{9}(1200) = 6000 - 2133.3 = 3866.7\ \mathrm{cm^{-1}}$。八面体对应的 $\Delta_\mathrm{o} = 3(4500) - 4(1200) = 8700\ \mathrm{cm^{-1}}$，而 $\tfrac49 \times 8700 = 3866.7\ \mathrm{cm^{-1}}$，如所要求。

::: exercise 为什么没有六羰基合镍 {level=3}
用电子计数与八面体 MO 图解释：为什么镍(0)生成 $\mathrm{[Ni(CO)_4]}$ 而不生成 $\mathrm{[Ni(CO)_6]}$；而 20 个价电子的 $\mathrm{[Ni(en)_3]^{2+}}$ 却仍是稳定配合物。
::: solution
$\mathrm{[Ni(CO)_6]}$ 将有 $10 + 12 = 22$ 个电子。在带 π 受体配体的八面体配合物中，九个成键轨道容纳 18 个电子，而 $e_g^*$ 强烈反键——CO 是强 σ 给体，反馈又把 $t_{2g}$ 压得更低。四个电子进入 $e_g^*$ 将抵消整整两条 σ 键的成键：两个 CO 最好离开，于是得到 18 电子的四面体 $\mathrm{[Ni(CO)_4]}$，其中十个 $d$ 电子填满 $e$ 与 $t_2$ 组（$d^{10}$，没有配体场偏好），四条 Ni–C σ 键与反馈都完好。在 $\mathrm{[Ni(en)_3]^{2+}}$ 中，镍(II)为 $d^8$，$t_{2g}^6e_g^{*2}$。乙二胺是中等强度的 σ 给体、没有 π 受体轨道；$\Delta_\mathrm{o}$ 只有约 $11\,500\ \mathrm{cm^{-1}}$，所以 $e_g^*$ 只是轻度反键，里面两个电子的代价远小于六条 Ni–N 键与三个螯合环换来的成键收益。18 电子规则讲的是强成键的 π 受体型配体，$\mathrm{[Ni(en)_3]^{2+}}$ 不在它的适用范围内。
:::

::: exercise π 移动的大小 {level=3 check="198"}
某金属 $t_{2g}$ 能级位于空的配体 $\pi^*$ 组之下 $20\,000\ \mathrm{cm^{-1}}$，$\beta_\pi = 2000\ \mathrm{cm^{-1}}$。(a) 用[[#eq-pi-shift]]的精确式求 $t_{2g}$ 的降低值，并与二阶近似比较。(b) $\Delta_\mathrm{o}$ 改变多少？(c) 若 $\pi^*$ 能级只比 $t_{2g}$ 高 $10\,000\ \mathrm{cm^{-1}}$，近似移动是多少？（输入 (a) 的精确降低值，以 $\mathrm{cm^{-1}}$ 计，保留三位有效数字。）
::: hint
取 $x = E_\mathrm{L} - E_d = +20\,000\ \mathrm{cm^{-1}}$，金属为主的根是 $E_- - E_d = \tfrac12\left[x - \sqrt{x^2 + 4\beta_\pi^2}\right]$。
:::
::: solution
(a) $\sqrt{20\,000^2 + 4 \times 2000^2} = \sqrt{4.00\times10^8 + 1.60\times10^7} = \sqrt{4.16\times10^8} = 20\,396\ \mathrm{cm^{-1}}$。于是 $E_- - E_d = \tfrac12(20\,000 - 20\,396) = -198\ \mathrm{cm^{-1}}$：降低 $198\ \mathrm{cm^{-1}}$。二阶公式给出 $\beta_\pi^2/(E_\mathrm{L} - E_d) = 4.0\times10^6/20\,000 = 200\ \mathrm{cm^{-1}}$，高 1 %。(b) 这是模型中每个 $t_{2g}$ 轨道单个 π 相互作用的值；由于 $e_g^*$ 不受影响，$\Delta_\mathrm{o}$ 增大同样的 $198\ \mathrm{cm^{-1}}$。真实的八面体配合物中每个 $t_{2g}$ 轨道与四个配体相互作用，这里的 $\beta_\pi$ 应读作与整个 LGO 的偶合。(c) 能隙减半，二阶移动加倍，成为 $4.0\times10^6/10\,000 = 400\ \mathrm{cm^{-1}}$。受体轨道越接近，反馈越强：CO 的 $2\pi^*$ 位置低，是远胜于 $\mathrm{N_2}$ 的 π 受体，后者的 $\pi^*$ 位置更高。
:::
