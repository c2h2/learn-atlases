大约三分之一的蛋白质需要一种金属才能工作。血红蛋白里的铁正携带着你此刻呼吸的氧；碳酸酐酶里的锌以每个酶分子每秒一百万次的速率把你产生的二氧化碳转化为碳酸氢根；细胞色素*c*氧化酶里的铜和铁在呼吸链的末端把氧还原成水；光系统 II 中的一个锰-钙簇制造了大气中的所有氧；而固氮酶里的一个铁-钼-硫簇固定的氮最终进入了你的蛋白质。这些位点中的每一个都是配位化合物，以氨基酸侧链、卟啉或水为配体；它们每一个之所以能工作，靠的都是前面各章的思想：配体场对自旋态与氧化还原电势的影响、配合物的稳定性与不惰性、硬-软匹配，以及取代与电子转移的机理。

本章概览生物界金属位点的主要类型：氧载体、电子传递蛋白、金属酶，以及金属在药物与影像剂中的医学应用。重点是化学性的：金属做了什么有机基团做不到的事，蛋白质又是如何调节它的。同一批蛋白质的生物化学——它们的结构及其在代谢中的位置——见[[biochemistry/protein-function]]与[[biochemistry/oxidative-phosphorylation]]。本文中的医学陈述仅供教育之用；本章没有任何内容是治疗建议。

## 蛋白质中的金属位点

::: definition 金属蛋白及其配体 {#def-metalloprotein}
**金属蛋白**含有一个或多个与蛋白质结合的金属离子；**金属酶**是金属参与催化的金属蛋白。金属可以直接由氨基酸侧链（组氨酸的咪唑 N、半胱氨酸的硫醇盐 S、甲硫氨酸的硫醚 S、天冬氨酸与谷氨酸的羧酸根 O、酪氨酸的酚盐 O、肽主链）和水配位，也可以被束缚在一个有机**辅因子**中，如卟啉（血红素）、钴啉（钴胺素）或蝶啶。配位球由蛋白质的三维结构决定，而蛋白质能够强加自由离子本不会采取的几何构型、给体集合与第二配位球相互作用（氢键、静电作用、疏水口袋）。蛋白质把金属保持在一种张紧的、与其反应的过渡态接近的高活性几何构型中——这一思想就是瓦利（Bert Vallee）与威廉姆斯（Robert Williams）1968 年提出的**张力态**（entatic state）假说。
:::

哪种金属去哪个位点，遵循[[coordination-chemistry/complex-stability]]的规则。硬离子（$\mathrm{Na^+}$，$\mathrm{K^+}$，$\mathrm{Mg^{2+}}$，$\mathrm{Ca^{2+}}$）结合羧酸根、磷酸根和水，是不惰性的，充当电荷载体、结构离子与信号。交界与软离子结合氮和硫。欧文-威廉姆斯序列意味着，对同一个蛋白质位点，铜和锌几乎会赢下对锰、铁或钴的任何竞争；细胞通过把游离铜与游离锌保持在极低浓度（据估计细胞质中游离 $\mathrm{Cu^+}$ 低于 $10^{-18}\ \mathrm{mol\,dm^{-3}}$），并用专门的分子伴侣蛋白递送金属，来防止错配金属化。

## 氧的运输：肌红蛋白与血红蛋白

氧在水中的溶解度很差（$25\ ^\circ\mathrm{C}$ 下与空气平衡时约 $0.25\ \mathrm{mmol\,dm^{-3}}$），远不够供给一只大型动物。脊椎动物把它结合在**血红蛋白**（Hb，在红细胞中）的铁(II)上运输，并储存在**肌红蛋白**（Mb，在肌肉中）里。两者都含有**血红素**：铁(II)位于一个双阴离子卟啉（原卟啉 IX）的平面中，与四个吡咯氮成键，并在另一侧与一个组氨酸相连（**近端组氨酸**）。第六个位点在另一侧结合 $\mathrm{O_2}$；第二个组氨酸（**远端组氨酸**）位于口袋中它的上方。

在**脱氧**血红蛋白中，铁是五配位的高自旋 $d^6$（$S = 2$），$\sigma$ 反键的 $e_g$ 型轨道上有两个电子。高自旋铁(II)太大，坐不进卟啉的空穴，而是朝近端组氨酸一侧偏离平面约 $40\ \mathrm{pm}$。当 $\mathrm{O_2}$ 结合时，铁变为六配位且**低自旋**，反键轨道排空，铁缩小并移入平面，把近端组氨酸一并拉动。氧合血红蛋白是抗磁性的。其 O–O 伸缩振动频率（约 $1105\ \mathrm{cm^{-1}}$，介于 $\mathrm{O_2}$ 的 $1555\ \mathrm{cm^{-1}}$ 与过氧化物附近的 $800$ 之间）表明结合的氧分子接近超氧化物；对这个位点最好的描述，如魏斯（Jerome Weiss）1964 年所提议的，是低自旋铁(III)与 $\mathrm{O_2^-}$ 成键，两个自旋反铁磁耦合。鲍林（Pauling）1936 年曾把它描述为铁(II)结合单线态 $\mathrm{O_2}$；两种描述是同一个弯曲 $\mathrm{Fe{-}O{-}O}$ 单元的两种极限共振式。

::: proposition 氧结合曲线 {#prop-binding}
对只有一个独立结合位点的蛋白质（肌红蛋白），氧分压 $p$ 处的饱和分数为
$$
Y = \frac{p}{P_{50} + p},
$$ {#eq-mb}
其中 $P_{50}$ 是半饱和时的分压。对四个位点协同相互作用的血红蛋白，饱和度由**希尔方程**经验地描述
$$
Y = \frac{p^{\,n}}{P_{50}^{\,n} + p^{\,n}}, \qquad \log\frac{Y}{1 - Y} = n\log p - n\log P_{50},
$$ {#eq-hill}
人血红蛋白的希尔系数 $n \approx 2.8$。希尔方程只对 $n$ 个配体全或无结合的极限情形精确；对真实的血红蛋白，它拟合曲线的中段，而 $n$ 是协同性的度量，不是位点数。
:::

::: proof
对单一位点，$\mathrm{Mb + O_2 \rightleftharpoons MbO_2}$，解离常数 $K_\mathrm{d} = [\mathrm{Mb}]\,p/[\mathrm{MbO_2}]$，其中溶解氧取为与 $p$ 成正比（亨利定律）。于是 $Y = [\mathrm{MbO_2}]/([\mathrm{Mb}] + [\mathrm{MbO_2}]) = p/(K_\mathrm{d} + p)$，当 $p = K_\mathrm{d}$ 时 $Y = \tfrac12$，故 $K_\mathrm{d} = P_{50}$。对全或无模型，设有 $n$ 个位点的蛋白质以单一步骤结合 $n$ 个配体，$\mathrm{P} + n\,\mathrm{O_2} \rightleftharpoons \mathrm{P(O_2)_n}$，常数 $K$，无部分配体的物种。被占据位点的分数等于完全结合形态的蛋白质分数，$Y = Kp^n/(1 + Kp^n)$；写成 $K = P_{50}^{-n}$ 即得[[#eq-hill]]。整理得 $Y/(1 - Y) = (p/P_{50})^n$，取对数得线性的**希尔图**，其斜率为 $n$。血红蛋白确实存在部分配体的形态，所以实测斜率（半饱和附近约 2.8）小于位点数（4），并在极低与极高饱和度处降为 1，因为那些地方一次只有一个位点在改变。协同性之所以产生，是因为一个血红素上的结合把铁移入卟啉平面，这一运动经由近端组氨酸传给蛋白质，并使四聚体从低亲和力（T）四级结构移向高亲和力（R）四级结构——这就是莫诺（Jacques Monod）、怀曼（Jeffries Wyman）与尚热（Jean-Pierre Changeux）1965 年的模型，以及佩鲁茨（Max Perutz）结构工作所阐明的图像。
:::

### 一氧化碳与蛋白质的作用

溶液中的游离血红素是很差的氧载体。两个铁(II)卟啉与 $\mathrm{O_2}$ 经 μ-过氧二聚体不可逆地反应，生成铁(III)的 μ-氧二聚体 $\mathrm{[(porph)Fe{-}O{-}Fe(porph)]}$。蛋白质通过把每个血红素隔离在一个口袋里来防止这一点。它还歧视一氧化碳：游离血红素结合 CO 的强度约为 $\mathrm{O_2}$ 的 $10^4$ 倍，而在血红蛋白中这一比值只有约 200–250。一氧化碳偏好线形的 Fe–C–O 单元，而氧偏好弯曲的 Fe–O–O 单元；远端口袋更能容纳弯曲的氧，且远端组氨酸向极性的 $\mathrm{Fe^{III}{-}O_2^-}$ 单元的末端氧提供一根氢键，而 CO 无法接受这样的氢键。即便被蛋白质降低，残余的偏好仍使 CO 成为一种危险的毒气（无色、无味的气体，GHS06 与 GHS08）：它取代氧结合血红蛋白，还提高其余位点对氧的亲和力，使释放给组织的氧更少。

其他生物使用不同的化学。**血蓝蛋白**（软体动物与节肢动物）有两个铜(I)离子，各由三个组氨酸配位；氧以侧基过氧的形式结合在两者之间，$\mathrm{Cu^{II}(\mu\text{-}\eta^2\!:\!\eta^2\text{-}O_2^{2-})Cu^{II}}$，无色的脱氧形态变为蓝色。**血铁氧载体蛋白**（haemerythrin，见于某些海洋蠕虫）有两个经氢氧根桥联的非血红素铁(II)离子；氧结合到一个铁上成为氢过氧根，质子取自桥。

## 电子传递蛋白

电子传递链在一串电势合适的载体之间，把电子在氧化还原酶之间作长距离迁移。载体必须快速转移电子，用马库斯的语言说（[[coordination-chemistry/inorganic-mechanisms#prop-marcus]]），这意味着小的重组能 $\lambda$：金属的配位球必须在两个氧化态之间几乎不变。

- **细胞色素**是血红素蛋白，其铁在低自旋铁(II)与铁(III)之间循环（$t_{2g}^6$ 与 $t_{2g}^5$，因此没有 $e_g$ 电子改变，Fe–N 键几乎不动）。细胞色素*c* 以组氨酸和甲硫氨酸为轴向配体；电势范围约从 $-0.3$ 到 $+0.4\ \mathrm{V}$，取决于轴向配体与蛋白质环境。
- **铁硫蛋白**含有由半胱氨酸硫醇盐配位的铁与硫簇：红氧还蛋白（一个 Fe，四个 Cys）、$\mathrm{[2Fe{-}2S]}$ 铁氧还蛋白、Rieske 中心（其中两个半胱氨酸被组氨酸取代，抬高电势）以及 $\mathrm{[4Fe{-}4S]}$ 立方烷型簇。电子离域在整个簇上，所以一步单电子变化只改变每个铁电荷的一个分数，重组能因而很小。$\mathrm{[4Fe{-}4S]}$ 簇在铁氧还蛋白中利用 $\mathrm{2+/1+}$ 电对（约 $-0.4\ \mathrm{V}$），在高电位铁硫蛋白（HiPIP）中利用 $\mathrm{3+/2+}$ 电对（约 $+0.35\ \mathrm{V}$）；哪个电对可用由蛋白质决定。
- **蓝铜蛋白**（质体蓝素、天青蛋白（azurin））含有一个与两个组氨酸、一个半胱氨酸硫醇盐键合、并较弱地键合一个甲硫氨酸硫醚的铜，呈畸变四面体几何。

::: example 蓝铜位点 {#ex-blue-copper}
质体蓝素呈深蓝色，在约 $597\ \mathrm{nm}$ 处吸收，$\varepsilon \approx 4500\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$，且 $E^{\circ\prime} = +0.37\ \mathrm{V}$，而水溶液中 $\mathrm{Cu^{2+}/Cu^+}$ 为 $+0.153\ \mathrm{V}$。(a) 为什么这条谱带不能是 $d$–$d$ 跃迁？(b) 解释高电势。(c) 为什么畸变的四面体位点有利于快速电子转移？
::: solution
(a) 四方配合物中铜(II)的 $d$–$d$ 谱带 $\varepsilon$ 约 10–100（[[coordination-chemistry/spectra-of-complexes#prop-selection]]）；接近 4500 的值需要一条允许跃迁。它是从半胱氨酸硫醇盐（软的、易氧化的给体，Cu–S 键强共价）到半充满铜轨道的配体到金属电荷迁移谱带。(b) 由[[coordination-chemistry/complex-stability#prop-redox-shift]]，$\log(\beta^\mathrm{II}/\beta^\mathrm{I}) = (0.153 - 0.37)/0.05916 = -3.7$：相对于水，该位点结合铜(I)比铜(II)强约 $10^{3.7}$ 倍。铜(I)（$d^{10}$）是软的，偏好与硫给体的四面体配位；铜(II)偏好与较硬给体的四方几何。蛋白质强加了更接近铜(I)偏好的几何与给体集合，从而抬高电势。(c) 铜(I)与铜(II)通常几何构型迥异（四面体对平面四方），所以它们在溶液中相互转移电子需要大的重组，速率很慢。蛋白质把两个氧化态都保持在几乎相同的畸变几何上——张力态——于是 $\lambda$ 小，自交换快。
:::
:::

## 金属酶

催化金属以前几章的化学反复使用于几种方式：作为**路易斯酸**活化底物或降低配位水的 $\mathrm{p}K_\mathrm{a}$（锌），作为**氧化还原催化剂**结合并活化 $\mathrm{O_2}$、$\mathrm{H_2O_2}$ 或 $\mathrm{N_2}$（铁、铜、锰、钼），以及作为**自由基发生器**，经由弱的金属-碳键（维生素 $\mathrm{B_{12}}$ 中的钴）。

### 锌作为路易斯酸：碳酸酐酶

碳酸酐酶催化 $\mathrm{CO_2 + H_2O \rightleftharpoons HCO_3^- + H^+}$，是已知最快的酶之一，转换数约 $10^6\ \mathrm{s^{-1}}$。它的锌由三个组氨酸和一个水配位，处于四面体位点。配位于 $\mathrm{Zn^{2+}}$ 使那分子水的 $\mathrm{p}K_\mathrm{a}$ 从约 14（严格地说按摩尔标度为 15.7）降到约 7，所以在生理 pH 下相当一部分以 $\mathrm{Zn{-}OH^-}$ 存在。锌结合的氢氧根进攻保持在疏水口袋中 $\mathrm{CO_2}$ 的碳，生成锌结合的碳酸氢根，被水取代；随后一个组氨酸穿梭体从新的锌水上取走质子，再生 $\mathrm{Zn{-}OH^-}$。锌对这个角色是理想的：作为 $d^{10}$ 它没有配体场偏好，因而在循环中容易改变配位数；它是氧化还原惰性的，不能产生自由基；它是足够强的路易斯酸，能把 $\mathrm{p}K_\mathrm{a}$ 降低七个单位。

::: example 有多少锌结合氢氧根？ {#ex-carbonic}
取碳酸酐酶锌结合水的 $\mathrm{p}K_\mathrm{a} = 7.0$，求 pH 7.4 与 pH 6.5 下酶处于活性 $\mathrm{Zn{-}OH^-}$ 形态的分数。速率随 pH 如何变化？
::: solution
$\mathrm{Zn{-}OH_2 \rightleftharpoons Zn{-}OH^- + H^+}$；去质子化的分数为 $f = 1/(1 + 10^{\mathrm{p}K_\mathrm{a} - \mathrm{pH}})$。pH 7.4：$f = 1/(1 + 10^{-0.4}) = 1/(1 + 0.398) = 0.715$。pH 6.5：$f = 1/(1 + 10^{0.5}) = 1/(1 + 3.16) = 0.240$。由于氢氧根形态是亲核体，$\mathrm{CO_2}$ 水合的速率随 $f$ 走，随 pH 呈 S 形上升，中点在 $\mathrm{p}K_\mathrm{a}$ 处，与观测一致。相比之下，pH 7.4 的大体积水中氢氧根只有 $10^{-6.6}\ \mathrm{mol\,dm^{-3}}$，约每 $2\times10^8$ 个水分子才有一个离子，而锌结合水中有 72 % 是氢氧根：这就是配位于 $\mathrm{Zn^{2+}}$ 对酸度影响的度量。
:::
:::

### 氧化还原酶

许多酶结合氧分子并把它用作氧化剂。**细胞色素 P450** 酶是以半胱氨酸硫醇盐为近端配体的血红素蛋白，在药物代谢与类固醇合成中羟基化未活化的 C–H 键。它们通过一种高价铁(IV)=氧卟啉自由基阳离子——"compound I"，形式上是铁(V)——做到这一点：它从底物抽取一个氢原子，再把一个羟基交还给所得自由基（"氧反弹"）。硫醇盐配体是强给电子体，有助于稳定这一中间体。**细胞色素*c* 氧化酶**在一个血红素-铁/铜位点用四个电子和四个质子把 $\mathrm{O_2}$ 还原为水，不释放部分还原的氧物种，并利用能量泵出质子（[[biochemistry/oxidative-phosphorylation]]）。

**光系统 II** 在一个 $\mathrm{Mn_4CaO_5}$ 簇上把水氧化为 $\mathrm{O_2}$，该簇在相继的光驱动步骤（科克（Bessel Kok）的"S 态"循环）中储存四个氧化当量，然后释放 $\mathrm{O_2}$；锰的高氧化态（III 与 IV）和氧化物桥使这成为可能。**固氮酶**在 FeMo 辅因子 $\mathrm{MoFe_7S_9C}$ 上把 $\mathrm{N_2}$ 还原为氨——一个带中心碳化物的簇，其结构直到 2011 年才最终确定；每还原一个 $\mathrm{N_2}$ 消耗 16 个 ATP 并放出一个 $\mathrm{H_2}$。哈伯-博施（Haber–Bosch）过程在约 $400$–$500\ ^\circ\mathrm{C}$ 和 $150$–$300\ \mathrm{bar}$ 下用铁做同一反应（[[green-chemistry/industrial-inorganic]]）；固氮酶在室温下完成它，而其机理仍在研究之中。

**维生素 $\mathrm{B_{12}}$**（钴胺素）把钴保持在钴啉大环中。它的辅酶形态有一条钴-碳键，连到 5′-脱氧腺苷基或甲基上，这是生物界为数极少的金属-碳键之一。腺苷钴胺素的 Co–C 键很弱（约 $130\ \mathrm{kJ\,mol^{-1}}$），在酶中均裂生成钴(II)与一个腺苷基自由基，后者引发自由基重排。霍奇金（Dorothy Hodgkin）维生素 $\mathrm{B_{12}}$ 的 X 射线结构（1956）是晶体学的里程碑。

## 金属与医药

### 铂类抗癌药物

罗森伯格（Barnett Rosenberg）1965 年发现，用铂电极在氯化铵介质中电解细菌培养物会阻止细菌分裂，并把这一效应追溯到由电极生成的 *cis*-$\mathrm{[PtCl_2(NH_3)_2]}$——**顺铂**。它成为最成功的抗癌药物之一，尤以对睾丸癌著称；*trans* 异构体无活性。它的作用方式是平面四方 platinum(II)上一连串的配体取代（[[coordination-chemistry/inorganic-mechanisms]]）。

::: proposition 顺铂经失氯活化 {#prop-cisplatin}
对第一步水解 $\mathrm{[PtCl_2(NH_3)_2] + H_2O \rightleftharpoons [PtCl(H_2O)(NH_3)_2]^+ + Cl^-}$，平衡常数 $K$（以 $\mathrm{mol\,dm^{-3}}$ 计，水的活度取为 1），平衡时以水合配离子形态存在的铂的分数，忽略进一步水解与氢解，为
$$
f_\mathrm{aq} = \frac{K}{K + [\mathrm{Cl^-}]}.
$$ {#eq-aquation}
:::

::: proof
$K = [\mathrm{PtCl(H_2O)^+}][\mathrm{Cl^-}]/[\mathrm{PtCl_2}]$，故 $[\mathrm{PtCl(H_2O)^+}]/[\mathrm{PtCl_2}] = K/[\mathrm{Cl^-}]$ 且 $f_\mathrm{aq} = (K/[\mathrm{Cl^-}])/(1 + K/[\mathrm{Cl^-}]) = K/(K + [\mathrm{Cl^-}])$。高氯浓度下平衡停在二氯一侧；低氯浓度下它移向水合配离子。水合配离子是活性物种，因为水远比氯离子更善于充当离去基团，所以它被亲核体取代要快得多。
:::

水合配离子结合 DNA 中鸟嘌呤的 N7 原子，然后失去第二个氯离子并结合第二个碱基，主要是同一条链上相邻的鸟嘌呤：1,2-链内 $\mathrm{d(GpG)}$ 交联，即主要加合物。这一交联使双螺旋弯曲并解旋，被细胞蛋白识别，并触发细胞死亡。*cis* 几何是不可或缺的：只有两个 *cis* 位点能跨越一条链上的相邻碱基。卡铂用一个螯合二羧酸根取代两个氯离子，它水解更慢、副作用更少；奥沙利铂带一个螯合二胺（1,2-二氨基环己烷）与一个草酸根。铂化合物有细胞毒性、致突变性与致敏性，在实验室中必须按与这些危害相称的防护措施处理。

### 影像剂：钆与锝

**钆(III)** 配合物是磁共振成像用得最广的对比剂。Gd³⁺ 有七个未成对电子和对称的 $^8S_{7/2}$ 基态（[[coordination-chemistry/f-block#ex-moments]]），电子弛豫缓慢，因此极善于缩短附近水质子的弛豫时间，而一个快速与本体交换的配位水分子把这一效应每秒传递给大量水分子。游离的 $\mathrm{Gd^{3+}}$ 有毒（它与尺寸相近的 $\mathrm{Ca^{2+}}$ 竞争），所以以极稳定的螯合物给药，配体是八齿的多胺多羧酸根：开链的 DTPA 或大环的 DOTA。两者的生成常数都极大，动力学惰性却不同。大环配合物只能靠多个给体原子同时解开的极不可能方式释放金属（[[coordination-chemistry/complex-stability]]，大环效应），解离慢得多。当发现反复注射某些开链制剂后钆会滞留于组织（包括脑）时，欧洲药品管理局于 2017 年建议暂停或限制其使用，转而支持大环制剂。这段插曲是热力学稳定性与动力学惰性之区分（[[coordination-chemistry/inorganic-mechanisms#warn-inert]]）的一次直接应用。

**锝-99m** 是诊断核医学的主力：它发射易于成像的 $140\ \mathrm{keV}$ γ 射线，半衰期 $6.0\ \mathrm{h}$，长到足以制备并施用配合物，又短到足以限制辐射剂量。它在医院发生器中由钼-99 的衰变以高锝酸盐 $\mathrm{[TcO_4]^-}$ 的形式产生，并在能把配合物导向特定器官的配体存在下于试剂盒中被还原。

::: example 锝-99m 剂量的衰变 {#ex-tc}
一份 $^{99m}\mathrm{Tc}$ 制剂在 $24.0\ \mathrm{h}$ 后还剩几分之几（$t_{1/2} = 6.01\ \mathrm{h}$）？母体 $^{99}\mathrm{Mo}$（$66\ \mathrm{h}$）的半衰期对医院为何方便？
::: solution
放射性衰变是一级的：$N/N_0 = (1/2)^{t/t_{1/2}} = (1/2)^{24.0/6.01} = (1/2)^{3.99} = 0.0628$，约 6 %（[[general-chemistry-2/nuclear-chemistry]]）。因此病人的辐射暴露迅速下降，这正是该同位素可取之处的一个原因。母体 $^{99}\mathrm{Mo}$ 的半衰期为 66 小时，衰变慢到一台每周送达一次的发生器可以每天"淋洗"：锝在两次淋洗之间累积，并以高锝酸盐的形式从柱上洗脱，而钼酸根保持结合。
:::
:::

::: warning 必需不等于无害，有毒不等于无用 {#warn-essential}
人们很想把金属分成"必需的"（铁、锌、铜）与"有毒的"（汞、镉、铅）。每种金属都有两面，区别在于浓度、化学形态与动力学。游离的铜和铁离子催化由过氧化氢生成羟基自由基（芬顿化学），所以细胞让它们保持结合状态并加以护卫；铁超载与铜积累（威尔逊氏病（Wilson's disease））致病。反过来，铂、砷（三氧化二砷治疗一种白血病）与金（老一代抗风湿药）的化合物正因为它们与生物配体反应而被用作药物。重要的是化学形态：游离 $\mathrm{Gd^{3+}}$ 有毒，它的大环螯合物却是诊断制剂；甲基汞与无机汞在吸收程度与去向上大不相同。本课程的配位化学，正是解释这类差异所用的语言。这里的讨论是教育性的，不是诊断或治疗的指南。
:::

## 后续内容

生物无机化学动用整门课程：配体场决定了使血红蛋白具有协同性的自旋态变化；稳定常数与欧文-威廉姆斯序列决定金属选择性；机理决定哪些药物能在体内存活；马库斯理论描述生物电子传递。蛋白质本身在[[biochemistry/protein-function]]与[[biochemistry/enzymes]]中研究，它们在能量代谢中的角色在[[biochemistry/oxidative-phosphorylation]]，金属类药物设计在[[medicinal-chemistry/drug-case-studies]]。再现酶位点特征的模型配合物，以及由它们启发、用于水氧化、固氮与产氢的催化剂，把本章连接到[[organometallics-catalysis]]与[[green-chemistry/carbon-hydrogen]]。

::: history
最早的金属蛋白结构也是最早的一批蛋白质结构：肯德鲁（John Kendrew）的肌红蛋白（1958 年，6 Å，1960 年到 2 Å）与佩鲁茨（Max Perutz）的血红蛋白（1959–60 年），两人因此分享 1962 年诺贝尔化学奖。鲍林（Linus Pauling）与科里尔（Charles Coryell）1936 年证明氧合血红蛋白是抗磁性的、脱氧血红蛋白是顺磁性的，这是把磁性用于研究蛋白质的第一个例子。碳酸酐酶在 1940 年由凯林（David Keilin）与曼恩（Thaddeus Mann）被鉴定为锌酶。霍奇金（Dorothy Hodgkin）1956 年测定了维生素 $\mathrm{B_{12}}$ 的结构（1964 年诺贝尔奖）。瓦利（Bert Vallee）与威廉姆斯（Robert J. P. Williams）1968 年提出张力态。罗森伯格（Barnett Rosenberg）关于顺铂生物活性的发现发表于 1965 年的《自然》（*Nature*），顺铂于 1978 年在美国获批临床使用。固氮酶 FeMo 辅因子的结构自 1992 年起逐步解决，中心碳化物在 2011 年被确认；光系统 II 锰簇的原子分辨率结构由于 2011 年由沈建仁（Jian-Ren Shen）、神谷信夫（Nobuo Kamiya）与合作者完成。
:::

::: summary
- 蛋白质中的金属位点是带氨基酸与辅因子配体的配位化合物；蛋白质设定几何、给体集合与第二配位球相互作用，有时是张力态；金属的选择遵循硬-软规则与欧文-威廉姆斯序列。
- 血红蛋白与肌红蛋白在铁(II)卟啉上结合 $\mathrm{O_2}$；结合把高自旋、偏离平面的铁(II)转变为抗磁性的低自旋位点（Fe(III)–超氧），这一运动驱动协同性（$n \approx 2.8$），使肺与组织之间的输送最大化。
- 蛋白质防止血红素的不可逆氧化，并把它对 CO 的偏好从约 $10^4$ 降到约 200–250。
- 电子传递蛋白（细胞色素、铁硫簇、蓝铜）使重组能最小化；它们的电势由配体与蛋白质环境调节，正如氧化还原位移方程所描述的。
- 锌充当氧化还原惰性的路易斯酸（碳酸酐酶，结合水的 $\mathrm{p}K_\mathrm{a}$ 约 7）；铁、铜、锰和钼活化 $\mathrm{O_2}$、$\mathrm{H_2O}$ 与 $\mathrm{N_2}$；$\mathrm{B_{12}}$ 中的钴经由一条弱 Co–C 键制造自由基。
- 顺铂在低细胞内氯浓度下经水解活化，形成 *cis* 1,2-链内 GpG 交联；Gd(III)磁共振对比剂既需要热力学稳定性也需要动力学惰性（大环）；$^{99m}\mathrm{Tc}$ 是主要的诊断放射性核素。
:::

::: exercise 配体与氧化态 {level=1}
对每个位点给出金属的氧化态、给体原子与配位数：(a) 脱氧肌红蛋白；(b) 氧化型质体蓝素；(c) 碳酸酐酶的锌位点；(d) 红氧还蛋白。

::: exercise 肺中的血红蛋白 {level=1 check="0.977"}
取 $P_{50} = 3.5\ \mathrm{kPa}$、$n = 2.8$，求 $13.3\ \mathrm{kPa}$ 下血红蛋白的饱和度。（$Y$ 保留三位有效数字输入。）
::: solution
$(13.3/3.5)^{2.8} = 3.80^{2.8}$；$\ln 3.80 = 1.335$，乘以 2.8 得 $3.738$，$e^{3.738} = 42.0$。$Y = 42.0/43.0 = 0.977$。
:::

::: exercise 由两点求希尔系数 {level=2 check="2.8"}
一份血红蛋白样品在 $2.13\ \mathrm{kPa}$ 时饱和 20 %，在 $5.74\ \mathrm{kPa}$ 时饱和 80 %。用[[#eq-hill]]求 $n$ 与 $P_{50}$。（$n$ 保留两位有效数字输入。）
::: hint
把两个 $Y/(1 - Y) = (p/P_{50})^n$ 相除以消去 $P_{50}$。
:::
::: solution
$Y/(1 - Y)$ 在 $p_1 = 2.13$ 处为 $0.25$，在 $p_2 = 5.74$ 处为 $4$。相除得 $16 = (5.74/2.13)^n = 2.695^n$，故 $n = \log16/\log2.695 = 1.204/0.4306 = 2.80$。于是 $P_{50} = p_1 \times 0.25^{-1/n} = 2.13 \times 4^{1/2.8} = 2.13 \times 1.641 = 3.50\ \mathrm{kPa}$。一个非协同蛋白质（$n = 1$）从 20 % 到 80 % 饱和度需要压力升高十六倍；血红蛋白只需要不到三倍。
:::
:::

::: exercise 锌水的酸度 {level=2 check="0.240"}
若锌结合水的 $\mathrm{p}K_\mathrm{a}$ 为 7.0，求 pH 6.5 下碳酸酐酶以 $\mathrm{Zn{-}OH^-}$ 形态存在的分数，并解释酶为何在酸性条件下失去活性。（分数保留三位有效数字输入。）
::: solution
$f = 1/(1 + 10^{7.0 - 6.5}) = 1/(1 + 3.162) = 0.240$。锌氢氧根是进攻 $\mathrm{CO_2}$ 的亲核体；当 pH 降到 $\mathrm{p}K_\mathrm{a}$ 以下，位点越来越多地处于不活泼的 $\mathrm{Zn{-}OH_2}$，活性随 $f$ 下降。
:::
:::

::: exercise 调节铜的电势 {level=3 check="-3.67"}
(a) 用[[coordination-chemistry/complex-stability#prop-redox-shift]]求质体蓝素 $E^{\circ\prime} = +0.370\ \mathrm{V}$ 相对于水合铜（$+0.153\ \mathrm{V}$）的 $\log(\beta^\mathrm{II}/\beta^\mathrm{I})$。(b) 锈蓝蛋白（rusticyanin，一种来自嗜酸细菌的蓝铜蛋白）的 $E^{\circ\prime} = +0.68\ \mathrm{V}$。相对于质体蓝素，它偏好铜(I)胜过铜(II)的因子是多少？(c) 提出两种蛋白质可用来抬高铜位点电势的结构特征。（输入 (a) 的值，保留三位有效数字。）
::: solution
(a) $\log(\beta^\mathrm{II}/\beta^\mathrm{I}) = (0.153 - 0.370)/0.05916 = -3.67$。(b) 电势差为 $0.68 - 0.37 = 0.31\ \mathrm{V}$，值 $0.31/0.05916 = 5.2$ 个对数单位：锈蓝蛋白偏好铜(I)相对铜(II)比质体蓝素约 $10^{5.2} \approx 1.7\times10^5$ 倍。(c) 强制四面体几何，它适合 $d^{10}$ 的铜(I)，而使 $d^9$ 的铜(II)失去其四方姜-泰勒稳定化；使用偏好铜(I)的软给体（硫醚、硫醇盐）；把位点埋在疏水环境中，使电荷更高的铜(II)去稳定；避免铜附近有氢键给体或负电荷，它们会稳定铜(II)。据认为锈蓝蛋白把更疏水的环境与对几何更紧的约束结合在一起。
:::

::: exercise 细胞内与细胞外的顺铂 {level=3 check="0.5"}
取 $K = 4\times10^{-3}\ \mathrm{mol\,dm^{-3}}$ 作为顺铂第一步水解的示例值。用[[#eq-aquation]]求平衡时水解的分数，(a) 在血浆中（$[\mathrm{Cl^-}] = 0.10\ \mathrm{mol\,dm^{-3}}$）；(b) 在 $[\mathrm{Cl^-}] = 4\ \mathrm{mmol\,dm^{-3}}$ 的细胞中。(c) 解释为什么药物被设计成中性二氯配合物而不是水合配离子，以及为什么第二个氯离子也必须是惰性的。（输入 (b) 的分数。）
::: solution
(a) $f_\mathrm{aq} = 4\times10^{-3}/(4\times10^{-3} + 0.10) = 0.038$：血浆中约 4 % 水解。(b) $4\times10^{-3}/(4\times10^{-3} + 4\times10^{-3}) = 0.5$：细胞内一半水解。(c) 中性二氯配合物穿过细胞膜（被动地并经转运体），与血浆中大量亲核体的反应很慢，因此更多的药物能到达靶点；预先形成的阳离子水合配离子摄取很差，并在途中不加区分地反应。一旦进入细胞，第一个氯离子的水解生成结合第一个鸟嘌呤 N7 的物种；失去第二个氯离子（或水）后，铂得以结合相邻的鸟嘌呤，形成 1,2-链内交联。只有一个惰性与一个不惰性离去基团的配合物只能单功能地结合 DNA，细胞毒性要小得多。这说明了取代的动力学——与热力学一样——如何决定金属药物的作用。
