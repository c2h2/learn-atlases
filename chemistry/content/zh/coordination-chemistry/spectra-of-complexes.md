铬(III)在水溶液中呈紫色，在氨合配合物中呈黄橙色，而在红宝石——它取代刚玉中百分之几的铝——中呈深红色，并在紫外光下发出绯红色的辉光。它的光谱并不是钛(III)那种单一吸收带——晶体场理论在[[coordination-chemistry/crystal-field-theory#ex-ti3]]中曾把它解释得那么漂亮。$\mathrm{[Cr(H_2O)_6]^{3+}}$ 在可见区有两条宽吸收带，位于 $17\,400$ 与 $24\,600\ \mathrm{cm^{-1}}$；第三条藏在紫外区；红区还有两条极弱而锐利的谱线，与上面几条毫无关系。含有五个 $d$ 电子的锰(II)溶液几乎无色，那一丝淡淡的粉色来自比同一只烧瓶中氯化钴(II)的吸收弱一千倍的吸收。而完全没有 $d$ 电子的高锰酸根，却是已知颜色最浓的离子之一。

以下三个概念可以把这一切理顺。其一，当 $d$ 电子不止一个时，$t_{2g}^2e_g^1$ 一类组态的能量取决于电子如何在各轨道之间排布，因为它们彼此排斥；配合物的状态是**谱项**而不是组态，其能量同时取决于 $\Delta_\mathrm{o}$ 与电子间排斥参数 $B$。相关图（Orgel 图与 Tanabe–Sugano 图）给出谱项如何从自由离子一路演化到强场极限，拟合谱带位置即得 $\Delta_\mathrm{o}$ 与 $B$。其二，**选律**决定强度：自旋改变或宇称不变的跃迁是禁阻的、因而很弱。其三，**电荷迁移**跃迁把电子在配体与金属之间转移，是完全允许的，并主导高锰酸根、硫氰酸根合铁(III)以及太阳能电池中钌染料的光谱。本章使用[[quantum-chemistry/many-electron-atoms]]的原子谱项符号与[[coordination-chemistry/ligand-field-mo]]的对称性标记。

## 自由离子谱项

对组态为 $d^n$ 的自由离子，在符合泡利原理的前提下，把 $n$ 个电子分配到十个自旋轨道（$m_l = 2, 1, 0, -1, -2$，各有 $m_s = \pm\tfrac12$）的每一种方式都是一个**微观态**。总数为 $\binom{10}{n}$：$d^1$ 为 10，$d^2$ 为 45，$d^3$ 为 120，$d^5$ 为 252。电子排斥把它们归并为**谱项** $^{2S+1}L$，每个谱项包含 $(2S + 1)(2L + 1)$ 个能量相同的微观态（忽略自旋-轨道耦合）。

::: proposition d² 的谱项 {#prop-d2-terms}
$d^2$ 组态的 45 个微观态构成五个拉塞尔-桑德斯（Russell–Saunders）谱项，
$$
d^2:\quad {}^3F,\ {}^3P,\ {}^1G,\ {}^1D,\ {}^1S,
$$
分别包含 $21 + 9 + 9 + 5 + 1 = 45$ 个微观态。由洪特规则，基谱项是 $^3F$。$d^8$ 有两个空穴取代两个电子，得到同样的谱项。
:::

::: proof
按总量 $M_L = m_{l1} + m_{l2}$ 与 $M_S = m_{s1} + m_{s2}$ 列出微观态表。由对称性，只需数 $M_L \ge 0$ 的部分：

| $M_L$ | $M_S = +1$ | $M_S = 0$ | $M_S = -1$ |
|---|---|---|---|
| 4 | 0 | 1 | 0 |
| 3 | 1 | 2 | 1 |
| 2 | 1 | 3 | 1 |
| 1 | 2 | 4 | 2 |
| 0 | 2 | 5 | 2 |

（例如 $M_L = 4$ 要求两个电子都在 $m_l = 2$ 上，而泡利原理只允许它们自旋相反，所以它只出现在 $M_S = 0$ 处。）现在从最高处逐层剥去谱项。最大的 $M_L$ 是 4，只出现在 $M_S = 0$：这是一个 $L = 4$、$S = 0$ 的谱项，即 $^1G$，它在 $M_S = 0$ 上对从 4 到 $-4$ 的每个 $M_L$ 各贡献一个微观态。把它剥去。剩下的最大 $M_L$ 是 3，此时 $M_S = 1, 0, -1$ 处各有一个微观态：这是一个 $^3F$ 谱项，对每个满足 $|M_L| \le 3$、$|M_S| \le 1$ 的 $(M_L, M_S)$ 各贡献一个微观态。再把它剥去。$M_L = 2$ 处还剩一个微观态，在 $M_S = 0$：$^1D$。$M_L = 1$ 处还剩 $(1, 1, 1)$：$^3P$。$M_L = 0$ 处在 $M_S = 0$ 处还剩一个：$^1S$。按 $(2S + 1)(2L + 1)$ 计数：$^1G$ 9 个，$^3F$ 21 个，$^1D$ 5 个，$^3P$ 9 个，$^1S$ 1 个，共 45 个。

洪特规则决定基谱项：先取 $S$ 最大（三重态 $^3F$ 与 $^3P$），再在其中取 $L$ 最大者，$^3F$。对 $d^8$，微观态是两个空穴的排布，其 $(M_L, M_S)$ 表完全相同，所以出现的谱项也相同，仍是 $^3F$ 最低。
:::

谱项的能量由静电排斥积分给出，按惯例组合成**拉卡（Racah）参数** $A$、$B$ 与 $C$。对 $d^2$，$E(^3F) = A - 8B$，$E(^3P) = A + 7B$，$E(^1D) = A - 3B + 2C$，$E(^1G) = A + 4B + 2C$，$E(^1S) = A + 14B + 7C$。$A$ 使所有谱项整体平移，从不出现在光谱中；自旋多重度*相同*的谱项之间的能量差只依赖于 $B$（$^3F$–$^3P$ 间隔为 $15B$），而不同多重度谱项之间的能量差还涉及 $C$。$3d$ 离子的 $B$ 约为 $700$–$1100\ \mathrm{cm^{-1}}$，且 $C \approx 4B$。

::: example 洪特规则下的基谱项 {#ex-ground-terms}
求 $\mathrm{Ti^{3+}}$、$\mathrm{V^{3+}}$、$\mathrm{Cr^{3+}}$、$\mathrm{Mn^{2+}}$、$\mathrm{Fe^{2+}}$、$\mathrm{Co^{2+}}$、$\mathrm{Ni^{2+}}$ 与 $\mathrm{Cu^{2+}}$ 的自由离子基谱项。
::: solution
把电子依次填入 $m_l$ 方框 $2, 1, 0, -1, -2$，只要可能就让自旋平行；于是 $S = \tfrac12 \times$（未成对电子数），$L = |\sum m_l|$。

$\mathrm{Ti^{3+}}$ $d^1$：$m_l = 2$，$L = 2$，$S = \tfrac12$：$^2D$。$\mathrm{V^{3+}}$ $d^2$：$2 + 1 = 3$，$S = 1$：$^3F$。$\mathrm{Cr^{3+}}$ $d^3$：$2 + 1 + 0 = 3$，$S = \tfrac32$：$^4F$。$\mathrm{Mn^{2+}}$ $d^5$：每个 $m_l$ 单占据，$L = 0$，$S = \tfrac52$：$^6S$。$\mathrm{Fe^{2+}}$ $d^6$：五个平行，另有一个成对在 $m_l = 2$，$L = 2$，$S = 2$：$^5D$。$\mathrm{Co^{2+}}$ $d^7$：两处成对（$m_l = 2, 1$），$L = 3$，$S = \tfrac32$：$^4F$。$\mathrm{Ni^{2+}}$ $d^8$：$L = 2 + 1 = 3$，$S = 1$：$^3F$。$\mathrm{Cu^{2+}}$ $d^9$：一个空穴：$^2D$。

注意其中的规律：$d^n$ 与 $d^{10-n}$ 有相同的基谱项，高自旋离子中 $d^n$ 与 $d^{5+n}$ 亦然（$d^1$ 与 $d^6$ 同为 $D$；$d^2$、$d^3$、$d^7$、$d^8$ 同为 $F$）。半满壳层对 $L$ 没有贡献，所以后一个对应成立。
:::
:::

## 从谱项到配体场状态

把自由离子放入八面体场。角动量为 $L$ 的谱项表现得像一组 $2L + 1$ 个、具有球谐函数 $Y_{Lm}$ 对称性的函数，它在 $O_h$ 中的分裂与具有相同 $l$ 的一组轨道完全一样（带 $g$ 标记，因为 $d$ 函数是偶的）。由旋转群在 $O_h$ 中的特征标导出的相关关系为：

| 自由离子谱项 | $S$ | $P$ | $D$ | $F$ | $G$ |
|---|---|---|---|---|---|
| $O_h$ 中的状态 | $A_{1g}$ | $T_{1g}$ | $E_g + T_{2g}$ | $A_{2g} + T_{1g} + T_{2g}$ | $A_{1g} + E_g + T_{1g} + T_{2g}$ |

场不改变自旋多重度。状态符号写作大写字母，多重度记作左上标：$\mathrm{V^{3+}}$ 的 $^3F$ 基谱项变为 $^3T_{1g} + {}^3T_{2g} + {}^3A_{2g}$。

::: definition Orgel 图与 Tanabe–Sugano 图 {#def-ts}
**Orgel 图**在弱场下把由自旋最大的自由离子谱项产生的配体场状态的能量对 $\Delta_\mathrm{o}$ 作图。**Tanabe–Sugano 图**则在固定 $C/B$ 比下，把 $d^n$ 离子所有状态的能量以 $B$ 为单位（$E/B$）对 $\Delta_\mathrm{o}/B$ 作图，并且永远把基态画在横轴上。由于 $E/B$ 只依赖于 $\Delta_\mathrm{o}/B$ 与 $C/B$，一张图适用于该组态的一切配合物。在 Tanabe–Sugano 图上按配合物的 $\Delta_\mathrm{o}/B$ 值作一条竖线，就给出预言的跃迁能量；$d^4$–$d^7$ 的图在基态由高自旋变为低自旋处有一处不连续。
:::

### 一个电子与一个空穴：d¹ 与 d⁹

对 $d^1$，唯一的谱项是 $^2D$，它分裂为 $^2T_{2g}$（电子在 $t_{2g}$）与 $^2E_g$（在 $e_g$），间隔 $\Delta_\mathrm{o}$：一条自旋允许的吸收带。对 $d^9$ 有一个空穴。空穴在 $e_g$ 上是基态（$t_{2g}^6e_g^3$，$^2E_g$），吸收带对应空穴跳到 $t_{2g}$，位置同样在 $\Delta_\mathrm{o}$，但两个状态的顺序相反。同一倒转既把 $d^4$ 与 $d^6$（高自旋）联系起来，又以相反的方式把 $d^1$ 与 $d^6$ 对应起来；奥尔格（Orgel）的洞见在于：一张图，对其中一组从左往右读，对它的伙伴从右往左读，便同时覆盖 $d^1$、$d^4$、$d^6$ 与 $d^9$。实际上铜(II)的 $d^9$ 吸收带非常宽且不对称，因为姜-泰勒畸变把两个状态都分裂了。

### 三个电子：d³ 图

对 $d^3$（以及它的空穴伙伴 $d^8$），$^4F$ 基谱项分裂为 $^4A_{2g}$（最低）、$^4T_{2g}$ 与 $^4T_{1g}(F)$，激发谱项 $^4P$ 给出第二个 $^4T_{1g}(P)$。两个 $^4T_{1g}$ 状态对称性与自旋都相同，因而相互作用并相互排斥。

::: proposition 八面体 d³ 与 d⁸ 的自旋允许跃迁 {#prop-d3}
对八面体 $d^3$ 或 $d^8$ 离子，以 $^4A_{2g}$（或 $^3A_{2g}$）基态为起点，三条自旋允许跃迁位于
$$
\begin{aligned}
\tilde\nu_1 &= \Delta_\mathrm{o} &&({}^4A_{2g} \rightarrow {}^4T_{2g}),\\
\tilde\nu_{2,3} &= \tfrac{15}{2}B + \tfrac32\Delta_\mathrm{o} \mp \tfrac12\sqrt{225B^2 - 18B\Delta_\mathrm{o} + \Delta_\mathrm{o}^2} &&({}^4A_{2g} \rightarrow {}^4T_{1g}(F),\ {}^4T_{1g}(P)).
\end{aligned}
$$ {#eq-d3}
因此 $\tilde\nu_2 + \tilde\nu_3 = 15B + 3\Delta_\mathrm{o}$。这些表达式忽略了自旋-轨道耦合以及与其他自旋状态之间的组态相互作用，并假定所有状态共用同一个 $B$。
:::

::: proof
在强场基下，四重态状态来自组态：$^4A_{2g}$ 来自 $t_{2g}^3$（相对重心的能量为 $-1.2\Delta_\mathrm{o}$），$^4T_{2g}$ 与一个 $^4T_{1g}$ 来自 $t_{2g}^2e_g^1$（$-0.2\Delta_\mathrm{o}$），另一个 $^4T_{1g}$ 来自 $t_{2g}^1e_g^2$（$+0.8\Delta_\mathrm{o}$）。计入电子排斥（标准矩阵元，其推导可见菲吉斯（Figgis）与希奇曼（Hitchman）的专著），相对于 $^4A_{2g}$ 的能量为：$^4T_{2g}$ 恰好在 $\Delta_\mathrm{o}$ 处，与 $B$ 无关，因为它与基态的差别只是把一个电子从 $t_{2g}$ 移到 $e_g$，而移法不改变排斥；至于两个 $^4T_{1g}$ 状态，$2 \times 2$ 矩阵为
$$
\begin{pmatrix} \Delta_\mathrm{o} + 12B & 6B \\ 6B & 2\Delta_\mathrm{o} + 3B \end{pmatrix},
$$
其对角元是 $t_{2g}^2e_g^1$ 与 $t_{2g}^1e_g^2$ 状态，非对角元使二者混合。特征值为
$$
E = \tfrac12\left[(3\Delta_\mathrm{o} + 15B) \mp \sqrt{(\Delta_\mathrm{o} - 9B)^2 + 4(6B)^2}\right],
$$
而 $(\Delta_\mathrm{o} - 9B)^2 + 144B^2 = \Delta_\mathrm{o}^2 - 18B\Delta_\mathrm{o} + 225B^2$，即[[#eq-d3]]。特征值之和为矩阵的迹，$3\Delta_\mathrm{o} + 15B$。两个极限可以检验这一结果。$\Delta_\mathrm{o} = 0$ 时，两根为 $0$ 与 $15B$：两个 $T_{1g}$ 状态都来自自由离子谱项 $^4F$ 与 $^4P$，二者相距 $15B$。$\Delta_\mathrm{o} \to \infty$ 时，两根趋于 $\Delta_\mathrm{o} + 12B - \dots$ 与 $2\Delta_\mathrm{o} + \dots$，即单电子与双电子激发。对 $d^8$，同样的代数对空穴成立，它把 $d^2$ 的 $T_{2g}$、$T_{1g}$ 状态的顺序变成 $d^3$ 的顺序，所以公式完全相同。
:::

::: example 拟合六水合铬(III)的 Δo 与 B {#ex-cr-fit}
$\mathrm{[Cr(H_2O)_6]^{3+}}$ 在 $17\,400$ 与 $24\,600\ \mathrm{cm^{-1}}$ 处吸收。求 $\Delta_\mathrm{o}$ 与 $B$，预言第三条自旋允许吸收带的位置，并把 $B$ 与自由离子值 $B_0(\mathrm{Cr^{3+}}) = 918\ \mathrm{cm^{-1}}$ 比较。

由[[#prop-d3]]，最低能量的吸收带就是 $\Delta_\mathrm{o} = 17\,400\ \mathrm{cm^{-1}}$。把它代入 $\tilde\nu_2$ 的表达式并对 $B$ 求解：
$$
24\,600 = 7.5B + 26\,100 - \tfrac12\sqrt{225B^2 - 313\,200B + 3.0276\times10^8}.
$$
整理得 $\sqrt{225B^2 - 313\,200B + 3.0276\times10^8} = 15B + 3000$。两边平方，$225B^2 - 313\,200B + 3.0276\times10^8 = 225B^2 + 90\,000B + 9.0\times10^6$，于是 $403\,200B = 2.9376\times10^8$，$B = 729\ \mathrm{cm^{-1}}$（$B^2$ 项相消，方程是线性的；验证 $15B + 3000 > 0$，确实如此）。再由和规则得 $\tilde\nu_3 = 15B + 3\Delta_\mathrm{o} - \tilde\nu_2 = 10\,929 + 52\,200 - 24\,600 = 38\,500\ \mathrm{cm^{-1}}$（$260\ \mathrm{nm}$），在紫外区，部分被电荷迁移吸收掩盖；实验在 $37\,800\ \mathrm{cm^{-1}}$ 附近观察到一条吸收带。比值 $\beta = B/B_0 = 729/918 = 0.79$：配合物中的电子间排斥比自由离子小 21 %。$575\ \mathrm{nm}$（黄光）与 $407\ \mathrm{nm}$（紫光）处的吸收带在蓝紫与红光处留下一个透过窗口，眼睛看到的就是紫灰色。

### 电子云扩展效应

配合物中 $B$ 的减小就是**电子云扩展效应**（nephelauxetic，源自希腊语，意为"扩展电子云"）：金属的 $d$ 电子通过共价混合扩展到配体上，电子之间的平均距离增大，排斥随之下降。比值 $\beta = B/B_0$ 把配体排成**电子云扩展序列**，大致为
$$
\mathrm{F^-} > \mathrm{H_2O} > \mathrm{NH_3} > \mathrm{en} > \mathrm{ox^{2-}} > \mathrm{SCN^-} > \mathrm{Cl^-} \approx \mathrm{CN^-} > \mathrm{Br^-} > \mathrm{I^-},
$$
按共价性从最弱到最强（氟离子的 $\beta$ 接近 1，溴离子与碘离子接近 0.5–0.6）。对铬(III)，水合物的 $\beta$ 为 $0.79$，氨合物为 $0.72$（[[#exr-cr-nh3]]）。与光谱化学序列不同，这一序列跟随给体原子的柔软度与极化率，正如其作为共价性度量所应有的那样（对比[[main-group/inorganic-acids-bases]]的软硬分类）。

::: quiz
对八面体 $d^8$ 离子（如 $\mathrm{Ni^{2+}}$），哪条吸收带的位置直接给出 $\Delta_\mathrm{o}$？
- [x] 能量最低的自旋允许吸收带。
- [ ] 中间那条吸收带。
- [ ] 能量最高的吸收带。
- [ ] 能量最高的两条吸收带之差。
::: solution
对 $d^3$ 与 $d^8$，与基态同自旋的最低激发态 $T_{2g}$ 恰好位于 $A_{2g}$ 基态之上 $\Delta_\mathrm{o}$ 处（[[#prop-d3]]），与 $B$ 无关。其余两条吸收带通向 $T_{1g}$ 状态，其能量同时依赖 $\Delta_\mathrm{o}$ 与 $B$；两者之和为 $15B + 3\Delta_\mathrm{o}$。
:::
:::

## 选律与强度

吸收带的强度用带最大处的摩尔吸收系数 $\varepsilon$ 度量（单位 $\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$），更根本的度量是积分强度或振子强度（[[spectroscopy/electronic-spectroscopy]]）。对电偶极跃迁，强度正比于跃迁偶极矩 $\langle \psi_\mathrm{f} | \hat{\boldsymbol\mu} | \psi_\mathrm{i} \rangle$ 的平方，而两条对称性规则使许多 $d$–$d$ 跃迁的这一量为零。

::: proposition d–d 跃迁的选律 {#prop-selection}
1. **自旋选律**：$\Delta S = 0$。偶极算符不作用于自旋，所以总自旋不同的状态之间互不联通。
2. **拉波特（Laporte）规则**：在中心对称的配合物中，宇称相同的状态之间的跃迁（$g \leftrightarrow g$ 或 $u \leftrightarrow u$）是禁阻的；只有 $g \leftrightarrow u$ 是允许的。

由于所有 $d$ 轨道状态都是 $g$，八面体或平面正方形配合物中的每一条 $d$–$d$ 跃迁都是拉波特禁阻的。这些规则会被**自旋-轨道耦合**（把自旋不同的状态混合起来，对较重原子更显著）、**振动-电子耦合**（不对称振动瞬时地消除反演中心）所放宽；在四面体等非中心对称配合物中，$d$ 与 $p$ 轨道的混合也起放宽作用。
:::

::: proof
电偶极算符 $\hat{\boldsymbol\mu} = -e\sum_i \mathbf{r}_i$ 是位置算符之和，在反演下变号：它是 $u$。于是对 $g \rightarrow g$ 跃迁，被积函数 $\psi_\mathrm{f}^*\hat{\boldsymbol\mu}\psi_\mathrm{i}$ 的宇称为 $g \times u \times g = u$，而奇函数在全空间的积分为零。对 $g \rightarrow u$，被积函数为 $g$，积分可以不为零。至于自旋规则，把每个状态写成空间函数与自旋函数的乘积；$\hat{\boldsymbol\mu}$ 只作用于空间部分，所以积分中含有因子 $\langle S_\mathrm{f} M_\mathrm{f} | S_\mathrm{i} M_\mathrm{i} \rangle$，由自旋本征函数的正交性，除非自旋相同，该因子为零。
:::

这些规则给出一个粗略的强度标尺，是无机化学中最有用的诊断手段之一：

| 跃迁类型 | 典型 $\varepsilon_\mathrm{max}$ / $\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$ | 例子 |
|---|---|---|
| 自旋禁阻、拉波特禁阻 | $< 1$ | $\mathrm{[Mn(H_2O)_6]^{2+}}$（淡粉色） |
| 自旋允许、拉波特禁阻（八面体 $d$–$d$） | 1–100 | $\mathrm{[Ni(H_2O)_6]^{2+}}$、$\mathrm{[Cr(H_2O)_6]^{3+}}$ |
| 自旋允许，四面体 $d$–$d$（$d$–$p$ 混合） | 100–1000 | $\mathrm{[CoCl_4]^{2-}}$（深蓝色） |
| 电荷迁移，完全允许 | 1000–50 000 | $\mathrm{[MnO_4]^-}$、$\mathrm{[Ru(bpy)_3]^{2+}}$ |

::: example 为什么锰(II)几乎无色？ {#ex-mn2}
请解释 $\mathrm{[Mn(H_2O)_6]^{2+}}$ 为何只有极弱的吸收（$\varepsilon < 0.1$），为何它的某些吸收带格外锐利，以及锰(II)盐如 $\mathrm{MnCl_2\cdot4H_2O}$ 为何看上去是淡粉色而不是无色。
::: solution
高自旋 $d^5$ 的基态是 $^6A_{1g}$（来自 $^6S$ 自由离子谱项，$t_{2g}^3e_g^2$，五个自旋全部平行）。没有其他 $d^5$ 状态的 $S = \tfrac52$：任何激发态都至少要求一个自旋翻转，所以每条 $d$–$d$ 跃迁既是自旋禁阻的也是拉波特禁阻的。这两条规则只被微弱的微扰放宽（$3d$ 离子的自旋-轨道耦合很小，振动-电子耦合只能部分解除宇称限制），所以 $\varepsilon$ 为 $0.01$–$0.1$ 量级。某些激发态，如来自 $^4G$ 谱项的 $^4A_{1g}$ 与 $^4E_g$，与基态有相同的组态 $t_{2g}^3e_g^2$，只是一个自旋反向了。它们相对基态的能量因此不依赖 $\Delta_\mathrm{o}$，而调制 $\Delta_\mathrm{o}$ 的分子振动也就无法加宽这些吸收带，于是它们是锐的（$25\,000\ \mathrm{cm^{-1}}$ 附近）。微弱的吸收散布在整个可见区，绿光处稍多，这就是浓溶液与晶体中看到的淡粉色。
:::
:::

::: warning 颜色不是 Δo 的可靠量度 {#warn-colour}
人们很容易从配合物的颜色出发、用互补色反推 $\Delta_\mathrm{o}$。这只有对单一、孤立、自旋允许的吸收带才成立（如 $\mathrm{Ti^{3+}}$）。有两条或三条吸收带时（多数 $d^2$、$d^3$、$d^7$、$d^8$ 离子），看到的颜色是它们之间透过的光，而对 $d^3$ 与 $d^8$ 给出 $\Delta_\mathrm{o}$ 的*最低*吸收带可能位于近红外（$\mathrm{[Ni(H_2O)_6]^{2+}}$ 在 $8500\ \mathrm{cm^{-1}}$、$1180\ \mathrm{nm}$ 处），完全不在可见区内。近紫外的电荷迁移吸收带常常拖尾进入可见区并主导颜色，例如黄色的铬酸根或橙红色的铁(III)溶液。而且强度与位置同样重要：一个强吸收的四面体配合物，在八面体配合物几乎透明的浓度下就显得颜色极深。吸收带的指认永远要依据光谱，绝不能依据颜色。
:::

## 电荷迁移跃迁

**电荷迁移**（CT）跃迁把一个电子从主要位于配体上的轨道移到主要位于金属上的轨道（**配体到金属电荷迁移**，LMCT），或从金属移到配体的空轨道（**金属到配体电荷迁移**，MLCT）。用[[coordination-chemistry/ligand-field-mo]]的分子轨道语言来说，它们是宇称不同、定域位置也不同的分子轨道之间的跃迁：通常是配体为主的 $u$ 轨道到金属的 $e_g^*$ 或 $t_{2g}$（LMCT），或金属的 $t_{2g}$ 到配体的 $\pi^*$（MLCT）。它们自旋允许且拉波特允许，因此非常强。

当配体易被氧化（柔软、易极化的给体：按能量 $\mathrm{I^-} < \mathrm{Br^-} < \mathrm{Cl^-}$）且金属易被还原（高氧化态）时，LMCT 吸收带的能量最低。四面体 $d^0$ 含氧酸根把金属效应显示得很清楚：第一条 LMCT 带，钒酸根 $\mathrm{[VO_4]^{3-}}$ 位于 $37\,000\ \mathrm{cm^{-1}}$（约 $270\ \mathrm{nm}$）附近，无色；铬酸根 $\mathrm{[CrO_4]^{2-}}$ 位于 $27\,000\ \mathrm{cm^{-1}}$（$370\ \mathrm{nm}$）附近，黄色；高锰酸根 $\mathrm{[MnO_4]^-}$ 位于 $19\,000\ \mathrm{cm^{-1}}$（$525\ \mathrm{nm}$）附近，紫色。沿这一等电子系列，金属电荷升高，其受体轨道（$e$）下降，吸收带因此移向低能量。

MLCT 带要求金属处于低氧化态、$t_{2g}$ 轨道已填满，并要求配体具有低能 $\pi^*$ 轨道：$\mathrm{[Ru(bpy)_3]^{2+}}$（$d^6$，MLCT 在 $452\ \mathrm{nm}$，$\varepsilon \approx 1.4\times10^4$）、$\mathrm{[Fe(phen)_3]^{2+}}$（试亚铁灵，红色的氧化还原指示剂），以及许多显色试剂的铜(I)与铁(II)配合物（[[analytical-chemistry/molecular-spectrometry]]）。

::: example 光谱的指认 {#ex-assign}
某镍(II)配合物的淡绿色溶液在 $10\,750$（$\varepsilon = 6$）、$17\,500$（$\varepsilon = 7$）与 $28\,200\ \mathrm{cm^{-1}}$（$\varepsilon = 10$）处显示吸收带，并在 $40\,000\ \mathrm{cm^{-1}}$ 以上有一条强吸收带（$\varepsilon \approx 8000$）。(a) 指认各吸收带。(b) 求 $\Delta_\mathrm{o}$ 与 $B$。(c) 该配合物是八面体还是四面体？
::: solution
(a) 三条弱吸收带（$\varepsilon \le 10$）是八面体 $d^8$ 离子的自旋允许但拉波特禁阻的 $d$–$d$ 跃迁：按能量依次为 $^3A_{2g} \rightarrow {}^3T_{2g}$、$^3T_{1g}(F)$ 与 $^3T_{1g}(P)$。紫外的强吸收带是电荷迁移（或配体内部跃迁）。(b) $\Delta_\mathrm{o} = \tilde\nu_1 = 10\,750\ \mathrm{cm^{-1}}$。和规则给出 $15B = \tilde\nu_2 + \tilde\nu_3 - 3\Delta_\mathrm{o} = 17\,500 + 28\,200 - 32\,250 = 13\,450$，所以 $B = 897\ \mathrm{cm^{-1}}$。用[[#eq-d3]]检验：取 $\Delta_\mathrm{o} = 10\,750$、$B = 897$，$\tilde\nu_2 = 6725 + 16\,125 - \tfrac12\sqrt{1.809\times10^8 - 1.735\times10^8 + 1.156\times10^8} = 22\,850 - 5544 = 17\,306\ \mathrm{cm^{-1}}$，且 $\tilde\nu_3 = 22\,850 + 5544 = 28\,394\ \mathrm{cm^{-1}}$。两者与观察到的吸收带（$17\,500$ 与 $28\,200$）都相差约 1 % 以内。仅凭和规则无法检验模型，因为 $B$ 正是对这个和拟合出来的；真正的检验是同一个 $B$ 能否把每条吸收带都放对位置，这里它做到了 1 % 以内。这些数值对 $\mathrm{[Ni(NH_3)_6]^{2+}}$ 很典型。(c) 八面体：四面体镍(II)的 $\varepsilon$ 应为 100 量级，$\Delta_\mathrm{t}$ 不到一半大，其主要可见吸收带在红区。
:::
:::

::: example 一个钌染料 {#ex-mlct}
$\mathrm{[Ru(bpy)_3]^{2+}}$ 呈橙色，吸收最大在 $452\ \mathrm{nm}$，$\varepsilon = 1.4\times10^4\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。(a) 求 $5.0\times10^{-5}\ \mathrm{mol\,dm^{-3}}$ 溶液在 $1.00\ \mathrm{cm}$ 吸收池中的吸光度，以及透过的光的分数。(b) 为什么这条吸收带不可能是 $d$–$d$ 跃迁？(c) 描述其激发态。
::: solution
(a) 朗伯-比尔定律：$A = \varepsilon c l = (1.4\times10^4)(5.0\times10^{-5})(1.00) = 0.70$，且 $T = 10^{-0.70} = 0.20$：即使是很稀的溶液，$452\ \mathrm{nm}$ 的光也只有 20 % 透过。(b) 钌(II)是低自旋 $d^6$，$t_{2g}^6$；它的 $d$–$d$ 吸收带本应很弱（$\varepsilon < 100$），而且第二过渡系金属与 bpy 配合的 $\Delta_\mathrm{o}$ 非常大，那些带位于紫外区。$10^4$ 的 $\varepsilon$ 要求的必须是允许跃迁。(c) 它是 MLCT：一个电子从钌的 $t_{2g}$ 组移到一个联吡啶的 $\pi^*$ 轨道，形式上得到 $\mathrm{[Ru^{III}(bpy)_2(bpy^{\bullet-})]^{2+}}$。这一激发态很快变成寿命较长的三重态，它同时比基态既是更强的还原剂又是更强的氧化剂，这就是钌的多吡啶配合物被用作光氧化还原催化与染料敏化太阳能电池中光敏剂的原因（[[kinetics/photochemistry]]）。
:::
:::

## 后续内容

本章的光谱是配体场理论的实验基础：光谱化学序列中的 $\Delta_\mathrm{o}$ 与电子云扩展序列中的 $B$，都来自这里做的这种拟合。我们大多忽略的自旋-轨道耦合，对[[coordination-chemistry/magnetism]]的磁学性质变得不可或缺，并主导镧系元素的光谱——后者的 $f$–$f$ 吸收带很锐利，几乎与配体无关（[[coordination-chemistry/f-block]]）。红宝石的红色发射来自 $\mathrm{Cr^{3+}}$ 的 $^2E_g$ 状态，它是第一台激光器（1960 年）的基础，至今仍被用作金刚石对顶砧中的压强计；固体中的应用见[[materials-chemistry/magnetic-optical]]。电荷迁移吸收带则是金属的比色分析与配合物光化学的基础。

::: history
原子谱项符号与电子角动量的耦合由亨利·诺利斯·拉塞尔（Henry Norris Russell）与弗雷德里克·桑德斯（Frederick Saunders）于 1925 年依据碱土金属的光谱确立，朱利奥·拉卡（Giulio Racah）则从 1942 年起在《物理评论》（*Physical Review*）的一系列论文中引入了他的参数。莱斯特·奥尔格（Leslie Orgel）1955 年发表在 *Journal of Chemical Physics* 上的论文给出了以他命名的弱场相关图。田边（Yukito Tanabe）与菅原（Satoru Sugano）1954 年在 *Journal of the Physical Society of Japan* 上发表了 $d^2$–$d^8$ 的完整图谱，对每个组态求解了配体场与排斥相加的完整问题；这些图至今仍是标准工具。强度规则源自奥托·拉波特（Otto Laporte）1924 年对原子光谱的工作，而禁阻 $d$–$d$ 带获得强度的振动-电子机理则在 1950 年代得到解释。克里斯蒂安·克利克斯比尔·约根森（Christian Klixbüll Jørgensen）自 1950 年代起在哥本哈根工作，创造了"nephelauxetic"（电子云扩展）一词，并把光谱化学序列与电子云扩展序列以及电荷迁移光谱都加以系统化。西奥多·梅曼（Theodore Maiman）1960 年的红宝石激光器把铬(III)那条锐利的自旋禁阻 $^2E_g \rightarrow {}^4A_{2g}$ 发射变成了一项技术。
:::

::: summary
- $d^n$ 离子有 $\binom{10}{n}$ 个微观态，电子排斥把它们归并为拉塞尔-桑德斯谱项；$d^2$ 给出 $^3F$（基）、$^3P$、$^1G$、$^1D$、$^1S$，洪特规则可以找出任何组态的基谱项。
- 八面体场中 $S \rightarrow A_{1g}$、$P \rightarrow T_{1g}$、$D \rightarrow E_g + T_{2g}$、$F \rightarrow A_{2g} + T_{1g} + T_{2g}$；自旋多重度不变。
- Tanabe–Sugano 图把 $E/B$ 对 $\Delta_\mathrm{o}/B$ 作图；对 $d^3$ 与 $d^8$，最低的自旋允许吸收带就是 $\Delta_\mathrm{o}$，其余两条满足 $\tilde\nu_2 + \tilde\nu_3 = 15B + 3\Delta_\mathrm{o}$。
- 配合物中的 $B$ 小于自由离子（$\beta = B/B_0 \approx 0.5$–$0.9$）：电子云扩展效应度量共价性，并跟随给体原子的柔软度。
- 自旋规则（$\Delta S = 0$）与拉波特规则（只允许 $g \leftrightarrow u$）使八面体 $d$–$d$ 带很弱（$\varepsilon \approx 1$–$100$），自旋禁阻带极弱（$< 1$）；四面体吸收带更强（100–1000）。
- 电荷迁移吸收带（高氧化态与软配体对应 LMCT，低氧化态与 $\pi$ 受体配体对应 MLCT）完全允许，$\varepsilon \approx 10^3$–$10^5$，并主导高锰酸根、铬酸根与钌多吡啶的颜色。
:::

## 习题

::: exercise 微观态计数 {level=1 check="120"}
$d^3$ 组态有多少个微观态？它的基谱项包含多少个？（输入微观态的数目。）
::: solution
$\binom{10}{3} = 120$ 个微观态。基谱项是 $^4F$（$S = \tfrac32$，$L = 3$），包含其中 $(2S + 1)(2L + 1) = 4 \times 7 = 28$ 个。
:::
:::

::: exercise 基谱项及其分裂 {level=1}
给出 $\mathrm{V^{2+}}$、$\mathrm{Fe^{3+}}$（高自旋）与 $\mathrm{Co^{3+}}$（自由离子）的自由离子基谱项，以及在八面体场中各自分裂成的状态。
::: solution
$\mathrm{V^{2+}}$，$d^3$：$^4F \rightarrow {}^4A_{2g} + {}^4T_{1g} + {}^4T_{2g}$（基态 $^4A_{2g}$）。$\mathrm{Fe^{3+}}$，$d^5$：$^6S \rightarrow {}^6A_{1g}$（无分裂；自旋允许的 $d$–$d$ 跃迁全部不存在，所以铁(III)的颜色主要来自电荷迁移）。$\mathrm{Co^{3+}}$，$d^6$：$^5D \rightarrow {}^5T_{2g} + {}^5E_g$。不过在大多数配合物中，钴(III)是低自旋的，基态为 $^1A_{1g}$（$t_{2g}^6$），它来自一个单重自由离子谱项，而不是 $^5D$；这正是 Tanabe–Sugano 图更换基态的地方。
:::
:::

::: exercise 朗伯-比尔定律的估算 {level=1 check="0.12"}
$\mathrm{[Ni(H_2O)_6]^{2+}}$ 在 $395\ \mathrm{nm}$ 吸收带处的 $\varepsilon = 5.0\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。$0.0240\ \mathrm{mol\,dm^{-3}}$ 溶液在 $1.00\ \mathrm{cm}$ 吸收池中的吸光度是多少？（输入吸光度。）
::: solution
$A = \varepsilon c l = 5.0 \times 0.0240 \times 1.00 = 0.12$。换成 $\mathrm{[MnO_4]^-}$（$525\ \mathrm{nm}$ 处 $\varepsilon \approx 2400$）要产生同样的吸光度，只需 $5\times10^{-5}\ \mathrm{mol\,dm^{-3}}$，这就是高锰酸钾滴定可以自身指示的原因。
:::
:::

::: exercise 六氨合铬(III) {#exr-cr-nh3 level=2 check="663"}
$\mathrm{[Cr(NH_3)_6]^{3+}}$ 在 $21\,500$ 与 $28\,500\ \mathrm{cm^{-1}}$ 处吸收。求 $\Delta_\mathrm{o}$、$B$ 与 $\beta$（$B_0 = 918\ \mathrm{cm^{-1}}$），并与 $\mathrm{[Cr(H_2O)_6]^{3+}}$ 比较。（$B$ 以 $\mathrm{cm^{-1}}$ 输入，保留三位有效数字。）
::: hint
按[[#ex-cr-fit]]：隔离根号，两边平方，$B^2$ 项相消。
:::
::: solution
$\Delta_\mathrm{o} = 21\,500\ \mathrm{cm^{-1}}$。于是 $28\,500 = 7.5B + 32\,250 - \tfrac12\sqrt{225B^2 - 387\,000B + 4.6225\times10^8}$，即 $\sqrt{\cdots} = 15B + 7500$。平方：$-387\,000B + 4.6225\times10^8 = 225\,000B + 5.625\times10^7$，得 $612\,000B = 4.06\times10^8$，$B = 663\ \mathrm{cm^{-1}}$。于是 $\beta = 663/918 = 0.72$，比水的 $0.79$ 小：氨是较软的给体，电子云扩展效应更强。氨合物的 $\Delta_\mathrm{o}$ 与共价性都比水合物大。
:::
:::

::: exercise 按强度指认 {level=2}
四种溶液的可见区最强吸收的 $\varepsilon_\mathrm{max}$ 分别为 (a) 0.03、(b) 12、(c) 600、(d) 4000 $\mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。把它们与 $\mathrm{[CoCl_4]^{2-}}$、$\mathrm{[Mn(H_2O)_6]^{2+}}$、$\mathrm{[Fe(SCN)(H_2O)_5]^{2+}}$ 和 $\mathrm{[Co(H_2O)_6]^{2+}}$ 配对，并说明理由。
::: solution
(a) 0.03：$\mathrm{[Mn(H_2O)_6]^{2+}}$，自旋禁阻且拉波特禁阻。(b) 12：$\mathrm{[Co(H_2O)_6]^{2+}}$，自旋允许的八面体 $d$–$d$ 带（粉色）。(c) 600：$\mathrm{[CoCl_4]^{2-}}$，四面体，无反演中心，$d$–$p$ 混合使 $d$–$d$ 带强得多（深蓝色）。(d) 4000：$\mathrm{[Fe(SCN)(H_2O)_5]^{2+}}$，血红色的 LMCT 带（硫氰酸根到铁(III)），即铁(III)比色检验所用的那条带。
:::

预言下列各组中最低 LMCT 吸收带能量的次序：(a) $\mathrm{[IrCl_6]^{2-}}$ 与 $\mathrm{[IrBr_6]^{2-}}$；(b) $\mathrm{[CrO_4]^{2-}}$ 与 $\mathrm{[MoO_4]^{2-}}$；(c) $\mathrm{[Fe(H_2O)_6]^{3+}}$ 与 $\mathrm{[Fe(H_2O)_6]^{2+}}$。解释每一组。
::: solution
(a) 溴离子比氯离子易被氧化（它的孤对电子能量更高），所以 $\mathrm{[IrBr_6]^{2-}}$ 的 LMCT 带在较低能量。(b) 钼(VI)比铬(VI)难被还原（较重的元素在最高氧化态更稳定，这是[[coordination-chemistry/d-block-chemistry]]的一般趋势），所以钼酸根的 LMCT 在较高能量：钼酸根无色，而铬酸根是黄色的。(c) 铁(III)比铁(II)易被还原得多，所以来自水的 LMCT 在 $\mathrm{Fe^{3+}}$ 处低得多；其在近紫外的拖尾促成了铁(III)溶液的黄棕色（其中还有水解物种，吸收位置更低），而 $\mathrm{[Fe(H_2O)_6]^{2+}}$ 因一条弱 $d$–$d$ 带而呈淡绿色。
:::

::: exercise 六水合镍(II)的拟合 {level=3 check="14144"}
$\mathrm{[Ni(H_2O)_6]^{2+}}$ 在 $8500$ 与 $25\,300\ \mathrm{cm^{-1}}$ 处的吸收带可指认为 $\tilde\nu_1$ 与 $\tilde\nu_3$；中间那条带很宽且有分裂。(a) 由 $\tilde\nu_1$ 与 $\tilde\nu_3$ 求 $B$。(b) 预言 $\tilde\nu_2$。(c) 观察到的中间带在 $13\,800$ 与 $15\,400\ \mathrm{cm^{-1}}$ 附近各有一个分量。试解释原因。（预言的 $\tilde\nu_2$ 以 $\mathrm{cm^{-1}}$ 输入，取到整数值。）
::: hint
对 $\tilde\nu_3$，按[[#eq-d3]]取加号。隔离根号，平方，解关于 $B$ 的线性方程。
:::
::: solution
(a) 取 $\Delta_\mathrm{o} = 8500$：$25\,300 = 7.5B + 12\,750 + \tfrac12\sqrt{225B^2 - 153\,000B + 7.225\times10^7}$，即 $\sqrt{\cdots} = 25\,100 - 15B$。平方：$225B^2 - 153\,000B + 7.225\times10^7 = 6.3001\times10^8 - 753\,000B + 225B^2$，于是 $600\,000B = 5.5776\times10^8$，$B = 929.6\ \mathrm{cm^{-1}}$（取 $B_0(\mathrm{Ni^{2+}}) = 1080\ \mathrm{cm^{-1}}$，则 $\beta = 929.6/1080 = 0.86$）。(b) 和规则：$\tilde\nu_2 = 15B + 3\Delta_\mathrm{o} - \tilde\nu_3 = 13\,944 + 25\,500 - 25\,300 = 14\,144\ \mathrm{cm^{-1}}$。(c) 预言的位置正落在观察到的两个分量之间。自旋禁阻的 $^3A_{2g} \rightarrow {}^1E_g$ 跃迁（来自 $^1D$ 谱项）恰好在这一场强下紧邻 $^3T_{1g}(F)$；自旋-轨道耦合把两个状态混合，它们共享强度并相互排斥，于是给出双重带。这种交叉附近的"强度借用"在 Tanabe–Sugano 图中十分常见，它提醒我们自旋规则只是近似的。
:::

::: exercise 由空穴看 d⁸ 的谱项 {level=3}
(a) 证明 $d^n$ 的微观态数目与 $d^{10-n}$ 相同。(b) 解释为什么 $d^8$ 的谱项与 $d^2$ 相同，但 $^3F$ 在八面体场中的分裂图样是倒转的（$d^2$ 基态是 $^3T_{1g}$，$d^8$ 则是 $^3A_{2g}$）。(c) 利用 (b)，解释为什么八面体 $d^2$ 离子的最低吸收带*不能*直接给出 $\Delta_\mathrm{o}$。
::: solution
(a) $\binom{10}{n} = \binom{10}{10-n}$：选出哪 $n$ 个自旋轨道被占据，等同于选出哪 $10 - n$ 个是空的。(b) $d^{10-n}$ 的每个微观态都对应 $n$ 个空穴的、$M_L$ 与 $M_S$ 符号相反的一个微观态，所以 $(M_L, M_S)$ 表因而谱项完全一致。空穴表现得像一个正电荷：配体场抬高 $e_g$ 上电子的能量，却*降低*那里空穴的能量。所有单电子分裂都变号，每个谱项给出状态的顺序随之倒转。$d^2$ 的两个电子优先占据 $t_{2g}$，使 $^3T_{1g}$（来自 $t_{2g}^2$）最低；$d^8$ 的两个空穴优先占据 $e_g$（等价地说，八个电子填满 $t_{2g}^6e_g^2$），使 $^3A_{2g}$ 最低。(c) 对 $d^2$，基态 $^3T_{1g}(F)$ 本身就是相互作用的两个 $T_{1g}$ 状态之一；它因与 $^3T_{1g}(P)$ 的相互作用而被压低，压低量依赖 $B$。因此最低吸收带 $^3T_{1g}(F) \rightarrow {}^3T_{2g}$ 位于比 $0.8\Delta_\mathrm{o}$ 略高的地方，高出的量依赖于 $B$，两个参数必须像 $\mathrm{[V(H_2O)_6]^{3+}}$ 那样一起拟合。只有 $d^3$、$d^8$（$A_{2g}$ 基态）以及单电子、单空穴情形，才有一条吸收带恰好等于 $\Delta_\mathrm{o}$。
:::
