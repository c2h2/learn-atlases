1890 年，化学家已经知道四种氯化钴(III)氨合物，却一种也解释不了。$\mathrm{CoCl_3\cdot 6NH_3}$ 是黄色的，$\mathrm{CoCl_3\cdot 5NH_3}$ 是紫色的，而 $\mathrm{CoCl_3\cdot 4NH_3}$ 有两种形态，一种绿色，一种紫罗兰色。氨是稳定的饱和分子，$\mathrm{CoCl_3}$ 的"化合价"也已经满足，那么多出来的氨靠什么保持住？为什么同一个化学式会以两种不同的物质存在？向新鲜配制的溶液中加入硝酸银，四种化合物以氯化银形式释出的氯各不相同：黄色盐的三个氯全部释出，紫色盐释出两个，绿色和紫罗兰色盐只释出一个。有些氯在溶液中是自由的，有些氯结合得极紧，连银离子都碰不到。

阿尔弗雷德·维尔纳（Alfred Werner）1893 年发表的回答开创了本课程。钴在其周围以固定的几何排列容纳六个基团：黄色盐里是六个氨分子，紫色盐里是五个氨加一个氯离子，绿色和紫罗兰色盐里是四个氨加两个氯离子。不在这个内界里的一切都是普通的离子。绿色与紫罗兰色盐就是把两个氯离子放在八面体上的两种方式。本章以现代表述给出维尔纳的图像：配体是什么、每个配体有几个原子参与配位，会出现哪些配位数与构型及其原因，配合物如何命名与书写，以及同一化学式可以描述两种以上不同物质的种种方式。本课程后面的全部内容（晶体场分裂、光谱、磁性、稳定性、反应机理）都假设你能看着一个化学式找到金属、它的配体、氧化态与几何构型，并列出它的异构体。

## 维尔纳的配位理论

::: definition 配位化合物、配体、配位数 {#def-complex}
**配位化合物**含有一个**配合物**：一个中心金属原子或离子与周围一组分子或离子成键，这些分子或离子称为**配体**，每个配体至少通过一个**给体原子**提供一对电子。用路易斯酸碱的语言（见[[main-group/inorganic-acids-bases]]），金属是酸，配体是碱，形成的键是配位（给予）键。金属与直接与其成键的配体构成**内界（配位层）**，写在方括号内；括号外的抗衡阳离子与溶剂构成**外界**。**配位数**（配位数，CN）是键合到金属上的给体原子数目。它不等于配体数目，因为一个配体可以通过多个原子配位。
:::

维尔纳的用语是"一级价"（primary valence，即我们今天说的氧化态与离子电荷平衡）与"二级价"（secondary valence，即配位数）。四种钴盐于是变成

| 旧化学式 | 维尔纳式（现代写法） | 颜色 | 每个 Co 的自由 $\mathrm{Cl^-}$ | 每个化学式的离子数 |
|---|---|---|---|---|
| $\mathrm{CoCl_3\cdot6NH_3}$ | $\mathrm{[Co(NH_3)_6]Cl_3}$ | 黄 | 3 | 4 |
| $\mathrm{CoCl_3\cdot5NH_3}$ | $\mathrm{[CoCl(NH_3)_5]Cl_2}$ | 紫 | 2 | 3 |
| $\mathrm{CoCl_3\cdot4NH_3}$ | *trans*-$\mathrm{[CoCl_2(NH_3)_4]Cl}$ | 绿 | 1 | 2 |
| $\mathrm{CoCl_3\cdot4NH_3}$ | *cis*-$\mathrm{[CoCl_2(NH_3)_4]Cl}$ | 紫罗兰 | 1 | 2 |

每个配合物的内界在氯化银检验的时间尺度上都是*动力学*完整的。钴(III)配合物交换配体需要几小时到几天（[[coordination-chemistry/inorganic-mechanisms]]），这正是维尔纳能够用这种方法数氯离子的原因。

::: example 用银离子数氯 {#ex-werner-silver}
将 $1.000\ \mathrm{g}$ 紫色盐 $\mathrm{CoCl_3\cdot5NH_3}$ 的样品溶于水，立即在室温下用过量硝酸银处理。若维尔纳的化学式正确，会析出多少克氯化银？使用摩尔质量 $M(\mathrm{CoCl_3\cdot5NH_3}) = 250.44\ \mathrm{g\,mol^{-1}}$ 与 $M(\mathrm{AgCl}) = 143.32\ \mathrm{g\,mol^{-1}}$。
::: solution
配合物的物质的量为 $1.000/250.44 = 3.993\times10^{-3}\ \mathrm{mol}$。在 $\mathrm{[CoCl(NH_3)_5]Cl_2}$ 中只有两个外界氯是自由的：
$$
\mathrm{[CoCl(NH_3)_5]^{2+}(aq) + 2\,Cl^-(aq) + 2\,Ag^+(aq) \rightarrow [CoCl(NH_3)_5]^{2+}(aq) + 2\,AgCl(s)}
$$
于是 $n(\mathrm{AgCl}) = 2 \times 3.993\times10^{-3} = 7.986\times10^{-3}\ \mathrm{mol}$，$m = 7.986\times10^{-3} \times 143.32 = 1.145\ \mathrm{g}$（四位有效数字，由样品质量决定）。若三个氯都是自由的，质量应为 $1.717\ \mathrm{g}$；若只有一个是自由的，则为 $0.572\ \mathrm{g}$。三种假设相差 50 % 以上，所以即便十九世纪的重量分析也能把它们区分开。这个实验必须迅速、在低温下进行。若放上几小时或加热，配位的氯会被水缓慢取代，析出更多 AgCl，这时实验测到的就是速率而不是结构了。
:::
:::

维尔纳的第二条证据是新鲜溶液的**摩尔电导**：一个化学式单元解离出的离子越多，电导越高。他与阿图罗·米奥拉蒂（Arturo Miolati）一起测定了一系列铂(IV)氨氯配合物，从 $\mathrm{PtCl_4\cdot6NH_3}$（五个离子，$\mathrm{[Pt(NH_3)_6]Cl_4}$）一直到 $\mathrm{PtCl_4\cdot2NH_3}$，后者几乎不导电，因为它是中性分子 $\mathrm{[PtCl_4(NH_3)_2]}$。接着他又越过氨为零的一点，测了 $\mathrm{K[PtCl_5(NH_3)]}$ 与 $\mathrm{K_2[PtCl_6]}$：配合物变成阴离子后，电导又升了上去。

## 配体：给体原子、齿数与螯合

::: definition 齿数、螯合物、桥联与两可配体 {#def-denticity}
配体的**齿数**指它键合到同一个金属上的给体原子数目：**单齿**（$\mathrm{NH_3}$、$\mathrm{Cl^-}$、$\mathrm{H_2O}$）、**双齿**（乙二胺、草酸根），一直到**六齿**（EDTA⁴⁻）。多齿配体通过两个以上原子键合到同一金属上时形成环，这样的配合物称为**螯合物**（希腊语 *chēlē*，蟹螯之意）。环内给体原子–金属–给体原子的夹角称为**齿合角**。**桥联**配体以词头 μ 表示，同时键合两个以上金属（$\mu$-$\mathrm{Cl}$、$\mu$-$\mathrm{OH}$、$\mu$-$\mathrm{O}$）。**两可配体**可以通过两种不同原子之一配位：硫氰酸根经 S（$-\mathrm{SCN}$，thiocyanato-κ*S*）或经 N（$-\mathrm{NCS}$，thiocyanato-κ*N*）；亚硝酸根经 N（硝基）或经 O（亚硝酸根 O 式）。
:::

下面这些配体是本课程的基本词汇。记住它们的化学式、电荷与缩写；后面的几乎每个例子都会用到。

| 配体 | 化学式 | 电荷 | 给体原子 | 齿数 | 配合物中的名称 |
|---|---|---|---|---|---|
| 水 | $\mathrm{H_2O}$ | 0 | O | 1 | 水（aqua） |
| 氨 | $\mathrm{NH_3}$ | 0 | N | 1 | 氨（ammine） |
| 一氧化碳 | CO | 0 | C | 1 | 羰基（carbonyl） |
| 氯离子 | $\mathrm{Cl^-}$ | $-1$ | Cl | 1 | 氯（chlorido） |
| 氰离子 | $\mathrm{CN^-}$ | $-1$ | C | 1 | 氰（cyanido） |
| 氢氧根 | $\mathrm{OH^-}$ | $-1$ | O | 1 | 羟基（hydroxido） |
| 乙烷-1,2-二胺（乙二胺，en） | $\mathrm{H_2NCH_2CH_2NH_2}$ | 0 | 2 个 N | 2 | 乙二胺（ethane-1,2-diamine） |
| 草酸根（ox） | $\mathrm{C_2O_4^{2-}}$ | $-2$ | 2 个 O | 2 | 草酸根（oxalato） |
| 乙酰丙酮根（acac） | $\mathrm{CH_3COCHCOCH_3^-}$ | $-1$ | 2 个 O | 2 | 乙酰丙酮根（acetylacetonato） |
| 2,2′-联吡啶（bpy） | $\mathrm{C_{10}H_8N_2}$ | 0 | 2 个 N | 2 | 2,2′-联吡啶（2,2′-bipyridine） |

螯合配体的结合远比等量的单齿配体强（**螯合效应**，主要是熵效应，在[[coordination-chemistry/complex-stability]]中定量讨论）。五元螯合环最常见，如 en、草酸根与 EDTA 所成的环；其齿合角接近 $85^\circ$，与八面体的 $90^\circ$ 相合。通过连续碳原子骨架配位的有机配体，如乙烯或环戊二烯基环，用**络合齿数（hapticity）** $\eta^n$ 描述（与金属成键的连续原子数目），属于[[organometallics-catalysis]]的内容。

::: definition 氧化态与 d 电子数 {#def-dn}
配合物中金属的**氧化态**是假想把每个配体连同其给予的电子对一起移走（各自成闭壳层）后金属所带的电荷：$\mathrm{Cl^-}$、$\mathrm{CN^-}$、$\mathrm{OH^-}$ 记 $-1$，$\mathrm{O^{2-}}$ 记 $-2$，$\mathrm{H_2O}$、$\mathrm{NH_3}$、CO、en 记 0。于是
$$
\text{M 的氧化态} = (\text{配合物的电荷}) - \sum (\text{配体的电荷}).
$$
$d^n$ 中的 **d 电子数** $n$ 等于金属的族数（3–12）减去氧化态。对过渡金属离子，$(n+1)s$ 电子总是先于 $(n)d$ 电子失去。例如 $\mathrm{Fe}$ 是 $[\mathrm{Ar}]3d^64s^2$，但 $\mathrm{Fe^{2+}}$ 是 $[\mathrm{Ar}]3d^6$，$\mathrm{Fe^{3+}}$ 是 $[\mathrm{Ar}]3d^5$。在配合物中，$(n+1)s$ 轨道位于 $d$ 轨道之上。
:::

::: example 氧化态与 d 电子数 {#ex-dn}
求下列配合物中金属的氧化态及其 $d^n$ 组态：(a) $\mathrm{K_3[Fe(CN)_6]}$，(b) $\mathrm{[Cr(en)_3]Cl_3}$，(c) $\mathrm{[PtCl_2(NH_3)_2]}$，(d) $\mathrm{Na_2[Ni(CN)_4]}$，(e) $\mathrm{K[MnO_4]}$，(f) $\mathrm{[Ni(CO)_4]}$。
::: solution
(a) 配阴离子是 $\mathrm{[Fe(CN)_6]^{3-}}$（外面有三个 $\mathrm{K^+}$）。由 $x + 6(-1) = -3$ 得 $x = +3$：铁(III)，第 8 族，$d^{8-3} = d^5$。(b) $\mathrm{[Cr(en)_3]^{3+}}$，en 中性：铬(III)，第 6 族，$d^3$。(c) 中性配合物，两个氯离子：铂(II)，第 10 族，$d^8$。(d) $\mathrm{[Ni(CN)_4]^{2-}}$：$x - 4 = -2$，镍(II)，$d^8$。(e) $\mathrm{[MnO_4]^-}$：$x - 8 = -1$，锰(VII)，$d^0$。(f) 镍(0)，$d^{10}$：中性金属配合物中，族数*就是* d 电子数。有两个组态会反复出现：Ni(II)、Pd(II)、Pt(II)与 Au(III)的 $d^8$ 配合物常为平面正方形；$d^{10}$ 与 $d^0$ 离子则完全没有晶体场稳定化能。这两条都会在[[coordination-chemistry/crystal-field-theory]]中给出理由。
:::
:::

## 配位数与几何构型

金属采取哪个配位数取决于三个朝不同方向拉扯的因素。第一是**尺寸**。大的金属离子（$\mathrm{La^{3+}}$、$\mathrm{U^{4+}}$、第二三行过渡金属）比小离子容得下更多给体原子；小的配体（$\mathrm{F^-}$、$\mathrm{H_2O}$）比庞大的配体（$\mathrm{PPh_3}$、$\mathrm{N(SiMe_3)_2^-}$）排得更密。第二是**电荷**。高电荷金属吸引很多配体，但许多阴离子配体彼此排斥。第三是**电子数**。$d^8$ 与 $d^{10}$ 组态各有特征偏好（分别为平面正方形与四面体或直线形），配体场理论对此作出解释。六是最最常见的配位数，本章其余部分默认的构型就是八面体配合物。

::: proposition 各配位数的构型（经验） {#prop-geometries}
对 d 区与 f 区金属的配合物，按每个 CN 下大致出现的频率排列，观测到的构型为：

- **CN 2**：直线形。多为 $d^{10}$ 离子：$\mathrm{[Ag(NH_3)_2]^+}$、$\mathrm{[CuCl_2]^-}$、$\mathrm{[Au(CN)_2]^-}$。
- **CN 3**：平面三角形，见于庞大配体或 $d^{10}$ 离子：$\mathrm{[HgI_3]^-}$、$\mathrm{[Fe\{N(SiMe_3)_2\}_3]}$。
- **CN 4**：四面体；$d^8$ 离子与强场配体则为平面正方形：四面体的 $\mathrm{[CoCl_4]^{2-}}$、$\mathrm{[ZnCl_4]^{2-}}$、$\mathrm{[Ni(CO)_4]}$、$\mathrm{[MnO_4]^-}$；平面正方形的 $\mathrm{[PtCl_4]^{2-}}$、$\mathrm{[Ni(CN)_4]^{2-}}$、$\mathrm{[AuCl_4]^-}$。
- **CN 5**：三角双锥（$\mathrm{[Fe(CO)_5]}$）或四方锥（$\mathrm{[VO(acac)_2]}$）。两者能量接近，容易互变。
- **CN 6**：压倒性地为八面体。三角棱柱罕见，见于硫醇盐类配体或固体中（$\mathrm{[Re(S_2C_2Ph_2)_3]}$、$\mathrm{[W(CH_3)_6]}$、$\mathrm{MoS_2}$ 的金属位点）。
- **CN 7**：五角双锥（$\mathrm{[UO_2F_5]^{3-}}$）、盖帽八面体或盖帽三角棱柱（$\mathrm{[NbF_7]^{2-}}$）。
- **CN 8**：四方反棱柱（$\mathrm{[TaF_8]^{3-}}$）或十二面体（某些盐中的 $\mathrm{[Mo(CN)_8]^{4-}}$）。
- **CN 9**：三盖帽三角棱柱（$\mathrm{[ReH_9]^{2-}}$、$\mathrm{[Nd(OH_2)_9]^{3+}}$）。
- **CN 10–12**：只有大离子配小螯合配体才可能，多为镧系与锕系：$\mathrm{[Ce(NO_3)_6]^{2-}}$ 有六个双齿硝酸根，配位数为十二。

对 $s$ 区、$d^0$、$d^5$（高自旋）与 $d^{10}$ 离子这些没有配体场偏好的离子，高 CN 构型接近于使球面上配体–配体排斥最小的构型（开普特模型，即[[bonding-structure/vsepr]]中 VSEPR 在配位化学里的对应物）。金属的 d 电子若*不是*成键电子对，就不像主族孤对电子那样占据"电子对区域"，所以 VSEPR 本身不适用于过渡金属配合物。
:::

::: example 五配位取哪种构型？τ₅ 参数 {#ex-tau5}
五配位结构常常介于两种理想构型之间。阿迪生（Addison）与里德伊克（Reedijk）（1984）定义
$$
\tau_5 = \frac{\beta - \alpha}{60^\circ},
$$
其中 $\beta \ge \alpha$ 为最大的两个给体原子–金属–给体原子夹角。理想四方锥在极限下 $\beta = \alpha = 180^\circ$，故 $\tau_5 = 0$。理想三角双锥有 $\beta = 180^\circ$（轴–轴）与 $\alpha = 120^\circ$（赤道–赤道），故 $\tau_5 = 1$。一个铜(II)配合物的两个最大角为 $176.4^\circ$ 与 $122.7^\circ$，另一个为 $165^\circ$ 与 $135^\circ$。试分别描述它们。
::: solution
第一个：$\tau_5 = (176.4 - 122.7)/60 = 53.7/60 = 0.895$。接近 1，所以这是一个略微畸变的三角双锥。第二个：$\tau_5 = (165 - 135)/60 = 0.500$，恰好居中。两个标签都不合适，正确的描述是"中间构型"。这个参数之所以有用，是因为五配位配合物确实构成一个连续谱。**贝里假旋转**——三角双锥的两个轴向配体相互弯近、同时两个赤道配体向外张开——经过四方锥的中点，并交换轴向与赤道位点。它的能垒常常只有几个 $\mathrm{kJ\,mol^{-1}}$。这正是 $\mathrm{[Fe(CO)_5]}$ 虽然有两类羰基，却在室温只显示一个 $^{13}\mathrm{C}$ NMR 信号的原因。
:::
:::

::: example 维尔纳的几何论证 {#ex-werner-geometry}
维尔纳没有 X 射线晶体学。他靠数异构体论证了八面体。对六配位配合物 $\mathrm{MA_4B_2}$，(a) 平面六边形、(b) 三角棱柱、(c) 八面体各预期多少异构体？$\mathrm{[CoCl_2(NH_3)_4]^+}$ 恰好存在两种形态这一事实说明了什么？还有什么不能说明？
::: solution
把两个 B 配体放上去，数不同的相互关系。(a) 六边形中一对顶点可以相邻（1,2）、隔一个（1,3）或相对（1,4）：**三个**异构体。(b) 三角棱柱中两个 B 可共用一条三角面的边、沿竖直边（矩形面的边）、或位于矩形面的对角线上：**三个**异构体。(c) 八面体中任意两个位置要么相邻（*cis*，$90^\circ$），要么相对（*trans*，$180^\circ$）：**两个**异构体。维尔纳找到了两个，并在 1907 年得到了紫罗兰色的 *cis* 型，即那个"缺失的"异构体。这是反对六边形与棱柱的证据，但否定性的证据不可能是结论性的：第三个异构体也许只是没被合成出来。决定性的检验来自手性。八面体的 $\mathrm{M(AA)_3}$ 或 *cis*-$\mathrm{M(AA)_2B_2}$ 是手性的，而它的平面六边形类似物不是。维尔纳 1911 年将 *cis*-$\mathrm{[CoCl(NH_3)(en)_2]^{2+}}$ 拆分成对映体，从此尘埃落定。
:::
:::

## 配合物的命名与书写

下面的规则是 IUPAC 的建议（《无机化学命名法》（*Nomenclature of Inorganic Chemistry*，2005 年，"红皮书"）。与旧教材最大的不同是：名称以 *-ide* 结尾的阴离子配体现在以 *-ido* 结尾（chlorido、cyanido、hydroxido、hydrido），旧教材写作 chloro、cyano、hydroxo。中文命名按中国化学会《无机化学命名原则》，与英文系统的主要差别在顺序与"合"字，下面在各处注明。

::: algorithm 配位化合物的命名 {#alg-naming}
1. **阳离子在前，阴离子在后**，与任何盐相同，无论配合物是阳离子、阴离子还是两者皆是。中文同样先读阳离子部分；若阴离子是配阴离子，则读作"某酸某"，如 六氯合铂(IV)酸钾。
2. **配合物内先写配体，按配体名称的字母顺序**排列，忽略倍数词头："ammine"（氨，a）排在"chlorido"（氯，c）之前，*tetra*aqua（四水）按 "a" 排序。中文则把**阴离子配体写在中性配体之前**，不同配体之间用"·"隔开，如 一氯·五氨。
3. **倍数词头**：简单配体用 di-、tri-、tetra-、penta-、hexa-（二、三、四、五、六）；名称中已含数字或较复杂的配体用 bis-、tris-、tetrakis-（双、三、四）并加括号：tris(ethane-1,2-diamine)（三(乙二胺)）、bis(2,2′-bipyridine)（双(2,2′-联吡啶)）。
4. **配体名称**：阴离子以 -o 结尾（chlorido、cyanido、oxido、oxalato、nitrito-κ*N*）；中性配体用分子本名，例外是 aqua（$\mathrm{H_2O}$，水）、ammine（$\mathrm{NH_3}$，氨）、carbonyl（CO，羰基）与 nitrosyl（NO，亚硝酰）。中文里阴离子配体直接用阴离子名（氯、氰、羟基、草酸根），中性配体用分子名（水、氨、羰基）。
5. **金属**：在阳离子或中性配合物中用普通元素名；在配阴离子中加词尾（英文 *-ate*，有拉丁词干者用拉丁词干：ferrate、cuprate、argentate、aurate、stannate、plumbate；但 cobaltate、nickelate、chromate、platinate、zincate）。中文一律在金属名后加"酸"字，如铁(III)酸根、钴(III)酸根。
6. **氧化态**以罗马数字加括号紧随金属名之后，(III)；或用整个配合物的电荷（Ewens–Bassett 数），(3−)。
7. **桥联配体**冠以 μ（μ-羟基），两可配体的给体原子用 κ 标明（thiocyanato-κ*N*）。立体描述符（*cis*、*trans*、*fac*、*mer*、Δ、Λ，顺式、反式、面式、经式）置于整个名称之前。

化学式中金属符号在最前，其后依次写配体，全部放在方括号内。IUPAC 按配体化学式的字母顺序排列，故写作 $\mathrm{[CoCl(NH_3)_5]^{2+}}$，但许多教材仍写 $\mathrm{[Co(NH_3)_5Cl]^{2+}}$，两种写法都被理解。
:::

::: example 由名称写化学式，由化学式写名称 {#ex-naming}
命名：(a) $\mathrm{[CoCl(NH_3)_5]Cl_2}$，(b) $\mathrm{K_3[Fe(CN)_6]}$，(c) $\mathrm{[CrCl_2(H_2O)_4]Cl}$，(d) $\mathrm{[Co(en)_3]Cl_3}$，(e) $\mathrm{[Pt(NH_3)_4][PtCl_4]}$；并写出化学式：(f) 氯化二氨合银(I)，(g) 三草酸合铁(III)酸钾，(h) 四羰基合镍(0)。
::: solution
(a) 二氯化一氯·五氨合钴(III)（英文 pentaamminechloridocobalt(III) chloride："ammine" 排在 "chlorido" 前，五只是词头，不影响顺序；中文则先氯后氨，外界写"二氯化"）。(b) 六氰合铁(III)酸钾，英文 potassium hexacyanidoferrate(III)，或六氰合铁(3−)酸根钾。传统名称铁氰化钾（potassium ferricyanide）在实验室里仍常用。(c) 氯化二氯·四水合铬(III)（英文 aqua（a）先于 chlorido（c））。(d) 三氯化三(乙二胺)合钴(III)。配体名称含数字，所以英文必须用带括号的 "tris"（中文用"三(乙二胺)"）。(e) 四氯合铂(II)酸四氨合铂(II)，即**马格努斯绿色盐**（Magnus's green salt）：两种离子都是配合物，阳离子部分在先。(f) $\mathrm{[Ag(NH_3)_2]Cl}$。(g) $\mathrm{K_3[Fe(C_2O_4)_3]}$：三个 $2-$ 草酸根与 $\mathrm{Fe^{3+}}$ 给出 $3-$ 阴离子与三个钾离子。这就是草酸铁(III)光量计与蓝晒法摄影中那个对光敏感的绿色盐。(h) $\mathrm{[Ni(CO)_4]}$。安全提示：四羰基合镍是挥发性极强的剧毒液体，只能在密闭体系中操作。它的生成与分解正是蒙德法（Mond process）精炼镍的基础（[[coordination-chemistry/d-block-chemistry]]）。
:::
:::

::: warning 电荷、氧化态与配位数是三个不同的数 {#warn-numbers}
对 $\mathrm{[Co(en)_3]^{3+}}$：配合物的*电荷*是 $+3$，钴的*氧化态*是 $+3$，*配体数目*是 3，*配位数*是 6。四个数，其中两个相等纯属巧合。在 $\mathrm{[Fe(CN)_6]^{4-}}$ 中电荷是 $-4$，铁却是 $+2$。在 $\mathrm{[Ni(CO)_4]}$ 中配合物是电中性的，镍是零价。在 $\mathrm{[Cu(H_2O)_6]^{2+}}$ 中配位数是 6，尽管理由姜-泰勒效应（[[coordination-chemistry/crystal-field-theory]]），其中两个水比另外四个远得多。永远先找电荷（由抗衡阳离子），再找氧化态（由配体电荷），再找配位数（由齿数）。不要把一个数拿去顶替另一个。
:::

## 异构现象

化学式相同而原子排布不同的两种化合物称为**异构体**。配位化合物表现出现代有机分子的所有异构类型，还有几种只有盐才有的类型。

::: definition 结构异构与立体异构 {#def-isomers}
**结构（构造）异构体**的区别在于哪些原子与哪些原子成键。配合物有五种：

- **电离异构体**：配体与抗衡阳离子互换：$\mathrm{[CoBr(NH_3)_5]SO_4}$（紫罗兰色；遇 $\mathrm{Ba^{2+}}$ 生成 $\mathrm{BaSO_4}$）与 $\mathrm{[Co(SO_4)(NH_3)_5]Br}$（红色；遇 $\mathrm{Ag^+}$ 生成 AgBr）；
- **水合（溶剂合）异构体**：配位水与晶格水互换：$\mathrm{[Cr(H_2O)_6]Cl_3}$（紫罗兰色）、$\mathrm{[CrCl(H_2O)_5]Cl_2\cdot H_2O}$（蓝绿色）与 $\mathrm{[CrCl_2(H_2O)_4]Cl\cdot2H_2O}$（暗绿色）；
- **键合异构体**：区别在两可配体的给体原子：$\mathrm{[Co(NO_2)(NH_3)_5]^{2+}}$，硝基（nitrito-κ*N*，黄色）与 $\mathrm{[Co(ONO)(NH_3)_5]^{2+}}$，亚硝酸根 O 式（nitrito-κ*O*，红色）；
- **配位异构体**：配体在配阳离子与配阴离子之间的分配不同：$\mathrm{[Co(NH_3)_6][Cr(CN)_6]}$ 与 $\mathrm{[Cr(NH_3)_6][Co(CN)_6]}$；
- **配体异构体**：所含配体本身互为异构体，例如丙烷-1,2-二胺与丙烷-1,3-二胺。

**立体异构体**的成键相同而空间排布不同。**几何异构体**（非对映异构体）的区别在配体的相对位置：*cis*/*trans*（顺式/反式，相邻或相对）；对 $\mathrm{MA_3B_3}$ 还有 *fac*（面式，三个同种配体同处一个面）与 *mer*（经式，三个同种配体绕一条子午线）。**光学异构体**（对映异构体）是不可重合的镜像。对三(螯合)与双(螯合)八面体，沿三重轴俯视，构型记为 **Δ**（右手螺旋）或 **Λ**（左手螺旋）。
:::

凡是能靠整个配合物的旋转联系起来的排布都算"同一个"。因此数异构体是形状的旋转群上的问题。对平面正方形配合物，这个群有八个元素：恒等操作，绕穿过金属且垂直于平面的轴旋转 $90^\circ$、$180^\circ$ 与 $270^\circ$，以及绕面内四个轴作 $180^\circ$ 翻转。作用在四个角位上，它就是正方形的二面体群，你可以在下面的表中研究它的结构。

::: example 数立体异构体 {#ex-stereo-count}
下列各配合物各有多少立体异构体（对映体分开计数）？(a) 平面正方形 $\mathrm{[PtCl_2(NH_3)_2]}$，(b) 八面体 $\mathrm{[CoCl_3(NH_3)_3]}$，(c) $\mathrm{[Co(en)_3]^{3+}}$，(d) $\mathrm{[CoCl_2(en)_2]^+}$，(e) $\mathrm{[MA_2B_2C_2]}$，(f) 四面体 $\mathrm{[ZnABCD]}$？
::: solution
(a) **两种**：顺式与反式。顺式异构体就是抗癌药顺铂，反式异构体没有活性（[[coordination-chemistry/bioinorganic]]）。两者都不手性：分子平面就是镜面。(b) **两种**：面式（三个 Cl 互为顺式，同在一个面上，$C_{3v}$）与经式（两个 Cl 互为反式，$C_{2v}$）。(c) **两种**：Δ 与 Λ。三个螯合环构成螺旋桨，而螺旋桨有左右手性之分。(d) **三种**：反式（不手性，有一个镜面同时过两个氯与金属）与顺式，后者是手性的，以 Δ 与 Λ 两种形式存在。维尔纳用的就是这类化合物的顺式体。(e) **六种**：五个几何异构体。其中一个三对配体全部互为反式；三个各有一对反式、另外两对顺式（以 A、B 或 C 为反式对）；最后一种三对全部顺式，这一种是手性的，以两个对映体存在：$5 + 1 = 6$。（可用穷举核对：把配体放到已编号的顶点上有 $6!/(2!\,2!\,2!) = 90$ 种方法，八面体的 24 个旋转恰好给出六个轨道。）(f) **两种**：四个不同配体的四面体金属正是手性的，如同一个手性碳。这类配合物很少能被拆分，因为多数四面体配合物交换配体极快。
:::
:::

::: example 一个不含碳的手性配合物 {#ex-hexol}
1914 年维尔纳拆分了阳离子 $\mathrm{[Co\{(\mu\text{-}OH)_2Co(NH_3)_4\}_3]^{6+}}$（"hexol"），它完全由钴、氨、水与氢氧根制成。解释它为什么是手性的，以及这个结果为何重要。
::: solution
中心钴是八面体的，与六个桥联氢氧根成键，排成三对 $\mathrm{(\mu\text{-}OH)_2}$。每一对连同外层的 $\mathrm{Co(NH_3)_4}$ 单元构成一个四元环，对中心钴起着双齿"螯合"配体的作用。中心单元因此是一个 $\mathrm{M(AA)_3}$ 螺旋桨，与 $\mathrm{[Co(en)_3]^{3+}}$ 一样以 Δ 或 Λ 形式呈手性。1914 年仍有一些化学家坚持旋光是碳化合物的属性，声称维尔纳拆分成功的 en 配合物的旋光性来自乙二胺配体的碳原子——而那些碳本身并不是手性中心。一个完全无机的阳离子手性异构体终结了这场争论。它表明手性是三维排布的属性，与由哪些元素构成无关。
:::
:::

::: quiz
下列配合物哪些能以一对对映体存在？选出所有正确的选项。
- [ ] 平面正方形 *cis*-$\mathrm{[PtCl_2(NH_3)_2]}$
- [x] *cis*-$\mathrm{[CoCl_2(en)_2]^+}$
- [ ] *trans*-$\mathrm{[CoCl_2(en)_2]^+}$
- [x] $\mathrm{[Cr(ox)_3]^{3-}}$
- [ ] *fac*-$\mathrm{[CoCl_3(NH_3)_3]}$
::: solution
配合物只有在没有任何非真对称元素（没有镜面、没有反演中心、没有 $S_n$ 轴）时才是手性的。双(螯合)顺式八面体与三(螯合)八面体都是没有镜面的螺旋桨，所以 *cis*-$\mathrm{[CoCl_2(en)_2]^+}$ 与 $\mathrm{[Cr(ox)_3]^{3-}}$ 是手性的（Δ 与 Λ）。反式异构体有一个含 Co 与两个 Cl 的镜面。平面配合物总把自身分子平面当作镜面。面式异构体有三个镜面（$C_{3v}$）。
:::
:::

::: warning 几何异构体不是共振式也不是构象体 {#warn-isomers}
顺式与反式 $\mathrm{[CoCl_2(NH_3)_4]^+}$ 是不同的化合物，颜色、偶极矩、溶解度各不相同，可以分别装进两个瓶子。它们的互变只能通过断裂一条 Co–Cl 键进行，对钴(III)而言这需要几个小时。对其他金属**并非**如此。$\mathrm{Ni^{2+}}$、$\mathrm{Cu^{2+}}$ 或 $\mathrm{Zn^{2+}}$ 这类活性离子的配合物每秒交换配体上百万次，它们的"异构体"在溶液中一经生成便立即达到平衡。数异构体告诉你有多少排布是*可能的*；它们能否被*分离出来*则是动力学问题，哪种金属惰性、哪种活性，[[coordination-chemistry/inorganic-mechanisms]]给出规则。
:::

## 后续内容

本章的概念是课程其余部分的语法。[[coordination-chemistry/crystal-field-theory]]解释为什么八面体占统治地位、为什么 $d^8$ 离子转向平面正方形、为什么 $\mathrm{[Cu(H_2O)_6]^{2+}}$ 是畸变的。[[coordination-chemistry/ligand-field-mo]]用按各几何构型的对称性（[[quantum-chemistry/molecular-symmetry]]的点群）构造的分子轨道处理金属–配体键。颜色与磁性——当年区分维尔纳异构体的可观测性质——在[[coordination-chemistry/spectra-of-complexes]]与[[coordination-chemistry/magnetism]]中解释。螯合效应与配合物的稳定性在[[coordination-chemistry/complex-stability]]中定量化；氯化银检验的速率问题——惰性的钴(III)对活性的镍(II)——在[[coordination-chemistry/inorganic-mechanisms]]中解答。配位反应用于分析化学（EDTA 滴定、掩蔽、比色试剂）见[[analytical-chemistry]]；蛋白质的金属位点——以氨基酸侧链为配体的配位化合物——见[[coordination-chemistry/bioinorganic]]。

::: history
配位化合物早在人们理解它们之前很久就已经被制得了。普鲁士蓝（铁氰化物颜料）十八世纪初在柏林制成；B. M. 塔塞特（B. M. Tassaert）1798 年观察到氨与钴生成化合物。整个十九世纪，钴与铂的氨合物按颜色分类（luteo 黄、purpureo 紫、praseo 绿、violeo 紫罗兰），并用布隆斯特兰（Christian Wilhelm Blomstrand）与约尔根森（Sophus Mads Jørgensen）的"链式理论"解释——他们模仿碳，设想氨连成 $\mathrm{Co{-}NH_3{-}NH_3{-}\ldots}$ 的链。约尔根森的实验工作极为出色，后来决定这场争论的许多化合物最早就出自他的实验室。维尔纳当时 26 岁、在苏黎世，1893 年在《无机化学杂志》（*Zeitschrift für anorganische Chemie*）上发表了配位理论。此后二十年，他与学生制备出理论预言的异构体：1907 年的紫罗兰色 *cis*-$\mathrm{[CoCl_2(NH_3)_4]^+}$，1911 年拆分的手性钴配合物（与维克多·金（Victor King）合作），以及 1914 年不含碳的 hexol——而诺贝尔化学奖的前一年刚刚颁给他，那是第一次授予无机化学的诺贝尔化学奖。直接证实八面体的 X 射线结构测定直到 1920 年代才出现。
:::

::: summary
- 配合物是路易斯酸（金属）通过给体原子与路易斯碱配体结合的产物。内界写在方括号内；配位数数的是给体原子，不是配体。
- 由抗衡阳离子定电荷，减去配体电荷得氧化态，d 电子数为族数减氧化态（$s$ 电子先失）。
- 多齿配体形成螯合环；桥联配体标 μ；两可配体可经两个原子之一配位（κ 标记法）。
- CN 6（八面体）占主导；CN 4 为四面体，$d^8$ 离子配强场配体时为平面正方形；CN 5 构成以 $\tau_5$ 度量的连续谱。大离子可达 CN 8–12。
- IUPAC 命名中配体按字母顺序列于金属之前，阴离子用 -ido/-o 词尾，配阴离子加 -ate 词尾，氧化态用罗马数字。中文则先阴离子配体、后中性配体，配阴离子读作"某酸某"。
- 结构异构（电离、水合、键合、配位、配体异构）的区别在连接方式；立体异构（*cis*/*trans*、*fac*/*mer*、Δ/Λ）的区别在排布，数立体异构就是数旋转群的轨道。
- 只有取代惰性的金属才能分离异构体；计数给出可能性，动力学决定瓶子里留下什么。
:::

::: exercise 氯化银重量分析 {level=1 check="0.307"}

::: exercise 哪一种异构？ {level=2}
判断每一对化合物之间属于哪类异构：(a) $\mathrm{[Co(NH_3)_5(NO_2)]Cl_2}$（黄色）与 $\mathrm{[Co(NH_3)_5(ONO)]Cl_2}$（红色）；(b) $\mathrm{[Cr(NH_3)_6][Co(CN)_6]}$ 与 $\mathrm{[Co(NH_3)_6][Cr(CN)_6]}$；(c) $\mathrm{[PtCl_2(NH_3)_4]Br_2}$ 与 $\mathrm{[PtBr_2(NH_3)_4]Cl_2}$；(d) $\mathrm{[CoCl_2(en)_2]Cl}$ 的两种互不成镜像的形态。提出一个能把 (c) 中两种盐区分开的实验。
::: solution
(a) 键合异构（亚硝酸根经 N 与经 O）。红色 O 式在放置中缓慢转变为黄色 N 式，这是最早观察到的异构化反应之一。(b) 配位异构。(c) 电离异构。加硝酸银：第一种盐生成淡黄色 AgBr，第二种生成白色 AgCl。也可以用少量氯水与有机溶剂检验游离的溴离子。(d) 几何（顺式与反式）异构体，它们是非对映异构体。顺式异构体本身又是一对对映体。
:::
:::

::: exercise 五配位连续谱 {level=2 check="0.25"}
一个镍(II)配合物最大的两个给体原子–Ni–给体原子角为 $171.0^\circ$ 与 $156.0^\circ$。计算 $\tau_5$ 并描述其构型。（输入 $\tau_5$。）
::: solution
$\tau_5 = (171.0 - 156.0)/60 = 0.25$。更接近 0 而不是 1，所以该配合物最好描述为畸变的四方锥，处在沿贝里路径通向三角双锥约四分之一的位置。
:::

::: exercise 电导与化学式 {level=2}
三个实验化学式为 $\mathrm{PtCl_4\cdot nNH_3}$ 的化合物，其摩尔电导率（单位 $\mathrm{S\,cm^2\,mol^{-1}}$）分别约为 520、230 与 0。设 Pt(IV)总是六配位，为每个化合物指定 $n$ 并写出配位化学式。
::: solution
Pt(IV)电荷平衡需要四个氯离子，而内界容纳六个给体原子。电导约 520 对应五个离子：$\mathrm{[Pt(NH_3)_6]Cl_4}$，$n = 6$。约 230 对应三个离子：$\mathrm{[PtCl_2(NH_3)_4]Cl_2}$，$n = 4$。零对应中性分子：$\mathrm{[PtCl_4(NH_3)_2]}$，$n = 2$。$n$ 每减 2，就有一个氯离子进入内界顶替被移走的氨，保持六个给体原子不变，与维尔纳表中的规律完全一致。
:::

::: exercise 混合配合物的全部异构体 {level=2 check="2"}
画出或描述 $\mathrm{[CoCl_2(NH_3)_2(en)]^+}$ 的全部立体异构体，并指出哪些是手性的。（输入手性异构体的数目，对映体分开计数。）
::: hint
en 配体必须跨占两个顺式位置。把它固定在赤道平面内，再放两个氯离子。
:::
::: solution
en 占据两个相邻的赤道位置后，剩下四个位置是另外两个赤道位（各与一个 en 氮互为反式）与两个轴向位。(i) 两个 Cl 都在轴向（互为反式），两个 $\mathrm{NH_3}$ 都在赤道：一个镜面同时包含 Co、en 与两个 $\mathrm{NH_3}$，不手性。(ii) 两个 $\mathrm{NH_3}$ 都在轴向，两个 Cl 都在赤道：同理不手性。(iii) 一个 Cl 与一个 $\mathrm{NH_3}$ 在轴向，另一个 Cl 与 $\mathrm{NH_3}$ 在赤道：没有镜面，这一异构体以两个对映体存在。所以共有四个立体异构体、三个几何异构体，其中**两个**是手性的（一对对映体）。
:::
:::

::: exercise 用伯恩赛特定理清点异构体 {#exr-burnside level=3 check="2"}
伯恩赛特定理说：不同排布的数目等于对群中所有对称操作 $g$ 下保持不变的排布数取平均。利用平面正方形配合物的八个旋转（上方凯莱表中的群）数出 $\mathrm{MA_2B_2}$ 的异构体数目。然后不加计算地解释为什么 $\mathrm{MABCD}$ 给出三种。（输入 $\mathrm{MA_2B_2}$ 的异构体数目。）
::: hint
把四个角依次编号 1–4。恒等操作保持全部 $\binom{4}{2} = 6$ 种排布不变。一个旋转要保持某种排布不变，它置换位置的每个轮换中的位置必须放同一种配体。
:::
::: solution
八个操作作用在角上的轮换结构：恒等（四个 1-轮换）固定 6 种。$90^\circ$ 与 $270^\circ$ 旋转（一个 4-轮换）要求四个配体全同，各固定 0 种。$180^\circ$ 旋转的轮换为 (1 3)(2 4)，要求 A 放在 1、3 或 2、4：固定 2 种。两个过对角顶点的翻转，如 (1)(3)(2 4)，要求 2 与 4 相同：若它们都是 A，则 1 与 3 都是 B，反之亦然，各固定 2 种。两个过对边中点的翻转，如 (1 2)(3 4)，要求 1 = 2 且 3 = 4：各固定 2 种。固定数总和：$6 + 0 + 0 + 2 + 2 + 2 + 2 + 2 = 16$，$16/8 = 2$ 个异构体（顺式与反式）。对 MABCD，任何非恒等操作都不固定任何排布（四个配体各不相同），所以数目是 $4!/8 = 3$：即选哪个配体与 A 互为反式的三种不同选法。由于平面本身是镜面，这些异构体没有一个具有手性。
:::
:::

::: exercise 排除三角棱柱 {level=3}
对一个螯合配体跨占一条棱的 $\mathrm{M(AA)_3}$ 配合物，比较八面体与三角棱柱各自预期的立体异构体数目；三角棱柱中每个螯合环跨占三条竖直棱（矩形面的棱）之一。解释维尔纳 1911 年对手性钴(III)螯合物的拆分如何区分了这两种构型，以及 1965 年发现的三角棱柱型 $\mathrm{[Re(S_2C_2Ph_2)_3]}$ 为什么与他并不矛盾。
::: solution
**八面体**：三个螯合环绕 $C_3$ 轴构成螺旋桨，对称性为 $D_3$，没有非真元素，所以有两个对映体（Δ、Λ）。**三角棱柱**中三个螯合环在三条竖直棱上：分子具有 $D_{3h}$ 对称性，包含把每个螯合环从中间切过的水平镜面，所以不手性，只有一个异构体。因此，在三(螯合)与双(螯合)钴(III)配合物中观察到旋光性——而且因为 Co(III)不会快速外消旋而得以保持——就排除了这些化合物的棱柱构型。维尔纳的论证针对的是钴(III)氨合物与 en 配合物。铼的二硫烯配合物是另一回事：二硫烯配体是平面、π 离域的、经硫成键的，配体间 S···S 的成键作用稳定了棱柱。构型是每个化合物自己的性质，由它的电子与配体决定。八面体是压倒性的常态，但不是自然定律。
:::
