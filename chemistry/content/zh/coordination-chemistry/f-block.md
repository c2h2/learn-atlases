1960 年代电视屏幕的红、荧光灯管的绿、白色 LED 的光、风力发电机与电动汽车电机里的磁体、欧元纸币上的防伪标记，以及 MRI 的对比剂，全都依赖**镧系元素**——从镧到镥（Lu）的十五种元素。一个半世纪以来，它们一直是分析化学家的梦魇。其三价离子彼此相似到分离相邻元素需要上千次分步结晶，而整个系列究竟包含多少种元素，直到 1913 年亨利·莫塞莱（Henry Moseley）的 X 射线光谱确定了原子序数才告解决。**锕系元素**从锕到铹（Lr），是核能的元素；全部具有放射性，铀以后的元素都是人造的。

两个系列都在填充 $f$ 亚层，而每个系列的化学都出自其 $f$ 轨道的一个性质：它们从核伸出多远。镧系的 $4f$ 轨道埋藏在已满的 $5s$ 与 $5p$ 壳层之内，几乎不参与成键，所以镧系表现为一整列硬的、几乎全同的 $\mathrm{Ln^{3+}}$ 离子，其 $f$ 电子保持着自由离子那种尖锐的光谱与大磁矩。较早的 $5f$ 轨道伸得更远，于是铀、镎（Np）与钚（Pu）显示出过渡金属那样多变的氧化态与共价成键，到后面的锕系才重新变得像镧系。本章建立这两幅图像，借助[[coordination-chemistry/spectra-of-complexes]]的项符号与[[coordination-chemistry/magnetism]]的磁性。

## 4f 轨道与镧系收缩

::: definition f 区与它的径向问题 {#def-f-block}
**镧系元素**（Ln）是 La–Lu（$Z = 57$–$71$），其 $\mathrm{Ln^{3+}}$ 离子的组态为 $[\mathrm{Xe}]4f^n$，$n$ 从 $0$（La）到 $14$（Lu）；它们与钪、钇一起构成**稀土元素**。**锕系元素**（An）是 Ac–Lr（$Z = 89$–$103$），填充 $5f$。七个 $f$ 轨道（$l = 3$）各具有三个角节点。$4f$ 的径向函数把极大值摆在已满的 $5s$、$5p$ 轨道极大值的*内侧*，所以 $4f$ 电子被更外层八个电子屏蔽在配体视线之外；它们与配体的相互作用很弱（晶体场分裂约 $100\ \mathrm{cm^{-1}}$，而 $3d$ 离子为 $10^4\ \mathrm{cm^{-1}}$）。$5f$ 轨道相对 $6s$、$6p$ 壳层伸展得更远，尤其对早锕系而言参与成键。
:::

正因为 $4f$ 电子是内层电子，它们彼此对核的屏蔽很差。每往下一个镧系元素就增加一个质子和一个 $4f$ 电子，外层电子感受到的有效核电荷上升，离子随之缩小：这就是**镧系收缩**。

## 镧系离子的化学

### 氧化态

+3 态在整个系列中占绝对主导。它的稳定不是由 $4f$ 组态（从 $f^0$ 到 $f^{14}$ 变化）解释的，而是由能量账解释的：移去三个外层电子（$5d^16s^2$ 或 $4f\,6s^2$）付得起，第四电离能（从 $4f$ 壳层）很大，而一个小体积 $3+$ 离子的晶格能与水合能很大。当别的氧化态恰好达到空的、半满的或全满的 $4f$ 壳层时也会出现：

- **铈(IV)**，$4f^0$：$E^\circ(\mathrm{Ce^{4+}/Ce^{3+}}) \approx +1.72\ \mathrm{V}$（随酸不同的条件电位为 $+1.44$ 至 $+1.70\ \mathrm{V}$），强一电子氧化剂，用于铈量滴定与有机合成（如硫酸高铈铵 $\mathrm{(NH_4)_2[Ce(NO_3)_6]}$）；
- **铕（Eu）(II)**，$4f^7$：$E^\circ(\mathrm{Eu^{3+}/Eu^{2+}}) = -0.35\ \mathrm{V}$，稳定到可以在水中存在一段时间；
- **镱（Yb）(II)**，$4f^{14}$，与**钐(II)**，$4f^6$：$E^\circ = -1.05$ 与 $-1.55\ \mathrm{V}$，强还原剂；四氢呋喃（THF）中的碘化钐(II)（Kagan 试剂）在有机合成中应用广泛；
- 铽（Tb）(IV) 与镨(IV) 仅存在于氧化物与氟化物中。

### Ln³⁺ 的配位化学

$\mathrm{Ln^{3+}}$ 离子是大体积、高电荷、无配体场偏好的硬路易斯酸（[[coordination-chemistry/complex-stability#prop-hsab]]）。其成键以离子性为主，所以配合物的配位数高而多变，由离子尺寸与配体的位阻要求决定：早期水合离子 $\mathrm{[Ln(H_2O)_9]^{3+}}$ 为九配位（三帽三棱柱），后期的为八配位，与硝酸根这类小的螯合配体可高达十二配位。它们偏爱氧给体（水、羧酸根、磷酸根、$\beta$-二酮酸根）与氟离子；胺与硫给体在水中结合很弱，因为水无法被它们取代。配体交换极快（水的 $k_\mathrm{ex}$ 约 $10^8$–$10^9\ \mathrm{s^{-1}}$），几何异构体很少能分离出来。

::: example 镧系元素的分离 {#ex-separation}
相邻两个镧系元素的半径差约 1 pm（0.1 %），它们与螯合配体的 $\log K$ 通常相差 0.1–0.3。(a) 若相邻元素的 $\log K$ 相差 0.20，溶剂萃取流程的一个平衡级给出多大的分离系数 $\alpha$？(b) 要把 50:50 的混合物富集到某一组分 99.9 % 的纯度，需要多少个理想级？(c) 为什么使用络合洗脱剂的离子交换色谱中，洗脱顺序从 Lu 排到 La？
::: solution
(a) 一级的分离系数是分配比之比，而对由络合控制的萃取，它就是生成常数之比：$\alpha = 10^{0.20} = 1.58$。(b) 经过 $N$ 级后，两种元素之比从 1 变为 $\alpha^N$。要达到 99.9 % 纯度，比值须达 $999$：$N = \log 999/\log 1.58 = 3.00/0.20 = 15$ 个理想级（实际上要多出好几倍，因为真实级并不理想，而且收率必须高）。工业镧系分离厂把数百个混合-澄清级串在一起。(c) 较重、较小的离子（靠 Lu 一边）与洗脱剂（如柠檬酸根或 $\alpha$-羟基异丁酸根）形成的配合物更强，于是它们在流动相中停留更久、在树脂上停留更少，先被洗脱。弗兰克·斯佩丁（Frank Spedding）1940 年代正是用这一原理做离子交换分离，第一次制出了公斤量级的纯镧系元素。
:::
:::

## 光谱与磁性：自由离子行为

由于配体场与自旋-轨道耦合（对 $4f$ 电子约 $10^3\ \mathrm{cm^{-1}}$）相比极其微小，镧系离子的行为近乎自由离子。相关的状态是拉塞尔-桑德斯项，被自旋-轨道耦合分裂为 $^{2S+1}L_J$ 能级，而配体场只是把每个能级稍稍再劈裂一点。能量层次的次序与 $d$ 区正好相反——那里配体场占主导，自旋-轨道耦合只是小修正。

::: proposition Ln³⁺ 离子的基能级（洪特规则） {#prop-hund-j}
$4f^n$ 离子的基能级由下述方法确定：(1) 使 $S$ 最大；(2) 在该 $S$ 下使 $L$ 最大；(3) $n < 7$（不足半满）时取 $J = |L - S|$，$n > 7$ 时取 $J = L + S$。对 $f^7$，$L = 0$，$J = S = \tfrac72$。基项内的激发能级能量由朗德间隔规则 $E(J) - E(J - 1) = \lambda J$ 给出，典型间隔为 $10^3$–$10^4\ \mathrm{cm^{-1}}$；只有 $\mathrm{Sm^{3+}}$ 与 $\mathrm{Eu^{3+}}$ 的第一激发能级仅高出几百 $\mathrm{cm^{-1}}$。
:::

::: proof
规则 (1) 与 (2) 就是[[coordination-chemistry/spectra-of-complexes#ex-ground-terms]]中的规则，应用于七个 $f$ 轨道（$m_l = 3, \dots, -3$）：先从最大的 $m_l$ 开始单占且自旋平行地填充。规则 (3)：项内的自旋-轨道耦合形如 $\lambda\mathbf{L}\cdot\mathbf{S}$，而 $\mathbf{L}\cdot\mathbf{S} = \tfrac12[J(J+1) - L(L+1) - S(S+1)]$，所以 $\lambda > 0$ 时能量随 $J$ 上升，$\lambda < 0$ 时随 $J$ 下降。单电子的自旋-轨道常数为正，不足半满的壳层的项常数 $\lambda = \zeta/2S$ 为正，故 $J$ 最小的最低。超过半满的壳层中，空穴表现得像正电荷，$\lambda$ 的符号反转，故 $J$ 最大的最低。间隔规则出自同一表达式：$E(J) - E(J - 1) = \tfrac{\lambda}{2}[J(J+1) - (J-1)J] = \lambda J$。
:::

例如 $\mathrm{Nd^{3+}}$，$4f^3$：三个电子在 $m_l = 3, 2, 1$，$S = \tfrac32$，$L = 6$（I），$J = L - S = \tfrac92$：$^4I_{9/2}$。$\mathrm{Dy^{3+}}$，$4f^9$：七个自旋平行的电子加两个配对的电子在 $m_l = 3, 2$，所以 $S = \tfrac52$，$L = 5$（H），$J = L + S = \tfrac{15}{2}$：$^6H_{15/2}$。

### 磁矩

当 $J$ 是好量子数且只有基能级被占据时，磁矩由 $J$ 与**朗德（Landé）$g$ 因子**决定，而不由自旋单独决定。

::: proposition 镧系离子的磁矩 {#prop-lande}
对处于量子数为 $S$、$L$、$J$ 的能级且只有该能级被占据的离子，
$$
\mu_\mathrm{eff} = g_J\sqrt{J(J+1)}\ \mu_\mathrm{B}, \qquad g_J = 1 + \frac{J(J+1) + S(S+1) - L(L+1)}{2J(J+1)},
$$ {#eq-lande}
取 $g_e = 2$。[[coordination-chemistry/magnetism#prop-curie]]的居里定律仍成立，只须以 $g_J^2J(J+1)$ 代替 $g^2S(S+1)$。
:::

::: proof
磁矩算符为 $\hat{\boldsymbol\mu} = -\mu_\mathrm{B}(\hat{\mathbf L} + 2\hat{\mathbf S})/\hbar$：轨道角动量以 $g = 1$ 贡献，自旋以 $g_e = 2$ 贡献。由于 $\mathbf{L}$ 与 $\mathbf{S}$ 绕其合矢量 $\mathbf{J}$ 快速进动，平均下来只有磁矩在 $\mathbf{J}$ 上的投影存活（矢量模型，或形式上写为固定 $J$ 的能级内矢量算符的投影定理）：
$$
\langle\hat{\boldsymbol\mu}\rangle = -\mu_\mathrm{B}\,\frac{(\mathbf{L} + 2\mathbf{S})\cdot\mathbf{J}}{J(J+1)}\,\mathbf{J} = -g_J\mu_\mathrm{B}\mathbf{J},
$$
其中 $\hbar = 1$。于是 $(\mathbf{L} + 2\mathbf{S})\cdot\mathbf{J} = \mathbf{J}^2 + \mathbf{S}\cdot\mathbf{J}$，而由 $\mathbf{L} = \mathbf{J} - \mathbf{S}$、$\mathbf{L}^2 = \mathbf{J}^2 + \mathbf{S}^2 - 2\mathbf{S}\cdot\mathbf{J}$ 得 $\mathbf{S}\cdot\mathbf{J} = \tfrac12[J(J+1) + S(S+1) - L(L+1)]$。除以 $J(J+1)$ 即得前面陈述的 $g_J$。基能级的塞曼能级于是为 $E = g_J\mu_\mathrm{B}BM_J$，而[[coordination-chemistry/magnetism#prop-curie]]的推导把 $S \rightarrow J$、$g \rightarrow g_J$ 照搬一遍即成立，给出 $\mu_\mathrm{eff}^2 = g_J^2J(J+1)$。检验：$L = 0$（Gd³⁺）时 $J = S$、$g_J = 2$，回到仅自旋结果。
:::

### f–f 光谱与发光

$4f^n$ 组态内的跃迁是拉波特禁阻的（所有 $f$ 状态宇称相同），而且由于 $4f$ 轨道几乎不与配体轨道混合，它们获得的光强极小：摩尔吸收系数通常低于 $10\ \mathrm{dm^3\,mol^{-1}\,cm^{-1}}$。因为 $4f$ 电子不参与成键，激发几乎不改变平衡几何，振动展宽很小，所以吸收带**尖锐**（溶液中宽度只有几纳米），而且几乎不依赖配体。这些尖锐而有特征的谱线，正是掺钕玻璃用来校准分光光度计、每种镧系都能用光谱鉴定的原因。少数**超灵敏**跃迁，例如 $\mathrm{Nd^{3+}}$ 在 $575\ \mathrm{nm}$ 附近的一条，强度确实随配体剧烈变化。

激发态也能发光。$\mathrm{Eu^{3+}}$ 发红光，主要来自 $^5D_0$ 能级到 $^7F_2$ 能级、波长约 $612\ \mathrm{nm}$；$\mathrm{Tb^{3+}}$ 发绿光，从 $^5D_4$ 到 $^7F_5$、约 $545\ \mathrm{nm}$。由于直接吸收如此微弱，实用的镧系发光材料都利用**天线效应**：有机配体或基质晶格强烈吸收光，经系间窜越与能量转移把能量交给镧系，镧系再以长寿命（毫秒量级，有机荧光染料是纳秒量级）发出尖锐的谱线。水等 O–H 振子会通过振动能量转移猝灭发光，所以好的发光体用螯合配体把离子保护起来。应用包括荧光灯的红色荧光粉 $\mathrm{Y_2O_3:Eu^{3+}}$、把 LED 蓝光变成白光的黄色荧光粉 $\mathrm{Y_3Al_5O_{12}:Ce^{3+}}$（Ce:YAG）、时间分辨发光生物检测，以及 $1064\ \mathrm{nm}$ 的 Nd:YAG 激光器。

::: warning 镧系配合物不同于 d 区配合物 {#warn-lanthanides}
把 d 区的习惯带进 f 区化学是人之常情，而这些习惯几乎无一灵验。不存在有化学意义的晶体场稳定化（分裂只有约 $100\ \mathrm{cm^{-1}}$），所以没有偏好几何；没有自旋状态可供选择；没有化学上要紧的姜-泰勒畸变；也没有 18 电子规则。颜色很淡，且不随配体大变。磁矩遵从 $J$，而不是仅自旋公式。配合物是活性的，所以异构体无法分离；成键以离子性为主，所以配位数由尺寸与位阻决定。而且"稀土"并不稀：铈在地壳中的丰度与铜相差无几。困难不在于获得它们，而在于把它们彼此分开。
:::

## 锕系元素

早期的锕系像过渡金属，晚期的像镧系。差别在 $5f$ 轨道：从钍到钚，它们与 $6d$、$7s$ 能量相近，且伸展得足以与配体轨道重叠，因此可以移走许多电子，共价成键也相当显著。随核电荷沿系列上升，$5f$ 轨道收缩并降能，从镅（Am）开始 +3 态像镧系那样占绝对主导。

| 元素 | Th | Pa | U | Np | Pu | Am | Cm |
|---|---|---|---|---|---|---|---|
| 常见氧化态 | IV | V | IV, **VI** | IV, V, VI | III, **IV**, V, VI | **III** | III |
| 已知最高 | IV | V | VI | VII | VII（VIII 有争议） | VI（VII 有报道） | IV |

**铀**是最有名的锕系元素。它在含氧水中的最稳定状态是铀(VI)，以**铀酰**离子 $\mathrm{[UO_2]^{2+}}$ 存在：一个线性的 $\mathrm{O{=}U{=}O}$ 单元，U–O 键很短（约 $176\ \mathrm{pm}$），另有四到六个配体结合在赤道平面上。它的黄绿色发光曾让十九世纪拥有"铀玻璃"。线性与 U–O 键的强度（形式上是三键，一根 σ 加两根 π，使用 $5f$ 与 $6d$ 轨道）是 $5f$ 参与成键的直接标志。铀(IV) 是绿色的，形成 $\mathrm{UO_2}$——多数核反应堆的陶瓷燃料——以及 $\mathrm{UF_4}$；六氟化铀 $\mathrm{UF_6}$ 是在 $56.5\ ^\circ\mathrm{C}$ 升华的挥发性固体，用于同位素富集，因为它是单一元素与单一同位素氟形成的分子化合物。**铀茂** $\mathrm{[U(\eta^8\text{-}C_8H_8)_2]}$ 由 Andrew Streitwieser 与 Ulrich Müller-Westerhoff 于 1968 年制成，其设计目的就是检验 $5f$ 的共价性：环辛四烯双阴离子提供与 $5f$ 对称性匹配的轨道来重叠。

**钚**最复杂：其 III、IV、V、VI 态的还原电势都在 $1\ \mathrm{V}$ 附近、彼此只差零点几伏，所以酸性溶液中多种氧化态能共存于平衡，由歧化与归中反应互相联系。乏燃料后处理的 PUREX 流程利用的正是不同氧化态萃取性的差别：铀(VI) 与钚(IV) 的硝酸盐从硝酸被萃取进煤油中的磷酸三丁酯，大多数裂变产物留在原相；再把钚还原为难萃取的钚(III)，使钚与铀分离。

::: example 为什么钚如此复杂 {#ex-plutonium}
$1\ \mathrm{mol\,dm^{-3}}$ 高氯酸中的近似条件电位为 $\mathrm{PuO_2^{2+}/PuO_2^+}$ $+0.92\ \mathrm{V}$、$\mathrm{PuO_2^+/Pu^{4+}}$ $+1.17\ \mathrm{V}$、$\mathrm{Pu^{4+}/Pu^{3+}}$ $+0.98\ \mathrm{V}$。(a) 钚(V) 相对于歧化稳定吗？(b) 求 $2\,\mathrm{PuO_2^+ + 4\,H^+ \rightleftharpoons Pu^{4+} + PuO_2^{2+} + 2\,H_2O}$ 的 $\log K$。(c) 为什么钚(IV) 在稀酸中也会轻微歧化？
::: solution
(a) 用[[coordination-chemistry/d-block-chemistry#prop-disproportionation]]，拉蒂默序列为 $\mathrm{PuO_2^{2+}}\ (0.92)\ \mathrm{PuO_2^+}\ (1.17)\ \mathrm{Pu^{4+}}$：右端电势（1.17）超过左端（0.92），所以 $\mathrm{PuO_2^+}$ 在 $1\ \mathrm{mol\,dm^{-3}}$ 酸中歧化。(b) $E^\circ_\mathrm{cell} = 1.17 - 0.92 = 0.25\ \mathrm{V}$，$\log K = 0.25/0.05916 = 4.2$。由于四个质子出现在左边，酸度下降时平衡退回钚(V) 一边，所以在某些接近中性的天然水中，钚(V) 确实是主要存在状态。(c) 相关反应是 $3\,\mathrm{Pu^{4+}} + 2\,\mathrm{H_2O} \rightleftharpoons 2\,\mathrm{Pu^{3+}} + \mathrm{PuO_2^{2+}} + 4\,\mathrm{H^+}$。双电子电对 $\mathrm{PuO_2^{2+}/Pu^{4+}}$ 的平均电势为 $(0.92 + 1.17)/2 = 1.045\ \mathrm{V}$（相加的是自由能而不是电势；对两个一电子步骤这就是平均值）。于是对 $n = 2$，$E^\circ_\mathrm{cell} = 0.98 - 1.045 = -0.065\ \mathrm{V}$，$\log K = 2(-0.065)/0.05916 = -2.2$。单位活度下平衡偏在左方，但偏得很少，而且因为释放四个质子，酸度下降时它移向右方：稀酸中钚(IV) 部分歧化为钚(III) 与钚(VI)。因此四种氧化态可以同时共存，各有各的化学，钚的环境行为因此难以预测。
:::

::: quiz
水溶液中三价镧系离子有哪些特征性质？
- [x] 尖锐、微弱、几乎不依赖配体的吸收带。
- [ ] 对八面体几何的强烈偏好。
- [x] 八或九的配位数。
- [x] 由 $J$ 而不是仅由自旋决定的磁矩。
- [ ] 缓慢、惰性的配体交换。
::: solution
被屏蔽的 $4f$ 壳层给出尖锐、对配体不敏感的 $f$–$f$ 带、由 $g_J\sqrt{J(J+1)}$ 给出的自由离子磁矩，并且没有配体场偏好，所以几何由尺寸决定（水合离子配位数 8–9）。水的交换极快，离子是活性的。
:::

### 安全

所有锕系都有放射性，其化学只能在持有许可、防护措施与核素相匹配的实验室中进行。超铀元素，尤其钚，主要危害是内照射：放 $\alpha$ 的核素一经吸入或食入就很危险，而钚会在骨与肝中积累。天然铀与贫铀放射性很弱，作为重金属的化学毒性（主要伤肾）常常是更要紧的危害。镧系化合物为低到中等毒性，但游离的钆（Gd）(III) 有毒，所以只能以极稳定、惰性的螯合物形式给药（[[coordination-chemistry/bioinorganic]]）。

## 后续内容

镧系的大磁矩与各向异性使其成为现代磁体（$\mathrm{Nd_2Fe_{14}B}$、$\mathrm{SmCo_5}$）与单分子磁体的核心，其尖锐发光则成就了荧光粉与激光器；这两个题目在[[materials-chemistry/magnetic-optical]]中继续。钆（Gd）(III) 的 MRI 对比剂把 $^8S_{7/2}$ 的磁性与[[coordination-chemistry/complex-stability]]、[[coordination-chemistry/inorganic-mechanisms]]的热力学和动力学稳定性结合在一起。核化学，包括铀与钍的衰变系及裂变产物，在[[general-chemistry-2/nuclear-chemistry]]；放射性核素在环境中的归宿在[[environmental-chemistry/pollutants-fate]]。

::: history
约翰·加多林（Johan Gadolin）1794 年从瑞典伊特比（Ytterby）发现的一种矿物中分离出"钇土"，接下来的一个世纪就耗在发现它和贝采利乌斯（Jöns Jacob Berzelius）的"铈土"原来是多种氧化物的混合物上；卡尔·古斯塔夫·莫桑德（Carl Gustaf Mosander）在 1840 年代分离出镧、"镨钕土（didymium）"、铒与铽，卡尔·奥尔·冯·韦尔斯巴赫（Carl Auer von Welsbach）1885 年把镨钕土拆成镨与钕。亨利·莫塞莱 1913 年的 X 射线光谱表明，从镧到镥之间必须恰好有十五种元素，其中 61 号缺位；钷（Pm）直到 1945 年才在铀的裂变产物中被最终确认。维克托·戈尔德施密特 1925 年为镧系收缩命名。铀由马丁·海因里希·克拉普罗特（Martin Heinrich Klaproth）1789 年命名，亨利·贝可勒尔（Henri Becquerel）1896 年发现了它的放射性。格伦·西博格（Glenn Seaborg）与合作者 1940–41 年制出钚，并于 1944 年提出锕系概念，把这些新元素作为镧系之下的第二个 $f$ 系列放置；西博格与埃德温·麦克米伦（Edwin McMillan）共获 1951 年诺贝尔化学奖。弗兰克·斯佩丁 1940 年代在艾奥瓦州立大学的镧系离子交换分离，第一次提供了可供使用的成量纯稀土。
:::

::: summary
- $4f$ 轨道位于已满的 $5s$、$5p$ 壳层之内，镧系离子与配体作用很弱；其化学是一批硬的、活性的、以离子性为主的 $\mathrm{Ln^{3+}}$ 离子的化学，配位数 8–9。
- $4f$ 电子屏蔽差导致镧系收缩（$\mathrm{La^{3+}}$ 103 到 $\mathrm{Lu^{3+}}$ 86 pm），使相邻镧系难以分离，也使 Zr 与 Hf 成为双胞胎。
- +3 占主导；Ce(IV)（$f^0$）是强氧化剂，Eu(II)（$f^7$）、Yb(II)（$f^{14}$）与 Sm(II) 是还原剂。
- 自旋-轨道耦合超过配体场：基能级 $^{2S+1}L_J$ 由洪特规则定，磁矩服从 $\mu_\mathrm{eff} = g_J\sqrt{J(J+1)}$ 而非仅自旋公式（例外：低能级热占据的 Sm³⁺、Eu³⁺）。
- $f$–$f$ 带弱、尖锐、不依赖配体；由天线配体敏化的 Eu³⁺（红）与 Tb³⁺（绿）发光用于照明、显示与生物检测。
- 早期锕系（Th–Pu）的 $5f$ 轨道可用、氧化态多、有共价成键（线性铀酰、铀茂）；从 Am 起像镧系。钚的多种氧化态在溶液中共存。
- 一切锕系都有放射性；其化学需要持证设施与相应的包容防护。
:::

## 习题

::: exercise 钕(III) 的基能级 {level=1 check="4.5"}
推出 $\mathrm{Nd^{3+}}$ 的基能级并给出 $J$ 值。（输入 $J$。）
::: solution
$4f^3$：三个自旋平行的电子在 $m_l = 3, 2, 1$；$S = \tfrac32$，$L = 6$（I）。壳层不足半满，故 $J = L - S = \tfrac92$：$^4I_{9/2}$。
:::

::: exercise 钆(III) 的磁矩 {level=1 check="7.94"}
由[[#eq-lande]]计算 $\mathrm{Gd^{3+}}$ 的 $\mu_\mathrm{eff}$。（$\mu_\mathrm{eff}$ 以 $\mu_\mathrm{B}$ 输入，保留三位有效数字。）
::: solution
$4f^7$，$^8S_{7/2}$：$L = 0$，$J = S = \tfrac72$，$g_J = 2$，$\mu = 2\sqrt{\tfrac72 \cdot \tfrac92} = 2\sqrt{15.75} = 7.94\ \mu_\mathrm{B}$。
:::

::: exercise 不寻常的氧化态 {level=1}
预测哪些镧系最可能显示 (a) 稳定的 +4 态与 (b) 水溶液中的 +2 态，并解释。
::: solution
(a) 铈：$\mathrm{Ce^{4+}}$ 是 $4f^0$（氙的组态），而铈的第四电离能在整个系列中最低。铽（Tb）(IV)（$4f^7$）与镨(IV) 存在于固体中，但氧化性太强，在水中不行。(b) 铕：$\mathrm{Eu^{2+}}$ 是半满的 $4f^7$，$E^\circ(\mathrm{Eu^{3+}/Eu^{2+}}) = -0.35\ \mathrm{V}$，在水中可暂存。镱（Yb）(II)（$4f^{14}$）与钐(II) 是强得多的还原剂（$-1.05$ 与 $-1.55\ \mathrm{V}$），会还原水，但在非水溶剂中很有用。
:::
:::

::: exercise 镝(III) 的磁矩 {level=2 check="10.65"}
推出 $\mathrm{Dy^{3+}}$ 的基能级，计算 $g_J$ 与 $\mu_\mathrm{eff}$，并与仅自旋值比较。（$\mu_\mathrm{eff}$ 以 $\mu_\mathrm{B}$ 输入，保留四位有效数字。）
::: solution
$4f^9$：自旋向上的七个电子占 $m_l = 3$ 到 $-3$（总 $m_l = 0$），自旋向下的两个在 $m_l = 3, 2$。$S = (7 - 2)/2 = \tfrac52$，$L = 5$（H），超过半满，$J = L + S = \tfrac{15}{2}$：$^6H_{15/2}$。$g_J = 1 + [\tfrac{15}{2}\cdot\tfrac{17}{2} + \tfrac52\cdot\tfrac72 - 30]/(2 \times 63.75) = 1 + (63.75 + 8.75 - 30)/127.5 = 1 + 0.3333 = 1.3333$。$\mu = 1.3333\sqrt{63.75} = 1.3333 \times 7.984 = 10.65\ \mu_\mathrm{B}$，而五个未成对电子的仅自旋值为 $\sqrt{35} = 5.92$。
:::
:::

::: exercise 铕(III) 并非抗磁性 {level=2}
$\mathrm{Eu^{3+}}$ 的基能级为 $^7F_0$，[[#eq-lande]]对其预言 $\mu_\mathrm{eff} = 0$，然而铕（Eu）(III) 化合物在室温有 $\mu_\mathrm{eff} \approx 3.4\ \mu_\mathrm{B}$。解释之，并预测冷到 $4\ \mathrm{K}$ 时 $\mu_\mathrm{eff}$ 如何变化。
::: solution
$4f^6$ 的 $^7F$ 项被自旋-轨道耦合分裂为 $J = 0, 1, \dots, 6$ 的能级，间隔规则 $E(J) - E(J - 1) = \lambda J$ 给出 $\lambda \approx 350\ \mathrm{cm^{-1}}$。$^7F_1$ 只比 $^7F_0$ 高约 $350\ \mathrm{cm^{-1}}$，与室温的 $k_\mathrm{B}T = 207\ \mathrm{cm^{-1}}$ 相当，$^7F_2$ 高约 $1050\ \mathrm{cm^{-1}}$。这些磁性能级被热占据，而且 $^7F_1$ 混入 $^7F_0$ 的场致混合还贡献一个与温度无关的项。降温时激发能级腾空，$\mu_\mathrm{eff}$ 降到只剩下温度无关项的小值；$4\ \mathrm{K}$ 时实测磁矩远低于 $1\ \mu_\mathrm{B}$。单能级的居里定律在此并不适用。
:::
:::

::: exercise 一条镧系发光线 {level=2 check="16340"}
$\mathrm{Eu^{3+}}$ 在许多配合物中最强的发光在 $612\ \mathrm{nm}$。给出所发光的波数，并解释为什么这个波长从一种铕配合物到另一种几乎不变。（波数以 $\mathrm{cm^{-1}}$ 输入，保留四位有效数字。）
::: solution
$\tilde\nu = 1/(612\times10^{-7}\ \mathrm{cm}) = 16\,340\ \mathrm{cm^{-1}}$。跃迁 $^5D_0 \rightarrow {}^7F_2$ 发生在 $4f^6$ 组态内部，这些电子被 $5s^25p^6$ 壳层屏蔽；配体场只能把能级移动与分裂几十到几百 $\mathrm{cm^{-1}}$，所以谱线至多移动几纳米。它的*强度*对环境超灵敏（铕位点缺少反演中心时最强），这正是铕发光光谱被用来探测位点对称性的原因。
:::

::: exercise 需要多少萃取级？ {level=3 check="23"}
相邻两个镧系的每理想萃取级分离系数为 $\alpha = 1.35$。(a) 要把较易萃取元素之比从 1:1 提到 999:1，需要多少个理想级？(b) 若进料中两者已按 1:9 存在，需要多少级？(c) 为什么镧系分离厂要建成连续逆流级联？((a) 的级数向上取整后输入。）
::: solution
(a) $\alpha^N \ge 999$：$N \ge \log 999/\log 1.35 = 2.9996/0.13033 = 23.0$，即 **23** 级。(b) 从 $1/9$ 到 $999/1$ 是 $8991$ 倍：$N \ge \log 8991/\log 1.35 = 3.954/0.1303 = 30.3$，即 31 级。(c) 逆流级联中，水相与有机相方向相反地流过一列混合-澄清器，每一级都收到已经部分富集的进料；级联能同时达到高纯度与高回收率，并可连续运行。$\alpha$ 只略大于 1 时，分离完整的稀土混合物需要数百到上千级，这正是稀土生产成本与环境负担的主要原因。
:::

::: exercise 铀酰与 5f 轨道的参与 {level=3}
(a) 铀酰离子 $\mathrm{[UO_2]^{2+}}$ 是线性的，而 $d^0$ 过渡金属的双氧单元，如钼（Mo）(VI) 配合物的 $\mathrm{[MoO_2]^{2+}}$ 核心，几乎总是 *cis*（弯曲）的。就可用的轨道提出解释。(b) 为什么铀酰的发光不像镧系那样对配体极不敏感，反而强烈依赖配体？(c) 为什么晚锕系（Am 以后）的行为更像镧系？
::: solution
(a) 与两个氧成 $\pi$ 键的 $d^0$ 金属偏好 *cis* 排布，因为 *cis* 几何中两个氧可以对不同的 $d$ 轨道成 $\pi$ 键，而不必争用同一根轨道（而偏好 *trans* 的 $p$ 轨道能量太高）。铀既有 $6d$ 又有 $5f$ 可用，而 $5f$ 组里有沿单一轴强相互作用的轨道（$\sigma$ 用的 $f_{z^3}$ 与 $\pi$ 用的 $f_{xz^2}$、$f_{yz^2}$），它们与 $6d$ 结合，有利于线性的 *trans* 排布，对每个氧形成形式上的 $\mathrm{U{\equiv}O}$ 三键。线性因此是 $5f$ 轨道参与成键的证据。(b) 铀酰发光是配体到金属的电荷转移跃迁（氧的非键轨道到空的 $5f$），涉及的正是成键轨道本身；赤道配体的改变会直接扰动这些轨道，不像被屏蔽的镧系 $4f$–$4f$ 跃迁。(c) 沿锕系，$5f$ 轨道像镧系的 $4f$ 那样收缩、降能，所以从镅（Am）起它们像芯电子，+3 以上的电离代价高昂，化学变成 $\mathrm{An^{3+}}$ 离子的化学，其尺寸与镧系十分接近。
:::
