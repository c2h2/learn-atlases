第 3 到 12 族的三十种元素，囊括了技术史各个时代的金属：史前就已知道的铜与金；文明的金属铁；轻而耐腐蚀、用于飞机与人造关节的钛；熔点居一切金属之首的钨；存在于每一辆汽车尾气净化器中的铂、钯与铑；以及充电电池里的钴与镍。它们的化合物是颜料（钛白、铬黄、普鲁士蓝、钴蓝）、催化剂（制硫酸用的五氧化二钒、合成氨用的铁、有机合成用的铑与钯）与氧化剂（高锰酸盐、重铬酸盐、四氧化锇）。一个化合物一个化合物地学这套化学是无望的。幸运的是，这些元素遵循几条趋势：每一周期内的横向趋势、每一族的纵向趋势，以及第一系列与两个较重系列之间的差异。

本章先摆出这些趋势，再逐族应用。它借助[[main-group/periodic-trends]]的电子排布与半径、[[main-group/inorganic-redox]]的氧化还原工具（拉蒂默（Latimer）图与弗罗斯特（Frost）图），以及本课程前面各章的配体场思想，来解释为什么锰(II)与铁(III)如此稳定、为什么铜(I)在水中歧化、为什么较重的金属偏爱较高的氧化态、为什么锆与铪化学上几乎完全相同，以及金属如何能彼此形成四重键。

## 什么才算过渡元素

::: definition 过渡元素与 d 区元素 {#def-transition}
**d 区**由第 3–12 族的元素组成。IUPAC 把**过渡元素**定义为原子的 $d$ 亚层未填满、或能形成 $d$ 亚层未填满的阳离子的元素。按这一定义，第 12 族元素（Zn、Cd、Hg）在原子中和在一切常见化合物里都是 $d^{10}$，因而是 d 区元素但不是过渡元素。第 3 族（Sc、Y 以及 La 或 Lu 之一）在其唯一常见氧化态 +3 中是 $d^0$，但其原子有一个 $d$ 电子，所以也计入。
:::

原子的基态电子排布大多是 $[\text{稀有气体}]\,(n-1)d^x\,ns^2$，例外出现在半满或全满的 $d$ 层获得的交换能足以把一个 $s$ 电子拉进去之处：铬与铜是 $3d^54s^1$ 与 $3d^{10}4s^1$；第二系的例外更多（Nb $4d^45s^1$、Mo $4d^55s^1$、Ru $4d^75s^1$、Rh $4d^85s^1$、Pd $4d^{10}5s^0$、Ag $4d^{10}5s^1$），因为 $4d$ 与 $5s$ 能级靠得更近。这些反常远没有看上去那么重要：在化合物中 $(n+1)s$ 能级位于 $(n)d$ 之上，一切离子都是 $d^n$（[[coordination-chemistry/coordination-compounds#def-dn]]），化学性质取决于 $n$，而不是自由原子的排布。

## d 区的横向与纵向趋势

### 半径与镧系收缩

在每一系列内，金属半径从第 3 族下降到大约第 8 族，然后趋于平缓或向第 11–12 族略升，因为加入的电子对新增核电荷的屏蔽越来越不力，而且 $e_g$ 型反键轨道开始填充。沿族向下，半径从第一系到第二系如预期般增大，但从第二系到第三系几乎不变：锆与铪的金属半径为 $160$ 与 $159\ \mathrm{pm}$，$\mathrm{Zr^{4+}}$ 与 $\mathrm{Hf^{4+}}$ 的六配位离子半径为 $72$ 与 $71\ \mathrm{pm}$（申农）。原因是**镧系收缩**：镧与铪之间隔着十四个镧系元素，其 $4f$ 电子屏蔽很差，于是 $5d$ 与 $6s$ 电子感受到的有效核电荷约增加十四单位的未屏蔽电荷，恰好抵消了本应出现的尺寸增大。相对论效应（在最重元素中收缩 $6s$ 轨道）又添上一笔（[[coordination-chemistry/f-block]]）。

::: example 锆与铪 {#ex-zr-hf}
锆合金用于包裹核燃料，因为锆吸收的中子很少（热中子俘获截面 $0.18\ \mathrm{barn}$），而铪吸收得很多（$\approx 100\ \mathrm{barn}$），用于控制棒。天然锆矿含铪 1–3 %。(a) 为什么铪难以除去？(b) 分离是怎样实现的？(c) 若包壳材料的截面不得超过 $0.20\ \mathrm{barn}$，这隐含了怎样的铪含量上限？
::: solution
(a) 镧系收缩使 $\mathrm{Zr^{4+}}$ 与 $\mathrm{Hf^{4+}}$ 的尺寸几乎相同（72 与 71 pm）、电荷相同、$d^0$ 组态也相同，所以它们形成同种化合物，溶解度、挥发度与稳定常数几乎一样；它们在每一种锆矿中总是共生。中子是唯一能把它们看得截然不同的常用探针，因为中子俘获是核性质。(b) 工业分离使用反复的溶剂萃取（例如把硫氰酸配合物萃取进甲基异丁基甲酮）或四氯化物的萃取蒸馏，两者都是把稳定常数或挥发度的微小差别在多级中放大，与分馏完全同理。(c) 加权平均：对铪的原子分数 $w$，$0.18(1 - w) + 100w \le 0.20$，故 $w \le 0.02/99.8 = 2.0\times10^{-4}$，即按原子计约 200 ppm。核级锆要求铪低于 100 ppm，比矿石降低了一百倍。
:::
:::

### 氧化态

::: proposition 氧化态趋势（经验规律） {#prop-oxidation-trends}
1. 在第一系列中，直到锰为止最高氧化态等于族数（Sc III、Ti IV、V V、Cr VI、Mn VII），此后下降（Fe VI 罕见；Co、Ni、Cu 很少超过 III），而最常见氧化态变为 +2。
2. 沿每一族向下，较高氧化态变得更稳定、较低者更不稳定：铬(VI) 是强氧化剂，钼(VI) 与钨(VI) 却不是；锰(VII) 是强氧化剂，铼(VII) 却稳定；铁止步于 VI，而钌与锇在 $\mathrm{RuO_4}$ 与 $\mathrm{OsO_4}$ 中达到 VIII。反过来，$\mathrm{Fe^{2+}}$、$\mathrm{Co^{2+}}$、$\mathrm{Ni^{2+}}$ 是常见的简单水合离子，而它们的较重同族元素几乎不形成简单 $\mathrm{M^{2+}}$ 离子。
3. 最高氧化态只与电负性最强的配体 $\mathrm{O^{2-}}$ 与 $\mathrm{F^-}$ 共存，通常以含氧酸根或氧化物形式出现；最低氧化态（0、负值）需要 CO 这类 $\pi$ 受体配体（[[coordination-chemistry/ligand-field-mo#prop-18e]]）。
:::

第一条趋势跟电离能走：横跨一个系列，有效核电荷升高，把所有价电子移走越来越难，所以锰之后达到族氧化态的代价超过了它换回的晶格能或水合能。第二条跟轨道的尺寸与能量走：$4d$ 与 $5d$ 轨道更大，且相对配体轨道能量更高，它们与氧、氟形成更强的共价键，而且（对高电荷求和的）电离能的增长赶不上所获键能的增长。水溶液中同样的趋势体现在弗罗斯特图上：从 $\mathrm{CrO_4^{2-}}$ 到 $\mathrm{Cr^{3+}}$ 的陡峭下坡，在钼与钨那里没有对应物——它们的氧化物与含氧酸根就是热力学汇。

::: warning 不要从自由原子的排布读化学 {#warn-configurations}
铬的 $3d^54s^1$ 基态并不意味着铬化合物有什么"半满壳层"，铜的 $3d^{10}4s^1$ 也不意味着铜(I) 是铜的天然状态。在化合物中一切 d 区离子都是 $d^n$，稳定性由电离能与成键（晶格、水合、配体场）能量之间的竞争决定。铜(II) $d^9$ 在水和大多数固体中是稳定氧化态；铜(I) $d^{10}$ 在水中歧化（[[#ex-cu-disproportionation]]），只有与软配体结合或在难溶化合物中才稳定。自由原子的排布由原子光谱检验，而不是由其化合物的化学检验。
:::

::: proposition 由拉蒂默图判断歧化 {#prop-disproportionation}
对某元素的三种氧化态，$\mathrm{A}\ \xrightarrow{E^\circ_\mathrm{L}}\ \mathrm{B}\ \xrightarrow{E^\circ_\mathrm{R}}\ \mathrm{C}$（按氧化态从高到低排列，如拉蒂默图所示），中间物种 B 相对于歧化为 A 与 C 不稳定的条件是
$$
E^\circ_\mathrm{R} > E^\circ_\mathrm{L},
$$
而对一电子步骤，$298\ \mathrm{K}$ 下平衡常数满足 $\log K = (E^\circ_\mathrm{R} - E^\circ_\mathrm{L})/0.05916$。
:::

::: proof
歧化 $2\,\mathrm{B} \rightarrow \mathrm{A} + \mathrm{C}$（一电子步骤）是还原 $\mathrm{B} + e^- \rightarrow \mathrm{C}$（电势 $E^\circ_\mathrm{R}$）与氧化 $\mathrm{B} \rightarrow \mathrm{A} + e^-$（电势为 $E^\circ_\mathrm{L}$ 的电对的逆反应）之和。其电池电势为 $E^\circ_\mathrm{cell} = E^\circ_\mathrm{R} - E^\circ_\mathrm{L}$，$\Delta_\mathrm{r}G^\circ = -FE^\circ_\mathrm{cell}$。标准条件下当 $E^\circ_\mathrm{cell} > 0$ 时反应自发。由 $\Delta_\mathrm{r}G^\circ = -RT\ln K$ 得 $\log K = FE^\circ_\mathrm{cell}/(RT\ln10) = E^\circ_\mathrm{cell}/0.05916\ \mathrm{V}$。对电子数不同的步骤，必须先把电势换算成自由能（$\Delta G^\circ = -nFE^\circ$）再相加，这正是弗罗斯特图在几何上做的事：B 位于连接 A 与 C 的直线之上时 B 歧化（[[main-group/inorganic-redox]]）。
:::

::: example 水中的铜(I) {#ex-cu-disproportionation}
酸性溶液中铜的拉蒂默图为 $\mathrm{Cu^{2+}}\ (+0.153)\ \mathrm{Cu^+}\ (+0.52)\ \mathrm{Cu}$。(a) 证明 $\mathrm{Cu^+(aq)}$ 会歧化，并求 $2\,\mathrm{Cu^+} \rightleftharpoons \mathrm{Cu^{2+}} + \mathrm{Cu}$ 的 $K$。(b) 当 $[\mathrm{Cu^{2+}}] = 0.10\ \mathrm{mol\,dm^{-3}}$ 时，与铜金属接触达平衡的溶液中 $[\mathrm{Cu^+}]/[\mathrm{Cu^{2+}}]$ 是多少？(c) 铜(I) 怎样才能被稳定？
::: solution
(a) $E^\circ_\mathrm{R} = 0.52 > E^\circ_\mathrm{L} = 0.153\ \mathrm{V}$，所以由[[#prop-disproportionation]]铜(I) 歧化：$E^\circ_\mathrm{cell} = 0.367\ \mathrm{V}$，$\log K = 0.367/0.05916 = 6.20$，$K = 1.6\times10^6$。(b) $K = [\mathrm{Cu^{2+}}]/[\mathrm{Cu^+}]^2$，所以 $[\mathrm{Cu^+}] = \sqrt{0.10/1.6\times10^6} = 2.5\times10^{-4}\ \mathrm{mol\,dm^{-3}}$，比值为 $2.5\times10^{-3}$。(c) 铜(I) 是软的 $d^{10}$ 离子。比铜(II) 结合得更牢的配体会降低 $\mathrm{Cu^+/Cu}$ 电对的电势、抬高 $\mathrm{Cu^{2+}/Cu^+}$ 的电势（[[coordination-chemistry/complex-stability#prop-redox-shift]]）。软配体如 $\mathrm{Cl^-}$（浓氯化物中的 $\mathrm{[CuCl_2]^-}$）、$\mathrm{CN^-}$、硫醇盐、膦与乙腈都能做到这一点，沉淀出难溶盐（CuCl、CuI、$\mathrm{Cu_2O}$）也可以。四面体或线性配位对 $d^{10}$ 没有 CFSE 的惩罚，这也利于铜(I)，因为铜(II) 会在四方环境中获得 CFSE 与姜-泰勒稳定化。
:::
:::

## 第一过渡系概览

下面各节把趋势逐族应用。重点是在化学其余部分反复出现的化合物。

**钛（第 4 族）。** 稳定状态是钛(IV)，$d^0$。二氧化钛（$\mathrm{TiO_2}$，金红石与锐钛矿）是最重要的白色颜料，折射率极高，由氯化物法生产（$\mathrm{TiO_2}$ 矿 + C + $\mathrm{Cl_2} \rightarrow \mathrm{TiCl_4}$，精馏，然后在氧气中燃烧）。$\mathrm{TiCl_4}$ 是分子液体，在潮湿空气中发烟（它水解为 $\mathrm{TiO_2}$ 与 HCl，须在通风橱中用干燥仪器操作）；用镁还原（克洛尔（Kroll）法）得钛金属。钛(III) $d^1$ 呈紫色，是中强还原剂；$\mathrm{TiCl_3}$ 是齐格勒-纳塔催化剂的基础（[[organometallics-catalysis/metathesis-polymerisation]]）。

**钒（第 5 族）。** 从 II 到 V 的每个氧化态在水中都可得到，且各有醒目的颜色：$\mathrm{[V(H_2O)_6]^{2+}}$ 紫、$\mathrm{[V(H_2O)_6]^{3+}}$ 绿、氧钒离子 $\mathrm{[VO(H_2O)_5]^{2+}}$ 蓝、$\mathrm{[VO_2(H_2O)_4]^+}$ 黄。用锌还原酸化钒酸盐溶液会依次经过全部四种颜色，是经典的课堂演示。氧钒离子含一根短的 $\mathrm{V{\equiv}O}$ 键（约 $160\ \mathrm{pm}$），氧向钒强烈地作 $\pi$ 给予。五氧化二钒 $\mathrm{V_2O_5}$ 在接触法制硫酸中通过在 V(V) 与 V(IV) 之间循环来催化 $\mathrm{SO_2}$ 氧化为 $\mathrm{SO_3}$。

**铬（第 6 族）。** 铬(III) $d^3$ 是水中的热力学汇，动力学惰性（[[coordination-chemistry/inorganic-mechanisms]]），随配体不同呈紫色或绿色。铬(VI) 在碱中以黄色铬酸根 $\mathrm{CrO_4^{2-}}$ 存在，在酸中以橙色重铬酸根 $\mathrm{Cr_2O_7^{2-}}$ 存在，两者由缩合平衡 $2\,\mathrm{HCrO_4^-} \rightleftharpoons \mathrm{Cr_2O_7^{2-} + H_2O}$ 联系，$\mathrm{p}K_\mathrm{a}(\mathrm{HCrO_4^-}) \approx 6.5$。重铬酸盐在酸中是强氧化剂（$E^\circ = +1.33\ \mathrm{V}$，还原为 $\mathrm{Cr^{3+}}$）。铬(VI) 化合物致癌且有毒（GHS06、GHS08），因为铬酸根经硫酸盐转运系统进入细胞，在胞内被还原为有反应活性的铬(V)、(IV)、(III) 物种而损伤 DNA；因此重铬酸盐氧化在教学与工业中已大体被弃用。铬(II) $d^4$ 是强还原剂（$-0.41\ \mathrm{V}$）且极其活性，这正是陶布（Taube）用它研究内界电子转移的原因。乙酸铬(II) 的四重键在下文讨论。

**锰（第 7 族）。** 锰的氧化态从 $-3$ 一直跨到 $+7$。锰(II) $d^5$ 在酸中最稳定，几乎无色（只有自旋禁阻带，[[coordination-chemistry/spectra-of-complexes#ex-mn2]]），没有 CFSE，因而是活性的且无几何偏好。锰(III) $d^4$ 在水中歧化，除非被配位稳定；锰(IV) 以 $\mathrm{MnO_2}$ 为人熟知，是碱性电池的阴极材料；锰(VII) 是深紫色的高锰酸盐，为强氧化剂，其颜色是一条 LMCT 带。生物学在光系统 II 中用一个 $\mathrm{Mn_4CaO_5}$ 簇来氧化水（[[coordination-chemistry/bioinorganic]]）。

**铁（第 8 族）。** 铁(II) 与铁(III) 唱主角。$\mathrm{Fe^{3+}(aq)}$ 是强酸性水合离子（$\mathrm{p}K_\mathrm{a} \approx 2.2$），除非溶液呈酸性，它会水解并聚合成难溶的氧化氢氧化物；这一低溶解度——$\mathrm{Fe(OH)_3}$ 的 $K_\mathrm{sp}$ 约 $10^{-39}$——就是海水中铁稀缺、生物不得不进化出铁载体与铁蛋白来驾驭它的原因。氧化物 FeO、$\mathrm{Fe_3O_4}$（反尖晶石，[[coordination-chemistry/crystal-field-theory#ex-spinels]]）与 $\mathrm{Fe_2O_3}$ 是矿石与铁锈。普鲁士蓝 $\mathrm{Fe^{III}_4[Fe^{II}(CN)_6]_3\cdot xH_2O}$ 是一种深蓝色的混合价化合物：低自旋铁(II) 与氰根的碳端成键，高自旋铁(III) 与氮端成键；它的颜色是一条跨界电荷转移带——$\mathrm{Fe^{II} \rightarrow Fe^{III}}$ 经氰桥发生。

**钴与镍（第 9、10 族）。** 钴(II) 在水中呈粉色，在四面体氯配合物中呈蓝色；钴(III) 是维尔纳化学中原典型的惰性低自旋 $d^6$ 离子。钴酸锂 $\mathrm{LiCoO_2}$ 中钴在 III 与 IV 之间循环，是第一代商用锂离子电池（1991 年）的阴极。镍几乎只有镍(II)，水中呈绿色，遇强场配体成平面正方形（[[coordination-chemistry/crystal-field-theory]]）。**蒙德法**（1890 年）精炼镍：在约 $50\ ^\circ\mathrm{C}$ 让粗镍与一氧化碳生成挥发性的 $\mathrm{[Ni(CO)_4]}$，再在约 $200$–$250\ ^\circ\mathrm{C}$ 的纯镍粒上使其分解——一个由温度移动平衡的过程；四羰基镍是最毒的工业化学品之一，整个过程必须在密闭装置中运行。

**铜与锌（第 11、12 族）。** 铜(II) $d^9$ 几乎总是姜-泰勒畸变的，水中呈蓝色，与氨呈深蓝紫色；铜(I) 是 $d^{10}$，除非有电荷转移带，否则呈白色。锌只有锌(II)，$d^{10}$，无色、抗磁、无 CFSE；它以几乎相同的难易采取四面体、五配位与六配位几何，正是这种灵活性使它成为许多酶的路易斯酸催化剂。

## 较重的过渡金属

第二、三系与第一系的差别有四点系统性规律，全部源自更大、更弥散的 $4d$ 与 $5d$ 轨道。

1. **较高的氧化态**更稳定，常见氧化态也常常更高（Mo 与 W(VI)、Re(VI)、Ru 与 Os 的 (IV)、(VI)、(VIII)、Pt(II) 与 (IV)），并有丰富的氧化物与卤化物化学。较重的第 6 族金属形成**多金属氧酸盐**（多酸根），即大型笼状阴离子，如 $\mathrm{[PMo_{12}O_{40}]^{3-}}$——磷钼酸根黄色，用于磷酸根的比色测定。
2. **配体场分裂更大**：相同电荷下，$4d$ 通常比 $3d$ 大约 50 %，$5d$ 大 75–100 %，所以它们的配合物几乎全是**低自旋**（[[coordination-chemistry/crystal-field-theory]]）且**取代惰性**的。
3. **较高的配位数**很常见（七、八、九配位，如 $\mathrm{[NbF_7]^{2-}}$、$\mathrm{[Mo(CN)_8]^{4-}}$、$\mathrm{[ReH_9]^{2-}}$），因为较大的金属容得下更多配体。
4. **金属-金属成键**重要得多：有许多含金属-金属键的卤化物簇（例如 $\mathrm{[Mo_6Cl_8]^{4+}}$ 与 $\mathrm{[Nb_6Cl_{12}]^{2+}}$ 核心），以及已知最强的金属-金属多重键。

铂族金属（Ru、Os、Rh、Ir、Pd、Pt）化学惰性而致密，Pd(II)、Pt(II)、Rh(I)、Ir(I) 形成平面正方形 $d^8$ 配合物，是加氢、氢甲酰化与交叉偶联的催化剂（[[organometallics-catalysis]]）。金是最不活泼的金属，只溶于同时能配位它的氧化性介质，如王水（生成 $\mathrm{[AuCl_4]^-}$）或充气的氰化物溶液（生成 $\mathrm{[Au(CN)_2]^-}$）。

::: example 为什么氰化物能溶解金 {#ex-gold}
$E^\circ(\mathrm{Au^+/Au}) = +1.69\ \mathrm{V}$；$\mathrm{[Au(CN)_2]^-}$ 的 $\log\beta_2 = 38.3$。(a) 求 $\mathrm{[Au(CN)_2]^- + e^- \rightarrow Au + 2\,CN^-}$ 的 $E^\circ$。(b) 证明 pH 11 时氧气能在氰化物溶液中氧化金（pH 11、$p(\mathrm{O_2}) = 0.21\ \mathrm{bar}$ 时 $E(\mathrm{O_2/OH^-}) \approx +0.58\ \mathrm{V}$）。
::: solution
(a) 循环与[[coordination-chemistry/complex-stability#prop-redox-shift]]相同，只是这次还原态就是金属本身（不配位）：$E^\circ = E^\circ(\mathrm{Au^+/Au}) - 0.05916\log\beta_2 = 1.69 - 0.05916 \times 38.3 = 1.69 - 2.27 = -0.58\ \mathrm{V}$。(b) 在氰化物中金电对位于 $-0.58\ \mathrm{V}$（氰根活度为 1 时；在浸取液的稀氰根下约正 $2 \times 0.059 \times |\log[\mathrm{CN^-}]|$，仍远低于 $+0.58$），所以电池 $\mathrm{O_2 + 4\,Au + 8\,CN^- + 2\,H_2O \rightarrow 4\,[Au(CN)_2]^- + 4\,OH^-}$ 的电势约为 $+1\ \mathrm{V}$：金溶解了。碱性 pH 防止生成剧毒且易挥发的氰化氢（$\mathrm{p}K_\mathrm{a}(\mathrm{HCN}) = 9.2$）。配位使金的电势降低 2 V 以上：贵金属之所以"贵"，只是因为不存在能结合其离子的配体。氰化物浸取至今仍是矿石提金的主要工艺，伴随氰化物泄漏的严重环境危害。
:::
:::

### 金属-金属多重键

1964 年，F. Albert Cotton 与合作者证明阴离子 $\mathrm{[Re_2Cl_8]^{2-}}$ 的 Re–Re 距离只有 $224\ \mathrm{pm}$，远短于铼金属中的 $275\ \mathrm{pm}$，而且两个 $\mathrm{ReCl_4}$ 单元呈*重叠式*构象，尽管交错式排列会减小 Cl···Cl 排斥。这两个事实都由**四重键**解释。

::: definition 金属-金属四重键 {#def-quadruple}
在 M–M 轴沿 $z$ 的二聚体 $\mathrm{M_2L_8}$ 中，每个金属用其 $d$ 轨道进行金属-金属成键：$d_{z^2}$ 以"头碰头"重叠成一根 **σ** 键；$d_{xz}$ 与 $d_{yz}$ 以侧向重叠成两根 **π** 键；$d_{xy}$ 以面对面重叠成一根 **δ** 键，它有两个包含 M–M 轴的节面。（$d_{x^2-y^2}$ 指向配体，用于 M–L 成键。）成键轨道的次序为 $\sigma < \pi < \delta$，其后是反键轨道 $\delta^* < \pi^* < \sigma^*$。**键级**是成键与反键金属-金属轨道中电子数之差的一半。八个电子（$\sigma^2\pi^4\delta^2$）给出四重键。
:::

δ 键很弱（重叠很小），但它要求重叠式构象：交错式二聚体中两个 $d_{xy}$ 轨道相对旋转 $45^\circ$，其重叠按对称性为零。所以这种违反位阻偏好的重叠式几何，正是 δ 键的签名。

::: example 数金属-金属键 {#ex-metal-metal}
求 (a) $\mathrm{[Re_2Cl_8]^{2-}}$、(b) $\mathrm{[Mo_2(O_2CCH_3)_4]}$、(c) $\mathrm{[Re_2Cl_8]^{3-}}$（设想的单电子还原产物）、(d) $\mathrm{[Ru_2(O_2CR)_4]^+}$ 的金属-金属键级，并对 (c) 略加评论。
::: solution
指定配体电荷后数每个金属上的 $d$ 电子。(a) 每个 Re 是 Re(III)，$d^4$：八个电子，$\sigma^2\pi^4\delta^2$，键级 **4**。(b) 每个 Mo 是 Mo(II)（四个乙酸根共 $-4$，由两个金属分摊），$d^4$：又是 $\sigma^2\pi^4\delta^2$，四重键，Mo–Mo 距离约 $209\ \mathrm{pm}$。乙酸铬(II) 是它的铬类似物，1844 年欧仁·佩利戈（Eugène Péligot）首次制得的红色固体。(c) 多出的一个电子进入 $\delta^*$：$\sigma^2\pi^4\delta^2\delta^{*1}$，键级 $(8 - 1)/2 = 3.5$。由于 δ 的贡献小，键长几乎不变；Cotton 正是用这类还原与氧化物种及其微小的结构变化，证明了 δ 键真实存在而微弱。(d) Ru(II)/Ru(III)，平均 $\mathrm{Ru^{2.5+}}$，即每个金属 $d^{5.5}$：十一个电子，$\sigma^2\pi^4\delta^2(\pi^*\delta^*)^3$，键级 $(8 - 3)/2 = 2.5$，近简并的 $\pi^*$ 与 $\delta^*$ 能级上有三个未成对电子。
:::
:::

## 后续内容

本章的趋势把课程其余部分所需的描述性化学组织起来。铂族金属的催化化学在[[organometallics-catalysis]]中展开，其中 16 电子与 18 电子配合物、金属-配体多重键的稳定性遵循同样的趋势。氧化物与尖晶石见[[materials-chemistry/crystal-structures]]与[[materials-chemistry/energy-materials]]（电池阴极），二氧化钛、铬化合物及金属本身的工业生产见[[green-chemistry/industrial-inorganic]]。f 区——镧系收缩的来源——是[[coordination-chemistry/f-block]]的主题，锰、铁、钴、镍、铜、锌与钼在酶中的作用在[[coordination-chemistry/bioinorganic]]中概览。

::: history
好几种过渡金属是 18 世纪研究矿物的瑞典化学家发现的：格奥尔格·布兰特（Georg Brandt）发现钴（约 1735 年），阿克塞尔·克龙斯泰特（Axel Cronstedt）发现镍（1751 年），约翰·戈特利布·冈恩（Johan Gottlieb Gahn）发现锰（1774 年）。路易-尼古拉·沃克兰（Louis-Nicolas Vauquelin）1797 年分离出铬，并以其化合物的颜色命名；安德烈斯·曼努埃尔·德尔里奥（Andrés Manuel del Río，1801 年）与尼尔斯·塞夫斯特伦（Nils Sefström，1830 年）发现了钒。铂族金属在 19 世纪初由威廉·海德·沃拉斯顿（William Hyde Wollaston，钯 1803 年、铑 1804 年）与史密斯森·坦南特（Smithson Tennant，锇与铱 1803 年）分离出来。路德维希·蒙德（Ludwig Mond）、卡尔·兰格（Carl Langer）与弗里德里希·昆克（Friedrich Quincke）1890 年发现四羰基镍，蒙德用它精炼镍。格奥尔格·冯·海维西（Georg von Hevesy）与德克·科斯特（Dirk Coster）在尼尔斯·玻尔（Niels Bohr）"72 号元素应像锆而不是像稀土"的预言指引下，1923 年在哥本哈根用锆矿的 X 射线光谱发现了铪。维克托·戈尔德施密特（Victor Goldschmidt）在 1920 年代为镧系收缩命名。F. Albert Cotton 1964 年对 $\mathrm{[Re_2Cl_8]^{2-}}$ 四重键的阐明，开创了金属-金属多重成键领域。
:::

::: summary
- 过渡元素在原子或常见离子中具有未填满的 $d$ 亚层；在化合物中一切 d 区离子都是 $d^n$，与自由原子的排布无关。
- 半径横跨一系减小；镧系收缩使第二、三系的尺寸几乎相同（Zr 与 Hf 是化学双胞胎）。
- 内聚能在第 6 族附近（钨）达极大，$4d$、$5d$ 金属更大；$3d$ 系在锰处下凹。
- 最高氧化态到第 7 族等于族数（Ru、Os 到第 8 族）；高氧化态沿族向下更稳定，最高氧化态需要氧离子或氟离子配体。
- 第一系不规则的 $\mathrm{M^{3+}/M^{2+}}$ 电势反映了 $d^5$ 的稳定性和 $d^3$、低自旋 $d^6$ 的 CFSE；中间氧化态在 $E^\circ_\mathrm{R} > E^\circ_\mathrm{L}$ 时歧化（水中的铜(I)，$K = 1.6\times10^6$）。
- 每族都有几种关键化合物：$\mathrm{TiO_2}$、$\mathrm{V_2O_5}$、铬酸根/重铬酸根（致癌）、高锰酸盐与 $\mathrm{MnO_2}$、铁的氧化物与普鲁士蓝、$\mathrm{LiCoO_2}$、$\mathrm{[Ni(CO)_4]}$。
- 较重的金属偏爱较高氧化态、低自旋、较高配位数与金属-金属键，直到 $\mathrm{[Re_2Cl_8]^{2-}}$ 的 σ²π⁴δ² 四重键，其 δ 分量强制重叠式结构。
:::

## 习题

::: exercise 氧化态与 d 电子数 {level=1}
写出 $\mathrm{TiCl_4}$、$\mathrm{V_2O_5}$、$\mathrm{[VO(H_2O)_5]^{2+}}$、$\mathrm{K_2Cr_2O_7}$、$\mathrm{KMnO_4}$、$\mathrm{OsO_4}$ 与 $\mathrm{LiCoO_2}$ 中金属的氧化态与 $d^n$ 计数。
::: solution
Ti(IV) $d^0$；V(V) $d^0$；V(IV) $d^1$（氧钒）；Cr(VI) $d^0$；Mn(VII) $d^0$；Os(VIII) $d^0$；Co(III) $d^6$（低自旋，这正是 $\mathrm{LiCoO_2}$ 抗磁的原因）。注意最高氧化态多么频繁地是 $d^0$：金属已失去全部价电子，此类化合物若有色，颜色便是电荷转移。
:::

::: exercise 铜(I) 的歧化 {level=1 check="1.6e6"}
已知 $E^\circ(\mathrm{Cu^{2+}/Cu^+}) = +0.153\ \mathrm{V}$ 与 $E^\circ(\mathrm{Cu^+/Cu}) = +0.52\ \mathrm{V}$，求 $2\,\mathrm{Cu^+(aq)} \rightleftharpoons \mathrm{Cu^{2+}(aq)} + \mathrm{Cu(s)}$ 在 $298\ \mathrm{K}$ 的平衡常数。（$K$ 保留两位有效数字。）
::: solution
$E^\circ_\mathrm{cell} = 0.52 - 0.153 = 0.367\ \mathrm{V}$，$\log K = 0.367/0.05916 = 6.20$，$K = 1.6\times10^6$。
:::
:::

::: exercise 钼二聚体的键级 {level=1 check="4"}
$\mathrm{[Mo_2Cl_8]^{4-}}$ 的 Mo–Mo 键级是多少？两个 $\mathrm{MoCl_4}$ 单元应取重叠式还是交错式？（输入键级。）
::: solution
每个 Mo 是 Mo(II)（由 $8 \times (-1)$ 与 $2x = -4$ 得 $x = +2$），$d^4$：八个电子，$\sigma^2\pi^4\delta^2$，键级 **4**。δ 键要求重叠式构象。
:::
:::

::: exercise 水中的锰(III) {level=2 check="10"}
已知 $E^\circ(\mathrm{Mn^{3+}/Mn^{2+}}) = +1.54\ \mathrm{V}$ 与 $E^\circ(\mathrm{MnO_2/Mn^{3+}}) = +0.95\ \mathrm{V}$（对应 $\mathrm{MnO_2 + 4\,H^+ + e^- \rightarrow Mn^{3+} + 2\,H_2O}$），证明 $\mathrm{Mn^{3+}}$ 在 $1\ \mathrm{mol\,dm^{-3}}$ 酸中歧化，并求 $2\,\mathrm{Mn^{3+} + 2\,H_2O \rightleftharpoons Mn^{2+} + MnO_2 + 4\,H^+}$ 的 $\log K$。（$\log K$ 保留两位有效数字。）
::: solution
右端电对（$1.54\ \mathrm{V}$）超过左端电对（$0.95\ \mathrm{V}$），所以锰(III) 歧化（[[#prop-disproportionation]]）。$E^\circ_\mathrm{cell} = 1.54 - 0.95 = 0.59\ \mathrm{V}$，$\log K = 0.59/0.05916 = 9.97 \approx 10$。锰(III) 只有在被配位（氟离子、硫酸根、焦磷酸根或乙酸根）或酸度极高使平衡退回时，才能在水中存留。
:::
:::

::: exercise 铁(III) 的酸性 {level=2 check="2.27"}
取 $\mathrm{[Fe(H_2O)_6]^{3+}}$ 的 $\mathrm{p}K_\mathrm{a} = 2.2$，忽略进一步的水解与聚合，求 $0.010\ \mathrm{mol\,dm^{-3}}$ 硝酸铁(III) 溶液的 pH。同样的处理对久置的 $0.10\ \mathrm{mol\,dm^{-3}}$ 溶液为什么不再好用？（pH 保留三位有效数字。）
::: solution
$K_\mathrm{a} = 10^{-2.2} = 6.31\times10^{-3}$。令 $x = [\mathrm{H^+}]$：$x^2/(0.010 - x) = 6.31\times10^{-3}$，即 $x^2 + 6.31\times10^{-3}x - 6.31\times10^{-5} = 0$，得 $x = 5.39\times10^{-3}\ \mathrm{mol\,dm^{-3}}$（近似 $x \ll c$ 在此严重失效）。pH $= 2.27$。浓度更高且久置时，$\mathrm{[Fe(OH)(H_2O)_5]^{2+}}$ 会二聚成氧桥或羟桥的 $\mathrm{[Fe_2(\mu\text{-}OH)_2(H_2O)_8]^{4+}$，继而聚合成胶态的氧化氢氧化物，释放更多酸；单个 $\mathrm{p}K_\mathrm{a}$ 不再能描述溶液。这就是铁(III) 储备液必须酸化保存的原因。
:::
:::

::: exercise 解释族趋势 {level=2}
解释 (a) 为什么 $\mathrm{CrO_3}$ 是危险的强氧化剂而 $\mathrm{WO_3}$ 不是；(b) 为什么 $\mathrm{OsO_4}$ 存在而"$\mathrm{FeO_4}$"不存在；(c) 为什么 $\mathrm{[NiCl_4]^{2-}}$ 是四面体而 $\mathrm{[PtCl_4]^{2-}}$ 是平面正方形。
::: solution
(a) 高氧化态沿族向下更稳定（[[#prop-oxidation-trends]]）；铬(VI) 容易被还原为极稳定的铬(III)，而钨(VI) 是钨最稳定的状态。$\mathrm{CrO_3}$ 接触即点燃许多有机物（GHS03 氧化剂，并且致癌）。(b) 要达到铁(VIII)，须从有效核电荷很高的紧凑 $3d$ 壳层移走八个电子；代价超过对四个氧的键能。锇的 $5d$ 轨道更大，与氧的键更强，电离能上升也更平缓。$\mathrm{OsO_4}$ 挥发且剧毒（使组织包括角膜着色并固定），只能在溶液中、在通风橱里使用。(c) 两者都是 $d^8$。镍(II) 配弱场的氯离子时，平面正方形的 CFSE 增益太小，抵不过增大的配体间排斥，故配合物取四面体。铂(II) 是 $5d$ 离子，分裂大得多，平面正方形排布中让 $d_{x^2-y^2}$ 空置所获的能量占支配地位。
:::

::: exercise 浸取计算 {level=3 check="-0.58"}
(a) 已知 $E^\circ(\mathrm{Au^+/Au}) = +1.69\ \mathrm{V}$ 且 $\mathrm{[Au(CN)_2]^-}$ 的 $\log\beta_2 = 38.3$，求 $E^\circ([\mathrm{Au(CN)_2}]^-/\mathrm{Au})$。(b) 求 $[\mathrm{CN^-}] = 1.0\times10^{-3}\ \mathrm{mol\,dm^{-3}}$、$[\mathrm{[Au(CN)_2]^-}] = 1.0\times10^{-5}\ \mathrm{mol\,dm^{-3}}$ 的浸取液中的实际电势。(c) 电势为 $+0.58\ \mathrm{V}$ 的氧气还能氧化金吗？（(a) 的 $E^\circ$ 以 V 输入，保留两位小数。）
::: solution
(a) $E^\circ = 1.69 - 0.05916 \times 38.3 = 1.69 - 2.266 = -0.58\ \mathrm{V}$（两位小数为 $-0.576$）。(b) 能斯特：$E = E^\circ - 0.05916\log([\mathrm{CN^-}]^2/[\mathrm{Au(CN)_2^-}]) = -0.576 - 0.05916\log(1.0\times10^{-6}/1.0\times10^{-5}) = -0.576 - 0.05916 \times (-1) = -0.517\ \mathrm{V}$。(c) 能：电池电势约 $0.58 - (-0.52) = 1.1\ \mathrm{V}$，强烈为正。工业浸取受速率而非热力学限制，其速率由氧气向金表面的传输支配。

::: exercise 普鲁士蓝中的混合价 {level=3}
普鲁士蓝是 $\mathrm{Fe_4[Fe(CN)_6]_3\cdot xH_2O}$。(a) 给两类铁指派氧化态与自旋状态，并用光谱化学序列解释你的指派。(b) 解释为什么该化合物呈深蓝色，尽管 $\mathrm{[Fe(CN)_6]^{4-}}$ 中的铁(II)（淡黄色）与 N 端配位的 $\mathrm{Fe^{3+}}$（颜色很淡）都不在红光区强吸收。(c) 特纳蓝由 $\mathrm{Fe^{2+}}$ 与 $\mathrm{[Fe(CN)_6]^{3-}}$ 制得，曾被认为是另一种化合物。解释它为什么其实是同一种物质。
::: solution
(a) 电荷平衡：三个 $\mathrm{[Fe(CN)_6]^{4-}}$ 共 $-12$，恰好由四个 $\mathrm{Fe^{3+}}$ 平衡。与氰根六个碳成键的铁是铁(II)，低自旋（$t_{2g}^6$，氰根在光谱化学序列高端，且有强反键）；与氮端成键的铁是铁(III)，高自旋，因为 N 端氰根与水的场弱得多。(b) 蓝色来自 $700\ \mathrm{nm}$ 附近的**跨界电荷转移**带：光把电子从 $\mathrm{Fe^{II}}$ 经 $\mathrm{Fe{-}C{\equiv}N{-}Fe}$ 桥激发到 $\mathrm{Fe^{III}}$。这一跃迁是允许的、强的，而且只因为两种氧化态同时存在且电子耦合才存在。(c) 把 $\mathrm{Fe^{2+}}$ 与铁氰化物混合会发生快速电子转移 $\mathrm{Fe^{2+} + [Fe(CN)_6]^{3-} \rightarrow Fe^{3+} + [Fe(CN)_6]^{4-}}$，因为碳端位点强烈偏好铁(II)、氮端位点偏好铁(III)（相反的安排远不那么稳定），所以产物是同样的 $\mathrm{Fe^{III}}$/$\mathrm{Fe^{II}(CN)_6}$ 骨架。1960 年代的穆斯堡尔谱证实两种蓝色物质完全相同。
:::
