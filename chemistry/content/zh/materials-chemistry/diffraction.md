我们怎么知道氯化钠中不含NaCl分子、金红石中的Ti–O键长$1.95\ \text{Å}$、或某种新电池正极材料具有尖晶石结构？答案几乎总是X射线衍射。一束波长与原子间距相当的X射线被晶体的电子散射；由于晶体是周期性的，散射波在几乎一切方向上相消、只在少数方向上相长，形成一幅由尖锐反射组成的花样。反射的*位置*给出品胞的大小与形状；反射的*强度*给出其中原子的排布；反射的*宽度*则报告晶粒的大小与应变。用这种方法已经测定了一百多万个晶体结构，而粉末衍射是材料实验室里制得的每种固体的常规鉴定手段。

[[bonding-structure/solid-structures]]一章已由晶面对X射线的反射导出布拉格定律。这里我们从格子对波的散射出发导出同一条件，由此引出倒格子与埃瓦尔德（Ewald）作图。然后通过**结构因子**计算强度，说明带心的点阵及其他对称元素如何产生**系统消光**，给粉末花样指标化，由线宽估计晶粒尺寸，并勾勒一个单晶结构如何被解出与精修。全篇晶胞与密勒指数的记法沿用[[materials-chemistry/crystal-structures]]。

## 产生X射线与X射线的散射

实验室X射线来自封闭管或旋转阳极靶：电子经$30$–$50\ \mathrm{kV}$加速后轰击金属靶。除了连续的轫致辐射本底，当一个外层电子填入$K$层空位时，靶还会发出尖锐的特征线：铜的$K\alpha_1$线$\lambda = 1.5406\ \text{Å}$（能量$8.05\ \mathrm{keV}$），钼的为$0.7107\ \text{Å}$。滤波片或单色器除去大部分$K\beta$线与连续谱。同步辐射提供的光束亮度高出数百万倍，且波长可调。

X射线被电子散射。孤立原子的散射振幅由**原子散射因子**（形状因子）$f$描述，它是原子电子密度的傅里叶变换：在正前方向上$f$等于电子数，中性原子即$Z$；它随散射角增大而下降，因为电子云有有限大小，其不同部分发出的波会逐渐失去同相。$f$随$\sin\theta/\lambda$变化的数值表见《国际晶体学表》C卷。由此立见两个推论：重原子主导X射线花样，而只有一个电子的氢几乎不可见。

::: warning 布拉格"反射"是干涉，不是镜面反射 {#warn-reflection}
人们很容易把晶面想象成半透明的镜子，在任何角度反射X射线，再由布拉格定律挑选反射叠加增强的那些角度。实际上"面"上并没有可供反射的东西：这些面只是过点阵点的数学构造，而散射来自电子——电子在哪里，散射就来自哪里。一族$(hkl)$中的一个面可能根本不含任何原子。布拉格定律描述的，是相继晶胞中*全部*电子的散射波同相的条件；强度则取决于一个晶胞内电子如何排布，这正是结构因子要解决的问题。请把晶面当作相位差的记账工具，而不是物理上的反射体。
:::

## 衍射条件

设入射波的波矢为$\mathbf{k}$，散射波的波矢为$\mathbf{k}'$，弹性散射时$\lvert\mathbf{k}\rvert = \lvert\mathbf{k}'\rvert = 1/\lambda$（晶体学家的约定不含因子$2\pi$）。**散射矢量**为$\mathbf{q} = \mathbf{k}' - \mathbf{k}$。位于$\mathbf{r}$处的散射体所贡献的波，相对于原点处散射体的相位为$2\pi\,\mathbf{q}\cdot\mathbf{r}$。

::: proposition 劳厄条件与布拉格定律 {#prop-laue}
具有点阵矢量$\mathbf{a}, \mathbf{b}, \mathbf{c}$的晶体，只有在散射矢量等于一个倒格矢时才发生强衍射，
$$
\mathbf{q} = \mathbf{G}_{hkl} = h\mathbf{a}^* + k\mathbf{b}^* + l\mathbf{c}^*, \qquad h, k, l \text{ 为整数},
$$ {#eq-laue}
其中$\mathbf{a}^*\cdot\mathbf{a} = 1$、$\mathbf{a}^*\cdot\mathbf{b} = \mathbf{a}^*\cdot\mathbf{c} = 0$，其余循环置换。由于$\lvert\mathbf{G}_{hkl}\rvert = 1/d_{hkl}$，这等价于**布拉格定律**
$$
\lambda = 2d_{hkl}\sin\theta,
$$ {#eq-bragg}
其中$2\theta$是入射束与衍射束之间的夹角。这一推导假定弹性、单次散射（运动学近似）；除大而完美的晶体外，X射线都满足该近似。
:::

::: proof
整个晶体散射的振幅，是对位于点阵点$\mathbf{R} = n_1\mathbf{a} + n_2\mathbf{b} + n_3\mathbf{c}$的各晶胞求和，每个晶胞贡献相同的振幅乘以相位因子$e^{2\pi i\mathbf{q}\cdot\mathbf{R}}$。对一块$N_1 \times N_2 \times N_3$个晶胞的晶体，对$n_1$的求和是几何级数，
$$
\sum_{n_1=0}^{N_1-1} e^{2\pi i n_1\mathbf{q}\cdot\mathbf{a}}, \qquad \text{其模的平方为} \qquad \frac{\sin^2(\pi N_1\,\mathbf{q}\cdot\mathbf{a})}{\sin^2(\pi\,\mathbf{q}\cdot\mathbf{a})}.
$$
$N_1$很大时，除非$\mathbf{q}\cdot\mathbf{a}$是整数$h$（此时该和达到$N_1^2$），否则此项可以忽略。$\mathbf{b}$与$\mathbf{c}$同理，所以强散射要求$\mathbf{q}\cdot\mathbf{a} = h$、$\mathbf{q}\cdot\mathbf{b} = k$、$\mathbf{q}\cdot\mathbf{c} = l$（三个**劳厄方程**）。由倒基矢的定义，矢量$h\mathbf{a}^* + k\mathbf{b}^* + l\mathbf{c}^*$恰好满足这三个方程，而且是唯一满足的矢量，这就证明了[[#eq-laue]]。

矢量$\mathbf{G}_{hkl}$垂直于$(hkl)$面，长度为$1/d_{hkl}$（如[[materials-chemistry/crystal-structures#prop-dspacing]]的证明中所述）。弹性散射时$\mathbf{k}$与$\mathbf{k}'$等长，均为$1/\lambda$，夹角为$2\theta$，所以它们与$\mathbf{q}$构成的三角形是等腰三角形，$\lvert\mathbf{q}\rvert = 2(1/\lambda)\sin\theta$。令$\lvert\mathbf{q}\rvert = 1/d_{hkl}$即得$\lambda = 2d_{hkl}\sin\theta$。
:::

这个证明说明的还不只是条件本身：它还说明了反射有多尖锐。干涉函数$\sin^2(\pi N x)/\sin^2(\pi x)$的主峰高度为$N^2$、宽度约为$1/N$，所以一千个晶胞见方的晶体给出的反射，宽度只有相邻反射间距的千分之一。小晶体给出宽化的谱线，这正是下文谢乐公式的基础。

::: widget plot

y: 0, 1.1
sliders: n=5:1:40:1

caption: [[#prop-laue]]证明中的干涉函数，除以$N^2$使主峰高度为1，对$x = \mathbf{q}\cdot\mathbf{a}$作图，对应一列$N$个晶胞（滑条）。整数$x$处的主峰就是布拉格反射；其间分布着$N - 2$个微弱的次极大。随着$N$增大，峰按$1/N$收窄，次极大的起伏也随之淡去：对于横贯一块典型晶体的$10^4$–$10^6$个晶胞，这些起伏细得根本看不见；但对几十个晶胞大小的纳米晶体，宽化很容易测得。
:::

**埃瓦尔德作图**把[[#eq-laue]]变成一幅图。画出倒格子，过一个倒格点作半径为$1/\lambda$的球，球心位于由原点起$-\mathbf{k}$处的点。每当一个倒格点落在球面上，就出现一个$hkl$反射。静止的单晶配上单色X射线很少恰好满足这一条件，所以单晶衍射仪旋转晶体，让倒格点扫过球面。粉末中的晶粒取一切取向，每个$\mathbf{G}_{hkl}$被抹成半径为$1/d_{hkl}$的球面，它与埃瓦尔德球的交线是一个圆：衍射束构成半角为$2\theta$的圆锥，在面探测器上记录为圆环，或沿$2\theta$扫描记录为峰。由于$\sin\theta \le 1$，只有$d_{hkl} \ge \lambda/2$的反射才可能被观测到；这一**分辨极限**对Cu $K\alpha$是$0.77\ \text{Å}$，对Mo $K\alpha$是$0.36\ \text{Å}$，这正是精密单晶测定偏爱钼辐射的原因。

## 强度与结构因子

劳厄条件说的是反射*能否*出现、出现在何处；每个反射有多强，则取决于晶胞里的内容物。

::: definition 结构因子 {#def-structure-factor}
对含有散射因子为$f_j$、分数坐标为$(x_j, y_j, z_j)$的原子$j$的晶胞，反射$hkl$的**结构因子**为
$$
F_{hkl} = \sum_{j} f_j \exp\!\big[2\pi i(hx_j + ky_j + lz_j)\big].
$$ {#eq-structure-factor}
它是一个复数，模为$\lvert F_{hkl}\rvert$，相位为$\phi_{hkl}$。实测强度为
$$
I_{hkl} \propto \lvert F_{hkl}\rvert^2 \times (\text{多重性因子}) \times (\text{洛伦兹-偏振因子}) \times (\text{吸收、热振动及其他因子}).
$$
:::

结构因子直接由[[#prop-laue]]的证明得出：在一个倒格点处，每个晶胞都以相同的振幅散射，而该振幅正是一个晶胞内各原子的波以相位$2\pi\mathbf{G}_{hkl}\cdot\mathbf{r}_j = 2\pi(hx_j + ky_j + lz_j)$叠加之和。热振动把每个原子抹开，使其$f_j$乘上一个**德拜-瓦勒因子**$\exp(-B_j\sin^2\theta/\lambda^2)$，$B_j$典型值为$0.3$–$2\ \text{Å}^2$。粉末花样中的**多重性因子**统计叠合在同一$2\theta$处的对称等价反射数目（立方晶系$\{100\}$为6，$\{110\}$为12，$\{111\}$为8），而**洛伦兹-偏振因子**$(1 + \cos^22\theta)/(\sin^2\theta\cos\theta)$则计及测量的几何构型与散射束的部分偏振。

当$f_j$为实数时，$F_{\bar h\bar k\bar l}$是$F_{hkl}$的复共轭，故$\lvert F_{hkl}\rvert = \lvert F_{\bar h\bar k\bar l}\rvert$（**弗里德尔定律**）：即使晶体本身没有反演对称性，衍射花样看起来也是中心对称的。吸收边附近的反常散射引起的微小偏离，可用来确定手性分子的绝对构型。

::: proposition 点阵带心引起的系统消光 {#prop-absences}
对带心的点阵，无论基元里是什么原子，都有成整类的反射满足$F_{hkl} = 0$：
- 体心（I）：$h + k + l$为奇数的反射消失；
- 面心（F）：$h, k, l$奇偶混杂（非全奇亦非全偶）的反射消失；
- C心：$h + k$为奇数的反射消失。

初基点阵没有这类条件。螺旋轴与滑移面会在特定层带引起更多消光（例如沿$b$的$2_1$螺旋轴消去$k$为奇数的$0k0$），而全部消光规律把空间群缩小到一两个候选。
:::

::: proof
在I心晶胞中，位于$(x, y, z)$的每个原子在$(x + \tfrac12, y + \tfrac12, z + \tfrac12)$都有一份复制。把和式[[#eq-structure-factor]]按这些原子对分组，
$$
F_{hkl} = \sum_{j \in \text{半数}} f_j e^{2\pi i(hx_j + ky_j + lz_j)}\left[1 + e^{\pi i(h + k + l)}\right],
$$
方括号即$1 + (-1)^{h+k+l}$，当$h + k + l$为奇数时等于0，为偶数时等于2。对F心晶胞，每个原子还有分别平移$(0, \tfrac12, \tfrac12)$、$(\tfrac12, 0, \tfrac12)$与$(\tfrac12, \tfrac12, 0)$的复制，方括号变为
$$
1 + (-1)^{k+l} + (-1)^{h+l} + (-1)^{h+k}.
$$
若$h, k, l$全偶或全奇，每一对指标之和皆为偶数，方括号为4。若奇偶混杂，比如两偶一奇，则三个两两之和恰有一个为偶、两个为奇，方括号为$1 + 1 - 1 - 1 = 0$；两奇一偶亦然。C心的方括号为$1 + (-1)^{h+k}$。
:::

立方晶体中$1/d^2 = N/a^2$，其中$N = h^2 + k^2 + l^2$，因此允许的$N$值可以辨认点阵。初基立方允许除$4^m(8n + 7)$型（7、15、23、28…，它们不是三个平方数之和）以外的一切整数。体心只允许偶数$N$：2、4、6、8、10、12、14…。面心允许3、4、8、11、12、16、19、20、24、27…，即特征性的"双、单、双、单"图样。

::: example 岩盐、KCl与硅的结构因子 {#ex-structure-factors}
(a) 岩盐的F心立方晶胞中，$\mathrm{Na^+}$在$(0, 0, 0)$，$\mathrm{Cl^-}$在$(\tfrac12, 0, 0)$。求允许反射的$F_{hkl}$。(b) KCl结构相同，解释为什么它的111反射几乎消失，以致KCl最初被认为属于简单立方。(c) 硅（金刚石结构）的F心晶胞中有位于$(0, 0, 0)$与$(\tfrac14, \tfrac14, \tfrac14)$的原子。证明200反射虽为F心所允许，却仍然消失。
::: solution
(a) 提出F心因子——指标不混杂时它贡献4，否则贡献0。基元给出$f_\mathrm{Na} + f_\mathrm{Cl}e^{\pi ih}$。允许反射的$h, k, l$全偶或全奇，所以
$$
F_{hkl} = \begin{cases} 4(f_\mathrm{Na} + f_\mathrm{Cl}) & h, k, l \text{ 全偶（200, 220, 222, …）}, \\ 4(f_\mathrm{Na} - f_\mathrm{Cl}) & h, k, l \text{ 全奇（111, 311, 331, …）}. \end{cases}
$$
全偶反射很强，全奇反射很弱。

(b) $\mathrm{K^+}$与$\mathrm{Cl^-}$都有18个电子，故在所有角度上$f_\mathrm{K^+} \approx f_\mathrm{Cl^-}$，奇反射几乎消失。于是观测到的谱线有$N = 4, 8, 12, 16 \dots$，恰与棱长为$a/2$、每胞一个"平均"原子的初基立方晶胞的图样相同。布拉格（W. L. Bragg）1913年对KCl与NaCl作出的正确解释——两类离子的面心排列——首次证明离子晶体中不含分子。

(c) F心因子对200为4。基元因子为$f_\mathrm{Si}\left[1 + e^{2\pi i(h + k + l)/4}\right] = f_\mathrm{Si}\left[1 + e^{\pi i(h+k+l)/2}\right]$。对200，$h + k + l = 2$，$e^{\pi i} = -1$，故$F_{200} = 0$。一般说来，金刚石结构还会消去$h + k + l = 4n + 2$的全偶反射（200、222、420…）。（硅的222反射事实上以极弱的强度被观测到，因为成键电子并不球对称地分布在原子周围：这是对共价键的一瞥，虽然微弱却很直接。）
:::
:::

::: quiz
某立方金属的粉末谱线，其$\sin^2\theta$值之比为$2 : 4 : 6 : 8 : 10 : 12 : 14$。它是哪种点阵？
- [ ] 初基立方
- [x] 体心立方
- [ ] 面心立方
- [ ] 没有强度数据无法判定
::: solution
$\sin^2\theta = (\lambda^2/4a^2)N$，所以比值就是允许的$N$之比。除以2得$1 : 2 : 3 : 4 : 5 : 6 : 7$。初基立方点阵给不出$N = 7$的谱线，所以若这些谱线来自初基点阵，第七个比值就应是8而不是7。序列$2, 4, 6, \dots, 14$（其中$N = 14$来自321）正是体心立方的图样。面心立方则会给出$3 : 4 : 8 : 11 \dots$。仅凭前六条谱线的位置，初基立方与体心立方是无法区分的。

## 粉末衍射

粉末衍射仪记录细磨晶粒制成的平板或毛细管样品的强度随$2\theta$的变化。花样就是指纹：与粉末衍射卡片库（由国际衍射数据中心维护）中上百万条条目比对，或与由晶体结构数据库算出的花样比对，就能鉴定存在的物相，常常几分钟即可完成。除鉴定之外，粉末花样还能给出点阵参数（用内标精确到$10^5$分之几）、定量物相分数、晶粒尺寸与应变，并能通过里特维尔德（Rietveld）精修给出完整结构。

::: algorithm 立方物质粉末花样的指标化 {#alg-indexing}
1. 把每个峰位换算成$\sin^2\theta$（$\theta$为实测$2\theta$之半）。
2. 把每个$\sin^2\theta$除以第一个，再依次把比值乘以2、乘以3，找出能使所有比值都接近整数的乘数。这些整数就是$N = h^2 + k^2 + l^2$值（差一个公因子）。
3. 由$N$的序列辨认点阵：除7、15…以外的一切整数（P）；只有偶数（I）；3、4、8、11、12…（F）。
4. 给每个$N$指定$hkl$，对每条谱线计算$a = \lambda\sqrt{N}/(2\sin\theta)$；取平均值，并给予高角线最大的权重，因为那里$2\theta$的误差引起的$d$误差最小。
5. 检验：密度$\rho = ZM/N_\mathrm{A}a^3$必须与某个合理$Z$下的实测密度一致。若任何乘数都给不出整数，该物质就不是立方的；四方与六方花样可借助[[materials-chemistry/crystal-structures#eq-dspacing]]试凑指标化，或借助计算机程序。
:::

::: example 一个未知金属的指标化 {#ex-indexing}
某金属粉末（Cu $K\alpha_1$，$\lambda = 1.5406\ \text{Å}$）在$2\theta = 38.47^\circ$、$44.72^\circ$、$65.10^\circ$、$78.23^\circ$与$82.44^\circ$处给出峰（为本例算得的数值）。给花样指标化，找出点阵类型与$a$，并在其密度为$2.70\ \mathrm{g\,cm^{-3}}$的条件下猜一猜这是哪种金属。
::: solution
第一步：
| $2\theta$ | $\sin^2\theta$ | 与首峰之比 | 比值$\times 3$ | $hkl$ |
|---|---|---|---|---|
| $38.47^\circ$ | $0.10855$ | $1.000$ | $3.00$ | 111 |
| $44.72^\circ$ | $0.14474$ | $1.333$ | $4.00$ | 200 |
| $65.10^\circ$ | $0.28947$ | $2.667$ | $8.00$ | 220 |
| $78.23^\circ$ | $0.39802$ | $3.667$ | $11.00$ | 311 |
| $82.44^\circ$ | $0.43421$ | $4.000$ | $12.00$ | 222 |

比值乘以2得$2, 2.67, \dots$（不是整数）；乘以3得整数$3, 4, 8, 11, 12$：面心立方。由222线，$a = \lambda\sqrt{12}/(2\sqrt{0.43421}) = 1.5406 \times 3.4641/(2 \times 0.65895) = 4.0496\ \text{Å}$；其余谱线与之相符到$0.0002\ \text{Å}$以内。面心立方金属$Z = 4$，故$M = \rho N_\mathrm{A}a^3/Z = 2.70 \times 6.022\times10^{23} \times (4.0496\times10^{-8})^3/4 = 27.0\ \mathrm{g\,mol^{-1}}$：铝。
:::
:::

### 线宽与晶粒尺寸

真实的粉末峰，其宽度一部分由仪器决定（光束发散度、波长散布、样品几何），此外还有样品本身的贡献：细小的晶粒与微观应变。

::: proposition 谢乐公式 {#prop-scherrer}
垂直于衍射晶面的平均厚度为$\tau$的晶粒，会使布拉格角$\theta$处的反射宽化
$$
\beta = \frac{K\lambda}{\tau\cos\theta},
$$ {#eq-scherrer}
其中$\beta$是$2\theta$的半高全宽（以弧度计，扣除仪器宽度之后），$K \approx 0.9$是形状因子（依晶粒形状与宽度的定义约在0.8至1.1之间）。该公式对小于约$100\ \mathrm{nm}$的晶粒是可靠的；它忽略了应变宽化——应变宽化随$\tan\theta$增长，必须分离出去（例如用$\beta\cos\theta$对$\sin\theta$作威廉森-霍尔图）。
:::

::: proof
考察一个由$m$个晶面组成、厚度$\tau = md$的晶粒。在准确的布拉格角处，来自相继晶面的波程差为$\lambda$，全部相长叠加。在$\theta + \varepsilon$处，相邻晶面的波程差为$2d\sin(\theta + \varepsilon) \approx \lambda + 2d\varepsilon\cos\theta$，于是顶面与底面之间的波程差与整数个波长相差$2m d\varepsilon\cos\theta = 2\tau\varepsilon\cos\theta$。当这一额外波程恰为一个波长时，晶粒上半部与下半部的波以$\pi$的相位差两两相消；这正是[[#prop-laue]]中间射函数的第一个零点，位于$\varepsilon_0 = \lambda/(2\tau\cos\theta)$。作为$2\theta$的函数，峰从$2(\theta - \varepsilon_0)$延伸到$2(\theta + \varepsilon_0)$：两零点间总宽$4\varepsilon_0 = 2\lambda/(\tau\cos\theta)$，半高处的宽度约为其一半。对$\sin^2(Nx)/\sin^2x$线型作细致处理并对晶粒形状取平均，得$\beta = K\lambda/(\tau\cos\theta)$，其中$K \approx 0.9$。
:::

::: example 金纳米粒子的尺寸 {#ex-scherrer}
金纳米粒子在$2\theta = 38.2^\circ$处给出111峰，半高全宽$0.45^\circ$（Cu $K\alpha_1$）。用粗晶标准品测得的仪器宽度为$0.05^\circ$；对这类峰形可线性扣除。试估计晶粒尺寸。
::: solution
样品宽化：$\beta = 0.45^\circ - 0.05^\circ = 0.40^\circ = 0.40 \times \pi/180 = 6.98\times10^{-3}\ \mathrm{rad}$。由$\theta = 19.1^\circ$、$\cos\theta = 0.945$，
$$
\tau = \frac{K\lambda}{\beta\cos\theta} = \frac{0.9 \times 1.5406\ \text{Å}}{6.98\times10^{-3} \times 0.945} = 210\ \text{Å} = 21\ \mathrm{nm}.
$$
考虑到$K$的不确定度（约10 %）与宽化修正的不确定度，宜写作"约20 nm"。这是相干衍射区的尺寸；电子显微照片上看起来$30\ \mathrm{nm}$的颗粒可能由若干孪晶畴组成，所以谢乐尺寸常常小于显微尺寸（[[materials-chemistry/nanomaterials]]）。
:::
:::

::: warning 不要过度解读峰宽 {#warn-scherrer}
谢乐公式常被用于只比仪器分辨率略宽的峰，得出几百纳米的"晶粒尺寸"，那其实是噪声。样品宽化一旦小于仪器宽度的约四分之一，结果就没有意义。应变、堆垛层错与成分起伏也会使峰宽化，而且对不同$hkl$宽化的方式各不相同；单峰谢乐估计假定一切宽化都来自尺寸。要得到可靠的结果，应测定仪器线型、使用多个反射，并把尺寸与应变分离开来。
:::

## 由强度到结构

结构因子是一个晶胞电子密度的傅里叶变换。对变换求逆即得密度：

::: definition 电子密度与位相问题 {#def-density}
分数位置$(x, y, z)$处的电子密度是傅里叶级式
$$
\rho(x, y, z) = \frac{1}{V}\sum_{hkl} F_{hkl}\exp\!\big[-2\pi i(hx + ky + lz)\big] = \frac{1}{V}\sum_{hkl}\lvert F_{hkl}\rvert\cos\!\big[2\pi(hx + ky + lz) - \phi_{hkl}\big].
$$ {#eq-density}
实验测得强度，从而得到$\lvert F_{hkl}\rvert$，却测不到相位$\phi_{hkl}$。找回相位就是晶体学的**位相问题**。
:::

[[#eq-density]]的第二种形式借助弗里德尔定律把$hkl$与$\bar h\bar k\bar l$配对。每个反射贡献一列沿其晶面法线方向运行、波长为$d_{hkl}$的余弦密度波；原子出现在各波相长叠加之处。用到$d_\mathrm{min}$的反射能分辨间距约$d_\mathrm{min}$的细节，这就是分辨率以埃报出的原因。

::: widget fourier
wave: pulse
terms: 6
max: 40
spectrum: true
caption: [[#eq-density]]的一维类比：一个狭窄的密度峰（一个"原子"）由它的傅里叶分量重建，每个分量扮演一个级数$h$递增的反射。项数很少时（低分辨，小$\sin\theta/\lambda$），原子是一团带起伏的宽弥散；加入高级项使它变锐。谱图显示的是振幅，即衍射实验所能测定的量。实验*给不出*的是每一项的符号（相位）：改动几个符号，同样的振幅就重建出截然不同的密度。
:::

由测得的$\lvert F\rvert$通往相位有三条路。**帕特森法**用到$\lvert F_{hkl}\rvert^2$的傅里叶级式，它不需要相位；它的峰位于原子*之间*的矢量处，而在只含少数重原子的结构中这些矢量占支配地位，从而给出重原子位置及近似的相位。**直接法**由赫伯特·豪普特曼（Herbert Hauptman）与杰罗姆·卡尔莱（Jerome Karle）发展（1985年诺贝尔化学奖），利用强反射相位之间的统计关系——这些关系源于电子密度为正且集中在原子上这两个事实；它们与**对偶空间**算法、电荷翻转算法一起，能自动解出大多数小分子与无机结构。对蛋白质，相位来自重原子衍生物、反常散射或已知的相关结构。

初生模型随后通过**最小二乘精修**原子坐标、位移参数与占据数来改进，使观测与计算的$\lvert F\rvert$之差极小化。吻合程度由残差因子概括：
$$
R_1 = \frac{\sum\big\lvert\lvert F_\mathrm{o}\rvert - \lvert F_\mathrm{c}\rvert\big\rvert}{\sum\lvert F_\mathrm{o}\rvert},
$$
一个小分子的好结构典型为$0.02$–$0.05$。对反射重叠的粉末数据，雨果·里特维尔德1969年的方法对整个谱线逐点精修结构，拟合优劣由加权谱线残差与差值曲线判断。低的$R$是必要的，却不是充分的：结构还必须化学上合理，这正是[[materials-chemistry/crystal-structures#def-bond-valence]]的键价和与晶体学验证软件的检验派上用场之处。

::: example 用帕特森函数定位两个原子 {#ex-patterson}
一个晶胞长$10.0\ \text{Å}$的一维"晶体"含有位于$x = 0.10$的一个重原子与位于$x = 0.35$的另一个原子。帕特森函数$P(u) = \sum_h \lvert F_h\rvert^2\cos(2\pi hu)$的峰在哪里？它们丢掉了什么信息？
::: solution
$\lvert F_h\rvert^2 = F_hF_h^* = \sum_j\sum_k f_jf_k e^{2\pi ih(x_j - x_k)}$，所以$P(u)$是在每个原子间矢量$u = x_j - x_k$处以$f_jf_k$为权重的峰之和。此处：$u = 0$处的自矢量（权重$f_1^2 + f_2^2$），以及$u = \pm(0.35 - 0.10) = \pm0.25$处的互矢量，即晶胞内的$0.25$与$0.75$处，对应间距$2.5\ \text{Å}$。帕特森函数给出间距而不给出绝对位置：位于$0.30$与$0.55$的一对给出同样的图。利用对称性把一个原子固定在方便的原点上即可解决这一点，这就是重原子位置能从帕特森图读出的原因。
:::
:::

### 中子与电子

**中子**被原子核散射，散射长度随原子序数与同位素不规则变化，而不随$Z$增大。因此H（用D更好）、Li、O等轻原子的定位可与重原子同样精确，这对氢化物、电池材料与氧化物超导体的氧位置至关重要；相邻元素如Mn与Fe可以区分；而由于中子具有磁矩，磁结构可以被直接看见（[[materials-chemistry/magnetic-optical]]）。中子源是反应堆与散裂源，样品必须足够大。**电子**与物质的相互作用比X射线强约$10^4$–$10^6$倍，因此在透射电镜中对几百纳米厚的晶体做衍射成为可能（三维电子衍射，对分子晶体即microED），代价是多次散射使强度复杂化。

## 后续内容

衍射是本课程中几乎每一个结构背后的测量手段。[[materials-chemistry/defects]]用点阵参数的变化与漫散射来追踪非化学计量；[[materials-chemistry/solid-synthesis]]依靠粉末衍射判断反应是否完全；[[materials-chemistry/porous-materials]]与[[materials-chemistry/nanomaterials]]分别利用大晶胞的低角反射与小颗粒的谢乐宽化。[[#eq-density]]背后的数学是傅里叶分析（[数学图谱](/learn/maths/)），同样的结构因子思想也支撑着[[biochemistry/amino-acids-proteins]]中蛋白质结构的测定。

::: history
马克斯·冯·劳厄（Max von Laue）与瓦尔特·弗里德里希（Walter Friedrich）、保罗·克尼平（Paul Knipping）1912年在慕尼黑观测到X射线被硫酸铜晶体的衍射，一举证明X射线是波、晶体是周期性的。数月之内，威廉·劳伦斯·布拉格（William Lawrence Bragg）把花样重新解释为来自晶面的反射，得到$n\lambda = 2d\sin\theta$；他与建造X射线谱仪的父亲威廉·亨利·布拉格（William Henry Bragg）在1913年解出了NaCl、KCl、金刚石等结构；劳厄获1914年诺贝尔物理学奖，布拉格父子获1915年。保罗·埃瓦尔德在1913年与1921年发表了他的倒格球作图。彼得·德拜（Peter Debye）与保罗·谢乐（Paul Scherrer）（1916年）以及各自独立工作的阿尔伯特·胡尔（Albert Hull）（1917年）引入了粉末衍射，谢乐于1918年给出了他的谱线宽化公式。阿瑟·林多·帕特森（Arthur Lindo Patterson）于1934年引入了以他命名的函数。雨果·里特维尔德于1969年发表了他的全谱线精修方法；豪普特曼与卡尔莱自1953年起发展的直接法获得了1985年诺贝尔化学奖。克利福德·舒尔（Clifford Shull）与伯特伦·布罗克豪斯（Bertram Brockhouse）因中子散射分享1994年诺贝尔物理学奖。截至2026年，剑桥结构数据库收录的有机与金属有机结构已逾130万个，无机晶体结构数据库则收录了数十万个无机结构。
:::

::: summary
- 衍射发生在散射矢量等于一个倒格矢之时，$\mathbf{q} = \mathbf{G}_{hkl}$，这等价于布拉格定律$\lambda = 2d_{hkl}\sin\theta$；只有$d \ge \lambda/2$的反射可以观测。
- 反射$hkl$的强度正比于$\lvert F_{hkl}\rvert^2$，其中$F_{hkl} = \sum_j f_j\exp[2\pi i(hx_j + ky_j + lz_j)]$，再乘以多重性、洛伦兹-偏振、热振动与吸收因子。
- 带心的点阵造成系统消光（I：$h + k + l$为奇；F：奇偶混杂），螺旋轴与滑移面带来更多消光；立方晶体允许的$N = h^2 + k^2 + l^2$可辨认P、I或F。
- 粉末花样可鉴定物相，经由$\sin^2\theta$的比值指标化，给出精确的点阵参数，并经里特维尔德精修给出完整结构。
- 谱线宽化$\beta = K\lambda/\tau\cos\theta$（扣除仪器宽度后）估计100 nm以下的晶粒尺寸。
- 电子密度是结构因子的傅里叶级式；强度缺少相位，帕特森法、直接法与对偶空间方法找回相位，随后进行最小二乘精修（$R_1$为百分之几）。
- X射线看到的是电子（重原子），中子看到的是原子核与磁矩（轻原子、同位素、磁有序），电子衍射则适用于纳米大小的晶体。
:::

## 练习

::: exercise 一个布拉格角 {level=1 check="43.32"}
铜的$(111)$面间距$d_{111} = 2.087\ \text{Å}$。在Cu $K\alpha_1$辐射（$\lambda = 1.5406\ \text{Å}$）下，111反射出现在哪个$2\theta$角？（以度输入$2\theta$，四位有效数字。）
::: solution
$\sin\theta = \lambda/2d = 1.5406/(2 \times 2.087) = 0.36909$，$\theta = 21.66^\circ$，故$2\theta = 43.32^\circ$。
:::
:::

::: exercise 哪些反射？ {level=1}
在(a) 初基、(b) 体心、(c) 面心立方点阵中，列出100、110、111、200、210、211、220里哪些反射是允许的。
::: solution
(a) 初基：七个全部允许。(b) 体心（$h + k + l$为偶）：110、200、211、220。(c) 面心（全偶或全奇）：111、200、220。具体的基元可能再消去一些反射（如金刚石中200消失），但以上是点阵给出的条件。
:::
:::

::: exercise 分辨极限 {level=1 check="0.3554"}
用Mo $K\alpha$辐射（$\lambda = 0.7107\ \text{Å}$）能测到的最小面间距是多少？（以Å输入$d_\mathrm{min}$，四位有效数字。）
::: solution
$\sin\theta \le 1$，故$d_\mathrm{min} = \lambda/2 = 0.3554\ \text{Å}$。实际数据通常收集到约$\theta = 30^\circ$（$d = 0.71\ \text{Å}$），这已具备分辨原子的能力；Cu $K\alpha$只能到$d \ge 0.77\ \text{Å}$。
:::
:::

::: exercise 有多少条谱线？ {level=2 check="10"}
铝是面心立方，$a = 4.0495\ \text{Å}$。用Cu $K\alpha_1$辐射（$\lambda = 1.5406\ \text{Å}$）能观测到多少条不同的粉末谱线？（输入谱线条数。）
::: hint
找出使$\sin\theta \le 1$成立的最大$N = h^2 + k^2 + l^2$，然后数出不超过它的面心立方允许的$N$值。
:::
::: solution
$\sin^2\theta = \lambda^2N/4a^2 \le 1$要求$N \le (2a/\lambda)^2 = (8.099/1.5406)^2 = 27.6$。不超过27的面心立方允许值为3、4、8、11、12、16、19、20、24与27：**10**条谱线（从111一直到511/333——最后两条在$N = 27$处重合，合成一条线）。最后一条出现在$2\theta = 162.5^\circ$。
:::
:::

::: exercise 催化剂的谢乐尺寸 {level=2 check="34"}
载体上的铂粒子在$2\theta = 46.2^\circ$处给出200峰，样品宽化（仪器宽度已扣除）为$0.25^\circ$（Cu $K\alpha_1$，$K = 0.9$）。以纳米估计晶粒尺寸。（以nm输入尺寸，两位有效数字。）
::: solution
$\beta = 0.25\pi/180 = 4.363\times10^{-3}\ \mathrm{rad}$；$\theta = 23.1^\circ$，$\cos\theta = 0.9198$。$\tau = 0.9 \times 1.5406/(4.363\times10^{-3} \times 0.9198) = 345\ \text{Å} = 34\ \mathrm{nm}$。这种粒子的表面原子分数很小，催化化学家会瞄准几纳米的粒子，而那种粒子的峰要宽好几度。
:::
:::

::: exercise 体心还是初基？ {level=2}
某立方金属在$2\theta = 40.26^\circ$、$58.25^\circ$、$73.19^\circ$、$87.00^\circ$、$100.63^\circ$与$114.9^\circ$出现六条谱线（Cu $K\alpha_1$；算得的数值）。(a) 证明这些$\sin^2\theta$值之比为$1 : 2 : 3 : 4 : 5 : 6$。(b) 解释为什么单凭峰位无法区分初基与体心，而第七条谱线或密度可以做出裁决。(c) 设体心，求$a$，并在$\rho = 19.3\ \mathrm{g\,cm^{-3}}$下辨认这种金属。
::: solution
(a) $\sin^2\theta = 0.1185, 0.2369, 0.3554, 0.4738, 0.5923, 0.7107$，比值$1 : 2.000 : 3.000 : 4.000 : 5.00 : 6.00$。(b) 初基立方会把它们指标化为$N = 1, 2, 3, 4, 5, 6$（100…211）；体心则指标化为$N = 2, 4, 6, 8, 10, 12$（110…222）。下一条谱线可以分辨：体心给出$N = 14$（321），比值7；初基没有$N = 7$，其下一条谱线比值为8。强度也有帮助：初基金属应有一条很强的100线。(c) 体心，110：$a = \lambda\sqrt2/(2\sqrt{0.1185}) = 1.5406 \times 1.4142/(2 \times 0.3442) = 3.165\ \text{Å}$。取$Z = 2$，$M = \rho N_\mathrm{A}a^3/2 = 19.3 \times 6.022\times10^{23} \times 3.171\times10^{-23}/2 = 184\ \mathrm{g\,mol^{-1}}$：钨（$183.8$）。若为初基，$a = 2.238\ \text{Å}$、$Z = 1$，则$M$为$130\ \mathrm{g\,mol^{-1}}$，与任何具有初基立方结构的金属都不符（唯一采取初基立方结构的钋，$M = 209\ \mathrm{g\,mol^{-1}}$）：密度排除了初基的可能。
:::
:::

::: exercise GaAs中一个近乎消失的反射 {level=3 check="0.00195"}
砷化镓具有闪锌矿结构：F心立方晶胞中Ga在$(0, 0, 0)$，As在$(\tfrac14, \tfrac14, \tfrac14)$。(a) 用$f_\mathrm{Ga}$与$f_\mathrm{As}$表出$F_{111}$与$F_{200}$。(b) 把散射因子近似为电子数（31与33），求$\lvert F_{200}\rvert^2/\lvert F_{111}\rvert^2$。(c) 为什么这个比值在ZnS中大得多？（输入(b)的比值，三位有效数字。）
::: solution
(a) F心对指标不混杂的反射给出因子4。基元给出$f_\mathrm{Ga} + f_\mathrm{As}e^{\pi i(h+k+l)/2}$。对111，$e^{3\pi i/2} = -i$：$F_{111} = 4(f_\mathrm{Ga} - if_\mathrm{As})$，$\lvert F_{111}\rvert^2 = 16(f_\mathrm{Ga}^2 + f_\mathrm{As}^2)$。对200，$e^{\pi i} = -1$：$F_{200} = 4(f_\mathrm{Ga} - f_\mathrm{As})$。(b) $\lvert F_{200}\rvert^2/\lvert F_{111}\rvert^2 = (31 - 33)^2/(31^2 + 33^2) = 4/2050 = 0.00195$。GaAs的200反射极弱；它被用作外延层中Ga/As有序度的灵敏探针。(c) ZnS中$f_\mathrm{Zn} \approx 30$、$f_\mathrm{S} \approx 16$：$(14)^2/(30^2 + 16^2) = 0.17$，200清晰可见。"差"反射的强度度量的是两个格位散射本领之间的反差。
:::
:::

::: exercise 螺旋轴引起的消光 {level=3}
某晶体沿$b$有$2_1$螺旋轴：位于$(x, y, z)$的每个原子有一个伙伴位于$(-x, y + \tfrac12, -z)$。(a) 证明$k$为奇数的$0k0$反射消失。(b) 解释为什么一般的$hkl$反射并不消失。(c) 某单斜晶体的消光只出现在$k$为奇数的$0k0$与$l$为奇数的$h0l$。第二组消光由哪个对称元素引起？（空间群是非常常见的$P2_1/c$。）
::: solution
(a) $h = l = 0$时，原子对贡献$f\left[e^{2\pi iky} + e^{2\pi ik(y + 1/2)}\right] = fe^{2\pi iky}\left[1 + (-1)^k\right]$，$k$为奇数时为零。(b) 对一般的$hkl$，两个伙伴的$x$与$z$相位不同，即$e^{2\pi i(hx + lz)}$与$e^{-2\pi i(hx + lz)}$，方括号不是简单的$1 + (-1)^k$，不恒为零。只有在沿该轴的投影中$x$与$z$消失，两个伙伴才精确相消。(c) 垂直于$b$的$c$滑移面（先对$y = 0$的面反映，再沿$c/2$平移）把$(x, y, z)$变为$(x, -y, z + \tfrac12)$；$k = 0$时原子对给出$1 + (-1)^l$，故$l$为奇数的$h0l$消失。螺旋轴与滑移面只影响特殊行与特殊面上的反射，这正是它们的消光能辨认它们的原因。
:::

::: exercise 帕特森矢量 {level=3 check="0.25"}
在[[#ex-patterson]]中的一维晶体里，证明对两个原子有$\lvert F_h\rvert^2 = f_1^2 + f_2^2 + 2f_1f_2\cos[2\pi h(x_2 - x_1)]$，并由此说明$P(u)$在$u = 0$与$u = \pm(x_2 - x_1)$处有峰。对位于$x = 0.10$与$x = 0.35$的两个原子，给出小于$0.5$的正帕特森互矢量。（以晶胞的分数输入$u$。）
::: solution
$F_h = f_1e^{2\pi ihx_1} + f_2e^{2\pi ihx_2}$；乘以它的共轭，$\lvert F_h\rvert^2 = f_1^2 + f_2^2 + f_1f_2\left(e^{2\pi ih(x_2 - x_1)} + e^{-2\pi ih(x_2 - x_1)}\right) = f_1^2 + f_2^2 + 2f_1f_2\cos[2\pi h(x_2 - x_1)]$。常数项的傅里叶级式$\sum_h\cos(2\pi hu)$在$u = 0$（及其点阵重复）处是尖峰，而$\sum_h\cos[2\pi h(x_2 - x_1)]\cos(2\pi hu)$在$u = \pm(x_2 - x_1)$给出峰。此处$x_2 - x_1 = 0.25$，故互峰位于$u = 0.25$与$u = 0.75$。每一对原子给出一对帕特森峰；$n$个原子共有$n(n - 1)$个互峰，这就是帕特森法在少数重原子占主导的结构中最有效的缘故。
:::
