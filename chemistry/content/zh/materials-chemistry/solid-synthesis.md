在溶液化学中，把两种试剂混合，它们的分子在微秒之内就彼此接触。在固体化学中，把两种粉末混合，真正接触的只有晶粒相碰的那些点，每种反应物的原子必须穿过逐渐增厚的产物层才能相遇。像$\mathrm{MgO} + \mathrm{Al_2O_3} \rightarrow \mathrm{MgAl_2O_4}$这样的反应，在所有温度下热力学上都是下坡的，却只有在约$1200\,^\circ\mathrm{C}$以上才有可用的速率，而且往往仍需数天时间、多次重新研磨才能进行完全。制备无机固体的许多技艺，就在于绕开这个扩散瓶颈：在固体形成之前就在原子尺度上混合各元素，用溶剂或气体来传送原子，或者从气相把固体一层一层地搭建起来。

本章概览主要的路线。先讲传统的**陶瓷法**及使其缓慢的动力学，然后转向**溶液前驱体**与**溶胶-凝胶**工艺、在密闭容器中使用过热溶剂的**水热与溶剂热**合成，以及制备薄膜与涂层的**化学气相沉积**与原子层沉积。贯穿始终的问题是相同的：什么控制速率？什么控制产物的物相、组成与氧化态？什么控制颗粒的大小与形状？产物用[[materials-chemistry/diffraction]]的粉末衍射方法加以鉴定。

::: warning 固体实验需要指导与风险评估 {#warn-safety}
本章的计算都是纸面练习。真实的固体合成涉及在一切工作开始之前必须评估的危害：$1000\,^\circ\mathrm{C}$以上的炉子（烫伤，若附近有可燃物还会起火）；可吸入的细粉末，其中一些有毒（可溶性钡化合物、列为致癌物或致敏剂的镍与钴的氧化物，以及铅化合物）；密闭高压釜，装料过满或过热时会剧烈失效；溶胶-凝胶实验中易燃的醇与对水敏感的醇盐；以及气相沉积中剧毒、自燃或腐蚀性的前驱气体，如硅烷、砷化氢与氯化氢，它们只能在专门建造、配有监测的体系中操作。实验必须在指导下进行，配备适当的防护装备、排风设施和安全数据表。
:::

## 陶瓷法

制备复杂氧化物的经典做法，是按化学计量把二元氧化物、碳酸盐或硝酸盐一起研磨，将粉末压成压片，再在空气中（通常）于远低于任何组分熔点的温度下加热。碳酸盐与硝酸盐受热分解为活泼的氧化物（"煅烧"），放出$\mathrm{CO_2}$或$\mathrm{NO_x}$。由于产物层一旦把反应物隔开反应就会停止，压片要经冷却、重新研磨再加热，如此反复多次，并用粉末衍射跟踪反应进程，直到原料的谱线消失。

::: algorithm 陶瓷合成的规划 {#alg-ceramic}
1. **选择前驱体**：能干净地分解为氧化物（碳酸盐、草酸盐、硝酸盐、氢氧化物），且稳定到可以称量（不吸湿，或干燥后再称）。
2. **计算质量**：依配平方程计算，计入损失的气体（如$\mathrm{CO_2}$）与得到的气体（如金属被氧化时来自气氛的$\mathrm{O_2}$）。
3. **充分混合**：在玛瑙研钵或球磨机中研磨，常借助丙酮一类挥发性液体帮助混合；颗粒越细，扩散距离越短。
4. **煅烧**：在中等温度下分解前驱体，然后**压片**以增大晶粒间的接触面积。
5. **焙烧**：在高于最难熔反应物熔点约三分之二（经验性的塔曼规则）的温度下，在能设定所需氧化态的气氛（空气、氧气、氩气、$\mathrm{H_2/Ar}$，或密封管）中进行。
6. **反复研磨与焙烧**，直到粉末衍射显示单一物相；然后除结构外还要测定组成（氧含量用热重分析或滴定）。
:::

::: example 制备高温超导体YBa₂Cu₃O₇ {#ex-ybco}
$\mathrm{YBa_2Cu_3O_7}$由$\mathrm{Y_2O_3}$、$\mathrm{BaCO_3}$与$\mathrm{CuO}$在空气中焙烧、最后在氧气中退火而得。(a) 写出配平方程，计算制得$10.0\ \mathrm{g}$产物所需三种前驱体的质量。(b) 损失多少克$\mathrm{CO_2}$？吸收多少克$\mathrm{O_2}$？
::: solution
(a) 氧化物提供$\tfrac12\mathrm{Y_2O_3} + 2\mathrm{BaO} + 3\mathrm{CuO} = \mathrm{YBa_2Cu_3O_{6.5}}$，所以每个化学式单位还有一个氧原子必须来自气体：
$$
\tfrac12\,\mathrm{Y_2O_3} + 2\,\mathrm{BaCO_3} + 3\,\mathrm{CuO} + \tfrac14\,\mathrm{O_2} \rightarrow \mathrm{YBa_2Cu_3O_7} + 2\,\mathrm{CO_2}.
$$
$M(\mathrm{YBa_2Cu_3O_7}) = 88.906 + 2(137.327) + 3(63.546) + 7(15.999) = 666.19\ \mathrm{g\,mol^{-1}}$，所以$10.0\ \mathrm{g}$是$0.015011\ \mathrm{mol}$。于是$\mathrm{Y_2O_3}$：$\tfrac12 \times 0.015011 \times 225.81 = 1.695\ \mathrm{g}$；$\mathrm{BaCO_3}$：$2 \times 0.015011 \times 197.33 = 5.924\ \mathrm{g}$；$\mathrm{CuO}$：$3 \times 0.015011 \times 79.545 = 3.582\ \mathrm{g}$。(b) $\mathrm{CO_2}$：$2 \times 0.015011 \times 44.009 = 1.321\ \mathrm{g}$；$\mathrm{O_2}$：$\tfrac14 \times 0.015011 \times 31.998 = 0.120\ \mathrm{g}$。核对：$1.695 + 5.924 + 3.582 + 0.120 - 1.321 = 10.000\ \mathrm{g}$。

氧含量是微妙之处。在焙烧温度（约$930\,^\circ\mathrm{C}$）下，平衡产物接近$\mathrm{YBa_2Cu_3O_{6.3}}$，四方相，不超导；在约$450\,^\circ\mathrm{C}$的氧气中缓冷或退火，把Cu–O链上的氧格位填满，得到正交相$\mathrm{YBa_2Cu_3O_{7-\delta}}$（$\delta \approx 0.05$），它在$92\ \mathrm{K}$以下超导。这就是把[[materials-chemistry/defects#prop-brouwer]]的缺陷平衡用作合成手段。（碳酸钡吞食有害；实验须按上文进行风险评估。）
:::

### 固相反应为什么慢

::: proposition 产物层的抛物线生长 {#prop-parabolic}
当一块平面产物层隔开两种反应物、其生长受离子在层内扩散控制时，厚度$x$随时间的增长规律是
$$
x^2 = 2k_\mathrm{p}t,
$$ {#eq-parabolic}
其中**抛物线速率常数**$k_\mathrm{p}$与穿越该层的最慢必需组分的扩散系数成正比，因而服从阿伦尼乌斯定律$k_\mathrm{p} = k_0\exp(-E_\mathrm{a}/RT)$。这一定律假定两个界面处都是局部平衡（因此那里的浓度固定）、扩散系数恒定、几何为平面；对被消耗的球形颗粒，应采用扬德（Jander）方程或金斯特林格-布劳恩斯坦（Ginstling–Brounshtein）方程一类修正。
:::

::: proof
两界面处浓度$c_1$与$c_2$固定时，准稳态下厚度为$x$的层中的浓度梯度为$(c_1 - c_2)/x$，由菲克第一定律，穿过它的通量为$J = D(c_1 - c_2)/x$。每个穿层的离子都在远侧界面反应，每个离子贡献固定体积$\Omega$的产物，所以$dx/dt = \Omega J = \Omega D(c_1 - c_2)/x$。记$k_\mathrm{p} = \Omega D(c_1 - c_2)$，则$x\,dx/dt = k_\mathrm{p}$，从$t = 0$时$x = 0$积分，得$\tfrac12x^2 = k_\mathrm{p}t$。层越厚速率越慢，是因为驱动扩散的梯度按$1/x$下降。既然$D$是被激活的（[[materials-chemistry/defects#prop-nernst-einstein]]），$k_\mathrm{p}$也是。
:::

由此得出两条实用规则。把颗粒尺寸减半，反应完全所需的时间降为四分之一——这就是细磨与反复重磨（它同时打断产物层、暴露出新鲜反应物）如此要紧的原因。而温度以指数方式起作用：取阳离子在氧化物中扩散的典型值$E_\mathrm{a} = 300\ \mathrm{kJ\,mol^{-1}}$，温度从$1200$升到$1300\,^\circ\mathrm{C}$，$k_\mathrm{p}$增大约4.7倍。

尖晶石生成的机理由卡尔·瓦格纳（Carl Wagner）在1930年代阐明，它显示反应如何在两个界面上分担。氧离子几乎不动；动的是$\mathrm{Mg^{2+}}$与$\mathrm{Al^{3+}}$，它们方向相反地穿过尖晶石层，每两个$\mathrm{Al^{3+}}$对应三个$\mathrm{Mg^{2+}}$以保持层内电中性。在MgO/尖晶石界面，$2\mathrm{Al^{3+}} + 4\mathrm{MgO} \rightarrow \mathrm{MgAl_2O_4} + 3\mathrm{Mg^{2+}}$；在尖晶石/$\mathrm{Al_2O_3}$界面，$3\mathrm{Mg^{2+}} + 4\mathrm{Al_2O_3} \rightarrow 3\mathrm{MgAl_2O_4} + 2\mathrm{Al^{3+}}$。在氧化铝一侧生长的尖晶石是在氧化镁一侧的三倍，这一预言被界面标记实验证实。

caption: 扩散限制的抛物线生长下产物层厚度（以μm计）对时间$x$（以小时计）的曲线，[[#eq-parabolic]]，速率常数$k_\mathrm{p} = k\ \mathrm{\mu m^2\,h^{-1}}$（滑条），并与一个假想的、初始量级相同的线性规律比较。抛物线生长先快后慢：长出一层所需的时间正比于其厚度的平方。对$20\ \mathrm{\mu m}$的反应物晶粒，取$k = 2$，吞掉一个晶粒需要几天；对$1\ \mathrm{\mu m}$的晶粒只需几分钟。这一标度关系正是下文一切"软"合成路线的中心论据。

::: example 要慢多久？ {#ex-parabolic}
$1300\,^\circ\mathrm{C}$下NiO与$\mathrm{Al_2O_3}$压片之间的反应在$10\ \mathrm{h}$内生成$5.0\ \mathrm{\mu m}$厚的尖晶石层。(a) 长出$20\ \mathrm{\mu m}$的层要多久？(b) 若活化能为$300\ \mathrm{kJ\,mol^{-1}}$，在$1200\,^\circ\mathrm{C}$下长出$5.0\ \mathrm{\mu m}$的层要多久？
::: solution
(a) $t \propto x^2$，所以$t = 10\ \mathrm{h} \times (20/5.0)^2 = 160\ \mathrm{h}$，将近一周。(b) $k_\mathrm{p}(1473\ \mathrm{K})/k_\mathrm{p}(1573\ \mathrm{K}) = \exp[-(300\,000/8.314)(1/1473 - 1/1573)] = \exp(-1.557) = 0.211$，所以时间变为$10/0.211 = 47\ \mathrm{h}$。降温$100\ \mathrm{K}$的代价几乎是五倍——这就是陶瓷合成要在产物的挥发性与稳定性允许的尽可能高的温度下进行的原因。
:::
:::

### 氧化态的控制

焙烧时的气氛决定氧的化学势，从而决定变价金属的氧化态。在空气中焙烧（$p_{\mathrm{O_2}} = 0.21\ \mathrm{bar}$）得到$\mathrm{Fe^{3+}}$、$\mathrm{Mn^{3+}/Mn^{4+}}$与$\mathrm{Co^{2+}/Co^{3+}}$的混合；在流动的$\mathrm{H_2/Ar}$、$\mathrm{CO/CO_2}$或$\mathrm{H_2/H_2O}$混合气中焙烧——它们的平衡把$p_{\mathrm{O_2}}$固定在选定的值上，可低到$10^{-20}\ \mathrm{bar}$以下——稳定较低的氧化态。所需的$p_{\mathrm{O_2}}$可由竞争氧化物的吉布斯自由能读出，就像在埃林汉姆（Ellingham）图上那样（[[main-group/inorganic-redox]]）。含低价金属的化合物，如电池用的$\mathrm{LiFePO_4}$或$\mathrm{Eu^{2+}}$掺杂的荧光粉，必须在还原性气体中或抽真空封接的石英管中制备；异常高氧化态的化合物，如富氧的$\mathrm{La_2NiO_4}$或铁(IV)酸盐，则需要高压氧气或电化学氧化。

## 软化学：原子尺度的混合

如果反应物在固体形成之前就已在原子水平上混合，扩散距离就从微米降到纳米，反应温度下降几百度，产物可以以细密、均匀的粉末得到，而且常常是陶瓷法无法达到的亚稳相。法国化学家把这一思路称为*chimie douce*，软化学。

**共沉淀**把全部阳离子从其盐的溶液中一起沉淀为氢氧化物、草酸盐或碳酸盐；将沉淀加热即得氧化物。铁氧体与荧光粉用的钇铝石榴石就是这样制备的。它的弱点是不同阳离子在不同pH下沉淀，沉淀可能不均匀。**佩基尼**（Pechini）法或柠檬酸法避开了这一点：用柠檬酸螯合阳离子，再用乙二醇把溶液聚合成树脂，阳离子以固定比例被锁在其中；烧去有机物质即得细密的复合氧化物。**拓扑定位**（topotactic）反应在保留骨架的前提下改造既有固体：层状氧化物中的离子交换、锂嵌入$\mathrm{TiS_2}$或石墨，或脱嵌得到本来无法获得的相，如$\mathrm{Li_{0.5}CoO_2}$（[[materials-chemistry/energy-materials]]）。

### 溶胶-凝胶工艺

::: definition 溶胶-凝胶工艺 {#def-sol-gel}
在**溶胶-凝胶**工艺中，分子前驱体——通常是金属醇盐$\mathrm{M(OR)}_n$，如正硅酸四乙酯（TEOS，$\mathrm{Si(OC_2H_5)_4}$）——在溶液中经两步反应转化为氧化物网络：
$$
\begin{aligned}
&\text{水解：} && \equiv\mathrm{Si{-}OR} + \mathrm{H_2O} \rightarrow \equiv\mathrm{Si{-}OH} + \mathrm{ROH},\\
&\text{缩合：} && \equiv\mathrm{Si{-}OH} + \mathrm{HO{-}Si}\equiv \rightarrow \equiv\mathrm{Si{-}O{-}Si}\equiv + \mathrm{H_2O} \quad (\text{或} + \mathrm{ROH}).
\end{aligned}
$$
缩合先生成悬浮在液体中的胶体颗粒或支化低聚物（**溶胶**）；继续连接便得到跨越整个容器的网络（**凝胶**），这一时刻称为**凝胶点**，粘度在此发散。干燥凝胶得到**干凝胶**（伴随收缩，且往往开裂）；若以超临界方式除去液体、不形成液-气弯月面，则得到极低密度的**气凝胶**。加热可把二者之一变为致密的玻璃或陶瓷。TEOS的总反应是$\mathrm{Si(OC_2H_5)_4} + 2\,\mathrm{H_2O} \rightarrow \mathrm{SiO_2} + 4\,\mathrm{C_2H_5OH}$。
:::

两步反应都由酸或碱催化，而催化剂决定织构。酸催化下水解快、缩合慢且倾向发生在链端，得到弱支化的聚合物状网络与细孔、致密的凝胶。碱催化下缩合在酸性更强、缩合程度更高的硅中心上更快，于是颗粒靠向已有团簇添加单体而生长，得到致密的胶体球（这是维尔纳·施特伯（Werner Stöber）1968年制备单分散二氧化硅球方法的基础），凝胶也更疏松多孔。比值$R = [\mathrm{H_2O}]/[\mathrm{Si}]$同样要紧：$R = 2$是化学计量下限，$R$更大有利于在缩合之前水解完全。过渡金属（Ti、Zr、Al）的醇盐比硅醇盐水解快得多，因为金属电正性更强、且能提高配位数，所以要用乙酰丙酮或乙酸一类螯合配体来加以缓和。

溶胶-凝胶化学可制备光学涂层与增透膜、二氧化硅气凝胶隔热材料（密度低到几$\mathrm{mg\,cm^{-3}}$）、多孔催化剂载体、生物活性玻璃，以及许多陶瓷纤维的前驱体。它的优点是温度低、纯度高，且能浇铸薄膜、纤维与整体块体；缺点是成本高、干燥时收缩、残留羟基或碳。

::: example 从TEOS能得到多少二氧化硅？ {#ex-teos}
用$10.0\ \mathrm{cm^3}$ TEOS（密度$0.933\ \mathrm{g\,cm^{-3}}$）配制溶胶。(a) 完全转化后得到多少克$\mathrm{SiO_2}$？(b) $R = 4$时需要多少体积的水？为什么加入乙醇作共溶剂？
::: solution
(a) $M(\mathrm{TEOS}) = 28.085 + 4(2 \times 12.011 + 5 \times 1.008 + 15.999) = 208.33\ \mathrm{g\,mol^{-1}}$。取料$9.33\ \mathrm{g}$，即$0.04478\ \mathrm{mol}$，得$0.04478 \times 60.08 = 2.69\ \mathrm{g}$ $\mathrm{SiO_2}$，只有前驱体质量的29 %：巨大的质量损失及随之而来的体积收缩是溶胶-凝胶工艺固有的。(b) $R = 4$意味着$0.179\ \mathrm{mol}$水，即$3.23\ \mathrm{g}$或$3.2\ \mathrm{cm^3}$。TEOS与水不互溶；乙醇本身也是产物，它使混合物均一，于是水解从一开始就发生在整个液体中，而不仅限于界面。
:::
:::

## 水热与溶剂热合成

许多在室温下不溶于水的氧化物、硅酸盐及其他固体，在$100\,^\circ\mathrm{C}$以上加压的水中却明显溶解，尤其当存在能形成可溶配合物的**矿化剂**（氢氧化物、氟化物或碳酸盐）时。在**水热**合成中，反应物与水被密封在高压釜——一种钢制容器，内衬通常为聚四氟乙烯（约$250\,^\circ\mathrm{C}$以下）或贵金属——中加热。物质在溶解度较大处溶解，在溶解度较小处结晶，往往得到完好晶形的晶体；改用其他溶剂（醇、胺、离子液体）时，该方法称为**溶剂热**。石英、许多沸石与宝石晶体等天然矿物就是这样在地壳中形成的；工业上每年在大型高压釜中生长数吨用于振荡器的合成石英晶体。

水的性质随温度剧变。相对介电常数从$25\,^\circ\mathrm{C}$的$78$降到$200\,^\circ\mathrm{C}$的约$35$，到临界点（$374\,^\circ\mathrm{C}$，$22.1\ \mathrm{MPa}$）附近降到$10$以下，于是它对共物种成为好得多的溶剂；离子积在约$250\,^\circ\mathrm{C}$升到约$10^{-11}$，使它同时具有更强的酸性与碱性；粘度下降，加快了传质。在密闭容器中，只要有液体存在，压力就是液体在反应温度下的蒸气压；若装液过满，液体膨胀充满容器，压力便以极陡的斜率攀升。这就是高压釜装液不超过约三分之二、且绝不在额定温度以上加热的原因。

::: example 水热高压釜中的压力 {#ex-autoclave}
用克劳修斯-克拉佩龙方程并取$\Delta_\mathrm{vap}H = 40.7\ \mathrm{kJ\,mol^{-1}}$（正常沸点下的值），估算保持在$200\,^\circ\mathrm{C}$、装液正确的高压釜中的压力，并与该温度下水的实测蒸气压$1.55\ \mathrm{MPa}$比较。
::: solution
从正常沸点（$T_1 = 373.15\ \mathrm{K}$时$p_1 = 1.013\ \mathrm{bar}$）出发，
$$
\ln\frac{p_2}{p_1} = -\frac{\Delta_\mathrm{vap}H}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right) = -\frac{40\,700}{8.314}\left(\frac{1}{473.15} - \frac{1}{373.15}\right) = 2.773,
$$
所以$p_2 = 1.013 \times e^{2.773} = 16.2\ \mathrm{bar} = 1.6\ \mathrm{MPa}$，与实测的$1.55\ \mathrm{MPa}$很接近。符合得这么好部分是巧合：$\Delta_\mathrm{vap}H$随温度降低（在$200\,^\circ\mathrm{C}$为$34.9\ \mathrm{kJ\,mol^{-1}}$），而且蒸气并不理想。$250\,^\circ\mathrm{C}$时同一估计给出$4.4\ \mathrm{MPa}$，实测为$4.0\ \mathrm{MPa}$；误差朝临界点增大，在临界点方程完全失效（[[thermodynamics/phase-equilibria]]）。
:::
:::

水热化学是制备**沸石**（[[materials-chemistry/porous-materials]]中的微孔铝硅酸盐）的路线：沸石在$80$–$200\,^\circ\mathrm{C}$的碱性铝硅酸盐凝胶中、围绕充当孔模板的有机或无机阳离子结晶；也是制备多数**金属有机框架**的路线——它们在二甲基甲酰胺或醇中溶剂热合成；还是制备形状可控的氧化物纳米晶（如$\mathrm{TiO_2}$、ZnO与$\mathrm{BaTiO_3}$）的路线——用能与特定晶面结合的添加剂可以引导其结晶（[[materials-chemistry/nanomaterials]]）。由于产物在不足以使其重排的低温下形成，水热合成常常得到**亚稳**相：产物是成核最快的那个，未必是最稳定的那个（奥斯特瓦尔德阶段规则）。

::: quiz
哪些改变预期会加快两种氧化物粉末之间生成扩散限制产物层的固相反应？
- [x] 把反应物磨到更小的颗粒尺寸
- [x] 提高反应温度
- [ ] 减轻压片时的压力
- [x] 对部分反应的混合物重新研磨
- [ ] 在颗粒尺寸不变的情况下把两种反应物的质量加倍
::: solution
抛物线动力学使吞掉一个晶粒的时间正比于扩散距离的平方，所以小颗粒帮助极大；温度使扩散系数指数增大；重新研磨打碎产物层、创造新的接触。压得更松会减少晶粒间的接触面积，使反应变慢。在颗粒尺寸不变时放大投料量，既不改变扩散距离，也不改变单个晶粒的速率。
:::

## 气相方法

### 化学气相沉积

在**化学气相沉积**（CVD）中，挥发性前驱体在加热的衬底上反应，沉积出固体薄膜，气相副产物则被抽走。例子有：硅烷或三氯硅烷制硅（$\mathrm{SiHCl_3} + \mathrm{H_2} \rightarrow \mathrm{Si} + 3\,\mathrm{HCl}$，多晶硅的西门子法）、微电子用的氮化硅与二氧化硅薄膜、刀具上TiN与TiC的硬质涂层、氢气中甲烷经等离子体活化的金刚石薄膜，以及由金属有机物生长的LED用III–V族半导体层（金属有机CVD，例如$\mathrm{Ga(CH_3)_3} + \mathrm{NH_3} \rightarrow \mathrm{GaN} + 3\,\mathrm{CH_4}$）。这些前驱体中有许多是有毒、自燃或有腐蚀性的，工业CVD设备都配有气体检测、尾气洗涤与联锁装置。

::: proposition CVD中的表面反应限制与传质限制 {#prop-grove}
若前驱体经质量传递系数为$h_\mathrm{g}$的气体边界层到达表面，并在表面上以一级速率常数$k_\mathrm{s}$反应，则对气相前驱体浓度$c_\mathrm{g}$，稳态沉积通量为
$$
J = \frac{k_\mathrm{s}h_\mathrm{g}}{k_\mathrm{s} + h_\mathrm{g}}\,c_\mathrm{g}, \qquad \frac{1}{J} = \frac{1}{c_\mathrm{g}}\left(\frac{1}{k_\mathrm{s}} + \frac{1}{h_\mathrm{g}}\right).
$$ {#eq-grove}
低温下$k_\mathrm{s} \ll h_\mathrm{g}$，$J \approx k_\mathrm{s}c_\mathrm{g}$：生长为**表面反应限制**，对温度强烈依赖（阿伦尼乌斯，$k_\mathrm{s} = A e^{-E_\mathrm{a}/RT}$），且在衬底上均匀。高温下$k_\mathrm{s} \gg h_\mathrm{g}$，$J \approx h_\mathrm{g}c_\mathrm{g}$：生长为**传质限制**，几乎与温度无关，却对气体流量与反应器几何敏感。（这是格鲁夫（Grove）模型；它假定一级表面动力学且不发生气相反应。）
:::

::: proof
稳态下，通过边界层的通量$h_\mathrm{g}(c_\mathrm{g} - c_\mathrm{s})$（$c_\mathrm{s}$是表面处的浓度）等于表面反应速率$k_\mathrm{s}c_\mathrm{s}$。解得$c_\mathrm{s} = h_\mathrm{g}c_\mathrm{g}/(k_\mathrm{s} + h_\mathrm{g})$，且$J = k_\mathrm{s}c_\mathrm{s} = k_\mathrm{s}h_\mathrm{g}c_\mathrm{g}/(k_\mathrm{s} + h_\mathrm{g})$。两个步骤像串联的电阻$1/k_\mathrm{s}$与$1/h_\mathrm{g}$，大的那个电阻控制速率。略去较小各项即得两个极限。
:::

### 原子层沉积

**原子层沉积**（ALD）把一个CVD反应拆成在时间上分离的两个半反应。以氧化铝为例：一次三甲基铝脉冲与表面羟基反应，直到羟基耗尽，$\equiv\mathrm{OH} + \mathrm{Al(CH_3)_3} \rightarrow \equiv\mathrm{O{-}Al(CH_3)_2} + \mathrm{CH_4}$；吹扫除去多余的前驱体；再通一次水脉冲，把甲基转化为羟基，$\equiv\mathrm{Al{-}CH_3} + \mathrm{H_2O} \rightarrow \equiv\mathrm{Al{-}OH} + \mathrm{CH_4}$；然后循环重复。因为每个半反应都是**自限制**的——表面位点饱和即停止——每个循环都沉积同样的量（约$0.1\ \mathrm{nm}$的$\mathrm{Al_2O_3}$，不足一个单分子层），与前驱体剂量和表面形状无关。ALD能以亚纳米级的厚度控制保形地覆盖深沟与多孔固体，这就是现代晶体管的高介电常数栅介质（$\mathrm{HfO_2}$）用它制备的原因。它的缺点是速度：超过约$100\ \mathrm{nm}$的薄膜需要很长时间。图莫·松托拉（Tuomo Suntola）1970年代在芬兰发展了这一方法（当时称"原子层外延"），苏联独立进行的"分子层叠"工作则可上溯到1960年代。

其他不依赖化学反应的气相方法：**物理气相沉积**（蒸发或溅射）、**分子束外延**（在超高真空中一层原子面一层原子面地生长半导体层），以及**化学气相传输**——借助碘一类输运剂，经由可逆反应沿温度梯度把固体从密封管的一端运到另一端，从而生长单晶（例如$\mathrm{ZrS_2}$或$\mathrm{Fe_3O_4}$）。

## 单晶生长

物理测量与单晶衍射需要晶体，器件则需要又大又完美的晶体。**切克劳斯基**（Czochralski）法（直拉法）从熔体中缓慢上提旋转的籽晶；几乎全部芯片用硅都这样生长，圆棒直径达$300\ \mathrm{mm}$、长两米，原料经区域熔炼后杂质低于十亿分之一。**助熔剂法**把组分溶入熔融的盐或氧化物（PbO、$\mathrm{B_2O_3}$、碱金属卤化物），在低于产物熔点的温度下缓冷使其结晶。**浮区**炉用聚焦光在多晶棒上熔化一个小熔区并沿棒移动，从而完全不用坩埚。维尔纳伊（Verneuil）1902年引入的焰熔法，使合成红宝石与蓝宝石成为最早商业合成的宝石。

::: summary
- 陶瓷法把充分混合的前驱体加热到远低于其熔点的温度；反应要求离子扩散穿过产物层，所以缓慢，需要细磨、压片、高温与反复研磨。
- 扩散限制的层按抛物线规律生长，$x^2 = 2k_\mathrm{p}t$，$k_\mathrm{p}$服从阿伦尼乌斯定律；反应完全的时间正比于颗粒尺寸的平方。
- 焙烧气氛固定氧的化学势，从而决定氧化态与氧含量（$\mathrm{YBa_2Cu_3O_7}$需要氧退火）。
- 软化学路线（共沉淀、柠檬酸/佩基尼法、拓扑定位反应、溶胶-凝胶）在原子尺度上混合组分，降低温度，得到细密或亚稳的产物。
- 溶胶-凝胶化学经酸或碱催化的醇盐水解与缩合先成溶胶、再成凝胶，干燥成干凝胶或气凝胶。
- 水热与溶剂热合成在密闭高压釜中使用高于自身沸点的溶剂，其中溶解度与传质都增大；产物有沸石、MOF、石英与纳米晶，且常为亚稳相。
- CVD由反应蒸气生长薄膜：低温下表面反应限制，高温下传质限制（格鲁夫模型）；ALD用自限制的半反应获得厚度控制达亚纳米的保形膜。
:::

氧化铝的熔点为$2345\ \mathrm{K}$。用经验性的塔曼规则估计它在固相反应中开始以可用速率反应的最低温度。（以K输入温度。）

::: exercise 称取钛酸锶 {level=1 check="4.023"}
制备$5.00\ \mathrm{g}$的$\mathrm{SrTiO_3}$需要多少克$\mathrm{SrCO_3}$与$\mathrm{TiO_2}$？（以g输入$\mathrm{SrCO_3}$的质量，四位有效数字。）
::: solution
$\mathrm{SrCO_3} + \mathrm{TiO_2} \rightarrow \mathrm{SrTiO_3} + \mathrm{CO_2}$。$M(\mathrm{SrTiO_3}) = 183.48\ \mathrm{g\,mol^{-1}}$，所以$n = 5.00/183.48 = 0.02725\ \mathrm{mol}$。$\mathrm{SrCO_3}$：$0.02725 \times 147.63 = 4.023\ \mathrm{g}$；$\mathrm{TiO_2}$：$0.02725 \times 79.87 = 2.176\ \mathrm{g}$。
:::

::: exercise 焙烧失重 {level=1 check="1.199"}
对上一题的混合物，完全反应时损失多少克$\mathrm{CO_2}$？这占初始质量的百分之几？（以g输入$\mathrm{CO_2}$的质量，四位有效数字。）
::: solution
$0.02725 \times 44.009 = 1.199\ \mathrm{g}$，占初始质量的$1.199/(4.023 + 2.176) = 19.3\ \%$。焙烧前后称量压片，是检验碳酸盐是否完全分解的简便方法。

::: exercise 瓦格纳比率 {level=2 check="3"}
在$\mathrm{MgAl_2O_4}$经由$\mathrm{Mg^{2+}}$与$\mathrm{Al^{3+}}$反方向扩散（氧离子不动）的生成中，证明尖晶石/$\mathrm{Al_2O_3}$界面生成的尖晶石与MgO/尖晶石界面生成的尖晶石之比为3。（输入比值。）
::: solution
通量的电荷中性要求每有$2\mathrm{Al^{3+}}$向一个方向移动，就有$3\mathrm{Mg^{2+}}$向另一个方向移动（两侧各为$+6$）。在MgO一侧，到达的$2\mathrm{Al^{3+}}$发生反应：$2\mathrm{Al^{3+}} + 4\mathrm{MgO} \rightarrow \mathrm{MgAl_2O_4} + 3\mathrm{Mg^{2+}}$，生成一个化学式单位。在$\mathrm{Al_2O_3}$一侧，到达的$3\mathrm{Mg^{2+}}$发生反应：$3\mathrm{Mg^{2+}} + 4\mathrm{Al_2O_3} \rightarrow 3\mathrm{MgAl_2O_4} + 2\mathrm{Al^{3+}}$，生成三个化学式单位。比值为3 : 1；原始界面（例如用惰性铂丝标记）最终落在尖晶石层中距MgO一侧四分之一处。
:::
:::

::: exercise ALD循环 {level=2 check="182"}
某ALD工艺每个循环沉积$0.11\ \mathrm{nm}$的$\mathrm{Al_2O_3}$。沉积$20\ \mathrm{nm}$的薄膜需要多少个循环？若一个循环（两个脉冲与两次吹扫）历时$4.0\ \mathrm{s}$，需要多长时间？（循环数向上取整后输入。）
::: solution
$20/0.11 = 181.8$，所以$182$个循环；时间$182 \times 4.0\ \mathrm{s} = 728\ \mathrm{s}$，约$12\ \mathrm{min}$。$1\ \mathrm{\mu m}$的膜约需$9100$个循环，即十个小时——这就是ALD只留给极薄保形层的原因。
:::
:::

::: exercise 溶胶-凝胶的水 {level=2 check="1.61"}
把$0.0448\ \mathrm{mol}$的TEOS完全转化为$\mathrm{SiO_2}$，净消耗多少克水？解释为什么仅水解一步就需要这个量的两倍。（以g输入净消耗的水，三位有效数字。）
::: solution
净反应：$\mathrm{Si(OEt)_4} + 2\mathrm{H_2O} \rightarrow \mathrm{SiO_2} + 4\mathrm{EtOH}$，所以$2 \times 0.0448 \times 18.015 = 1.61\ \mathrm{g}$。完全水解$\mathrm{Si(OEt)_4} + 4\mathrm{H_2O} \rightarrow \mathrm{Si(OH)_4} + 4\mathrm{EtOH}$用去四个水分子，但$\mathrm{Si(OH)_4}$缩合为$\mathrm{SiO_2}$时又放出两个。这就是$R = 2$是化学计量下限、且$R < 4$的溶胶在过程很靠后仍残留未水解醇盐基团的原因。
:::
:::

::: exercise 传质何时接管？ {level=3 check="944"}
某CVD反应器的表面速率常数为$k_\mathrm{s} = 2.0\times10^8\exp(-E_\mathrm{a}/RT)\ \mathrm{cm\,s^{-1}}$，$E_\mathrm{a} = 150\ \mathrm{kJ\,mol^{-1}}$，质量传递系数为$h_\mathrm{g} = 1.0\ \mathrm{cm\,s^{-1}}$（示例数值）。(a) 两者相等是在什么温度？(b) 从$900$到$1000\ \mathrm{K}$，沉积速率变为多少倍？（以K输入(a)的温度，三位有效数字。）
::: hint
令$k_\mathrm{s} = h_\mathrm{g}$解出$T$；(b)在两个温度下分别计算[[#eq-grove]]。
:::
::: solution
(a) $2.0\times10^8 e^{-E_\mathrm{a}/RT} = 1.0$给出$E_\mathrm{a}/RT = \ln(2.0\times10^8) = 19.11$，所以$T = 150\,000/(8.314 \times 19.11) = 944\ \mathrm{K}$。(b) $900\ \mathrm{K}$时：$k_\mathrm{s} = 2.0\times10^8 e^{-20.05} = 0.393\ \mathrm{cm\,s^{-1}}$，$k_\mathrm{s}h_\mathrm{g}/(k_\mathrm{s} + h_\mathrm{g}) = 0.393/1.393 = 0.282$。$1000\ \mathrm{K}$时：$k_\mathrm{s} = 2.0\times10^8e^{-18.04} = 2.92$，$2.92/3.92 = 0.745$。速率上升$2.6$倍，而表面速率常数单独上升$7.4$倍：在交点附近，传质已经开始抑制温度的影响。
:::
:::

::: exercise 更热的高压釜 {level=3 check="4.4"}
(a) 用克劳修斯-克拉佩龙方程并取$\Delta_\mathrm{vap}H = 40.7\ \mathrm{kJ\,mol^{-1}}$，估算$250\,^\circ\mathrm{C}$下水的蒸气压。(b) 实测值为$3.98\ \mathrm{MPa}$。解释误差的符号。(c) 为什么高压釜不能装满液体？（以MPa输入估计值，两位有效数字。）
::: solution
(a) $\ln(p/1.013\ \mathrm{bar}) = -(40\,700/8.314)(1/523.15 - 1/373.15) = 3.762$，$p = 1.013 \times 43.0 = 43.6\ \mathrm{bar} = 4.4\ \mathrm{MPa}$。(b) 估计偏高，因为$\Delta_\mathrm{vap}H$随温度减小（$250\,^\circ\mathrm{C}$时约$34\ \mathrm{kJ\,mol^{-1}}$）；使用沸点数值会夸大$\ln p$上升的快慢。(c) 液态水受热膨胀（$25$至$250\,^\circ\mathrm{C}$之间密度从$1.00$降到$0.80\ \mathrm{g\,cm^{-3}}$）。若它充满容器，就没有蒸气空间，压力将由液体的压缩决定——每升高一开尔文攀升多个兆帕，直至容器失效。因此高压釜的装液量要远低于液体在工作温度下所占的体积。

::: exercise 晶粒尺寸减半 {level=2 check="0.25"}
平均晶粒半径$10\ \mathrm{\mu m}$的粉末间的固相反应在$40\ \mathrm{h}$内完成。假定抛物线动力学，且完成反应要求产物层长到晶粒半径，半径$5\ \mathrm{\mu m}$的晶粒需要这一时间的几分之几？（输入该分数。）
::: solution
$t \propto x^2$，所以$t(5\ \mathrm{\mu m})/t(10\ \mathrm{\mu m}) = (5/10)^2 = 0.25$，即$10\ \mathrm{h}$。若降到$0.1\ \mathrm{\mu m}$（如溶胶-凝胶或共沉淀前驱体），同一温度下的时间将缩短$10^4$倍至约$15\ \mathrm{s}$，或者可以在低得多的温度下进行。
