一克好的金属有机框架（MOF）拥有数千平方米的内表面积，比一个足球场还大，却折叠在可以用指尖托起的晶体里。一克沸石A——那种被添加进许多洗衣粉的铝硅酸盐——能从硬水中除去约一百毫克钙。汽车油箱里的汽油，几乎可以肯定在炼油厂里流经过某种沸石催化剂，重质油在仅比分子本身宽一点点的孔道内被裂解成较小的分子。在所有这些材料中，固体有用的部分恰恰是不存在的那部分：原子之间规则的空隙。

本章讲的就是这类**多孔固体**。先从孔的分类和**沸石**的结构化学讲起——沸石是结晶型铝硅酸盐，骨架由共顶角的四面体搭成——并解释它们的离子交换、分子筛分与酸催化。然后转向由金属簇与有机连接体搭建、并以所谓网状化学的设计策略构建的**金属有机框架**（MOF），以及有序介孔固体。后半部分建立表征和使用孔隙率所需的物理化学：朗缪尔（Langmuir）与BET吸附等温式、表面积的测定，以及由开尔文（Kelvin）方程描述的介孔中的毛细凝聚。

## 孔及其分类

::: definition 孔隙率与孔径 {#def-pores}
多孔固体含有可被外部分子进入的空腔、孔道或间隙。IUPAC按孔宽$w$（圆柱形孔的直径，或狭缝孔两壁之间的距离）把孔分类：
- **微孔**，$w < 2\ \mathrm{nm}$（沸石、多数MOF、活性炭）；
- **介孔**，$2\ \mathrm{nm} \le w \le 50\ \mathrm{nm}$（MCM-41与SBA-15二氧化硅，许多凝胶和催化剂载体）；
- **大孔**，$w > 50\ \mathrm{nm}$。

**比表面积**$a_\mathrm{s}$是单位质量的可用表面积，以$\mathrm{m^2\,g^{-1}}$计；**比孔体积**是单位质量的孔体积，以$\mathrm{cm^3\,g^{-1}}$计；**孔隙率**是孔占总体积的分数。
:::

这些界限并非随意划定。在微孔中，两侧孔壁距离之近使它们的吸引势相互重叠，所以吸附被强烈增强，孔在极低的压力下就已被填满。在介孔中，孔壁上的吸附膜与蒸气判然可分，孔按照依赖于其尺寸的压力经毛细凝聚而被填满。大孔的行为几乎同于开放表面。

## 沸石

::: definition 沸石的组成与洛文斯坦规则 {#def-zeolite}
**沸石**是结晶型铝硅酸盐，其骨架由$\mathrm{SiO_4}$与$\mathrm{AlO_4}$四面体（"T原子"）经每个顶角相连而成，围出分子尺度的空腔与孔道。其通式为
$$
\mathrm{M}^{n+}_{x/n}\left[(\mathrm{AlO_2})_x(\mathrm{SiO_2})_y\right]\cdot z\,\mathrm{H_2O},
$$
其中方括号内是骨架。每个$\mathrm{AlO_4}$四面体带$-1$电荷，由骨架外阳离子$\mathrm{M^{n+}}$补偿；这些阳离子与水一起坐在孔中，并可被交换。**洛文斯坦规则**（Löwenstein，1954年，经验规律）指出Al–O–Al连接是被避免的，于是每个$\mathrm{AlO_4}$都被四个$\mathrm{SiO_4}$包围；因此$y/x = \mathrm{Si/Al} \ge 1$。
:::

这条规则出自鲍林的静电价原理（[[materials-chemistry/crystal-structures#def-bond-valence]]）：桥接两个Al的氧只能得到$2 \times \tfrac34 = 1.5$个价单位，而Si–O–Si是$2$、Si–O–Al是$1.75$，会留下很大的局域负电荷。硅铝比是沸石最重要的化学变量。Si/Al低（1–1.5，A型与X型沸石）意味着阳离子多、离子交换能力强、孔亲水；Si/Al高（ZSM-5为10直至超过1000；纯硅的Silicalite）意味着阳离子少、热稳定性与酸稳定性更高、孔疏水。

这些骨架可以由为数不多的几种**二级构建单元**搭成。**方钠石笼**（β笼）是由24个T原子构成、带正方形面和六角面的截角八面体，是三种重要结构的关键单元。让方钠石笼经小立方体（四元双环）以正方形面相连，得到**沸石A**（骨架代号LTA）：直径约$1.1\ \mathrm{nm}$的大型α笼由宽约$0.41\ \mathrm{nm}$的八元环窗互连。让它们经六棱柱（六元双环）按四面体方式相连——如同金刚石中的碳原子——得到**八面沸石**（FAU，X型与Y型沸石）：超笼直径$1.3\ \mathrm{nm}$，十二元环窗宽$0.74\ \mathrm{nm}$。**ZSM-5**（MFI）的搭法不同，由五元环构成，具有相交的直十元环孔道与折线形十元环孔道，宽约$0.55\ \mathrm{nm}$。截至2026年，国际沸石协会承认250余种不同的骨架类型，每种有一个三字母代号。

衡量开阔程度的一个有用指标是**骨架密度**，即每$1000\ \text{Å}^3$中T原子的个数：石英这类致密的硅石多晶型物约为27，八面沸石约为13。环的大小决定谁能通过：八元环窗允许正构烷烃这样的直链分子通过而不让支链分子通过；十元环允许苯和对二甲苯通过，却把更大的邻二甲苯与间二甲苯拒之门外；十二元环则容得下大多数小的芳香族分子和支链分子。

::: example 沸石A中的离子交换 {#ex-zeolite-a}
含水钠型沸石A每个伪晶胞的组成为$\mathrm{Na_{12}[(AlO_2)_{12}(SiO_2)_{12}]\cdot27H_2O}$。(a) 验证骨架电荷是平衡的。(b) 计算它的离子交换容量，以每克毫当量计。(c) $1.00\ \mathrm{g}$这种沸石经完全交换$2\,\mathrm{Na^+} \rightarrow \mathrm{Ca^{2+}}$，能从硬水中除去多少克钙？
::: solution
(a) 十二个$\mathrm{AlO_2^-}$单元给出骨架电荷$-12$，由十二个$\mathrm{Na^+}$平衡；Si/Al $= 1$，是洛文斯坦规则允许的最小值，所以Si与Al严格交替。(b) $M = 12(22.990) + 12(26.982) + 12(28.085) + 48(15.999) + 27(18.015) = 2191.0\ \mathrm{g\,mol^{-1}}$。每摩尔十二当量可交换电荷，给出$12/2191.0 = 5.48\times10^{-3}\ \mathrm{eq\,g^{-1}} = 5.48\ \mathrm{meq\,g^{-1}}$（脱水固体约$7.0$）。(c) 完全交换每个化学式单位结合$6\ \mathrm{Ca^{2+}}$：$6 \times 40.078/2191.0 = 0.110\ \mathrm{g}$，即每克除钙$110\ \mathrm{mg}$。实际上洗衣液中的交换并不完全，快速的动力学比容量更要紧。自1970年代起用沸石A取代磷酸盐助剂，消除了湖泊富营养化的一个主因。
:::

### 沸石作为分子筛与催化剂

交换阳离子会改变沸石A的有效窗口尺寸：换成$\mathrm{K^+}$（3A沸石）时，窗口只容水而不容乙醇或氮气，乙醇与制冷剂的干燥就靠这一点；换成$\mathrm{Na^+}$（4A）时窗口约$0.4\ \mathrm{nm}$；换成$\mathrm{Ca^{2+}}$（5A）时——它只需一半数目的阳离子，且留下一些窗口未被堵塞——直链烷烃可以通过而支链烷烃不能，这正是从石油馏分中分离正构烷烃的基础。更大孔的沸石利用氮与氧同阳离子相互作用的不同，把空气中的氮与氧分开：$\mathrm{N_2}$的四极矩较大、结合较强，所以经锂交换X型沸石的变压吸附能产生富氧空气，供医用制氧机使用。

把阳离子换成铵再加热，氨被赶出，一个质子就留在桥接Si与Al的氧上：得到**布朗斯特酸位**$\equiv\mathrm{Si{-}O(H){-}Al}\equiv$，强度可与浓硫酸相比，却固定在形状确定的孔中。这类酸性沸石是化学工业中产量最大的催化剂。经脱铝稳定的Y型沸石（"超稳Y"）是把重质石油馏分裂化成汽油的流化催化裂化催化剂的活性组分。ZSM-5把甲醇转化为烃并使二甲苯异构化，这里就出现了**择形选择性**：对二甲苯扩散穿过十元环孔道的速度比邻、间二甲苯快几个数量级，所以尽管孔道内的平衡更偏向另外两种异构体，聚酯原料对苯二甲酸所需的对位异构体仍优先逸出。选择性也可能源自只有装得进孔中的过渡态才能形成。

::: warning 孔并非越大越好 {#warn-pores}
人们容易诱于按表面积或孔径为多孔材料排序，仿佛空得越多材料就越好。对分离与选择性催化，事实往往相反：5A对直链烷烃、ZSM-5对对二甲苯的选择性，恰恰来自只比分子大不了多少的孔。对气体储存，过大的孔是在浪费体积，因为宽孔中心的分子，其浓度并不比本体气体中高多少；储存甲烷的最佳孔径约为分子直径的两倍。而且大表面积通常伴随低骨架密度以及较差的机械、热与化学稳定性。孔隙率要按需而设。
:::

## 金属有机框架

**金属有机框架**是一类结晶固体，由金属离子或簇（节点，常称为二级构建单元）经多齿有机配体（连接体）连接，伸展成可能含孔的网络。罗布森（Richard Robson）1989年证明，把几何构型已知的金属中心与刚性桥连配体组合起来，就能设计出拓扑可预测的骨架，例如含四腈配体的类金刚石铜(I)网络。北川进（Susumu Kitagawa）1997年在一种配位框架中演示了可逆气体吸附，后来发展出客体进入时骨架会"呼吸"的柔性框架；亚吉（Omar Yaghi）引入了具有永久孔隙率的稳健羧酸盐MOF，并提出网状合成策略。三人分享了2025年诺贝尔化学奖。

**MOF-5**是原型，$\mathrm{Zn_4O(BDC)_3}$（BDC = 对苯二甲酸根，即苯-1,4-二甲酸根），亚吉与合作者1999年报道。它的节点是一个氧心$\mathrm{Zn_4O}$四面体，被六个羧酸根封端，羧酸根指向八面体的六个顶点；用这样的节点经线形的BDC杆连接，就生成简单立方网络，空腔直径约$1.2$–$1.5\ \mathrm{nm}$，BET表面积约为$3000$–$4000\ \mathrm{m^2\,g^{-1}}$量级。因为几何由节点决定，把BDC换成更长的线形二元羧酸根，就得到拓扑相同、孔更大的**同网状**（isoreticular）系列骨架：这就是**网状化学**，先把结构设计成一张网，再选择构建单元把它实现。其他里程碑式的骨架包括：**HKUST-1**，$\mathrm{Cu_3(BTC)_2}$（BTC = 均苯三甲酸根，即苯-1,3,5-三甲酸根），由类似乙酸铜的铜"桨轮"二聚体建成（[[coordination-chemistry/magnetism]]），其轴向水配体可以除去做成开放金属位；**UiO-66**，$\mathrm{Zr_6O_4(OH)_4(BDC)_6}$，因其强Zr–羧酸盐键与十二连接的节点而对水和酸异常稳定；以及**沸石咪唑酯骨架**材料，如ZIF-8，$\mathrm{Zn(mim)_2}$，其中四面体$\mathrm{Zn^{2+}}$被咪唑酯桥连，桥角接近Si–O–Si角，于是采取沸石的拓扑（此处为方钠石型）。

MOF兼有沸石无法同时具备的长处：表面积高过$7000\ \mathrm{m^2\,g^{-1}}$以上；连接体可经官能化（胺基用于$\mathrm{CO_2}$捕集，手性基团用于对映选择性分离）而连续调节孔内化学；柔性；以及合成后修饰骨架的可能。它们的弱点是热稳定性（通常低于$400\,^\circ\mathrm{C}$，而沸石为$700$–$1000\,^\circ\mathrm{C}$）、许多框架对水敏感以及成本。截至2026年在研或已用的应用包括：为电子工业储存有毒气体、从烟气中捕集$\mathrm{CO_2}$、从沙漠空气中取水，以及烃类分离。**共价有机骨架**（COF）是全有机的对应物，由B–O、C=N或C–C键连接。

::: example 数出MOF-5的化学式 {#ex-mof5}
在MOF-5中，每个$\mathrm{Zn_4O}$节点连接六个BDC连接体，每个连接体连接两个节点。(a) 证明化学式为$\mathrm{Zn_4O(BDC)_3}$且电中性。(b) 计算它的摩尔质量及锌的质量分数。(c) 抽空的骨架的晶体密度约为$0.59\ \mathrm{g\,cm^{-3}}$，而致密的锌羧酸盐接近$2\ \mathrm{g\,cm^{-3}}$。估算空隙分数。
::: solution
(a) 每个节点伸出六个连接体端头，每个连接体被两个节点共享，所以每个节点对应$6/2 = 3$个连接体：$\mathrm{Zn_4O(BDC)_3}$。电荷：$4(+2) + (-2) + 3(-2) = 0$。(b) BDC是$\mathrm{C_8H_4O_4^{2-}}$，$M = 8(12.011) + 4(1.008) + 4(15.999) = 164.12\ \mathrm{g\,mol^{-1}}$。$M = 4(65.38) + 15.999 + 3(164.12) = 769.9\ \mathrm{g\,mol^{-1}}$。锌的质量分数$= 261.52/769.9 = 34.0\ \%$。(c) 若骨架"壁"具有致密锌羧酸盐的密度，它们约占体积的$0.59/2 \approx 0.3$，空隙分数即约$0.7$：MOF-5晶体大约有70 %是空的。（由晶体结构计算、用小球形分子探测，给出的值约为$0.8$。）

### 有序介孔固体

1992年，Mobil公司的研究者报道了**MCM-41**：一种具有六角排列、孔径均匀（$2$–$10\ \mathrm{nm}$）的圆柱形介孔的二氧化硅。它的制法是让硅酸盐在阳离子表面活性剂（如十六烷基三甲基溴化铵）棒状胶束周围缩聚，再把表面活性剂烧除。**SBA-15**（1998年）改用嵌段共聚物表面活性剂，得到更厚的孔壁和宽达约$30\ \mathrm{nm}$的孔。这类材料的孔壁是无定形的，所以不具备沸石那样的强酸性与择形选择性，但其大而均匀的孔能容纳大分子、酶与纳米颗粒，并可作为硬模板（"纳米铸造"）制备介孔碳与介孔氧化物。相形之下，活性炭是无序的微孔-介孔固体，由椰壳、煤或聚合物热解活化而得；廉价而坚固，在水处理与气体净化中占主导地位。

## 吸附等温式

孔隙率靠**吸附**来表征，多孔材料也靠吸附来使用：吸附就是气体或液体中的分子在表面上的富集。**吸附等温式**描述固定温度下吸附量$n$（每克固体的摩尔数）随压力$p$、或低于饱和蒸气压$p^\circ$时的相对压力$p/p^\circ$的变化。物理吸附（physisorption）靠范德华力，焓为$-5$至$-40\ \mathrm{kJ\,mol^{-1}}$，且可逆；化学吸附形成化学键，是[[kinetics/surface-kinetics]]的主题。

::: proposition 朗缪尔吸附等温式 {#prop-langmuir}
对由全同、彼此独立的位点构成的表面，每个位点至多容纳一个分子，则压力$p$下的覆盖分数为
$$
\theta = \frac{n}{n_\mathrm{m}} = \frac{Kp}{1 + Kp},
$$ {#eq-langmuir}
其中$n_\mathrm{m}$是单层容量，$K = k_\mathrm{a}/k_\mathrm{d}$是平衡常数，随温度升高而下降，$K \propto \exp(-\Delta_\mathrm{ads}H/RT)$（$\Delta_\mathrm{ads}H < 0$）。它的假设（至多单层、位点等价、吸附分子间无相互作用）对化学吸附和对均匀骨架中的微孔填充符合得最好；对开放表面上的多层物理吸附则失效。
:::

::: proof
吸附速率与压力（对表面的碰撞频率）和空位分数成正比：$k_\mathrm{a}p(1 - \theta)$。脱附速率与占据位点分数成正比：$k_\mathrm{d}\theta$。平衡时两者相等：$k_\mathrm{a}p(1 - \theta) = k_\mathrm{d}\theta$，于是$\theta(k_\mathrm{d} + k_\mathrm{a}p) = k_\mathrm{a}p$，代入$K = k_\mathrm{a}/k_\mathrm{d}$即得$\theta = Kp/(1 + Kp)$。低压下$\theta \approx Kp$（亨利定律区）；高压下$\theta \to 1$。把位点当作与蒸气平衡的格子气体，用统计热力学可得同一结果（[[statistical-thermodynamics/equilibrium-from-molecules]]）。
:::

朗缪尔形式描述**I型**等温线，即微孔固体给出的形状：在极低的$p/p^\circ$处急剧上升（微孔被填满），随后出现平台；平台量度的是微孔体积，而不是表面上的单层。无孔与大孔固体给出**II型**等温线：先形成单层，然后当$p \to p^\circ$时多层无限制地堆叠。介孔固体给出**IV型**等温线：低压处与II型相同，但在介孔经毛细凝聚被填满处出现一个台阶和一个平台，吸附支与脱附支之间通常有**滞后回线**。

::: proposition BET吸附等温式 {#prop-bet}
若分子以多层吸附，第一层的吸附焓为$\Delta H_1$，以上各层的焓均为液化焓$\Delta H_\mathrm{L}$，且每一层对下层的吸附-脱附都服从朗缪尔型动力学，则以$x = p/p^\circ$
$$
\frac{n}{n_\mathrm{m}} = \frac{Cx}{(1 - x)(1 - x + Cx)}, \qquad \frac{x}{n(1 - x)} = \frac{1}{n_\mathrm{m}C} + \frac{C - 1}{n_\mathrm{m}C}\,x,
$$ {#eq-bet}
其中$C \approx \exp[(\Delta H_\mathrm{L} - \Delta H_1)/RT]$，量度第一层被结合得比上层强多少。线性形式用来提取$n_\mathrm{m}$与$C$，对II型等温线通常取$0.05 < x < 0.30$的区间——模型的假设在那里错得最少。
:::

::: proof
设$s_i$为恰好被$i$层覆盖的表面分数。平衡时，向$i$层斑块的凝聚等于从$(i+1)$层斑块的蒸发。对第一层，$a_1ps_0 = b_1s_1e^{\Delta H_1/RT}$（把焓显式写出，$b_1$便是指前因子；$\Delta H_1 < 0$使脱附更慢）；对更上的层，$a ps_{i} = bs_{i+1}e^{\Delta H_\mathrm{L}/RT}$。于是$s_1 = ys_0$，其中$y = (a_1/b_1)pe^{-\Delta H_1/RT}$；对$i \ge 1$，$s_{i+1} = xs_i$，其中$x = (a/b)pe^{-\Delta H_\mathrm{L}/RT}$；由于上面的各层如同液体，$x$就等于$p/p^\circ$（当$p \to p^\circ$时形成无限多层）。所以$s_i = Cx^is_0$，其中$C = y/x$。总吸附量为$n = n_\mathrm{m}\sum_i is_i$，且表面归一化$\sum_i s_i = 1$：
$$
\frac{n}{n_\mathrm{m}} = \frac{\sum_{i\ge1} iCx^is_0}{s_0 + \sum_{i\ge1}Cx^is_0} = \frac{Cx/(1 - x)^2}{1 + Cx/(1 - x)} = \frac{Cx}{(1 - x)(1 - x + Cx)},
$$
其中用了$\sum ix^i = x/(1 - x)^2$与$\sum x^i = x/(1 - x)$。整理即得线性形式：$x/[n(1 - x)] = (1 - x + Cx)/(n_\mathrm{m}C) = 1/(n_\mathrm{m}C) + (C - 1)x/(n_\mathrm{m}C)$。若第一层焓与液化焓采用相同的指前因子之比，则$C = y/x = \exp[(\Delta H_\mathrm{L} - \Delta H_1)/RT]$。
:::

**BET表面积**由单层容量求得：$a_\mathrm{s} = n_\mathrm{m}N_\mathrm{A}\sigma$，其中$\sigma$是一个被吸附分子占据的面积，$77\ \mathrm{K}$下的氮气取$0.162\ \mathrm{nm^2}$；氮气是标准的吸附质。对微孔固体，"BET面积"在形式上没有意义，因为微孔是被填满的，表面并不包覆单层；但若按公认标准计算（选取使$n(1 - x)$随$x$增大而$C$为正的压力区间），它仍是可重现的、有用的比较指标。

::: example 一次BET分析 {#ex-bet}
$77\ \mathrm{K}$下氮气在一种介孔氧化物上的吸附给出如下吸附量（由BET方程生成的示例数据）：

| $x = p/p^\circ$ | $0.05$ | $0.10$ | $0.15$ | $0.20$ | $0.25$ | $0.30$ |
|---|---|---|---|---|---|---|
| $n\ /\ \mathrm{mmol\,g^{-1}}$ | $7.27$ | $8.27$ | $8.99$ | $9.68$ | $10.41$ | $11.21$ |

求$n_\mathrm{m}$、$C$与BET表面积。
::: solution
计算$y = x/[n(1 - x)]$：$0.05/(7.27 \times 0.95) = 0.00724$，随后依次为$0.01343$、$0.01963$、$0.02583$、$0.03203$、$0.03823\ \mathrm{g\,mmol^{-1}}$。过这些点的最小二乘直线（可在下图中试一试）斜率$s = 0.1239\ \mathrm{g\,mmol^{-1}}$，截距$i = 0.00104\ \mathrm{g\,mmol^{-1}}$。由[[#eq-bet]]，$n_\mathrm{m} = 1/(s + i) = 1/0.1250 = 8.00\ \mathrm{mmol\,g^{-1}}$，$C = s/i + 1 = 120$。表面积为
$$
a_\mathrm{s} = 8.00\times10^{-3}\ \mathrm{mol\,g^{-1}} \times 6.022\times10^{23}\ \mathrm{mol^{-1}} \times 0.162\times10^{-18}\ \mathrm{m^2} = 780\ \mathrm{m^2\,g^{-1}}.
$$
截距很小且难以确定（它有$10\ \%$的误差会使$C$变$10\ \%$，而$n_\mathrm{m}$变动不到$1\ \%$），这就是BET面积稳健、而BET的$C$值不稳健的原因。用真实数据时，面积只报两三位有效数字，并注明所用压力区间。
:::

### 毛细凝聚与开尔文方程

::: proposition 开尔文方程 {#prop-kelvin}
被限制在圆柱形孔中、具有半径为$r$的半球形弯月面（接触角为零）的液体，与其蒸气压低于正常蒸气压$p^\circ$的蒸气平衡：
$$
\ln\frac{p}{p^\circ} = -\frac{2\gamma V_\mathrm{m}}{rRT},
$$ {#eq-kelvin}
其中$\gamma$是表面张力，$V_\mathrm{m}$是液体的摩尔体积。在相对压力$p/p^\circ$下，半径小于$r$的孔都被凝聚的液体填满。方程把凝聚相当作具有宏观界面的块体液体，在约$2\ \mathrm{nm}$以下就不再可靠。
:::

::: proof
在半径为$r$的弯曲界面两侧，凹侧的压力比凸侧高$2\gamma/r$（拉普拉斯）。孔中的液体位于弯月面的凸侧（对蒸气而言它是凹的），所以液体承受的压力比蒸气低$2\gamma/r$。液体压力改变$\Delta P$，其化学势改变$V_\mathrm{m}\Delta P$，于是$\mu_\mathrm{l} = \mu_\mathrm{l}^\circ - 2\gamma V_\mathrm{m}/r$，其中$\mu_\mathrm{l}^\circ$是块体液体在其蒸气压下的化学势。与理想蒸气平衡要求$\mu_\mathrm{l} = \mu_\mathrm{g}^\circ + RT\ln(p/p^\circ)$，而$\mu_\mathrm{l}^\circ = \mu_\mathrm{g}^\circ$（块体液体与蒸气在$p^\circ$下共存），故$RT\ln(p/p^\circ) = -2\gamma V_\mathrm{m}/r$，即[[#eq-kelvin]]（[[thermodynamics/phase-equilibria]]）。
:::

对$77\ \mathrm{K}$的氮气（$\gamma = 8.85\ \mathrm{mN\,m^{-1}}$，$V_\mathrm{m} = 34.7\ \mathrm{cm^3\,mol^{-1}}$），在$p/p^\circ = 0.5$处凝聚对应开尔文半径$r = 2\gamma V_\mathrm{m}/[RT\ln(p^\circ/p)] = 1.38\ \mathrm{nm}$。真实孔半径还要加上凝聚之前孔壁上吸附膜的厚度（该压力下约$0.6\ \mathrm{nm}$）。按这一思路分析IV型等温线的凝聚台阶（巴雷特-乔伊纳-哈伦达法）可得孔径分布；现代做法改用受限流体的密度泛函理论，它可以一直用到微孔区间。

::: quiz
$77\ \mathrm{K}$的氮气等温线在$p/p^\circ = 0.01$以下几乎垂直上升，此后一直到$p/p^\circ = 0.95$都是平的。这表明什么？
- [x] 微孔固体（I型等温线），其孔在低压下就已填满
- [ ] 吸附很弱的无孔固体
- [ ] 正在发生毛细凝聚的介孔固体
- [ ] 大外表面上的多层吸附
::: solution
在极低的相对压力下就发生填充，意味着极强的相互作用势，而这种势只有在两侧孔壁很近时才存在：微孔。平坦的平台表示不再有吸附，所以外表面或介孔很少。无孔固体会给出朝$p^\circ$上升的II型曲线；介孔在中压处给出台阶，且常伴有滞后。
:::
:::

::: example 中等压力下的甲烷储存 {#ex-storage}
一种晶体密度为$0.59\ \mathrm{g\,cm^{-3}}$的MOF在$35\ \mathrm{bar}$、$298\ \mathrm{K}$下每克吸附$0.20\ \mathrm{g}$甲烷（对最好的材料来说量级正确的示例数值）。把它的储存容量表示为每单位晶体体积、在$0\,^\circ\mathrm{C}$与$1\ \mathrm{atm}$下的气体体积（STP，摩尔体积$22.41\ \mathrm{dm^3\,mol^{-1}}$），并与同压力下的一只空罐比较。
::: solution
每立方厘米晶体：$0.20 \times 0.59 = 0.118\ \mathrm{g}$甲烷，即$0.118/16.04 = 7.36\ \mathrm{mmol}$，在STP下占$7.36\times10^{-3} \times 22\,410 = 165\ \mathrm{cm^3}$：$165\ \mathrm{v/v}$。空罐容纳$n/V = p/RT = 35\times10^5/(8.314 \times 298) = 1413\ \mathrm{mol\,m^{-3}} = 1.41\ \mathrm{mmol\,cm^{-3}}$，在STP下为$31.7\ \mathrm{v/v}$（理想气体估计）。这一压力下吸附剂储存的气体量约为它的五倍。两点提醒：真实的罐要装填晶体，颗粒之间的空隙会降低床层密度；而且只有降压到最低供气压力（约$5\ \mathrm{bar}$）之间放出的气体可用。衡量这类材料的优值指标是"可释放容量"。
:::
:::

## 后续内容

多孔固体与课程及课程体系的许多部分相连。它们的合成就是[[materials-chemistry/solid-synthesis]]中的水热与溶剂热方法；它们的结构由[[materials-chemistry/diffraction]]解出；它们的催化化学在[[organometallics-catalysis/heterogeneous-catalysis]]与[[kinetics/surface-kinetics]]中延续；它们在碳捕集与储氢中的应用见[[materials-chemistry/energy-materials]]与[[green-chemistry/carbon-hydrogen]]。把纳米颗粒限制在孔中，是[[materials-chemistry/nanomaterials]]的策略之一。

::: history
阿克塞尔·弗雷德里克·克朗斯泰特（Axel Fredrik Cronstedt）1756年根据沸石加热时放出的水为它们命名（"沸石"，意为会沸腾的石头）。欧文·朗缪尔（Irving Langmuir）在1916–18年导出了他的等温式（1932年诺贝尔化学奖），斯蒂芬·布鲁纳尔（Stephen Brunauer）、保罗·埃米特（Paul Emmett）与爱德华·特勒（Edward Teller）1938年发表了BET理论。理查德·巴雷尔（Richard Barrer）从1940年代开始系统地水热合成沸石；联合碳化物公司的罗伯特·米尔顿（Robert Milton）与唐纳德·布雷克（Donald Breck）在1949–54年前后合成了A型与X型沸石；瓦尔特·洛文斯坦（Walter Löwenstein）于1954年提出他的规则。沸石催化剂于1960年代初进入石油裂化，Mobil公司1972年为ZSM-5申请了专利。Mobil公司的科学家（查尔斯·雷斯格（Charles Kresge）、杰弗里·贝克（Jeffrey Beck）及同事）1992年报道了MCM-41。伯纳德·霍斯金斯（Bernard Hoskins）与罗布森（Richard Robson）1989年描述了设计出的配位框架；北川进1997年报道了多孔配位聚合物的气体吸附；亚吉的小组1999年报道了MOF-5，同年HKUST-1由威廉（Ian Williams）的小组在香港发表。北川、罗布森与亚吉获2025年诺贝尔化学奖。
:::

::: summary
- 孔分为微孔（$< 2\ \mathrm{nm}$）、介孔（$2$–$50\ \mathrm{nm}$）与大孔（$> 50\ \mathrm{nm}$）；所属类别决定它们被填满的方式。
- 沸石是由共顶角$\mathrm{SiO_4}$与$\mathrm{AlO_4}$四面体构成的骨架；每个Al带来一个由可交换阳离子平衡的$-1$电荷，洛文斯坦规则给出Si/Al $\ge 1$。
- 方钠石笼搭出沸石A与八面沸石；环大小（8、10、12）决定窗口，从而决定分子筛分与择形催化（ZSM-5、对二甲苯）；质子型沸石是强固体酸。
- MOF用有机连接体连接金属簇节点；网状化学设计出同网状系列（MOF-5），稳定性取决于节点-连接体键强（UiO-66、ZIF）。
- 朗缪尔等温式$\theta = Kp/(1 + Kp)$描述单层吸附与微孔填充（I型）；BET等温式描述多层（II型）并给出$n_\mathrm{m}$，从而由$a_\mathrm{s} = n_\mathrm{m}N_\mathrm{A}\sigma$（$\sigma(\mathrm{N_2}) = 0.162\ \mathrm{nm^2}$）得表面积。
- 介孔在$\ln(p/p^\circ) = -2\gamma V_\mathrm{m}/rRT$（开尔文）处经毛细凝聚被填满，给出带滞后的IV型等温线与孔径分布。
- 对储存与分离，相关的指标是体积容量、可释放容量与选择性，而不是孤立的表面积。
:::

::: exercise 朗缪尔覆盖度 {level=2 check="9"}
某吸附剂服从朗缪尔等温式，在$2.0\ \mathrm{bar}$下覆盖度为$0.50$。(a) 求$K$。(b) 覆盖度为$0.90$时的压力是这个压力的多少倍？（输入倍数。）
::: solution

::: exercise 一个开尔文半径 {level=2 check="2.68"}

::: exercise 解离吸附 {level=3 check="0.667"}
氢在金属上解离吸附，$\mathrm{H_2(g)} + 2\,{*} \rightleftharpoons 2\,\mathrm{H}{*}$，其中${*}$是表面位点。(a) 证明$\theta = (Kp)^{1/2}/[1 + (Kp)^{1/2}]$。(b) 计算$Kp = 4$时的$\theta$。(c) 如何在实验上检验吸附是否解离？（以三位有效数字输入$Kp = 4$时的$\theta$。）
::: solution
(a) 吸附需要两个相邻的空位，速率$k_\mathrm{a}p(1 - \theta)^2$；脱附需要两个相邻的H原子，速率$k_\mathrm{d}\theta^2$。平衡时$\theta^2/(1 - \theta)^2 = Kp$，所以$\theta/(1 - \theta) = (Kp)^{1/2}$，$\theta = (Kp)^{1/2}/[1 + (Kp)^{1/2}]$。(b) $(Kp)^{1/2} = 2$，$\theta = 2/3 = 0.667$。(c) 低覆盖时$\theta \propto p^{1/2}$而不是$p$；对解离吸附，$1/n$对$1/p^{1/2}$作图是直线，而对分子吸附，$1/n$对$1/p$作图是直线。
:::

::: exercise 由两点作BET拟合 {level=3 check="8.0"}
只用[[#ex-bet]]中$x = 0.10$（$n = 8.27\ \mathrm{mmol\,g^{-1}}$）与$x = 0.25$（$n = 10.41\ \mathrm{mmol\,g^{-1}}$）两点，由线性BET方程求$n_\mathrm{m}$与$C$。评论各自的可靠性。（以$\mathrm{mmol\,g^{-1}}$输入$n_\mathrm{m}$，两位有效数字。）
::: hint
先算出两点的$y = x/[n(1 - x)]$，再求过这两点直线的斜率与截距。
:::
::: solution
$y_1 = 0.10/(8.27 \times 0.90) = 0.013436$，$y_2 = 0.25/(10.41 \times 0.75) = 0.032020\ \mathrm{g\,mmol^{-1}}$。斜率$s = (0.032020 - 0.013436)/0.15 = 0.12389$；截距$i = 0.013436 - 0.10s = 0.001045$。于是$n_\mathrm{m} = 1/(s + i) = 1/0.12494 = 8.0\ \mathrm{mmol\,g^{-1}}$，$C = s/i + 1 = 120$。单层容量与六点拟合的一致性优于1 %，但$C$取决于外推得到的一个小截距：把$n$舍入到三位数字就会使截距变化几个百分点。$n_\mathrm{m}$（以及面积）可以放心报告；$C$只宜作定性看待。
:::

::: exercise 体积容量 {level=2 check="165"}
重做[[#ex-storage]]的计算，给出甲烷储存容量，以每$\mathrm{cm^3}$晶体在STP下的$\mathrm{cm^3}$气体计。若把晶体装入罐中，颗粒间有30 %的空隙，空隙中装着处于$31.7\ \mathrm{v/v}$的压缩气体，总容量是多少？（以三位有效数字输入纯晶体的容量。）
::: solution
晶体：$165\ \mathrm{v/v}$，同正文。填充床：$0.70 \times 165 + 0.30 \times 31.7 = 115.5 + 9.5 = 125\ \mathrm{v/v}$。装填损失是质量容量与晶体学容量高估真实罐性能的主要原因，也是人们开发整体式与致密化MOF的原因。
