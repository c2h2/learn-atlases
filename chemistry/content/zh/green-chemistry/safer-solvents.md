看几乎任何一个精细化工或制药工艺的物料衡算，最大的一项既不是反应物、试剂，也不是产品，而是溶剂。反应要在溶液中进行，因为溶解的分子相遇快，反应热也被带走；后处理还要用更多溶剂来洗涤、萃取和结晶；设备在批次之间要用更多的溶剂清洗。葛兰素史克（GlaxoSmithKline）与美国化学会绿色化学研究所制药圆桌会议（ACS Green Chemistry Institute Pharmaceutical Roundtable）对制药制造的分析一再发现，溶剂约占制造一种活性成分所用物料的一半或以上，其余大部分是水。危害也主要在溶剂：许多常用实验室溶剂易燃，若干种对神经系统、肝脏或生殖系统有毒，有些致癌，它们的蒸气助长光化学烟雾，少数氯代溶剂还造成平流层臭氧损耗。

绿色化学原则 5（[[green-chemistry/green-principles]]）要求尽可能避免辅助物质，使用时则使其无害。本章把这一点付诸实践。先讲使溶剂有用的性质，用溶解度参数来量化；然后介绍溶剂选择指南如何对溶剂排序、法规如何限制其中最差的几种；接着考察替代品——水、超临界二氧化碳、离子液体、生物基溶剂，以及完全不用溶剂——以及它们真正的优点与局限；最后讲连续流加工，它改变反应的条件（温度、压力、停留时间、存量）之剧烈，不亚于换一种溶剂。评判这一切所用的指标是 [[green-chemistry/green-metrics]] 的那些。

## 溶剂的作用与选择

溶剂必须溶解反应物（有时还要不溶解产物，使其结晶），在反应条件下惰性，具有方便的液态范围，能把产品分离出来，且能回收或安全处置。对特定反应，它还可能通过稳定带电的过渡态（极性非质子溶剂加速阴离子的 $\mathrm{S_N2}$ 反应；见 [[organic-1/nucleophilic-substitution]]）或通过氢键影响速率与选择性。“相似相溶”由液体的内聚能量化为定量。

::: definition 希尔德布兰与汉森溶解度参数 {#def-solubility-parameter}
液体的**内聚能密度**是把其分子分离为理想气体所需的能量除以体积：$(\Delta_\mathrm{vap}H - RT)/V_\mathrm{m}$，其中 $V_\mathrm{m}$ 为液体摩尔体积。**希尔德布兰溶解度参数**是其平方根，
$$
\delta = \left(\frac{\Delta_\mathrm{vap}H - RT}{V_\mathrm{m}}\right)^{1/2},
$$ {#eq-hildebrand}
常用 $\mathrm{MPa^{1/2}}$ 表示（$1\ \mathrm{MPa} = 1\ \mathrm{J\,cm^{-3}}$）。**汉森溶解度参数**把内聚能分成色散、极性与氢键三部分，$\delta^2 = \delta_\mathrm{D}^2 + \delta_\mathrm{P}^2 + \delta_\mathrm{H}^2$，并用距离
$$
R_\mathrm{a} = \left[4(\delta_{\mathrm{D}1} - \delta_{\mathrm{D}2})^2 + (\delta_{\mathrm{P}1} - \delta_{\mathrm{P}2})^2 + (\delta_{\mathrm{H}1} - \delta_{\mathrm{H}2})^2\right]^{1/2} .
$$ {#eq-hansen}
度量两种物质的相异程度。溶质由汉森空间中半径为 $R_0$ 的球表征；相对能量差 $\mathrm{RED} = R_\mathrm{a}/R_0 < 1$ 的溶剂预期能溶解它。因子 $4$ 是经验的，选取它使可溶区域成为球形。
:::

::: proposition 正规溶液的混合焓 {#prop-regular}
对两种无特殊相互作用而混合的非极性液体（希尔德布兰的**正规溶液**），体积分数为 $\phi_1$、$\phi_2$，混合物摩尔体积为 $V$，则每摩尔混合物的混合焓近似为
$$
\Delta_\mathrm{mix}H \approx V\,\phi_1\phi_2\,(\delta_1 - \delta_2)^2 \ \geq 0 .
$$ {#eq-regular}
因此溶解度参数相等时混合最有利（吸热最少）。
:::

::: proof
把液体建模为晶格上的分子，近邻之间有接触（[[thermodynamics/mixtures]] 对正规溶液的推导）。设单位体积接触相互作用能在纯液体 1 中为 $-c_{11}$、纯液体 2 中为 $-c_{22}$、两者之间为 $-c_{12}$，则内聚能密度为 $c_{11} = \delta_1^2$、$c_{22} = \delta_2^2$。随机混合时，接触对的比例为 $\phi_1^2$ 是 1–1、$\phi_2^2$ 是 2–2、$2\phi_1\phi_2$ 是 1–2，混合物单位体积能量为 $-(\phi_1^2c_{11} + \phi_2^2c_{22} + 2\phi_1\phi_2c_{12})$；未混合液体的为 $-(\phi_1c_{11} + \phi_2c_{22})$。利用 $\phi_1 + \phi_2 = 1$，单位体积混合能为 $\phi_1\phi_2(c_{11} + c_{22} - 2c_{12})$。对色散力的**几何平均假设** $c_{12} = (c_{11}c_{22})^{1/2}$（源于伦敦公式，其中相互作用正比于极化率之积）给出 $c_{11} + c_{22} - 2\sqrt{c_{11}c_{22}} = (\delta_1 - \delta_2)^2$。乘以 $V$ 并略去液体中混合能与混合焓的小差异即得[[#eq-regular]]。该假设对氢键或强极性液体失效，所以它们要用汉森的三分量参数。
:::

::: example 由蒸发焓求溶解度参数 {#ex-hildebrand}
计算 $25\,^\circ\mathrm{C}$ 下正己烷（$\Delta_\mathrm{vap}H = 31.56\ \mathrm{kJ\,mol^{-1}}$，$M = 86.18\ \mathrm{g\,mol^{-1}}$，$\rho = 0.655\ \mathrm{g\,cm^{-3}}$）与乙醇（$42.32\ \mathrm{kJ\,mol^{-1}}$，$46.07$，$0.789$）的希尔德布兰参数，并就正己烷与甲苯（$\delta = 18.2\ \mathrm{MPa^{1/2}}$）的混合焓作评论。
::: solution
**正己烷：**$V_\mathrm{m} = 86.18/0.655 = 131.6\ \mathrm{cm^3\,mol^{-1}}$；$\Delta_\mathrm{vap}H - RT = 31\,560 - 8.314\times298.15 = 29\,081\ \mathrm{J\,mol^{-1}}$；
$$
\delta = \left(\frac{29\,081\ \mathrm{J\,mol^{-1}}}{131.6\ \mathrm{cm^3\,mol^{-1}}}\right)^{1/2} = (221.0\ \mathrm{J\,cm^{-3}})^{1/2} = 14.9\ \mathrm{MPa^{1/2}}.
$$
**乙醇：**$V_\mathrm{m} = 58.4\ \mathrm{cm^3\,mol^{-1}}$，$\Delta_\mathrm{vap}H - RT = 39\,841\ \mathrm{J\,mol^{-1}}$，$\delta = (682\ \mathrm{J\,cm^{-3}})^{1/2} = 26.1\ \mathrm{MPa^{1/2}}$，大数值反映了氢键。

对 50:50（体积）的正己烷-甲苯混合物，[[#eq-regular]]给出 $\Delta_\mathrm{mix}H/V \approx 0.25\times(18.2 - 14.9)^2 = 2.7\ \mathrm{J\,cm^{-3}}$，很小：两液体完全互溶，混合熵轻易压过它。正己烷与乙醇的差为 $11\ \mathrm{MPa^{1/2}}$，模型会预言 $30\ \mathrm{J\,cm^{-3}}$，而且因乙醇的内聚主要来自氢键，正规溶液模型本就不适用；这对液体在室温互溶，但对拉乌尔定律显示很大的正偏差。手册值（汉森手册）为正己烷 $14.9$、乙醇 $26.5$。
:::
:::

### 溶剂选择指南

因为危害、环境归趋与工艺适用性都很重要，制药工业发展出按多项标准给溶剂排序的**溶剂选择指南**。辉瑞 2008 年发布了第一份，GSK 2011 年（2016 年更新）、赛诺菲（Sanofi）2013 年各有其份，欧洲 CHEM21 联盟发表了共识指南（Prat 等，*Green Chemistry*，2016），对安全（闪点、自燃、过氧化物生成）、健康（GHS 危险性说明、接触限值）与环境（挥发性、水生生物毒性、持久性、回收难易）打分并合并为四个类别。概略如下：

| 类别（CHEM21） | 示例 |
|---|---|
| 推荐 | 水、乙醇、丙-2-醇、丁-1-醇、乙酸乙酯、乙酸异丙酯、苯甲醚、丙酮（有条件的） |
| 有问题 | 甲醇、甲苯、环己烷、正庚烷、乙腈、四氢呋喃、2-甲基四氢呋喃、二甲基亚砜、环戊基甲基醚 |
| 危险 | 二氯甲烷、*N*,*N*-二甲基甲酰胺、*N*,*N*-二甲基乙酰胺、*N*-甲基吡咯烷酮、1,4-二噁烷、正己烷、正戊烷 |
| 高度危险 | 苯、氯仿、四氯化碳、1,2-二氯乙烷、硝基甲烷、乙醚 |

各类别反映具体的危害。乙醚的闪点为 $-45\,^\circ\mathrm{C}$ 且生成爆炸性过氧化物；正己烷在体内代谢为己烷-2,5-二酮（一种神经毒素），这就是首选正庚烷的原因；苯是人类致癌物；氯仿与四氯化碳对肝有毒；偶极非质子酰胺（DMF、DMAc、NMP）是生殖毒性物质。“有问题”的溶剂在有理由使用时可以接受，最好配合回收。这些指南是结构化讨论的工具，不是判决书：一种“推荐”溶剂若要求冗长的额外精馏，总体可能不如允许直接结晶的一种“有问题”溶剂。

法规为指南加力。在欧盟，REACH 附件 XVII 限制 NMP（条目 71，自 2020 年）与 DMF（条目 76，自 2023 年 12 月），除非把工人暴露控制在协调的推导无影响水平之下；两者作为生殖毒性物质都在 REACH 候选清单的极高关注物质之列。二氯甲烷自 2010–2012 年在欧盟被限制用于脱漆剂（条目 59）；2024 年美国 EPA 依据《有毒物质控制法》发布最终规则，禁止二氯甲烷的大部分消费用途与许多商业用途，对保留用途施加严格的职场管控。对于药品，ICH 的 **Q3C** 指南限定原料药中的残留溶剂：第一类溶剂如苯（限度 $2\ \mathrm{ppm}$）应予避免；第二类溶剂有允许日接触量，例如二氯甲烷（$600\ \mathrm{ppm}$）、乙腈（$410\ \mathrm{ppm}$）、甲苯（$890\ \mathrm{ppm}$）与甲醇（$3000\ \mathrm{ppm}$）；第三类低毒溶剂如乙醇、丙酮与乙酸乙酯，在 $5000\ \mathrm{ppm}$ 以下无须论证即可接受。

::: example 替代 NMP {#ex-nmp}
某偶联反应在 NMP 中进行，汉森参数 $(\delta_\mathrm{D}, \delta_\mathrm{P}, \delta_\mathrm{H}) = (18.0, 12.3, 7.2)\ \mathrm{MPa^{1/2}}$。候选替代品：二氢左旋葡萄糖酮（Cyrene，一种由纤维素制的生物基偶极非质子溶剂），$(18.8, 10.6, 6.9)$；二甲基亚砜，$(18.4, 16.4, 10.2)$；DMF，$(17.4, 13.7, 11.3)$；丙酮，$(15.5, 10.4, 7.0)$。按对 NMP 的汉森距离排序。
::: solution
由[[#eq-hansen]]，对 Cyrene：
$$
R_\mathrm{a} = \left[4(18.8 - 18.0)^2 + (10.6 - 12.3)^2 + (6.9 - 7.2)^2\right]^{1/2} = (2.56 + 2.89 + 0.09)^{1/2} = 2.35\ \mathrm{MPa^{1/2}}.
$$
类似地：DMF $4.50$，DMSO $5.14$，丙酮 $5.35$。Cyrene 匹配最好；其次是 DMF——而那只是把一种受限溶剂换成另一种。汉森距离是初筛：替代溶剂还必须对试剂稳定（Cyrene 是酮，对强碱与某些亲核试剂不稳定），沸点与反应温度和后处理相匹配（Cyrene 沸点约 $227\,^\circ\mathrm{C}$，难以蒸发除去，所以产品通常靠加水析出来分离），并给出相当的速率与选择性，而这必须实验检验。
:::
:::

### 挥发性

大多数溶剂危害——火灾、吸入暴露、挥发性有机化合物（VOC）排放——随蒸气压标度，而蒸气压随温度陡变。

::: proposition 蒸气压的克劳修斯-克拉佩龙估算 {#prop-cc}
若蒸发焓与温度无关且蒸气理想，正常沸点为 $T_\mathrm{b}$ 的液体在温度 $T$ 下的蒸气压为
$$
p(T) = p^\ominus\exp\!\left[-\frac{\Delta_\mathrm{vap}H}{R}\left(\frac{1}{T} - \frac{1}{T_\mathrm{b}}\right)\right], \qquad p^\ominus = 101.325\ \mathrm{kPa},
$$ {#eq-cc}
液面上方空气中蒸气的平衡质量浓度为 $c = pM/RT$。
:::

::: proof
液-气相平衡的克拉佩龙方程 $\mathrm{d}p/\mathrm{d}T = \Delta_\mathrm{vap}H/(T\Delta_\mathrm{vap}V)$，取 $\Delta_\mathrm{vap}V \approx V_\mathrm{m}(\mathrm{g}) = RT/p$（略去液体体积），化为 $\mathrm{d}\ln p/\mathrm{d}T = \Delta_\mathrm{vap}H/RT^2$（[[thermodynamics/phase-equilibria]]）。从 $T_\mathrm{b}$（此处按正常沸点定义 $p = p^\ominus$）到 $T$ 积分，取 $\Delta_\mathrm{vap}H$ 恒定，即得[[#eq-cc]]。浓度由理想气体定律 $n/V = p/RT$ 乘以 $M$ 得到。
:::

::: warning “不挥发”不等于“绿色” {#warn-ionic}
1990 年代末离子液体曾作为绿色溶剂被推崇，因为其蒸气压可以忽略：没有吸入暴露、没有 VOC 排放、没有可燃蒸气。但溶剂的寿命周期并不终止于反应器。许多离子液体对水生生物有毒，尤其是长烷基链的；有些生物降解性差而在水中迁移性极强；四氟硼酸盐与六氟磷酸盐阴离子缓慢水解为 HF；其合成通常 PMI 很高；而且因为不能蒸馏，分离产品往往需要用挥发性溶剂萃取，把问题又带了回来。这一教训可以推广：单一有利性质（低挥发性、生物基来源、可生物降解）不是充分判据，溶剂应在整个寿命周期上、并与少用或不用溶剂的替代方案相比较。
:::

## 常规有机溶剂的替代品

### 水

水不可燃、无毒、便宜，对许多反应还是出人意料地好的介质。罗纳德·布雷斯洛（Ronald Breslow）1980 年证明，环戊二烯与丁烯酮的狄尔斯-阿尔德反应在水中的速率约是异辛烷中的 $700$ 倍：疏水效应把非极性反应物挤到一起，羰基上的氢键稳定了极化的过渡态。2005 年夏普利斯（Sharpless）与合作者描述了“水上”（on water）反应——不溶反应物在水中悬浮搅拌时，反应比在有机溶剂中或纯态更快——归因于油水界面的氢键。**胶束催化**由布鲁斯·利普舒茨（Bruce Lipshutz）用 TPGS-750-M 这类设计型表面活性剂大力发展（2011），在水中纳米尺度的胶束内进行过渡金属催化的偶联，表面活性剂浓度低，常常在室温、低催化剂载量下进行。

局限是真实的。许多有机金属试剂与水反应；许多底物不溶；含有机物与金属的废水在排放前必须处理——它不会从 PMI 中消失。水的蒸发焓很高（$40.7\ \mathrm{kJ\,mol^{-1}}$，$2.26\ \mathrm{MJ\,kg^{-1}}$），靠蒸发除它能耗很大。当产品能靠过滤或分相分离、水相能循环或简单处理时，水才是绿色的。

### 超临界二氧化碳

超过临界点 $T_\mathrm{c} = 304.13\ \mathrm{K}$（$31.0\,^\circ\mathrm{C}$）与 $p_\mathrm{c} = 7.377\ \mathrm{MPa}$，二氧化碳成为**超临界流体**：液气之别不复存在，在临界点附近稍变压力或温度就能把密度连续地从气样调到液样。溶解能力随密度升高，所以溶解度可调；泄压时溶剂直接蒸发，留下无溶剂的产品。$\mathrm{CO_2}$ 不可燃、毒性低（但在密闭空间是窒息剂）、便宜，且作为氨厂与乙醇厂的副产物易得，若取自回收则其使用不增加排放。氢和氧与它完全互溶，消除了加氢与氧化的气-液传质限制。

::: example 超临界 CO₂ 有多不理想？ {#ex-scco2}
$40\,^\circ\mathrm{C}$、$10.0\ \mathrm{MPa}$ 下 $\mathrm{CO_2}$ 的密度约 $630\ \mathrm{kg\,m^{-3}}$（NIST 参考数据）。把它与理想气体值以及液态水比较，并解释这对其作溶剂为何重要。
::: solution
理想气体，
$$
\rho = \frac{pM}{RT} = \frac{10.0\times10^{6}\ \mathrm{Pa}\times0.04401\ \mathrm{kg\,mol^{-1}}}{8.314\ \mathrm{J\,K^{-1}\,mol^{-1}}\times313.15\ \mathrm{K}} = 169\ \mathrm{kg\,m^{-3}}.
$$
真实流体密度是它的 $3.7$ 倍：接近临界点时分子间吸引力占主导，压缩因子 $Z = \rho_\mathrm{ideal}/\rho = 0.27$。在 $630\ \mathrm{kg\,m^{-3}}$（约为水密度的三分之二）时，$\mathrm{CO_2}$ 能溶解许多非极性与中等极性有机物；而在同一温度下降压到几 MPa，密度下降数倍，溶质便析出。这种可调性（用真实气体状态方程分析，[[statistical-thermodynamics/real-gases-liquids]]）是超临界萃取与逐级泄压分离的基础。但压力要求厚壁设备与压缩能耗，而且除非加入溶剂或表面活性剂，$\mathrm{CO_2}$ 对极性与离子化合物是不良溶剂。
:::
:::

最大的应用是萃取。米尔海姆马克斯·普朗克煤炭研究所的库尔特·佐塞尔（Kurt Zosel）在 1970 年代为超临界 $\mathrm{CO_2}$ 咖啡脱咖啡因申请了专利，取代了氯代溶剂；啤酒花、香料与天然精油以类似方式萃取，超临界 $\mathrm{CO_2}$ 还用于干洗与聚合物发泡。诺丁汉大学马廷·波利亚科夫（Martyn Poliakoff）的团队与 Thomas Swan 公司 2002 年建成一座连续的通用装置，在超临界 $\mathrm{CO_2}$ 中进行加氢等反应。

### 离子液体与低共熔溶剂

**离子液体**是熔点低于约 $100\,^\circ\mathrm{C}$ 的盐，通常带大体积不对称有机阳离子（1-烷基-3-甲基咪唑鎓、吡咯烷鎓、鏻）和弱配位阴离子（双(三氟甲磺酰)亚胺、乙酸根）。其性质可通过选择离子调节，有些能很好地溶解纤维素或 $\mathrm{CO_2}$。最著名的工业应用——BASF 的 BASIL 工艺（2002）——与其说是溶剂替代，不如说是巧妙的工程：制造烷氧基苯基膦时，副产 HCl 过去用叔胺吸收，形成浓稠的铵盐浆料。以 1-甲基咪唑代替胺后得到氯化 1-甲基咪唑鎓，它在反应温度下是液体，作为第二相分离，于是反应可在一台小型连续反应器中进行；BASF 报告时空产率提高约 $80\,000$ 倍。上文警告中的告诫仍然适用。**低共熔溶剂**由安德鲁·阿博特（Andrew Abbott）与合作者于 2003 年引入（氯化胆碱与尿素，两纯组分熔点 $302$ 与 $133\,^\circ\mathrm{C}$，混合物却在 $12\,^\circ\mathrm{C}$ 熔化），更便宜，常由无害组分制成，在金属加工与生物质领域日益受到研究。

### 生物基与更安全的有机溶剂

许多替代品只是性质更好的普通分子。**2-甲基四氢呋喃**（2-MeTHF）由糠醛或乙酰丙酸制得，在萃取中取代四氢呋喃和二氯甲烷，因为与四氢呋喃不同，它与水只是部分互溶；**环戊基甲基醚**生成过氧化物的速度比其他醚慢得多；**乙酸乙酯**与**乙酸异丙酯**在许多萃取与色谱中取代二氯甲烷；**Cyrene** 与 **γ-戊内酯**正在开发以取代偶极非质子酰胺；**碳酸二甲酯**取代有毒的甲基化试剂与部分溶剂。生物基来源只有寿命周期确认后才算优势（[[green-chemistry/green-principles#ex-lca-solvent]]）。

### 不用溶剂

最有效的溶剂策略常常是少用。在更高浓度下反应，或当反应物为液体时以**本体（neat）**进行，既降低 PMI 又缩小反应器体积；把几步在同一溶剂中串联（telescoping）可免去分离；产品直接从反应混合物中结晶可免去萃取。**机械化学**——在球磨机中研磨固体反应物，有时加几滴液体（“液相辅助研磨”）——在没有大量溶剂的情况下实现固相间反应；它用于共晶、金属有机框架和越来越多的有机与有机金属反应，IUPAC 在 2019 年把它列为化学领域“十大新兴技术”之一。

::: quiz
某工艺化学家想在水-有机产品液液萃取中取代二氯甲烷。替代品必须具备四氢呋喃所没有的哪个性质？
- [ ] 沸点高于水
- [x] 与水互溶度有限，从而形成两相
- [ ] 希尔德布兰参数接近水
- [ ] 蒸气压为零
::: solution
萃取需要两个互不相溶的相。四氢呋喃与水完全互溶，无法使用；2-MeTHF、乙酸乙酯、乙酸异丙酯与环戊基甲基醚只是部分互溶，是常见替代品。溶解度参数接近水反而会使溶剂与水互溶；蒸气压为零则难以从产品中除去。
:::
:::

## 连续流化学

换溶剂是让反应更安全的一种办法；换反应器是另一种。**连续流**加工是把反应物泵过一根管、一条通道或一串小容器，在行进中反应；产品连续流出。其思想即 [[green-chemistry/chemical-industry]] 的那几个：小存量、大比表面、稳态操作。2000 年代以来的新东西，是把它们应用到精细化工与制药合成中，用毫米级直径的管子。

::: definition 停留时间与理想流动反应器 {#def-flow}
体积为 $V$、以体积流率 $Q$ 进料（假设沿反应器恒定）的反应器，其**空时**或平均**停留时间**为 $\tau = V/Q$。两种理想化流动反应器界定真实行为：**平推流反应器**（PFR），流体微元在其中流动而不沿流动方向混合，每个微元恰停留 $\tau$；以及**全混流反应器**（CSTR），完全混合，出口组成即器内组成。适中的流速下细管近似平推流；串联的搅拌釜数目增多时逼近平推流。
:::

::: proposition 理想流动反应器中的转化率 {#prop-pfr-cstr}
对速率常数为 $k$ 的不可逆一级反应，密度与温度恒定时，停留时间 $\tau$ 下的转化率为
$$
X_\mathrm{PFR} = 1 - \mathrm{e}^{-k\tau}, \qquad X_\mathrm{CSTR} = \frac{k\tau}{1 + k\tau} .
$$ {#eq-pfr-cstr}
达到给定转化率，CSTR 所需体积比 PFR 大，倍数为 $[X/(1 - X)]/[-\ln(1 - X)]$。
:::

::: proof
PFR 中，流体微元像一台已经反应了它在器内停留时间的小型间歇反应器；经 $\tau$ 后一级动力学给出 $c/c_0 = \mathrm{e}^{-k\tau}$（[[kinetics/rate-laws]]），故 $X = 1 - \mathrm{e}^{-k\tau}$。稳态 CSTR 中反应物的衡算为进 $=$ 出 $+$ 反应：$Qc_0 = Qc + kcV$，故 $c/c_0 = 1/(1 + k\tau)$，$X = k\tau/(1 + k\tau)$。在给定 $X$ 下分别解出 $k\tau$：$k\tau_\mathrm{PFR} = -\ln(1 - X)$，$k\tau_\mathrm{CSTR} = X/(1 - X)$；$Q$ 相同时体积比即 $\tau$ 之比。CSTR 效率低，是因为全部反应物都处于低的出口浓度，而正级数反应在此处最慢。
:::

::: widget plot

x: 0, 6
y: 0, 1
sliders: N=3:1:20:1
labels: \text{平推流（PFR）}; \text{全混流（CSTR）}; N\ \text{台串联全混釜}
caption: 一级反应转化率对达姆科勒数（Damköhler）$k\tau$（$x$）作图：平推流反应器、单台全混釜，以及总停留时间相同的 $N$ 台等体积全混釜串联（滑块）。$90\,\%$ 转化率下，PFR 需要 $k\tau = 2.30$，单台 CSTR 要 $9.0$，体积大四倍；几台串联即可挽回大部分差距，这就是固体或浆料使细管不可用时采用连续全混釜串级的原因。
:::

流动对绿色化学的优点来自前面各章的规模论证：

- **传热。**内径 $d$ 的管有 $A/V = 4/d$：$1\ \mathrm{mm}$ 时 $4000\ \mathrm{m^{-1}}$，而 $10\ \mathrm{m^3}$ 反应器约 $2.6\ \mathrm{m^{-1}}$（[[green-chemistry/chemical-industry#ex-av]]）。强放热反应——硝化、有机锂化学、氟化——可以在更高温度与浓度下近等温运行，常常用更少溶剂。
- **小存量。**任一时刻只有反应器持料量（毫升到升）在反应，危险中间体（重氮化合物、叠氮化物、有机过氧化物）可在线生成并消耗，而不必累积（[[green-chemistry/green-principles#ex-inventory]]）。
- **工艺窗口。**细管轻易耐受高压，溶剂可被加热到远高于其正常沸点（“过热”条件），气体（氢、氧、CO）可高浓度溶入；秒级停留时间使不稳定中间体在未及分解前即被利用。
- **光化学与电化学。**光在吸光溶液中只能穿透很短的距离（朗伯-比尔定律，[[analytical-chemistry/molecular-spectrometry]]），电极反应需要电极间短距离；薄通道对二者都合适。
- **以数放大（numbering up）。**增产靠运行更长时间或并联系列，而不是重新设计一台传热更差的大容器。

也有缺点。固体会堵塞细通道；慢反应需要长管或大体积；开停车产生不合格物料；设备、泵与在线分析（原则 11）更复杂。流动是一个强有力的选项，不是普适答案。

::: example 流动反应器的选型 {#ex-flow}
某一级反应在所选温度下 $k = 0.20\ \mathrm{min^{-1}}$。(a) PFR 中达到 $95\,\%$ 转化率需要多少停留时间？通量 $50\ \mathrm{cm^3\,min^{-1}}$ 时体积多大？(b) 内径 $2.0\ \mathrm{mm}$ 的管要多长？(c) 单台 CSTR 需要多少停留时间？
::: solution
(a) $k\tau = -\ln(1 - 0.95) = 3.00$，故 $\tau = 3.00/0.20 = 15.0\ \mathrm{min}$，$V = Q\tau = 50\times15.0 = 750\ \mathrm{cm^3}$。

(b) 横截面 $\pi(0.10\ \mathrm{cm})^2 = 0.0314\ \mathrm{cm^2}$，故 $L = 750/0.0314\ \mathrm{cm} = 2.39\times10^{4}\ \mathrm{cm} = 239\ \mathrm{m}$——很长的盘管，实际中会用更粗的管或多根并联盘管，或提高反应温度以增大 $k$（反应快十倍只需 $24\ \mathrm{m}$）。

(c) $k\tau = X/(1 - X) = 19$，$\tau = 95\ \mathrm{min}$：长六倍多。$50\ \mathrm{cm^3\,min^{-1}}$ 的通量即每天 $72\ \mathrm{dm^3}$，用一台持液 $0.75\ \mathrm{dm^3}$ 的反应器就足以生产千克级的精细化学品。
:::
:::

::: history 溶剂在审视之下 {#hist-solvents}
乔尔·希尔德布兰（Joel Hildebrand）在 1930 年代引入溶解度参数，并与罗伯特·斯科特（Robert Scott）发展了正规溶液理论（*The Solubility of Nonelectrolytes*，1950）；查尔斯·汉森（Charles Hansen）在 1967 年的博士论文中提出其三分量参数。《蒙特利尔议定书》（1987）作为臭氧层消耗物质淘汰了四氯化碳与 1,1,1-三氯乙烷，这是第一次大规模强制的溶剂替代。库尔特·佐塞尔的超临界脱咖啡因 1978 年起在德国商业化。罗纳德·布雷斯洛 1980 年报告了水中狄尔斯-阿尔德反应的疏水加速；肯尼斯·塞登（Kenneth Seddon）等在 1990 年代倡导离子液体，BASF 的 BASIL 工艺 2002 年投产。辉瑞（2008）、GSK（2011、2016）、赛诺菲（2013）与 CHEM21 联盟（2016）发表了溶剂选择指南。ICH Q3C 残留溶剂指南于 1997 年首次通过。药物的连续流合成从 2000 年代的学术演示走向商业制造，并有 ICH Q13 指南（2022）支持。
:::

## 后续内容

溶剂将在 [[green-chemistry/renewable-feedstocks]] 中再次出现——那里纤维素加工需要特殊溶剂（离子液体、制莱赛尔纤维用的 N-甲基吗啉-N-氧化物），生物催化大多在水中；也将在 [[green-chemistry/circular-economy]] 中再次出现——塑料的溶剂法回收与 REACH 监管在那里重新登场。混合热力学在 [[thermodynamics/mixtures]] 展开；反应器类型的分析是化学反应工程的课题，见 Moulijn、Makkee 与 van Diepen 的《Chemical Process Technology》。

::: summary
- 溶剂通常占制药制造所用物料的一半以上，危害也主要在这里；少用溶剂常是最有效的改变。
- 希尔德布兰参数 $\delta = [(\Delta_\mathrm{vap}H - RT)/V_\mathrm{m}]^{1/2}$ 与正规溶液结果 $\Delta_\mathrm{mix}H \approx V\phi_1\phi_2(\delta_1 - \delta_2)^2$ 把“相似相溶”定量化；汉森的三个参数与距离 $R_\mathrm{a}$ 处理极性与氢键液体并指导替代。
- 选择指南（辉瑞、GSK、赛诺菲、CHEM21）把溶剂分为推荐、有问题、危险与高度危险；REACH 限制 NMP 与 DMF，美国 EPA 2024 年的 TSCA 规则限制二氯甲烷，ICH Q3C 为药品设定残留限度。
- 蒸气压（克劳修斯-克拉佩龙）主宰火灾、暴露与 VOC 危害；单凭低挥发性（离子液体）不能使溶剂变绿。
- 水、超临界 $\mathrm{CO_2}$（$T_\mathrm{c} = 31.0\,^\circ\mathrm{C}$，$p_\mathrm{c} = 7.38\ \mathrm{MPa}$）、生物基溶剂、低共熔溶剂与机械化学各以各自的局限解决各自的问题。
- 流动中 $\tau = V/Q$；一级转化率在平推流中为 $1 - \mathrm{e}^{-k\tau}$，在 CSTR 中为 $k\tau/(1 + k\tau)$。细通道带来大 $A/V$、小存量与高温高压的可达性。
:::

## 练习

::: exercise 停留时间 {level=1 check="10"}
一台 $20\ \mathrm{cm^3}$ 盘管反应器的进料为 $2.0\ \mathrm{cm^3\,min^{-1}}$。停留时间是多少？（以分钟计。）
::: solution
$\tau = V/Q = 20/2.0 = 10\ \mathrm{min}$。
:::
:::

::: exercise 一个希尔德布兰参数 {level=1 check="16.8"}
环己烷在 $25\,^\circ\mathrm{C}$ 的 $\Delta_\mathrm{vap}H = 33.0\ \mathrm{kJ\,mol^{-1}}$，$M = 84.16\ \mathrm{g\,mol^{-1}}$，密度 $0.774\ \mathrm{g\,cm^{-3}}$。计算它的希尔德布兰参数。（$\delta$ 以 $\mathrm{MPa^{1/2}}$ 计，保留三位有效数字。）
::: solution
$V_\mathrm{m} = 84.16/0.774 = 108.7\ \mathrm{cm^3\,mol^{-1}}$；$\Delta_\mathrm{vap}H - RT = 33\,000 - 2479 = 30\,521\ \mathrm{J\,mol^{-1}}$；$\delta = (30\,521/108.7)^{1/2} = (280.8)^{1/2} = 16.8\ \mathrm{MPa^{1/2}}$，与手册值一致。
:::
:::

::: exercise 平推流的转化率 {level=1 check="86.5"}
$k = 0.20\ \mathrm{min^{-1}}$ 的一级反应在 $\tau = 10\ \mathrm{min}$ 的平推流反应器中进行。求转化率。（以百分比计。）
::: solution
$X = 1 - \mathrm{e}^{-2.0} = 1 - 0.135 = 0.865$，即 $86.5\,\%$。同样的 $\tau$ 在单台 CSTR 中将是 $2.0/3.0 = 66.7\,\%$。
:::
:::

::: exercise 汉森距离 {level=2 check="3.13"}
用汉森参数二氯甲烷 $(17.0, 7.3, 7.1)$ 与乙酸乙酯 $(15.8, 5.3, 7.2)\ \mathrm{MPa^{1/2}}$，计算 $R_\mathrm{a}$。（以 $\mathrm{MPa^{1/2}}$ 计，保留三位有效数字。）
::: solution
$R_\mathrm{a} = [4(1.2)^2 + (2.0)^2 + (0.1)^2]^{1/2} = (5.76 + 4.00 + 0.01)^{1/2} = 9.77^{1/2} = 3.13\ \mathrm{MPa^{1/2}}$。作为对照，DCM 到 2-MeTHF $(16.9, 5.0, 4.3)$ 是 $3.63$。两者都足够近，值得作为许多溶质的替代品试验，与实践相符。
:::
:::

::: exercise 全混釜的体积代价 {level=2 check="3.91"}
一级反应在相同流率下达到 $90\,\%$ 转化率，单台 CSTR 的体积须比 PFR 大多少倍？（倍数保留三位有效数字。）
::: solution
$\tau_\mathrm{CSTR}/\tau_\mathrm{PFR} = [X/(1 - X)]/[-\ln(1 - X)] = 9.0/2.303 = 3.91$。$99\,\%$ 转化率下倍数为 $99/4.605 = 21.5$：代价随转化率迅速增大。
:::
:::

::: exercise 多少蒸气？ {level=2 check="48.3"}
由二氯甲烷的正常沸点（$39.6\,^\circ\mathrm{C}$）与 $\Delta_\mathrm{vap}H = 28.8\ \mathrm{kJ\,mol^{-1}}$，估算它在 $20\,^\circ\mathrm{C}$ 的蒸气压，以及空气中的平衡蒸气浓度（$M = 84.93\ \mathrm{g\,mol^{-1}}$）。（蒸气压以 kPa 计，保留三位有效数字。）
::: solution
$\ln(p/p^\ominus) = -(28\,800/8.314)(1/293.15 - 1/312.75) = -3464.0\times2.138\times10^{-4} = -0.7405$，故 $p = 101.325\times0.4769 = 48.3\ \mathrm{kPa}$（实测约 $47\ \mathrm{kPa}$）。浓度：$c = pM/RT = 48\,300\times84.93/(8.314\times293.15)\ \mathrm{g\,m^{-3}} = 1.68\times10^{3}\ \mathrm{g\,m^{-3}}$，即饱和空气中 $1.7\ \mathrm{kg\,m^{-3}}$——比典型的职业接触限值（约每立方米数百毫克）高约四个数量级。这就是凡仍在使用 DCM 之处必须密闭操作并设局部排风的原因。
:::
:::

::: exercise 正规溶液的混合焓 {level=3 check="2.7"}
用几何平均规则从晶格模型推导[[#eq-regular]]，并用它估算正己烷（$\delta = 14.9$）与甲苯（$\delta = 18.2\ \mathrm{MPa^{1/2}}$）50:50（体积）混合物每立方厘米的混合焓。（答案以 $\mathrm{J\,cm^{-3}}$ 计，保留两位有效数字。）
::: hint
以概率 $\phi_1^2$、$\phi_2^2$、$2\phi_1\phi_2$ 计数接触；用 $c_{12} = \sqrt{c_{11}c_{22}}$。
:::
::: solution
推导即[[#prop-regular]]的推导。数值上，$\phi_1\phi_2(\delta_1 - \delta_2)^2 = 0.25\times3.3^2 = 2.7\ \mathrm{J\,cm^{-3}}$。对摩尔体积约 $120\ \mathrm{cm^3\,mol^{-1}}$ 的混合物，这是 $0.33\ \mathrm{kJ\,mol^{-1}}$，远小于理想混合熵项 $-T\Delta_\mathrm{mix}S \approx -RT\times2\times0.5\ln2 = -1.7\ \mathrm{kJ\,mol^{-1}}$（摩尔分数取近 $0.5$），所以两液体任意比例互溶，与观察相符。
:::
:::

::: exercise 以数放大 {level=3 check="133"}
某产品要在停留时间 $2.0\ \mathrm{min}$ 的管式反应器中每年生产 $100\ \mathrm{t}$（运行 $8000\ \mathrm{h}$）；反应混合物密度 $1.0\ \mathrm{kg\,dm^{-3}}$。求反应器体积，以及内径 $2.0\ \mathrm{mm}$ 所需管长。与每批 $1.0\ \mathrm{t}$ 的间歇工艺比较在线存量。（管长以米计，保留三位有效数字。）
::: solution
通量 $= 10^{5}\ \mathrm{kg}/8000\ \mathrm{h} = 12.5\ \mathrm{kg\,h^{-1}} = 12.5\ \mathrm{dm^3\,h^{-1}}$。体积 $= 12.5\times(2.0/60) = 0.417\ \mathrm{dm^3}$。横截面 $\pi(1.0\times10^{-3}\ \mathrm{m})^2 = 3.14\times10^{-6}\ \mathrm{m^2}$，故 $L = 4.17\times10^{-4}/3.14\times10^{-6} = 133\ \mathrm{m}$。反应在线存量为 $0.42\ \mathrm{kg}$，而间歇工艺为 $1000\ \mathrm{kg}$：相差 $2400$ 倍。$133\ \mathrm{m}$ 的盘管尚属可行，但更常见的做法是用十根并联的 $13\ \mathrm{m}$ 通道或更粗的管加静态混合器提供同样的体积，以保持压降可控。
:::
