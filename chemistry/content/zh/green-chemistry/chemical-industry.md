几乎所有人造物都要在某个阶段经过化学工业。种出你面包里小麦的化肥、你手机外壳的聚合物、洗涤剂、油漆、墙里的保温材料、医院药房里的药品、水龙头里流出的净水，全都依赖由寥寥几种原材料制成的数百种大宗化学品：天然气、原油、煤、盐、空气、水、硫、磷矿石，以及越来越多的生物质。这个工业是一张网络：一座工厂的产出是另一座的进料，常常就靠同一基地内的管道输送；乙烯这样的单一产品可能有几十种衍生物，用于成千上万种场合。

工业化学不同于实验室化学，不是因为反应不同——反应的还是那些反应——而是因为规模改变了什么才要紧。在实验室，评价一个反应看它能否成功、产物有多纯；在一座年产百万吨的工厂，选择性提高 $1\,\%$ 可能比一个新分子更值钱，反应放出的热量可能决定全厂是否安全，把产物从溶剂中分离出来的成本可能超过反应本身的成本。本章概览工业的结构、大宗/精细/专用的分类、规模经济、描述一台真实反应器所用的转化率、选择性与循环的词汇，以及一个反应不能简单放大的物理原因——首当其冲的是传热。下面两章把这些思想应用于最大的无机与有机工艺。

## 化学价值链

这个工业通常被描述为一条从原材料到消费品、每一阶段增加价值并减小数量的链。

| 阶段 | 例子 | 典型规模 |
|---|---|---|
| 原材料 | 天然气、乙烷、石脑油、煤；盐、硫、磷矿石；空气、水；生物质 | $10^8$–$10^9\ \mathrm{t\,a^{-1}}$ |
| 基础（一次）化学品 | 氨、甲醇、乙烯、丙烯、丁二烯、苯、甲苯、二甲苯；硫酸、氯、氢氧化钠 | 各 $10^7$–$10^8\ \mathrm{t\,a^{-1}}$ |
| 中间体 | 环氧乙烷、氯乙烯、苯乙烯、对苯二甲酸、乙酸、苯酚、己内酰胺、硝酸 | $10^6$–$10^7\ \mathrm{t\,a^{-1}}$ |
| 产品 | 聚合物、化肥、溶剂、表面活性剂、染料、农化品、药品、催化剂 | $1$–$10^7\ \mathrm{t\,a^{-1}}$ |

国际能源署（IEA）把七种基础化学品归为**一次化学品**——氨、甲醇，以及“高价值化学品”乙烯、丙烯、苯、甲苯和混合二甲苯——因为它们占了该部门能耗与排放的大部分。2022 年它们的直接 $\mathrm{CO_2}$ 排放约 $935\ \mathrm{Mt}$，其中氨约占 $45\,\%$、甲醇 $28\,\%$、高价值化学品 $27\,\%$（IEA《化工》追踪报告，截至 2026 年的最新数值）。化工部门是石油和天然气最大的工业消费者，其中大量是作为**原料**（feedstock）——进入产品的碳和氢——而不是作为燃料。这一区别对脱碳至关重要：燃料原则上可以用电力替代，但原料碳总得有个出处（[[green-chemistry/renewable-feedstocks]]、[[green-chemistry/carbon-hydrogen]]）。

按销售额计，2022 年全球化工销售约 $5.4$ 万亿欧元（Cefic，《欧洲化学工业的事实与数字》2023 年版）。地理格局变化很快：据 Cefic 2025 年版，2024 年中国占全球化工销售约 $46\,\%$，高于 2009 年的约 $24\,\%$；同期欧盟份额从约 $21\,\%$ 降到 $13\,\%$，欧盟化工营业额约 $6350$ 亿欧元，雇员约 $120$ 万。这类数字每年修订，并取决于汇率以及什么被算作“化学品”（药品通常除外），所以最好只用来看数量级和趋势。

::: definition 大宗、精细、专用与日用化学品 {#def-classes}
化学品按其制造和销售方式分类：

- **大宗（通用）化学品**以大批量（$\gtrsim 10^4\ \mathrm{t\,a^{-1}}$，常达 $10^6$）在专用连续装置中生产，**按规格**（组成与纯度）销售，单价低且随原料成本波动；多家生产者制造完全相同的产品，竞争在于成本。
- **精细化学品**是较小批量（$10$–$10^4\ \mathrm{t\,a^{-1}}$）在多用途间歇装置中生产的纯单一化合物，同样按规格销售但价格高得多：医药与农化中间体和活性成分、维生素、香料化合物。
- **专用（性能）化学品**是**按功能**销售的——卖的是它能做什么而非它是什么——且常为复配混合物：催化剂、添加剂、涂料、黏合剂、电子化学品、水处理剂。其价值在于性能与服务。
- **日用化学品**是售给公众的配方产品：洗涤剂、化妆品、油漆。

各类之间界限模糊，一个化合物会随市场成长而在类别间迁移。
:::

各类化学品面临的绿色化学问题不同。大宗工艺的 E 因子低（[[green-chemistry/green-metrics]]），但物料和能量的绝对流量巨大，所以主要挑战是能量、$\mathrm{CO_2}$ 和原料。精细化学品与制药工艺因多步合成、化学计量试剂和溶剂而 E 因子高，所以主要挑战是质量效率和危害。专用化学品和日用消费品则是报废期问题——持久性、使用中的毒性、可回收性——最尖锐的地方（[[green-chemistry/circular-economy]]）。

## 转化率、选择性与产率

在实验室里，“产率”通常指一次实验的分离产率。工业反应器由三个相关量描述，因为未反应的进料几乎总是被分离并循环。

::: definition 转化率、选择性与产率 {#def-xsy}
一台反应器投入关键反应物 $\mathrm{A}$ $n_{\mathrm{A},0}$ 摩尔，其中 $n_\mathrm{A}$ 未反应地离开，生成目标产物 $\mathrm{P}$ $n_\mathrm{P}$ 摩尔（化学计量比 $\nu_\mathrm{A}/\nu_\mathrm{P}$，即每摩尔 $\mathrm{P}$ 对应消耗的 $\mathrm{A}$ 摩尔数）：

- **转化率** $X = (n_{\mathrm{A},0} - n_\mathrm{A})/n_{\mathrm{A},0}$，被消耗的 $\mathrm{A}$ 的份额；
- **选择性** $S = (\nu_\mathrm{A}/\nu_\mathrm{P})\,n_\mathrm{P}/(n_{\mathrm{A},0} - n_\mathrm{A})$，被消耗的 $\mathrm{A}$ 中变成 $\mathrm{P}$ 的份额；
- **产率** $Y = (\nu_\mathrm{A}/\nu_\mathrm{P})\,n_\mathrm{P}/n_{\mathrm{A},0}$，投入的 $\mathrm{A}$ 中变成 $\mathrm{P}$ 的份额。

立即可得 $Y = X\,S$。对连续反应器，同样定义适用于摩尔流率；“单程”量指物料通过反应器一次。
:::

转化率低但选择性高的反应，常常优于转化率高而选择性较低的反应，因为未转化的进料可以回收循环，而变成副产品的进料就永远失去了。许多工业反应有串联副反应——产物进一步反应成不需要的东西——选择性随转化率升高而下降（[[green-chemistry/petrochemicals]] 对部分氧化作了分析），所以反应器常被有意控制在适中的单程转化率下运行，未反应的进料予以循环。

::: proposition 低单程转化率下的循环 {#prop-recycle}
考虑一台单程转化率 $X$、选择性 $S$ 的反应器，其后接一台分离器，把全部未反应的 $\mathrm{A}$ 回收并送回反应器入口，与新鲜进料 $F$（单位时间的 $\mathrm{A}$ 摩尔数）混合。稳态下无吹扫排放（purge，即从回路连续放空的少量气体），新鲜 $\mathrm{A}$ 的总转化率为 $1$，总产率为 $S$，循环流率 $R$ 与反应器入口流率 $F + R$ 为
$$
R = F\,\frac{1 - X}{X}, \qquad F + R = \frac{F}{X} .
$$ {#eq-recycle}
:::

::: proof
稳态下没有积累，进入系统的每一摩尔 $\mathrm{A}$ 必须离开或反应。回收完全时，未反应的 $\mathrm{A}$ 永不离开；于是全部新鲜 $\mathrm{A}$ 都会反应，其中份额 $S$ 变成 $\mathrm{P}$。对反应器作衡算，入口流率 $F + R$ 以程度 $X$ 转化，离开的未反应流率为 $(1 - X)(F + R)$，它就是循环流 $R$。解 $R = (1 - X)(F + R)$ 得 $RX = (1 - X)F$，即[[#eq-recycle]]。因此，$X$ 低的代价不是物料损失，而是按流率 $F/X$ 选型的、更大的反应器、压缩机和分离器。
:::

::: example 氨合成回路 {#ex-loop}
氨厂中合成气在合成塔内的单程转化率受平衡限制，约 $15\,\%$（[[green-chemistry/industrial-inorganic]]）。氨冷凝分出，未反应气体循环。取 $X = 0.15$ 并忽略惰性组分，求循环与新鲜进料之比，以及合成塔相对新鲜进料必须超配的倍数。
::: solution
由[[#eq-recycle]]，$R/F = (1 - 0.15)/0.15 = 5.67$：每摩尔新鲜气体对应近六摩尔循环气体。合成塔要处理 $F/X = 6.67$ 倍于新鲜进料的物料。循环压缩机必须补回回路中损失的压力，氨的冷凝又需要冷冻；两者都耗能。真实回路还含有来自合成气的少量甲烷和氩，它们不反应，没有**吹扫排放**——从回路气体放出的少量流股——就会不断积累。吹扫排放除去了惰性组分，但也损失一部分氢和氮（[[#exr-purge]]），所以回路是吹扫损失与惰性组分稀释反应物之间的折衷。
:::
:::

## 规模经济

为什么大宗化学品要在巨型工厂里生产？部分因为大厂每吨所需工人更少，且能整合热量与副产品；但主要原因是几何学。

::: proposition 0.6 次方法则 {#prop-six-tenths}
化工装置的建设投资 $C$ 随其产能 $Q$ 近似地按
$$
\frac{C_2}{C_1} = \left(\frac{Q_2}{Q_1}\right)^{n}, \qquad n \approx 0.6 ,
$$ {#eq-six-tenths}
标度，因此**单位产能**的投资按 $Q^{\,n - 1} \approx Q^{-0.4}$ 下降。指数是经验值，不同设备与工厂在约 $0.4$ 到 $0.9$ 之间；该法则只在能沿用同一设计的尺寸范围内成立。
:::

::: proof
一个启发式推导能解释其数值的由来。容器、塔或管的产能正比于其体积，即对特征长度 $L$ 有 $V \propto L^3$。其成本大致正比于金属质量，而给定壁厚下质量正比于表面积，即 $A \propto L^2 \propto V^{2/3}$。故 $C \propto Q^{2/3} \approx Q^{0.67}$。压力容器壁厚随直径增大（半径 $r$、压力 $p$ 的圆筒环向应力为 $pr/t$，故定应力下 $t \propto r$），这使高压设备的指数趋向 $1$；完全不随尺寸变化的成本——仪表、控制系统、设计与工程——又把它压低。由威廉斯（R. Williams）1947 年从成本数据确立的平均值约 $0.6$，正是这种混合的反映。该法则不是定律；超过某一规模它就会失效，因为能达到最大可制造或可运输尺寸的设备已到顶，更多产能只能以平行系列追加。
:::

:::

::: example 工厂放大 {#ex-scale}
一座产能 $50\ \mathrm{kt\,a^{-1}}$ 的工厂造价 $80$ 百万（货币单位）。用 0.6 次方法则估算一座 $500\ \mathrm{kt\,a^{-1}}$ 工厂的造价，以及每吨产能投资之比。
::: solution
$C_2 = 80\times(500/50)^{0.6} = 80\times10^{0.6} = 80\times3.98 = 318$ 百万。按每年每吨产能计：$80\,\mathrm{M}/50\,\mathrm{kt} = 1600$ 每吨，对 $318\,\mathrm{M}/500\,\mathrm{kt} = 637$ 每吨，比值 $10^{-0.4} = 0.40$。规模十倍增长使每吨资本投资降低 $60\,\%$。这解释了单系列能力持续攀升的现象——乙烯蒸汽裂解炉超过 $1.5\ \mathrm{Mt\,a^{-1}}$、氨厂日产超过 $3000\ \mathrm{t}$——也解释了大宗部门的脆弱：巨型工厂必须接近满负荷运行才能收回资本，而需求下滑时最先关闭的总是较小的老厂。
:::
:::

衡量设备使用强度的补充量是**时空产率**：单位反应器体积单位时间的产品质量（$\mathrm{kg\,m^{-3}\,h^{-1}}$）。大宗催化过程可达数百至数千；间歇精细化工过程由于进料、升温、冷却、出料的周期长，往往只有个位数。提高时空产率——用更快的反应、更高的浓度或连续操作——可减少给定产量所需的工厂规模，这正是**过程强化**（[[green-chemistry/safer-solvents]]）的目标之一。

## 从烧瓶到工厂：热

在 $250\ \mathrm{cm^3}$ 烧瓶里放热温和的反应，到 $10\ \mathrm{m^3}$ 反应器里可能完全无法控制。原因是：生成的热随反应混合物的体积增长，而经器壁移出的热只随其面积增长。

::: definition 绝热温升 {#def-dtad}
反应混合物的**绝热温升**是反应进行到底而不与环境换热时温度将升高的度数：
$$
\Delta T_\mathrm{ad} = \frac{(-\Delta_\mathrm{r}H)\,c_\mathrm{A,0}}{\rho\,c_p} = \frac{(-\Delta_\mathrm{r}H)\,b_\mathrm{A,0}}{c_p} ,
$$ {#eq-dtad}
其中 $c_\mathrm{A,0}$ 是限量反应物的初始浓度（单位体积的摩尔数），$b_\mathrm{A,0}$ 是按单位质量混合物的同一量，$\rho$ 为混合物密度，$c_p$ 为其比热容，$\Delta_\mathrm{r}H$ 按限量反应物的每摩尔计。它是热危害评估的起点：若 $\Delta T_\mathrm{ad}$ 足以使混合物越过溶剂沸点或某个分解的起始温度，它就是潜在的飞温体系。
:::

::: example 能热到什么程度？ {#ex-dtad}
一批间歇反应按每千克混合物 $2.0\ \mathrm{mol}$ 限量反应物投料；$\Delta_\mathrm{r}H = -150\ \mathrm{kJ}$ 每摩尔限量反应物，$c_p = 1.8\ \mathrm{kJ\,kg^{-1}\,K^{-1}}$。求 $\Delta T_\mathrm{ad}$，并就 $40\,^\circ\mathrm{C}$ 开始、溶剂沸点为 $110\,^\circ\mathrm{C}$ 的反应作出评论。
::: solution
$$
\Delta T_\mathrm{ad} = \frac{150\ \mathrm{kJ\,mol^{-1}}\times2.0\ \mathrm{mol\,kg^{-1}}}{1.8\ \mathrm{kJ\,kg^{-1}\,K^{-1}}} = 167\ \mathrm{K}.
$$
若全部反应物一次投料且冷却失效，混合物将向 $40 + 167 = 207\,^\circ\mathrm{C}$ 升温；实际上它会在 $110\,^\circ\mathrm{C}$ 沸腾，蒸气的产生可能使容器超压，而任何起始温度低于 $207\,^\circ\mathrm{C}$ 的分解都可能被触发。标准对策是**滴加**一种反应物，使任一时未反应量都很小（决定最坏情况的是累积量而非总量）、稀释（代价是更多溶剂和更高的过程质量强度）、或把反应移到小型连续反应器中进行。这类热数据在放大前由反应量热法和差示扫描量热法测定。
:::
:::

::: proposition 移热与规模 {#prop-heat-scale}
对特征尺寸为 $L$ 的几何相似容器，按给定单位体积速率进行的反应，其放热速率按 $L^3$ 标度；而给定总传热系数 $U$ 与温差下经器壁的最大移热速率按 $L^2$ 标度：
$$
\frac{\dot Q_\mathrm{gen}}{\dot Q_\mathrm{rem}} = \frac{r\,(-\Delta_\mathrm{r}H)\,V}{U A\,\Delta T} \ \propto\ \frac{V}{A} \ \propto\ L .
$$
对高与直径均为 $D$、整个表面冷却的圆筒，$A/V = 6/D$；体积放大 $k$ 倍使 $A/V$ 缩小 $k^{1/3}$。
:::

::: proof
放热速率是单位体积反应速率 $r$（在放大中保持浓度与温度不变，$r$ 即被固定）乘 $-\Delta_\mathrm{r}H$ 乘体积 $V$。经器壁的移热是 $UA\,\Delta T$（牛顿冷却定律），$\Delta T$ 受可用冷却介质限制。几何相似意味着一切长度都按 $L$ 标度，故 $V \propto L^3$、$A \propto L^2$，比值按 $V/A \propto L$ 标度。对直径 $D$、高 $D$ 的圆筒：$V = \pi D^3/4$，$A = \pi D^2 + 2(\pi D^2/4) = 3\pi D^2/2$，故 $A/V = 6/D$。由于 $D \propto V^{1/3}$，$V$ 乘 $k$ 使 $A/V$ 除以 $k^{1/3}$。（$U$ 在放大时也会变，因为搅拌与壁厚变了，但不足以补偿。）
:::

::: example 从一升到十立方米 {#ex-av}
比较 $1.0\ \mathrm{dm^3}$ 容器与 $10\ \mathrm{m^3}$ 反应器的面积体积比，两者均为高与直径相等的圆筒。
::: solution
$V = 1.0\times10^{-3}\ \mathrm{m^3}$ 时，$D = (4V/\pi)^{1/3} = 0.108\ \mathrm{m}$，$A/V = 6/D = 55\ \mathrm{m^{-1}}$。$V = 10\ \mathrm{m^3}$ 时，$D = 2.34\ \mathrm{m}$，$A/V = 2.6\ \mathrm{m^{-1}}$。比值为 $(10/10^{-3})^{1/3} = 21.5$。在实验室里热量轻易移得走的反应，在工厂里按单位冷却面积计放热多出 $21.5$ 倍；要保持同样温度，必须放慢滴加速率——批次时间相应拉长近同样的倍数——或增设冷却（内盘管、外循环回路、回流冷凝器）。直径 $1\ \mathrm{mm}$ 的微反应器通道 $A/V = 4/d = 4000\ \mathrm{m^{-1}}$，这就是快速、强放热反应日益改在连续流中进行的原因。
:::
:::

### 热失控

危险不只是冷却慢，而是冷却可能被追上。放热经阿伦尼乌斯因子随温度指数上升，移热只线性上升。谢苗诺夫（Semyonov）1928 年针对气相爆炸最初提出的分析，说明了这何时导致飞温。

::: proposition 热失控的谢苗诺夫判据 {#prop-semenov}
对温度 $T$ 的良好混合反应器，冷却介质为 $T_\mathrm{c}$，设放热 $\dot Q_\mathrm{g} = B\exp(-E_\mathrm{a}/RT)$（忽略反应物消耗）、移热 $\dot Q_\mathrm{r} = UA(T - T_\mathrm{c})$。稳定的定常态仅当直线 $\dot Q_\mathrm{r}$ 与曲线 $\dot Q_\mathrm{g}$ 相交时才存在；临界条件是相切，此时
$$
T_* - T_\mathrm{c} = \frac{R T_*^2}{E_\mathrm{a}} \approx \frac{R T_\mathrm{c}^2}{E_\mathrm{a}} .
$$ {#eq-semenov}
若冷却介质温度升过临界值（或 $UA$ 降过临界值），反应器温度将失去控制地跳升。
:::

::: proof
临界点上热平衡与其导数平衡同时成立：$B\exp(-E_\mathrm{a}/RT_*) = UA(T_* - T_\mathrm{c})$ 且 $B\exp(-E_\mathrm{a}/RT_*)\,E_\mathrm{a}/RT_*^2 = UA$。第一式除以第二式得 $T_* - T_\mathrm{c} = RT_*^2/E_\mathrm{a}$。这个关于 $T_*$ 的二次方程 $RT_*^2 - E_\mathrm{a}T_* + E_\mathrm{a}T_\mathrm{c} = 0$ 的物理相关根为 $T_* = [E_\mathrm{a} - \sqrt{E_\mathrm{a}^2 - 4E_\mathrm{a}RT_\mathrm{c}}]/2R$；对小 $RT_\mathrm{c}/E_\mathrm{a}$ 展开得 $T_* \approx T_\mathrm{c} + RT_\mathrm{c}^2/E_\mathrm{a}$。相切之下，较低交点是稳定的：温度小升时移热的增加大于放热。相切之上，高温分支以下不存在交点，温度一路升高直到反应物耗尽。
:::

::: warning “实验室里做成功了”不是安全评估 {#warn-scaleup}
实验室烧瓶单位体积的表面积大，而且在实验台上化学家可以观察并干预。放大后，单位体积移热下降一个数量级（[[#ex-av]]），混合时间从秒变成分钟，一分钟加完的加料要加一小时，哪些反应相互竞争也随之改变。间歇装置的若干严重事故——包括 1976 年的塞维索（Seveso）泄漏——都涉及小尺度表现良好、大尺度或批次处于反常状态时发生飞温的反应。放大之前，工艺化学家要测定反应热、$\Delta T_\mathrm{ad}$、滴加期间未反应试剂的累积量以及各分解的起始温度，并进行结构化的危害研究（例如 HAZOP，危险与可操作性分析）。在欧盟，存有大量危险物质的场所受《塞维索 III 号指令》（2012/18/EU）监管，要求提交安全报告并制定应急计划。
:::

## 间歇、连续与工厂的形态

化工厂由为数不多的**单元操作**构成——这是利特尔（Arthur D. Little）1915 年在麻省理工学院提出的概念：反应、换热、混合、精馏、吸收、萃取、结晶、过滤、干燥、粉碎、压缩、泵送。任何工艺都可画成把这些操作连接起来的**工艺流程图**。典型的连续工厂有一个进料制备段、一台反应器，以及一个大得多的分离段，用来回收产品、循环未反应进料、脱除副产品。在多数大宗工艺中，占资本和能量大头的是**分离**而不是反应：仅精馏一项，就常被估计占化工与炼油工业能耗的很大一部分，因为它把整股物流气化再冷凝，只为分离挥发性可能只差一点的组分。

| | 间歇 | 连续 |
|---|---|---|
| 典型产品 | 精细化学品、制药、专用化学品 | 大宗化学品、聚合物、燃料 |
| 规模 | 每年千克至数千吨 | 每年 $10^4$ 至 $10^6$ 吨 |
| 灵活性 | 一套装置，多种产品 | 一套装置，一种产品 |
| 危险物在线量 | 整批物料 | 仅反应器持料量 |
| 质量控制 | 按批检验放行 | 连续监测 |
| 停机时间 | 进料、升温、冷却、清洗 | 仅开停车 |

传统的分工正在松动。制药厂商已在监管鼓励下引入连续工艺（关于原料药与制剂连续制造的 ICH Q13 指南于 2022 年通过），因为流动反应器传热更好、在线存量更小、质量更稳定；模块化、集装箱式的工厂也在为较小批量的产品建造。相关技术在 [[green-chemistry/safer-solvents]] 讨论。

::: quiz
某反应单程转化率 $25\,\%$、选择性 $96\,\%$；未反应进料完全回收并循环。以新鲜进料计，产品的总产率是多少？
- [ ] $24\,\%$
- [ ] $25\,\%$
- [x] $96\,\%$
- [ ] $100\,\%$
::: solution
完全循环时，全部新鲜进料终归会反应完（[[#prop-recycle]]），所以总转化率为 $1$、总产率等于选择性 $96\,\%$。单程产率 $XS = 24\,\%$ 描述的是通过反应器一次，而不是整个工艺。低的单程转化率的代价是三倍于新鲜进料的循环流。
:::
:::

## 经济学与绿色化学议程

工艺设计者做的第一个估算是**经济潜力**：在产品价值减去原材料成本之后、任何设备设计开始之前，每年的差额。它就是一张带价格的物料衡算，也解释了为什么大宗工艺的材料利用如此高效。原材料通常占大宗化学品生产成本一半以上，所以选择性就是金钱：一座以每吨 €$600$ 的进料生产价值 €$1000$ 每吨的产品 $10^6\ \mathrm{t\,a^{-1}}$ 的工厂，选择性损失 $1\,\%$ 就是每年约六百万欧元白白扔掉的进料——还不计处理副产品的费用。能量通常是第二大成本。

经济利益与环境利益的一致——少废、少能就是低成本——正是大宗工业早在绿色化学得名之前很久就达到低 E 因子的原因。也正是在这种一致性最薄弱之处，绿色化学能贡献的最多：精细化工中原料成本只占产品价值一小部分、开发速度更重要；危害在出事之前不计价；以及温室气体这类**外部性**，其代价由社会承担，除非政策为其定价——欧盟排放交易体系自 2005 年起就如此对待大型工业排放者。

::: history 从勒布朗法到一体化基地 {#hist-industry}
现代化学工业始于碱。勒布朗（Leblanc）由盐制碳酸钠的方法（1791 年获专利）在十九世纪初传遍英国，其氯化氢排放之多促使 1863 年《碱业法》设立了第一个工业污染监察机构。珀金（Perkin）的苯胺紫合成（1856）创立了合成染料工业，由此诞生了 BASF（1865）、Bayer 与 Hoechst。索尔维法（1860 年代）取代了勒布朗法，哈伯-博施（Haber–Bosch）氨合成（奥保第一座工厂，1913）引入了高压催化加工。利特尔（Little）的单元操作概念（1915）与 1920 年代第一批化学工程教科书使工艺设计成为一门学科。1945 年以后，石油和天然气取代煤成为主要原料，蒸汽裂解为聚合物工业提供烯烃，大型一体化基地——路德维希港的德国 *Verbund* 是原型——用管道把数百座工厂连接起来，把每座厂的产品与副产品送到下一座。弗里克斯伯勒（Flixborough，1974）、塞维索（Seveso，1976）与博帕尔（Bhopal，1984）的重大事故使工艺安全成为化学工程的核心组成部分。
:::

## 后续内容

本章的词汇——转化率与选择性、循环与吹扫排放、规模经济、绝热温升与移热——在此后每一章都要用到。[[green-chemistry/industrial-inorganic]] 把它用于氨、硫酸、硝酸、氯碱与纯碱，那里的中心问题是如何为一个可放回热的反应选择温度与压力。[[green-chemistry/petrochemicals]] 追踪碳从原油和天然气到基础化学品和聚合物的道路。化学工程背景——反应器设计、物料与能量衡算——在 Moulijn、Makkee 和 van Diepen 的《Chemical Process Technology》等参考书中讲授；催化反应器的动力学在 [[kinetics/surface-kinetics]] 与 [[organometallics-catalysis/heterogeneous-catalysis]]。

::: summary
- 化学工业把少数几种原材料（天然气、石油、煤、盐、空气、水、硫、磷酸盐、生物质）经基础化学品和中间体转化为产品；IEA 的七种一次化学品 2022 年直接排放 $\mathrm{CO_2}$ 约 $935\ \mathrm{Mt}$。
- 大宗化学品在连续装置中大规模按规格销售；精细化学品按规格在间歇装置中销售；专用化学品按功能销售。三者的绿色挑战不同：大宗在于能量与碳，精细在于质量效率与危害。
- 反应器用转化率、选择性与产率（$Y = XS$）描述；完全循环时总产率等于选择性，循环流率为 $F(1 - X)/X$。惰性组分要求吹扫排放。
- 建设投资大致按产能的 $0.6$ 次方标度，故每吨成本按产能的 $-0.4$ 次方下降——这是超大单系列工厂的经验依据。
- 放热按体积标度，移热按面积标度；放大时 $A/V$ 按 $V^{-1/3}$ 下降。绝热温升 $(-\Delta_\mathrm{r}H)b_\mathrm{A,0}/c_p$ 与谢苗诺夫判据 $T_* - T_\mathrm{c} \approx RT^2/E_\mathrm{a}$ 用于评估飞温风险。
- 分离在许多工厂中主宰成本与能耗；经济与环境的利益在材料和能量上一致，但在危害与外部性上并不自动一致。
:::

::: exercise 0.6 次方法则 {level=1 check="151.6"}
一座 $200\ \mathrm{kt\,a^{-1}}$ 的工厂造价 $100$ 百万（货币单位）。用 0.6 次方法则估算一座 $400\ \mathrm{kt\,a^{-1}}$ 工厂的造价。（造价以百万计，保留四位有效数字。）
::: solution
$C = 100\times2^{0.6} = 100\times1.516 = 151.6$ 百万。产能翻倍成本只增 $52\,\%$，所以每吨资本下降 $24\,\%$。
:::
:::

::: exercise 由转化率与选择性求产率 {level=1 check="53.3"}
通过反应器一次转化 $65\,\%$ 的进料，对产品的选择性为 $82\,\%$。单程产率是多少？（以百分比计。）
::: solution
$Y = XS = 0.65\times0.82 = 0.533$，即 $53.3\,\%$。其余 $35\,\%$ 的进料未反应（可以循环）；$0.65\times0.18 = 11.7\,\%$ 变成了副产品。
:::

::: exercise 时空产率 {level=1 check="80"}
一台 $30\ \mathrm{m^3}$ 反应器每小时生产产品 $2.4\ \mathrm{t}$。求时空产率。（以 $\mathrm{kg\,m^{-3}\,h^{-1}}$ 计。）
::: solution
$2400\ \mathrm{kg\,h^{-1}}/30\ \mathrm{m^3} = 80\ \mathrm{kg\,m^{-3}\,h^{-1}}$。
:::

::: exercise 绝热温升 {level=2 check="117"}
某加氢反应每摩尔底物放热 $-\Delta_\mathrm{r}H = 125\ \mathrm{kJ}$。混合物每千克含底物 $1.5\ \mathrm{mol}$，$c_p = 1.6\ \mathrm{kJ\,kg^{-1}\,K^{-1}}$。若全部底物在无冷却下反应，求 $\Delta T_\mathrm{ad}$。（以 K 计，保留三位有效数字。）
::: solution
$\Delta T_\mathrm{ad} = 125\times1.5/1.6 = 117.2\ \mathrm{K} \approx 117\ \mathrm{K}$。加氢反应的速率通常由氢气的供给控制，而供气可以随时切断，所以液相中未反应氢的累积很小——这是慢滴加对液体试剂所提供的同类本质安全特性。
:::
:::

::: exercise 循环比 {level=2 check="4"}
某部分氧化为保选择性在单程转化率 $20\,\%$ 下运行，未反应烃完全回收循环。循环流率与新鲜进料之比是多少？（输入 $R/F$。）
::: solution
$R/F = (1 - X)/X = 0.80/0.20 = 4$。反应器与分离设备要处理五倍于新鲜进料的物料；这笔交易是用更大的工厂换更高的选择性。
:::
:::

::: exercise 冷却的放大 {level=2 check="4.64"}
某工艺从 $0.10\ \mathrm{m^3}$ 的中试反应器放大到几何相似的 $10\ \mathrm{m^3}$ 生产反应器。单位体积的冷却面积缩小多少倍？（保留三位有效数字。）
::: solution
$A/V \propto V^{-1/3}$，故倍数为 $(10/0.10)^{1/3} = 100^{1/3} = 4.64$。若中试在所选滴加速率下用到冷却能力的 $40\,\%$，工厂在同样单位体积速率下将需要 $186\,\%$——不可能做到——因此滴加速率必须放慢到不超过约为中试的一半，或增设冷却面积。
:::
:::

::: exercise 谢苗诺夫温度裕度 {level=3 check="10.2"}
推导临界条件[[#eq-semenov]]，并用近似式求 $E_\mathrm{a} = 100\ \mathrm{kJ\,mol^{-1}}$、在 $350\ \mathrm{K}$ 冷却的反应，其反应器温度高出冷却介质温度的最大稳定值。与精确根比较。（$T_* - T_\mathrm{c}$ 的近似值以 K 计。）
::: hint
同时施加 $\dot Q_\mathrm{g} = \dot Q_\mathrm{r}$ 与 $\mathrm{d}\dot Q_\mathrm{g}/\mathrm{d}T = \mathrm{d}\dot Q_\mathrm{r}/\mathrm{d}T$。
:::
::: solution
推导即[[#prop-semenov]]的推导：两条件相除得 $T_* - T_\mathrm{c} = RT_*^2/E_\mathrm{a}$。近似地，$RT_\mathrm{c}^2/E_\mathrm{a} = 8.314\times350^2/100\,000 = 10.2\ \mathrm{K}$。精确根 $T_* = [E_\mathrm{a} - \sqrt{E_\mathrm{a}^2 - 4E_\mathrm{a}RT_\mathrm{c}}]/2R$，其中 $E_\mathrm{a}/R = 12\,028\ \mathrm{K}$，得 $T_* = 6013.95 - \sqrt{6013.95^2 - 12\,027.9\times350} = 6013.95 - 5653.13 = 360.82\ \mathrm{K}$，即 $T_* - T_\mathrm{c} \approx 10.8\ \mathrm{K}$。一个只在高出冷却介质 $10\ \mathrm{K}$ 时稳定运行的反应器几乎没有裕度，这就是放热间歇工艺要设计在稳定区深处运行的原因。
:::
:::

::: exercise 吹扫排放的损失 {#exr-purge level=3 check="4.52"}
某循环回路的新鲜进料含惰性气体摩尔分数 $z = 0.0050$（其余为反应物）。惰性组分只能经取自循环流的吹扫排放物流离开，其中惰性摩尔分数维持在 $y = 0.10$；吹扫的其余部分是未反应的反应物。证明随吹扫损失的新鲜反应物份额为 $z(1 - y)/[y(1 - z)]$ 并求值。（以百分比计。）
::: hint
稳态下随进料进入的惰性组分必等于随吹扫排出的惰性组分。
:::
::: solution
设新鲜进料总量为 $F$（总摩尔）。惰性衡算：$zF = yP$，故吹扫量 $P = zF/y$。它带走反应物 $(1 - y)P = z(1 - y)F/y$ 摩尔，而新鲜反应物为 $(1 - z)F$。损失份额为
$$
\frac{z(1 - y)}{y(1 - z)} = \frac{0.0050\times0.90}{0.10\times0.995} = 0.0452 ,
$$
即 $4.52\,\%$。允许惰性积累到 $y = 0.20$ 会使损失减半（$2.0\,\%$），但会稀释回路中的反应物，降低反应速率，并使氨合成这类平衡受限反应的单程转化率下降。氨厂从吹扫气中回收氢——常用膜或变压吸附——正是为了减少这一损失。
:::
:::
