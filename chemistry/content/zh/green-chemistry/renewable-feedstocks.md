每年植物通过光合作用从大气中固定的碳约为一千亿吨量级，远超世界燃烧的全部化石燃料所含的碳，而化学工业制造产品只需要几亿吨碳。按这些数字，可再生碳本应轻而易举。它并不是，原因既在经济，也在化学。石油是几乎不含氧的烃类混合物，一个世纪以来工业已学会向它一次加上一个官能团。生物质恰恰相反：纤维素、半纤维素和糖都是多元醇，几乎每个碳原子上都带着一个氧；木质素是结构不规则的交联芳香聚合物；植物油是酯。用生物质制造今天的产品意味着选择性地*移除*氧而不是加入氧，在水相而不是气相中进行，而且原料是组成多变、散布在广大土地上、按季节收获的固体。

本章讲的就是这如何做到。本章先描述生物质的组成，以及一个简明的指数——有效氢碳比，它说明为什么生物质与石油天然地导向不同的产品；然后介绍**平台化学品**——乙醇、乳酸与丁二酸（琥珀酸）、糠醛与 5-羟甲基糠醛、乙酰丙酸、甘油——以及生产它们的**生物精炼**，其中发酵产率受电子衡算限制。后半部分是**生物催化**：酶，无论在活细胞内还是分离出来，作为工业合成的催化剂，以及围绕它们设计工艺所用的动力学与指标。贯穿全章的问题仍是 [[green-chemistry/green-principles#def-lifecycle]] 提出的那一个：只有当整个寿命周期——包括土地、水与化肥——都予以确认时，可再生原料才算优势。生物分子本身的化学在 [[biochemistry/carbohydrates-lipids]]。

## 作为原料的生物质

植物生物质主要是**木质纤维素**，即木材、秸秆与牧草的材料。按干燥质量计，其三种组分的典型比例是：

- **纤维素**（$40$–$50\,\%$）：β-1,4 连接的 D-葡萄糖直链，靠氢键堆积成部分结晶的微纤丝，这使其不溶于水、抗水解；
- **半纤维素**（$20$–$35\,\%$）：木糖、阿拉伯糖、甘露糖及其他糖构成的支化无定形多糖，较易水解；
- **木质素**（$15$–$30\,\%$）：苯丙烷单元（来自松柏醇、芥子醇与对香豆醇）以醚键为主连接成的三维芳香聚合物，它把纤维黏结在一起并抗拒微生物侵蚀。

其他原料有**淀粉**（α-1,4 连接的葡萄糖，易水解，来自玉米、小麦与木薯）、**蔗糖**（来自甘蔗与甜菜）、**植物油**（油棕、大豆、油菜的甘油三酯），以及废物与残余物（秸秆、蔗渣、林业残余物、废食用油、食物废料）。“第一代”生物基工艺使用粮食作物——糖、淀粉与油；“第二代”瞄准木质纤维素与残余物，它们不与粮食直接竞争，但要转化它们却难得多。

::: definition 有效氢碳比 {#def-hc-eff}
对元素组成为 $\mathrm{C}_c\mathrm{H}_h\mathrm{O}_o\mathrm{N}_n\mathrm{S}_s$ 的化合物或原料，**有效氢碳比**（Chen 与合作者，1986）为
$$
(H/C)_\mathrm{eff} = \frac{h - 2o - 3n - 2s}{c} ,
$$ {#eq-hc-eff}
即把所有杂原子以 $\mathrm{H_2O}$、$\mathrm{NH_3}$ 与 $\mathrm{H_2S}$ 的形式名义上移去后每个碳剩余的氢数。烷烃的 $(H/C)_\mathrm{eff} \approx 2$（$\mathrm{C}_c\mathrm{H}_{2c+2}$ 为 $2 + 2/c$），芳烃约 $1$，植物油约 $1.6$，碳水化合物为 $0$。
:::

这个指数能说明许多问题。碳水化合物的 $(H/C)_\mathrm{eff} = 0$，只有靠加氢或排出碳（发酵中排 $\mathrm{CO_2}$，或催化裂解中成焦——这就是糖的沸石加工迅速积碳的原因）才能变成烃类燃料。但它们却是**含氧**产品——酸、醇、多元醇、呋喃——的天然原料，而这些产品石化路线要靠费力的氧化来制。合理的策略是让原料与产品相匹配：用生物质制富氧分子，保留官能度；把烃类留给别的路线。

::: example 生物质与石油产品的氢平衡 {#ex-hc}
比较葡萄糖（$\mathrm{C_6H_{12}O_6}$）、甘油（$\mathrm{C_3H_8O_3}$）、三油酸甘油酯（$\mathrm{C_{57}H_{104}O_6}$）、乙醇（$\mathrm{C_2H_6O}$）与正庚烷（$\mathrm{C_7H_{16}}$）的 $(H/C)_\mathrm{eff}$，并推出把葡萄糖变成正己烷（$\mathrm{C_6H_{14}}$）原则上需要多少氢。
::: solution
由[[#eq-hc-eff]]：葡萄糖 $(12 - 12)/6 = 0$；甘油 $(8 - 6)/3 = 0.67$；三油酸甘油酯 $(104 - 12)/57 = 1.61$；乙醇 $(6 - 2)/2 = 2.0$；正庚烷 $16/7 = 2.29$。

葡萄糖到正己烷：$\mathrm{C_6H_{12}O_6} + n\,\mathrm{H_2} \rightarrow \mathrm{C_6H_{14}} + 6\,\mathrm{H_2O}$。氢衡算：$12 + 2n = 14 + 12$，故 $n = 7$：每摩尔葡萄糖七摩尔氢，每 $86.2\ \mathrm{g}$ 己烷 $14.1\ \mathrm{g}$（每千克 $0.164\ \mathrm{kg}$）。这些氢若由天然气制取，每千克己烷约排放 $1.5\ \mathrm{kg}$ $\mathrm{CO_2}$（[[green-chemistry/carbon-hydrogen]]），把气候效益抵消掉一大块。相比之下，乙醇的有效比值高，因为发酵把三分之一的碳以 $\mathrm{CO_2}$ 排出，$\mathrm{CO_2}$ 把氧带走而不需要外来氢。植物油已经接近烃类，这就是它成为可再生柴油第一条路线的原因。
:::
:::

## 平台化学品与生物精炼

石油炼油厂把原油分成馏分，再把每个馏分转化为许多产品。**生物精炼**对生物质做同样的事：把原料分离成其组分（纤维素与半纤维素制的糖、木质素、油脂、蛋白质），再把每一组分转化为燃料、化学品、材料、食品或饲料以及能量，力求物尽其用。由以之制造产品族的中间分子称为**平台化学品**。美国能源部的报告《Top Value Added Chemicals from Biomass》（Werpy 与 Petersen，2004）选出了十二种糖衍生的砌块；Joseph Bozell 与 Gene Petersen 在 2010 年重审了这份名单，点名乙醇、呋喃类（糠醛、5-羟甲基糠醛（HMF）与 2,5-呋喃二甲酸（FDCA））、甘油及其衍生物、异戊二烯等生物烃、乳酸、丁二酸（琥珀酸）、3-羟基丙酸、乙酰丙酸、山梨醇与木糖醇。

### 发酵及其理论产率

许多平台化学品由**发酵**制造：微生物把糖转化为产物，且在该条件下产物（而非生物质生长）是糖的碳与电子的主要出路。最大产率不是由原子经济性决定，而是由电子衡算决定。

::: definition 还原度 {#def-gamma}
有机化合物 $\mathrm{C}_c\mathrm{H}_h\mathrm{O}_o\mathrm{N}_n$ 按每个碳原子（每 C 摩尔）计的**还原度**为
$$
\gamma = \frac{4c + h - 2o - 3n}{c} ,
$$ {#eq-gamma}
即完全氧化为 $\mathrm{CO_2}$、$\mathrm{H_2O}$ 与 $\mathrm{NH_3}$ 时每个碳释放的电子数，其中 C 计 $+4$、H 计 $+1$、O 计 $-2$、N 计 $-3$。按定义 $\mathrm{CO_2}$、$\mathrm{H_2O}$ 与 $\mathrm{NH_3}$ 的 $\gamma = 0$。葡萄糖的 $\gamma = 4$，乙醇 $6$，乳酸 $4$，丁二酸 $3.5$，甲烷 $8$。
:::

::: proposition 由电子衡算求最大产率 {#prop-max-yield}
在某发酵中，糖（底物，还原度 $\gamma_\mathrm{S}$）转化为单一产物 P（还原度 $\gamma_\mathrm{P}$）、$\mathrm{CO_2}$ 与水，无外来电子受体（厌氧）、无其他电子供体、无生物量生成，则产物对底物的产率（C 摩尔对 C 摩尔）不能超过
$$
Y_\mathrm{P/S}^\mathrm{max} = \frac{\gamma_\mathrm{S}}{\gamma_\mathrm{P}} ,
$$ {#eq-max-yield}
且碳产率也受 $1$ 限制，除非有 $\mathrm{CO_2}$ 被固定（仅当 $\gamma_\mathrm{P} < \gamma_\mathrm{S}$ 时才可能）。
:::

::: proof
化学转化中可用于还原的电子是守恒的：把 $\mathrm{CO_2}$、$\mathrm{H_2O}$ 与 $\mathrm{NH_3}$ 定义为还原度为零，则所有这些含碳物种的 $\gamma\times$(C 摩尔) 之和在它们与该参考化合物之间的任何配平反应中不变。（这是电荷守恒应用于氧化数的又一种表述。）每 C 摩尔底物进入 $\gamma_\mathrm{S}$ 个电子；它们只能随产物离开（没有其他受体），故至多 $Y\gamma_\mathrm{P} = \gamma_\mathrm{S}$，等号在没有电子去往副产物或细胞生长时成立。碳也守恒：产物 C 摩尔加 $\mathrm{CO_2}$ C 摩尔等于底物 C 摩尔，所以 $Y \leq 1$，除非 $\mathrm{CO_2}$ 是净反应物。当 $\gamma_\mathrm{P} > \gamma_\mathrm{S}$ 时电子限制更严，多余的碳必须以 $\mathrm{CO_2}$ 排出；当 $\gamma_\mathrm{P} < \gamma_\mathrm{S}$，如丁二酸，产物可经固定 $\mathrm{CO_2}$ 含有比所供底物更多的碳，一些细菌正是通过磷酸烯醇式丙酮酸或丙酮酸的羧化做到这一点。真实产率更低，因为部分底物用于生长与维持（ATP），部分被分流到副产物；代谢途径本身在 [[biochemistry/glycolysis-citric-acid]]。
:::

::: example 乙醇产率 {#ex-ethanol}
用[[#prop-max-yield]]求葡萄糖制乙醇的最大产率（摩尔对摩尔与克对克），并与酒精发酵的配平方程式比较。
::: solution
$\gamma_\mathrm{S} = 4$（葡萄糖），$\gamma_\mathrm{P} = (8 + 6 - 2)/2 = 6$（乙醇），故 $Y^\mathrm{max} = 4/6 = \tfrac23$ C 摩尔对 C 摩尔。一个葡萄糖（6 C 摩尔）至多给出 $4$ C 摩尔乙醇，即 $2$ 个分子，另外 $2$ C 摩尔以 $\mathrm{CO_2}$ 离开：
$$
\mathrm{C_6H_{12}O_6} \rightarrow 2\,\mathrm{C_2H_5OH} + 2\,\mathrm{CO_2} .
$$
质量产率为 $2\times46.07/180.16 = 0.511\ \mathrm{g\,g^{-1}}$。工业酵母发酵可达此值的约 $90$–$95\,\%$，其余用于酵母生长、甘油与其他副产物。该方程式的“原子经济性”是 $51.1\,\%$，但 $\mathrm{CO_2}$ 不是可避免的废物：它是带走氧、从而提高产物有效 H/C 比的载体。它还是一股纯流，许多乙醇厂把它捕集出售（饮料级，或作 [[green-chemistry/carbon-hydrogen]] 的原料）。
:::
:::

### 主要平台化合物

**乙醇**是最大的发酵产品，美国用玉米淀粉、巴西用甘蔗生产，主要作燃料。在氧化铝或沸石催化剂上脱水即得乙烯，$\mathrm{C_2H_5OH \rightarrow C_2H_4 + H_2O}$，质量产率 $28.05/46.07 = 0.609$。Braskem 自 2010 年起在巴西特林富用甘蔗乙醇制聚乙烯；这种聚合物与化石聚乙烯化学上完全相同，并与之一同回收——一种**直接替换型（drop-in）**产品。

**乳酸**（2-羟基丙酸）由细菌发酵生产，产率接近理论值 $1\ \mathrm{g\,g^{-1}}$（$\gamma = 4$，与葡萄糖相同），光学纯度也高。其环状二聚体丙交酯经开环聚合制成**聚乳酸**（PLA），NatureWorks 自 2002 年起在内布拉斯加州布莱尔大规模生产（其化学与降解见 [[polymer-chemistry/step-growth]] 与 [[polymer-chemistry/functional-polymers]]）。PLA 是**全新**产品而非直接替换品：它有自己特有的性能和寿命终期的要求——在工业堆肥条件下降解，但在土壤或海水中却不然。

**丁二酸**、**1,3-丙二醇**（用于聚酯聚对苯二甲酸丙二醇酯）与**1,4-丁二醇**由工程微生物生产；生物基二醇是直接替换石化二醇的产品。

**呋喃类**来自糖的酸催化脱水。戊糖（来自半纤维素）给**糠醛**，自 1920 年代起工业上以玉米芯与蔗渣生产。己糖，尤其果糖，给 **5-羟甲基糠醛（HMF）**：
$$
\mathrm{C_6H_{12}O_6\ (fructose)} \rightarrow \mathrm{C_6H_6O_3\ (HMF)} + 3\,\mathrm{H_2O}, \qquad \mathrm{AE} = \frac{126.11}{180.16} = 70.0\,\%.
$$
HMF 在热的酸性水溶液中不稳定，会水合为**乙酰丙酸**（4-氧代戊酸）与甲酸，并缩合成不溶的类腐殖质（humins），所以它的合成是 [[green-chemistry/petrochemicals#prop-consecutive]] 所分析的串联型选择性问题，通常用能把 HMF 边生成边萃取出来的双相溶剂体系来解决。HMF 氧化得 **2,5-呋喃二甲酸（FDCA）**，它与乙二醇缩合成聚2,5-呋喃二甲酸乙二醇酯（PEF），一种阻隔性能优于 PET 的聚酯；荷兰公司 Avantium 在 2020 年代中期使首座商用规模的 FDCA 装置投入运行。

**甘油**是生物柴油与肥皂生产的联产品。生物柴油扩张后甘油过剩，催生了新用途：Solvay 的 Epicerol 工艺以甘油和 HCl 制环氧氯丙烷，而不以丙烯和氯气；甘油还可氢解为 1,2-丙二醇。

::: example 生物柴油与其甘油 {#ex-biodiesel}
脂肪酸甲酯（FAME，“生物柴油”）由甘油三酯与甲醇的碱催化酯交换反应制得。以三油酸甘油酯（$\mathrm{C_{57}H_{104}O_6}$，$885.43\ \mathrm{g\,mol^{-1}}$）为模型油，写出方程式，求对甲酯（油酸甲酯，$296.49$）的原子经济性，以及每吨生物柴油的甘油（$92.09$）质量。（$M(\mathrm{CH_3OH}) = 32.04$。）
::: solution
$$
\mathrm{C_{57}H_{104}O_6} + 3\,\mathrm{CH_3OH} \rightarrow 3\,\mathrm{C_{19}H_{36}O_2} + \mathrm{C_3H_8O_3} .
$$
质量衡算：$885.43 + 96.12 = 981.55$；$889.47 + 92.09 = 981.56$，舍入意义上一致。$\mathrm{AE} = 889.47/981.55 = 90.6\,\%$。每吨 FAME 的甘油：$92.09/889.47 = 0.104\ \mathrm{t}$，约 $10\,\%$——这就是生物柴油扩张后甘油过剩的原因。甲醇过量使用（通常六倍摩尔比）并回收；碱催化剂（甲醇钠或氢氧化钠）会被任何游离脂肪酸消耗而成皂，这就是高酸值废油要先经酸催化酯化的原因。甲醇有毒且易燃，工艺在密闭设备中运行。另一条路线**加氢植物油**（HVO）在硫化物催化剂上用氢把氧脱除，得到烷烃——直接替换型的柴油或航空燃料——代价约为油质量 $3$–$4\,\%$ 的氢。
:::
:::

### 木质素与土地

**木质素**是最大的天然芳香环来源，但它大部分在纸浆厂烧掉产能，因为硫酸盐法制浆（用氢氧化钠与硫化钠）断裂其醚键的同时又形成新的、难断的碳-碳键，留下难以升级的含硫缩合材料。“木质素优先”策略（还原催化解离、醛辅助分级）自 2010 年代中期起发展，在木质素被抽提出的同时把活性中间体稳定下来，高收率给出 4-丙基愈创木酚这类单体；香兰素由木质素商业化生产已有数十年（挪威 Borregaard）。

土地是每一种生物基工艺背后的制约。作物需要土地、水与化肥；在原本可生产粮食的土地上、或在由森林转化来的土地上种植原料，会带来**直接与间接土地利用变化**排放，可能超过所省下的化石碳。欧盟《可再生能源指令》（2018 与 2023 年修订）限制粮用作物生物燃料的贡献份额，为生物燃料设定可持续性标准与最低温室气体减排量，并区分来自废物与残余物的“先进”原料。这些规则针对燃料，但也框定了生物基化学品的争论。

::: warning 生物基、可生物降解与可持续是三种不同的声明 {#warn-bio}
*生物基*说的是碳的来源：生物基聚乙烯是生物基的，但并不比化石聚乙烯更易生物降解。*可生物降解*说的是寿命终期：广泛用于可堆肥袋的聚己二酸对苯二甲酸丁二醇酯可生物降解，却主要由化石原料制成。*可持续*需要寿命周期评估：生物基产品的气候、富营养化或土地使用影响可能高于其化石对照品，取决于作物、种植、转化能量与寿命终期。标签应当说明它声明的是三者中的哪一个、依据什么标准（生物基含量用现代碳组分的放射性碳测定，如 ASTM D6866 或 EN 16640；可堆肥性用 EN 13432），以及在哪条系统边界上。
:::

## 生物催化

酶是蛋白质（偶尔是 RNA），能以高达 $10^{17}$ 的速率增强催化反应，常常具有完全的区域选择性和对映选择性，在近室温、中性的水中进行。它们由发酵从可再生资源制得，可生物降解，且不含稀缺金属（或只含丰量金属）。这些正是原则 3、6、7、9 所要求的性质，而限制其更大范围使用的主要障碍——底物范围窄、不稳定、抑制、需要辅因子——自 1990 年代起已被**定向进化**削弱，即弗朗西斯·阿诺德（Frances Arnold）（2018 年诺贝尔化学奖）开创的、在实验室重复突变与选择的方法。工业生物催化以**全细胞**、溶液中**游离酶**或固载于载体上**固定化**使用酶，以便在填充床中重复使用。

::: definition 米氏方程与生物催化剂指标 {#def-mm}
对遵循米氏动力学的酶，底物浓度为 $[\mathrm{S}]$ 时的初始速率为
$$
v = \frac{V_\mathrm{max}[\mathrm{S}]}{K_\mathrm{M} + [\mathrm{S}]}, \qquad V_\mathrm{max} = k_\mathrm{cat}[\mathrm{E}]_0 ,
$$ {#eq-mm}
其中 $k_\mathrm{cat}$ 是转换数（每个活性部位单位时间转化底物分子的最大数目），$K_\mathrm{M}$ 是米氏常数（[[biochemistry/enzymes]]）。工艺指标有**总转换数** $\mathrm{TTN} = $ 酶的使用期内每摩尔酶产物摩尔数；**时空产率**；**最终产物浓度**（滴度），它决定下游处理的负担；以及**酶载量**或**生物催化剂产率**（每千克酶的产品千克数）。
:::

::: proposition 酶转化的间歇时间 {#prop-batch-time}
在酶活性恒定、无产物抑制、反应不可逆的间歇反应器中，从初始底物浓度 $[\mathrm{S}]_0$ 达到转化率 $X$ 所需时间为
$$
t = \frac{1}{V_\mathrm{max}}\left[K_\mathrm{M}\ln\frac{1}{1 - X} + [\mathrm{S}]_0X\right] .
$$ {#eq-batch-time}
$[\mathrm{S}]_0/K_\mathrm{M}$ 高时反应近乎零级，$t \approx [\mathrm{S}]_0X/V_\mathrm{max}$；$[\mathrm{S}]_0/K_\mathrm{M}$ 低时为一级，$k = V_\mathrm{max}/K_\mathrm{M}$。
:::

::: proof
间歇反应器中 $-\mathrm{d}[\mathrm{S}]/\mathrm{d}t = v$。用[[#eq-mm]]分离变量：
$$
\int_{[\mathrm{S}]_0}^{[\mathrm{S}]}\frac{K_\mathrm{M} + [\mathrm{S}]'}{[\mathrm{S}]'}\,\mathrm{d}[\mathrm{S}]' = -V_\mathrm{max}t
\;\Rightarrow\;
K_\mathrm{M}\ln\frac{[\mathrm{S}]_0}{[\mathrm{S}]} + ([\mathrm{S}]_0 - [\mathrm{S}]) = V_\mathrm{max}t .
$$
代入 $[\mathrm{S}] = [\mathrm{S}]_0(1 - X)$ 即得[[#eq-batch-time]]。两个极限由比较两项得到：$[\mathrm{S}]_0X \gg K_\mathrm{M}\ln[1/(1 - X)]$ 时线性项主导，反之时对数项主导。实际中常见的产物抑制、酶失活与可逆性都会延长时间；该式是初步设计用的下限。
:::

:::

::: example 一个酶法批次 {#ex-enzyme}
某酶 $k_\mathrm{cat} = 50\ \mathrm{s^{-1}}$、$K_\mathrm{M} = 5.0\ \mathrm{mmol\,dm^{-3}}$，以 $2.0\ \mu\mathrm{mol\,dm^{-3}}$ 的浓度转化初始浓度 $0.50\ \mathrm{mol\,dm^{-3}}$ 的底物。求达到 $99\,\%$ 转化率的时间，以及酶只用一次时的总转换数。
::: solution
$V_\mathrm{max} = 50\ \mathrm{s^{-1}}\times2.0\times10^{-6}\ \mathrm{mol\,dm^{-3}} = 1.0\times10^{-4}\ \mathrm{mol\,dm^{-3}\,s^{-1}} = 0.36\ \mathrm{mol\,dm^{-3}\,h^{-1}}$。由[[#eq-batch-time]]，
$$
t = \frac{0.0050\ln100 + 0.50\times0.99}{0.36}\ \mathrm{h} = \frac{0.0230 + 0.495}{0.36}\ \mathrm{h} = 1.44\ \mathrm{h}.
$$
因为 $[\mathrm{S}]_0 = 100\,K_\mathrm{M}$，对数项只贡献 $4\,\%$。$\mathrm{TTN} = 0.495/(2.0\times10^{-6}) = 2.5\times10^{5}$。若底物摩尔质量约 $200\ \mathrm{g\,mol^{-1}}$、酶约 $40\ \mathrm{kg\,mol^{-1}}$，则每质量酶的产品质量为 $2.5\times10^{5}\times200/40\,000 \approx 1200$：每千克产品约一克酶，这是制药中间体经济工艺的典型值。实际时间会更长，因为有产物抑制和活性的逐渐损失。
:::
:::

### 工业实例

- **高果糖浆。** 固定化葡萄糖异构酶在填充床反应器中把葡萄糖转化为与果糖的平衡混合物；按产物体积计，它是最大的固定化酶工艺。
- **丙烯酰胺。** 红球菌（*Rhodococcus*）全细胞中的腈水合酶在低温下把丙烯腈水合为丙烯酰胺，选择性基本完全；1985 年由 Nitto Chemical 在日本引入，取代了需要更高温度、产生副产物的铜催化工艺，是最大的大宗化学品生物催化工艺之一。
- **半合成青霉素与头孢菌素。** 固定化青霉素酰化酶在水中切除青霉素 G 的侧链得 6-氨基青霉烷酸，取代了需要硅烷保护、二氯甲烷、五氯化磷和近 $-40\,^\circ\mathrm{C}$ 温度的化学脱酰化；同一家族酶反向使用可接上新侧链。
- **西格列汀。** 降糖药西格列汀最初由铑催化烯胺的高压不对称氢化制造，再经重结晶提高对映体过量。Merck 与 Codexis 通过十一轮定向进化改造出一种转氨酶（Savile 等，*Science*，2010），直接对前手性酮胺化，以丙-2-胺为胺供体，胺的对映体过量 $> 99.95\,\%$；他们报告总收率提高 $10$–$13\,\%$、总废弃物减少 $19\,\%$，消除了铑催化剂与高压设备，生产率提高 $53\,\%$。这项工作获 2010 年美国总统绿色化学挑战奖。
- **脂肪酶**（固定化为 Novozym 435 的南极假丝酵母（*Candida antarctica*）脂肪酶 B）在有机溶剂中或无溶剂条件下催化酯化、酯交换与动力学拆分，用于润肤酯与手性胺。

::: quiz
水相中的转氨酶反应受平衡限制并被其酮联产物抑制。哪一项改变*最不可能*有帮助？
- [ ] 大量过量的胺供体
- [ ] 边生成边除去酮联产物（例如供体为丙-2-胺时蒸发丙酮）
- [x] 增加酶量，因为酶能把平衡推向产物
- [ ] 进化出受副产物抑制更小的酶变体
::: solution
酶与任何催化剂一样，同等加速正逆两个方向，不能改变平衡位置（[[green-chemistry/green-principles#prop-catalyst-rate]]）；多加酶只是更快到达同一平衡。过量供体与副产物移出移动平衡（勒夏特列）；受抑制较小的变体提高反应后期的速率。西格列汀工艺同时使用了丙-2-胺大过量与对生成丙酮的移出。
:::
:::

::: history 从酿造到定向进化 {#hist-bio}
发酵与酿酒烘焙同样古老；巴斯德（Pasteur）在 1850–60 年代证明它由活的微生物完成，而毕希纳（Buchner）1897 年用无细胞酵母抽液实现发酵（1907 年诺贝尔奖）表明做化学工作的是酶而非生命本身。米夏埃利斯（Michaelis）与门滕（Menten）1913 年发表其速率方程。魏茨曼（Weizmann）约 1915 年开发的丙酮-丁醇发酵在第一次世界大战中为英国军火供应丙酮，是最早的大型工业发酵之一；随后有黑曲霉制柠檬酸（Pfizer，1919）与 1940 年代的青霉素生产。糠醛自 1922 年起由 Quaker Oats 以燕麦壳生产。千叶（Chibata）在日本的氨基酰化酶工艺（1969）使固定化酶进入工业。美国能源部的《Top Value Added Chemicals from Biomass》报告发表于 2004 年，Bozell 与 Petersen 的更新在 2010 年。弗朗西斯·阿诺德（Frances Arnold）与乔治·史密斯（George Smith）、格雷戈里·温特（Gregory Winter）共享 2018 年诺贝尔奖，自 1990 年代起使定向进化成为常规工具。
:::

## 后续内容

可再生碳是离开化石原料的三条路线之一；[[green-chemistry/carbon-hydrogen]] 讲第二条，二氧化碳配低排放氢；[[green-chemistry/circular-economy]] 讲第三条，再生碳。生物基单体（PLA、PEF、生物基 PE、生物基 PET）的聚合物及其寿命终期选项在 [[polymer-chemistry]] 中分析。生物催化背后的酶学在 [[biochemistry/enzymes]]，决定发酵产率的代谢途径在 [[biochemistry/glycolysis-citric-acid]]。

::: summary
- 木质纤维素约含 $40$–$50\,\%$ 纤维素、$20$–$35\,\%$ 半纤维素与 $15$–$30\,\%$ 木质素；第一代工艺用糖、淀粉与油，第二代用残余物与木质纤维素。
- 有效 H/C 比 $(h - 2o - 3n - 2s)/c$：碳水化合物为 $0$，烷烃约 $2$；生物质最适合含氧产品，用它制烃需要氢或排碳。
- 还原度 $\gamma = (4c + h - 2o - 3n)/c$ 决定最大发酵产率 $\gamma_\mathrm{S}/\gamma_\mathrm{P}$（C 摩尔/C 摩尔）：乙醇 $0.511\ \mathrm{g\,g^{-1}}$，乳酸 $1\ \mathrm{g\,g^{-1}}$。
- 平台化学品——乙醇、乳酸与丁二酸、糠醛、HMF、FDCA、乙酰丙酸、甘油、山梨醇——供养直接替换型产品（生物基 PE）与全新产品（PLA、PEF）；生物柴油联产约 $10\,\%$ 甘油。
- 生物基、可生物降解、可持续是不同的声明；可持续性由土地利用、化肥与转化能量决定。
- 酶遵循米氏动力学；间歇时间为 $[K_\mathrm{M}\ln(1/(1 - X)) + [\mathrm{S}]_0X]/V_\mathrm{max}$。定向进化已使生物催化具有竞争力，如西格列汀转氨酶、腈水合酶制丙烯酰胺与酶法青霉素脱酰。
:::

## 练习

::: exercise 葡萄糖制乙醇 {level=1 check="51.1"}
酒精发酵由葡萄糖制乙醇的最大质量产率是多少？（$M$：葡萄糖 $180.16$、乙醇 $46.07\ \mathrm{g\,mol^{-1}}$。）（产率以质量百分比计。）
::: solution
$2\times46.07/180.16 = 0.511$，即质量产率 $51.1\,\%$。
:::

::: exercise 甘油的有效 H/C {level=1 check="2/3"}
计算甘油 $\mathrm{C_3H_8O_3}$ 的有效氢碳比。（输入该比值。）
::: solution
$(8 - 2\times3)/3 = 2/3 \approx 0.67$。甘油比糖（$0$）还原程度高，但远未达到烃类（$\approx 2$）。
:::
:::

::: exercise 生物基乙烯 {level=1 check="0.609"}
以 $100\,\%$ 产率由一吨乙醇经脱水可得多少乙烯质量？（质量以吨计。）
::: solution
$28.05/46.07 = 0.609\ \mathrm{t}$。连同发酵产率，每吨葡萄糖至多 $0.511\times0.609 = 0.311\ \mathrm{t}$ 乙烯：只有糖质量的 $31\,\%$，却是其碳的 $67\,\%$（$6$ 个碳中 $4$ 个）。
:::

::: exercise 生物柴油的甘油 {level=2 check="10.4"}
三油酸甘油酯与甲醇酯交换时，每 $100\ \mathrm{kg}$ 油酸甲酯生成多少甘油？（数据见[[#ex-biodiesel]]。）（质量以 kg 计。）
::: solution
$100\times92.09/(3\times296.49) = 100\times92.09/889.47 = 10.4\ \mathrm{kg}$。
:::
:::

::: exercise 丁二酸 {level=2 check="1.12"}
丁二酸（$\mathrm{C_4H_6O_4}$，$118.09\ \mathrm{g\,mol^{-1}}$）可由固定 $\mathrm{CO_2}$ 的细菌制造。用还原度求对葡萄糖的最大产率，以每 C 摩尔葡萄糖的 C 摩尔计，以及以克对克计。（质量产率以 $\mathrm{g\,g^{-1}}$ 计，保留三位有效数字。）
::: solution
$\gamma(\text{丁二酸}) = (16 + 6 - 8)/4 = 3.5$，$\gamma(\text{葡萄糖}) = 4$。$Y^\mathrm{max} = 4/3.5 = 1.143$ C 摩尔对 C 摩尔：产物碳多于底物碳，只有在固定 $\mathrm{CO_2}$ 时才可能。每摩尔葡萄糖（6 C 摩尔）得 $6.857$ C 摩尔丁二酸 $= 1.714\ \mathrm{mol}$，$1.714\times118.09/180.16 = 1.12\ \mathrm{g\,g^{-1}}$。与此相符的总化学计量为 $7\,\mathrm{C_6H_{12}O_6} + 6\,\mathrm{CO_2} \rightarrow 12\,\mathrm{C_4H_6O_4} + 6\,\mathrm{H_2O}$。消耗 $\mathrm{CO_2}$ 的发酵有吸引力，但实际中生长与副产物（乙酸、甲酸）会降低产率。
:::
:::

::: exercise 较慢的酶 {level=2 check="5.88"}
某酶法反应 $K_\mathrm{M} = 10\ \mathrm{mmol\,dm^{-3}}$、$V_\mathrm{max} = 40\ \mathrm{mmol\,dm^{-3}\,h^{-1}}$，$[\mathrm{S}]_0 = 200\ \mathrm{mmol\,dm^{-3}}$。假设无抑制或失活，求达到 $98\,\%$ 转化率的时间。（时间以小时计，保留三位有效数字。）
::: solution
$t = [10\ln50 + 200\times0.98]/40 = (39.12 + 196)/40 = 5.88\ \mathrm{h}$。这里对数项占总时间的 $17\,\%$，因为 $[\mathrm{S}]_0$ 只有 $20\,K_\mathrm{M}$。
:::
:::

::: exercise 异丁醇 {level=3 check="0.411"}
异丁醇（2-甲基丙-1-醇，$\mathrm{C_4H_{10}O}$，$74.12\ \mathrm{g\,mol^{-1}}$）是由工程微生物制造的燃料与化学品前体。用[[#prop-max-yield]]求对葡萄糖的最大产率，写出配平的总方程式，并评论其余碳的去向。（最大质量产率以 $\mathrm{g\,g^{-1}}$ 计，保留三位有效数字。）
::: hint
计算异丁醇按每碳计的 $\gamma$，用 $Y = \gamma_\mathrm{S}/\gamma_\mathrm{P}$。
:::
::: solution
$\gamma = (16 + 10 - 2)/4 = 6$，故 $Y^\mathrm{max} = 4/6$ C 摩尔对 C 摩尔：$6$ C 摩尔葡萄糖得 $4$ C 摩尔，即一个异丁醇分子。方程式为 $\mathrm{C_6H_{12}O_6} \rightarrow \mathrm{C_4H_{10}O} + 2\,\mathrm{CO_2} + \mathrm{H_2O}$（校核：C $6 = 4 + 2$；H $12 = 10 + 2$；O $6 = 1 + 4 + 1$）。质量产率 $74.12/180.16 = 0.411\ \mathrm{g\,g^{-1}}$。三分之一的碳以 $\mathrm{CO_2}$ 离开，比例与乙醇相同，因为两产物的 $\gamma$ 都是 $6$；代谢路线（经丙酮酸、乙酰乳酸与 2-氧代异戊酸脱羧）每葡萄糖恰好释放两个 $\mathrm{CO_2}$。要提高碳产率就必须输入额外电子，例如以氢或电的形式——这正是电发酵与气体发酵背后的思想。
:::
:::

::: exercise 生物基聚乙烯的土地 {level=3 check="69.4"}
某厂计划由甘蔗乙醇每年生产 $200\ \mathrm{kt}$ 聚乙烯。假设脱水与聚合两步都是定量完成，且甘蔗每公顷每年产乙醇 $6000\ \mathrm{dm^3}$（密度 $0.789\ \mathrm{kg\,dm^{-3}}$）。需要多少甘蔗地？（面积以千公顷计，保留三位有效数字。）
::: solution
所需乙醇：$200\ \mathrm{kt}/0.609 = 328.4\ \mathrm{kt}$（由 $46.07/28.05 = 1.642\ \mathrm{t}$ 每吨乙烯）。每公顷乙醇：$6000\times0.789 = 4734\ \mathrm{kg} = 4.734\ \mathrm{t}$。面积：$328\,400/4.734 = 6.94\times10^{4}\ \mathrm{ha}$，即 $69.4$ 千公顷，约 $694\ \mathrm{km^2}$。按 2024 年约 $430\ \mathrm{Mt}$ 塑料产量放大，同样的单产将需要约 $1.5$ 亿公顷量级——约为世界耕地的十分之一——这说明为什么生物基碳单独无法替代塑料中的化石碳，为什么回收（[[green-chemistry/circular-economy]]）与需求削减是所有方案的一部分。
:::
