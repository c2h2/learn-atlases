二氧化碳是碳的终点站。其标准摩尔生成吉布斯自由能为 $-394.4\ \mathrm{kJ\,mol^{-1}}$，位于热力学深阱之底——一切燃料和大多数有机产物最终都落入这个阱中——这正是它不断累积的原因：2024 年全球与能源相关的 $\mathrm{CO_2}$ 排放约 $37.8\ \mathrm{Gt}$（IEA，*Global Energy Review 2025*），2024 年大气 $\mathrm{CO_2}$ 全球年均浓度超过 $420$ ppm，比工业化前水平高约 $50\,\%$（NOAA）。政府间气候变化专门委员会（IPCC）在其第六次评估报告（2021–2023）中得出结论：要把增暖限制在 $1.5$ 或 $2\,^\circ\mathrm{C}$，必须在世纪中叶前后或之后实现 $\mathrm{CO_2}$ 净零排放，而多数情景中，工业部门的残余排放要靠**二氧化碳捕集与封存**（CCS）和二氧化碳移除来平衡。

氢是故事的另一半。2024 年氢的使用量约 $100\ \mathrm{Mt}$（IEA，*Global Hydrogen Review 2025*），主要用于炼油、氨和甲醇，而且几乎全部是以释放 $\mathrm{CO_2}$ 的方式由天然气或煤制得；低排放氢不到总量的 $1\,\%$。无排放制得的氢可一举使氨（[[green-chemistry/industrial-inorganic]]）脱碳；与捕集的 $\mathrm{CO_2}$ 结合，它还能为化学品和燃料提供碳。这两个想法在化学上都很古老，在规模上却是新鲜的。本章讲 $\mathrm{CO_2}$ 捕集、利用与储存的化学和热力学；制氢路线及其排放强度；以及利用化学键——在氢、氨、甲醇和有机载体中——储存能量。与本课程其余部分一样，统计数据注明日期，政策只作描述而不作鼓吹。电解水的电化学见 [[electrochemistry/fuel-cells-electrolysis]]，温室气体的大气化学见 [[environmental-chemistry/greenhouse-gases]]。

## 捕集二氧化碳

$\mathrm{CO_2}$ 可以从三类源中捕集：**高浓度工艺物流**（天然气处理、氨与氢工厂、乙醇发酵、环氧乙烷装置），其中 $\mathrm{CO_2}$ 占 $15$–$100\,\%$，捕集最便宜；发电厂、水泥窑、钢铁厂和工业炉窑燃烧产生的**烟气**，在常压下含 $4$–$30\,\%\ \mathrm{CO_2}$；以及**空气**，约 $0.042\,\%$。所需的最小能量取决于浓度，这可以用一个简单热力学论证说明。

::: proposition 分离的最小功 {#prop-wmin}
一种行为理想的混合气体含 $\mathrm{CO_2}$ 摩尔分数 $y$，在恒定温度 $T$ 和压力下被分离为纯 $\mathrm{CO_2}$（进料中 $\mathrm{CO_2}$ 的份额 $\phi$）和残余气体。每摩尔被捕集 $\mathrm{CO_2}$ 的最小（可逆）功为
$$
w_\mathrm{min} = \frac{RT}{\phi y}\Big[(1 - \phi y)\,s(y_\mathrm{r}) - s(y)\Big], \qquad s(z) = z\ln z + (1 - z)\ln(1 - z), \qquad y_\mathrm{r} = \frac{y(1 - \phi)}{1 - \phi y} ,
$$ {#eq-wmin}
其中 $y_\mathrm{r}$ 为残留在残余气体中的摩尔分数。当 $\phi \to 0$ 时，$w_\mathrm{min} \to -RT\ln y$。
:::

::: proof
在固定的 $T$ 和 $p$ 下，$n$ 摩尔理想混合气体的吉布斯自由能比分离后的纯组分高出 $nRT\sum_i x_i\ln x_i$（混合吉布斯自由能，[[thermodynamics/mixtures]]），对二元混合物即 $nRT\,s(x)$，其中 $s < 0$。等温等压分离的最小功就是进料与产物之间吉布斯自由能的增量。取进料 $1$ mol。产物为 $\phi y$ mol 纯 $\mathrm{CO_2}$（$s = 0$）和 $1 - \phi y$ mol 残余气体，后者含 $\mathrm{CO_2}$ $y - \phi y = y(1 - \phi)$，由此得摩尔分数 $y_\mathrm{r}$。于是
$$
W_\mathrm{min} = G_\mathrm{products} - G_\mathrm{feed} = RT\big[(1 - \phi y)s(y_\mathrm{r}) - s(y)\big],
$$
除以被捕集的 $\phi y$ 摩尔即得[[#eq-wmin]]。求极限：对小 $\phi$ 展开——从一个大储库中移出 $\delta n = \phi y$ mol $\mathrm{CO_2}$ 的代价，是纯 $\mathrm{CO_2}$ 与摩尔分数为 $y$ 的 $\mathrm{CO_2}$ 之间化学势之差，即每摩尔 $-RT\ln y$。真实过程需要最小功的二到五倍，因为吸收与解吸在有限推动力下运行，而溶剂还必须被加热、泵送和冷却。
:::

注意一个实际细节：源越稀，最小功只按对数缓慢增长，但必须处理的气体*体积*按反比增大，而后者才是空气捕集成本的主宰。

::: example 捕集至少该花多少能量？ {#ex-wmin}
在 $298\ \mathrm{K}$ 用[[#eq-wmin]]，求从燃煤烟气（$y = 0.12$）捕集 $90\,\%$、以及从空气（$y = 4.2\times10^{-4}$）捕集 $75\,\%$ 时每吨 $\mathrm{CO_2}$ 的最小功。与基准胺法工艺约 $3.5$–$4\ \mathrm{GJ\,t^{-1}}$ 的热量再生能耗比较。
::: solution
**烟气。** $y_\mathrm{r} = 0.12\times0.10/(1 - 0.108) = 0.01345$；$1 - \phi y = 0.892$。于是 $s(y_\mathrm{r}) = 0.01345\ln0.01345 + 0.98655\ln0.98655 = -0.05795 - 0.01336 = -0.0713$，而 $s(0.12) = 0.12\ln0.12 + 0.88\ln0.88 = -0.2544 - 0.1125 = -0.3669$。所以
$$
w_\mathrm{min} = \frac{8.314\times298.15}{0.108}\big[0.892\times(-0.0713) + 0.3669\big]\ \mathrm{J\,mol^{-1}} = 22\,953\times0.3033\ \mathrm{J\,mol^{-1}} = 6.96\ \mathrm{kJ\,mol^{-1}},
$$
即 $6.96/44.01\ \mathrm{GJ\,t^{-1}} = 0.158\ \mathrm{GJ\,t^{-1}}$。

**空气。** 同一公式给出 $20.6\ \mathrm{kJ\,mol^{-1}}$、$0.468\ \mathrm{GJ\,t^{-1}}$（接近极限值 $-RT\ln y = 19.3\ \mathrm{kJ\,mol^{-1}}$，因为移走痕量组分的四分之三几乎不改变残余气体）。

胺法工艺每吨消耗 $3.5$–$4\ \mathrm{GJ}$ 热量，是烟气最小功的二十多倍。这个比较并不完全公道——$120\,^\circ\mathrm{C}$ 的热量价值低于功，在电厂里或许只抵四分之一到三分之一——但它表明捕集离热力学极限还很远，也说明了能把再生能耗降到约 $2.5\ \mathrm{GJ\,t^{-1}}$ 的改进溶剂（位阻胺、哌嗪混合胺）为何重要。再把捕集的 $\mathrm{CO_2}$ 压缩到管道压力（约 $100$–$150\ \mathrm{bar}$），每吨另需约 $0.3$–$0.4\ \mathrm{GJ}$ 电力。
:::
:::

### 捕集技术

燃烧后捕集的主力是胺水溶液的**化学吸收**，其雏形是 1930 年代为天然气脱硫开发的工艺。约 $40\,^\circ\mathrm{C}$ 的烟气在吸收塔与 2-氨基乙醇（单乙醇胺，MEA）的 $30\,\%$ 溶液相遇；$\mathrm{CO_2}$ 与胺反应生成氨基甲酸酯，
$$
\mathrm{CO_2 + 2\,RNH_2 \rightleftharpoons RNHCOO^- + RNH_3^+},
$$
富液再被泵到约 $120\,^\circ\mathrm{C}$ 的再生塔，蒸汽使反应逆转，放出近乎纯的 $\mathrm{CO_2}$。吸收热（MEA 约每摩尔 $\mathrm{CO_2}$ $80$–$90\ \mathrm{kJ}$）必须在再生塔中再次供给，加上加热溶剂和产生汽提蒸汽所需的热，一起构成再生能耗。胺会因氧化以及与 $\mathrm{SO_2}$、$\mathrm{NO_x}$ 反应而降解，生成氨、亚硝胺等产物，必须在净化气中加以控制。

替代方案包括**物理吸收**（以甲醇为溶剂的 Rectisol 工艺，或以聚乙二醇醚为溶剂的 Selexol 工艺），适合高压气体；在沸石、胺功能化二氧化硅或金属有机框架（[[materials-chemistry/porous-materials]]）上**吸附**，以压力、温度或湿度变压（变温、变压湿）循环再生；**膜**；以及**钙循环**——CaO 在约 $650\,^\circ\mathrm{C}$ 与 $\mathrm{CO_2}$ 反应生成 $\mathrm{CaCO_3}$，在 $900\,^\circ\mathrm{C}$ 再生。两种流程构型可以避免燃烧后分离：**燃烧前捕集**先把燃料转化为 $\mathrm{CO_2}$ 和 $\mathrm{H_2}$（重整或气化加水煤气变换），再在高压下把二者分开——氨厂早已这么做；**富氧燃烧**在氧气中烧燃料，于是烟气只是 $\mathrm{CO_2}$ 和水，代价是一套空分装置。

**直接空气捕集**（DAC）使用碱金属氢氧化物水溶液（吸收生成碳酸盐，再回收为 $\mathrm{CaCO_3}$ 并煅烧）或在约 $100\,^\circ\mathrm{C}$ 再生的固体胺吸附剂。当 $\mathrm{CO_2}$ 被永久封存时，它是二氧化碳移除的一种形式；2020 年代中期运行的装置年捕集量是数千吨而非数百万吨。

捕集的 $\mathrm{CO_2}$ 通过注入深部咸水层或枯竭油气藏**封存**，通常在地表以下 $800\ \mathrm{m}$ 以深，此处它是稠密的超临界流体（[[green-chemistry/safer-solvents]]）。封存机制包括：不透水盖层的遮挡、孔隙空间中的毛细管力、溶入地层卤水，以及经数百年到数千年以碳酸盐形式发生的矿化。挪威北海的 Sleipner 项目自 1996 年起每年注入约一百万吨从天然气中分离出的 $\mathrm{CO_2}$。2024 年全球在运捕集能力约为每年 $50\ \mathrm{Mt\,CO_2}$ 量级（IEA 与 Global CCS Institute 的追踪），而许多 IPCC 情景设想到世纪中叶需要每年数千吉吨；其中很大一部分被用于强化采油，其净气候效益另有问题。

::: warning 利用 CO₂ 并不等于移除它 {#warn-ccu}
“碳捕集与利用”（CCU）把捕集的 $\mathrm{CO_2}$ 转化为产品。这能否减少排放，取决于碳离开大气的时长以及所耗的能量。用捕集的 $\mathrm{CO_2}$ 制尿素，肥料在土壤中水解后几周内就把 $\mathrm{CO_2}$ 放回大气；合成燃料在燃烧时释放其碳，所以充其量只能替代一种化石燃料的排放，而且前提是制它所用的氢和能量本身是低排放的。二氧化碳的*移除*需要持久封存——地质封存，或封存在矿物碳酸盐和混凝土这类长寿命材料中。对一条 CCU 路线与它所替代的传统产品作比较，唯一的办法是带上明确功能单位做生命周期评估（[[green-chemistry/green-metrics#alg-lca]]）。
:::

## 利用二氧化碳

$\mathrm{CO_2}$ 动力学上惰性、热力学上稳定，所以它的反应分为两类。**碳保持 $+4$ 氧化态的反应**——羧基化和碳酸盐生成——几乎不需能量，甚至可以是放热的：尿素合成（$2\,\mathrm{NH_3 + CO_2}$，[[green-chemistry/industrial-inorganic]]）；由苯酚钠经 Kolbe–Schmitt 羧基化制水杨酸；由环氧化物制环状碳酸酯，$\mathrm{CO_2 + C_2H_4O \rightarrow C_3H_4O_3}$（碳酸乙烯酯），用卤化物或金属催化剂，原子经济性 $100\,\%$；$\mathrm{CO_2}$ 与环氧化物催化共聚制聚碳酸酯和聚醚碳酸酯多元醇，科思创（Covestro）2016 年已将其商业化用于聚氨酯泡沫；以及**矿化**，$\mathrm{CaSiO_3 + CO_2 \rightarrow CaCO_3 + SiO_2}$，放热且永久，但缓慢且物料通量巨大。**把碳还原的反应**——还原为 CO、甲酸、甲醇、甲烷或烃——需要能量，以氢、电或光的形式输入，其清洁程度只等同于所输入能量的清洁程度。

::: example 由 CO₂ 制甲醇 {#ex-meoh}
甲醇可由 $\mathrm{CO_2 + 3\,H_2 \rightarrow CH_3OH + H_2O}$ 在 Cu/ZnO 催化剂上制得（[[green-chemistry/petrochemicals]]）。(a) 求每吨甲醇所需的 $\mathrm{CO_2}$ 和 $\mathrm{H_2}$ 质量及反应焓（产物为气态；$\Delta_\mathrm{f}H^\circ$：$\mathrm{CH_3OH(g)}$ $-200.66$、$\mathrm{H_2O(g)}$ $-241.82$、$\mathrm{CO_2}$ $-393.51\ \mathrm{kJ\,mol^{-1}}$）。(b) 若氢来自耗电 $52.5\ \mathrm{kWh\,kg^{-1}}$ 的电解，每吨甲醇需要多少电力？
::: solution
(a) 每摩尔甲醇（$32.04\ \mathrm{g}$）：$\mathrm{CO_2}$ $44.01\ \mathrm{g}$、$\mathrm{H_2}$ $3\times2.016 = 6.048\ \mathrm{g}$。每吨甲醇：$\mathrm{CO_2}$ $1.374\ \mathrm{t}$、$\mathrm{H_2}$ $0.189\ \mathrm{t}$。$\Delta_\mathrm{r}H^\circ = -200.66 - 241.82 + 393.51 = -48.97\ \mathrm{kJ\,mol^{-1}}$：轻度放热，所以能量已经“付”在氢里了。

(b) $188.8\ \mathrm{kg}\times52.5\ \mathrm{kWh\,kg^{-1}} = 9.91\ \mathrm{MWh}$，每吨甲醇。甲醇的低位热值约 $20\ \mathrm{GJ\,t^{-1}} = 5.5\ \mathrm{MWh\,t^{-1}}$，所以输入电能略过半数进入了燃料。三分之一的氢以水的形式离开——这是从 $\mathrm{CO_2}$ 中摘掉一个氧原子的代价；经由 CO 的逆水煤气变换路线总化学计量相同。若电的排放强度为 $0.40\ \mathrm{kg\,CO_2\,kWh^{-1}}$（以化石为主的电网），仅氢就造成每吨甲醇 $3.96\ \mathrm{t\,CO_2}$，几乎是甲醇所含 $\mathrm{CO_2}$ 的三倍：靠电解氢走 CCU，只有配用极低排放的电才能减排。
:::
:::

## 氢

::: definition 氢的排放强度 {#def-h2-intensity}
氢供应的**排放强度**是在一个既定边界内（通常是从井口到大门：从一次能源开采到工厂出口，包括上游甲烷泄漏），每交付一千克氢所排放的温室气体质量，以 $\mathrm{CO_2}$ 当量计。氢常按颜色标记——**灰氢**（由天然气制、不捕集）、**褐氢/黑氢**（由煤制）、**蓝氢**（由天然气制并配 CCS）、**绿氢**（用可再生电力电解制取）、**粉氢**（用核电）、**青氢**（甲烷热解）——但这些标记只是约定俗成，并不给出强度数值。法规定义以强度为准：例如欧盟（在其 2025 年通过的一项授权法案中）把低碳氢定义为相对 $94\ \mathrm{g\,CO_2e\,MJ^{-1}}$ 的化石基准实现 $70\,\%$ 的减排，即每千克 $\mathrm{H_2}$ 至多约 $3.38\ \mathrm{kg\,CO_2e}$；美国清洁氢生产税收抵免（国内收入法典第 45V 条，2022 年）则按 $4\ \mathrm{kg\,CO_2e\,kg^{-1}}$ 以下的强度分档。
:::

### 甲烷蒸汽重整

大多数氢由**甲烷蒸汽重整**（SMR）制得，即氨厂的前端（[[green-chemistry/industrial-inorganic]]）：在镍催化剂上 $800$–$900\,^\circ\mathrm{C}$、$20$–$40\ \mathrm{bar}$ 下重整，$\mathrm{CH_4 + H_2O \rightleftharpoons CO + 3\,H_2}$（$\Delta_\mathrm{r}H^\circ = +206\ \mathrm{kJ\,mol^{-1}}$），随后进行水煤气变换，并以变压吸附提纯。重整平衡吸热且气体分子数增加，故有利于高温低压（[[green-chemistry/petrochemicals#prop-dilution]] 的热力学在此适用，过量蒸汽起稀释剂作用，同时抑制积碳）；装置在中等压力下运行，因为下游需要带压的氢。

::: proposition 由甲烷制氢的化学计量 CO₂ 与焓 {#prop-smr}
重整加完全变换的总反应 $\mathrm{CH_4(g) + 2\,H_2O(g) \rightarrow CO_2(g) + 4\,H_2(g)}$ 至少释放
$$
\frac{M(\mathrm{CO_2})}{4M(\mathrm{H_2})} = \frac{44.01}{8.064} = 5.46\ \mathrm{kg\,CO_2\ per\ kg\,H_2}
$$
并要求 $\Delta_\mathrm{r}H^\circ = +164.9\ \mathrm{kJ}$（每摩尔甲烷，$41.2\ \mathrm{kJ}$ 每摩尔 $\mathrm{H_2}$，水为气态）。甲烷热解 $\mathrm{CH_4 \rightarrow C(s) + 2\,H_2}$ 需要 $37.4\ \mathrm{kJ}$ 每摩尔 $\mathrm{H_2}$ 且不释放 $\mathrm{CO_2}$，但每千克氢产出 $2.98\ \mathrm{kg}$ 固体碳，且每个甲烷只给出半数氢。
:::

::: proof
碳衡算：每个 $\mathrm{CH_4}$ 生成一个 $\mathrm{CO_2}$ 和四个 $\mathrm{H_2}$，故质量比为 $44.01/(4\times2.016)$。焓：由 NBS 生成焓（$\mathrm{CH_4}$ $-74.81$、$\mathrm{H_2O(g)}$ $-241.82$、$\mathrm{CO_2}$ $-393.51\ \mathrm{kJ\,mol^{-1}}$）按盖斯定律得 $\Delta_\mathrm{r}H^\circ = -393.51 - (-74.81 - 2\times241.82) = +164.94\ \mathrm{kJ\,mol^{-1}}$，即重整（$+206.1$）与变换（$-41.2$）之和。热解的 $\Delta_\mathrm{r}H^\circ = -\Delta_\mathrm{f}H^\circ(\mathrm{CH_4}) = +74.81\ \mathrm{kJ\,mol^{-1}}$，对应两个 $\mathrm{H_2}$；固体碳为 $12.011/(2\times2.016)$ kg 每千克氢。两个数都是下限：真实装置还要额外燃烧甲烷来供吸热和产蒸汽。
:::

算上重整炉燃烧的燃料，无捕集的 SMR 装置每千克氢直接排放约 $9$–$11\ \mathrm{kg}$ $\mathrm{CO_2}$；若计入上游甲烷泄漏则更多。**蓝氢**捕集工艺 $\mathrm{CO_2}$（这很容易：它浓度高且带压），高捕集率时连炉用烟气一并捕集，或采用**自热重整**——向重整器供氧，使全部 $\mathrm{CO_2}$ 都进入高压工艺物流。蓝氢的净强度强烈依赖捕集率和供气链中的甲烷泄漏，因为甲烷的百年全球升温潜能值为 $29.8$（IPCC AR6）。

### 电解

热力学上，水电解在热中性电压下需要每千克氢 $39.4\ \mathrm{kWh}$；截至 2026 年，商用系统约耗电 $50$–$55\ \mathrm{kWh\,kg^{-1}}$（[[electrochemistry/fuel-cells-electrolysis]]）。因此电解氢的排放强度就是电的排放强度乘以约 $50$。

::: example 用电网电制氢 {#ex-grid}
一台电解槽每千克氢耗电 $52.5\ \mathrm{kWh}$。求 (a) 其氢的强度与无捕集 SMR（$10\ \mathrm{kg\,CO_2\,kg^{-1}}$）相同时电网的排放强度；(b) 达到 $3.38\ \mathrm{kg\,CO_2e\,kg^{-1}}$ 时的电网强度；(c) 若 2024 年使用的全部 $100\ \mathrm{Mt}$ 氢都改用电解供应，需要多少电力。
::: solution
(a) $10\ \mathrm{kg}/52.5\ \mathrm{kWh} = 0.190\ \mathrm{kg\,kWh^{-1}} = 190\ \mathrm{g\,kWh^{-1}}$。

(b) $3.38/52.5 = 0.0644\ \mathrm{kg\,kWh^{-1}} = 64\ \mathrm{g\,kWh^{-1}}$。

(c) $10^{11}\ \mathrm{kg}\times52.5\ \mathrm{kWh\,kg^{-1}} = 5.25\times10^{12}\ \mathrm{kWh} = 5250\ \mathrm{TWh}$ 每年——约为 2020 年代中期世界发电量（$30\,000\ \mathrm{TWh}$ 量级）的五分之一。因此在开发任何新用途之前，仅替代今日的化石氢就需要与当时全世界风电和光伏总发电量相当的低排放电力。决定低排放氢优先流向现有用途（氨、炼油）和缺乏替代方案之应用的，正是这种规模论证而非化学本身。
:::

## 把能量储存在化学键中

风与光的电力逐时逐季变化。电池（[[electrochemistry/batteries]]）高效储存数小时到数天；要存几个星期或数月、以及远距离输送，可以把能量储存在化学键里。选项有氢本身（压缩至 $350$–$700\ \mathrm{bar}$、在 $20\ \mathrm{K}$ 液化、或存入盐穴），以及**氢载体**：氨（质量含氢 $17.8\,\%$，在 $-33\,^\circ\mathrm{C}$ 或室温下 $10\ \mathrm{bar}$ 即为液体，且已有全球贸易）、甲醇与合成烃（需要碳源），以及**液态有机氢载体**（LOHC），如甲苯–甲基环己烷一对体系（质量含氢 $6.2\,\%$）或二苄基甲苯——储氢时加氢，释氢时吸热脱氢。

::: proposition 转化链的往返效率 {#prop-roundtrip}
若能量依次经过效率为 $\eta_1, \eta_2, \dots, \eta_k$ 的若干转化与储存步（每一步的效率都定义为有效输出能量除以输入能量，且采用一致的热值基准），往返效率为
$$
\eta_\mathrm{RT} = \prod_{i=1}^{k}\eta_i ,
$$ {#eq-roundtrip}
每交付一单位能量就必须生成 $1/\eta_\mathrm{RT}$ 单位。
:::

::: proof
设第一步入射能量 $E_0$。按效率定义，第 $i$ 步的输出是其输入（即第 $i - 1$ 步的输出）的 $\eta_i$ 倍；归纳即得第 $k$ 步输出 $E_0\prod\eta_i$。这一结果是[[green-chemistry/green-principles#prop-overall-yield]]的能量版本，与它一样，被最薄弱的步骤主宰。基准一致很要紧：电解槽效率常按高热值（HHV）标出，而燃料电池效率按低热值（LHV），混用会把 $\eta_\mathrm{RT}$ 高估至多 $18\,\%$——即两个热值之比。
:::

::: example 电—氢—电 {#ex-roundtrip}
估算把电能存为压缩氢、再用燃料电池发电的往返效率：电解 $52.5\ \mathrm{kWh\,kg^{-1}}$，压缩消耗氢能量的 $10\,\%$，燃料电池效率 $50\,\%$（LHV 基准）。与约 $90\,\%$ 的锂离子电池比较。
::: solution
在 LHV 基准（$33.3\ \mathrm{kWh\,kg^{-1}}$）下，电解效率为 $33.3/52.5 = 0.634$。加上压缩 $0.90$、燃料电池 $0.50$：
$$
\eta_\mathrm{RT} = 0.634\times0.90\times0.50 = 0.285 .
$$
约 $28\,\%$ 的电力得以回收，而电池约为 $90\,\%$。用氢储存一度电需要约 $3.5\ \mathrm{kWh}$ 输入，是电池的三倍。化学储能的理由不是效率而是**容量与时长**：一座装满氢的盐穴所储能量（数百吉瓦时），按每千瓦时容量计的成本远低于电池，数月存放的损失可以忽略。同理，若氢将直接用作化学品（制氨、炼钢、炼油）而非再转化为电，就完全省去了逆转转化，比较就变成了原料成本与排放强度之争。
:::
:::

**氨**作为载体和船用燃料都有吸引力，因为它不含碳且早已大量贸易。用电解氢在哈伯-博施回路中合成氨约需每吨 $10$–$12\ \mathrm{MWh}$ 电力；氨可在发动机和轮机中燃烧（须注意限制 $\mathrm{NO_x}$ 和 $\mathrm{N_2O}$ 生成），或在钌或镍催化剂上裂解回氢。氨吸入有剧毒，且对水生生物有毒，因此其作为燃料的使用必须沿用化肥工业长期实行的严格安全规程。

::: quiz
捕集的 $\mathrm{CO_2}$ 的下列用途中，哪一种最接近从大气中永久移除？
- [ ] 制尿素肥料
- [ ] 用电解氢制合成航空燃料
- [x] 与硅酸钙矿物反应生成碳酸钙
- [ ] 用于碳酸饮料充气
::: solution
矿物碳酸化把碳固定在热力学稳定的固体中，可持续地质时间尺度。尿素在土壤中水解，数周内就放回 $\mathrm{CO_2}$；燃料在燃烧时放碳；碳酸饮料数小时内就把 $\mathrm{CO_2}$ 放回。这些路线可以替代化石碳，但谈不上封存。
:::
:::

::: history 从 Sleipner 到氢经济 {#hist-ccs}
阿伦尼乌斯（Arrhenius）1896 年就估算了大气 $\mathrm{CO_2}$ 倍增引起的增暖，基林（Keeling）1958 年在莫纳罗亚开始了连续观测。酸性气体的胺洗法由博顿斯（Bottoms）于 1930 年取得专利，用于天然气处理。“氢经济”一词由博克里斯（Bockris）在 1970 年代初推广开来；而大型工业电解槽早已在挪威建成（Rjukan，自 1920 年代后期），用水电解为氨厂供氢。把分离出的 $\mathrm{CO_2}$ 注入封存始于 1996 年的 Sleipner；IPCC 于 2005 年出版了二氧化碳捕集与封存特别报告。IPCC 的《全球变暖 1.5 °C》（*Global Warming of 1.5 °C*，2018）和第六次评估报告（2021–2023）给出了包含二氧化碳移除的路径。科思创（Covestro）2016 年开始生产含 $\mathrm{CO_2}$ 的多元醇；IEA 的年度《全球氢评述》（*Global Hydrogen Review*）自 2021 年起追踪这一部门。
:::

## 后续内容

本章的热力学——混合、平衡、热值——来自 [[thermodynamics/free-energy]] 和 [[thermodynamics/mixtures]]；电解槽与燃料电池的电化学来自 [[electrochemistry/fuel-cells-electrolysis]]；吸附剂与催化剂来自 [[materials-chemistry/porous-materials]] 和 [[materials-chemistry/energy-materials]]。排放目标背后的气候科学在 [[environmental-chemistry/greenhouse-gases]]。最后一章 [[green-chemistry/circular-economy]] 通过让已经制成产品的碳留在使用中，补全非化石碳的图景。

::: summary
- 2024 年全球与能源相关的 $\mathrm{CO_2}$ 排放约 $37.8\ \mathrm{Gt}$（IEA），大气 $\mathrm{CO_2}$ 超过 $420\ \mathrm{ppm}$（NOAA）；IPCC 通往 $1.5$–$2\,^\circ\mathrm{C}$ 的情景包含 CCS 和二氧化碳移除。
- 由混合吉布斯自由能得到的最小分离功：燃煤烟气捕集 $90\,\%$ 约 $7\ \mathrm{kJ\,mol^{-1}}$，空气捕集约 $21\ \mathrm{kJ\,mol^{-1}}$；胺法工艺耗热 $3.5$–$4\ \mathrm{GJ\,t^{-1}}$，是最小功的许多倍。
- 捕集方式有吸收、吸附、膜与循环；燃烧前与富氧燃烧构型；封存在咸水层与枯竭油气藏中，2024 年在运能力约 $50\ \mathrm{Mt\,a^{-1}}$。
- 碳保持 $+4$ 的 $\mathrm{CO_2}$ 利用（尿素、碳酸酯、聚碳酸酯、矿物）几乎不需能量；还原为甲醇或燃料需要氢（每吨甲醇 $0.189\ \mathrm{t}$），只有配用低排放电力才是低排放的。唯有持久封存才谈得上移除。
- SMR 每千克 $\mathrm{H_2}$ 至少释放 $5.46\ \mathrm{kg\,CO_2}$（实际约 $9$–$11$）；电解氢的强度约为电网强度的 $50$ 倍，在约 $190\ \mathrm{g\,kWh^{-1}}$ 处与 SMR 持平。2024 年低排放氢不到约 $100\ \mathrm{Mt}$ 总量的 $1\,\%$（IEA）。
- 化学储能（氢、氨、甲醇、LOHC）以效率（电—氢—电往返约 $30\,\%$）换取容量与时长。
:::

$3\times1.008/17.031 = 0.178$，即 $17.8\,\%$——约为甲基环己烷作 LOHC 时质量含氢量的三倍；而作为中等压力下的液体，其每升含氢比液态氢本身还多。

::: exercise 燃气轮机的捕集 {level=2 check="9.78"}
在 $298.15\ \mathrm{K}$ 用[[#eq-wmin]]，求从 $y = 0.040$ 的燃气轮机排气中捕集 $90\,\%$ $\mathrm{CO_2}$ 的最小功。（以每摩尔 $\mathrm{CO_2}$ 的 $\mathrm{kJ}$ 计，保留三位有效数字。）
::: solution
$\phi y = 0.036$，$1 - \phi y = 0.964$，$y_\mathrm{r} = 0.004/0.964 = 0.004149$。$s(y_\mathrm{r}) = 0.004149\ln0.004149 + 0.995851\ln0.995851 = -0.02276 - 0.00413 = -0.02689$。$s(0.04) = 0.04\ln0.04 + 0.96\ln0.96 = -0.12876 - 0.03919 = -0.16795$。$w_\mathrm{min} = (2478.9/0.036)[0.964\times(-0.02689) + 0.16795] = 68\,858\times0.14203 = 9780\ \mathrm{J\,mol^{-1}} = 9.78\ \mathrm{kJ\,mol^{-1}}$（$0.222\ \mathrm{GJ\,t^{-1}}$），比燃煤烟气多约 $40\,\%$。
:::

::: exercise 经由氨的往返 {level=2 check="0.366"}
把电存为氨、再用轮机回收：电解效率 $70\,\%$，氨合成与储存 $95\,\%$，燃氨轮机 $55\,\%$（均在一致基准上）。求往返效率。（以小数输入，保留三位有效数字。）
::: solution
由[[#eq-roundtrip]]，$\eta_\mathrm{RT} = 0.70\times0.95\times0.55 = 0.366$。所设效率偏乐观；计入氨裂解或压缩的实际链条常在 $0.25$–$0.30$ 附近。
:::

::: exercise 矿物碳酸化 {level=2 check="2.64"}
设反应完全，按 $\mathrm{CaSiO_3 + CO_2 \rightarrow CaCO_3 + SiO_2}$ 固定一吨 $\mathrm{CO_2}$ 需要多少硅灰石 $\mathrm{CaSiO_3}$（$116.16\ \mathrm{g\,mol^{-1}}$）？（质量以吨计。）
::: solution
$116.16/44.01 = 2.64\ \mathrm{t}$，同时产出 $3.64\ \mathrm{t}$ 碳酸盐与二氧化硅。矿化吉吨量意味着要开采和搬运数倍于此的岩石——这就是原位矿化（把 $\mathrm{CO_2}$ 注入反应性玄武岩，如冰岛 CarbFix 项目自 2012 年以来的做法）有吸引力的原因。
:::

::: exercise 直接空气捕集 {level=3 check="0.468"}
证明小 $\phi$ 时[[#eq-wmin]]趋于 $-RT\ln y$，并在 $298.15\ \mathrm{K}$ 下计算从空气（$y = 4.2\times10^{-4}$）捕集 $75\,\%$ 时每吨的最小功。每捕集一吨必须处理多少空气？（最小功以每吨 $\mathrm{GJ}$ 计，保留三位有效数字。）
::: hint
求极限时，写出从摩尔分数为 $y$ 的大储库中移出 $\mathrm{d}n$ 摩尔 $\mathrm{CO_2}$ 的吉布斯自由能变化。
:::
::: solution
$\phi$ 很小时，从混合物中移出 $\mathrm{d}n$ 的 $\mathrm{CO_2}$ 并交付纯品，使其化学势从 $\mu^\circ + RT\ln y$ 升到 $\mu^\circ$；混合物其余部分一阶不变，故 $\mathrm{d}G/\mathrm{d}n = -RT\ln y$，对 $y = 4.2\times10^{-4}$ 为 $19.27\ \mathrm{kJ\,mol^{-1}}$。$\phi = 0.75$ 时：$\phi y = 3.15\times10^{-4}$，$y_\mathrm{r} = 1.05\times10^{-4}/0.999685 = 1.0503\times10^{-4}$。$s(y_\mathrm{r}) = 1.0503\times10^{-4}\times(-9.1612) - 1.0503\times10^{-4} = -1.0673\times10^{-3}$（小 $z$ 时用 $(1 - z)\ln(1 - z) \approx -z$）；$s(y) = 4.2\times10^{-4}\ln(4.2\times10^{-4}) + (1 - 4.2\times10^{-4})\ln(1 - 4.2\times10^{-4}) = -3.6855\times10^{-3}$。于是 $w_\mathrm{min} = (2478.9/3.15\times10^{-4})[0.999685\times(-1.0673\times10^{-3}) + 3.6855\times10^{-3}] = 7.8695\times10^{6}\times2.6186\times10^{-3} = 20.61\ \mathrm{kJ\,mol^{-1}}$，即 $20.61/44.01 = 0.468\ \mathrm{GJ\,t^{-1}}$。空气：$1\ \mathrm{t}$ $\mathrm{CO_2}$ 为 $22\,722\ \mathrm{mol}$；每摩尔空气捕集 $3.15\times10^{-4}$ mol，需要空气 $7.21\times10^{7}\ \mathrm{mol}$，在 $25\,^\circ\mathrm{C}$、$1\ \mathrm{bar}$ 下约 $1.8\times10^{6}\ \mathrm{m^3}$——让这些空气流过接触器（而非热力学最小功）才是 DAC 能耗与成本的主宰。
:::
:::

::: exercise 电制氨的电力 {level=3 check="9.72"}
估算用电解氢（$52.5\ \mathrm{kWh}$ 每 kg $\mathrm{H_2}$）制一吨氨所需的电力，另加空分、压缩和合成回路每吨 $0.40\ \mathrm{MWh}$。若电的排放强度为 $30\ \mathrm{g\,CO_2\,kWh^{-1}}$，把所得排放与 2020 年世界平均每吨氨 $2.4\ \mathrm{t\,CO_2}$（IEA）作比较。（电力以每吨 MWh 计，保留三位有效数字。）
::: solution
每吨氨所需氢：每个 $\mathrm{NH_3}$ 对应 $\tfrac32\,\mathrm{H_2}$，即 $3\times1.008/17.031 = 0.1776\ \mathrm{t} = 177.6\ \mathrm{kg}$。电解：$177.6\times52.5 = 9324\ \mathrm{kWh}$；加上装置其余部分的 $400\ \mathrm{kWh}$，共 $9724\ \mathrm{kWh} = 9.72\ \mathrm{MWh}$ 每吨。排放：$9724\times0.030\ \mathrm{kg} = 292\ \mathrm{kg\,CO_2}$，比 $2.4\ \mathrm{t}$ 减少 $88\,\%$。以此替代 2020 年全球约 $185\ \mathrm{Mt}$ 的氨产量，每年约需 $1800\ \mathrm{TWh}$ 低排放电力。另须注意：若把氨进一步制成尿素，仍然需要碳源；而用电解氢时，重整已没有工艺 $\mathrm{CO_2}$ 可供。
:::
:::
