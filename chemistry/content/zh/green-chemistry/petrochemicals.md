现代蒸汽裂解装置是一排裂解炉，每座炉内装有若干直径几厘米的炉管，烃类与蒸汽的混合物在约 $850\,^\circ\mathrm{C}$ 下流过其中。气体在热区停留零点几秒，随后在几毫秒内被急冷。就在这一瞬间，乙烷、丙烷或石脑油被“打碎”成乙烯、丙烯、丁二烯、芳烃和氢，而炉子之后的装置——一座 $-100\,^\circ\mathrm{C}$ 的冷箱和一连串精馏塔——再把它们分开。一台裂解装置每年可生产超过一百万吨乙烯，而乙烯是产量最大的有机化学品：它是聚乙烯的单体，也是环氧乙烷、乙二醇、氯乙烯与苯乙烯的起点。

有机化学工业的大部分碳来自石油和天然气，并流经数量少得惊人的几种分子。**石油化工**把原油馏分和天然气凝析液转化为寥寥几种基础原料——乙烯、丙烯、C₄ 烯烃与丁二烯、苯、甲苯与二甲苯，以及由合成气制的甲醇——再由它们制出支撑现代物质生活的中间体与聚合物。本章沿这条路径展开。它先讲制取馏分的炼油；再分析蒸汽裂解——一个受热力学与自由基链动力学共同支配的吸热反应；然后概览主要衍生物，用原子经济性与选择性解释为何某些路线被抛弃而另一些被采用。新旧路线的比较——氯醇法对直接氧化、氯乙烯平衡法工艺、环氧丙烷的过氧化氢路线——正是大宗工业在经济压力下践行的绿色化学。转化率、选择性与循环的词汇即 [[green-chemistry/chemical-industry]] 的语言；若干工艺背后的催化化学在 [[organometallics-catalysis]]。

## 从原油到馏分

原油是数千种烃的混合物——烷烃（石蜡烃）、环烷烃（环烷属烃）与芳烃——并含少量硫、氮、氧化合物和微量金属。炼油的第一步是**常压蒸馏**，按沸程把它分成馏分：炼厂气与液化石油气（C₁–C₄）、**石脑油**（大致 C₅–C₁₀，沸点约至 $180\,^\circ\mathrm{C}$）、煤油、瓦斯油（柴油），以及在真空下继续蒸馏的常压渣油。原油大部分成为燃料；石油需求中只有约十分之一左右用作石化原料，但这一部分的增长快于燃料需求。

馏分随后由转化工艺重新整形。

::: definition 裂化、重整与加氢精制 {#def-refining}
- **热（蒸汽）裂解**在高温下无催化剂，以自由基反应断裂 C–C 与 C–H 键；以蒸汽稀释和短停留时间使轻烯烃产率最大化。
- **流化催化裂化（FCC）**约 $500\,^\circ\mathrm{C}$ 下在沸石催化剂（基质中的八面沸石，即 Y 型沸石）上经碳正离子化学裂解重质瓦斯油；主要产品是汽油，副产丙烯与丁烯。催化剂数秒内积碳，并在流化床中烧焦连续再生。
- **催化重整**在铂（常加铼或锡）/氯化氧化铝催化剂上约 $500\,^\circ\mathrm{C}$ 转化石脑油，使环烷烃脱氢、烷烃脱氢环化成芳烃，并副产有价值的氢。它是苯、甲苯与二甲苯（BTX）的主要来源。
- **加氢精制**以氢在钴-钼或镍-钼硫化物催化剂上反应，脱除硫、氮与金属；硫以 $\mathrm{H_2S}$ 形式离开，在克劳斯法中转化为元素硫，并大多成为硫酸装置的原料（[[green-chemistry/industrial-inorganic]]）。
:::

碳正离子化学与自由基化学给出截然不同的产物。沸石中的碳正离子会重排为最稳定的（叔）离子，β-断裂给出支化碎片而几乎不生成乙烯，因为伯碳正离子太不稳定而无法生成；自由基不易重排，而伯自由基的 β-断裂给出乙烯。这就是乙烯以蒸汽裂解而不是催化裂化生产的原因。

## 蒸汽裂解

### 热力学

最简单的裂解反应是乙烷脱氢：
$$
\mathrm{C_2H_6(g)} \rightleftharpoons \mathrm{C_2H_4(g)} + \mathrm{H_2(g)} .
$$
由 NBS 数据（$\Delta_\mathrm{f}H^\circ$：乙烷 $-84.68$、乙烯 $+52.26\ \mathrm{kJ\,mol^{-1}}$；$S^\circ$：乙烷 $229.60$、乙烯 $219.56$、$\mathrm{H_2}$ $130.68\ \mathrm{J\,K^{-1}\,mol^{-1}}$），$\Delta_\mathrm{r}H^\circ = +136.9\ \mathrm{kJ\,mol^{-1}}$，$\Delta_\mathrm{r}S^\circ = +120.6\ \mathrm{J\,K^{-1}\,mol^{-1}}$。这是氨合成的镜像：吸热，且气体分子数增加。高温低压有利于产物，而 $K = 1$ 仅在 $T \approx \Delta_\mathrm{r}H^\circ/\Delta_\mathrm{r}S^\circ = 1135\ \mathrm{K}$。

::: proposition 含稀释剂的脱氢平衡 {#prop-dilution}
对 $\mathrm{A(g)} \rightleftharpoons \mathrm{B(g)} + \mathrm{C(g)}$，以纯 $\mathrm{A}$ 进料、每摩尔 $\mathrm{A}$ 用 $s$ 摩尔惰性气（蒸汽）稀释，总压为 $p$，气体理想，则平衡转化率 $X$ 满足
$$
K = \frac{X^2}{(1 - X)(1 + X + s)}\,\frac{p}{p^\circ},
\qquad
X = \frac{-Ks + \sqrt{K^2s^2 + 4(p/p^\circ + K)K(1 + s)}}{2(p/p^\circ + K)} .
$$ {#eq-dilution}
在固定 $T$ 下，$X$ 随 $p$ 降低而增大、随 $s$ 增大而增大：稀释相当于降低压力。
:::

::: proof
每摩尔进料的 A，在转化率 $X$ 下各量为：A $1 - X$，B 与 C 各 $X$，惰性气 $s$，总量 $n = 1 + X + s$。对理想气体 $K = (x_\mathrm{B}x_\mathrm{C}/x_\mathrm{A})(p/p^\circ)$，压力指数为 $\Delta\nu = +1$，而 $x_\mathrm{B}x_\mathrm{C}/x_\mathrm{A} = [X^2/n^2]/[(1 - X)/n] = X^2/[(1 - X)n]$，即得第一个方程。展开得 $(p/p^\circ)X^2 = K(1 - X)(1 + X + s) = K(1 + s - sX - X^2)$，这是关于 $X$ 的二次方程 $(p/p^\circ + K)X^2 + KsX - K(1 + s) = 0$，其正根即[[#eq-dilution]]。增大 $s$ 使 $n$ 增大，从而降低 B 与 C 的分压，与降低 $p$ 的作用完全相同；形式上 $X$ 只通过反应组分（烃）的分压依赖 $p$ 与 $s$。
:::

$\Delta_\mathrm{r}G^\circ(1100\ \mathrm{K}) \approx 136\,940 - 1100\times120.64 = 4236\ \mathrm{J\,mol^{-1}}$，故 $K = \exp(-4236/(8.314\times1100)) = 0.630$。

(a) $s = 0$：$X^2/(1 - X^2) = K/(p/p^\circ) = 0.315$，故 $X^2 = 0.315/1.315 = 0.2395$，$X = 0.489$。

(b) $s = 0.5$：由[[#eq-dilution]]，$X = [-0.315 + \sqrt{0.0992 + 4\times2.630\times0.630\times1.5}]/(2\times2.630) = (-0.315 + 3.168)/5.259 = 0.542$。

半摩尔蒸汽的稀释把平衡上限提高五个百分点；蒸汽还减少炉管壁上的积碳（通过降低烃分压和气化碳），其热容又限制沿炉管的温度降。按每吨乙烯计的反应焓为
$$
\frac{136.9\ \mathrm{kJ\,mol^{-1}}}{28.05\ \mathrm{g\,mol^{-1}}}\times10^{6}\ \mathrm{g} = 4.88\ \mathrm{GJ},
$$
这些热在约 $850\,^\circ\mathrm{C}$ 下由炉内燃烧燃料供给——主要是裂解副产的甲烷与氢。把进料和蒸汽加热到反应温度以及运转冷分离的能量大约使此数增至三倍；按其能量分摊基准，Ren、Patel 与 Blok（2006）估计乙烷裂解的单位能耗约每吨乙烯 $17$–$21\ \mathrm{GJ}$，石脑油 $26$–$31\ \mathrm{GJ}$。蒸汽裂解是有机化学工业中能耗最高的单一工艺。
:::
:::

### 机理与选择性

裂解按自由基链进行，赖斯（Rice）与赫茨费尔德（Herzfeld）于 1934 年最先针对乙烷分析了这一链：

1. **链引发**：最弱的键——C–C 键——均裂：$\mathrm{C_2H_6 \rightarrow 2\,CH_3^{\bullet}}$。
2. **夺氢**：$\mathrm{CH_3^{\bullet} + C_2H_6 \rightarrow CH_4 + C_2H_5^{\bullet}}$。
3. **β-断裂**（链传递）：乙基自由基断裂与自由基中心处于 β 位的 C–H 键，给出乙烯和氢原子：$\mathrm{C_2H_5^{\bullet} \rightarrow C_2H_4 + H^{\bullet}}$。
4. **链传递**：$\mathrm{H^{\bullet} + C_2H_6 \rightarrow H_2 + C_2H_5^{\bullet}}$，再生链载体。
5. **链终止**：自由基复合或歧化。

步骤 3 与 4 构成生成乙烯和氢的链；链很长，所以总化学计量接近 $\mathrm{C_2H_6 \rightarrow C_2H_4 + H_2}$，并因链引发带少量甲烷。这类链的动力学在 [[kinetics/chain-reactions]] 展开。对更大的烷烃，在不同碳上夺氢生成的自由基经 β-断裂给出较小的烯烃与自由基的分布，这就是石脑油同时给出乙烯、丙烯、丁二烯与芳烃的原因。

产物本身也有反应性。乙烯与丙烯能加上自由基、低聚、环化成芳烃，最终在炉管壁上成焦，焦层隔热使管子必须定期烧焦除碳。目标产物是一连串反应中的*中间体*，其产率随停留时间经过一个极大值。

::: proposition 中间产物的最大产率 {#prop-consecutive}
对一级串联反应 $\mathrm{A} \xrightarrow{k_1} \mathrm{B} \xrightarrow{k_2} \mathrm{C}$，在 $t = 0$ 只含 $\mathrm{A}$ 的平推流或间歇反应器中，$\mathrm{B}$ 的产率为
$$
\frac{[\mathrm{B}]}{[\mathrm{A}]_0} = \frac{k_1}{k_2 - k_1}\left(\mathrm{e}^{-k_1t} - \mathrm{e}^{-k_2t}\right) \quad (k_1 \neq k_2),
$$ {#eq-consecutive}
在 $t_\mathrm{max} = \ln(k_2/k_1)/(k_2 - k_1)$ 处达到最大，最大值为 $(k_1/k_2)^{k_2/(k_2 - k_1)}$。最大产率只依赖比值 $\kappa = k_2/k_1$：$\kappa \to 0$ 时为 $1$，$\kappa = 1$ 时为 $1/\mathrm{e}$，$\kappa$ 很大时趋于 $0$。
:::

::: proof
速率方程为 $\mathrm{d}[\mathrm{A}]/\mathrm{d}t = -k_1[\mathrm{A}]$ 与 $\mathrm{d}[\mathrm{B}]/\mathrm{d}t = k_1[\mathrm{A}] - k_2[\mathrm{B}]$。第一式给出 $[\mathrm{A}] = [\mathrm{A}]_0\mathrm{e}^{-k_1t}$；第二式是线性的，$\mathrm{d}[\mathrm{B}]/\mathrm{d}t + k_2[\mathrm{B}] = k_1[\mathrm{A}]_0\mathrm{e}^{-k_1t}$，以积分因子 $\mathrm{e}^{k_2t}$、结合 $[\mathrm{B}](0) = 0$ 即得[[#eq-consecutive]]（[[kinetics/rate-laws]]）。令导数为零：$k_1\mathrm{e}^{-k_1t} = k_2\mathrm{e}^{-k_2t}$，故 $\mathrm{e}^{(k_2 - k_1)t} = k_2/k_1$，$t_\mathrm{max} = \ln(k_2/k_1)/(k_2 - k_1)$。在此时刻 $\mathrm{e}^{-k_2t} = (k_1/k_2)\mathrm{e}^{-k_1t}$，于是括号为 $\mathrm{e}^{-k_1t}(1 - k_1/k_2)$，产率为 $(k_1/k_2)\mathrm{e}^{-k_1t_\mathrm{max}} = (k_1/k_2)(k_1/k_2)^{k_1/(k_2 - k_1)} = (k_1/k_2)^{k_2/(k_2 - k_1)}$。以 $\kappa = k_2/k_1$ 表示即 $\kappa^{-\kappa/(\kappa - 1)}$，$\kappa \to 1$ 时趋于 $1/\mathrm{e}$。
:::

::: example 在炉子里停留多久？ {#ex-residence}
在一个对裂解炉出口温度的理想化模型中，乙烷以 $k_1 = 20\ \mathrm{s^{-1}}$ 消耗，乙烯以 $k_2 = 4.0\ \mathrm{s^{-1}}$ 转化为较重的产物与焦前驱体，均视为一级。求使乙烯产率最大的停留时间、该时刻的产率与乙烷转化率，以及气体停留时间增至三倍时的产率。
::: solution
$\kappa = k_2/k_1 = 0.20$，由[[#prop-consecutive]]
$$
t_\mathrm{max} = \frac{\ln(4.0/20)}{4.0 - 20}\ \mathrm{s} = \frac{-1.609}{-16}\ \mathrm{s} = 0.101\ \mathrm{s},
\qquad
Y_\mathrm{max} = \left(\frac{k_1}{k_2}\right)^{k_2/(k_2 - k_1)} = 5^{4/(-16)} = 5^{-0.25} = 0.669 .
$$
$t_\mathrm{max}$ 时的乙烷转化率为 $1 - \mathrm{e}^{-20\times0.101} = 0.866$。在 $0.30\ \mathrm{s}$ 时乙烷几乎全部消耗（$99.8\,\%$），但乙烯产率已降到 $\tfrac{20}{-16}(\mathrm{e}^{-6} - \mathrm{e}^{-1.2}) = 0.373$。真实裂解装置取停留时间 $0.1$–$0.5\ \mathrm{s}$，乙烷转化率略低（约 $60$–$70\,\%$，未反应乙烷循环），因为当转化率接近最大产率点时选择性陡降，且积碳加速。该模型忽略了真实动力学的可逆性与自由基链本性，但抓住了停留时间为何以零点几秒计、气体为何在转移线换热器中数毫秒急冷的原因。
:::
:::

### 原料与产物

裂解装置产出什么取决于投入什么。乙烷主要给乙烯（未反应乙烷循环时总产率按质量约 $80\,\%$）和氢；丙烷与丁烷给更多丙烯；石脑油约给 $30\,\%$ 乙烯、$15\,\%$ 丙烯、丁二烯与其他 C₄，以及富苯的“裂解汽油”，并副产作燃料烧掉的甲烷与氢。约 2010 年起美国的页岩气革命使乙烷变得廉价，并把新增产能转向乙烷裂解装置，它们几乎不产丙烯与丁二烯；缺口由**专产（on-purpose）**路线弥补，如铂-锡或铬氧化物催化剂上的丙烷脱氢，在中国则由**甲醇制烯烃**（MTO）在沸石 SAPO-34 上完成，甲醇来自煤制合成气——这条路线的 $\mathrm{CO_2}$ 足迹大得多。

烯烃最大的出路是塑料，2024 年全球产量约 $431\ \mathrm{Mt}$（Plastics Europe,《Plastics – the fast Facts 2025》），其中绝大多数来自化石原料。

## 合成气与甲醇

第二条碳路径流经**合成气**（syngas）：CO 与 $\mathrm{H_2}$ 的混合物，由天然气蒸汽重整、重质油部分氧化或煤气化制得。甲醇由合成气在铜-锌氧化物-氧化铝催化剂上约 $250\,^\circ\mathrm{C}$、$50$–$100\ \mathrm{bar}$ 下制成：
$$
\mathrm{CO + 2\,H_2 \rightleftharpoons CH_3OH}, \qquad \mathrm{CO_2 + 3\,H_2 \rightleftharpoons CH_3OH + H_2O}.
$$
同位素标记研究表明，工业条件下大部分甲醇由气体中的 $\mathrm{CO_2}$ 生成，CO 主要通过水煤气变换起作用——这使同一批催化剂也是 $\mathrm{CO_2}$ 利用的候选（[[green-chemistry/carbon-hydrogen]]）。与氨合成一样，甲醇合成放热且摩尔数减少，在循环回路中进行。甲醇是甲醛、乙酸、甲基叔丁基醚（MTBE）以及经 MTO 制烯烃的原料。

**乙酸**展示了催化如何革新原子经济性。孟山都法（1970）使用铑-碘催化剂，以及 BP 以铱为基础的 Cativa 工艺（1996）使甲醇羰基化，$\mathrm{CH_3OH + CO \rightarrow CH_3COOH}$，原子经济性 $100\,\%$，以甲醇计选择性超过 $99\,\%$；其有机金属催化循环（碘甲烷的氧化加成、CO 的迁移插入、乙酰碘的还原消除）是 [[organometallics-catalysis/elementary-reactions]] 中的标准例子。丙烯氢甲酰化制丁醛是另一个有机金属工艺，在 [[organometallics-catalysis/hydrogenation-hydroformylation]] 讨论。

## 乙烯衍生物

### 环氧乙烷

环氧乙烷（氧化乙烯，oxirane）是乙二醇（用于聚酯与防冻液）、乙氧基化物表面活性剂与乙醇胺的前体，最初以**氯醇法**生产：乙烯与氯水反应生成 2-氯乙醇，再用碱（石灰）环化：
$$
\mathrm{C_2H_4 + Cl_2 + H_2O \rightarrow HOCH_2CH_2Cl + HCl}, \qquad 2\,\mathrm{HOCH_2CH_2Cl + Ca(OH)_2 \rightarrow 2\,C_2H_4O + CaCl_2 + 2\,H_2O}.
$$
所有氯最终都成为氯化钙，还有氯化有机副产物。自 1930 年代（Union Carbide，1937）以来、且如今几乎全部以氧气在 α-氧化铝负载的银催化剂上**直接氧化**制环氧乙烷，约 $230$–$280\,^\circ\mathrm{C}$、$10$–$30\ \mathrm{bar}$：
$$
\mathrm{C_2H_4 + \tfrac12O_2 \rightarrow C_2H_4O} \quad (\mathrm{AE} = 100\,\%), \qquad \mathrm{C_2H_4 + 3\,O_2 \rightarrow 2\,CO_2 + 2\,H_2O}.
$$
与之竞争的完全燃烧，以及环氧乙烷自身随后的燃烧，限制了选择性。银是唯一给出实用选择性的金属；微量氯化物（进料中 ppm 级的氯乙烷）以及铯和铼助剂把选择性从早期催化剂的约 $70\,\%$ 提高到今天的 $85$–$90\,\%$，单程转化率不超过 $10\,\%$，未反应的乙烯循环。

::: example 以二氧化碳计的选择性 {#ex-eo}
某环氧乙烷装置以 $85\,\%$ 的选择性运行，消耗的其余乙烯燃烧为 $\mathrm{CO_2}$。求每吨环氧乙烷消耗的乙烯与生成的 $\mathrm{CO_2}$，以及把选择性提高到 $90\,\%$ 的节约。并与氯醇法的原子经济性比较。
::: solution
每摩尔环氧乙烷消耗 $1/0.85 = 1.176\ \mathrm{mol}$ 乙烯，其中 $0.176\ \mathrm{mol}$ 燃烧为 $2\times0.176 = 0.353\ \mathrm{mol}\ \mathrm{CO_2}$。每吨（$M$：$\mathrm{C_2H_4O}$ $44.05$、$\mathrm{C_2H_4}$ $28.05$、$\mathrm{CO_2}$ $44.01$）：
$$
m(\mathrm{C_2H_4}) = 1.176\times\frac{28.05}{44.05} = 0.749\ \mathrm{t}, \qquad m(\mathrm{CO_2}) = 0.353\times\frac{44.01}{44.05} = 0.353\ \mathrm{t}.
$$
$90\,\%$ 时：乙烯 $0.708\ \mathrm{t}$、$\mathrm{CO_2}$ $0.222\ \mathrm{t}$——五个百分点的选择性每吨节省 $41\ \mathrm{kg}$ 乙烯与 $131\ \mathrm{kg}$ $\mathrm{CO_2}$，对年产数十万吨的装置而言，足以支撑催化剂上的巨额研发投入。这股燃烧 $\mathrm{CO_2}$ 是从循环气中移出的浓缩物流，是捕集成本较低的 $\mathrm{CO_2}$ 来源之一。

对氯醇法，总方程式 $\mathrm{C_2H_4 + Cl_2 + Ca(OH)_2 \rightarrow C_2H_4O + CaCl_2 + H_2O}$ 给出 $\mathrm{AE} = 44.05/(28.05 + 70.90 + 74.09) = 25.5\,\%$，即使产率完美，每吨产品也带来约 $2.5\ \mathrm{t}$ 氯化钙和水。
:::
:::

环氧乙烷是高度易燃气体和致癌物；它在密闭系统中处置，反应器在乙烯-氧混合气爆炸范围之外运行，以甲烷作致稳气。大部分环氧乙烷在厂内经水解直接转化为乙二醇；Shell 的 OMEGA 工艺经由碳酸乙烯酯（由环氧乙烷与 $\mathrm{CO_2}$ 制得），它水解对单乙二醇的选择性比直接水合高得多。

### 氯乙烯与平衡法

氯乙烯（chloroethene），聚氯乙烯的单体，由乙烯与氯经 1,2-二氯乙烷（EDC）制成。先直接氯化，$\mathrm{C_2H_4 + Cl_2 \rightarrow ClCH_2CH_2Cl}$，随后 EDC 在约 $500\,^\circ\mathrm{C}$ 热裂解，$\mathrm{ClCH_2CH_2Cl \rightarrow CH_2{=}CHCl + HCl}$，把一半的氯以氯化氢释放。平衡法不是把 HCl 出售或中和，而是送入**氧氯化**，$\mathrm{C_2H_4 + 2\,HCl + \tfrac12O_2 \rightarrow ClCH_2CH_2Cl + H_2O}$，在氯化铜(II) 催化剂上进行，再制 EDC。两条路线等量生产 EDC 时，HCl 即生即用。

::: example 平衡法 VCM 工艺的原子经济性 {#ex-vcm}
写出平衡法的总方程式并求其原子经济性（$M$：$\mathrm{C_2H_4}$ $28.05$、$\mathrm{Cl_2}$ $70.90$、$\mathrm{O_2}$ $32.00$、$\mathrm{C_2H_3Cl}$ $62.50$）。
::: solution
把直接氯化、氧氯化与两个 EDC 的裂解相加：
$$
\begin{aligned}
\mathrm{C_2H_4 + Cl_2} &\rightarrow \mathrm{C_2H_4Cl_2}\\
\mathrm{C_2H_4 + 2\,HCl + \tfrac12O_2} &\rightarrow \mathrm{C_2H_4Cl_2 + H_2O}\\
2\,\mathrm{C_2H_4Cl_2} &\rightarrow 2\,\mathrm{C_2H_3Cl} + 2\,\mathrm{HCl}\\ \hline
2\,\mathrm{C_2H_4 + Cl_2 + \tfrac12O_2} &\rightarrow 2\,\mathrm{C_2H_3Cl} + \mathrm{H_2O}
\end{aligned}
$$
$\mathrm{AE} = 2\times62.50/(2\times28.05 + 70.90 + 16.00) = 125.0/143.0 = 87.4\,\%$，唯一副产物是水。若没有氧氯化，仅裂解一步每摩尔氯乙烯就产生一摩尔 HCl，$\mathrm{C_2H_4 + Cl_2 \rightarrow C_2H_3Cl + HCl}$ 的原子经济性只有 $62.50/98.95 = 63.2\,\%$。实际上，副产物——氧氯化与裂解生成的氯代乙烷及更重的化合物——被焚烧并回收 HCl。氯乙烯是致癌物（1970 年代确认了接触工人的肝血管肉瘤），此后职业接触限值下降了几个数量级：风险管理（[[green-chemistry/green-principles#def-hazard-risk]]）改变整个工业运行方式的一例。
:::
:::

## 丙烯与芳烃衍生物

**环氧丙烷**展示了三代工艺化学。与环氧乙烷类似的**氯醇**法每吨产品约产两吨氯化钙。**联产品（Halcon/ARCO）路线**先把异丁烷或乙苯氧化为氢过氧化物，再由它在钼或钛催化剂上把氧原子转移给丙烯；联产品叔丁醇（制 MTBE）或苯乙烯（经 1-苯基乙醇）按固定比例生成，每吨环氧丙烷约 $2.2$–$2.5\ \mathrm{t}$ 苯乙烯，使装置被两个市场绑在一起。**HPPO 工艺**于 2008 年首次工业化（BASF 与 Dow 在安特卫普；Evonik 与 Uhde 在韩国），以过氧化氢在钛硅沸石-1（TS-1）上使丙烯环氧化——TS-1 是一种沸石，其中孤立的钛原子活化 $\mathrm{H_2O_2}$：
$$
\mathrm{CH_3CH{=}CH_2 + H_2O_2 \rightarrow CH_3CH(O)CH_2 + H_2O} .
$$
其副产物是水，2010 年获美国总统绿色化学挑战奖。过氧化氢本身以蒽醌自氧化法生产，公平的寿命周期比较必须计入蒽醌法自身的溶剂、能量与氢耗用（[[green-chemistry/green-metrics#alg-lca]]）。

**苯酚与丙酮**以**异丙苯法**一道生产（霍克（Hock），1944）：苯在沸石上与丙烯烷基化得异丙苯（cumene），空气自氧化为过氧化氢异丙苯；酸催化重排（霍克重排，苯基向缺电子氧的迁移）使其断裂为苯酚与丙酮。总化学计量 $\mathrm{C_6H_6 + C_3H_6 + O_2 \rightarrow C_6H_5OH + (CH_3)_2CO}$ 对两种产品的原子经济性为 $100\,\%$——但比例固定，每吨苯酚 $58.08/94.11 = 0.617\ \mathrm{t}$ 丙酮，不论各自需求如何。苯酚大部分用于双酚 A（恰好与丙酮一起）和酚醛树脂。

**苯、甲苯与二甲苯**供给乙苯与苯乙烯（聚苯乙烯）、异丙苯、环己烷（制尼龙中间体）、硝基苯与苯胺（制聚氨酯异氰酸酯），以及最重要的对二甲苯——在 Amoco/Mid-Century 工艺中以空气在乙酸中经钴-锰-溴催化剂氧化为对苯二甲酸，即聚对苯二甲酸乙二醇酯（PET）的单体。过剩的甲苯经歧化转化为苯与二甲苯。苯是人类致癌物，这就是汽油中苯含量受管制、且苯在密闭系统中处置的原因。

::: warning 100 % 的原子经济性可能掩盖联产品问题 {#warn-coproduct}
异丙苯法与联产品环氧丙烷路线的原子经济性完美或近乎完美，却都很脆弱：它们按固定比例生产两种产品，一旦其中一种的市场萎缩，其价格下跌，必须储存或烧掉，工艺的经济学与真实废弃物状况就恶化。原子经济性把联产品计为产品；市场却未必。相反，原子经济性较低但副产品无害且可销售的工艺可能更稳健。正因如此，工艺设计者重视**柔性（flexibility）**——如 HPPO 或专产丙烯这类只生产一种产品的路线。
:::

::: quiz
为什么乙烯以热（蒸汽）裂解而不是沸石上的催化裂化生产？
- [ ] 沸石会被乙烯破坏
- [x] 碳正离子会重排为更稳定的支化离子，且极少生成伯碳正离子，所以酸催化给出支化的较大碎片；而自由基 β-断裂容易给出乙烯
- [ ] 催化裂化吸热而热裂解放热
- [ ] 热裂解在更低的温度下进行
::: solution
机理不同。催化裂化中，碳正离子经氢负离子与甲基迁移向叔离子重排，而生成伯碳正离子的 β-断裂（生成乙烯所需要的）极不利，所以产物是汽油馏分的支化烷烃、丙烯与丁烯。自由基不易重排，伯自由基经 β-断裂给出乙烯。两个工艺都吸热，且热裂解温度更高（约 $850$ 对 $500\,^\circ\mathrm{C}$）。
:::
:::

## 碳、能量与石油化工的未来

石油化工面临两个相关的挑战。其一是**排放**：高价值化学品（烯烃与芳烃）占 2022 年一次化学品约 $935\ \mathrm{Mt}$ 直接 $\mathrm{CO_2}$ 排放的约 $27\,\%$（IEA，截至 2026 年的最新有日期数值），主要来自裂解炉。正在开发的选项包括电加热裂解炉（BASF、SABIC 与 Linde 2024 年在路德维希港投产了一座示范装置）、捕集炉用燃料的 $\mathrm{CO_2}$，以及使用富氢燃料气。其二是**原料**：即使过程排放为零，产品中的碳仍是化石的，并会在寿命终结焚烧时释放。替代它需要生物质（[[green-chemistry/renewable-feedstocks]]）、捕集的 $\mathrm{CO_2}$ 配低排放氢（[[green-chemistry/carbon-hydrogen]]）或再生塑料（[[green-chemistry/circular-economy]]），每种在规模与能量上都有自己的制约。

::: history 从煤焦油到裂解炉 {#hist-petrochem}
第一个有机化学工业以煤焦油为原料，即煤气的副产品，从 1850 年代起为染料工业提供苯、甲苯、萘与苯酚。重油热裂解制汽油由印第安纳标准石油（Standard Oil of Indiana）的威廉·伯顿（William Burton）于 1913 年获专利，欧仁·胡德里（Eugène Houdry）1937 年引入了催化裂化；流化催化裂化继起于 1942 年，沸石催化剂（Mobil 开发）在 1960 年代初出现。Union Carbide 1920 年在西弗吉尼亚州克莱丁宁开始以天然气凝析液生产乙烯及其衍生物，一般被视为石油化工的开端，并于 1937 年使银催化环氧乙烷工业化。海因里希·霍克（Heinrich Hock）与尚·朗（Shon Lang）1944 年描述了异丙苯过氧化氢重排。卡尔·齐格勒（Karl Ziegler）的乙烯低压聚合与朱利奥·纳塔（Giulio Natta）的立构规整聚丙烯（1953–1954，1963 年诺贝尔奖），以及菲利普斯铬催化剂（霍根（Hogan）与班克斯（Banks），1951），造就了聚烯烃工业。孟山都的铑催化甲醇羰基化始于 1970 年，HPPO 工艺在 2008 年。维特科夫（Wittcoff）、鲁本（Reuben）与普洛特金（Plotkin）的《Industrial Organic Chemicals》逐产品描述了由此形成的网络。
:::

## 后续内容

本章的基础原料是 [[polymer-chemistry]] 的单体，其寿命终期的命运是 [[green-chemistry/circular-economy]] 的主题。石油化工原料不含氧，与生物质富氧结构形成对照，界定了 [[green-chemistry/renewable-feedstocks]] 的挑战。合成气、甲醇与重整氢通向 [[green-chemistry/carbon-hydrogen]]。许多分离——近沸点烃的精馏、以环丁砜抽提芳烃——以及衍生物生产中的溶剂选择则连接到 [[green-chemistry/safer-solvents]]。

::: summary
- 炼油以蒸馏把原油分馏，并以催化裂化（碳正离子、沸石，产汽油与丙烯）、重整（Pt，产芳烃与 $\mathrm{H_2}$）与加氢精制（硫转为 $\mathrm{H_2S}$ 再制硫）重新整形。
- 乙烷裂解吸热（$+136.9\ \mathrm{kJ\,mol^{-1}}$）且摩尔数增加；$K = 1$ 在约 $1135\ \mathrm{K}$，蒸汽稀释相当于降低压力（$1100\ \mathrm{K}$、$2\ \mathrm{bar}$ 下无稀释剂 $X = 0.49$、加 $0.5$ 蒸汽 $X = 0.54$）。
- 裂解是自由基链（赖斯-赫茨费尔德，Rice–Herzfeld）；烯烃产物会进一步反应，所以中间体产率在 $t_\mathrm{max} = \ln(k_2/k_1)/(k_2 - k_1)$ 处达峰——故毫秒级急冷、单程转化率有限。
- 合成气制甲醇（Cu/ZnO，主要经 $\mathrm{CO_2}$），并经羰基化（Rh、Ir）制乙酸，原子经济性 $100\,\%$。
- 银催化直接氧化制环氧乙烷（$\mathrm{AE} = 100\,\%$，选择性 $85$–$90\,\%$）取代了氯醇法（$25.5\,\%$）；氯乙烯平衡法循环 HCl（$87.4\,\%$）；HPPO 制环氧丙烷副产水。
- 固定的联产品比（苯酚/丙酮 $1 : 0.617$，环氧丙烷/苯乙烯）使原子经济性完美的工艺受制于市场。
- 2022 年高价值化学品约占一次化学品 $\mathrm{CO_2}$ 的四分之一；电裂解、碳捕集与非化石碳是主要选项。
:::

(a) $X^2/(1 - X^2) = 0.630$，$X^2 = 0.630/1.630 = 0.3865$，$X = 0.622$。

(b) $X = [-0.630\times4 + \sqrt{(0.630\times4)^2 + 4(1 + 0.630)(0.630)(5)}]/[2(1.630)] = [-2.520 + \sqrt{6.350 + 20.54}]/3.260 = (-2.520 + 5.186)/3.260 = 0.818$，即 $81.8\,\%$。

等价压力：令 $s = 0$，$p/p^\circ = K(1 - X^2)/X^2 = 0.630\times(1 - 0.669)/0.669 = 0.312$：每摩尔乙烷四摩尔蒸汽、$1\ \mathrm{bar}$ 下，等价于在约 $0.31\ \mathrm{bar}$ 下裂解未稀释乙烷，因为烃分压相近。让裂解装置在真空下运行是危险的（空气漏入高温烃流），且需要庞大的设备；蒸汽安全地达到同样效果。工业稀释比低于 $4$（乙烷约 $0.3$–$0.5$，质量计），在平衡与积碳同产蒸汽的能耗之间折衷。

::: exercise 炉子热负荷 {level=3 check="4.88"}
对 $\mathrm{C_2H_6 \rightarrow C_2H_4 + H_2}$（$\Delta_\mathrm{r}H^\circ = 136.94\ \mathrm{kJ\,mol^{-1}}$），计算每吨乙烯须供给的反应焓（以 GJ 计）。若这些热由燃烧甲烷（$\Delta_\mathrm{c}H = -802\ \mathrm{kJ\,mol^{-1}}$，产物为气态）供给、炉子向反应传热效率为 $90\,\%$，仅反应焓一项每吨乙烯释放多少 $\mathrm{CO_2}$？（焓以每吨的 GJ 计。）
::: solution
$136.94\ \mathrm{kJ\,mol^{-1}}\times(10^6/28.05)\ \mathrm{mol} = 4.88\times10^{6}\ \mathrm{kJ} = 4.88\ \mathrm{GJ}$ 每吨。所需燃料为 $4.88\times10^{6}/(0.90\times802) = 6.76\times10^{3}\ \mathrm{mol}$ 甲烷，释放等摩尔的 $\mathrm{CO_2}$：$6.76\times10^{3}\times44.01\ \mathrm{g} = 0.298\ \mathrm{t\,CO_2}$ 每吨乙烯。把进料与蒸汽加热以及驱动分离系统的压缩机会使此数增加数倍，这就是典型排放达每吨乙烯 $1\ \mathrm{t\,CO_2}$ 量级或更高的原因。若炉子改烧副产的氢，原则上反应热负荷可在无 $\mathrm{CO_2}$ 的情况下满足——这是低排放裂解的路线之一。
