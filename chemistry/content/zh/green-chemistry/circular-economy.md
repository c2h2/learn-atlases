一个聚对苯二甲酸乙二醇酯（PET）塑料瓶，由石油和天然气经大约六座化工厂的链条制成，灌入产品、售出、几天内被清空，然后丢弃。如果被收集、清洗并重新挤出，它可能变成抓绒衣的纤维，而这种纤维在自己生命终结时又很少再被回收。若未被收集，它就进填埋场、被烧掉，或逸入环境中持续数十年。同样的线性模式——取料、制造、处置——适用于大多数材料。OECD 的《全球塑料展望》（*Global Plastics Outlook*，2022）估计，2019 年全球产生的 $353\ \mathrm{Mt}$ 塑料废物中，只有 $9\,\%$ 被回收（计入分选与加工损失后），$19\,\%$ 被焚烧，约一半进入卫生填埋，$22\,\%$ 管理不善——被倾倒、露天焚烧或泄漏到环境中。

**循环经济**力求让材料尽可能长期地以最高价值留在使用之中，并再生自然系统，使废物成为新产品的原料。这一理念由艾伦·麦克阿瑟基金会自 2010 年起推动，如今已融入欧盟政策；它虽是经济与系统层面的构想，其成败却在很大程度上取决于化学：聚合物能否经受再加工、混合物能否被分开、一个分子能否解聚回单体再聚合、产品是否含有根本不该进入循环的物质，以及进入市场的化学品是否经过危害评估。本章讨论这些问题。它给出描述循环性的量，分析**机械回收**及其引发的降解，建立**化学回收**的热力学与化学，讨论**面向报废的设计**，最后落在化学品与产品的法规上——REACH 及其在各法域的对应物，以及截至 2026 年的包装与塑料规则。其背后的聚合物科学在 [[polymer-chemistry]]，尤其 [[polymer-chemistry/functional-polymers]]，那里从聚合物一侧讲解可降解聚合物与回收化学；这里采取系统视角。

## 度量循环性

欧盟《废弃物框架指令》（2008/98/EC）确立了**废弃物层级**：源头减量优先；其次是再使用准备；回收；包括能量回收在内的其他回收；最后是处置。层级是默认次序而非自然法则——对某一特定流股，生命周期评估可以证明偏离它是正当的——但它抓住了这一直觉：材料被转化的次数越少，损失的能量和物料就越少。

::: definition 收集率、工艺产率与再生材料含量 {#def-circular}
对处于一个使用周期终点的材料：

- **收集率** $r$ 是被丢弃的材料中为回收而被收集的份额；
- **工艺产率** $\eta$ 是被收集的材料经分选和再加工后、作为可用再生材料出来的份额（其余作为残渣、污染物和加工损失丢掉）；
- **有效回收率** $r\eta$，即被丢弃的材料中真正重返使用的份额；
- 产品的**再生材料含量**是其材料中属再生（而非原生）部分的质量分数。

统计常报告收集率或“送交回收”率，它们高于有效回收率；已发表数值之间的分歧，很大部分源于这一区别。
:::

::: proposition 每单位原生材料的可使用次数 {#prop-cycles}
设每个使用周期把材料份额 $r\eta$ 交给下一个周期，而需求不变。则一单位原生材料平均提供
$$
N = \sum_{k=0}^{\infty}(r\eta)^k = \frac{1}{1 - r\eta}
$$ {#eq-cycles}
单位的使用；稳态下每个周期必须以原生材料补足的材料份额为 $1 - r\eta$。若需求每周期按 $1 + g$ 增长，再生材料含量不能超过 $r\eta/(1 + g)$。
:::

::: proof
一单位原生材料被使用一次；其份额 $r\eta$ 被第二次使用，$(r\eta)^2$ 第三次使用，依此类推。总使用量是公比 $r\eta < 1$ 的几何级数，和为 $1/(1 - r\eta)$。在每周期需求为 $D$ 的稳态下，可用的再生材料为 $r\eta D$（来自上一周期的 $D$），故原生投入为 $D(1 - r\eta)$。若第 $k$ 周期的需求为 $D_k = D_0(1 + g)^k$，进入周期 $k + 1$ 的再生材料为 $r\eta D_k$，即其需求的份额 $r\eta D_k/D_{k+1} = r\eta/(1 + g)$。这一简单模型假定材料质量不限制再使用、且产品寿命恰为一个周期。对长寿命产品（建筑、车辆），生产与报废之间的滞后意味着：即使今天的废物被完美回收，也只能满足几十年前更小的需求。
:::

::: example 回收能把一千克拉伸多远？ {#ex-cycles}
某种聚合物包装的收集率为 $50\,\%$，分选与再加工可回收收集质量的 $80\,\%$。(a) 一千克原生聚合物提供多少次使用？(b) 稳态下每年的包装必须有多大份额是原生的？(c) 若需求每周期增长 $4\,\%$，再生材料含量最大是多少？
::: solution
(a) $r\eta = 0.40$，故 $N = 1/(1 - 0.40) = 1.67$ 次使用。

(b) 原生份额为 $1 - 0.40 = 0.60$：每个周期的聚合物有 $60\,\%$ 是新的。

(c) $r\eta/(1 + g) = 0.40/1.04 = 0.385$：再生材料含量至多 $38.5\,\%$。

因此，即便一套为多数国家自认良好的回收系统，所替代的原生生产也不到一半。提高 $\eta$ 与提高 $r$ 同等重要，而两者都需要设计：能可靠分选的包装，不含不相容的层或添加剂，不被内装物污染。
:::
:::

## 机械回收

**机械回收**保持聚合物链完整：废物被收集、分选（近红外光谱、密度、颜色，金属用涡电流）、破碎、清洗、熔融、重新挤出造粒。它在所有回收路线中耗能最低——远低于生产原生聚合物——并且对 PET 瓶和商品包装的聚乙烯膜这类干净单一聚合物流效果良好。三个化学问题限制了它。

**降解。** 在 $200$–$300\,^\circ\mathrm{C}$ 熔体加工中，痕量氧、水和催化剂残物的存在会断裂链。聚烯烃发生自由基氧化与断链（聚丙烯）或交联（聚乙烯）。PET 这类聚酯被残余水水解，所以挤出前必须严格干燥，有时还在略低于熔点的温度下用**固相缩聚**重新提升摩尔质量。聚合物的力学性能——拉伸强度、韧性、熔体黏度——依赖摩尔质量（[[polymer-chemistry/polymer-properties]]），于是反复再加工会逐渐损害性能。

::: proposition 无规断链后的摩尔质量 {#prop-scission}
初始数均摩尔质量为 $M_{\mathrm{n},0}$ 的聚合物，每个加工周期每克平均发生 $z$ 摩尔无规断链，且别无他事（无交联、无复合），则经 $k$ 个周期后
$$
\frac{1}{M_{\mathrm{n},k}} = \frac{1}{M_{\mathrm{n},0}} + kz .
$$ {#eq-scission}
:::

::: proof
数均摩尔质量是质量除以链数：对 1 克而言 $M_\mathrm{n} = 1/N$，$N$ 为每克链的摩尔数。主链每断一根键，一条链变两条，$N$ 增一，质量不变。初始 $N_0 = 1/M_{\mathrm{n},0}$；经每克断链 $z$ 的 $k$ 个周期后，$N_k = N_0 + kz$，即[[#eq-scission]]。重均摩尔质量对熔体黏度主宰更强，初始分布越窄它下降越快，且分布趋向最可几分布（[[polymer-chemistry/polymer-structure]]）。若有交联（如聚乙烯），$1/M_\mathrm{n}$ 反而下降，并生成凝胶。
:::

:::

**混合物。** 多数聚合物两两不相容，因为它们的混合熵小得可怜（$1000$ 个链段的链，$\chi_\mathrm{c} \approx 0.002$，[[polymer-chemistry/polymer-solutions]]），所以聚乙烯与聚丙烯、或聚乙烯与 PET 的共混物形成粗大、脆弱的相分离结构。把多种聚合物（常常还有铝箔）复合以获得阻隔性能的多层包装膜，因此尤其难以机械回收。**增容剂**——位于界面的嵌段或接枝共聚物——可以挽回一部分性能。

**添加剂与遗留物质。** 聚合物含有增塑剂、稳定剂、阻燃剂、颜料和填料，其中一些具有危害。聚合物被回收时，添加剂随其同行。旧电子设备产生的塑料可能含多溴二苯醚这类溴化阻燃剂——它们现已被列入斯德哥尔摩公约——而欧盟关于持久性有机污染物的法规规定：此类废物中超过限值者必须销毁而不得回收。回收绝不能变成扩散已被市场淘汰之物质的通道——化学品法规与废物法规必须一并设计，这是原因之一。

::: example 回收还是焚烧？ {#ex-lca-pe}
一千克聚乙烯废物要么焚烧并回收能量，要么机械回收。使用示意性数据：焚烧把碳以 $\mathrm{CO_2}$ 释放，所发电力替代价值 $1.0\ \mathrm{kg\,CO_2}$ 的电网电力；回收产生 $0.5\ \mathrm{kg\,CO_2e}$（收集、分选、清洗、挤出），其产品按替代比 $0.8$（因质量下降）替代从摇篮到大门足迹为 $1.8\ \mathrm{kg\,CO_2e\,kg^{-1}}$ 的原生聚乙烯。用系统扩展比较两者的净气候影响。
::: solution
聚乙烯是 $(\mathrm{CH_2})_n$。燃烧一千克释放 $44.01/14.03 = 3.14\ \mathrm{kg\,CO_2}$。**焚烧：** $3.14 - 1.0 = +2.14\ \mathrm{kg\,CO_2e}$。**回收：** $0.5 - 0.8\times1.8 = -0.94\ \mathrm{kg\,CO_2e}$（净节省）。两者相差约 $3.1\ \mathrm{kg\,CO_2e}$ 每千克，其中大头来自不燃烧化石碳。结论符合废弃物层级，但其大小取决于假设，正如 [[green-chemistry/green-metrics#alg-lca]] 所告诫的：电网变清洁会降低焚烧的发电抵扣（使回收显得更好），而替代比过低、或肮脏混杂的流股长途运输，都能让回收对那一股流而言成为更差的选择。用生命周期评估的语言说，这就是**系统扩展**：给每个选项记上它所替代的产品的账。
:::
:::

## 化学回收

**化学回收**（原料回收）把聚合物拆解为单体、低聚物或其他化学品，纯化后重建为新的聚合物或其他产品。由于纯化发生在分子水平，原则上它能除去污染物和添加剂、恢复原生品质，代价是更多的能量和更复杂的装置。哪条路线可行取决于聚合物的化学。

### 解聚与上限温度

乙烯基单体的加成聚合放热且熵为负（自由的单体成为受约束的重复单元），所以和一切此类反应一样，高温下变得可逆。

::: proposition 上限温度 {#prop-ceiling}
对增长平衡 $\mathrm{M}_n^{*} + \mathrm{M} \rightleftharpoons \mathrm{M}_{n+1}^{*}$，$\Delta_\mathrm{p}H < 0$、$\Delta_\mathrm{p}S < 0$（按每摩尔单体计，参考标准单体浓度 $[\mathrm{M}]^\circ = 1\ \mathrm{mol\,dm^{-3}}$），温度 $T$ 下的平衡单体浓度为
$$
\frac{[\mathrm{M}]_\mathrm{eq}}{[\mathrm{M}]^\circ} = \exp\!\left(\frac{\Delta_\mathrm{p}H}{RT} - \frac{\Delta_\mathrm{p}S}{R}\right),
$$ {#eq-ceiling}
而在**上限温度** $T_\mathrm{c} = \Delta_\mathrm{p}H/\Delta_\mathrm{p}S$ 以上，由浓度为 $[\mathrm{M}]^\circ$ 的单体进行聚合在热力学上不可能。高于 $T_\mathrm{c}$ 时，具有活性链端的聚合物会“解扣”（拉链式解聚）回单体。
:::

::: proof
对长链，加成一个单体的平衡常数与链长无关，$K = [\mathrm{M}_{n+1}^{*}]/([\mathrm{M}_n^{*}][\mathrm{M}]) \approx 1/[\mathrm{M}]_\mathrm{eq}$（以 $[\mathrm{M}]^\circ$ 为单位），因为两种链的浓度相等。由 $K = \exp(-\Delta_\mathrm{p}G^\circ/RT) = \exp(-\Delta_\mathrm{p}H/RT + \Delta_\mathrm{p}S/R)$ 取倒数即得[[#eq-ceiling]]。浓度为 $[\mathrm{M}]^\circ$ 的单体要能聚合，须 $[\mathrm{M}]^\circ > [\mathrm{M}]_\mathrm{eq}$，即 $\Delta_\mathrm{p}H/RT - \Delta_\mathrm{p}S/R < 0$；因 $\Delta_\mathrm{p}H < 0$，这就是 $T < \Delta_\mathrm{p}H/\Delta_\mathrm{p}S = T_\mathrm{c}$。这一推导是 [[thermodynamics/reaction-equilibrium]] 的自由能论证用于一个增长步，它对速率未置一词；而且解扣需要活性链端——在多数聚合物中，活性链端须先由断键产生。
:::

取奥迪安（Odian）《Principles of Polymerization》的近似值（$\Delta_\mathrm{p}H$ 以 $\mathrm{kJ\,mol^{-1}}$、$\Delta_\mathrm{p}S$ 以 $\mathrm{J\,K^{-1}\,mol^{-1}}$ 计）：甲基丙烯酸甲酯 $-56$、$-117$，$T_\mathrm{c} \approx 479\ \mathrm{K}$；α-甲基苯乙烯 $-35$、$-110$，$T_\mathrm{c} \approx 318\ \mathrm{K}$；苯乙烯 $-73$、$-104$，$T_\mathrm{c} \approx 700\ \mathrm{K}$；乙烯 $-93$、$-155$，$T_\mathrm{c} \approx 600\ \mathrm{K}$。因此聚甲基丙烯酸甲酯（PMMA）是干净解聚的经典之例：加热到 $400$–$500\,^\circ\mathrm{C}$，它以高解扣回单体，PMMA 以此法回收已有数十年。聚苯乙烯给出苯乙烯与二聚体、三聚体的混合物。聚乙烯与聚丙烯的自由基发生氢转移并经历 β-断裂，不能干净解扣，得到烷烃与烯烃的宽分布混合物——这就是热解的基础。

::: example 聚苯乙烯能“解扣”吗？ {#ex-ceiling}
用苯乙烯的 $\Delta_\mathrm{p}H = -73\ \mathrm{kJ\,mol^{-1}}$、$\Delta_\mathrm{p}S = -104\ \mathrm{J\,K^{-1}\,mol^{-1}}$，求上限温度以及 $400$、$500$、$600\,^\circ\mathrm{C}$ 下的平衡单体浓度。纯液态苯乙烯约为 $8.7\ \mathrm{mol\,dm^{-3}}$。与甲基丙烯酸甲酯比较。
::: solution
$T_\mathrm{c} = 73\,000/104 = 702\ \mathrm{K}$（$429\,^\circ\mathrm{C}$）。由[[#eq-ceiling]]，$[\mathrm{M}]_\mathrm{eq} = \exp(-73\,000/RT + 104/8.314) = \exp(-73\,000/RT + 12.509)$：

| $T$ | $-\Delta_\mathrm{p}H/RT$ | $[\mathrm{M}]_\mathrm{eq}/\mathrm{mol\,dm^{-3}}$ |
|---|---|---|
| $673\ \mathrm{K}$ | $13.04$ | $0.59$ |
| $773\ \mathrm{K}$ | $11.36$ | $3.2$ |
| $873\ \mathrm{K}$ | $10.06$ | $11.6$ |

热力学上，聚苯乙烯只有在大致 $600\,^\circ\mathrm{C}$ 以上、$[\mathrm{M}]_\mathrm{eq}$ 超过纯单体浓度时才能大量解聚；实践中让单体以蒸气移出有帮助，但在这个温度区间副反应（氢转移，生成二聚体、三聚体、甲苯和乙苯）与之竞争，热解的苯乙烯产率典型为 $50$–$70\,\%$。对甲基丙烯酸甲酯，$T_\mathrm{c} = 56\,000/117 = 479\ \mathrm{K}$，而在 $400\,^\circ\mathrm{C}$ 时 $[\mathrm{M}]_\mathrm{eq} = 58\ \mathrm{mol\,dm^{-3}}$：在副反应仍然缓慢的温度下，解扣在热力学上具有压倒优势，而 α-甲基阻碍了沿链的氢抽取，使解聚保持干净。这一比较说明了为什么解聚对 PMMA 是实用的回收路线，对聚苯乙烯难得多，对聚烯烃则行不通。
:::
:::

### 缩聚物：溶剂解与酶

逐步聚合物（[[polymer-chemistry/step-growth]]）含有可被小分子切断的键——酯、酰胺、碳酸酯、氨酯——从而逆转缩聚。PET 的主要路线是用乙二醇的**乙二醇解**生成对苯二甲酸双(2-羟乙基)酯（BHET）、**甲醇解**生成对苯二甲酸二甲酯（DMT）与乙二醇，以及**水解**生成对苯二甲酸。尼龙-6 解聚为己内酰胺，聚氨酯经乙二醇解为多元醇。

::: example PET 的甲醇解 {#ex-methanolysis}
写出 PET（重复单元 $\mathrm{C_{10}H_8O_4}$，$192.17\ \mathrm{g\,mol^{-1}}$）甲醇解为 DMT（$\mathrm{C_{10}H_{10}O_4}$，$194.18$）与乙二醇（$\mathrm{C_2H_6O_2}$，$62.07$）的方程，并求每吨 PET 消耗的甲醇和生成的产物的质量。原子经济性是多少？
::: solution
每个重复单元 $\mathrm{-[OC{-}C_6H_4{-}CO{-}O{-}CH_2CH_2{-}O]-}$ 含两个酯键；两个甲醇把它们切断：
$$
\mathrm{(C_{10}H_8O_4)_n} + 2n\,\mathrm{CH_3OH} \rightarrow n\,\mathrm{C_{10}H_{10}O_4} + n\,\mathrm{HOCH_2CH_2OH}.
$$
每重复单元的质量衡算：$192.17 + 2\times32.04 = 256.25$；$194.18 + 62.07 = 256.25$。每吨 PET：甲醇 $64.08/192.17 = 0.333\ \mathrm{t}$；DMT $194.18/192.17 = 1.010\ \mathrm{t}$；乙二醇 $62.07/192.17 = 0.323\ \mathrm{t}$。两种产物都是新 PET 的单体（DMT 与乙二醇酯交换，重新生成甲醇），所以对有用产品的原子经济性为 $100\,\%$，且甲醇是循环试剂。实践中，目标原料是有色、受污染的 PET 和聚酯纤维——干净的瓶级 PET 机械回收更便宜——染料、其他聚合物与添加剂必须靠蒸馏和结晶从单体中除去，能量就花在这里。
:::
:::

**酶法解聚**用酯水解酶——角质酶与 PET 水解酶——在水中水解 PET。2016 年吉田（Yoshida）等报道了能降解 PET 的细菌 *Ideonella sakaiensis*；2020 年图尔尼耶（Tournier）等（与公司 Carbios 合作）报道了一种工程化的落叶堆肥角质酶，在约 $72\,^\circ\mathrm{C}$ 下 $10$ 小时内把经预处理、变为非晶的 PET 的 $90\,\%$ 解聚为对苯二甲酸和乙二醇。该过程要求 PET 为非晶（结晶区被进攻得很慢，反应温度定在略低于 PET 玻璃化转变处），生成的对苯二甲酸必须中和并回收，但它在温和温度下工作，且能容忍混合原料。其酶学见 [[green-chemistry/renewable-feedstocks]]。

### 热解、气化与溶解

对没有可断裂官能团的聚烯烃，约 $400$–$600\,^\circ\mathrm{C}$、隔氧条件下的**热解**把链打碎为烃类油、蜡和气体；催化剂（沸石）可以收窄产物范围。除去氯（来自 PVC 污染）、含氮与含氧化合物后，这种油可以送入蒸汽裂解装置（[[green-chemistry/petrochemicals]]）制新烯烃。由于油与化石石脑油掺混，所得聚合物的再生材料含量按**质量平衡核算**认定：ISCC PLUS 这类认证体系追踪再生投入并将其分摊到指定产出——这一方法虽已标准化却有争议，因为它允许把产品在物理上可能并不含再生料的情况下作为含再生料产品销售。废塑料到新单体的总碳产率不高，因为油的大部分成为燃料范围的副产品和气体。**气化**把混合废物转化为合成气，可据此制甲醇和其他化学品；它几乎来者不拒，但把聚合物的结构全部丢掉。**溶解法**（又称物理回收或溶剂回收）选择性地溶解聚合物，过滤和萃取除去污染物与添加剂，再把纯化的聚合物沉淀出来；它像机械回收一样保持链完整，同时把纯化做得更彻底。

::: warning 回收并不自动优于其替代方案 {#warn-recycling}
两个方向的错误都很常见。一是把任何回收过程都视为有益：一座把大部分原料转化为燃料的化学回收厂，或一条把受污染废物长途运往他处填埋的机械回收线，其足迹可能大于带能量回收的焚烧。在欧盟法律下，转化为燃料不算回收。二是因回收不完美而否定回收：[[#prop-cycles]] 表明有效回收率每提高一分，就多替代一分原生材料，而多数生命周期评估发现，运转良好的干净流股回收既省能量也减排放。判断每条路线，应在载明的功能单位下与它所替代的对象作生命周期比较，并计入它所生产产品的质量。
:::

## 面向报废的设计

产品若为回收而设计，回收就最容易。由上面的化学可引出这些原则：

- **单一材质设计：** 由单一聚合物族制成的包装（例如全聚乙烯层压膜代替 PET/PE/铝箔）可以作为一个物流分选和再加工。
- **避免问题物质：** 不用具有危害或干扰回收的添加剂（炭黑妨碍近红外分选；PVC 标签污染 PET）；颜料与稳定剂要选用与回收路线相容的。
- **面向拆解的设计：** 可逆的紧固件和按需释放的胶黏剂，使电子产品和车辆能拆分为可回收的料流——这对回收钴、锂和稀土等关键金属必不可少。
- **动态与可解聚材料：** 设计成能在温和条件下解聚回单体的聚合物，如上限温度较低或含可断裂连接基的聚合物，以及虽交联仍可再加工的类玻璃高分子（vitrimer）（[[polymer-chemistry/functional-polymers]]）。
- **面向降解的设计（原则 10）：** 在无法收集的场合——农用地膜、渔具、随废水排放的产品如洗涤剂和药品——材料应在其实际遭遇的条件下生物降解为无害产物。工业堆肥设施中的生物降解（EN 13432）与土壤、淡水或海水中并不是一回事；而碎裂为微塑料的氧化降解塑料，已被欧盟《一次性塑料指令》（2019/904）限制。

金属显示了循环性多么有价值。再生铝所需能量约为原生冶炼的 $5\,\%$（[[electrochemistry/fuel-cells-electrolysis]]）；钢、铜和铅的回收率很高，因为其价值足以偿付收集成本，且可精炼到原生质量。难点在合金与混合物：一辆汽车含有多种铝合金，若混在一起熔炼，合金元素就会累积，所以按合金分选——例如用激光诱导击穿光谱（[[analytical-chemistry/atomic-spectrometry]]）——是回收链条的一环。

::: quiz
一只食品托盘由三层膜制成：PET、乙烯–乙烯醇（EVOH）阻氧层和聚乙烯，用胶黏剂复合。哪种再设计最能改善其机械可回收性？
- [ ] 把 PET 层改用生物基乙二醇制造
- [ ] 添加促氧化剂，使托盘在环境中碎裂
- [x] 换成以聚乙烯为基础的结构，其中阻隔层是一薄层与聚乙烯回收相容的材料
- [ ] 把托盘印成黑色，以遮盖污染
::: solution
可回收性取决于产品含有多少种互不相容的聚合物。单一材质的聚乙烯结构（阻隔层控制在百分之几以内，聚乙烯回收流能够容忍）可以作为同一种材料分选和再加工。生物基来源一点也改变不了可回收性；促氧化剂制造微塑料，在欧盟受限；而以炭黑为基的黑色颜料吸收近红外光，会使自动分选失效。
:::
:::

## 化学品与产品的法规

循环性要求产品中的物质已知且安全，因为进入产品之物会随其废物出来。化学品的监管自 1970 年代以来，从管制少数劣名昭著的物质，转向要求市场上一切物质的数据。

::: definition REACH {#def-reach}
**REACH**——《关于化学品注册、评估、授权与限制的法规》（Regulation (EC) No 1907/2006），自 2007 年 6 月 1 日生效——是欧盟的化学品一般法，由欧洲化学品管理局（ECHA）主管。其主要内容：

- **注册：** 每年制造或进口某物质 $1\ \mathrm{t}$ 以上的制造商与进口商必须提交注册档案，信息要求随吨位档递增（$1$–$10$、$10$–$100$、$100$–$1000$、$\geq 1000\ \mathrm{t\,a^{-1}}$）；$10\ \mathrm{t\,a^{-1}}$ 以上需要带暴露情景与风险表征比（[[green-chemistry/green-principles#prop-rcr]]）的化学品安全报告。“无数据，无市场”：未注册的物质不得制造或投放市场。现有物质的分阶段注册截止已于 2018 年结束。
- **评估：** ECHA 与成员国核查档案的合规性，并评估受关注物质。
- **授权：** **极高关注物质**（SVHC）——致癌、致突变或具有生殖毒性（CMR），持久、生物累积且有毒（PBT），很高持久性且很高生物累积性（vPvB），或具有同等关注度的物质如内分泌干扰物——被列入**候选清单**；转入**附件十四**的物质，仅可在获得针对特定用途的授权后使用，授权的条件是风险得到充分控制，或效益超过风险且不存在合适的替代品。
- **限制：** **附件十七**对构成不可接受风险的物质，不论吨位，限制其制造、投放市场或使用。

危害分类与标签由配套的 CLP 法规（(EC) No 1272/2008）管辖。
:::

REACH 把举证责任转给了工业界，要求为数万种物质提供数据，并旨在驱动**替代**：一旦列入附件十四，继续使用一种物质就既昂贵又充满不确定性，从而推动寻找替代品。截至 2025 年，候选清单约有 $250$ 项（ECHA）。含候选清单物质质量分数超过 $0.1\,\%$ 的物品必须通报；自 2021 年起这些信息录入 ECHA 的 SCIP 数据库，使回收商能够知道自己接收的产品含有什么。

其他法域有相应的法律：美国 **《有毒物质控制法》**（1976 年）经 2016 年《劳滕伯格 21 世纪化学品安全法》大幅加强，要求 EPA 按基于风险的安全标准评估现有化学品（[[green-chemistry/safer-solvents]] 提到的 2024 年二氯甲烷规则即是一例）；加拿大、日本、韩国和中国也各有化学品法。全球性条约针对特定类别：**斯德哥尔摩公约**针对持久性有机污染物（2001），**水俣公约**针对汞（2013），**蒙特利尔议定书**针对消耗臭氧层物质（1987）。五个国家于 2023 年 1 月向 ECHA 提出的、对全氟和多氟烷基物质（PFAS）的欧盟范围广泛限制提案，2025 年仍在 ECHA 各委员会的科学评估之中。

**产品与废物规则**直接设定循环的条件。在欧盟，《一次性塑料指令》（2019/904）要求 PET 饮料瓶自 2025 年起至少含 $25\,\%$ 再生塑料、所有塑料饮料瓶自 2030 年起含 $30\,\%$，并规定单独收集率在 2025 年前达 $77\,\%$、2029 年前达 $90\,\%$。**《包装与包装废弃物法规》**（Regulation (EU) 2025/40）于 2025 年 1 月公布、自 2026 年 8 月起适用，要求按面向回收的设计标准在 2030 年前使所有包装可回收，并自 2030 年起规定塑料包装的最低再生材料含量（例如接触敏感 PET 包装为 $30\,\%$）。在国际层面，联合国环境大会 2022 年决议谈判一份关于塑料污染的法律约束文书；谈判委员会第五届会议（釜山，2024）及其续会（日内瓦，2025 年 8 月）均未谈成文本。这些政策存在争议——强调生产限额者、强调废物管理者、以及关切成本、贸易与可行性者——而其效果将取决于执行。

::: history 从废物管理到循环经济 {#hist-circular}
金属与纸张的回收古已有之；家庭可回收物的有组织收集随填埋场的紧缺在 1970 与 1980 年代普及。施塔尔（Walter Stahel）与雷代（Geneviève Reday）向欧盟委员会提交的报告 *The Potential for Substituting Manpower for Energy*（1976 年完成、1981 年出版）描述了“闭环”经济；麦克唐纳（William McDonough）与布劳恩加特（Michael Braungart）的《从摇篮到摇篮》（*Cradle to Cradle*，2002）使面向技术循环与生物循环的设计广为人知。艾伦·麦克阿瑟基金会成立于 2010 年，出版了 *Towards the Circular Economy*（2013）与 *The New Plastics Economy*（2016）——后者估计全球仅 $14\,\%$ 的塑料包装被收集回收、$32\,\%$ 泄漏到环境中。欧盟《废弃物框架指令》（2008）把废弃物层级写入法典，REACH 于 2007 年生效，欧盟又在 2015 与 2020 年通过循环经济行动方案。在聚合物科学方面，PMMA 聚合的可逆性在 1940 年代业已知晓，戴顿（Dainton）与欧文（Ivin）1948 年给出了上限温度的热力学解释，降解 PET 的细菌 *Ideonella sakaiensis* 于 2016 年被报道。
:::

## 后续内容

本章回到 [[green-chemistry/green-principles]] 的原则 1——预防——为课程收束。[[green-chemistry/green-metrics]] 的各种指标——质量、生命周期、分摊——恰是判断回收路线所需要的工具；[[green-chemistry/petrochemicals]] 的石化链是再生油重新进入之处；[[green-chemistry/renewable-feedstocks]] 与 [[green-chemistry/carbon-hydrogen]] 的可再生及 $\mathrm{CO_2}$ 基原料是非化石碳的另外两个来源。逸出一切循环的物质之归宿，是 [[environmental-chemistry/pollutants-fate]] 的主题；降解与解聚的聚合物化学在 [[polymer-chemistry/functional-polymers]] 中展开。

::: summary
- 2019 年，全球 $353\ \mathrm{Mt}$ 塑料废物中 $9\,\%$ 被回收，$19\,\%$ 被焚烧，约一半进填埋，$22\,\%$ 管理不善（OECD，2022）。废弃物层级依次为减量、再使用、回收、其他回收、处置。
- 收集率 $r$、工艺产率 $\eta$ 时，一单位原生材料给出 $1/(1 - r\eta)$ 次使用；稳态原生份额为 $1 - r\eta$，需求增长时再生材料含量以 $r\eta/(1 + g)$ 为上限。
- 机械回收保住链却损害链：无规断链给出 $1/M_{\mathrm{n},k} = 1/M_{\mathrm{n},0} + kz$；不相容混合物与添加剂（包括遗留的持久性有机污染物）限制质量。
- 化学回收：越过上限温度 $T_\mathrm{c} = \Delta_\mathrm{p}H/\Delta_\mathrm{p}S$ 的解聚（PMMA 约 $480\ \mathrm{K}$）；缩聚物的溶剂解（PET 甲醇解对单体原子经济性 $100\,\%$）与酶法水解；聚烯烃的热解与气化，辅以质量平衡核算。
- 回收路线按与所替代对象的生命周期比较来判断；面向报废的设计（单一材质、良性添加剂、可拆解，以及无法收集处的可降解性）使其得以成立。
- REACH（2007）要求 $\geq 1\ \mathrm{t\,a^{-1}}$ 物质注册、对 SVHC 授权并实施限制；截至 2026 年，TSCA（2016 年修订）、斯德哥尔摩、水俣与蒙特利尔公约、欧盟《一次性塑料指令》与《包装与包装废弃物法规》（2025/40）共同塑造着什么能被制造与回收。
:::

## 练习

::: exercise 原生份额 {level=1 check="77.5"}
某材料为回收的收集率为 $30\,\%$，收集量中 $75\,\%$ 可作为可用再生材料回收。稳态下，每个周期的材料必须有多大百分比是原生的？（以百分比计。）
::: solution
$1 - r\eta = 1 - 0.30\times0.75 = 0.775$，即 $77.5\,\%$。
:::
:::

::: exercise 燃烧 PET {level=1 check="2.29"}
一千克 PET（重复单元 $\mathrm{C_{10}H_8O_4}$，$192.17\ \mathrm{g\,mol^{-1}}$）完全燃烧释放多少 $\mathrm{CO_2}$？（质量以 kg 计。）
::: solution
每个重复单元十个碳：$10\times44.01/192.17 = 2.29\ \mathrm{kg}$。聚乙烯释放更多，$3.14\ \mathrm{kg\,kg^{-1}}$，因为它不含氧。
:::
:::

::: exercise α-甲基苯乙烯的上限温度 {level=1 check="318"}
用 $\Delta_\mathrm{p}H = -35\ \mathrm{kJ\,mol^{-1}}$、$\Delta_\mathrm{p}S = -110\ \mathrm{J\,K^{-1}\,mol^{-1}}$，求 α-甲基苯乙烯的上限温度。（$T_\mathrm{c}$ 以 K 计，保留三位有效数字。）
::: solution
$T_\mathrm{c} = \Delta_\mathrm{p}H/\Delta_\mathrm{p}S = 35\,000/110 = 318\ \mathrm{K}$（$45\,^\circ\mathrm{C}$）。聚（α-甲基苯乙烯）因此须在低温下以离子聚合制备，且受热即易解聚。
:::
:::

::: exercise 五次再加工 {level=2 check="26.7"}
某聚丙烯牌号 $M_\mathrm{n} = 80\ \mathrm{kg\,mol^{-1}}$，每次挤出循环每克发生 $5.0\times10^{-6}\ \mathrm{mol}$ 断链。求五个周期后的 $M_\mathrm{n}$。（以 $\mathrm{kg\,mol^{-1}}$ 计，保留三位有效数字。）
::: solution
$1/M_{\mathrm{n},5} = 1/80\,000 + 5\times5.0\times10^{-6} = 1.25\times10^{-5} + 2.5\times10^{-5} = 3.75\times10^{-5}\ \mathrm{mol\,g^{-1}}$，故 $M_{\mathrm{n},5} = 26\,700\ \mathrm{g\,mol^{-1}} = 26.7\ \mathrm{kg\,mol^{-1}}$。每条原始链平均被切了两刀（$5\times5.0\times10^{-6}\times80\,000 = 2.0$）。
:::
:::

::: exercise PET 的水解 {level=2 check="0.864"}
PET 可水解为对苯二甲酸（苯-1,4-二羧酸，$166.13\ \mathrm{g\,mol^{-1}}$）和乙二醇。按重复单元写出方程，并求每吨 PET 所得对苯二甲酸的质量。（质量以吨计，保留三位有效数字。）
::: solution
$\mathrm{C_{10}H_8O_4} + 2\,\mathrm{H_2O} \rightarrow \mathrm{C_8H_6O_4} + \mathrm{C_2H_6O_2}$；校核：$192.17 + 36.03 = 228.20 = 166.13 + 62.07$。对苯二甲酸：每吨 PET 得 $166.13/192.17 = 0.864\ \mathrm{t}$，同时得乙二醇 $0.323\ \mathrm{t}$。
:::
:::

::: exercise 高绩效系统 {level=2 check="6.90"}
押金返还制度收集了 $90\,\%$ 的瓶子，再加工回收其质量的 $95\,\%$。若质量得以保持，每千克原生聚合物提供多少次使用？（输入 $N$，保留三位有效数字。）
::: solution
$r\eta = 0.855$，故 $N = 1/(1 - 0.855) = 1/0.145 = 6.90$ 次使用。稳态下的原生份额为 $14.5\,\%$。
:::
:::

::: exercise 需求增长下的再生材料含量 {level=3 check="49.0"}
对需求每周期按 $1 + g$ 增长的情形，推导再生材料含量的上界 $r\eta/(1 + g)$，并对 $r = 0.60$、$\eta = 0.85$、$g = 0.04$ 求值。若在同一样产率与增速下达到 $65\,\%$ 的再生材料含量目标，需要多大的收集率？（再生材料含量以百分比计，保留三位有效数字。）
::: hint
在周期 $k + 1$ 返回的材料来自周期 $k$ 的需求。
:::
::: solution
推导见[[#prop-cycles]]：周期 $k + 1$ 的再生供应为 $r\eta D_k$，需求为 $D_k(1 + g)$，故再生材料含量至多 $r\eta/(1 + g)$。数值上 $0.60\times0.85/1.04 = 0.490$，即 $49.0\,\%$。要达 $65\,\%$：$r = 0.65\times1.04/0.85 = 0.795$——将近 $80\,\%$ 的收集率，且尚未计入不能满足食品接触或性能要求的材料。需求增长是与回收绩效同等重要的变量。

::: exercise PMMA 的解扣 {level=3 check="58.4"}
用甲基丙烯酸甲酯的 $\Delta_\mathrm{p}H = -56\ \mathrm{kJ\,mol^{-1}}$、$\Delta_\mathrm{p}S = -117\ \mathrm{J\,K^{-1}\,mol^{-1}}$，计算 $25\,^\circ\mathrm{C}$ 和 $400\,^\circ\mathrm{C}$ 下的平衡单体浓度（相对 $1\ \mathrm{mol\,dm^{-3}}$）。纯液态 MMA 约为 $9.4\ \mathrm{mol\,dm^{-3}}$；解释结果对聚合与回收的意义。（$400\,^\circ\mathrm{C}$ 的 $[\mathrm{M}]_\mathrm{eq}$ 以 $\mathrm{mol\,dm^{-3}}$ 计，保留三位有效数字。）
::: solution
由[[#eq-ceiling]]，在 $298.15\ \mathrm{K}$：$\exp(-56\,000/(8.314\times298.15) + 117/8.314) = \exp(-22.59 + 14.07) = \exp(-8.52) = 2.0\times10^{-4}\ \mathrm{mol\,dm^{-3}}$——室温下的聚合基本进行到底。在 $673.15\ \mathrm{K}$：$\exp(-10.006 + 14.073) = \exp(4.066) = 58.4\ \mathrm{mol\,dm^{-3}}$，远高于纯单体浓度；没有任何聚合物能与自身单体处于平衡，所以带活性链端的 PMMA 完全解扣，单体一生成便蒸馏出去。这就是 PMMA 废料能以 $90\,\%$ 以上产率解聚回收 MMA 的原因，也是对聚乙烯（$T_\mathrm{c}$ 约 $600\ \mathrm{K}$，但没有干净的解扣机理）作同样处理只会得到烃类混合物的原因。$\Delta_\mathrm{p}H$ 与 $\Delta_\mathrm{p}S$ 对应特定的标准态且为近似值，故算得的浓度只宜作为估计。
:::
