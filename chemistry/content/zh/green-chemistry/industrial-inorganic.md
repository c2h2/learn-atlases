你体内约有一半的氮原子曾从一座氨厂经过。由哈伯-博施法生产的氨制成的合成氮肥，养活着全世界约一半的人口，而这一工艺消耗了全球终端能源的约 $2\,\%$。接触法生产的硫酸是所有化学品中产量最大的，用于制造磷肥、浸取金属矿石并用于无数其他工艺。奥斯特瓦尔德法生产的硝酸进入硝酸铵化肥以及聚氨酯与尼龙链。电解食盐水得到的氯和氢氧化钠，加上索尔维法得到的碳酸钠，凑齐了重无机化学品这一组，工业其余部分的大厦就搭建在其上。

这些工艺都有一个世纪以上的历史，值得学习的原因有二。第一，它们最清楚地展示了化学热力学与动力学如何决定工业实践。氨合成与二氧化硫氧化是**可逆放热**反应：低温有利于平衡，高温有利于速率，而实际采用的条件——以及反应器的设计——是能够从 [[thermodynamics/reaction-equilibrium]] 定量化理解的折衷。第二，化学工业的环境负担有相当大一部分正位于这里：仅氨一项在 2022 年就占一次化学品生产直接 $\mathrm{CO_2}$ 排放的约 $45\,\%$（IEA，截至 2026 年的最新有日期数值），硝酸厂排放强温室气体氧化亚氮，磷矿加工则堆起一座座石膏山。本章逐个算这五个工艺，连同作为其基础的处理与能量衡算。转化率、循环与吹扫排放的语言见 [[green-chemistry/chemical-industry]]。叙述止于工业化学教科书水平；氨、氯、这些酸与烧碱都有害（有毒、有腐蚀性或具氧化性），工业装置在严格的过程安全制度下处置它们。

## 可逆放热反应

本章有两个工艺立于同一个热力学两难之上，所以先作一般性处理。考虑一个气相反应，$\Delta_\mathrm{r}H < 0$ 且 $\Delta_\mathrm{r}S < 0$（产物侧气体摩尔数较少）。由范特霍夫方程，平衡常数随温度升高而下降，可达到的最高转化率随之下降；由勒夏特列原理，压力升高使其增大。但正反应速率随温度急剧上升。温度低，平衡有利而反应不发生；温度高，反应快却早早停止。

::: proposition 氨合成中的平衡 {#prop-nh3-eq}
对 $\tfrac{1}{2}\mathrm{N_2(g)} + \tfrac{3}{2}\mathrm{H_2(g)} \rightleftharpoons \mathrm{NH_3(g)}$，化学计量比进料（$\mathrm{N_2:H_2} = 1:3$，无惰性组分），并把气体当作理想气体，则总压 $p$ 下氨的平衡摩尔分数 $y$ 满足
$$
\frac{y}{(1 - y)^2} = a \equiv \frac{3^{3/2}}{16}\,K\,\frac{p}{p^\circ}, \qquad y = \frac{2a + 1 - \sqrt{4a + 1}}{2a},
$$ {#eq-nh3-eq}
其中 $K = \exp(-\Delta_\mathrm{r}G^\circ/RT)$ 对应如上所写的反应，$3^{3/2}/16 = 0.3248$。在固定 $T$ 下，$y$ 随 $p$ 增大；在固定 $p$ 下，$y$ 随 $T$ 减小，因为 $\mathrm{d}\ln K/\mathrm{d}T = \Delta_\mathrm{r}H^\circ/RT^2 < 0$。
:::

::: proof
对理想气体，用摩尔分数表示，$K = x_{\mathrm{NH_3}}\,x_{\mathrm{N_2}}^{-1/2}\,x_{\mathrm{H_2}}^{-3/2}\,(p/p^\circ)^{-1}$（$p$ 的指数为 $\Delta\nu = 1 - \tfrac12 - \tfrac32 = -1$）。因为氮和氢按进料比 $1:3$ 消耗，它们始终保持这一比例，所以 $x_{\mathrm{N_2}} = (1 - y)/4$、$x_{\mathrm{H_2}} = 3(1 - y)/4$。于是 $x_{\mathrm{N_2}}^{1/2}x_{\mathrm{H_2}}^{3/2} = (1 - y)^2\,(1/4)^{1/2}(3/4)^{3/2} = (1 - y)^2\,3^{3/2}/16$，把 $K$ 重新整理即得[[#eq-nh3-eq]]。二次方程 $a(1 - y)^2 = y$，即 $ay^2 - (2a + 1)y + a = 0$，其根为 $y = [2a + 1 \pm \sqrt{4a + 1}]/2a$；位于 $0$ 与 $1$ 之间的物理根取负号。由于 $\mathrm{d}y/\mathrm{d}a > 0$ 且 $a \propto Kp$，$y$ 随压力上升、随温度下降（范特霍夫方程，[[thermodynamics/reaction-equilibrium]]）。
:::

用 NBS 热化学数据（Wagman 等，1982）——$\Delta_\mathrm{f}H^\circ(\mathrm{NH_3,g}) = -46.11\ \mathrm{kJ\,mol^{-1}}$，以及 $\mathrm{NH_3}$、$\mathrm{N_2}$、$\mathrm{H_2}$ 的标准熵 $192.45$、$191.61$ 和 $130.68\ \mathrm{J\,K^{-1}\,mol^{-1}}$——得 $\Delta_\mathrm{r}H^\circ = -46.11\ \mathrm{kJ\,mol^{-1}}$，每摩尔氨的 $\Delta_\mathrm{r}S^\circ = 192.45 - \tfrac12(191.61) - \tfrac32(130.68) = -99.38\ \mathrm{J\,K^{-1}\,mol^{-1}}$。在 $298\ \mathrm{K}$，$K = 7.7\times10^{2}$，$1\ \mathrm{bar}$ 下的平衡位于氨 $94\,\%$ 处——但反应慢得无法测量。$\mathrm{N_2}$ 的三键（键焓 $945\ \mathrm{kJ\,mol^{-1}}$）必须断裂，这需要催化剂，而即使最好的催化剂也要约 $400\,^\circ\mathrm{C}$ 以上的温度，反应才有可用的速率。

用上面的数据，求 $450\,^\circ\mathrm{C}$ 下的 $K$、$200\ \mathrm{bar}$ 下氨的平衡摩尔分数，以及被转化的氢的份额。
::: solution
在 $T = 723.15\ \mathrm{K}$，$\Delta_\mathrm{r}G^\circ \approx -46\,110 + 723.15\times99.38 = 25\,757\ \mathrm{J\,mol^{-1}}$，所以 $K = \exp(-25\,757/(8.314\times723.15)) = 0.01379$。于是 $a = 0.3248\times0.01379\times200 = 0.8955$，
$$
y = \frac{2(0.8955) + 1 - \sqrt{4(0.8955) + 1}}{2(0.8955)} = \frac{2.791 - 2.141}{1.791} = 0.363 .
$$
转化率：从 $\mathrm{N_2}$ $1\ \mathrm{mol}$、$\mathrm{H_2}$ $3\ \mathrm{mol}$ 出发，生成 $2\xi$ mol 氨后总量剩 $4 - 2\xi$ mol，所以 $y = 2\xi/(4 - 2\xi)$，$\xi = 2y/(1 + y) = 0.533$：平衡时 $53\,\%$ 的氢被转化。两个近似把准确度限制在几个百分点：$\Delta_\mathrm{r}H$ 和 $\Delta_\mathrm{r}S$ 并非跨 $425\ \mathrm{K}$ 恒定（温度更高时反应放热更多），且 $200\ \mathrm{bar}$ 下逸度系数明显偏离 $1$。真实的转化器达不到平衡又含有惰性组分，出口氨浓度单程只有约 $15$–$20\,\%$，所以未反应的气体要循环（[[green-chemistry/chemical-industry#ex-loop]]）。
:::
:::

既然转化率受平衡限制而速率受动力学限制，每一转化程度必有一个最佳温度。

::: proposition 可逆放热反应的最佳温度 {#prop-topt}
设 $\mathrm{A} \rightleftharpoons \mathrm{B}$ 在转化率 $X$ 下的净速率为 $r = k_1(1 - X) - k_{-1}X$，其中 $k_1 = A_1\mathrm{e}^{-E_1/RT}$，$k_{-1} = A_{-1}\mathrm{e}^{-E_{-1}/RT}$，$E_{-1} = E_1 - \Delta_\mathrm{r}H > E_1$（放热）。在固定 $X$ 下，$r$ 在温度 $T_\mathrm{opt}$ 处取极大，由
$$
\frac{1}{T_\mathrm{opt}} = \frac{1}{T_\mathrm{eq}(X)} + \frac{R}{E_{-1} - E_1}\ln\frac{E_{-1}}{E_1} ,
$$ {#eq-topt}
给出，其中 $T_\mathrm{eq}(X)$ 是使 $X$ 恰为平衡转化率的温度。$T_\mathrm{opt}$ 位于 $T_\mathrm{eq}$ 以下，并随 $X$ 增大而下降，所以一台理想反应器应当先热运行，随转化推进逐级降温。
:::

::: proof
在恒定 $X$ 下求导：$\partial r/\partial T = (E_1/RT^2)k_1(1 - X) - (E_{-1}/RT^2)k_{-1}X$。令其为零得 $k_{-1}X/[k_1(1 - X)] = E_1/E_{-1}$，即 $K(T_\mathrm{opt}) \equiv k_1/k_{-1} = [X/(1 - X)]\,E_{-1}/E_1$。平衡时 $r = 0$，所以 $K(T_\mathrm{eq}) = X/(1 - X)$。两式相除，$\ln K(T_\mathrm{opt}) - \ln K(T_\mathrm{eq}) = \ln(E_{-1}/E_1)$。由 $K \propto \exp(-\Delta_\mathrm{r}H/RT)$ 及 $-\Delta_\mathrm{r}H = E_{-1} - E_1$，左边为 $[(E_{-1} - E_1)/R](1/T_\mathrm{opt} - 1/T_\mathrm{eq})$，即得[[#eq-topt]]。由于 $E_{-1} > E_1$，对数为正，$T_\mathrm{opt} < T_\mathrm{eq}$；由于 $T_\mathrm{eq}(X)$ 随 $X$ 升高而下降（更多转化需要更大的 $K$，因而更低的 $T$），$T_\mathrm{opt}$ 也随之下降。二阶导为负——是极大而非极小——可由低温时速率小、而在 $T_\mathrm{eq}$ 时为零看出。上述分析假设一级动力学，但对真实催化剂更复杂的速率方程，结论同样成立。
:::

::: algorithm 为可逆放热气相反应选择条件 {#alg-conditions}
1. **平衡图。** 由 $\Delta_\mathrm{r}H^\circ$ 与 $\Delta_\mathrm{r}S^\circ$ 计算 $K(T)$，并对拟用进料求平衡转化率随 $T$ 与 $p$ 的变化（氨见[[#prop-nh3-eq]]）。
2. **催化剂窗口。** 找出最好的可用催化剂给出有用速率的最低温度（其"起燃"）与不因烧结或失去选择性而受损的最高温度。
3. **压力。** 若反应减少气体摩尔数，把压力定在催化剂窗口内的平衡转化率恰好抵得上压缩能耗与容器成本的数值。
4. **温度路径。** 在窗口内尽可能贴近[[#prop-topt]]那条下降的最佳温度——带中间冷却的绝热床，或冷却式管式反应器——使每一床都以其接近最快的速率工作。
5. **压制平衡。** 在级间移除产物（氨的冷凝，$\mathrm{SO_3}$ 的级间吸收），循环未反应气体，并为惰性组分设置吹扫排放（[[green-chemistry/chemical-industry#prop-recycle]]）。
6. **能量集成。** 以尽可能高温度的蒸汽回收反应热，用它驱动压缩机或预热进料。
:::

## 氨：哈伯-博施法

哈伯（Haber）在 1909 年证明，氨可以在锇催化剂上于约 $200\ \mathrm{bar}$、$500\,^\circ\mathrm{C}$ 由单质合成，并把未反应的气体循环。BASF 的博施（Bosch）把实验室装置变成了一座工厂，解决了高压容器的问题（高温高压下氢会侵蚀碳钢，所以转化器以内衬低碳钢制造），并与米塔施（Mittasch）一起通过试验数千种配方找到了一种廉价催化剂。至今仍在使用（形式有所改进）的催化剂，是由磁铁矿还原制得、以氧化钾、氧化铝和氧化钙作助剂的铁；某些工厂使用钌基催化剂。

一座现代装置有三个部分：

1. **合成气制备。** 天然气先脱除硫（催化剂毒物），在镍上与蒸汽重整，$\mathrm{CH_4 + H_2O \rightleftharpoons CO + 3H_2}$（$\Delta_\mathrm{r}H^\circ = +206\ \mathrm{kJ\,mol^{-1}}$），在由燃烧更多天然气加热的管中进行（一段重整），然后与空气在二段转化器中反应，由空气以恰当的量供入氮。经水煤气变换 $\mathrm{CO + H_2O \rightleftharpoons CO_2 + H_2}$（$-41\ \mathrm{kJ\,mol^{-1}}$）把 CO 转化为更多氢；$\mathrm{CO_2}$ 用吸收（胺液或碳酸盐溶液）脱除，残余的一氧化碳与二氧化碳微量组分经甲烷化转为甲烷，因为含氧化合物会使铁催化剂中毒。在部分地区——尤其中国——以煤气化代替重整。
2. 把 $\mathrm{N_2/H_2}$ 混合物**压缩**到约 $100$–$250\ \mathrm{bar}$。
3. **合成回路**：催化剂床层约 $400$–$500\,^\circ\mathrm{C}$，带中间冷却，氨用冷冻冷凝分出，循环并吹扫排放。

合成只占能耗的较小部分。最好的天然气装置每吨氨约耗 $28\ \mathrm{GJ}$（低热值），而由甲烷、空气和水制氨的热力学理论最小值约 $21\ \mathrm{GJ\,t^{-1}}$；全球平均值明显更高，因为存在老装置和煤头生产。按 IEA 的《氨技术路线图》（*Ammonia Technology Roadmap*，2021），2020 年世界产量约 $185\ \mathrm{Mt}$，直接排放约 $450\ \mathrm{Mt\,CO_2}$，平均每吨氨 $2.4\ \mathrm{t\,CO_2}$；约 $70\,\%$ 的氨用于化肥。

::: example 化学计量里内置的碳足迹 {#ex-nh3-co2}
把蒸汽重整与变换反应合并，$\mathrm{CH_4} + 2\,\mathrm{H_2O} \rightarrow \mathrm{CO_2} + 4\,\mathrm{H_2}$，求仅由原料计每吨氨释放的最小 $\mathrm{CO_2}$，并与上面引用的平均值比较。
::: solution
每个 $\mathrm{NH_3}$ 需要 $\tfrac32\,\mathrm{H_2}$；每个 $\mathrm{CH_4}$ 提供 $4\,\mathrm{H_2}$，所以每个 $\mathrm{NH_3}$ 用 $\tfrac38\,\mathrm{CH_4}$，释放 $\tfrac38\,\mathrm{CO_2}$。每吨：
$$
\frac{0.375\times44.01}{17.03}\ \mathrm{t\,CO_2} = 0.969\ \mathrm{t\,CO_2\ per\ t\,NH_3}.
$$
这一**过程 $\mathrm{CO_2}$** 以近乎纯的物流从吸收塔放出；一座气头工厂其余的排放——通常还有 $0.6$–$0.9\ \mathrm{t}$——来自为重整炉供热和产生蒸汽而燃烧的燃料，以稀薄烟气的形式排出。全球平均的 $2.4\ \mathrm{t}$ 反映了煤头工厂，其排放约为气头的两倍。这股浓缩的工艺物流是工业上捕集起来最便宜的 $\mathrm{CO_2}$，其中很大一部分已经被捕集——但用于制尿素，肥料在土壤中水解后它又被释放出来。带捕集或用电解氢的低排放氨路线见 [[green-chemistry/carbon-hydrogen]]。
:::
:::

氮肥的施用有其自身的环境代价：作物未吸收的氮以硝酸盐形式淋入水体造成富营养化，或被土壤细菌转化为 $\mathrm{N_2O}$——它如今是最重要的正在排放的臭氧层消耗物质，同时也是强效温室气体（[[environmental-chemistry/greenhouse-gases]]）。

## 硫酸：接触法

硫酸由硫制成，其中大部分是从天然气与石油的脱硫（克劳斯法）中回收的硫，或来自金属冶炼烟道气中的二氧化硫——所以它很大程度上是用本会成为废物的东西来生产的。三步：
$$
\begin{aligned}
\mathrm{S(l)} + \mathrm{O_2(g)} &\rightarrow \mathrm{SO_2(g)} &\quad \Delta_\mathrm{r}H^\circ &= -297\ \mathrm{kJ\,mol^{-1}}\\
\mathrm{SO_2(g)} + \tfrac12\mathrm{O_2(g)} &\rightleftharpoons \mathrm{SO_3(g)} & \Delta_\mathrm{r}H^\circ &= -98.9\ \mathrm{kJ\,mol^{-1}}\\
\mathrm{SO_3(g)} + \mathrm{H_2O\ (in\ H_2SO_4)} &\rightarrow \mathrm{H_2SO_4} & &
\end{aligned}
$$
$\mathrm{SO_2}$ 的氧化是可逆放热的一步，由负载在二氧化硅上的五氧化二钒与硫酸钾催化。在操作温度下，活性相是催化剂孔道中钒的氧硫酸盐配合物的熔融盐膜，催化剂在约 $400$ 到 $620\,^\circ\mathrm{C}$ 之间工作。三氧化硫不吸收到水里——那样会形成能穿过吸收塔的细酸雾——而是吸收到 $98$–$99\,\%$ 的硫酸中，其浓度靠加水维持。

三步都是放热的。燃硫工厂是能量的净输出者：反应热产生高压蒸汽，驱动工厂的空气鼓风机并发电，现代工厂回收的热量通常达到每吨产品一兆瓦时以上。硫酸是少数几个净输出可用能量而不是净消耗可用能量大宗工艺之一。

::: example 第一催化床中的平衡 {#ex-so2}
某转化器在约 $1\ \mathrm{bar}$、$690\ \mathrm{K}$（$417\,^\circ\mathrm{C}$）下进料摩尔分数为 $0.10\ \mathrm{SO_2}$、$0.11\ \mathrm{O_2}$、$0.79\ \mathrm{N_2}$ 的气体。第一床是绝热的；取气体的热容为每摩尔进料 $31\ \mathrm{J\,K^{-1}}$。用 NBS 数据（$\Delta_\mathrm{r}H^\circ = -98.89\ \mathrm{kJ\,mol^{-1}}$，$\Delta_\mathrm{r}S^\circ = -94.03\ \mathrm{J\,K^{-1}\,mol^{-1}}$），求第一床的最大转化率和出口温度。
::: solution
**操作线。** 每摩尔进料，转化率 $X$ 释放 $0.10\,X\times98\,890\ \mathrm{J}$，使温度每单位转化率升高 $0.10\times98\,890/31 = 319\ \mathrm{K}$：$T = 690 + 319X$。

**平衡。** 每摩尔进料、转化率 $X$ 时：$\mathrm{SO_2}$ $0.10(1 - X)$，$\mathrm{SO_3}$ $0.10X$，$\mathrm{O_2}$ $0.11 - 0.05X$，总量 $n = 1 - 0.05X$。对理想气体，
$$
K(T) = \frac{X}{1 - X}\left(\frac{n}{n_{\mathrm{O_2}}}\,\frac{p^\circ}{p}\right)^{1/2}, \qquad K(T) = \exp\!\left(\frac{98\,890 - 94.03\,T}{8.314\,T}\right).
$$
$700\ \mathrm{K}$ 时 $K = 294$，平衡转化率为 $98.7\,\%$；$800\ \mathrm{K}$ 时 $K = 35.1$，为 $90.2\,\%$；$873\ \mathrm{K}$ 时 $73.6\,\%$。

**交点。** 数值上联立解两个条件得 $X = 0.657$、$T = 900\ \mathrm{K}$（$626\,^\circ\mathrm{C}$）。所以第一床无论装多少催化剂，转化率都不能超过约三分之二：放出的热把气体推上平衡曲线。随后把气体冷却（副产蒸汽）到约 $700\ \mathrm{K}$，通过第二床，依此类推：三四床加中间冷却可把转化率提高到约 $96$–$98\,\%$——这是一道台阶，沿着[[#prop-topt]]那条下降的最佳温度走。出口温度接近催化剂的上限操作温度，这是进料 $\mathrm{SO_2}$ 浓度被限制在约 $10$–$12\,\%$ 的原因之一。
:::
:::

剩下 $2$–$4\,\%$ 的 $\mathrm{SO_2}$ 本会成为严重的空气污染物。**双接触双吸收**（DCDA）工艺由拜耳在 1960 年代引入，在第二或第三床之后设中间吸收塔除去 $\mathrm{SO_3}$；产物被移除后，剩余 $\mathrm{SO_2}$ 的平衡在最后的床层中强烈右移。若第一段转化份额 $X_1$，第二段转化剩余量的份额 $X_2$，则总转化率为
$$
X = 1 - (1 - X_1)(1 - X_2),
$$
所以 $X_1 = 0.96$、$X_2 = 0.95$ 给出 $99.8\,\%$。现代工厂达到 $99.7$–$99.9\,\%$，尾气洗涤还可进一步降低排放。

## 硝酸：奥斯特瓦尔德法

硝酸由氨氧化制备。奥斯特瓦尔德（Ostwald）于 1902 年开发了这一工艺，而它的工业成功有赖于哈伯-博施法不久后提供的廉价氨。三个反应：
$$
\begin{aligned}
4\,\mathrm{NH_3} + 5\,\mathrm{O_2} &\rightarrow 4\,\mathrm{NO} + 6\,\mathrm{H_2O} &\quad \Delta_\mathrm{r}H^\circ &= -905\ \mathrm{kJ\,mol^{-1}}\\
2\,\mathrm{NO} + \mathrm{O_2} &\rightleftharpoons 2\,\mathrm{NO_2} & \Delta_\mathrm{r}H^\circ &= -114\ \mathrm{kJ\,mol^{-1}}\\
3\,\mathrm{NO_2} + \mathrm{H_2O} &\rightarrow 2\,\mathrm{HNO_3} + \mathrm{NO} & &
\end{aligned}
$$
（焓值由 NBS 数据计算，水为气态）。第一个反应是动力学选择性的一个惊人例子。热力学上，氨和氧宁愿生成氮气，$4\,\mathrm{NH_3} + 3\,\mathrm{O_2} \rightarrow 2\,\mathrm{N_2} + 6\,\mathrm{H_2O}$，甚至放热更多。在约 $850$–$950\,^\circ\mathrm{C}$ 的铂铑丝网上，接触时间约一毫秒，对 NO 的选择性达到 $93$–$98\,\%$；接触时间更长或温度更低，$\mathrm{N_2}$ 和 $\mathrm{N_2O}$ 就更多。网因以 $\mathrm{PtO_2}$ 形式挥发而缓慢损失铂，由下游的钯"捕集"网回收。

第二个反应，NO 的氧化，很不寻常：它是三级反应，速率随温度升高而*降低*（生成 $\mathrm{N_2O_2}$ 二聚体的前置平衡，见 [[kinetics/reaction-mechanisms]]），所以它在气体冷却之后、在压力下进行。在高塔中用水吸收得 $50$–$68\,\%$ 的硝酸，第三个反应放出的 NO 被重新氧化、重新吸收。

副产物**氧化亚氮**是这一工艺的主要环境问题。不加消除的硝酸厂每吨酸排放数千克 $\mathrm{N_2O}$，而其百年全球升温潜能值为 $273$（IPCC AR6），每千克相当于 $273\ \mathrm{kg}$ 的 $\mathrm{CO_2}$。置于网下或尾气中的催化剂把 $\mathrm{N_2O}$ 分解为 $\mathrm{N_2}$ 和 $\mathrm{O_2}$，效率超过 $90\,\%$；欧盟的硝酸厂自 2013 年起因其 $\mathrm{N_2O}$ 而被纳入排放交易体系。尾气中的 $\mathrm{NO_x}$ 用氨选择性催化还原为氮气。

::: warning 选定产物的是催化剂，不是热力学 {#warn-kinetic}
人们容易想用 $\Delta_\mathrm{r}G$ 最负的一方来预言一个反应的产物。对氨氧化，那将预言氮气，而工业上却以超过 $95\,\%$ 的选择性生产 NO。热力学说的是哪些产物*可能*生成，以及单个可逆反应能走多远；当多种产物都可能时，生成的那个是生成最快的那个，而催化剂正是为加速某一条路径而选定的。[[green-chemistry/petrochemicals]] 中的环氧乙烷、部分氧化与选择性加氢工艺也是如此。另一种相反的错误同样常见：催化剂不能把单个可逆反应推过其平衡转化率，这就是氨与 $\mathrm{SO_3}$ 合成需要循环回路和级间吸收器的原因。
:::

## 氯与氢氧化钠

氯碱工艺——电解食盐水——在电池电压、能量消耗、析氯相对析氧的选择性以及三种槽技术等方面，[[electrochemistry/fuel-cells-electrolysis]] 有详细处理。从工业与绿色化学的角度看，有三个特点突出。

- **固定联产。** 每生产一吨氯就附带 $1.128\ \mathrm{t}$ 氢氧化钠和 $28\ \mathrm{kg}$ 氢，所以这个工业被夹在两个市场之间平衡——氯用于聚氯乙烯、异氰酸酯（制聚氨酯）、环氧氯丙烷与水处理；烧碱用于氧化铝精炼、纸浆造纸、肥皂与纺织——而这两个市场各自独立波动。"一吨氯连同其联产品"这一单位称为电化学单元（ECU）。
- **汞。** 曾占主导地位的汞法槽把汞排入空气和水。根据《关于汞的水俣公约》（2013 年通过，2017 年生效），汞法氯碱生产正在被淘汰；在欧盟，最后一批汞法槽根据《工业排放指令》的最佳可得技术结论于 2017 年底关闭。离子膜槽既更清洁也更节能。
- **能量。** 离子膜槽每吨氯约需 $2.2$–$2.5\ \mathrm{MWh}$ 电力，氯碱因此是化学工业中最大的耗电户之一，其排放就是供电系统的排放。氧去极化阴极以氧还原代替析氢，把电压降低约 $1\ \mathrm{V}$，代价是失去氢这一联产品。

关于氯的绿色化学问题，与其说在于它如何生产，不如说在于它如何使用。氯常常是一种"过境"元素：它活化一个分子，然后作为氯化物废物离开。在环氧丙烷的旧氯醇路线中，氯穿过整个工艺，最终成为氯化钙盐水；在以光气为基础的异氰酸酯制造中，它以 HCl 的形式离开，再经电解或催化氧化回收为氯。完全避免氯的路线，如以过氧化氢为基础的环氧丙烷工艺，见 [[green-chemistry/petrochemicals]]。

## 碳酸钠：从勒布朗法到索尔维法

碳酸钠（纯碱）用于玻璃、洗涤剂与化学品。它的历史是在这一术语出现之前的一个原子经济性案例研究。**勒布朗法**（1791）用硫酸处理食盐，得硫酸钠和氯化氢，再把硫酸钠与石灰石和煤共热：
$$
\begin{aligned}
2\,\mathrm{NaCl} + \mathrm{H_2SO_4} &\rightarrow \mathrm{Na_2SO_4} + 2\,\mathrm{HCl}\\
\mathrm{Na_2SO_4} + 2\,\mathrm{C} + \mathrm{CaCO_3} &\rightarrow \mathrm{Na_2CO_3} + \mathrm{CaS} + 2\,\mathrm{CO_2}
\end{aligned}
$$
氯化氢起初直接排空，毁掉了工厂周围的植被；硫化钙被堆成渣堆，在那里释放硫化氢。英国 1863 年的《碱业法》要求 $95\,\%$ 的 HCl 必须冷凝回收——由此创建了第一个工业污染监察机构——后来 HCl 被氧化为氯以制漂白粉，把废物变成了联产品。

**索尔维法**由索尔维（Solvay）在 1860 年代开发，取代了它。用氨饱和的盐水以 $\mathrm{CO_2}$ 碳酸化；碳酸氢钠是该体系中最难溶的盐，析出沉淀：
$$
\mathrm{NaCl} + \mathrm{NH_3} + \mathrm{CO_2} + \mathrm{H_2O} \rightarrow \mathrm{NaHCO_3(s)} + \mathrm{NH_4Cl}.
$$
碳酸氢钠煅烧成碳酸钠，$2\,\mathrm{NaHCO_3} \rightarrow \mathrm{Na_2CO_3} + \mathrm{CO_2} + \mathrm{H_2O}$，回收一半的 $\mathrm{CO_2}$；其余来自石灰石煅烧，$\mathrm{CaCO_3} \rightarrow \mathrm{CaO} + \mathrm{CO_2}$。生石灰消化后用来把氨从氯化铵中解放出来循环使用，$2\,\mathrm{NH_4Cl} + \mathrm{Ca(OH)_2} \rightarrow 2\,\mathrm{NH_3} + \mathrm{CaCl_2} + 2\,\mathrm{H_2O}$。氨与 $\mathrm{CO_2}$ 循环，总反应就只是
$$
\mathrm{CaCO_3} + 2\,\mathrm{NaCl} \rightarrow \mathrm{Na_2CO_3} + \mathrm{CaCl_2},
$$
一个并不直接进行的反应（其平衡在水中远在左侧，从混合溶液中沉淀 $\mathrm{CaCO_3}$ 即可看出）；靠氨与 $\mathrm{CO_2}$ 的循环，利用溶解度差异和热把它驱动。

::: example 纯碱的原子经济性 {#ex-soda}
由总方程式比较勒布朗法与索尔维法的原子经济性（$M$：NaCl $58.44$、$\mathrm{H_2SO_4}$ $98.08$、C $12.01$、$\mathrm{CaCO_3}$ $100.09$、$\mathrm{Na_2CO_3}$ $105.99\ \mathrm{g\,mol^{-1}}$）。
::: solution
**勒布朗法**，总反应：$2\,\mathrm{NaCl} + \mathrm{H_2SO_4} + 2\,\mathrm{C} + \mathrm{CaCO_3} \rightarrow \mathrm{Na_2CO_3} + 2\,\mathrm{HCl} + \mathrm{CaS} + 2\,\mathrm{CO_2}$。反应物 $116.88 + 98.08 + 24.02 + 100.09 = 339.07\ \mathrm{g}$；$\mathrm{AE} = 105.99/339.07 = 31.3\,\%$。

**索尔维法**：反应物 $100.09 + 116.88 = 216.97\ \mathrm{g}$；$\mathrm{AE} = 105.99/216.97 = 48.9\,\%$。

索尔维法做得好些，但它的反应物质量仍有半数以上以氯化钙的形式离开，每吨纯碱约 $1.05\ \mathrm{t}$（$110.98/105.99$），传统上以溶液形式排放或存入沉降池；只有小部分售出（例如用于道路融雪）。此外该工艺损失一些氨，煅烧又用去大量能量。凡有天然碱矿 $\mathrm{Na_2CO_3\cdot NaHCO_3\cdot 2H_2O}$ 的地方——最著名的在怀俄明州——纯碱只需采矿并煅烧矿石即可制得，这就解释了为什么美国没有索尔维法工厂。侯氏制碱法（侯德榜，1930–40 年代）在中国广泛应用，把氯化铵作为化肥结晶出来而不再生氨，从而消除了氯化钙废物：一种联产品策略。
:::
:::

## 化肥：尿素与磷酸

**尿素**是使用最广泛的氮肥，由氨与氨厂的工艺 $\mathrm{CO_2}$ 经博世-迈泽（Bosch–Meiser）法（1922）制成：氨基甲酸铵快速放热生成，随后缓慢吸热脱水，
$$
2\,\mathrm{NH_3} + \mathrm{CO_2} \rightleftharpoons \mathrm{H_2NCOONH_4} \rightleftharpoons \mathrm{CO(NH_2)_2} + \mathrm{H_2O},
$$
在约 $140$–$200\ \mathrm{bar}$、$180$–$190\,^\circ\mathrm{C}$ 下进行，未转化的氨基甲酸铵分解后循环回收。

磷肥用的**磷酸**以“湿法”生产，用硫酸分解磷矿（理想化为氟磷灰石）：
$$
\mathrm{Ca_5(PO_4)_3F} + 5\,\mathrm{H_2SO_4} + 10\,\mathrm{H_2O} \rightarrow 3\,\mathrm{H_3PO_4} + 5\,\mathrm{CaSO_4\cdot2H_2O} + \mathrm{HF}.
$$
世界硫酸的相当大一部分用在这里。副产物**磷石膏**——按化学计量每吨磷酸盐（以 $\mathrm{P_2O_5}$ 计）约 $4$ 吨，实践中更多——含有随矿石而来的微量镭等杂质，大多堆成大堆；为它找到用途是长期难题。氟化物以氟硅酸的形式回收，用于饮用水加氟和制氟化铝。磷矿是集中于少数国家的有限资源，列在欧盟关键原材料清单上；从废水中回收磷（例如以鸟粪石的形式）是 [[green-chemistry/circular-economy]] 中日益重要的部分。

::: quiz
为什么三氧化硫吸收到浓硫酸中而不是吸收到水里？
- [ ] 因为 $\mathrm{SO_3}$ 不与水反应
- [ ] 因为浓酸催化 $\mathrm{SO_3}$ 的生成
- [x] 因为直接与水汽反应会形成难以捕集的细酸雾，而吸收到 $98\,\%$ 酸中既高效又可控
- [ ] 因为水会使 $\mathrm{SO_2/SO_3}$ 平衡逆向移动
::: solution
$\mathrm{SO_3}$ 与水的反应极其放热；与水或稀酸接触会在气相中生成硫酸，形成亚微米液滴的酸雾，穿过吸收塔逸出。在 $98$–$99\,\%$ 酸中——该组成在溶液上方的总蒸气压最低——$\mathrm{SO_3}$ 溶解并与其中少量水反应，向循环酸中加水以维持其浓度恒定。气相氧化的平衡不受影响，因为吸收塔位于转化器下游。
:::
:::

::: history 从空气中获取面包 {#hist-haber}
哈伯的高压氨合成于 1909 年 7 月向 BASF 演示，第一座工厂在 Oppau 开工，1913 年投产；哈伯获 1918 年度诺贝尔化学奖，博施与因高压方法同贝吉乌斯（Friedrich Bergius）共同获得 1931 年的奖项。第一次世界大战期间，这一工艺也为炸药供应硝酸，而哈伯在化学战中的角色使其遗产毁誉参半。奥斯特瓦尔德于 1902 年为氨的催化氧化申请了专利（因催化获 1909 年诺贝尔奖）。硫酸的铅室法（Roebuck，1746）在佩勒格林·菲利普斯（Peregrine Phillips）1831 年的专利之后让位于接触法，接触法约于 1900–1915 年间在德国以铂、其后以钒催化剂发展成熟。尼古拉·勒布朗（Nicolas Leblanc）的制碱法（1791）被欧内斯特·索尔维（Ernest Solvay）的方法取代（第一座工厂在比利时的 Couillet，1865 年起），卡斯纳（Hamilton Castner）与卡尔·凯尔纳（Karl Kellner）的汞法槽（1890 年代）开启了电化学氯碱工业。博世-迈泽尿素法始于 1922 年。格哈德·埃特尔（Gerhard Ertl）对铁上氨合成的表面科学研究获得 2007 年诺贝尔奖的认可，最终确立了反应机理：$\mathrm{N_2}$ 的解离吸附是速控步骤。
:::

## 后续内容

本章的热力学推理在 [[green-chemistry/petrochemicals]] 中重现——蒸汽裂解是相反的情形：吸热、摩尔数增加的反应，高温与低压有利于它——并在 [[green-chemistry/carbon-hydrogen]] 中再次用到，那里展开蒸汽重整、低排放氢与作为能量载体的氨。铁与钒催化剂的表面化学见 [[kinetics/surface-kinetics]] 与 [[organometallics-catalysis/heterogeneous-catalysis]]，活性氮与硫的环境化学见 [[environmental-chemistry/particulates-acid-deposition]]。

::: summary
- 氨合成与 $\mathrm{SO_2}$ 氧化是可逆放热、气体摩尔数减少的反应：平衡有利于低 $T$ 高 $p$，速率有利于高 $T$。对理想气体与化学计量比进料，$y_{\mathrm{NH_3}}/(1 - y)^2 = 0.3248\,K\,p/p^\circ$，在 $450\,^\circ\mathrm{C}$、$200\ \mathrm{bar}$ 下给出 $36\,\%$ 的氨。
- 在固定转化率下速率在 $T_\mathrm{opt}$ 处达峰，$1/T_\mathrm{opt} = 1/T_\mathrm{eq} + [R/(E_{-1} - E_1)]\ln(E_{-1}/E_1)$；带中间冷却的多床反应器沿着下降的最优温度走。
- 哈伯-博施法：蒸汽重整、变换与 $\mathrm{CO_2}$ 脱除，铁催化剂，$100$–$250\ \mathrm{bar}$，带循环。仅原料每吨就释放 $0.97\ \mathrm{t\,CO_2}$；2020 年全球平均约 $2.4\ \mathrm{t}$（IEA）。
- 接触法：$\mathrm{V_2O_5}$ 催化剂，绝热床受平衡限制（第一床转化率约三分之二），双吸收达到 $> 99.7\,\%$；净输出能量。
- 奥斯特瓦尔德法：铂铑网以动力学选择性生成 NO 而非 $\mathrm{N_2}$；$\mathrm{N_2O}$（$\mathrm{GWP_{100}} = 273$）必须消除。
- 氯碱联产品固定（每吨 $\mathrm{Cl_2}$ 联产 $1.128\ \mathrm{t}$ NaOH）；汞法槽正根据水俣公约被淘汰。
- 索尔维法（$\mathrm{AE} = 48.9\,\%$，$\mathrm{CaCl_2}$ 废物）取代了勒布朗法（$31.3\,\%$，HCl 与 CaS 废物）；湿法磷酸每吨 $\mathrm{P_2O_5}$ 产生约 $4\ \mathrm{t}$ 磷石膏。
:::

::: exercise 尿素的原子经济性 {level=1 check="76.9"}
求 $2\,\mathrm{NH_3} + \mathrm{CO_2} \rightarrow \mathrm{CO(NH_2)_2} + \mathrm{H_2O}$ 的原子经济性（$M$：$\mathrm{NH_3}$ $17.03$、$\mathrm{CO_2}$ $44.01$、尿素 $60.06\ \mathrm{g\,mol^{-1}}$）。（以百分比计。）
::: solution
$\mathrm{AE} = 60.06/(2\times17.03 + 44.01) = 60.06/78.07 = 76.9\,\%$，副产物是水。
:::

::: exercise 双吸收 {level=1 check="99.8"}
某 DCDA 工厂第一段接触转化 $96\,\%$ 的 $\mathrm{SO_2}$，第二段转化到达它的气体的 $95\,\%$。总转化率是多少？（以百分比计。）
::: solution
$X = 1 - (1 - 0.96)(1 - 0.95) = 1 - 0.04\times0.05 = 0.998$，即 $99.8\,\%$。未转化的 $\mathrm{SO_2}$ 从（单吸收时的）$4\,\%$ 降到进料的 $0.2\,\%$。
:::
:::

::: exercise 硝酸厂的氧化亚氮 {level=1 check="1.91"}
某座不加消除装置的硝酸厂每吨 $\mathrm{HNO_3}$ 排放 $7.0\ \mathrm{kg}$ 的 $\mathrm{N_2O}$。用 $\mathrm{GWP_{100}} = 273$，把它表示为每吨酸的 $\mathrm{CO_2}$ 当量吨数。（答案以 t $\mathrm{CO_2e}$ 计。）
::: solution
每吨酸 $7.0\times273 = 1911\ \mathrm{kg} = 1.91\ \mathrm{t\,CO_2e}$——与制造它所用的氨所排放的 $\mathrm{CO_2}$ 相当。效率 $90\,\%$ 的消除催化剂可把它降到 $0.19\ \mathrm{t}$。
:::

::: exercise 氨的范特霍夫计算 {level=2 check="7.25"}
对 $\mathrm{N_2 + 3H_2 \rightleftharpoons 2NH_3}$ 取 $\Delta_\mathrm{r}H^\circ = -92.22\ \mathrm{kJ\,mol^{-1}}$ 且视为常数，$700\ \mathrm{K}$ 下的平衡常数是 $800\ \mathrm{K}$ 下的多少倍？（输入该倍数。）
::: solution
$\ln(K_{700}/K_{800}) = -(\Delta_\mathrm{r}H^\circ/R)(1/700 - 1/800) = (92\,220/8.314)\times1.786\times10^{-4} = 1.981$，故倍数为 $\mathrm{e}^{1.981} = 7.25$。温度改变 $100\ \mathrm{K}$，$K$ 变七倍；在低转化率下需要把压力改变 $\sqrt{7.25} = 2.7$ 倍才能补偿（按所写反应，$y$ 小时 $K \propto y/p^2$）。
:::
:::

::: exercise 磷石膏 {level=2 check="4.04"}
由正文的湿法方程式，求以 $\mathrm{P_2O_5}$（$141.94\ \mathrm{g\,mol^{-1}}$）表示的每吨磷酸盐所产生 $\mathrm{CaSO_4\cdot2H_2O}$（$172.17\ \mathrm{g\,mol^{-1}}$）的质量。（质量以吨计。）
::: solution
三个 $\mathrm{H_3PO_4}$ 对应 $1.5$ 个 $\mathrm{P_2O_5}$，并伴随 $5$ 个石膏：$5\times172.17/(1.5\times141.94) = 860.85/212.91 = 4.04\ \mathrm{t}$ 每吨 $\mathrm{P_2O_5}$。真实磷矿含有额外钙（以碳酸盐形式），磷的回收也不完全，所以实际数字更高，约 $4.5$–$5\ \mathrm{t}$。
:::

::: exercise 较低压力下的氨 {level=2 check="34.2"}
用每摩尔 $\mathrm{NH_3}$ 的 $\Delta_\mathrm{r}H^\circ = -46.11\ \mathrm{kJ\,mol^{-1}}$ 与 $\Delta_\mathrm{r}S^\circ = -99.38\ \mathrm{J\,K^{-1}\,mol^{-1}}$，求化学计量比进料在 $400\,^\circ\mathrm{C}$、$100\ \mathrm{bar}$ 下氨的理想气体平衡摩尔分数。（$y$ 以百分比计，保留三位有效数字。）
::: solution
在 $673.15\ \mathrm{K}$：$\Delta_\mathrm{r}G^\circ = -46\,110 + 673.15\times99.38 = 20\,788\ \mathrm{J\,mol^{-1}}$，$K = \exp(-20\,788/(8.314\times673.15)) = 0.02437$。$a = 0.3248\times0.02437\times100 = 0.7914$。$y = [2(0.7914) + 1 - \sqrt{4(0.7914) + 1}]/(2\times0.7914) = (2.5828 - 2.0412)/1.5828 = 0.342$，即 $34.2\,\%$——接近 $450\,^\circ\mathrm{C}$、$200\ \mathrm{bar}$ 下的数值。温度降低 $50\ \mathrm{K}$，只要 $400\,^\circ\mathrm{C}$ 下有足够活跃的催化剂，压力就能减半而平衡几乎不变：这正是人们对钌等低温催化剂感兴趣的原因——它们能降低压缩能耗。
:::
:::

::: exercise 最佳温度分布 {level=3 check="725.7"}
对[[#prop-topt]]的模型，取 $E_1 = 100\ \mathrm{kJ\,mol^{-1}}$、$E_{-1} = 200\ \mathrm{kJ\,mol^{-1}}$、$800\ \mathrm{K}$ 时 $K = 1$，求转化率 $X = 0.70$ 下的 $T_\mathrm{eq}$ 与 $T_\mathrm{opt}$。（$T_\mathrm{opt}$ 以 K 计，保留一位小数。）
::: hint
$K(T) = \exp[(-\Delta_\mathrm{r}H/R)(1/T - 1/800)]$，其中 $-\Delta_\mathrm{r}H = E_{-1} - E_1$，且 $K(T_\mathrm{eq}) = X/(1 - X)$。
:::
::: solution
$-\Delta_\mathrm{r}H/R = 100\,000/8.314 = 12\,027.9\ \mathrm{K}$。平衡：$\ln(0.7/0.3) = 0.8473 = 12\,027.9(1/T_\mathrm{eq} - 1/800)$，所以 $1/T_\mathrm{eq} = 1.25\times10^{-3} + 7.044\times10^{-5} = 1.3204\times10^{-3}\ \mathrm{K^{-1}}$，$T_\mathrm{eq} = 757.3\ \mathrm{K}$。再由[[#eq-topt]]，$1/T_\mathrm{opt} = 1.3204\times10^{-3} + (\ln2)/12\,027.9 = 1.3204\times10^{-3} + 5.763\times10^{-5} = 1.3781\times10^{-3}$，$T_\mathrm{opt} = 725.7\ \mathrm{K}$。$X = 0.5$ 时最优温度为 $764.7\ \mathrm{K}$：转化率从 $50\,\%$ 升到 $70\,\%$，最优温度下降约 $39\ \mathrm{K}$。
:::
:::

::: exercise $800\ \mathrm{K}$ 下 $\mathrm{SO_2}$ 的平衡 {level=3 check="90.2"}
对[[#ex-so2]]的进料（$0.10\ \mathrm{SO_2}$、$0.11\ \mathrm{O_2}$、$0.79\ \mathrm{N_2}$）在 $1.0\ \mathrm{bar}$ 下，已知 $K(800\ \mathrm{K}) = 35.1$，求 $800\ \mathrm{K}$ 时 $\mathrm{SO_2}$ 的平衡转化率。解释为什么把压力提到 $5\ \mathrm{bar}$ 通常并不划算。（转化率以百分比计，保留三位有效数字。）
::: hint
在 $1\ \mathrm{bar}$ 下写出 $K = [X/(1 - X)]\sqrt{(1 - 0.05X)/(0.11 - 0.05X)}$，用试差法求解。
:::
::: solution
定义 $g(X) = [X/(1 - X)]\sqrt{(1 - 0.05X)/(0.11 - 0.05X)}$。$X = 0.90$ 时：$9.000\times\sqrt{0.955/0.065} = 9.000\times3.833 = 34.5$。$X = 0.905$ 时：$9.526\times\sqrt{0.95475/0.06475} = 9.526\times3.840 = 36.6$。插值到 $35.1$ 得 $X = 0.9015$，即 $90.2\,\%$。在 $5\ \mathrm{bar}$ 下右端获得因子 $\sqrt5 = 2.24$，所以在固定 $K$ 下 $X/(1 - X)$ 必须按该因子减小：平衡转化率会升到约 $95\,\%$。但双吸收在近常压下已实现 $99.8\,\%$，而让载有 $\mathrm{SO_2}$ 的气体在更高压力下运行所需的设备与压缩能耗得不偿失；不过仍有少数工厂在中等压力下运行。
:::
