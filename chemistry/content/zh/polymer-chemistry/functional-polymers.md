直到 1970 年代，聚合物几乎按定义就是电绝缘体。聚乙烯裹在电缆外面，恰恰因为它什么都不导。然后在 1977 年，Shirakawa（Hideki Shirakawa）、MacDiarmid（Alan MacDiarmid）与 Heeger（Alan Heeger）把聚乙炔薄膜暴露在碘蒸气中，看着它的电导率上升七个数量级以上，进入金属的行列。这一结果改变了人们对聚合物的期待。今天人们要求聚合物在手机屏幕上发光、在电池中传导离子、在温度越过体温时溶胀或塌缩、带着药物穿行于血流并在数周内释放、把伤口合拢然后消失、记住一种形状、愈合划痕，并且越来越紧迫地要求：在我们用完之后分解或被回收。这些就是**功能聚合物**：选择它们不是为了强度或便宜，而是为了某种"做事"的性能。

本章巡礼四个家族，用前面各章的物理化学解释每一类如何工作。**导电与半导体聚合物**的行为源于共轭、带隙与掺杂。**刺激响应聚合物与凝胶**把[[polymer-chemistry/polymer-solutions]]的 Flory–Huggins 热力学反着用，以下限临界溶解温度作开关，外加形状记忆与动态网络。**生物医学聚合物**涵盖 PEG、可降解缝线与扩散控制的控释给药。**为降解或回收而设计的聚合物**收尾：水解动力学、堆肥标准，以及物理、化学与酶法回收，并给出截至 2026 年的塑料问题规模。

## 导电与半导体聚合物

聚乙烯这类饱和聚合物的充满的 σ 成键轨道与空的 σ* 轨道之间有很大的能量间隙（约 $8\ \mathrm{eV}$）。室温下没有电子能被激发越过这个间隙，所以它是绝缘体。**共轭**聚合物沿主链单双键交替，π 轨道离域在链上。随着共轭长度增长，π 能级挤成能带。充满的 π 带（价带，由 HOMO 构成）与空的 π* 带（导带，由 LUMO 构成）之间的间隙从乙烯的约 $5\ \mathrm{eV}$ 缩小到可见与近红外区。共轭聚合物因此是有颜色的半导体。

::: proposition 多烯 HOMO–LUMO 能隙的自由电子估算 {#prop-free-electron}
把 $N$ 个碳原子构成的线性共轭链的 $N$ 个 π 电子模拟为长度 $L \approx Nl$（$l = 0.139\ \mathrm{nm}$ 为平均 C–C 距离）的一维势箱中的粒子。每个能级占据两个电子，最高占据能级为 $n = N/2$，最低激发能为
$$
\Delta E = E_{N/2+1} - E_{N/2} = \frac{h^2(N+1)}{8m_\mathrm{e}L^2} \approx \frac{h^2}{8m_\mathrm{e}l^2}\cdot\frac{N+1}{N^2} \;\longrightarrow\; 0 \quad (N \to \infty).
$$ {#eq-free-electron}
模型预言无限长多烯是金属。真实聚乙炔的间隙约 $1.5\ \mathrm{eV}$，因为键长发生交替（派尔斯（Peierls）畸变）；模型对长链在定量上失效。
:::

::: proof
质量 $m_\mathrm{e}$ 的粒子在长度 $L$ 的势箱中的能级为 $E_n = n^2h^2/(8m_\mathrm{e}L^2)$（见[[quantum-chemistry]]）。$N$ 个电子、每级两个，能级 $1$ 到 $N/2$ 被填满。HOMO–LUMO 间隙为
$$
E_{N/2+1} - E_{N/2} = \frac{h^2}{8m_\mathrm{e}L^2}\left[\left(\frac{N}{2}+1\right)^2 - \left(\frac{N}{2}\right)^2\right] = \frac{h^2}{8m_\mathrm{e}L^2}(N + 1) .
$$
代入 $L = Nl$，得 $\frac{h^2}{8m_\mathrm{e}l^2}\cdot\frac{N+1}{N^2}$，大 $N$ 时按 $1/N$ 下降，在无限长链中消失。于是两带相接，半满的带应当导电。失效有物理原因。一维半满带对一种使晶胞加倍的畸变不稳定（派尔斯定理）。长短交替的键在费米面处打开间隙，并把已占据态的能量压低的幅度超过抬高任何东西的幅度。键长相等的"金属"永远不会形成。$\blacksquare$
:::

::: example 共轭链的颜色 {#ex-polyene}
用[[#eq-free-electron]]估算己三烯（$N = 6$）与 $N = 22$ 的多烯（β-胡萝卜素的发色团长度）的最低吸收波长。与实验比较：己三烯约 $258\ \mathrm{nm}$，β-胡萝卜素约 $450\ \mathrm{nm}$。
::: solution
$N = 6$ 时，$L = 6(0.139\ \mathrm{nm}) = 0.834\ \mathrm{nm}$：
$$
\Delta E = \frac{(6.626\times10^{-34}\ \mathrm{J\,s})^2(7)}{8(9.109\times10^{-31}\ \mathrm{kg})(0.834\times10^{-9}\ \mathrm{m})^2} = 6.06\times10^{-19}\ \mathrm{J} = 3.78\ \mathrm{eV},
$$
所以 $\lambda = hc/\Delta E = 328\ \mathrm{nm}$。$N = 22$ 时，$L = 3.06\ \mathrm{nm}$，$\Delta E = 0.92\ \mathrm{eV}$，$\lambda = 1340\ \mathrm{nm}$。

模型的趋势正确（共轭越长吸收越红），对短链也算公平，偏差约 30%。对长链则严重失败：它预言红外吸收，而 β-胡萝卜素吸收 $450\ \mathrm{nm}$ 附近的蓝光、因而呈橙色。真实的间隙因键交替与电子-电子排斥而饱和：类胡萝卜素约 $2.5\ \mathrm{eV}$，聚乙炔约 $1.5\ \mathrm{eV}$。共轭聚合物的行为是半导体，不是一维金属。
:::
:::

**掺杂**把这些半导体变成导体。氧化（p 型掺杂，用碘、$\mathrm{FeCl_3}$ 或电化学方法）从 π 体系移去电子，还原（n 型掺杂，用碱金属）加入电子。抗衡离子进入膜内以平衡电荷。电荷并不待在僵硬的能带里。链上的正电荷在其周围几个重复单元的范围内扭曲键交替，形成**极化子（polaron）**——一个穿着局部晶格畸变外衣的自由基阳离子。掺杂更高时，极化子两两配对成无自旋的**双极化子**。电荷沿链靠极化子迁移运动，链与链之间靠跃迁运动，所以电导率强烈依赖链的有序度、薄膜形貌与掺杂水平。电导率 $\sigma = ne\mu$，$n$ 为载流子浓度，$\mu$ 为迁移率。无序聚合物膜中的迁移率很小（$10^{-4}$ 到 $1\ \mathrm{cm^2\,V^{-1}\,s^{-1}}$，晶体硅约为 $1400$），所以高电导率需要高载流子浓度——达到重复单元的百分之几。

::: example 导电聚合物掺得多浓？ {#ex-doping}
碘掺杂聚乙炔薄膜的电导率 $\sigma = 5.0\times10^{2}\ \mathrm{S\,cm^{-1}}$。设载流子迁移率 $1.0\ \mathrm{cm^2\,V^{-1}\,s^{-1}}$，$\mathrm{(CH)}_x$ 的密度 $1.16\ \mathrm{g\,cm^{-3}}$（每个 CH 为 $13.02\ \mathrm{g\,mol^{-1}}$），估算载流子浓度以及带电 CH 单元的分数。
::: solution
$$
n = \frac{\sigma}{e\mu} = \frac{5.0\times10^{2}\ \mathrm{S\,cm^{-1}}}{(1.602\times10^{-19}\ \mathrm{C})(1.0\ \mathrm{cm^2\,V^{-1}\,s^{-1}})} = 3.1\times10^{21}\ \mathrm{cm^{-3}} .
$$
CH 单元的密度为 $(1.16/13.02)\times6.022\times10^{23} = 5.37\times10^{22}\ \mathrm{cm^{-3}}$，带电分数为 $3.1\times10^{21}/5.37\times10^{22} = 0.058$，约每 17 个 CH 单元一个电荷。这与元素分析（以 $\mathrm{I_3^-}$ 计）发现的百分之几掺杂水平相符。铜这样的金属载流子浓度约 $8\times10^{22}\ \mathrm{cm^{-3}}$，迁移率为几十 $\mathrm{cm^2\,V^{-1}\,s^{-1}}$。掺杂聚合物在载流子浓度上接近金属，败在迁移率上——这是无序的代价。
:::
:::

聚乙炔本身在空气中不稳定。实际使用的导电聚合物是芳族或杂芳族的。以聚苯乙烯磺酸盐掺杂的聚(3,4-乙烯二氧噻吩)（PEDOT:PSS）是可水系加工的导体，用作透明电极、抗静电涂层和有机器件的空穴传输层。**聚苯胺**与**聚吡咯**用于传感器与缓蚀防护。未掺杂的共轭聚合物则是**有机发光二极管**（从相反电极注入的电子与空穴在链上复合形成激子而发光，1990 年首次在聚(对苯撑乙烯撑)上报道）、**有机太阳电池**与**有机场效应晶体管**的活性层。在所有这些应用中，带隙由分子设计设定，例如在"给体-受体"主链上交替排列富电子与缺电子单元，以缩小带隙、吸收更多太阳光谱。离子传导性聚合物是独立的一类，靠链段运动而非电子导电。例子是聚环氧乙烷-锂盐电解质与燃料电池的全氟磺酸膜（Nafion）。它们的电导率遵循[[polymer-chemistry/polymer-properties#prop-wlf]]的 WLF 温度依赖，因为离子只能跟着周围的链一起动。

## 刺激响应聚合物

### 受热沉淀的聚合物

多数聚合物-溶剂对越热*越*互溶：它们的 $\chi$ 随温度下降，表现出上限临界溶解温度（[[polymer-chemistry/polymer-solutions#prop-critical]]）。许多水溶性聚合物恰好相反。聚(*N*-异丙基丙烯酰胺)（PNIPAM）溶于冷水，但加热越过约 $32\ ^\circ\mathrm{C}$ 时骤然析出，这一温度称为它的**下限临界溶解温度**（LCST）。聚环氧乙烷、甲基纤维素、聚甲基乙烯基醚和许多蛋白质都如此。

::: proposition LCST 的热力学条件 {#prop-lcst}
低温下均一的溶液若在加热时分相，其混合自由能必具有**负的混合焓**与**负的混合熵**，使得 $\Delta_\text{mix}G = \Delta_\text{mix}H - T\Delta_\text{mix}S$ 随 $T$ 升高由负变正。用 Flory–Huggins 形式 $\chi = A + B/T$ 表达，LCST 要求 $B < 0$（使 $\chi$ *随温度升高*）且 $A > \tfrac12$。对长链，LCST 一侧满足 $\chi = \tfrac12$ 的 θ 温度为
$$
\Theta_\text{LCST} = \frac{-B}{A - \tfrac12} .
$$ {#eq-lcst}
:::

::: proof
分相要求混合变得不利。当 $\Delta_\text{mix}H < 0$ 且 $\Delta_\text{mix}S < 0$ 时，只有 $T < \Delta_\text{mix}H/\Delta_\text{mix}S$（两者皆负，故比值正）才有 $\Delta_\text{mix}G < 0$。高于该温度，熵的惩罚占上风，组分即分层。在 Flory–Huggins 理论中，相互作用参数 $\chi$ 是每个接触的相互作用自由能除以 $k_\mathrm{B}T$：$\chi = (\Delta h - T\Delta s)/k_\mathrm{B}T = B/T + A$，其中 $B = \Delta h/k_\mathrm{B}$、$A = -\Delta s/k_\mathrm{B}$。负的接触焓（水与酰胺间有利的氢键）给出 $B < 0$；负的接触熵（异丙基周围水被排齐）给出 $A > 0$。于是 $\chi$ 随 $T$ 上升；令 $\chi = \tfrac12$（无限长链的临界值）得 $A + B/T = \tfrac12$，即 $T = -B/(A - \tfrac12)$，仅当 $A > \tfrac12$ 时为正。$\blacksquare$
:::

分子图像是**疏水效应**。低温下，水在聚合物的疏水异丙基周围形成排齐的、氢键键合的笼，并与酰胺基形成氢键。混合在焓上有利，但水被排齐使熵代价高昂。加热时 $-T\Delta S$ 项增大，放出有序的水、让链塌缩就变得有利。单条 PNIPAM 链发生**线团到球状粒的转变**；交联的 PNIPAM 凝胶在一两度之内排出大部分水、收缩到原体积的一小部分。通过共聚可以调节这一转变：亲水共聚单体抬高 LCST，疏水的降低它，因此可以把 LCST 安置在室温与体温之间。这是注射后在体内定型的凝胶、降温即释放细胞的培养表面以及"智能"阀门的基础。

**水凝胶**是交联的亲水网络，能保持自身质量许多倍的水，例如聚（甲基丙烯酸羟乙酯）隐形眼镜、聚丙烯酰胺电泳凝胶和尿布里的聚丙烯酸钠。它们的溶胀是两股作用的平衡：把水拉进来的 Flory–Huggins 混合自由能，与抵抗网络拉伸的[[polymer-chemistry/polymer-properties#prop-rubber]]橡胶弹性。这就是 Flory–Rehner 理论。**聚电解质凝胶**（如部分中和的聚丙烯酸）溶胀得极其厉害，因为被困在凝胶里的抗衡离子贡献了渗透压。在盐水中它们溶胀较少（盐把电荷屏蔽），并随羧酸基（$\mathrm{p}K_\mathrm{a} \approx 4.5$）的电离而对 pH 产生响应。高吸水性树脂能吸收自身质量数百倍的纯水，但吸收尿液或盐水就少得多。

### 形状记忆、自修复与动态网络

**形状记忆聚合物**是带一个开关转变（通常是 $T_\mathrm{g}$ 或熔点、且位于使用区间内）的网络（化学的或物理的）。加热到开关以上，它呈橡胶态、可以变形；在负载下冷却，玻璃相或晶相锁住链，临时形状便被冻结。再次加热，网络的熵弹性把它拉回由交联点固定的永久形状。应用包括热缩管（交联聚乙烯，以 $T_\mathrm{m}$ 为开关），自收紧缝线与支架正在研发中。

传统热固性树脂不能重塑或回收，因为交联是永久的（[[polymer-chemistry/step-growth]]）。**动态共价网络**把部分或全部交联换成在触发条件下可交换的键。Leibler 与合作者 2011 年提出的**类玻璃高分子（vitrimer）**在高温下由锌盐催化发生酯交换，酰氧键不断重排。交联的*数目*守恒，材料绝不溶解，但网络拓扑可以重排，于是它能流动，能像玻璃一样重新模塑与焊接。它的黏度按 Arrhenius 方式下降（石英玻璃如此），而不遵循 WLF。二硫键、硼酸酯、亚胺与 Diels–Alder 交换化学给出同类的**自修复**与可回收网络。靠多重氢键结合的超分子聚合物（如 Meijer 课题组的脲基嘧啶酮单元）通过重新形成非共价键而愈合。

## 聚合物与医学

医用聚合物的选择标准是**生物相容性**——在特定用途下不引起有害响应——往往还有可控**降解**。例子有高分子植入物（超高分子量聚乙烯髋关节衬垫、PMMA 骨水泥、硅橡胶）、软性隐形眼镜（水凝胶）、缝线与支架（可降解聚酯）以及给药系统。本节仅供教学，不提供任何医疗建议；下文剂量数值均为示例，不具临床意义。

**聚乙二醇**（PEG）水溶、柔顺且强烈水合，因此抗拒蛋白质吸附。把 PEG 链接到蛋白质药物上（**PEG 化**）增大其流体力学体积，肾脏清除变慢，并把它屏蔽起来免受酶与抗体的攻击。首个 PEG 化蛋白质药物 1990 年在美国获批，此后已有数十个。PEG 还包覆在脂质纳米颗粒上（包括 mRNA 疫苗的那些）；一部分人群中可检出抗 PEG 抗体，这是当前的研究课题。

**可降解聚酯**由开环聚合（[[polymer-chemistry/controlled-polymerisation]]）制备，是可吸收器械的主力。它们是聚乙醇酸（PGA，第一种合成可吸收缝线，约 1970 年引入）、聚乳酸（PLA）、它们的共聚物（PLGA）与聚（ε-己内酯）（PCL）。其酯键在体液中水解，产物乳酸与乙醇酸可被代谢。水解速率从数周（PGA、无规 PLGA 50:50）到数年（结晶 PLLA、PCL）不等，由结晶度、疏水性与 $T_\mathrm{g}$ 决定——水必须先进得去，水解才可能发生。

### 扩散控制的释放

最简单的控释装置是把药物分散或溶解于其中的聚合物基体。药物靠扩散离开。厚度 $L$ 的平板从两个表面同时释放，Fick 第二定律给出的释放曲线以时间的平方根开始。

::: proposition 平板的 Fick 释放 {#prop-release}
厚度 $L$ 的平板，药物初始均匀分布于浓度 $c_0$，扩散系数 $D$，置于充分搅拌的接收槽中（表面浓度为零），释放分数为
$$
\frac{M_t}{M_\infty} = 1 - \sum_{k=0}^{\infty}\frac{8}{(2k+1)^2\pi^2}\exp\!\left[-\frac{(2k+1)^2\pi^2Dt}{L^2}\right]
\;\approx\; 4\left(\frac{Dt}{\pi L^2}\right)^{1/2} \quad\left(\frac{M_t}{M_\infty} \lesssim 0.6\right).
$$ {#eq-release}
早期释放正比于 $t^{1/2}$，之后指数式趋近完全，最慢模态的弛豫时间为 $L^2/(\pi^2D)$。
:::

::: proof
早期、两个贫化前沿尚未在中线相遇之前，每个表面都像半无限介质的表面。浓度分布为 $c(x, t) = c_0\,\mathrm{erf}\bigl(x/2\sqrt{Dt}\bigr)$，它满足 Fick 第二定律 $\partial c/\partial t = D\,\partial^2c/\partial x^2$，且表面 $c = 0$、内部远处 $c = c_0$。经表面流出的通量为 $D(\partial c/\partial x)_{x=0} = Dc_0/\sqrt{\pi Dt} = c_0\sqrt{D/\pi t}$。对时间积分得经一个单位面积单侧释放的量 $2c_0\sqrt{Dt/\pi}$。两个面给出 $4c_0\sqrt{Dt/\pi}$，再除以单位面积的总载药量 $c_0L$，即得短时形式。完整级数来自在 $0 < x < L$ 上对两端 $c = 0$ 作分离变量。解为 $c = \sum_kb_k\sin[(2k+1)\pi x/L]\,e^{-(2k+1)^2\pi^2Dt/L^2}$，其中 $b_k = 4c_0/[(2k+1)\pi]$（常数的傅里叶正弦级数）。对平板积分 $c$ 并从 $c_0L$ 中减去，即得[[#eq-release]]。$\blacksquare$
:::

$t^{1/2}$ 律意味着基体装置最初释放最快（"突释"），随后变慢。临床上常要的零级（恒速率）释放需要另一种设计。药芯外包速率控制膜的储库型装置，只要药芯保持饱和，就给出恒定通量。**表面侵蚀**聚合物（如聚酸酐）疏水到水透不进去，只能逐层侵蚀，释放药物正比于已侵蚀的体积。实践中用拟合 $M_t/M_\infty = kt^n$ 诊断释放指数。对平板，$n = 0.5$ 指示 Fick 扩散，$n = 1$ 指示零级（侵蚀或溶胀控制）释放，介于两者之间指示混合机理。

::: example 设计释放时长 {#ex-release}
载药聚合物膜厚 $1.0\ \mathrm{mm}$，从两个表面释放，药物在聚合物中的扩散系数 $1.0\times10^{-13}\ \mathrm{m^2\,s^{-1}}$。估算释放 50% 所需的时间。要把这段时间加倍，厚度应为多少？（示例数值，不是临床设计。）
::: solution
令 $4(Dt/\pi L^2)^{1/2} = 0.50$，则 $Dt/\pi L^2 = (0.125)^2 = 0.015625$，
$$
t_{1/2} = \frac{0.015625\,\pi L^2}{D} = \frac{0.015625\times3.1416\times(1.0\times10^{-3}\ \mathrm{m})^2}{1.0\times10^{-13}\ \mathrm{m^2\,s^{-1}}} = 4.9\times10^{5}\ \mathrm{s} \approx 5.7\ \mathrm{days} .
$$
完整级数在此时刻给出 49.95%，所以短时形式在这里基本上就是精确的。因为 $t_{1/2} \propto L^2$，时间加倍需要膜厚 $\sqrt2$ 倍，即 $1.4\ \mathrm{mm}$。若聚合物在此期间还发生降解（PLGA），$D$ 随摩尔质量下降而增大，释放会在后期阶段加速。这是可降解储库常见且经设计的特性。
:::
:::

## 为降解而设计的聚合物

### 水解与断链

聚酯靠主链酯键的水解而降解。主链每断裂一处，一个分子就变成两个，所以数均摩尔质量以一种简单的方式下降。

::: proposition 随机断链 {#prop-scission}
若主链键随机断裂，每个键的一级速率常数为 $k$，聚合物初始数均摩尔质量为 $\bar{M}_{\mathrm{n},0}$、重复单元摩尔质量为 $M_0$，则在降解程度较小时
$$
\frac{1}{\bar{M}_\mathrm{n}(t)} = \frac{1}{\bar{M}_{\mathrm{n},0}} + \frac{kt}{M_0},
$$ {#eq-scission}
每条原始链的断链数为 $s = \bar{M}_{\mathrm{n},0}/\bar{M}_\mathrm{n} - 1$。若反应被其自身生成的羧酸端基自催化，速率随端基浓度增大，$\ln\bar{M}_\mathrm{n}$ 则大致随时间线性下降。
:::

::: proof
对单位质量聚合物计算。分子数（摩尔）为 $1/\bar{M}_\mathrm{n}$，主链键数约为 $1/M_0$（长链中每个重复单元一个）。每断一次链，分子数恰增一。随机断链、一级动力学、断裂键的分数很小时，到时间 $t$ 断裂的键的摩尔数为 $(1/M_0)(1 - e^{-kt}) \approx kt/M_0$。于是 $1/\bar{M}_\mathrm{n}(t) = 1/\bar{M}_{\mathrm{n},0} + kt/M_0$。乘以 $\bar{M}_{\mathrm{n},0}$，每条原始分子变成的分子数即 $\bar{M}_{\mathrm{n},0}/\bar{M}_\mathrm{n}$，减一即每条原始链的断链数。存在自催化时，每个键的断裂速率 $k'[\mathrm{COOH}] \propto 1/\bar{M}_\mathrm{n}$，故 $\mathrm{d}(1/\bar{M}_\mathrm{n})/\mathrm{d}t \propto 1/\bar{M}_\mathrm{n}$。这给出 $1/\bar{M}_\mathrm{n}$ 的指数增长，即 $\ln\bar{M}_\mathrm{n}$ 线性下降。$\blacksquare$
:::

摩尔质量远在质量损失之前就已下降。PLA 器件在 $\bar{M}_\mathrm{n}$ 降到约 $2\times10^{4}$ 以下时失去大部分强度，外观却看似完好；只有当碎片短到能溶解（少于约十个单元的低聚物）时才失重。在厚器件中，自催化使内部——酸端基积聚之处——比表面——端基扩散出去之处——降解更快。大的 PLA 植入物因此可能从内部空掉（"不均匀的本体侵蚀"）。

::: example PLA 植入物降解多快？ {#ex-scission}
聚（L-丙交酯）制件（每个乳酸单元 $M_0 = 72.06\ \mathrm{g\,mol^{-1}}$）初始 $\bar{M}_\mathrm{n} = 1.00\times10^{5}\ \mathrm{g\,mol^{-1}}$，在 $37\ ^\circ\mathrm{C}$ 缓冲液中 30 天后为 $5.00\times10^{4}\ \mathrm{g\,mol^{-1}}$（示例数据）。假设随机、非自催化断链，求 $k$，并预言 90 天后的 $\bar{M}_\mathrm{n}$。届时每条原始链已断了几次？
::: solution
由[[#eq-scission]]：
$$
k = \frac{M_0}{t}\left(\frac{1}{\bar{M}_\mathrm{n}} - \frac{1}{\bar{M}_{\mathrm{n},0}}\right) = \frac{72.06}{30\ \mathrm{d}}\,(2.00\times10^{-5} - 1.00\times10^{-5}) = 2.4\times10^{-5}\ \mathrm{d^{-1}} .
$$
每个酯键每天被切断的概率约四万分之一。90 天后，$1/\bar{M}_\mathrm{n} = 1.00\times10^{-5} + 3\times1.00\times10^{-5} = 4.00\times10^{-5}$，所以 $\bar{M}_\mathrm{n} = 2.5\times10^{4}\ \mathrm{g\,mol^{-1}}$，$s = 10^{5}/2.5\times10^{4} - 1 = 3$，即每条原始链断三次。只切断了 $3/1388$ 的键（0.2%），摩尔质量却已降至四分之一。真实数据若显示首月之后速率翻倍，那就是自催化的信号。
:::
:::

### 可生物降解、可堆肥、生物基

::: warning "生物基""可生物降解""可堆肥"是三种不同的声明 {#warn-bio}
这三个词常被当作同义词使用，其实不然。**生物基**说的是碳的*来源*：来自玉米糖的 PLA，或来自甘蔗乙醇的生物聚乙烯。生物聚乙烯与化石基聚乙烯化学上完全相同，并不更容易降解。**可生物降解**说的是*归宿*：被微生物转化为 $\mathrm{CO_2}$（或 $\mathrm{CH_4}$）、水和生物质。不指明环境与时标，这个词毫无意义。**可堆肥**是在规定堆肥条件下经测试验证的生物降解声明。欧盟包装材料标准 EN 13432 要求（除其他指标外）在*工业*堆肥（约 $58\ ^\circ\mathrm{C}$）中六个月内至少 90% 生物降解、十二周内 90% 崩解。PLA 满足工业堆肥标准，但在家庭堆肥、土壤或海水中降解极慢，因为在低温下它是玻璃（$T_\mathrm{g} \approx 55$–$60\ ^\circ\mathrm{C}$），水渗进去很慢。细菌合成的聚羟基脂肪酸酯（如聚(3-羟基丁酸酯)）与一些脂肪族聚酯能在更多样的环境中降解。化石基聚酯（PBAT、PCL）可以是可堆肥的，而生物基的不一定。判断每个声明，都要对照其声称依据的标准。
:::

### 回收

让聚合物保持有用有四条路，按保有的价值递减排列。

- **材料回收**（物理回收）：分选、清洗、熔融、重新挤出。这是 PET 瓶与 HDPE 的主导路线。每过一轮，热与水解断链使链变短，并混入污染物与不相容的聚合物。按[[polymer-chemistry/polymer-solutions]]，不相容的共混物会分相而脆弱，所以品质逐轮下降（"降级回收"），除非物流纯净或加入相容化剂。
- **化学回收**：解聚为单体或低聚物。PET 经乙二醇解、甲醇解或水解转化（[[polymer-chemistry/step-growth#prop-equilibrium]]的逆过程），PMMA 与聚苯乙烯经越过其上限温度（[[polymer-chemistry/radical-polymerisation#prop-ceiling]]）的热解拉链式解聚，尼龙-6 回到己内酰胺。不能干净解拉链的聚烯烃被热解为油和气——这条高能耗路线的环境效益取决于产物替代什么。
- **酶法回收**：使用水解酶。2016 年 Yoshida 与合作者报道了*Ideonella sakaiensis*，其 PETase 与 MHETase 酶把 PET 分解为对苯二甲酸与乙二醇。2020 年 Tournier 与合作者报道了一种工程化的叶堆肥角质酶，十小时内解聚了 90% 的预处理 PET。酶对靠近其 $T_\mathrm{g}$、链段可动的无定形 PET 最有效。
- **面向回收的设计**：以单一材料包装取代层压复合材料，使用可去除的标签与黏合剂，以及可再加工的动态共价热固性树脂。

问题规模很大。按 2026 年可得的最新行业数据（Plastics Europe《Plastics – the fast Facts 2024》），2023 年全球塑料产量约 $414$ 百万吨，人均约 $50\ \mathrm{kg}$。OECD 的《Global Plastics Outlook》（2022）估计，2019 年产生的约 $353$ 百万吨塑料废物中，只有约 9% 被回收，约 19% 被焚烧，约 50% 进入卫生填埋，约 22% 管理不当（露天倾倒、露天焚烧或泄漏到环境中）。监管正在收紧。欧盟《单次使用塑料指令》（2019/904）为 PET 饮料瓶设定再生料含量目标（2025 年 25%，2030 年全部塑料瓶 30%），欧盟《包装与包装废物条例》（2025）进一步扩展再生含量与可回收性要求。自 2022 年起，一项具法律约束力的全球塑料条约在联合国环境规划署主持下谈判。其第五轮谈判分两部分举行（釜山，2024；日内瓦，2025），结束时未就案文达成一致。这些数字逐年变动，引用来源应查证有无更新。

::: history
Shirakawa（Hideki Shirakawa）、MacDiarmid（Alan MacDiarmid）与 Heeger（Alan Heeger）1977 年报道了高电导的碘掺杂聚乙炔，并因"发现和发展了导电聚合物"分享 2000 年诺贝尔化学奖。1990 年，剑桥的 Burroughes（Jeremy Burroughes）、Friend（Richard Friend）与合作者报道了聚(对苯撑乙烯撑)的电致发光（*Nature* 347, 539），聚合物 LED 由此发端。Heskins（Michael Heskins）与 Guillet（James Guillet）1968 年描述了 PNIPAM 水溶液的相变；Tanaka（Toyoichi Tanaka）自 1978 年起对凝胶体积相变的研究使响应性凝胶成为一个领域。聚乙醇酸合成可吸收缝线约 1970 年问世。Davis（Frank Davis）与 Abuchowski（Abraham Abuchowski）在 1970 年代开创蛋白质 PEG 化，首个 PEG 化药物 1990 年在美国获批。Langer（Robert Langer）与 Folkman（Judah Folkman）1976 年证明大分子可以从聚合物基体中长期释放，开创了控释给药。Leibler（Ludwik Leibler）课题组 2011 年引入类玻璃高分子（*Science* 334, 965）。Yoshida（Shosuke Yoshida）、Oda（Kohei Oda）与合作者 2016 年报道了降解 PET 的细菌*Ideonella sakaiensis*（*Science* 351, 1196）。
:::

## 后续内容

功能聚合物把整门课程汇于一身。合成依赖[[polymer-chemistry/controlled-polymerisation]]得到端基、嵌段与可降解主链。响应行为是[[polymer-chemistry/polymer-solutions]]的 Flory–Huggins 热力学，器件则依赖[[polymer-chemistry/polymer-properties]]的玻璃化转变、网络与黏弹性。可持续聚合物设计——生命周期评估、原子经济性、可再生原料与解聚催化——是[[green-chemistry]]的主题。共轭链的能带图像接上[[materials-chemistry]]，势箱中粒子的量子力学接上[[quantum-chemistry]]。药物释放所用的扩散方程在 Maths Atlas（[/learn/maths/](/learn/maths/)）中求解。

::: summary
- 共轭缩小 π–π* 间隙，但键交替（派尔斯畸变）使它保持在约 1.5 eV。自由电子模型趋势正确，长链失效。掺杂产生极化子与双极化子，重复单元带电达百分之几时 $\sigma = ne\mu$ 可达金属量级。应用包括 PEDOT:PSS、OLED、有机太阳电池与晶体管。
- LCST 要求混合焓与混合熵皆为负（$\chi = A + B/T$，$B < 0$、$A > \tfrac12$）。PNIPAM 通过疏水效应在 32 °C 附近塌缩。水凝胶是混合能与网络弹性的平衡（Flory–Rehner），聚电解质凝胶响应 pH 与盐。
- 形状记忆用 $T_\mathrm{g}$ 或 $T_\mathrm{m}$ 开关加熵回复。类玻璃高分子与动态共价网络靠键交换实现再加工与自修复。
- PEG 化延长药物循环时间。可降解聚酯（PGA、PLA、PLGA、PCL）的水解速率由结晶度与吸水决定。
- 基体释放是 Fick 型的，$M_t/M_\infty \approx 4(Dt/\pi L^2)^{1/2}$，时间 $\propto L^2$。储库型与表面侵蚀趋于零级释放。
- 随机断链给出 $1/\bar{M}_\mathrm{n} = 1/\bar{M}_{\mathrm{n},0} + kt/M_0$。强度远早于质量丧失，自催化使内部加速。
- 生物基、可生物降解、可堆肥（EN 13432）是互不相同的声明。按 2026 年数据，每年生产塑料约 414 Mt（2023 年数据），塑料废物仅约 9% 被回收（OECD，2019 年数据）。物理、化学、酶法回收的局限各植根于聚合物化学。
:::

药物从 $2.0\ \mathrm{mm}$ 厚的聚合物膜经两个表面扩散出来，$D = 1.0\times10^{-12}\ \mathrm{m^2\,s^{-1}}$。用[[#eq-release]]的短时形式估算 50% 释放所需时间。（以小时输入 $t_{1/2}$，保留三位有效数字。）
::: solution
$t_{1/2} = (0.125)^2\pi L^2/D = 0.015625\times3.1416\times4.0\times10^{-6}/1.0\times10^{-12} = 1.96\times10^{5}\ \mathrm{s} = 54.5\ \mathrm{h}$。与[[#ex-release]]相比：膜厚一倍（$\times4$），$D$ 大十倍（$\div10$），所以时间为原来的 $0.4$ 倍。
:::

::: exercise 降解速率常数 {level=3 check="0.000113"}
(a) 导出[[#eq-scission]]，说明所用假设。(b) 某 PLA 样品（$M_0 = 72.06\ \mathrm{g\,mol^{-1}}$）初始 $\bar{M}_\mathrm{n} = 8.0\times10^{4}$，8 周后为 $4.0\times10^{4}\ \mathrm{g\,mol^{-1}}$。求每周的 $k$。(c) 16 周的测量给出 $\bar{M}_\mathrm{n} = 1.5\times10^{4}$。降解是随机的还是自催化的？（以 $\mathrm{week^{-1}}$ 输入 $k$，保留三位有效数字。）
::: solution
(a) 见[[#prop-scission]]的证明。假设是所有主链键随机断裂、对键为一级、断裂键的分数很小、且样品中没有短链流失。每次断链增加一个分子，所以 $1/\bar{M}_\mathrm{n}$ 的增长等于单位质量中被切断的键的摩尔数 $kt/M_0$。

(b) $k = M_0(1/\bar{M}_\mathrm{n} - 1/\bar{M}_{\mathrm{n},0})/t = 72.06\times(2.5\times10^{-5} - 1.25\times10^{-5})/8 = 1.13\times10^{-4}\ \mathrm{week^{-1}}$。

(c) 随机模型预言 16 周时 $1/\bar{M}_\mathrm{n} = 1.25\times10^{-5} + 2\times1.25\times10^{-5} = 3.75\times10^{-5}$，即 $\bar{M}_\mathrm{n} = 2.7\times10^{4}$。实测的 $1.5\times10^{4}$ 低得多。自催化模型中 $\ln\bar{M}_\mathrm{n}$ 线性下降：8 周减半预言 16 周为 $2.0\times10^{4}$，接近但仍偏高。降解在加速，这与积聚的酸端基的自催化相符，也可能与聚合物失去结晶度或 $T_\mathrm{g}$ 下降后吸水增多有关。
:::

::: exercise 聚乙炔的掺杂水平 {level=3 check="0.116"}
碘掺杂聚乙炔薄膜的 $\sigma$ 已达约 $1.0\times10^{3}\ \mathrm{S\,cm^{-1}}$。设 $\mu = 1.0\ \mathrm{cm^2\,V^{-1}\,s^{-1}}$、密度 $1.16\ \mathrm{g\,cm^{-3}}$、每个载流子是链上一个正电荷并由一个 $\mathrm{I_3^-}$ 离子平衡，求带电 CH 单元的分数以及掺杂膜中碘的质量分数。评论结果。（输入带电分数，保留三位有效数字。）
::: hint
先求载流子浓度，再与 CH 单元密度比较。求质量分数时用 $\mathrm{(CH I_{3y})}_x$，$y$ 为带电分数。
:::
::: solution
$n = 1.0\times10^{3}/(1.602\times10^{-19}\times1.0) = 6.24\times10^{21}\ \mathrm{cm^{-3}}$。CH 单元：$5.37\times10^{22}\ \mathrm{cm^{-3}}$（见[[#ex-doping]]）。分数 $y = 6.24\times10^{21}/5.37\times10^{22} = 0.116$。每个 CH 单元带 $3y = 0.349$ 个碘原子，碘的质量分数为 $(0.349\times126.9)/(13.02 + 0.349\times126.9) = 44.3/57.3 = 0.77$。按质量算，"聚合物"膜的四分之三以上是碘。与其说这是轻掺杂半导体，不如说它是一种聚阳离子的盐——与硅不同，硅的掺杂剂只有百万分之几。掺杂还会使膜溶胀、改变链堆积，这是电导率如此强烈依赖加工工艺的原因之一。
:::
