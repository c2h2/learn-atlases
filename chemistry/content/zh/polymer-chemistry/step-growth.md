把己二酸与己烷-1,6-二胺共热，就得到一个酰胺，正如任何教科书里的酰胺成反应。但每个分子的两端都带*同一个*基团，所以每形成一个酰胺键，仍留下一个自由的酸端和一个自由的胺端，随时可以再次反应。二聚体连成四聚体，四聚体连成八聚体，链不断生长，直到官能团耗尽。1935 年 2 月，在杜邦公司华莱士·卡罗瑟斯（Wallace Carothers）的实验室里，这个反应得到了一种聚合物：它的熔体细丝可以在冷态下拉成比蚕丝更强的纤维——尼龙-6,6。其化学无非是[[organic-2/carboxylic-derivatives]]中缩合的重复，重复了几千次。把它变成聚合的，是一组苛刻的*统计*要求。要达到一百个单元的实用链长，99% 的官能团必须反应，两种单体的配料比必须精确到优于百分之一。聚酯、聚酰胺、聚氨酯、聚碳酸酯、环氧树脂以及第一种全合成塑料贝克莱特（Bakelite）都是用这种方法制造的。

本章讲的是**逐步**生长的聚合物。我们定义逐步聚合，并将其与链式聚合对照。我们推导 Carothers 方程，它解释了为什么只有在极高转化率下才达到高分子量，以及它对单体不等量情形的推广——这是工业上控制摩尔质量的实际手段。我们求聚酯化反应的动力学与 Flory 的等活性原理，并说明[[polymer-chemistry/polymer-structure#def-flory]]的 Flory 分布如何直接由统计得出。我们讨论平衡与副产物脱除的作用、主要的工业聚缩聚反应，最后看当一个单体带三个或更多官能团时会发生什么：支化、凝胶点，以及网络的诞生。

## 制造长链的两条路

1929 年，Carothers 把聚合物分为*缩聚*物（condensation，生成时失去水之类的小分子）与*加聚*物（addition，其重复单元与单体分子式相同）。这一分类讲的是化学计量，它把聚氨酯错分了——聚氨酯按缩聚型化学生长却不损失任何东西。对动力学与摩尔质量真正重要的分类是 Flory 的按*机理*分类。

::: definition 逐步聚合与链式聚合 {#def-step-growth}
在**逐步聚合**中，链通过体系中*任意*两个分子的官能团之间的反应生长：单体+单体、单体+低聚物、低聚物+低聚物。每个带官能团的分子都有反应性，而两个基团连接的速率常数（近似得很好）与携带它们的分子大小无关。单体很快消失，长链只在反应末期才出现。

在**链式聚合**中，单体一次一个单元地加到链端少数几个**活性中心**（自由基、离子或金属–碳键）上。单体与长链从一开始就共存，反应混合物由单体、完全长成的聚合物和极少量增长链组成。

放出小分子的逐步聚合是**聚缩聚**（聚酯、聚酰胺），不放出的是**聚加成**（二异氰酸酯与二醇生成聚氨酯、环氧化物与胺生成环氧树脂）。
:::

使用两类单体。**A–B 型单体**在同一分子上带两个基团，例如羟基酸 $\mathrm{HO{-}R{-}COOH}$ 或氨基酸。这里化学计量平衡是自动的。**A–A + B–B 配对**，如二醇加二酸或二胺加二酰氯，则要求两组分精确称量。无论哪种情形，重复单元都包含 A 与 B 残基经新键相连。

两种机理的反差在取半转化率的样品时看得最清楚。苯乙烯的链式聚合在 50% 转化率时，一半质量是单体，另一半是 $\bar{X}_\mathrm{n}$ 达数千的聚苯乙烯。而官能团 50% 转化率的逐步聚酯化几乎没有单体剩下，平均分子是一个**二聚体**。下一节把这变成一个方程。

## Carothers 方程

追踪*分子的数目*。A 基团与 B 基团之间的每一个新连接都把两个分子并为一个，所以每形成一个键，分子数减一。数键是容易的，因为它就是数已反应的官能团。

::: definition 反应程度 {#def-extent}
逐步聚合的**反应程度** $p$ 是给定类型（按惯例取少数类型 A）的官能团中已反应的分数：
$$
p = \frac{N_0 - N}{N_0},
$$
其中 $N_0$ 与 $N$ 是初始与 $t$ 时刻 A 基团的数目。它通过滴定剩余的酸或胺基团来测量，或用光谱法。
:::

::: proposition Carothers 方程 {#prop-carothers}
对于 A 与 B 基团**恰好等量**（或 A–B 单体）的双官能团单体线性逐步聚合，反应程度为 $p$ 时的数均聚合度为
$$
\bar{X}_\mathrm{n} = \frac{1}{1-p}.
$$ {#eq-carothers}
若 B 基团过量，**化学计量比**为 $r = N_\mathrm{A}/N_\mathrm{B} \le 1$，且 $p$ 是 A 的反应程度，则
$$
\bar{X}_\mathrm{n} = \frac{1 + r}{1 + r - 2rp},
\qquad\text{于是}\qquad
\bar{X}_\mathrm{n}(p \to 1) = \frac{1+r}{1-r}.
$$ {#eq-carothers-r}
这里 $\bar{X}_\mathrm{n}$ 数的是**结构单元**（单体残基）。对 A–A + B–B 聚合物，每个重复单元含两个结构单元。这些方程假定无环化、无副反应，且每个反应都连接两个独立的分子。
:::

::: proof
从 $N_\mathrm{A}$ 个 A 基团与 $N_\mathrm{B} = N_\mathrm{A}/r$ 个 B 基团出发，它们载于双官能团分子上。初始分子数是基团总数除以二：
$$
N_\text{mol,0} = \frac{N_\mathrm{A} + N_\mathrm{B}}{2} = \frac{N_\mathrm{A}}{2}\left(1 + \frac{1}{r}\right).
$$
在反应程度 $p$ 时形成了 $pN_\mathrm{A}$ 个连接。每个连接恰好使分子数减一（它连接两个分子，因为闭成一个环的连接不会，而环已被排除）。基团总数不变，所以剩余的分子数为
$$
N_\text{mol} = \frac{N_\mathrm{A}}{2}\left(1 + \frac{1}{r}\right) - pN_\mathrm{A}
= \frac{N_\mathrm{A}}{2}\left(1 + \frac{1}{r} - 2p\right).
$$
每个单体分子成为一个结构单元，所以 $\bar{X}_\mathrm{n}$ 是结构单元数除以分子数，即 $N_\text{mol,0}/N_\text{mol}$：
$$
\bar{X}_\mathrm{n} = \frac{1 + 1/r}{1 + 1/r - 2p} = \frac{1 + r}{1 + r - 2rp}.
$$
$r = 1$ 时这就是 $2/(2 - 2p) = 1/(1-p)$，即 Carothers 方程。$p \to 1$ 时每个 A 基团都已反应，$\bar{X}_\mathrm{n} \to (1+r)/(1-r)$。此时每条链的两端都被未反应的 B 基团封住，不能再增长。$\blacksquare$
:::

[[#eq-carothers]]是高分子化学最重要的结果之一，而它的推论是严酷的：

| 反应程度 $p$ | $0.50$ | $0.90$ | $0.95$ | $0.99$ | $0.995$ | $0.999$ |
|---|---|---|---|---|---|---|
| $\bar{X}_\mathrm{n} = 1/(1-p)$ | $2$ | $10$ | $20$ | $100$ | $200$ | $1000$ |

90% 的转化率在小分子合成里是很好的产率，这里却只给出十聚体——毫无力学价值的油性低聚物。工程聚缩聚物需要 $\bar{X}_\mathrm{n}$ 为 100–200，也就是 **99–99.5%** 的转化率。要达到它，反应必须基本没有副反应（每个副反应破坏一个官能团，也就封住一条链），单体必须很纯（单官能团杂质就是链终止剂），化学计量必须精确。

::: example 聚酯化必须进行到什么程度？ {#ex-carothers}
一种聚酯由等摩尔的二醇与二酸制成。(a) 要达到 $\bar{X}_\mathrm{n} = 150$ 个结构单元，反应程度需多大？(b) 那时原始酸基团有多大分数尚未反应？(c) 若反应在 $p = 0.95$ 处停止，$\bar{X}_\mathrm{n}$ 是多少？
::: solution
(a) 由[[#eq-carothers]]，$1 - p = 1/\bar{X}_\mathrm{n} = 1/150 = 0.00667$，所以 $p = 0.9933$。

(b) 未反应分数为 $1 - p = 0.0067$：酸基团的三分之二个百分点。聚缩聚结束时，官能团是自身聚合物中的痕量杂质。

(c) $\bar{X}_\mathrm{n} = 1/(1 - 0.95) = 20$。把转化率从 95% 提高到 99.3%，链长增为 7.5 倍。最后那几个百分点的转化率才是制造聚合物的地方。
:::
:::

### 用化学计量控制摩尔质量

链在熔体里不断生长的聚酰胺，在挤出机里的黏度会一直变，所以工业上*有意*限制 $\bar{X}_\mathrm{n}$。办法有两个。一个是让某个双官能团单体稍微过量。另一个是加少量**单官能团**试剂，如尼龙生产中的乙酸，它把链永久封端。只要 $r$ 定义得当，两者都归入[[#eq-carothers-r]]。对等量的 A–A 与 B–B 加入 $N_\mathrm{B'}$ 个单官能团 B 试剂时，
$$
r = \frac{N_\mathrm{A}}{N_\mathrm{B} + 2N_\mathrm{B'}} .
$$
因子 2 是因为一个单官能团分子与一个过量的*双官能团* B–B 分子封链的效果相同，后者封住一个链端却在计数中贡献两个 B 基团。

::: example 限定尼龙-6,6 的摩尔质量 {#ex-nylon-cap}
某厂商想在少数基团完全转化时得到 $\bar{M}_\mathrm{n} = 2.00\times10^{4}\ \mathrm{g\,mol^{-1}}$ 的尼龙-6,6。重复单元 $-\mathrm{NH(CH_2)_6NH{-}CO(CH_2)_4CO}-$，$\mathrm{C_{12}H_{22}N_2O_2}$，$M = 226.32\ \mathrm{g\,mol^{-1}}$。需要什么化学计量比？对应己二酸百分之几的过量？忽略端基。
::: solution
每个重复单元含两个结构单元，所以结构单元的平均质量为 $M_0 = 226.32/2 = 113.16\ \mathrm{g\,mol^{-1}}$，
$$
\bar{X}_\mathrm{n} = \frac{2.00\times10^{4}}{113.16} = 176.7 .
$$
在 $p \to 1$ 时 $\bar{X}_\mathrm{n} = (1+r)/(1-r)$。解出 $r$：
$$
r = \frac{\bar{X}_\mathrm{n} - 1}{\bar{X}_\mathrm{n} + 1} = \frac{175.7}{177.7} = 0.9887 .
$$
以二胺为少数组分，$N_\text{diacid}/N_\text{diamine} = 1/r = 1.0114$：己二酸**摩尔过量 1.14%**。所要求的精度惊人。称量中一个半百分点的意外误差，就会使最终 $\bar{M}_\mathrm{n}$ 偏移几十个百分点。这就是尼龙-6,6 要用**尼龙盐**（己二酸六亚甲基二铵）来合成的原因。这种 1 : 1 的盐从水中结晶出来，化学计量与生俱来，聚合前还可检验其在等当点的 pH。选定的过量剂或端基封端剂随后再有意加入。
:::
:::

## 动力学与等活性原理

逐步聚合包含成千上万的物种：单体、二聚体、三聚体、……，每一个都与其余每一个反应。若每一对都要一个速率常数，动力学就没法做了。Flory 的洞见——他在 1936 年起的一系列论文中用实验证据为之辩护——是这种复杂性并非真实存在。

::: definition 等活性原理 {#def-equal-reactivity}
**等活性原理**（Flory）指出：一个官能团的本征反应性与它所连分子的大小无关。酸端与醇端反应的速率常数，无论这两个端属于单体还是百聚体，都是一样的。这是一个近似，在链长过几个单元之后、介质变化不大时成立；对同系列的头一两个成员，以及链端扩散成为限制因素时，它失效。
:::

为什么一个大而慢的分子会像一个小分子那样快？大分子整体扩散慢，所以它遇到其他分子的次数更少。但一旦两个端基彼此接近，它们就会靠近更久，在扩散开之前经历许多次碰撞：**笼效应**。两个因素相消。决定速率的是链端的局部迁移率，它来自几个键范围内的链段运动，与整条链的长度无关。Flory 用同系酸 $\mathrm{H(CH_2)_nCOOH}$ 与二酸的酯化速率支持了这一原理。$n \approx 3$ 之后，速率常数实质上与 $n$ 无关。

有了等活性，一场包含成千上万物种的聚合坍缩为*一对*官能团的动力学。聚酯化是酸催化的，于是出现两种情形。

::: proposition 聚酯化的速率方程 {#prop-polyester-kinetics}
设 $c = [\mathrm{COOH}] = [\mathrm{OH}]$（化学计量混合物），初值为 $c_0$，于是 $c = c_0(1-p)$。假定等活性且逆反应被抑制（水被脱除）。则：

1. **自催化**（二酸自身是催化剂，速率 $= k[\mathrm{COOH}]^2[\mathrm{OH}]$，总级数三）：
$$
\frac{1}{(1-p)^2} = 2c_0^2kt + 1,
\qquad\text{即}\qquad \bar{X}_\mathrm{n}^2 = 1 + 2c_0^2kt .
$$ {#eq-self-cat}
2. **外催化**（强酸催化剂浓度恒定，速率 $= k'[\mathrm{COOH}][\mathrm{OH}]$，总级数二）：
$$
\frac{1}{1-p} = c_0k't + 1,
\qquad\text{即}\qquad \bar{X}_\mathrm{n} = 1 + c_0k't .
$$ {#eq-ext-cat}
:::

::: proof
自催化的情形，一个酸基团反应、第二个充当催化剂，所以
$$
-\frac{\mathrm{d}c}{\mathrm{d}t} = k c^2 \cdot c = kc^3 .
$$
分离变量，$-\int_{c_0}^{c} c^{-3}\,\mathrm{d}c = kt$，得 $\tfrac12(c^{-2} - c_0^{-2}) = kt$。代入 $c = c_0(1-p)$ 并乘以 $2c_0^2$：
$$
\frac{1}{(1-p)^2} - 1 = 2c_0^2kt .
$$
外催化的情形，催化剂浓度折入 $k'$，所以 $-\mathrm{d}c/\mathrm{d}t = k'c^2$，$c^{-1} - c_0^{-1} = k't$。乘以 $c_0$ 得 $1/(1-p) - 1 = c_0k't$。在等活性之下，这些是*官能团*的速率方程，无论基团分布在哪些分子上都成立。把它们与 Carothers 方程 $\bar{X}_\mathrm{n} = 1/(1-p)$ 结合，就变成上面陈述的生长规律。$\blacksquare$
:::

实际差别很大。有外催化剂时，$\bar{X}_\mathrm{n}$ 随时间*线性*生长。没有催化剂时，它只按 $t^{1/2}$ 生长，因为催化剂正是酸基团，而它们正在消失。自催化聚合因此恰在需要加速的时候放慢。这就是聚酯化要加催化剂的原因（实验室用强酸，工业上用锑、钛或锡的金属化合物）。Flory 自己的己二酸与二甘醇的数据，从 $p \approx 0.8$ 到 $p = 0.99$ 都线性地服从[[#eq-ext-cat]]。$p \approx 0.8$ 以下图线弯曲，因为混合物从极性的酸–醇混合变成了聚酯介质。这是一个提醒：等活性假定*介质*保持不变。

::: example 跟踪一场酸催化聚酯化 {#ex-kinetics}
二醇与二酸在熔体中加成量的强酸催化剂聚合，$c_0 = [\mathrm{COOH}]_0 = 5.0\ \mathrm{mol\,dm^{-3}}$，水连续脱除。滴定显示 $200\ \mathrm{min}$ 后反应程度 $p = 0.9756$（$\bar{X}_\mathrm{n} = 41$）。数字是示意的，但量级真实。(a) 求 $k'$。(b) 达到 $\bar{X}_\mathrm{n} = 100$ 需多长时间？(c) 若反应是自催化的，同样在 200 min 达到 $\bar{X}_\mathrm{n} = 41$，$\bar{X}_\mathrm{n} = 100$ 需要多久？
::: solution
(a) 由[[#eq-ext-cat]]，$\bar{X}_\mathrm{n} - 1 = c_0k't$，所以
$$
k' = \frac{41 - 1}{(5.0\ \mathrm{mol\,dm^{-3}})(200\ \mathrm{min})} = 0.040\ \mathrm{dm^{3}\,mol^{-1}\,min^{-1}} .
$$
(b) $t = (100 - 1)/(c_0k') = 99/(0.20\ \mathrm{min^{-1}}) = 495\ \mathrm{min}$，约 8.3 h。

(c) 自催化时 $\bar{X}_\mathrm{n}^2 - 1 \propto t$。时间之比为 $(100^2 - 1)/(41^2 - 1) = 9999/1680 = 5.95$，所以 $t = 5.95 \times 200 = 1.19\times10^{3}\ \mathrm{min}$，约 20 h，而用催化剂只要 8.3 h。两个速率方程在 200 min 处被凑成一致，但超过那一点之后，平方根规律越落越远，而且目标链长每增加一分，差距就加大一分。
:::
:::

## 摩尔质量分布

等活性同时也决定了链长的*分布*。[[polymer-chemistry/polymer-structure#def-flory]]引入的最可几分布，正是理想线性逐步聚合的精确结果。

::: proposition 线性聚缩聚物的 Flory 分布 {#prop-flory-dist}
对服从等活性、无环化、官能团化学计量的线性逐步聚合，反应程度 $p$ 时含 $x$ 个结构单元的分子的数分数为
$$
N_x = (1-p)\,p^{x-1},
$$
质量分数为 $W_x = x(1-p)^2p^{x-1}$。于是 $\bar{X}_\mathrm{n} = 1/(1-p)$，$\bar{X}_\mathrm{w} = (1+p)/(1-p)$，$Đ = 1 + p$。
:::

::: proof
取 A–B 聚合，它使记账最简单。A–A + B–B 情形按结构单元给出相同结果。随机取一个分子，从它未反应的 A 端开始。沿链往前走：第一个单元的 B 基团要么已反应（概率 $p$），链就续到第二个单元；要么未反应（概率 $1 - p$），分子就到此为止。由等活性，任一给定基团已反应的概率都是 $p$，且与其他每个基团的状态独立。所以恰含 $x$ 个单元的分子要求 $x - 1$ 个已反应的连接，后面跟一个未反应的末端：
$$
N_x = p^{x-1}(1-p) .
$$
平均值与分散度由[[polymer-chemistry/polymer-structure#prop-flory-averages]]中计算的矩得出。作为一致性检验，$\bar{X}_\mathrm{n} = 1/(1-p)$ 再现了 Carothers 方程——它是由另一套论证（数键）导出的，本来就该如此。$\blacksquare$
:::

Flory 分布是高分子化学家的基准线。高转化率下制得的逐步聚合物 $Đ \approx 2$，测得的分散度远离 2 就说明发生了非理想的事。远高于 2 的分散度指向支化或反应性变化。低于 2 的指向后处理中的分级损失（洗涤损失了短链），或指向某种链式特征，如某些现代催化转移聚缩聚。

### 环

每个 A–B 链端都可以与*自己的*另一端反应，生成环而不是更长的链。分子内环化与分子间生长竞争。其概率随环长衰减的方式，是无规线团两端相遇的概率 $\propto x^{-3/2}$（Jacobson 与 Stockmayer，1950），且与浓度无关，而分子间反应正比于浓度。所以在熔体中或高浓度下操作可抑制环。环无法完全消除：商品 PET 含约 1–2 质量% 的环状低聚物，主要是环三聚体。反过来，稀释是制备大环化合物的经典路线。

## 平衡与副产物的脱除

聚缩聚是平衡。酸与醇的酯化平衡常数量级为一，聚酯的每个连接亦然。

::: proposition 平衡对链长的限制 {#prop-equilibrium}
对聚缩聚 $\mathrm{A} + \mathrm{B} \rightleftharpoons \text{link} + \mathrm{W}$，平衡常数 $K = [\text{link}][\mathrm{W}]/([\mathrm{A}][\mathrm{B}])$，假定等活性、官能团化学计量、初始浓度 $c_0$：

1. **封闭体系**（副产物 $\mathrm{W}$ 保留，$[\mathrm{W}] = [\text{link}] = c_0p$），
$$
\bar{X}_\mathrm{n} = 1 + \sqrt{K};
$$ {#eq-closed}
2. **开放体系**，通过脱除把 $\mathrm{W}$ 维持在低浓度 $[\mathrm{W}]$，
$$
\bar{X}_\mathrm{n} \approx \left(\frac{Kc_0}{[\mathrm{W}]}\right)^{1/2} \qquad (p \to 1).
$$ {#eq-open}
:::

::: proof
平衡时 $[\text{link}] = c_0p$，$[\mathrm{A}] = [\mathrm{B}] = c_0(1-p)$。所以
$$
K = \frac{c_0p\,[\mathrm{W}]}{c_0^2(1-p)^2} = \frac{p\,[\mathrm{W}]}{c_0(1-p)^2}.
$$
封闭体系中 $[\mathrm{W}] = c_0p$，所以 $K = p^2/(1-p)^2$，$p/(1-p) = \sqrt{K}$。由 $\bar{X}_\mathrm{n} = 1/(1-p)$ 及 $p/(1-p) = \bar{X}_\mathrm{n} - 1$，即得 $\bar{X}_\mathrm{n} = 1 + \sqrt{K}$。开放体系中，解出 $(1-p)^{-2} = \bar{X}_\mathrm{n}^2 = Kc_0/(p[\mathrm{W}])$，取 $p \to 1$ 即得[[#eq-open]]。$\blacksquare$
:::

封闭体系的结果令人清醒。$K \approx 1$–$10$ 时，密闭容器里的聚酯化停在 $\bar{X}_\mathrm{n} \approx 2$–$4$。聚酯之所以可能制成，全靠把水（或甲醇、乙二醇）不断赶出去。做法是在高真空下加热到 $250\ ^\circ\mathrm{C}$ 以上，用薄膜或强烈搅拌更新表面，因为反应末期副产物必须从一个极黏的熔体里逸出。聚酰胺宽容得多（$K$ 达几百）。平衡也会倒退着走：受热受潮存放的 PET 瓶会缓慢水解，而 PET 经醇解或甲醇解回到单体则是*化学*回收的基础——被有意利用的逆反应。

::: example 聚酯熔体要多干才行？ {#ex-equilibrium}
某聚酯化 $K = 1$（量级正确的示意值），熔体中各基团 $c_0 = 5.0\ \mathrm{mol\,dm^{-3}}$。(a) 密闭容器能达到多少 $\bar{X}_\mathrm{n}$？(b) 要达到 $\bar{X}_\mathrm{n} = 100$，水必须降到什么浓度？
::: solution
(a) [[#eq-closed]]：$\bar{X}_\mathrm{n} = 1 + \sqrt{1} = 2$，此时 $p = 0.5$。在密闭管里，"聚合物"是一个二聚体。

(b) 由证明中的精确关系，$1 - p = 0.01$ 时 $[\mathrm{W}] = Kc_0(1-p)^2/p$：
$$
[\mathrm{W}] = \frac{(1)(5.0)(0.01)^2}{0.99}\ \mathrm{mol\,dm^{-3}} = 5.1\times10^{-4}\ \mathrm{mol\,dm^{-3}} .
$$
这大约是每 $\mathrm{dm^3}$ 熔体 $9\ \mathrm{mg}$ 水，按质量计约十 ppm。水必须脱除到比反应开始时官能团浓度低一万倍。真空、高温与表面更新不是可选的精饰。
:::
:::

## 工业逐步聚合

同样的算术支配着每一场大规模聚缩聚。

- **聚对苯二甲酸乙二酯**（PET），瓶与纺织纤维用的聚酯，由对苯二甲酸（或其二甲酯）与过量的乙烷-1,2-二醇（乙二醇）制成。酯化或酯交换阶段给出对苯二甲酸双(2-羟乙基)酯及其低聚物。随后的聚缩聚阶段在约 $280\ ^\circ\mathrm{C}$、真空下经酯交换把它们连接起来，蒸出被除去的乙二醇。从一开始就用过量二醇并随后蒸出它，就绕开了化学计量问题：随着乙二醇被拉出，反应自动配平。
- **聚酰胺。**尼龙-6,6 由其盐（[[#ex-nylon-cap]]）制成；尼龙-6 由己内酰胺开环制得——尽管产物看起来像聚缩聚物，那却是链式过程。芳香族聚酰胺（芳纶，如由苯-1,4-二胺与对苯二甲酰氯制成的 Kevlar）在低温下用反应性很强的酰氯在溶液中聚合。
- **聚碳酸酯。**双酚 A 聚碳酸酯传统上用光气（剧毒气体，只在密闭工业装置中处理）经界面反应制造。现在越来越多地改用无光气的熔融酯交换，以碳酸二苯酯为原料，副产苯酚。
- **聚氨酯**是二异氰酸酯（如二苯基甲烷二异氰酸酯，MDI）与二醇或聚醚多元醇的聚加成。没有副产物生成，所以无须驱赶平衡。异氰酸酯是强烈的呼吸道致敏剂，须以工程控制处理。水与异氰酸酯反应放出 $\mathrm{CO_2}$，在泡沫中被有意用作发泡剂。
- **环氧树脂与酚醛树脂**使用官能度大于二的单体，并被设计成要*凝胶化*。它们是下一节的主题。

逐步聚合的经典教学演示是**界面"尼龙绳魔术"**：把癸二酰二氯的有机溶液铺在己烷-1,6-二胺的水溶液之上，尼龙-6,10 就在界面生成一层膜，可以连续拉成绳子。它之所以奏效，是因为酰氯太活泼，聚合物只在两种试剂相遇之处生成，而界面恰好以相等的量提供两者。这就是靠扩散实现的化学计量平衡。酰氯有腐蚀性与催泪性，二胺有腐蚀性，溶剂易燃。与一切实践操作一样，必须在通风橱中进行，戴护目镜与手套，有人指导，并作风险评估。

::: warning 不要把两个单体的"产率"加起来 {#warn-yield}
受小分子训练的化学家常以分离产率评价逐步聚合："聚酯产率 92%"。产率度量的是回收的*物料*多少，对链有多长只字未提。92% 的*反应程度*只给出 $\bar{X}_\mathrm{n} = 12.5$——即使每克都回收了，那也是低聚物。反过来，一个达到 $p = 0.995$ 的反应，经过滤洗涤的损失后也能以 60% 的产率分离出聚合物。要报告和设计的是 $p$，或者最好是直接测得的 $\bar{X}_\mathrm{n}$。还要记住：1% 的化学计量误差不等于产物有 1% 的误差。由[[#eq-carothers-r]]，它把 $\bar{X}_\mathrm{n}$ 封顶在 199，无论等多久。
:::

## 支化、凝胶化与网络

到此为止每个单体恰好两个官能团。引入一个带三个官能团的单体——如聚酯中的甘油（丙三醇）或环氧树脂中的三胺——每个反应了的三官能团单元都是一个**支化点**。随着反应进行，支化分子并成更大的支化分子，并在一个界限分明的反应程度处，出现一个跨越整个容器的单一分子。这就是**凝胶点**。黏度发散，混合物停止流动，材料变成溶胀而不溶解的弹性固体。凝胶点之后，**凝胶分数**（不溶网络）以**溶胶**（可溶支化分子）为代价增长。

::: definition 平均官能度与凝胶点 {#def-gel}
单体混合物的**平均官能度**是每个单体分子的官能团数，对所有分子计数，
$$
f_\mathrm{av} = \frac{\sum_i N_if_i}{\sum_i N_i},
$$
即官能度为 $f_i$ 的分子有 $N_i$ 个，适用于 A 与 B 基团化学计量平衡的混合物。**凝胶点**是无限（跨越样品）网络首次形成时的反应程度 $p_\mathrm{c}$，其标志是 $\bar{X}_\mathrm{w}$ 发散。
:::

两个经典理论预言 $p_\mathrm{c}$，二者之差颇有启发。

**Carothers 的论证**推广了[[#prop-carothers]]的计数。$N_0$ 个分子带 $N_0f_\mathrm{av}$ 个基团，$p$ 为已反应基团的分数，则连接数为 $N_0f_\mathrm{av}p/2$（每个连接用两个基团）。若每个连接都连接两个独立分子，分子数为 $N = N_0 - N_0f_\mathrm{av}p/2$，于是
$$
\bar{X}_\mathrm{n} = \frac{N_0}{N} = \frac{2}{2 - pf_\mathrm{av}} .
$$ {#eq-carothers-gel}
令 $\bar{X}_\mathrm{n} \to \infty$ 得 **Carothers 凝胶点** $p_\mathrm{c} = 2/f_\mathrm{av}$。它*高估*了 $p_\mathrm{c}$，因为凝胶点是 $\bar{X}_\mathrm{w}$ 发散之处，而这远早于 $\bar{X}_\mathrm{n}$ 发散。凝胶点处的网络是一个巨大分子，周围围着许多小分子。它的质量支配重均，在数均里却只计一次。

**Flory 与 Stockmayer** 把问题作为分支过程作统计处理。

::: proposition Flory–Stockmayer 凝胶点 {#prop-flory-stockmayer}
设**支化系数** $\alpha$ 为支化单元（官能度 $f > 2$）上一个给定官能团经一串双官能团单元连到另一个支化单元的概率。假定等活性且无分子内反应。则无限网络在
$$
\alpha_\mathrm{c} = \frac{1}{f-1}
$$ {#eq-alpha-c}
时形成。对所有 A 基团都在 $f$ 官能度单元上、所有 B 基团都在双官能团单元上的混合物，化学计量比 $r = N_\mathrm{A}/N_\mathrm{B}$，A 的反应程度为 $p_\mathrm{A}$，则
$$
\alpha = p_\mathrm{A}p_\mathrm{B} = rp_\mathrm{A}^2,
\qquad\text{于是}\qquad
p_{\mathrm{A,c}} = \frac{1}{\sqrt{r(f-1)}} .
$$ {#eq-fs-pc}
:::

::: proof
从一个支化单元出发，沿它的一个基团向外走。这条路以概率 $\alpha$ 到达另一个支化单元。该单元还有 $f - 1$ 个其余基团（有一个用于到达），其中每个又以概率 $\alpha$ 独立地通向一个支化单元——依据等活性与无环。于是相继"代"中到达的支化单元数是一个分支（Galton–Watson）过程，每个单元平均有 $\alpha(f-1)$ 个子代。若 $\alpha(f-1) < 1$，第 $n$ 代的期望大小 $[\alpha(f-1)]^n$ 趋于零，每个分子都有限。若 $\alpha(f-1) > 1$，期望的代数大小无界增长，且以非零概率这条路永不断头：存在无限网络。阈值是 $\alpha_\mathrm{c}(f-1) = 1$。

对 $\mathrm{A}_f + \mathrm{B}_2$ 体系：从支化单元上的 A 出发的路要继续，须该 A 已反应（概率 $p_\mathrm{A}$，与一个 B 反应）。这个 B 属于一个 B–B 单体，它的另一个 B 以概率 $p_\mathrm{B}$ 已反应。若已反应，它就与一个 A 相连，而每个 A 都在支化单元上。所以 $\alpha = p_\mathrm{A}p_\mathrm{B}$。从任一侧数的连接数相同，$p_\mathrm{A}N_\mathrm{A} = p_\mathrm{B}N_\mathrm{B}$，所以 $p_\mathrm{B} = rp_\mathrm{A}$，$\alpha = rp_\mathrm{A}^2$。令其等于 $1/(f-1)$ 即得[[#eq-fs-pc]]。$\blacksquare$
:::

f: r*x^2; 1/(fn-1)
x: 0, 1
y: 0, 1
sliders: r=1:0.5:1:0.01; fn=3:3:6:1
labels: \text{支化系数}\ \alpha = rp_\mathrm{A}^2; \text{临界值}\ 1/(f-1)
caption: $\mathrm{A}_f + \mathrm{B}_2$ 混合物的 Flory–Stockmayer 凝胶化（[[#prop-flory-stockmayer]]）。抛物线是支化系数 $\alpha = rp_\mathrm{A}^2$ 随反应程度 $p_\mathrm{A}$ 的曲线。水平线是临界值 $1/(f-1)$，凝胶点就是二者相交处。$f = 3$、$r = 1$ 时，凝胶化在 $p_\mathrm{A} = 1/\sqrt{2} = 0.707$ 发生。增大 $f$，凝胶点提前，因为每个支化单元更多的臂意味着更多通往无穷的路。降低 $r$（B 过量）则推后。$r < 1/(f-1)$ 时两线永不相交：B–B 足够过量，混合物就永不凝胶——这是一条有意用来制造可溶支化树脂的规则。
:::

::: example 甘油–邻苯二甲酸树脂的凝胶点 {#ex-gel}
一种醇酸型树脂由甘油（$f = 3$）与苯-1,2-二羧酸（邻苯二甲酸，$f = 2$）按化学计量比 $2 : 3$（OH 与 COOH 数目相等）制成。用 (a) Carothers 方法与 (b) Flory–Stockmayer 方法预言凝胶点的反应程度，并解释真实凝胶点落在何处。
::: solution
(a) 取 2 mol 甘油与 3 mol 邻苯二甲酸：$f_\mathrm{av} = (2\times3 + 3\times2)/(2 + 3) = 12/5 = 2.4$。Carothers 凝胶点为 $p_\mathrm{c} = 2/f_\mathrm{av} = 2/2.4 = 0.833$。

(b) 所有 OH 都在三官能度的甘油上，所有 COOH 都在双官能度的酸上，$r = 6/6 = 1$，所以[[#eq-fs-pc]]给出 $p_\mathrm{c} = 1/\sqrt{1\times(3-1)} = 1/\sqrt{2} = 0.707$。

两个预言把实验凝胶点夹在中间：此类体系中实验值略*高于* Flory–Stockmayer 值，远低于 Carothers 值。Carothers 偏高，因为凝胶化是 $\bar{X}_\mathrm{w}$ 而不是 $\bar{X}_\mathrm{n}$ 的发散。Flory–Stockmayer 略低，因为真实体系把一些连接浪费在分子内环上，而[[#prop-flory-stockmayer]]假定没有环。一个环消耗两个基团却不连接两个分子，所以需要更多的反应才能到达网络。实际中醇酸树脂在凝胶点之前停下，此时它尚可加工；涂覆之后它才凝胶（固化）。
:::
:::

凝胶点是热固性塑料制造的定义性事件。**环氧树脂**（双酚 A 二缩水甘油醚，用多官能度胺固化）、**酚醛树脂**（贝克莱特，其中甲醛在三个位置连接苯酚环）、**不饱和聚酯**与**聚氨酯**网络，其配方都设计成混合与模塑时是流体、在模具中越过凝胶点。此后无法再成形——这既是热固性塑料如此耐久的原因，也是它们难以回收的原因。

::: quiz
一位化学家做等摩尔二醇–二酸聚酯化，在酸基团 95% 转化率处停止，然后加入 1 mol%（相对于二酸）的苯甲酸，再把反应推进到底。哪个说法正确？
- [ ] 最终 $\bar{X}_\mathrm{n}$ 是 20，因为它在停止反应时就已固定。
- [x] 最终 $\bar{X}_\mathrm{n}$ 受单官能团酸限制：$r = N_\mathrm{A}/(N_\mathrm{B} + 2N_\mathrm{B'})$ 接近 0.99，完全转化时 $\bar{X}_\mathrm{n}$ 趋于约 200。
- [ ] 苯甲酸没有作用，因为单官能团试剂不能连接两条链。
- [ ] 苯甲酸引起凝胶化，因为它改变了平均官能度。
::: solution
第二个选项。逐步聚合暂停时并不会"冻结"：剩余的基团会恢复反应。单官能团酸把链端永久封住，在[[#eq-carothers-r]]中表现为 $r = N_\mathrm{OH}/(N_\mathrm{COOH} + 2N_\text{PhCOOH})$。苯甲酸相对二酸为 1 mol% 时，$N_\text{PhCOOH}/N_\mathrm{COOH} = 0.005$，所以 $r = 1/1.01 = 0.990$，$\bar{X}_\mathrm{n}(p \to 1) = (1+r)/(1-r) = 201$。单官能团试剂使平均官能度降到 2 以下，这是阻止而非促成凝胶化。
:::
:::

I. ## 后续内容

链式聚合——通往长链的另一条路——在[[polymer-chemistry/radical-polymerisation]]中展开。那里的动力学图像完全不同（从第一刻起就有高聚物），但 Flory 分布会以新面目重现。内酰胺、内酯与丙交酯的开环聚合——以链式方式给出"缩聚型"聚合物——出现在[[polymer-chemistry/controlled-polymerisation]]。网络在[[polymer-chemistry/polymer-properties]]中回归，那里橡胶弹性把交联密度与模量联系起来；也在[[polymer-chemistry/functional-polymers]]中回归，那里可逆（动态共价）连接让网络得以再加工，聚乳酸之类的聚酯被设计成可降解。酯、酰胺与酰氯的机理化学在[[organic-2/carboxylic-derivatives]]。[[#prop-equilibrium]]中的平衡是[[thermodynamics]]中处理的一般化学平衡。

::: summary
- 逐步聚合连接*任意*两个分子上的官能团。单体早早消失，高聚物在最后一刻才形成。链式聚合把单体加到少数活性中心上，从一开始就给出高聚物。
- 数键得到 Carothers 方程 $\bar{X}_\mathrm{n} = 1/(1-p)$：$\bar{X}_\mathrm{n} = 100$ 需要 99% 转化率。化学计量比为 $r$ 时 $\bar{X}_\mathrm{n} = (1+r)/(1+r-2rp) \to (1+r)/(1-r)$，用它以轻微过量或单官能团试剂给摩尔质量封顶。
- 等活性（Flory）把动力学化为单一的官能团速率方程。外催化聚酯化给出 $\bar{X}_\mathrm{n} = 1 + c_0k't$，自催化只有 $\bar{X}_\mathrm{n}^2 = 1 + 2c_0^2kt$。
- 同样的统计给出最可几分布 $N_x = (1-p)p^{x-1}$ 与 $Đ = 1 + p \to 2$，它是线性聚缩聚物的基准。
- 聚缩聚是平衡。封闭体系只给出 $\bar{X}_\mathrm{n} = 1 + \sqrt{K}$，所以必须把副产物脱除到 ppm 水平（$\bar{X}_\mathrm{n} \approx (Kc_0/[\mathrm{W}])^{1/2}$），而逆反应是化学回收的基础。
- $f > 2$ 的单体给出支化与凝胶点。Flory–Stockmayer 预言 $\alpha_\mathrm{c} = 1/(f-1)$（对 $\mathrm{A}_f + \mathrm{B}_2$，$p_\mathrm{c} = [r(f-1)]^{-1/2}$），Carothers 给出 $p_\mathrm{c} = 2/f_\mathrm{av}$。真实凝胶点介于两者之间，因环化略高于 Flory–Stockmayer。
:::

## 习题

::: exercise 98% 转化率下的链长 {level=1 check="50"}
一种 A–B 羟基酸聚合至酸基团 98.0% 转化率。$\bar{X}_\mathrm{n}$ 是多少？（输入 $\bar{X}_\mathrm{n}$。）
::: solution
$\bar{X}_\mathrm{n} = 1/(1 - 0.980) = 50$。对 A–B 单体，化学计量自动平衡，Carothers 方程直接适用。
:::
:::

::: exercise 目标链长所需的转化率 {level=1 check="0.995"}
化学计量的二胺–二酸聚合要达到 $\bar{X}_\mathrm{n} = 200$，反应程度需多大？（输入 $p$。）
::: solution
$p = 1 - 1/\bar{X}_\mathrm{n} = 1 - 1/200 = 0.995$。未反应的基团可以剩半个百分点，但不能再多。
:::
:::

::: exercise Carothers 凝胶点 {level=1 check="0.833"}
甘油与邻苯二甲酸按物质的量比 $2 : 3$ 混合。用 Carothers 方法预言凝胶点的反应程度。（输入 $p_\mathrm{c}$。）
::: solution
$f_\mathrm{av} = (2\times3 + 3\times2)/5 = 2.4$，$p_\mathrm{c} = 2/2.4 = 0.833$。Flory–Stockmayer 值是 $0.707$，实验介于两者之间、靠近较低的那个（[[#ex-gel]]）。
:::
:::

::: exercise 百分之一的过量 {level=2 check="201"}
一次尼龙-6,6 合成中，己二酸按比二胺摩尔过量 1.00% 称量。胺基团全部反应时，极限 $\bar{X}_\mathrm{n}$（以结构单元计）是多少？（输入 $\bar{X}_\mathrm{n}$。）
::: solution
$r = N_\mathrm{NH_2}/N_\mathrm{COOH} = 1/1.01 = 0.9901$。$p \to 1$ 时 $\bar{X}_\mathrm{n} = (1+r)/(1-r) = 1.9901/0.0099 = 201$。对应 $\bar{M}_\mathrm{n} \approx 201 \times 113.16 = 2.27\times10^{4}\ \mathrm{g\,mol^{-1}}$，是注塑级尼龙的典型值。
:::
:::

::: exercise 等待一场自催化聚酯 {level=2 check="8.06"}
一场自催化聚酯化在 $2.00\ \mathrm{h}$ 后达到 $p = 0.90$。假定[[#eq-self-cat]]自 $t = 0$ 起成立，达到 $p = 0.95$ 需多久（从开始计）？（以小时输入时间。）
::: solution
$\bar{X}_\mathrm{n}^2 - 1 = 2c_0^2kt$。$p = 0.90$ 时 $\bar{X}_\mathrm{n}^2 - 1 = 100 - 1 = 99$。$p = 0.95$ 时为 $400 - 1 = 399$。时间正比于此量，所以 $t = 2.00 \times 399/99 = 8.06\ \mathrm{h}$。$\bar{X}_\mathrm{n}$ 加倍，时间四倍——这就是自催化的平方根代价。
:::
:::

::: exercise 四官能度体系的凝胶点 {level=2 check="0.577"}
四官能度胺（$f = 4$）与化学计量的双官能度试剂（所有 A 基团在四官能度单元上，所有 B 基团双官能度，$r = 1$）固化。预言 Flory–Stockmayer 凝胶点。（$p_\mathrm{c}$ 保留三位有效数字。）
::: solution
$p_\mathrm{c} = 1/\sqrt{r(f-1)} = 1/\sqrt{3} = 0.577$。对比 $f = 3$ 给出的 $0.707$：每个支化点更多的臂，更早的凝胶。（真实环氧–胺体系更微妙，因为每个伯胺 N–H 与其变成的仲 N–H 以不同的速率常数反应，这违反了等活性。）
:::
:::

::: exercise 长聚酯所需的水含量 {level=3 check="0.000505"}
某聚酯化 $K = 1.0$，各官能团 $c_0 = 5.0\ \mathrm{mol\,dm^{-3}}$。用精确平衡关系 $K = p[\mathrm{W}]/(c_0(1-p)^2)$，求允许 $\bar{X}_\mathrm{n} = 100$ 的水浓度，并说明该浓度升高十倍时 $\bar{X}_\mathrm{n}$ 会怎样。（以 $\mathrm{mol\,dm^{-3}}$ 输入 $[\mathrm{W}]$。）
::: solution
$\bar{X}_\mathrm{n} = 100$ 时 $p = 0.99$：
$$
[\mathrm{W}] = \frac{Kc_0(1-p)^2}{p} = \frac{(1.0)(5.0)(1.0\times10^{-4})}{0.99} = 5.05\times10^{-4}\ \mathrm{mol\,dm^{-3}} .
$$
由于 $\bar{X}_\mathrm{n} \approx (Kc_0/[\mathrm{W}])^{1/2}$，$[\mathrm{W}]$ 升高十倍使 $\bar{X}_\mathrm{n}$ 降为 $1/\sqrt{10}$，降到约 32。链被水解切断，直到达到新的平衡。这就是 PET 熔融加工前必须彻底干燥的原因：熔体里几百 ppm 的水就会明显降低摩尔质量与制件的强度。
:::
:::

::: exercise 推导并应用非计量的 Carothers 方程 {level=3 check="66.8"}
(a) 从第一性原理推导[[#eq-carothers-r]]，陈述每条假定。(b) 一场聚合以 $r = 0.990$ 进行，在 $p = 0.990$ 处停止。计算 $\bar{X}_\mathrm{n}$，并与 $r = 1$、同一 $p$ 下的值比较。（$r = 0.990$、$p = 0.990$ 时的 $\bar{X}_\mathrm{n}$ 保留三位有效数字。）
::: hint
先数初始分子数，再每形成一个连接减一个分子。
:::
::: solution
(a) 同[[#prop-carothers]]的证明。双官能团分子上带 $N_\mathrm{A}$ 个 A 与 $N_\mathrm{A}/r$ 个 B，初始有 $\tfrac12N_\mathrm{A}(1 + 1/r)$ 个分子。$pN_\mathrm{A}$ 个连接每个连接两个分子。假定是无环、无副反应、只有双官能团单体。于是 $N = \tfrac12N_\mathrm{A}(1 + 1/r - 2p)$，$\bar{X}_\mathrm{n} = N_0/N = (1+r)/(1+r-2rp)$。

(b) $\bar{X}_\mathrm{n} = 1.990/(1.990 - 2\times0.990\times0.990) = 1.990/(1.990 - 1.9602) = 1.990/0.0298 = 66.8$。$r = 1$、$p = 0.990$ 时 $\bar{X}_\mathrm{n} = 100$。99% 转化率下 1% 的失衡已经损失了三分之一的链长，因为过量的 B 端与未反应的 A 端一起把链封住了。
:::
:::
