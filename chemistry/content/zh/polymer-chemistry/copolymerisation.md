聚苯乙烯是硬而脆的玻璃，聚丁二烯是软橡胶。把两种单体混在一起共聚，得到的是丁苯橡胶（SBR），汽车轮胎的主要材料。把它们做成一段聚苯乙烯、一段聚丁二烯、再接一段聚苯乙烯的长链，得到的材料在室温下是橡胶，却也能像热塑性塑料那样熔融、模塑。把聚丁二烯链接枝到聚苯乙烯上，得到高抗冲聚苯乙烯，韧到足以做冰箱内衬。同样的两种单体给出三种不同的材料。不同的是链上单元的**序列**，而序列由共聚反应动力学决定。

**共聚物**含有不止一种单体单元。本章回答两个问题。第一，单体混合物一起聚合时会产生什么样的组成与序列。答案是末端模型、Mayo–Lewis 方程与竞聚率，外加相同单元连续段的统计，以及活性较高的单体先被耗完引起的组成漂移。第二，如何制备序列经过*设计*的共聚物——交替、嵌段与接枝结构——以及嵌段共聚物为什么分离成有序的纳米尺度微区。两者都建立在[[polymer-chemistry/radical-polymerisation]]的链式增长动力学和[[polymer-chemistry/controlled-polymerisation]]的活性方法之上。

## 共聚物的种类

::: definition 共聚物的序列类型 {#def-copolymer-types}
对单体单元 A 与 B，IUPAC 区分：

- **统计共聚物** poly(A-*stat*-B)：序列服从某种统计规律，如下文的末端模型。**无规共聚物** poly(A-*ran*-B)是特例：在某位置找到某一单元的概率与其邻居无关（伯努利统计）。
- **交替共聚物** poly(A-*alt*-B)：$\mathrm{{-}ABABAB{-}}$。
- **梯度共聚物**：组成沿链连续变化。
- **嵌段共聚物** poly(A)-*block*-poly(B)：长的 A 序列连接长的 B 序列。可以是两嵌段（AB）、三嵌段（ABA）、多嵌段或星形。
- **接枝共聚物** poly(A)-*graft*-poly(B)：A 主链上接枝 B 侧链。

共聚物的**瞬时组成**是某一时刻生成的聚合物中 A 单元的摩尔分数 $F_\mathrm{A}$。它一般不同于该时刻单体混合物中 A 的摩尔分数 $f_\mathrm{A}$。
:::

序列类型决定性能。统计共聚物在两种均聚物的玻璃化转变温度之间只有一个玻璃化转变，是一种单一材料。引入百分之几的第二单体是调节结晶度的标准手段：线性低密度聚乙烯含百分之几的丁-1-烯、己-1-烯或辛-1-烯，其短支链破坏结晶。相反，嵌段与接枝共聚物通常保留各自组分两个玻璃化转变，因为它们较长的 A 序列与 B 序列会分离成不同的微区。

## 末端模型

在单体 $\mathrm{M_1}$ 与 $\mathrm{M_2}$ 的（自由基或离子型）共聚反应中，增长链端有两类：一类以 $\mathrm{M_1}$ 单元结尾，写作 $\sim\!\mathrm{M_1\cdot}$；另一类以 $\mathrm{M_2}$ 结尾，写作 $\sim\!\mathrm{M_2\cdot}$。**末端模型**假设链端的反应性只取决于末端单元。每个链端都可加成任一单体，于是共有四个增长反应：

$$
\begin{aligned}
\sim\!\mathrm{M_1\cdot} + \mathrm{M_1} &\xrightarrow{k_{11}} \sim\!\mathrm{M_1\cdot} &\qquad \sim\!\mathrm{M_1\cdot} + \mathrm{M_2} &\xrightarrow{k_{12}} \sim\!\mathrm{M_2\cdot} \\
\sim\!\mathrm{M_2\cdot} + \mathrm{M_1} &\xrightarrow{k_{21}} \sim\!\mathrm{M_1\cdot} &\qquad \sim\!\mathrm{M_2\cdot} + \mathrm{M_2} &\xrightarrow{k_{22}} \sim\!\mathrm{M_2\cdot}
\end{aligned}
$$

::: definition 竞聚率 {#def-reactivity-ratios}
单体对的**竞聚率**为
$$
r_1 = \frac{k_{11}}{k_{12}},\qquad r_2 = \frac{k_{22}}{k_{21}} .
$$
$r_1$ 度量以 $\mathrm{M_1}$ 结尾的链对自身单体相对于另一单体的偏好。$r_1 > 1$ 表示 $\sim\!\mathrm{M_1\cdot}$ 偏好加 $\mathrm{M_1}$，$r_1 < 1$ 表示偏好 $\mathrm{M_2}$，$r_1 = 0$ 表示完全不能加 $\mathrm{M_1}$。竞聚率是单体对、机理（自由基、阴离子、阳离子）的属性，并与温度、溶剂有微弱的依赖关系。
:::

::: proposition 共聚方程（Mayo–Lewis） {#prop-mayo-lewis}
在末端模型下，对两类链端取稳态假设并设链很长，两种单体进入共聚物的速率之瞬时比为
$$
\frac{\mathrm{d}[\mathrm{M_1}]}{\mathrm{d}[\mathrm{M_2}]} = \frac{[\mathrm{M_1}]}{[\mathrm{M_2}]}\cdot\frac{r_1[\mathrm{M_1}] + [\mathrm{M_2}]}{[\mathrm{M_1}] + r_2[\mathrm{M_2}]} .
$$ {#eq-mayo-lewis}
用摩尔分数写出，单体投料中 $f_1 = 1 - f_2$，生成的共聚物中 $F_1 = 1 - F_2$，
$$
F_1 = \frac{r_1f_1^2 + f_1f_2}{r_1f_1^2 + 2f_1f_2 + r_2f_2^2} .
$$ {#eq-mayo-lewis-f}
:::

::: proof
单体 $\mathrm{M_1}$ 被两类链端的加成消耗，$\mathrm{M_2}$ 亦然：
$$
-\frac{\mathrm{d}[\mathrm{M_1}]}{\mathrm{d}t} = k_{11}[\mathrm{M_1\cdot}][\mathrm{M_1}] + k_{21}[\mathrm{M_2\cdot}][\mathrm{M_1}],
\qquad
-\frac{\mathrm{d}[\mathrm{M_2}]}{\mathrm{d}t} = k_{12}[\mathrm{M_1\cdot}][\mathrm{M_2}] + k_{22}[\mathrm{M_2\cdot}][\mathrm{M_2}] .
$$
链端只能通过交叉增长步骤从一类变成另一类。自身增长保持类型不变，而对长链来说引发与终止比增长慢得多。因此每类链端的稳态要求两种转化相平衡：
$$
k_{12}[\mathrm{M_1\cdot}][\mathrm{M_2}] = k_{21}[\mathrm{M_2\cdot}][\mathrm{M_1}]
\qquad\Longrightarrow\qquad
\frac{[\mathrm{M_1\cdot}]}{[\mathrm{M_2\cdot}]} = \frac{k_{21}[\mathrm{M_1}]}{k_{12}[\mathrm{M_2}]} .
$$
把第一个速率方程除以第二个，再把分子分母同除以 $[\mathrm{M_2\cdot}]$ 并代入链端之比：
$$
\frac{\mathrm{d}[\mathrm{M_1}]}{\mathrm{d}[\mathrm{M_2}]} = \frac{[\mathrm{M_1}]\left(k_{11}\dfrac{k_{21}[\mathrm{M_1}]}{k_{12}[\mathrm{M_2}]} + k_{21}\right)}{[\mathrm{M_2}]\left(k_{12}\dfrac{k_{21}[\mathrm{M_1}]}{k_{12}[\mathrm{M_2}]} + k_{22}\right)}
= \frac{[\mathrm{M_1}]}{[\mathrm{M_2}]}\cdot\frac{k_{21}\left(r_1[\mathrm{M_1}] + [\mathrm{M_2}]\right)/[\mathrm{M_2}]}{k_{21}\left([\mathrm{M_1}] + r_2[\mathrm{M_2}]\right)/[\mathrm{M_2}]} .
$$
这里在分子中用了 $k_{11}/k_{12} = r_1$，在分母中用了 $k_{22}/k_{21} = r_2$。公因子 $k_{21}/[\mathrm{M_2}]$ 相消，即得[[#eq-mayo-lewis]]。为得到摩尔分数形式，写出 $F_1/F_2 = \mathrm{d}[\mathrm{M_1}]/\mathrm{d}[\mathrm{M_2}]$ 与 $[\mathrm{M_1}]/[\mathrm{M_2}] = f_1/f_2$，于是 $F_1/F_2 = f_1(r_1f_1 + f_2)/[f_2(f_1 + r_2f_2)]$，再用 $F_1 = (F_1/F_2)/(1 + F_1/F_2)$。展开即得[[#eq-mayo-lewis-f]]。$\blacksquare$
:::

注意结果中*没有*什么。引发与终止速率都消去了，速率常数的绝对大小也消去了。共聚组成只取决于两个速率常数之比和投料组成。这正是竞聚率如此有用之处，也是它的局限：仅凭组成数据无法告诉你共聚反应跑得多快。

### 共聚行为的类型

乘积 $r_1r_2$ 对行为分类。

- **理想共聚**，$r_1r_2 = 1$。两类链端对两种单体有相同的相对偏好（$k_{11}/k_{12} = k_{21}/k_{22}$），末端单元无所谓。共聚方程化为 $F_1/F_2 = r_1f_1/f_2$，序列是无规的（伯努利），共聚物总是富含较活泼的单体。这是理想溶液气相的聚合物类比：挥发度较高的组分在气相中富集。
- **交替倾向**，$r_1r_2 < 1$ 且两个比值都小于 1。每个链端都偏好加*另一个*单体。在 $r_1 = r_2 = 0$ 的极限下共聚物完全交替，任何投料下都有 $F_1 = 0.5$。多数真实的自由基对位于这一区域，交替由极性驱动：富电子单体（苯乙烯、乙烯基醚）优先加到缺电子自由基（丙烯酸酯、马来酸酐）上，反之亦然。
- **恒比共聚（共沸共聚）。** 当 $r_1$ 与 $r_2$ 都小于 1（或都大于 1）时，存在一个投料组成，使共聚物组成与投料组成相同，组成因此不漂移。在[[#eq-mayo-lewis-f]]中令 $F_1 = f_1$ 得
$$
f_1^\text{az} = \frac{1 - r_2}{2 - r_1 - r_2} .
$$ {#eq-azeotrope}
- **嵌段倾向**，$r_1 > 1$ 且 $r_2 > 1$。每个链端偏好自己的单体，产生长连续段。这在自由基共聚中罕见，其极端是两种均聚物并排生成。

## 序列：相同单元的连续段

共聚方程给出整体组成。末端模型还给出*序列统计*，因为它把链描述为一阶马尔可夫过程：下一个单元只取决于当前的末端单元。

::: proposition 末端模型的序列统计 {#prop-runs}
在末端模型下，以 $\mathrm{M_1}$ 结尾的链加上 $\mathrm{M_1}$ 的概率为
$$
p_{11} = \frac{k_{11}[\mathrm{M_1}]}{k_{11}[\mathrm{M_1}] + k_{12}[\mathrm{M_2}]} = \frac{r_1[\mathrm{M_1}]}{r_1[\mathrm{M_1}] + [\mathrm{M_2}]},
\qquad p_{12} = 1 - p_{11},
$$
类似地 $p_{22} = r_2[\mathrm{M_2}]/(r_2[\mathrm{M_2}] + [\mathrm{M_1}])$。$\mathrm{M_1}$ 单元连续段（不间断序列）的长度服从几何分布，$P(n) = p_{11}^{\,n-1}p_{12}$，数均连续段长度为
$$
\bar{n}_1 = \frac{1}{p_{12}} = 1 + r_1\frac{[\mathrm{M_1}]}{[\mathrm{M_2}]},
\qquad
\bar{n}_2 = 1 + r_2\frac{[\mathrm{M_2}]}{[\mathrm{M_1}]} .
$$ {#eq-run-length}
:::

::: proof
$\sim\!\mathrm{M_1\cdot}$ 上两个相互竞争的加成速率为 $k_{11}[\mathrm{M_1}]$ 与 $k_{12}[\mathrm{M_2}]$，所以事件为自身增长的分数即如上所述为 $p_{11}$。分子分母同除以 $k_{12}$ 就引入 $r_1$。$\mathrm{M_1}$ 的连续段在 $\mathrm{M_1}$ 加到 $\mathrm{M_2}$ 端链上时开始。它的长度恰为 $n$，当且仅当随后 $n - 1$ 次加成都是 $\mathrm{M_1}$（每次概率 $p_{11}$）而再下一次是 $\mathrm{M_2}$（概率 $p_{12}$），于是 $P(n) = p_{11}^{\,n-1}p_{12}$。这与[[polymer-chemistry/polymer-structure#def-flory]]的链长是同一个几何分布，均值 $1/(1 - p_{11}) = 1/p_{12}$。最后，$1/p_{12} = (r_1[\mathrm{M_1}] + [\mathrm{M_2}])/[\mathrm{M_2}] = 1 + r_1[\mathrm{M_1}]/[\mathrm{M_2}]$。$\blacksquare$
:::

作为检验，平均连续段长度之比 $\bar{n}_1/\bar{n}_2$ 等于单元数之比 $F_1/F_2$，因为 $\mathrm{M_1}$ 的连续段与 $\mathrm{M_2}$ 的连续段交替出现、数目相等。把[[#eq-run-length]]中 $\bar{n}_1$ 的式子除以 $\bar{n}_2$ 的式子，就还原出[[#eq-mayo-lewis]]。连续段长度公式让"交替倾向"变得具体。对 $f_1 = 0.25$ 的苯乙烯–MMA，苯乙烯连续段平均 $\bar{n}_1 = 1 + 0.52/3 = 1.17$ 个单元，MMA 连续段 $\bar{n}_2 = 1 + 0.46\times3 = 2.38$。苯乙烯大多以孤立单元出现，每个夹在短 MMA 序列之间。序列统计可用 $^{13}\mathrm{C}$ NMR 检验，它能分辨以某个单元为中心的 $\mathrm{M_1M_1M_1}$、$\mathrm{M_1M_1M_2}$、$\mathrm{M_2M_1M_2}$ 等三单元组。对末端模型预言的偏离，正是发现**次末端效应**（倒数第二个单元也有影响）的途径。对若干常见单体对（包括苯乙烯–MMA）它相当显著：末端模型能拟合组成，却预言不了总速率。

## 组成漂移

除非投料恰在恒比组成，生成的共聚物组成总与投料不同。投料因此被更快进入共聚物的单体消耗而贫化，其组成在反应过程中*漂移*，共聚物组成随之漂移。高转化率时收得的聚合物是不同时刻生成的、组成各异的各种链的混合物。若组成差异大到链彼此不相容，这种混合物就可能发雾或发脆。

::: proposition 组成漂移（Skeist） {#prop-skeist}
设 $x$ 为单体的总转化分数，$f_1(x)$ 为转化率 $x$ 时的投料组成。$\mathrm{M_1}$ 的质量衡算给出
$$
\frac{\mathrm{d}f_1}{\mathrm{d}x} = \frac{f_1 - F_1(f_1)}{1 - x},
$$ {#eq-skeist}
其中 $F_1(f_1)$ 由[[#eq-mayo-lewis-f]]给出。**累积**共聚物组成（转化率 $x$ 之前形成的全部聚合物）为
$$
\bar{F}_1 = \frac{f_1^0 - (1-x)f_1}{x} .
$$
:::

::: proof
设 $N$ 为剩余单体总量、$N_0$ 为其初值，于是 $x = 1 - N/N_0$。剩余 $\mathrm{M_1}$ 的量为 $f_1N$。当 $\mathrm{d}N$ 的单体聚合（$\mathrm{d}N < 0$），生成的共聚物带走 $F_1\,\mathrm{d}N$ 的 $\mathrm{M_1}$，所以
$$
\mathrm{d}(f_1N) = F_1\,\mathrm{d}N \quad\Longrightarrow\quad N\,\mathrm{d}f_1 = (F_1 - f_1)\,\mathrm{d}N .
$$
代入 $\mathrm{d}N = -N_0\,\mathrm{d}x$ 与 $N = N_0(1-x)$，即得 $\mathrm{d}f_1/\mathrm{d}x = (f_1 - F_1)/(1 - x)$。累积组成由守恒量得出：现在聚合物中的 $\mathrm{M_1}$ 为 $f_1^0N_0 - f_1N$，聚合物中的单体总量为 $xN_0$。两式相除即得。$\blacksquare$
:::

::: example 理想共聚对会漂移到多远？ {#ex-drift}
对上图的理想共聚对（$r_1 = 2$、$r_2 = 0.5$、$f_1^0 = 0.50$），转化率 $x = 0.50$ 时的投料组成为 $f_1 = 0.382$。求此时正在生成的共聚物组成、至此生成的全部共聚物的累积组成，并与最初形成的共聚物比较。
::: solution
理想对有 $F_1/F_2 = r_1f_1/f_2$，所以 $F_1 = r_1f_1/(r_1f_1 + f_2)$。在起点（$f_1 = 0.50$）：
$$

$$
在 $x = 0.50$（$f_1 = 0.382$，$f_2 = 0.618$）：$F_1 = 0.764/(0.764 + 0.618) = 0.553$。累积组成：
$$
\bar{F}_1 = \frac{0.50 - (0.50)(0.382)}{0.50} = 0.618 .
$$
（这些数字是精确的：解析解给出半程转化处 $f_1 = (3 - \sqrt5)/2$，$\bar{F}_1 = (\sqrt5 - 1)/2$。）共聚物从 67 mol% 单体 1 漂移到半程转化处的 55 mol%，90% 转化时接近 25%，差异幅度足以影响透明性和力学性能。工业对策是在低转化率停止并回收单体，或者**连续补加较活泼的单体**（半间歇"贫料"进料操作），使 $f_1$ 保持恒定。活性聚合则有意利用漂移：由于每条链全程都在增长，漂移会把组成梯度写进每条链，得到梯度共聚物。
:::
:::

## 竞聚率的预测与测定

### Q–e 方案

单体对数以千计，逐一测量是不可能的。1947 年 Alfrey 与 Price 提出一个经验方案，给每个单体赋予两个参数。$Q$ 描述共振稳定化（反应性），$e$ 描述极性。自由基 $i$ 加单体 $j$ 的速率常数写作 $k_{ij} = P_iQ_j\exp(-e_ie_j)$。于是
$$
r_1 = \frac{Q_1}{Q_2}\exp[-e_1(e_1 - e_2)],
\qquad
r_2 = \frac{Q_2}{Q_1}\exp[-e_2(e_2 - e_1)],
\qquad
r_1r_2 = \exp[-(e_1 - e_2)^2] .
$$ {#eq-qe}
苯乙烯是基准，取 $Q = 1.00$、$e = -0.80$。该方案是**经验的**，只能半定量。它的理论基础（单体与其衍生自由基具有同一个极性 $e$）并不可靠。但它抓住了两个真实的趋势：共轭单体（$Q$ 大）活泼，形成稳定而不活泼的自由基；乘积 $r_1r_2 = \exp[-(e_1 - e_2)^2]$ 随极性之差增大而下降，这正是交替倾向。

::: example 由 Q 与 e 估算竞聚率 {#ex-qe}
估算苯乙烯（1，$Q = 1.00$，$e = -0.80$）与甲基丙烯酸甲酯（2，$Q = 0.78$，$e = 0.40$）的 $r_1$ 与 $r_2$，并与实测值 $0.52$、$0.46$ 比较。
::: solution
$e_1 - e_2 = -1.20$。于是
$$
r_1 = \frac{1.00}{0.78}\exp[-(-0.80)(-1.20)] = 1.282\,e^{-0.96} = 0.49,
\qquad
r_2 = \frac{0.78}{1.00}\exp[-(0.40)(1.20)] = 0.78\,e^{-0.48} = 0.48 .
$$
与实验值的偏差约在 5% 以内。这好得罕见，因为参数本就部分是对这一对单体拟合出来的。乘积 $r_1r_2 = e^{-1.44} = 0.24$ 精确重现了交替倾向。对极性差别很大的单体对，Q–e 的预言可能差出两倍甚至更多，任何时候都应优先采用实测比值。
:::
:::

### 竞聚率的测定

测定竞聚率的方法是在若干投料组成下进行共聚并控制到**低转化率**（约 5–10% 以下，使 $f_1$ 尚未漂移），用 NMR、元素分析或其他方法测定 $F_1$。经典分析把共聚方程线性化。记投料比 $X = [\mathrm{M_1}]/[\mathrm{M_2}]$、聚合物比 $Y = \mathrm{d}[\mathrm{M_1}]/\mathrm{d}[\mathrm{M_2}] = F_1/F_2$，**Fineman–Ross** 形式为
$$
\frac{X(Y-1)}{Y} = r_1\frac{X^2}{Y} - r_2 ,
$$ {#eq-fineman-ross}
这是一条斜率 $r_1$、截距 $-r_2$ 的直线。由[[#eq-mayo-lewis]]交叉相乘再除以 $Y$ 即得。线性化会歪曲实验误差：处于极端投料比的点主宰拟合。因此现行 IUPAC 建议偏好用非线性最小二乘直接拟合[[#eq-mayo-lewis-f]]，并报告 $(r_1, r_2)$ 的联合置信区间。拟合与置信区间的办法见 Maths Atlas 的回归部件（[/learn/maths/](/learn/maths/)）。

::: warning 竞聚率不是速率常数，而且依赖机理 {#warn-reactivity-ratios}
人们总想把 $r_1 > r_2$ 读成"单体 1 聚合得更快"。它没有这个意思。竞聚率比较的是*同一链端*的两个速率常数，对哪种均聚更快、共聚跑多快则不置一词。苯乙烯的均聚比甲基丙烯酸甲酯慢（$60\ ^\circ\mathrm{C}$ 下 $k_\mathrm{p}$ 分别为 341 与约 830 $\mathrm{dm^{3}\,mol^{-1}\,s^{-1}}$），二者的竞聚率却几乎相等。比值随机理彻底改变：在*阴离子*共聚中，苯乙烯与 MMA 最初给出近乎纯的聚（MMA），因为较缺电子的单体对碳负离子的反应性高得多；*阳离子*共聚中情况正好相反。自由基竞聚率不能搬给离子体系；共聚单体对在齐格勒-纳塔催化剂上的竞聚率还依赖催化剂。最后，共聚方程描述的是*瞬时*组成。把它用于高转化率样品的平均组成——仿佛漂移没有发生——会得出错误的竞聚率。
:::

## 交替、嵌段与接枝共聚物

**交替共聚物**自发形成于强给体-受体单体对。苯乙烯与马来酸酐（$r_1 \approx 0.02$，$r_2 \approx 0$）在几乎整个投料范围内给出交替共聚物：马来酸酐不均聚，苯乙烯基自由基加它比加苯乙烯快约五十倍。另一极端，乙酸乙烯酯 (1) 与苯乙烯 (2)（$r_1 \approx 0.01$，$r_2 \approx 55$）几乎不能共聚。乙酸乙烯酯自由基未被稳定、极其活泼，会立刻加上苯乙烯生成稳定的苄基自由基，而后者几乎再也不加回乙酸乙烯酯。因此苯乙烯在耗尽之前起着乙酸乙烯酯聚合*抑制剂*的作用。

**嵌段共聚物**需要活性或受控链端（[[polymer-chemistry/controlled-polymerisation]]）。路线有顺序加单体、活性链偶联，以及大分子引发剂法——用一种方法制得的聚合物带着能引发另一种单体的端基。阴离子合成中加料*顺序*很要紧，因为第一嵌段的阴离子必须碱性足够强才能引发第二种单体。聚苯乙烯基锂能引发甲基丙烯酸酯，聚甲基丙烯酸酯的烯醇负离子却不能引发苯乙烯。所以聚（苯乙烯）-*block*-聚（甲基丙烯酸甲酯）要先聚合苯乙烯，通常还先用 1,1-二苯基乙烯"封顶"聚苯乙烯链端，以缓和它对酯基的反应性。SBS 三嵌段共聚物用顺序加料制得，或用二卤化物把两个苯乙烯-丁二烯双嵌段双阴离子偶联起来。

**接枝共聚物**的形成方式有三种：主链上带有能引发新链的位点（引发接枝，"grafting from"）；把预先制成的链接到主链上（接枝偶联，"grafting onto"）；或者让**大分子单体**（带着可聚合端基的链）参与共聚（大分子单体共聚，"grafting through"）。自由基聚合中向聚合物的链转移就是一种失控的引发接枝。高抗冲聚苯乙烯与 ABS（丙烯腈-丁二烯-苯乙烯）是在溶有聚丁二烯的体系中聚合苯乙烯（或苯乙烯与丙烯腈）制得的。自由基从橡胶上夺取烯丙基氢，把聚苯乙烯接枝上去；接枝链充当相容化剂，形成约 $1\ \mu\mathrm{m}$ 的橡胶颗粒以吸收冲击能。

### 嵌段共聚物的微相分离

大多数聚合物对彼此不相容，理由正是[[polymer-chemistry/polymer-solutions]]导出的热力学：两条长链混合的熵微乎其微，相互作用稍有不利便使它们分离。在共混物中，两种聚合物在宏观尺度上分开。在嵌段共聚物中却不能，因为它们由共价键连在一起。它们分离成**微区**，尺寸由链段长度决定，典型为 5–100 nm。驱动力的强弱用乘积 $\chi N$ 度量：$\chi$ 是 A、B 链段之间的 Flory–Huggins 相互作用参数，$N$ 是总聚合度。平均场理论（Leibler，1980）预言，对称双嵌段（A 与 B 体积分数相等）在 $\chi N$ 超过约 $10.5$ 时转变为层状相；低于该值则是无序熔体。非对称双嵌段随少数组分分数 $f_\mathrm{A}$ 减小，依次形成双连续 gyroid 相、六方堆积柱状相，以及少数组分的球以体心立方堆积于多数组分基体中的相。强偏析极限下，微区周期约按 $N^{2/3}$ 增长。

这种纳米尺度的有序有用处。在 SBS 热塑性弹性体中，约 30%（质量）的聚苯乙烯形成直径约 20 nm 的玻璃态球或柱，锚定在橡胶态聚丁二烯基体中。每条聚丁二烯链两端都系在玻璃态微区上，在聚苯乙烯玻璃化转变（约 $100\ ^\circ\mathrm{C}$）以下充当交联点，其上一旦软化，橡胶便可熔融加工、可以回收。PS-*b*-PMMA 的薄膜——其微区可在图形化表面上取向——正被研究用作图形化半导体特征的模板，特征尺寸低于光学光刻轻易可达的极限（"定向自组装"）。

::: example 嵌段共聚物要多长才能形成有序结构？ {#ex-odt}
聚苯乙烯-聚（甲基丙烯酸甲酯）的相互作用参数实测为 $\chi \approx 0.028 + 3.9/T$（$T$ 以开尔文计；Russell 与合作者，1990，按参考体积的每单元计）。用平均场判据 $(\chi N)_\mathrm{ODT} \approx 10.5$，估算对称 PS-*b*-PMMA 在 $150\ ^\circ\mathrm{C}$ 处于微相分离态所需的最小总聚合度。那大约相当于多大的摩尔质量？
::: solution
$T = 423\ \mathrm{K}$ 时：$\chi = 0.028 + 3.9/423 = 0.028 + 0.0092 = 0.037$。于是
$$
N_\mathrm{ODT} = \frac{10.5}{0.0372} = 2.8\times10^{2} .
$$
取重复单元摩尔质量约 $104$（苯乙烯）与 $100\ \mathrm{g\,mol^{-1}}$（MMA），并取链段与重复单元大致相当，总摩尔质量约为 $2.9\times10^{4}\ \mathrm{g\,mol^{-1}}$。更短的共聚物在 $150\ ^\circ\mathrm{C}$ 是无序的。这一对单体的 $\chi$ 很小且对温度依赖很弱，PS-*b*-PMMA 形成不了明显小于约 10 nm 的微区。因此 10 nm 以下的图形化要用 $\chi$ 更大的体系，如聚苯乙烯与聚（二甲基硅氧烷）或与聚丙交酯的组合。（涨落修正会把短链的临界 $\chi N$ 提高到平均场的 10.5 之上，所以这个估计是 $N$ 的下界。）
:::
:::

::: quiz
一次自由基共聚的 $r_1 = 0.05$、$r_2 = 0.08$。对 50 : 50 投料生成的共聚物，哪种描述正确？
- [ ] 它几乎是两种均聚物的共混物，因为两个竞聚率都很小。
- [x] 它接近交替：每个链端都强烈偏好加另一单体，大多数投料下 $F_1$ 接近 0.5。
- [ ] 它是理想的无规共聚物，因为 $r_1$ 与 $r_2$ 接近。
- [ ] 不知道绝对速率常数就无法预言其组成。
::: solution
竞聚率很小意味着 $k_{12} \gg k_{11}$、$k_{21} \gg k_{22}$：交叉增长占绝对优势，序列交替。取 $f_1 = 0.5$，[[#eq-mayo-lewis-f]]给出 $F_1 = (0.0125 + 0.25)/(0.0125 + 0.5 + 0.02) = 0.493$。理想共聚要求 $r_1r_2 = 1$，而不是 $r_1 \approx r_2$：这里 $r_1r_2 = 0.004$。组成只依赖比值（[[#prop-mayo-lewis]]），不依赖绝对速率常数。均聚物共混物则要求两个比值都*大*。
:::
:::

::: history
工业共聚物先于其理论出现。丁二烯-苯乙烯橡胶（Buna S）约 1929 年在 IG Farben 开发成功。其美国对应物 GR-S 在二战期间以紧急计划投产——当时日本的征服使盟国失去了与世界大部分天然橡胶的联系。末端模型共聚方程 1944 年由 Mayo（Frank Mayo）与 Lewis（Frederick Lewis）发表（*Journal of the American Chemical Society* 66, 1594），Alfrey（Turner Alfrey）与 Goldfinger（George Goldfinger）以及 Wall（Frederick Wall）也各自独立发表。Skeist（Isidor Skeist）1946 年处理了组成漂移。Alfrey 与 Price（Charles Price）1947 年提出 Q–e 方案，Fineman（Mortimer Fineman）与 Ross（Shane Ross）1950 年给出他们的线性化形式。嵌段共聚物微相分离理论 1980 年由 Leibler（Ludwik Leibler）建立在平均场基础上（*Macromolecules* 13, 1602）。其 $\chi N \approx 10.5$ 的有序-无序转变如今是教科书的地标，并经 Fredrickson 与 Helfand 的涨落理论得到修正。
:::

## 后续内容

把嵌段共聚物拆开的 $\chi$ 参数是[[polymer-chemistry/polymer-solutions]]的主题，Flory–Huggins 理论在那里解释聚合物为何很少互溶。共聚组成与序列由 NMR 和热分析测定，见[[polymer-chemistry/polymer-characterisation]]。无规共聚物的单个玻璃化转变或嵌段共聚物的两个玻璃化转变如何决定力学行为、热塑性弹性体如何工作，见[[polymer-chemistry/polymer-properties]]。自组装成胶束用于给药的亲疏水两嵌段共聚物出现在[[polymer-chemistry/functional-polymers]]。乙烯与 α-烯烃的有机金属共聚（LLDPE）使用[[polymer-chemistry/controlled-polymerisation]]中的催化剂。

::: summary
- 共聚物可为统计、无规、交替、梯度、嵌段或接枝。决定性能的不只是组成，还有序列。
- 末端模型有四个增长速率常数和两个竞聚率 $r_1 = k_{11}/k_{12}$、$r_2 = k_{22}/k_{21}$。链端稳态给出 Mayo–Lewis 方程 $F_1 = (r_1f_1^2 + f_1f_2)/(r_1f_1^2 + 2f_1f_2 + r_2f_2^2)$，与引发、终止和绝对速率无关。
- $r_1r_2 = 1$ 给出理想的无规共聚物。$r_1r_2 < 1$ 给出交替倾向；两个比值都低于 1 时在 $f_1 = (1-r_2)/(2-r_1-r_2)$ 处有恒比点。两者都高于 1 给出嵌段倾向。
- 连续段长度服从几何分布，$\bar{n}_1 = 1 + r_1[\mathrm{M_1}]/[\mathrm{M_2}]$。NMR 三单元组检验模型并揭示次末端效应。
- 偏离恒比组成时，投料与共聚物都随转化率漂移（Skeist 方程）。控制办法是低转化率或贫料进料；梯度共聚物则加以利用。
- Q–e 方案（经验性）估算竞聚率，$r_1r_2 = \exp[-(e_1-e_2)^2]$。测定用低转化率数据与非线性拟合。竞聚率依赖机理，不是速率常数。
- 嵌段共聚物需要活性链端与正确的加料顺序。$\chi N \gtrsim 10.5$ 时发生微相分离，给出纳米尺度的层状、gyroid、柱状或球状结构，是热塑性弹性体与纳米图形化的基础。
:::

## 习题

::: exercise 共聚物组成 {level=1 check="0.734"}
苯乙烯（$r_1 = 0.52$）与甲基丙烯酸甲酯（$r_2 = 0.46$）从 $f_1 = 0.80$ 的投料共聚。初始共聚物中 $F_1$ 是多少？（输入 $F_1$，保留三位有效数字。）
::: solution
$f_1 = 0.80$，$f_2 = 0.20$。分子 $= 0.52(0.64) + 0.16 = 0.3328 + 0.16 = 0.4928$。分母 $= 0.3328 + 0.32 + 0.46(0.04) = 0.6712$。所以 $F_1 = 0.734$。这里共聚物反而比投料*更贫*苯乙烯：在恒比点（$0.53$）之上，被富集的是少数单体 MMA。
:::
:::

::: exercise 恒比投料 {level=1 check="0.563"}
某单体对 $r_1 = 0.30$、$r_2 = 0.10$。投料中单体 1 的摩尔分数为多少时，共聚物与投料组成相同？（输入 $f_1$，保留三位有效数字。）
::: solution
$f_1^\text{az} = (1 - r_2)/(2 - r_1 - r_2) = 0.90/1.60 = 0.5625 \approx 0.563$。两个比值都小于 1，恒比点存在。
:::

::: exercise 平均连续段长度 {level=1 check="1.52"}
苯乙烯（$r_1 = 0.52$）与甲基丙烯酸甲酯在等摩尔投料下共聚，苯乙烯单元连续段的数均长度是多少？（输入 $\bar{n}_1$。）
::: solution
$\bar{n}_1 = 1 + r_1[\mathrm{M_1}]/[\mathrm{M_2}] = 1 + 0.52\times1 = 1.52$。MMA 连续段平均 $1.46$。两者都很短，与温和的交替倾向一致。
:::
:::

::: exercise 苯乙烯与丙烯腈的 Q–e 估算 {level=2 check="0.336"}
用 Q–e 方案估算苯乙烯（1，$Q = 1.00$，$e = -0.80$）与丙烯腈（2，$Q = 0.60$，$e = 1.20$）的 $r_1$。再估算 $r_2$，并与实测值（约 $0.40$ 与 $0.04$）比较评论。（输入 $r_1$，保留三位有效数字。）
::: solution
$e_1 - e_2 = -2.00$。$r_1 = (1.00/0.60)\exp[-(-0.80)(-2.00)] = 1.667\,e^{-1.60} = 1.667\times0.2019 = 0.336$。$r_2 = 0.60\exp[-(1.20)(2.00)] = 0.60\,e^{-2.40} = 0.054$。两者量级正确，强交替倾向（$r_1r_2 \approx 0.02$）也被抓住。20–35% 的误差是该方案的典型水平。苯乙烯-丙烯腈共聚物（SAN）在 $f_1 \approx 0.6$ 附近有恒比点，实际就在该投料附近生产以避免漂移。
:::
:::

::: exercise 乙酸乙烯酯加少量苯乙烯 {level=2 check="0.133"}
乙酸乙烯酯（1，$r_1 = 0.01$）与苯乙烯（2，$r_2 = 55$）从含 90 mol% 乙酸乙烯酯的投料共聚。最初生成的共聚物中乙酸乙烯酯的摩尔分数是多少？（输入 $F_1$，保留三位有效数字。）
::: solution
$f_1 = 0.90$，$f_2 = 0.10$。分子 $= 0.01(0.81) + 0.09 = 0.0981$。分母 $= 0.0081 + 0.18 + 55(0.01) = 0.7381$。所以 $F_1 = 0.133$。投料虽含 90% 乙酸乙烯酯，聚合物却含 87% 苯乙烯，且总速率极低，因为苯乙烯基自由基加乙酸乙烯酯极不情愿。在苯乙烯耗尽之前，乙酸乙烯酯的聚合实际上被抑制了。
:::

::: exercise 嵌段共聚物的有序化 {level=2 check="282"}
用 PS–PMMA 的 $\chi = 0.028 + 3.9/T$ 和平均场判据 $(\chi N)_\mathrm{ODT} = 10.5$，求对称 PS-*b*-PMMA 在 $423\ \mathrm{K}$ 保持有序所需的最小总聚合度 $N$。（输入 $N$，保留三位有效数字。）
::: solution
$\chi = 0.028 + 3.9/423 = 0.03722$，所以 $N = 10.5/0.03722 = 282$。在 $473\ \mathrm{K}$，$\chi = 0.03624$，$N = 290$。温度依赖性之弱意味着加热几乎不能使这一对单体无序化。
:::

::: exercise 共聚方程及其恒比点 {level=3 check="0.529"}
(a) 由四个增长步骤导出[[#eq-mayo-lewis]]，指明稳态假设用在何处。(b) 证明：当且仅当 $r_1$ 与 $r_2$ 都小于 1 或都大于 1 时，恒比点存在，且 $f_1^\text{az} = (1-r_2)/(2-r_1-r_2)$ 介于 0 与 1 之间。(c) 对苯乙烯–MMA（$r_1 = 0.52$、$r_2 = 0.46$）求值。（输入 $f_1^\text{az}$，保留三位有效数字。）
::: hint
对 (b)，令 $\mathrm{d}[\mathrm{M_1}]/\mathrm{d}[\mathrm{M_2}] = [\mathrm{M_1}]/[\mathrm{M_2}]$ 并约去公因子。
:::
::: solution
(a) 见[[#prop-mayo-lewis]]的推导。稳态假设体现为两个交叉增长速率相等，$k_{12}[\mathrm{M_1\cdot}][\mathrm{M_2}] = k_{21}[\mathrm{M_2\cdot}][\mathrm{M_1}]$，它确定了两类链端之比。

(b) 令进入比率等于投料比并约去 $[\mathrm{M_1}]/[\mathrm{M_2}]$，得 $r_1[\mathrm{M_1}] + [\mathrm{M_2}] = [\mathrm{M_1}] + r_2[\mathrm{M_2}]$，即 $(r_1 - 1)[\mathrm{M_1}] = (r_2 - 1)[\mathrm{M_2}]$。于是 $[\mathrm{M_1}]/[\mathrm{M_2}] = (1 - r_2)/(1 - r_1)$；浓度比必须为正，而这只有当 $1 - r_1$ 与 $1 - r_2$ 同号时才成立。用摩尔分数表示，$f_1 = (1-r_2)/[(1-r_1) + (1-r_2)] = (1-r_2)/(2 - r_1 - r_2)$，此时它介于 0 与 1 之间。

(c) $f_1^\text{az} = 0.54/1.02 = 0.529$。
:::
:::

::: exercise 由低转化率数据求竞聚率 {level=3 check="0.52"}
苯乙烯 (1) 与甲基丙烯酸甲酯 (2) 的五次低转化率共聚给出如下投料比 $X = [\mathrm{M_1}]/[\mathrm{M_2}]$ 与共聚物比 $Y = F_1/F_2$（由末端模型生成的模拟数据，取三位有效数字）：

| $X$ | $0.25$ | $0.50$ | $1.00$ | $2.00$ | $4.00$ |
|---|---|---|---|---|---|
| $Y$ | $0.398$ | $0.656$ | $1.04$ | $1.66$ | $2.76$ |

用 Fineman–Ross 方程[[#eq-fineman-ross]]求 $r_1$ 与 $r_2$，并解释真实数据为何更宜用非线性拟合。（输入 $r_1$，保留两位有效数字。）
::: hint
对每次实验计算 $G = X(Y-1)/Y$ 与 $H = X^2/Y$，再拟合 $G = r_1H - r_2$。
:::
::: solution
变换后的变量为：

| $H = X^2/Y$ | $0.157$ | $0.381$ | $0.962$ | $2.410$ | $5.797$ |
|---|---|---|---|---|---|
| $G = X(Y-1)/Y$ | $-0.378$ | $-0.262$ | $0.038$ | $0.795$ | $2.551$ |

对这些点作最小二乘直线，斜率 $0.519$、截距 $-0.460$，所以 $r_1 = 0.52$、$r_2 = 0.46$。用精确（模拟）数据时任何方法都能还原真值。对真实数据，这一变换给各点以悬殊的权重：$X = 4$ 的实验 $H = 5.8$，主宰斜率，其 $Y$ 中的误差还被放大。交换两种单体的标号会得到不同的答案，一个健全的估计量不该如此。对[[#eq-mayo-lewis-f]]作 $F_1(f_1)$ 的非线性最小二乘拟合、并对 $F_1$ 的误差正确加权，可避免这两个问题，还能给出联合置信区间。
:::
